# 接口

## interface AssertPrintable<T>

```
public interface AssertPrintable<T> {
    prop hasNestedDiff: Bool
    func pprintForAssertion(
        pp: PrettyPrinter,
        that: T,
        thisPrefix: String,
        thatPrefix: String,
        level: Int64
    ): PrettyPrinter
}
```

功能：提供打印 [@Assert](./../../unittest_testmacro/unittest_testmacro_package_api/unittest_testmacro_package_macros.html#assert-宏)/[@Expect](./../../unittest_testmacro/unittest_testmacro_package_api/unittest_testmacro_package_macros.html#expect-宏) 的检查结果的方法。

