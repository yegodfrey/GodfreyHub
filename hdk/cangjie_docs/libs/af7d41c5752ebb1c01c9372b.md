# std.unittest.mock.mockmacro

## 功能介绍

unittest.mock.mockmacro 为 mock 框架提供了用户所需的宏。

## API 列表

### 宏

| 宏名 | 功能 |
| --- | --- |
| [Called](./unittest_mock_mockmacro_package_api/unittest_mock_mockmacro_package_macros.html#called-宏) | 创建一个[验证语句](./../unittest_mock/unittest_mock_samples/mock_framework_verification.html#验证语句和-called-宏)。 |
| [On](./unittest_mock_mockmacro_package_api/unittest_mock_mockmacro_package_macros.html#on-宏) | 使用[配置 API](./../unittest_mock/unittest_mock_samples/mock_framework_basics.html#配置-api) 定义 mock/spy 对象成员的行为（或重新定义 spy 对象）。 |
