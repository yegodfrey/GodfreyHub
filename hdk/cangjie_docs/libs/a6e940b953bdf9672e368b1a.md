# 枚举

## enum SeekPosition

```
public enum SeekPosition {
    | Current(Int64)
    | Begin(Int64)
    | End(Int64)
}
```

功能：该枚举类型表示光标在文件中的位置。

### Begin(Int64)

```
Begin(Int64)
```

功能：表示从起点开始移动指定的长度。

### Current(Int64)

```
Current(Int64)
```

功能：表示从当前位置开始移动指定的长度。

### End(Int64)

```
End(Int64)
```

功能：表示从末尾开始移动指定的长度。
