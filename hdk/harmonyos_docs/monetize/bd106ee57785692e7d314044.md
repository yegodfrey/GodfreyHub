# 鸿蒙应用

## 鸿蒙应用

鸿蒙应用流量变现服务，依托HarmonyOS NEXT系统让您无需集成SDK，轻松实现广告的接入。接入详情查看[《Ads Kit》](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ads-introduction)。

提示：接入开发时需注意申请OAID权限，调用getOAID接口需要申请ohos.permission.APP_TRACKING_CONSENT权限，并获取用户授权（默认开启权限），详情请查看[《Ads Kit广告标识服务》](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/oaid-service)。
