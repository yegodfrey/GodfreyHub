# 广告样式

为满足各类应用/快应用/快游戏不同场景下的内容体验需要，应用流量变现服务已提供原生、激励视频、横幅、插屏、开屏等广告样式，Android应用（APK）独有快速变现的极速开屏广告样式，鸿蒙应用独有视频贴片广告样式。快应用/快游戏流量变现服务已提供原生、激励视频、横幅、插屏四种样式。元服务流量变现已提供原生、激励视频、横幅、插屏、视频贴片五种样式。  

#### 1. 原生广告

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403091204.23482495589467956339403216560022:50001231000000:2800:581BDA4A79016D0B8651CCCEF5D2BE76B3AE514C7DDF947A868011712444C5D6.png "点击放大")

* 以"原生"的形式植入到应用本身的信息或服务内容中的广告，广告内容的植入和呈现不破坏页面本身的和谐，用户干扰度低，更愿意主动阅读。
* 适用场景：信息流场景或需自渲染广告的场景。
* 支持格式：信息流场景 - 大图文、三图文、小图文、视频。  

#### 2. 激励视频广告

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403091204.77098430550319074629242570892156:50001231000000:2800:C69BA004571EFE07CE8116479F70F89B3D91007DD696E1C28047965F039BF5CC.png "点击放大")

* 用户通过观看完整的视频广告，获得应用内相关的奖励。
* 适用场景：游戏/快游戏的通关、继续机会、道具获取、积分等场景中，阅读、影音等应用的权益体系也有相关使用。
* 支持格式：横版视频、竖版视频。  

#### 3. 横幅广告

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403091204.46159685339266717243840989252958:50001231000000:2800:184EAA388DF3DA1AE4CEF3A4142542FA111C44F9BABC1972D8EC741C5277265E.png "点击放大")

* 以通栏式或矩形式出现在应用页面顶部、中部或底部。
* 适用场景：适合于游戏页、阅读资讯页、工具功能页等用户停留较久或者访问频繁的页面。
* 支持格式：图文。  

#### 4. 插屏广告

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403091204.48495395994945876326536627240560:50001231000000:2800:4CE8E02D4F4E290A287F07A712E32556038A53FF86C5B3C7436C022B18B9ED94.png "点击放大")

* 在弹出窗口上展示广告，快速吸引用户注意力且不影响应用的正常体验。
* 适用场景：在应用开启、暂停或退出时弹出。
* 支持格式：横版插屏视频/图片、竖版插屏视频/图片。  

#### 5. 开屏广告

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403091204.56658408739959322663488747941941:50001231000000:2800:D76DC005C1FC29617AF0064FECA5F46475325265541E46988662E93528B0239B.png "点击放大")

* 应用启动加载时展现，全屏沉浸式广告，品牌曝光效果佳，点击率高，eCPM高。
* 适用场景：日活跃用户多、用户高频使用的应用。
* 支持格式：图文、视频。  

#### 6. 视频贴片广告

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403091204.50533139613508168728538543759497:50001231000000:2800:ECD40FB6AFD9CB650CD097CCD540738ACAC8D805E767D39977DB494C113C51E1.png "点击放大")

* 在应用内的视频播放前/播放中/播放结束后展示。
* 适用场景：应用内的视频播放场景。
* 支持格式：视频。  

#### 7.极速开屏广告

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250403091204.90084483841056009061490803063164:50001231000000:2800:AA083687C4EE31978113E74E6961DDE97B99BCDF12AE224126C4256B4B82A9EF.png "点击放大")

* 极速开屏广告是在应用启动时，由鲸鸿动能系统推送广告的开屏广告展示形式，无需媒体嵌入广告SDK就能快速实现广告变现。相比普通开屏，展示率更具优势，用户体验更佳。
* 适用场景：日活跃用户多、用户高频使用的应用。
* 支持格式：图文、视频。
