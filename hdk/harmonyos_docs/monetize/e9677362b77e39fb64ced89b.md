# 极速开屏

极速开屏是Android应用（APK）独有的广告样式，在应用启动时，由鲸鸿动能系统推送广告的开屏展示形式，无需媒体嵌入SDK就能快速实现广告变现。接入方式如下：

1. 【媒体管理】- 点击媒体名称打开展示位列表 -- 启用【极速开屏】。
2. 【媒体管理】- 设置媒体 -- 上传媒体默认Slogan（在无广告展示时或等待广告返回时默认展示此Slogan）。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250126143004.91830384542508250968985391065918:50001231000000:2800:908290D3658370702E4CA53B874028C37236DE3B35534E627A4367E4F01E3955.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 极速开屏接入[详见链接](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/publisher-service-exsplash-0000001051056577)
