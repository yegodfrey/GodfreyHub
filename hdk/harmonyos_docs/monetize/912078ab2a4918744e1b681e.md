# 展示位修改

1. 展示位允许媒体根据运营需求合理修改

* 【流量管理】-【展示位管理】，即可进入"展示位列表"进行修改。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250126143003.86897549687706613678528059748012:50001231000000:2800:02F6D535FE792E9A66B1D229E1CEEC1869A84C7C79B9D170CFFE5A329831A5A8.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 编辑展示位

* 支持展示位状态的变更，启用或停用。
* 支持展示位格式和尺寸增删，但至少需保留一种格式和尺寸。
* 如需删除展示位，请为展示位名称加上"-废弃"后停用，再删除。
