EventTrack 参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
event | O | String | 事件标识。 除播放完成事件，其余上报时需包含已播放时长的宏参数(PLAYEDDURATION)。 单位：秒
    * feed_play：视频手动播放第一帧时上报。
    * feed_auto_play：视频自动播放第一帧时上报。
    * feed_break：视频播放一帧后、停止视频播放、未完成视频播放。
    * feed_play_over：视频播放完成。  
trackUrl | O | String | 对应事件的跟踪地址。 格式如下：
    
    https://xxxxxx.xxxx.com/agd/mediareport?event=xxx&param=xxxxx&detailId=xxxxx&playedDuration=**_PLAYEDDURATION_**
