# 自测验收

在正式以SDK方式接入AGD Pro服务前，您需要对集成后业务进行自测，自测完成后再提交给华为验收。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250314174016.24908892426857910680011033853000:50001231000000:2800:33A900BFE83EF78F5653AB0A569B1B03A40D21DE6505A32EF09D4C2ACC9E0328.png)  
如果请求不到广告，不能以报错的形式显示给用户。

1. 请对照《[AGD PRO SDK验收规范(快应用)](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250314174016.89502084759051052514108911529270:50001231000000:2800:E475C6BAA72B31ECB51D98B4EB6B6053B6917B88C8291AA62F4351C676914EE0.xlsx)》交付件中的"应用转测自检项"页签核对检查。
2. 自测完成后，按《AGD PRO SDK验收规范》交付件要求填写check项要求的满足情况。
3. 按照如下邮件模板将填写好的《AGD PRO SDK验收规范》交付件发送邮件到developer@huawei.com邮箱申请开通上线。 邮件模板如下：

   邮件标题：APP名称-AGD Pro验收申请

   邮件内容：

   APP名称：\*\*\*\*\*\*\*

   APP ID：\*\*\*\*\*\*\*\*\*

申请验收：AGD Pro SDK
