# 运营规范

为了保护整个平台业务的合法、诚信、有序开展，我们会仔细监控和分析广告的点击和展示等数据，结合自动系统和人工审核手段，剔除数据中虚增广告客户费用或发布商收入的无效活动的数据，保证广告客户只为真实的消耗付费。同时我们会开展主动巡检，主动排查识别各类违规行为，保障广告生态公平可信、平台业务持续健康运转，维护广告主与媒体开发者等各方合法权益，营造良好的终端用户体验。

* 我们的自动系统，利用专业技术手段，根据储备的无效流量黑名单库，分析点击和展示数据，过滤掉大部分的无效点击和展示。
* 我们的人工审核团队，运用多种专业的工具和自身丰富的经验，随机抽检部分广告的点击和展示数据，分析具体情况，监测无效行为。
* 我们的巡检团队，在真实线上环境开展真机体验巡检，主动识别各类违规行为，落实违规处置。   

**一、违规行为定义**

开发者违规行为是指接入鲸鸿动能（以下简称"平台"）的应用/快应用/小游戏/元服务使用鲸鸿动能广告展示服务时违反法律法规规定、[应用审核](https://developer.huawei.com/consumer/cn/doc/distribution/app/50104)、[元服务审核](https://developer.huawei.com/consumer/cn/doc/app/50129-05)指南要求、鲸鸿动能流量变现等广告展示服务相关的协议、规定、规范性文件等的相关行为。

  

**二、违规处罚类型**

平台对开发者的广告展示违规行为有以下处罚措施，平台有权根据开发者违规行为的情节及后果，采取以下一项或多项措施。如平台已向开发者支付广告收益的，平台有权在开发者其他待结算广告收益中予以扣除，并保留追究相关法律责任的权利。

1. **警告：**平台向开发者发出警告通知，要求限时整改；若开发者未及时反馈和整改的，平台可采取冻结应用广告展示服务等进一步处罚。
2. **冻结广告展示服务：**暂时关闭开发者应用或账号的广告展示权限。冻结应用时，则该应用无法使用流量变现服务；冻结账号时，则账号下全部应用无法使用流量变现服务。
3. **终止广告展示服务：**永久关闭开发者账号的广告展示权限。终止后，开发者账号下全部应用无法使用流量变现服务。
4. **扣除广告展示收入：**冻结开发者变现收益结算并扣罚相关结算款项。为维护广告主权益，平台有权将扣除款项用于纠纷处置及损失赔偿，若款项不足以弥补损失，平台有权进一步向开发者追偿。
5. **主体累计违规升级处罚**：同一收款主体（同一自然人或同一公司主体）下的开发者应用违规累计达到一定数量的，平台有权视违规次数、情节与影响程度升级处罚。

  

**三、违规行为分类**

**1. 一级违规**

**1.1** **恶意作弊行为**

* 通过作弊或其他不正当手段，自行、委托或利用第三方、程序脚本、人工反复操作等方式，制造虚假或无效流量，伪造曝光、点击、下载、效果等数据的行为。

**1.2** **强制、恶意诱骗用户点击、浏览广告**

* 强制点击：以广告阻断用户正常使用服务，将观看、点击或播放广告作为用户继续使用服务或退出页面的前置条件。例如：所有运营内容只能通过观看激励视频广告解锁；用户必须点击广告后才能关闭弹窗、继续操作或返回等。
* 诱骗点击：通过误导、伪装、制造误触等手段，使用户在无预期下点击广告。包括但不限于：广告伪装为功能按钮、关闭按钮或内容入口；用户高频点击时突然弹出广告；通过移动类 Banner 广告诱导误触。
* 恶意篡改样式或隐藏广告：包括但不限于修改广告组件透明度、样式，或将广告隐藏、遮挡等行为，造成用户误点击广告。

**1.3** **恶意干扰与设备侵害**

* 自拉起：无用户主动点击操作，自动拉起并跳转至其他页面应用程序，劫持用户操作意图，违背用户预期，包含关闭界面后反复拉起、阻碍用户退出等劫持行为。
* 静默下载：未经用户明确授权及主动确认，自动发起应用安装包或外部文件下载，用户无感知，侵占用户设备资源。
* 阻止退出：通过技术手段拦截用户退出、关闭的操作，阻碍用户正常离开页面或应用。
* 劫持系统事件触发广告：劫持系统按键、监听应用前后台状态等系统级事件触发广告，包括但不限于触发返回/主屏键时唤起广告、应用处于后台仍触发广告等场景。
* 恶意高频连续弹窗：在用户单次交互操作流程内，无合理理由连续强制弹出广告，导致用户需反复关闭才能继续使用，严重阻断产品操作流程。
* 激励视频自动播放：在用户无主动点击或观看意愿的情况下，自动弹出并播放激励视频广告。

**1.4 非正常手段拉取广告导致误点**

* 包含但不限于通过技术手段在无用户预期的情况下拉取广告，导致用户误点广告的行为。

**一级违规处罚说明**

开发者出现上述一级违规行为，平台将结合本次违规情形、历史违规记录与影响程度采取扣除广告展示收入、冻结或终止账号广告展示服务等处罚手段；多次违规，平台将升级处罚。

  

**2. 二级违规**

**2.1 滥用广告组件**

* 激励视频广告交互异常：激励视频广告入口未明确说明广告播放等交互；未完整播放（提前关闭）仍发放奖励；完整播放后未发放奖励；点击激励入口交互异常或延后视频拉起播放时机等。
* 自定义广告关闭逻辑：包括但不限于自定义广告关闭按钮、增加关闭拦截操作，抬高用户关闭广告的操作门槛。
* 广告触发时机干扰：在用户有明确操作目的的关键交互节点、非自然停顿时机弹出弹窗广告，或广告触发节点配置过于密集、弹窗频发，违背用户意图，打断操作流程或骚扰用户。
* 广告布局密集：单屏内容里密集堆叠多个广告，过度侵占页面内容区域。
* 在桌面小组件场景植入广告。

**2.2 诱导、误导用户点击、浏览广告**

* 使用按钮、图片、文字等页面元素遮挡广告位，易造成用户误点击。
* 广告区域与页面原生可点击内容紧贴无间距，缺少清晰视觉边界，易造成用户误点击。
* 模仿系统通知、官方界面、功能弹窗等样式展示广告，给用户造成误解或误导性的点击。
* 在用户习惯点击的功能区域突然弹出广告，导致误点击。
* 刻意调低交互动作阈值，设置过高触发灵敏度，造成用户误触发广告跳转。
* 在应用可控页面位置，以明示或暗示的方式诱导用户反复访问、点击广告。
* 使用整屏图片、视频作为跳转链接，诱导点击跳转。

**2.3 强制式激励广告设计**

* 激励视频广告仅限用于合理的用户可自主选择的增值场景，不得作为完成关键操作或继续使用功能的必要条件，包括但不限于：对局结算弹窗全部按钮均绑定激励视频、通关后解锁下一关须观看广告等情形。

**二级违规处罚说明**

开发者出现上述二级违规行为，平台将结合本次违规情形、历史违规记录与影响程度采取冻结违规应用广告展示服务等处罚手段；多次违规，平台将升级处罚。

  

**3. 三级违规**

**3.1 广告展示问题**

* 广告位悬浮展示无序，与页面整体布局不匹配，造成页面展示效果异常，影响用户浏览体验。
* 广告位渲染错位、偏移，与页面内容重叠遮挡，影响广告正常展示与内容浏览体验。
* 广告功能适配异常，包括但不限于空白广告页、负反馈未适配、关闭广告造成应用退出、激励广告入口点击无响应。
* 广告标识展示异常，包括但不限于广告标识缺失、深浅模式适配异常导致标识无法正常展示等情形。

**3.2 广告展示时机/时序问题**

* 广告展示时机或顺序不符合常规业务逻辑，包括但不限于先加载页面内容后再弹出开屏广告等情形。

**三级违规处罚说明**

开发者出现上述三级违规行为，平台将结合本次违规情形、历史违规记录与影响程度采取冻结违规应用广告展示服务等处罚手段；多次违规，平台将升级处罚。
