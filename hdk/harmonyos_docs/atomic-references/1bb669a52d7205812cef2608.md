# 元服务API说明

#### 什么是元服务API集

从HarmonyOS NEXT Developer Preview1（API 11）版本开始，元服务只能采用"元服务API集"进行开发。

"元服务API集"是[HarmonyOS SDK API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/development-intro-api)的子集，API能力来自各Kit，用于支撑元服务高效开发。

本文档将说明如何使用"元服务API集"进行开发。在开发前，需要了解其特征：

1. 只支持Stage模型。
2. 只支持ArkTS接口。
3. 与应用相同，元服务也支持两种API模块导入方式，开发者可自行选择：
   * 按Kit导入，例如：

     ```
     import { authentication } from '@kit.AccountKit';
     ```

   * 按模块导入，例如：

     ```
     import authentication from '@hms.core.authentication';
     ```

4. 不支持使用so库。
5. 仅支持使用元服务API集开发的三方库，否则将导致上架审核不通过。

从HarmonyOS NEXT Developer Preview1（对应API 11）版本开始，使用配套的HarmonyOS SDK开发的元服务，只能运行在系统软件版本为HarmonyOS NEXT Developer Preview1及以上版本的设备上。  

#### 如何查看支持元服务的API

"元服务API集"是HarmonyOS SDK API的子集。开发者在DevEco Studio中选择开发元服务时，工具将自动筛选出"元服务API集"。

开发者可根据需要在HarmonyOS SDK的API文档中，查看"元服务API集"的文档。

1. 点击[API参考](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/development-intro-api)，跳转到HarmonyOS SDK的API文档。
2. 在页面左侧的目录上，找到"高级筛选 \> 元服务API集"，在下拉框中点击选择"筛选"，查看支持元服务的API。 如下图所示，支持元服务的API的节点正常显示，不支持元服务的API节点将被置灰。

   建议开发者同步勾选"只看筛选内容"，查阅元服务API集。
