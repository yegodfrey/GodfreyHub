#### qg.createUDPSocket(Object object)（1117+）

* 描述 创建一个UDP Socket实例。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-----|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |object|Object/string|O|当不传入参数时，默认创建udp4类型的对象，使用IPv4协议，并且不进行地址重用。 当传入参数为string类型时，根据参数创建指定的UDPSocket类型，可用类型为udp4或者udp6。 当传入参数为object类型时，根据参数创建指定的UDPSocket类型和是否允许进行地址重用，详情请参见[object参数](#ZH-CN_TOPIC_0000002109267164__li096418515912)。|

  * object参数  

    |参数|类型|必填(M)/选填(O)|说明|
    |:--------|:------|:----------|:------------------------------|
    |type|string|M|创建的UDPSocket类型，可用类型为udp4或者udp6。|
    |reuseAddr|boolean|M|是否允许在bind时重用端口。|

* 返回值 一个UDP Socket实例。

* 示例代码

  ```
  const udp4 = qg.createUDPSocket('udp4');
  const udp6 = qg.createUDPSocket({
    type: "udp6",
    reuseAddr: true
  });
  ```

#### UDPSocket.bind(number port)（1117+）

* 描述 绑定一个系统随机分配的可用端口，或绑定一个指定的端口号。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:---|:-----|:----------|:--------------------------|
  |port|number|O|指定要绑定的端口号，不传则返回系统随机分配的可用端口。|

* 返回值 绑定成功的端口号。

* 示例代码

  ```
  const udp = qg.createUDPSocket();
  const port = udp.bind()
  ```

#### UDPSocket.setTTL(number ttl)（1117+）

* 描述 设置 IP_TTL 套接字选项，用于设置一个IP数据包传输时允许的最大跳步数。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:--|:-----|:----------|:---------------|
  |ttl|number|M|ttl参数可以是0到255之间。|

* 示例代码

  ```
  const udp = qg.createUDPSocket();
  udp.onListening(function () {
    udp.setTTL(64);
  )}
  udp.bind();
  ```

#### UDPSocket.send(Object object)（1117+）

* 描述 向指定的IP和port发送消息。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:------|:-----------------|:----------|:---------------------------------------------------------|
  |address|string|M|要发消息的地址。|
  |port|number|M|要发送消息的端口号。|
  |message|string/ArrayBuffer|M|要发送的数据。|
  |offset|number|O|发送数据的偏移量，仅当message为ArrayBuffer类型时有效。默认值为0。|
  |length|number|O|发送数据的长度，仅当message为ArrayBuffer类型时有效。默认值为message.byteLength。|

* 示例代码

  ```
  const udp = qg.createUDPSocket();
  udp.bind();
  udp.send({
    address: '192.168.193.2',
    port: 8848,
    message: 'hello, how are you'
  })
  ```

#### UDPSocket.connect(Object object)（1117+）

* 描述 预先连接到指定的 IP 和 port，需要配合[UDPSocket.write(Object object)](#section1532724713247)方法一起使用。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:------|:-----|:----------|:---------|
  |address|string|M|要发消息的地址。|
  |port|number|M|要发送消息的端口号。|

* 示例代码

  ```
  const udp = qg.createUDPSocket();
  udp.bind();
  udp.connect({
    address: '192.168.193.2',
    port: 8848,
  })
  udp.write({
    address: '192.168.193.2',
    port: 8848,
    message: 'hello, how are you;
  })
  ```

#### UDPSocket.close()（1117+）

* 描述 关闭UDP Socket实例，相当于销毁。 在关闭之后，UDP Socket实例不能再发送消息，每次调用[UDPSocket.send(Object object)](#section7820144313246)将会触发错误事件，并且message事件回调函数也不会再执行。在UDPSocket实例被创建后将被Native强引用，保证其不被GC。在[UDPSocket.close()](#section1612544802417)后将解除对其的强引用，让UDPSocket实例遵从GC。

#### UDPSocket.offClose(function listener)（1117+）

* 描述 移除关闭事件的回调函数。

<!-- -->

  |:-------|:-------|:----------|:---------------------------------------------------------------------|


  * 错误码说明  

    |错误码|说明|
    |:--|:-----------|
    |1|绑定错误。|
    |2|监听数据包消息错误。|
    |3|connect调用错误。|
    |4|发送数据错误。|
    |5|接收数据错误。|
    |6|设置TTL错误。|
    |7|解析域名失败。|

#### UDPSocket.onMessage(function listener)（1117+）

* 描述 监听收到消息的事件。

  * 参数  

    |参数|类型|必填(M)/选填(O)|说明|
    |:-------|:-------|:----------|:------------|
    |listener|function|M|收到消息的事件的回调函数。|

<!-- -->

* 返回值 收到的消息的信息组成的对象。

  |参数|类型|说明|
  |:---------|:----------|:--------------------------------------------------------------------------|
  |message|ArrayBuffer|收到的消息。消息长度需要小于4096。|
  |remoteInfo|Object|发送端地址信息。详情请参见[remoteInfo参数](#ZH-CN_TOPIC_0000002109267164__li454310281390)。|
  |localInfo|Object|接受端地址信息。详情请参见[localInfo参数](#ZH-CN_TOPIC_0000002109267164__li4431342153916)。|

  * remoteInfo参数  

    |参数|类型|说明|
    |:------|:-----|:------------------|
    |address|string|发送消息的socket的地址。|
    |family|string|使用的协议族，为IPv4或者IPv6。|
    |port|number|端口号。|
    |size|number|message的大小，单位为字节。|

  * localInfo参数  

    |参数|类型|说明|
    |:------|:-----|:------------------|
    |address|string|接收消息的socket的地址。|
    |family|string|使用的协议族，为IPv4或者IPv6。|
    |port|number|端口号。|
