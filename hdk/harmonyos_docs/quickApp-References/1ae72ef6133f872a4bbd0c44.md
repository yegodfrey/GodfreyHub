# 通知消息

> 说明
>
> 为了规范通知栏消息，提升用户体验，2023年5月19日起，快应用通知服务将全面升级。
>
> 服务升级期间，快应用推送能力整体下线，即快应用的推送/通知（即通知栏消息）均无法触达用户，请您暂停使用，给您造成的不便敬请谅解。
>
> 本次服务升级预计于2023年四季度完成，完成后我们将会邮件通知您。如您遇到任何问题，请发邮件至developer@huawei.com与我们联系，感谢您的支持。

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.notification"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import notification from '@system.notification'
```

或

```screen
var notification = require("@system.notification")
```

## 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|中国大陆|

## 接口定义

|接口|描述|
|:------------------------------------------------------------|:-------------|
|[notification.show(OBJECT)](#section9697191614172)|显示通知。|
|[notification.postDelayedShow(OBJECT)](#section132959417216)|设置延时显示通知。|
|[notification.cancelDelayedShow(OBJECT)](#section98067454331)|取消处在延时状态的通知消息。|

### notification.show(OBJECT)

**描述**

显示通知。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------------|:-------|:---|:---------------------------------------------|
|contentTitle|string|否|标题。如果未开启通知权限，则不显示通知消息；开启通知权限，此参数不能为空，否则无法显示通知。|
|contentText|string|否|内容。如果未开启通知权限，则不显示通知消息；开启通知权限，此参数不能为空，否则无法显示通知。|
|clickAction|object|否|通知点击后触发动作的信息|
|success(1107+)|function|否|成功回调。|
|fail(1107+)|function|否|失败回调。|

**success返回值**

|参数|类型|说明|
|:---|:-----|:------|
|data|string|返回成功信息。|

**fail返回值**

|参数|类型|说明|
|:---|:-----|:------|
|data|string|返回错误信息。|
|code|int|返回的错误码。|

**clickAction说明：**

|参数|类型|是否必填|说明|
|:--|:-----|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uri|string|是|点击通知后跳转的页面地址。支持的格式包括： 1. 以"/"开头的应用内页面的路径；例：/about 2. 以非"/"开头的应用内页面的名称；例：About 3. 特殊的，如果uri的值是"/"，则跳转到path为"/"的页，没有则跳转到首页 可以通过"?param1=value1"的方式添加参数，参数可以在页面中通过this.param1的方式使用|

**示例代码**

```screen
notification.show({
	contentTitle:'title',
	clickAction: {
	uri:'/index.html?index=1'
	},
	success: function(data) {
		console.log("notification.show succeeded, result data=" + JSON.stringify(data));
	
	},
	fail: function(data, code) {
		console.log(" notification.show failed, result data=" + JSON.stringify(data) + ", code=" + code);
	}
})
```

### notification.postDelayedShow(OBJECT) （1070+，华为扩展接口，非厂商联盟规范）

**描述**

设置延时显示通知。
> 说明
>
> 发送通知消息的快应用进程存在，才会显示通知消息。如果快应用的进程停止，则不会显示通知。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:--------|:-------|:---|:--------|
|message|object|是|具体消息信息。|
|buildInfo|object|是|延迟参数。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**message参数说明**

|参数|类型|是否必填|说明|
|:-----------|:-----|:---|:---------------------------------------------|
|contentTitle|string|否|标题。如果未开启通知权限，则不显示通知消息；开启通知权限，此参数不能为空，否则无法显示通知。|
|contentText|string|否|内容。如果未开启通知权限，则不显示通知消息；开启通知权限，此参数不能为空，否则无法显示通知。|
|clickAction|object|否|通知点击后触发动作的消息。|

**buildInfo参数说明**

|参数|类型|是否必填|说明|
|:----------|:------|:---|:------------------------------------|
|latencyTime|long|是|延迟时间（单位：秒）。|
|isPersisted|boolean|是|重启手机是否保留通知消息。必须手动为快应用中心开启开机自启动权限才能生效。|

**success返回值**

|参数|类型|说明|
|:----|:--|:------------------------|
|jobId|int|延时消息的id。 通过此ID可以取消延时消息任务。|

**示例代码**

```screen
notification.postDelayedShow({
    message:{
           contentTitle: 'title',
           clickAction: {
            uri: '/index.html?index=1'
           }
    },
    buildInfo:{
           latencyTime: 1*60,  //1分钟
           isPersisted:false
    },
    success:function(params){
          console.info("success, id is "+ params.jobId)
    }
})
```

### notification.cancelDelayedShow(OBJECT)（1070+，华为扩展接口，非厂商联盟规范）

**描述**

取消处在延时状态的通知消息。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:---------|
|jobId|int|是|延时消息的任务ID。|
|success|function|否|成功的回调。|
|fail|function|否|失败的回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
notification.cancelDelayedShow({
    jobId:12,
    success:function(params){
          console.info("success")
    }
})
```
