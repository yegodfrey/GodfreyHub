# 多媒体

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.media"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import media from '@system.media'
```

或

```screen
var media = require("@system.media")
```

## 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

## 接口定义

|接口|描述|
|:-----------------------------------------------------|:-----------------------------------------------------------------|

|[media.pickFiles(OBJECT)](#section1356153092317)|选择多个文件。|

### media.takePhoto(OBJECT)

**描述**

拍摄照片。

智慧屏不支持。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|cancel|function|否|取消回调。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:----------|:-----|:-----------|
|uri|string|照片文件路径。|
|name(1060+)|string|照片文件名称。|
|size(1060+)|string|照片文件的大小，单位B。|

**fail返回错误码：**

|错误码|说明|
|:--|:-------------|
|201|用户拒绝，获取相机权限失败。|

**示例代码**

```screen
media.takePhoto({  
  success: function(data) {
    console.log("handling success: " + data.uri);
  },
  fail: function(data, code) {
    console.log("handling fail, code=" + code);
  }
});
```

### media.saveToPhotosAlbum(OBJECT) (1010+)

**描述**

将图片/视频文件保存到相册中。需要用户授权。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:----------------|:-------|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uri|string|是|源文件的uri。文件的扩展名必须是图片或视频的扩展名。 > 说明 > 仅支持本地路径。如需保存网络图片或者视频，请先调用文件下载接口把图片或者视频下载到本地，再保存到相册。|
|folderName(1080+)|string|否|图片/视频保存在相册中的文件夹名，最大长度为 50 个字符。最多支持 10 级目录，每级目录名不超过 10 个字符。不能包含下列任何英文字符之一：\:*?"<> | 。 > 说明 > * 如果没有设置 folderName，图片保存地址格式为：sdcard/Pictures/"快应用包名"/"快应用的应用名"/xxx.jpg > * 如果手动设置了 folderName，图片保存地址格式为：sdcard/Pictures/"快应用包名"/"folderName"/yyy.jpg|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**fail返回错误码：**

|错误码|说明|
|:--|:-----|
|201|用户拒绝。|
|202|参数错误。|
|300|I/O错误。|

**示例代码**

```screen
media.saveToPhotosAlbum({
    uri: 'internal://cache/123.png',
    folderName: 'custom-folder',
    success:function(data){console.log("save success: ");},
    fail: function(data, code) {
        console.log("handling fail, code=" + code);
    }
})
```

### media.setRingtone(OBJECT)（1035+）

**描述**

设置铃声。

调用此接口时，每次都会弹授权框，需获得用户同意后才可进行设置。

智慧屏不支持。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------------------------------------------------------|
|title|string|否|铃声名称，没有设置的话默认取铃声文件名。 > 说明 > 仅支持中文、字母、数字和下划线，长度不能超过85字节。|
|uri|string|是|铃声文件路径，只支持本地路径。 > 注意 > 本地路径为项目工程的路径和internal路径（不包含tmp类型）。|
|type|string|是|铃声类型 * ringtone：来电 * notification：通知 * alarm：闹钟|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**fail返回错误码：**

|错误码|说明|
|:---|:-----|
|202|参数非法。|
|1001|文件不存在。|

**示例代码**

```screen
media.setRingtone({
    uri:"/Common/test.mp3",
    type:"ringtone",
    success: function () {
        console.log('media.setRingtone----------success')
    },
    fail: function (erromsg, errocode) {
        console.log('media.setRingtone----------' + errocode + ': ' + erromsg)
    },
    complete: function () {
        console.log('media.setRingtone----------complete')
    }
})
```

### media.getRingtone(OBJECT)（1035+）

**描述**

获取系统铃声。

智慧屏不支持。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------------------------------------------|
|type|string|是|铃声类型。 * ringtone：来电 * notification：通知 * alarm：闹钟|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:----|:-----|:------------------------------------|
|title|string|铃声名称，若铃声被删除，返回空字符串。静音的情况，返回'none'字符串。|

**fail返回错误码：**

|错误码|说明|
|:--|:----|
|202|参数非法。|

> 说明
>
> 若用户参数设置错误如铃声类型单词拼写错误，返回参数非法错误码。
>
> 双卡情况，如果卡1卡2都设置铃声，获取铃声时，返回卡1的。

**示例代码**

```screen
media.getRingtone({
    type:"alarm",
    success: function (ret) {
        console.log('media.getRingtone----------success'+ret.title)
    },
    fail: function (erromsg, errocode) {
        console.log('media.getRingtone----------' + errocode + ': ' + erromsg)
    },
    complete: function () {
        console.log('media.getRingtone----------complete')
    }
});
```

### media.previewImage(OBJECT)（1035+）

**描述**

预览图片，调用之后会在新打开的页面中全屏预览传入的图片，预览的过程中用户可以左右滑动浏览，可以通过双指缩放图片，可以保存图片到相册。智慧屏不支持。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------------------|
|current|string|否|当前展示的图片路径。|
|uris|array|是|需要预览的图片链接列表，同时支持网络和本地地址。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
media.previewImage({
    current: "https://static.wgpet.com/editor/attached/image/20141124/20141124225933_71813.jpg",
    uris: ["https://img3.imgtn.bdimg.com/it/u=3993672553,267575750&fm=21&gp=0.jpg",
        "https://img5.imgtn.bdimg.com/it/u=2652905594,2769975769&fm=21&gp=0.jpg",
        "/common/logo.png",
            "https://imgsrc.baidu.com/forum/w%3D580/sign=fe8a7e7f78ec54e741ec1a1689399bfd/4b3f9682d158ccbfb334467b1ad8bc3eb33541cd.jpg",
        "https://static.wgpet.com/editor/attached/image/20141124/20141124225933_71813.jpg",
        "https://zyline-photo.qiniudn.com/1392705051156.jpg",
        "https://v1.qzone.cc/pic/201405/25/13/57/5381864e3b8af886.jpg%21600x600.jpg",
        "https://wanzao2.b0.upaiyun.com/system/pictures/23660313/original/8d4f08e50be02ae3.png"],
    success: function () {
        console.log('previewImage success');
    },
    fail: function (erromsg, errocode) {
        console.log('previewImage errocode:' + errocode);
    },
    complete: function () {
        console.log('previewImage complete');
    }
});
```
