# 通用样式

|名称|类型|默认值|描述|
|:--------------------------------------------|:------------------------------------------------------------------------------------------------------------------|:----------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|width|length \| percentage|-|未设置时使用组件自身内容需要的宽度。 说明： flex的元素实际展示宽度会受到父容器的影响。|
|height|length \| percentage|-|未设置时使用组件自身内容需要的高度。 说明： flex的元素实际展示高度会受到父容器的影响。|
|padding|length|0|简写属性，在一个声明中设置所有的内边距属性，该属性可以有1到4个值，4个值分别对应上、右、下、左。|
|padding-\[top\|right\|bottom\|left\]|length|0|设置一个元素的某个方向的内边距，padding 区域指一个元素的内容和其边界之间的空间，该属性不能为负值。|
|margin|length \| auto(1073+)|0|简写属性，在一个声明中设置所有的外边距属性，该属性可以有1到4个值，4个值分别对应上、右、下、左。|
|margin-\[top\|right\|bottom\|left\]|length \| auto(1073+)|0|设置一个元素的某个方向的外边距，该属性不能为负值。|
|border|-|0|简写属性，在一个声明中设置所有的边框属性，可以按顺序设置属性width style color，不设置的值为默认值。|
|border-\[left\|top\|right\|bottom\](1050+)|-|0|简写属性，在一个声明中设置对应位置的边框属性，可以按顺序设置属性 width style color，不设置的值为默认值。|
|border-style|dotted \| dashed \| solid|solid|暂时仅支持1个值，为元素的所有边框设置样式。|
|border-width|length|0|简写属性，在一个声明中设置元素的所有边框宽度，或者单独为各边边框设置宽度。|
|border-\[left\|top\|right\|bottom\]-width|length|0|为元素的某个方向的边框设置边框宽度。|
|border-color|color|black|简写属性，在一个声明中设置元素的所有边框颜色，或者单独为各边边框设置颜色。|
|border-\[left\|top\|right\|bottom\]-color|color|black|为元素的某个方向的边框设置边框颜色。|
|border-radius|length \| percentage(1072+)|0|* 圆角时只使用border-width，border-\[left\|top\|right\|bottom\]-width * 无效圆角时只使用border-color，border-\[left\|top\|right\|bottom\]-color无效|
|border-\[top\|bottom\]-\[left\|right\]-radius|length \| percentage(1073+)|0|设置四个角的圆角弧度。|
|background|linear-gradient|-|支持[渐变样式](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-gradient-styles-0000001123690170)，暂时不能与background-color、background-image同时使用。|
|background-color|color|-|背景颜色。|
|background-image|uri|-|暂时不支持与background-color，border-color同时使用。同时支持网络图片资源和本地图片资源。支持.9.png图片（网络的.9.png图片需要预先 进行aapt的编译）。|
|background-size|contain\|cover\|auto\|length\|percentage|* 100%(\<1080) * auto (1080+)|设置背景图片大小。 * 小于1080版本时，backgroud-size默认值为100%。 * 1080及以上版本时，backgroud-size默认值为auto。|
|background-repeat|repeat\|repeat-x\|repeat-y\|no-repeat|repeat|设置是否及如何重复背景图像，背景图像默认在水平和垂直方向上重复。|
|background-position(1010+)|left top\|center top\|right top\|left center\|center center\|right center\|left bottom\|center bottom\|right bottom|0px 0px|第一个值是水平位置，第二个值是垂直位置。 如果仅规定了一个值，那么另一个值为center，即50%。 * x% y%格式：左上角是 0% 0% ，右下角是 100% 100% 。 * xpx ypx格式：左上角是 0px 0px 。 说明： % 和 px 可以混合使用 。|
|opacity|number|1|指定元素的透明度。可设置为0\~1的小数。|
|display|flex \| none|flex|快应用只支持 flex 布局。将当前元素的 display 设置为 none 快应用页面将不渲染此元素。|
|visibility|visible \| hidden|visible|控制显示或隐藏元素。|
|flex|number|-|父容器为\<div\>、\<list-item\>、\<tabs\>时生效。|
|flex-grow|number|0|父容器为\<div\>、\<list-item\>时生效。|
|flex-shrink|number|1|父容器为\<div\>、\<list-item\>时生效。|
|flex-basis|length|-1|父容器为\<div\>、\<list-item\>时生效。|
|position|relative(1060+) \| absolute(1060+) \| fixed|relative|* 当父组件为\<list\>、\<swiper\>时，position设置不生效。 * 在智慧屏上，position不支持设置为fixed。 * 如果需要设置position为fixed时的布局与快应用联盟保持一致，请把minPlatformVersion设置为1078及以上版本。|
|\[left\|top\|right\|bottom\]|number|-|一般配合fixed或absolute(1060+)布局使用。|
|min-width(1080+)|length \| percentage|0|指定元素的最小宽度。|
|max-width(1080+)|length \| percentage \| none|none|指定元素的最大宽度。|
|min-height(1080+)|length \| percentage|0|指定元素的最小高度。|
|max-height(1080+)|length \| percentage \| none|none|指定元素的最大高度。|
