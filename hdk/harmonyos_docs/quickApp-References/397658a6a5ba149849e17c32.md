# 文件存储

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507152446.97419607309927663580836887164118:50001231000000:2800:6CBB1524B5F2B7FF6028E4ACDBFB313520E8E475C8ED7E462F848F2FD7BAA706.png)  
此接口处理的数据在PC终端使用时，可能会被其它应用读取，所以建议请勿使用此接口存储敏感数据。  

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{"name": "system.file"}
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import file from '@system.file'
```

或

```
var file = require("@system.file")
```

#### 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

#### file.move(OBJECT)

描述

将源文件移动到指定位置。

OBJECT参数  

|属性名|类型|是否必填|说明|
|:-------|:-------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|srcUri|string|是|源文件的uri，不可以是应用资源路径和tmp类型的uri。 uri描述请参见"[文件组织 \> URI](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-filestructure-0000001074564510#section8808123141011)"。|
|dstUri|string|是|目标文件的uri，不可以是应用资源路径和tmp类型的uri。 uri描述请参见"[文件组织 \> URI](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-filestructure-0000001074564510#section8808123141011)"。|
|success|function|否|成功回调，返回目标文件的uri。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

fail返回错误码：  

|错误码|说明|
|:--|:-----|
|202|参数错误。|
|300|I/O错误。|

示例代码

```
file.move({
  srcUri: "internal://cache/path/to/file",
  dstUri: "internal://files/path/to/file",
  success: function(uri) {
    console.log("move success: " + uri);
  },
  fail: function(data, code) {
    console.log("handling fail, code=" + code);
  }
})
```

#### file.list(OBJECT)

描述

获取指定目录下的文件列表。

OBJECT参数  

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uri|string|是|目录的uri。 uri描述请参见"[文件组织 \> URI](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-filestructure-0000001074564510#section8808123141011)"。 说明： * 不可以是tmp类型的uri。 * uri为应用内资源路径时，可以是绝对路径，也可以是相对路径。|
|success|function|否|成功回调，返回{fileList:\[{uri:'file1',lastModifiedTime:1234456, length:123456} ...\]} 返回值说明请参见"success返回值"，返回值中每个文件元信息请参见"文件元信息说明"。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

success返回值：  

|参数名|类型|说明|
|:-------|:----|:------------------------------------------------------------------|
|fileList|array|文件列表，每个文件的格式为{uri:'file1',lastModifiedTime:1234456, length:123456}。|

文件元信息说明：  

|参数名|类型|说明|
|:---------------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uri|string|文件的uri，该uri可以被其他组件或Feature访问。 uri描述请参见"[文件组织 \> URI](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-filestructure-0000001074564510#section8808123141011)"。|
|length|number|文件大小，单位B。|
|lastModifiedTime|number|文件保存时的时间戳，从 1970/01/01 00:00:00 GMT 到当前时间的毫秒数。|

fail返回错误码：  

|错误码|说明|
|:--|:-----|
|202|参数错误。|
|300|I/O错误。|

示例代码

```
file.list({
  uri: "internal://files/movies/"
  success: function(data) {
    console.log(data.fileList)
  },
  fail: function(data, code) {
    console.log("handling fail, code=" + code);
  }
})
```

#### file.copyFileToPublicDir(OBJECT)（1078+）

描述

复制文件到系统公共目录。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507152446.20163164174268624285034748583150:50001231000000:2800:54D07EACB40FC90D7A231F8A46FEE4337B72A0D203EA6C7897F1B905B0567AF2.png)  
需要获得用户的存储权限授权。

参数  

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|srcPath|string|是|源文件路径，只可以是本地文件。|
|destPath|string|是|目标文件路径，只支持external://DIRECTORY_TYPE/xxx\[optional\]/yyy.\[extensionName\] 格式，例如"external://DIRECTORY_DOCUMENTS/test/test.pdf"。 其中DIRECTORY_TYPE只支持如下类型： * DIRECTORY_MUSIC * DIRECTORY_PICTURES * DIRECTORY_MOVIES * DIRECTORY_DCIM * DIRECTORY_DOCUMENTS <br /> HarmonyOS 2.0及以上或Android 10.0及以上版本需正确配置文件类型，否则会存储异常。HarmonyOS 2.0及以上或Android 10.0及以上版本各目录类型下存储文件类型支持情况如下： * DIRECTORY_MUSIC只支持音频类型文件 * DIRECTORY_PICTURES只支持图片 * DIRECTORY_MOVIES只支持视频 * DIRECTORY_DCIM只支持图片|
|success|Function|否|接口调用成功的回调函数。|
|fail|Function|否|接口调用失败的回调函数。|
|complete|Function|否|接口调用结束的回调函数（调用成功、失败都会执行）。|

fail返回错误码  

|错误码|说明|
|:--|:--------|
|200|通用错误。|
|202|参数错误。|
|300|IO异常。|
|302|文件已存在。|
|303|文件后缀名不存在。|
|304|文件路径不合法。|

示例代码

```
file.copyFileToPublicDir({
    srcPath: '/Common/test.mp3',
    destPath: 'external://DIRECTORY_DOCUMENTS/test.mp3',
    success: function (ret) {
      console.log("copy success: " + ret);
    },
    fail: function (data, code) {          
      console.log("handling fail, code=" + code)       
    }
})
```

<script>
  import file from '@system.file'
  import fetch from '@system.fetch'

  export default {
    data: {
      componentName: 'file',
      fileDownloadData: '',
      fileMoveData: '',
      fileMoveToFolderData: '',
      fileCopyData: '',
      fileGetListData: '',
      fileGetData: '',
      fileDeleteData: '',
      fileWriteData: '',
      fileReadData: '',
      writeBufferData: '',
      readBufferData: '',
      fileAccessData: '',
      makeDir: '',
      deletDir: '',
      textContent:'',
      result:''
    },
    onInit: function () {
      this.$page.setTitleBar({ text: 'file' })
    },
    downloadFile: function () {
      var that = this
      fetch.fetch({
        url: 'https://developer.huawei.com/dev_index/img/logo_ch.png',
        success: function (ret) {
          that.fileDownloadData = ret.data
          console.log("wlj"+ret.data);
          that.fileDeleteData = that.fileDownloadData
          console.log('file_download_data--------' + JSON.stringify(ret))
        }
      })
    },
    moveFile: function () {
      var that = this
      var dstUri = 'internal://files/testfile/file.png'
      file.move({
        srcUri: this.fileDownloadData,
        dstUri: dstUri,
        success: function (ret) {
          that.fileMoveData = dstUri
          that.fileDownloadData = dstUri
          that.fileDeleteData = that.fileDownloadData
          console.log('file_save--------success ' + JSON.stringify(ret))
        },
        fail: function (errmsg, errcode) {
          that.fileMoveData = errcode + '---' + errmsg
          console.log('file_save--------fail ' + errcode + ': ' + errmsg)
        }
      })
    },
    moveFileToFolder: function () {
      var that = this
      var dstUri = 'internal://files/testfile/'
      file.move({
        srcUri: this.fileDownloadData,
        dstUri: dstUri,
        success: function (ret) {
          that.fileMoveToFolderData = ret
          that.fileDownloadData = ret
          that.fileDeleteData = ret
          console.log('file_save--------success ' + JSON.stringify(ret))
        },
        fail: function (errmsg, errcode) {
          that.fileMoveToFolderData = errcode + '---' + errmsg
          console.log('file_save--------fail ' + errcode + ': ' + errmsg)
        }
      })
    },
    copyFile: function () {
      var that = this
      var dstUri = 'internal://files/testfile/filecopy.png'
      file.copy({
        srcUri: that.fileDownloadData,
        dstUri: dstUri,
        success: function (ret) {
          that.fileCopyData = ret
          console.log('file_list_data-------- success ' + JSON.stringify(ret))
        },
        fail: function (errmsg, errcode) {
          that.fileCopyData = errcode + '---' + errmsg
          console.log('file_list_data--------complete ' + errcode + ': ' + errmsg)
        }
      })
    },
    getFileList: function () {
      var that = this
      file.list({
        uri: 'internal://files/testfile',
        success: function (ret) {
          that.fileGetListData = JSON.stringify(ret)
          console.log('file_get_data---------success ' + JSON.stringify(ret))
        },
        fail: function (errmsg, errcode) {
          that.fileGetListData = errcode + '---' + errmsg
          console.log('file_get_data---------fail ' + errcode + ': ' + errmsg)
        }
      })
    },
    getFile: function () {
      var that = this
      file.get({
        uri: 'internal://files/testfile',
        recursive: true,
        success: function (ret) {
          that.fileGetData = JSON.stringify(ret)
          console.log('file_get_data---------success ' + JSON.stringify(ret))
        },
        fail: function (errmsg, errcode) {
          that.fileGetData = errcode + '---' + errmsg
          console.log('file_get_data---------fail ' + errcode + ': ' + errmsg)
        }
      })
    },

          console.log('file_remove_data---------fail ' + errcode + ': ' + errmsg)

        }

    readFile: function () {
      var that = this
      file.readText({
        uri: 'internal://cache/test/test.txt',
        encoding: 'UTF-8',
        success: function (data) {
          console.log(`success data.text = ${data.text}`)
          that.fileReadData = data.text
        },
        fail: function (errmsg, errcode) {
          console.log('failed ' + errmsg + ' errcode = ' + errcode)
          that.fileReadData = 'Failed'
        }
      })
