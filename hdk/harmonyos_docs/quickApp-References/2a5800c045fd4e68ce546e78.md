# 车辆驾驶安全限制

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.uxrestrictions"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import restrictions from '@system.uxrestrictions'
```

或

```screen
const restrictions = require("@system.uxrestrictions")
```

## 使用限制

|限制条件|说明|
|:---|:---|
|适用终端|车机|
|适用区域|中国大陆|

## 接口定义

|接口|描述|
|:-----------------------------------------------------------------------------|:------------------------------------|
|[restrictions.getUxRestrictions(OBJECT)](#section6531125915813)|查询获取当前车辆UX限制项限制结果。|
|[restrictions.registerUxRestrictionsListener(OBJECT)](#section024602514411)|注册UX限制监听，车辆状态变化（如从驻车变为行驶状态）则接口回调返回结果。|
|[restrictions.unregisterUxRestrictionsListener(OBJECT)](#section1389172615114)|注销UX限制监听。|

### 限制项说明

|限制项|取值|描述|
|:-------------------------------------|:--|:------------------------------------|
|UX_RESTRICTIONS_BASELINE|0|应用需启用基准限制|
|UX_RESTRICTIONS_NO_DIALPAD|1|限制使用电话|
|UX_RESTRICTIONS_NO_FILTERING|2|限制对内容列表做过滤|
|UX_RESTRICTIONS_LIMIT_STRING_LENGTH|4|限制字符串显示的长度|
|UX_RESTRICTIONS_NO_KEYBOARD|8|限制使用软键盘|
|UX_RESTRICTIONS_NO_VIDEO|16|限制视频播放|
|UX_RESTRICTIONS_LIMIT_CONTENT|32|限制所显示的内容条目数量|
|UX_RESTRICTIONS_NO_SETUP|64|限制使用外接设备|
|UX_RESTRICTIONS_NO_QRSCAN|64|限制提供二维码扫描（之前取值为1024，新版本修改取值后仍然兼容旧的取值）|
|UX_RESTRICTIONS_NO_TEXT_MESSAGE|128|限制文本内容的显示（短信，邮件等）|
|UX_RESTRICTIONS_NO_VOICE_TRANSCRIPTION|256|限制语音进行文本翻译后在界面显示|
|UX_RESTRICTIONS_FULLY_RESTRICTED|511|应用需开启所有限制|

### restrictions.getUxRestrictions(OBJECT)

**描述**

查询获取当前车辆UX限制项限制结果。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:---------------|:-------|:---|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|restrictionsType|int|是|限制类型。 传入"[限制项说明](#section108811515205717)"表中限制项取值，如果接口调用成功，则返回isRestricted，表示该限制项是否限制； 传入"[限制项说明](#section108811515205717)"表中未列出限制项的取值，如果接口调用成功，则返回activeRestrictions，表示所有限制项的限定情况。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:------------------------------|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requiresDistractionOptimization|boolean|当前运行的快应用是否需要优化干扰驾驶的内容，即对功能和内容做限制。如果需要优化，则返回true，否则返回false。|
|timeStamp|long|调用接口的时间（单位纳秒）。|
|isRestricted|boolean|表示传入限制项的限制情况，restrictionsType传入具体限定项值时返回。例如传入restrictionsType为16时，isRestricted返回true表示限制视频播放，返回false则不限制。|
|activeRestrictions|int|表示所有支持限定项的限制情况。restrictionsType传入非"[限制项说明](#section108811515205717)"表中限制项的取值时返回，例如传入restrictionsType为-1。通过返回值与具体限制项的取值进行&运算，判断该限制项是否需要限制。例如activeRestrictions & 16，如果结果不等于0表示限制视频播放，等于0表示不限制。|
|maxContentDepth|int|当需要对UX_RESTRICTIONS_LIMIT_CONTENT进行限制时，该参数表示在单个任务中获得最大允许的内容深度级别数。 例如：一项任务仅涉及在一个视图中从单个列表中选择一个项目，则该任务的内容深度视为1；如果任务涉及在原始视图中选择内容项，然后向用户显示辅助视图，则该任务的内容深度视为2；如果任务涉及先浏览国家/地区列表，然后选择国家/地区内的歌曲流派，最后查看国家/地区内的热门歌曲，则该任务的内容深度视为3。|
|maxCumulativeContentItems|int|当需要对UX_RESTRICTIONS_LIMIT_CONTENT进行限制时，该参数表示单个任务中通过任何一条路径遍历时，允许显示给用户内容项的最大数量。 例如：如果一项任务仅涉及一个视图，则这个值表示该单个视图中允许显示内容项的最大数量。以最大允许值为60为例，任务为浏览国家列表，然后查看对应国家的热门歌曲，则可以执行以下任一操作：显示10个国家/地区，然后在选择国家/地区后显示前50首歌曲；或者显示20个国家/地区，然后在选择国家/地区后显示前40首歌曲。|
|maxRestrictedStringLength|int|当需要对UX_RESTRICTIONS_LIMIT_STRING_LENGTH进行限制时，该参数表示可以显示的通用字符串的最大长度。|

**fail返回错误码：**

|错误码|说明|
|:--|:---|
|200|通用错误|

**示例代码**

```screen
restrictions.getUxRestrictions({
        restrictionsType: 16,
                success: function (res) {
                        console.log("getUxRestrictions：  success", res)
                        prompt.showToast({ message: res })
                        let restricted = res.isRestricted;
                        console.log("限制视频播放状态为 ：  restricted ", restricted);
                },
                fail: function (erromsg) {
                        console.log("获取视频播放限制状态：  fail ", erromsg);
                        prompt.showToast({ message: erromsg })
                },
                complete: function () {
                        console.log("方法调用完成：  complete");
                }
})
```

### restrictions.registerUxRestrictionsListener(OBJECT)

**描述**

注册UX限制监听，车辆状态变化（如从驻车变为行驶状态）则接口回调返回结果。

|参数|类型|是否必填|说明|
|:---------------|:-------|:---|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|restrictionsType|int|是|限制类型。 传入"[限制项说明](#section108811515205717)"表中限制项取值，如果接口调用成功，则返回isRestricted，表示该限制项是否限制； 传入"[限制项说明](#section108811515205717)"表中未列出限制项的取值，如果接口调用成功，则返回activeRestrictions，表示所有限制项的限定情况。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:------------------------|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|timeStamp|long|调用接口的时间（单位纳秒）。|
|isRestricted|boolean|表示传入限制项的限制情况，restrictionsType传入具体限定项值时返回。例如传入restrictionsType为16时，isRestricted返回true表示限制视频播放，返回false则不限制。|

|maxContentDepth|int|当需要对UX_RESTRICTIONS_LIMIT_CONTENT进行限制时，该参数表示在单个任务中获得最大允许的内容深度级别数。 例如：一项任务仅涉及在一个视图中从单个列表中选择一个项目，则该任务的内容深度视为1；如果任务涉及在原始视图中选择内容项，然后向用户显示辅助视图，则该任务的内容深度视为2；如果任务涉及先浏览国家/地区列表，然后选择国家/地区内的歌曲流派，最后查看国家/地区内的热门歌曲，则该任务的内容深度视为3。|

|maxRestrictedStringLength|int|当需要对UX_RESTRICTIONS_LIMIT_STRING_LENGTH进行限制时，该参数表示可以显示的通用字符串的最大长度。|

**fail返回错误码：**

|错误码|说明|
|:--|:---|
|200|通用错误|

**示例代码**

```screen
restrictions.registerUxRestrictionsListener({
        restrictionsType: 16,
        success: function (res) {
                console.log("车辆状态变化，监听回调：  success", res);

        },
        fail: function (erromsg) {
                console.log("车辆状态变化，监听回调：  fail ", erromsg);
                prompt.showToast({ message: erromsg })
        },
        complete: function () {
                console.log("方法调用完成：  complete");
        }
})
```

### restrictions.unregisterUxRestrictionsListener(OBJECT)

**描述**

注销UX限制监听。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:------|:-----|:------|
|message|string|注销提示信息。|

**fail返回错误码：**

|错误码|说明|
|:--|:---|
|200|通用错误|

**示例代码**

```screen
restrictions.unregisterUxRestrictionsListener({
        success: function (res) {
                console.log("取消车辆状态监听改变：  success", res);
                    prompt.showToast({ message: res });
                },
                fail: function (erromsg, errocode) {
                    console.log("取消车辆状态监听改变：  fail ", erromsg);
                    prompt.showToast({ message: erromsg })
                },
                complete: function () {
                    console.log("取消车辆状态监听改变：  complete");
                }
})
```
