# 设备信息

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.device"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import device from '@system.device'
```

或

```screen
var device = require("@system.device")
```

## 使用限制

|限制条件|说明|
|:---|:-----------------|
|适用终端|手机、平板、车机，智慧屏支持部分接口|
|适用区域|全球|

## 属性（1030+）

|属性|类型|默认值|是否必选|说明|
|:--------------------|:------|:--|:---|:------------------------------------------------------------------------------------------------------------|
|platform|object|-|否|用于获取平台信息，该对象包括一个属性值：versionCode，表示平台版本号。|
|allowTrackOAID(1060+)|boolean|-|否|限制oaid以及HarmonyOS 2.0及以上或Android 10.0及以上的deviceId是否可以用于广告跟踪。设置为true，表示限制用于广告跟踪。该值的更新需要引擎进程重启后生效，否则读取的为引擎缓存的值。|

### device.getInfo(OBJECT)

**描述**

获取设备信息。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:-----------------------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|brand|string|设备品牌。|
|manufacturer|string|设备生产商。|
|model|string|设备型号。|
|product|string|设备代号。|
|osType|string|操作系统名称。|
|osVersionName|string|操作系统版本名称。|
|osVersionCode|number|操作系统版本号。|
|platformVersionName|string|运行平台版本名称。|
|platformVersionCode|number|运行平台版本号。|
|language|string|系统语言。|
|region|string|系统地区。|
|screenWidth|number|屏幕宽。|
|screenHeight|number|屏幕高。|
|engineProvider|string|华为扩展参数，非厂商联盟标准，引擎的提供商，返回固定值"huawei"。|
|windowWidth(1020+)|number|可使用窗口宽度，以屏幕的实际分辨率为单位。|
|windowHeight(1020+)|number|可使用窗口高度，以屏幕的实际分辨率为单位。 可使用窗口高度=屏幕的高度- 状态栏高度-标题栏高度-虚拟导航栏高度。|
|cutout(1080+)|array|针对异形屏（比如刘海屏、水滴屏和开孔屏），返回异形区域的位置。包含以下参数： * left：cutout左边界和屏幕左边框的距离 * top：cutout上边界和屏幕上边框的距离 * right：cutout右边界和屏幕右边框的距离 * bottom：cutout下边界和屏幕下边框的距离 例如：cutout: [{"left":0,"top":0,"right":955,"bottom":2208}]。|
|statusBarHeight(1020+)|number|状态栏的高度，以屏幕的实际分辨率为单位。|
|pixelRatio(1020+)|number|设备像素比（华为扩展接口，非厂商联盟规范）。|
|screenDensity(1035+)|number|设备的屏幕密度。|
|screenLogicWidth|number|设备的屏幕逻辑宽度。|
|screenLogicHeight|number|设备的屏幕逻辑高度。|
|timeZone(1040+)|string|当前的系统时区。|
|emuiVer(1040+)|string|EMUI的系统版本号，如9.0.0。|
|fontScale(1040+)|number|用户字体大小设置。以"系统-设置-通用-字体大小"中的设置为准，例如0.9， 1，1.1，1.2，1.5等。|
|characteristics(1040+)|string|终端类型，通过读取ro.build.characteristics获取： default、tv、tablet、phone。缺省为phone。|
|windowLogicWidth(1040+)|number|* 在卡片场景下，以750为基准，卡片宿主应用为卡片显示分配的宽度。例如非全屏显示的卡片，该值为小于750的某个值， 比如460。 * 在快应用场景下，该值与快应用manifest文件中config的designWidth配置，默认为750。|
|windowLogicHeight(1040+)|number|在卡片场景下特有，以750为基准，卡片宿主应用为卡片显示分配的高度。如果宿主应用没有给卡片分配特定的高度，获取此值将失败。|
|emuiApiLevel(1050+)|string|系统的api版本号，如18。|
|marketingName(1060+)|string|机型传播名，如P20Pro。|
|harmonyOSVer(1078+)|string|HarmonyOS设备版本号，如2.0.0。|
|vendorOsName(1080+)|string|手机厂商定制的系统名称。|
|vendorOsVersion(1080+)|string|手机厂商定制的系统版本号。|
|deviceType(1090+)|string|设备类型。 取值如下： * phone：手机 * tablet：平板 * tv：智慧屏 * foldable(1110+)：可折叠设备|
|screenRefreshRate(1100+)|float|屏幕当前显示的刷新率。 获得的帧率可能不是60、90、144等标准帧率值。|

### device.getId(OBJECT)

**描述**

获取设备标识、用户标识、MAC地址。

智慧屏和卡片不支持。
> 注意
>
> Android 10.0以前需要弹框授权，HarmonyOS 2.0及以上或Android10.0及以上版本不弹框。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|type|array|是|支持device、mac、user三种类型，可以同时提供多个，至少提供一个。|
|success|function|否|成功回调，参数为：{"device":"1234567890","mac":"abcdef123456","user":"abcdef123456"}每项结果仅在type中有对应类型的时候才会返回，快应用引擎版本从3.2.1.310版本开始，mac返回固定值02:00:00:00:00:00，3.2.1.310版本以前mac在系统版本号为6.0及以上返回固定值：02:00:00:00:00:00。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:-----|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|device|string|设备唯一标识。Android 10.0以前返回 IMEI 或 MEID，HarmonyOS 2.0及以上或Android 10.0及以上版本返回AAID（应用匿名设备标识符），AAID和快应用相关，每个快应用AAID不同。当清空应用数据或者卸载应用，AAID会发生变化。|
|mac|string|设备的mac地址。Android 6.0以前返回设备的MAC地址，HarmonyOS 2.0及以上或Android 6.0及以上版本返回固定值。|
|user|string|用户唯一标识。Android 10.0以前返回 ANDROID_ID，HarmonyOS 2.0及以上或Android 10.0及以上版本返回值和快应用签名值相关，相同的签名值相同。如下情况将导致获取值发生改变： 1. 恢复出厂设置 2. 快应用签名指纹改变（HarmonyOS 2.0及以上或Android 10.0及以上版本）|

**fail返回错误码：**

|错误码|说明|
|:--|:---------------|
|201|用户拒绝，获取电话状态权限失败。|

**示例代码**

```screen
device.getId({
    type: ["device", "mac"],
    success:function(data) {
        console.log("handling success: " + data.device);
    },
    fail: function(data, code) {
        console.log("handling fail, code=" + code);
    }
})
```

### device.getOAID(OBJECT)（1060+）

**描述**

获取匿名设备标识符，建议只在广告的场景使用。

智慧屏、车机和卡片不支持。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:---|:-----|:-------------------------------------------------------------------------------|
|oaid|string|匿名设备标识符。如果当前设备不支持oaid，返回空值。当用户重置广告标识符后，该值发生改变。当手机系统设置项"限制广告跟踪"为开启状态时，返回由0组成的字符串。|

**示例代码**

```screen
device.getOAID({
        success: function (ret) {
            that.OAID = JSON.stringify(ret);
        },
        fail: function (erromsg, errocode) {
            that.OAID = errocode + ': ' + erromsg
        },
        complete: function () {
            prompt.showToast({
                message: "请求完成" + device.allowTrackOAID
            })
        }
})
```
