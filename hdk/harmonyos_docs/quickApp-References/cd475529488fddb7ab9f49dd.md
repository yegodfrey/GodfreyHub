# 网络

> 说明
>
> 从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。

## 接口定义

|接口|描述|
|:------------------------------------------------------------------|:------------|
|[qg.getNetworkType(Object object)](#section114123714276)|获取网络类型。|
|[qg.onNetworkStatusChange(function callback)](#section989124510294)|监听网络状态变化事件。|
|[qg.offNetworkStatusChange(function callback)](#section83134343213)|取消监听网络状态变化事件。|

### qg.getNetworkType(Object object)

* 描述 获取网络类型。

* 参数object

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:----------------------------------------------------------------------------|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000001083874628__li26263117013)。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数

    |参数|类型|说明|
    |:----------|:-----|:-------------------------------------------------------------------------|
    |networkType|string|网络类型，取值请参见[networkType合法值](#ZH-CN_TOPIC_0000001083874628__li882951515019)。|

    * networkType合法值

      |属性名称|说明|
      |:------|:----------|
      |wifi|wifi网络。|
      |2g|2g网络。|
      |3g|3g网络。|
      |4g|4g网络。|
      |5g|5g网络。|
      |unknown|系统不常见的网络类型。|
      |none|无网络。|

* 示例代码

  ```screen
  qg.getNetworkType({
          success : function (res) {
                  console.log("getNetworkType success networkType" + res.networkType );
          },
          fail:function(){
                  console.log("getNetworkType fail");
          },
          complete:function() {
                  console.log("getNetworkType complete");
          }
  });
  ```

### qg.onNetworkStatusChange(function callback)

* 描述 监听网络状态变化事件。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-------------------------------------------------------------------------------|
  |callback|function|M|网络状态变化事件的回调函数，请参见[callback回调函数参数](#ZH-CN_TOPIC_0000001083874628__li20913681427)。|

  * callback回调函数参数

    |参数|类型|说明|
    |:----------|:------|:--------------------------------------------------------------------------|
    |isConnected|boolean|当前是否有网络链接。|
    |networkType|string|网络类型，取值请参见[networkType的合法值](#ZH-CN_TOPIC_0000001083874628__li882951515019)。|

* 示例代码

  ```screen
  qg.onNetworkStatusChange(
      function callback(res){
          console.log("onNetworkStatusChange isConnected = " + res.isConnected + ", networkType = " + res.networkType);
      }
  );
  ```

### qg.offNetworkStatusChange(function callback)

* 描述 取消监听网络状态变化事件。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------|
  |callback|function|M|取消监听事件的回调函数。|

* 示例代码

  ```screen
  qg.offNetworkStatusChange(
      function callback(){
          console.log("offNetworkStatusChange");
      }
  );
  ```
