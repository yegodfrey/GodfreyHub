# tab-content

#### 概述

\<tabs\> 的子组件，用于展示tab的内容区，高度默认充满tabs剩余空间，子组件排列方式为横向排列。  

#### 使用限制

|限制条件|说明|
|:---|:-------|
|适用终端|手机、平板、车机|
|适用区域|全球|

#### 子组件

支持  

#### 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-attributes-0000001170050123)以外，还支持如下属性。  

|名称|类型|默认值|是否必填|描述|
|:----------------|:------|:---|:---|:----------------------------------------------|
|scrollable(1040+)|boolean|true|否|是否可以通过滑动切换页面。设置为false后，页面的切换需通过与 tab-bar 的联动实现。|

#### 样式

支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-common-styles-0000001170210009)。  

#### 事件

支持 [通用事件](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-events-0000001123530338) ，不支持swipe事件。

<script>
    import prompt from '@system.prompt'

    export default {
        data: {
            scrollable: true,
            componentName: 'tabs',
            time: '',
            loadMore: true,
            scrollPage: false,
            btndisabled: false,
            list_data: [{ name: 'A' }, { name: 'B' }, { name: 'C' }, { name: 'D' }, { name: 'E' }, { name: 'F' }]
        },
        onInit: function () {
            this.$page.setTitleBar({ text: 'tab-content' })
            // initial time
            this.time = new Date().getHours() + ':' + new Date().getMinutes()
        },
        changeTabcontentScrollable: function () {
            this.scrollable = !this.scrollable
        },
        changeTabactive: function (e) {
            prompt.showToast({
                message: "the playing page number is " + e.index + "  "
            })
            // switch tab
            console.log('----------switch tab: ' + e.index)
        },
        setTime: function (e) {
            // After select time picker,set time
            this.time = e.hour + ':' + e.minute
        },
        scrollbottom: function () {
            var that = this
            // list scroll to bottom
            setTimeout(function () {
                that.list_data = that.list_data.concat([{ name: 'A' }, { name: 'B' }, { name: 'C' }, { name: 'D' }, { name: 'E' }, { name: 'F' }])
            }, 1000)
        },
        goIndex: function () {
            // List scrolls to the specified index position
            this.$element('list').scrollTo({ index: 0, smooth: true })
        }
    }
</script>
