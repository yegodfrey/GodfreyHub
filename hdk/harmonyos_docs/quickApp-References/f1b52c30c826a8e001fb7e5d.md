# 通用属性

#### 常规属性

|名称|类型|默认值|描述|
|:----------------------|:------|:----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|id|string|-|唯一标识。|
|style|string|-|样式声明。|
|class|string|-|引用样式表。|
|disabled|boolean|false|表明当前组件是否可用。|
|focusable|boolean|false|是否可获取焦点。 智慧屏上如果组件需要响应遥控器事件，必须设置focusable为true。|
|data|string|-|支持组件设置 data 属性，方便实现一些数据存储和读取。|
|dir(1070+)|string|-|指定组件的语言方向。 * ltr：从左到右； * rtl：从右向左； * auto：随系统设置 不设置时，继承父组件dir的值，如果本身为顶级组件则跟随系统设置。 注意： * \<marquee\>组件在阿拉伯语等从右向左语言环境下，设置dir属性为ltr，不生效。 * EMUI9.1以下版本，\<select\>、\<input\>、\<switch\>组件 在阿拉伯语等从右向左语言环境下，设置dir属性为ltr，不生效。|
|aria-label（1101+）|string|-|无障碍模式下组件的描述文本。|
|aria-unfocusable（1101+）|boolean|false|无障碍模式下，是否可以获取焦点。 设置为true时，表示该组件在无障碍模式下不会被选中，所以该组件的aria-label属性也不会生效。|

#### 渲染属性

|名称|类型|默认值|描述|
|:---|:------|:--|:-----------------------------------------------------|
|for|array|-|根据数据列表，循环展开当前标签。|
|if|boolean|-|根据数据boolean值，添加或移除当前标签。|
|show|boolean|-|根据数据boolean值，显示或隐藏当前标签，相当于控制{ display: flex \| none }。|

渲染属性工作方式详细请参见"[template模板](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-template-0000001073436395)"。
