# 动画

#### 接口声明

使用 动画 接口前，需要在js代码中，为element统一新增animation方法：

```
var animation = this.$element('xxx').animate(keyframes, options);
```

#### 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

keyframes参数说明：  

|参数|类型|说明|
|:----|:-------------|:-------------|
|frame|array\<style\>|设置动画样式属性的多组对象。|

style类型说明：  

|参数|类型|默认值|说明|
|:------------------------|:-----|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|width|number|-|动画执行后应用到组件上的宽度值。|
|height|number|-|动画执行后应用到组件上的高度值。|
|backgroundColor|color|none|动画执行后应用到组件上的背景颜色。|
|opacity|number|1|动画执行后应用到组件上的不透明度值介于0到1间的数值，默认为1。|
|transformOrigin|string|'center center'|定义变化过程的中心点。 * 第一个参数代表x轴，可能的值为left、center、right、长度值或百分比值； * 第二个参数代表y轴，可能的值为top、center、bottom、长度值或百分比值。|
|transform|object|-|定义应用在元素上的变换类型，支持"[transform说明](#ZH-CN_TOPIC_0000001074264335__table1064043532418)"中列出的属性。|
|backgroundPosition(1090+)|string|'0px 0px'|背景图片在容器中绘制的位置，支持 1-4 个参数，详情请参见"通用样式"中的"[background-position](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-common-styles-0000001170210009#ZH-CN_TOPIC_0000001170210009__p2311421162913)"说明。|

transform说明：  

|参数|类型|说明|
|:------------------------------------------------|:----------------|:--------------------------------------------------|
|translate/translateX/translateY/translateZ(1110+)|length|指定元素要移动到的位置。 说明： 每个属性在keyframes数组中最多只能设置2次。|
|translate3d(1110+)|length \| percent|3D平移，通过向量 \[tx,ty,tz\]来指定tx、ty和tz分别作为第一、第二和第三平移值参数。|
|scale/scaleX/scaleY|number|按比例放大或缩小元素。 说明： 每个属性在keyframes数组中最多只能设置2次。|
|rotate/rotateX/rotateY|deg|指定元素将被旋转的角度，单位是度。 说明： 每个属性在keyframes数组中最多只能设置2次。|

options参数说明：  

|参数|类型|默认值|说明|
|:---------|:---------------|:-----|:---------------------------------------------------------------------------------------------------|
|duration|number|0|指定动画的持续时间（单位毫秒）。默认值0，表示没有动画效果。|
|easing|string|linear|描述动画执行的速度曲线，用于使动画更为平滑。easing的值请参见"[easing有效值说明](#ZH-CN_TOPIC_0000001074264335__table1635415814265)"。|
|delay|number|0|指定请求动画操作到执行动画之间的时间间隔（单位毫秒）；默认值 0，表示没有延迟。|
|iterations|number|1|动画执行次数，可设置为 Infinity 无限次。|
|fill|none \| forwards|none|指定动画执行结束后是否恢复初始状态，默认值为none，表示恢复初始状态。|

easing有效值说明：  

|值|描述|
|:---------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|linear|动画从头到尾的速度是相同的。|
|ease-in|动画速度由慢到快。|
|ease-out|动画速度由快到慢。|
|ease-in-out|动画先加速到达中间点后减速到达终点。|
|cubic-bezier(x1, y1, x2, y2)(1080+)|在三次贝塞尔函数中定义变化过程，函数的x轴参数值必须处于0到1之间，y轴参数值建议处于0到1之间。|
|steps(number-of-steps, step direction) (1090+)|把动画分为n步阶段性展示，每段停止的时间都相同。 * number-of-steps：指定动画分割的段数。 * step direction：指定每个间隔的起点或是终点发生阶跃变化，可选值为 jump-start、jump-end、jump-none、jump-both、start 和 end，默认为end 。|
|step-start (1090+)|等同于steps(1, jump-start) 。|
|step-end (1090+)|等同于steps(1, jump-end) 。|

animation属性说明  

|属性|类型|说明|
|:--------|:------|:---------------------------------------------------------------------------------------------------------------------------|
|finished|boolean|只读属性，当前动画是否已完成。|
|pending|boolean|只读属性。当前动画是否是等待其他异步操作完成的等待状态（例如启动一个延时播放的动画）。|
|playState|string|获取或设置动画的执行状态。 * idle：未执行状态，包括已结束或未开始。动画当前的时间是无法解析的，并且队列里没有处于等待执行的任务。 * running：动画处于正在运行状态。 * paused：动画中止。 * finished：动画播放结束。|
|startTime|number|获取或设置动画播放开始的预定时间，用途类似于options参数中的delay。|

animation方法说明  

|方法|参数|说明|
|:------|:-|:---------|
|play|-|开始执行动画。|
|finish|-|结束动画。|
|pause|-|暂停动画。|
|cancel|-|取消动画。|
|reverse|-|反转动画的执行方向。|

animation事件说明  

|事件|说明|
|:-----|:------|
|cancel|动画被取消。|
|finish|动画执行结束。|

示例代码

```
var options = {
    duration: 15000,
    easing: 'linear',
    delay: 0,
    fill: 'forwards',
    iterations: 1
}
var frames = [
    {transform: {
        scaleX: "0.1",
        scaleY: "0.1",
    }},
    {transform: {
        scaleX: "1",
        scaleY: "1",
    }}];
var animation = this.$element('xxx').animate(frames, options);
animation.play();
animation.finish();
animation.pause();
animation.cancel();
animation.reverse();
animation.onfinish = function() {
    console.log("animation onfinish");
}
animation.oncancel = function() {
    console.log("animation  oncancel");
}
```
