# 日志打印

#### 接口声明

无需声明  

#### 导入模块

无需声明  

#### 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

#### 接口定义

|接口|描述|
|:------------------------------------------------------------------|:-------------|
|[console.debug/log/info/warn/error(message)](#section1799713141254)|在华为IDE中打印一段文本。|

#### console.debug/log/info/warn/error(message)

描述

在华为IDE中打印一段文本。

参数  

|参数|类型|是否必填|描述|
|:------|:-----|:---|:--------------------------------|
|message|string|是|要打印的文本，也可以是格式化文本，规则与浏览器的console相同|

示例代码

```
for (var i=0; i<5; i++) {
 console.log("Hello, %s. You've called me %d times.", "Bob", i+1);
 }
 console.log("I want to print a number: %d", 123456);
```

  import app from '@system.app'

      console.log(JSON.stringify(app.getInfo()))

      app.getPackageInfo({
        packageName: 'com.tencent.mm',
        success: (data) => {
          this.packageInfo = JSON.stringify(data)
          console.info('getPackageInfo success', JSON.stringify(data))
        },
        fail: (errormsg, errorcode) => {
          this.packageInfo = 'get fail --- ' + errorcode + ':' + errormsg
          console.info('get fail --- ' + errorcode + ':' + errormsg)
