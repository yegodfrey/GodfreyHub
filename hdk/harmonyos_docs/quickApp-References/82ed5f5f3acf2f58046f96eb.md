接口定义 [h2]qa.getAdProvider()（1101+）**描述** 获取服务提供商，返回提供商的英文品牌名称。 **返回值** 字符串，服务提供商的代号，如厂商的英文品牌名称，如果无此服务则返回空字符串。返回空字符串时，请勿调用该服务其他接口，否则将抛出异常。 **示例代码**
    
    qa.getAdProvider();

[h2]qa.requestAdConsentUpdate(object)（1101+）**描述** 请求用户意见更新状态。 **参数** 参数 | 类型 | 是否必填 | 说明  
---|---|---|---  
success | function | 否 | 请求用户意见更新状态成功。  
fail | function | 否 | 请求用户意见更新状态失败。  
complete | function | 否 | 执行结束后的回调。  
**success回调参数** 参数 | 类型 | 说明  
---|---|---  
consentStatus | number | 用户意见状态。
    * 0：用户已同意接收个性化广告与非个性化广告。
    * 1：用户已同意仅接收非个性化广告。
    * 2：用户既未同意接收也未拒绝接收个性化广告或非个性化广告。  
isNeedConsent | boolean | 是否需要用户确认意见。
    * 取值为false，表明可以向鲸鸿动能SDK请求个性化广告。
    * 取值为true，表明用户在欧洲经济区内或其他敏感地区，需进一步确认用户意见。  
AdProviderList | array | 广告技术提供商信息列表。AdProvider对象结构详细请参见“AdProvider说明”。  
**AdProvider说明** 字段 | 定义  
---|---  
id | 广告技术提供商的ID。  
name | 广告技术提供商的名称。  
serviceArea | 广告技术提供商的服务地。  
privacyPolicyUrl | 广告技术提供商的隐私政策链接URL。  
**示例代码**
    
    qa.requestAdConsentUpdate({
      success: function(data) {
        console.log('requestConsentUpdate success data ' + JSON.stringify(data))
      },
      fail: function(data) {
        console.log('requestConsentUpdate fail data ' + JSON.stringify(data))
      },
      complete: function() {},
    })

[h2]nativeAd.reportAdClick()（1101+）**描述** 上报广告点击，一个广告只有一次上报有效，adId 为 load 方法获取的广告数据的 adId 字段。 **参数** 参数 | 类型 | 是否必填 | 说明  
---|---|---|---  
adId | string | 是 | 广告信息标识，由onload回调返回。  
clickInfo(1105+) | object | 否 | 广告点击信息，详细内容参见“clickInfo说明”。  
**clickInfo说明** 参数 | 类型 | 是否必填 | 说明  
---|---|---|---  
clickX | number | 否 | 点击按下位置相对于广告位的横坐标，单位为px。  
clickY | number | 否 | 点击按下位置相对于广告位的纵坐标，单位为px。  
upX(1106+) | number | 否 | 点击抬起位置相对于广告位的横坐标，单位为px。  
upY(1106+) | number | 否 | 点击抬起位置相对于广告位的纵坐标，单位为px。  
density(1106+) | float | 否 | 设备密度。  
sld(1106+) | int | 否 | 广告触发类型。取值范围如下：
    * 0：常规触屏点击
    * 1：滑动点击，广告上引导用户进行滑动以触发点击
    * 2：摇一摇，由重力加速变化触发点击
    * 3：自定义手势
    * 4：点击或滑动，即广告既允许点击，也允许滑动触发
    * 5：扭一扭，由屏幕角度变化触发点击
    * 6：擦除触发点击
    * 7：横竖屏转换  
creativeSize | object | 否 | 广告区域的尺寸，即完整广告容器大小，详细内容参见“creativeSize说明”。  
**creativeSize说明（1106+）** 参数 | 类型 | 是否必填 | 说明  
---|---|---|---  
width | number | 否 | 广告区域的宽度，单位为px。  
height | number | 否 | 广告区域的高度，单位为px。  
**示例代码**
    
    nativeAd.reportAdClick({ adId: "xxx",
          clickInfo: {
              clickX:750,
              clickY:200,
              upX:740,
              upY:202,
              sld:0,
              density:3.0,
              creativeSize:{
                width:1500,
                height:750
              }
          }
    })
