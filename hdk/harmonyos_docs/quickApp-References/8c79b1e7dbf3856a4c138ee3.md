# 屏幕亮度

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.brightness"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import brightness from '@system.brightness'
```

或

```screen
var brightness = require("@system.brightness")
```

## 使用限制

|限制条件|说明|
|:---|:-------|
|适用终端|手机、平板、车机|
|适用区域|全球|

## 接口定义

|接口|描述|
|:---------------------------------------------------------|:----------|
|[brightness.getValue(OBJECT)](#section176811533102713)|获得当前屏幕亮度值。|
|[brightness.setValue(OBJECT)](#section1173910212328)|设置当前屏幕亮度值。|
|[brightness.getMode(OBJECT)](#section17954161193317)|获得当前屏幕亮度模式。|
|[brightness.setMode(OBJECT)](#section10863195519401)|设置当前屏幕亮度模式。|
|[brightness.setKeepScreenOn(OBJECT)](#section179848194320)|设置是否保持常亮状态。|

### brightness.getValue(OBJECT)

**描述**

获得当前屏幕亮度值。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:----|:-----|:----------------|
|value|number|屏幕亮度，取值范围0 ~ 255。|

**示例代码**

```screen
brightness.getValue({
    success:function(ret){console.log("handling success");}
})
```

### brightness.setValue(OBJECT)

**描述**

设置当前屏幕亮度值。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:----------------------------------------------------------------------------------------------------|
|value|number|是|屏幕亮度，取值范围0 ~ 255的整数。 * 如果设置值小于等于0，系统按1处理。 * 如果设置值大于255，系统按255处理。 * 如果设置值为小数，系统将处理为整数。例如设置为1.8，系统按1处理。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
brightness.setValue({
    success:function(data){console.log("handling success"); },
    fail: function(data, code){console.log("handling fail, code=" + code);}
})
```

### brightness.getMode(OBJECT)

**描述**

获得当前屏幕亮度模式。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:---|:-----|:------------------------|
|mode|number|* 0为手动调节屏幕亮度 * 1为自动调节屏幕亮度|

**示例代码**

```screen
brightness.getMode({
    success:function(ret){console.log("handling success");}
})
```

### brightness.setMode(OBJECT)

**描述**

设置当前屏幕亮度模式。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:------------------------|
|mode|number|是|* 0为手动调节屏幕亮度 * 1为自动调节屏幕亮度|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
brightness.setMode({
    success:function(data){console.log("handling success"); },
    fail: function(data, code){console.log("handling fail, code=" + code);}
})
```

### brightness.setKeepScreenOn(OBJECT)（1060+）

**描述**

设置是否保持常亮状态。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-----------|:-------|:---|:--------|
|keepScreenOn|boolean|是|是否保持屏幕常亮。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
brightness.setKeepScreenOn({
    keepScreenOn: true,
    success: function () {
        console.log(`handling success`)
    },
    fail: function (data, code) {
    }
})
```

```screen
<script>
  import brightness from '@system.brightness'

  export default {
    private: {
      componentName: 'Brightness',
      value: 0,
      sliderValue: 0,
      status: '',
      mode: '',
      setModStatus: '',
      keepScreenStatus:'',
    },
    onInit () {
      this.$page.setTitleBar({text: 'Brightness'})
    },
    getValue () {
      const self = this
      brightness.getValue({
        success: function (ret) {
          self.value = ret.value
        },
        fail: function (error) {
          self.value = error
        }
      })
    },
    getSliderValue (e) {
      this.sliderValue = e.progress
    },
    setValue () {
      const self = this
      brightness.setValue({
        value: self.sliderValue,
        success: function () {
          self.status = 'success';

        },
        fail: function (err) {
          self.status = 'set brightness failed： ' + err;
        }
      })
    },
    getMode () {
      const self = this
      brightness.getMode({
        success: function (ret) {
          self.mode = ret.mode
        }
      })
    },
    setMode (index) {
      const self = this
      brightness.setMode({
        mode: index,
        success: function(){
          self.setModStatus = 'mode=' + index
        },
        fail: function(err, code){
          self.setModStatus = 'handling fail, code=' + code
        }
      })
    },
    setKeepScreenOn(){
      let self = this;
        brightness.setKeepScreenOn({
          keepScreenOn: true,
          success() {
            self.keepScreenStatus = 'success'
            console.log(`handling success`)
          },
          fail(data, code) {
            console.log(`handling fail, data=${data},code=${code}`)
          }
      })
    }
  }
</script>
```
