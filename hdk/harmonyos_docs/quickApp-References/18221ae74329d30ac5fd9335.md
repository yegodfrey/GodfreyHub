# 截屏（1100+）

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.screenshot"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import screenshot from '@system.screenshot'
```

或

```screen
var screenshot = require("@system.screenshot")
```

## 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

## 接口定义

|接口|描述|
|:---------------------------------------------------------------|:--------|
|[screenshot.onUserCaptureScreen(OBJECT)](#section17862114873311)|监听用户截屏。|
|[screenshot.offUserCaptureScreen()](#section170045693318)|取消监听用户截屏。|

### screenshot.onUserCaptureScreen(OBJECT)

**描述**

监听用户截屏。用户使用系统截屏、按键截屏、三指滑屏等方式时触发。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------|
|callback|function|是|用户截屏后会回调此函数。|

**callback返回值**

无

**fail返回错误码**

|错误码|说明|
|:--|:------------|
|201|用户拒绝获取手机存储权限。|

**示例代码**

```screen
screenshot.onUserCaptureScreen({
    callback: function (data) {
        prompt.showToast({
        message: 'The user took a screenshot success',
        duration: "100000",
        gravity: 'center'
        })
        console.log('The user took a screenshot success!.')
    },
    fail:function (data,code) {
        prompt.showToast({
        message: 'The user took a screenshot fail',
        duration: "100000",
        gravity: 'center'
        })
        console.log('The user took a screenshot fail.')
    }
})
```

### screenshot.offUserCaptureScreen()

**描述**

取消监听用户截屏。

**参数**

无

**示例代码**

```screen
screenshot.offUserCaptureScreen()
```
