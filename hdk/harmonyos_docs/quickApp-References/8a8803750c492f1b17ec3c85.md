# 生命周期

![](https://media:201785478326975754)  
从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。  

#### 接口定义

|接口|描述|
|:--------------------------------------------------------|:-----------------------|
|[qg.exitApplication(Object object)](#section827053913382)|退出当前快游戏。|
|[qg.getLaunchOptionsSync()（1103+）](#section4844135503910)|获取快游戏启动时的参数。|
|[qg.onHide(function callback)](#section4172346204817)|监听隐藏到后台事件，快游戏切换到后台后触发回调。|
|[qg.offHide(function callback)](#section67289273509)|取消监听快游戏隐藏到后台事件。|
|[qg.onShow(function callback)](#section16220131917512)|监听快游戏回到前台的事件。|
|[qg.offShow(function callback)](#section6163413205219)|取消监听快游戏回到前台的事件。|
|[qg.restartMiniProgram()](#section109261152195017)|重启快游戏。|

#### qg.exitApplication(Object object)

* 描述 退出当前快游戏。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------------------|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|接口调用结束的回调函数，调用成功、失败都会执行。|

* 示例代码

  ```
  qg.exitApplication({
          success : function () {
                  console.log("exitApplication success" );
          },
          fail:function(){
                  console.log("exitApplication fail");
          },
          complete:function() {
                  console.log("exitApplication complete");
          }
  });
  ```

#### qg.getLaunchOptionsSync()（1103+）

* 描述 获取快游戏启动时的参数。

* 返回参数  

  |参数|类型|说明|
  |:-----------|:-----|:----------------------------------------------------------------------------------------------------------|
  |query|string|启动快游戏时携带的参数，请参见[query参数](#ZH-CN_TOPIC_0000001083746128__li18551447114811)。支持转换成JSON Object。|
  |referrerInfo|object|来源信息。从另一个快游戏、应用市场、快游戏中心或桌面快捷方式启动，否则返回{}，请参见[referrerInfo参数](#ZH-CN_TOPIC_0000001083746128__li171865044916)。|

  * query参数  
    ![](https://media:201785478327014755)  
    返回参数取决于您在deeplink传递的参数，除了如下参数，还会返回您自定义的参数。  

    |参数|类型|说明|
    |:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    |gameGiftId|string|游戏礼包ID。|
    |giftUri|string|礼包页面地址，即您在创建礼包时设置的跳转地址。启动后由游戏自行根据礼包地址展示相应礼包页面。|
    |userEntry|string|渠道平台，取值如下： * 101：巨量平台。 * 102：腾讯平台。 * 900\~999：自定义的渠道平台。|
    |gameRunMode|string|游戏运行模式，取值说明如下： * normal：普通模式，当快游戏正常启动或未设置该参数值时触发，按照正常游戏流程运行游戏。 * revisit：复访模式，根据直玩拉起的场景触发，需要为老用户提供个性化体验。 * userAcquire：获客模式，根据直玩拉起的场景触发，需要为新用户提供引导和激励。 该参数不存在时，将视作设置为normal。|

  * referrerInfo参数  

    |参数|类型|说明|
    |:--------|:-----|:-----------------------------------------------------------------------------------------------|
    |type|string|参数的来源类型： * shortcut：桌面图标。 * url：网页链接。 * app：鸿蒙应用。 * quickapp：快应用或快游戏。 * deeplink：链接。 * other：其它。|
    |extraData|object|鸿蒙应用或游戏，快应用或快游戏场景下，通过packageName标识调用方的包名信息。 ``` { packageName:"com.huawei.appMarket" } ```|

#### qg.onHide(function callback)

* 描述 监听隐藏到后台事件，快游戏切换到后台后触发回调。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:---------------|
  |callback|function|M|快游戏隐藏到后台触发的回调函数。|

* 示例代码

  ```
  qg.onHide(
       callback() {console.log("onHide");}
  );
  ```

#### qg.offHide(function callback)

* 描述 取消监听快游戏隐藏到后台事件。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------|
  |callback|function|M|取消监听回调函数。|

* 示例代码

  ```
  qg.offHide(
       callback() {console.log("offHide");}
  );
  ```

#### qg.onShow(function callback)

* 描述 监听快游戏回到前台的事件。

* 参数  

  |参数|类型|说明|
  |:------------------|:-----|:-----------------------------------------------------------------------------------------------------------|
  |query(1078+)|object|启动快游戏的query。|
  |referrerInfo(1078+)|object|来源信息。从另一个快游戏、应用市场、快游戏中心或桌面快捷方式启动，否则返回{}，请参见[referrerInfo参数](#ZH-CN_TOPIC_0000001083746128__li1697531219514)。|

  * referrerInfo参数  

    |参数|类型|说明|
    |:--------|:-----|:-----------------------------------------------------------------------------------------------|
    |type|string|参数的来源类型： * shortcut：桌面图标。 * url：网页链接。 * app：鸿蒙应用。 * quickapp：快应用或快游戏。 * deeplink：链接。 * other：其它。|
    |extraData|object|鸿蒙应用或游戏，快应用或快游戏场景下，通过packageName标识调用方的包名信息。 ``` { packageName:"com.huawei.appMarket" } ```|

* 示例代码

  ```
  var callback = function (res) {
      console.log("收到 onShow 回调:\n" + JSON.stringify(res));
  };
  qg.onShow(callback);
  ```

#### qg.offShow(function callback)

* 描述 取消监听快游戏回到前台的事件。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:---------------------------------------------------------------|
  |callback|function|M|取消监听快游戏回到前台事件的回调函数。 说明： 传入的callback必须与onShow的保持一致，否则无法取消对应的监听事件。|

* 示例代码

  ```
  qg.offShow(
          callback() {console.log("offShow");}
  );
  ```

#### qg.restartMiniProgram()

* 描述 重启快游戏。

* 示例代码

  ```
  if (qg.restartMiniProgram) {
      qg.restartMiniProgram();
  }
  ```
