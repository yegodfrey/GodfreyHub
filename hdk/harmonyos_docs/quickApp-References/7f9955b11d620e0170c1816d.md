# 画布

#### 接口声明

使用 画布 接口前，需要在js代码中，通过canvas组件的 getContext() 获取 画布 对象。

```
var canvasComponent = this.$element(canvasId)
var canvas = canvasComponent.getContext(“2d”)
```

#### 使用限制

|限制条件|说明|
|:---|:--------|
|适用终端|手机、平板、智慧屏|
|适用区域|全球|

#### 属性

|属性|参数|类型|是否必填|说明|
|:-----------------------------|:------------|:--------------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|fillStyle|style|color、gradient object|否|设置填充色。 如果没有设置，默认颜色为black。|
|strokeStyle|style|color、gradient object|否|设置边框的颜色。 如果没有设置，默认颜色为black。|
|lineWidth|lineWidth|number|否|线条的宽度(单位是px)。|
|lineCap|lineCap|string|否|'butt'、'round'、'square' 线条的结束端点样式默认值'butt'。|
|lineJoin|lineJoin|string|否|'bevel'、'round'、'miter' 线条的结束交点样式默认值'miter'。|
|miterLimit|miterLimit|number|否|最大斜接长度。 设置最大斜接长度，斜接长度指的是在两条线交汇处内角和外角之间的距离。 当 LineJoin 为 miter 时才有效。超过最大倾斜长度的，连接处将以 lineJoin 为 bevel 来显示。|
|font（默认值：10px sans-serif）|font-style|string|否|字体样式（可能值：normal，italic，obliqua）。|
|font（默认值：10px sans-serif）|font-weight|string|否|规定字体的粗细（可能值：normal bold）。|
|font（默认值：10px sans-serif）|font-family|string|否|规定字体系列。（sans-serif ，serif ，monospace）仅支持这三种。|
|font（默认值：10px sans-serif）|font-size|string|否|字体的字号，以像素计。|
|textAlign|align|string|否|设置文字的对齐，可选值 'left'、'center'、'right' 、'start'、'end'（默认。文本在指定的位置开始'start'）。|
|textBaseline|textBaseline|string|否|设置文字的水平对齐，可选值 'top'、'bottom'、'middle'、'hanging'、'alphabetic'、'ideographic'（默认。文本基线是普通的字母基线'alphabetic'。）。|
|globalAlpha|alpha|number|否|设置全局画笔透明度。 0\~1 透明度，0 表示完全透明，1 表示完全不透明。|
|globalCompositeOperation|model|string|否|属性设置或返回如何将一个源（新的）图像绘制到目标（已有）的图像上，source-over(默认)source-atop，source-in，source-out，destination-over，destination-atop，destination-in，destination-out，lighter，copy，xor。 如果设置了该属性，则不支持抗锯齿的绘制PDF Canvas。|

|shadow（华为扩展接口，非厂商联盟规范）|shadowOffsetX|number|否|阴影相对于形状在水平方向的偏移，默认值为0。|

|shadow（华为扩展接口，非厂商联盟规范）|shadowBlur|number|否|阴影的模糊级别，数值越大越模糊，默认值为0。 【在1078版本以前】 设置为0时，实现时会绘制一个0.1模糊边界的shadow。 【1078版本开始】 设置为0时，则不会有shadow，如果需要显示shadow信息，需要手动设置shadow边界大于0。|
|shadow（华为扩展接口，非厂商联盟规范）|shadowColor|string|否|阴影的颜色，默认值为black。|

#### getContext()

描述

返回一个对象，该对象提供了用于在画布上绘图的方法和属性。

参数  

|参数|类型|说明|
|:-|:-----|:-------------------------|
|维度|string|设置为"2d"，表示画布2d显示（目前只支持2d）。|

#### toTempFilePath()（1050+）

描述

把当前画布指定区域的内容导出生成指定大小的图片。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507152506.13188376999455619464027678673909:50001231000000:2800:70A63C9D13BA7701945D62408096761386D5D3C77BE8AA688A6A4E216B36BB1F.png)  
调用此接口前，请先调用getcontext()判断画布上内容是否为空，如果为空，则调用toTempFilePath()将无效。

参数  

|参数|类型|默认值|是否必填|说明|
|:---------|:-------|:-------------|:---|:-----------------------------------------------|
|x|number|0|否|指定的画布区域的左上角横坐标。|
|y|number|0|否|指定的画布区域的左上角纵坐标。|
|width|number|canvas 宽度-x|否|指定的画布区域的宽度。|
|height|number|canvas 高度-y|否|指定的画布区域的高度。|
|destWidth|number|width\*屏幕像素密度|否|输出的图片的宽度。|
|destHeight|number|height\*屏幕像素密度|否|输出的图片的高度。|
|fileType|string|png|否|目标文件的类型。 * jpg：jpg图片 * png：png图片|
|quality|number|1.0|否|图片的质量，目前仅对 jpg 有效。取值范围为 (0, 1\]，不在范围内时当作 1.0 处理。|
|success|function|-|否|接口调用成功的回调函数。|
|fail|function|-|否|接口调用失败的回调函数。|
|complete|function|-|否|接口调用结束的回调函数。|

success回调函数参数：  

|属性|类型|说明|
|:--|:-----|:-------|
|uri|string|生成文件的路径。|

