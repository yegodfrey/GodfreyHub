# AI

> 注意
>
> 华为仅提供AI基础能力，如需应用于医学、政治等敏感领域，请开发者务必声明华为HiAI仅提供基础能力。

AI对软件和硬件要求如下：软件：EMUI 8.1.0.108(C00)+ 硬件：Kirin 970+当前支持机型有：P20、 P20pro、 MateRS 、Honor 10 、 Honor play、 Nova3、Mate10（EMUI8.1）、Mate 10 pro（EMUI8.1）
> 说明
>
> AI能力保证向后兼容性，例如P20 EMUI8.1支持的所有AI能力在后续版本中依然支持。后续Mate系列、P系列、荣耀系列、Nova系列、麦芒系列旗舰机都会支持AI能力。

## 接口声明

```screen
{"name": "system.ai"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import ai from '@system.ai'
```

或

```screen
var ai = require("@system.ai")
```

## 使用限制

|限制条件|说明|
|:---|:--------|
|适用终端|手机、平板、智慧屏|
|适用区域|全球|

### ai.detectAestheticsScore(OBJECT)

**描述**

美学评分：从多维度判断图像质量，为图像打分。不仅能对图像的失焦、抖动等技术因素进行评价，还可以从歪斜、色彩、构图等角度评判主观"美"的感受。
> 说明
>
> 建议输入图片大小不超过2000万像素，超过2000万像素会自动压缩，影响图片质量。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------------------------------------------|
|uri|string|是|源文件的uri，仅支持本地路径。应用内部资源，或者"internal://**/**"格式路径。|
|success|function|否|成功回调。|
|fail|function|否|失败回调，具体请参见"[常见错误码](#section258019564303)"。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:----|:-----|:------------------------|
|score|Number|结果评分，范围0 ~ 100，值越大图片质量越高。|

**示例代码**

```screen
ai.detectAestheticsScore ({
    uri: "internal://temp/xxxx",
    success: function (data) {
        console.log("handling success: " + data.score)
    },
    fail: function (data, code) {
        console.log("handling fail, code: " + code)
    },
    complete: function () {
        console.log("handling complete")
    }
})
```

### ai.detectFace(OBJECT)

**描述**

人脸检测：检测图片中的人脸，返回高精度人脸矩形框坐标。
> 说明
>
> 建议输入图片大小不超过2000万像素，超过2000万像素会自动压缩，影响图片质量。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------------------------------------------|
|uri|string|是|源文件的uri，仅支持本地路径。应用内部资源，或者"internal://**/**"格式路径。|
|success|function|否|成功回调。|
|fail|function|否|失败回调，具体请参见"[常见错误码](#section258019564303)"。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:----------|:-------|:------------------------------------------------------------------------------|
|faces|object[]|人脸对象数组，详细内容请参见"[faces参数说明](#ZH-CN_TOPIC_0000001074264337__table1244411945519)"。|
|imageHeight|number|图片的高度。|
|imageWidth|number|图片的宽度。|

**faces参数说明：**

|参数|类型|说明|
|:----------|:-------|:------------------------------------------------------------------------------------------------|
|id|number|人脸ID，ID > 0。|
|probability|number|人脸置信度，范围-1及0 ~ 1， -1表示算法未提供置信度，值越大置信度越高。|
|faceRect|object|人脸在图片中的位置，详细内容请参见"[faceRect参数说明](#ZH-CN_TOPIC_0000001074264337__table18831175715161)"。|
|landmarks|object[]|特征点列表（左右眼中心、鼻子、左右嘴角），详细内容请参见"[landmarks参数说明](#ZH-CN_TOPIC_0000001074264337__table1057671811811)"。|
|yaw|number|左右旋转角度[-90(左), 90(右)]。|
|pitch|number|俯仰角度[-90(俯), 90(仰)]。|
|roll|number|平面内旋转角[-180(逆时针), 180(顺时针)]。|

**faceRect参数说明：**

|参数|类型|说明|
|:-----|:-----|:-----------|
|left|number|人脸区域离左边界的距离。|
|top|number|人脸区域离上边界的距离。|
|width|number|人脸区域的宽度。|
|height|number|人脸区域的高度。|

**landmarks参数说明：**

|参数|类型|说明|
|:-------|:-----|:--------------------------------------------------------------------------------|
|type|number|特征点类型，详细内容请参见"[type参数说明](#ZH-CN_TOPIC_0000001074264337__table176307514248)"。|
|position|object|特征点位置，详细内容请参见"[position参数说明](#ZH-CN_TOPIC_0000001074264337__table1787814112615)"。|

**type参数说明：**

|特征点类型|特征点类型值|特征点说明|
|:-----------------|:-----|:------|
|LEFT_EYE|0|左眼中心位置。|
|RIGHT_EYE|1|右眼中心位置。|
|NOSE_BASE|2|鼻子位置。|
|LEFT_MOUTH_CORNER|3|左嘴角位置。|
|RIGHT_MOUTH_CORNER|4|右嘴角位置。|

**position参数说明：**

|参数|类型|说明|
|:-|:-----|:------|
|x|number|特征点x坐标。|
|y|number|特征点y坐标。|

**示例代码**

```screen
ai.detectFace({
    uri: "internal://temp/xxxx",
    success: function (data) {
        console.log("detect data="+JSON.stringify(data))
    },
    fail: function (data, code) {
        console.log("handling fail, code: " + code)
    },
    complete: function () {
        console.log("handling complete")
    }
})
```

### ai.faceCompare(OBJECT)

**描述**

人脸比对：通过识别并提取人脸特征，对人像进行高精度比对，给出置信度分数，判断对象是否为同一个人。
> 说明
>
> 建议输入图片大小不超过2000万像素，超过2000万像素会自动压缩，影响图片质量。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------------------------------------------------|
|uri1|string|是|第一张源文件的uri，仅支持本地路径。应用内部资源，或者"internal://**/**"格式路径。|
|uri2|string|是|第二张源文件的uri，仅支持本地路径。应用内部资源，或者"internal://**/**"格式路径。|
|success|function|否|成功回调。|
|fail|function|否|失败回调，具体请参见"[常见错误码](#section258019564303)"。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:---------|:------|:---------------------------|
|samePerson|boolean|是否为同一人。|
|score|number|人脸比对的分数（0% ~ 100%，值越大置信度越高）。|

**示例代码**

```screen
ai.faceCompare({
    uri1: "internal://temp/xx1",
    uri2: "internal://temp/xx2",
    success: function (data) {
        console.log("handling success: " + data.samePerson + data.socre)
    },
    fail: function (data, code) {
        console.log("handling fail, code: " + code)
    },
    complete: function () {
        console.log("handling complete")
    }
})
```

### ai.startRecognize(OBJECT)

**描述**

开始语音识别。
> 说明
>
> 开始语音识别后，引擎将用户说的话转化成文字。只支持中文识别。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:------------------|:-------|:---|:----------------------------------------------------------------------------------------------------------|
|fontTime|number|否|前端静音检测时间，单位毫秒，范围0 ~ 20000，设置参数错误时自动设置为4000。在这段时间内识别有没有传入语音，不传入语音停止检测。|
|backTime|number|否|后端静音检测时间，单位毫秒，范围0 ~ 20000，设置参数错误时自动设置为5000。语音传入时停顿时间，停顿超过这个时间段，检测停止。|
|totalTime|number|否|超时时间，单位毫秒，默认以及最多为20000，设置参数错误时自动设置为默认参数。引擎检测的时间（包含fontTime和backTime）。|
|onBeginningOfSpeech|function|否|用户开始说话回调该函数。|
|onRmsChanged|function|否|返回当前输入语音的能量，详细返回值请参见"[onRmsChanged参数说明](#ZH-CN_TOPIC_0000001074264337__table15566184418917)"。|
|onPartialResult|function|否|识别过程中，每解码一个chunk，回调一次，详细返回值请参见"[onPartialResult返回值说明](#ZH-CN_TOPIC_0000001074264337__table17352193071014)"。|
|onEndOfSpeech|function|否|引擎检测到用户已经说完后回调该函数。|
|onEnd|function|否|识别结束回调。|
|success|function|否|成功回调。|
|fail|function|否|失败回调，具体请参见"[常见错误码](#section258019564303)"。|
|complete|function|否|执行结束后的回调。|

**onRmsChanged参数说明：**

|参数|类型|说明|
|:--|:-----|:-----------|
|rms|number|返回当前输入语音的能量。|

**success以及onPartialResult返回值：**

|参数|类型|说明|
|:-----|:-------|:--------------------------------------------------------------------------------|
|result|object[]|语音检测结果数组，详细内容请参见"[result参数说明](#ZH-CN_TOPIC_0000001074264337__table355161718124)"。|

**result参数说明：**

|参数|类型|说明|
|:---------|:-----|:-------------------------|
|confidence|number|可信度，取值为0 ~ 100，目前可信度统一返回0。|
|word|string|识别出的文字。|

**示例代码**

```screen
ai.startRecognize({
    fontTime: 3000,
    backTime: 4000,
    totalTime: 20000,
    onBeginningOfSpeech: function () {
        console.log("begin speech")
    },
    onRmsChanged: function (res ) {
        console.log("rms is" + res.rms)
    },
    onEndOfSpeech: function () {
        console.log("end of speech")
    },
    onPartialResult: function (res) {
        console.log("PartialResult is: " + res.result.word)
    },
    onEnd: function () {
        console.log("voice recognization end")
    },
    success: function (data) {
        console.log("handling success: " + data.result.word)
    },
    fail: function (data, code) {
        console.log("handling fail, code: " + code)
    }
})
```

### ai.stopRecognize(OBJECT)

**描述**

停止语音识别。
> 说明
>
> 停止语音识别是指引擎停止对用户声音的采集，而不是销毁语音识别流程，停止语音识别之后引擎会继续执行startRecognize的onEndOfSpeech，success，onEnd等回调。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
ai.stopRecognize({
    success: function () {
        console.log("handling success")
    },
    fail: function (data, code) {
        console.log("handling fail, code: " + code)
    },
    complete: function (msg) {
        console.log("handling complete")
    }
})
```
