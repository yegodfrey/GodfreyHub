# 震动

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.vibrator"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import vibrator from '@system.vibrator'
```

或

```screen
var vibrator = require("@system.vibrator")
```

## 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

## 接口定义

|接口|描述|
|:-----------------------------------------------|:---------|
|[vibrator.vibrate(OBJECT)](#section196986508377)|触发震动，持续1秒。|

### vibrator.vibrate(OBJECT)

**描述**

触发震动，持续1秒。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:----------|:-----|:---|:-------------------------------------------------------------------------------|
|mode(1030+)|string|否|振动模式，默认为long。 * long：表示长振动。 * short：表示短振动。 实现时，long的时长定义为1000ms，short的时长定义为35ms。|

**示例代码**

```screen
vibrator.vibrate({ mode: "short" });
```
