# 实时语音识别（1077+）

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813173003.45685030094977987155133489930161:50001231000000:2800:3F9FF2DA078231B03FBCA3BCE527AD6E9D5CF12C66E8AD947A4919B7C9E2DFC8.png)  
本文档仅介绍接口的定义，接口详细的使用顺序和场景，请参见"[实时语音识别](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-access-ml-asr-0000001137038989)"。  

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{"name": "service.ml.asr"}
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import mlasr from '@service.ml.asr'
```

或

```
var mlasr = require("@service.ml.asr")
```

#### 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

#### mlasr.start(OBJECT)（1077+）

描述

启动语音识别，在回调中获取识别结果。

在没有识别到语音输入的情况下会自动停止语音识别。

参数  

|参数|类型|是否必填|说明|
|:---------------------------|:-------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|string|是|[获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-get-agconnectfile-0000001117853750)中的app_id。|
|apiKey|string|是|[获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-get-agconnectfile-0000001117853750)中的api_key。 请妥善保管apiKey、设置apiKey，详细请参见"[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides-V5/sdk-data-security-0000001050040129-V5#section2688102310166)"。|
|language|string|否|设置识别语言，若不设置，则默认识别中文。支持设置选项包括： * zh-CN：中文 * en-US：英文 * fr-FR：法语 * es-ES：西班牙语 * de-DE：德语|
|feature|number|否|设置识别文本返回模式，若不设置，默认为边识别边出字。支持设置选项包括： * 11：通过onRecognizingResults接口，识别的同时返回文字。 * 12：识别完成后通过onResults接口返回文字。|
|callback(eventName, ...data)|function|是|回调方法，会多次回调，返回1个或多个参数，第一个参数为事件名称，其它参数视业务而定。|
|fail()|function|否|回调方法，识别发生错误后调用。|

callback返回值  

|参数|类型|说明|
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|eventName|string|回调事件名称。 * onStartListening：录音器开始接收声音。 * onStartingOfSpeech：用户开始讲话，即语音识别器检测到用户开始讲话。 * onVoiceDataReceived：实时返回给用户原始的PCM音频流和音频能量。 * onRecognizingResults：实时接收到持续语音识别的文本。 * onResults：最终语音识别的文本。 * onState：通知应用状态发生改变。|
|...data|0或多个参数的集合|0或多个参数的集合，视eventName而定。 * 当eventName为onStartListening，无参数返回。 * 当eventName为onStartingOfSpeech，无参数返回。 * 当eventName为onVoiceDataReceived，返回参数参见"[VoiceDataReceived说明](#ZH-CN_TOPIC_0000001074914680__table15322121231816)"。 * 当eventName为onRecognizingResults，返回参数参见"[RecognizingResults说明](#ZH-CN_TOPIC_0000001074914680__table9533305199)"。 * 当eventName为onResults，返回参数参见"[Result说明](#ZH-CN_TOPIC_0000001074914680__table5645834101916)"。 * 当eventName为onState，返回参数参见"[Status说明](#ZH-CN_TOPIC_0000001074914680__table224414718202)"。|

VoiceDataReceived说明  

|数据|类型|描述|
|:--------|:-------|:-----------|
|data\[0\]|string|音频流。|
|data\[1\]|string|音频能量。|
|data\[2\]|object类型|扩展参数，暂无实际作用。|

RecognizingResults说明  

|数据|类型|描述|
|:--------|:-----|:---------|
|data\[0\]|string|持续语音识别的文本。|

Result说明  

|数据|类型|描述|
|:--------|:-----|:---------|
|data\[0\]|string|最终语音识别的文本。|

Status说明  

|数据|类型|描述|
|:--------|:-------|:-----------|
|data\[0\]|string|状态值。|
|data\[1\]|object类型|扩展参数，暂无实际作用。|

fail返回错误码  

|错误码|说明|处理建议|
|:----|:------|:------------|
|11202|网络错误|-|
|11203|服务不可用|根据返回错误信息修改参数。|
|11204|无法识别的语音|-|

示例代码

```
mlasr.start({ //启动语音识别。
    appId: ‘123456’, //String 参数，必填。
    apiKey: ‘’, //String 参数，必填，鉴权，设置apiKey。
    certFingerprint: ‘test’, //String 参数，非必填，签名认证信息。
    language: ‘zh-CN’, //String 参数，非必填，设置识别语言，可不传，默认识别中文：【zh-CN】: 中文；【en-US】: 英文；【fr-FR】: 法语；【es-ES】西班牙语；【de-DE】:德语。
    feature: 11, //Number 参数，非必填，设置识别文本返回模式为边识别边出字，可不传，默认为边识别边出字：【11】：通过onRecognizingResults事件回调，识别同时返回文字；【12】：通过onResults事件回调，识别完成后返回文字；
    callback: (eventName, ...data) => { //回调方法，返回1个或多个参数，第一个参数为事件名称(eventName)，其它参数视业务而定。
        console.log(eventName, ...data);
        switch (eventName) {
            case 'onStartListening': //录音器开始接收声音。
                break;
            case 'onStartingOfSpeech'://用户开始讲话，即语音识别器检测到用户开始讲话。
                break;
            case 'onVoiceDataReceived'://返回给用户原始的PCM音频流和音频能量。
                let voice = data[0], energy = data[1];
                break;
            case 'onRecognizingResults'://从MLAsrRecognizer接收到持续语音识别的文本。
                let partialResults = data[0];
                break;
            case 'onResults'://语音识别的文本数据。
                let results = data[0];
                break;
            case 'onState'://通知应用状态发生改变。
                let state = data[0];
                break;
        }
    },
    fail: (errMsg, errCode) => { //失败回调，识别发生错误后调用该接口。
        console.log("error:", errMsg);
    },
});
```

#### mlasr.stop()（1077+）

描述

停止语音识别。

示例代码

```
mlasr.stop(); //停止识别
```
