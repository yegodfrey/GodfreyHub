# manifest文件

manifest.json文件中包含了应用描述、接口声明、页面路由信息。  

|属性|类型|默认值|是否必填|描述|
|:-----------------------|:------|:---|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|package|string|-|是|应用包名，确认与原生应用的包名不一致，推荐采用com.company.module的格式，如：com.example.demo。 由数字、字母、"."、下划线组成，必须以字母开头，以数字、字母或者下划线结尾，同时必须包含"."，长度不能超过255字节。|
|name|string|-|是|应用名称，与应用商店保存的名称一致，用于在桌面图标、弹窗等处显示应用名称。 支持设置为多语言字符串，但不支持以下场景： 1. 固定字符串与变量字符串的组合 例如不支持设置为："name":"快应用示例${message.appname}" 2. 多变量字符串的拼接 例如不支持设置为："name":"${message.appname1}${message.appname2}" 3. 除"."之外的子节点访问 例如不支持设置为："name":"${message\['appname'\]}"，应该设置为"name":"${message.appname}"|
|icon|string|-|是|用于在应用市场或者桌面显示的应用图标，必须与提交上架审核的应用图标信息一致。|
|versionName|string|-|否|应用版本名称，如："1.0"。|
|versionCode|integer|-|是|应用版本号，从1自增，务必每次重新上传包时versionCode+1，否则将影响上架版本的更新。例如原版本为11，更新版本的versionCode需要为12。|
|minPlatformVersion|integer|1000|是|支持的最小平台版本号，兼容性检查，避免上线后在低版本平台运行并导致不兼容。 说明： 当用户手机上的快应用引擎版本低于该值，打开快应用时将弹框提示用户更新到最新版本。用户可以选择不更新，退出快应用。|
|features|array|-|否|接口列表，绝大部分接口都需要在这里声明，否则不能调用，详见每个接口的文档说明。示例如下： ``` [ { "name": "system.app" }, { "name": "system.network" } ] ```|
|permissionDesc(1072+)|array|-|否|获取权限的理由描述，即当调用API需要用户授权时，在授权框显示的文字信息。理由描述需尽量清晰、合理。 详细定义格式参见"[permissionDesc格式说明](#ZH-CN_TOPIC_0000001073698621__li137319191437)"。|
|config|object|-|是|系统配置信息，详细内容参见"[config](#section169381859312)"。|
|router|object|-|是|路由信息，详细内容参见"[router](#section710512317442)"。|
|display|object|-|否|UI显示相关配置，详细内容参见"[display](#section117944131414)"。|
|subpackages|object|-|否|定义并启用分包加载，详细内容参见"[subpackages](#section1821818471993)"。|
|trustedSslDomains(1060+)|array|-|否|可信的 https 站点列表，如："www.huawei.com"。 * 在1060版本，当 web 组件访问这些站点出现证书过期或无效时，会提供继续访问的选项，供用户选择是否继续访问。 * 从1065版本开始，始终提供继续访问的选项，供用户选择是否继续访问。|
|exitDesc(1107+)|string|-|否|退出页面提示信息。如果该页面是唯一页面，在该页面上第一次按下后退按钮时，会显示一条toast消息，该消息是exitDesc的值。|

permissionDesc可以配置name和desc两个属性信息。name目前支持的权限配置包括：WRITE_CALENDAR、ACCESS_FINE_LOCATION、CAMERA、RECORD_AUDIO、WRITE_EXTERNAL_STORAGE(1075+)、STORAGE_READ(1078+)、READ_PHONE_STATE(1078+)、NOTIFYCATION(1078+)、SILENT_NOTIFYCATION(1078+)、READ_CONTACT(1078+)、CAR_INFO。desc支持配置多语言字符串，但不支持以下配置：

* 固定字符串和变量字符串的混合，例如不支持配置为："desc": "The reason is ${message.permissionDesc}"
* 多变量字符串拼接，例如不支持配置为："desc": "${message.permissionDesc}${message.permissionDesc1}"
* 除 . 之外的子节点访问方式，例如不支持配置为："desc": "获取权限理由如下：${message\['permissionDesc'\]}"

permissionDesc配置示例如下：

```
"permissionDesc":[
    {
        "name": "ACCESS_FINE_LOCATION",
        "desc": "此示例用来演示获取地理位置的能力，需要您授予获取地理位置的权限。"
    },
    {
        "name": "RECORD_AUDIO",
        "desc": "${message.permissionDesc}"
    }
]
```

#### config

用于定义系统配置和全局数据。  

|属性|类型|默认值|描述|
|:------------------------|:-------------|:----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|logLevel|string|log|打印日志等级，分为off（表示不写）、error、warn、info、log、debug。|
|designWidth|integer/string|750|页面设计基准宽度，根据实际设备宽度来缩放元素大小。当为String类型时值只能是"device-width"("designWidth":"device-width")，表示视觉viewport的宽度。|
|data|object|-|全局数据对象，属性名不能以$或_开头，在页面中可通过this进行访问；如果全局数据属性与页面中data属性重名，则页面初始化时，全局数据会覆盖页面中对应的属性值。|
|network(1060+)|object|-|网络超时时间配置选项，详细配置请参见"[config.network说明](#ZH-CN_TOPIC_0000001073698621__table68054224439)"。该配置仅适用如下接口或方法：system.fetch，system.request.upload()，system.websocketfactory。|
|background(1070+)|object|-|在features子字段中配置需要在后台运行的接口。可以配置的接口包括： * system.audio * system.geolocation * system.record * system.request 详细使用方法参见"[后台运行](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-runinback-0000001073796478)"。|
|recreateOnFolding(1070+)|boolean|true|折叠屏折叠、展开过程中是否重新加载页面。 * true：重新加载页面。效果和初次进入当前页面相同，会回调生命周期函数onInit、onReady、onShow，通过页面调整传递的参数依然可以获取。 * false：不重新加载页面。|
|aboutPageConfig(1078+)|array|-|在统一菜单中"关于"页面的条目，最多可以展示20条。详细内容参见"[aboutPageConfig说明](#ZH-CN_TOPIC_0000001073698621__p8112524155411)"。|
|grayMode(1100+)|object|-|页面饱和度为零的显示模式（灰色模式），用以响应特殊事件，详细配置请参见"[config.grayMode说明](#ZH-CN_TOPIC_0000001073698621__table1717644231911)"，该配置项会被[configuration.setGrayMode](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-configuration-0000001074911860#section44691942638)的相关配置覆盖。|
|permissionAdapted (1107+)|boolean|false|每48小时可以提出一次权限请求。该属性表示在48小时内请求许可时是否显示toast。 * false: 显示toast消息。 * true: 不显示toast消息。|
|exit(1110+)|object|-|快应用引擎支持退出应用时返回快应用首页。对于此功能，添加了退出配置，即在exit属性中定义所需的行为。它包含两个不同的关键值，如下： * desc：退出应用时显示的字符内容。 * jumpEntry：表明直接退出应用还是返回快应用首页。|
|disableDynamicCode（1104+）|boolean|false|禁止动态代码执行|

#### router

用于定义页面的组成和相关配置信息，如果页面没有配置路由信息，则在编译打包时跳过。  

|属性|类型|默认值|描述|
|:---------------|:-----|:--|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|entry|string|-|首页名称。|
|errorPage(1060+)|string|-|错误页面。 1. 当跳转到一个不存在的页面时，会跳转到错误页面，错误页面与其他页面同样需要在router里去注册，此选项为可选配置。 2. 如果没有设置错误页面或者错误页面没有在router中注册，则跳转到默认错误页面，默认错误页面的launchMode为singleTask。在使用默认错误页面的时候，如果在页面栈里仅有一个页面而且这个页面是错误页面的时候，点击返回键会回到快应用首页。返回首页的逻辑参见"[errorpage.ux示例代码](#section2038241151110)"。|
|pages|object|-|页面配置列表，key值为页面名称（对应页面目录名，例如Hello对应'Hello'目录），value为页面详细配置page，详细内容参见"[router.page](#ZH-CN_TOPIC_0000001073698621__table3882305542)"。|

#### router.pages

用于定义单个页面路由信息。  

|属性|类型|默认值|是否必填|描述|
|:----------------|:-----|:-------|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|component|string|-|是|页面对应的组件名，与ux文件名保持一致，例如hello对应hello.ux。|
|path|string|/|否|页面路径，例如"/user"，不填则默认为/\<页面名称\>。path必须唯一，不能和其他page的path相同。下面page的path因为缺失，会被设置为"/Index"："Index": {"component": "index"}。|
|filter|object|-|否|声明页面可以处理某种请求。|
|launchMode(1050+)|string|standard|否|声明页面的启动模式，支持"singleTask"，"standard"两种页面启动模式。 * 标识为"singleTask"模式时每次打开目标页面都会打开已有的目标页面并回调onRefresh生命周期函数，清除该页面上打开的其他页面，没有打开过此页面时会创建新的目标页面实例。 * 标识为"standard"模式时会每次打开新的目标页面（多次打开目标页面地址时会存在多个相同页面） 首页仅支持"singleTask"模式。|

#### router.page.filter

声明页面可以处理某种请求，页面可以从$page获取打开页面的参数，参见"[script脚本](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-script-0000001073643163)"。filter的结构如下：

```
"filter": {
  "<action>": {
    "uri": "<pattern>"
  }
}
```

|属性|类型|默认值|是否必填|描述|
|:-----|:------|:--|:---|:------------------------------------------------------|
|action|string|-|是|请求的动作，目前仅支持view这一种。|
|uri|pattern|/|否|请求的数据的匹配规则。必须是正则表达式。如https?://.\*可以匹配所有http和https类型的网址。|

处理所有 http 和 https 请求的 filter 定义如下：

```
"filter": {
  "view": {
    "uri": "https?://.*"
  }
}
```

```
// 页面中需要声明参数变量名称，注意参数名称需要和shareParams中key-value的key值名称对应，对于usePageParams或者shareCurrentPage为true情况，也要对应页面参数声明对应的key值接收参数
public: {
    key: null
},

// 如果快应用当前页面和打开的分享页面不同，在打开快应用，跳转到分享页时，分享参数可以在onInit中接收到
onInit() {

}

onRefresh(data){

}
```

#### menuBar快速适配

使用menuBar，您无需再重复实现分享、添加到桌面、关联页等功能，可减少工作量。

您可以按照以下步骤，实现快应用项目对menuBar的适配：

* 在manifest.json的display属性下，添加menuBarData配置项。
  * 若您手动添加menuBarData配置项，则全部快应用页面应用menuBarData的配置。
  * 若您在display的pages子项中添加menuBarData配置项，则对应的页面应用menuBarData的配置。

  menuBar配置示例如下：  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240807112814.31270823304408777332971380504333:50001231000000:2800:CC3796F9C5524BDE4868EDE2AFD9BDE0EA3CFC3B24A455A3EDD82DE46485F7A8.png?needInitFileName=true?needInitFileName=true)  
  实际代码中JSON文件不能包含注释行，此处注释仅用于说明。

  ```
  {
    "display": {
      "menuBarData": {
        // 全局配置
        "menuBar":true,
        "menuBarStyle":"dark",
        "shareTitle":"分享标题",
        "shareDescription":"分享描述",
        "shareIcon":"分享url"
      },
      "pages": {
        "Hello": {
          // 页面配置，默认使用页面menuBarData配置，页面无配置时使用全局menuBarData配置
          "menuBarData": {
            "menuBar":true,
            "menuBarStyle":"dark",
            "shareTitle":"子页面分享标题",
            "shareDescription":"分享页面描述",
            "shareIcon":"页面分享url",
            "shareCurrentPage":true,
            "shareUrl":"https://developer.huawei.com",
            "shareParams":"{key:1,id:2})"
           }
        }
      }
  }
  ```

* 您还可以在页面代码中动态设置menuBarData分享参数，用法参见[setMenubarData描述](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-script-0000001073643163#ZH-CN_TOPIC_0000001073643163__p2795620154320)。  

#### subpackages

用于定义分包的相关配置。分包的详细使用方法请参见"[分包加载](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-subpackage-guide-0000001126790461)"。  

|属性|类型|描述|
|:-------|:-----|:----------------------------------------------------------------------------------------------------|
|name|string|分包的名称，用于区分不同分包。只能是字母数字和下划线，不允许包含其他符号，"base"作为基础包的保留名称（无需为基础包定义分包配置）。|
|resource|string|分包资源根目录，相对于源码目录"src"的相对路径。只能是字母数字以及"_"、"-"、"/"组成，第一个字符不允许为"-"和"/"，不允许包含其他符号。编译时会把该目录下的所有资源都打包到这个分包中去。|
