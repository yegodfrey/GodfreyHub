# 账号

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830103612.60998951675277916343721187028390:50001231000000:2800:6CE0A68DFFA71B5ABD7561CD30D062267FC14316791F919DD9132902CC0D8193.png)  
使用此接口前，请先完成[申请账号MCP权限](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-account-0000002414052162#section057783114910)。

本文档仅介绍接口的定义，接口详细的使用顺序和场景，请参见"[接入账号服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-applet-access-account-kit-0000001126445971)"。  

#### 接口描述

华为账号为开发者提供简单、安全的登录授权功能，应用接入华为账号后，用户可以使用华为账号快速登录应用。  

#### 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

#### 接口定义

#### ft.hwGetProvider ()

描述

获取服务提供商，返回提供商的英文品牌名称。

参数

无

返回值

服务提供商的英文品牌的字符串，例如：huawei。如果返回空字符串，表示不支持此服务，此时请勿调用其他方法，否则将抛异常。

示例代码

```
ft.hwGetProvider()
```

#### ft.hwAuthorize(Object)

描述

进行 OAuth 授权。

Object参数  

|参数|类型|是否必填|说明|
|:----------|:-------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appid|string|是|开发者在华为开发者联盟上创建应用后获取的唯一标识，查询方式请参见"创建快应用"中的"[获取APP ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824#section975713401464)"章节。|
|type|string|是|token（简化模式）即将废弃，仅用于存量应用，新应用需设置为code（授权码模式）。|
|redirectUri|uri|否|重定向URI。|
|scope|string|是|申请的权限范围，支持配置以下scope： 获取用户基本信息，必须配置为"scope.baseProfile"|
|state|string|是|可以指定任意值，认证服务器会原封不动地返回这个值。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调（调用成功、失败都会执行）。|

success返回值  

|参数|类型|说明|
|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|state|string|请求时同字段指定的任意值。|
|code|string|授权码模式下可用，返回的授权码。更详细的使用指导，参见"接入账号服务"中的"[授权码模式](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-applet-access-account-kit-0000001126445971#section1675510344144)"章节。|
|accessToken|string|简化模式下可用，返回的访问令牌。通过此令牌开发者可以调用hwGetProfile接口获取OpenID和用户基本信息。|
|tokenType|string|简化模式下可用，访问令牌类型。|
|expiresIn|number|简化模式下可用，访问令牌过期时间，单位为秒，如果通过其他方式设置，则此处可能为空。|
|scope|string|简化模式下可用，实际权限范围，如果与申请一致，则此处可能为空。|
|openid|string|简化模式下可用，用户的openid，可能为空。|
|unionid|string|简化模式下可用，用户在开放平台上的唯一标示符，本字段需要在厂商的开放平台上额外申请后，才会返回。 （在华为开发者联盟申请账号服务时，勾选"启用UnionId"）。|
|nickname|string|简化模式下可用，用户的昵称，可能为空。|
|avatar|object|简化模式下可用，用户的头像图片地址，可能为空。按照分辨率组织，当只有一个分辨率时，可以使用default对应的图片地址。|
|email|string|简化模式下可用，用户绑定的Email地址。如果未绑定Email，此处可能为空。|

fail返回值  

|参数|类型|说明|
|:------|:-----|:-----|
|errCode|number|返回状态码。|
|errMsg|string|消息内容。|

错误码  

|错误码|说明|
|:--|:-------------|
|201|用户拒绝，获取账号权限失败。|

示例代码

简化模式：

```
ft.hwAuthorize({ 
    appid: "101373095", 
    type: "token", 
    state: "feedbeef", 
    scope: "scope.baseProfile", 
    success: function (data) { 
        console.log("signInByBaseScope Authorize base profile success."); 
        var accessToken = data.accessToken; 
        console.log("signInByBaseScope Authorize base profile success data=" + JSON.stringify(data)); 
    }, 
   fail: function (data, code) { 
        console.log("signInByBaseScope Authorize base profile fail, code=" + code); 
        prompt.showToast({ message: data + "fail code: " + code }) 
    } 
})
```

授权码模式：

```
ft.hwAuthorize({ 
    appid:"101373095", 
    type:"code", 
    redirectUri:"https://www.example.com/", 
    scope: "scope.baseProfile", 
    state: "feedbeef", 
    success:function(res){ 
        console.log("handling success: " + res.code); 
    }, 
    fail: function(res) { 
        console.log("handling fail, code=" + res.errCode); 
    }, 
    complete: function() { 
        console.log("handling complete") 
    } 
})
```

#### ft.hwGetProfile(Object)

描述

获得用户基本信息。

Object参数  

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appid|string|否|开发者在华为开发者联盟上创建应用后获取的唯一标识，查询方式请参见"创建快应用"中的"[获取APP ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824#section975713401464)"章节。|
|token|string|是|访问令牌。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调（调用成功、失败都会执行）。|

unionid机制说明：

如果开发者拥有多个移动应用，可通过unionid来区分用户的唯一性，因为只要是同一个开放平台账号下的移动应用，用户的unionid是唯一的。换句话说，同一用户，对同一个开放平台下的不同应用，unionid是相同的。

success返回值：  

|参数|类型|说明|
|:-------|:-----|:-------------------------------------------------------------|
|openid|string|用户的openid，可能为空。|
|unionid|string|用户在开放平台上的唯一标示符，本字段在满足一定条件下才会返回（在华为开发者联盟申请账号服务时，勾选"启用UnionId"）。|
|nickname|string|用户的昵称，可能为空。|
|avatar|object|用户的头像图片地址，可能为空。按照分辨率组织，当只有一个分辨率时，可以使用default对应的图片地址。|

fail返回值  

|参数|类型|说明|
|:------|:-----|:-----|
|errCode|number|返回状态码。|
|errMsg|string|消息内容。|

错误码  

|错误码|说明|
|:--|:---------|
|102|session无效。|

示例代码

```
ft.hwGetProfile({ 
    appid:"101373095", 
    token:"this.accessToken", //使用实际的accessToken值 
    success:function(res){ 
        console.log("handling success: " + res.nickname); 
    }, 
    fail: function(res) { 
        console.log("handling fail, code=" + res.errCode); 
    }, 
    complete: function() { 
        console.log("handling complete") 
    } 
})
```

#### ft.hwIsLogin(Object)

|参数|类型|是否必填|说明|
|:------|:-------|:---|:----|

|参数|类型|说明|
|:------|:------|:--------------------------|

fail返回值  

|参数|类型|说明|
|:------|:-----|:-----|
|errCode|number|返回状态码。|
|errMsg|string|消息内容。|

错误码

```
    complete: function() {  
        console.log("handling complete")  
    }  
})
```

#### ft.hwCheckUserSession(Object)

描述

该接口用于校验应用是否有通过 [ft.hwAuthorize](#section68221371135) 接口完成过登录授权，以及应用登录后，账号是否有退出登录的场景。

在如下情况下，调用此接口将校验无效：

● 应用未调用 [ft.hwAuthorize](#section68221371135) 进行授权登录。

● 应用登录后，用户退出过华为账号，包括退出登录，或退出登录后重新登录。

如果希望您的应用和华为账号保持同进同出的状态，在code模式下，建议先调用 [ft.hwCheckUserSession](#section204734715218)，如果校验无效，再调用 [ft.hwAuthorize](#section68221371135) 进行授权。

Object参数  

|参数|类型|是否必填|说明|
|:------|:-------|:---|:----|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|

fail返回值  

|参数|类型|说明|
|:------|:-----|:-----|
|errCode|number|返回状态码。|
|errMsg|string|消息内容。|

示例代码

```
ft.hwCheckUserSession({  
    success:function(res){  
        console.log("handling success: " + JSON.stringify(res));  
    },  
    fail: function(res) {  
        console.log("handling fail, code=" + res.errCode);  
    },  
    complete: function() {  
        console.log("handling complete")  
    }  
})
```
