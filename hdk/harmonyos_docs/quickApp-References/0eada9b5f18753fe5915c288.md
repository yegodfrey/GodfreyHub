# 系统音量

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.volume"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import volume from '@system.volume'
```

或

```screen
var volume = require("@system.volume")
```

## 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

## 接口定义

|接口|描述|
|:----------------------------------------------------|:---------|
|[volume.getMediaValue(OBJECT)](#section1582551285319)|获取当前多媒体音量。|
|[volume.setMediaValue(OBJECT)](#section1720244019334)|设置当前多媒体音量。|

### volume.getMediaValue(OBJECT)

**描述**

获取当前多媒体音量。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:----|:-----|:--------------------|
|value|number|系统媒体当前音量，0.0 ~ 1.0之间。|

### volume.setMediaValue(OBJECT)

**描述**

设置当前多媒体音量。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-----------|:-------|:---|:-----------------|
|value(1077+)|number|是|设置的音量，0.0 ~ 1.0之间。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**fail返回错误码：**

|错误码|说明|
|:--|:-----|
|200|一般性错误。|
|202|参数非法。|

```screen
<template>
  <!-- Only one root node is allowed in template. -->

  </div>
</template>

<script>
  import volume from '@system.volume';
  import prompt from '@system.prompt';
  module.exports = {
    public: {
      volumeNum: 0,
      volumeInted:false,
      getvolumeNum:''
    },
    onInit: function () {
      this.$page.setTitleBar({ text: 'system volume' });

      let that = this;
      volume.getMediaValue({
        success: function (ret) {
          that.volumeNum = ret.value * 100;
          setTimeout(() => {
            that.volumeInted = true;
          },500);
        }
      })
    },
    updateVolume({ progress }) {
      if(!this.volumeInted)
      {
        return;
      }
      this.volumeNum = progress;
      volume.setMediaValue({
        volume: progress / 100,
        success: function (data) {
        },
        fail: function (data, code) {
          prompt.showToast({
            message: 'fail',
            duration: 2000,
            gravity: 'bottom'
          })
        }
      })
    },
    getMediaVolume:function() {
      let that = this;
      volume.getMediaValue({
        success: function (ret) {
          that.getvolumeNum = ret.value * 100;
          setTimeout(() => {
            that.volumeInted = true;
          },500);
        }
      })
    }
  }
</script>
```
