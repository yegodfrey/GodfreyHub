# 电量信息

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{"name": "system.battery"}
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import battery from '@system.battery'battery.getStatus(OBJECT)
```

或

```
var battery = require("@system.battery")
```

#### 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

#### 接口定义

|接口|描述|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------|
|[battery.getStatus(OBJECT)](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-battery-0000001074911743#section1582551285319)|获取当前设备的电量信息。|

#### battery.getStatus(OBJECT)

描述

获取当前设备的电量信息。

OBJECT参数  

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

success返回值：  

|参数名|类型|说明|
|:-------|:------|:------------------|
|charging|boolean|是否正在充电。|
|level|float|当前电量，0.0 \~ 1.0 之间。|

示例代码

```
battery.getStatus({
    success:function(ret){console.log("handling success");}
})
```

<script>
  import battery from '@system.battery';
  import prompt from '@system.prompt';
  module.exports = {
    public: {
      batteryNum: 0,
      isCharging: false,
      batteryInfoGeted: false,
    },
    onInit: function () {
      this.$page.setTitleBar({ text: 'battery level'});
    },
    getBatteryInfo() {
      let that = this;
      battery.getStatus({
        success: function (ret) {
          that.batteryInfoGeted = true;
          that.batteryNum = ret.level * 100;
          that.isCharging = ret.charging;
        },
        fail: function () {
          prompt.showToast({
            message: 'fail',
            duration: 2000,
            gravity: 'bottom'
          })
        }
      })
    }
  }
</script>
