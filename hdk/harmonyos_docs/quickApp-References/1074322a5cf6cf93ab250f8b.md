# 屏幕

> 说明
>
> 从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。

## 接口定义

|接口|描述|
|:-----------------------------------------------------------|:----------|
|[qg.getScreenBrightness(Object object)](#section43346016342)|获取屏幕亮度。|
|[qg.setKeepScreenOn(Object object)](#section11162101720363)|设置是否保持常亮状态。|
|[qg.setScreenBrightness(Object object)](#section86131863719)|设置屏幕亮度。|

### qg.getScreenBrightness(Object object)

* 描述 获取屏幕亮度。


* 参数object

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:------------------------------------------------------------------------------|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000001084034254__li9589195212175)。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数

    |参数|类型|说明|
    |:----|:-----|:-------------------|
    |value|number|屏幕亮度值，范围0~1，0最暗，1最亮。|

* 示例代码

  ```screen
  qg.getScreenBrightness({
          success : function (res) {
                  console.log("getScreenBrightness success value = " + res.value);
          },
          fail:function(){
                  console.log("getScreenBrightness fail");
          },
          complete:function() {
                  console.log("getScreenBrightness complete");
          }
  });
  ```

### qg.setKeepScreenOn(Object object)

* 描述 设置是否保持常亮状态。

* 参数object

  |参数|类型|必填(M)/选填(O)|说明|
  |:-----------|:-------|:----------|:--------------------|
  |keepScreenOn|boolean|M|是否保持屏幕常亮。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|


* 示例代码

  ```screen
  qg.setKeepScreenOn({
          keepScreenOn : true ,
          success : function () {
                  console.log("setKeepScreenOn success" );
          },
          fail:function(){
                  console.log("setKeepScreenOn fail");
          },
          complete:function() {
                  console.log("setKeepScreenOn complete");
          }
  });
  ```

### qg.setScreenBrightness(Object object)

* 描述 设置屏幕亮度。

* 参数object

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |value|number|M|屏幕亮度值，范围0~1，0最暗，1最亮。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 示例代码

  ```screen
  qg.setScreenBrightness({
           value: 0.5,
           success: function () {
                  console.log("setScreenBrightness success");
           },
           fail: function () {
                  console.log("setScreenBrightness fail");
           },
           complete: function () {
                  console.log("setScreenBrightness complete");
           }
  });
  ```
