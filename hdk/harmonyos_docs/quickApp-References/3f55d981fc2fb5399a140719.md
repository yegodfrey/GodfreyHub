# 蓝牙

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.bluetooth"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import bluetooth from '@system.bluetooth'
```

或

```screen
var bluetooth = require("@system.bluetooth")
```

## 使用限制

|限制条件|说明|
|:---|:-------|
|适用终端|手机、平板、车机|
|适用区域|全球|

### bluetooth.openAdapter(OBJECT)

**描述**

初始化蓝牙模块。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------------|:-------|:---|:----------------------------------------------------|
|operateAdapter|boolean|否|是否打开系统蓝牙开关。 设置为true，在系统蓝牙开关关闭的情况下会弹框提示是否打开。 默认值false。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
bluetooth.openAdapter({
    operateAdapter: true,
    success: function () {
        console.log("success");
    },
    fail: function () {
        console.log("fail");
    },
    complete: function () {
        console.log("complete");
    }
})
```

### bluetooth.startDevicesDiscovery(OBJECT)

**描述**

开始搜寻附近的蓝牙外围设备。此操作比较耗费系统资源，请在搜索并连接到设备后调用 bluetooth.stopDevicesDiscovery 方法停止搜索。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-----------------|:-------------|:---|:--------------------------------------------------------------------------------------------------------|
|services|array.<string>|否|要搜索的主service的uuid列表。某些蓝牙设备会广播自己的主service的uuid。如果设置此参数，则只搜索广播包有对应uuid的主服务的蓝牙设备。建议主要通过该参数过滤掉周边不需要处理的其他蓝牙设备。|
|allowDuplicatesKey|boolean|否|默认值为false。是否允许重复上报同一设备。如果允许重复上报，则 bluetooth.ondevicefound 方法会多次上报同一设备，但是RSSI值会有不同。|
|interval|number|否|默认值为0。上报设备的间隔。0表示找到新设备立即上报，其他数值根据传入的间隔上报。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
bluetooth.startDevicesDiscovery({
    services: ['FEE7'],
    success: function () {
        console.log("success")
    }
})
```

### bluetooth.getDevices(OBJECT)

**描述**

获取在蓝牙模块生效期间所有已发现的蓝牙设备。包括已经和本机处于连接状态的设备。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:------|:-------------|:------------------------------------------------------------------------------------------|
|devices|array.<string>|uuid对应的的已连接设备列表，devices结构请参见"[devices说明](#ZH-CN_TOPIC_0000001074629693__table49750156597)"。|

**devices说明：**

|参数名|类型|说明|
|:-------------------|:-------------|:-----------------------------------------------------------------------|
|name|string|蓝牙设备名称，某些设备可能没有。|
|deviceId|string|用于区分设备的id。|
|RSSI|number|当前蓝牙设备的信号强度。|
|advertisData|arraybuffer|当前蓝牙设备的广播数据段中的 ManufacturerData 数据段。|
|advertisServiceUUIDs|array.<string>|当前蓝牙设备的广播数据段中的 ServiceUUIDs 数据段。|
|localName|string|当前蓝牙设备的广播数据段中的 LocalName 数据段。|
|serviceData|string|当前蓝牙设备的广播数据段中的 ServiceData数据段，返回结构为{"service uuid string": ArrayBuffer}。|

**示例代码**

```screen
bluetooth.getDevices({
    success:function(res){
        console.log(res)
        if (res.devices[0]) {
            console.log(res.devices[0].advertisData)
        }
    },
    fail: function() {
        console.log("fail");
    },
    complete: function (){
        console.log("complete");
    }
})
```

### bluetooth.notifyBLECharacteristicValueChange(OBJECT)

**描述**

启用低功耗蓝牙设备特征值变化时的 notify 功能，订阅特征值。
> 注意
>
> 必须设备的特征值支持 notify 或者 indicate 才可以成功调用。
>
> 必须先启用notifyBLECharacteristicValueChange才能监听到设备 characteristicValueChange 事件。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:---------------|:-------|:---|:---------------|
|deviceId|string|是|蓝牙设备 id。|
|serviceId|string|是|蓝牙特征值对应服务的 uuid。|
|characteristicId|string|是|蓝牙特征值的 uuid。|
|state|boolean|是|是否启用 notify。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**示例代码**

```screen
bluetooth.notifyBLECharacteristicValueChange({
    state: true, // 启用 notify 功能
    // 这里的 deviceId 需要已经通过 createBLEConnection 与对应设备建立链接
    deviceId:deviceid,
    // 这里的 serviceId 需要在 getBLEDeviceServices 接口中获取
    serviceId:serviceId,
    // 这里的 characteristicId 需要在 getBLEDeviceCharacteristics 接口中获取
    characteristicId:characteristicId,
    success:function(){
        console.log("success")
    }，
    fail: function() {
        console.log("fail");
    },
    complete: function (){
        console.log("complete");
    }
})
```

### bluetooth.onbleconnectionstatechange(OBJECT)

**描述**

监听低功耗蓝牙连接状态的改变事件。包括开发者主动连接或断开连接，设备丢失，连接异常断开等。

**callback返回值**

|参数名|类型|说明|
|:--------|:------|:---------|
|deviceId|string|蓝牙设备id。|
|connected|boolean|是否处于已连接状态。|

**示例代码**

```screen
bluetooth.onbleconnectionstatechange = function(res){
  console.log('device'+ res.deviceId+'state has changed,connected:'+res.connected)
}
```

### bluetooth.getDevicesBattery(OBJECT)（1078+，非厂商联盟规范）

**描述**

查询华为蓝牙耳机的电量。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:----------|
|mac|String|是|蓝牙耳机的mac地址。|
|success|Function|否|成功回调。|
|fail|Function|否|失败回调。|
|complete|Function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:-----------|:-----|:------------------------------|
|batteryValue|Object|电量。 -1表示未知状态，0~100表示剩余电量的百分比。|
|chargeState|Object|充电状态。 * -1：未知状态 * 0：未充电 * 1：充电中|
|infoStr|String|整体电量情况。|

返回数据示例如下：

{"chargeState":{"1":-1,"2":0,"3":1,"4":0},"batteryValue":{"1":-1,"2":55,"3":100,"4":65},"infoStr":"6,2,55,3,0,4,100,5,1,6,65,7,0"}

chargeState和batteryValue信息的参数值含义如下：

* 代表normal（当前无实际意义）
* 代表left（左耳机）
* 代表right（右耳机）
* 代表charger（盒子）

fail返回值：

|参数|说明|
|:------|:----|
|errCode|错误码。|
|errMsg|错误信息。|

错误码说明：

|错误码|说明|
|:--|:------|
|200|其他通用错误。|

**示例代码**

```screen
bluetooth.getDevicesBattery({
  mac: "XX:XX:XX:XX:XX:XX",
  success: function (data) {
    console.log('getDevicesBattery success data = ' + JSON.stringify(data));
  },
  fail: function (errMsg, errCode) {
    console.log('getDevicesBattery fail errMsg = ' + errMsg + '; errCode = ' + errCode);
  },
  complete: function () {
    console.log('getDevicesBattery complete .');
  }
})
```

    stringToByte(str) {
      var bytes = []
      var len, c
      len = str.length
      for (var i = 0; i < len; i++) {
        c = str.charCodeAt(i)
        if (c >= 0x010000 && c <= 0x10FFFF) {
          bytes.push(((c >> 18) & 0x07) | 0xF0)
          bytes.push(((c >> 12) & 0x3F) | 0x80)
          bytes.push(((c >> 6) & 0x3F) | 0x80)
          bytes.push((c & 0x3F) | 0x80)
        } else if (c >= 0x000800 && c <= 0x00FFFF) {
          bytes.push(((c >> 12) & 0x0F) | 0xE0)

        }
      }
      return bytes
    },
