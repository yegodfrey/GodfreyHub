# websocket

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.websocketfactory"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import websocketfactory from '@system.websocketfactory'
```

或

```screen
var websocketfactory = require("@system.websocketfactory")
```

## 使用限制

|限制条件|说明|
|:---|:-----------|
|使用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

### websocketfactory.create(OBJECT)

**描述**

创建一个WebSocket连接，每次成功调用websocketfactory.create将返回一个新的websocket对象。

从1060版本开始，可以通过 manifest.json 的 [config.network](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621#section169381859312) 进行网络超时的配置。
> 说明
>
> 创建Websocket的个数不受限制。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:--------|:-----|:---|:------------------------------|
|url|string|是|开发者服务器接口地址，必须是wss或ws协议。|
|header|object|否|HTTP Header，header中不能设置Referer。|
|protocols|array|否|子协议组。|

**示例代码**

```screen
var websocket = websocketfactory.create({
    url: 'ws://echo.websocket.org',
    header:{
        'content-type': 'application/json'
    },
    protocols: ['protocol1']
})
```

### websocket.send(OBJECT)

**描述**

使用create创建的对象websocket发送消息。

**OBJECT参数**

|参数|类型|默认值|是否必填|说明|
|:------|:-------------------|:--|:---|:-----------------------|
|data|string | arraybuffer|-|是|需要发送到服务器的数据，数据大小不能超过16M。|
|success|function|-|否|接口调用成功的回调函数。|
|fail|function|-|否|接口调用失败的回调函数|

**示例代码**

```screen
websocket.send({
    data:'send message',
    success:function() {
        console.log('success');
    },
    fail:function() {
        console.log('failed');
    }
}) 
sendMessage: function () {
    var that = this;
    var buffer = new ArrayBuffer(4);
    var a = new Uint8Array(buffer);
    a[0] = 1;
    a[1] = 2;
    a[2] = 3;
    a[3] = 4;
    if (that.websocket) {
        that.websocket.send({
            data: buffer,
            success: function () {
                console.log('success');
                that.isSend = "发送成功";
            },
            fail: function () {
                console.log('failed');
                that.isSend = "发送失败";
            }
        })
    }
},
```

### websocket.close(OBJECT)

**描述**

关闭websocket连接。

**OBJECT参数**

|参数|类型|默认值|是否必填|说明|
|:------|:-------|:---|:---|:-----------|
|code|number|1000|否|关闭链接的状态号。|
|reason|string|-|否|关闭的原因。|
|success|function|-|否|接口调用成功的回调函数。|
|fail|function|-|否|接口调用失败的回调函数。|

**示例代码**

```screen
websocket.close({
    code: 1000,
    reason: 'close as normal',
    success: function() {
        console.log('close success');
    },
    fail: function() {
        console.log('close fail');
    }
})
```

### websocket.onopen(OBJECT)

**描述**

监听websocket连接打开的状态。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:------|
|callback|function|否|打开连接回调。|

**示例代码**

```screen
websocket.onopen = function() {
    console.log('connect open');
}
```

### websocket.onmessage(OBJECT)

**描述**

消息事件的监听，用于接收服务端发来的message。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------|
|callback|function|否|服务器返回消息事件回调。|

**callback返回参数：**

|参数|类型|说明|
|:---|:-------------------|:---------|
|data|string | arraybuffer|监听器接收到的消息。|

**示例代码**

```screen
websocket.onmessage = function (e) {
    console.log("onmessage e = "+e.data);
}
websocket.onmessage = function (e) {
    console.log("onmessage e = "+JSON.stringify(String.fromCharCode.apply(null, new Uint8Array(e.data))));
}
```

### websocket.onclose(OBJECT)

**描述**

关闭连接的监听。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|callback|function|否|关闭连接事件回调。|

**callback返回参数：**

|参数|类型|说明|
|:-------|:------|:-----------|
|code|number|服务器返回关闭的状态码。|
|reason|string|服务器返回的关闭原因。|
|wasClean|boolean|是否完全关闭。|

**code说明：**

|状态码|名称|
|:---|:-------------------------|
|1000|Normal Closure|
|1001|Going Away|
|1002|Protocol Error|
|1003|Unsupported Data|
|1005|No Status Recvd|
|1006|Abnormal Closure|
|1007|Invalid frame payload data|
|1008|Policy Violation|
|1009|Message too big|
|1010|Missing Extension|
|1011|Internal Error|
|1012|Service Restart|
|1013|Try Again Later|
|1014|Bad Gateway|
|1015|TLS HandShake|

**示例代码**

```screen
websocket.onclose = function(e) {
    console.log("onclose e.code = "+e.code+", e.reason = "+e.reason+", wasClean = "+e.wasClean);
}
```

## 安全要求

对于HTTPS请求，对证书要求如下：

* HTTPS证书必须有效。证书必须被系统信任，不支持自签名证书，部署SSL证书的网站域名必须与证书颁发的域名一致，证书必须在有效期内。
* 从1200版本开始，TLS必须支持1.2及以上版本，请确保HTTPS服务器的TLS版本能够同时支持TLS1.2及以下版本。 从安全性考虑，建议也支持TLS1.3。1200及以上版本在配置加密套件时排除不安全算法：TEA/DES/DESX/DES40/RC2/RC4/RIPEMD/NULL/SHA0/MD2/MD4/MD5/ANON/TLS_EMPTY_RENEGOTIATION_INFO_SCSV；1200以下版本在配置加密套件时排除不安全算法：TEA/DES/DESX/DES40/RC2/RC4/RIPEMD/eNULL/aNULL/NULL/SHA0/MD2/MD4/MD5/ANON/TLS_EMPTY_RENEGOTIATION_INFO_SCSV。部分CA可能不被操作系统信任，请开发者在选择证书时注意操作系统的相关通告。
