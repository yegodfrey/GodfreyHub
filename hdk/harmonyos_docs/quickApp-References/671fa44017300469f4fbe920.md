[h2]pay.getProvider(OBJECT) **描述** 获取服务提供商。 **返回值** 字符串，服务提供商的代号，如厂商的英文品牌名称，如果无此服务则返回空字符串。返回空字符串时，请勿调用该服务其他接口，否则将抛出异常。 **示例代码**
    
    pay.getProvider();

applicationID | string | 是 | 应用ID。在华为开发者联盟上获取的AppID。  
requestId | string | 是 | 查询标识号，由开发者应用自行生成，用于唯一标识一次商品查询请求。  
merchantId | string | 是 | 商户ID，即华为开发者联盟给开发者分配的“支付ID”。  
productNos | string | 是 | 需要获取商品详情的商品ID列表，多个商品ID时以竖线“|”分割，一次查询最多支持20个商品。 商品ID来源于开发者在AppGallery Connect中配置商品信息时设置的“商品ID”，请参见“[创建应用内商品](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-product-0000001099854866)”。  
success | function | 否 | 成功回调。  
fail | function | 否 | 失败回调。  
complete | function | 否 | 执行结束后的回调。  
**success返回值：** 参数 | 类型 | 说明  
---|---|---  
requestId | string | 商品查询请求的标识号，与请求参数中的requestId一致。 应用通过该参数识别本次回调结果所属的查询请求。  
productList | list<productdetail> | 成功查询到商品信息的商品列表，值为包含ProductDetail对象的数组。  
failList | productfailobject | 查询失败的商品信息列表，值为包含ProductFailObject对象的数组。  
**ProductDetail说明：** 参数 | 类型 | 说明  
---|---|---  
productNo | string | 查询成功的商品ID。  
microsPrice | long | 商品实际价格乘以1,000,000后的微单位价格。 例如某个商品实际价格是1.99美元，则该商品对应的微单位价格为：1.99*1000000=1990000。  
price | string | 商品的展示价格，包含商品货币单位和实际价格，格式为“货币单位 商品价格”，中间使用空格分隔，例如“CNY 0.15”。  
currency | string | 用于支付该商品的币种，必须符合[ISO 4217](https://www.iso.org/iso-4217-currency-codes.html)标准，例如USD、CNY、MYR。  
country | string | 国家码，用于区分国家信息，必须符合[ISO 3166](https://www.iso.org/iso-3166-country-codes.html)标准，如US、CN、MY。  
productName | string | 商品名称，为配置商品信息时配置的名称。  
productDesc | string | 商品描述，为配置商品信息时配置的描述信息。  
**ProductFailObject返回值：** 参数 | 类型 | 说明  
---|---|---  
productNo | string | 查询失败的商品ID。  
code | int | 查询失败的错误码，具体错误码请参见“[错误码](https://developer.huawei.com/consumer/cn/doc/HMS-2-References/hmssdk_huaweiiap_api_reference_errorcode)”。  
msg | string | 查询失败的错误描述。  
**fail返回值：** 参数 | 类型 | 说明  
---|---|---  
code | number | 返回状态码。  
data | string | 状态码说明。
