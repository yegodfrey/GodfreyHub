# 第三方分享

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210715163908.84849620822273670045227934145467:50001231000000:2800:A7739AD647DC0FA59DB9899BA60D2B553C56DEFAFD8D7567C7D79A74FE98F0FC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
该功能依赖第三方SDK提供服务，第三方SDK可能会收集用户的个人数据。应用中请务必在使用该功能前，告知用户将搜集个人数据，并引导用户阅读相应的隐私政策。

在接入 第三方分享 前，请了解以下关键点：

1. 支持微信分享，暂时无法获取分享结果。
2. 推荐使用图文分享类型，其他类型个别平台无法支持，将使用图文类型分享。
3. 不同厂商引擎的处理会有不同，使用华为引擎请参见华为文档接入。

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{
    "name": "service.share"
    "params":{
    }
}
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import share from '@service.share'
```

或

```
var share = require("@service.share")
```

#### 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|中国大陆|

#### 接口定义

|接口|描述|
|:----------------------------------------------------------|:------------------|
|[share.getProvider(OBJECT)](#section352613562595)|获取服务提供商，如厂商的英文品牌名称。|
|[share.share(OBJECT)](#section18836173214215)|分享内容。|
|[share.getAvailablePlatforms(OBJECT)](#section832714552613)|获取当前可用的支持分享的平台列表。|

#### share.getProvider(OBJECT)

描述

获取服务提供商，如厂商的英文品牌名称。

返回值

字符串，服务提供商的代号，如厂商的英文品牌名称，如果无此服务则返回空字符串。返回空字符串时，请勿调用该服务其他接口，否则将抛出异常。

示例代码

```
share.getProvider();
```

#### share.share(OBJECT)

描述

分享内容。

OBJECT参数  

|参数|类型|是否必填|说明|
|:--------|:-------|:--------------|:----------------------------------------------------------------------------------------------|
|shareType|int|是|分享类型。 * 默认图文0 * 纯文字1 * 纯图片2 * 音频3 * 视频4|
|title|string|分享类型为0,1,3,4时必填|分享的标题。|
|summary|string|否|分享的摘要。|
|targetUrl|string|分享类型为0,3,4时必填|点击后的跳转URL。 说明： URL是否能正常打开依赖被分享的第三方平台的能力。|
|imagePath|string|分享类型为2,3,4时必填|分享图片/缩略图的本地地址或网络地址。 当分享类型为0时，imagePath可以选填，如果填写则为分享图片的本地路径，不填的话，则分享后没有图片。 微信分享图片时，图片大小不能超过32KB。|
|mediaUrl|string|分享类型为3,4时必填|分享的音乐/视频数据URL。|
|platforms|array|否|分享到的平台，不填则默认分享所有平台。 可用值包括：WEIXIN(微信好友)、WEIXIN_CIRCLE(微信朋友圈)、SYSTEM(系统分享)。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|cancel|function|否|取消回调。|

示例代码

```
share.share({
    shareType:0,
    title:"我是标题",
    summary:"我是摘要",
    imagePath:"xxx/xxx/xxx/share.jpg",
    targetUrl:"https://www.example.com",
    success:function() {
        console.log(“message”);
    },
    fail: function(data, code) {
        console.log("handling fail, code=" + code);
    }
})
```

#### share.getAvailablePlatforms(OBJECT)（1030+）

描述

获取当前可用的支持分享的平台列表。

OBJECT参数  

|参数|类型|是否必填|说明|
|:------|:-------|:---|:----|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|cancel|function|否|取消回调。|

success返回值：  

|参数|类型|说明|
|:--------|:----|:-------------------------------------------------------------|
|platforms|array|当前可用的支持分享的平台列表，可用值包括：WEIXIN、WEIXIN_CIRCLE(微信朋友圈)、SYSTEM(系统分享)。|

示例代码

```
share.getAvailablePlatforms({
    success:function(data) {
        For(const i in data.platforms) {
             console.log(“platforms: ” + data.platforms[i]);
        }
    },
    Fail:function(data, code) {
         console.log(“handling fail, code = ” + code);
    }
})
```
