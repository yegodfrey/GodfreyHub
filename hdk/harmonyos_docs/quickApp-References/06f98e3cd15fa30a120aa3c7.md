qa.enableAlertBeforeUnload（1106+） 接口描述快应用页面返回时，弹出询问对话框。 使用限制 限制条件 | 说明  
---|---  
适用终端 | 手机、平板  
适用区域 | 中国  
接口定义 [h2]qa.enableAlertBeforeUnload(Object object)**描述** 快应用页面返回时，弹出询问对话框。 **OBJECT参数** 参数 | 类型 | 是否必填 | 描述  
---|---|---|---  
message | string | 是 | 询问对话框内容。  
success | function | 否 | 接口调用成功的回调函数。  
fail | function | 否 | 接口调用失败的回调函数。  
complete | function | 否 | 接口调用结束的回调函数（调用成功、失败都会执行）。  
**示例代码**
    
    qa.enableAlertBeforeUnload({
         message: "123",
         success(res) {
               console.info('succeed to enableAlertBeforeUnload.', res)
         },
         fail(err) {
               console.info('failed to enableAlertBeforeUnload.', err)
         },
         complete(res) {
               console.info('finished to enableAlertBeforeUnload.', res)
         }
     })
