# 应用配置

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{"name": "system.configuration"}
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import configuration from '@system.configuration'
```

或

```
const configuration = require("@system.configuration")
```

#### 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

#### configuration.getLocale()（1060+）

描述

获取应用当前的语言环境。默认使用系统的语言环境，会随着设置或系统语言环境改变而发生变化。

返回值  

|参数名|类型|说明|
|:--------------|:-----|:-----|
|language|string|语言。|
|countryOrRegion|string|国家或地区。|

示例代码

```
const locale = configuration.getLocale()
console.log(locale.language)
```

#### configuration.getLayoutDirection()（1070+）

描述

获取当前系统的语言方向。

返回值  

|参数名|类型|说明|
|:--|:-----|:-------|
|ltr|string|从左向右的方向。|
|rtl|string|从右向左的方向。|

示例代码

```
const dir = configuration.getLayoutDirection()
console.log("direction="+dir)
```

#### configuration.setScreenOrientation(OBJECT)（1070+）

描述

设置屏幕方向。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507152458.14884422526035597527992137973650:50001231000000:2800:889F30BA5B7CDB98C4A21980A2B06668B9663AEECFECE296BE3CDF5871B59009.png)  
横竖屏切换后，屏幕宽度会发生变化，导致开发者即使设置相同的尺寸，实际展示会不一致。所以如果使用横竖屏切换，建议使用"[响应式布局](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-responsive-layout-0000001082763996)"进行开发。

参数  

|参数|类型|是否必填|说明|
|:----------|:-------|:---|:----------------------------|
|orientation|string|是|屏幕方向：portrait、landscape、auto。|
|success|function|否|接口调用成功的回调函数。|
|fail|function|否|接口调用失败的回调函数。|
|complete|function|否|接口调用结束的回调函数（调用成功、失败都会执行）。|

示例代码

```
configuration.setScreenOrientation({
    orientation:"portrait",
    success:function (data) {
        console.log('result:' + data); // success
    },
    fail:function () {
    }
})
```

#### configuration.formatDateAndTime(OBJECT)（1070+，非联盟规范）

描述

基于当前语言环境和设置的格式选项，返回时间戳格式化后的时间字符串。

OBJECT参数  

|参数|类型|是否必填|说明|
|:--------|:-------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|timeStamp|long|是|时间戳。|
|flag|int|是|格式选项，可以根据需要显示信息设置多个格式，多个格式之间使用 \| 分隔，例如需要显示星期、时、分信息，可以设置为 0x00001 \| 0x00002，常见选项有： * 0x00001：显示时和分，例如：下午2：16。 * 0x00002：显示星期几，例如：星期五。 * 0x00004：如果设置了该值，则年份始终会显示。 * 0x00010：显示月份和日期。 * 0x00020：显示月份。 更多选项参见Java中的DateUtils的常量取值，各选项的组合规则以及实现效果，与Java的DateUtils实现相同。|
|success|function|否|接口调用成功的回调函数。|
|fail|function|否|接口调用失败的回调函数。|
|complete|function|否|接口调用结束的回调函数（调用成功、失败都会执行）。|

success返回值：  

|参数|类型|说明|
|:------|:-----|:---------------|
|dateStr|string|返回时间戳格式化后的时间字符串。|

示例代码

```
var date = Date.now()
configuration.formatDateAndTime({
    timeStamp: date,
    flag: 0x00001 | 0x00002 ,
    success: function(ret){
        console.log(`dateStr= ${ret.dateStr }`)
    }
})
```

#### configuration.simpleFormatDate(OBJECT)（1070+，非联盟规范）

描述

基于当前语言环境和设置的格式选项，返回时间戳格式化后的时间字符串。

OBJECT参数  

|参数|类型|是否必填|说明|
|:--------|:-------|:---|:------------------------|
|timeStamp|long|是|时间戳。|
|format|string|是|时间格式字符串。|
|success|function|否|接口调用成功的回调函数。|
|fail|function|否|接口调用失败的回调函数。|
|complete|function|否|接口调用结束的回调函数（调用成功、失败都会执行）。|

success返回值：  

|参数|类型|说明|
|:------|:-----|:---------------|
|dateStr|string|返回时间戳格式化后的时间字符串。|

示例代码

```
var date = Date.now()
configuration.simpleFormatDate({
    timeStamp: date,
    format:"yyyy年MM月dd日  HH时mm分ss秒",
    success: function(ret){
        console.log(`dateStr= ${ret.dateStr }`)
    }
})
```

#### configuration.getThemeMode()（1083+）

描述

获取应用当前的主题模式。

返回值

返回当前主题模式值，类型为 number，返回值是下表的其中之一：  

|参数值|说明|
|:--|:----|
|0|浅色模式。|
|1|深色模式。|

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507152458.90857210432236457748453114005036:50001231000000:2800:B7B82683577D96BDE6F5D672B7176488C7AAEDF47FF336775A05937D18574A8D.png)  
获取主题模式值有两种情况：

* 如果manifest.json的display属性下的themeMode值为-1（跟随系统主题模式），则此时快应用主题模式会跟随系统主题模式，返回值也跟随系统主题模式，返回0（浅色模式）或1（深色模式）。
* 如果manifest.json的display属性下的themeMode值为0（浅色模式）、1（深色模式）或没有设置（此时主题模式为默认值0（浅色模式）），则此时快应用主题模式会设置为固定模式，返回值会与themeMode值保持一致（没有设置themeMode值则返回 0 ）。

示例代码

```
const themeMode = configuration.getThemeMode()
console.log(`Theme mode is ${themeMode} now~`)
```

#### configuration.getFoldableState()（1083+）

描述

获取折叠屏的状态。

返回值  

|返回值|说明|
|:--|:------------------|
|0|未知/不支持状态（如设备不是折叠屏）。|
|1|展开。|
|2|折叠。|
|3|半折叠。|
|11|三折叠屏完全展开(1118+)|

示例代码

```
const foldableState = configuration.getFoldableState();
console.log('foldableState ', foldableState);
```

#### configuration.getScreenOrientation()（1083+）

描述

获取屏幕当前的横竖屏状态。

返回值  

|返回值|说明|
|:--------|:--------|
|portrait|竖屏。|
|landscape|横屏。|
|undefined|未知（内部出错）。|

示例代码

```
const orientation = configuration.getScreenOrientation();
console.log('orientation ', orientation);
```

#### configuration.setGrayMode(OBJECT)（1100+）

描述

设置灰色模式相关配置。通过该接口设置的配置项会覆盖[manifest中的相应配置](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621#ZH-CN_TOPIC_0000001073698621__table1717644231911)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507152458.93263744578802911268897614420528:50001231000000:2800:865711479DA0CEE270E2A32E8002779EF31E5B0359F720FE00D5F08FC87856C3.png)  
setGrayMode方法需要在页面渲染前调用。

OBJECT参数  

|参数|类型|是否必填|说明|
|:------------|:------|:---|:-----------------------------------------------------------------------------------|
|enable|boolean|否|是否开启灰色模式。|
|duration|object|否|灰色模式需要启动的日期，详细内容参见"[duration参数](#ZH-CN_TOPIC_0000001074911860__table5562135113182)"。|
|excludedPages|array|否|需要禁用灰色模式的页面列表。|

duration参数  

|参数|类型|是否必填|说明|
|:--------|:----|:---|:------------------------|
|regular|array|否|每年固定的日期，日期格式为MM/dd。|
|temporary|array|否|一次性的临时日期，日期格式为yyyy/MM/dd。|

返回值

无

示例代码

```
configuration.setGrayMode({
    enable: true,
    duration:
    {
        regular: ["06/22"],
        temporary: ["2022/06/22"]
    },
    excludedPages: ["Hello/configuration"]
});
```

#### configuration.getWideScreenFitMode()（1109+）

描述

获取折叠屏展开时应用页面的满屏或居中状态。

返回值  

|返回值|说明|
|:--------|:--------------|
|original|折叠屏展开时应用页面满屏显示。|
|fitScreen|折叠屏展开时应用页面居中显示。|

示例代码

```
const foldableScreenState = configuration.getWideScreenFitMode();
console.log('foldableScreenState ', foldableScreenState);
```
