# 通用事件

所有组件支持的事件如下表所示。

|名称|参数|描述|
|:------------------------|:-------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|touchstart(1010+)|TouchEvent|手指触摸动作开始。 智慧屏不支持。|
|touchmove(1010+)|TouchEvent|手指触摸后移动。 智慧屏不支持。|
|touchcancel(1010+)|TouchEvent|手指触摸动作被打断，如来电提醒，弹窗。 智慧屏不支持。|
|touchend(1010+)|TouchEvent|手指触摸动作结束。 智慧屏不支持。|
|click|-|组件被点击时触发。 智慧屏在按下遥控器确认键时触发。从1040版本开始，在智慧屏上支持获取系统坐标。|
|longpress|-|组件被长按时触发。 智慧屏不支持。|
|focus|-|组件获得焦点时触发，支持所有组件（1040+，非厂商联盟规范）。|
|blur|-|组件失去焦点时触发，支持所有组件（1040+，非厂商联盟规范）。|
|appear|-|屏幕划入，组件出现时触发。|
|disappear|-|屏幕划出，组件消失时触发。|
|swipe|direction:String|swipe 事件在用户在某个元素上快速滑动时被触发，元素本身消耗触摸事件以及有手势事件的场景不支持，其中上下滑动事件只支持list。 * left：向左滑动 * right：向右滑动 * up：向上滑动 * down：向下滑动 智慧屏不支持。|
|resize(1035+)|{ offsetWidth: offsetWidthValue, offsetHeight: offsetHeightValue, offsetLeft: offsetLeftValue, offsetTop: offsetTopValue }|元素大小改变后触发： offsetLeft与offsetTop为相对父元素的位置|
|key(1037+)|KeyEvent|智慧屏特有的按键事件，手机、平板等触摸设备不支持。当用户操作遥控器按键时触发。 * 返回true表示页面自己处理按键事件。 * 返回false表示使用默认的按键事件逻辑。 * 不返回值作为false处理。|
|animationstart(1070+)|AnimationEvent|某个 CSS 动画开始时触发。 > 说明 > 该事件需要配合通用方法中的[addEventListener](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-methods-0000001123690168#section510442634619)方法使用。|
|animationiteration(1070+)|AnimationEvent|某个 CSS 动画完成后重新开始时触发。 > 说明 > 该事件需要配合通用方法中的[addEventListener](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-methods-0000001123690168#section510442634619)方法使用。|
|animationend(1070+)|AnimationEvent|某个 CSS 动画完成时触发。 > 说明 > 该事件需要配合通用方法中的[addEventListener](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-methods-0000001123690168#section510442634619)方法使用。|

**TouchEvent类型说明(1010+)：**

|属性|类型|说明|
|:-------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|touches|objectarray|触摸事件，当前停留在屏幕中的触摸点信息的数组。|
|changedTouches|objectarray|触摸事件，当前变化的触摸点信息的数组changedTouches 数据格式同 touches， 表示有变化的触摸点，如从无变有（touchstart），位置变化（touchmove），从有变无（touchend、touchcancel），比如用户手指离开屏幕时，touches数组中无数据，但changedTouches则会保存离开前的数据。|

**BaseEvent类型说明(1010+)：**

|属性|类型|说明|
|:------------|:------|:-----------------------------------|
|type|string|事件类型，比如click，touchstart，touchcancel。|
|timeStamp|integer|事件生成时的时间戳。|
|target|object|触发事件的组件的一些属性值集合。|
|currentTarget|object|当前组件的一些属性值集合。|

**target（含currentTarget）属性说明（1020+，华为扩展接口，非厂商联盟规范）：**

|属性|类型|说明|
|:---|:-----|:-----------------------|
|id|string|元素的id属性对应的值，如果未定义则为空字符串。|
|type|type|元素类型。|

**touches（含changedTouches）属性说明（1020+）：**

|属性|类型|说明|
|:-------------|:-----|:------------------------------------------------------|
|identifier|number|触摸点的标识符。对于多点同时触摸则是[0,1,2,...]，分别表示第一个手指、第二个手指、第三个手指...。|
|pageX|number|距离document对象左上角的距离。document对象的左上角为原点，横向为X轴，纵向为Y轴。|
|pageY|number|距离document对象左上角的距离。document对象的左上角为原点，横向为X轴，纵向为Y轴。|
|clientX|number|距离页面可显示区域（屏幕除去导航条）左上角距离，横向为X轴，纵向为Y轴。|
|clientY|number|距离页面可显示区域（屏幕除去导航条）左上角距离，横向为X轴，纵向为Y轴。|
|offsetX(1050+)|number|距离被触摸组件左上角距离，组件的左上角为原点，横向为X轴，纵向为Y轴。|
|offsetY(1050+)|number|距离被触摸组件左上角距离，组件的左上角为原点，横向为X轴，纵向为Y轴。|

**canvasTouch属性说明（1030+）：**

|属性|类型|说明|
|:-------------|:-----|:------------------------------------------------------|
|identifier|number|触摸点的标识符。对于多点同时触摸则是[0,1,2,...]，分别表示第一个手指、第二个手指、第三个手指...。|
|offsetX(1050+)|number|距离Canvas左上角的距离，Canvas的左上角为原点，横向为X轴，纵向为Y轴。|
|offsetY(1050+)|number|距离Canvas左上角的距离，Canvas的左上角为原点，横向为X轴，纵向为Y轴。|
|pageX|number|距离document对象左上角的距离。document对象的左上角为原点，横向为X轴，纵向为Y轴。|
|pageY|number|距离document对象左上角的距离。document对象的左上角为原点，横向为X轴，纵向为Y轴。|
|clientX|number|距离页面可显示区域（屏幕除去导航条）左上角距离，横向为X轴，纵向为Y轴。|
|clientY|number|距离页面可显示区域（屏幕除去导航条）左上角距离，横向为X轴，纵向为Y轴。|

**KeyEvent属性说明，继承于BaseEvent（1040+，仅支持智慧屏）：**

|属性|类型|说明|
|:----------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------|
|code|number|遥控器的按键值，详细请参见"[常用按键值](#ZH-CN_TOPIC_0000001123530338__table182095555494)"。|
|Number|number|按键类型： 0：down 1：up 2：multiple 用户点击一个遥控器按键，通常会触发两次key事件，先触发action为0，再触发action为1，即先触发按下事件，再触发抬起事件。 action为2的场景比较少见，一般为用户按下按键不松，此时repeatCount将返回次数。|
|repeatCount|Int|按键重复次数，通常为0。|

**常用按键值：**

|数值|约定行为|设备按键|
|:--|:---|:--------|
|19|上|遥控器的向上方向键|
|20|下|遥控器的向下方向键|
|21|左|遥控器的向左方向键|
|22|右|遥控器的向右方向键|
|23|确定|遥控器的确认键|
|109|确定|手柄的选择键|
|96|确定|手柄的A按键|
|66|确定|键盘的回车键|
|160|确定|键盘的小键盘回车键|

**AnimationEvent类型说明（1070+）：**

|属性|类型|说明|
|:------------|:-----|:-------------------------------------------------------|
|type|string|事件类型。可选值为animationstart、animationiteration和animationend。|
|animationName|string|动画的名称。|
|elapsedTime|float|事件发生时动画的执行时长，单位：秒。|
