# input

#### 概述

提供可交互的界面，接收用户的输入，默认为单行。  

#### 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

#### 子组件

不支持  

#### 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-attributes-0000001170050123) 以外，还支持如下属性。  

|名称|类型|默认值|是否必填|描述|
|:-----------------|:---------------------------------------------------------------------------------|:------|:---|:-----------------------------------------------------------------------------------------------------------------------|
|type|button \| checkbox \| radio \| text \| email \| date \| time \| number \| password|text|否|支持动态修改。|
|checked|boolean|false|否|当前组件的checked状态，可触发checked伪类，type为checkbox时生效。|
|name|string|-|否|input组件名称。|
|value|string|-|否|input组件的值。|
|placeholder|string|-|否|提示文本的内容，type为button\|checkbox\|radio\|text\|email\|date\|time\|number时生效。|
|maxlength|number|-|否|输入框可输入的最多字符数量。不填表示不限制输入框中的字符数量。|
|enterkeytype|default \| next \| go \| done \| send \| search|default|否|不支持动态修改。 设置软键盘Enter按钮的显示文本 * default：默认显示 * next：下一个 * go：开始 * done：完成 * send：发送 * search：搜索 说明： 不同输入法设置相同的值，显示文本可能存在差异。|
|model:value(1100+)|string|-|否|用于绑定和更新框架中的值的model指令。|

#### 样式

\<input\> 支持active伪类，除了支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-common-styles-0000001170210009) 以外，还支持如下样式。  

|名称|类型|默认值|是否必填|描述|
|:-----------------|:-------------------------------------------------------------------------------------------------|:---------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|color|color|rgba(0,0,0,0.87)|否|文本颜色。|
|font-size|number|37.5px|否|文本尺寸。|
|placeholder-color|color|rgba(0,0,0,0.38)|否|提示文本的颜色，type为button\|checkbox\|radio\|text\|email\|date\|time\|number\|password时生效。|
|font-weight(1030+)|lighter \| 100 \| 200 \| 300 \| 400 \| 500 \| 600 \| 700 \| 800 \| 900 \| normal \| bold \| bolder|normal|否|字体的粗细，默认为normal。|
|width|length \| percentage|-|否|type为button时，默认值为128px。|
|height|length \| percentage|-|否|type为button时，默认值为70px。|
|font-family(1030+)|string|-|否|通过该属性可以设置组件中字符串的字体。 支持四种系统原生字体：normal,sans-serif,serif,monospace（此四种字体只对英文有效）。 如果需要设置自定义字体，请参见"[font-face样式](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-font-face-0000001170050125)"。|
|caret-color(1060+)|color \| transparent \| auto|auto|否|自定义光标颜色。|

#### 事件

\<input\> 支持 change 事件，当input组件的值、checked状态发生变化时触发。除了支持[通用事件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-events-0000001123530338)以外，还支持如下事件。  

|参数|text \| email \| date \| time \| number \| password|checkbox|radio|备注|
|:---------------------|:--------------------------------------------------|:-------|:----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|name|-|√|√|-|
|value|√|√|√|当type类型为 checkbox \| radio \| text \| email \| date \| time \| number \| password 时，获取input更新后的值需要通过change事件中的e.value。使用this.$element('xx').value将无法获取到值。 详细例子请参见案例"[获取input框输入值异常](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-case-0000001082020374#section53009461612)"。|
|checked|-|√|-|-|
|enterkeyclick|{value:valuestring}|-|-|软键盘enter键点击事件。|
|selectionchange(1030+)|√|-|-|在\<input\>组件中调用其select()和setSelectionRange()方法改变选中字符串时触发此事件。 注意： \<input\> 组件类型为text\|email\|date\|time\|number时，才触发此事件。|

#### 方法

|名称|参数|描述|
|:----------------|:--------------------------------------------------|:--------------------------------------------------------------------------------|
|focus|{focus:true\|false}，focus不传默认为true|使组件获得或者失去焦点，可触发focus伪类，type为text\|email\|date\|time\|number\|password时，可弹出或收起输入法。|
|select|-|选中文本框的全部文本。|
|setSelectionRange|{start: number, end : number}|设置文本框的选中区域。|
|getSelectionRange|{callback : function(start : number, end : number)}|获取文本框的选中区域。|

<script>
    import prompt from '@system.prompt'
    export default {
        data: {
            inputValue: ''
        },
        onInit() {
            this.$page.setTitleBar({ text: 'input1' });
        },
        updateValue(e) {
            this.inputValue = e.value;
        },
        setValue() {
            this.inputValue = "hello world";
        },
        resetValue() {
            this.inputValue = ''
        },
        showChangePrompt(e) {
            prompt.showToast({
                message: (e.name === undefined ? '' : '---name: ' + e.name)
                    + (e.value === undefined ? '' : '---value: ' + e.value)
                    + (e.checked === undefined ? '' : '---checked: ' + e.checked)
                    + (e.text === undefined ? '' : '---text: ' + e.text)
            })
        },
        enterkeyclicked(e) {
            let msg = "enterkeyclicked-->" + "value:" + e.value;
            console.log(msg);
            prompt.showToast({ message: msg });
        },
        truefocus(e) {
            this.$element('selectionInput').focus({ focus: true })
            prompt.showToast({
                message: "get focus"
            })
        },
        falsefocus(e) {
            this.$element('selectionInput').focus({ focus: false })
            prompt.showToast({
                message: "lose focus"
            })
        },
        showClickPrompt(msg) {
            prompt.showToast({
                message: msg
            })
        },
        selectAll() {
            this.$element('selectionInput').select();
        },
        setSelectionRange() {
            this.$element('selectionInput').setSelectionRange({ start: 0, end: 3 });
            //start=3 end=3 Can move the cursor to index=3
            //this.$element('selectionInput').setSelectionRange({start : 3, end : 3});  
        },
        getSelectionRange() {
            this.$element('selectionInput').getSelectionRange({
                callback: function (start, end) {
                    let msg = "getSelectionRange start:" + start + " end:" + end;
                    prompt.showToast({
                        message: msg
                    })
                }
            })
        },
        selectionchange() {
            console.log("selectionchange");
        }
    }
</script>
