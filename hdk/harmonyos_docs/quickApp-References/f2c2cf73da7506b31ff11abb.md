# 用户凭据（1079+）

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{ "name": "service.keyring" }
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import keyring from '@service.keyring'
```

或

```
var keyring = require('@service.keyring')
```

#### 使用限制

|限制条件|说明|
|:---|:------------------------------------|
|适用终端|HarmonyOS 2.0及以上或Android 7.0及以上版本的手机。|
|适用区域|全球。|

#### 接口定义

|接口|描述|
|:------------------------------------------------------------|:-----------------|
|[keyring.getProvider()](#section7247725135314)|获取服务提供商。|
|[keyring.saveCredential(OBJECT)](#section199437254539)|保存用户的凭证信息。|
|[keyring.deleteCredential(OBJECT)](#section349516262537)|删除本应用之前保存的用户凭证信息。|
|[keyring.findCredential(OBJECT)](#section8975142615313)|查询目标应用中用户已登录的凭证信息。|
|[keyring.getCredentialContent(OBJECT)](#section9655102716531)|获取目标凭证的敏感信息。|

#### keyring.getProvider()（1079+）

描述

获取服务提供商。

返回值

字符串，服务提供商的代号，如厂商的英文品牌名称，如果无此服务则返回空字符串。返回空字符串时，请勿调用该服务其他接口，否则将抛出异常。

示例代码

```
functionGetProvider() {
  keyring.getProvider({
    success: function (msg) {
      prompt.showToast({
        message: msg,
        duration: 2000,
        gravity: 'bottom'
      })
    },
    fail: function (msg) {
      prompt.showToast({
        message: msg,
        duration: 2000,
        gravity: 'bottom'
      })
    }
  })
}
```

#### keyring.saveCredential(OBJECT)（1079+）

描述

保存用户的凭证信息，成功返回success，失败返回错误信息。

OBJECT参数  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250807165010.57996336817652070768878739324643:50001231000000:2800:84897A488F61AA6CCFF724A740A746AFF917F7EFFC82B7C6C5AEF37A241BB892.png)  
如果需要保存更新的数据，建议使用[keyring.findCredential](#section8975142615313)返回的参数，更新可修改的部分。  

|参数|类型|是否必填|说明|
|:----------|:----------------------------------------------------------------------|:-----------------------------------------------|:------------------------------------------------------------------------------------------------------|
|avatarUrl|string|否|用户头像URL。|
|username|string|是|凭据的用户名（更新时不可修改）。|
|displayName|string|否|显示名称。|
|owner|[AppIdentity](#ZH-CN_TOPIC_0000001206738947__table184232173545)|* 否（如果是新增一条数据，不必填） * 是（如果是更新已存在的数据则必填，但是不能做任何修改）|凭据的所有者，即最初保存本凭据的应用。 注意： 更新已存在的数据时，需要先调用[keyring.findCredential](#section8975142615313)，返回的owner请务必不做修改。|
|sharedWith|list\<[AppIdentity](#ZH-CN_TOPIC_0000001206738947__table184232173545)\>|否|快应用保存的数据，可以共享给HarmonyOS应用、Android应用和浏览器网址使用。配置对应的身份信息即可共享给特定的应用。|
|syncable|boolean|是|是否支持在不同设备间进行同步。 说明： 此为预留能力，当前版本不支持同步，请设置为false。|
|tag|string|否|凭据的标签。|
|type|int|否|凭据的类型（更新时不可修改），如果不设置，按设置为0的情况处理。 * 0：口令类型的凭据 * 1：Token类型的凭据 * 2：联邦认证类型的凭据|
|userAuth|boolean|是|是否需要对用户的身份进行验证。 说明： 用于查询密钥时，通过系统的锁屏密码或者指纹来验证身份。 如果有锁屏密码或者指纹，该属性需要设置为true，没有则设置为false。|
|newContent|string/object/int|是|凭据的敏感信息内容。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|

AppIdentity说明  

|参数|类型|是否必填|说明|
|:----------|:-----|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|name|string|否|应用的名称。|
|packageName|string|* 是（快应用和原生应用） * 否（浏览器）|应用的包名。|
|certHash|string|* 是（快应用和原生应用） * 否（浏览器）|签名SHA256指纹。 各个字节使用HEX格式表示，字节之间以":"分隔。 说明： * 如果是保存新增数据，签名指纹可从AppGallery Connect上[配置的证书指纹](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-generate-fingerprint-0000001079484294#section1249171493412)处获取。 * 如果是保存更新数据，签名指纹需要填写keyring.saveCredential接口最初创建用户凭据时返回的certHash。|
|domain|string|* 否（快应用和原生应用） * 是（浏览器）|浏览器网址域名。|
|type|string|是|所有者的类型。 * android_app：原生应用 * quick_app：快应用 * web：浏览器|

fail返回错误码  

|错误码|说明|
|:--------|:----------------------------------------------------------------------------------------------------------------|
|200|通用错误。|
|202|参数错误。|
|907300010|certHash参数错误。|
|其他错误码|参见"钥匙环服务"中的"[错误码](https://developer.huawei.com/consumer/cn/doc/Security-References/error-code-0000001133185192)"。|

保存新增数据：

```
  syncable: "false",
  userAuth: "true",
  username: "Zhang San",
  newContent: "123456",
  success: function (msg) {
    prompt.showToast({
      message: msg,
      duration: 2000,
      gravity: 'bottom'
    })
  },
  fail: function (code,msg) {
    prompt.showToast({
      message: code + msg,
      duration: 2000,
      gravity: 'bottom'
    })
  }
})
```

#### keyring.findCredential(OBJECT)（1079+）

描述

查询目标应用中用户已登录的凭证信息，成功返回查询到的信息列表，失败返回错误信息。

OBJECT参数  

|参数|类型|是否必填|描述|
|:----------|:-----------------------------------------------------------------------|:---|:-------------------------|
|trustedApps|list\<[AppIdentity](#ZH-CN_TOPIC_0000001206738947__table5444111317229)\>|否|可信应用列表。不传则返回所有应用共享给调用者的凭据。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|

AppIdentity说明  

|参数|类型|是否必填|说明|
|:----------|:-----|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|name|string|否|应用的名称。|
|packageName|string|* 是（快应用和原生应用） * 否（浏览器）|应用的包名。|
|certHash|string|* 是（快应用和原生应用） * 否（浏览器）|签名SHA256指纹。 各个字节使用HEX格式表示，字节之间以":"分隔。 说明： 签名指纹可从AppGallery Connect上[配置的证书指纹](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-generate-fingerprint-0000001079484294#section1249171493412)处获取。|
|domain|string|* 否（快应用和原生应用） * 是（浏览器）|浏览器网址域名。|
|type|string|是|所有者的类型。 * android_app：原生应用 * quick_app：快应用 * web：浏览器|

success返回值  

|参数|类型|说明|
|:----------|:-----------------------------------------------------------------------|:----------------------------------------------|
|avatarUrl|string|用户头像URL。|
|username|string|凭据的用户名。|
|displayName|string|显示名称。|
|owner|[AppIdentity](#ZH-CN_TOPIC_0000001206738947__table5444111317229)|凭据的所有者，即最初保存本凭据的应用。|
|sharedWith|list\<[AppIdentity](#ZH-CN_TOPIC_0000001206738947__table5444111317229)\>|凭据的共享关系。|
