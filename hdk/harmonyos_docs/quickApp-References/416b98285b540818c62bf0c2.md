# 性能

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135252.71447096796484937489962991938893:50001231000000:2800:FF41E42EB021AFA478D136803D0EF90DC44BF3B6300439EB985E06178249B0B2.png)  
从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。  

#### 接口定义

|接口|描述|
|:-----------------------------------------------|:--------------------------|
|[qg.getPerformance()](#section2095073765014)|获取性能管理器对象Performance。|
|[number Performance.now()](#section724755905012)|可以获取当前时间的时间戳，时间戳精度为毫秒。|
|[qg.triggerGC()](#section23841615526)|加快触发JS GC，但不保证一定能立即触发JS GC。|

#### qg.getPerformance()

* 描述 获取性能管理器对象Performance。Performance对象仅支持一个now()方法，Performance.now() 获取当前时间以毫秒为单位的时间戳。

#### number Performance.now()

* 描述 可以获取当前时间的时间戳，时间戳精度为毫秒。

<!-- -->

* 返回值  

  |类型|说明|
  |:-----|:---|
  |number|时间戳。|

<!-- -->

* 示例代码

  ```
  var p = qg.getPerformance();
  var t = p.now();
  ```

#### qg.triggerGC()

* 描述 加快触发JS GC，但不保证一定能立即触发JS GC。
