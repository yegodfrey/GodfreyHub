# 自定义数据分享

## 接口定义

|接口|描述|
|:--------------------------------------------------------------|:-----------------------|
|[qg.onShare(function callback)](#section94961019174317)|监听游戏触发分享事件。|
|[qg.offShare()](#section2052914311437)|移除监听游戏触发分享事件。|
|[qg.onReceiveShare(function callback)](#section870510433594)|监听游戏通过分享链接启动时是否有自定义数据。|
|[qg.offReceiveShare(function callback)](#section10633134685920)|移除监听游戏通过分享链接启动时是否有自定义数据。|

### qg.onShare(function callback)

* 描述 监听游戏触发分享事件。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:----------------------------------------------|
  |callback|function|M|游戏触发分享事件的回调函数。触发分享事件时，可以在回调函数返回值内携带自定义数据分享给其他人。|

  * callback回调函数参数

    |参数|类型|说明|
    |:--------|:-----|:---------------------------------------------------------------------|
    |shareType|string|分享类型，取值说明如下： * knock：碰一碰分享。 * gesturesShare：抓一抓分享。 * systemShare：系统分享。|

  * callback回调函数返回值

    |参数|类型|说明|
    |:----------|:-----|:-------------------------------------------------------------------------|
    |shareParams|object|分享内容，详情请参见[shareParams参数](#ZH-CN_TOPIC_0000002292750829__li1716913311374)。|

    * shareParams参数

      |参数|类型|必填(M)/选填(O)|说明|
      |:--------|:-----|:----------|:-------|
      |extraData|string|M|分享自定义数据。|

* 示例代码

  ```screen
  qg.onShare((shareType) => {
    if ("knock" === shareType) {
      return {
        extraData: "{roomId: 176568}",
      };
    } else if ("gesturesShare" === shareType) {
      return {
        extraData: "{roomId: 176568}",
      };
    } else if ("systemShare" === shareType) {
      return {
        extraData: "{roomId: 176568}",
      };
    }
  });
  ```

### qg.offShare()

* 描述 移除监听游戏触发分享事件。

* 示例代码

  ```screen
  qg.offShare();
  ```

### qg.onReceiveShare(function callback)

* 描述 监听游戏通过分享链接启动时是否有自定义数据。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-------------------------------------------------------------------|
  |callback|function|M|游戏通过分享链接启动时是否有自定义数据的回调函数。如果有自定义数据，则通过callback回调函数返回给游戏，游戏可执行相应的业务逻辑。|

  * callback回调函数参数

    |参数|类型|说明|
    |:----------|:-----|:------------------------------------------------------------------------|
    |shareType|string|分享类型，取值说明如下： * knock：碰一碰分享。 * gesturesShare：抓一抓分享。 * systemShare：系统分享。|
    |shareParams|object|分享内容，详情请参见[shareParams参数](#ZH-CN_TOPIC_0000002292750829__li699115332021)。|

    * shareParams参数

      |参数|类型|必填(M)/选填(O)|说明|
      |:--------|:-----|:----------|:-------|
      |extraData|string|M|分享自定义数据。|

* 示例代码

  ```screen
  const listener = function (shareType, params) {
    if ("knock" === shareType) {
      var extraData = params && params.extraData;
      if (extraData) {
        console.log(extraData);
      }
    } else if ("gesturesShare" === shareType) {
      var extraData = params && params.extraData;
      if (extraData) {
        console.log(extraData);
      }
    } else if ("systemShare" === shareType) {
      var extraData = params && params.extraData;
      if (extraData) {
        console.log(extraData);
      }
    }
  }
  qg.onReceiveShare(listener);
  ```

### qg.offReceiveShare(function callback)

* 描述 移除监听游戏通过分享链接启动时是否有自定义数据。

* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:---------|
  |callback|function|O|移除的回调函数对象。|

* 示例代码

  ```screen
  const listener = function (shareType, params) {
      var extraData = params && params.extraData;
      if (extraData) {
          console.log(extraData);
      }
  }
  qg.onReceiveShare(listener);
  qg.offReceiveShare(listener);
  ```
