# 密码算法

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.cipher"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import cipher from '@system.cipher'
```

或

```screen
var cipher = require("@system.cipher")
```

## 使用限制

|限制条件|说明|
|:---|:--------|
|适用终端|手机、平板、智慧屏|
|适用区域|全球|

## 接口定义

|接口|描述|
|:--------------------------------------------------|:-------|
|[cipher.rsa(OBJECT)](#section76199516432)|RSA加解密。|
|[cipher.aes(OBJECT)](#section2854825157)|AES加解密。|
|[cipher.getRandomValues(int)](#section317371222620)|获取一个随机数。|

### cipher.rsa(OBJECT)

**描述**

RSA加解密。

**OBJECT参数**

|属性|类型|是否必填|说明|
|:-------------|:-------|:---|:----------------------------------------------------------------------------|
|action|string|是|加解密类型，两个可选值： * encrypt：加密 * decrypt：解密|
|text|string|是|待加密或解密的文本内容。待加密的文本内容应该是一段普通文本。待解密的文本内容应该是经过 base64 编码的一段二进制值。base64 编码使用默认风格。|
|key|string|是|加密或解密使用到的 RSA 密钥，经过 base64 编码后生成的字符串。加密时key为公钥，解密时key为私钥。|
|transformation|string|否|RSA算法的填充项，默认为"RSA/None/OAEPWithSHA256AndMGF1Padding"。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数|类型|说明|
|:---|:-----|:---------------|
|text|string|经过加密或解密后生成的文本内容。|

**fail返回错误码：**

|错误码|说明|
|:--|:------|
|202|输入参数错误。|

**示例代码**

* **加密**

```screen
     action: 'encrypt',
    //待加密的文本内容

     '3ouBwHlsfm2ekey8PpQxfXaj8lhM9t8rJlC4FEc0s8Qp7Q5/uYrowQbT9m6t7BFK\n' +
     '3egOO2xOKzLpYSqfbQIDAQAB',
```
```screen
     success: function(data){
       console.log("handling success: " + data.text);
     },
     fail: function (erromsg, errocode) {
       console. log ('cipher.rsa fail--------' + errocode + ': ' + erromsg);
     }
   });
```

### cipher.aes(OBJECT)（1060+）

**描述**

AES加解密。

**OBJECT参数**

|属性|类型|是否必填|说明|
|:-------------------|:----------|:---|:----------------------------------------------------------------------------|
|action|string|是|加解密类型，两个可选值： * encrypt：加密 * decrypt：解密|
|text|string|否|待加密或解密的文本内容。待加密的文本内容应该是一段普通文本。待解密的文本内容应该是经过 base64 编码的一段二进制值。base64 编码使用默认风格。|
|key|string|否|加密或解密使用到的密钥，经过 base64 编码后生成的字符串。处理text参数设置的内容时需要使用。|
|transformation|string|否|AES算法的加密模式和填充项，默认为"AES/CBC/PKCS5Padding"。|
|iv|string|否|AES加解密的初始向量，经过base64编码后的字符串，默认值为key值。|
|ivOffset|int|否|AES加解密的初始向量偏移，默认值为0。|
|ivLen|int|否|AES加解密的初始向量字节长度，默认值为16。|
|input(1079+)|ArrayBuffer|否|待加密或解密的内容，如果text设置了内容，则只处理text设置的内容。|
|secretKey(1079+)|ArrayBuffer|否|加密或解密使用到的密钥，处理input参数设置的内容时需要使用。|
|initialVector(1079+)|ArrayBuffer|否|AES加解密的初始向量，处理input参数设置的内容时需要使用，如果不设置默认值为secretKey的值。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

> 注意
>
> IV固定存在诸多安全隐患，如统计攻击等，可能会对加密数据的安全性造成影响。建议IV使用安全随机数，每次调用接口随机生成IV并且与密文绑定，解密时传入相应IV。

**success返回值：**

|参数|类型|说明|
|:------------|:----------|:---------------------------------------------------------------------------------|
|text|string|经过加密或解密后生成的文本内容。加密后内容是经过 base64 编码的一段二进制值，解密后内容是一段普通文本。如果解密后的内容不能转化为 UTF-8 字符串会出错。|
|output(1079+)|ArrayBuffer|经过加密或解密后生成的内容，对input设置的值进行加密或者解密时返回。|

**fail返回错误码：**

|错误码|说明|
|:--|:------|
|202|输入参数错误。|

**示例代码**

```screen
//加密
cipher.aes({
  action: 'encrypt',
  //待加密的文本内容
  text: 'hello',
  //base64编码后的密钥
  key: 'NDM5Qjk2UjAzMEE0NzVCRjlFMkQwQkVGOFc1NkM1QkQ=',
  transformation: 'AES/CBC/PKCS5Padding',
  ivOffset: 0,
  ivLen: 16,
  success: (data) => {
    console.log(`handling success: ${data.text}`)
  },
  fail: (data, code) => {
    console.log(`### cipher.aes fail ### ${code}: ${data}`)
  }
})
//解密：
cipher.aes({
  action: 'decrypt',
  //待解密的内容，是base64编码后的一段二进制值
  text: '1o0kf2HXwLxHkSh5W5NhzA==\n',
  //base64编码后的密钥
  key: 'NDM5Qjk2UjAzMEE0NzVCRjlFMkQwQkVGOFc1NkM1QkQ=',
  transformation: 'AES/CBC/PKCS5Padding',
  ivOffset: 0,
  ivLen: 16,
  success: (data) => {
    this.dealTxt = data.text
  },
  fail: (data, code) => {
    prompt.showToast({
      message: ("解密失败, code=" + code + ":" + data)
    })
  }
})
```

### cipher.getRandomValues(int)（1073+）

**描述**

获取一个随机数。

**OBJECT参数**

|类型|是否必填|返回值|说明|
|:--|:---|:-----|:------------------------------------------------------------------------------------------------------------------|
|int|是|string|输入正整数，范围是1 ~ 32。表示生成的随机数二进制位数。返回一个16进制编码的字符串，全小写。 假设输入参数是3，并且生成的3位随机数是['a','b','c']，则返回值是616263。 非法参数或其他异常场景返回空字符串。|

**示例代码**

```screen
// 获取16位随机数并打印log
let r16 = cipher.getRandomValues(16);
console.log(`random16:${r16}`);
```
