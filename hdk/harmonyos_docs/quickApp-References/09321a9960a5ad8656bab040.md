# 网络请求

## 创建网络请求对象

var xmlHttp = new XMLHttpRequest();

XMLHttpRequest对象提供了对HTTP协议的完全访问，包括POST和HEAD请求以及普通的GET请求的能力。XMLHttpRequest 可以同步或异步地返回Web服务器的响应，并且能够以文本或者一个DOM文档的形式返回内容。

### XMLHttpRequest.onreadystatechange = callBack

* 描述 指定响应处理函数。

### XMLHttpRequest.open(method, url, async, username, password)

* 描述 初始化Http请求参数。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:------|:----------|:----------------------|
  |method|string|M|请求的 HTTP 方法。|
  |url|string|M|请求的主体。|
  |async|boolean|O|指示请求使用应该异步地执行。默认值为true。|
  |username|string|O|为url所需的授权提供认证资格。|
  |password|string|O|为url所需的授权提供认证资格。|


* 示例代码

  ```screen
  var xhr = new XMLHttpRequest();
  xhr.open('GET', '" + "test.php"+ "', true);
  ```

### XMLHttpRequest.setRequestHeader(name, value)

* 描述 设置请求头。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:----|:-----|:----------|:---------|
  |name|string|M|要设置的头部的名称。|
  |value|string|M|头部的值。|


* 示例代码

  ```screen
  var xhr = new XMLHttpRequest();
  xhr.setRequestHeader("Content-Type","application/x-www-form-urlencoded");
  ```

### XMLHttpRequest.send(body)

* 描述 发送HTTP请求，使用传递给open()方法的参数，以及传递给该方法的可选请求体。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:---|:--------------|:----------|:---------------|
  |body|string/document|O|string/Document。|


* 示例代码

  ```screen
  var xhr = new XMLHttpRequest();
  xhr.open('POST', '" + "test.php"+ "', true);
  xhr.send("foo=bar&lorem=ipsum");
  ```

### XMLHttpRequest.getAllResponseHeader()

* 描述 返回所有的响应头。

### XMLHttpRequest.getResponseHeader(header)

* 描述 返回指定的HTTP响应头部的值。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:-----|:-----|:----------|:---------------|
  |header|string|M|要返回的HTTP响应头部的名称。|


* 示例代码

  ```screen
  var client = new XMLHttpRequest();
  client.open("GET", "unicorns-are-teh-awesome.txt", true);
  client.send();
  client.onreadystatechange = function() {
    if(this.readyState == this.HEADERS_RECEIVED) {
      console.log(client.getResponseHeader("Content-Type"));
    }
  }
  ```

### XMLHttpRequest.abort()

* 描述 取消当前的请求。

### XMLHttpRequest.responseText

* 描述 目前为止被服务器接收到的响应体（不包括头部），或者如果还没有接收到数据的话，就是空字符串。

### XMLHttpRequest.responseXML

* 描述 返回一个包含请求检索的XML的Document对象。

### XMLHttpRequest.status

* 描述 对请求的响应，解析为XML并作为Document对象返回。

### XMLHttpRequest.statusText

* 描述 请求的HTTP的状态代码。

### XMLHttpRequest.readyState

* 描述 HTTP请求的状态。当一个XMLHttpRequest初次创建时，这个属性的值从0开始，直到接收到完整的HTTP响应，这个值增加到4。

### XMLHttpRequest.response

* 描述 返回一个 ArrayBuffer、Blob、Document，或 DOMString，具体是哪种类型取决于 XMLHttpRequest.responseType 的值。其中包含整个响应实体（response entity body）。

### XMLHttpRequest.responseType

* 描述 用于定义响应类型的枚举值（enumerated value）。

### XMLHttpRequest.responseURL

* 描述 返回经过序列化（serialized）的响应 URL，如果该 URL 为空，则返回空字符串。

### XMLHttpRequest.timeout

* 描述 一个无符号长整型（unsigned long）数字，表示该请求的最大请求时间（毫秒），若超出该时间，请求会自动终止。

### XMLHttpRequest.withCredentials

* 描述 一个布尔值，用来指定跨域Access-Control请求是否应当带有授权信息，如 cookie 或授权 header 头。

### XMLHttpRequest.overrideMimeType

* 描述 重写由服务器返回的 MIME 类型。
