# 加速计

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135253.64951381990083076713736149653464:50001231000000:2800:670514BC732CA5F1511B284B2E87E62843943FC23F7F57A5D8592974ECC159AF.png)  
从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。  

#### 接口定义

|接口|描述|
|:-------------------------------------------------------------------|:---------|
|[qg.onAccelerometerChange(function callback)](#section1853342618118)|监听加速度数据。|
|[qg.startAccelerometer(Object object)](#section6364221239)|开始监听加速度数据。|
|[qg.stopAccelerometer(Object object)](#section9650184012510)|停止监听加速度数据。|

#### qg.onAccelerometerChange(function callback)

* 描述 监听加速度数据。

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------------------------------------------------------------------------|
  |callback|function|M|加速度事件的回调函数，请参见[callback回调函数参数](#ZH-CN_TOPIC_0000001130573697__li264452815112)。|

  * callback回调函数参数  

    |参数|类型|说明|
    |:-|:-----|:---|
    |x|number|X 轴。|
    |y|number|Y 轴。|
    |z|number|Z 轴。|

* 示例代码

  ```
  qg.onAccelerometerChange(
      function callback(res){
          console.log("onAccelerometerChange x = " + res.x + ", y = " + res.y + ", z = " + res.z);
      }
  );
  ```

#### qg.startAccelerometer(Object object)

* 描述 开始监听加速度数据。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 示例代码

  ```
  qg.startAccelerometer({
          success : function () {
                  console.log("startAccelerometer success" );
          },
          fail:function(){
                  console.log("startAccelerometer fail");
          },
          complete:function() {
                  console.log("startAccelerometer complete");
          }
  });
  ```

#### qg.stopAccelerometer(Object object)

* 描述 停止监听加速度数据。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 示例代码

  ```
  qg.stopAccelerometer({
          success : function () {
                  console.log("stopAccelerometer success" );
          },
          fail:function(){
                  console.log("stopAccelerometer fail");
          },
          complete:function() {
                  console.log("stopAccelerometer complete");
          }
  });
  ```
