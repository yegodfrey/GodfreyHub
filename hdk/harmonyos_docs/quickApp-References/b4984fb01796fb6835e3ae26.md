# 二维码

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240229104010.69873448338089316726841035380075:50001231000000:2800:F8076255514F44F3AC8805CD3816520B03227BDCB664BF0F110D19664F440D51.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
该接口集成了Scan Kit的能力，会基于运营目的收集BI数据，详细内容参见"[SDK收集数据](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/scan-sdk-data-4)"。应用中使用该接口前，务必告知用户将收集部分数据，并引导用户阅读相应的隐私政策。  

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{"name": "system.barcode"}
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import barcode from '@system.barcode'
```

或

```
var barcode = require("@system.barcode")
```

#### 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

#### barcode.scan(OBJECT)

描述

扫描二维码。

OBJECT参数  

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:--------|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|cancel|function|否|取消回调。|
|complete|function|否|执行结束后的回调。|

success返回值：  

|参数名|类型|说明|
|:-----|:-----|:------|
|result|string|解析后的内容。|

fail返回错误码：  

|错误码|说明|
|:--|:-------------|
|201|用户拒绝，获取相机权限失败。|

示例代码

```
barcode.scan({
  success:function(data){
    console.log("handling success: " + data.result);
  },
  fail: function(data, code) {
    console.log("handling fail, code=" + code);
  }
})
```

  import barcode from '@system.barcode';
  import prompt from '@system.prompt';
  module.exports = {
    public: {
        codeData:"" 
    },
    onInit: function () {
      this.$page.setTitleBar({ text: 'qr code' });
    },
    scanCode(){
      let that = this;

      barcode.scan({
        success: function (data) {
          that.codeData = data.result;
        },
        fail: function (data, code) {
          console.log("handling fail, code=" + code);
          prompt.showToast({
            message: 'Callback upon failure.',
            duration: 2000,
            gravity: 'bottom'
          })
        },
        complete:function (code) {
          console.log("handling complete code: " + code);
        },
        cancel:function (code) {

        }
      })
    }
  }
</script>
