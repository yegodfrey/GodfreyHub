# 直达礼包兑换接口

#### 接口介绍

用于兑换直达礼包。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为游戏服务器 -\> 第三方应用服务器|
|性能指标|TPS\>200|
|最大响应时间|\<500ms|
|接口URL|无|
|------|--------------------|

#### 请求参数

|名称|必选(M)/可选(O)|类型|是否参与签名|描述|
|:--------|:----------|:---------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|requestId|M|String(48)|是|请求号，UUID（去分隔符）。|
|playerId|M|String(20)|是|玩家playerId。 说明： 请根据playerId查找玩家最近登录过的角色区服自行进行游戏内邮件发放。|
|giftId|M|String(24)|是|游戏内可兑换的礼包ID。|
|zoneId|O|String(36)|是|游戏内区服ID。 注意： 目前暂不支持该参数，|
|roleId|O|String(36)|是|游戏内角色ID。 注意： 目前暂不支持该参数，|
|sign|M|String|否|RSA签名，使用游戏服务公钥进行验签，待验签内容生成方法见"[签名机制](#section1217516466268)"。签名算法为SHA256WithRSA/PSS。 注意： * 考虑到自选参数格式多样化，本参数在"utf-8" urlencode后发送。 * Java中request的getParameter()方法会隐含进行urldecode。|

#### 请求示例

```
POST {第三方应用服务器url} HTTP/1.1
Content-Type : application/x-www-form-urlencoded; charset=UTF-8
requestId=550***00&playerId=144***50&giftId=11&sign=***
```

#### 响应参数

|名称|必选(M)/可选(O)|类型|描述|
|:-----|:----------|:--|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|result|M|int|操作结果： 0：表示成功（已领取时也返回成功）。 1：验签失败。 2：超时。 3：业务信息错误，比如请求重复、礼包信息错误等。 4：IP白名单限制，开发者侧拒绝服务（禁止开发者设置白名单，错误码仅用于异常监控）。 11：角色已经领取过该礼包。 12：playerId不存在，开发者侧无法根据华为提供的playerId查询到区服角色信息。 13：该礼包已领完。 94：系统错误，比如开发者服务器内部出现异常。 95：IO错误。 96：错误的URL。 97：错误的响应。 98：参数非法，比如参数的长度或空值判断校验未通过。 99：其他错误。|

#### 响应示例

```
HTTP/1.1 200 OK
Content-Type : application/json ; charset=UTF-8
{
"result":0
}
```

#### 校验签名

#### 生成签名字符串

以如下参数数组为例：

```
requestId=550***00&playerId=144***50&giftId=11&sign=***
```

1. 将请求参数中需要参与签名的参数，按参数名首字母的ASCII码将参数升序排序，若遇到相同首字母，则比较第二个字母，以此类推。需要参与签名的参数是指接口说明中"是否参与签名"列为"是"的参数。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135252.57857594076610419135647405657581:50001231000000:2800:8A2BB8D7A7907D95CEE5CAF1974FDB036E4923C428E76EAAFCAFD35BBFE153D8.png)  
   * 没有值（包括null和""情况）的参数如果出现在请求中也需要包含到待签名数据中，参与签名的格式如下：

     ```
     parametername = **
     ```

   * 只有出现在接口中的参数需要参与验签，没有出现的不参与。
2. 排序完成之后，将所有数组值（value非空）进行urlencode。
3. 将urlencode之后的所有参数名和参数值的键值对以"\&"字符连接起来，此字符串便是待签名字符串，如下列字符串所示：

   ```
   giftId=11&playerId=144***50&requestId=550***00
   ```

   生成待签名字符串的Java示例代码如下：

   ```
   public static String buildSortedSignData(Map<String, String> params) throws UnsupportedEncodingException {
       StringBuilder targetParamStr = new StringBuilder();
       Map<String, String> sortedParamMap = new TreeMap<>(params);
       for (Map.Entry<String, String> param : sortedParamMap.entrySet()) {
           String key = param.getKey();
           String value = param.getValue();
           targetParamStr.append(key)
               .append("=")
               .append(null == value ? "" : URLEncoder.encode(value, "UTF-8"))
               .append("&");
       }
       return targetParamStr.substring(0, targetParamStr.toString().length() - 1);
   }
   ```

4. 将待签名字符串使用游戏私钥按照RSA算法（SHA256WithRSA/PSS）进行签名，将签名后的字符串经过Base64编码，得到的字符串即为签名字符串。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135252.79031725819803921315314270685651:50001231000000:2800:42DD113ED972F6FCDE69487ED4A3FDA9D8469239F05C064C1BA580530D159049.png)  
   * 游戏私钥在开通游戏服务后生成，查询方法参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367)。
   * 正式上线时，示例代码中的privateKey请务必替换为AppGallery Connect上的[游戏私钥](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section16882021380)；在自行验证时，亦可将代码中的privateKey在本地代码中替换为AppGallery Connect上的[游戏私钥](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section16882021380)，用于自验证验签逻辑。
   * sign在RSA签名后需要进行Base64编码。  
   生成签名字符串的Java示例代码如下：

   ```
   public static String signWithRSA(byte[] data, String privateKey) throws Exception {
       byte[] keyBytes = Base64.decodeBase64(privateKey);
       PKCS8EncodedKeySpec pkcs8KeySpec = new PKCS8EncodedKeySpec(keyBytes);
       KeyFactory keyFactory = KeyFactory.getInstance("RSA");
       PrivateKey privateK = keyFactory.generatePrivate(pkcs8KeySpec);
       Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
       signature.initSign(privateK);
       signature.update(data);
       return Base64.encodeBase64String(signature.sign());
   }
   ```

#### 校验签名

1. 获取请求参数，[生成签名字符串](#section15458102542611)。
2. 使用游戏公钥对签名字符串进行验证。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135252.80656689093344371213425427299682:50001231000000:2800:DBEA6548D3CF10A3604FBBB30609E78EBC25730847A5C38F1B91414E7AB16789.png)  
   * 游戏公钥在开通游戏服务后生成，查询方法参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367)。
   * 正式上线时，示例代码中的publicKey请务必替换为AppGallery Connect上的[游戏公钥](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section16882021380)；在自行验证时，亦可将代码中的publicKey在本地代码中替换为AppGallery Connect上的[游戏公钥](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section16882021380)，用于自验证验签逻辑。

   校验签名的Java示例代码如下：

   ```
   public static boolean verify(byte[] data, String publicKey, String sign) throws Exception {
       byte[] keyBytes = Base64.decodeBase64(publicKey);
       X509EncodedKeySpec keySpec = new X509EncodedKeySpec(keyBytes);
       KeyFactory keyFactory = KeyFactory.getInstance("RSA");
       PublicKey publicK = keyFactory.generatePublic(keySpec);
       Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
       signature.initVerify(publicK);
       signature.update(data);
       return signature.verify(Base64.decodeBase64(sign));
   }
   ```

#### 服务端示例代码

* 验签示例代码  

  ```
  "JAVA"
  package com.huawei.game.domain.develop.test;
  import org.apache.commons.codec.binary.Base64;
  import java.io.UnsupportedEncodingException;
  import java.net.URLEncoder;
  import java.nio.charset.StandardCharsets;
  import java.security.KeyFactory;
  import java.security.PublicKey;
  import java.security.Signature;
  import java.security.spec.X509EncodedKeySpec;
  import java.util.HashMap;
  import java.util.Map;
  import java.util.TreeMap;
  public class SecretVerifyTest {
      public static void main(String[] args) throws Exception {
          // 以下公钥和私钥为临时生成，以供展示代码示例，正式环境请替换
          String publicKey = "MIIBIjANBgkqh*****AB";
          String privateKey = "MIIEvAIBADANB*****==";
          System.out.println("公钥：" + publicKey);
          System.out.println("私钥：" + privateKey);
          // 模拟入参
          HashMap<String, String> reqMap = new HashMap<>();
          // 验签步骤
          // 1. 从请求中取出sign属性，注意：待验签的字符串不包含sign属性，此时需要从Map中取出。
          String reqSign = reqMap.remove("sign");
          System.out.println("加签结果：" + reqSign);
          // 2. 生成待验签的字符串。
          String targetStr = buildSortedSignData(reqMap);
          System.out.println("加签的字符串：" + targetStr);
          // 3. 进行验签，注意：此处验签的公钥需要修改为AGC管理台上的公钥。
          boolean result = verify(targetStr.getBytes(StandardCharsets.UTF_8), publicKey, reqSign);
          System.out.println("验签结果为：" + result);
      }
      /**
       * 生成待签名的字符串
       *
       * @param params 入参
       * @return 待签名的字符串
       */
      public static String buildSortedSignData(Map<String, String> params) throws UnsupportedEncodingException {
          StringBuilder targetParamStr = new StringBuilder();
          Map<String, String> sortedParamMap = new TreeMap<>(params);
          for (Map.Entry<String, String> param : sortedParamMap.entrySet()) {
              String key = param.getKey();
              String value = param.getValue();
              targetParamStr.append(key)
                  .append("=")
                  .append(null == value ? "" : URLEncoder.encode(value, "UTF-8"))
                  .append("&");
          }
          return targetParamStr.substring(0, targetParamStr.toString().length() - 1);
      }
      /**
       * 验签结果
       *
       * @param data 待验签的字符串
       * @param publicKey 公钥
       * @param sign 签名字符串
       * @return 验签结果
       */
      public static boolean verify(byte[] data, String publicKey, String sign) throws Exception {
          byte[] keyBytes = Base64.decodeBase64(publicKey);
          X509EncodedKeySpec keySpec = new X509EncodedKeySpec(keyBytes);
          KeyFactory keyFactory = KeyFactory.getInstance("RSA");
          PublicKey publicK = keyFactory.generatePublic(keySpec);
          Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
          signature.initVerify(publicK);
          signature.update(data);
          return signature.verify(Base64.decodeBase64(sign));
      }
  }
  ```
