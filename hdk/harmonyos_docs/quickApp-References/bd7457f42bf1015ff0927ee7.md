# 支付宝支付

> 注意
>
> 该功能依赖第三方SDK提供服务，第三方SDK可能会收集用户的个人数据。应用中请务必在使用该功能前，告知用户将收集个人数据，并引导用户阅读相应的隐私政策。

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "service.alipay"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import alipay from '@service.alipay'
```

或

```screen
var alipay = require("@service.alipay")
```

## 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|中国大陆|

## 接口定义

|接口|描述|
|:-----------------------------------------|:---------|
|[alipay.pay(OBJECT)](#section393122434720)|使用支付宝完成支付。|

### alipay.pay(OBJECT)

**描述**

使用支付宝完成支付。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:--------|:-------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------|
|orderInfo|string|是|服务端生成的订单信息，参见支付宝的"[请求参数说明文档](https://doc.open.alipay.com/doc2/detail.htm?spm=a219a.7629140.0.0.x7kkCI&treeId=204&articleId=105465&docType=1)"。|
|callback|function|否|支付结果回调，格式参见支付宝的"[通知参数说明文档](https://doc.open.alipay.com/doc2/detail.htm?spm=a219a.7629140.0.0.xN1NnL&treeId=204&articleId=105302&docType=1)"。|
|fail|function|否|失败回调。|

**示例代码**

```screen
alipay.pay({
  orderInfo: "partner=\"2088611359395958\"&seller=\"2088611359395958\"&out_trade_no=\"201320148794006836322946\"&subject=\"支付金额 29.99 元\"&body=\"支付金额 29.99 元\"&total_fee=\"29.99\"&notify_url=\"https%3A%2F%2Fgw.pay.xiaomi.com%2Fnotify%2Fucashier%2F201320148794006836322946%2F0048002\"&sign_type=\"RSA\"&itbpay=\"1440m\"&sign=\"nKDHQigYsBKlBQQ2CDSdSKXlCwzjjaFLWiihjUNx1X1S2d5qP6mPavZG7le9ty2GdPi7958iOQw76bhALOdUO2Vn2pxIUPwTLWQ%2FUH9h5sp7gTTrjAOEWsDEIJSrJ0%2FLl4GtnBtYEWr0dL23gmbV0IcnqXWsNOGi5XDnfqs4IAw%3D\"",
  callback: function(ret) {
    console.log("handling callback");
  },
  fail: function (data, code) {
    console.log("Alipay handling fail, code=" + code);
  },
});
```
