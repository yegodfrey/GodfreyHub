qa.getExtConfig（1105+） 接口描述获取ext配置信息。 使用限制 限制条件 | 说明  
---|---  
适用终端 | 手机、平板  
适用区域 | 全球  
接口定义 [h2]qa.getExtConfig(Object)**描述** 获取ext配置信息。 **OBJECT参数** 参数 | 类型 | 是否必填 | 描述  
---|---|---|---  
success | function | 否 | 成功回调。  
fail | function | 否 | 失败回调。  
complete | function | 否 | 执行结束后的回调。  
**success****返回值** 参数 | 类型 | 描述  
---|---|---  
extConfig | Object | 第三方平台自定义的数据。  
**示例代码**
    
    qa.getExtConfig({
        success: function(data) {
           console.log('getShareAvailablePlatforms' + JSON.stringify(data))
        },
        fail: function(data, code) {
           console.log('getShareAvailablePlatforms1' + JSON.stringify(data))
        }
    })
