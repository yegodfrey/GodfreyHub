# 字体

从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。  

#### 接口定义

|接口|描述|
|:-------------------------------------------------------------------|:---------|
|[qg.getTextLineHeight(Object object)](#section14168124717522)|获取一行文本的行高。|
|[qg.loadFont(string fontFamily, string path)](#section1017117474521)|加载自定义字体文件。|

#### qg.getTextLineHeight(Object object)

* 描述 获取一行文本的行高。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:---------|:-------|:----------|:------------------------------|
  |fontStyle|string|O|字体样式： * normal：正常。 * italic：斜体。|
  |fontWeight|string|O|字体粗细： * normal：正常。 * bold：粗体。|
  |fontSize|number|O|字号。|
  |fontFamily|string|M|字体名称。|
  |text|string|M|文本的内容。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 返回参数 文本的行高（number类型）。

* 示例代码

  ```
  var height = qg.getTextLineHeight({
          "fontStyle": "italic",
          "fontWeight": "bold",
          "fontSize": "20",
          "fontFamily": "Arial",
          "text": "test",
          "success": function(h){
                  console.log("getTextLineHeight:" + h)
          },
          "fail": function(msg){
                  console.log("getTextLineHeight fail:" + msg)
          },
          "complete": function(){
                  console.log("getTextLineHeight complete")
          }
  });
  ```

#### qg.loadFont(string familyName, string path)

* 描述 加载自定义字体文件。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:---------|:-----|:----------|:-----------------------------------------------------|
  |familyName|string|O|字体family值。|
  |path|string|M|字体文件路径。可以是代码包文件路径，也可以是qg.env.USER_DATA_PATH + ${文件地址}。|

<!-- -->

* 返回参数 若加载字体成功，则返回字体family值（String型），否则返回null。

<!-- -->

* 示例代码

  ```
  var userFilePath = `${qg.env.USER_DATA_PATH}/writer.ttf`;  //userFilePath 是手机路径（字体文件可以是从远程目录下载后存储在本地）
  var rpkFilePath = "font/writer.ttf" //代码路径

  //字体在代码包中，双参数
  var font = qg.loadFont("Arial"，rpkFilePath)
  //字体在本地，双参数
  var font = qg.loadFont("Arial"，userFilePath);

  //字体在代码包中，单参数
  var font = qg.loadFont(rpkFilePath)
  //字体在本地，单参数
  var font = qg.loadFont(userFilePath);
  ```
