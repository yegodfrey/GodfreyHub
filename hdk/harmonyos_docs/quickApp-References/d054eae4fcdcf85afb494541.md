# ad-template（1113+）

#### 概述

用来展示鲸鸿动能原生模板广告内容的组件。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813173003.34682761485772212087429430827136:50001231000000:2800:AD8017EACB06D4B59890B66BFF6D0F04110A37937A227B4CE5D3CB6C3A7CE338.png)  
1. 开发需要先基于ad.createNativeAd创建并load（必须设置新增的参数supportTemplate为true）成功后再去创建ad-template组件，且在onLoad中返回的广告类型为99(creativeType为99)时创建，否则无法渲染对应的广告。且一个adId只应绑定一个ad-template组件，此处可参考[广告接口文档](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667)中的原生广告接口。
2. 原生广告creativeType为99时，该广告对象只能用于绑定模板广告，请勿调用nativeAd.reportAdShow()、nativeAd.reportAdClick()、nativeAd.showAppDetailPage()和nativeAd.destroy()接口或绑定ad-button和ad-native-view组件，以免影响您的计费。  

#### 子组件

不支持。  

#### 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-attributes-0000001170050123)以外，还支持如下属性。  

|名称|类型|默认值|是否必填|描述|
|:---|:-----|:--|:---|:------------------|
|adid|string|-|是|广告信息标识，由onload回调返回。|

#### 样式

有限制地支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-common-styles-0000001170210009) （不支持background和background-image，不支持padding,padding-left,padding-right,padding-top,padding-bottom，不支持opacity样式，不支持transform:scale,transform:scaleX,transform:scaleY动画样式），受限制的通用样式如下：  

|名称|类型|默认值|是否必填|描述|
|:-------------------|:---------|:-----|:---|:--------------------------------------------|
|background-color|\<color\>|无|否|组件背景颜色，当设置成rgba或者hsla类型颜色值时，透明度通道设置无效，指定为不透明。|
|height|\<length\>|无|否|组件高度，取值范围：不小于590px。|
|width|\<length\>|无|否|组件宽度，取值范围：不小于650px。|
|border-radius(1118+)|\<length\>|33.5px|否|组件圆角，建议设置为33.5px。|

建议宽高：  

|广告类型|样式|建议宽高|
|:---|:---|:--------------------------|
|原生模板|原生插屏|width:650px ; height:590px。|
|原生模板|原生插页|width:650px ; height:933px。|

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250813173003.19694047121115348436326620882406:50001231000000:2800:AA8EF663E16221A136F5E8FB15732B3AB668179BEADEAAB5C6D8656B0A54C41E.png)  
1. 该组件必须完整对用户可见，不应被任何元素覆盖或遮挡（包括透明元素），否则可能影响计费。
2. 请设置组件宽高为建议宽高，如果未设置宽高，当广告内容填充时，ad-template组件宽高会填充为父组件的宽高。
3. 该组件必须完全在屏幕范围内。  

#### 事件

除了支持 [通用事件](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-events-0000001123530338)以外，还支持如下事件。  

|名称|参数|描述|
|:------------------|:-----------------------------------------------------------------------|:-------------------------------------------------------------------------------------------|
|error|{code:codeInteger,description:descriptionString}|广告加载失败。|
|render|-|广告加载成功。|
|feedback|{eventName: ""}|用户点击了广告反馈按钮。 like:用户喜欢。 dislike:用户不喜欢。 close:关闭。 其中dislike与close强行清除广告对应的广告内容，广告组件交给开发者进行处理。|
|downloadStatus|{packageName:packageNameValue,status:statusValue,progress:progressValue}|adid:广告标识；status：下载状态；progress：下载进度，范围0\~100。|
|adclick(1116+)|{adid:""}|广告点击事件|
|adimpression(1117+)|{adid:""}|广告曝光事件|
