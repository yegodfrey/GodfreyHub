#### var webSocket = new WebSocket(url, \[protocol\] );

* 描述 创建WebSocket对象。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-----|:----------|:---------|
  |url|string|M|指定连接的URL。|
  |protocol|array|O|指定可接受的子协议。|

<!-- -->

* 示例代码

  ```
  createWebSocket(item, url, request, response, protocol, cert) {
          let ws = new WebSocket(url, protocol, cert);
          ws.onopen = function () {
              item.addEvent("open");
              request(ws);
          };
          ws.onmessage = function (evt) {
              item.addEvent("message");
              response(evt.data);
          };
          ws.onerror = function (evt) {
              item.addEvent("error");
              item.setState(TEST_STATE.ERROR);
          };
          ws.onclose = function () {
              item.addEvent("close");
          };
          item.setState(TEST_STATE.RUNNING);
          return ws;
      }
  ```

#### close(code, reason)

* 描述 关闭WebSocket连接。

<!-- -->

* 参数  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-----|:-----|:----------|:-------------------|
  |code|number|O|一个数字值，表示关闭连接的状态号。|
  |reason|string|O|一个可读的字符串，表示连接被关闭的原因。|

#### webSocket.protocol

* 描述 返回实例对象使用的协议。

#### webSocket.readyState

* 描述 返回实例对象的当前状态的状态码。

* 状态码  

  |状态码|值|意义|
  |:---------|:-|:---------------|
  |CONNECTING|0|正在连接。|
  |OPEN|1|连接成功，可以通信。|
  |CLOSING|2|连接正在关闭。|
  |CLOSED|3|连接已经关闭，或者打开连接失败。|

#### webSocket.url

* 描述 连接的URL。
