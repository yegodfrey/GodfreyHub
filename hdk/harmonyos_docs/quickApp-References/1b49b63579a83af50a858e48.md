# tabs

## 概述

tab容器。

## 使用限制

|限制条件|说明|
|:---|:-------|
|适用终端|手机、平板、车机|
|适用区域|全球|

## 子组件

仅支持最多一个 <tab-bar> 和最多一个 <tab-content>。<tab-content> 暂不支持动态增加，否则可能出现内容错乱的现象。

## 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-attributes-0000001170050123)以外，还支持如下属性。

|名称|类型|默认值|是否必填|描述|
|:----|:-----|:--|:---|:--------------|
|index|number|0|否|当前active tab索引。|

## 样式

支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-common-styles-0000001170210009)。

## 事件

不支持swipe事件，除了支持 [通用事件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-events-0000001123530338) 以外，还支持如下事件。

|名称|参数|描述|
|:-----|:------------------|:------------------|
|change|{index: indexValue}|tabs子组件active变化时触发。|

## 示例代码

```screen
<template>
    <div class="container">
        <tabs class="tabs" onchange="changeTabactive" index="2">
            <tab-bar class="tab-bar">
                <text class="tab-text">tab1</text>
                <text class="tab-text">tab2</text>
                <text class="tab-text">tab3</text>
            </tab-bar>
            <tab-content class="tab-content" scrollable="{{scrollable}}">
                <div class="item-container">
                    <div class="item-content">
                        <text class="item-title">tab1 page</text>
                    </div>
                </div>
                <div class="item-container">
                    <div class="item-content">
                        <text class="item-title">tab2 page</text>
                    </div>
                </div>
                <div class="item-container">
                    <div class="item-content">
                        <text class="item-title">tab3 page</text>
                    </div>
                </div>
            </tab-content>
        </tabs>
    </div>
</template>
<style>
    .tabs {
        flex: 1;
        margin-top: 20px;
        margin-right: 30px;
        margin-left: 30px;
        background-color: #ffffff;
    }
    .tab-content {
        flex: 1;
    }
    .tab-bar {
        height: 100px;
        border-color: #bbbbbb;
        color: #bbbbbb;
        border-bottom-width: 1px;
    }
    .tab-text {
        width: 300px;
        text-align: center;
    }
    .tab-text:active {
        color: #f76160;
    }
    .item-container {
        padding-top: 30px;
        padding-left: 30px;
        padding-right: 30px;
        flex-direction: column;
    }
    .item-content {
        flex-direction: column;
        padding-bottom: 30px;
    }
    .item-title {
        padding-top: 50px;
        padding-bottom: 20px;
        color: #aaaaaa;
    }
</style>
<script>
    import prompt from '@system.prompt'
    export default {
        data: {
            scrollable: true,
        },
        onInit: function () {
            this.$page.setTitleBar({ text: 'tabs' })
        },
        changeTabactive: function (e) {
            prompt.showToast({
                message: this.$t('message.component.tabs.range') + e.index + this.$t('message.component.tabs.page')
            })
            // switch tab
            console.log('----------switch tab: ' + e.index);
        },
    }
</script>
```
