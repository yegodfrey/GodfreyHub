# section-header（1090+）

## 概述

<section-group>的子组件。<section-header>是每个分组的头部，支持 flex 布局，不支持 position。

<section-header>必须依附在<section-group>上，不可单独存在。点击<section-header>可以展开或折叠对应<section-group>的子<section-item>和子<section-group>。

## 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

## 子组件

支持。

## 样式

支持[通用样式](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-common-styles-0000001170210009)。

## 事件

不支持click事件，支持其他[通用事件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-events-0000001123530338)。
