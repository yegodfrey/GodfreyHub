# 剪贴板

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135254.99415063031912429828211571816677:50001231000000:2800:772BA9DA0C76BE739518F978411D80B8E6EAA70D2B0A1F0D00495FCA366B891F.png)  
从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。  

#### 接口定义

|接口|描述|
|:-----------------------------------------------------------|:----------|
|[qg.getClipboardData(Object object)](#section18307358141320)|获取系统剪贴板的内容。|
|[qg.setClipboardData(Object object)](#section1710725510154)|设置系统剪贴板的内容。|

#### qg.getClipboardData(Object object)

* 描述 获取系统剪贴板的内容。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-----------------------------------------------------------------------------|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000001084194210__li171967211564)。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数|类型|说明|
    |:---|:-----|:------|
    |data|string|剪贴板的内容。|

* 示例代码

  ```
  qg.getClipboardData({
          success : function (object) {
                  console.log("getClipboardData success data = " + object.data );
          },
          fail:function(){
                  console.log("getClipboardData fail");
          },
          complete:function() {
                  console.log("getClipboardData complete");
          }
  });
  ```

#### qg.setClipboardData(Object object)

* 描述 设置系统剪贴板的内容。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |data|string|M|剪贴板的内容。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 示例代码

  ```
  qg.setClipboardData({
          data : 'string',
          success : function () {
                  console.log("setClipboardData success" );
          },
          fail:function(){
                  console.log("setClipboardData fail");
          },
          complete:function() {
                  console.log("setClipboardData complete");
          }
  });
  ```
