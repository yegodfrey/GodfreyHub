# 文本翻译（1077+）

本文档仅介绍接口的定义，接口详细的使用顺序和场景，请参见"[文本翻译](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-access-ml-translate-0000001090073204)"。  

#### 接口声明

在manifest.json文件的 features属性中增加如下配置。

```
{"name": "service.ml.translate"}
```

#### 导入模块

在调用接口页面的\<script\>部分增加如下配置。

```
import translate from '@service.ml.translate'
```

或

```
var translate = require("@service.ml.translate")
```

#### translate.translate(OBJECT)（1077+）

描述

进行文本翻译，在回调中获取翻译结果。

参数  

|参数|类型|是否必填|说明|
|:-----------------|:-------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|string|是|[获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-get-agconnectfile-0000001117853750)中的app_id。|
|apiKey|string|是|[获取agconnect-services.json文件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-get-agconnectfile-0000001117853750)中的api_key。 请妥善保管apiKey、设置apiKey，详细请参见"[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides-V5/sdk-data-security-0000001050040129-V5#section2688102310166)"。|
|sourceLanguageCode|string|否|设置翻译源语言的编码，使用ISO 639-1标准 （中文繁体使用BCP-47标准，zh-HK），例如"zh"。若不设置，将自动检测语种进行翻译。|
|targetLanguageCode|string|是|设置目标语言的编码，使用ISO 639-1标准 （中文繁体使用BCP-47标准，zh-HK），例如"en"。|
|sourceText|string|是|需要翻译的文本，每次翻译最多支持5000个字符。输入数据格式为UTF-8。|
|success|function|是|回调方法，返回1个String参数，表示翻译后的语言文本。|
|fail|function|否|回调方法，识别发生错误后调用该接口。|

success返回值  

|参数|类型|说明|
|:---|:-----|:--------|
|text|string|翻译后的语言文本。|

fail返回错误码  

|错误码|说明|处理建议|
|:--|:-----------------------|:----|
|-1|未知类型错误。|-|
|0|服务正常运行。|-|
|1|操作被取消。|-|
|2|内部错误。|-|
|3|当前服务不可用。|-|
|4|不支持的操作，可能是接口未实现或当前版本不支持。|-|
|5|错误参数，表示参数本身错误，与服务无关。|修改参数。|
|6|操作超时，在设定的截止时间之前，操作未完成。|-|
|7|请求的资源未发现或不存在。|-|
|8|想要创建的资源已经存在，不需要重复创建。|-|
|9|没有权限操作。|-|
|10|资源耗尽，可能是系统资源或当前用户的资源不足。|-|
|11|由于系统未准备就绪，导致操作失败。|-|
|12|操作被打断，可能是并发导致中止。|-|
|13|跨界限操作，试图请求有效范围外的操作。|-|

示例代码

```
translate.translate({ //启动语音识别
    appId: '开发者申请的appId', //String 参数，必填
    apiKey: '开发者申请的apiKey', //String 参数，必填，鉴权，设置apiKey
    sourceLanguageCode: 'zh', //String 参数，设置翻译源语言的编码，使用ISO 639-1标准（中文繁体使用BCP-47标准，zh-HK），例如”zh”。若不设置，将自动检测语种进行翻译
    targetLanguageCode: 'en', //String 参数，设置目标语言的编码，使用ISO 639-1标准（中文繁体使用BCP-47标准，zh-HK），例如”en”。
    sourceText: '我是中国人', //String 参数，需要翻译的文本，每次翻译最多支持5000个字符。输入数据格式为UTF-8。
    success: (text) => { //回调方法，返回文本。
        console.log(text);
    },
    fail: (errMsg, errorCode) => { //失败回调，识别发生错误后调用该接口
        console.log("error:", errMsg);
    },
});
```
