# 应用上下文

## 接口声明

无需声明

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import app from '@system.app' 
```

或

```screen
var app = require("@system.app")
```

### app.getInfo()

**描述**

获取当前应用信息。

**返回值**

|参数|类型|说明|
|:-----------------|:-----|:---------------------------------------|
|name|string|应用名称。|
|versionName|string|应用版本名称。|
|versionCode|number|应用版本号。|
|logLevel|string|log级别。|
|source|object|应用来源。|
|icon(1045+)|string|manifest文件中配置的应用图标路径。例如：/common/logo.png|
|packageName(1045+)|string|应用包名。|

**source说明：**

|参数|类型|说明|
|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|packageName|string|来源 app 的包名，一级来源。|
|type|string|来源类型，二级来源，包括： * shortcut：桌面图标 * push：push消息推送 * url：网页跳转 * barcode：扫描二维码 * nfc：NFC接入 * bluetooth：连接蓝牙 * other：其他|
|extra|object|来源其他信息，与 type 相关，不同的 type，extra 中的字段会不同。 当 type=shortcut 时，extra的信息如下： * scene：三级来源，表示快捷方式创建的场景，值为 dialog（平台内部策略Dialog弹窗创建）、api（API接口调用创建）、web（H5站接入流量切换，浏览时创建）、other * original：原始来源 source，表示快捷方式创建时的来源。|

> 注意
>
> 使用华为快应用调试器调试时，不会返回packageName和type属性值，正式上线后可以返回。

**示例代码**

```screen
console.log("App getInfo:"+ JSON.stringify(app.getInfo()));
```

输出结果如下所示：

```screen
App getInfo:{
    "versionName":"1.0.0",
    "icon":"/Common/logo.png",
    "source":{
        "type":"unknown",
        "packageName":"unknown"
    },
    "versionCode":1,
    "logLevel":"debug",
    "name":"HelloWorld"
}
```

### app.getPackageInfo(OBJECT)（1050+）

**描述**

获取本地已安装应用信息，快应用场景下可以同时查询本地原生应用和快应用的信息，卡片场景下只能查询原生应用的信息。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:----------|:-------|:---|:-----------------|
|packageName|string|是|需要查询的快应用或者原生应用的包名。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:----------|:-----------|:-----------------------------|
|versionName|string|应用版本名称。|
|versionCode|number|应用版本号。|
|signatures|list<string>|应用的签名列表，使用 SHA-256 加密的数据发布方签名。|

**fail返回错误码：**

|错误码|说明|
|:---|:-----|
|200|一般性错误。|
|202|参数错误。|
|1000|应用未安装。|

### app.createQuickAppQRCode(OBJECT)（1090+）

**描述**

生成当前应用的分享二维码。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:----------|
|path|string|否|页面路径，可携带参数。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:--|:-----|:-------|
|uri|string|二维码文件地址。|

**fail返回错误码：**

|错误码|说明|
|:--|:-----|
|200|一般性错误。|

**示例代码**

```screen
app.createQuickAppQRCode({
  path: '/interface/basic/router/detail',
  success: (data) => {
    this.packageInfo = JSON.stringify(data)
    this.srcUrl = data.uri;
    console.info('createQuickAppQRCode success', JSON.stringify(data))
  },
  fail: (errormsg, errorcode) => {
    this.packageInfo = 'get fail --- ' + errorcode + ':' + errormsg
    console.info('get fail --- ' + errorcode + ':' + errormsg)
  },
  complete: () => {
    console.info('get complete.')
  }
})
```

### app. getUpdateManager()（1105+）

**描述**

获取应用更新管理器对象，返回UpdateManager。

### UpdateManager.applyUpdate()（1105+）

**描述**

强制重启快应用并使用新版本。在快应用新版本下载完成后调用，即收到[onUpdateReady](#section45847253239)回调时调用。

**返回值**

|错误码|说明|
|:--|:---------|
|200|执行更新成功。|
|201|当前更新版本未就绪。|
|202|重复调用。|

### UpdateManager.onCheckForUpdate(function listener)（1105+）

**描述**

用于监听快应用检查更新的结果。快应用在每次启动时将自动检查更新。

**回调参数**

|参数名称|类型|说明|
|:--------|:------|:----------------------------------------|
|hasUpdate|boolean|检查是否有新的版本，不需要等待版本下载结果。 参数值为false表示检查更新失败。|

### UpdateManager.onUpdateReady(function listener)（1105+）

**描述**

新版本下载成功时进行回调。快应用版本更新后，客户端将主动触发下载新版本。

**返回值**

|参数名称|类型|说明|
|:-------------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|currentVersion|String|当前版本号，即manifest中的[versionCode](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621#ZH-CN_TOPIC_0000001073698621__p11799157154117)。|
|newVersion|String|检测到更新的版本。|

### UpdateManager.onUpdateFailed(function listener)（1105+）

**描述**

新版本下载失败时进行回调。快应用版本更新后，客户端将主动触发下载新版本。

**回调参数**

|参数名称|类型|说明|
|:-------------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|code|int|新版本下载失败错误码，详细请参见"[code说明](#ZH-CN_TOPIC_0000001074404884__p3757184141811)"。|
|msg|String|新版本下载失败描述。|
|currentVersion|String|当前版本号，即manifest中的[versionCode](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621#ZH-CN_TOPIC_0000001073698621__p11799157154117)。|
|newVersion|String|检测到更新的版本。|

**code说明**

|取值|说明|
|:---|:--------------|
|1001|更新的版本与当前版本证书冲突。|
|1002|rpk大小超出限制。|
|1003|网络问题，下载更新失败。|
|1004|IO错误，写文件失败。|

**示例代码**

```screen
    getUpdateManager() {
      this.updatemanger = system.getUpdateManager()
    },
    applyUpdate() {
      const result = this.updatemanger.applyUpdate()
      console.log("apply result = " + result);
    },
    onCheckForUpdate() {
      this.updatemanger.onCheckForUpdate(function (res) {
        console.log("onCheckForUpdate = " + JSON.stringify(res));
      })
    },
    onUpdateSuccess() {
      this.updatemanger.onUpdateReady(function (res) {
        console.log("onUpdateReady = " + JSON.stringify(res));
      })
    },
    onUpdateFailed() {
      this.updatemanger.onUpdateFailed(function (res) {
        console.log("onUpdateFailed = " + JSON.stringify(res));
      })
    },
```
