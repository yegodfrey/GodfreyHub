ad-button（1101+） 概述原生广告组件，用于下载原生广告中的广告主App。 使用限制 限制条件 | 说明  
---|---  
适用终端 | 手机、平板、智慧屏、车机  
适用区域 | 全球  
子组件不支持。 属性![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507142411.63840918213931930165542931861588:50001231000000:2800:3E4DAE658DE28F034ECED05D220BD16405386011FEE20869DBE1578AE47E91C9.png) 可通过valuetype和open-type指定文案类型。 名称 | 类型 | 默认值 | 是否必填 | 描述  
---|---|---|---|---  
adid | string | - | 是 | 广告信息标识，调用[nativeAd.onLoad](https://developer.huawei.com/consumer/cn/doc/quickApp-References/webview-api-hwads-0000001309497712#section1528411518185)，在回调中获取。  
adunitid | string | - | 是 | 原生广告位标识，即调用[qa.createNativeAd](https://developer.huawei.com/consumer/cn/doc/quickApp-References/webview-api-hwads-0000001309497712#section443419211957)创建原生广告时传入的广告位标识。 说明： 一个adunitid只能绑定在一个ad-button组件上。  
valuetype | number | 0 | 否 | 按钮安装文案预置类型，仅在中国大陆支持。 valuetype设置值对应文案如下：
    * 0：安装
    * 1：下载并领取
    * 2：安装并领取
    * 3：安装并收下
    * 4：安装并兑换
    * 5：立即下载领取
    * 6：下载并解锁
    * 7：立即下载查看
    * 8：下载立即阅读
    * 9：下载解锁精彩章节
    * 10：安装并领取
    * 11：快速安装
    * 12：安装并提现  
open-type(1106+) | number | 0 | 否 | 按钮打开文案预置类型，仅在中国大陆支持。 open-type设置值对应文案如下：
    * 0：打开
    * 1：打开并领取
    * 2：打开查看
    * 3：打开并解锁
    * 4：立即打开
    * 5：打开应用
    * 6：打开APP  
bindtap | eventhandle | - | 否 | 点击时触发，event.detail = {resultCode} 。 resultCode是number类型，数值含义如下：
    * 0：调用应用开始下载或重启下载方法成功的标识。
    * -1：由于参数错误导致调用应用开始下载或重启下载失败的标识，如：素材为非应用下载类广告。
    * -2：由于无下载权限导致调用应用开始下载或重启下载失败的标识。
    * -3：无网络。  
install-text-value(1103+) | string | - | 否 | 按钮安装文案。 1106版本该属性已废弃，设置无效。  
open-text-value(1103+) | string | - | 否 | 按钮打开文案。 1106版本该属性已废弃，设置无效。  
progressbar-color(1103+) | color | - | 否 | 下载过程中按钮的进度条颜色。 说明： 当设置成rgba或者hsla类型颜色值时，从1106版本开始透明度设置无效，指定为不透明。  
progressbar-background-color(1103+) | color | - | 否 | 下载过程中按钮的背景颜色。 说明： 当设置成rgba或者hsla类型颜色值时，从1106版本开始透明度设置无效，指定为不透明。  
progressbar-text-color(1103+) | color | #000000 | 否 | 下载过程中按钮的文案颜色。 说明： 当设置成rgba或者hsla类型颜色值时，从1106版本开始透明度设置无效，指定为不透明。  
样式![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507142411.12587134304338027686444094161429:50001231000000:2800:0100DDF8DB1B2A133656FC6626AAD3A2EB16AFAEF53110D1DCBDA57AD95C76D3.png) 样式限制：
    * 组件宽高不支持设置百分比。
    * 字体大小、宽高若设置为非法值，会按默认值处理。
    * 字体大小、宽高若设置比最小值小，则按照最小值取值；比最大值大，则按照最大值取值。
名称 | 类型 | 默认值 | 是否必填 | 描述  
---|---|---|---|---  
font-size | number | 18px | 否 | 文本尺寸。按钮文本字体大小。取值范围：12px~54px  
width | length | 65px | 否 | 组件宽度。取值范围：不小于55px，最大不能超过屏幕宽度。  
height | length | 32px | 否 | 组件高度。取值范围：15px~90px  
border-radius(1103+) | length | 42px | 否 | 组件圆角，不支持设置百分比。  
color(1103+) | color | #FFFFFF | 否 | 按钮初始文案颜色。当background-color和color值过于相似时，这两个字段设置的值无效。 说明： 当设置成rgba或者hsla类型颜色值时，从1106版本开始透明度设置无效，指定为不透明。  
background-color(1103+) | color | #0A59F7 | 否 | 按钮初始背景颜色。当background-color和color值过于相似时，这两个字段设置的值无效。 说明： 当设置成rgba或者hsla类型颜色值时，从1106版本开始透明度设置无效，指定为不透明。

    2. 该组件必须完全在屏幕范围内，否则无法触发下载

    // page.js
    let nativeAd 
    Page({
      data: {
        logs: [],
        native: {
          adUnitId: 'testy63txaom86',
          isShow: false,
          adData: {},
          isShowImg: false,
          isShowVideo: false,
          isShowData: false,
          errStr: '',
          adImgSrc: 'http://cs02-pps-drcn.dbankcdn.com/cc/creative/upload/20191226/b750592e-04be-4132-9971-52494b1e5b43.jpg',
          adVideoSrc: ''
        },
        valuetype: 0
      },
      onLoad: function () {},
      showNativeAd () {
        nativeAd = qa.createNativeAd({ adUnitId: this.data.native.adUnitId })
        nativeAd.onLoad((data) => {
          console.info('ad data loaded: ' + JSON.stringify(data))
          this.setData({
            ['native.adData']: data.adList[0]
          })
          if (this.data.native.adData) {
            if (this.data.native.adData.imgUrlList) {
              this.setData({
                ['native.adImgSrc']: this.data.native.adData.imgUrlList[0],
                ['native.isShowImg']: true
              })
            } else {
              this.setData({
                ['native.isShowImg']: false,
                ['native.adImgSrc']: ''
              })
            }
    
            let showVideoFlag = false
            if (this.data.native.adData.videoUrlList && this.data.native.adData.videoUrlList[0]) {
              showVideoFlag = true
              this.setData({
                ['native.adVideoSrc']: this.data.native.adData.videoUrlList[0]
              })
            } else {
              this.setData({
                ['native.isShowVideo']: false,
                ['native.adVideoSrc']: ''
              })
            }
    
            if (this.data.native.isShowImg && showVideoFlag) {
              setTimeout(() => {
                console.log('show video')
                this.setData({
                  ['native.isShowVideo']: true,
                  ['native.isShowImg']: false
                })
              }, 1000)
            }
          }
          this.setData({
            ['native.isShow']: true,
            ['native.errStr']: ''
          })
        })
        const errEvent = (e) => {
          console.error('load ad error:' + JSON.stringify(e))
          this.setData({
            ['native.isShowImg']: false,
            ['native.isShowVideo']: false,
            ['native.errStr']: JSON.stringify(e),
          })
        }
        nativeAd.onError(errEvent)
        nativeAd.load()
      },
      startButton (e) {
        console.log('startButton e.resultCode = '+ e.resultCode)
      },
      reportNativeClick () {
        console.log('reportNativeClick')
      },
      changeValueType: function (e) {
        this.setData({
          valuetype: 1
        })
      }
    })
