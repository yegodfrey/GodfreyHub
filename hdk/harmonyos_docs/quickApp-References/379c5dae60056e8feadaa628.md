# 应用内支付3.0

> 注意
>
> 该功能依赖 IAP SDK 提供服务，IAP SDK 可能会收集用户的个人数据。请在快应用中使用该功能之前，告知用户将搜集个人数据，并引导用户阅读相应的隐私政策。
> 说明
>
> 本文档仅介绍接口的定义，接口详细的使用顺序和场景，请参见"[接入应用内支付服务3.0](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-access-iap-kit-0000001099300540)"。

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "service.pay"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import pay from '@service.pay'
```

或

```screen
var pay = require("@service.pay")
```

## 使用限制

|限制条件|说明|
|:---|:--------|
|适用终端|手机、平板、智慧屏|
|适用区域|全球|

### pay.getProvider(OBJECT)

**描述**

获取服务提供商。

**返回值**

字符串，服务提供商的代号，如厂商的英文品牌名称，如果无此服务则返回空字符串。返回空字符串时，请勿调用该服务其他接口，否则将抛出异常。

**示例代码**

```screen
pay.getProvider();
```

### pay.obtainOwnedPurchases(OBJECT)

**描述**

查询用户所有已订购商品信息，商品包括消耗商品、非消耗商品和订阅类商品。

* 若返回消耗型商品信息，说明可能存在因某些异常而导致未进行发货的情况，应用需判断是否有发货。如果没有发货，则需要进行补发货处理，并调用 [pay.consumeOwnedPurchase](#section2946161093810) 接口进行消耗处理。
* 若返回非消耗型商品信息，则无需进行消耗处理。
* 若返回订阅型商品信息，则返回该用户在此应用下已有的订阅关系，包括以下几种订阅关系：

- 续期：正常使用，下个周期进行续费。

- 到期：如果下个周期不再续费，该周期过后变成已过期。

- 已过期：不能再使用订阅服务，但可以从订阅关系历史中查询到记录。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:----------------|:-------|:---|:-------------------------------------------------------------------------------------------------------|
|ownedPurchasesReq|json|是|查询用户所有已订购商品未被消耗信息，详细信息请参见"[ownedPurchasesReq参数说明](#ZH-CN_TOPIC_0000001075552476__table132791118183412)"。|
|success|function|否|成功回调。|
|fail|function|否|失败回调。|
|complete|function|否|完成回调。|

**ownedPurchasesReq参数说明**

|参数|类型|是否必填|说明|
|:----------------|:-----|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|applicationID|string|是|在华为开发者联盟上创建快应用后分配的唯一标识。获取方式请参见"创建快应用"中的"[获取APP ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824#section975713401464)"章节。|
|priceType|number|是|商品类型。 * 0：消耗型商品 * 1：非消耗型商品 * 2：订阅类商品|
|publicKey|string|是|开通支付服务时获取的支付公钥。获取方式请参见"开通支付服务"中的"[获取支付公钥](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-iap-kit-0000001079803876#section1318913307128)"章节。|
|continuationToken|string|否|分页查询的定位标志。该参数首次请求时不需要传入，当数据过多需分次查询时，传入上次查询时success返回值中的continuationToken。|

**success返回值**

|参数|类型|说明|
|:--------------------------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|returnCode|number|查询结果的返回码。|
|errMsg|string|返回码描述信息。|
|itemList|array|以String数组方式返回用户已购买的商品ID列表。|
|inAppPurchaseDataList|array|以String数组方式返回用户已购买商品的详情信息列表。数组中每个String元素为JSON格式。|
|inAppSignature|array|包含已使用支付私钥签名的购买数据（inAppPurchaseDataList）签名字符串。签名算法为SHA256WITHRSA，签名字符串与 inAppPurchaseDataList中的商品详细信息为一一对应关系，即inAppSignature中的第1个签名字符串对应inAppPurchaseDataList中第1条商品的详情信息，依次类推。应用需要对inAppPurchaseDataList中的每个JSON字符串都进行验签，如果验签不通过则需要重新获取该商品信息，验签方法请参见"[对结果验签](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-access-iap-kit-0000001099300540#section9450525193515)"。|
|continuationToken|string|数据定位标志。如果用户拥有的商品数量非常大，当响应中存在continuationToken时，应用必须对当前方法发起另一次调用，并传入本次接收到的continuationToken。如果商品仍未查完，需要继续发起调用，直到不再返回continuationToken，表示已经返回全部商品。|
|placedInappPurchaseDataList|array|以JSON字符串数组方式返回用户发生过订阅商品切换时的订阅关系信息，每个JSON字符串包含的参数请参见"[InAppPurchaseData](#ZH-CN_TOPIC_0000001075552476__table11473151783113)"。商品切换是指用户购买了订阅商品A后，在下一个周期购买了同一个订阅组下的商品B，则此时A的订阅关系将取消，用户转而与商品B建立订阅关系。则查询时此字段将返回商品B的订阅关系信息。该值仅在priceType为2且用户存在订阅商品切换时才会返回。|
|placedInappSignatureList|array|对应placedInappPurchaseDataList中订阅关系的签名字符串。应用需要对placedInappPurchaseDataList中的每个JSON字符串都进行验签，如果验签不通过则需要重新获取该订阅关系，验签方法请参见"[对结果验签](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-access-iap-kit-0000001099300540#section9450525193515)"。该值仅在priceType为2且用户存在订阅商品切换时才会返回。|

### pay.createPurchaseIntent(OBJECT)

**描述**

创建购买AppGallery Connect上配置商品的订单。

在AppGallery Connect创建商品后，使用此接口调用华为支付收银台，显示商品、价格和支付方式。华为会根据国际汇率变动进行商品价格档调整，为了保证应用内商品价格显示一致，请同时使用[obtainProductInfo](#section125017344614)接口获取商品详情，避免从自有服务端获取价格，以免在汇率变动价格调整时，导致价格显示不一致。

**OBJECT参数**

### pay.consumeOwnedPurchase(OBJECT)

**描述**

针对消耗型商品，在商品支付成功后，应用需要在发放商品之后调用此接口对消耗商品执行消耗操作。

1. 如果在消耗之后进行发货，可能存在以下异常场景：调用消耗接口过程中，服务器消耗成功但因网络异常等原因没有成功将结果回调给端侧，从而造成服务器已经消耗但是端侧没有发货的场景。此场景后续很难处理，所以建议开发者在发货之后再执行消耗操作。
2. 开发者需要把已发货的token传至应用的服务器，后续即使消耗失败也可以从服务器获取数据进行对比，避免出现异常。建议开发者在发货前检查应用服务器，以确保每个购买令牌都未使用过，即未发过货。
