# 传感器

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.sensor"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import sensor from '@system.sensor'
```

或

```screen
var sensor = require("@system.sensor")
```

## 使用限制

|限制条件|说明|
|:---|:----|
|适用终端|手机、平板|
|适用区域|全球|

### sensor.subscribeAccelerometer(OBJECT)

**描述**

监听重力感应数据。如果多次调用，仅最后一次调用生效。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:--------------|:-------|:---|:---------------------------------------------------------------------------------------------------------------------|
|interval(1060+)|string|否|监听回调函数的执行频率，默认normal。 * game：适用于更新游戏的回调频率，在 20ms/次 左右。 * ui：适用于更新 UI 的回调频率，在 60ms/次 左右。 * normal：普通的回调频率，在 200ms/次 左右。|
|callback|function|是|重力感应数据变化后会回调此函数，5次每秒。|

**callback返回值：**

|参数|类型|说明|
|:-|:-----|:----|
|x|Number|x轴坐标。|
|y|Number|y轴坐标。|
|z|Number|z轴坐标。|

**示例代码**

```screen
sensor.subscribeAccelerometer({
  interval:"normal",
  callback:function(ret){console.log("handling callback");}
})
```

### sensor.unsubscribeAccelerometer()

**描述**

取消监听重力感应数据。

**示例代码**

```screen
sensor.unsubscribeAccelerometer()
```

### sensor.subscribeCompass(OBJECT)

**描述**

监听罗盘数据。如果多次调用，仅最后一次调用生效。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-------------|
|callback|function|是|罗盘数据变化后会回调此函数。|

**callback返回值：**

|参数|类型|说明|
|:--------------|:-----|:------------------------------------------------------------------------|
|direction|float|面对的方向度数。|
|accuracy(1070+)|number|传感器当前的精度。 * -1：数值不可信，传感器失去连接。 * 0：数值不可信，原因未知。 * 1：低精度。 * 2：中等精度。 * 3：高精度。|

**示例代码**

```screen
sensor.subscribeCompass({
    callback:function(ret){console.log("handling callback");}
})
```

### sensor.unsubscribeCompass()

**描述**

取消监听罗盘数据。

**示例代码**

```screen
sensor.unsubscribeCompass()
```

### sensor.subscribeStepCounter(OBJECT)(1045+)

**描述**

监听计步传感器数据。如果多次调用，仅最后一次调用生效。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:----------------|
|callback|function|是|计步传感器数据变化后会回调此函数。|

**callback返回值：**

|参数|类型|说明|
|:----|:------|:-----------------------------------|
|steps|integer|计步传感器当前累计记录的步数。每次手机重启，这个值就会从0开始重新计算。|

**示例代码**

```screen
sensor.subscribeStepCounter({
    callback: function (ret) {
        console.error(ret.steps);
    }
})
```

### sensor.unsubscribeStepCounter()(1045+)

**描述**

取消监听计步传感器数据，如果不主动调用会在快应用退出时自动取消监听。

**示例代码**

```screen
sensor.unsubscribeStepCounter()
```

## 版本更新说明

|版本|发布日期|描述|
|:---|:---------|:---------------------------------------------------------------------------|
|1070|2020-05-19|sensor.subscribeCompass回调函数新增accuracy参数，用于获取传感器的精度。|
|1060|2019-12-10|sensor.subscribeAccelerometer增加interval参数，以设定监听加速度数据回调函数的执行频率。|
|1050|2019-09-20|新增sensor.subscribeStepCounter和sensor.unsubscribeStepCounter，可监听和取消监听计步传感器数据。|
