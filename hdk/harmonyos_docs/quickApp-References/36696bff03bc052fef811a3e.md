# 灰色模式（1100+）

快应用配置页面的灰色模式有两种方式：

1. 在manifest.json文件的config中设置[grayMode](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-manifest-0000001073698621#ZH-CN_TOPIC_0000001073698621__p0647120131010)属性。

   ```
   "config": {    
     "grayMode": {
       "enable": true,
       "duration": {
           "regular": ["12/13", "09/18"],
           "temporary": ["2020/04/04", "2018/05/12"]
       },
       "excludedPages": ["/WelcomePage"]
     }
   },
   ```

2. 使用[configuration.setGrayMode()](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-api-configuration-0000001074911860#section44691942638)接口在页面上设置灰色模式。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220801160209.10974146227096978753825810104802:50001231000000:2800:8FA42A2ECECC01398DFBB5E2F69FDD970D4BA7A564A6E0E9BAC7D2594E2AF6A8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   setGrayMode方法需要在页面渲染前调用。

   ```
   configuration.setGrayMode({
       enable: true,
       duration:
       {
           regular: ["06/22"],
           temporary: ["2022/06/22"]
       },
       excludedPages: ["Hello/configuration"]
   });
   ```

首先enable必须为真，然后duration属性将检查今天的日期是否在regular或temporary中，如果是，则引擎会检查目标页面是否不存在于 excludePages 数组中，如果满足这些条件，目标页面将变成灰色模式。
