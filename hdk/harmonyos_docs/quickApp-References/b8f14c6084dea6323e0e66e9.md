# popup

## 概述

用于在点击控件或者某个区域后，浮出一个气泡来引导用户，气泡内容通过子组件来定义。如果设置了遮罩层，可通过点击遮罩层的任意位置退出，否则点击气泡外任意区域退出。

## 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

## 子组件

仅支持 <text> 子组件。

## 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-attributes-0000001170050123) 以外，还支持如下属性。

|名称|类型|默认值|是否必填|描述|
|:--------|:-----|:-----|:---|:---------------------------------------------------------------------------------------|
|target|string|-|是|目标元素选择器。|
|placement|string|bottom|否|弹出窗口位置。 {'left','right','top','bottom','topLeft','topRight','bottomLeft', 'bottomRight'}|

## 样式

除了支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-common-styles-0000001170210009) 以外，还支持如下样式。

|名称|类型|默认值|是否必填|描述|
|:---------|:----|:---------|:---|:-----------------------------------|
|mask-color|color|0x00000000|否|遮罩背景层的颜色，缺省为全透明。 假如只设置了颜色，透明度默认为30%。|

## 事件

不支持appear，disappear事件，除了支持 [通用事件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-events-0000001123530338) 以外，还支持如下事件。

|名称|参数|描述|
|:---------------|:-----------------|:------------|
|visibilitychange|{visible: boolean}|当显隐状态变化时回调函数。|
