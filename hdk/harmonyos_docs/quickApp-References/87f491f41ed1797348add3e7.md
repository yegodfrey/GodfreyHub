# 弹出APK游戏安装页

#### 接口定义

|接口|描述|
|:------------------------------------------------------|:--------------|
|[qg.downloadApp(Object object)](#section18269112115377)|下载并安装相关联的APK游戏。|

#### qg.downloadApp(Object object)

* 描述 下载并安装相关联的APK游戏。

* 请求参数  

  |参数|类型|必选(M)/可选(O)|说明|
  |:----------|:-------|:----------|:-------------------------------------------------------------------------------------|
  |packageName|String|M|相关联的APK游戏包名。|
  |success|function|O|接口调用成功。|
  |fail|function|O|接口调用失败，详情请参见[fail参数说明](#ZH-CN_TOPIC_0000001504792169__li15752137104117)。|
  |callback|function|O|获取APK游戏下载/安装的进度，详情请参见[callback参数说明](#ZH-CN_TOPIC_0000001504792169__li147532037154120)。|

* fail参数说明  

  |参数|类型|说明|
  |:---|:-----|:-------------------------------------------------|
  |code|number|错误码： * 2：华为应用市场未安装。 * 15：华为应用市场未同意协议。 * 2001：下载失败。|
  |data|String|错误码说明。|

* callback参数说明  

  |参数|类型|说明|
  |:----------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |packageName|String|相关联的APK游戏包名。|
  |appType|String|用户手动确认下载后，APK游戏状态： * 1：安装状态。 * 2：下载状态。|
  |status|String|* appType=1，即APK游戏的安装进展： * 0：等待安装。 * 1：安装中。 * 2：安装成功。 * -1：安装失败。 <!-- --> * appType=2，即APK游戏的下载进展： * -1：wifi预约中。 * 0：排队等待中。 * 1：准备下载。 * 2：下载中。 * 3：取消下载。 * 4：下载完成。 * 5：下载失败。 * 6：下载暂停。 * 7：差分合成中。 * 8：下载中断。 * 10：重试下载开始。|
  |progress|String|APK游戏下载进度，仅在appType=2时有效。取值\[0,100\]，代表下载进度为0\~100%。|

<!-- -->

* 示例代码

  ```
  qg.downloadApp({
      // 替换成真实有效的APK游戏包名
      packageName:"com.huawei.***",
      success: function () {
        console.log("downloadApp successfully invoked");
      },
      fail: function (data, code) {
        console.log("downloadApp fail data =" + JSON.stringify(data), "code =" + code);
      },
      callback: function (data) {
        console.log("downloadApp callback data =", JSON.stringify(data));
      },
  });
  ```
