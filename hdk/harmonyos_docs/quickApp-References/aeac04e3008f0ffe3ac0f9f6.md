# section-item（1090+）

## 概述

<section-list>或<section-group>的子组件。支持 flex 布局，不支持 position。

## 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

支持。
