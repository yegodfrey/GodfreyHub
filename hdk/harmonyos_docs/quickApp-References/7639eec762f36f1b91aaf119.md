#### qg.hideKeyboard(Object object)

* 描述 隐藏软键盘。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 示例代码

  ```
  qg.hideKeyboard({
          success : function () {
                  console.log("hideKeyboard success" );
          },
          fail:function(){
                  console.log("hideKeyboard fail");
          },
          complete:function() {
                  console.log("hideKeyboard complete");
          }
  });
  ```

#### qg.showKeyboard(Object object)

* 描述 显示软键盘。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-----------|:-------|:----------|:-----------------------------------------------------------------------------------------------|
  |defaultValue|string|M|键盘输入框显示的默认值。|
  |maxLength|number|M|键盘中文本的最大长度。|
  |multiple|boolean|M|是否为多行输入。|
  |confirmHold|boolean|M|当点击完成时键盘是否保持。|
  |confirmType|string|M|键盘右下角confirm按钮的类型，只影响按钮的文本内容，请参见[confirmType合法值](#ZH-CN_TOPIC_0000001130573699__li155098882212)。|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * confirmType合法值  

    |属性名称|说明|
    |:-----|:---|
    |done|完成。|
    |next|下一个。|
    |search|搜索。|
    |go|前往。|
    |send|发送。|

* 示例代码

  ```
  qg.showKeyboard ({
          defaultValue : 'default value',
          maxLength : 666,
          multiple : true,
          confirmHold : true,
          confirmType : 'done',
          success : function () {
                  console.log("showKeyboard  success" );
          },
          fail:function(){
                  console.log("showKeyboard  fail");
          },
          complete:function() {
                  console.log("showKeyboard  complete");
          }
  });
  ```

#### qg.updateKeyboard(Object object)

* 描述 更新键盘输入框显示的默认值。

<!-- -->

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:------------------------------------------------------------------------------|
  |value|string|M|键盘输入的当前值。|
  |success|function|O|接口调用成功的回调函数，请参见[success回调函数参数](#ZH-CN_TOPIC_0000001130573699__li1947810311435)。|
  |fail|function|O|接口调用失败的回调函数，请参见[fail回调函数参数](#ZH-CN_TOPIC_0000001130573699__li9890994615)。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数|类型|说明|
    |:-----|:-----|:---------------------------|
    |errMsg|string|调用成功固定返回"updatekeyboard:ok"。|

  * fail回调函数参数  

    |参数|类型|说明|
    |:-----|:-----|:-----------------------------|
    |errMsg|string|调用失败固定返回"updatekeyboard:fail"。|

* 示例代码

  ```
  qg.updateKeyboard ({
          value : 'update value',
          success : function (res) {
                  console.log("updateKeyboard  success" + res.errMsg);
          },
          fail:function(res){
                  console.log("updateKeyboard  fail" + res.errMsg);
          },
          complete:function() {
                  console.log("updateKeyboard  complete");
          }
  });
  ```
