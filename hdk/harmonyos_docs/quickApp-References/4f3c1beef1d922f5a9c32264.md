# richtext

#### 概述

富文本容器。文本内容直接写在标签内容区，内容格式需与type相匹配。文本内容只支持静态内容。由于实时编译，文本内容尽量不要频繁改变，否则可能导致性能问题。  

#### 使用限制

|限制条件|说明|
|:---|:-------|
|适用终端|手机、平板、车机|
|适用区域|全球|

#### 子组件

不支持  

#### 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-attributes-0000001170050123) 以外，还支持如下属性。  

|名称|类型|默认值|是否必填|描述|
|:---|:---|:--|:---|:---------------------------------------------------------------------------|
|type|html|-|是|html格式支持标准的h5标签与样式，用于静态页面的展现，复杂的富文本需求尽量采用html格式富文本，内容只支持静态内容，不支持数据绑定，渲染指令等功能|

#### 样式

除了支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-common-styles-0000001170210009) 以外，支持 \<div\> 样式，height 样式设置无效，不允许设置height和background-color样式。  

#### 事件

支持 [通用事件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-events-0000001123530338) ，不支持swipe事件。当属性type为html时，还支持如下事件。  

|名称|参数|描述|
|:--------------|:-|:-------|
|start(1070+)|-|开始加载时触发。|
|complete(1070+)|-|加载完成时触发。|
