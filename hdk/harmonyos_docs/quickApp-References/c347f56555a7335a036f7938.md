### qg.createGameNearbyPlayingManager()

* 描述 获取近场联机对象，最多同时创建一个对象。

* 返回值 近场联机对象。

* 示例代码

  ```screen
  this.gameNearbyPlayingManager = qg.createGameNearbyPlayingManager({
    success: function (res) {},
    fail: function (res) {
      that.showLog("nearby: create nearby failed, res = " + JSON.stringify(res));
    },
    complete: function (res) {
      that.showLog("nearby: create nearby complete, res = " + res);
    },
  });
  ```

### GameNearbyPlayingManager.createRoom(Object object)

* 描述 创建房间。


* 参数

  |参数|类型|必填(M)/选填(O)|说明|
  |:---------------|:-----|:----------|:------------------------------------|
  |roomName|string|M|房间名称，最大长度为12个字符，只允许数字、字母、下划线和中文字符。|
  |minPlayerNum|number|M|最小支持人数，取值[1,6]。|
  |maxPlayerNum|number|M|最大支持人数，取值[1,6]。|
  |roomType|number|O|房间类型，取值说明如下： * 1：公开。 * 2：私有。 默认值为"1"。|
  |customProperties|string|O|房间自定义属性，最大长度300个字符。|


* 示例代码

  ```screen
  this.gameNearbyPlayingManager.createRoom({
    roomName: roomName,
    minPlayerNum: 1,
    maxPlayerNum: 4,
    roomType: 1,
    customProperties: "custom room properties",
  });
  ```
