# swiper

#### 概述

滑块视图容器。  

#### 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

#### 子组件

支持除\<list\>之外的子组件。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240716165408.65751121128353691804390446450671:50001231000000:2800:488785974236BD66AC6917C488D7C827226E3A3578C0864CD07D8501CC4664D5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
swiper子组件不支持position:fixed，1116版本开始，swiper子组件设置position:fixed会自动转换成position:relative  

#### 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-attributes-0000001170050123)以外，还支持如下属性。  

|名称|类型|默认值|是否必填|描述|
|:--------------------|:------|:----|:---|:----------------------------|
|index|number|0|否|当前显示的子组件索引。|
|autoplay|boolean|false|否|渲染完成后，是否自动进行播放。|
|interval|number|3000|否|自动播放时的时间间隔，单位毫秒。|
|indicator|boolean|true|否|是否启用indicator，默认true。|
|loop|boolean|true|否|是否开启循环模式。|
|duration(1040+)|number|-|否|滑动动画时长。|
|vertical(1040+)|boolean|false|否|滑动方向是否为纵向，纵向时 indicator 也为纵向。|
|previousmargin(1072+)|string|0px|否|前边距，用于露出前一项的一小部分，支持单位：px和%。|
|nextmargin(1072+)|string|0px|否|后边距，用于露出后一项的一小部分，支持单位：px和%。|
|enableswipe(1080+)|boolean|true|否|是否支持swiper沿其内容的排列方向滑动。|

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240716165408.97379336054061055425589312121289:50001231000000:2800:556798F159DF982F968F8A776225E89359BFED55AA5A9491CA65DA5234E01FE8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
previousmargin和nextmargin的总和不应该超过整个swiper大小的1/2，超过部分将会被截取。  

#### 样式

除了支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-common-styles-0000001170210009) 以外，还支持如下样式。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240716165408.51052358492150326884669479822404:50001231000000:2800:BC12D62524FD790F95B5CE10C79DEC72FE18453DB289B0DBDAA42337E1D25714.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
swiper组件的直接子节点不支持修改宽度和高度，宽度默认和swiper宽度相等。  

|名称|类型|默认值|是否必填|描述|
|:----------------------------------------|:-------------------|:-------------------|:---|:--------------------|
|indicator-color|color|rgba(0,0,0,0.50)|否|indicator填充颜色|
|indicator-selected-color|color|rgba(51,180,255,1.0)|否|indicator选中时的颜色|
|indicator-size|length|20px|否|indicator组件的直径大小|
|indicator-top\|left\|right\|bottom(1040+)|length \| percentage|-|否|indicator相对于swiper的位置|

除了支持 [动画样式](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-animation-styles-0000001123530340) 以外，还支持页面切换动画。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240716165408.57785086198240823840563003639367:50001231000000:2800:AC2CDF8E4D868ED1AC52261E3CBF6085BF9A92E880AE445924A19780E4FFC374.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
swiper动画在设置previousmargin和nextmargin场景下不生效。  

|名称|类型|默认值|描述|
|:-------------------------------|:---------------------------------------------------|:------|:--------------------------------------------------------------------------------------------|
|page-transform-origin(1080+)|position|0px 0px|变换原点位置。取值中两个数值分别对应X轴和Y轴的坐标，单位为px，例如150px 200px 。|
|transform(1080+)|string|-|详情请参见"[transform操作](#ZH-CN_TOPIC_0000001074057289__table755414441479)" 。|
|page-animation-name(1080+)|string|-|对应@keyframes的name取值，详情请参见 "[@keyframes属性](#ZH-CN_TOPIC_0000001074057289__table493363535015)"。|
|animation-timing-function(1080+)|linear \| ease \| ease-in \| ease-out \| ease-in-out|ease|CSS动画在每个周期中的速度曲线。|

transform操作  

|方法|类型|
|:---------|:---------|
|translate|length|
|translateX|length|
|translateY|length|
|scale|multiple|
|scaleX|multiple|
|scaleY|multiple|
|rotate|deg \| rad|
|rotateX|deg \| rad|
|rotateY|deg \| rad|

@keyframes属性  

|名称|类型|默认值|描述|
|:---------------|:-----|:--|:---------------------------|
|background-color|color|-|-|
|opacity|number|-|-|
|transform|string|-|仅translateX和translateY支持百分比。|

使用from和to来标识起点和终点，示例代码如下：

```
.sampleAnimation {
  page-animation-name: Opacity, Rotate;
  page-transform-origin: 200px 200px;
  animation-timing-function: ease-in-out;
}
@keyframes Opacity {
  from {
    opacity: 0.2;
  }
  to {
    opacity: 1;
  }
}
@keyframes Rotate {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(180deg);
  }
}
```

#### 事件

除了支持 [通用事件](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-events-0000001123530338) 以外，还支持如下事件。  

|名称|参数|描述|
|:-----|:-------------------|:--------------|
|change|{index:currentIndex}|当前显示的组件索引变化时触发。|

#### 方法

|名称|参数|描述|
|:------|:--------------------|:---------------------------------------------------------------------------|
|swipeTo|{index: number(指定位置)}|swiper滚动到index位置。 示例如下： ``` this.$element('swiper').swipeTo({ index:2 }) ```|
