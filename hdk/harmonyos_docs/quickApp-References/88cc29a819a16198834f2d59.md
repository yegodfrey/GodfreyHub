# 系统信息

![](https://media:201786005011164547)  
从1078版本开始，接口前缀由hbs调整为qg，原hbs仍支持。  

#### 接口定义

|接口|描述|
|:--------------------------------------------------------------|:---------------|
|[qg.getSystemInfo(Object object)](#section16231152791216)|获取系统信息。|
|[qg.getSystemInfoSync(Object object)](#section14651153111516)|获取系统信息（同步方法）。|
|[qg.canIUse(string capability)（1127+）](#section165771434195617)|判断当前客户端是否支持某个能力。|

#### qg.getSystemInfo(Object object)

* 描述 获取手机的系统信息。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:-------------------------------------------------------------------------------|
  |success|function|O|接口调用成功的回调函数，详情请参见[success回调函数参数](#ZH-CN_TOPIC_0000001083874626__li479771312165)。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

  * success回调函数参数  

    |参数|类型|说明|
    |:------------------|:-----|:-----------------------------------------------------------------------------------------------------------------------------|
    |brand|string|手机品牌。|
    |model|string|手机型号。|
    |pixelRatio|number|设备像素比。 说明： 为确保获取的pixelRatio和safeArea相匹配，需将minPlatformVersion配置1078及以上版本。|
    |screenWidth|number|屏幕宽度。|
    |screenHeight|number|屏幕高度。|
    |windowWidth|number|可使用窗口宽度。|
    |windowHeight|number|可使用窗口高度。|
    |language|string|系统语言。|
    |region|string|系统地区。|
    |script|string|系统语言书写方式。|
    |coreVersion|string|渲染引擎版本号。|
    |COREVersion|string|渲染引擎版本号。|
    |system|string|操作系统版本。|
    |platform|string|客户端平台。 说明： 若返回值为"HarmonyOS"，表示当前客户端平台所在的操作系统版本为HarmonyOS 5.0及以上；若返回其他值，则表示当前客户端平台所在的操作系统版本为HarmonyOS 3.1/4.0及以下。|
    |version|string|快应用中心版本。|
    |statusBarHeight|number|状态栏高度，以屏幕的实际分辨率为单位。|
    |platformVersionName|string|运行平台版本名称。 说明： 若快游戏minPlatformVersion在1078及以上版本，才会返回当前字段。|
    |platformVersionCode|number|运行平台标准版本号。 说明： 若快游戏minPlatformVersion在1078及以上版本，才会返回当前字段。|
    |safeArea|object|在竖屏正方向下的安全区域，详情可参见[safeArea参数](#ZH-CN_TOPIC_0000001083874626__li1291054422018)。 说明： 若快游戏minPlatformVersion在1078及以上版本，才会返回当前字段。|

    * safeArea参数  

      |属性|类型|说明|
      |:-----|:-----|:------------------------------|
      |bottom|number|安全区域右下角纵坐标。|
      |left|number|安全区域左上角横坐标。|
      |right|number|安全区域右下角横坐标。|
      |top|number|安全区域左上角纵坐标。|
      |height|number|安全区域的高度，大小为实际高度（以px为单位）/设备屏幕密度。|
      |width|number|安全区域的宽度，大小为实际宽度（以px为单位）/设备屏幕密度。|

* 示例代码

  ```
  qg.getSystemInfo({
      success(res) {
          console.log("on getSystemInfo: success =" + JSON.stringify(res));
      },
      fail() {
          console.log("on getSystemInfo: fail");
      },
      complete() {
          console.log("on getSystemInfo: complete");
      }
  });
  ```

#### qg.getSystemInfoSync(Object object)（1078+）

* 描述 获取系统信息（同步方法）。

* 返回参数 详情可参见[success回调函数参数](#ZH-CN_TOPIC_0000001083874626__li479771312165)。

* 示例代码

  ```
  var res = qg.getSystemInfoSync();
  console.log("on getSystemInfoSync: success =" + JSON.stringify(res));
  ```

#### qg.canIUse(string capability)（1127+）

* 描述 判断当前客户端是否支持某个能力。

* 参数object  

  |参数|类型|必填(M)/选填(O)|说明|
  |:---------|:-----|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |capability|string|M|能力名称，取值如下： * MiniGame.NearbyPlaying：判断近场联机特性是否支持使用。 * MiniGame.KnockSharing：判断碰一碰分享是否支持使用。 * MiniGame.MenuButtonBoundingRect：判断[qg.getMenuButtonBoundingClientRect](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-menu-0000002425101165#section14948251203111)是否支持使用。 * MiniGame.InteractiveCard：判断[qg.addInteractiveCard(Object object)](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-card-size-0000002045925504#section43861750112916)是否支持使用。 * MiniGame.OnShare：判断OnShare特性是否支持使用。 * MiniGame.SystemShare.ShareSelf：判断系统分享是否支持分享当前快游戏。 * MiniGame.GesturesShare：判断抓一抓分享是否支持使用。 * MiniGame.SubscribePushMsg：判断是否支持订阅消息。|

* 示例代码

  ```
  if (typeof qg.canIUse === 'function') {
      const isSupportNearbyPlaying = qg.canIUse('MiniGame.NearbyPlaying');
      console.log('isSupportNearbyPlaying: ' + isSupportNearbyPlaying) // 是否支持近场联机特性
      const isSupportInteractiveCard = qg.canIUse('MiniGame.InteractiveCard');
      console.log('isSupportInteractiveCard: ' + isSupportInteractiveCard) // 是否支持互动卡片加桌能力
  }
  ```
