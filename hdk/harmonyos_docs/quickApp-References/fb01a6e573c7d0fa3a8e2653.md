# 设备标识符

## 接口定义

|接口|描述|
|:--------------------------------------------------|:---------------------|
|[qg.getOAID(Object object)](#section94961019174317)|获取匿名设备标识符，建议只在广告的场景使用。|

### qg.getOAID(Object object)（1103+）

* 描述 获取匿名设备标识符，建议只在广告的场景使用。

* 参数说明

  |参数|类型|必填(M)/选填(O)|说明|
  |:-------|:-------|:----------|:--------------------|
  |success|function|O|接口调用成功的回调函数。|
  |fail|function|O|接口调用失败的回调函数。|
  |complete|function|O|若有函数传入，将在成功、失败后调用该函数。|

* 返回值

  |参数|类型|说明|
  |:---|:-----|:------------------------------------------------------------------------------|
  |oaid|string|匿名设备标识符。若当前设备不支持oaid，返回空值。当用户重置广告标识符后，该值发生改变。当手机系统设置项"限制广告跟踪"为开启状态时，返回由0组成的字符串。|

* 示例代码

  ```screen
  "function" == typeof qg.getOAID && qg.getOAID({
  	success: function (ret) {
  		console.log("qg.getOAID success :" + JSON.stringify(ret));
  	},
  	fail: function (errMsg, errCode) {
  		console.log("qg.getOAID fail " + errCode + ': ' + errMsg)
  	},
  	complete: function () {
  		console.log("qg.getOAID complete")
  	}
  }) 
  ```
