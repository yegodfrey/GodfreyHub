animation-timing-function类型说明

1090版本支持的类型中：

* steps(number_of_steps，step-direction)(1090+)  

  |名称|类型|默认值|是否必填|描述|
  |:--------------|:---------------------------------------------------------------|:--|:---|:-------------|
  |number_of_steps|number|-|是|步长数，该参数必须为正整数。|
  |step-direction|jump-start \| jump-end \| jump-none \| jump-both \| start \| end|end|否|函数左连续或右连续的关键字。|

* cubic-bezier(x1, y1, x2, y2)(1090+) 参数x1、y1、x2、y2的数据类型为number，表示三次贝塞尔曲线中P1和P2的横坐标和纵坐标值。x1和x2的取值范围是\[0,1\]，超出取值范围，cubic-bezier将失效。

通过from和to显示指定起始和结束。示例：

```
@keyframes Go
     {
       from {background-color:#f76160;}
       to {background-color: #09ba07;}
     }
```

百分比写法，暂时不支持起始值(0%)或终止值(100%)缺省的情况，需显示指定。示例：

```
 @keyframes Test1 {
    0% {
      background-color: black;
    }
    33% {
      background-color: red;
    }
    66% {
      background-color: blue;
    }
    100% {
      background-color: green;
    }
  }
  @keyframes Test2 {
    0% {
      transform: translateX(0px);
    }
    25% {
      transform: translateX(90px);
    }
    100% {
      transform: translateX(180px);
    }
  }
```

transition过渡动画（1100+）

过渡动画是实现动画的另一种方式，定义组件切换状态时的过渡效果。例如，通过伪类和JavaScript实现状态变更。

transition共有4种样式属性：transition-property、transition-duration、transition-timing-function和transition-delay，可直接写入样式中。

示例代码如下：

```
.div {
  width: 100px;
  transition-property: width;
  transition-duration: 2s;
  transition-timing-function: ease-in;
  transition-delay: 0.5s;
}
.div:active {
  width: 300px;
}
```

上述四种样式属性也可简写成一条，如下示例表示当触发div组件宽度变化后0.5s，会加速变为新宽度，过渡动画持续2s。

```
.div {
  transition: width 2s ease-in 0.5s;
}
```

快应用中transition-property支持的通用样式属性如下：

* width
* height
* background-color
* background-position
* opacity
* transform
