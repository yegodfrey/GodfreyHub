# 日志回传（1103+）

## 接口声明

在manifest.json文件的 features属性中增加如下配置。

```screen
{"name": "system.feedback"}
```

## 导入模块

在调用接口页面的<script>部分增加如下配置。

```screen
import feedback from '@system.feedback'
```

或

```screen
var feedback = require("@system.feedback")
```

## 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

|接口|描述|

### feedback.getLogFiles(OBJECT)

**描述**

获取本地缓存的console日志。
> 说明
>
> 返回的uri参数可用于[file.get](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-api-file-0000001074911856#section1690793215714)，以获取本地文件信息。

**OBJECT参数**

|参数|类型|是否必填|说明|
|:-------|:-------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|success|function|否|成功回调，返回{fileList:[{uri:'file1',lastModifiedTime:1234456, length:123456} ...]} 返回值说明请参见"[success返回值](#ZH-CN_TOPIC_0000001469983341__table1259571616318)"，返回值中每个文件元信息请参见"[文件元信息说明](#ZH-CN_TOPIC_0000001469983341__table144263337512)"。|
|fail|function|否|失败回调。|
|complete|function|否|执行结束后的回调。|

**success返回值：**

|参数名|类型|说明|
|:-------|:----|:------------------------------------------------------------------|
|fileList|array|文件列表，每个文件的格式为{uri:'file1',lastModifiedTime:1234456, length:123456}。|

**文件元信息说明：**

|参数名|类型|说明|
|:---------------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|uri|string|日志缓存文件的uri，该uri可以被其他组件或Feature访问。 uri描述请参见"[文件组织 > URI](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-filestructure-0000001074564510#section8808123141011)"。|
|length|number|文件大小，单位B。|
|lastModifiedTime|number|文件保存时的时间戳，从 1970/01/01 00:00:00 GMT 到当前时间的毫秒数。|

**fail返回错误码：**

|错误码|说明|
|:--|:-------|
|301|日志文件不存在。|

**示例代码**

```screen
feedback.getLogFiles({
    success:function (ret) {
        console.log('getlogfiles success ' + JSON.stringify(ret));
    },
    fail:function(data, code) {
          console.log("getlogfile fail, code=" + code);
    }
})
```
