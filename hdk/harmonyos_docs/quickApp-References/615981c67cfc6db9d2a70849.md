# 打开APK游戏预约页

## 接口定义

|接口|说明|
|:----------------------------------------------------|:------------------|
|[qg.reserveApp(Object object)](#section1584911596204)|在快游戏内打开APK游戏的预约详情页。|

### qg.reserveApp(Object object)(1106+)

* 接口描述 在快游戏内打开APK游戏的预约详情页。

* 请求参数

  |参数|类型|必选(M)/可选(O)|说明|
  |:----------|:-------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------|
  |packageName|String|M|待预约的APK游戏包名，与[创建快游戏](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-create-quickgame-0000001159652387)时的应用包名保持一致。|
  |success|function|O|[success回调](#ZH-CN_TOPIC_0000001583092993__li193499112102)。|
  |fail|function|O|[fail回调](#ZH-CN_TOPIC_0000001583092993__li173343351015)。|

* success回调

  |参数|类型|说明|
  |:---------------|:-----|:----------------------------------------|
  |appReserveStatus|String|成功打开预约详情页后，返回用户预约游戏的状态： * 1：已预约。 * 0：未预约。|
  |packageName|String|待预约的APK游戏包名。|

* fail回调

  |参数|类型|说明|
  |:----------|:-----|:---------------------------------------------------------------------|
  |code|Number|在快游戏内未成功打开预约详情页的[错误码](#ZH-CN_TOPIC_0000001583092993__li1956014835319)。|
  |packageName|String|待预约的APK游戏包名。|

* 错误码
* 示例代码

  ```screen
  qg.reserveApp({
           packageName: "待预约应用的包名",
           success : function (data) {
                   console.log("reserveApp success data = " + JSON.stringify(data));
           },
           fail:function (data) {
                   console.log("reserveApp fail return data = " + JSON.stringify(data));
          },
  });
  ```
