# list-item

#### 概述

\<list\> 的子组件，用于展示列表具体item，宽度默认充满list组件。  

#### 使用限制

|限制条件|说明|
|:---|:-----------|
|适用终端|手机、平板、智慧屏、车机|
|适用区域|全球|

#### 子组件

支持  

#### 属性

除了支持 [通用属性](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-attributes-0000001170050123) 以外，还支持如下属性。  

|名称|类型|默认值|是否必填|描述|
|:-----------------------|:------|:----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|type|string|-|是|list-item类型，同一list支持多种type的list-item，相同的list-item需要确保渲染后的视图布局也完全相同，当type固定时，使用show属性代替if属性，确保视图布局不变。 注意： 在 list-item 内部需谨慎使用 if 和 for，因为 if 和 for 可能造成相同的 type 的 list-item 的 DOM 结构不一致，从而引发渲染错误。|
|disallowintercept(1100+)|boolean|false|否|是否禁止父list拦截点击事件。 * true：禁止滚动list，点击事件将在list-item中处理。 * false：允许父list滚动并处理点击事件。|

#### 样式

支持 \<div\> 样式，不支持 \<position\> 样式。除了支持 [通用样式](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-common-styles-0000001170210009) 以外，还支持如下样式。  

|名称|类型|默认值|是否必填|描述|
|:----------|:-----|:--|:---|:---------------------------------|
|column-span|number|1|否|list-item在list中所占列数，一般用于list多列显示时。|

list-item及其子组件设置宽、高时，不支持设置为百分比样式，例如：width只能设置为300px，不能设置为30%。

正常情况下，list-item的column-span数值应小于等于其父组件list的columns数值。

从1070 版本开始，list 组件支持配置样式layout-type，可选属性值：stagger、grid(默认)

* 当layout-type为stagger时：若list-item的column-span数值等于其父组件list的columns数值，表示占满所有列；否则，list-item 组件将表现为column-span: 1的样式
* 当没有指定layout-type或layout-type为grid时：若list-item的column-span数值小于等于其父组件list的columns数值，则表现为占有column-span列宽度的样式；否则，list-item 组件将表现为column-span: 1的样式

#### 事件

支持 [通用事件](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-events-0000001123530338)。  

#### 示例代码

```
<list  class="stagger"style="layout-type: stagger" >
        <list-item type="listItem" class="item item-color">
          <text onclick="textClick" class="txt">{{$item}}--{{$idx}}</text>
        </list-item>
        <!--设置column-span为1-->
        <list-item style="column-span:1" type="loadMore" class="load-more" if="{{loadMore}}">
          <progress type="circular"></progress>
          <text>{{messageloadMore}}</text>
        </list-item>
    </list>
    <list class="stagger" style="layout-type: stagger" >
        <list-item type="listItem" class="item item-color" disallowintercept=false>
          <text onclick="textClick" class="txt">{{$item}}--{{$idx}}</text>
        </list-item>
        <!--设置column-span为4-->
        <list-item style="column-span:4" type="loadMore" class="load-more" if="{{loadMore}}">
          <progress type="circular"></progress>
          <text>{{messageloadMore}}</text>
        </list-item>
    </list>
```
