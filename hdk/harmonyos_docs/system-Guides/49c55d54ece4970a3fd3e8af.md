# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[Codelabs](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMS5G-Modem)快速体验一个应用的开发过程。

## 开发环境

* 安装[Android Studio](https://developer.android.com/studio?hl=zh-cn) 3.X及以上

* [JDK](https://www.java.com/zh-CN/) 1.8及以上
* 您的应用应满足以下条件：
  * minSdkVersion 26及以上
  * targetSdkVersion 31（推荐）
  * compileSdkVersion 31（推荐）
  * Gradle 4.6及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：HarmonyOS 2.0及以上的使用Kirin990、Kirin985、Kirin820及Kirin9000芯片的华为手机。

## 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001110065766)|（若您的应用不需要在AppGallery Connect上架，则可跳过本步骤）在开发应用前，需要在AppGallery Connect中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001110065766#section1464519554325)、[创建应用](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001110065766#section466511118298)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001110065766#section17984151818389)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001110065766#section2051913912366)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/system-Guides/integrating-sdk-0000001079536030)|在开发应用前，您需要将5G Modem Kit的SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-obfuscation-scripts-0000001079247952)|编译APK前需要配置混淆配置文件，避免混淆5G Modem Kit的SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/system-Guides/add-permissions-0000001126152769)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[众测功能开发](https://developer.huawei.com/consumer/cn/doc/system-Guides/client-dev-0000001079365926)|您可根据业务需求，通过调用5G Modem Kit提供的API完成众测功能开发。|
|6|[通信体验优化功能开发](https://developer.huawei.com/consumer/cn/doc/system-Guides/interaction-client-dev-0000001760778061)|您可根据业务需求，通过调用5G Modem Kit提供的API完成通信体验优化相关的功能开发。|
|7|[开发后自检](https://developer.huawei.com/consumer/cn/doc/system-Guides/pre-release-check-0000001079525542)|（若您的应用不需要在AppGallery Connect上架，则可跳过本步骤） 华为提供对应用自动检查的能力。|
|8|[上架申请](https://developer.huawei.com/consumer/cn/doc/system-Guides/app-release-0000001079237472)|（若您的应用不需要在AppGallery Connect上架，则可跳过本步骤） 开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
