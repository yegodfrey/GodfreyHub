## 发布消息

发布消息到云端，Nearby Message同时对外广播SharingCode（蓝牙共享码，遵循华为Hilink蓝牙协议），附近的App用户能够接收到该消息。请参见[Message](https://developer.huawei.com/consumer/cn/doc/system-References/message-message-0000001050132615)类构造待发布消息。

示例代码：

```screen
Message message = new Message("Hello World!".getBytes());
PutOption putOption = new PutOption.Builder().build();
Nearby.getMessageEngine(getApplicationContext()).put(message, putOption)
// 发布消息失败
.addOnFailureListener(new OnFailureListener() {
    @Override 
    public void onFailure(Exception e) {      
       Log.e(TAG, "NearbyAgent sendMsg failed: " + e.getMessage());          
    }
})
// 发布消息成功
.addOnSuccessListener(new OnSuccessListener<Void>() {
    @Override 
    public void onSuccess(Void aVoid) {      
       Log.i(TAG, "NearbyAgent sendMsg succeed");             
}
});
```

## 停止发布消息

停止已发布消息，[unput](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section1811517564180)([Message](https://developer.huawei.com/consumer/cn/doc/system-References/message-message-0000001050132615))接口传入的历史消息会从云端删除。

示例代码：

```screen
Nearby.getMessageEngine(this).unput(message);
```

> 说明
>
> * 请您在应用程序退出时使用[unput](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section1811517564180)([Message](https://developer.huawei.com/consumer/cn/doc/system-References/message-message-0000001050132615))接口停止之前的消息发布。
> * 如果需要更新TTL（云端消息超时时间），请调用[unput](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section1811517564180)([Message](https://developer.huawei.com/consumer/cn/doc/system-References/message-message-0000001050132615))接口后，重新设置TTL再调用[put](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section8851250699)([Message](https://developer.huawei.com/consumer/cn/doc/system-References/message-message-0000001050132615))接口或者[put](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section5245431141118)([Message](https://developer.huawei.com/consumer/cn/doc/system-References/message-message-0000001050132615), [PutOption](https://developer.huawei.com/consumer/cn/doc/system-References/putoption-0000001050130678))接口。

## 订阅消息

订阅消息，请参见[get](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section5780511181418)([MessageHandler](https://developer.huawei.com/consumer/cn/doc/system-References/messagehandler-0000001050132619), [GetOption](https://developer.huawei.com/consumer/cn/doc/system-References/getoption-0000001050130682))接口。可通过[MessagePicker](https://developer.huawei.com/consumer/cn/doc/system-References/messagepicker-0000001050130666)过滤需要的消息类型，同时通过[MessageHandler](https://developer.huawei.com/consumer/cn/doc/system-References/messagehandler-0000001050132619)对订阅到的目标消息进行处理。

示例代码：

```screen
MessageHandler messageHandler = new MessageHandler() {
    // 获取到周围设备新消息 
    @Override
    public void onFound(Message message) {
        super.onFound(message);
        String json = new String(message.getContent(), StandardCharsets.UTF_8);
        Log.i(TAG, "NearbyAgent onFound() json: " + json + ", Namespace: " + message.getNamespace() + ", type: " + message.getType());            
    }
    // 蓝牙设备扫描不到或云端消息消失时回调
    @Override
    public void onLost(Message message) {
        super.onLost(message);
        String json = new String(message.getContent(), StandardCharsets.UTF_8);
        Log.i(TAG, "NearbyAgent onLost() json: " + json + ", Namespace: " + message.getNamespace() + ", type: " + message.getType());
    }
 };
// 消息获取过程的自定义参数选项
Policy policy = new Policy.Builder().setTtlSeconds(Policy.POLICY_TTL_SECONDS_INFINITE).build();
GetOption getOption = new GetOption.Builder().setPolicy(policy).build();
Nearby.getMessageEngine(getApplicationContext()).get(messageHandler, getOption);
```

> 说明
>
> 当您开启订阅消息任务后，Nearby Message会按照一定的时间间隔从云端更新消息，这个时间间隔由HMS Core根据业务情况进行配置和修改。如果您认为该参数不满足您的应用需求，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。

## 停止订阅消息

若停止订阅消息，请调用[unget](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section16678445206)([MessageHandler](https://developer.huawei.com/consumer/cn/doc/system-References/messagehandler-0000001050132619))接口，传入之前为了订阅消息构造的[MessageHandler](https://developer.huawei.com/consumer/cn/doc/system-References/messagehandler-0000001050132619)。

示例代码：

```screen
// unget()接口与订阅消息中的get()接口调用时传入的messageHandler一致
Nearby.getMessageEngine(getApplicationContext()).unget(messageHandler);
```
