# 业务介绍

|---------------------------------------------------------------------------------------------------------------------------------|-|
|Network Kit是一款网络基础服务套件，聚合远场网络通信优秀实践，辅以RESTful、文件上传/下载等场景化接口，为您提供简单易用、低时延、高吞吐和高安全的端云传输通道。 通过学习本课程，您将了解Network Kit的功能、优势以及主要应用场景 等。| |

|标准HTTP网络请求|华为手机、华为平板|EMUI 3.0及以上|5.2.0.300及以上|
|标准HTTP网络请求|非华为手机、非华为平板|Android 4.4及以上|5.2.0.300及以上|

## 场景介绍

* URL访问网络场景中：可提升网络访问速度。
* 弱网环境中：可减少无效网络等待时间，且支持网络平滑迁移。
* 文件上传/下载场景中：可以提升文件上传/下载的速度和成功率。 说明
  > * Network Kit中的网络协议（如QUIC）可能会包含个人数据，如Connection ID（CID）。在使用网络协议通信时，对包含的个人数据，您将承担所有责任。在使用HUAWEI提供的Network Kit API时，您必须遵守所有关于个人数据处理的规则和规范，尤其是此类数据的安全要求。您还应遵守[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)、[《华为APIs使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)等相关条款。您需确保API不会用于非法活动或侵犯第三方权利，并确保您对API的使用符合所有适用的法律法规。您或任何第三方使用API产生的结果引起的争议，您应予以解决，华为不承担任何责任。
  > * Network Kit支持的QUIC（Quick UDP Internet Connections）协议，是Google提出的一套网络传输协议。它使用UDP（User Datagram Protocol）协议，基于TLS（Transport Layer Security）/DTLS（Datagram Transport Layer Security）来提供网络安全保护。与其他标准协议相比，QUIC网络草案尚未得到业界全面的安全和隐私评估。您需要评估QUIC对您软件的隐私影响，并采取合适的方案通知用户。
  > * Network Kit提供了缓存功能，您需要评估缓存数据对隐私的影响并决定是否启用。Network Kit默认不启用缓存功能，如果您需要启用，可以通过调用[HttpClient.Builder](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-builder-0000001072701879)的[cache](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-builder-0000001072701879#section513912419219)方法自行开启缓存功能。若启用，您需要自行设置数据的缓存路径并为用户提供缓存数据的清除功能，Network Kit不会对缓存数据进行收集。
  > * Network Kit提供了AI加速能力。AI加速能力根据历史网络行为规律进行网络预热，会在本地收集业务域名访问记录，您需要评估此功能对隐私的影响并决定是否启用。Network Kit默认启用AI加速能力，若您不需要启用此功能，可以调用[NetworkKit](https://developer.huawei.com/consumer/cn/doc/system-References/network-networkkit-0000001050171213)的初始化方法[init(Context context, NetworkKit.Callback callback, String options)](https://developer.huawei.com/consumer/cn/doc/system-References/network-networkkit-0000001050171213#section1333012415550)，通过配置[options](https://developer.huawei.com/consumer/cn/doc/system-References/network-networkkit-0000001050171213#ZH-CN_TOPIC_0000002059302393__table4435511183712)参数，将[core_switch_ai](https://developer.huawei.com/consumer/cn/doc/system-References/network-networkkit-0000001050171213#ZH-CN_TOPIC_0000002059302393__table4435511183712)配置为false，并确认调用此方法时，为Network Kit首次初始化，即可关闭此功能。
  > * 在使用Network Kit发送过网络请求后，Network Kit会产生持久化的非个人数据，之后再调用[init(Context context, NetworkKit.Callback callback)](https://developer.huawei.com/consumer/cn/doc/system-References/network-networkkit-0000001050171213#section114498411300)等初始化接口时，将存在发起网络请求的情况。如果在用户同意应用联网协议前调用了初始化接口，当用户取消同意应用联网协议后，您需要主动清除"/data/user_de/0/<package_name>"和"/data/data/<package_name>"下的数据。

## 服务优势

* 简单易用：提供场景化网络编程接口，屏蔽网络细节，支持RESTful风格的请求方式，简单易懂让您更聚焦业务逻辑。
* 更低时延：通过网络预热、缓存、多协议支持、复合建链、智能网络参数调优等关键技术，降低网络请求时延。
* 更高吞吐量：通过QUIC、多路径并发（即将推出）等新型网络协议，辅以华为自研拥塞算法，提升网络吞吐量。
