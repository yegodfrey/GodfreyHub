# DPC激活/去激活

HEM SDK为DPC App提供激活与去激活的能力。DPC App可以通过调用HEM SDK的激活接口向PMS（Package Manager Service）完成权限设置操作，同样可以通过调用去激活接口取消该权限。  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220623150402.63017863027310831265026329598455:50530622094706:2800:6D60978D189707A83C4B9212276CE8EB4A0DDA02CFC517AEBEECB1C09E036E34.png?needInitFileName=true?needInitFileName=true)  
华为MDM（Mobile Device Management）权限授予要同时具备激活设备管理器和在线授权两个条件。在线授权存在有效期限制，HEM Kit会周期性地向云端检测PMS的系统时间是否在授权有效期内。

如果端侧与云侧的系统时间不同步，会导致授权失效。  

#### 前提条件

完成DPC App的[License申请](https://developer.huawei.com/business/cn/doc/distribution/HEM/developer-commercial-license-commdm-0000001324740701)。  

#### 开发指导

1. 创建[HemLicenseManager](https://developer.huawei.com/consumer/cn/doc/development/system-References/hemlicensemanager-0000001058803272)对象。

   ```
   public class MainActivity extends Activity {    
       ...
       private HemLicenseManager hemInstance;
       ...
       @Override  
       protected void onCreate(Bundle savedInstanceState) {  
           super.onCreate(savedInstanceState);  
           setContentView(R.layout.activity_main); 
           // 创建对象
           hemInstance = HemLicenseManager.getInstance(this);
           ...
       }  
   }
   ```

2. 设置状态回调。 在调用激活、去激活接口前需要先调用接口[setStatusListener](https://developer.huawei.com/consumer/cn/doc/development/system-References/hemlicensemanager-0000001058803272#section825989191217)设置状态回调的监听，通过回调函数获取调用激活/去激活接口的结果。回调函数通过实现[HemLicenseStatusListener](https://developer.huawei.com/consumer/cn/doc/development/system-References/hemlicensestatuslistener-0000001058503928)类中的方法来监听调用状态。

   了解详细方法说明，请参见API文档中的[HemLicenseStatusListener](https://developer.huawei.com/consumer/cn/doc/development/system-References/hemlicensestatuslistener-0000001058503928)类。

   ```
   ...
   public class MainActivity extends Activity {    
       ...
       private HemLicenseManager hemInstance;
       ...
       @Override  
       protected void onCreate(Bundle savedInstanceState) {  
           ...
           // 设置状态回调监听
           hemInstance.setStatusListener(new HemLicenseStatusListener() {
               @Override
               public void onStatus(int errorCode,String msg) {
                   ...
               }
           });
       ...
       } 
   ...
   }
   ```

3. 通过DPC App的License设置权限。 通过调用[activeLicense](https://developer.huawei.com/consumer/cn/doc/development/system-References/hemlicensemanager-0000001058803272#section813217288108)接口实现DPC App激活。

   ```
   ...
   public class MainActivity extends Activity {    
       ...
       private HemLicenseManager hemInstance;
       ...
       // 激活    
       private void activeLicense() {
          ...
          hemInstance.activeLicense();
          ...
       }
       ...
   }
   ```

4. （可选）通过DPC App的License取消权限。 调用去激活接口前需要先完成激活操作。

   ```
   ...
   public class MainActivity extends Activity {    
       ...
       private HemLicenseManager hemInstance;
       ...
       // 去激活  
       private void deActiveLicense() {
           ...
           hemInstance.deActiveLicense();
           ...
       }
       ...
   }
   ```
