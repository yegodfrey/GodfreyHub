# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## App中集成HEM SDK后，激活失败，errorCode为1000

该错误码为内部错误。需要您检查测试手机连接的网络是否正确，或者重新发送请求。

## 如何查看HMS Core（APK）的版本

集成HEM SDK，App需要运行在华为Android终端设备上的HMS Core（APK）版本要求是5.2.1及以上版本。

查看方法：设备上选择"设置 > 应用 > 应用管理"，搜索"HMS Core"。
