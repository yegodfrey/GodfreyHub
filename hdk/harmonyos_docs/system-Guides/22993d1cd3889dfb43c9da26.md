# 版本更新说明

## 7.0.6.300（2024-01-11）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本网络请求功能：com.huawei.hms:network-embedded:7.0.6.300 Android版本文件上传/下载功能：com.huawei.hms:filemanager:7.0.6.300 **修改特性** 1.逃生机制优化 2.解决请求调用submit.cancel接口出现线程阻塞问题|

## SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）5.2.0.300及以上版本；如果用户手机安装了低版本的HMS Core（APK），您的应用调用HMS Core（APK）时，将根据用户设置的HMS Core静默安装策略完成Network Kit的下载升级；如果用户手机没有安装HMS Core（APK），将使用应用中已集成的Network Kit版本，不会进行下载升级。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
