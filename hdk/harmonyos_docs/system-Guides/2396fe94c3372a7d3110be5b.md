# 开发流程

#### 场景设计

开发者根据自己的业务对网络的诉求，设计对网络的使用策略。可以通过检测网络质量发现不满足业务诉求快速切换网络从而保障业务不中断，也可以同时使用多个网络进行数据请求从而获得大带宽。以下举例典型的使用场景。  

#### 业务零中断

在视频播放或VoIP通话场景，应用在Wi-Fi环境下建立好Socket通道后，使用如下方式快速切换网络，保障业务零中断：

* 方式一：整个应用业务粒度

  1. 当应用感知到视频卡顿或VoIP体验不佳时，将整个应用的业务绑定到蜂窝网络（参见[将业务绑定到特定网口](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/link-turbo-guide-api-0000001051088058#ZH-CN_TOPIC_0000001050825169__section119871412105619)）。
  2. 绑定成功后，在蜂窝网络里创建新的Socket通道，发送业务数据，保持业务连续性。
* 方式二：Socket级业务流粒度

  1. 当应用感知到某Socket流承载的视频卡顿或VoIP体验不佳时，如果当前Socket为TCP连接，需要重新创建Socket；如果当前Socket为UDP连接，无需重建Socket，使用原Socket即可。
2. 将Socket的业务绑定到蜂窝网络（参见[将Socket绑定到特定网口](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/link-turbo-guide-api-0000001051088058#ZH-CN_TOPIC_0000001050825169__section18355155725510)），绑定成功后发送业务数据，保持业务连续性。  

#### 聚合大带宽

在上传视频或下载大文件时，应用在Wi-Fi环境下建立好Socket通道后：

1. 创建新的Socket通道，将该Socket绑定到蜂窝网络（参见[将Socket绑定到特定网口](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/link-turbo-guide-api-0000001051088058#ZH-CN_TOPIC_0000001050825169__section18355155725510)）。

2. 绑定成功后，通过新建立的Socket从业务服务器同时拉取数据。

3. 应用将多个Socket获取的多网络的数据组装起来，通过此方式获得的多个网络的融合带宽。提高并发下载速度或上传速度，从而提升用户体验。

1. 在应用启动时，需要创建LocalSocket客户端，建立与系统LocalSocket服务器的通信通道，然后向系统注册。
2. 在向系统注册成功后，系统会发送LinkTurbo Engine状态变化、系统可用网络接口变化等事件，应用在收到事件后可以查询系统可用网络接口等信息。
3. 应用在需要接入LinkTurbo Engine的场景内，根据预先设计的网络使用方式（参见[场景设计](#ZH-CN_TOPIC_0000001051145110__section3597153112315)），通过LocalSocket的消息调用LinkTurbo Engine业务提供的接口，达成业务的网络使用方式。
4. 在应用结束时，向系统去注册。
