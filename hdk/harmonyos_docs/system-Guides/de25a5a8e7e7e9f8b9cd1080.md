# 在HUAWEI DevEco Studio项目中创建工程

HUAWEI DevEco Studio目前处于Beta阶段，需要向华为申请试用权限。同时也期待您在使用过程中给我们反馈您宝贵的意见，我们将持续进行优化，提升您的使用体验。

在使用HUAWEI DevEco Studio进行应用开发前，您应该提前知道如何"获取Beta权限"和"获取技术支持"通道。

1. 获取Beta权限。

   您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。
   1. 访问[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)。
   2. 注册华为开发者联盟帐号，并点击右上角头像旁边的下拉图标，点击"立即前往实名认证"上传信息进行实名认证。
   3. 实名认证后，在开发者联盟网站中选择"开发 > 开发工具 > HUAWEI DevEco Studio"。

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201112114002.17130102279639225368182199623131:50511112041428:2800:522D3C17404CA79C26BB185A006B63A13352B84539E3D8A85DB4A817A6BE921F.jpg?needInitFileName=true?needInitFileName=true "点击放大")
   4. 点击"试用申请"。

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201112114002.55174082718714126251041821066953:50511112041428:2800:61F1F297C6A1159B3BA171E644FEB7364B88157F42E9C928360C275FC46760A9.jpg?needInitFileName=true?needInitFileName=true "点击放大")
   5. 点击"我要报名"，并填写报名信息后，提交给华为进行审核。

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201112114002.37838918032675073515678250159477:50511112041428:2800:33EC506840A7F72769B4ACC6CCB4B3F48CD16CD4A86233F62CEEBB1F625925A1.png?needInitFileName=true?needInitFileName=true "点击放大")
      > 说明
      >
      > 提交申请后，华为将在1-2个工作日内对您的申请进行处理，并会及时通知您审批结果，请耐心等待。
2. 获取技术支持。

   您在使用Huawei DevEco Studio时，如果您有任何的问题或建议，都可以通过如下方式与我们取得联系。

   在线工单：登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)，在菜单栏选择"支持 > 技术支持 > 在线提单"，进入在线提单页面提交工单。
3. 安装和配置DevEco Studio。

   获取Beta权限后，您就可以下载HUAWEI DevEco Studio软件进行开发了。
   1. 登录华为开发者联盟官网。
   2. 点击右上角"管理中心"，然后点击"应用服务 > 开发服务"旁边的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201112114002.77074391596978212823954050222390:50511112041428:2800:2218DCF94482F0F9569DF082B4AD3459D333760638675D5BD5FEFA027C941D04.gif?needInitFileName=true?needInitFileName=true)图标，在弹出的配置框中勾选"HUAWEI DevEco Studio"卡片，然后点击"关闭"。

   3. 在开发服务中，点击"HUAWEI DevEco Studio"卡片，阅读和签署Beta保密协议。

5. 添加appid信息。

   在自身应用AndroidManifest.xml中添加开发者联盟创建应用时生成的appid信息，name为"com.huawei.hms.client.appid"，value为"appid=******"，******用自己注册的appid。

   ```screen
   <meta-data
       android:name="com.huawei.hms.client.appid"
       android:value="appid=******"/>
   ```
