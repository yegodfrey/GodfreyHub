# 在Android Studio项目中创建工程

1. 创建工程。
   1. 点击Start a new Android Studio project，新建Android Studio项目。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201112114002.40079935864679866969365705218029:50511112041428:2800:F21F261ADA7B9FCABCBBB185C601F736D139D401ACFA2308E8FDBB45C86F63BA.png?needInitFileName=true?needInitFileName=true "点击放大")

   2. 选择Empty Activity。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201112114002.76768633633311635383725988861207:50511112041428:2800:89D59BC6D417DB36051F195744D8125B7BDAF7891C341926D5ED7BF7EF77F9D5.png?needInitFileName=true?needInitFileName=true "点击放大")

   3. 填写文件名称，并点击Finish。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201112114003.38027114165904909194623831312851:50511112041428:2800:AE8BCA8C7B24C08C47B6F21060F24D0D693AB98544BB34F0F57B12CA1FF4A34D.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 添加appid信息。

   在自身应用AndroidManifest.xml中添加开发者联盟创建应用时生成的appid信息，name为"com.huawei.hms.client.appid"，value为"appid=******"，******用开发者注册的appid。

   ```screen
   <meta-data
       android:name="com.huawei.hms.client.appid"
       android:value="appid=******"/>
   ```
