# 开发指引

#### 业务流程

#### 设备间数据传输

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240708165610.65480611607151812012407178410045:50001231000000:2800:934FF5525593775496DA7FC194FBF48AE7694CD7F57ECF210B3050845DC8D848.png?needInitFileName=true?needInitFileName=true "点击放大")

整体流程可以划分为4个阶段。

1. 广播扫描：
   1. 广播端调用[startBroadcasting](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section17116532184219)(String, String, [ConnectCallback](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589), [BroadcastOption](https://developer.huawei.com/consumer/cn/doc/system-References/broadcastoption-0000001050132579))启动广播。
   2. 发现端调用[startScan](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section118310535196)(String, [ScanEndpointCallback](https://developer.huawei.com/consumer/cn/doc/system-References/scanendpointcallback-0000001050132583), [ScanOption](https://developer.huawei.com/consumer/cn/doc/system-References/scanoption-0000001050130634))启动扫描以发现附近的设备。
   3. 由[onFound](https://developer.huawei.com/consumer/cn/doc/system-References/scanendpointcallback-0000001050132583#section15556152801712)(String, [ScanEndpointInfo](https://developer.huawei.com/consumer/cn/doc/system-References/scanendpointinfo-0000001050130632))方法通知扫描结果。
2. 建立连接：
   1. 发现端调用[requestConnectEx](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section5430634112314)(String, String, [ConnectCallback](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589), [ConnectOption](https://developer.huawei.com/consumer/cn/doc/system-References/android-discovery-connectoption-0000001075801928))向广播端发起连接请求。
   2. 两端由[onEstablish](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589#section1487514421181)(String, [ConnectInfo](https://developer.huawei.com/consumer/cn/doc/system-References/connectinfo-0000001050130638))通知连接启动后，均可以调用[acceptConnect](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section9344760149)(String, [DataCallback](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654))接受连接或调用[rejectConnect](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section15885104571619)(String)拒绝连接。
   3. 两端由[onResult](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589#section3826114515249)(String, [ConnectResult](https://developer.huawei.com/consumer/cn/doc/system-References/connectresult-0000001050130640))通知连接结果。仅当两端都接受连接时，连接才能建立。
3. 传输数据：
   1. 连接建立后，两端均可以调用[sendData](https://developer.huawei.com/consumer/cn/doc/system-References/transferengine-0000001050130658#section10201153764712)(String, [Data](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599))发送数据给对端。
   2. 接收数据的一端由[onReceived](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654#section4844134385219)(String, [Data](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599))通知接收到数据；两端由[onTransferUpdate](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654#section18715435195410)(String, [TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/system-References/transferstateupdate-0000001050132605))通知当前的传输状态。
4. 断开连接： 主动断开连接的一端调用[disconnect](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section31761824181518)(String)断开连接，对端由[onDisconnected](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589#section10427162616103)(String)通知连接断开。

* Nearby Connection服务只在处理业务时，才使用对端设备的蓝牙标识符，且不会在磁盘中存储。
* 持续蓝牙广播，扫描会引起2.4GHz频段发送bytes耗时明显增加，建链成功之后建议关闭广播、扫描。
* Nearby Connection服务在数据传输过程中，建议保持设备屏幕处于亮屏状态，避免数据传输失败。
