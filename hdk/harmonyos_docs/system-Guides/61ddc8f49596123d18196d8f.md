# 版本更新说明

## 6.10.0.100（2023-04-26）

|-------------------------------------------------------------|
|Android版本：com.huawei.hms:wireless:6.10.0.100 **修改特性** 依赖组件升级。|

## SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）5.3.0.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。

## 历史版本

### 5.0.3.302（2020-09-27）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
