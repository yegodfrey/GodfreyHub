# URL请求

#### 概述

Network Kit提供了使用[HttpClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-0000001073658008)实例发送请求（Client风格，类似OkHttp）和使用[RestClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-restclient-restclient-0000001050197774)实例发送请求（RESTful风格，类似Retrofit）共两种使用方式。两种使用方式在应用层方面使用两套不同的接口，提供了相同的网络通信能力，您只需选择其中一种集成方式即可。下面将分别为您讲解。  

#### HttpClient方式请求示例

使用[HttpClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-0000001073658008)方式发送网络请求可以通过如下操作实现。详细开发过程和代码实现可以参见[codelab（URL请求集成）](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/Network-URL)和[示例代码](https://developer.huawei.com/consumer/cn/doc/system-Examples/network-sample-code-0000001081852581)。

1. 异步加载[NetworkKit](https://developer.huawei.com/consumer/cn/doc/system-References/network-networkkit-0000001050171213)对象并初始化。

   <br />

   ```
   /**
    * 异步加载NetworkKit。
    */
   public void init() {
       // 只需要初始化一次。再次调用不会重新初始化，但会再次回调onResult方法。
       NetworkKit.init(getApplication(), new NetworkKit.Callback() {
           @Override
           public void onResult(boolean result) {
               if (result) {
                   // Networkkit初始化成功
                   Log.i(TAG, "Networkkit init success");
               } else {
                   // Networkkit初始化失败
                   Log.i(TAG, "Networkkit init failed");
               }
           }
       });
   }
   ```

   <br />

2. 创建[HttpClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-0000001073658008)对象，并设置网络请求超时时间等参数。

   <br />

   ```
   /**
    * 创建HttpClient对象。
    */
   public HttpClient createClient() {
       HttpClient httpClient = new HttpClient.Builder()
              // (可选) 设置请求超时时长，单位毫秒           
               .callTimeout(10000)
              // (可选) 设置连接超时时长，单位毫秒
               .connectTimeout(10000)
               // (可选) 添加应用拦截器，一次调用只执行一次               
               .addInterceptor(new TestCustomInterceptor())
               // (可选) 添加网络拦截器，每次请求均会执行                
               .addNetworkInterceptor(new TestCustomInterceptor())
                //（可选）设置读超时时长，单位毫秒                
               .readTimeout(10000)
                //（可选）设置是否允许开启QUIC，默认不开启                
               .enableQuic(false)
               .build();
               return httpClient;
           }
   ```

   <br />

3. 构造[Request](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-request-0000001073688886)请求对象，并设置[Request](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-request-0000001073688886)对象的请求参数。更多参数设置请参见[Request.Builder](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-requestbuilder-0000001073048939)。

   <br />

   ```
   /**
    * 构造Request请求对象。
    */
   public void createRequest() {
       String URL = "https://developer.huawei.com/";
       Request request = httpClient.newRequest()
       // 设置此次请求使用的URL            
       .url(URL)
       // 设置此次请求使用的HTTP方法            
       .method("GET")
       .build();
   }
   ```

   <br />

4. 使用[HttpClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-0000001073658008)对象，发送同步请求或异步请求。同步请求需要获取响应后再继续执行其他操作，异步请求在请求发送后不需等待请求结果即可执行其他操作，通常推荐使用异步请求方式。

   <br />

   ```
   /**
    * （1）使用HttpClient对象发送同步请求（使用时请您在子线程中调用）。
    */
   public void httpClientExecute() {
       try {
         Response<ResponseBody> response = httpClient.newSubmit(request).execute();
         // 请求成功，处理响应。
          Log.i(TAG, "response code:" + response.getCode());
       } catch (IOException e) {
          // 请求失败，处理异常。
          Log.w(TAG, "response onFailure = " + e.getMessage());
       }
   }
   /**
    * （2）使用HttpClient对象发送异步请求。
    */
   public void httpClientEnqueue() {
       httpClient.newSubmit(request).enqueue(new Callback<ResponseBody>() {
           @Override
           public void onResponse(Submit<ResponseBody> submit, Response<ResponseBody> response)
           throws IOException {
            // 请求成功，回调此方法处理响应。
           Log.i(TAG, "response code:" + response.getCode());
           }

           @Override
           public void onFailure(Submit<ResponseBody> submit, Throwable throwable) {
           // 请求失败，回调此方法处理异常。
           Log.w(TAG, "response onFailure = " + throwable.getMessage());
           }
       });
   }
   ```

   <br />

5. 分别获取同步或异步请求返回的响应数据并解析，获取需要的值或对象。  

#### RestClient注解方式请求示例

使用RestClient注解方式发送网络请求可以通过如下操作实现。详细开发过程和代码实现可以参见[codelab（URL请求集成）](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/Network-URL)和[示例代码](https://developer.huawei.com/consumer/cn/doc/system-Examples/network-sample-code-0000001081852581)。

1. 异步加载[NetworkKit](https://developer.huawei.com/consumer/cn/doc/system-References/network-networkkit-0000001050171213)对象并初始化（与[HttpClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-httpclient-0000001073658008)方式一致）。

   <br />

   ```
   /**
    * 异步加载NetworkKit。
    */
   public void init() {
       // 只需要初始化一次。再次调用不会重新初始化，但会再次回调onResult方法。
       NetworkKit.init(getApplication(), new NetworkKit.Callback() {
            @Override
            public void onResult(boolean result) {
                if (result) {
           // Networkkit初始化成功                
           Log.i(TAG, "Networkkit init success");
                } else {
          // Networkkit初始化失败                
          Log.i(TAG, " Networkkit init failed");
                }
            }
        });
   }
   ```

   <br />

2. 创建[RestClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-restclient-restclient-0000001050197774)对象。

   <br />

   ```
   /**
    * 创建RestClient对象。
    */
   private void createRestClient() {
       RestClient restClient = new RestClient.Builder()
                  .httpClient(new HttpClient.Builder().build())
                  .build();
   }
   ```

   <br />

3. 声明请求接口。

   <br />

   ```
   /**
    * 声明请求接口。
    */
   interface SampleService {
       @GET
       Submit<String> getTest(@Url String url);
   }
   ```

   <br />

4. 使用[RestClient](https://developer.huawei.com/consumer/cn/doc/system-References/network-restclient-restclient-0000001050197774)对象，创建请求接口对象。

   <br />

   ```
   // 要请求的地址。
   private static final String URL = "https://developer.huawei.com/";
   // 创建请求接口对象。
   SampleService sampleService = restClient.create(SampleService.class);
   ```

   <br />

5. 使用创建的接口实例，发送同步或异步请求。同步请求需要获取响应后再继续执行其他操作，异步请求在请求发送后不需等待请求结果即可执行其他操作，通常推荐使用异步请求方式。

   <br />

   ```
   /**
    * （1）使用创建的接口对象发送同步请求（使用时请您在子线程中调用）。
    */
   public void annoExecute() {
       try {
           Response<String> response = sampleService.getTest(URL).execute();
           // 处理响应，请求成功。
           Log.i(TAG, "response code:" + response.getCode());
       }catch (Exception e) {
           String errorMsg = "response onFailure : ";
           if (e.getMessage() != null) {
               errorMsg += e.getMessage();
           }
           Log.w(TAG, errorMsg);
       }
   }

   /**
    * （2）使用创建的接口对象发送异步请求。
    */
   public void annoEnqueue() {
       sampleService.getTest(URL).enqueue( new Callback<String>() {
           @Override
           public void onResponse(Submit<String> submit, Response<String> response)
                   throws IOException {
               // 获取响应，请求成功则回调此方法。
               Log.i(TAG, "response code:" + response.getCode());
           }

           @Override
           public void onFailure(Submit<String> submit, Throwable throwable) {
               // 获取响应，请求失败则回调此方法。
               Log.w(TAG, "response onFailure = " + throwable.getMessage());
           }
       });
   }
   ```

   <br />

6. 分别获取同步或异步请求返回的响应数据并解析，获取需要的数据或对象。
