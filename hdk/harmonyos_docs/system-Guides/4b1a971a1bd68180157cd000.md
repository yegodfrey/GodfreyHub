# 开发指引

## 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231121105006.68980678779159770703347898249099:50001231000000:2800:1FD1D98599168AC588618295757F9AE9860ED6DE157A63242A4790A3D0E6CEE9.png?needInitFileName=true?needInitFileName=true)

整体流程可以划分为3个阶段。

1. 绑定服务：
   1. App获取Wireless Kit的[IQoeService](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784)对应的Intent。
   2. 使用上一步中得到的Intent绑定[IQoeService](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784)。
2. 使用服务：
   1. Wireless会发送弱信号预测广播，App可以接收弱信号预测广播。
   2. App可以使用[registerNetQoeCallBack](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784#section101119651619)注册网络QoE信息的回调，Wireless回调网络QoE信息给App。
   3. App可以使用[queryRealTimeQoe](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784#section54415107325)查询实时QoE信息。
   4. App可以使用[reportAppQuality](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784#section29691849561)反馈应用数传故障等信息给Wireless。
3. 解绑服务： App解除和[IQoeService](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784)的绑定关系。在解绑服务之前，若APP已注册网络QoE信息回调，需使用[unRegisterNetQoeCallBack](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784#section6231151772917)去注册网络QoE信息回调。

## 异常流程

1. [getNetworkQoeClient(Activity activity)](https://developer.huawei.com/consumer/cn/doc/system-References/wirelessclient-0000001051067902#section12617195934414)或者[getNetworkQoeClient(Context context)](https://developer.huawei.com/consumer/cn/doc/system-References/wirelessclient-0000001051067902#section122694121797)接口返回为null，确认入参非null后，重新调用接口。
2. [getNetworkQoeServiceIntent](https://developer.huawei.com/consumer/cn/doc/system-References/networkqoeclient-0000001050987967#section1833218156528)异步返回值调用[OnFailureListener](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/onfailurelistener-0000001050123093)，说明获取intent失败。错误码及解决方法请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)和[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)。
3. [IQoeService](https://developer.huawei.com/consumer/cn/doc/system-References/iqoeservice-0000001051066784)里的接口调用返回值错误码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)。
