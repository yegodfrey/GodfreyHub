# 使用入门

## 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8.211及以上
* 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上

  * minSdkVersion 21及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 5.4.1及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个服务对应的最大值。
* 测试应用的设备：EMUI 5.0 ~ 11、HarmonyOS 2.0及以上的华为手机或Android 5.0 ~ 12的非华为手机。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|开发步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001050040578)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001050040578#section122101316114910)、[创建应用](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001050040578#section5708730134710)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001050040578#section840133823911)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001050040578#section18312134018452)。|
|2|[开通服务](https://developer.huawei.com/consumer/cn/doc/system-Guides/enabling-service-0000001050042529)|开通华为近距离通信服务的相关能力。|
|3|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/system-Guides/android-integrating-sdk-0000001050126093)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|4|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-obfuscation-scripts-0000001050262540)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|5|[添加权限](https://developer.huawei.com/consumer/cn/doc/system-Guides/nearbyservice-add-access-0000001142548835)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|6|[Nearby Connection开发](https://developer.huawei.com/consumer/cn/doc/system-Guides/connection-preparations-0000001050040586)|调用Nearby Connection接口实现近距离设备间数据传输功能。|
|7|[Nearby Message开发](https://developer.huawei.com/consumer/cn/doc/system-Guides/message-preparations-0000001050042561)|调用Nearby Message接口实现近距离设备间消息发布与订阅。|
|8|[开发后自检](https://developer.huawei.com/consumer/cn/doc/system-Guides/pre-release-check-0000001050185713)|华为提供对应用自动检查的能力。|
|9|[上架申请](https://developer.huawei.com/consumer/cn/doc/system-Guides/app-release-0000001606198930)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。
