# 开发指引

Nearby Message提供以下两种业务：第一种是基于应用的消息发布和订阅，第二种是基于信标的消息发布和订阅。  

#### 注意事项

* 仅限企业开发者账号注册信标设备，个人开发者仍可基于应用完成消息发布和订阅。
* 请注意尊重用户隐私，提醒用户使用Nearby Message服务时，不要发布敏感信息。
* 请明确告知用户，使用Nearby Message服务会开启蓝牙广播扫描功能，可能导致耗电量增加。
* 在进行应用开发时，当应用退出的时候，请必须调用[unput](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section1811517564180)([Message](https://developer.huawei.com/consumer/cn/doc/system-References/message-message-0000001050132615))接口回收发布的消息和[unget](https://developer.huawei.com/consumer/cn/doc/system-References/messageengine-0000001050130686#section16678445206)([MessageHandler](https://developer.huawei.com/consumer/cn/doc/system-References/messagehandler-0000001050132619))接口停止订阅消息。
* 请遵守适用的数据保护法律法规，包括但不限于对个人数据的收集和处理、识别用户身份以及履行数据主体权利。
* 请负责存储用户的设备和网络标识符，Nearby服务不会存储用户的任何设备/网络标识符。
* 请保证不要在用户不知情的情况下发布或订阅消息，并且让用户易于停止消息的发布和订阅。  

#### 设置API Key

API Key鉴权凭证有两种使用方式：

* 预置JSON配置文件：在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的"app"目录下。这种方式使用简单，但存在安全问题，可能被别人通过反编译等非法手段获取。
* 通过接口设置API Key：获取方法参见[创建API Key](#section35181620141120)。创建之后，您需要在使用近距离通信服务API之前，调用[setApiKey](https://developer.huawei.com/consumer/cn/doc/system-References/nearbyapicontext-0000001050751045#section1143911511016)(String)进行设置，示例代码如下。这种方法需要您修改代码，但安全性更高。

  ```
  NearbyApiContext.getInstance().setApiKey("CV6r****rOyJ");
  ```

#### 创建API Key

在[开发者联盟](https://developer.huawei.com/consumer/cn)网站上获取API Key，具体操作步骤请参见[API密钥](https://developer.huawei.com/consumer/cn/doc/start/api-0000001062522591#ZH-CN_TOPIC_0000001062522591__section1853870145112)。为增强API Key的安全性，推荐您对API Key进行限制。可以在API Key的编辑页面进行"应用限制"和"API限制"。  

#### 设置数据处理位置策略

数据处理位置策略有两种配置方式：

* 配置数据处理位置策略：在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，"项目设置 \> 数据处理位置"页面设置数据处理位置策略。具体请参见[配置数据处理位置策略](https://developer.huawei.com/consumer/cn/doc/system-Guides/enabling-service-0000001050042529#section1745530172214)。
* 您也可以调用[setAgcRegion](https://developer.huawei.com/consumer/cn/doc/system-References/nearby-0000001050130624#section8221131865518)(Context context, [RegionCode](https://developer.huawei.com/consumer/cn/doc/system-References/regioncode-0000001375412093) code)进行设置，此接口可以在Application的onCreate()中调用，设置示例代码如下。

  ```
  int code = Nearby.setAgcRegion(getApplicationContext(), RegionCode.CN);
  ```
