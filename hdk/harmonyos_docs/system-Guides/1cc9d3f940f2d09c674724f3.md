# 配置网络权限

在targetSdkVersion 28及以上的手机上允许HTTP(S)网络请求，建议在AndroidManifest.xml做以下配置。

```java
<application
    ...
    // 指示应用程序是否打算使用明文网络流量，例如明文HTTP
    android:usesCleartextTraffic="true"
    >
    ...
</application>
```
