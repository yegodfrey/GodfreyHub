# 万能联播集成华为Nearby Service，提升音视频分享体验

## 万能联播简介

万能联播是爱奇艺团队开发的一款广受欢迎的视频播放器，秉承着"爱分享，更快乐"的理念，不断追求着更好的视频播放与分享体验。支持在Android手机、iPhone及电脑间跨平台设备间高速互传，在附近的人之间可共享音视频图片等资源，支持卡片式浏览视频资源，并支持多种音视频格式的播放。自推出以来，凭借着过硬的品质获得海内外用户的一致好评。

## 业务挑战

万能联播想要快速在众多视频播放类软件中脱颖而出，引领自己的潮流，面临以下挑战：

* 如何提供更好的音视频分享体验。


* 如何快速完成集成开发。

## 解决方案

通过集成华为Nearby Service，万能联播实现了更快的设备发现速度和文件传输速率，带给用户更快速的文件分享体验。

* 传输速率快：基于华为自研协议，节点发现速率和文件传输速率均大幅度优于业界既有方案。


* API简单易用：Nearby Service提供简单易用的文件传输API，您不再需要关心底层蓝牙、Wi-Fi等网络细节，极大程度简化开发工作量。

## 集成价值

Nearby Service为万能联播提供面对面视频分享能力，操作更便捷，传输更高速，从以下几点体现对用户的价值：

* 解决网络覆盖面积和网速不理想地区使用互联网传输和下载音视频的麻烦，节省用户流量。


* 设备间音视频传输不再依赖于社交软件的聊天功能进行分享，也不用导入电脑进行中转。


* 免除用户使用系统蓝牙或WLAN直连时麻烦的组网操作。


* 避免使用系统蓝牙或WLAN直连时传输速率低带来的长时间等待。
