# TamTam集成华为Nearby Service，开启面对面交友新方式

## TamTam简介

TamTam是由俄罗斯最大的网络公司Mail.ru集团研发的一款集聊天、视频通话、语音通话等为一体的社交通讯App。它的目的是为用户提供更快，更好的聊天和呼叫体验。

## 业务挑战

TamTam致力于为用户提供良好的聊天通讯体验，为用户提供更好的交友聊天方式。TamTam需要解决：

* 如何帮助用户将新认识的朋友添加为TamTam好友。
* 如何利用手机发现附近的人，方便地添加为好友，实现更快捷的交友方式。

## 解决方案

TamTam通过集成Nearby Servcie提供近距离社交服务，使得TamTam用户能更加方便地搜索到附近的其他用户，将其添加为TamTam好友。

## 合作收益

* TamTam 集成了Nearby Service，实现了面对面添加好友功能，开发简单。

* TamTam用户 精准扫描出面对面的好友，解决了基于GPS位置查找附近好友不精准问题，提升了体验。
