# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 哪些设备支持5G Modem Kit？

目前5G Modem Kit众测服务只支持使用Kirin990、Kirin985、Kirin820及Kirin9000芯片平台的华为手机。通信体验优化功能只支持使用Kirin9000芯片平台的华为手机。  

#### 5G Modem Kit对手机系统版本有没有约束？

目前5G Modem Kit众测服务支持HarmonyOS 2.0及以上的手机版本。通信体验优化功能支持HarmonyOS 3.0及以上的手机版本。  

#### 5G Modem Kit服务调用异常怎么办？

* 查看对应的[错误码](https://developer.huawei.com/consumer/cn/doc/system-References/error-code-0000001126788617)信息。

<!-- -->

* 检查您使用的软、硬件是否满足要求。

<!-- -->

* 检查是否开启了所需的权限，在接入5G Modem Kit众测服务时需要开启位置权限。

<!-- -->

* 检查您的网络状态，请检查您的设备是否可以正常连接网络。
