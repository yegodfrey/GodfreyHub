# 快牙集成华为Nearby Service，文件传输速率倍增

#### 快牙简介

快牙是一款实现跨平台文件传输的应用，能帮助智能手机用户之间实现高速海量数据传输。支持Android、iOS、WP、PC、Mac等多种智能终端间的互联互通。通过快牙，可以和任何人分享应用、照片、视频、音乐及其他任意格式文件。目前快牙全球用户数量已达6亿，遍及海内外200多个国家和地区，在同类型的传输应用中稳居前列。  

#### 业务挑战

面对业内众多文件传输App，快牙如何脱颖而出，面临以下挑战：

* 如何快速发现周边的设备。
* 如何高速传输文件。  

#### 解决方案

通过集成华为Nearby Service快牙实现了50MB/s的文件传输速率，带给用户更快速的文件分享体验。

* 传输速率快：基于华为自研协议，节点发现速率和文件传输速率均大幅度优于业界既有方案。
* API简单易用：封装底层网络细节，您无需处理各种组网难题。

#### 合作受益

* 快牙 集成华为Nearby Service，文件传输速率可达50MB/s，传输3G大小的文件仅需1分钟，大幅提升了文件传输速率，提升用户体验。

* 快牙用户 享受更加高效、安全的文件传输服务。
