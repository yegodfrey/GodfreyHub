# 开发步骤

## 绑定服务

获取[WifiEnhanceClient](https://developer.huawei.com/consumer/cn/doc/system-References/dualwificlient-0000001097621682)对象。利用[getWifiEnhanceServiceIntent](https://developer.huawei.com/consumer/cn/doc/system-References/dualwificlient-0000001097621682#section1833218156528)接口获取Intent，并绑定IWifiEnhanceService服务。若Intent获取失败，App无法使用[IWifiEnhanceService](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634)服务。错误码及解决方法请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)和[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)。

如下示例代码里WifiEnhanceActivity绑定IWifiEnhanceService服务。

```screen
// 根据需要添加Android相关类
import com.huawei.hmf.tasks.OnFailureListener;
import com.huawei.hmf.tasks.OnSuccessListener;
import com.huawei.hms.common.ApiException;
import com.huawei.hms.wireless.IWifiEnhanceService;
import com.huawei.hms.wireless.WirelessClient;
import com.huawei.hms.wireless.WirelessResult;
import com.huawei.hms.wireless.wifi.WifiEnhanceClient;

public class WifiEnhanceActivity extends AppCompatActivity {
    private static WifiEnhanceActivity sInstance = null;
    private IWifiEnhanceService mWifiEnhanceService = null;
    private ServiceConnection mServiceConnection = new ServiceConnection() {
        @Override
        public void onServiceConnected(ComponentName name, IBinder service) {
            // 服务连接，绑定IWifiEnhanceService服务
            mWifiEnhanceService = IWifiEnhanceService.Stub.asInterface(service);
        }

        @Override
        public void onServiceDisconnected(ComponentName name) {
            // 服务断开，WifiEnhanceService置为null
            mWifiEnhanceService = null;
        }
    };

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        WifiEnhanceClient wifiEnhanceClient = WirelessClient.getWifiEnhanceClient(WifiEnhanceActivity.this);
        wifiEnhanceClient.getWifiEnhanceServiceIntent()
                .addOnSuccessListener(new OnSuccessListener<WirelessResult>() {
                    @Override
                    public void onSuccess(WirelessResult wirelessResult) {
                        Intent intent = wirelessResult.getIntent();
                        // intent获取失败， app无法使用IWifiEnhanceService服务
                        if (intent == null) {
                            return;
                        }
                        WifiEnhanceActivity.this.bindService(intent, mServiceConnection, Context.BIND_AUTO_CREATE);
                    }
                })
                .addOnFailureListener(new OnFailureListener() {
                    @Override
                    public void onFailure(Exception exception) {
                        if (exception instanceof ApiException) {
                            ApiException ex = (ApiException) exception;
                            int errCode = ex.getStatusCode();
                        }
                    }
                });
    }
}
```

## 使用IWifiEnhanceService提供的服务

### 设置Wi-Fi高优先级发包

当Wi-Fi处于连接状态时，可调用[setHighPriority](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634#section54415107325)接口使能或者禁用Wi-Fi高优先级发包功能。

```screen
public class WifiEnhanceActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        if (mWifiEnhanceService != null) {
            try {
                mWifiEnhanceService.setHighPriority("com.huawei.hms.wirlesstestdemo", 6, 1);
            } catch (RemoteException exception) {
                // 这里可以添加打印
            }
        }
    }
}
```

> 说明
>
> [setHighPriority](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634#section54415107325)接口参数说明：
>
> * 参数1：App自身包名。
> * 参数2：使能协议类型，使能时需要设置正确的协议类型（6表示TCP，17表示UDP）；禁用时可随意设置，会同时禁用TCP和UDP。
> * 参数3：使能模式，1表示使能，0表示禁用。

## 解绑服务

使用Android服务机制，App解绑[IWifiEnhanceService](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634)。

如下示例代码里WifiEnhanceActivity解绑Wi-Fi增强服务。

```screen
// mServiceConnection要与绑定时的ServiceConnection对象保持一致。在onCreate函数或者onDestroy函数中调用。
WifiEnhanceActivity.this.unbindService(mServiceConnection); 
```
