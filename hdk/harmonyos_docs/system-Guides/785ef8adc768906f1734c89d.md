# 开发指引

#### 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231121105009.68246703197528046839908666216826:50001231000000:2800:4C9F844F26DF4CA7ED3D9A51811C707E53C50286AEFFE74624886B3C8CA9ADE8.png?needInitFileName=true?needInitFileName=true)

整体流程可以划分为3个阶段。

1. 绑定服务：
   1. App获取Wireless Kit的[IDualWifiService](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627)对应的Intent。
   2. 使用上一步中得到的Intent绑定[IDualWifiService](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627)。
2. 使用服务：
   1. App可以使用[enableDualWifi](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627#section8146125774712)来开启双Wi-Fi。
   2. App可以使用[disableDualWifi](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627#section984718528548)来关闭双Wi-Fi。
   3. App可以在使能双Wi-Fi后接收Wi-Fi信号和状态变化的广播。 App可以使用[getSlaveWifiConnectionInfo](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627#section73981566599)获取Wi-Fi2的连接信息。

      App可以使用[getLinkPropertiesForSlaveWifi](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627#section107883191572)获取Wi-Fi2连接的网络链路属性。

      App可以使用[getNetworkInfoForSlaveWifi](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627#section4864201914117)获取Wi-Fi2的网口状态。
3. 解绑服务： App解除和[IDualWifiService](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627)的绑定关系。

#### 异常流程

1. [getDualWifiClient(Activity activity)](https://developer.huawei.com/consumer/cn/doc/system-References/wirelessclient-0000001051067902#section1224165715317)或者[getDualWifiClient(Context context)](https://developer.huawei.com/consumer/cn/doc/system-References/wirelessclient-0000001051067902#section10491422193313)接口返回为null，确认入参非null后，重新调用接口。
2. [getDualWifiServiceIntent](https://developer.huawei.com/consumer/cn/doc/system-References/wifienhanceclient-0000001054335451#section1377518421554)异步返回值调用[OnFailureListener](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/onfailurelistener-0000001050123093)，说明获取Intent失败。错误码及解决方法请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)和[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)。
3. [IDualWifiService](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627)里的接口调用返回值错误码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)。
