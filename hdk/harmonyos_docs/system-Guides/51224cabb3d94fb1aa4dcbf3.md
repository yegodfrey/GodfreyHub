# 前言

由于MDM能力API大都具有敏感权限，为保障消费者权益，华为将对开发者的资质、API的具体使用场景等做审核之后，予以授权使用。目前有License和证书两种授权方式。

* License授权通过集成HEM Kit，为已审批项目中的设备进行远程授权。
* 证书授权通过申请证书后将证书集成到对应的APK中进行线下授权。
