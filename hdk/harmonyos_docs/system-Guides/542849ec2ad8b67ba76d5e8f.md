# 使用入门

#### 开发环境

* 安装Android Studio 4.0及以上

* JDK 1.8及以上
* 您的应用应满足以下条件：

  * minSdkVersion 21及以上
  * targetSdkVersion 29（推荐）
  * compileSdkVersion 29（推荐）
  * Gradle 3.4及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 自定义振动类型要求测试应用的设备：EMUI 11.1.0及以上的手机

* 系统预置振动类型要求的试应用的设备：EMUI 9.0及以上的手机  

#### 开发流程

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/configure_appgallery_connect-0000001089188071)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹、打开相关服务。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/integrated_hms_core_sdk-0000001076772888)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/configure_obfuscation_script-0000001077060962)|您编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/add_permissions-0000001077220932)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[自定义振动类型](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/json_file_as_input_parameter-0000001089822959)|您可以根据实际情况选择Haptics Engine提供的自定义振动类型的API，实现应用内调用线性马达的自定义振动。|
|6|[系统预置振动类型](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/client-dev-0000001051148004)|您可以根据实际情况选择Haptics Engine提供的系统预置振动类型的API，实现应用内调用线性马达的系统预置振动。|
|7|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/pre-release-check-0000001051148000)|华为提供对应用自动检查的能力。|
|8|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/app-release-0000001050830169)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
