# 权限申请

基于安全考虑，服务侧对开放的接口做了权限保护处理，使用相关接口需要向华为方申请对应权限。权限申请需提供开发者联盟网站创建应用时生成的appid，且指纹信息已配置。权限申请请通过"支持 \> 技术支持 \> 在线提单"提交，华为支持人员会及时处理。
