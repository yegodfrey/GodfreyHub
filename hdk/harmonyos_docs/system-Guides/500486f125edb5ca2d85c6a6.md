# 开发指引

## 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231121105004.82130886114608106391562908002245:50001231000000:2800:3B0B378C75DAC5223889E79B5060C5D570539D9109B9C61F2DF5FCC6FA1AE13E.jpg?needInitFileName=true?needInitFileName=true "点击放大")

整体流程可以划分为3个阶段。

1. 绑定服务：
   1. App获取Wireless Kit的[IWifiEnhanceService](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634)对应的Intent。
   2. 使用上一步中得到的Intent绑定[IWifiEnhanceService](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634)。
2. 使用服务： App可以使用[setHighPriority](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634#section54415107325)使能/禁用Wi-Fi高优先级发包功能。

3. 解绑服务： App解除和[IWifiEnhanceService](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634)的绑定关系。

## 异常流程

1. [getWifiEnhanceClient(Activity activity)](https://developer.huawei.com/consumer/cn/doc/system-References/wirelessclient-0000001051067902#section102472479185)或者[getWifiEnhanceClient(Context context)](https://developer.huawei.com/consumer/cn/doc/system-References/wirelessclient-0000001051067902#section1324834721816)接口返回为null，确认入参非null后，重新调用接口。
2. [getWifiEnhanceServiceIntent](https://developer.huawei.com/consumer/cn/doc/system-References/dualwificlient-0000001097621682#section1833218156528)异步返回值调用[OnFailureListener](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/onfailurelistener-0000001050123093)，说明获取intent失败。错误码及解决方法请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)和[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)。
3. [IWifiEnhanceService](https://developer.huawei.com/consumer/cn/doc/system-References/iwifienhanceservice-0000001054337634)里的接口调用返回值错误码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)。
