# 动态调节振动波形

动态调节分为动态强度调节与动态锐度调节，调节参数由开发者设置。调节参数设置的不同，Haptics Engine处理机制如下：

* 静态强度调节的时间点和动态强度调节的时间点相等，则将此时间点的动态强度调节值与静态强度调节值相乘，得到一个合成的调节值。
* 静态强度调节的时间点和动态强度调节的时间点不相等，则将动态强度调节加入到调节序列中。
* 静态锐度调节的时间点和动态锐度调节的时间点相等，则将此时间点的动态锐度调节值与静态锐度调节值相加，得到一个合成的调节值。
* 静态锐度调节的时间点和动态锐度调节的时间点不相等，则将动态锐度调节加入到调节序列中。

1. 导入需要的包。

   ```
   import com.huawei.devices.hapticsengine.HapticChannel; 
   import com.huawei.devices.hapticsengine.HapticCurve;
   import com.huawei.devices.hapticsengine.HapticPlayer; 
   ```

2. 创建HapticPlayer对象。

   ```
   HapticPlayer mHapticPlayer = new HapticPlayer(this);
   ```

3. 创建动态调节曲线。

   ```
   HapticCurve.Builder curveIntensityBuilder = new HapticCurve.Builder();
   ```

4. 将动态调节值添加到动态调节曲线。

   ```
   HapticCurve.AdjustPoint adjustPoint = new HapticCurve.AdjustPoint(20, 10);
   curveIntensityBuilder.addAdjustPoint(adjustPoint);
   ```

5. 对振动波形的强度和锐度进行调节。

   ```
   HapticCurve curveIntensity = curveIntensityBuilder.build();
   // 对振动波形的强度进行动态调节
   boolean isIntensity = mHapticPlayer.setDynamicCurve(HapticCurve.CURVE_TYPE_INTENSITY, HapticChannel.HAPTIC_CHANNEL_A, curveIntensity);
   ```
