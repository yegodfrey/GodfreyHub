# 业务介绍

#### 业务简介

5G Modem Kit依托于基于海思芯片的华为终端强大的Modem能力为您提供以下两种功能。

* 众测功能：您通过集成5G Modem Kit的SDK，可以获取如CSI-RS RRM测量、动态频谱共享、非独立组网下LTE锚点信息等网络数据，提升众测数据的准确性和丰富性。
* 通信体验优化功能：通过集成5G Modem Kit的SDK，可以获取部分Modem能力，增强应用在蜂窝网络下的用户体验。  

#### 支持的设备

|服务|设备类型|芯片平台|OS版本|
|:-------|:---|:---------------------------------------|:--------------------------------------------------------------------------------------------------|
|众测功能|华为手机|* Kirin990、Kirin985和Kirin820 * Kirin9000|HarmonyOS 2.0版本：支持LTE、NR(NSA组网)和Bearer信息的参数上报 EMUI 12版本：支持LTE、NR(NSA组网和SA组网)、Bearer，网络诊断以及失败事件的信息上报|
|通信体验优化功能|华为手机|* Kirin9000|HarmonyOS 3.0版本及以上|

#### 场景介绍

众测功能：通过在App中集成5G Modem Kit的SDK可以获取网络参数信息，包括LTE、NR、Bearer信息。众测厂商获取到海量的网络参数信息后可以生成用户体验报告，为网络评估、调优提供基础的数据支撑。

通信体验优化功能：通过在App中集成5G Modem Kit的SDK可以使用Modem提供的部分增强能力，包括上下行空口实时速率、上行数据缓存最大时长、弱网环境提前预测等。应用可在不同业务场景下，借助Modem增强能力，提升用户体验。  

#### 功能使用限制

众测服务需要您的App获得用户位置授权后才能使用，具体请参见[添加权限](https://developer.huawei.com/consumer/cn/doc/system-Guides/add-permissions-0000001126152769)。
