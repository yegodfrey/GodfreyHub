# 证书申请

## 华为证书介绍

### 华为证书的基本格式

MDM能力的证书是一个以".cer"后缀结尾的文件，格式如下：

* DeveloperKey：开发者签名，与android.content.pm.Signature.toCharsString()的输出相同。
* PackageName：开发者应用包名。
* Permissions：开发者想要申请的权限。
* DeviceIds：开发者应用被限制使用的设备，仅限开发证书有效，商用证书时无效。
* ValidPeriod：证书有效期，如果有效期过期，则应用在华为设备上安装失败，目前开发证书的有效期为6个月。
* ApkHash：开发者应用HASH值，在商用证书中必选。
* Signature：前6项SHA256 HASH值的签名。

### 华为证书的分类

华为证书目前分为两类：开发证书和商用证书。

* 开发证书：专门为开发者提供的一种调试适配阶段的证书，设备数量（DeviceIds字段）会被严格限制在50台以内，ApkHash字段不做限制。
* 商用证书：作为开发者使用开发证书进行功能调试完成之后，处于正式商用阶段的证书。一般DeviceIds字段不做限制，ApkHash字段必选。 商用证书分为临时证书和正式证书。存在临时证书这一环节是由于集成证书后需要上传APK给华为审核，V1+V2签名的APK因为APK的完整性校验，任何对APK的修改，在安装时都会失败，打包证书后APK发生了改变，上传的APK无法审核，需要二次签名才能安装，所以需要集成临时证书并进行二次签名后再提交申请得到正式证书。

> 说明
>
> 开发者在使用开发证书调试完成之后，一定要申请正式商用证书，才能正式发布。

### 开发证书

开发证书的申请流程如下图，详细步骤参见[证书申请指导](#section54599303111)。开发证书的审核一般需要2~3个工作日。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/YiemTEUUTJq3Eztz_UnaMA/zh-cn_image_0000001306817646.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=0E24BAC6B8CF877D155E33E329FDBDB608589B0C697EFB7D700C480C4C0AC20C "点击放大")

### 商用证书

申请商用证书，需要上传APK进行审核。开发者需要按照[权限使用声明、免责声明与软件许可协议](https://developer.huawei.com/consumer/cn/doc/system-Guides/app-dev-0000001077043320#section151933314719)的要求，完成"权限使用声明"界面的适配，否则会导致应用无法通过华为证书审核。商用证书的审核一般需要1~2周。

商用证书的申请流程如下图，详细步骤参见[证书申请指导](#section54599303111)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/qfh6T4daS0Cafb8X2ALw0g/zh-cn_image_0000001359417521.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=5B785E6618D69035DDB7BFED9DD09A2B2DC3769CA6F0AE4916789C2A3E01534A)

1. 第一次申请得到的是临时商用证书的下载链接。
2. 下载临时商用证书打包到APK并对APK进行V1+V2签名。
3. 将上一步的APK提交申请正式商用证书。
4. 下载正式商用证书打包到APK并对APK进行V1+V2签名。

> 说明
>
> 当前建议开发者使用Android V1+V2对APK进行签名，将证书集成到APK中后，还需要再次对此APK进行签名。

## 证书申请指导

1. 参见文档[注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)，注册、实名认证企业帐号并登录成功后，进入 "管理中心"页面。选择"应用服务 > 开发服务 > 安全授权"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/OTunAByETrm4q312ncIm3w/zh-cn_image_0000001306497842.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=10891A50D06CC94454AAE8248C0B2773B6BB3D48A6F7CFCAB74F1BEFF30122D6 "点击放大")
   > 说明
   > 1. 使用企业帐号登录[开发者联盟](https://developer.huawei.com/)，因当前安全授权业务只对联盟上的企业帐号开放，登录个人帐号无法使用安全授权服务。
   > 2. 如果使用企业帐号登录后，在"管理中心"页面没有看到"安全授权"卡片，可以点击"开发服务"旁边图标添加此卡片到桌面。

2. 申请MDM权限。

   1. 如果帐号还未开通MDM权限，点击安全授权卡片会跳转到权限申请页面，具体申请指导如下。如果帐号已经开通了MDM权限，点击安全授权卡片会跳转到证书申请页面，无需再关注此步骤，可直接跳转到下一小节。
   2. 点击"申请MDM权限"申请权限。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/RxBnLIOXTYaj_34VOIqCUw/zh-cn_image_0000001359417517.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=DB4F316EAA43E34F94891578D50DFAEE0F2AD6D32F7610B9D37F3608A6565BD7 "点击放大")

   3. 根据界面提示填写必要信息，包括申请人邮件，手机号，承诺函，行为准则，以及企业营业执照，并选择权限有效期，最大申请有效期为一年，点击"提交审核"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/qSdxtJatQbG1KJjUgDisnw/zh-cn_image_0000001306497838.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C9DF09DFC1318C3E4F45F7F5B2AB43F42EE951FEC86F52B4C7E2F123F6F6C5D "点击放大")

      > 注意
      >
      > 三方公司需要签署《API授权证书申请承诺函》、《政企合作伙伴行为准则》，请按照模板仔细填写，文件要求加盖公司公章及法人手写签字，加盖骑缝章。将签署好的纸质原件扫描件、营业执照扫描件在如上页面提交。具体文件请参见[资料下载](#section3185197133111)。
   4. 在权限申请列表界面可以查询当前权限申请的进度，点击"提醒"可以催促审核人员审核，如果填写信息有误也可以主动撤回已提交的权限申请流程。MDM权限审核一般需要3~4个工作日。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/AQWnet7-QW2LH6HQmE2vcQ/zh-cn_image_0000001306817650.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=F0099844F2BDCAE410852F15EC747E3EBB64EA882387719B9FDC1AD001F742E5 "点击放大")

3. 权限申请通过后，点击申请MDM服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/cwZ_hK3gSCqKrHb6sg4Afw/zh-cn_image_0000001306977282.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=CEF4F6324FCF2BDABE9EA1579BD7181F12FA326EBC273F9E6C38D314EBBD24AE "点击放大")

4. 在创建MDM服务后，进行创建产品。在开放API授权申请列表V2.0表格中，填写您需要申请的权限。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/3YFpZjPARc2aV0q96CxnLA/zh-cn_image_0000001359457317.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=03D5F8C4127CC24EE8A000604D4F1573AA809781913B5FA51D3B379341EE637D "点击放大")
   > 说明
   > 1. 填写"开放API授权申请列表"时，申请的权限不能多于AndroidManifest.xml中声明使用的权限，以免无法通过华为证书审核。
   > 2. 填写"开发设备列表"项时，如果填写的是连续的IMEI号（即区间），请使用"-"分隔，且必须小值在前，大值在后，否则无法申请开发证书。如果当前设备有两个IMEI号，填写其中一个IMEI号即可。

5. 当申请审核通过后，点击刚刚申请的产品名称，如下图所示：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/-RVOHQltSLWxwOpbc6g6QQ/zh-cn_image_0000001359617201.png?HW-CC-KV=V1&HW-CC-Date=20260909T174505Z&HW-CC-Expire=31536000000&HW-CC-Sign=147B7FF8717683CA3026C9D62FB99FB6B10C36DD3AA97312BC1CBDBAB57D903E "点击放大")
