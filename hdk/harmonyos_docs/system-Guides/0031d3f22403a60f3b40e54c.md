# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSWirelessKit)快速体验一个应用的开发过程。

## 开发环境

* 安装[Android Studio](https://developer.android.com/studio) 3.X及以上

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上
* 您的应用应满足以下条件：

  * minSdkVersion 21及以上
  * targetSdkVersion 29（推荐）
  * compileSdkVersion 29（推荐）
  * Gradle 3.3及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：EMUI 11.0及以上的华为手机

## 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。

|序号|步骤|说明|
|:-|:----------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-agc-0000001050749961)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹、打开相关服务。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/system-Guides/integrating-sdk-0000001050749967)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/system-Guides/config-obfuscation-scripts-0000001052088752)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[Wi-Fi增强能力客户端开发](https://developer.huawei.com/consumer/cn/doc/system-Guides/client-dev-wifi-preparations-0000001054538297)|当Wi-Fi处于连接状态时，可调用接口使能或者去使能Wi-Fi高优先级发包功能。|
|5|[通信感知能力客户端开发](https://developer.huawei.com/consumer/cn/doc/system-Guides/client-dev-preparations-0000001050995151)|当应用程序处于前台且数据业务处于连接状态时，可实时反馈精准的QoE信息。|
|6|[双Wi-Fi能力客户端开发](https://developer.huawei.com/consumer/cn/doc/system-Guides/client-dev-dualwifi-preparations-0000001093141342)|当Wi-Fi处于连接状态时，可调用接口开启或者关闭双Wi-Fi功能。|
|7|[开发后自检](https://developer.huawei.com/consumer/cn/doc/system-Guides/pre-release-check-0000001051070742)|华为提供对应用自动检查的能力。|
|8|[上架申请](https://developer.huawei.com/consumer/cn/doc/system-Guides/app-release-0000001051075006)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|
