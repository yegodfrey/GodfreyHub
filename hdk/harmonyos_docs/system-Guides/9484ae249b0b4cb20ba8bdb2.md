# 接口调用

## 接入华为帐号获取凭证

企业用户在EMM厂商Portal完成登录后，需要绑定华为帐号获取用户授权，服务器应用通过此[步骤](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-get-access-token-0000001050048946)获取授权码code。

## 获取Openid

应用在获取到授权码code后，再次请求OAuth服务，通过授权码code换取Openid。请求示例：

```screen
POST  https://oauth-login.cloud.huawei.com/oauth2/v3/token  HTTP/1.1
Content-Type: application/x-www-form-urlencoded
grant_type=authorization_code&
code=<返回的授权码code>&
client_id=<APP ID>&
client_secret=<APP SECRET>&
redirect_uri=<应用的回调地址>&
need_open_uid=true
```

响应示例：

```screen
HTTP/1.1 200 OK
Content-Type: text/json ; charset=UTF-8
Cache-Control: no-store
{
"access_token": "<返回的鉴权凭证Access Token>",
"refresh_token": "<返回的Refresh Token>",
"expires_in": 3600,
"scope": "profile openid",
"token_type": "Bearer",
"open_id": "<返回的Openid>"
}
```

## 获取应用级AccessToken

开发者服务器访问HEM服务器时，服务器间采用应用级AccessToken认证，因此开发者服务器需要向华为鉴权服务器申请[应用级AccessToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides-V5/open-platform-oauth-0000001053629189-V5#ZH-CN_TOPIC_0000001053629189__section12493191334711)。

## 根据凭证请求华为API

调用HEM服务端接口时，需要将Openid和应用级AccessToken放在请求头中，以便服务方进行鉴权。

示例：调用/hds/v1/customer/device-batches，获取企业设备列表。

```screen
POST https://hemapi-drcn.cloud.huawei.com/hds/v1/customer/emm/device-batches/get
HTTP/1.1
Host: <XXX>
Content-Type: application/json
Accept: application/json
cache-control: no-cache
Authorization: Bearer <Access Token>
open_id:open_id
```

具体开放接口列表请参见[HEM接口文档](https://developer.huawei.com/consumer/cn/doc/development/system-References/term-0000001087880721)。
