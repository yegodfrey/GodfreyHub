# 业务介绍

近距离通信服务（Nearby Service）包括近距离数据通信（Nearby Data Communication）。近距离数据通信（Nearby Data Communication）是指使用蓝牙、Wi-Fi等技术，发现附近的设备并与它们通信，包括：近距离设备间数据传输（Nearby Connection）、近距离设备间消息订阅（Nearby Message）。

* 近距离设备间数据传输（Nearby Connection） 提供附近多台设备间组建一个本地网络进行数据传输的能力，直接收发数据，无需互联网中转。

* 近距离设备间消息订阅（Nearby Message） 提供向周边设备发送广播短消息的能力，周边已联网的设备上运行相应的应用即可以接收此消息。

#### 服务优势

* 靠近就可发现，触发场景化的交互和服务；靠近才可发现，提供用户在场的可信验证。
* 提供简单易用的API，封装了底层网络细节，无需处理各种组网难题。
* 基于华为自研协议，节点发现速率和网络传输带宽均大幅度优于业界既有方案。
