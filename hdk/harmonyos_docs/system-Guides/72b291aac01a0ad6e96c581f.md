# 文件上传/下载

#### 概述

Network Kit为您提供优质的文件上传/下载功能，支持多线程下载、多任务并发、下载断点续传、以及备份URL重试等技术，实现提升文件上传和下载速率，增加文件上传和下载成功率的目标。  

#### 文件上传

文件上传功能可以通过如下操作实现。详细开发过程和代码实现可以参见[codelab（文件上传/下载集成）](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/NetworkKit-filemanager)和[示例代码](https://developer.huawei.com/consumer/cn/doc/system-Examples/network-sample-code-0000001081852581)。

1. 当适配版本为Android6.0（API Level 23）及以上时，需要动态申请读写手机存储权限（每个应用只需成功申请一次）。

   <br />

   ```
   if (Build.VERSION.SDK_INT >= 23) {
       if (checkSelfPermission(Manifest.permission.WRITE_EXTERNAL_STORAGE) != PackageManager.PERMISSION_GRANTED ||
   checkSelfPermission(Manifest.permission.READ_EXTERNAL_STORAGE) != PackageManager.PERMISSION_GRANTED) {
       requestPermissions(new String[]{Manifest.permission.WRITE_EXTERNAL_STORAGE}, 1000);
       requestPermissions(new String[]{Manifest.permission.READ_EXTERNAL_STORAGE}, 1001);
       }
   }
   ```

   <br />

2. 初始化全局上传管理类[UploadManager](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-upload-uploadmanager-0000001091714063)。

   <br />

   ```
   UploadManager upManager = (UploadManager) new UploadManager
           .Builder("uploadManager")
           .build(context);
   ```

   <br />

3. 构造请求体对象。我们以上传文件file1和file2为例。

   <br />

   ```
   Map<String, String> httpHeader = new HashMap<>();
   httpHeader.put("header1", "value1");
   Map<String, String> httpParams = new HashMap<>();
   httpParams.put("param1", "value1");
   // 替换成您需要上传的目的地址。
   String normalUrl = "https://path/upload";
   // 替换成您需要上传的文件的地址。
   String filePath1 = context.getString(R.string.filepath1);
   // 替换成您需要上传的文件的地址。
   String filePath2 = context.getString(R.string.filepath2);

   // 构造POST请求对象。
   try{
       BodyRequest request = UploadManager.newPostRequestBuilder()
               .url(normalUrl)
               .fileParams("file1", new FileEntity(Uri.fromFile(new File(filePath1))))
               .fileParams("file2", new FileEntity(Uri.fromFile(new File(filePath2))))
               .params(httpParams)
               .headers(httpHeader)
               .build();
   }catch(Exception exception){
       Log.e(TAG,"exception:" + exception.getMessage());
   }
   ```

   <br />

4. 创建[FileUploadCallback](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-upload-fileuploadcallback-0000001077469252)请求回调类。

   <br />

   ```
   FileUploadCallback callback = new FileUploadCallback() {
       @Override
       public BodyRequest onStart(BodyRequest request) {
           // 文件上传开始时回调此方法。
           Log.i(TAG, "onStart:" + request);
           return request;
       }

       @Override
       public void onProgress(BodyRequest request, Progress progress) {
           // 文件上传进度变化时回调到此方法。
           Log.i(TAG, "onProgress:" + progress);
       }

       @Override
       public void onSuccess(Response<BodyRequest, String, Closeable> response) {
           // 文件上传成功时回调此方法。
           Log.i(TAG, "onSuccess:" + response.getContent());
       }

       @Override
       public void onException(BodyRequest request, NetworkException exception, Response<BodyRequest, String, Closeable> response) {
           // 文件上传过程中网络发生异常，或请求被取消时回调此方法。
           if (exception instanceof InterruptedException) {
               String errorMsg = "onException for canceled";
               Log.w(TAG, errorMsg);
           } else {
               String errorMsg = "onException for:" + request.getId() + " " + Log.getStackTraceString(exception);
               Log.e(TAG, errorMsg);
           }
       }
   };
   ```

   <br />

5. 发送请求上传指定文件，并获取上传是否启动成功。当[Result](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-result-0000001091587549)的[getCode](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-result-0000001091587549#section668132695614)方法获取的返回值与静态变量[Result.SUCCESS](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-result-0000001091587549#section5357733184820)一致则文件上传任务启动成功。

   <br />

   ```
   Result result = upManager.start(request, callback);
   // 上传任务启动是否成功,可以通过Result的getCode()方法获取的返回值是否与静态变量Result.SUCCESS一致来判断。
   if (result.getCode() != Result.SUCCESS) {
       Log.e(TAG, result.getMessage());
   }
   ```

   <br />

6. 文件上传状态回调。文件上传状态改变时，[步骤4](#ZH-CN_TOPIC_0000002059221357__li1989142525712)创建的[FileUploadCallback](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-upload-fileuploadcallback-0000001077469252)对象的不同回调方法将被调用。

   <br />

   * 文件上传开始时，[onStart](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section1197745234916)方法会被调用。
   * 文件上传进度改变时，[onProgress](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section2067494665920)方法会被调用，并可通过解析回调的[Progress](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-progress-0000001077469134)对象，获取上传进度。
   * 文件上传任务发生异常时，[onException](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section668132695614)方法会被调用。

   <br />

7. 验证上传结果。

   <br />

   文件上传成功后会回调到[步骤4](#ZH-CN_TOPIC_0000002059221357__li1989142525712)创建的[FileUploadCallback](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-upload-fileuploadcallback-0000001077469252)请求回调对象的[onSuccess](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section155564414510)方法。

   <br />

#### 文件下载

文件下载功能可以通过如下操作实现。详细开发过程和代码实现请参见[codelab（文件上传/下载集成）](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/NetworkKit-filemanager)和[示例代码](https://developer.huawei.com/consumer/cn/doc/system-Examples/network-sample-code-0000001081852581)。

1. 当适配版本为Android6.0（API Level 23）及以上时，需要动态申请读写手机存储权限（每个应用只需成功申请一次）。

   <br />

   ```
   if (Build.VERSION.SDK_INT >= 23) {
       if (checkSelfPermission(Manifest.permission.WRITE_EXTERNAL_STORAGE) != PackageManager.PERMISSION_GRANTED ||
   checkSelfPermission(Manifest.permission.READ_EXTERNAL_STORAGE) != PackageManager.PERMISSION_GRANTED) {
       requestPermissions(new String[]{Manifest.permission.WRITE_EXTERNAL_STORAGE}, 1000);
       requestPermissions(new String[]{Manifest.permission.READ_EXTERNAL_STORAGE}, 1001);
       }
   }
   ```

   <br />

2. 初始化全局下载管理类[DownloadManager](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-download-downloadmanager-0000001077469352)。

   <br />

   ```
   DownloadManager downloadManager = new DownloadManager.Builder("downloadManager")
                .build(context);
   ```

   <br />

3. 构造请求体对象。

   <br />

   ```
   // 替换成您需要下载的资源地址。
   String normalUrl = "https://gdown.baidu.com/data/wisegame/10a3a64384979a46/ee3710a3a64384979a46542316df73d4.apk";
   // 替换成您想要保存的目的地址。
   String downloadFilePath = context.getExternalCacheDir().getPath() + File.separator + "test.apk";
   // 构造GET请求体对象。
   GetRequest getRequest = DownloadManager.newGetRequestBuilder()
           .filePath(downloadFilePath)
           .url(normalUrl)
           .build();
   ```

   <br />

4. 创建[FileRequestCallback](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-download-filerequestcallback-0000001077628860)请求回调对象。

   <br />

   ```
   FileRequestCallback callback = new FileRequestCallback() {
       @Override
       public GetRequest onStart(GetRequest request) {
           // 文件下载开始时回调此方法。
           Log.i(TAG, "activity new onStart:" + request);
           return request;
       }
    
       @Override
       public void onProgress(GetRequest request, Progress progress) {
           // 文件下载进度变化时回调此方法。
           Log.i(TAG, "onProgress:" + progress);
       }
    
       @Override
       public void onSuccess(Response<GetRequest, File, Closeable> response) {
           // 文件下载成功时回调到此方法。
           String filePath = "";
           if (response.getContent() != null) {
               filePath = response.getContent().getAbsolutePath();
           }
           Log.i(TAG, "onSuccess:" + filePath);
       }
    
       @Override
       public void onException(GetRequest request, NetworkException exception, Response<GetRequest, File, Closeable> response) {
           // 文件下载过程中网络发生异常，或请求被暂停、取消时回调此方法。
           if (exception instanceof InterruptedException) {
               String errorMsg = "onException for paused or canceled";
               Log.w(TAG, errorMsg);
           } else {
               String errorMsg = "onException for:" + request.getId() + " " + Log.getStackTraceString(exception);
               Log.e(TAG, errorMsg);
           }
       }
   };
   ```

   <br />

5. 使用[DownloadManager](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-download-downloadmanager-0000001077469352)启动下载任务并检验下载任务是否启动成功。当[Result](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-result-0000001091587549)的[getCode](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-result-0000001091587549#section668132695614)方法获取的返回值与静态变量[Result.SUCCESS](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-result-0000001091587549#section5357733184820)一致则文件下载任务启动成功。

   <br />

   ```
   Result result = downloadManager.start(getRequest, callback);
   if (result.getCode() != Result.SUCCESS) {
       // 当通过result获取到的值为Result.SUCCESS时，则下载任务启动成功，否则启动失败。
       Log.e(TAG, “start download task failed:” + result.getMessage());
   }
   ```

   <br />

6. 文件下载状态回调。文件下载状态改变时，[步骤4](#ZH-CN_TOPIC_0000002059221357__li651564953610)创建的[FileRequestCallback](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-download-filerequestcallback-0000001077628860)请求回调对象的不同方法将被调用。

   <br />

   * 文件开始下载时，[onStart](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section1197745234916)方法会被调用。
   * 文件下载进度改变时，[onProgress](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section2067494665920)方法会被调用，并可通过解析回调的[Progress](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-progress-0000001077469134)对象，获取下载进度。
   * 文件下载任务发生异常时，[onException](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section668132695614)方法会被调用。

   <br />

7. 验证下载结果。

   <br />

   文件下载成功后会回调到[步骤4](#ZH-CN_TOPIC_0000002059221357__li651564953610)创建的[FileRequestCallback](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-download-filerequestcallback-0000001077628860)请求回调对象的[onSuccess](https://developer.huawei.com/consumer/cn/doc/system-References/network-file-api-callback-0000001077821946#section155564414510)方法，并可根据您设置的下载路径在手机内存中查看到您下载的文件。

   <br />
