# 开通服务

使用近距离通信服务的能力需要您先打开近距离通信服务开关，再配置数据处理位置策略。下面提供了两种方式开通服务：

当您首次在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)首页"我的项目"创建新项目时，页面会弹出[AppGallery Connect协议包](https://developer.huawei.com/consumer/cn/doc/20208)，包含必须签署的基础协议和可选的服务协议，如果您已勾选签署同意《[华为Nearby服务使用协议](https://developer.huawei.com/consumer/cn/doc/64141665)》，在此处点击"启用"时不再弹出签署同意《[华为Nearby服务使用协议](https://developer.huawei.com/consumer/cn/doc/64141665)》的提示框。详情请参见[AppGallery Connect 协议签署指南](https://developer.huawei.com/consumer/cn/doc/distribution/app/signing-guide)。  

#### 在开发者联盟打开服务开关

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)后，点击并进入右上角的"[管理中心](https://developer.huawei.com/consumer/cn/console)"。
2. 点击左侧菜单栏"我的API"，选择您要开通服务的项目，再点击"申请新的HMS API服务"，进入HMS API库的详情页面。
3. 在HMS API库的详情页面，选择"System \> 近距离通信服务"，进入近距离通信服务的页面。点击"启用"开关，启用近距离通信服务。
4. 如果页面弹出《[华为Nearby服务使用协议](https://developer.huawei.com/consumer/cn/doc/64141665)》，您需要签署同意后才能成功启用近距离通信服务。
5. 启用成功之后，在"HMS API服务 \> 我的API"中可以看到当前项目下的已启用的API服务列表。  

#### 在AppGallery Connect打开服务开关

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，点击"我的项目"，选择您要开通近距离通信服务的项目。
2. 在项目设置菜单内，打开"API管理"页面，在"构建"区域内找到并打开近距离通信服务开关。
3. 如果页面弹出《[华为Nearby服务使用协议](https://developer.huawei.com/consumer/cn/doc/64141665)》，您需要签署同意后才能成功启用近距离通信服务。  

#### 配置数据处理位置策略

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要配置数据处理位置策略的应用。
3. 在"项目设置"页面内，选择"数据处理位置"，找到"数据处理位置策略"区域，为近距离通信服务选择数据处理位置策略。
