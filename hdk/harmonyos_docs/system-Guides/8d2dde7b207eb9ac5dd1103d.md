# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab（URL请求集成）](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_tutorials_Network-URL)、[codelab（文件上传/下载集成）](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_tutorials_NetworkKit-filemanager)快速体验应用的集成过程。

## 开发环境

* 安装Android Studio 3.3及以上

* JDK 1.8及以上
* 您的应用应满足以下条件：

  * minSdkVersion 19及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 4.6及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：EMUI 3.0及以上的华为手机或Android 4.4及以上的非华为手机

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-config-agc-0000001050192302)|（若您的应用不需要在AppGallery Connect上架，则可跳过本步骤）在开发应用前，需要在AppGallery Connect中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-config-agc-0000001050192302#ZH-CN_TOPIC_0000002023143862__s1955a1857a3547dc9a3415a85236ea9b)、[创建应用](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-config-agc-0000001050192302#ZH-CN_TOPIC_0000002023143862__s9c8961cc6d0849feabb75b61d5b9235e)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-config-agc-0000001050192302#ZH-CN_TOPIC_0000002023143862__s7c93393aa06148799abf79b048e88025)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-config-agc-0000001050192302#ZH-CN_TOPIC_0000002023143862__s9c2a03abec054a2c9abba81276f082d3)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-integrating-sdk-0000001050189899)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-config-obfuscation-scripts-0000001194273241)|您编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-add-permissions-0000001050440049)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[URL请求](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-exp-url-0000001077825976)|您可根据业务需求，通过调用Network Kit提供的API完成与云端/服务端通信功能的开发。|
|5|[文件上传/下载](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-exp-file-0000001093424975)|您可根据业务需求，通过调用Network Kit提供的上传/下载的API完成文件上传/下载功能的开发。|
|6|[开发后自检](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-pre-release-check-0000001050192223)|（若您的应用不需要在AppGallery Connect上架，则可跳过本步骤）华为提供对应用自动检查的能力。|
|7|[上架申请](https://developer.huawei.com/consumer/cn/doc/system-Guides/network-app-release-0000001050183434)|（若您的应用不需要在AppGallery Connect上架，则可跳过本步骤）开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
