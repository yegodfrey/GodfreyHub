# 开发步骤

## 广播和扫描

Nearby支持三种不同策略的广播和扫描方式，请根据您的应用场景选择策略。

* [POLICY_P2P](https://developer.huawei.com/consumer/cn/doc/system-References/discovery-policy-0000001050132587#section1628820301409)策略是一种支持1-1连接拓扑的点到点连接策略。

  该策略在拓扑约束方面比POLICY_STAR更严格，但会带来更高的连接带宽。它非常适合需要高带宽的场景（例如：将大型视频共享到另一台设备）。
* [POLICY_STAR](https://developer.huawei.com/consumer/cn/doc/system-References/discovery-policy-0000001050132587#section098230122218)策略是一种支持星型（1-N）连接拓扑的点到点连接策略。

  使用该模式的广播端可以连接多个扫描端，成为中心节点。使用该模式的扫描端只能连接一个广播端，成为叶子节点。叶子节点之间无法直接通信。该策略在拓扑约束方面比POLICY_MESH更严格，但会带来较高的连接带宽。适合在一个确定的群组内发送数据的场景（例如：向一群朋友分享视频或者照片）。
* [POLICY_MESH](https://developer.huawei.com/consumer/cn/doc/system-References/discovery-policy-0000001050132587#section5781511220)策略支持M-N或者网状连接拓扑的点到点连接策略。

  在无线范围内的设备都可以发现和连接对方，组成全连接的网络。任意一台设备可以随时加入或退出该网络。该策略在拓扑约束方面比POLICY_STAR灵活，但会降低连接的带宽。它适合需要较小带宽并且需要建立网状连接拓扑的场景（例如：多人游戏）。Nearby Connection将在后续版本实现该特性。

选择策略为POLICY_STAR，示例代码如下：

```screen
Policy policy = Policy.POLICY_STAR;
```

### 启动广播

广播端调用[startBroadcasting](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section17116532184219)(String, String, [ConnectCallback](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589), [BroadcastOption](https://developer.huawei.com/consumer/cn/doc/system-References/broadcastoption-0000001050132579))启动广播，示例代码如下：

```screen
private voidsendFilesInner() {
    // 获取设备信息
    String mEndpointName = android.os.Build.DEVICE;
    BroadcastOption.Builder advBuilder = new BroadcastOption.Builder();
    // 选择广播策略
    advBuilder.setPolicy(Policy.POLICY_P2P);
    // 启动广播
    Nearby.getDiscoveryEngine(getApplicationContext()).startBroadcasting(mEndpointName, mFileServiceId, mConnCbSender, advBuilder.build());
    Log.d(TAG, "Start Broadcasting.");
}
```

> 说明
>
> * 参数mConnCbSender是一个连接侦听回调类实例，用于通知您连接状态信息。
> * 参数mFileServiceId用于唯一标识您的应用，您可以使用应用包名作为mFileServiceId（例如：com.huawei.example.myapp）。

### 启动扫描

发现端调用[startScan](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section118310535196)(String, [ScanEndpointCallback](https://developer.huawei.com/consumer/cn/doc/system-References/scanendpointcallback-0000001050132583), [ScanOption](https://developer.huawei.com/consumer/cn/doc/system-References/scanoption-0000001050130634))启动扫描以发现附近的设备，示例代码如下：

```screen
public voidonScanResult(Intent data) { 
    ScanOption scanOption = new ScanOption.Builder()
        // 选择扫描策略
        .setPolicy(Policy.POLICY_P2P) 
        .build();
    // 启动扫描
    Nearby.getDiscoveryEngine(getApplicationContext()).startScan(mFileServiceId, mDiscCb, scanBuilder.build());     
    Log.d(TAG, "Start Scan.");
}
```

> 说明
>
> * 参数mDiscCb是发现侦听回调，发现对端设备时触发回调。
> * 在您的应用启动扫描后，为了降低设备待机功耗，当设备进入夜间模式或者灭屏时，Nearby Connection将关闭蓝牙BLE扫描；当设备退出夜间模式或者亮屏时，Nearby Connection将恢复蓝牙BLE扫描。

### 停止广播

当需要停止广播时，调用[stopBroadcasting](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section18158165592014)()。停止广播后，广播端仍可以接收来自发现端的连接请求。

```screen
Nearby.getDiscoveryEngine(getApplicationContext()).stopBroadcasting();
```

### 停止扫描

当需要停止扫描时，调用[stopScan](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section17398857102114)()。停止扫描后，发现端仍可以向已发现的设备请求连接。常见的做法是：一旦发现需要连接的设备，就调用[stopScan](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section17398857102114)()停止扫描，避免扫描动作给后续数据传输带来不必要的性能影响。

```screen
Nearby.getDiscoveryEngine(getApplicationContext()).stopScan();
```

## 管理连接

### 请求连接

当附近的设备被发现后，可以调用[requestConnect](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section19879123918174)(String, String, [ConnectCallback](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589))发起连接。示例代码如下：

```screen
private ScanEndpointCallback mDiscCb = new ScanEndpointCallback() {
    // 通知发现端扫描结果，结果为发现设备
    @Override
    public void onFound(String endpointId, ScanEndpointInfo discoveryEndpointInfo) {
        if (discoveryEndpointInfo.getName().equals(mScanInfo)) {
            Log.d(TAG, "Found endpoint:" + discoveryEndpointInfo.getName() + ". Connecting.");
            Nearby.getDiscoveryEngine(getApplicationContext()).requestConnect(mEndpointName, endpointId, mConnCbRcver);
        }
    }
    @Override
    public void onLost(String endpointId) {
        Log.d(TAG, "Lost endpoint.");
    }
};
```

> 说明
>
> * 参数endpointId是扫描到的设备标识ID。
> * mScanInfo为建立连接的目标设备标识ID。
> * mEndpointName为当前设备自定义的名称，可用于对端扫描到展示该名称。
> * 参数mConnCbRcver是一个连接侦听回调类实例，用于通知您连接状态信息。

### 确认连接

发现端发起连接后，通过回调[ConnectCallback](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589)的[onEstablish](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589#section1487514421181)(String, [ConnectInfo](https://developer.huawei.com/consumer/cn/doc/system-References/connectinfo-0000001050130638))方法将连接建立事件通知给双方。双方必须通过调用[acceptConnect](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section9344760149)(String, [DataCallback](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654))接受连接或者通过调用[rejectConnect](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section15885104571619)(String)拒绝连接。仅当双方都接受连接时，连接才会建立成功。如果一方或双方都选择拒绝，则连接失败。无论哪种方式，连接结果都会通过[onResult](https://developer.huawei.com/consumer/cn/doc/system-References/connectcallback-0000001050132589#section3826114515249)(String, [ConnectResult](https://developer.huawei.com/consumer/cn/doc/system-References/connectresult-0000001050130640))方法通知。示例代码如下：

```screen
private ConnectCallback mConnCbSender =new ConnectCallback() {
    // 接受连接请求            
    @Override             
    public void onEstablish(String endpointId, ConnectInfo connectionInfo) {
        Log.d(TAG, "Accept connection.");             
        Nearby.getDiscoveryEngine(getApplicationContext()).acceptConnect(endpointId, mDataCbSender);           
     }          
     // 获取连接结果            
     @Override            
     public void onResult(String endpointId, ConnectResult result) {               
         if (result.getStatus().getStatusCode() == StatusCode.STATUS_SUCCESS) {                   
             Log.d(TAG, "Connection Established. Stop discovery. Start to send file.");
             Log.d(TAG, "Actual channel policy is " + result.getChannelPolicy().toString());
         }            
     }           
     // 断开连接         
     @Override            
     public void onDisconnected(String endpointId) {               
         Log.d(TAG, "Disconnected.");            
     }
};
```

> 说明
>
> * 参数mDataCbSender是与远端进行数据传输的回调，用于数据接收或者收发进度通知。
> * 以上示例显示了一种双方自动接受连接的确认连接方式。根据您的需要，您可以使用其他确认连接的方式。

### 验证连接

您的应用程序可以提供一种让用户确认连接到指定设备的方法，例如：token验证（token可以是一个短随机字符串或者数字）。通常这涉及在两个设备上显示token并要求用户手动输入或者确认，类似于蓝牙配对对话框。下面演示一种通过弹窗确认配对码的方式验证连接，示例代码如下：

```java
@Override
public void onEstablish(String endpointId, ConnectInfo connectInfo) {
    DiscoveryEngine engine = Nearby.getDiscoveryEngine(context);
    AlertDialog alert = new AlertDialog.Builder(context)
            .setTitle(connectInfo.getEndpointName() + " request connection")
            .setMessage("Please confirm the match code is: " + connectInfo.getAuthCode())
            // 接受连接
            .setPositiveButton("Accept", (DialogInterface dialog, int which) ->
                    engine.acceptConnect(endpointId, dataCallback))
            // 拒绝连接
            .setNegativeButton("Reject", (DialogInterface dialog, int which) ->
                    engine.rejectConnect(endpointId))
            .create();
    alert.show();
}
```

> 说明
>
> * context为应用上下文。
> * dataCallback为建立连接DataCallback回调对象。

### 断开连接

如果需要断开与endpoint的连接，调用[DiscoveryEngine](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591)类实例方法[disconnect](https://developer.huawei.com/consumer/cn/doc/system-References/discoveryengine-0000001050132591#section31761824181518)(String)。一旦调用此接口，将不能与该endpoint收发数据。

## 传输数据

设备间建立连接后，需要进行以下操作：

1. 通过调用[sendData](https://developer.huawei.com/consumer/cn/doc/system-References/transferengine-0000001050130658#section10201153764712)(String, [Data](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599))方法发送数据，[Data](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599)对象的类型包括字节序列（BYTES）、文件（FILE）和流（STREAM）。
2. 通过[DataCallback](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654)回调类的[onReceived](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654#section4844134385219)(String, [Data](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599))方法接收数据。
3. 通过[DataCallback](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654)回调类的[onTransferUpdate](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654#section18715435195410)(String, [TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/system-References/transferstateupdate-0000001050132605))方法提供数据发送或接收的进度更新。

如果需要在接收或发送过程中取消传输，调用[TransferEngine](https://developer.huawei.com/consumer/cn/doc/system-References/transferengine-0000001050130658)类实例方法[cancelDataTransfer](https://developer.huawei.com/consumer/cn/doc/system-References/transferengine-0000001050130658#section1794515469468)(long)。

### 传输字节序列

发送BYTES类型数据的示例代码如下：

```screen
Nearby.getTransferEngine(getApplicationContext()).sendData(mRemoteEndpointId, Data.fromBytes("Receive Success".getBytes(StandardCharsets.UTF_8)));
```

> 说明
>
> * 参数mRemoteEndpointId是接收端设备标识ID。
> * 单次发送的BYTES类型数据大小不能超过32KB。

接收BYTES类型数据的示例代码如下：

```screen
private DataCallback mDataCbSender = new DataCallback() {
    @Override
    public void onReceived(String endpointId, Data data) {
        if (data.getType() == Data.Type.BYTES) {
            String msg = new String(data.asBytes(), StandardCharsets.UTF_8);
            if (msg.equals("Receive Success")) {
                Log.d(TAG, "Received ACK. Send next.");          
            }
         }
    }

    @Override
    public void onTransferUpdate(String string, TransferStateUpdate update) {
    }
};
```

> 说明
>
> BYTES是以单个数据块发送的，因此接收端可以在[onReceived](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654#section4844134385219)(String, [Data](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599))函数中调用[asBytes](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599#section296519501836)()获取并处理本次传输的字节数据。

### 传输文件

发送FILE类型数据的示例代码如下：

```screen
private List<File> mFiles = new ArrayList<>();
private void sendOneFile() {
     // 文件传输完成时，断开连接   
     if (mFiles.isEmpty()) {     
         Log.d(TAG, "All Files Done. Disconnect");        
         Nearby.getDiscoveryEngine(getApplicationContext()).disconnectAll();
         return;
     }
     String fileName;
     Data filePayload;
     try {
         fileName = mFiles.get(0).getName();
         filePayload = Data.fromFile(mFiles.get(0));
         mFiles.remove(0);
      } catch (FileNotFoundException e) {
         Log.e(TAG, "File not found", e);
         return;
     }
     // 传输文件
     Data filenameMsg = Data.fromBytes(fileName.getBytes(StandardCharsets.UTF_8));
     Log.d(TAG, "Send filename: " + fileName);  
     Nearby.getTransferEngine(getApplicationContext()).sendData(mRemoteEndpointId, filenameMsg);
     Log.d(TAG, "Send Payload.");
     Nearby.getTransferEngine(getApplicationContext()).sendData(mRemoteEndpointId, filePayload);
}
```

> 说明
>
> 参数mRemoteEndpointId是接收端设备标识ID。

接收设备收到文件后，文件将以Data ID为文件名保存在"/Download/Nearby"目录中。传输完成后，即在[onTransferUpdate](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654#section18715435195410)(String, [TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/system-References/transferstateupdate-0000001050132605))中判断状态更新为TRANSFER_STATE_SUCCESS时，您可以获取FILE对象。为了适配Android 11分区存储（媒体和文件）权限，Nearby 5.1.0.300版本[Data.File](https://developer.huawei.com/consumer/cn/doc/system-References/data-file-0000001050132601)类新增了[asUri](https://developer.huawei.com/consumer/cn/doc/system-References/data-file-0000001050132601#section1026318817617)()接口。当您的App目标版本为Android 11 ~ 12时，您需要通过URI来访问接收文件。

示例代码如下：

```screen
// 您可在下载文件夹中获取接收的文件以及文件URI
Uri uri = data.asFile().asUri();
```

> 说明
>
> 文件保存的"/Download/Nearby"目录是个公共目录，任何应用都可以访问，为了安全起见，请及时将文件移到您应用的目录中。

### 传输流

发送端的示例代码如下：

```screen
URL url = new URL("https://developers.huawei.com");
Data streamData = Data.fromStream(url.openStream());
Nearby.getTransferEngine(getApplicationContext()).sendData(toEndpointId, streamData);
```

当[onReceived](https://developer.huawei.com/consumer/cn/doc/system-References/datacallback-0000001050130654#section4844134385219)(String, [Data](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599))回调时，可以调用[asStream](https://developer.huawei.com/consumer/cn/doc/system-References/data-0000001050132599#section146406371551)()或者[asParcelFileDescriptor](https://developer.huawei.com/consumer/cn/doc/system-References/data-stream-0000001050130652#section744462713012)()获取流对象。

接收端示例代码如下：

```screen
public class ReceiveStreamCallback extends DataCallback {
    private static final String TAG = "ReceiveStreamCallback";
    private static final int READ_BUFFER_SIZE = 1024 * 1024;
    private final SimpleArrayMap<Long, Data> incomingData = new SimpleArrayMap<>();

    // 接收数据回调
    @Override
    public void onReceived(String endpointId, Data data) {
        incomingData.put(data.getId(), data);
        if (data.getType() == Data.Type.STREAM) {
            InputStream inputStream = data.asStream().asInputStream();
            onStreamReceived(inputStream);
        }
    }

    // 流传输状态回调
    @Override
    public void onTransferUpdate(String endpointId, TransferStateUpdate update) {
        if (update.getStatus() == TransferStateUpdate.Status.TRANSFER_STATE_SUCCESS) {
            // 传输成功
        }
    }

    // 另起线程接收流
    private void onStreamReceived(InputStream inputStream) {
        Thread streamTread = new Thread() {
            @Override
            public void run() {
                byte[] readBuffer = new byte[READ_BUFFER_SIZE];
                int readLength = 0;
                while (true) {
                    try {
                        readLength = inputStream.read(readBuffer);
                    } catch (IOException e) {
                        Log.e(TAG, "onStreamReceived failed：" + e.getMessage());
                        break;
                    }

                    if (readLength == -1) {
                        Log.i(TAG, "End of the stream has been reached");
                        break;
                    }

                    // 进一步处理
                    ...
                }
            }
        };

        try {
            streamTread.start();
        } catch (IllegalThreadStateException e) {
            Log.e(TAG, e.getMessage());
        }
    }
}
```
