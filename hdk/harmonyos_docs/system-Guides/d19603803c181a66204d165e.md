# 添加权限

1. 打开项目中的"AndroidManifest.xml"文件。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250422170603.87563012426860444289721041330604:50001231000000:2800:0A7E350C3167EA9AB48C524C7FCF54FFC57F43E8A1B0DC22F276FBD1E8BB5EC2.png)

2. 添加应用所需权限。

   ```screen
   <!--允许程序访问网络连接-->
   <uses-permission android:name="android.permission.INTERNET" />
   <!--允许程序获取网络信息状态-->
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
   <!--允许程序获取wifi状态-->
   <uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
   ```

   如使用众测服务开发，还需要额外添加以下权限。

   ```screen
   <!--允许程序通过GPS芯片接收卫星的定位信息-->
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
   ```

   > 说明
   >
   > ACCESS_FINE_LOCATION是危险的系统权限，因此您需要动态地申请这个权限。如果权限不足，5G Modem Kit将会由于缺少必需权限无法提供服务。
