# License申请

#### License介绍

* 测试权限的License：为开发者提供的一种调试适配阶段的License，用于在指定的设备中测试MDM能力。测试权限的License最多只能绑定在20台设备上使用，有效期默认3个月。
* 商用权限的License：用于正式商用项目中使用MDM能力，有效期可在申请时选择。  

#### 适用范围

|设备类型|系统版本|区域|
|:-------|:---------------|:----|
|华为的手机、平板|HarmonyOS 2.0及以上|中国、欧洲|

#### License申请流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240430085407.79740079279324387878791077344886:50001231000000:2800:ACF9E4926CAB3679C16AA99700E1C65A104743B4B6F5221D470B6D76AB4299D8.png?needInitFileName=true?needInitFileName=true "点击放大")

* EMM厂商资质认证：在完成华为开发者实名认证之后，您需要提交EMM厂商的资质认证信息，完成EMM厂商的资质认证以成为我们的EMM合作伙伴。
* 集成开放能力：您需要在您的DPC App中集成HEM的开放能力。具体集成方法请参见[集成HEM SDK](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/hem-integrating-sdk-0000001061424215)。
* 申请MDM测试权限：针对需要测试华为MDM能力的场景，您可申请MDM测试权限，用于在指定的设备中测试MDM能力。
* DPC App管理：在申请MDM商用权限之前，您需要先上传您的DPC App至HEM系统中。
* 申请MDM商用权限：针对需要集成华为MDM能力的场景，您可申请MDM商用权限，用于正式商用项目中使用MDM能力。 具体申请指导请参见[EMM厂商操作指导](https://developer.huawei.com/business/cn/doc/distribution/HEM/developer_operation-procedure-0000001144194520)。
