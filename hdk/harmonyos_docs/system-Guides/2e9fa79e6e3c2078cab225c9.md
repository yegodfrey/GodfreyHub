# 业务介绍

#### 业务简介

全网络聚合技术（LinkTurbo Engine）是在端侧将Wi-Fi和蜂窝网络同时使用的技术。通过LinkTurbo Engine，联合生态伙伴，为用户带来聚合高网速、稳定低时延的移动上网体验。

当前华为提供的LocalSocket方案，对于三方应用来说，可以允许APK无需集成任何SDK，以彻底解耦的方式与系统的开放能力交互，且其实现与编程语言无关，适用面最广。

LocalSocket方案主要包括两种典型的场景，分别是："双网主备"和"多网并发"。

* 双网主备 在观看视频或VoIP通话时，可以在Wi-Fi建立好已有Socket通道后，绑定到蜂窝网络，建立辅助通道与业务服务器进行网络质量探测。当应用检测到视频卡顿或VoIP体验不佳时，及时切换到蜂窝网络的Socket上发送数据，保持业务连续性。

* 多网并发 在上传视频或下载大文件时，可以在Wi-Fi建立好已有Socket通道后，绑定到蜂窝网络，建立辅助通道从业务服务器同时拉取数据，然后在端侧将数据组装起来，以获得的多个网络融合带宽。提高并发下载速度或上传速度，从而提升用户体验。

总的来说，华为LinkTurbo Engine技术是通过LocalSocket消息机制获得两个网卡状态，根据网卡网络质量自定义IP报文的收发策略，让优质网络环境得到充分利用，避免网络拥塞带来不良业务体验，保障移动化业务的延续性。  

#### 服务特点

* 集成方便：LinkTurbo Engine提供的LocalSocket方式允许APK无需集成任何SDK，以彻底解耦的方式与系统的开放能力交互，集成方便。
* 策略灵活：LinkTurbo Engine能够根据不同的使用场景，调整不同的双工策略，获得不同的网络加速能力，处理灵活。  

#### 场景介绍

* 对战游戏类：对数据交互实时性和稳定性要求高。
* 点播视频类：数据吞吐量大，要求更大带宽和低时延解决播放卡顿的问题。
* 购物抢单：要求网络低时延、提升网络稳定性。
* 社交IM类：移动化使用，确保在Wi-Fi环境和纯LTE环境之间无缝切换，切网不断网。
