# 开发步骤

#### 绑定服务

获取[DualWifiClient](https://developer.huawei.com/consumer/cn/doc/system-References/wifienhanceclient-0000001054335451)对象。利用[getDualWifiServiceIntent](https://developer.huawei.com/consumer/cn/doc/system-References/wifienhanceclient-0000001054335451#section1377518421554)接口获取Intent，并绑定IDuaWifiService服务。若intent获取失败，App无法使用[IDualWifiService](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627)服务。错误码及解决方法请参见[错误码](https://developer.huawei.com/consumer/cn/doc/system-Guides/error-code-0000001050791658)和[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)。

如下示例代码里DualWifiActivity绑定IDualWifiService服务。

```
// 根据需要添加Android相关类
import com.huawei.hmf.tasks.OnFailureListener;
import com.huawei.hmf.tasks.OnSuccessListener;
import com.huawei.hms.common.ApiException;
import com.huawei.hms.wireless.IDualWifiService;
import com.huawei.hms.wireless.WirelessClient;
import com.huawei.hms.wireless.WirelessResult;
import com.huawei.hms.wireless.wifi.DualWifiClient;

public class DualWifiActivity extends AppCompatActivity {
    private static final String TAG = "DualWifiActivity";
    private IDualWifiService mDualWifiService = null;
    private ServiceConnection mServiceConnection = new ServiceConnection() {
        @Override
        public void onServiceConnected(ComponentName name, IBinder service) {
            // 服务连接，绑定IWifiEnhanceService服务
            mDualWifiService = IDualWifiService.Stub.asInterface(service); 
        }

        @Override
        public void onServiceDisconnected(ComponentName name) {
            // 服务断开，DualWifiService置为null
            mDualWifiService = null;
        }
    };

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        DualWifiClient dualWifiClient = WirelessClient.getDualWifiClient(DualWifiActivity.this);
        dualWifiClient.getDualWifiServiceIntent()
                .addOnSuccessListener(new OnSuccessListener<WirelessResult>() {
                    @Override
                    public void onSuccess(WirelessResult wirelessResult) {
                        Intent intent = wirelessResult.getIntent();
                        // intent获取失败， App无法使用IDualWifiService服务
                        if (intent == null) {
                            return;
                        }
                        DualWifiActivity.this.bindService(intent, mServiceConnection, Context.BIND_AUTO_CREATE);
                   }
               })
               .addOnFailureListener(new OnFailureListener() {
                   @Override
                   public void onFailure(Exception exception) {
                       if (exception instanceof ApiException) {
                           ApiException ex = (ApiException) exception;
                           int errCode = ex.getStatusCode(); 
                       }
                   }
               });
    }
}
```

#### 开启双Wi-Fi

1. 定义双Wi-Fi服务[INetworkCallback](https://developer.huawei.com/consumer/cn/doc/system-References/inetworkcallback-0000001143941719)回调接口。

   ```
   // 根据需要添加Android相关类
   import com.huawei.hmf.tasks.OnFailureListener;
   import com.huawei.hmf.tasks.OnSuccessListener;
   import com.huawei.hms.common.ApiException;
   import com.huawei.hms.wireless.INetworkCallback;
   import com.huawei.hms.wireless.WirelessClient;
   import com.huawei.hms.wireless.WirelessResult;

   public class DualWifiActivity extends AppCompatActivity {
       private INetworkCallback callBack = new INetworkCallback.Stub() {

           @Override
           public void onAvailable(Network network) {
               if (network == null) {
                   return;
               }
               Log.d(TAG, "onAvailable: DualWifiActivity receive");
               // 这里可以绑定网络
           }

           @Override
           public void onUnavailable() {
               Log.d(TAG, "onUnavailable: DualWifiActivity receive");
           }

           @Override
           public void onLost(Network network) {
               if (network == null) {
                   return;
               }
           }
       };
   }
   ```

2. 当Wi-Fi处于连接状态时，通过调用[enableDualWifi](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627#section8146125774712)来开启双Wi-Fi服务。

   ```
   // 根据需要添加Android相关类
   import com.huawei.hmf.tasks.OnFailureListener;
   import com.huawei.hmf.tasks.OnSuccessListener;
   import com.huawei.hms.common.ApiException;
   import com.huawei.hms.wireless.INetworkCallback;
   import com.huawei.hms.wireless.WirelessClient;
   import com.huawei.hms.wireless.WirelessResult;

   public class DualWifiActivity extends AppCompatActivity {
       @Override
       protected void onCreate(Bundle savedInstanceState) {
           super.onCreate(savedInstanceState);
           if (mDualWifiService != null) {
               try {
                   mDualWifiService.enableDualWifi("com.huawei.hms.wirlesstestdemo", callBack);
               } catch (RemoteException e) {
                   // 这里可以添加打印
               }
            }
       }
   }
   ```

#### 注册接收双Wi-Fi广播

1. 注册接收双Wi-Fi广播。 当开启Wi-Fi2后，可通过BroadcastReceiver动态注册广播事件，注册后便可以接收到Wireless Kit发出的Wi-Fi信号和状态变化的广播消息。

   ```
   // DualWifiActivity类和onCreate()函数展示
   public class DualWifiActivity extends AppCompatActivity {
       private BroadcastReceiver receiver;
       private static final String RSSI_CHANGED_ACTION = "huawei.net.slave_wifi.RSSI_CHANGED";
       private static final String WIFI_STATE_CHANGED_ACTION = "huawei.net.slave_wifi.WIFI_STATE_CHANGED";
       @Override
       protected void onCreate(Bundle savedInstanceState) {
           super.onCreate(savedInstanceState);
           startListener();
       }

       private void startListener() {
           receiver = new BroadcastReceiver() {
               @Override
               public void onReceive(Context context, Intent intent) {
                   if (RSSI_CHANGED_ACTION.equals(intent.getAction())) {
                       Log.d(TAG, "onReceive: get RSSI_CHANGED_ACTION");
                   } else if (WIFI_STATE_CHANGED_ACTION.equals(intent.getAction())) {
                       Log.d(TAG, "onReceive: get WIFI_STATE_CHANGED_ACTION"); 
                   }
               }
           };

           final IntentFilter filter = new IntentFilter();
           filter.addAction(RSSI_CHANGED_ACTION);
           filter.addAction(WIFI_STATE_CHANGED_ACTION);
           registerReceiver(receiver, filter);
       }
   }
   ```

2. 去注册双Wi-Fi处理广播。  
   当应用程序处于后台或退出时，可通过调用unregisterReceiver去注册弱信号预测广播接收。

   ```
   // DualWifiActivity类和onDestroy()函数展示，为了准确描述变量和函数实现的逻辑
   public class DualWifiActivity extends AppCompatActivity {
       @Override
       protected void onDestroy() {
           unregisterReceiver(receiver);
           super.onDestroy();
       }
   }
   ```

#### 获取Wi-Fi2的连接信息

当Wi-Fi2处于连接状态时，通过调用[getSlaveWifiConnectionInfo](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627#section73981566599)可以获取Wi-Fi2的连接信息，如连接的SSID、BSSID、RSSI、频率等。

```

            @Override

                    // 这里可以添加打印
                }
         }

}
```

#### 解绑服务

使用Android服务机制，App解绑[IDualWifiService](https://developer.huawei.com/consumer/cn/doc/system-References/idualwifiservice-0000001144301627)。

如下示例代码里DualWifiActivity解绑双Wi-Fi服务。

```
// mServiceConnection要与绑定时的ServiceConnection对象保持一致。在onCreate函数或者onDestroy函数中调用。
DualWifiActivity.this.unbindService(mServiceConnection); 
```
