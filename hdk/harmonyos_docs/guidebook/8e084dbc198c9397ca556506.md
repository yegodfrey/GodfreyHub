# 故障分析

故障分析旨在给开发者提供一种开箱即用的能力，帮助开发者能自主分析故障的根因。开发者在主动巡查或者被告警通知现网应用存在故障时，可以在故障分析下找到相关的故障，点击查看系统分析的结果。通过问题分析，开发者可以提前解决问题，消减现网的质量风险。

平台聚类整理后的故障列表将共同特征的故障聚类在一起，有助于共性问题的分析定位。

开发者可以在TOP问题中查看具体的系统分析的根因及建议。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/kDRpi2N_QcuuvJkrWJUB6w/zh-cn_image_0000002625281987.png?HW-CC-KV=V1&HW-CC-Date=20260909T131101Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C2BE3F2577B2E9459747089C9436C62232165B4027F16EFC39FE39CDCC8CCC5 "点击放大")

**符号表上传功能：**如果开发者分析到问题出现在具体的so下，可以通过上传so的符号表来进行日志解析。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/DuOR2yDjQ5GOPZY31g_4nA/zh-cn_image_0000002625362125.png?HW-CC-KV=V1&HW-CC-Date=20260909T131101Z&HW-CC-Expire=31536000000&HW-CC-Sign=CBCF66A0446B517F5F0D64D8B78272C647BD59E03D837843794B79C3BE3D916A "点击放大")

**应用灰度：**针对资源泄露类的故障场景，由于日志无法在故障发生后直接上传到云测，需要通过应用灰度的功能，来解决此类日志缺失的问题。通过应用灰度可以圈选一定数量的端侧设备，当故障发生后，这些设备会将日志上报到云侧。进而就可以结合事件一起分析故障根因。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/O9dv8H1lSAC3_xccMZQcbw/zh-cn_image_0000002594762624.png?HW-CC-KV=V1&HW-CC-Date=20260909T131101Z&HW-CC-Expire=31536000000&HW-CC-Sign=2671E691E932A67B8AA5460605F456A1698D9BFD69DA8FF0384C3C3DD3B6BEBE "点击放大")

**AI诊断分析：**系统分析的结果如果不足以支撑定位时，开发者还可以通过AI辅助分析的能力，基于现有的日志结合HarmonyOS开发知识库，给出辅助分析的意见，给开发者更多自助分析的信息。
