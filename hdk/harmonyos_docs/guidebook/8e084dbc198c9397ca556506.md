# 故障分析

故障分析旨在给开发者提供一种开箱即用的能力，帮助开发者能自主分析故障的根因。开发者在主动巡查或者被告警通知现网应用存在故障时，可以在故障分析下找到相关的故障，点击查看系统分析的结果。通过问题分析，开发者可以提前解决问题，消减现网的质量风险。

平台聚类整理后的故障列表将共同特征的故障聚类在一起，有助于共性问题的分析定位。

开发者可以在TOP问题中查看具体的系统分析的根因及建议。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/zHbn2Cn3Qh-ZlqwGCUWYtw/zh-cn_image_0000002625281987.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=EF51F1A9A2D1D88B362F7723C9F23ED0474FCAE034B007B15049B86ED166E8BA "点击放大")

**符号表上传功能：**如果开发者分析到问题出现在具体的so下，可以通过上传so的符号表来进行日志解析。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/Y3elP3dWQzSC6EsLFF3lVQ/zh-cn_image_0000002625362125.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=0EA6666E9E0BC196E3AD90960FEEBEC896EC470A79F0B2CB6E88F7B332E937F0 "点击放大")

**应用灰度：**针对资源泄露类的故障场景，由于日志无法在故障发生后直接上传到云测，需要通过应用灰度的功能，来解决此类日志缺失的问题。通过应用灰度可以圈选一定数量的端侧设备，当故障发生后，这些设备会将日志上报到云侧。进而就可以结合事件一起分析故障根因。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/h4f7uPyrRE2kP3ttncUjiw/zh-cn_image_0000002594762624.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=A99EBF6FAC180F7C1A07B812BFA412081DBA8A356A648F6C31C9AECB8E313239 "点击放大")

**AI诊断分析：**系统分析的结果如果不足以支撑定位时，开发者还可以通过AI辅助分析的能力，基于现有的日志结合HarmonyOS开发知识库，给出辅助分析的意见，给开发者更多自助分析的信息。
