# 云测试

云测试集成了体验专项质量标准的必选检测项，根据不同的设备形态、系统版本、API版本在不同的设备上进行兼容、稳定、性能、功耗、UX专项测试能力；同时通过上架全量测试和自定义测试，满足开发者不同诉求，不同场景的测试要求，并通过专业详细的测试报告，可以提前发现并精准定位和解决问题，帮助开发者解决开发者应用上架不符合规范而被驳回的困扰，降低开发者反复申请上架的时间成本，提升一次性上架通过率。

云测试的工作原理如下图所示，选择测试场景和测试范围后，上传应用程序包，然后选择云侧设备点击执行，完成后可获取详细的测试报告。

1. **云测试支持的五大检测能力**
   * **兼容性测试：**兼容性测试为开发者提供大量的手机、折叠屏和热门平板等设备，全自动化验证应用在不同类型设备上的首次安装、再次安装、卸载和启动中的异常问题，检测应用的崩溃、无响应、闪退、运行错误、账号异常、黑白屏、无法回退等兼容性方面的问题。
   * **稳定性测试：**稳定性测试执行时长约2H，提供长时间遍历测试及随机测试，以检测应用手机上的崩溃、冻屏、内存泄漏、进（线）程限制、文件资源限制等稳定性问题
   * **性能测试：**性能测试在真机完成性能数据采集，并深入分析应用性能薄弱点，支持应用冷启动时延、音视频操作时延、帧率、内存占用、CPU占用等测试项。
   * **功耗测试：**功耗测试检测影响手机应用功耗的前台资源占用和后台资源占用的各项关键指标。
   * **UX测试：**UX测试多设备形态上的运行，可有效检测问题类别包括基础体验、系统特性适配、视觉风格、动效、大屏体验等。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/J43uamO7QQm1iDWoTH8OqA/zh-cn_image_0000002625281975.png?HW-CC-KV=V1&HW-CC-Date=20260909T151208Z&HW-CC-Expire=31536000000&HW-CC-Sign=50640A0F5CE47FAAA9F3A9260B39A3E87D09A3F554AB99D8ABD3530DB40A2B75 "点击放大")
2. **云测试支持上架测试与自定义测试场景**
   * **上架测试：**上架合规预检严格遵循华为应用市场最新的审核准入规范与上架标准，对APP的安装启动、兼容稳定、隐私政策以及UI适配进行深度扫描和有效检测。该测试将潜在的审核驳回风险前置化识别并以报告日志形式呈现给开发者，显著降低应用上架周期内的驳回率，为应用顺利发布至华为应用市场提供坚实的质量保障与合规背书。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/SH1qqknZShmVR0LRmpvIHA/zh-cn_image_0000002625362113.png?HW-CC-KV=V1&HW-CC-Date=20260909T151208Z&HW-CC-Expire=31536000000&HW-CC-Sign=218C2B7C5B111ECD66579D21DD0AB686B35D81397B1C35FF4F4389C0DAC85A95 "点击放大")
   * **自定义测试：**云测试支持高度灵活的策略配置，开发者可结合APP测试中的高频问题与检测相关能力的特定需求，自主定义测试范围与测试时长，让开发者测试APP更有针对性，节省时间成本。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/YZd-kSujTPS7L8nTzLIs-g/zh-cn_image_0000002594762610.png?HW-CC-KV=V1&HW-CC-Date=20260909T151208Z&HW-CC-Expire=31536000000&HW-CC-Sign=6C54FCF621F7A4302231356F9D56AB741BEA7293EDA7B657F5D99BA5EDE18FD2 "点击放大")
   * **软件包管理：**云测试能力后移，提供了AGC-软件包管理入口，上传软件包后，页面会弹窗提示使用云测试能力，更方便开发者在上传软件包之后上架前进行全量测试，多渠道进行检测，提前发现问题。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/77/v3/_ORwVWxwTguuMuksibcmEA/zh-cn_image_0000002594922524.png?HW-CC-KV=V1&HW-CC-Date=20260909T151208Z&HW-CC-Expire=31536000000&HW-CC-Sign=B819AE9B660AFA8C27BF97545B3C4C49711FAC5C0CF0DC03C3B22EC0F5AEE903 "点击放大")
   * **IDE-云测试：**云测试能力前移，提供了IDE上检测入口，开发者者在IDE打release包成功后，日志信息区引导启动质量检测，开发者可以选择云测试检测，上传包到云测试任务中任务启动，检测完成后可以查看测试报告。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/XPBqynuDS_y7rdNZWk3XDg/zh-cn_image_0000002625281977.png?HW-CC-KV=V1&HW-CC-Date=20260909T151208Z&HW-CC-Expire=31536000000&HW-CC-Sign=B15FA7AF577C108476F9BFD5834AFEB34A30DE1A4A94F2159C08AF22210DDAE5 "点击放大")

   * 软件包管理-进入AGC-APP与元服务控制台查看；
   * IDE-AppAnalyzer页面查看报告结果；
