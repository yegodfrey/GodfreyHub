# 线上众测

线上众测是依托海量多元化外部测试用户群体，结合真实终端设备、多元使用场景与差异化用户行为习惯，面向移动应用、客户端软件、平台系统等各类数字化应用开展全域实战化测试的新型质量验证模式。  

|----|----------|---------------|-------------|
|对比因素|传统实验室封闭式测试|线上众测|众测核心优势|
|测试人员|专职测试工程师|海量不同圈层真实用户|视角多元，规避固有思维盲区|
|运行环境|标准化设备、固定网络|全机型、多网络、地域化真实环境|覆盖小众机型、极端网络场景|
|测试场景|常规标准操作流程|碎片化、高频并发、冷门操作场景|易捕获偶发、边缘隐性缺陷|
|体验评判|技术合规性判定|真实使用体感评价|贴合用户实际体验诉求|
|执行规模|人员设备数量有限|可快速规模化铺开测试|短周期完成大批量验证|
|成本投入|团队、设备场地成本偏|依托外部资源，轻量化投入|降本增效，压缩测试周期|
|风险排查|难预判线上突发问题|提前模拟全网运行状态|前置防控线上运行风险|
