# 多设备术语

|专用词|中文解释|
|:-----|:---------------------------------------------------------------------------------|
|一多|一次开发，多端部署的简称，是HarmonyOS 面向多设备开发的核心理念。|
|1 + 8|1：代表手机，以手机为入口，承担中枢角色；8：覆盖座舱、平板、PC、智慧屏、音响、耳机、手表/手环、AR/VR八大核心终端设备，构建多场景协同能力。|
|泛手机|特指HarmonyOS 多形态手机，设备品类包含直板机、多种形态的折叠机。|
|栅格系统|又叫 Grid System，在应用界面开发中，是将一个区域划分为一个二维的坐标系，用于辅助内部元素进行布局。|
|断点系统|断点是控制页面进行布局变化的一系列数值，当窗口尺寸到达某个数值区间时，页面布局按照开发者声明进行布局更新。|
|交互归一|HarmonyOS 多形态设备交互场景下，对相同用户意图的交互进行归一化设计，提供归一化的高级事件，提升开发者应用开发效率。|
|启动页|Starting Window，应用冷启动时显示的首个页面。在应用进程没有运行或者应用内容没有加载完成前，都将显示启动页，可以提升用户在应用启动阶段的用户等待体验。|
|SysCap|SystemCapability 的缩写，中文定义为"系统能力"，指HarmonyOS 中一个相对独立的功能特性。|
