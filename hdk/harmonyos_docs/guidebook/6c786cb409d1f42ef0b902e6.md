# Hypium设备测试MCP工具

AI时代来临，为支持开发者通过AI Agent在HarmonyOS设备上执行测试，Hypium提供了设备测试MCP工具，通过标准MCP协议，让AI模型能够调用 Hypium 能力对HarmonyOS设备进行智能自动化操作。

MCP 工具列表（仅列出MCP工具，全量接口可参考使用指南）：

|**模块**|**工具名称**|**说明**|
|:----------------------|:-----------------------|:-----------------------------------|
|基础操作（basic）|start_app|启动指定应用（支持包名或应用名称）|
|基础操作（basic）|stop_app|停止指定应用|
|基础操作（basic）|double_click|在指定坐标执行双击操作|
|屏幕控制（screen）|unlock_screen|解锁设备屏幕|
|屏幕控制（screen）|screen_on|打开设备屏幕|
|屏幕控制（screen）|rotate_screen|旋转屏幕方向|
|应用管理(app_manager)|install_app|安装应用程序|
|应用管理(app_manager)|uninstall_app|卸载应用程序|
|应用管理(app_manager)|get_current_app|获取当前运行应用的包名|
|Toast 监听(toast)|start_listen_toast|开始监听 Toast 消息|
|Toast 监听(toast)|get_toast|获取最新 Toast 消息|
|通用手势操作(general_gesture)|pinch_in|双指捏合缩小操作|
|通用手势操作(general_gesture)|pinch_out|双指张开放大操作|
|通用手势操作(general_gesture)|rotate_gesture|双指旋转手势，支持指定角度和方向|
|系统手势(system_gesture)|open_notification_center|打开系统通知中心|
|系统手势(system_gesture)|enter_recent_task|进入系统最近任务界面|
|系统手势(system_gesture)|drag_to_xiaoyi|将元素拖拽给小艺智能助手|
|观察工具(observation)|screenshot|获取屏幕截图（保存到指定路径，仅支持jpg格式）|
|观察工具(observation)|layout|获取当前页面布局结构|
|观察工具(observation)|find_elements|通过属性查找页面元素|
|数据采集（plugins）|start_data_collect|开始数据采集|
|数据采集（plugins）|stop_data_collect|结束数据采集|
|数据采集（plugins）|generate_report|生成测试报告|
|应用管理扩展(app_manager_ext)|start_app_by_deep_link|通过 Deep Link 启动应用，支持额外指定包名和ability名称|
|应用管理扩展(app_manager_ext)|write_clipboard|写入字符串到剪切板|
|应用管理扩展(app_manager_ext)|read_clipboard|读取剪切板内容|
|应用管理扩展(app_manager_ext)|clear_clipboard|清空剪切板内容|
|剪贴板操作(clipboard)|write_clipboard|写入字符串到剪贴板|
|剪贴板操作(clipboard)|read_clipboard|读取剪贴板内容|
|剪贴板操作(clipboard)|clear_clipboard|清空剪贴板内容|
|系统设置(settings)|set_view_mode|设置系统视图模式（深色/浅色模式）|
|Shell 命令(shell)|execute_shell_command|在设备上执行 Shell 命令|
|Shell 命令(shell)|pull_file|从设备拉取文件到本地|
|Shell 命令(shell)|push_file|将本地文件推送到设备|
