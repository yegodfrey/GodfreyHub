# 实验方案

**一、评测场景**

本章节实验重点面向端到端鸿蒙ArkTS全流程中的代码生成能力开展评测，将整体划分为三大一级评测场景，分别为全新需求代码生成、增量需求迭代开发、线上缺陷问题修复；在此基础上进一步细化二级评测场景，覆盖页面布局开发、组件逻辑实现、接口调用适配、功能迭代扩展、兼容性问题修复等细分开发任务，全面验证Coding Agent在不同开发阶段、不同任务类型下的实际落地能力。

**二、评测对象**

本次实验选取DevEco Code、OpenCode两款具有代表性的Coding Agent作为评测对象，覆盖鸿蒙原生适配、开源终端通用两类主流智能体形态。其中DevEco Code为面向鸿蒙生态深度定制的AI编码助手，原生适配ArkTS语法与鸿蒙开发规范；OpenCode 是开源终端型Coding Agent代表，具备多模型兼容与灵活的工程化代码处理能力。

本次实验选取 GLM‑5.1、DeepSeek V4‑Pro、Kimi K2.6、MiniMax M2.7 四款主流大模型作为底层基座，分别接入对应Coding Agent开展对比测试，可从模型能力、Agent Harness、上下文工程等多维度进行效果验证。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/-kg0XgBQQ2ijObQiE29qzw/zh-cn_image_0000002686528871.png?HW-CC-KV=V1&HW-CC-Date=20260909T152710Z&HW-CC-Expire=31536000000&HW-CC-Sign=9376DFC370CB0DEFDA4963982A884EAA3D53010551DCA7CC3404BBB59400C610)

受限于执行成本，并非所有Agent与模型组合均进行全量交叉测试。本文优先选择具备代表性的组合开展对比，并在结果展示中标注实际评测覆盖范围。
