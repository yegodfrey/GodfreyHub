# 评测指标与评测方法

**评测指标**

本次评测基于人机交互过程视角，结合AI辅助开发领域的优秀实践与场景知识工程模式（KEP）构建评估体系。其中，编译通过率用于衡量智能体生成代码语法合规性与可编译性，任务成功率反映代码是否满足需求规范、实现预期功能，Token 消耗数则用于评估智能体推理过程的资源开销与执行效率，多维度综合对比不同 Agent与基座模型在鸿蒙ArkTS代码生成任务中的实际表现。本章节所描述的数据集均构造了相应的测试用例可以进行自动化测试。

关键评估指标清单如下：

|---------|-------------------------------------|
|**评价指标**|**描述**|
|代码编译构建通过率|评价Agent最终产物构建状态为成功的比例|
|任务成功率|每个任务都配备了相应的测试用例，若所有测试用例都通过，则该任务判定为成功。|
|Token消耗数|OpenCode/DevEco Code所记录的总token数。|

**评测方法**

本次评测基于隔离沙箱环境开展自动化验证。针对UI交互类任务，采用鸿蒙生态专用的 Hypium 自动化 UX 测试框架构建标准化测试用例。Coding Agent生成代码后的 Git Patch 将同步上传至评测系统，系统自动提取并部署完整工程代码，拉起鸿蒙模拟器或物理真机环境；随后通过 Hypium 框架模拟人工对界面组件的点击、滑动、输入等交互行为，自动验证UI功能逻辑，最终输出标准化测试结果，实现对UI类代码生成任务的客观、可复现评估。
