# 性能测试

**性能基础质量测试服务**：通过自主遍历引擎模拟用户操作，对应用进行长时间、高频率的页面遍历，从响应时延、完成时延、卡顿率、黑白块、音视频流畅维度进行性能评估，并提供专业报告辅助性能优化。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/aMTV-tbrSx6bt3Ht3hMNZg/zh-cn_image_0000002594922518.png?HW-CC-KV=V1&HW-CC-Date=20260909T135647Z&HW-CC-Expire=31536000000&HW-CC-Sign=664DA769D40F6B4752EAB96F763E7B6E05AA0DBA0F18F73171EC0F22351A2726 "点击放大")

**场景化性能测试服务**：针对HarmonyOS应用的具体测试建议，提供一套包含自动化脚本执行和性能指标分析的解决方案，帮助用户测试指定场景（如滑动列表、视频播放等）下的性能表现，性能评估维度与性能基础质量测试服务相同。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6/v3/cVbajHmWTPa6eKwlTo1IdQ/zh-cn_image_0000002625281971.png?HW-CC-KV=V1&HW-CC-Date=20260909T135647Z&HW-CC-Expire=31536000000&HW-CC-Sign=B762A3A2308F0AEED328BF5A92D72AA0C3F88AD88BB8278526C08DB3A152D347 "点击放大")

**性能指标监控测试服务**：针对指定应用，检测应用帧率、内存、CPU负载等性能指标，通过实时渲染图的方式呈现，帮助用户进行性能评估。
