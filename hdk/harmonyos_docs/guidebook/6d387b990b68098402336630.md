# 性能测试

**性能基础质量测试服务**：通过自主遍历引擎模拟用户操作，对应用进行长时间、高频率的页面遍历，从响应时延、完成时延、卡顿率、黑白块、音视频流畅维度进行性能评估，并提供专业报告辅助性能优化。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/StjNAPfaTyOJ8bzXdpBwRQ/zh-cn_image_0000002594922518.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4458E3E0EB3A333CD1215E70C1523510C1D40E1D62AAEE92D9DEC15EAF91555 "点击放大")

**场景化性能测试服务**：针对HarmonyOS应用的具体测试建议，提供一套包含自动化脚本执行和性能指标分析的解决方案，帮助用户测试指定场景（如滑动列表、视频播放等）下的性能表现，性能评估维度与性能基础质量测试服务相同。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/4tRxj0WZSzmsoQ_yi6fj8A/zh-cn_image_0000002625281971.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=26D8F90C7CEC75033CAFEE752FADD2EADD99CAB2B557EE67814ED921B9DD330D "点击放大")

**性能指标监控测试服务**：针对指定应用，检测应用帧率、内存、CPU负载等性能指标，通过实时渲染图的方式呈现，帮助用户进行性能评估。
