# 金融领域交互体验提升

利用系统的悬浮窗能力，给开发者提供矩形样式轻量化悬浮窗口，降低开发者成本；同时支持用户高效便捷且安全的在应用外进行操作。在金融领域的重要盯盘场景下，利用该能力在多设备上体验进一步优化，在横竖屏切换、折叠开合等场景统一交互，充分利用大屏空间，为金融用户提供灵活便捷体验。
