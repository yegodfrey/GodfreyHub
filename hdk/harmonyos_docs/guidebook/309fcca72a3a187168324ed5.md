# 信息显示效率体验提升

利用鸿蒙的自适应组件能力和动态布局能力，在信息浏览场景下，在折叠屏/pad上浏览图文。左图右文布局，图片更大更清晰、文字一屏信息量更大，用户可以一边看左图细节、一边对照着看右文笔记详情或精彩评论，左右开弓、让阅读更轻松高效。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/BElHoNMGTy601PPIu-UfTw/zh-cn_image_0000002625112581.png?HW-CC-KV=V1&HW-CC-Date=20260909T140345Z&HW-CC-Expire=31536000000&HW-CC-Sign=F28E10A968AF7D141AD8519DBDE6A79352611F64894735599BC1B12D4B2FDBD8 "点击放大")

通过系统提供的沉浸光感能力，根据当前设备的算力动态调整组件的材质效果，实现性能与显示效果的最佳平衡体验。通过毛玻璃和微阴影的处理，让组件看起来"悬浮"在内容之上，不那么生硬地用各块布局切断内容、保持了视觉上的连贯性的同时增加了信息显示效率。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/MPCeJLQSQ6Ofjr-QIypdpQ/zh-cn_image_0000002594832992.png?HW-CC-KV=V1&HW-CC-Date=20260909T140345Z&HW-CC-Expire=31536000000&HW-CC-Sign=0765D26F0912080F32DFA61E49AAF490CD3D3FA3C267F93F080029F93B1316ED "点击放大")

利用鸿蒙系统的多列自适应能力，三方应用可以做到信息流的多列可缩放布局体验，用户可以一眼看到更多的内容，并支持手指捏合自由调整显示信息流的列数。
