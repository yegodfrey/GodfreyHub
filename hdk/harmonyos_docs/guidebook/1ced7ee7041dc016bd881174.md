# UX测试

**多设备布局对比测试服务：**基于UX体验标准，聚焦应用在直板机/阔折叠/双折叠/三折叠不同设备形态上的UX体验测试，重点覆盖界面布局、大图大字、状态栏/导航条等基础体验问题，测试设备支持真机和模拟器，自动进行横竖屏、折叠开合切换。
