# 质量报告

应用的现网运行质量分析可以帮助开发者掌握应用在多设备、多系统上的新老版本质量变化、以及应用在同类应用中的质量表现，以帮助开发者抓住应用质量提升的重点。

通过质量分析报告，可以给开发者团队测试提供定向测试信息，在研发测试环节加强功能及DFX验证，进一步提升新版本的应用质量。
