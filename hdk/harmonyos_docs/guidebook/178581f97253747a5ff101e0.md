# 稳定性测试

**稳定性基础质量测试服务（分布式遍历功能）：**基于轻量化随机遍历引擎的稳定性测试服务，单任务支持最多15台设备并发测试，检测问题类型包括应用闪退（JS Crash、Cpp Crash）、应用卡死（AppFreeze）、内存泄漏（基础水线检测）、资源过载（句柄、线程）。

**稳定性基础质量测试服务（定向压测功能）：**基于控件黑名单和指定入口的配置实现自定义应用遍历范围，定向压测业务模块，提升稳定性测试效率。应用图谱管理工具支持交互式录制保存Text、XPath粒度的控件黑名单，DeepLink指定模块入口。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/cWeMPaUIQzaOVZ9Kw4z2oQ/zh-cn_image_0000002625281973.png?HW-CC-KV=V1&HW-CC-Date=20260909T152349Z&HW-CC-Expire=31536000000&HW-CC-Sign=264E42DE7A4E239D86B61035ADB16596C633CE36C4C6B5F200EF062509D1EF95 "点击放大")

**内存泄漏测试服务：**基于内存对象分析、内存申请调用栈分析技术，构建ArkTS、Native等内存泄漏精准检测能力，测试服务提供自主遍历和自定义场景两种运行模式，支持灵活内存泄漏检测，提供详细的泄漏对象与调用栈日志以辅助问题定位。
