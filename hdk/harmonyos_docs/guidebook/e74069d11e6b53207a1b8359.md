# 单元测试

开发人员在不同编码阶段可以使用DevEco Studio预置的自测试工具，保障开发质量。

开发自测试工具包含：

* 编码环节进行代码静态检查：
  * Code Linter：对代码风格及代码正确性进行检查，同时支持使用命令行执行代码检查与修复，可将 Code Linter命令行工具集成到门禁或持续集成环境中。
  * Code Scanner：对代码进行内存泄漏静态扫描，发现潜在内存泄漏等稳定性问题。
* 编码完成后进行单元测试：
  * Instrument Test：基于真机环境执行单元测试用例，并生成覆盖率报告。
  * Local Test：基于预览环境执行本地单元测试用例，并生成覆盖率报告。
* 代码转测前进行动态分析诊断：
* AppAnalyzer：HarmonyOS应用动态分析诊断体检工具，快速发现基础体验问题并提供修复建议。
