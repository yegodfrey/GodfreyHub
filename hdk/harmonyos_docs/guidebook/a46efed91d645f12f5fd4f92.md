# 体验专项测试（本地）

为了帮助开发者做好体验专项测试，HarmonyOS提供了DevEco Testing本地体验专项测试工具，包含上架预检、性能、稳定性、UX等多个专项测试服务，支撑开发者在本地完成任务的创建与测试执行，并获取详尽的测试过程报告及问题日志，从而快速定位应用与产品问题，提升应用质量。

* 上架预检：本地化上架质量检测引擎，与应用市场同规则，包体不出本地环境，支持五大专项一键执行，发现基础体验类上架审核问题。
* 性能测试：基于性能体验测试标准，提供自主遍历、自定义场景、指标监控三种测试模式，发现时延、卡顿、黑白块等性能问题。
* 稳定性测试：基于本地化自主遍历引擎构建，支持多设备分布式并发压测、自定义应用遍历范围能力，加速稳定性问题激发；提供精准内存泄漏检测能力，提前发现内存泄漏问题。
* UX测试：针对HarmonyOS多形态设备特点提供多设备布局对比测试服务，支持对接模拟器、自动进行屏幕旋转/折叠开合等能力，发现应用在不同形态设备上的UX布局体验问题。
