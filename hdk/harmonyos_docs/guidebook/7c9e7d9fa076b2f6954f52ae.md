# 鸿蒙应用AI辅助研发新范式技术报告

#### 引言：AI Coding开发范式演进趋势

在人工智能技术高速迭代的行业背景下，数字化研发体系正迎来全局性变革，软件开发模式、研发流程架构与产业协作逻辑均迎来全新重塑。大语言模型（LLM）自问世以来就一直深刻地改变着软件开发范式，一路走来经历了三个阶段：

* Copilot模式：2021年6月提出，全称"交互式辅助开发范式"，是一种以"人类主导，AI辅助"为典型特点的开发范式。该范式以人类开发者为绝对行为主体和逻辑控制核心，AI仅充当副驾驶的角色，通过实时感知人类开发者的行为与开发环境中的上下文来预测人类意图，提供微观层面的自动化任务执行与建议。
* Vibe Coding模式：2025年2月提出，全称"意图驱动的协同开发范式"，是一种以"人类指挥，AI执行"为典型特点的开发范式。该范式中人类开发者以自然语言描述开发意图，AI作为执行主体负责实际开发任务，再将开发产物交由人类审核，根据人类给出的改进意见进行循环迭代。
* Agentic模式：2025年5月提出，全称"目标驱动的智能体开发范式"，是一种以"人类监督，AI自主"为典型特点的开发范式。该范式以具备复杂推理能力与长期记忆的AI智能体为核心主体执行具体开发工作，人类仅需提供顶层任务目标，并且在执行链路中的关键节点进行审查监督。

Agentic时代已经来临，给鸿蒙生态建设带来了巨大机遇和挑战。通过构建领先的鸿蒙AI开发工具，助力应用三端齐发、应用关键特性鸿蒙首发。
