# 兼容性体验测试

应用的基础功能兼容性，一般是指某个应用能稳定地工作在操作系统之上，而不会出现意外退出等问题。HarmonyOS应用需要兼容不同OS版本、不同设备形态，以及保证应用升级场景工作正常。
