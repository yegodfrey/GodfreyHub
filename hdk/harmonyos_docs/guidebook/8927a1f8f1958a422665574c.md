# 故障指标

APMS故障指标是基于应用现网运行的真实数据，端侧发生故障时会上报对应的故障事件，在云测统计分析。针对开发者最常见的应用崩溃、应用冻屏、系统查杀、OOM、资源泄露等常见的故障，提供多维度的指标数据。开发者需要主动查看这些数据，对应用质量指标进行日常巡检，主动发现应用隐患。

崩溃趋势分析：开发者基于如下视图可以对最近一段时间的崩溃有个比较直观的认识，还可以通过历史版本对比识别质量改进或劣化信息。

![](https://media:801788430184943352 "点击放大")

故障维度分布：基于故障在版本、系统、设备维度的分别排序，可以让开发者快速识别问题的出现范围，帮助聚焦问题的解决重点。

![](https://media:801788430184991353 "点击放大")

TOP问题列表：通过把最近一段时期内的高频问题分析聚类，可以识别最重要的问题，以帮助开发者决策解决质量提升的关键问题。

![](https://media:801788430185040354 "点击放大")
