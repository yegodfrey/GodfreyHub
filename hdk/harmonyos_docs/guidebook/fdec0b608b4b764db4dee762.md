# 格物市场

在鸿蒙生态中，一个专用的AI工程能力市场是必要的，原因在于AI开发与传统软件开发存在根本差异：通用应用商店解决"分发"，而AI工程市场解决"生产"。它的核心价值是把鸿蒙中分散、异构、高门槛的AI资源，转化为标准化、可用、可比对的工程能力。[格物市场](https://matrix.openharmony.cn/)可以提供统一接口供端侧Agent调用，支持多种托管方式。同时，格物市场支持按标签、按分类、按组织检索各种AI资产，也支持按照业务场景，提供精品集，汇聚业务场景下的工程能力集，供开发者一键式批量下载。格物市场解决了鸿蒙AI辅助研发新范式下的关键难题：

* 解决能力发现难：AI资产分散在多平台，难以一站式触达。专用市场聚合所有能力，无需多平台跳转。
* 降低选型成本：AI技术路线快速演进，选型复杂。市场提供横向对比、场景推荐、社区评价，帮助决策。
* 提升集成效率：各AI能力接入方式、依赖、权限不统一。市场提供一键集成（如代码片段+环境配置），减少摩擦。
* 保障质量可预期：第三方AI能力质量参差不齐，市场建立质量评级（兼容性、性能、安全、社区评分），供开发者预判。
* 促进资产沉淀与复用：避免重复造轮子。市场激励开发者开放可复用的AI资产（框架、模板、工具），形成共享循环。

格物市场的工具定位于"鸿蒙AI工程能力路由器"------不生产AI能力，而是链接、索引、编排、赋能，让开发者一站式找到高质量、可复用的AI工程化资产，支持场景化导航+智能推荐，支持按标签、按分类、按组织检索，也支持按业务场景定制能力。

![](https://media:801788430181334294)

格物市场还建立了和开发者充分交互的共建流程，以及AI资产的高安全审计能力：

* 建立开发者贡献AI工程能力到Matrix的流程，实现从注册-\>创建托管需求-\>编辑草稿-\>提交申请-\>审核-\>安全\&合规检测-\>上架的一站式服务；
* 建立遇到舆情投诉或者安检未通过的AI资产的下架机制；
* 针对AI可能投毒作恶，威胁系统与用户数据安全，提供事前上架审计检测，保障SKILL、工具等供应链安全。事中检测审计，阻断高危命令执行。事后审计追溯，持续改进提升系统安全。

AI开发已从"调用API"升级到"工程化集成"，格物市场通过聚合、评测、集成、激励，解决开发者"找得到、选得对、接得快、用得稳、能分享"五大痛点，加速鸿蒙原生智能应用规模化落地。
