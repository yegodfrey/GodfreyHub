# HarmonyOS特性质量测试

HarmonyOS特性是围绕HarmonyOS的六大体验场景，提供了一系列的通用系统能力。通过接入HarmonyOS特性能降低开发成本，还能给用户带来更好的用户体验。

开发者接入HarmonyOS系统特性时，**需** **结合自身应用实际业务场景**，匹配特性能力特点，制定针对性测试方案，精准落地专项测试，保障特性适配顺畅、业务融合自然，用户使用体验更优。
