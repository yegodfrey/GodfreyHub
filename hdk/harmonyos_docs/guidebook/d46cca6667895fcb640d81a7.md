# UI自动化测试框架Hypium

UI自动化测试是应用质量保障中非常关键的环节，Hypium自动化测试框架是HarmonyOS生态提供的自动化测试基础框架以及配套的开发工具，可支持开发者开发自动化测试用例包括创建工程、自动化代码开发、用例执行和报告分析等步骤。

* 创建DevEco Testing Hypium自动化测试工程 在官网下载DevEco Testing Hypium PyCharm插件以后，可在Pycharm中创建自动化测试工程。

  ![](https://media:801788430184025337 "点击放大")  
  工程目录简介：

  ```
  ~project	# 工程根目录
  ├─aw		# 公共方法目录
  ├─config 	# 工程配置目录，可配置设备SN、报告路径等
  ├─reports	# 测试报告目录
  ├─resource	# 测试中使用到的资源文件目录
  ├─testcases     # 测试用例目录
  ```

* 自动化用例执行 结合自动化调试、开发、本地快速执行、产线无间断执行等场景，Hypium提供了以下多种自动化执行方式：

  * 基于当前文件执行;
  * 选择单步调试运行;
  * 选择多条用例批量执行;
  * 基于命令行下发执行;

* 报告查看与分析 通过查看报告、分析失败日志以定位问题。

  执行报告中包括整体执行结果：通过用例用例数、失败用例数等。

  ![](https://media:801788430184059338 "点击放大")

  点击用例可查看每条用例详细的执行日志和对应步骤中手机界面的截图。

  ![](https://media:801788430184091339 "点击放大")

  <br />

  Hypium提供了HarmonyOS UI测试常用组件库, 以提升开发者的自动化开发效率，组件及对应功能如下：  

  |分类|组件名称|功能描述|
  |:-----|:----------|:-----------------------------------------------------------|
  |基础组件|UIDriver|设备UI测试核心功能类, 提供设备管理操作：如连接设备、断开设备等； 提供系统级基础操作：设备点击/滑动操作、控件查找等|
  |基础组件|UIWindow|窗口对象, 提供窗口相关属性获取和窗口操作接口|
  |基础组件|UIComponent|控件组件，提供控件相关属性获取和控件操作接口|
  |基础组件|BY|控件选择器, 根据控件属性定位控件，支持多条件组合查询|
  |常用系统组件|Launcher|桌面常用操作组件，提供应用的桌面启动等操作接口|
  |常用系统组件|NetCopilot|网络模拟组件，可模拟电梯、离家、地库、地铁、高铁、高速等各类网络场景|
  |常用系统组件|Clipboard|剪贴板常用操作组件，提供剪贴板读取、写入、清除等接口|
  |常用系统组件|TimeLocale|时间时区操作组件，提供设置、查询时间和时区的接口|
  |常用系统组件|FontManager|字体管理组件，提供字体安装、卸载等接口|
  |常用系统组件|Mouse|鼠标光标操作组件，提供获取鼠标光标样式，自定义光标图片等接口|
  |常用系统组件|System|系统设置操作组件，提供深色模式等系统级设置等接口|
