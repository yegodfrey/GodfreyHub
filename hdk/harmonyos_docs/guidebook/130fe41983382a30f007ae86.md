# 鸿蒙AI辅助研发工具共建

华为与钉钉、蚂蚁、WPS、哔哩哔哩等生态伙伴基于AI辅助研发实践，共同建设Rules、Skills、Tools、Agents等基础设施能力，并面向开发者发布，支持广大鸿蒙应用开发者快速构建AI辅助研发专属Agent，显著提升鸿蒙应用开发效率。

![](https://media:801788430182907324 "点击放大")

1）与钉钉共建AutoBugFix Agent，问题定位修复效率提升30%

AutoBugFix实现了Bug修复全程自动化，主要针对UI显示问题以及功能缺失问题。Agent基于问题描述自动编写测试计划，进行问题复现、分析定位、编码修复、编译构建、运行验证以及经验沉淀。

AutoBugFix调用DevEco CLI提供的verify_ui工具启动应用、执行操作、保存截图。如果问题复现成功，则调用get_ui_verification_log获取运行日志进行问题分析；如果问题无法复现，则记录无法复现的原因，并结合日志、截图等调整测试计划。如果存在细微的UI组件问题，则运行到目标页后，使用get_app_ui_tree工具查看当前页面的组件信息。

AutoBugFix已在钉钉发现页、聊天页试点应用，成功定位并修复UI显示问题以及功能缺失问题，包含瀑布流适配、共享元素转场、UI截断等，问题定位修复效率提升30%以上。该问题定位修复的能力已经形成Skill并发布到格物市场。

2）与蚂蚁集团共建三端一致开发流水线，开发效率提升60%以上

三端一致开发流水线定义了鸿蒙、安卓、iOS三端同步开发的工作流，包含环境检查初始化、需求创建、跨端技术方案分析、端侧实施计划、编码实施、编译构建、UI验证等全流程。

三端一致开发工作流内部嵌入HarmonyOS ArkTS、ArkUI以及Kits使用知识，同时构建了HarmonyOS知识的分层和路由机制，有效减少上下文污染，优化模型对复杂场景的理解。主要分为四层：L0: 框架机制 （FOUNDATION），查语法规则；L1: 组件用法（HOW），查API、Kits使用；L2: 设计模式（WHAT），查架构、状态、数据、交互、工程等；L3: 领域约束（WHY），查业务规则、领域逻辑等。

以框架机制层为例，大模型按照如下步骤获取ArkTS知识：① 大模型可快速学习ArkTS语法核心约束摘要；② 大模型根据具体编码场景：编写类型定义、编写class/struct、编写函数、编写模块、编写声明式UI等，快速索引到对应的详细约束、Good example、Bad example。该路由机制有效提升了ArkTS代码生成的准确率，同时节省了上下文空间。

经实际项目验证，某开发任务原需5人天/平台，三端齐发需要15人天。利用三端一致开发流水线同步开发，仅需0.5人天工作量，以及1.5人天调试工作量/平台，总计5人天，开发效率提升60%以上。该三端一致开发的能力已经形成Skill并发布到格物市场。

3）与WPS共建自动化Trace性能分析工具Harmony Trace Analyzer，性能专项问题分析效率提升4倍

WPS在性能专项中长期面临Trace分析耗时的困境。对于单个样张的性能分析，工程师需手动抓取Trace、框选完成时延区间、识别并记录火焰图热点，一般需要数分钟；面对性能专项自动化测试产出的上千份Trace文件，人工分析已成为性能专项的核心瓶颈，且分析过程高度依赖专家经验，新手难以参与。

WPS基于HiTrace业务埋点构建全链路自动化分析工具，将"打开Profiler、逐条人工review"升级为"采集即分析、落盘即出结论"。该工具具备四大核心能力：① Trace精准抓取，以HiTrace Tag作为业务起止边界，Tag的duration即为真实耗时，无需推断帧边界，准确率接近100%；② 热点自动发现，将专家的火焰图解读策略固化为规则，自动定位调用栈分叉点并输出瓶颈函数及占比，显著降低分析门槛；③ AI热点聚类，借助大模型跨Trace统计高频热点函数、灵活聚类排序，并生成结构化根因描述与优化建议；④ 流水线集成，支持目录监听、批量并发与增量跳过，与CI/CD无缝对接，测试跑完即刻生成根因描述与优化建议报告。该工具可支持.htrace、.ftrace、.db等格式的Trace，可输出CSV、JSON、HTML等格式的报告，任何鸿蒙应用只要添加Tag埋点即可低成本复用。

经WPS鸿蒙版性能专项验证，以"表格打开性能分析"为例，有798个样张，人工全量样张摸测，耗时66小时（约8人天），将该工具集成到性能流水线后，耗时最多13小时，从单样张"场景自动触发-\>trace抓取-\>符号导入-\>输出分析报告" 到多样张"输出聚类报告"，实现全流程自动化，报告中给出性能瓶颈线程、TOP5高频函数名称和占比以及对应的代表样张名称。该工具结合AI聚类Skill输出TOP高频热点和典型样张，让开发者不再进行繁复的海量热点查找，专注于核心算法与业务逻辑优化。目前该工具已开源，并将分析能力封装为可被Agent调用的Skill，帮助更多伙伴实现端到端的高效性能分析。

4）与哔哩哔哩共建代码迁移与历史资产复用Agent，提效30%

哔哩哔哩作为内容生态领域的代表性企业，拥有大量基于安卓、iOS平台的历史代码资产，传统代码迁移方式依赖研发人员手动适配、改写，不仅耗时费力，且易出现兼容性问题，同时历史代码中的优质逻辑、组件无法高效复用，导致开发成本居高不下、迁移周期漫长。

华为与哔哩哔哩携手，基于开源通用Agent底座，结合鸿蒙领域定制化需求，共同构建了代码迁移与历史资产复用智能Agent，实现全链路自动化代码迁移与资产复用，覆盖开发者全流程体验。该Agent具备三大核心能力：① 精准的需求理解能力，可通过自然语言交互、代码解析等方式，快速识别迁移需求、业务场景及核心约束，明确代码迁移的目标、范围及适配标准，避免因需求理解偏差导致的迁移返工；② 高效的代码生成与适配能力，可自动将安卓平台的存量代码（如Java、Kotlin代码）转化为符合鸿蒙规范的KMP三方框架代码，同时自动处理跨平台API差异、组件适配、权限兼容等问题，生成可直接编译运行的代码片段；③ 全流程自动化验证能力，集成编译构建、功能测试、兼容性验证等模块，代码迁移完成后可自动触发编译构建，检测代码语法错误、运行异常。同时对比迁移前后的功能一致性，生成详细的验证报告，减少人工测试成本。经哔哩哔哩实际迁移项目验证，"我的收藏"页面迁移至鸿蒙平台，传统方式需40人天完成，使用该智能Agent后，仅需15人天即可完成全流程迁移与验证，开发全流程效率提升30%以上，大幅降低了迁移成本和开发周期。

目前，该Agent已完成核心功能迭代并开源，将逐步开放给全行业开发者，助力企业快速实现历史代码资产向鸿蒙平台的迁移，加速鸿蒙生态的应用落地。
