# 代码静态检查工具

**Code Linter**：HarmonyOS应用开发中提供的代码静态检查工具，用于在代码编写阶段自动检测代码质量问题。该工具支持ArkTS和TS语言的代码检查，能够发现语法错误、代码风格问题、最佳实践违规等。Code Linter集成在DevEco Studio开发环境中，在开发者编写代码时实时提供问题提示和修复建议。同时，Code Linter也支持命令行执行，开发者可以将其集成到门禁或持续集成环境中，实现代码提交前的自动化检查。

Code Linter 支持的规则集如下：

* 通用规则@typescript-eslint
* 安全规则@security
* 性能规则@performance
* 预览规则@previewer
* 一次开发多端部署规则@cross-device-app-dev
* ArkTS代码风格规则@hw-stylistic
* 正确性规则@correctness
* 兼容性规则@compatibility

**Code Scanner：**HarmonyOS 应用开发中提供的代码静态深度扫描工具，主要用于检测内存泄漏等API使用问题。该工具通过对代码进行静态分析，能够发现潜在的内存泄漏风险、空指针引用、资源未释放等稳定性问题。Code Scanner可以帮助开发者在应用开发早期阶段识别并修复这些潜在问题，提升应用的稳定性和可靠性。使用Code Scanner时，开发者只需在DevEco Studio中启动扫描任务，即可获得详细的检测报告和修复建议。
