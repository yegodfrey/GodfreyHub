# 自动化测试

DevEco Testing Hypium UI自动化测试框架(以下简称Hypium)提供了丰富的设备检查和操作接口，支持驱动多种形态的HarmonyOS设备执行UI自动化测试。

Hypium提供了公共的操作接口来操作不同形态的设备，提升了开发者针对多种形态设备的自动化测试脚本适配效率。同时还提供了设备类型感知、设备特有操作接口以及用例支持设备类型配置功能，支持自动化测试脚本针对不同设备进行，从而支持开发者实现自动化测试脚本的一次开发和多形态设备执行。

公共操作接口

开发者可以使用相同的接口驱动不同形态的设备完成公共的操作，例如通过driver.click点击接口可以驱动手机、平板电脑、个人PC、智能手表等不同设备实现点击操作。

设备类型感知

开发者可以通过driver.device_type接口读取当前驱动的设备类型，从而针对性的执行设备特有的操作。

设备特有接口

Hypium针对平板电脑、个人PC、智能手表等设备提供了对应设备类型特有的操作接口，例如提供了鼠标点击、滚轮滚动、键鼠组合等接口支持个人PC特有的应用场景；提供了触控笔操作支持平板电脑特有的应用场景；提供了表冠操作支持智能手表特有的应用场景等。

用例支持设备类型配置

Hypium的用例配置文件支持配置当前用例能够运行的设备类型。开发者可以根据用例实际情况，在Hypium的用例配置文件中设置用例不限制设备类型，或者仅支持在部分设备类型上运行。

多台设备交互测试

Hypium提供的设备连接接口支持连接本地或者远程的多台设备，开发者可以在任务配置文件以及用例配置文件中定义测试所需的设备数量和类型，按照测试场景的交互流程控制多台不同形态的设备进行测试。典型场景如下图所示，开发者可通过Hypium同时控制手机、PC以及智慧屏设备，完成应用流转、跨设备分享等功能的自动化测试。

DevEco Testing 多设备布局对比测试根据应用UX建议，覆盖直板机/阔折叠/双折叠/三折叠设备品类，检查应用在多设备上是否存在大图大字，界面遮挡截断等基础问题。

多设备检测

支持直板机、阔折叠、双折叠、三折叠设备同时测试，支持对应手机、模拟器接入测试。

典型UX问题检测

针对大图大字、界面截断遮挡、留白等典型布局问题做自动化测试。

单设备和多设备对比测试报告

测试报告按检测规则统计通过和不通过的页面截图，针对不通过页面或控件给出问题描述和修改建议。多设备对比报告展示同一页面在不同设备上的截图对比，帮助开发者更直观的发现UX问题。
