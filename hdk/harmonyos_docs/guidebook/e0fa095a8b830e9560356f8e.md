# HarmonyOS创新特性测试

|领域|场景与分类|特性能力说明|
|:-|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|易用|统一文件下载|HarmonyOS系统为应用提供了下载控件多次保存到固定目录、FilePicker单次保存到指定目录两种将文件存储到公共目录的方案，解决不同场景应用及用户对文件的使用诉求，同时保障了文件使用的安全性与隐私性。|
|易用|华为账号|华为账号提供登录体验设计规范，帮助用户使用已有的华为账号登录HarmonyOS生态内全部应用。|
|易用|一键登录|应用可以通过华为账号一键登录能力方便地获取华为账号用户的身份标识和手机号，快速建立应用内的用户体系。|
|易用|数字收银台|数字商品收银台对应数字商品。通过数字收银台，用户可以在应用内购买各种类型的数字商品（虚拟商品），包括消耗型商品、非消耗型商品和自动续期订阅商品。|
|易用|实物收银台|实物商品收银台对应实物商品，商户应用接入实物商品收银台后，可在商户的应用内通过拉起华为支付收银台来完成订单的支付并展示支付结果以及完成用户对实体商品或服务（例如酒店服务、出行服务、充值缴费服务等）的购买。|
|易用|应用多开|应用创建应用分身，两个应用可登录不同的账号使用，运行互不影响。|
|易用|扫码直达|控制中心扫一扫应用二维码，直达应用内的各种服务。|
|易用|服务卡片|将元服务/HarmonyOS应用的重要信息以卡片的形式展示在桌面，用户可通过快捷手势使用卡片，通过轻量交互行为实现服务直达、减少层级跳转的目的。|
|易用|VoIP一键接听|锁屏状态点击应用来电接听按钮一键接听、一键消息回复、回电提醒。|
|易用|日历开放能力|应用服务日程写入系统日历，多端多入口统一提醒，一键跳转至落地页。|
|易用|扫码能力开放|基于HarmonyOS架构建的统一扫码服务。实现扫得快、扫的准、扫得远。|
|易用|PC一步直达特性|应用和系统工具高频操作的轻量化便捷入口，在桌面使用小而轻的浮窗式面板完成应用高频核心功能（如备忘录的速记），避免调取全量应用吗，即开即用，简化交互，为用户带来高效专注的沉浸式办公体验。|
|易用|统一文件预览|通过预览来快速查看图片、音乐、视频、 Office文档、PDF文档、TXT文档、HTML文档，不跳转弹窗。|
|易用|手写体验|连接手写笔，选择不同的笔刷书写，书写笔迹连续，使用擦除工具擦除笔迹，使用套索/手写工具栏/橡皮擦/一笔成形等工具多元化优化手写效果和体验。|
|易用|统一拖拽|拖拽操作是一种直观且高效的数据传输方式，它允许用户通过手势（如用手指、鼠标或触控笔按住并移动）在应用程序之间及其内部进行数据传输。拖拽功能不仅操作便捷，还能与多种系统能力深度融合，从而拓展出更为广泛的应用场景。例如，跨设备拖拽功能使得用户能够在不同设备间无缝传输数据，而跨窗口拖拽则提高了多任务处理的灵活性。此外，基于拖拽操作还可以开发出更多创新性应用场景，如AI智能识别、水印添加等，这些创新性的功能统称为"统一拖拽"。|
|易用|智慧多窗-应用内分屏|办公类应用，提供应用内分屏，方便应用内的任务并行。|
|易用|智慧多窗-画中画|视频播放、视频通话、视频会议、直播场景支持画中画能力。|
|易用|实况窗|实况窗是一种帮助用户聚焦正在进行的任务，方便快速查看和即时处理的通知形态，具有时段性、时效性、变化性的特点。 在展示形态上，实况窗支持在锁屏、通知中心、状态栏等位置展示，主要有两种展示形式：胶囊态和卡片态。|
|易用|统一链接跳转|在链接中唤起APP，如果安装了就唤起，否则引导下载。|
|安全|权限安全Picker|应用拉起系统Picker组件（通讯录、媒体和文件-图片/音频/视频，剪贴板），由用户在Picker上选择对应的文件、照片、联系人等资源，应用即可获取到Picker的返回结果,不需要授予应用读取图片文件的权限。|
|安全|设备真实性证明服务|能够识别模拟器、云手机等非真实设备/仿冒应用等非真实应用/伪造应用请求，防止游戏防作弊/外挂，防营销活动中黑灰产利用工具"薅羊毛"。|
|安全|Asset敏感资产存储|基于硬件TEE级别的数据加密存储安全服务，提供了用户短敏感数据（如口令、Token，卡号等）本地的安全存储及管理能力。|
|安全|Device Verify匿名设备查询服务|应用可以根据Device Verify服务器返回的设备使用状态，应用于营销风控、新设备识别业务场景。|
|安全|DLP数据分享保护|帮助开发者的应用快速构建数据加密分享能力。|
|安全|未成年人模式|系统级未成年保护模式为青少年用户营造纯净安全的用户体验。|
|流畅|纹理超压缩|通过利用纹理超压缩技术，宫格万图浏览瞬息加载，无白块流畅显示。|
|流畅|预加载服务|内容型的应用通常是从后台获取资源和布局数据，然后加载页面，比如新闻、电商、应用市场、视频、银行、政务等应用，这样会导致首次（应用首次启动/页面首次加载）打开速度慢。预加载服务通过数据的提前加载提升应用页面打开速度50%左右。|
|流畅|低时延编解码，直播开播流畅|在实时视频业务场景，如直播连麦、视频会议、视频聊天等，音视频低时延实时互动、低时延、低卡顿。|
|流畅|音频低时延通路|在实时音频语音通话场景，如会议通话、语音聊天等VoIP语音通话在传输带宽受限场景的场景（如高铁、地库等）下不卡顿断续、音质变差影响用户。|
|流畅|FFRT并行加速库(C/C++)|多任务并发编程，使能应用极致能效。FFRT（Function Flow Runtime）任务并发调度服务提供高效、易用的多任务并发编程框架，让应用专注于自身的应用程序开发，提升开发效率和应用并发性能。|
|流畅|小视频流畅优化|解码器支持复用和Surface技术，支持切换抖音等小视频滑动流畅。|
|流畅|游戏渲染加速服务|开启渲染加速服务，游戏的性能功耗低。|
|流畅|LTPO可变帧率|应用LTPO可变帧率技术构建省电流畅的HarmonyOS应用。|
|流畅|TaskPool任务池|TaskPool是ArkTS语言提供的一个多线程任务池API，提供了丰富的多线程并发能力、流畅的用户体验、更低的编程复杂度。|
|流畅|弱网感知|OS侧提供的弱网卡顿感知能力可以从底层提供多参数特征组合(延时、磁感应强度、接近光强度等)，识别率高于APP原有网络感知能力。|
|协同|手机车机导航流转|上车前、行车途中，通过手机地图开始导航，导航自动流转到车机地图。离车时，离目的地还有一段距离，车机上的导航将自动流转到手机，可以通过手机地图继续步行导航。用手机碰一碰中控屏，可以快速地将手机地图或APP中的地址流转到车机地图。|
|协同|跨设备互通|打开应用，平板或2in1设备可以调用手机的相机、扫描、图库等功能跨设备的相机、扫描、图库访问。|
|协同|接续|应用接续可以在其他设备上无缝衔接当前设备上的任务 。|
|协同|无线投屏&投播|大小屏协同，创新多屏体验。双屏协作，影音娱乐更沉浸办公更高效。|
|精致|拍照一致性|一键式拍照，相机系统统一拍照过程，确保相同场景下效果一致，全面提升三方相机效果。|
|精致|HarmonyOS VIVID标准能力开放|视频和图片显示统一架构，节省功耗和算力，对画面细节的表现力更佳。 视频：高动态范围广色域极致视觉体验。 音频：支持更好的音质、更沉浸的空间感，还原物理和感知世界中的真实听感。|
|精致|流畅动效-一镜到底|一镜到底是通过共享元素、容器等来进行转场过渡的一种编排方式，有助于提升用户操作任务的效率，增强视觉的流畅感，是转场设计中重点推荐的技法。开发者可以通过属性动画、Navigation自定义动画、geometryTransition共享元素接口等方式，实现各类场景中的一镜到底效果。|
|精致|MovingPhoto|HarmonyOS生态社交APP支持华为HarmonyOS框架动态照片格式，以使其能以动态效果展示图片；让影像记录更加丰富，更具有临场感，赋能照片"有声有色"。|
|智能|智感支付|开启智感支付设置默认支付方式，手机在主桌面时，扣向扫描设备自动跳转应用的支付码界面 。|
|智能|AR空间计算|为应用提供AR空间计算能力，助力应用理解现实空间，打造创新的虚实融合视觉体验和空间计算应用场景。|
|智能|智能图文提取-AI基础控件|打开支持文字识别、抠图、表格提取等功能的应用，对常见文本实体、图片、画面进行对应的智能提取表格，翻译，识图搜索，图像分割，文字识别等图文提取操作，可拖拽分享。|
|智能|意图框架|应用接入意图框架，理解用户意图将功能和内容精准触达用户，比如场景化推荐（习惯推荐、时间推荐、位置推荐）。|
|智能|智能填充|智能推荐输入建议，复杂表单一键填充。|
|智能|文档扫描-AI场景化控件|文档边缘识别、矫正，生成高质量文档，智能高效。支持多种方式扫描文档（手动拍摄，自动拍摄，图库导入，表格提取，滤镜，闪光灯，旋转，裁剪，保存，重拍，变更语种）。|
|智能|活体检测-AI场景化控件|检测是否为活体，输出活体结果及检测过程照片；自研算法实现有效防护高精视频高精面具攻击。|
|智能|卡证识别-AI场景化控件|卡证识别控件可以支持身份证、银行卡证件的结构化识别，在一些需要进行证件信息采集的应用中可以使用该控件，不仅可以降低用户输入错误信息的概率，OCR识别能力增强，提升文字搜索召回率，同时提升交互体验。|
|智能|朗读-AI场景化控件|新闻资讯和小说等听的场景，可以一次接入多处露出（锁屏和播控中心）。|
|智能|AI字幕-AI场景化控件|使用视频控件，打开开关即可实现支持单/双语字幕。|
