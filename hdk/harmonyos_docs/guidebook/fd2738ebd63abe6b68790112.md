# 学习课程

开发者可通过HarmonyOS开发者学堂的在线课程获取测试相关的全部学习内容，测试课程包含DevEco Studio开发态自测试服务、DevEco Testing和Hypium测试阶段自测试服务、云测试/云调试远程真机测试、HarmonyOS邀请测试和质量监测服务等等。

|--------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------|
|课程名称|课程介绍|
|[DevEco Studio：开发态自测试服务](https://developer.huawei.com/consumer/cn/training/course/live/C101762308912727284)|系统介绍了当前整体的开发者自测试服务，同时介绍了开发态的测试能力包括：DevEco Studio的测试框架，静态检查Code Linter，应用与元服务体检AppAnalyzer|
|[DevEco Testing和Hypium：测试阶段自测试服务](https://developer.huawei.com/consumer/cn/training/course/live/C501764656546952070)|主要介绍DevEco Testing测试工具的上架预检和专项测试能力以及Hypium的自动化测试框架能力。|
|[云测试、云调试：远程真机测试](https://developer.huawei.com/consumer/cn/training/course/live/C301753070434999220)|主要介绍云测试云调试服务能力和接入流程。通过学习可以快速了解云测试云调试的使用方法。|
|[解读HarmonyOS邀请测试和质量监测服务](https://developer.huawei.com/consumer/cn/training/course/live/C201768961510472164)|主要介绍邀请测试和应用现网监测能力，可以通过课程了解这2个能力的定义，规格和使用场景。|

开发者如需学习其他课程，可访问[开发者学堂在线课程链接](https://developer.huawei.com/consumer/cn/training/result?courseType=5&orderBy=1&type1List=101718934267126043)。
