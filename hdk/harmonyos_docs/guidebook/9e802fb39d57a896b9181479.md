# 自动化开发助手HypiumAssist

HypiumAssist是一款提升测试人员自动化开发效率的工具，其核心功能为对设备界面进行投屏和透视页面布局信息，以帮助开发者快速开发和调试。

提供设备 Shell 命令执行和文件传输功能。
