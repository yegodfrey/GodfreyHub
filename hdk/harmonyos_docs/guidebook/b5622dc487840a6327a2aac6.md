# 反馈渠道

开发者可通过访问Developer社区中的[开发者论坛官网](https://developer.huawei.com/consumer/cn/forum/)，在线提交问题。同时，可利用论坛搜索功能查阅[其他开发者已提出的问题](https://developer.huawei.com/consumer/cn/forum/topics?keyword=蜕变之旅)及专业回复，与社区中的技术专家在线交流，分享实践经验。

开发者亦可通过[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)获取相关问题的AI解决方案，智能客服能够基于智能分析快速识别问题本质，提供高效且精准的解答，切实提升开发者问题解决效率。
