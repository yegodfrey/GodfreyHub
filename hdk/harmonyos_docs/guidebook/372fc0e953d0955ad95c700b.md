# 应用上架与发布

华为应用市场（AppGallery）作为华为终端设备的官方应用分发平台，为用户提供安全、可信、体验流畅的应用，同时也致力于为开发者提供丰富的工具、能力、资源支持以及增长全栈解决方案。

AppGallery Connect作为华为应用市场面向开发者的门户，致力于为开发者提供应用创意、开发、分发、运营、分析全生命周期服务，构建全场景智慧化的应用生态。该门户旨在提升开发、运营效率，帮助开发者实现用户及收入的规模增长。

华为应用市场通过实施严格的安全检测机制，确保所有上架的应用都符合高标准的安全要求，从而有效保护用户的隐私和数据安全。

开发者完成HarmonyOS应用的功能开发后，最终将其上架至应用市场，以便广大用户能够便捷地下载并使用这些应用。
