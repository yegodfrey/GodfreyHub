# 稳定性体验测试

应用稳定性，指应用在持续操作时间内出错的概率。稳定运行的应用长时间运行故障率低、内存资源无异常，分布式协同业务操作无故障。

|领域|场景与分类|测试要点说明|应用形态|
|:-------------|:----|:--------------|:------------------------|
|HarmonyOS稳定性约束|稳定性|应用运行稳定无闪退问题|HarmonyOS应用, HarmonyOS元服务|
|HarmonyOS稳定性约束|稳定性|应用运行稳定无卡死问题|HarmonyOS应用, HarmonyOS元服务|
|HarmonyOS稳定性约束|稳定性|应用运行无内存泄露异常|HarmonyOS应用, HarmonyOS元服务|
|HarmonyOS稳定性约束|稳定性|应用运行无文件句柄资源过载异常|HarmonyOS应用, HarmonyOS元服务|
|HarmonyOS稳定性约束|稳定性|应用运行无线程资源过载异常|HarmonyOS应用, HarmonyOS元服务|
