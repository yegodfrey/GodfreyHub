# 相机体验增强

在鸿蒙（HarmonyOS）应用开发中，多设备相机适配是确保相机应用在不同设备形态（如手机、折叠屏、平板等）上提供一致且良好用户体验的关键。适配工作主要涉及布局适配、相机设备选择、预览画面比例设置、拍照旋转角度处理以及悬停态支持等方面。  

#### 5.3.1 相机可用性适配

折叠设备在不同折叠状态下，可用的相机镜头可能发生变化。例如，Pura X设备，在折叠态时无后置相机，再如笔记本电脑设备无后置相机。因此开发者需要通过CameraManager.getSupportedCameras()接口获取当前折叠状态下支持的所有镜头，然后根据相机位置（如前置、后置）选择可用的相机。对于PC设备而言，用户可能外接其他拍摄设备，此时可通过接口返回的ConnectionType字段进行判断。

当设备相机的可用状态发生变化，如外置相机的插拔、相机抢占等情况下，开发者可使用CameraManager.on('cameraStatus')进行监听。但是在设备折叠状态切换时，设备相机的可用性并没有发生改变，因此需要开发者监听CameraManager.on('foldStatusChange')重新选择相机并重置预览画面，以确保使用正确的镜头。  

#### 5.3.2 设置多设备上相机预览画面比例

相机预览画面需要适配不同设备的屏幕比例，避免出现拉伸、压缩或异常旋转。通常，将XComponent组件的宽高设置为100%，然后通过设置其对应Surface区域的宽高来控制预览画面大小。在折叠屏悬停态等特殊状态下，可能需要调整预览区域以避开折痕区域。  

#### 5.3.3 特有能力支持适配

不同设备相机模块所支持的能力可能各不相同，如调焦、防抖、微距、广角等，若应用希望对相机模组调用进行精细化配置，则需要在调用对应能力前先判断当前设备是否支持。鸿蒙系统提供了较为完善的能力支持判断，详见@ohos.multimedia.camera 相机管理。

较为常见的即为闪光灯的调用，开发者在进行闪光灯设置前，应使用hasFlash()方法检查设备是否支持闪光灯，然后使用isFlashModeSupported()方法检查设备是否支持指定模式的闪光灯。
