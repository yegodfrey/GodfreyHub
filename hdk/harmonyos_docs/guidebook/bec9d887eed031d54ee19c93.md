# 单元测试框架

HarmonyOS应用开发提供了功能完善的单元测试框架，支持开发者编写和执行单元测试用例。该测试框架同时支持Instrument Test和Local Test两种测试模式。

* Instrument Test用于在真机或模拟器上运行的测试，能够测试应用与系统API的交互

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/siROHeTmRl-acleuzwRGfQ/zh-cn_image_0000002625362103.png?HW-CC-KV=V1&HW-CC-Date=20260909T174529Z&HW-CC-Expire=31536000000&HW-CC-Sign=773BBBE46323BA545A13C8AEDCF61F2C37B14F7CF75C40776144FDB76511810E "点击放大")

* Local Test 用于本地快速执行测试，无需连接设备。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/-5yN7985S8i9WHc855gVkw/zh-cn_image_0000002594762598.png?HW-CC-KV=V1&HW-CC-Date=20260909T174529Z&HW-CC-Expire=31536000000&HW-CC-Sign=50EE34BA44C4509786A17C6EF53B478049682C8FB27E3985A94230EB05245D69 "点击放大")

测试框架提供了丰富的断言库，支持同步和异步测试用例的编写，开发者可以对函数返回值、对象状态、异常抛出等进行验证。测试框架集成在DevEco Studio中，开发者可以直接在IDE中创建测试用例、运行测试并查看测试结果。

同时，测试框架支持生成黑盒覆盖率测试报告，开发者不需要开发测试用例，将编译插桩的HAP包推到设备上，然后对该应用/元服务模拟用户操作，测试完成后可生成覆盖率报告。
