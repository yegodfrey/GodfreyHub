# 单元测试框架

HarmonyOS应用开发提供了功能完善的单元测试框架，支持开发者编写和执行单元测试用例。该测试框架同时支持Instrument Test和Local Test两种测试模式。

* Instrument Test用于在真机或模拟器上运行的测试，能够测试应用与系统API的交互

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/l9V7a7WjSD2uI2p7MrBuWg/zh-cn_image_0000002625362103.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=0AE3FD5BF8645155A3FB3049CF02E157918ECE9E0BEC4FBE7397E4B1D191C054 "点击放大")

* Local Test 用于本地快速执行测试，无需连接设备。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/IL2gGUnfRoqyfOxa7QZJ7A/zh-cn_image_0000002594762598.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=2A7D8CD255BE75B4F10AD95205817035217942151E8DB930F01273A9BF6C071F "点击放大")

测试框架提供了丰富的断言库，支持同步和异步测试用例的编写，开发者可以对函数返回值、对象状态、异常抛出等进行验证。测试框架集成在DevEco Studio中，开发者可以直接在IDE中创建测试用例、运行测试并查看测试结果。

同时，测试框架支持生成黑盒覆盖率测试报告，开发者不需要开发测试用例，将编译插桩的HAP包推到设备上，然后对该应用/元服务模拟用户操作，测试完成后可生成覆盖率报告。
