# 单元测试框架

HarmonyOS应用开发提供了功能完善的单元测试框架，支持开发者编写和执行单元测试用例。该测试框架同时支持Instrument Test和Local Test两种测试模式。

* Instrument Test用于在真机或模拟器上运行的测试，能够测试应用与系统API的交互

![](https://media:801788430185159355 "点击放大")

* Local Test 用于本地快速执行测试，无需连接设备。

![](https://media:801788430185185356 "点击放大")

测试框架提供了丰富的断言库，支持同步和异步测试用例的编写，开发者可以对函数返回值、对象状态、异常抛出等进行验证。测试框架集成在DevEco Studio中，开发者可以直接在IDE中创建测试用例、运行测试并查看测试结果。

同时，测试框架支持生成黑盒覆盖率测试报告，开发者不需要开发测试用例，将编译插桩的HAP包推到设备上，然后对该应用/元服务模拟用户操作，测试完成后可生成覆盖率报告。
