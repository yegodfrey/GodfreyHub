# DevEco Code

DevEco Code定义为鸿蒙应用开发的开箱即用AI Coding工具，默认包含鸿蒙专属的软件工程能力，涵盖需求、设计、开发、验证四个阶段。支持开发者定制专属的开发流程，并支持按照标准协议接入扩展能力。其核心的设计理念遵循开箱即用、开放原则。

![](https://media:801788430180460283)

* 开箱即用：默认提供给开发者三种模式，Goal、Build 、Plan三种方式。
  * Build模式：根据开发者需求自动执行编码、检查、构建、打包、模拟器运行、意图校验、问题修复等的全流程，可直接生成代码以及部署鸿蒙应用包。
  * Plan模式：根据开发者需求进行任务的分解和分配，并与开发者进行交互，完善任务。
  * Goal模式：严格的鸿蒙应用开发范式，先文档、后代码。规格为第一要素，保证代码质量稳定。根据开发者需求进行需求分解、系统设计以及任务规划，按照任务规划完成应用开发。
* 开放原则：代码开源，DevEco Code支持按照标准协议接入扩展能力，例如Skill、MCP、Agent定制、Subagent定制。

DevEco Code默认集成官方Skill能力，为鸿蒙应用开发带来便利性：

* 确定性提升，模型无关性：将高频的开发操作（如配置编译、签名、部署测试）固化为精确的指令集，不依赖特定模型版本，任务成功率可大幅提升。
* Token消耗锐减，效率倍增：AI Agent无需在提示词或历史对话中反复加载冗长、可能出错的配置步骤，直接调用Skill和知识库，可使任务完成速度提升3倍以上，Token消耗降低70%以上。
* 保持"当下最佳实践"：知识库会随IDE版本实时更新，保证AI Agent始终遵循最新的技术规范，避免生成充满"技术债"的过时代码。
* 弥合通用知识与平台特性的鸿沟：对于鸿蒙应用的多设备开发、原子化服务等核心场景，通用大模型难以理解，官方Skill和知识库能有效弥补这一差距。
* 构建"知识资产"：Skill库沉淀了团队的鸿蒙开发经验与Know-How，将个人能力转化为组织资产，是未来团队的核心竞争力来源。

DevEco Code深度集成 DevEco CLI 全量能力，结合鸿蒙原生应用开发特性做全链路深度优化，全方位打磨流畅高效的开发体验，倾力打造适配鸿蒙生态、贴合开发者需求的极致 Agentic智能开发工具：

* Terminal/Desktop：用户交互界面，负责接收Prompt指令，并把它们统一编码为DevEco Code系统能理解的请求格式；
* 鸿蒙领域软件工程能力：专为鸿蒙应用开发场景设计的标准化智能体能力体系。它通过对鸿蒙领域的专用智能体、系统提示词、工具与技能等原子化能力进行系统性整合、调优与封装，形成开箱即用、持续进化的领域专属解决方案，显著提升在鸿蒙生态中的开发效率与任务成功率。
  * 鸿蒙Agent调度引擎：负责接收任务、实现任务分解与分配、多Agent协作、上下文管理和能力路由的协同运行，管理其执行全过程，最终驱动完成高质量的自动化交付。
  * 鸿蒙Agent：构建的鸿蒙专属智能体，集成了Goal、Build、Plan三大核心能力，实现全流程自动化开发。
  * 鸿蒙场景Skill/Tool/Plugin：鸿蒙场景专属Skills、Tools、Plugins。
* Agent基础设施：集成Agent核心框架、鉴权、代码库和记忆管理的服务化架构。
* 云端服务：提供鸿蒙中控、MCP/Skill/二进制包市场、大模型服务和升级服务的云端资源调度。
