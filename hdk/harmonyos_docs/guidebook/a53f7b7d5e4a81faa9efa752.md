# 核心测试能力概述

#### 单元测试能力

定义与范畴：作为白盒/灰盒测试的基础环节，旨在应用开发初期对函数、类、模块及接口进行独立验证，确保代码逻辑实现的准确性与边界条件的鲁棒性。

工具能力：推荐集成 DevEco Studio 单元测试框架，支持在 IDE 环境内高效完成测试用例的编写、调试与执行，实现开发过程中的即时质量反馈。  

#### 功能场景测试能力

定义与范畴：在应用功能模块开发完成后，基于业务逻辑设计覆盖全场景的测试用例，验证功能实现的完整性与正确性。

工具能力：推荐使用 Hypium 自动化测试框架。该框架专为HarmonyOS生态打造，支持构建高可维护、高执行效率的自动化测试脚本，显著提升回归测试的覆盖率与执行速度。  

#### 体验专项测试

定义与范畴：在功能稳定基础上，开展多维度的深度体验评估。涵盖关键指标包括：

* 性能体验：操作流畅度、长时间运行稳定性、功耗续航表现。
* 安全合规：应用安全机制及用户隐私保护合规性。
* 兼容适配：跨操作系统版本、不同硬件设备（分辨率、内存等）的兼容性适配。

工具能力：DevEco Testing、云测试与App Test中均提供了体验专项测试能力，推荐在相应的测试环节使用提供的工具开展体验专项测试。  

#### 线上众测

定义与范畴：在应用正式发布前，引入灰度发布机制，面向特定范围的真实用户群体进行试点部署。

工具能力：App Test提供面向特定范围用户群体邀请测试，验证应用在实际使用场景下的质量表现与用户体验，提前发现实验室环境难以复现的潜在问题。  

#### 线上运维

定义与范畴：应用正式发布后，建立线上运维体系，实时采集关键性能指标（KPI）与稳定性数据。

工具能力：APMS提供现网运维数据，支持精准定位运行时的性能瓶颈与崩溃异常，形成"识别 - 分析 - 修复 - 验证"的闭环反馈机制，持续保障应用现网质量。
