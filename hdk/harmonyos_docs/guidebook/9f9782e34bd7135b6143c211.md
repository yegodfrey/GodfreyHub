# 功耗体验测试

应用的功耗和用户使用设备整机的续航体验强相关，为构筑用户良好续航体验，对后台任务使用，后台资源占用有以下建议和要求。

|领域|场景与分类|测试要点说明|应用形态|
|:-|:-----|:----------------------|:------------------------|
|功耗|后台资源占用|应用应后台长时任务使用合理|HarmonyOS应用, HarmonyOS元服务|
|功耗|后台资源占用|后台进程CPU负载约束（长时任务）|HarmonyOS应用, HarmonyOS元服务|
|功耗|后台资源占用|后台进程CPU负载约束（短时任务）|HarmonyOS应用|
|功耗|后台资源占用|应用退后台禁止使用传感器|HarmonyOS应用, HarmonyOS元服务|
|功耗|后台资源占用|后台合理使用音频播放|HarmonyOS应用, HarmonyOS元服务|
|功耗|后台资源占用|无长时任务的应用退后台对应资源释放，不能有持锁|HarmonyOS应用, HarmonyOS元服务|
|功耗|前台|应用处于前台不可见动效不使用资源，及时停止|HarmonyOS应用, HarmonyOS元服务|
|功耗|前台|视频播放场景使用硬件编解码器|HarmonyOS应用, HarmonyOS元服务|
|功耗|前台|视频弹幕场景走硬件加速|HarmonyOS应用, HarmonyOS元服务|
|功耗|前台|音乐类应用设置正确的音乐类型|HarmonyOS应用, HarmonyOS元服务|
|功耗|前台|导航类要设置正确的应用类型|HarmonyOS应用, HarmonyOS元服务|
