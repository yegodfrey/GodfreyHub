# 分阶段发布

在当前上架更新版本为全网发布时，开发者可以先向一定比例的用户发布更新的版本，然后再逐步提升用户比例，最终实现全网发布，过程无需人工次次操作。比如：

|-------|---|---|---|---|---|---|----|
|阶段性发布天数|第1天|第2天|第3天|第4天|第5天|第6天|第7天|
|推送更新百分比|1%|2%|5%|10%|20%|50%|100%|

* 发布过程中所有用户主动下载均为新版本，旧版本用户也可以通过应用市场搜索下载新版本。
* 发布过程中，可以结合用户舆情（是否存在冷门边缘场景的功能失效等）和应用稳定性检测（应用的闪退，白屏率等），对该版本做实时风险评估，并可以进行加速更新版本分阶段发布、暂停更新版本分阶段发布、更新版本立即全网、下架分阶段的更新版本等操作。

通过应用分阶段发布的能力，可以降低全网发布后版本更新出现问题的风险。
