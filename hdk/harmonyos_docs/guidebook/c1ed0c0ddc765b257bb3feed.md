# 线上运维

应用质量管理服务（Application Performance Management Service，简称APMS）是面向HarmonyOS应用开发者提供的智能化运维平台，构建了涵盖"故障指标、故障告警、故障分析、质量报告"的全链路质量保障体系。平台提供可视化多维指标大盘，实时聚合稳定性、性能、功耗等关键运行指标，实现对应用健康状态的全局洞察。支持对关键指标设置告警规则，提供短信、邮件、Webhook等多种通知方式，帮助开发者在应用上线后能够及时感知并响应故障。基于运维大数据，将应用故障发生时上报的事件与日志快速聚类分析，帮助开发者高效故障定界及定位。此外，支持应用质量报告分析，将应用的现网运行质量情况提供详细的多维度分析报表，给出应用质量和用户体验提升建议，帮助持续提升应用质量。

* 故障指标：为开发者提供应用在稳定性、性能、功耗等多种DFX场景下的现网运行指标，帮助开发者整体掌握应用实时的运行质量现状。支持多维度下钻分析，包括系统版本、设备型号、应用版本等维度，满足开发者多方面的详细指标查看。同时，针对新版本发布场景，支持与历史版本对比，帮助开发者从宏观上识别新版本问题，从而科学评估新版本的运行质量。
* 故障告警：为开发者提供针对应用运行质量的检测告警能力，帮助开发者提前快速发现问题，减少现网风险。支持自定义告警能力，支持灵活配置告警策略，实现对特定版本、特定指标类型等多维条件的精准告警。当指标达到预设阈值时，系统将自动触发告警，并通过开发者指定的渠道（邮件、短信、Webhook回调）实时推送告警信息。
* 故障分析：为开发者提供了故障场景的初步分析能力（支持CPP Crash、JS Error、应用冻屏、资源泄露等常见的故障），帮助开发者能快速定位问题根因，从而尽快修复问题。支持按故障类型快速检索当前应用的Top问题及其分布情况，并提供详尽的故障诊断信息，涵盖日志堆栈、采样栈、内存快照及问题分析证据链。支持符号表上传用来还原原始堆栈信息，通过应用灰度解决复杂场景下日志缺失无法分析故障的痛点。针对崩溃及应用冻屏类故障，系统集成大模型AI诊断能力，实现对故障的智能定界及定位分析。
* 质量报告：为开发者提供应用在指定周期内的质量分析报告，帮助开发者全面分析应用运行质量，为应用的质量提升提供丰富参考信息。应用质量报告基于真实用户环境下应用运行数据的采集、分析、聚合与可视化输出，形成综合质量评估报告。提供行业对标能力，帮助开发者客观评估应用在行业内的质量定位；同时通过分析Top问题分布，结合HarmonyOS应用知识库，输出针对性的优化改进建议，为开发者提供明确的改进方向与实施路径。
