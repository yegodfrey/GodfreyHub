# DevEco CLI

DevEco CLI定位于统一集成DevEco Studio开发工具链、鸿蒙知识库、鸿蒙Skills的AI友好的CLI工具，是**面向鸿蒙"1+8+N"全场景生态及AI Agent的原子化能力调度枢纽** 。它不仅是命令行工具，更是**AI Agent与鸿蒙"1+8+N"全场景分布式生态之间的桥梁。**

**DevEco CLI的核心设计理念遵循以下原则：**

* 原子能力服务化：将鸿蒙的"原子化服务"理念延伸至开发工具链。基于鸿蒙"原子化服务"（Atomic Service）思想，每一个工具能力（如编译、模拟器管理、日志抓取等）都应被封装为独立、可组合、可复用的原子能力（Ability）。DevEco CLI本身应以原子化、组件化的方式构建，将编译、调试、模拟器管理等开发能力封装为独立的"原子化工具服务"，内部各模块高度解耦。
* 全场景AI协同：在"一次开发，多端部署"的顶层设计下，让AI Agent能够统一管理和调度面向手机、平板、车机等多设备的代码生成、编译、部署与调试流程。CLI需内置设备感知与管理能力，让AI Agent能够理解并适配不同设备的差异。
* 知识原生集成：内置HarmonyOS官方知识库与Skills，AI Agent可通过命令harmonyos knowledge "ArkUI组件生命周期"直接查询官方API文档和最佳实践，彻底解决通用大模型训练数据陈旧、不了解鸿蒙最新规范（如ArkUI、ArkTS）的问题，确保AI生成的代码从第一行起就遵循鸿蒙官方规范。
* 环境零配置化：摒弃繁琐的环境变量和路径配置，针对鸿蒙特有的包管理工具（ohpm）和构建工具（hvigor）提供自动检测与按需下载功能，显著减少Token浪费与重复配置操作。
* 双向可演进性：让人类开发者和AI Agent都能用。它需要提供人类可读的优雅输出和AI Agent专用的结构化（如JSON）数据流，同时支持脚本化自动化，兼容传统IDE开发和Agent驱动开发两种范式。

**DevEco CLI 通过拆解、改造DevEco Studio，为Agent的编译构建验证调优提供端到端的原子化能力：**

* create（项目创建）：可基于官方模板快速生成项目，自动集成鸿蒙推荐的工程结构。
* build （编译构建）：驱动hvigor构建系统，支持hap、hsp、har等多目标产物，支持处理HAP打包、代码签名等任务。
* device / emulator（设备与模拟器管理）：统一管理真机与虚拟设备，支持模拟器的生命周期管理。
* run（运行部署）：自动完成安装、权限配置并启动应用，支持处理HSP依赖。
* log / debug（调试与诊断）：集成hilog进行日志抓取、过滤及崩溃/性能监控。
* 语法检查：支持ArkTS、C++语法实时检查，Agent在不编译构建情况下发现语法错误，快速修复，效率提升5倍以上。
