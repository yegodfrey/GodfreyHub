# 鸿蒙AI辅助研发工具的核心挑战

在鸿蒙AI辅助开发工具的构建过程中，当前面临多维度、系统性的挑战，需分层拆解。从整体生态看，语言语料、意图理解以及开发工具基础设施（如LSP等）三个层面共同构成了技术难点。其中，语言语料缺乏的问题尤其突出：鸿蒙ArkTS作为新兴端侧应用开发语言，目前训练语料储备较少，业界主流大模型对ArkTS代码的适配与生成能力普遍偏弱。尽管ArkTS语法体系与TypeScript高度相近，但其公开可用的语料体量尚不足TypeScript的百分之一，这就导致大模型在代码生成时，极易默认沿用TypeScript语法逻辑输出内容。而TypeScript中大量与ArkTS规范不兼容的语法特性，也由此成为鸿蒙AI Coding场景下，ArkTS 开发出现语法错误的核心诱因。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/0vmhPrAaQYKNZ26zFGa-eQ/zh-cn_image_0000002686648673.png?HW-CC-KV=V1&HW-CC-Date=20260909T173407Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D8056334D85E8EB4CEFCEB5EF9B70CAD67EE072C4AA14F59AC371605B473A11)

短期内无法完成ArkTS语料库2至3倍数量级的快速扩容，通过工程化路径优化代码生成精度，已然势在必行。

经调研广大鸿蒙生态开发者的实际体验后，汇总AI辅助应用开发过程中的三类突出痛点：

1）代码生成环节问题较多，尤以语法错误最为突出，致使项目无法正常构建，需多轮人机协同修改，且部分缺陷无法通过AI自主修复；

2）构建完成并部署至终端设备或模拟器后，频繁出现界面展示错乱、交互逻辑异常等缺陷，人工测试核验重复性强、耗时久；

3）测试问题的整改依赖开发者手动输入自然语言指令引导AI修复，持续陷入编码改错、编译打包、真机测试的低效迭代流程。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/Es0PLJfLR4Ke99_xAF-W8A/zh-cn_image_0000002656609194.png?HW-CC-KV=V1&HW-CC-Date=20260909T173407Z&HW-CC-Expire=31536000000&HW-CC-Sign=EA2B75B51C722D77FDFF9E0BE7DB7A7D5FD64483CD75E7DFB66430617CE8F2C4)

鸿蒙应用特性开发与缺陷修复阶段，AI 可有效提升代码编写速率，但多轮纠错调试、人工测试验证、二次修复等流程存在效率阻滞，致使端到端开发效率提升遇阻，开发者普遍反映实际增效效果并不明显。

实现应用落地、完成功能特性迭代，是开发者核心开发目标。开发者初衷本是借助AI提升开发效率，可当前在通用 AI辅助工具上的开发流程存在断点，反而拉长整体开发周期。即便最终能够完成功能开发，整体开发体验也大打折扣。

站在全流程开发视角来看，理想开发模式应实现开发旅程的自动化闭环：开发者提交开发需求与验收规格后，AI自动完成代码生成，联动语法校验工具智能排查并修复语法问题；无误代码可自动编译构建 HAP 安装包，同步推送至模拟器完成部署，自动开展功能校验与兼容性测试；一旦检测出异常问题，即刻反向回流至代码生成与修改环节，启动迭代优化。

经过多轮自动化自验证与迭代修正，直至精准达成特性的开发目标。该模式既能大幅提升代码生成正确率，又能最大限度减少人工干预，显著压缩开发耗时，全面优化开发者使用体验。

基于此，我们提出了鸿蒙AI辅助工具的核心应用场景：**鸿蒙应用全流程 Agentic 智能开发模式**。开发者仅需明确业务需求，即可交由AI自主闭环完成代码编写、语法纠错、模拟器/真机自验证、问题整改等全链路工作，直至需求开发完成。最终由开发者确认验收。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/fuulR8x1TZyaQ3pNG7ayoA/zh-cn_image_0000002656449258.png?HW-CC-KV=V1&HW-CC-Date=20260909T173407Z&HW-CC-Expire=31536000000&HW-CC-Sign=12FBB5EFEC37D76FA2CBBCA368F5FD6EACC738D5BEDF17063D6E2C001C44058E)

而这套全流程 Agentic 开发作业链路，可通过两大环节系统性解决代码生成准确率偏低的痛点。

① 现有通用AI工具易生成TypeScript风格代码，与ArkTS语法规范不匹配，直接导致代码编译失败。对此可基于ArkTS LSP工具的语法校验能力，助力AI快速精准识别语法问题、输出明确错误提示，实现问题高效整改，保障应用顺利完成编译构建。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/pF8sk3quQ8iZt4X0D7fzig/zh-cn_image_0000002686528865.png?HW-CC-KV=V1&HW-CC-Date=20260909T173407Z&HW-CC-Expire=31536000000&HW-CC-Sign=165F0CFBE3ACADB176E013B9EA5C3BBCDEDFAD96884DA13C052FEB83BC64BC27)

② 编译生成的 HAP 安装包，在模拟器或真机环境运行时，可能出现应用闪退、UI界面展示错乱、交互逻辑异常等运行时问题。对此可搭建适配真机与模拟器的 UI意图校验能力，通过多模态大模型的自验证Agent自主完成UI界面视觉核验与交互逻辑的智能化验证。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/r3NdU1_RQRieV5wTDfSnRw/zh-cn_image_0000002686648675.png?HW-CC-KV=V1&HW-CC-Date=20260909T173407Z&HW-CC-Expire=31536000000&HW-CC-Sign=5AF198EA81653FFEE4306441B613C17F05F40B58C45F1CC3606FAA2CAA41458A)

至此，鸿蒙AI辅助工具达成**端到端自主开发** 与**代码生成精准度优化**两大核心目标。鸿蒙生态应用开发者可率先体验全新开发模式，用户仅需提出业务需求，由AI全权完成全流程开发工作，最终由用户验收成果，大幅提升开发体验与研发效率。
