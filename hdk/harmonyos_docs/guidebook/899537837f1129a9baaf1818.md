# 鸿蒙AI辅助研发工具的设计理念

鸿蒙生态开发者主要分为两类使用场景：

第一类开发者习惯使用Trae、OpenCode等各类AI辅助开发工具来生成鸿蒙ArkTS代码，后续需自行排查并修复代码中存在的语法与功能问题。这类开发者希望获取鸿蒙开发专属原子能力，包括鸿蒙IDE工具、鸿蒙专业知识库、鸿蒙开发Skills等，将其接入自有AI辅助开发工具，支持AI工具完成代码生成、问题检查、缺陷修复、效果校验、自动化测试等开发工作。

第二类开发者更倾向使用一站式的鸿蒙AI开发工具来提升研发效率，不愿耗费精力配置开发工具环境。他们迫切需要一款开箱即用的一体化鸿蒙AI辅助开发工具，融合行业主流AI Coding技术优势，可在鸿蒙应用开发场景下，稳定、高效、轻量化地产出贴合实际业务诉求的应用代码，降低开发上手门槛。

结合两类开发者的实际需求、梳理AI Coding技术演进脉络，不难发现：AI 开发工具与研发运行环境始终保持协同迭代、同步发展。

AI Coding早期以Copilot代码补全为主要形态，开发者依托DevEco Studio开展开发工作，仅借助AI实现单行或小段代码实时联想补全，单次生成代码普遍不足十行。该阶段AI参与度极低，项目整体架构、业务框架均由开发者自主设计搭建；代码错误依靠开发工具主动检测，代码调整完成后需手动执行编译打包，再部署至模拟器完成自测，全流程以人工操作为核心。

Vibe Coding模式普及，开发模式迎来全面革新。开发者可通过自然语言与AI开展多轮交互，灵活引导AI完成代码生成与迭代优化，依托编译结果定位各类语法问题后，继续以自然语言指令驱动AI完成代码整改。与此同时，开发环境也迎来升级变革，业界开始通过MCP协议将语法校验、编译构建等开发工具的底层能力无缝接入AI工具，实现错误自查、自动编译、智能修复的一体化运行。开发流程自动化程度大幅提升，研发整体效率也随之显著增长。

迈入 Agentic 智能开发新时代，AI Coding向着全流程工程化自主交付演进，对调用鸿蒙专业知识库、联动各类开发工具的需求愈发迫切，开发者也愈发呼吁以 AI友好的方式开放鸿蒙标准化开发原子能力。

针对市场的两大核心诉求，我们顺势推出两款定位清晰、互为协同的独立产品：

**DevEco CLI：**定位为AI友好型开发命令行基座，统一整合鸿蒙开发工具链、鸿蒙专属知识库与鸿蒙精品Skills。面向各类AI Agent使用的AI产品，将鸿蒙开发能力封装为适配AI调用的标准化接口，既可供给DevEco Code集成，也可全面开放给各类通用AI开发工具集成使用。

**DevEco Code：**鸿蒙应用AI 辅助开发工具，融合鸿蒙领域软件工程能力，深度集成 DevEco CLI 全量能力，结合鸿蒙原生应用开发特性做全链路深度优化，全方位打磨流畅高效的开发体验，倾力打造适配鸿蒙生态、贴合开发者需求的极致 Agentic 智能开发工具。

我们将以AI产品的理念来打磨DevEco Code和DevEco CLI。DevEco Code深耕AI辅助鸿蒙应用开发领域，沉淀行业最佳实践。工具持续强化鸿蒙原生应用开发、AI代码转译生成鸿蒙应用、元服务开发、一多适配等核心特色能力，是覆盖鸿蒙应用需求、开发、测试、运维全生命周期的一站式AI开发利器。而DevEco CLI作为AI Agent 调度调用鸿蒙开放能力的命令行统一入口，全面聚合IDE各类原子化开发能力和鸿蒙知识库，是适配Agentic开发时代、专为AI 交互场景打造的轻量化友好型鸿蒙应用开发基座。
