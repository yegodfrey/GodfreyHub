# 上架配置

一个应用如果是使用一多的方式进行开发，那么上架前需要配置应用支持的设备类型。

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择一个待上架应用，在"应用信息"界面选择应用支持的设备。如果应用支持智慧屏，还需要选择支持哪些智慧屏的操作设备。
