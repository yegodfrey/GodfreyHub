# 性能体验测试

应用应提供用户期望的响应速度和流畅性，包括应用冷启动、应用内操作、资源占用等要求。性能指标详见[应用性能体验建议](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/performance-experience-suggestions)

|性能|时延|在线长视频类应用播放起播快|HarmonyOS应用|
|性能|时延|在线长视频类应用Seek操作播放快|HarmonyOS应用|
