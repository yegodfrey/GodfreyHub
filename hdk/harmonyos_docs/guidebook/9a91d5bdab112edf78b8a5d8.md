# 上架预检

应用上架预检服务：基于应用上架质量标准构建的本地自检服务，提供兼容性、功耗、性能、UX、稳定性五大基础体验检测能力，通过自主遍历引擎模拟用户操作进行应用页面遍历，测试结果通过专业化测试报告呈现。

* 自定义预检模式：根据具体诉求自由选择专项组合，并且支持自定义遍历时长。
* 综合预检模式：五大专项全量测试，遍历时长使用默认推荐值。

![](https://media:801788430184161340 "点击放大")

* 应用包：建议开发者采用调试证书签名的Release包，启动测试前安装到待测设备，并完成应用账号登陆与数据预置操作，使得应用页面覆盖更加充分。
