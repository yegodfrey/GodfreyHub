# 故障告警

故障告警给开发者提供了一种被动巡查的机制，当现网某些指标发生异常时，可以通过多种媒介通知到开发者。如下图（短信告警通知）：

![](https://media:801788430186272369 "点击放大")

故障告警总览视图：开发者在收到告警信息（短信、邮件等）后，可以通过这个视图，查看并处理一定周期内的所有告警信息。

![](https://media:801788430186320370 "点击放大")

开发者根据应用的需求，可以自定义告警，支持不同故障场景、应用版本，不同触发的规则，满足定制化的需要。

![](https://media:801788430186383371 "点击放大")
