# 故障告警

故障告警给开发者提供了一种被动巡查的机制，当现网某些指标发生异常时，可以通过多种媒介通知到开发者。如下图（短信告警通知）：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/-VByfw56QK-9SjCx8AhLFw/zh-cn_image_0000002625281985.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=22051974256DE043E2C56CE86C9C35AAF3DD84E393B82C6AE01C71B7B4979661 "点击放大")

**故障告警总览视图：**开发者在收到告警信息（短信、邮件等）后，可以通过这个视图，查看并处理一定周期内的所有告警信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ef/v3/TXjsT6IMTz-pMiHo-C2mhg/zh-cn_image_0000002625362123.png?HW-CC-KV=V1&HW-CC-Date=20261009T073131Z&HW-CC-Expire=31536000000&HW-CC-Sign=47AB945E6857B7B21CF8DA699626A120F6F57C69EE5991CD46280A00358EE551 "点击放大")

开发者根据应用的需求，可以自定义告警，支持不同故障场景、应用版本，不同触发的规则，满足定制化的需要。
