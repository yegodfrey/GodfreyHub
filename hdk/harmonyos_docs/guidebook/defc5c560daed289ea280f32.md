# 故障告警

故障告警给开发者提供了一种被动巡查的机制，当现网某些指标发生异常时，可以通过多种媒介通知到开发者。如下图（短信告警通知）：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/sW6FovZPQ86fDDu6mqg8KA/zh-cn_image_0000002625281985.png?HW-CC-KV=V1&HW-CC-Date=20260909T135930Z&HW-CC-Expire=31536000000&HW-CC-Sign=F94C9D92EBE440554773CCF7CAA52B83831FB867FC97884673EC4E692CE63687 "点击放大")

**故障告警总览视图：**开发者在收到告警信息（短信、邮件等）后，可以通过这个视图，查看并处理一定周期内的所有告警信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/pcd-l2RlSdCAL5OMTQDm2A/zh-cn_image_0000002625362123.png?HW-CC-KV=V1&HW-CC-Date=20260909T135930Z&HW-CC-Expire=31536000000&HW-CC-Sign=41C79C1AE331E27C9446AA135C1EAC9C62C7A321E5A6D5EBE8BBA1A58B1DE119 "点击放大")

开发者根据应用的需求，可以自定义告警，支持不同故障场景、应用版本，不同触发的规则，满足定制化的需要。
