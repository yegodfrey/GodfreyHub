# 体验专项测试（云端）

功能场景测试和本地体验专项测试，测试过程都需依赖本地真机设备，但是实际测试时开发者可能会面临本地机型不足、特定机型和版本问题无法复现等问题。为了解决这些痛点，HarmonyOS生态提供了云侧体验专项测试服务。开发者可以通过AGC网站接入云侧体验专项测试服务，选择需要测试的机型设备，快速进行测试或者定位复现问题，提升HarmonyOS应用在不同设备和系统环境下的稳定性和可靠性。

根据使用场景不同，云侧体验专项测试支持2种测试能力，分别是云测试和云调试。

* 云测试：集成体验专项质量检测项标准，开发者通过云测试可以提前发现兼容性、稳定性、性能、功耗、UX等体验问题，检测结果与上架检测互信，提高上架成功率。
* 云调试：提供丰富的远程真机资源，支持在线进行问题定位和复现，还支持一帧多屏的多设备兼容性测试，帮助开发者快速完成HarmonyOS应用功能调试及问题定位，降低设备采购和管理成本。
