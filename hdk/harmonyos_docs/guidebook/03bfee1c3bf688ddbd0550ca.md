# 高效办公体验提升

会议悬停：利用系统的悬停组件能力，结合折叠屏特有形态，用户可以将设备稳定悬停于桌面，参会者双手可完全解放，专注记录会议要点，无需分心持握或调整设备；这使得设备成为咖啡厅、高铁、办公桌等小空间中的会议神器。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/6A24PFIMSsyNKfVYw3yTqA/zh-cn_image_0000002594673068.png?HW-CC-KV=V1&HW-CC-Date=20261009T073130Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E6AD4361A3E3867A44D2F61BD8CBFFDE507FAF96D3B5A3FA1360897A8DEE5CE "点击放大")

多任务：利用系统的多实例能力，同时运行聊天、在线文档和视频会议等多个任务，彼此独立、互不打扰------在屏幕左侧参与部门群的紧急讨论，右侧同步编辑项目排期表，此时如果需要临时发起一个审批，新建的审批页面会自动将之前的文档暂存至侧边"最近使用"区，整个过程无需退出或重新加载，实现了真正的"任务连续、思维不中断"。

分栏布局：凭借鸿蒙系统的Navigation分栏能力，鸿蒙多设备大屏优势为移动办公带来高效体验。在折叠屏办公时打破手机单屏操作的局限，充分利用折叠屏展开后的大屏尺寸，信息密度与操作效率兼得，让移动办公效率迈上新台阶。同一应用三分栏布局，导航、列表与详情同屏显示，无需页面跳转，信息获取更高效；

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/echawEsHR2W3RqNVjAAQHw/zh-cn_image_0000002625112583.png?HW-CC-KV=V1&HW-CC-Date=20261009T073130Z&HW-CC-Expire=31536000000&HW-CC-Sign=E57E3DAD7C6698D5B94DD17B0D340B315B6E8445360AAB852E294807EA7B12C8 "点击放大")

窗口级投屏：使用系统的窗口能力，实现窗口级投屏。在分享材料过程中，如遇到接听来电或者信息回复的场景，观看端不会看到投屏端上的其他操作，保障会议讲稿不中断的无干扰体验，既安全隐私又保证了会议的高效专业。
