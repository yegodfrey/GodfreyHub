# 上架审核

华为应用市场审核应用时，会从以下多个维度确保应用的安全性、合规性及用户体验：

1. 合规性与法律要求：应用资质、内容合规、用户隐私、版权和知识产权、游戏版号、未成年设计等。

2. 应用安全：禁止存在恶意行为、过度索取数据/权限等行为。

3. 功能与性能：应用需稳定运行，无频繁崩溃、卡顿或功能缺陷，无异常耗电、内存泄漏、启动时间过长或过度占用资源。

4. 用户体验：界面设计无误导性按钮或诱导，不得包含非法、误导性内容，内容质量高。
