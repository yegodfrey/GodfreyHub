# HarmonyOS通用特性测试

|场景与分类|特性能力说明|
|:-----|:----------------------------------------------------------------------------------------------------|
|全球化|HarmonyOS系统支持多语言，确保多语言字串翻译准确，满足国内外用户语言和文化习惯正确性和地道性，使人们交流中遵循自己的语言文化表达，或者信息展示时符合区域的规范。|
|无障碍|HarmonyOS系统提供了无障碍解决方案，视力障碍、阅读困难或暂时无法阅读的人群可以开启屏幕朗读，屏幕朗读会对界面元素进行朗读，使其获取到屏幕信息。|
|适老化|关怀模式下，用户可以设置屏幕显示放得更大，并根据个人习惯调节屏幕触控时长，让用户看得更清楚，操控得更顺畅。|
|深色模式|深色主题满足更多个性化的需求，开启深色模式，浅色主题应用界面背景会变成深色，而文字、图标等前景会变成浅色。深色模式的界面内容更加突出、在OLED屏幕的设备更加省电、能够给用户带来视觉舒适感和沉浸式体验。|
|数据备份迁移|HarmonyOS系统提供了数据克隆工具，支撑应用数据在设备间进行数据迁移。应用可以实现数据从旧机克隆到新机，支持无线、有线、无线+有线双径传输方式，在高速完成数据传输同时，保障用户换机后一见如故。|
