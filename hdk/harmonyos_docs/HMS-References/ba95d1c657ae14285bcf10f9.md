public interface GameManager.GameCallback  
GameManager类内部定义的接口。设备通过该接口反馈设备信息，如温度信息等。  
  
## Public Method Summary

Return| Method  
---|---  
void| onPhoneInfoUpdated(String info)  
  
## Public Methods

Method  
---  
public void onPhoneInfoUpdated(String info)  
设备通过该回调接口获取设备信息，如温度信息等。该方法取得的设备信息与通过GameManager的getPhoneInfo()方法得到的设备信息格式一致。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
String info| 设备的信息。比如温度信息等。该值可能为null或empty。  
常见的原因是：应用未注册或注册失败；系统未上报设备信息。  
手机系统返回系统关键资源信息，包含当前温度等级等相关信息。  
json格式：  
{  
“MessageType”:20001,  
“TempCurLevel”:3  
}  
类型：int字段：MessageType 说明：必填。取值是20001，标识了是一个系统返回的关键资源信息。  
类型：byte字段：TempCurLevel说明：必填。标识温度当前等级1: 普通，2:中，3:高。
