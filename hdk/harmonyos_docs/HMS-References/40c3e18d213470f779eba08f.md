CLASS info  
---  
public class Message implements Parcelable  
nearby设备共享的消息类，消息包含客户端定制的内容和类型，MessagePicker.Builder用此类型可以限制应用程序接收订阅的消息类型。

## Public Constructor Summary

Constructor name  
---  
public Message(byte[] content)  
基于消息内容和default类型，创建一个新的消息。应用使用default类型与近场设备通信时，用此函数创建消息  
参数：  
content：消息内容，不大于MAX_CONTENT_SIZE  
  
public Message(byte[] content, String type)  
基于消息内容和给定的消息类型创建一个新的消息参数：  
content：消息内容，不大于MAX_CONTENT_SIZE  
type：消息类型，不大于MAX_TYPE_LENGTH
