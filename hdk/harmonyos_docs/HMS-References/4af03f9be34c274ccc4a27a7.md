车载蓝牙围栏，包括连接、未连接、状态驻留的围栏。

public static AwarenessBarrier keep(int deviceType, int bluetoothStatus)  
车载蓝牙状态驻留围栏，开发者添加连接或非连接两种状态的车载蓝牙状态驻留围栏后，当车载蓝牙状态保持为指定状态时，此围栏状态为TRUE并触发围栏事件上报。使用此围栏需添加android.permission.BLUETOOTH权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
deviceType| 车载蓝牙设备类型。  
0：标识车载蓝牙设备。  
bluetoothStatus| 车载蓝牙状态。  
CONNECTED：车载蓝牙已连接；  
DISCONNECTED：车载蓝牙未连接。  
  
**Return**

Type| desc  
---|---  
AwarenessBarrier| 情景感知围栏。  
  
**Throws**

Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（deviceType不是非负整数， bluetoothStatus不是CONNECTED或DISCONNECTED或UNKNOWN）异常。

public static AwarenessBarrier connecting(int deviceType)  
车载蓝牙连接围栏，添加此围栏后，当车载蓝牙连接设备时，此围栏状态为TRUE并触发围栏事件上报，5s后状态切换为FALSE。使用此围栏需添加android.permission.BLUETOOTH权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
deviceType| 车载蓝牙设备类型。  
0：标识车载蓝牙设备。  
  
**Return**

Type| desc  
---|---  
AwarenessBarrier| 情景感知围栏。  
  
**Throws**

Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（deviceType不是非负整数）异常。

public static AwarenessBarrier disconnecting(int deviceType)  
车载蓝牙断开连接围栏，添加此围栏后，当车载蓝牙断开连接时，此围栏状态为TRUE并触发围栏事件上报，5s后状态切换为FALSE。使用此围栏需添加android.permission.BLUETOOTH权限。  
  
**Parameters**

**Throws**

IllegalArgumentException| 参数不合法（deviceType不是非负整数）异常。
