public abstract class MessageEngine  
定义了一系列API，应用可以通过Put/Get实现消息在近场设备间的传输。API执行不需要绑定帐号，但需要开发者申请API_KEY。除非Get时使用PendingIntent参数，否则所有API都必须在应用前台时才能调用。put、get和onStart应该和unput、unget、onStop对称调用
