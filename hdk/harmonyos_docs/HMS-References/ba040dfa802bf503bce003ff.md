## **public Task<Player> getCurrentPlayer()**

**返回值**  
返回[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4 "Player")类型的玩家对象。

## public Task<String> submitPlayerEvent(String playerId,String eventId,String eventType)

上报玩家进入游戏或退出游戏时的行为事件。

**请求参数**

Parameter Name| Parameter Description  
---|---  
playerId| 当前登录玩家的**playerId** 。  
eventId| 玩家事件ID。
     * 当**eventType** 为**GAMEBEGIN** 时，**eventId** 为开发者生成的随机数，应用内唯一，不超过64位。
     * 当**eventType** 为**GAMEEND** 时，**eventId** 为玩家进入游戏时调用**submitPlayerEvent** 返回的transactionId。  
eventType| 事件类型。
     * **GAMEBEGIN** ：进入游戏
     * **GAMEEND** ：退出游戏  
  
**返回值**  


Type| Description  
---|---  
String| 仅当**eventType** 为**GAMEBEGIN** 时，该值返回游戏服务器为玩家分配的transactionId，其他场景返回null。  
  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception)实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。
