# 接口整体规范

接口协议：HTTPS/HTTP

响应协议接口数据格式：JSON

协议接口数据字符编码：UTF-8

  * 接口支持get、post、delete，查询类操作使用get，修改类操作为post、delete；

  * 编码：utf-8；

  * Post Content Type：application/json；

  * Get Content Type：application/x-www-form-urlencoded；

  * 认证信息基于请求Header指定，具体为：

    * 应用级AT：Authorization: Basic Base64(APPAT:atvalue)

\- 例如，发送请求的应用级AT为：thisIsAppAtValue

\- APPAT:atvalue则为：APPAT:thisIsAppAtValue

\- Base64(APPAT:atvalue)则计算方式为Base64(“APPAT:thisIsAppAtValue”)，值为：QVBQQVQ6dGhpc0lzQXBwQXRWYWx1ZQ==

\- 最终请求头Authorization的值为：Basic QVBQQVQ6dGhpc0lzQXBwQXRWYWx1ZQ==

    * 无认证信息：没有对应的Header

  * 语言信息基于请求Header中Accept-Language指定，取值为标准的Locale




# 接口错误码

接口错误码如下：

**响应代码**| **错误码**| **含义**  
---|---|---  
IAP_RESPONSE_RESULT_OK| 0| 成功  
IAP_RESPONSE_RESULT_USER_CANCELED| 1| 用户按下了“返回”或者取消了对话  
IAP_RESPONSE_RESULT_SERVICE_UNAVAILABLE| 2| 网络连接丢失  
IAP_RESPONSE_RESULT_BILLING_UNAVAILABLE| 3| Billing API 版本不受所请求类型的支持  
IAP_RESPONSE_RESULT_ITEM_UNAVAILABLE| 4| 请求的商品不可以购买  
IAP_RESPONSE_RESULT_DEVELOPER_ERROR| 5| 向 API 提供的参数无效。此错误也可能说明应用未在 IAP 中针对应用内购买结算正确签署或设置，或者在清单中没有所需的权限  
IAP_RESPONSE_RESULT_ERROR| 6| API 操作期间发生致命错误  
IAP_RESPONSE_RESULT_ITEM_ALREADY_OWNED| 7| 由于已经拥有该商品，购买失败  
IAP_RESPONSE_RESULT_ITEM_NOT_OWNED| 8| 由于未拥有该商品，消耗或者确认失败  
IAP_RESPONSE_RESULT_ITEM_CONSUMED| 9| 商品已经消耗或者确认，不能再次消耗或者确认

# 站点选择

在完成一笔支付后，您从HMS Core客户端获取到购买信息，返回商品订单详情JSON字符串inAppPurchaseData。inAppPurchaseData中包含accountFlag字段，如果accountFlag为1，使用AppTouch德国站点，如果accountFlag不为1，则需要在四个站点中选择一个（中国、德国、新加坡和俄罗斯）。
