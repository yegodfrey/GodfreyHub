class info  
---  
com.huawei.hms.mlplugin.card.bcr.MLBcrCaptureConfig.Factory  
银行卡检测插件配置器工厂，用于创建银行卡检测插件配置器实例。  
  
# Public Method Summary

Return type| Method name  
---|---  
MLBcrCaptureConfig| create()  
MLBcrCaptureConfig.Factory| setOrientation(int orientation)  
  
# Public Methods

Method  
---  
public MLBcrCaptureConfig create()  
创建银行卡检测插件配置器的实例。  
  
**Return**

Type| desc  
---|---  
MLBcrCaptureConfig| 返回新创建的银行卡检测插件配置器实例。  
  
**Sample Code**  

    
    
     复制
      
        1. MLBcrCaptureConfig config = new MLBcrCaptureConfig.Factory()
        2.      // 设置插件页面屏幕方位。
        3.      // MLBcrCaptureConfig.ORIENTATION_AUTO: 自适应模式，由物理感应器决定显示方向。
        4.      // MLBcrCaptureConfig.ORIENTATION_LANDSCAPE: 横屏，显示时屏幕宽度大于高度。
        5.      // MLBcrCaptureConfig.ORIENTATION_PORTRAIT: 竖屏，显示时屏幕高度大于宽度。
        6.      .setOrientation(MLBcrCaptureConfig.ORIENTATION_AUTO)
        7.      .create();
    
    

Method  
---  
public MLBcrCaptureConfig.Factory setOrientation(int orientation)  
设置插件页面屏幕方位。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
orientation| 插件页面屏幕方位。ORIENTATION_AUTO：自动。ORIENTATION_LANDSCAPE：横屏；ORIENTATION_PORTRAIT：竖屏；  
  
**Return**  


Type| desc  
---|---  
MLBcrCaptureConfig.Factory| 返回银行卡检测插件配置器的工厂实例。
