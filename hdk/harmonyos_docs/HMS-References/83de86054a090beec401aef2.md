public CircleOptions zIndex(float zIndex)  
设置圆的z指数。z指数指的是圆的叠加顺序，具有较大z指数的圆会绘制在具有较小z指数的圆上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
zIndex| z指数，即圆的叠加顺序。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
CircleOptions| CircleOptions对象。
