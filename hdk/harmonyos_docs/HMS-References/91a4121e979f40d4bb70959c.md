int| STATUS_ENDPOINT_UNKNOWN| 尝试与未知的endpoint进行连接。 这个endpoint尚未被发现，也没有与别的设备建立连接

int| STATUS_MISSING_PERMISSION_ACCESS_COARSE_LOCATION| 权限ACCESS_COARSE_LOCATION丢失

int| STATUS_MISSING_PERMISSION_RECORD_AUDIO| 权限RECORD_AUDIO丢失  
int| STATUS_MISSING_SETTING_LOCATION_ON| 位置权限没有打开

int| STATUS_MESSAGE_WRONG_CONTEXT| Message API无效的全局信息

int| STATUS_MESSAGE_AUTH_FAILED| Message API没有被授权  
int| STATUS_MESSAGE_PENDING_INTENTS_LIMITED| 应用发起了超过PendingIntent消息订阅限额，在添加新的请求前需要先删除老的请求
