集成 FIDO SDK 之后，您就可以调用** __** Huawei** __** FIDO BioAuthn API** __** 来完成生物特征认证，包括指纹认证和3D人脸认证。

## Classes

Class name| Class description  
---|---  
[BioAuthnManager](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthnManagerAPI)| FIDO BioAuthn指纹认证是否可用API入口。  
[BioAuthnPrompt](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthnPromptAPI)| FIDO BioAuthn指纹认证API的主入口。  
[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthnCallbackAPI)| 提供给BioAuthn指纹认证或人脸认证的结果回调。需要由开发者完成具体实现。  
[BioAuthnResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthn_BioAuthnResult)| BioAuthnCallback回调的输入参数。  
[CryptoObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/CryptoObjectAPI)| 与指纹认证或人脸认证关联的加密对象的包装类。  
[BioAuthnPrompt.PromptInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthnPromptPromptInfoAPI)| 展示给用户的指纹认证提示框中的信息。  
[BioAuthnPrompt.PromptInfo.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthnPromptPromptInfoBuilderAPI)| 用于生成BioAuthnPrompt.PromptInfo对象的构造器。  
[FaceManager](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/FaceManagerAPI)| FIDO BioAuthn 3D人脸认证API的主入口。
