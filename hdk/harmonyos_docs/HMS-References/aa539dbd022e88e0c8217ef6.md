public Policy.Builder setTtlSeconds(int ttlSeconds)  
在#Put和#Get消息时，设置消息的生命周期，该TTL值要么是TTL_SECONDS_INFINITE，或者是在1到TTL_SECONDS_MAX区间的值，如果未设置TTL，默认使用TTL_SECONDS_DEFAULT。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
ttlSeconds| TTL时间
