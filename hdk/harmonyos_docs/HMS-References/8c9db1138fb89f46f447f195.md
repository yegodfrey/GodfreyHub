**public abstract interface OnStreetViewPanoramaReadyCallback**

当街道全景地图可用时回调的接口。街景相关功能接口暂不支持，包括StreetViewPanoramaCamera、StreetViewPanoramaFragment、StreetViewPanoramaOptions、StreetViewPanoramaView、SupportStreetViewPanoramaFragment。

无

无
