## **com.huawei.hms.mlsdk.tts.MLTtsConfig**

通过此配置类来对TTS引擎进行配置。

# Sample Code
      
      1. // 1.创建新的配置项，不是必须设置，不设置则使用默认值 
        2. MLTtsConfig mlTtsConfig = new MLTtsConfig() 
        3.     .setVolume(1.5f) 
        4.     .setSpeed(1.5f) 
        5.     .setLanguage(MLTtsConstants.TTS_ZH_HANS) 
        6.     .setPerson(MLTtsConstants.TTS_SPEAKER_FEMALE_ZH); 
        7. // 2.查看自定义配置的值； 
        8.     mlTtsConfig.getLanguage();//获取自定义语言，返回null表示未自定义 
        9.     mlTtsConfig.getPerson();//获取发音人名称，返回null表示未自定义 
        10.     mlTtsConfig.getSpeed();//获取当前自定义语速，返回0表示未自定义 
        11.     mlTtsConfig.getVolume();//获取当前自定义音量，返回0表示未自定义 
        12. // 3.更新配置： 
        13.     //a.未定义的配置，则继承当前引擎的上一次配置，若之前未配置过，则使用默认配置； 
        14.     //b.自定义的配置，使用当前定义的配置； 
        15. // 4.更新方式： 
        16. // a.初始化时设置： 
        17.     MLTtsEngine mlTtsEngine =  = new MLTtsEngine(mlTtsConfig); 
        18. // b.过程中更新； 
        19.     mlTtsEngine.updateConfig(mlTtsConfig);

public MLTtsConfig setLanguage(String language)  
  
设置语言。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
language| 语言名称。不设置默认为 "zh-Hans"，表示中文简体。当前支持范围：TTS_EN_US 美标英语。TTS_ZH_HANS 简体汉字。TTS_LAN_ES_ES 西班牙语。TTS_LAN_FR_FR 法语。

Type| desc

MLTtsConfig| 设置语言后的配置实例。

public MLTtsConfig setPerson(String person)

**Parameters**

Parameter name| Parameter desc  
---|---  
person| 发音人名称，不设置默认为"Female-zh"：表示中文女声。当前支持设置范围：TTS_SPEAKER_FEMALE_EN英文女声。TTS_SPEAKER_FEMALE_ZH中文女声。TTS_SPEAKER_MALE_EN英文男声。TTS_SPEAKER_MALE_ZH中文男声。TTS_SPEAKER_FEMALE_ES西班牙标准女声。TTS_SPEAKER_FEMALE_FR法语标准女声。

---|---  
MLTtsConfig| 设置发音人后的配置实例。

public MLTtsConfig setSpeed(float speed)  
  
设置语速。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
speed| 范围（0, 2）。1.0表示正常语速, 小于1.0表示降低语速，0.5表示正常语速的一半；大于1.0表示加快语速，比如1.5表示是正常语速的1.5倍；默认为1.0正常语速；不设置默认为 1.0。  
  
**Return**  


Type| desc  
---|---  
MLTtsConfig| 设置语速后的配置实例。

public MLTtsConfig setVolume(float volume)  
  
设置音量。  
  
**Parameters**
