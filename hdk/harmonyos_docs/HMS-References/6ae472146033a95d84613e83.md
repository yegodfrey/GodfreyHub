public final class BarCode.Builder  
以Builder方式对条形码进行赋值。  
  
## Public Method Summary

Return type| Method name  
---|---  
BarCode.Builder| setText(String text)设置条形码文本信息(目前只支持"**qrCode** ”, “**codabar** ”)，用于在条形码下方展示。  
BarCode.Builder| setType(String type)条形码类型,支持的类型有"**qrCode** ”, “**codabar** ”。不设置的话，默认qrCode.可选字段。  
BarCode.Builder| setValue(String value)条形码展示的值.可选字段。  
BarCode| build()获取通过Builder方式赋值后的BarCode对象。
