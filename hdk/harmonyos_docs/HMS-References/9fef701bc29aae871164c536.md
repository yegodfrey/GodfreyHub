public abstract class TransferEngine  
nearby服务数据传输的总体入口类，此类中实现相关的数据传输方法  
  
## Field Summary

Type| Name| Desc  
---|---|---  
int| MAX_SIZE_DATA| 调用sendData方法时，最大允许的DATA载荷的大小，32768字节  
  
## Public Method Summary

Return type| Method name  
---|---  
Task<Void>| cancelDataTransfer(long dataId)  
接收或发送过程中取消传输  
Task<Void>| sendData(String endpointId, [Data](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-transfer-data) data)  
发送数据，只有连接建立成功（onResult）才可以调用此接口发送数据  
Task<Void>| sendData(List<String> endpointIds, [Data](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-transfer-data) data)  
上述方法的变种，提供了一个endpointId的列表，给多个设备同时发送数据  
  
## Public Methods

Method  
---  
public abstract Task<Void> cancelDataTransfer(long dataId)  
接收或发送过程中取消传输。  
Method  
---  
public abstract Task<Void> sendData(String endpointId, [Data](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-transfer-data) data)  
发送数据，只有连接建立成功（onResult）才可以调用此接口发送数据，返回状态描述如下，  
[STATUS_API_DISORDER](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_API_DISORDER): 调用乱序；  
[STATUS_ENDPOINT_UNKNOWN](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_ENDPOINT_UNKNOWN): 有效连接未建立；  
[STATUS_SUCCESS](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_SUCCESS): 成功，此处成功只表示开始发送数据，并不代表数据发送完成，数据发送状态通过后续的onDataTransferUpdate通知。  
Method  
---  
public abstract Task<Void> sendData(List<String> endpointIds, [Data](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-transfer-data) data)  
提供了一个endpointId的列表，给多个设备同时发送数据,只有连接建立成功（onResult）才可以调用此接口发送数据，返回状态描述如下，  
[STATUS_API_DISORDER](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_API_DISORDER): 调用乱序；  
[STATUS_ENDPOINT_UNKNOWN](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_ENDPOINT_UNKNOWN): 有效连接未建立；  
[STATUS_SUCCESS](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_SUCCESS): 成功，此处成功只表示开始发送数据，并不代表数据发送完成，数据发送状态通过后续的onDataTransferUpdate通知。
