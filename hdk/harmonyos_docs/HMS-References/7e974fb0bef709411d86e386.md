public static Task<[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-authhuaweiId)> parseAuthResultFromIntent(Intent data)  
从登录结果信息的Intent对象中获取Task封装过的AuthHuaweiId对象。  
开发者首先调用getSignInIntent()获取华为帐号授权登录页面的Intent，然后通过startActivityForResult(Intent, int) 发起授权登录流程。登录授权成功后，在onActivityResult(int, int, Intent)中获取登录结果Intent。再调用此方法从Intent中解析出登录结果信息。  
参数intent必须是登录授权成功后通过onActivityResult(int, int, Intent)获取的intent对象。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
data| 授权登录成功后，通过onActivityResult(int, int,Intent)获取的Intent对象。  
  
  
**Return**  


type| desc  
---|---  
Task<[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-authhuaweiId)>| Task封装的华为帐号信息，类型为Task<AuthHuaweiId>。
