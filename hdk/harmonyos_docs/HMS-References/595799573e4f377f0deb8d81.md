public synchronized int doZoom(float scale)  
按缩放系数调整当前相机焦距(数码变焦）。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
Scale| 缩放系数，当缩放系数大于1.0, 以相机支持的最大焦距的1/10为基数的放大系数；当缩放系数等于1.0，不放大；当缩放系数小于1.0，以当前焦距为基数的放大系数。  
  
**Return**  


Type| Desc  
---|---  
int| 缩放后的相机焦距，经过系数缩放后，如果焦距大于当前摄像头支持的最大焦距，则取值为最大焦距。

public synchronized LensEngine run() throws IOException  
启动相机引擎。启动过程会根据用户对帧率，预览尺寸的要求选择合适的相机，并对选中的相机参数做初始化，启动分析器线程，对帧数据进行检测和处理。android SDK 版本大于11时默认采用SurfaceTexture作为帧预览面板，反之默认采用SurfaceView作为帧预览面板。帧预览面板：用于预览帧图像和显示检测结果。  
  
**Return**

Type| Desc  
---|---  
LensEngine| 相机引擎。  
  
**Throws**  


Exception name| Exception desc  
---|---  
IOException| 相机引擎启动失败会抛出该异常。
