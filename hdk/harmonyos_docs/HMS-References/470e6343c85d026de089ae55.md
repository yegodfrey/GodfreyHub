public class WeatherSituation implements Parcelable  
当前天气情况，由当前天气信息（[Situation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-situation)）及城市信息（[City](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-city)）组成。  
  
## Public Method Summary

Return type| Method name  
---|---  
City| getCity()  
Situation| getSituation()  
  
## Public Methods

Method  
---  
public City getCity()  
当前天气的城市信息。  
  
**Return**

Type| desc  
---|---  
City| 天气状态WeatherStatus中的城市信息。包括城市码、省份名称、时区、和城市/区名称。  
Method  
---  
public Situation getSituation()  
当前时间的天气信息。包括天气ID(CN)、湿度、摄氏度、华氏度、体感温度（℃）、体感温度（℉）、风向、风力等级、风速、气压、紫外线强度、更新时间。  
  
**Return**

Type| desc  
---|---  
Situation| 当前时间的天气信息。包括天气ID(CN)、湿度、摄氏度、华氏度、体感温度（℃）、体感温度（℉）、风向、风力等级、风速、气压、紫外线强度、更新时间。
