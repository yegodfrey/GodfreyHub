ML Kit的图片地标检测组件  
此包提供了地标检测的标准模式，核心API如下：  
MLRemoteLandmark：地标识别的信息描述，表示图像地标识别结果的具体信息。  
MLRemoteLandmarkAnalyzer：地标分析器，用于在提供的图像中，识别地标，调用云端API，检测模型在云端运行。

## Classes

Class name| Class description  
---|---  
[MLRemoteLandmark](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteLandmark-4)| 地标识别信息类，表示图像地标识别结果的具体信息。  
[MLRemoteLandmarkAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteLandmarkAnalyzer-4)| 地标分析器：用于在提供的图像中识别地标。  
[MLRemoteLandmarkAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteLandmarkAnalyzerSetting-4)| 地标检测配置器：用于获取地标分析器的属性。  
[MLRemoteLandmarkAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteLandmarkAnalyzerSettingFactory-4)| 地标检测配置器实例创建，用于设置地标分析器的属性。
