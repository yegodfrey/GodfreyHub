**public abstract class UrlTileProvider**

瓦片图层[TileOverlay](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-tileoverlay)的提供者，需要一个URL指向图像。 注意：使用这个类，要求所有的图像都具有相同的尺寸。

public final Tile getTile(int x, int y, int zoom)  
开发者调用此API可以获取指定坐标和缩放级别下的瓦片图层对象。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
x| tile的横坐标，范围为[0, 2zoom \- 1]。  
y| tile的纵坐标，范围为[0, 2zoom \- 1]。  
zoom| 瓦片的缩放级别，范围通过类[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)的[getMinZoomLevel](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap#getMinZoomLevel\(\))()和[getMaxZoomLevel](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap#getMaxZoomLevel\(\))()获得。

[Tile](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-tile)| 指定坐标和缩放级别下的Tile对象。

public abstract URL getTileUrl(int x, int y, int zoom)  
开发者调用此API可以获取指定瓦片坐标对应图片的URL。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
x| tile的横坐标，范围为[0, 2zoom \- 1]。  
y| tile的纵坐标，范围为[0, 2zoom \- 1]。  
zoom| 瓦片的缩放级别，范围通过类HuaweiMap的getMinZoomLevel()和getMaxZoomLevel()获得。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
URL| 指定tile坐标对应图片的URL。
