ArchiveDetails类主要用于对存档内容文件进行操作。

# Public Methods  


## public abstract boolean update(int dstOffset, byte[] content, int srcOffset, int count)

修改存档文件。修改后的存档将保存在本地缓存，直到提交存档时才会提交到游戏服务器。

注意：此方法不会覆盖文件的全部内容，如果写入的数据少于存档文件中原有的数据，剩余的数据将会保留。如需覆盖原有的存档文件，请使用writeBytes方法。

**请求参数**

Parameter Name| Parameter Description  
---|---  
dstOffset| 目标存档文件的偏移量，0表示从文件头部开始。  
content| 要修改的文件内容。存档文件中的文件内容将替换为content中的内容。  
srcOffset| 源文件的偏移量。  
count| 写入存档文件的字节数。  
  
**返回值**

Type| Description  
---|---  
boolean| 修改是否成功。

  * true：成功。
  * false：失败。

## public abstract void set(byte[] content)  


将指定的文件内容写入存档文件。文件写入后将保存在本地缓存，直到提交存档时才会提交到华为游戏服务器。

**请求参数**

Parameter Name| Parameter Description  
---|---  
content| 需要写入文件的二进制字节数据。
