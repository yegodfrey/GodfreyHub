CLASS info

public class ReadSmsManager  
开启读取短信的服务，直到读取到符合规则的短信或者服务超时（超时时间5分钟）。如果收到错误码2021，表示华为帐号无法提供读取短信能力。  
  
**短信规则说明**  


开启读取短信服务后，成功获取的短信内容参看下方样例：
    
    
    prefix_flag short message verification code is XXXXXX hash_value

其中，“prefix_flag”表示短信的前缀标记，包括“<#>”、“[#]”和“\u200b\u200b”，“\u200b\u200b”是不可见unicode字符；“short message virification code is ”表示短信内容（内容可变）；“XXXXXX”表示验证码；“hash_value”表示由HMS SDK产生用于唯一标识当前应用程序的哈希值，该哈希值是通过应用包名生成的，具体请参考[Hash_value的获取](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-hash-value)。
