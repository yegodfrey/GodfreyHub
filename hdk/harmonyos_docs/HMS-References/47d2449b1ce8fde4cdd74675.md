云侧身份证识别检测器：用于在提供的图像中，识别身份证信息。云侧身份证识别检测器，调用云端API，检测模型在云端运行。  
  
## Classes

Class name| Class description  
---|---  
[MLRemoteIcrAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteIcrAnalyzer-4)| 云侧身份证检测器：用于在提供的图像中，识别身份证信息。云侧身份证检测器，调用云端API，检测模型在云端运行。创建云侧身份证检测器有两种方式，根据实际情况二选一。// 方式1：使用默认的参数配置 MLRemoteIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getRemoteIcrAnalyzer(); // 方式2：使用自定义的参数配置 MLRemoteIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getRemoteIcrAnalyzer(setting);  
[MLRemoteIcrAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteIcrAnalyzerSetting-4)| 云侧身份证检测配置器：可指定云侧身份证检测器的属性。身份证检测器的属性包括：1. 身份证正反面；2. 国家编码。  
[MLRemoteIcrAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteIcrAnalyzerSF-4)| 创建云侧身份证检测配置器的实例。
