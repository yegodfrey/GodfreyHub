包含HUAWEI Ads的基本类。  
  
## Interfaces

Interface name| Interface description  
---|---  
[AdParam.ErrorCode](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-adparam-errorcode "AdParam.ErrorCode")| 广告请求错误码。  
[AudioFocusType](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-audiofocustype "AudioFocusType")| 视频播放时获取音频焦点的场景的类型。  
[ContentClassification](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-contentcassification "ContentClassification")| 广告内容分级。  
[Gender](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-gender "Gender")| 性别。  
[NonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nonpersonalizedad "NonPersonalizedAd")| 是否只请求非个性化广告。  
[TagForChild](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-tagforchild "TagForChild")| 面向儿童的设置。  
[UnderAge](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-underage "UnderAge")| 面向未达到法定承诺年龄用户的设置。  
[VideoOperator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videooperator "VideoOperator")| 视频控制器，实现对视频的播放、暂停、静音等控制。

[ChoicesView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-choicesView "ChoicesView")| 选择视图。

[RequestOptions.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-requestoptions-builder "RequestOptions.Builder")| 全局请求配置生成器。

[VideoConfiguration.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videoconfiguration-builder "VideoConfiguration.Builder")| 视频配置信息的生成器。  
[VideoOperator.VideoLifecycleListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-videolifecyclelistener "VideoOperator.VideoLifecycleListener")| 监听器，用以接收视频事件回调。
