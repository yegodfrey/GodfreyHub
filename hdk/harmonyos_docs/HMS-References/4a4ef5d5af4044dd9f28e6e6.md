CLASS info  
---  
public final class RemoteMessage extends Object implements Parcelable  
RemoteMessage类是一个消息实体类，App通过[onMessageReceived](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-HmsMessageService-cls#onMessageReceived)(RemoteMessage)方法接收服务端推送的消息。[RemoteMessage.Notification](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-Notification-cls)类是一个数据类，代表通知消息。当您在服务端推送通知消息时，通过服务端提供的开放接口设置了如果应用进程在前台则不通过华为的统一消息中心（Notification Center, 简称NC）展示消息，那么应用在前台时这个通知消息是直接透传给应用，由应用自己处理展示，此时RemoteMessage消息实体中包含RemoteMessage.Notification数据实例。Notification类中成员字段定义与服务端发送Push消息中的AndroidNotification结构体字段定义相映射。如果应用进程在后台或者不存在，通知消息都是通过NC展示。[RemoteMessage.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-Builder-cls)类用于构建RemoteMessage消息实例。

public String getData()  
获取消息的有效内容数据。getData方法获取到的是String类型，非Java自带Map数据类型，由开发者自行决定格式的解析规则。如果在控制台界面上传入的是键值对（key-value）格式，会转化成JSON格式的String，需要开发者自行解析。如果通过push传输的数据涉及高敏感，高保密性，建议开发者自己对消息体进行加解密处理，以保证消息的安全性。  
  
**Return**

type| desc  
---|---  
String| 消息内容，如果开发者发送消息中data字段设置为"123"，则getData()方法返回"123"；data字段设置为{"k", "v"}，则getData()方法返回JSON格式的字符串{"k", "v"}。
