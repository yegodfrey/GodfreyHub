提供信标围栏、活动状态围栏、耳机状态围栏、位置围栏、时间围栏、环境光围栏和车载蓝牙围栏。同时提供围栏管理：添加、查询、更新、删除，以及围栏的组合逻辑运算。  
  
## Interface

Interface name| Interface description  
---|---  
[BarrierStatusMap](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierstatusmap)| 通过在[BarrierQueryRequest](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierqueryrequest)中输入围栏参数得到的围栏状态集合。  
  
## Classes

Class name| Class description  
---|---  
[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)| 围栏基础类，支持围栏的逻辑运算。  
[BeaconBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-beaconbarrier)| 信标围栏，包括发现、接近和丢失围栏。  
[BehaviorBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-behaviorbarrier)| 活动状态检测围栏，包括活动开始、活动结束和活动进行中围栏。  
[HeadsetBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-headsetbarrier)| 耳机围栏，包括连接、未连接、状态驻留的围栏。  
[LocationBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-locationbarrier)| 位置围栏，包括进入、离开和驻留的围栏。  
[TimeBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier)| 时间围栏，支持按照时间状态设置单次触发和周期触发的围栏。  
[BluetoothBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-bluetoothbarrier)| 车载蓝牙围栏，包括连接、未连接、状态驻留的围栏。  
[AmbientLightBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-ambientlightbarrier)| 光照度围栏，提供小于（below）设定值、大于（above）设定值、在设定的区间（range）三种围栏能力。  
[BarrierQueryRequest](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierqueryrequest)| 查询围栏的请求。  
[BarrierQueryResponse](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierqueryresponse)| 查询围栏的响应。  
[BarrierStatus](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierstatus)| 将围栏状态封装在[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)中。其中，围栏状态包括当前状态、上一次状态和上一次围栏状态更新的时间。  
[BarrierUpdateRequest](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierupdaterequest)| 添加或删除围栏的请求。  
[BarrierUpdateRequest.Builder](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierupdaterequest-builder)| 添加或删除围栏的请求的构造器。
