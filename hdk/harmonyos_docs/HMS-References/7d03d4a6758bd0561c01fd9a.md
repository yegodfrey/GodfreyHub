# 接口功能  
  
应用服务端在获取登录签名后调用此接口请求华为游戏服务器进行登录验签。

说明：

游戏服务提供了各种语言的登录验签示例代码，具体请参考[游戏服务示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-Examples/game-example-v4)。

调用场景  


当应用客户端在获取玩家的登录签名后，将玩家信息和登录签名传递给应用服务端。为了确保玩家信息的准确性，应用的服务端需要调用本接口向华为游戏服务器验证登录签名，验证成功后才能确定登录成功。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器->华为游戏服务器  
接口URL| https://jos-api.cloud.huawei.com/gameservice/api/gbClientApi注意：此接口当前不支持SSL双向认证，在发送HTTPS请求时需要先关闭SSL认证。  
数据格式| 请求：Content-Type:   application/urlencode（表单方式）响应：Content-Type:   application/json  
  
# 请求参数

参数名称| 必选(M)/可选(O)| 类型| 是否参与签名| 参数说明  
---|---|---|---|---  
method| M| string| 是| 固定传入“external.hms.gs.checkPlayerSign”。  
appId| M| string| 是| 游戏的应用ID，在创建应用后由华为开发者联盟为应用分配的唯一标识。应用ID的查询方法请参见[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。  
cpId| M| string| 是| 商户ID，即华为开发者联盟给开发者分配的“支付ID”。  
支付ID的查询方法请参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_querypaymentinfo)。  
ts| M| string| 是| 时间戳，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4)对象。  
playerId| M| string| 是| 玩家ID，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4)对象。  
playerLevel| M| string| 是| 玩家等级，取自当前玩家[Player.getLevel](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4#getLevel)方法，必须转化为string类型。  
playerSSign| M| string| 是| 登录签名，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4)对象。  
cpSign| M| string| 否| 用于华为游戏服务器对请求参数验签的签名字符串。  
为防止请求被篡改，应用需要根据[登录验签接口签名字符串的生成方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/generation-method)中的方法生成签名字符串，华为服务器在收到请求后会对签名字符串进行验签，验签成功后才会进行后续处理，否则将返回失败错误码。  
  
# 返回参数

参数名称| 必选(M)/可选(O)| 类型| 是否参与验签| 参数说明  
---|---|---|---|---  
rtnCode| M| int| 是| 登录验签的返回码。  
● 0：验签成功。  
● -1：验签失败，请检查签名字符串是否按要求生成、时间戳是否失效、签名是否进行urlencode等。  
● 3001：参数错误，请检查传参是否满足格式要求、是否遗漏。  
ts| O| string| 是| 接口返回的当前时间的时间戳，即当前时间距1970年的毫秒数。  
此参数仅在rtnCode等于0时返回。  
rtnSign| O| string| 否| 返回参数的签名字符串。应用可以参考[对登录验签接口响应消息验签](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/verification-method)对签名字符串进行验签，确认响应消息是否被篡改。
