public class BehaviorStatus implements Parcelable  
活动识别的结果。  
识别活动的结果，包含在指定时间内用户可能正在进行的活动的列表，列表按照活动置信度排序，置信度越高排名越靠前。  
类中的getMostLikelyBehavior方法将返回识别到的用户最可能的活动。

public List<[DetectedBehavior](https://developer.huawei.com/consumer/cn/doc/detected-behavior-4)> getProbableBehavior()  
返回一个用户可能在特定时间执行的活动的列表。活动列表按照最可能的活动优先进行排序。每一个可能的活动都有一个置信度，它表示用户在执行该活动的可能性有多大。  
由于有些活动不是互斥的（例如，您可以在公共汽车上行走），并且某些活动是分级的（[ON_FOOT](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-behaviorbarrier#BEHAVIOR_ON_FOOT)是[WALKING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-behaviorbarrier#BEHAVIOR_WALKING)和[RUNNING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-behaviorbarrier#BEHAVIOR_RUNNING)的一种泛化），因此所有检测到的分类活动的置信度之和不需要<=100。  
  
**Return**

Type| desc  
---|---  
List<[DetectedBehavior](https://developer.huawei.com/consumer/cn/doc/detected-behavior-4)>| 返回一个用户可能在特定时间执行的活动的列表。活动列表按照最可能的活动优先进行排序。
