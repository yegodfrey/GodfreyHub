public interface HeadsetStatus   
耳机状态接口类，其中定义了3个耳机状态的常量，即表示耳机已连接CONNECTED和表示耳机未连接DISCONNECTED。   
  
##  Constant Value Summary 

Constant name  |  desc   
---|---  
CONNECTED             |  int CONNECTED = 1；  
表示耳机已连接。   
DISCONNECTED             |  int DISCONNECTED = 0；  
表示耳机未连接。   
UNKNOWN             |  int UNKNOWN = -1；  
表示无法识别到耳机状态。
