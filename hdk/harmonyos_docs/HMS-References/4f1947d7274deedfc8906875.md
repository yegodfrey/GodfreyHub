# 接口功能

此接口用于退款给顾客，不会取消订阅，在订阅到期之前一直有效。

# 调用场景

当顾客意外购买订阅商品后，顾客申诉退款，则您的APP先调用取消订阅接口，确保订阅续期终止，之后调用返还订阅费用接口退还顾客费用。让顾客免费试用一段时间，再确定是否保留该订阅商品。

注意：

  * 本接口仅仅对指定订阅的最近一次收费完成退款处理，不会取消订阅，订阅的有效性和后续的续期仍然会正常发生。

  * 在订阅最新收据上已经有退款信息情况下，会拒绝服务。在此情况下，如果您希望处理其他往期收据的费用返还，或者最新收据的剩余费用返还，建议通过华为应用内支付服务器的退款能力进行处理。

  * 沙箱购买和购买金额为0的商品，退费直接成功。




# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器-> 华为支付服务器  
接口URL| {rootUrl}/sub/applications/{apiVersion}/purchases/returnFeerootUrl在不同站点有不同的url：开发者应固定选择最近站点的Subscription服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#State-Infomation)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#h1-1590477491025)。  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
# 请求参数

**参数名称**| **必选(M)/****可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
subscriptionId| M| String| 订阅Id  
purchaseToken| M| String| 商品的已购买Token，发起购买和查询订阅信息均会返回。  
  
# 响应参数

**参数名称**| **必选(M)/可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
responseCode| M| String| 返回码。●  0：成功●  其他：失败，具体参考[接口错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#API-ErrorCode)。  
responseMessage| O| String| 响应描述。
