public static AdvertisingIdClient.Info getAdvertisingIdInfo(Context context) throws IOException  
获取OAID和“限制个性化广告”开关。  
如果用户手机中，“华为移动服务（APK）”版本在2.6.1及以下，无法获取OAID，将抛出IOException。

public static boolean verifyAdId(Context context, String adId, boolean isLimitAdTracking) throws AdIdVerifyException  
校验OAID和“限制个性化广告”开关是否是有效。此方法可能会耗时较长，请不要在主线程调用此方法。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
context| Android的标准Context。  
adId| OAID。  
isLimitAdTracking| “限制个性化广告”开关。  
  
**Return**

Type| desc  
---|---  
boolean| true:有效的OAID和“限制个性化广告”开关, false:无效的OAID和“限制个性化广告”开关。  
  
**Throws**

Parameter name| Parameter desc  
---|---  
AdIdVerifyException| 接口调用失败抛出AdIdVerifyException，通过getMessage可以获取异常信息描述。
