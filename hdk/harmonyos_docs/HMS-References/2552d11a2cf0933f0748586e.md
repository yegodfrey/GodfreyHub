ML Kit的身份证识别检测组件，此包提供了身份证识别检测的标准模式，核心API如下：  
  
MLIdCard：身份证识别结果的具体信息。

MLIcrAnalyzer：端侧身份证识别检测器,用于在提供的图像中，识别身份证信息，调用端侧API，检测模型在端侧运行。

## Classes

Class name| Class description  
---|---  
[MLIcrAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLIcrAnalyzer-4)| 端侧身份证检测器：用于在提供的图像中，识别身份证信息。端侧身份证检测器，调用端侧API，检测模型在端侧运行。创建端侧身份证检测器有两种方式，根据实际情况二选一。// 方式1：使用默认的参数配置 MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer();   
// 方式2：使用自定义的参数配置 MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer(setting);  
[MLIcrAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLIcrAnalyzerSetting-4)| 端侧身份证检测配置器：可指定端侧身份证检测器的属性。身份证检测器的属性包括：1.身份证正反面；2.语言。  
[MLIcrAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLIcrAnalyzerSettingFactory-4)| 创建端侧身份证检测配置器的实例。  
[MLIdCard](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLIdCard-4)| 检测出的身份证信息。
