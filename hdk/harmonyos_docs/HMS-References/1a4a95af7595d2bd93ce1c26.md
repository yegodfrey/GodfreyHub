public static SafeteDetectClient getClient (android.content.Context context)  
返回一个 SafetyDetectClient 对象，这个对象用于调用 Safety Detect API。说明：返回一个 SafetyDetectClient 实例，这个实例用于调用 Safety Detect API。当传入参数为非Activity类型时，如果使用SafetyDetectClient实例调用Safety Detect服务接口发生异常，就不会弹出UI交互界面提示用户处理，只会返回错误码。例如：当HMS不符合Safety Detect服务的版本要求时，便会返回错误码907135003，此时需要手动升级HMSCore。如果需要拉起升级引导界面，建议传入Activity类型参数替代Context类型，创建Client实例。  
  
**Parameters**  
Parameter name| Parameter desc  
---|---  
context| 安卓应用的 Context  
  
  
**Return**  


type| desc  
---|---  
SafetyDetectClient| Safety Detect API 的主入口

public static SafeteDetectClient getClient (android.app.Activity activity)  
返回一个 SafetyDetectClient 对象，这个对象用于调用 Safety Detect API。说明：返回一个 SafetyDetectClient 实例，这个实例用于调用 Safety Detect API。当传入参数为Activity类型时，如果使用SafetyDetectClient实例调用Safety Detect服务接口发生异常，那么应用就会弹出UI交互界面提示用户处理。例如：当HMS Core不符合Safety Detect服务的版本要求时，就会拉起升级提示界面，引导用户升级。

---|---  
activity| 安卓应用的 Activity  
  
  
**Return**  


type| desc

SafetyDetectClient| Safety Detect API 的主入口
