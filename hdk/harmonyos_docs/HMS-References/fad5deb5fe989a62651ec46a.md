com.huawei.hms.mlsdk.objects.MLObjectAnalyzerSetting.Factory

## Sample Code
    
    
    复制
      
        1. MLObjectAnalyzerSetting options = new MLObjectAnalyzerSetting.Factory()
        2.     .allowClassification()
        3.     .setAnalyzerType(MLObjectAnalyzerSetting.TYPE_VIDEO)
        4.     .create();
