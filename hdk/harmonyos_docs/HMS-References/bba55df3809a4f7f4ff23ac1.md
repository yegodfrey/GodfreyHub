class info  
---  
com.huawei.hms.mlsdk.common.MLPosition  
点数据类，表示图像中的二维或三维点，以浮点精度指定（float），(0,0)表示图像左上角像素点，向右为x正向，向下为y正向。只有x、y同时有值，才构成一个有效坐标。

Constructor name
