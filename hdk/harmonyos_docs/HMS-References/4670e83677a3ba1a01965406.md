# 1 数据类型  
  
  * **GeofenceBuilder**




包含地理围栏信息的简单对象。

字段| 类型  
---|---  
longitude| Float  
latitude| Float  
radius| Float  
uniqueId| String  
conversions| Number  
validContinueTime| Float  
dwellDelayTime| Number  
notificationInterval| Number  
  
  * **GeofenceRequest**




地理围栏请求对象。

字段| 类型  
---|---  
geonfences| Array  
conversions| Number  
coordinate| Number  
  
  * **GeofenceResponse**




地理围栏响应对象。

字段| 类型  
---|---  
uniqueId| String  
  
  * **GeofenceData**




地理围栏数据对象。

字段| 类型  
---|---  
convertingGeofenceList| Array  
conversion| Number  
convertingLocation| Array  
errorCode| Number  
errorMessage| String  
  
# 2 公共函数

  * **createGeofenceList(geofenceRequest)**




添加地理围栏。 当地理围栏触发时，系统广播一则通知。 您可以通过addGeofenceEventListener函数来订阅广播。

参数| 描述  
---|---  
geofenceRequest| GeofenceRequest对象。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回一个包含请求ID的对象。 （例如， {"requestCode": 3}）  
  
  * **deleteGeofenceList(requestCode)**




基于请求码删除地理围栏。

参数| 描述  
---|---  
requestCode| 请求码。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回true。 否则报错。  
  
  * **addGeofenceEventListener(callback)**




订阅地理围栏更新。 包含一个通过地理围栏数据持续调用的回调函数。 首先您需要通过createGeofenceList函数来注册更新。

参数| 描述  
---|---  
callback| 以GeofenceData对象为入参的回调函数。  
  
  * **removeGeofenceEventListener(callback)**




This function removes the event listener that is added by addGeofenceEventListener.

参数| 描述  
---|---  
callback| 待删除的回调函数。  
  
# 3 常量

常量| 定义  
---|---  
GeofenceRequestConstants.ENTER_INIT_CONVERSION| 当添加一个用户设备已经处在其中的地理围栏时，GEOFENCE_TRANSITION_ENTER会立即触发。  
GeofenceRequestConstants.EXIT_INIT_CONVERSION| 当添加一个用户设备已经离开的地理围栏时，GEOFENCE_TRANSITION_EXIT会立即触发。  
GeofenceRequestConstants.DWELL_INIT_CONVERSION| 当添加一个用户设备已经进入其中且在其中停留指定时间的地理围栏时，GEOFENCE_TRANSITION_DWELL会立即触发。  
GeofenceRequestConstants.COORDINATE_TYPE_WGS_84| 使用WGS_84坐标系。  
GeofenceRequestConstants.COORDINATE_TYPE_GCJ_02| 使用GCJ_02坐标系。  
GeofenceConstants.ENTER_GEOFENCE_CONVERSION| 用户进入地理围栏。  
GeofenceConstants.EXIT_GEOFENCE_CONVERSION| 用户离开地理围栏。  
GeofenceConstants.DWELL_GEOFENCE_CONVERSION| 用户在地理围栏中逗留。  
GeofenceConstants.GEOFENCE_NEVER_EXPIRE| 地理围栏未配置超时间隔。
