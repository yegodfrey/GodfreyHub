# 接口功能

  * 调用该接口，对已经获得的Access Token进行鉴权。

  * 传入Access Token到华为服务器上获取用户的union_id、open_id、expire_in、scope等信息返回。




# 调用场景

  * 应用已经获取到Access Token，要对其进行解析鉴权，获取Access Token中包含的union_id、open_id等信息。




# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器->华为帐号服务器  
接口URL（开发者）| https://api.cloud.huawei.com/rest.php?nsp_fmt=JSON&nsp_svc=huawei.oauth2.user.getTokenInfo  
接口URL（运营商）| https://oauth-api-at.platform.dbankcloud.com/rest.php?nsp_fmt=JSON&nsp_svc=huawei.oauth2.user.getTokenInfo  
数据格式| Content-type: application/x-www-form-urlencoded  
  
# 接口约束

  * 接口是3.0.0版本SDK新增接口。




# 请求参数

**参数名称**|  必选(M)/可选(O)| **类型**| **参数说明**  
---|---|---|---  
access_token| M| string| 通过授权码code或者Refresh Token获取到的Access Token。  
open_id| O| string| 固定值“OPENID”。  
  
# 返回参数

调用成功情况下,返回如下：

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
client_id| M| string| 应用APP ID。  
expire_in| M| Long| Access Token的过期时间，单位为秒。默认为60分钟。  
union_id| O| string| 用户的union_id，由用户帐号和应用开发者帐号签名而成，需要应用ID包含com.huawei.android.hms.account.getUnionId权限时才会返回。  
open_id| O| string| 用户的open_id，由用户帐号和应用ID加密生成的，当Access Token为用户级，且入参open_id为OPENID时才返回。  
scope| O| string| 用户授权scope列表，当Access Token为用户级时才返回。  
  
# 返回码

失败则返回“error”，且抛出异常NSPException（返回体Header中携带NSP_STATUS字段）

字段| 错误码| 子错误码| 描述  
---|---|---|---  
NSP_STATUS| 500| 暂无| 调用接口出错  
NSP_STATUS| 6| 暂无| AT正常过期  
NSP_STATUS| 102| 暂无| AT无效，如因用户修改密码而被加入禁用清单，或AT格式不对等  
NSP_STATUS| 1| 暂无| 未知错误
