public class TimeCategoriesResponse extends BaseResponse<TimeCategories>  
时间状态的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getTimeCategories](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getTimeCategories)方法获取。  
  
## Public Method Summary

Return type| Method name  
---|---  
TimeCategories| getTimeCategories()  
  
## Public Methods

Method  
---  
public TimeCategories getTimeCategories()  
返回设备当前所在地的时间状态信息。时间状态是TimeBarrier类中定义的上午[TIME_CATEGORY_MORNING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_MORNING)，下午[TIME_CATEGORY_AFTERNOON](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_AFTERNOON)，晚上[TIME_CATEGORY_EVENING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_EVENING)，夜间[TIME_CATEGORY_NIGHT](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NIGHT)，工作日[TIME_CATEGORY_WEEKDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKDAY)，休息日[TIME_CATEGORY_WEEKEND](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKEND)，节假日[TIME_CATEGORY_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_HOLIDAY)，非节假日[TIME_CATEGORY_NOT_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NOT_HOLIDAY)。  
  
Return

Type| desc  
---|---  
TimeCategories| 时间状态信息。
