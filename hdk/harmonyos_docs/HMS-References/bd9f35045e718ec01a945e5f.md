public class TokenBinding  
Token绑定（协议），用于客户端与依赖方进行通信。  
  
## Public Constructor Summary

Method name  
---  
**TokenBinding**(TokenBindingStatus status, String id)构建TokenBinding实例。  
  
## Public Methods Summary

Return type| Method name  
---|---  
TokenBindingStatus| **getStatus**()获取客户端的绑定状态与依赖方的通信状态：present——与依赖方处于通信状态；supported——支持绑定，但暂未与依赖方通信。  
String| **getId**()获取ID。
