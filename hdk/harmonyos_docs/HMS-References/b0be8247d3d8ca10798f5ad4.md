# ActivityRecord.Builder  
  
**CLASS info**  
---  
public static class Builder  
构造活动记录构造器  
  
#### Public Method Summary

**Return** | **Method**  
---|---  
Builder | setName(String sessionName) 设置活动记录的名称，入参可以是null或者长度在1到980之间的字符串  
Builder | setId(String identifier) 设置活动记录的标识符，入参可以是长度在1到1000之间的字符串  
Builder | setStartTime(long startTimeMillis, TimeUnit timeUnit) 根据传入的时间单位设置活动记录的开始时间  
Builder | setEndTime(long endTimeMillis, TimeUnit timeUnit) 根据传入的时间单位设置活动记录的结束时间  
Builder | setDurationTime(long time, TimeUnit timeUnit) 根据传入的时间单位设置活动记录的持续时间  
Builder | setActivityTypeId(String activityType) 设置与此活动记录关联的活动类型  
Builder | setDesc(String describer) 设置此活动记录的描述，入参可以是null、空字符串或者长度在1到1000之间的字符串  
ActivityRecord | build() 完成构建并返回活动记录实例
