class info  
---  
public interface CapabilityStatus  
各能力支持状态接口类，可以从该接口调用getCapabilityStatus方法获取Awareness在当前设备所支持的能力，其中定义了10个能力状态码，分别代表各能力。  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
int| AWA_CAP_CODE_HEADSET| 耳机感知能力  
int| AWA_CAP_CODE_LOCATION_CAPTURE| 位置感知（快照）能力  
int| AWA_CAP_CODE_LOCATION_NORMAL_BARRIER| 位置感知（正常围栏）能力  
int| AWA_CAP_CODE_LOCATION_LOW_POWER_BARRIER| 位置感知（低功耗围栏）能力  
int| AWA_CAP_CODE_BEHAVIOR| 活动感知能力  
int| AWA_CAP_CODE_TIME| 时间感知能力  
int| AWA_CAP_CODE_AMBIENT_LIGHT| 环境光感知能力  
int| AWA_CAP_CODE_WEATHER| 天气感知能力  
int| AWA_CAP_CODE_BEACON| Beacon感知能力  
int| AWA_CAP_CODE_INCAR_BLUETOOTH| 车载蓝牙感知能力
