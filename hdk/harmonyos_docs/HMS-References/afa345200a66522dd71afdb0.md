# 1 数据类型

  * **LatLng**




包含经纬度信息的简单对象。

字段| 类型  
---|---  
Latitude| 数值型  
Longitude| 数值型  
  
  * **Point**




包含经纬度信息的简单对象。

字段| 类型  
---|---  
x| 数值型  
y| 数值型  
  
# 2 属性

属性| 类型| 描述  
---|---|---  
title| 字符串| 标记标题。该属性仅在组件没有<Callout />子组件时使用，此时使用默认的信息窗行为，既展示标题也展示提供的描述。  
description| 字符串| 标记描述。该属性仅在组件没有<Callout />子组件时使用，此时使用默认的信息窗行为，既展示标题也展示提供的描述。  
image| ImageSource| 待用作标记图标的自定义图片。仅支持本地图像资源。  
icon| ImageSource| 待渲染的标记图标（等同于GMSMarker Class的icon属性）。  
pinColor| Color| 如果没有提供自定义标记视图或者自定义图片，则使用平台默认的大头针图标。可通过该属性设置大头针图标的颜色。如果使用自定义标记，则忽略该属性。可用颜色有限。如果设置为不支持的颜色，则默认采用红色。  
coordinate| LatLng| 标记坐标。  
anchor| Point| 标记的锚点。该锚指定标记图像展示在地球表面上的标记位置。锚点值在连续区间[0.0, 1.0] x [0.0, 1.0]内，其中（0，0）表示图片的左上角，（1，1）表示图片的右下角。在WxH格式的图片中，锚点是(W + 1) x (H + 1)网格中的最近的离散网格点，通过刻度然后四舍五入获得。例如在4x2格式的图片中，锚点（0.7，0.6）对应的网格点是（3，1）。  
calloutAnchor| Point| 指定在标记图片中展示信息窗锚点的位置点。该属性取值采用和anchor属性相同的坐标系。详情请参见anchor属性。默认为图片的顶部中间位置。  
flat| Boolean| 设置是否在地图或者面向相机的公告牌上平铺展示该标记。  
identifier| 字符串| 用于后续引用该标记的标识符。  
rotation| 浮点型| 表示标记旋转角度的浮点数，单位为度。  
draggable| <null>| 该属性是一个非值类属性。传入该参数时，表示标记可以拖拽（移动）。  
tracksViewChanges| Boolean| 指定标记是否跟踪视图修改。建议尽量关闭该功能以提升自定义标记的性能。  
opacity| 浮点型| 标记的不透明度。取值范围是0.0~1.0。  
  
# 3 事件

事件名| 返回值| 描述  
---|---|---  
onPress| { coordinate: LatLng, position: Point }| 用户点击标记时调用的回调。  
onCalloutPress| -| 用户点击信息窗时调用的回调。  
onDragStart| { coordinate: LatLng, position: Point }| 用户开始拖拽（可拖拽的）标记时调用的回调。  
onDrag| { coordinate: LatLng, position: Point }| 标记拖动过程中持续调用的回调。  
onDragEnd| { coordinate: LatLng, position: Point }| 标记拖拽完成时调用的回调。该事件通常是您想重新设置标记在地图上的坐标时调用。  
  
# 4 方法

方法名| 参数| 描述  
---|---|---  
showCallout| -| 展示该标记的信息窗。  
hideCallout| -| 隐藏该标记的信息窗。  
animateMarkerToCoordinate| coordinate: LatLng, duration: number| 动画化标记移动。  
redraw| -| 重绘标记。该属性在标记有更新且tracksViewChanges成本过高的情况下比较有用。
