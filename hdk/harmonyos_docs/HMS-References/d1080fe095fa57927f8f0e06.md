GamesClient类定义了游戏基础功能相关接口，例如获取应用ID、设置欢迎提示语的位置。

# Public Method Summary

Return| Method  
---|---  
Task< String >| getAppId()  
获取游戏的应用ID。  
Task< Void >| setPopupsPosition(int position)  
设置欢迎提示语和完成成就提示框的位置。  
Task<Boolean>| cancelGameService()取消游戏服务授权。  
  
# Public Methods

## **public Task<String> getAppId()**

获取游戏的应用ID。

## **public Task<Void> setPopupsPosition(int position)**

设置欢迎提示语和完成成就提示框展示的位置。如果不调用本接口，将默认在页面顶部展示。

**请求参数**

参数名| 参数说明  
---|---  
position| 当前只支持传入“TOP”，表示在页面顶部展示欢迎提示语和完成成就提示框。  
  
## public Task<Boolean> cancelGameService()

用户在华为应用市场开启游戏服务授权后，应用可以调用本方法向用户提供取消游戏服务授权的功能。

**返回值**

类型| 参数说明  
---|---  
Boolean| 取消授权是否成功。

  * true：成功 
  * false：失败
