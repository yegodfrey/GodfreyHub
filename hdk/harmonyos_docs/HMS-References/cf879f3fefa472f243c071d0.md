# Public Methods  


## public Task<GamePlayerStatistics> getGamePlayerStatistics(boolean isRealTime)

以异步方式获取当前玩家的统计信息，例如在线时长、在线名次等。支持从本地缓存或游戏服务器获取。

**请求参数**

Parameter Name| Parameter Description  
---|---  
isRealTime| 是否联网获取数据。

  * true：是，表示从游戏服务器获取数据。
  * false：否，表示从本地缓存获取数据。本地缓存时间为5分钟，如果本地无缓存或缓存超时，则从游戏服务器获取。

  
  
**返回值**  


Type| Description  
---|---  
Task<[GamePlayerStatistics](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gameplayerstatistics)>| 当前玩家统计信息。  
  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception)实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。
