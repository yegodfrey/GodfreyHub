# dataCollectors.sampleSets: patch

上传数据采集器采集的采样数据。

注意：只允许创建该数据采集器的应用上传该数据采集器的采样数据，其他应用只支持读取该数据采集器的数据。

#### 请求

#### [h2]HTTP请求
    
    
    PATCH 
    https://health-api.cloud.huawei.com/hihealth/v1/dataCollectors/dataCollectorId/sampleSets/sampleSetId

#### [h2]请求参数

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
dataCollectorId | string | 数据采集器的唯一标识 | 必选 | 需满足如下拼接规则：collectorType:collectorDataType.name: appInfo.appPackageName:deviceInfo.manufacturer: deviceInfo.modelNum:deviceInfo.uniqueId:collectorName。参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中collectorId的约束。 需与请求体 SampleSet中dataCollectorId保持一致  
sampleSetId | string | 采样数据集标识符，单位：纳秒 | 必选 | 格式：“startTime-endTime”，其中：startTime/endTime必须是19位整数的时间戳，对应时间范围是2000-01-01 00:00:00 ~ 2099-12-31 23:59:59  
  
#### [h2]请求体

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
dataCollectorId | string | 数据采集器的唯一标识 | 必选 | 需满足如下拼接规则：collectorType:collectorDataType.name: appInfo.appPackageName:deviceInfo.manufacturer: deviceInfo.modelNum:deviceInfo.uniqueId:collectorName。参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中collectorId的约束。 需与请求体 SampleSet中dataCollectorId保持一致  
sampleSetId | string | 采样数据集标识符，单位：纳秒 | 必选 | 格式：“startTime-endTime”，其中：startTime/endTime必须是19位整数的时间戳，对应时间范围是2000-01-01 00:00:00 ~ 2099-12-31 23:59:59  
  
#### 响应

成功后，返回SampleSet的所有字段，参考请求体。

#### 返回码

成功：http 200

失败：其他
