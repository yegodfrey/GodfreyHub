public MLDocumentSetting.Factory setLanguageList(List  
设置预置语种，正确地预置检测器语种，可以使检测更快速更准确，但错误的设置会导致错误的检测结果；在不确定语种的情况下，可以不设置，服务会自动识别语种；当前检测器可支持中、日、韩、英、法、德、俄、意大利、葡萄牙、西班牙、波兰、挪威、瑞典、丹麦、土耳其、芬兰、泰语、阿拉伯语和印地语等19国语言。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
languages| 语种列表，语种使用语言代码表示：“en”（英）, “zh”（中）,“ja”（日）, “ko”（韩）, “ru”（俄）, “de”（德）, “fr”（法）, “it”（意大利）, “pt”（葡萄牙）, “es”（西班牙）,“pl”（波兰）, “no”（挪威）, “sv”（瑞典）, “da”（丹麦）, “tr”（土耳其）, “fi”（芬兰）,“th”（泰语）,“ar”（阿拉伯语）,“hi”（印地语）。

Type| desc

MLDocumentSetting.Factory| 返回MLDocumentSetting.Factory的实例。
