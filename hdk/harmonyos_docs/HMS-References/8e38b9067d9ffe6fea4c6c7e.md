public class Situation implements Parcelable  
当前天气信息。包括天气ID(CN)、湿度、摄氏度、华氏度、体感温度（℃）、体感温度（℉）、风向、风力等级、风速、气压、紫外线强度、更新时间。

public int getCnWeatherId()  
获取CN天气Id（cnWeatherId）。CN天气Id表示的是当前的天气，每个值都对应不同的天气，例如0表示晴，1表示多云，7表示小雨。更多天气ID对应的天气信息请参见[CNWeatherId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/cn-weatherId-4)。  
  
**Return**

Type| desc  
---|---  
int| CN天气Id。

public String getWindDir()  
获取风向，风向值有“NE（东北风向）”、“E（东风向）”、“SE（东南风向）”、“S（南风向）”、“SW（西南风向）”、“W（西风向）”、“N（北风向）”和“NW（西北风向）”八个值。  
  
**Return**
