public Task<Void> updateBarriers(BarrierUpdateRequest request)  
添加或删除一组围栏。添加围栏时，如果添加给定的围栏键值已经成功注册，会创建一个新的围栏代替已存在的围栏。无论新的围栏注册成功或失败，原来围栏所有的回调请求都将无效。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
request| 添加或移除围栏的请求。  
  
  
**Return**  


Type| desc  
---|---  
Task<Void>| 返回的Task泛型。可以使用Task中的isSuccessful()判断是否成功。  
  
## **public void** enableUpdateWindow(boolean isEnable)

当Awareness Kit和HMS Core升级时，是否出现弹窗。

注意：慎用该功能。如果设置成false将无法触发升级，没有升级弹窗提示，相当于在升级弹窗点击了取消升级。在没有完成升级前，Awareness Kit 所有功能将不可用。只能等待完成静默升级后，功能恢复。静默升级触发时间一般为7-14天。
