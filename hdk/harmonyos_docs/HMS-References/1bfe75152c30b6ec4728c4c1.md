# 1 数据类型

  * **Region**




包含地区数据的简单对象。

字段| 类型  
---|---  
Latitude| 数值型  
Longitude| 数值型  
latitudeDelta| 数值型  
longitudeDelta| 数值型  
  
  * **Camera**




包含相机数据的简单对象。

字段| 类型  
---|---  
center| LatLng  
pitch| 数值型  
heading| 数值型  
altitude| 数值型  
zoom| 数值型  
  
  * **LatLng**




包含经纬度信息的简单对象。

字段| 类型  
---|---  
latitude| 数值型  
longitude| 数值型  
  
  * **Location**




包含位置数据的简单对象。

字段| 类型  
---|---  
latitude| 数值型  
longitude| 数值型  
timestamp| 数值型  
accuracy| 数值型  
altitudeAccuracy| 数值型  
speed| 数值型，单位为米/秒。  
  
  * **Point**




包含点数据的简单对象。

字段| 类型  
---|---  
x| 数值型  
y| 数值型  
  
  * **Frame**




包含帧数据的简单对象。

字段| 类型  
---|---  
x| 数值型  
y| 数值型  
width| 数值型  
height| 数值型  
  
  * **EdgePadding**




包含EdgePadding数据的简单对象。

字段| 类型  
---|---  
top| 数值型  
right| 数值型  
bottom| 数值型  
left| 数值型  
  
  * **EdgeInsets**




包含EdgeInsets数据的简单对象。

字段| 类型  
---|---  
top| 数值型  
right| 数值型  
bottom| 数值型  
left| 数值型  
  
  * **Marker**




包含标记数据的简单对象。

字段| 类型  
---|---  
id| 字符串  
coordinate| LatLng  
title| 字符串  
description| 字符串  
  
# 2 属性

属性| 类型| 描述  
---|---|---  
region| Region| 地图展示的区域。该区域由中心点坐标以及坐标跨度定义。  
initialRegion| Region| 地图展示的初始区域。如您不想要控制地图初始区域以外的视角，则使用该属性而非仅仅使用region属性。如果容器挂载后修改该属性，地图展示区域将保持不变。此属性与文本输入型的initialValue属性类似。  
camera| Camera| 地图展示的相机视图。如果使用该属性，则忽略region属性。  
initialCamera| Camera| 与initialRegion属性类似。如您不想控制地图初始相机设置以外的地图视角，则使用该属性而非仅仅使用相机属性。如果容器挂载后修改该属性，地图展示区域将保持不变。此属性与文本输入型的initialValue属性类似。  
showsCompass| Boolean| 如果该属性配置为false，地图上将不会展示指南针。  
zoomEnabled| Boolean| 如果该属性设置为false，用户将无法缩放地图。  
zoomTapEnabled| Boolean| 如果该属性设置为false，用户将无法通过双击来缩放地图。注意：该属性设置为false时，点击手势的识别时延会大大降低。  
zoomControlEnabled| Boolean| 如果该属性设置为false，地图右下角的缩放控件将不可见。  
minZoomLevel| Number| 地图的最小缩放值。取值范围为3~20。  
maxZoomLevel| Number| 地图的最大缩放值。取值范围为3~20。  
rotateEnabled| Boolean| 如果该属性设置为false，用户将无法旋转地图。  
scrollEnabled| Region| 如果该属性设置为false，用户将无法修改地图的展示区域。  
pitchEnabled| Boolean| 如果该属性设置为false，用户将无法调整相机的倾斜角度。  
moveOnMarkerPress| Boolean| 如果该属性设置为false，用户点击标记时地图将不移动。  
  
# 3 事件

访问事件数据，您需要使用e.nativeEvent。例如，onPress={e => console.log(e.nativeEvent)}会将整个事件对象记录到您的控制台。

事件名| 返回值| 描述  
---|---|---  
onMapReady| -| 地图完全加载完成时调用的回调。  
onRegionChange| Region| 区域改变时持续调用的回调，比如当用户拖拽地图时。  
onRegionChangeComplete| Region| 区域改变时调用的回调，比如当用户移动地图时。  
onPress| { coordinate: LatLng, position: Point }| 用户点击地图时调用的回调。  
onDoublePress| { coordinate: LatLng, position: Point }| 用户双击地图时调用的回调。  
onPanDrag| { coordinate: LatLng, position: Point }| 用户点击并拖拽地图时调用的回调。  
onLongPress| { coordinate: LatLng, position: Point }| 用户长按地图时调用的回调。  
onMarkerPress| -| 用户点击地图上标记时调用的回调。  
onCalloutPress| -| 用户点击气泡时调用的回调。  
onMarkerDragStart| { coordinate: LatLng, position: Point }| 用户开始拖拽（可拖拽的）标记时调用的回调。  
onMarkerDrag| { coordinate: LatLng, position: Point }| 标记移动过程中持续调用的回调。  
onMarkerDragEnd| { coordinate: LatLng, position: Point }| 标记拖拽完成时调用的回调。该事件通常是您想重新设置标记在地图上的坐标时调用。  
  
# 4 方法

方法名| 参数| 描述  
---|---|---  
getCamera| -| 返回表示当前相机配置的Camera对象。  
animateCamera| camera: Camera, { duration: Number }| 将相机动画化成新的视图。此处您可以传入部分camera对象的属性，为传入的属性取值保持不变。  
setCamera| camera: Camera, { duration: Number }| 与animateCamera相似。不同之处在于，此方法立即设置新的视图，没有动画效果。  
getMapBoundaries| Promise<{northEast: LatLng, southWest: LatLng}>| 返回地图边界。  
setMapBoundaries| northEast: LatLng, southWest: LatLng| 边界由地图中心点坐标定义，而非由设备的视角定义。  
fitToElements| animated: Boolean| 适配地图上的元素。  
fitToSuppliedMarkers| markerIDs: String[], options: { edgePadding: EdgePadding, animated: Boolean }| 如在ComponentDidMount中使用该方法，确保为其设置超时时间，否则可能导致性能问题。  
fitToCoordinates| coordinates: Array<LatLng>, options: { edgePadding: EdgePadding, animated: Boolean }| 如果在android中的ComponentDidMount中调用，会抛出异常。建议从MapView的onLayout时间中调用该方法。  
pointForCoordinate| coordinate: LatLng| 将地图坐标转换为视图坐标（点）。返回Promise<Point>。  
coordinateForPoint| point: Point| 将视图坐标（点）转换为地图坐标。返回Promise<Coordinate>。
