public final void setFlat(boolean flat)  
开发者调用此API可以设置Marker是否平贴地图。如果标记平贴地图，则在相机旋转和倾斜时，标记仍将停留在地图上，但与GroundOverlay不同，它将保持与照相机缩放时相同的大小。 如果标记面对相机，它将始终面向相机绘制，并随相机旋转和倾斜。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
flat| 平贴地图设置为 true，面对相机设置为 false，默认值为false。  
  
  
**Return：**  
无

public final void setInfoWindowAnchor(float anchorU, float anchorV)  
开发者调用此API可以设置Marker的标记信息窗口的锚点坐标， 这是在与锚点相同的坐标系中指定的， 默认值为标记图像的顶部中间。 有关更多详细信息，请参见setAnchor(float anchorU, float anchorV)。

---|---  
anchorU| 标记信息窗口锚点的水平坐标，以图像宽度的比例，在[0，1]范围内。  
anchorV| 标记信息窗口锚点的垂直坐标，以图像高度的比例，在[0，1]范围内。  
  
  
**Return：**  
无

public final void setZIndex(float zIndex)  
用于设置Marker的z指数。z指数指的是标记的叠加顺序，具有较大z指数的标记会绘制在具有较小z指数的标记上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
zIndex| z指数，即标记的叠加顺序。  
  
  
**Return：**  
无
