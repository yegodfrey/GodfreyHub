# 1 数据类型

  * **LatLng**




包含经纬度信息的简单对象。

字段| 类型  
---|---  
Latitude| 数值型  
Longitude| 数值型  
  
# 2 属性

属性| 类型| 描述  
---|---|---  
center| LatLng| 圆心的坐标。  
radius| 数值型| 待绘制的圆形的半径，单位为米。  
strokeWidth| 数值型| 线条宽度，单位为像素。  
strokeColor| 字符串| 线条颜色。  
fillColor| 字符串| 填充颜色。  
zIndex| 数值型| 该瓦片覆盖物相对于其他覆盖物的绘制顺序。Z指标值较大的覆盖物绘制在Z指标值较小的覆盖物之上。Z指标值相同的覆盖物的绘制顺序随机。默认的Z指标值是0。  
geodesic| Boolean| 表示是否将折线的每一段绘制成与墨卡托投影中直线相对的测地线。测地线表示在地表上两点之间的最短路径。绘制测地线曲线时假设地球是一个球体。
