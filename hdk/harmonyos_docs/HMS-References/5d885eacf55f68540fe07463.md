# com.huawei.hms.dtm  
  
包含自定义变量实现接口、自定义模板实现接口以及预览界面实现类。

## Interfaces

[AdParam.ErrorCode](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-adparam-errorcode "AdParam.ErrorCode")| 广告请求错误码。  
---|---  
[ICustomVariable](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/24055276 "AudioFocusType")| DTM函数调用变量实现接口。  
[ICustomTag](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/22655229)| DTM函数调用模板实现接口。  
  
## Classes

[AdListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-adlistener "AdListener")| 接受广告状态的监听器。  
---|---  
[PreviewActivity](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/78535605)| 预览界面，用于下载网页新配置的未发布的tag容器版本。
