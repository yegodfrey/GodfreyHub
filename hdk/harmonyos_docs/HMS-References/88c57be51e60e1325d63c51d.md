# 1 属性  
  
属性| 类型| 描述  
---|---|---  
tooltip| Boolean| 如果该属性设置为false，则在该信息窗周围会绘制一个tooltip气泡窗口。如果该属性设置为true，子视图外观可以完全自定义，包括定义成任意气泡样式。  
  
# 2 事件

事件名| 返回值| 描述  
---|---|---  
onPress| -| 用户点击信息窗时调用的回调。
