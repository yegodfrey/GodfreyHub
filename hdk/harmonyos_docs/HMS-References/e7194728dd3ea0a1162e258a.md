com.huawei.hms.mlsdk.productvisionsearch.cloud.MLRemoteProductVisionSearchAnalyzer  
拍照购检测器：用于在提供的图像中，识别商品信息。拍照购检测器,调用云端API，检测模型在云端运行。创建拍照购检测器有两种方式，根据实际情况二选一。  
      
      1. // 方式1：使用默认的参数配置  
        2.     MLRemoteProductVisionSearchAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteProductVisionSearchAnalyzer();  
        3. // 方式2：使用自定义的参数配置  
        4.     MLRemoteProductVisionSearchAnalyzer analyzer =  MLAnalyzerFactory.getInstance().getRemoteProductVisionSearchAnalyzer(setting);
