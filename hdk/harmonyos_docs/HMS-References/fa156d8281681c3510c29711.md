# 1 数据类型

  * **LatLng**




包含经纬度信息的简单对象。

字段| 类型  
---|---  
Latitude| 数值型  
Longitude| 数值型  
  
# 2 属性

属性| 类型| 描述  
---|---|---  
image| ImageSource| 覆盖物的自定义图标。仅支持本地图片资源以及URI（网络图片的地址）。  
bounds| Array<LatLng>| 图片的坐标（左上角和右下角）。即，[[lat, long], [lat, long]]。  
tappable| Boolean| 表示覆盖物是否可点击并使用onPress功能。  
opacity| 数值型| 覆盖物的不透明度。  
  
# 3 事件

事件名| 返回值| 描述  
---|---|---  
onPress| -| 用户点击覆盖物时调用的回调。
