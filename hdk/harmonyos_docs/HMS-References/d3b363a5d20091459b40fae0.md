public abstract Set<String> getBarrierLabels()  
获取BarrierStatusMap中所有围栏的键值的集合。  
  
**Return**

Type| desc  
---|---  
Set<String>| 围栏键值的集合。

public abstract BarrierStatus getBarrierStatus(String barrierKey)  
根据给定的围栏参数得到围栏状态。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
barrierKey| 围栏参数，用于指定某个具体围栏。  
  
  
**Return**  


Type| desc  
---|---  
BarrierStatus| 围栏状态，如果没有得到围栏状态，则返回null。
