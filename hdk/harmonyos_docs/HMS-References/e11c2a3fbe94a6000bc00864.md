# Public Methods

## **public Task<Intent> getShowAchievementListIntent()**

获取包含当前玩家的所有游戏成就列表的数据界面。仅在用户查看成就列表时调用。

**返回值**  
返回成就列表界面的Intent对象，应用可以使用startActivityForResult方法拉起成就列表界面。  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception "ApiException")实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理，返回码参见[通用返回码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/game-return-code-v4 "通用返回码")。

**调用示例**
    
    
     复制
      
        1. private final static int REQUEST_CODE = 3000;
        2.  client.getShowAchievementListIntent().addOnSuccessListener(new OnSuccessListener<Intent>() {
        3.      @Override
        4.     public void onSuccess(Intent intent) {
        5.          startActivityForResult(intent, REQUEST_CODE);
        6.      }
        7.  });
    
    

## **public void grow(String id, int numSteps)**

以异步方式增加当前玩家对某个成就的当前步长，例如某个成就需5步完成，玩家从第2步完成到第3步，则需要调用此方法将成就的当前步长增加1步。需增加步长的成就必须是一个分步成就并且还未解锁。一旦玩家达到了成就当前的最大步长，此成就将自动解锁，再调用本方法增加步长时请求将被忽略。  
本方法的提交方式为异步提交，即应用客户端调用本方法时如果设备无网络，HMS SDK会先将数据缓存在本地，待网络恢复后用户再次登录时提交到华为服务器。开发者无需关注此方法的执行结果。  
如果您需要立即增加成就的步长或想要了解方法的执行结果，请使用growWithResult方法。

**请求参数**

参数名| 参数说明  
---|---  
id| 需要增加步长的成就ID。  
numSteps| 需要增加的步长数，值必须大于0。

本方法的提交方式为同步提交，即应用客户端调用本方法后将立即向华为服务器发送请求，并返回执行结果。

**请求参数**

---|---  
id| 需要增加步长的成就ID。  
numSteps| 需要增加的步长数，值必须大于0。  
  
**返回值**  
返回执行结果，true表示执行成功，false表示接口调用成功但执行失败，请检查成就ID与设置的步数是否准确。  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception "ApiException")实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理，返回码参见[通用返回码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/game-return-code-v4 "通用返回码")。  
如果增长后的步数刚好达到成就的最大步数，HMS SDK将返回7202返回码，表示增长步数后自动触发解锁成就，属于增长成功。
