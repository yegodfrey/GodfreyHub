# **接口功能**

查询Beacon下面所有已配置的Attachment。

# **调用场景**

调用此接口查询Beacon下面所有配置的Attachment的信息。

# **接口原型**

**承载协议**|  HTTPS POST  
---|---  
**接口方向**|  应用服务器或APP应用->近距离通信服务器  
**接口URL**|  https://{域名}/WiseCloudNearbyBeaconService/v1/queryBeaconAttachment/{beaconId}?projectId=[projectId]  
**数据格式**|  Content-type: application/json  
  
# **接口约束**

  * 需要获取服务账号凭证；

  * Beacon设备需要处于激活状态。




# **请求参数**

**参数名称**| **必选(M)/可选(O)**| **类型**| **参数说明**  
---|---|---|---  
timeStamp| M| Long| 请求头参数，时间戳。  
srcTranID| M| String| 请求头参数，事务ID，最长为24个字符。  
Authorization| M| String| 请求头参数，用于网关认证，请参考[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-common-service-account)获取JWT。  
projectId| O| String| 查询参数。  
beaconId| M| String| 路径参数。Beacon设备的ID。  
  
# **返回参数**

请求成功，状态码200，响应体如下：

**参数名称**| **类型**| **参数说明**  
---|---|---  
attachments| Json object| Attachment结构体的列表，Attachment具体见下面Attachment结构体定义。  
  
Attachment结构体定义：
    
    
    复制
      
        1. {
        2. "namespace": "namespace002",
        3. "attachmentId": "202001191739115580278122214157680128",
        4. "type": "4",
        5. "value": "5oiR5piv5Lit5Zu95Lq6qw"
        6. }
    
    

**参数值**| **类型**| **功能**  
---|---|---  
attachmentId| String| Attachment的ID，在配置Attachment时由系统自动生成。  
namespace| String| Attachment对应的Namespace。  
type| String| 消息类型。  
value| String| Attachment内容，base64编码字符串。  
  
请求失败，状态码非200，响应体如下：

(1) 非业务(网关校验失败、token过期等情况)请求失败时：

**参数名称**| **类型**| **参数说明**  
---|---|---  
error| String| 非业务返回错误信息。  
  
(2) 业务请求失败时：

**参数名称**| **类型**| **参数说明**  
---|---|---  
serviceError| object| 业务返回的错误信息。  
  
serviceError的JSON结构体为：

**参数名称**| **类型**| **参数含义**  
---|---|---  
code| int| 错误码，错误码描述见返回码。  
status| String| 错误状态。  
message| String| 错误描述信息。  
  
# **返回码**

**错误码**| **错误码含义**| **建议业务处理方式**  
---|---|---  
400000001| 请求头参数不对。| 检查请求头参数。  
400000009| 当前Beacon未激活。| 激活当前Beacon。  
403000003| 服务账号不可用。| 切换成可用的服务账号操作。  
403000004| 没有权限操作此Beacon。| 检查当前Beacon所有者。  
404000006| 当前Beacon不存在。| 检查请求参数。  
500000001| 内部服务错误。| 建议重试，重试仍失败则反馈该问题。
