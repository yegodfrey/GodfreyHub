public interface AccountAuthService  
AppTouch ID登录客户端。注意：AppTouch ID 未发布，待发布后此接口可用。  
  
## Public Method Summary

Intent| getSignInIntent()获取登录授权页面的Intent，可以通过startActivityForResult拉起授权页面。  
---|---  
Task<[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-authaccount)>| silentSignIn()静默授权，该接口不会拉起授权页面。  
Task<Void>| signOut()登出。  
Task<Void>| cancelAuthorization()取消授权。
