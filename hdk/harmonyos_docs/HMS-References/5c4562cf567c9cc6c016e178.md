RankingScores类返回排行榜分数列表及分数所在的排行榜信息。

# Public Method Summary

Return| Method  
---|---  
[Ranking](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ranking)| getRanking()获取分数所在的排行榜信息。  
List<[RankingScore](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingscore)>| getRankingScores()获取所有分数信息。  
  
# Public Methods

## public Ranking getRanking()

获取分数所在的排行榜信息，以[Ranking](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ranking)对象形式返回。

**返回值**

Type| Description  
---|---  
[Ranking](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ranking)| 排行榜信息。  
  
## public List<RankingScore> getRankingScores()

获取所有分数信息，以[RankingScore](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingscore)对象形式返回。

**返回值**

Type| Description  
---|---  
List<[RankingScore](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingscore)>| 所有分数信息。
