public static BitmapDescriptor defaultMarker(float hue)  
根据不同的色值来创建不同颜色的默认[Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker)图标的[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-bitmapdescriptor)对象。  
本类提供了10个颜色的[Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker)图标，开发者可以通过传入本类的字段来调用，请参考本类的公共字段。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
hue| 颜色常量。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-bitmapdescriptor)| BitmapDescriptor对象。
