# Public Methods  


## public abstract Task<ArchiveSummary> addArchive(ArchiveDetails details, ArchiveSummaryUpdate update, boolean isSupportCache)

以异步方式提交存档记录，只增加存档。

本方法的提交方式为异步提交，即应用客户端调用本方法时如果设备无网络，HMS SDK会先将数据缓存在本地，待网络恢复后用户再次登录时提交到华为服务器。开发者无需关注此方法的执行结果。

**请求参数**

Parameter Name| Parameter Description  
---|---  
update| 包含存档元数据变更的[ArchiveSummaryUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivesummaryupdate)对象。  
details| 包含存档文件内容的[ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)对象。  
isSupportCache| 是否支持网络异常时先缓存到本地，待网络恢复后再提交。

  * true：是
  * false：否

  
  
**返回值**  


Type| Description  
---|---  
Task<[ArchiveSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivesummary)>| 提交后的存档元数据。如果存档元数据没有打开，或已经提交，将返回异常。  
  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception)实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。

## public abstract Task<OperationResult> loadArchiveDetails(ArchiveSummary summary, int diffStrategy)

使用指定的冲突策略打开存档元数据。如果存在冲突则需要先解决冲突后再打开。

**请求参数**

Parameter Name| Parameter Description  
---|---  
summary| 需要打开的现有存档元数据对象，[ArchiveSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivesummary)对象一般从[getArchiveSummaryList](httpgetArchiveSummaryList)方法中获取。  
diffStrategy| 冲突策略。

  * [ArchiveConstants.STRATEGY_SELF](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archiveconstants#STRATEGY_SELF)：华为游戏服务器不处理冲突，由开发者自行通过[updateArchive](httpupdateArchive)方法自行处理冲突。
  * [ArchiveConstants.STRATEGY_ACTIVE_TIME](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archiveconstants#STRATEGY_ACTIVE_TIME)：游戏时长，在冲突的两个存档中使用游戏时长较长的存档处理冲突。
  * [ArchiveConstants.STRATEGY_TOTAL_PROGRESS](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archiveconstants#STRATEGY_TOTAL_PROGRESS)：最近修改版本，在冲突的两个存档中使用最近修改的存档处理冲突。
  * [ArchiveConstants.STRATEGY_LAST_UPDATE](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archiveconstants#STRATEGY_LAST_UPDATE)：最高的进度，在冲突的两个存档中使用进度较高的存档处理冲突。

  
  
**返回值**  


Type| Description  
---|---  
Task<[OperationResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/operationresult)>| 如果[OperationResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/operationresult)对象的isDifference()返回true，表示打开存档时发生冲突，需要使用[updateArchive](httpupdateArchive)方法来解决冲突。如果[OperationResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/operationresult)对象的isDifference()返回false，表示不存在冲突，则可以从[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)[OperationResult.getArchive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/operationresult#getArchive)中获取返回的存档元数据和内容。  
  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception)实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。
