CLASS info

public class CryptoObject extends java.lang.Object  
与指纹认证或3D面容认证关联的加密对象的包装类。目前框架支持Signature、Cipher和Mac对象。

Method name

**CryptoObject**(java.security.Signature signature)

**CryptoObject**(javax.crypto.Mac mac)
