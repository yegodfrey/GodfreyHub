# 获取时区

## 1\. 使用样例

请求消息：
      
      1. POST https://siteapi.cloud.huawei.com/mapApi/v1/timezoneService/getTimezone?key=API KEY   HTTP/1.1 
        2. Content-Type: application/json 
        3. Accept: application/json 
        4. {
        5.     "location": {
        6.         "lng": "30.23235",
        7.         "lat": "12.242585"
        8.     },
        9.     "timestamp": 1577435043,
        10.     "language": "en"
        11. }
    
    

 响应消息：
      
      1. {
        2.     "returnCode": "0",
        3.     "timeZoneName": "Eastern African Time",
        4.     "rawOffset": 10800,
        5.     "timeZoneId": "Africa/Khartoum",
        6.     "dstOffset": 0,
        7.     "returnDesc": "OK"
        8. }
    
    

## 2\. 请求参数

> POST  https://siteapi.cloud.huawei.com/mapApi/v1/timezoneService/getTimezone?key=API KEY

  


注意：

使用API KEY需要进行**encodeURI** 编码。例如：原始API KEY：**ABC/DFG+** ，转换结果：**ABC%2FDFG%2B** 。

  


**参数名称**| **必选(M)/可选(O)**| **参数类型**| **参数说明**  
---|---|---|---  
location| M| [Coordinate](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-paramdescription#h2-1583152160165)| 经纬度。  
timestamp| M| Long| 距离UTC 1970年1月1日0点0分0秒的秒数。  
language| O| String(<=6)| 搜索结果的语种。如果不传，使用地点的当地语言。语种取值请参考[语种映射](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-site-language)列表。  
  
## 3\. 返回参数  


**参数名称**| **必选(M)/可选(O)**| **参数类型**| **参数说明**  
---|---|---|---  
returnCode| M| String| 返回码，具体请参考“[返回码](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-site-result-code)”。  
returnDesc| O| String| 返回值描述。  
dstOffset| O| int| 夏令时的偏移量，单位是秒。如果给定的timestamp不在夏令时里，返回0。  
rawOffset| O| int| 给定位置与UTC的偏移量（以秒为单位）。  
timeZoneId| O| String| 时区ID。例如“ America   / Los_Angeles”或“   Australia / Sydney”这些ID由Unicode [公共区域数据存储库（CLDR）项目定义](http://cldr.unicode.org/)。可以参见GitHub上的[链接](https://github.com/unicode-org/cldr/blob/master/common/bcp47/timezone.xml)。  
timeZoneName| O| String| 时区名称。比如太平洋夏令时。
