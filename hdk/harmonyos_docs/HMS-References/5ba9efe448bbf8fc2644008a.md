public abstract class DiscoveryEngine

public abstract Task<Void> acceptConnect(String endpointId, [DataCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-transfer-datacallback) dataCallback)  
接受连接，在数据传输前必须调用此接口确认，[STATUS_SUCCESS](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_SUCCESS): 表示接受此连接，[STATUS_ALREADY_CONNECTED](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_ALREADY_CONNECTED): 表示应用程序已经连接到该端点。  
  
Parameters

Parameter name| Parameter desc  
---|---

public abstract Task<Void> requestConnect(String name, String endpointId, [ConnectCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-discovery-connectcallback) connectCallback)  
请求连接。  
[STATUS_SUCCESS](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_SUCCESS): 连接请求发送完成；  
[STATUS_ALREADY_CONNECTED](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_ALREADY_CONNECTED): 应用程序已经连接到该端点；  
[STATUS_BLUETOOTH_OPERATION_FAILED](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_BLUETOOTH_OPERATION_FAILED): 由于蓝牙的问题导致连接失败；  
[STATUS_FAILURE](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_FAILURE): 其他原因导致连接失败。  
  
Parameters

Parameter name| Parameter desc  
---|---  
name| 本地设备名称  
endpointId| 远端设备的endpointId  
connectCallback| 连接监听回调

---  
public abstract Task<Void> startBroadcasting(String name, String serviceId, [ConnectCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-discovery-connectcallback) connectCallback, [BroadcastOption](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-discovery-broadcastoption) option)  
启动发送广播消息，返回状态描述如下，  
[STATUS_SUCCESS](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_SUCCESS):启动广播成功；  
[STATUS_ALREADY_BROADCASTING](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_ALREADY_BROADCASTING): 应用正在广播中；  
[STATUS_API_DISORDER](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_API_DISORDER): 连接当前已经建立，先调用disconnectAll()。  
  
Parameters

Parameter name| Parameter desc  
---|---  
name| 本地设备名称  
serviceId| 服务id，用于标识自己的服务，推荐使用应用包名  
connectCallback| 连接监听回调，用于监听对端连接请求事件  
option| 广播选项设置，一般为连接策略设置  
Method  
---  
public abstract Task<Void> startScan(String serviceId, [ScanEndpointCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-discovery-scanendpointcallback) scanEndpointCallback, [ScanOption](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-discovery-scanoption) option)  
启动发现特定服务ID，返回状态描述如下，  
[STATUS_SUCCESS](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_SUCCESS):启动发现成功；  
[STATUS_ALREADY_SCANNING](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_ALREADY_SCANNING): 应用已经发现了服务；  
[STATUS_API_DISORDER](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-nearby-StatusCode#STATUS_API_DISORDER): 连接当前已经建立，先调用disconnectAll()。  
  
Parameters

scanEndpointCallback| 发现监听回调，发现对端设备时触发回调  
option| 扫描选项设置，一般为连接策略设置
