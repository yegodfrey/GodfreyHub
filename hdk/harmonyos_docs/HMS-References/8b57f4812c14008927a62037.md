com.huawei.hms.mlsdk.face.MLMaxSizeFaceTransactor  
最大人脸处理器，在某一时刻只处理图像中面积最大的人脸。（此接口使用方法请参考Github上的[微笑抓拍神器](https://github.com/HMS-Core/hms-ml-demo/tree/master/Smile-Camera "微笑抓拍神器")）  
  
## Sample Code
      
      1. // 创建人脸分析器。
        2. MLFaceAnalyzer analyzer = MLAnalyzerFactory.getInstance().getFaceAnalyzer();
        3. // 创建最大人脸处理器，用于筛选出一张最大的人脸，将结果传递给MLResultTrailer处理。MLResultTrailer是一个基类，需要开发者根据业务逻辑继承实现。
        4. MLMaxSizeFaceTransactor transactor = new MLMaxSizeFaceTransactor.Creator(analyzer, new MLResultTrailer<MLFace>()).create();
        5. analyzer.setTransactor(transactor);
        6. // 该处理器仅用于实时视频检测，对单张图像检测无效。
        7. LensEngine lensEngine = new LensEngine.Creator(context, analyzer)
        8.    .applyDisplayDimension(640, 480)
        9.    .create();
