public static synchronized HmsMessaging getInstance(Context context)  
获取HmsMessaging类实例，开发者在使用主题订阅等功能前需要先获取HmsMessaging类实例然后才能调用类中的其他方法。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
context| 应用上下文。应用集成HMS SDK最新版本需要满足HMS Core（APK）的版本不低于3.0.0。如果低于3.0.0版本，当应用有前台界面时HMS SDK会提示用户升级HMS Core（APK）为最新版本，此时getInstance的入参必须传入Activity类实例；当应用是后台应用时，如果开发者不想弹出引导升级的页面时，可以传入非Activity类型的Context类实例。  
  
  
**Return**  


type| desc  
---|---  
HmsMessaging| 实例对象。

public Task< Void > subscribe(String topic)  
异步任务订阅指定的主题消息。HUAWEI Push Kit主题消息传递功能可让您将消息发送至已经选择加入特定主题的多台设备。开发者根据需要撰写主题消息，HUAWEI Push Kit负责确定发布路径并将消息可靠地传送至正确的设备。此接口为异步操作接口，开发者需要添加对应的侦听器来侦听任务执行结果。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
topic| 要订阅的主题的名称。必须匹配以下正则表达式：[\u4e00-\u9fa5\w-_.~%]{1,900}  
  
  
**Throws**  


Throw name| Throw desc  
---|---  
IllegalArgumentException| 无效的主题名称，主题名必须匹配以下正则表达式：[\u4e00-\u9fa5\w-_.~%]{1,900}  
  
  
**Return**  


type| desc  
---|---  
Task< Void >| 接口调用结果为[Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/task-tresult)< Void >，开发者需要添加对应的侦听器来侦听任务执行结果。  
  
**Sample Code**
         
         1.  public void subscribe(String topic) {
              2.     try {
              3.         HmsMessaging.getInstance(context).subscribe(topic)
              4.         .addOnCompleteListener(new OnCompleteListener<Void>() {
              5.             @Override
              6.             public void onComplete(Task<Void> task) {
              7.                 if (task.isSuccessful()) {
              8.                     Log.i(TAG, "subscribe Complete");
              9.                 } else {
              10.                     Log.e(TAG, "subscribe failed: ret=" + task.getException().getMessage());
              11.                 }
              12.             }
              13.         });
              14.     } catch (Exception e) {
              15.         Log.e(TAG, "subscribe failed: exception=" + e.getMessage());
              16.     }
              17. }
