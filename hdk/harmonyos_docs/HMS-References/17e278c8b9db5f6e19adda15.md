public final class AwarenessStatusCodes extends Object  
情景感知状态码。  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
int| AWARENESS_SUCCESS_CODE| 成功。  
int| AWARENESS_UNKNOWN_ERROR_CODE| 未知的错误。  
int| AWARENESS_BINDER_ERROR_CODE| binder为空导致bind服务失败。  
int| AWARENESS_REGISTER_FAILED_CODE| 注册围栏失败。  
int| AWARENESS_TIMEOUT_CODE| 超时错误。例如，更新围栏超时，获取时间属性超时，获取信标状态超时，bind服务连接超时，等待Intent超时等。  
int| AWARENESS_COUNT_LIMIT_CODE| 次数限制错误（例如，单cp访问围栏达到最大次数限制。其中，围栏次数限制为200次）。  
int| AWARENESS_FREQUENCY_LIMIT_CODE| 访问围栏或快照频率限制（接口访问频率限制为1000次/小时或20次/5秒，5秒累计注册围栏限制500次）。  
int| AWARENESS_BARRIER_PARAMETER_ERROR_CODE| 围栏参数无效错误（addBarrier入参有误）。  
int| AWARENESS_REQUEST_ERROR_CODE| 请求参数错误（updateBarriers入参有误）。  
int| AWARENESS_AGC_FILE_ERROR| AGC文件错误。  
int| AWARENESS_RESULT_INVALID_ERROR| 从Awarreness Kit返回的结果无效。例如，获取耳机状态未知。  
int| AWARENESS_REMOTE_EXCEPTION_ERROR| bind方法抛remote异常。  
int| AWARENESS_WAIT_CALLBACK_CODE  
| 等待service端回调  
int| AWARENESS_INTERFACE_INVALID| 请求的接口已不再提供服务。  
int| AWARENESS_NO_ENOUGH_RESOURCE| 系统没有足够的资源。  
int| AWARENESS_SDK_VERSION_ERROR| SDK版本错误，需要检查SDK版本是否大于等于24。  
int| AWARENESS_LOCATION_PERMISSION_CODE| APP中定位权限被禁止。  
int| AWARENESS_LOCATION_CORE_PERMISSION_CODE| 华为移动服务定位权限被禁止。  
int| AWARENESS_BEHAVIOR_PERMISSION_CODE| APP中活动识别权限被禁止。  
int| AWARENESS_BLUETOOTH_PERMISSION_CODE| APP中未申请蓝牙权限。  
int| AWARENESS_LOCATION_NOCACHE_CODE| location无缓存。  
int| AWARENESS_LOCATION_NOT_AVAILABLE_CODE| location服务找不到。  
int| AWARENESS_BEACON_NOT_AVAILABLE_CODE| 信标服务找不到。  
int| AWARENESS_BLUETOOTH_NOT_AVAILABLE_CODE| 蓝牙服务找不到。  
int| UPDATE_KIT_CODE| 情景感知服务需要更新。  
int| UPDATE_HMS_CODE| 华为移动服务需要更新。
