## 概览

用来在地图上添加HWOverlay。

## 构造方法

**构造方法**| **描述**  
---|---  
HWMapJsSDK. HWOverlay(overlayOptions)| overlayOptions用来设置Overlay的属性，见OverlayOptions。  
  
## 公共方法

**方法名**| **描述**| **参数类型**| **返回值**  
---|---|---|---  
getMap()| 获取HWOverlay的所在的HWMap对象。| 无| [HWMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-map)  
setMap(map)| 绑定到地图。| [HWMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-map)| 无  
getContent()| 获取Overlay内容。| 无| String | Element  
  
setContent(content)| 设置Overlay内容。| String | Element| 无  
getPosition()| 获取路径。| 无| [](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)[LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)  
setPosition(position)| 设置路径。| [LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)| 无  
getStopEvent()| 获取是否支持穿透。| 无| [](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)boolean  
setStopEvent(stopEvent)| 设置是否支持穿透。| boolean| 无  
  
## OverlayOptions

**参数名**| **必选(M)/****可选(O)**| **数据类型**| **描述**  
---|---|---|---  
map| M| [HWMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-map)| 地图实例。  
position| M| [LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)| 用于设置HWOverlay的位置。  
content| O| String | Element| 弹出框中的显示内容，可以是纯文本或者是HTML元素。窗口会根据内容自动调整大小。调用该接口需要注意跨站脚本攻击，SDK中没有过滤有可能导致xss的html代码，因为作为SDK无法区分是否开发者主动使用。  
offset| O| [Number,Number]| 设置x,y偏移量。默认位置是position指定的位置。  
stopEvent| O| Boolean| 用于设置HWOverlay是否支持穿透，穿透表示不阻止事件，即鼠标事件在HWOverlay上可以穿透到地图上。true表示不支持穿透，false表示支持穿透，默认为true。
