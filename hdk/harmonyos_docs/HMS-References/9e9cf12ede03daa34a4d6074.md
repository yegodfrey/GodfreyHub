class info

public interface InstallReferrerStateListener  
建立服务链接的回调接口；当与服务完成建立时，将调用此侦听器的onInstallReferrerSetupFinished(int)方法。  
  
## Public Method Summary

Return type| Method name  
---|---  
abstract void| onInstallReferrerServiceDisconnected()当服务断开连接时该方法被调用以通知监听者。  
  
abstract void| onInstallReferrerSetupFinished(int responseCode)当连接服务完成时调用以通知监听者，其中responseCode描述。  
  
  
## Public Methods

Method  
---  
public abstract void onInstallReferrerServiceDisconnected()  
当服务断开连接时该方法被调用以通知监听者。  
Method  
---  
public abstract void onInstallReferrerSetupFinished(int responseCode)  
当连接服务完成时调用以通知监听者，其中responseCode描述。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
responseCode| 连接响应状态。  
-1：连接服务失败。0：连接服务成功。1：服务不存在。2：服务不支持。3：开发者调用错误。

     复制
      
        1. InstallReferrerClient referrerClient;
        2. ...
        3. referrerClient = InstallReferrerClient.newBuilder(this).setTest(true).build();
        4.     /**
        5.      * Create a listener.
        6.      */
        7.     private InstallReferrerStateListener installReferrerStateListener = new
        8.             InstallReferrerStateListener() {
        9.                 @Override
        10.                 public void onInstallReferrerSetupFinished(int responseCode) {
        11.                     switch (responseCode) {
        12.                         case InstallReferrerClient.InstallReferrerResponse.OK:
        13.                             //Connected to the service.
        14.                             break;
        15.                         case InstallReferrerClient.InstallReferrerResponse.FEATURE_NOT_SUPPORTED:
        16.                             // API not available on the current app.
        17.                             break;
        18.                         case InstallReferrerClient.InstallReferrerResponse.SERVICE_UNAVAILABLE:
        19.                             // Connection could not be established.
        20.                             break;
        21.                     }
        22.                 }
        23.                 @Override
        24.                 public void onInstallReferrerServiceDisconnected() {
        25.                     // Try to restart the connection calling the startConnection() method.
        26.                 }
        27.             };
