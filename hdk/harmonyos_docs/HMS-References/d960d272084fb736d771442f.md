class info

com.huawei.hms.mlsdk.asr.MLAsrRecognizer  
语音识别器。通过startRecognizing (Intent intent)开始收听识别语音，开始前需要先设置监听器setAsrListener(MLAsrListener listener)。  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
String| RESULTS_RECOGNIZED| 用于标记语音识别结果中的文本信息对应的Key值；在onResults()中，用户通过该key值从Bundle中获取语音识别器识别到的文本。  
String| RESULTS_RECOGNIZING| 用于标记语音识别过程中识别到的文本信息对应的Key值；在onRecognizingResults()中，用户通过该key值从Bundle中获取语音识别器识别到的文本。
