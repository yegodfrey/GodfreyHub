存储上报数据的map。

# 1 EVENT_KEY

字符串常量，值为“event”，DataBundle中key为“event”对应的数据都会通过OnPushListener上报。

# 2 get(String key):Object

## 2.1 接口描述

返回Bundle中key对应的对象，如果key没找到，则返回null。

## 2.2 调用示例
    
    
    复制
      
        1. DataBundle mDataBundle = new DataBundle(new WeOnPushListener());
        2. Object object = mDataBundle.get("event");
    
    

## 2.3 请求参数

参数名称| 参数类型| 备注  
---|---|---  
key| String| Bundle中数据对应的key  
  
## 2.4 返回值

返回Bundle中key对应的对象，如果key没找到，则返回null。

# 3 toList(Object... objects):List<Object>

## 3.1 接口描述

以objects为基础，创建List的工具方法。

## 3.2 调用示例
    
    
    复制
      
        1. Object objArray = {"a","b","java","spring","hadoop","lucene"};
        2. List<Object> objList = DataBundle.toList(objArray);
    
    

## 3.3 请求参数

参数名称| 参数类型| 备注  
---|---|---  
objects| Object...| 生成的List将包含objects中的元素  
  
## 3.4 返回值

返回一个包含objects中所有元素的List。

# 4 toMap(Object... objects):Map<String, Object>

## 4.1 接口描述

以objects为基础，创建Map的工具方法。

## 4.2 调用示例
    
    
    复制
      
        1. Object objArray = {"a","b","java","spring","hadoop","lucene"};
        2. Map<Object> objList = DataBundle.toMap(objArray);
    
    

## 4.3 请求参数

参数名称| 参数类型| 备注  
---|---|---  
objects| Object...| objects必须是key-value形式的数组  
  
## 4.4 返回值

返回以objects key-value构建的map。

# 5 put(Map<String, Object> update):void

## 5.1 接口描述

把update合并到DataBundle中。

## 5.2 调用示例
    
    
    复制
      
        1. Map objupdate = new HashMap();
        2. objupdate.put("1", "one");
        3. objupdate.put("2", "two");
        4. DataBundle dataBundle = new DataBundle(new WeOnPushListener());
        5. dataBundle.put(objupdate);
    
    

## 5.3 请求参数

参数名称| 参数类型| 备注  
---|---|---  
update| Map<String, Object>| objects必须是key-value形式的数组  
  
## 5.4 返回值

无。

# 6 put(String key, Object value):void

## 6.1 接口描述

把key-value数据合并到DataBundle中。

## 6.2 调用示例
    
    
    复制
      
        1. DataBundle dataBundle = new DataBundle(new WeOnPushListener());
        2. dataBundle.put("1", "one");
    
    

## 6.3 请求参数

参数名称| 参数类型| 备注  
---|---|---  
key| String| 无  
value| Object| 无  
  
## 6.4 返回值

无

# 7 putEvent(String event, Map<String, Object> update):void

## 7.1 接口描述

把event和update合并到DataBundle中。

## 7.2 调用示例
    
    
    复制
      
        1. Map objupdate = new HashMap();
        2. objupdate.put("1", "one");
        3. objupdate.put("2", "two");
        4. DataBundle dataBundle = new DataBundle(new WeOnPushListener());
        5. dataBundle.putEvent("event", objupdate);
    
    

## 7.3 请求参数

参数名称| 参数类型| 备注  
---|---|---  
event| String| 无  
update| Map<String, Object>| 无  
  
## 7.4 返回值

无。

# 8 toString():String

## 8.1 接口描述

返回一个人类可读的字符串，描述这个DataBundle

## 8.2 调用示例
    
    
    复制
      
        1. Map objupdate = new HashMap();
        2. objupdate.put("1", "one");
        3. objupdate.put("2", "two");
        4. DataBundle dataBundle = new DataBundle(new WeOnPushListener());
        5. dataBundle.pushEvent("event", objupdate);
        6. dataBundle.toString();
    
    

## 8.3 请求参数

无。

## 8.4 返回值

返回一个字符串，来描述这个DataBundle。
