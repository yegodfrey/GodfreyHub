**public   interface TileProvider**  
  
接口类，为类[TileOverlay](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-tileoverlay)提供瓦片图像。 调用这个接口的方法可能会存在多线程，所以实现时注意线程安全。

public abstract Tile getTile(int x, int y, int zoom)  
开发者调用此API可以获取指定坐标和缩放级别下的瓦片图层对象。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
x| tile的横坐标，范围为[0, 2zoom \- 1]。  
y| tile的纵坐标，范围为[0, 2zoom \- 1]。  
zoom| 瓦片的缩放级别，范围通过类[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)的getMinZoomLevel()和getMaxZoomLevel()获得。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
[Tile](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-tile)| 指定坐标和缩放级别下的Tile对象。
