#### enableLog(int level)

Method  
---  
public static void enableLog(int level)打开调试日志，可自定义打印的最小日志级别。调试日志：

  * Log.DEBUG(3)
  * Log.INFO(4)
  * Log.WARN(5)
  * Log.ERROR(6)

  
  
**Parameters**

Name| Description  
---|---  
level| 开启指定级别的调试日志。日志级别：Log.DEBUG,Log.INFO,Log.WARN,Log.ERROR。
