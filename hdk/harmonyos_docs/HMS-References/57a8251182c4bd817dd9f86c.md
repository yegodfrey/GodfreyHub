## Classes  
  
Class name| Class description  
---|---  
[BeaconId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-beaconid)| Beacon ID(BLE广播，可以是iBeacon或者Eddystone类型)  
[Message](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-message)| nearby设备共享的消息类，消息包含客户端定制的内容和类型  
[MessagePicker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-messagepicker)| 用于指定要接收的消息集。近场扫到sharingcode后，MessagePicker需要做匹配，多个过滤器中，任何一个匹配成功就认为匹配  
[MessageHandler](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-messagehandler)| 信号变化、距离变化、订阅消息发现和丢失，都会触发调用该回调  
[MessageOption](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-messageoption)| 针对Message API的配置参数信息  
[Permission](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-permission)| Nearby权限，调用推送Message#Put和获取Message#Get接口时，需要匹配相对应的请求权限  
[StatusCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-statuscallback)| MessageEngine状态信息改变后回调此函数  
[Policy](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-policy)| 定义了一系列策略用于#Put或#Get消息  
[PutOption](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-putoption)| 调用#Put时的参数  
[PutCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-putcallback)| 推送（#Put）消息回调函数  
[GetOption](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-getoption)| 调用#Get时的参数  
[GetCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-getcallback)| 获取（#Get）消息回调函数  
[MessageEngine](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-messageengine)| 定义了一系列API，应用可以通过#Put/#Get实现消息在近场设备间的传输
