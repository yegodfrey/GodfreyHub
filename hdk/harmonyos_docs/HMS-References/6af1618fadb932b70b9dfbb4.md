public VideoConfiguration.Builder setCustomizeOperateRequested(boolean customizeOperateRequested)  
设置是否使用视频广告的自定义视频控件。  
使用VideoConfiguration.isCustomizeOperateRequested()验证加载的视频广告是否启用了自定义视频控件。验证后，您可以使用VideoOperator.play()，VideoOperator.pause()和VideoOperator.mute(boolean)来控制视频广告。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
customizeOperateRequested| 是否请求自定义视频控件。
