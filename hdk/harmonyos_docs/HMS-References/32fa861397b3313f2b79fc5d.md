# BleController  
  
**CLASS info**  
---  
public class BleController  
用于扫描和使用低功耗蓝牙设备。支持扫描和保存设备信息，设备保存后，可以通过 SensorsController和AutoRecorderController 获取设备数据。  
  
#### Public Constructor Summary

**Constructor name**  
---  
BleController() BleController构造器。  
  
#### Public Method Summary

**Return** | **Method**  
---|---  
Task<Void> | saveDevice(String deviceAddress) 通过设备地址保存设备。  
Task<Void> | saveDevice(BleDeviceInfo bleDeviceInfo) 通过设备信息保存设备。  
Task< List<BleDeviceInfo> > | getSavedDevices() 列出当前用户已经保存的所有设备。  
Task<Void> | beginScan(List<DataType> dataTypes, int timeoutSecs, BleScanCallback callback) 开始扫描对应的设备。  
Task<Boolean> | endScan(BleScanCallback callback) 结束当前的扫描。  
Task<Void> | deleteDevice(String deviceAddress) 通过设备地址将设备删除。  
Task<Void> | deleteDevice(BleDeviceInfo bleDeviceInfo) 通过设备信息将设备删除。  
  
#### Public Methods

#### [h2]saveDevice(String deviceAddress)

**Method**  
---  
public Task<Void> saveDevice(String deviceAddress)  
使用设备地址将设备与当前用户绑定并且保存设备。  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
deviceAddress | 待保存的设备地址。  
  
示例代码如下：
    
    
    // 创建一个BleController 对象用于扫描远端蓝牙设备 
        private BleController mBleController; 
     
     
        @Override 
        protected void onCreate(@Nullable Bundle savedInstanceState) { 
            super.onCreate(savedInstanceState); 
            setContentView(R.layout.activity_hihealth_sensor); 
            logInfoView = (TextView) findViewById(R.id.sensor_controller_log_info); 
            logInfoView.setMovementMethod(ScrollingMovementMethod.getInstance()); 
     
            // 进入界面时首先获取BleController 
            HiHealthOptions options = HiHealthOptions.builder().build(); 
     
            // 登录华为ID 
            AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options); 
     
            // 获取BleController 
            mBleController = HuaweiHiHealth.getBleController(this, signInHuaweiId); 
        } 
     
    /** 
    * 蓝牙扫描回调对象 
    */ 
        private BleScanCallback mBleCallback = new BleScanCallback() { 
            @Override 
            public void onDeviceDiscover(BleDeviceInfo bleDeviceInfo) { 
                // 扫描到匹配的蓝牙设备回调到这里，bleDeviceInfo 对象 
                Log.i("BleController","onDeviceDiscover : " + bleDeviceInfo.getDeviceName()); 
     
                // 将扫描到的心率设备保存到变量，后面会用到 
                mBleDeviceInfo = bleDeviceInfo; 
            } 
     
            @Override 
            public void onScanEnd() { 
                Log.i("BleController","onScanEnd called"); 
            } 
        }; 
     
    /** 
    * 保存我们扫描到的心率设备到设备，以便后面注册监听器获取数据 
    */ 
        public void saveHeartRateDevice(View view) { 
            if (mBleController == null) { 
                Log.i("BleController","BleController is null"); 
                return; 
            } 
     
            mBleController.saveDevice(mBleDeviceInfo.getDeviceAddress()).addOnSuccessListener(new OnSuccessListener<Void>() { 
                @Override 
                public void onSuccess(Void aVoid) { 
                    Log.i("BleController","saveHeartRateDevice successed... "); 
                } 
            }).addOnFailureListener(new OnFailureListener() { 
                @Override 
                public void onFailure(@NonNull Exception e) { 
                    Log.i("BleController","saveHeartRateDevice failed... "); 
                } 
            }); 
        }

#### [h2]getSavedDevices()

**Method**  
---  
public Task<List<BleDeviceInfo>> getSavedDevices()  
获取所有保存的设备。  
  
**Return**

**Type** | **Desc**  
---|---  
List<BleDeviceInfo> | 设备信息列表  
  
示例代码如下：
    
    
    // 创建一个BleController 对象用于扫描远端蓝牙设备 
        private BleController mBleController; 
     
    @Override 
        protected void onCreate(@Nullable Bundle savedInstanceState) { 
            super.onCreate(savedInstanceState); 
            setContentView(R.layout.activity_hihealth_sensor); 
            logInfoView = (TextView) findViewById(R.id.sensor_controller_log_info); 
            logInfoView.setMovementMethod(ScrollingMovementMethod.getInstance()); 
     
            // 进入界面时首先获取BleController 
            HiHealthOptions options = HiHealthOptions.builder().build(); 
     
            // 在这里登录华为ID 
            AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options); 
     
            // 获取BleController 
            mBleController = HuaweiHiHealth.getBleController(this, signInHuaweiId); 
        } 
     
    /** 
    * 列出已保存到手机的远端蓝牙设备 
    */ 
        public void listMatchedDevices(View view) { 
            if (mBleController == null) { 
                Log.i("SensorsController is null"); 
                return; 
            } 
     
            Task<List<BleDeviceInfo>> bleDeviceInfoTask = mBleController.getSavedDevices(); 
            bleDeviceInfoTask.addOnSuccessListener(new OnSuccessListener<List<BleDeviceInfo>>() { 
                @Override 
                public void onSuccess(List<BleDeviceInfo> bleDeviceInfos) { 
                    // bleDeviceInfos 为我们保存的设备列表 
                    for (BleDeviceInfo bleDeviceInfo : bleDeviceInfos) { 
                        Log.i("Matched BLE devices:" + bleDeviceInfo.getDeviceName()); 
                    } 
                } 
            }); 
        }

#### [h2]beginScan(List<DataType> dataTypes, int timeoutSecs, BleScanCallback callback)

**Method**  
---  
publicTask<Void> beginScan(List<DataType> dataTypes, int timeoutSecs, BleScanCallback callback)  
该方法需要启用蓝牙权限和位置权限，并打开手机上的蓝牙和位置信息开关。 启动蓝牙设备扫描，每次扫描到设备时，回调该方法onDeviceDiscover(BleDeviceInfo)，扫描结束时调用onScanEnd()。  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
dataTypes | 搜索的数据类型  
timeoutSecs | 扫描自动停止的时间（单位：秒）  
callback | 扫描回调  
  
示例代码如下：
    
    
    // 创建一个BleController 对象用于扫描远端蓝牙设备 
        private BleController mBleController; 
     
    // 创建一个BleDeviceInfo 对象用于临时保存扫描的设备 
        private BleDeviceInfo mBleDeviceInfo; 
     
    @Override 
        protected void onCreate(@Nullable Bundle savedInstanceState) { 
            super.onCreate(savedInstanceState); 
            setContentView(R.layout.activity_hihealth_sensor); 
            logInfoView = (TextView) findViewById(R.id.sensor_controller_log_info); 
            logInfoView.setMovementMethod(ScrollingMovementMethod.getInstance()); 
     
            // 进入界面时首先获取BleController 
            HiHealthOptions options = HiHealthOptions.builder().build(); 
     
            // 在这里登录华为ID 
            AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(options); 
     
            // 获取BleController 
            mBleController = HuaweiHiHealth.getBleController(this, signInHuaweiId); 
        } 
     
    /** 
    * 蓝牙扫描回调对象 
    */ 
        private BleScanCallback mBleCallback = new BleScanCallback() { 
            @Override 
            public void onDeviceDiscover(BleDeviceInfo bleDeviceInfo) { 
                // 扫描到匹配的蓝牙设备回调到这里，bleDeviceInfo 对象 
                Log.i("onDeviceDiscover : " + bleDeviceInfo.getDeviceName()); 
     
                // 将心率设备保存到变量，后面会用到 
                mBleDeviceInfo = bleDeviceInfo; 
            } 
     
            @Override 
            public void onScanEnd() { 
                Log.i("onScanEnd  Scan called"); 
            } 
        }; 
     
    /** 
    * 启动蓝牙扫描具有心率功能的远端蓝牙设备 
    */ 
        public void scanHeartRateDevices(View view) { 
            if (mBleController == null) { 
                Log.i("BleController is null"); 
                return; 
            } 
     
            Log.i("Scanning devices started"); 
     
            // 将心率数据类型作为数组传入，这里可以同时传入多种数据类型，设定的扫描时间为15秒 
            mBleController.beginScan(Arrays.asList(DataType.DT_INSTANTANEOUS_HEART_RATE), 15, mBleCallback); 
        }
