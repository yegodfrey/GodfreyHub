public class PublicKeyCredentialCreationOptions  
表示新建认证凭据的选项。  
  
## Nested Class Summary

Class| Desc  
---|---  
PublicKeyCredentialCreationOptions.Builder| PublicKeyCredentialCreationOptions的构造器。  
  
## Public method summary

Return type| Method name  
---|---  
byte[]| **getChallenge**()获取挑战值。  
PublicKeyCredentialRpEntity| **getRp**()获取在新建凭据时的依赖方属性。  
PublicKeyCredentialUserEntity| **getUser**()获取账户信息。  
List| **getPubKeyCredParams**()获取认证凭据额外参数列表。  
List| **getExcludeList**()获取排除列表。  
Map| **getExtensions**()获取扩展参数。  
AuthenticatorSelectionCriteria| **getAuthenticatorSelection**()获取与认证器相关的配置项。  
AttestationConveyancePreference| **getAttestation**()获取凭据偏好。  
Long| **getTimeoutSeconds**()获取超时时间。
