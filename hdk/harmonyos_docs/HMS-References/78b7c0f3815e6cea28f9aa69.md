public Creator(android.content.Context context, MLAnalyzer<?> analyzer, LensRequest lensRequest)  
创建一个相机引擎构造器实例。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
context| 上下文  
analyzer| 分析器，继承MLAnalyzer的分析器类实例，如MLCompositeAnalyzer。  
lensRequest| LensRequest类实例，包含相机选择参数，  
如相机类型（前置/后置），要求相机支持的帧率和预览尺寸等，  
相机引擎启动时会根据这些条件去匹配满足条件的相机，并对匹配到的相机参数进行初始化，  
如设定自动聚焦，闪光灯开启模式等。

public Creator(android.content.Context context, MLAnalyzer<?> analyzer, LensRequest lensRequest, MLLensSelector lensSelector)  
创建一个相机引擎构造器实例。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
context| 上下文  
analyzer| 分析器，继承MLAnalyzer<T> 的分析器类实例，如括MLCompositeAnalyzer<T>。  
lensRequest| LensRequest类实例，包含相机选择参数，  
如相机类型（前置/后置），支持的帧率和预览尺寸等。  
相机引擎启动时会根据这些条件去匹配最合适的相机参数并进行初始化，  
如设定自动对焦，闪光灯开启模式等。  
lensSelector| 自定义相机选择器，支持用户自定义相机选择策略，  
如帧率匹配策略，预览尺寸匹配策略，相机类型匹配策略（前置/后置）等。

public LensEngine.Creator applyDisplayDimension(int width, int height)  
设置相机预览尺寸。不同算法对于处理的图片尺寸有不同的建议值，另外处理大图片会带来更多的内存和CPU消耗，建议设置的预览尺寸不超过1920*1920。  
  
**Parameters**

---|---
