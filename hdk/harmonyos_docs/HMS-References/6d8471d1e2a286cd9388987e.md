class info

com.huawei.hms.mlsdk.objects.MLObjectAnalyzerSetting  
  
  
对象分析器设置类：用于设置分析器（MLObjectAnalyzer）的属性。分析器的属性包括：  
1、检测模式  
2、是否支持检测结果分类  
3、是否支持多对象检测  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
int| TYPE_PICTURE| 检测模式0：基于图片的检测。  
int| TYPE_VIDEO| 检测模式1：基于视频流的检测。
