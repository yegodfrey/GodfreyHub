**public interface HuaweiMap.OnCameraMoveCanceledListener**

OnCameraMoveCanceledListener是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)类的一个内部接口，包含一个抽象函数onCameraMoveCanceled()。

public abstract void onCameraMoveCanceled()  
当开发者显式调用[stopAnimation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap#stopAnimation\(\))()方法或在[onCameraIdle](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimaponcameraidlel#onCameraIdle\(\))()有机会在上一个动画触发之前改变相机移动原因时调用此方法。不要在此方法中更新相机状态。必须在主线程中调用。
