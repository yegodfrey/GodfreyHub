# 接口功能

此接口用于主动取消顾客订阅的商品，不影响已经收取费用的收据，只是在订阅器到期日不会继续续订。

# 调用场景

在收到顾客申诉不希望对订阅的商品续期后，您的服务器可以调用华为应用内支付服务器提供的取消订阅接口停止续期，商品在有效期内仍然有效，但后续的续期会终止。取消的订阅商品在一定时间段内仍然会保留，比如30天。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器-> 华为支付服务器  
接口URL| {rootUrl}/sub/applications/{apiVersion}/purchases/stoprootUrl在不同站点有不同的url：开发者应固定选择最近站点的Subscription服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#State-Infomation)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#h1-1590477491025)。  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
# 请求参数

**参数名称**| **必选(M)/****可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
subscriptionId| M| String| 订阅Id  
purchaseToken| M| String| 商品的已购买Token，发起购买和查询订阅信息均会返回。  
  
# 响应参数

**参数名称**| **必选(M)/可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
responseCode| M| String| 返回码。●  0：成功●  其他：失败，具体参考[接口错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#API-ErrorCode)。  
responseMessage| O| String| 响应描述。
