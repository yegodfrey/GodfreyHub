public static synchronized SearchService create(Context context, String apiKey)  
通过context和apiKey实例化出SearchService对象。  
  
**Parameters：**

Parameter name| Parameter desc  
---|---  
context| 上下文。  
apiKey| apiKey需要从agconnect-services.json文件的client>>api_key中获取。注意：如果apiKey包含特殊字符，则需要进行encodeURI编码。例如：原始apiKey：ABC/DFG+ ，转换结果: ABC%2FDFG%2B。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
[SearchService](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-site-searchservice)| 华为位置服务的入口类。
