public abstract boolean onMyLocationButtonClick()  
点击我的位置按钮时的回调方法。必须在主线程中调用。  
  
  
**Parameters：**  
无  
**Return：**  


Return type| Parameter desc  
---|---  
boolean| 如果监听器已经消耗了该事件（即不发生默认行为），返回true,否则（即发生默认行为），返回false。默认行为是相机移动，使其以用户位置为中心。
