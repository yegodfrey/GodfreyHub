**关联/去关联优惠信息到会员卡**  


# **1 请求**

## **HTTP请求**

PATCH  
https://**${url}** /hmspass/v1/loyalty/instance/**{instanceId}** /linkedoffers  
备注：请求地址中的 **${url}  **变量需要开发者根据服务器所属区域自行选择，请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。

## **URL路径参数**

  
|   
|   
  
---|---|---  
instanceId| String| 个人化数据 Id，instance 的唯一标识，该 Id 在一个商户的所有 instance 中唯一，这个 Id 只能包含字母、数字和（.）、（-）、（_）。  
  
## **请求体**

请求体包含一个待处理优惠券信息对象 LinkedOfferInstanceIds。

**LinkedOfferInstanceIds:**

  
|   
|   
  
---|---|---  
addOffers| Array<Offer>| 需要增加的优惠券信息  
deleteOffers| Array<Offer>| 需要删除的优惠券信息  
  
**Offer:**  


  
|   
|   
  
---|---|---  
passTypeIdentifier| String| 要添加或删除的优惠券的卡券类型。  
instanceId| String| 优惠券个人化实例 Id。  
  
# 2 响应

如果成功，响应消息包含更新后的 [hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject") 对象。
