**public interface HuaweiMap.OnCameraMoveListener**

public abstract void onCameraMove()  
在调用onCameraMoveStarted后随着相机的移动反复调用此方法。每一帧都可能被调用一次，因此不能执行高消耗的操作。必须在主线程中执行。
