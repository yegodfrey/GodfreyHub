ScoreSubmissionInfo类主要用于返回提交排行榜分数的结果，在调用[RankingsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingsclient)的submitScoreWithResult方法时会返回该类型的实例。  
  
# Public Method Summary

Return| Method  
---|---  
String| getRankingId()获取提交分数所在的排行榜ID。  
String| getPlayerId()获取分数所属玩家的playerId。  
[ScoreSubmissionInfo.Result](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scoresubmissioninforesult)| getSubmissionScoreResult(int timeDimension)根据时间维度获取提交后的结果。  
  
# Public Methods

## public String getRankingId()

获取提交分数所在的排行榜ID。

**返回值**

Type| Description  
---|---  
String| 分数所在的排行榜ID。  
  
## public String getPlayerId()

获取分数所属玩家的playerId。

**返回值**

Parameter Name| Parameter Description  
---|---  
String| 提交分数的玩家ID。  
  
## public ScoreSubmissionInfo.Result getSubmissionScoreResult(int timeDimension)

根据时间维度查询提交后的结果。

**请求参数**

Parameter Name| Parameter Description  
---|---  
timeDimension| 指定查询的时间维度。
     * 0：日
     * 1：周
     * 2：全部时间  
  
**返回值**

Type| Description  
---|---  
[ScoreSubmissionInfo.Result](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scoresubmissioninforesult)| 包含提交后分数信息的[ScoreSubmissionInfo.Result](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scoresubmissioninforesult)对象。
