Player类主要用于返回游戏玩家的具体信息，在调用[PlayersClient.getCurrentPlayer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/playersclient-v4#getCurrentPlayer)方法时会返回Player类型的实例。

# Public Method Summary

Return| Method  
---|---  
String| getDisplayName()  
获取玩家昵称。  
Uri| getHiResImageUri()  
获取玩家高清头像的URI地址。  
Uri| getIconImageUri()  
获取玩家普通图标头像的URI地址。  
int| getLevel()  
获取玩家等级信息，当前只支持中国大陆玩家，中国大陆以外的玩家将默认返回1。  
String| getPlayerId()  
获取华为为玩家分配的游戏账户ID，该ID可在应用内唯一标识该用户。  
boolean| hasHiResImage()  
检查玩家是否存在高清头像。  
boolean| hasIconImage()  
检查玩家是否存在普通头像。  
String| getPlayerSign()  
获取玩家的登录签名，应用服务端可以根据登录签名调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/verify-login-signature "校验登录签名")接口向华为服务器验证玩家ID的有效性。  
String| getSignTs()  
获取校验登录签名时需要提交的时间戳信息。  
  
# Public Methods

## **public String getDisplayName()**  


获取玩家昵称。

**返回值**  
用于游戏展示的玩家昵称字符串。

## **public Uri getHiResImageUri()**

获取玩家高清头像的URI地址，hasHiResImage()方法返回**true** 时才需要获取。  


**返回值**  
玩家高清头像的URI地址。如果玩家不存在高清头像，返回null。

## **public Uri getIconImageUri()**

获取玩家普通图标头像的URI地址，hasIconImage()方法返回**true** 才需要获取。

**返回值**  
玩家普通图标头像的URI地址。如果玩家没有头像，返回null。

## **public int getLevel()**

获取玩家等级。当前只支持中国大陆玩家，中国大陆以外的玩家将默认返回1。

**返回值**  
返回玩家等级数字。

## **public String getPlayerId()**

获取玩家ID。

**返回值**  
玩家ID。

## **public boolean hasHiResImage()**

玩家是否存在高清头像。

**返回值**  
● true：存在。如果存在可调用getHiResImageUri()方法获取头像的URI地址。  
● false：不存在。

## **public boolean hasIconImage()**  


玩家是否存在普通图标头像。

**返回值**  
● true：存在。如果存在可调用getIconImageUri()方法获取头像的URI地址。  
● false：不存在。

## **public String getPlayerSign()**

获取玩家的登录签名，用于应用服务端调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/verify-login-signature "校验登录签名")接口时向华为游戏服务器发起登录签名验证。

**返回值**  
登录签名字符串。

## **public String getSignTs()**

获取华为游戏服务器返回的时间戳，用于应用服务端调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/verify-login-signature "校验登录签名")接口时向华为游戏服务器发起登录签名验证。

**返回值**  
时间戳字符串。时间戳的有效时间默认为5分钟，请在有效期内完成登录签名校验，否则将导致登录签名校验失败。
