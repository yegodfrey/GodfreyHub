## com.huawei.hms.mlsdk.tts.MLTtsEngine

TTS 引擎。

Type| Name| Desc  
---|---|---  
int| EXTERNAL_PLAYBACK| TTS引擎合成的语音不使用内部播放器自动播放。  
int| OPEN_STREAM| TTS引擎合成的语音通过[onAudioAvailable](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsCallback-4#onAudioAvailable)回调接口返回给App。  
int| QUEUE_APPEND| 串行排队模式。当你选择排队模式时，如果有多个语音合成任务，这些任务按照调用次序，顺序执行。

public String speak(String text, int Mode)  
实时语音合成并播放API。

  * 排队模式（QUEUE_APPEND）：生成语音合成任务。如果当前正在播放，则将任务放在队列中顺序执行；如果当前处于播放暂停状态，则恢复播放，再将任务放入队列中顺序执行；如果当前无播放任务，则立即执行。
  * 清空模式（QUEUE_FLUSH）：立即停止正在进行的语音合成任务以及播放，并清空正在排队的语音合成任务，立即执行此次语音合成任务并播放。

注意：排队模式和清空模式二者选其一，如果都选清空模式会覆盖排队模式。

  * 实时流输出模式（OPEN_STREAM）：将文本合成的语音数据流通过[onAudioAvailable](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsCallback-4#onAudioAvailable)回调输出。即音频流在往内部播放器发送的时候，同时拷贝了一份透传给APP。
  * 外部播放模式（EXTERNAL_PLAYBACK）：屏蔽内部自带播放器播放音频的能力，同时将文本合成的语音数据流通过[](file:///C:/Users/l00483567/Desktop/%E4%B8%AD%E6%96%87%E6%89%B9%E6%B3%A8.docx#section18852205617712)[onAudioAvailable](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsCallback-4#onAudioAvailable)回调输出。此时回调接口中播放相关回调接口将会失效，仅能监听语音合成相关回调接口。

  
  
  
**Parameters**  


Parameter name| Parameter desc  
---|---  
text| 传入待转语音的文本，文本长度最大500字符，即text.length()不能大于500，text文本编码格式为UTF-8。  
queueMode| 语音合成任务播放模式。当前有四种类型：QUEUE_APPEND、QUEUE_FLUSH、OPEN_STREAM、EXTERNAL_PLAYBACK。  
  
**Return**  


Type| desc  
---|---  
String| taskID 返回语音合成任务ID。  
  
**Sample Code**
      
      1.  MLTtsEngine mlTtsEngine = new MLTtsEngine(null); 
        2. String text = "Hello world"; 
        3. // 排队模式进行语音合成，使用SDK内置播放器播放语音。 
        4. String id = mlTtsEngine.speak(text, MLTtsEngine.QUEUE_APPEND);  
        5. // 排队模式进行语音合成，将合成的语音流通过onAudioAvailable回调输出，同时使用SDK内置播放器播放语音。 
        6. String id = mlTtsEngine.speak(text, MLTtsEngine.QUEUE_APPEND | MLTtsEngine.OPEN_STREAM);  
        7. // 排队模型进行语音合成，将合成的语音流通过onAudioAvailable回调输出，输出语音流不播放，由开发者控制。 
        8. String id = mlTtsEngine.speak(text, MLTtsEngine.QUEUE_APPEND | MLTtsEngine.OPEN_STREAM | MLTtsEngine.EXTERNAL_PLAYBACK);
