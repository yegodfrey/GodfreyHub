# 1 接口描述  
  
DTM函数调用模板实现接口。

# 2 调用示例

以下示例会将自定义数据上报到自定义平台：
    
    
    复制
      
        1. public class CallTagDemo implements ICustomTag {
        2.     @Override
        3.     public void call(Map<String, Object> var1) {
        4.         Object var2 = dosomething(var1);
        5.         sendMessage(var2);
        6.     }
        7.     private void sendMessage(String var) {
        8.         MyPlatform.logEvent(var);
        9.     }
        10. }
    
    

# 3 请求参数

参数名称| 参数类型| 备注  
---|---|---  
var1| Map<String, Object>| 自定义代码  
  
# 4 返回值

无。
