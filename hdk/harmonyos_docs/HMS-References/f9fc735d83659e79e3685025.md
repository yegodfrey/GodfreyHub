public TileOverlayOptions visible(boolean visible)  
开发者调用此方法来设置瓦片图层的可见性，如果瓦片图层不可见，则不会绘制，其他所有状态均保留，瓦片图层默认是可见的。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
visible| 可见性，true为可见，false为不可见。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
TileOverlayOptions| 设置新的可见性后的TileOverlayOptions对象。

public TileOverlayOptions zIndex(float zIndex)  
用于设置瓦片图层的z指数。z指数指的是瓦片图层的叠加顺序，具有较大z指数的瓦片图层会绘制在具有较小z指数的瓦片图层上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
zIndex| z指数，即瓦片图层的叠加顺序。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
TileOverlayOptions| 设置新的z指数后的TileOverlayOptions对象。
