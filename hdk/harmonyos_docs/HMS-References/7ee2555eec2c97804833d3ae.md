# activityRecords: update

创建或者修改一个activityRecord。

#### 请求

#### [h2]HTTP请求
    
    
    PUT 
    https://health-api.cloud.huawei.com/hihealth/v1/activityRecords/activityRecordId

#### [h2]请求参数

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
activityRecordId | string | 活动记录ID | 必选 | 长度范围：1~1000。 需与请求体id保持一致  
  
#### [h2]请求体

ActivityRecord的结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
id | string | 客户端生成的标识符，在该用户拥有的所有活动记录中都是唯一的 | 必选 | 长度范围：1~1000。 需与请求参数activityRecordId保持一致  
name | string | 用户设定的活动记录名称 | 可选 | 长度范围：1~1000  
desc | string | 活动记录描述 | 可选 | 长度范围：1~1000  
startTime | long | 活动记录开始时间，单位：毫秒 | 必选 | 13位整数的时间戳，对应时间范围是2000-01-01 00:00:00 ~ 2099-12-31 23:59:59。 startTime必须小于endTime startTime与endTime相隔时间不能超过5天  
endTime | long | 活动记录结束时间，单位：毫秒 | 必选 | 13位整数的时间戳，对应时间范围是2000-01-01 00:00:00 ~ 2099-12-31 23:59:59。 endTime必须大于startTime startTime与endTime相隔时间不能超过5天  
modifyTime | long | 活动记录的最后修改时间。 若用户创建activityRecords时填写了modifyTime，界面返回用户创建的activityRecords信息时将返回传入的modifyTime值；否则不返回 | 可选 |     
appInfo | AppInfo | 创建该活动记录的应用 | 必选 |     
activityType | integer | 活动记录对应的[活动类型](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/activity_types-0000001050071667)的取值，例如：wakeboarding对应89 | 可选 |     
activeTime | long | 活动记录活跃时间 | 可选 |     
  
AppInfo结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
appName | string | 应用的名称 | 可选 | 长度范围：1~1000  
appPackageName | string | 应用程序的包名称 | 可选 | 长度范围：1~300。 如果appPackageName/clientId同时存在，appPackageName/clientId必须匹配  
clientId | string | 应用ID | 可选 | 由数字组成，长度范围：2~128。 如果appPackageName/clientId同时存在，appPackageName/clientId必须匹配  
appVersion | string | 应用的版本信息 | 可选 | 长度范围：1~1000  
desc | string | 用于链接该应用程序的URL | 可选 | 长度范围：1~1000  
  
#### 响应

ActivityRecord的所有字段，参考1.3中请求体。

#### 返回码

成功：http 200

失败：其他
