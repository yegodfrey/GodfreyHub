# ActivityRecordsController  
  
**CLASS info**  
---  
public class ActivityRecordsController 提供创建和管理用户活动的功能  
  
获取ActivityRecordsController实例对象的示例代码如下：
    
    
    HiHealthOptions hihealthOptions = HiHealthOptions.builder().build();
    AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(hihealthOptions);
    ActivityRecordsController mActivityRecordsController = HuaweiHiHealth.getActivityRecordsController(context, signInHuaweiId);

#### Public Method Summary

**Return** | **Method**  
---|---  
Task<Void> | beginActivityRecord(ActivityRecord activityRecord) 为当前应用启动一个新的活动记录.  
Task<List<ActivityRecord>> | endActivityRecord(String activityRecordId) 停止当前应用的指定活动记录  
Task<Void> | addActivityRecord(ActivityRecordInsertOptions activityRecordInsertOptions) 插入指定的活动记录和相应的数据到Health平台中  
Task<ActivityRecordReply> | getActivityRecord(ActivityRecordReadOptions activityRecordReadOptions) 根据请求参数中指定的活动记录和类型，从Health平台中读取数据  
Task<Void> | addActivityRecordsMonitor(PendingIntent pendingIntent) 为活动记录的开始和结束事件注册一个待定意图  
Task<Void> | removeActivityRecordsMonitor(PendingIntent pendingIntent) 取消活动记录的开始和结束事件注册的待定意图

#### [h2]endActivityRecord(String activityRecordId)

**Method**  
---  
public Task<List<ActivityRecord>> endActivityRecord(String activityRecordId)  
停止当前应用的活动记录  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
activityRecordId | 活动记录的唯一标识符。如果传递的是null，则该应用的所有活跃态活动记录都将被停止  
  
**Return**

**Type** | **Return desc**  
---|---  
Task<List<ActivityRecord>> | 包含已停止活动记录列表  
  
示例代码如下：
    
    
    HiHealthOptions hihealthOptions = HiHealthOptions.builder().build(); 
    AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(hihealthOptions); 
    ActivityRecordsController mActivityRecordsController = HuaweiHiHealth.getActivityRecordsController(context, signInHuaweiId); 
     
    // 1.调用活动记录控制器的方法停止活动记录入参为ActivityRecord的ID字符串或者null 
    // 入参为ID字符串时，停止当前应用的一个活动记录 
    // 入参为null时，停止该应用当前所有的未停止活动记录 
    Task<List<ActivityRecord>> endTask = mActivityRecordsController.endActivityRecord("MyBeginActivityRecordId"); 
    endTask.addOnSuccessListener(new OnSuccessListener<List<ActivityRecord>>() { 
        @Override 
        public void onSuccess(List<ActivityRecord> activityRecords) { 
            Log.i("ActivityRecords","MyActivityRecord End success"); 
            // 返回停止成功的活动记录列表
            if (activityRecords.size() > 0) { 
                for (ActivityRecord activityRecord : activityRecords) { 
                    dumpActivityRecord(activityRecord); 
                } 
            } else { 
                // 没有停止成功的返回null 
                Log.i("ActivityRecords","MyActivityRecord End response is null"); 
            } 
        }}).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
                    String errorCode = e.getMessage(); 
                    String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
                    Log.i("ActivityRecords",errorCode + ": " + errorMsg); 
        } 
    });

#### [h2]addActivityRecord(ActivityRecordInsertOptions activityRecordInsertOptions)

**Method**  
---  
public Task<Void> addActivityRecord(ActivityRecordInsertOptions activityRecordInsertOptions)  
插入指定的活动记录和相应的数据到Health平台中  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
activityRecordInsertOptions | 插入活动记录和关联数据的请求，包括活动记录详细信息以及采样集  
  
示例代码如下：
    
    
    HiHealthOptions hihealthOptions = HiHealthOptions.builder().build(); 
    AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(hihealthOptions); 
    ActivityRecordsController mActivityRecordsController = HuaweiHiHealth.getActivityRecordsController(context, signInHuaweiId); 
     
    // 1.构造请求对象的时间区间：开始和结束时间 
    Calendar cal = Calendar.getInstance(); 
    Date now = new Date(); 
    cal.setTime(now); 
    long endTime = cal.getTimeInMillis(); 
    cal.add(Calendar.HOUR_OF_DAY, -1); 
    long startTime = cal.getTimeInMillis(); 
     
    // 2.构造活动记录请求对象 
    ActivityRecord activityRecord = new ActivityRecord.Builder() 
            .setName("AddActivityRecord") 
            .setDesc("This is ActivityRecord add test!") 
            .setId("MyAddActivityRecordId") 
            .setActivityTypeId(HiHealthActivities.RUNNING) 
            .setStartTime(startTime, TimeUnit.MILLISECONDS) 
            .setEndTime(endTime, TimeUnit.MILLISECONDS) 
            .build(); 
     
    // 3.构造数据采集器对象 
    DataCollector dataSource = new com.huawei.hms.hihealth.data.DataCollector.Builder() 
            .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA) 
            .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
            .setPackageName(mContext) 
            .setDataCollectorName("AddActivityRecord") 
            .build(); 
    // 4. 根据数据采集器，构造数据样本集合 
    SampleSet dataSet = SampleSet.create(dataSource); 
     
    // 5. 构造步数增量（DT_CONTINUOUS_STEPS_DELTA）数据点对象，添加到数据样本集合 
    SamplePoint dataPoint = dataSet.createSamplePoint().setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS); 
    dataPoint.getFieldValue(Field.FIELD_STEPS_DELTA).setIntValue(1024); 
    dataSet.addSample(dataPoint); 
     
    // 6. 构造添加活动记录请求对象 
    ActivityRecordInsertOptions insertRequest = 
            new ActivityRecordInsertOptions.Builder().setActivityRecord(activityRecord).addSampleSet(dataSet).build(); 
     
    // 7.调用活动记录控制器的方法添加活动记录 
    Task<Void> addTask = mActivityRecordsController.addActivityRecord(insertRequest); 
    addTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
        @Override 
        public void onSuccess(Void aVoid) { 
             Log.i("ActivityRecords","ActivityRecord add was successful!"); 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
                    String errorCode = e.getMessage(); 
                    String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
                    Log.i("ActivityRecords",errorCode + ": " + errorMsg); 
        } 
    });

#### [h2]getActivityRecord(ActivityRecordReadOptions activityRecordReadOptions)

**Method**  
---  
public Task<ActivityRecordReply> getActivityRecord(ActivityRecordReadOptions activityRecordReadOptions)  
根据请求参数中指定的活动记录和类型，从Health平台中读取数据  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
activityRecordReadOptions | 创建的活动记录查询请求，包括查询时间段、数据类型等参数  
  
**Return**

**Type** | **Return desc**  
---|---  
Task<ActivityRecordReply> | 返回结果，包括每个活动记录的采样集和数据类型  
  
示例代码如下：
    
    
    HiHealthOptions hihealthOptions = HiHealthOptions.builder().build(); 
    AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(hihealthOptions); 
    ActivityRecordsController mActivityRecordsController = HuaweiHiHealth.getActivityRecordsController(context, signInHuaweiId); 
     
    // 1.构造请求对象的时间区间：开始和结束时间 
    Calendar cal = Calendar.getInstance(); 
    Date now = new Date(); 
    cal.setTime(now); 
    long endTime = cal.getTimeInMillis(); 
    cal.add(Calendar.DAY_OF_YEAR, -1); 
    long startTime = cal.getTimeInMillis(); 
     
    // 2.构造读取活动记录请求体 
    ActivityRecordReadOptions readRequest = new ActivityRecordReadOptions.Builder() 
            .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS) 
        .readActivityRecordsFromAllApps() 
        .read(DataType.DT_CONTINUOUS_STEPS_DELTA) 
        .build(); 
     
    checkConnect(); 
    // 3. 调用活动记录控制器的读取方法，根据请求体条件获取Health平台中的活动记录 
    Task<ActivityRecordReply> getTask = mActivityRecordsController.getActivityRecord(readRequest); 
    getTask.addOnSuccessListener(new OnSuccessListener<ActivityRecordReply>() { 
        @Override 
        public void onSuccess(ActivityRecordReply activityRecordReply) { 
             Log.i("ActivityRecords","Get ActivityRecord was successful!"); 
            //打印结果 printActivityRecord和printSampleSet为自定义的输出函数 
            List<ActivityRecord> activityRecordList = activityRecordReply.getActivityRecords(); 
            for (ActivityRecord activityRecord : activityRecordList) { 
                printActivityRecord(activityRecord); 
                for (SampleSet sampleSet : activityRecordReply.getSampleSet(activityRecord)) { 
                    printSampleSet(sampleSet); 
                } 
            } 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
                    String errorCode = e.getMessage(); 
                    String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
                    Log.i("ActivityRecords",errorCode + ": " + errorMsg); 
        } 
    });

#### [h2]addActivityRecordsMonitor(PendingIntent pendingIntent)

**Method**  
---  
public Task<Void> addActivityRecordsMonitor(PendingIntent pendingIntent)  
为活动记录的开始和结束事件注册通知，仅对调用beginActivityRecord方法启动的活动记录发送通知  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
pendingIntent | 活动记录开始或停止时发送的PendingIntent  
  
示例代码如下：
    
    
    HiHealthOptions hihealthOptions = HiHealthOptions.builder().build(); 
    AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(hihealthOptions); 
    ActivityRecordsController mActivityRecordsController = HuaweiHiHealth.getActivityRecordsController(context, signInHuaweiId); 
     
    // 1.构造pendingIntent请求体  ActivityRecordsMonitorReceiver为提前创建的广播接收类 
    pendingIntent = PendingIntent.getBroadcast(this, 0, 
            new Intent(this, ActivityRecordsMonitorReceiver.class), 
            PendingIntent.FLAG_UPDATE_CURRENT); 
    // 2.调用活动记录控制器的方法添加状态监听 
    Task<Void> addMonitorTask = mActivityRecordsController.addActivityRecordsMonitor(pendingIntent); 
    addMonitorTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
        @Override 
        public void onSuccess(Void aVoid) { 
            Log.i("ActivityRecords","addActivityRecordsMonitor is successful"); 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
                    String errorCode = e.getMessage(); 
                    String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
                    Log.i("ActivityRecords",errorCode + ": " + errorMsg); 
            pendingIntent = null; 
        } 
    });
