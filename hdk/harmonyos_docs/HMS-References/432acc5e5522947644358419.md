public MLGcrCaptureUIConfig create()  
创建通用卡证UI界面配置器实例。  
  
**Return**

Type| desc  
---|---  
MLGcrCaptureUIConfig| 通用卡证UI界面配置器的实例。  
  
**Sample Code**  

    
    
     复制
      
        1. MLGcrCaptureUIConfig uiConfig = new MLGcrCaptureUIConfig.Factory()
        2.      // 设置扫描框颜色。
        3.      .setScanBoxCornerColor(Color.GREEN)
        4.      // 设置扫描框中的提示文字，建议少于30个字符。
        5.      .setTipText("Recognizing, align edges")
        6.      // 设置界面横竖屏，支持三种模式：
        7.      // MLGcrCaptureUIConfig.ORIENTATION_AUTO:自动模式，由物理感应器决定显示方向。
        8.      // MLGcrCaptureUIConfig.ORIENTATION_LANDSCAPE:横屏模式，显示时屏幕宽度大于高度。
        9.      // MLGcrCaptureUIConfig.ORIENTATION_PORTRAIT:竖屏模式，显示时屏幕高度大于宽度。
        10.      .setOrientation(MLGcrCaptureUIConfig.ORIENTATION_AUTO)
        11.      .create();
