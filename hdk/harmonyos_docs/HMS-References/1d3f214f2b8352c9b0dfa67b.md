**1\. Classes Overview**  
  
Class name| Class description  
---|---  
GameManager| GameManager是GameKit对外提供的类，它是一个抽象类，具有一个公共的静态方法，用来获取一个继承并实现GameManager抽象方法的类的实例。  
GameManager.GameCallback| GameCallback接口是GameManager类内部定义的接口。设备通过该接口反馈设备信息，如温度信息等。
