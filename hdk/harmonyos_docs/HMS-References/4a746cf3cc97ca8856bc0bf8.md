public class CreateWalletPassRequest extends Objects implements Parcelable  
添加卡劵组装请求,目前建议开发者使用JWT方式有参构造器实例化该CreateWalletPassRequest.内部会封装JWT字符串,提供HMS core 需要的JWT格式。由WalletPassClient进行请求。
