**public interface HuaweiMap.OnMarkerDragListener**  
  
OnMarkerDragListener是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)类的一个内部接口，包含三个抽象函数onMarkerDrag([Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker))、onMarkerDragEnd([Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker))、onMarkerDragStart([Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker))。用户实现此接口可以对标记拖拽事件进行监听。

## Public Fields

无

无
