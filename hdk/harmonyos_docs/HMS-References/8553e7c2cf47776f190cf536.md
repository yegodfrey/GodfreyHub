public MLLocalTextSetting.Factory setLanguage(String language)  
设置分析器的检测语种，默认设置为拉丁语系“rm”。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
language| 语种使用语言代码表示，支持识别的语言代码：“en”（英），“zh”（中），  
“ja”（日），“ko”（韩），“ru”（俄），“de”（德），“fr”（法），  
“it”（意大利），“pt”（葡萄牙），“es”（西班牙）。  
  
  
**Return**  


Type| desc  
---|---  
MLLocalTextSetting.Factory| 返回MLLocalTextSetting.Factory的实例。  
Method  
---  
public MLLocalTextSetting.Factory setOCRMode(int ocrMode)  
设置文本检测模式，分析器会根据检测模式调用不同的文本检测接口。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
ocrMode| 文本检测模式。  
1：OCR_DETECT_MODE，独立检测模式  
2：OCR_TRACKING_MODE，追踪模式  
  
  
**Return**  


Type| desc  
---|---  
MLLocalTextSetting.Factory| MLLocalTextSetting.Factory的实例。
