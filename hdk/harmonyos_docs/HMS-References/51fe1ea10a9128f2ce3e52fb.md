# 接口功能  
  
  * 应用向华为帐号服务器，调用该接口验证ID Token的合法性，并解析ID Token中的信息，只用于调试目的。



# 调用场景

  * 第三方应用通过ID Token方式进行华为帐号登录授权，要解析出用户的ID Token，需要先对ID Token的有效性进行验证，如果本地验证失败，可调用此接口向华为服务器发送验证请求进行调试，验证ID Token的有效性。

  * 如果ID Token是直接调用[Token获取接口](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-obtain-token)获取的，则不需要验证ID Token的有效性。  





# 接口原型

承载协议| HTTP POST  
---|---  
接口方向| 开发者服务器->华为帐号服务器  
接口URL（开发者）| https://oauth-login.cloud.huawei.com/oauth2/v3/tokeninfo  
接口URL（运营商）| https://oauth-login-at.platform.dbankcloud.com/oauth2/v3/tokeninfo  
  
# 接口约束

  * 由于调用此接口会带来耗时，并且受网络状况的影响，所以该接口只能用于调试目的，在商用环境需采用本地验证的方式。




# 请求参数

**参数名称**            | 必选(M)/可选(O)| **类型**            | **参数说明**              
---|---|---|---  
id_token| M| string| 应用获取到的ID Token。  
  
# 返回参数

调用成功情况下，返回的信息，与生成id_token的scope是否包含openid，email，profile有关，如下：

Scope包含权限项 openid 时，解析的字段映射表如下：

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
iss| M| String| 固定值：https://accounts.huawei.com  
sub| M| String| 同一个开发者下的所有应用，此参数均相同  
aud| M| String| 应用ID，标识ID Token包含此应用ID的信息  
exp| M| Long| ID Token过期时间  
iat| M| Long| ID Token生成时间  
nonce| O| String| 随机字符串，区分大小写。如果生成Authorization Code时入参包含nonce，则与该入参nonce一致  
at_hash| O| String| Access Token的哈希值  
azp| O| String| 应用ID，标识ID Token由此应用ID生成  
  
Scope包含权限项 email 时，解析的字段映射表如下：  


参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
email_verified| O| Boolean| 用户邮箱是否已验证      ● true：是      ● false：否        
email| O| String| 用户邮箱地址，由于email不是华为帐号的必填项,响应中可能没有这个属性。  
  
Scope包含权限项 profile 时，解析的字段映射表如下：  


参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
picture| O| String| 用户头像图片链接  
name| O| String| 用户的全名（姓和名拼在一起）  
locale| O| String| 用户语言偏好，例如"zh-cn"、"en-us"  
family_name| O| String| 姓  
given_name| O| String| 名  
display_name| O| String| 华为帐号对应的昵称
