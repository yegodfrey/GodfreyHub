public class DailyWeather implements Parcelable  
当天和未来六到七天的天气信息。包括月出、月落、日出、日落、最低最高温度（摄氏度）、最低最高温度（华氏度）、综合空气指数（国外不支持）、当地时间凌晨时间戳、月相、白天天气情况（[DailySituation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-dailysituation)）、夜间天气情况（[DailySituation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-dailysituation)）。

public String getMoonphase()  
获取该天的月相。月相moonPhase共有8种值，分别是“New”、“Waxingcrescent”、“First”、“WaxingGibbous”、“Full”、“WaningGibbous”、“Last”和“WaningCrescent”。  
  
**Return**

Type| desc  
---|---  
String| 该天的月相。月相moonPhase共有8种值，分别是“New”、“Waxingcrescent”、“First”、“WaxingGibbous”、“Full”、“WaningGibbous”、“Last”和“WaningCrescent”。
