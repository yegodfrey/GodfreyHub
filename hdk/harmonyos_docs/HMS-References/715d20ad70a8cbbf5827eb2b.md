**public class Tile**

组成[TileOverlay](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-tileoverlay)的最小单位，调用[TileProvider](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-tileprovider)方法返回Tile对象。

## Public Fields

Name| Type| Description  
---|---|---  
data| byte[]| 包含图片数据的字节数组，这个图片可以通过调用类BitmapFactory的decodeByteArray(byte[], int, int)方法来创建。  
height| int| 瓦片的高度，以像素为单位。  
width| int| 瓦片的宽度，以像素为单位。
