## public Task<Intent> getTotalRankingsIntent()

获取所有排行榜页面的Intent对象。

**返回值**

Type| Description  
---|---  
Task<Intent>| 排行榜页面的Intent对象，应用可以使用**startActivityForResult** 方法拉起排行榜展示界面。注意：只有安装10.3.0版本应用助手的终端才支持。  
  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception)实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。

## public Task<RankingsClient.RankingScores> getMoreRankingScores(String rankingId,long offsetPlayerRank, int maxResults, int pageDirection, int timeDimension)

分页获取某个排行榜的分数信息。

**请求参数**

Parameter Name| Parameter Description  
---|---  
rankingId| 需要获取数据的排行榜ID。  
offsetPlayerRank| 从offsetPlayerRank指定的位置，根据pageDirection指定的数据获取方向获取一页数据，offsetPlayerRank取值必须为大于等于0的整数。例如offsetPlayerRank取值为5，pageDirection取值为0，表示从排行榜的第5位分数向下获取一页数据。  
maxResults| 每页的最大数量，支持取值为1到21的整数。  
pageDirection| 数据获取方向。
     * 0：下一页
     * 1：上一页  
timeDimension| 获取指定时间维度的排行榜。
     * 0：日，表示获取当天的排行榜数据。
     * 1：周，表示获取本周的排行榜数据。
     * 2：全部时间。  
  
**返回值**  


Type| Description  
---|---  
Task<[RankingsClient.RankingScores](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingscores)>| 返回指定排行榜的分数数据。

## public void submitRankingScore(String rankingId, long score, String scoreTips)

本方法的提交方式为异步提交，即应用客户端调用本方法时如果设备无网络，HMS SDK会先将数据缓存在本地，待网络恢复后用户再次登录时提交到华为服务器。开发者无需关注此方法的执行结果。

**请求参数**

Parameter Name| Parameter Description

rankingId| 排行榜ID。  
score| 当前玩家的分数。  
scoreTips| 分数的自定义单位，只支持[a-zA-Z0-9_-]中的字符。
