public Task<Void> deleteActivityConversionUpdates(PendingIntent pendingIntent)  
移除指定pendingIntent关联的活动转换更新。调用此函数需要在Manifest文件中申请：com.huawei.hms.permission.ACTIVITY_RECOGNITION权限（Android Q以下版本）或android.permission.ACTIVITY_RECOGNITION权限（Android Q及以上版本），其他活动识别接口对权限要求一致。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
pendingIntent| 待移除的活动转换请求关联  
  
**Return**

type| desc  
---|---  
[Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hmf-task)<Void>| 任务。给它添加监听器，获取当前方法执行结果，通过getStatusCode()以确定是否成功。

public Task<Void> createActivityIdentificationUpdates(long intervalMillis，PendingIntent callbackIntent)  
注册活动识别更新。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
intervalMillis| 活动检测更新间隔，以毫秒为单位，值越大，活动检测越少，值越小，活动检测越频繁。  
callbackIntent| 待更新的PendingIntent，构造PendingIntent时需设置Class、Action，不能构造空Intent。  
  
**Return**

type| desc  
---|---  
[Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hmf-task)<Void>| 任务。给它添加监听器，获取当前方法执行结果，通过getStatusCode()以确定是否成功。
