public MLMaxSizeFaceTransactor.Creator setMaxFrameLostCount(int maxFrameLostCount)  
设置判断人脸消失帧数阈值。如果当前跟踪到的人脸在后续帧中消失，消失帧数小于该阈值，则可以继续跟踪该人脸；如果消失帧数大于该阈值，则认为该人脸消失，选择下一个最大的人脸进行跟踪。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
maxFrameLostCount| 人脸消失帧数阈值。

MLMaxSizeFaceTransactor.Creator| 返回MLProminentFaceTransactor.Creator的实例。
