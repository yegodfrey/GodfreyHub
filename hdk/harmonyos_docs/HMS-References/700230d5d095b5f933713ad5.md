#### 功能介绍  
  
应用服务端调用此接口能够查询数据删除请求任务在分析平台的执行进展。

#### 场景描述

应用服务器在调用“创建删除个人数据任务”接口后，Analytics Kit服务端异步删除数据，开发者的应用服务器需要定时查询删除任务的状态，并及时将删除结果通知终端用户。

#### 使用约束

  * 调用频率不超过1条/秒。




#### 接口原型

**承载协议**|  HTTP GET  
---|---  
**接口方向**|  分析服务服务器→开发者回调接口服务器  
**接口URL**|  GET https://<URI>/analytics/gdpr/user_deletion_tasks/v2  
**数据格式**|  请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
#### 请求参数

**表1** 请求Body参数参数| 是否必选| 参数类型| 描述  
---|---|---|---  
aaid| 否| string| 通过HMS端侧接口获取。  
  
#### 响应参数

**表2  **响应Body参数参数| 是否必选| 参数类型| 描述  
---|---|---|---  
result_code| 是| String| 响应码，详见错误码。  
result_msg| 是| String| 响应描述。  
task_list| 否| TaskList| 任务列表。  
  
  


**表3  **TaskList结构参数名| 是否必选| 值| 说明  
---|---|---|---  
request_id| 是| String| 请求ID。  
request_time| 是| DateTime| 请求时间。  
status| 是| String| 任务状态：

  * DELETING: 删除中。
  * PENDING: 等待删除。
  * DELETED: 成功删除。
  * IDMAPPING_NOT_FOUND: ID映射关系未找到。
  * IDMAPPING_DEL_FAILED: 映射关系删除失败。

  
status_time| 否| DateTime| 状态最后更新时间。  
  
#### 响应示例
      
      1. HTTP/1.1 200 OK
        2. Content-Type: application/json; charset=UTF-8
        3. Connection: Close
        4. Content-Length: xxxx
        5. {
        6. "result_code":"0",
        7. "result_msg":"success",
        8. "task_list":[{
        9. "request_id":"12345678",
        10. "request_time":"datetime",
        11. "status":" DELETING ",
        12. "status_time":"datetime"
        13. }]
        14. }
    
    

#### 错误码

状态码| 错误码| 响应代码| 描述| 处理建议  
---|---|---|---|---  
200| 0| Success| 请求成功。| -  
400| 10020| invalidParameter| 非法参数。| 开发者修改填写错误的参数值。  
400| 10008| tooFrequentRequest| 接口请求过于频繁。| 开发者修改代码，降低查询导出任务状态的频率。
