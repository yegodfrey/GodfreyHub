GameSummaryClient类定义了游戏信息获取的相关接口。  
  
# Public Method Summary

Return| Method  
---|---  
Task<[GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)>| getLocalGameSummary()从本地缓存获取当前游戏信息。  
Task<[GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)>| getGameSummary()优先从游戏服务器获取当前游戏信息，获取失败时从本地缓存获取。  
  
# Public Methods  


## public Task<GameSummary> getLocalGameSummary()

以异步方式从本地缓存获取当前游戏信息。

**返回值**

Type| Description  
---|---  
Task<[GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)>| 包含当前游戏信息的[GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)对象。  
  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception)实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。  


## public Task<GameSummary> getGameSummary()

以异步方式从游戏服务器获取当前游戏信息，获取失败时再尝试从本地缓存获取。

**返回值**

Type| Description  
---|---  
Task<[GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)>| 返回当前游戏信息。  
  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception)实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。
