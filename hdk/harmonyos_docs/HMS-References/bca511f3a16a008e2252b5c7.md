语种检测云端调用API接口。  
  
## Classes

Class name| Class description  
---|---  
[MLRemoteLangDetector](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteLangDetector-4)| 语种检测器，用于根据提供的文本，进行语种检测。调用云端API，检测模型在云端运行。创建语种检测器有两种方式，根据实际情况二选一。  
[MLRemoteLangDetectorSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDetectorSetting-4)| 语种检测器的配置器。  
[MLRemoteLangDetectorSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLSettingFactory-4)| 创建语种检测器的配置器的实例。
