此包为文本识别组件，可用于从图片中识别出文本信息。  
提供了文本检测的核心API，主要包含以下类：  
属性设置类 MLRemoteTextSetting：提供设置云端分析器参数的API。  
属性设置类 MLLocalTextSetting：提供设置本地分析器参数的API。  
文本信息类 MLText：提供从检测结果获取文本信息的API。  
分析器类 MLTextAnalyzer：提供创建分析器及执行文本检测的API。  
  
## Classes

Class name| Class description  
---|---  
[MLLocalTextSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLLocalTextSetting-4)| 文本分析器设置类：  
设置文本分析器（MLTextAnalyzer）本地检测的属性，  
用于调用本地算法API接口检测图像中的文本。  
[MLLocalTextSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLLocalTextSettingFactory-4)| 创建文本检测配置器的实例，  
用于设置本地文本检测的属性。  
[MLRemoteTextSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteTextSetting-4)| 文本分析器设置类：  
设置文本分析器（MLTextAnalyzer）云端检测的属性，  
用于调用云端API接口检测图像中的文本。  
[MLRemoteTextSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteTextSettingFactory-4)| 创建云端文本检测配置器的实例，  
用于设置云端文本检测的属性。  
[MLText](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLText-4)| 表示图像检测出的文本信息。  
[MLText.Base](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4)| 文本信息的父类，表示图像检测出的基本文本信息。包含5个属性：  
1、检测出的文本内容  
2、文本的边框  
3、文本边框的顶点  
4、检测结果的置信度  
5、检测到的所有语种  
[MLText.Block](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBlock-4)| 表示图像中检测出的文本区块。包含继承自Base的5个属性和文本行：  
1、[getStringValue()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q6)：检测出的文本内容  
2、[getBorder()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q1)：文本区块的边框  
3、[getVertexes()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q7)：文本区块的顶点  
4、[getPossibility()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q5)：检测结果的置信度  
5、[getLanguageList()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q4)：检测到的所有语种  
6、[getContents()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q2)：组成文本区块的文本行  
[MLText.TextLine](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextTextLine-4)| 表示图像中检测出的文本行。包含继承自Base的5个属性和字：  
1、[getStringValue()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q6)：检测出的文本内容  
2、[getBorder()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q1)：文本行的边框  
3、[getVertexes()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q7)：文本行边框的顶点  
4、[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q4)[getPossibility()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q5)：检测结果的置信度  
5、[getLanguageList()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q4)：检测到的所有语种  
6、[getContents()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q2)：组成文本行的字  
[MLText.Word](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextWord-4)| 表示图像中检测出的字。包含继承自Base的5个属性：  
1、[getStringValue()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q6)：检测出的文本内容  
2、[getBorder()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q1)：文本元素的边框  
3、[getVertexes()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q7)：文本元素边框的顶点  
4、[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q4)[getPossibility()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q5)：检测结果的置信度  
5、[getLanguageList()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextBase-4#q4)：检测到的所有语种  
[MLTextAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextAnalyzer-4)| 文本分析器：检测图像中的文本信息（MLText）。  
[MLTextAnalyzer.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTextAnalyzerFactory-4)| 创建文本分析器实例，用于检测文本；仅支持本地检测，不支持云端检测。  
[TextLanguage](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/TextLanguage-4)| 表示图像检测出的语种。
