#### 功能介绍

应用服务端调用此接口后，能够同步应用服务端计算的自定义用户属性，用于基于用户自定义属性的分析及受众管理。

#### 场景描述

当开发者的应用服务器自行计算了一些用户属性、而不是在App端侧直接获取用户属性，同时开发者又希望将这些用户属性应用到高级分析提供的各种分析报告中（如作为查看报告时的一个过滤条件），开发者可以在其应用服务器调用此接口，通过服务端上报其自行计算的用户属性。

#### 使用约束

     * 每次请求中，userDataSet可以最多携带100个用户的信息。

     * 开发者可以通过移动端SDK上报的自定义用户属性、也可以通过服务端同步的自定义用户属性，累计可以上报不超过25个自定义用户属性。服务端同步自定义用户属性时，需要考虑端侧已经上报了多少个自定义用户属性，服务端同步自定用户属性数时，不能超过可用配额上限。

     * 如果有某个自定义用户属性即通过移动端上报、也通过服务端同步，则以服务端同步的自定义用户属性值为准。

     * 需要确保未将用户的个人数据作为自定义用户属性进行同步。

     * 每秒请求数不超过100。

#### 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 分析服务服务器→开发者回调接口服务器  
接口URL| POST https://<URI>/analytics/datacollection/import/user  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
#### 请求参数

**表1** 请求Body参数参数| 是否必选| 参数类型| 描述  
---|---|---|---  
data_type| 是| Integer| 数据类型：1：自定义用户属性。  
userdata_set| 是| UserData[1…100]| 待导入的用户及属性列表。  
**表2  **UserDataSet数据结构说明参数| 是否必选| 参数类型| 描述  
---|---|---|---  
id| 是| String| 用户ID，最多256个字符。  
properties| 是| UserProperty[1…25]| 用户属性列表。  
**表3  **UserProperty数据结构说明参数| 是否必选| 参数类型| 描述  
---|---|---|---  
id| 是| String| 用户属性的Id，由数字、字母、下划线组合成，且不能以数字开头，大于6个字符，最多256个字符。[example]favorite_sport  
value| 是| String| 用户属性值，最多256个字符。[example]football  
  
说明：

     1. 每次请求中，userDataSet可以最多携带100个用户的信息。

     2. 开发者可以通过移动端SDK上报自定义用户属性、也可以通过服务端同步自定义用户属性，累计可上报不超过25个自定义用户属性。服务端同步自定义用户属性时，需要考虑端侧已经上报了多少个自定义用户属性，服务端同步自定义用户属性时，不能超过可用配额上限。

     3. 如果有某个自定义用户属性既通过移动端上报、也通过服务端同步，则以服务端同步的自定义用户属性值为准。

     4. 需要确保未将用户的个人数据作为自定义用户属性进行同步。

     5. 每秒请求数不超过100。
