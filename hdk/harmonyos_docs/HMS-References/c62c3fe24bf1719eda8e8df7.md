RankingScore类主要用于返回排行榜中的某个分数的具体信息，在调用[RankingsClient](https://developer.huawei.com/consumer/en/doc/development/HMS-References/rankingsclient)的分数获取方法时会返回RankingScore类型的实例。

# Constant Summary

type| name| description  
---|---|---  
static final int| RANK_UNKNOWN| 未知的排行榜分数。  
  
# Public Method Summary

Return| Method  
---|---  
String| getDisplayRank()获取分数在排行榜中名次的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。  
String| getRankingDisplayScore()获取排行榜中展示的分数的分值。  
long| getPlayerRank()获取该分数在排行榜中的名次。  
long| getPlayerRawScore()获取该分数的原始分值。  
Player| getScoreOwnerPlayer()获取该分数对应的玩家信息。  
String| getScoreOwnerDisplayName()获取该分数对应玩家的昵称。  
Uri| getScoreOwnerHiIconUri()获取该分数对应玩家的高清头像URI地址。  
Uri| getScoreOwnerIconUri()获取该分数对应玩家的普通头像URI地址。  
String| getScoreTips()获取该分数对应的自定义单位。  
long| getScoreTimestamp()获取玩家达到该分数时的时间戳。  
int  
| getTimeDimension()获取分数对应的排行榜的时间维度。  
  
# Constants  


## public static final int RANK_UNKNOWN

未获取到排行榜分数时返回该常量。

常量值：-1

# Public Methods

## public String getDisplayRank()

获取分数在排行榜中名次的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。

**返回值**

Type| Description  
---|---  
String| 用于展示排行榜名次的本地化数字。  
  
## public String getRankingDisplayScore()  


获取排行榜中展示的分数的分值。

**返回值**

Type| Description  
---|---  
String| 排行榜中展示的分值。  
  
## public long getPlayerRank()  


获取该分数在排行榜中的名次。

**返回值**

Type| Description  
---|---  
long| 分数在排行榜中对应的名次。  
  
## public long getPlayerRawScore()

获取该分数的原始分值。例如分数的分值为时间值“09:30:25”，则原始分值为毫秒数。

**返回值**

Type| Description  
---|---  
long| 该分数的原始分值。  
  
## public Player getScoreOwnerPlayer()

获取分数对应的玩家信息。

**返回值**

Type| Description  
---|---  
[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4)| 返回分数对应的玩家信息。玩家信息中只包含昵称和头像信息，即只有getDisplayName、getHiResImageUri和getIconImageUri方法能获取到值，其他方法都返回空。  
  
## public String getScoreOwnerDisplayName()  


获取分数对应的玩家昵称。

**返回值**

Type| Description  
---|---  
String| 返回该分数对应玩家的昵称。如果玩家身份未知，会返回匿名的名称。  
  
## public Uri getScoreOwnerHiIconUri()

获取分数对应的玩家的高清头像URL地址。

**返回值**

Type| Description  
---|---  
Uri| 玩家的高清头像URL地址。如果没有则返回null。  
  
## public Uri getScoreOwnerIconUri()

获取分数对应的玩家的普通头像URL地址。

**返回值**

Type| Description  
---|---  
Uri| 玩家的普通图标URL地址。如果没有则返回null。  
  
## public String getScoreTips()

获取分数对应的自定义单位。由开发者在创建排行榜时指定。

**返回值**

Type| Description  
---|---  
String| 分数对应的自定义单位。  
  
## public long getScoreTimestamp()

获取玩家达到该分数时的时间戳。

**返回值**

Type| Description  
---|---  
long| 玩家达到该分数时的时间戳。  
  
## public int getTimeDimension()

获取分数对应排行榜的时间维度。

**返回值**

type| description  
---|---  
int| 排行榜时间维度。
     * 0：当天
     * 1：本周
     * 2：全部时间
