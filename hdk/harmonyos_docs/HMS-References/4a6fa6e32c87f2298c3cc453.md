#### 功能介绍  
  
由开发者实现，用于接受导出任务的执行状态。当分析服务导出任务完成后，通过该接口将导出的结果和文件的下载路径通过此接口返回。

#### 场景描述

开发者的应用服务器在调用“创建导出数据任务”接口后，Analytics Kit服务端异步导出数据，当分析服务导出任务完成后，通过该接口通知开发者的应用服务器导出任务的执行状态和文件下载路径，开发者需要提供接收通知的服务端接口，并根据通知及时下载已导出的数据。

#### 使用约束

  * 开发者需要按接口定义实现服务端接口，用于接收通知消息。

  * 开发者的应用服务器接收到通知消息后，需要在2小时内下载已经导出的数据文件。




#### 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 分析服务服务器→开发者回调接口服务器  
接口URL| {rootUrl}/sub/applications/{apiVersion}/purchases/get  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
#### 请求参数

**表1** 请求Body参数参数| 是否必选| 参数类型| 描述  
---|---|---|---  
request_id| 是| string| 请求编号，由创建数据导出任务接口返回。  
app_id| 是| string| 用户在AppGallery Connect上的AppID。  
status| 是| string| 任务状态

  * EXPORTED：成功导出。
  * NO_DATA：没有符合条件的数据。
  * EXPORT_FAILED：导出失败，建议重试。
  * TOO_MANY_RECORDS：一次导出数据量太多，建议缩小数据导出范围后重新发起请求。

  
file_path| 否| string| 导出文件下载路径，该字段只有在任务状态是“EXPORTED”才会有值。  
status_time| 否| DateTime| 状态最后更新时间。  
  
#### 响应参数

**表2  **响应Body参数参数| 是否必选| 参数类型| 描述  
---|---|---|---  
result_code| 是| String| 开发者服务端返回的处理结果状态。  
result_msg| 是| String| 开发者服务器处理结果的描述信息。  
  
#### 响应示例
      
      1. HTTP/1.1 200 OK
        2. Content-Type: application/json; charset=UTF-8
        3. Connection: Close
        4. Content-Length: xxxx
        5. {
        6. "result_code":"0",
        7. "result_msg":"success",
        8. }
