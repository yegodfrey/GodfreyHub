public class City implements Parcelable  
天气状态[WeatherStatus](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-weatherstatus-4)中的城市信息。包括城市码、省份名称、时区、和城市/区名称。  
  
## Public Method Summary

Return type| Method name  
---|---  
String| getCityCode()  
String| getProvinceName()  
String| getTimeZone()  
String| getName()  
  
## Public Methods

Method  
---  
public String getCityCode()  
获取服务内部使用的城市码标识符，用于标识全世界州/省市区/县乡镇。  
  
**Return**

Type| desc  
---|---  
String| 服务内部使用的城市码标识符，用于标识全世界州/省市区/县乡镇。  
Method  
---  
public String getProvinceName()  
获取省份名，可能返回空值。  
  
**Return**

Type| desc  
---|---  
String| 省名，可能返回空值。  
Method  
---  
public String getTimeZone()  
获取城市所在的时区timeZone，Alson格式。例如：Asia/shanghai。  
  
**Return**

Type| desc  
---|---  
String| 城市所在时区timeZone，Alson格式。例如：Asia/shanghai。  
Method  
---  
public String getName()  
获取城市/区镇名称。  
  
**Return**

Type| desc  
---|---  
String| 城市/区镇名称。
