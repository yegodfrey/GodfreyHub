# 1\. Overview  


Interface info  
---  
public interface com.huawei.hms.panorama.PanoramaInterface.PanoramaLocalInterface提供了应用内集成全景图展示的接口。

# 3\. Public Methods

## 3.1 init

Method  
---  
int init()初始化应用内接口。  
  
**Return**

Type| Description  
---|---  
int| 成功返回ResultCode.SUCCEED，失败返回错误码。  
  
## 3.2 getView

Method  
---  
View getView()从服务端获取展示全景图的视图对象，开发者可根据自己的实际情况将该视图添加到自己的布局中。  
  
**Return**

Type| Description  
---|---  
View| 用于渲染全景图的View。  
  
## 3.3 setImage

Method  
---  
int setImage(Uri uri, int type)设置全景图的图片并指定格式。  
  
**Parameters**

Parameter| Description  
  
---|---  
uri| 将要加载的全景图URI，支持以file、content及android.resource开头的三类Uri。  
type| 图片类型，当前支持球形全景图（[IMAGE_TYPE_SPHERICAL](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#IMAGE_TYPE_SPHERICAL)）、环形（柱状）全景图（[IMAGE_TYPE_RING](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface#IMAGE_TYPE_RING)）。  
  
**Return**

Type| Description  
---|---  
int| 成功返回ResultCode.SUCCEED，失败返回错误码。

**Parameters**

**Return**

Type| Description  
---|---

## 3.7 setControlMode

Method  
---  
void setControlMode(int mode)设置全景图浏览的控制方式，支持使用过程中动态切换。  
  
**Parameters**

Parameter| Description  
---|---  
mode| 设置全景图浏览的控制方式。当前支持的类型有：手机姿态控制和触摸控制，其中触摸控制需要开发者调用updateTouchEvent。  
  
## 3.8 updateTouchEvent

Method  
---  
void updateTouchEvent(MotionEvent event)更新视图触摸事件，在开启触屏控制模式的情况下，全景服务将根据触屏事件动态调整视图显示内容。  
  
**Parameters**

Parameter| Description  
---|---  
event| Android标准触摸事件，触摸位置以全景图View控件左上角为原点，可通过View的OnTouchListener传入。开发者可处理掉上层APP需要的触摸事件，将其余事件转给SDK处理。  
  
## 3.9 deInit

Method  
---  
void deInit()反初始化应用内接口并销毁资源。  
  
**Return**

Type| Description  
---|---  
int| 成功返回ResultCode.SUCCEED，失败返回错误码。
