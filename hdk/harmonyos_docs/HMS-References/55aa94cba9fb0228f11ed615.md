# activityRecords: delete  
  
删除指定的activityRecord数据。

#### 请求

#### [h2]HTTP请求
    
    
    DELETE
    https://health-api.cloud.huawei.com/hihealth/v1/activityRecords/activityRecordId

#### [h2]请求参数

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
activityRecordId | string | 待删除的活动记录 ID | 必选 | 长度范围：1~1000。  
  
#### [h2]请求体

无

#### 响应

空body体响应

#### 返回码

成功：http 204

失败：其他

#### 示例

#### [h2]请求
    
    
    DELETE
    https://health-api.cloud.huawei.com/hihealth/v1/activityRecords/145789654314
    Content-Type: application/json
    Authorization: Bearer ***

#### [h2]响应
    
    
    HTTP 204 No Content
