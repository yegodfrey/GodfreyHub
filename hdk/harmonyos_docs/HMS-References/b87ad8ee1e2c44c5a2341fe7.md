public abstract Task<[BeaconStatusResponse](https://developer.huawei.com/consumer/zh/doc/awareness-capture-beaconstatusresponse)> getBeaconStatus(BeaconStatus.Filter… filters)  
使用可变数量的filters参数，获取相关信标的信息。  
请注意，信标快照仅在API级别24或更高版本上可用。要使用此方法，您的应用必须在AndroidManifest.xml中声明android.permission.BLUETOOTH 和android.permission.ACCESS_FINE_LOCATION权限，并且用户必须在运行时选择同意。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
filters| 信标过滤器，可以通过以下任一方式构造过滤器：1．按照在信标下注册的附件信息的命名空间和类型进行过滤。2．按照在信标下注册的附件信息的命名空间、类型和内容进行过滤。  
  
**Return**  


Type| desc  
---|---  
Task<[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-beaconstatusresponse)>| 返回[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-beaconstatusresponse)的Task泛型。可以使用Task中的isSuccessful()判断是否成功。如果成功，可继续通过[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-beaconstatusresponse)获取信标数据；否则表示获取信标信息失败。

public abstract Task<[TimeCategoriesResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-timecategoriesresponse)> getTimeCategoriesByCountryCode(String countryCode)  
  
根据国家地区代码来获取当前时间状态。国家地区代码是根据ISO 3166-1标准的两位代码来的。使用国家码来获取时间状态时，会按照该国家首都的位置来返回时间状态和时区信息，即使该国家涉及多个时区。  
时间状态是TimeBarrier类中定义的上午[TIME_CATEGORY_MORNING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_MORNING)，下午[TIME_CATEGORY_AFTERNOON](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_AFTERNOON)，晚上[TIME_CATEGORY_EVENING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_EVENING)，夜间[TIME_CATEGORY_NIGHT](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NIGHT)，工作日[TIME_CATEGORY_WEEKDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKDAY)，休息日[TIME_CATEGORY_WEEKEND](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKEND)，节假日[TIME_CATEGORY_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_HOLIDAY)，非节假日[TIME_CATEGORY_NOT_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NOT_HOLIDAY)。  
请注意，时间快照仅在运行API级别24或更高版本的设备上可用。

请注意，时间快照仅在运行API级别24或更高版本的设备上可用。要使用此方法，您的应用必须在AndroidManifest.xml中声明android.permission.ACCESS_COARSE_LOCATION权限。

public abstract Task<[WeatherStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-weatherstatusresponse)> getWeatherByPosition(WeatherPosition position)  
获取指定地名的天气信息。由于系统的限制，5秒内调用快照接口不得超过20次；一个小时内，调用快照接口不得超过1000次。该接口为快照接口，遵循该条件限制，调用频率超过时，调用该天气接口将返回失败。  
根据指定的地址来获取天气，地址由国家、省份、城市、地区、县5个层级组成，其中城市名必须传入，其他4个属性非必需。建议将每个层级的地址写全，组成更精确的地址信息，以便获取更精确的天气信息。在输入地址时，需要指明输入地址使用的语言类型，系统将根据地址名的语言类型，返回对应语言的天气信息。  
例如可以传入“London”或者“England，London”，然后locale指定为”en_GB”来获取伦敦的天气；传入“中国，南京市”、“中国，江苏省，南京”、“江苏，南京”，然后locale指定为”zh_CN”来获取中国江苏省南京市的天气。  
请注意，天气快照仅在运行API级别24或更高版本的设备上可用。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
position| 需要查询的地点信息，包括地址信息和语言环境。地址由国家、省份、城市、地区、县等组成地点名，其中城市名必须传入，其他4个属性非必需。例如想查看英国伦敦的天气时，可以只传入城市名“伦敦”，或者也可以传入国家名“英国”和城市名“伦敦”。语言环境表示传入地址的语言类型，格式是locale格式，比如en_GB表示英国英语。需要注意的是，必须传入语言类型，且语言类型应当是“语言码_国家码”的格式。  
  
**Return**  


Type| desc  
---|---  
Task<[WeatherStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-weatherstatusresponse)>| 返回[WeatherStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-weatherstatusresponse)的Task泛型。可以调用[WeatherStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-weatherstatusresponse)中的getWeatherStatus可以获取到天气状态（WeatherStatus），天气状态中携带了指定位置的具体天气信息。

当Awareness Kit和HMS Core升级时，是否出现弹窗。注意：慎用该功能。如果设置成false将无法触发升级，没有升级弹窗提示，相当于在升级弹窗点击了取消升级。在没有完成升级前，Awareness Kit所有功能将不可用。只能等待完成静默升级后，功能恢复。静默升级触发时间一般为7-14天。
