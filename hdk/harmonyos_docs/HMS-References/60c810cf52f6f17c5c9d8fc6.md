Difference类主要用于返回具体的冲突信息，调用[OperationResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/operationresult)的getDifference方法会返回该对象。  
  
# **Public Method Summary**

Return| Method  
---|---  
[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)| getServerArchive()获取游戏服务器中已经存在的存档数据。  
[ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)| getEmptyArchiveDetails()获取发生冲突时待更新存档文件的[ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)对象。  
[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)| getRecentArchive()获取发生冲突时待修改的[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)对象。  
  
# Public Methods  


## public Archive getServerArchive()

获取游戏服务器中已经存在的存档数据。

**返回值**

Type| Description  
---|---  
[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)| 游戏服务器中与待修改的存档数据冲突的[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)对象。  
  
## public ArchiveDetails getEmptyArchiveDetails()  


获取发生冲突时待更新存档文件的[ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)对象。

**返回值**

Type| Description  
---|---  
[ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)| 更新存档文件的[ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)对象。  
  
## public Archive getRecentArchive()  


获取发生冲突时待修改的存档数据。

**返回值**

Type| Description  
---|---  
[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)| 待修改的[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)对象。
