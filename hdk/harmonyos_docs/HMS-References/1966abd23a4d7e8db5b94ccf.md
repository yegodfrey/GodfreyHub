public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier) discover(Collection<BeaconStatus.Filter> beaconTypes)  
信标发现围栏，添加此围栏后，当指定类型的信标被发现时，此围栏状态为[TRUE](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierstatus#TRUE)并触发围栏事件上报，5s后状态切换为[FALSE](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-barrierstatus#FALSE)。  
使用此围栏需添加android.permission.ACCESS_FINE_LOCATION和android.permission.BLUETOOTH权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
beaconTypes| 信标类型。  
  
  
**Return**  


Type| desc  
---|---  
[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)| 情景感知围栏。  
  
  
**Throws**  


Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（当参数为beaconTypes或不存在）异常。
