**com.huawei.hms.mlsdk.tts.MLTtsCallback**

单个语音合成任务回调。通过此回调监听语音合成任务的播放状态，以及错误和告警事件。

public void onAudioAvailable(String taskId, MLTtsAudioFragment audioFragment, int offset, Pair<Integer, Integer> range, Bundle bundle)  
TTS合成音频流回调接口，通过此接口将音频合成数据返回给App。当前实时输出音频数据默认规格为单声道，位深为16Bit，音频采样率为16kHZ。例如：语音合成任务输入文本T，返回的任务Id为"1587653499796229" ，合成时分成T1、T2两段文本。T1文本在合成时合成了3段音频，分别是A0，A1，A2；T2文本在合成时合成了2段音频，分别是A3，A4。以上会生成5个onAudioAvailable回调事件，分别如下：onAudioAvailable("1587653499796229", A0, 0, Pair(T1.START, T1.END), null)onAudioAvailable("1587653499796229", A1, 1, Pair(T1.START, T1.END), null)onAudioAvailable("1587653499796229", A2, 2, Pair(T1.START, T1.END), null)onAudioAvailable("1587653499796229", A3, 3, Pair(T2.START, T2.END), null)onAudioAvailable("1587653499796229", A4, 4, Pair(T2.START, T2.END), null)  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
taskId| 该音频对应的语音合成任务ID。  
audioFragment| 音频数据。  
offset| 一个语音合成任务会对应一个音频合成数据队列，该字段表示本次传输的音频分片在该队列中的偏移量。  
range| 本次传输的音频分片所在的文本区域，range.first为起始位置（包含的），range.second为结束位置（不包含的），以字符为单位计算，中文单个字算一个字符。例如：语音合成任务传入一段文本“机器学习，Hello！”，文本会被分割成“Hello！”和“机器学习”两段文本，这两段文本对应的range分别为(0,5)，(5,11)。  
bundle| 扩展字段。

public void onEvent(String taskId, int eventId, Bundle bundle)  
语音合成任务回调扩展接口，当前支持：1、播放状态监听，可通过此回调监听语音生成后播放开始、暂停、恢复、停止的接口。2、语音合成进度监听，可以通过此回调监听语音合成的开始、结束、处理完成的接口。  
  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
taskId| 回调事件对应的语音合成任务ID。  
eventId| 回调事件ID。

  * 播放相关回调（使用外部播放器时以下接口不会生效）：

[MLTtsConstants.EVENT_PLAY_START](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsConstants-4#EVENT_PLAY_START)：播放开始回调。[MLTtsConstants.EVENT_PLAY_RESUME](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsConstants-4#EVENT_PLAY_RESUME)：恢复播放的回调。[MLTtsConstants.EVENT_PLAY_PAUSE](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsConstants-4#EVENT_PLAY_PAUSE)：暂停播放的回调。[MLTtsConstants.EVENT_PLAY_STOP](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsConstants-4#EVENT_PLAY_STOP)：停止播放的回调。该接口携带boolean参数interrupted。如果为true，表示播放是非正常结束，是被外部打断播放。例如，清空模式，或主动调用stop接口，或出现异常。如果为false，则表示正常播放结束。

  * 语音合成相关回调：  


[MLTtsConstants.EVENT_SYNTHESIS_START](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsConstants-4#START)：语音合成开始的回调。[MLTtsConstants.EVENT_SYNTHESIS_END](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsConstants-4#END)：语音合成结束的回调。[MLTtsConstants.EVENT_SYNTHESIS_COMPLETE](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsConstants-4#COMPLETE)：语音合成事件处理完毕的回调。当打开实时流时（见[speak](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsEngine-4#speak)接口描述），流全部传输结束后调用此接口。该接口携带boolean参数interrupted。如果为true，表示语音合成任务是非正常结束，是被外部打断。例如，清空模式，或主动调用stop接口，或出现异常。如果为false，则表示语音合成正常结束。  
bundle| 扩展参数，配合eventId使用。

  * 当eventName = MLTtsConstants.EVENT_PLAY_STOP 时，携带boolean类型MLTtsConstants.EVENT_PLAY_STOP_INTERRUPTED，true表示被外部强制中断。
  * 当eventName = MLTtsConstants.EVENT_SYNTHESIS_COMPLETE时，携带boolean类型MLTtsConstants.EVENT_SYNTHESIS_INTERRUPTED，true表示被外部强制结束语音合成任务。

  
  
**Sample Code**
      
      1.  switch (eventId){ 
        2.     //以下回调事件类型是在使用内部播放器播放合成音频时，需要关注的回调接口。 
        3.     case MLTtsConstants.EVENT_PLAY_START: 
        4.         // 播放开始回调。 
        5.         break; 
        6.     case MLTtsConstants.EVENT_PLAY_STOP: 
        7.         // 播放停止回调。 
        8.         boolean isInterrupted = bundle.getBoolean(MLTtsConstants.EVENT_PLAYSTOP_INTERRUPTED); 
        9.         break; 
        10.     case MLTtsConstants.EVENT_PLAY_PAUSE: 
        11.         // 播放暂停回调。 
        12.         break; 
        13.     case MLTtsConstants.EVENT_PLAY_RESUME: 
        14.         // 播放恢复回调。 
        15.         break; 
        16.     //以下回调事件类型是在不使用内部播放器播放，只关注合成音频数据时，需要关注的回调接口。 
        17.     case MLTtsConstants.EVENT_SYNTHESIS_START: 
        18.         // 语音合成开始。 
        19.         break; 
        20.     case MLTtsConstants.EVENT_SYNTHESIS_END: 
        21.         // 语音合成结束，音频流可能还在调用onAudioAvailable传输中。 
        22.               break; 
        23.     case MLTtsConstants.EVENT_SYNTHESIS_COMPLETE: 
        24.         // 默认内部播放场景下，音频流都传递给播放器后调用。 
        25.         // OPEN_STREAM 和EXTERNAL_PLAYBACK模式下，音频流都传递APP后调用。 
        26.         boolean isInterrupted = bundle.getBoolean(MLTtsConstants.EVENT_SYNTHESIS_INTERRUPTED); 
        27.         break; 
        28.     default: 
        29.         break; 
        30.  }

public void onRangeStart(String taskId, int start, int end)  
TTS引擎会对语音合成任务输入的文本进行分割，可通过该回调对这些分割文本的起播事件进行监听。例如：语音合成任务输入文本T，返回的任务ID为"1587653499796229"，合成时分成T1、T2两段文本。当播放到T1文本时：onRangeStart("1587653499796229", T1.START, T1.END)。当播放到T2文本时：onRangeStart("1587653499796229", T2.START, T2.END)。App可通过监听此接口实现对当前播放文本进行高亮跟踪的功能。注意：不包含结束位置。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
taskId| 语音合成任务ID。  
start| 音频分片在输入文本中的起始位置。  
end| 音频分片对应当前语音合成任务输入文本中的结束位置（不包含）。  
  
**Sample Code**
      
      1.  //speak传入文本 "Hello Tom!How are you?" 
        2. MLTtsEngine ttsEngine = new MLTtsEngine(null)； 
        3. ttsEngine.setTtsCallback(new  new MLTtsCallback() { 
        4.     ... 
        5.     public void onRangeStart(String taskId, int start, int end) { 
        6.         // SDK按照如下方式调用 
        7.         // onRangeStart("1587653499796229", 0, 10); 表示"Hello Tom!"开始播放 
        8.         // onRangeStart("1587653499796229", 10, 22); 表示"How are you?"开始播放 
        9.     } 
        10.     ... 
        11. }); 
        12. ttsEngine.speak("Hello world!"); //返回taskId为"1587653499796229";

public void onWarn(String taskId, [MLTtsWarn warn](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsWarn-4))  
告警事件回调函数。此回调接口仅做告警通知，应用可根据具体业务场景决定是否忽略告警通知。例如，网络情况不好或带宽不够时，会收到[WARN_INSUFFICIENT_BANDWIDTH](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLTtsWarn-4)告警，可以做用户提示，也可以选择忽略。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
taskId| 发生告警的语音合成任务ID。  
warn| 发生告警详情。  
  
****Sample Code****
      
      1.  warnId = MLTtsWarn.WARN_INSUFFICIENT_BANDWIDTH;
