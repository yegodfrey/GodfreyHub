# 1 数据类型  
  
  * **LocationData**




包含位置数据的简单的对象。

字段| 类型  
---|---  
latitude| Float  
longitude| Float  
speed| Float  
bearing| Float  
accuracy| Float  
verticalAccuracyMeters| Float  
bearingAccuracyDegrees| Float  
speedAccuracyMetersPerSecond| Float  
time| Float  
fromMockProvider| Boolean  
  
  * **LocationRequest**




包含位置请求所需信息的简单对象。

字段| 类型  
---|---  
priority| Number  
interval| Float  
numUpdates| Number  
fastestInterval| Float  
expirationTime| Float  
expirationTimeDuration| Float  
smallestDisplacement| Float  
maxWaitTime| Float  
needAddress| Boolean  
language| String  
countryCode| String  
  
  * **LocationSettingsRequest**




包含位置设置请求所需信息的简单对象。

字段| 类型  
---|---  
locationRequests| Array  
needBle| Boolean  
alwaysShow| Boolean  
  
# 2 公共函数

  * **flushLocations**




更新正在处理的位置。

返回值| 描述  
---|---  
promise| 操作成功时返回true。 否则报错。  
  
  * **checkLocationSettings(locationSettingsRequest)**




传入LocationSettingsRequest 并返回LocationSettingsStatesResponse响应。

返回值| 描述  
---|---  
promise| 操作成功时返回true。 否则报错。  
  
  * **getLastLocation()**




获取最新可用位置。

返回值| 描述  
---|---  
promise| 操作成功时返回包含最后已知位置信息的Location对象。 否则报错。  
  
  * **getLastLocationWithAddress(locationRequest)**




获取最后一次请求的可用位置，包含详细的地址信息。

参数| 描述  
---|---  
locationRequest| LocationRequest对象。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回HWLocation对象。 否则报错。  
  
  * **getLocationAvailability()**




检查位置数据是否可用。

返回值| 描述  
---|---  
promise| 操作成功时返回Boolean值，表示位置是否可用。 否则报错。  
  
  * **setMockLocation(latLong)**




当使用模拟位置时，更新正在处理的位置。

参数| 描述  
---|---  
latLong| 包含经纬度字段的对象。 (Ex. {"longitude": 48.24123 ,"latitude": 24.34545})  
  
返回值| 描述  
---|---  
promise| 操作成功时返回true。 否则报错。  
  
  * **setMockMode(shouldMock)**




指定位置提供者是否使用模拟位置模式。 如过是，则不使用GPS和网络位置，直接返回通过setMockLocation(latLong)方法设置的位置。

参数| 描述  
---|---  
shouldMock| Boolean  
  
返回值| 描述  
---|---  
promise| 操作成功时返回true。 否则报错。  
  
  * **requestLocationUpdatesWithCallback(locationRequest)**




请求位置更新。 请求位置更新后，您可以通过addFusedLocationEventListener(callback)来订阅更新。

参数| 描述  
---|---  
locationRequest| LocationRequest对象。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回一个包含指定ID的对象，比如{"id": "7"}。 否则报错。  
  
  * **removeLocationUpdates(requestId)**




移除指定回调信息的位置更新。

参数| 描述  
---|---  
id| 包含请求ID的字符串。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回一个包含指定ID的对象，比如{"id": "7"}。 否则报错。  
  
  * **requestPermission()**




向用户展示定位权限请求对话框。

  * **hasPermission()**




检查应用是否拥有收集位置信息的必要权限。

返回值| 描述  
---|---  
promise| 操作成功时返回一个布尔值，表示应用是否有收集位置信息的权限。 否则报错。  
  
  * **addFusedLocationEventListener(callback)**




包含一个通过位置数据持续调用的回调函数。 您首先需要通过 requestLocationUpdatesWithCallback函数来注册更新。

参数| 描述  
---|---  
callback| 回调函数，具有一个Location对象作为入参。  
  
  * **removeFusedLocationEventListener(callback)**




移除通过addFusedLocationEventListenerk添加的事件监听器。

参数| 描述  
---|---  
callback| 待移除的回调。  
  
# 3 常量

常量| 描述  
---|---  
PriorityConstants.PRIORITY_BALANCED_POWER_ACCURACY| 用于请求街区级的位置。  
PriorityConstants.PRIORITY_HIGH_ACCURACY| 用于请求最精确的位置。  
PriorityConstants.PRIORITY_LOW_POWER| 用于请求城市级的位置。  
PriorityConstants.PRIORITY_NO_POWER| 用于请求最佳精度的位置，同时不增加功耗。
