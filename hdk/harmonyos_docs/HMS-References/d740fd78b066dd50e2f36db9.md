Ranking类主要用于返回具体排行榜数据，在调用[RankingsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingsclient)的getRankingSummary方法时会返回Ranking类型的实例。

# Constant Summary

type| name| description  
---|---|---  
static final int| SCORE_VALUE_HIGH_BETTER| 排行榜排序规则最大最好。  
static final int| SCORE_VALUE_SMALL_BETTER| 排行榜排序规则最小最好。  
  
# Public Method Summary

Return| Method  
---|---  
String| getRankingDisplayName()获取排行榜的展示名称。  
Uri| getRankingImageUri()获取排行榜图标的URI地址。  
String| getRankingId()获取排行榜的id。  
int| getRankingScoreOrder()获取排行榜的排序规则。  
ArrayList<[RankingVariant](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingvariant)>| getRankingVariants()获取玩家在排行榜列表按照3个时间维度（日、周、全部）的排行记录。  
  
# Constants  


## public static final int SCORE_VALUE_HIGH_BETTER

排行榜排序规则最大最好。

常量值：1

## public static final int SCORE_VALUE_SMALL_BETTER

排行榜排序规则最小最好。

常量值：0

# Public Methods

## public String getRankingDisplayName()

获取排行榜的展示名称。

**返回值**

Type| Description  
---|---  
String| 排行榜的展示名称。  
  
## public Uri getRankingImageUri()  


获取排行榜图标的URI地址。

**返回值**

Type| Description  
---|---  
Uri| 排行榜图标的URI地址。  
  
## public String getRankingId()

获取排行榜ID。

**返回值**

Type| Description  
---|---  
String| 排行榜ID。在创建排行榜时由AppGallery Connect分配。  
  
## public int getRankingScoreOrder()

获取排行榜的排序规则。

**返回值**

Type| Description  
---|---  
int| 排序规则。
     * Ranking.SCORE_VALUE_HIGH_BETTER（1）：最大更好
     * Ranking.SCORE_VALUE_SMALL_BETTER（0）：最小更好  
  
## public ArrayList<RankingVariant> getRankingVariants()

获取玩家在排行榜列表按照3个时间维度（日、周、全部）的排行记录。

**返回值**

Type| Description  
---|---  
ArrayList<[RankingVariant](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingvariant)>| 返回3个时间维度（日、周、全部）的[RankingVariant](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/rankingvariant)对象，包含当前玩家在这3个时间维度的分数信息。
