Archive类用于返回存档记录的元数据和文件信息，在打开存档或解决数据冲突时会返回该对象。

# Public Method Summary

Return| Method  
---|---  
abstract [ArchiveSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivesummary)| getSummary()获取存档记录的元数据。  
abstract [ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)| getDetails()获取存档记录的内容。  
  
# **Public Methods**

##  public abstract ArchiveSummary getSummary()

获取存档记录的元数据。

**返回值**

Type| Description  
---|---  
abstract [ArchiveSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivesummary)| 返回包含存档元数据的[ArchiveSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivesummary)对象。  
  
## public abstract ArchiveDetails getDetails()

获取存档记录的内容。

**返回值**

Type| Description  
---|---  
abstract [ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)| 返回包含存档对应内容的[ArchiveDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archivedetails)对象。
