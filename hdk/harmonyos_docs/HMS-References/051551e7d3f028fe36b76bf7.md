# dataCollectors: create  
  
创建一个数据采集器，数据采集器的ID是由请求体中的某些字段根据一定规则组合生成的，并且该ID在该用户下是唯一的。

#### 请求

#### [h2]HTTP请求
    
    
    POST
    https://health-api.cloud.huawei.com/hihealth/v1/dataCollectors

#### [h2]请求参数

无

#### [h2]请求体

请求体中的请求参数需要遵循下面的数据格式：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
collectorId | string | 数据采集器唯一标识，该字段由请求中的参数根据规则生成 | 可选 | 需满足如下拼接规则：collectorType:collectorDataType.name: appInfo.appPackageName:deviceInfo.manufacturer: deviceInfo.modelNum:deviceInfo.uniqueId:collectorName。配置时，配置值需与请求体中相关字段保持一致。  
collectorName | string | 使用该名称来标识用户下同一类型数据产生的数据采集器，内部标识 | 可选 | 长度范围：1~300  
name | string | 用户页面展示的数据采集器名称 | 可选 | 长度范围：1~1000  
collectorType | string | 数据采集器类型常量 | 必选 | 可支持的取值如下： "derived"：派生数据类型 "raw"：原始数据类型  
appInfo | AppInfo | 数据采集器的应用程序信息 | 必选 |     
collectorDataType | DataType | 数据类型定义 | 必选 |     
deviceInfo | DeviceInfo | 集成各种传感器的硬件设备描述，例如：手表、手环等可穿戴设备 | 可选 |     
  
AppInfo结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
appName | string | 应用的名称 |  appName和appPackageName至少存在一个。 | 长度范围：1~1000  
appPackageName | string | 应用程序的包名称 | 长度范围：1~300。 如果appPackageName/clientId同时存在，appPackageName/clientId必须匹配。  
clientId | string | 应用ID | 可选 | 由数字组成，长度范围：2~128。 如果appPackageName/clientId同时存在，appPackageName/clientId必须匹配。  
appVersion | string | 应用的版本信息 | 可选 | 长度范围：1~1000  
desc | string | 用于链接该应用程序的URL | 可选 | 长度范围：1~1000  
  
DataType结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束条件  
---|---|---|---|---  
name | string | 每个数据类型唯一的、命名空间的名称 | 必选 | HUAWEI提供了一组以com.huawei.命名空间开头的共享、可见的健康数据类型（[公共数据类型](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/public_dt-0000001050069714)/[受限数据类型](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/restricted_dt-0000001050071665)），也支持自定义数据类型，但是自定义的name不能以com.huawei.开头，长度范围：1~300  
field | list<DataTypeField> | 数据类型的一个维度 | 必选 |     
  
DataTypeField结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束条件  
---|---|---|---|---  
name | string | 定义的该数据维度的名称 | 必选 | 长度范围：1~1000 同一个DataType内，field不能重复。如果使用HUAWEI提供的[公共数据类型](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/public_dt-0000001050069714)/[受限数据类型](https://developer.huawei.com/consumer/cn/doc/HMS-Guides/restricted_dt-0000001050071665)，field要与定义的字段一致  
format | string | 数据类型中每个维度的支持格式 | 必选 | 可支持的格式如下： "float" "integer" "map" "string"  
optional | boolean | 对应数据赋值时是否必填： true：可选 false：必选 未配置时，默认必选 | 可选 |     
desc | string | 描述信息 | 可选 | 长度范围：1~1000  
  
DeviceInfo结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束条件  
---|---|---|---|---  
manufacturer | string | 产品制造商 | 必选 | 长度范围：1~300  
modelNum | string | 终端型号名称 | 必选 | 长度范围：1~300  
devType | string | 设备类型 | 必选 | 可支持的类型如下： "Phone"：手机 "Scales"：体脂称 "Smart Watch"：智能手表 "Smart Band"：智能手环 "Smart earphone"：耳机 "Blood glucose monitor"：血糖仪 "Blood pressure monitor"：血压计 "Heart rate monitor"：心率设备 "Unknown"：未知设备  
uniqueId | string | 硬件序列号或其他唯一标识 | 必选 | 长度范围：1~300  
version | string | 设备硬件/软件版本 | 可选 | 长度范围：1~1000  
  
#### 响应

创建成功后，返回DataCollector的所有字段，参考1.3中请求体。

#### 返回码

成功：http 200

失败：其他

#### 示例

      }
    }
