public static final class PublicKeyCredentialCreationOptions.Builder  
用于生成PublicKeyCredentialCreationOptions对象的构造器。  
  
## Public method summary

Return type| Method name  
---|---  
Builder| **setChallenge**(byte[] challenge)设置挑战值。  
Builder| **setRp**(PublicKeyCredentialRpEntity rp)设置新建凭据时的依赖方属性。  
Builder| **setUser**(PublicKeyCredentialUserEntity user)设置用户账户相关信息。  
Builder| **setPubKeyCredParams**(ListpubKeyCredParams)设置认证凭据额外参数列表。  
Builder| **setExcludeList**(ListexcludeList)设置注册请求的入参列表。  
Builder| **setExtensions**(Mapextensions)设置扩展参数。  
Builder| **setAuthenticatorSelection**(AuthenticatorSelectionCriteria authenticatorSelection)设置WebAuthn依赖方指定的与认证器相关的配置项。  
Builder| **setAttestation**(AttestationConveyancePreference attestation)设置凭据传递偏好。  
Builder| **setTimeoutSeconds**(Long timeoutSeconds)设置超时时间。  
PublicKeyCredentialCreationOptions| **build**()构造PublicKeyCredentialCreationOptions实例。
