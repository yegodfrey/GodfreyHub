# DataCollector.Builder

**CLASS info**  
---  
public static class Builder  
创建DataCollector的构造器  
  
#### Public Method Summary

**Return** | **Method**  
---|---  
Builder | setDataCollectorName(String dataCollectorName) 设置数据采集器的名称，入参可以是null或者长度在1到300之间的字符串  
Builder | setDataStreamName(String dataStreamName) 设置数据流名称，入参可以是空字符串或者长度在1到300之间的字符串  
Builder | setPackageName(String packageName) 设置应用程序包名称，入参可以是空字符串或者长度在1到300之间的字符串  
Builder | setPackageName(Context context) 根据上下文设置应用程序包名称  
Builder | setDeviceInfo(DeviceInfo deviceInfo) 设置设备信息，入参可以是null或者长度在1到1000之间的字符串  
Builder | setDataType(DataType dataType) 设置数据类型  
Builder | setDataGenerateType(int dataGenerateType) 设置数据采集器的类型，如Raw、derived等  
DataCollector | build() 构建数据采集器对象
