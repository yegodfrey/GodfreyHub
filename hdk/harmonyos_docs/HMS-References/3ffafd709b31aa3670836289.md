public String getLanguage()  
获取检测出的语种。  
  
**Return**

Type| desc  
---|---  
String| 返回BCP-47 语言标记，当前支持：  
“en”（英），“zh”（中），“ja”（日），“ko”（韩），  
“ru”（俄），“de”（德），“fr”（法），“it”（意大利），  
“pt”（葡萄牙），“es”（西班牙），“rm”（拉丁语系语言）；  
云侧接口还支持语种：  
“pl”（波兰），“no”（挪威），“sv”（瑞典），“da”（丹麦），“tr”（土耳其），“fi”（芬兰），“th”（泰语），“ar”（阿拉伯语），“hi”（印地语）。
