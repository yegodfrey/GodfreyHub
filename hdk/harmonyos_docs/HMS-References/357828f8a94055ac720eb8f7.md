**public interface HuaweiMap.OnMarkerClickListener**

OnMarkerClickListener是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)类的一个内部接口，包含一个抽象函数onMarkerClick([Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker))。

public abstract boolean onMarkerClick([Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker) marker)  
点击标记时回调此方法。注意，点击标记时发生的第一件事是关闭当前显示的所有信息窗口并触发[HuaweiMap.OnInfoWindowCloseListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-oninfowindowclosel)，然后再触发OnMarkerClickListener。因此，从任何标记的OnMarkerClickListener中调用 [isInfoWindowShown](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker#isInfoWindowShown\(\))()都将返回false。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
marker| 标记。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
boolean| 当监听器没有执行默认行为则返回true,否则返回false。
