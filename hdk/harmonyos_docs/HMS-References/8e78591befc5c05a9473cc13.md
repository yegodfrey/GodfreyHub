# 1 数据类型

  * **LatLng**




包含经纬度信息的简单对象。

字段| 类型  
---|---  
Latitude| 数值型  
Longitude| 数值型  
  
# 2 属性

属性| 类型| 描述  
---|---|---  
coordinates| Array<LatLng>| 多边形坐标数组。  
holes| Array<Array<LatLng>>| 多边形中空洞的2D坐标点数组，每个空洞至少有三个点。  
strokeWidth| 数值型| 线条宽度，单位为像素。  
strokeColor| 字符串| 线条颜色。  
fillColor| 字符串| 填充颜色。  
geodesic| Boolean| 表示是否将折线的每一段绘制成与墨卡托投影中直线相对的测地线。测地线表示在地表上两点之间的最短路径。绘制测地线曲线时假设地球是一个球体。  
tappable| Boolean| 表示折线是否可点击并使用onPress功能。  
  
# 3 事件

事件名称| 返回值| 描述  
---|---|---  
onPress| -| 用户点击多边形时调用的回调。
