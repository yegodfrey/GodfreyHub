# BleManager  
  
**CLASS info**  
---  
public class BleManager  
用于扫描和使用低功耗蓝牙设备。支持扫描和储存设备信息，设备保存后，可以通过 SensorsController和AutoRecorderController 获取设备数据。  
  
#### Public Method Summary

**Return** | **Method**  
---|---  
PendingResult<Status> | saveDevice(HiHealthKitClient client, String deviceAddress) 通过设备地址保存设备信息。  
PendingResult<Status> | saveDevice(HiHealthKitClient client, BleDeviceInfo BleDeviceInfo) 保存设备信息。  
PendingResult< BleDeviceInfosResult > | getSavedDevices(HiHealthKitClient client) 列出已经储存的所有设备。  
PendingResult<Status> | beginScan(HiHealthKitClient client, StartScanOptions options) 根据请求开始扫描对应的设备。  
PendingResult<Status> | endScan(HiHealthKitClient client, BleScanCallback callback) 结束当前的扫描。  
PendingResult<Status> | deleteDevice(HiHealthKitClient client, String deviceAddress) 通过设备地址将设备删除。  
PendingResult<Status> | deleteDevice(HiHealthKitClient client, BleDeviceInfo bleDeviceInfo) 通过设备信息将设备删除。

#### [h2]beginScan(HiHealthKitClient client, StartBleScanOptions options)

**Method**  
---  
public PendingResult<Status> beginScan(HiHealthKitClient client, StartBleScanOptions options)  
该方法需要启用蓝牙权限和位置权限，并打开手机上的蓝牙和位置信息开关。 启动蓝牙设备扫描，每次扫描到设备时，回调该方法onDeviceDiscover(BleDeviceInfo)，扫描结束时调用onScanEnd()。  
  
**Parameter name** | **Parameter desc**  
---|---  
client | HiHealthKitClient实例
