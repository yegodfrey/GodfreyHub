# HAEventType  


此接口提供了所有预定义事件的事件ID常量。

Qualifier and Type| Constant field| Value  
---|---|---  
static NSString *const| kCreatePaymentInfo| 结算过程中，用户已经添加付款信息时，上报此事件。此事件可以与StartCheckout、CompletePurchase组合适用，构建结算过程的漏斗分析。  
static NSString *const| kAddProduct2Cart| 用户添加商品到购物车时，上报此事件。此事件可以与ViewProduct、StartCheckout组合使用，构建商品购买的漏斗分析；也可用于分析用户对开发者的哪些商品感兴趣，进而对这些用户进行营销。  
static NSString *const| kAddProduct2WishList| 用户添加商品到收藏夹时，上报此事件。可用于分析用户对开发者的哪些商品感兴趣，进而对这些用户进行营销。  
static NSString *const| kStartApp| 用户打开应用时，上报此事件。  
static NSString *const| kStartCheckout| 用户下单后，点击结算按钮时，触发此事件。可以与ViewProduct、CompletePurchase等事件结合使用，用于分析电商购买漏斗转化情况。  
static NSString *const| kViewCampaign| 用户参考一个营销活动的内容时，触发此事件。可以用于分析评价营销活动的转化情况。  
static NSString *const| kViewCheckoutStep| 用户开始结算后，如果结算过程包括多个步骤，可以在每个步骤完成后，上报此事件。可以用于分析结算过程各个步骤的转化情况，优化产品设计。  
static NSString *const| kWinVirtualCoin| 用户获取到虚拟汇报时，上报此事件。可以用于分析用户获取虚拟币的难以程度，优化产品设计。  
static NSString *const| kCompletePurchase| 用户购买商品后，上报此事件。可以用于分析用户对哪些商品或内容更感信息，优化运营策略。  
static NSString *const| kObtainLeads| 获取到销售线索时，上报此事件。如开发者投放了广告，用户获取用户的联系方式，用户点击投放广告且填写并提交了联系方式时，可以上报该事件，以评估本次获取到的线索可能会给开发者带来的收入。可以用于评估投放广告的ROI。  
static NSString *const| kJoinUserGroup| 用户加入群组时，上报此事件。如社交类App，用户加入群聊。可以用于评价产品的社交特性对用户的吸引力。  
static NSString *const| kStartLevel| 游戏类应用，用户进入某个关卡，开始游戏时，上报此事件。可以与CompleteLevel结合使用，分析游戏关卡设计是否合理，有针对性地制定优化策略。  
static NSString *const| kCompleteLevel| 游戏类应用，用户完成某个关卡，上报此事件。可以与StartLevel结合使用，分析游戏关卡设计是否合理，有针对性地制定优化策略。  
static NSString *const| kUpgradeLevel| 游戏应用中用户升级时，上报此事件。分析产品的用户等级设置是否合理，有针对性地制定优化策略。  
static NSString *const| kSignIn| 有登录功能的应用，用户登录时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。  
static NSString *const| kSubmitScore| 游戏/教育类应用中，用户提交分数时，上报此事件。用于分析产品内容的难易程度，有针对性得制定优化策略。  
static NSString *const| kCreateOrder| 展示订单详情，用户开始结算之前上报此事件。可以和ViewProduct、CompletePurchase等事件组合使用，构建分析漏斗，分析用户在各个环节的流失情况，制定优化策略。  
static NSString *const| kRefundOrder| 用户退款成功后，上报此事件。可以分析退款造成的损失，有针对性得制定优化策略。  
static NSString *const| kDelProductFromCart| 用户将商品从购物车中移除时，上报此事件。可以对相关用户进行营销。  
static NSString *const| kSearch| 用户在应用内搜索内容时，上报此事件。可以与ViewSearchResult、ViewProduct等事件结合使用，分析搜索结果的准确性。  
static NSString *const| kViewContent| 用户点击内容时，上报此事件。如在电商应用内，点击列表中的某个商品以参考详情。可以分析用户对哪些商品感兴趣。  
static NSString *const| kUpdateCheckoutOption| 结算过程中，用户填写一些结算选项时，上报此事件。可以分析用户的结算偏好。  
static NSString *const| kShareContent| 用户通过社交渠道分享商品或内容时，上报此事件。可以分析用户对产品的忠诚度。  
static NSString *const| kRegisterAccount| 用户注册账号时，上报此事件。可以分析用户来源，有针对性得优化运营策略。  
static NSString *const| kConsumeVirtualCoin| 用户消费虚拟币时，上报此事件。可以用于分析用户对哪些产品更感兴趣。  
static NSString *const| kStartTutorial| 用户开始使用引导教程时，上报此事件。可以与CompleteTutorial结合使用，评价引导教程的质量，有针对性得制定优化措施。  
static NSString *const| kCompleteTutorial| 用户完成引导教程时，上报此事件。可以与StartTutorial结合使用，评价引导教程的质量，有针对性得制定优化措施。  
static NSString *const| kObtainAchievement| 用户达成某项新成就时，上报此事件。可以衡量成就等级设计是否合理，并有针对性得制定优化策略。  
static NSString *const| kViewProduct| 用户浏览商品时，上报此事件。可以分析用户对哪些商品感兴趣，也可用和其他事件组合完成漏斗分析。  
static NSString *const| kViewProductList| 浏览商品列表时，上报此事件。如用户按分类查看商品列表时。可以分析用户对哪些类型的内容更感兴趣。  
static NSString *const| kViewSearchResult| 用户查看搜索结果时，上报此事件。与ViewProduct、Search组合使用，衡量搜索算法的准确性。  
  
# HAParamType

此接口提供了所有预定义参数的参数ID，包括预定义参数的ID常量和预定义用户属性的ID常量。

Qualifier and Type| Constant field| Value  
---|---|---  
static NSString *const| kStoreName| 被添加到收藏夹中的商品来自于哪个店铺。  
static NSString *const| kBrand| 被添加到收藏夹中的商品的品牌。  
static NSString *const| kCategory| 被添加到收藏夹中的商品的分类。  
static NSString *const| kProductId| 被添加到购物车中的商品的ID。  
static NSString *const| kProductName| 被添加到购物车中的商品的名称。  
static NSString *const| kProductFeature| 关联的商品特征。  
static NSString *const| kPrice| 商品的价格。  
static NSString *const| kQuantity| 用户购买该商品的数量。  
static NSString *const| kRevenue| 该交易会给开发者带来的收入。  
static NSString *const| kCurrName| 标识收入的货币类型。与$Revenue一起使用。  
static NSString *const| kPlaceId| 商品所在地标识。  
static NSString *const| kDestination| 针对预定酒店场景，标识用户目的地。  
static NSString *const| kEndDate| 针对预定酒店场景，标识用户离店日期。  
static NSString *const| kBookingDays| 针对预定酒店场景，标识用户入住天数。  
static NSString *const| kPassengersNumber| 针对预定酒店场景，标识入住旅客人数。  
static NSString *const| kBookingRooms| 针对预定酒店场景，标识用户预定房间数。  
static NSString *const| kOriginatingPlace| 针对预定酒店场景，标识用户出发地。  
static NSString *const| kBeginDate| 针对预定酒店场景，标识用户入住日期。  
static NSString *const| kTransactionId| 开发者交易系统生成的交易ID。  
static NSString *const| kClass| 针对预定酒店场景，标识用户预定房间等级。  
static NSString *const| kClickId| 广告网络生成的用于标记广告点击的参数。  
static NSString *const| kPromotionName| 营销活动的名称。  
static NSString *const| kContent| 营销活动的营销内容。  
static NSString *const| kExtendParam| 自定义参数。

static NSString *const| kMaterialSlot| 创意素材被展示的位置信息。  
static NSString *const| kMedium| 营销活动的类型，如：CPC、Email等。  
static NSString *const| kSource| 营销活动提供者的标识，如Huawei PPS等。  
static NSString *const| kKeywords| 使用的搜索字符串/关键字。  
static NSString *const| kOption| 当前结算步骤中用户填写的结算选项。  
static NSString *const| kStep| 标识用户当前处于结算过程中的第几个步骤。  
static NSString *const| kVirtualCurrName| 本次交易产生的运输费。  
static NSString *const| kVoucher| 出发日期，入住日期或租赁开始日期。  
static NSString *const| kPlace| 商品所在地标识。  
static NSString *const| kShipping| 本次交易产生的运输费。  
static NSString *const| kTaxFee| 本次交易产生的税费。  
static NSString *const| kUserGroupId| 用户加入的用户群组ID。  
static NSString *const| kLevelName| 游戏中关卡的名称。  
static NSString *const| kResult| 操作的结果。  
static NSString *const| kRoleName| 标识用户的角色。  
static NSString *const| kLevelId| 游戏等级。  
static NSString *const| kChannel| 操作中使用的特定方法;例如，在sign_up或登录事件的上下文中的“facebook”或“email”。  
static NSString *const| kScore| 在游戏中得分。
