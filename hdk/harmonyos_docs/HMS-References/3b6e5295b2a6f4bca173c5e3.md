MLKit提供的实时语音识别SDK。  
  
此包提供了实时语音识别SDK，开发者集成此SDK，即可获取华为ML Kit提供的实时语音识别能力，开发者可以定义自己的拾音界面，开发丰富多彩的语音识别应用。

具体使用方法可参考：实时语音识别[开发步骤](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-asr-dev-4)。

## Class Summary

Return type| Method name  
---|---  
[MLAsrConstants](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/asrconstants)| 实时语音识别服务配置常量定义。  
[MLAsrListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/mlasrlistener)| 当识别相关事件发生后，使用该接口从MLAsrRecognizer接收数据和事件通知。  
[MLAsrRecognizer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/mlasrrecognizer)| 语音识别器。通过startRecognizing开始收听识别语音，开始前需要先设置监听器setAsrListener。
