public MLTextAnalyzer.Factory setLocalOCRMode(int analyseType)  
设置分析器检测模式，默认为独立检测模式OCR_DETECT_MODE。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
analyseType| 分析器检测模式                      OCR_DETECT_MODE：  
值为1， 独立检测模式，独立检测每一张传入图片，适用于单张图片的检测 。  
OCR_TRACKING_MODE：  
值为2， 追踪检测模式，以上一帧检测结果为基准，快速检测定位图片中文本位置，适用于视频流文本检测。  
  
  
**Return**  


Type| desc  
---|---  
MLTextAnalyzer.Factory| 返回MLTextAnalyzer.Factory的实例。
