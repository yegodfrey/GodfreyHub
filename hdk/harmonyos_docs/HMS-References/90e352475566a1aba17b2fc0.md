包含原生广告的类。  
  
## Interfaces

Interface name| Interface description  
---|---  
[DislikeAdListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-dislikeadlistener "DislikeAdListener")| 监听器，用以监听用户对广告不感兴趣事件。  
[DislikeAdReason](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-dislikeadreason "DislikeAdReason")| 用于获取用户对广告不感兴趣的原因。  
[MediaContent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-MediaContent "MediaContent")| 原生广告媒体内容信息。

[NativeAdAssetNames](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadassetnames "NativeAdAssetNames")| 原生广告所有组件常量ID。  
[NativeAdConfiguration.ChoicesPosition](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadconfiguration-choicesposition "NativeAdConfiguration.ChoicesPosition")| 广告选项图标位置常量。  
[NativeAdConfiguration.Direction](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ads-api-nativeadconfiguration-direction "NativeAdConfiguration.Direction")| 方向常量。
