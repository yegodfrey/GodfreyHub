处理接口异常场景的时候，您需要在接口返回的Task中设置OnFailureListener监听来获取到请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)实例对象，可以根据[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)实例中的[getStatusCode()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception#public%20int%20getStatusCode\(\))方法获取到错误码，通过[getStatusMessage()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/apiexception#public%20String%20getStatusMessage\(\))可以获知相关的失败信息。在某些场景下，比如调用[isEnvReady](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#isEnvReady)接口并返回错误码ORDER_HWID_NOT_LOGIN（60050）时，您可以通过获取到的[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)对象的getStatus()方法得到一个[Status](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/status)对象，然后使用[Status](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/status)对象的startResolutionForResult(activity, reqCode)即可拉起我们提供的账号登录页面。

相关示例：
      
      1. task.addOnFailureListener(new OnFailureListener() { 
        2.         @Override 
        3.         public void onFailure(Exception e) { 
        4.             if (e instanceof IapApiException) { 
        5.                 IapApiException iapApiException = (IapApiException) e; 
        6.                 Status status = iapApiException.getStatus(); 
        7.                 int returnCode = iapApiException.getStatusCode(); 
        8.                 String returnMsg = iapApiException.getStatusMessage;  
        9.                 return;  
        10.             }  
        11.         } 
        12. });
    
    

  


返回码| 值| 意义| 处理方式  
---|---|---|---  
OrderStatusCode.ORDER_STATE_SUCCESS| 0| 成功| -  
OrderStatusCode.ORDER_STATE_FAILED| -1| 通用失败错误码| 若购买请求返回该错误码，建议通过[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainOwnedPurchases)接口确认用户是否购买了该商品。  
OrderStatusCode.ORDER_STATE_CANCEL| 60000| 用户取消支付| 记录订单号，待用户再次执行支付操作时再执行支付流程。  
OrderStatusCode.ORDER_STATE_PARAM_ERROR| 60001| 参数错误，包括无参| 请检查请求参数是否遗漏，参数值格式是否正确。  
OrderStatusCode.ORDER_STATE_NET_ERROR| 60005| 网络连接异常| 应用向用户给出提示请用户检查网络。  
OrderStatusCode.ORDER_VR_UNINSTALL_ERROR| 60020| VR APK未安装错误码| 请先安装VR APK。VR支付场景返回。  
OrderStatusCode.ORDER_HWID_NOT_LOGIN| 60050| 未登录华为账号| 需要处理登录场景。针对支付和[isEnvReady](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#isEnvReady)接口，您可以通过status引导用户进行登录，其他接口则根据实际情况进行处理。  
OrderStatusCode.ORDER_PRODUCT_OWNED| 60051| 由于已经拥有该商品，购买失败| 可通过[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainOwnedPurchases)接口确认用户是否购买了该商品。若商品为消耗型商品，检查商品是否发货，确认发货成功之后调用[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#consumeOwnedPurchase)接口进行消耗，下次可正常购买；若商品为非消耗型商品或者订阅型商品，已经购买则不能再次购买。  
OrderStatusCode.ORDER_PRODUCT_NOT_OWNED| 60052| 由于未拥有该商品，消耗失败| 可通过[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainOwnedPurchases)接口确认用户是否购买了该商品。  
OrderStatusCode.ORDER_PRODUCT_CONSUMED| 60053| 商品已经消耗，不能再次消耗| 可通过[obtainOwnedPurchaseRecord](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#obtainOwnedPurchaseRecord)接口查询是否有该商品的消耗记录。  
OrderStatusCode.ORDER_ACCOUNT_AREA_NOT_SUPPORTED| 60054| 用户账号服务地暂不支持IAP| 存在服务地支持IAP但由于服务出错返回该错误码的场景，可重新调用相关接口或联系华为技术进行确认。  
OrderStatusCode.ORDER_NOT_ACCEPT_AGREEMENT| 60055| 用户未同意支付协议| 需要用户同意支付协议。从请求接口返回的[IapApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapApiException-v4)中获取到一个status对象，status包含协议页面的pendingIntent对象，应用可使用status.startResolutionForResult(activity, reqCode)方法来启动协议页面。  
OrderStatusCode.ORDER_HIGH_RISK_OPERATIONS| 60056| 用户触发风控，交易被拒绝| -
