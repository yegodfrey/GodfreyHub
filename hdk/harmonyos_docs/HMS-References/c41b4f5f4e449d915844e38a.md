# 接口功能

此接口用于查询全球最近一个月已取消或者有退费的购买信息。

# 调用场景

当您想查看近期订阅商品的取消或者退费情况，您可以调用华为应用内支付服务器提供的已取消或者退费购买查询接口进行查询，查询的时间范围为最近一个月内。

注：为避免批量查询的性能问题，并且https服务本身安全性高，因此返回的购买信息不包含签名信息。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器-> 华为应用内支付服务器  
接口URL| {rootUrl}/applications/{apiVersion}/purchases/cancelledListrootUrl在不同站点有不同的url：开发者应固定选择最近站点的Order服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#State-Infomation)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#h1-1590477491025)。  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
# 请求参数

**参数名称**| **必选(M)/****可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
endAt| O| Long| 希望查询的最近被取消或者退费的购买，UTC时间戳。在输入continuationToken情况下忽略，不能超过当前时间，默认值为当前时间；endAt必须大于等于startAt。  
startAt| O| Long| 希望查询的最近被取消或者退费的购买，UTC时间戳。在输入continuationToken情况下忽略，不能超过当前时间，默认值为当前时间；endAt必须大于等于startAt。  
maxRows| O| Integer| 大于0，当前查询返回的最大条数，默认值为1000，最大值也为1000.  
continuationToken| O| String| 输入上次查询返回的token以查询下一页数据  
type| M| Integer| 查询类别，在输入continuationToken情况下忽略：0：查询消费和非消费型商品的购买信息，也是默认值；1：查询消费、非消费型，以及订阅型商品的购买信息；

continuationToken| O| String| 表示下一页数据，如果返回，可以输入下一次查询请求，以此查询下一页数据
