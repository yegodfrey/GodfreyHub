# **接口功能**

● 应用服务端调用此接口时，使用Authorization Code获取用户Access Token，Refresh Token，ID Token。  
● 当Access Token快要失效或已经失效时，使用Refresh Token来获取新的Access Token。

# **调用场景**

● 已经通过授权拿到Authorization Code，调此接口获取access_token，refresh_token，id_token。  
● Access Token即将过期的时候调用。

# **接口原型**

承载协议  
| HTTP POST  
---|---  
接口方向| 开发者服务器->华为帐号服务器  
接口URL（开发者）| https://oauth-login.cloud.huawei.com/oauth2/v3/token  
接口URL（运营商）| https://oauth-login-at.platform.dbankcloud.com/oauth2/v3/token  
数据格式| Content-type: application/x-www-form-urlencoded  
  
  


# **接口约束**

Authorization Code只有5分钟有效期，并且用完一次就会失效。

# **请求参数**

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
grant_type| M| String| 请求类型。枚举值:  
● “authorization_code”：使用Authorization Code换取Access Token、Refresh Token及ID Token。  
● “refresh_token”： 刷新Access Token。  
client_id| M| String| APP ID，在创建应用后由华为开发者联盟为应用分配的唯一标识。APP ID的查询方法请参见[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。  
client_secret| M| String| APP SECRET，在创建应用后由华为开发者联盟为应用分配公钥。APP SECRET查询方法请参见[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。  
code| O| String| 当"grant_type"为"authorization_code"时，此参数必选。传入登录授权时获取到的Authorization Code。  
redirect_uri| O| String| 当"grant_type"为"authorization_code"时，传入申请帐号服务时配置的回调地址。  
refresh_token| O| String| 当"grant_type"为"refresh_token"时，此参数必选。传入使用Authorization Code获取的Refresh Token。  
  
  


# **返回参数(JSON格式)**

调用成功情况下,返回如下：

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
token_type| M| String| 固定字符串”Bearer”。  
access_token| M| String| Access Token。  
scope| M| String| Access Token中的[scope](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scope)。  
expires_in| O| Long| Access Token的过期时间，以秒为单位。默认60分钟过期。  
refresh_token| O| String| 如果应用申请帐号服务时,入参中包含access_type=offline，则会返回此参数。该参数用于刷新AccessToken。  
id_token| O| String| 如果应用申请帐号服务时,入参scope中包含openid，则会返回此参数（JWT格式）。ID Token的描述信息参见[ID Token验证接口](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-verify-id-token)中ID Token描述。  
  
  
调用失败情况下(HttpStatus=400)：

参数名称| 类型| 参数含义  
---|---|---  
error| int| 主错误码，错误码描述见返回码。  
sub_error| int| 子错误码，错误码描述见返回码。  
error_description| String| 错误描述信息。  
  
  
调用失败会返回json格式的错误码和子错误码。  
样例：
      
      1. HTTP/1.1 400 Bad Request
        2. Content-Type: application/json;charset=UTF-8
        3. {"error":1203,"sub_error":31204,"error_description":"The request is invalid"}
    
    

# **返回码**

主错误码| 子错误码| 错误码含义| 建议业务方处理方式  
---|---|---|---  
1101| 20002| client_id格式不对。| 这些情况是入参不对，需要检查参数的配置。  
20022| redirect_uri格式不对。  
20023| code中的redirect_uri与华为开发者联盟中配置回调地址不匹配。  
20086| need_code参数不合法。  
20024| code中的redirect_uri和入参不一致。  
20152| code格式不对。  
20154| code或refresh_token中的client_id和入参不一致。  
20172| client_secret格式不对。  
20182| grant_type值不对。  
20192| refresh_token格式不对。  
22023| redirect_uri如果以非hms开头，回调地址不是在开发者联盟上注册的地址。  
1102| 20001| client_id为空。  
20021| redirect_uri为空。  
20151| code为空。  
20181| grant_type为空。  
20191| refresh_token为空。  
1103| 20153| code非法。  
1203| 31202| RT满足了正则表达式校验，但是实际无法被解析。举例：原RT被截断了或者被编码转换了。  
12303| client_id在系统不存在。  
12304| client_secret不对。  
31218| refresh_token不满足正则表达式。  
1101| 20155| code过期，code只有5分钟有效期。| 需要重新获取Authorization Code。  
20156| code已经被使用过。  
1203| 11205| refresh_token过期。| 需要重新获取Refresh Token。  
31204| refresh_token已失效（用户修改密码或者登出操作，会使之前的refresh_token失效）。  
其他错误码| 其他错误码| 系统内部错误。| 1、建议进行重试调用，可能会成功。  
2、除了上面的子错误码，其他子错误码都算到这个分支里。  
3、建议把子错误码打印出来，有助于定位问题。
