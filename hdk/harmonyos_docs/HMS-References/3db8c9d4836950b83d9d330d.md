# **1.接口信息**

**功能** ：开发者调用发送Push消息API完成消息下发功能。

**约束** ：消息体最大不能超过4096Bytes（不包括token）。按Token发送时，最大Token数不能超过1000（系统当前配置值）。

# **2.接口原型**

**承载协议**|  HTTPS POST  
---|---  
**接口方向**|  应用服务器-> 服务器  
**接口 URL**| https://push-api.cloud.huawei.com/v1/[appid]/messages:send

# **4.接口错误码**

**HTTP****错误码**| **错误描述**| **解决措施**  
---|---|---  
200| OK| 不涉及  
400| 参数错误| 请检查响应内容错误码并根据错误码进一步排查问题  
401| 鉴权失败| 请检查HTTP头中Authorization参数里面的Access Token  
404| 找不到服务| 请检查请求url是否正确  
500| 服务内部错误| 请联系华为技术支持人员  
  
  


**业务错误码**| **错误描述**| **解决措施**  
---|---|---  
80000000| 成功| 不涉及。  
80100000| 部分token发送成功，返回的illegal_token为不合法而发送失败的token| 请检查返回值中发送失败的token  
80100001| token参数部分检查错误| 按照响应消息中的提示，请检查token参数。  
80100002| 发送同步消息的时候，token的数量必须为1| 请检查请求参数中token字段  
80100003| 消息结构体错误| 按照响应消息中的提示，请检查消息结构体的参数。  
80100004| 消息设置的过期时间小于当前时间导致| 请检查消息字段ttl  
80100013| 消息字段collapse_key不合法| 请检查消息字段collapse_key  
80100016| 消息里面含有敏感信息| 请检查消息里面是否包含敏感词，[详见FAQ](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/push-faq-v4#h1-1577152526378)。  
80100018| 消息体内容验签不通过| 请检查发给三方机构审核的消息体与发给Push服务器的消息体内容是否一致。  
80200001| Oauth认证错误| 请求HTTP头中Authorization参数里面的Access Token鉴权失败，请检查。  
80200003| Oauth Token过期| 请求HTTP头中Authorization参数里面的Access Token已过期，请重新申请后重试。  
80300002| 当前应用无权限下发推送消息| 请检查当前应用的推送权限，[详见FAQ](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/push-faq-v4#h1-1577152526378)。  
80300007| 所有token都是无效的| 请检查token参数，[详见FAQ](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/push-faq-v4#h1-1577152526378)。  
80300008| 消息体大小超过系统设置的默认值| 请求消息体大小超过默认值，请减小消息体后重试。  
80300010| 消息体中的token数量超过系统设置的默认值| 请减少token数量后分批发送。  
80300011| 无权限发送高级别通知消息| 需申请权限，[请参考FAQ](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/push-faq-v4#apply_special_permissions)。  
81000001| 系统内部错误| 请联系华为push技术支持人员。
