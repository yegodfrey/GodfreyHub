public Drive.Comments.List setCursor(String cursor)  
设置分页查询的起始游标。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
cursor| 分页游标，用于指定分页查询，由前一个响应的nextCursor获取；由于每次查询请求，服务器返回的评论数量至多为100个，如果本次待返回的评论数量大于100，则需要将响应中的nextCursor值设置为下一次查询的分页游标，再次进行遍历查询请求，直至响应结果中的nextCursor为空，才能获取到所有待查询的评论。
