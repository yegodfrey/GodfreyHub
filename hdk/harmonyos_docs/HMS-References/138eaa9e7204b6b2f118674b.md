# 1 数据类型  
  
  * **ActivityConversionInfo**




包含活动转换信息的简单对象。

字段| 类型  
---|---  
conversionType| Int  
activityType| Int  
  
  * **ActivityConversionData**




包含活动转换信息的简单对象。

字段| 类型  
---|---  
conversionType| Int  
elapsedTimeFromReboot| Float  
conversionType| Int  
  
  * **ActivityConversionRequest**




包含活动转换请求所需信息的数组。每一项都必须是该对象的格式。

字段| 类型  
---|---  
conversionType| Int  
activityType| Int  
  
  * **ActivityConversionResponse**




包含活动转换响应的简单对象。

字段| 类型  
---|---  
elapsedTimeFromReboot| Int  
mostActivityIdentification| ActivityIdentificationData  
activityIdentificationDatas| ActivityIdentificationData  
time| Int  
  
  * **ActivityIdentificationData**




包含活动转换数据的简单对象。

字段| 类型  
---|---  
possibility| Int  
identificationActivity| Int  
  
  * **ActivityIdentificationResponse**




包含活动识别响应的简单对象。

字段| 类型  
---|---  
elapsedTimeFromReboot| Int  
mostActivityIdentification| Int  
activityIdentificationDatas| ActivityIdentificationData  
time| Int  
  
# 2 公共函数

  * **createActivityConversionUpdates(activityConversionRequests)**




检测活动转换（进入或退出），比如检测用户状态从行走转换为骑车。 您可以通过addActivityConversionEventListener(callback)函数来订阅更新。

参数| 描述  
---|---  
activityConversionRequest| ActivityConversionRequest object.  
  
返回值| 描述  
---|---  
promise| 操作成功时返回一个包含请求码的对象，例如{"requestCode": "7"}。 否则报错。  
  
  * **createActivityIdentificationUpdates(intervalMillis)**




注册活动识别更新。 注册后，您可以通过addActivityIdentificationEventListener(callback) 函数来订阅更新。

参数| 描述  
---|---  
intervalMillis| 活动识别更新间隔，单位毫秒。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回一个包含请求码的对象，例如{"requestCode": "7"}。 否则报错。  
  
  * **deleteActivityConversionUpdates(requestCode)**




根据请求码移除活动转换更新。

参数| 描述  
---|---  
requestCode| 请求码。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回true。 否则报错。  
  
  * **deleteActivityIdentificationUpdates(requestCode)**




根据请求码移除活动识别更新。

参数| 描述  
---|---  
requestCode| 请求码。  
  
返回值| 描述  
---|---  
promise| 操作成功时返回true。 否则报错。  
  
  * **requestPermission()**




向用户展示活动权限请求对话框。

  * **hasPermission()**




检查应用是否有收集活动信息的必要权限。

返回值| 描述  
---|---  
promise| 操作成功时返回一个布尔值，表示应用是否有收集活动信息的权限。 否则报错。  
  
  * **addActivityIdentificationEventListener(callback)**




包含一个通过活动识别数据持续调用的回调函数。 您首先需要通过createActivityIdentificationUpdates函数注册更新。

参数| 描述  
---|---  
callback| 以ActivityIdentificationData对象为入参的回调函数。  
  
  * **removeActivityIdentificationEventListener(callback)**




移除通过addActivityIdentificationEventListener添加的事件监听器。

参数| 描述  
---|---  
callback| 待移除的回调。  
  
  * **addActivityConversionEventListener(callback)**




包含一个通过活动转换数据持续调用的回调函数。 您首先需要通过 createActivityConversionUpdates函数注册更新。

参数| 描述  
---|---  
callback| 以ActivityIdentificationData对象为入参的回调函数。  
  
  * **removeActivityConversionEventListener(callback)**




移除通过addActivityConversionEventListener添加的事件监听器。

参数| 描述  
---|---  
callback| 待移除的回调。  
  
# 3 常量

常量| 描述  
---|---  
ActivityConversions.VEHICLE| 设备用户在车上，比如在汽车上。  
ActivityConversions.BIKE| 设备用户在骑自行车。  
ActivityConversions.FOOT| 设备用户在步行或者奔跑。  
ActivityConversions.RUNNING| 设备用户在奔跑。该活动是FOOT活动的子活动。  
ActivityConversions.STILL| 设备用户处于静止状态。  
ActivityConversions.TILTING| 设备处于明显倾斜状态。  
ActivityConversions.OTHERS| 设备处于其他状态。  
ActivityConversions.WALKING| 设备用户在步行。 该活动是FOOT活动的一个子活动。  
Activities.ENTER_ACTIVITY_CONVERSION| 用户进入指定的活动。 取值为0。  
Activities.EXIT_ACTIVITY_CONVERSION| 用户退出指定的活动。 取值为1。
