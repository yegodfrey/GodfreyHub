无

无

public void onMapReady([HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap) huaweiMap)  
在地图对应的Activity或者Fragment上设置此接口的实例后，当地图可以被使用时会触发onMapReady方法，并提供非null的[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)实例。
