# **接口功能**  
  
查询服务子账号（Service Account）下面所有的Beacon信息。

# **调用场景**

调用此接口分页列举出当前开发者账号下的Beacon信息。

# **接口原型**

**承载协议**|  HTTPS POST  
---|---  
**接口方向**|  应用服务器或APP应用->近距离通信服务器  
**接口URL**|  https://{域名}/WiseCloudNearbyBeaconService/v1/queryBeaconList?projectId=[projectId]  
**数据格式**|  Content-type: application/json  
  
# **接口约束**  


需要获取服务账号凭证。

# **请求参数**

**参数名称**| **必选(M)/可选(O)**| **类型**| **参数说明**  
---|---|---|---  
timeStamp| M| Long| 请求头参数，时间戳。  
srcTranID| M| String| 请求头参数，事务ID，最长为24个字符。  
projectId| O| String| 查询参数。  
Authorization| M| String| 请求头参数，用于网关认证，请参考[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-common-service-account)获取JWT。  
upOrDown| M| int| 请求体参数，用于分页查询，1表示向后查询， 2表示向前查询。  
pageSize| M| int| 请求体参数，用于分页查询， 表示一页查询出的Beacon数量（最大值100）。  
sequence| M| Long| 请求体参数，表示Beacon的序号，由注册Beacon设备时，系统自动生成。如果upOrDown是1：则表示上一页的最后一个Beacon的序号；如果upOrDown是2：则端侧上报上一页的第一个Beacon的序号。  
status| O| String| 请求体参数，0、1组成的字符串，用于匹配特定状态的Beacon进行返回。从最低位依次往高位推算，第一位表示是否匹配激活状态的Beacon，第二位表示是否匹配去激活状态的Beacon，第三位表示是否匹配停用状态的Beacon。0表示不匹配，1表示匹配。例如：00000001表示匹配激活的Beacon，000000100表示匹配停用的Beacon，000000101表示匹配激活或者停用的Beacon。此参数不传则默认取00000011，匹配激活或者去激活状态的Beacon，最长为8个字符。  
property| O| String| 请求体参数，key:value键值对，表示Beacon的属性，用于匹配特定属性的Beacon设备，最长为64个字符。  
  
# **返回参数****  
**

请求成功：状态码200，响应体如下：

参数值| 类型| 参数说明  
---|---|---  
moreBeacon| int| 表示是否还要更多的Beacon，1表示还有Beacon，可以再次查询。0表示没有更多的Beacon了。  
beacons| Json object| Beacon结构体的列表，Beacon具体见下面Beacon结构体定义。  
  
Beacon结构体定义：
    
    
    复制
      
        1. {
        2. "sequence": 1578643043892,
        3. "beaconDesc": "beacon1 test",
        4. "beaconType": 1,
        5. "beaconId": "beac0025",
        6. "status": 2
        7. }
    
    

**参数名称**| **类型**| **参数说明**  
---|---|---  
beaconId| String| Beacon设备的ID。  
beaconType| int| Beacon设备的类型。  
beaconDesc| String| Beacon设备的描述。  
status| int| Beacon设备的状态：1表示激活，2表示去激活，3表示停用。  
sequence| Long| Beacon设备的序号。  
  
请求失败，状态码非200，响应体如下：

（1）非业务（网关校验失败，token过期等情况）请求失败时：

**参数名称**| **类型**| **参数含义**  
---|---|---  
error| String| 非业务返回的错误信息。  
  
（2）业务请求失败时：

**参数名称**| **类型**| **参数说明**  
---|---|---  
serviceError| object| 业务返回的错误信息。  
  
serviceError的JSON结构体为：

**参数名称**| **类型**| **参数含义**  
---|---|---  
code| int| 错误码，错误码描述见返回码。  
status| String| 错误状态。  
message| String| 错误描述信息。  
  
# **返回码**

**错误码**| **错误码含义**| **建议业务处理方式**  
---|---|---  
400000001| 请求头参数不对。| 检查请求头参数。  
400000002| 请求体参数不对。| 检查请求体参数。  
403000003| 服务账号不可用。| 检查服务账号是否可用，在华为开发者联盟的管理中心可查看服务账号状态。  
500000001| 内部服务错误。| 建议重试，重试仍失败则反馈该问题。
