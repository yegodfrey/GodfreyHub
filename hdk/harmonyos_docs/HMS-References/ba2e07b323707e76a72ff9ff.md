public interface TimeCategories  
表示当前时间和位置的语义时间状态的接口类。时间状态是TimeBarrier类中定义的上午[TIME_CATEGORY_MORNING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_MORNING)，下午[TIME_CATEGORY_AFTERNOON](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_AFTERNOON)，晚上[TIME_CATEGORY_EVENING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_EVENING)，夜间[TIME_CATEGORY_NIGHT](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NIGHT)，工作日[TIME_CATEGORY_WEEKDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKDAY)，休息日[TIME_CATEGORY_WEEKEND](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKEND)，节假日[TIME_CATEGORY_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_HOLIDAY)，非节假日[TIME_CATEGORY_NOT_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NOT_HOLIDAY)。

Method

public abstract int[] getTimeCategories()  
获取用户当前所在地的时间状态。  
  
**Return**

Type| desc  
---|---  
int[]| 与适用于当前时间和地理位置的所有时间状态标签相对应的int常数数组。时间状态是TimeBarrier类中定义的上午[TIME_CATEGORY_MORNING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_MORNING)，下午[TIME_CATEGORY_AFTERNOON](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_AFTERNOON)，晚上[TIME_CATEGORY_EVENING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_EVENING)，夜间[TIME_CATEGORY_NIGHT](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NIGHT)，工作日[TIME_CATEGORY_WEEKDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKDAY)，休息日[TIME_CATEGORY_WEEKEND](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKEND)，节假日[TIME_CATEGORY_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_HOLIDAY)，非节假日[TIME_CATEGORY_NOT_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NOT_HOLIDAY)。  
Method

public abstract boolean isTimeCategory(int desiredTimeCategory)  
判断当前的时间状态信息是否包含传入的时间状态标签。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
desiredTimeCategory| 时间状态标签。  
  
  
**Return**  


Type| desc  
---|---  
boolean| 如果当前的时间状态信息包含传入的时间状态，则返回true；否则返回false。
