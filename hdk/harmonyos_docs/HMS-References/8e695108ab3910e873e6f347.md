# 功能介绍

对于消耗型商品，发货成功后，您可以调用此接口，以此通知华为应用内支付服务器更新商品的发货状态。如果不通知，将导致无法再次购买这个商品。

说明：

该接口的作用类似于客户端的[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#consumeOwnedPurchase)接口。

# 接口原型  


承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器-> 华为应用内支付服务器  
接口URL| {rootUrl}/applications/{apiVersion}/purchases/confirmrootUrl在不同站点有不同的url：开发者应固定选择最近站点的Order服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#State-Infomation)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#h1-1590477491025)。  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
# 请求参数

**参数**| **是否必选**| **参数类型**| **描述**  
---|---|---|---  
purchaseToken| 是| String| 商品的已购买Token，发起购买和查询订阅信息均会返回。  
productId| 是| String| 商品Id。  
  
# 响应参数

**参数**| **是否必选**| **参数类型**| **描述**  
---|---|---|---  
responseCode| 是| String| 返回码。● 0：成功● 其他：失败，具体参见[接口错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#h1-1578313441097-0)。  
responseMessage| 否| String| 响应描述。
