## Classes  
  
Class name| Class description  
---|---  
About| 用户信息类，包括用户名，存储容量，上传限制，是否要提示安全策略更新等状态信息。  
Change| File或者Drive的变化Change描述类。  
ChangeList| 变化列表数据模型类，用于网络传输ChangeList数据的解析和序列化。  
Channel| 资源变更通知通道数据模型类。  
File| File文件元数据类。  
FileList| File类对象列表类。  
Permission| Permission实体，文件权限类。  
PermissionList| 文件权限列表类。  
StartCursor| StartCursor对象类，即文件变化起始Cursor。  
User| Drive 用户详情类。  
Reply| Drive file文件评论的回复。  
ReplyList| 文件评论的回复列表类。  
Comment| 文件评论模型类。  
CommentList| CommentList实体，文件权限类。
