**根据  ****modelId  ****获取对应的优惠券模板。**  


**HTTP请求**  


GET  
https://**${url}** /hmspass/v1/offer/model/**{modelId}**  
备注：请求地址中的 **${url}  **变量需要开发者根据服务器所属区域自行选择，请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。  


## URL路径参数

  
|   
|   
  
---|---|---  
modelId| String| 优惠券模板的唯一标识符，这个 Id 在商户的所有模板中是全局唯一的，这个 Id 只能包含字母、数字和（.）、（-）、（_）。  
  
## **请求体**

请求体必须为空。

# 2 响应

如果成功，响应消息包含 modelId 所对应的 [hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject") 对象。
