情景感知快照包，包含获取信标状态、活动状态、耳机状态、地理位置、时间状态、天气状态、光照度、车载蓝牙状态和各能力支持状态等快照的请求响应。  
  
## Classes

Class name| Class description  
---|---  
[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-beaconstatusresponse)| 信标状态的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getBeaconStatus](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getBeaconStatus1)方法获取。  
[BehaviorResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-behaviorresponse)| 活动状态的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getBehavior](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getBehavior)方法获取。  
[HeadsetStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-headsetstatusresponse)| 耳机状态的请求响应。可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getHeadsetStatus](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getHeadsetStatus)方法获取。  
[LocationResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-locationresponse)| 地理位置的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getLocation](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getLocation)方法获取上次的地理位置响应，或调用getCurrentLocation方法获取当前的地理位置响应。  
[TimeCategoriesResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-timecategoriesresponse)| 时间状态的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getTimeCategories](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getTimeCategories)方法获取。  
[AmbientLightResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-ambientlightresponse)| 光照度的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getLightIntensity](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getLightIntensity)方法获取。  
[WeatherStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-weatherstatusresponse)| 天气状态的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getWeatherByDevice](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getWeatherByDevice)方法获取设备当前位置天气状态响应；或者调用[getWeatherByIP](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getWeatherByIP)方法获取网络IP位置的天气状态响应；或者调用[getWeatherByPosition](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getWeatherByPosition)指定地址获取天气状态响应。  
[WeatherPosition](https://developer.huawei.com/consumer/cn/doc/awareness-capture-weatherposition)| 请求参数类，用来传入地址信息以获取天气信息。包括国家、省份、城市、区、县、语言类型等6个属性。  
[BluetoothStatusResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capture-bluetooth)| 车载蓝牙状态的请求响应。可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getBluetoothStatus](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getBluetoothStatus)方法获取。  
[CapabilityResponse](https://developer.huawei.com/consumer/cn/doc/awareness-capabilityresponse)| 能力查询快照请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[querySupportingCapabilities](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient#querySupportingCapabilities)方法获取。
