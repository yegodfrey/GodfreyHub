# dataCollectors: update

更新指定的数据采集器信息，但部分字段不允许更新，例如：collectorId, collectorDataType, collectorType, collectorName和deviceInfo(除了version字段)。

注意：只允许创建该数据采集器的应用对该数据采集器做更新操作，其他应用只支持读取该数据采集器的数据。

#### 请求

#### [h2]HTTP请求
    
    
    PUT 
    https://health-api.cloud.huawei.com/hihealth/v1/dataCollectors/dataCollectorId

#### [h2]请求参数

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
dataCollectorId | string | 数据采集器的唯一标识 | 必选 | 需与请求体collectorId一致  
  
#### [h2]请求体

请求体中的请求参数需要遵循下面的数据格式：

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
collectorId | string | 数据采集器的唯一标识 | 必选 | 需满足如下拼接规则：collectorType:collectorDataType.name: appInfo.appPackageName:deviceInfo.manufacturer: deviceInfo.modelNum:deviceInfo.uniqueId:collectorName。需与请求参数collectorId一致  
collectorName | string | 使用该名称来标识用户下同一类型数据产生的数据采集器，内部标识 | 可选 | 长度范围：1~300  
name | string | 用户页面展示的数据采集器名称 | 可选 | 长度范围：1~1000  
collectorType | string | 数据采集器类型常量。 | 必选 | 可支持的取值如下： "derived"：派生数据类型 "raw"：原始数据类型  
appInfo | AppInfo | 数据采集器的应用程序信息 | 必选 | 参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中AppInfo的约束说明  
collectorDataType | DataType | 数据类型定义 | 必选 | 参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中DataType的约束说明  
deviceInfo | DeviceInfo | 集成各种传感器的硬件设备描述，例如：手表、手环等可穿戴设备 | 可选 | 参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中DeviceInfo的约束说明  
  
#### 响应

更新后的DataCollector的所有字段，参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中请求体。

#### 返回码

成功：http 200

失败：其他
