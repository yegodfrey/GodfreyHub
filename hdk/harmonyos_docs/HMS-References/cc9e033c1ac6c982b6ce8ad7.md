public static boolean containDataFromIntent(Intent intent)  
如果Intent包含ActivityIdentificationResponse，则返回true。这是一个工具函数，可以从intent接收器内部调用，以确保接收到的intent来自活动识别。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
intent| 活动识别服务发送的Intent。  
  
**Return**

type| desc  
---|---  
boolean| 如果intent包含ActivityIdentificationResponse则返回true，intent为空或者intent中不包含ActivityIdentificationResponse则返回false。
