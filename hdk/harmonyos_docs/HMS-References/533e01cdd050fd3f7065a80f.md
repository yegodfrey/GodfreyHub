ArchiveConstants类定义了游戏存档的相关常量。

# Constant Summary

类型| 常量| 说明  
---|---|---  
String| ARCHIVE_SELECT| 玩家在应用助手存档列表页面选择查看存档时返回的常量。  
String| ARCHIVE_ADD| 玩家在应用助手存档列表页面选择新增存档时返回的常量。  
int| STRATEGY_SELF| 指定冲突解决策略时选择不解决冲突。  
int| STRATEGY_ACTIVE_TIME| 指定冲突解决策略时选择根据游戏时长由华为游戏服务服务器自动解决冲突。  
int| STRATEGY_TOTAL_PROGRESS| 指定冲突解决策略时选择根据游戏进度由华为游戏服务服务器自动解决冲突。  
int| STRATEGY_LAST_UPDATE| 指定冲突解决策略时选择根据游戏修改时间由华为游戏服务服务器自动解决冲突。  
  
# Constants  


## public static final String ARCHIVE_SELECT

玩家在应用助手存档列表页面选择查看某个存档时返回的常量。

可以使用Intent对象的getParcelableExtra(ArchiveConstants.ARCHIVE_SELECT)方法获取玩家选择的存档对应的bundle对象。

## public static final String ARCHIVE_ADD

玩家在应用助手存档列表页面选择新增存档时返回的常量。

## public static final int STRATEGY_SELF

指定冲突解决策略时选择不解决冲突。

常量值：-1

## public static final int STRATEGY_ACTIVE_TIME

指定冲突解决策略时选择根据游戏时长由华为游戏服务服务器自动解决冲突。

常量值：1

## public static final int STRATEGY_TOTAL_PROGRESS

指定冲突解决策略时选择根据游戏进度由华为游戏服务服务器自动解决冲突。

常量值：2

## public static final int STRATEGY_LAST_UPDATE

指定冲突解决策略时选择根据游戏修改时间由华为游戏服务服务器自动解决冲突。

常量值：3
