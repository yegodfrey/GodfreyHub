public MarkerOptions anchor(float u, float v)  
开发者调用此API可以设置[Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker)的锚点位置。当前u，v已设置固定值，所以该接口固定锚点位置为Marker图标的中部。  
该接口已弃用，设置锚点位置请使用anchorMarker。  
  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
u| 锚点的水平坐标，以图像宽度的比例，在[0，1]范围内。  
v| 锚点的垂直坐标，以图像高度的比例，在[0，1]范围内。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
MarkerOptions| 设置新的锚点位置后的MarkerOptions对象。

public MarkerOptions flat(boolean flat)  
开发者调用此API可以设置[Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker)是否平贴地图。如果标记平贴地图，则在相机旋转和倾斜时，标记仍将停留在地图上，但与[GroundOverlay](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-groundoverlay)不同，它将保持与照相机缩放时相同的大小。如果标记面对相机，它将始终面向相机绘制，并随相机旋转和倾斜。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
flat| 平贴地图设置为 true，面对相机设置为 false。默认值为false。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
MarkerOptions| 设置新的flat属性后的MarkerOptions对象。

public MarkerOptions infoWindowAnchor(float u, float v)

public MarkerOptions zIndex(float zIndex)  
用于设置[Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-marker)的z指数。z指数指的是标记的叠加顺序，具有较大z指数的标记会绘制在具有较小z指数的标记上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**
