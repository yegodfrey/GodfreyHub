public int getItemIdentity()  
获取帧ID，相机每生成一帧，都会对该帧进行编号，编号按次序不断加1，用于识别帧之间的生成次序。  
  
**Return**

Type| desc  
---|---  
int| 帧唯一ID，为整数。  
Method  
---  
public int getQuadrant()  
获取帧对应的相机屏幕方向。  
  
**Return**

Type| desc  
---|---  
int| 相机屏幕方向：  
0：正向横屏  
1：正向竖屏  
2：反向横屏  
3：反向竖屏

public long getTimestamp()

public void resetWidthAndHeight()  
重置图像元数据到正向横屏方位，如果当前相机屏幕是竖向的，则需要交换宽、高的数值。
