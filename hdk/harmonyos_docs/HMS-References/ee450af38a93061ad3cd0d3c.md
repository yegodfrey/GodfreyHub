## 概览

地图上添加信息窗。

## 构造方法

**构造方法**| **描述**  
---|---  
HWMapJsSDK.HWInfoWindow(infoWindowOptions)| infoWindowOptions用来设置InfoWindow的属性，见InfoWindowOptions。  
  
## 公共方法

**方法名**| **描述**| **参数类型**| **返回值**  
---|---|---|---  
close()| 关闭信息窗。| 无| 无  
getContent()| 获取信息窗内容。| 无| String | Element  
setContent(content)| 设置信息窗内容。| String | Element| 无  
getPosition()| 获取信息窗位置。| 无| [LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)  
setPosition(position)| 设置信息窗位置。| [LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)| 无  
open(marker)| 打开弹出框。| [Marker](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-marker)| 无  
  
## 事件

**事件**| **描述**| **用法**  
---|---|---  
close| 点击关闭。| infoWindow.addListener('close',  callback), 参数callback为自定义回调函数。  
  
## InfoWindowOptions

**参数名**| **必选(M)/****可选(O)**| **数据类型**| **描述**  
---|---|---|---  
map| M| [HWMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-map)| 地图实例。  
content| O| String | Element| 弹出框中的显示内容，可以是纯文本或者是HTML元素。窗口会根据内容自动调整大小。调用该接口需要注意跨站脚本攻击，SDK中没有过滤有可能导致xss的html代码，因为作为SDK无法区分是否开发者主动使用。  
position| M| [LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)| 弹出框显示的位置。  
offset| O| [Number,Number]| 设置x,y偏移量。默认位置是position指定的位置。
