public String getPaymentData()  
获取购买订单详情的JSON字符串。  
说明：只在使用[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntentWithPrice)接口返回，使用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntent)接口时不返回。  
  
**Return**

type| desc  
---|---  
String| 包含购买订单详情的JSON字符串。字符串中包含的参数请参见[PaymentData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PaymentData-v4)。  
Method  
---  
public String getPaymentSignature()  
该方法返回使用支付私钥签署购买数据（[getPaymentData方法返回的字符串](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PaymentData-v4)）生成的签名字符串。签名算法为SHA256WITHRSA。  
注意：应用在收到签名字符串后，需要参考[对响应消息验签](https://developer.huawei.com/consumer/cn/doc/iap-verifying-signature-returned-result-v4)的方法对购买数据的JSON字符串校验签名，成功才继续拉起支付。  
说明：只在使用[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntentWithPrice)接口返回，使用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-IapClient-v4#createPurchaseIntent)接口时不返回。  
  
**Return**

type| desc  
---|---  
String| 使用支付私钥签署购买订单数据（[getPaymentData方法返回的字符串](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-PaymentData-v4)）生成的签名字符串。签名算法为SHA256WITHRSA。
