# 接口鉴权方式  


分析服务采用共享API密钥的方式为开发者开放服务端接口，开发者服务器端在调用接口时，统一的消息头格式如下：

Http头定义| Value| Description  
---|---|---  
x-product-id| String| 用户在AppGallery  Connect上的ProductID  
x-app-id| String| 用户在AppGallery  Connect上的AppID  
Authorization| String| [请参考开放平台鉴权章节3.2客户端密码模式](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/30101#h2-3-2-)。**注意：** Bearer后面拼接空格，再拼接获取的access_token。
