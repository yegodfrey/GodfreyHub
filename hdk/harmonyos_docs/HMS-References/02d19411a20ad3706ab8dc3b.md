# **参数描述**

passVersion| String| Mandatory| Version of the hwWalletObject. The value contains a maximum of 64 bytes, consisting of only alphabetic letters, digits, dots (.), hyphens (-), and underscores (_)_._  
---|---|---|---  
passVersion| String| 创建模板时必选| 钱包对象版本，开发者可以依据此确定钱包对象的版本信息，最长64个字节，只能是字母、数字和（.）、（-）、（_）。  
passTypeIdentifier| String| 必选| 卡券类型，是一个固定值，需要开发者到华为开发者联盟申请。  
passStyleIdentifier| String| 必选| 开发者自己定义的模板 Id，模板 Id 需全局唯一，长度不超过128字节，只能是字母、数字和（.）、（-）、（_）。  
organizationName| String| 创建模板时必选| 开发者自定义的商户名称，是一个固定值，最长64个字节。  
organizationPassId| String| 创建个人化数据时必选| 开发者自定义的卡号，对应商户真实的卡号，最长128个字节，只能是字母、数字和（.）、（-）、（_）。  
serialNumber| String| 创建个人化数据时必选| 开发者自定义生成的instanceId，关联钱包对象，全局唯一，最长128个字节，只能是字母、数字和（.）、（-）、（_）。  
[fields](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-hwWalletObject-4)| Complex| 可选| 卡券展示信息
