CLASS info

public Interface Fido2Intent  
Fido2Client获取注册或认证启动FIDO2客户端的相关接口。  
  
## Public Method Summary

Return type| Method name  
---|---  
boolean| **canLaunch**()是否可以启动FIDO2客户端。  
void| **launchFido2Activity**(Activity activity, int requestCode)启动注册或认证FIDO2客户端。  
  
## Public methods

Method  
---  
boolean canLaunch()  
是否具备Intent。  
Method  
---  
void launchFido2Activity(Activity activity, int requestCode)  
启动Fido2的注册或认证Activity。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
activity| Activity实例，该Activity实例通过其onActivityResult接收FIDO处理结果注册请求消息。  
requestCode| 请求码，区分当前流程是注册还是认证。注册：Fido2Client.REGISTRATION_REQUEST。认证：Fido2Client.AUTHENTICATION_REQUEST。
