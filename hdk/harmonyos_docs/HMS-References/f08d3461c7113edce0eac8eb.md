class info

public class DriveScopes extends Object  
Drive可用的scopes类。  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
String| SCOPE_DRIVE| 所有权限，除应用文件夹权限。  
String| SCOPE_DRIVE_FILE| 允许查看和管理文件。  
String| SCOPE_DRIVE_READONLY| 只允许查看文件内容和元数据。  
String| SCOPE_DRIVE_METADATA| 允许查看和管理文件元数据，但不包括文件实体。  
String| SCOPE_DRIVE_METADATA_READONLY| 只允许查看文件元数据，但不包括文件实体。  
String| SCOPE_DRIVE_APPDATA| 支持app数据上传和存储。  
  
## Public Method Summary

Return type| Method name  
---|---  
static Set<String>| all()  
返回Drive定义的所有scopes集合（不可修改）。
