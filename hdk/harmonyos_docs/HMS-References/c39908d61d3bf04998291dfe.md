public String getDeveloperChallenge()  
获取开发者自定义挑战字。  
  
**Return**

type| desc  
---|---  
String| 开发者自定义的挑战字，唯一标识此次消耗请求。注意：该参数长度限制为(0, 64)。  
Method  
---  
public String getPurchaseToken()  
获取purchaseToken，即用户购买商品的token。  
  
**Return**

type| desc  
---|---  
String| 用户购买商品的标识，在支付商品时由支付服务器生成并在[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)中返回给应用。应用传入此参数供支付服务器对订单状态进行更新后再发放商品。
