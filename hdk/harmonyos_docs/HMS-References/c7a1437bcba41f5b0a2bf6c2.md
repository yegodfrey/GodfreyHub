public interface Fido2Client  
FIDO2 API入口。  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
int| REGISTRATION_REQUEST| 注册请求码。  
int| AUTHENTICATION_REQUEST| 认证请求码。  
  
## Public Method Summary

Return type| Method name  
---|---  
boolean| **isSupported**()是否可以使用FIDO2能力。  
void| **getRegistrationIntent**(Fido2RegistrationRequest request, NativeFido2RegistrationOptions options, Fido2IntentCallback callback)常规应用获取用于启动注册功能的FIDO2Intent对象。  
void| **getRegistrationIntent**(PrivilegedFido2RegistrationRequest request, Fido2IntentCallback callback)特权应用获取用于启动注册功能的FIDO2Intent对象。目前仅华为浏览器使用。开发者如果要使用，联系华为申请后才能正常使用。  
void| **getAuthenticationIntent**(Fido2AuthenticationRequest request, NativeFido2AuthenticationOptions options, Fido2IntentCallback callback)常规应用获取用于启动认证功能的Fido2Intent对象。  
void| **getAuthenticationIntent**(PrivilegedFido2AuthenticationRequest request, Fido2IntentCallback callback);特权应用获取用于启动认证功能的Fido2Intent对象。目前仅华为浏览器使用。开发者如果要使用，联系华为申请后才能正常使用。  
Fido2RegistrationResponse| **getFido2RegistrationResponse**(Intent data)获取注册结果。  
Fido2AuthenticationResponse| **getFido2AuthenticationResponse**(Intent data)获取认证结果。
