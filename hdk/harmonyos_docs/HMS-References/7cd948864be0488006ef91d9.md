public class Aqi implements Parcelable  
天气状态[WeatherStatus](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-weatherstatus-4)中的空气质量指数。包括一氧化碳浓度指数、二氧化氮浓度指数、臭氧浓度指数、pm10浓度指数、pm25浓度指数、二氧化硫浓度指数，和综合天气指数。
