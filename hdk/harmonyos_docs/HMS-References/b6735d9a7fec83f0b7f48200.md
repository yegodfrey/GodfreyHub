public int getConfidence()  
返回一个置信度，表示用户正在执行此活动的可能性，值在0~100之间。  
置信度的值越大，持有该设备的用户的行为与检测到的活动越一致。  
该值将<=100。这意味着较大的值表示检测到的活动很可能是正确的，而值<=50则表示可能存在另一个置信度差不多或更高的活动。  
多个活动可能同时具有很高的置信度。  
  
**Return**

Type| desc  
---|---  
int| 置信度，表示用户正在执行此活动的可能性，值在0~100之间。
