该包下提供了全景SDK所有的接口和类，开发者集成全景SDK后，就可使用提供的接口进行全景图浏览及交互。  


# Interfaces  


Interface  
| Description  
  
---|---  
[ _PanoramaInterface_](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-panointerface)  
|  提供了浏览全景图的基本接口。  
[ _PanoramaLocalInterface_](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-localinterface)  
|  获取用于应用内全景展示的接口。  
  
# Classes  


Class  
| Description  
  
---|---  
[ _Panorama_](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-pano)|  获取浏览全景图基本接口对象。  
[ _ImageInfoResult_](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-imageresult)  
|  全景图加载结果类。  
[ _ResultCode_](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/panorama-api-resultcode)  
|  通用错误码
