# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| HUAWEI Push服务器->应用服务器  
接口请求地址| 开发者的上行消息接收服务器的地址，由开发者定义，同AppGallery Connect上配置的接收地址一致。  
  
# 接口功能

华为push服务器调用此接口采用HTTPS方式给开发者服务器推送上行消息。

# 接口参数

接口请求参数（HTTP header）

参数名| 取值描述| 样例  
---|---|---  
X-HW-SIGNATURE| 消息头签名参数，必选字段，代表发送给开发者上行消息接收服务器的签名信息。| timestamp=1563105451261;nonce=:;value=E4YeOsnMtHZ6592U8B9S37238E+Hwtjfrmpf8AQXF+c=
     * timestamp为系统UTC时间戳。
     * nonce为英文冒号。
     * value为待加密字符串。
（timestamp+nonce+上行消息内容）使用回调秘钥进行HmacSHA256加密后，再经Base64编码后获得。  
X-HW-TIMESTAMP| 消息头时间戳参数，必选字段，代表华为服务器收到上行消息的时间。| 1563105451261  
  
接口请求参数（HTTP body）

参数名| 类型| 必选(M)/可选(O)| 参数说明  
---|---|---|---  
from| String| M| 发送上行消息的客户端应用的Token。  
category| String| M| 发送上行消息的应用的包名。  
message_id| String| M| 由端侧应用自己生成，保证应用内唯一的消息ID。  
data| String| O| 消息有效负载的键值对。字段内容需要加密，base64处理。  
  
接口响应参数

参数名| 类型| 参数含义  
---|---|---  
errno| String| 开发者服务端返回的处理结果状态。  
errmsg| String| 开发者处理结果的描述信息。
