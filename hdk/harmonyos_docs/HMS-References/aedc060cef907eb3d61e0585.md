Scan Kit提供[com.huawei.hms.hmsscankit](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hmsscankit4)和[com.huawei.hms.ml.scan](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hms-ml4)两个包，具体内容参考如下：  
  
  
**Package**| **Class**| **介绍**  
---|---|---  
[com.huawei.hms.hmsscankit](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hmsscankit4)| [ScanUtil](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-scanutil4)| 提供Default  View mode和Bitmap mode的扫码调用接口、生成二维码接口  
[RemoteView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-remoteview4)| 提供Customized  View mode的扫码调用接口  
[OnResultCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-onresultcallback4)| 提供Customized  View mode的扫码回调接口  
[WriterException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-WriterException4)| 生成码异常  
[com.huawei.hms.ml.scan](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hms-ml4)| [HmsScan](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hms-scan4)| 扫码结果的统一返回类  
[HmsScanAnalyzerOptions](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-analyzer-options4)| Default View mode 、Bitmap mode、Multiprocessor mode的扫码选项参数  
[HmsScanAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-analyzer4)| 提供Multiprocessor  mode的扫码调用接口  
  
  


**场景**| **需要使用的Class**  
---|---  
构建Default  View mode扫码方式| [ScanUtil](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-scanutil4)[HmsScanAnalyzerOptions](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-analyzer-options4)[HmsScan](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hms-scan4)  
构建Customized  View mode扫码方式| [RemoteView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-remoteview4)[OnResultCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-onresultcallback4)[HmsScan](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hms-scan4)  
构建Multiprocessor  mode扫码方式| [HmsScanAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-analyzer4)[HmsScanAnalyzerOptions](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-analyzer-options4)[HmsScan](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-hms-scan4)  
构建码生成方式| [ScanUtil](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-scanutil4)[WriterException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scan-WriterException4)
