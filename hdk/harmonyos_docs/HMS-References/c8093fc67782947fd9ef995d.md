public String getChannelInfo() throws android.os.RemoteException  
获取转化跟踪参数。  
  
**Return**

Return type| desc  
---|---  
String| 返回转化跟踪参数。  
JSON格式：{"channelInfo":"http%3a%2f%2fwww.huawei.com%2fappgalley%2fc001231", "clickTimestamp":1561820232123,"installTimestamp":1561820266321"}，其中channelInfo是转化跟踪参数，clickTimestamp是点击广告的时间戳，installTimestamp是安装APP的时间戳。  
  
**Throws**

Parameter name| Parameter desc  
---|---  
RemoteException| 远程服务发生错误时抛出。
