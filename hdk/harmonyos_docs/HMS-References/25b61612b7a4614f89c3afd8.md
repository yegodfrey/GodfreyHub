public interface Fido2IntentCallback extends Fido2Status  
Fido2Client获取注册或认证Intent回调的接口。  
  
## Public Method Summary

Return type| Method name  
---|---  
void| **onSuccess**(Fido2Intent fido2Intent)获取注册或认证Intent，成功时的回调。在主线程中执行。  
void| **void onFailure**(int errorCode, @NonNull CharSequence errString) Fido2Client获取注册或认证Intent，失败时的回调。在主线程中执行。
