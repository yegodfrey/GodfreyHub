该软件包提供了HMS MLKit中对象检测与跟踪的能力，定义了  
1.对象分析器（MLObjectAnalyzer）  
2.对象分析器配置类（MLObjectAnalyzerSetting）  
3.对象属性类（MLObject）  
开发人员可以通过实例化一个对象分析配置器（MLObjectAnalyzerSetting）配置对象分析器（MLObjectAnalyzer）的参数，以此配置器实例作为对象分析器的实例化参数，得到自定义的对象分析器，最终对象分析器返回对象属性类（MLObject）作为对象检测的结果。  
  
## Classes

Class name| Class description  
---|---  
[MLObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLObject-4)| 对象属性类，表示由对象分析器(MLObjectAnalyzer)检测到的对象。  
[MLObjectAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLObjectAnalyzer-4)| 对象分析器：用于在输入的图片或视频流中检测MLObject类型的对象。  
[MLObjectAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLObjectAnalyzerSetting-4)| 对象分析器设置类：用于设置分析器（MLObjectAnalyzer）的属性。  
[MLObjectAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLObjectAnalyzerSettingFactory-4)| 创建对象分析配置器的实例，用于设置对象检测的属性。
