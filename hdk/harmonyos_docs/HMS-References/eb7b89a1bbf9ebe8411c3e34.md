public class DailyLiveInfo implements Parcelable  
某日某项生活指数的信息。生活指数包括穿衣指数、运动指数、寒冷指数、洗车指数、旅游指数和紫外线指数。  
  
## Public Method Summary

Return type| Method name  
---|---  
String| getLevel()  
long| getDateTimeStamp()  
  
## Public Methods

Method  
---  
public String getLevel()  
获取某项生活指数的等级，每个生活指数都有各自的指数等级。例如，如果是穿衣指数，则这里获取到的level可能有“1”、“2”、“3”、“4”、“5”和“6”共6种等级。具体的生活指数和指数等级请参见[WeatherStatus](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-weatherstatus-4)。  
  
**Return**

Type| desc  
---|---  
String| 某项生活指数的等级，每个生活指数都有各自的指数等级。例如，如果是穿衣指数，则这里获取到的level可能有“1”、“2”、“3”、“4”、“5”和“6”共6种等级。具体的生活指数和指数等级请参见[WeatherStatus](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-weatherstatus-4)。  
Method  
---  
public long getDateTimeStamp()  
获取某天生活指数对应该天的时间戳，表示的是当地凌晨的时间戳。  
  
**Return**

Type| desc  
---|---  
long| 某天生活指数对应该天的时间戳，表示的是当地凌晨的时间戳。
