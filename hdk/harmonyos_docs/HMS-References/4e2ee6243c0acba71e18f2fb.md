ArchiveSummaryUpdate类主要用于提交存档记录或解决数据冲突时保存对存档元数据的修改。

# **Public Method Summary**  


Return| Method  
---|---  
abstract Bitmap| getThumbnail()获取存档变更的封面图片。  
abstract String| getDescInfo()获取存档变更的描述信息。描述信息在ArchiveSummaryUpdate对象中必须存在。  
abstract long| getActiveTime()获取存档变更的存档时长。  
abstract long| getCurrentProgress()存档变更的进度值。  
abstract String| getThumbnailMimeType()获取存档变更的封面图片的Mime类型。当存在封面图片时，Mime类型肯定存在。  
  
# Public Methods  


## public abstract Bitmap getThumbnail()

获取存档变更的封面图片。

**返回值**

Type| Description  
---|---  
Bitmap| 存档封面图片。  
  
## public abstract String getDescInfo()  


获取存档描述信息。

**返回值**

Type| Description  
---|---  
String| 存档描述信息。描述信息在ArchiveSummaryUpdate对象中必须存在。  
  
## public abstract long getActiveTime()  


获取存档的时长。

**返回值**

Type| Description  
---|---  
long| 存档的时长。由开发者在提交存档时自行定义。  
  
## public abstract long getCurrentProgress()  


获取存档的进度值。

**返回值**

Type| Description  
---|---  
long| 存档的进度值。由开发者在提交存档时自行定义。  
  
## public abstract String getThumbnailMimeType()  


获取存档封面图片的Mime类型。

**返回值**

Type| Description  
---|---  
String| 存档封面图片的Mime类型。
