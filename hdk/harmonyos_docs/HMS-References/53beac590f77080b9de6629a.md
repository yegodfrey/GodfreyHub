com.huawei.hms.mlplugin.card.gcr.MLGcrCaptureUIConfig  
通用卡证识别UI界面配置器，支持提示文本，扫描框，屏幕方位等客制化配置。  
  
# Constant Summary

Type| Name| Desc  
---|---|---  
int| ORIENTATION_AUTO| 自动，由物理感应器决定显示方向。  
int| ORIENTATION_LANDSCAPE| 横屏，显示时屏幕宽度大于高度。  
int| ORIENTATION_PORTRAIT| 竖屏，显示时屏幕高度大于宽度。
