#### [h2]register(SensorOptions options, OnSamplePointListener listener)

**Method**  
---  
public Task<Void> register(SensorOptions options, OnSamplePointListener listener)  
添加对指定数据采集器的监听。  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
options | 请求指定的数据采集器、数据类型  
listener | 数据返回监听器  
  
**Throws**

**Throw name** | **Throw desc**  
---|---  
SecurityException | 如果缺少指定的数据类型或数据采集器权限，则抛出异常  
RemoteException | 如果通信连接失败，则抛出异常  
IllegalStateException | 如果服务没有连接成功，则抛出异常  
  
示例代码：
    
    // 创建一个SensorsController 对象用于获取数据 
        private SensorsController mSensorsController; 
     
         /** 
         * 注册监听器从手机获取步数 
         * 
         * @param view 前端事件对象 
         */ 
        public void registerSteps(View view) { 
            // 获取SensorsController 
            mSensorsController = HuaweiHiHealth.getSensorsController(this, signInHuaweiId); 
     
            if (mSensorsController == null) { 
                Log.i("SensorsController is null"); 
                return; 
            } 
     
            // 构建一个SensorsOptions 传入数据类型，此处为总步数 
            SensorOptions.Builder builder = new SensorOptions.Builder(); 
            builder.setDataType(DataType.DT_CONTINUOUS_STEPS_TOTAL); 
     
            // 注册监听器，并添加注册成功、失败的回调 
            mSensorsController.register(builder.build(), onSamplePointListener) 
                .addOnSuccessListener(new OnSuccessListener<Void>() { 
                    @Override 
                    public void onSuccess(Void aVoid) { 
                        Log.i("registerSteps successed... "); 
                    } 
                }) 
                .addOnFailureListener(new OnFailureListener() { 
                    @Override 
                    public void onFailure(Exception e) { 
                        Log.i("registerSteps failed... "); 
                    } 
                }); 
        } 
     
        /** 
         * 创建一个监听器对象用来接收步数上报 
         */ 
        private OnSamplePointListener onSamplePointListener = new OnSamplePointListener() { 
            @Override 
            public void onSamplePoint(SamplePoint samplePoint) { 
                // 计步器上报的步数、时间、类型等数据通过samplePoint 回调 
                Log.i(TAG, "Sample Point = " + samplePoint.getFieldValue(Field.FIELD_STEPS)); 
            } 
        };

#### [h2]getDataCollectors(DataCollectorsOptions options)

**Method**  
---  
public Task<List<DataCollector>> getDataCollectors(DataCollectorsOptions options)  
查找符合条件的数据采集器  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
options | 请求指定的数据采集器。  
  
**Return**

**Type** | **Return desc**  
---|---  
Task<List<DataCollector>> | 数据采集器列表  
  
**Throws**

**Throw name** | **Throw desc**  
---|---  
SecurityException | 如果缺少指定的数据类型或数据采集器权限，则抛出异常  
RemoteException | 如果通信连接失败，则抛出异常  
IllegalStateException | 如果服务没有连接成功，则抛出异常  
  
示例代码：
    
    // 创建一个SensorsController 对象用于获取数据 
        private SensorsController mSensorsController; 
        // 创建一个DataCollector 对象用于临时保存远端蓝牙设备 
        private DataCollector mDataCollector; 
     
    public void findDataCollectors(View view) { 
            mSensorsController = HuaweiHiHealth.getSensorsController(this, signInHuaweiId); 
            // 构建一个DataCollectorsOptions 将要找的设备类型传入，这里为心率设备 
            DataCollectorsOptions dataCollectorsOptions = 
                new DataCollectorsOptions.Builder().setDataTypes(DataType.DT_INSTANTANEOUS_HEART_RATE).build(); 
     
            // 将 dataSourcesRequest 作为参数，返回可用的心率设备 
            mSensorsController.getDataCollectors(dataCollectorsOptions) 
                .addOnSuccessListener(new OnSuccessListener<List<DataCollector>>() { 
                    @Override 
                    public void onSuccess(List<DataCollector> dataCollectors) { 
                        // dataCollectors 就是返回的可用数据源 
                        for (DataCollector dataCollector : dataCollectors) { 
                            Log.i("Sensor", "Available data collector:" + dataCollector.getDataCollectorName()); 
     
                            // 将心率数据源保存，后面注册监听器时用 
                            mDataCollector = dataCollector; 
                        } 
                    } 
                }) 
                .addOnFailureListener(new OnFailureListener() { 
                    @Override 
                    public void onFailure(Exception e) { 
                        Log.i("findDataCollectors failed... "); 
                    } 
                }); 
        }
