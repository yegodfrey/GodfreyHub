# 请求参数说明

## Coordinate

**参数名称**| **类型**| **参数含义**  
---|---|---  
lat| double| 纬度，取值范围[-90,90] 。  
lng| double| 经度，取值范围[-180,180] 。  
  
## Point

**名称**| **类型**| **描述**  
---|---|---  
lat| double| 纬度。  
lng| double| 经度。  
  
# 响应参数说明

## CoordinateBounds

**名称**| **类型**| **描述**  
---|---|---  
northeast| Coordinate| 东北角的位置。  
southwest| Coordinate| 西南角的位置。  
  
## Path

**名称**| **类型**| **描述**  
---|---|---  
steps| Step[]| 路线分段信息。  
distance| double| 行驶距离，单位是米。  
duration| double| 行驶时长，单位是秒。  
distanceText| String| Distance的文本描述  
durationInTraffic| double| 基于实时路况计算出来的行驶时长，单位是秒。  
durationText| String| Duration的文本描述  
startLocation| Coordinate| 出发地的经纬度。  
startAddress| String| startLocation对应的地址详情。  
endLocation| Coordinate| 目的地的经纬度。  
endAddress| String| endLocation对应的地址详情。  
viaWaypoints| ViaWaypoint[]| 途径点信息。  
  
## Route  


**名称**| **类型**| **描述**  
---|---|---  
paths| Path[]| 路线规划信息。  
optimizedWaypoints| int[]| 当viaType =  false 且 optimize =  true 时才会有结果，表示进行路径优化之后途径点的索引。  
bounds| CoordinateBounds| 路线边界范围。  
  
## Step  


**名称**| **类型**| **描述**  
---|---|---  
distance| double| 行驶距离，单位是米。  
distanceText| String| Distance的文本描述  
durationInTraffic| double| 基于实时路况计算出来的行驶时长，单位是秒。  
durationText| String| Duration的文本描述  
startLocation| Coordinate| 出发地的经纬度。  
startAddress| String| startLocation对应的地址详情。  
endLocation| Coordinate| 目的地的经纬度。  
endAddress| String| endLocation对应的地址详情。  
action| String| 当前步骤要执行的操作，取值包括：

  * TURN_SLIGHT_LEFT
  * TURN_SHARP_LEFT
  * UTURN_LEFT
  * TURN_LEFT
  * TURN_SLIGHT_RIGHT
  * TURN_SHARP_RIGHT
  * UTURN_RIGHT
  * TURN_RIGHT
  * STRAIGHT
  * RAMP_LEFT
  * RAMP_RIGHT
  * MERGE
  * FORK_LEFT
  * FORK_RIGHT
  * FERRY （暂不支持）
  * FERRY_TRAIN （暂不支持）
  * ROUNDABOUT_LEFT
  * ROUNDABOUT_RIGHT

  
polyline| Coordinate[]| 此路段的一系列坐标点（包含起点和终点坐标）。  
roadName| String| 路名。  
orientation| int| 道路方向。取值包括

  * 0：双向
  * 1：正向
  * 2：反向

  
instruction| String| 文字指引  
  
## ViaWayPoints

**名称**| **类型**| **描述**  
---|---|---  
location| Coordinate| 途经点的经纬度。  
stepIndex| int| 途经点在Step数组里的索引。  
  
## Row

**名称**| **类型**| **描述**  
---|---|---  
cells| Cell[]| 距离矩阵结果每个单元格的信息。  
  
## Cell

**名称**| **类型**| **描述**  
---|---|---  
status| int| 起点和终点进行路径规划计算的错误码，具体请参考“[返回码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-matrix-return-codes)”。  
distance| double| 行驶距离，单位是米  
distanceText| String| Distance的文本描述  
duration| double| 行驶时长，单位是秒  
durationText| String| Duration的文本描述
