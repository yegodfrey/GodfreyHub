# ActivityRecordsManager

**CLASS info**  
---  
public class ActivityRecordsManager 提供创建和管理用户活动记录功能  
建议使用ActivityRecordsController  
  
#### Nested Class Summary

**Type** | **Name** | **Desc**  
---|---|---  
Class | ActivityRecordsManager.GetIntentInfos | 构建一个意图，用于查看存储在Health平台中的活动记录  
  
#### Public Method Summary

**Return** | **Method**  
---|---  
PendingResult<Status> | beginActivityRecord(HiHealthKitClient huaweiApiClient, ActivityRecord activityRecord) 为当前应用启动一个新的活动记录.  
PendingResult<ActivityRecordStopResult > | endActivityRecord(HiHealthKitClient huaweiApiClient, String activityRecordIdentifier) 停止当前应用的指定活动记录  
PendingResult<Status> | addActivityRecord(HiHealthKitClient huaweiApiClient, ActivityRecordInsertOptions activityRecordInsertOptions) 插入指定的活动记录和相应的数据到Health平台中  
PendingResult<ActivityRecordResult> | getActivityRecord(HiHealthKitClient huaweiApiClient, ActivityRecordReadOptions activityRecordReadOptions) 根据请求参数中指定的活动记录和类型，从Health平台中读取数据  
PendingResult<Status> | addActivityRecordsMonitor(HiHealthKitClient huaweiApiClient, PendingIntent pendingIntent) 为活动记录的开始和结束事件注册一个待定意图  
PendingResult<Status> | removeActivityRecordsMonitor(HiHealthKitClient huaweiApiClient, PendingIntent pendingIntent) 取消活动记录的开始和结束事件注册的待定意图

**Method**  
---  
public PendingResult<ActivityRecordStopResult> endActivityRecord(HiHealthKitClient huaweiApiClient, String activityRecordIdentifier)  
根据活动记录标识停止当前应用的活动记录

**Parameter name** | **Parameter desc**  
---|---
