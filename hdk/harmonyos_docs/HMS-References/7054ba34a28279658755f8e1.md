提供ML Kit SDK 基础实现类及接口方法。  
  
## Classes

Class name| Class description  
---|---  
[LensEngine](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/LensEngine-4)| 相机引擎LensEngine封装了相机初始化、帧获取以及控制逻辑功能。  
[LensEngine.Creator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/LensEngineCreator-4)| 相机引擎构造器，用于创建相机引擎实例。  
[LensEngine.PhotographListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/LensEnginePhotographListener-4)| 获得图像数据后的回调接口。  
[LensEngine.ShutterListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/LensEngineShutterListener-4)| 按下快门后的回调接口。  
[MLAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLAnalyzer-4)| 分析器抽象类，所有分析器必须继承该类。例如：MLFaceAnalyzer（人脸分析器）、MLObjectAnalyzer（对象分析器）、MLTextAnalyzer（文本分析器）等。  
[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLAnalyzerMLTransactor-4)| 分析处理器需要实现的通用接口，用于处理检测结果。  
[MLAnalyzer.Result](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLAnalyzerResult-4)| 分析结果封装类，包含三组数据：  
1、分析结果  
2、图片元数据  
3、该数据是否可用  
[MLApplication](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLApplication-4)| APP信息类，用于存储集成了MLKit SDK的APP基本信息，通常情况下，应用开发者不与这个类直接交互，MLKit SDK会结合开发者申请的agconnect-services.json，完成MLKit的初始化，不需要开发者编写额外的代码。  
[MLApplicationSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLApplicationSetting-4)| APP信息配置类，用于指定应用初始化需要的应用ID,API秘钥等信息。  
[MLApplicationSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLApplicationSettingFactory-4)| 创建APP信息配置类的实例，用于设置APP属性。  
[MLCompositeAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCompositeAnalyzer-4)| 多类型分析器，继承自MLAnalyzer，可集成多种类型的分析器，同时检测不同类型对象，  
如：在同一张图片上同时实现人脸检测和文字识别。  
[MLCompositeAnalyzer.Creator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCompositeAnalyzerCreator-4)| 创建多类型分析器的实例，允许添加不同类型的分析器。  
[MLCompositeTransactor](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCompositeTransactor-4)| 多类型分析结果处理器，支持对多个目标的检测结果进行独立处理。  
[MLCompositeTransactor.Creator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCompositeTransactoCreator-4)| 多类型分析结果处理器实例构建器。  
[MLCompositeTransactor.TrailerFactory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCompositeTransactorTrailerFactory-4)| 目标跟踪器工厂接口，实现类可用于创建特定目标的跟踪器实例。  
[MLCoordinate](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCoordinate-4)| 经纬度数据类，包含经度信息和纬度信息。  
[MLException](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLException-4)| 异常状态处理类，封装了ML Kit的各种异常状态码。  
[MLFrame](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFrame-4)| MLFrame封装了源自相机的视频帧或静态图片数据，以及相关的数据处理逻辑。支持byte、ByteBuffer、Bitmap不同存储方案。  
[MLFrame.Creator](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFrameCreator-4)| 帧构建器。  
[MLFrame.Property](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFrameProperty-4)| 帧元数据。  
[MLPosition](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLPosition-4)| 点数据类，表示图像中的二维或三维点，以浮点精度指定（float），(0,0)表示图像左上角像素点，向右为x正向，向下为y正向。只有x、y同时有值，才构成一个有效坐标。  
[MLProminentTransactor](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLProminentTransactor-4)| 特定目标分析结果处理器抽象类，实现以下功能：  
1、设定需要跟踪的目标，目标在连续帧中状态发生变化时，自动调用目标跟踪器中的对应处理逻辑  
2、设定连续帧对同一目标的匹配策略，可以设置最大面积，最宽，最高等匹配策略。  
[MLResultTrailer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLResultTrailer-4)| 目标跟踪器抽象类，支持对特定目标连续帧检测结果进行跟踪,识别目标出现，变化，消失，处理完成等场景。每个场景对应有一个处理方法，可以在其中实现自定义的处理逻辑。
