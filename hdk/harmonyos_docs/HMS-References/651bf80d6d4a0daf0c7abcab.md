包含华为帐号服务的登录类。  
  
## Classes

Class name| Class description  
---|---  
[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-authhuaweiId "AuthHuaweiId")| 登录的华为帐号信息，包含id、显示名称、头像url、权限、AccessToken等信息。  
[HuaweiIdAuthResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-huaweiIdauthresult "HuaweiIdAuthResult")| 开发者通过调用getHuaweiId()方法来获取[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-authhuaweiId "AuthHuaweiId")实例对象，进而得到该对象中封装的授权信息、用户信息等相关华为帐号所包含的内容。
