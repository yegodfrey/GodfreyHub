# HiHealthOptions  
  
**CLASS info**  
---  
public class HiHealthOptions implements HuaweiIdAuthExtendedParams  
用于通过华为帐号的接口HuaweiIdAuthManager.addAuthScopes(Activity, int, HuaweiIdAuthExtendedParams)申请权限。 权限通过DataType定义，决定了应用登录的账号所拥有的HealthKit的scope权限。
