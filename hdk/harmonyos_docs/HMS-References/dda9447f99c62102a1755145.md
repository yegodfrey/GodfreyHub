public class ResolveTaskHelper  
处理task任务的辅助类.该类的**excuteTask** 方法处理了回调结果,将该回调结果返回到当前的activity的**onActivityResult(int,int,Intent)** ;在**onActivityResult** 中,根据返回的错误码,提示相应的添卡状态给用户.成功为Activity.RESULT_OK,目前提供的错误标记在WalletPassConstant 中,有以下几种:ERROR_CODE_SERVICE_UNAVAILABLEERROR_CODE_UNSUPPORTED_API_REQUESTERROR_CODE_INTERNAL_ERRORERROR_CODE_OTHERSERROR_CODE_INVALID_PARAMETERSERROR_CODE_USER_ACCOUNT_ERRORERROR_CODE_DEVELOPER_ERRORERROR_CODE_MERCHANT_ACCOUNT_ERROR
