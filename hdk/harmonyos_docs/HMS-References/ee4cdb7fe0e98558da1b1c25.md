CLASS info  
---  
public class AAIDResult implements IMessageEntity  
开发者调用[HmsInstanceId.getAAID()](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/push-HmsInstanceId-cls#getAAID)方法请求应用的匿名设备标识（AAID）后获得的AAID通过此实体类承载返回，开发者可以调用AAIDResult类中的getId()方法得到AAID。  
  
# Public Method Summary

Return| Method  
---|---  
String| getId()获取应用的匿名设备标识。
