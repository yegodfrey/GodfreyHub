public String getInAppDataSignature()  
该方法返回使用支付私钥签署购买数据（getInAppPurchaseData方法返回的字符串）生成的签名字符串。签名算法为SHA256WITHRSA。  
  
**Return**

type| desc  
---|---  
String| 包含已使用应用私钥签署的购买数据（[inAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)）的签名字符串。签名算法为SHA256WITHRSA。  
支付成功后应用需要参考对响应消息验签的方法使用支付公钥对[inAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)的JSON字符串进行验签。  
公钥获取参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_querypaymentinfo)。
