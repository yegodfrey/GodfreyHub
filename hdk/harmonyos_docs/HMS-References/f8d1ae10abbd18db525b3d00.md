## Public Method Summary  
  
Return type| Method name  
---|---  
boolean| isComplete()  
判断任务是否完成，如果完成返回true，否则返回false。  
boolean| isSuccessful()  
判断任务是否成功完成，true：表示成功完成，否则为false。  
boolean| isCanceled()  
判断任务是否被取消，true：表示任务被取消，否则返回false。  
TResult| getResult()  
如果任务完成，则获取任务的执行结果。  
< E extends Throwable > TResult| getResult(Class exceptionClass) throws E  
如果任务完成，则获取任务的执行结果，如果存在异常时，如果入参的异常类型exceptionClass是当前任务异常的实例，则返回指定的exceptionClass类型异常。  
Exception| getException()  
返回导致任务失败的异常。  
Task< TResult >| addOnSuccessListener(OnSuccessListener< TResult > listener)  
添加一个或者多个监听器，当任务成功完成时该监听器被调用，当添加多个监听时，按照添加时的顺序调用，该调用在主线程中执行。

添加一个或者多个监听器，当任务成功完成时该监听器被调用，当添加多个监听时，按照添加时的顺序调用，该调用在指定的executor 中执行。  
Task< TResult >| addOnFailureListener(OnFailureListener listener)  
添加监听器，当任务失败时调用，该监听器在主线程中执行，当添加多个监听器时，任务执行失败后，按照添加的顺序执行。  
Task< TResult >| addOnFailureListener(Executor executor,OnFailureListener listener)  
添加监听器，当任务失败时调用，当添加多个监听器时，任务执行失败时，按照添加时的顺序执行，该监听器调用在指定线程executor上执行。

Task< TResult >| addOnCanceledListener(OnCanceledListener listener)

Task< TResult >| addOnCanceledListener(Executor executor, OnCanceledListener listener)  
添加监听器，当任务被取消时调用，当添加多个监听器时，多个监听器按照添加时的顺序执行，监听器在指定的executor线程中执行。  
< TContinuationResult > Task< TContinuationResult >| onSuccessTask(SuccessContinuation< TResult, TContinuationResult > listener)  
当前Task< TResult >执行成功后，执行调用listerner的then方法，该方法返回一个Task< TContinuationResult >，根据Task< TContinuationResult>的结果创建一个新的Task< TContinuationResult >任务，其中listener在主线程中执行。  
如果当前任务被取消，那么返回的新的TASK也会被取消，listener不会被执行。如果当前任务执行失败，则会执行失败处理，listener不会被执行。

如果当前任务被取消，那么返回的新的TASK也会被取消，listener不会被执行。如果当前任务执行失败，则会执行失败处理，listener不会被执行。  
< TContinuationResult > Task< TContinuationResult >| continueWithTask(Continuation> taskContinuation)当前Task< TResult >执行成功后，执行调用listerner的then方法，该方法返回一个Task< TContinuationResult>，根据Task< TContinuationResult>的结果创建一个新的Task< TContinuationResult >任务，其中listener在主线程中执行。  
如果当前任务被取消，那么返回的taskContinuation仍然会被执行。

##### public abstract < E extends Throwable > TResult getResult(Class< E > exceptionClass) throws E  
  
如果任务完成，则获取任务的执行结果，如果存在异常时，如果入参的异常类型exceptionClass是当前任务异常的实例，则返回指定的exceptionClass类型异常。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
exceptionClass| 指定异常类型。  
  
**Throws**  
Parameter name| Parameter desc  
---|---  
Class< E >| exceptionClass为当前异常的实例，抛出该入参类型异常。  
RuntimeException| 任务执行失败时，如果异常不是入参的exceptionClass类型则返回RuntimeException异常。  
  
**Return**  
type| desc  
---|---  
TResult| 任务返回结果。

##### public < TContinuationResult > Task< TContinuationResult > onSuccessTask(SuccessContinuation< TResult, TContinuationResult > listener)  
  
当前Task< TResult >执行成功后，执行调用listerner的then方法，该方法返回一个Task< TContinuationResult >，根据Task< TContinuationResult >的结果创建一个新的Task< TContinuationResult >任务，其中listener在主线程中执行。  
如果当前任务被取消，那么返回的新的TASK也会被取消，listener不会被执行。如果当前任务执行失败，则会执行失败处理，listener不会被执行。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
listener| 接口实现类实例，实现了then接口，用于在当前TASK成功执行后调用后续任务。  
  
**Return**  
type| desc  
---|---  
Task< TContinuationResult >| 当前任务的后续任务。
