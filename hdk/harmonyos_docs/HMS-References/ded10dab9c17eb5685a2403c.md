public MLCompositeTransactor.Creator<T> setMaxFrameLostCount(int maxFrameLostCount)  
设置目标允许检测失败的最大帧数，低于这个帧数, 将判断为目标消失，执行目标跟踪器的目标消失处理逻辑。超过这个帧数，将会终止目标的检测，执行目标跟踪器的目标检测完成的处理逻辑。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
MaxFrameLostCount| 目标允许检测失败的最大帧数。
