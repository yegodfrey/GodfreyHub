**根据 modelId 局部更新优惠券模板。**

# **1 请求**

## **HTTP请求**

PATCH  
https://**${url}** /hmspass/v1/offer/model/**{modelId}**  
备注：请求地址中的 **${url}  **变量需要开发者根据服务器所属区域自行选择，请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。

## **URL路径参数**

Parameter name| Value| Description  
---|---|---  
modelId| String| 优惠券模板的唯一标识符，这个 Id 在商户的所有模板中是全局唯一的，这个 Id 只能包含字母、数字和（.）、（-）、（_）。  
  
## **请求体**

请求体中包含一个待更新的 [hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject") 对象。

# 2 响应

如果成功，响应消息包含更新后 [hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject") 对象。
