# Public Methods

## **public String getId()**

获取当前成就的成就ID，该ID唯一标识一个成就。

**返回值**  
成就ID字符串。

## **public int getReachedSteps()**

获取当前玩家对该成就已完成的步数。

**返回值**  
当前玩家已完成的步数。

## **public String getDescInfo()**

获取当前成就的描述信息。请根据实际情况选择使用getDescription()或getDescription(CharArrayBuffer   dataOut)。

**返回值**  
当前成就的描述信息。

**public String getLocaleReachedSteps()**

获取当前玩家已完成的成就步长数对应的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。

**返回值**  
返回本地化语言的数字。

**public String getLocaleAllSteps()**

获取当前成就总步长数对应的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。

**返回值**  
返回本地化语言的数字。

## **public long getRecentUpdateTime()**

获取最近一次更新成就的时间戳。

**返回值**  
返回最近一次更新成就的时间戳字符串，即最近一次更新成就距离1970年1月1日0点的毫秒数。

**public String getDisplayName()**  


获取当前成就的名称。

**返回值**  
当前成就名称。

## **public Player getGamePlayer()**

获取当前登录的玩家信息。

**返回值**  
以[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4 "Player")对象方式返回玩家具体信息。

## **public Uri getVisualizedThumbnailUri()**

获取揭示成就后未解锁时的图标URI地址。

**返回值**  
图标的URI地址。

## **public int getState()**

获取成就状态。

**返回值**  
● 1：显示  
● 2：隐藏

● 3：解锁

## **public int getAllSteps()**

获取解锁该成就所需的总步长。

**返回值**  
解锁该成就所需的步长数。

## **public int getType()**

获取该成就的类型。

**返回值**  
● 1：标准，没有设置分步步长的成就。  
● 2：增量，设置了分步步长的成就。

## **public Uri getReachedThumbnailUri()**

获取成就解锁后图标的URI地址。

**返回值**  
图标的URI地址。
