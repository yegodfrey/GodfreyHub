class info

com.huawei.hms.mlsdk.objects.MLObjectAnalyzer  
对象分析器：检测图像中的对象信息（MLObject）。  
创建一个对象分析器的方法有两种：  
1、带参数的创建方法，可以自定义一个对象分析配置器；  
2、不带参数的创建方法，使用默认的对象分析配置器，默认使用视频流模式。  
  
## Sample Code
    
    
    复制
      
        1. //创建对象分析配置器的实例
        2. MLObjectAnalyzerSetting setting = new MLObjectAnalyzerSetting.Factory()
        3.     .allowClassification()
        4.     .allowMultiResults()
        5.     .setAnalyzerType(MLObjectAnalyzerSetting.TYPE_PICTURE)
        6.     .create();
        7. //使用不带参数的方法创建对象分析器
        8. MLObjectAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalObjectAnalyzer();
        9. //使用带参数的方法创建对象分析器
        10. MLObjectAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalObjectAnalyzer(setting);
