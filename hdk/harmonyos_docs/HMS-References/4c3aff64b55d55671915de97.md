## 概览

该类提供位置搜索和地理编码接口。

## 构造方法

**构造方法**| **描述**  
---|---  
HWMapJsSDK.HWSiteService()| 无  
  
## 公共方法

**方法名**| **描述**| **参数类型**| **返回值**  
---|---|---|---  
geocode(request,callback)| 正地理编码。| 

  * request: GeocodeRequest
  * callback:  function(GeocodeResult, StatusCode)

| 无  
nearbySearch(request, callback)| 周边搜索。| 

  * request: NearbySearchRequest
  * callback: function(NearbySearchResult,  StatusCode)

| 无  
querySuggestion(request, callback)| 地点搜索建议。| 

  * request:  QuerySuggestionRequest
  * callback:  function(QuerySuggestionResult, StatusCode)

| 无  
reverseGeocode(request, callback))| 逆地理编码。| 

  * request:  ReverseGeocodeRequest
  * callback: function(ReverseGeocodeResult, StatusCode)

| 无  
searchById(request,callback)| 地点详情。| 

  * request: SearchByIdRequest
  * callback:  function(SearchByIdResult, StatusCode)

| 无  
searchByText(request, callback)| 关键字搜索。| 

  * request: SearchByTextRequest
  * callback:  function(SearchByTextResult, StatusCode)

| 无  
  
说明：

StatusCode是接口调用状态的返回码，具体请参考“返回码”。

## NearbySearchRequest

**参数名称**| **必选(M)/****可选(O)**| **参数类型**| **参数说明**  
---|---|---|---  
location| M| [LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)| 当前用户的位置。  
radius| O| Number| 可以指定搜索半径，单位是米，默认值是1公里。取值范围是1米-50公里。  
query| O| String(<=512)| 可以输入搜索关键字。  
poiType| O| String| 返回指定POI类型的地点。  
language| O| String(<=6)| 搜索结果的语种。如果不传，使用地点的当地语言。语种取值请参考语种映射列表。  
pageSize| O| Number| 每页返回的记录数。默认值是20。取值范围是1-20。  
pageIndex| O| Number| 当前页数，默认值是1。取值范围是1-60。约束：pageindex*pagesize <= 60。  
politicalView| O| String(=2)| 政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家码。

QuerySuggestionRequest  


地点搜索建议请求对象，相关参数类型详细说明请参见“[参数说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description)”章节描述。

**参数名称**| **必选(M)/****可选(O)**| **参数类型**| **参数说明**  
---|---|---|---  
query| M| String(<=512)| 搜索关键字。  
location| O| [LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLng)| 搜索建议偏向的经纬度。  
radius| O| Number| Location的搜索半径，单位是米，默认值是50公里。取值范围是1米-50公里。  
bounds| O| [LatLngBounds](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-js-hw-parameter-description#latLngBounds)| 搜索建议偏向的搜索范围。注意：如果bounds、location都传的话，那么bounds优先。  
poiType| O| String| 返回指定POI类型的地点。取值包括：

  * GEOCODE ： 仅返回地理编码结果（如国家、城市、街道等），而不返回商业结果（如酒店、餐馆、火车站等）。可以使用此类型过滤掉商业数据，消除用户输入中存在的歧义。例如：用户输入中国时，返回中国，不返回中国银行等数据。。
  * ADDRESS：GEOCODE的子集。仅返回具有精确地址的地理编码结果，不返回商业结果和粗粒度的地理编码结果（如国家、城市等），推荐在搜索完整地址时使用此类型。
  * ESTABLISHMENT：GEOCODE的补集。仅返回作为商业结果（如酒店、餐馆、火车站等），不返回地理编码结果（如国家、城市、街道等）。例如：用户输入中国时，返回中国银行等数据，不返回中国。
  * REGIONS ：GEOCODE的子集，仅返回与以下类型匹配的地点：LOCALITYSUBLOCALITYPOSTAL_CODECOUNTRYADMINISTRATIVE_AREA_LEVEL_1ADMINISTRATIVE_AREA_LEVEL_2  

  * CITIES：仅返回LOCALITY或 ADMINISTRATIVE_AREA_LEVEL_3类型的地点。

  
countryCode| O| String(=2)| 在指定的国家内搜索，采用ISO  3166-1 alpha-2。  
language| O| String(<=6)| 搜索建议的语种。如果不传，使用地点的当地语言。语种取值请参考语种映射列表。  
politicalView| O| String(=2)| 政治观点参数，采用ISO  3166-1-alpha-2规范的2位国家码。
