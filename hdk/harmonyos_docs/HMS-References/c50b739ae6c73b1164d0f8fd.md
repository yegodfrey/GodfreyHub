public static [DiscoveryEngine](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-discovery-discoveryengine) getDiscoveryEngine(Context context)  
校验入参context，当context为空时，抛出空指针异常；当context非空时，返回DiscoveryEngine的实例。注意：当传入参数为非Activity类型时，如果使用DiscoveryEngine实例调用近距离通信服务接口发生异常，就不会弹出UI交互界面提示用户处理，只会返回错误码。例如：当HMS Core (APK)不符合近距离通信服务的版本要求时，便会返回错误码907135003，此时需要手动升级HMS Core (APK)。如果需要拉起升级引导界面，建议传入Activity类型参数替代Context类型，创建Engine实例。
