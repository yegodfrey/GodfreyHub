public final class AmbientLightBarrier extends Object  
光照度围栏，提供小于（below）设定值、大于（above）设定值、在设定的区间（range）三种围栏能力。

public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier) range(float minLightIntensity, float maxLightIntensity)  
设置光照度range围栏，当光照度值在[minLightIntensity, maxLightIntensity)之内时，此围栏状态为TRUE，并触发围栏事件上报；当光照度值不在区间时，围栏状态为FALSE，并触发围栏事件上报。  
  
**Parameters**  

Parameter name| Parameter desc  
---|---  
minLightIntensity| 设定的最小光照度值。  
maxLightIntensity| 设定的最大光照度值。  
  
  
**Return**  
 

Type| desc  
---|---  
[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)| 情景感知围栏。  
  
  
**Throws**  
 

Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（当minLightIntensity<0，mMinLightIntensity> maxLightIntensity或maxLightIntensity大于Float.MAX_VALUE）异常。
