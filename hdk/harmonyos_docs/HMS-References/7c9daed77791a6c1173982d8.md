com.huawei.hms.mlsdk.imgseg.MLImageSegmentationSetting.Factory  
创建图像分割配置器的实例，用于设置图像分割的属性。  
  
## Sample Code
      
      1. MLImageSegmentationSetting settingoptions = new MLImageSegmentationSetting
        2.               .Factory()
        3.               .setExact(true)
        4.               .setAnalyzerType(MLObjectAnalyzerSetting. BODY_SEGIMAGE_SEG)
        5.               .setScene(MLImageSegmentationScene.ALL)
        6.               .create();

public mlsdk.imgseg.MLImageSegmentationSetting.Factory setAnalyzerType(int analyzerType)  
分类模式设置。对静态图像进行分割时，支持设置MLImageSegmentationSetting.BODY_SEG (只分割人像和背景)，以及MLImageSegmentationSetting.IMAGE_SEG (分割11大类场景，包括人像)。对视频流进行分割时，只支持设置MLImageSegmentationSetting.BODY_SEG (只分割人像和背景)。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
analyzerType| 分类模式。MLImageSegmentationSetting.BODY_SEG(0)：人像分割模式；MLImageSegmentationSetting.IMAGE_SEG(1)：图像多类别分割模式。  
  
**Return**  


Type| desc  
---|---  
mlsdk.imgseg.MLImageSegmentationSetting.Factory| 指定分类模式的图像分割检测器。

**public mlsdk.imgseg.MLImageSegmentationSetting.Factory setScene(int scene)******

设置返回结果种类，只有在MLImageSegmentationSetting.BODY_SEG模式下，此项配置才生效，MLImageSegmentationSetting.IMAGE_SEG模式下，返回结果中只包含像素级标记信息。支持设置MLImageSegmentationScene.ALL（返回所有分割结果，包括：像素级标记信息、背景透明的人像图和人像为白色，背景为黑色的灰度图），MLImageSegmentationScene.MASK_ONLY（只返回像素级标记信息），MLImageSegmentationScene.FOREGROUND_ONLY（只返回背景透明的人像图），MLImageSegmentationScene.GRAYSCALE_ONLY（只返回人像为白色，背景为黑色的灰度图）。

**Parameters**  


Parameter name| Parameter desc  
---|---  
scene| 用户选择返回结果种类。MLImageSegmentationScene.ALL(0)：返回所有分割结果，包括：像素级标记信息、背景透明的人像图和人像为白色，背景为黑色的灰度图。MLImageSegmentationScene.MASK_ONLY (1)：只返回像素级标记信息。MLImageSegmentationScene. FOREGROUND_ONLY (2)：只返回背景透明的人像图。MLImageSegmentationScene. GRAYSCALE_ONLY (3)：只返回人像为白色，背景为黑色的灰度图。  
  
**Return**  


Type| desc  
---|---  
mlsdk.imgseg.MLImageSegmentationSetting.Factory| 指定场景模式下的图像分割检测器。
