CLASS info  
---  
public class Policy extends AbstractSafeParcelable  
定义了一系列策略用于#Put或#Get消息  
  
## Nested Class Summary

Type| Name| Desc  
---|---|---  
Class| [Policy.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-policy-builder)| Policy的构造类  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
int| POLICY_FINDING_MODE_BROADCAST| 近场设备发现，广播配对码，以便其他设备扫描  
int| POLICY_FINDING_MODE_SCAN| 近场设备发现，扫描其他设备广播的配对码  
int| POLICY_FINDING_MODE_DEFAULT| 近场设备发现；广播配对码，同时扫描其他设备广播的配对码  
int| POLICY_DISTANCE_TYPE_DEFAULT| 允许任何距离范围的消息传输  
int| POLICY_DISTANCE_TYPE_EARSHOT| 允许听力所及范围内的消息传输  
int| POLICY_TTL_SECONDS_DEFAULT| 存活缺省时间（单位：秒）  
int| POLICY_TTL_SECONDS_INFINITE| 无限期存活（单位：秒）  
int| POLICY_TTL_SECONDS_MAX| 允许最大存活时间（单位：秒）  
  
## Field Summary

Type| Name| Desc  
---|---|---  
public static final Policy| BLE_ONLY| 只使用BLE发现周边设备，此策略的存活时间用TTL_SECONDS_INFINITE，并且只支持#Get  
public static final Creator| CREATOR|   
public static final Policy| DEFAULT| 缺省策略，适用于大部分应用程序，缺省策略目前使用广播和扫描，当前支持蓝牙来发现近场设备（不考虑距离）
