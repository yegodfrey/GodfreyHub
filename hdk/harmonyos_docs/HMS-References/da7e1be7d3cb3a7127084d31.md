# **接口功能**

为Beacon设备配置Attachment。

# **调用场景**

创建Beacon后，调用此接口为Beacon配置需要广播的Attachment。

# **接口原型**

**承载协议**|  HTTPS POST  
---|---  
**接口方向**|  应用服务器或APP应用->近距离通信服务器  
**接口URL**|  https://{域名}/WiseCloudNearbyBeaconService/v1/updateAttachment/{beaconId}?projectId=[projectId]  
**数据格式**|  Content-type: application/json  
  
# **接口约束**

需要获取服务账号凭证。

# **请求参数**

**参数名称**| **必选(M)/可选(O)**| **类型**| **参数说明**  
---|---|---|---  
timeStamp| M| Long| 请求头参数，时间戳。  
srcTranID| M| String| 请求头参数，事务ID，最长为24个字符。  
Authorization| M| String| 请求头参数，用于网关认证，请参考[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-common-service-account)获取JWT。  
projectId| O| String| 查询参数。  
beaconId| M| String| 路径参数，Beacon设备的ID。  
attachment| M| object| 请求体参数，Attachment信息，具体见下面Attachment结构体。  
  
Attachment结构体：

**参数值**| **必选(M)/可选(O)**| **类型**| **功能**  
---|---|---|---  
attachmentId| O| String| Attachment id，配置Attachment时必须为空。  
namespace| M| String| 创建project时对应的Namespace，最长为32个字符。  
type| M| String| 消息类型，用户自定义，最长为16个字符。  
value| M| String| Attachment内容，必须为Base64编码，最长为4096个字符，解码后最大为2048字节。  
  
# **返回参数**

请求成功：状态码200，响应体如下：

**参数值**| **类型**| **参数说明**  
---|---|---  
attachment| object| 具体见下面Attachment结构体定义。  
  
Attachment结构体定义：

**参数值**| **类型**| **功能**  
---|---|---  
attachmentId| String| Attachment id，服务器生成，36位。  
namespace| String| 参数传入时的原始值。  
type| String| 参数传入时的原始值。  
value| String| 参数传入时的原始值。  
  
请求失败，状态码非200，响应体如下：

(1) 非业务(网关校验失败、token过期等情况)请求失败时：

**参数值**| **类型**| **参数说明**  
---|---|---  
error| String| 非业务返回的错误信息。  
  
(2) 业务请求失败时：

**参数名称**| **类型**| **参数说明**  
---|---|---  
serviceError| object| 业务返回的错误信息。  
  
serviceError的JSON结构体为：

**参数名称**| **类型**| **参数含义**  
---|---|---  
code| int| 错误码，错误码描述见返回码。  
status| String| 错误状态。  
message| String| 错误描述信息。  
  
# **返回码**

**错误码**| **错误码含义**| **建议业务处理方式**  
---|---|---  
400000001| 请求头参数不对。| 检查请求头参数。  
400000002| 请求体参数不对。| 检查请求体参数。  
400000007| beaconId不合法。| 请检查beaconId。  
400000009| 当前Beacon未激活。| 激活当前Beacon。  
400009001| attachmentId不为空。| 检查请求体attachmentId字段是否为空。  
400009002| attachment value不是合法的Base64字符串。| 检查请求体value字段是否为合法Base64字符串。  
400009003| Attachment内容过大。| 检查请求体value字段是否超过最大限制2048 byte。  
400009004| 已配置的Attachment数量已达到最大限制。| 删除不需要的Attachment。  
403000003| 服务账号不可用。| 切换成可用的服务账号操作。  
403000004| 当前账号没有权限操作此Beacon。| 切换为可操作该Beacon的账号。  
403000005| 当前账号无权限操作此命名空间。| 切换为可操作该命名空间的账号。  
404000006| Beacon不存在。| 检查Beacon是否存在，或注册Beacon。  
500000001| 内部服务错误。| 建议重试，重试仍失败则反馈该问题。  
  
# **调用样例**

#### 使用过期的Authorization进行调用，返回错误的响应体

请求消息：
    
    
    复制
      
        1. POST /WiseCloudNearbyBeaconService/v1/updateAttachment/a1bc3331?projectId=id123 HTTP/1.1
        2. POST data: {"attachment":{"namespace":"dev9105385871708434","type":"myType","value":"SGVsbG8gSE1TIQ=="}}
        3. Host: 域名
        4. Content-Type: application/json
        5. Authorization: Bearer eyJraWQiOiIx---xxx.eyJhdWQiOiJodHR---xxx.QRodgXa2xeXSt4Gp---xxx
        6. srcTranID: 202001141709412953357215
        7. timeStamp: 922337203685477580
        8. Accept: application/json

    复制
      
        1. HTTP/1.1 401
        2. Content-Type: application/json
        3. Content-Length: 27
