class info  
---  
com.huawei.hms.mlsdk.common.MLCompositeAnalyzer  
多类型分析器，继承自MLAnalyzer，可集成多种类型的分析器，同时分析不同类型对象，  
如：在同一张图片上同时实现人脸检测和文字识别。  
  
## Sample Code
    
    
    复制
      
        1. //创建多类型分析器的实例
        2. MLCompositeAnalyzer analyzer = new MLCompositeAnalyzer.Creator()
        3. .add(faceAnalyzer)
        4. .add(objectAnalyzer)
        5. .create();
        6. //根据多类型分析器实例创建LensEngine实例
        7. LensEngine mLensEngine = new LensEngine.Creator(getAppContext(), analyzer)
        8. .setLensType(LensEngine.BACK_LENS)
        9. .applyDisplayDimension(640, 480)
        10. .applyFps(30.0f)
        11. .enableAutomaticFocus(true)
        12. .create();
