ML Kit的图片商品检测API。通过自动识别图片或者相机拍摄中的物品，在线检索第三方应用程序中的类似商品，将结果呈现给用户。例如，在购物类应用中，可以使用扫一扫功能，快速找到其拍摄的商品信息。  
  
## Classes

Class name| Class description  
---|---  
[MLProductVisionSearch](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLProductVisionSearch-4)| 拍照购结果描述，表示图像拍照购识别结果的具体信息，包括：  
1\. type：商品类别（参考[拍照购商品类别清单](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyManage/011/111/111/0000000000011111111.20200512194104.49028130536217701109920756176743:50510519092739:2800:C0CD6CDD7819829CC240CD1624401D05FC2591F92C6FC11A0CA2A7FD09AA01F6.xlsx?needInitFileName=true "拍照购商品类别清单.xlsx")）。  
2\. border：轴对齐矩形边界框，包括left、top、right、bottom 4个值。其中left、top的值构成矩形边界区域的左上顶点坐标，right、bottom的值构成矩形边界区域的右下顶点坐标，目前没有倾斜度。  
3\. productList：商品信息列表，按照置信度降序排序。  
[MLVisionSearchProduct](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLVisionSearchProduct-4)| 商品信息描述，包括：  
1\. productId：商品Id；  
2\. imageList：商品图片列表。  
[MLVisionSearchProductImage](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLVisionSearchProductImage-4)| 商品图片信息描述，包括：  
1\. productId：商品Id；  
2\. imageId：商品图片Id；  
3\. possibility: 置信度。  
[MLRemoteProductVisionSearchAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLSearchAnalyzer-4)| 拍照购检测器：用于在提供的图像中，识别商品信息。拍照购检测器，调用云端API，检测模型在云端运行。创建拍照购检测器有两种方式，根据实际情况二选一。  
[MLRemoteProductVisionSearchAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLSearchAnalyzerSetting-4)| 拍照购配置器：用于设置云端拍照购的属性。云端拍照购的属性包括：  
1\. 返回商品数量的最大值；  
2\. 置信度阈值（目前不支持设置，预留）。  
[MLRemoteProductVisionSearchAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLASettingFactory-4)| MLRemoteProductVisionSearchAnalyzerSetting配置工厂类。
