此包为文档识别组件，可用于从文档图片中，识别出带段落格式的文本信息。  
此包提供了文档检测的核心API，包含以下类：  
属性设置类 MLDocumentSetting：提供设置分析器参数的API。  
文档信息类 MLDocument：提供从检测结果获取文档信息的API。  
检测器类 MLDocumentAnalyzer：提供创建检测器及执行文档检测的API。  
  
## Classes

Class name| Class description  
---|---  
[MLDocument](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocument-4)| 表示图像检测出的文档信息。包含两个属性：1、图像中检测到的所有文本内容。2、图像中检测到的所有文本区块，包含文本内容、文本区块边界和语种等信息。  
[MLDocument.Base](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumenBase-4)| 文档信息的父类，表示检测出的基本文档信息。包含5个属性：1、检测出的语种列表；2、文本的间隔；3、文本边框的顶点；4、检测出的文本内容；5、检测结果的置信度。  
[MLDocument.Block](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumenBlock-4)| 用来表示检测出的文本区块，继承自Base，包含6个属性：  
1、getLanguageList()：检测出文本区块的语种；2、getInterval()：文本区块的间隔类型；3、getBorder()：文本区块的边框；4、getStringValue()：文本区块的文本内容；5、getPossibility()：检测结果置信度；6、getSections()：文本区块包含的所有段落。  
[MLDocument.Character](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumenCharacter-4)| 用来描述检测出的单一字符，是模型能识别的最小元素，包含继承自Base的5个属性：  
1、getLanguageList()：检测出字符的语种；2、getInterval()：字符的间隔类型；3、getBorder()：字符的边框；4、getStringValue()：字符内容；5、getPossibility()：检测结果置信度。  
[MLDocument.Interval](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumeninterval-4)| 用于表示文本间隔，包含3种类型：  
1、空格；  
2、换行符；  
3、未知类型间隔。  
[MLDocument.Line](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumenline-4)| 用来表示检测出的行，继承自Base，包含7个属性：  
1、getLanguageList()：检测出行的语种；2、getInterval()：行的间隔类型；3、getBorder()：行的边框；4、getPoints()：行的边界顶点；5、getStringValue()：行的文本内容；6、getPossibility()：检测结果置信度；7、getWordList()：行中包含的所有词。  
[MLDocument.Section](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumensection-4)| 用来表示检测出的段落，继承自Base，包含7个属性：1、getLanguageList()：检测出段落的语种；2、getInterval()：段落的间隔类型；3、getBorder()：段落的边框；4、getStringValue()：段落的文本内容；5、getPossibility()：检测结果置信度；6、getWordList()：段落中包含的所有词；7、getLineList()：段落中包含的所有行。  
[MLDocument.Word](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumentWord-4)| 用来描述检测出的词，继承自Base，包含6个属性：1、getLanguageList()：检测出词的语种；2、getInterval()：词的间隔类型；3、getBorder()：词的边框；4、getStringValue()：词的内容；5、getPossibility()：检测结果置信度；6、getCharacterList()：词中包含的所有字符。  
[MLDocumentAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumentAnalyzer-4)| 文档检测器：通过调用云端API接口检测文档图像中的文档信息（MLDocument）。 创建设备端图像检测器有两种方式：1、默认方式：MLAnalyzerFactory.getInstance().getRemoteDocumentAnalyzer()，默认情况下系统自动识别语种，不校验证书指纹。2、自定义方式：MLAnalyzerFactory.getInstance().getRemoteDocumentAnalyzer( MLDocumentSetting setting)，用户可设置检测语种和是否校验证书指纹。  
[MLDocumentSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumentSetting-4)| 文档检测器设置类：用于设置文档检测器（MLDocumentAnalyzer）的属性。 检测器属性包括：1、预置的语种，正确地预置检测器语种，可以使检测更快速更准确。2、是否校验证书指纹，设置为true后只允许能通过校验的已注册应用访问文档检测的云端API接口。3、文本行边界返回格式，可设置为NGON或者ARC。NGON：返回四边形行边界的四个顶点坐标；ARC：返回文本行文字排列为弧形的多边形边界的顶点，最多可返回多达72个顶点的坐标。  
[MLDocumentSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLDocumentSettingFactory-4)| 创建文档检测配置器的实例，用于设置文档检测的属性。
