# Record.Builder  
  
**CLASS info**  
---  
public static class Builder  
用于构造Record对象的构造器。创建Record对象时，可以指定数据类型、数据采集器信息，同时指定两种信息时，须保证数据采集器的数据类型与记录信息的数据类型完全一致，否则会报错。

**Return** | **Method**  
---|---  
Builder | setDataCollector() 设置数据采集器  
Builder | setDataType() 设置数据类型  
Record | build() 构建完成返回Record对象
