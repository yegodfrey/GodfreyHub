MLKit的身份证识别质量检测插件，提供API启动预置的检测页面，该页面已经封装好视频帧获取，质量检测和身份证云端检测逻辑，并返回检测结果或异常信息到回调函数供第三方应用做后续处理。  
  
## Classes

Class name| Class description  
---|---  
[MLCnIcrCapture](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCnlcr-4)| 二代身份证识别插件。  
[MLCnIcrCapture.CallBack](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCallback-4)| 插件识别结果回调接口。  
[MLCnIcrCaptureConfig](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLConfig-4)| 二代身份证识别配置，支持以下识别配置：1.身份证正反面，2.使用云侧或端侧识别。  
[MLCnIcrCaptureConfig.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLFactory-4)| 创建二代身份证识别配置器的实例。  
[MLCnIcrCaptureFactory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCnIcrFactory-4)| 二代身份证识别工厂类，指定不同类型检测器配置。  
[MLCnIcrCaptureResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLCnIcrCaptureResult-4)| 二代身份证识别结果。
