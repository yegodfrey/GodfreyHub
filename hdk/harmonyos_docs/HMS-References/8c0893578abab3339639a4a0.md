public class WeatherPosition implements Parcelable  
请求参数类，用来传入地址信息以获取天气信息。包括国家、省份、城市、区、县、语言类型等6个属性。  
地址由国家、省份、城市、地区、县等组成地点名，其中城市名必须传入，其他4个属性非必需。例如想查看英国伦敦的天气时，可以只传入城市名“伦敦”，或者也可以传入国家名“英国”和城市名“伦敦”。  
语言环境表示传入地址的语言类型，格式是locale格式，比如en_GB表示英式英语 _。_ 需要注意的是，必须传入语言类型，且语言类型应当是“语言码_国家码”的格式。
