com.huawei.hms.mlsdk.common.LensEngine.PhotographListener  
获得图像数据后的回调接口。  
  
## Sample Code
    
    
    复制
      
        1. //lenEngine为相机引擎实例,需要先启动
        2. lensEngine.run();
        3. // 执行lensEngine.photograph()相机拍一次照
        4. lensEngine.photograph(new LensEngine.ShutterListener() {
        5.    @Override
        6.    public void clickShutter() {
        7.    //按下快门时该方法被调用
        8.    }
        9. },new LensEngine.PhotographListener() {
        10.    @Override
        11.    public void takenPhotograph(byte[] data) {
        12.        //拍照完成后，该方法被调用。
        13.        //data参数及对应相片图像数据，可在这里获取并做进一步处理
        14.    }
        15. });
