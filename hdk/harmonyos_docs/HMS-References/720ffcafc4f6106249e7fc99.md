EventsClient类定义了事件管理的相关接口，例如提交事件数据、获取当前玩家的事件数据等。

# Public Method Summary

parameter| description  
---|---  
void| [grow](httpgrow)(String eventId, int growAmount)提交当前玩家的事件数据。  
Task<List<[Event](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/event-v4)>>| [getEventList](httpgetEventList)(boolean forceReload)获取当前玩家的所有事件数据。  
Task<List<[Event](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/event-v4)>>| [getEventListByIds](httpgetEventListByIds)(boolean forceReload, String[] eventIds)获取当前玩家指定ID的事件信息。  
  
# Public Methods

#### public void grow(String eventId, int growAmount)

提交事件数据。

本方法的提交方式为异步提交，即应用客户端调用本方法时如果设备无网络，HMS SDK会先将数据缓存在本地，待网络恢复后提交到华为服务器。开发者无需关注此方法的执行结果。

**请求参数**

parameter| description  
---|---  
eventId| 需要提交数据的事件ID。由开发者在配置事件后获取。  
growAmount| 在已有事件数值的基础上要增量增加的数值。  
  
### public Task<List<Event>> getEventList (boolean forceReload)  


获取当前玩家的所有事件数据。

**请求参数**

parameter| description  
---|---  
forceReload| 获取服务器端还是本地缓存的事件列表。

  * true：服务器端。
  * false：本地缓存。

  
  
**返回值**

返回[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/event-v4)[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/annotateddata)[Event](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/event-v4)对象列表。

#### public Task<List<Event>> getEventListByIds(boolean forceReload, String[] eventIds)

获取当前玩家指定事件数据，可支持获取一个或多个事件数据。

**请求参数**

parameter| description  
---|---  
forceReload| 获取服务器端还是本地缓存的事件列表。

  * true：服务器端。
  * false：本地缓存。

  
eventIds| 需要获取数据的事件ID，格式为String数组形式。  
  
**返回值**

返回[Event](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/event-v4)对象列表。
