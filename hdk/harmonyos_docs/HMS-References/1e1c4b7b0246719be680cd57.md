public List< String > getInAppSignature()  
该方法与getInAppPurchaseDataList方法对应，返回inAppPurchaseDataList中每一个字符串的签名字符串，过程中使用支付私钥签署，签名算法为SHA256WITHRSA。说明：签名字符串与inAppPurchaseDataList中的商品详情信息为一一对应关系，即inAppSignature中的第1个签名字符串对应inAppPurchaseDataList中第1条商品详情信息，依次类推。应用需要对inAppPurchaseDataList中的每个JSON字符串都进行验签，如果验签不通过则需要重新获取该订阅关系，验签方法请参见[对响应消息验签](https://developer.huawei.com/consumer/cn/doc/iap-verifying-signature-returned-result-v4)的方法。  
  
**Return**

type| desc  
---|---  
List< String >| 对应getInAppPurchaseDataList方法返回的List中每一个订阅关系的签名字符串。

public List< String > getPlacedInappPurchaseDataList()  
以JSON字符串数组方式返回用户发生过订阅商品切换时的订阅关系信息，每个JSON字符串包含的参数请参见[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)。商品切换是指用户购买了订阅商品A后，在下一个周期购买了同一个订阅组下的商品B，则此时A的订阅关系将取消，用户转而与商品B建立订阅关系。则查询时此字段将返回商品B的订阅关系信息。注意：仅在查询订阅关系且用户存在订阅商品切换时才会返回。  
  
**Return**

type| desc  
---|---  
List< String >| 以JSON字符串数组方式返回用户发生过订阅商品切换时的订阅关系信息，每个JSON字符串包含的参数请参见[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)。
