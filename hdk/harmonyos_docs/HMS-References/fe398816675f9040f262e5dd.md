GamePlayerStatistics类主要用于返回玩家的游戏统计信息，在调用[ GamePlayerStatisticsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gameplayerstatisticsclient)的loadPlayerStats方法时会返回该类型的实例。  
  
# Public Method Summary

Return| Method  
---|---  
float| getAverageOnLineMinutes()获取玩家12个月内的平均在线时长（分钟）。  
int| getDaysFromLastGame()获取玩家距离上次玩游戏的时间（天数）。  
int| getPaymentTimes()获取玩家12个月内的支付总次数。  
int| getOnlineTimes()获取玩家12个月内的在线次数。  
int| getTotalPurchasesAmountRange()获取玩家12个月内付款总额的区间。  
  
# Public Methods

## public float getAverageOnLineMinutes()

获取玩家12个月内的平均在线时长（分钟）。

**返回值**

Type| Description  
---|---  
float| 玩家的平均在线时长，单位分钟。  
  
## public int getDaysFromLastGame()

获取玩家距离上次玩游戏的时间（天数），最多统计12个月内的数据。

**返回值**

Type| Description  
---|---  
int| 玩家距离上一次玩游戏的时间，单位天。  
  
## public int getPaymentTimes()

获取玩家12个月内总的支付次数。

**返回值**

Type| Description  
---|---  
int| 玩家总的支付次数。  
  
## public int getOnlineTimes()

获取玩家12个月内登录游戏的总次数。

**返回值**

Type| Description  
---|---  
int| 玩家总的在线次数。  
  
## public int getTotalPurchasesAmountRange()

获取玩家12个月内的付款总额区间。

**返回值**

Type| Description  
---|---  
int| 使用1-6的数字表示。

  * 1：无消费
  * 2：10美元以下
  * 3：10美元以上（含10美元），50美元以下
  * 4：50美元以上（含50美元），300美元以下
  * 5：300美元以上（含300美元），1000美元以下
  * 6：1000美元以上。
