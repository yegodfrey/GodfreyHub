ArchiveSummary类主要用于返回存档记录的元数据信息，例如存档的描述等。

# **Public Method Summary**

Return| Method  
---|---  
abstract float| getThumbnailRatio()获取存档封面图像的长宽比。  
abstract String| getDescInfo()获取存档的描述信息。  
abstract [GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)| getGameSummary()获取存档相关联的游戏信息。  
abstract long| getRecentUpdateTime()获取上次修改存档的时间戳。  
abstract [Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4)| getGamePlayer()获取存档关联的玩家信息。  
abstract long| getActiveTime()获取存档的时长。  
abstract long| getCurrentProgress()获取存档的进度值。  
abstract String| getId()获取存档的唯一标识。  
abstract String| getFileName()获取存档的唯一文件名称。  
abstract boolean| hasThumbnail()存档是否存在封面缩略图。  
  
# Public Methods

## public abstract String getThumbnailRatio()

获取存档封面图像的长宽比。

**返回值**

Type| Description  
---|---  
float| 存档封面图片的长宽比。  
  
## public abstract String getDescInfo()

获取存档的描述信息。

**返回值**

Type| Description  
---|---  
String| 存档的描述信息。  
  
## public abstract GameSummary getGameSummary()  


获取存档相关联的游戏基本信息。

**返回值**

Type| Description  
---|---  
[GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)| 返回包含存档相关联游戏基本信息的[GameSummary](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/gamesummary)对象。  
  
## public abstract long getRecentUpdateTime()  


获取存档上次修改的时间戳。

**返回值**

Type| Description  
---|---  
long| 上一次修改存档数据的时间戳。  
  
## public abstract Player getGamePlayer()  


获取存档关联的玩家信息。

**返回值**

Type| Description  
---|---  
[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4)| 包含玩家信息的[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/player-v4)对象，其中不包含getPlayerSign和getSignTs。  
  
## public abstract long getActiveTime()  


获取存档的时长。

**返回值**

Type| Description  
---|---  
long| 存档的时长。由开发者在提交存档时自行定义。  
  
## public abstract long getCurrentProgress()

获取存档当前的进度值。

**返回值**

Type| Description  
---|---  
long| 存档当前的进度值。由开发者在提交存档时自行定义。  
  
## public abstract String getId()  


获取存档ID。

**返回值**

Type| Description  
---|---  
String| 返回存档的唯一标识，由华为游戏服务器生成。  
  
## public abstract String getFileName()  


获取存档的唯一名称。

**返回值**

Type| Description  
---|---  
String| 返回存档的唯一名称，即本地保存的文件名称。由华为游戏服务器生成。  
  
## public abstract boolean hasThumbnail()  


存档是否存在封面缩略图。

**返回值**

Type| Description  
---|---  
boolean| 存档是否存在封面缩略图。

  * true：存在
  * false：不存在
