public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier) keeping(int headsetStatus)  
耳机状态驻留围栏，开发者添加连接或非连接两种状态的耳机状态驻留围栏后，当耳机状态保持为指定状态时，此围栏状态为TRUE并触发围栏事件上报。  
使用此围栏需添加android.permission.BLUETOOTH权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
headsetStatus| 耳机状态。  
CONNECTED：耳机已连接；  
DISCONNECTED：耳机未连接。  
  
  
**Return**  


Type| desc  
---|---  
[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)| 情景感知围栏。  
  
  
**Throws**  


Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（headsetStatus不为CONNECTED或DISCONNECTED）异常。

public static [AwarenessBarrier ](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)connecting()  
耳机连接围栏，添加此围栏后，当耳机连接设备时，此围栏状态为TRUE并触发围栏事件上报，5s后状态切换为FALSE。  
使用此围栏需添加android.permission.BLUETOOTH权限。

public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier) disconnecting()  
耳机断开连接围栏，添加此围栏后，当耳机断开连接时，此围栏状态为TRUE并触发围栏事件上报，5s后状态切换为FALSE。  
使用此围栏需添加android.permission.BLUETOOTH权限。
