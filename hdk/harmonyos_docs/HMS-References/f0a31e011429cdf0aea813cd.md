public String getResult ()  
获取系统完整性检测结果，检测结果的格式为 JSON Web Signature。  
  
  
**Return**  


type| desc  
---|---  
String| 一个 JSON Web Signature 格式的字符串，使用 Base64URL 编码，如果发生异常或错误，则返回 null。JWS 的 Header 字段如下：
      
      1. {
        2.     "alg": "RS256",
        3.     "x5c": ["",""]
        4. }
    
    

说明： "alg": 签名算法名称，RS256 表示为 SHA256withRSA "x5c": 华为签名服务器对 JWS 签名的证书链，x5c[0] 为给 JWS 签名的证书， x5c[1] 为华为设备 CA  
JWS 的 Payload 字段如下：
      
      1. {
        2.     "nonce":"bSshKk0YTZrfOl5IjK7HcQ==",
        3.     "timestampMs":1571708929141,
        4.     "apkPackageName":"com.huawei.hms.safetydetectsample",
        5.     "apkDigestSha256":"6Ihk8Wcv1MLm0O5KUCEVYCI/0KWzAHn9DyN38R3WYu8=",
        6.     "apkCertificateDigestSha256":["yT5JtXRgeIgXssx1gQTsMA9GzM9ER4xAgCsCC69Fz3I="],
        7.     "basicIntegrity":false,
        8.  "advice":"RESTORE_TO_FACTORY_ROM"
        9. }
    
    

说明："nonce": 调用 sysIntegrity 接口时传入的 nonce 值的 base64 编码"timestampMs": 华为签名服务器生成的时间戳 "apkPackageName": 您的应用的包名"apkDigestSha256": 您的应用的 apk SHA256 摘要"apkCertificateDigestSha256": 您的应用的签名证书 SHA256 摘要,"basicIntegrity":  系统完整性检测的结果，为 true 表示检测结果完整"advice": 根据系统完整性检测结果提出的建议，RESTORE_TO_FACTORY_ROM 表示恢复出厂设置
