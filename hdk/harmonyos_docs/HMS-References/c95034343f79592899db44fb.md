# AutoRecorderManager

**CLASS info**  
---  
public class AutoRecorderManager  
提供自动记录传感器数据、停止记录传感器数据、以及获取记录信息的能力  
  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200515175601.86922713927821534915913907926061:50510515100727:2800:1B116AA03CFF0C7E66124C2198DF099050139C15237838F344C175D922AFCA94.png?needInitFileName=true?needInitFileName=true)

目前，只支持累计步数（DT_CONTINUOUS_STEPS_TOTAL）、增量步数（DT_CONTINUOUS_STEPS_DELTA）类型的自动记录功能。

**Return** | **Method**  
---|---  
PendingResult<ListRecordsResult> | getRecords(HiHealthKitClient client) 获取当前应用的记录信息列表  
PendingResult<ListRecordsResult> | getRecords(HiHealthKitClient client, DataType dataType) 获取当前应用中，指定数据类型的记录信息列表  
PendingResult<Status> | startRecord(HiHealthKitClient client, DataCollector dataCollector) 按照数据采集器启动数据记录  
PendingResult<Status> | startRecord(HiHealthKitClient client, DataType dataType) 按照数据类型启动数据记录

PendingResult<Status> | stopRecord(HiHealthKitClient client, DataType dataType) 按照数据类型停止数据记录

#### [h2]getRecords(HiHealthKitClient client)

**Method**  
---  
PendingResult<ListRecordsResult> getRecords(HiHealthKitClient client)  
获取当前应用的记录信息列表  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
client | HiHealthKitClient实例对象，用于鉴权等功能，使用该对象之前必须先调用connect接口  
  
**Returns**

**Type** | **Return desc**  
---|---  
PendingResult<ListRecordsResult> | 记录信息的列表，包含当前应用的记录信息  
  
示例代码如下：
    
    
    HiHealthKitClient hiHealthKitClient = new HiHealthKitClient.Builder(context).build(); 
    hiHealthKitClient.connect(); 
    HuaweiHiHealth.AUTORECORDERMANAGER.getRecords(hiHealthKitClient) 
                .setResultCallback(new ResultCallback<ListRecordsResult>() { 
                    @Override 
                    public void onResult(@NonNull ListRecordsResult listRecordsResult) { 
                        if (listRecordsResult.getStatus().isSuccess()) { 
                            for (Record record : listRecordsResult.getRecords()) { 
                                Log.i("TEST", "record info: " + record.toString()); 
                            } 
                        } 
                    } 
                });

#### [h2]stopRecord(HiHealthKitClient client, Record record)

**Method**  
---  
PendingResult<Status> stopRecord(HiHealthKitClient client, Record record)  
按照记录信息停止数据记录  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
client | HiHealthKitClient实例对象，用于鉴权等功能，使用该对象之前必须先调用connect接口  
record | 待停止的记录  
  
该接口使用前，建议先使用getRecords接口获取记录信息，将得到的Record信息作为该接口的入参：
    
    
    HiHealthKitClient hiHealthKitClient = new HiHealthKitClient.Builder(context).build(); 
    hiHealthKitClient.connect(); 
    HuaweiHiHealth.AUTORECORDERMANAGER.getRecords(hiHealthKitClient) 
        .setResultCallback(new ResultCallback<ListRecordsResult>() { 
            @Override 
            public void onResult(@NonNull ListRecordsResult listRecordsResult) { 
                if (listRecordsResult.getStatus().isSuccess()) { 
                    for (Record record : listRecordsResult.getRecords()) { 
                        Log.i("TEST", "record info: " + record.toString()); 
                        HuaweiHiHealth.AUTORECORDERMANAGER.stopRecord(hiHealthKitClient, record); 
                    } 
                } 
            } 
        });
