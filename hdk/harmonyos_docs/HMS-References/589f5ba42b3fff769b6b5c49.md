#### 功能介绍  
  
开发者应用服务器调用此接口创建导出数据任务，可以导出开发者在App端侧采集上报的所有数据。

#### 场景描述

当开发者自建了分析平台或使用第三方分析平台，如果开发者需要将通过Analytics Kit采集的数据导入这些分析平台的数据做分析时，开发者可以通过此接口请求导出Analytics Kit采集的数据。

#### 使用约束

  * 一个App同时支持最多3个导出的任务，即：当有3个在执行导出任务时，不再接收新的导出请求，其中的某个或全部任务执行完成后，可以接收新的导出请求。

  * 调用频率不超过1条/秒。




#### 接口原型

承载协议| HTTP POST  
---|---  
接口方向| 分析服务服务器→开发者回调接口服务器  
接口URL| POST https://<URI>/analytics/export/raw_data_requests/v2  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
#### 请求参数

**表1** 请求Body参数参数| 是否必选| 参数类型| 描述  
---|---|---|---  
date_range| 是| DateRange| 查询时间范围。  
file_format| 是| String| 文件格式只支持csv。  
filters| 否| List<Filter>| 属性过滤条件。  
**表2  **DateRange参数| 是否必选| 参数类型| 描述  
---|---|---|---  
start_date| 是| string| 起始时间，字符串格式yyyy-MM-dd。  
end_date| 是| string| 结束时间，字符串格式yyyy-MM-dd。  
**表3  **Filter参数| 是否必选| 参数类型| 描述  
---|---|---|---  
name| 是| string| 过滤参数key，为用户属性名。  
values| 是| string| 过滤参数值，为用户属性值。  
  
#### 响应参数

**表4  **响应Body参数参数| 参数类型| 描述  
---|---|---  
result_code| String| 响应码，详见错误码。  
result_msg| String| 响应描述。  
  
#### 响应示例
      
      1. HTTP/1.1 200 OK
        2. Content-Type: application/json; charset=UTF-8
        3. Connection:  Close
        4. Content-Length: xxxx                       
        5. {
        6.   "result_code":"0",
        7.   "result_msg":"success",
        8. }
    
    

#### 错误码

状态码| 错误码| 响应代码| 描述| 处理建议  
---|---|---|---|---  
200| 0| Success| 请求成功。| -  
400| 10020| invalidParameter| 非法参数。| 开发者修改填写错误的参数值。  
400| 10008| tooFrequentRequest| 接口请求过于频繁。| 开发者修改代码，降低查询导出任务状态的频率。  
400| 10009| tooManyTask| 超过任务上限，一天同一个APP下载请求只允许3个。| 开发者需要等待其他任务执行完成后重新调用创建导出任务。
