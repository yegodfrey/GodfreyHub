public GroundOverlayOptions anchor(float u, float v)  
开发者调用此API可以设置覆盖物图片的对齐方式，即指定锚点的位置。（0, 0）是左上角，（1, 0）是右上角，（0, 1）是左下角，（1, 1）是右下角 。如果不设置，默认为（0.5, 0.5）图片的中心点。例如，在覆盖物X（0.5, 0.3）处的锚点坐标如下：![](http://10.116.132.132:8080/idp-edit-service/editor/image/1032914/1_zh-cn_image_0000001050312750.png)  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
u| 锚点的水平坐标，以图像宽度的比例，在[0，1]范围内。  
v| 锚点的垂直坐标，以图像高度的比例，在[0，1]范围内。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
GroundOverlayOptions| 设置新的对齐方式后的GroundOverlayOptions对象。

public GroundOverlayOptions zIndex(float zIndex)  
用于设置覆盖物的z指数。z指数指的是覆盖物的叠加顺序，具有较大z指数的覆盖物会绘制在具有较小z指数的覆盖物上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
zIndex| z指数，即覆盖物的叠加顺序。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
GroundOverlayOptions| 设置新的z指数后的GroundOverlayOptions对象。
