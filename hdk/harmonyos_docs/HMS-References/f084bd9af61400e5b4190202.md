**根据 instanceId 全量更新礼品卡个人化数据。**  
  
# **1 请求**

## **HTTP请求**

PUT  
https://**${url}** /hmspass/v1/giftcard/instance/**{instanceId}**  
备注：请求地址中的 **${url}  **变量需要开发者根据服务器所属区域自行选择，请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。

## **URL路径参数**

  
|   
|   
  
---|---|---  
instanceId| String| 个人化数据 instanceId，该 Id 在一个商户的所有 instance 中唯一，这个 Id 只能包含字母、数字和（.）、（-）、（_）。  
  
## **请求体**

请求体包含一个 [hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject") 对象，为待更新礼品卡个人化数据。

# 2 响应

如果成功，响应消息包含更新后的 [hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject") 对象。
