情景感知状态包，包括信标状态、耳机状态、时间状态、地理位置、活动状态、天气状态、环境光状态、车载蓝牙状态和各能力支持状态相关类。  
  
## Interfaces

Interface name| Interface description  
---|---  
[BeaconStatus](https://developer.huawei.com/consumer/cn/doc/beacon-status-4)| public interface BeaconStatus  
附近信标设备状态的接口类，定义了一个内部类[BeaconStatus.Filter](https://developer.huawei.com/consumer/cn/doc/HMS-References/status-filter-4)和一个内部接口[BeaconStatus.BeaconData](https://developer.huawei.com/consumer/cn/doc/beacon-data-4)。  
[HeadsetStatus](https://developer.huawei.com/consumer/cn/doc/headset-status-4)| public interface HeadsetStatus  
耳机状态接口类，其中定义了3个耳机状态的常量，即表示耳机已连接CONNECTED、耳机未连接DISCONNECTED和无法识别到耳机状态UNKNOWN。  
[TimeCategories](https://developer.huawei.com/consumer/cn/doc/time-categories-4)| public interface TimeCategories  
表示设备当前所在地的时间状态信息的接口类。时间状态是TimeBarrier类中定义的上午[TIME_CATEGORY_MORNING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_MORNING)，下午[TIME_CATEGORY_AFTERNOON](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_AFTERNOON)，晚上[TIME_CATEGORY_EVENING](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_EVENING)，夜间[TIME_CATEGORY_NIGHT](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NIGHT)，工作日[TIME_CATEGORY_WEEKDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKDAY)，休息日[TIME_CATEGORY_WEEKEND](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_WEEKEND)，节假日[TIME_CATEGORY_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_HOLIDAY)，非节假日[TIME_CATEGORY_NOT_HOLIDAY](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#TIME_CATEGORY_NOT_HOLIDAY)。  
[AmbientLightStatus](https://developer.huawei.com/consumer/cn/doc/ambient-light-status-4)| public interface AmbientLightStatus  
光照度状态接口，可以从该接口中调用[getLightIntensity](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getLightIntensity)获取光照度值。  
[WeatherStatus](https://developer.huawei.com/consumer/cn/doc/awareness-weatherstatus-4)| public interface WeatherStatus  
天气状态接口，携带了完整的天气信息，在该类中提供了5个方法，可分别获取AQI天气指数、当前天气信息、未来7天天气、未来24小时天气和未来1~2天的生活指数。其中，AQI和生活指数仅提供中国大陆数据。  
[CNWeatherId](https://developer.huawei.com/consumer/cn/doc/cn-weatherId-4)| public interface CNWeatherId  
中国使用的天气ID常量接口，说明了不同[cnWeatherId](https://developer.huawei.com/consumer/cn/doc/cn-weatherId-4)对应的天气情况。  
[WeatherId](https://developer.huawei.com/consumer/cn/doc/weatherid-4)| public interface WeatherId  
天气ID常量接口，说明了不同[weatherId](https://developer.huawei.com/consumer/cn/doc/weatherid-4)对应的天气情况。  
[BluetoothStatus](https://developer.huawei.com/consumer/cn/doc/awareness-status-bluetoothstatus)| public interface BluetoothStatus  
车载蓝牙状态接口类，中定义了3个车载蓝牙状态的常量，即表示车载蓝牙已连接CONNECTED、表示车载蓝牙未连接DISCONNECTED和表示未识别到车载蓝牙状态UNKNOWN。  
[CapabilityStatus](https://developer.huawei.com/consumer/cn/doc/awareness-capabilitystatus)| public interfaceCapabilityStatus各细分能力支持状态接口类，可以从该接口调用[getCapabilityStatus](https://developer.huawei.com/consumer/cn/doc/awareness-capabilityresponse#getCapabilityStatus)方法获取Awareness在当前设备所支持的能力。  
  
## Classes

Class name| Class description  
---|---  
[BehaviorStatus](https://developer.huawei.com/consumer/cn/doc/awareness-behaviorstatus-4)| 识别活动的结果，包含在指定时间内用户可能正在进行的活动的列表，列表按照活动置信度排序，置信度越高排名越靠前。  
[DetectedBehavior](https://developer.huawei.com/consumer/cn/doc/detected-behavior-4)| 检测到的活动类型和该活动的置信度。  
[Aqi](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-aqi)| 天气状态WeatherStatus中的空气质量指数。包括一氧化碳指数、二氧化氮指数、臭氧指数、pm10指数、pm25指数、二氧化硫指数，和综合天气指数。  
[City](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-city)| 天气状态WeatherStatus中的城市信息。包括城市码、省份名称、时区、和城市/区名称。  
[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-dailyliveinfo)| 当天与未来一到两天的生活指数信息。每天的生活指数包括穿衣指数、运动指数、寒冷指数、洗车指数、旅游指数和紫外线指数。  
[DailySituation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-dailysituation)| 白天或者晚上的简略天气情况。包括天气Id(CN)、风速、风级、风向。  
[DailyWeather](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-dailyweather)| 当天和未来六到七天的天气信息。包括月出、月落、日出、日落、最低温最高温（摄氏度）、最低温最高温（华氏度）、综合空气指数（国外版不支持）、当地时间凌晨时间戳、月相、白天简略天气情况（DailySituation）、夜间简略天气情况（DailySituation）。  
[HourlyWeather](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-hourlyweather)| 当前小时和未来24个小时的天气信息。包括天气ID(CN)、对应时间信息、摄氏度、华氏度、降雨概率、是否是晚上。  
[LiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-liveinfo)| 某个生活指数当天和未来一到两天的指数等级。包括该指数的指数码、当天和未来一到两天的该指数的等级。  
[Situation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-situation)| 当前天气信息。包括天气ID(CN)、湿度、摄氏度、华氏度、体感温度（℃）、体感温度（℉）、风向、风力等级、风速、气压、紫外线强度、更新时间。  
[WeatherSituation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-weathersituation)| 当前天气情况，由当前天气信息（Situation）及城市信息（City）组成。
