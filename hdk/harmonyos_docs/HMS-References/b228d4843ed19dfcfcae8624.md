# DataController  
  
**CLASS info**  
---  
public class DataController  
数据管理的接口定义，用户可通过该接口插入、删除、 更新和读取数据，也可以通过监听接口监听数据的更新等。 开发者可以通过HuaweiHiHealth类获取到DataController。 获取DataController实例对象的示例代码如下：
    
    
    // 获取并设置步数增量（DT_CONTINUOUS_STEPS_DELTA）读写权限，身高（DT_CONTINUOUS_STEPS_DELTA）读写权限，
    // 并使用该权限获取到数据控制器对象
    HiHealthOptions hiHealthOptions = HiHealthOptions.builder()
    	.addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA, HiHealthOptions.ACCESS_READ)
    	.addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA, HiHealthOptions.ACCESS_WRITE)
    	.addDataType(DataType.DT_INSTANTANEOUS_HEIGHT, HiHealthOptions.ACCESS_READ)
    	.addDataType(DataType.DT_INSTANTANEOUS_HEIGHT, HiHealthOptions.ACCESS_WRITE)
    	.build();
    AuthHuaweiId signInHuaweiId = HuaweiIdAuthManager.getExtendedAuthResult(hiHealthOptions);
    DataController dataController = HuaweiHiHealth.getDataController(context, signInHuaweiId);

Task<Void> | clearAll() 清除本应用插入的所有端侧和云侧的数据

#### [h2]insert(SampleSet sampleSet)

**Method**  
---  
public Task<Void> insert(SampleSet sampleSet)  
将采样数据集插入到“health平台”  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
sampleSet | 待插入到Health数据平台中的数据采样集。  
  
示例代码如下：
    
    
    // 1. 构造一个数据采集器对象 
    DataCollector dataCollector = new DataCollector.Builder().setPackageName(context) 
        .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA) 
        .setDataStreamName("STEPS_DELTA") 
        .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
        .build(); 
     
    // 2. 根据数据采集器，创建一个数据样本集合 
    final SampleSet sampleSet = SampleSet.create(dataCollector); 
     
    // 3. 构造步数增量（DT_CONTINUOUS_STEPS_DELTA）一个数据点的开始，结束时间，增量步数 
    SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd hh:mm:ss"); 
    Date startDate = dateFormat.parse("2020-03-17 09:00:00"); 
    Date endDate = dateFormat.parse("2020-03-17 09:05:00"); 
    int stepsDelta = 1000; 
     
    // 4. 构造一个步数增量（DT_CONTINUOUS_STEPS_DELTA）数据点 
    SamplePoint samplePoint = sampleSet.createSamplePoint() 
        .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS); 
    samplePoint.getFieldValue(Field.FIELD_STEPS_DELTA).setIntValue(stepsDelta); 
     
    // 5. 可以将一个步数增量数据点添加到数据样本集合，也可以重复执行3 ~ 5添加多个样本点数据到样本集合 
    sampleSet.addSample(samplePoint); 
     
    // 6. 调用数据控制器，将数据样本集合插入到 Health 平台中 
    Task<Void> insertTask = dataController.insert(sampleSet); 
     
    // 7. 调用数据控制器写入样本集合数据是异步操作，需要设置完成，成功或失败监听器，监听数据写入成功或失败 
    insertTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
        @Override 
        public void onSuccess(Void result) { 
            logger("Success insert a SampleSet into HMS core"); 
            showSampleSet(sampleSet); 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
            String errorCode = e.getMessage(); 
            String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
            logger(errorCode + ": " + errorMsg); 
        } 
    });

#### [h2]delete(DeleteOptions options)

**Method**

public Task<Void> delete(DeleteOptions options)  
删除插入的采样数据集，可以删除指定时间范围的数据，删除全部数据，以及删除活动记录  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
options | DeleteOptions类型，指定要删除数据的数据采集器、数据类型和时间范围  
  
示例代码如下：
    
    
    // 1. 构造删除条件：一个数据采集器对象 
    DataCollector dataCollector = new DataCollector.Builder().setPackageName(context) 
        .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA) 
        .setDataStreamName("STEPS_DELTA") 
        .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
        .build(); 
     
    // 2. 构造删除条件时间区间：开始，结束时间 
    SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd hh:mm:ss"); 
    Date startDate = dateFormat.parse("2020-03-17 09:00:00"); 
    Date endDate = dateFormat.parse("2020-03-17 09:05:00"); 
     
    // 3. 构造条件删除的参数对象 
    DeleteOptions deleteOptions = new DeleteOptions.Builder().addDataCollector(dataCollector) 
        .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS) 
        .build(); 
     
    // 4. 使用指定的条件删除对象，调用数据控制器删除数据样本集 
    Task<Void> deleteTask = dataController.delete(deleteOptions); 
     
    // 5. 调用数据控制器删除样本集合数据是异步操作，需要设置完成，成功或失败监听器，监听数据删除成功或失败 
    deleteTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
        @Override 
        public void onSuccess(Void result) { 
            logger("Success delete sample data from HMS core"); 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
            String errorCode = e.getMessage(); 
            String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
            logger(errorCode + ": " + errorMsg); 
        } 
    });

public Task<Void> update(UpdateOptions options)  
对于已有数据进行更新，若指定更新的数据不存在，则直接插入该数据  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
options | UpdateOptions类型，指定待更新数据所处的时间范围和更新后的数值  
  
示例代码如下：
    
    
    // 1. 构造修改条件：一个数据采集器对象 
    DataCollector dataCollector = new DataCollector.Builder().setPackageName(context) 
        .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA) 
        .setDataStreamName("STEPS_DELTA") 
        .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
        .build(); 
     
    // 2. 构造修改数据样本集合：根据数据采集器，创建一个修改数据样本集合 
    SampleSet sampleSet = SampleSet.create(dataCollector); 
     
    // 3. 构造修改步数增量（DT_CONTINUOUS_STEPS_DELTA）一个数据点的开始，结束时间，增量步数 
    SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd hh:mm:ss"); 
    Date startDate = dateFormat.parse("2020-03-17 09:00:00"); 
    Date endDate = dateFormat.parse("2020-03-17 09:05:00"); 
    int stepsDelta = 2000; 
     
    // 4. 构造一个修改步数增量（DT_CONTINUOUS_STEPS_DELTA）数据点 
    SamplePoint samplePoint = sampleSet.createSamplePoint() 
        .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS); 
    samplePoint.getFieldValue(Field.FIELD_STEPS_DELTA).setIntValue(stepsDelta); 
     
    // 5. 将一个步数增量数据点添加到修改数据样本集合，也可以重复执行3 ~ 5添加多个修改样本点数据到修改样本集合 
    sampleSet.addSample(samplePoint); 
     
    // 6. 构造一个修改操作的参数对象 
    // 注意：（1）修改对象updateRequest的开始时间，此时间不能比修改数据样本集合中所有样本数据点的开始时间的最小值大 
    //       （2）修改对象updateRequest的结束时间，此时间不能比修改数据样本集合中所有样本数据点的结束时间的最大值小 
    UpdateOptions updateRequest = 
        new UpdateOptions.Builder().setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS) 
            .setSampleSet(sampleSet) 
            .build(); 
     
    // 7. 使用指定的修改参数对象，调用运动与健康数据控制器修改数据样本集 
    Task<Void> updateTask = dataController.update(updateRequest); 
     
    // 8. 调用数据控制器修改样本集合数据是异步操作，需要设置完成，成功或失败监听器，监听数据修改成功或失败 
    updateTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
        @Override 
        public void onSuccess(Void result) { 
            logger("Success update sample data from HMS core"); 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
            String errorCode = e.getMessage(); 
            String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
            logger(errorCode + ": " + errorMsg); 
        } 
    });

#### [h2]read(ReadOptions readOptions)

**Method**

public Task<ReadReply> read(ReadOptions readOptions)  
读取用户数据的接口，可通过设置ReadOptions的参数，读取不同时间、设备、数据采集源等维度的数据  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
readOptions | ReadOptions类型，读取数据的请求参数选项，用于指定数据采集器、数据类型以及查询数据的时间范围等条件，具体可参考ReadOptions的定义。  
  
**Return**

**Type** | **Return desc**  
---|---  
ReadReply | 返回读取数据  
  
示例代码如下：
    
    
    // 1. 构造查询条件：一个数据采集器对象 
    DataCollector dataCollector = new DataCollector.Builder().setPackageName(context) 
        .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA) 
        .setDataStreamName("STEPS_DELTA") 
        .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
        .build(); 
     
    // 2. 构造查询条件时间区间：开始，结束时间 
    SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd hh:mm:ss"); 
    Date startDate = dateFormat.parse("2020-03-17 09:00:00"); 
    Date endDate = dateFormat.parse("2020-03-17 09:05:00"); 
     
    // 3. 构造条件查询的查询对象 
    ReadOptions readOptions = new ReadOptions.Builder().read(dataCollector) 
        .setTimeRange(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS) 
        .build(); 
     
    // 4. 使用指定的条件查询对象，调用运动与健康数据控制器查询数据样本集 
    Task<ReadReply> readReplyTask = dataController.read(readOptions); 
     
    // 5. 调用数据控制器查询样本集合数据是异步操作，需要设置成功或失败监听器，监听数据查询成功或失败 
    readReplyTask.addOnSuccessListener(new OnSuccessListener<ReadReply>() { 
        @Override 
        public void onSuccess(ReadReply readReply) { 
            logger("Success read a SampleSets from HMS core"); 
            for (SampleSet sampleSet : readReply.getSampleSets()) { 
                showSampleSet(sampleSet); 
            } 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
            String errorCode = e.getMessage(); 
            String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
            logger(errorCode + ": " + errorMsg); 
        } 
    });

注册数据变化的监听，当数据有变化时将会收到通知，可以在收到的通知里获取变化的信息  
  
**Parameters**

**Parameter name** | **Parameter desc**  
---|---  
options | ModifyDataMonitorOptions类型，注册数据监听器的参数选项，包含数据采集器，数据类型以及pendingIntent，数据更新时触发pendingIntent调用。  
  
示例代码如下：
    
    
    // 1. 构造一个数据采集器对象, 数据类型指定当前允许添加监听的6种数据类型中的一种 
    DataCollector dataCollector = new DataCollector.Builder().setPackageName(context) 
        .setDataType(DataType.DT_INSTANTANEOUS_HEIGHT) 
        .setDataStreamName("STEPS_DELTA") 
        .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
        .build(); 
     
    // 2. 构建一个数据修改的监听对象： PendingIntent 
    PendingIntent pendingIntent = PendingIntent.getBroadcast(this, 0, new Intent(this, DataRegisterReceiver.class), 
        PendingIntent.FLAG_UPDATE_CURRENT); 
     
    // 3. 构造一个添加数据更改监听的参数对象 
    ModifyDataMonitorOptions dataMonitorOptions = 
        new ModifyDataMonitorOptions.Builder().setModifyDataType(DataType.DT_INSTANTANEOUS_HEIGHT) 
            .setModifyDataCollector(dataCollector) 
            .setModifyDataIntent(pendingIntent) 
            .build(); 
     
    // 4. 使用指定的添加数数据更改监听参数对象，调用运动与健康数据控制器添加数据监听 
    Task<Void> registerTask = dataController.registerModifyDataMonitor(dataMonitorOptions); 
     
    // 5. 调用数据控制器添加数据监听是异步操作，需要设置成功或失败监听器，监听数据监听成功或失败 
    registerTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
        @Override 
        public void onSuccess(Void result) { 
            logger("Register Data Update Listener Success"); 
        } 
    }).addOnFailureListener(new OnFailureListener() { 
        @Override 
        public void onFailure(Exception e) { 
            String errorCode = e.getMessage(); 
            String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
            logger("Register Data Update Listener Failure: " + errorCode + ": " + errorMsg); 
            pendingIntent = null; 
        } 
    });
