OperationResult类主要用于打开存档或解决数据冲突时，返回最终存档数据或冲突数据。  
  
# **Public Method Summary**

Return| Method  
---|---  
[Difference](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/difference)| getDifference()获取包含冲突信息的[Difference](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/difference)对象。  
[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)| getArchive()获取不存在冲突时的数据。  
boolean| isDifference()是否存在冲突信息。  
  
# Public Methods  


## public Difference getDifference()

获取包含冲突信息的[Difference](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/difference)对象。只有当isDifference返回true时才需要获取。

**返回值**

Type| Description  
---|---  
[Difference](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/difference)| 包含具体冲突信息的[Difference](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/difference)对象，只有isConflict返回true才需要获取。  
  
## public Archive getArchive()  


获取[OperationResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/operationresult)中包含的存档数据。

**返回值**

Type| Description  
---|---  
[Archive](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/archive)| [OperationResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/operationresult)包含的存档对象。  
  
## public boolean isDifference()  


打开存档元数据或解决数据冲突时，是否存在数据冲突。

**返回值**

Type| Description  
---|---  
boolean| 是否存在数据冲突。
     * true：存在冲突，使用getDifference获取冲突数据。
     * false：不存在冲突，使用getArchive获取存档数据。
