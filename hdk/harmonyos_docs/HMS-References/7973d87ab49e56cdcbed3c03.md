**public final class CameraUpdateFactory**

CameraUpdateFactory是一个包含了各种用于创建[CameraUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-cameraupdate)对象的方法，该对象用于更改地图相机属性。

public static CameraUpdate newLatLngBounds([LatLngBounds](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-latlngbounds) bounds, int width, int height, int padding)  
开发者调用此API可以设置相机中心区域，包括屏幕中心区域宽度、高度、地图区域与中心区域边框之间的间距。

height| 边框高度，以像素为单位。  
padding| 地图区域与边框之间的间距，以像素为单位。
