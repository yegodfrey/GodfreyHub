public RemoteMessage.Builder setTtl(int ttl)  
当设备离线时，设置离线消息的最大缓存时间，单位秒。如果不设置，消息将尝试立即发送而不会缓存，如果设备不可连接，那么消息将丢弃。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
ttl| 华为推送服务缓存离线消息的最大时间，单位为秒。支持设置最大15天。  
  
**Throws**

Throw name| Throw desc  
---|---  
IllegalArgumentException| 入参ttl的值必须满足闭区间[1, 1296000]，否则会抛出不合法参数（IllegalArgumentException）的异常。

public RemoteMessage.Builder setCollapseKey(String collapseKey)  
设置消息分类标识，用于控制离线消息的覆盖功能。对于缓存的离线消息，具有相同分类标识的最新消息会覆盖老的消息。当华为推送服务检测到目标设备离线时，下发给离线用户的多条消息，华为推送服务会按照设置的TTL将消息进行缓存，待用户上线后会将缓存的消息下发给用户。  
  
  
**Parameters**  


Parameter name| Parameter desc  
---|---  
collapseKey| 设置collapse_key为-1表示对于本应用的离线消息待用户上线后全部发送给用户；设置collapse_key为0表示对于本应用的离线消息待用户上线后按照华为推送系统默认策略发送给用户(一般是最新的一条);设置collapse_key为1~100是对消息进行分组，例如如果开发者发送了10条消息，其中前5条的collapse_key为1，后5条的collapse_key为2，那么待用户上线后collapse_key为1和2的分别下发最新的一条消息给最终用户。

public RemoteMessage.Builder setSendMode(int sendMode)  
设置是否使用终端设备上Push的消息缓存重发能力。如果不设置则不支持消息缓存，比如当网络不可用时消息会直接丢弃。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
sendMode| 取值只有0与1，1表示使用消息缓存重发能力。  
  
**Throws**

Throw name| Throw desc  
---|---  
IllegalArgumentException| 设置的值非0非1则抛出此异常。

public RemoteMessage.Builder setReceiptMode(int receiptMode)  
设置上行消息发送到App服务器后的消息回执能力。即App发送的上行消息如果成功发送给您的服务器，您的服务器应答之后，这个应答消息会通过HmsMessageService类的onMessageDelivered方法回执给您的App。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
receiptMode| 取值只有0与1，1表示使用消息回执能力。  
  
**Throws**

Throw name| Throw desc  
---|---  
IllegalArgumentException| 设置的值非0非1则抛出此异常。
