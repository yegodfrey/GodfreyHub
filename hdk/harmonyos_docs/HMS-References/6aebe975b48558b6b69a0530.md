public class AuthAccount extends AbstractAuthAccount

public String getUnionId()  
如果授权时携带new AccountAuthParamsHelper().setId()指定的授权参数，该方法返回用户的unionId，否则返回null。unionId和openId的区别在于，如果开发者帐号下管理了多个应用，针对同一个AppTouch ID，不同的应用返回的openId值不同，但返回的unionId相同。如果开发者需要在不同应用中共享同一个AppTouch ID的用户信息，可以使用unionId作为用户标识。使用unionId作为用户标识需要满足以下所有条件，如果任一不满足则不会返回：● 应用集成Account SDK 4.0.4以及更高版本。● 华为移动服务APK版本为4.0.4以及更高版本。● 应用启用了UnionId。
