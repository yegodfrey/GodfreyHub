com.huawei.hms.mlsdk.classification.MLImageClassificationAnalyzer  
图像分类器：用于在提供的图像中查找图像类别（MLImageClassification）。图像分类器有两种类型，一种是设备端分类器，即在设备上运行分类模型，返回分类结果；另一种是云端分类器，即调用云端API进行分类，分类模型在云端运行。创建设备端图像分类器有两种方式：MLAnalyzerFactory.getInstance().getLocalImageClassificationAnalyzer()和MLAnalyzerFactory.getInstance().getLocalImageClassificationAnalyzer(MLLocalClassificationAnalyzerSetting)， 前者使用MLLocalClassificationAnalyzerSetting中设置的默认配置，后者可自定义配置项。  
  
## Sample Code
    
    
    复制
      
        1. // 创建使用默认配置的设备端图像分类器。
        2. MLImageClassificationAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalImageClassificationAnalyzer();
        3. // 也可以通过用同样的方式创建云端图像分类器。
        4. // MLImageClassificationAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteImageClassificationAnalyzer();
        5. // 通过bitmap创建MLFrame。建议图片尺寸不小于224*224。
        6. MLFrame frame = MLFrame.fromBitmap(bitmap);
        7. Task<List<MLImageClassification>> task = analyzer.asyncAnalyseFrame(frame);
        8. task.addOnSuccessListener(new OnSuccessListener<List<MLImageClassification>>() {
        9.    public void onSuccess(List<MLImageClassification> classifications) {
        10.    // 对分类结果进行处理
        11.    }
        12. }).addOnFailureListener(new OnFailureListener() {
        13.    public void onFailure(Exception e) {
        14.    // 处理失败
        15.    }
        16. });
