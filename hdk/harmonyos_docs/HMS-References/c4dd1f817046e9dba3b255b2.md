com.huawei.hms.mlsdk.translate.cloud.MLRemoteTranslator  
文本翻译器，根据提供的文本，从源语言转换为目标语言。调用云端API，检测模型在云端运行。  
  
## Sample Code
      
      1.  // 创建文本翻译器
        2.  // setSourceLangCode 设置源语言编码，使用ISO 639-1标准
        3.  // setTargetLangCode 设置目标语言编码，使用ISO 639-1标准
        4.  MLRemoteTranslateSetting settings = new MLRemoteTranslateSetting.Factory()
        5.          .setSourceLangCode(sourceLangCode)
        6.          .setTargetLangCode(targetLangCode)
        7.          .create();
        8.  MLRemoteTranslator mlRemoteTranslator = MLTranslatorFactory.getInstance().getRemoteTranslator(settings);
        9.  // 进行文本翻译
        10.  // sourceText是待翻译的文本
        11.  final Task<String> task = mlRemoteTranslator.asyncTranslate(sourceText);
        12.  task.addOnSuccessListener(new OnSuccessListener<String>() {
        13.     public void onSuccess(String text) {
        14.         // 成功的处理逻辑
        15.     }
        16.  }).addOnFailureListener(new OnFailureListener() {
        17.     public void onFailure(Exception e) {
        18.         // 失败的处理逻辑
        19.     }
        20.  });
        21.  // 释放资源
        22.  mlRemoteTranslator.stop();
