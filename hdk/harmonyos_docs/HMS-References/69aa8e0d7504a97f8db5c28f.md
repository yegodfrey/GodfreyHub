BuoyClient类定义了浮标的相关接口。  
  
# Public Method Summary

Return| Method  
---|---  
Task<void>| showFloatWindow(Activity activity)展示浮标  
Task<void>| hideFloatWindow(Activity activity)隐藏浮标。  
  
# Public Methods  


## public Task<void> showFloatWindow(Activity activity)

在游戏界面中展示浮标。一般建议在游戏界面的onResume方法中调用。

**请求参数**

Parameter Name| Parameter Description  
---|---  
activity| 需要显示浮标的Activity实例。  
  
## public Task<void> hideFloatWindow(Activity activity)  


将游戏界面中浮标隐藏。一般建议在onPause中调用本接口隐藏游戏浮标。

同一个游戏界面必须已经调用showFloatWindow接口显示浮标以后，才能调用本方法隐藏浮标。

**请求参数**

Parameter Name| Parameter Description  
---|---  
activity| 需要隐藏浮标的Activity实例。必须与调用showFloatWindow方法时传入的Activity示例一致。
