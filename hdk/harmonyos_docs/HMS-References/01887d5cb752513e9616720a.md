public BarrierUpdateRequest.Builder addBarrier(String key, AwarenessBarrier barrier, PendingIntent pendingIntent)  
根据围栏键值，在PendingIndent中关联一个Intent实现回调响应，此响应会在围栏触发时进行回调。如果给定的键值已经存在，会创建一个新的围栏代替已存在的围栏，并且原来所有的回调请求都将无效。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
key| 围栏唯一标识符，根据此参数可以添加或替换对应的围栏。  
barrier| 要注册的围栏。  
pendingIntent| 围栏状态变化时，pendingIntent发出回调响应。  
  
  
**Return**  


type| desc  
---|---  
BarrierUpdateRequest.Builder| Builder对象。  
  
  
**Throws**  


Parameter name| Parameter desc  
---|---  
NullPointerException| 空指针（当barrier或pendingIntent为null）异常。  
IllegalArgumentException| 非法入参（当key为空）异常。
