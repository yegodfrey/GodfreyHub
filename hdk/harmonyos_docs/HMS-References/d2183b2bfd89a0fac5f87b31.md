public MLFrame.Creator setTimestamp(long timestamp)  
设置帧时间戳，帧时间戳:记录系统启动到帧生成的毫秒数，包含设备深度休眠的时间。该时钟被保证是单调的，即使CPU在省电模式下，该时间也会继续计时。           该时钟可以被使用在当测量时间间隔可能跨越系统睡眠的时间段。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
timestamp| 帧时间戳。
