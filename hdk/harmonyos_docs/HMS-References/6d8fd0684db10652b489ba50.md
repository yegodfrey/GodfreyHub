public class DailySituation implements Parcelable  
白天或者晚上的天气情况。包括天气Id(CN)、风速、风级、风向。  
  
## Public Method Summary

Return type| Method name  
---|---  
int| getCnWeatherId()  
String| getWindDir()  
int| getWindLevel()  
int| getWindSpeed()  
  
## Public Methods

Method  
---  
public int getCnWeatherId()  
获取CN天气Id（cnWeatherId）。CN天气Id表示的是当前的天气，每个值都对应不同的天气，例如0表示晴，1表示多云，7表示小雨。更多天气ID对应的天气信息请参见[CNWeatherId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/cn-weatherId-4)。  
  
**Return**

Type| desc  
---|---  
int| CN天气Id。  
Method  
---  
public String getWindDir()  
获取风向，风向值有“NE（东北风向）”、“E（东风向）”、“SE（东南风向）”、“S（南风向）”、“SW（西南风向）”、“W（西风向）”、“N（北风向）”和“NW（西北风向）”八个值。  
  
**Return**

Type| desc  
---|---  
String| 风向，风向值有“NE（东北风向）”、“E（东风向）”、“SE（东南风向）”、“S（南风向）”、“SW（西南风向）”、“W（西风向）”、“N（北风向）”和“NW（西北风向）”八个值。  
Method  
---  
public int getWindLevel()  
获取风级。风级，实时天气的风级，值区间为0~17，0表示微风。  
  
**Return**

Type| desc  
---|---  
int| 风级，实时天气的风级，值区间为0~17，0表示微风。  
Method  
---  
public int getWindSpeed()  
获取风速，单位：km/h。  
  
**Return**

Type| desc  
---|---  
long| 风速，单位：km/h。
