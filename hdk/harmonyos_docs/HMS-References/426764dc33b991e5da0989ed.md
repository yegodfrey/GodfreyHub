# dataCollectors.sampleSets: get

指定开始时间和结束时间，返回该时间段内的采样数据集。

#### 请求

#### [h2]HTTP请求
    
    
    GET 
    https://health-api.cloud.huawei.com/hihealth/v1/dataCollectors/dataCollectorId/sampleSets/sampleSetId?limit=***&cursor=***

#### [h2]请求参数

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
dataCollectorId | string | 数据采集器的唯一标识 | 必选 | 需满足如下拼接规则：collectorType:collectorDataType.name: appInfo.appPackageName:deviceInfo.manufacturer: deviceInfo.modelNum:deviceInfo.uniqueId:collectorName。参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中collectorId的约束  
sampleSetId | string | 采样数据集标识符，单位：纳秒 | 必选 | 格式：“startTime-endTime”，其中：startTime/endTime必须是19位整数的时间戳，对应时间范围是2000-01-01 00:00:00 ~ 2099-12-31 23:59:59  
limit | integer | 单次分页查询长度 | 可选 | 取值范围：1~2000  
cursor | string | 分页继续查询的标识，填入上一个请求的cursor值即可 | 可选 | 长度范围：1~1000  
  
#### [h2]请求体

无

#### 响应

参数名称 | 参数类型 | 参数描述 | 可选/必选  
---|---|---|---  
startTime | long | 所有采样点的最小开始时间。单位：纳秒 | 必选  
endTime | long | 所有采样点的最大结束时间。单位：纳秒 | 必选  
dataCollectorId | string | 数据采集器的唯一标识 | 必选  
samplePoints | list<SamplePoint> | sample point 列表 | 必选  
  
其中，SamplePoint的所有字段，参考[dataCollectors.sampleSets: history](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_samplesets_history-0000001050116809) 第2点中的响应体。

#### 返回码

成功：http 200

失败：其他
