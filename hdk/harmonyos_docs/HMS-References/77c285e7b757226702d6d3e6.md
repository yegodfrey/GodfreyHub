public void setCompassEnabled(boolean enabled)  
开发者调用此API可以设置地图指南针功能是否可用。如果启用，当地图不是指向正北方向时，地图右上角会显示一个指南针图标，点击指南针可使地图旋转为正北方向；当地图为正北方向时，指南针图标隐藏。如果禁用，将永远不会显示指南针图标。  
  
  
**Parameters：**

Parameter name| Parameter desc  
---|---  
enabled| true表示启用指南针功能，false表示禁用指南针功能，默认值为true。  
  
  
**Return：**  
无

public void setTiltGesturesEnabled(boolean enabled)  
开发者调用此API可以设置是否启用倾斜手势。如果启用，用户可以使用两指垂直向上滑动来倾斜相机。如果禁用，则用户无法通过手势来倾斜相机。  
  
  
**Parameters：**

Parameter name| Parameter desc  
---|---  
enabled| true表示启用倾斜手势，false表示禁用倾斜手势，默认值为true。  
  
  
**Return：**  
无
