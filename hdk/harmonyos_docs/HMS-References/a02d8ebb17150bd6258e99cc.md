public static class Stream  
表示传输流  
  
## Public Method Summary

Return Type| Method Name  
---|---  
InputStream| asInputStream()  
从Data.Stream中获取InputStream。当收到STREAM类型的Data时，Nearby Transfer会将输入的流数据连续写入此InputStream中；当没有更多数据可用时（可能是因为发送设备停止了流数据传输），此InputStream将关闭  
ParcelFileDescriptor| asParcelFileDescriptor()  
从Data.Stream中获取ParcelFileDescriptor
