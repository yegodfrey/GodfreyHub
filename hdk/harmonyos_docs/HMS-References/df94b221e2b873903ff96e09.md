public class LocationResponse extends BaseResponse<Location>  
地理位置的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getLocation](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getLocation)方法获取上次的地理位置响应，或调用[getCurrentLocation](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getCurrentLocation)方法获取当前的地理位置响应。  
  
## Public Method Summary

Return type| Method name  
---|---  
Location| getLocation()  
  
## Public Methods

Method  
---  
public Location getLocation()  
获取地理位置，返回设备当前的经/纬度信息。  
  
**Return**

Type| desc  
---|---  
Location| 设备当前的经/纬度位置。
