public static AwarenessBarrier inSunriseOrSunsetPeriod(int timeInstant, long startTimeOffset, long stopTimeOffset)  
日出日落时间围栏，添加此围栏后，在以日出或者日落时间为基准的一段指定时间范围内时围栏状态为TRUE；否则，围栏状态为FALSE。  
使用此围栏需添加android.permission.ACCESS_FINE_LOCATION权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
timeInstant| 日出或日落的标识常量，可选值为：[SUNRISE_CODE ](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#SUNRISE_CODE)[SUNSET_CODE](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-timebarrier#SUNSET_CODE)。  
startTimeOffset| 时间围栏的开始时间偏移量。单位为ms，取值范围是-24小时到24小时范围内的毫秒数，且必须小于stopTimeOffset。  
stopTimeOffset| 时间围栏的结束时间偏移量。单位为ms，取值范围是-24到24小时范围内的毫秒数，且必须大于startTimeOffset。  
  
**Return**

Type| desc  
---|---  
AwarenessBarrier| 情景感知围栏。  
  
**Throws**

Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数异常（传入了未知或无效的timeInstant，startTimeOffset大于或等于stopTimeOffset，startTimeOffset或stopTimeOffset的绝对值大于24小时的毫秒数）。

public static AwarenessBarrier duringPeriodOfDay(TimeZone timeZone, long startTimeOfDay, long stopTimeOfDay)  
指定时间围栏，添加此围栏后，在指定时区的指定时间段内，围栏状态为TRUE；否则，围栏状态为FALSE。  
使用此围栏需添加android.permission.ACCESS_FINE_LOCATION权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
timeZone| 指定时区。如果不存在，则使用用户所在地时区。  
startTimeOfDay| 围栏的开始时间。单位为ms，0点为0，最大值为24小时的毫秒数。  
stopTimeOfDay| 围栏的结束时间。单位为ms，须保证stopTimeOfDay>=startTimeOfDay。  
  
**Return**

Type| desc  
---|---  
AwarenessBarrier| 情景感知围栏。  
  
**Throws**

Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数异常（startTimeOfDay大于stopTimeOfDay，startTimeOfDay、stopTimeOfDay为负或大于24小时的毫秒数）。

public static AwarenessBarrier duringTimePeriod(long startTimeStamp, long stopTimeStamp)  
时间段围栏, 添加此围栏后，在指定时间段内，围栏状态为TRUE；否则，围栏状态为FALSE。  
  
**Parameters**

---|---  
startTimeStamp| 起始时间戳，必须大于或等于0。  
stopTimeStamp| 结束时间戳，必须满足stopTimeStamp>= startTimeStamp。  
  
**Return**

Type| desc  
---|---  
AwarenessBarrier| 情景感知围栏。  
  
**Throws**

Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数异常（startTimeStamp大于stopTimeStamp，startTimeStamp或stopTimeStamp为负）。

**Parameters**

Parameter name| Parameter desc  
---|---

timeZone| 指定时区。如果不存在，则使用用户所在地时区。  
startTimeOfSpecifiedDay| 围栏的开始时间，单位为ms，0点为0，最大值为24小时的毫秒数。  
stopTimeOfSpecifiedDay| 围栏的结束时间，单位为ms，需要保证stopTimeOfSpecifiedDay>= startTimeOfSpecifiedDay。  
  
**Return**

AwarenessBarrier| 情景感知围栏。

Parameter name| Parameter desc
