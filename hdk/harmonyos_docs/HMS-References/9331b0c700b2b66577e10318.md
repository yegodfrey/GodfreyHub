public interface OpenDeviceIdentifierService extends android.os.Iinterface  
获取OAID和“限制个性化广告”的AIDL服务接口。  
  
## Public Method Summary

Return type| Method name  
---|---  
String| getOaid()获取当前的OAID。  
  
boolean| isOaidTrackLimited()获取当前“限制个性化广告”的设置。  
  
  
## Public Methods

Method  
---  
public String getOaid()  
获取当前的OAID。  
  
**Return**

Return type| desc  
---|---  
String| 返回OAID。返回格式样例：fcffd123-372b-d965-daff-77726234f5ec  
Method  
---  
public boolean isOaidTrackLimited()  
获取当前“限制个性化广告”的设置。  
  
**Return**

Return type| desc  
---|---  
boolean| true：限制个性化广告。false：不限制个性化广告。
