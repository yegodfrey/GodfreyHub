public interface BluetoothStatus  
车载蓝牙状态接口类，其中定义了3个车载蓝牙状态的常量，即表示车载蓝牙已连接CONNECTED、表示车载蓝牙未连接DISCONNECTED和未识别到车载蓝牙状态UNKNOWN。  
  
## Constant Value Summary

Constant name| desc  
---|---  
CONNECTED| int CONNECTED = 1；  
表示车载蓝牙已连接。  
DISCONNECTED| int DISCONNECTED = 0；  
表示车载蓝牙未连接。  
UNKNOWN| int UNKNOWN = -1；  
表示未识别到车载蓝牙状态。
