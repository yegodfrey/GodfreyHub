**public class HuaweiMap**  
  
HuaweiMap是适用于Huawei Map SDK的主要功能入口类，与地图有关的所有方法从此处接入，开发者不能直接对象化HuaweiMap类，需要通[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)或者[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)中的getMapAsync()方法来获取它的对象。

## Public Fields

Name| Type| Description  
---|---|---  
MAP_TYPE_NONE| public static final int| 空地图。  
MAP_TYPE_NORMAL| public static final int| 标准地图。  
MAP_TYPE_HYBRID| public static final int| 带有主要街道透明层的卫星地图（华为地图SDK暂不支持）。  
MAP_TYPE_SATELLITE| public static final int| 没有标记的卫星地图（华为地图SDK暂不支持）。  
MAP_TYPE_TERRAIN| public static final int| 地形图（华为地图SDK暂不支持）。
