public MLRemoteAftSetting.Factory setLanguageCode(String languageCode)  
设置语言编码。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
languageCode| 语言编码，由用户指定，当前支持中文普通话(zh)、英文（en-US），使用BCP-47规范。 如果不指定，默认为中文普通话。  
  
**Return**  


Type| desc  
---|---  
MLRemoteAftSetting.Factory| 返回云侧语音转写配置工厂的实例。
