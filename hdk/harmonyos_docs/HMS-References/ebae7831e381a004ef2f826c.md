# SamplePoint  
  
**CLASS info**  
---  
public class SamplePoint implements Parcelable  
采样点类，是特定数据采集器在某时刻（或一段时间）采集到的特定数据类型的样本。保存了该时刻（或时间范围内）数据类型各维度的值，以及采样的起止时间。 采样点的采样方式根据数据类型的定义，分为瞬时采样和区间采样两种， 在设置采样点时间时，建议瞬时数据使用 setSamplingTime() 接口，区间数据使用setTimeInterval()接口（必须是一个有效时间段）。 另外， 瞬时数据也可以使用 setTimeInterval() 接口设置时间，但传入的开始时间和结束时间必须相同，否则无法创建成功； 区间数据在初次创建时不支持使用 setSamplingTime()，否则无法创建成功；但该接口可以用来更新已创建的区间采样点的结束时间，调用后仅会更新结束时间。
