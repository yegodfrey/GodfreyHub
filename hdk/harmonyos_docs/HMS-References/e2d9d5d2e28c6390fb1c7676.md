# 1\. signIn

## 1.1 接口定义

void signIn(boolean forceLogin, SignInHandler handler);

## 1.2 接口描述

登录华为帐号，并获取帐号相关信息：昵称、openid、头像地址等。

## 1.3 请求参数

参数名| 参数类型| 是否必填| 说明  
---|---|---|---  
forceLogin| boolean| 是| 是否强制登录。●  True：如果华为帐号未登录会拉起登录界面，如果未授权会拉起授权界面●  False：如果已经登录授权直接返回帐号信息，否则返回失败错误码  
handler| SignInHandler| 是| 登录结果通过此实例回调给调用方。  
  
## 1.4 结果回调
    
    
    复制
      
        1. public interface SignInHandler {
        2.     /**
        3.     * 登录结果回调
        4.     * @param rtnCode 结果码
        5.      * @param hwidInfo 登录结果
        6.      */
        7.      void onResult(int rtnCode, SignInHuaweiId hwidInfo);      
        8. }
    
    

回调参数包括retCode和hwidInfo，retCode是登录结果的错误码，融合了各个阶段的错误码，如果只需要判断错误码可直接使用。retCode取值和意义如表4-1所示。

**表****4-2 SignInHuaweiId****说明**

参数名| 获取方式| 意义  
---|---|---  
openId| getOpenId()| 应用内用户的唯一标识。  
disPlayName| getDisplayName()| 返回用户昵称，用于在开发者的应用中显示。

# 2\. signOut  


## 2.1 接口定义

void signOut(SignInHandler handler);

## 2.2 接口描述  


该接口不用于取消授权，注销华为帐号授权后，再次登录会出现短暂的授权界面，影响用户体验，所以建议除以下情况，请不要调用此接口。

当signIn获取的accessToken在访问网关时返回失效，重新获取的accessToken访问仍然失效时，可调用此接口清除HMS APK的缓存，然后再次调用signIn获取新的accesstoken。

## 2.3 请求参数

参数名| 参数类型| 是否必填| 说明  
---|---|---|---  
handler| SignOutHandler| 是| signOut结果通过此实例回调给调用方。  
  
## 2.4 结果回调  

    
    
    复制

        6.      */

回调参数包括retCode和signOutResult，retCode是signOut结果的错误码，融合了各个阶段的错误码，如果只需要判断错误码可直接使用。retCode取值和意义如表4-1所示。

**表4-1 retCode说明**

---|---|---|---|---  
通用错误码| 参见“通用错误码”。  
业务错误码| AuthCode.StatusCode.OK| 0| 成功|   
  
  
signOutResult是SignOutResult的实例，包含了登出结果信息。signOutResult各字段意义如表4-2所示。

**表****4-2 signOutResult****说明**
