**com.huawei.hms.analytics.type.HAEventType**

此接口提供了所有预定义事件的事件ID常量。

Constant Field| Value  
---|---  
String CREATEPAYMENTINFO| 结算过程中，用户已经添加付款信息，但尚未发起支付时，上报此事件。此事件可以与STARTCHECKOUT、COMPLETEPURCHASE组合适用，构建结算过程的漏斗分析。  
String ADDPRODUCT2CART| 用户添加商品到购物车时，上报此事件。此事件可以与VIEWPRODUCT、STARTCHECKOUT组合使用，构建商品购买的漏斗分析；也可用于分析用户对开发者的哪些商品感兴趣，进而对这些用户进行营销。  
String ADDPRODUCT2WISHLIST| 用户添加商品到收藏夹时，上报此事件。可用于分析用户对开发者的哪些商品感兴趣，进而对这些用户进行营销。  
String STARTAPP| 用户打开应用时，上报此事件。  
String STARTCHECKOUT| 用户下单后，点击结算按钮时，触发此事件。可以与VIEWPRODUCT、COMPLETEPURCHASE等事件结合使用，用于分析电商购买漏斗转化情况。  
String VIEWCAMPAIGN| 用户参考一个营销活动的内容时，触发此事件。可以用于分析评价营销活动的转化情况。  
String VIEWCHECKOUTSTEP| 用户查看结算过程各个步骤时，上报此事件。  
String WINVIRTUALCOIN| 用户获取到虚拟货币时，上报此事件。可以用于分析用户获取虚拟币的难易程度，优化产品设计。  
String COMPLETEPURCHASE| 用户购买商品后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。  
String OBTAINLEADS| 获取到销售线索时，上报此事件。如开发者投放了广告，获取用户的联系方式，用户点击投放广告，填写并提交了联系方式时，可以上报该事件，以评估本次获取到的线索可能会给开发者带来的收入。可以用于评估投放广告的ROI。  
String JOINUSERGROUP| 用户加入群组时，上报此事件。如社交类App，用户加入群聊。可以用于评价产品的社交特性对用户的吸引力。  
String COMPLETELEVEL| 游戏类应用，用户完成某个关卡，上报此事件。可以与STARTLEVEL结合使用，分析游戏关卡设计是否合理，有针对性地制定优化策略。  
String STARTLEVEL| 游戏类应用，用户进入某个关卡，开始游戏时，上报此事件。可以与COMPLETELEVEL结合使用，分析游戏关卡设计是否合理，有针对性地制定优化策略。  
String UPGRADELEVEL| 游戏应用中用户升级时，上报此事件。分析产品的用户等级设置是否合理，有针对性地制定优化策略。  
String SIGNIN| 有登录功能的应用，用户登录时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。  
String SIGNOUT| 用户退出时，上报此事件。  
String SUBMITSCORE| 游戏/教育类应用中，用户提交分数时，上报此事件。用于分析产品内容的难易程度，有针对性的制定优化策略。  
String CREATEORDER| 用户创建订单时，上报此事件。  
String REFUNDORDER| 用户退款成功后，上报此事件。可以分析退款造成的损失，有针对性的制定优化策略。  
String DELPRODUCTFROMCART| 用户将商品从购物车中移除时，上报此事件。可以对相关用户进行营销。  
String SEARCH| 用户在应用内搜索内容时，上报此事件。可以与VIEWSEARCHRESULT、VIEWPRODUCT等事件结合使用，分析搜索结果的准确性。  
String VIEWCONTENT| 用户点击内容时，上报此事件。如在电商应用内，点击列表中的某个商品以参考详情。可以分析用户对哪些商品感兴趣。  
String UPDATECHECKOUTOPTION| 结算过程中，用户填写一些结算选项时，上报此事件。可以分析用户的结算偏好。  
String SHARECONTENT| 用户通过社交渠道分享商品或内容时，上报此事件。可以分析用户对产品的忠诚度。  
String REGISTERACCOUNT| 用户注册账号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。  
String CONSUMEVIRTUALCOIN| 用户消费虚拟币时，上报此事件。可以用于分析用户对哪些产品更感兴趣。  
String STARTTUTORIAL| 用户开始使用引导教程时，上报此事件。可以与COMPLETETUTORIAL结合使用，评价引导教程的质量，有针对性的制定优化措施。  
String COMPLETETUTORIAL| 用户完成引导教程时，上报此事件。可以与STARTTUTORIAL结合使用，评价引导教程的质量，有针对性的制定优化措施。  
String OBTAINACHIEVEMENT| 用户达成某项新成就时，上报此事件。可以衡量成就等级设计是否合理，并有针对性的制定优化策略。  
String VIEWPRODUCT| 用户浏览商品时，上报此事件。可以分析用户对哪些商品感兴趣，也可用和其他事件组合完成漏斗分析。  
String VIEWPRODUCTLIST| 浏览商品列表时，上报此事件。如用户按分类查看商品列表时。可以分析用户对哪些类型的内容更感兴趣。  
String VIEWSEARCHRESULT| 用户查看搜索结果时，上报此事件。与VIEWPRODUCT、SEARCH组合使用，衡量搜索算法的准确性。  
String UPDATEMEMBERSHIPLEVEL| 用户购买会员或者会员失效后首次登录时，上报此事件，用于分析会员用户行为习惯等。  
String FILTRATEPRODUCT| 用户选择一定条件筛选查看上报的范围时，上报此事件。可用于分析用户的喜好。  
String VIEWCATEGORY| 用户点击商品分类时，上报此事件。可用于分析热门类别商品或者分析的喜好。  
String UPDATEORDER| 用户修改订单时，上报此事件。  
String CANCELORDER| 用户取消订单时，上报此事件。  
String COMPLETEORDER| 用户确认收货后，上报此事件。  
String CANCELCHECKOUT| 用户已经下单，并开始支付，支付过程中，取消支付时，上报此事件。可用于分析用户流失原因。  
String OBTAINVOUCHER| 用户领取优惠券时，上报此事件。  
String CONTACTCUSTOMSERVICE| 用户联系客服咨询商品详情、投诉等场景下，上报此事件。  
String RATE| 用户平均App、服务、商品时，上报此事件。  
String INVITE| 用户通过社交渠道邀请其他用户使用App时，上报此事件。  
  
  


**com.huawei.hms.analytics.type.HAParamType**

此接口提供了所有预定义参数的参数ID，包括预定义参数的ID常量和预定义用户属性的ID常量。

Constant Field| Value  
---|---  
String ACHIEVEMENTID| 标识成就ID。  
String STORENAME| 发生此交易的商店或所属机构。  
String ROLENAME| 标识用户的角色。  
String OPTION| 当前结算步骤中用户填写的结算选项。  
String STEP| 标识用户当前处于结算过程中的第几个步骤。  
String CONTENTTYPE| 标识用户选择的内容类型。  
String VOUCHER| 用户在本次交易中使用的优惠券。  
String CURRNAME| 标识收入的货币类型,与$Revenue一起使用。  
String DESTINATION| 航班或旅行等的目的地。  
String ENDDATE| 项目的到达日期，结账日期或租赁结束日期。  
String FLIGHTNO| 开发者交易系统生成的航班号。  
String USERGROUPID| 用户加入的用户群组ID。  
String POSITIONID| 列表中项目的索引。  
String BRAND| 商品品牌。  
String CATEGORY| 商品类别。  
String PRODUCTID| 商品ID。  
String PRODUCTLIST| 呈现给用户的商品列表。  
String PRODUCTNAME| 商品名称。  
String PRODUCTFEATURE| 商品特征。  
String LEVELID| 游戏等级。  
String LEVELNAME| 游戏中关卡的名称。  
String PLACE| 商品所在地标识。  
String CHANNEL| 标识用户通过哪种渠道登录。  
String BOOKINGDAYS| 针对预定酒店场景，标识用户入住天数。  
String PASSENGERSNUMBER| 针对预定酒店场景，标识入住旅客人数。  
String BOOKINGROOMS| 针对预定酒店场景，标识用户预定房间数。  
String ORIGINATINGPLACE| 出发地。  
String PRICE| 购买价格。  
String QUANTITY| 购买数量。  
String SCORE| 在游戏中得分。  
String SEARCHKEYWORDS| 使用的搜索字符串/关键字。  
String SHIPPING| 本次交易产生的运输费。  
String BEGINDATE| 出发日期，入住日期或租赁开始日期。  
String RESULT| 操作的结果。  
String TAXFEE| 本次交易产生的税费。  
String KEYWORDS| 营销活动的关键词。如：搜索广告的关键词。  
String TRANSACTIONID| 电子商务事务ID。  
String CLASS| 针对预定酒店场景，标识用户预定房间等级。  
String REVENUE| 为每种事件类型自动累积的特定于上下文的数值。  
String VIRTUALCURRNAME| 虚拟货币类型的名称。  
String CLICKID| 广告网络生成的用于标记广告点击的参数。  
String PROMOTIONNAME| 营销活动的名称。  
String CONTENT| 营销活动的营销内容。  
String EXTENDPARAM| 自定义参数。  
String MATERIALNAME| 营销活动使用的创意素材名称。  
String MATERIALSLOT| 创意素材被展示的位置信息。  
String PLACEID| 商品所在地标识。  
String MEDIUM| 营销活动的类型，如：CPC、Email等。  
String SOURCE| 营销活动提供者的标识，如Huawei PPS等。  
String ACOUNTTYPE| 用户账号类型，如：邮箱、手机号、微信等。  
String REGISTMETHOD| 用户来源。  
String OCCURREDTIME| 用户注册账号的时间。  
String EVTRESULT| 登录结果。  
String PREVLEVEL| 变更前级别。  
String CURRVLEVEL| 当前级别。  
String REASON| 变更原因。  
String VOUCHERS| 商品使用的优惠券名称列表。  
String MATERIALSLOTTYPE| 展示位置类型。  
String LISTID| 商品列表ID。  
String FILTERS| 过滤条件。  
String SORTS| 排序条件。  
String ORDERID| 开发者交易系统生成的订单ID。  
String PAYTYPE| 用户选择的支付方式。  
String EXPIREDATE| 优惠券过期时间。  
String VOUCHERTYPE| 优惠券类型。  
String SERVICETYPE| 为用户提供服务的类型，如：咨询、投诉等。  
String DETAILS| 用户对主体的详细评价说明。  
String COMMENTTYPE| 标识评价的主体。
