public class RelatedPassInfo extends WalletParcelable  
相关联的优惠劵提供可查询的信息，在会员卡详情页展示具体的数量，点击数量，跳转到具体的优惠券详情。通过该优惠券的PassTypeIdentifier与organizationPassId可以查询到具体的优惠券。
