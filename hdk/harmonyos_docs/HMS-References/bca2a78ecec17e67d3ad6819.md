com.huawei.hms.mlsdk.text.MLText.Base  
文本信息的父类，表示图像检测出的基本文本信息。  
包含5个属性：  
1、检测出的文本内容  
2、文本的边框  
3、文本边框的顶点  
4、检测结果的置信度  
5、检测到的所有语种

public List<? extends MLText.Base> getContents()  
获取当前文本对象包含的低一级的文本对象，当前方法需要在子类中重写。文本对象分为文本区块（Block）、文本行（TextLine）、文本元素（Word）。文本区块（Block）是最高级的文本对象，可包含多个低一级的文本行（TextLine）对象；文本行对象可包含多个最低级的文本元素（Word）对象；文本元素（Word）对象是一组字符组成的词。如果当前文本对象为最低级文本对象（Word）则返回空。  
  
**Return**

Type| desc  
---|---  
List<? extends MLText.Base>| 返回当前文本对象包含的低一级的文本对象，  
例如：如果当前对象是文本行(TextLine),则返回文本元素(Word)集合。

public String getLanguage()  
获取文本中出现次数最多的语种。  
  
**Return**

Type| desc  
---|---  
String| 返回语种，语种使用语言代码表示，可能返回的语种有：  
“en”（英），“zh”（中），“ja”（日），  
“ko”（韩），“ru”（俄），“de”（德），  
“fr”（法），“it”（意大利），“pt”（葡萄牙），  
“es”（西班牙），“rm”（拉丁语系语言）；  
云侧接口还支持语种：  
“pl”（波兰），“no”（挪威），“sv”（瑞典），  
“da”（丹麦），“tr”（土耳其），“fi”（芬兰），  
“th”（泰语），“ar”（阿拉伯语），“hi”（印地语）。
