public MLFaceAnalyzerSetting.Factory setPerformanceType(int performanceType)  
设置分析器的偏好模式。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
performanceType| 分析器的偏好模式。  
TYPE_PRECISION：值为1，精度偏好模式，与速度偏好模式相比，检测到的人脸更多，关键点和轮廓信息  
更加准确，但是检测速度较慢；  
TYPE_SPEED：值为2，速度偏好模式，与精度偏好模式相比，检测到的人脸关键点和轮廓信息准确度较低，  
但是检测速度更快。  
  
  
**Return**  


Type| desc  
---|---  
MLFaceAnalyzerSetting.Factory| 返回MLFaceAnalyzerSetting.Factory的实例。
