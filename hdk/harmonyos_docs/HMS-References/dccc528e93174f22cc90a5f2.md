class info  
---  
com.huawei.hms.mlsdk.document.MLDocument.Interval  
用于表示文本间隔，包含3种类型：  
1、空格；  
2、换行符；  
3、未知类型间隔。

## Public Methods

Method  
---  
public int getIntervalType()  
获取检测出的文本间隔类型。  
  
**Return**

Type| desc  
---|---  
int| 返回文本间隔类型，包括：  
SPACE（空格）；  
NEW_LINE_CHARACTER（换行符）；  
OTHER（未知）。  
  
public boolean isTextFollowed()

判断文本间隔后是否还有文本。

**Return**

Type| desc  
---|---  
boolean| true：表示文本间隔后还有文本；false：表示文本间隔后没有文本。
