提供图像分类SDK，包含机器学习图像分类服务类和接口。

## Classes

Class name| Class description  
---|---  
[MLImageClassification](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLImageClassification-4)| 表示由图像分类器（MLImageClassificationAnalyzer）识别出的图像类别。  
包含三种属性：  
1、类别唯一id；  
2、类别名称；  
3、类别的置信度。  
[MLImageClassificationAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLImageClassificationAnalyzer-4)| 图像分类器：用于在提供的图像中查找图像类别。（MLImageClassification）  
[MLImageClassificationAnalyzer.ImageClassificationType](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLImageClassificationAnalyzerImageClassificationType-4)| 图像分类器类型的抽象接口，实现注解。  
[MLLocalClassificationAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLLocalClassificationAnalyzerSetting-4)| 图像分类配置器：用于设置设备端图像分类器的属性。  
[MLLocalClassificationAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLLocalClassificationAnalyzerSettingFactory-4)| 创建设备端图像分类配置器的实例。  
[MLRemoteClassificationAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteClassificationAnalyzerSetting-4)| 图像分类配置器：用于设置云端图像分类器的属性。  
[MLRemoteClassificationAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/MLRemoteClassificationAnalyzerSettingFactory-4)| 创建云端图像分类配置器的实例。
