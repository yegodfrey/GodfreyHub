## Classes

Class name| Class description  
---|---  
[HuaweiIdAuthButton](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-huaweiIdAuthButton)| 华为登录按钮对用户进行身份验证。注意此类只处理按钮的视觉方面。为了触发一个动作，请使用setOnClickListener(OnClickListener)注册一个监听器。注意，必须显式调用setOnClickListener(OnClickListener) 。不要通过XML注册一个侦听器，否则会收不到回调。
