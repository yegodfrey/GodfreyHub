# **定义**

state| String| Optional| Status of the pass. Values:**active** ,**inactive** ,**completed** , and**expired**.**active** is the default value.  
---|---|---|---  
state| String  
| 可选| 状态值，取值如下:active：生效  
inactive：未激活  
completed：已使用  
expired：已过期  
effectTime| String| 可选| UTC格式，生效时间  
expireTime| String| 可选| UTC格式，失效时间，如果超过此事件，卡券自动按照 expired 状态处理  
  
备注：如果没有填写 state 参数，卡券状态默认为 active。effectTime 和 expireTime 需同时填写或同时不填写。添加时如果填写了 state 和 expireTime，state 不可以为已过期，expireTime 必须大于当前时间，expireTime 必须大于 effectTime。
