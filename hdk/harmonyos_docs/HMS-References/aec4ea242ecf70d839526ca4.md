# **接口功能**

Beacon有激活、去激活、停用三种状态，分别调用这三个接口，可以设置Beacon的相关状态。

# **调用场景**

  * 调用者调用Beacon激活接口，将处于去激活状态的Beacon设备激活；

  * 调用者调用Beacon去激活接口，将处于激活状态的Beacon设备去激活；

  * 调用者调用Beacon停用接口，将处于激活或者去激活状态的Beacon设备停用，Beacon停用后，将不可再调用激活或者去激活接口修改Beacon状态。




# **接口原型**

**承载协议**|  HTTPS POST  
---|---  
**接口方向**|  应用服务器或APP应用->近距离通信服务器  
**接口URL**|  https://{域名}/WiseCloudNearbyBeaconService/v1/activeBeacon?projectId=[projectId]https://{域名}/WiseCloudNearbyBeaconService/v1/deactiveBeacon?projectId=[projectId]https://{域名}/WiseCloudNearbyBeaconService/v1/abandonBeacon?projectId=[projectId]  
**数据格式**|  Content-type: application/json  
  
# **接口约束**

  * 需要获取服务账号凭证；

  * 调用这三个接口需要保证Beacon设备是非停用状态。




# **请求参数**

**参数名称**| **必选(M)/可选(O)**| **类型**| **参数说明**  
---|---|---|---  
timeStamp| M| Long| 请求头参数，时间戳。  
srcTranID| M| String| 请求头参数，事务ID，最长为24个字符。  
projectId| O| String| 查询参数。  
Authorization| M| String| 请求头参数，用于网关认证，请参考[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-common-service-account)获取JWT。  
beaconId| M| String| 请求体参数。最长为64个字符。  
  
# **返回参数**

请求成功，状态码200，无响应体。

请求失败，状态码非200，响应体如下：

（1）非业务（网关校验失败，token过期等情况）请求失败时：

**参数名称**| **类型**| **参数含义**  
---|---|---  
error| String| 非业务返回的错误信息。  
  
（2）业务请求失败时：

**参数名称**| **类型**| **参数说明**  
---|---|---  
serviceError| object| 业务返回的错误信息。  
  
serviceError的JSON结构体为：

**参数名称**| **类型**| **参数含义**  
---|---|---  
code| int| 错误码，错误码描述见返回码。  
status| String| 错误状态。  
message| String| 错误描述信息。  
  
# **返回码**

**错误码**| **错误码含义**| **建议业务处理方式**  
---|---|---  
400000001| 请求头参数不对。| 检查请求头参数。  
400000002| 请求体参数不对。| 检查请求体参数。  
404000006| 当前Beacon不存在。| 检查请求参数。  
403000008| 当前Beacon已停用。| 处于停用状态的Beacon只能删除，不能进行其他操作。  
403000003| 服务账号不可用。| 切换成可用的服务账号操作。  
403000004| 没有权限操作此Beacon。| 检查当前Beacon所有者。  
500000001| 内部服务错误。| 建议重试，重试仍失败则反馈该问题。
