#### setUserId

Method  
---  
public void setUserId(String id)设置用户ID。调用setUserId()接口时，如果旧userId不为空字符串且和新userId不同，会重新生成新的session会话。若您不希望使用setUserId标识用户（如用户退出时），必须将userID设为null。id：用于应用标识用户的ID，在分析的服务侧通过此标识进行关联用户数据。使用userID需要遵守相关隐私规范，请在您应用的隐私声明中进行声明。  
  
**Parameters**

Name| Description  
---|---  
id| 用户id，非空，长度不超过256字符。  
  
#### setUserProfile

Method  
---  
public void setUserProfile(String name, String value)设置用户属性。用户属性值将在整个应用程序生命周期和会话期间保持不变。最多支持25个用户属性名称，如果后面设置属性有重复的name，则刷新。  
  
**Parameters**

Name| Description  
---|---  
name| 用户属性的标识符。非空，由数字、字母、下划线组成，不能以数字、下划线开头，长度不超过256字符。  
value| 属性值。非空，长度不超过256字符。

public void setMinActivitySessions(long milliseconds)设置重新开始新Session的最短时间间隔。此方法设置的时间间隔，用于指定App在后台运行多长后，再次切回前台时，需要生成新的会话。默认30秒。  
  
**Parameters**

#### setSessionDuration

Method

public void setSessionDuration(long milliseconds)设置Session超时时长。App一直在前台运行，当两个相邻事件的时间间隔超过此方法设置的阈值时，将生成一个新的会话。默认30分钟。  
  
**Parameters**

Name| Description  
---|---  
milliseconds| Session超时时长。单位：毫秒。  
  
#### setCurrentActivity

Method  
---  
public void setCurrentActivity(Activity activity, String activityName, String activityClassOverride)

  * 该接口已废弃。请使用pageStart()和pageEnd()接口，支持非Activity页面完整的进入和退出事件采集。
  * Analytics Kit会自动采集$EnterScreen和$ExitScreen事件中的$CurActivityName 参数即为当前页面的名称。若您需要覆盖自动采集的$EnterScreen和$ExitScreen事件，您可在Activity的onResume中调用此方法，并指定页面名称（activityName,必须）和类名（activityClassOverride，可选，若为null或空，Analytics Kit将根据传入的activity获取类名）。
  * 您也可以调用该接口记录非Activity的页面事件(如Fragment, 自定义View等)，并指定相关页面名称（activityName，必须）。

  
  
**Parameters**

Name| Description  
---|---  
activity| 当前活动Activity。  
activityName| 当前活动页面名称，必须；非空，长度不超过256字符。  
screenClassOverride| 页面类名，可选，若设置为null或空，则会使用当前活动Activity的类名；长度不超过256字符。

#### pageStart

Method  
---  
public void pageStart(String pageName, String pageClassOverride)自定义页面开始事件，只在非Activity的页面调用，Activity页面无需调用，Activity页面会自动采集。如果在Activity页面调用，会导致页面进出事件统计不准确。需要在调用本方法后调用pageEnd方法配对使用。  
  
**Parameters**

Name| Description  
---|---  
pageName| 当前页面名称，长度不超过256字符，不可为空。  
pageClassOverride| 当前页面类名，长度不超过256字符，不可为空。  
  
#### pageEnd

Method  
---  
public void pageEnd(String pageName)自定义页面结束事件，只在非Activity的页面调用，Activity页面无需调用，Activity页面会自动采集。如果在Activity页面调用，会导致页面进出事件统计不准确。需要在调用本方法前先调用pageStart方法配对使用。  
  
**Parameters**

Name| Description  
---|---  
pageName| 当前结束的页面名称，长度不超过256字符，不可为空，需要和对应pageStart内传入的pageName相同。
