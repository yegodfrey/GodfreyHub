# ActivityRecord  
  
**CLASS info**  
---  
public class ActivityRecord implements SafeParcelable  
活动记录类，记录用户一次活动的基本信息。例如一次户外跑步活动，记录跑步的开始时间、结束时间，活动记录的名称、标识符、描述信息、对应的活动类型（参考[HiHealthActivities](https://developer.huawei.com/consumer/cn/doc/HMS-References/hihealthactivities-0000001050089540)）、活动持续时间等。
