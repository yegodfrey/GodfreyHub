情景感知服务的入口包，包括Awareness、BarrierClient、CaptureClient等几个主要的类，主要的API都定义在其中。  
  
## Interfaces

Interface name| Interface description  
---|---  
[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)| 情景感知快照API的主要入口，能够通过该接口获取耳机状态、活动状态、时间状态、地理位置、信标状态、光照度、天气状态、车载蓝牙状态和各能力支持状态的响应。  
[BarrierClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-barrierclient)| 客户端向服务端注册以及查询情景感知围栏的入口。  
  
## Classes

Class name| Class description  
---|---  
[Awareness](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awarenes-awareness)| 情景感知服务的主要入口。
