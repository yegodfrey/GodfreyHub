public class Data implements Parcelable  
数据载荷类，载荷以一个特定的类型发送，同时接收方需要同样以该类型接收

@interface| [Data.Type](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-transfer-data-type)| 负载类型
