class info

com.huawei.hms.mlsdk.common.MLApplication  
APP信息类，用于存储集成了MLKit SDK的APP基本信息，通常情况下，应用开发者不与这个类直接交互，MLKit SDK会结合开发者申请的agconnect-services.json，完成MLKit的初始化，不需要开发者编写额外的代码。
