该类是Analytics SDK 预置事件ID列表及事件参数列表，代码埋点时,可直接调用预置事件及事件参数。

## 

#### **Class Summary**

Class| Description  
---|---  
[HAEventType](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/android_api_constant_values#HAEventType)| 此接口提供了所有预定义事件的事件ID常量。  
[HAParamType](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/android_api_constant_values#HAParamType)| 此接口提供了所有预定义参数的参数ID，包括预定义参数的ID常量和预定义用户属性的ID常量。
