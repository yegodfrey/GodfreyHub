# SampleSet  
  
**CLASS info**  
---  
public class SampleSet implements Parcelable  
采样集合类，是存放采样点的容器。其存放的采样点必须来自相同的数据采集器（但允许它们的原始数据采集器不相同），通常用于批量插入或读取采样数据。
