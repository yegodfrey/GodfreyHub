public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier) enter(double latitude, double longitude, double radius)  
区域进入围栏，添加此围栏后，当用户进入指定区域时，此围栏状态为TRUE并触发围栏事件上报，5s后状态切换为FALSE。  
使用此围栏需添加android.permission.ACCESS_FINE_LOCATION权限。对于Android 10及以后的版本还需要添加android.permission.ACCESS_BACKGROUND_LOCATION权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
latitude| 指定区域的中心纬度，单位为度，范围[-90°,90°]。  
longitude| 指定区域的中心经度，单位为度，范围(-180°,180°]。  
radius| 指定区域半径，单位为m。  
  
  
**Return**  


Type| desc  
---|---  
[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)| 情景感知围栏。  
  
  
**Throws**  


Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（当latitude/longitude超出指定范围，radius或timeOfDuration为负）异常。

public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier) stay(double latitude, double longitude, double radius, long timeOfDuration)  
区域驻留围栏，添加此围栏后，若此时用户处于圈内，则围栏状态为TRUE；若此时用户处于圈外，进入圈内且驻留超过指定时间，此围栏状态为TRUE并触发围栏事件上报。  
使用此围栏需添加android.permission.ACCESS_FINE_LOCATION权限。对于Android 10及以后的版本还需要添加android.permission.ACCESS_BACKGROUND_LOCATION权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
latitude| 指定区域的中心纬度，单位为度，范围[-90°,90°]。  
longitude| 指定区域的中心经度，单位为度，范围(-180°,180°]。  
radius| 指定区域半径，单位为m。  
timeOfDuration| 在指定区域内最小驻留时间，单位为ms。  
  
  
**Return**  


Type| desc  
---|---  
[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/awareness-barrier-awarenessbarrier)| 情景感知围栏。  
  
  
**Throws**  


Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（当latitude/longitude超出指定范围，radius或timeOfDuration为负）异常。
