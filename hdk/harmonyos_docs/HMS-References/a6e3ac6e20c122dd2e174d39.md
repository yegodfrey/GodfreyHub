public static FusedLocationProviderClient getFusedLocationProviderClient(Activity activity)  
创建一个新的[FusedLocationProviderClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/fusedlocationproviderclient "fusedlocationproviderclient")实例，用于在Activity中使用。注意：当传入参数为非Activity类型时，如果使用FusedLocationProviderClient实例调用定位服务接口发生异常，就不会弹出UI交互界面提示用户处理，只会返回错误码。例如：当HMS不符合定位服务的版本要求时，便会返回错误码907135003，此时需要手动升级HMSCore。如果需要拉起升级引导界面，建议传入Activity类型参数替代Context类型，创建Client实例。

public static SettingsClient getSettingsClient (Activity activity)  
创建一个新的[SettingsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/settingsclient "settingsclient")实例，用于在Activity中使用。注意：当传入参数为Activity类型时，如果使用SettingsClient 实例调用定位服务接口发生异常，那么应用就会弹出UI交互界面提示用户处理。例如：当HMS Core不符合定位服务的版本要求时，就会拉起升级提示界面，引导用户升级。
