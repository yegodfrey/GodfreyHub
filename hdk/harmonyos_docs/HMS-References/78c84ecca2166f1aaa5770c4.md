CLASS info  
---  
public abstract class BioAuthnCallback extends java.lang.Object  
提供给BioAuthn指纹认证或面容认证的结果回调。需要由开发者完成具体实现。  
  
## Public Constructor Summary

Method name  
---  
**BioAuthnCallback**()构造一个提供给BioAuthn指纹认证或面容认证的回调结构。  
  
## Public Method Summary

Return type| Method name  
---|---  
void| **onAuthError**(int errorCode, java.lang.CharSequence errString)在BioAuthn指纹认证或面容认证过程中遇到不可恢复的错误且操作完成时回调方法，可以表明本次认证失败。不会执行进一步操作。  
void| **onAuthHelp**(int helpCode, java.lang.CharSequence helpString)在BioAuthn指纹认证或面容认证过程中提示信息回调方法，返回识别过程中提示信息。  
void| **onAuthSucceeded**(BioAuthnResult result)指纹认证或面容认证成功时的回调方法，可以表明本次认证成功。  
void| **onAuthFailed**()指纹认证或面容认证失败时的回调方法，可以表明本次认证失败。
