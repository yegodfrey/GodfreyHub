public int getPriceType()

**Return**

type| desc  
---|---  
int| 商品类型。

  * 0: 消耗型商品
  * 1: 非消耗型商品
  * 2: 自动续费订阅商品

  
Method  
---  
public String getPrice()  
获取商品的展示价格。  
  
**Return**

type| desc  
---|---  
String| 商品的展示价格，包含商品货币符号和实际价格，格式为“货币符号 商品价格”，例如“￥0.15”。此价格含税。说明：当查询为非订阅型商品时，若存在促销活动，该方法将返回商品的促销价格。当查询为订阅型商品时，该方法将返回商品的原价。  
Method

public long getMicrosPrice()  
获取商品微单位价格。  
  
**Return**

type| desc  
---|---  
long| 商品实际价格乘以1,000,000后的微单位价格。例如某个商品实际价格是1.99美元，则该商品对应的微单位价格为：1.99*1000000=1990000。

public int getStatus()  
获取商品的状态。  
  
**Return**

type| desc  
---|---  
int| 商品状态。

  * 0：表示有效。
  * 1：表示取消，即删除。此状态的商品不可续订，也不可订阅。
  * 3：表示下线，不能订阅，但老用户仍可续订。

说明：查询非订阅商品时无需关注此字段。
