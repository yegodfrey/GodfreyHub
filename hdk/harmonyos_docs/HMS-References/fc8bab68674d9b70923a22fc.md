RankingVariant类主要用于返回当前玩家在排行榜中特定时间维度的分数信息，在调用[Ranking](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ranking)类的getRankingVariants方法时会返回该类型的实例。  
  
# Constant Summary

type| name| description  
---|---|---  
static final int| NUM_SCORES_UNKNOWN| 排行榜总分数未知。  
static final int| PLAYER_RANK_UNKNOWN| 玩家在排行榜名次未知。  
static final int| PLAYER_SCORE_UNKNOWN| 玩家分数未知。  
static final int| NUM_TIME_DIMENSION| 排行榜时间维度的个数。  
static final int| TIME_DIMENSION_DAILY| 日排行。  
static final int| TIME_DIMENSION_WEEKLY| 周排行。  
static final int| TIME_DIMENSION_ALL_TIME| 总排行。  
  
# Public Method Summary

Return| Method  
---|---  
abstract String| getDisplayRanking()获取用于展示的玩家名次对应的本地化数字，仅当hasPlayerInfo()为true时才返回。  
abstract String| getPlayerDisplayScore()获取用于展示的玩家分数对应的本地化数字，仅当hasPlayerInfo()为true时才返回。  
abstract long| getRankTotalScoreNum()获取排行榜的总分数。  
abstract long| getPlayerRank()获取玩家在该排行榜的名次，仅当hasPlayerInfo()为true时才返回。  
abstract String| getPlayerScoreTips()获取玩家分数的自定义单位，仅当当hasPlayerInfo()为true且存在自定义单位时才返回。  
abstract long| getPlayerRawScore()获取玩家分数的原始分值，仅当hasPlayerInfo()为true时才返回。  
abstract int| timeDimension()玩家当前排名的时间维度。  
abstract boolean| hasPlayerInfo()排行榜中是否有当前玩家。
