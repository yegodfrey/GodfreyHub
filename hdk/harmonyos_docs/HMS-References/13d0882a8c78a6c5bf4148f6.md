public LatLng fromScreenLocation(Point point)  
将屏幕坐标转换成经纬度  
开发者调用此API实现屏幕像素点坐标转换成对应的经纬度。屏幕位置是以相对于地图左上角（而不是整个屏幕的左上角）的屏幕像素（而非显示像素）指定的。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
point| 屏幕上的坐标点，以像素为单位。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
[LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-latlng)| LatLng对象，表示经纬度。

public Point toScreenLocation([LatLng](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-latlng) latLng)  
开发者调用此API可获取与经纬度对应的屏幕上的点的位置。屏幕位置是以相对于地图左上角（而不是整个屏幕的左上角）的屏幕像素（而非显示像素）指定的。  
  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
latLng| 地图位置的经纬度。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
Point| 屏幕上的坐标点，以像素为单位。
