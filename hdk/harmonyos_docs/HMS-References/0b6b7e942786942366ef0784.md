**public final class TileOverlay**  
  
TileOverlay是瓦片图层的相关类。瓦片图层是显示在地图上的一组图像。这些瓦片可以是透明的，允许您增加一些新的功能到现有的地图上。

public void setZIndex(float zIndex)  
用于设置瓦片图层的z指数。z指数指的是瓦片图层的叠加顺序，具有较大z指数的瓦片图层会绘制在具有较小z指数的瓦片图层上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**

Parameter name| Parameter desc  
---|---  
zIndex| z指数，即瓦片图层的叠加顺序。  
  
  
**Return：**  
无
