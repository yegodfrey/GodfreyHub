public MessagePicker.Builder includeEddystoneUids(String hexNamespace, String hexInstance)  
包含Eddystone ID; Eddystone UID消息包含：  
namespace = [MESSAGE_NAMESPACE_RESERVED](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-message#MESSAGE_NAMESPACE_RESERVED);   
type = [MESSAGE_TYPE_EDDYSTONE_UID](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-message#MESSAGE_TYPE_EDDYSTONE_UID);  
可以用 [parse](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-beaconid#parse)([Message](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-message-message)) 解析该消息内容。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
hexNamespace| 10字节的Eddystone UID域名（十六进制），如“c526dfec5403adc62585”  
hexInstance| 6字节的实例（十六进制），如“32ddbcad1576”

public MessagePicker.Builder includeNamespaceType(String namespace, String type)  
过滤器，基于给定的域名和类型过滤所有消息，域名仅支持Beacon消息。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
namespace| 消息归属的域名，非空且不能包含无效字符：星号(*)  
type| 消息归属的类型，非空且不能包含无效字符：星号(*)
