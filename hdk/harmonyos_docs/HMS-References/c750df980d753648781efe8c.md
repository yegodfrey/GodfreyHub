这个包中包含了安全检测结果的实体类。  
  
## Classes

Class name| Class description  
---|---  
BaseResp| Safety Detect API 的返回实体基类  
SysIntegrityResp| 系统完整性检测接口 sysIntegrity 的返回实体类  
VerifyAppsCheckEnabledResp| 开启应用安全检测接口 enableAppsCheck 和查询应用安全检测状态接口 isVerifyAppsCheck 的返回实体类  
MaliciousAppsListResp| 应用安全检测接口 getMaliciousAppsList 的返回实体类  
MaliciousAppsData| 恶意应用的实体类  
AppsCheckConstants| 应用安全检测的恶意应用类型  
UrlCheckThreat| URL检测威胁类型  
UrlCheckResponse| URL检测接口 urlCheck 的返回实体类  
UserDetectResponse| 虚假用户检测接口 userDetection 的返回实体类
