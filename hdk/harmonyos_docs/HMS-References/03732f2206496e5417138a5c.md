# Group  
  
**CLASS info**  
---  
public class Group implements Parcelable  
聚合数据类，代表一个数据分组，用户可以通过聚合查询获取到一组聚合类数据。 例如，聚合查询某一时间段内体重数据的分组，通过该数据分组反映此段时间内体重数据的最大值、最小值、平均值。 当前，我们支持的分组类型包括：按时间分组，按活动记录分组，按活动类型分组，按单个活动片段分组。
