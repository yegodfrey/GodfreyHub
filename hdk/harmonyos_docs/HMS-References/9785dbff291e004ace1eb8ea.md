## Interfaces  
  
Interface name| Interface description  
---|---  
[OnSuccessListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/onsuccesslistener "OnSuccessListener")| 当任务成功完成时进行监听调用。  
[OnFailureListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/onfailurelistener "OnFailureListener")| 任务执行失败时调用。  
[OnCompleteListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/oncompletelistener "OnCompleteListener")| 任务完成时调用。  
[OnCanceledListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/oncanceledlistener "OnCanceledListener")| 任务被取消时调用。  
[OnTokenCanceledListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/ontokencanceledlistener "OnTokenCanceledListener")| 当CancellationToken被成功取消时调用。  
[Continuation](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/continuation "Continuation")| 包含一个函数，调用该函数还在一个任务执行完后，继续执行。  
[SuccessContinuation< TResult, TContinuationResult >](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/successcontinuation)| 一个任务执行成功后，调用该函数继续执行。  
[ExecuteResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/executeresult "ExecuteResult")| 任务执行结果。  
  
## Classes

Class name| Class description  
---|---  
[Task< TResult >](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/task-tresult)| 任务的抽象类，表示一个异步的操作。  
[Tasks](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/tasks "Tasks")| Task的工具类  
[TaskExecutors](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/taskexecutors "TaskExecutors")| 线程管理类，包含一个Executor实例，用于Task执行。  
[TaskCompletionSource](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/taskcompletionsource "TaskCompletionSource")| 提供创建Task的能力。  
[CancellationTokenSource](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/cancellationtokensource "CancellationTokenSource")| 创建一个CancellationToken或者取消一个已创建的CancellationToken。  
[CancellationToken](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/cancellationtoken "CancellationToken")| 传播被取消操作的通知。
