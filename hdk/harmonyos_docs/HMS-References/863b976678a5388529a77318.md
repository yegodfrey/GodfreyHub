** _订阅文件的变化_**  
  
##  请求

### HTTP请求

POST  
https://drive.cloud.hicloud.com/drive/v1/files/{fileId}/subscribe

### 参数

*仅对必填项做特别说明。

参数名| 数据类型|   
| 描述  
---|---|---|---  
fileId| string| path| 必填，文件ID。  
fields| string| query| 采用[Partial-response格式]。  
form| string| query| 媒体格式。  
prettyPrint| boolean| query| 是否以美观格式输出。  
quotaId| string| query| 用户标识，小于40个字符。用于限制单个用户的API访问数量。  
callback| string| query| JSONP的callback函数。  
x-hw-trace-id| string| header| 业务跟踪id。  
x-hw-app-id| string| header| 应用的appid。  
version| string| header| sdk版本。  
x-hw-terminal| string| header| 终端型号。  
x-hw-os| string| header| 终端操作系统类型。  
unionID| string| header| 开放的用户id。  
User-Agent| string| header| 应用版本号/appid。  
  
### 请求体

在请求正文中，提供具有以下结构的数据:

参数名| 参数类型| 描述  
---|---|---  
id| string| 必填，一个唯一ID，标识这个订阅通道。  
userToken| string| 必填，发送消息通知时，回传给业务。  
type| string| 必填，发送机制类型，web_hook。  
url| string| 必填，发送通知的地址。  
expirationTime| integer| 通道的到期的日期和时间，以Unix时间戳表示，以毫秒为单位，File资源最长1天，Change资源最长1周。  
  
## 响应

如果成功，此方法将返回具有以下结构的响应正文：
    
    
    复制
      
        1. {
        2.             "category": "api#channel",
        3.             "id": "string",
        4.             "resourceId": "string",
        5.             "resourceUri": "string",
        6.             "userToken": "string",
    
    
      
        1.             "expirationTime": 0,
        2.             "type": "string",
        3.             "url": "string"
        4. }
    
    

参数名| 参数类型| 描述  
---|---|---  
category| string| 资源类型，固定为api#channel。  
id| string| ID。  
resourceId| string| 资源ID，标识通道上正在监视的资源。  
resourceUri| string| 资源版本标识符。  
userToken| string| 发送消息通知时，回传给业务。  
expirationTime| integer| 通道的到期的日期和时间，以Unix时间戳表示，以毫秒为单位，File资源最长1天，Change资源最长1周。  
type| string| 类型。  
url| string| 回调地址。
