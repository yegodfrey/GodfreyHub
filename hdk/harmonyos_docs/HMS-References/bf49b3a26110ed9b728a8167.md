包含AppTouch ID登录服务类和接口。  
  
注意：

AppTouch ID 未发布，待发布后此接口可用。

Classes  


Class name| Class description  
---|---  
[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-authaccount)       | 登录的AppTouch ID信息，包含id、显示名称、头像url、权限、AccessToken等信息。  
[AccountAuthResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthresult)         | 开发者通过调用getAccount()方法来获取AuthAccount实例对象，进而得到该对象中封装的授权信息、用户信息等相关AppTouch ID所包含的内容。
