# 接口功能

应用可以调用本接口向华为支付服务器校验支付结果中的购买令牌，确认支付结果的准确性。

# 调用场景

在完成一笔支付后，App从HMS Core客户端获取到购买信息，返回商品订单详情JSON字符串[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)和签名字符串inAppDataSignature。应用可以通过验证签名字符串方式确保订单详情的准确性。

如果应用对安全性要求较高，需要进一步到华为应用内支付服务器验证订单信息，可以从[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData)中解析出purchaseToken参数（用于唯一标识商品和用户对应关系的购买令牌），并调用本接口向华为应用内支付服务器发起校验请求。

注意：

该接口只针对非订阅型商品，包括消耗型商品和非消耗型商品。

本节接口可选调用，应用有服务器校验要求时才需要调用。

  


**接口约束**  


请求头需要使用AccessToken进行鉴权，这里使用开放平台鉴权提供的服务接口获取AccessToken。具体请参考调用示例。

响应体要求使用应用RSA支付公钥进行验证，具体参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/iap-verifying-signature-returned-result-v4)。支付公钥获取请参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_querypaymentinfo)。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器-> 华为支付服务器  
接口URL| {rootUrl}/applications/purchases/tokens/verifyrootUrl在不同站点有不同的url：开发者应固定选择最近的站点访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#State-Infomation)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#h1-1590477491025)。  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
# 请求参数

**参数名称**| **必选(M)/可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
purchaseToken| M| String| 待下发商品的购买Token，发起购买和查询待消费商品信息时均会返回purchaseToken参数。  
productId| M| String| 待下发商品ID。商品ID来源于开发者在AppGallery Connect中配置商品信息时设置的“商品ID”。  
  
# 响应参数

**参数名称**| **必选(M)/可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
responseCode| M| String| 返回码。●  0：成功●  其他：失败，具体参考[接口错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#API-ErrorCode)。  
responseMessage| O| String| 响应描述。  
purchaseTokenData| O| String| 包含购买数据的JSON字符串，具体参考表[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseDetails-v4)[](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseDetails-v4)[InAppPurchaseDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseData "InAppPurchaseData")。该字段原样参与签名。  
dataSignature| O| String| purchaseTokenData基于应用RSA支付私钥的签名信息，签名算法为SHA256WITHRSA。应用可以参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/iap-verifying-signature-returned-result-v4)使用支付公钥对PurchaseTokenData的JSON字符串进行验签。
