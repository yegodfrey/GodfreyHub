public int onResult(MLGcrCaptureResult result, Object object)  
获取到通用卡证识别结果后的回调方法，如果没有识别到任何文字结果会调用onFailure。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
result| 识别结果。  
object| 用户传入的保留字段，可以为null。  
  
  
**Return**  


Type| desc  
---|---  
int| 通知插件是否继续检测或终止检测。  CAPTURE_CONTINUE：表示对后处理效果不满意，通知插件继续检测（仅在视频流模式下生效)。CAPTURE_STOP：表示对后处理效果满意，通知插件终止检测并自动销毁和退出插件页面。
