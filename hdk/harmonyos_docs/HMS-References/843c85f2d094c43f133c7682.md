**根据 instanceId 对交通卡个人化数据增加 message。**

# **1 请求**

## **HTTP请求**

POST  
https://**${url}** /hmspass/v1/transit/instance/**{instanceId}** /addMessage  
备注：请求地址中的 **${url}  **变量需要开发者根据服务器所属区域自行选择, 请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。

## **URL请求参数**

  
|   
|   
  
---|---|---  
instanceId| String| 个人化数据 instanceId，该 Id 在一个商户的所有 instance 中唯一，这个 Id 只能包含字母、数字和（.）、（-）、（_）。  
  
## **请求体**

请求体包含待增加的 messageList 对象，messageList 不可以超过10个 [valueObject](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-hwWalletObject-11 "valueObject") 对象。

{

  "messageList": [

    {

      object ([**valueObject**](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-hwWalletObject-11 "valueObject"))

    }

  ]  
}

# 2 响应

如果成功，响应消息包含更新后的 [hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1) 对象。
