集成 FIDO SDK 之后，您就可以调用 Huawei FIDO BioAuthn API 来完成生物特征认证，包括指纹认证和3D面容认证。  
  
## Classes

Class name| Class description  
---|---  
[FingerprintManager](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthn_FingerprintManager)| FIDO BioAuthn 指纹认证API的主入口。  
[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthn_BioAuthnCallback)| 提供给BioAuthn指纹认证或面容认证的结果回调。需要由开发者完成具体实现。  
[BioAuthnResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthn_BioAuthnResult)| BioAuthnCallback回调的输入参数。  
[CryptoObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthn_CryptoObject)| 与指纹认证或面容认证关联的加密对象的包装类。  
[FaceManager](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/BioAuthn_FaceManager)| FIDO BioAuthn 3D面容认证API的主入口。
