# 接口功能  
  
此接口用于校验购买的商品，判断商品是否已经成功购买，是否在有效期内。

# 调用场景

在完成一笔支付后，HMS Core客户端会返回商品购买单详情JSON字符串[inAppPurchaseData ](https://developer.huawei.com/consumer/cn/doc/HMS-References/iap-InAppPurchaseData)和签名字符串inAppDataSignature。InAppPurchaseData中有用于唯一标识商品和用户对应关系的purchaseToken。

通过签名验证，可确保InAppPurchaseData 有效性。您还可以解析出InAppPurchaseData中的purchaseToken数据，调用华为应用内支付服务器提供的Subscription服务验证购买Token接口，用于对已经购买的商品提供服务之前，对购买进行校验。一般应该判断商品是否已经成功购买，对于订阅商品返回最近的收费情况，包括何时收费以及是否在有效期内。

注意：该接口只针对订阅型商品。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器-> 华为支付服务器  
接口URL| {rootUrl}/sub/applications/{apiVersion}/purchases/getrootUrl在不同站点有不同的url：开发者应固定选择最近站点的Subscription服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#State-Infomation)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-api-specification-related-v4#h1-1590477491025)。  
数据格式| 请求消息：Content-Type: application/json响应消息：Content-Type: application/json  
  
# 请求参数

**参数名称**| **必选(M)/****可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
subscriptionId| M| String| 订阅Id  
purchaseToken| M| String| 商品的已购买Token，发起购买和查询订阅信息均会返回。

**参数名称**| **必选(M)/可选(O)**| **数据类型**| **参数描述**

responseMessage| O| String| 响应描述。  
inappPurchaseData| O| String| 包含购买详情的字符串（JSONString 格式），格式参考InappPurchaseDetail。  
  
InappPurchaseDetail说明：

**参数名称**| **必选(M)/可选(O)**| **数据类型**| **参数描述**  
---|---|---|---  
在[InappPurchaseDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-InAppPurchaseDetails-v4)基础上增加下面两个字段  
surveyReason| O| Integer| 顾客取消原因：0：其他原因1：费用过高，用户反悔2：技术问题，比如商品未提供5：欺诈，禁用清单。7：商品切换9：较少使用，不再需要该服务10：有其他更好应用。  
surveyDetails| O| String| 在surveyReason为0的时候，收集顾客输入的取消原因。

# 接口功能

此接口用于撤销订阅，订阅商品会立即取消，同时会立即发起退费。

# 调用场景

在收到顾客申诉误购买该订阅商品或不需要该订阅商品的情况下，您可以调用华为应用内支付服务器提供的撤销订阅接口终止服务，购买的订阅商品立即消失，同时最近的订阅费用会立即发起返还；一般在您或者HW在怀疑顾客有欺诈行为时使用。

注意：退款发起后，可能需要一定的时间才能到账。

承载协议| HTTPS POST
