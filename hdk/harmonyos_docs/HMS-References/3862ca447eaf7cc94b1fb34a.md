# HuaweiHiHealth  
  
**CLASS info**  
---  
public class HuaweiHiHealth  
API总入口类，定义了获取各个Manager和Controller实例的接口

**Field**  
---  
public static final DataManager DATAMANAGER  
DataManager功能类，提供给开发者对数据的管理功能，可以对运动健康数据进行增删改查，也可以监听数据的更新变化。
