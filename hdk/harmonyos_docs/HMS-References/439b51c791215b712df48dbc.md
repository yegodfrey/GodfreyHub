public PolygonOptions zIndex(float zIndex)  
用于设置多边形的z指数。z指数指的是多边形的叠加顺序，具有较大z指数的多边形会绘制在具有较小z指数的多边形上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
zIndex| z指数，即多边形的叠加顺序。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
PolygonOptions| 设置新的z指数后的PolygonOptions对象。
