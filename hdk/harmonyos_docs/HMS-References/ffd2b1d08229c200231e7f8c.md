public class WeatherStatusResponse extends BaseResponse<WeatherStatus>  
天气状态的请求响应，可通过调用[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-captureclient)中提供的[getWeatherByDevice](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getWeatherByDevice)方法获取设备当前位置天气状态响应；或者调用[getWeatherByIP](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getWeatherByIP)方法获取网络IP位置的天气状态响应；或者调用[getWeatherByPosition](https://developer.huawei.com/consumer/cn/doc/awareness-captureclient#getWeatherByPosition)指定地址获取天气状态响应。
