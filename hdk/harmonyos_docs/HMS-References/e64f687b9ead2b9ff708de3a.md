com.huawei.hms.mlsdk.common.MLResultTrailer  
目标跟踪器抽象类，支持对特定目标连续帧检测结果进行跟踪,识别目标出现，变化，消失，处理完成等场景。每个场景对应有一个处理方法，可以在其中实现自定义的处理逻辑。

## Public Methods

Method  
---  
public void completeCallback()  
结束处理，处理目标对象在当前帧消失，且连续消失帧数超过设定值，或当前对象不再被关注的场景。  
Method  
---  
public void lostCallback(MLAnalyzer.Result<T> result)  
目标对象丢失，处理目标对象在当前帧消失，但连续消失帧数未超过设定值的场景。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
result| 当前目标对象的检测结果。  
Method  
---  
public void objectCreateCallback(int itemId, T obj)  
发现一个新的对象，可用于处理目标对象首次出现的场景。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
itemId| 新目标对象的ID。  
obj| 新的目标对象，如一个MLFace实例。  
Method  
---  
public void objectUpdateCallback(MLAnalyzer.Result<T> result, T obj)  
目标对象更新，可用于处理当前帧中识别到了与上一帧中同一对象的场景。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
result| 当前目标对象的检测结果。  
obj| 当前目标对象，如一个MLFace实例。
