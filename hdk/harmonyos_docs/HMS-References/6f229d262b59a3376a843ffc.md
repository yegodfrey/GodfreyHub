class info  
---  
com.huawei.hms.mlsdk.classification.MLImageClassification  
表示由图像分类器（MLImageClassificationAnalyzer）识别出的图像类别。图像类别列表参见[图像分类类别清单](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/ml-resource-4)。包含三种属性：1、类别唯一id  
2、类别名称  
3、类别的置信度
