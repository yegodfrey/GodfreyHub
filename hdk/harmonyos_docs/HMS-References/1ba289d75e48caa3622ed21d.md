public final class BehaviorBarrier extends Object  
活动状态检测围栏，包括活动开始、活动结束和活动进行中的围栏。  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
int| BEHAVIOR_IN_VEHICLE| 表示用户在开车状态。  
int| BEHAVIOR_ON_BICYCLE| 表示用户在骑车状态。  
int| BEHAVIOR_ON_FOOT| 表示用户在行走或跑步状态。  
int| BEHAVIOR_RUNNING| 表示用户在跑步状态。  
int| BEHAVIOR_WALKING| 表示用户在行走状态。  
int| BEHAVIOR_STILL| 表示用户在静止状态。  
int| BEHAVIOR_UNKNOWN| 表示无法检测到用户当前活动状态。注意：不支持注册unknown围栏。

public static AwarenessBarrier keeping(int… behaviorTypes)  
活动状态进行中围栏，添加指定活动状态（[BEHAVIOR_UNKNOWN](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-barrier-behaviorbarrier#BEHAVIOR_UNKNOWN)除外）的围栏后，当用户正在进行以上该类活动时，此围栏状态为TRUE并触发围栏事件上报。  
对于Android 10（API级别29）及以后的版本需要添加android.permission.ACTIVITY_RECOGNITION权限。  
对于Android 9（API级别28）及以前的版本需要添加com.huawei.hms.permission.ACTIVITY_RECOGNITION权限。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
behaviorTypes| 一个或多个活动类型常量。  
  
  
**Return**  


Type| desc  
---|---  
AwarenessBarrier| 情景感知围栏。  
  
  
**Throws**  


Parameter name| Parameter desc  
---|---  
IllegalArgumentException| 参数不合法（当behaviorTypes为空或为无效的数值，或为[BEHAVIOR_UNKNOWN](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-barrier-behaviorbarrier#BEHAVIOR_UNKNOWN)）异常。

public static AwarenessBarrier beginning(int… behaviorTypes)  
活动开始围栏，添加指定活动状态（[BEHAVIOR_UNKNOWN](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/awareness-barrier-behaviorbarrier#BEHAVIOR_UNKNOWN)除外）的围栏后，当用户开始进行该类活动时，此围栏状态为TRUE并触发围栏事件上报，5s后状态切换为FALSE。  
对于Android 10（API级别29）及以后的版本需要添加android.permission.ACTIVITY_RECOGNITION权限。  
对于Android 9（API级别28）及以前的版本需要添加com.huawei.hms.permission.ACTIVITY_RECOGNITION权限。
