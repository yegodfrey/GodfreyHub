**获取钱包服务器保存的会员卡所有模板，按 session 和 pageSize 分页返回。**

# **1 请求**

## **HTTP请求**

GET

https://**${url}** /hmspass/v1/loyalty/model?session=**{session}** &pageSize=**{pageSize}**

备注：请求地址中的 ****${url}  ****变量需要开发者根据服务器所属区域自行选择，请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。

## **URL路径参数**

session| String| This parameter is designed to control the context when different sets of results are returned. It is used to get the next set of results if pageSize is specified and objects that are available in a list are more than the pageSize.  
---|---|---  
session| String| 如果已指定 pageSize 且对象总数大于 pageSize，调用批量查询接口会返回一个 nextSession 参数。再次调用此接口时，将这个 session 参数设置为之前获取的 nextSession，可以得到下一组对象。首次调用批量查询接口不填写此参数。  
pageSize| Int| 确定每次返回的记录数，如果未定义，则返回所有结果。  
  
备注：session 和 pageSize 都不存在则返回全部对象。session 不存在而 pageSize 存在，则返回第一组对象。session 和 pageSize 都存在则返回下一组对象。不能填写了 session 而不填写 pageSize。

## **请求体**

请求体必须为空。

# 2 响应

如果成功，消息按如下格式返回：  
响应消息：  


{  
  "pageInfo": {  
    object (**PageInfo**)  
  }  
  "data": [  
    {  
      object (****[**hwWalletObject**](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject")****)  
    }  
  ]  
}

data| Array< hwWalletObject>| Loyalty card templates corresponding to the query request.  
---|---|---  
data| Array<[hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject")>| 会员卡模板数据列表。  
pageInfo| PageInfo| 页面信息。  
  
  
**PageInfo**  


serviceType| String| The value is always hmspass#pageInfo.  
---|---|---  
serviceType| String| 固定值"hmspass#pageInfo"。  
pageSize| Int| 返回列表的长度。  
nextSession| String| 查询下一页使用的 session（5分钟内有效）。
