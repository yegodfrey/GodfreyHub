ScoreSubmissionInfo.Result类主要用于返回提交排行榜分数后的分数信息，在调用[ScoreSubmissionInfo.getSubmissionScoreResult](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/scoresubmissioninfo#getSubmissionScoreResult)方法时会返回该类型的实例。

# **Field Summary**

Return| Parameter Name| Description  
---|---|---  
public final String| displayScore| 用于展示的分数的本地化数字。  
public final boolean| isBest| 是否为当前玩家的最好成绩。
     * true：是
     * false：否  
public final long| playerRawScore| 提交分数的原始分值。  
public final String| scoreTips| 提交分数的自定义单位。没有自定义单位则为null。  
  
**Fields**  


## **public final String displayScore**

用于展示的分数的本地化数字。

## **public final boolean isBest**

是否为当前玩家的最好成绩。

     * true：是

     * false：否

## **public final long playerRawScore**

提交分数的原始分值。

## **public final String scoreTips**

提交分数的自定义单位。没有自定义单位则为null。
