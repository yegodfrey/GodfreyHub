public final class WalletPassApi extends Object  
该类主要作用是让第三方APP发起HmsPass服务  
  
## Public Method Summary

Return type| Method name  
---|---  
WalletPassApiResponse| canAddPass(String appid,String passTypeId)                      是否可添加Pass。  
WalletPassApiResponse| addPass(String hwPassData)               添加Pass。  
WalletPassApiResponse| requireAccessToken(String passTypeId)申请与NFC卡交互Token。  
WalletPassApiResponse| requireAccessCardSec(String passTypeId，String passId，String sign)申请与NFC卡通信临时公钥。  
WalletPassApiResponse| modifyNFCCard(String passTypeId，String passId，String reason, String cardParams, String sign)修改NFC卡（写卡）。  
WalletPassApiResponse| readNFCCard(String passTypeId，String passId，String cardParams, String reason,  String sign)读取NFC卡。  
WalletPassApiResponse| deletePass(String passTypeId，String passId，String sign)删除指定Pass接口。  
WalletPassApiResponse| queryPassStatus(String passTypeId，String passId)查询指定Pass状态接口。  
WalletPassApiResponse| requirePassDeviceId(String passTypeId)查询账号和设备唯一标识的接口。

public WalletPassApiResponse requireAccessCardSec(String passTypeId，String passId，String sign)  
3rd app通过此接口可以申请与NFC卡通信的临时公钥，申请前必须获得与NFC卡交互的Token，签名时需要包含Token。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
passTypeId| Pass类型Id。  
passId| 卡劵Id。  
sign| 对passTypeId +PassId +accesstoken使用证书签名；accesstoken需要调用申请Token接口获取。  
  
  
**Return**  


Type| desc  
---|---  
WalletPassApiResponse| 调用接口返回的对象。

public void modifyNFCCard(String passTypeId, String passId, String cardParams, String reason, String sign, IpassModifyNFCCardImpl callBack)  
3rd app通过此接口可以修改Pass（仅针对NFC卡）中的参数，调用前必须获得与NFC卡通信的临时公钥，并对请求参数值进行加密。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
passTypeId| 卡类型Id。  
passId| 卡id。  
cardParams| 需要修改的卡参数列表，Json，每个参数的Key在联盟申请卡时明确名称，Value需要用卡临时通信公钥tempAccessSec加密。  
reason| 申请写卡的原因，首次实例化时可以不填写，后续更新必须填写，钱包需要弹出界面让用户确认写入。  
sign| 注意：cardParams参数格式需要参考白卡的文件格式要求，详细请参考“推送卡券接口说明 – 白卡文件格式”。  
callBack| 3rd app调完修改Pass接口后的回调接口，异步返回结果。  
  
  
**Return**  


Type| desc  
---|---  
WalletPassApiResponse| 调用接口返回的对象。

public WalletPassApiResponse readNFCCard(String passTypeId, String passId, String cardParams, String reason,String sign)  
3rd app通过此接口可以查询Pass（仅针对NFC卡）中的指定参数，需传入外部生成的临时公钥，用于对查询结果进行加密。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
passTypeId| 卡类型Id。  
passId| 卡id。  
cardParams| cardParams内部结构如下{“car_key_sn”:”” ,”car_key_group”:””,”read_publickey”:”外部传入的临时公钥，用于加密查询结果，必填”}查询后，会将卡应用序列号填入car_key_sn的value，秘钥组号用|分隔，填入car_key_group，整体用read_publickey加密后返回。  
reason| 申请查询的原因，预留字段，可以为空；  
sign| 证书对passTypeId + passId + cardParams + reason+accessToken签名值。  
  
  
**Return**  


Type| desc  
---|---  
WalletPassApiResponse| 调用接口返回的对象。
