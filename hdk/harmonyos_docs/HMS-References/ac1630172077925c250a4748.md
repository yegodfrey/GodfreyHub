# 1 接口描述

DTM函数调用变量实现接口。

# 2 调用示例

以下示例通过实现 ICustomVariable 接口获取AppsFlyer的UID：
    
    
    复制
      
        1. public class CallVariableDemo implements ICustomVariable {
        2.     @Override
        3.     public String getValue(Map<String, Object> var1) {
        4.         return AppsFlyerLib.getInstance()
        5.                            .getAppsFlyerUID(DTMApplication.getInstance());
        6.     }
        7. }
    
    

# 3 请求参数  


参数名称| 参数类型| 备注  
---|---|---  
var1| Map<String, Object>| 自定义变量  
  
# 4 返回值

函数调用变量值。
