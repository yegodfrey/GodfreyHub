**public final class Polygon**  
  
地球表面的多边形。多边形可以是凸面或凹面，它可以跨越180子午线并且可以具有未填充的孔。

public void setZIndex(float zIndex)  
设置多边形的z指数。z指数指的是多边形的叠加顺序，具有较大z指数的多边形会绘制在具有较小z指数的多边形上，具有相同z指数的叠加顺序是任意的。默认的z指数是0。  
  
  
**Parameters：**

Parameter name| Parameter desc  
---|---  
zIndex| z指数，即多边形的叠加顺序。  
  
  
**Return：**  
无
