## **1 场景描述**

在使用HMS卡券功能进行设备注册、解注册时，用于回调通知商户服务器。

## **2 请求**

### 2.1 接口定义  


POST  
https://**${url}** /**{serviceId}** /hms/wallet/v1/notify

备注：请求地址中的 **${url}  **变量需要开发者根据服务器所属区域自行选择, 请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。

### **2.2 鉴权方式**

签名参数放置于HTTP HEADER中，

签名方式参数，HMSSignType: SHA256WithRSA

签名值（对整个body进行签名），HMSSign:XXX

### **2.3 接口参数描述(http body)**

名称| 类型| 描述| 是否可选  
---|---|---|---  
eventId| String(32)| 事件 Id（可以依赖此参数去重）| 必选  
modelId| String(32)| 模板的唯一标识符，这个 Id 在商户的所有模板中是全局唯一的，这个 Id 只能包含字母、数字和（.）、（-）、（_）。| 必选  
instanceId| String(32)| 个人化数据 instanceId，该 Id 在一个商户的所有 instance 中唯一，这个 Id 只能包含字母、数字和（.）、（-）、（_）。| 必选  
eventTime| String(32)| 事件发生时间（UTC时间）：“yyyy-mm-dd HH:MM:SS”| 必选  
eventType| String(24)| 事件类型：“RECEIVE_CARD”： 领卡“DELETE_CARD”： 删卡| 必选  
instanceId| String| 个人化数据 instanceId，该 Id 在一个商户的所有 instance 中唯一，这个 Id 只能包含字母、数字和（.）、（-）、（_）。  
---|---|---  
  
# 2 响应

名称| 类型| 描述| 是否可选  
---|---|---|---  
returnCode| String| 返回码（0为成功，其余值为失败）| 必选  
returnDesc| String| 返回描述信息| 必选
