public class HuaweiIdAuthTool  
HuaweiIdAuthTool提供静态实用方法，以获取、清除授权信息。

public static void deleteAuthInfo(Context context, String accessToken) throws HuaweiIdAuthException  
清除本地缓存。说明：当传入参数为非Activity类型时，调用deleteAuthInfo接口会发生异常，不会弹出UI交互界面提示用户处理。例如：当HMS Core (APK)不符合帐号服务的版本要求时，便会抛出“hms apk version is low”异常信息，此时需要手动升级HMS Core (APK)。如果需要拉起升级引导界面，建议传入Activity类型参数替代Context类型。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
context| 上下文。  
accessToken| 要清除的token。  
  
**Throws**  


Parameter name| Parameter desc  
---|---  
HuaweiIdAuthException| 认证异常。
