public class HourlyWeather implements Parcelable  
当前小时和未来24个小时的天气信息。包括天气ID(CN)、对应时间信息、摄氏度、华氏度、降雨概率、是白天还是晚上。

## Public Methods

Method  
---  
public int getCnWeatherId()  
获取CN天气Id（cnWeatherId）。CN天气Id表示的是当前的天气，每个值都对应不同的天气，例如0表示晴，1表示多云，7表示小雨。更多天气ID对应的天气信息请参见[CNWeatherId](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/cn-weatherId-4)。  
  
**Return**

Type| desc  
---|---  
int| CN天气Id。
