**public final class HuaweiMapOptions**

HuaweiMapOptions是继承自Object的final类，实现了Parcelable接口。为[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)定义了配置信息，这些属性用于开发者将地图添加到应用程序中。如果使用[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)，可以使用静态工厂方法newInstance(HuaweiMapOptions)传递这些配置。如果使用的是[MapView](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapview)，可以使用构造函数MapView(Context,HuaweiMapOptions)传递这些配置信息。

public HuaweiMapOptions useViewLifecycleInFragment(boolean isUseViewLifecycleInFragment)  
开发者调用此API指定是将地图的生命周期绑定到[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)的视图上还是[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)本身。默认将地图的生命周期与[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)绑定在一起。使用[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)的生命周期，当[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)分离和重新建立连接时能够更快地渲染地图，这样做的代价是[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)分离时不会被破坏，不会释放地图映射的内存。如果使用[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)视图的生命周期，在[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)分离和重新建立连接时，不会重用地图，这将导致地图重新渲染，这可能需要几秒的时间。这就意味着当[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)分离时，因为没有视图，[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-huaweimap)的方法都会抛出NullPointerException异常。  
  
  
**Parameters：**  


Parameter name| Parameter desc  
---|---  
isUseViewLifecycleInFragment| true表示指定了地图的生命周期与[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)的视图绑定，false表示指定了地图的生命周期与[MapFragment](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/hms-map-mapfragment)本身绑定。  
  
  
**Return：**  


Return type| Parameter desc  
---|---  
HuaweiMapOptions| 华为地图配置项。
