# **接口功能**

查询Beacon设备的详细信息。

# **调用场景**

调用此接口进行查询Beacon设备的详细信息。

# **接口原型**

**承载协议**|  HTTPS GET  
---|---  
**接口方向**|  应用服务器或APP应用->近距离通信服务器  
**接口URL**|  https://{域名}/WiseCloudNearbyBeaconService/v1/queryBeaconInfo/{beaconId}?projectId=[projectId]  
**数据格式**|  Content-type: application/json  
  
# **接口约束**  


需要获取服务账号凭证。

# **请求参数**

**参数名称**| **必选(M)/可选(O)**| **类型**| **参数说明**  
---|---|---|---  
srcTranID| M| String| 请求头参数，事务ID，最长为24个字符。  
timeStamp| M| Long| 请求头参数，时间戳。  
Authorization| M| String| 请求头参数，用于网关认证，请参考[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-common-service-account)获取JWT。  
projectId| O| String| 查询参数。  
beaconId| M| String| 路径参数，Beacon设备的ID。  
  
# **返回参数**

请求成功，状态码200，响应体如下：

**参数名称**| **类型**| **参数说明**  
---|---|---  
beacon| object| Beacon设备的详情信息。详情查看[beacon的结构体](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/api-beacon-struct)。  
  
请求失败，状态码非200，响应体如下：

(1) 非业务(网关校验失败、token过期等情况)请求失败时：

**参数名称**| **类型**| **参数说明**  
---|---|---  
error| String| 非业务返回错误信息。  
  
(2) 业务请求失败时：

**参数名称**| **类型**| **参数说明**  
---|---|---  
serviceError| object| 业务返回的错误信息。  
  
serviceError的JSON结构体为：

**参数名称**| **类型**| **参数含义**  
---|---|---  
code| int| 错误码，错误码描述见返回码。  
status| String| 错误状态。  
message| String| 错误描述信息。  
  
# **返回码**

**错误码**| **错误码含义**| **建议业务处理方式**  
---|---|---  
400000001| 请求头参数不对。| 检查请求头参数。  
400000002| 请求体参数不对。| 检查请求体参数。  
403000003| 服务账号不可用。| 检查服务账号是否可用，在华为开发者联盟的管理中心可查看服务账号状态。  
403000004| 当前账号没有权限操作此Beacon。| 检查此账号是否有权限操作。  
404000006| 当前Beacon不存在。| 检查该当前的Beacon是否注册过，若无请先注册。  
500000001| 内部服务错误。| 请联系华为技术支持人员。
