## Public Methods

Method  
---  
public int getPriceType()  
获取商品类型。  
  
**Return**

type| desc  
---|---  
int| 商品类型。  
● 0: 消耗型商品  
● 1: 非消耗型商品  
● 2: 自动续费订阅商品  
Method  
---  
public String getProductId()  
获取商品id。  
  
**Return**

type| desc  
---|---  
String| 待支付的商品ID。商品ID来源于开发者在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置商品信息时设置的“商品ID”，具体参见[新增商品](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_product)章节。 说明：该参数长度限制为(0, 148)。同一个应用内商品ID不能重复，保存后将无法修改（删除后也无法再次使用）。  
Method  
---  
public String getDeveloperPayload()  
获取商户侧保留信息。  
  
**Return**

type| desc  
---|---  
String| 商户侧保留信息。  
若该字段有值，在支付成功后的回调结果中会原样返回给应用。        
注意：该参数长度限制为(0, 128)。
