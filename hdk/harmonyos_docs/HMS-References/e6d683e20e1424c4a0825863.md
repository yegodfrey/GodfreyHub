CLASS info  
---  
public class AccountAuthResult extends AbstractAuthResult  
开发者通过调用getAccount()方法来获取AuthAccount实例对象，进而得到该对象中封装的授权信息、用户信息等相关AppTouch ID所包含的内容。注意：AppTouch ID 未发布，待发布后此接口可用。  
  
## Public Method Summary

[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/account-accountauthresult)| getAccount()授权成功后，从授权结果信息AccountAuthResult中获取包含AppTouch ID授权信息的AuthAccount对象，如果未授权则返回null。  
  
---|---  
void| setAuthAccount(AuthAccount authAccount)设置AccountAuthResult对象实例。  
boolean| isSuccess()授权结束后，调用该方法判断返回结果是否授权成功。true表示授权成功，false表示授权失败。
