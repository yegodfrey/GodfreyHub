public final class GeofenceErrorCodes extends CommonStatusCodes  
地理围栏状态码。  
  
# **Constant Summary**

Type| Name| Desc  
---|---|---  
int| GEOFENCE_UNAVAILABLE| 当前地理围栏服务不可用。  
int| GEOFENCE_NUMBER_OVER_LIMIT| 添加了太多的围栏，当前每个应用仅支持添加100个围栏。  
int| GEOFENCE_PENDINGINTENT_OVER_LIMIT| 使用了太多的PendingIntent添加围栏，PendingIntent上限为5。  
int| GEOFENCE_INSUFFICIENT_PERMISSION| 没有足够的权限进行地理围栏相关操作。  
int| GEOFENCE_REQUEST_TOO_OFTEN| 添加地理围栏过于频繁。
