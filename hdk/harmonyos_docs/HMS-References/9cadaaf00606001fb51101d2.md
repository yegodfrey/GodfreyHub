# dataCollectors.sampleSets: history

查询指定数据采集器下的采样数据的历史记录。

#### 请求

#### [h2]HTTP请求
    
    
    GET 
    https://health-api.cloud.huawei.com/hihealth/v1/dataCollectors/dataCollectorId/sampleSets/history?limit=***&cursor=***

#### [h2]请求参数

参数名称 | 参数类型 | 参数描述 | 可选/必选 | 约束说明  
---|---|---|---|---  
dataCollectorId | string | 数据采集器的唯一标识 | 必选 | 需满足如下拼接规则：collectorType:collectorDataType.name: appInfo.appPackageName:deviceInfo.manufacturer: deviceInfo.modelNum:deviceInfo.uniqueId:collectorName。参考[dataCollectors: create](https://developer.huawei.com/consumer/cn/doc/HMS-References/datacollectors_create-0000001050114852)中collectorId的约束  
limit | integer | 单次分页查询长度 | 可选 | 取值范围：0~1000  
cursor | string | 分页继续查询的标识，填入上一个请求的cursor值即可 | 可选 | 长度范围：1~1000  
  
#### [h2]请求体

无

#### 响应

待查询的SamplePoint数据、分页标识cursor和数据采集器ID

参数名称 | 参数类型 | 参数描述 | 可选/必选  
---|---|---|---  
insertedSamplePoint | list<SamplePoint> | 已插入的samplePoints | 可选  
deletedSamplePoint | list<SamplePoint> | 已删除的samplePoints | 可选  
cursor | string | 下次查询的分页标识 | 可选  
dataCollectorId | string | 数据采集器的唯一标识 | 可选  
  
SamplePoint结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选  
---|---|---|---  
startTime | long | 开始时间，单位：纳秒 | 必选  
endTime | long | 结束时间，单位：纳秒 | 必选  
dataTypeName | string | 数据类型名称 | 必选  
originalDataCollectorId | string | 原始数据采集器ID，仅在该samplePoint被包含在派生dataCollector的sampleSet中时有效 | 必选  
value | list<SamplePointValue> | 数据值 | 必选  
modifyTime | long | 最后修改该采样点的时间。单位：毫秒，仅在查询数据变更历史时可见 | 必选  
  
SamplePointValue结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选  
---|---|---|---  
integerValue | integer | 整型值 | 四选一，参数类型与SamplePoint对应的DataTypeField一致。  
floatValue | double | 浮点型值  
stringValue | string | 字符串值  
mapValue | list<SamplePointMap> | Map值  
  
SamplePointMap结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选  
---|---|---|---  
key | string | Key值 | 必选  
value | SamplePointMapVal | 数据值 | 必选  
  
SamplePointMapVal结构：

参数名称 | 参数类型 | 参数描述 | 可选/必选  
---|---|---|---  
floatValue | double | 浮点型值 | 必选  
  
#### 返回码

成功：http 200

失败：其他
