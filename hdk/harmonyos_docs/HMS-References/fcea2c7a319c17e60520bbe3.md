**获取钱包服务器保存的登机牌所有模板，按 session 和 pageSize 分页返回。**

# **1 请求**

## **HTTP请求**

GET  
https://**${url}** /hmspass/v1/flight/model?session=**{session}** &pageSize=**{pageSize}**  
备注：请求地址中的 **${url}  **变量需要开发者根据服务器所属区域自行选择, 请参考[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/wallet-api-server-address)。

## **URL路径参数**

session| String| 用于控制多批返回时上下文控制。如果已指定 pageSize，但列表中多于 pageSize 对象，则此参数将用于获取下一组结果。  
---|---|---  
session| String| 用于控制多批返回时上下文控制。如果已指定 pageSize，但列表中多于 pageSize 对象，则此参数将用于获取下一组结果。  
pageSize| Int| 确定每次返回的记录数，如果未定义，则返回所有结果。  
  
备注：session 与 pageSize 同时存在或者同时不存在。同时不存在，则全部返回。

## **请求体**

请求体必须为空。

# 2 响应

如果成功，消息按如下格式返回：

响应消息：

{  
  "pageInfo": {  
    object (**PageInfo**)  
  }  
  "data": [  
    {  
      object (****[**hwWalletObject**](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1 "hwWalletObject")****)  
    }  
  ]  
}

  
|   
|   
  
---|---|---  
data| Array<[hwWalletObject](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/wallet-api-server-hwWalletObject-1)>| 登机牌模板数据列表。  
pageInfo| PageInfo| 页面信息。  
  
  
**PageInfo**  


  
|   
|   
  
---|---|---  
serviceType| String| 固定值"hmspass#pageInfo"。  
pageSize| Int| 返回列表的长度。  
nextSession| String| 查询下一页使用的 session（5分钟内有效）。
