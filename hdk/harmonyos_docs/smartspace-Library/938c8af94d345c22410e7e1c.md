# 插件pluginInfoV2.json配置字段说明

|-----------------|------------|---------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|
|**字段名**|**类型**|**说明**|样例|
|packageName|String|插件的包名|com.huawei. xxx|
|pluginName|String|插件名称,跟包名一致，|com.huawei.xxx|
|proId|String|插件名称,跟包名一致，|com.huawei.xxx|
|pluginPath|String|插件在华为智慧生活云的地址|由华为提供|
|fileName|String|文件名称，跟包名一致，加上文件后缀.apk|com.huawei.xxx.apk|
|allowDaemon|int|是否需要开机启动；0表示不需要，1表示需要|1|
|launcherClassName|String|插件启动的首页activity类|com.huawei.xxxActivity|
|binderAction|String|插件跟宿主进行绑定的service|com.huawei.xxx.PluginService|
|accessMethods|List<String>|需要调用宿主的方法集合,具体接口请参考《智慧生活Ex插件AIDL API参考》|[ "setUiContent","getBuildNetInfo","setBuildPort","wakeLockScreen","subscribeSecurityEvent","unsubscribeSecurityEvent","getHomeInfo"]|
|pluginData|List<Object>|插件信息|  |
|appExVersionMatch|String|匹配华为智慧生活全屋版的版本号|123-|
|versionCode|String|插件的版本号|1000000|
|pluginStatus|String|是否上线；0表示未上线，1表示上线|0|
|signDigest|String|插件包名的签名摘要|xxxxxx|
