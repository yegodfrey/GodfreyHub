# 如何判断dark、light模式

```codeblock
public static boolean isDarkMode() {
    if (Build.VERSION.SDK_INT <= Build.VERSION_CODES.P) {
        return false;
    }
    Context baseContext = BaseUtil.getAppContext();
    if (baseContext == null) {
        return false;
    }
    if (baseContext.getApplicationContext() == null || baseContext.getApplicationContext().getResources() == null
        || baseContext.getApplicationContext().getResources().getConfiguration() == null) {
        return false;
    }
    int uiMode = baseContext.getApplicationContext().getResources().getConfiguration().uiMode;
    Log.debug(true, TAG, "isDarkMode() uiMode == ", uiMode);
    return (uiMode & Configuration.UI_MODE_NIGHT_MASK) == Configuration.UI_MODE_NIGHT_YES;
}
```
