# 卡片刷新

刷新时机：切换LCD顶部tab或亮灭屏触发，宿主主动查询；

刷新间隔：

1. 静态卡片12h内不会重复刷新，即超过12h间隔后触发主动查询；
2. 动态卡片30min内不会重复刷新，即超过30min间隔后触发主动查询；

说明：如果点击按钮触发某个业务，该业务需要一定时间内主动通知刷新界面，则插件后台业务自己处理，在需要刷新卡片时主动调用宿主setUiContent接口触发刷新；
