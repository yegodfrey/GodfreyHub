# 如何查看子进程开销

* 【内存】

```codeblock
adb shell dumpsys meminfo com.huawei.smarthome.extend:p0 > /mnt/sdcard/meminfo.txt
```

* 【CPU占用】

```codeblock
adb shell dumpsys cpuinfo com.huawei.smarthome.extend:p0 > /mnt/sdcard/meminfo.txt
```
