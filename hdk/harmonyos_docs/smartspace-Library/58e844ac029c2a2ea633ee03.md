# 概述

本文介绍华为中控屏首页卡片开放规范，支撑全屋智能面向2B提供三方差异化服务能力接入方式。华为中控屏首页开放卡片支持三类卡片：运营展示类、功能类及运营服务类，卡片服务能力由三方开发插件提供，同时支持行业伙伴基于卡片(插件)开发个性化接口，自定义丰富的行业应用卡片。
