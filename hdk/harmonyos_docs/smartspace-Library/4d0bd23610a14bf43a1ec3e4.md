# 样例说明

* 【初始化配置】

```codeblock
{
	"ttl": 30,  // 单位min，30或720
	"uiContent": {
		"title": "客房服务",
		"titleEn": "ABCDE",
		"subTitle": "7x24小时贴心服务",
		"subTitleEn": "ABCDE",
		"click": "@page:",
		"selectedStatus": 0,
		"buttons": [
			{
				"index": 0,
				"icon": "",
				"text": "",
				"textEn": "",
				"click": "@function:"
			},
			{
				"index": 1,
				"icon": "",
				"text": "",
				"textEn": "",
				"click": "@function:"
			}
		]
	}
}
```

【当触发某个按钮后，需要卡片的副标题变化字段，只需在执行方法的成功回调中，按照如下格式返回接口】

```codeblock
{
	"uiContent": {
		"subTitle": "正在执行服务"
	}
}
```

【当触发某个按钮后，需要卡片中的右侧小按钮变化字段，需在执行方法的成功回调中，按照如下格式（小按钮中的全部字段）返回接口】

```codeblock
{
	"uiContent": {
		"buttons": [
			{
				"index": 1,
				"icon": "",
				"text": "电梯上行中",
				"textEn": "",
				"click": "@function:"
			}
		]
	}
}
```
