# getUiContent返回字段说明

|---------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------|--|
|字段名||说明|类型|要求|
|ttl|  |卡片需要宿主主动获取数据的时间，当前仅支持30或720，单位mins，|int|必选|
|uiContent|  |卡片的UI内容|Object|必选|
|  |title|标题|String|必选|
|  |titleEn|英文标题|String|必选|
|  |subTitle|辅助说明/状态显示|String|可选|
|  |subTitleEn|英文辅助说明/状态显示|String|可选|
|  |click|卡片点击事件, 特定格式字符串 @function: showSomething @ page: com.xxx.xxx.device.activity.MainActivity|String|必选|
|  |buttons|**index** **为固定的标志，0** **代表左边的按钮，1** **代表右边的按钮** { "index": 0, "icon": "", "text": "", "textEn": "", "click": "@function " }, { "index": 1, "icon": "", "text": "", "textEn": "", "click": "@function " }|Array|必选|
