# 进程隔离

规则：

1. 插件里的常驻业务（如可视对讲）才允许配置子进程，非常驻业务不需要单独配置，即工作在主进程；
2. 一个插件最多允许有一个常驻服务（工作在独立进程），该服务占用RAM<=5MB，后台静默CPU消耗<=0.5%；
3. 常驻进程名为com.huawei.smarthome.extend:p0，配置方法为修改插件工程主module里AndroidManifest.xml：

   <meta-data

   android:name="process_map"

   android:value="[{'from':'com.huawei.***','to':'$p0'}]"/>

   同时在插件的pluginInfoV2.json里配置字段：

   "allowDaemon": 1,
