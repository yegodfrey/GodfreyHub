# 样例说明

* 【初始化配置】

```codeblock
{
	"ttl": 30,  // 单位min，30或720
	"uiContent": {
		"title": "呼叫前台",
		"titleEn": "ABCDE ",
		"subTitle": "一键呼叫酒店前台",
		"subTitleEn": "ABCDEFG",
		"click": "@function:",
		" imageBtn": {
			"url": "",
			"click": "" // 不需要click事件，可以直接删除此字段
		}
	}
}
```

【当触发此卡片后，需要卡片的副标题变化字段，只需在执行方法的成功回调中，按照如下格式返回接口】

```codeblock
{
       "uiContent": {
              "subTitle": "正在呼叫酒店前台"
       }
}
```
