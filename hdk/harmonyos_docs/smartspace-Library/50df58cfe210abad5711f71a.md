# 样例说明

* 【初始化配置】

```codeblock
{
	"ttl": 30,  // 单位min，30或720
	"uiContent": {
		"title": "景点推荐",
		"titleEn": "ABCDE",
		"subTitle": "周边热门景点推荐",
		"subTitleEn": "ABCDE",
		"click": "@function:",
		"imageBtn": {
			"url": ""
		},
		"buttons": [
			{
				"index": 0,
				"icon": "",
				"text": "",
				"textEn": ""
			}
		]
	}
}
```

* 【当触发某个按钮后，需要卡片的副标题变化字段，只需在执行方法的成功回调中，按照如下格式返回接口】

  ```codeblock
  {
  	"uiContent": {
  		"subTitle": "正在执行服务"
  	}
  }
  ```
