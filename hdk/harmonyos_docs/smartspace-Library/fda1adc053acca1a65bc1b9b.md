# 卡片坑位配置文件

华为中控屏卡片的开放完整参数如下所示：

```codeblock
[
	{
		"featureName": "meetTime",
		"pluginName": "com.huawei.xxx",
		"uiTemplateType": " TEMPLATE_TYPE_1",
		"panelSize": "10|6",
		"buildPort": 1
	},
	{
		"featureName": "elevator",
		"pluginName": "com.huawei.xxx",
		"uiTemplateType": " TEMPLATE_TYPE_1",
		"panelSize": "10|6",
		"buildPort": 0
	}
]
```

> 说明
>
> 以上示例对应的ui信息参考[样例](https://developer.huawei.com/consumer/cn/doc/development/smartspace-Library/sample-0000001455176032)，由接口返回对应uiContent和ttl信息。
