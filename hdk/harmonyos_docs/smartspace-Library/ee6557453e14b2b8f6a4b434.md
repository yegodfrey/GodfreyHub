# 整体规范

1. 图片素材要求：需要提供**dark** **和light** 两种模式下不同的图片素材,暂不支持视频、动画，dark和light模式判断可以参考[如何判断dark、light模式](https://developer.huawei.com/consumer/cn/doc/development/smartspace-Library/dark-light-mode-selection-0000001504975701)。
2. 多语言：需要提供**中、英**两种语言的对应文字素材；其他语言据项目情况针对性提供。
3. 卡片支持静态卡片和动态卡片两种，无论是哪种类型均需要在配置文件中配置兜底内容，建议优先使用静态卡片。
4. 卡片点击交互支持**点击触发** 和**点击跳转** 两种方式；
   * **点击触发：**提供两种即时反馈效果包括 Toast提示和卡片激活效果。如下图所示。弹Toast提示的方法需要在插件执行的方法中自行实现；

   1. Toast文字展示时间统一为3s
   2. Toast弹窗文字以陈述语气告知用户操作结果，建议使用句子或短语，句末不加标点（英文句末加标点）。
   3. 言简意骇，避免使用大段文字，推荐字数控制在10字以内，不允许超过20个字。
5. 常驻服务约束：一个插件最多允许有一个常驻服务，该服务占用RAM<=5MB，后台静默CPU消耗<=0.5%，详见[插件pluginInfoV2.json配置字段说明](https://developer.huawei.com/consumer/cn/doc/development/smartspace-Library/plug-in-configuration-description-0000001455495864)。
