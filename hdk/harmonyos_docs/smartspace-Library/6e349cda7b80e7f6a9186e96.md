# 卡片加载

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091414.04000953610350539050937780853166:50001231000000:2800:AA03BADE0A3514C331557CC689C17D2215CD9DC4AD1C66AD402572935FC9B00E.png?needInitFileName=true?needInitFileName=true)

关键业务流程说明：

1. P1：DPC将卡片坑位信息写入时会同步写入坑位配置的版本信息，如果坑位有变化需要更新DPC App；
2. P4：pluginInfoV2.json主要描述插件对应的后台服务类名、插件可以调用宿主的方法及插件和宿主的匹配关系，参见[pluginInfoV2.json配置文件](https://developer.huawei.com/consumer/cn/doc/development/smartspace-Library/plug-in-configuration-file-0000001455016268)；
3. P6：如果插件未下载则会先渲染默认布局，随后自动下载插件。如果插件已安装则会自动检查更新；
   * P7：插件下载后如果是静态卡片且本地未获取过卡片信息，则会调用 插件接口查询卡片信息并持久化宿主本地，之后一直使用本地数据；
4. P9：拉起后台服务：如果卡片涉及到常驻，比如可视对讲功能，则配置后宿主会主动拉起后台服务；一个插件限定只允许有一个常驻服务，常驻服务需要满足华为的后台CPU和内存开销要求；
