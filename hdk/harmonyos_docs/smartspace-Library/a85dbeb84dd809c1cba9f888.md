# 卡片坑位配置字段说明

华为中控屏卡片上的坑位是开放给插件开发者自行配置。插件开发者只需要按照不同类型卡片的开放参数进行配置，即可完成中控屏卡片的开发；若插件需要通知宿主进行UI的刷新，可通过调用"插件通知宿主"的接口------callV2，同时传入对应的参数即可，整体参数如下表：

|-----------|------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------|
|**字段名**|**类型**|**说明**|**要求**|
|featureName|String|描述卡片的功能，不支持特殊字符，且卡片与卡片不能重复，需唯一标志。|必选|
|pluginName|String|所对应的插件包名，用于宿主寻找插件，拉起插件。|必选|
|uiType|String|卡片类型，需要在已支持的卡片范围内，卡片类型选定就确定了卡片的尺寸和显示样式，内容必须与此一致；目前支持5中类型： 1. TEMPLATE_TYPE_1：运营展示类卡片4*4 2. TEMPLATE_TYPE_2：功能类4*4 3. TEMPLATE_TYPE_3：功能图标类2*4 4. TEMPLATE_TYPE_4：功能双按钮类2*4 5. TEMPLATE_TYPE_5：运营服务类2*4|必选|
|panelSize|String|使用的中控屏的尺寸，样例如下： "panelSize": "10|6"|必选|
|buildPort|int|是否依赖楼宇网口，0表示不依赖，1表示依赖|必选|

插件开发者只需填写所选择卡片的开放字段的值，完成后提供给华为，华为侧即会按照参数自动配置好所需的卡片样式。样例如下：

```codeblock
{
	"featureName": "XXXX",
	"pluginName": "com.huawei.xxx",
	"uiTemplateType": " TEMPLATE_TYPE_1",
	"panelSize": "10|6",
	"needPort": 0
}
```
