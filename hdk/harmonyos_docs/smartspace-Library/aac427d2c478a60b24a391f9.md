# 样例说明

* 【初始化配置】

  ```codeblock
  {
  	"ttl": 30,// 单位min，30或720
  	"uiContent": {
  		"logo": "",
  		"title": "尊敬的住客",
  		"titleEn ": "Dear Passenger",
  		"subTitle": "您好，欢迎入住，我们将竭诚为您服务。",
  		"subTitleEn": "Welcome to XXXX hotle.",
  		"background": ""
  	}
  }
  ```

* 【需要卡片仅变更变化title字段，需要在插件中调用接口------callV2，并传如下参数即可】

  ```codeblock
  {
  	"uiContent": {
  		"title": "尊敬的住客"
  	}
  }
  ```
