# 在HarmonyOS应用开发中，仓颉语言与ArkUI、HarmonyOS API是什么关系

仓颉语言提供的ArkUI的声明式UI开发范式，是基于仓颉语言的元编程能力扩展而出，为开发者提供UI开发能力。在功能上，仓颉语言实现的ArkUI与ArkTS实现的ArkUI基本保持一致，为开发者使用仓颉开发UI降低学习成本。

仓颉语言基于HarmonyOS系统框架能力，为开发者提供应用开发API。在功能上，仓颉语言实现的HarmonyOS API与ArkTS实现的HarmonyOS API基本保持一致。
