# DevEco Studio界面出现卡顿现象

#### 问题现象

在编辑代码或者其他操作时，DevEco Studio出现卡顿现象，运行不流畅。

#### 解决措施

点击DevEco Studio的Help -> Change Memory Settings:

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/s2oVo8_IRvm8guohRWKvMQ/zh-cn_image_0000002659514068.png?HW-CC-KV=V1&HW-CC-Date=20260921T085446Z&HW-CC-Expire=86400&HW-CC-Sign=81D6B002E9FBAA380FB0EF31214B42BD13DB48041F7EE0086D40E948EB4BECAC)
