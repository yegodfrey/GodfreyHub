# 如何查看仓颉代码中宏展开后的内容

编译仓颉包时增加编译选项--debug-macro。编译后在源码目录将生成"xxx.cj.macrocall"文件，即为宏展开后的内容。

示例：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/8QigI0SwQqKoTbzMCsp5tQ/zh-cn_image_0000002689593459.png?HW-CC-KV=V1&HW-CC-Date=20260921T085434Z&HW-CC-Expire=86400&HW-CC-Sign=4C80B4FCBA34723B8A253E09BAEA7939674E57CF040B39F5D47B70F5A876601F)

宏相关内容，详情请参见[宏](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-macro_introduction)。

\--debug-macro编译选项介绍详情请参见[使用--debug-macro输出宏展开结果](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-compiling_error_reporting_and_debugging#使用---debug-macro-输出宏展开结果)。
