# 断连设备

行业App调用断开设备连接接口，可断开与穿戴设备的蓝牙连接。  
![](https://media:301785133828664202)  
* 断开连接后，设备会进入断开状态，行业App可以通过注册连接状态监听来监测设备状态变化。
* 断开连接后，设备仍然保留在手机蓝牙系统的已配对设备列表中，可以通过调用[connect](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section10173244192617)方法重新连接。
* 断开连接只是断开蓝牙连接，用户设置的本地配置不会删除。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[disconnect](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section3165124083114)方法断开设备连接。

   <br />

   ```
   import IndustrySDK

   Task {
       do {
           try await device.disconnect()
           print("Succeeded in disconnecting device")
       } catch let err as IndustryError {
           print("Failed to disconnect device. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
