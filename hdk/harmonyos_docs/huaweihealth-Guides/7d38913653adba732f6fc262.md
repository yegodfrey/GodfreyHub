# 血氧自动检测开关设置与查询

设置与查询穿戴设备的血氧自动检测开关状态。开启血氧自动检测开关后，穿戴设备将在静止状态下每10分钟自动测量血氧饱和度。关闭血氧自动检测开关后，穿戴设备将停止自动测量血氧饱和度。
> 注意
>
> * 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
> * 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
> * 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的血氧自动检测开关状态给穿戴设备。
> 说明
>
> 在未设置血氧自动检测开关时，查询返回错误码9。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section988418811913)方法设置血氧自动检测开关状态。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 调用Device对象的setSettingInfo方法设置血氧自动检测开关状态
       device.setSettingInfo(IndustryService.SettingType.AUTOMATIC_SPO2_MEASUREMENT_SWITCH, true).then(() => {
         // 设置血氧自动检测开关状态成功
         console.info('Succeeded in setting automaticSpO2MeasurementSwitch.');
       }).catch((err: BusinessError) => {
         // 设置血氧自动检测开关状态失败
         console.error(`Failed to set automaticSpO2MeasurementSwitch. Code is ${err.code}, message is ${err.message}.`);
       })
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section15162172713563)方法查询血氧自动检测开关状态。

   ```screen
   // 调用Device对象的getSettingInfo方法查询血氧自动检测开关状态
   device.getSettingInfo(IndustryService.SettingType.AUTOMATIC_SPO2_MEASUREMENT_SWITCH).then((result: boolean) => {
     // 查询血氧自动检测开关状态成功，打印返回的血氧自动检测开关状态
     console.info(`Succeeded in getting automaticSpO2MeasurementSwitch, result is ${result}.`);
   }).catch((err: BusinessError) => {
     // 查询血氧自动检测开关状态失败
     console.error(`Failed to get automaticSpO2MeasurementSwitch. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
