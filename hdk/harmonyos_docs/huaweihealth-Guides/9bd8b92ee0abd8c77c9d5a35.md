# 通知栏消息推送开关设置和查询

设置与查询终端设备（iOS手机）通知栏消息推送到穿戴设备的开关状态。开启通知栏消息推送开关后，终端设备收到的通知栏消息会推送到穿戴设备。关闭通知栏消息推送开关后，终端设备收到的通知栏消息不会推送到穿戴设备。穿戴设备首次连接后默认关闭通知栏消息推送开关。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setNotificationPushSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section990770181815)方法设置通知栏消息推送开关状态。

   <br />

   ```
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setNotificationPushSwitch方法设置通知栏消息推送开关状态
           try await device.setNotificationPushSwitch(notificationPushSwitch: true)

           // 设置通知栏消息推送开关状态成功
           print("Succeeded in setting notification push switch")
       } catch let err as IndustryError {
           // 设置通知栏消息推送开关状态失败
           print("Failed to set notification push switch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getNotificationPushSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1422183018574)方法查询通知栏消息推送开关状态。

   <br />

   ```
   Task {
       do {
           // 调用Device对象的getNotificationPushSwitch方法查询通知栏消息推送开关状态
           let switchValue = try await device.getNotificationPushSwitch()

           // 查询通知栏消息推送开关状态成功
           print("Succeeded in getting notification push switch, switchValue: \(switchValue)")
       } catch let err as IndustryError {
           // 查询通知栏消息推送开关状态失败
           print("Failed to get notification push switch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />
