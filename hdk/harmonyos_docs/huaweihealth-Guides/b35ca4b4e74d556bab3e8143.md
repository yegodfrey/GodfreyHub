# 查询脉搏波心律失常检测结果数据

穿戴设备提供脉搏波心律失常分析功能，用户测量脉搏波心律失常进行结果分析后，行业应用可以通过本接口查询穿戴设备上记录的脉搏波心律失常检测结果数据。  
![](https://media:301785133844396453)  
* 需要采集脉搏波心律失常检测结果数据时，建议在查询时间段内测量一次或数次脉搏波心律失常分析，否则穿戴设备侧可能返回空数据。
* 不支持并发查询脉搏波心律失常检测结果数据，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询脉搏波心律失常检测结果数据的JSON格式参数。

   <br />

   ```
   {
     "item": "arrhythmiaResultData",
     "value": {
       "startTime": 1725193422, // 单位：秒(s)
       "endTime": 1725452622 // 单位：秒(s)
     }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:--------------------|
   |startTime|UTC时间戳，单位：秒（s）|查询脉搏波心律失常检测结果数据的开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询脉搏波心律失常检测结果数据的结束时间。|
   [表1 查询脉搏波心律失常检测结果数据参数]

   ![](https://media:301785133844431454)  
   查询脉搏波心律失常检测结果数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和当前时间间隔不超过7天（不包含今天）。

   <br />

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询脉搏波心律失常检测结果数据。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询脉搏波心律失常检测结果数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject valueObject= new JSONObject();
       valueObject.put("startTime", 1725193422);
       valueObject.put("endTime", 1725452622);
       jsonObject.put("item", "arrhythmiaResultData");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询脉搏波心律失常检测结果数据
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:--------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、7、11、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回脉搏波心律失常检测结果数据，失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含脉搏波心律失常检测结果数据。

   <br />

   ```
   result样例：
   [{
       "dataType": "arrhythmiaResultData",
       "totalCount": 3,
       "dataList": {
           "startTime": 1736586113,
           "ppgIrregularHeartbeat": 2
           "saveTime": 1736586113,
           "measureType": 1,
       }
   },
   {
       "dataType": "arrhythmiaResultData",
       "dataList": {
           "startTime": 1736585902,
           "ppgIrregularHeartbeat": 4
           "saveTime": 1736585902,
           "measureType": 1,
       }
   },...
   ]
   ```

   |返回值|取值|含义|
   |:--------------------|:-------------------|:----------------------------------------------------------------------------------|
   |dataType|arrhythmiaResultData|脉搏波心律失常检测结果类型|
   |totalCount|int类型数据|当前数据类型的数据总条数|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段|
   |startTime|UTC时间，单位：秒|开始时间|
   |ppgIrregularHeartbeat|int类型数据|脉搏波心律失常分析结果： * 1：表示未见异常 * 2：表示疑似早搏 * 3：表示疑似房颤 * 4：表示不规则心率-存在房颤风险 * 5：表示不规则心率-存在早搏风险|
   |saveTime|UTC时间，单位：秒|保存脉搏波心律失常检测结果数据的时间。|
   |measureType|int类型数据|测量类型： * 0：自动测量 * 1：主动测量|
   [表3 result返回值]

   <br />
