# 连接设备

行业App首次连接成功后，如果穿戴设备连接断开了，可调用此接口连接穿戴设备。连接设备前需要开启终端设备侧的蓝牙与位置相关权限，并[注册连接状态监听](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/register-connection-status-listener-0000002338298252)。
> 注意
>
> 1. 设备重连时请保证两次连接间隔时间大于60秒，在60秒内多次重连会触发蓝牙系统限制导致连接功能异常。如出现异常请重新关闭-开启蓝牙恢复。
> 2. SDK版本从2.13.0.102开始：
>    * 连接设备时，如果已有设备处于已连接状态，该设备会断开连接。
>    * 行业App连接过的设备恢复出厂且行业App未删除设备，重新连接设备后设置过的设备信息需要重新设置。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)的[getDeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceConnectClient-android_content_Context-)方法获取[DeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 调用[connectDevice](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800#ZH-CN_TOPIC_0000002648084238__connectDevice-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)连接指定设备。

   ```screen
   // 获取DeviceConnectClient对象
   DeviceConnectClient deviceConnectClient = IndustryWear.getDeviceConnectClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 连接指定设备
   deviceConnectClient.connectDevice(deviceId, new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、23、26|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [**表1**ServiceCallback返回值]
