# 设置睡眠呼吸暂停检测开关

设置穿戴设备的睡眠呼吸暂停检测开关状态。开启睡眠呼吸暂停检测开关后，在用户睡眠期间，穿戴设备将进行睡眠呼吸暂停检测。关闭睡眠呼吸暂停检测开关后，穿戴设备不再进行睡眠呼吸暂停检测。
> 说明
>
> * 调用设置睡眠呼吸暂停检测开关接口前，需确保睡眠呼吸暂停功能已激活。
> * 由于睡眠呼吸暂停功能依赖于科学睡眠功能。因此建议在行业应用中实现如下睡眠呼吸暂停检测开关与[科学睡眠开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-trusleep-switch-0000002338300784)的联动：
>   1. 开启睡眠呼吸暂停检测开关时，如果科学睡眠开关为关，需同步开启科学睡眠开关。
>   2. 关闭科学睡眠开关时，如果睡眠呼吸暂停检测开关为开，需同步关闭睡眠呼吸暂停检测开关。
>
1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置睡眠呼吸暂停检测开关的JSON格式参数。

   ```screen
   {
     "settingKey": "osaSwitch",
     "settingValue": 0
   }
   ```

   |参数|取值|含义|
   |:-----------|:--------|:------------|
   |settingKey|osaSwitch|睡眠呼吸暂停检测开关键值。|
   |settingValue|0|关闭睡眠呼吸暂停检测。|
   |settingValue|1|开启睡眠呼吸暂停检测。|
   [**表1**设置睡眠呼吸暂停检测开关参数]

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置睡眠呼吸暂停检测开关。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于设置睡眠呼吸暂停检测开关的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("settingKey", "osaSwitch");
       jsonObject.put("settingValue", 0);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置睡眠呼吸暂停检测开关
   manageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、2、3、4、5、6、7、12、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [**表2**ServiceCallback返回值]
