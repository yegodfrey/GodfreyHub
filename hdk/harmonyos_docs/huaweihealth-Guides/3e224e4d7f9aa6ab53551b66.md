# 查询逐搏测量数据

穿戴设备提供测量逐搏测量（RRI）能力，用户佩戴设备一段时间后，行业应用可以通过本接口查询穿戴设备上记录的RRI数据。  
![](https://media:301785133845036466)  
RRI监测频率为10分钟测量一次。RRI测量要求用户处于非活动状态，活动状态下可能不出值。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询逐搏测量数据。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryHistoryData方法查询逐搏测量数据
           let data = try await device.queryHistoryData(
               type: .rri,
               startTime: 1778428800,
               endTime: 1778479200
           )

           // 查询逐搏测量数据成功
           print("Succeeded in querying rri, data is \(data)")
       } catch let err as IndustryError {
           // 查询逐搏测量数据失败
           print("Failed to query rri. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   ![](https://media:301785133845072467)  
   查询逐搏测量数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有逐搏测量数据返回\[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)\]，查询成功逐搏测量数据为空返回\[\]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。  
   查询成功返回的逐搏测量数据样例：

   ```
   [
       {
           startTime: 1778473234,
           endTime: 1778473328,
           type: .rri,
           fields: [
               "detailData": [
                   [
                       "timestamp": 1778473234000,
                        "rri": 698,
                        "sqi": 100
                   ],
                   ...
               ]
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:--------|:----|:-|:-----------|
   |timestamp|Int64|毫秒|rri数据发生的时间戳。|
   |rri|Int|-|rri数据值。|
   |sqi|Int|-|rri置信度。|
   [表1 返回逐搏测量数据fields说明]
