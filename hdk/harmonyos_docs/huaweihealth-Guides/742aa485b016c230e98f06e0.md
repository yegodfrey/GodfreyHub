# 查询压力数据

穿戴设备提供压力测量能力，用户测量压力后，行业应用可以通过本接口查询穿戴设备上记录的压力数据。
> 说明
>
> 获取设备的压力数据，需要先在运动健康APP打开压力自动检测开关。打开路径：点击【设备】->点击已连接的【设备卡片】->点击【健康监测】->点击【压力自动检测】->打开页面后，点击【压力自动检测】右侧开关。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询压力数据的ZSON格式的入参数据。

   ```screen
   {
       "item": "stressData"
   }
   ```


3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询压力数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询压力数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "stressData");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询压力数据
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回当天0点到当前所有压力数据，失败时返回错误信息。|
   [**表1**ServiceCallback返回值]


4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含当天0时到当前时间的所有压力数据。

   ```screen
   data样例：
   {
       "stressData":[
       {
           "stressStartTime":1680492389,
           "stressEndTime":16804892445,
           "stressScore":66,
           "stressGrade":3
       },
       {
           "stressStartTime":1680500187,
           "stressEndTime":1680500244,
           "stressScore":43,
           "stressGrade":2
       },
       ...
       ]
   }
   ```

   |返回值|取值|含义|
   |:--------------|:-------|:-----------------------------------------------|
   |stressData|-|具体数据信息列表，不同数据类型包含不同字段。|
   |stressStartTime|long类型数据|开始时间，UTC时间戳，单位：秒。|
   |stressEndTime|long类型数据|结束时间，UTC时间戳，单位：秒。|
   |stressScore|int类型数据|压力分数： * 80-99：偏高 * 60-79：中等 * 30-59：正常 * 1-29：放松|
   |stressGrade|int类型数据|压力等级： * 4：偏高 * 3：中等 * 2：正常 * 1：放松|
   [**表2**data返回值]
