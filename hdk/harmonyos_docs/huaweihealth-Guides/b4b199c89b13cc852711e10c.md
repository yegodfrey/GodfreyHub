# 语言设置和查询

设置穿戴设备的显示语言。穿戴设备首次连接后默认语言为终端设备（iOS手机）系统语言。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setLanguage](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section17734193313419)方法设置设备语言。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()
            
           // 调用Device对象的setLanguage方法设置设备语言
           try await device.setLanguage(language: "zh-CN")

           // 设置设备语言成功
           print("Succeeded in setting language")
       } catch let err as IndustryError {
           // 设置设备语言失败
           print("Failed to set language. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getLanguage](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2669053132512)方法查询设备语言。

   ```screen
   Task {    
       do {
           // 调用Device对象的getLanguage方法查询设备语言
           let language = try await device.getLanguage()

           // 查询设备语言成功    
           print("Succeeded in getting language, language: \(language)")
       } catch let err as IndustryError {
           // 查询设备语言失败
           print("Failed to get language. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
