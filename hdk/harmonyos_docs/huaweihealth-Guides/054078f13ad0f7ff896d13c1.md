# 订阅睡眠状态

订阅和取消订阅穿戴设备佩戴者的睡眠状态。订阅成功后，当穿戴设备佩戴者的睡眠状态变化时返回当前睡眠状态。取消订阅后，不再返回睡眠状态。
> 说明
>
> 支持在穿戴设备熄屏状态下上报睡眠状态。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。


4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section141971612182616)方法订阅睡眠状态。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 睡眠状态回调
       let callback: Callback<IndustryService.EventData> = (eventData: IndustryService.EventData) => {
         console.info(`report event: ${JSON.stringify(eventData)}.`);
       }
       // 调用Device对象的subscribeEvent方法订阅睡眠状态
       device.subscribeEvent(IndustryService.EventType.SLEEP_STATUS_CHANGED_EVENT, callback).then(() => {
         // 订阅睡眠状态成功
         console.info(`Succeeded in subscribing sleepStatusChangedEvent.`);
       }).catch((err: BusinessError) => {
         // 订阅睡眠状态失败
         console.error(`Failed to subscribe sleepStatusChangedEvent. Code is ${err.code}, message is ${err.message}.`);
       })
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```


5. 睡眠状态变化信息在Callback<IndustryService.[EventData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7634104243910)>中处理。睡眠状态变化时eventData中包含事件类型（event）和睡眠状态类型（status）。

   ```screen
   eventData样例：
   {
     event: 'sleepStatusChangedEvent',
     status: 0
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:------------------------|
   |status|0|进入浅睡（LIGHT_SLEEP_STATUS)。|
   |status|1|进入深睡(DEEP_SLEEP_STATUS)。|
   |status|2|进入清醒(AWAKE_STATUS)。|
   |status|3|进入普通睡眠(ASLEEP_STATUS)。|
   |status|4|进入清醒(OTHER_SLEEP_STATUS)。|
   |status|5|疑似入睡(SUSPECTED_SLEEP)。|
   [**表1**睡眠状态类型]


6. 调用[unSubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section29691015152720)方法，取消订阅睡眠状态。

   ```screen
   // 调用Device对象的unSubscribeEvent方法取消订阅睡眠状态。注意：这里的callback和上述睡眠状态回调要为同一个对象
   device.unSubscribeEvent(IndustryService.EventType.SLEEP_STATUS_CHANGED_EVENT, callback).then(() => {
     // 取消订阅睡眠状态成功
     console.info(`Succeeded in unsubscribing sleepStatusChangedEvent.`);
   }).catch((err: BusinessError) => {
     // 取消订阅睡眠状态失败
     console.error(`Failed to unsubscribe sleepStatusChangedEvent. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   > 说明
   >
   > 取消订阅传入的callback，要求和订阅时传入的callback为同一个对象。
