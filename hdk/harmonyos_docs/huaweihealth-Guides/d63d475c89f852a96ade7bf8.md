# 查询每日静息热量消耗目标

穿戴设备提供体重管理功能，功能包括热量缺口评估、热量消耗监测及热量摄入记录，行业应用可以通过本功能查询穿戴设备上记录的每日静息热量消耗目标数据。  
![](https://media:301785133830263230)  
* 查询穿戴设备的静息消耗热量数据，需要先在手表上打开减脂塑型应用。
* 静息热量数据产生时间是00:00:00，因此查询开始需要从00:00:00开始。
* 本接口返回的静息热量值为每日的静息热量消耗目标（如果有运动包括运动后的静息热量消耗）。
* 不支持并发查询静息热量，需等待上一次查询结束后方可进行下一次查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询每日静息热量消耗目标。

   <br />

   ```
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询静息热量数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.BASAL_METABOLISM,
         startTime: 1736524800,
         endTime: 1736527800
       };

       // 调用Device对象的queryHistoryData方法查询静息热量数据
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 查询静息热量数据成功, 打印接口返回的静息热量数据
         console.info(`Succeeded in querying basalMetabolism data, result is ${data}.`);
       }).catch((err: BusinessError) => {
         // 查询静息热量数据失败
         console.error(`Failed to query basalMetabolism data. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   ![](https://media:301785133830299231)  
   查询静息热量接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有静息热量数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)\[\]，查询成功静息热量数据为空返回\[\]，查询失败抛出BusinessError。  
   查询成功返回的静息热量数据样例：

   ```
   [{
       "startTime": 1736524800,
       "endTime": 1736524800,
       "type": "basalMetabolism",
       "fields": {
           "basalMetabolism": 1872
       }
   },...]
   ```

   |返回值|类型|单位|含义|
   |:--------------|:-----|:-|:----------|
   |fields|object|-|包含静息热量数据对象。|
   |basalMetabolism|number|千卡|静息热量。|
