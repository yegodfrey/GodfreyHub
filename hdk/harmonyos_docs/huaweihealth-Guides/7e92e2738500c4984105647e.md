# 查询当天日常活动汇总数据

查询穿戴设备的当天日常活动汇总数据。当用户佩戴穿戴设备进行日常活动后，行业应用可以通过本接口查询穿戴设备上记录的当天日常活动汇总数据。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryTodaySummation](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1516318916132)方法查询当天日常活动汇总数据。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryTodaySummation方法查询当天日常活动汇总数据
           let data = try await device.queryTodaySummation(
               type: .fitness
           )

           // 查询当天日常活动汇总数据成功
           print("Succeeded in querying fitness, data is \(data)")
       } catch let err as IndustryError {
           // 查询当天日常活动汇总数据失败
           print("Failed to query fitness. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   查询成功并且有当天日常活动汇总数据返回[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)]，查询成功当天日常活动汇总数据为空返回[]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。

   查询成功返回的当天日常活动汇总数据样例：

   ```screen
   [
       {
           startTime: 1778428800,
           endTime: 1778470204,
           type: .fitness,
           fields: [
               "totalStep": 100,
               "totalCalorie": 1000,
               "totalDistance": 10,
               "totalStrengthTime": 0,
               "totalHeight": 36
           ]
       }
   ]
   ```

   |返回值|类型|单位|含义|
   |:----------------|:--|:-|:---------|
   |totalStep|Int|-|当前总步数。|
   |totalCalorie|Int|卡|当前总活动卡路里。|
   |totalDistance|Int|米|当前总距离。|
   |totalStrengthTime|Int|分钟|当前中高强度总时长。|
   |totalHeight|Int|米|当前总爬楼高度。|
   [**表1**返回日常活动汇总数据fields说明]
