# 返回码

|场景|含义|值|建议处理措施|
|:--------------|:----------|:--|:--------------------------------|
|通用返回码|处理成功|0|NA|
|通用返回码|通用错误|1|请联系运维人员支持|
|通用返回码|参数无效|2|请检查输入参数|
|通用返回码|接口不支持调用|3|请检查命令合法性 请检查SDK Service端API Level|
|通用返回码|请求超时|4|NA|
|通用返回码|授权证书校验失败|5|请检查证书是否配置正确 请检查网络状态是否良好|
|通用返回码|业务冲突|6|当前正在执行相同的任务，请等当前任务执行完成后再调用接口|
|通用返回码|设备不支持当前数据类型|7|检查数据类型合法性 检查SDK service端Api Level|
|通用返回码|订阅数据返回成功|8|NA|
|通用返回码|正在请求鉴权|9|有鉴权任务正在进行，请等当前鉴权任务执行完成再调用鉴权接口|
|通用返回码|订阅事件提醒|10|NA|
|订阅实时Sensor数据状态码|设备不支持此种传感器|300|NA|
|订阅实时Sensor数据状态码|设备未佩戴或已解除佩戴|303|数据需要佩戴后订阅或上报|
|设备管控与设备事件状态码|正在测量中|401|NA|
|设备管控与设备事件状态码|测量结束|402|NA|
|设备管控与设备事件状态码|测量取消|403|用户主动在设备上取消了本次测量|
|设备管控与设备事件状态码|无法测量|404|穿戴设备上有更高优先级的功能正在进行中|
|设备管控与设备事件状态码|未佩戴|405|请佩戴上穿戴设备|
|设备管控与设备事件状态码|佩戴姿势不正确|406|请检查佩戴姿势重新佩戴后再调用|
|设备管控与设备事件状态码|测量超时|407|超过五分钟仍未收到设备上报的测量状态|
|设备管控与设备事件状态码|测量结果异常|408|测量上报的结果不正常，测量的温度或外界环境温度异常|
|设备管控与设备事件状态码|通话等待|409|正在通话状态中，请等待测量结果|
|设备管控与设备事件状态码|测量业务冲突|410|手机侧SDK正在拉起血氧或体温测量|
