# 订阅心率数据

订阅和取消订阅穿戴设备佩戴者的心率数据。订阅成功后，当设备侧产生心率数据时返回心率数据。取消订阅后，不再返回心率数据。
> 说明
>
> * 解除佩戴后，设备会上报一次255。
> * 设备被拿起时，会自动测量，如果设备发现未佩戴设备，或者佩戴姿势不对，会上报255。
> * 在心率测量方式设置为智能的情况下，如果设备处于低活动量、中活动量、中低活动量的状态下，每10分钟上报一次心率数据。
> * 心率数据上报，设备侧低功耗上报，即订阅心率数据后，熄屏状态下不上报，亮屏状态下才上报。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅心率数据的ZSON格式的入参数据。

   ```screen
   {
       "item": "heartRate"
   }
   ```


3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅心率数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅心率数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "heartRate");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅心率数据
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   };
   deviceManageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、8|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；订阅成功后，在佩戴设备的情况下，每5s上报一次心率。|
   [**表1**ServiceCallback返回值]


4. 订阅操作的结果和心率数据在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；设备产生心率数据时返回statusCode为8，data数据中包含心率数据。

   ```screen
   data样例：
   {
       "heartRate":80,
   }
   ```

   |返回值|取值|含义|
   |:--------|:------|:------------|
   |heartRate|int类型数据|当前心率，255为无效值。|
   [**表2**data返回订阅信息]


5. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅心率数据。

   ```screen
   // 调用unSubscribe方法取消订阅心率数据。
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   deviceManageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```
