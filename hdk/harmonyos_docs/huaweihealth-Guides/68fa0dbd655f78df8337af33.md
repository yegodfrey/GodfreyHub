# 开发环境

#### HarmonyOS 5及以上

* DevEco Studio 5.0.3.910及以上
* 您的应用应满足以下条件：
* compatibleSdkVersion: 5.0.0(12)  

#### HarmonyOS 3.1/4.0及以下

* DevEco Studio 3.0.0.800至3.1.0.501（含两端版本）
* 您的应用应满足以下条件：
  * compileSdkVersion：7
* compatibleSdkVersion：6  

#### Android手机侧

* Android Studio 2024.2.1及以上
* 您的应用应满足以下条件：
  * minSdkVersion 24及以上
* compileSdk 35  

#### iOS手机侧

* Xcode 15及以上
* 您的应用应满足以下条件：
* 最低支持iOS版本13.4及以上
