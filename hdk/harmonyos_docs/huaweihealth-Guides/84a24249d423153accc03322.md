# 设置语言和单位制

设置穿戴设备的显示语言和运动数据的单位制。  
![](https://media:301785133821811109)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。

<!-- -->

* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的语言给穿戴设备。
* 设置的语言不是支持的标准语言代码，会出现下列现象：
* 接口调用成功并返回状态码0，在智能模式下语言默认设置为英文，在超长续航模式下语言默认设置为中文。  
![](https://media:301785133821849110)  
* [智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002478257024#ZH-CN_TOPIC_0000002647924598__li1717645195615)运动联动过程中请勿调用此接口修改语言和单位制，否则会导致联动暂停。
* 应用设置语言成功后，应用会重启。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于设置语言和单位制的ZSON格式的入参数据。

   <br />

   ```
   {
       "settingKey": "languageAndUnit",
       "settingValue": {
           "language": "zh-CN",
           "unit": 0
       }
   }
   ```

   |参数|取值|含义|
   |:-----------|:----------------------------------------------------|:-------------|
   |settingKey|languageAndUnit|语言和单位制键值。|
   |settingValue|包含以下参数：language、unit|语言和单位制内容。|
   |language|* 标准的语言代码，例如："zh-CN" 、"en-US" <!-- --> * 要求：字符串长度不超过8|设备显示的语言。|
   |unit <br />|0|设备显示的数据单位制：公制。|
   |unit <br />|1|设备显示的数据单位制：英制。|
   [表1 设置语言和单位制参数]

   <br />

3. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section447217361429)方法设置语言和单位制。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于设置语言和单位制的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   ZSONObject valueObject = new ZSONObject();
   try {
       zsonObject.put("settingKey", "languageAndUnit");
       valueObject.put("language", "zh-CN");
       valueObject.put("unit", 0);
       zsonObject.put("settingValue", valueObject);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置语言和单位制
   deviceManageClient.set(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、7|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回空字符串，接口调用失败时返回错误信息。|
   [表2 ServiceCallback 返回值]

   <br />
