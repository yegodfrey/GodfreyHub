# 单位制设置与查询

设置与查询穿戴设备的运动数据的单位制。当用户佩戴穿戴设备进行运动时，穿戴设备会根据当前设置的单位制显示运动数据（例如，在穿戴设备上开启户外跑步运动，当单位制设置为公制后，距离单位为km；当单位制设置为英制后，距离单位为mi）。
> 注意
>
> * 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
> * 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置与查询请保持在同一侧的SDK。
> * 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的单位制给穿戴设备。
> 说明
>
> 在未设置单位制时，查询返回错误码9。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section45051114675)方法设置单位制。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from 'industrysdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 调用Device对象的setSettingInfo方法设置单位制
       device.setSettingInfo(IndustryService.SettingType.UNIT, IndustryService.Unit.Metric).then(() => {
         // 设置单位制成功
         console.info('Succeeded in setting unit.');
       }).catch((err: BusinessError) => {
         // 设置单位制失败
         console.error(`Failed to set unit. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section16701734145419)方法查询单位制。

   ```screen
   // 调用Device对象的getSettingInfo方法查询单位制
   device.getSettingInfo(IndustryService.SettingType.UNIT).then((result: IndustryService.Unit) => {
     // 查询单位制成功，打印返回的单位制
     console.info(`Succeeded in getting unit, result is ${result}.`);
   }).catch((err: BusinessError) => {
     // 查询单位制失败
     console.error(`Failed to get unit. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
