# 订阅血压数据更新

订阅和取消订阅穿戴设备的血压数据更新事件。订阅成功后，当穿戴设备测量血压结束后，如果结束时间在订阅时间范围内，上报血压数据更新事件。取消订阅后，不再上报血压数据更新事件。  
![](https://media:301785133843676436)  
当前接口仅支持具备血压测量功能的行业版本穿戴设备。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于订阅或取消订阅血压数据更新的JSON格式参数。

   <br />

   ```
   {
       "item": "bloodPressureUpdateEvent",
       "value": {
           "onDutyTime": "0000",
           "offDutyTime": "2400"
       }
   }
   ```

   |参数|取值|含义|
   |:----------|:---------------------------------------------------------------------------------|:-------------|
   |onDutyTime|长度为4，格式为"HHmm"的24小时制时分字符串。前两个字符代表小时，后两个字符代表分钟，最大为"2400"，最小为"0000"，例如："0800"、"2000"|订阅开始时间（24小时制）。|
   |offDutyTime|长度为4，格式为"HHmm"的24小时制时分字符串。前两个字符代表小时，后两个字符代表分钟，最大为"2400"，最小为"0000"，例如："0800"、"2000"|订阅结束时间（24小时制）。|
   [表1 订阅或取消订阅血压数据更新参数]

   ![](https://media:301785133843705437)  
   offDutyTime小于onDutyTime时，说明为跨天的订阅时间。

   <br />

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅血压数据更新。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于订阅或取消订阅血压数据更新的JSON格式的入参数据 
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject valueObject = new JSONObject();
       valueObject.put("onDutyTime", "0000");
       valueObject.put("offDutyTime", "2400");
       jsonObject.put("item", "bloodPressureUpdateEvent");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅血压数据更新
   manageClient.subscribe(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:------------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、8、10、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|订阅成功时返回订阅id，订阅失败时返回错误信息，血压数据更新时返回空字符串。|
   [表2 ServiceCallback返回值]

   <br />

5. 调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅血压数据更新提醒。

   <br />

   ```
   // 调用unSubscribe方法取消订阅血压数据更新
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   ![](https://media:301785133843733438)  
   取消订阅成功条件：
   * 取消订阅时要求输入的解订阅参数和订阅时的参数一致。
   * 取消订阅时传入的ServiceCallback，要求和订阅时传入的ServiceCallback为同一个对象。

   <br />
