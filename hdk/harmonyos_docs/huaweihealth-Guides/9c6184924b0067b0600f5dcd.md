# 查询血氧数据

穿戴设备提供血氧测量能力，用户佩戴穿戴设备测量血氧后，行业App可以通过本接口查询穿戴设备上记录的血氧数据。  
![](https://media:301785133840437390)  
需要调用此接口查询血氧数据时，请提前[开启血氧自动检测开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-automatic-spo2-measurement-switch-0000002624549033)，否则会返回空数据。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询血氧数据。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryHistoryData方法查询血氧数据
           let data = try await device.queryHistoryData(
               type: .spo2,
               startTime: 1778428800,
               endTime: 1778463000
           )

           // 查询血氧数据成功
           print("Succeeded in querying spo2, data is \(data)")
       } catch let err as IndustryError {
           // 查询血氧数据失败
           print("Failed to query spo2. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   ![](https://media:301785133840464391)  
   查询血氧数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有血氧数据返回\[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)\]，查询成功血氧数据为空返回\[\]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。  
   查询成功返回的血氧数据样例：

   ```
   [
       {
           startTime: 1778462820,
           endTime: 1778462820,
           type: .spo2,
           fields: [
               "spo2": 96
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:---|:--|:-|:--------------------|
   |spo2|Int|%|血氧值，例如：99代表血氧饱和度为99%。|
   [表1 返回血氧数据fields说明]
