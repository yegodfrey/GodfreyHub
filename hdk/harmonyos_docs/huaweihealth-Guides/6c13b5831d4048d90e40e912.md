# 注册账号及申请账号服务

1. 注册成为企业开发者并完成实名认证，注册链接详细操作请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
2. 登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/)，点击进入"管理中心"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/Sk0Q4IXdSBWoml3WhmCuHA/zh-cn_image_0000002678004473.png?HW-CC-KV=V1&HW-CC-Date=20260909T183224Z&HW-CC-Expire=31536000000&HW-CC-Sign=8ED17CCABB3D301C7D4E5DA2E5CD62E77F3A3AD69AFE3559A94AD236B0DC3CD5 "点击放大")

3. 点击"应用服务 > 上架及推广服务 > AppGallery Connect "卡片。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/UYeQtqAZQf2PMzrlvqfckA/zh-cn_image_0000002648084594.png?HW-CC-KV=V1&HW-CC-Date=20260909T183224Z&HW-CC-Expire=31536000000&HW-CC-Sign=DD8499FCAE47F4A912C5F85C617CB6244CA4BBE1C829199ED486CAA8C4465985)

   > 说明
   >
   > 如果无"AppGallery Connect"卡片。请点击"上架及推广服务"右侧![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/bouuL7aDTKG9yEsRJH9S7g/zh-cn_image_0000002647924712.gif?HW-CC-KV=V1&HW-CC-Date=20260909T183224Z&HW-CC-Expire=31536000000&HW-CC-Sign=FADE174F50248FBF5B5D1976AC71D6BFECEDC7113A1F9244C5580D8BCE47769D)图标添加卡片。
4. 点击"开发与服务"，进入项目页面。点击"添加项目"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/ZZ6ACjbeT4CSPbYKL_Xz7A/zh-cn_image_0000002678164315.png?HW-CC-KV=V1&HW-CC-Date=20260909T183224Z&HW-CC-Expire=31536000000&HW-CC-Sign=84747B7E1C8D2D3CFB15A1FF575FE331AF0F4AFE0263ACDD50AFD0F939C72D20 "点击放大")

5. 输入项目名称，点击"完成"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/Ql_HgPJpR86nTHeKGpdr5Q/zh-cn_image_0000002648084598.png?HW-CC-KV=V1&HW-CC-Date=20260909T183224Z&HW-CC-Expire=31536000000&HW-CC-Sign=D61F00F01FB612357052E83E12032AD24206128389F4928F2EF72C33BD2E3886)

6. 在项目中添加应用。选择"iOS"，填写软件包ID（[Bundle ID](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-bundle-id-0000002594269386)）和应用名称。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/JzsWieUcQSGMBVAY2Wm7TA/zh-cn_image_0000002678004477.png?HW-CC-KV=V1&HW-CC-Date=20260909T183224Z&HW-CC-Expire=31536000000&HW-CC-Sign=4F76A325C5681A96A07B1E4EEE1968D4815B6345261FBF5518F30FA4CC0203EC "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/eFRy0oz_Rzuwzk8q0WFdMQ/zh-cn_image_0000002678004479.png?HW-CC-KV=V1&HW-CC-Date=20260909T183224Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D0780C05BE4542A0451BCA91A90EA406AA4EA672C12BDD1EEFC89262892EF55 "点击放大")

7. 点击"确认"，即可完成"iOS应用"的创建，接下来请[申请Health Industry SDK服务](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/apply-for-health-industry-sdk-service-0000002594109482)。
