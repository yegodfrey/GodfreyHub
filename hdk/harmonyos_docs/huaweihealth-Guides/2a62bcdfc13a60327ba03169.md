# 设置血压周期测量计划

穿戴设备提供血压测量能力，行业App可以通过本接口设置穿戴设备的血压周期测量计划。
> 说明
>
> 此接口仅在支持单次血压测量的穿戴设备上可用，当前支持HUAWEI WATCH B9-D10和HUAWEI WATCH H9D20设备。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置血压周期测量计划的JSON格式参数。

   ```screen
   {
     "settingKey": "bloodPressureMeasurePlan",
     "settingValue": {
         "wakeUpTime":"0700",
         "beforeSleepTime":"2200",
         "enabled":1,
         "daysOfWeek":[1,2,6],
         "planTimes":["0745","0840","1433"]
     }
   }
   ```

   |参数|取值|含义|
   |:--------------|:------------------------------------------------------------------|:--------------------------------------------------------------------|
   |settingKey|bloodPressureMeasurePlan|血压周期测量计划键值。|
   |settingValue|包含以下参数：wakeUpTime、beforeSleepTime、enabled、daysOfWeek、planTimes|血压周期测量计划内容。|
   |wakeUpTime|格式为HHmm的24小时制的时刻字符串，前两个字符代表小时，后两个字符代表分钟，最大为"0900"，最小为"0600"|起床后测量时间，取值范围6:00~9:00。|
   |beforeSleepTime|格式为HHmm的24小时制的时刻字符串，前两个字符代表小时，后两个字符代表分钟，可跨天，当天最小为"2000"，跨天最大为"0159"|睡前测量时间，取值范围20:00~1:59。|
   |enabled|int类型|是否提醒，1：提醒，0：不提醒。|
   |daysOfWeek|int类型数组|计划提醒的星期，取值范围1~7。|
   |planTimes|格式为HHmm的24小时制的时刻字符串数组，前两个字符代表小时，后两个字符代表分钟|自定义测量计划时间，取值范围wakeUpTime~beforeSleepTime，测量计划（包含起床和睡前计划）时间间隔不小于45min。|
   [**表1**设置血压周期测量计划参数]

   > 注意
   > * 自定义测量计划时间最多有8个。
   > * 自定义测量计划时间不能早于起床测量时间且不能晚于睡前测量时间。
   > * 如果开启了动态血压测量计划，设置血压周期测量计划不会提醒单次血压测量。

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置血压周期测量计划。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构建用于设置血压周期测量计划的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("settingKey", "bloodPressureMeasurePlan");
       JSONArray settingJson = new JSONArray();
       settingJson.put("wakeUpTime", "0700");
       settingJson.put("beforeSleepTime", "2200");
       settingJson.put("enabled", 1);
       JSONArray daysOfWeekArray = new JSONArray();
       daysOfWeekArray.put(1);
       daysOfWeekArray.put(2);
       daysOfWeekArray.put(6);
       settingJson.put("daysOfWeek", daysOfWeekArray);
       JSONArray planTimesArray = new JSONArray();
       daysOfWeekArray.put("0745");
       daysOfWeekArray.put("0840");
       daysOfWeekArray.put("1433");
       settingJson.put("planTimes", planTimesArray );
       jsonObject.put("settingValue", settingJson);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置血压周期测量计划
   deviceManageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [**表2**ServiceCallback返回值]
