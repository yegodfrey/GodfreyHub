# 查询压力数据

穿戴设备提供压力测量能力，用户佩戴穿戴设备测量压力后，行业App可以通过本接口查询穿戴设备上记录的压力数据。  
![](https://media:301785133838103353)  
需要调用此接口查询压力数据时，请提前开启[情绪/压力自动检测开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-emotion-auto-monitor-switch-0000002624549035)，否则会返回空数据。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询压力数据。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           let device = try IndustryService.shared().getDeviceManager().getDevice()
           let data = try await device.queryHistoryData(
               type: .stress,
               startTime: 1778428800,
               endTime: 1778464800
           )
           print("Succeeded in querying stress, data is \(data)")
       } catch let err as IndustryError {
           print("Failed to query stress. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   ![](https://media:301785133838148354)  
   查询压力数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有压力数据返回\[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)\]，查询成功压力数据为空返回\[\]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。  
   查询成功返回的压力数据样例：

   ```
   [
       {
           startTime: 1778463459,
           endTime: 1778463515,
           type: .stress,
           fields: [
               "duration": 56.0,
               "grade": 2,
               "score": 48
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:-------|:-----------|:-|:---------------------------------------------------|
   |duration|TimeInterval|秒|压力采样持续时长。|
   |grade|Int|-|压力等级： * 1：放松 * 2：正常 * 3：中等 * 4：偏高|
   |score|Int|-|压力得分： * 80-99: 偏高 * 60-79: 中等 * 30-59: 正常 * 1-29: 放松|
   [表1 返回压力数据fields说明]
