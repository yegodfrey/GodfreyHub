# 配置界面主题

在使用Health IndustryConnectionUI SDK时，开发者在开发时需要使用与Health IndustryConnectionUI SDK一致的主题，以保证界面显示正常。

1. 打开**AndroidManifest.xml**文件，在"application"中修改App主题。

   ```screen
   <application android:theme="@style/Theme.IndustryConnectionUI">
   ```

   **图1**设置App主题   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/ci1D9qLFRyq5-fe0hkloYQ/zh-cn_image_0000002647924714.png?HW-CC-KV=V1&HW-CC-Date=20260909T151904Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6B5D0B9AEE85EEE702B8E36586409394EC149A8502F80AF56D315110E4AC7AB "点击放大")

2. 打开代码java文件，在代码中动态更改状态栏显示图标的颜色，以适配普通模式与深色模式，可参考如下示例。

   ```screen
   // 状态栏图标颜色适配
   int uiMode = this.getResources().getConfiguration().uiMode;
   if ((uiMode & Configuration.UI_MODE_NIGHT_MASK) == Configuration.UI_MODE_NIGHT_NO) {
       getWindow().getDecorView().setSystemUiVisibility(View.SYSTEM_UI_FLAG_LIGHT_STATUS_BAR);
   }
   ```
