# 订阅设备充电状态

订阅和取消订阅穿戴设备的充电状态。订阅成功后，当穿戴设备的充电状态变化时返回当前充电状态。取消订阅后，不再返回充电状态。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section484944212315)方法订阅设备充电状态。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的subscribeEvent方法订阅设备充电状态
           let uuid = try await device.subscribeEvent(type: .chargeStatusChangedEvent) { eventData in
               print("Event report. Event: \(eventData.event), status: \(eventData.status)")
           }

           // 订阅设备充电状态成功
           print("Succeeded in subscribing chargeStatusChangedEvent")
       } catch let err as IndustryError {
           // 订阅设备充电状态失败
           print("Failed to subscribe chargeStatusChangedEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 设备充电状态在(EventData -> Void)闭包中处理。设备充电状态变化时eventData中包含事件类型（event）和设备充电状态（status）。

   ```screen
   eventData样例：
   {
       event: "chargeStatusChangedEvent",
       status: 2
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:-----|
   |status|1|充电开始。|
   |status|2|充电结束。|
   |status|3|电量已充满。|
   [**表1**设备充电状态]

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[unsubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section686172218408)方法取消订阅设备充电状态。

   ```screen
   Task {
       do {
           // 调用Device对象的unsubscribeEvent方法取消订阅设备充电状态
           try await device.unsubscribeEvent(type: .chargeStatusChangedEvent, subscribeId: uuid)

           // 取消订阅设备充电状态成功
           print("Succeeded in unsubscribing chargeStatusChangedEvent")
       } catch let err as IndustryError {
           // 取消订阅设备充电状态失败
           print("Failed to unsubscribe chargeStatusChangedEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   > 说明
   >
   > 取消订阅传入的uuid，要求和订阅返回的uuid为同一个对象。
