# 获取穿戴设备侧应用版本号

行业App获取穿戴设备侧应用版本号。  
![](https://media:301785133824373149)  
* [智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)在超长续航模式下不支持获取穿戴设备侧应用版本号。
* 若要使用获取穿戴设备侧应用版本号功能，穿戴设备侧需安装相对应的通信应用，参考[穿戴设备侧应用开发](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/version-change-history-0000001119036892)。
* 仅支持[智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于获取穿戴设备侧应用版本号的JSON格式参数。

   <br />

   ```
   {
       "item": "p2pGetAppVersion",
       "value": {
           "peerPkgName": "com.huawei.aa"
       }
   }
   ```

   |参数|取值|含义|
   |:----------|:---------------|:-----------------------------------------------------------------------------------------------------------------|
   |item|p2pGetAppVersion|获取穿戴侧应用的版本号|
   |peerPkgName|-|穿戴设备侧[应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)|
   [表1 获取穿戴设备侧应用版本号参数]

   <br />

4. 调用[send](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__send-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法向穿戴设备侧应用获取版本号。

   <br />

   ```
   // 步骤1 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 步骤2 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 步骤3 创建获取穿戴设备侧应用版本号的JSON对象
   JSONObject jsonObject = new JSONObject();
   JSONObject valueObject = new JSONObject();
   try {
       valueObject.put("peerPkgName", "com.huawei.aa");
       jsonObject.put("item", "p2pGetAppVersion");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 步骤4 调用send方法获取穿戴设备侧应用版本号
   deviceManageClient.send(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:--------------------|:-------------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、26、30、200|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码和设备间消息通信状态码|
   |result|-|接口调用成功时返回版本号信息，失败时返回错误信息|
   [表2 ServiceCallback返回值]

   ```
   result样例：
   {
       "versionCode": 10001
   }
   ```

   |返回值|含义|
   |:----------|:----------|
   |versionCode|穿戴设备侧应用的版本号|
   [表3 result返回值]

   <br />
