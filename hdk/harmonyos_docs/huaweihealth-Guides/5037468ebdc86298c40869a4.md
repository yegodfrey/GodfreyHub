# 订阅睡眠状态

订阅和取消订阅穿戴设备佩戴者的睡眠状态。订阅成功后，当穿戴设备佩戴者的睡眠状态变化时返回睡眠状态。取消订阅后，不再返回睡眠状态。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅睡眠状态的ZSON格式的入参数据。

   ```screen
   {
       "item": "sleepStatus"
   }
   ```


3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅设备睡眠状态。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅睡眠状态的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "sleepStatus");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅设备睡眠状态
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   };
   deviceManageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、8|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；订阅成功后，睡眠状态变化时返回睡眠状态。|
   [**表1**ServiceCallback返回值]


4. 订阅操作的结果和睡眠状态在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；设备睡眠状态变化时返回statusCode为8，data数据中包含睡眠状态。

   ```screen
   data样例：
   {
       "sleepStatus":1
   }
   ```

   |返回值|取值|含义|
   |:----------|:-|:------------------------|
   |sleepStatus|0|进入浅睡（LIGHT_SLEEP_STATUS)。|
   |sleepStatus|1|进入深睡(DEEP_SLEEP_STATUS)。|
   |sleepStatus|2|进入清醒(AWAKE_STATUS)。|
   |sleepStatus|3|进入普通睡眠(ASLEEP_STATUS)。|
   |sleepStatus|4|进入清醒(OTHER_SLEEP_STATUS)。|
   |sleepStatus|5|疑似入睡(SUSPECTED_SLEEP)。|
   [**表2**data返回订阅信息]


5. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅睡眠状态。

   ```screen
   // 调用unSubscribe方法取消订阅睡眠状态。
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   deviceManageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```
