# 查询活动记录

穿戴设备提供活动记录能力，用户活动后，行业应用可以通过本接口查询穿戴设备上的活动记录。活动记录包含：活动热量、锻炼时长、活动小时数和对应的目标值。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询活动记录数据。

   ```screen
   Task {
       do {
           let device = try IndustryService.getDeviceManager().getDevice()
           let data = try await device.queryHistoryData(
               type: .activityRecord,
               startTime: 1778299200,
               endTime: 177829980
           )
           print("Succeeded in querying activityRecord, data is \(data)")
       } catch let err as IndustryError {
           print("Failed to query activityRecord. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   > 说明
   >
   > 查询活动记录数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和当前时间间隔不超过7天（包含当天）。

   查询成功并且有活动记录数据返回[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)]，查询成功活动记录数据为空返回[]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。

   查询成功返回的活动记录数据样例：

   ```screen
   [
       {
           startTime: 1778428800,
           endTime: 1778515199,
           type: .activityRecord,
           fields: [
               "calories": 1560,
               "exerciseDuration": 0,
               "standHours": 1,
               "caloriesGoal": 220000，
               "exerciseDurationGoal": 30,
               "standHoursGoal": 16
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:-------------------|:--|:-|:--------|
   |calories|Int|卡|活动热量。|
   |exerciseDuration|Int|分钟|锻炼时长。|
   |standHours|Int|小时|活动小时数。|
   |caloriesGoal|Int|卡|活动热量目标值。|
   |exerciseDurationGoal|Int|分钟|锻炼时长目标值。|
   |standHoursGoal|Int|小时|活动小时数目标值。|
