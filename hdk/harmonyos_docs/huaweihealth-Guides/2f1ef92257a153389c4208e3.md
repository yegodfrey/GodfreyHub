# 血氧异常告警设置与查询

设置与查询穿戴设备的血氧异常告警开关状态和告警阈值（单位：%）。开启血氧异常告警开关后，当穿戴设备连续三次检测到血氧值低于告警阈值时，将产生血氧异常的告警。关闭血氧异常告警开关后，穿戴设备不再产生血氧异常的告警。穿戴设备首次连接后默认关闭血氧异常告警开关。  
![](https://media:301785133838042352)  
* 如果需要启用血氧异常告警，请提前开启血氧自动检测开关，参见[血氧自动检测开关设置与查询](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-automatic-spo2-measurement-switch-0000002624549033)。
* 当关闭血氧异常告警开关时，若设置了告警阈值，则不会对告警阈值进行校验，查询返回告警开关为false，告警阈值为设置的告警阈值；若未设置告警阈值，查询返回告警开关为false，告警阈值为nil。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setAlertSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section89289364016)方法设置血氧异常告警开关和阈值。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 构造血氧异常告警开关和阈值参数
           let alertSetting = AlertSetting(switchValue: true, threshold: 90)

           // 调用Device对象的setAlertSwitch方法设置血氧异常告警开关和阈值
           try await device.setAlertSwitch(type: .spO2Alert, alertSwitchValue: alertSetting)

           // 设置血氧异常告警开关和阈值成功
           print("Succeeded in setting spO2Alert")
       } catch let err as IndustryError {
           //设置血氧异常告警开关和阈值失败
           print("Failed to set spO2Alert. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getAlertSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section17401123111313)方法查询血氧异常告警开关和阈值。

   <br />

   ```
   Task {
       do {
           // 调用Device对象的getAlertSwitch方法查询血氧异常告警开关和阈值
           let alertSetting = try await device.getAlertSwitch(type: .spO2Alert)

           // 查询血氧异常告警开关和阈值成功
           print("Succeeded in getting spO2Alert, switchValue: \(alertSetting.switchValue), threshold: \ (String(describing: alertSetting.threshold))")
       } catch let err as IndustryError {
           //查询血氧异常告警开关和阈值失败
           print("Failed to get spO2Alert. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
