# 恢复穿戴设备出厂设置

恢复设备到出厂设置。恢复设备出厂将清空设备中的设置和运动健康数据。
> 说明
>
> 穿戴设备主动进行恢复出厂设置（不通过行业App下发）后，请在行业App删除设备后重新添加设备。恢复出厂后设备所有数据已被清除，会严重影响SDK功能的使用。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[factoryReset](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section13462134914918)方法恢复设备到出厂设置。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的factoryReset方法恢复设备出厂设置
           try await device.factoryReset(mode: .resetDevice)
        
           // 恢复设备出厂设置成功
           print("Succeeded in factory reset")
       } catch let err as IndustryError {
           // 恢复设备出厂设置失败
           print("Failed to factory reset. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
