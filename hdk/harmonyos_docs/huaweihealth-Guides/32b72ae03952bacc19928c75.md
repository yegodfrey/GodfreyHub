# 查询情绪数据

穿戴设备提供情绪测量能力，用户佩戴穿戴设备测量情绪后，行业应用可以通过本接口查询穿戴设备上记录的情绪数据。
> 说明
>
> * 获取穿戴设备的情绪数据，请提前开启情绪/压力自动检测开关，参见[情绪/压力自动检测开关设置与查询](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-emotion-switch-0000002526499302)。
> * 需要采集情绪数据时，建议在查询时间段内佩戴穿戴设备超过30分钟，否则穿戴设备侧可能返回空数据。
> * 不支持并发查询情绪数据，需等待上一次查询结束后方可进行下一次查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询情绪数据。

   ```screen
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询情绪数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.EMOTION,
         startTime: 1736580274,
         endTime: 1736580330
       };

       // 调用Device对象的queryHistoryData方法查询情绪数据
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 查询情绪数据成功, 打印接口返回的情绪数据
         console.info(`Succeeded in querying emotion data, result is ${data}.`);
       }).catch((err: BusinessError) => {
         // 查询情绪数据失败
         console.error(`Failed to query emotion data. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   > 说明
   >
   > 查询情绪数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   > * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有情绪数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)[]，查询成功情绪数据为空返回[]，查询失败抛出BusinessError。

   查询成功返回的情绪历史数据样例：

   [{
       "startTime": 1736580274,
       "endTime": 1736580330,
       "type": "emotion",
       "fields": {
   	"emotionStatus": 2,
   	"valenceCharacter": 59.87324142456055,
   	"arousalCharacter": 9.810883522033691,
       }
   },
   {
       "startTime": 1736580154,

       "fields": {
   	"emotionStatus": 1,
   	"valenceCharacter": 54.87324142456055,
   	"arousalCharacter": 7.810883522033691,

   |返回值|类型|单位|含义|
   |:---------------|:-----|:-|:-----------------------------------------------|
   |fields|object|-|包含情绪数据对象。|
   |emotionStatus|number|-|情绪值： * 1：负面情绪，不愉快 * 2：平静情绪，平和 * 3：积极情绪，愉快|
   |valenceCharacter|number|-|效价特征，代表人情绪的效价维度，较低代表情绪偏负面，较高代表情绪偏正面，有效范围[0, 100]|
   |arousalCharacter|number|-|唤醒特征，代表人的生理性激活的水平，越大代表激活程度越高，有效范围[0, 100]|
