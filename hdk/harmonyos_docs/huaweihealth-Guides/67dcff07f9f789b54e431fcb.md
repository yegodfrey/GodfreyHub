# 定制简介

企业通过HEM和VMALL的政企定制服务平台，调用开放的企业定制能力，可以满足企业设备品牌及营销定制化需求，实现在华为行业版穿戴设备上定制适合本企业的个性化内容，包括行业穿戴设备的开机logo、开机动画、表盘、鸿蒙应用、企业信息等内容。

**HEM企业定制**

目前HEM定制服务平台支持企业定制的行业穿戴有轻量级智能穿戴设备B5系列（B5-536 / B5-532 / B5-736）、华为擎云H5系列（H5546 / H5556 / H5756）、华为擎云H9系列（H9D20）、华为擎云H3系列（H3540）、B9系列（B9-D10）；智能穿戴设备B7系列（B7-536 / B7-738）和华为擎云H7系列（H7546）；智能手环系列（HA580，HA590, HA5A0）。以上行业设备支持开机logo，表盘、企业信息，其中智能表B7、H7系列还支持预置鸿蒙应用、对预置应用进行保活和自启动、开机动画等。HEM企业定制拥有简洁的定制页面，帮助企业更快完成定制，用户体验更加便捷。

定制过程和介绍请参考[HEM业务](https://developer.huawei.com/business/cn/doc/distribution/HEM/hem-introduction-0000001144034694)

**VMALL企业定制**

目前VMALL定制服务平台支持企业定制的行业穿戴有B5系列（B5-536 / B5-532）、华为擎云H5系列（H5546 / H5556 / H5756）、华为擎云H9系列（H9D20）、华为擎云H3系列（H3540）、B9系列（B9-D10）和手环系列（HA580 / HA590 / HA5A0），VMALL企业定制拥有规范的定制流程和健全的反馈机制。
