# 订阅实时心率

订阅和取消订阅穿戴设备的实时心率数据。订阅成功后，当开启实时心率联动开关时上报实时心率数据。取消订阅后，不再上报实时心率数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于订阅或取消订阅实时心率的JSON格式参数。

   <br />

   ```
   {
       "item":"realtimeHeartRateData"
   }
   ```

   <br />

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅实时心率。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于订阅或取消订阅实时心率的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "realtimeHeartRateData");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅实时心率
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   };
   manageClient.subscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、8、300、303|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回空字符串，失败时返回错误信息，已开启[心率联动](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-realtime-heart-rate-0000002338141040)时返回实时心率信息。|
   [表1 ServiceCallback返回值]

   ![](https://media:301785133845427474)  
   订阅实时心率数据的ServiceCallback不仅会返回订阅操作的结果，另外还会返回后续订阅的事件上报时的数据。

   <br />

5. 订阅操作的结果和实时心率数据更新事件变化信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，result为空字符串；失败时statusCode返回错误码，result返回对应错误信息；设备上报实时心率时返回statusCode为8，result数据中包含心率数据时间戳和心率值。

   <br />

   ```
   result样例：
   {
       "timeStamp":1644544380,
       "heartRate":86
   }
   ```

   |返回值|取值|含义|
   |:--------|:----------|:-----------|
   |timeStamp|UTC时间戳，单位：秒|心率数据时间点。|
   |heartRate|int类型数据|心率值，单位：次/分钟。|
   [表2 result返回值]

   ![](https://media:301785133845546475)  
   * 心率传感器采集周期1000ms，上报周期1000ms左右，1次1个数据，代表每分钟心跳次数。
   * 连续分钟上报的心率值有可能相同，实际上报周期有可能因设备原因增加或者减少。

   <br />

6. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅实时心率数据。

   <br />

   ```
   // 调用unSubscribe方法取消订阅实时心率数据
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   ![](https://media:301785133845579476)  
   取消订阅成功条件：
   * 取消订阅时要求输入的解订阅参数和订阅时的参数一致。
   * 取消订阅时传入的ServiceCallback，要求和订阅时传入的ServiceCallback为同一个对象。

   <br />
