# 应用鉴权

行业应用调用行业SDK接口时，行业SDK会进行权限校验，只有权限校验通过之后才能调用相关接口。  
![](https://media:301785133816995037)  
* 鉴权需要访问网络，请确保设备已连接网络（连接网络方式：1、手表连接WIFI；2、手表配对运动健康APP共享手机网络；3、手表开通esim使用esim网络）。
* 设置证书路径前请先把[证书](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/apply-for-health-industry-sdk-service-0000002447189737#ZH-CN_TOPIC_0000002678164053__li16905940101212)放到行业App开发工程的src/main/resources/rawfile目录下（如没rawfile目录，需自行创建），证书文件的后缀为.cer。
* 开发者测试证书存在有效期限制，行业用户测试证书转商用证书后需重新进行一次鉴权操作。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getServiceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#ZH-CN_TOPIC_0000002648084254__getServiceClient-android_content_Context-)方法，获取[ServiceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/servicemanageclient-0000002412617972)对象。
2. 调用[getAuthorization](https://developer.huawei.com/consumer/cn/doc/health-References/servicemanageclient-0000002412617972#section5914149183414)方法进行应用鉴权。

   <br />

   ```
   // 获取ServiceManageClient对象
   ServiceManageClient serviceManageClient = IndustryWear.getServiceManageClient(getContext());

   // 填写证书路径，是以resource/rawfile目录为根路径的相对路径字符串
   String certPath = "industrycer.cer";

   // 进行应用鉴权
   serviceManageClient.getAuthorization(certPath, new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // statusCode接口回调状态码，data为回调数据
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、9|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|鉴权成功时返回空字符串，鉴权失败时返回对应错误信息。|
   [表1 ServiceCallback返回值]
