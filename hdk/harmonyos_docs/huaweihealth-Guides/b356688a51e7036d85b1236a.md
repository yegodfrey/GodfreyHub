# 科学睡眠开关设置与查询

设置穿戴设备的科学睡眠开关状态。开启科学睡眠开关后，在用户睡眠期间，穿戴设备将实时监测睡眠与呼吸质量。关闭科学睡眠开关后，穿戴设备不再监测睡眠与呼吸质量。穿戴设备首次连接后默认关闭科学睡眠开关。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setMonitorSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section125741385215)方法设置科学睡眠开关状态。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setMonitorSwitch方法设置科学睡眠开关状态
           try await device.setMonitorSwitch(type: .TruSleepSwitch, monitorSwitchValue: true)

           // 设置科学睡眠开关状态成功
           print("Succeeded in setting TruSleepSwitch")
       } catch let err as IndustryError {
           // 设置科学睡眠开关状态失败
           print("Failed to set TruSleepSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getMonitorSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section10623588387)方法查询科学睡眠开关状态。

   ```screen
   Task {
       do {
           // 调用Device对象的getMonitorSwitch方法查询科学睡眠开关状态
           let switchValue = try await device.getMonitorSwitch(type: .TruSleepSwitch)

           // 查询科学睡眠开关状态成功
           print("Succeeded in getting TruSleepSwitch, switchValue: \(switchValue)")
       } catch let err as IndustryError {
           // 查询科学睡眠开关状态失败
           print("Failed to get TruSleepSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
