# 设置科学睡眠开关

设置穿戴设备的科学睡眠开关状态。开启科学睡眠开关后，在用户睡眠期间，设备将实时监测睡眠与呼吸质量。关闭科学睡眠开关后，设备将不会监测睡眠与呼吸质量。  
![](https://media:301785133831134238)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于设置科学睡眠开关的ZSON格式的入参数据。

   <br />

   ```
   {
       "settingKey": "TRUSleepSwitch",
       "settingValue": 0
   }
   ```

   |参数|取值|含义|
   |:-----------|:-------------|:--------|
   |settingKey|TRUSleepSwitch|科学睡眠开关键值。|
   |settingValue|0|关闭科学睡眠监测。|
   |settingValue|1|开启科学睡眠监测。|
   [表1 设置科学睡眠开关参数]

   <br />

3. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section447217361429)方法设置科学睡眠开关。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于设置科学睡眠开关的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("settingKey", "TRUSleepSwitch");
       zsonObject.put("settingValue", 1);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置科学睡眠开关
   manageClient.set(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、7|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回空字符串，接口调用失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />
