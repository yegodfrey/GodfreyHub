# 查询血氧历史数据

穿戴设备提供测量血氧能力，用户测量血氧后，行业应用可以通过本接口查询穿戴设备上记录的血氧数据。  
![](https://media:301785133838442360)  
* 此接口返回的血氧数据包括用户手动测量的血氧数据和开启血氧自动检测开关后穿戴设备自动测量的血氧数据。
* 需要采集血氧数据时，建议在查询时间段内测量一次或数次血氧，否则穿戴设备侧可能返回空数据。
* 不支持并发查询血氧历史数据，需等待上一次查询结束后方可进行下一次查询。
* 此接口不可与心率历史数据或者日常活动数据或者日常活动状态同时查询，需等待上一个任务结束后方可继续查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询血氧历史数据。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.SPO2,
         startTime: 1736521200,
         endTime: 1736547600
       }
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 处理查询结果
         console.info(`Succeeded in querying SPO2 data, result is ${data}.`);
       }).catch((error: BusinessError) => {
         // 处理查询异常
         console.info(`Failed to query SPO2 data. Code is ${error.code}, message is ${error.message}.`);
       })
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   ![](https://media:301785133838475361)  
   查询血氧历史数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有血氧历史数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)\[\]，查询成功血氧历史数据为空返回\[\]，查询失败抛出BusinessError。  
   查询成功返回的血氧历史数据样例：

   ```
   [
       {
           "startTime": 1740366420,
           "endTime": 1740366480,
           "type": "spo2",
           "fields": {
               "spo2": 99
           }
       },
       {
           "startTime": 1740366480,
           "endTime": 1740366540,
           "type": "spo2",
           "fields": {
               "spo2": 98
           }
       },
       ...
   ]
   ```

   |返回值|取值|单位|含义|
   |:-----|:-----|:-|:--------------------|
   |fields|object|-|包含血氧历史数据对象。|
   |spo2|number|%|血氧值，例如：99代表血氧饱和度为99%。|
   [表1 返回血氧历史数据说明]
