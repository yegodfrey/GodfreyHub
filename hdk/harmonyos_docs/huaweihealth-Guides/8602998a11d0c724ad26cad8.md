# 添加权限

## 配置蓝牙权限

由于本 SDK 涉及蓝牙通信功能，应用必须在 Info.plist 中声明蓝牙权限，否则在 iOS 13 及以上系统上运行时应用会直接崩溃。

1. 在 Xcode 中打开你的工程，找到并选中 Info.plist 文件（或者选中 Target -> Info 选项卡）。
2. 添加以下两个 Key，并根据应用实际场景填写面向用户的权限提示文案（Value）： Privacy - Bluetooth Always Usage Description：例如"本应用需要持续使用蓝牙以连接并管理你的智能设备"。

   Privacy - Bluetooth Peripheral Usage Description：（针对 iOS 13 以下版本的兼容）例如"本应用需要使用蓝牙以连接外部设备"。

## 配置蓝牙后台模式 (Background Modes)

为了保证应用切换到后台或手机锁屏时，SDK 仍能与蓝牙设备保持稳定的连接和数据通信，必须开启蓝牙后台权限。请按照以下步骤配置：

1. 在 Xcode 中选中你的 App Project，并在 Targets 列表中点击对应的应用。
2. 选择 Signing & Capabilities 选项卡。
3. 点击左上角的 + Capability 按钮，在弹出的列表中双击添加 Background Modes。
