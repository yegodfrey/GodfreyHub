# 设置行业应用保活

设置行业应用保活开关状态。开启行业应用保活开关后，行业应用处于后台时保持其正常运行，并且在因系统或者其它进程意外终止时能够自动重启。关闭行业应用保活开关后，行业应用处于后台时无法保持其正常运行，并且在因系统或者其它进程意外终止时不会自动重启。
> 说明
>
> * 当行业应用重启或者穿戴设备重启后，设置的行业应用保活功能仍然生效。
> * 为确保设备息屏后行业应用仍能常驻后台运行，需同步开启[RunningLock锁](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-runninglock)。
> * 为确保行业应用在设备息屏并重新唤醒后仍能保持在前台状态，可以参考FAQ中[如何处理行业应用在前台息屏后，重新唤醒设备后应用退到了后台](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/faq-0000002511427352#section482213763016)。
> * 开启行业应用保活开关可能会对穿戴设备续航产生一定影响，请根据实际需求合理使用。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setApplicationAbility](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1043434833)方法，设置应用保活。

   ```screen
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 调用setApplicationAbility设置应用保活。
       device.setApplicationAbility(IndustryService.ApplicationAbilityType.APP_PERSISTENT, true).then(() => {
         console.info(`Succeeded in setting appPersistent.`);
       }).catch((err: BusinessError) => {
         console.error(`Failed to set appPersistent. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     })
   ```
