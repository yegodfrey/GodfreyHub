# FAQ

## 1.如何获取智能手表的UDID

1. 打开智能手表的"设置 > 关于手表"，多次点击版本号，打开开发者模式。
2. 打开"设置"，在最下方找到"开发人员选项"，打开"HDC调试"开关。
3. 使用PC连接智能手表后，打开命令行工具，进入HDC目录（一般为：*HarmonyOS SDK安装目录* /toolchains/*{版本号}* ），输入**hdc shell bm get --udid** 命令，获取设备的UDID。

## 2.如何查询设备充电状态

导入batteryInfo模块，batteryInfo的chargingStatus属性表示当前设备的充电状态。示例如下。

```screen
import batteryInfo from '@ohos.batteryInfo';

let chargingStatusInfo = batteryInfo.chargingStatus;
console.info("The chargingStatusInfo is: " + chargingStatusInfo);
```

## 3.如何订阅/解订阅设备佩戴状态

1. 导入sensor模块，调用sensor.on订阅设备佩戴状态。示例如下。

   ```screen
   import sensor from "@ohos.sensor";
   import BusinessError from "@ohos.base";

   try {
     sensor.on(sensor.SensorId.WEAR_DETECTION, (data: sensor.WearDetectionResponse) => {
       console.info('Succeeded in invoking on. Wear status: ' + data.value);
     }, { interval: 100000000 });
   } catch (error) {
     let e: BusinessError.BusinessError = error as BusinessError.BusinessError;
     console.error(`Failed to invoke on. Code: ${e.code}, message: ${e.message}`);
   }
   ```

2. 调用sensor.off解订阅设备佩戴状态。示例如下。

   ```screen
   import sensor from "@ohos.sensor";
   import BusinessError from "@ohos.base";

   try {
     sensor.off(sensor.SensorId.WEAR_DETECTION);
   } catch (error) {
     let e: BusinessError.BusinessError = error as BusinessError.BusinessError;
     console.error(`Failed to invoke off. Code: ${e.code}, message: ${e.message}`);
   }
   ```

## 4.如何订阅/解订阅设备电量状态或设备充电状态

1. 创建订阅者对象。示例如下。

   ```screen
   import commonEventManager from '@ohos.commonEventManager';
   import Base from '@ohos.base';

   // 订阅者信息
   let subscribeInfo: commonEventManager.CommonEventSubscribeInfo = {
     events: [commonEventManager.Support.COMMON_EVENT_BATTERY_CHANGED] // 表示电池充电状态、电平和其他信息发生变化的公共事件。
   };
   let subscriber: commonEventManager.CommonEventSubscriber; // 订阅者对象，后续使用其完成订阅和解订阅的动作。

   // 创建订阅者
   try {
     commonEventManager.createSubscriber(subscribeInfo, (err, commonEventSubscriber) => {
       if(!err) {
         console.info("createSubscriber");
         subscriber = commonEventSubscriber;
       } else {
         console.error(`createSubscriber failed, code is ${err.code}, message is ${err.message}`);
       }
     });
   } catch (error) {
     let err:Base.BusinessError = error as Base.BusinessError;
     console.error(`createSubscriber failed, code is ${err.code}, message is ${err.message}`);
   }
   ```

2. 订阅公共事件。示例如下（以订阅设备电量状态为例，订阅设备充电状态同理）。

   ```screen
   import commonEventManager from '@ohos.commonEventManager';
   import Base from '@ohos.base';
   import batteryInfo from '@ohos.batteryInfo';

   let subscribeInfo: commonEventManager.CommonEventSubscribeInfo = {
     events: [commonEventManager.Support.COMMON_EVENT_BATTERY_CHANGED]
   };
   let subscriber: commonEventManager.CommonEventSubscriber;
   let curBatteryLevel: number = 0; // 保存当前设备的电量

   try {
     commonEventManager.createSubscriber(subscribeInfo, (err, commonEventSubscriber) => {
       if(!err) {
         console.info("createSubscriber");
         subscriber = commonEventSubscriber;
         curBatteryLevel = batteryInfo.batterySOC;

         // 订阅公共事件
         commonEventManager.subscribe(subscriber, (err, data) => {
           if (err) {
             console.error(`subscribe failed, code is ${err.code}, message is ${err.message}`);
           } else {
             console.info("subscribe");
             let params: Record<string, number> = data?.parameters as Record<string, number>;
             if (params.soc != curBatteryLevel) { // 事件触发时的设备电量和当前设备电量不相等则表示设备电量状态发生了变化
               curBatteryLevel = params.soc;
               // 处理逻辑
             }
           }
         });
       } else {
         console.error(`createSubscriber failed, code is ${err.code}, message is ${err.message}`);
       }
     });
   } catch (error) {
     let err:Base.BusinessError = error as Base.BusinessError;
     console.error(`createSubscriber failed, code is ${err.code}, message is ${err.message}`);
   }
   ```

3. 解订阅公共事件。示例如下。

   ```screen
   // 解订阅公共事件
   // 注意：这里的subscriber和步骤2中订阅公共事件的subscriber要为同一个对象
   try {
     commonEventManager.unsubscribe(subscriber, (err) => {
       if (err) {
         console.error(`unsubscribe failed, code is ${err.code}, message is ${err.message}`);
       } else {
         console.info("unsubscribe");
       }
     });
   } catch (error) {
     let err:Base.BusinessError = error as Base.BusinessError;
     console.error(`unsubscribe failed, code is ${err.code}, message is ${err.message}`);
   }
   ```

## 5.返回授权证书校验失败状态码5，如何处理

* 方法一：请检查手机能否正常连接外部网络。

* 方法三：请检查手机系统时间与当前真实时间是否偏差过大，如偏差超过10分钟。

## 7.BLE连接的穿戴设备什么情况下不会自动重连

1. 主动调用断开连接。
2. 手机侧或智能穿戴设备侧蓝牙未打开。
3. 设备连接断开超过5分钟。
4. Android 10及以上版本手机未打开定位。

## 8.订阅后开启实时心率，订阅接口返回的心率值中含有0或255的数据，如何处理

0和255为瞬时异常数据，出现异常数据的原因可能是手表佩戴的位置有误或佩戴较松，请开发者对此异常数据进行过滤。

## 9.订阅实时心率联动及订阅运动联动数据上报时，返回状态码为6，如何处理

联动的前提条件是佩戴设备，需要佩戴设备再订阅。

## 11.使用"智能穿戴设备"如何才能被行业App扫描出来

* 方法一：在智能穿戴设备上点击"设置 > 系统和更新 > 连接到新手机"。
* 方法二：如果开发的程序出现每次都要扫第二次才能扫描到穿戴设备，这是因为打开蓝牙，系统需要时间，建议打开蓝牙之后，等一下再扫描（等待时间取决于手机硬件能力，建议是3到5秒左右）。
* 方法三：更换穿戴设备，重新扫描尝试，有可能是穿戴设备本身的问题。

## 12.建议的扫描配对流程是什么

1. 注册连接状态监听；
2. 调用[addDevice](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800#ZH-CN_TOPIC_0000002648084238__addDevice-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)添加设备。

## 13.什么时候加载证书

扫描之后调用[addDevice](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800#ZH-CN_TOPIC_0000002648084238__addDevice-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)接口进行添加设备时，会先进行证书读取和鉴权。

## 14.扫描到设备后，在设备侧没有弹框提示，如何处理

* 情况一：鉴权失败。 排查方法：调用addDevice接口的状态码返回5，说明为鉴权失败。

* 情况二：操作过于频繁，请稍后重试。

## 15.设备侧点击配对后，显示配对失败，如何处理

请先确保穿戴设备型号在支持的设备列表范围内，打开手表"设置 > 关于"查看设备广播名，或者在初始配对界面的广播名称确认设备名字带有B10/B20/B5/B7等，而不是GT3、WATCH 3这种面向消费者层面的蓝牙广播名。

## 16.蓝牙配对返回什么值表示连接成功

statusCode状态码返回0，仅表示调用成功；当connectionStatus连接状态码返回2时，表示连接成功。

## 17.数据上报部分是0

* 如果查询的是运动联动数据： 该数据不支持直接上报，需要通过其他方式联动计算，所以报上来就是0。

* 如果查询的是日常活动数据/历史数据： 查询的结束时间为当前时刻（尤其是整分钟，如14:00:00），由于穿戴侧处理数据有时延，穿戴侧可能无法获取当前时刻的数据。建议查询的结束时间比当前时刻稍微提前1分钟。

## 18.deviceId是做什么用的？什么时候会变

deviceId是每次调用addDevice接口配对连接时生成的（注意不是SN码），且每次生成的都为新的id，不与之前的id重复。

仅在调用addDevice添加设备的时候会变化，所以以下情况deviceid不会改变：

* 蓝牙关掉，重新开启蓝牙，调用重连接口connectDevice，deviceId不会变。
* 取消注册连接状态监听之后再重新注册连接状态监听，deviceId不会变。

## 19.连接成功之后是否需要取消注册连接状态监听

不建议取消注册连接状态监听，否则无法确定设备的连接状态。

## 20.调用删除设备或断开连接接口后，当即进行连接设备可能会出现连接状态由1变为3，再由3变为1再变为2的情况

由于低版本Android系统可能在处理断开蓝牙状态时存在时延，建议调用断开连接接口后，间隔6s以上再重新调用连接接口。

## 21.调用扫描设备接口时无反应或仅扫描到部分设备

请确认已打开手机系统蓝牙和GPS服务开关，并且已申请位置权限。

请确认周围存在行业版本的穿戴设备，且穿戴设备蓝牙已开启，等15s后重新进行设备扫描。

请确认待扫描设备是否已经解除配对。

## 22.调用包含ServiceCallback类型参数的接口时，程序异常终止

请检查接口调用时ServiceCallback参数，ServiceCallback不可以为null，同时也可以捕获IllegalArgumentException异常以避免程序异常终止。

## 23.调用设置来电状态接口中的参数subscriptionId如何获取

步骤1：先动态申请READ_PHONE_STATE权限，然后调用SubscriptionManager.getActiveSubscriptionInfoList()方法获取当前激活的SIM卡的SubscriptionInfo。

步骤2：调用TelephonyManager.getCallState()等方法找到处于来电状态的SIM卡的SubscriptionId。

参考如下代码：

```screen
/**
 * 获取当前来电SIM卡的SubscriptionId
 *
 * @return 当前来电SIM的SubId
 */
public static int getSubIdForIncomingCall(Context context) {
    List<Integer> simSubIds = getSimSubscriptionIds(context);
    if (simSubIds.isEmpty()) {
        return ERROR_SUBSCRIPTION_ID;
    }

    // 当前手机只有一张SIM卡
    if (simSubIds.size() == SINGLE_SIM) {
        Log.w(TAG, "getSubscriptionIdForIncomingState single sim subId:" + simSubIds.get(0));
        return simSubIds.get(0);
    }

    // 当前手机有两张SIM卡
    Object systemService = BaseApplication.getContext().getSystemService(Context.TELEPHONY_SERVICE);
    if (!(systemService instanceof TelephonyManager)) {
        return ERROR_SUBSCRIPTION_ID;
    }
    TelephonyManager telephonyManager = (TelephonyManager) systemService;
    int subIdForIncomingCall;
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
        subIdForIncomingCall = getSubIdForIncomingCallForHighVersion(telephonyManager, simSubIds);
    } else {
        subIdForIncomingCall = getSubIdForIncomingCallForLowVersion(telephonyManager, simSubIds);
    }
    return subIdForIncomingCall;
}

/**
 * 获取当前双卡模式下的SIM卡的subscriptionId信息
 *
 * @return subId集合
 */
private static List<Integer> getSimSubscriptionIds(Context context) {
    List<Integer> subList = new ArrayList<>();
    boolean hasReadCallLogPermission =
        ContextCompat.checkSelfPermission(context, Manifest.permission.READ_PHONE_STATE) == PackageManager.PERMISSION_GRANTED;
    if (!hasReadCallLogPermission) {
        Log.w(TAG, "getSimSubscriptionIds does not have READ_PHONE_STATE permission");
        return subList;
    }
    SubscriptionManager sm = SubscriptionManager.from(BaseApplication.getContext());
    List<SubscriptionInfo> infoList = sm.getActiveSubscriptionInfoList();
    for (SubscriptionInfo subscriptionInfo : infoList) {
        subList.add(subscriptionInfo.getSubscriptionId());
    }
    return subList;
}

/**
 * 对于高于12（SDK >= 31）的Android版本获取当前来电SIM卡的SubscriptionId.
 *
 * @param telephonyManager telephonyManager
 * @param simSubIds subscriptionId列表
 * @return 当前来电SIM卡的SubscriptionId
 */
@RequiresApi(api = Build.VERSION_CODES.S)
private static int getSubIdForIncomingCallForHighVersion(TelephonyManager telephonyManager, List<Integer> simSubIds) {
    for (Integer subId : simSubIds) {
        if (subId == null) {
            continue;
        }
        TelephonyManager telephonyManagerForSubId = telephonyManager.createForSubscriptionId(subId);
        if (ActivityCompat.checkSelfPermission(BaseApplication.getContext(),
            Manifest.permission.READ_PHONE_STATE) != PackageManager.PERMISSION_GRANTED) {
            Log.i(TAG, "getSubIdForIncomingCallForHighVersion does not have READ_phone_STATE permission");
            return ERROR_SUBSCRIPTION_ID;
        }
        int callState = telephonyManagerForSubId.getCallStateForSubscription();
        int subscriptionId = telephonyManagerForSubId.getSubscriptionId();
        Log.i(TAG, "getSubIdForIncomingCallForHighVersion callState: " + callState + ", subId:" + subscriptionId);

        if (callState == TelephonyManager.CALL_STATE_RINGING) {
            return subscriptionId;
        }
    }
    return ERROR_SUBSCRIPTION_ID;
}

/**
 * 对于低于12（SDK < 31）的Android版本获取当前来电SIM卡的SubscriptionId.
 *
 * @param telephonyManager telephonyManager
 * @param simSubIds subscriptionId列表
 * @return 当前来电SIM卡的SubscriptionId
 */
private static int getSubIdForIncomingCallForLowVersion(TelephonyManager telephonyManager, List<Integer> simSubIds) {
    Class<TelephonyManager> clazz = TelephonyManager.class;
    try {
        Method method = clazz.getDeclaredMethod(GET_CALL_STATE, int.class);
        method.setAccessible(true);
        for (Integer simSubId : simSubIds) {
            Object value = method.invoke(telephonyManager, simSubId);
            if (!(value instanceof Integer)) {
                continue;
            }
            int callState = (int) value;
            Log.i(TAG, "getSubIdForIncomingCallForLowVersion callState:" + callState +
                " multiSimSubId:" + simSubId);
            if (callState == TelephonyManager.CALL_STATE_RINGING) {
                return simSubId;
            }
        }
    } catch (SecurityException | IllegalAccessException | InvocationTargetException | NoSuchMethodException e) {
        Log.e(TAG, "getSubIdForIncomingCallForLowVersion han an exception");
    }
    return ERROR_SUBSCRIPTION_ID;
}
```

## 25.如何获取手机联系人数据

步骤1：先动态申请READ_CONTACTS权限。

步骤2：创建ContactInfo类，用于保存获取到的联系人信息。参考示例如下。

```screen
public class ContactInfo {
    private String name;
    private String phoneNumber;

    public ContactInfo(String name, String phoneNumber) {
        this.name = name;
        this.phoneNumber = phoneNumber;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getPhoneNumber() {
        return phoneNumber;
```

步骤3：使用ContentResolver查询联系人数据，并对获取到的联系人数据进行排序。参考示例如下。

```screen
private void readContacts() {
    ContentResolver contentResolver = getContentResolver();
    Cursor cursor = contentResolver.query(ContactsContract.Contacts.CONTENT_URI, null, null, null, null);
    if (cursor != null && cursor.moveToFirst()) {
        List<ContactInfo> contactsList = new ArrayList<>();
        do {
            String id = cursor.getString(cursor.getColumnIndexOrThrow(ContactsContract.Contacts._ID));
            String displayName = cursor.getString(cursor.getColumnIndexOrThrow(ContactsContract.Contacts.DISPLAY_NAME));
            String hasPhone = cursor.getString(cursor.getColumnIndexOrThrow(ContactsContract.Contacts.HAS_PHONE_NUMBER));
            if ("1".equals(hasPhone)) {
                Cursor phoneCursor = contentResolver.query(ContactsContract.CommonDataKinds.Phone.CONTENT_URI,
                    null, ContactsContract.CommonDataKinds.Phone.CONTACT_ID + " = ?", new String[]{id}, null);
                if (phoneCursor != null && phoneCursor.moveToFirst()) {
                    String phoneNumber = phoneCursor.getString(phoneCursor.getColumnIndexOrThrow(ContactsContract.CommonDataKinds.Phone.NUMBER));
                    contactsList.add(new ContactInfo(displayName, phoneNumber));
                    phoneCursor.close();
                }
            }
        } while (cursor.moveToNext());
        cursor.close();
        // 联系人集合按照拼音排序
        Collections.sort(contactsList, new Comparator<ContactInfo>() {
            final Collator collator = Collator.getInstance(Locale.CHINA);
            @Override
            public int compare(ContactInfo o1, ContactInfo o2) {
                return collator.compare(o1.getName(), o2.getName());
            }
        });
    }
}
```
