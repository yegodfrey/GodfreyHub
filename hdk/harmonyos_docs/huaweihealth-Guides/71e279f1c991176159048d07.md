# 拉起体温测量

穿戴设备提供测量体温的能力，通过行业SDK可以拉起穿戴设备上的体温应用进行体温测量。  
![](https://media:301785133822025112)  
* 接口仅支持拉起体温测量功能的行业版本穿戴设备，当前支持HUAWEI WATCH H7546设备。
* 单次测量最长等待时间为5分钟，如果超过5分钟未进行测量将会返回测量超时状态码。在测量等待时间内，如再次下发血氧或体温测量将会返回业务冲突。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于拉起体温测量的ZSON格式的入参数据。

   <br />

   ```
   {
       "item": "temperatureMeasure"
   }
   ```

   <br />

3. 调用[send](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section162931529126)方法拉起体温应用进行体温测量。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于拉起体温测量的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "temperatureMeasure");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用send方法拉起体温应用进行体温测量
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   };
   deviceManageClient.send(zsonObject.toString(), serviceCallback);
   ```

   |参数|取值|含义|
   |:---------|:----------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、6、7、401、402、403、404、405、406、407、408、409、410|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)中的通用返回码和设备管控与事件状态码。|
   |data|-|接口调用成功时返回空字符串，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />
