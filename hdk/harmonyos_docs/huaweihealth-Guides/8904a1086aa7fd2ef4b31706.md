# 用户基本信息设置和查询

设置与查询穿戴设备的用户基本信息，包括出生日期、性别、身高以及体重数据。设置用户基本信息后，穿戴设备可以提供更准确的健康监测服务。
> 说明
>
> * 在用户没有自行设置过心率区间的情况下，设置用户基本信息时会设置一个默认心率区间。心率区间的最大心率值计算方法为：220 - 用户年龄，当计算的结果小于100时，则为100。心率区间值依次为最大心率的100%，90%，80%，70%，60%，50%，各个区间值四舍五入取整。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setUserBasicInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section644231935811)方法设置用户基本信息。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 构造用户基本信息
           let userBasicInfo = IndustryService.UserBasicInfo(
               dateOfBirth: "20000101",
               gender: .male,
               height: 175,
               weight: 70
           )

           // 调用Device对象的setUserBasicInfo方法设置用户基本信息
           try await device.setUserBasicInfo(userBasicInfo: userBasicInfo)
        
           // 设置用户基本信息成功
           print("Succeeded in setting user basic info")
       } catch let err as IndustryError {
           // 设置用户基本信息失败
           print("Failed to set user basic info. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getUserBasicInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1312113259293)方法查询用户基本信息。

   ```screen
   Task {
       do {
           // 调用Device对象的getUserBasicInfo方法查询用户基本信息
           let userBasicInfo = try await device.getUserBasicInfo()

           // 查询用户基本信息成功
           print("Succeeded in getting user basic info, dateOfBirth: \(userBasicInfo.dateOfBirth), gender: \(userBasicInfo.gender), height: \(userBasicInfo.height),   weight: \(userBasicInfo.weight)")
       } catch let err as IndustryError {
           // 查询用户基本信息失败
           print("Failed to get user basic info. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
