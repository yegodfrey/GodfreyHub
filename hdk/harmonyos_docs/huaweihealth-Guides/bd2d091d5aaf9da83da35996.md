# 体温过高提醒开关设置与查询

设置与查询穿戴设备的体温过高提醒开关状态。开启体温过高提醒开关后，穿戴设备将连续监测体温。当体温持续10分钟以上都高于设定值（支持设定的温度范围为37.2℃-38.5℃）时，穿戴设备会发出提醒。关闭体温过高提醒开关后，穿戴设备不再发出提醒。
> 注意
>
> * 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
> * 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
> * 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的体温过高提醒开关状态给穿戴设备。
> * 本开关仅支持国内版本的部分设备，若使用不受支持的设备，将返回错误码10。
> 说明
>
> 体温过高提醒开关设置需要先在手表体温应用中激活体温研究功能。激活路径：点击【体温】->点击【加入研究】。未加入体温研究的情况下无法使用体温过高提醒开关设置接口。设置的结果将不会生效。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1639374991110)方法设置体温过高提醒开关。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造体温过高提醒开关参数
       let info: IndustryService.AlertSetting = {
         switch: true,
         threshold: 37.5      
       };
       // 调用Device对象的setSettingInfo方法设置体温过高提醒开关
       device.setSettingInfo(IndustryService.SettingType.HIGH_TEMP_ALERT, info).then(() => {
         // 设置体温过高提醒开关成功
         console.info('Succeeded in setting highTempAlert.');
       }).catch((err: BusinessError) => {
         // 设置体温过高提醒开关失败
         console.error(`Failed to set highTempAlert. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section15787757114)方法查询体温过高提醒开关。

   ```screen
   // 调用Device对象的getSettingInfo方法查询体温过高提醒开关
   device.getSettingInfo(IndustryService.SettingType.HIGH_TEMP_ALERT).then((result: IndustryService.AlertSetting) => {
     // 查询体温过高提醒开关成功，打印返回的体温过高提醒开关
     console.info(`Succeeded in getting highTempAlert, result is ${JSON.stringify(result)}.`);
   }).catch((err: BusinessError) => {
     // 查询体温过高提醒开关失败
     console.error(`Failed to get highTempAlert. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
