# 查询微体检报告

穿戴设备提供微体检测量能力。当用户佩戴穿戴设备打开微体检应用完成微体检测量后，行业应用可以通过本接口查询穿戴设备上生成的微体检报告数据。
> 注意
>
> 用户个人信息（性别、出生日期、身高、体重等）将影响部分测量结果准确性，建议提前调用[设置用户基本信息](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-user-basic-info-0000002376394493)接口。
> 说明
>
> 需要采集微体检报告数据时，建议在查询时间范围内测量一次或数次微体检，否则穿戴设备侧可能返回空数据。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询微体检报告数据。

   ```screen
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询微体检报告数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.HEALTH_GLANCE_REPORT,
         startTime: 1773126000,
         endTime: 1773129600
       };

       // 调用Device对象的queryHistoryData方法查询微体检报告数据
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 查询微体检报告数据成功, 打印接口返回的微体检报告数据
         console.info(`Succeeded in querying healthGlanceReport data, result is ${data}.`);
       }).catch((err: BusinessError) => {
         // 查询微体检报告数据失败
         console.error(`Failed to query healthGlanceReport data. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   > 说明
   >
   > 查询微体检报告数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和查询结束时间间隔不超过24小时。

   查询成功并且有微体检报告数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)[]，查询成功微体检报告数据为空返回[]，查询失败抛出BusinessError。

   |返回值|类型|单位|含义|
   |:------------------|:-----|:-----|:---------------------------------------------------------------------------------------------|
   |fields|object|-|包含微体检报告数据对象。|
   |averageHeartRate|number|次/分钟|平均心率。|
   |hrv|number|毫秒|心率变异性，取值范围：[0, 300]（300表示无效值）。|
   |hrvTimestamp|number|秒|心率变异性生成时间戳（默认值为0）。|
   |bloodOxygen|number|百分比（%）|血氧（255表示无效值）。|
   |bodyTemperature|number|摄氏度|体温（65535表示无效值）。|
   |skinTemperature|number|摄氏度|皮肤温度（65535表示无效值）。|
   |stress|number|-|压力（255表示无效值）。|
   |emotionStatus|number|-|情绪状态，取值范围：[0, 100]。 * 1：负面情绪，不愉快 * 2：平静情绪，平和 * 3：积极情绪，愉快 * 100：无效值|
   |emotionTimestamp|number|秒|情绪生成时间戳（默认值为0）。|
   |heartType|number|-|心律类型。 * 0：心电图 * 1：脉搏波|
   |heartResult|number|-|心律结果。 heartType=0时： * 1：窦性心律 * 2：房性早搏 * 4：室性早搏 * 8：房颤 heartType=1时： * 1：未见异常 * 2：疑似早搏 * 3：疑似房颤|
   |arrhythmiaTotal|number|-|脉搏波心律失常总检测项数（默认值为0）。|
   |arrhythmiaRule|number|-|脉搏波心律失常未见异常数（默认值为0）。|
   |arrhythmiaAfPrem|number|-|脉搏波心律失常疑似早搏数（默认值为0）。|
   |arrhythmiaAfAtrial|number|-|脉搏波心律失常疑似房颤数（默认值为0）。|
   |sleepApneaGrade|number|-|睡眠呼吸暂停检测结果。 * 1：正常 * 2：疑似低风险 * 3：疑似中风险 * 4：疑似高风险|
   |sleepApneaTimestamp|number|秒|睡眠呼吸暂停检测时间戳（默认值为0）。|
   |systolicPressure|number|mmHg|高压（65535表示无效值）。|
   |diastolicPressure|number|mmHg|低压（65535表示无效值）。|
   |bpHeartRate|number|次/分钟|血压测量中的脉搏。|
