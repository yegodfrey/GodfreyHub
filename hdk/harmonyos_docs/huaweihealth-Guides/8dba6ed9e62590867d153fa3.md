# 注册服务端连接状态监听

注册和取消注册行业应用与行业SDK服务端的连接状态监听。注册成功后，当行业应用与行业SDK服务端的连接状态变化时返回当前连接状态。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getServiceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#ZH-CN_TOPIC_0000002648084254__getServiceClient-android_content_Context-)方法，获取[ServiceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/servicemanageclient-0000002412617972)对象。
2. 调用[registerServiceConnectionListener](https://developer.huawei.com/consumer/cn/doc/health-References/servicemanageclient-0000002412617972#ZH-CN_TOPIC_0000002647924342__getServiceClient-android_content_Context-)方法注册应用与服务的连接状态监听。

   ```screen
   // 获取ServiceManageClient对象
   ServiceManageClient serviceManageClient = IndustryWear.getServiceManageClient(getContext());

   // 注册应用与服务的连接状态监听
   serviceManageClient.registerServiceConnectionListener(new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // statusCode接口回调状态码，data回调数据
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:--|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、8|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|注册成功时返回空字符串，与服务端连接状态发生变化时返回连接状态。 * 断开连接：1 * 连接成功：0|
   [**表1**ServiceCallback返回值]

3. 若需要取消注册服务端连接状态监听，调用[unregisterServiceConnectionListener](https://developer.huawei.com/consumer/cn/doc/health-References/servicemanageclient-0000002412617972#section884813561243)方法。

   ```screen
   // 解注册应用与服务的连接状态监听
   serviceManageClient.unregisterServiceConnectionListener(serviceCallback);
   ```

   > 说明
   >
   > 解注册成功条件：
   > * 解注册时传入的ServiceCallback，要求和注册时传入的ServiceCallback为同一个对象
