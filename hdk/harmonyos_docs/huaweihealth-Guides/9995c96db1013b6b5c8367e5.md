# 订阅设备连接状态

行业App订阅设备连接状态后方可监测到已配对的穿戴设备连接状态。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)对象的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section232815255518)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象的[subscribeConnectionStateChange](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section12792205320017)方法订阅设备连接状态。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   // 调用IndustryService对象的getDeviceManager方法获取DeviceManager对象        
   let deviceManager = IndustryService.getDeviceManager()

   // 调用DeviceManager对象的subscribeConnectionStateChange方法订阅设备连接状态
   let uuid = deviceManager.subscribeConnectionStateChange { state in
       print("deviceId: \(state.deviceId), connectionState: \(state.connectionState)")
   }

   // 订阅设备连接状态成功
   print("Succeeded in subscribing connection state")    
   ```

   <br />

4. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象的[unsubscribeConnectionStateChange](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section888811301641)方法取消订阅设备连接状态。

   <br />

   ```
   // 调用DeviceManager对象的unsubscribeConnectionStateChange方法取消订阅设备连接状态
   deviceManager.unsubscribeConnectionStateChange(subscribeId: uuid)

   // 取消订阅设备连接状态成功
   print("Succeeded in unsubscribing connection state")
   ```

   ![](https://media:301785133822837127)  
   取消订阅传入的uuid，要求和订阅返回的uuid为同一个对象。
