## 配置Maven仓地址

1. 打开DevEco Studio项目根路径下的build.gradle文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/44/v3/a4pB6CnBQWOG4-OYMUpNZQ/zh-cn_image_0000002678004471.png?HW-CC-KV=V1&HW-CC-Date=20260909T170708Z&HW-CC-Expire=31536000000&HW-CC-Sign=738916D6B113DFC66009ACBFDCE2FBFD4E152BDDB999DCE79D4F3ABEEECFECB0)

2. 在"buildscript > repositories"里面增加Maven仓配置。

   ```screen
   maven {
       url 'https://developer.huawei.com/repo/'
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/wfk8dA9QRBahagaPCnrPSA/zh-cn_image_0000002647924708.png?HW-CC-KV=V1&HW-CC-Date=20260909T170708Z&HW-CC-Expire=31536000000&HW-CC-Sign=BC107A066C56366678BBE998FFF9EC46AEA6802DB46E216763C4D1331E7740D8)
3. 在"allprojects > repositories"里面增加Maven仓地址。

   ```screen
   maven {
       url 'https://developer.huawei.com/repo/'
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a0/v3/hW2ziPjWT_i697OsZJhljQ/zh-cn_image_0000002678164309.png?HW-CC-KV=V1&HW-CC-Date=20260909T170708Z&HW-CC-Expire=31536000000&HW-CC-Sign=B82C747F0048BE2163F8C15A84B9E697BE7E5D86DF78715792EE2616CEB2809E)

## 添加编译依赖

1. 打开应用级的build.gradle文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/a9lo4pE3SsSIRSA80qTQPQ/zh-cn_image_0000002678164307.png?HW-CC-KV=V1&HW-CC-Date=20260909T170708Z&HW-CC-Expire=31536000000&HW-CC-Sign=CC26141E5C2F2FBC65F6DBE951EF64B699367AB2D9932BC0E896A9A3DA969DA2)

2. 在"dependencies"中添加如下编译依赖。

   ```screen
   implementation 'com.huawei.health.industry:industry-client-wearable:{version}'
   ```

   > 说明
   >
   > *{version}* 替换为实际的SDK版本号：com.huawei.health.industry:industry-client-wearable:4.3.0.106。建议集成最新的SDK版本，版本号详见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/version-change-history-0000002447182205)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/CnCw_V-UQMqYpDaIf4XlRw/zh-cn_image_0000002648084590.png?HW-CC-KV=V1&HW-CC-Date=20260909T170708Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD03705CEE4FB0D39508F7EC1813C9D8BB75A7ED146F4EFB864BB6E0FED1B4FC)

## 同步工程

在完成以上的配置后，点击File->Sync Project with Gradle Files，完成"build.gradle"文件的同步，将相关依赖下载到本地。
> 说明
>
> 如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
