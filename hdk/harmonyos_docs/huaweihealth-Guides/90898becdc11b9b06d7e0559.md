# 查询日常活动数据

查询穿戴设备用户的日常活动数据。当用户佩戴穿戴设备进行日常活动后，行业应用可以通过本接口查询穿戴设备上记录的日常活动数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询日常活动数据的ZSON格式的入参数据。

   <br />

   ```
   {
       "item": "dailyTotalData"
   }
   ```

   <br />

<!-- -->

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询日常活动数据。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询日常活动数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "dailyTotalData");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询日常活动数据
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回当天手表中的活动记录，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />

<!-- -->

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含日常活动数据。

   <br />

   ```
   data样例：
   {
       "totalStep":129,
       "totalCalorie":4289,
       "totalDistance":49,
       "totalStrengthTime":0,
       "totalHeight":200,
   }
   ```

   |返回值|取值|含义|
   |:----------------|:---------|:---------------|
   |totalStep|int类型数据|步数值。|
   |totalCalorie|double类型数据|当前卡路里，单位：卡。|
   |totalDistance|double类型数据|当前距离，单位：米。|
   |totalStrengthTime|int类型数据|当前中高强度总时间，单位：分钟。|
   |totalHeight|double类型数据|爬楼高度，单位：米。|
   [表2 data返回值]

   <br />
