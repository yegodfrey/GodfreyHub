# 久坐提醒开关设置和查询

设置与查询穿戴设备的久坐提醒开关状态。开启久坐提醒开关后，在每天的8:00到21:00，用户每久坐一小时穿戴设备会产生久坐活动提醒。关闭久坐提醒开关后，穿戴设备不会产生久坐活动提醒。穿戴设备首次连接后默认开启久坐提醒开关。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setRemindSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section24381853174618)方法设置久坐提醒开关状态。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setRemindSwitch方法设置久坐提醒开关状态
           try await device.setRemindSwitch(type: .standReminderSwitch, remindSwitchValue: true)

           // 设置久坐提醒开关状态成功
           print("Succeeded in setting standReminderSwitch")
       } catch let err as IndustryError {
           // 设置久坐提醒开关状态失败
           print("Failed to set standReminderSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getRemindSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section0593868401)方法查询久坐提醒开关状态。

   ```screen
   Task {
       do {
           // 调用Device对象的getRemindSwitch方法查询久坐提醒开关状态
           let switchValue = try await device.getRemindSwitch(type: .standReminderSwitch)

           // 查询久坐提醒开关状态成功
           print("Succeeded in getting standReminderSwitch, switchValue: \(switchValue)")
       } catch let err as IndustryError {
           // 查询久坐提醒开关状态失败
           print("Failed to get standReminderSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
