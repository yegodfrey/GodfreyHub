# 查询心率变异性（HRV）数据

穿戴设备提供测量心率变异性（HRV）能力，用户佩戴设备一段时间后，行业应用可以通过本接口查询穿戴设备上记录的HRV数据。
> 说明
>
> * HRV监测频率为10分钟测量一次。HRV测量要求用户处于非活动状态，活动状态下可能不出值。
> * 不支持并发查询HRV历史数据，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询心率变异性数据的JSON格式的入参数据。

   ```screen
   {
       "item": "hrvData"
   }
   ```


3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询心率变异性数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询连续心率异变数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "hrvData");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询心率异变数据
   manageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回最近一次hrv值，失败时返回错误信息。|
   [**表1**ServiceCallback返回值]


4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含hrv数据。

   ```screen
   {
       "dataType": "heartRateVariabilityRMSSD",
       "totalCount": 1,
       "index": 0,
       "count": 1,
       "dataList": [
           {
               "startTime": 1774409495,
               "heartRateVariabilityRMSSD": 37
           }
       ]
   }
   ```

   |返回值|取值|含义|
   |:------------------------|:-------|:-----------------|
   |startTime|long类型数据|hrv数据产生的时间戳。（单位：s）|
   |heartRateVariabilityRMSSD|int类型数据|hrv值。（单位：ms）|
   [**表2**data返回值]
