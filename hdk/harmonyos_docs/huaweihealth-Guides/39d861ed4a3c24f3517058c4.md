# 订阅心率告警

订阅和取消订阅穿戴设备的静息心率告警。订阅成功后，当穿戴设备侧产生心率告警时返回心率告警信息。取消订阅后，不再返回心率告警信息。
> 说明
>
> 支持在穿戴设备熄屏状态下上报心率告警信息。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section141971612182616)方法订阅心率告警信息。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 心率告警信息回调
       let callback: Callback<IndustryService.EventData> = (eventData: IndustryService.EventData) => {
         console.info(`report event: ${JSON.stringify(eventData)}`);
       }
       // 调用Device对象的subscribeEvent方法订阅心率告警信息
       device.subscribeEvent(IndustryService.EventType.HEART_RATE_ALARM_EVENT, callback).then(() => {
         // 订阅心率告警信息成功
         console.info(`Succeeded in subscribing heartRateAlarmEvent.`);
       }).catch((err: BusinessError) => {
         // 订阅心率告警信息失败
         console.error(`Failed to subscribe heartRateAlarmEvent. Code is ${err.code}, message is ${err.message}.`);
       })
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

5. 心率告警信息在Callback<IndustryService.[EventData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7634104243910)>中处理。触发心率告警时eventData中包含事件类型（event）和心率告警类型（status）。

   ```screen
   eventData样例：
   {
     event: 'heartRateAlarmEvent',
     status: 0
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:------|
   |status|0|静息心率过高。|
   |status|1|静息心率过低。|
   [**表1**心率告警类型]

6. 调用[unSubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section29691015152720)方法，取消订阅心率告警。

   ```screen
   // 调用Device对象的unSubscribeEvent方法取消订阅心率告警。注意：这里的callback和上述心率告警信息回调要为同一个对象
   device.unSubscribeEvent(IndustryService.EventType.HEART_RATE_ALARM_EVENT, callback).then(() => {
     // 取消订阅心率告警成功
     console.info(`Succeeded in unsubscribing heartRateAlarmEvent.`);
   }).catch((err: BusinessError) => {
     // 取消订阅心率告警失败
     console.error(`Failed to unsubscribe heartRateAlarmEvent. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   > 说明
   >
   > 取消订阅传入的callback，要求和订阅时传入的callback为同一个对象。
