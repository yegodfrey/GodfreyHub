# 设置最大运动心率

设置穿戴设备在运动状态下的最大心率（单位：次/分钟）。设置最大运动心率会自动生成心率区间，当用户佩戴穿戴设备进行运动时自动识别运动强度。  
![](https://media:301785133831003235)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。  
![](https://media:301785133831049236)  
* 设置最大运动心率会自动向设备下发心率区间，心率区间取值分别为最大运动心率的100%、90%、80%、70%、60%、50%（存在小数时采用"四舍五入"原则）。
* 此接口和[设置心率区间](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-heart-rate-interval-0000002413832944)会互相覆盖心率配置信息，设备侧最终的心率相关配置信息按照最后一次下发的配置为准。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于设置最大运动心率的ZSON格式的入参数据。

   <br />

   ```
   {
       "settingKey": "maxHeartRate",
       "settingValue": 180
   }
   ```

   |参数|取值|含义|
   |:-----------|:--------------------------------------------------------------------|:--------|
   |settingKey|maxHeartRate|最大运动心率键值。|
   |settingValue|整数，取值范围：max(100, (220 - age) \* 85%) \~ min(220, (220 - age) \* 115%)|最大运动心率值。|
   [表1 设置最大运动心率参数]

   ![](https://media:301785133831081237)  
   最大运动心率数值支持范围：max(100, (220 - age) \* 85%) \~ min(220, (220 - age) \* 115%)。
   * age为用户年龄，通过设置的用户基本信息计算得到。
   * 当用户没有设置用户基本信息时，age默认为18。
   * max(a,b) 表示两个数中取最大值，min(a, b) 表示两个数中取最小值。

   <br />

3. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section447217361429)方法设置运动状态下的最大心率。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于设置最大运动心率的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("settingKey", "maxHeartRate");
       zsonObject.put("settingValue", 180);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置运动状态下的最大心率
   manageClient.set(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、7|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回空字符串，接口调用失败时返回错误信息。|
   [表2 ServiceCallback返回值]
