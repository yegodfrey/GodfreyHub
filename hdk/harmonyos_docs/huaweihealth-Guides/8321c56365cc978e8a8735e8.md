# 查询心率区间

查询穿戴设备的心率区间，在未调用心率相关配置接口（设置用户基本信息、设置最大运动心率、设置心率区间）的情况下，查询返回错误码9。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询心率区间的JSON格式参数。

   <br />

   ```
   {
       "item": "heartRateInterval"
   }
   ```

   <br />

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询心率区间。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询心率区间的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "heartRateInterval");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询心率区间
   manageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、9|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回心率区间，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含心率区间heartRateInterval，heartRateInterval为一个长度为6、降序排列的整数数组，分别代表最大心率（极限心率上限）、极限心率下限（无氧心率上限）、无氧心率下限（有氧心率上限）、有氧心率下限（燃脂心率上限）、燃脂心率下限（热身心率上限）、热身心率下限。

   <br />

   ```
   result样例：
   {
       "heartRateInterval":[110,100,90,80,70,60]
   }
   ```

   |返回值|取值|含义|
   |:----------------|:----------------------------------------------------------------------------------------------------------------------------------|:----|
   |heartRatelnterval|参见[设置心率区间](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-heart-rate-interval-0000002372259061)settingValue取值|心率区间。|
   [表2 result返回值]

   <br />
