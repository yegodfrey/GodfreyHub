# 添加权限

1. 打开**AndroidManifest.xml**文件，在"application"中添加权限。

   ```screen
   <uses-permission android:name="android.permission.INTERNET" />
   <uses-permission android:name="android.permission.BLUETOOTH"
       tools:remove="android:maxSdkVersion" />
   <uses-permission android:name="android.permission.BLUETOOTH_ADMIN"
       tools:remove="android:maxSdkVersion" />
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
   <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
   <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
   ```

   如果行业App需要使用[发送文件](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/send-file-0000002342776776)、[添加音乐到设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/add-music-to-device-0000002383970222)功能，且需要读取外部存储的文件，还要添加外部存储读取权限声明，如果未添加相应权限会导致文件发送失败或者歌曲添加失败（在 Android 11或更高版本中，此权限声明仅支持访问外部存储中的可共享媒体文件：图片、音频文件、视频文件）：

   ```screen
   <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
   ```

   注意：Android 13以上版本READ_EXTERNAL_STORAGE权限已经失效，读取外部存储媒体文件需要增加以下三个细分媒体权限：

   ```screen
   <uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
   <uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
   <uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
   ```

   如果行业App的目标设备版本为Android 10系统，且需要使用[发送文件](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/send-file-0000002342776776)、[添加音乐到设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/add-music-to-device-0000002383970222)功能读取外部存储的文件，建议添加配置：

   ```screen
   android:requestLegacyExternalStorage="true"
   ```

2. 为了保证Health Industry SDK提供的相关能力接口的正常使用，需要在工程中动态申请位置相关权限Manifest.permission.ACCESS_FINE_LOCATION和Manifest.permission.ACCESS_COARSE_LOCATION，参考示例如下。

   ```screen
   // 动态申请：ACCESS_FINE_LOCATION、ACCESS_COARSE_LOCATION
   String[] permissions = new String[] {Manifest.permission.ACCESS_FINE_LOCATION, Manifest.permission.ACCESS_COARSE_LOCATION}

   // 判断是否缺少相关权限
   boolean isLackPermission = false;
   for (String permission : permissions) {
       if (ContextCompat.checkSelfPermission(this, permission) != PackageManager.PERMISSION_GRANTED) {
           isLackPermission = true;
           break;
       }
   }

   // 申请权限
   int permissionRequestCode = 10008;
   if (isLackPermission) {
       ActivityCompat.requestPermissions(this, permissions, permissionRequestCode);
   }
   ```

   如果需要在Android 12以上版本上运行行业App，还要动态申请蓝牙权限Manifest.permission.BLUETOOTH_SCAN和Manifest.permission.BLUETOOTH_CONNECT。

   如果需要使用[发送文件](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/send-file-0000002342776776)、[添加音乐到设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/add-music-to-device-0000002383970222)功能，且需要读取外部存储的文件，还要动态申请外部存储读取权限Manifest.permission.READ_EXTERNAL_STORAGE（注意：在 Android 11或更高版本中，此权限声明仅支持访问外部存储中的可共享媒体文件：图片、音频文件、视频文件；Android 13以上版本Manifest.permission.READ_EXTERNAL_STORAGE已被细分媒体运行时权限Manifest.permission.READ_MEDIA_IMAGES、Manifest.permission.READ_MEDIA_VIDEO、Manifest.permission.READ_MEDIA_AUDIO 替代，开发者需要在代码中动态申请以上细分媒体运行时权限）；如果未申请相应权限会导致文件发送失败或者歌曲添加失败。

3. 如需使用**通知栏消息推送** 功能，需要开发者申请应用的**通知栏使用权限**。参考示例如下。

   ```screen
   private void checkStatusBarNotificationPermission(Context context) {
       if (checkStatusBarPermission()) {
           return;
       }
       // 申请通知栏使用权限
       try {
           Intent intent = new Intent("android.settings.ACTION_NOTIFICATION_LISTENER_SETTINGS");
           intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
           context.startActivity(intent);
       } catch (ActivityNotFoundException e) {
           try {
               Intent intent = new Intent();
               intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
               ComponentName cn = new ComponentName("com.android.settings",
                       "com.android.settings.Settings$NotificationAccessSettingsActivity");
               intent.setComponent(cn);
               intent.putExtra(":settings:show_fragment", "NotificationAccessSettings");
               context.startActivity(intent);
           } catch (Exception ex) {
               LogUtil.e(TAG, "request StatusBar Notification permission error." + ex);
           }
       }
   }

   // 判断当前应用是否拥有通知栏权限
   private boolean checkStatusBarPermission() {
       String pkgName = getPackageName();
       final String flat = Settings.Secure.getString(getContentResolver(), "enabled_notification_listeners");
       if (TextUtils.isEmpty(flat)) {
           return false;
       }
       final String[] names = flat.split(":");
       for (String name : names) {
           final ComponentName cn = ComponentName.unflattenFromString(name);
           if (cn != null && TextUtils.equals(pkgName, cn.getPackageName())) {
               return true;
           }
       }
       return false;
   }
   ```

4. 使用**日历同步** 功能，需要开发者申请**日历读写权限，**在AndroidManifest.xml文件的"application"中添加权限，并且需要动态申请。参考示例如下。

   ```screen
   <!-- AndroidManifest.xml文件的"application"中添加权限 -->
   <uses-permission android:name="android.permission.READ_CALENDAR" />
   <uses-permission android:name="android.permission.WRITE_CALENDAR" />

   // 动态申请：READ_CALENDAR、WRITE_CALENDAR
   // 参考步骤2示例在permissions中加入Manifest.permission.READ_CALENDAR, Manifest.permission.WRITE_CALENDAR
   ```
