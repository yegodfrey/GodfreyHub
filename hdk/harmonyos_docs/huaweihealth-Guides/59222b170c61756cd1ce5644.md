# 查询日常活动汇总数据

查询穿戴设备的当天日常活动汇总数据。当用户佩戴穿戴设备进行日常活动后，行业应用可以通过本接口查询穿戴设备上记录的当天日常活动汇总数据。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryTodaySummation](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section102431619008)方法查询当天日常活动汇总数据。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       device.queryTodaySummation(IndustryService.DataType.FITNESS).then((data: IndustryService.HistoryData[]) => {
         // 处理查询结果
         console.info(`Succeeded in querying todaySummation data, result is ${data}.`);
       }).catch((error: BusinessError) => {
         // 处理查询异常
         console.info(`Failed to query todaySummation data, code: ${error.code}, message: ${error.message}.`);
       })
     })
     .catch((error: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${error.code}, message is ${error.message}.`);
     });
   ```

   查询成功并且有当天日常活动汇总数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)[]，查询成功当天日常活动汇总数据为空返回[]，查询失败抛出BusinessError。

   ```screen
   // 返回的data样例
   [{
       "startTime": 1740153600,
       "endTime": 1740211889,
       "type": "fitness",
       "fields": {
           "totalStep": 1000,
           "totalCalorie": 11125683,
           "totalDistance": 0,
           "totalStrengthTime": 0,
           "totalHeight": 50
       }
   }]
   ```

   |返回值|类型|单位|含义|
   |:----------------|:-----|:-|:--------------|
   |fields|object|-|包含当天日常活动汇总数据对象。|
   |totalStep|number|-|当前总步数值。|
   |totalCalorie|number|卡|当前总活动卡路里数据。|
   |totalDistance|number|米|当前总距离。|
   |totalStrengthTime|number|分钟|当前中高强度总时间。|
   |totalHeight|number|米|当前总爬楼高度。|
   [**表1**返回日常活动汇总数据说明]
