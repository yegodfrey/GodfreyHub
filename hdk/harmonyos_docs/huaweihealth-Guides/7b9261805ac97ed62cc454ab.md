# 抬腕亮屏开关设置和查询

设置与查询穿戴设备的抬腕亮屏开关状态。开启抬腕亮屏开关后，穿戴设备在用户抬腕时自动亮屏。关闭抬腕亮屏开关后，穿戴设备在用户抬腕时不会自动亮屏。穿戴设备首次连接后默认开启抬腕亮屏开关。
> 注意
>
> SDK设置抬腕亮屏开关状态后，存储开关状态到本地，查询时从本地读取开关状态；如果用户在穿戴设备的系统设置中修改抬腕亮屏开关状态，会导致SDK返回错误的查询结果。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setRemindSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section24381853174618)方法设置抬腕亮屏开关状态。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setRemindSwitch方法设置抬腕亮屏开关状态
           try await device.setRemindSwitch(type: .raiseToWakeSwitch, remindSwitchValue: true)

           // 设置抬腕亮屏开关状态成功
           print("Succeeded in setting raiseToWakeSwitch")
       } catch let err as IndustryError {
           // 设置抬腕亮屏开关状态失败
           print("Failed to set raiseToWakeSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getRemindSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section0593868401)方法查询抬腕亮屏开关状态。

   ```screen
   Task {
       do {
           // 调用Device对象的getRemindSwitch方法查询抬腕亮屏开关状态
           let switchValue = try await device.getRemindSwitch(type: .raiseToWakeSwitch)

           // 查询抬腕亮屏开关状态成功
           print("Succeeded in getting raiseToWakeSwitch, switchValue: \(switchValue)")
       } catch let err as IndustryError {
           // 查询抬腕亮屏开关状态失败
           print("Failed to get raiseToWakeSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
