# 查询心率变异性数据

穿戴设备提供测量心率变异性（HRV）能力，用户佩戴设备一段时间后，行业应用可以通过本接口查询穿戴设备上记录的HRV数据。
> 说明
>
> HRV监测频率为10分钟测量一次。HRV测量要求用户处于非活动状态，活动状态下可能不出值。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询心率变异性数据。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryHistoryData方法查询心率变异性数据
           let data = try await device.queryHistoryData(
               type: .hrv,
               startTime: 1778428800,
               endTime: 1778479200
           )

           // 查询心率变异性数据成功
           print("Succeeded in querying hrv, data is \(data)")
       } catch let err as IndustryError {
          // 查询心率变异性数据失败
           print("Failed to query hrv. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   > 说明
   >
   > 查询心率变异性数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   > * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有心率变异性数据返回[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)]，查询成功心率变异性数据为空返回[]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。

   查询成功返回的心率变异性数据样例：

   ```screen
   [
       {
           startTime: 1778473234,
           endTime: 1778473234,
           type: .hrv,
           fields: [
               "heartRateVariabilityRMSSD": 42
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:------------------------|:--|:-|:------|
   |heartRateVariabilityRMSSD|Int|毫秒|心率变异性值。|
