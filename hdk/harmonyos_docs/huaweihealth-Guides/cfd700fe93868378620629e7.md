# 查询单次运动数据

查询穿戴设备用户的单次运动数据。当用户打开锻炼应用完成运动且有运动记录产生后，行业应用可以通过本接口查询穿戴设备上记录的运动数据。
> 说明
>
> * 不支持并发查询单次运动数据，需等待上一次查询结束后方可进行下一次查询。
> * 此接口可以配合[订阅单次运动数据更新](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-workout-update-event-0000002414072668)使用，当订阅的单次运动数据事件上报有数据更新时，调用此接口查询单次运动数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询单次运动数据的ZSON格式的入参数据。

   ```screen
   {
       "item": "workoutData",
       "value": {
           "startTime": 1992342222, // 单位：秒(s)
           "endTime": 1992342229 // 单位：秒(s)
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:--------------------------------------|
   |startTime|UTC时间戳，单位：秒（s）|查询单次运动记录的开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询单次运动记录的结束时间。 注意：结束时间与开始时间的跨度需要<=24小时。|
   [**表1**查询单次运动数据参数]

   > 说明
   >
   > 接口要求查询开始时间和结束时间间隔不超过24小时。

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询单次运动数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询单次运动数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       ZSONObject valueObject= new ZSONObject();
       valueObject.put("startTime", 1992342222);
       valueObject.put("endTime", 1992342229);
       zsonObject.put("item", "workoutData");
       zsonObject.put("value", valueObject);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询单次运动数据
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、6、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回单次运动数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含单次运动数据。

   ```screen
   data样例：
   {
       "totalCount": 1,
       "index": 0,
       "count": 1,
       "dataList": [{
           "workoutRecordId": 1,
           "startTime": 1646806879,
           "endTime": 1646806952,
           "workoutType": 2,
           "accumulativeDropHeight": -1,
           "highestAltitude": -1,
           "lowestAltitude": -1,
           "workoutHrABSPeakMax": 114,
           "workoutHrABSPeakMin": 86,
           "workoutClimb": 0,
           "workoutEtrainingEffect": 0,
           "workoutMaxMET": 48,
           "workoutRecoveryTime": 0,
           "workoutExerciseDuration": 69,
           "workoutLoadPeak": 0,
           "workoutRecordCalorie": 7,
           "workoutRecordDistance": 150,
           "workoutRecordSpeed": "7.83",
           "workoutRecordTotalTime": 69,
           "workoutRecordStep": 133,
           "pace": [{
               "distance": 0,
               "unitType": 0,
               "pace": 460,
               "pointIndex": 0,
               "lastLessDistance": 150
           }, {
               "distance": 0,
               "unitType": 1,
               "pace": 740,
               "pointIndex": 0,
               "lastLessDistance": 150
           }]
       }]
   }
   ```

   |返回值|取值|含义|
   |:----------------------|:-----------------------------------------------------------|:----------------------------|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |workoutRecordId|int类型数据|单次运动记录ID。|
   |startTime|UTC时间，单位：秒|运动起始时间，单位：秒(s)。|
   |endTime|UTC时间，单位：秒|运动结束时间，单位：秒(s)。|
   |workoutType|* 1：户外跑步 * 2：户外步行 * 3：户外骑行 * 4：室内跑步（跑步机） * 5：室内单车 * 255：自由训练|运动类型。|
   |workoutHrABSPeakMax|int类型数据|心率最大值，单位：次/分钟。|
   |workoutHrABSPeakMin|int类型数据|心率最小值，单位：次/分钟。|
   |workoutClimb|long类型数据|累计爬升高度，单位：分米(dm)（仅手表支持）。|
   |workoutEtrainingEffect|long类型数据|训练效果。|
   |workoutMaxMET|long类型数据|最大摄氧量，单位：毫升/公斤/分钟(ml/kg/min)。|
   |workoutRecoveryTime|int类型数据|完全恢复时长，单位：分钟(min)。|
   |workoutExerciseDuration|long类型数据|活动时间，单位：秒(s)。|
   |workoutLoadPeak|long类型数据|运动负荷。|
   |workoutRecordCalorie|long类型数据|卡路里，单位：千卡(kcal)。|
   |workoutRecordDistance|long类型数据|距离，单位：米(m)。|
   |workoutRecordSpeed|String类型数据|平均速度， 单位：公里/小时(km/h)。|
   |workoutRecordTotalTime|long类型数据|总时长，单位：秒(s)。|
   |workoutRecordStep|long类型数据|步数。|
   |accumulativeDropHeight|long类型数据|累计下降高度，单位：分米(dm)（仅手表支持）。|
   |highestAltitude|long类型数据|最高海拔，单位：分米(dm)（仅手表支持）。|
   |lowestAltitude|long类型数据|最低海拔，单位：分米(dm)（仅手表支持）。|
   |pace|int类型数据|配速，单位：秒/公里(s/km)，或秒/英里(s/mi)。|
   |distance|long类型数据|第几公里/英里。从0开始计数。|
   |unitType|int类型数据|单位制，取值： * 0：公制 * 1：英制|
   |pointIndex|int类型数据|从运动开始到配速计算点结束的GPS点累计个数。|
   |lastLessDistance|long类型数据|最后末尾非整公里/英里的距离。单位：米(m)。|
   [**表3**dataList返回值]

   > 说明
   > * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回，不需要开发者再调用查询接口。
   > * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。
