# 定制能力集

本文档主要对HEM和VMALL定制能力集进行介绍，包括HEM和VMALL定制项的输入约束、不同型号设备定制能力集差异等，帮助企业用户更快理解和熟悉定制业务，高效协作，提升企业效率。

不同定制产品支持定制能力如下：  

|途径 定制项|VMALL|HEM||
|途径 定制项|
|-------------------|-------------------|-------|-|
|B5/B9/H3/H5/H9/手环系列|B5/B9/H3/H5/H9/手环系列|B7/H7系列|

![](https://media:301785133807852947)  
1. "/"表示此系列设备不支持此项定制。
2. 三种定制产品中，智能穿戴设备系列企业名称、定制版本号为可选项，其它系列此两项为必选项。
3. VMALL-B5/B9/H3/H5/H9/手环系列和HEM-B5/B9/H3/H5/H9/手环系列，开机logo和表盘至少定制一项。
4. 企业地址、联系方式、电子邮箱三项为Vmall定制资源必填项，但在设备侧不展示。
