# 添加设备

行业App选择需要连接的穿戴设备进行配对连接，行业App首次添加设备前需要开启终端设备（例如：手机等）侧的蓝牙与位置相关权限，[设置证书路径](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-cert-path-0000002372256561)并[注册连接状态监听](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/register-connection-status-listener-0000002338298252)。  
![](https://media:301785133823750139)  
1. 如果穿戴设备连接过运动健康APP，请先在运动健康APP中删除穿戴设备，同时穿戴设备必须恢复出厂设置，再使用行业App添加该穿戴设备。
2. 如果穿戴设备（HUAWEI Band 6 B10、HUAWEI Band 6 B20除外）连接过行业App，重新调用添加设备时，请先在行业APP中删除穿戴设备，同时穿戴设备必须进行恢复出厂设置，如果穿戴设备未恢复出厂设置，行业App进行添加穿戴设备，穿戴设备会有"恢复出厂"弹窗，穿戴设备需恢复出厂后才能添加穿戴设备。
3. SDK版本从2.13.0.102开始，连接新设备时，如果已有设备处于已连接状态，该设备会自动断开连接。  
![](https://media:301785133823787140)  
SDK版本从2.13.0.102开始：

* 添加设备接口支持设置用户账号参数。如果开发者有自己的账号体系，可以通过此参数设置用户账号。每次添加设备时如果用户账号一致，则不需要设备强制恢复出厂设置。当行业App删除设备且设备未恢复出厂时，若用户使用相同账号重新添加设备，行业App需要重新下发删除设备前的设置。
* 行业App添加设备成功后会自动同步手机的时间给穿戴设备（除HUAWEI WATCH B7-536/HUAWEI WATCH B7-738/HUAWEI WATCH H7546外，手机时间的24/12小时制也会同步给穿戴设备）。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)的[getDeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceConnectClient-android_content_Context-)方法获取[DeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800)对象。
2. 构造添加设备的JSON格式参数。

   <br />

   ```
   {
       "deviceName": "HUAWEI Fara-B69-66A",
       "mac": "F4:87:C5:90:16:6A",
       "bluetoothType": 0,
       "userId": "a87c38475da045349dee"    
   }
   ```

   |参数|类型|含义|
   |:----------------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |deviceName|String|穿戴设备名称（非设备唯一标识）。|
   |mac0|String|穿戴设备mac地址（设备唯一标识）。|
   |bluetoothType（可选）|int|支持指定蓝牙连接模式： * 0：自动选择连接模式（默认） * 1：指定BLE连接模式（仅[智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)、HUAWEI WATCH H5546及以后的[轻量级智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li1184517579555)支持）|
   |userId（可选）|String|用户账号，只包含字母和数字，长度不能超过256个字符。2.13.0.102版本新增参数，解配对后使用相同账号添加设备，设备不需要恢厂。|
   [表1 添加设备参数]

   <br />

3. 调用[addDevice](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800#ZH-CN_TOPIC_0000002648084238__addDevice-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)发起添加设备。

   <br />

   ```
   // 获取DeviceConnectClient对象
   DeviceConnectClient deviceConnectClient = IndustryWear.getDeviceConnectClient(this);

   // 构建Json参数，deviceName为设备名称，mac为设备mac地址
   JSONObject deviceInfo = new JSONObject();
   try {
       deviceInfo.put("deviceName", deviceName);
       deviceInfo.put("mac", mac);
       deviceInfo.put("bluetoothType", bluetoothType);
       deviceInfo.put("userId", userId);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 发起添加设备
   deviceConnectClient.addDevice(deviceInfo.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------------------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、23、25、26、28、29、31|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   添加设备过程中，若需要取消添加设备，请调用以下接口取消添加设备。  
   ![](https://media:301785133823827141)  
   如果您在添加设备接口有传入bluetoothType字段，请确保此接口传入相同的bluetoothType。

   ```
   // 发起取消添加设备
   deviceConnectClient.cancelAddDevice(deviceInfo.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、23、26|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [表3 ServiceCallback返回值]
