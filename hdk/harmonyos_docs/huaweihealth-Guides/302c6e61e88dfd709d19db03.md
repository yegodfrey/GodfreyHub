# 订阅运动状态

订阅和取消订阅穿戴设备的运动状态。订阅成功后，穿戴设备在运动进入相关控制状态时会上报运动状态。取消订阅后，不再上报运动状态。
> 说明
>
> * 穿戴设备在准备运动、退出准备运动、开始运动、暂停运动、继续运动、结束运动等控制状态下，均会上报运动状态。
> * 支持在穿戴设备熄屏状态下上报运动状态。

1. 导入相关模块。


2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section141971612182616)方法订阅运动状态。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError, Callback } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 运动状态事件回调
       let callback: Callback<IndustryService.EventData> = (eventData: IndustryService.EventData) => {
         // 处理运动状态事件
         console.info(`report exerciseTypeChangedEvent: ${JSON.stringify(eventData)}`);
       };
       // 调用Device对象的subscribeEvent方法订阅运动状态
       device.subscribeEvent(IndustryService.EventType.EXERCISE_TYPE_CHANGED_EVENT, callback).then(() => {
         // 订阅运动状态成功
         console.info('Succeeded in subscribing exerciseTypeChangedEvent.');
       }).catch((err: BusinessError) => {
         // 订阅运动状态失败
         console.error(`Failed to subscribe exerciseTypeChangedEvent. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
     // 获取穿戴设备列表失败
     console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
   });
   ```


5. 运动状态事件在Callback<IndustryService.[EventData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7634104243910)>中处理。运动状态变化时eventData中包含事件类型（event）和运动状态类型（status）。

   ```screen
   eventData样例：
   {
     event: 'exerciseTypeChangedEvent',
     status: 23
   }
   ```

   |数据项|取值|含义|
   |:-----|:--------------------------------------------------------------------------------------------------------------------------|:----------------|
   |status|运动状态码，参考[运动状态](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/sport-status-enumeration-0000002338268622)。|当前处于运动状态码对应的运动状态。|
   [**表1**运动状态类型]

6. 需要取消订阅时，调用[unSubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section29691015152720)方法取消订阅运动状态。

   ```screen
   // 调用Device对象的unSubscribeEvent方法取消订阅运动状态。注意：这里的callback和上述运动状态回调要为同一个对象
   device.unSubscribeEvent(IndustryService.EventType.EXERCISE_TYPE_CHANGED_EVENT, callback).then(() => {
     // 取消订阅成功
     console.info('Succeeded in unsubscribing exerciseTypeChangedEvent.');
   }).catch((err: BusinessError) => {
     // 取消订阅失败
     console.error(`Failed to unsubscribe exerciseTypeChangedEvent. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   > 说明
   >
   > 取消订阅传入的callback，要求和订阅时传入的callback为同一个对象。
