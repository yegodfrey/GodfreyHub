# 生成签名证书文件及其指纹

开发者通过Android Studio创建一个新的签名文件用于对行业App进行签名，并生成签名证书的指纹用于在开发者联盟申请账号服务。

如果开发者没有行业App的签名证书，请先[生成签名证书文件](#section9130185816368)，再执行[生成签名证书指纹](#section11131558123616)；如果已有签名证书文件，执行[生成签名证书指纹](#section11131558123616)即可。

## 生成签名证书文件

本节中的所有操作步骤和截图均基于Android Studio 2025.1.2.2版本。

1. 在新建的Android Studio工程的菜单栏中选择"Build > Generate Signed App Bundle or APK..."。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/f6pd0E_yROO7C53pzsAy0Q/zh-cn_image_0000002648084576.png?HW-CC-KV=V1&HW-CC-Date=20261008T154738Z&HW-CC-Expire=31536000000&HW-CC-Sign=0431B40E72DCD3042756B1A8C5D17F2369B7065B7EACC7A99A8A5127EC8554A0)

2. 在"Generate Signed App Bundle or APK"页面，选择"APK"签名，并点击"Next"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/IA0l7XjmRh2AganlK5VE9g/zh-cn_image_0000002678164293.png?HW-CC-KV=V1&HW-CC-Date=20261008T154738Z&HW-CC-Expire=31536000000&HW-CC-Sign=B7EE61242C0D810B38EF8898246F9817D337A1635BCF29520726EC4A4D6A88D3)

3. 在填写签名文件信息页面，点击"Create new..."，创建一个新的签名文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/PkvvhToFQLOtKyscSnDQMA/zh-cn_image_0000002647924692.png?HW-CC-KV=V1&HW-CC-Date=20261008T154738Z&HW-CC-Expire=31536000000&HW-CC-Sign=6B4C284137BB3473621D5AC69662BA8D87DBB330E781DB787CE7110D38EA599C)

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f7/v3/mOAAFKDpSBSSYGVq2O3XGQ/zh-cn_image_0000002678004457.png?HW-CC-KV=V1&HW-CC-Date=20261008T154738Z&HW-CC-Expire=31536000000&HW-CC-Sign=D78BCFDDF481A095C12F3A344840CB042CC623BA130103ACAE807D8A47183903)

## 生成签名证书指纹

1. Windows操作系统下，执行CMD命令打开命令行工具；MacOS操作系统下，打开Terminal终端。执行cd命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

   ```screen
   cd C:\Program Files\Java\jdk\bin
   ```

2. 执行命令keytool -list -keystore <*keystore-file* >，其中<keystore-file>为签名证书的完整路径（以下样例以*D:\Code\Demo\industryDemo.jks*为例，实际执行时请输入正确的签名证书完整路径）。

   ```screen
   keytool -list -keystore D:\Code\Demo\industryDemo.jks
   ```

3. 按命令行提示输入签名文件的密码，获取对应的SHA256证书指纹。
