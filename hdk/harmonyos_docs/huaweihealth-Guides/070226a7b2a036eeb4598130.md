# 生成签名证书文件及其指纹

开发者通过Android Studio创建一个新的签名文件用于对行业App进行签名，并生成签名证书的指纹用于在开发者联盟申请账号服务。

如果开发者没有行业App的签名证书，请先[生成签名证书文件](#section9130185816368)，再执行[生成签名证书指纹](#section11131558123616)；如果已有签名证书文件，执行[生成签名证书指纹](#section11131558123616)即可。

## 生成签名证书文件

本节中的所有操作步骤和截图均基于Android Studio 2025.1.2.2版本。

1. 在新建的Android Studio工程的菜单栏中选择"Build > Generate Signed App Bundle or APK..."。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/f6pd0E_yROO7C53pzsAy0Q/zh-cn_image_0000002648084576.png?HW-CC-KV=V1&HW-CC-Date=20260909T144836Z&HW-CC-Expire=31536000000&HW-CC-Sign=13FEB193D6A1A567D147076346E80B8C923C3526B8CA85AA0E6F13960B251560)

2. 在"Generate Signed App Bundle or APK"页面，选择"APK"签名，并点击"Next"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/IA0l7XjmRh2AganlK5VE9g/zh-cn_image_0000002678164293.png?HW-CC-KV=V1&HW-CC-Date=20260909T144836Z&HW-CC-Expire=31536000000&HW-CC-Sign=0EEAFF0C7219BAC8AB6DC0E8AD9740995A27ACCD4B745331327E9A30B5B08121)

3. 在填写签名文件信息页面，点击"Create new..."，创建一个新的签名文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/PkvvhToFQLOtKyscSnDQMA/zh-cn_image_0000002647924692.png?HW-CC-KV=V1&HW-CC-Date=20260909T144836Z&HW-CC-Expire=31536000000&HW-CC-Sign=D0D271C9A0DEEA1A5C4FC13B2972A3C54B3528BBDD7BFBCF76A1F4BA50396AEB)

4. 在创建新的签名文件页面，填写签名文件的保存地址以及保存文件名称、签名文件的密码、Alias等信息，点击"OK"完成签名文件创建。（以下为填写样例，请按照实际情况填写签名文件信息）

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f7/v3/mOAAFKDpSBSSYGVq2O3XGQ/zh-cn_image_0000002678004457.png?HW-CC-KV=V1&HW-CC-Date=20260909T144836Z&HW-CC-Expire=31536000000&HW-CC-Sign=1489D10EC05CE67B31C45647B0343810657279C9CE231A448E3BE2751AC7B4FD)

5. 完成签名文件创建后，回到"Generate Signed App Bundle or APK"弹出框页面，点击"Cancel"退出。打开[步骤4](#ZH-CN_TOPIC_0000002648084346__li153189141022)中选择的"Key store path"，可以看到生成的签名证书文件。

## 生成签名证书指纹

1. Windows操作系统下，执行CMD命令打开命令行工具；MacOS操作系统下，打开Terminal终端。执行cd命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

   ```screen
   cd C:\Program Files\Java\jdk\bin
   ```

2. 执行命令keytool -list -keystore <*keystore-file* >，其中<keystore-file>为签名证书的完整路径（以下样例以*D:\Code\Demo\industryDemo.jks*为例，实际执行时请输入正确的签名证书完整路径）。

   ```screen
   keytool -list -keystore D:\Code\Demo\industryDemo.jks
   ```

3. 按命令行提示输入签名文件的密码，获取对应的SHA256证书指纹。
