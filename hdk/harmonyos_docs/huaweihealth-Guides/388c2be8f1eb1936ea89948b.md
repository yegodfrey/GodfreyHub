# 订阅心率告警

订阅和取消订阅穿戴设备的心率告警信息。订阅成功后，当穿戴设备产生心率告警时返回心率告警信息。取消订阅后，不再返回心率告警信息。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section484944212315)方法订阅心率告警。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的subscribeEvent方法订阅心率告警信息
           let uuid = try await device.subscribeEvent(type: .heartRateAlarmEvent) { eventData in
               print("Event report. Event: \(eventData.event), status: \(eventData.status)")
           }

           // 订阅心率告警信息成功
           print("Succeeded in subscribing heartRateAlarmEvent")
       } catch let err as IndustryError {
           // 订阅心率告警信息失败
           print("Failed to subscribe heartRateAlarmEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 设备心率告警信息在(EventData) -> Void闭包中处理。心率告警时eventData中包含事件类型（event）和心率告警类型（status）。

   ```screen
   eventData样例：
   {
       "event": "heartRateAlarmEvent",
       "status": 1
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:------|
   |status|1|静态心率过高。|
   |status|2|静态心率过低。|
   [**表1**心率告警信息]

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[unsubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section686172218408)方法取消订阅心率告警。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 调用Device对象的unsubscribeEvent方法取消订阅心率告警信息
           try await device.unsubscribeEvent(type: .heartRateAlarmEvent, subscribeId: uuid)

           // 取消订阅心率告警信息成功
           print("Succeeded in unsubscribing heartRateAlarmEvent")
       } catch let err as IndustryError {
           // 取消订阅心率告警信息失败
           print("Failed to unsubscribe heartRateAlarmEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   > 说明
   >
   > 取消订阅传入的uuid，要求和订阅返回的uuid为同一个对象。
