# 监听行业应用与行业服务连接状态

行业服务作为一个独立的进程运行，当系统内存紧张或行业服务功耗过高等场景，系统会杀死行业服务，从而导致行业应用与行业服务的连接断开。对于类似这种不确定的断开场景，开发者可以监听行业应用与行业服务连接状态，然后做相应的恢复动作，如：重新订阅心率数据。  
![](https://media:301785133809802961)  
此接口仅能监听到行业应用与行业服务连接断开的事件。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[on](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section3953113762210)方法，监听行业应用与行业服务连接状态。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 构造行业应用与行业服务连接断开时执行的回调函数
   let callback = () => {
     console.info('The service destruction event.');
   }
   // 调用industryServiceClient中的on方法，订阅监听行业应用与行业服务的断连事件
   try {
     industryServiceClient.on('serviceDie', callback);
     // 订阅监听行业应用与行业服务的断连事件成功
     console.info('Succeeded in subscribing the service destruction event.');
   } catch (error) {
     // 订阅监听行业应用与行业服务的断连事件失败 
     const err: BusinessError = error as BusinessError;
     console.error(`Failed to subscribe the service destruction event. Code is ${err.code}, message is ${err.message}`);
   }
   ```

   <br />

3. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[off](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section202781268276)方法，取消监听行业应用与行业服务连接状态。

   <br />

   ```
   // 调用industryServiceClient中的off方法，取消监听行业应用与行业服务的断连事件。注意：这里的callback和上述行业应用与行业服务连接断开时执行的回调函数要为同一对象
   try {
     industryServiceClient.off('serviceDie', callback);
     // 取消监听行业应用与行业服务的断连事件成功
     console.info('Succeeded in unsubscribing the service destruction event.');
   } catch (error) {
     // 取消监听行业应用与行业服务的断连事件失败
     const err: BusinessError = error as BusinessError;
     console.error(`Failed to unsubscribe the service destruction event. Code is ${err.code}, message is ${err.message}`);
   }
   ```

   ![](https://media:301785133809976962)  
   取消订阅传入的callback，要求和订阅时传入的callback为同一个对象。

   <br />
