# 查询日常活动状态数据

查询穿戴设备的日常活动状态。用户佩戴穿戴设备进行日常活动后，行业App可以通过本接口查询穿戴设备上记录的活动状态类型和活动持续时长。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询日常活动状态数据。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryHistoryData方法查询日常活动状态数据
           let data = try await device.queryHistoryData(
               type: .fitnessStatus,
               startTime: 1778461200,
               endTime: 1778464800
           )

           // 查询日常活动状态数据成功
           print("Succeeded in querying fitness status, data is \(data)")
       } catch let err as IndustryError {
           // 查询日常活动状态数据失败
           print("Failed to query fitness status. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   ![](https://media:301785133823080128)  
   查询日常活动状态接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有日常活动状态返回\[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)\]，查询成功日常活动状态为空返回\[\]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。  
   查询成功返回的日常活动状态样例：

   ```
   [
       {
           startTime: 1778461860,
           endTime: 1778461920,
           type: .fitnessStatus,
           fields: [
               "statusType": 1,
               "duration": 1
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:---------|:--|:-|:-------------------------------------------------------------------------------------------------------------------------------------------|
   |statusType|Int|-|日常活动状态类型，请参考[日常活动状态说明](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/daily-activity-status-enumeration-0000002372186769)。|
   |duration|Int|分钟|此种活动状态持续的时间。|
