# 设置用户账号

给配对设备设置用户账号。如果不调用此接口设置用户账号，SDK会生成一个随机用户账号下发给设备。  
![](https://media:301785133824709151)  
* 此方法并非立即下发用户账号给设备，而是在[连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/connect-device-0000002624549015)时把用户账号下发给设备。
* 行业SDK连接不同用户账号的设备，设备需要先进行恢复出厂设置。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)的[setUserId](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section935819365181)方法给配对设备设置用户账号。

   <br />

   ```
   import IndustrySDK

   Task {
       do {
           let uId = "123456"
           try await IndustryService.setUserId(userId: uId)
       } catch let err as IndustryError {
           print("Failed to set user id. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
