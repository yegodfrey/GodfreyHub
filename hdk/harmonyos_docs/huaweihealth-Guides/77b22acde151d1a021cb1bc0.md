# 查询睡眠历史数据

穿戴设备提供实时监测睡眠与呼吸质量能力，用户佩戴穿戴设备入睡（夜间睡眠或者午睡）后，行业应用可以通过本接口查询穿戴设备上记录的睡眠数据。
> 说明
>
> * 穿戴设备侧收集睡眠数据要求提前开启科学睡眠开关，查询睡眠数据前请先确保已调用[科学睡眠开关设置与查询](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-trusleep-switch-0000002376514397)接口打开科学睡眠开关且用户有睡眠行为。
> * 需要采集睡眠数据时，建议在查询时间段内佩戴穿戴设备入睡且睡眠时间超过3个小时（午睡除外），否则穿戴设备侧可能会返回空数据。
> * 不支持并发查询睡眠数据，需等待上一次查询结束后方可进行下一次查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询睡眠历史数据。

   ```screen
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询睡眠数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.SLEEP,
         startTime: 1736521200,
         endTime: 1736547600
       };

       // 调用Device对象的queryHistoryData方法查询睡眠数据
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 查询睡眠数据成功, 打印接口返回的睡眠数据
         console.info(`Succeeded in querying sleep data, result is ${data}.`);
       }).catch((err: BusinessError) => {
         // 查询睡眠数据失败
         console.error(`Failed to query sleep data. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   > 说明
   >
   > 查询睡眠历史数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有睡眠数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)[]，查询成功睡眠数据为空返回[]，查询失败抛出BusinessError。
