# 订阅日常活动数据

订阅和取消订阅穿戴设备用户的日常活动数据。订阅成功后，当用户的日常活动数据变化时上报日常活动数据。取消订阅后，不再上报日常活动数据。
> 说明
>
> * 订阅日常活动为设备低功耗上报，即订阅后日常活动数据发生改变，熄屏状态下不上报，亮屏状态下才上报。
> * 日常活动数据有时出现上报相同数据的情况，因为未开放的数据更新也会触发活动数据上报，导致出现上报的数据相同的情况。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅日常活动数据的ZSON格式的入参数据。

   ```screen
   {
       "item": "dailyTotalData"
   }
   ```


3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅日常活动数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅日常活动数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "dailyTotalData");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅日常活动数据
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   };
   deviceManageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、8|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；订阅成功后，日常活动数据发生改变则上报日常活动数据。|
   [**表1**ServiceCallback返回值]


4. 订阅操作的结果和设备日常活动数据信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；设备产生日常活动数据时返回statusCode为8，data数据中包含日常活动数据。

   ```screen
   data样例：
   {
       "totalStep":194,
       "totalCalorie":245,
       "totalDistance":119,
       "totalStrengthTime":0,
       "totalHeight":200
   }
   ```

   |返回值|取值|含义|
   |:----------------|:---------|:---------------|
   |totalStep|int类型数据|步数值。|
   |totalCalorie|double类型数据|当前卡路里，单位：卡。|
   |totalDistance|double类型数据|当前距离，单位：米。|
   |totalStrengthTime|int类型数据|当前中高强度总时间，单位：分钟。|
   |totalHeight|double类型数据|爬楼高度，单位：米。|
   [**表2**data返回订阅信息]


5. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅日常活动数据。

   ```screen
   // 调用unSubscribe方法取消订阅日常活动数据。
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   deviceManageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```
