# 订阅动态血压测量状态

订阅和取消订阅穿戴设备的动态血压测量状态。订阅成功后，当穿戴设备动态血压测量状态变化时返回动态血压测量状态信息。取消订阅后，不再返回动态血压测量状态信息。
> 说明
>
> 此接口仅在支持动态血压测量的穿戴设备上可用，当前支持HUAWEI WATCH H9D20设备。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于订阅或取消订阅动态血压测量状态的JSON格式参数。

   ```screen
   {
       "item": "dynamicBloodPressureStatus"
   }
   ```

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅动态血压测量状态。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于订阅或取消订阅动态血压测量状态的JSON格式的入参数据 
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "dynamicBloodPressureStatus");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅动态血压测量状态
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   };
   manageClient.subscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:----------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、10、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|订阅成功时返回空字符串，订阅失败时返回错误信息，设备动态血压测量状态变化时返回动态血压测量状态信息。|
   [**表1**ServiceCallback返回值]

   > 说明
   >
   > 订阅动态血压测量状态的ServiceCallback不仅会返回订阅操作的结果，另外还会返回后续订阅的事件上报时的数据。

5. 订阅操作的结果和设备动态血压测量状态信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，result为空字符串；失败时statusCode返回错误码，result返回对应错误信息；设备动态血压测量状态变化时返回statusCode为10，result数据中包含动态血压测量状态。

   ```screen
   result样例：
   {
       "planId":"W_4:D8_1742201815000",
       "planStartTime":1742201815,
       "planEndTime":1742288215,
       "planLocalData":1742207266,
       "ratio":0.08,
       "lastSystolic":129,
       "lastDiastolic":95,
       "lastTimestamp":1742207266
   }
   ```

   |返回值|取值|含义|
   |:------------|:---------|:--------------------|
   |planId|String类型数据|动态血压测量计划id。|
   |planStartTime|long类型数据|计划开始时间，UTC时间戳，单位：秒。|
   |planEndTime|long类型数据|计划结束时间，UTC时间戳，单位：秒。|
   |planLocalData|long类型数据|计划本地日期，UTC时间戳，单位：秒。|
   |ratio|double类型数据|计划完成进度，百分比，保留两位小数。|
   |lastSystolic|int类型数据|最近一次测量的收缩压。|
   |lastDiastolic|int类型数据|最近一次测量的舒张压。|
   |lastTimestamp|long类型数据|最近一次测量时间，UTC时间戳，单位：秒。|
   [**表2**result返回订阅信息]

   > 说明
   >
   > 穿戴设备断开连接时进行动态血压测量，重新连接后测量结束会上报两条动态血压测量状态。

6. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅动态血压测量状态。

   ```screen
   // 调用unSubscribe方法取消订阅动态血压测量状态
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   > 说明
   >
   > 取消订阅成功条件：
   > * 取消订阅时要求输入的解订阅参数和订阅时的参数一致。
   > * 取消订阅时传入的ServiceCallback，要求和订阅时传入的ServiceCallback为同一个对象。
