# 订阅日常健康数据更新

订阅和取消订阅穿戴设备的日常健康数据更新事件。订阅成功后，当穿戴设备判断达成日常健康数据更新条件后，上报日常健康数据更新事件。取消订阅后，不再上报日常健康数据更新事件。
> 说明
>
> * **只有亮屏时才会上报数据更新事件，灭屏时不会上报数据更新事件**。
> * 每小时首次站立状态改变会上报数据更新事件。
> * 只要设备侧判断达到以下四个条件中的任意一个，则会上报数据更新事件，同时把四个条件的统计数值重置为0：
>   * 步数达到500步
>   * 距离达到1000米
>   * 活动时间达到1小时
>   * 卡路里消耗达到100千卡

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅日常健康数据更新事件的ZSON格式的入参数据。

   ```screen
   {
       "item": "dailyHealthUpdateEvent"
   }
   ```

3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅日常健康数据更新事件。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅日常健康数据更新事件的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "dailyHealthUpdateEvent");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅日常健康数据更新事件
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理订阅返回信息
       }
   }
   manageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:---------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、7、10|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；设备日常健康数据更新事件上报时返回{"rtnMsg":"event reported."}。|
   [**表1**ServiceCallback返回值]

   > 说明
   >
   > 订阅日常健康数据更新事件的ServiceCallback不仅会返回订阅操作的结果，另外还会返回后续订阅的事件上报时的数据。

4. 订阅操作的结果和设备日常健康数据更新事件变化信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；设备日常健康数据更新事件变化时返回statusCode为10，data为{"rtnMsg":"event reported."}。
5. 调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅日常健康数据更新事件。

   ```screen
   // 调用unSubscribe方法取消订阅日常健康数据更新事件。
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   manageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```
