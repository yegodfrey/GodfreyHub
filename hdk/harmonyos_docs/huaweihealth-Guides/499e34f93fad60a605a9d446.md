# 设置实时心率联动开关

设置行业App与穿戴设备的实时心率联动开关状态。开启实时心率联动开关后，[订阅实时心率](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-realtime-heart-rate-data-0000002376595249)将每秒上报心率数据。关闭实时心率联动开关后，不再上报心率数据。  
![](https://media:301785133839255374)  
* 当前接口仅开启设备上报心率数据，不对返回的心率数据处理，开发者需要首先调用[订阅实时心率](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-realtime-heart-rate-data-0000002376595249)进行订阅，实现对实时心率数据的处理逻辑。
* 如果在心率联动过程中解除佩戴或者设备断开连接，设备会自动停止心率联动，恢复佩戴或者重新连接后需要重新开启心率联动才会再次进行心率数据联动。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置实时心率联动开关的JSON格式参数。

   <br />

   ```
   {
       "settingKey": "realtimeHeartRate",
       "settingValue": {
           "operateType": 1
       }
   }
   ```

   |参数|取值|含义|
   |:-----------|:-----------------|:----------|
   |settingKey|realtimeHeartRate|实时心率联动开关键值。|
   |settingValue|包含以下参数：operateType|实时心率联动开关内容。|
   |operateType|1|开启实时心率联动。|
   |operateType|2|关闭实时心率联动。|
   [表1 设置实时心率联动开关参数]

   <br />

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置实时心率联动开关。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于设置实时心率联动开关的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject subJsonObject = new JSONObject();
       subJsonObject.put("operateType", 1);
       jsonObject.put("settingKey", "realtimeHeartRate");
       jsonObject.put("settingValue", subJsonObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置实时心率联动开关
   manageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、303|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />
