# 查询日历同步开关

查询穿戴设备的日历同步开关状态。
> 说明
>
> * 未开启日历权限时，穿戴设备首次连接后日历同步开关无默认值，查询返回错误码9。
> * 开启日历权限后，穿戴设备首次连接后默认开启日历同步开关。
> * 设置日历同步开关后，关闭日历权限查询返回最后一次设置的开关值。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询日历同步开关的JSON格式参数。

   ```screen
   {
       "item": "syncCalendarSwitch"
   }
   ```

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询日历同步开关。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询日历同步开关的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "syncCalendarSwitch");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询日历同步开关
   manageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:---------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、9、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回日历同步开关值，失败时返回错误信息。|
   [**表1**ServiceCallback返回值]

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含日历同步开关。

   ```screen
   result样例：
   {
       "syncCalendarSwitch":1
   }
   ```

   |返回值|取值|含义|
   |:-----------------|:-|:--------|
   |syncCalendarSwitch|0|日历同步开关关闭。|
   |syncCalendarSwitch|1|日历同步开关开启。|
   [**表2**result返回值]
