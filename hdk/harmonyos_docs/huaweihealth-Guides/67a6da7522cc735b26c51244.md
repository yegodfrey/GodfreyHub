# 订阅单次运动数据更新

订阅和取消订阅穿戴设备的单次运动数据更新事件。订阅成功后，当穿戴设备单次运动结束后，上报单次运动数据更新事件。取消订阅后，不再上报单次运动数据更新事件。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅单次运动数据更新的ZSON格式的入参数据。

   ```screen
   {
       "item": "workoutUpdateEvent"
   }
   ```

3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅单次运动数据更新。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅单次运动数据更新的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "workoutUpdateEvent");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅单次运动数据更新
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理订阅返回信息
       }
   }
   manageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、7、10|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；设备单次运动数据更新事件上报时返回{"rtnMsg":"event reported."}。 当前只有以下运动类型支持上报运动数据更新事件： * 1：户外跑步 * 2：户外步行 * 3：户外骑行 * 4：室内跑步（跑步机） * 5：室内单车 * 255：自由训练|
   [**表1**ServiceCallback返回值]

   > 说明
   >
   > 订阅单次运动数据更新事件的ServiceCallback不仅会返回订阅操作的结果，另外还会返回后续订阅的事件上报时的数据。

4. 订阅操作的结果和设备单次运动数据更新事件变化信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；设备单次运动数据更新事件变化时返回statusCode为10，data为{"rtnMsg":"event reported."}。
5. 调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅单次运动数据更新事件。

   ```screen
   // 调用unSubscribe方法取消订阅单次运动数据更新。
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   manageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```
