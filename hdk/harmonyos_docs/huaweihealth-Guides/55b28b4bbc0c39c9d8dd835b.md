# 发送文件

行业App向穿戴设备侧应用发送文件。
> 说明
>
> * [智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)在超长续航模式下不支持发送文件。
> * 若要使用发送文件到穿戴设备侧应用功能，穿戴设备侧需安装相对应的通信应用，参考[穿戴设备侧应用开发](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/version-change-history-0000001119036892)。
> * 仅支持[自动选择连接模式](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/add-device-0000002338138536#ZH-CN_TOPIC_0000002678163965__li132048191618)下的配对的[智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)。
> * 暂不支持行业矿灯。
> 注意
>
> 如果您行业App需要支持访问外部存储，您需要申请读写权限。
>
> 如果访问外部存储需支持Android10及以上，需要在主工程AndroidManifest.xml的application中增加android:requestLegacyExternalStorage="true"。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于向穿戴设备侧应用发送文件的JSON格式参数。

   ```screen
   {
       "item": "p2pSendFile",
       "value": {
           "peerPkgName": "com.huawei.aa",
           "peerFingerPrint": "com.huawei.aa_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
           "filePath": "\/sdcard\/a.png"
       }
   }
   ```

   |参数|取值|含义|
   |:--------------|:----------|:-----------------------------------------------------------------------------------------------------------------------|
   |item|p2pSendFile|发送文件到穿戴设备侧应用|
   |peerPkgName|-|穿戴设备侧[应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)|
   |peerFingerPrint|-|[穿戴设备侧应用签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/signature-0000001053969657)|
   |filePath|-|行业App文件传输路径（文件大小不超过4MB）|
   [**表1**向穿戴设备侧应用发送文件参数]

4. 调用[send](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__send-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法向穿戴设备侧应用进行发送文件。

   > 说明
   >
   > 请先调用[检查穿戴侧应用是否在线](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/check-app-online-0000002376734761)检测穿戴侧应用是否在线，确认应用在线后再发送文件。

   ```screen
   // 步骤1 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 步骤2 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 步骤3 创建向穿戴设备侧应用发送文件的Json对象
   JSONObject jsonObject = new JSONObject();
   JSONObject valueObject = new JSONObject();
   try {
       valueObject.put("peerPkgName", "com.huawei.aa");
       valueObject.put("peerFingerPrint", "com.huawei.aa_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx");
       valueObject.put("filePath", "\/sdcard\/a.png");
       jsonObject.put("item", "p2pSendFile");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 步骤4 调用send方法给穿戴设备侧发送文件
   deviceManageClient.send(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:--------------------------------|:-------------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、26、30、206、207、208、210|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码和设备间消息通信状态码|
   |result|-|接口调用失败时返回错误信息，成功时发送文件时返回传输文件进度|
   [**表2**ServiceCallback返回值]

   |返回值|含义|
   |:-------|:----------|
   |progress|行业App发送文件进度|
   [**表3**result返回值]

   行业App发送文件到穿戴设备侧应用过程中会不断返回发送的进度，当进度为100时说明文件发送完成。

   ```screen
   // 文件发送中
   {
       "progress": 0
   }
   {
       "progress": 1
   }
   ...
   // 文件发送完成
   {
      "progress": 100
   }
   ```
