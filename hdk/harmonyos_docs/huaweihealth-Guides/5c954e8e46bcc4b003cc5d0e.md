# 脉搏波心律失常自动检测开关设置与查询

设置与查询穿戴设备的心律失常自动检测开关状态。开启心律失常自动检测开关后，穿戴设备将定期自动测量心律失常数据。关闭心律失常自动检测开关后，穿戴设备将不会自动测量PPG数据。  
![](https://media:301785133829990222)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
* 脉搏波心律失常功能未激活时，调用此接口设置无效。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section116193619289)方法设置心律失常自动检测开关。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造设置心律失常自动检测开关参数
       let switches: boolean = true;
       // 调用Device对象的setSettingInfo方法设置心律失常自动检测开关
       device.setSettingInfo(IndustryService.SettingType.PPG_PERIOD_SWITCH, switches).then(() => {
         // 设置心律失常自动检测开关成功
         console.info('Succeeded in setting PPG period switch.');
       }).catch((err: BusinessError) => {
         // 设置心律失常自动检测开关失败
         console.error(`Failed to set PPG period switch. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section134881731165612)方法查询心律失常自动检测开关。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询心律失常自动检测开关
   device.getSettingInfo(IndustryService.SettingType.PPG_PERIOD_SWITCH).then((result: boolean) => {
     // 查询心律失常自动检测开关成功，打印返回的开关状态
     console.info(`Succeeded in getting PPG period switch, result is ${result}.`);
   }).catch((err: BusinessError) => {
     // 查询心律失常自动检测开关失败
     console.error(`Failed to get PPG period switch. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   <br />
