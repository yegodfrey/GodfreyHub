# 查询压力数据

穿戴设备提供压力测量能力，用户佩戴穿戴设备测量压力后，行业应用可以通过本接口查询穿戴设备上记录的压力数据。
> 说明
>
> * 获取穿戴设备的压力数据，请提前开启情绪/压力自动检测开关，参见[情绪/压力自动检测开关设置与查询](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-emotion-switch-0000002526499302)。
> * 需要采集压力数据时，建议在查询时间段内佩戴穿戴设备超过30分钟，否则穿戴设备侧可能返回空数据。
> * 不支持并发查询压力数据，需等待上一次查询结束后方可进行下一次查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询压力数据。

   ```screen
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询压力数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.STRESS,
         startTime: 1736580274,
         endTime: 1736580330
       };

       // 调用Device对象的queryHistoryData方法查询压力数据
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 查询压力数据成功, 打印接口返回的压力数据
         console.info(`Succeeded in querying stress data, result is ${data}.`);
       }).catch((err: BusinessError) => {
         // 查询压力数据失败
         console.error(`Failed to query stress data. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   > 说明
   >
   > 查询压力数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有压力数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)[]，查询成功压力数据为空返回[]，查询失败抛出BusinessError。

   查询成功返回的压力历史数据样例：

   ```screen
   [{
       "startTime": 1736580274,
       "endTime": 1736580330,
       "type": "stress",
       "fields": {
           "stressScore": 56,
           "stressGrade": 2
       }
   },
   {
       "startTime": 1736580154,
       "endTime": 1736580210,
       "type": "stress",
       "fields": {
           "stressScore": 55,
           "stressGrade": 2
       }
   },...
   ]
   ```

   |返回值|类型|单位|含义|
   |:----------|:-----|:-|:-----------------------------------------------|
   |fields|object|-|包含压力数据对象。|
   |stressScore|number|-|压力分数： * 80-99：偏高 * 60-79：中等 * 30-59：正常 * 1-29：放松|
   |stressGrade|number|-|压力等级： * 4：偏高 * 3：中等 * 2：正常 * 1：放松|
   [**表1**返回压力数据说明]
