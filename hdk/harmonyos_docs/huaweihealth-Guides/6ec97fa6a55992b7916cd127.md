# 订阅运动联动数据

订阅和取消订阅穿戴设备的运动联动数据。行业App允许一次订阅，多次启动运动联动。订阅成功后，运动联动过程中每秒上报一次实时数据，运动联动结束后上报一次统计数据。取消订阅后，不再上报数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构建用于订阅或取消订阅运动联动数据的JSON格式参数。

   <br />

   ```
   {
       "item": "realtimeWorkoutData"
   }
   ```

   <br />

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅运动联动数据。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 构造用于订阅或取消订阅运动联动数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "realtimeWorkoutData");
   } catch (JSONException e) {
       e.printStackTrace();
   }
   String json = jsonObject.toString();
   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 调用subscribe方法订阅运动联动数据
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   };
   manageClient.subscribe(deviceId, json, serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、8、26|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回空字符串，失败时返回错误信息，[启动运动联动](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-workout-control-0000002338300792)后每秒返回运动信息。|
   [表1 ServiceCallback返回值]

   运动联动期间返回运动信息：

   ```
   {
       "reportType": "inProgress",
       "reportData": {
           "timeStamp": 1644979034,
           "heartRate": 83,
           "calorie": 2000,
           "step": 130
       }
   }
   ```

   |返回值|取值|含义|
   |:--------|:-------|:------------------|
   |timeStamp|long类型数据|数据产生的UTC时间，单位：秒（s）。|
   |heartRate|int类型数据|心率。|
   |calorie|long类型数据|卡路里，单位：cal。|
   |step|long类型数据|步数。|

5. 调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅运动联动数据，取消后穿戴设备停止上报数据。

   <br />

   ```
   // 调用unSubscribe接口取消订阅运动联动数据
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   ![](https://media:301785133836891335)  
   取消订阅成功条件：
   * 取消订阅时要求输入的解订阅参数和订阅时的参数一致。
   * 取消订阅时传入的ServiceCallback，要求和订阅时传入的ServiceCallback为同一个对象。
