# 发送穿戴设备模版化通知

行业App向穿戴设备下发模板化通知。  
![](https://media:301785133820641089)  
* HUAWEI WATCH B7-536与HUAWEI WATCH B7-738在超长续航模式下不支持发送穿戴设备模板化通知。

<!-- -->

* 穿戴设备侧无对应的行业App也可以显示模板化通知。
* 请确保穿戴设备处于连接状态。
* 穿戴设备振动或响铃的条件：
  1. 穿戴设备侧已开启振动或响铃；
  2. 穿戴设备处于佩戴状态；
  3. 穿戴设备未开启勿扰模式。
* 通知在穿戴设备上自动弹出通知的条件：
  1. 穿戴设备处于佩戴状态；
  2. 穿戴设备未开启勿扰模式。
3. HUAWEI WATCH H5546、HUAWEI WATCH H7546、HUAWEI WATCH H7556、HUAWEI Band HA590、HUAWEI Band HA5A0、HUAWEI WATCH H5556、HUAWEI WATCH H5756、HUAWEI WATCH H3540以及HUAWEI WATCH H9D20需要在设备上设置-通知里打开通知时主动亮屏开关。  
![](https://media:301785133820680090)  
HUAWEI WATCH H7556需要先[订阅设备通话操作](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-phone-call-operation-0000002417409621)才能收到未接来电的消息。  
图1 通知在主页、消息列表中的显示效果   
![](https://media:301785133820708091)

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于向穿戴设备发送模板化通知的JSON格式参数。

   <br />

   ```
   {
     "item": "notification",
     "value": {
       "templateId": 53,
       "pkgName": "com.aa.bb",
       "title": "title",
       "content": "content",
       "remindType": 1,
       "button": {
         "button_1": "buttonText1",
         "button_2": "buttonText2",
         "button_3": "buttonText3"
       }
     }
   }
   ```

   |参数|含义|
   |:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |templateId|int类型，设备侧的通知模板ID，必选，支持以下4个取值： 50：表示不携带按钮 51：表示携带一个按钮 52：表示携带两个按钮 53：表示携带三个按钮|
   |pkgName|应用包名（设备侧根据包名显示图标），最多支持28个字节，必选|
   |title|通知title，最多28个字节，必选|
   |content|通知内容，最多400个字节，必选|
   |button|按钮内容，可选，最多3个按钮（button_1、button_2、button_3），具体按钮数量需要和templateId匹配|
   |button_1|第一个按钮内容，最多12个字节|
   |button_2|第二个按钮内容，最多12个字节|
   |button_3|第三个按钮内容，最多12个字节|
   |remindType|int类型，可选，模板通知支持以下三种震动响铃模式的整型取值： 1：less_importance模式，开启振动、振动时间0.5秒，振动1次，响铃关闭。 2：normal_importance模式，开启振动、振动时间0.5秒、振动间隔0.5秒，振动3次，响铃时长3秒。 3：most_importance模式，开启振动、振动时间1秒、振动间隔0.5秒，振动3次，响铃时长5秒。|

   ![](https://media:301785133820738092)  
   输入的按钮数量必须和输入的templateId保持一致。

   建议用户在使用模板化通知时不使用QQ/微信等其他企业应用包名。

   remindType自定义类型当前支持HUAWEI WATCH H5546、HUAWEI WATCH H7546、HUAWEI Band HA590、HUAWEI Band HA5A0、HUAWEI WATCH H5556、HUAWEI WATCH H5756、HUAWEI WATCH H3540以及HUAWEI WATCH H9D20设备，震动与响铃时长会受到穿戴设备系统设置的影响。

   <br />

4. 调用[send](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__send-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法向穿戴设备下发模板化通知。

   <br />

   ```
   // 步骤1 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 步骤2 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 步骤3 创建穿戴设备模板化通知的JSON对象
   JSONObject jsonObject = new JSONObject();
   JSONObject valueObject = new JSONObject();
   try {
       // 模板Id
       valueObject.put("templateId", 51);
       // 应用包名
       valueObject.put("pkgName", "com.aa.bb");
       // 消息标题
       valueObject.put("title", "这是一个标题");
       // 消息内容
       valueObject.put("content", "这是内容");
       // 自定义震动与响铃类型，可选参数
       valueObject.put("remindType", 1);
       // 按钮，由于templateId为51，这里需要填写一个按钮信息
       JSONObject buttons = new JSONObject();
       buttons.put("button_1", "按钮1");
       valueObject.put("button", buttons);
       jsonObject.put("item", "notification"); 
       jsonObject.put("value", valueObject); 
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 步骤4 调用send方法发送穿戴设备模板化通知
   deviceManageClient.send(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:---------|:--------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、7、24|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码|
   |result|-|接口调用成功时返回空字符串，失败时返回错误信息，用户在设备上对模板化通知消息操作时返回对信息的操作类型|
   [表1 ServiceCallback返回值]

   <br />

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理。接口调用成功时返回statusCode为0，result为空字符串；失败时statusCode返回错误码，result返回对应错误信息；用户在设备上点击按钮时返回statusCode为24，result中返回具体的用户操作。

   <br />

   ```
   result样例：
   {
       "feedback":1
   }
   ```

   |取值|含义|
   |:-|:---------------------|
   |0|未反馈（按手表的物理HOME键退出或灭屏等）|
   |1|删除消息|
   |2|用户点击按钮1|
   |3|用户点击按钮2|
   |4|用户点击按钮3|
   [表2 feedback取值]
