# 查询睡眠数据

穿戴设备提供实时监测睡眠与呼吸质量能力，用户佩戴穿戴设备入睡（夜间睡眠或者午睡）后，行业App可以通过本接口查询穿戴设备上记录的睡眠数据。  
![](https://media:301785133842086413)  
* 设备侧收集睡眠数据要求提前开启科学睡眠开关，查询睡眠数据前请先确保已调用[设置科学睡眠开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-trusleep-switch-0000002594109506)接口打开开关且用户有睡眠行为。
* 需要采集睡眠数据时，建议在查询时间段内佩戴手表入睡且睡眠时间超过3个小时（午睡除外），否则设备侧可能会返回空数据。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询睡眠数据。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           let device = try IndustryService.getDeviceManager().getDevice()
           let data = try await device.queryHistoryData(
               type: .sleep,
               startTime: 1778428800,
               endTime: 1778463000
           )
           print("Succeeded in querying sleep, data is \(data)")
       } catch let err as IndustryError {
           print("Failed to query sleep. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   ![](https://media:301785133842113414)  
   查询睡眠数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有睡眠数据返回\[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)\]，查询成功睡眠数据为空返回\[\]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。
