# 注册连接状态监听

行业App注册连接状态监听后方可监测到已配对的穿戴设备连接状态。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)的[getDeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceConnectClient-android_content_Context-)方法获取[DeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800)对象。
2. 调用[registerConnectionStatusListener](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800#ZH-CN_TOPIC_0000002648084238__registerConnectionStatusListener--)方法注册连接状态监听。

   ```screen
   // 获取DeviceConnectClient对象 
   DeviceConnectClient deviceConnectClient = IndustryWear.getDeviceConnectClient(this); 

   // 调用registerConnectionStatusListener()接口 
   int statusCode = deviceConnectClient.registerConnectionStatusListener();

   // 广播监听连接状态
   String action = "com.huawei.health.industry.client.CONNECTION_STATE_CHANGED";
   IntentFilter intentFilter = new IntentFilter();
   intentFilter.addAction(action);
   LocalBroadcastManager.getInstance(this).registerReceiver(new BroadcastReceiver() {
       @Override
       public void onReceive(Context context, Intent intent) {
           if (intent.getAction().equals(action)) {
               // 对返回值的处理
               String deviceId = intent.getStringExtra("deviceId");
               String deviceName = intent.getStringExtra("deviceName");
               String mac = intent.getStringExtra("mac");
               String connectionStatus = intent.getStringExtra("connectionStatus");
           }
       }
   }, intentFilter);
   ```

   |返回值|取值|含义|
   |:---------|:--|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   [**表1**注册连接状态监听返回值]

   |返回值|取值|含义|
   |:---------------|:----------|:-----------------------------------------------------------------------------------------------------------------------|
   |deviceId|-|设备Id。|
   |deviceName|-|穿戴设备名称。|
   |mac|-|穿戴设备mac地址，返回格式：10:20:30:40:50:60|
   |connectionStatus|0、1、2、3、4、5|设备连接状态码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)设备连接状态广播状态码。|
   [**表2**BroadcastReceiver返回值]

3. 若需要取消注册连接状态监听，调用[unregisterConnectionStatusListener](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800#ZH-CN_TOPIC_0000002648084238__unregisterConnectionStatusListener--)方法。

   ```screen
   // 调用deviceConnectClient.unregisterConnectionStatusListener();
   int statusCode = deviceConnectClient.unregisterConnectionStatusListener();
   ```

   |返回值|取值|含义|
   |:---------|:--|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   [**表3**取消注册连接状态监听返回值]
