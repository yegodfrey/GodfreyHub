# 蓝牙断连提醒开关设置和查询

设置与查询穿戴设备的蓝牙断连提醒开关状态。开启蓝牙断连提醒开关后，当穿戴设备检测到和终端设备（例如：手机等）拉距断连时，穿戴设备将产生蓝牙断开连接的提醒。关闭蓝牙断连提醒开关后，穿戴设备不再产生蓝牙断开连接的提醒。穿戴设备首次连接后默认开启蓝牙断连提醒开关。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setRemindSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section24381853174618)方法设置蓝牙断连提醒开关状态。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setRemindSwitch方法设置蓝牙断连提醒开关状态
           try await device.setRemindSwitch(type: .BTDisconnectionReminderSwitch, remindSwitchValue: true)

           // 设置蓝牙断连提醒开关状态成功
           print("Succeeded in setting BTDisconnectionReminderSwitch")
       } catch let err as IndustryError {
           // 设置蓝牙断连提醒开关状态失败
           print("Failed to set BTDisconnectionReminderSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getRemindSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section0593868401)方法查询蓝牙断连提醒开关状态。

   ```screen
   Task {
       do {
           // 调用Device对象的getRemindSwitch方法查询蓝牙断连提醒开关状态
           let switchValue = try await device.getRemindSwitch(type: .BTDisconnectionReminderSwitch)

           // 查询蓝牙断连提醒开关状态成功
           print("Succeeded in getting BTDisconnectionReminderSwitch, switchValue: \(switchValue)")
       } catch let err as IndustryError {
           // 查询蓝牙断连提醒开关状态失败
           print("Failed to get BTDisconnectionReminderSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
