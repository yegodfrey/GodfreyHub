# 删除设备

行业App调用删除设备接口，可删除已配对的穿戴设备。  
![](https://media:301785133827761188)  
* 如果删除的设备是当前已连接的设备，会先断开连接。
* 删除设备会清除设备相关的所有事件订阅、清除SDK本地保存的该设备相关开关设置。
* 删除设备后，有以下两种方式可以重新连接设备：
  1. 删除设备后，设备仍然保留在手机蓝牙系统的已配对设备列表中。行业App可以调用[getDeviceList](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1275193634915)方法获取系统已连接设备列表，然后选择需要连接的设备进行连接。
  2. 如果需要重新扫描发现设备，需要在手机设置蓝牙中"忽略"该设备，才能重新扫描连接。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)对象的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section232815255518)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象的[deleteDevice](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section12179115195011)方法删除设备。

   <br />

   ```
   import IndustrySDK

   let deviceManager = IndustryService.getDeviceManager()
   Task {
       do {
           try await deviceManager.deleteDevice(deviceId: "ABC123")
           print("Succeeded in deleting device")
       } catch let err as IndustryError {
           print("Failed to delete device. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
