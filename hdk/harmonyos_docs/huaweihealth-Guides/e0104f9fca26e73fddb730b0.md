# 集成添加设备页面

> 说明
>
> 在调用IndustryConnectionUI SDK进行设备扫描连接的过程中，不推荐开启或关闭手机深色模式，且请勿终止App运行。

手机侧应用与设备首次配对，实现扫描设备到配对成功下发个人信息一系列操作界面。

1. 创建Intent，传入扫描页面ScanActivity类。
2. （可选）传入用户个人信息用于首次配对成功后下发个人信息。

   |参数|取值|含义|
   |:----------|:----------------------------|:-------------|
   |gender|* male：男性 * female：女性|用户性别|
   |dateOfBirth|* yyyyMMdd格式的日期 * 不早于19000101|用户出生日期|
   |height|整数，取值范围：[50,250]|用户身高，单位：厘米(cm)|
   |weight|整数，取值范围：[10,250]|用户体重，单位：千克(kg)|

3. 启动ScanActivity，可参考如下示例。

   ```screen
   // 创建启动activity的intent
   Intent intent = new Intent(MainActivity.this, ScanDeviceActivity.class);

   // 传入个人信息（可选）
   String dateOfBirth = "19890131";
   String gender = "male";
   String height = "180";
   String weight = "65";
   intent.putExtra("gender", gender);
   intent.putExtra("dateOfBirth", dataOfBirth);
   intent.putExtra("height", height);
   intent.putExtra("weight", weight);

   // 启动ScanDeviceActivity
   startActivity(intent);
   ```
