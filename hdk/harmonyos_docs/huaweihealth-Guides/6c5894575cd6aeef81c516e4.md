# 血氧自动检测开关设置与查询

设置与查询穿戴设备的血氧自动检测开关状态。开启血氧自动检测开关后，穿戴设备将在静止状态下每10分钟自动检测血氧饱和度。关闭血氧自动检测开关后，穿戴设备不再自动检测血氧饱和度。穿戴设备首次连接默认关闭血氧自动检测开关。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setMonitorSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section125741385215)方法设置血氧自动检测开关状态。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setMonitorSwitch方法设置血氧自动检测开关状态
           try await device.setMonitorSwitch(type: .automaticSpO2MeasurementSwitch, monitorSwitchValue: true)

           // 设置血氧自动检测开关状态成功
           print("Succeeded in setting automaticSpO2MeasurementSwitch")
       } catch let err as IndustryError {
          // 设置血氧自动检测开关状态失败
           print("Failed to set automaticSpO2MeasurementSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getMonitorSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section10623588387)方法查询血氧自动检测开关状态。

   <br />

   ```
   Task {
       do {
           // 调用Device对象的getMonitorSwitch方法查询血氧自动检测开关状态
           let switchValue = try await device.getMonitorSwitch(type: .automaticSpO2MeasurementSwitch)

           // 查询血氧自动检测开关状态成功
           print("Succeeded in getting automaticSpO2MeasurementSwitch, switchValue: \(switchValue)")
        } catch let err as IndustryError {
           // 查询血氧自动检测开关状态失败 
           print("Failed to get automaticSpO2MeasurementSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />
