# 订阅日常健康数据更新

订阅和取消订阅穿戴设备的日常健康数据更新事件。订阅成功后，当穿戴设备判断达成日常健康数据更新条件后，上报日常健康数据更新事件。取消订阅后，不再上报日常健康数据更新事件。
> 说明
>
> * 每小时首次站立状态改变会上报数据更新事件。
> * 只要穿戴设备侧判断达到以下四个条件中的任意一个，则会上报数据更新事件，同时把四个条件的统计数值重置为0：
>   * 步数达到500步
>   * 距离达到1000米
>   * 活动时间达到1小时
>   * 卡路里消耗达到100千卡

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section484944212315)方法订阅日常健康数据更新。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的subscribeEvent方法订阅日常健康数据更新
           let uuid = try await device.subscribeEvent(type: .fitnessUpdateEvent) { eventData in
               print("Event report. Event: \(eventData.event), status: \(eventData.status)")
           }

           // 订阅日常健康数据更新成功
           print("Succeeded in subscribing fitnessUpdateEvent")
       } catch let err as IndustryError {
           // 订阅日常健康数据更新失败
           print("Failed to subscribe fitnessUpdateEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 日常健康数据有更新上报信息在(EventData -> Void)闭包中处理。日常健康数据有更新时eventData中包含事件类型（event）和事件状态（status）。

   ```screen
   eventData样例：
   {
       event: "fitnessUpdateEvent",
       status: 9
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:-----------|
   |status|9|表示日常健康数据有更新。|
   [**表1**事件状态值说明]

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[unsubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section686172218408)方法取消订阅日常健康数据更新。

   ```screen
   Task {
       do {
           // 调用Device对象的unsubscribeEvent方法取消订阅日常健康数据更新
           try await device.unsubscribeEvent(type: .fitnessUpdateEvent, subscribeId: uuid)

           // 取消订阅日常健康数据更新成功
           print("Succeeded in unsubscribing fitnessUpdateEvent")
       } catch let err as IndustryError {
           // 取消订阅日常健康数据更新失败
           print("Failed to unsubscribe fitnessUpdateEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   > 说明
   >
   > 取消订阅传入的uuid，要求和订阅返回的uuid为同一个对象。
