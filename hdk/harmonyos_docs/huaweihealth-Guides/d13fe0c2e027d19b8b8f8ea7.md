# 获取设备列表

行业App获取已配对的穿戴设备列表，获取的结果是JSON字符串，开发者需要自行解析封装。
> 说明
>
> SDK版本从2.13.0.102开始，行业App获取到的设备列表中的设备支持获取设备型号。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)的[getDeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceConnectClient-android_content_Context-)方法获取[DeviceConnectClient](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800)对象。
2. 调用[getDeviceList](https://developer.huawei.com/consumer/cn/doc/health-References/deviceconnectclient-0000001435104800#ZH-CN_TOPIC_0000002648084238__getDeviceList-com_huawei_health_industry_client_callback_ServiceCallback-)方法，获取已配对的穿戴设备列表。

   ```screen
   // 获取DeviceConnectClient对象
   DeviceConnectClient deviceConnectClient = IndustryWear.getDeviceConnectClient(this);

   // 获取已配对的设备列表
   deviceConnectClient.getDeviceList(new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
           // statusCode为0时说明获取设备列表成功，需要解析返回数据result获取设备的信息，可参考如下方式获取设备信息：
           try {
               JSONArray jsonArray = new JSONArray(result);
               for (int i = 0; i < jsonArray.length(); i++) {
                   JSONObject deviceJson = jsonArray.getJSONObject(i);
                   int connectionStatus = deviceJson.getInt("connectionStatus");
                   String deviceId = deviceJson.getString("deviceId");
                   String deviceName = deviceJson.getString("deviceName");
                   String mac = deviceJson.getString("mac");
                   String sn = deviceJson.getString("SN");
                   String softwareVersion = deviceJson.getString("softwareVersion");
                   if (deviceJson.has("deviceMode")) {
                      String deviceMode = deviceJson.getString("deviceMode");
                   }
               }
           } catch (JSONException e) {
               e.printStackTrace();
           }
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:---------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、26|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息，成功时返回设备信息。|
   [**表1**ServiceCallback返回值]

   result返回设备信息：

   ```screen
   [{
       "connectionStatus": 2,
       "deviceId": "XXXXXXXXXXXXXXXXXXXXXX",
       "deviceName": "XXXXXXXXXXXXXX",
       "mac": "XX:XX:XX:XX:XX:XX",
       "SN"："XXXXXXXXXXXXXXXX",
       "softwareVersion": "12.0.0.136C00SP1",
       "deviceMode": "XXX"
   }]
   ```

   |参数|取值|含义|
   |:---------------|:----------|:-----------------------------------------------------------------------------------------------------------------------|
   |connectionStatus|0、1、2、3、4、5|设备连接状态码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)设备连接状态广播状态码。|
   |deviceId|-|设备Id。|
   |deviceName|-|穿戴设备名称。|
   |mac|-|穿戴设备mac地址。|
   |SN|-|穿戴设备SN序列号。|
   |softwareVersion|-|设备软件版本号。|
   |deviceMode|-|设备型号。|
   [**表2**result返回设备信息]

   > 说明
   >
   > Health Industry SDK版本升级到2.7.0.105版本后，请重新连接设备再调用接口获取设备SN号。
