# 心率过低告警设置与查询

设置与查询穿戴设备在非运动状态下的心率过低告警开关状态和告警阈值（单位：次/分钟）。开启心率过低告警开关后，当穿戴设备检测到心率连续10分钟以上低于告警阈值时，将产生心率过低的告警。关闭心率过低告警开关后，穿戴设备不再产生心率过低的告警。穿戴设备首次连接后默认关闭心率过低告警开关。
> 说明
>
> * 如果需要启用心率过低告警，请提前开启连续测量心率模式，参见[连续测量心率模式设置与查询](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-heart-rate-monitoring-mode-0000002594269408)。
> * 当关闭心率过低告警开关时，若设置了告警阈值，则不会对告警阈值进行校验，查询返回告警开关为false，告警阈值为设置的告警阈值；若未设置告警阈值，查询返回告警开关为false，告警阈值为nil。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setAlertSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section89289364016)方法设置心率过低告警开关和阈值。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 构造心率过低告警开关和阈值参数
           let alertSetting = AlertSetting(switchValue: true, threshold: 50)

           // 调用Device对象的setMonitorSwitch方法设置心率过低告警开关和阈值
           try await device.setAlertSwitch(type: .lowHeartRateAlert, alertSwitchValue: alertSetting)

          // 设置心率过低告警开关和阈值成功
           print("Succeeded in setting lowHeartRateAlert")
       } catch let err as IndustryError {
          // 设置心率过低告警开关和阈值失败
           print("Failed to set lowHeartRateAlert. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getAlertSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section17401123111313)方法查询心率过低告警开关状态。

   ```screen
   Task {
       do {
           // 调用Device对象的getAlertSwitch方法查询心率过低告警开关和阈值
           let alertSetting = try await device.getAlertSwitch(type: .lowHeartRateAlert)

            // 查询心率过低告警开关和阈值成功
            print("Succeeded in getting lowHeartRateAlert, switchValue: \(alertSetting.switchValue), threshold: \(String(describing: alertSetting.threshold))")
       } catch let err as IndustryError {
            // 查询心率过低告警开关和阈值失败
            print("Failed to get lowHeartRateAlert. Code: \(err.code), message: \(err.message)")
      }
   }
   ```
