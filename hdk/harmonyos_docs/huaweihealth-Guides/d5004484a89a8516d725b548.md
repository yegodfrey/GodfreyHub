# 查询情绪数据

穿戴设备提供情绪测量能力，用户佩戴穿戴设备测量情绪后，行业App可以通过本接口查询穿戴设备上记录的情绪数据。  
![](https://media:301785133840519392)  
需要调用此接口查询情绪数据时，请提前开启[情绪/压力自动检测开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-emotion-auto-monitor-switch-0000002624549035)，否则会返回空数据。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询情绪数据。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           let device = try IndustryService.shared().getDeviceManager().getDevice()
           let data = try await device.queryHistoryData(
               type: .emotion,
               startTime: 1778428800,
               endTime: 1778472000
           )
           print("Succeeded in querying emotion, data is \(data)")
       } catch let err as IndustryError {
           print("Failed to query emotion. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   ![](https://media:301785133840552393)  
   查询情绪数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有情绪数据返回\[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)\]，查询成功情绪数据为空返回\[\]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。  
   查询成功返回的情绪数据样例：

   ```
   [
       {
           startTime: 1778466633,
           endTime: 1778466633,
           type: .emotion,
           fields: [
               "emotionStatus": 2,
               "arousalCharacter": 0.4611235558986664,
               "valenceCharacter": 90.367919921875
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:---------------|:-----|:-|:--------------------------------------------------|
   |emotionStatus|Int|-|情绪状态： * 1：负面情绪，不愉快 * 2：平静情绪，平和 * 3：积极情绪，愉快|
   |arousalCharacter|Double|-|唤醒特征，代表人的生理性激活的水平，越大代表激活程度越高，取值范围：\[0,100\]。|
   |valenceCharacter|Double|-|效价特征，代表人情绪的效价维度，较低代表情绪偏负面，较高代表情绪偏正面，取值范围：\[0,100\]。|
