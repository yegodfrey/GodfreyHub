# 扫描设备

扫描附近的行业穿戴设备。扫描开始后，扫描接口会实时上报发现的设备，扫描持续10秒后自动结束。
> 说明
>
> * 应用扫描前需要开启终端设备侧的蓝牙与位置相关权限，参见[添加权限](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/add-permission-0000002594109484)进行权限动态申请。
> * 使用智能穿戴设备时，如果设备已被其他应用连接，需要在iOS手机的"设置 > 蓝牙"中找到该设备，点击右侧的"i"图标，然后选择"忽略此设备"，之后才能被行业App扫描出来。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)对象的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section232815255518)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象的[scanDevice](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section3753115173613)方法发起设备扫描。

   ```screen
   import IndustrySDK

   let deviceManager = IndustryService.getDeviceManager()
   Task {
       do {
           // 构造扫描过滤参数
           let scanFilter = ScanFilter(type: .noFiltering, matcher: "")
           // 调用扫描接口开始扫描
           try await deviceManager.scanDevice(scanFilter: scanFilter) { device in
               print("Device found: \(device.name)")
               print("Device ID: \(device.deviceId)")
               print("RSSI: \(device.bluetoothRssi ?? 0)")
               print("Connection state: \(device.connectionState)")
           }
       } catch {
           print("Scan failed: \(error)")
       }
   }
   ```

4. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象的[stopScanDevice](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section659482174214)方法停止扫描设备。

   ```screen
   deviceManager.stopScanDevice()
   print("Stopped scanning device")
   ```
