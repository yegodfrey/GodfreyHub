# 查询单次运动数据

查询穿戴设备用户的单次运动数据。当用户佩戴穿戴设备打开锻炼应用完成运动且有运动记录产生后，行业应用可以通过本接口查询穿戴设备上记录的运动数据。
> 说明
>
> * 需要采集单次运动数据时，建议在查询时间段内完成一次或数次运动且有运动记录产生，否则穿戴设备侧可能返回空数据。
> * 不支持并发查询单次运动数据，需等待上一次查询结束后方可进行下一次查询。
> * 此接口可以配合[订阅单次运动数据更新](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-workout-update-event-0000002376514421)使用，当订阅的单次运动数据事件上报有数据更新时，调用此接口查询单次运动数据。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询单次运动数据。

   ```screen
   // 导入相关模块
   import {IndustryService, industryServiceClient} from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询单次运动数据查询参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.WORKOUT,
         startTime: 1740195486,
         endTime: 1740206286
       }
       // 调用Device对象的queryHistoryData方法查询单次运动数据
       device.queryHistoryData(queryParam).then((result: IndustryService.HistoryData[]) => {
         // 查询单次运动数据成功, 打印接口返回的单次运动数据
         console.info(`Succeeded in querying workout, result: ${JSON.stringify(result)}`);
       }).catch((err: BusinessError) => {
         // 查询单次运动数据失败
         console.error(`Failed to query workout. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
     // 获取穿戴设备列表失败
     console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   > 说明
   >
   > 查询单次运动数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和查询结束时间间隔不超过24小时。

   查询成功并且有单次运动数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)[]，查询成功单次运动数据为空返回[]，查询失败抛出BusinessError。
