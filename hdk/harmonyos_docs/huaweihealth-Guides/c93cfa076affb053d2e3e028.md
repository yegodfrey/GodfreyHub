# 连续测量心率模式设置与查询

设置与查询穿戴设备的连续测量心率模式。开启连续测量心率（智能模式）后，穿戴设备会根据运动状态动态调整测量频率，24小时智能监测心率。开启连续测量心率（实时模式）后，穿戴设备会24小时实时监测心率。关闭连续测量心率后，穿戴设备不再自动测量心率。穿戴设备首次连接后默认开启连续测量心率（智能模式）。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setContinuousHeartRateMonitoringMode](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section24816144141)方法设置连续心率监测模式。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()
           let realtimeMode = 2

           // 调用Device对象的setContinuousHeartRateMonitoringMode方法设置连续测量心率模式
           try await device.setContinuousHeartRateMonitoringMode(continuousHeartRateMonitoringMode: realtimeMode)

           // 设置连续测量心率模式成功
           print("Succeeded in setting continuousHeartRateMonitoringMode")
       } catch let err as IndustryError {
           // 设置连续测量心率模式失败
           print("Failed to set continuousHeartRateMonitoringMode. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getContinuousHeartRateMonitoringMode](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section152433162212)方法查询连续心率监测模式。

   ```screen
   Task {
       do {
           // 调用Device对象的getContinuousHeartRateMonitoringMode方法查询连续测量心率模式
           let mode = try await device.getContinuousHeartRateMonitoringMode()

           // 查询连续测量心率模式成功
           print("Succeeded in getting continuousHeartRateMonitoringMode, mode: \(mode)")
       } catch let err as IndustryError {
           // 查询连续测量心率模式失败
           print("Failed to get continuousHeartRateMonitoringMode. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
