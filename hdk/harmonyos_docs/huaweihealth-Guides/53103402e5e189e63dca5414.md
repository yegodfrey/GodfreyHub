# 设置体温过高提醒开关

若穿戴设备提供体温过高提醒能力，开启本开关后，设备将在监测到体温大于设定的温度时进行弹窗提醒。
> 注意
>
> 本开关仅支持国内版本的部分设备，若使用不受支持的设备，将返回错误码30。
> 说明
>
> * 体温过高提醒开关设置需要先在手表体温应用中激活体温研究功能。激活路径：点击【体温】->点击【加入研究】。未加入体温研究的情况下无法使用体温过高提醒开关设置接口。接口会返回错误码10。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于设置体温过高提醒开关和阈值的JSON格式的入参数据。

   ```screen
   {
       "settingKey": "highTempAlertSwitch",
       "settingValue": {
           "switch": 1,
           "threshold": 37.5
       }
   }
   ```

   |参数|取值|含义|
   |:-----------|:----------------------|:------------------------------|
   |settingKey|highTempAlertSwitch|体温过高提醒开关和阈值键值。|
   |settingValue|包含以下参数：switch、threshold|体温过高提醒开关和阈值内容。|
   |switch|0|关闭体温过高提醒开关。|
   |switch|1|开启体温过高提醒开关。|
   |threshold|整数，取值范围： [37.2,38.5]|可选参数，体温过高提醒阈值，**选择开启提醒时此参数必填**。|
   [**表1**设置体温过高提醒开关和阈值参数]

3. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section447217361429)方法设置体温过高提醒开关和阈值。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于设置体温过高提醒开关和阈值的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject switchAndThreshold = new JSONObject();
       switchAndThreshold.put("switch", 1);
       switchAndThreshold.put("threshold", 37.5);
       jsonObject.put("settingKey", "highTempAlertSwitch");
       jsonObject.put("settingValue", switchAndThreshold);

   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置体温过高提醒开关和阈值
   manageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、7|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回空字符串，接口调用失败时返回错误信息。|
   [**表2**ServiceCallback返回值]
