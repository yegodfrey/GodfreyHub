# 查询证书路径

查询当前配置的证书路径。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)的[getCertPath](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section660165212614)方法查询证书路径。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 调用IndustryService的getCertPath方法查询证书路径
           let path = try await IndustryService.getCertPath()

           // 查询证书路径成功
           print("Succeeded in getting cert path, path: \(path)")
       } catch let err as IndustryError {
           // 查询证书路径失败
           print("Failed to get cert path. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
