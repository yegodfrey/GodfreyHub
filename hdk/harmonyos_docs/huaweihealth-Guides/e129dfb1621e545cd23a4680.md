# 查询脉搏波心律失常分析数据

穿戴设备提供脉搏波心律失常分析功能，用户测量脉搏波心律失常分析后，行业应用可以通过本接口查询穿戴设备上记录的脉搏波心律失常分析数据。
> 说明
>
> * 查询穿戴设备的脉搏波心律失常分析数据，需要先在运动健康APP中激活脉搏波心律失常分析功能。打开路径：点击【设备】->点击已连接的【设备卡片】->点击【脉搏波心律失常分析】->打开页面后点击【同意】->进入下一页面，点击上方的【激活】按钮。
> * 需要采集脉搏波心律失常分析数据时，建议在查询时间段内测量一次或数次脉搏波心律失常分析，否则穿戴设备侧可能返回空数据。
> * 不支持并发查询脉搏波心律失常分析数据，需等待上一次查询结束后方可进行下一次查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询脉搏波心律失常分析数据。

   ```screen
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询脉搏波心律失常分析数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.ARRHYTHMIA,
         startTime: 1736586113,
         endTime: 1736585902
       };

       // 调用Device对象的queryHistoryData方法查询脉搏波心律失常分析数据
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 查询脉搏波心律失常分析数据成功, 打印接口返回的脉搏波心律失常分析数据
         console.info(`Succeeded in querying arrhythmia data, result is ${data}.`);
       }).catch((err: BusinessError) => {
         // 查询脉搏波心律失常分析数据失败
         console.error(`Failed to query arrhythmia data. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   > 说明
   >
   > 查询脉搏波心律失常分析数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有脉搏波心律失常分析数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)[]，查询成功脉搏波心律失常分析数据为空返回[]，查询失败抛出BusinessError。

   查询成功返回的脉搏波心律失常分析数据样例：

   ```screen
   [{
       "startTime": 1736586113,
       "endTime": 1736586113,
       "type": "arrhythmia",
       "fields": {
           "saveTime": 1736586113,
           "measureType": 1,
           "ppgIrregularHeartbeat": 2
       }
   },
   {
       "startTime": 1736585902,
       "endTime": 1736585902,
       "type": "arrhythmia",
       "fields": {
           "saveTime": 1736585902,
           "measureType": 1,
           "ppgIrregularHeartbeat": 4
       }
   },...
   ]
   ```

   |返回值|类型|单位|含义|
   |:--------------------|:-----|:-|:----------------------------------------------------------------------------------|
   |fields|object|-|包含脉搏波心律失常分析数据对象。|
   |saveTime|number|秒|保存脉搏波心律失常分析数据的时间，UTC时间戳。|
   |measureType|number|-|测量类型： * 0：自动测量 * 1：主动测量|
   |ppgIrregularHeartbeat|number|-|脉搏波心律失常分析结果： * 1：表示未见异常 * 2：表示疑似早搏 * 3：表示疑似房颤 * 4：表示不规则心率-存在房颤风险 * 5：表示不规则心率-存在早搏风险|
   [**表1**返回脉搏波心律失常分析数据说明]
