# 获取Bundle ID

在申请证书前，需要提供你的APP Bundle ID。你可以通过以下方式获取：

1. 在 Xcode 中点击左侧导航栏最顶部的 Project（项目根目录）。
2. 在中间的 Targets 列表中，选中你的 App Target。
3. 选择 Signing & Capabilities 选项卡。
4. Bundle Identifier 配置项即为APP Bundle ID。
