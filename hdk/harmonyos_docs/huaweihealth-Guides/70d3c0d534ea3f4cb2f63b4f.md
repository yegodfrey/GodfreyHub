# 获取系统蓝牙已配对设备列表

行业App调用获取设备列表接口，可获取系统蓝牙已配对的行业穿戴设备列表。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)对象的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section232815255518)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section162022615492)对象的[getDeviceList](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1275193634915)方法获取当前系统蓝牙已配对的行业穿戴设备列表。

   <br />

   ```
   import IndustrySDK

   let deviceManager = IndustryService.getDeviceManager()

   do {
       // 获取系统蓝牙已连接设备列表
       let deviceList = try deviceManager.getDeviceList()
       for device in deviceList {
           print("Device: \(device.name), deviceId: \(device.deviceId), state: \(device.connectionState)")
       }
   } catch let err as IndustryError {
       print("Failed to get device list. Code: \(err.code), message: \(err.message)")
   }
   ```
