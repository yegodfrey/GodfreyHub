# 订阅日常活动数据更新

订阅和取消订阅穿戴设备的日常活动数据更新事件。订阅成功后，当穿戴设备判断达成日常活动数据更新条件后，上报日常活动数据更新事件。取消订阅后，不再上报日常活动数据更新事件。
> 说明
>
> * **只有亮屏时才会上报数据更新事件，灭屏时不会上报数据更新事件**。
> * 每小时首次站立状态改变会上报数据更新事件。
> * 只要穿戴设备侧判断达到以下四个条件中的任意一个，则会上报数据更新事件，同时把四个条件的统计数值重置为0：
>   * 步数达到500步
>   * 距离达到1000米
>   * 活动时间达到1小时
>   * 卡路里消耗达到100千卡

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section141971612182616)方法订阅日常活动数据更新。

   ```screen
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError, Callback } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 日常活动数据更新事件回调
       let callback: Callback<IndustryService.EventData> = (eventData: IndustryService.EventData) => {
         // 处理日常活动数据更新事件
         console.info(`report fitnessUpdateEvent: ${JSON.stringify(eventData)}`);
       };
       // 调用Device对象的subscribeEvent方法订阅日常活动数据更新
       device.subscribeEvent(IndustryService.EventType.FITNESS_UPDATE_EVENT, callback).then(() => {
         // 订阅日常活动数据更新成功
         console.info('Succeeded in subscribing fitnessUpdateEvent.');
       }).catch((err: BusinessError) => {
         // 订阅日常活动数据更新失败
         console.error(`Failed to subscribe fitnessUpdateEvent. Code is ${err.code}, message is ${err.message}.`);
       });
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

5. 日常活动数据有更新上报信息在Callback<IndustryService.[EventData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7634104243910)>中处理。日常活动数据有更新时eventData中包含事件类型（event）和事件状态（status）。

   ```screen
   eventData样例：
   {
     event: 'fitnessUpdateEvent',
     status: 10
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:-----------|
   |status|10|表示日常活动数据有更新。|
   [**表1**事件状态值说明]

6. 需要取消订阅时，调用[unSubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section29691015152720)方法取消订阅日常活动数据更新事件。

   ```screen
   // 调用unSubscribeEvent方法取消订阅日常活动数据更新事件。
   // 注意：这里的callback和订阅数据事件更新时的callback要为同一个对象。
   device.unSubscribeEvent(IndustryService.EventType.FITNESS_UPDATE_EVENT, callback).then(() => {
     // 取消订阅日常活动数据更新事件成功
     console.info('Succeeded in unsubscribing fitnessUpdateEvent.');
   }).catch((err: BusinessError) => {
     // 取消订阅日常活动数据更新事件失败
     console.error(`Failed to unsubscribe fitnessUpdateEvent. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   > 说明
   >
   > 取消订阅传入的callback，要求和订阅时传入的callback为同一个对象。
