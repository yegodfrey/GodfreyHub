# 查询当日静息热量消耗

行业App可以通过本功能查询穿戴设备记录的当日静息热量消耗数据。
> 说明
>
> * 查询穿戴设备的静息消耗热量数据，需要先在手表上打开减脂塑型应用。
> * 本接口返回的**当日当前的静息热量值**为从当天00:00:00开始，截止到查询时的静息热量消耗（如果有运动包括运动后的静息热量消耗）。
> * 本接口返回的**当日当前的静息热量值**和手表上减脂塑型应用显示的值有1-2的偏差是正常情况。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryTodaySummation](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1516318916132)方法查询当日静息热量消耗。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           let device = try IndustryService.getDeviceManager().getDevice()
           let data = try await device.queryTodaySummation(
               type: .todayRestingCalories
           )
           print("Succeeded in querying today resting calories, data is \(data)")
       } catch let err as IndustryError {
           print("Failed to query today resting calories. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   查询成功返回Int类型的当日静息热量消耗，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。

   |类型|单位|含义|
   |:--|:-|:--------|
   |Int|千卡|当日静息热量消耗。|
   [**表1**当日静息热量消耗返回值]
