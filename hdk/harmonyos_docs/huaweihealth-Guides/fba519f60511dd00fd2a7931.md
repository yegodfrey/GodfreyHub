# 查询睡眠历史数据

穿戴设备提供实时监测睡眠与呼吸质量能力，用户入睡（夜间睡眠或者午睡）后，行业应用可以通过本接口查询穿戴设备上记录的睡眠历史数据。  
![](https://media:301785133839122371)  
* 设备侧收集睡眠数据要求提前开启科学睡眠开关，查询睡眠数据前请先确保已调用[设置科学睡眠开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-trusleep-switch-0000002447392129)接口打开开关且用户有睡眠行为。
* 不支持并发查询睡眠数据，需等待上一次查询结束后方可进行下一次查询。
* 需要采集睡眠数据时，建议在查询时间段内佩戴手表入睡且睡眠时间超过3个小时（午睡除外），否则设备侧可能会返回空数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询睡眠历史数据的ZSON格式的入参数据。

   <br />

   ```
   {
       "item": "historySleepData",
       "value": {
           "startTime": 1685341304, // 单位：秒(s)
           "endTime": 1685686904 // 单位：秒(s)
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:--------|
   |startTime|UTC时间戳，单位：秒（s）|查询数据开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询数据结束时间。|
   [表1 查询睡眠历史数据参数]

   ![](https://media:301785133839148372)  
   接口要求查询开始时间和当前时间间隔不超过7天。

   <br />

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询睡眠历史数据。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询睡眠历史数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       ZSONObject valueObject= new ZSONObject();
       valueObject.put("startTime", 1685341304);
       valueObject.put("endTime", 1685686904);
       zsonObject.put("item", "historySleepData");
       zsonObject.put("value", valueObject);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询睡眠历史数据
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、6、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回历史睡眠数据，失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含睡眠历史数据。

   <br />

   ```
   data样例：
   {
     "dataType": "sleepData",
     "totalCount": 2,
     "index": 0,
     "count": 2,
     "dataList": [
       {
         "fallAsleepTime": 1685376180,
         "wakeupTime": 1685399040,
         "sleepScore": 80,
         "sleepEfficiency": 100,
         "deepSleepPart": 55,
         "snoreFreq": 2,
         "sleepDetail": [
           {
             "startTime": 1685387880,
             "sleepState": 1,
             "duration": 32
           },
           {
             "startTime": 1685389800,
             "sleepState": 3,
             "duration": 10
           }
         ]
       },
       {
         ...
       }
     ]
   }
   ```

   |返回值|取值|含义|
   |:--------------|:---------|:---------------------|
   |dataType|sleepData|睡眠数据类型。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一个数据点在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |fallAsleepTime|UTC时间，单位：秒|入睡时间，单位：秒(s)。|
   |wakeupTime|UTC时间，单位：秒|出睡时间，单位：秒(s)。|
   |sleepScore|long类型数据|睡眠得分，0\~100分。|
   |sleepEfficiency|int类型数据|睡眠效率。|
   |deepSleepPart|long类型数据|深睡连续性得分。|
   |snoreFreq|String类型数据|打鼾频率。|
   |sleepDetail|List类型数据|睡眠状态详情数据。|
   [表3 data返回值]

   睡眠状态详情数据sleepDetail：  

   |----------|------------------------------------------------------------------------------------------------------------------------------|-------|
   |返回字段名称|取值|含义|
   |startTime|UTC时间，单位：秒|睡眠开始时间。|
   |duration|int类型数据，单位：分钟|睡眠状态时长。|
   |sleepState|int类型数据，参见[睡眠状态枚举](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/sleep-status-enumeration-0000002372106937)|睡眠状态类型。|

   ![](https://media:301785133839174373)  
   * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回。
   * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。
   * sleepScore、sleepEfficiency、deepSleepPart、snoreFreq四个字段为可选返回字段，是否返回依赖设备端，开发者在获取这四项数据时请提前判断是否存在。

   <br />
