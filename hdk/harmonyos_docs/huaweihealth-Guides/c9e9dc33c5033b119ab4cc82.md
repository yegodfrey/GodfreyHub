# 获取服务端Api Level

获取行业SDK服务端的API级别。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)的[getApiLevel](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section921625593319)方法，获取服务端的API级别。

   ```screen
   // 导入相关模块
   import { industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 调用industryServiceClient中getApiLevel方法获取服务端API级别
   industryServiceClient.getApiLevel(getContext(this)).then((value: number) => {
     // 获取服务端API级别成功，打印返回的API级别
     console.info(`Succeeded in getting apiLevel, value is ${value}.`);
   }).catch((err: BusinessError) => {
     // 获取服务端API级别失败
     console.error(`Failed to get apiLevel. Code is ${err.code}, message is ${err.message}.`);
   })
   ```
