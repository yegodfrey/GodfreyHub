# 订阅SOS事件

订阅和取消订阅穿戴设备的SOS事件。订阅成功后，当穿戴设备判断SOS触发时上报SOS事件。取消订阅后，不再上报SOS事件。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅SOS事件的ZSON格式的入参数据。

   <br />

   ```
   {
       "item": "SOSEvent"
   }
   ```

   <br />

<!-- -->

3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅SOS事件。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅SOS事件的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "SOSEvent");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅SOS事件
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   };
   deviceManageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:-------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、10|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；订阅成功后，设备产生SOS事件时，返回{"rtnMsg":"event reported."}。|
   [表1 ServiceCallback返回值]

   <br />

<!-- -->

4. 订阅操作的结果和SOS事件上报在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；设备产生SOS事件时返回statusCode为10，data数据为{"rtnMsg":"event reported."}。

<!-- -->

5. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅SOS事件。

   <br />

   ```
   // 调用unSubscribe方法取消订阅SOS事件。
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   deviceManageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```

   <br />
