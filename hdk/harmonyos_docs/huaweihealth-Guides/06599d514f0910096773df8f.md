# 订阅设备电量状态

订阅和取消订阅穿戴设备的电量状态。订阅成功后，当穿戴设备的电量降低时返回当前剩余电量。取消订阅后，不再返回剩余电量。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section484944212315)方法订阅设备电量状态。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的subscribeEvent方法订阅设备电量状态
           let uuid = try await device.subscribeEvent(type: .batteryLevelChangedEvent) { eventData in
               print("Event report. Event: \(eventData.event), status: \(eventData.status)")
           }

           // 订阅设备电量状态成功
           print("Succeeded in subscribing batteryLevelChangedEvent")
       } catch let err as IndustryError {
           // 订阅设备电量状态失败
           print("Failed to subscribe batteryLevelChangedEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 设备电量状态在(EventData -> Void)闭包中处理。设备电量降低时eventData中包含事件类型（event）和设备当前电量（status）。

   ```screen
   eventData样例：
   {
       event: "batteryLevelChangedEvent",
       status: 50
   }
   ```

   |返回值|取值|含义|
   |:-----|:---|:------|
   |status|1~99|设备当前电量。|
   [**表1**设备当前电量]

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[unsubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section686172218408)方法取消订阅设备电量状态。

   ```screen
   Task {
       do {
           // 调用Device对象的unsubscribeEvent方法取消订阅设备电量状态
           try await device.unsubscribeEvent(type: .batteryLevelChangedEvent, subscribeId: uuid)

           // 取消订阅设备电量状态成功
           print("Succeeded in unsubscribing batteryLevelChangedEvent")
       } catch let err as IndustryError {
           // 取消订阅设备电量状态失败
           print("Failed to unsubscribe batteryLevelChangedEvent. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   > 说明
   >
   > 取消订阅传入的uuid，要求和订阅返回的uuid为同一个对象。
