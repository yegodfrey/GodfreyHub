# 查询心率数据

穿戴设备提供心率测量能力，用户佩戴穿戴设备测量心率后，行业App可以通过本接口查询穿戴设备上记录的心率数据。  
![](https://media:301785133843866440)  
需要调用此接口查询心率数据时，请提前[开启连续测量心率模式](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-heart-rate-monitoring-mode-0000002594269408)，否则会返回空数据。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询心率数据。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryHistoryData方法查询心率数据
           let data = try await device.queryHistoryData(
               type: .heartRate,
               startTime: 1778461200,
               endTime: 1778464800
           )

           // 查询心率数据成功
           print("Succeeded in querying heart rate, data is \(data)")
       } catch let err as IndustryError {
           // 查询心率数据失败
           print("Failed to query heart rate. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   ![](https://media:301785133843899441)  
   查询心率数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有心率数据返回\[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)\]，查询成功心率数据为空返回\[\]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。  
   查询成功返回的心率数据样例：

   ```
   [
       {
           startTime: 1778461980,
           endTime: 1778461980,
           type: .heartRate,
           fields: [
               "restingHeartRate": 0,
               "heartRate": 85
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:---------------|:--|:---|:-----|
   |restingHeartRate|Int|次/分钟|静息心率值。|
   |heartRate|Int|次/分钟|心率值。|
