# 查询血压周期测量计划

穿戴设备提供血压测量能力，行业App可以通过本接口查询已下发到穿戴设备的血压周期测量计划。  
![](https://media:301785133836665332)  
此接口仅在支持单次血压测量的穿戴设备上可用，当前支持HUAWEI WATCH B9-D10和HUAWEI WATCH H9D20设备。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询血压周期测量计划的JSON格式参数。

   <br />

   ```
   {
     "item": "bloodPressureMeasurePlan"
   }
   ```

   <br />

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询血压周期测量计划。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询血压周期测量计划的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "bloodPressureMeasurePlan");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询血压周期测量计划
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回血压周期测量计划信息，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含设备侧的血压周期测量计划。

   <br />

   ```
   result样例
   {
         "wakeUpTime":"0700",
         "beforeSleepTime":"2200",
         "enabled":1,
         "daysOfWeek":[1,2,6],
         "planTimes":["0745","0840","1433"]
   }
   ```

   |返回值|取值|含义|
   |:--------------|:------------------------------------------------------------------|:-----------------------------------------------------------------------|
   |wakeUpTime|格式为HHmm的24小时制的时刻字符串，前两个字符代表小时，后两个字符代表分钟，最大为"0900"，最小为"0600"|起床后测量时间，取值范围\[6:00\~9:00\]。|
   |beforeSleepTime|格式为HHmm的24小时制的时刻字符串，前两个字符代表小时，后两个字符代表分钟，可跨天，当天最小为"2000"，跨天最大为"0159"|睡前测量时间，取值范围\[20:00\~1:59\]。|
   |enabled|int类型|是否提醒，1：提醒，0：不提醒。|
   |daysOfWeek|int类型数组|计划提醒的星期，取值范围\[1\~7\]。|
   |planTimes|格式为HHmm的24小时制的时刻字符串数组，前两个字符代表小时，后两个字符代表分钟|自定义测量计划时间，取值范围(wakeUpTime\~beforeSleepTime)，测量计划（包含起床和睡前计划）时间间隔不小于45min。|
   [表2 result返回值]

   <br />
