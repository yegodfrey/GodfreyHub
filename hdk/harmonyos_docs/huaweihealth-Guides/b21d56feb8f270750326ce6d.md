# 订阅运动状态

订阅和取消订阅穿戴设备的运动状态。订阅成功后，穿戴设备在运动进入相关控制状态时会上报运动状态。取消订阅后，不再上报运动状态。
> 说明
>
> 设备在准备运动、退出准备运动、开始运动、暂停运动、继续运动、结束运动等控制状态下，均会上报运动状态。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅运动状态的ZSON格式的入参数据。

   ```screen
   {
       "item": "exerciseStatus"
   }
   ```


3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅运动状态。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅运动状态的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "exerciseStatus");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅运动状态
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   };
   deviceManageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、8|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；订阅成功后，设备在进入锻炼模式后，会上报相应的运动状态。|
   [**表1**ServiceCallback返回值]


4. 订阅操作的结果和运动状态变化信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；运动状态变化时返回statusCode为8，data数据中包含运动状态。

   ```screen
   data样例：
   {
       "exerciseStatus":1
   }
   ```

   |返回值|取值|含义|
   |:-------------|:------|:--------------------------------------------------------------------------------------------------------------------------------|
   |exerciseStatus|int类型数据|对应运动状态，运动状态参考[运动状态码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/sport-status-enumeration-0000002338268622)。|
   [**表2**data返回订阅信息]


5. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅运动状态。

   ```screen
   // 调用unSubscribe方法取消订阅运动状态。
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   deviceManageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```
