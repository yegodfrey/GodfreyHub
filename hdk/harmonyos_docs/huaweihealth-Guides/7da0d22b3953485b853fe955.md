# 查询每日静息热量消耗目标值

穿戴设备提供体重管理功能，包括热量缺口评估、热量消耗监测及热量摄入记录。行业App可通过本功能查询穿戴设备记录的每日静息热量消耗目标数据。  
![](https://media:301785133834419290)  
* 使用此接口前，需在手表端打开减脂塑型应用。若未打开应用，手表端将不会产生相关数据。
* 静息热量数据产生时间为每日00:00:00，因此查询时间需从00:00:00开始。
* 本接口返回的静息热量值为每日静息热量消耗目标（如果有运动包括运动后的静息热量消耗）。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询每日静息热量消耗目标。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           let device = try IndustryService.shared().getDeviceManager().getDevice()
           let data = try await device.queryHistoryData(
               type: .dailyRestingCaloriesGoal,
               startTime: 1778428800,
               endTime: 1778463000
           )
           print("Succeeded in querying daily resting calories goal, data is \(data)")
       } catch let err as IndustryError {
           print("Failed to query daily resting calories goal. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   查询成功返回Int类型的每日静息热量消耗目标，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。  
   ![](https://media:301785133834640291)  
   查询每日静息热量消耗目标值接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。  

   |类型|单位|含义|
   |:--|:-|:-------|
   |Int|千卡|静息热量目标值。|
