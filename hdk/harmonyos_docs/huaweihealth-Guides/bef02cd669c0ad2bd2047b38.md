# 设置音乐播放信息

设置穿戴设备音乐界面显示的音乐播放信息，包含歌曲名，歌手名，歌曲播放状态，设备音量，设备最大音量。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置音乐播放信息的JSON格式参数。

   ```screen
   {
       "settingKey":"musicInfo",
       "settingValue": {
           "playState": 3,
           "singerName": "singer2",
           "songName": "song2",
           "maxVolume": 15,
           "currentVolume": 3
       }
   }
   ```

   |参数|取值|含义|
   |:------------|:-----------------------------------------------------------|:-------------|
   |settingKey|musicInfo|音乐播放信息键值。|
   |settingValue|包含以下参数：playState、singerName、songName、maxVolume、currentVolume|音乐播放信息内容。|
   |playState|0：音乐未播放 1：播放停止 2：播放暂停 3：播放中|歌曲播放状态。|
   |singerName|字符串，长度不大于60字节|歌手姓名。|
   |songName|字符串，长度不大于120字节|歌曲名称。|
   |maxVolume|整数 ，范围：[1, 255]|手机媒体播放最大音量值。|
   |currentVolume|整数 ，范围：[0, 255](不大于maxVolume)|当前手机媒体播放音乐音量值。|
   [**表1**设置音乐播放信息参数]

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置音乐播放信息。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构建用于设置音乐播放信息的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("settingKey", "musicInfo");
       JSONObject info = new JSONObject();
       info.put("singerName", "singer2");
       info.put("songName", "song2");
       info.put("playState", 3);
       info.put("maxVolume", 15);
       info.put("currentVolume", 3);
       jsonObject.put("settingValue", info);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置音乐播放信息
   deviceManageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:-----------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、2、4、5、6、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

   > 说明
   >
   > 设置音乐信息功能，必须在负一屏且下发订阅后才能正常使用。
