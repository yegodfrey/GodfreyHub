# 设置心率过高/过低告警开关和阈值

设置穿戴设备在非运动状态下的心率过高/过低告警开关状态和告警阈值（单位：次/分钟）。开启心率过高/过低告警开关后，当穿戴设备检测到心率连续10分钟以上超过/低于告警阈值时，将产生心率过高/过低的告警。关闭心率过高/过低告警开关后，穿戴设备不再产生心率过高/过低的告警。
> 说明
>
> 如果需要启用心率过高/过低告警，请提前开启连续测量心率模式，参见[设置连续测量心率模式](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-continue-measure-heart-rate-switch-0000002372218953)。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置心率过高/过低告警开关和阈值的JSON格式参数。

   ```screen
   设置心率过高告警开关和阈值的JSON格式参数：
   {
       "settingKey": "maxHeartRateAlarm",
       "settingValue": {
           "switch": 1,
           "threshold": 130
       }
   }

   设置心率过低告警开关和阈值的JSON格式参数：
   {
       "settingKey": "minHeartRateAlarm",
       "settingValue": {
           "switch": 1,
           "threshold": 40
       }
   }
   ```

   |参数|取值|含义|
   |:-----------|:----------------------|:-------------------------------------|
   |settingKey|maxHeartRateAlarm|心率过高告警开关和阈值键值。|
   |settingKey|minHeartRateAlarm|心率过低告警开关和阈值键值。|
   |settingValue|包含以下参数：switch、threshold|心率过高/过低告警开关和阈值内容。|
   |switch|0|关闭非运动状态下的心率过高/过低告警。|
   |switch|1|开启非运动状态下的心率过高/过低告警。|
   |threshold|整数，取值范围： [100,150]|可选参数，非运动状态下的心率过高告警阈值，**选择开启告警时此参数必填**。|
   |threshold|整数，取值范围： [40,50]|可选参数，非运动状态下的心率过低告警阈值，**选择开启告警时此参数必填**。|
   [**表1**设置心率过高/过低告警开关和阈值参数]

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置心率过高/过低告警开关和阈值。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于设置心率过高/过低告警开关和阈值的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject switchAndThreshold = new JSONObject();
       switchAndThreshold.put("switch", 1);
       switchAndThreshold.put("threshold", 130); 
       // switchAndThreshold.put("threshold", 40);
       jsonObject.put("settingKey", "maxHeartRateAlarm");
       // jsonObject.put("settingKey", "minHeartRateAlarm");
       jsonObject.put("settingValue", switchAndThreshold);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置心率过高/过低告警开关和阈值
   manageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、2、3、4、5、6、7|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [**表2**ServiceCallback返回值]
