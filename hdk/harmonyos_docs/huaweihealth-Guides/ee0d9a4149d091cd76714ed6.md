# 查询运动状态

穿戴设备支持多种运动模式，用户佩戴穿戴设备打开锻炼应用开启运动后，行业App可以通过本接口查询用户的当前运动状态。

1. 导入相关模块
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryStatus](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section178854115210)方法查询运动状态。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryStatus方法查询运动状态
           let exerciseStatus = try await device.queryStatus(type: .exerciseStatus)

           // 查询运动状态成功
           print("Succeeded in querying exerciseStatus, exerciseStatus: \(exerciseStatus)")
       } catch let err as IndustryError {
           // 查询运动状态失败
           print("Failed to query exerciseStatus, code: \(err.code), message: \(err.message)")
       }
   }
   ```
