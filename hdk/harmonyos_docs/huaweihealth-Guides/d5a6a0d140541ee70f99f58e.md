# 订阅音乐控制事件

订阅与取消订阅已连接设备的音乐控制事件。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于订阅或取消订阅音乐控制事件提醒的JSON格式参数。

   ```screen
   {
       "item": "musicControl"
   }
   ```

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅音乐控制事件提醒。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于订阅音乐控制的JSON格式的入参数据 
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "musicControl");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法
   manageClient.subscribe(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:----------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、10、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002338108834)中的通用返回码。|
   |result|-|订阅成功时返回空字符，订阅失败时返回错误信息。|
   [**表1**ServiceCallback返回值]

   > 说明
   >
   > 订阅音乐控制事件的ServiceCallback不仅会返回订阅操作的结果，另外还会返回后续订阅的事件上报时的数据。
   >
5. 订阅操作的结果和音乐控制事件信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，result为空字符串；失败时statusCode返回错误码，result返回对应错误信息；设备上报音乐控制事件时返回statusCode为10，result数据中包含控制类型和音量数值。

   ```screen
   result样例：
   {
       "controlType":7,
       "musicVolume":50
   }
   ```

   |返回值|取值|含义|
   |:----------|:---------------------------------------------------------------------------------------------|:-------------------------------------------------------|
   |controlType|* 0 查询音乐信息 * 1 音乐播放 * 2 音乐暂停 * 3 音乐切歌上一首 * 4 音乐切歌下一首 * 5 音量增加 * 6 音量减少 * 7 直接根据musicVolume设置音量|设备上报控制指令类型。|
   |musicVolume|int类型数据|设置的音量，设备发给APP，APP 根据传入值直接进行手机的音量设置。仅当controlType为7的时候上报。|
   [**表2**result返回值]

6. 调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅音乐控制事件提醒。

   ```screen
   // 调用unSubscribe方法取消订阅音乐控制事件提醒
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   > 说明
   >
   > 取消订阅成功条件：
   > * 取消订阅时要求输入的解订阅参数和订阅时的参数一致。
   > * 取消订阅时传入的ServiceCallback，要求和订阅时传入的ServiceCallback为同一个对象。
