# 查询活动记录

查询穿戴设备上的活动记录。活动记录包含：活动热量、锻炼时长、活动小时数和对应的目标值。  
![](https://media:301785133826431172)  
不支持并发查询活动记录，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询活动记录的JSON格式参数。

   <br />

   ```
   {
       "item": "activityRecords",
       "value": {
           "startTime": "1685341304",
           "endTime": "1685686904",
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:--------------------------------------------------|
   |startTime|UTC时间戳，单位：秒（s）|查询活动记录的开始时间，只取年月日，查询时间会转化为当天00:00:00时间戳，即从当天零点开始查询。|
   |endTime|UTC时间戳，单位：秒（s）|查询活动记录的结束时间，只取年月日，查询时间会转化为当天23:59:59时间戳，即当天时间末结束查询。|
   [表1 查询活动记录参数]

   ![](https://media:301785133826467173)  
   * 查询时间只取年月日是因为设备返回的每条数据是设备活动记录的一整天的数据。
   * 查询的结束时间不能超过当天。
   * 接口要求查询开始时间和当前时间间隔不超过7天（包含今天）。

   <br />

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询活动记录。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询活动记录的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "activityRecords");
       valueObject.put("startTime", "1685341304");
       valueObject.put("endTime", "1685686904");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询活动记录
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、6、7、11、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回活动记录数据，失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含活动记录数据。

   <br />

   ```
   result样例：
   {
     "dataType": "activityRecords",
     "totalCount": 3,
     "dataList": [
       {
         "startTime": 1724083200,
         "endTime": 1724169599,
         "calories": 0,
         "exerciseDuration": 0,
         "standHours": 0,
         "caloriesGoal": 270000,
         "exerciseDurationGoal": 25,
         "standHoursGoal": 12
       },
       {
         "startTime": 1724169600,
         "endTime": 1724255999,
         "calories": 4598,
         "exerciseDuration": 0,
         "standHours": 2,
         "caloriesGoal": 270000,
         "exerciseDurationGoal": 25,
         "standHoursGoal": 12
       },
       {
         "startTime": 1724256000,
         "endTime": 1724257588,
         "calories": 25244,
         "exerciseDuration": 0,
         "standHours": 4,
         "caloriesGoal": 270000,
         "exerciseDurationGoal": 25,
         "standHoursGoal": 12
       }
     ]
   }
   ```

   |返回值|取值|含义|
   |:-------------------|:--------------|:---------------------|
   |dataType|activityRecords|活动记录数据类型。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |startTime|UTC时间，单位：秒|当天数据的开始时间，单位：秒(s)。|
   |endTime|UTC时间，单位：秒|当天数据的结束时间，单位：秒(s)。|
   |calories|int类型数据|活动热量，单位：卡。|
   |exerciseDuration|int类型数据|锻炼时长，单位：分钟。|
   |standHours|int类型数据|活动小时数，单位：小时。|
   |caloriesGoal|int类型数据|活动热量目标值，单位：卡。|
   |exerciseDurationGoal|int类型数据|锻炼时长目标值，单位：分钟。|
   |standHoursGoal|int类型数据|活动小时数目标值，单位：小时。|
   [表3 result返回值]

   ![](https://media:301785133826538174)  
   * 一天返回一条活动记录，返回的数据值是当天的累计值。
   * 非今天的活动记录，返回数据的开始时间是当天的凌晨时间戳，结束时间是当天的23:59:59时间戳。
   * 今天的活动记录，返回数据的开始时间是当天凌晨时间戳，结束时间是当前系统时间。
   * 断连状态修改设备目标值，查询前需要进行活动或锻炼。
