# 单位制设置和查询

设置与查询穿戴设备的运动数据的单位制。当用户佩戴穿戴设备进行运动时，穿戴设备会根据当前设置的单位制显示运动数据（例如，在穿戴设备上开启户外跑步运动，当单位制设置为公制后，距离单位为km；当单位制设置为英制后，距离单位为mi）。穿戴设备首次连接后默认单位制为终端设备（iOS手机）系统单位制。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setUnit](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section16609135823814)方法设置设备单位制。

   <br />

   ```
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setUnit方法设置设备单位制
           try await device.setUnit(unit: .metric)

           // 设置设备单位制成功
           print("Succeeded in setting unit")
       } catch let err as IndustryError {
           // 设置设备单位制失败
           print("Failed to set unit. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getUnit](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section13655903016)方法查询设备单位制。

   <br />

   ```
   Task {
       do {
           // 调用Device对象的getUnit方法查询设备单位制
           let unit = try await device.getUnit()

           // 查询设备单位制成功
           print("Succeeded in getting unit, unit: \(unit)")
       } catch let err as IndustryError {
           // 查询设备单位制失败
           print("Failed to get unit. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />
