# 查询设备SN号

查询穿戴设备的序列号SN。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询设备SN号的ZSON格式的入参数据。

   <br />

   ```
   {
       "item": "serialNumber"
   }
   ```

   <br />

<!-- -->

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询设备SN号。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询设备SN号的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "serialNumber");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询设备SN号
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回设备SN号，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />

<!-- -->

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回设备SN号。

   <br />

   ```
   data样例：
   {
       "serialNumber": "xxxx"
   }
   ```

   |返回值|取值|含义|
   |:-----------|:-----|:-----|
   |serialNumber|String|设备SN号。|
   [表2 data返回值]

   <br />
