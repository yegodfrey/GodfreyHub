# 设置运动联动操作

行业App控制穿戴设备进行运动联动，在联动过程中，行业App和穿戴设备都可以执行暂停、继续、结束控制操作。开始运动联动前请先正确佩戴穿戴设备，可以配合[订阅运动联动数据](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-realtime-workout-data-0000002342757102)接口获取联动实时数据。  
![](https://media:301785133833371275)  
* 使用运动联动能力需要开启终端设备侧的蓝牙与位置权限。权限申请参见[添加权限](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/add-permission-0000002338138528)。
* 如果行业App发生了重启操作，部分穿戴设备不会主动停止运动联动而影响到联动控制功能的使用，建议在设备端手动停止联动后再使用运动联动功能。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置运动联动操作的JSON格式参数。

   <br />

   ```
   {
       "settingKey": "workoutControl",
       "settingValue": {
           "workoutType": 1,
           "operateType": 1,
           "operationTime": 1644823557
       }
   }
   ```

   |参数|取值|含义|
   |:------------|:-----------------------------------------------------------|:----------------------------------------|
   |settingKey|workoutControl|运动联动操作键值。|
   |settingValue|包含以下参数：workoutType、operateType、operationTime|运动联动操作内容。|
   |workoutType|* 1：户外跑步 * 2：户外步行 * 3：户外骑行 * 4：室内跑步（跑步机） * 5：室内单车 * 255：自由训练|联动运动类型。|
   |operateType|* 1：开始运动 * 2：暂停运动 * 3：恢复运动 * 4：结束运动|操作类型。|
   |operationTime|UTC时间，单位：秒，long型数据，为当前时间：System.currentTimeMillis()/1000|操作时间，请保证当前终端设备和穿戴设备时间一致，如果时间差超过5s会导致超时报错。|
   [表1 设置运动联动操作参数]

   <br />

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置运动联动操作。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于设置运动联动操作的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("settingKey", "workoutControl");
       JSONObject valueObject = new JSONObject();
       valueObject.put("workoutType", 1);
       valueObject.put("operateType", 1);
       valueObject.put("operationTime", System.currentTimeMillis() / 1000);
       jsonObject.put("settingValue", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置运动联动操作
   deviceManageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11、26|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   如果行业App已经执行命令开始运动，用户在穿戴设备侧执行暂停、继续、结束运动等操作时，行业App会收到数据上报，上报数据包含statusCode和result。  

   |返回值|取值|含义|
   |:------------|:-----------------------------------------------------------|:---------|
   |statusCode|0|成功。|
   |result|包含以下返回值：workoutType、operateType、operationTime|设备上报的操作内容。|
   |workoutType|* 1：户外跑步 * 2：户外步行 * 3：户外骑行 * 4：室内跑步（跑步机） * 5：室内单车 * 255：自由训练|当前运动类型。|
   |operateType|* 2：暂停运动 * 3：恢复运动 * 4：结束运动|操作类型。|
   |operationTime|UTC时间戳，单位：秒（s）|操作时间。|
   [表3 设备操作上报数据]

   行业App收到设备上报数据样例：

   ```
   {
       "workoutType": 4,
       "operateType": 2,
       "operationTime": 1645000795
   }
   ```
