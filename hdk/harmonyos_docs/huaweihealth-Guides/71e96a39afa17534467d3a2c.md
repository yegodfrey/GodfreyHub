# 订阅实时光传感器

订阅和取消订阅穿戴设备的实时光传感器数据。
> 说明
>
> * 行业应用订阅PPG数据会占用较多资源，应用切入后台后可能会被系统杀掉，请注意行业应用保活或者保持应用运行在前台。
> * 设备解除佩戴后将自动停止数据上报，重新佩戴后不会自动上报，需要重新订阅。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于订阅或取消订阅实时PPG数据的ZSON格式的入参数据。

   ```screen
   {
       "item":"realtimePpgData"
   }
   ```

3. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section06031630309)方法订阅实时PPG数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于订阅或取消订阅实时PPG数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "realtimePpgData");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅实时PPG数据
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理订阅返回信息
       }
   };
   manageClient.subscribe(zsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:--------------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7、8、300、303|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|订阅成功时返回空字符串，订阅失败时返回错误信息；订阅成功后，设备上报实时PPG数据。|
   [**表1**ServiceCallback返回值]

   > 说明
   >
   > 订阅实时PPG数据的ServiceCallback不仅会返回订阅操作的结果，另外还会返回后续订阅的事件上报时的数据。

4. 订阅操作的结果和实时PPG数据更新事件变化信息在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，data为空字符串；失败时statusCode返回错误码，data返回对应错误信息；设备上报实时PPG数据时返回statusCode为8，data数据中包含ppg数据时间戳和三路通道数据。

   ```screen
   data样例：
   {
     "timeStamp": 1678695182449,
     "ppg": [
       {
         "channel": 3,
         "data": "[1783458.0, 1784041.0, 1785281.0, 1786011.0, 1786193.0, 1787470.0, 1787981.0, 1788455.0, 1789367.0, 1790279.0]"
       },
       {
         "channel": 5,
         "data": "[6.192854E7, 6.1930292E7, 6.1930364E7, 6.1932624E7, 6.1934888E7, 6.193496E7, 6.1938536E7, 6.1939048E7, 6.1941452E7, 6.1940724E7]"
       },
       {
         "channel": 7,
         "data": "[6.4321564E7, 6.4323048E7, 6.4324736E7, 6.4326144E7, 6.4327128E7, 6.4328132E7, 6.4329588E7, 6.4331264E7, 6.4332924E7, 6.4334696E7]"
       }
     ]
   }
   ```

   |返回值|取值|含义|
   |:--------|:---------------------------|:--------------------------------|
   |timeStamp|UTC时间戳，单位：毫秒|PPG数据时间点。|
   |ppg|JSON数组，channel、data字段组成的列表集合|ppg数据，包含三路通道。|
   |channel|int类型数据|三种数据通道类型，3/5/7分别对应GREEN/RED/IR通道。|
   |data|float[]类型数据|每一路具体的ppg数据。|
   [**表2**data返回订阅信息]

   > 说明
   >
   > PPG传感器采集周期10ms，上报周期100ms左右：三路数据（GREEN/RED/IR） 通道，每路通道上报10个浮点数据。
   >
   > 数据上报数量非固定，示例中给出的是通常上报结果，实际上报周期和数据有可能因设备原因增加或者减少。

5. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section79475211626)方法取消订阅实时PPG数据。

   ```screen
   // 调用unSubscribe方法取消订阅实时光传感数据
   // 注意：这里的serviceCallback和步骤3中声明的serviceCallback要为同一个对象，参数zsonObject要和订阅时保持一致
   manageClient.unSubscribe(zsonObject.toString(), serviceCallback);
   ```
