# 高原关爱自动监护开关设置与查询

设置与查询穿戴设备的高原关爱自动监护开关状态。开启高原关爱自动监护开关后，在设备置于2500米高海拔时，高原关爱应用将提供高反评估的相应功能及建议。同时基于一段时间内的血氧测量结果，对存在较大风险的用户进行提醒。  
![](https://media:301785133830047224)  
* 高原关爱自动监护功能依赖血氧自动检测功能。因此在开启高原关爱自动监护开关时设备会同步开启血氧自动检测开关；关闭高原关爱自动监护开关后血氧自动检测开关不会受到影响。
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的高原关爱自动监护开关状态给穿戴设备。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section209303302232)方法设置高原关爱自动监护开关状态。

   <br />

   ```
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 高原关爱自动监护开关状态值
       let value: boolean = true;
       // 调用Device对象的setSettingInfo方法设置高原关爱自动监护开关状态
       device.setSettingInfo(IndustryService.SettingType.HIGH_LAND_BLOOD_OXYGEN_SWITCH, value).then(() => {
         // 设置高原关爱自动监护开关状态成功
         console.info('Succeeded in setting highLandBloodOxygenSwitch.');
       }).catch((err: BusinessError) => {
         // 设置高原关爱自动监护开关状态失败
         console.error(`Failed to set highLandBloodOxygenSwitch. Code is ${err.code}, message is ${err.message}.`);
       });
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4786175712107)方法查询高原关爱自动监护开关状态。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询高原关爱自动监护开关状态
   device.getSettingInfo(IndustryService.SettingType.HIGH_LAND_BLOOD_OXYGEN_SWITCH).then((result: boolean) => {
     // 查询高原关爱自动监护开关状态成功，打印返回的状态值
     console.info(`Succeeded in getting highLandBloodOxygenSwitch, result is ${result}.`);
   }).catch((err: BusinessError) => {
     // 查询高原关爱自动监护开关状态失败
     console.error(`Failed to get highLandBloodOxygenSwitch. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
