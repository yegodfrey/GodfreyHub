# 获取日志开关状态

获取日志开关状态。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getServiceClient-android_content_Context-)方法，获取[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952)对象。
2. 调用[isLogEnabled](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952#ZH-CN_TOPIC_0000002647924358__isLogEnabled-com_huawei_health_industry_client_callback_ServiceCallback-)方法获取日志开关状态数据。

   ```screen
   // 获取ServiceClient 对象
   ServiceClient serviceClient = IndustryWear.getServiceClient(this);

   // 获取日志开关状态数据
   serviceClient.isLogEnabled(new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
   	// 处理返回信息
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:--------|:--------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码|
   |result|-|接口调用失败时返回错误码，成功时返回日志开关状态|
   [**表1**ServiceCallback返回值]

   ```screen
   result样例：
   {
       "isLogEnabled":false
   }
   ```

   |参数|取值|含义|
   |:-----------|:----|:-----|
   |isLogEnabled|false|日志开关关闭|
   |isLogEnabled|true|日志开关开启|
   [**表2**result返回值]
