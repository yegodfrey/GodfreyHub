# 设置常用联系人

穿戴设备支持常用联系人功能，行业App可以通过本接口设置穿戴设备的常用联系人信息。设置完成后允许用户在在穿戴设备上快速拨打常用联系人电话。  
![](https://media:301785133833994285)  
当需要获取手机上的联系人信息作为参数下发到设备时，可以参考FAQ中[如何获取手机联系人数据](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/faq-0000002511427352#section498154014567)。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置常用联系人的JSON格式参数。

   <br />

   ```
   {
     "settingKey": "favoriteContacts",
     "settingValue": [
       {
         "name": "zs",
         "phoneNumber": "11122223333"
       },
       ...
       {
         "name": "ls",
         "phoneNumber": "44455556666"
       }
     ]
   }
   ```

   |参数|取值|含义|
   |:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------|
   |settingKey|favoriteContacts|常用联系人键值。|
   |settingValue|由name、phoneNumber组成的JSON数组，JSON数组长度不大于穿戴设备支持的常用联系人最大数量(穿戴设备支持的常用联系人最大数量可以从[查询常用联系人](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/query-favorite-contacts-0000002417529489)获取)|常用联系人内容。|
   |name|字符串，长度不大于30字节|联系人姓名。|
   |phoneNumber|字符串，长度不大于20字节|联系人电话号码，只能包含数字\[0-9\]、英文括号()、+、-，必须包含一个数字。|
   [表1 设置常用联系人参数]

   <br />

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置常用联系人。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构建用于设置常用联系人的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("settingKey", "favoriteContacts");
       JSONArray valueArray = new JSONArray();

       JSONObject item1 = new JSONObject();
       item1.put("name", "zs");
       item1.put("phoneNumber", "11122223333");
       valueArray.put(item1);

       JSONObject item2 = new JSONObject();
       item2.put("name", "ls");
       item2.put("phoneNumber", "44455556666");
       valueArray.put(item2);

       jsonObject.put("settingValue", valueArray);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置常用联系人
   deviceManageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:-----------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、2、3、6、7、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [表2 ServiceCallback返回值]
