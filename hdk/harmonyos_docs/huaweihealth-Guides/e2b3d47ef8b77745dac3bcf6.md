# 设置证书路径

行业App设置证书路径后，在连接设备时会读取证书内容并访问HEM鉴权地址进行权限校验，仅当校验通过后才能和设备进行连接配对。  
![](https://media:301785133820854093)  
* HEM（HUAWEI Enterprise Manager）是依托华为终端强大的平台和硬件能力提供的移动管理终端设备的解决方案，可以提供对设备的权限授权检测服务。
* 开发者测试证书存在有效期限制，行业用户测试证书转商用证书后需提醒用户进行一次重新配对连接操作。

1. 在APP Target的Build Phases选项卡的Copy Bundle Resources中添加证书。

   <br />

   ![](https://media:301785133820914094 "点击放大")

   <br />

2. 导入相关模块。
3. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)的[setCertPath](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section23791051152312)方法设置证书路径。

   <br />

   ```
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 调用IndustryService的setCertPath方法设置证书路径
           try await IndustryService.setCertPath(cerPath: "XXXX")

           // 设置证书路径成功
           print("Succeeded in setting cert path")
       } catch let err as IndustryError {
           // 设置证书路径失败
           print("Failed to set cert path. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />
