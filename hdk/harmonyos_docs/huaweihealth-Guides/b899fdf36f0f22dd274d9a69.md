# 查询日常活动数据

查询穿戴设备的日常活动数据。用户佩戴穿戴设备进行日常活动后，行业App可以通过本接口查询穿戴设备上记录的日常活动数据。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section2013310181189)方法查询日常活动数据。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryHistoryData方法查询日常活动数据
           let data = try await device.queryHistoryData(
               type: .fitness,
               startTime: 1778461200,
               endTime: 1778464800
           )

           // 查询日常活动数据成功
           print("Succeeded in querying fitness, data is \(data)")
       } catch let err as IndustryError {
           // 查询日常活动数据失败
           print("Failed to query fitness. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   > 说明
   >
   > 查询日常活动数据接口参数要求：
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   > * 查询开始时间和当前时间间隔不超过7天（不包含当天）。

   查询成功并且有日常活动数据返回[[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section1036173885514)]，查询成功日常活动数据为空返回[]，查询失败抛出[IndustryError](https://developer.huawei.com/consumer/cn/doc/health-References/industry_error_ios-0000002594109612)。

   查询成功返回的日常活动数据样例：

   ```screen
   [
       {
           startTime: 1778462380,
           endTime: 1778462380,
           type: .fitness,
           fields: [
               "step": 100,
               "calorie": 1000,
               "distance": 10,
               "exerciseIntensity": 0,
               "height": 36
           ]
       },
       ...
   ]
   ```

   |返回值|类型|单位|含义|
   |:----------------|:--|:-|:--------------------------------------------------------------|
   |step|Int|-|步数。|
   |calorie|Int|卡|卡路里。|
   |distance|Int|米|距离。|
   |exerciseIntensity|Int|-|运动强度，见[运动强度](#ZH-CN_TOPIC_0000002647924550__table132645267117)。|
   |height|Int|分米|高度。|
   [**表1**返回日常活动数据fields说明]

   |返回值|取值|含义|
   |:----------------|:-|:----|
   |exerciseIntensity|0|低强度。|
   |exerciseIntensity|1|中高强度。|
   [**表2**运动强度]
