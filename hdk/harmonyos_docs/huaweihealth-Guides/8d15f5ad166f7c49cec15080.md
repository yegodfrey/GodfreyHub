# 查询脉搏波心律失常分析数据

穿戴设备提供脉搏波心律失常分析功能，用户测量脉搏波心律失常分析后，行业应用可以通过本接口查询穿戴设备上记录的脉搏波心律失常分析数据。  
![](https://media:301785133831532245)  
* 查询设备的脉搏波心律失常分析数据，需要先在运动健康APP中激活脉搏波心律失常分析功能。打开路径：点击【设备】-\>点击已连接的【设备卡片】-\>点击【脉搏波心律失常分析】-\>打开页面后点击【同意】-\>进入下一页面，点击上方的【激活】按钮。
* 不支持并发查询脉搏波心律失常分析数据，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询脉搏波心律失常分析数据的ZSON格式的入参数据。

   <br />

   ```
   {
       "item": "arrhythmiaResult",
       "value": {
           "startTime": 1992342222, // 单位：秒(s)
           "endTime": 1992342229 // 单位：秒(s)
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:--------|
   |startTime|UTC时间戳，单位：秒（s）|查询数据开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询数据结束时间。|
   [表1 查询脉搏波心律失常分析数据参数]

   ![](https://media:301785133831566246)  
   接口要求查询开始时间和当前时间间隔不超过7天。

   <br />

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询脉搏波心律失常分析数据。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询脉搏波心律失常分析数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       ZSONObject valueObject= new ZSONObject();
       valueObject.put("startTime", 1992342222);
       valueObject.put("endTime", 1992342229);
       zsonObject.put("item", "arrhythmiaResult");
       zsonObject.put("value", valueObject);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询脉搏波心律失常分析数据
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、6、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回脉搏波心律失常分析数据，失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含脉搏波心律失常分析数据。

   <br />

   ```
   data样例：
   {
       "dataType": "arrhythmiaResult",
       "totalCount": 1,
       "index": 0,
       "count": 1,
       "dataList": [{
           "saveTime": 1657158420,
           "measureType": 1,
           "ppgIrregulerHeartbeat": 1
       }]
   }
   ```

   |返回值|取值|含义|
   |:--------------------|:---------|:----------------------------------------------------------------------------------|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |saveTime|UTC时间，单位：秒|记录保存时间。|
   |measureType|int类型数据|心律测量类型： * 0：自动测量 * 1：主动测量|
   |ppgIrregulerHeartbeat|int类型数据|脉搏波心律失常分析结果： * 1：表示未见异常 * 2：表示疑似早搏 * 3：表示疑似房颤 * 4：表示不规则心律-存在房颤风险 * 5：表示不规则心律-存在早搏风险|
   [表3 dataList返回值]

   ![](https://media:301785133831597247)  
   * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回，不需要开发者再调用查询接口。
   * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。

   <br />
