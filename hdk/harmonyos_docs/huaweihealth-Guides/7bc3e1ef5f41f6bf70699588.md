# 订阅设备通话操作

行业SDK支持行业App订阅和取消订阅设备侧挂断电话和短信拒接来电操作，当行业App收到挂断电话操作时，可以调用系统挂断电话接口挂断电话；当行业App收到短信拒接来电操作时，行业App可以调用系统发送短信接口回复对方。  
![](https://media:301785133837323344)  
* 如果行业App需要挂断电话，请动态申请应答电话呼叫权限（android.permission.ANSWER_PHONE_CALLS）才可以调用系统挂断电话接口挂断电话。
* 如果行业App需要短信拒接回复，请动态申请发送短信权限（android.permission.SEND_SMS）才可以调用系统发送短信接口发送短信。  
![](https://media:301785133837351345)  
行业App没有短信发送权限时，[轻量级智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li1184517579555)/[智能手环](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li19369195911148)无法使用短信拒接功能。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于订阅或取消订阅设备通话操作的JSON格式参数。

   <br />

   ```
   {
       "item":"phoneCallOperation"
   }
   ```

   <br />

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅设备通话操作。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于订阅或取消订阅设备通话操作的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "phoneCallOperation");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅设备通话操作
   ServiceCallback serviceCallback = new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   };
   manageClient.subscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   |返回值|取值|含义|
   |:---------|:---------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、2、3、4、5、6、7、10|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|订阅成功时返回空字符串，订阅失败时返回错误信息，设备通话操作时返回对应操作状态。|
   [表1 ServiceCallback返回值]

   ![](https://media:301785133837379346)  
   订阅设备通话操作的ServiceCallback不仅会返回订阅操作的结果，另外还会返回后续订阅的通话操作状态。

   <br />

5. 订阅操作的结果和设备通话操作状态在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，result为空字符串；失败时statusCode返回错误码，result返回对应错误信息；设备通话挂断或者短信拒接时返回statusCode为10，result数据中包含当前操作状态。

   <br />

   ```
   当operation为0挂断来电时result样例：
   {
       "operation":0
   }
   ```

   ```
   当operation为1短信拒接来电时result样例：
   {
       "operation":1,
       "phoneNumber":"18211111111",
       "subscriptionId":1,
       "replyContent":"一会联系你！"
   }
   ```

   |返回值|取值|含义|
   |:-------------|:----------------|:-----------------------------------------------------------------|
   |operation|0：挂断来电 1：短信拒接来电|设备挂断来电或者短信拒接来电操作。|
   |phoneNumber|String类型数据，非必返回字段|来电时的呼入电话号码，对应短信拒接来电操作时接收短信的电话号码。 当operation为0时不返回。当operation为1时返回。|
   |subscriptionId|int类型数据，非必返回字段|当前来电SIM卡的subscriptionId。 当operation为0时不返回。当operation为1时返回。|
   |replyContent|String类型数据，非必返回字段|短信拒接来电的短信内容。 当operation为0时不返回。当operation为1时返回。|
   [表2 result返回订阅信息]

   <br />

6. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅设备通话操作。

   <br />

   ```
   // 调用unSubscribe方法取消订阅设备通话操作。
   // 注意：这里的serviceCallback和步骤4中声明的serviceCallback要为同一个对象，参数jsonObject要和订阅时保持一致
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   <br />
