# 订阅设备侧应用消息

订阅与取消订阅行业App与穿戴设备侧应用消息。订阅成功后行业App可以接收设备侧应用发送的文本消息和文件。  
![](https://media:301785133828140193)  
* 若要使用订阅穿戴设备侧应用消息功能，穿戴设备侧需安装相对应的应用，参考[穿戴设备侧应用开发](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/version-change-history-0000001119036892)。
* 最大支持10个不同包名的订阅，如果超过了10个，请先取消已有的订阅再重试。

<!-- -->

* 建议及时将已使用完毕的临时文件删除。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于订阅或取消订阅设备侧应用消息的JSON格式参数。

   <br />

   ```
   {
       "item": "p2pMessage",
       "value": {
           "peerPkgName": "com.huawei.aa",
           "peerFingerPrint": "com.huawei.aa_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
       }
   }
   ```

   |value参数|含义|
   |:--------------|:-----------------------------------------------------------------------------------------------------------------------|
   |peerPkgName|穿戴设备侧[应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)|
   |peerFingerPrint|[穿戴设备侧应用签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/signature-0000001053969657)|
   [表1 订阅设备侧应用消息参数]

   <br />

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅设备侧应用消息。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于订阅或取消订阅设备侧应用消息的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   JSONObject valueObject = new JSONObject();
   try {
       jsonObject.put("item", "p2pMessage");
       valueObject.put("peerPkgName", "com.huawei.aa");
       valueObject.put("peerFingerPrint", "com.huawei.aa_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法
   manageClient.subscribe(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:----------------------------|:--------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、26、30、207、208、209|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码|
   |result|-|接口调用成功时返回空字符串，失败时返回错误信息，穿戴设备侧应用发送消息或文件到行业APP时返回文本消息、文件接收进度、文件保存位置等信息|
   [表2 ServiceCallback返回值]

   ```
   // result样例:穿戴设备侧应用发送文本消息到行业App
   {
       "type": 1,
       "data": "this is a message."
   }
   ```

   <br />

   ```
   // result样例:穿戴设备侧应用发送文件到行业App
   // 文件接收过程data样例
   {
       "progress": 0
   }
   ...
   {
       "progress": 100
   }
   // 文件接收完成时data样例
   {
       "type": 2,
       "filePath": "\/data\/data\/com.huawei.health.industry.demo\/files\/commonFileRequest\/demo.txt"
   }
   ```

   |返回值|含义|
   |:-------|:-----------------------------|
   |type|* 1：表示消息 * 2：表示文件|
   |data|穿戴设备侧应用发送的文本消息|
   |progress|穿戴设备侧上传文件时，行业SDK文件接收进度|
   |filePath|行业SDK接收完穿戴设备侧上传的文件后，文件在手机的保存路径|
   [表3 result返回值]

   <br />

5. 调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅设备侧应用消息。

   <br />

   ```
   // 调用unSubscribe方法取消订阅设备侧应用消息
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```

   ![](https://media:301785133828167194)  
   取消订阅成功条件：
   * 取消订阅时要求输入的解订阅参数和订阅时的参数一致。
   * 取消订阅时传入的ServiceCallback，要求和订阅时传入的ServiceCallback为同一个对象。

   <br />
