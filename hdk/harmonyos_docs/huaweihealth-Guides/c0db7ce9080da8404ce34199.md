# 添加音乐到设备

行业SDK支持添加手机本地音乐到穿戴设备，添加成功后，穿戴设备可以播放本地音乐。  
![](https://media:301785133841839410)  
* 对于[智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)需要先打开表侧的音乐应用，同意音乐应用访问存储权限后，才可以添加音乐，否则返回设备音乐未授权错误500（参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)）。对于[轻量级智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li1184517579555)/[智能手环](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li19369195911148)无存储权限限制，可以直接添加音乐。
* 添加音乐时行业SDK会校验歌曲的格式设备是否支持、部分高清格式设备是否支持，歌曲数量是否超过设备支持的最大数量，歌曲文件大小是否超过穿戴设备剩余存储空间，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。
* [智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)和[轻量级智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li1184517579555)/[智能手环](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li19369195911148)添加音乐的差异：
  1. [智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)在添加音乐的过程中（没有添加完成），如果手表连接断开导致添加音乐失败，手表上会显示刚才添加失败的歌曲，查询设备本地音乐信息接口能查询到刚才添加失败的歌曲。建议您根据添加音乐接口的返回结果判断歌曲是否添加成功，如果添加失败，请先查询歌曲是否存在（参见[查询设备本地音乐](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/query-device-local-music-0000002417409613)），如果存在则删除后重新添加。
2. [轻量级智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li1184517579555)/[智能手环](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li19369195911148)在添加歌曲的过程中添加失败，手表上不显示添加失败的歌曲，不能查询到添加失败的歌曲。  
![](https://media:301785133841875411)  
添加歌曲文件需要您的App具有访问存储权限或者媒体权限，添加歌曲前App请先申请访问存储权限或者媒体权限，参见[添加权限](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/add-permission-0000002338138528)。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于添加音乐到设备的JSON格式参数。

   <br />

   ```
   {
       "item":"addMusicToDevice",
       "value": {
           "songName":"Dream It Possible",
           "singerName":"Delacey",
           "songFilePath":"/storage/emulated/0/Music/Dream It Possible.flac"
       }
   }
   ```

   |参数|取值|含义|
   |:-----------|:--------------------------------------|:------------------------------------------------------|
   |item|addMusicToDevice|添加音乐到设备键值。|
   |value|包含以下参数：songName、singerName、songFilePath|添加音乐到设备内容。|
   |songName|String类型数据|歌曲名称，歌曲名称最大长度120字节。超出最大长度返回状态码2。|
   |singerName|String类型数据|歌手名称，歌手名称最大长度60字节。超出最大长度返回状态码2。|
   |songFilePath|String类型数据|歌曲文件路径，歌曲文件路径最大长度1024字节，其中歌曲文件名称最大长度244字节。超出最大长度返回状态码2。|
   [表1 添加音乐到设备参数]

   ![](https://media:301785133841981412)  
   * 歌曲文件路径只支持绝对路径，不支持相对路径，比如包含../的路径。
   * 获取绝对路径方法：
     * 如果使用File访问音乐文件，请使用file.getCanonicalPath()方法获取歌曲文件绝对路径。
     * 如果使用ContentResolver访问音乐，索引MediaStore.Audio.Media.DATA对应的值为音乐文件绝对路径。

   <br />

4. 调用[send](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__send-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法添加音乐到设备。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于添加音乐到设备的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject value = new JSONObject();
       value.put("songName", "Dream It Possible");
       value.put("singerName", "Delacey");
       value.put("songFilePath", "/storage/emulated/0/Music/Dream It Possible.flac");
       jsonObject.put("item", "addMusicToDevice");
       jsonObject.put("value", value);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用send方法添加音乐到设备
   deviceManageClient.send(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int resultCode, String result) {
           // 处理返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:---------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11、30、40、41、42、43、44、208、500、501、502、503|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码和音乐同步状态码。|
   |result|-|接口调用成功时返回音乐文件传输进度和结果，失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   行业App添加音乐的过程中会不断返回音乐文件传输的进度，当statusCode为208，表示音乐文件传输中，result返回传输进度。当statusCode为0表示音乐文件添加成功，result返回空字符串。

   ```
   // 音乐文件传输中result样例：
    {
       "progress": 0
    }  
    {
       "progress": 1
    }  
   ...
   ```

   |返回值|取值|含义|
   |:-------|:------|:--------|
   |progress|int类型数据|歌曲文件传输进度。|
   [表3 result返回值]
