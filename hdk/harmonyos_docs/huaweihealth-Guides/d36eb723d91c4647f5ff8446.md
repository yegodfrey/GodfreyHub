# 查询日常健康数据

查询穿戴设备用户的日常健康数据，支持查询：日常活动数据、周期心率数据和血氧数据。
> 说明
>
> * 不支持并发查询日常健康数据，需等待上一次查询结束后方可进行下一次查询。
> * 此接口不可与日常活动状态同时查询，需等待上一个任务结束后方可继续查询。
> * 需要查询心率和血氧数据时，请提前开启连续测量心率和血氧自动检测开关，否则会返回空数据。
> * 此接口可以配合[订阅日常健康数据更新](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-daily-health-update-event-0000002447591805)使用，当订阅的日常健康数据事件上报有数据更新时，调用此接口查询日常健康数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询日常健康数据的ZSON格式的入参数据。

   ```screen
   {
       "item":"dailyHealthData",
       "value":
       {
           "startTime":1644796800,
           "endTime":1644811200,
           "dataType":["fitness","heartRate","spo2"]
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:----------------------------------------------|:---------|
   |startTime|UTC时间戳，单位：秒|查询数据开始时间。|
   |endTime|UTC时间戳，单位：秒|查询数据结束时间。|
   |dataType|长度至少为1的数组，可选元素如下所示 * fitness * heartRate * spo2|需要查询的数据类型。|
   [**表1**查询日常健康数据参数]

   > 说明
   > * 接口要求查询开始时间和结束时间间隔不超过24小时且不少于1分钟，查询开始时间和当前时间间隔不超过7天。
   > * 建议查询开始时间至少比当前时间早5分钟以上，否则查询得到的运动强度数据可能不准确。
   > * 查询的数据类型当前支持：日常活动（fitness）、周期心率（heartRate）、血氧（spo2），入参要求至少输入一个数据类型。

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询日常健康数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询日常健康数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       ZSONArray zsonArray = new ZSONArray();
       zsonArray .put("fitness");
       zsonArray .put("heartRate");
       zsonArray .put("spo2");
       ZSONObject valueObject = new ZSONObject();
       valueObject.put("startTime", 1644796800);
       valueObject.put("endTime", 1644811200);
       valueObject.put("dataType", zsonArray);
       zsonObject.put("item", "dailyHealthData");
       zsonObject.put("value", valueObject);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询日常健康数据
   manageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、6、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回日常健康数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含日常健康数据。

   ```screen
   data样例：
   {
       "dataType": "fitness",
       "totalCount": 30,
       "index": 0,
       "count": 30,
       "dataList": [{
           "startTime": 1644544380,
           "step": 30,
           "calorie": 200,
           "distance": 5,
           "height": 0,
           "restingHeartRate": 68,
           "exerciseIntensity": 0
       },{
           ...
       }]
   }
   {
       "dataType": "heartRate",
       "totalCount": 11,
       "index": 0,
       "count": 11,
       "dataList": [{
           "startTime": 1644544380,
           "heartRate": 97
       },{
           ...
       }]
   }
   {
       "dataType": "spo2",
       "totalCount": 5,
       "index": 0,
       "count": 5,
       "dataList": [{
           "startTime": 1644544380,
           "spo2": 98
       },{
           ...
       }]
   }
   ```

   |返回值|取值|含义|
   |:----------------|:------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------|
   |dataType|"fitness"|日常健康活动数据。|
   |dataType|"heartRate"|心率。|
   |dataType|"spo2"|血氧。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一个数据点在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|包含以下一个或多个字段：startTime、step、calorie、distance、height、restingHeartRate、exerciseIntensity|具体数据信息列表，不同数据类型包含不同字段，详见以上data样例。|
   |startTime|long类型数据|当前数据点的开始时间戳，UTC时间，单位：秒。|
   |step|int类型数据|日常活动数据字段，步数。|
   |calorie|int类型数据|日常活动数据字段，卡路里，单位：cal。|
   |distance|int类型数据|日常活动数据字段，距离。|
   |height|int类型数据|日常活动数据字段，高度，单位：米。|
   |restingHeartRate|int类型数据|日常活动数据字段，静息心率值。|
   |exerciseIntensity|int类型数据|日常活动数据字段，运动强度，参见[运动强度类型枚举](#ZH-CN_TOPIC_0000002648084488__table1144284415323)。|
   |heartRate|int类型数据|周期心率数据字段，心率值，单位：次/分钟。|
   |spo2|int类型数据|血氧数据字段，血氧值，99代表血氧浓度99%。|
   [**表3**data返回值]

   |exerciseIntensity取值|含义|
   |:------------------|:---------------------------|
   |0|未指定或低强度。说明：运动强度类型未指定时，使用此字段。|
   |1|中高强度。|
   [**表4**运动强度类型枚举]

   > 说明
   > * 日常健康数据返回时会根据查询时输入的数据类型分别返回，每种类型的数据都单独调用回调方法。
   > * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回。
   > * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。
