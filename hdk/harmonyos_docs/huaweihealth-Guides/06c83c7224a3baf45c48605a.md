# 查询日常活动数据

查询穿戴设备的日常活动数据。用户佩戴穿戴设备进行日常活动后，行业App可以通过本接口查询穿戴设备上记录的日常活动数据。
> 说明
>
> * 同一设备不支持日常活动数据的并发查询，需等待上一次查询结束后方可进行下一次查询。
> * 此接口不可与历史步数记录或日常活动状态同时查询，需等待上一个任务结束后方可继续查询。
> * 此接口可以配合[订阅日常活动数据更新](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-daily-health-update-event-0000002376715109)使用，当订阅的日常活动数据事件上报有数据更新时，调用此接口查询日常活动数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询日常活动数据的JSON格式参数。

   ```screen
   {
       "item":"dailyHealthData",
       "value":
       {
           "startTime":1644796800,
           "endTime":1644811200,
           "subscribeId":"3fc65203-dc4c-49d8-a436-71a8ceaffbff",
           "dataType":["fitness"]
       }
   }
   ```

   |参数|取值|含义|
   |:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------|
   |startTime|UTC时间戳，单位：秒|查询数据开始时间。|
   |endTime|UTC时间戳，单位：秒|查询数据结束时间。|
   |subscribeId（可选）|[订阅日常活动数据更新](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-daily-health-update-event-0000002376715109)接口返回的订阅ID|订阅ID。|
   |dataType|["fitness"]|日常活动数据类型。|
   [**表1**查询日常活动数据参数]

   > 说明
   > * 接口要求查询开始时间和结束时间间隔不超过24小时且不少于1分钟，查询开始时间和当前时间间隔不超过7天。
   > * 建议查询开始时间至少比当前时间早5分钟以上，否则查询得到的运动强度数据可能不准确。
   > * subscribeId为可选参数，如果不传入subscribeId字段或者传入的内容为空字符串，按照当前输入的查询时间作为实际查询时间；如果输入有效的subscribeId，会将订阅Id对应的订阅时间和当前输入的查询时间取交集，在查询数据时采用交集的时间区间作为实际查询时间，如不存在交集，返回失败。

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询日常活动数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询日常活动数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONArray jsonArray = new JSONArray();
       jsonArray.put("fitness");
       JSONObject valueObject = new JSONObject();
       valueObject.put("startTime", 1644796800);
       valueObject.put("endTime", 1644811200);
       // 如果没有订阅，可以不传入subscribeId参数。
       valueObject.put("subscribeId", "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx");
       valueObject.put("dataType", jsonArray);
       jsonObject.put("item", "dailyHealthData");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询日常活动数据
   manageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回日常活动数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含日常活动数据。

   ```screen
   result样例：
   {
       "dataType": "fitness",
       "totalCount": 30,
       "index": 0,
       "count": 30,
       "dataList": [{
           "startTime": 1644544380,
           "step": 30,
           "calorie": 200,
           "distance": 5,
           "height": 0,
           "restingHeartRate": 68,
           "exerciseIntensity": 0
       },{
           ...
       }]
   }
   ```

   |返回值|取值|含义|
   |:----------------|:-------|:-----------------------------------------------------------------------|
   |dataType|fitness|日常活动数据类型。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一个数据点在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |startTime|long类型数据|当前数据点的开始时间戳，UTC时间，单位：秒。|
   |step|int类型数据|步数。|
   |calorie|int类型数据|卡路里，单位：cal。|
   |distance|int类型数据|距离，单位：米。|
   |height|int类型数据|高度，单位：分米。|
   |restingHeartRate|int类型数据|静息心率值。|
   |exerciseIntensity|int类型数据|运动强度，参见[表4 运动强度类型枚举](#ZH-CN_TOPIC_0000002647924554__table1144284415323)。|
   [**表3**result返回值]

   |exerciseIntensity取值|含义|
   |:------------------|:---------------------------|
   |0|未指定或低强度。说明：运动强度类型未指定时，使用此字段。|
   |1|中高强度。|
   [**表4**运动强度类型枚举]

   > 说明
   > * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回。
   > * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。
