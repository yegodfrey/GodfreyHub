# 配置混淆脚本

开发者编译APK前需要配置不混淆Health IndustryConnectionUI SDK，避免功能异常。

1. 打开应用级的混淆配置文件proguard-rules.pro。
2. 加入排除IndustryConnectionUI SDK的混淆配置

   <br />

   ```
   -keepattributes *Annotation*, Signature, InnerClasses, EnclosingMethod
   -keep class com.huawei.health.industry.industryconnectionui.activity.ScanDeviceActivity {*;}
   ```

   <br />
