# 心率区间设置与查询

设置与查询穿戴设备在运动状态下的心率区间。当用户佩戴穿戴设备进行运动时，穿戴设备会根据用户实际心率判断当前所处的心率区间，提示对应的的运动状态。
> 说明
>
> * 心率区间由6个按降序排列的心率数值（单位：次/分钟）组成，分别代表最大心率（极限心率上限）、极限心率下限（无氧心率上限）、无氧心率下限（有氧心率上限）、有氧心率下限（燃脂心率上限）、燃脂心率下限（热身心率上限）、热身心率下限。这6个心率数值共组成5个心率区间，分别对应5种运动状态：极限、无氧耐力、有氧耐力、燃脂、热身。
> * 心率区间数值设置规则：
>   * 最大心率 > 极限心率下限 > 无氧心率下限 > 有氧心率下限 > 燃脂心率下限 > 热身心率下限
>   * 心率区间各个参数的可选值范围为：最大心率*30% ~ 最大心率
>   * 最大心率取值范围：[100, 220]

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setHeartRateZones](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section18716241119)方法设置心率区间。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 心率区间参数
           let heartRateZones = [210,180,150,120,90,70]

           // 调用Device对象的setHeartRateZones方法设置心率区间
           try await device.setHeartRateZones(heartRateZones: heartRateZones)

           // 设置心率区间成功
           print("Succeeded in setting heartRateZones")
       } catch let err as IndustryError {
           // 设置心率区间失败
           print("Failed to set heartRateZones. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getHeartRateZones](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section9858217417)方法查询心率区间。

   ```screen
   Task {
       do {
           // 调用Device对象的getHeartRateZones方法查询心率区间
           let heartRateZones = try await device.getHeartRateZones()

           // 查询心率区间成功
           print("Succeeded in getting heartRateZones, heartRateZones: \(heartRateZones)")
       } catch let err as IndustryError {
           // 查询心率区间失败
           print("Failed to get heartRateZones. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
