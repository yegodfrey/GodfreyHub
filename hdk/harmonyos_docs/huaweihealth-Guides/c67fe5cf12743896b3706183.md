# 配置应用签名信息

开发者通过DevEco Studio创建新的密钥文件（.p12文件）和证书请求文件（.csr文件），用于申请数字证书（.cer文件）和HarmonyAppProvision文件（.p7b文件），保证集成Health Industry SDK后应用能正常安装到穿戴设备。

## 生成密钥文件和证书请求文件

1. 在主菜单栏单击Build > Generate Key and CSR。

   > 说明
   >
   > 如果本地已有对应的密钥，无需新生成密钥，可以在Generate Key界面中单击下方的Skip跳过密钥生成过程，直接使用已有密钥生成证书请求文件。

2. 在Key Store File中，可以单击Choose Existing选择已有的密钥库文件（存储有密钥的.p12文件）；如果没有密钥库文件，单击New进行创建。下面以新创建密钥库文件为例进行说明。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/xyh1JjxoS26QaG0Sm8VfMw/zh-cn_image_0000002648084566.png?HW-CC-KV=V1&HW-CC-Date=20261008T170817Z&HW-CC-Expire=31536000000&HW-CC-Sign=DADB99D454A494FAB6D31468E8118A6B1189CF494E7FD76BE01C143BA887B65E)

3. 在Create Key Store窗口中，填写密钥库信息后，单击OK。

   * Key Store File：设置密钥库文件存储路径，并填写p12文件名。
   * Password：设置密钥库密码，必须由大写字母、小写字母、数字和特殊符号中的两种以上字符的组合，长度至少为8位。请记住该密码，后续签名配置需要使用。
   * Confirm Password：再次输入密钥库密码。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/tNaqmcsBRE2f93DK2oENUA/zh-cn_image_0000002647924686.png?HW-CC-KV=V1&HW-CC-Date=20261008T170817Z&HW-CC-Expire=31536000000&HW-CC-Sign=87AF705609E2F5E9AFCA5FD0FE454DFC1A48BD04D15A3A0DA8F50C6FFE5FEDE6)

4. 在Generate Key and CSR界面中，继续填写密钥信息后，单击Next。

   * Alias：密钥的别名信息，用于标识密钥名称。请记住该别名，后续签名配置需要使用。
   * Password：密钥对应的密码，与密钥库密码保持一致，无需手动输入。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/E68X1r6DQeSaDUVR_fipPQ/zh-cn_image_0000002678004449.png?HW-CC-KV=V1&HW-CC-Date=20261008T170817Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CCC02B845C3DD2AFF6A68E1DBE3BB983BFCA450F4BE1A89FE099D8984F1044A)

5. 在Generate Key and CSR界面，设置CSR文件存储路径和CSR文件名。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/pY3ub3QETjCkNH5YyoLjnw/zh-cn_image_0000002678004447.png?HW-CC-KV=V1&HW-CC-Date=20261008T170817Z&HW-CC-Expire=31536000000&HW-CC-Sign=7392F248F2C244E4D2863D94D969A0AD2818F33AB1AC8D6B4F2DB4BA6863B422)

6. 单击Finish按钮，创建CSR文件成功，可以在存储路径下获取生成的密钥库文件（.p12）和证书请求文件（.csr）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/lpcJcEW-TBapQqMoXsaBSQ/zh-cn_image_0000002648084568.png?HW-CC-KV=V1&HW-CC-Date=20261008T170817Z&HW-CC-Expire=31536000000&HW-CC-Sign=CCC5880D0BB050ACD3EF8C4D6FD2C712E383CE61B43501F5C16E7BDE41B70B33)

## 申请发布证书和Profile文件

通过生成的证书请求文件，向[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)申请发布证书和Profile文件，操作如下。

1. 创建HarmonyOS应用/元服务：在AppGallery Connect项目中，创建一个HarmonyOS应用/元服务，用于发布证书和Profile文件申请，具体请参考[创建HarmonyOS应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-app-0000002247955506)或[创建元服务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-atomic-service-0000002247795706)。 说明
   >
   > 在应用/服务分发阶段，HarmonyOS应用将被分发至应用市场，元服务将会被分发至服务中心。如果申请元服务的签名证书，在创建应用操作时，"是否元服务"选项请选择"是"。
2. 申请发布证书和Profile文件：在AppGallery Connect中申请、下载发布证书和Profile文件，具体请参考[申请发布证书](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-cert-0000002283336729)和[申请发布Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-profile-0000002248341090)。 注意
   > * 发布证书和发布Profile文件签名的应用不能手动安装到穿戴设备上，只能通过发布到应用市场后安装到穿戴设备上。
   > * 在开发调试阶段，使用调试证书和调试Profile手动签名的应用才能安装到穿戴设备上。具体请参考[申请调试证书](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-cert-0000002283256797)和[申请调试Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-profile-0000002248181278)。

用于发布的证书和Profile文件申请完成后，请在DevEco Studio中进行签名，请参考[配置签名信息](#section1839475132817)。

## 配置签名信息

使用制作的私钥（.p12）文件、在AppGallery Connect中申请的证书（.cer）文件和Profile（.p7b）文件，在DevEco Studio配置工程的签名信息，构建携带发布签名信息的APP。

在File > Project Structure > Project > Signing Configs > default界面中，取消"Automatically generate signature"勾选项，然后配置工程的签名信息。

* Store File：选择密钥库文件，文件后缀为.p12。
* Store Password：输入密钥库密码。
* Key Alias：输入密钥的别名信息。
* Key Password：输入密钥的密码。
* Sign Alg：签名算法，固定为SHA256withECDSA。
* Profile File：选择申请的发布Profile文件，文件后缀为.p7b。
* Certpath File：选择申请的发布数字证书文件，文件后缀为.cer。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/8va6d-EMRhCtTSKc3gmOAQ/zh-cn_image_0000002678164285.png?HW-CC-KV=V1&HW-CC-Date=20261008T170817Z&HW-CC-Expire=31536000000&HW-CC-Sign=2A640C411D147B50A93B910130584BC28CB8CE2F1FA1B157110E2C06E7FDE5E4 "点击放大")

设置完签名信息后，单击OK进行保存，然后使用DevEco Studio生成APP，请参考[编译构建.app文件](#section164316581548)。

## 编译构建.app文件

> 注意
>
> 应用上架时，要求应用包类型为Release类型。

打包APP时，DevEco Studio会将工程目录下的所有HAP/HSP模块打包到APP中，因此，如果工程目录中存在不需要打包到APP的HAP/HSP模块，请手动删除后再进行编译构建生成APP。

1. 单击Build > Build Hap(s)/APP(s) > Build APP(s)，等待编译构建完成已签名的应用包。 说明
   >
   > 当未指定[构建模式](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hvigor-compilation-options-customizing-guide#section192461528194916)时，构建APP包，默认Release模式；构建HAP/HSP/HAR包，默认Debug模式。
   >
   > 即Build APP(s)时，默认构建的APP包为Release类型，符合上架要求，开发者无需进行另外设置。
2. 编译构建完成后，可以在工程目录build > outputs > default下，获取带签名的应用包。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/xri_-i-UTcishlSB4AbQrg/zh-cn_image_0000002647924684.png?HW-CC-KV=V1&HW-CC-Date=20261008T170817Z&HW-CC-Expire=31536000000&HW-CC-Sign=48930A9B8915526AC1B3725747FF4664C120BEAEC214C168ED87986B49BF8BB6)
