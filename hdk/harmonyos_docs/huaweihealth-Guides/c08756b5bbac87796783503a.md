# 设置闹钟信息

穿戴设备支持闹钟功能，行业App可以通过本接口设置穿戴设备的闹钟信息。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置闹钟信息的JSON格式参数。

   <br />

   ```
   {
       "settingKey": "alarmInfo",
       "settingValue": {
           "alarmsList": [
               {
                   "index": 1,
                   "enable": 1,
                   "time": "0809",
                   "cycle": 0,
                   "name": "clock1"
               },
               {
                   "index": 2,
                   "enable": 0,
                   "time": "2100",
                   "cycle": 7,
                   "name": "clock2"
               },
               {
                   "index": 3,
                   "enable": 0,
                   "time": "2300",
                   "cycle": 7,
                   "name": "clock3"
               },
               {
                   "index": 4,
                   "enable": 0,
                   "time": "2305",
                   "cycle": 7,
                   "name": "clock4"
               }
           ]
       }
   }
   ```

   |参数|取值|含义|
   |:-----------|:-----------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |settingKey|alarmInfo|设置闹钟信息键值。|
   |settingValue|包含以下参数：alarmsList|设置闹钟信息内容。|
   |alarmsList|列表，列表元素包含以下参数：index、enable、time、cycle、name|闹钟信息列表，列表长度需要在[查询闹钟信息](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/query-alarm-info-0000002383970234) 查询的闹钟最大数量范围内。|
   |index|int数据类型|闹钟索引，从1开始。|
   |enable|int数据类型|闹钟是否开启，取值范围\[0,1\]： 0：不使能 1：使能|
   |time|String数据类型|闹钟起闹时间： 长度为4，格式为"HHmm"的24小时制时分字符串。前两个字符代表小时，后两个字符代表分钟，最大为"2359"，最小为"0000"，例："0800"、"2000"|
   |cycle|int数据类型，范围：\[0, 127\]|闹钟循环配置，根据配置项对应的二进制数据控制闹钟循环机制： 0：不循环，仅执行一次 0B0000001:周一 0B0000010:周二 0B0000100:周三 0B0001000:周四 0B0010000:周五 0B0100000:周六 0B1000000:周日 <br /> 如： 5（0B0000101）:表示周一和周三循环； 127（0B1111111）:表示每天循环； 0（0B0000000）:表示仅执行一次|
   |name|String数据类型|闹钟标题，编码格式UTF-8，最大长度24字节。|
   [表1 设置闹钟信息参数]

   ![](https://media:301785133833930284)  
   1、设置的闹钟数量需要在[查询闹钟信息](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/query-alarm-info-0000002383970234)时返回的最大数量范围内，否则设置失败，返回错误码2。

   2、设置的闹钟信息为全量覆盖式，索引信息从1开始计数，不允许跳过某一索引值，否则设置失败，返回错误码2。

   3、设置闹钟信息，除了单独说明的情况下，数字字符串与数字类型等同。

   <br />

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置闹钟信息。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构建用于设置闹钟信息的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("settingKey", "alarmInfo");
       JSONArray array = new JSONArray();
       JSONObject clock = new JSONObject();
       clock.put("index",1);
       clock.put("enable",1);
       clock.put("time","0800");
       clock.put("cycle","15");
       clock.put("name","clockName");
       array.put(clock);
       valueObject.put("alarmsList", array);
       JSONObject valueObject = new JSONObject();
       jsonObject.put("settingValue", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置闹钟信息
   deviceManageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }});
   ```

   |返回值|取值|含义|
   |:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
