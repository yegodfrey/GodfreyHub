# 获取日志路径

获取当前行业SDK日志文件的存储路径。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)的[getIndustryLog](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section16440688163)方法获取日志路径。

   <br />

   ```
   import IndustrySDK

   Task {
       do {
           // 调用getIndustryLog方法获取日志路径
           let logPath = try await IndustryService.getIndustryLog()

           // 获取日志路径成功
           print("Succeeded in getting log path, path: \(logPath)")
       } catch let err as IndustryError {
           // 获取日志路径失败
           print("Failed to get log path. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
