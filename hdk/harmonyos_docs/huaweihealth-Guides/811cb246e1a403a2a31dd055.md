# 订阅短信快捷回复

订阅与取消订阅穿戴设备的短信快捷回复数据。订阅成功后，当穿戴设备收到短信通知时，用户选择快捷回复内容进行短信回复，返回当前短信快捷回复数据。取消订阅后，不再返回短信快捷回复数据。
> 说明
>
> * 接口仅支持具备短信快捷回复功能的行业版本穿戴设备。
> * 使用短信快捷回复功能需要在行业App的AndroidManifest.xml中添加以下权限，并且需要动态申请。
>
>   ```screen
>   <uses-permission android:name="android.permission.READ_SMS"/>
>   <uses-permission android:name="android.permission.SEND_SMS"/>
>   ```
>
> * 当需要调用Android接口来发送短信时，可以参考FAQ中[如何调用系统接口发送短信](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/faq-0000002511427352#section246991918536)。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于订阅或取消订阅短信快捷回复的JSON格式参数。

   ```screen
   {
     "item": "quickReplies"
   }
   ```

4. 调用[subscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__subscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法订阅短信快捷回复。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于订阅短信快捷回复的JSON格式的入参数据 
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "quickReplies");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用subscribe方法订阅短信快捷回复
   manageClient.subscribe(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理订阅返回信息
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:---------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、8、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|订阅成功时返回空字符，订阅失败时返回错误信息，用户点击穿戴设备上的快捷回复内容时返回短信快捷回复数据。|
   [**表1**ServiceCallback返回值]

5. 订阅操作的结果在ServiceCallback的onResult方法中处理。订阅操作成功时返回statusCode为0，result为空字符串；失败时statusCode返回错误码，result返回对应错误信息；用户在穿戴设备上点击快捷回复内容时返回statusCode为8，result数据中包含短信快捷回复数据。

   ```screen
   result样例：
   {
     "subscriptionId": 0,
     "desPhoneNumber": "+8611122223333",
     "replyContent": "ok"
   }
   ```

   |返回值|取值|含义|
   |:-------------|:---------|:-------------------------|
   |subscriptionId|int类型数据|当前接收短信SIM卡的subscriptionId。|
   |desPhoneNumber|String类型数据|短信发送目标号码。|
   |replyContent|String类型数据|回复内容。|
   [**表2**result返回订阅信息]

6. 需要取消订阅时，调用[unSubscribe](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__unSubscribe-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消订阅短信快捷回复。

   ```screen
   // 调用unSubscribe方法取消订阅短信快捷回复。
   // 注意：这里的serviceCallback和步骤4中声明的serviceCallback要为同一个对象，参数jsonObject要和订阅时保持一致
   manageClient.unSubscribe(deviceId, jsonObject.toString(), serviceCallback);
   ```
