# 个人数据处理说明

华为是数据处理者，不是数据控制者，数据使用目的和方式由开发者决定。

此文档针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

* 华为处理的个人数据清单。
* 指导开发者如何帮助最终用户实现对数据的控制。

## 华为处理的个人数据清单

|个人数据|使用目的|存储期|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:------|
|设备信息：可变设备标识符（设备UUID）、设备名称、系统属性（固件版本号）、**MAC地址** 、**SN**、系统设置信息（语言）、设备状态信息（设备佩戴状态、电池电量状态、充电状态）|1. **可变设备标识符（设备UUID）和设备名称用于行业SDK扫描和连接指定设备，同时可变设备标识符（设备UUID）还用于行业SDK实现设备拉距断开连接后自动重连功能和数据上报场景中的设备标识，仅本地存储，解配对后清除。** 2. **其他设备信息和设备状态开放给行业App，本地不存储，也不上云。**|**不涉及**|
|个人基本资料：身高、体重、性别、出生日期、年龄|由APP下发给设备，用于初始化设备，不上云。|不涉及|

|传感器信息：PPG传感器、**陀螺仪传感器数据、加速度传感器数据**|**用于行业APP订阅传感器数据，行业SDK仅透传此类数据，本地不存储，也不上云。**|**不涉及**|

## 指导开发者如何帮助最终用户实现对数据的控制

* 上述个人清单数据中，行业SDK仅本地存储可变设备标识符（UUID）用于设备拉距断开连接后自动重连和数据上报场景的设备标识，解配对后删除。
* 开发者针对数据处理行为应获得最终用户的授权，制定符合适用法律法规的公开声明的隐私政策，根据适用法律法规合法处理最终用户的个人数据，并仅在最低限度的必要期限内留存个人数据。
