# 设置血氧异常告警开关和阈值

设置穿戴设备的血氧异常告警开关状态和告警阈值（单位：%）。开启血氧异常告警开关后，当穿戴设备连续三次检测到血氧值低于告警阈值时，将产生血氧异常的告警。关闭血氧异常告警开关后，穿戴设备将不会产生血氧异常的告警。
> 注意
>
> * 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
> * 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
> 说明
>
> 如果需要启用血氧异常告警，请提前开启血氧自动检测，参见[设置血氧自动检测开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-blood-oxygen-switch-0000002447392133)。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于设置血氧异常告警开关和阈值的ZSON格式的入参数据。

   ```screen
   {
       "settingKey": "bloodOxygenAlarm",
       "settingValue": {
           "switch": 1,
           "threshold": 80
       }
   }
   ```

   |参数|取值|含义|
   |:-----------|:----------------------|:------------------------------|
   |settingKey|bloodOxygenAlarm|血氧异常告警开关和阈值键值。|
   |settingValue|包含以下参数：switch、threshold|血氧异常告警开关和阈值内容。|
   |switch|0|关闭血氧异常告警。|
   |switch|1|开启血氧异常告警。|
   |threshold|整数，取值范围： [75, 90]|可选参数，血氧异常告警阈值，**选择开启告警时此参数必填**。|
   [**表1**设置血氧异常告警开关和阈值参数]

3. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#section447217361429)方法设置血氧异常告警开关和阈值。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于设置血氧异常告警开关和阈值的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       ZSONObject switchAndThreshold = new ZSONObject();
       switchAndThreshold.put("switch", 1);
       switchAndThreshold.put("threshold", 80);
       zsonObject.put("settingKey", "bloodOxygenAlarm");
       zsonObject.put("settingValue", switchAndThreshold);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置血氧异常告警开关和阈值
   manageClient.set(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、4、5、7|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回空字符串，接口调用失败时返回错误信息。|
   [**表2**ServiceCallback返回值]
