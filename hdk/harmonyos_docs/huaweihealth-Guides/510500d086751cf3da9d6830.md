# 查询睡眠状态

查询穿戴设备佩戴者当前睡眠状态。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[queryStatus](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section178854115210)方法查询睡眠状态。

   ```screen
   // 导入相关模块
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的queryStatus方法查询睡眠状态
           let sleepStatus = try await device.queryStatus(type: .sleepStatus)

           // 查询睡眠状态成功
           print("Succeeded in querying sleepStatus, sleepStatus: \(sleepStatus)")
       } catch let err as IndustryError {
           // 查询睡眠状态失败
           print("Failed to query sleepStatus, code: \(err.code), message: \(err.message)")
       }
   }
   ```

   |取值|含义|
   |:-|:--|
   |1|入睡。|
   |2|出睡。|
   [**表1**睡眠状态返回值]
