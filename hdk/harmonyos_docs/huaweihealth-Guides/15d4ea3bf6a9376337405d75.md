# 查询设备支持的音乐规格

穿戴设备并不支持全部的音乐格式，同时也有最大歌曲数量限制，添加音乐到穿戴设备时如果穿戴设备存储空间不足，会添加失败，因此提供查询穿戴设备支持的音乐规格的能力，以便成功地添加穿戴设备支持的音乐。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询设备支持的音乐规格的JSON格式参数。

   <br />

   ```
   {
       "item": "musicSupportSpec"
   }
   ```

   <br />

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询设备支持的音乐规格。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询设备支持的音乐规格的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "musicSupportSpec");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询设备支持的音乐规格
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int resultCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回设备支持的音乐规格，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含设备支持的音乐规格。

   <br />

   ```
   result样例：
   {
       "maxMusicNum":500,
       "musicSupportedFormat":["MP3","WAV","AAC","M4A","FLAC","OPUS"],
       "musicRemainingStorageSpace":1501
   }
   ```

   |返回值|取值|含义|
   |:-------------------------|:-------------|:-------------|
   |maxMusicNum|int类型数据|设备支持的最大音乐数量。|
   |musicSupportedFormat|String\[\]类型数据|设备支持的音乐格式。|
   |musicRemainingStorageSpace|int类型数据|设备剩余存储空间，单位MB。|
   [表2 result返回值]

   <br />
