# 查询微体检报告

穿戴设备提供微体检测量能力。当用户佩戴穿戴设备打开微体检应用完成微体检测量后，行业应用可以通过本接口查询穿戴设备上生成的微体检报告数据。
> 说明
>
> * 此接口仅在支持微体检的穿戴设备上可用。
> * 不支持并发查询微体检报告数据，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询微体检报告数据的JSON格式参数。

   ```screen
   {
     "item": "healthGlanceReport",
     "value": {
       "startTime": 1773126000, // 单位：秒（s）
       "endTime": 1773129600 // 单位：秒（s）
     }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:--------------|
   |startTime|UTC时间戳，单位：秒（s）|查询微体检报告数据的开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询微体检报告数据的结束时间。|
   [**表1**查询微体检报告数据参数]

   > 注意
   >
   > 接口要求查询开始时间和结束时间间隔不超过24小时。

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询微体检报告数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询微体检报告数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject valueObject= new JSONObject();
       valueObject.put("startTime", 1773126000);
       valueObject.put("endTime", 1773129600);
       jsonObject.put("item", "healthGlanceReport");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询微体检报告数据
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回微体检报告数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含微体检报告数据。

   ```screen
   result样例：
   {
     "dataType": "healthGlanceReport",
     "totalCount": 1,
     "index": 0,
     "count": 1,
     "dataList": [
       {
         "startTime": 1773199123,
         "averageHeartRate": 82,
         "hrv": 300,
         "hrvTimestamp": 0,
         "bloodOxygen": 98,
         "bodyTemperature": 33.3,
         "stress": 50,
         "emotionStatus": 100,
         "emotionTimestamp": 0,
         "heartType": 0,
         "heartResult": 1,
         "arrhythmiaTotal": 0,
         "arrhythmiaRule": 0,
         "arrhythmiaAfPrem": 0,
         "arrhythmiaAfAtrial": 0,
         "sleepApneaGrade": 0,
         "sleepApneaTimestamp": 0,
         "systolicPressure": 65535,
         "diastolicPressure": 65535,
         "bpHeartRate": 0
       }
     ]
   }
   ```

   |返回值|取值|含义|
   |:------------------|:-----------------|:---------------------------------------------------------------------------------------------------------|
   |dataType|healthGlanceReport|微体检报告数据类型。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一个数据点在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |startTime|long类型数据|开始时间，单位：秒（s）。|
   |averageHeartRate|int类型数据|平均心率，单位：次/分钟。|
   |hrv|int类型数据|心率变异性，单位：毫秒，取值范围：[0, 300]（300表示无效值）。|
   |hrvTimestamp|long类型数据|心率变异性生成时间戳，单位：秒（s），取值范围：[0, ∞)（默认值为0）。|
   |bloodOxygen|int类型数据|血氧。|
   |bodyTemperature|double类型数据|体温，单位：摄氏度。|
   |skinTemperature|double类型数据|皮肤温度，单位：摄氏度。|
   |stress|int类型数据|压力，取值范围：[0, ∞)。|
   |emotionStatus|int类型数据|情绪状态，取值范围：[0, 100]。 * 1：负面情绪，不愉快 * 2：平静情绪，平和 * 3：积极情绪，愉快 * 100：无效值|
   |emotionTimestamp|long类型数据|情绪生成时间戳，单位：秒（s），取值范围：[0, ∞)（默认值为0）。|
   |heartType|int类型数据|心律类型，取值范围：[0, ∞)。 * 0：心电图 * 1：脉搏波|
   |heartResult|int类型数据|心律结果，取值范围：[0, ∞)。 heartType=0时： * 1：窦性心律 * 2：房性早搏 * 4：室性早搏 * 8：房颤 heartType=1时： * 1：未见异常 * 2：疑似早搏 * 3：疑似房颤|
   |arrhythmiaTotal|int类型数据|脉搏波心律失常总检测项数。|
   |arrhythmiaRule|int类型数据|脉搏波心律失常未见异常数。|
   |arrhythmiaAfPrem|int类型数据|脉搏波心律失常疑似早搏数。|
   |arrhythmiaAfAtrial|int类型数据|脉搏波心律失常疑似房颤数。|
   |sleepApneaGrade|int类型数据|睡眠呼吸暂停检测结果，取值范围：[0, ∞)。 * 1：正常 * 2：疑似低风险 * 3：疑似中风险 * 4：疑似高风险|
   |sleepApneaTimestamp|long类型数据|睡眠呼吸暂停检测时间戳，单位：秒（s），取值范围：[0, ∞)（默认值为0）。|
   |systolicPressure|double类型数据|高压，单位：mmHg，取值范围：[0, ∞)（65535表示无效值）。|
   |diastolicPressure|double类型数据|低压，单位：mmHg，取值范围：[0, ∞)（65535表示无效值）。|
   |bpHeartRate|int类型数据|血压测量中的脉搏，单位：次/分钟。|
   [**表3**result返回值]
