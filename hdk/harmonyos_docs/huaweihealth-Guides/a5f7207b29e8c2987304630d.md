# 查询压力数据

穿戴设备提供压力测量能力，用户佩戴穿戴设备测量压力后，行业App可以通过本接口查询穿戴设备上记录的压力数据。
> 说明
>
> * 此接口仅在支持情绪健康的穿戴设备上可用，当前支持HUAWEI WATCH H9D20和HUAWEI WATCH H3540、HUAWEI WATCH H7556设备。
> * 设备侧收集压力数据要求提前开启压力自动检测开关，查询压力数据前请先确保已调用[设置压力自动检测开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-stress-auto-monitor-switch-0000002417316317)接口打开开关且用户在查询时间段内佩戴穿戴设备至少30分钟。
> * 不支持并发查询压力数据，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询压力数据的JSON格式参数。

   ```screen
   {
     "item": "stressData",
     "value": {
       "startTime": 1725193422, // 单位：秒(s)
       "endTime": 1725452622 // 单位：秒(s)
     }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:-----------|
   |startTime|UTC时间戳，单位：秒（s）|查询压力数据的开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询压力数据的结束时间。|
   [**表1**查询压力数据参数]

   > 说明
   >
   > 接口要求查询开始时间和当前时间间隔不超过7天。

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询压力数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询压力数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject valueObject= new JSONObject();
       valueObject.put("startTime", 1725193422);
       valueObject.put("endTime", 1725452622);
       jsonObject.put("item", "stressData");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询压力数据
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:--------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、7、11、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回压力数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含压力数据。

   ```screen
   data样例:
   {
     "stressData": [
       {
         "stressStartTime": 1680492389,
         "stressEndTime": 1680492445,
         "stressScore": 66,
         "stressGrade": 3
       },
       {
         "stressStartTime": 1680500187,
         "stressEndTime": 1680500244,
         "stressScore": 43,
         "stressGrade": 2
       },
       ...
     ]
   }
   ```

   |返回值|取值|含义|
   |:--------------|:-------|:---------------------------------------------------|
   |stressData|-|压力数据类型。|
   |stressStartTime|long类型数据|开始时间，UTC时间戳，单位：秒。|
   |stressEndTime|long类型数据|结束时间，UTC时间戳，单位：秒。|
   |stressScore|int类型数据|压力得分： * 80-99: 偏高 * 60-79: 中等 * 30-59: 正常 * 1-29: 放松|
   |stressGrade|int类型数据|压力等级： * 1：放松 * 2：正常 * 3：中等 * 4：偏高|
   [**表3**result返回值]
