# 查询体温数据

穿戴设备提供体温测量能力，用户测量体温后，行业应用可以通过本接口查询穿戴设备上记录的最近一次或者历史测量的体温数据。
> 说明
>
> 不支持并发查询体温历史数据，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询体温数据的ZSON格式的入参数据。

   ```screen
   {
       "item": "temperatureData",
       "value": {
           "startTime": 1685341304, // 单位：秒(s)
           "endTime": 1685686904 // 单位：秒(s)
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:--------------|:----------------------------------------|
   |item|temperatureData|查询体温数据的键值。|
   |value(可选)|-|传入value可以查询体温历史测量数据，不传入value表示查询最近一次体温数据。|
   |startTime|UTC时间戳，单位：秒（s）|查询体温数据的开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询体温数据的结束时间。 注意：结束时间与开始时间的跨度需要<=24小时。|
   [**表1**查询体温数据参数]


3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询体温数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询体温数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "temperatureData");
       ZSONObject valueObject= new ZSONObject();
       valueObject.put("startTime", 1685341304);
       valueObject.put("endTime", 1685686904);
       // 可选参数
       zsonObject.put("value", valueObject);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询体温数据
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、6、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回最新一次或者历史（传入查询时间时）测量到的体温数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]


4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含体温、皮肤温度数据。

   ```screen
   查询最近体温数据：
   data样例：
   {
       "bodyTemperature":36.7,
       "skinTemperature":31.8
   }
   ```

   ```screen
   查询体温历史数据：
   data样例：
   {
     "dataType": "temperatureData",
     "totalCount": 2,
     "index": 0,
     "count": 2,
     "dataList": [
       {
         "startTime": 1716195780,
         "bodyTemperature": 37,
         "skinTemperature": 34.6
       },
       {
         ...
       }
     ]
   }
   ```

   |返回值|取值|含义|
   |:--------------|:-------------|:---------------------|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |startTime|UTC时间戳，单位：秒（s）|体温测量时间。|
   |bodyTemperature|float类型数据|体温，单位：℃。|
   |skinTemperature|float类型数据|皮肤温度，单位：℃。|
   [**表3**dataList返回值]
