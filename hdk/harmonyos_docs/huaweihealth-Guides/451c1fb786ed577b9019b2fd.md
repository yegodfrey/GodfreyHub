# 删除设备本地音乐

行业SDK支持删除穿戴设备本地歌曲能力。
> 说明
>
> 对于[智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)需要先打开表侧的音乐应用，同意音乐应用访问存储权限后，才可以删除设备歌曲，否则返回设备音乐未授权错误500（参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)）。对于[轻量级智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li1184517579555)和[智能手环](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li19369195911148)无存储权限限制，可以直接删除设备歌曲。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于删除设备本地音乐的JSON格式参数。

   ```screen
   {
       "item":"deleteDeviceLocalMusic",
       "value": {
           "songIds":[0,1]
       }
   }
   ```

   |参数|取值|含义|
   |:------|:-------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------|
   |item|deleteDeviceLocalMusic|删除设备本地音乐键值。|
   |value|包含以下参数：songIds|删除设备本地音乐内容。|
   |songIds|int[]类型数据，取值为[查询设备本地音乐](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/query-device-local-music-0000002417409613)返回的songId|歌曲Id数组，支持一次删除多首歌曲。注意：一次最多支持删除10首歌曲。超出最大删除数量返回状态码504。|
   [**表1**删除设备本地音乐参数]

4. 调用[send](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__send-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法删除设备本地音乐。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于删除设备本地音乐的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject value = new JSONObject();
       JSONArray jsonArray = new JSONArray();

       // 删除songId为0和1的歌曲
       jsonArray.put(0);
       jsonArray.put(1);
       value.put("songIds", jsonArray);
       jsonObject.put("item", "deleteDeviceLocalMusic");
       jsonObject.put("value", value);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用send方法删除设备本地音乐
   deviceManageClient.send(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int resultCode, String result) {
           // 处理返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、30、500、504|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码和音乐同步状态码。|
   |result|-|接口调用成功时返回空字符串，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

   > 说明
   >
   > 歌曲Id不存在，接口默认删除成功返回状态码0，如果歌曲Id列表中有不存在的歌曲Id，接口依然返回状态码0，会删除存在的歌曲，不存在的歌曲不做处理。
