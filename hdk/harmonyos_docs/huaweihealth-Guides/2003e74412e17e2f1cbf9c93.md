# 睡眠呼吸暂停检测开关设置与查询

设置与查询穿戴设备的睡眠呼吸暂停检测开关状态。开启睡眠呼吸暂停检测开关后，在用户睡眠期间，穿戴设备将进行睡眠呼吸暂停检测。关闭睡眠呼吸暂停检测开关后，穿戴设备不再进行睡眠呼吸暂停检测。  
![](https://media:301785133829905219)  
* 睡眠呼吸暂停功能依赖科学睡眠功能。因此建议在开启睡眠呼吸暂停检测开关前同步开启科学睡眠开关；关闭科学睡眠开关后同步关闭睡眠呼吸暂停检测开关。
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的睡眠呼吸暂停检测开关状态给穿戴设备。  
![](https://media:301785133829932220)  
在穿戴设备未连接运动健康App激活睡眠呼吸暂停功能前，设置和查询睡眠呼吸暂停检测开关返回错误码6。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section988418811913)方法设置睡眠呼吸暂停检测开关状态。

   <br />

   ```
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 睡眠呼吸暂停检测开关状态值
       let value: boolean = true;
       // 调用Device对象的setSettingInfo方法设置睡眠呼吸暂停检测开关状态
       device.setSettingInfo(IndustryService.SettingType.OBSTRUCTIVE_SLEEP_APNEA_DETECTION_SWITCH, value).then(() => {
         // 设置睡眠呼吸暂停检测开关状态成功
         console.info('Succeeded in setting obstructiveSleepApneaDetectionSwitch.');
       }).catch((err: BusinessError) => {
         // 设置睡眠呼吸暂停检测开关状态失败
         console.error(`Failed to set obstructiveSleepApneaDetectionSwitch. Code is ${err.code}, message is ${err.message}.`);
       });
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section15162172713563)方法查询睡眠呼吸暂停检测开关状态。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询睡眠呼吸暂停检测开关状态
   device.getSettingInfo(IndustryService.SettingType.OBSTRUCTIVE_SLEEP_APNEA_DETECTION_SWITCH).then((result: boolean) => {
     // 查询睡眠呼吸暂停检测开关状态成功，打印返回的状态值
     console.info(`Succeeded in getting obstructiveSleepApneaDetectionSwitch, result is ${result}.`);
   }).catch((err: BusinessError) => {
     // 查询睡眠呼吸暂停检测开关状态失败
     console.error(`Failed to get obstructiveSleepApneaDetectionSwitch. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
