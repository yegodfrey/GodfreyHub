# 查询情绪健康数据

穿戴设备提供情绪测量能力，用户佩戴穿戴设备测量情绪后，行业应用可以通过本接口查询穿戴设备上记录的情绪数据。
> 说明
>
> * 此接口仅在支持情绪测量的穿戴设备上可用。
> * 支持情绪测量的设备需要先打开[压力开关](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-stress-auto-monitor-switch-0000002417316317)才能进行情绪测量。
> * 不支持并发查询情绪数据，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询情绪数据的JSON格式参数。

   ```screen
   {
       "item": "emotionData",
       "value": {
           "startTime": 1992342222, // 单位：秒(s)
           "endTime": 1992342229 // 单位：秒(s)
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:-------------|:-----------|
   |startTime|UTC时间戳，单位：秒（s）|查询情绪记录的开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询情绪记录的结束时间。|
   [**表1**查询情绪数据参数]

   > 说明
   > * 查询开始时间和结束时间间隔不超过24小时。
   > * 查询开始时间小于查询结束时间。
   > * 查询结束时间不大于当前时间。
   > * 查询开始时间和当前时间间隔不超过7天（不包含今天）。

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询情绪数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询情绪数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject valueObject= new JSONObject();
       valueObject.put("startTime", 1992342222);
       valueObject.put("endTime", 1992342229);
       jsonObject.put("item", "emotionData");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询情绪数据
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回情绪数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含情绪数据。

   ```screen
   result样例：
   {
     "dataType": "emotionData",
     "totalCount": 1,
     "dataList": [
       {
         "startTime": 1657158420,
         "emotionStatus": 2,
         "valenceCharacter": 59.87324142456055,
         "arousalCharacter": 9.810883522033691,
       }
     ]
   }
   ```

   |返回值|取值|含义|
   |:---------------|:----------|:------------------------------------------------|
   |dataType|emotionData|情绪数据类型。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |startTime|UTC时间，单位：秒|开始时间，单位：秒(s)。|
   |emotionStatus|int类型数据|情绪值： * 1：负面情绪，不愉快 * 2：平静情绪，平和 * 3：积极情绪，愉快|
   |valenceCharacter|double类型数据|效价特征，代表人情绪的效价维度，较低代表情绪偏负面，较高代表情绪偏正面，取值范围：[0,100]。|
   |arousalCharacter|double类型数据|唤醒特征，代表人的生理性激活的水平，越大代表激活程度越高，取值范围：[0,100]。|
   [**表3**result返回值]
