# 取消注册应用与服务的连接状态监听

行业App取消注册应用与Industry SDK服务端的连接状态监听。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getServiceClient-android_content_Context-)方法，获取[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952)对象。
2. 调用[unregisterServiceConnectionListener](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952#ZH-CN_TOPIC_0000002647924358__unregisterServiceConnectionListener-com_huawei_health_industry_client_callback_ServiceCallback-)方法取消注册应用与服务的连接状态监听。

   <br />

   ```
   // 获取ServiceClient 对象
   ServiceClient serviceClient = IndustryWear.getServiceClient(this);

   // 取消注册应用与服务的连接状态监听
   serviceClient.unregisterServiceConnectionListener(new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理连接状态变化信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:--|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、3|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回空字符串，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   ![](https://media:301785133822077113)  
   取消连接状态监听时传入的callback对象需要和进行连接状态监听时传入的callback为同一个对象。
