# 查询设备本地音乐

查询穿戴设备的本地音乐信息，以便在手机上查看和管理穿戴设备本地音乐。
> 说明
>
> * 只支持查询穿戴设备本地已下载的歌曲信息，不支持查询在线歌曲。
> * 对于[智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li165266350557)需要先打开表侧的音乐应用，同意音乐应用访问存储权限后，才可以查询歌曲信息，否则返回设备音乐未授权错误500（参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)）。对于[轻量级智能穿戴设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li1184517579555)和[智能手环](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/supported-devices-0000002510376967#ZH-CN_TOPIC_0000002647924354__li19369195911148)无存储权限限制，可以直接查询歌曲信息。
> * 同一设备不支持并发查询设备本地音乐，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询设备本地音乐信息的JSON格式参数。

   ```screen
   {
       "item": "deviceLocalMusicInfo"
   }
   ```

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询设备本地音乐信息。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询设备本地音乐信息的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "deviceLocalMusicInfo");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询设备本地音乐信息
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int resultCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:--------------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11、30、500|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回设备本地音乐信息，失败时返回错误信息。|
   [**表1**ServiceCallback返回值]

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含设备本地音乐信息。

   ```screen
   result样例：
   {
       "dataType":"deviceLocalMusicInfo",
       "totalCount":2,
       "index":0,
       "count":2,
       "dataList":[
           {
               "songId":0,
               "songName":"Dream It Possible",
               "singerName":"Delacey"
           },
           {
               "songId":1,
               "songName":"Beijing Bass",
               "singerName":"J.R.G."
           }
       ]
   }
   ```

   |返回值|取值|含义|
   |:---------|:--------------------------------|:------------------------|
   |dataType|deviceLocalMusicInfo|设备本地音乐信息类型。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一条数据在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|包含以下字段：songId、songName、singerName|具体数据信息列表，不同数据类型包含不同字段。|
   |songId|int类型数据|设备返回的歌曲Id，歌曲的唯一标识，用于删除歌曲。|
   |songName|String类型数据|设备返回的歌曲名称。|
   |singerName|String类型数据|设备返回的歌手名称。|
   [**表2**result返回值]

   > 说明
   > * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回，不需要开发者再调用查询接口。
   > * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。
