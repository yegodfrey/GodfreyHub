# 情绪/压力自动检测开关设置与查询

设置与查询穿戴设备的情绪/压力自动检测开关状态。开启情绪/压力自动检测开关后，在静止状态下穿戴设备会自动测量压力值、情绪状态及相关特征。关闭情绪/压力自动检测开关后，穿戴设备不会自动测量压力值、情绪状态及相关特征。穿戴设备首次连接后默认关闭情绪/压力自动检测开关。

1. 导入相关模块。
2. 参考[获取已连接设备](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-0000002594269394)章节，获取[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象。
3. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[setMonitorSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section125741385215)方法设置情绪/压力自动检测开关状态。

   <br />

   ```
   import IndustrySDK

   Task {
       do {
           // 获取Device对象
           let device = try IndustryService.getDeviceManager().getDevice()

           // 调用Device对象的setMonitorSwitch方法设置情绪/压力自动检测开关状态        
           try await device.setMonitorSwitch(type: .emotionAutoMeasurementSwitch, monitorSwitchValue: true)

           // 设置情绪/压力自动检测开关状态成功
           print("Succeeded in setting emotionAutoMeasurementSwitch")
       } catch let err as IndustryError {
           // 设置情绪/压力自动检测开关状态失败
           print("Failed to set emotionAutoMeasurementSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section15492171716504)对象的[getMonitorSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section10623588387)方法查询情绪/压力自动检测开关状态。

   <br />

   ```
   Task {
       do {
           // 调用Device对象的getMonitorSwitch方法查询情绪/压力自动检测开关状态
           let switchValue = try await device.getMonitorSwitch(type: .emotionAutoMeasurementSwitch)

           // 查询情绪/压力自动检测开关状态成功
           print("Succeeded in getting emotionAutoMeasurementSwitch, switchValue: \(switchValue)")
       } catch let err as IndustryError {
           // 查询情绪/压力自动检测开关状态失败
           print("Failed to get emotionAutoMeasurementSwitch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

   <br />
