# 定制项要求和约束

各定制项所需元素的要求和约束如下：  

|途径 定制项|VMALL||HEM|||
|途径 定制项|
|----------------|----|----------------|-------|----|-|
|B5/B9/H3/H5/H9系列|手环系列|B5/B9/H3/H5/H9系列|B7/H7系列|手环系列|

![](https://media:301785133808130948)  
字符：汉字、英文字母、数字、符号均为1字符。

开机logo图片规格：

请按照下方图片规格上传bmp格式的图片1张。

请从源头制作输出BMP格式图片。

HEM表盘文件名：仅支持5至32位以内英文、数字、下划线、点。

VMALL表盘文件名：仅支持5至32位以内英文、数字、下划线、点。

HEM开机logo文件名：32位以内中英文、数字、下划线、点。

VMALL开机logo文件名：logo。
