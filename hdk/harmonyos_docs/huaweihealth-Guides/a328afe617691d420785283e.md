# 同步手机通话状态到设备

行业SDK支持同步手机通话状态到穿戴设备，通话状态包括：来电、挂断、接听、去电。
> 说明
>
> 行业App监听系统的来电、挂断、接听、去电状态，然后调用同步手机通话状态接口把通话状态同步到穿戴设备。因此行业App需要动态申请如下权限：
>
> * 访问电话状态权限（android.permission.READ_PHONE_STATE）：行业App申请此权限后，才可调用监听系统来电状态的接口。
> * 访问通话记录权限（android.permission.READ_CALL_LOG）：行业App申请此权限后，监听系统来电状态接口才会返回来电手机号码信息。
> * 访问联系人权限（android.permission.READ_CONTACTS）：行业App申请此权限后，才能根据来电手机号码去通讯录查询来电联系人姓名信息。
> * 去电监听权限（android.permission.PROCESS_OUTGOING_CALLS）：行业App申请此权限后，注册Intent.ACTION_NEW_OUTGOING_CALL广播才可以监听到系统去电状态。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于同步手机通话状态的JSON格式参数。

   ```screen
   {
       "settingKey":"phoneCallInfo",
       "settingValue": {
           "callState": 0,
           "phoneNumber": "18866666666",
           "name": "张三",
           "subscriptionId": 1
       }
   }
   ```

   |参数|取值|含义|
   |:-------------|:-----------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |settingKey|phoneCallInfo|手机通话状态键值。|
   |settingValue|包含以下参数：callState、phoneNumber、name、subscriptionId|手机通话状态内容。|
   |callState|0：来电 1：挂断 2：接听 3：去电|通话状态。|
   |phoneNumber|String类型数据|手机号码，最大长度20个字符，只能包含数字[0-9]、英文括号()、+、-，必须包含一个数字。|
   |name|String类型数据|姓名，最大长度60个字符。|
   |subscriptionId|非必填项，只有当callState为0来电状态时必填，其他状态可以不用填。|当前来电SIM卡的subscriptionId。如何获取请参考FAQ[调用设置来电状态接口中的参数subscriptionId如何获取](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/faq-0000002511427352#section18210143714918)。|
   [**表1**同步手机通话状态参数]

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法同步手机通话状态。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于同步手机通话状态的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject settingValue = new JSONObject();
       settingValue.put("callState", 0);
       settingValue.put("phoneNumber", "18811111111");
       settingValue.put("subscriptionId", 1);
       settingValue.put("name", "张三");
       jsonObject.put("settingKey", "phoneCallInfo");
       jsonObject.put("settingValue", settingValue);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法同步手机通话状态
   deviceManageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int resultCode, String result) {
           // 处理返回信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回空字符串，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]
