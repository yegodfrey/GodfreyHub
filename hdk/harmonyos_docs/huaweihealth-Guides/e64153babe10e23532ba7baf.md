# 日志开关设置和查询

设置与查询行业SDK的日志开关状态。开启日志开关后，SDK的日志会自动写入到本地日志文件中。关闭日志开关后，SDK的日志不会写入到日志文件中。
> 说明
>
> 行业SDK日志开关初始化默认为开。

1. 导入相关模块。
2. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)的[setLogSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section108536311993)方法设置日志开关状态。

   ```screen
   import IndustrySDK

   Task {
       do {
           // 调用setLogSwitch方法设置日志开关状态
           try await IndustryService.setLogSwitch(logSwitchValue: true)

           // 设置日志开关状态成功
           print("Succeeded in setting log switch")
       } catch let err as IndustryError {
           // 设置日志开关状态失败
           print("Failed to set log switch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```

3. 调用[IndustryService](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977)的[getLogSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industry_service_ios-0000002624668977#section137838559133)方法查询日志开关状态。

   ```screen
   Task {
       do {
           // 调用getLogSwitch方法查询日志开关状态
           let switchValue = try await IndustryService.getLogSwitch()

           // 查询日志开关状态成功
           print("Succeeded in getting log switch, switchValue: \(switchValue)")
       } catch let err as IndustryError {
           // 查询日志开关状态失败
           print("Failed to get log switch. Code: \(err.code), message: \(err.message)")
       }
   }
   ```
