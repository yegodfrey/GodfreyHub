# 查询血压数据

穿戴设备提供血压测量能力，用户佩戴穿戴设备测量血压后，行业App可以通过本接口查询穿戴设备上记录的血压数据。
> 说明
>
> * 此接口仅在支持血压测量的穿戴设备上可用，当前支持HUAWEI WATCH B9-D10和HUAWEI WATCH H9D20设备。
> * 此接口可以配合[订阅血压数据更新](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-blood-pressure-update-event-0000002342597334)使用，当订阅的血压数据事件上报有数据更新时，调用此接口查询血压数据。
> * 不支持并发查询血压数据，需等待上一次查询结束后方可进行下一次查询。
> * HUAWEI WATCH B9-D10查询血压数据最多支持返回60条。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询血压数据的JSON格式参数。

   ```screen
   {
       "item": "bloodPressure",
       "value": {
           "startTime": 1992342222, // 单位：秒(s)
           "endTime": 1992342229 // 单位：秒(s)
       }
   }
   ```

   |参数|取值|含义|
   |:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------|
   |startTime|UTC时间戳，单位：秒（s）|查询血压记录的开始时间。|
   |endTime|UTC时间戳，单位：秒（s）|查询血压记录的结束时间。 注意：结束时间与开始时间的跨度需要<=24小时。|
   |subscribeId（可选）|[订阅血压数据更新](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/subscribe-blood-pressure-update-event-0000002342597334)接口返回的订阅ID|订阅ID。|
   [**表1**查询血压数据参数]

   > 说明
   > * 接口要求查询开始时间和结束时间间隔不超过24小时。
   > * subscribeId为可选参数，如果不传入subscribeId字段或者传入的内容为空字符串，按照当前输入的查询时间作为实际查询时间；如果输入有效的subscribeId，会将订阅Id对应的订阅时间（仅包含时、分，例如0900）和当前输入的查询时间取交集，在查询数据时采用交集的时间区间作为实际查询时间，如不存在交集，返回失败。

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询血压数据。

   ```screen
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(this);

   // 参考https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询血压数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject valueObject= new JSONObject();
       valueObject.put("startTime", 1992342222);
       valueObject.put("endTime", 1992342229);
       jsonObject.put("item", "bloodPressure");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询血压数据
   deviceManageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回血压数据，失败时返回错误信息。|
   [**表2**ServiceCallback返回值]

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含血压数据。

   ```screen
   result样例：
   {
     "dataType": "bloodPressure",
     "totalCount": 1,
     "index": 0,
     "count": 1,
     "dataList": [
       {
         "startTime": 1657158434,
         "systolic": 96,
         "diastolic": 62,
         "sphygmus": 65
       }
     ]
   }
   ```

   |返回值|取值|含义|
   |:---------|:------------|:---------------------|
   |dataType|bloodPressure|血压数据类型。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一个数据点在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|-|具体数据信息列表，不同数据类型包含不同字段。|
   |startTime|UTC时间，单位：秒|血压数据生成时间，单位：秒(s)。|
   |systolic|int类型数据|收缩压，单位：mmHg。|
   |diastolic|int类型数据|舒张压，单位：mmHg。|
   |sphygmus|int类型数据|脉搏，单位：bpm。|
   [**表3**result返回值]

   > 说明
   > * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回，不需要开发者再调用查询接口。
   > * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。
