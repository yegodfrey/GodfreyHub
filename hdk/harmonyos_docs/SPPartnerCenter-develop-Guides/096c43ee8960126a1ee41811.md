# 查询Scope权限列表

#### 功能介绍

代商家查询应用Scope权限列表和申请状态。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140046.46722055214943596441965042282860:50001231000000:2800:5704C2F3B94C1DD0F5143246F83A7E7969CFE3069F023B3114D182B05F79A0F0.png)

                * 需要商家完成元服务[权限集的授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-merchant-0000002372696581)。
                * 此章节应用即元服务。

#### 接口原型

**承载协议** | HTTPS GET  
---|---  
**接口方向** | 服务商服务器 -> 华为服务器  
**接口URL** | https://connect-api.cloud.huawei.com/api/tpp/v1/client-scope/list  
**数据格式** | 请求消息：Content-Type: application/json 响应消息：Content-Type: application/json  
  
#### 请求参数

#### [h2]Header

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
client_id | M | String | API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台“开发配置 > 开发资料设置”页面中获取，详情请参见[接口访问凭证（平台访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p0838591506)。  
Authorization | M | String | 认证信息，格式为“Authorization: Bearer ${access_token}”。access_token为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-token-0000002338698720)中获取的access_token。  
appId | M | String | 需要查询的元服务ID  
  
#### [h2]Query

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
publicServiceId | O | String | 服务ID。 当前仅支持“publicServiceId”为“account”。  
sensitiveFlag | O | Integer | 是否敏感权限。 取值范围：
                * 0：公开
                * 1：敏感  
status | O | String | 权限审批状态。 取值范围：
                * SUCCESS：已获取
                * PENDING：待审批
                * REJECTED：不通过
                * NO_APPLY：未申请  
  
#### 请求示例
    
    GET /api/tpp/v1/client-scope/list?publicServiceId=account HTTP/1.1
    Host: connect-api.cloud.huawei.com
    client_id: 414*******68
    Content-Type: application/json
    Authorization: Bearer ******
    appId: 1********57

#### 响应参数

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
ret | M | [ConnectRet](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-publish-connectret-0000002338858596) | 包含返回码及描述信息的结果。  
scopeList | O | List<ScopeItem> | 申请Scope权限提交状态列表。  
  
**ScopeItem**

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
publicServiceId | O | String | 服务ID。 当前仅支持“publicServiceId”为“account”。  
scopeUrl | O | String | Scope权限URL。 当前仅支持“scopeUrl”为“phone”。  
scopePrompt | O | String | Scope权限描述。  
sensitiveFlag | O | Integer | 是否敏感权限。 取值范围：
                * 0：公开
                * 1：敏感  
status | O | String | 权限审批状态。 取值范围：
                * SUCCESS：已获取
                * PENDING：待审批
                * REJECTED：不通过
                * NO_APPLY：未申请  
comment | O | String | 审核驳回意见。  
  
#### 响应示例
    
    {
        "ret": {
            "code": 0,
            "msg": "success"
        },
        "scopeList": [
        {
            "publicServiceId": "account",
            "scopeUrl": "phone",
            "scopePrompt": "usageScenario",
            "sensitiveFlag": 0,
            "status": "SUCCESS",
            "comment": "comment"
        }
      ]
    }
