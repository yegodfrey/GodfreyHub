# 版本更新说明

|版本号|发布时间|更新说明|
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|16.8.1.300|2026-09-10|第三方管理平台体验优化。 1. 新增"代开发流程指引"功能。 具体操作请参见[创建第三方平台](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/create-platform-0000002523075512#ZH-CN_TOPIC_0000002523075512__li19169192274417)。 2. [商家确认授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/confirm-authorization-0000002523235598)时，系统会校验服务商合作计划是否已失效。 3. 对于新增元服务授权，[商家确认授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/confirm-authorization-0000002523235598)时，系统会校验填写的元服务是否与已上架的元服务重名。 4. 部分页面UI效果优化。 具体请参见[发布第三方平台](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/release-platform-0000002554235415)、[添加模板到模板库](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/add-template-to-library-0000002523247958)和[配置平台级域名](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/manage-platform-domain-0000002554247847)。|
|16.4.1.300|2026-05-06|1. 在第三方管理台构建元服务时，新增对appConfig.versionName、appConfig.description、moduleConfig.clientId的校验。 具体请参见[extJson说明](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/extjson-description-0000002554249601)。 2. 第三方管理台的年龄分级复制逻辑优化。发布元服务时，如果元服务中没有"内容分级"信息，将复制模板中的"内容分级"到元服务中，否则将保留元服务中已有信息。|
|16.2.1.300|2026-03-18|在第三方管理台获取的授权链接增加24小时的时效性限制。|
|15.4.2.300|2026-01-27|支持服务商代替商家在华为云进行备案。|
|15.4.1.300|2025/12/2|1. 第三方管理平台权限集新增"应用备案"权限，在[商家确认授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/confirm-authorization-0000002523235598)中支持授予"应用备案"权限。|
|15.3.2.300|2025/10/11|1. 第三方管理平台权限集细化，商家授权服务商后，商家禁用AGC页面操作的软件包管理、提交审核、域名管理功能。 具体禁用的操作请参见[授权后被禁用的AGC界面](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/disabled-age-pages-0000002554289651)。 2. 代调用[华为账号服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/account-kit-0000002523249700)支持获取收货地址的功能。 3. 第三方管理平台支持模板类目管理，增加"模板分类"字段。 具体请参见[上传模板](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/upload-template-0000002554287879)。 4. 第三方管理平台授权功能UI效果优化。 具体请参见[商家确认授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/confirm-authorization-0000002523235598)。|
|15.3.1.300|2025/09/03|第三方管理平台部分页面UI效果优化。|
|15.2.1.300|2025/07/04|首个正式版本发布。|
