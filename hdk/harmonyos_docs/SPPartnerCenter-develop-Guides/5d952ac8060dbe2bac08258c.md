# 业务介绍

服务商申请入驻为HarmonyOS开发服务商后，可以申请凭证授权，以及与商家建立授权关系后，获取商家授权的HarmonyOS应用的代开发和代上架权限，并可以调用API接口进行HarmonyOS应用上架操作。
