# 商家确认授权

服务商获取授权链接提供给商家，商家访问链接完成授权。

## 前提条件

商家已经具备相关资质，如果需要授权服务商代备案，还需要在华为云完成实名认证，具体请参考[商家资质](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/quick-start-0000002523235518#section1133783915417)。

## 确认授权（新增元服务授权）

1. 商家点击服务商提供的授权链接。
2. 用实名认证后的华为帐号登录。 说明
   >
   > 仅团队账号持有者角色才能进行授权操作，请确保登录的账号具备授权权限。
3. 进入授权页面，配置待授权的元服务名称，点击"下一步"。 如果填写的元服务名称与已上架的元服务名称重复，系统会进行提示，建议修改为其他名称。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/scESlMNATPWI-5D9nvXDRQ/zh-cn_image_0000002723233943.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=2B0F9221A98B1E82C9DF64601468340409C9256C02F9A35AC521C3919D22B7D1 "点击放大")

   如果弹出如下所示合作计划已失效的提示，请服务商参考[HarmonyOS开发服务商行为准则](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/sp_partner-huawei_rule-0000002504031168)进行排查，并重新[加入HarmonyOS开发服务商计划](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/sp_partner-hmos_develop_partner_guide-0000002101543573#section99881317111212)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/uKnSMWoSR3WEhRNyVmdBoA/zh-cn_image_0000002693714386.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=85A0C2A0745A21C99ADF775ACB857B8F19174259BB8948D0B20C642E627E2E40)
4. （可选）如果授权集勾选"应用备案"，则务必执行以下步骤，否则将导致服务商代备案异常。
   1. 在打开授权链接的浏览器（推荐谷歌Chrome浏览器）中，打开[华为云备案系统](https://console.huaweicloud.com/beian)。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/UJY3jndiTfqjNaICvp9x6g/zh-cn_image_0000002554245865.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8E5BEBE141DB7F454E86DEB095E79D2FF0547527EE1F5DA76A98A600078D7C5)
   2. 使用委托服务商代备案的账号登录华为云备案系统。
5. 确认授权信息无误，点击"确认授权"。
   * 授予权限集：确认授予勾选的权限，如果勾选"应用备案"，请务必已执行第[4](#ZH-CN_TOPIC_0000002523235598__li1837462145018)步。
   * 关联项目：选择已有项目或者填写项目名称创建新的项目。
   * 协议签署：首次授权需要签署相关协议。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/cjbOX9FcQAG4zjL6Y_YDaQ/zh-cn_image_0000002523245978.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=563AA971D0E003C7A80A46201D3322908E0130AC074E198D32A35C6415FE7E9B "点击放大")
6. （可选）如果授权权限勾选"应用备案"，则会弹出新的提示框。
   * 如果弹出如下所示的提示信息，确认授权的账号准确，点击"授权"完成授权。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/J9kViq7KSKW_uKmnb666fQ/zh-cn_image_0000002554285901.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=C265C5BCA58CAEDAEEFBCD3AC53051C79E01DAFD91C34CE633A7E2AB0C6941BB)

   * 如果弹出如下所示授权按钮无效的提示，请参考FAQ：[商家授权"应用备案"时，弹出页面"授权"按钮无效](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/recordal-faq-0000002523089704#section52626619115)。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/uU1JHxbfTLWvAM-12E7GFg/zh-cn_image_0000002523085964.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB9E75DA4B72E02A68AB7E9FEA6DD97E37350C77EBDF95C7D20CA388A585F5F6)
   * 如果弹出如下所示账号不一致的提示，请使用需要授权代备案的华为云账号重新登录华为云。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8e/v3/JO0AIXbrQ9Gxw177V62KdQ/zh-cn_image_0000002554245867.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=046BD958147408A0DB4007F5C029A1E726A736B5984DA8A6B2B89AE98B885C42)

## 商家查询授权信息

1. 使用授权账号登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)。
2. 选择"用户与访问"。
3. 左侧导航选择"第三方授权管理"，进入"授权管理"页面，选择"应用授权"页签。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/i1GeU7YwSRKy2J9USAeCWg/zh-cn_image_0000002523086606.png?HW-CC-KV=V1&HW-CC-Date=20261008T183452Z&HW-CC-Expire=31536000000&HW-CC-Sign=4BF18678FE26C2344AEBE38B5DEB349C6DFD00605FEAC5B5D2DE8FE57E450061 "点击放大")

4. 点击授权元服务所在行的"查看授权"即可查看完成的授权详情。
