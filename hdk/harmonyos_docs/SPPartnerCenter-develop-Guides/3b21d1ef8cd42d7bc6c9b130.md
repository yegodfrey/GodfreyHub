# 开发元服务模板

模板是服务商开发调试好的元服务样例代码编译后的包，模板的样例代码内是已经编写好了常用业务代码。服务商可通过模板直接重用常用业务代码，批量快速生成元服务。模板能简化开发元服务的成本，并满足商家的部分个性化需求。

服务商可以使用1.0.6版本及以上的ASCF toolkit或者以ASCF开发助手进行开发、编译、构建和打包成.spk包，用于后续上传到第三方平台的行业模板中。

具体开发和调试元服务模板请参见**[元服务兼容版开发指南](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/ascf-cross-atomicservice)** 。

**创建元服务模板的工程时，需要注意如下：**

                * 在创建工程时，Bundle name中需填写第三方平台中的开发元服务包名。
                * 工程构建build-profile.json5中需要设置useNormalizedOHMUrl=true。

**开发元服务模板时，需要注意如下：**

                * 不可使用router，需要使用navigation。因为router也会存在字节码中写入bundlename的情况，所以不可使用。

**元服务模板编译打包时，需要注意如下：**

                * 模板需要使用正常编译出的.spk包，并且为不含服务商release签名的空包。
                * 编译包的apiLevel >= api11。
                * 支持使用Stage模型，不支持使用FA模型。
