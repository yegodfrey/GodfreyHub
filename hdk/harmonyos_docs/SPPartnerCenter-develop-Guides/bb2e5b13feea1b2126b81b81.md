# 获取授权链接

第三方平台审核通过后，即可与商家元服务建立授权关系，获取授权链接的方式有两种：通过页面获取授权链接、通过接口获取授权链接。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.59433813547968750509632748394760:50001231000000:2800:F48D39EC717900402804E3079E0EB2BBA15F85D16D0CF59DF5DCA4C11E06BB33.png)

通过接口获取的授权链接，商家在授权成功后，跳转到服务商设置的指定页面。通过页面获取的授权链接，不支持授权跳转。

#### 通过页面获取授权链接

通过第三方平台详情页左侧的“授权信息”页面，可获取授权链接。

                * **新增元服务授权** ：适用于帮助商家创建元服务并获取元服务授权。服务商向商家获取授权的同时会自动创建元服务对应的项目和应用。
                * **已有元服务授权** ：适用于商家已自行创建元服务并选择元服务进行授权。需要在授权前完成元服务创建，具体请参见[创建项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-project-0000002242804048)和[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-app-0000002235710234)。

#### [h2]新增元服务授权

适用于商家尚未创建元服务的场景。点击“新增元服务授权”右侧的复制按钮可直接获取链接，把授权链接集成到服务商的网站中，供商家打开并授权。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.70489883985300367985574051349319:50001231000000:2800:C332B9EB4FB4E76AACFA124885DCB67B4BB63ED54F03C5AA1EA49AF9B534873F.png)

#### [h2]已有元服务授权

适用于商家已创建了元服务的场景。点击“已有元服务授权”右侧的复制按钮可直接获取链接，把授权链接集成到服务商的网站中，供商家打开并授权。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.90460170408803500024509298597247:50001231000000:2800:43B2B4EACBD406E78615B7CEB63439CD4B7D5BE0438B184882F83D236B9A8231.png)
