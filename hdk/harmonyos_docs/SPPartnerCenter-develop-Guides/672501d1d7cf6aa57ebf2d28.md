# 华为帐号服务

Account Kit（华为账号服务）提供简单、快速、安全的登录功能，让用户快捷地使用华为账号登录元服务。用户授权后，Account Kit可提供头像昵称、手机号码等信息，帮助元服务更了解用户。

## 前提条件

[查看授权信息](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/query-authorization-infor-0000002523075604)，已获取商家"服务集成与开发"的授权。如果没有，则需要[修改第三方平台的权限集](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section109408011447)，重新获取商家授权。

## 开发步骤

1. 为需要使用华为账号服务的元服务[申请相应的权限](https://developer.huawei.com/consumer/cn/doc/atomic-guides/account-guide-atomic-permissions)。
2. [客户端登录华为帐号](https://developer.huawei.com/consumer/cn/doc/atomic-guides/account-atomic-silent-login#客户端开发)获取Authorization Code。
3. 调用[获取用户级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-user-0000001622722589)接口，获取服务商调用华为开发服务的用户级Token。
4. 调用[获取头像昵称](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/account-api-get-user-info-get-nickname-and-avatar)、[获取手机号](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/account-api-get-user-info-get-phone)接口，实现相应的功能。其中接口里传入的access_token为上一步获取的用户级Token中的内容。 说明
   > * 上述接口中传入的access_token为步骤[3](#ZH-CN_TOPIC_0000002523249700__li154531147599)获取用户级Token中的内容。
   > * Access Token有时效性，当失效或者即将失效时，可以调用[刷新用户级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/refresh-token-0000001622974637)接口获取新的Access Token。
5. 如果通过模板批量开发元服务，可以按以下思路实现：
   1. 在模板中参考上述步骤集成华为帐号服务。
   2. 在构建元服务时，extJson参数moduleConfig部分配置代构建元服务的clientId，此clientId的信息可通过[查询授权信息](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/query-authorization-infor-0000002523075604#ZH-CN_TOPIC_0000002523075604__li38012531054)获取。
