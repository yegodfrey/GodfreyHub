# 添加模板到模板库

模板代码上传后，只提交到第三方平台的草稿箱中，草稿箱中的模板还不能算一个正式的模板，不能用于元服务的构建。将草稿箱中的模板添加至模板库，生成模板ID即可成为一个正式模板，后续可使用模板库中的模板ID进行模板管理、元服务构建等操作。

#### 操作步骤

                1. 点击“草稿箱”中对应的元服务兼容版模板后面“操作”列的“添加到模板库”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.56732530791118770334630539450051:50001231000000:2800:9C40218A0C78AC0CD8BA782C66D0D943830247F6EF6A490AC10BD9FC1D916206.png)

                2. 添加成功后，“模板库”列表中新增一条记录，代表该模板已成为一个正式模板。服务商可基于该模板，进行模板管理、元服务构建等操作。
