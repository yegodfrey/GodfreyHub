# 商家管理授权

商家确认授权后，可以对授权进行更新和解除等管理操作。  
![](https://media:201775033410659660)  
调整授权可能会影响服务商的业务操作或授权元服务的正常运行，所以在调整前建议商家与服务商充分沟通。  

#### 更新权限

1. 使用授权账号登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)。
2. 选择"用户与访问"。
3. 左侧导航选择"第三方授权管理"，进入"授权管理"页面，选择"应用授权"页签，点击待更新元服务所在行的"修改授权"。 ![](https://media:201775033410689661 "点击放大")

4. 进入修改授权页，调整授权范围后，点击"确认授权"。 ![](https://media:201775033410719662 "点击放大")

#### 解除授权

1. 使用授权账号登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)。
2. 选择"用户与访问"。
3. 左侧导航选择"第三方授权管理"，进入"授权管理"页面，选择"应用授权"页签，点击待更新元服务所在行的"解除授权"。 ![](https://media:201775033410751663 "点击放大")

4. 在二次确认弹窗中点击"确认"。
