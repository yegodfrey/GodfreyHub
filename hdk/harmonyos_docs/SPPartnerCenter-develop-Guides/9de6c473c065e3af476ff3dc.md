# 商家管理授权

商家确认授权后，可以对授权进行更新和解除等管理操作。
> 注意
>
> 调整授权可能会影响服务商的业务操作或授权元服务的正常运行，所以在调整前建议商家与服务商充分沟通。

## 更新权限

1. 使用授权账号登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)。
2. 选择"用户与访问"。
3. 左侧导航选择"第三方授权管理"，进入"授权管理"页面，选择"应用授权"页签，点击待更新元服务所在行的"修改授权"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9/v3/qjJmHsAXQTqpKT-uEq6g6Q/zh-cn_image_0000002554286607.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=61D711F817B761C9639229ECFCF8805F3610515C0B5519A606CFBE6106750849 "点击放大")

4. 进入修改授权页，调整授权范围后，点击"确认授权"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5d/v3/945sWwKzSRqzitOcR_awVA/zh-cn_image_0000002523086696.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=91C6AC5BD18BBB1DC9722C354508B14334C1BA638C45AD9C2B250F0730368EB3 "点击放大")

## 解除授权

1. 使用授权账号登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)。
2. 选择"用户与访问"。
3. 左侧导航选择"第三方授权管理"，进入"授权管理"页面，选择"应用授权"页签，点击待更新元服务所在行的"解除授权"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b2/v3/KHWTuR-PRPCFpeOjqjP9lQ/zh-cn_image_0000002554246575.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=28172DFBF70604106938B3EAC894A032F805AD31A4A9B3E4B396C770F69B99EB "点击放大")

4. 在二次确认弹窗中点击"确认"。
