# 创建第三方平台

服务商进入第三方管理平台后，需要创建一个第三方平台，用于代商家开发元服务的基础信息管理、行业模板管理以及授权管理等。

#### 前置条件

已参见[如何具备元服务的服务商资质](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-start-0000002338858416#section25311243124210)完成了服务商账号注册、实名认证以及加入服务商计划。

#### 准备材料

                * 平台网站：需要准备可访问的官网网站，创建第三方平台时需要填写官方网站地址，用于用户访问以了解您的业务和功能。
                * 平台图标：平台图标建议使用能够展示品牌信息的图片，仅支持jpg、jpeg和png格式，尺寸要求为256*256像素，不能超过500KB。
                * 消息与事件接收URL：用于接收华为平台推送的消息与事件通知，如授权结果通知、已授权元服务的事件推送等。

#### 进入第三方管理平台

                1. 使用已认证为服务商的华为账号，登录[服务商合作伙伴中心](https://developer.huawei.com/consumer/cn/partner/)网站，通过点击“管理中心”进入服务商管理中心。
                2. 在服务商管理中心左侧出现“第三方管理平台”菜单。点击“第三方管理平台”，即可进入第三方管理平台页面。

#### 创建第三方平台

                1. 首次进入第三方管理平台页面时，点击页面右上角或列表页的“创建第三方平台”，进入创建第三方平台“基本信息”设置页面。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140036.31681788969739422156978299056531:50001231000000:2800:18171FB009C0F3562F17BC263C76750D2FBD32B741C039E5A70DF3763299D9A0.png)

                2. 按照页面提示填写待创建的第三方平台相关信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.60090526460426348470875226039352:50001231000000:2800:8AC8621FFA4EBEA1C1506C9AFC63171B93D25C455D4138722856AA4E50727EA4.png)

                   * 平台名称具有全局唯一性，若名称被占用则需调整成其他名称。
                   * 最多可创建10个第三方平台。
                   * 平台名称、行业标签、平台简介、平台图标、平台网站的信息，创建完毕后续可以修改，修改后重新提交审核即可。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.28512633514942843777681535832813:50001231000000:2800:B3EB91CD565D751D2E8E57B89FE54A6439A86F0626CB118E94996924AECACB88.png)

具体参数说明如下所示：

参数 | 说明  
---|---  
平台名称 | 需在2-20个字符之间，尽量简短，避免使用“华为”、“huawei”、“测试”、“test”等文案。  
平台简介 | 平台简介将显示于商家扫码授权页面，需认真填写，需在5-200个字符之间。  
您的官网 | 请确保用户可以正常访问该网站，并且在官方网站了解您的业务和功能。  
行业标签 | 请至少选择1个标签，最多可选择4个标签。 行业标签包括：生活服务、教育、鞋服运动、出行交通、食品饮料、家具、奢侈品/配饰、美妆、母婴玩具、家电数码、日化、医疗、汽车、金融、体育、房地产、游戏、商场百货。  
平台图标 | 请上传高清图片作为普通图标，要求256*256像素，仅支持jpg、png和jpeg格式，单个文件不能超过500KB。  
  
                3. 点击“下一步”，进入“权限集”列表页面，选择代商家开发元服务的权限集。

具体权限集说明请参考[权限集说明](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-permission-0000002372777101)。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.28023460392007217318056551854216:50001231000000:2800:F48AD2CAF51F0F6121E7DB9BC85243A26219DAE7F1040FE9FCED548A30E47A81.png)

                   * 权限集默认都勾选，“应用基本信息管理”和“应用开发与发布管理”为必选，“服务集成与开发”和“运营管理”为可选。
                   * 选择的权限会展示在商家授权页面上，商家同意后即可建立授权关系。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.44144099909552304126182969028016:50001231000000:2800:3F3A3B008FEC24EA0ECA4D15B90CB77EB190E56D287763850D874DCCEDF1B8B5.png)

                4. 点击“下一步”，进入“开发资料”填写页面。配置如下参数后，点击“保存并创建凭证”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.70413245711650840213053260867506:50001231000000:2800:62C6A6F58A81AC22EAADC6A2E164980F9B3EEBD6543A967929CE0CBB84A9C70E.png)

具体参数说明如下所示： 

参数 | 说明  
---|---  
消息与事件接收URL | 服务商接收消息与事件的URL。用于接收华为平台推送的消息与事件通知，如商家权限变更通知、元服务构建结果通知应用上架审核结果通知等。 如果服务商需要使用华为平台的推送消息与事件通知功能时，则请配置此参数。 华为平台向服务商推送通知的场景包括：
                   * [商家权限变更通知](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-authorization-link-0000002372696625#ZH-CN_TOPIC_0000002372696625__zh-cn_topic_0000002363237513_zh-cn_topic_0000002319876389_p13651938175111)（商家确认授权或取消授权时）
                   * [软件包构建结果通知](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-build-application-0000002372696657#ZH-CN_TOPIC_0000002372696657__zh-cn_topic_0000002329319298_zh-cn_topic_0000002285283888_p157835084015)
                   * [应用上架审核结果通知](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-app-submit-0000002338698824#ZH-CN_TOPIC_0000002338698824__zh-cn_topic_0000002329319286_zh-cn_topic_0000002319923353_p5601932125313)
                   * [应用下架审核结果通知](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-remove-app-0000002372696721#ZH-CN_TOPIC_0000002372696721__zh-cn_topic_0000002329159382_zh-cn_topic_0000002285387062_p128125538531)  
授权回调域名 | 服务商与商家授权成功后，需要回调并重定向到的特定页面的域名。此参数用于授权回调时的检查重定向页面的域名是否与此参数值一致，如果校验不一致，则系统拒绝进行跳转，最终实现避免错误页面的跳转。 如果服务商需要使用华为平台校验授权回调地址时，则请配置此参数。 此参数配置时无需带有http://等协议内容。例如：a.b.com。  
  
                5. 在弹出“应用访问凭据”创建界面，创建并下载凭据文件。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.77462729768719818964611611410724:50001231000000:2800:CD5DD230F894A7A6812C9EF980C7D9859CBAA99E3BF6D2DCDE46022396F46428.png)

                   1. 点击“一键生成公私钥”，可自动生成公私钥。
                   2. 点击“创建并下载凭据文件”，生成“ _xxxxxx_ private.json”格式的凭据文件。

“ _xxxxxx_ private.json”文件中信息可用于调用华为对外开放的API，请妥善保存。后续调用[获取用户级Token](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-token-user-0000002372696617#ZH-CN_TOPIC_0000002372696617__zh-cn_topic_0000002363117633_zh-cn_topic_0000002285387050_p975043213111)接口和[获取应用级Token](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-token-application-0000002338858468#ZH-CN_TOPIC_0000002338858468__zh-cn_topic_0000002363237585_zh-cn_topic_0000002285283928_p975043213111)接口均需要此json凭据文件中信息。

以下参数均为保留参数，供后继支持代商家调用华为开放能力时使用。

参数 | 说明  
---|---

                6. 点击“完成”。创建成功后默认展示该第三方平台详情页面。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.13716309207976047736444151002059:50001231000000:2800:04E242C761FBA8C35C7E2562CCE1D51C0724886CE86AD200457A72E4599B1769.png)

详情页面中的菜单及功能介绍具体如下： 

页面 | 简介  
---|---  
概览 | 展示第三方平台的名称、简介、图标、平台网址以及行业标签信息。创建成功后，概览页显示平台状态为“待提交”，可在该页面继续编辑平台基本信息或直接申请发布。申请发布详情可参见[发布第三方平台](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-release-platform-0000002338858428)。  
开发配置 | 该菜单下包括“权限设置”和“开发资料设置”页面。“权限设置”页面支持查看或修改权限集，“开发资料设置”页面支持创建并下载[接口访问凭证（应用访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p17449134919597)、修改或查看开发配置信息。详情可参见[配置第三方平台](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705)。  
域名配置 | 服务商可以基于第三方平台提供平台级的域名给商家使用，服务商可以代商家为多个已授权的元服务配置域名，以实现一个第三方平台的域名批量给多个元服务复用。详情可参见[管理平台级元服务域名](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-manage_platform_domain-0000002338858452)。  
行业模板管理 | 您可以通过第三方平台可以管理已开发好的元服务模板，上传模板到草稿箱，再将草稿箱的模板添加至模板库。详情可参见[上传元服务模板](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-upload-template-0000002372696597)。  
授权信息 | 第三方平台创建成功后，系统会为其分配元服务授权链接，用于服务商提供给商家访问并确认授权。详情可参见[获取授权链接](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-merchant-0000002372696581)。 商家确认授权后，服务商可在该页面查看已授权元服务的相关信息。详情可参见[查看已授权元服务信息](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-view-authorization-0000002338698692)。  
  
                7. 点击详情页左上角![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140037.87875573967645076889291237905996:50001231000000:2800:F045A6CAE9D13D2CAD6C5AF2DEC48C9FB5C7C9F1A0AC80A12A43C6AB3B761795.png)，可返回到第三方管理平台首页。

在首页列表中可查看新创建的第三方平台信息。
