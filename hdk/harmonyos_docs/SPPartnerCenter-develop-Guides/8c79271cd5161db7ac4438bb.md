# 获取分片上传地址

#### 功能介绍

此接口用于获取文件所有分片的上传地址，调用此接口前必须先调用[分片上传初始化](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-obbfile-init-0000002338698976)接口完成分片初始化。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 服务商服务器 -> 华为服务器  
接口URL | https://connect-api.cloud.huawei.com/api/publish/v2/upload/multipart/parts  
数据格式 | 请求：Content-Type: application/json 响应：Content-Type: application/json  
  
#### 请求参数

#### [h2]Header

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
client_id | M | String | API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台“开发配置 > 开发资料设置”页面中获取，详情请参见[接口访问凭证（平台访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p0838591506)。  
Authorization | M | String | 认证信息，格式为“Authorization: Bearer ${access_token}”。access_token为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-token-0000002338698720)中获取的access_token。  
  
#### [h2]Query

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
objectId | M | String | 对象ID，必须与[分片上传初始化](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-obbfile-init-0000002338698976)时生成的objectId参数一致。  
nspUploadId | M | String | 上传ID，必须与[分片上传初始化](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-obbfile-init-0000002338698976)时生成的nspUploadId参数一致。  
  
#### [h2]Body

请求Body中使用JSON格式携带详细的分片信息，参数如下所示。

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
additionalProp _X_ | M | FilePartInfo | 详细分片信息。其中参数名中的X为分片的编号，从1开始顺序编号，例如additionalProp1、additionalProp2。  
  
**FilePartInfo**

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
sha256 | O | String(64) | 分片文件的sha256值。  
length | M | Integer(64) | 分片文件大小，单位字节，必须与分片的实际大小一致。单个分片最大限制为100MB。  
  
#### 请求示例
    
    POST /api/publish/v2/upload/multipart/parts?objectId=*******&nspUploadId=***** HTTP/1.1
    Host: connect-api.cloud.huawei.com
    client_id: 41******68
    Content-Type: application/json
    Authorization: Bearer ******
    {
        "additionalProp1": {
            "sha256": "",
            "length": 5242880
        },
        "additionalProp2": {
            "sha256": "",
            "length": 3519290
        }
    }

#### 响应参数

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
ret | M | ConnectRet | 包含返回码及描述信息的结果。  
uploadInfoMap | M | HashMap<String, FilePartUploadInfo> | 包含分片地址的Map对象。key为分片的编号（例如“additionalProp1”, “additionalProp2”），value为包含对应分片地址信息的FilePartUploadInfo实体类。  
  
**ConnectRet**

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
code | O | Integer | 返回码，请参见[错误码](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-error-code-information-0000002338858792)。  
msg | O | String | 返回码描述信息。  
  
**FilePartUploadInfo**

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
url | M | String | 分片上传地址。上传地址有效期为4分钟，请在4分钟内调用[上传分片实体](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-obbfile-upload-0000002372776997)接口上传分片。  
method | M | String | 上传分片时需要使用的HTTP请求方式，默认为PUT。  
partObjectId | M | String | 分片对象ID。 有可能为空字符串。  
headers | M | String | 使用分片上传地址上传分片文件时，请求头所需的参数，为JSON结构，格式为：{"Authorization":"***","x-amz-content-sha256":"***","x-amz-date":"***","Host":"***","Content-Type":"***"}。 具体说明请参见[上传分片实体](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-obbfile-upload-0000002372776997)接口。
