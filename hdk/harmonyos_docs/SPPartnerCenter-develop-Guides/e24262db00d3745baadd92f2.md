# 查看授权信息

获取商家授权后，服务商可以在第三方平台查看授权元服务的信息。

1. 进入第三方平台详情页，左侧导航选择"授权信息 > 服务商授权管理"，在"服务商授权管理"页面将展示所有获取授权的元服务列表。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/rqBrqSwbSPqBZgQtWEF8Ig/zh-cn_image_0000002554246759.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=B41AE3CF9FFF84B954C66E6C5906719E303F36C2891DC8FD7C71DD31A6B975BB "点击放大")

2. 点击待查询元服务"已授予的权限集"列的"详情"，可查看服务商获取到的权限集。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/te0BW6BgTiiyDbzwPBKbRQ/zh-cn_image_0000002523086880.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=7C1D265E4F386C4E91BA2DBE96380ACCC748FB4342CA3DE83952A06A06D8F059 "点击放大")

3. 点击待查询元服务"更多"列的"详情"，可查看授权元服务相关信息，这些信息将用于后续接口的调用。
