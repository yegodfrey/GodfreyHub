# 查看授权信息

获取商家授权后，服务商可以在第三方平台查看授权元服务的信息。

1. 进入第三方平台详情页，左侧导航选择"授权信息 > 服务商授权管理"，在"服务商授权管理"页面将展示所有获取授权的元服务列表。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/rqBrqSwbSPqBZgQtWEF8Ig/zh-cn_image_0000002554246759.png?HW-CC-KV=V1&HW-CC-Date=20260929T084032Z&HW-CC-Expire=31536000000&HW-CC-Sign=1A4B79D472B7E0368134F5CC8A8520838873B54369D4ACBCB864B9B739D50E5A "点击放大")

2. 点击待查询元服务"已授予的权限集"列的"详情"，可查看服务商获取到的权限集。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/te0BW6BgTiiyDbzwPBKbRQ/zh-cn_image_0000002523086880.png?HW-CC-KV=V1&HW-CC-Date=20260929T084032Z&HW-CC-Expire=31536000000&HW-CC-Sign=D2FC4936481618290B6A530646CB3700ECB4F6A49F18B8E722892E201AA2E945 "点击放大")

3. 点击待查询元服务"更多"列的"详情"，可查看授权元服务相关信息，这些信息将用于后续接口的调用。
