# 查看授权信息

获取商家授权后，服务商可以在第三方平台查看授权元服务的信息。

1. 进入第三方平台详情页，左侧导航选择"授权信息 \> 服务商授权管理"，在"服务商授权管理"页面将展示所有获取授权的元服务列表。 ![](https://media:201775033410811664 "点击放大")

2. 点击待查询元服务"已授予的权限集"列的"详情"，可查看服务商获取到的权限集。 ![](https://media:201775033410855665 "点击放大")

3. 点击待查询元服务"更多"列的"详情"，可查看授权元服务相关信息，这些信息将用于后续接口的调用。
