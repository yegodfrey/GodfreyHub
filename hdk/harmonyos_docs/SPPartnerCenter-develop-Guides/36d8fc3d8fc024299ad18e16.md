# 概述

**第三方管理平台**，是华为面向元服务服务商提供的为商家提供代开发、代运营服务的开放平台。在获取商家授权后，基于此平台，服务商可以通过使用平台官方接口，为商家基于模板快速开发元服务，为商家在华为云完成备案等全方位服务。

* [代开发元服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/development-use-template-0000002554287877)
  * 商家：仅需授权给服务商，即可委托服务商完成元服务的开发、上架，且过程中随时可以管理权限的授予和解除，更方便、安全。
  * 服务商：基于商家需求，构建一个元服务模板，即可基于此模板批量为商家开发多个元服务，并完成元服务的发布，可有效提升开发效率。
* [代备案元服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/build-recordal-capability-0000002554289647)

  备案是元服务发布应用市场的前提条件之一，当服务商为商家开发完元服务发布时，需要商家先完成备案，此过程双方沟通成本较高。若商家授权服务商代备案，即可有效提升上架的效率。
  * 商家：仅需授权给服务商，即可委托服务商完成元服务在华为云的备案，且过程中随时可以管理权限的授予和解除，更方便、安全。
  * 服务商：使用第三方管理平台开放的接口构建自己的SaaS平台，即可代替商家为授权的元服务在华为云进行备案，以及管理备案整个流程。
