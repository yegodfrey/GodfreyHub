# 添加软件包

#### 功能介绍

此接口用于测试版本上传软件包。

上传软件包之后，需要再调用更新测试版本接口绑定软件包。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 服务商服务器 -> 华为服务器  
接口URL | https://connect-api.cloud.huawei.com/api/publish/v2/test/version/pkg  
数据格式 | 请求：Content-Type: application/json 响应：Content-Type: application/json  
  
#### 请求参数

#### [h2]Header

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
client_id | M | String | API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台“开发配置 > 开发资料设置”页面中获取，详情请参见[接口访问凭证（平台访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p0838591506)。  
Authorization | M | String | 认证信息，格式为“Authorization: Bearer ${access_token}”。access_token为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-token-0000002338698720)中获取的access_token。  
  
#### [h2]Query

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
appId | M | String | 应用ID。  
  
#### [h2]Body

请求Body中使用JSON格式携带需要上传的软件包信息，参数如下表所示。

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
distributeMode | O | Integer(32) | 软件包分发方式。 取值范围：
                * 1：测试专区。
                * 2：应用市场。  
file | M | FileInfo | 文件信息。  
  
**FileInfo**

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
fileName | M | String(255) | 文件名称，包括文件的后缀名。  
objectId | M | String(1024) | 文件在文件服务器中的对象ID。 先调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-upload-url-0000002372776989)接口，然后调用[上传文件](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-upload-file-0000002338858712)接口上传文件，最后得到[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-upload-url-0000002372776989)接口返回的objectId。  
  
#### 请求示例
    
    POST /api/publish/v2/test/version/pkg?appId=10****47 HTTP/1.1 
     Host: connect-api.cloud.huawei.com 
     client_id: 4141******68 
     Content-Type: application/json 
     Authorization: Bearer ******* 
    {
      "distributeMode": 1,
      "file": {
        "fileName": "com.atomicservice.20250730-1-release-20250730.spk",
        "objectId": "CN/2025073007/1753862071000-01a135fa-8d7b-4bec-b035-70cOd25ee95f.spk"
      }
    }

#### 响应参数

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
ret | M | String(100) | 包含返回码及描述信息的JSON字符串，格式为{"code":_retcode_ , "msg": "_description_ "}，retcode为返回码，description为返回码描述信息。返回码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-error-code-information-0000002338858792)。  
pkgVersion | O | String[] | 软件包ID。仅返回一个值。  
  
#### 响应示例
    
    {
         "ret": {
             "code": 0,
             "msg": "success"
         },
         "pkgVersion": ["1426********00"]
    }
