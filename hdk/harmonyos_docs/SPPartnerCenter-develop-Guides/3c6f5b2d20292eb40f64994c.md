# 备案FAQ

## 商家授权"应用备案"时，弹出页面"授权"按钮无效

当商家授权"应用备案"时，如果弹出如下提示框，说明商家授权前没有登录华为云备案系统。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/s-dVC-WLTTmK2SQ6cNCO2g/zh-cn_image_0000002554384691.png?HW-CC-KV=V1&HW-CC-Date=20260929T084032Z&HW-CC-Expire=31536000000&HW-CC-Sign=A1E4B49A17591BA8CEAD58A716DF3224C1968210E25DC39456A570F2F33E64E3)

在授权页面所在浏览器（建议使用谷歌Chrome浏览器），先使用该商家的账号登录[华为云备案系统](https://console.huaweicloud.com/beian)，然后刷新授权页面重新授权。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fb/v3/07bBIedSTSalXbuU9iAyZg/zh-cn_image_0000002523264802.png?HW-CC-KV=V1&HW-CC-Date=20260929T084032Z&HW-CC-Expire=31536000000&HW-CC-Sign=ACC40D10E5B8704DDAD798D47BCADA1089A9C97A9C704F8FABC735EDD4B588B6)

## 商家授权时，提示登录的华为账号与授权的华为云账号不一致

当商家授权"应用备案"时，如果弹出如下提示框，则表示进行授权的华为账号有问题。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/o5SgVKcrRPyZkt3gTHM6lg/zh-cn_image_0000002541658134.png?HW-CC-KV=V1&HW-CC-Date=20260929T084032Z&HW-CC-Expire=31536000000&HW-CC-Sign=88B0FEE66614BF4A6EAFDC13205AB6DEF42EDE03B23EAC81303CEE0D7A6CF594)

出现此问题，请按如下方式进行排查：

1. 检查授权的华为账号是否已经在华为云实名认证。
   * 如果授权的华为账号已经在华为开发者联盟实名认证，那么可以通过[开发者联盟授权认证](https://support.huaweicloud.com/usermanual-account/account_real_cloud0001.html)。
   * 如果授权的华为账号从来没有认证过，则可以前往[华为云实名认证](https://support.huaweicloud.com/usermanual-account/account_auth_00001.html)。
2. 如果已经在华为云实名认证，则检查授权登录的账号是否和登录华为云备案的账号一致。
