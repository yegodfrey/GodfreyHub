# 业务介绍

#### 什么是元服务兼容版

元服务兼容版是ASCF框架基于容器化方式运行提供的能力，支持在即享App或负一屏中运行元服务的兼容模式，使元服务运行在任意版本的HarmonyOS系统上。

由于兼容模式下的元服务采用独立spk（Service package）包格式，所以需要使用1.0.6版本及以上的ASCF toolkit，或者以ASCF开发助手进行开发进行开发、编译、构建和打包。

后续文中提到的**元服务** ，都是元服务兼容版。

#### 什么是模板

**模板** 是服务商开发调试好的元服务代码样例，模板内已经编写好了常用业务代码，并基于已完成的代码样例编译后的包。

针对没有开发能力的商家，服务商基于已开发好的模板，让商家购买合适的模板并授权，服务商通过模板直接重用常用业务代码，批量快速生成元服务。模板能简化开发元服务的成本，并满足商家的部分个性化需求。

#### 什么是第三方管理平台

元服务第三方管理平台，简称**第三方管理平台** ，是华为面向元服务服务商提供、使能服务商为商家提供代开发、代运营的开放平台。**第三方管理平台** 能力覆盖元服务的各生命周期，包括：**第三方平台** 管理、模板管理、商家授权、代开发和代运营等，端到端支撑服务商**通过模板代开发** 的开发模式帮助商家构建元服务。
