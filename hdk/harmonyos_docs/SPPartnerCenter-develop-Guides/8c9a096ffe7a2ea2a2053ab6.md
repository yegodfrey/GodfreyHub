# 商家确认授权

服务商获取授权链接后，将授权链接集成到服务商的网站中，商家通过授权链接完成授权。

#### 确认授权(新增元服务授权)

此场景服务商需要帮助商家创建新的元服务，以及开发元服务。此时无需商家自行创建元服务。

                1. 商家点击服务商提供的授权URL。
                2. 如果商家尚未登录华为账号，请先登录已实名的华为账号。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.09019719810778206479531236270456:50001231000000:2800:690BD92DEE038C8473F783B463474CCC338FA4A0BEBE39AE2B55B958A5E3586D.png)

仅团队账号持有者角色才能进行授权操作，请确保您登录的账号具备授权权限。

如果服务商使用商家账号进行授权调试，请申请与服务商企业主体不同的账号。

                3. 进入授权页面，配置待授权的元服务信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.84485678255555347262365168269336:50001231000000:2800:B9CC03274C1EDCDC81C11591E289F2B6B6211399014F30D368677A7C5582F653.png)

                4. 确认待授权的第三方信息无误。
                5. 填写待授权给第三方的元服务名称，点击“下一步”。
                6. 进入授予权限集页面，勾选所需的权限集，输入此应用关联的项目名称用于自动创建项目或下拉选择已有的项目进行关联，将“相关协议签署”全部勾选后，点击“确认授权”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.67002553822073117957719495611438:50001231000000:2800:F785B227069106207A5F8B5D3AFC896517938E5CD9BF3F4D672B4834A2A1925C.png)

商家在首次授权时，需要签署相关协议。如果商家已经完成过相关协议签署，后续再次授权时，不需要再次签署协议。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.76926202271006160615547023270976:50001231000000:2800:56A8B0F312365FBDD1C04D33648B11D8D6F66A5D3C7D17B15C951E6AA00B72C8.png)

                7. 授权成功后，商家可登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，进入“用户与访问 > 第三方授权管理”页面，点击“应用授权”页签查看元服务的授权信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.78045725259577465881084090223347:50001231000000:2800:7F62877C1115397ED79A9071AF417059D30382050FD0CCC4668303A3761DE941.png)

#### 确认授权(已有元服务授权)

此场景商家已创建元服务，服务商只需要帮助商家开发元服务。

                1. 商家点击服务商提供的授权URL。
                2. 如果商家尚未登录华为账号，请先登录已实名的华为账号。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.85639379740901882522233047796296:50001231000000:2800:A6251BE7B3550112F2DB87DBAE79D6A1549EF9E5B04621EF77A1DE81DDDDB0E0.png)

仅团队账号持有者角色才能进行授权操作，请确保您登录的账号具备授权权限。

                3. 进入授权页面，点击“元服务兼容版”页签，配置待授权的元服务信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.05074769498554146957470788483213:50001231000000:2800:F71FE7E9FEAFCE8441CF515B0DE669CB8745930C0AA53D2F923994CE3D236C19.png)

                4. 确认待授权的第三方平台信息无误。
                5. 选择待授权给第三方平台的元服务，点击“下一步”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.09467804424007444318431955966444:50001231000000:2800:AAE68E92FA60791E89112AFA3FCF91F498651F8F02FFF07368DFCE0F05BF05D8.png)

应用列表中均为可授权的元服务，支持一次选择多个元服务进行批量授权。可按元服务名称进行搜索。

                6. 进入授予权限集页面，勾选所需的权限集后，将“相关协议签署”全部勾选后，点击“确认授权”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.91329252372142712874132485824952:50001231000000:2800:6F98764AB25FFA1A64557E1A3B9312672A00BF554F5807C56F2206F4DA4C1070.png)

商家在首次授权时，需要进行相关协议签署。如果商家已经完成过相关协议签署，后续再次授权时，不需要再次协议签署。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.74666680243902497964994992131153:50001231000000:2800:3E41A7F58CAC8BD9FBB4B103D13CF0781F1BAFA5E09FA36E70237F134CA9EF46.png)

                7. 授权成功后，商家可登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，进入“用户与访问 > 第三方授权管理”页面，点击“应用授权”页签查看元服务的授权信息。
