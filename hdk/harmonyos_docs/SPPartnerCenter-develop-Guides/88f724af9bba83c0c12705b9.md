# 业务概览

#### 什么是服务商

* 服务商是为华为客户或伙伴提供销售或服务的合作伙伴，主要分为生态型服务商和销售型服务商。
* 生态型服务商：主要为开发者和伙伴提供业务、技术和营销等产品和服务，增加华为生态伙伴和产品数量，促进生态繁荣。
* 销售型服务商：主要为华为提供销售代理服务，促进华为生态产品销售、商业变现等。  

#### 什么是服务商计划

* 华为终端云服务商计划是华为终端云推出的旨在建设面向服务商伙伴的身份认证体系，保证服务商伙伴的投入获得相应的回报。
* 服务商加入对应的服务商计划是服务商入驻的必要步骤。只有成功加入服务商计划，签署服务商合作协议，才可以开展后续业务。

#### 服务商账号与服务商计划

* 一个服务商账号，仅可申请一个服务商计划，即一个销售型服务商计划或一个生态型服务商计划；
* 一个服务商账号在加入某个服务商计划后，还可以同时申请入驻生态市场，成为生态市场认证商户，开设卖家店铺，并在店铺内上架您的服务或产品从而促成交易。
