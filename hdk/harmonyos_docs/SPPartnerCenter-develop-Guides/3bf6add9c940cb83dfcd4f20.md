# HarmonyOS开发服务商行为准则

1. 总则 鸿蒙开发服务商应严格遵守鸿蒙应用开发/元服务开发及相关专项规则，以用户价值为核心，秉持"一切以客户（用户）为中心、为客户创造开发好的鸿蒙应用/元服务"的价值观，为用户提供持续价值和高品质的服务。

   <br />

2. 注册与提交规范 联系方式：服务商需提供有效的用户联络方式（如链接或电子邮箱）及平台联络管理员联系方式，并确保联系电话真实有效。

   合法授权：提交的元服务不得关联至服务商无完整合法权益或授权的网站、应用程序、产品或服务。

   审核配合：在审核过程中，服务商应按要求提供材料或进行修改，否则可能影响审核结果。

   <br />

3. 内容与功能规范 内容合规：元服务的名称、图标、介绍等需真实准确，不得包含政治敏感、色情、暴力等非法内容，或侵犯他人知识产权（如商标、肖像权）。

   功能一致性：实际服务内容应与应用/元服务介绍一致，核心功能需在主页展示，且不得隐藏类别或超出平台类目库。

   禁止同质化：功能设计应避免与其他元服务严格同质，不得提供简单重复服务。

   <br />

4. 行为管理 禁止诱导行为：不得通过页面文案、图片、按钮等诱导、强迫、恶意引导用户分享、关注或下载，或利用利益诱惑胁迫用户传播。

   隐私保护：不得主动设置或引导用户隐藏真实身份，否则可能面临功能限制或下架处理。

   营销合规：禁止使用插件、外挂等违规工具，或利用模板消息骚扰用户或进行广告营销。

   禁止分销：禁止通过多级分销欺诈诱导第三方参与，禁止任何传销、非法集资或其他非法经营行为。

   <br />

5. 违规处理 若元服务违反平台规则或法律法规，华为有权采取强制措施，包括限制访问、封禁、删除数据或终止协议，并保留采取必要法律措施的权利。服务商应定期自查，确保运营合规。（详细的违规行为、违规等级和处罚措施见下表。）
