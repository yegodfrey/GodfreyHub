# 申请Scope权限

#### 功能介绍

代商家申请应用的Scope权限。

其中可申请的权限调用[查询Scope权限列表](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-query-permission-0000002372776793)接口查询，即返回**status** 字段值为NO_APPLY的Scope权限。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140045.18138981749110461927723975407590:50001231000000:2800:4507C17C3CEB482371DEAB997A43295404E5BAB0DC192E1C97716C63614FDB03.png)

                * 需要商家完成元服务[权限集的授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-merchant-0000002372696581)。
                * 此章节应用即元服务。

#### 接口原型

**承载协议** | HTTPS POST  
---|---  
**接口方向** | 服务商服务器 -> 华为服务器  
**接口URL** | https://connect-api.cloud.huawei.com/api/tpp/v1/client-scope/apply  
**数据格式** | 请求消息：Content-Type: application/json 响应消息：Content-Type: application/json  
  
#### 请求参数

#### [h2]Header

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
client_id | M | String | API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台“开发配置 > 开发资料设置”页面中获取，详情请参见[接口访问凭证（平台访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p0838591506)。  
Authorization | M | String | 认证信息，格式为“Authorization: Bearer ${access_token}”。access_token为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-token-0000002338698720)中获取的access_token。  
appId | M | String | 需要查询的元服务ID  
  
#### [h2]Body

参数 | 必选(M)/可选(O) | 类型 | 说明  
---|---|---|---  
scopeList | M | List< ApplyScopeInfoV2> | 申请的权限列表。 数组长度不超过20。 当前仅支持华为账号的phone scope权限申请，phone仅支持企业开发者申请。  
  
**ApplyScopeInfoV2**

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
publicServiceId | O | String | 服务ID。 当前仅支持“publicServiceId”为“account”。  
scopeUrl | M | String(255) | 权限URL。 当前仅支持“scopeUrl”为“phone”。  
usageScenario | M | String(512) | 使用场景。 此字段用于描述申请理由，作为权限审批依据。  
fileObjectId | O | String(255) | 附件的objectId。 仅支持png/jpg/jpeg类型文件。文件大小限制5MB。  
tagId | O | Number | 元服务分类标签标识ID。 具体标签ID请参见[分类标签ID和使用目的ID对照表](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-api-class-label-usage-purpose-table-0000002476818316)。 说明： 此字段仅当“scopeUrl”为“phone”时，支持填写此字段，**tagId** 和**purposeId** 字段或者都填写，或者都不填写。  
purposeId | O | Number | 使用目的标识ID。 具体使用目的ID请参见[分类标签ID和使用目的ID对照表](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-api-class-label-usage-purpose-table-0000002476818316)。 说明： 此字段仅当“scopeUrl”为“phone”时，支持填写此字段，**tagId** 和**purposeId** 字段或者都填写，或者都不填写。

#### 响应参数

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
ret | M | [ConnectRet](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-publish-connectret-0000002338858596) | 包含返回码及描述信息的结果。  
applyStatus | O | List<ApplyClientScopeState> | 申请Scope权限提交状态列表。  
  
**ApplyClientScopeState**

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
scopeUrl | O | String(255) | 权限URL。  
usageScenario | O | String(512) | 使用场景。 此字段用于描述申请理由。  
code | O | Integer | 申请状态返回码。 取值范围：
                * 0：表示成功  
msg | O | String | 申请状态描述。  
  
#### 响应示例
    
    {
      "ret": {
        "code": 0,
        "msg": "success"
      },
      "applyStatus": [
        {
          "scopeUrl": "phone",
          "usageScenario": "usageScenario",
          "code": 0,
          "msg": "Success"
        }
      ]
    }
