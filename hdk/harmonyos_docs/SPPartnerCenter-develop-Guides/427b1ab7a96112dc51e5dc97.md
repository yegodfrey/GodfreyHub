# 创建、配置模板关联的元服务

开发完的模板需要在AGC创建一个元服务与之关联，仅需配置上"内容分级"和"隐私声明"的内容，后续基于模板构建元服务时，将自动复制相关内容至元服务，无需重复配置。

1. 使用服务商帐号登录AppGallery Connect，[新建一个元服务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-atomic-service-0000002247795706)。
2. 为此元服务[配置内容分级](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-rating-0000002293651526)。
3. 为此元服务[配置隐私政策](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-policy-atomic-0000002317135133)。  
   ![](https://media:201774944747212529)  
   配置隐私声明"设备权限调用"信息时，请务必保证勾选的权限和模板软件包中实际配置的权限保持一致，否则后续审核将无法通过。
4. 将上步配置的隐私政策[配置到隐私声明](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-atomic-privacy-state-0000002293811150)中。
