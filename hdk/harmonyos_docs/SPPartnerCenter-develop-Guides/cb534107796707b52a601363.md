# 上传元服务模板

使用开发者工具开发与调试好元服务模板的代码后，需将元服务模板打包成.spk文件上传到第三方平台中。元服务模板上传后会提交到第三方平台的草稿箱中，后续需添加至模板库才可以使用。

                1. 进入第三方管理平台，点击行业模板管理页面右侧的“上传行业模板”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.80318980211186751124971104916985:50001231000000:2800:6850B44139355B549A0646521A56D237443D08A948AD46EAEBE63DA2F06C2309.png)

                2. 右侧弹出“上传行业模板”侧滑框，配置如下参数。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140040.91833110068519639529003028061433:50001231000000:2800:F9EB873498260543446A715A3DE1077E899A23590D4CEA5F84F166122FE44891.png)

具体参数说明如下：

参数 | 说明  
---|---  
版本号 | 模板自身的版本号，模板可能存在演进，需要通过版本号来标识。 格式为X.X.X，推荐使用1.0.0作为第一个版本。  
模板类型 | 请选择“元服务兼容版模板”。  
模板分类 | 请选择模板对应的分类。  
描述 | 对模板的详细介绍，说明模板的能力和用途。  
上传模板 | 上传模板包。上传的模板支持.spk格式编码的文件。 说明： “.spk”格式为开发元服务工程打包后的文件。  
  
                3. 点击“上传模板”下方选择框的任意位置，选择本地模板包的文件，点击“确定”，即可上传模板到第三方平台的草稿箱中。
