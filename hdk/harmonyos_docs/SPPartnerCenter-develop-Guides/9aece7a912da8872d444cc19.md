# 获取授权链接

申请凭证授权后，即可与商家建立HarmonyOS应用的授权关系。

使用[申请凭证授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ho_sp-cert_auth-0000001947886657)中获取“API客户端ID”进行授权链接的地址拼接。

授权URL格式：

**https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/authorization?clientId** =1442865090448660864**& type**=1**& devType=1&appId**=123456789**& redirecturl**=https://xxx.com/**& authlist**=saas.app.basicinfo.manage,saas.app.version.manage

此授权URL支持**type** 、**devType** 、**appId** 、**redirecturl** 、**authlist** 参数，具体参数说明如下表所示。

参数 | 参数说明  
---|---  
**type** | 授权URL的场景类型。 取值范围：
                * 0：用于指定商家授权新建应用场景。此场景商家需要先填写应用名称，然后确认授权。
                * 1：用于指定商家授权已有应用场景。此场景商家需要选择已有应用，然后确认确权。
                * 2：用于指定商家更新已有应用授权场景。此场景服务商需在授权URL中追加**appId** 参数以指定需要更新权限的应用，商家只需确认授权。
说明：如果授权URL中不追加任何参数，则**type** 参数默认值为**0** 。  
**devType** | 控制仅元服务的开关参数。
                * 代创建+代开发的授权场景（即**type** 为0）：
                  * **devType** 为1，则展示“是否元服务”的单选框。用于在创建应用默认是元服务的情况下，选择“否”，即创建HarmonyOS应用。
                  * **devType** 不为1，则不展示“是否元服务”的单选框。
                * 代开发的授权场景（即**type** 为1）：
                  * **devType** =1，则仅查询元服务。
                  * 如果不带**devType** 字段，则查询所有类型，即元服务和HarmonyOS应用，此时HarmonyOS应用是不带元服务下标的。
                  * **devType** 不为1，与不带**devType** 字段效果相同。  
**appId** | HarmonyOS应用或元服务对应的appid。  
**redirecturl** | 重定向URL。 此参数用于服务商网站引用商户授权URL后，当商家访问授权URL完成授权后能跳转回服务商网站。 此参数支持前缀配置模式，不在前缀范围内的URL不予跳转。  
**authlist** | 授权的权限集。 此参数用于服务商网站根据代开发服务的类型指定需要商户授权的权限集范围。 多个权限间用英文逗号分隔。 系统处理此字段的逻辑具体如下：
                * **authlist** 字段携带的权限集不能超出工作台设置的权限集范围。
                * 如果授权URL中携带**authlist** 字段，则授权页面呈现的权限集为**authlist** 字段对应的权限集。
                * 如果授权URL中未携带**authlist** 字段，则授权页面呈现的权限集为工作台对应的权限集。
具体权限集的ID可在[申请凭证授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ho_sp-cert_auth-0000001947886657)中获取。  
  
                * 如果获取HarmonyOS应用代创建+代开发的授权链接，则在如下URL中将“API客户端ID”值填入“clientId”字段值位置。

https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/authorization?clientId=_1442865090448660864_ &type=0&devType=1

                * 如果获取HarmonyOS应用代开发的授权链接，则在如下URL中将“API客户端ID”值填入“clientId”字段值位置。

https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/authorization?clientId=_1442865090448660864_ &type=1
