# 鲸鸿动能服务商合作指南

#### 合作咨询

如果您有意愿成为服务商伙伴、寻找服务商伙伴、或在合作过程中有任何意见，可以点击服务商伙伴中心官网各页面【合作咨询】按钮，提交表单或通过公邮向我们反馈，我们将在收到表单/邮件后尽快答复。

#### 入驻条件

若您的企业符合以下条件，即可申请鲸鸿动能服务商：

* 资质：具有广告代理资质。
* 注册资本：100万及以上。
* 成立年限：1年及以上（\*含母公司或控股公司具备广告资质、且成立时间超一年)。
