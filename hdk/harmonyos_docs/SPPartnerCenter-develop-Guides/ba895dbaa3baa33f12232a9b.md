# 商家确认授权  
  
服务商获取授权链接后，将授权链接集成到服务商的网站中，商家通过授权链接完成授权。

#### 确认授权(HarmonyOS应用代创建+代开发)

此场景服务商需要帮助商家创建新的HarmonyOS应用，以及开发HarmonyOS应用。

                1. 商家点击服务商提供的授权URL。
                2. 如果商家尚未登录华为账号，请先登录已实名的华为账号。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.62315933203728637403418628786028:50001231000000:2800:D7B27C153588E2ADF00B112B13F7D9A43C2CB4ADB943AEBCCF0EEEE5EFF5CE5E.png)

仅团队账号持有者角色才能进行授权操作，请确保您登录的账号具备授权权限。

如果服务商使用商家账号进行授权调测，请申请与服务商企业主体不同的账号。

                3. 进入新建应用页面，配置待授权的HarmonyOS应用信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.61524951381544151349395666491686:50001231000000:2800:F62DE70756A4A36C1B07CAC3D0787B135B495740FB63340186DE4ECF22DCDB26.png)

                4. 确认待授权的服务商信息无误。
                5. 填写待授权给服务商的HarmonyOS应用名称，点击“下一步”。
                6. 进入授权权限页面，勾选相应授予服务商的权限集后，点击“确认授权”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.81931271266030560237553022244724:50001231000000:2800:A58B5F1A9C1EDBEBA898F328C0B04958CFDDA2D09EFE6F6F2905DF2F214B3E9F.png)

                7. 在AGC查看已授权HarmonyOS应用的状态。

进入“我的应用”页面，可在“HarmonyOS”页签查看已授权的HarmonyOS应用。已授权HarmonyOS应用将置灰显示并标注“已授权”，商家只可进行查看，无法再进行其他任意操作。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.28503790044788914322928987367570:50001231000000:2800:42849398D90DC3EB68620F847F4902F941021C119F63AAD4E1E5745232346D63.png)

#### 确认授权(HarmonyOS应用代开发)

此场景商家已创建HarmonyOS应用，服务商只需要帮助商家开发HarmonyOS应用。

                1. 商家点击服务商提供的授权URL。
                2. 如果商家尚未登录华为账号，请先登录已实名的华为账号。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.55409186557978969731880105436702:50001231000000:2800:C85AFED3179BFDB3ED77F4D97CC17673FB322BC1F09C1ECF763491DAE7F27C20.png)

仅团队账号持有者角色才能进行授权操作，请确保您登录的账号具备授权权限。

                3. 进入授权应用页面，配置待授权的HarmonyOS应用信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.68639771974994964642833855557492:50001231000000:2800:B612A1E2DF32D976FD847D27D313291682BDF5078A2D1B27D30F7F0DDBC1EDFD.png)

                4. 确认待授权的服务商信息无误。
                5. 选择待授权给服务商的HarmonyOS应用，点击“下一步”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.91313845255466108799584004523250:50001231000000:2800:103D6FAC9C1C4FFEBBFD0804B85E24E902D0275EF2E3D3352DD3790C7AE1079D.png)

应用列表中均为可授权的HarmonyOS应用，一次只可选择一个HarmonyOS应用。可按HarmonyOS应用名称进行搜索。

                6. 进入授权权限页面，勾选相应授予服务商的权限集后，点击“确认授权”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.45968891374573850259891073890989:50001231000000:2800:8778D379EAFD69263AF8208D6FE0986E1437E423BCC4235173092748482204B3.png)

                7. 在AGC查看已授权HarmonyOS应用的状态。

进入“我的应用”页面，可在“HarmonyOS”页签查看已授权的HarmonyOS应用。已授权HarmonyOS应用将置灰显示并标注“已授权”，商家只可进行查看，无法再进行其他任意操作。
