# 获取开发配置信息

## 权限集

在向商家获取权限前，可以确认设置的权限是否准确，获取相应的授权才能保证后续工作顺利进行。

1. 在第三方平台首页的列表中，点击查看第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/n9dzHr4WRvKesq7tfd_SWQ/zh-cn_image_0000002523244936.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C8581398908856F3CCBFC383091A122FDCAC3C8432B7E8E40A530939A47D87F "点击放大")

2. 左侧导航选择"开发配置 > 权限设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/4ufnwyUTRH-Vk7BLu916EQ/zh-cn_image_0000002723353819.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=2F32159E917AC62550495A41D8D1288E304E3D558BAAB60CEE1332CDE35569F2)

3. 进入"权限设置"页面。该页面展示已设置的权限集，如果需要调整，在此页面修改后点击"保存"即可。 注意
   >
   > 一旦修改了权限，请务必重新[获取授权链接](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-authorization-link-0000002523075602)，并让[商家确认授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/confirm-authorization-0000002523235598)，否则更新的权限将不会生效。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/3MxvNQ2sR6W4LGaj5XG3ow/zh-cn_image_0000002523084944.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=83F485D72C8FF0B8E38906739BFE990F363B2AB5D8D570E4D58E034F243A392B "点击放大")

## 平台访问凭据

该凭据信息在后续使用第三方平台接口时，用于获取接口鉴权的Token。

1. 在第三方平台首页的列表中，点击查看第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/Imhx06VsTKy6V3xCwrunbg/zh-cn_image_0000002554284867.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=4711EEF05949CA8EF9884DCB7E0756E5EB6E793538A158EDEC3D0DD0F603750C "点击放大")

2. 左侧导航选择"开发配置 > 开发资料设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/F-IZje2WTnWNfIJsTpjS-w/zh-cn_image_0000002693714356.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=9918881B4B68785BDE3B1758572FE378FF35E150D2803AE7A94B88BCED2B0EEB)

3. 进入"开发资料设置"页面，获取"API客户端ID"和"API客户端密钥"。 此凭证在创建第三方平台时自动生成，不支持修改。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/m2TyysZoR8CINcfhM5zN6g/zh-cn_image_0000002706776069.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=AD40E24201978809CE5F3410E955770A19820A933E94097F944E7B34EB46D39C "点击放大")

## 消息与事件接收信息

在某些业务场景，例如商家权限变更、应用上架、下架，华为平台会向服务商推送通知，如果需要接收通知，需要配置获取相关信息。

1. 在第三方平台首页的列表中，点击查看第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/ssz8JUahSGK0f5nZHgEG9A/zh-cn_image_0000002532467016.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=0827209A4A17D1D7A18625341FCA5E670DBFE06FB179904C08E9391E9CE192ED "点击放大")

2. 左侧导航选择"开发配置 > 开发资料设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/e6Pe33b8RVCPngOmhDQc_A/zh-cn_image_0000002723233907.png?HW-CC-KV=V1&HW-CC-Date=20261008T180729Z&HW-CC-Expire=31536000000&HW-CC-Sign=7DBEF4B45884DF9BFF259EA57C7D79E6F5B3F2D9214BE5C8A401C4B9C9102D13)

3. 进入"开发资料设置"页面，获取配置的相关信息。
   * 消息与事件接收URL：服务商接收消息与事件的URL
   * 消息验证公钥：接收华为平台推送的消息时，用于校验签名。
