# 获取开发配置信息

#### 权限集

在向商家获取权限前，可以确认设置的权限是否准确，获取相应的授权才能保证后续工作顺利进行。

1. 在第三方平台首页的列表中，点击查看第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://media:201775033408985621 "点击放大")

2. 左侧导航选择"开发配置 \> 权限设置"。 ![](https://media:201775033409013622 "点击放大")

3. 进入"权限设置"页面。该页面展示已设置的权限集，如果需要调整，在此页面修改后点击"保存"即可。  
   ![](https://media:201775033409039623)  
   一旦修改了权限，请务必重新[获取授权链接](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-authorization-link-0000002523075602)，并让[商家确认授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/confirm-authorization-0000002523235598)，否则更新的权限将不会生效。

![](https://media:201775033409077624 "点击放大")  

#### 平台访问凭据

该凭据信息在后续使用第三方平台接口时，用于获取接口鉴权的Token。

1. 在第三方平台首页的列表中，点击查看第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://media:201775033409119625 "点击放大")

2. 左侧导航选择"开发配置 \> 开发资料设置"。 ![](https://media:201775033409159626 "点击放大")

3. 进入"开发资料设置"页面，获取"API客户端ID"和"API客户端密钥"。 此凭证在创建第三方平台时自动生成，不支持修改。

![](https://media:201775033409207627 "点击放大")  

#### 应用访问凭据

该凭据信息在后续使用华为开放能力提供的接口时，用于获取相应的Access Token。

1. 在第三方平台首页的列表中，点击查看第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://media:201775033409241628 "点击放大")

2. 左侧导航选择"开发配置 \> 开发资料设置"。 ![](https://media:201775033409268629 "点击放大")

3. 进入"开发资料设置"页面，获取应用访问凭据信息。 此信息来自创建第三方平台时生成的凭据文件（即下载的"xxxxxxprivate.json"文件）。如果创建时没有下载或丢失了此文件，可以[4](#ZH-CN_TOPIC_0000002523235520__li02581363113)。

   ![](https://media:201775033409331630 "点击放大")
4. （可选）重新生成并下载凭据文件。
   1. 点击区域右侧的"管理"。 ![](https://media:201775033409429631 "点击放大")

   2. 在跳转的"凭证管理"页面中筛选框中选择对应第三方平台名称，点击"创建凭证"。 ![](https://media:201775033409462632 "点击放大")

   3. "操作类型"选择对应的第三方平台，点击"生成公私钥"，系统自动生成公钥后，点击"添加并下载JSON"。 ![](https://media:201775033409494633 "点击放大")

#### 消息与事件接收信息

在某些业务场景，例如商家权限变更、应用上架、下架，华为平台会向服务商推送通知，如果需要接收通知，需要配置获取相关信息。

1. 在第三方平台首页的列表中，点击查看第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://media:201775033409525634 "点击放大")

2. 左侧导航选择"开发配置 \> 开发资料设置"。 ![](https://media:201775033409554635 "点击放大")

3. 进入"开发资料设置"页面，获取配置的相关信息。
   * 消息与事件接收URL：服务商接收消息与事件的URL
   * 消息验证公钥：接收华为平台推送的消息时，用于校验签名。

![](https://media:201775033409590636 "点击放大")
