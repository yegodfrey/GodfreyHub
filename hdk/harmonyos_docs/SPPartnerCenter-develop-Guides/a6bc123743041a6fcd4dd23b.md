# 权限集说明

|scope|权限集描述|是否默认开通|说明|
|:------------------------|:--------|:-----|:-----------------------------------------------------------------------------|
|saas.app.basicinfo.manage|应用基本信息管理|是|基于该权限可对应用进行基本应用信息管理。|
|saas.app.version.manage|应用开发与发布管理|是|基于该权限可对应用进行开发配置管理，以及提交代码编译、测试、提审、发布操作。|
|saas.app.dev|服务集成与开发|否|基于该权限可访问元服务所属项目，启用、集成华为账号、PUSH、Serverless等多种开放能力并进行相关配置管理、功能开发，用于构建、支撑元服务各种能力。|
|saas.app.operation|运营管理|否|基于该权限可申请获取元服务的用户信息（如头像、昵称、手机号码等）用于元服务运营管理。|
|saas.app.icp.manage|应用备案|否|基于该权限可代商家发起备案全流程，包括提交、撤回、取消、修改等，快速便捷对备案全生命周期进行操作。|
