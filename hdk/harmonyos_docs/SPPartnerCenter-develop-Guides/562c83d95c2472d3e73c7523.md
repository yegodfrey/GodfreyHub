# 测试、发布元服务

> 说明
>
> 基于HarmonyOS可以开发**HarmonyOS** **应用** 和**元服务** ，但是第三方平台当前仅支持代开发元服务，所以下文中接口提到应用**仅指代元服务**。

## 配置元服务域名

在提交测试、发布元服务前，需要完成元服务域名的配置，否则将影响测试版本和发布版本的审核。

### 前提条件

在第三方平台完成[平台级域名的配置](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/manage-platform-domain-0000002554247847)。

### 开发步骤

1. （可选）如果配置元服务业务域名，需要执行以下步骤将业务域名的配置文件部署到域名服务器中。配置服务器域名，则跳过此步骤，执行[2](#ZH-CN_TOPIC_0000002554287881__li12610156164217)。
   1. 调用[下载域名配置文件](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/download-domain-config-file-0000002057667017)接口，下载配置文件。

      如果元服务的APP ID为"6917****37162267256"，则下载的域名配置文件文件为"6917****37162267256.txt"。
   2. 将下载的本地配置文件放置到域名根目录下，例如"test.com.cn/6917****37162267256.txt"，并确保可以成功访问该配置文件。
2. 调用[更新元服务的平台级域名配置](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/update_fa_platform_domain-0000002260116342)接口，配置元服务的域名信息。 注意
   >
   > 为元服务配置域名类别可以小于或者等于第三方平台配置的类别，但同一类别配置的值必须保持一致，否则配置将产生异常。
   >
   > 例如：第三方平台配置了"httpRequest服务器域名"和"webSocket服务器域名"，那么元服务可以配置"httpRequest服务器域名"和"webSocket服务器域名"，也可以只配置"httpRequest服务器域名"或者"webSocket服务器域名"，但是给"httpRequest服务器域名"或者"webSocket服务器域名"配置的值必须和第三方平台的保持一致。
   >
   > 第三方平台配置的域名信息可调用[查询第三方平台的平台级域名信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/query_platform_domain-0000002294613381)接口获取。
3. （可选）调用[查询元服务的平台级域名信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/query_fa_platform_domain-0000002294686425)接口查询是否配置准确。

## 测试元服务

构建出的元服务包服务商无法安装到设备中进行测试体验，建议通过邀请测试选择特定用户群组提前使用版本，以便提前发现问题，及时修复和优化版本体验。

### 前提条件

完成[元服务的域名配置](#section1562792813217)。

### 开发步骤

1. 调用[新建测试版本](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/add-test-version-0000002057706045)接口，创建元服务的测试版本，获取versionId。
2. 调用[添加软件包](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/add-test-package-0000002057667005)接口，上传进行测试的软件包，objectId为调用[查询构建任务状态](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-task-status-0000001552137517)接口获取的编译成功的软件包ID。
3. 调用[查询软件包编译状态](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/query-appfile-states-0000002057702509)接口，确保上传的测试包编译成功，再进行后续操作。
4. （可选）如果进行邀请测试，则进行如下操作。
   1. 调用[新增测试群组](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/add-test-group-0000002057663449)接口，创建受邀参与测试的用户群组；
   2. 调用[生成邀请码](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/add-invitation-code-0000002058783721)接口生邀请码。
5. 调用[更新测试版本](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/modify-test-version-0000002021706726)接口将测试版本信息填入，调用[提交测试版本](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/submit-test-version-0000002057706085)接口，等待测试版本审核。
6. 测试版本审核通过后，即可对测试版本进行测试。
   * 公开测试：全网用户可前往"应用市场"的"我的 > 应用尝鲜"去查看测试版本。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2/v3/rlKp1jOGTkOSib8ICaaGNw/zh-cn_image_0000002658575532.png?HW-CC-KV=V1&HW-CC-Date=20260929T084032Z&HW-CC-Expire=31536000000&HW-CC-Sign=8B828C57A178A8227F0A5778B5C527534DD71385E636467F6E4E7686E7DC7A5B)

   * 邀请测试：被邀请测试的用户通过测试链接参与测试。
     1. 调用[查询应用信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-query-0000002130941805)接口，通过返回的shareLink获取分享链接。
     2. 调用[查询测试组邀请码](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-invitation-code-0000002021544950)接口，获取生效中的邀请码。
     3. 拼出邀请测试链接发给被邀请人参与测试，链接格式为：分享链接&invitationCode=邀请码。
7. （可选）在测试阶段，可调用[更新有效期内的测试版本信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/update-test-version-opentest-0000002110043670)接口调整测试的开始、结束时间。
8. 测试完成，调用[停止测试版本](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/stop-test-version-0000002021706766)接口，停止测试，并调用[删除测试版本](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/delete-test-version-0000002021548486)接口，删除已停止的测试版本。

## 发布元服务

版本测试没有问题，即可提交发布审核，审核通过后，元服务就发布成功了。

### 前提条件

完成[元服务的域名配置](#section1562792813217)。

### 开发步骤

1. 设置元服务图标。可使用DevEco Studio[生成元服务图标](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-service-icon-generation)，图标格式为PNG，大小为500K以内，分辨率为216*216。
   1. 调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-upload-url-0000002057702505)接口，然后调用[上传文件](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/upload-file-0000002095222766)接口上传元服务图标。
   2. 调用[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-file-info-update-0000002021703174)接口，将图标关联到对应的元服务。
2. 调用[更新应用语言信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/language-info-update-0000002057663433)接口，配置元服务语言、名称等信息。
3. 调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-update-0000002021703170)接口，配置版本发布所需其他信息。
4. 调用[提交发布](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-submit-0000002021703178)接口，发布元服务。 说明
   >
   > 此时会复制模板元服务中配置的"隐私声明"到元服务中。如果元服务中没有"内容分级"信息，将同时复制模板中的"内容分级"到元服务中，否则将保留元服务中已有信息。
5. （可选）如果提交发布后，发现版本有问题，可调用[撤销审核](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/on-shelf-cancel-0000002521750541)接口，取消提交的发布申请。
6. （可选）如果发布时选择"指定时间发布"，当版本处于"待上架"状态时，可调用[更新版本上架时间](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/update-releasetime-0000002021544938)接口修改发布时间，或者改成立刻发布。
7. （可选）如果提交发布因为资质被驳回，可调用[删除资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/delete-qualification-review-task-0000002557760669)接口，删除不符合资质要求的标签，修改后调用[提交资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/post-tag-qual-dependent-0000002152513894)重新提交删除标签的审核。
