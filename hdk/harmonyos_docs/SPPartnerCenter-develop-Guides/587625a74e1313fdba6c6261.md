# 查看已授权元服务信息

商家确认授权后，服务商可在第三方平台查看已授权元服务的信息。

                1. 在第三方平台详情页面，点击左侧“授权信息”菜单。
                2. 商家授权后，相关授权信息展示在授权信息列表页中。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140044.25306962163039902584556813982800:50001231000000:2800:13800C549AD368E28CFAB64905FE7C008D9E5A8CE86BF7C3EECCB043BE2131E2.png)

                3. 点击“已授权的权限集”列中的“详情”，可查看商家已授权的权限集情况；点击“更多”列中的“详情”，可查看更多商家信息。

详情中可以查看到此元服务对应的商家开发者ID，以及应用包名、App ID和ClientID的信息。
