# 新增应用的域名配置信息

#### 功能介绍

此接口用于新增应用的域名配置信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140046.94357110304059545535803767763361:50001231000000:2800:BF379888DAC9C6232528D4B8E8DD636D7DC62CD9DC03F52BC5B738A6480ECA7E.png)

新增超过10个业务域名时，建议先调用[预检查业务域名配置](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-post-domain-precheck-0000002338699032)接口确认是否可以新增成功。

#### 服务器域名配置约束与限制

                * 同一个元服务每个自然月服务器域名修改次数，默认为50次。
                * 单项服务器域名配置数量最多不超过200个。
                * 域名只支持HTTPS和WSS协议。
                * 域名不能使用IP地址或localhost。
                * 不可配置全局禁止清单内的域名。

#### 业务域名配置约束与限制

                * 同一个元服务每个自然月业务域名修改次数，默认为50次。
                * 同一个APPID下，最多支持配置100个业务域名；同一个业务域名最多可配置100个APPID。
                * 域名只支持HTTPS协议。
                * 域名不能使用IP地址或localhost。
                * 网页内iframe的域名也需要配置。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 服务商服务器 -> 华为服务器  
接口URL | https://connect-api.cloud.huawei.com/api/dms/domain-manage/v1/app/domain  
数据格式 | 请求：Content-Type: application/json 响应：Content-Type: application/json  
  
#### 请求参数

#### [h2]Header

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
client_id | M | String | API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台“开发配置 > 开发资料设置”页面中获取，详情请参见[接口访问凭证（平台访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p0838591506)。  
Authorization | M | String | 认证信息，格式为“Authorization: Bearer ${access_token}”。access_token为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-get-token-0000002338698720)中获取的access_token。  
appId | M | String(32) | 应用ID。  
  
#### [h2]Query

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
category | M | String(32) | 域名分类。 取值范围：
                * server：服务器域名
                * business：业务域名  
  
#### [h2]Body

请求Body中使用JSON格式携带域名信息，参数如下表所示。

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
domains | O | List<[DomainInfo](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-domianapi-domaininfo2-0000002372696933)> | 域名全量数据。 集合长度最大3000。  
  
#### 请求示例
    
    POST /api/dms/domain-manage/v1/app/domain?category=server HTTP/1.1 
     Host: connect-api.cloud.huawei.com 
     client_id: 4141******68 
     Content-Type: application/json 
     Authorization: Bearer *******
     appId: 10******57
     {
      "domains": [
        {
          "type": "httpRequest",
          "value": "https://huawei.com:8080"
        }
      ]
    }

#### 响应参数

参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
ret | M | [ConnectRet](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-domianapi-connectret-0000002338858776) | 包含返回码及描述信息的结果。  
invalidDomains | O | List<[DomainInfo](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-domianapi-domaininfo-0000002338699040)> | 不合法的域名列表。 当ret不为成功的时候存在。

        "code": 0,

      },

        {

          "value": "https://huawei.com:8080",

          "errorMsg": "string"
        }
      ]
    }
