# resource_ext.zip配置说明

#### resource_ext.zip定义

resource_ext.zip是一个资源替换包，用于替换resource下的资源文件，覆盖OS定义的所有分类类型。

#### resource_ext.zip包格式说明

                * 整体按照zip格式压缩。
                * zip内部目录格式定义如下：
                  * ascf-resource：与开发态的ascf_src目录结构一致，遍历所有HAP和HSP的rawfile目录，替换同目录同名文件资源。源码类文件（例如css、html、js、ts等后缀文件）以及manifest.json文件不支持替换。
                  * 实际工程中资源目录结构是什么，resource_ext.zip资源替换包就是什么结构，如下图所示。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140045.56097439434390974091538408166450:50001231000000:2800:86172D604959D50179FBF2FCEF66E274A6467156695FCEF574BF3E7B5AD0EF9A.png)

对应此图，resource_ext.zip包中应该会有“ascf-resource”文件夹，文件夹中的结构与工程中是一致的。

                * 目录内部为具体的资源组文件，同OS定义格式一致。

#### resource下的资源文件替换能力说明

                * 资源不允许新增或删除，仅允许替换。
                * 支持限定词。
                * 仅支持一个目录叠加。
                * 支持rawfile。
