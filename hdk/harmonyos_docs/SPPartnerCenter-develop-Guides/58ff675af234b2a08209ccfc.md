# （可选）管理授权链接

为了保证授权链接的安全性，服务商提供给商家的授权链接具有24小时的有效期，服务商可以查看有效的授权链接，也可以授权后提前将授权链接失效。

1. 进入第三方平台详情页，左侧导航选择"授权信息 > 授权链接管理"。
2. 在"授权链接管理"页面，将展示所有有效状态的授权链接，以及当天失效的链接。
   * 点击待管理链接所在行的"复制"，可以快速复制链接，以便提供给商家进行授权。
   * 点击待管理链接所在行的"失效"，可以在有效期结束前，将链接失效。
