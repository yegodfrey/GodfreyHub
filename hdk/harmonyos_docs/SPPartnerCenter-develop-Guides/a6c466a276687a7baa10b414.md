# FAQ

#### 元服务上架常见问题

针对元服务上架问题，请参考[元服务审核FAQ](https://developer.huawei.com/consumer/cn/doc/app/50150)。

#### 您的应用因缺少资质证明文件未通过审核

请联系华为运营人员申请处理，可以通过[客服沟通渠道](https://developer.huawei.com/consumer/cn/doc/app/50000-1)联系。

#### 您在AppGallery Connect上提交的隐私政策网址内容与用户个人信息保护不相关，不符合华为应用市场审核标准

应用内的隐私政策/补充应用信息提交的隐私政策网址的内容应和用户个人信息保护相关， 需保证在应用内展示的隐私政策网址，和更新信息提交的隐私政策地址一致，同时保证隐私政策展示清晰无误，告知用户收集个人信息的目的、方式、范围。

#### 您服务名称的内容与服务实际信息不相符，不符合华为应用市场审核标准

请提交与服务实际功能内容相符的服务信息，服务信息包括服务名称、服务图标、服务一句话简介、服务介绍、服务新版本特性、服务截图及服务视频，确保更新应用信息提交的应用的名称、图标、介绍、截图等与实际待上架的应用一致。

#### 您的应用内未提供账号注销服务，不符合华为应用市场审核标准

如果元服务涉及到请在应用内提供账号注销功能选项，功能选项名称需表述清晰，需使用如“注销账号”等表述。

#### 您有多个华为账号，无法确认是否是服务商认证账号

您可登录[服务商合作伙伴中心网站](https://developer.huawei.com/consumer/cn/partner/)，通过点击右上角“管理中心”进入服务商管理中心。若页面提示“您已认证开发者账号，无法加入终端云服务商体系，请使用其他未认证过的华为账号加入终端云服务商体系”，即账号非服务商认证账号；若页面提示“当前账号无权限访问第三方管理平台”，即账号为服务商认证账号，提供Developer ID配置白名单后，即可开始使用。

#### 如何查询您的Developer ID

您需使用完成服务商认证并加入HarmonyOS开发服务商计划的账号，登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，点击“用户与访问”，点击“个人信息”，即可找到Developer ID。

#### 如何查询元服务对应的开发者ID、应用包名、App ID和ClientID信息

在商家将元服务授权给服务商后，就可以[通过第三方管理台查询](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-view-authorization-0000002338698692#ZH-CN_TOPIC_0000002338698692__p194951935915)获取此元服务对应的开发者ID、应用包名、App ID和ClientID信息。
