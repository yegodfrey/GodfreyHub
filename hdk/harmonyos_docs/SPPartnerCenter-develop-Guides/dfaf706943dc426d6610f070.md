# 构建元服务

![](https://media:201778144681172539)  
基于HarmonyOS可以开发HarmonyOS应用和元服务，但是第三方平台当前仅支持代开发元服务，所以下文中接口提到应用仅指代元服务。  

#### 提交元服务资质审核

元服务上架时，需要提供相关资质文件，不同类型的元服务需要提供的资质文件会有所不同，您可以提前提交资质文件的审核，以便缩短元服务上架的审核周期。

1. 调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-update-0000002021703170)接口，设置分类、主标签和附属标签。  
   ![](https://media:201778144681200540)  
   "附属标签"为可选项，当为元服务设置多个标签时，需要设置，以便区分主标签和附属标签。
2. 调用[查询需要上传的资质文件信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/query-tag-qual-dependent-0000002187911037)接口，确定元服务需要上传的资质文件。
3. 调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-upload-url-0000002057702505)接口，然后调用[上传文件](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/upload-file-0000002095222766)接口上传所有需要提交的资质文件。
4. 调用[提交资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/post-tag-qual-dependent-0000002152513894)接口，提交资质文件的审核。
5. 调用[查询资质审核任务详情](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-qualification-review-task-0000002152671922)接口，查看审核进度以及审核意见；也可以调用[修改资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/modify-qualification-review-task-0000002483476657)接口、[撤销资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/cancel-qualification-review-task-0000002187952733)接口修改或撤销资质审核任务。  

#### 基于模板构建元服务

1. 获取模板ID。可通过第三方平台查询或者调用接口查询。
   * 通过第三方平台查询：进入模块库查询。 ![](https://media:201778144681259541 "点击放大")

   * 调用[获取模板列表](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-template-list-0000001552137521)接口获取。
2. 构建extJson信息，具体各字段说明参考[extJson说明](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/extjson-description-0000002554249601)。
   * ArkUI开发模式：通过extJson配置信息，将模板中AppScope/app.json5文件相关信息，以及模块下module.json5文件的client_id替换为元服务的内容，extJson内容样例如下：

     ```
     {
        "extAppId": "57658802078XXXXxxxx", 
        "appConfig":{
          "app": {
            "versionCode": 1000000,
            "versionName": "1.0.0.0",
            "description": "元服务简介"
          }
         },
         "moduleConfig": [
             {
                 "module": {
                     "name": "entry",
                     "clientId": "576588020785592xxxx"
                 }
             }
         ]
     }
     ```

   * 类Web开发模式：通过extJson配置信息，将模板中AppScope/app.json5文件相关信息，ascf/ascf_src/app.json5文件相关信息以及模块下module.json5文件的client_id替换为元服务的内容，extJson内容样例如下：

     ```
     {
        "extAppId": "1118669435474119700", 
        "appConfig":{
          "app": {
            "versionCode": 1000,
            "versionName": "1.0.0.0",
            "description": "元服务简介"
          }
         },
         "moduleConfig": [
             {
                 "module": {
                     "name": "entry",
                     "abilities": [
                         {
                             "name": "EntryAbility",
                             "maxWindowHeight": 300,
                             "maxWindowRatio": 3.5,
                             "maxWindowWidth": 2560,
                             "minWindowHeight": 200,
                             "minWindowRatio": 0.5,
                             "minWindowWidth": 1400
                         }
                     ],
                     "clientId": "1****1"
                 }
             }
         ],
         "ascfConfig": {
             "entryPagePath": "entryPagePath",
             "pages": {
                 "pages/discovery/discovery": {
                     "info": {
                         "navigationBarTitleText": ""
                     }
                 }
             },
             "tabBar": {
                 "backgroundColor": "#FFFFFF",
                 "borderStyle": "white",
                 "color": "#626567",
                 "list": [
                     {
                         "iconPath": "images/index.png",
                         "pagePath": "pages/index/index",
                         "selectedIconPath": "images/index_focus.png",
                         "text": ""
                     }
                 ],
                 "selectedColor": "#2A8CE5"
             },
             "window": {
                 "backgroundColor": "#F4F4F4",
                 "backgroundTextStyle": "light",
                 "enablePullDownRefresh": true,
                 "navigationBarBackgroundColor": "#0068C4",
                 "navigationBarTextStyle": "white",
                 "navigationBarTitleText": "窗口"
             }
         }
     }
     ```

3. 打包resource_ext.zip文件。 resource_ext.zip打开首层目录结构定义如下：

   * app-resource：有且仅有一个，表示app级的资源目录，用于替换AppScope/resources下的资源。
   * module-resource-$moduleName：支持每个module需配置一个，通过$moduleName进行区分，用于替换对应模块resources下的资源。 例如有entry和phone两个模块，那么就要存在两个目录，分别为module-resource-entry和module-resource-phone。

   * entry-card：有且仅有一个，表示app级的资源目录，用于存放服务卡片的资源文件。
   * ascf-resource：类Web开发模式的元服务才需要，用于替换ascf_src下extConfig.json文件和用到的资源文件。资源文件存放目录结构与开发态的ascf_src目录结构保持一致，ascf_src下源码类文件（例如css、html、js、ts等后缀文件）以及manifest.json文件不支持替换。

   ![](https://media:201778144681286542)  
   * resource_ext.zip解压后务必展示以上目录层级，请勿再多加一层根目录，比如解压后为resource_ext，否则将导致资源无法成功替换。
   * resource_ext.zip中配置的资源相对模板中的不允许新增或者删除，仅允许替换。比如zip包里有startIcon.png，那么模板里同样的目录层级下必须已经有startIcon.png，否则构建将出错。
   * 支持限定词、rawfile的替换，不支持替换profile。
   * 如果使用macOS压缩resource_ext.zip，请务必清理掉.DS_Store这类文件，否则后续对文件安全性校验将报错。
   * 请勿用好压等非标准压缩工具进行压缩，容易出错，请使用标准压缩工具或者压缩命令进行压缩。

   resource_ext.zip与元服务工程资源对应关系如下：

   ![](https://media:201778144681358543 "点击放大")
4. 调用[获取文件上传地址](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-upload-url-0000002057702505)接口，获取resource_ext.zip上传后的objectId。
5. 调用[构建应用](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/build-application-0000001552057365)接口基于模板构建生成元服务包，并获取taskId。
6. 调用[查询构建任务状态](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-task-status-0000001552137517)接口查询此次构建任务的构建结果。
7. 构建成功后，调用[更新应用软件包信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-file-info-update-app-0000002130782149)接口，将软件包关联到对应的元服务。
8. 调用[查询软件包编译状态](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/query-appfile-states-0000002057702509)接口，确保软件包编译成功，从而完成软件包信息的更新。
