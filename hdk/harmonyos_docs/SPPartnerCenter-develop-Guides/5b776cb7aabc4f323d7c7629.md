# 获取用户级Token

#### 功能介绍

“用户级”的含义是该access_token可以代表用户的身份来访问服务API，可以访问用户个人信息有关的API，如[查询用户信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-references-V5/account-api-get-user-info-V5)接口。

服务商在使用用户级access_token代调用华为开放服务API前，需要通过授权码模式生成用户级access_token，授权码模式依赖于调用[端侧SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-java-integration-hms-core-sdk-0000001148191776)获取到的Authorization Code。

#### 使用注意事项

Authorization Code只有5分钟有效期，并且用完一次就会失效。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 服务商服务器 -> 华为服务器  
接口URL | https://oauth-login.cloud.huawei.com/oauth2/agent/v1/access-token  
数据格式 | 请求：Content-Type: application/json 响应：Content-Type: application/json  
  
#### 请求参数

#### [h2]Header

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
x-client-id | M | String | 商家的client_id。  
x-agent-client-id | M | String | 服务商的client_id。 创建第三方平台时由服务商主动创建的服务账号ID，可在第三方管理平台“开发配置 > 开发资料设置”页面中创建/查询，详情请参见[接口访问凭证（应用访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p17449134919597)。  
  
#### [h2]Body

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
grant_type | M | String | 固定为authorization_code。  
code | M | String | 华为账号授权成功并获取到的Authorization Code。  
client_assertion_type | M | String | 固定为"urn:ietf:params:oauth:client-assertion-type:jwt-bearer"。  
client_assertion | M | String | 服务商生成的JWT。  
  
其中，**client_assertion** 是一个JSON Web Token（JWT）。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140041.19686629691792655473015896262539:50001231000000:2800:816DEA59A48F4DD34E37D7723B392DC100EB5172F532D27D96200DF9C69949FE.png)

JWT是一个开放标准（RFC 7519），定义了一种安全传输信息的方法，具体请参见[jwt.io](https://jwt.io/)。

JWT由Header、Payload和Signature三部分拼接组成，三部分中间以“.”号分隔，例如：xxxx.yyyy.zzzz。

服务商可以依据Header中指定算法以及使用创建凭据下载的json文件内密钥ID关联的私钥（即json凭据文件中[private_key](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-create-platform-0000002372696573#ZH-CN_TOPIC_0000002372696573__zh-cn_topic_0000002329319234_p8324442152714)）进行签名生成JWT。

**JWT Header**

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
alg | M | String | 算法类型，固定为PS256。  
typ | M | String | Token类型，固定为JWT。  
kid | M | String | 密钥ID。即json凭据文件中[key_id](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-create-platform-0000002372696573#ZH-CN_TOPIC_0000002372696573__zh-cn_topic_0000002329319234_p73739394272)。  
  
**JWT****Payload**

**参数** | 必选(M)/可选(O) | **类型** | **说明**  
---|---|---|---  
iss | M | String | 服务商的client_id。 创建第三方平台时由服务商主动创建的服务账号ID，可在第三方管理平台“开发配置 > 开发资料设置”页面中创建/查询，详情请参见[接口访问凭证（应用访问凭据）](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/ht-configure-platform-0000002372776705#ZH-CN_TOPIC_0000002372776705__zh-cn_topic_0000002329159394_p17449134919597)。  
sub | M | String | 商家的client_id。  
aud | M | String | 固定为"https://oauth-login.cloud.huawei.com/oauth2/agent/token"。  
iat | M | Integer | 生成时间，linux时间戳。  
exp | M | Integer | 过期时间，linux时间戳。  
  
#### 请求示例
    
    POST /oauth2/agent/v1/access-token HTTP/1.1
    Host: oauth-login.cloud.huawei.com
    x-client-id: 12345000
    x-agent-client-id: 12345666
    Content-Type: application/json
     
    {
        "grant_type": "authorization_code",
        "code": "n0esc3Nxxxxxxxc3f0ogp4",
        "client_assertion_type": "urn:ietf:params:oauth:client-assertion-type:jwt-bearer",
        "client_assertion": "xxxx.yyyy.zzzz"
    }

#### 响应参数

返回值为JSON格式的字符串，包含参数如下。

字段名 | **类型** | 说明  
---|---|---  
id_token | String | 如果scope中包含openid，则返回id_token，JWT格式。 如果要解析出用户的ID Token，需要先对ID Token的有效性进行验证，详情请参见[ID Token验证签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/account-faq-7-V5)。  
access_token | String | ACCESS_TOKEN，后续用它来调用业务API接口。  
token_type | String | 固定值Bearer。  
expires_in | Integer | access_token的过期时间，以秒为单位。过期时间默认60分钟。  
refresh_token | String | 返回refresh_token。  
refresh_expires_in | String | refresh_token过期时间。过期时间默认180天。  
scope | String | 该access_token对应的scope列表，以空格分隔。  
  
其中id_token是一个JWT，包含如下字段：

scope（根据scope识别是否返回后面的字段） | 字段名 | 类型 | 字段说明  
---|---|---|---  
openid | iss | String | 固定值https://accounts.huawei.com。  
sub | String | unionid，对同一个开发者下的所有应用是相同的。  
aud | String | 商家的client_id。  
exp | Integer | id_token过期时间，Linux时间戳。  
iat | Integer | id_token生成时间，Linux时间戳。  
nonce | String | 区分大小写，跟/authorize接口传入的nonce一致。  
at_hash | String | 区分大小写，用JOSE Header里申明的算法进行hash计算，然后截取左边一半值，再进行base64url。  
azp | String | 商家的client_id。  
openid | String | openid，不同client_id下不同。  
email | email_verified | Boolean | 用户邮箱是否已验证。  
email | String | 用户邮箱。  
profile | picture | String | 用户头像图片链接。  
name | String | 用户的全名（姓和名拼在一起）。  
locale | String | 用户语言偏好。  
family_name | String | 用户全名中的姓。  
given_name | String | 用户全名中的名。  
display_name | String | 昵称，华为账号对应的昵称。没有昵称则取匿名化的邮箱或手机号。  
nickname | String | 昵称，当用户没有昵称时，不返回该字段。  
https://www.huawei.com/auth/account/country | register_country_code | String | 注册地国家码。自定义字段。 当client_id有com.huawei.android.hms.account.getCountry权限时返回。  
home_country_code | String | 服务地国家码。自定义字段。 当client_id有com.huawei.android.hms.account.getCountry权限时返回。  
https://www.huawei.com/auth/account/age.range | ageRange | String | 年龄范围，应用拥有权限com.huawei.hms.account.ageRange的返回。
                * -1：未知（没输入生日）
                * 0：成人
                * 1：未成年人
                * 2：儿童  
  
#### 响应示例

**成功** ：
    
    HTTP/1.1 200 OK
    Content-Type: application/json;charset=UTF-8
    Cache-Control: no-store
    Pragma: no-cache
     
    {
    "access_token": "CFyJ21sxxxxxxxl0Y=",
    "refresh_token": "CF13G0sRxxxxxxxPvL8=",
    "expires_in": 3600,
    "refresh_expires_in": "15552000",
    "id_token": "eyJhbGciOiJSxxxxxxxGDLQ",
    "scope": "openid profile email",
    "token_type": "Bearer"
    }

**失败** ：

失败返回的httpstatus=400，在body中返回错误码和描述，json格式。

例如：
    
    HTTP/1.1 400 Bad Request
    Content-Type: application/json;charset=UTF-8
     
    {"error":20003,"error_description":"parameter invalid"}
