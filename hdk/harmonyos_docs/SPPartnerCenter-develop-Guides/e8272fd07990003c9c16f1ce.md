# 商家管理授权

商家确认授权后，可以对授权进行解除授权的管理操作。

#### 解除授权

商家可以随时解除授予第三方平台的应用权限。服务商无法单方面解除授权。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.75034582879486096199942931242191:50001231000000:2800:36B1F7600831B4B8C379F2EC572FC9E46171B3417C587E71D985B1460E8DD120.png)

若元服务使用了授权第三方平台的相关资源，解除授权可能导致应用无法正常运行。建议商家先与服务商充分沟通，确保相关资源数据处理妥善后再解除授权。

                1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“用户与访问”。
                2. 在左侧导航栏选择“第三方授权管理”菜单，点击“应用授权”页签，在需要解除授权应用的“操作”列点击“解除授权”，然后在二次确认弹窗中点击“确认”即可。
