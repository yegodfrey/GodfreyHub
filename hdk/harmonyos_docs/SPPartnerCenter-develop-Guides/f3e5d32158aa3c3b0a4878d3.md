# 入门指引

#### 业务开展流程

![](https://media:201775033406600573 "点击放大")  

#### 获取资质

#### 服务商

服务商在开展业务前，需要获取HarmonyOS开发服务商的资质，详细操作参考[HarmonyOS开发服务商合作指南](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/sp_partner-hmos_develop_partner_guide-0000002101543573)，主要流程如下：

1. 通过合作咨询，了解相关服务商合作的事宜。
2. 了解HarmonyOS开发服务商入驻条件，审视是否满足入驻的准入条件。
3. 注册服务商的华为账号。
4. 对注册的华为账号进行实名认证。
5. 加入HarmonyOS开发服务商计划。

![](https://media:201775033406681574 "点击放大")  

#### 商家

1. [注册华为开发者账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
2. 对账号进行实名认证，分为：[个人开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/ht-idrna-0000001200848143)或者[企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/ht-edrna-0000001154848578)。
3. （可选）如果需要授权服务商去华为云代备案，则需要实名认证华为云账号。
   * 商家如果已在华为开发者联盟实名认证，则可以通过[开发者联盟授权认证](https://support.huaweicloud.com/usermanual-account/account_real_cloud0001.html)。
* 商家如果从来没有认证过，则可以前往[华为云实名认证](https://support.huaweicloud.com/usermanual-account/account_auth_00001.html)。  

#### 搭建第三方平台

1. 准备创建第三方平台所需材料，包括：
   * 服务商官方的介绍网站
   * 第三方平台的图标，需要是jpg、jpeg和png格式，尺寸为256\*256像素，不能超过500KB。
   * 消息与事件接收URL：用于接收华为平台推送的消息与事件通知的URL。当商家授权变更、元服务构建有结果、元服务上架/下架审核后，华为平台将向服务商发送通知。
2. [创建第三方平台](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/create-platform-0000002523075512)。
3. [发布第三方平台](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/release-platform-0000002554235415)，等待华为方审核通过。  

#### 获取商家授权

1. 服务商在第三方平台[获取让商家授权的链接](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-authorization-link-0000002523075602)，需要根据商家创建元服务的情况获取不同的授权链接。
   * 如果商家已自行创建元服务，则获取"已有元服务授权"链接。
   * 如果商家没有创建元服务，则获取"新增元服务授权"链接，商家授权后，会自动创建元服务。
2. [商家确认授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/confirm-authorization-0000002523235598)。
3. （可选）商家授权后，还可以主动对授权信息进行调整，详细操作参考[商家管理授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/manage-authorization-0000002554235495)。  
   ![](https://media:201775033406713575)  
   授权信息的更改将影响业务的进行和元服务的运行，所以更改权限前建议商家和服务商做好充分沟通。
4. 授权完成后，服务商在第三方平台[查看商家授权元服务信息](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/query-authorization-infor-0000002523075604)，包括授权的权限集、被授权元服务的相关信息。  

#### 通过模板代开发元服务

#### 构建模板

模板是服务商开发调试好的元服务常用业务代码，并基于已完成的代码样例编译后的包。后续服务商可以基于此模板，做少量修改即可快速批量生成类似功能的元服务。

1. 使用DevEco Studio工具参考元服务开发规范完成[元服务模板的开发](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/develop-template-0000002554247845)。
2. 在AGC上创建一个元服务，并为该元服务配置隐私政策和内容分级，后续构建元服务时，此两部分信息会同步复制至元服务，避免重复配置。详细操作参考[创建、配置模板关联的元服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/create-template-fa-0000002523087966)。
3. 将开发完成的模板上传至第三方平台，详细操作参考[上传模板](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/upload-template-0000002554287879)。
4. 将上传的[模板添加至模板库](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/add-template-to-library-0000002523247958)。  

#### 配置元服务域名

为规范元服务请求域名范围，提升平台合规经营安全性，元服务需要配置服务器域名，服务器域名主要用于通过网络接口访问服务器的场景。如果元服务中用到Web组件加载了H5，那么还需要配置业务域名，详细操作参考[配置元服务域名](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/manage-platform-domain-0000002554247847)。

调用API基于模板[构建生成元服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/build-atomic-service-0000002523087968)。  

#### 备案

备案是中国大陆的一项法规，使用大陆节点服务器提供互联网信息服务的用户，需要在服务器提供商处提交备案申请。未取得许可或者未履行备案手续的，不得从事互联网信息服务，否则属违法行为。

在发布元服务前，必须完成元服务的备案，提交发布申请时，需要提交备案相关信息，否则将无法通过发布审核。备案操作可以由服务商或者商家来完成：

* 服务商：获取商家代备案的授权，使用第三方管理平台开放的API代替商家在华为云完成备案，详细操作参考[构建备案能力](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/build-recordal-capability-0000002554289647)。
* 商家：自行完成元服务的备案手续，将备案信息提供给服务商。  

#### 测试、上架元服务

在发布前，服务商可选择特定用户群组来测试构建出的元服务，以便提前发现问题，及时修复和优化版本体验。测试通过后，即可提交发布，待审核通过，元服务即成功上架至华为应用市场。详细操作参考[测试、发布元服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/test-release-atomic-service-0000002554287881)。
