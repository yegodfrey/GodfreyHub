# 添加模板到模板库

[上传完模板](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/upload-template-0000002554287879)还只是提交到草稿箱，只有将草稿箱中的模板添加至模板库，生成模板ID才成为一个正式模板，后续可用于元服务的构建。

1. 进入第三方平台详情页，左侧导航选择"行业模板管理"，进入页面点击草稿箱中待上传模板所在行的"添加到模板库"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/Y_TWCAy8Q6q_ZlSNRLW7HA/zh-cn_image_0000002693555862.png?HW-CC-KV=V1&HW-CC-Date=20261008T162417Z&HW-CC-Expire=31536000000&HW-CC-Sign=71744D38C360337272332118E62C79BBDADD54365B2B7191513C7D9E1DC8BBDA "点击放大")

2. 添加成功后，"模板库"列表中新增一条记录，代表该模板已成为一个正式模板。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/hc8s7i8nR4qCaiV4kA6oMA/zh-cn_image_0000002723235295.png?HW-CC-KV=V1&HW-CC-Date=20261008T162417Z&HW-CC-Expire=31536000000&HW-CC-Sign=09226C9B5D5FEF486A9EDC9A4E3A05EFE51A7034775597E0BC56F63D9F1E1AB1 "点击放大")

   成功添加模板到模板库后，可以点击对应模板后"操作"列的"查看基础配置"，查看模板关联内容分级和隐私政策信息。
