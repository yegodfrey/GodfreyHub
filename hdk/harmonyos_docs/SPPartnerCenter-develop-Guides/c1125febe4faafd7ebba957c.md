# 发布第三方平台

第三方平台创建完成，检查平台基本信息、开发配置信息准确无误后即可申请发布。审核通过后，即可与商家建立授权关系，并进行后续的相关操作。

1. 在第三方平台首页的列表中，点击需要申请发布的第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://media:201775033407737594 "点击放大")

2. 在第三方平台详情"概览"页面，点击"申请发布"。 ![](https://media:201775033407776595 "点击放大")

3. 弹出"确认发布"弹框，点击"确定"。 ![](https://media:201775033407811596 "点击放大")

4. 第三方平台进入"审核中"状态，请等待审核人员的审批。  
   ![](https://media:201775033407836597)  
   * "审核中"状态时，基本信息不可编辑；权限集和开发配置信息可以编辑，即改即生效。
   * "审核中"的第三方平台不支持删除。

   ![](https://media:201775033407875598 "点击放大")
5. 审核成功后，在第三方平台首页的列表页中可查看到审核状态为"审核成功"。  
   ![](https://media:201775033407912599)  
   审核成功后的第三方平台，如已有商家授权账号，则不支持删除。

![](https://media:201775033407940600 "点击放大")
