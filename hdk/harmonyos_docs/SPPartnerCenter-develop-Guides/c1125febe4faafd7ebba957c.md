# 发布第三方平台

第三方平台创建完成，检查平台基本信息、开发配置信息准确无误后即可申请发布。审核通过后，即可与商家建立授权关系，并进行后续的相关操作。

1. 在第三方平台首页的列表中，点击需要申请发布的第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/5Yeo-1NpRUaAGurcMNDQVQ/zh-cn_image_0000002554284863.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=3C61AC60195F93C2F852199F756BDE2154C7F25FCC342AD19C8A2DB80E021D3F "点击放大")

2. 在第三方平台详情"概览"页面，点击"申请发布"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/dnaWlM-RQo-TWbc3Z6DiFQ/zh-cn_image_0000002693714354.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=8D3DDC674661C798298A9079855EC04B01884AB19EBCE1F5526E1DD1FE3D1AF8 "点击放大")

3. 弹出"确认发布"弹框，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/TUsL49qXR4eKO2ykyhQcPw/zh-cn_image_0000002693554480.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=B75F595A91D516A6068236CAC4ADD93045BA7D8C7DBE4BD094672D2411F63FDF "点击放大")

4. 第三方平台进入"审核中"状态，请等待审核人员的审批。 说明
   > * "审核中"状态时，基本信息不可编辑；权限集和开发配置信息可以编辑，即改即生效。
   > * "审核中"的第三方平台不支持删除。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/nY2yo2PsRhKW_kmAZ6R1Cg/zh-cn_image_0000002723233905.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=D73128F0FFF684B1D5134654CEE4060321559FDC475B37BE53C18A029F1E54C1 "点击放大")
5. 审核成功后，在第三方平台首页的列表页中可查看到审核状态为"审核成功"。 说明
   >
   > 审核成功后的第三方平台，如已有商家授权账号，则不支持删除。
