# 发布第三方平台

第三方平台创建完成，检查平台基本信息、开发配置信息准确无误后即可申请发布。审核通过后，即可与商家建立授权关系，并进行后续的相关操作。

1. 在第三方平台首页的列表中，点击需要申请发布的第三方平台所在行中的"详情"，进入第三方平台详情页。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/5Yeo-1NpRUaAGurcMNDQVQ/zh-cn_image_0000002554284863.png?HW-CC-KV=V1&HW-CC-Date=20261008T153553Z&HW-CC-Expire=31536000000&HW-CC-Sign=205F34E89B961C83A8B73CC3DABC8BC9751DA229FA665BB1B98E7F9911995D8E "点击放大")

2. 在第三方平台详情"概览"页面，点击"申请发布"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/dnaWlM-RQo-TWbc3Z6DiFQ/zh-cn_image_0000002693714354.png?HW-CC-KV=V1&HW-CC-Date=20261008T153553Z&HW-CC-Expire=31536000000&HW-CC-Sign=4FE3AA49008C5E3BC049B0C2BE8FCE9E0ABA13433576DF1BBE8A9E9D79C17F02 "点击放大")

3. 弹出"确认发布"弹框，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/TUsL49qXR4eKO2ykyhQcPw/zh-cn_image_0000002693554480.png?HW-CC-KV=V1&HW-CC-Date=20261008T153553Z&HW-CC-Expire=31536000000&HW-CC-Sign=BFFB98B9F060DDA0EC152411B85F5855710939AC4D5CBCC33A0DC45458024DB3 "点击放大")

4. 第三方平台进入"审核中"状态，请等待审核人员的审批。 说明
   > * "审核中"状态时，基本信息不可编辑；权限集和开发配置信息可以编辑，即改即生效。
   > * "审核中"的第三方平台不支持删除。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/nY2yo2PsRhKW_kmAZ6R1Cg/zh-cn_image_0000002723233905.png?HW-CC-KV=V1&HW-CC-Date=20261008T153553Z&HW-CC-Expire=31536000000&HW-CC-Sign=FE436BB119E741AB7D72BCF8CBD9B14978F957CBF79A7B32D90EF6B143648B5E "点击放大")
5. 审核成功后，在第三方平台首页的列表页中可查看到审核状态为"审核成功"。 说明
   >
   > 审核成功后的第三方平台，如已有商家授权账号，则不支持删除。
