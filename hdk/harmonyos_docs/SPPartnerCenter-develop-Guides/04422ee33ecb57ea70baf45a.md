# 开发FAQ

#### 模板

#### 本地调试、打包正常，但是提交测试会出现异常

请检查以下几点：

* 工程根目录的"hvigor/hvigor-config.json5"文件中需要增加如下配置。

  ```
    "properties": {
         "ohos.arkCompile.emptyBundleName": true
    }
  ```

* 工程构建配置文件build-profile.json5中需要设置useNormalizedOHMUrl=true。
* 确认是否使用navigation，不能使用router。
* 确认首页使用loadContentByName加载页面，不能使用loadContent
* 全局搜索obfuscation，看下ruleOptions的enable是否全部都是false

  ```
  "obfuscation": {
    "ruleOptions": {
      "enable": false
    }        
  }
  ```

#### 调用"将草稿添加到模板库"接口，提示208211968：draft not found

1. 调用[获取草稿模板列表](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-draft-template-list-0000001552257477)接口确认草稿模板是否存在。
2. 存在的话检查传入的模板id是否一致。如果前端进行封装，可能会因为丢失精度导致id不对。  

#### 构建元服务

#### 更新应用信息，提示错误204144696，update app info failed,additional msg is kindSubTags or kindMainTag is invalid

请检查以下几点：

* 检查设置的元服务标签是否已经通过审核。
* 检查接口中配置的标签是否和设置的一致，harmonyChildType对应分类，kindMainTag对应标签。取值对应关系参见[应用游戏分类](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/api-reference-apptype-0000002095222770)。  

#### 更新应用软件包信息，提示错误204144693，addAppPkg.addAppPkgReq.fileName: size must be between 0 and 64

[更新应用软件包信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-file-info-update-app-0000002130782149)接口的fileName可以是用户自定义，但是长度不能超过64，且必须以.app结尾。  

#### 更新图标异常

参考如下结构更新应用图标：

```
{
    "appIconList": [{
      "lang": "zh-CN",
      "fileInfoList": [{
        "deviceType": 4,
        "objectIdList": ["CN/20241118**/17319******.png"],
        "showType": 0
      }]
    }
  ]
}
```

虽然更新应用文件信息接口的参数都是可选，但是body不能为空，参数都可选，是为了支持各个字段都能更新。  

#### 更新业务域名，提示错误：208220193 not all domain in update request are valid

检查是否没有下载配置文件放到域名根目录。将下载到本地的配置文件放置到域名根目录下，例如"test.com.cn/XXX.txt"，并须确保可以成功访问该配置文件。详细参见[配置业务域名](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/test-release-atomic-service-0000002554287881#section1562792813217)。  

#### 提交标签审核，提示错误：204144783：invoke qualification service create review task failed

在提交标签审核前，需要先调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-update-0000002021703170)设置元服务类别，即harmonyChildType字段，然后再提交标签审核。  

#### 构建出的元服务名称没有变化

resource_ext.zip里面可以加上app-resource目录下的string.json文件，里面定义app_name，设置元服务名称；修改module-resource-entry目录下的string.json文件，里面定义EntryAbility_label，设置入口页面显示名称。  

#### 构建后的.app包，服务商可以直接下载吗

不可以，只有商家可以到AGC软件包管理页面去下载。  

#### 新增用户协议后，更新应用信息时报错，错误信息：204144691："agreement is not complete"

更新用户协议信息时，如果元服务设置了隐私政策协议，会去校验此协议的状态，如果是"草稿"状态，则会报错，需要调用[提交隐私政策协议](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/put-privacy-agreement-0000002191379330)接口，将状态变成"完成"。  

#### 测试、发布

#### 提审出错，错误信息："inAgreementButNotInPkg":\[\],"inPkgButNotInAgreement":\["LOCATION","APPROXIMATELY_LOCATION"\]

此错误是隐私声明中"设备权限调用"设置的权限和软件包内module.json5声明的权限不一致，inAgreementButNotInPkg有信息，表示权限在隐私声明中设置了，但是软件包中没有；inPkgButNotInAgreement有信息，表示权限在软件包中设置了，但是隐私声明中没有设置。出现这种错误，需要修改模板的隐私声明，详细参见[配置隐私声明（元服务）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-privacy-policy-atomic-0000002317135133)，然后删除已构建元服务的隐私声明，再调用提交发布接口。  

#### 删除元服务隐私声明时，没有删除按钮，无法删除

检查是否存在在架的测试版本或者正式版本，如果存在，则需要停止测试或者下架正式版本。  

#### 提审出错，错误信息：the versionName and versionCode of the pkg is same with other pkg in use

此错误表示已经发布了一个相同版本号的在架版本或测试版本，请升级新发布软件包的版本号，版本号可以通过构建参数extJson中的versionCode进行替换。  

#### 提审出错，错误信息：registeredEntity and registeredEntityName can not be empty

此错误是因为用于核准备案的主办单位信息没有填写完整，请调用[更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-update-0000002021703170)接口，对registeredIdType、registeredIdNumber、registeredEntity和registeredEntityName4个关于主办单位的参数进行赋值。  

#### 提审出错，错误信息：204144641，app must have only one package

出现此问题，是构建元服务后，没有调用[更新应用软件包信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-file-info-update-app-0000002130782149)将构建的软件包信息更新到元服务中，需要调用此接口更新后，再提交审核。  

#### 驳回的原因是否只能在AGC查看，可以通过接口吗

如果仅看文字描述，是可以通过[查询应用信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-query-0000002130941805)接口里的auditInfo字段获取。  

#### 提交邀请测试审核被驳回，元服务图标尺寸为216\*216

在工程包里的应用图标是要512\*512，216\*216是提交应用市场上架审核时上传的，两个图标需要注意区分。

可以使用DevEco Studio生成图标，详细内容参见[生成元服务图标](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-service-icon-generation)。  

#### 撤销审核传入的versionId从哪里获取

可以调用[查询应用信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-query-0000002130941805)接口在appInfo中获取versionId。  

#### 提交审核资质不符合要求，但是资质审核任务已通过，无法修改，如何处理？

调用[删除资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/delete-qualification-review-task-0000002557760669)接口删除有问题的标签，然后调用[提交资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/post-tag-qual-dependent-0000002152513894)将删除的标签重新提交审核。  

#### 更新隐私政策出错，错误信息：204144850，agreement not allow update

检查是否有测试版本或者正式版本正在使用了此隐私政策，已被使用的隐私政策不能修改。
