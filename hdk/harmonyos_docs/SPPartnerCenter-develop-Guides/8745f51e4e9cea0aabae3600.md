# App Linking

App Linking提供的元服务链接是专为开发者设计的密文URL服务，可以直达元服务任意页面。开发者可以为自己的元服务生成并配置专属的元服务链接，同时设置有效期，精准把握用户访问的时效与范围。还可以为元服务生成二维码，用户只需扫描二维码，无需手动输入网址，即可快速访问指定的元服务页面。

## 前提条件

[查看授权信息](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/query-authorization-infor-0000002523075604)，已获取商家"服务集成与开发"的授权。如果没有，则需要[修改第三方平台的权限集](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section109408011447)，重新获取商家授权。

## 开发步骤

### 使用元服务链接跳转元服务

1. 调用[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-0000001569170877)接口，获取服务商调用开放接口的用户级Token。
2. 调用[创建元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-create-atomiclink-0000002513998258)接口创建元服务链接。
   * isQRCodeLinked：设置为false。
   * customParams：如果需要使用静态自定义参数跳转至元服务指定页面，则需要配置此参数。

   创建完成，可以调用[查询元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-query-atomiclink-0000002513838336)接口查看具体信息，如需调整，可以调用[修改元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-update-atomiclink-0000002545518217)接口进行修改，也可以调用[删除元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-delete-atomiclink-0000002545598213)接口删除。
3. （可选）如果需要跳转至元服务指定页面，则选择以下方式中一种进行配置。
   * **使用动态自定义参数跳转** ：即通过在链接URL的末尾添加动态自定义参数，从而精确定位到元服务指定页面，详细参考[使用动态自定义参数跳转指定页面](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-applinking#section1620481746)。
   * **使用静态自定义参数跳转** ：创建链接时必须配置customParams，详细参考[使用静态自定义参数跳转到指定的页面](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-applinking#section125451919568)。
4. 参考[使用元服务链接拉起元服务](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-applinking#section1355112161714)调试跳转效果。
5. 开发调试完，调用[修改元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-update-atomiclink-0000002545518217)接口将isReleased设置为true。

### 使用链接二维码跳转元服务

1. 调用[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-0000001569170877)接口，获取服务商调用开放接口的用户级Token。
2. 调用[创建元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-create-atomiclink-0000002513998258)接口创建元服务链接。
   * isQRCodeLinked：设置为true。
   * customParams：如果需要跳转至元服务指定页面，则需要配置此参数。
   * isReleased：调试时设置为false，并使用testQrCodeUrl配置的链接进行测试，调试完成发布前，修改为true。

   创建完成，可以调用[查询元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-query-atomiclink-0000002513838336)接口查看具体信息，如需调整，可以调用[修改元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-update-atomiclink-0000002545518217)接口进行修改，也可以调用[删除元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-delete-atomiclink-0000002545598213)接口删除。
3. 配置域名服务器，以便确认哪些元服务合法归属此域名，确保链接的安全可靠。
   1. 创建域名配置文件applinking.json，内容如下：

      ```typescript
      {
       "applinking": {
         "atomicServices": [
           {
             "appIdentifier": "1234567"
           },
           {
             "appIdentifier": "3456789"
           }
         ]
       }
      }
      ```

      > 说明
      > * appIdentifier填写元服务的App ID，此信息可通过[查询授权信息](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/query-authorization-infor-0000002523075604#ZH-CN_TOPIC_0000002523075604__li38012531054)获取。
      > * 同一个网站域名可以关联多个元服务，只需在"atomicServices"列表里放置多个"appIdentifier"元素即可，其中每个"appIdentifier"对应1个元服务。
   2. 将applinking.json放在域名服务器的固定目录下：https://*domain.name* /.well-known/applinking.json。

      例如：域名为www.example.com，则必须将applinking.json文件放在如下位置：

      https://www.example.com/.well-known/applinking.json
4. 解析二维码码值，跳转至不同的元服务页面。二维码码值可以从want的orgScanCode参数中读取，示例代码如下：

   ```screen
   import { AbilityConstant, UIAbility, Want } from '@kit.AbilityKit';
   import { hilog } from '@kit.PerformanceAnalysisKit';
   import { url } from '@kit.ArkTS';
   export default class EntryAbility extends UIAbility {
     onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
       // 从want中获取传入的码值信息。
       // 如传入的码值信息url为：https://www.example.com/programs?action=showall
       let orgScanCode = want?.parameters?.orgScanCode as string;
       if (orgScanCode) {
         // 从链接中解析query参数，拿到参数后，开发者可根据自己的业务需求进行后续的处理。
         try {
           let urlObject = url.URL.parseURL(orgScanCode);
           let action = urlObject.params.get('action');
           // 例如，当action为showall时，展示所有的节目。
           if (action === "showall"){
             // ...
           }
           // ...
         } catch (error) {
           hilog.error(0x0000, 'testTag', `Failed to parse orgScanCode.`);
         }
       }
     }
   }
   ```

5. 开发调试完，调用[修改元服务链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-update-atomiclink-0000002545518217)接口将isReleased设置为true。
