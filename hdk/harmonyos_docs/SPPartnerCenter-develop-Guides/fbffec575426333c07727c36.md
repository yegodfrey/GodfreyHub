# DependentQualLang  
  
参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
language | O | String | 资质的语言类型。 取值范围：
                * zh_CN：中文
                * en_US：英文
                * ru_RU：俄语  
description | O | String | 资质的描述信息。
