# 发布第三方平台

第三方平台创建并配置完成后，检查平台基本信息、开发配置信息准确无误后即可申请发布。审核通过后，即可与商家元服务建立授权关系，并进行后续的通过模板代开发元服务相关操作。

#### 操作步骤

                1. 第三方平台创建完毕后，平台审核状态为“待提交”。在第三方平台首页的列表中，点击需要申请发布的第三方平台所在行中的“详情”，进入第三方平台详情页。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.82217766986421216608156424498718:50001231000000:2800:24F5A33538272A93475D577D651C83DDAA5A95CA9E4F9859DAEFA24338236D7F.png)

                2. 在第三方平台详情中的概览页面，点击“申请发布”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.25567343632310414127874096641845:50001231000000:2800:7A8B492D687C1D948B9F44AAAC16F850D46FB9ADCBBA6C29E171AB6BA1D728DA.png)

                3. 弹出“确认发布”弹框，点击“确定”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.85864436688716689342449761687887:50001231000000:2800:55A1DE218E2B785E77F3EB13EDB165FDD04797D000D9991D8638CAEE4E7AE352.png)

                4. 进入审核流程，请等待审核人员的审批。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.08341488075815408024262121980175:50001231000000:2800:2B041A655AE026D6DC56AEC63EA242ADF0692CCECF0B6C5E6235422ABDFF1BB8.png)

                   * 第三方平台进入“审核中”状态时，基本信息不可编辑；权限集和开发配置信息可以编辑，即改即生效。
                   * “审核中”的第三方平台不支持删除。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.93346216449346083008252494295599:50001231000000:2800:9AD9BF3CC592DA1440330A03C29371FDC244BA805B9D4B87494F56EFB7AEB934.png)

                5. 审核成功后，在第三方平台首页的列表页中可查看到审核状态为“审核成功”。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126140043.42594977398250623090000322469909:50001231000000:2800:DC3C5103DA1B6493A01C6B9EF1D8EF4A8C15388CA3C58AFBDCF7528C9ACB7FB1.png)

审核成功后的第三方平台，如已有商家授权账号，则不支持删除。
