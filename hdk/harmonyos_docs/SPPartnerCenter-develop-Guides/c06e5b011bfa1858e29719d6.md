# 授权后被禁用的AGC界面

商家将元服务授权给服务商后，AGC上部分页面会被禁用，其他功能页面仍可正常使用。

## 软件包管理页面

元服务授权后，软件包管理页面功能禁止商家操作。

## 软件版本模块

元服务授权后，版本信息页面中的软件版本功能模块禁止商家操作，同时提交审核、撤销审核、申请下架等所有改变版本状态的操作禁止商家操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/yzAlmlCfS3eLR-Z21E1lGQ/zh-cn_image_0000002523106324.png?HW-CC-KV=V1&HW-CC-Date=20260929T084032Z&HW-CC-Expire=31536000000&HW-CC-Sign=BEEEEC48AD4C38ED62EE251A7510D931C04F0CFC810B08A78AA58B9A6BB72684 "点击放大")

## 域名管理页面

元服务授权后，域名管理页面禁止商家操作。
