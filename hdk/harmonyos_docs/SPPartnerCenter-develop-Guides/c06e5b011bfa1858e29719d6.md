# 授权后被禁用的AGC界面

商家将元服务授权给服务商后，AGC上部分页面会被禁用，其他功能页面仍可正常使用。

## 软件包管理页面

元服务授权后，软件包管理页面功能禁止商家操作。

## 软件版本模块

元服务授权后，版本信息页面中的软件版本功能模块禁止商家操作，同时提交审核、撤销审核、申请下架等所有改变版本状态的操作禁止商家操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/yzAlmlCfS3eLR-Z21E1lGQ/zh-cn_image_0000002523106324.png?HW-CC-KV=V1&HW-CC-Date=20260914T111900Z&HW-CC-Expire=31536000000&HW-CC-Sign=6FC0CFA2DE5D4697D80F420E3FEA7A373DD70DC9CEB233FDC706B8900289C9D8 "点击放大")

## 域名管理页面

元服务授权后，域名管理页面禁止商家操作。
