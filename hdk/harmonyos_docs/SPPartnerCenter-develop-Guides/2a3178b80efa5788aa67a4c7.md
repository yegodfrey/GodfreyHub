# 上传模板

## 前提条件

已[创建、配置模板关联的元服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/create-template-fa-0000002523087966)。

## 操作步骤

1. 进入第三方平台详情页，左侧导航选择"行业模板管理"，进入页面点击"上传行业模板"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/44/v3/OtWzVPxyTWO9CxeCqwYZmg/zh-cn_image_0000002723355215.png?HW-CC-KV=V1&HW-CC-Date=20260914T111901Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4D043092A4BF31CFF426DFE3A2EC70573BD53D161E915F482FD3CEE19E8EC79 "点击放大")

2. 右侧弹出"上传行业模板"侧滑框，配置如下参数。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/cpzUmbnTRQmpivGCLMTBHA/zh-cn_image_0000002554290959.png?HW-CC-KV=V1&HW-CC-Date=20260914T111901Z&HW-CC-Expire=31536000000&HW-CC-Sign=FA45267EBBEB7F2752FEC09093401E7E43A0A17FAC1CAB62DBFD3F669A165EF2 "点击放大")

   参数说明如下：

   |参数|说明|
   |:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |版本号|模板自身的版本号，模板可能存在演进，需要通过版本号来标识。 格式为X.X.X，推荐使用1.0.0作为第一个版本。|
   |模板类型|请选择"元服务模板"。|
   |模板分类|请选择模板对应的分类。|
   |描述|对模板的详细介绍，说明模板的能力和用途。|
   |来源元服务|选择已创建的与该模板关联的元服务。 如果还未创建，请参考[创建、配置模板关联的元服务](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/create-template-fa-0000002523087966)。|
   |上传模板代码|上传模板包。模板包为[开发模板](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/develop-template-0000002554247845)时打出的.app格式的包。|

3. 配置完成点击"保存"，即可上传模板到第三方平台的草稿箱中。
