# 1. 检查应用类型  


由于应用创建后应用类型不可更改，在正式开发联运应用之前，请确保应用的类型为“游戏”。

1、登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的应用”。

2、点击应用对应的“移动应用”链接。

3、在“分发 > 应用上架 > 应用信息”中查看“应用分类”，确保类型为“游戏”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224201519.39483822260864817072883459031855:50510916032941:2800:A384A711E75D022BAE98871539B6E8A457DB9FC490078F9DE479E621FA84622C.png?needInitFileName=true)

如果应用分类不是“游戏”，则需要参考[创建应用](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_creatgame)重新创建应用，并申请相关服务。

# 2. 准备应用参数  


在开发联运应用前，请确保下表所示信息已经具备。

---|---|---|---  
公共| Keystore-file| 文件| 自行创建。  
应用ID| 字符串| 应用服务详情，获取方法参考[查询应用ID](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_queryappid)。  
应用包名| 字符串| 创建应用时填写的包名，参考[创建应用](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_creatgame)。  
支付服务| 支付ID| 字符串| 支付服务详情，获取方法参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_querypayinfo)。  
支付私钥| 字符串  
支付公钥| 字符串  
游戏服务| 游戏私钥| 字符串| 游戏服务详情，获取方法参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_queryGameService)。  
游戏公钥| 字符串
