# 1. Agent常见问题

  * **Q：如何将日志打印到自己统一的方法中？**        

**具体场景** ：已有的项目中统一封装了日志方法，如L.d(tag, msg); L.e(tag, msg)。 而HMSAgent代码中日志都是通过HMSAgentLog.d(msg);HMSAgentLog.e(msg)打印的。想要HMSAgent代码中的日志也使用自己统一的日志方法。  
**解决方法** ：通过调用HMSAgentLog.setHMSAgentLogCallback方法，接管HMSAgent的默认日志打印，在空方法里使用自己的日志方法将tag和log输出。        



      
      1. HMSAgentLog.setHMSAgentLogCallback(new HMSAgentLog.IHMSAgentLogCallback() {  
         
        2.     public void logD(String tag, String log) {  
         
        3.     }
        4.     public void logV(String tag, String log) {  
         
        5.     }  
         
        6.     public void logI(String tag, String log) {  
         
        7.     } 
        8.     public void logW(String tag, String log) {  
         
        9.     }  
         
        10.     public void logE(String tag, String log) {  
         
        11.     }  
        12. });     
    
    

  * **Q：如果不在启动界面进行华为移动服务（APK）连接，如何处理？**        

为了提高HMS SDK接口的连接速度，建议在程序启动时进入第一个界面就进行华为移动服务（APK）的连接。  
如果由于业务限制，不能过早进行华为移动服务（APK）的连接，请将HMSAgent.connect调用延迟到合适的位置调用，但是必须在应用启动时用户开始操作前，由应用自动调用。         




  


# 2. 支付常见问题

  * **Q：华为IAP是否收费？**        

华为IAP免费提供给开发者使用，您的APP通过华为IAP产生的支付交易，华为会扣除一定比例渠道费用。         

  * ****Q：** 支付服务参数如何保护？**        

支付服务参数是华为IAP认证开发者身份的关键信息，如果支付服务参数泄露，会造成攻击者冒用开发者身份向华为发起支付请求，请谨慎保护。  
强烈建议开发者把支付服务参数保存在服务器，而不是保存在客户端。支付的签名、验签动作在您的服务器完成，并通过HTTPS等安全通道，将您服务器的签名、验签结果下发到客户端。         

  * ****Q：** 支付成功回调的签名在开发者服务器侧验证不通过，如何处理？**        

支付成功回调流程及常见问题可参考“[支付回调流程简介](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_video_payment_callback_process)”视频讲解。  
如果验签失败，请对以下项目进行自检：  
**1\. 检查回调结果中null和“”值是否参与验签。**  
    只要实际回调结果中携带的参数，除去sign和signtype都需要参与签名。  
    华为支付服务器不会传null和**“”** 值给CP服务器，即使开发者在支付时部分字段传null和**“”** 值，华为支付服务器在向开发者服务器发送支付结果时会自动过滤null和**“”** 值的字段。  
**2\. 检查验签失败是否是支付宝支付可以验签通过，微信支付验签失败。**  
    不同的支付方式，收到的支付回调中携带的字段是不一样的。例如微信支付方式，回调结果中会有多一个sysReserved字段，而支付宝支付方式则没有该字段，因此在解析字段时不要把key写死，需要根据回调结果中实际传入的字段解析。  
**3\. 检查是否是支付公钥导致的验签失败。  
**     支付验签使用支付公钥，在申请支付服务后获取。注意，游戏开发者请勿混淆游戏公钥和支付公钥，支付验签应该使用支付公钥。  
    公钥在传递至开发者服务器时直接使用通讯工具传递，导致公钥被转义，比如出现空格和%等字符。要求公钥传递过程中一律以文件方式传递。  
    公钥缺失，传递过程中会导致在java代码验签时会报长度不正确的异常，这时请重新从开发者联盟后台获取公钥，且以文件形式传递。在使用过程中也要检查是否缺省或者自己误添加空格等。  
**4\. 检查是否由于支付时商品描述含有“+”号的商品导致验签失败。**  
    支付时的所有字段格式，需要严格按照文档要求，特殊符号一律不准使用。由于商品描述字段或其他字段中含有+号，在回调结果中会有很大概率会被默认转义成空格导致与实际值不匹配。  
**5\. 检查是否对sign、sysReserved和extReserved参数进行urldecode处理。**      
    华为支付服务器在回调结果中传入的sign、sysReserved和extReserved参数进行了urlencode处理，其他参数均为原始数据，所以开发者服务器在获取参数后需要对sign、sysReserved和extReserved参数进行urldecode处理，其他参数不需要处理。但是由于服务器不同语言和框架，可能在获取时会多做一次urlencode或urldecode导致数据被转义，在解析时需注意。例如，Java中request的getParameter()方法会隐含进行urldecode。  
   开发者服务器可根据检查解析出来的值是否含有“%”和空格来判断是否为原始数据，含有%号说明被执行了urlencode。含有空格，说明可能执行了urldecode。  
**6\. 检查是否由于验签算法导致验签失败。**  
    签名算法需要和回调字段signtype同步，signtype=RSA256时签名算法使用SHA256WithRSA，其他任何情况都使用SHA1withRSA。其他任何情况包括signtype=RSA和实际回调结果中没有传入signType。  
    在很久之前老版本回调中signType字段是可选的，所以存在回调中没有的情况。自从2.6.1 HMS SDK版本之后signType字段已经是必选字段，意思是回调中必然存在且目前2.6.1 之后的SDK默认都是RSA256.  
        

  * ****Q：** 华为移动服务（APK）是否能在Application中连接？**  
不建议这么做，因为处理onConnectionFailed时需要依赖activity。如果开发者能确保在出现onConnectionFailed时，获取当前的activity用来拉起解决问题的界面，则可以在Application中进行connect。另外在调用接口时发现华为移动服务（APK）未连接，需要重新连接。        

  * ****Q：** 非华为手机使用华为支付，有什么要求吗？**  
非华为手机接入HMS SDK后，需要根据提示下载华为移动服务（APK），安装后即可使用华为支付。但是支付测试时需注意以下几点：  
1、建议所有测试标准以华为手机测试为准。  
2、个别非华为手机由于系统权限可能会对华为移动服务（APK）做限制，在遇到华为手机测试正常但是在非华为手机测试异常场景下可以尝试开启非华为手机的应用权限后再次测试。  
       

  * ****Q：** 客户端回调支付接口时，读取哪个字段是获取商户订单号？**  
requestId，商户侧生成的支付订单号。orderId，华为支付服务器生成的订单号。        

  * ****Q：** 华为是否提供服务端Demo？**  
服务端没有demo，只有示例代码。        

  * ****Q：** 连接华为移动服务（APK）出现907135702错误码，如何处理？**  
1、检查当前手机设备是否可以正常访问网络。2、检查是否在华为开发者联盟上配置了正确的证书指纹。登录开发者联盟，点击“管理中心”，在“应用服务”中依次点击“账号”和“支付”，点击需要检查证书指纹的应用，在“服务信息”界面检查“SHA256证书指纹”配置的信息是否和开发者生成的指纹证书一致，如果不一致请修改。        

  * ****Q：** 华为移动服务（APK）升级弹窗只显示英文，如何处理？**  
请将项目的build.gradle文件中的resconfig参数去除。对于使用jar方式接入开发的，一定要记得把res文件夹下所有资源导入。        

  * ****Q：** 华为支付SDK支持的EMUI系统最低版本是多少？**  
请使用4.2版本以上。        

  * ****Q：** 私钥和签名是否可以都在服务端执行？**  
如果私钥保存在服务端，则生成签名字符串必须在服务端进行。        

  * ****Q：** 支付的UI界面只有一种吗？是否还有其他支付界面？**  
是的，目前支付只有一种UI界面。        

  * ****Q：** 是否必须使用SHA256的证书才能通过验签？**  
是的，现在华为开发者联盟上要求配置的就是SHA256指纹。        

  * ****Q：** App签名证书的签名算法为SHA1withRSA，对应用有影响吗？**  
有，现在必须使用SHA256算法。        

  * ****Q：** 是否存在验证openid的接口？**  
目前没有提供该接口。        

  * ****Q：** 支付界面上的支付方式是否可以由开发者控制实现展现那些支付方式？**  
不能。        

  * ****Q：** 接入支付时，需要导入哪些库？**  
需要导入IAP库和Base库。        

  * ****Q：** 华为支付是否每个应用只能配置一个回调地址？**  
       

在华为开发者联盟后台只能配置一个回调地址。如需使用多个回调地址，建议在支付接口中自行传入url字段且保证开发者联盟后台回调地址栏置空（华为支付服务器优先回调开发者联盟后台配置的回调地址）。         

  * ****Q：** 支付接口中的urlVer参数填写2和不填写有什么区别？**  
       

  * 如果传递这个参数则该参数必须设置为2，否则就不传。        

  * ****Q：** 使用华为登录时，登录成功回调中获取用户信息中性别为-1，是什么原因？**  
为保护用户隐私信息，以后版本帐号信息中将不返回用户性别信息。        

  * ****Q：** 如何知道使用的是什么支付方式？**  
查看支付回调中的paytype参数的值，具体值对应的含义请参考“[支付成功回调](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s1)”。        

  * ****Q：** 华为支付方式渠道可以自定义吗？**  
不行，目前支付方式是固定的。        

  * ****Q：** 示例代码中HwPayConstant.KEY_MERCHANTID需要填写商户ID，这商户ID从哪里获取？**  
商户ID即在华为开发者联盟上获取支付服务参数中的支付ID，详细获取步骤请参见“[申请支付服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_applypayservice)”。

没有限制，金额由开发者确定。        

  * ****Q：** 支付失败返回30001错误码，如何处理？**  
请检查参与签名的参数情况：  
1、支付时携带的参数中需要参与签名的参数和sign中签名的参数个数或者参数值不一致.  
2、接口传入的sign值和原始签名出来的值不一致。  
3、支付签名应该使用支付私钥。  
4、支付私钥在传递过程中缺失或者使用通讯工具导致转义。  
5、检查算法是否使用sha256withrsa。  
6、支付签名sign中的参数需要同时满足两个条件：支付接口中实际携带了的字段；文档中要求参与签名的参数。  
支付签名的详细指导可以参见“[支付签名指导](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_vedio_payment_signature)”视频。

  * ****Q：** 签名和验签的算法有区别吗？**  
当前最新的签名算法必须是SHA256，验签可以根据回调中signType确定。signType等于RSA256时使用SHA256算法，其他情况都是用SHA1(包括实际回调中没有这个字段的情况)。主要是为了适配老板本的SDK存在SHA1的情况，目前的SDK基本都是SHA256。

  * **********Q：************************支付回调和支付验签有什么区别，又有什么关系？**  
       

支付回调是华为支付服务器回调支付结果给开发者应用的服务器；服务器验签是开发者在自己的服务器对支付回调结果进行验签。

  * ******Q ：****游戏登录是否可以使用HMS SDK中的帐号？**        

游戏开发者不需要使用HMS SDK的账号能力，但需要申请游戏服务，申请后使用login接口登录。        

  * ******Q：************游戏要求添加华为icon角标和闪屏吗？是否要求在游戏打开后出现华为游戏的logo？**  
       

没有这些要求。         

  * ******Q：************首次发布游戏，显示登录成功，但是浮标不显示，如何处理？**        

游戏上架前，只需要游戏显示悬浮的圆点即可，点击显示空白没有问题，游戏上架后将显示内容。         

  * ******Q：************之前的浮标秘钥，新版本在哪里获取？**        

新版本“浮标秘钥”修改为“游戏私钥 ”。  
登录华为开发者联盟，点击“管理中心”，选择“应用服务 > 游戏”，点击需要查询游戏私钥的游戏产品，在“服务信息”页可以获取“游戏私钥”的信息。![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200225111802.77819772701973354474595009283216:50510916032942:2800:EFEB0BDF361F758F5BE711F3A85F6483ED479E6E080A50948AC3EE9B5F7B763A.png?needInitFileName=true)         

  * ******Q：************强制更新是由华为SDK完成吗？**  
       

强制更新在应用在AppGallery Connect中提交审核时，选择强制更新的选项即可。         

  * ******Q：************单机游戏gametype参数是否只能设置为0？**        

可以设置为0，也可以设置为1，根据单机游戏的实际情况确定。         

  * ******Q：************当isAuth=0时，需要进行鉴权吗？**        

isAuth=0时，只返回playerID，如果游戏不需要鉴权，可以直接进入游戏，如果需要鉴权，可以等第二次回调结果，isAuth=1的信息。         

  * ******Q：************之前接入过老版本的SDK，如何在新版本SDK中演示大小号切换？**        

如果已有在此游戏创建过小号的华为帐号，登录游戏后会在浮标中出现切换帐号按钮，如果未在此游戏创建过小号，请在手机上先安装老版本游戏中心，在老版本SDK的游戏包上面登录帐号，创建个小号，然后在新SDK的游戏包上更新游戏中心，登录该帐号，就可以测试切换账号功能了。         

  * ******Q ：****一次登录，为什么要回调两次？**        

第一次是通知登录完成，第二次是鉴权后的回调。         

  * ******Q：************在浮标中没有找到录屏的入口，如何处理？**        

录屏需要等到游戏上线之后才能使用。         

  * ******Q：************接入华为游戏服务的单机游戏不登录可以使用华为支付吗？**        

不可以。         

  * ******Q：************游戏登录时，获得rtnCode=1，如何处理？**        

1、检查登录签名私钥或者签名算法是否正确。  
2、已经上架的游戏，请检查apk打包签名是否和上架apk签名保持一致。         

  * ******Q：************华为SDK悬浮窗里边点击帐号退出后，是否产生回调？**        

不产生回调。         

  * ******Q：************游戏强制更新下载的地址是什么？**        

接入游戏SDK的检测游戏更新接口(checkUpdate)后，游戏会提示用户更新版本，开发者不需要自己处理下载游戏安装包，如果一定要下载，下载链接为：http://appstore.huawei.com/dl/C+APPID，请将地址中APPID修改为游戏的APPID，并将中间+去除。         

  * ******Q：************登录请求返回的playerId是否为动态，并且长度有变化？**        

请以实际返回的playerId为准。

登录华为开发者联盟，点击“管理中心”，选择“应用服务 > 游戏”，点击需要查询的游戏产品，在“服务信息”页可以获取“APP SECRET”的信息。         

  * ******Q：游戏应用************如何获取CPID的信息？**        

登录华为开发者联盟，点击“管理中心”，选择“应用服务 > 支付”，点击需要查询的游戏产品，在“服务信息”页可以获取“支付ID”的信息，即为CPID。

如果游戏有新版本，SDK会有更新的提示，但是不强制游戏升级。         

  * ********Q：******************每个游戏的游戏私钥是否都不一样？**        

是的。具体以申请游戏服务时获取的游戏私钥为准。        

  * ********Q：******************在未安装华为游戏中心手机上，用户点击取消安装，游戏需要如何处理？**        

游戏开发者不需要自己去处理给出提示，只需要重新调用初始化接口，华为接口会实现弹出安装提示的功能。         

  * ********Q：******************在游戏中进行支付时，提示“登录帐号异常，请重新登录游戏”，如何处理？**        

如果没有登录就进行支付，就可能出现此情况，请先调用游戏登录接口成功后再进行支付。         

  * ********Q：******************游戏公钥和支付公钥是一样的吗？**  
       

两者不一样，“支付公钥”用于向服务端验证支付签名，“游戏公钥”用于登录验签。         

  * ********Q：******************游戏账号的用户ID是否为登录成功后返回的playerId？**        

login接口只返回**playerId** 。         

  * **********Q：************************有些手机登录失败，无法拉起游戏中心，如何处理？**        

将手机上和华为移动服务（APK），华为游戏中心相关所有权限都打开，包括游戏和游戏中心的自启动。         

  * **********Q：************************提示应用更新的弹窗是否可以去除？**        

不可以。如果游戏更新，会弹出弹窗引导玩家更新，但如果不设置强制更新，玩家可以点击取消。         

  * **********Q：************************游戏提示更新的依据是什么？**        

HMS SDK会根据versioncode判断是否需要升级，如果versioncode大于当前版本，则需要升级。versioncode由开发者在生成APK包时配置。         

  * **********Q：************************打开游戏弹出的游戏中心logo可以去除吗？**        

华为对于闪屏不做强制要求，开发者可以自己决定加或者去除。         

  * **********Q：游戏************************支付界面可以强制设置横竖屏吗？**        

支付界面横竖屏目前由HMS SDK控制。         

  * **********Q：************************游戏上传后，华为方是否会做二次签名？**  
       

不会。         

  * **********Q：************************单机游戏使用支付也需要登录吗？**        

需要，只要使用华为支付，就必须登录。

单机游戏在启动时必须调用登录接口，但是用户可以选择不登录。但是如果后面用户需要支付，则必须让用户先登录，并保证登录成功。有部分单机游戏（例如棋牌类游戏），要求必须要用户登录，请在开发时与运营人员确认。        

  * **********Q：************************玩家角色信息上报接口必接吗？**        

是的，联运服务要求网络游戏必须接入。        

  * **********Q：游戏应用的************************CPID是否是固定的？**        

是的。同一个开发者账号申请服务后的CPID是固定的。         

  * **********Q：************************单机游戏的回调地址是否可以不填写？**        

可以，这样的话，支付结果以客户端回调为准。         

  * **********Q：************************接入游戏SDK是否必须安装华为游戏中心？**        

是的，必须安装。         

  * **********Q：************************游戏是否有帐号登出的接口？**        

没有单独的接口，游戏的帐号登出需要游戏开发者自己实现。            

  * **********Q：************************游戏包升级了，需要如何提示用户更新？**        

在游戏中接入检查游戏更新接口，如果有新版本的应用在华为应用市场上线，游戏调用checkUpdate接口时HMS SDK就会提示用户更新。         

  * **********Q：******** 游戏中，已经登录的帐号如何进行切换？**        

可以使用游戏浮标中切换帐号的功能。此处的账号切换是指主子账号切换，不是指退出当前账号重新登录另一个账号。 

  * **********Q：************************游戏没有上架，如果要做更新删除，如何处理？**        

可以在AppGallery Connect中删除未发布的应用。        

  * **********Q：************************加载游戏时，是否必须弹出华为帐号登录界面？**        

如果是网游，那么需要强制登录成功；如果是单机游戏，在游戏启动时，必须调用登录接口，但是是否需要强制要求登录成功可以由应用自行规划，请开发时与运营人员确认。         

  * **********Q ：************************游戏未调用HMS SDK接口能正常启动，调用接口后，却出现启动异常（例如黑屏、卡顿等），如何处理？**  
       

出现此情况，请延迟调用HMS SDK接口（init接口除外），建议在游戏加载完成后调用。         

  * **********Q：************************为什么游戏的优惠券无法使用，在其他上线游戏是可以使用的？**        

未上线的游戏不能使用优惠券。         

  * **********Q：************************游戏的计费点如何添加？**        

如果是非托管商品支付，计费点由开发者自己确定，华为只要求计费金额保留两位小数。 如果是托管商品支付，商品金额只能在AppGallery Connect中配置商品信息时设置。       




  


# 4. 审核常见问题

  * ******Q ：****创建应用时，包名没有以.huawei或.HUAWEI结尾，怎么修改？或者支付服务的包名填错了，能删除重新填么？**        

包名一旦确定就无法修改，只能重新创建应用，配置支付服务，获取支付参数了。        

  * ******Q：************CP正式包完成，是发群里给华为人员测试审核，还是直接后台上传进行审核测试？**        

请直接上传后台。        

  * **********Q：************Provider配置有误[没有配置华为移动服务（APK）升级provider|没有配置自升级provider]被驳回，如何处理？**        

请参考“[配置工程文件 > 配置manifest文件](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameProFile)”的步骤4，校验AndroidManifest.xml文件的配置。         

  * **********Q：************接入HMS SDK中appid错误被驳回，如何处理？**        

请参考“[配置工程文件 > 配置manifest文件](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameProFile)”的步骤1，校验AndroidManifest.xml文件的配置。         

  * ****Q：** 上架的应用，修改了签名是否可以重新上架？**  
修改签名的应用不能直接上架，必须重新创建应用再上架。        

  * **********Q：************对支付结果异常情况（错误码为1005, 30005, or 30002）处理不当被驳回，如何处理？**  
       

支付需要针对超时、网络异常等情况进行处理，避免影响用户正常权益，掉单处理的详细指导可参见“[支付掉单处理指导](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_vedio_missing_order)”视频。
