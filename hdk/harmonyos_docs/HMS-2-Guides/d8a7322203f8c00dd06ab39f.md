# 1. 场景介绍

发布地区中包含中国大陆的游戏，必须集成游戏助手。游戏助手是指游戏界面中以浮标方式展示华为游戏中心的入口，用户点击浮标后可查看用户在华为游戏中心的游戏增值功能，如浏览论坛、领取礼包、查看攻略、游戏录屏等。

# 2. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200225200503.95069319147966165746252257653184:50510916032943:2800:8650FD3D936B7FF6F800E8828D2681AF274D0653CDA3D20438EEE8CBC34DA357.png?needInitFileName=true)

1\. 用户启动游戏后，游戏完成启动流程，具体参见[游戏启动](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/page%3Dhmssdk_jointOper_gameStart)。

2\. 应用调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c12)接口请求展示游戏助手浮标。

3\. HMS SDK在游戏界面展示游戏助手浮标。

4\. 用户点击游戏浮标。  
如果当前设备未安装华为游戏中心，系统将提示下载并安装华为游戏中心。

5\. HMS SDK向用户展示游戏助手页面。

6\. 用户在游戏助手页面中操作，例如查看论坛热帖、查看礼包等。

7\. HMS SDK向华为游戏中心请求相关信息。

8\. 华为游戏中心向HMS SDK返回相关信息。

9\. HMS SDK在游戏助手页面展示用户查看的信息。

10\. 用户离开当前游戏界面。

11\. 应用调用[hideFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c8)接口请求隐藏浮标。

12\. HMS SDK隐藏浮标。

# 3. 注意事项

●  游戏助手当前只为中国大陆用户提供服务，非中国大陆用户当前不支持游戏助手。发布地区没有中国大陆的游戏，开发者可以预先集成该能力，后续游戏助手为非中国大陆用户提供服务时，您的游戏无需修改即可提供游戏助手服务。  


● 游戏助手的展示和隐藏功能，在本应用的所有游戏操作界面中都要具备。

# 4. 开发步骤

游戏助手功能涉及应用的关键开发步骤如下：

1、调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c12)接口。  
应用需要在所有游戏界面Activity的onResume中调用showFloatWindow接口展示浮标。  


示例代码如下：
      
      1. protected void onResume()
        2. {
        3.     Super.onResume();
        4.     HMSAgent.Game.showFloatWindow(this);
        5. }
    
    

2、HMS SDK展示浮标，用户点击浮标打开游戏助手，并在游戏助手页面中互动，此部分由HMS SDK自行完成，开发者无需关注。

警告：

游戏调试阶段，需要测试浮标能正常拖动、隐藏，翻转手机浮标能显示。如果点击浮标界面提示“没有相关内容”或无法“无法连接服务器，请稍后重试”，是因为游戏没有上线，调试时可忽略。

  


3、调用[hideFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c8)接口。

应用需要在Activity的onPause中调用hideFloatWindow接口隐藏浮标。  


示例代码如下：
      
      1. protected void onPause()
        2. {
        3.     super.onPause();
        4.     HMSAgent.Game.hideFloatWindow(this);
        5. }
