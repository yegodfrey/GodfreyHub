# 1. 场景介绍  


用户点击应用图标打开应用，应用后台启动时需要对HMS SDK进行初始化并连接HMS Core（APK）。在应用启动成功展示首页后，应用需要检查华为应用市场是否上架了新版本应用，如果应用版本有更新，则提示用户升级应用。

说明：

游戏启动时必须检测升级，另外应用还可以提供用户主动检查升级的功能，具体参见[游戏升级](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameUpdate)。

# 2. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224200931.00880665031537611575572634810308:50510916032942:2800:E477176175EA8A076A47637309ADFB73F03E47D3B88D27E93528B92C74E1DE7D.png?needInitFileName=true)

1\. 用户在移动设备中点击应用图标打开应用启动界面。

2\. 应用执行启动程序，加载应用相关资源，具体启动程序由开发者自行完成。

3\. 应用在启动程序中调用[init](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_init)接口进行HMS SDK初始化。

4\. HMS SDK返回初始化结果。

5\. 应用在HMS SDK初始化完成后调用[connect](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_game_connect)接口请求连接HMS Core（APK）。

6\. HMS SDK返回连接结果。

7\. 应用在启动成功后展示首页，并调用[checkUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiid_api_reference_game_checkUpdate)接口请求进行应用升级。  


游戏升级的具体流程可参见[游戏升级](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameUpdate)。

# 3. 注意事项  


本场景中涉及的功能必须在应用启动时完成，而不是用户在进行登录、支付等操作时才完成，否则可能会导致应用审核被驳回。

# 4. 开发步骤

1、调用[init](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_init)接口。  
在应用的onCreate方法中调用init初始化HMS SDK。  


示例代码如下：
      
      1. public class MyApplication extends Application {
        2.     @Override
        3.     public void onCreate() {
        4.         super.onCreate();
        5.         HMSAgent.init(this);
        6.     }
        7.     @Override
        8.     public void onTerminate() {
        9.         super.onTerminate();
        10.         HMSAgent.destroy();
        11.     }
        12. }
    
    

警告：

init接口用于初始化HMS SDK，在调用其他接口之前HMS SDK必须已经初始化。

2、调用[connect](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_game_connect)接口。  


在应用启动后调用connect连接HMS Core（APK）。  


示例代码如下：
      
      1. HMSAgent.connect(this, new ConnectHandler() {
        2.      @Override
        3.      public void onConnect(int rst) {
        4.          showLog("HMS connect end:" + rst);
        5.       }
        6. });
    
    

3、调用[checkUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiid_api_reference_game_checkUpdate)接口。  


connect接口调用成功后，调用checkUpdate检查应用是否需要更新。

警告：

应用使用checkUpdate接口前必须确保已经在Manifest文件中配置了UpdateSdkFileProvider，参见[配置工程文件](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameProFile)。
      
      1. HMSAgent.checkUpdate(this, new CheckUpdateHandler() {
        2.     @Override
        3.     public void onResult(int rst) {
        4.         showLog("check app update end:" + rst);
        5.     }
        6. });
