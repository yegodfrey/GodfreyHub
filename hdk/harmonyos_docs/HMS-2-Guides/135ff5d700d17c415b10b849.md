# 1. 场景介绍

托管商品支付是指应用中的虚拟商品信息提前在华为AppGallery Connect中配置，应用在使用华为支付服务时无需传入商品价格、国家码等，华为支付系统会根据商品ID自动判断所需要支付的商品名称，货币种类以及价格等信息。

托管商品支付支持商品的全球化定价功能，华为会根据当前币种对美元的国际汇率变动进行商品价格档调整。应用从华为支付系统获取商品价格，相比于自行维护商品信息，可以避免在汇率变动价格调整时，商品价格与当前最新价格不一致。

举例：某应用使用华为商品定价系统，商品定价选择档位1，即0.99美元对应6.00元人民币，2019年1月，因美元对人民币汇率变动，定价系统调整定价档位1，调整为0.99美元对应7.00元人民币。如果开发者从华为服务端获取商品信息，可以保证应用内价格同步显示为7元人民币。

具体交互细节如下：

1、用户在浏览商品时，应用从华为服务器查询到商品信息后向用户展示商品详情和商品价格，用户选择点击购买，如左图所示。

2、应用展示华为应用内支付页面，如右图所示。

3、用户选择一种支付方式后跳转至对应支付服务商的支付页面。

4、用户付款成功后即可使用付费商品。

# 2. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224195650.89106959928393759689311333215873:50510916032943:2800:1744CE6A25EF091CDA807F5DF15341CD5834C60692512609C5F5BF52206817F2.png?needInitFileName=true)

1\. 用户进入购买页面查看商品。

2\. 应用调用[getProductDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c22)接口请求获取商品信息。

3\. HMS SDK从华为服务端获取商品详情后将其返回给应用。

4\. 应用向用户展示商品详情，包括价格、币种等。

5\. 用户选择商品后点击购买。

6\. 应用调用[productPay](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c20)接口向HMS SDK发起支付请求，调用时需要传入用于验证支付的签名字符串。

7\. HMS SDK向华为支付服务器请求验证订单信息。

8\. 华为支付服务器校验支付请求参数是否准确后并返回验证结果。

9\. HMS SDK根据验证结果确认是否向用户拉起支付页面。  
   ● 如果验证成功，应用直接向用户拉起支付方式选择页面。  
   ● 如果验证失败，直接返回相关错误码。    

10\. 用户选择一种支付方式，点击确认支付。    

11\. HMS SDK拉起对应支付方式的付款页面。    

12\. 用户确认付款。    

13\. 为了确保支付的安全性，HMS SDK根据[productPay](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c20)接口传入的sign参数向华为支付服务器请求验证签名。    

14\. 华为支付服务器向HMS SDK返回验证结果。    

15\. 确认无误后，HMS SDK执行支付。    

16\. 支付完成后HMS SDK向华为支付服务器发送支付成功消息。  
   ● 如果开发者有自己的服务器，转到下一步。  
   ● 如果开发者没有自己的服务器，直接转到19。    

17\. 华为支付服务器调用[支付成功回调](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s1)接口向开发者服务器发送支付结果。    

18\. 开发者服务器收到结果后向华为支付服务器返回响应。    

19\. HMS SDK向用户展示付款成功页面。    

20\. 用户确认成功后跳转回应用页面。    

21\. HMS SDK通过回调方式向应用返回支付结果。  
   ● 如果开发者有自己的服务器，转到下一步。  
   ● 如果开发者没有自己的服务器，如支付成功直接转到24。如果由于网络异常、应用异常退出等原因导致应用无法获取用户实际支付结果，应用可以调用[getOrderDetail](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c5)接口查询订单信息，具体流程参考[支付订单查询](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameBillQuery)。    

22\. 应用向开发者服务器验证支付结果。    

23\. 开发者服务器向应用返回真实的支付结果。    

24\. 开发者服务器向用户展示购买成功信息，并向用户发放商品。    

# 3. 注意事项        

● 必须已经提前为应用申请支付服务，参见[申请支付服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_applypayservice)。        

● 必须已经提前在AppGallery Connect中配置商品信息，参见[配置商品信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devprepare_configproduct)。  
● 托管商品支付支持的地区为“[全球价格信息](https://developer.huawei.com/consumer/cn/service/josp/agc/app/views/operate/productmng/html/price.list.html)”中所列地区。    

# 4. 开发步骤        

1、封装productDetailRequest参数，具体参数参见[getProductDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c22)接口。

        4. int random= new SecureRandom().nextInt() % 100000;

2、调用[getProductDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c22)接口并处理回调结果。  
● 如果商品查询成功，回调结果中的productList将包含待查询的商品详情，包括商品价格、币种、国家码等。  


● 如果有商品查询失败，回调结果中的failList将包含查询失败的商品ID和错误码，应用需要根据返回码处理建议进行相关的处理。        

警告：

在传入productNos时，一次最多支持查询20个商品，请勿超过上限。

3、应用向用户展示商品详情，商品价格与币种需要与接口返回的价格一致，此部分由开发者自行完成。    

4、获取支付参数。  
用户选中商品点击确认支付后，应用获取相关支付参数并封装成对象，具体需要获取的具体参数参见[productPay](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c20)接口。  


示例代码如下：
      
      1. private ProductPayRequest createProductPayReq(String productNo) {
        2.     ProductPayRequest payReq = new ProductPayRequest();
        3.     /**
        4.       * 生成requestId
        5.     */
        6.     DateFormat format = new java.text.SimpleDateFormat("yyyyMMddhhmmssSSS");
        7.     int random= new SecureRandom().nextInt() % 100000;
        8.     random = random < 0 ? -random : random;
        9.     String requestId = format.format(new Date());
        10.     requestId = String.format("%s%05d", requestId, random);
        11.     //商户ID
        12.     payReq.merchantId = cpId;
        13.     //应用ID 
        14.     payReq.applicationID = appId;
        15.     //商品编号
        16.     payReq.productNo = productNo;
        17.     //支付订单号
        18.     payReq.requestId = requestId;
        19.     //渠道号
        20.     payReq.sdkChannel = 1;
        21.     //回调接口版本号
        22.     payReq.urlVer = "2";
        23.     //商户名称，必填，不参与签名。
        24.     payReq.merchantName = "XXX Company (set as your company name here)";
        25.     //商品分类，必填，不参与签名。
        26.     payReq.serviceCatalog = "X5";  //应用设置为"X5"，游戏设置为"X6"
        27.     //商户保留信息，选填不参与签名
        28.     payReq.extReserved = "Here to fill in the Merchant reservation information";
        29.     /**     
        30.        * 此处为生成支付签名（即sign字段）的代码，参见下一步。    
        31.   */ 
        32.     return payReq;
        33. }  
    
    

5、 生成支付签名，即productPay接口的sign字段。  
● 如果支付签名在应用的服务端生成，参见[支付签名的生成方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_generateSign)中的生成规则生成。

● 如果由应用客户端生成支付签名，可以参考HMS SDK工程目录PaySignUtil.java中的rsaSign()方法生成支付签名。示例代码如下：
      
      1. payReq.sign = PaySignUtil.rsaSign(PaySignUtil.getStringForSign(payReq), pay_priv_key);
    
    

PaySignUtil.getStringForSign(payReq)返回支付参数组成的待签名字符串，pay_priv_key为支付私钥。      


说明：

如果开发者有自己的服务器，为了保证支付私钥的安全性，强烈建议在应用服务端生成签名字符串。            

6、调用productPay接口并处理回调。  
●  如果返回码为0且返回的支付结果信息不为空，应用需要参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_verifySign)对支付结果进行验签。  
    \- 如果验签成功，表示支付成功。  
    \- 如果验签失败，应用需要查询订单状态以确认支付结果。对于单机应用，只能调用[getOrderDetail](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c5)接口查询订单状态，具体流程参考[支付订单查询](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameBillQuery)。对于有开发者服务器的应用，还可以直接向开发者服务器查询支付结果，具体交互由开发者自行完成。  
●  如果返回码为30002、30005、30006、30008、30012、30013、-1005，或 onActivityResult回调参数resultCode不等于 Activity.RESULT_OK 时，应用需要查询订单状态以确认支付结果，具体流程参考[支付订单查询](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_gameBillQuery)。更详细的支付掉单处理指导可参见[支付掉单处理指导视频](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_vedio_missing_order)。  
●  其他错误码根据productPay接口中定义的返回码处理建议进行处理。

示例代码如下：

        14.                 }
        15.             } else if (retCode == HMSAgent.AgentResultCode.ON_ACTIVITY_RESULT_ERROR
        16.                         || retCode == PayStatusCodes.PAY_STATE_TIME_OUT

7、华为支付服务器调用[支付成功回调](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s1)接口向开发者服务器通知支付结果。    

说明：

本步骤仅适用有独立开发者服务器的应用，无服务器的单机应用可跳过。            

8、开发者服务器收到华为支付服务器的请求消息后，从请求消息解析支付结果参数。  


说明：

本步骤仅适用有独立开发者服务器的应用，无服务器的单机应用可跳过。            

  


警告：

开发者服务器获取支付结果参数时需注意：请求消息中sign、sysReserved和extReserved参数进行了urlencode处理，其他参数为原始信息。开发者服务器在获取参数后需要对sign、sysReserved和extReserved参数进行urldecode处理，其他参数不需要处理。            

服务端获取请求参数的JAVA示例代码如下：
      
      1. /** 
        2.  * @param request 
        3.  * @return 本接口Content-Type是：application/x-www-form-urlencoded，对所有参数，会自动进行编码，  
        4.  * 接收端收到消息也会自动根据Content-Type进行解码。 同时，接口中参数在发送端并没有进行单独的URLEncode  
        5.  * (sign和extReserved、sysReserved参数除外)，所以，在接收端根据Content-Type解码后，即为原始的参数信息。 
        6.  * 但是HttpServletRequest的getParameter()方法 
        7.  * 会对指定参数执行隐含的URLDecoder.decode(),所以参数中如果包含比如"%"，就会发生错误。  
        8.  * 因此，我们建议通过request.getInputStream()方法获取原始参数信息。*  
        9.  * 注意：使用如下方法必须在原始ServletRequest未被处理的情况下进行，否则无法获取到信息。比如  
        10.  * 在Struts情况，由于struts层已经对参数进行若干处理，  
        11.  * http中InputStream中其实已经没有信息，因此，本方法不适用。要获取原始信息  
        12.  * ，必须在原始的，未经处理的ServletRequest中进行。  
        13.  */ 
        14. public Map<String, Object> getValue(HttpServletRequest request) {
        15.    String line = null;
        16.    StringBuffer sb = new StringBuffer();
        17.    try {
        18.       request.setCharacterEncoding("UTF-8");
        19.       InputStream stream = request.getInputStream();
        20.       InputStreamReader isr = new InputStreamReader(stream);
        21.       BufferedReader br = new BufferedReader(isr);
        22.       while ((line = br.readLine()) != null) {
        23.            sb.append(line).append("\r\n");
        24.       }
        25.       System.out.println("The original data is : " + sb.toString());
        26.       br.close();
        27.    } catch (Exception e) {
        28.       e.printStackTrace();
        29.    } catch (Throwable e) {
        30.       e.printStackTrace();
        31.    }
        32.    String str = sb.toString();
        33.     /**
        34.      * @param valueMap  解析获取实际回调中含有的字段值，且sign，extReserved(有值的情况)，sysReserved(有值的情况)需要进行Urldecode处理。
        35.      */
        36.    Map<String, Object> valueMap = new HashMap<String, Object>();
        37.    if (null == str || "".equals(str)) {
        38.       return valueMap;
        39.    }
        40.    String[] valueKey = str.split("&");
        41.    for (String temp : valueKey) {
        42.       String[] single = temp.split("=");
        43.       valueMap.put(single[0], single[1]);
        44.    }
        45.    System.out.println("The parameters in map are : " + valueMap);
        46.    // 接口中， sign、extReserved和sysReserved是URLEncode的，所以需要decode，其他参数直接是原始信息发送，不需要decode
        47.    try {
        48.       String sign = (String) valueMap.get("sign");
        49.       String extReserved = (String) valueMap.get("extReserved");
        50.       String sysReserved = (String) valueMap.get("sysReserved");
        51.       if (null != sign) {
        52.         sign = URLDecoder.decode(sign, "utf-8");
        53.         valueMap.put("sign", sign);
        54.       }
        55.       if (null != extReserved) {
        56.         extReserved = URLDecoder.decode(extReserved, "utf-8");
        57.         valueMap.put("extReserved", extReserved);
        58.       }
        59.       if (null != sysReserved) {
        60.         sysReserved = URLDecoder.decode(sysReserved, "utf-8");
        61.         valueMap.put("sysReserved", sysReserved);
        62.       }
        63.    } catch (Exception e) {
        64.       e.printStackTrace();
        65.    } 
        66.    return valueMap;
        67. } 
    
    

9、开发者服务器获取参数后参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_verifySign)对支付结果进行验签，验签成功后才能返回成功。    

10、开发者服务器验签完毕后，严格按照[支付成功回调](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s1)接口约定的返回码向华为支付服务器返回结果。    

说明：

本步骤仅适用有独立开发者服务器的应用，无服务器的单机应用可跳过。            

开发者可以在开发过程中参考[服务端回调接口测试](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_serverInterfaceTest)中的方法提前测试接口响应消息是否满足华为要求。        

返回消息示例：        
      
      1. HTTP/1.1 201 Created 
        2. Content Type : application/json ; charset=UTF-8 
        3. { 
        4. "result":0 
        5. }

说明：

本步骤仅适用有独立开发者服务器的应用，无服务器的单机应用可跳过。            

12、应用收到支付成功的结果后，向用户展示购买商品成功界面，并向用户发放商品，此步骤由开发者自行完成。
