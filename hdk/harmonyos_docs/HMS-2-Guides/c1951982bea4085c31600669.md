# 1. 场景介绍

非托管商品支付是指应用中的虚拟商品信息不在华为AppGallery Connect中录入，由开发者自行管理，在使用华为支付服务时开发者需自行传入商品价格。非托管商品支付无法支持商品信息自动全球化能力，如果涉及多国家、多币种的支付形式，需要开发者自行区分。

具体交互细节如下：

1、应用在界面中自行展示商品详情和商品价格，用户选择点击购买，如左图所示。

2、应用展示华为应用内支付页面，如右图所示。

3、用户选择一种支付方式后跳转至对应支付服务商的支付页面。

4、用户付款成功后即可使用付费商品。

# 2. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224200324.10194861909469940426117649389150:50510916032943:2800:A1B876A027086D91B991BC6D68B6B14C7CB5C890E57D0762858664F24547537C.png?needInitFileName=true)

1\. 用户进入购买页面后，应用向用户展示商品详情和商品价格。

2\. 用户选择商品后点击购买。

3\. 应用调用[pay](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c10)接口向HMS SDK发起支付请求。

4\. HMS SDK向华为支付服务器请求验证订单信息。

5\. 华为支付服务器校验支付请求参数是否准确后并返回验证结果。

6\. HMS SDK根据验证结果确认是否向用户拉起支付页面。  
   ● 如果验证成功，应用直接向用户拉起支付方式选择页面。  
   ● 如果验证失败，直接返回相关错误码。

7\. 用户选择一种支付方式，点击确认支付。

8\. HMS SDK拉起对应支付方式的付款页面。

9\. 用户确认付款。

10\. 为了确保支付的安全性，HMS SDK向华为支付服务器请求验证签名。

11\. 华为支付服务器向HMS SDK返回验证结果。

12\. 确认签名无误后，HMS SDK执行支付。

13\. 支付完成后HMS SDK向华为支付服务器发送支付成功消息。  
   ● 如果开发者有自己的服务器，转到下一步。  
   ● 如果开发者没有自己的服务器，直接转到16。

14\. 华为支付服务器调用[支付成功回调](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s1)接口向开发者服务器发送支付结果。

15\. 开发者服务器收到结果后向华为支付服务器返回响应。

16\. HMS SDK向用户展示付款成功页面。

17\. 用户确认成功后跳转回应用页面。

18\. HMS SDK通过回调方式向应用返回支付结果。  
   ● 如果开发者有自己的服务器，转到下一步。  
   ● 如果开发者没有自己的服务器，如果支付成功则直接转到21。如果由于网络异常、应用异常退出等原因导致应用无法获取用户实际支付结果，应用可以调用[getOrderDetail](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c5)接口查询订单信息，具体流程参考[支付订单查询](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_appBillQuery)。

19\. 应用向开发者服务器验证支付结果。

20\. 开发者服务器向应用返回真实的支付结果。

21\. 应用向用户展示购买成功信息，并向用户发放商品。

# 3. 注意事项

● 必须已经提前为应用申请支付服务，参见[申请支付服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_applypayservice)。

● 非托管商品支付，只支持发布区域只有中国大陆的应用。只要发布区域包含中国大陆以外地区的应用，必须接入[托管商品支付](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_appProductPay)。

# 4. 开发步骤

非托管商品支付功能涉及应用的关键开发步骤如下：

1、展示商品详情。  
应用在用户进入商品页面时向用户展示商品详情，此部分由开发者自行完成。

2、获取支付参数。  
用户选中商品点击确认支付后，应用获取相关支付参数并封装成对象，具体需要获取的具体参数参见[pay](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c10)接口。  


示例代码如下：
      
      1. private PayReq createPayReq(float totalAmount) {
        2.         PayReq payReq = new PayReq();
        3.         /**
        4.          * 生成requestId
        5.          */
        6.         DateFormat format = new java.text.SimpleDateFormat("yyyyMMddhhmmssSSS");
        7.         int random= new SecureRandom().nextInt() % 100000;
        8.         random = random < 0 ? -random : random;
        9.         String requestId = format.format(new Date());
        10.         requestId = String.format("%s%05d", requestId, random);
        11.         //生成商品总金额
        12.         String amount = String.format("%.2f", totalAmount);
        13.         //商品名称
        14.         payReq.productName = "test product";
        15.         //商品描述 | Product Description
        16.         payReq.productDesc = "test product description";
        17.         // 应用ID
        18.         payReq.applicationID = appId;
        19.         // 支付订单号
        20.         payReq.requestId = requestId;
        21.         // 支付金额
        22.         payReq.amount = amount;
        23.         // 商户ID，来源于开发者联盟的“支付ID”
        24.         payReq.merchantId = cpId;
        25.         //商品分类，必填，不参与签名。该字段会影响风控策略 
        26.         payReq.serviceCatalog = "X5";
        27.         // 商户名称，必填，不参与签名。会显示在支付结果页面
        28.         payReq.merchantName = "XXX Company (set as your company name here)";
        29.         // 渠道号
        30.         payReq.sdkChannel = 1;
        31.         //币种
        32.         payReq.currency = "CNY";
        33.         //国家码
        34.         payReq.country = "CN";
        35.         //回调接口版本号
        36.         payReq.urlVer = "2";
        37.         //商户保留信息，选填不参与签名
        38.         payReq.extReserved = "Here to fill in the Merchant reservation information";
        39.         /*此处为生成签名字符串的代码，参见步骤2*/
        40.         return payReq;
        41. }
    
    

3、生成支付签名，即pay接口的sign字段。  
● 如果由应用服务端生成支付签名，参见[支付签名的生成方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_generateSign)中的生成规则生成。  
● 如果由应用客户端直接生成支付签名，可以参考HMS SDK工程目录PaySignUtil.java中的rsaSign()方法生成支付签名。示例代码如下：
      
      1. payReq.sign = PaySignUtil.rsaSign(PaySignUtil.getStringForSign(payReq), pay_priv_key);
    
    

PaySignUtil.getStringForSign(payReq)返回支付参数组成的待签名字符串，pay_priv_key为RSA支付私钥。

4、调用pay接口并处理回调。  
●  如果返回码为0且返回的支付结果信息不为空，应用需要参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_verifySign)对支付结果进行验签。  
   − 如果验签成功，表示支付成功。  
   − 如果验签失败，应用需要查询订单状态以确认支付结果。对于单机应用，只能调用[getOrderDetail](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c5)接口查询订单状态，具体流程参考[支付订单查询](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_appBillQuery)。对于有开发者服务器的应用，除了调用getOrderDetail接口，还可以向开发者服务器查询订单状态，具体交互由开发者自行完成。  
●  如果返回码为30002、30003、30005、30006、30008、30010、30012、30013、30014、-1005，或onActivityResult回调参数resultCode不等于 Activity.RESULT_OK 时，应用需要查询订单状态以确认支付结果，具体流程参考[支付订单查询](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_appBillQuery)。更详细的支付掉单处理指导可参见[支付掉单处理指导视频](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_vedio_missing_order)。  
●  其他错误码根据pay接口中定义的返回码处理建议进行处理。  


示例代码如下：
      
      1. PayReq payReq = createPayReq(amount);
        2.       HMSAgent.Pay.pay(payReq, new PayHandler() {
        3.           @Override
        4.           public void onResult(int retCode, PayResultInfo payInfo) {
        5.           if (retCode == HMSAgent.AgentResultCode.HMSAGENT_SUCCESS && payInfo != null) {
        6.              // 校验签名
        7.        boolean checkRst = PaySignUtil.checkSign(payInfo, pay_pub_key);
        8.              showLog("pay: onResult: pay success and checksign=" + checkRst);
        9.              if (checkRst) {
        10.                 // TODO: 支付成功并且验签成功，发放商品。
        11.              } else {
        12.                 // TODO: 签名失败，需要查询订单状态。
        13.              }
        14.               } else if (retCode == HMSAgent.AgentResultCode.ON_ACTIVITY_RESULT_ERROR
        15.                         || retCode == PayStatusCodes.PAY_STATE_TIME_OUT
        16.                         || retCode == PayStatusCodes.PAY_STATE_NET_ERROR) {
        17.                  // TODO: 需要查询订单状态。 
        18.                 } else {
        19.                     showLog("pay: onResult: pay fail=" + retCode);
        20.                     // 其他错误码意义参照支付api参考
        21.                 }
        22.             }
        23.         });
        24.         //将requestid缓存，供查询订单
        25.         addRequestIdToCache(payReq.getRequestId());
        26. }
    
    

5、华为支付服务器调用[支付成功回调](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s1)接口向开发者服务器通知支付结果。

6、开发者服务器收到华为支付服务器的请求消息后，从请求消息解析支付结果参数，并对支付结果进行验签。

说明：

本步骤仅适用有独立开发者服务器的应用，无服务器的单机应用可跳过。

警告：

开发者服务器获取支付结果参数时需注意：请求消息中sign、sysReserved和extReserved参数进行了urlencode处理，其他参数为原始信息。开发者服务器在获取参数后需要对sign、sysReserved和extReserved参数进行urldecode处理，其他参数必须使用原始信息。

服务端获取请求参数的JAVA示例代码如下：
      
      1. /** 
        2.  * @param request 
        3.  * @return 本接口Content-Type是：application/x-www-form-urlencoded，对所有参数，会自动进行编码，  
        4.  * 接收端收到消息也会自动根据Content-Type进行解码。 同时，接口中参数在发送端并没有进行单独的URLEncode  
        5.  * (sign和extReserved、sysReserved参数除外)，所以，在接收端根据Content-Type解码后，即为原始的参数信息。 
        6.  * 但是HttpServletRequest的getParameter()方法 
        7.  * 会对指定参数执行隐含的URLDecoder.decode(),所以参数中如果包含比如"%"，就会发生错误。  
        8.  * 因此，我们建议通过request.getInputStream()方法获取原始参数信息。*  
        9.  * 注意：使用如下方法必须在原始ServletRequest未被处理的情况下进行，否则无法获取到信息。比如  
        10.  * 在Struts情况，由于struts层已经对参数进行若干处理，  
        11.  * http中InputStream中其实已经没有信息，因此，本方法不适用。要获取原始信息  
        12.  * ，必须在原始的，未经处理的ServletRequest中进行。  
        13.  */ 
        14. public Map<String, Object> getValue(HttpServletRequest request) {
        15.    String line = null;
        16.    StringBuffer sb = new StringBuffer();
        17.    try {
        18.       request.setCharacterEncoding("UTF-8");
        19.       InputStream stream = request.getInputStream();
        20.       InputStreamReader isr = new InputStreamReader(stream);
        21.       BufferedReader br = new BufferedReader(isr);
        22.       while ((line = br.readLine()) != null) {
        23.            sb.append(line).append("\r\n");
        24.       }
        25.       System.out.println("The original data is : " + sb.toString());
        26.       br.close();
        27.    } catch (Exception e) {
        28.       e.printStackTrace();
        29.    } catch (Throwable e) {
        30.       e.printStackTrace();
        31.    }
        32.    String str = sb.toString();
        33.     /**
        34.      * @param valueMap  解析获取实际回调中含有的字段值，且sign，extReserved(有值的情况)，sysReserved(有值的情况)需要进行Urldecode处理。
        35.      */
        36.    Map<String, Object> valueMap = new HashMap<String, Object>();
        37.    if (null == str || "".equals(str)) {
        38.       return valueMap;
        39.    }
        40.    String[] valueKey = str.split("&");
        41.    for (String temp : valueKey) {
        42.       String[] single = temp.split("=");
        43.       valueMap.put(single[0], single[1]);
        44.    }
        45.    System.out.println("The parameters in map are : " + valueMap);
        46.    // 接口中， sign、extReserved和sysReserved是URLEncode的，所以需要decode，其他参数直接是原始信息发送，不需要decode
        47.    try {
        48.       String sign = (String) valueMap.get("sign");
        49.       String extReserved = (String) valueMap.get("extReserved");
        50.       String sysReserved = (String) valueMap.get("sysReserved");
        51.       if (null != sign) {
        52.         sign = URLDecoder.decode(sign, "utf-8");
        53.         valueMap.put("sign", sign);
        54.       }
        55.       if (null != extReserved) {
        56.         extReserved = URLDecoder.decode(extReserved, "utf-8");
        57.         valueMap.put("extReserved", extReserved);
        58.       }
        59.       if (null != sysReserved) {
        60.         sysReserved = URLDecoder.decode(sysReserved, "utf-8");
        61.         valueMap.put("sysReserved", sysReserved);
        62.       }
        63.    } catch (Exception e) {
        64.       e.printStackTrace();
        65.    } 
        66.    return valueMap;
        67. }
    
    

7、开发者服务器获取参数后参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_verifySign)对支付结果进行验签，验签成功后才能返回成功。

8、开发者服务器验签完毕后，严格按照[支付成功回调](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s1)接口约定的返回码向华为支付服务器返回结果。

说明：

本步骤仅适用有独立开发者服务器的应用，无服务器的单机应用可跳过。

  


开发者可以在开发过程中参考[服务端回调接口测试](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_serverInterfaceTest)中的方法提前测试接口响应消息是否满足华为要求。

返回消息示例：
      
      1. HTTP/1.1 201 Created 
        2. Content Type : application/json ; charset=UTF-8 
        3. { 
        4. "result":0 
        5. }
    
    

9、应用客户端在收到HMS SDK返回的支付回调结果后，向开发者服务器请求查询真实的支付结果。开发者客户端与服务端之间的支付验证机制由开发者自行开发。

说明：

本步骤仅适用有独立开发者服务器的应用，无服务器的单机应用可跳过。

10、应用收到支付成功的结果后，向用户展示购买商品成功界面，并向用户发放商品，此步骤由开发者自行完成。
