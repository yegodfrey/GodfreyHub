# 1. 检查应用类型  


由于应用创建后应用类型不可更改，在正式开发联运应用之前，请确保应用的类型为“应用”。

1、登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的应用”。

2、点击应用对应的“移动应用”链接。

3、在“分发 > 应用上架 > 应用信息”中查看“应用分类”，确保类型为“应用”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224201629.96303431918394516597643983250896:50510916032942:2800:4AE624218A069ED06F0C3DC286A030F034D31ED04A7ED46F86804FE5ACD2CFC2.png?needInitFileName=true)

如果应用分类不是“应用”，则需要参考[创建应用](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_createapp)重新创建应用，并申请相关服务。

# 2. 准备应用参数  


在开发联运应用前，请确保下表所示信息已经具备。

---|---|---|---  
公共| Keystore-file| 文件| 自行创建。  
应用ID| 字符串| 应用服务详情，获取方法参考[查询应用ID](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_queryappid)。
