在接口调用过程中，请求方在获取接收方的响应结果后，如果响应结果中包含了接收方返回的签名字符串，请求方可以对签名字符串进行验签，确认响应结果是否被篡改，保证接口调用的安全性。

# 在应用客户端验签

如果应用直接在客户端验签，可以参考HMS SDK工程目录PaySignUtil.java中的checkSign(result, pay_pub_key)方法验签。result为响应结果对象，paypub_key为支付公钥。

说明：

支付公钥在申请支付服务后生成，查询方法参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_querypayinfo)。

以getOrderDetail接口返回消息的验签为例，示例代码如下：
      
      1. HMSAgent.Pay.getOrderDetail(or, new GetOrderHandler() {
        2.     @Override
        3.     public void onResult(int retCode, OrderResult checkPayResult) {
        4.         showLog("checkPay: requId="+reqId+"  retCode=" + retCode);
        5.         if (checkPayResult != null && checkPayResult.getReturnCode() == retCode) {
        6.             if (retCode == HMSAgent.AgentResultCode.HMSAGENT_SUCCESS) {      
        7.                 //对查询结果验签
        8.                 boolean checkRst = PaySignUtil.checkSign(checkPayResult, pay_pub_key);
        9.                 if (checkRst) {
        10.                     //验签成功
        11.                 } else {
        12.                      //验签失败
        13.                 }
        14.             …
        15.    }
        16. });
    
    

# 在应用服务端验签

如果应用需要在服务端验签，需要参考以下步骤完成验签。

1、获取返回结果中的签名字符串，即接口（例如getOrderDetail接口）返回的sign字段。

2、将返回参数中需要参与签名的参数，按参数名首字母的ASCII码将参数升序排序，若遇到相同首字母，则比较第二个字母，以此类推。  
需要参与签名的参数是指接口说明中“是否参与验签”列为“是”且实际返回结果中携带了该参数，并且参数值不为空（null或""）。

说明：

“是否参与验签”列为“是”但实际未返回的参数，请勿参与排序。

3、排序完成之后，将所有参与签名的参数名和参数值的键值对以“&”字符连接成字符串，例如“a=xxxxxx&b=xxxxxxx&c=xxxxxxxxxxx...”。

注意：

拼接字符串需注意：  
●参数名和参数值请勿进行urlencode。  
●参数值必须与响应消息中的实际参数值保持一致。

JAVA示例代码如下：
      
      1. /**
        2.  * 根据参数map获取待签名字符串
        3.  * @param params 待签名参数map
        4.  * @param includeEmptyParam 是否包含值为空的参数：
        5.  *                          与HMS-SDK支付能力交互的签名或验签，需要为false（不包含空参数）
        6.  *                          由华为支付服务器回调给开发者的服务器的支付结果验签，需要为true（包含空参数）
        7.  * @return 待签名字符串
        8.  */
        9. private static String getNoSign(Map<String, Object> params, boolean includeEmptyParam) {
        10.     StringBuilder content = new StringBuilder();
        11.     // 按照key做排序
        12.     List<String> keys = new ArrayList<String>(params.keySet());
        13.     Collections.sort(keys);
        14.     String value = null;
        15.     Object object = null;
        16.     boolean isFirstParm = true;
        17.     for (int i = 0; i < keys.size(); i++) {
        18.         String key = (String) keys.get(i);
        19.         object = params.get(key);
        20.         if (object == null) {
        21.             value = "";
        22.         }else if (object instanceof String) {
        23.             value = (String) object;
        24.         } else {
        25.             value = String.valueOf(object);
        26.         }
        27.         //拼接成key=value&key=value&....格式的字符串
        28.         if (includeEmptyParam || !TextUtils.isEmpty(value)) {
        29.             content.append((isFirstParm ? "" : "&") + key + "=" + value);
        30.             isFirstParm = false;
        31.         } else {
        32.             continue;
        33.         }
        34.     }
        35.     android.util.Log.e("content.toString()==:", content.toString());
        36.     //待签名的字符串
        37.     return content.toString();
        38. }
    
    

说明：

如果返回参数中包含对象类型的参数，需要参考如下方法拼接待签名字符串：  
a. 将除了对象类型参数的其他参数排序并拼接成字符串。  
b. 将对象中的属性与属性值排序并使用“&”拼接成字符串。  
 如果对象为数组，则需要将数组中每个记录分别排序拼接，最后使用“&”拼接成总的字符串。  
c. 将步骤b得到的字符串使用“&”拼接到步骤a字符串的最后。

4、使用支付公钥对待验签字符串和响应消息的签名字符串进行验证。

说明：

支付公钥在申请支付服务后生成，查询方法参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_querypayinfo)。

JAVA示例代码如下：
      
      1. /** 
        2.  * 校验签名信息 
        3.  * @param  content 待校验字符串 
        4.  * @param sign  签名字符串 
        5.  * @param publicKey 公钥 
        6.  * @param signType 加密类型 
        7.  * @param 是否校验通过 
        8. */
        9. public static boolean doCheck(String content, String sign, String publicKey, String signtype) {
        10.    try {
        11.       KeyFactory keyFactory = KeyFactory.getInstance("RSA");
        12.       byte[] encodedKey = decoder.decode(publicKey);
        13.       PublicKey pubKey = keyFactory.generatePublic(new X509EncodedKeySpec(encodedKey));
        14.       java.security.Signature signature = null;
        15.       if ("RSA256".equals(signtype)) {
        16.         signature = java.security.Signature.getInstance(SIGN_ALGORITHMS256);
        17.       } else {
        18.         signature = java.security.Signature.getInstance(SIGN_ALGORITHMS);
        19.       }       
        20.       signature.initVerify(pubKey);
        21.       signature.update(content.getBytes("utf-8"));
        22.       boolean bverify = signature.verify(decoder.decode(sign));
        23.       return bverify;
        24.    } catch (Exception e) {
        25.       e.printStackTrace();
        26.    }
        27.    return false;
        28. }
