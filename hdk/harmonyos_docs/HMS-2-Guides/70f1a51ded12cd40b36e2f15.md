# 新版本优势说明

尊敬的华为开发者，您好：

感谢您一直以来对Account Kit的关注与支持。

Account Kit历经几次大的版本迭代更新，目前已经迭代到5.0版本，2.0版本的开发者资料已做废弃处理，不再继续维护。

相比2.0版本，5.0版本的Account Kit给开发者提供了更强大的功能，举例如下：

  * 更快速的集成SDK和方便的快捷登录 
  * 支持ID Token和Authorization Code两种模式的登录 
  * 支持华为帐号取消授权 
  * 支持自动读取短信验证码 
  * 支持手机、平板、智慧屏等多设备 



有关更多更详细的功能说明请参见[华为帐号服务5.0文档](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050048870)。

# 客户端升级指导

Android Studio开发环境下我们从以下几个方面来进行升级指导。

#### Gradle文件

打开应用级的“build.gradle”文件，删除对Account Kit 2.0版本的依赖，并新增对5.0版本的依赖。如下：
    
    
    dependencies {
         implementation 'com.huawei.android.hms:hwid:{version}' //mobile phones, tablets 2.0 delete
         implementation 'com.huawei.android.hms:hwid-tv:{version}' //smart screens 2.0 delete
         implementation 'com.huawei.hms:hwid:{version}'  //5.0 add
    }

#### 代码

  * **步骤1**  删除工程中所有HMS SDK Agent套件代码。 
  * **步骤2**  将登录的代码替换，具体参见[客户端升级变更说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/account_upgrade_guide#h1-1599805156050-0)。 
  * **步骤3**  将登出的代码替换，具体参见[客户端升级变更说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/account_upgrade_guide#h1-1599805156050-0)。 
  * **步骤4**  实现华为帐号快捷登录。 



#### 5.0版本详细接入

5.0版本详细接入请参见[华为帐号服务5.0文档](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050048870)。

# 服务端升级指导

#### 场景描述

若您在2.0版本使用unionID作为用户的唯一标识，则继续推荐使用unionID。

若您在2.0版本使用UID作为用户的唯一标识，则推荐使用unionID。获取unionID的方法如下：

  * 调用下面接口通过UID和Access Token获取unionID。

  * 调用[解析凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-gettokeninfo-0000001050050585)接口通过Access Token和open ID在华为帐号服务器进行获取unionID。




#### 接口原型

承载协议                  |  HTTPS POST  
---|---  
接口方向                  |  开发者服务器->华为帐号服务器                   
接口URL                  |  https://oauth-api.cloud.huawei.com/rest.php?nsp_svc=huawei.oauth2.app.getUnionID  
数据格式                  |  请求消息：Content-type: application/x-www-form-urlencoded                  响应消息：Content-Type: application/json;charset=UTF-8  
  
#### 请求参数

**Request Header**

参数 |  是否必选 |  参数类型 |  描述  
---|---|---|---  
Content-type |  否 |  String |  取值为：application/x-www-form-urlencoded。  
  
**Request Body**

参数                  |  是否必选 |  参数类型 |  描述  
---|---|---|---  
uid |  是 |  long |  用户的uid。  
access_token |  是 |  string |  应用级Access Token。  
  
#### 请求示例
    
    
    POST oauth-api.cloud.huawei.com/rest.php?nsp_svc=huawei.oauth2.app.getUnionID HTTP/1.1
    Host: account.cloud.huawei.com
    Content-Type: application/x-www-form-urlencodeduid=890086000000004083&access_token=CV3LzWFsqxABJQivQip4NEt8SmFjCaiv7AvSH6PDtjVB9Qy5scfXKuLVtMB1336fZzSPUT7uP7uK%2bmHgz4Oq8kL%2bn8So%2be2lqLt7RtHzo03AallH

#### 响应参数

调用成功时，返回如下：

**Response Header**

参数 |  是否必选 |  参数类型 |  描述  
---|---|---|---  
Content-type |  否 |  string |  取值为：application/json;charset=UTF-8。  
  
**Response Body**

参数                  |  是否必选 |  参数类型 |  描述  
---|---|---|---  
unionid |  是 |  string |  用户在应用App上登录产生的unionid。  
  
#### 响应示例
    
    
    HTTP/1.1 200 OK
    Content-Type: application/json;charset=UTF-8
    {
        "unionid":"MDF0qg244eUh0ffu5sgyDVuxjy5ZhBwNeSbCEicSgA9qRnQ"
    }
