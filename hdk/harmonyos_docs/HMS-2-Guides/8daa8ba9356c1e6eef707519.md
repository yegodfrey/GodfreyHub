# 1\. 自检Checklist

为尽早发现问题，尽量减少开发者集成业务提交审核后被打回的概率，HUAWEI HMS Core业务提供了提交审核前自检checklist。请下载“[消息推送服务开发自检Checklist.xlsx](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/00c0c5a1-feea-43a5-8c19-273223693ee0.xlsx)”进行自检，检查通过后，再提交上架应用。
