[问题二] 用户的AccessToken有效期是多长时间？

用户的AccessToken为1个小时的有效期。

* * *

[问题三] 用户的AccessToken过期后怎么处理？

重新调用登录接口signIn接口，不需要用户重新授权。

在signIn接口中，使用addScope可以传入新的需要授权的Scope，会返回授权页面的Intent，你通过startActivityForResult打开授权页面，让用户重新授权。

* * *

[问题四] 如何管理HUAWEIApiClient的生命周期？

HUAWEIApiClient需要调用connect开始生命周期，调用disconnect结束生命周期。connect和disconnect必须成对使用。比如在onCreate中调用connect并在onDestory中调用disconnect，又或者在onStart中调用connect并在onStop中调用disconnect。登录界面不建议开发者在onStart中调用client.connect以及在onStop中调用client.disConnnect。这样会导致开发者在onActivityReuslt中调用登录接口失败。建议处理方式：开发者在onCreate中调用client.connect以及在onDestory中调用client.disConnnect。

[问题五] 取消HMS Core（APK）升级后，调用接口无反应，如何处理？

请检查调用接口前，HUAWEIApiClient未连接的时候，是否进行重新连接的处理。示例代码如下：
      
      1. private void signIn() {
        2.     if(!client.isConnected()) {
        3.         Log.i(TAG, "支付失败，原因：HUAWEIApiClient未连接");
        4.         client.connect();
        5.         return;
        6.     }
        7.     PendingResultsignInResult = HUAWEIId. HUAWEIIdApi.signIn(client);
        8.     signInResult.setResultCallback(new SignInResultCallback());
        9. }

[问题六] HMS Core（APK）是否能在Application中连接？

不建议这么做，因为处理onConnectionFailed时需要依赖activity。如果开发者能确保在出现onConnectionFailed时，获取当前的activity用来拉起解决问题的界面，则可以在Application中进行connect。另外在调用接口时发现HMS Core（APK）未连接，需要重新连接。

* * *

[问题七] 应用开发者是否需要对登录接口获取的ACCESSTOKEN进行验签？

应用通过登录接口返回值中获取的ACCESSTOKEN由HMS Core（APK）进行有效性验证，只有合法有效的ACCESSTOKEN才会返回给应用，所以应用不需要对ACCESSTOKEN进行验签，可以直接使用。

* * *

[问题八] 接入华为帐号，是否可以获取UID？

不可以，由于需要隐私保护，接入华为帐号后只能获取openid。

* * *

[问题九]不同的应用接入华为帐号登录，是否返回同一openid？

不是，不同应用登录同一华为帐号获取的openid不一样，openid是应用内的唯一标识。
