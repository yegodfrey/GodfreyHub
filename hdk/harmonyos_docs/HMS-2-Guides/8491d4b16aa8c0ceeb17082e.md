# 场景介绍

华为帐号是用户访问华为云业务的凭证，拥有华为帐号的用户，可以使用华为云业务，如华为云服务、华为游戏中心、华为应用市场等。华为帐号登录是指开发者在为应用申请了华为帐号服务后，华为基于OAuth2.0协议标准经过用户的授权，允许应用使用用户的华为帐号信息。通过华为帐号服务，开发者可以安全快速的获取用户，共享华为庞大的用户资源。具体交互细节如下：

1、用户在应用界面中选择华为帐号登录方式。  
● 如果用户在当前设备未登录华为帐号，应用界面将展示华为帐号登录页面，如左图所示。  
● 如果用户在当前设备已经登录华为帐号但未进行授权，应用界面将展示华为帐号授权页面，如中图所示。  
● 如果用户在当前设备已经登录且授权，则应用可直接获取用户信息。

2、用户在华为帐号登录页面登录成功并进行登录授权后，应用展示获取到的用户信息（头像、用户昵称），如右图所示。

# 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200221174556.75169745612036219659395493318811:50510916032943:2800:298079D2AD1C8D16D8FBB45BBD9E2D5A395204DAE59FD3D144A960E14797BC31.png?needInitFileName=true)

  


1\. 用户进入应用登录界面，选择华为帐号登录方式登录。

2\. 应用调用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口向HMS SDK请求进行华为帐号登录。

3\. HMS SDK检查用户的华为帐号登录情况。

 如果用户在当前终端未登录华为帐号，转到4。否则，转到6。

4\. HMS SDK向用户拉起华为帐号登录页面。

5\. 用户输入华为帐号名和密码后确认登录。

6\. HMS SDK检查华为帐号登录授权情况。

如果用户未授权，转到7。否则，转到9。

7\. HMS SDK向用户拉起华为帐号登录授权页面。

8\. 用户点击“授权并登录”。

9\. 登录授权成功，HMS SDK向应用返回用户的华为帐号信息，包括用户昵称和头像。

# 开发步骤

华为帐号登录功能涉及应用的关键开发步骤如下：

1、展示华为登录方式图标。  
应用在登录页面展示华为帐号登录方式的图标，华为登录方式图标规范可参考[华为图标规范](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_icon_rules)。

2、调用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口。  
在用户选择华为帐号登录方式后，应用调用signIn接口并处理结果回调。  
● 如果希望HMS SDK显式拉起华为帐号登录和授权页面，forceLogin传入True。  
● 如果不希望HMS SDK拉起华为帐号登录和授权页面，forceLogin传入False。如果用户在当前设备未登录华为帐号或未授权，signIn接口会直接返回2001（未登录）或2002（未授权）错误码。应用可根据应用的实际情况决定是否需要重新调用signIn接口。  
示例代码如下：
      
      1. private void signIn(boolean forceLogin) {
        2.     HMSAgent.Hwid.signIn(forceLogin, new SignInHandler() {
        3.         @Override
        4.        public void onResult(int rtnCode, SignInHuaweiId signInResult) {
        5.           if (rtnCode == HMSAgent.AgentResultCode.HMSAGENT_SUCCESS && signInResult != null) {
        6.                //可以获取帐号的 openid，昵称，头像 at信息
        7.                showLog("signIn successful=========");
        8.                showLog("Nickname:" + signInResult.getDisplayName());
        9.                showLog("openid:" + signInResult.getOpenId());
        10.                showLog("accessToken:" + signInResult.getAccessToken());
        11.                showLog("Head pic URL:" + signInResult.getPhotoUrl());
        12.                showLog("unionID:" + signInResult.getUnionId());
        13.               } else {
        14.                     showLog("signIn---error: " + rtnCode);
        15.               }
        16.          }
        17.      });
        18. }
    
    

3、登录成功后应用获取用户的华为帐号信息。  
● 如果是单机应用，用户的唯一标识无需在应用的服务端保存，应用可直接从signIn接口的返回结果获取用户信息。  
● 如果应用对用户的唯一标识有较高安全要求，必须在应用的服务端保存，则应用的服务端需要根据signIn接口的返回的accessToken调用[获取用户帐号信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_queryUser)接口从华为服务器直接获取用户信息。另外，如果应用启用了unionId，应用的服务端可根据accessToken调用[accessToken鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_accesstokenVer)接口获取用户的unionId。

注意：

应用获取到的accessToken有可能有效期已小于1小时，因此为了防止accessToken失效请应用获取后立刻使用。如果应用发现accessToken已超过有效期，需要再次调用signIn接口重新获取accessToken。
