# 新版本优势说明

  * 全球化商品管理服务

支持78种语言；支持195个商品价格档位；支持170+国家和地区的本地货币自动定价。

  * 订单管理实现零掉单

提供丰富的订单管理开放接口；记录完整的订单信息；主动查询异常订单，及时补发，实现零掉单。

  * 订阅管理创造稳定收入

助力您持续获取稳定的收入；支持订阅关系管理、订阅周期管理、订阅商品管理、订阅促销管理。




# 升级变更说明

IAP2.0到5.0的功能变更点：

功能 |  HMS Core 2.0 |  HMS Core 5.0  
---|---|---  
服务端回调 |  客户端支付成功后，华为服务器会主动回调通知CP服务器。 |  取消支付成功的服务端回调机制，提供新的主动校验机制。 开发者如需对支付结果进行校验，可以参考[Order服务购买Token校验](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/order-verify-purchase-token-0000001050033078)。  
支付接口 |  2.0支持pay接口，CP可通过该接口实现商品价格等信息的自定义，无需在华为侧管理商品。 |  取消了自定义价格的支付接口，所有商品必须全部在华为侧配置，调用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section1255302563115)接口完成商品购买。  
发货确认机制 |  2.0不支持发货确认，支付成功后华为侧无法获知CP侧是否发货成功，容易出现掉单。 |  支持发货确认，可实现零掉单： CP收到支付成功回调，发货成功后通过[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口告知华为侧发货成功，华为侧更新内部订单状态。 CP可通过[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section15126153542812)查询已购买但未发货的购买信息，补发货成功后通过[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口告知华为侧发货成功，华为侧更新内部订单状态。  
  
# 升级指导

从以上变更说明可以看出，IAP2.0和5.0能力差异很大，是两套完全不同的流程。建议CP先删除IAP2.0接口调用逻辑，再按照IAP5.0的指导文档重新接入。

#### 删除IAP2.0接口

步骤1. 删除工程中所有HMS SDK Agent套件代码。

步骤2. 删除IAP SDK依赖。

步骤3. 删除AndroidManifest中IAP2.0的相关Activity配置。

1\. 删除application节点下的APPID配置。
    
    
    <meta-data
      android:name="com.huawei.hms.client.appid"
      <!-- value的值“xxx”用实际申请的应用ID替换，来源于开发者联盟网站应用的服务详情。-->
      android:value="appid=xxx">
    meta-data>

2\. 删除BridgeActivity配置。
    
    
    <activity
      android:name="com.huawei.hms.activity.BridgeActivity"
      android:configChanges="orientation|locale|screenSize|layoutDirection|fontScale"
      android:excludeFromRecents="true"
      android:exported="false"
      android:hardwareAccelerated="true"
      android:theme="@android:style/Theme.Translucent" >
      <meta-data
        android:name="hwc-theme"
        android:value="androidhwext:style/Theme.Emui.Translucent" />
    activity>

3\. 删除AppUpdateActivity和PackageInstallActivity的配置。
    
    
    <activity
      android:name="com.huawei.updatesdk.service.otaupdate.AppUpdateActivity"
      android:configChanges="orientation|screenSize"

      <meta-data
       android:name="hwc-theme"
        android:value="androidhwext:style/Theme.Emui.Translucent.NoTitleBar" />
    activity>
    <activity
      android:name="com.huawei.updatesdk.support.pm.PackageInstallerActivity"
      android:configChanges="orientation|keyboardHidden|screenSize"
      android:exported="false"
      android:theme="@style/upsdkDlDialog" >
      <meta-data
        android:name="hwc-theme"
        android:value="androidhwext:style/Theme.Emui.Translucent" />
    activity>

4\. 删除HMSAgentActivity。
