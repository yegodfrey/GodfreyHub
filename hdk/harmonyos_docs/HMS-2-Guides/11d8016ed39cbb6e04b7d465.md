## 3.2 AndroidStudio开发环境

### **3.2.1 Gradle+maven集成方式**

**步骤 1 配置maven仓。**  
1、打开项目的build.gradle文件，如图3-1圈中的文件。  
图3-1 项目的build.gradle位置在示例图

2、在allprojects->repositories 里面配置HMSSDK的maven仓。
      
      1. allprojects {
        2.     repositories {
        3.     jcenter()
        4.     maven {url 'https://developer.huawei.com/repo/'}
        5.     }
        6. }
    
    

**步骤 2 配置项目依赖。**

1、打开子工程的build.gradle文件，如图3-2圈中的文件。  
图3-2 子工程的build.gradle位置在示例图  
![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/18c368e8-7e31-4fdd-944c-ce4a015a6a08.png)

      1. dependencies {
        2.     implementation 'com.huawei.android.hms:hwid:{version}'

**步骤 3 同步修改的文件。**

1、重新打开修改完的gradle文件，右上方出现Sync Now链接，如图3-3所示。

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。        

**步骤 4 多语言设置。**  


HMS SDK支持全球多种语言（后续将逐步增加对新语言的支持）。  
● 如果您的应用不需要设置只支持某些特定语言，则请忽略此步骤。  
● 如果您的应用需要设置只支持某些特定语言，请最少要支持en（英文） 和 zh-rCN（简体中文）两种语言。在Android Studio工程的build.gradle中配置resConfigs，配置样例如下：
      
      1. android {
        2.     defaultConfig {
        3.         ...
        4.         resConfigs "en", "zh-rCN"，"其他应用需要支持的语言"
        5.     }
        6. }
    
    

## 3.3 Eclipse+ADT 开发环境

### 3.3.1 解压hmssdk_eclipse_{version}.zip

hmssdk_eclipse_{version}.zip只适合采用工程依赖方式接入HMS SDK功能的工程，如果您的应用不能使用工程依赖的方式集成HMS SDK，那么请参照 3.4 章节的方式接入。  
解压后将生成5个Eclipse Library工程，如表3-1所示。  
表3-1 Eclipse Library工程说明

Sdk工程名                | 提供的能力                | 需求场景                  
---|---|---  
HMSSdkBase                | HMS SDK核心功能包                | 该包必须集成。                  
HMSSdkID                | 提供帐号功能                | 如果只需要集成华为帐号功能，则只需要集成该包以及HMSSdkBase。                  
HMSSdkIAP                | 提供支付功能                | 如果只需要集成华为应用内支付功能，则只需要集成该包以及HMSSdkBase。                  
HMSSdkPush                | 提供PUSH能力                | 如果只需要集成华为PUSH功能，则只需要集成该包以及HMSSdkBase。                  
HMSSdkSNS                | 提供华为消息功能                | 华为消息功能依赖为华为帐号能力，因此如果需要集成华为消息能力，则需要集成该包，HMSSdkBase包以及HMSSdkID包。                  
HMSSdkOpendevice                | 暂未开放功能| 暂未开放功能

各个Library工程配套使用的时候一定要使用同一个版本号的，否则会引入异常。        

版本号见hmssdk_eclipse_{version}.zip中version字段。

## 3.4 通用包

### 3.4.1 解压hmssdk_gradle_{version}.zip

推荐使用“3.2 AndroidStudio开发”和“3.3 Eclipse+ADT开发”，如果此两种方式都无法正常接入HMS SDK，请参考本章节的方式接入。

表3-2 通用包目录说明  


目录                | 说明                | 使用方式                  
---|---|---  
libs/hmssdk_gradle_{version}.jar                | 包含HMS所有功能的jar包。通用包不再按照业务功能分成多个jar包，hmssdk_gradle_{version}.jar包含帐号、支付、消息、推送、游戏服务。                | 请直接将libs目录拷贝到应用工程根目录。

# 4\. 集成Agent

  **步骤 1  **解压包，生成目录和文件，包括HMSAgent的示例工程和脚本文件。

脚本文件                | 说明                | 备注  
---|---|---  
GetHMSAgent_cn.bat                | windows批处理脚本，用于从示例代码中提取所需要模块的HMSAgent代码（只包含）需要的模块。请直接运行，根据提示操作即可。如果由于PC环境问题导致脚本无法运行，请手动拷贝hmsagents\src\main\到 copysrc\。                                        注意：如果选择了游戏服务，则必须选择支付服务。                            | 中文脚本，适用于发行区域为中国大陆地区的应用和游戏使用。  
GetHMSAgent_oversea.bat                | windows批处理脚本，用于从示例代码中提取所需要模块的HMSAgent代码（只包含）需要的模块。请直接运行，根据提示操作即可。如果由于PC环境问题导致脚本无法运行，请手动拷贝hmsagents\src\main\到 copysrc\。                    | 英文脚本，适用于发行区域为非中国大陆地区的应用和游戏使用。  
  
  **步骤 2  **执行GetHMSAgent _xx.bat生成copysrc的文件夹，里面是根据您选择需要集成HMS服务，抽取后的HMSAgent代码（java 文件夹）和manifest文件（AndroidManifest.xml）。

  **步骤 3  **拷贝copysrc/java里面的代码到您现有的工程（例如，在Eclipse环境下，请将代码拷贝至src目录下）。请保持HMSAgent代码的包的路径和结构不变。AndroidManifest.xml仅供配置参考。

# 5\. 配置manifest文件

**步骤 1** 在application节点下增加APPID。
      
      1. <meta-data
        2.     android:name="com.huawei.hms.client.appid"
        3.     <!-- value的值“xxx”用实际申请的应用ID替换，来源于开发者联盟网站应用的服务详情。-->
        4.     android:value="appid=xxx">
        5. </meta-data>
    
    

**步骤 2** 在application节点下增加activity，BridgeActivity定义了HMS-SDK中一些跳转所需要的透明页面。
      
      1. <activity
        2.     android:name="com.huawei.hms.activity.BridgeActivity"
        3.     android:configChanges="orientation|locale|screenSize|layoutDirection|fontScale"
        4.     android:excludeFromRecents="true"
        5.     android:exported="false"
        6.     android:hardwareAccelerated="true"
        7.     android:theme="@android:style/Theme.Translucent">
        8.     <meta-data
        9.         android:name="hwc-theme"
        10.         android:value="androidhwext:style/Theme.Emui.Translucent" />
        11. </activity>
    
    

**步骤 3** 在application节点下增加provider，UpdateProvider用于HMS-SDK引导升级HMS，提供给系统安装器读取升级文件。
      
      1. <provider
        2.     android:name="com.huawei.hms.update.provider.UpdateProvider"
        3.     <!--“xxx.xxx.xxx”用实际的应用包名替换-->
        4.     android:authorities="xxx.xxx.xxx.hms.update.provider"
        5.     android:exported="false"
        6.     android:grantUriPermissions="true" >
        7. </provider>
    
    

**步骤 4** 在manifest节点下增加所需权限。
      
      1. <!--HMS-SDK引导升级HMS功能，访问OTA服务器需要网络权限-->
        2. <uses-permission android:name="android.permission.INTERNET" />
        3. <!--HMS-SDK引导升级HMS功能，保存下载的升级包需要SD卡写权限-->
        4. <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
        5. <!--检测网络状态-->
        6. <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
        7. <!--检测wifi状态-->
        8. <uses-permission android:name="android.permission.ACCESS_WIFI_STATE"/>
        9. <!--为了获取用户手机的IMEI，用来唯一的标识用户。-->
        10. <uses-permission android:name="android.permission.READ_PHONE_STATE"/>
        11. <!--如果是安卓8.0，应用编译配置的targetSdkVersion>=26，请务必添加以下权限 -->
        12. <uses-permission android:name="android.permission.REQUEST_INSTALL_PACKAGES" />

# 6\. 配置混淆脚本

开发者编译APK时请不要混淆本SDK，避免功能异常。

注意：

不要混淆HMS SDK自带的资源文件。部分应用和游戏会混淆工程中的所有资源文件，请注意不要混淆HMS SDK的相关资源文件。        

**步骤 1** 打开android工程的混淆配置文件。  
**步骤 2** 加入排除hms的混淆配置。
      
      1. -ignorewarnings
        2. -keepattributes *Annotation*
        3. -keepattributes Exceptions
        4. -keepattributes InnerClasses
        5. -keepattributes Signature
        6. -keepattributes SourceFile,LineNumberTable
        7. -keep class com.hianalytics.android.**{*;}
        8. -keep class com.huawei.updatesdk.**{*;}
        9. -keep class com.huawei.hms.**{*;}
        10. -keep class com.huawei.android.hms.agent.**{*;}
    
    

**步骤 3** 如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单。
      
      1. "R.string.hms*",
        2. "R.string.connect_server_fail_prompt_toast",
        3. "R.string.getting_message_fail_prompt_toast",
        4. "R.string.no_available_network_prompt_toast",
        5. "R.string.third_app_*",
        6. "R.string.upsdk_*",
        7. "R.layout.hms*",
        8. "R.layout.upsdk_*",
        9. "R.drawable.upsdk*",
        10. "R.color.upsdk*",
        11. "R.dimen.upsdk*",
        12. "R.style.upsdk*"
    
    

# 7\. 配置签名

1、请在开发环境配置签名证书，该配置属于Android通用技术，此处不详细描述。  
2、请确认在华为开发者联盟已经配置此签名证书的指纹，获取和配置指纹的操作请参见“[接入准备 > 3 申请HMS服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweiid_prepare)”。

注意：

请务必确保开发环境和开发者联盟上使用的签名文件一致，否则连接HMS Core（APK）将失败，错误码为 6003 或 907135702。
