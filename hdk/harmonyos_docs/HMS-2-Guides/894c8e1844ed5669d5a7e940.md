为了确保通信的安全性，请求方在向接收方发送请求消息时需要传入签名字符串，接收方在收到请求后对签名字符串进行验签，防止请求消息中的支付参数被篡改。详细的支付签名指导视频可参见[支付签名指导视频](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_vedio_payment_signature)。支付签名的具体生成规则如下：

1、将请求参数中需要参与签名的参数，按参数名首字母的ASCII码将参数升序排序，若遇到相同首字母，则比较第二个字母，以此类推。  
需要参与签名的参数是指接口说明（例如pay、productPay接口）中“是否参与签名”列为“是”且实际请求中携带了该参数，并且参数值不为空（null或""）。

注意：

“是否参与签名”列为“是”但实际请求中未携带的参数，请勿参与签名。

2、排序完成之后，将所有参与签名的参数名和参数值的键值对以“&”字符连接成字符串，例如“a=xxxxxx&b=xxxxxxx&c=xxxxxxxxxxx...”。

注意：

●参数名和参数值请勿进行urlencode。  
●“urlVer”参数拼接时必须修改为“urlver”，其他参数名必须和接口说明中的参数大小写保持一致。  
●参数值必须与接口中传入的实际参数值保持一致。

拼接字符串的JAVA示例代码如下：
      
      1. /**
        2.  * 根据参数map获取待签名字符串
        3.  * @param params 待签名参数map
        4.  * @param includeEmptyParam 是否包含值为空的参数：
        5.  *                          与HMS-SDK支付能力交互的签名或验签，需要为false（不包含空参数）
        6.  *                          由华为支付服务器回调给开发者的服务器的支付结果验签，需要为true（包含空参数）
        7.  * @return 待签名字符串
        8.  */
        9. private static String getNoSign(Map<String, Object> params, boolean includeEmptyParam) {
        10.     StringBuilder content = new StringBuilder();
        11.     // 按照key做排序
        12.     List<String> keys = new ArrayList<String>(params.keySet());
        13.     Collections.sort(keys);
        14.     String value = null;
        15.     Object object = null;
        16.     boolean isFirstParm = true;
        17.     for (int i = 0; i < keys.size(); i++) {
        18.         String key = (String) keys.get(i);
        19.         object = params.get(key);
        20.         if (object == null) {
        21.             value = "";
        22.         }else if (object instanceof String) {
        23.             value = (String) object;
        24.         } else {
        25.             value = String.valueOf(object);
        26.         }
        27.         //拼接成key=value&key=value&....格式的字符串
        28.         if (includeEmptyParam || !TextUtils.isEmpty(value)) {
        29.             content.append((isFirstParm ? "" : "&") + key + "=" + value);
        30.             isFirstParm = false;
        31.         } else {
        32.             continue;
        33.         }
        34.     }
        35.     android.util.Log.e("content.toString()==:", content.toString());
        36.     //待签名的字符串
        37.     return content.toString();
        38. }
    
    

3、将待签名字符串使用应用的支付私钥进行签名，将签名后的字符数组经过Base64编码，得到的字符串即为对应的签名值。

说明：

支付私钥在申请支付服务后获取，查询方法参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_querypayinfo)。如果支付私钥必须保存在应用的服务端，则生成签名字符串必须在服务端执行。
      
      1. /**
        2.  * 签名字符串（SHA256WithRSA）
        3.  * @param content 待签名字符串
        4.  * @param privateKey 私钥
        5.  * @return 字符串的签名
        6.  */
        7. public static String rsaSign(String content, String privateKey) {
        8.     if (null == content || privateKey == null) {
        9.         return null;
        10.     }
        11.     try {
        12.         PKCS8EncodedKeySpec priPKCS8 = new PKCS8EncodedKeySpec(Base64.decode(privateKey, Base64.DEFAULT));
        13.         KeyFactory keyf = KeyFactory.getInstance("RSA");
        14.         PrivateKey priKey = keyf.generatePrivate(priPKCS8);
        15.         java.security.Signature signature = java.security.Signature.getInstance(SIGN_ALGORITHMS);
        16.         signature.initSign(priKey);
        17.         signature.update(content.getBytes(CHARSET));
        18.         byte[] signed = signature.sign();
        19.         //使用BASE64进行编码
        20.         return Base64.encodeToString(signed, Base64.DEFAULT);
        21.     } catch (Exception e) {
        22.         //  这里是安全算法，为避免出现异常时泄露加密信息，这里不打印具体日志
        23.         HMSAgentLog.e("rsaSign error");
        24.     }
        25.     return null;
        26. }
