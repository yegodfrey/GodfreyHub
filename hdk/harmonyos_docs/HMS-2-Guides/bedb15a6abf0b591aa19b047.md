# 1. 场景介绍  

当用户在应用中浏览商品时，应用可以在商品页面展示AppGallery Connect中配置的商品信息。  

# 2. 业务流程  

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224204259.46416492639875317458548496890466:50510916032943:2800:E3F5774261D5AFDE9F2996A2CA05C5C75115B2AD1833174D158C23B0E956FA71.png?needInitFileName=true)  

1\. 用户进入商品页面。  

2\. 应用调用[getProductDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c22)接口请求查询商品详情。  

3\. HMS SDK根据用户所属的地区从商品服务器获取商品详情，并通过回调方式返回给应用。  

4\. 应用将获取到的商品详细信息展示给用户。  

# 3. 注意事项  

必须已经提前在AppGallery Connect中配置商品信息，参见[配置商品信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devprepare_configproduct)。  

# 4. 开发步骤  

1、封装productDetailRequest参数，具体参数参见[getProductDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c22)接口。  


示例代码如下：

        17.  // 注意：所查询的productNo必须属于对应的packageName,且在应用内唯一。
        18. request.productNos = productNos;
    
    

2、调用getProductDetails接口并处理回调结果。

● 如果商品查询成功，回调结果中的productList将包含待查询的商品详情，包括商品价格、币种、国家码等。  


● 如果有商品查询失败，回调结果中的failList将包含查询失败的商品ID和错误码，应用需要根据返回码处理建议进行相关的处理。    

警告：

在传入productNos时，一次最多支持查询20个商品，请勿超过上限。            

示例代码如下：
