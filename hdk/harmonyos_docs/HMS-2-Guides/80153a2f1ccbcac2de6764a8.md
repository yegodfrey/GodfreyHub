本章节主要介绍接入华为Push的客户端开发步骤，以帮助开发者快速了解华为Push提供的客户端接口及其调用方法，通过必选步骤的开发快速体验华为Push服务，通过可选功能的开发实现多样的个性化能力，例如“推送消息的可控接收”以及“应用角标展示”的能力。

主要包括：

1.初始化Agent

2.申请PUSH Token

3.实现自定义广播接收消息

4.注销PUSH Token（可选）

5.是否接收PUSH通知栏消息（可选）

6.是否接收PUSH透传消息（可选）

7.展示应用角标（可选）

# 1\. 功能描述  


华为Push开发包括APP客户端开发和APP服务端开发两部分，全流程如下。

**图4-1 push开发全流程**

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/63b95be35c1c44cbbe8e3e64736bd253-4643476245630605814.png)

**客户端开发：使客户端APP具备单条 Push消息的发送和接收能力。**

**STEP1、** 开发者的APP集成HMS SDK，调用getToken接口从Push服务器获取到PUSH Token。  
**STEP2、** 开发者的APP对于获取到的PUSH Token需要上报到开发者自己的服务器APP ProviderServer上。

**服务端开发：实现APP服务器批量发送通知消息。**  
**STEP3、** 开发者利用服务器上保存的PUSH Token向对应的终端设备发送通知消息。  
**STEP4、** 消息携带的PUSH Token作为鉴权和路由机制会通过华为Push平台将消息发送到最终用户设备上。

本章节指导开发者完成APP客户端的开发（STEP1和STEP2），开发者可以通过示例代码[下载](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Examples/hmssdk_huaweipush_sample_code_agent_c)结合本章节的开发指导完成客户端部分的开发。

客户端开发主要的目的是为了向Push服务器获取设备的PUSH Token，获取Token后开发者可以在联盟Push控制台或者开发者自己的服务器向这些Token发送推送消息。

在华为手机上，预置了HMS Core和Pushagent（EMUI系统服务进程），集成了HMS SDK的APP调用getToken接口向Push服务器申请token，请求会由HMS Core发送给PushAgent，PushAgent再向Push服务器申请token，最终PushAgent收到Push服务器返回的token后会通过广播返回token给APP。

**图:华为手机申请token流程**

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/0f4dc52eb63d4e5fa3654e2acaeb147f1334032947120680609.png)

在非华为手机上，开发者除了在APP内集成HMS SDK外，还需要安装最新的华为移动服务，也可以实现推送功能。下图流程中Hwid:pushservice为HUAWEI HMS Core拉起的pushagent进程，用于后续推送消息的接收，其功能等同于华为手机中预置的系统Push，集成了HMS SDK的APP可以调用接口申请token，请求会由HMSSDK通过AIDL请求发送给HUAWEI HMS Core，HUAWEI HMS Core直接向PUSH服务器发送HTTP形式的getToken()接口，服务器返回token后，HUAWEI HMS Core通过AIDL返回token和token申请的返回码给HMS SDK，SDK发送应用内广播，由APP接收处理onToken()的广播回调。

**图：非华为手机申请token流程**

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/bde58657aca94ed0be83b9e1dd795144-1990125890227645193.png)

完成本章节的开发后，开发者可以使用华为开发者联盟Push控制台发送测试消息，测试APP能否接收到推送的消息。控制台上可以自定义实现[“透传消息”和“通知栏消息”](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_introduction_agent)的发送，对于通知栏消息，开发者可以自定义实现打开通知的“[触发事件](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_apptest_agent)”，如打开应用、打开网页、打开自定义的富媒体。

# 2\. 初始化Agent

HMS Agent 套件提供了对HMS SDK原生接口的二次封装，处理了部分必要的接入逻辑而不再将它们暴露给开发者，使用封装后的Agent接口接入HMS SDK，可大大提升接入效率，降低出错几率。

# 3\. 申请PUSH Token

## 3.1 接口说明

接口名：void HMSAgent.Push.getToken(GetTokenHandler handler)，简称getToken。

接口详细定义请参见[getToken](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweipush_api_reference_agent_c1)。

getToken接口向服务端请求应用的唯一标识——Device Token，开发者的服务器根据这个Token发送推送消息。每个设备的上每个应用的Token都是唯一存在。开发者可以在自定义广播的onToken方法中接收返回的token字符串，并且将token上报到自己的应用服务器维护这些已申请的token列表，然后调用PUSH服务器的推送消息接口，根据token批量推送消息。

说明：

l Huawei Push为了提升安全性，在2018/3/10 升级了Token生成规则和变更机制，增加了Token格式2.0，在新的设备上会使用新格式的Token

l 非华为终端首次申请Token的时候会弹出一次授权框

  


**使用限制：**

getToken接口只有在服务端[开通了Push服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_devprepare_agent#h1-1575517118190)申请token才会返回成功。目前仅中国区和部分海外地区支持开通Push服务（参见“支持的国家和地区”）

## 3.2 开发步骤

**前提条件：**

开始此章节前请务必完成“开发准备”、“客户端开发-初始化Agent”章节

建议开发者在首个activity的onCreate方法调用getToken方法，同一个手机的同一个应用获取的Token不会变，但是建议每次启动更新一次PUSH token。调用getToken接口后，Token不是在本接口中直接返回的，而是通过广播的形式通知APP因此需要开发者实现自定义广播的onToken方法来接收Token。

申请Token的示例代码如下：

        7.         @Override
        8.         public void onResult(int rtnCode, TokenResult tokenResult) {
        9.             showLog("get token: end" + rtnCode);
        10.         }
        11.     }); 
        12. }
    
    

# 4\. 实现自定义广播接收消息

## 4.1 接口说明

PUSH Token的返回，Push服务器发送的透传消息以及通知栏点击事件的处理都是通过广播来接收，因此开发者需要实现自定义广播，开发者需要创建子类继承com.huawei.hms.support.api.push.PushReceiver，实现onToken，onPushMsg，onEvent这几个方法，用于接收Token返回，透传消息和通知栏点击事件处理。

**使用限制：**

onEvent会在后续版本中逐渐废弃，请开发者谨慎使用，建议开发者创建两个子类继承PushReceiver类，分别实现onToken，onPushMsg和onEvent的处理。

由于是通过广播触发，所以当应用的进程不存在时可能由于系统原因无法通过广播方式拉起应用处理通知栏点击事件等。需要在手机上面为应用设置“允许自启动”才能在进程不存在时正常处理PushReceiver的广播

## 4.2 开发步骤

**前提条件：**

确保开发准备中manifest.xml的配置已完成，参考“[配置manifest文件步骤7、8](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_devprepare_agent#h2-1575111780236)”

**步骤1：**

开发者自定义HuaweiPushRevicer类继承PushReceiver，实现PUSH Token和透传消息的接收。

**示例代码：**
      
      1.  public class HuaweiPushReceiver extends PushReceiver {
        2.     @Override
        3.     public void onToken(Context context, String token, Bundle extras) {
        4.                //开发者自行实现Token保存逻辑。
        5.     }
        6.     @Override
        7.     public boolean onPushMsg(Context context, byte[] msg, Bundle bundle) {
        8.                //开发者自行实现透传消息处理。
        9.     }    
        10.  }
    
    

**onToken方法说明**

Push服务器返回Token后，开发者需要在onToken回调方法中将Token妥善的保存起来，例如存放到开发者的应用服务器上，此业务逻辑需要开发者自行实现。后续如果开发者的应用服务器实现了调用华为Push服务器端接口发送推送消息，开发者就可以向这些保存Token发送批量推送消息，此业务需要开发者参考实现《服务端开发》章节。

如果有涉及到在APP客户端和开发者自己的服务器之前传输Token,请开发者自行确保Token传输的安全。

**示例代码：**
      
      1.  @Override
        2.  public void onToken(Context context, String token, Bundle extras) {
        3.         String belongId = extras.getString("belongId");
        4.         Log.i(TAG, "belongId:" + belongId);
        5.         Log.i(TAG, "Token:" + token);
        6.                //开发者自行实现token保存逻辑。 
        7.  }
    
    

**onPushMsg方法说明**

推送“透传消息”下来时会自动调用onPushMsg方法实现应用透传消息的业务处理，此业务处理逻辑部分需要开发者自行实现。

**示例代码：**

****
      
      1. @Override
        2.  public boolean onPushMsg(Context context, byte[] msg, Bundle bundle) {
        3.     try {
        4.         //开发者可以自己解析消息内容，然后做相应的处理
        5.         String content = new String(msg, "UTF-8"); 
        6.         Log.i(TAG, "收到PUSH透传消息,消息内容为:" + content); 
        7.     } catch (Exception e) {
        8.         e.printStackTrace();
        9.     }
        10.     return false; 
        11. }
    
    

  


**步骤2** （可选，后续版本逐渐废弃，请开发者谨慎使用）：

开发者自定义HuaweiPushRevicerEx类继承PushReceiver，实现接收通知栏或通知栏上按钮点击事件的onEvent回调。

**示例代码：**
      
      1.  public class HuaweiPushReceiverEx extends PushReceiver {
        2.     @Override    
        3.     public void onEvent(Context context, Event event, Bundle extras) {
        4.     //开发者自行实现相应处理逻辑
        5.     }
        6. }
    
    

**onEvent方法说明**

实现通知栏点击事件回调。该方法会在点击打开通知栏消息、点击通知栏上的按钮之后被调用。开发者决定是否实现该方法，如果需要触发onEvent点击事件回调，开发者需要在下发的Push消息中携带customize参数自定义键值对。添加方法：对于开发者联盟Push控制台发送的Push消息，请在控制台界面配置“[自定义内容](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_apptest_agent)”；对于开发者应用服务器发送的Push消息，开发者需要在调用的服务端接口中携带customize参数。

目前版本支持的Event事件
      
      1. public static enum Event
        2. {
        3.     NOTIFICATION_OPENED, //通知栏中的通知被点击打开
        4.     NOTIFICATION_CLICK_BTN, //通知栏中通知上的按钮被点击
        5. }
    
    

**Event事件携带的extras参数如下表：**

Event| extras参数| 描述  
---|---|---  
NOTIFICATION_OPENED| BOUND_KEY.pushMsgKey| 匹配该字符串以决定点击按钮后处理何种事件。该附加信息，由业务自行处理。  
NOTIFICATION_CLICK_BTN| BOUND_KEY.pushMsgKey| 匹配该字符串以决定点击按钮后处理何种事件。该附加信息，由业务自行处理。  
BOUND_KEY.pushNotifyId| 通知栏id，点击通知栏上的按钮后，业务可根据需要清除掉该通知栏或保留；默认为保留。  
  
**示例代码：**
      
      1.  public void onEvent(Context context, Event event, Bundle extras) {
        2.     if (Event.NOTIFICATION_OPENED.equals(event) || Event.NOTIFICATION_CLICK_BTN.equals(event)) {
        3.         int notifyId = extras.getInt(BOUND_KEY.pushNotifyId, 0); 
        4.         Log.i(TAG, "收到通知栏消息点击事件,notifyId:" + notifyId);  
        5.         if (0 != notifyId) {
        6.             NotificationManager manager = (NotificationManager) context.getSystemService(Context.NOTIFICATION_SERVICE); 
        7.             manager.cancel(notifyId); 
        8.         }
        9.     }
        10.     String message = extras.getString(BOUND_KEY.pushMsgKey);  
        11.     super.onEvent(context, event, extras);  
        12. }
    
    

# 5\. 删除PUSH Token（可选）

## 5.1 接口说明

**接口名：** void HMSAgent.Push.deleteToken(String token,DeleteTokenHandler handler)，接口详细定义请参见[deleteToken](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweipush_api_reference_agent_c2)。

**接口说明：** 开发者如果不希望应用接收Push消息，可以调用deleteToken接口删除token，删除成功后，客户端就不会再接收到Push消息。

但是建议开发者暂时不要依赖deleteToken接口，如果开发者要实现不接收Push消息，可以自行将开发者应用服务器端的Token状态设置为失效状态，并且在推送消息时判断是失效Token就不进行推送，避免频繁的向服务器申请token。

**使用限制：**

中国大陆地区的华为手机，必须满足EMUI版本不低于EMUI5.1

海外地区的华为手机或者非华为手机，则必须满足华为移动服务的版本不低于2.5.0。

## 5.2 开发步骤

调用删除Token接口。

**示例代码：**
      
      1.     /**

        12.     }

至此开发者已经完成了所有Push功能客户端的开发，开发者可以尝试将自己的android工程打包成apk安装到手机中进行测试，打包的时候请确保使用了正确的[keystore证书](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_devprepare_agent#h1-1575111604142)，打包完成后开发者可以使用keytool命令获取apk的证书指纹，apk中的SHA256指纹信息必须和开发者在开发者联盟上创建应用的指纹保持一致。否则请检查apk打包过程的正确性。如图所示。
