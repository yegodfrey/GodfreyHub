# 1. Agent常见问题

  * **Q：如何将日志打印到自己统一的方法中？**

**具体场景** ：已有的项目中统一封装了日志方法，如L.d(tag, msg); L.e(tag, msg)。 而HMSAgent代码中日志都是通过HMSAgentLog.d(msg);HMSAgentLog.e(msg)打印的。想要HMSAgent代码中的日志也使用自己统一的日志方法。  
**解决方法** ：通过调用HMSAgentLog.setHMSAgentLogCallback方法，接管HMSAgent的默认日志打印，在空方法里使用自己的日志方法将tag和log输出。



      
      1. HMSAgentLog.setHMSAgentLogCallback(new HMSAgentLog.IHMSAgentLogCallback() {
        2.     public void logD(String tag, String log) {
        3.     }
        4.     public void logV(String tag, String log) {
        5.     }
        6.     public void logI(String tag, String log) {
        7.     }
        8.     public void logW(String tag, String log) {
        9.     }
        10.     public void logE(String tag, String log) {
        11.     }
        12. });     
    
    

  * **Q：如果不在启动界面进行HMS Core（APK）连接，如何处理？**  





为了提高HMS SDK接口的连接速度，建议在程序启动时进入第一个界面就进行HMS Core（APK）的连接。  
如果由于业务限制，不能过早进行HMS Core（APK）的连接，请将HMSAgent.connect调用延迟到合适的位置调用，但是必须在应用启动时用户开始操作前，由应用自动调用。

  * **Q：用户的accessToken有效期是多长时间？**

HMS SDK返回的用户accessToken最长有效期为1个小时，但是由于HMS Core（APK）缓存可能会被清理导致accessToken有效期无法保证，因此请获取后马上使用。  

  * **Q：用户的accessToken过期后怎么处理？**

如果用户的accessToken失效，可以重新调用登录接口signIn接口，不需要用户重新授权。当重新调用signIn接口获取的accessToken在访问华为服务器时仍然返回失效，可调用signOut接口清除HMS Core（APK）的缓存，然后再次调用signIn接口获取新的accesstoken。  

  * **Q：应用开发者是否需要对登录接口获取的accessToken进行验签？**

应用通过登录接口返回值中获取的accessToken由HMS Core（APK）客户端进行有效性验证，只有合法有效的accessToken才会返回给应用，所以应用不需要对accessToken进行验签，可以直接使用。  

  * **Q：接入华为帐号，是否可以获取unionId？**

unionId和openId的区别在于，如果开发者帐号下管理了多个应用，针对同一个华为帐号，不同的应用返回的openId值不同，但返回的unionId相同。如果开发者需要在不同应用中共享同一个华为帐号的用户信息，可以使用unionId作为用户标识。  
调用signIn接口可以获取unionId，但是需要满足以下条件：  
1、应用集成HMS SDK 2.6.1以及更高版本。  
2、配套的HMS CoreAPK版本为2.6.1以及更高版本。  
3、应用申请帐号服务时启用了UnionId。  

  * **Q：不同的应用接入华为帐号登录，是否返回同一openid？**

不是，不同应用登录同一华为帐号获取的openid不一样，openid是应用内的唯一标识。  

  * **Q：是否只有在非华为手机上会提示安装HMS Core（APK）？**

不是，只要手机上没有安装HMS Core（APK）就会提示。  




# 3. 支付常见问题

  * **Q：华为IAP是否收费？**

华为IAP免费提供给开发者使用，您的APP通过华为IAP产生的支付交易，华为会扣除一定比例渠道费用。         

  * ****Q：** 支付服务参数如何保护？**

支付服务参数是华为IAP认证开发者身份的关键信息，如果支付服务参数泄露，会造成攻击者冒用开发者身份向华为发起支付请求，请谨慎保护。  
强烈建议开发者把支付服务参数保存在服务器，而不是保存在客户端。支付的签名、验签动作在您的服务器完成，并通过HTTPS等安全通道，将您服务器的签名、验签结果下发到客户端。         

  * ****Q：** 支付成功回调的签名在开发者服务器侧验证不通过，如何处理？**

支付成功回调流程及常见问题可参考“[支付回调流程简介](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_video_payment_callback_process)”视频讲解。  
如果验签失败，请对以下项目进行自检：  
**1\. 检查回调结果中null和“”值是否参与验签。**  
    只要实际回调结果中携带的参数，除去sign和signtype都需要参与签名。  
    华为支付服务器不会传null和**“”** 值给CP服务器，即使开发者在支付时部分字段传null和**“”** 值，华为支付服务器在向开发者服务器发送支付结果时会自动过滤null和**“”** 值的字段。  
**2\. 检查验签失败是否是支付宝支付可以验签通过，微信支付验签失败。**  
    不同的支付方式，收到的支付回调中携带的字段是不一样的。例如微信支付方式，回调结果中会有多一个sysReserved字段，而支付宝支付方式则没有该字段，因此在解析字段时不要把key写死，需要根据回调结果中实际传入的字段解析。  
**3\. 检查是否是支付公钥导致的验签失败。  
**     支付验签使用支付公钥，在申请支付服务后获取。注意，游戏开发者请勿混淆游戏公钥和支付公钥，支付验签应该使用支付公钥。  
    公钥在传递至开发者服务器时直接使用通讯工具传递，导致公钥被转义，比如出现空格和%等字符。要求公钥传递过程中一律以文件方式传递。  
    公钥缺失，传递过程中会导致在java代码验签时会报长度不正确的异常，这时请重新从开发者联盟后台获取公钥，且以文件形式传递。在使用过程中也要检查是否缺省或者自己误添加空格等。  
**4\. 检查是否由于支付时商品描述含有“+”号的商品导致验签失败。**  
    支付时的所有字段格式，需要严格按照文档要求，特殊符号一律不准使用。由于商品描述字段或其他字段中含有+号，在回调结果中会有很大概率会被默认转义成空格导致与实际值不匹配。  
**5\. 检查是否对sign、sysReserved和extReserved参数进行urldecode处理。**      
    华为支付服务器在回调结果中传入的sign、sysReserved和extReserved参数进行了urlencode处理，其他参数均为原始数据，所以开发者服务器在获取参数后需要对sign、sysReserved和extReserved参数进行urldecode处理，其他参数不需要处理。但是由于服务器不同语言和框架，可能在获取时会多做一次urlencode或urldecode导致数据被转义，在解析时需注意。例如，Java中request的getParameter()方法会隐含进行urldecode。  
   开发者服务器可根据检查解析出来的值是否含有“%”和空格来判断是否为原始数据，含有%号说明被执行了urlencode。含有空格，说明可能执行了urldecode。  
**6\. 检查是否由于验签算法导致验签失败。**  
    签名算法需要和回调字段signtype同步，signtype=RSA256时签名算法使用SHA256WithRSA，其他任何情况都使用SHA1withRSA。其他任何情况包括signtype=RSA和实际回调结果中没有传入signType。  
    在很久之前老版本回调中signType字段是可选的，所以存在回调中没有的情况。自从2.6.1 HMS SDK版本之后signType字段已经是必选字段，意思是回调中必然存在且目前2.6.1 之后的SDK默认都是RSA256.  
        

  * ****Q：** HMS Core（APK）是否能在Application中连接？**  
不建议这么做，因为处理onConnectionFailed时需要依赖activity。如果开发者能确保在出现onConnectionFailed时，获取当前的activity用来拉起解决问题的界面，则可以在Application中进行connect。另外在调用接口时发现HMS Core（APK）未连接，需要重新连接。

  * ****Q：** 非华为手机使用华为支付，有什么要求吗？**  
非华为手机接入HMS SDK后，需要根据提示下载HMS Core（APK），安装后即可使用华为支付。但是支付测试时需注意以下几点：  
1、建议所有测试标准以华为手机测试为准。  
2、个别非华为手机由于系统权限可能会对HMS Core（APK）做限制，在遇到华为手机测试正常但是在非华为手机测试异常场景下可以尝试开启非华为手机的应用权限后再次测试。  


  * ****Q：** 客户端回调支付接口时，读取哪个字段是获取商户订单号？**  
requestId，商户侧生成的支付订单号。orderId，华为支付服务器生成的订单号。

  * ****Q：** 华为是否提供服务端Demo？**  
服务端没有demo，只有示例代码。

  * ****Q：** 连接HMS Core（APK）出现907135702错误码，如何处理？**  
1、检查当前手机设备是否可以正常访问网络。

  * 2、检查是否在华为开发者联盟上配置了正确的证书指纹。登录开发者联盟，点击“管理中心”，在“应用服务”中依次点击“账号”和“支付”，点击需要检查证书指纹的应用，在“服务信息”界面检查“SHA256证书指纹”配置的信息是否和开发者生成的指纹证书一致，如果不一致请修改。

  * ****Q：** HMS Core（APK）升级弹窗只显示英文，如何处理？**  
请将项目的build.gradle文件中的resconfig参数去除。对于使用jar方式接入开发的，一定要记得把res文件夹下所有资源导入。

  * ****Q：** 华为支付SDK支持的EMUI系统最低版本是多少？**  
请使用4.2版本以上。

  * ****Q：** 私钥和签名是否可以都在服务端执行？**  
如果私钥保存在服务端，则生成签名字符串必须在服务端进行。

  * ****Q：** 支付的UI界面只有一种吗？是否还有其他支付界面？**  
是的，目前支付只有一种UI界面。

  * ****Q：** 是否必须使用SHA256的证书才能通过验签？**  
是的，现在华为开发者联盟上要求配置的就是SHA256指纹。

  * ****Q：** App签名证书的签名算法为SHA1withRSA，对应用有影响吗？**  
有，现在必须使用SHA256算法。

  * ****Q：** 是否存在验证openid的接口？**  
目前没有提供该接口。

  * ****Q：** 支付界面上的支付方式是否可以由开发者控制实现展现那些支付方式？**  
不能。

  * ****Q：** 接入支付时，需要导入哪些库？**  
需要导入IAP库和Base库。

  * ****Q：** 华为支付是否每个应用只能配置一个回调地址？**  


在华为开发者联盟后台只能配置一个回调地址。如需使用多个回调地址，建议在支付接口中自行传入url字段且保证开发者联盟后台回调地址栏置空（华为支付服务器优先回调开发者联盟后台配置的回调地址）。         

  * ****Q：** 支付接口中的urlVer参数填写2和不填写有什么区别？**  


  * 如果传递这个参数则该参数必须设置为2，否则就不传。

  * ****Q：** 支付失败返回30001错误码，如何处理？**  
请检查参与签名的参数情况：  
1、支付时携带的参数中需要参与签名的参数和sign中签名的参数个数或者参数值不一致.  
2、接口传入的sign值和原始签名出来的值不一致。  
3、支付签名应该使用支付私钥。  
4、支付私钥在传递过程中缺失或者使用通讯工具导致转义。  
5、检查算法是否使用sha256withrsa。  
6、支付签名sign中的参数需要同时满足两个条件：支付接口中实际携带了的字段；文档中要求参与签名的参数。  
支付签名的详细指导可以参见“[支付签名指导](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_devguide_vedio_payment_signature)”视频。

  * ****Q：** 签名和验签的算法有区别吗？**  
当前最新的签名算法必须是SHA256，验签可以根据回调中signType确定。signType等于RSA256时使用SHA256算法，其他情况都是用SHA1(包括实际回调中没有这个字段的情况)。主要是为了适配老板本的SDK存在SHA1的情况，目前的SDK基本都是SHA256。

  * ****Q：** 支付回调测试中填写的订单号是商户订单号还是华为订单号？**  
商户订单号。

可以，登录华为开发者联盟，点击“管理中心”，选择“我的报表 > 支付报表”，手动申请退款（开发者需要有退款权限）。

联盟没有测试环境，但是可以创建其他包名的应用作为测试应用，把获取的参数作为测试参数，后续正式应用中再替换为正式环境的参数。

当这两个参数传入的时候为空或者默认值（Currency默认值为CNY，Country默认值CN）时，回调里面不出现这两个参数。

  * ******Q：************如何修改支付服务的回调地址？**

  * ******Q：************回调地址一天可以修改多少次？是否立即生效？**  


没有修改次数限制，修改完立即生效。  

  * ******Q：************如何检测支付是否含有其他支付方式？**  


请不要接入除SDK中支付外的其他支付方式，含第三方支付方式。请检查androidmanifest、代码（包括注释掉的代码或者没有使用的代码）、jar包、各种资源，都不能存在除华为支付外的其他任何资源、代码、注释。 

  * **********Q：************************支付回调和支付验签有什么区别，又有什么关系？**  


支付回调是华为支付服务器回调支付结果给开发者应用的服务器；服务器验签是开发者在自己的服务器对支付回调结果进行验签。        

  * ******Q：************非华为手机出现支付闪退问题，如何处理？**

请检查是否开启了wifi-change权限。        

  * **********Q：************************如何修改商品的名称？**

如果是非托管商品，可以在接口重修改productName字段。如果是托管商品，则需要在AppGallery Connect中修改商品信息。        

  * **********Q：************************支付订单中的商户名称填写什么信息？**  


开发者在华为开发者联盟上注册的公司名称。

请将userName强制转换为UTF-8。

# 4. 审核常见问题

  * ******Q ：****创建应用时，包名没有以.huawei或.HUAWEI结尾，怎么修改？或者支付服务的包名填错了，能删除重新填么？**

包名一旦确定就无法修改，只能重新创建应用，配置支付服务，获取支付参数了。        

  * ******Q：************CP正式包完成，是发群里给华为人员测试审核，还是直接后台上传进行审核测试？**

请直接上传后台。        

  * **********Q：************Provider配置有误[没有配置HMS Core（APK）升级provider|没有配置自升级provider]被驳回，如何处理？**

请参考“[配置工程文件 > 配置manifest文件](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_appProFile)”的步骤4，校验AndroidManifest.xml文件的配置。         

  * **********Q：************接入HMS SDK中appid错误被驳回，如何处理？**

请参考“[配置工程文件 > 配置manifest文件](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_appProFile)”的步骤1，校验AndroidManifest.xml文件的配置。         

  * ****Q：** 上架的应用，修改了签名是否可以重新上架？**  
修改签名的应用不能直接上架，必须重新创建应用再上架。

  * **********Q：************对支付结果异常情况（错误码为1005, 30005, or 30002）处理不当被驳回，如何处理？**
