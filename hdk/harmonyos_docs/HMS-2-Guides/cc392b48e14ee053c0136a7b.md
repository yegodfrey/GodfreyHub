# 1\. 服务简介

HUAWEI Push Kit（华为推送服务）是华为为开发者提供的消息推送平台，建立了从云端到终端的消息推送通道。开发者通过集成华为推送服务可以将最新信息即时通知用户，构筑良好的用户关系，提升用户的感知度和活跃度。

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/aa6b8c8f43d04db493210b14f0be0439-2960481630309352776.png) 

1、 开发者通过在APP服务器端调用PUSH接口，向HUAWEI Push平台发送推送消息。

2、 HUAWEI Push平台将消息发给安装了相应APP的终端设备。

HUAWEI Push Kit可发送两种类型的消息给终端：通知栏消息和透传消息。

l 通知栏消息

终端用户点击对应的通知栏消息触发相应的动作，如打开应用、打开一个网页、打开应用内某界面。通知栏消息的呈现效果如图所示。

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/e9d130d4db644fc1ac9ba0c7938fc7ca-3407136547542562521.png)

l 透传消息

透传消息由开发者的APP自主解析自定义内容，并触发相关动作，HUAWEI Push Kit仅仅提供通道能力。利用此功能开发者可以实现好友邀请、IP呼叫等功能，例如好友邀请在应用内展现如图所示。

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/64ff14f9eaa349ea94371344f13b7efc-6037490080157272729.png)

Push服务能够协助开发者快速高效的触达用户，Push提供的系统级通道拥有高到达率，推送速度每秒最高可达百万级，消息量每日百亿级，并且支持实时消息回执（需申请）。

华为PUSH主要功能有：  
●  支持单发、群发机制，可以一次给一个或者多个用户发送Push消息

●  支持Android平台多用户条件下向不同用户发送Push消息。  
●  当终端用户不在线时，支持消息缓存能力。

消息缓存是指当消息到达华为Push平台后，如果设备不在线华为Push平台会将消息缓存起来，等到设备上线后华为Push平台会将缓存的消息再次推送给用户。如果用户很长时间不在线，这些缓存的消息默认保存24小时，最大保存15天，超期的消息会被Push平台丢弃。

●  支持实时消息回执。

消息回执是华为Push服务器提供的对应用服务器消息推送结果的通知，回执消息发生在系统检测到终端有应答返回，并且开发者在开发者联盟上开通了消息回执的场景。

●  支持通知栏消息和透传消息两种方式。华为推荐用户尽量使用通知栏消息。

通知栏消息的优势如下：

1、 降低Push业务的功耗。

传统的Push功能都需要应用的进程存在时才能显示通知栏消息，但是应用进程很难常驻在系统，一般系统出于功耗的考虑会停止后台长时间没有活动的进程，这种情况下当收到通知栏消息需要展示时就需要拉起应用进程，频繁的操作会增加耗电影响手机续航能力。

华为Push采用了统一消息中心（Notification Center，简称NC）的能力，当华为手机收到通知栏消息时由NC统一展示消息，不需要拉起应用的进程。当用户点击通知栏消息时才会拉起应用进程。

2、 通知栏消息到达率通常比透传消息高（不受低功耗方案对广播拉起应用的限制）；但是在灵活性方面透传消息比通知栏消息要好些。

**说明** :

支持NC功能的手机：部分EMUI4.0和4.1的手机，以及EMUI5.0及之后的华为手机。

在非华为手机上面华为Push也有类似NC的能力，依赖HUAWEI HMS Core的能力，不过在非华为手机上HUAWEI HMS Core会受到限制，可能会影响华为推送的到达率。

  


# 2\. 受限说明

## **2.1 Push消息送达率约束**

华为PUSH平台首发在线（用户第一次发送并且接收消息的终端设备网络正常）成功率接近100%。但华为Push平台并不保证100%的消息送达率，影响Push消息送达率的因素有：  
●  终端设备是否在线

如果设备离线， Push平台会缓存消息，待用户上线后，再次将消息投递给用户。Push平台只缓存一次用户的消息，如果用户在线后还发不通，Push平台不再缓存。

●  用户手机上集成HMS SDK的应用是否被卸载

●  移动网络是否稳定

●  终端手机的安全控制策略

●  不同终端厂商设备的支持度

   

## **2.2 不同终端平台对Push消息的限制**

原则上安装了Huawei Mobile Services(APK)的Android终端设备即可支持华为Push业务。

●  华为Android终端设备（设备出厂自带Huawei Mobile Services(APK)）  
华为手机管家可以拦截Android广播消息，Push消息因此也会被拦截。  
●  非华为Android手机（小米、VIVO、OPPO、三星、酷派、中兴等）  
需要终端设备先安装Huawei Mobile Services(APK)。 某些厂商手机可能会删除华为进程，导致消息不可达。

## **2.3 Push消息的及时性**

Push消息首次发送，应用在线联网的情况下，时延在1s内。如果受限于网络环境的情况，消息时延无法保证。

## **2.4 Push消息大小限制**

Push消息支持的Android APP包名称最大为128个字节，消息内容最大限制为2K。

## **2.5 Push消息流控限制**

目前华为Push服务会对如下两个场景进行流控。

●  服务端申请Access Token  
开发者应用服务器短时间内频繁申请Access Token会被网关流控，返回error=6错误码。

●  服务端发送Push消息api.push.hicloud.com  
开发者应用服务器短时间内发送大量的推送消息会被流控，返回HTTP 503状态码。

# 3\. 华为PUSH通道的安全性说明

华为Push通道的安全性分为三个层面。

1、 开发者通过HTTPS通道将消息从APP服务器端发送到华为Push平台。

获取Access Token的URL为：https://login.cloud.huawei.com/oauth2/v2/token

消息发送的URL为：https://api.push.hicloud.com/pushsend.do

华为Push平台对外的证书由华为提供，如图所示。开发者使用时，为了确保连接的是华为Push，可以使用公钥对华为的证书进行验签，并校验证书中的地址域名api.push.hicloud.com

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/94f3b80d0e074170a9ef84862e2f7e03-7486966007853154079.png)

2、 华为Push平台和终端设备之间使用安全的加密通道发送消息。

采用RSA(1024以上)加密算法，如果需要更强的安全性请用户自行加解密信息。

3、 消息到达终端Android系统后, 如果是透传消息, 那么消息是通过广播明文的方式到达Push的。如果是通知消息, 由Push NC显示，点击后直接拉起Push。

l 在华为设备上，华为Push功能使用的广播都设置了系统保护，无法被恶意仿冒

l 在非华为设备上，使用Service方式，加强了安全防护，确保Push功能的安全。

**说明** :

Push NC是客户端的一个模块用来识别Push消息的类型做不同的操作，可以参考Push通知栏消息格式说明。

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/ba4e84960a3a46bbbe51b93ef0da5295-8038771543917609383.png)

**华为Push开放API认证方式**

目前华为Push的开放API存在两种鉴权模式：

l 用户级鉴权模式

开发者使用开发者帐号登录华为开发者联盟后使用Push控制台进行通知消息发送时采用用户级鉴权模式。

说明：

Push控制台是华为为开发者提供的Push消息发送测试平台，可以在线编辑并发送Push消息用于测试应用是否正确集成Push服务。详细使用请参考“[Push控制台发送测试消息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_apptest_agent)”。

  


l 应用级鉴权模式

开发者在应用服务器调用开放API发送的通知消息采用的是基于应用的鉴权模式，在使用前必须获取对应级别的Access Token才能进行正常的消息下发。

**安全性约束**

Push平台只提供通道业务，建议只承载通知消息，如果用户使用Push传输银行卡、用户密码等隐私数据需要由Push供应商自己保证安全性。

  


# 4\. 隐私说明

您的应用集成HMS SDK后，SDK会收集设备标识符，用于内部统计SDK接口的调用成功率、时延及使用次数，并上报给华为服务器。设备标识符包括：IMEI、SN。
