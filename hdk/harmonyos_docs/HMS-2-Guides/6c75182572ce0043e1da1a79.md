# 概述

从2020年9月16日起不推荐使用HMS Core 2.x版本SDK，华为将在2021年9月30日下架HMS Core 2.x版本的SDK。如果您的应用接入了如下版本的一个或多个Kit，需要按照本指导书进行升级操作：

Kit名称 | 版本  
---|---  
Account Kit |  2.x  
Push Kit |  2.x  
In-App Purchases |  2.x  
  
# 升级变更说明

## 公共

功能 | HMS Core 2.x | HMS Core 5.0  
---|---|---  
HMS Agent套件 |  HMSAgent.init HMSAgent.connect | 不再提供HMS Agent套件，即无法再调用HMSAgent.init方法和HMSAgent.connect方法，connect操作由每个HMS服务去实现，开发者无需感知。  
根目录下的build.gradle配置Maven仓 | - | maven { url 'https://developer.huawei.com/repo/' }  
App_ID，cp_id，package_name等一系列配置参数从build.gradle移动到agconnect-services.json中 | 配置在app目录下的build.gradle |  在app目录下导入agconnect-services.json文件。 agconnect-services.json文件的生成，请参见[华为帐号5.0文档](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050048870)。  
删除工程中所有HMS SDK Agent套件代码 | HMS SDK Agent套件代码 | -

## In-App Purchases

功能 | HMS Core 2.x | HMS Core 5.0  
---|---|---  
服务端回调 |  客户端支付成功后，华为服务器会主动回调通知CP服务器。 |  取消支付成功的服务端回调机制，提供新的主动校验机制。开发者如需对支付结果进行校验，可以参考[Order服务购买Token校验](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/order-verify-purchase-token-0000001050033078)。  
支付接口 |  2.x支持pay接口，CP可通过该接口实现商品价格等信息的自定义，无需在华为侧管理商品。 |  取消了自定义价格的支付接口，所有商品必须全部在华为侧配置，调用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section1255302563115)接口完成商品购买。  
发货确认机制 |  2.x不支持发货确认，支付成功后华为侧无法获知CP侧是否发货成功，容易出现掉单。 |  支持发货确认，可实现零掉单： CP收到支付成功回调，发货成功后通过[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口告知华为侧发货成功，华为侧更新内部订单状态。 CP可通过[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section15126153542812)查询已购买但未发货的购买信息，补发货成功后通过[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口告知华为侧发货成功，华为侧更新内部订单状态。

登录授权后，您需要选择团队名称、工程模块、一个或多个Kit名称。在选择Kit时，点击“Click here to select Kit”链接后弹出如下弹框，在弹框内选择对应的Kit，点选“OK”按钮即可完成Kit的选择。

借助两种证书类型，您可以选择已有的证书文件，也可以选择创建一个新的证书。关于证书的指导可参见[Android证书签名](https://developer.android.com/studio/publish/app-signing#generate-key)。

## 设置升级相关的目录信息

设置需要升级的Analysis Path、Excluded Path和Backup Path信息。其中：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20201201141509.18069690190696033959705064781101:50520726075848:2800:CE63EA78D56D531525B8D7D231FB6985AB0827333C68FE81DCB21C0605C37909.png?needInitFileName=true)

  * Analysis Path：选择待分析工程的根目录。

  * Backup Path：备份升级前的项目文件，用于后续恢复工程。只能选择该工程外的目录。其中Excluded Path中的文件不会进行备份。

# 各个Kit的后续升级处理

## Account Kit

### 升级服务端的API

按照[华为帐号升级指导书](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/account_upgrade_guide#h1-1611562951183-0)的“服务端升级变更说明”和“服务端升级指导”章节升级服务端的API。

## Push Kit

### 新增一个HmsMessageService类的实现类

实现一个继承了HmsMessageService类的子类，请参见HmsMessageService类的API参考文档[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839)。

### 重写onNewToken方法

## 备份当前工程以及升级信息

对于大型项目，当开发者执行了部分升级，希望对升级中的工程代码以及升级列表进行存量备份时，点击“Save All”可以实现当前升级中的工程代码以及升级列表备份。后续可以通过“Restore Project”进行恢复，然后从备份时的进度继续完成升级。

备份路径固定为开发者在上一次执行扫描时设置的“Backup Path”目录。备份的zip文件名称为“工程名+时间戳+升级进度”。

## 恢复已备份的工程

在菜单栏选择“HMS > Upgrade > Restore Project”，打开备份工程的恢复设置界面，可以将指定备份目录下的文件恢复到目标目录。

恢复文件后，需要手动在work tree选中当前工程目录，然后右键选择“Reload from Disk”进行刷新。当前备份分为两种：

名称为“工程名+时间戳”的备份，这是对于升级前工程进行的备份，选择这样的备份进行恢复，会还原到升级前的工程，并清空升级列表信息。

名称为“工程名+时间戳+升级进度”的备份，这是工具菜单中的“Save All”功能生成的备份文件，选择该备份文件进行恢复，不仅恢复工程代码，同时还加载升级列表信息，恢复后，可以继续进行升级操作。
