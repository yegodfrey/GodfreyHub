应用在调用支付接口发起支付后，如果应用有自己的服务端，华为支付服务器在支付成功后会调用开发者的回调地址向开发者服务端发起回调，开发者服务器验证支付结果后按照支付成功回调接口中的要求向华为支付服务器返回响应。  
  
在开发过程中，为了保证开发者服务器返回的响应满足华为要求，开发者可以提前进行服务端回调接口测试。

1、登录[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站，点击“管理中心”。

2、在“应用服务”页面，选择“支付”。

3、在应用列表中点击需要测试的应用的“修改”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200225190943.90298384927972972719107752788251:50510916032943:2800:F4EF7F70394EB12C8DEAA5986622181B5F9FBA485D00267C277B25C677BA59A0.png?needInitFileName=true)

4、在“回调地址”栏后点击“服务端回调接口测试”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200225191002.02652722150009844394886764494577:50510916032943:2800:B88D213434DB74D07907291A0A8B814B2CA624B06B8D837C7D5F50B86E475B3F.png?needInitFileName=true)

5、在测试页面中按照支付接口实际传入的参数值配置相关参数信息，点击“发送回调测试”。

注意：

服务器回调测试必须使用页面中默认的测试公钥，测试完成后，在应用中正式进行支付时，请将服务器端验签公钥由测试公钥替换为正式公钥。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200225191033.88571289291508088698069360112679:50510916032943:2800:9CD6D5BA0CF7F1802F100923CB8AC60A948DDC8BA82A48DD53DF5FF014BA851F.png?needInitFileName=true)

● 如果开发者服务器返回的结果满足接口要求，页面将返回0或接口对应的错误码。  
● 如果开发者服务器返回的结果不满足接口要求或消息格式不正确，页面将提示其他错误信息。  
返回消息样例如下：
      
      1. HTTP/1.1 200 Created 
        2. Content Type : application/json ; charset=UTF-8 
        3. { 
        4. "result":0 
        5. }
