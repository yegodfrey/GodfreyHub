# 1. 场景介绍

游戏登录是指开发者为应用申请游戏服务后，华为允许应用使用用户的华为帐号登录游戏。通过华为游戏服务，开发者可以安全快速的获取用户，共享华为庞大的用户资源。

游戏登录的具体交互细节如下：

1、用户启动游戏，应用加载游戏首页。

2、如果用户在当前设备未登录华为帐号，将展示华为帐号登录页面，如左图所示。

3、如果用户的华为账户为中国大陆用户且未进行实名认证，将展示实名认证页面引导用户实名认证，如右图所示。

4、用户登录成功后，应用可以获取玩家信息。

# 2. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224201251.76749036874187504333246080168733:50510903092845:2800:1D6BD90278646014B711D3BDFC6EE7D47B63DFBC1D69A561EAC997C562D3F77A.png?needInitFileName=true?needInitFileName=true)

1\. 用户启动游戏应用，应用执行启动程序。

2\. 应用调用[login](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c9)接口向HMS SDK请求游戏登录。

3\. HMS SDK检查用户的华为帐号登录情况。  
如果用户在当前终端未登录华为帐号，转到4。否则，转到6。

4\. HMS SDK向用户拉起华为帐号登录页面。

5\. 用户输入华为帐号名和密码后确认登录。

6\. HMS SDK检查用户游戏帐号的实名认证情况。  
如果是中国大陆用户且未进行实名认证，转到7。否则，转到9。

7\. HMS SDK向用户拉起实名认证页面。

8\. 用户提交实名认证信息。

9\. HMS SDK会通过回调2次的方式向应用返回登录结果。  
第1次回调时，isAuth为0，且结果中只返回playerId，应用可以先让用户进入游戏，等待第2次回调的登录验签结果。  


第2次回调时，isAuth为1，此时需要对登录结果验签，转到11。

说明：

用户如果是首次登录，首次回调将不会出现isAuth为0的情况。

10\. HMS SDK同时向用户展示欢迎信息和游戏公告信息。  


● 如果应用有自己的开发者服务器，转到11。  
● 如果开发者没有自己的服务器，则由应用客户端需要参考HMS SDK工程目录GameLoginSignUtil.java中的checkLoginSign()方法自行验签，具体方法参见“开发步骤”中的步骤2，验签成功后转到15。

11\. 应用在收到登录结果后向开发者服务器请求进行登录验签。

12\. 开发者服务器调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s4)接口向华为服务器请求进行验证签名。

13\. 华为服务器向开发者服务器返回验签结果。

14\. 开发者服务器验证验签结果后向应用客户端返回验签结果。

15\. 应用确认登录成功后，如果游戏具有游戏等级、角色名称、游戏区服、游戏公会信息，调用[savePlayerInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c1)接口向HMS SDK请求上传角色信息。

说明：

发布地区包含中国大陆的网络游戏（请向华为游戏运营人员确认游戏是否属于网络游戏），必须调用savePlayerInfo接口上传角色信息，但仅支持上传中国大陆用户的角色信息。

16\. HMS SDK通过回调方式返回上传结果。

# 3. 注意事项

● 使用华为帐号登录游戏前，必须已经提前为应用申请游戏服务，参见[申请游戏服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_applygameservice)。

● 如果接口返回7021错误码，表示用户在实名认证窗口中取消了实名认证，建议采用如下步骤引导用户进行实名认证。

   (1) 调用[getCertificationIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c24)接口拉起实名认证弹框。

   (2) 在onActivityResult中调用[getCertificationInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c23)接口查询实名情况，如果未实名，继续调用[getCertificationIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c24)接口拉起实名弹框。

# 4. 开发步骤

游戏登录功能涉及的关键开发步骤如下：

1、 应用加载启动资源后，调用[login](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c9)接口并处理结果回调。  
当登录成功时，onResult方法会回调2次。  
● 第1次，isAuth为0，登录结果中只返回playerId和isAuth。  
● 第2次，isAuth为1，会返回所有登录信息，应用需要对登录结果验签，参见步骤2。  
代码需要根据isAuth值区分处理这两次回调。  
● 如果游戏要求快速登录且对安全性要求不高，可先使用第1次回调结果中的用户playerId允许用户先进入游戏，同时等待第2次回调的异步登录验签结果。  
\-  登录验签成功，则允许用户继续游戏。  
\-  验签失败则终止游戏并提示重新登录。  


● 如果游戏要求必须验签成功后才能允许用户进入游戏，应用可以忽略第1次的回调结果，直接根据第2次回调结果判断是否登录成功。

说明：

用户首次登录时，第1次回调isAuth为1，应用必须等待登录验签成功后才能让用户进入游戏。

示例代码如下：
      
      1. private void login() {
        2.     showLog("game login: begin");
        3.     HMSAgent.Game.login(new LoginHandler() {
        4.         @Override
        5.         public void onResult(int retCode, GameUserData userData) {
        6.             if (retCode == HMSAgent.AgentResultCode.HMSAGENT_SUCCESS && userData != null) {
        7.                 showLog("game login: onResult: retCode=" + retCode + "  user=" + userData.getDisplayName() + "|" + userData.getPlayerId() + "|" + userData.getIsAuth() + "|" + userData.getPlayerLevel());
        8.             // 当登录成功时，此方法会回调2次
        9.             // 第1次：只回调playerId，userData.getIsAuth()为0，在要求快速登录时可以用此playerId登录
        10.             // 第2次：回调所有信息，userData.getIsAuth()为1，此时需要对登录结果进行验签
        11.                 if (userData.getIsAuth() == 1) {
        12.            // 如果需要对登录结果进行验签，建议发送请求到开发者服务器进行。
        13.            // 下面的示例代码为在客户端验签的示例代码，实际验签建议放在应用的服务端。
        14.                     GameLoginSignUtil.checkLoginSign(appId, cpId, game_priv_key, game_public_key, userData, new ICheckLoginSignHandler() {
        15.                         @Override
        16.                         public void onCheckResult(String code, String resultDesc, boolean isCheckSuccess) {
        17.                             showLog("game login check sign: onResult: retCode=" + code + "  resultDesc=" + resultDesc + "  isCheckSuccess=" + isCheckSuccess);
        18.                         }
        19.                     });
        20.                 }
        21.             } else {
        22.                 showLog("game login: onResult: retCode=" + retCode);
        23.             }
        24.         }
        25.     }, 1);  
         
        26. }
    
    

2、 应用对登录结果验签。  


● 如果应用在服务器端进行登录验签，则应用服务端可调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_s4)接口完成验签。  
示例代码可参见[游戏服务端示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Examples/hmssdk_jointOper_game_sample_code)。  
●  如果应用没有自己的服务器，则可以参考HMS SDK工程目录GameLoginSignUtil.java中的checkLoginSign()方法在应用客户端自行完成验签，方法定义如下：  
GameLoginSignUtil.checkLoginSign(appId, cpId, game_priv_key, game_public_key, userData, ICheckLoginSignHandler handler);  
\- appId：应用ID，查询方法参见[查询应用ID](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_queryappid)。  
\- cpId：支付ID，查询方法参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_querypayinfo)。  
\- game_priv_key：游戏私钥。  
\- game_public_key：游戏公钥。游戏公钥和私钥查询方法可参见[查询游戏服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_queryGameService)。  
\- userData：回调结果中的返回参数对象，可直接使用login接口返回的userData对象。  
\- handler：checkLoginSign方法的回调结果。  


定义方法：
      
      1. public interface ICheckLoginSignHandler{ 
        2.         /** 
        3.         * 结果回调 
        4.         * @param code 返回码 
        5.         * @param resultDesc 结果描述 
        6.         * @param isCheckSuccess 验签是否成功 
        7.         */ 
        8.        void onCheckResult(String code, String resultDesc, boolean isCheckSuccess) ; 
        9. }
    
    

示例代码可参见步骤1。

警告：

为了确保游戏私钥和游戏公钥的安全性，强烈建议将验签过程放在应用服务端进行。如果没有服务器保存密钥，建议在C或者C++语言编译的库中存储密钥，或者在java代码中分不同位置存储密钥，然后相加获得完整密钥。

3、发布地区包含中国大陆地区的网游，登录成功需要调用[savePlayerInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c1)接口。  


示例代码如下：
      
      1. private void savePlayerInfo() {
        2.     showLog("game savePlayerInfo: begin");
        3.     GamePlayerInfo gpi = new GamePlayerInfo();
        4.     gpi.area = "20";
        5.     gpi.rank = "level 56";
        6.     gpi.role = "hunter";
        7.     gpi.sociaty = "Red Cliff II";
        8.     HMSAgent.Game.savePlayerInfo(gpi, new SaveInfoHandler() {
        9.         @Override
        10.         public void onResult(int retCode) {
        11.             showLog("game savePlayerInfo: onResult=" + retCode);
        12.         }
        13.     });
        14. }
    
    

如果上传的角色信息不属于中国大陆用户，将直接返回7006错误码。
