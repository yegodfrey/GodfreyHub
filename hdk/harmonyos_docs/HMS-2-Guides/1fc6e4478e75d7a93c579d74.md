# 1\. Push控制台发送测试消息

开发者可以在华为开发者联盟PUSH控制台在线编辑PUSH消息，并向已经从PUSH服务器获取Token的设备推送消息，开发者联盟PUSH控制台支持发送“通知栏消息”和“透传消息”。本章节重点介绍如何在控制台上编辑和发送这两种PUSH消息。PUSH控制台只提供给开发者单个或者小批量的PUSH消息发送测试，如果开发者需要实现大批量的消息推送，需要参考“服务端开发”完成自己应用服务器的开发。

登录开发者联盟，进入PUSH控制台，点击应用的“新增推送”按钮，如图5-1所示。

---|---|---|---

标题                 | 用户自定义                 | 否                 | 最大支持长度40                   
消息内容                 | 用户自定义                 | 是                 | 最大支持长度80                   
点击通知                 | 选择其一                 l 打开应用                 l 打开网页                 l 打开富媒体                 | 是                 | 选择“打开应用”方式可以定义后续行为                 选择“打开网页”方式可以定义打开页面的URL                 选择“打开富媒体”方式可以自定义富媒体                   
后续行为                 | “点击通知”选择“打开应用”时显示                 选择其一                 l 直接打开应用                 l 自定义动作                 | “点击通知”选择“打开应用”时必选                                   | 开发者可以自定义Intent，如果选择自定义动作需要填写自定义intent，用户收到通知栏消息后点击通知栏消息打开应用定义的这个Intent页面，该过程通过context.startActivity(intent)实现，获取Intent字符串具体代码如下：                 Intent intent = new Intent(Intent.ACTION_VIEW);                 intent.setData(Uri.parse("unitehnreader://nativepage/book/detail?bid=357735?closeback=1&startinner=0"));                 intent.addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP);                  String intentUri = intent.toUri(Intent.URI_INTENT_SCHEME);                  Log.d("intentUri", intentUri);                 其中intent.addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP);是应用必须添加的选项，如果不添加该选项有可能会显示重复的消息，其他为应用自己的配置项。生成的intentUri字符串即为intent参数需要填写的值。                                     
输入网址                 | “点击通知”选择“打开网页”时显示                 | “点击通知”选择“打开网页”时必选                 | 需要打开网页的网址                 例如：https://developer.huawei.com/consumer/cn/hms                   
编辑富媒体                 | “点击通知”选择“打开富媒体”时显示                 | “点击通知”选择“打开富媒体”时必选                 | 自定义实现自己的富媒体文本

**Ø  透传消息发送举例：**

# 2\. 下一步

到这一步开发者已经完成了所有必要的开发和测试工作，在上架应用前开发者需要确保自己的应用满足应用市场上架的条件，为此华为提供了[自动检测平台](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_selfcheck_tool_agent)供开发者上传应用并输出检测报告，同时也提供了[自检checklist](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_huaweipush_selfcheck_agent)帮助开发者自行完成检查工作。
