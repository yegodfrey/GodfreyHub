# 1. 场景介绍

应用升级是指用户启动应用后应用后台主动检查新版本，或用户在应用的检查升级入口主动触发升级检查操作，HMS SDK从华为应用市场请求下载新版本应用并进行升级安装的过程。

具体交互细节如下：

1、用户启动应用或在应用内主动触发检查升级操作。

2、应用检查到更新后拉起升级确认页面，如左图所示。

3、用户确认升级后进入华为应用市场的应用升级页面，执行升级操作，如右图所示。

# 2. 业务流程

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200224201048.95476351119063807602995706143729:50510916032942:2800:76F4749BFF6D7B711CB10597A5E164889B54E896EFEAFE5D18632AE56689E9CC.png?needInitFileName=true)

1\. 用户触发检查升级操作，例如启动应用或主动在检查升级页面检查升级。

2\. 应用调用[checkUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiid_api_reference_game_checkUpdate)接口请求检查应用是否有更新。

3\. HMS SDK在华为应用市场查询最新的应用版本信息。

4\. 华为应用市场向HMS SDK返回应用版本信息。

5\. HMS SDK通过回调方式将检查结果返回给应用。

6\. 应用根据检查结果判断应用是否需要升级。  
   ● 如果应用版本有更新则进行下一步。  
   ● 如果应用版本没有更新，则流程结束。

7\. HMS SDK向用户拉起升级提示页面。

8\. 用户在升级确认页面中选择升级应用。

9\. HMS SDK向华为应用市场请求下载最新的应用安装包。

10\. 华为应用市场向HMS SDK返回应用软件包。

11\. HMS SDK在下载完成后启动应用安装。

# 3. 开发步骤

应用升级功能仅涉及调用[checkUpdate](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiid_api_reference_game_checkUpdate)接口。

示例代码如下：

        3.     public void onResult(int rst) { 
        4.           showLog("check app update rst:" + rst); 
        5.         } 
        6. }
