# 1. 场景介绍  
  
为了使游戏与手机系统深度配合，根据不同的游戏场景，将资源调配到最佳状态，对复杂游戏场景带来更流畅的体验，应用可以通过HMS SDK实现以下硬件能力：

● 实时查询系统温度，并根据系统返回的设备温度信息，主动调整游戏运行模式适配设备状态，保障用户的流畅体验。  


● 当游戏界面同时存在多个对象，容易发生卡顿时，例如多人PK、回城、观战、特效较多等情况，应用可以将游戏信息主动上报到HMS SDK，系统调控资源适配游戏场景，从而保障用户的流畅体验。

# 2. 业务流程

1\. 开发者通过邮件的方式向华为游戏中心申请使用开放硬件能力功能。  
合作伙伴提交权限申请邮箱：game.business@huawei.com，华为游戏中心在3个工作日内回复。

2\. 权限成功开通后，应用在游戏运行中的合适时机调用[registerHardwareCapability](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c18)接口向HMS SDK请求注册硬件开放能力。  
只有注册通过的应用才可以建立游戏和手机系统之间的通讯机制。

3\. HMS SDK通过回调方式向应用返回注册结果。

4\. 应用根据游戏运行的实际场景，在合适时机调用[getTemperature](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c17)接口向HMS SDK请求查询当前系统的温度。

5\. HMS SDK通过回调方式向应用返回当前系统的温度数据，当前分为“高”、“中”、“低”3档。  
当温度为“高”时，应用需要降低影响游戏性能的参数，例如画质、特效等，以保障游戏的流畅度。

6\. 当游戏场景发生切换或场景内信息发生变化时，应用可以调用[updateGameInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c19)接口向HMS SDK请求上传游戏信息。

7\. HMS SDK通过回调方式返回上传结果，并根据应用上传的游戏信息调控资源适配游戏场景，以保障游戏的流畅度。

# 3. 注意事项

● 当前开放硬件能力只支持在中国大陆地区发布的应用。  
● 只支持特定的华为手机（目前仅支持EMUI8.2及以上版本），并且HMS Core（APK）的版本需要大于2.6.1。  


● 只有向华为游戏中心成功提交并通过审核的应用才可以使用该能力。

# 4. 开发步骤

开放硬件能力涉及应用的关键开发步骤如下：

1、调用[registerHardwareCapability](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c18)接口。  
应用根据接口返回码判断注册是否成功。  


示例代码如下：
      
      1. private boolean isRegister = false;
        2. private void registerHardwareCapability() {
        3.     showLog("registerHardwareCapability: begin");
        4.     HMSAgent.Game.registerHardwareCapability(new RegisterHardwareCapabilityHandler() {
        5.         @Override
        6.         public void onResult(int retCode) {
        7.             showLog("registerHardwareCapability: onResult=" + retCode);
        8.             if(retCode == GameStatusCodes.GAME_STATE_SUCCESS) {
        9.                 isRegister = true;
        10.             } else {
        11.                 isRegister = false;
        12.             }
        13.         }
        14.     });
        15. }
    
    

2、在合适时机调用[getTemperature](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c17)接口。  
● 在调用getTemperature接口前，应用需判断是否已经注册开发硬件能力。  
● 应用需要根据返回的温度档位对游戏进行不同的处理。  


示例代码如下：
      
      1. private void getTemperature() {
        2.     if(!isRegister) {
        3.         return;
        4.     }
        5.     showLog("getTemperature: begin");
        6.     HMSAgent.Game.getTemperature(new GetTemperatureHandler() {
        7.         @Override
        8.         public void onResult(int retCode, TemperatureResult result) {
        9.             showLog("getTemperature: onResult=" + retCode);
        10.             if(retCode == GameStatusCodes.GAME_STATE_SUCCESS && result != null) {
        11.                 showLog("getTemperature: onResult=" + result.getTemperature());
        12.                 String temperature = result.getTemperature();
        13.                 if(!TextUtils.isEmpty(temperature)) {
        14.                     try {
        15.                         JSONObject object = new JSONObject(temperature);
        16.                         int temperatureInfo = (int) object.getInt("temperature");
        17.                         if(temperatureInfo == 1) {
        18.                             //温度低
        19.                         } else if(temperatureInfo == 2) {
        20.                             //温度中
        21.                         } else if(temperatureInfo == 3) {
        22.                             //温度高
        23.                         }
        24.                     } catch (JSONException e) {
        25.                         e.printStackTrace();
        26.                     }
        27.                 }
        28.             }
        29.         }
        30.     });
        31. }
    
    

3、调用[updateGameInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c19)接口。  


在调用接口前，应用需判断是否已经注册开发硬件能力。

        5.     showLog("updateGameInfo: begin");
        6.     GameInfo info = new GameInfo();

        8.      * info.setxxxx;
