# 场景介绍

在华为帐号登录时，应用为了更高的安全性，必须在应用的服务器端保存用户信息。应用服务端需要直接根据signIn接口返回的用户accessToken访问华为服务器获取用户帐户信息。如果此时返回accessToken失效（NSP_STATUS=6），应用服务端使用新的accessToken尝试后仍然返回accessToken失效，此时可通过注销授权的方式清除HMS SDK的缓存，然后再重新获取accessToken后尝试。

由于注销华为帐号授权后，再次登录会闪现短暂的授权界面，影响用户体验。除以上场景，请勿轻易注销华为帐号登录授权。

# 业务流程

1\. 应用客户端调用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口后将获取的用户accessToken传递给应用的服务端。

2\. 应用服务端使用accessToken调用获取用户帐号信息接口尝试访问华为服务器请求获取用户信息。

3\. 华为服务器返回accessToken失效。

此时应用服务端可以重新调用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口后使用新的accessToken访问华为服务器，如果仍然返回失效则转到下一步。

4\. 应用客户端调用[signOut](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c2)接口向HMS SDK请求注销华为帐号授权。

5\. HMS SDK清理缓存后向应用返回注销授权结果。

6\. 应用客户端重新调用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口请求获取accessToken。

7\. HMS SDK向应用客户端返回新的accessToken。

8\. 应用客户端将新的accessToken传递给应用服务端。

9\. 应用服务端使用新获取的accessToken访问华为服务器。

# 注意事项

● 必须已经提前为应用开通帐号服务，参见[开通帐号服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_apply_account_service)。  
● 帐号注销授权仅在多次访问华为服务器返回accessToken失效时用于清除HMS SDK缓存，其他场景请勿注销授权。

# 开发步骤

华为帐号注销授权功能涉及应用的关键开发步骤如下：

1、应用客户端将用户的accessToken传递给应用服务端，此部分由开发者自行完成。

2、应用的服务端使用accessToken调用[获取用户帐号信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_queryUser)接口访问华为服务器，返回accessToken失效。

3、应用调用[signOut](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c2)接口请求注销授权。
