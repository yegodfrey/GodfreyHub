# 管控设备硬件损坏SN替换问题

被管控的设备，硬件损坏，通过华为官方售后维修，出具华为终端服务报告（需要展示损坏设备SN），设备管控有效期内，可免费替换SN。

<br />

第一步

请提供以下信息：

华为终端服务报告

![](https://media:201786691183792335 "点击放大")

需要替换的设备序列号与图片（SN）

被替换的设备序列号（SN）

原设备所属企业及该企业HEM ID

邮件发送至heminquiry@huawei.com

<br />

第二步

保留HEM后台损坏设备SN数据，不做任何变动或操作

新的SN无需用户/渠道手动上传HEM，审核完成后，系统会操作替换。

<br />

第三步

5个工作日内完成替换流程后，新设备开机激活，损坏设备恢复出厂或由售后处理。
