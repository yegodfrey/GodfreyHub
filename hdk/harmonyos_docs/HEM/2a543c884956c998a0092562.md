# 企业开箱定制操作流程（隐藏）

![](https://media:201786691178137267)  
1、使用场景：适用于购买HEM付费套餐的用户。

2、如需使用三方管控请告知您的管控厂商在项目之处，[点此适配HEM平台](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-osnext-cope-0000002268995666)。

3、设备开机后，修改企业开箱定制策略，需要设备恢复出厂方可生效。

4、目前仅支持HarmonyOS 5.1及以上系统。
