# 如何管理企业客户

![](https://media:201786691173312215)  
目的：

绑定您的企业客户，绑定企业客户之后您才能为企业上传企业已采购的设备的信息（SN号）。在绑定企业客户之前，您需要获取他在HEM中的HEM ID信息。  

#### HEM ID

在绑定企业用户之前，您需要获取他的HEM ID信息。

进入HEM管理台，鼠标移到右上角企业名称处，复制HEM ID线下传递给您的企业用户。

![](https://media:201786691173393216)  

#### 添加企业客户

1、登录HEM渠道商控制台，选择"设备注册"。

![](https://media:201786691173713217)

2、选择"客户管理菜单，在"客户列表"页面点击"添加"添加您的客户。

![](https://media:201786691173858218)

<br />

3、在"添加"页面填写您线下沟通获取的HEM ID，可以点击右侧的"检测"进行信息验证。

![](https://media:201786691173972219)  
![](https://media:201786691174011220)  
同一企业客户只需添加一次即可。您需线下联系您的企业客户以获取其企业ID信息。

需要HEM企业客户登录HEM官网，点击右上角账号下拉菜单，查看ID信息。

![](https://media:201786691174042221)

4、点击"添加"完成企业客户的添加。  

#### 删除企业客户

在"客户列表"界面选择客户后，点击右侧的"删除"按钮并确认，可删除企业客户。  
![](https://media:201786691174086222)  
删除企业客户后，后续您将无法为此企业客户上传设备信息，请谨慎操作。

<br />
