# 如何管理应用

![](https://media:201786691192118496)  
目的：

1、在企业应用管理中添加的应用，策略管理中才能选中。

2、策略中添加的应用，设备OOBE阶段中自动安装。  

#### 添加企业应用

<br />

在HEM管理台-企业应用管理界面，右侧，点击添加按钮；

![](https://media:201786691192195497)

<br />

手机/平板请选择AppGallery应用：若是公开发布的应用填写应用名；若是非公开发布的应用请填写包名；

PC可选择AppGallery应用或者[企业应用](https://developer.huawei.com/business/cn/doc/HEM/hem-qyyyfl-0000002467258392#section55917372110)，请填写相应的应用信息；

![](https://media:201786691192242498)
