# 企业资料人工审核认证

![](https://media:201786691187206400)  
目的：对企业进行资质认证。

注意：企业资料人工审核认证需要提供企业基本信息、企业相关证件、法人身份证证件，审核周期一般为1-2个工作日。

1、进入[HEM官网](https://developer.huawei.com/business/cn/overview)的"管理中心"，登陆您的华为账号，选择"企业资料人工审核认证"。

![](https://media:201786691187261401 "点击放大")

2、进入实名认证界面，填写您的企业基本信息，上传营业执照、法人手持身份证照片等信息。

![](https://media:201786691187304402 "点击放大")

3、填写您企业的联系人信息，包括姓名、邮箱、手机号等。

![](https://media:201786691187339403 "点击放大")

4、填写和您对接沟通的华为方销售联系信息，包括销售的姓名、华为邮箱、手机号。  
![](https://media:201786691187377404)  
华为方销售是指与您前期沟通对接项目相关事项的华为方销售人员，如各省份华为终端政企同事。

![](https://media:201786691187498405 "点击放大")

5、查看并同意企业客户服务\&隐私协议，点击"提交"。

![](https://media:201786691187527406 "点击放大")
