# MDM应用测试

![](https://media:201786691190815471)  
目的：测试您上传的MDM应用是否能正常获取MDM权限授权与自动部署，测试完成后才能正式商用。

有效期：目前测试SN MDM权限有效期为3个月，3个月后MDM权限自动失效。

1、登录控制台，在"MDM应用测试"页面点击"新建任务"。

![](https://media:201786691190851472)

2、填写权限申请相关信息。

![](https://media:201786691190890473) ![](https://media:201786691190936474)

相关字段信息说明：

创建任务

* 任务名称：填写您MDM测试项目的名称。
* 终端类型：根据您实际项目情况进行选择"手机\&平板"、"PC"。
* 操作系统类型：HarmonyOS NEXT
* 选择测试SN：每个SN号只能绑定一次，如需再次绑定请至测试SN号列表解除管控后再绑定。
* 选择MDM应用软件包：选择已上传的MDM应用软件包。
* 设备定制信息（根据业务诉求，无特定模板）
* 协议名称：企业和设备使用者之间的服务协议条款的名称。
* 协议条款：企业和设备使用者之间的服务协议条款，该条款将在OOBE首次开机过程中要求设备使用者"同意"。
* 单位：填写测试设备所属公司。
* 联系人：填写测试设备所属公司的联系人名称。
* 联系人邮箱：填写测试设备所属公司的联系人邮箱。
* 联系人手机：填写测试设备所属公司的联系人手机号。

<br />

3、点击"提交"，完成"新建测试任务"的申请。提交申请后会自动审批通过，无需审核。

![](https://media:201786691190972475)

4、验证MDM权限与自动部署测试

设备恢复出厂并联网激活（不区分设备类型）

注：如您仅想测试MDM权限可自行手动（hdc）安装MDM 调试应用，验证是否有MDM权限（具体激活验证方式根据业务实现方式验证）后，也请自行手动去激活。
