# BYOD项目获取设备激活记录

一、功能介绍

此接口提供给企业开发者，用于获取企业在HEM平台注册的BYOD设备激活记录。

<br />

二、接口原型  

|-----|-----------------------------------------------------------------------|
|承载协议|HTTPS GET|
|接口方向|企业主服务器 -\> 行业解决方案（HEM）平台|
|接口URL|/api/hem/enterprise/byod-device-recode|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

三、请求参数  
1、Request Header  

|-------------|------|----|------|
|参数名称|参数类型|是否必填|描述信息|
|Authorization|String|是|鉴权头信息|
|client_id|String|是|企业密钥id|

2、Request Param  

|---------|-------|----|-------------|--------------|
|参数名称|参数类型|是否必填|长度/大小限制|描述信息|
|pageNum|Integer|是|大小：大于0|分页参数：查询页码|
|pageSize|Integer|是|大小：\[4,1000\]|分页参数：分页大小|
|startTime|Long|是| |操作记录时间区间：起始时间戳|
|endTime|Long|是| |操作记录时间区间：结束时间戳|
|projectId|String|否|长度：\[0,32\]|项目id|

四、请求示例

```
GET https://connect-api.cloud.huawei.com/api/hem/enterprise/byod-device-recode/?startTime=1762669488000&endTime=1765175090916&pageNum=1&pageSize=5
 Headers  
 Authorization: Bearer eyJraWQiOiJJbnBuMjNUaUJZbnJCb1RiYzJwSDhMaHdTMFdwUUFLViIsInR5cCI....... 
 client_id: 321153465481515
```

<br />

五、响应参数  
1、Response Body  

|----------|--------------------------------------|----|------------|
|参数名称|参数类型|是否必填|描述信息|
|rtnCode|Integer|是|分页参数：查询页码|
|rtnMsg|Integer|是|分页参数：分页大小|
|pageNum|Integer|否|分页页数|
|pageSize|Integer|否|分页大小|
|totalPages|Integer|否|分页总数|
|totalCount|Long|否|BYOD设备操作记录总数|
|result|List\< EnterpriseByodDeviceRecodeVo \>|否|BYOD设备操作记录集合|

2、EnterpriseByodDeviceRecodeVo  

|--------------|------|----|----------------------------------------------------------------------------------|
|参数名称|参数类型|是否必填|描述信息|
|uuid|String|是|设备uuid|
|projectId|String|是|项目id|
|projectName|String|是|项目名称|
|operateType|String|是|操作类型； 操作状态： 0：开始激活； 1：激活成功上报 ； 2：去激活成功上报； 3：激活失败上报； 4：开始去激活 ； 5：去激活失败上报 ； 6：停止去激活；|
|operateTime|long|是|操作时间|
|customizedInfo|String|是|自定义信息|
