# 使用EMM APP部署流程

![](https://media:201786691180571285)  
1. 一个MDM APP可以绑定多个项目，申请不同的MDM商用权限。
2. MDM APP业务侧内容如需更新，请做应用内自更新。仅需要更新MDM商用权限时，MDM APP无需更新。
3. MDM APP审核中：确保数据备份安全，AndroidManifest.xml中android:allowBackup需设置为false。
4. MDM应用在完成激活的同时获取华为MDM（Mobile Device Management）权限授予。在线授权存在有效期限制（最长10年），过期后需要重新申请。
5. 由于权限的发放时间为MDM APP在设备上的激活时间，依赖云侧的权限发放，所以如果端侧与云侧的系统时间不同步，会导致授权存在一定的时间差异常。
6. HEM平台只记录DPC部署状态，因状态上报依赖客户端网络状态，为保证客户端状态准确性，建议三方DPC安装部署完成后，自行上报部署状态至对应云侧，实现三方DPC的使用统计。
7. 自动部署：需要渠道提前绑定设备序列号，然后序列号白名单的设备首次开机激活时将自动部署即安装三方的管控APP。设备恢复出厂后依然会重新执行自动部署。
8. MDM接口授权：可实现MDM接口的授权（可使用的[MDM接口文档请点击此处查看](https://developer.huawei.com/consumer/cn/doc/system-References/api-desc-0000001053522874)，接口使用问题请咨询MDM）。
9. MDM业务逻辑：由三方EMM厂家自行实现。

![](https://media:201786691180855287)  
1、HEM负责协助三方安装APK到终端设备同时对APK授予管控权限，如遇到设备/应用管控等疑问，需要咨询三方EMM厂商。

2、企业用户和渠道商角色注册，根据实际项目场景来决定是否为同一个开发者，但渠道商与EMM厂商角色不能为同一个开发者。

3、建议在完成管理中心所有配置后再启动终端设备，若选择DO模式请勿使用手动部署，否则需要将终端设备重新恢复出厂设置。
