# HEM套餐授权

![](https://media:201786691196538567)  
1、为您的套餐设备数量授权/取消授权（license），只有在设备是分配了使用HEM管控的部署策略且设备是"待部署"状态才能取消授权（取消套餐生效状态）。  

#### 授权（生效套餐）

选择需要授权/取消授权的设备，点击右上角 "授权设备"，点击"授权"/"取消授权"。若无法点击取消授权，请确认是否为该设备分配了部署策略。

![](https://media:201786691196577568)

<br />

如套餐到期需要继续管控，可点击：延期授权

![](https://media:201786691196671569 "点击放大")

设备状态对应表  

|设备状态|状态含义|
|:---|:------------------------|
|未授权|暂未获取license授权|
|待部署|已获取license授权，但是设备暂未进入注册流程|
|已失效|授权超期，或者管理员已经对该设备做解除管控|
|已锁定|设备已锁定|
