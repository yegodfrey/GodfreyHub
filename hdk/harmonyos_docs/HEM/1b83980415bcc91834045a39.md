# 如何完成信息发布

![](https://media:201786691191785490)  
目的：

信息发布可以进行消息推送和信息窗管理，使企业终端用户可以及时接收到相关信息。推送功能依赖于HEM企业管控软件，终端设备需要安装软件才可以收到发布的相关信息。

1、新建消息

在HEM管理台-信息发布-消息管理页面，点击右上角"新建消息"按钮进入消息编辑页面；

![](https://media:201786691191896491 "点击放大")

在消息编辑页面，输入消息标题、消息内容，选择发送时间，可以选择立即发送，也可以定时发送，选择发送人群，可以通过群组和组织对发送人群进行筛选管理。

![](https://media:201786691191932492)

![](https://media:201786691191972493)

2、查看消息

选择要查看的消息，点击右侧"详情"按钮，可以查看消息详情。

![](https://media:201786691192009494)

3、删除消息

点击右侧"删除"按钮，可以删除该条消息；也可以勾选多条消息，点击页面右上角"删除"按钮进行批量删除。

![](https://media:201786691192061495)
