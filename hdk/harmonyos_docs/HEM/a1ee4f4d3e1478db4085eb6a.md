# 回调码汇总

|错误码|错误原因|解决方法|
|:----------|:--------------------------------------------------|:--------------------------------------------------------------------------------|
|1000|内部错误|* 检查当前网络是否可用 * 重试请求 * 设备不支持部署|
|1001|网络未连接|检查当前网络是否可用|
|1002|接口请求参数不符合规定（比如长度错误，必传项没有传之类）|请检查请求参数是否正确|
|<br /> 1003|包名与指纹证书不正确|确认包名是否正确，如果包名正确，则检查指纹证书的正确性|
|<br /> 1003|MDM权限已激活设备数大于可激活的设备数|重新申请MDM权限|
|<br /> 1003|部署策略不存在|重新分配部署策略（商用）|
|1004|DPC App的MDM License过期。|请确认License是否过期，如过期请登录管理台申请License续期。|
|1005|DPC App的MDM License未授权。|请检查License与设备所在项目是否绑定。|
|1006|HEM查询DPC App的MDM License后，调用PMS方法设置权限失败。|检查HMS Core版本是否为5.2.1及以上版本。|
|2000|激活成功。|-|
|3000|去激活成功。|-|
|3001|去激活失败。|* 检查HMS Core版本是否为5.2.1及以上版本。 <!-- --> * 检查当前网络是否可用。|
|2001|HEM无此报错且并非所有报错都与HEM相关，此报错仅提供排除问题方案，如最终无法解决，建议更换测试设备|* 请自行检查设备是否为定制ROM的demo版本 * 请自行检查是否为墨水屏等缺少部署组件的设备 * 请自行检查是否后台提交表格等必要项有删除模板、填写错误等问题|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
