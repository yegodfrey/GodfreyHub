# 关于HEM在企业场景下提供HarmonyOS 5及以上设备管理能力说明

HEM 作为企业场景项目中HarmonyOS 5及以上设备安全管理服务提供方，为企业（以下简称"企业"）的"违约限制使用"项目提供核心的技术能力支持。本声明旨在阐明HEM平台提供的能力范围、必要的权限使用目的，并明确对恶意破坏租赁设备管理行为的法律立场。

一、 平台核心能力说明

HEM平台为企业提供基于移动设备管理（MDM）技术的设备屏幕与功能锁定能力。该能力主要用于保障企业及其客户在设备使用期间的资产安全，具体体现在：

远程设备屏幕与功能锁定： 在企业管理周期内触发安全风险场景下（如设备遗失、使用期内未归还、设备异常状态等），在设备管理期限内企业可通过HEM管理平台，远程下发指令锁定指定设备屏幕与功能的锁定。

二、 必要的权限使用与目的

为实现上述限定的设备屏幕锁定功能，在设备开箱配置（OOBE）阶段，经最终用户明确同意隐私协议与企业设备协议后，系统将自动安装由HEM平台提供的"设备配置"应用（企业设备管理应用）。该应用在运行期间需要且仅会申请和使用以下必要权限：

1. 获取设备序列号（SN）： 唯一目的 在于精确标识设备身份，确保锁定/解锁指令准确无误地下发至目标设备，并与企业管理平台进行绑定。

2. 允许互联网访问： 唯一目的 在于使"设备配置"应用能够与平台云端服务进行安全通信，实时接收来自企业管理平台下发的锁机/解锁指令，并上报设备状态。

3. 允许启用Kiosk（单一应用/锁定屏幕）模式： 核心权限，唯一目的 在于实现屏幕锁定功能，将设备界面限制在预设的安全信息页面或指定应用，阻止用户进行非授权操作。

4. 必要的设备限制权限： 如网络禁止、应用禁止等权限，唯一目的在于保障锁定功能的有效性和设备安全，防止锁定被轻易绕过。

所申请的每一项权限均严格服务于实现"设备屏幕与功能锁定"功能目标，不会用于任何无关目的。且HEM平台除了设备SN与设备状态外不会获取任何设备端个人数据。

无额外数据收集： "设备配置"应用及HEM平台不会收集或上传设备SN与设备状态以外的用户个人数据、应用数据、通讯录、通话记录、短信、非必要的位置信息等。

管理权限边界： 锁定/解锁指令的发起权仅属于企业及其授权客户通过其专属管理平台操作。HEM仅提供技术能力支撑，不主动发起或干预具体设备的锁定/解锁决策。

三、 关于恶意破解行为的严正声明

企业设备的所有权归属于企业用户。安装在设备上的"设备配置"应用及相关的设备管理策略，是保障企业资产安全的核心技术措施。实施以下行为均构成严重违法与违约：

1. 非法卸载、禁用、破坏或干扰 "设备配置"管理应用的正常运行；

2. 利用Root、越狱、刷机、漏洞利用工具、非授权调试接口等任何技术手段，蓄意绕过、破解或解除 由企业通过HEM平台合法下发的设备锁定状态；

3. 故意篡改设备固件、系统设置或安装恶意软件，以规避或破坏HEM平台提供的设备管理功能；

4. 其他任何明知或应知会损害设备管理功能有效性 的操作。

上述恶意破坏行为：直接侵犯了设备企业的财产所有权。同时此类行为属于破坏计算机信息系统功能，干扰合法技术服务，可能违反《中华人民共和国刑法》第二百八十五条、第二百八十六条（非法侵入计算机信息系统罪、破坏计算机信息系统）、《中华人民共和国网络安全法》、《中华人民共和国治安管理处罚法》等相关法律法规 。
