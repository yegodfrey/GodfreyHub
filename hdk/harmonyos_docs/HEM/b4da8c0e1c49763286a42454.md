# 如何开通付费服务

![](https://media:201786691184215342)  
目的：

您需要先开通付费服务后才能够购买HEM套餐。

1、HEM管理中心---个人中心---个人信息设置---付费服务，点击"立即开通"进行付费服务信息维护。

![](https://media:201786691184262343)

2、完善发票信息和发票邮寄信息。

* 选择是否为增值税一般纳税人，增值税一般纳税人需上传三证合一的营业执照和一般纳税人资格证书；

![](https://media:201786691184296344 "点击放大")

* 非增值税一般纳税人，仅需上传三证合一的营业执照照片；
* 填写发票信息：发票抬头（默认和您企业主实名认证的主体名称一致，不支持修改）、税号、税务注册地址、注册电话、开户行和银行账号信息；

![](https://media:201786691184343345 "点击放大")

* 填写邮寄信息：发票寄送地址、邮寄联系人姓名、联系电话、发票寄送Email等。

![](https://media:201786691184459346 "点击放大")

3、保存信息后即可购买套餐，如您的发票或发票邮寄信息发生变更，请及时在此处进行维护，以免影响您后续开票。

* 开票功能说明：只能给当前企业主认证的帐户主体开票，请您妥善处理以免影响开票事宜；
* 开发票时间：本月开上个月的发票，发票寄出时间在20号左右（节假日顺延）；
* 企业税务信息、发票邮寄信息如发生变更，请及时在管理中心-个人中心-设置-付费服务进行更新维护。
