# 鸿蒙PC企业版套餐授权

![](https://media:201786691198102595)  
仅为鸿蒙PC授权，企业版套餐；需与部署策略中的企业版配置搭配使用。

[PC企业定制版配置方法](https://developer.huawei.com/business/cn/doc/HEM/hem_user-guide_add-reseller_management-devices-ot-0000002307766441#section1177603005511)  

#### 授权套餐

选择需要授权的设备，在鸿蒙电脑企业版授权中，点击"授权"，可为PC设备授权企业版套餐；

设备授权套餐后，套餐未激活可以"取消授权"；套餐激活后，无法取消。
