# 如何在同一设备上验证自动部署和MDM权限？

准备2个SN

1、上传测试APK至后台

2、使用SN:A关联MDM测试权限

3、使用SN:B关联测试自动部署，创建策略时选择使用MDM权限并关联

4、SN:B 恢复出厂并连接非权鉴网络即可
