# HEM自动部署不成功怎么办

使用HEM自动部署后，提示设备即将重置或者管控APP没有下发到设备上请优先按照以下步骤操作：

1）请检查网络状态，目前HEM暂不支持内网、验证的Wi-Fi（在Wi-Fi连接页面获取验证码、账号口令等二次弹出验证页面）。

2）请检查在设备激活过程中是否选择成为新设备。（新设备在首次开机时需要联网激活进入桌面；已开机设备，需要恢复出厂设置并联网激活进入桌面。）

3）检查设备是否支持HEM自动部署，详见[支持的终端设备](https://developer.huawei.com/business/cn/doc/HEM/hem-introduction-0000001144034694#section989mcpsimp)。

4）检查后台是否有配置部署策略并分发给设备。

5）如您使用的是三方管控请联系三方研发确认HEM代码适配（是否在OOBE结束后完成自身finish）。

<br />

按照上述完成自查修改后，请将设备恢复出厂即可完成部署，若依旧不成功，请联系后台人员。
