# 如何管理角色权限

![](https://media:201786691198485604)  
目的：

创建不同的角色，以分配不同的管理权限，对设备注册、用户权限和应用权限进行分配和管控，通过授予不同员工不同的角色以实现权限的管控。  

#### 角色管理

* 新建角色

在HEM管理台-用户与权限-角色权限管理页面，点击右上角"新建角色"按钮，在弹窗中输入角色名称，根据需求给该角色分配不同的权限。

![](https://media:201786691198537605)

* 删除角色

在HEM管理台-用户与权限-角色权限管理页面，点击角色右侧"删除"按钮，在弹窗中点击"确认"以删除该角色。如果该角色已经分配给企业员工，则无法删除，需要在在组织与成员中删除对应成员的该角色信息后才可以操作删除角色。

![](https://media:201786691198579606)
