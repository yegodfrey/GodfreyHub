# 操作步骤

* 企业主后台添加在架应用

  路径：应用管控------企业应用管理------添加"App Gallery应用"
* MDM服务器调用HEM接口获取在架应用数据信息

  一、功能介绍

  此接口提供给企业开发者，用于获取企业在HEM平台添加的在架应用列表。

  二、场景描述

  1. 企业用户在HEM管理台添加应用市场在架应用；

  2. 三方MDM服务器通过本接口获取步骤1添加的在架应用；

  3. 三方MDM服务器分发应用至MDM客户端；

  4. MDM客户端使用MDM Kit提供的在架应用安装接口，实现在架应用的安装。

  三、接口原型  

  |-----|-----------------------------------------------------------------------|
  |承载协议|HTTPS GET|
  |接口方向|三方MDM服务器 -\> 行业解决方案（HEM）平台|
  |接口URL|/api/hem/enterprise-app/list|
  |数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

  四、请求参数

  1、Request Header  

  |-------------|------|----|------|
  |参数名称|参数类型|是否必填|描述信息|
  |Authorization|String|是|鉴权头信息|
  |client_id|String|是|企业密钥id|

  2、Request Param  

  |--------|-------|----|-------------|---------|
  |参数名称|参数类型|是否必填|长度/大小限制|描述信息|
  |pageNum|Integer|是|大小：大于0|分页参数：查询页码|
  |pageSize|Integer|是|大小：\[4,1000\]|分页参数：分页大小|

  五、请求示例

  ```
  GET https://connect-api.cloud.huawei.com/api/hem/enterprise-app/list/?pageNum=-1&pageSize=5
  Headers 
  Authorization: Bearer eyJraWQiOiJJbnBuMjNUaUJZbnJCb1RiYzJwSDhMaHdTMFdwUUFLViIsInR5cCI.......
  client_id: 321153465481515
  ```

  <br />

  六、响应参数

  1、Response Body  

  |----------|------------------------|----|---------|
  |参数名称|参数类型|是否必填|描述信息|
  |rtnCode|Integer|是|分页参数：查询页码|
  |rtnMsg|Integer|是|分页参数：分页大小|
  |pageNum|Integer|否|分页页数|
  |pageSize|Integer|否|分页大小|
  |totalPages|Integer|否|分页总数|
  |totalCount|Long|否|在架应用总数|
  |result|List\<AGAppInfoToMdmVo\>|否|在架应用元数据集合|

  2、AGAppInfoToMdmVo  

  |-----------------|-------------------------|----|---------------------|
  |参数名称|参数类型|是否必填|描述信息|
  |appId|String|是|应用Id|
  |bundleName|Integer|是|应用包名|
  |versionName|String|是|版本名称|
  |versionCode|Long|是|版本号|
  |size|Long|否|应用大小(单位:byte)|
  |releaseDate|Long|否|应用上架时间|
  |deviceTypes|List\<String\>|否|支持设备类型。如：phone,tablet|
  |installCount|Long|否|安装次数|
  |gradeLevel|Integer|否|年龄等级|
  |minAge|Integer|否|最小年龄|
  |harmonyAppLanList|List\<HarmonyAppLanInfo\>|否|应用多语言信息|

  3、HarmonyAppLanInfo  

  |---------------|----------------------|----|--------|
  |参数名称|参数类型|是否必填|描述信息|
  |localeId|String|否|语言编码|
  |language|String|否|语言名称|
  |appName|String|否|应用名称|
  |description|String|否|应用描述|
  |briefInfo|String|否|应用简介|
  |iconUrl|String|否|应用图标下载地址|
  |privacyUrl|String|否|隐私政策地址|
  |permissions|PermissionInfo|否|权限信息|
  |screenShotInfos|List\<ScreenShotInfo\>|否|截图信息|

  4、PermissionInfo  

  |-------------------|-----------------------|----|----------|
  |参数名称|参数类型|是否必填|描述信息|
  |permissionIntroList|List\<PermissionIntro\>|否|在架应用权限信息列表|

  5、PermissionIntro  

  |-----|------|----|---------------------|
  |参数名称|参数类型|是否必填|描述信息|
  |title|String|否|权限标题。 例如：相机|
  |text|String|否|权限描述。 例如：允许应用拍摄照片和视频。|

  6、ScreenShotInfo  

  |----------|------|----|-----------------------|
  |参数名称|参数类型|是否必填|描述信息|
  |url|String|否|应用url|
  |webpUrl|String|否|webp图标地址|
  |resolution|String|否|截图分辨率（xxx\*xxx）|
  |rotated|String|否|截图是否旋转，0-不旋转，1-旋转（横转竖向）|
