# 回调码返回1000如何处理

1、网络问题，目前HEM暂不支持内网、验证的Wi-Fi（在Wi-Fi连接页面获取验证码、账号口令等二次弹出验证页面）。

2、设备不HEM不支持，检查设备是否支持HEM自动部署，详见[支持的终端设备](https://developer.huawei.com/business/cn/doc/HEM/hem-introduction-0000001144034694#section989mcpsimp)。

3、设备管理组件填写不对。

![](https://media:201786691198208597)

例如：Unable to start activity ComponentInfo{com.bissyungu.bissv100pad/com.iyungu.www.bissv100.MainActivity}: java.lang.SecurityException: does not have DEVICE MANAGER permission!: Neither user 10140 nor current process has com.huawei.permission.sec.MDM_DEVICE_MANAGER.

这个错是指调用方没有mdm权限，申请apk上架的时候会填一个设备管理组件

1、确认设备管理组件填的是否为继承自DeviceAdminReceiver的receiver的包名+类名。

2、检查下类名是否的权限

\<receiver

android:name=".XXXReceiver"

android:label="@string/app_name"

android:permission="android.permission.BIND_DEVICE_ADMIN"\>

\<intent-filter\>

\<action android:name="android.app.action.DEVICE_ADMIN_ENABLED" /\>

\</intent-filter\>

\</receiver\>
