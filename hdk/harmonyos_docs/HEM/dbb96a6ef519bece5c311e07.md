# 上传商用MDM应用

![](https://media:201786691186523388)  
【厂家自检】：

为了帮助您尽可能顺利地通过应用审核，请查看下列可能会导致审核流程延误或审核不通过的常见问题：

1.确保应用信息及包体的完整和正确。

2.确保应用运行不会发生崩溃或错误。

3.确保应用遵守隐私保护所适用的法律法规，并符合用户预期。

4.确保应用不得出现低俗、涉黄、涉赌、涉毒等违法违规内容。

5.确保您的联系信息真实有效，以便应用管理人员在需要时与您取得联系。

6.确保提供有效的演示帐户和登录信息，以及审核应用时所需的任何其他硬件或资源 (例如，特殊配置或特殊测试环境所需的相关资源或信息需备注清楚)。

7.确保应用审核期间可登录，需提前后台授权审核测试设备或放通网络或其他配置

8.确保应用后续自更新符合上述要求。

9.如提交MDM应用软件包有账号密码等特殊要求，请提前发送至heminquiry@huawei.com，避免因无法测试而驳回。

10.如果有软件包防破解和防逆向工程等诉求，可选用三方应用加固方案，以实现知识产权保护。

11.MDM应用若涉上传至HEM更新，则也需等待审核，审核完毕后，若不具备自更新能力则需重新恢复出厂部署设备。建议做自更新。

1、登录控制台，选择"MDM应用管理"\>"上传MDM应用"。

![](https://media:201786691186558389)

2、选择"上传应用"并填完成此页面其他填写。

![](https://media:201786691186603390)

相关字段信息说明：

* 应用名称：填写您上传的MDM应用名称。
* 操作系统类型：HarmonyOS NEXT。
* 终端类型：根据您实际项目情况进行选择"手机\&平板"或"笔记本\&台式机"。
* 设备管理组件

  HarmonyOS NEXT：填写继承自EnterpriseAdminExtensionAbility的组件名称。它必须在工程Module对应的module.json5配置文件里的"extensionAbilities"中注册，type标签需要设置为"enterpriseAdmin"，srcEntry标签表示当前组件对应的代码路径，这里要填写的是"name"标签中的内容。
* 发布类型：商用应用
* 应用安全自检表：根据业务实际填写，不可改变模板。

![](https://media:201786691186634391)  
1、MDM应用软件包上传审核需要7个工作日左右，请耐心等待，审核成功后企业用户即可在HEM管理台获取到您的管控软件。

2、相同包名的应用，每个项目只能绑定一个；已提交商用的应用如需更新，在原记录中提交新包。

3、若MDM应用软件包更新，则重新触发审核，已部署设备不受影响；已部署设备通过HEM平台升级MDM应用，需要恢复出厂重新激活获取最新安装包。

4、建议MDM应用增加自更新能力，无需恢复出厂即可自行升级MDM应用。
