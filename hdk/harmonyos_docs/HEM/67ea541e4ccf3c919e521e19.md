# 关于在线证书与离线证书问题

1、MDM在HEM激活后，在线授权申请权限，申请权限需要联网吗，权限有效期是多久？

HEM激活MDM权限与自动部署时候，需要完成非权鉴网络的链接，针对某项目的MDM权限最长可至10年

2、在有效期内，若通过MDM禁用了某权限，权限到期后，某权限是否还是在禁用状态

权限到期，即失效，请及时延续申请权限

3、MDM只能在现授权吗，设备在内网环境，无法连接外网进行授权申请

目前HEM在线授权暂不支持内网，如有特殊内网项目，请先联系对应华为销售人员。

4、HEM激活后，是否永久激活

非永久激活

5、在内网环境，能否进行HEM和MDM的激活、授权申请操作

一台设备不可以同时使用在线与离线，离线证书已下线，非特殊需求不予申请
