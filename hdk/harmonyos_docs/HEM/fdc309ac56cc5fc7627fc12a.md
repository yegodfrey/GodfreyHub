# 鉴权方式

鉴权分为前端鉴权和后端鉴权两个概念，前端鉴权为AGC云侧网关对企业云服务器的鉴权，后端鉴权为HEM云服务对AGC网关的鉴权（企业侧不需要关注）。

![](https://media:201786691177175258)

前端鉴权方式：clientToken鉴权又称CT鉴权。访问网关的企业云服务需要具备有效的clientId以及clientSecret，才能通过云侧网关的鉴权校验并对业务接口发起有效调用。

后端鉴权方式：AKSK鉴权。 Access Key Id（AK）用于标示用户或者系统，Secret Access Key（SK）是客户端用于加密认证字符串和服务端用来验证认证字符串的密钥，其中SK必须保密且加密存储。

请求头参数获取

1、获取clientId及clientSecret

1.1 使用HEM平台企业主账号登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/console/overview) -\> 进入AppGallery Connect -\>进入用户与访问页面

![](https://media:201786691177227259)

![](https://media:201786691177286260)

1.2 选择api密钥---创建---输入名称、勾选角色（管理员）

API客户端创建后可获取客户端id（client_id）与密钥字段（client_secret）

![](https://media:201786691177562261)

![](https://media:201786691177879262)

<br />

2、使用clientId及clientSecret获取到clientToken

2.1 请求URL

```
Post https://connect-api.cloud.huawei.com/api/oauth2/v1/token
```

2.2 RequestBody

```
{
    "grant_type": "client_credentials", // 固定值
    "client_id": "xxxxx", // 客户端id, AGC页面获取
    "client_secret": "xxxxx", // 客户端秘钥，AGC页面获取
    "useJwt": 0 // 固定值：0
}
```

2.3 ResponseBody

```
{
    "access_token": "xxxxxx", // Token 信息
    "expires_in": "175895" // token过期时间
}
```
