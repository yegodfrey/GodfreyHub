# 如何管理隐私协议管理

![](https://media:201786691192565503)  
目的：

设置安装在终端设备上的管控软件和设备使用者用户之间的隐私声明文件。

<br />

登录HEM设备注册平台，选择"设备注册"\>"隐私协议管理"\>"新建隐私协议"\>"单框架-通用版"，根据模板创建隐私协议。
