# EMM厂商资质认证

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)，点击"管理中心"，选择"开发服务"\>"HEM行业解决方案"。

   ![](https://media:201786691178280269 "点击放大")
2. 进入资质认证界面，填写您的资质信息，包括企业名称、对接行业、企业规模、解决方案产品介绍材料，以及您对接的华为销售信息。

![](https://media:201786691178311270)  
华为销售是指与您前期沟通对接HEM相关事项的华为方销售人员，可线下联系以获取其联系信息。

![](https://media:201786691178460271)

填写资质信息提交后，认证结果会在1-3个工作日发送至您邮箱。
