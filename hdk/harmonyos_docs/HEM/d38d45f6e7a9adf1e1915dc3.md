# 扫码上传错误怎么办

1)如果未在开发者联盟APP提交，可点击右上角的"管理"删除错误的SN号。

2)如果已在开发者联盟APP提交，则需要联系企业用户驳回或删除错误的SN号，再去渠道商账号的"客户详情-\>设备管理"删除SN号。
