# 如何角色认证

![](https://media:201786691181073290)  
目的：您需要按需完成HEM角色认证才能享受HEM的各类能力和服务。

注意：

1.开发者联盟的In---house应用分发账号，不支持认证HEM业务角色；

2.若企业只认证了In---house账号，请重新认证开发者联盟普通开发者账号。

1、完成实名认证后返回[HEM管理台](https://developer.huawei.com/business/console/)，选择"企业主"或"渠道商"进行角色认证。

![](https://media:201786691181124291)

<br />

2、填写和您对接沟通的华为方销售联系信息，包括销售的姓名、华为邮箱、手机号。  
![](https://media:201786691181157292)  
华为方销售是指与您前期沟通对接HEM相关事项的华为方销售人员，可线下联系以获取其联系信息。

若您不确定华为销售代表联系方式，请提供您的项目所在地、联系方式、企业名称，发邮件至heminquiry@huawei.com咨询。

![](https://media:201786691181187293 "点击放大")

3、查看并同意企业客户服务\&隐私协议，点击"提交"。审核结果会在1-3个工作日内通过邮件的方式通知您。

![](https://media:201786691181235294 "点击放大")
