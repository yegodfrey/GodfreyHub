# BYOD项目部署流程

![](https://media:201786691181877304)  
1、BYOD自带设备办公场景：指一些企业允许员工携带自己的平板或智能手机到公司，并将这些设备接入办公环境，用于企业办公或者外来访客携带设备访问工厂、实验室等场景。

2、请确保设备为HarmonyOS 5.1系统及以上。

3、如若是升级为HarmonyOS 5及以上系统的设备请确保升级成功，可再系统设置里查看设备当前版本。

4、目前仅支持手机\&平板。

5、分发应用类型为：非公开发布应用。

![](https://media:201786691181917305)

1、[注册联盟账号](https://developer.huawei.com/business/cn/doc/HEM/hem_user-guide_certification_zczh-0000001407393610)、[账号实名认证](https://developer.huawei.com/business/cn/doc/HEM/hem_user-guide_certification_rhsmrz-0000001547814172)

2、最终企业用户[认证HEM角色](https://developer.huawei.com/business/cn/doc/HEM/hem_user-guide_certification_rhjsrz-0000001547976112)

3、[创建BYOD项目](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-osnext-byod-0000002502386967#section64672595564)

4、[创建应用项目](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createproject-0000001100334664)和[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)

5、申请[应用调试证书与Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-cert-0000002283256797)

6、获取项目激活ID并提供给开发者

7、[应用开发并测试](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-osnext-byod-0000002502727919)

8、[申请发布证书与Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-releasecert-0000001946273961)

9、应用上架并选择[非公开发布](https://developer.huawei.com/consumer/cn/doc/app/agc-help-non-public-release-0000002047208149)

10、购买[设备注册套餐](https://developer.huawei.com/business/cn/price/pricing)并[为项目授权套餐](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-osnext-byod-0000002502386967#section37074171573)

11、[员工使用BYOD场景](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-osnext-byod-0000002502386967#section102831826205714)

12、[企业主查看员工激活设备状态](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-osnext-byod-0000002502386967#section11523031195718)
