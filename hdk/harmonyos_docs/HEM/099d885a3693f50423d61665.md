# 上传测试MDM应用

![](https://media:201786691189400445)  
目的：测试您上传的MDM应用是否能正常获取MDM权限授权，测试完成后才能正式商用。

1、登录控制台，选择"MDM应用管理"\>"上传应用"。

![](https://media:201786691189439446)

<br />

2、应用类型选择"测试应用"并填完成此页面其他填写。

![](https://media:201786691189479447)

<br />

相关字段信息说明：

* 应用名称：填写您上传的MDM应用名称。
* 操作系统类型：HarmonyOS NEXT
* 终端类型：根据您实际项目情况进行选择"手机\&平板"或"笔记本\&台式机"。
* 设备管理组件

  HarmonyOS NEXT：填写继承自EnterpriseAdminExtensionAbility的组件名称。它必须在工程Module对应的module.json5配置文件里的"extensionAbilities"中注册，type标签需要设置为"enterpriseAdmin"，srcEntry标签表示当前组件对应的代码路径，这里要填写的是"name"标签中的内容。
* 发布类型：测试应用
* 应用安全自检表：根据业务实际填写，不可改变模板。

<br />

3、请点击"提交"，提交成功，无需审核。

![](https://media:201786691189530448 "点击放大")
