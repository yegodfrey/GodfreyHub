# EMM厂商概述

![](https://media:201786691173072211)  
HEM解决方案支持三方管控软件：

1、自动部署：需要提前绑定设备序列号，然后加入HEM后台的设备首次启动时会执行激活和OOBE的流程。此时将自动安装您的MDM APP到华为桌面上。设备恢复出厂后依然会重新执行激活和OOBE此时也会自动部署。

2、MDM接口授权：可实现MDM接口的授权。

3、MDM业务逻辑：由三方EMM厂家自行实现。

#### 为什么要适配HEM

MDM应用可以通过适配HEM完成MDM应用的在线激活/去激活、MDM商用权限在线申请。  
![](https://media:201786691173174214)  
1. 一个MDM应用可以绑定多个项目，申请不同的MDM商用权限。
2. MDM应用业务侧内容如需更新，请做应用内自更新。仅需要更新MDM商用权限时，MDM应用无需更新。
3. MDM应用审核中：确保数据备份安全，AndroidManifest.xml中android:allowBackup需设置为false。
4. MDM应用在完成激活的同时获取华为MDM（Mobile Device Management）权限授予。在线授权存在有效期限制（最长10年），过期后需要重新申请。
5. 由于权限的发放时间为MDM应用在设备上的激活时间，依赖云侧的权限发放，所以如果端侧与云侧的系统时间不同步，会导致授权存在一定的时间差异常。
6. HEM平台只记录DPC部署状态，因状态上报依赖客户端网络状态，为保证客户端状态准确性，建议三方DPC安装部署完成后，自行上报部署状态至对应云侧，实现三方DPC的使用统计。
