# HarmonyOS 4及以下应用上传问题

1、应用类型：

必装应用：后台下载安装包，静默安装。删除后依然会重复安装，可配合应用防卸载使用。

选装应用：需要访问"设备配置"APP的应用列表，手动点击安装。如有选择需求，请勿选择无图标版设备配置APP。

预装应用：第一次激活部署时仅安装一次，手工删除后不会再次安装。注意：设备激活部署后，再新增预装应用策略，不会安装。

2、应用大小与格式：

文件大小不超过500M，仅支持上传APK格式

3、应用上传与使用

（1）点击应用管理-新建私有应用上传

（2）将上传的应用分发至对应组织

4、应用更新

（1）点击应用管理-新建私有应用上传

（2）将上传的应用分发至对应组织（同组织相同包名不同版本，最终只会下发高版本的APP）。

5、其他注意事项

（1）支持上传相同包名不同版本号

（2）相同组织只可以存在一个包名应用，不可以存在2个包名相同但版本不同的应用，此为应用更新
