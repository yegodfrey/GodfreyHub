# COPE项目部署流程

![](https://media:201786691180931288)  
1、COPE企业派发设备场景：指企业统一购买笔记本电脑、平板电脑、智能手机等设备，并将这些设备分发给企业员工使用，这类设备的所属权属于企业，企业对这类设备进行统一管理。

2、请确保设备为HarmonyOS 5.1系统及以上。

3、如若是升级为HarmonyOS 5及以上系统的设备请确保升级成功，可在系统设置里查看设备当前版本。

4、设备开机激活后，修改定制项策略，需要设备恢复出厂方可生效
