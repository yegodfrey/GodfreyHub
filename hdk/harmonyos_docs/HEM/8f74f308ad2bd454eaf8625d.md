# 商用申请时无法选择MDM应用怎么办

商用申请时，相同包名的应用仅可与同一项目绑定一次。若项目已绑定应用，新提交的应用无法再次绑定。处理办法。

（1）将新应用删除，[原应用更新](https://developer.huawei.com/business/cn/doc/HEM/hem_developer_faq_emmwenti_yygx-0000002521129618)

（2）渠道商建新项目与新应用绑定
