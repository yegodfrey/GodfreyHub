# 如何管理渠道商

![](https://media:201786691191368483)  
目的：

1、绑定您采购设备的渠道商，绑定渠道商之后，渠道商才能为您上传已采购设备的信息（SN号）。

2、删除绑定渠道商。  

#### HEM ID

在绑定渠道商之前，您需要线下联系您采购终端的设备渠道商，并获取他的HEM ID信息。

进入HEM管理台，鼠标移到右上角企业名称处，复制HEM ID线下传递给您的渠道商。

![](https://media:201786691191396484)  

#### 添加渠道商

1、选择"设备注册"\>"渠道商管理"\>"渠道商"\>"添加渠道商"。

![](https://media:201786691191437485)

2、在"添加渠道商"页面填写您线下沟通获取的HEM ID，可点击右侧的"检测"进行ID验证。

审批模式的说明如下：

* 自动审批：代表此设备渠道商为您上传的所有设备信息将自动审批通过，无需您后续手动在HEM部署平台进行审批的操作。
* 手动审批：代表您需要在HEM设备注册平台-审批设备SN号处手动审批此渠道商上传的所有设备信息。

![](https://media:201786691191471486)

3、点击"添加"完成渠道商的绑定添加。  

#### 删除绑定渠道商

在HEM设备注册平台的"渠道商列表"界面，您可根据实际业务需求删除指定的渠道商，解除和渠道商的绑定关系。  
![](https://media:201786691191495487)  
删除绑定渠道商后，您将后续无法接收到此渠道商为您上传的设备信息。若删除绑定后，仍需此渠道商为您上传设备信息，还请重新添加此渠道商。

![](https://media:201786691191527488)
