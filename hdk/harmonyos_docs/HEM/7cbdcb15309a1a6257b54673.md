# 常用定制项配置

![](https://media:201786691176192251)  
1、使用场景：此部分适用于购买HEM付费套餐的用户，指导企业客户快速配置手机/平板常用定制项，其他定制项可参照进行配置。

2、使用前提：需先完成[HEM快速开通](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-0000001556496678)。

3、注意事项：HarmonyOS 4及以下策略在套餐使用期内可随时在管理中心进行修改，终端设备联网后可生效。
