# 企业主操作

#### 1.企业主获取HEM ID

<br />

企业主完成HEM角色认证后，登录后台，即可获得HEM ID；

![](https://media:201786691196725570)  

#### 2.企业主获取兑换码

<br />

企业应用定向发布并审核通过后，企业用户可以在HEM管理台查看开发者上架的企业定向应用，选择数量，点击"获取"按钮（免费应用按钮是"获取"，付费应用按钮是"购买"），即可生成兑换码；  

#### 3.企业主下载兑换码

<br />

点击"生成兑换码"按钮，下载包含兑换码以及兑换码链接的表格文件；

![](https://media:201786691196782571)
