# 如何使用HEM SDK

#### 开发指导

1. 创建[HemLicenseManager](https://developer.huawei.com/consumer/cn/doc/system-References/hemlicensemanager-0000001058803272)对象。
2. 设置状态回调。 在调用激活、去激活接口前需要先调用接口[setStatusListener](https://developer.huawei.com/consumer/cn/doc/system-References/hemlicensemanager-0000001058803272#section825989191217)设置状态回调的监听，通过回调函数获取调用激活/去激活接口的结果。回调函数通过实现[HemLicenseStatusListener](https://developer.huawei.com/consumer/cn/doc/system-References/hemlicensestatuslistener-0000001058503928)类中的方法来监听调用状态。

3. 通过DPC App的License设置权限。 通过调用[activeLicense](https://developer.huawei.com/consumer/cn/doc/system-References/hemlicensemanager-0000001058803272#section813217288108)接口实现DPC App激活。

4. 通过DPC App的License取消权限。 调用去激活接口前需要先完成激活操作。

5. DPC上报 使用状态 至 三方自己的云服务器。  

   ```
   public class MainActivity extends Activity {    
       ...
       private HemLicenseManager hemInstance;
       ...
       @Override  
       protected void onCreate(Bundle savedInstanceState) {
           super.onCreate(savedInstanceState);  
           setContentView(R.layout.activity_main); 

           // 1. 创建HemLicenseManager对象
           hemInstance = HemLicenseManager.getInstance(this);

           private final String TAG = "MainActivity";

           // 2. 设置状态回调
           hemInstance.setStatusListener(new HemLicenseStatusListener() {
               @Override
               public void onStatus(int errorCode,String msg) {
                   Log.d(TAG,"errorCode="+errorCode+",msg="+msg);
                   if (errorCode == 2000) {
                       // 成功，后续可以调用MDM
                       ...
                   } else {
                       // 失败，请点击此处查看错误码
                   }
               }
           });

           // 3. 实现DPC App激活
           activeLicense();

           // 4. （可选，不再需要权限时调用）实现DPC APP去激活
           deActiveLicense();  // 调用去激活接口前需要先完成激活操作
       }

       private void activeLicense() {
          ...
          hemInstance.activeLicense();
          ...
       }

       private void deActiveLicense() {
           ...
           hemInstance.deActiveLicense();
           ...
       }
   }
   ```
