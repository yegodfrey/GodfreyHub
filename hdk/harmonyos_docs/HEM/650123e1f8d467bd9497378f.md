# 上传应用包提示应用包重复怎么办

EMM 厂商上传的MDM应用包具有唯一性，同一个应用包不能重复上传。如果提示上传应用包重复，则需进行如下排查。

（1）确认当前账号下是否已有相同包

在MDM应用管理菜单，根据应用包名、应用版本号段判断是否已经上传了相同包。

（2）联系HEM运营人员处理

确认当前账号下没有相同应用包，怀疑其他开发者有侵权行为，请将应用名称、应用包名、应用版本号等信息发送HEM运营人员处理，公共邮箱：heminquiry@huawei.com
