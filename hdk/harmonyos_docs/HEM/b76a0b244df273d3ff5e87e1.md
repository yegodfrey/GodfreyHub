# 关于HEM部署管控软件的配置介绍

![](https://media:201786691191213480)  
在您购入HEM付费管控套餐后，您在设备注册-部署策略中可选择对应的部署模式，达到不同的管控与定制效果。

华为设备配置软件-HarmonyOS

![](https://media:201786691191247481)

华为设备配置软件-HarmonyOS（轻定制）

![](https://media:201786691191273482)  

|选择MDM应用|华为设备配置软件-HarmonyOS 4及以下 <br />|华为设备配置软件-HarmonyOS 4及以下|华为设备配置软件-HarmonyOS 4及以下（轻定制）|
|:------|:----------------------------------|:------------------------|:---------------------------|
|部署模式|Device Owner（DO模式）|Device Admin （DA模式）|默认DA模式，不可更改|
|名词解释|设备所有者模式，授权后后可以对托管设备上的配置、安全性和应用的精确控制|设备管理者模式，授权后可修改托管设备的系统级设置。|默认设备管理者模式，最小权限|
|适用场景|强管控场景（禁用wifi、蓝牙等）|弱管控场景（开机logo、壁纸等）|纯定制场景|
|功能限制|系统会禁用应用分身、隐私空间、多用户功能|不会禁用应用分身、隐私空间、多用户功能|不会禁用应用分身、隐私空间、多用户功能|
|客户提示|锁屏：显示设备正在被企业管控 多任务窗口、消息弹窗|消息弹窗|无弹窗|
|权限|MDM权限能力全|仅部分MDM接口能力|仅开机logo、动画、预置应用、保活、防卸载、单北斗|
|适用套餐|全部套餐|内容定制套餐|内容定制套餐（少量功能）|
