# 锁屏密码忘记如何处理

华为设备出于对用户隐私安全保护考虑，数据都是通过锁屏密码基于不可逆转的算法进行加密过的，没有预留后门，一旦手机在本地设置了锁屏密码，设备内的所有信息将随着锁屏密码的设置而进行加密保护，华为设备确实不具备自动设置密码/自动修改密码的功能，作为设备生产厂商也无权以任何方式强制破解用户的密码，否则将无法保障消费者的隐私和信息安全。我们对于此情况深感抱歉，请您谅解。

<br />

如果您确认遗忘自己的设备密码，需要解锁，请携带有效证件（如：身份证）前往华为官方售后门店，说明设备情况（是否有定制等），由售后工作人员处理。
