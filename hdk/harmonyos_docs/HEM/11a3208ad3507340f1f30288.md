# 常用定制项配置

![](https://media:201786691176273252)  
1.仅支持开箱定制，收费功能需要授权HEM套餐；

2.折叠屏设备开机LOGO/开机动画仅支持HarmonyOS 6.1及以上，配置前需提前联系HEM运营后台配置设备型号；

3.PC开机logo仅支持华为擎云 HM740定制，设备分辨率为：2880\*1920。

4.分辨率查询方式：1）设置------关于本机------屏幕/分辨率；2）登录Vmall，找到机型查询详情
