# 申请MDM商用权限

1、登录控制台，在"MDM应用商用权限"页面点击"商用申请"。

![](https://media:201786691189584449)2、在"商用申请"页面填写商用权限申请的相关信息。

![](https://media:201786691189625450)

相关字段信息说明：

* 项目ID：由您的渠道商创建的项目且为真实在交付的项目。
* 项目名称：项目的名称。
* 绑定MDM应用：选择已审核通过的APK包。

<br />

3、点击"提交"，完成MDM商用权限的申请。企业用户即可在HEM管理台获取到您的管控软件。

![](https://media:201786691189662451)

<br />

![](https://media:201786691189690452)  
一个商用MDM应用可以绑定多个项目，但每一个项目需要提交MDM权限。
