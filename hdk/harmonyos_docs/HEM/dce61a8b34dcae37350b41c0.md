# 使用自动部署后终端用户的注意事项

1、无法使用应用分身、隐私空间、多用户功能。

1) 应用分身：设置-应用和服务-应用分身。

2) 隐私空间：设置-隐私-隐私空间。

3) 多用户：设置-用户和帐户-用户-添加用户/添加访客。

<br />

2、设备激活时需注意

1）关于设备激活中数据导入步骤，请选择 "新设备"

![](https://media:201786691189744453)

<br />

2）激活时请不要选择二次认证的Wi-Fi网

![](https://media:201786691189774454)
