# HarmonyOS 5及以上应用更新问题

开箱定制应用仅OOBE阶段下发，定制完成后应用更新请用以下方法。

1.上架应用：通过应用市场进行更新；

2.企业应用（Normal应用）：应用如有自更新功能，可完成更新；若无自更新功能，请使用离线安装完成更新。仅支持擎云PC。
