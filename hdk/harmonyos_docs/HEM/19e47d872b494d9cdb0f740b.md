  5）安全桌面

  注意：
  1. 安全桌面开启，系统将自动启动应用使用白名单功能，安全桌面上的应用将自动加入白名单，以保证其正常运行。 （1）若您的应用会跳转到其他页面，还需要将此应用加入网址白名单豁免应用中；

     （2）若您的应用还会拉起其他应用，还需要将拉起应用加入应用使用白名单/网址白名单豁免应用中。
  2. 不能裁剪手机管家/平板管家（com.huawei.systemmanager）、应用安装器（com.android.packageinstaller），请谨慎操作。
  3. 安全桌面开启后，若您的设备系统为HarmonyOS3.1以下（不包含3.1），"设置-重置-恢复出厂设置"此功能将无法使用。
  4. 安全桌面包含功能可以见下表，可以考虑和其他管控功能配合使用，以达到更好的管控效果。如：禁止分享文件、禁止蓝牙文件传输、禁止使用外部SD卡、禁止OTG、禁止使用USB调试模式、数据传输、禁止智慧多窗。

  |功能|详细|备注|
  |:-------|:------------------------------------|:---------------------------------------------------------------------------------|
  |安全桌面定制文案|姓名|桌面展示对应设备用户姓名|
  |安全桌面定制文案|设备SN|桌面展示对应设备SN序列号|
  |安全桌面定制文案|自定义|桌面统一展示用户自定义文案（20字符以内）|
  |桌面快捷方式|Wi-Fi配置|桌面展示wifi跳转入口|
  |桌面快捷方式|蓝牙配置|桌面展示蓝牙跳转入口|
  |默认裁剪应用|智慧助手、智慧语音、应用市场、游戏空间、华为音乐、华为阅读、图库、华为视频|勾选应用，设备管控成功后会自动裁切该应用，若需要裁切应用不包含在内，请于设备内容配置-应用-系统预装应用裁切设置|
  |安全桌面应用|被添加的应用会展示在安全桌面上|1. 所有非设备预装应用要展示在安全桌面上，请与私有应用-应用管理先行上传并分发。 2. 此功能自带应用使用白名单，无需额外添加，同时请不要额外设置应用安装白名单。|
