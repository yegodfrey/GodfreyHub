# 如何查看设备信息

您可在HEM渠道商控制台查看已上传的设备信息，若设备信息被企业客户驳回，需要修改后重新提交给客户审核。

1、登录HEM渠道商控制台，选择"设备注册"模块。

![](https://media:201786691175827245)

2、选择"客户管理"菜单，在"客户列表"页面选择指定的企业客户，单击右侧的"详情"，进入"客户详情"页面。

<br />

3、在"上传记录"菜单中，可按上传批次的维度查看为此客户上传的设备信息，包括"待审批"、"已通过"和"已驳回"三个状态的上传记录。  
![](https://media:201786691175881246)  
处于"待审批"和"已通过"的上传记录仅可查看该批次所有已经上传的设备信息。

![](https://media:201786691175930247)

4、针对处于"已驳回"状态的上传记录，点击记录右侧的"详情"进入"上传记录详情"页面后，根据驳回理由删除指定的SN号后重新提交审批。

![](https://media:201786691175978248)

5、在"设备管理"菜单中，可按单设备的维度查看为此客户上传的设备信息。其中，针对"已驳回"状态的设备，可选择删除。后续如果需要更新正确的SN号，可重新为该项目上传正确的SN号，扫码或CSV方式上传均可。  
![](https://media:201786691176006249)  
可在搜索框中输入指定的设备SN号，以快速查询指定设备的状态信息。

![](https://media:201786691176070250)
