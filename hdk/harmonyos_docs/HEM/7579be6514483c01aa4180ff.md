# 获取企业SN

![](https://media:201786691190597467)  
此操作需要您的企业用户在对应的管理台进行操作。

1、登录HEM设备注册平台，选择"EMM厂商设备SN号同步"，进入"EMM厂商设备SN号同步"页面。

2、在"EMM厂商设备SN号同步"页面，从下拉框中选择您合同的EMM厂商，点击"添加批次"来添加您需要同步的设备信息。

![](https://media:201786691190646468 "点击放大")

3、在"添加批次"页面选择"添加方式"并选择具体的同步设备信息，有三种添加设备信息的方式供您选择：

* 全部同步：将您审批通过的所有设备信息进行添加。
* 按项目同步：按项目维度来添加您审批通过的设备信息。
* 按批次同步：按批次维度来添加您审批通过的设备信息。

![](https://media:201786691190702469 "点击放大")

4、点击下方的"同步"即可完成将添加的设备信息同步给EMM厂商。
