# 如何获取SN

#### 如何获取 SN

<br />

--2.0设备获取方式

目前客户业务需要使用设备标识符的话，可以用SN号代替，获取方式见下：

1、应用在mainfest申请READ_PHONE_STATE和android.permission.READ_PRIVILEGED_PHONE_STATE权限

2、应用在HEM网站中申请android.permission.READ_PRIVILEGED_PHONE_STATE权限

3、应用侧通过如下代码获取：

if (ActivityCompat.checkSelfPermission(this, Manifest.permission.READ_PHONE_STATE) == PackageManager.PERMISSION_GRANTED) {

String serialNumber=android.os.Build.getSerial();
