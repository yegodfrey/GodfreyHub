# HEM业务流程图

您可以根据实际需求选择对应场景，并严格按照所描述操作步骤开通业务。

<br />

场景1：选择EMM管控（三方管控）解决方案(HarmonyOS 4及以下/HarmonyOS 5及以上)，适用于购买三方管控方案（非华为）的用户。

场景2：选择HEM自研管控方案，适用于购买HEM付费套餐的用户。

场景3：华为与EMM管控（三方管控）联合交付，适用于同时购买HEM付费套餐和三方管控方案的用户。

* [HarmonyOS 5及以上](https://developer.huawei.com/business/cn/doc/HEM/hem-kuaisukaitong-osnext-0000002303712761)
