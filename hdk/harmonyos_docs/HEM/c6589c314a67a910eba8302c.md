# 如何设置离线定制管理

![](https://media:201786691200324631)  
目的：

为已经开机联网激活后转入内网场景的设备，通过后台下载策略以U盘方式链接设备，修改设备策略。仅"已授权"的设备才可以设置。

1、点击右上角"新增定制任务"。

![](https://media:201786691200357632)

2、选择要复制策略的组织与设备。

![](https://media:201786691200403633)

3、点击"下载定制包"。

![](https://media:201786691200442634)

4、将下载下来的zip文件，命名为"customization.zip"，转入U盘根目录\\DPC\\，链接设备。

![](https://media:201786691200470635)

<br />
