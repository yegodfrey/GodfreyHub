# 如何设置设备违规监控

![](https://media:201786691198673607)  
目的：

设定设备违规场景并监控。  

|功能/特性名称|功能描述|
|:------------|:--------------------------------|
|违规类型-系统版本过低|配置系统版本低于某版本时触发违规|
|违规类型-设备破解|设置设备root破解后触发违规|
|违规类型-设备失联|设置设备失联1-30天后触发违规|
|违规执行-通知违规用户|设置设备违规后是否通过邮件/短信警告设备使用责任人|
|违规执行-发送应用消息警告|设置设备违规后是否发送应用消息警告设备使用责任人，以及配置告警消息|
|违规执行-锁定设备|设置违规后是否锁定设备，以及锁定延迟时间|
|策略执行范围|设置合规策略需要覆盖的组织或成员|
|策略推送范围|设置需要接收违规统计信息的组织或成员|
