# 如何管理隐私协议管理

![](https://media:201786691198822609)  
目的：

设置安装在终端设备上的管控软件（DPC）和设备使用者用户之间的隐私声明文件。

<br />

登录HEM设备注册平台，选择"设备注册"\>"隐私协议管理"，根据模板创建隐私协议。

![](https://media:201786691198926610)
