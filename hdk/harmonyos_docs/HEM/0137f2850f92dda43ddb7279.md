# 发票类问题

发票类型：

若您为一般纳税人，华为向您开具增值税专用发票；若您为小规模纳税人，华为向您开具增值税普通发票。

<br />

开发票时间：

大额发票：本月开上个月的发票，申请开票成功后，发票寄出时间在20号左右（节假日顺延）。

小额发票：需等财务统一汇总开具寄出，如有疑问请联系客服。

<br />

若您在订单成功后的十四（14）日内没有主动索取发票，华为平台将自动触发开票申请，开票信息以您在HEM网站设置的信息为准。请确保您在"个人中心-设置-付费服务"中的开票信息准确。
