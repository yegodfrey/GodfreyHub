# 应用包更新问题

已申请商用权限的MDM应用，如需更新，请在MDM应用管理中，找到已审核通过的应用包，点击编辑，将更新后的MDM应用包上传，替换旧应用包。  
![](https://media:201786691183717334)  
1、应用包上传审核需要7个工作日左右，请耐心等待，审核成功后企业用户即可在HEM管理台获取到您的管控软件。

2、若MDM应用软件包更新，则重新触发审核，已部署设备不受影响；已部署设备通过HEM平台升级MDM应用，需要恢复出厂重新激活获取最新安装包。

3、建议MDM应用增加自更新能力，无需恢复出厂即可自行升级MDM应用。
