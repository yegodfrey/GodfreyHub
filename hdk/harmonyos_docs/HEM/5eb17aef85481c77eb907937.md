# 对公银行打款认证（推荐）

![](https://media:201786691183899336)  
目的：对企业进行资质认证。

注意：对公银行打款认证需要您提供一个公司的对公银行账号，华为开发者联盟将通过招商银行向此账号里转入随机金额，您在华为开发者联盟实名认证页面准确输入到账金额后，即可完成认证。

1、进入[HEM官网](https://developer.huawei.com/business/cn/overview)的"管理中心"，登陆您的华为账号后，选择"对公银行打款认证"。

![](https://media:201786691183945337 "点击放大")

2、完善企业的基本信息和企业银行账户信息。

![](https://media:201786691184004338)

![](https://media:201786691184067339)

3、企业的基本信息和企业银行账户信息填写完成后，签署[《华为开发者联盟与隐私的声明》](https://developer.huawei.com/consumer/cn/devservice/term)和[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)，点击"下一步"，系统会同步验证企业的法人信息，若验证通过后，系统会发送邮件和短信通知您已发起打款申请。通知发出后30分钟\~3工作日内，联盟尾号为0505的账户将向您提供的银行账户打一笔小于1元的款项。

![](https://media:201786691184102340)

4、输入打款金额。

收到打款后，点击"管理中心"，或登录开发者联盟点击页面上方通知消息的"查看"按钮或左边菜单栏"开发者基本信息"进入打款金额输入页面。输入打款金额后，点击"提交认证"。

![](https://media:201786691184143341)
