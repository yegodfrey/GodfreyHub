# 1\. Android SDK下载

针对Android Studio开发环境，华为提供了maven仓集成方式的HMS SDK包。集成方式请参考[集成HMS SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#h2-1580723912233)。

# 2\. Eclipse SDK下载

针对Eclipse开发环境，华为提供了下载HMS SDK包本地集成的方式。下载后的集成方法请参见开发指南中的[在Eclipse项目中集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-preparation-v4#h2-1580724757206)。
