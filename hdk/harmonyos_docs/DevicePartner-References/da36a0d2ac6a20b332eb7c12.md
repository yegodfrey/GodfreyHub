# 查询房间列表信息  
  
#### 接口描述

hilink.getRoomList(String callback);

查询房间列表信息。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getRoomList(callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 房间列表的json字符串。  
  
#### 响应示例
    
    
    {"roomList": ["客厅", "主卧", "入户门", "走廊", "客卧", "车内", "阳台", "书房", "客房", "卧室", "主卫","厨房", "玄关", "儿童房", "餐厅", "卫生间", "客厅", "次卧", "天台", "办公区", "衣帽间", "公卫", "浴室"...]}

#### 错误码

无
