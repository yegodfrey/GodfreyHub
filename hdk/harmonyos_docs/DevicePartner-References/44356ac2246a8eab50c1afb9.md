# 启动GATT服务  
  
int BleGattsStartServiceEx(int *srvcHandle, BleGattService *srvcInfo)

SDK通过调用此接口创建并启动蓝牙协议栈中的GATT服务，此接口一次传递一个GATT服务，且会被调用多次。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/aWAygh9xQteF9gFh063q6A/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090915Z&HW-CC-Expire=86400&HW-CC-Sign=C4233AC87C58EA81430A1C0FB7E3BD512BD378A0C97E9FC21BB307C85C1BFF93)

  1. srvcInfo参数为此GATT服务描述的信息，attrList字段为GATT服务的节点链表，attrNum字段为链表节点数量，链表节点仅包括服务本身、characteristic，如果一个GATT服务有2个characteristic，则attrNum为3（即1个服务加2个characteristic），依赖伙伴补全协议栈所需的description及CCCD等配置。
  2. 当链表节点attrType字段为OHOS_BLE_ATTRIB_TYPE_CHAR时表示characteristic，此时BleGattOperateFunc字段有此特征的读写回调函数，需要在创建服务时挂载回调函数，当特征被读写时，调用回调函数传递数据给SDK。
  3. 由于链表节点仅为GATT服务以及characteristic的描述，因此value字段为空，且valueLen为0，链表内存空间在使用后将会释放，开发者需要根据实际情况构建自己的GATT结构体；
  4. 开发者通过此接口完成GATT服务创建和启动后，需要调用GATT回调函数中serviceStartCb回调，通知SDK，以进行下一个gatt服务的创建和启动。
  5. 开发者创建GATT服务时，需记录GATT创建顺序与服务handle值的映射关系，后续发送数据时将通过创建顺序获取GATT服务的handle值。



**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
srvcHandle | int * | 输出 | GATT服务handle的存放缓冲区，开发者创建GATT服务后将服务handle写入srvcHandle传递给SDK****用于后续发送数据指定characteristic以及关闭GATT服务。  
srvcInfo | BleGattService * | 输入 | GATT服务中包含的service、characteristic、description等信息。  
  
**函数返回值** | **描述**  
---|---  
0 | 启动GATT服务成功。  
其他值 | 启动GATT服务失败。  
  
其中入参BleGattService结构如下：

**字段名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
attrNum | unsigned int | 输入 | 当前GATT服务包括的节点信息数量，计算方式详见补充说明1。  
attrList | BleGattAttr * | 输入 | 此GATT服务的节点链表，见补充说明2,3。  
  
函数入参srvcInfo实例如下：
    
    
    // 每个BleGattAttr中的uuid根据实际情况生成，此处省略未体现
    BleGattAttr serviceAttrList[] = {
        {
            .attrType = OHOS_BLE_ATTRIB_TYPE_SERVICE,
            .uuidType = OHOS_UUID_TYPE_128_BIT,
            .value = NULL,
            .valLen = 0
        },
        {
            .attrType = OHOS_BLE_ATTRIB_TYPE_CHAR,
            .permission = OHOS_GATT_PERMISSION_READ_ENCRYPTED | OHOS_GATT_PERMISSION_WRITE_ENCRYPTED,
            .uuidType = OHOS_UUID_TYPE_128_BIT,
            .value = NULL,
            .valLen = 0,
            .properties = OHOS_GATT_CHARACTER_PROPERTY_BIT_WRITE,
            .func = {
    // 当此characteristic被写时，需要调用write回调将数据传递给SDK
                .write = CharWriteFunc
            }
        },
        {
            .attrType = OHOS_BLE_ATTRIB_TYPE_CHAR,
            .permission = OHOS_GATT_PERMISSION_READ_ENCRYPTED | OHOS_GATT_PERMISSION_WRITE_ENCRYPTED,
            .uuidType = OHOS_UUID_TYPE_128_BIT,
            .value = NULL,
            .valLen = 0,
            .properties = OHOS_GATT_CHARACTER_PROPERTY_BIT_READ | OHOS_GATT_CHARACTER_PROPERTY_BIT_INDICATE,
            .func = {
                .read = CharReadFunc
            }
        }
    };
    
    BleGattService gattSvcInfo = {
        .attrNum = sizeof(serviceAttrList) / sizeof(BleGattAttr),
        .attrList = &serviceAttrList
    };
