# 上报设备状态数据  
  
#### 接口描述

reportDeviceData

通过智慧生活代理上报当前设备的状态数据到华为云侧，上报的数据必须是设备profile中定义的。

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：reportDeviceData  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
homeId | string | 否 | 家庭id，可不传  
deviceJsonData | DeviceStateEntity转Json字符串 | 是 | 上报的数据  
  
DeviceStateEntity实体

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
services | List<DeviceServiceEntity> | 是 | 上报的数据  
  
DeviceServiceEntity实体

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
sid | string | 是 | 服务id，支持设备profile里面定义的  
data | Map<string,string|boolean|number> | 是 | map的key为上面sid对应的cid
