# 关闭GATT服务

int BleGattsStopServiceEx(int srvcHandle)

SDK通过调用此接口停止协议栈中的GATT服务，参数handle为创建服务时，开发者回传的server的handle。在SDK出错退出运行时或者去初始化时调用。同BleGattsStartServiceEx，在停止指定GATT服务后，需要调用serverStopCb回调通知SDK，以进行下一个GATT服务的停止。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
srvcHandle | int | 输入 | 创建GATT服务时，开发者回传的服务handle。  
  
**函数返回值** | **描述**  
---|---  
0 | 关闭GATT服务成功。  
其他值 | 关闭GATT服务失败。
