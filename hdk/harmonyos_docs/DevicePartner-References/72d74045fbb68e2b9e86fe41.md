# 查询设备状态上报的统计数据  
  
#### 接口描述

hilink.getDevStatisticsDataWithQuery(String devId, String request, String callback);

查询设备状态上报的统计数据。如上报次数最大值、上报次数最小值等。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 设备ID。  
request | String | 是 | 请求信息。格式为json字符串。其中包含如下字段：

  * sid：设备的serviceId。
  * character：设备sid下的属性名称。
  * startTime：查询统计的开始时间戳，精确到秒。
  * endTime：查询统计的结束时间，精确到秒。
  * accuracy：枚举值，目前只支持HOUR、DAILY。最大支持查询2年。
  * pageSize：int分页大小，取值范围1-100，缺省值为100

  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    var devId = "设备的id";
    var request= 
    {
        "sid": "设备的serviceId",
        "character": "设备sid下面的属性名称",
        "startTime": "查询统计的开始时间戳，精确到秒"（时间不能是毫秒级别，否则获取到数据为空）,
        "endTime": "查询统计的结束时间，精确到秒"（时间不能是毫秒级别，否则获取到数据为空）,
        "accuracy": " (枚举值)  目前只支持HOUR，DAILY最大支持查询2年"
        "pageSize":"int分页大小，取值范围1-100，缺省值为100"
    }	
    ;
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getDevStatisticsDataWithQuery(devId, JSON.stringify(request), callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 请求成功，返回统计数据的json字符串。  
errcode | int | 是 | 请求失败，返回错误码。  
  
#### 响应示例

  * 成功
        
        {
        	"devDatas": [
        		{
        			"time": "小时粒度，则返回值为yyyyMMddhh",
        			"max": "该统计周期内最大值",
        			"min": "该统计周期内最小值",
        			"avg": "该统计周期内平均值",
        			"sum": "该统计周期内求和",
        			"accuracy": "(枚举值)目前只支持HOUR，DAILY",
        			"count": "该统计周期内上报的数据的次数"
        		}
        	],
        	"cursor": "下一页查询游标，无下一页则值为null",
        	"hasMore": "是否有剩余记录"
        }

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
