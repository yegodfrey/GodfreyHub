# 查询设备历史记录

#### 接口描述

hilink.getDevHistory(String devId, String pageNo, String pageSize, String startTime, String endTime, String sid, String character, String json_body)

查询设备历史记录。

#### 适用平台

Android、iOS

#### 接口约束

已开通历史记录权限，参考[云端服务申请（仅部分品类支持）](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-cloud-services-0000001087684232)。

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
pageNo | String | 否 | 返回的页码数，缺省为0。  
pageSize | String | 否 | 每页的数据个数，缺省为10。  
startTime | String | 是 | 获取历史记录开始的UTC（世界标准时间）时间。 格式：yyyyMMddTHHmmssZ 如：20150501T010203Z， 表示世界标准时间2015-05-01 01:02:03；北京时间为2015-05-01 09:02:03。  
endTime | String | 是 | 获取历史记录结束的UTC（世界标准时间）时间。 格式：yyyyMMddTHHmmssZ 如：20150601T010203Z， 表示世界标准时间2015-06-01 01:02:03；北京时间为2015-06-01 09:02:03。  
serviceId | String | 是 | 设备的service id，取值参见Device Partner平台的Profile中的定义。  
characteristicName | String | 是 | 设备的characteristicName，取值参见Device Partner平台的Profile中的定义。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var devId = "xxx";
    var startTime = "20150501T010203Z";
    var endTime = "20150601T010203Z";
    var serviceId = "xxx";
    var characteristicName = "xxx";
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.getDevHistory(devId, "0", "10", startTime ,endTime , serviceId, characteristicName, "resultCallback");

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
totalCount | int | 是 | 获取的历史记录数据总条数。  
pageNo | int | 是 | 页码数。  
pageSize | int | 是 | 每页的数据个数。  
list | Array | 是 | 具体的历史记录，每个sid下的数据以对象形式返回。
