# 重写返回键按键

#### 适用平台

Android、iOS

#### 接口描述

hilink.overrideBackPressed(boolean isOverride, String resultCallback)

是否覆盖原生返回按钮方法。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
isOverride | boolean | 设为true后，所有原生后退按钮点击时都会动用函数名为goBack的js方法。  
resultCallback | String | 回调函数的方法名。
