# 升级结束  
  
bool HILINK_OtaAdapterFlashFinish(void);

SDK在结束OTA流程后调用此接口获取OTA状态，返回ture表示正常，返回false表示异常；

**函数返回值** | **描述**  
---|---  
true | 升级结束正常。  
false | 升级结束异常。
