# 初始化  
  
bool HILINK_OtaAdapterFlashInit(void);

SDK在可以开始OTA流程后，将调用此接口。开发者需要进行Flash操作相关的初始化动作，以便后续进行FLASH相关操作，如读、写和擦除。

**函数返回值** | **描述**  
---|---  
true | FLASH初始化成功。  
false | FLASH初始化失败。
