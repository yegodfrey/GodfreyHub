# 跳转至其他App

#### 接口描述

hilink.startApp(String packageName, String resultCallback)

跳转应用。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
packageName | String | 是 | 待拉起应用的包名  
resultCallback | String | 是 | 结果回调方法名  
  
#### 请求示例
    
    
    hilink.startApp("com.test.app","resultCallback");

#### 响应参数

无
