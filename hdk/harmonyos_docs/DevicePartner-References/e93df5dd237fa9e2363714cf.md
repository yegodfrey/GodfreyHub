# 以indication的方式发送数据

int BleGattsSendIndication(int serverId, GattsSendIndParam *param)

SDK对外发送数据时，调用此接口通过参数指定characteristic，以indication的方式发送数据给连接对端，当发送数据成功后对端回复indication时，需要调用GATT事件回调函数indicationSentCb通知SDK。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/1WMk-JsjSsOTV4bNiHMDlg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090931Z&HW-CC-Expire=86400&HW-CC-Sign=614D3438BC63A9CA2301B5CA07B3B2E5A3C86EA901A57F3204977FFAE7B216C7)

serverId与入参param中attrHandle字段，指定发送数据的characteristic。指定方法如下：

  1. serverId为BleGattsStartServiceEx接口创建GATT服务时，传入的第N个服务的序号，由serverId得到出参返回的GATT服务handle值；
  2. attrHandle计算方法为characteristic所在的GATT Server的handle，加上目标characteristic在server中的序号;



例如：当需要用第三个创建的GATT服务下第二个characteristic发送indication数据时：

  1. 由于GATT服务为第三个创建，因此入参serverId值为2；
  2. 假设第三个GATT server的handle值为20，由于characteristic为server中的第2个，那最终attrHandle的值为22；



开发者发送数据时，根据自己GATT结构表以及attrHandle确定发送的特征。当前使用uuid为15F1E601A27......(此处省略后续)的characteristic发送数据，OTA时使用uuid为15F1E611A27......的characteristic；

注：协议栈函数适配情况，可以用hobt用例进行相关测试，XTS中展示了接口调用时传入的参数等相关信息。hobt测试完成后，设备将具有广播开关、蓝牙连接断开、GATT服务创建以及数据接收发送等基础功能，给后续设备添加、控制等功能使用。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
serverId | int | 输入 | 创建GATT服务时，第N个传递给蓝牙协议栈的GATT服务，N从0开始；serverId与param中的attrHandle结合，指定发送indication的characteristic。  
param | GattsSendIndParam * | 输入 | SDK发包携带的数据及对应character的句柄。  
  
**函数返回值** | **描述**  
---|---  
0 | Indication数据发送成功。  
其他值 | Indication数据发送失败。
