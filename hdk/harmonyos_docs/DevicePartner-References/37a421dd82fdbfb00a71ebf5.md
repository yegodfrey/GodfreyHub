# 广播开启结果回调

typedef void (*AdvEnableCallback)(int advId, int status)

此接口为广播开启之后的回调接口，通知SDK广播开启结果。启动广播失败后，SDK会尝试重新启动广播，当连续失败达到3次后，SDK将因为错误退出运行。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
advId | int | 输入 | 开启的广播id，SDK接收但不做处理。  
status | int | 输入 | 广播开启结果，0表示启动成功，非0表示失败。失败SDK会重试开启广播。
