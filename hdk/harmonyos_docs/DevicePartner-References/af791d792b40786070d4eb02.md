# 获取设备SN号

void HILINK_GetDeviceSn(unsigned int len, char *sn);

SDK通过HILINK_GetDeviceSn接口获取设备SN号，若SN为空时，发送广播时会使用MAC填充广播数据，但后续设备添加、OTA升级等流程也需要使用此转换得到的SN。注：函数入参缓冲区长度len不包括SN的结束符。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
len | unsigned int | 输入 | 存放SN区域长度，长度40不包括结束符。  
sn | unsigned char * | 输出 | 设备SN的缓冲区。  
  
此接口实现示例如下：
    
    
    #define DEVICE_SN "12345678"
    #define MIN_LEN(a, b) (((a) < (b)) ? (a) : (b))
    
    void HILINK_GetDeviceSn(unsigned int len, char *sn)
    {
        if (sn == NULL) {
            return;
        }
    
        const char *ptr = DEVICE_SN;
        int tmp = MIN_LEN(len, strlen(DEVICE_SN));
        for (int i = 0; i < tmp; i++) {
            sn[i] = ptr[i];
        }
        return;
    }
