# 删除云端BLE设备  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.deleteDevice (String deviceId, final String resultCallback)

删除云端用户名下的BLE设备。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 设备ID，由华为家居云分配。  
resultCallback | String | JS回调。  
  
#### 返回参数

  * 删除成功
        
        {"errcode":0}

  * 删除失败
        
        {"errcode":-1}
