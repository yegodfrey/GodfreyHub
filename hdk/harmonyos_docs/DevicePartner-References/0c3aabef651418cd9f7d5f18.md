# 查询未注册设备

#### 适用平台

Android、iOS

#### 接口描述

hilink.getCurrentUnregisteredDevice(CallbackName)

查询当前页面被选中的未注册的设备。此接口在添加蓝牙新设备的页面中调用。如果errCode不为0，表示未找到设备。

#### 返回参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 用于区分设备的 id，Android 上查询到的deviceId为设备 MAC 地址，iOS 上则为设备 uuid。  
RSSI | number | 当前蓝牙设备的信号强度  
advertisData | string | 当前蓝牙设备的广播数据段中的ManufacturerData数据段 ，转换为16进制字符串输出。Android将字符全转大写，iOS默认不处理。  
advertisServiceUUIDs | array | 当前蓝牙设备的广播数据段中的ServiceUUIDs数据段（UUID字符串数组）（Android为null） 示例：["0000ffe0-0000-1000-8000-00805f9b34fb", "0000ffe1-0000-1000-8000-00805f9b34fb", "0000ffe2-0000-1000-8000-00805f9b34fb"]  
localName | string | 当前蓝牙设备的广播数据段中的LocalName数据段  
serviceData | string | 当前蓝牙设备的广播数据段中的ServiceData数据段。  
errCode | Number | 错误码：0, 90001, 90005 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
