# 获取设备房间

#### 接口描述

getDeviceRoomName

获取设备房间名称

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getDeviceRoomName。  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识。
