# 显示标题栏中的图标

#### 适用平台

Android、iOS

#### 请求消息

在标题栏中，除设置、返回按钮外，最多可再配置2个图标。WEB中调用JS方法如下：
    
    
    hilink.showTitleBarIcons(
    "json_body", // body,string，图标地址，见下描述
    "buttonClick", // string，设置点击图标的回调方法
    "isVisible", // boolean，标题栏上的名称控件是否可见
    "resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
    );

json_body中需要的属性：
    
    
    {
      "url": xxx, // 示例：/static/img/img_xxx.png
      "url2": xxx 
    }
    // json_body中设置需要添加的图标url地址。“设置”图标为右侧第1个图标，"url" 对应从右到左第2个图标地址，"url2" 对应从右到左第3个图标地址。
    // 若仅需配置1个图标，仅配置 "url" 字段即可，无需配置"url2" 字段。

当点击图标时，将根据传入的buttonClick调用对应的js方法，并传入index参数表示点击的是哪一个图标。
    
    
    //web页面中需实现该函数，用来实现自定义的返回
    function buttonClick(index){
    //web 实现点击事件，其中index为0表示点击靠近设置按钮的图标，1为远离设置按钮的图标
    }

#### 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将如下结果返回到resultStr中。
    
    
    {
      "errcode": 0,
    }

#### 错误码
    
    
    {
      "errcode": 11
    }

错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077308408)。
