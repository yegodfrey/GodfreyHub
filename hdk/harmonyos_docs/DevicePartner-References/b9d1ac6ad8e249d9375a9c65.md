# 获取设备注册时间  
  
#### 接口描述

getHiLinkDeviceRegisterTime

获取设备在华为的注册时间

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getHiLinkDeviceRegisterTime。  
deviceId | string | 是 | 智慧生活拉起插件时传递给插件的设备唯一标识。
