# 删除设备

#### 接口描述

deleteDevice

删除设备，或者删除共享设备。主账号调用就是删除设备，共享用户调用就是删除共享设备

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：deleteDevice  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识
