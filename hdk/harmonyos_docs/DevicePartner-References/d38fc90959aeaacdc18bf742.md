# 调用原生弹框样式

#### 接口描述

hilink.toast(String time, String description)

调用原生弹框样式。

#### 适用平台

Android、iOS

#### 请求参数

参数 | 类型 | 描述 | 是否必填  
---|---|---|---  
time | String | 弹框停留时间，单位秒（s），时间不限。 | 否 （默认值为3.5秒）  
description | String | 弹框提示内容，内容长度不限。 | 是  
  
#### 请求示例
    
    
    hilink.toast(
       "time" //string，提示显示时长
       "description" //string，提示内容
    );

#### 响应参数

无

#### 响应示例

无
