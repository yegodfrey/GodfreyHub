# 跳转至华为商城产品页面  
  
#### 接口描述

hilink.gotoVmall(String suffix)

跳转到华为商城的某个产品页面。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
suffix | String | 是 | 华为商城某个产品页面的后缀，格式为“/product/xxxxxxxxxxxxxx.html”。  
  
#### 请求示例
    
    
    hilink.gotoVmall("/product/xxxxxxxxxxxxxx.html");

#### 响应参数

无

#### 响应示例

无

#### 错误码

无
