# 上报扩展数据  
  
#### 接口描述

hilink.postDeviceExtendData(String json_body, String resultCallback)

将前端自定义的扩展数据存储到云侧。扩展数据指未在物模型中定义、但需要在H5中使用的对象形式的数据。

#### 适用平台

Android、iOS

#### 接口约束

已通过线下方式申请云侧扩展数据权限。目前已不支持新增申请该权限。

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
json_body | String | 是 | 需要向云侧存储的数据。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var json_body = JSON.stringify({
      "type": "extendType", // 扩展属性的类型，需要云侧配合配置权限
      "data": {
          "sid": {
              "characteristicName": "xxx"  // sid和参数属性以及值的数据
          }
      } // sid和参数属性以及值的数据
    })
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.postDeviceExtendData(json_body, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
12 | 控制参数为空。 | 请检查请求参数。  
-1 | 设备ID为空或参数为空。iOS无该错误码。 | 请检查请求参数。  
-3 | 组网类型不存在。iOS无该错误码。 | -
