# 时间适配层接口

#### 获取当前设备启动后运行时间
    
    
    /*
     * 描述：获取当前设备启动后运行时间
     * 参数：time，出参，表示当前设备启动后运行时间
     * 返回：0成功，其他失败
     */
    int HILINK_GetOsTime(HiLinkTimeval *time);

#### 获取当前UTC时间
    
    
    /*
     * 描述：获取当前UTC时间
     * 参数：time，出参
     * 返回：0成功，其他失败
     * 注意: 对于不支持时间同步的设备，该接口不使用
     */
    int HILINK_GetUtcTime(HiLinkTimeval *time);
