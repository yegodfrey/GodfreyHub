# 连接蓝牙  
  
#### 接口描述

connectBle

连接蓝牙

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：connectBle  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
needBond | string |    | 是否需要配对，值："true"或者"false"  
bleMac | string |    | 蓝牙的bleMac地址，serviceType不为sts时生效  
isBond | string |    | 是否需要配对，值："true"或者"false"，serviceType不为sts时生效  
is2MPhy | string |    | 是否需要配对，值："true"或者"false"，serviceType不为sts时生效  
pinCode | string |    | 蓝牙配对码，serviceType不为sts时生效  
encryptedType | string |    |     
connectPriority | string |    | 值："1"或者"0"  
serviceType | string |    | 服务类型，值：sts（表示speke协商）或者其他  
  
#### 错误码

code | 描述  
---|---  
0 | 成功  
-1 | 连接失败
