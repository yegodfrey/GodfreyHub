# 写入数据

#### 适用平台

Android、iOS，平台差异如下：

  * Android平台：有返回值，标识读取返回成功或失败。
  * iOS平台：没有返回值，通过callback来获取结果。



#### 接口描述

hilink.writeBLECharacteristicValue (deviceId, serviceId, characteristicId, data, CallbackName)

对蓝牙设备写入data数据。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 蓝牙设备Id  
serviceId | String | 蓝牙特征值对应服务的 uuid（不使用4位的简写，用完整写法的UUID）  
characteristicId | String | 蓝牙特征值的 uuid（不使用4位的简写，用完整写法的UUID）  
data | String | 写入的二进制数据，以16进制字符串方式构造。  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
errCode | Number | 错误码：0, 90001 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
