# 从云侧查询设备状态

#### 接口描述

hilink.getDevInfo(String devId, String sid, String json_body, String resultCallback)

从云侧查询当前设备某个服务的状态。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
sid | String | 是 | 表示设备的服务ID ，取值详见Device Partner平台的Profile中的定义。  
json_body | String | 否 | 表示过滤条件。

  * 如果需要查询该sid下的所有属性值，json_body取值为空即可。
  * 如果需要查询该sid下的部分属性值，json_body取值应包含所需查询的characteristicName的取值。例如：JSON.stringify(["version","introduction"])。

  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var **sid** = "xxx";
    var cid = JSON.stringify(["on"]);
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.getDevInfo("0", **sid** , cid, "resultCallback");

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
responseData | String | 否 | 调用成功返回的结果。  
  
#### 响应示例

  * 成功
        
        {
          "characteristicName1": "value1",
          "characteristicName2": "value2"
        }




  * 失败
        
        {"errcode":12}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
12 | 请求参数校验失败。 | 确认请求参数合法。
