# 断开GATT连接  
  
int BleGattsDisconnect(int serverId, BdAddr bdAddr, int connId)

SDK通过调用此接口，与指定addr的对端设备断开连接。当前SDK固定以如下方式调用接口，其中addr为连接回调时传递的对端设备addr信息。
    
    
        if (BleGattsDisconnect(0, addr, 0) != 0) {
            printf("disconnect failed\r\n");
        }

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
serverId | int | 输入 | GATT服务ID，当前固定传入0。  
bdAddr | BdAddr | 输入 | 对端设备地址信息。  
connId | int | 输入 | 连接的ID，当前固定传入0。  
  
**函数返回值** | **描述**  
---|---  
0 | 断开蓝牙连接成功。  
其他值 | 断开蓝牙连接失败。
