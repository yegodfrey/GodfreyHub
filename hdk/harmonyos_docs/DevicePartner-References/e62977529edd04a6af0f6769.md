# 获取同类型摄像头列表  
  
#### 接口描述

getCameraList

获取当前时刻用户账号下全部同类型摄像头，用于多路同屏特性摄像头选择，提供网络摄像头使用

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getCameraList  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
  
#### 回调

data是一个Record<string, Object>[]转Json字符串，返回的参数如下：

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
deviceId | string | 是 | 华为deviceId  
vendorDevId | string | 是 | 设备上报profile的deviceInfo下面deviceID，或者id  
role | string | 是 | 用户角色，值：owner值family  
productId | string | 是 | dp平台创建的产品id  
deviceName | string | 是 | 设备名称  
verifyId | string | 是 | 设备上报profile的deviceInfo下面的verifyId  
sn | string | 是 | 设备序列号  
  
data为设备列表，示例：
