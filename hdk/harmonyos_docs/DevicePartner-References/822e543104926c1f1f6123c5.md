# 监听蓝牙状态变化  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.onBluetoothAdapterStateChange (CallbackName)

监听蓝牙状态变化的事件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/db/v3/7VlxbzSNRmu0dfgDrLgDpA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090918Z&HW-CC-Expire=86400&HW-CC-Sign=A81D76B11B61813410D4DD205153B3824AA1FB0F2E0C1A201E4C5BA11582C600)

使用该接口可多次注册不同名称回调函数，已注册的全部回调函数会持续生效。

#### 返回参数

参数 | 类型 | 描述  
---|---|---  
discovering | Boolean | 是否正在搜索设备  
available | Boolean | 蓝牙适配器是否可用
