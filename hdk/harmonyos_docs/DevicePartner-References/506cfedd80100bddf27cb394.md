# 发送MCU固件数据  
  
int HILINK_NotifyOtaData(const unsigned char *data, unsigned int len, unsigned int offset);

SDK获取MCU数据后，通过调用此函数写入MCU固件数据。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
data | const unsigned char * | 输入 | 存放MCU固件数据的缓冲区。  
len | unsigned int | 输入 | data缓冲区的长度。  
offset | unsigned int | 输入 | 写入位置的偏移量。  
  
**函数返回值** | **描述**  
---|---  
0 | MCU数据写入成功。  
其他值 | 有MCU但获取版本号失败。
