# 取消订阅蓝牙事件

#### 接口描述

unSubscribeBleEvent

取消订阅蓝牙事件

#### 适用平台

鸿蒙Next

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：disconnectBle  
bleMac | string | 设备blemac地址，为空时，使用设备注册时的bleMac  
  
#### 回调

正常情况不会回调

#### 错误码

code | 描述  
---|---  
-1007 | 参数不正确，deviceId为空。或者调用失败
