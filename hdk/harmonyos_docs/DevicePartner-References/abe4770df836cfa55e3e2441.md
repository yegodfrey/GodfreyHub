# 使能协议栈  
  
int EnableBtStack(void)

SDK在初始化协议栈后，使能协议栈时调用此接口，开发者可在此启动蓝牙协议栈，此接口在InitBtStack后调用。

**函数返回值** | **描述**  
---|---  
0 | 蓝牙协议栈使能成功。  
其他值 | 蓝牙协议栈使能失败。
