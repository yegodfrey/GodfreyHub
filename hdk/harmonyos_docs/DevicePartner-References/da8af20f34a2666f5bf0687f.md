# 查询设备信息  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.getDevInfoAll(devId, body, callback)

从云端查询设备的信息。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
devid | String | 华为云分配给设备的唯一id，查询本设备时传0。  
body | String | 该参数为预留参数。当前请传空值。  
callback | String | 回调方法。
