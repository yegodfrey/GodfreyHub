# 改变标题样式  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.changeTitleStyle(int styleValue)

改变设备标题样式：1：标题居中风格（默认） 2：标题居左风格。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
styleValue | int | 1：标题居中风格（默认） 2：EMUI10.0风格，标题居左
