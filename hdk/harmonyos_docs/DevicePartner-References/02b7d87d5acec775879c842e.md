# 清除设备BLE用户注册信息

#### 适用平台

Android、iOS

#### 接口描述

hilink.clearBleRegInfo(String deviceId, String bleMac, final String resultCallback)

清除设备侧BLE用户注册信息，适用于设备侧集成华为蓝牙SDK或适配华为蓝牙应用层开放协议规范的设备。

当设备没有硬重置按钮或硬重置不方便时，可以在删除设备时调用此接口清除设备信息，以便于下一次用户添加设备。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 被连接设备的ID，由华为家居云分配。  
bleMac | String | 设备BLE MAC地址。  
resultCallback | String | JS回调。  
  
#### 返回参数

  * 清除成功
        
        {"errcode":0,"responseData":"xxx"}

  * 清除失败
        
        {"errcode":-1}
