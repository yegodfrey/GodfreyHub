# 携带参数跳转固件升级页面

#### 适用平台

Android、iOS

  * Android：目前仅支持跳转到蓝牙OTA固件升级页面。
  * iOS：目前仅支持跳转到蓝牙OTA固件升级页面功能。



#### 接口描述

hilink. jumpToWithParams (String uri，String params, final String resultCallback)

根据对应uri跳转至对应页面

#### 请求参数

**表1** 参数 | 类型 | 描述  
---|---|---  
uri | String | 待跳转的页面，当跳转到蓝牙固件升级页面时，uri固定传入值为“com.huawei.smarthome.deviceBleUpgradeActivity”  
params | String | 跳转携带的json参数 当跳转页面为蓝牙固件升级页面时，使用params传递参数如下： { "intervalTime": 10, // 可选参数，如不传递使用默认值10。发包间隔时间，单位毫秒, android取值范围（1~10）（示例值，实际值可根据需要调整）; ios取值范围(1~100) "mtuPackageLength": 160 // 可选参数，如不传递使用默认值160。MTU发包大小，最大不超过500，取值范围（1~500）（示例值，应确保在允许范围内），具体该值需结合设备侧实际的MTU值 ，与设备侧的MTU值匹配。 }  
resultCallback | String | 回调js
