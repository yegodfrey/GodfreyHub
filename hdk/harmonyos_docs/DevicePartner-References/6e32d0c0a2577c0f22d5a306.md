# 连接蓝牙

#### 接口描述

hilink.connectBle(String deviceId, String bleMac, final String resultCallback)

应用通过BLE方式连接设备，适用于设备侧集成华为蓝牙SDK或适配华为蓝牙应用层开放协议规范的设备。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 被连接设备的ID，由华为家居云分配。通过[查询已注册设备](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/obtain-registered-devices-0000001090265827)获取  
bleMac | String | 是 | 被连接设备的BLE MAC地址。通过[查询已注册设备](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/obtain-registered-devices-0000001090265827)获取。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var deviceId = "xxx";
    var bleMac = "yyy";
    // web页面中需实现该函数，用来获取执行结果
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.connectBle(deviceId, bleMac, resultCallback);

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。非0错误码的说明详见错误码。

  * 0：成功。
  * -1：失败。

  
responseData | String | 是 | 执行状态或失败的原因。  
  
#### 响应示例

  * 连接成功
        
        {"errcode":0,"responseData":"success"}



  * 连接失败
        
        {"errcode":-1, "responseData":"reason"}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
-1 | 连接失败 | 检查设备处在可连接状态，尝试重新连接。
