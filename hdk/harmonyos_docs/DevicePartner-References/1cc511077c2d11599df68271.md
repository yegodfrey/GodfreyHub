# 设置安全请求  
  
int BleSetSecurityAuthReq(BleAuthReqMode mode)

SDK通过调用此接口设置蓝牙连接时的安全能力，当BLE_ConfPara结构体中isBlePair字段（详见BLE_CfgNetInit入参介绍）为0时，mode为OHOS_BLE_AUTH_NO_BOND；为1时，mode为OHOS_BLE_AUTH_REQ_SC_BOND。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
mode | 枚举类型BleAuthReqMode | 输入 | 是否请求与对方连接配对。  
  
**函数返回值** | **描述**  
---|---  
0 | 蓝牙协议栈发起安全请求成功。  
其他值 | 蓝牙协议栈发起安全请求失败。
