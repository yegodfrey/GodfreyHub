# 调用原生弹框样式

#### 适用平台

Android、iOS

#### 请求消息

当需要在页面中调用原生弹框样式时，WEB中调用js方法如下：
    
    
    hilink.toast(
    "time" //string，提示显示时长
    "body" //string，提示内容
    );

#### 响应消息

口无
