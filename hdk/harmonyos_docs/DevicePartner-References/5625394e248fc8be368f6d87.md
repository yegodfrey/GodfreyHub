# 注册蓝牙设备（SN与MAC）

#### 适用平台

Android、iOS，平台差异如下：

  * Android平台：函数名为“registerBleDevice”，本节以Android平台为例进行介绍。
  * iOS平台：函数名为“registerBleDeviceWithSnAndMac”。



#### 接口描述

hilink.registerBleDevice(sn, mac, fwv, hwv, CallbackName)

将蓝牙信息下发到底层，通知底层在HarmonyOS Connect云端注册蓝牙设备。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
sn | String | 设备的序列号，用于唯一标识该设备。  
mac | String | 设备的mac地址。  
fwv | String | 蓝牙设备固件版本。  
hwv | String | 蓝牙设备硬件版本。  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
errCode | Number | 错误码：0, 90001, 90012。 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
