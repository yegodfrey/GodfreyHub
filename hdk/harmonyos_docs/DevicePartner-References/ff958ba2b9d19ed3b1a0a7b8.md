# 查询规则（根据过滤条件）  
  
#### 接口描述

hilink.getRules(String condition, String callback);

根据过滤条件，查询对应的场景联动与消息推送规则。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
condition | String | 是 | 所有规则的过滤条件。格式为json字符串。其中的参数说明如下：

  * ruleId：可以为空值或者某个规则ID。当取值为空时，表示查询所有规则。
  * executor：执行主体。默认为Cloud，保持默认值即可。
  * ruleType：规则类型。默认为"1"（ifttt页面查询），需要修改为"2"（单品页面查询）。
  * name：规则名称。

  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    String condition = "{
        "ruleId":"", 
        "executor":"Cloud", 
        "ruleType":"2",
        "name":"Rule01"
    }";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getRules(condition, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 请求成功，返回所查询的规则对应的json字符串。  
errcode | int | 是 | 请求失败，返回错误码。  
  
#### 响应示例

  * 成功
        
        [
            {
                "id": 101,
                "name": "scene1",
                "type": 0,
                "description": "回家模式",
                "actions": [
                    {
                        "devId": "2323-1221-...",
                        "sid": "/switch1",
                        "data": {
                            "on": true
                        }
                    }
                ]
            }
        ]

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
-1 | 请求失败。 | -  
10 | 请求超时。 | 请检查网络。  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
