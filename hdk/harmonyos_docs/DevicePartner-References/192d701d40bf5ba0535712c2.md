# GATT服务启动回调  
  
typedef void (*ServiceStartCallback)(int status, int serverId, int srvcHandle)

SDK调用BleGattsStartServiceEx创建一个GATT Server后，开发者需要调用此回调函数通知SDK当前服务创建状态，以进行下一个服务创建流程的启动。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
status | int | 输入 | 创建服务的结果，status为0时，表示服务创建成功，SDK才创建下一个服务。  
serverId | int | 输入 | GATT服务的serverId。  
srvcHandle | int * | 输入 | 创建的GATT服务句柄。
