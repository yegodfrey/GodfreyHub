# 跳转智慧生活指定页面  
  
#### 接口描述

openHostView

跳转智慧生活指定页面

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：openHostView  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
targetView | number | 是 | 访问的页面的标记 10001：打开固件升级页面 10002：设备信息 10003：设备网络信息 10005：设备离线帮助页面，tv上不支持 10008：售后服务界面，tv上不支持 10009：设备分享页面，tv上不支持  
  
#### 错误码

只有在异常时才会回调，正常情况不会回调
