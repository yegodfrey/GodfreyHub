# 订阅蓝牙事件  
  
#### 接口描述

subscribeBleEvent

订阅蓝牙事件

#### 适用平台

鸿蒙Next

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：disconnectBle  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
bleMac | string | 设备blemac地址，为空时，使用设备注册时的bleMac  
serviceType | string | 服务类型，值为"sts"时，且传参bleMac不为空时，使用传过来的参数bleMac  
  
#### 回调

有蓝牙事件时会回调给插件的callback，调用接口成功，不会回调。

回调数据格式示例：

设备数据变化上报示例：

{"type":"CharacteristicChanged","content":{"data":{"on":1},"sid":"lightSwitch"}}

{"type":"CharacteristicChanged","content":{"data":{"gear":0},"sid":"gear"}}

设备连接状态变化示例：

{"newStatus":2,"oldStatus":0,"type":"ConnectionStateChange","mac":"40:24:B2:F6:8D:4C"}
