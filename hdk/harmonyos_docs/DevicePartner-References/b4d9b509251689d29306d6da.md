# OTA  
  
SDK提供了OTA功能，需要对相关OTA接口进行适配，接口包括了升级前、flash、MCU和升级状态通知等方面。由手机APP下发新固件数据，SDK通过调用flash接口存至对应分区的flash中。需要注意的是，在OTA固件下载完成后需要进行设备重启，请确保 HILINK_GetRebootFlag 接口返回正确结果，避免重启导致其他业务中断。
