# 查询手机状态栏高度  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.getStatusBarHeight(String resultCallback)

查询手机状态栏高度。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
resultCallback | String | 回调函数的方法名  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
statusBarHeight | Int | 手机状态栏高度（单位:dp）
