# 设备重置功能

int HILINK_BT_HardRevoke(void)

开发者调用此接口进行设备硬重置。当设备侧需要进行重置时，可以调用接口 HILINK_BT_HardRevoke 并重启设备的方式对SDK进行重置。此接口只对SDK本身进行重置，设备其他模块需要进行自身重置，重置后需要重启设备。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/UmIFIphkQMmG1xZT_PW0QQ/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090911Z&HW-CC-Expire=86400&HW-CC-Sign=841C57BECD86C98700F3E1046D23DF660BB02363684703A399CB1394D36EED36)

重置功能将会对flash数据进行修改，部分设备是异步对flash进行读写，可能出现接口调用完成，但flash数据未读写完成就进行设备重启，导致后续功能异常；请确保重启前flash操作已经完成。

**函数返回值** | **描述**  
---|---  
0 | SDK重置成功。  
其他值 | SDK重置失败。
