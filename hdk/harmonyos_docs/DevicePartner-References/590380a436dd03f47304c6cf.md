# 设置安全加密级别  
  
int BleGattsSetEncryption(BdAddr bdAddr, BleSecAct secAct)

SDK在开发者调用蓝牙连接回调函数时，将会调用此函数，以设置连接时数据传输通道的加密级别。加密等级由启动SDK时传入的启动参数中BLE_ConfPara结构体的isBlePair字段决定，当isBlePair为1时，传入OHOS_BLE_SEC_ENCRYPT，否则传入OHOS_BLE_SEC_NONE。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
bdAddr | BdAddr | 输入 | 对端设备地址。  
secAct | BleSecAct | 输入 | 安全加密的等级。当前只传递OHOS_BLE_SEC_ENCRYPT或者OHOS_BLE_SEC_NONE。  
  
**函数返回值** | **描述**  
---|---  
0 | 设置安全加密等级成功。  
其他值 | 设置安全加密等级失败。
