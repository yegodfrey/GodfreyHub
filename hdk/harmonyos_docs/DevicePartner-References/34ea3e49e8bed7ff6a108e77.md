# 修改设备名称（带devid）  
  
#### 接口描述

hilink.modifyDeviceNameByDevId(String deviceId, String deviceName, String resultCallback)

在设备设置页面，修改设备名称。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 设备的devId。  
deviceName | String | 是 | 修改的设备名称。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var deviceId = "xxx"; // deviceId,String,修改的设备id
    var deviceName = "xxx"; // deviceName,String,修改的设备名称字段
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.modifyDeviceNameByDevId(deviceId, deviceName, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 成功。iOS无该错误码。 | -  
-1 | 请求超时。iOS无该错误码。 | -  
12 | 请求参数校验失败。Android无该错误码。 | 请检查请求参数。
