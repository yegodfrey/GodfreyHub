# 查询手机状态栏高度  
  
#### 适用平台

Android、iOS

#### 请求消息

用于查询手机状态栏高度，WEB中调用js方法如下：
    
    
    hilink.getStatusBarHeight(
    "resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
    );

#### 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将对应的结果JSON字符串返回到resultStr中。
    
    
    {
      "statusBarHeight": "24", // 状态栏高度
    }

#### 错误码
    
    
    {
      "errcode": 11
    }

错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077308408)。
