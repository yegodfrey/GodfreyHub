# 下发命令到设备（循环控制）  
  
#### 接口描述

hilink.setDeviceServiceLoop(String devId, String serivceId, String json_body, String loopFlag, String intervalTime, String resultCallback)

下发循环控制命令给设备。例如，通过循环控制命令，实现照明设备灯光颜色的变幻和闪烁。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
serivceId | String | 是 | 服务ID。  
json_body | String | 是 | 传入需要设置的characteristicName以及相应的取值。取值详见Device Partner平台的Profile中的定义。 json_body不能为空，否则将导致失败。  
loopFlag | String | 是 | 是否重复循环。

  * "1"：是。
  * "0" ：否。

  
intervalTime | String | 是 | 间隔时间，单位为ms。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var serivceId = "xxx";
    var loopFlag = "xxx";
    var intervalTime = "";
    var json_body = JSON.stringify(
    {
        // sid为该设备的的service id，取值参见Profile定义。
        "sid1":{
            "characteristicName1": "value1",
            "characteristicName2": "value2"
        },
    }
    );
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.setDeviceServiceLoop("0", serivceId, json_body, loopFlag, intervalTime, 'resultCallback');

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 命令下发成功。 | -  
12 | 请求参数校验失败。 | 确认请求参数合法。
