# 分享模块

#### 导入模块
    
    
    import BasicLib from '@huawei/h5pro-basic-lib'

#### BasicLib.share.hideShareBtn

hideShareBtn(): void

隐藏分享按钮。

#### BasicLib.share.registryShareByElement

registryShareByElement(eleName: String, param: Object): void

向H5pro容器注册分享事件，当用户点击分享按钮时，自动截取元素图片进行分享。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
eleName | String | 元素的class类名。  
param | Object | 分享参数。  
  
    * Object 

参数名 | 类型 | 描述  
---|---|---  
isReport | Boolean | true: 保留“保存至本地”的按钮，图片支持缩放。false: 不保留“保存至本地”的按钮。  
moduleId | String | BI打点的ID。  
  



#### BasicLib.share.shareFileByBase64

shareFileByBase64(param: Object): void

将Base64字符串转为文件并分享。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
param | Object | 分享文件参数对象。  
  
    * Object 

参数名 | 类型 | 描述  
---|---|---  
data | String | 文件转成的base64字符串。  
mineType | String | MINE标准类型，如"application/pdf"。  
moduleId | String | [可选]分享动作所在的模块的唯一标识符，一般用于打点。  
fileName | String | 文件名，不带后缀。  
  



#### BasicLib.share.shareImageByElement

shareImageByElement(eleName: String, param: Object): void

通过对元素进行截图来分享图片。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
eleName | String | 元素的class类名。  
param | Object | 分享参数。  
  
    * Object 

参数名 | 类型 | 描述  
---|---|---  
isReport | Boolean | 是否为报告导出的分享，仅保留保存至本地的按钮，UI样式支持缩放。  
moduleId | String | BI打点的ID。  
  



#### BasicLib.share.shareLink

shareLink(url: String, title: String, desc: String, iconUrl: String): void

分享链接，包括url、标题、简述、Icon。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
url | String | 要分享的链接。  
title | String | 要分享的内容标题。  
desc | String | 要分享的内容简述。  
iconUrl | String | 要分享的icon的图片下载链接。  
  



#### BasicLib.share.shareText

shareText(str: String): void

文字分享。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
str | String | 分享的文字内容。
