# 广播关闭结果回调  
  
typedef void (*AdvDisableCallback)(int advId, int status)

此接口在SDK关闭ble广播之后，调用此接口通知SDK关闭状态。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
advId | int | 输入 | 关闭的广播id，SDK接收但不做处理。  
status | int | 输入 | 广播关闭结果，0表示关闭成功，非0表示失败。
