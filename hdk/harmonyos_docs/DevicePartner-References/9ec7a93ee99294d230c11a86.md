# 蓝牙

#### 导入模块
    
    
    import '@huawei/h5pro-hilink'

#### window.hilink.openBluetoothAdapter

openBluetoothAdapter()

打开手机蓝牙适配器。

  * 响应参数： 

参数名 | 类型 | 参数描述  
---|---|---  
retCode | Number | 返回码：0表示当前已经是开启状态， 90001表示当前是关闭状态。  
  



#### window.hilink.closeBluetoothAdapter

closeBluetoothAdapter()

关闭手机蓝牙适配器。

  * 响应参数： 

参数名 | 类型 | 参数描述  
---|---|---  
retCode | Number | 返回码：0关闭蓝牙适配成功，90001表示失败。详见[返回码清单](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-device-0000001227598363#section1580314217327)。  
  



#### window.hilink.getBluetoothAdapterState

getBluetoothAdapterState(callbackName: String): Object

获取手机蓝牙适配器状态。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
callbackName | String | 获取手机蓝牙模块状态回调函数名，该回调函数有三个参数，详情参见响应参数。  
  


  * 示例：
        
        function() {
             window.getBluetoothState = this.getBluetoothState;
             window.hilink.getBluetoothAdapterState("getBluetoothState");
        }



  * 响应参数： 

参数名 | 类型 | 参数描述  
---|---|---  
discovering | Boolean | 是否正在搜索设备，true代表正在搜索设备，false表示本地蓝牙适配器状态不是准备使用状态，不能被搜索。  
available | Boolean | 蓝牙适配器是否可用，true表示可用，false表示不可用。  
errCode | Number | 返回码：0表示获取状态成功，90001表示失败。详见[返回码清单](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-device-0000001227598363#section1580314217327)。

#### window.hilink.startBluetoothDevicesDiscovery

startBluetoothDevicesDiscovery(services: Array, allowDuplicatesKey: Boolean, interval: Number): Object

开始搜寻附近的蓝牙设备。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
services | Array | 当前搜索的蓝牙设备的广播数据段中的ServiceUUIDs数据段（UUID字符串数组）。 示例：[‘0000ffe0-0000-1000-8000-00805f9b34fb’, ‘0000ffe1-0000-1000-8000-00805f9b34fb’, ‘0000ffe2-0000-1000-8000-00805f9b34fb’]  
allowDuplicatesKey | Boolean | 是否允许重复上报同一设备， 如果允许重复上报，则onBluetoothDeviceFound方法会多次上报同一设备。  
interval | Number | 上报设备的间隔，默认为0，表示找到新设备立即上报，否则根据传入的间隔上报。  
  


  * 响应参数： 

参数名 | 类型 | 参数描述  
---|---|---  
retCode | Number | 返回码：0, 90001。详见[返回码清单](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-device-0000001227598363#section1580314217327)

#### window.hilink.onBluetoothDeviceFound

onBluetoothDeviceFound(callbackName: String): Object

订阅发现新的蓝牙设备的事件。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
callbackName | String | 手机蓝牙模块状态回调函数名，详情参见响应参数。  
  


  * 响应参数： 

参数名称 | 参数类型 | 参数描述  
---|---|---  
devices | Array | Device数组，Json字符串格式。  
deviceId | String | 用于区分设备的 id，Android上获取到的deviceId为设备MAC地址。  
RSSI | Number | 当前蓝牙设备的信号强度。  
manufacturerData | String | 当前蓝牙设备的广播数据段中的ManufacturerData数据段。  
advertisServiceUUIDs | String | 当前蓝牙设备的广播数据段中的ServiceUUIDs数据段（UUID字符串数组）。 示例：[‘0000ffe0-0000-1000-8000-00805f9b34fb’, ‘0000ffe1-0000-1000-8000-00805f9b34fb’, ‘0000ffe2-0000-1000-8000-00805f9b34fb’]  
localName | String | 当前蓝牙设备的广播数据段中的LocalName数据段。  
serviceData | String | 当前蓝牙设备的广播数据段中的ServiceData数据段。

  1. CallbackName可多次注册不同名称回调函数，已注册的全部回调函数，会在stopBluetoothDevicesDiscovery调用前生效。stopBluetoothDevicesDiscovery后，会清除回调注册。
  2. onBluetoothDeviceFound建议在startBluetoothDevicesDiscovery前调用，确保启动发现后每一次搜索到设备都能被准确回调。



#### window.hilink.requestConnectionPriority

requestConnectionPriority(connectionPriority: Number): Object

设置蓝牙设备请求连接的优先级。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
connectionPriority | Number | 只能传0,1,2。
    * 0表示Bluetooth传输的默认值。
    * 1表示请求高优先级，低延迟连接，以便快速传输BLE上的大量数据，传输完成请再次设置为0，降低功耗。
    * 2表示请求低功耗，降低数据传输速率。  
  


  * 响应参数： 

参数名称 | 参数类型 | 参数描述  
---|---|---  
errCode | Number | 返回码：0, 90001。详见[返回码清单](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-device-0000001227598363#section1580314217327)
