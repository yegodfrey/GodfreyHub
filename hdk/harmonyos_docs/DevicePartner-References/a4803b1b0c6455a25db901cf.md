# 设置自定义广播  
  
int BLE_CfgNetAdvUpdate(const BLE_AdvInfo *advInfo)

开发者调用此接口更新广播，BLE_AdvInfo结构中包含广播参数、广播数据（包含扫描应答数据）等字段。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/cWasOe5dQmKw_v6MnstU2A/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090932Z&HW-CC-Expire=86400&HW-CC-Sign=6F2C455A74D4A384044613E0AD312528DAE96D2875E7B8A69FCC45A8D411DDEC)

本接口用于配置自定义广播参数及数据。若未进行自定义设置或设置入参为空，系统将默认采用SDK内置的广播内容，自定义广播数据一经设置，即刻生效。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
advInfo | const BLE_AdvInfo * | 输入 | 广播相关参数配置，包括广播扫描参数和广播数据；传入NULL时将使用SDK默认配置。  
  
**函数返回值** | **描述**  
---|---  
0 | 参数配置成功。  
其他值 | 参数配置失败。  
  
int HILINK_BT_ChangeSleAdvParam(const BLE_AdvPara *advPara)

开发者调用此接口设置星闪广播参数，设置后立即生效。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
advInfo | const BLE_AdvPara * | 输入 | 星闪广播参数。  
  
**函数返回值** | **描述**  
---|---  
0 | 星闪广播设置成功。  
其他值 | 星闪广播设置失败。  
  
int HILINK_BT_ChangeBleAdvParam(const BLE_AdvPara *advPara)

开发者调用此接口更新蓝牙广播参数，设置后立即生效。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
advInfo | const BLE_AdvPara * | 输入 | 蓝牙广播参数。  
  
**函数返回值** | **描述**  
---|---  
0 | 蓝牙广播设置成功。  
其他值 | 蓝牙广播设置失败。
