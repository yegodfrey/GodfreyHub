# 获取地理位置数据  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.getGeolocation(String purpose，String resultCallback)

本接口适用于智慧生活App中H5页面获取地理位置。

#### 接口约束

需要第三方弹出自己的隐私声明，且联系华为侧产品经理评审才能增加调用权限。

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
purpose | String | 是 | 描述申请目的，取值长度范围[0,200]个字符。例如：“我们需要获取XX信息，用于XXX功能”。  
resultCallback | String | 是 | 回调方法。  
  
#### 请求示例
    
    
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){ 
        var result = resultStr; // 请求的返回结果 
    } 
    hilink.getGeolocation (“我们需要获取XX信息，用于XXX功能”, “resultCallback”);

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。非0错误码的说明详见错误码。

  * 0：成功。
  * -1：没有在mainhelp授权。
  * -2：用户没有同意目的声明。
  * -3：用户没有同意系统授权。

12：参数校验非法。  
data | string | 否 | 执行状态或失败原因。  
  
#### 成功响应示例
    
    
    {
    "errorcode": 0,
    "data": {
    "latitude": "xxx",
    "longitude": "yyy"
    }
    }

#### 失败响应示例
    
    
    {"errcode":-1}

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
-1 | 没有在mainhelp授权。 | 需要提出申请，并经过评审。  
-2 | 用户没有同意目的声明。 | NA  
-3 | 用户没有同意系统权限授权。 | NA  
-4 | 系统错误，调用native获取位置接口报错。 | NA  
12 | 参数校验非法。 | 检查参数purpose是否超长。
