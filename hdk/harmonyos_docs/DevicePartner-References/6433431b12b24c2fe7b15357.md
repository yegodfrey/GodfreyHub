# 获取HmsCode

#### 接口描述

getHmsCode

获取插件的Auth Code，用于厂家去华为云侧鉴权

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getHmsCode  
subAppId | string | 是 | 插件在华为开发者联盟申请的 appId  
targetValue | int | 否 | 默认值：1， 值：0，如果用户未授权过的应用，会拉起授权弹框，用户确认授权后返回Auth Code，使用场景：在插件里面进行授权，可以进行弹框。 值：1，如果未授权的应用，不会拉起授权弹框，返回账号未授权。使用场景：不在插件里面的场景，这时不弹框。  
pluginHmsScope | string | 是 | Scope 权限,多个权限可以使用“+”连接  
  
#### 回调

code:1000时data为获取的 Auth Code 值

#### 错误码

code | 描述  
---|---  
1001500001 | 应用指纹证书校验失败  
1001500002 | 重复请求，当已有相同的请求在处理时，返回此错误码  
1001500003 | 不支持该scopes或permissions  
1001500004 | 已登录的华为账号不支持该功能  
1001500005 | 该功能被限制调用  
1001502001 | 用户未登录华为账号  
1001502002 | 应用未授权  
1001502005 | 网络异常  
1001502009 | 内部错误，如华为账号服务器错误或其他内部错误等  
1001502012 | 用户取消授权  
1001502014 | 应用未申请scopes或permissions权限
