# 打开蓝牙  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.openBluetoothAdapter()

请求打开蓝牙。

#### 返回参数

参数 | 类型 | 描述  
---|---|---  
retCode | Number | 错误码：0表示当前已经是开启状态, 90001表示当前是关闭状态。 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
