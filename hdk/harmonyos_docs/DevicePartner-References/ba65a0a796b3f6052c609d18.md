# 设备蓝牙断开回调

typedef void (*DisconnectServerCallback)(int connId, int serverId, const BdAddr *bdAddr)

当设备蓝牙连接断开时，通过此接口通知SDK连接断开。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
connId | int | 输入 | 本次连接的ID。  
serverId | int | 输入 | 本次连接的serverId。  
bdAddr | const BdAddr * | 输入 | 本次连接的对端设备地址。
