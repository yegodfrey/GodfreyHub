# 跳转设备离线页面

#### 接口描述

hilink.jumpToOfflineHelpActivity(String deviceId, String hotline, String resultCallback)

跳转设备离线页面。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 跳转的设备ID  
hotline | String | 是 | 厂家售后热线  
resultCallback | String | 否 | 结果回调方法名  
  
#### 请求示例
    
    
    hilink.jumpToOfflineHelpActivity("deviceId", "hotline");

#### 响应参数

无

#### 响应示例

无
