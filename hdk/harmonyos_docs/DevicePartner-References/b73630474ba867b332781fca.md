# 查询设备状态上报统计数据（标量）  
  
#### 接口描述

hilink.getDevScalarData(String devId, String serviceId, String characteristicName, String callback);

查询设备状态上报的统计数据（标量）。如设备第一次注册时间、状态第一次上报时间等。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 设备ID。  
serviceId | String | 是 | 服务ID。  
characteristicName | String | 是 | 服务ID下的属性名。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    var devId = "设备ID";
    var serviceId = "服务ID";
    var characteristicName = "属性名";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getDevScalarData(devId, serviceId, characteristicName, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 请求成功，返回统计数据的json字符串。  
errcode | int | 是 | 请求失败，返回错误码。  
  
#### 响应示例

  * 成功
        
        {
        	"regTime": "设备第一次注册时间",
        	"beginTime": "sid第一次上报时间on",
        	"total": "使用总时长",
        	"extent": "扩展信息"
        }

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
