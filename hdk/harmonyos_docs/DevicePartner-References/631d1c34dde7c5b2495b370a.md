# 是否提示固件升级

#### 适用平台

Android

#### 接口描述

hilink.isNeedUpgrade(String deviceId, String versionNumber)

判断当前设备是否需要提示固件升级。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 蓝牙设备Id  
versionNumber | String | 传入的固件版本号码  
  
#### 返回参数

true表示需要；false表示不需要。
