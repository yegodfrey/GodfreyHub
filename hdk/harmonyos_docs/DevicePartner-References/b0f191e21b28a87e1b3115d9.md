# 同意对端安全请求  
  
int BleGattSecurityRsp(BdAddr bdAddr, bool accept)

SDK在securityRespondCb回调中，调用此接口，同意对端设备的连接配对请求。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
bdAddr | 结构体BdAddr | 输入 | 对端设备地址信息。  
accept | bool | 输入 | 是否同意安全请求。  
  
**函数返回值** | **描述**  
---|---  
0 | 同意安全请求成功。  
其他值 | 同意安全请求失败。
