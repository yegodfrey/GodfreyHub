# 智慧生活调用插件接口

插件将要提供接口在插件module跟目录的index.exs里面将响应的接口导出，然后提供给智慧生活har，智慧生活集成har，即可调用插件的接口。通常提供一个通用接口通过，通过参数来区分具体调用的接口。

一、插件提供外部调用接口，示例如下：
    
    
    export class XXPluginApi {
      public static callPlugin(context: Context | undefined, params: string, callBack: (code: number, data?: Object, msg?: string) => void) {
        let data: Record<string, string | object | number | null> = JSON.parse(params)
        let functionName = data['functionName']
        if (functionName == 'deleteHomeDevice') {
          //处理删除设备逻辑
        } else if ("deviceDataChanged") {
          //设备数据变化
        }
      }
    }

二、在插件的跟路径的index.ets export 类
    
    
    export{XXPluginApi} from "./src/main/ets/api/XXPluginApi"

三、然后把打包生成后的har提供给智慧生活接口人，进行联调

  * **[删除设备](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/genera-error-codes02-0000002584595968)**  

  * **[设备状态变化](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/genera-error-codes04-0000002614795709)**
