# 上报信息  
  
int BLE_SendCustomData(BLE_DataType dataType, const unsigned char *buff, unsigned int len)

开发者调用此接口进行自定义数据上报。设备添加完成后，如需主动向智慧生活 App 上报电量、开关状态等信息，可通过该接口实现；亦可对接收到的自定义控制指令进行异步响应，完成状态同步。若接口返回值非零，则表示数据上报失败。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/E4QsLXX9QoKZWgSyRTtQ-g/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090928Z&HW-CC-Expire=86400&HW-CC-Sign=8FA3F72CE73F456C3F057EFE3EA569D133E59683A5A4CABD551E99E1F6D1E376)

  1. 当设备设备未被手机/网关连接时，无法进行数据上报。
  2. 数据上报时请注意当前连接会话是否已认证，避免数据泄露。接收设备状态方法见BLE_CfgNetCb 结构体中 cfgNetProcessCb 字段，回调函数的入参枚举值对应设备各个状态；调用BLE_SendCustomData时，dataType请使用CUSTOM_SEC_DATA，SDK会对数据进行加密传输，避免数据泄露。



**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
dataType | BLE_DataType | 输入 | 参考BLE_DataType枚举值；NETCFG_DATA用于上报配网相关数据，不常使用；CUSTOM_DATA不加密上报数据，不推荐；CUSTOM_SEC_DATA加密上报数据，推荐。  
buff | const unsigned char * | 输入 | 要上报至APP/网关的字符串。  
len | unsigned int | 输入 | 要上报至APP/网关的字符串长度。  
  
**函数返回值** | **描述**  
---|---  
0 | 数据已传入ble/sle协议栈，待协议栈上报。  
其他值 | 数据上报失败。
