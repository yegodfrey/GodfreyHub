# 开关广播

int BLE_CfgNetAdvCtrl(unsigned int advSecond);

开发者调用此接口可以发起BLE广播或关闭BLE广播，当星闪功能使能时，会同步打开SLE 广播。未设置广播参数及数据时，使用SDK默认广播参数及数据，无特殊场景无需配置参数及数据。广播开启时间由入参控制，单位为秒。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
advSecond | unsigned int | 输入 | 广播启动时长，单位秒。

  * 0：停止广播。
  * 0xFFFFFFFF：一直广播。
  * 其它值：广播指定时间后停止。

  
  
**函数返回值** | **描述**  
---|---  
0 | 广播启动完成。  
其他值 | 广播启动失败。
