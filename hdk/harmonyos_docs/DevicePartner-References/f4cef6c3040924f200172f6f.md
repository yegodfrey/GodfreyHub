# 删除设备文件

#### 接口描述

hilink.deleteObjectReq(String request, String callback);

从云端删除设备相关文件，如智能门锁的用户头像。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
request | String | 是 | 请求附带参数。格式为json字符串。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    var request = "{devId:设备id, objectName:文件名}";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){} 
    hilink.deleteObjectReq(request, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。  
  
#### 响应示例

  * 成功
        
        {"errcode":0}

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
-3 | 网络错误。 | 请检查网络。  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
