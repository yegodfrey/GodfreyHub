# 跳转至设备信息页面

#### 接口描述

hilink.jumpTo(String uri, String resultCallback)

跳转设备信息页面。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
uri | String | 是 | 固定值“com.huawei.smarthome.deviceinfoactivity”  
resultCallback | String | 是 | 结果回调方法名  
  
#### 请求示例
    
    
    hilink.jumpTo("com.huawei.smarthome.deviceinfoactivity","resultCallback");

#### 响应参数

无
