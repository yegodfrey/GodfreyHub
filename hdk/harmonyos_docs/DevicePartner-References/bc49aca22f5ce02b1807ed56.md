# 从本地查询设备静态信息  
  
#### 接口描述

hilink.getDeviceInfo(String resultCallback)

从本地缓存中查询设备的静态信息，如deviceId、devName及devInfo。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/1uOrIwtlSle-pgrrXUZm2g/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090920Z&HW-CC-Expire=86400&HW-CC-Sign=A1F58BC2AE882D91D24FBC45C4423E521F239A130DBA9993525279DB4C69D0A5)

该接口services节点下的数据无法保证最新，如需查询Profile数据，推荐使用[getDevInfoAll](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/obtain-device-info-from-cloud-0000001273822281)接口。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.getDeviceInfo(
        "resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
    );

#### 响应参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 设备ID。  
devName | String | 是 | 设备名称。  
roomName | String | 是 | 设备所在房间名称。  
status | String | 是 | 设备状态。  
gatewayId | String | 是 | 设备所处Gateway的ID。  
nodeType | String | 是 | 节点类型，取值范围如下：

  * ENDPOINT：通过网关接入的设备。
  * GATEWAY：网关。
  * GROUP：设备组。

  
devInfo | Object | 是 | 设备信息，见下表。  
services | Array | 是 | profile的services数据模型，取值参见HiLink Profile定义。  
  
devInfo中的设备信息参数如下表。

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
sn | String | 是 | 设备SN号。  
manu | String | 是 | 制造商ID。  
devType | String | 是 | 设备类型。  
model | String | 是 | 设备型号。  
mac | String | 是 | MAC地址，格式为“XX:XX:XX:XX:XX:XX”，统一为大写。  
hiv | String | 是 | HiLink协议版本。  
fwv | String | 是 | 固件版本（Firmware Version）。  
swv | String | 是 | String，软件版本（Software Version）。  
id | String | 是 | 网关子设备信息实体设备ID。  
prototype | String | 是 | 协议类型。取值范围如下：

  * 1: Wi-Fi。
  * 2: Z-Wave。
  * 3: ZigBee。
  * 4: BLE。
  * 5: PLC。

  
subProdId | String | 否 | 设备子型号（同一设备的不同子型号）。
