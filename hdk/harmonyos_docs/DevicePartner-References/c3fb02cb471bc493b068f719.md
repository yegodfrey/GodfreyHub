# 开始升级  
  
int HILINK_OtaStartProcess (int type);

SDK通过此接口通知开发者设备将启动升级，当前纯蓝牙设备仅有用户手动触发升级的方式。开发者需要根据设备情况，判断当前是否可以进行OTA升级。如果处理正常就返回0，否则返回-1。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
type | int | 输入 | 本次OTA升级类型，由于单蓝牙（不带WiFi）设备无法自动升级，因此当前仅传入0表示用户手动触发升级。  
  
**函数返回值** | **描述**  
---|---  
0 | 当前可进行OTA升级流程。  
其他值 | 当前不可进行OTA升级流程。
