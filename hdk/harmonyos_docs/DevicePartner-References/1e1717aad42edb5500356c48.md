# 下发命令到设备（带多个sid）  
  
#### 接口描述

hilink.setMultipleDeviceInfo(String devId, String json_body, String isParallel, String isWaitAll, String resultCallback)

下发命令给设备，以实现对设备状态的控制。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
json_body | String | 是 | 传入需要设置的sid（支持多个sid）、characteristicName以及相应的取值。取值详见Device Partner平台的Profile中的定义。 json_body不能为空，否则将导致失败。  
isParallel | boolean | 是 | 命令是否并行下发。

  * true：并行下发。
  * false：串行下发。

  
isWaitAll | boolean | 是 | 是否等待所有命令下发成功后，再回调返回结果。

  * true：当所有命令下发成功，才会回调返回结果。
  * false：只要有一个命令下发成功，就会回调返回结果。

  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var isParallel = xx;
    var isWaitAll = xx;
    var json_body = JSON.stringify( [
    {
        // sid为该设备的的service id，取值参见Profile定义。
        "sid1":{
            "characteristicName1": "value1",
            "characteristicName2": "value2"
        },
        "sid2":{
            "characteristicName1": "value1",
            "characteristicName2": "value2"
        }
    }]
    );
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.setMultipleDeviceInfo("0", json_body, isParallel, isWaitAll, 'resultCallback');

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 命令下发成功。 | -  
12 | 请求参数校验失败。 | 确认请求参数合法。
