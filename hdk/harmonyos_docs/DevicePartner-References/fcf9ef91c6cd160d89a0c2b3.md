# 创建快捷方式

#### 适用平台

Android、iOS，平台差异如下：

  * Android平台：入参不需要resultCallback回调，，本节以Android平台为例进行介绍。
  * iOS平台：入参需要resultCallback回调，调用方式如下：
        
        hilink.createShortCut(String deviceId, String productId, String deviceName, String resultCallback) 




#### 请求消息

当需要在当前页面中创建快捷方式时，WEB中调用js方法如下：
    
    
    hilink.createShortCut(
    "deviceId", // string, 设备Id
    "productId", // string, 产品Id
    "deviceName", // string, 设备名称
    );

#### 响应消息

该接口无回应。
