# 查询广播类型  
  
int BLE_GetAdvType(void)

开发者调用此接口查询当前设置的SDK广播类型。

**函数返回值** | **描述**  
---|---  
BLE_ADV_DEFAULT | 默认广播类型。  
BLE_ADV_NEARBY_V0 | 靠近发现广播类型。  
BLE_ADV_ONEHOP | 碰一碰类型。  
BLE_ADV_LOCAL_NAME | 常态广播类型。
