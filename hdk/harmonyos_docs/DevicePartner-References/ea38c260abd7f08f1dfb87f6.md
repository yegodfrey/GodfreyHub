# 设置靠近发现广播持续时长

void HILINK_BT_SetNearbyAdvDuration(unsigned int seconds)

开发者可调用此接口设置靠近发现广播持续时长。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
seconds | unsigned int | 输入 | 靠近发现广播持续时长，s为单位。
