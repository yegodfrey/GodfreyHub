# 删除设备历史记录  
  
#### 接口描述

hilink.deleteDeviceHistory(String devId, String serviceId, String cursor, String json_body)

删除设备历史记录。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
serviceId | String | 是 | 设备的service id，取值参见Device Partner平台的Profile中的定义。  
cursor | String | 否 | 查询的游标，缺省时为null。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var **devId** = "xxx";
    var serviceId = "xxx";
    var cursor = "xxx"
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.deleteDeviceHistory(devId, serviceId, cursor, "resultCallback");

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
hasMore | String | 是 | 返回true时，表明历史记录已经分页，需要根据cursor查询下一页。 App携带cursor继续发送请求，删除剩余历史记录，直到hasMore返回false为止。  
cursor | String | 是 | 查询的游标。  
  
#### 响应示例

  * 成功
        
        {
            "hasMore": true, // 表明历史记录已经分页，需要根据cursor查询下一页。App携带cursor继续发送请求，删除剩余历史记录，直到hasMore返回false为止。
            "cursor":"317b226c6173745265636f72644b657956616c756" //查询的游标
        }




  * 连接失败
        
        {"errcode":12}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
12 | ID无效或数据解析失败。 | 检查请求参数。  
-1 | 设备ID或service ID为空。iOS无该错误码。 | 检查请求参数。  
-3 | 控制渠道不存在。iOS无该错误码。 | -
