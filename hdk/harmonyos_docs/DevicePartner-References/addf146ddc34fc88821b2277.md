# 删除多个规则

#### 接口描述

hilink.deleteRules(String ruleIds, String callback);

根据ruleID数组，删除多个规则。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
ruleIds | String | 是 | 规则的ruleId数组的json字符串。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    String ruleIds = ["101","10"];
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.deleteRules(ruleIds, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errorcode | int | 是 | 请求成功，返回errcode为0。  
result | string | 是 | 请求失败，返回删除失败的规则ID的集合。  
  
#### 响应示例

  * 成功
        
        {errcode:0}

  * 失败
        
        ["删除失败的规则ID", "删除失败的规则ID"]




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
10 | 请求超时。 | 请检查网络。  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
