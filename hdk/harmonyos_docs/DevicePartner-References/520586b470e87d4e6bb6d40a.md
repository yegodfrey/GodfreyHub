# 窗口容器  
  
#### 导入模块
    
    
    import BasicLib from '@huawei/h5pro-basic-lib'

#### BasicLib.container.exit

exit(): void

退出容器，关闭整个页面。

#### BasicLib.container.goBack

goBack(): void

返回上一个页面。如果已经是第一个页面，则关闭当前窗口。

#### BasicLib.container.setImmerse

setImmerse(param: Object): void

切换沉浸模式和状态栏字体颜色。

  * 参数： 

参数名 | 类型 | 说明  
---|---|---  
param | Object | 设置切换沉浸模式和状态栏字体颜色。  
  
    * Object 

参数名 | 类型 | 说明  
---|---|---  
isImmerse | Boolean | true表示开启沉浸模式，false表示关闭沉浸模式。  
isStatusBarTextBlack | Boolean | true表示状态栏文字为黑色，false表示状态栏文字为白色。  
  


  * 示例：
        
        BasicLib.container.setImmerse({
            isImmerse: true,
            isStatusBarTextBlack: false,
        });




#### BasicLib.container.setPageTitle

setPageTitle(title: String): void

设置页面标题。显示在标题栏，导航按钮右侧。

  * 参数： 

参数名 | 类型 | 说明  
---|---|---  
title | String | 标题字符串。  
  



#### BasicLib.container.setScreenLandscape

setScreenLandscape(isLandscape: Boolean): void

设置H5页面是否横屏显示。

  * 参数： 

参数名 | 类型 | 说明  
---|---|---  
isLandscape | Boolean | true表示横屏，false表示竖屏。
