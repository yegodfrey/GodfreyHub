# 删除设备

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为： deleteHomeDevice  
deviceList | Record<string,object> | 删除的设备列表  
  
deviceList包含的参数：

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
deviceId | string | 是 | 华为设备id  
sn | string | 是 | 设备序列号  
productId | string | 是 | dp平台创建的产品类型  
mac | string | 是 | mac地址  
role | string | 是 | 用户角色，值：owner值family  
verifyId | string | 否 | 网络摄像头使用使用  
uuid | string | 否 | 网络摄像头使用使用  
  
删除设备智慧生活不处理返回值，只是通知插件
