# 修改设备所处房间  
  
#### 接口描述

hilink.modifyDeviceRoomName(String chooseRoomString, String resultCallback)

在设备设置界面，修改设备所处房间。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
chooseRoomString | String | 是 | 修改的设备所处房间。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var chooseRoomString= "xxx";
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.modifyDeviceRoomName(chooseRoomString, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 下发成功。 | -  
9999 | 请求参数为空。iOS无该错误码。 | 检查请求参数。  
12 | 请求参数校验失败。Android无该错误码。 | 检查请求参数。
