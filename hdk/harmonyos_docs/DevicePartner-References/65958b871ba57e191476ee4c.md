# 查询设备的H5 URL地址

#### 接口描述

hilink.getSubDeviceUrl(String productId, String callback);

查询设备的H5 URL地址。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
productId | String | 是 | 产品ID。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    String productId = "产品ID";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getSubDeviceUrl(productId, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 返回查询设备的H5 URL地址。  
  
#### 响应示例

返回查询设备的H5 URL地址，例如：
    
    
    https://smarthome.hicloud.com/device/guide/101v/h5_001/index.html

#### 错误码

无
