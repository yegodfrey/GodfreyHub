# 获取用户设备管理角色

#### 接口描述

getUserDeviceManagerRole

获取当前用户是设备的拥有者还是分享用户

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：getUserDeviceManagerRole  
deviceId | string | 华为设备id  
  
#### 回调

返回data未number类型，0：设备拥有者，1：分享用户
