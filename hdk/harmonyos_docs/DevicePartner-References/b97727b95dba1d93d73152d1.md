# 获取HmsAccessToken  
  
#### 接口描述

getHmsAt

智慧生活连接 HMS SDK 获取 AT

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getHmsAt  
subAppId | string | 是 | 插件在华为开发者联盟申请的 appId  
forceFlag | boolean | 否 | 是否强制获取 AT （false为正常获取 AT ，true为强制获取 AT），默认值：“false”  
pluginHmsScope | String | 是 | Scope 权限,多个权限可以使用“+”连接  
  
#### 回调

code:1000时data为获取的 AT 值

#### 错误码

code | 描述  
---|---  
10012 | 云侧RT刷新AT超时  
9999 | 云侧请求超时
