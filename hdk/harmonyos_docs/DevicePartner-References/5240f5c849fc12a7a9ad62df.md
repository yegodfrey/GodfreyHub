# 检查是否有新的固件

#### 适用平台

Android、iOS

#### 接口描述

hilink.checkBleHota(String deviceId, String versionNum, final String callback)

查询设备的最新固件信息。

如果有新的固件版本则返回新的固件信息，否则返回空。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 蓝牙设备Id  
versionNum | String | 设备当前固件版本号  
callback | String | 回调函数的方法名  
  
#### 请求示例
    
    
    hilink.checkBleHota (
      "deviceId", // deviceId,string, 规则json字符串
      "versionNum", // versionNum,string, 规则json字符串
      "resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
    )

#### 返回参数

参数 | 类型 | 描述  
---|---|---  
description | String | 固件更新内容描述  
version | String | 固件版本号  
url | String | 固件下载地址  
  
#### 响应示例
    
    
    // web页面中需实现该函数，用来查询执行结果
    window.resultCallback = resultStr => {
        const result = JSON.parse(resultStr); // REST请求的返回结果
        if (result.errcode === undefined || result.errcode === 0) {
            const { description, version , url } = result
        }
    }
