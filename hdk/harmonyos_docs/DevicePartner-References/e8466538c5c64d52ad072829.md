# 判断折叠屏手机屏幕是否展开

#### 接口描述

hilink.isScreenSpreaded()

判断折叠屏手机屏幕是否展开。

#### 适用平台

Android

#### 请求参数

无

#### 请求示例
    
    
    let isScreenSpreaded = hilink.isScreenSpreaded();
    if (isScreenSpreaded){
       // 折叠屏展开的代码操作
    } else {
       // 折叠屏未展开的代码操作
    }

#### 响应参数

返回boolean类型值：

  * true：折叠屏展开
  * false：折叠屏未展开



#### 响应示例

无
