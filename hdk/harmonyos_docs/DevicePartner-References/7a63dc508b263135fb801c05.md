# 清除本地全部缓存

#### 适用平台

Android、iOS

#### 接口描述

hilink.clearStorageSync()

清除同一用户同一类型设备的全部缓存数据。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/HUtTqZlYQeO__j97S_QFOA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090908Z&HW-CC-Expire=86400&HW-CC-Sign=8FA17C4045E4FB7EC12D53464ADBA623300489DFC9A303CD1876CA0776D582E2)

缓存数据是保存在App内部存储空间的，所以清除App数据后，存储数据会被全部清除。如果特定数据需要持续保存，可以考虑将数据保存在HarmonyOS Connect云端（需定义产品的Profile）。

#### 返回参数

参数 | 类型 | 描述  
---|---|---  
retCode | Number | 错误码：0, 90001 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
