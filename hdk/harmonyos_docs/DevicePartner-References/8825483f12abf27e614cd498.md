# 注册GAP回调函数

int BleGattRegisterCallbacks(BtGattCallbacks *func)

SDK初始化过程中，调用此接口将GAP事件回调函数注册到蓝牙协议栈中。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
func | BtGattCallbacks * | 输入 | SDK要注册的GAP事件回调函数，当前仅使用广播开启关闭和安全请求回应的回调。  
  
**函数返回值** | **描述**  
---|---  
0 | 注册GAP事件回调函数成功。  
其他值 | 关注册GAP事件回调函数失败。  
  
  * **[广播开启结果回调](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-callback-0000002583479942)**  

  * **[广播关闭结果回调](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-callback01-0000002583639840)**  

  * **[安全请求回调](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-callback02-0000002613999621)**
