# 下发命令到设备（长按控制）  
  
#### 接口描述

hilink.setLongPressDeviceInfo(String devId, String json_body, String resultCallback, boolean isLongPressInProgress)

下发长按控制命令给设备。例如，通过长按控制命令，实现智能床/升级桌等设备的高度调节。

该方法可以防止在控制过程中，H5页面反复弹出提示框、影响控制连续性。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
json_body | String | 是 | 传入需要设置的sid（仅支持单个sid）、characteristicName以及相应的取值。取值详见Device Partner平台的Profile中的定义。 json_body不能为空，否则将导致失败。  
resultCallback | String | 是 | JS回调。  
isLongPressInProgress | boolean | 是 | 

  * true：长按命令开始执行。
  * false：长按命令结束。

  
  
#### 请求示例
    
    
    var json_body = JSON.stringify(
    {
        // sid为该设备的的service id，取值参见Profile定义。
        "sid1":{
            "characteristicName1": "value1",
            "characteristicName2": "value2"
        },
    }
    );
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.setLongPressDeviceInfo(**"0"** , json_body, 'resultCallback','isLongPressInProgress');

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 命令下发成功。 | -  
12 | 请求参数校验失败。 | 确认请求参数合法。
