# 跳转到对应的页面

#### 适用平台

Android、iOS

  * Android：支持跳转到固件升级页面、以及设置页面功能。
  * iOS：仅支持跳转到固件升级页面功能，不支持跳转到设置页面功能。



#### 接口描述

hilink.jumpTo (String uri, String resultCallback)

根据对应的URI，跳转到对应的界面。例如：

  * 当跳转到固件升级页面时，uri固定传入值为“com.huawei.smarthome.deviceBleUpgradeActivity”。
  * 当跳转到设置页面时，uri固定传入值为“com.huawei.smarthome.deviceSettingActivity”。iOS平台暂不支持该功能，后续版本会优化。



#### 请求参数

参数 | 类型 | 描述  
---|---|---  
uri | String | 传入对应的字符串  
resultCallback | String | 回调函数的方法名
