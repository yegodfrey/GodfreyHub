# 公共工具

#### 导入模块
    
    
    import BasicLib from '@huawei/h5pro-basic-lib'

#### BasicLib.util.deviceInfo

deviceInfo(): Object

获取应用显示信息。

  * 返回值： 

类型 | 说明  
---|---  
Object | 应用显示信息。  
  
    * Object 

参数名 | 类型 | 描述  
---|---|---  
bottomLayout | Number | 底部留白高度。  
topLayout | Number | 顶部留白高度。指手机状态栏高度。  
isDarkTheme | Boolean | 是否为深色模式。返回true表示为深色模式，返回false表示为非深色模式。  
  



#### BasicLib.util.getNetworkStatus

getNetworkStatus(): Object

获取网络状态。

  * 返回值： 

类型 | 说明  
---|---  
Object | 网络信息。  
  
    * Object 

名称 | 类型 | 描述  
---|---|---  
type | String | 连接的网络类型。
      * unConnected：表示未连接网络。
      * wifi：表示网络类型为WLAN。
      * mobile：表示网络类型为手机移动网络。  
metered | Number | 表示是否计量。
      * 0：表示未知类型。
      * 1：表示计量类型。
      * 2：表示非计量类型。
