# 注册GATT回调函数

int BleGattsRegisterCallbacks(BtGattServerCallbacks *func)

SDK通过调用此接口注册GATT的事件回调函数，当有对应GATT事件时，需要调用回调函数通知SDK，当前仅使用connectServerCb、disconnectServerCb、serviceStartCb、serviceStopCb、indicationSentCb以及mtuChangeCb。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
func | BtGattServerCallbacks * | 输入 | GATT事件回调函数结构体。  
  
**函数返回值** | **描述**  
---|---  
0 | 注册GATT事件回调函数成功。  
其他值 | 注册GATT事件回调函数失败。
