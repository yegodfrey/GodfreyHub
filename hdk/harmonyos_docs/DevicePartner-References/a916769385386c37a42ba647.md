# 获取升级区间长度  
  
unsigned int HILINK_OtaAdapterFlashMaxSize(void);

SDK在进行固件写入前调用此函数获取升级区间的最大空间，**当空间小于固件大小时，将会升级失败** 。开发者需保证实际分区空间能容纳固件。

**函数返回值** | **描述**  
---|---  
分区实际大小 | 要升级分区的最大flash空间。
