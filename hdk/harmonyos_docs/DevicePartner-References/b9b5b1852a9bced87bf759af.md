# 修改设备名称  
  
#### 接口描述

hilink.modifyDeviceName(String deviceName, String resultCallback)

在设备设置页面，修改设备名称。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceName | String | 是 | 修改的设备名称。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var deviceName= "xxx";
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.modifyDeviceName(deviceName, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
-2 | 请求超时。iOS无该错误码。 | -  
3 | 网络错误。iOS无该错误码。 | 请检查网络。  
12 | 请求参数校验失败。Android无该错误码。 | 请检查请求参数。
