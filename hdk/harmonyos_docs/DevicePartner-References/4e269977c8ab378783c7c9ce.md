# 设备控制

SDK 提供了手机控制设备时控制命令的下发通道。开发者需在设备侧挂载控制命令回调函数，以接收控制指令并执行相应的控制动作。

设备侧要能接收自定义指令，需在启动 SDK 时，于入参 BLE_CfgNetCb 结构体中挂载 rcvCustomDataCb 的回调函数。当手机侧下发控制指令时，SDK 将通过此回调函数传递下发的自定义命令。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/7JjdJa4LSmO0ii1-vpEuQg/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090911Z&HW-CC-Expire=86400&HW-CC-Sign=9928F1ECF7E11215EDE5BBE312CF7C67920D08EBCFDC6593B896BE83CBC5DAD5)

  1. SDK 仅提供设备控制下发的通道。控制下发完毕后，回调函数的返回值将直接反馈至手机端。
  2. 由开发者自定义设备物模型，制定每个控制指令数据以及返回值含义。
  3. 一般数据以json格式传输，如{"sid":"switch","data":{"on":1}}，其中sid对应指令，data为指令携带的数据。



设备侧挂载回调函数demo如下：
    
    
    /* 自定义指令处理函数 */
    int ble_rcv_custom_data(unsigned char *buff, unsigned int bufLen)
    {
        // 处理收到的数据，数据一般为json格式如：
        // {"sid":"switch","data":{"on":1}}
        (void)buff;
        return 0;
    
    }
    
    static BLE_ConfPara isblepair =
    {
        .isBlePair = 1,
    };
    
    static BLE_InitPara ble_init_param = 
    {
        .confPara = &isblepair,
        .advInfo  = NULL,
        .gattList = NULL,
    };
    
    static BLE_CfgNetCb ble_cfg_net_cb = 
    {
        // 将指令处理函数挂载到SDK中
        .rcvCustomDataCb = ble_rcv_custom_data,
    };
    
    BLE_CfgNetInit(&ble_init_param, &ble_cfg_net_cb);
