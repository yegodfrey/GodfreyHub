# 修改设备消息推送状态  
  
#### 接口描述

setNotification

设置插件设备的push消息开关的状态

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：setNotification  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
enable | string | 是否开启告警消息推送：1为开启，0为关闭  
pushStatus | number | 分类告警推送，不传该参数，则不走分类告警，所有的告警通过上面enable字段控制，全部开启或者全部关闭。PluginConfig.json需要配置pushIndex才支持分类告警。取值方式：每一条pushIndex的值对应二进制的位数，二进制每一位的值0表示关闭告警，1表示开启告警。pushIndex的值从1开始，二进制的第0位表示总开关。当前只支持网络摄像头和智能门铃  
  
#### 回调

code等于1000时，data返回告警的设置状态列表

参数 | 类型 | 描述  
---|---|---  
name | string | 创建的告警规则name，通过PluginConfig.json里面的path+deviceId拼接  
status | string | 告警规则是否激活，active：激活，inactive：未激活  
result | boolean | 设置告警规则是否成功，只有返回true，上面的status才算实际值，返回false，status都是inactive  
  
返回data字符串转json后，示例：
    
    
    [
    {
    "name":"alarmEvent/videoAlarm4dd6b025-b7",
    "status":"active",
    "result":true
    },
    {
    "name":"alarmEvent/humanBodyAlarm4dd6b02",
    "status":"active",
    "result":true
    }
    ]
