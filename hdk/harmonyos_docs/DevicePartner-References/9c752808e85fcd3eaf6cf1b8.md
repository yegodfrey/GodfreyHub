# 概述  
  
智慧生活App提供JSAPI，用于在App的H5界面连接和控制蓝牙设备。

#### 接口定义规则

  1. API参数定义遵循如下风格：0个或多个简单数据类型参数，用于输入；0或1个回调函数，用于返回执行结果。例如：
         
         // JSAPI样例
         hilink.jsApiSample(
         “deviceName”,	// String, 设备名称
         sid, // Number, Service Id
         true, // Boolean, 设备状态
         body, // String, json格式内容
         “jsApiSampleCallback” // String，回调函数名称，该名称需与开发者实际定义的回调函数名保持一致
         );
         
         // 回调函数样例
         function jsApiSampleCallback(resultStr) {
         console.log(resultStr);
         }



  2. 回调函数只有一个String类型入参，对于下述接口中定义的回调参数，通过Json字符串方式进行传参。
  3. 接口中涉及二进制数据，使用底层十六进制字符串方式通知JS，例如：
         
         // 二进制数据(OS)与十六进制字符串（JS）转换
         // ‘A’的ASCII码16进制值为41，使用2位十六进制数表达一个字节，没有前导0x，数字间没有空格
         1,9,"A",0, 10 <-> "010941000A"
