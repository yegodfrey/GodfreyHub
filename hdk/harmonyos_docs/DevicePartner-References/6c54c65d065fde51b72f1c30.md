# 设置广播mpp字段

int BLE_SetAdvNameMpp(const unsigned char *mpp, unsigned int len)

开发者调用此接口设置广播中mpp字段以接入网关。此字段设置后，m字段当前使用2个比特位，其他比特位暂未使用。当设备不需要接入网关时，开发者可不设置此字段，不影响SDK其他功能。

  1. m: 1个字节：0x00---0xFF，可选，如果发送该参数，则pp为必传，如果设备侧不携带mpp字段，则网关默认不回连该BLE设备。

bit0: 0心跳广播报文；1设备主动回连请求广播报文（比如设备有数据上报需要连接网关）。

bit1: 心跳时长间隔单位，0单位毫秒，1 单位为秒。

  2. pp: 采用小端格式传输，2个字节 unsigned int 类型参数，16进制。标识设备心跳间隔时长,例如5000ms。
  3. len: 长度固定为3个字节。



示例：
    
    
        /* 设备按需设置，例如接入蓝牙网关时，设置广播类型标志及心跳间隔 */
        unsigned char mpp[] = {0x02, 0x3c, 0x00};
        int ret = BLE_SetAdvNameMpp(mpp, sizeof(mpp));
        if (ret != 0) {
            printf("set adv name mpp failed\r\n");
            return -1;
        }

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
mpp | const unsigned char * | 输入 | 设置蓝牙广播名称中的MPP字段，用于网关回连参考"BLE设备接入规范"文档中蓝牙设备名称描述，按需设置。  
len | unsigned int | 输入 | mpp对应的字节数。  
  
**函数返回值** | **描述**  
---|---  
0 | 参数配置成功。  
其他值 | 参数配置失败。
