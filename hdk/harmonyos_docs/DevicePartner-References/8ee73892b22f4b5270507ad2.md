# 获取或者修改蓝牙设备属性

#### 接口描述

modifyBleDeviceProperty

修改蓝牙设备属性

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：disconnectBle  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
bleMac | string | 设备blemac地址，为空时，使用设备注册时的bleMac  
serviceType | string | 服务类型，值为"sts"时，且传参bleMac不为空时，使用传过来的参数bleMac  
serviceName | string | 蓝牙服务名称，可不传  
data | string | 下发命令数据,JSON格式，最后转化成String，此数据是透传给设备端，具体数据内容需要和设备端协商好， 最好是按照设备profile规范来  
  
#### 回调

透传，和设备协商内容

#### 错误码

code | 描述  
---|---  
-1004 | 调用失败  
-1007 | 参数不正确，deviceId为空。或者调用失败
