# 下发命令到设备（支持LUA脚本）  
  
#### 接口描述

hilink.setDeviceInfoWithProdId(String devId, String json_body, String resultCallback)

下发命令给设备，以实现对设备状态的控制，适用于支持LUA脚本的设备。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
json_body | String | 是 | 传入需要设置的sid（支持多个sid）、characteristicName以及相应的取值。取值详见Device Partner平台的Profile中的定义。 json_body不能为空，否则将导致失败。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var json_body = JSON.stringify({
      sid1: {on1: 1, action1: 1},
      sid2: {on2: 1, action2: 1}}
    );
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.setDeviceInfoWithProdId("0", **sid** , json_body, 'resultCallback');

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 命令下发成功。 | -  
12 | 请求参数校验失败。 | 确认请求参数合法。
