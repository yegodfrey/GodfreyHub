# 设备状态变化  
  
以下接口都会走这个接口通知给插件：删除共享设备，修改设备名称，修改设备房间位置、华为账号退出、有新的固件版本更新

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为： deviceDataChanged  
deviceDataType | string | 是 | 设备数据改变的类型，华为账号退出：huaweiAccountLogout，当前仅网络摄像头使用。 删除共享设备：deviceDeleted，仅预留 设备名称更新：deviceNameUpdated，仅预留。 设备房间位置改变：deviceMoved，仅预留。 检测到新的固件版本：newFirmwareEvent，仅预留。  
deviceId | string | 否 | 华为设备id，仅删除共享设备时必传  
sn | string | 否 | 设备序列号，仅删除共享设备时必传  
productId | string | 否 | dp平台创建的产品类型，仅删除共享设备时必传  
mac | string | 否 | mac地址，仅删除共享设备时必传  
role | string | 否 | 用户角色，值：owner值family，仅删除共享设备时必传
