# 查询网桥子设备列表  
  
#### 接口描述

hilink.getBridgeSubclassRegisteredDevices (String callback);

查询网桥子设备列表。例如，查询网关下挂的所有子设备。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getBridgeSubclassRegisteredDevices(callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 多个子设备信息的json字符串。  
  
#### 响应示例

返回包含多个子设备信息的json字符串。

#### 错误码

无
