# 下载新固件  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.downloadHotaFile(String url, String fileName, String callback)

下载新的固件包，返回固件包存到数据库中的key值，H5页面需要再调用hilink.getStorageSync(key)接口分别去取固件中的数据再传递给设备，进行固件升级。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
url | String | 固件的下载地址  
fileName | String | 固件包名称  
callback | String | 回调函数的方法名  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
XXXX.json | String | 固件的json描述（部分设备有）  
XXXX.bin | String | 固件升级的bin文件  
XXXX.dat | String | 固件升级的dat文件（部分设备有）
