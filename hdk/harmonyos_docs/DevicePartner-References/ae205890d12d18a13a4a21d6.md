# 网桥跳转到子设备页面

#### 接口描述

hilink.jumpToH5Device (int listCount, String resultCallback)

网桥设备跳转至子设备页面。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
listCount | int | 是 | getBridgeSubclassRegisteredDevices中查询的设备编号  
resultCallback | String | 是 | 结果回调方法名  
  
#### 请求示例
    
    
    hilink.jumpToH5Device(101, "resultCallback");

#### 响应参数

无
