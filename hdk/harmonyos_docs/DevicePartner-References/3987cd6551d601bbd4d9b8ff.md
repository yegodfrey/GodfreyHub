# 获取设备发射功率强度  
  
int HILINK_BT_GetDevSurfacePower(char *power);

SDK使用HILINK_BT_GetDevSurfacePower接口，获取设备表面的最强点信号强度，用于填充广播数据，单位dbm。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
power | char * | 输出 | 存放信号值的缓冲区地址，长度仅为1字节。如果无特殊用途，使用0xF8填充即可。  
  
**函数返回值** | **描述**  
---|---  
0 | 获取子型号成功。  
其他值 | 获取信号值失败，SDK将退出运行。  
  
实现实例如下：
    
    
    #define ADV_TX_POWER 0xF8
    
    int HILINK_BT_GetDevSurfacePower(char *power)
    {
        if (power == NULL) {
            return -1;
        }
        *power = ADV_TX_POWER;
        return 0;
    }
