# Bi打点  
  
#### 接口描述

onCustomEvent

Bi打点接口，用于问题定位、功能使用频次统计等

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：onCustomEvent  
biReportId | string | 微信小程序id  
data | string | Json格式的字符串，打点的具体内容，不能包含用户个人信息。
