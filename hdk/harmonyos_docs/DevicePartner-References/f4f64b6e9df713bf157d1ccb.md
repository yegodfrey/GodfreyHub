# 初始化协议栈  
  
int InitBtStack(void);

SDK运行初始化时调用，在此函数中实现初始化蓝牙协议栈的内容，为后续创建GATT服务、开关ble广播以及收发数据做准备。

**函数返回值** | **描述**  
---|---  
0 | 蓝牙协议栈初始化成功。  
其他值 | 蓝牙协议栈初始化失败。
