# 通知智慧生活检查固件更新  
  
#### 接口描述

notifyHostCheckNewFirmware

通知智慧生活检查固件更新

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：notifyHostCheckNewFirmware  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
  
#### 误码

code | 描述  
---|---  
-1005 | 下发控制命令失败，可能的原因：设备离线
