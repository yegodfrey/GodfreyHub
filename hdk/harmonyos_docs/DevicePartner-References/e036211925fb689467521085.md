# 断开蓝牙  
  
#### 接口描述

disconnectBle

断开蓝牙

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：disconnectBle  
bleMac | string | 设备blemac地址  
  
#### 回调

断开蓝牙成功不会回调

#### 错误码

code | 描述  
---|---  
0 | 成功  
-1111 | 断开蓝牙异常
