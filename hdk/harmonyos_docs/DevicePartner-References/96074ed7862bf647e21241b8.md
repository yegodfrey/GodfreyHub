# indication发送回调  
  
typedef void (*IndicationSentCallback)(int connId, int status)

当SDK调用BleGattsSendIndication接口以indication的方式发送数据后，收到对端设备返回的答复之后，需要调用此回调通知SDK数据发送结果。SDK当前只接收结果，不做其他处理。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
connId | int | 输入 | 蓝牙连接的ID。  
status | int | 输入 | 发送蓝牙数据包状态。status为0时，表示发送数据成功。  
srvcHandle | int * | 输入 | 创建的GATT服务句柄。
