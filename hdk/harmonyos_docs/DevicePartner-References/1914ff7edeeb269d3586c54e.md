# 是否EMUI10系统

#### 适用平台

Android

#### 接口描述

hilink.isEmuiTen()

判断当前手机EMUI系统是否是EMUI10。EMUI10可能无法连接蓝牙，如果EMUI10，建议在蓝牙设备页面重启蓝牙后重新连接。

#### 返回参数

true表示是，false表示不是。
