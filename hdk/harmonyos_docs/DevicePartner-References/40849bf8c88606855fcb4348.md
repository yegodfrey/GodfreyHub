# 设置设备名称  
  
int SetDeviceName(const char *name, unsigned int len)

SDK通过调用此接口设置设备名称，设备名称来源于HILINK_BT_GetDevInfo接口中获取的devName字段，如果此字段为空，则使用默认名称HiLinkBT。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
name | char * | 输入 | 设备名称的字符串指针。  
len | unsigned int | 输入 | 设备名称字符串的长度，不包括结束符。  
  
**函数返回值** | **描述**  
---|---  
0 | 设置设备名称成功。  
其他值 | 设置设备名称失败。
