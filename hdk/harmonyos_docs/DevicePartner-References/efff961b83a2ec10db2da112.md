# 设备重启  
  
void HILINK_OtaAdapterRestart(int flag);

SDK在传输写入完OTA数据后需要进行重启。开发者根据传入的flag判断是否需要执行分区切换再进行重启。当flag为1时表示模组重启，需要切换分区再进行重启。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
flag | int | 输入 | 设备重启标志，当flag是1时，只有mcu升级可以立即重启；当flag是2时，模组重启，需要切换分区后再重启。
