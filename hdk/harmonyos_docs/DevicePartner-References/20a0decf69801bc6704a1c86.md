# 设置设备IO属性

int BleSetSecurityIoCap(BleIoCapMode mode)

SDK通过调用此接口设置设备蓝牙的IO能力，当前设置为OHOS_BLE_IO_CAP_NONE，让设备以justworks的方式进行连接配对。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
mode | BleIoCapMode | 输入 | 设备的IO能力模式，当前固定传入OHOS_BLE_IO_CAP_NONE。  
  
**函数返回值** | **描述**  
---|---  
0 | 设置设备IO能力成功。  
其他值 | 设置设备IO能力失败。
