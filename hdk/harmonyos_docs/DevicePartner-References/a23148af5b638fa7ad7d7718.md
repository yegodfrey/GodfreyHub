# MTU值变化回调  
  
typedef void (*MtuChangeCallback)(int connId, int mtu)

设备蓝牙连接时mtu发生变化，需要调用此回调函数通知SDK新的mtu的值。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
connId | int | 输入 | 蓝牙连接的ID。  
mtu | int | 输入 | 新的mtu值。
