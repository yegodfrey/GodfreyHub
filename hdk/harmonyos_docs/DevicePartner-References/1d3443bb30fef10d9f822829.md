# 判断（折叠屏手机）屏幕是否展开

#### 适用平台

Android

#### 请求消息

用于判断（折叠屏手机）屏幕是否展开，WEB中调用js方法如下：
    
    
    hilink.isScreenSpreaded();

#### 响应消息

该接口将直接返回true:展开， false:未展开
