# 查询本地缓存数据  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.getStorageSync(KEY)

从本地缓存中同步查询指定 key 对应的内容。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
KEY | String | 本地缓存中的指定的 key  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
data | String | 返回key对应的缓存数据，如果返回数据为对象，则16进制字符串。如果发生异常，返回null
