# 华为安全函数适配层

SDK使用了华为安全库函数，三方厂商需要将以下头文件添加进编译脚本中：

**头文件** | **OpenHarmony路径**  
---|---  
securec.h | third_party/bounds_checking_function/include  
  
对于非OpenHarmony设备，推荐通过开源方式获取安全函数库引入编译，OpenHarmony社区安全函数仓链接：<https://gitee.com/openharmony/third_party_bounds_checking_function>
