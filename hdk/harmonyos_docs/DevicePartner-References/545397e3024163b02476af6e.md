# 去使能协议栈

int DisableBtStack(void);

SDK在退出运行或者去初始化时调用，用于去使能协议栈，作用与EnableBtStack相反。

**函数返回值** | **描述**  
---|---  
0 | 蓝牙协议栈使能成功。  
其他值 | 蓝牙协议栈使能失败。
