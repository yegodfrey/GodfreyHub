# 查询已注册设备  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.getCurrentRegisteredDevice(CallbackName)

查询宫格页面中选择的已注册的设备。此接口用户完成设备注册后，从宫格拉起设备H5后，H5页面中调用。如果errCode不为0，则hilinkDevId，deviceId，deviceName无效。

#### 返回参数

**表1** 参数说明参数 | 类型 | 描述  
---|---|---  
hilinkDevId | String | 云端分配的设备唯一标示（设备ID）。  
deviceId | String | 用于区分设备的ID。  
deviceName | String | 设备名称。  
errCode | Number | 错误码：0, 90001, 90005。 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。  
role | String | 用户角色：owner/family。  
hilinkDeviceEntity | Object | 设备信息。

  * Android平台：参数详见表2。
  * iOS平台：参数详见表3。

  
  
**表2** hilinkDeviceEntity对象参数说明（Android）参数 | 类型 | 描述  
---|---|---  
devId | String | 设备ID。  
devInfo | Object | 设备详细信息。对象中的参数包括：

  * model：String，设备型号。
  * devType：String，设备类型。
  * manu：String，制造商ID。
  * prodId：String，产品ID。
  * subProdId：String，产品子型号。
  * sn：String，设备的序列号，用于唯一标识该设备，可以根据MAC地址或者IMEI号等信息来设置。SN只用于对初次发现的设备进行唯一标识，一旦注册从云端分配到devId后，便通过devId来访问该设备。
  * mac：String，MAC地址，格式为“XX:XX:XX:XX:XX:XX”，统一为大写。
  * bleMac：Srting，蓝牙BLE MAC地址。
  * brMac：Srting，蓝牙BR MAC地址。
  * fwv：String，固件版本（Firmware Version）。
  * hwv：String，硬件版本（Hardware Version）。
  * swv：String，软件版本（Software Version）。
  * protTypeString，协议类型。取值范围如下：
    * 1: Wi-Fi。
    * 2: Z-Wave。
    * 3: ZigBee。
    * 4: BLE。
    * 5: PLC。
  * setupType：String，设置设备信息。

  
devIds | List | 子产品ID。  
operations | Integer | 用户对device的操作权限，取值范围如下：READ、WRITE、EXECUTE。  
role | String | 用户角色，取值范围如下：owner、family。  
homeId | String | 家庭ID。  
homeName | String | 家庭名称。  
services | List | 设备的服务能力信息。  
nodeType | String | 节点类型，取值范围如下：

  * ENDPOINT：通过网关接入的设备。
  * GATEWAY：网关。
  * GROUP：设备组。

  
gatewayId | String | 设备所处Gateway的ID。  
roomId | Long | 房间ID。  
roomName | String | 房间名称。  
devName | String | 设备名称。  
status | String | 设备状态。  
thirdPartyId | String | 设备第三方标识。  
resultCode | String | 返回码。  
homeType | String | 设备家庭类型。  
familyGroupIds | String | 设备所属家庭群组ID。  
registryTime | String | 设备注册时间（毫秒级时间戳）。  
operationTime | String | 设备的操作权限。  
subscribeStatus | Integer | 订阅状态。  
devTags | Map | 设备标签。  
dataSource | String | 数据来源。  
hichainEnable | String | 是否支持HiChain。  
id | String | 网关子设备信息实体设备ID  
gatewayId | String | 网关子设备信息实体网关ID。
