# 获取设备的子型号

int HILINK_GetSubProdId(char *subProdId, int len);

SDK使用HILINK_GetSubProdId接口，获取设备的子型号信息，用于填充广播数据以识别同一类型设备的不同子类型。子型号长度固定为2个字节，以'\0'结束，如果设备没有子型号，则此接口返回-1，SDK将会以默认值00填充子型号。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
subProdId | char * | 输出 | 设备子型号缓存区，开发者需要将设备子型号写入subProdId中。  
len | int | 输入 | 设备子型号缓存区长度，当前固定为3，其中包括1字节的结束符。  
  
**函数返回值** | **描述**  
---|---  
0 | 获取子型号成功。  
-1 | 获取子型号失败，将用默认的00填充子型号。
