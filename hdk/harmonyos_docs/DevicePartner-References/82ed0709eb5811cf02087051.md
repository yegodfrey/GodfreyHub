# 获取广播参数

BLE_AdvPara HILINK_BT_GetDefaultAdvParam(void)

开发者调用此接口获取SDK默认使用的广播参数。

**函数返回值** | **描述**  
---|---  
BLE_AdvPara | 返回内部使用的默认广播参数。
