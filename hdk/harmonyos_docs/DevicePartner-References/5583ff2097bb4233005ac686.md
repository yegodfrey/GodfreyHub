# 结束升级  
  
int HILINK_OtaEndProcess (int status);

SDK 在将固件写入到OTA 升级区后，且完整性校验通过后，将调用厂商适配的此接口。开发者可在此函数中实现模组升级结束时需要添加的功能，如果处理正常就返回0，处理异常请返回-1。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
status | int | 输入 | OTA流程结束时的结果。100：OTA升级完成；101：OTA升级失败；1001：固件下载失败；1002：文件校验失败；1003：写flash失败。  
  
**函数返回值** | **描述**  
---|---  
0 | 升级结束处理成功。  
其他值 | 升级结束处理失败。
