# 设备状态数据上报

#### 适用平台

Android、iOS

#### 接口描述

  * iOS平台：hilink.reportDeviceProfileImpermanency (devid, json_body, callback)
  * Android平台：hilink.newReportDeviceProfileImpermanency(devid, json_body, callback)



设备状态数据上报接口。iOS平台与Android平台的接口名称不同，但是使用规则一致。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
devid | String | 华为云分配给设备的唯一id。  
Json_body | String | Json字符串，结构看下图。  
callback | String | 回调方法。  
  
Json_body结构：

字段 | 必选/可选 | 类型 | 描述  
---|---|---|---  
ts | 可选 | String(32) | UTC时间。直连Device可选；Gateway上报时必选添加此字段，通过Gateway连接的Device通过Gateway后，Gateway也需要补充此字段。 时间格式：yyyyMMddTHHmmssZ 如： 20151212T121212Z 使用24小时制。  
sid | 必选 | String(64) | 服务的唯一标识，在该设备内唯一标识该服务  
data | 必选 | object | 服务下各属性的值，如：
    
    
    {
        "characteristicName1": "value1",
        "characteristicName2": "value2"
    }  
  
Json_body具体样式：
    
    
    {
        "status": "offline",
        "services": [
            {
                "ts": "string",
                "sid": "string",
                "data": {
                    "additionalProp1": "***",
                    "additionalProp2": "***",
                    "additionalProp3": "***"
                }
            }
        ]
    }

#### 返回参数

参数 | 类型 | 描述  
---|---|---  
errCode | Number | 错误码：

  * 200：正常。
  * 16001：profile数据类型校验失败，需要排查已上传的json数据类型是否与proflie一致。
  * 90001：参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
