# 设置广播类型  
  
void BLE_SetAdvType(int type)

开发者调用此接口设置广播类型，修改后立即生效。若启用自定义广播类型，该配置将被保存，并在下次使用SDK默认广播时生效。中途可多次设置，最终以最后一次设置的类型为准。

当前支持的广播类型包括靠近发现、蓝牙碰一碰及常态广播，开发者可根据具体场景切换广播类型。其中，靠近发现广播支持靠近发现弹出半模态配网，若注册NearbyTimeoutCb（见2.2.8），靠近发现广播到时间后切换广播类型；常态广播支持智慧生活扫描配网，不支持星闪，但有蓝牙回落。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
type | int | 输入 | 使用SDK默认广播配置时的类型，详见BLE_AdvType枚举定义：BLE_ADV_DEFAULT表示默认类型;BLE_ADV_ONEHOP表示碰一碰类型；BLE_ADV_LOCAL_NAME表示常态广播类型；BLE_ADV_NEARBY_V0表示靠近发现广播。
