# 上传设备文件

#### 接口描述

hilink.uploadObjectReq(String file, String additionInfo, String callback);

将设备文件上传到云侧。例如，智能门锁将用户头像上传到云侧。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
file | String | 是 | 上传文件的base64字符串。  
additionInfo | String | 是 | 附加信息，格式为json字符串。其中包含如下字段：

  * devId：设备ID。
  * objectName：文件名。

  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    var file = "上传文件的base64字符串"; 
    var additionInfo = "{"devId": "设备Id", "objectName": "文件名"}"; 
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){} 
    hilink.uploadObjectReq(file, additionInfo, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。  
  
#### 响应示例

  * 成功
        
        {"errcode":0}

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
