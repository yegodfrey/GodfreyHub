# 请求三方服务器  
  
#### 适用平台

Android、iOS

#### 请求消息

由于页面存在跨域，需要从三方服务器查询数据的接口供页面调用，确保页面的出口统一。
    
    
    hilink.requestThirdPartConfig(
    "json_body", // string 三方服务器完整的URL地址
    "resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
    );

json_body中列出请求所需参数，格式如下：
    
    
    {
    	"domain": "https://xxx.xxxx.com",  // 请求域名
    	"path": "/xxxxxx/xxxx.xxxx",  // 请求路径
    	"method": "GET",  // 请求方法
    	"param": {  // 请求参数
    		"xxx": "xxx",
    		"xxx": "xxx"
    	}
    }

#### 请求示例
    
    
    const jsonBody = {
    'domain': 'https://www.runoob.com',
    'path': '/try/ajax/json_demo.json',
    'method': 'GET',
    'param': {}  由于示例代码，请求的接口没有param参数，所以传入{}空对象
    };
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    window.hilink.requestThirdPartConfig((JSON.stringify(jsonBody)), 'resultCallback');

#### 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将结果返回到resultStr中。resultStr的实例如下：
    
    
    {
      三方服务器json数据格式
    }

#### 返回参数

200： success

400： Bad Request

401： auth Failed

403： forbidden

500： Internal Service Error
