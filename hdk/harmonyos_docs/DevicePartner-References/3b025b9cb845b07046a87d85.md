# 从本地查询设备状态  
  
#### 接口描述

hilink.getDevCacheAll(String devId, String json_body, String resultCallback)

从智慧生活App本地缓存中，查询当前设备的全部状态。例如，用于H5设备详情页面的设备状态查询。

此接口仅涉及本地调用，不涉及网络请求。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备，暂不支持其他取值。  
json_body | String | 否 | 取值为空，表示获取设备的全部状态。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.getDevCacheAll("0", "", 'resultCallback');

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
responseData | String | 否 | 调用成功返回的结果。
