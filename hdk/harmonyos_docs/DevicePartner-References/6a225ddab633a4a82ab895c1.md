# 设备管理

#### 导入模块
    
    
    import '@huawei/h5pro-hilink'

#### window.hilink.bindDevice

bindDevice(data: String, callbackName: String): void

将设备与运动健康App绑定。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
data | String | 设备信息数据，JSON字符串格式。  
callbackName | String | 运动健康App返回绑定结果的回调函数，该回调函数有一个参数。  
  


  * 示例：
        
        window.hilink.bindDevice(JSON.stringify({
           "uuid": "", // 通过getDeviceId获取
           "measureKitId": "",  // 可选
           "deviceName": "xxx血糖仪", // 可选
           "uniqueId": "1000000",
           "sn": "xxxxxxxx"
        }),callbackName);



  * 响应： 

参数名称 | 参数类型 | 参数描述  
---|---|---  
errCode | Number | 0，表示绑定成功。 -1，表示已绑定。 其他表示绑定失败，具体错误信息参见返回码清单。  
  



#### window.hilink.unbindDevice

unbindDevice(callbackName: String): void

解除当前绑定设备。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
callbackName | String | 运动健康App返回解绑结果的回调函数。  
  
  * 响应： 

参数名称 | 参数类型 | 参数描述  
---|---|---  
errCode | Number | 0，表示设备解绑成功。 1，表示设备解绑失败。  
  



#### window.hilink.syncCloud

syncCloud(param: String): void

端云同步。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
param | String | 同步的数据类型信息，JSON对象字符串。  
callbackName | String | 回调同步的结果。  
  



  * 示例：
        
        window.hilink.syncCloud(
        JSON.stringify({
            dataType: 10001 
        }),
        callbackName);

dataType数据类型，使用[常量类型](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-data-0000001182831794#ZH-CN_TOPIC_0000001182831794__li3306220105513)，例：HealthEngine.dataType.DATA_BLOODSUGAR

此接口目前支持支血压、血糖、体温、体重的数据同步



  * 响应： 

参数名称 | 参数类型 | 参数描述  
---|---|---  
errCode | Number | 0，表示数据同步成功。 0以外表示数据同步失败，具体错误信息参见返回码清单。如果没有收到回调，则数据无变化。  
  



#### window.hilink.getDeviceId

getDeviceId(): String

获取绑定设备在平台分配的UUID。

  * 响应： 

参数名称 | 参数类型 | 参数描述  
---|---|---  
deviceId | String | 该设备在平台分配的UUID。  
  



#### window.hilink.getDeviceInfo

getDeviceInfo(callbackName: String): void

获取当前绑定设备的Mac或SN。

使用该接口需要在调用[signIn](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-account-0000001181901252#section123194615477)接口时填入读取设备信息的scopes权限。

  * 参数： 

参数名 | 类型 | 参数描述  
---|---|---  
callbackName | String | 获取设备信息回调函数名称，该回调函数有一个参数。  
  


  * 响应： 

参数名称 | 参数类型 | 参数描述  
---|---|---  
devInfo | String | JSON字符串，包含mac或sn。举例：
        
        {
            "errCode": 0,
            "devInfo": {
                "deviceName": "xxxxxxxx额温计",
                "measureKit": "00000000",
                "sn": "1234567891",
                "mac": "01:02:03:04:05:06",
                "uuid": "11111111-2222-3333-4444-555555555555",
                "prodId": "xxxx"
            }
        }

#### 返回码

返回码 | 说明  
---|---  
0 | 正常。  
2 | 参数异常。  
1001 | 隐私权限校验异常。  
90001 | 内部错误/系统错误。  
90002 | DATA数据过大或过小。  
90003 | 同帐号下，存储空间已用完。  
90004 | 系统存储空间不足。  
90008 | 输入的数据格式错误。
