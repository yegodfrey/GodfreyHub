# 获取MCU版本

int HILINK_GetMcuVersion(char *version, unsigned int inLen, unsigned int *outLen);

SDK通过调用此接口获取设备MCU的版本号，开发者需要将当前MCU版本号写入缓冲区中，写入成功后修改outLen传递版本号真实长度，并返回0。如果设备没有MCU则直接返回-1。其他错误情况返回其他值。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
version | char * | 输出 | 版本号存储缓冲区。  
inLen | unsigned int | 输入 | version缓冲区长度，最长为64字节（包括结束符）。  
outLen | unsigned int * | 输出 | MCU版本号的存储缓冲区，需写入版本号实际长度（含结束符，不超过63）。  
  
**函数返回值** | **描述**  
---|---  
0 | 有MCU，且版本号获取成功。  
-1 | 当前没有MCU，不需要获取版本号。  
其他值 | 有MCU但获取版本号失败。
