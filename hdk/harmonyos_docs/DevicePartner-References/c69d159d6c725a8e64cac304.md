# 获取设备消息推送状态

#### 接口描述

getNotification

获取插件设备的push消息开关的状态

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：getNotification  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
  
#### 回调

code等于1000时，data返回告警的设置状态列表

参数 | 类型 | 描述  
---|---|---  
name | string | 创建的告警规则name，通过PluginConfig.json里面的path+deviceId拼接  
status | string | 告警规则是否激活，active：激活，inactive：未激活  
result | boolean | 设置告警规则是否成功，只有返回true，上面的status才算实际值，返回false，status都是inactive
