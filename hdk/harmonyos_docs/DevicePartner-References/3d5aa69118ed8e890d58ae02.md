# 发现蓝牙服务  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.onBLEServicesDiscovered(CallbackName)

蓝牙设备建立连接后，开始发现设备支持的服务，当服务发现完成，调用本接口通知上层。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/JN8LJq7eT3275ereuEU2lA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090911Z&HW-CC-Expire=86400&HW-CC-Sign=DBEE0E00466FB94B423EAF84D46A22338395085DCFCEF640EC30A85A0A70F7E7)

该方法可多次注册不同名称回调函数，已注册的全部回调函数，会在hilink.closeBLEConnection调用前生效。hilink.closeBLEConnection后，会清除回调注册。

#### 返回参数

参数 | 类型 | 描述  
---|---|---  
errCode | Number | 0，表示发现了BLE服务。
