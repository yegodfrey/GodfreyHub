# 下发命令到设备  
  
#### 接口描述

sendCommand

根据deviceId和serviceId下发设备控制命令

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
payload | string | 是 | 修改serviceId属性携带的参数  
  
其中：

payload的是json字符串，示例如下：
    
    
    {
    "deviceId": "value",
    "serviceId": "value",
    "payload":  {
    "characteristicName1": "value1",
    "characteristicName2": "value2"...
    }
    }
    例子：
    {
    "deviceId": "123**",
    "serviceId": "switch",
    "payload":  {
    "on": "1"
    }
    }
