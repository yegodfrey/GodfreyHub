# 查询用户列表  
  
#### 接口描述

hilink.getUserList(String devId, String callback);

查询设备的用户列表。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 设备ID。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    var devId = "设备ID";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){} 
    hilink.getUserList(devId, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
userInfo | string | 是 | 请求成功，返回用户信息的json字符串。  
errcode | int | 是 | 错误码。  
  
#### 响应示例

  * 成功
        
        [
          {
            "userId": "用户id",
            "name": "昵称",
            "type": "种类",
            "label": "标签",
            "deviceid": "设备id"
          }
        ]

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
