# 跳转到设备离线帮助页面（自定义离线帮助信息）

#### 接口描述

hilink.jumpToSelfOfflineHelpActivity(String deviceId, String message, String resultCallback)

跳转设备自定义离线帮助页面。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 跳转的设备ID  
message | String | 是 | 厂家自定义的离线帮助信息  
resultCallback | String | 是 | 结果回调方法名  
  
#### 请求示例
    
    
    hilink.jumpToSelfOfflineHelpActivity ("deviceId", "message"，"resultCallback");

#### 响应参数

无
