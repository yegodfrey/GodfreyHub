# 查询系统的功能的设备标识  
  
#### 适用平台

Android、iOS，平台差异如下：

  * Android平台：入参不需要resultCallback回调，本节以Android平台为例进行介绍。
  * iOS平台：入参需要resultCallback回调，调用方式为：
        
        hilink.getHmsCapabilityTypeId(int type, String resultCallback)




#### 接口描述

hilink.getHmsCapabilityTypeId(type)

查询系统的功能的设备标识。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
type | Int | 01-Huawei Share设备标识 02-保留，支持扩展  
  
#### 返回参数

查询成功后返回对应的十六进制字符串。如果查询失败，返回空字符串。

标识类型(4Bit) | 长度(1BYTE) | 标识数据(DATA)  
---|---|---  
01 | 标识数据的长度 | Huawei Share设备标识数据  
02 | 标识数据的长度 | Reserved（保留）
