# 删除扩展数据  
  
#### 接口描述

hilink.deleteDeviceExtendData(String type, String resultCallback)

从云侧删除前端自定义的扩展数据。

#### 适用平台

Android、iOS

#### 接口约束

已通过线下方式申请云侧扩展数据权限。目前已不支持新增申请该权限。

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
type | String | 是 | 扩展属性的类型，即云侧配置的权限。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var type = "xxx";
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.deleteDeviceExtendData( type, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
12 | 请求参数校验失败。Android无该错误码。 | 请检查请求参数。  
-1 | devId或type取值为空。iOS无该错误码。 | 请检查请求参数。  
-3 | 组网类型不存在。iOS无该错误码。 | -
