# 设置启用指示或者通知  
  
#### 适用平台

Android

#### 接口描述

hilink.setEnableIndication (boolean isEnableIndication)

设置启用指示还是启用通知。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/83/v3/sFYnUka-RG2BZbUpg2MsaA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090913Z&HW-CC-Expire=86400&HW-CC-Sign=CE822975861C99C7813450C1F4CDC00DA348C8F178CB8D7CE5CFC21C4E7734FE)

该方法需要和notifyBLECharacteristicValueChange配合使用，在notifyBLECharacteristicValueChange前调用。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
isEnableIndication | boolean | true：启用指示。 false：不启用指示，启用通知。默认是false。
