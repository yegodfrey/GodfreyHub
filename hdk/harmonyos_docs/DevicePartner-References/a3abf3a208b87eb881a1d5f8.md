# 删除当前设备  
  
#### 接口描述

hilink.deleteDevice(String isAssociate, String resultCallback)

从智慧生活APP九宫格中删除当前设备。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
isAssociate | boolean | 是 | 是否同时删除设备下挂关联设备，目前只有桥设备用到。 其他设备不涉及该参数，传"false"即可。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var isAssociate = "xxx";
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.deleteDevice(isAssociate, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 下发成功。 | -  
12 | 请求参数校验失败。Android无该错误码。 | 检查请求参数。  
-1 | 设备不存在。 | iOS无该错误码。  
-3 | 组网类型不存在。 | iOS无该错误码。
