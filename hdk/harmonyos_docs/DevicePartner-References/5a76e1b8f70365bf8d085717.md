# 查询设备的Profile信息  
  
#### 接口描述

hilink.getDeviceProfile(String callback);

查询设备的profile信息。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getDeviceProfile(callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 设备profile的json字符串。
