# 获取设备ssid和密码  
  
#### 接口描述

getDeviceSsidAndPassword

获取设备ssid和密码，目前该接口只支持盯盯拍行车记录仪

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getDeviceSsidAndPassword  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
  
#### 回调

code等于1000时，data返回告警的设置状态列表

参数 | 类型 | 描述  
---|---|---  
ssid | string | wifi的ssid  
password | string | password  
  
返回data字符串转json后，示例：
    
    
    {
    "ssid": "xxx",
    "password": "xxx"
    }

#### 错误码

-1013 | 发生异常
