# 启动BLE广播

int BleStartAdvEx(int *advId, const StartAdvRawData rawData, BleAdvParams advParam)

SDK通过调用此接口传递广播参数及数据启动设备的ble广播，广播发送结果需要调用GAP事件回调中的advEnableCb函数，通知SDK广播开启结果。如果开启失败，SDK会进行重新调用此接口尝试发送广播，连续失败次数超过三次，SDK会出错退出运行。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
advId | int * | 输出 | 发起的ble广播id，默认传出0即可。  
rawData | StartAdvRawData | 输入 | 广播的数据以及扫描响应数据。  
advParam | BleAdvParams | 输入 | 广播的相关参数，如发送间隔等  
  
**函数返回值** | **描述**  
---|---  
0 | 发送广播成功。  
其他值 | 发送广播失败。
