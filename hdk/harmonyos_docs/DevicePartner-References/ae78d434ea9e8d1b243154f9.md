# 设备蓝牙连接回调

typedef void (*ConnectServerCallback)(int connId, int serverId, const BdAddr *bdAddr)

当有别的设备连接设备蓝牙时，通过此回调通知SDK连接状态以及连接对端的addr相关信息。在此回调函数中，会调用会调用BleGattsSetEncryption来设置安全连接加密等级。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
connId | int | 输入 | 本次连接的ID。  
serverId | int | 输入 | 本次连接的serverId。  
bdAddr | BdAddr * | 输入 | 本次连接的对端设备地址。  
  
调用方式如下：
    
    
    /* isBond参数为BLE_CfgNetInit中入参isPair字段 */
        BleSecAct secAct = (isBond == true) ? OHOS_BLE_SEC_ENCRYPT : OHOS_BLE_SEC_NONE;
        if (BleGattsSetEncryption(*bdAddr, secAct) != 0) {
            printf("set encryption failed\r\n");
            return;
        }
