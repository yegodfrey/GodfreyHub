# 查询设备为触发条件的智能场景数量

#### 接口描述

hilink. getAutoRuleSize(String resultCallback)

查询以当前设备为触发条件的智能场景数量。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
resultCallback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    // web页面中需实现该函数，用来获取执行结果
    function callback(result){
    }
    hilink.getAutoRuleSize(callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 场景数量。  
  
#### 响应示例

返回查询的场景数量：
    
    
    "5"

#### 错误码

无
