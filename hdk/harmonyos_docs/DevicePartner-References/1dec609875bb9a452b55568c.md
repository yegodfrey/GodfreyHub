# 与设备建立配对

#### 适用平台

Android、iOS，平台差异如下：

  * Android平台：入参不需要resultCallback回调，本节以Android平台为例进行介绍。
  * iOS平台：入参需要传递resultCallback回调，调用方式如下：
        
        hilink.createDeviceBond (String deviceId, String productId, String resultCallback)




#### 接口描述

hilink.createDeviceBond (deviceId, productId)

智慧生活App与蓝牙设备进行配对。App会根据产品id查询设备名单中对应的netConfigType属性，如果该属性中含有leBond字段，则该接口会通过ble协议进行配对，否则将进行br配对。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 蓝牙设备Id  
productId | String | 设备产品id  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
retCode | Number | 错误码：0, 90001, 90009 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
