# 取消蓝牙订阅  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.unSubscribeBleEvent(String deviceId, String bleMac, final String resultCallback)

应用取消蓝牙事件订阅，适用于设备侧集成华为蓝牙SDK或适配华为蓝牙应用层开放协议规范的设备。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 被连接设备的ID，由华为家居云分配。  
bleMac | String | 被连接设备的BLE MAC地址。  
resultCallback | String | JS回调。  
  
#### 返回参数

  * 取消成功
        
        {"errcode":0}

  * 取消失败
        
        {"errcode":-1}
