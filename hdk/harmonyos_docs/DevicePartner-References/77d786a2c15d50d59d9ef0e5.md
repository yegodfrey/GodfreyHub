# 打印日志

getPrintLog

打印hilog日志并将日志保存到智慧生活自己写的日志文件里面，现网用户hilog不会打印info级别，并且打印的日志每分钟有条数限制，所以智慧生活自己写了一个日志文件。用户在智慧生活-我的-帮助与反馈里面提交日志，即可获取到插件写的日志。请注意打印日志不能打印敏感信息，例如：账号、密码、鉴权凭据、用户个人信息等敏感数据。

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getPrintLog  
moduleName | string | 是 | 插件唯一标识  
level | number | 是 | 日志等级，hilog.LogLevel  
tag | string | 是 | 日志TAG  
format | string | 是 | 日志内容，不支持自动格式化，纯字符串。
