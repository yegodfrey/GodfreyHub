# 安全请求回调  
  
typedef void (*SecurityRespondCallback)(const BdAddr *bdAddr)

蓝牙连接配对时，安全请求回调函数。开发者调用此接口时，SDK会调用BleGattSecurityRsp函数统一对端的连接配对请求。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
bdAddr | const BdAddr * | 输入 | 对端蓝牙信息。  
  
调用方式如下：
    
    
    /* 授予安全请求访问权限 */
        if (BleGattSecurityRsp(*bdAddr, true) != 0) {
            hilink_error("gap security rsp\r\n");
        }
