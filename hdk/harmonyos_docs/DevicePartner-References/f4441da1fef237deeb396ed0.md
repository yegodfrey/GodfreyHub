# 设备一键注册  
  
#### 接口描述

  * Android平台：hilink.registerInfraredHubDevice(String json_body, String resultCallback)
  * iOS平台： hilink.regiterInfraredHubDevice(String json_body, String resultCallback)



通过智慧生活App代理将设备注册到云侧。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
json_body | String | 否 | 在json_body中使用对象形式传入设备信息。例如： JSON.stringify({"devInfo": {"xxx": "xxx"}})。  
resultCallback | String | 是 | JS回调。  
  
json_body中的设备信息参数如下表。

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
sn | String | 是 | String，设备的序列号，用于唯一标识该设备，可以根据MAC地址或者IMEI号等信息来设置。SN只用于对初次发现的设备进行唯一标识，一旦注册从云端分配到devId后，便通过devId来访问该设备。  
model | String | 是 | 设备分类。  
devType | String | 是 | 设备类型。  
manu | String | 是 | 制造商ID。  
prodId | String | 是 | 产品ID。  
hiv | String | 是 | HiLink协议版本。  
mac | String | 是 | MAC地址，格式为"XX:XX:XX:XX:XX:XX"，统一为大写。  
fwv | String | 是 | 固件版本（Firmware Version）。  
hwv | String | 是 | 硬件版本（Hardware Version）。  
swv | String | 是 | 软件版本（Software Version）。  
  
#### 请求示例
    
    
    var json_body = JSON.stringify(
    {
        "devInfo": {
            "sn": "string",
            "model": "string",
            "devType": "string",
            "manu": "string",
            "prodId": "string",
            "hiv": "string",
            "mac": "string",
            "fwv": "string",
            "hwv": "string",
            "swv": "string"
        }
    }
    );
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.registerInfraredHubDevice(json_body, "resultCallback");

#### 响应参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | String | 是 | 错误码。200表示成功，其他值表示失败，详见错误码。  
devId | String | 是 | 成功后，返回注册的devId。  
  
#### 响应示例

  * 连接成功
        
        {
          "errcode": "200",
          "devId": "string", //成功后可返回注册的devId：
        }




  * 连接失败
        
        {"errcode":12}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
12 | 回调接口为空。 | 检查回调接口。  
-1 | 数据体为空。iOS无该错误码。 | 检查请求参数。  
-3 | 组网类型不存在。iOS无该错误码。 | -
