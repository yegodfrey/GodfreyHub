# 请求三方服务器（支持自定义header）

#### 适用平台

Android、iOS

#### 接口描述

hilink.doHttpsRequest(String jsonBody, String resultCallback)

请求三方服务器（支持自定义header）

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
resultCallback | String | 是 | 回调方法。  
Json_body | String | 是 | H5回传数据。  
  
#### 参数说明
    
    
    "method":"doHttpsRequest",
    "Json_body":{
    "domain":"XXX XXX XXX",
    "path":"/Huawei/1.php", //末尾无需拼接'？'号，平台代码内部会自动拼接'？'号
    "method":"GET", //请求方式支持 GET、POST
    "header":{
             "value1":"1",
             "value1":"1",
             "value1":"1"
             },     //自定义header
    "param":{
           "contentType":"json", //Post请求时，需要添加此行，GET请求需要删除此行
           "value1":"1",
           "value1":"1"
         }
    },
    "resultCallback":"resultCallback"

#### 请求示例
    
    
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){ 
        var result = resultStr; // 请求的返回结果 
    } 
    hilink. _doHttpsRequest_ (Json_body string , resultCallback);

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。非0错误码的说明详见错误码。

  * 0：成功。
  * -1：失败。

  
responseData | String | 是 | 执行状态或失败的原因。  
  
#### 响应示例

  * 连接成功
        
        {"errcode":0,"responseData":"success"}

  * 连接失败
        
        {"errcode":-1, "responseData":"reason"}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
-1 | 连接失败 | 检查设备处在可连接状态，尝试重新连接。
