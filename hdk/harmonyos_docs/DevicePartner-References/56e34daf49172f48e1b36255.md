# 获取华为账号登录信息  
  
#### 接口描述

getHwIdInfo

获取智慧生活登录的华为账号信息

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getHwIdInfo  
needAll | string | 否 | 是否返回AT，默认：“true”（字符串）  
  
#### 回调

code为1000时，data：返回账号信息

回调参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
userId | string | 是 | 华为账号uid  
nickName | string | 是 | 昵称  
headPictureUrl | string | 是 | 用户头像  
token | string | 是 | AT，在needAll为“true”时返回
