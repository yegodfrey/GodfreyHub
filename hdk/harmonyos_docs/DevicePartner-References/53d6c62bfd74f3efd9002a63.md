# 查询设备与路由的连接关系

#### 接口描述

hilink.getHilinkConnection(String deviceId, String callback);

查询设备与路由的连接关系。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 设备ID。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    String deviceId = "设备id";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getHilinkConnection(deviceId, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 

  * true：表示设备已连接路由。
  * false：表示设备未连接路由。

  
  
#### 响应示例
    
    
    "true"

#### 错误码

无
