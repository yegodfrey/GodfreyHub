# 更新用户信息

#### 接口描述

hilink.updateUserList (String userInfo, String callback);

更新设备的用户信息，适用于智能门锁。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
userInfo | String | 是 | 用户信息。格式为json字符串。其中包含如下字段：

  * userId：用户ID。
  * name：昵称。
  * type：分类。
  * label：标签。
  * deviceid：设备ID。

  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    var userInfo = 
    [
    	{
    		"userId": "用户id",
    		"name": "昵称",
    		"type": "种类",
    		"label": "标签",
    		"deviceid": "设备id"
    	}
    ]
    ;
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.setUserList(userInfo, callback);

#### 响应参数：

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | “ok”字符串。  
  
#### 响应示例
    
    
    "ok"

#### 错误码

无
