# 订阅蓝牙事件

#### 适用平台

Android、iOS

#### 接口描述

hilink.subscribeBleEvent(String deviceId, String bleMac, final String resultCallback)

应用订阅蓝牙设备事件，适用于设备侧集成华为蓝牙SDK或适配华为蓝牙应用层开放协议规范的设备。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 被连接设备的ID，由华为家居云分配。  
bleMac | String | 被连接设备的BLE MAC地址。  
resultCallback | String | JS回调。  
  
#### 返回参数

  * 订阅成功
        
        {"errcode":0}



  * 订阅失败
        
        {"errcode":-1}



  * 订阅回调设备数据变化上报
        
        {"type":"CharacteristicChanged","content":xxxxx}

示例：
        
        {"type":"CharacteristicChanged","content":{"data":{"on":1},"sid":"lightSwitch"}}
        {"type":"CharacteristicChanged","content":{"data":{"gear":0},"sid":"gear"}}

参数释义：

参数 | 类型 | 描述  
---|---|---  
type | String | 上报事件类型，CharacteristicChanged表示profile数据变化，ConnectionStateChange表示连接状态变化。  
content | String | profile完整内容。  
data | String | characterName及对应characterValue值。  
sid | String | 发生变化或查询的sid。  
  


  * 订阅回调连接状态变化
        
        {"type":"ConnectionStateChange","newStatus":x,"oldStatus":x, "mac":"xx:xx:xx:xx:xx:xx"}

示例
        
        {"newStatus":2,"oldStatus":0,"type":"ConnectionStateChange","mac":"40:24:B2:F6:8D:4C"}

参数释义：

参数 | 类型 | 描述  
---|---|---  
newStatus | int | 变化后的BLE连接状态，0表示断开，1表示连接中，2表示已连接。  
oldStatus | int | 变化前的BLE连接状态，0表示断开，1表示连接中，2表示已连接。  
mac | String | BLE设备蓝牙MAC地址。  
type | String | ConnectionStateChange表示事件类型为连接状态发生变化。
