# 设备一键注销

#### 接口描述

hilink.deleteInfraredHubDevice(String devId, String resultCallback)

通过智慧生活App代理将设备从云侧注销。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 注销设备的deviceId。  
resultCallback | String | 是 | JS回调。  
  
#### 请求示例
    
    
    var devId = "xxx";
    // web页面中需实现该函数，用来获取执行结果 
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.deleteDeviceHistory(devId, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
12 | devId为空或回调接口不存在。 | 请检查请求参数。  
10 | 删除超时。iOS无该错误码。 | -  
14 | 网络错误。iOS无该错误码。 | 请检查网络。
