# 写入FLASH  
  
int HILINK_OtaAdapterFlashWrite(const unsigned char *buf, unsigned int bufLen);

SDK在接收到固件升级包后调用此接口写入新固件数据。开发者实现此接口时，需要维护当前已写入flash的地址，从上次写入数据末尾写入本次数据。写入成功后返回0，否则返回-1。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
buf | unsigned char * | 输入 | 指向要写入FLASH的固件数据缓冲区。  
bufLen | unsigned int | 输入 | 要写入FLASH的数据长度。  
  
**函数返回值** | **描述**  
---|---  
0 | 写入flash成功  
其他值 | 写入flash失败
