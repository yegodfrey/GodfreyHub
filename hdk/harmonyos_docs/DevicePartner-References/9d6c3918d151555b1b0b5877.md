# 控制单个规则的激活状态  
  
#### 接口描述

hilink.controlRuleActive(String ruleId, String active, String resultCallback)

控制单个规则的激活状态。创建的规则默认为“激活”状态，通过该接口可以允许用户开启/关闭某个智能场景。

#### 适用平台

Android

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
ruleId | String | 是 | 需要控制的规则的ID。  
active | String | 是 | 规则的激活状态，“active”为激活，“inactive”为未激活。  
resultCallback | String | 是 | 结果回调方法名。  
  
#### 请求示例
    
    
    String ruleId = "规则ID";
    String active = "“active”为激活，“inactive”为未激活";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.controlRuleActive(ruleId, active, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。  
  
#### 响应示例

  * 成功
        
        {"errcode": 0}

  * 失败
        
        {"errcode": -1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
10 | 请求超时。 | 请检查网络。  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
