# 从云端查询设备快照

#### 接口描述

hilink.getDevInfoAll(String deviceId, String extendData, String callback);

从云端查询设备状态，包括设备名称、设备基础信息（如SN、MAC等）以及Profile数据。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
deviceId | String | 是 | 设备ID。  
extendData | String | 是 | 扩展参数，当前传空值即可。  
Callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    String deviceId = "设备id";
    String extendData = "扩展数据";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.getDevInfoAll(deviceId, extendData, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | string | 是 | 设备信息的json字符串。  
errcode | int | 是 | 错误码。

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
-1 | 请求失败。 | -  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
