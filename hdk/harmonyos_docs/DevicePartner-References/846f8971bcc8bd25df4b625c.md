# 读取FLASH  
  
int HILINK_OtaAdapterFlashRead(unsigned int offset, unsigned char *buf, unsigned int bufLen);

SDK在写入flash数据之后，调用此接口读取已写入flash内容进行校验。开发者实现此接口时，以分区起始地址为基准，入参offset为偏移量，读取指定长度的内容写入buf中。读取成功后，返回0；读取失败时返回-1。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
offset | unsigned int | 输入 | 从分区起始地址开始，需要偏移的值，通过offset确定从哪开始读取数据。  
buf | unsigned char * | 输出 | 存放flash数据的缓冲区指针。  
bufLen | unsigned int | 输入 | 要读取flash的数据长度。  
  
**函数返回值** | **描述**  
---|---  
0 | 读取flash成功。  
其他值 | 读取flash失败。
