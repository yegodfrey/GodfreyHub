# 通知MCU固件传输状态  
  
int HILINK_NotifyOtaStatus(int flag, unsigned int len, unsigned int type)；

SDK调用厂商适配的此接口通知MCU固件传输的状态。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/qqmtoXapRcSj1DwiZhmXvw/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090918Z&HW-CC-Expire=86400&HW-CC-Sign=39AB2F076F2F060100AFDD2F0DC4DA1783A5436173CC7422CB6716DC4C0C4F9E)

  1. 当flag是STOP_SEND_DATA时，此接口需返回MCU侧固件升级的结果；当flag是其它值时，需返回接口接收到此消息后的处理结果。
  2. 如果用户打开了自动升级开关，检测到有新版本并且是可以重启的情况下，就进行新版本的下载，下载完成后自动重启。
  3. 自动升级流程可能在凌晨进行，因此厂商在实现升级流程相关功能时，确保在升级的下载安装固件和重启设备时避免对用户产生影响，比如发出声音，光亮等。



**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
flag | int | 输入 | 升级流程标志START_SEND_DATA：模组即将开始发送MCU固件数据包STOP_SEND_DATA：模组完整的MCU固件包已发送完成SEND_DATA_ERROR：模组本次MCU固件升级异常终止。  
len | unsigned int | 输入 | MCU固件包的大小。  
type | unsigned int | 输入 | type表示升级类型UPDATE_TYPE_MANUAL：升级流程是由用户主动发起的手动升级；UPDATE_TYPE_AUTO：升级流程是经过用户同意的自动升级。  
  
**函数返回值** | **描述**  
---|---  
0 | 表示处理成功，SDK继续正常处理后续流程。  
其他值 | 表示处理失败，SDK终止后续流程。
