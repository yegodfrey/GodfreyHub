# GATT服务停止回调  
  
typedef void (*ServiceStopCallback)(int status, int serverId, int srvcHandle)

当SDK调用BleGattsStopServiceEx 停止一个GATT服务时，需要调用此回调函数通知SDK服务已经关闭，可以关闭下一个GATT服务。否则SDK不进行下一个GATT服务的关闭流程。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
status | int | 输入 | 服务关闭结果，status为0时，表示服务关闭成功，SDK才关闭下一个GATT服务。  
serverId | int | 输入 | GATT服务的serverId。  
srvcHandle | int * | 输入 | 创建的GATT服务句柄。
