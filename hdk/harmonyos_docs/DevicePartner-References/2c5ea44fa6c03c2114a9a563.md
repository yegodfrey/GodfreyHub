# 数据访问

#### 导入模块
    
    
    import HealthEngine from '@huawei/h5pro-health-engine'

#### HealthEngine.saveSample

saveSample(param: Object): Object

存储单条数据到运动健康App。

  * 参数： 

参数名 | 类型 | 说明  
---|---|---  
param | Object | 单条数据对象。  
  
  * Object 

参数名 | 类型 | 说明  
---|---|---  
type | Number | 数据类型，使用常量类型，例：HealthEngine.dataType.DATA_BLOODPRESSURE  
startTime | Number | 开始时间（毫秒）。  
endTime | Number | 结束时间（毫秒）。  
map | Array<Object> | 类型、值数组。  
metadata | Object | 是否确认。  
deviceInfo | Object | 可选。设备信息。  
  
    * type 

Key 值的常量定义 | Key 值 | 描述  
---|---|---  
USER_PROFILE_INFORMATION | 101001 | 个人基本信息  
DATA_SET_CORE_SLEEP | 10007 | 睡眠  
DATA_BLOODPRESSURE | 10002 | 血压  
DATA_BLOODSUGAR | 10001 | 血糖  
DATA_BODYTEMPERATURE | 400011975 | 体温  
  
    * map 

Key 值的常量定义 | Key 值 | 描述  
---|---|---  
DATA_POINT_BLOODSUGAR_BF_BEFORE | 2008 | 早餐前 测量的血糖值  
DATA_POINT_BLOODSUGAR_BF_AFTER | 2009 | 早餐后 测量的血糖值  
DATA_POINT_BLOODSUGAR_LC_BEFORE | 2010 | 午餐前 测量的血糖值  
DATA_POINT_BLOODSUGAR_LC_AFTER | 2011 | 午餐后 测量的血糖值  
DATA_POINT_BLOODSUGAR_DN_BEFORE | 2012 | 晚餐前 测量的血糖值  
DATA_POINT_BLOODSUGAR_DN_AFTER | 2013 | 晚餐后 测量的血糖值  
DATA_POINT_BLOODSUGAR_SL_BEFORE | 2014 | 睡前 测量的血糖值  
DATA_POINT_BLOODSUGAR_BEFORE_DAWN | 2015 | 凌晨 测量的血糖值  
DATA_POINT_BLOODSUGAR_RANDOM | 2106 | 血糖随机值  
DATA_POINT_BLOODPRESSURE_SYSTOLIC | 2006 | 高压  
DATA_POINT_BLOODPRESSURE_DIASTOLIC | 2007 | 低压  
DATA_POINT_REST_HEARTRATE | 2018 | 脉搏  
CONTENT_SLEEP_REM | 44101 | 快速眼动（REM睡眠）时长  
CONTENT_SLEEP_DEEP | 44102 | 深度睡眠时长  
CONTENT_SLEEP_LIGHT | 44103 | 轻度睡眠时长  
CONTENT_SLEEP_NIGHT_SLEEP_AMOUNT | 44105 | 夜间睡眠量  
CONTENT_SLEEP_DEEP_CONTINUITY | 44106 | 深度睡眠连续性  
CONTENT_SLEEP_AWAKE_TIMES | 44107 | 清醒次数  
CONTENT_SLEEP_BED_TIME | 44201 | 入睡时间  
CONTENT_SLEEP_RISE_TIME | 44202 | 醒来时间  
CONTENT_SLEEP_SCORE | 44203 | 得分  
CONTENT_SLEEP_WHOLE_DAY_AMOUNT | 44209 | 全天量  
  
    * metadata Object 

参数名 | 类型 | 说明  
---|---|---  
mIsConfirmed | Boolean | 该条数据是否已确认。  
  
    * deviceInfo Object 

参数名 | 类型 | 说明  
---|---|---  
deviceName | String | 设备名称。  
deviceModel | String | 设备模式。  
deviceUniqueCode | String | 设备唯一标识码。  
  
  * 示例（血糖）：
        
        let map = [{
            type: HealthEngine.dataMapping.DATA_POINT_BLOODSUGAR_BF_BEFORE,
            value: 6.8
        }
        ] // 类型、值数组
        let deviceInfo = {
            deviceName:   // 设备名称
            deviceModel:  "xxxxxx" // 设备模式
            deviceUniqueCode: "xxxxxx"  // 设备唯一标识
        }
        let param = {
            type: HealthEngine.dataType.DATA_BLOODSUGAR,
            startTime: Date.now(),
            endTime: Date.now(),
            deviceInfo,
            map
        }
        HealthEngine.saveSample(param).then(data => {
            // 成功
        }).catch(err => {
            // 失败
        });



  * 示例（体温）：
        
        let param = {
            type: HealthEngine.dataType.DATA_BODYTEMPERATURE,
            startTime:  Date.now(),
            endTime: Date.now(),
            value: 40,  // 温度（整数）
        };
        HealthEngine.saveSample(param).then(data => {
            // 成功
        }).catch(err => {
            // 失败
        });




#### HealthEngine.saveSamples

saveSamples(params: Array): Object

存储数据集合到运动健康App，可存单条数据。

  * 参数： 

参数名 | 类型 | 说明  
---|---|---  
params | Array<Object> | 数据集合。  
  
  * Object 

参数名 | 类型 | 说明  
---|---|---  
type | Number | 数据类型，使用常量类型，例：HealthEngine.dataType.DATA_BLOODPRESSURE  
startTime | Number | 开始时间（毫秒）。  
endTime | Number | 结束时间（毫秒）。  
map | Array<Object> | 类型、值数组。  
metadata | Object | 是否确认。  
deviceInfo | Object | 可选。设备信息。  
  
    * metadata Object 

参数名 | 类型 | 说明  
---|---|---  
mIsConfirmed | Boolean | true：表示该条数据已确认；false：表示该条数据未确定。  
  
    * deviceInfo Object 

参数名 | 类型 | 说明  
---|---|---  
deviceName | String | 设备名称。  
deviceModel | String | 设备模式。  
deviceUniqueCode | String | 设备唯一标识码。  
  


  * 示例（血糖）：
        
        let param = [{
            type: HealthEngine.dataType.DATA_BLOODSUGAR,
            startTime: Date.now(),
            endTime: Date.now(),
            metadata: "{\"mIsConfirmed\":true}",
            map: [{
                type: HealthEngine.dataMapping.DATA_POINT_BLOODSUGAR_BF_BEFORE,
                value: 6.8
            }]
        },{
            type: HealthEngine.dataType.DATA_BLOODSUGAR,
            startTime: Date.now(),
            endTime: Date.now(),
            metadata: "{\"mIsConfirmed\":true}",
            map: [{
                type: HealthEngine.dataMapping.DATA_POINT_BLOODSUGAR_BF_BEFORE,
                value: 6.8
            }]
        }]
        HealthEngine.saveSamples(param).then(data => {
            // 成功
        }).catch(err => {
            // 失败
        })

  * 示例（体温）：
        
        let param = [{
            type: HealthEngine.dataType.DATA_BODYTEMPERATURE,
            startTime:  Date.now(),
            endTime:  Date.now(),
            value: 37 // 温度（整数）
        }, {
            type: HealthEngine.dataType.DATA_BODYTEMPERATURE,
            startTime: Date.now(),
            endTime: Date.now(),
            value:  38// 温度（整数）
        }];
        HealthEngine.saveSamples(param).then(data => {
            // 成功   
        }).catch(err => {
            // 失败
        });




#### HealthEngine.executeQuery

executeQuery(param: Object): Array

从运动健康App查询数据。

  * 参数： 

参数名 | 类型 | 说明  
---|---|---  
param | Object | 数据对象。  
  
    * Object 

参数名 | 类型 | 说明  
---|---|---  
type | Number | 数据类型，使用常量类型，例：HealthEngine.dataType.DATA_BLOODPRESSURE  
startTime | Number | 开始时间（毫秒）。  
endTime | Number | 结束时间（毫秒）。  
queryOption | Object | 查询倒序、数据条数（非必填，默认正序、查询所有数据）。  
  
      * queryOption Object 

参数名 | 类型 | 说明  
---|---|---  
mOrder | Number | 0：正序；1：按记录时间倒序。  
mLimit | Number | 可选。查询条数。例如填入1，表示查询一条数据。  
  


  * 入参示例：
        
        let param = { 
            type: HealthEngine.dataType.DATA_BLOODPRESSURE,  // 这里调用的血压type
            startTime: Date.now() - 30*24*3600*1000, // 开始时间
            endTime: Date.now(), // 结束时间
            queryOption: {
                mLimit:1, // 查询一条数据（查询所有数据可不传）
                mOrder:1 // 倒序
            }
        }
        HealthEngine.executeQuery(param).then(data => { 
             // 拿到结果 data
         }).catch(err => { 
             // 报错
         })



  * 返回参数： 

参数名 | 类型 | 说明  
---|---|---  
type | Number | 数据类型，使用常量类型，例：HealthEngine.dataType.DATA_BLOODPRESSURE  
startTime | Number | 开始时间（毫秒）。  
endTime | Number | 结束时间（毫秒）。  
sourceDevice | Object | 设备信息。  
values | Object | 查询的数据。  
metadata | Object | 是否确认。  
  


  * 返回示例：
        
        {
                "type": 10001,  // 类型常量
                "startTime": 1636961403000,
                "endTime": 1636961403000,
                "sourceDevice": {
                    "deviceName": "Sport Health Manual",  // 设备名称
                    "deviceUniqueCode": "***",  // 设备唯一标识码
                    "deviceModel": ""  // 设备模式
                },
                "values": {
                    "2008": 0,  // 空腹
                    "2009": 0,  // 早餐后
                    "2010": 0,  // 午餐前
                    "2011": 0,  // 午餐后
                    "2012": 5.7,  // 晚餐前
                    "2013": 0,  // 晚餐后
                    "2014": 0,  // 睡前
                    "2015": 0,  // 夜间
                    "2106": 0  // 随机
                },
                "metadata": {
                    "mIsConfirmed":false  // 该条数据是否已确认
                }
            }
