# 跳转至Native页面

#### 接口描述

hilink.gotoNative(String typeString, String callback)

跳转至Native页面，例如智能场景页面。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
typeString | String | 是 | Native页面类型。例如，智能场景页面对应的typeString为“IftttList”。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    var typeString = "Native页面类型";
    // web页面中需实现该函数，用来获取执行结果
    function callback(result){
    }
    hilink.gotoNative(typeString, callback);

#### 响应参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。  
  
#### 响应示例

  * 成功
        
        {"errcode":0}

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
12 | 参数校验失败、IO异常、响应数据为空。 | 检查参数是否符合要求。
