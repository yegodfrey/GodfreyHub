# 删除单个规则  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.deleteSingleRule(String ruleId, final String resultCallback)

删除任务执行的规则。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
ruleId | String | 规则的唯一标识符  
resultCallback | String | 回调函数的方法名  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
errcode | int | 0代表成功 11代表失败
