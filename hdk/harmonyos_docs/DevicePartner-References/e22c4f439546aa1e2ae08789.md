# 星闪  
  
void HILINK_EnableSle(void)

开发者调用此接口打开星闪功能总开关。当前接入协议中，星闪与蓝牙功能十分接近，SDK提供星闪功能开关用于启动星闪功能；开启后广播开关、广播数据设置等接口调用后会同时作用于SLE与BLE。
