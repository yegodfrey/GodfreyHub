# 擦除FLASH  
  
int HILINK_OtaAdapterFlashErase(unsigned int size);

SDK在升级过程中需要擦除升级分区的flash数据，调用此数据擦除从头开始的size大的分区。开发者在擦除成功后返回0，擦除失败返回-1或者其他值。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
size | unsigned int | 输入 | 从升级分区开始，擦除flash数据的长度。  
  
**函数返回值** | **描述**  
---|---  
0 | 擦除成功。  
其他值 | 擦除失败。
