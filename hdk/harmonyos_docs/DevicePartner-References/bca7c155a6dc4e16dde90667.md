# 通用错误码

code | 描述  
---|---  
1000 | 成功，除单独标注为0为成功的外，其他都是1000表示成功  
-1001 | 参数不正确  
-1003 | 参数不正确，deviceId为空  
-1004 | 获取设备失败  
-1005 | 获取设备房间异常，或者下发控制命令失败  
-1007 | 参数不正确  
-1008 | 设备上报的service数据为空  
-1009 | 上报失败  
-1010 | 在华为的注册时间为空  
-1011 | 云侧接口请求失败
