# 获取设备升级状态

#### 接口描述

getDeviceUpgradeStatus

获取设备升级状态

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：getDeviceUpgradeStatus  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
  
#### 回调

通过code判断设备是否在升级状态

#### 错误码

code | 描述  
---|---  
1 | 设备正在升级  
0 | 设备空闲
