# 上报设备状态数据  
  
#### 接口描述

hilink.reportDeviceProfileImpermanency(String devId, String json_body, String resultCallback)

通过智慧生活App代理上报当前设备的状态数据到云侧。通常适用于本身不具备上报能力的设备，比如蓝牙设备。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
devId | String | 是 | 取值为"0"，表示当前设备。  
json_body | String | 是 | 设备上报的数据内容。  
resultCallback | String | 是 | JS回调。  
  
json_body中的字段说明：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
status | String | 是 | 当前设备的状态：

  * online：在线。
  * offline：离线。

  
services | Object | 是 | 设备上报的services中的数据。  
  
#### 请求示例
    
    
    var devId = "xxx";
    // web页面中需实现该函数，用来获取执行结果 
    var json_body = JSON.stringify({
    {
        "status": "offline",
        "services": [{
            "ts": "string",
            "sid": "string",
            "data": {
                "additionalProp1": "***",
                "additionalProp2": "***",
                "additionalProp3": "***"
      }
     }]
    }
    })
    function resultCallback(resultStr){
        var result = resultStr; // 请求的返回结果
    }
    hilink.reportDeviceProfileImpermanency(devId, json_body, "resultCallback");

#### 响应参数

无

#### 响应示例

无

#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
200 | 成功。 | -  
400 | 客户端请求的语法错误，服务器无法理解。 | -  
401 | 请求要求用户的身份认证。 | -  
500 | 服务器遇到错误，无法完成请求。通常为服务器内部错误。 | -
