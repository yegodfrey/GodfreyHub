# 读取蓝牙Mac地址  
  
int ReadBtMacAddr(unsigned char *mac, unsigned int len)

SDK通过调用此接口，传入长度为6字节的缓冲区，开发者读取设备的蓝牙MAC地址后，将地址填入缓冲区中，并返回0。

**参数名** | **类型** | **输入/输出** | **描述**  
---|---|---|---  
mac | unsigned char * | 输入 | 存放蓝牙Mac地址的缓冲区。  
len | unsigned int | 输入 | mac缓冲区长度，当前为6字节。  
  
**函数返回值** | **描述**  
---|---  
0 | 读取设备蓝牙mac地址成功。  
其他值 | 读取设备蓝牙mac地址失败。
