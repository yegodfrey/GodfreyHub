# 发送蓝牙设备命令  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.sendCommand (String deviceId, String bleMac, String serviceId, String data, final String resultCallback)

下发蓝牙设备控制命令或查询设备状态，适用于设备侧集成华为蓝牙SDK或适配华为蓝牙应用层开放协议规范的设备。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 被连接设备的ID，由华为家居云分配。  
bleMac | String | 设备BLE MAC地址。  
serviceId | String | 设备服务ID，示例：lightSwitch。  
data | String | 下发的控制命令数据，需要使用JSON.stringify()方法转为json字符串形式下发，如：JSON.stringify({"on": 1})。 如果需要查询sid对应的数据，则该字段填写“{}”，并与设备侧联调，从订阅蓝牙事件接口的回调中获取。  
resultCallback | String | JS回调。  
  
#### 返回参数

  * 修改成功
        
        {"errcode":0,"responseData":"xxx"}

  * 修改失败
        
        {"errcode":-1}
