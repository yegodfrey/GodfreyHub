# 查询设备事件通知

#### 接口描述

deviceEventCallback(String resultCallback)

从云侧查询最近一次设备产生的事件通知。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

无

#### 请求示例
    
    
    // web页面中需实现该函数，用来查询设备产生的事件
    function deviceEventCallback(event) {
    var result = event; // 事件详情
    }

#### 响应参数

响应参数通过resultCallback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
result | Object | 是 | 返回设备产生的事件。  
  
#### 响应示例

  * 成功
        
        {
                "devId":"{deviceId}",
                "gatewayId":"xxxxx",
                "services": [{
                    "reportId": "",
                    "st": "air_conditioner",
                    "ts": "20151212T121212Z",
                    "sid": "1",
                    "data": {
                        "characteristicName1": "value1",
                        "characteristicName2": "value2"
                     }
                 }
               ]
        }



  * 失败
        
        {
                "devId":"{null}",
                "gatewayId":"null",
                "services": [{
                    "reportId": "",
                    "st": "null",
                    "ts": "null",
                    "sid": "1",
                    "data": {
                        "characteristicName1": "null",
                        "characteristicName2": "null"
                     }
                 }
               ]
        }




#### 错误码

无
