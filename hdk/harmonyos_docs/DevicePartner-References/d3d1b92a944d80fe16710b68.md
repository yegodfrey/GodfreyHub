# 存储数据在本地缓存  
  
#### 适用平台

Android、iOS

#### 接口描述

hilink.setStorageSync(KEY, data)

将 data 存储在本地缓存中指定的 key 中，会覆盖掉原来该 key 对应的内容，这是一个同步接口。

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
KEY | String | 本地缓存中的指定的 key  
data | String | 需要存储的内容，使用16进制字符串表达。  
  
#### 返回参数

参数 | 类型 | 描述  
---|---|---  
retCode | Number | 错误码：0, 90001, 90002, 90003, 90004 错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。
