# 获取设备的Profile信息  
  
#### 接口描述

getHiLinkDeviceEntity

获取当前设备的设备信息

#### 请求参数

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
functionName | string | 是 | 接口名称，固定为：getHiLinkDeviceEntity。  
deviceId | string | 是 | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识。  
isFromCloud | boolean | 否 | 是否从云端获取，默认值为：true。  
  
#### 回调

code为1000时，data：返回的是将设备信息转Json字符串,示例如下：
    
    
    {
    "devId":"设备id",
    "role":"角色",
    "homeId":"设备id",
    ......
    
    }

data包含的设备信息如下：

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
devId | string | 是 | 华为设备id。  
devName | string | 是 | 设备名称  
role | string | 是 | 用户角色，值：owner值family  
homeId | string | 是 | 家庭id  
homeName | string | 是 | 家庭名称  
gatewayId | string | 是 | 网关id  
roomId | number | 是 | 房间id  
roomName | string | 是 | 房间名称  
status | string | 是 | 设备状态，联网的设备支持。值：online：在线，offline：离线  
thirdPartyId | string | 是 | 三方厂家标识  
homeType | string | 是 | 设备家庭类型  
operations | Array<string> | 是 | 用户对设备的操作权限：READ/WRITE/EXECUTE  
registryTime | string | 是 | 设备在华为的注册时间  
devIds | ChildrenDeviceEntity[] | 是 | 子设备信息，详细见下面ChildrenDeviceEntity实体信息  
devInfo | DeviceInfoEntity | 是 | 设备信息，详细见下面DeviceInfoEntity实体信息  
services | Array<ServiceEntity> | 是 | 设备服务，集成hilink SDK，设备上报的profile数据  
  
ChildrenDeviceEntity实体信息：

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
id | string | 是 | 子设备id  
gatewayId | string | 是 | 网关id  
  
DeviceInfoEntity实体信息：

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
sn | string | 是 | 设备序列号  
model | string | 是 | 设备型号  
devType | string | 是 | 设备类型  
manu | string | 是 | 设备制造商  
mac | string | 是 | 设备mac地址  
bleMac | string | 否 | 低功耗mac地址  
hiv | string | 是 | 设备硬件版本  
fwv | string | 是 | 固件版本  
swv | string | 是 | hilink SDK版本  
protType | string | 是 | 单品设备类型  
prodId | string | 是 | DP平台产品id  
subProdId | string | 是 | 子设备id  
peerId | string | 否 | 对等标识  
brMac | string | 否 | 经典蓝牙mac地址  
deviceName | string | 是 | 设备名称  
setupType | string | 是 | 安装类型  
coap | string | 否 | wifi放大器通过coap协议扫描获取到的ip地址。  
hcv | string | 否 | coap设备支持的hiChain版本  
sleMac | string | 否 | 星闪设备slemac  
discType | string | 是 | 设备支持的扫描类型  
udid | string | 否 | 设备udid  
vin | string | 否 | 车架号  
  
ServiceEntity实体信息：

参数 | 类型 | 是否必选 | 描述  
---|---|---|---  
sid | string | 是 | 服务id  
st | string | 是 | 服务类型  
data | string | 是 | 服务数据  
ts | string | 是 | 时间戳  
reportId | string | 是 | 上报id  
  
#### 错误码

code | 描述  
---|---  
0 | 成功
