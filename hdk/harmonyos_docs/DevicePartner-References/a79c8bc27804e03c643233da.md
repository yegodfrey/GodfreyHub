# 创建规则  
  
#### 接口描述

hilink.createRule(String rule, String callback);

创建场景联动或消息推送规则。

#### 适用平台

Android、iOS

#### 接口约束

无

#### 请求参数

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
rule | String | 是 | 规则json字符串。  
callback | String | 是 | 结果回调。  
  
#### 请求示例
    
    
    String rule = "
    {
    	"name": "Rule01",
    	"conditions": [
    		{
    			"type": "DEVICE_DATA",
    			"deviceInfo": {
    				"devId": "2323-1221-...",
    				"devType": "005",
    				"path": "switch/on"
    			},
    			"operator": "=",
    			"value": "1"
    		}
    	],
    	"actions": [
    		{
    			"type": "DEVICE_CMD",
    			"devId": "2323-1221-...",
    			"devType": "01B",
    			"cmd": {
    				"sid": "switch",
    				"messageType": "POST",
    				"messageBody": {
    					"on": 1
    				}
    			}
    		}
    	]
    }
    ";
    // web页面中需实现该函数，用来获取执行结果 
    function callback(result){}
    hilink.createRule(rule, callback);

#### 响应参数

响应参数通过callback返回，结构如下：

参数 | 类型 | 是否必选 | 说明  
---|---|---|---  
errcode | int | 是 | 错误码。  
  
#### 响应示例

  * 成功
        
        {"errcode":0}

  * 失败
        
        {"errcode":-1}




#### 错误码

错误码 | 错误码描述 | 解决措施  
---|---|---  
0 | 请求成功。 | -  
-1 | 请求失败。 | -  
10 | 请求超时。 | 请检查网络。  
12 | 参数校验失败、IO异常、响应数据为空。 | 请检查请求参数。
