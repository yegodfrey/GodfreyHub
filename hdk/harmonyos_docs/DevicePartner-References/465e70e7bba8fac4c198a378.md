# 下发命令从设备上获取profile属性  
  
#### 接口描述

sendReadProfileCommand

根据deviceId和serviceId下发获取设备当前状态属性命令，返回设备状态属性

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：sendReadProfileCommand  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
serviceId | string | 设备profile中的serviceId  
  
#### 回调

code等于0时，data返回从设备获取到的profile属性，返回data字符串转json后，示例：
    
    
    {
    "characteristicName1": "value1",
    "characteristicName2": "value2"...
    }

#### 错误码

code | 描述  
---|---  
0 | 成功  
-2007 | 调用失败
