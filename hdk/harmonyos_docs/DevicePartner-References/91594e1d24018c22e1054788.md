# 取消注册蓝牙/星闪设备事件监听  
  
#### 接口描述

unsubscribeDeviceEvent

修改蓝牙设备属性

#### 适用平台

鸿蒙Next

#### 请求参数

参数 | 类型 | 描述  
---|---|---  
functionName | string | 接口名称，固定为：unsubscribeDeviceEvent  
deviceId | string | 智慧生活拉起插件时通过路由传递给插件的设备唯一标识  
  
#### 错误码

code | 描述  
---|---  
-1111 | 调用失败
