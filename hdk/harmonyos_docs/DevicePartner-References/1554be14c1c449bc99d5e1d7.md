# 模组能否立即重启  
  
int HILINK_GetRebootFlag (void);

SDK在开启自动升级并检测到新版本时，通过此接口判断模组是否能升级并重启。开发者需根据设备业务情况判断是否处于业务空闲状态，能重启时返回1，不能重启时返回0。

**函数返回值** | **描述**  
---|---  
0 | 模组当前不能重启。  
1 | 模组当前可以重启，SDK将开启自动升级流程。
