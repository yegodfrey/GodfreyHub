# 监听蓝牙连接状态变化

#### 适用平台

Android、iOS

#### 接口描述

hilink.onBLEConnectionStateChange (CallbackName)

监听低功耗蓝牙连接状态的改变事件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/AIp5HC11S52zq-zUF1PtMQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T090918Z&HW-CC-Expire=86400&HW-CC-Sign=98F6190D6CDCECCFE9713925FC863E0ACFA8EEDECA4694101547185A4476A277)

  * 该方法可多次注册不同名称回调函数，已注册的全部回调函数，会在hilink.closeBLEConnection调用前生效。hilink.closeBLEConnection后，会清除回调注册。
  * 该方法建议在hilink.createBLEConnection前调用，确保每一次连接状态都可以被准确接收。



#### 请求参数

参数 | 类型 | 描述  
---|---|---  
deviceId | String | 蓝牙设备Id  
connected | Boolean | 连接目前的状态
