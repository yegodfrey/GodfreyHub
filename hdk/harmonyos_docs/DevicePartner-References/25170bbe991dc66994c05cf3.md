# 获取固件升级区域

unsigned int HILINK_OtaAdapterGetUpdateIndex(void);

SDK在下载固件时，调用此接口获取要升级的分区。开发者需要返回本次升级的区域，返回0时，对应image2_all_ota1.bin，否则image2_all_ota2.bin。

**函数返回值** | **描述**  
---|---  
0x00 | 升级分区1。  
0x01 | 升级分区2。
