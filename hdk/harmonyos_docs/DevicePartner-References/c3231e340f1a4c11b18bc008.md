# 判断平板横竖屏状态

#### 接口描述

hilink.getPadLandscape()

判断平板横竖屏状态。

#### 适用平台

Android

#### 请求参数

无

#### 请求示例
    
    
    let getPadLandscape = hilink.getPadLandscape();
    if (getPadLandscape === -1) {
      // 非平板时的操作
    } else if (getPadLandscape === 0) {
      // 平板横屏时的操作 
    } else if (getPadLandscape === 1) {
      // 平板竖屏时的操作
    }

#### 响应参数

该接口将直接返回int类型值：

  * -1：不是平板
  * 0： 平板横屏
  * 1： 平板竖屏



#### 响应示例

无
