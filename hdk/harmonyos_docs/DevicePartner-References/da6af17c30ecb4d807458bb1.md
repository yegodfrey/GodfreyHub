# 下载蓝牙固件

#### 适用平台

Android、iOS

#### 接口描述

hilink.downloadFile (url, fileName, CallbackName)

蓝牙设备升级接口，通过HTTP GET从厂商服务器下载蓝牙固件，完成下载后（针对服务器响应200 OK，才认为是正常响应），通过回调返回fileKey，此后厂商利用fileKey去访问下载到的蓝牙固件。

#### 请求参数

参数 | 类型 | 必填 | 描述  
---|---|---|---  
url | String | 是 | 固件url地址，只支持HTTP GET，最大文件大小为10M –用户已使用的内部存储大小。  
fileName | String | 是 | 文件名  
CallbackName | String | 是 | 回调函数名  
  
#### 返回参数

错误码说明参见[通用错误码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/result-codes-0000001077437634)。

参数 | 类型 | 描述  
---|---|---  
fileKey | String | 已经下载的升级包保存到本地后，对应的getStorageSync的key，通过这个key，可以利用getStorageSync来读取蓝牙固件。  
errCode | Number | 错误码：0, 90001, 90011
