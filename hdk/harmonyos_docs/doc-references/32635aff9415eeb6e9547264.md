Describes the accessibility event information and provides the information for the accessibility service.  The information includes the accessibility event type, the operation that triggers the accessibility event, the package name of the event source, the movement step used for reading texts, and the accessibility event list.  When any change is made on the UI, for example, when a view control gains the focus, your app can send an [AccessibilityEventInfo#TYPE_VIEW_FOCUSED_EVENT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityeventinfo-0000001054678661#ZH-CN_TOPIC_0000001054678661__TYPE_VIEW_FOCUSED_EVENT) accessibility event to the accessibility service to trigger the accessibility function. **Since:** 2**See Also:** [AccessibilitySystemAbilityClient.sendEvent(AccessibilityEventInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitysystemabilityclient-0000001054358680#ZH-CN_TOPIC_0000001054358680__sendEvent-ohos_accessibility_AccessibilityEventInfo-)Field Summary Modifier and Type | Field | Description
