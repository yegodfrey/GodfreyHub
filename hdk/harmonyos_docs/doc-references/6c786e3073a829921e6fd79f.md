# Overview  
  
Provides [Fraction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fraction-0000001059908801)-related capabilities. 

A [Fraction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fraction-0000001059908801) can be placed in a container (an [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007)) as a part of its UI and cannot be used independently. A Fraction has its own lifecycle, but its lifecycle state depends on its container. If the container is destroyed, all fractions in it will also be destroyed. You can use the Fraction class to define a variety of layouts to enrich the user interface of your application.
