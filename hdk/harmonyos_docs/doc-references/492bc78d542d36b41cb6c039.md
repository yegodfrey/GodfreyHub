# Overview  
  
Provides classes for networking applications. These classes include factories for creating sockets. Using socket factories you can encapsulate socket creation and configuration behavior. 

**Since:**

1.4

#### Class Summary

Class | Description  
---|---  
[ServerSocketFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serversocketfactory-0000001054358646) | This class creates server sockets.  
[SocketFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketfactory-0000001054119987) | This class creates sockets.
