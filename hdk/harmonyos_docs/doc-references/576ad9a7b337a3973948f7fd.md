Revocable  
      
    public interface Revocable  
  
---  
Revokes an asynchronous task that is dispatched by calling [TaskDispatcher.asyncDispatch(java.lang.Runnable)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__asyncDispatch-java_lang_Runnable-), [TaskDispatcher.delayDispatch(java.lang.Runnable, long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__delayDispatch-java_lang_Runnable-long-), or [TaskDispatcher.asyncGroupDispatch(ohos.app.dispatcher.Group, java.lang.Runnable)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__asyncGroupDispatch-ohos_app_dispatcher_Group-java_lang_Runnable-). The following example shows how to use this interface to revoke an asynchronous task: 
    
    void postTaskAndRevoke(Context context) {
         TaskDispatcher dispatcher = context.getUITaskDispatcher();
         System.out.println("1");
         Revocable revocable = dispatcher.delayDispatch(new Runnable(){
             System.out.println("delay dispatch");
         }, 10);
         boolean revoked = revocable.revoke();
         System.out.println(revoked);
     }
    
     // A typical result is :
     // true
