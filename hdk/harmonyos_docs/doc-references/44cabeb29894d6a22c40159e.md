# Overview  
  
Provides common utility classes and interfaces for implementing cross-platform interaction. 

The utility methods in this package help you significantly improve your efficiency in developing applications involving cross-platform interactions. 

    * [ParcelableEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcelableex-0000001054678859) is an interface used to marshal data for cross-platform interactions.
    * [PacMapEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pacmapex-0000001054358878) defines the data packet structure used in cross-platform interactions. The data packets are used to store key-value pairs and perform cross-platform data marshalling.
