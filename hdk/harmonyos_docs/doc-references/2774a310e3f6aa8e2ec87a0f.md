#### [h2]MERGE_REPLACE

public static final int MERGE_REPLACE

Allows merging and replacement. 

When multiple [ComponentProvider.Action](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider_action-0000001060679060) are applied to the same attribute of the same component, these actions can be merged.
