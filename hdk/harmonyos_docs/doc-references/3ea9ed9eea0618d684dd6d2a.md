# NotificationSubscribeInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationSubscribeInfo
    
    public class NotificationSubscribeInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Sets filter criteria of publishers for subscribing to desired notifications. 

After you set the filter criteria in a NotificationSubscribeInfo object, you can use it to subscribe to or unsubscribe from notifications only from publishers meeting the filter criteria. only the system app can subscribe or unsubscribe notifications.
