# Overview  
  
Manages Data Object. 

This package provides methods to put and get data object to cache and sync with other devices.

**Since:**

7

#### Interface Summary

Interface | Description  
---|---  
[ObjectStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstore-0000001172716672) | Interfaces of ObjectStore that caching and syncing objects  
[ObjectWatcher](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectwatcher-0000001172398176) | Interface of class that watching object changes
