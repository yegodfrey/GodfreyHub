#### [h2]batchInsertOrThrowException

[List](https://developer.harmonyos.com/cn/docs/documentation/doc-references/list-0000001054119842)<[Long](https://developer.harmonyos.com/cn/docs/documentation/doc-references/long-0000001054439731)> batchInsertOrThrowException​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) tableName, [List](https://developer.harmonyos.com/cn/docs/documentation/doc-references/list-0000001054119842)<[ValuesBucket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/valuesbucket-0000001054678818)> initialValues, [RdbStore.ConflictResolution](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819) conflictResolution)

Inserts data into the database in batches based on the conflict handling policy. 

If the conflict handling policy is null, the default policy [ConflictResolution#ON_CONFLICT_NONE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819#ZH-CN_TOPIC_0000001054558819__ON_CONFLICT_NONE) will be used. If an exception occurs during the data insertion, the operation varies depending on the type of the conflict handling policy. 

    * [ConflictResolution#ON_CONFLICT_ROLLBACK](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819#ZH-CN_TOPIC_0000001054558819__ON_CONFLICT_ROLLBACK): If a data conflict occurs, the database column is null, or the database column has only one value, all the inserted data will be rolled back. 
    * [ConflictResolution#ON_CONFLICT_ABORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819#ZH-CN_TOPIC_0000001054558819__ON_CONFLICT_ABORT) or [ConflictResolution#ON_CONFLICT_FAIL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819#ZH-CN_TOPIC_0000001054558819__ON_CONFLICT_FAIL): If a data conflict occurs, the database column is null, or the database column has only one value, the inserted data will be retained, and an exception will be thrown. 
    * [ConflictResolution#ON_CONFLICT_IGNORE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819#ZH-CN_TOPIC_0000001054558819__ON_CONFLICT_IGNORE): If a data conflict occurs or the database column is null, the exception will be ignored, and value -1 will be returned. The data insertion will continue until all data is inserted into the database. If the foreign key does not exist or a foreign key conflict occurs, see [ConflictResolution#ON_CONFLICT_ABORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819#ZH-CN_TOPIC_0000001054558819__ON_CONFLICT_ABORT). 
    * [ConflictResolution#ON_CONFLICT_REPLACE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore_conflictresolution-0000001054558819#ZH-CN_TOPIC_0000001054558819__ON_CONFLICT_REPLACE): If a data conflict occurs, or the database column has a default value or only one value, the conflict data will be replaced and the data insertion will continue until all data is inserted into the database. #### [h2]restore

boolean restore​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) srcName, byte[] srcEncryptKey, byte[] destEncryptKey)

Restores a database from a specified encrypted or unencrypted database file. 

When being called, this method deletes the original data and generates an encrypted or unencrypted database, as defined by your application. If both srcEncryptKey and destEncryptKey are null, this method is equivalent to the [RdbStore#restore(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore-0000001054518828#ZH-CN_TOPIC_0000001054518828__restore-java_lang_String-) method. For the maximum size of the encryption key, see [StoreConfig#MAX_ENCRYPT_KEY_SIZE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storeconfig-0000001054200090#ZH-CN_TOPIC_0000001054200090__MAX_ENCRYPT_KEY_SIZE).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
srcName  |  Indicates the name that stores the source database file. Ensure that your application has write permissions to this name.  
srcEncryptKey  |  Indicates the encryption key of the source database. If the database is unencrypted, set the value of this parameter to null.  
destEncryptKey  |  Indicates the encryption key of the restored database.If you want the database to be unencrypted, set the value of this parameter to null.  
  
**Returns:**

Returns true if the database is restored successfully; returns false otherwise.

**Since:**

3
