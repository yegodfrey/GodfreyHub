# DependentLayout.LayoutConfig

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.components.ComponentContainer.LayoutConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentcontainer_layoutconfig-0000001054119972) |---|---ohos.agp.components.DependentLayout.LayoutConfig
    
    public static class DependentLayout.LayoutConfig
    extends [ComponentContainer.LayoutConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentcontainer_layoutconfig-0000001054119972)  
  
---  
Provides layout configs for a dependent layout. 

These configs specify the position of a [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) in [DependentLayout](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dependentlayout-0000001054358695). If the [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) is not in [DependentLayout](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dependentlayout-0000001054358695), these layout configs are ignored.

**Since:**

3
