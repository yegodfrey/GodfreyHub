This event is propagated to a SSLSessionBindingListener. When a listener object is bound or unbound to an SSLSession by [SSLSession#putValue(String, Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsession-0000001054238659#ZH-CN_TOPIC_0000001054238659__putValue-java_lang_String-java_lang_Object-) or [SSLSession#removeValue(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsession-0000001054238659#ZH-CN_TOPIC_0000001054238659__removeValue-java_lang_String-), objects which implement the SSLSessionBindingListener will be receive an event of this type. The event's name field is the key in which the listener is being bound or unbound.**Since:** 1.4**See Also:** [SSLSession](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsession-0000001054238659), [SSLSessionBindingListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsessionbindinglistener-0000001054678629), Field Summary Fields inherited from class java.util.[EventObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventobject-0000001054119921)
