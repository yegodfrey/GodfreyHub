# DirectoryIteratorException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466) |---|---|---|---[java.util.ConcurrentModificationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentmodificationexception-0000001054558603) |---|---|---|---|---java.nio.file.DirectoryIteratorException
    
    public final class DirectoryIteratorException
    extends [ConcurrentModificationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentmodificationexception-0000001054558603)

Runtime exception thrown if an I/O error is encountered when iterating over the entries in a directory. The I/O error is retrieved as an [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) using the [getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/directoryiteratorexception-0000001054439795#ZH-CN_TOPIC_0000001054439795__getCause--) method.
