# Overview  
  
Obtains application information during runtime. 

You can obtain the context and process information of applications and abilities during application runtime.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) | Provides the context of an object in the application and obtains application environment information.  
[ElementsCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementscallback-0000001054200052) | Provides callbacks that can be used by elements to listen for system configuration and memory status changes.  
[IAbilityManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymanager-0000001054518792) | Obtains running process and memory information about an application.  
  
#### Class Summary

Class | Description  
---|---  
[AbilityContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitycontext-0000001054358759) | An abstract class that provides the application context for the current object and obtains the application environment information.  
[Environment](https://developer.harmonyos.com/cn/docs/documentation/doc-references/environment-0000001054558781) | Provides system environment variables.  
[GeneralReceiver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/generalreceiver-0000001054238779) | Provides generic callback methods for receiving results from other processes during inter-process communication (IPC).  
[ProcessInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processinfo-0000001054678749) | Saves process information about an application.  
  
#### Exception Summary

Exception | Description  
---|---  
[ContextInvalidArgException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contextinvalidargexception-0000001054358768) | Describes the exception thrown when a parameter passed in a [Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) is invalid.
