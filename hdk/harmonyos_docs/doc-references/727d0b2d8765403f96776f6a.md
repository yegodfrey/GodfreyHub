# ListContainer.ItemSelectedListener  
      
    public static interface ListContainer.ItemSelectedListener  
  
---  
Listens for selected events of a Component item in the [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) object. The selected events are processed by calling onItemSelected.

#### Method Detail

#### [h2]onItemSelected

void onItemSelected​([ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) parent, [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, int position, long id)

Called when a component item in the [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) object is selected. 

This callback processes the selected event in when: 

    1. No item in the [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) object has been selected.
    2. Another component item in the [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) object is selected.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
parent  |  Indicates the [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) object with the selected component item.  
component  |  Indicates the selected component item in the [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) object.  
position  |  Indicates the position of the selected component item in the [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) object.  
id  |  Indicates the row ID of the selected component item.
