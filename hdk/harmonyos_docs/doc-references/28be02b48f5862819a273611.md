    public abstract class CharsetDecoder
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
An engine that can transform a sequence of bytes in a specific charset into a sequence of sixteen-bit Unicode characters. __ The input byte sequence is provided in a byte buffer or a series of such buffers. The output character sequence is written to a character buffer or a series of such buffers. A decoder should always be used by making the following sequence of method invocations, hereinafter referred to as a _decoding operation_ : 
                1. Reset the decoder via the [reset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__reset--) method, unless it has not been used before; 
                2. Invoke the [decode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__decode-java_nio_ByteBuffer-java_nio_CharBuffer-boolean-) method zero or more times, as long as additional input may be available, passing false for the endOfInput argument and filling the input buffer and flushing the output buffer between invocations; 
                3. Invoke the [decode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__decode-java_nio_ByteBuffer-java_nio_CharBuffer-boolean-) method one final time, passing true for the endOfInput argument; and then 
                4. Invoke the [flush](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__flush-java_nio_CharBuffer-) method so that the decoder can flush any internal state to the output buffer. 
Each invocation of the [decode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__decode-java_nio_ByteBuffer-java_nio_CharBuffer-boolean-) method will decode as many bytes as possible from the input buffer, writing the resulting characters to the output buffer. The [decode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__decode-java_nio_ByteBuffer-java_nio_CharBuffer-boolean-) method returns when more input is required, when there is not enough room in the output buffer, or when a decoding error has occurred. In each case a [CoderResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/coderresult-0000001054238499) object is returned to describe the reason for termination. An invoker can examine this object and fill the input buffer, flush the output buffer, or attempt to recover from a decoding error, as appropriate, and try again. __ There are two general types of decoding errors. If the input byte sequence is not legal for this charset then the input is considered _malformed_. If the input byte sequence is legal but cannot be mapped to a valid Unicode character then an _unmappable character_ has been encountered. __ How a decoding error is handled depends upon the action requested for that type of error, which is described by an instance of the [CodingErrorAction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/codingerroraction-0000001054678469) class. The possible error actions are to [CodingErrorAction#IGNORE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/codingerroraction-0000001054678469#ZH-CN_TOPIC_0000001054678469__IGNORE) the erroneous input, [CodingErrorAction#REPORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/codingerroraction-0000001054678469#ZH-CN_TOPIC_0000001054678469__REPORT) the error to the invoker via the returned [CoderResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/coderresult-0000001054238499) object, or [CodingErrorAction#REPLACE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/codingerroraction-0000001054678469#ZH-CN_TOPIC_0000001054678469__REPLACE) the erroneous input with the current value of the replacement string. The replacement has the initial value "\uFFFD"; its value may be changed via the [replaceWith](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__replaceWith-java_lang_String-) method.  The default action for malformed-input and unmappable-character errors is to [CodingErrorAction#REPORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/codingerroraction-0000001054678469#ZH-CN_TOPIC_0000001054678469__REPORT) them. The malformed-input error action may be changed via the [onMalformedInput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__onMalformedInput-java_nio_charset_CodingErrorAction-) method; the unmappable-character action may be changed via the [onUnmappableCharacter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__onUnmappableCharacter-java_nio_charset_CodingErrorAction-) method.  This class is designed to handle many of the details of the decoding process, including the implementation of error actions. A decoder for a specific charset, which is a concrete subclass of this class, need only implement the abstract [decodeLoop](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__decodeLoop-java_nio_ByteBuffer-java_nio_CharBuffer-) method, which encapsulates the basic decoding loop. A subclass that maintains internal state should, additionally, override the [implFlush](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__implFlush-java_nio_CharBuffer-) and [implReset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__implReset--) methods.  Instances of this class are not safe for use by multiple concurrent threads.  **Since:** 1.4**See Also:** [ByteBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771), [CharBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498), [Charset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charset-0000001054678500), [CharsetEncoder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetencoder-0000001054558501)Constructor Summary Modifier | Constructor | Description
