# NotificationHelper  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationHelper
    
    public class NotificationHelper
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Manages notifications. 

The methods provided by this class are all static and can be called without creating an object of this class. 

Generally, only system applications have permissions on notification subscription and unsubscription. You can specify the content of a notification to be published and the content is carried by [NotificationRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854). A notification ID is unique in an application and must be specified when using [NotificationRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854) to carry the notification content. If a notification with this ID has been published and you need to use this ID to publish another notification, the original notification will be updated. In addition, the notification ID can be used to cancel a notification by calling the [cancelNotification(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationhelper-0000001054200114#ZH-CN_TOPIC_0000001054200114__cancelNotification-int-) method.
