XMLEventConsumer  
      
    public interface XMLEventConsumer  
  
---  
This interface defines an event consumer interface. The contract of the of a consumer is to accept the event. This interface can be used to mark an object as able to receive events. Add may be called several times in immediate succession so a consumer must be able to cache events it hasn't processed yet.**Since:** 1.6Method Summary Modifier and Type | Method | Description
