# ProgressBar

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.components.Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) |---|---ohos.agp.components.ProgressBar

---  
Provides an element for indicating the progress of an operation on the UI. 

The progress bar supports the determinate and indeterminate types. The progress bar is displayed on a UI or in a notification without interrupting users. 

**Indeterminate Progress**

The indeterminate progress bar is used when the time required for the operation is uncertain. 

**Determinate Progress**

The determinate progress bar is used when you need to display the specific quantity of progress of the operation. You can use the [setProgressValue(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/progressbar-0000001054199992#ZH-CN_TOPIC_0000001054199992__setProgressValue-int-) function to update the current progress. By default, when the progress value displayed on the progress bar reaches 100, the operation is complete.
