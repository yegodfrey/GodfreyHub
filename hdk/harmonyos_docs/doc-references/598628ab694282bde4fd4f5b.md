# PropertyChangeListenerProxy  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.EventListenerProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventlistenerproxy-0000001054358580)<[PropertyChangeListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertychangelistener-0000001054199698)> |---|---java.beans.PropertyChangeListenerProxy
    
    public class PropertyChangeListenerProxy
    extends [EventListenerProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventlistenerproxy-0000001054358580)<[PropertyChangeListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertychangelistener-0000001054199698)>
    implements [PropertyChangeListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertychangelistener-0000001054199698)  
  
---  
A class which extends the EventListenerProxy specifically for adding a PropertyChangeListener with a "bound" property. Instances of this class can be added as PropertyChangeListeners to a bean which supports firing property change events. 

If the object has a getPropertyChangeListeners method then the array returned could be a mixture of PropertyChangeListener and PropertyChangeListenerProxy objects.

**Since:**

1.4
