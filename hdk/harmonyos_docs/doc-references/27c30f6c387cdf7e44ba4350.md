A long value that may be updated atomically. See the [java.util.concurrent.atomic](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054558619) package specification for description of the properties of atomic variables. An AtomicLong is used in applications such as atomically incremented sequence numbers, and cannot be used as a replacement for a [Long](https://developer.harmonyos.com/cn/docs/documentation/doc-references/long-0000001054439731). However, this class does extend Number to allow uniform access by tools and utilities that deal with numerically-based classes.**Since:** 1.5Constructor Summary Constructor | Description
