# Overview  
  
Provides basic capabilities of the local data framework and data-sharing service. Local data generally refers to user-defined structured or unstructured data, such as the XML data. Data-sharing indicates the cross-device or cross-scenario data transmission. 

This package contains the rdb [ohos.data.rdb](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054120072), orm [ohos.data.orm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054678779), preferences [ohos.data.preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054518826), and dataability [ohos.data.dataability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054120058) modules to meet users' demands on data services in different scenarios.
