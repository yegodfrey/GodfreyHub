# Overview  
  
Provides basic USB communication capabilities for other peripherals and devices running OHOS. 

The basic USB communication capabilities include control transfer and bulk transfer.

**Since:**

5

#### Class Summary

Class | Description  
---|---  
[USBConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/usbconfig-0000001138728623) | Gets information about USB configuration.  
[USBCore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/usbcore-0000001091930960) | This class allows you to obtain USB devices currently attached, obtain USB device status, and communicate with USB devices.  
[USBDevice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/usbdevice-0000001138633167) | Get configuration information of a USB device.  
[USBDevicePipe](https://developer.harmonyos.com/cn/docs/documentation/doc-references/usbdevicepipe-0000001091611358) | Provides methods for transferring data and control messages between USB devices.  
[USBEndpoint](https://developer.harmonyos.com/cn/docs/documentation/doc-references/usbendpoint-0000001091771028) | Get endpoint information about a USB device.  
[USBInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/usbinterface-0000001091482878) | Get interface and endpoint information about a USB device.  
[USBRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/usbrequest-0000001138987493) | Implements bulk transfer of data and control messages between USB devices.
