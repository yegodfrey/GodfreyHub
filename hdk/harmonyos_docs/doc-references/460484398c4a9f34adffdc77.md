# DeviceCapability

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.global.configuration.DeviceCapability
    
    public class DeviceCapability
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides the device capability to manage resources. 

You can use [ResourceManager.getDeviceCapability()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863#ZH-CN_TOPIC_0000001054358863__getDeviceCapability--) to obtain the device capability and use [ResourceManager.updateConfiguration(Configuration, DeviceCapability)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863#ZH-CN_TOPIC_0000001054358863__updateConfiguration-ohos_global_configuration_Configuration-ohos_global_configuration_DeviceCapability-) to update the device capability.
