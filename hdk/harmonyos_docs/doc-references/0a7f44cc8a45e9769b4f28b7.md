# OrmDatabase

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.data.orm.OrmDatabase
    
    public abstract class OrmDatabase
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Represents object databases. 

An object relational mapping (ORM) database class corresponds to a relational database. Before using an ORM database, you need to create a database class that inherits from [OrmDatabase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormdatabase-0000001054838766) and annotate it with @Database.

#### [h2]getVersion

public abstract int getVersion​()

Obtains the database version. 

If you have specified the database version in the @Database annotation, the ORM annotation processor will automatically implement and invoke this method during compilation. In this case, your application does not need to implement and invoke this method.

**Returns:**

Returns the database version.

**Since:**

1

#### [h2]getHelper

public abstract [RdbOpenCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbopencallback-0000001054120145) getHelper​()

Obtains the RdbOpenCallback instance for creating a relational database that corresponds to the current object database. 

If you have specified the implementation class of [OrmMigration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormmigration-0000001054358800) in [DatabaseHelper.getOrmContext(java.lang.String, java.lang.String, java.lang.Class<T>, ohos.data.orm.OrmMigration...)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databasehelper-0000001054678767#ZH-CN_TOPIC_0000001054678767__getOrmContext-java_lang_String-java_lang_String-java_lang_Class-ohos_data_orm_OrmMigration___-), the ORM annotation processor will automatically read the database version and the implementation class, and generate an instance for creating a relational database that corresponds to the current object database. In this case, your application does not need to implement and invoke this method.

**Returns:**

Returns the RdbOpenCallback instance for creating the relational database.
