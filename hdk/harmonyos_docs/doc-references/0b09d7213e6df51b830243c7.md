# InvocationTargetException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.ReflectiveOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reflectiveoperationexception-0000001054199726) |---|---|---|---java.lang.reflect.InvocationTargetException
    
    public class InvocationTargetException
    extends [ReflectiveOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reflectiveoperationexception-0000001054199726)  
  
---  
InvocationTargetException is a checked exception that wraps an exception thrown by an invoked method or constructor. 

As of release 1.4, this exception has been retrofitted to conform to the general purpose exception-chaining mechanism. The "target exception" that is provided at construction time and accessed via the [getTargetException()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/invocationtargetexception-0000001054838424#ZH-CN_TOPIC_0000001054838424__getTargetException--) method is now known as the _cause_ , and may be accessed via the [Throwable#getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method, as well as the aforementioned "legacy method."

#### [h2]getTargetException

public [Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) getTargetException​()

Get the thrown target exception. 

This method predates the general-purpose exception chaining facility. The [Throwable#getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method is now the preferred means of obtaining this information.

**Returns:**

the thrown target exception (cause of this exception).
