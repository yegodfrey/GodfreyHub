Thrown to indicate that an assertion has failed. The seven one-argument public constructors provided by this class ensure that the assertion error returned by the invocation: 
    
    new AssertionError(_expression_)
     

has as its detail message the _string conversion_ of _expression_ (as defined in section 15.18.1.1 of 《The Java™ Language Specification》), regardless of the type of _expression_.**Since:** 1.4Constructor Summary Constructor | Description
