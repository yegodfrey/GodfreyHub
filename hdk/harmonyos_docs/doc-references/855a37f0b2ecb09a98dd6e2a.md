# KvStoreResultSet
    
    public interface KvStoreResultSet  
  
---  
Provide methods to obtain the result set of the KvStore database. 

The result set is created by using the getResultSet method in the DeviceKvStore class. This interface also provides methods for moving the data read position in the result set.

#### [h2]skipRow

boolean skipRow​(int offset)

Moves the read position by a relative offset to the current position. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
offset  |  Indicates the relative offset to the current position. A negative offset indicates moving backwards, and a positive offset indicates moving forewards. For example, if the current position is entry 1 and this offset is 2, the destination position will be entry 3; if the current position is entry 3 and this offset is -2, the destination position will be entry 1. The valid final position after moving forwards starts with 0. If the final position is invalid, false will be returned.  
  
**Returns:**

Returns true if the operation succeeds; return false otherwise.

**Since:**

1
