# Overview  
  
Executes or configures Wi-Fi P2P. 

  * [WifiP2pCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pcallback-0000001054359002): provides callbacks that are invoked to notify the results of Wi-Fi P2P requests. 
  * [WifiP2pConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pconfig-0000001054120343): represents the Wi-Fi P2P configuration for setting up a connection, such as the device address and passphrase. 
  * [WifiP2pController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pcontroller-0000001054120272): provides methods for managing the Wi-Fi P2P service. 
  * [WifiP2pDevice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pdevice-0000001054440301): provides detailed information about the Wi-Fi P2P device, such as the device address and status. 
  * [WifiP2pGroup](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pgroup-0000001054200288): provides detailed information about the Wi-Fi P2P group, such as the name and network ID. 
  * [WifiP2pNetworkInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pnetworkinfo-0000001054519028): provides detailed information about the Wi-Fi P2P network, such as its status.
