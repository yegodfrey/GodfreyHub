# NotificationRequest.NotificationLongTextContent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationRequest.NotificationLongTextContent

Constructs notifications that include long text. The long text contains a maximum of 1024 characters. 

This class is used with [NotificationContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationcontent-0000001054678842) and [NotificationRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854). Example code: 
    
    NotificationRequest request = new NotificationRequest();
     NotificationLongTextContent longTextContent = new NotificationLongTextContent();
     NotificationContent notificationContent = new NotificationContent(longTextContent);
     request.setContent(notificationContent);

Sets the brief text to be included in a long text notification. 

The brief text is a summary of a long text notification and is displayed in the first line of the notification. Similar to [setAdditionalText(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationlongtextcontent-0000001054238841#ZH-CN_TOPIC_0000001054238841__setAdditionalText-java_lang_String-), the font of the brief text is also smaller than the notification text. 

The positions where the brief text and additional text will display may conflict. If both texts are set, only the additional text will be displayed.
