#### [h2]onProgressChanged

void onProgressChanged​([Rating](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rating-0000001060039127) rating, int progress, boolean fromUser)

Notifies change events of a rating. 

This method notifies the change of the number of rating items displayed on the rating.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
rating  |  Indicates the rating to listen for.  
progress  |  Indicates the progress value to set.  
fromUser  |  Indicates whether the change is made by users. The value is true if the change is made by users; the value is false otherwise.  
  
**Since:**

4
