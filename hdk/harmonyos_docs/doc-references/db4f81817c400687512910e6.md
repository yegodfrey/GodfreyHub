# LineNumberReader

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.Reader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435) |---|---[java.io.BufferedReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bufferedreader-0000001054199702) |---|---|---java.io.LineNumberReader
    
    public class LineNumberReader
    extends [BufferedReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bufferedreader-0000001054199702)  
  
---  
A buffered character-input stream that keeps track of line numbers. This class defines methods [setLineNumber(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linenumberreader-0000001054439719#ZH-CN_TOPIC_0000001054439719__setLineNumber-int-) and [getLineNumber()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linenumberreader-0000001054439719#ZH-CN_TOPIC_0000001054439719__getLineNumber--) for setting and getting the current line number respectively. 

By default, line numbering begins at 0. This number increments at every line terminator as the data is read, and can be changed with a call to setLineNumber(int). Note however, that setLineNumber(int) does not actually change the current position in the stream; it only changes the value that will be returned by getLineNumber(). 

A line is considered to be _terminated_ by any one of a line feed ('\n'), a carriage return ('\r'), or a carriage return followed immediately by a linefeed.

**Since:**

JDK1.1
