# Overview  
  
Provides basic classes for developing input method applications. [InputMethodAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputmethodability-0000001060388838) is a base class ready to be inherited and implemented. This class initiates system operations on the input method application. [KeyboardDelegate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyboarddelegate-0000001060519199) represents a delegate interface needs to be overridden and implemented for callback services. You can use [KeyboardController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyboardcontroller-0000001060039153) to switch between and hide input method keyboards, set keyboard layout, and obtain and set the keyboard display mode. You can use [TextInputClient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textinputclient-0000001060837294) to submit, delete, modify, and obtain content in the edit box on the client.
