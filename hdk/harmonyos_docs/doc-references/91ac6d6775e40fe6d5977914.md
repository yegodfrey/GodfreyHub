# Overview  
  
Provides download service-related classes and interfaces. 

This package allows you to configure and operate download sessions using either HTTP or HTTPS. You can perform basic download task operations such as adding or removing a task, query download information, and set download session listeners. 

With this package, you can create a remote download session on another device in the ohos network so that it can download data for the local device without consuming local network and storage resources. The remote download sessions support both HTTP and HTTPS. You can also query and remove created sessions.

3
