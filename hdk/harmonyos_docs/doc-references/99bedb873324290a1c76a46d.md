# EventHandlerEx  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.eventhandler.EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858) |---|---ohos.interwork.eventhandler.EventHandlerEx
    
    public class EventHandlerEx
    extends [EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858)  
  
---  
Allows you to send and process [InnerEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/innerevent-0000001054358825) and Runnable objects on asynchronous threads. 

Each EventHandlerEx instance is bound to a thread, and the thread has an event queue. The thread cyclically retrieves events from the event queue and dispatches the events to the EventHandlerEx for processing. The EventHandlerEx delivers an event or a Runnable task to the thread's event queue and executes the event or task when it comes out of the event queue. 

You can use an EventHandlerEx to dispatch and process events and Runnable objects among different threads and to schedule events or Runnable objects to be processed at a certain interval. 

You can use methods provided in this class to send a synchronous or asynchronous event, delay the processing of an event, and set the event priority. 

You need to override the [EventHandler.processEvent(ohos.eventhandler.InnerEvent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858#ZH-CN_TOPIC_0000001054518858__processEvent-ohos_eventhandler_InnerEvent-) method to process events.
