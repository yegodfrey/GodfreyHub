An int value that may be updated atomically. See the [java.util.concurrent.atomic](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054558619) package specification for description of the properties of atomic variables. An AtomicInteger is used in applications such as atomically incremented counters, and cannot be used as a replacement for an [Integer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/integer-0000001054119702). However, this class does extend Number to allow uniform access by tools and utilities that deal with numerically-based classes.**Since:** 1.5Constructor Summary Constructor | Description
