# Overview  
  
Provides basic Bluetooth capabilities. 

The related classes are as follows: 

    * [BluetoothHost](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothhost-0000001054440075): Performs Bluetooth operations on a device, such as enabling and disabling Bluetooth.
    * [BluetoothDeviceClass](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothdeviceclass-0000001054838742): Provides Bluetooth device capabilities.
    * [ProfileBase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/profilebase-0000001054358767): Represents a basic Bluetooth profile class and provides public profile statuses and interfaces.
    * [A2dpSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsource-0000001054678757): Manages the A2DP source profile.
    * [A2dpSink](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsink-0000001054238787): Manages the A2DP sink profile.
    * [HandsFreeAudioGateway](https://developer.harmonyos.com/cn/docs/documentation/doc-references/handsfreeaudiogateway-0000001054518802): Manages [HandsFreeAudioGateway](https://developer.harmonyos.com/cn/docs/documentation/doc-references/handsfreeaudiogateway-0000001054518802) (HFP AG) profiles.
