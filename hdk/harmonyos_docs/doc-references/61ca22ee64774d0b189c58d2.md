# 日志打印

#### 导入模块

无需导入。

#### console.debug

debug(message: string): void

打印debug级别的日志信息。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
message | string | 是 | 表示要打印的文本信息。  
  
#### console.log

log(message: string): void

打印debug级别的日志信息。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
message | string | 是 | 表示要打印的文本信息。  
  
#### console.info

info(message: string): void

打印info级别的日志信息。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
message | string | 是 | 表示要打印的文本信息。  
  
#### console.warn

warn(message: string): void

打印warn级别的日志信息。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
message | string | 是 | 表示要打印的文本信息。  
  
#### console.error

error(message: string): void

打印error级别的日志信息。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
message | string | 是 | 表示要打印的文本信息。  
  
#### 示例
    
    export default {    
      clickConsole(){        
        var versionCode = 1;        
        console.info('Hello World. The current version code is ' + versionCode);        
        console.log(`versionCode: ${versionCode}`);        
                
            
      }
    }
