# DoubleFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface DoubleFunction<R>  
  
---  
Represents a function that accepts a double-valued argument and produces a result. This is the double-consuming primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [apply(double)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublefunction-0000001054358605#ZH-CN_TOPIC_0000001054358605__apply-double-).

**Since:**

1.8
