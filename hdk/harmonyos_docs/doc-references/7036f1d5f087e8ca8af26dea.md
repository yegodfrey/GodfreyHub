UnicodeSetIterator iterates over the contents of a UnicodeSet. It iterates over either code points or code point ranges. After all code points or ranges have been returned, it returns the multicharacter strings of the UnicodSet, if any. To iterate over code points and multicharacter strings, use a loop like this: 
    
    for (UnicodeSetIterator it = new UnicodeSetIterator(set); it.next();) {
       processString(it.getString());
     }
     

To iterate over code point ranges, use a loop like this: 
    
    for (UnicodeSetIterator it = new UnicodeSetIterator(set); it.nextRange();) {
       if (it.codepoint != UnicodeSetIterator.IS_STRING) {
         processCodepointRange(it.codepoint, it.codepointEnd);
       } else {
         processString(it.getString());
       }
     }
