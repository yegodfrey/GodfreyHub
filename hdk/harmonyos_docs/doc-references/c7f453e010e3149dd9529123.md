Manages Bluetooth on a device, such as enabling and disabling Bluetooth. The [BluetoothHost#getDefaultHost](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothhost-0000001054440075#ZH-CN_TOPIC_0000001054440075__getDefaultHost-ohos_app_Context-) method can be used to obtain a [BluetoothHost](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothhost-0000001054440075) instance, which can be used to perform Bluetooth operations on a device. You can use [enableBt()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothhost-0000001054440075#ZH-CN_TOPIC_0000001054440075__enableBt--) to enable Bluetooth, [disableBt()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothhost-0000001054440075#ZH-CN_TOPIC_0000001054440075__disableBt--) to disable Bluetooth, [startBtDiscovery()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothhost-0000001054440075#ZH-CN_TOPIC_0000001054440075__startBtDiscovery--) to start a device scan, and [cancelBtDiscovery()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothhost-0000001054440075#ZH-CN_TOPIC_0000001054440075__cancelBtDiscovery--) to cancel a device scan. **Since:** 1 Field Summary Modifier and Type | Field | Description
