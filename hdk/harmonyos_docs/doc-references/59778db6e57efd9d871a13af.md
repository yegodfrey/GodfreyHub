# IWallpaperColorsChangedListener
    
    public interface IWallpaperColorsChangedListener  
  
---  
Provides the listener for wallpaper color changes. 

When wallpaper color changes, [onWallpaperColorsChanged(ohos.miscservices.wallpaper.WallpaperColorsCollection, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iwallpapercolorschangedlistener-0000001054440241#ZH-CN_TOPIC_0000001054440241__onWallpaperColorsChanged-ohos_miscservices_wallpaper_WallpaperColorsCollection-int-) will be called to notify your application of the changes.

#### [h2]onWallpaperColorsChanged

void onWallpaperColorsChanged​([WallpaperColorsCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wallpapercolorscollection-0000001054518968) colors, int wallpaperType)

Called when wallpaper color changes. You can use this method to customize follow-up operations when your application is notified of the change. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
colors  |  Indicates new color information.  
wallpaperType  |  Indicates the wallpaper type. The value can be [WallpaperController#WALLPAPER_SYSTEM](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wallpapercontroller-0000001054678956#ZH-CN_TOPIC_0000001054678956__WALLPAPER_SYSTEM), [WallpaperController#WALLPAPER_LOCK](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wallpapercontroller-0000001054678956#ZH-CN_TOPIC_0000001054678956__WALLPAPER_LOCK), or the bitwise OR result of them.
