# PhoneNumberFormattingTextObserver

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.telephony.PhoneNumberFormattingTextObserver
    
    public class PhoneNumberFormattingTextObserver

    implements [Text.TextObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/text_textobserver-0000001054558713)

Provides an observer to listen for phone number changes in the text component. 

If a new character is detected, the phone number will be formatted based on the country/region code.
