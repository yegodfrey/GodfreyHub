# DataBinding

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.abilityjet.databinding.DataBinding
    
    public abstract class DataBinding
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
  
A base class of automatically generated binding code that implements binding between [ComponentContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentcontainer-0000001054120043) and [ActiveData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/activedata-0000001054120017) objects.

When a ComponentContainer or ActiveData object is modified, the DataBinding object automatically modifies the object bound to the ComponentContainer or ActiveData. For example, if you modified the attribute of a ComponentContainer, DataBinding will synchronize the attribute value to the ActiveData object bound to the ComponentContainer. Similarly, if the attribute value of an ActiveData object is changed, the attribute value of the bound ComponentContainer will also be updated.

To enable the data binding feature, you must first add "dataBindingEnable true" to the **build.gradle** file of the current module as follows:
    
    ohos {
         ...
         buildTypes {
             debug {
                 dataBindingEnabled true
             }
             ...
         }
     }
     
     

Before using the DataBinding class, use an ActiveData object to define the data to observe, the data type to bind, and the set() and get() methods. The sample code snippet is as follows:
    
    import ohos.aafwk.abilityjet.activedata.ActiveData;
    
     public class FruitComponentModel {
         private ActiveData<String> price;
    
         public ActiveData<String> getPrice() {
             return price;
         }
    
         public void setPrice(ActiveData<String> price) {
             this.price = price;
         }
     }
     
     

Then, declare the data to be bound by DataBinding in the layout file. Example declaration:
    
    <?xml version="1.0" encoding="utf-8"?>
      <DirectionalLayout xmlns:ohos="http://schemas.huawei.com/res/ohos"
            ohos:id="$+id:root"
            ohos:width="match_parent"
            ohos:height="match_parent"
            ohos:orientation="vertical">
    
        <Text
            ohos:id="$+id:fruit_text"
            ohos:width="match_parent"
            ohos:height="300"
            ohos:text="${apple.price}"
            ohos:text_color="#FF555555"
            ohos:text_size="50"
            ohos:text_alignment="center"/>
        <binddata>
            <variable class="com.example.fruitstore.FruitComponentModel" name="apple"/>
        </binddata>
      </DirectionalLayout>
    
    

In this example, a binding is declared in fruit.xml and the system will automatically generate a FruitBinding class after the compilation. You can call the [DataBindingUtil#createBinding(int, Context, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databindingutil-0000001054358669#ZH-CN_TOPIC_0000001054358669__createBinding-int-ohos_app_Context-java_lang_String-) method to obtain a FruitBinding object and call [initComponent(ohos.agp.components.ComponentContainer)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databinding-0000001054678690#ZH-CN_TOPIC_0000001054678690__initComponent-ohos_agp_components_ComponentContainer-) and [setLifecycle(ohos.aafwk.ability.Lifecycle)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databinding-0000001054678690#ZH-CN_TOPIC_0000001054678690__setLifecycle-ohos_aafwk_ability_Lifecycle-) to initialize the object. The obtained FruitBinding object then calls the method defined in FruitComponentModel to bind it to an ActiveData object. Example code:
    
    public class FruitSlice extends AbilitySlice {
         private static final HiLogLabel LABEL_LOG = new HiLogLabel(3, 0xD001100, "FruitSlice");
    
         private FruitBinding binding;
    
         @Override
         public onStart(Intent intent) {
             super.onStart(intent);
             ComponentContainer componentContainer =
                 (ComponentContainer) LayoutScatter.getInstance(this).parse(ResourceTable.Layout_fruit, null, false);
             if (!(componentContainer instanceof ComponentContainer)) {
                 return;
             }
             super.setUIContent(componentContainer);
    
             try {
                 binding = DataBindingUtil.createBinding(ResourceTable.Layout_fruit, getContext(), "ohos.myapplication");
             } catch (IllegalArgumentException | IOException exception) {
                 HiLog.info(LABEL_LOG, exception.toString());
             }
    
             if(binding != null) {
                 binding.initComponent(componentContainer);
                 binding.setLifecycle(getLifecycle());
                 ActiveData<String> price = new ActiveData<>();
                 price.setData("7.23");
                 FruitComponentModel apple = new FruitComponentModel();
                 apple.setPrice(price);
                 binding.setApple(apple);
             }
         }
     }

#### [h2]setLifecycle

public void setLifecycle​([Lifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967) lifecycle)

Sets the lifecycle of the bound object.

The lifecycle of the bound object is required because the data of the object can be updated only when it is visible (either in the ACTIVE or INACTIVE state). You are advised to set the lifecycle when initializing the ability slice that hosts the bound object.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
lifecycle | Indicates the lifecycle of the bound object.
