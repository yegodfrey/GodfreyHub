#### [h2]STATE_DEFAULT

public static final int STATE_DEFAULT

A given caller should use its default security check. This mode is not commonly used. It should only be used with appop permissions and must be explicitly checked and handled by the caller. 

**See Also:**

[Constant Field Values](https://developer.harmonyos.com/cn/docs/documentation/doc-references/constant-values-0000001054359004#ZH-CN_TOPIC_0000001054359004__ohos_security_permission_PermissionState_STATE_DEFAULT)
