# Preferences  
      
    public interface Preferences  
  
---  
Provides interfaces to obtain and modify preference data. 

The preference data is stored in a file, which matches only one [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793) instance in the memory. You can use [DatabaseHelper.getPreferences(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databasehelper-0000001054678767#ZH-CN_TOPIC_0000001054678767__getPreferences-java_lang_String-) to obtain the [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793) instance matching the file that stores preference data, and use [DatabaseHelper.removePreferencesFromCache(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databasehelper-0000001054678767#ZH-CN_TOPIC_0000001054678767__removePreferencesFromCache-java_lang_String-) to remove the [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793) instance from the memory.
