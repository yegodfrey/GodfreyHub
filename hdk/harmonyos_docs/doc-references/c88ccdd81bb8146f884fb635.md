# FontFamily  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.text.FontFamily
    
    public class FontFamily
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a set of fonts ([RawFont](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfont-0000001172398162)) of different styles to create [Font](https://developer.harmonyos.com/cn/docs/documentation/doc-references/font-0000001054238751). 

Ensure that the raw fonts added to a [FontFamily](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fontfamily-0000001172238186) belong to the same family, and they are only different in style (such as weight and italic).
