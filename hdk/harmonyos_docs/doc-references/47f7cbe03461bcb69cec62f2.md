public ListValue​(float[] values, long startTime, int timeStep, java.lang.String current)

**Parameters:**

Parameter Name | Parameter Description  
---|---  
values  |  Indicates the array of list values. The array length range is [0, 48].  
startTime  |  Indicates the start time, which is a timestamp (in milliseconds) and is rounded up to the half hour or full hour (for example, 14:16 is rounded up to 14:30).  
timeStep  |  Indicates the time step, which is (0, 48]*30 minutes.  
current  |  Indicates a string that represents the current value. The length range is [0, 16].
