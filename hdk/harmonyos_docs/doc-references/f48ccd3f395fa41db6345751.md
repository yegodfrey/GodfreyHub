# SecurityPermission  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.security.Permission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permission-0000001054238525) |---|---[java.security.BasicPermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicpermission-0000001054558523) |---|---|---java.security.SecurityPermission

    extends [BasicPermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicpermission-0000001054558523)  
  
---  
This class is for security permissions. A SecurityPermission contains a name (also referred to as a "target name") but no actions list; you either have the named permission or you don't. 

The target name is the name of a security configuration parameter (see below). Currently the SecurityPermission object is used to guard access to the Policy, Security, Provider, Signer, and Identity objects. 

The following table lists all the possible SecurityPermission target names, and for each provides a description of what the permission allows and a discussion of the risks of granting code the permission. 

The following permissions have been superseded by newer permissions or are associated with classes that have been deprecated: [Identity](https://developer.harmonyos.com/cn/docs/documentation/doc-references/identity-0000001054439809), [IdentityScope](https://developer.harmonyos.com/cn/docs/documentation/doc-references/identityscope-0000001054199796), [Signer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/signer-0000001054119786). Use of them is discouraged. See the applicable classes for more information.
