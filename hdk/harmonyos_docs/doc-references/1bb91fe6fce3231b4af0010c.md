# Overview  
  
Implements animation on a UI. 

This package includes the AnimatorValue, AnimatorProperty, and AnimatorGroup classes. AnimatorValue generates a sequence to customize animators. AnimatorProperty sets the property animator to achieve the movement, rotation, and scaling of a control. AnimatorGroup customizes an animator set and configures animators to run in series or in parallel.
