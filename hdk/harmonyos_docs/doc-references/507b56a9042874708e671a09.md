# Overview  
  
Provides quality attribute classes, such as reliability and testability, including HiLog, HiTrace, and Debug. 

The HiLog class is used for service debugging and maintenance. Logs are output on applications based on the specified log type, level, and privacy parameter setting. 

The HiTrace class is used for performance debugging and maintenance of service flows. A trace task is enabled for applications to trace a service call chain, including cross-thread, -process, and -device service calls. 

The Debug class is used for applications to obtain their memory information for service debugging and maintenance.
