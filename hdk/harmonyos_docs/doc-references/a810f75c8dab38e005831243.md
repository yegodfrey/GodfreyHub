Base class for letting a background agent to publish reminders on behalf of a third-party application. 

Third-party applications can use this class to create scheduled reminders, including those for countdown timers, calendar events, and active alarm clocks. 

After this class is called, the timing and pop-up notification functions of the calling application will be performed by the system service agent in the background, even when the application is frozen or exits. You can call the [ReminderRequest#setIntentAgent(String, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419#ZH-CN_TOPIC_0000001170214419__setIntentAgent-java_lang_String-java_lang_String-) method to specify whether to start the application after the pop-up notification is taped.

#### [h2]setSnoozeTimes

public [ReminderRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419) setSnoozeTimes​(int snoozeTimes)

Sets the number of snooze times for this reminder. 
    * If the value of snoozeTimes is less than or equal to 0, this reminder is a one-shot reminder and will not be snoozed. 
    * If the value of snoozeTimes is greater than 0, for example, 3, this reminder will be snoozed three times after the first alarm, that is, this reminder will be triggered for four times.
    * This method does not take effect on the reminders for countdown timers. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
snoozeTimes  |  Indicates the number of times that the reminder will be snoozed.  
  
**Returns:**

Returns this ReminderRequest instance.

public [ReminderRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419) setTimeInterval​(long timeIntervalInSeconds)

Sets the snooze interval for this reminder, in seconds. The default value is 0. 
    1. The minimum snooze interval is 5 minutes. If the snooze interval is set to a value greater than 0 and less than 5 minutes, the system converts it to 5 minutes by default.
