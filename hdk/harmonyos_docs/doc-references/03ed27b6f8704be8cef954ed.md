SSLParameters [java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---javax.net.ssl.SSLParameters  
      
    public class SSLParameters
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Encapsulates parameters for an SSL/TLS connection. The parameters are the list of ciphersuites to be accepted in an SSL/TLS handshake, the list of protocols to be allowed, the endpoint identification algorithm during SSL/TLS handshaking, the Server Name Indication (SNI), the algorithm constraints and whether SSL/TLS servers should request or require client authentication, etc.  SSLParameters can be created via the constructors in this class. Objects can also be obtained using the getSSLParameters() methods in [SSLSocket#getSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsocket-0000001054838618#ZH-CN_TOPIC_0000001054838618__getSSLParameters--) and [SSLServerSocket#getSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslserversocket-0000001054558665#ZH-CN_TOPIC_0000001054558665__getSSLParameters--) and [SSLEngine#getSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslengine-0000001054199936#ZH-CN_TOPIC_0000001054199936__getSSLParameters--) or the [SSLContext#getDefaultSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslcontext-0000001054119920#ZH-CN_TOPIC_0000001054119920__getDefaultSSLParameters--) and [SSLContext#getSupportedSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslcontext-0000001054119920#ZH-CN_TOPIC_0000001054119920__getSupportedSSLParameters--) methods in SSLContext.  SSLParameters can be applied to a connection via the methods [SSLSocket#setSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsocket-0000001054838618#ZH-CN_TOPIC_0000001054838618__setSSLParameters-javax_net_ssl_SSLParameters-) and [SSLServerSocket#setSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslserversocket-0000001054558665#ZH-CN_TOPIC_0000001054558665__setSSLParameters-javax_net_ssl_SSLParameters-) and [SSLEngine#setSSLParameters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslengine-0000001054199936#ZH-CN_TOPIC_0000001054199936__setSSLParameters-javax_net_ssl_SSLParameters-).  For example: 
    
    SSLParameters p = sslSocket.getSSLParameters();
         p.setProtocols(new String[] { "TLSv1.2" });
         p.setCipherSuites(
             new String[] { "TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256", ... });
         p.setApplicationProtocols(new String[] {"h2", "http/1.1"});
         sslSocket.setSSLParameters(p);
