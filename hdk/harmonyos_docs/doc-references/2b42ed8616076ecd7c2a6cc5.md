Provides access to secure elements on a device. You can use the interfaces provided by this class to obtain all secure elements and their names, check whether the secure element is available, and enable a session on the secure element. After that, you can send APDU commands to secure elements. **Since:** 1Nested Class Summary Modifier and Type | Class | Description
