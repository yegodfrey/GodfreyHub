Method Detail [h2]onSoftKeyBoardShowModeChanged void onSoftKeyBoardShowModeChanged​([SoftKeyBoardController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/softkeyboardcontroller-0000001054199968) controller, int showMode) Called when the show/hide mode of the soft keyboard changes. When an input box gains the cursor focus, the default show/hide mode of the soft keyboard is [AccessibleAbility#SHOW_MODE_AUTO](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__SHOW_MODE_AUTO) and the soft key board is shown properly. In this case, you can use [AccessibleAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663) to set the show/hide mode of the soft keyboard to [AccessibleAbility#SHOW_MODE_HIDE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__SHOW_MODE_HIDE). Then, the soft keyboard will be hidden. **Parameters:** Parameter Name | Parameter Description  
---|---  
controller  |  Indicates the soft keyboard controller.  
showMode  |  Indicates the show/hide mode of the soft keyboard.
