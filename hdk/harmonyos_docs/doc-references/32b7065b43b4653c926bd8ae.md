# Position

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.media.image.common.Position
    
    public class Position
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Describes location information of image pixels in a two-dimensional coordinate system. 

The location information includes abscissa and ordinate values of pixels.
