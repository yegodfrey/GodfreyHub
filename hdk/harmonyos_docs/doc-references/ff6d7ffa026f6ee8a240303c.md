#### [h2]getNfcState

public int getNfcState​()

Obtains the NFC status. 

The NFC status can be any of the following: 

    * [STATE_OFF](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfccontroller-0000001054518974#ZH-CN_TOPIC_0000001054518974__STATE_OFF): Indicates that NFC is disabled. 
    * [STATE_TURNING_ON](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfccontroller-0000001054518974#ZH-CN_TOPIC_0000001054518974__STATE_TURNING_ON): Indicates that NFC is being enabled. 
    * [STATE_ON](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfccontroller-0000001054518974#ZH-CN_TOPIC_0000001054518974__STATE_ON): Indicates that NFC is enabled. 
    * [STATE_TURNING_OFF](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfccontroller-0000001054518974#ZH-CN_TOPIC_0000001054518974__STATE_TURNING_OFF): Indicates that NFC is being disabled.

**Returns:**
