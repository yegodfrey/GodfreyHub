# Overview  
  
Provides permission-related interfaces and information, such as permission group information.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[Permission.OnRequestPermissionsResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permission_onrequestpermissionsresult-0000001060996906) | This change is effective since API version 4.  
  
#### Class Summary

Class | Description  
---|---  
[Permission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permission-0000001054558977) | Provides methods for permission management, such as granting, revoking, and requesting permissions.  
[PermissionDef](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permissiondef-0000001054238975) | Provides known system security permissions.  
[PermissionFlags](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permissionflags-0000001054678945) | Defines the set of markup states for permissions.  
[PermissionGroupDef](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permissiongroupdef-0000001054838930) | Provides known system security permission groups.  
[PermissionState](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permissionstate-0000001054358964) | Defines a collection used to represent the grant status of permissions.  
  
#### Enum Summary

Enum | Description  
---|---  
[PermissionAvailableScope](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permissionavailablescope-0000001138633165) | Defines the application scope of the permission.  
[PermissionGrantMode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permissiongrantmode-0000001091611356) | Defines the permission authorization mode.  
  
#### Annotation Types Summary

Annotation Type | Description  
---|---  
[NeedsPermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080) | Indicates that one or more permissions are required for invoking an interface.  
[PermissionLevel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permissionlevel-0000001091771026) | Indicates the protection level of a permission.
