Signals that a malformed string in [modified UTF-8](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datainput-0000001054119684#ZH-CN_TOPIC_0000001054119684__modified-utf-8) format has been read in a data input stream or by any class that implements the data input interface. See the [DataInput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datainput-0000001054119684#ZH-CN_TOPIC_0000001054119684__modified-utf-8) class description for the format in which modified UTF-8 strings are read and written.**Since:** JDK1.0**See Also:** [DataInput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datainput-0000001054119684), [DataInputStream.readUTF(java.io.DataInput)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datainputstream-0000001054838384#ZH-CN_TOPIC_0000001054838384__readUTF-java_io_DataInput-), [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426), Constructor Summary Constructor | Description
