An optionally-bounded [BlockingDeque](https://developer.harmonyos.com/cn/docs/documentation/doc-references/blockingdeque-0000001054678575) based on linked nodes. 

The optional capacity bound constructor argument serves as a way to prevent excessive expansion. The capacity, if unspecified, is equal to [Integer#MAX_VALUE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/integer-0000001054119702#ZH-CN_TOPIC_0000001054119702__MAX_VALUE). Linked nodes are dynamically created upon each insertion unless this would bring the deque above capacity. 

Most operations run in constant time (ignoring time spent blocking). Exceptions include [remove](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkedblockingdeque-0000001054678614#ZH-CN_TOPIC_0000001054678614__remove-java_lang_Object-), [removeFirstOccurrence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkedblockingdeque-0000001054678614#ZH-CN_TOPIC_0000001054678614__removeFirstOccurrence-java_lang_Object-), [removeLastOccurrence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkedblockingdeque-0000001054678614#ZH-CN_TOPIC_0000001054678614__removeLastOccurrence-java_lang_Object-), [contains](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkedblockingdeque-0000001054678614#ZH-CN_TOPIC_0000001054678614__contains-java_lang_Object-), [iterator.remove()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkedblockingdeque-0000001054678614#ZH-CN_TOPIC_0000001054678614__iterator--), and the bulk operations, all of which run in linear time. 

This class and its iterator implement all of the optional methods of the [Collection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563) and [Iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913) interfaces. 

This class is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).

#### [h2]toArray

public <T> T[] toArray​(T[] a)

Returns an array containing all of the elements in this deque, in proper sequence; the runtime type of the returned array is that of the specified array. If the deque fits in the specified array, it is returned therein. Otherwise, a new array is allocated with the runtime type of the specified array and the size of this deque. 

If this deque fits in the specified array with room to spare (i.e., the array has more elements than this deque), the element in the array immediately following the end of the deque is set to null. 

Like the [toArray()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkedblockingdeque-0000001054678614#ZH-CN_TOPIC_0000001054678614__toArray--) method, this method acts as bridge between array-based and collection-based APIs. Further, this method allows precise control over the runtime type of the output array, and may, under certain circumstances, be used to save allocation costs. 

Suppose x is a deque known to contain only strings. The following code can be used to dump the deque into a newly allocated array of String: 
    
    String[] y = x.toArray(new String[0]);

Note that toArray(new Object[0]) is identical in function to toArray().
