# ObjectOutput  
      
    public interface ObjectOutput
    extends [DataOutput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataoutput-0000001054439713), [AutoCloseable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/autocloseable-0000001054518454)  
  
---  
ObjectOutput extends the DataOutput interface to include writing of objects. DataOutput includes methods for output of primitive types, ObjectOutput extends that interface to include objects, arrays, and Strings.

**Since:**

JDK1.1

**See Also:**

[InputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420), [ObjectOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectoutputstream-0000001054678434), [ObjectInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectinputstream-0000001054199706)
