#### [h2]connect

public void connect​([PipedReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pipedreader-0000001054119692) snk) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Connects this piped writer to a receiver. If this object is already connected to some other piped reader, an IOException is thrown. 

If snk is an unconnected piped reader and src is an unconnected piped writer, they may be connected by either the call: 
    
    src.connect(snk)

or the call: 
    
    snk.connect(src)

The two calls have the same effect. 

**Parameters:**

---|---  
snk  |  the piped reader to connect to.

#### [h2]write

public void write​(char[] cbuf, int off, int len) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Writes len characters from the specified character array starting at offset off to this piped output stream. This method blocks until all the characters are written to the output stream.
