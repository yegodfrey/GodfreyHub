# IDeviceStateCallback
    
    public interface IDeviceStateCallback  
  
---  
Provides callbacks that can be invoked when the state of a device on the distributed network changes to online or offline. 

Before calling [DeviceManager#registerDeviceStateCallback(IDeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__registerDeviceStateCallback-ohos_distributedschedule_interwork_IDeviceStateCallback-) to register device state callbacks, you must first create a class to implement this interface and override the [IDeviceStateCallback#onDeviceOffline(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831#ZH-CN_TOPIC_0000001054238831__onDeviceOffline-java_lang_String-int-) and [IDeviceStateCallback#onDeviceOnline(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831#ZH-CN_TOPIC_0000001054238831__onDeviceOnline-java_lang_String-int-) methods. After device state callbacks are registered, [IDeviceStateCallback#onDeviceOnline(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831#ZH-CN_TOPIC_0000001054238831__onDeviceOnline-java_lang_String-int-) will be called when a device on the distributed network is online; [IDeviceStateCallback#onDeviceOffline(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831#ZH-CN_TOPIC_0000001054238831__onDeviceOffline-java_lang_String-int-) will be called when a device goes offline; and your application will be notified of the network ID and device type of the device that goes online or offline. If your application no longer needs to receive these notifications, you can call [DeviceManager#unregisterDeviceStateCallback(IDeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__unregisterDeviceStateCallback-ohos_distributedschedule_interwork_IDeviceStateCallback-) to unregister all previously registered callbacks.
