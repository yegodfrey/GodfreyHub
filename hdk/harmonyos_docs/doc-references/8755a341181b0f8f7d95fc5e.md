Notifies a dataset subscriber of detected dataset changes. 

This class extends the [Publisher](https://developer.harmonyos.com/cn/docs/documentation/doc-references/publisher-0000001054678730) class of the [DataSetSubscriber](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datasetsubscriber-0000001054518742) type. It is used to notify the dataset subscriber when the dataset changes or the dataset is invalidated.
