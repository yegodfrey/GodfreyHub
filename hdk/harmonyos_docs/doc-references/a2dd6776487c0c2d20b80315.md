# IntBinaryOperator
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface IntBinaryOperator  
  
---  
Represents an operation upon two int-valued operands and producing an int-valued result. This is the primitive type specialization of [BinaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/binaryoperator-0000001054119953) for int. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsInt(int,int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intbinaryoperator-0000001054119884#ZH-CN_TOPIC_0000001054119884__applyAsInt-int-int-).
