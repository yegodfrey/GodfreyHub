禁用控制 组件是否可交互，可交互状态下响应[点击事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-universal-events-click-0000001333800605)、[触摸事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-universal-events-touch-0000001281001286)、[拖拽事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-universal-events-drag-drop-0000001333641121)、[按键事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-universal-events-key-0000001333321249)、[焦点事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-universal-focus-event-0000001281480746)和[鼠标事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-universal-mouse-key-0000001281361166)。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172413.85235445135680004490205155041698:50001231000000:2800:08CDBBBFDB089BB048A8CE85C5CF481836198E632B80F4EA26C09325D15B3592.png?needInitFileName=true?needInitFileName=true?needInitFileName=true) 从API Version 7开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。 属性 名称 | 参数类型 | 默认值 | 描述  
---|---|---|---  
enabled | boolean | true | 值为true表示组件可交互，响应点击等操作。 值为false表示组件不可交互，不响应点击等操作。 默认值：true  
示例
    
    // xxx.ets
    @Entry
    @Component
    struct EnabledExample {
      build() {
        Flex({ justifyContent: FlexAlign.SpaceAround }) {
          // 点击没有反应
          Button('disable').enabled(false).backgroundColor(0x317aff).opacity(0.4)
          Button('enable').backgroundColor(0x317aff)
        }
        .width('100%')
        .padding({ top: 5 })
      }
    }
