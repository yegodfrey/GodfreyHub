# AbstractSelectableChannel  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.nio.channels.spi.AbstractInterruptibleChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractinterruptiblechannel-0000001054238497) |---|---[java.nio.channels.SelectableChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/selectablechannel-0000001054838446) |---|---|---java.nio.channels.spi.AbstractSelectableChannel

Base implementation class for selectable channels. 

This class defines methods that handle the mechanics of channel registration, deregistration, and closing. It maintains the current blocking mode of this channel as well as its current set of selection keys. It performs all of the synchronization required to implement the [SelectableChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/selectablechannel-0000001054838446) specification. Implementations of the abstract protected methods defined in this class need not synchronize against other threads that might be engaged in the same operations. 

**Since:**

1.4

Registers this channel with the given selector, returning a selection key. 

This method first verifies that this channel is open and that the given initial interest set is valid. 

If this channel is already registered with the given selector then the selection key representing that registration is returned after setting its interest set to the given value. 

Otherwise this channel has not yet been registered with the given selector, so the [AbstractSelector#register](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractselector-0000001054358486#ZH-CN_TOPIC_0000001054358486__register-java_nio_channels_spi_AbstractSelectableChannel-int-java_lang_Object-) method of the selector is invoked while holding the appropriate locks. The resulting key is added to this channel's key set before being returned.

protected abstract void implCloseSelectableChannel​() throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

This method is invoked by the [close](https://developer.harmonyos.com/cn/docs/documentation/doc-references/channel-0000001054838442#ZH-CN_TOPIC_0000001054838442__close--) method in order to perform the actual work of closing the channel. This method is only invoked if the channel has not yet been closed, and it is never invoked more than once. 

An implementation of this method must arrange for any other thread that is blocked in an I/O operation upon this channel to return immediately, either by throwing an exception or by returning normally.
