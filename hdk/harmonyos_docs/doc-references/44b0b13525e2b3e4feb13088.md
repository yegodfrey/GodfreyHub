# Group
    
    public interface Group  
  
---  
Defines a group, which stands for a set of tasks semantically. 

Multiple tasks can be associated with a group so that they can be considered as a whole. 

This interface must be used with methods in [TaskDispatcher](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794), such as [createDispatchGroup](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__createDispatchGroup--), [asyncGroupDispatch](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__asyncGroupDispatch-ohos_app_dispatcher_Group-java_lang_Runnable-), [groupDispatchWait](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__groupDispatchWait-ohos_app_dispatcher_Group-long-), and [groupDispatchNotify](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__groupDispatchNotify-ohos_app_dispatcher_Group-java_lang_Runnable-).
