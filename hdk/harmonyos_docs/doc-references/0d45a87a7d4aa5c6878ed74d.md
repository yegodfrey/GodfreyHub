# DoubleStream  
      
    public interface DoubleStream
    extends [BaseStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basestream-0000001054238641)<[Double](https://developer.harmonyos.com/cn/docs/documentation/doc-references/double-0000001054678413),[DoubleStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublestream-0000001054838596)>  
  
---  
A sequence of primitive double-valued elements supporting sequential and parallel aggregate operations. This is the double primitive specialization of [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656). 

The following example illustrates an aggregate operation using [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and [DoubleStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublestream-0000001054838596), computing the sum of the weights of the red widgets: 
    
    double sum = widgets.stream()
                             .filter(w -> w.getColor() == RED)
                             .mapToDouble(w -> w.getWeight())
                             .sum();
     

See the class documentation for [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and the package documentation for [java.util.stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621) for additional specification of streams, stream operations, stream pipelines, and parallelism.

#### [h2]sum

double sum​()

Returns the sum of elements in this stream. Summation is a special case of a [reduction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621#ZH-CN_TOPIC_0000001054358621__Reduction). If floating-point summation were exact, this method would be equivalent to: 
    
    return reduce(0, Double::sum);

The behavior of this operation is explicitly nondeterministic; it is free to select any element in the stream. This is to allow for maximal performance in parallel operations; the cost is that multiple invocations on the same source may not return the same result. (If a stable result is desired, use [findFirst()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublestream-0000001054838596#ZH-CN_TOPIC_0000001054838596__findFirst--) instead.)

**Returns:**

an OptionalDouble describing some element of this stream, or an empty OptionalDouble if the stream is empty

**See Also:**

[findFirst()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublestream-0000001054838596#ZH-CN_TOPIC_0000001054838596__findFirst--)

#### [h2]concat

static [DoubleStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublestream-0000001054838596) concat​([DoubleStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublestream-0000001054838596) a, [DoubleStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublestream-0000001054838596) b)

Creates a lazily concatenated stream whose elements are all the elements of the first stream followed by all the elements of the second stream. The resulting stream is ordered if both of the input streams are ordered, and parallel if either of the input streams is parallel. When the resulting stream is closed, the close handlers for both input streams are invoked. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
a  |  the first stream  
b  |  the second stream  
  
**Returns:**

the concatenation of the two input streams
