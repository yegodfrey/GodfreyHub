Enum Constant Detail [h2]WORD_WRAP public static final [TextLayout.LineBreakStrategy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout_linebreakstrategy-0000001172238190) WORD_WRAP Indicates the default line breaking strategy, which is simple and fast. According to this strategy, [HyphenationStrategy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout_hyphenationstrategy-0000001172398164) applies only when a line has a single word and that word is longer than the line width. This strategy may result in too large blank spaces at the end of a line if long words exist.  [h2]ADVANCED public static final [TextLayout.LineBreakStrategy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout_linebreakstrategy-0000001172238190) ADVANCED Indicates the advanced line breaking strategy, which complies with the settings of [HyphenationStrategy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout_hyphenationstrategy-0000001172398164). This strategy tries to break lines in different places so that each line looks relatively full (except the last line of a paragraph).  [h2]BALANCED public static final [TextLayout.LineBreakStrategy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout_linebreakstrategy-0000001172238190) BALANCED Indicates the balanced line breaking strategy, which complies with the settings of [HyphenationStrategy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout_hyphenationstrategy-0000001172398164). This strategy tries to break lines in different places so that the width of each line looks similar (including the last line of a paragraph).
