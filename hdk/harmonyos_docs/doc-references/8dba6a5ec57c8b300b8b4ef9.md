# Rawfile  
  
提供操作rawfile目录和rawfile文件的功能，包括遍历、打开、搜索、读取和关闭rawfile。

#### [h2]OH_ResourceManager_GetRawFileDescriptor()
    
    bool OH_ResourceManager_GetRawFileDescriptor (const RawFile * rawFile, RawFileDescriptor & descriptor )

**描述：**

基于offset(单位为int32_t)和文件长度打开rawfile，并获取rawfile文件描述符。打开的文件描述符被用于读取rawfile。

**参数：**

Name | 描述  
---|---

descriptor | 显示rawfile文件描述符，以及在HAP包中的起始位置和长度。  
  
**返回：**

返回true表示打开rawfile文件描述符成功，返回false表示rawfile不允许被访问。

**起始版本：**

8

#### [h2]OH_ResourceManager_ReleaseRawFileDescriptor()
    
    bool OH_ResourceManager_ReleaseRawFileDescriptor (const RawFileDescriptor & descriptor)

**描述：**

关闭rawfile文件描述符。已打开的文件描述符在使用完以后必须释放，防止文件描述符泄露。

**参数：**

Name | 描述  
---|---  
descriptor | 包含rawfile文件描述符，以及在HAP包中的起始位置和长度。  
  
**返回：**

返回true表示关闭文件描述符成功，返回false表示关闭文件描述符失败。

**起始版本：**

8

#### [h2]OH_ResourceManager_SeekRawFile()
    
    int OH_ResourceManager_SeekRawFile (const RawFile * rawFile, long offset, int whence )

**描述：**

基于指定的offset，在rawfile文件内搜索读写数据的位置。

**参数：**

Name | 描述  
---|---  
rawFile | 表示指向[RawFile](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfile-0000001360445118#ZH-CN_TOPIC_0000001445347080__gacf2dc23017812d7daf535b80f1a6ab27)的指针。  
offset | 表示指定的offset。  
whence | 读写位置，有以下场景: **0** : 读写位置为**offset** **1** : 读写位置为当前位置加上**offset** **2** : 读写位置为文件末尾(EOF)加上**offset** 。  
  
**返回：**

如果搜索成功返回新的读写位置，如果发生错误返回 **(long) -1** 。

**起始版本：**

8
