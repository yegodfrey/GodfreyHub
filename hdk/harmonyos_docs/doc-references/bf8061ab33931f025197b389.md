# CommonEventSubscribeInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.commonevent.CommonEventSubscribeInfo
    
    public final class CommonEventSubscribeInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Sets filter criteria of publishers, such as the device ID and permission, for subscribing to desired common events. 

After you set the filter criteria in a CommonEventSubscribeInfo object, you can pass it to the [CommonEventManager#subscribeCommonEvent(CommonEventSubscriber)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventmanager-0000001054238835#ZH-CN_TOPIC_0000001054238835__subscribeCommonEvent-ohos_event_commonevent_CommonEventSubscriber-) or [CommonEventManager#unsubscribeCommonEvent(CommonEventSubscriber)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventmanager-0000001054238835#ZH-CN_TOPIC_0000001054238835__unsubscribeCommonEvent-ohos_event_commonevent_CommonEventSubscriber-) method to subscribe to or unsubscribe from common events only from publishers meeting the filter criteria. 

For an ordered common event (common event that has a sending order), you can use the [setPriority(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscribeinfo-0000001054838790#ZH-CN_TOPIC_0000001054838790__setPriority-int-) method to set the subscriber priority, and the ordered common event will be sent first to a subscriber with a higher priority. Additionally, you can call [setThreadMode(ohos.event.commonevent.CommonEventSubscribeInfo.ThreadMode)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscribeinfo-0000001054838790#ZH-CN_TOPIC_0000001054838790__setThreadMode-ohos_event_commonevent_CommonEventSubscribeInfo_ThreadMode-) to specify the thread to run the callback method. For details, see [ThreadMode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscribeinfo_threadmode-0000001054200110).
