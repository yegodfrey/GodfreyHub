---  
Represents a supplier of boolean-valued results. This is the boolean-producing primitive specialization of [Supplier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/supplier-0000001054678599). There is no requirement that a new or distinct result be returned each time the supplier is invoked.  This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [getAsBoolean()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/booleansupplier-0000001054439911#ZH-CN_TOPIC_0000001054439911__getAsBoolean--). **Since:** 1.8**See Also:** [Supplier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/supplier-0000001054678599)Method Summary Modifier and Type | Method | Description
