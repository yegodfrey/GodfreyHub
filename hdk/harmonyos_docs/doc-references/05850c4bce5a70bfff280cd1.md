Displays brief information about another Ability. The following two roles are involved in the presentation of an AbilityForm depending on who provides or displays the content: 
                * **Supplier:** Provides the AbilityForm content to be displayed. The supplier controls the display content and logic. 
                  * The supplier uses the singleton pattern.
                  * One supplier can provide display contents for multiple clients.
                * **Client:** Displays the AbilityForm content. The client controls the AbilityForm layout. 
                  * A client can display the content provided by only one supplier.
                  * Clients display the AbilityForm on AbilitySlice objects. Multiple clients can display AbilityForm contents on the same AbilitySlice.
                  * Clients can use the layout component provided by an AbilitySlice to lay out AbilityForm instances displayed on the ability slice.
The typical interaction process for a client to display an AbilityForm for the first time is as follows: 
                1. The client calls the [AbilitySlice#acquireAbilityFormAsync(Intent, OnAcquiredCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireAbilityFormAsync-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilityForm_OnAcquiredCallback-) method to send an asynchronous request to the supplier through the AbilityForm framework to request the AbilityForm to be displayed.
                2. The AbilityForm framework calls back the [Ability#onCreateForm()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onCreateForm--) method on the supplier to notify the developer of the supplier to create an AbilityForm instance. You need to provide a layout file when creating an AbilityForm. You can also set attributes of components and register a listener for click events.
                3. The AbilityForm framework calls back the [OnAcquiredCallback#onAcquired(AbilityForm)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform_onacquiredcallback-0000001054199950#ZH-CN_TOPIC_0000001054199950__onAcquired-ohos_aafwk_ability_AbilityForm-) method on the client to notify the developer of the client in an asynchronous way that the AbilityForm display request has been processed.
                4. The developer of the client calls the [AbilityForm#getComponent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952#ZH-CN_TOPIC_0000001054199952__getComponent--) method to obtain the root component of the AbilityForm, and uses the layout method provided in AbilitySlice to inflate the AbilityForm content to the layout of the client.
The supplier provides the following functions: 
                * **Creating an AbilityForm:** After the developer of the client calls [AbilitySlice#acquireAbilityFormAsync(Intent, OnAcquiredCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireAbilityFormAsync-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilityForm_OnAcquiredCallback-) to send an asynchronous request to the supplier through the AbilityForm framework to request the AbilityForm to be displayed, the AbilityForm framework calls back the [Ability#onCreateForm()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onCreateForm--) method on the supplier to notify the developer of the supplier to create an AbilityForm instance. You need to provide a layout file when creating an AbilityForm. You can also set attributes of components and register a listener for click events.
                * **Setting component attributes:** The developer of the supplier can set attributes of components on the client by calling methods such as [AbilityForm#setText(int, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952#ZH-CN_TOPIC_0000001054199952__setText-int-java_lang_String-).
                * **Setting a click listener:** The developer of the supplier can call [AbilityForm#registerViewListener(int, ViewListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952#ZH-CN_TOPIC_0000001054199952__registerViewListener-int-ohos_aafwk_ability_ViewListener-) to listen for click events of specific components.
The client provides the following functions: 
                * **Obtaining an AbilityForm:** The developer of the client calls [AbilitySlice#acquireAbilityFormAsync(Intent, OnAcquiredCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireAbilityFormAsync-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilityForm_OnAcquiredCallback-) to send an asynchronous request to the supplier through the AbilityForm framework to request the AbilityForm to be displayed. 
                * **Releasing an AbilityForm:** The developer of the client calls [AbilitySlice#releaseAbilityForm(AbilityForm)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__releaseAbilityForm-ohos_aafwk_ability_AbilityForm-) to release an AbilityForm.
                * **Controlling the AbilityForm layout:** The developer of the client calls the [getComponent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952#ZH-CN_TOPIC_0000001054199952__getComponent--) method to obtain the root component of the AbilityForm, and uses the layout method provided in AbilitySlice to inflate the AbilityForm content to the layout of the client.
                * **Displaying complete AbilityForm content:** The developer of the client calls [startFullPage()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952#ZH-CN_TOPIC_0000001054199952__startFullPage--) to display the complete content of an AbilityForm.
