# Overview  
  
Provides basic file access capabilities. 

You can use the classes and APIs in the package to access device files.

**Since:**

6

#### Class Summary

Class | Description  
---|---  
[FileAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileability-0000001170334521) | FileAbility is a special implementions of IDataAbility that facilitates secure sharing of a files associated with an app by creating a dataability://[Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009) for a file instead of file:/// [Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009).
