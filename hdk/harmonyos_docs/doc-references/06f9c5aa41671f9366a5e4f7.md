Represents the node component that describes hierarchical relationships among objects. This class is inherited from [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678705). 

Concepts such as child and parent nodes are used to describe the hierarchy of objects in a scene.
