# Overview  
  
Describes resource configurations, including the language and region, screen resolution, device type, and device orientation. 

These configurations determine the resource data to be read. 

For example, you can use [ResourceManager.getConfiguration()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863#ZH-CN_TOPIC_0000001054358863__getConfiguration--) to obtain the configuration and [ResourceManager.updateConfiguration(Configuration, DeviceCapability)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863#ZH-CN_TOPIC_0000001054358863__updateConfiguration-ohos_global_configuration_Configuration-ohos_global_configuration_DeviceCapability-) to update the configuration.
