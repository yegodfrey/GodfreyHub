StandardJavaFileManager
    
    public interface StandardJavaFileManager
    extends [JavaFileManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javafilemanager-0000001123694572)  
  
---  
File manager based on [java.io.File](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759). A common way to obtain an instance of this class is using [getStandardFileManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javacompiler-0000001170334507#ZH-CN_TOPIC_0000001170334507__getStandardFileManager-javax_tools_DiagnosticListener-java_util_Locale-java_nio_charset_Charset-), for example: 
    
    JavaCompiler compiler = ToolProvider.getSystemJavaCompiler();
       DiagnosticCollector<JavaFileObject> diagnostics =
           new DiagnosticCollector<JavaFileObject>();
       StandardJavaFileManager fm = compiler.getStandardFileManager(diagnostics, null, null);
     

This file manager creates file objects representing regular [files](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759), [zip file entries](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zipentry-0000001054518660), or entries in similar file system based containers. Any file object returned from a file manager implementing this interface must observe the following behavior: 
    * File names need not be canonical. 
    * For file objects representing regular files 
      * the method [FileObject.delete()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__delete--) is equivalent to [File.delete()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759#ZH-CN_TOPIC_0000001054119759__delete--), 
      * the method [FileObject.getLastModified()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__getLastModified--) is equivalent to [File.lastModified()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759#ZH-CN_TOPIC_0000001054119759__lastModified--), 
      * the methods [FileObject.getCharContent(boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__getCharContent-boolean-), [FileObject.openInputStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__openInputStream--), and [FileObject.openReader(boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__openReader-boolean-) must succeed if the following would succeed (ignoring encoding issues): 
            
            new [FileInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileinputstream-0000001054439717#ZH-CN_TOPIC_0000001054439717__FileInputStream-java_io_File-)(new [File](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759#ZH-CN_TOPIC_0000001054119759__File-java_net_URI-)([fileObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738).[toUri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__toUri--)()))

      * and the methods [FileObject.openOutputStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__openOutputStream--), and [FileObject.openWriter()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__openWriter--) must succeed if the following would succeed (ignoring encoding issues): 
            
            new [FileOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileoutputstream-0000001054199704#ZH-CN_TOPIC_0000001054199704__FileOutputStream-java_io_File-)(new [File](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759#ZH-CN_TOPIC_0000001054119759__File-java_net_URI-)([fileObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738).[toUri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__toUri--)()))

    * The [URI](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434) returned from [FileObject.toUri()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738#ZH-CN_TOPIC_0000001123534738__toUri--)
      * must be [absolute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434#ZH-CN_TOPIC_0000001054838434__isAbsolute--) (have a schema), and 
      * must have a [normalized](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434#ZH-CN_TOPIC_0000001054838434__normalize--) [path component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434#ZH-CN_TOPIC_0000001054838434__getPath--) which can be resolved without any process-specific context such as the current directory (file names must be absolute). 
According to these rules, the following URIs, for example, are allowed: 
    * file:///C:/Documents%20and%20Settings/UncleBob/BobsApp/Test.java 
    * jar:///C:/Documents%20and%20Settings/UncleBob/lib/vendorA.jar!com/vendora/LibraryClass.class 
Whereas these are not (reason in parentheses): 
    * file:BobsApp/Test.java (the file name is relative and depend on the current directory) 
    * jar:lib/vendorA.jar!com/vendora/LibraryClass.class (the first half of the path depends on the current directory, whereas the component after ! is legal) 
    * Test.java (this URI depends on the current directory and does not have a schema) 
    * jar:///C:/Documents%20and%20Settings/UncleBob/BobsApp/../lib/vendorA.jar!com/vendora/LibraryClass.class (the path is not normalized)
