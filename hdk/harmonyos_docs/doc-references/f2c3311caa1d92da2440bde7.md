An entry in an access control list (ACL).  The ACL entry represented by this class is based on the ACL model specified in [_RFC 3530: Network File System (NFS) version 4 Protocol_](http://www.ietf.org/rfc/rfc3530.txt). Each entry has four components as follows: 
                1. The [type](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry-0000001054358502#ZH-CN_TOPIC_0000001054358502__type--) component determines if the entry grants or denies access. 
                2. The [principal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry-0000001054358502#ZH-CN_TOPIC_0000001054358502__principal--) component, sometimes called the "who" component, is a [UserPrincipal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/userprincipal-0000001054678483) corresponding to the identity that the entry grants or denies access 
                3. The [permissions](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry-0000001054358502#ZH-CN_TOPIC_0000001054358502__permissions--) component is a set of [AclEntryPermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentrypermission-0000001054358495)
                4. The [flags](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry-0000001054358502#ZH-CN_TOPIC_0000001054358502__flags--) component is a set of [AclEntryFlag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentryflag-0000001054678516) to indicate how entries are inherited and propagated 
ACL entries are created using an associated [Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry_builder-0000001054119843) object by invoking its [Builder#build](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry_builder-0000001054119843#ZH-CN_TOPIC_0000001054119843__build--) method.  ACL entries are immutable and are safe for use by multiple concurrent threads. **Since:** 1.7Nested Class Summary Modifier and Type | Class | Description
