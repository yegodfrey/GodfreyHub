# Overview  
  
Provides the Preferences module for storing a small number of key-value pairs.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793) | Provides interfaces to obtain and modify preference data.  
[Preferences.PreferencesObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences_preferencesobserver-0000001054558815) | Provides an interface to listen for preference data changes.  
  
#### Exception Summary

Exception | Description  
---|---  
[PreferencesFileBrokenException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferencesfilebrokenexception-0000001054678783) | Represents an exception indicating that a file is damaged.  
[PreferencesFileReadException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferencesfilereadexception-0000001054838768) | Represents an exception indicating that the structure of the file content to be read does not meet the specified requirements.  
[PreferencesFileWriteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferencesfilewriteexception-0000001054358802) | Represents an exception indicating that the structure of the content to be written to a file does not meet the specified requirements.
