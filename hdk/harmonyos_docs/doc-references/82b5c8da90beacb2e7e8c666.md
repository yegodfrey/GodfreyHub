Provides methods related to the anonymous shared memory (Ashmem), including creating, closing, mapping, and unmapping the Ashmem, reading data from and writing data into the Ashmem, obtaining the Ashmem size, and setting protection for the Ashmem. The Ashmem is created by a process. You can map the created Ashmem object to the current process to read and write data. Alternatively, you can transfer and map this Ashmem object to another process for data read and write. You need to ensure the timing sequence for concurrent read and write operations among multiple processes. **Since:** 3Field Summary Modifier and Type | Field | Description
