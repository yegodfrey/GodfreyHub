#### Intl.DateTimeFormat

DateTimeFormat(local: string, options: DateTimeFormatOptions): void

可以支持同一日期在不同国家，地区的不同显示风格，也可以支持开发者设置对应的日期格式化的样式返回不同的格式的日期。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
locale | string | 否 | 设置需要格式化对应的语言，地区信息，支持language[-script][-region]的设定方式  
options | DateTimeFormatOptions | 否 | 设置格式化的日期样式  
  
**表1** DateTimeFormatOptions参数名 | 类型 | 必填 | 默认值 | 说明  
---|---|---|---|---  
hour12 | bool | 否 | 根据locale信息自动确定 | 是否使用12小时制，可选项有 ：
      * true：设置时间为12小时制
      * false：设置时间为24小时制  
weekday | string | 否 | - | 星期的展示方式，默认不显示，可选项有 :
      * short：短格式的星期显示
      * long： 显示完整的星期  
year | string | 否 | numeric | 年的展示方式，可选项有 :
      * 2-digit：显示2位年份
      * numeric：显示完整的年份  
month | string | 否 | numeric | 月份的展示方式，可选项有 :
      * numeric：显示数字月份
      * 2-digit：显示2位数字的月份
      * short：显示短格式的月份
      * long：显示完整的月份  
day | string | 否 | numeric | 日的展示方式，可选项有：
      * numeric：显示数字日
      * 2-digit：显示2位数字日  
hour | string | 否 | - | 小时的展示方式，默认不显示，可选项有 :
      * numeric：显示数字小时
      * 2-digit：显示2位数字小时  
minute | string | 否 | - | 分钟的展示方式，默认不显示，可选项有 :
      * numeric：显示数字分钟
      * 2-digit : 显示2位数字分数  
second | string | 否 | - | 秒的展示方式，默认不显示，可选项有 :
      * numeric：显示数字秒
      * 2-digit：显示2位数字秒  
  
    * 实例方法

**format(date: Date)**

对指定的日期对象采用构造器中定义的样式进行格式化。 

**表2** format参数说明参数名 | 类型 | 必填 | 说明  
---|---|---|---  
date | Date | 是 | 需要进行格式化的日期对象。  
  
    * 示例
          
          export default {    
            dateFormat() {        
              const dateFormat = new Intl.DateTimeFormat("zh-CN", {            
                hour12:true,            
                weekday : 'long',            
                year : 'numeric',            
                month : 'long',            
                day : 'numeric',            
                hour : '2-digit',            
                minute : '2-digit',            
                second : '2-digit',        
              });        
              // 2020年9月22日星期二 下午05:14:13        
              console.log(dateFormat.format(new Date()));    
            },
          }
          

#### Intl.NumberFormat

NumberFormat(locale: string, options: NumberFormatOptions): void

可以支持根据传入的国家，地区信息，开发者可以设置不同的数字样式，实现对数字的本地化操作。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
locale | string | 否 | 设置需要格式化对应的语言，地区信息，支持language[-script][-region]的设定方式  
options | NumberFormatOptions | 否 | 设置数字或者百分比的样式，具体支持的样式设置如下所示：  
  
**表3** NumberFormatOptions参数名 | 类型 | 必填 | 默认值 | 说明  
---|---|---|---|---  
style | string | 否 | decimal | 使用的格式样式，可选项有 :
      * decimal：纯数字格式
      * percent：百分比格式  
useGrouping | bool | 否 | true | 是否使用分隔符,可选项有 :
      * true：使用分隔符
      * false：不使用分隔符  
minimumIntegerDigits | number | 否 | 1 | 使用的整数数字的最小数目，可以设置的范围是1-21  
minimumFractionDigits | number | 否 | 0 | 使用的小数位的最小数目，可以设置的范围是0-20  
maxmumFractionDigits | number | 否 | minimumFractionDigits与3更大的一个 | 使用的小数位的最大数目，可以设置的范围是0-20  
  
    * 实例方法

**format(num:number)**

对传入的数字按照构造器中设置的样式进行格式化 

**表4** format参数说明参数名 | 类型 | 必填 | 说明  
---|---|---|---  
num | number | 是 | 需要进行格式化的数字对象。  
  
    * 示例
          
          export default {    
            numberFormat() {       
              const numberFormat = new Intl.NumberFormat('zh-CN', {  
                style:'decimal',  
                usegrouping:true, 
                maximumFractionDigits:4, 
                mininumFractionDigits:2,
               });    
               //1.2346    
               console.log(numberFormat.format(1.234567));   
               //12,345.6789   
               console.log(numberFormat.format(12345.6789));    
            },
          }
