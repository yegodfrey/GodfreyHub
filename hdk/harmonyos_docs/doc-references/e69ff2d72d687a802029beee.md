A base class used to provide callback methods that are registered with the AbilityForm supplier to listen for click or touch events. Currently, the system provides a child class [OnClickListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/onclicklistener-0000001054358661) for a callback upon click events. You can inherit the ViewListener class to add other callback methods as required. **Since:** 1Constructor Summary Constructor | Description

Generally, this method is triggered in the following scenario: 
    1. The developer of the supplier uses [AbilityForm#registerViewListener(int, ViewListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952#ZH-CN_TOPIC_0000001054199952__registerViewListener-int-ohos_aafwk_ability_ViewListener-) to register a callback method upon touch events.
    2. When a touch event is dispatched to a component on the client, the event is sent to the supplier through the AbilityForm framework, and the AbilityForm framework triggers the registered callback method [ViewListener#onTouchEvent(AbilityForm, ViewsStatus)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/viewlistener-0000001054358670#ZH-CN_TOPIC_0000001054358670__onTouchEvent-ohos_aafwk_ability_AbilityForm-ohos_aafwk_ability_ViewsStatus-).
