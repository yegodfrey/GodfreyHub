# Overview  
  
Provides interfaces for obtaining media metadata.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[AVStorage.AVBaseColumns](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avstorage_avbasecolumns-0000001054358919) | Provides basic fields for media data.
