# Overview  
  
Provides a collection of classes for interacting with the accessibility system service and provides interfaces for sending accessibility events, querying the accessibility service status, and sending accessibility status change events. 

The [AccessibilitySystemAbilityClient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitysystemabilityclient-0000001054358680) class is used to create an accessibility system client that interacts with the accessibility system service. You can use the client to send accessibility events specified by [AccessibilityEventInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityeventinfo-0000001054678661) to the accessibility ability for processing. 

The [AccessibilityStateObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitystateobserver-0000001054358671) class is used to create an observer. You can register the observer using [AccessibilitySystemAbilityClient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitysystemabilityclient-0000001054358680). When the accessibility status changes, the observer will receive a status event specified by [AccessibilityStateEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitystateevent-0000001054838646). 

The [AccessibilityAbilityInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityabilityinfo-0000001054238691) class describes the basic information about the accessibility abilities. You can call this class to query information about the accessibility ability.
