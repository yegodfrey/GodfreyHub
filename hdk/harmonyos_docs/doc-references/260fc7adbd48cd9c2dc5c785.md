# DeviceInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.distributedhardware.devicemanager.DeviceInfo
    
    public class DeviceInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides basic information about a device, including the network ID, name, and type. 

Basic device information is returned when your application queries the trusted device list via [DeviceManager#getTrustedDeviceList](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__getTrustedDeviceList-java_lang_String-java_util_Map-) or queries local device information via [DeviceManager#getLocalDeviceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__getLocalDeviceInfo--).
