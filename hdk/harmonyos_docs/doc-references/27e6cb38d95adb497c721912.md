# DecimalStyle

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.time.format.DecimalStyle
    
    public final class DecimalStyle
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Localized decimal style used in date and time formatting. 

A significant part of dealing with dates and times is the localization. This class acts as a central point for accessing the information.

This uses standard ASCII characters for zero, positive, negative and a dot for the decimal point.
