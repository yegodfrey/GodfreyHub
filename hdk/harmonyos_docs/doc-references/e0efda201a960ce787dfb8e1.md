# Lifecycle.Event

Indicates a lifecycle event. The system dispatches an Event when the lifecycle state changes. 

The system schedules a lifecycle change and dispatches an Event to [Lifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967). [Lifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967) then dispatches the Event to a registered [ILifecycleObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ilifecycleobserver-0000001054678647) for responding to the lifecycle change.

For example, if a registered [LifecycleObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycleobserver-0000001054199954) receives an ON_ACTIVE event, it will call [LifecycleObserver#onActive()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycleobserver-0000001054199954#ZH-CN_TOPIC_0000001054199954__onActive--) to change the ability or ability slice to the ACTIVE state.
