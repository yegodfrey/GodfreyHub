# Overview  
  
Provides definitions of common classes that image-related functions may be dependent on.

**Since:**

1

#### Class Summary

Class | Description  
---|---  
[Filter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filter-0000001060268789) | Abstract base class for image processing.  
[ImageFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imageformat-0000001054120192) | Defines the image format and provides interfaces for obtaining image format information.  
[ImageInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imageinfo-0000001054440221) | Describes basic image information, including image dimensions, pixel formats, and color space.  
[Position](https://developer.harmonyos.com/cn/docs/documentation/doc-references/position-0000001054200208) | Describes location information of image pixels in a two-dimensional coordinate system.  
[PropertyKey](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertykey-0000001054518948) | Provides definitions of image property keys.  
[PropertyKey.Exif](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertykey_exif-0000001054678936) | Provides definitions of image Exif property keys.  
[PropertyKey.GIF](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertykey_gif-0000001054358915) | Provides definitions of GIF property keys.  
[Rect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rect-0000001054558937) | Describes rectangle areas of images.  
[Size](https://developer.harmonyos.com/cn/docs/documentation/doc-references/size-0000001054238935) | Provides image size information, includes the width and height.
