Provides methods for installing, selecting, and using private keys and their certificate chains. An application can install new private keys and certificates through the Intent obtained using [getInstallationIntent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/seckeychain-0000001054678978#ZH-CN_TOPIC_0000001054678978__getInstallationIntent--), and select the default private key and certificate using [selectSecPrivateKey(ohos.app.AbilityContext,java.lang.String[],java.security.Principal[],ohos.utils.net.Uri,ohos.security.seckeychain.SecKeyAliasCallback,java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/seckeychain-0000001054678978#ZH-CN_TOPIC_0000001054678978__selectSecPrivateKey-ohos_app_AbilityContext-java_lang_String:A-java_security_Principal:A-ohos_utils_net_Uri-ohos_security_seckeychain_SecKeyAliasCallback-java_lang_String-).  All applications can obtain trusted private keys and certificates through the [X509KeyManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/x509keymanager-0000001054119989) by calling [getSecPrivateKey(ohos.app.AbilityContext, java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/seckeychain-0000001054678978#ZH-CN_TOPIC_0000001054678978__getSecPrivateKey-ohos_app_AbilityContext-java_lang_String-) and [getSecCertificateChain(ohos.app.AbilityContext, java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/seckeychain-0000001054678978#ZH-CN_TOPIC_0000001054678978__getSecCertificateChain-ohos_app_AbilityContext-java_lang_String-). **Since:** 3Field Summary Modifier and Type | Field | Description
