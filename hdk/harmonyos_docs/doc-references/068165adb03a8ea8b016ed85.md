# Picker.ScrolledListener
    
    public static interface Picker.ScrolledListener  
  
---  
Processes scroll events of a [Picker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picker-0000001054119976) instance. 

This class listens for the scroll state of a number picker.

#### [h2]STATE_DRAGGING

static final int STATE_DRAGGING

Indicates the touch scroll state. 

The [Picker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picker-0000001054119976) instance is scrolled on a touchscreen.

#### [h2]STATE_FLING

static final int STATE_FLING

Indicates the fling scroll state. 

The scrolling has stopped while the number picker continues to fling.
