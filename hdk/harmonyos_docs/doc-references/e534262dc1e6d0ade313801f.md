# RadioStateObserver

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.telephony.RadioStateObserver
    
    public class RadioStateObserver
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Monitors state updates of a device, including updates of the network state, signal strength, and cell information. 

You can use [RadioInfoManager#addObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radioinfomanager-0000001054358975#ZH-CN_TOPIC_0000001054358975__addObserver-ohos_telephony_RadioStateObserver-int-) to add the RadioStateObserver with a specific observer mask. The corresponding method is invoked when the state updates. You need to override the method to receive the state information. Access to certain information is permission-protected. You must declare the appropriate permissions in the profile of the application. 

You can use [RadioInfoManager#removeObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radioinfomanager-0000001054358975#ZH-CN_TOPIC_0000001054358975__removeObserver-ohos_telephony_RadioStateObserver-) to delete the RadioStateObserver. The observer must be the same as that added.
