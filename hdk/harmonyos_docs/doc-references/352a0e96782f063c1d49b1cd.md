# 多模输入

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172459.56210225069041354848972411380058:50001231000000:2800:708C7AE881CDC6FFB7A97A5F7ADA787CCA4B88F683225EE6DF596E6559FB8625.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    * 从API version 4开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。
    * 多模输入能力仅在智慧屏生效。

设置了click通用事件的组件，可以设置相应的多模输入属性，当多模输入事件触发时，会触发组件相应的click事件。

名称 | 类型 | 默认值 | 描述  
---|---|---|---  
voicelabel | string | - | 语音标签，当触发语音标签时，会触发组件的click事件。 说明： 只有设置了click事件时，语音标签才会生效。  
subscriptflag | string | - | 语音角标开关，可选值为： auto：image组件和list-item组件等同于设置on，其他组件等同于设置off。 on：打开语音角标。 off：关闭语音角标。 当没有设置自定义角标标签内容时，角标内容会从1开始自动累加。 说明： 只有设置了click事件时，角标才会生效。  
subscriptlabel | string | - | 自定义角标标签内容，设置该内容后，角标会使用自定义内容展示。该属性生效需要设置subscriptflag开启角标能力。  
scenelabel | string | - | 可选值有：
    * video：视频场景，触发场景：语音标签（voiceLabel）、播放（语音标签）、打开（语音标签）、看（语音标签）；
    * audio：音乐场景，触发场景：语音标签（voiceLabel）、播放（语音标签）、打开（语音标签）、听（语音标签）；
    * page： 页面场景，触发场景：语音标签（voiceLabel）、切换到（语音标签）、打开（语音标签）、跳转到（语音标签）；
    * switch：开关场景，触发场景：语音标签（voiceLabel）、打开（语音标签）、开下（语音标签）、关闭（语音标签）、关了（语音标签）；
    * common：通用场景，触发场景：语音标签（voiceLabel）。
