#### [h2]setSmoothScrollbarAllowed

public void setSmoothScrollbarAllowed​(boolean enabled)

Sets whether to enable the smooth scroll bar.

When child components in the ListComponent have different height values, the scroll bar height does not change dynamically if the smooth scroll bar is enabled. If the smooth scroll bar is disabled, the scroll bar height changes dynamically with the height of the child components.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
enabled | Specifies whether to enable the smooth scroll bar. The value true means to enable the smooth scroll bar, and false means the opposite.  
  
**Since:**

7
