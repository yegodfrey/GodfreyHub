# Overview  
  
Provides classes for handling standards events to which input events of different input devices are mapped.

**Since:**

5

#### Interface Summary

Interface | Description  
---|---  
[CommonEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventhandle-0000001139632439) | Provides methods for handling standard common events.  
[KeyEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyeventhandle-0000001139370709) | Provides methods for handling standard key events.  
[MediaEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mediaeventhandle-0000001093133062) | Provides methods for handling standard media events.  
[StandardizedEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardizedeventhandle-0000001139715265) | Represents the base interface of all types of standard events.  
[SystemEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/systemeventhandle-0000001092813454) | Provides methods for handling standard system events.  
[TelephoneEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/telephoneeventhandle-0000001092973128) | Provides methods for handling standard call events.  
[TouchEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/toucheventhandle-0000001092684974) | Provides methods for handling standard touch events.  
  
#### Class Summary

Class | Description  
---|---  
[MultimodalEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodaleventhandle-0000001139632441) | Provides methods for handling standard events, including registering and deregistering a standard event.
