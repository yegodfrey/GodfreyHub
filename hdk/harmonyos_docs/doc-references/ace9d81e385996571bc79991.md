# NoType
    
    public interface NoType
    extends [TypeMirror](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typemirror-0000001123534712)  
  
---  
A pseudo-type used where no actual type is appropriate. The kinds of NoType are: 
    * [VOID](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typekind-0000001170214379#ZH-CN_TOPIC_0000001170214379__VOID) \- corresponds to the keyword void. 
    * [PACKAGE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typekind-0000001170214379#ZH-CN_TOPIC_0000001170214379__PACKAGE) \- the pseudo-type of a package element. 
    * [NONE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typekind-0000001170214379#ZH-CN_TOPIC_0000001170214379__NONE) \- used in other cases where no actual type is appropriate; for example, the superclass of java.lang.Object. 

**Since:**

1.6
