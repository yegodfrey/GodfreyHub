Displays the directional layout of tabs and allows the content in the layout to scroll along the layout direction. You can create a tab using a [TabList](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tablist-0000001054238721) object, and then add the new tab to the list using [addTab(ohos.agp.components.TabList.Tab)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tablist-0000001054238721#ZH-CN_TOPIC_0000001054238721__addTab-ohos_agp_components_TabList_Tab-). The layout direction can be either [Component.HORIZONTAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__HORIZONTAL) or [Component.VERTICAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__VERTICAL).
