# form  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172501.89177903606189445536122565016935:50001231000000:2800:8F11898B57E549F4396CBCD557BAC8496E9E92EAEB6C7D7876908262A303E854.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

从API version 6开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。

表单容器，支持容器内input元素的内容提交和重置。

#### 权限列表

无

#### 子组件

支持。

#### 示例

#### 属性

支持[通用属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-attributes-0000001281480654)。

#### 样式

支持[组件通用样式](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-styles-0000001281201106)。

#### 事件

除支持[通用事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-events-0000001333720913)外，还支持如下事件：

名称 | 参数 | 描述  
---|---|---  
submit | FormResult | 点击提交按钮，进行表单提交时，触发该事件。  
reset | - | 点击重置按钮后，触发该事件。  
  
**表1** FormResult

名称 | 类型 | 描述  
---|---|---  
value | Object | input元素的name和value的值。

支持[通用方法](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-methods-0000001333321161)。
