Streaming validator that works on SAX stream.  A [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) object is not thread-safe and not reentrant. In other words, it is the application's responsibility to make sure that one [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) object is not used from more than one thread at any given time.  [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) checks if the SAX events follow the set of constraints described in the associated [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001060519193), and additionally it may modify the SAX events (for example by adding default values, etc.)  [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) extends from [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797), but it refines the underlying [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) in the following way: 
    1. startElement/endElement events must receive non-null String for uri, localName, and qname, even though SAX allows some of them to be null. Similarly, the user-specified [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) will receive non-null Strings for all three parameters. 
    2. Applications must ensure that [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147)'s [ContentHandler#startPrefixMapping(String,String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797#ZH-CN_TOPIC_0000001060268797__startPrefixMapping-java_lang_String-java_lang_String-) and [ContentHandler#endPrefixMapping(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797#ZH-CN_TOPIC_0000001060268797__endPrefixMapping-java_lang_String-) are invoked properly. Similarly, the user-specified [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) will receive startPrefixMapping/endPrefixMapping events. If the [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) introduces additional namespace bindings, the user-specified [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) will receive additional startPrefixMapping/endPrefixMapping events. 
    3. [Attributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributes-0000001060519100) for the [ContentHandler#startElement(String,String,String,Attributes)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797#ZH-CN_TOPIC_0000001060268797__startElement-java_lang_String-java_lang_String-java_lang_String-ohos_org_xml_sax_Attributes-) method may or may not include xmlns* attributes. 
A [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) is automatically reset every time the startDocument method is invoked.  **Recognized Properties and Features** This spec defines the following feature that must be recognized by all [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) implementations.  **http://xml.org/sax/features/namespace-prefixes** This feature controls how a [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) introduces namespace bindings that were not present in the original SAX event stream. When this feature is set to true, it must make sure that the user's [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) will see the corresponding xmlns* attribute in the [Attributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributes-0000001060519100) object of the [ContentHandler#startElement(String,String,String,Attributes)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797#ZH-CN_TOPIC_0000001060268797__startElement-java_lang_String-java_lang_String-java_lang_String-ohos_org_xml_sax_Attributes-) callback. Otherwise, xmlns* attributes must not be added to [Attributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributes-0000001060519100) that's passed to the user-specified [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797).  (Note that regardless of this switch, namespace bindings are always notified to applications through [ContentHandler#startPrefixMapping(String,String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797#ZH-CN_TOPIC_0000001060268797__startPrefixMapping-java_lang_String-java_lang_String-) and [ContentHandler#endPrefixMapping(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797#ZH-CN_TOPIC_0000001060268797__endPrefixMapping-java_lang_String-) methods of the [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) specified by the user.)  Note that this feature does NOT affect the way a [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147) receives SAX events. It merely changes the way it augments SAX events.  This feature is set to false by default. **Since:** 1.5Constructor Summary Modifier | Constructor | Description
