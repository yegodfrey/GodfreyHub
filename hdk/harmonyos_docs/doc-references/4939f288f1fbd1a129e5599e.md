# IAbilityMonitor
    
    public interface IAbilityMonitor  
  
---  
Provides methods for matching monitored [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) objects that meet specified conditions. The most recently matched [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) objects will be saved in the IAbilityMonitor object. 

You can call [IAbilityDelegator#addAbilityMonitor(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942#ZH-CN_TOPIC_0000001054119942__addAbilityMonitor-java_lang_String-) to add the Ability objects to be monitored and then use methods provided in [IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958) to obtain the monitored Ability objects when newAbility objects are started or the lifecycle states of monitored abilities have changed.

#### [h2]waitForAbility

[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) waitForAbility​(long timeoutMillisecond)

Waits for and returns the state-changing Ability object that matches the conditions specified in this monitor within the specified time. 

The current thread will be blocked until the timer specified by timeoutMillisecond expires.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
timeoutMillisecond  |  Indicates the maximum amount of time to wait, in milliseconds. The value must be a positive integer.  
  
**Returns:**

Returns the Ability object if any object whose lifecycle state has changed is matched within the specified time; returns null otherwise.

**Since:**

3

#### [h2]waitForAbility

[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) waitForAbility​()

Waits for and returns the state-changing Ability object that matches the conditions specified in this monitor within 5 seconds. 

The current thread will be blocked until the 5-second default timer expires.

**Returns:**

Returns the Ability object if any object whose lifecycle state has changed is matched within 5 seconds; returns null otherwise.
