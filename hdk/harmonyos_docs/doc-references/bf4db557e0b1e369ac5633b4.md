# ListContainer.ItemClickedListener
    
    public static interface ListContainer.ItemClickedListener  
  
---  
Listens for click events of [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) items. 

To respond to and process click events of [ListContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcontainer-0000001054678718) items, onItemClicked must be implemented.

---|---
