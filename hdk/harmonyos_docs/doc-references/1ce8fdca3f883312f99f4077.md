# NullPointerException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466) |---|---|---|---java.lang.NullPointerException
    
    public class NullPointerException
    extends [RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466)  
  
---  
Thrown when an application attempts to use null in a case where an object is required. These include: 
    * Calling the instance method of a null object. 
    * Accessing or modifying the field of a null object. 
    * Taking the length of null as if it were an array. 
    * Accessing or modifying the slots of null as if it were an array. 
    * Throwing null as if it were a Throwable value. 

Applications should throw instances of this class to indicate other illegal uses of the null object. NullPointerException objects may be constructed by the virtual machine as if [Throwable#Throwable(String, Throwable, boolean, boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__Throwable-java_lang_String-java_lang_Throwable-boolean-boolean-).
