# Overview  
  
ICU(International Components for Unicode): enhanced character property. 

Please refer to http://site.icu-project.org for more information.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Collator.ReorderCodes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collator_reordercodes-0000001054678858) | Reordering codes for non-script groups that can be reordered under collation.  
[Replaceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/replaceable-0000001054358837) | Replaceable is an interface representing a string of characters that supports the replacement of a range of itself with a new string of characters.
