#### [h2]getDevicesByStates

[List](https://developer.harmonyos.com/cn/docs/documentation/doc-references/list-0000001054119842)<[BluetoothRemoteDevice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothremotedevice-0000001054200062)> getDevicesByStates​(int[] states)

**Parameters:**

Parameter Name | Parameter Description  
---|---  
states  |  Indicates the connection status, which can be [STATE_DISCONNECTED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/profilebase-0000001054358767#ZH-CN_TOPIC_0000001054358767__STATE_DISCONNECTED), [STATE_CONNECTING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/profilebase-0000001054358767#ZH-CN_TOPIC_0000001054358767__STATE_CONNECTING), [STATE_CONNECTED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/profilebase-0000001054358767#ZH-CN_TOPIC_0000001054358767__STATE_CONNECTED), or [STATE_DISCONNECTING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/profilebase-0000001054358767#ZH-CN_TOPIC_0000001054358767__STATE_DISCONNECTING).  
  
**Returns:**

Returns the list of [BluetoothRemoteDevice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bluetoothremotedevice-0000001054200062) matching the specified status.
