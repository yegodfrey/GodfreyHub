Annotation retention policy. The constants of this enumerated type describe the various policies for retaining annotations. They are used in conjunction with the [Retention](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retention-0000001054238461) meta-annotation type to specify how long annotations are to be retained.**Since:** 1.5Enum Constant Summary Enum Constant | Description  
---|---  
[CLASS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retentionpolicy-0000001054678429#ZH-CN_TOPIC_0000001054678429__CLASS) |  Annotations are to be recorded in the class file by the compiler but need not be retained by the VM at run time.   
[RUNTIME](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retentionpolicy-0000001054678429#ZH-CN_TOPIC_0000001054678429__RUNTIME) |  Annotations are to be recorded in the class file by the compiler and retained by the VM at run time, so they may be read reflectively.   
[SOURCE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retentionpolicy-0000001054678429#ZH-CN_TOPIC_0000001054678429__SOURCE) |  Annotations are to be discarded by the compiler.
