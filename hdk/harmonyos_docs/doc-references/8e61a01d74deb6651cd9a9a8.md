# AbilityForm.OnAcquiredCallback
    
    public static interface AbilityForm.OnAcquiredCallback  
  
---  
Provides callback methods that are invoked when an AbilityForm instance created by the supplier is obtained or destroyed on the client. 

This interface provides callback methods that are called after an asynchronous request sent by calling [AbilitySlice#acquireAbilityFormAsync(Intent, OnAcquiredCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireAbilityFormAsync-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilityForm_OnAcquiredCallback-) on the client. The callback methods are used to notify the client that the AbilityForm request has been processed.

#### [h2]onAcquired

void onAcquired​([AbilityForm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952) abilityForm)

Called when an AbilityForm instance created by the supplier is obtained on the client. 

This method is called back when: 

    * The asynchronous request sent from the client by calling [AbilitySlice#acquireAbilityFormAsync(Intent, OnAcquiredCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireAbilityFormAsync-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilityForm_OnAcquiredCallback-) has been processed.
    * The supplier is restarted by the Ability Manager Service.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
abilityForm  |  Indicates the AbilityForm instance created by the supplier by calling [Ability#onCreateForm()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onCreateForm--).

#### [h2]onDestroyed

void onDestroyed​([AbilityForm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952) abilityForm)

Called when an AbilityForm has been destroyed. 

You will be notified through this callback method when an AbilityForm is destroyed. You can also use this method to reconnect to the AbilityForm or clear resources.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
abilityForm  |  Indicates the destroyed AbilityForm.
