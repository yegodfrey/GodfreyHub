# Overview  
  
Manages sensors on hardware devices. 

This package provides basic operations for sensors, including obtaining all sensors in a sensor category, a type of sensors in the sensor category, and the first sensor of a specific type, setting or releasing the sensor data callback, and querying the minimum sampling interval of a sensor.
