Indicates that an unknown kind of annotation value was encountered. This can occur if the language evolves and new kinds of annotation values can be stored in an annotation. May be thrown by an [annotation value visitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotationvaluevisitor-0000001170214361) to indicate that the visitor was created for a prior version of the language.**Since:** 1.6**See Also:** [AnnotationValueVisitor.visitUnknown(javax.lang.model.element.AnnotationValue, P)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotationvaluevisitor-0000001170214361#ZH-CN_TOPIC_0000001170214361__visitUnknown-javax_lang_model_element_AnnotationValue-P-), Constructor Summary Constructor | Description
