# IntentAgentHelper

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.intentagent.IntentAgentHelper
    
    public final class IntentAgentHelper
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A helper class used to obtain, trigger, cancel, and compare [IntentAgent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagent-0000001054678807) objects and to obtain the bundle name, UID, and hash code value of an [IntentAgent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagent-0000001054678807) object. 

The methods provided by this class are all static and can be called without creating an object of this class.

---|---

agent  |  Indicates the [IntentAgent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagent-0000001054678807) to trigger.  
onCompleted  |  Indicates the callback method to be called after the [IntentAgent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagent-0000001054678807) is triggered. This parameter can be null.  
handler  |  Indicates the thread for executing the callback indicated by onCompleted. If this parameter is null, the callback method will be executed in a thread in the thread pool of the current process.  
paramsInfo  |  Indicates the [TriggerInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/triggerinfo-0000001054120096) object that contains triggering parameters.
