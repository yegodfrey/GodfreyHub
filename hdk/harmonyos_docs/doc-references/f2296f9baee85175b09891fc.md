# IntFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface IntFunction<R>  
  
---  
Represents a function that accepts an int-valued argument and produces a result. This is the int-consuming primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [apply(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intfunction-0000001054199900#ZH-CN_TOPIC_0000001054199900__apply-int-).

**Since:**

1.8
