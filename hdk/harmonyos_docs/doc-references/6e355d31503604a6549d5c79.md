ThreadFactory
    
    public interface ThreadFactory  
  
---  
An object that creates new threads on demand. Using thread factories removes hardwiring of calls to [Thread#Thread(Runnable)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__Thread-java_lang_Runnable-), enabling applications to use special thread subclasses, priorities, etc.  The simplest implementation of this interface is just: 
    
    class SimpleThreadFactory implements ThreadFactory {
       public Thread newThread(Runnable r) {
         return new Thread(r);
       }
     }

The [Executors#defaultThreadFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/executors-0000001054119941#ZH-CN_TOPIC_0000001054119941__defaultThreadFactory--) method provides a more useful simple implementation, that sets the created thread context to known values before returning it.**Since:** 1.5Method Summary Modifier and Type | Method | Description
