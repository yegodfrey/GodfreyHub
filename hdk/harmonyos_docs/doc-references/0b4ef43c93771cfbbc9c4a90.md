# ExceptionInInitializerError  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Error](https://developer.harmonyos.com/cn/docs/documentation/doc-references/error-0000001054199728) |---|---|---[java.lang.LinkageError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkageerror-0000001054678425) |---|---|---|---java.lang.ExceptionInInitializerError
    
    public class ExceptionInInitializerError
    extends [LinkageError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkageerror-0000001054678425)  
  
---  
Signals that an unexpected exception has occurred in a static initializer. An ExceptionInInitializerError is thrown to indicate that an exception occurred during evaluation of a static initializer or the initializer for a static variable. 

As of release 1.4, this exception has been retrofitted to conform to the general purpose exception-chaining mechanism. The "saved throwable object" that may be provided at construction time and accessed via the [getException()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exceptionininitializererror-0000001054518468#ZH-CN_TOPIC_0000001054518468__getException--) method is now known as the _cause_ , and may be accessed via the [Throwable#getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method, as well as the aforementioned "legacy method."

**Since:**

JDK1.1

#### [h2]getException

public [Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) getException​()

Returns the exception that occurred during a static initialization that caused this error to be created. 

This method predates the general-purpose exception chaining facility. The [Throwable#getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method is now the preferred means of obtaining this information.

**Returns:**

the saved throwable object of this ExceptionInInitializerError, or null if this ExceptionInInitializerError has no saved throwable object.
