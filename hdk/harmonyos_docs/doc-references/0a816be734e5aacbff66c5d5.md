# IndexData

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.data.search.model.IndexData
    
    public class IndexData
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Represents a container that stores index data. 

The index data is in key-value pair format. Neither the key nor value can be null. Currently, five data types are supported: string, integer, long, double, and float.
