Text.EditorActionListener | 
    
    public static interface Text.EditorActionListener

Listens for change events of an editor action. The corresponding component will respond to and process the change event of the editor action, such as searching or switching. Method Summary Modifier and Type | Method | Description  
---|---|---  
boolean | [onTextEditorAction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/text_editoractionlistener-0000001054358691#ZH-CN_TOPIC_0000001054358691__onTextEditorAction-int-)​(int action) |  Called when change events of the specified editor action are processed.   
Method Detail [h2]onTextEditorAction boolean onTextEditorAction​(int action) Called when change events of the specified editor action are processed. **Parameters:** Parameter Name | Parameter Description  
---|---  
action  |  Indicates the editor action. For example, [InputAttribute#ENTER_KEY_TYPE_GO](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputattribute-0000001054440003#ZH-CN_TOPIC_0000001054440003__ENTER_KEY_TYPE_GO) indicates a "go" action, and [InputAttribute#ENTER_KEY_TYPE_SEND](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputattribute-0000001054440003#ZH-CN_TOPIC_0000001054440003__ENTER_KEY_TYPE_SEND) indicates a "send" action. For details, see [InputAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputattribute-0000001054440003).  
**Returns:** Returns true if the event is processed; returns false otherwise. **Since:** 4 **See Also:** [InputAttribute.inputEnterKeyType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputattribute-0000001054440003#ZH-CN_TOPIC_0000001054440003__inputEnterKeyType)
