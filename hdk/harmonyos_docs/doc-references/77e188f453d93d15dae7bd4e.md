# Overview  
  
Provides basic functions of the input method service for implementing interaction between applications and input method engines. 

Life cycle management for input method engines, for example, displaying and hiding the input method panel. 

Content editing on a focused editor, for example, inserting, deleting, and selecting texts.

**Since:**

1

---|---  
[EditingCapability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/editingcapability-0000001060411187) | Describes the attributes of the text obtained by an input method.  
[EditingText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/editingtext-0000001061156874) | Transfers all or updated text in the application editor to the input method.
