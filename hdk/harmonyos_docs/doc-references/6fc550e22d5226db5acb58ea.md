#### [h2]getName

public [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) getName​()

Obtains the name of this Codec object. 

You can understand features of a codec through its name. The name can describe whether the codec is software or hardware, which MIME types it supports, and whether it is an encoder or decoder. For example, SoftwareAvcDecoder indicates a software decoder that supports the AVC format.

#### [h2]getSupportedFormat

public [Format](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893) getSupportedFormat​()

Obtains the formats supported by this Codec. 

This method returns a [Format](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893) object that contains keys in the media metadata. The keys include ranges of the audio sampling rate and bit rate, or ranges of the video height and width, bit rate, and frame rate. 

To obtain values of these keys, you need to use the [Format.getObjectValue(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893#ZH-CN_TOPIC_0000001054678893__getObjectValue-java_lang_String-) method and convert data types of return values. 

Format keys that can be obtained are as follows: 

[Format.KEY_SAMPLE_RATE_SCOPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893#ZH-CN_TOPIC_0000001054678893__KEY_SAMPLE_RATE_SCOPE),[Format.KEY_SAMPLE_RATE_LIST](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893#ZH-CN_TOPIC_0000001054678893__KEY_SAMPLE_RATE_LIST), [Format.KEY_BIT_RATE_SCOPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893#ZH-CN_TOPIC_0000001054678893__KEY_BIT_RATE_SCOPE), [Format.KEY_FRAME_RATE_SCOPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893#ZH-CN_TOPIC_0000001054678893__KEY_FRAME_RATE_SCOPE), [Format.KEY_HEIGHT_SCOPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893#ZH-CN_TOPIC_0000001054678893__KEY_HEIGHT_SCOPE), ohos.media.common.Format#KEY_WIGHT_SCOPE

**Returns:**

Returns the Format object.

**Since:**

4
