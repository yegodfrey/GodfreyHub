# Overview  
  
Provides camera parameter classes, including definitions of camera properties, supported parameters, and parameter setting results.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[AeResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aeresult-0000001054678885) | Interface for the automatic exposure (AE) results.  
[AfResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/afresult-0000001054838870) | Interface for autofocus (AF) results.  
[FaceDetectionResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/facedetectionresult-0000001054358904) | An interface to obtain face detection results.  
[FocusResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/focusresult-0000001054120245) | Represents focus result data in a mode.  
[ParametersResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parametersresult-0000001054120174) | Describes parameter setting results.  
[SceneDetectionResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/scenedetectionresult-0000001054440203) | Represents result data of scene detection.
