# ExpiredCallback

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.backgroundtaskmgr.ExpiredCallback
    
    public abstract class ExpiredCallback
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Abstract class of the timeout callback for delayed transition to the suspended state. If an application needs to continue an unfinished task in the background, it must send a request for delayed transition to the suspended state. When the requested delay duration times out, ExpiredCallback will be called to notify the application. 

Implementation of this class requires that you rewrite the respective methods and define the processing logic for timeout of the delay duration.
