# Overview  
  
Provides classes that allow applications to insert, delete, update, query, and listen to data in system databases. 

This package defines global, security, and system configuration items. 

Applications have only the read permission on the global and security configuration items, the values of which can be modified only in a specified mode. 

Methods are provided to retrieve and store the global, security, and system configuration items into different types such as string, int, long, and float.

**Since:**

3
