AttributedCharacterIterator
    
    public interface AttributedCharacterIterator
    extends [CharacterIterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/characteriterator-0000001054678531)  
  
---  
An AttributedCharacterIterator allows iteration through both text and related attribute information.  An attribute is a key/value pair, identified by the key. No two attributes on a given character can have the same key.  The values for an attribute are immutable, or must not be mutated by clients or storage. They are always passed by reference, and not cloned.  A run with respect to an attribute is a maximum text range for which: 
                * the attribute is undefined or null for the entire range, or 
                * the attribute value is defined and has the same non-null value for the entire range. 
A run with respect to a set of attributes is a maximum text range for which this condition is met for each member attribute.  When getting a run with no explicit attributes specified (i.e., calling [getRunStart()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributedcharacteriterator-0000001054238561#ZH-CN_TOPIC_0000001054238561__getRunStart--) and [getRunLimit()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributedcharacteriterator-0000001054238561#ZH-CN_TOPIC_0000001054238561__getRunLimit--)), any contiguous text segments having the same attributes (the same set of attribute/value pairs) are treated as separate runs if the attributes have been given to those text segments separately.  The returned indexes are limited to the range of the iterator.  The returned attribute information is limited to runs that contain the current character.  Attribute keys are instances of [AttributedCharacterIterator.Attribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributedcharacteriterator_attribute-0000001054119891) and its subclasses, such as [TextAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textattribute-0000001054678393). **Since:** 1.2**See Also:** [AttributedCharacterIterator.Attribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributedcharacteriterator_attribute-0000001054119891), [TextAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textattribute-0000001054678393), [AttributedString](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributedstring-0000001054119820), [Annotation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotation-0000001054358550)Nested Class Summary Modifier and Type | Interface | Description
