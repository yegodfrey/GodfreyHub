Implements an uppercase character filter, which supports filtering of plain text and [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706). When lowercase characters exist in the text to be filtered, they will be converted to uppercase if the corresponding uppercase characters exist in the specified [Locale](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852). **Since:** 7Nested Class Summary Nested classes/interfaces inherited from class ohos.agp.text.[InputFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputfilter-0000001217877963)
