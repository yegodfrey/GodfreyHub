Represents a session used for pagination or group search. You can obtain a search session by calling [SearchAbility#beginSearch(String, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchability-0000001054518838#ZH-CN_TOPIC_0000001054518838__beginSearch-java_lang_String-java_lang_String-) and perform search operations. If the search session is no longer needed, call [SearchAbility#endSearch(String, String, SearchSession)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchability-0000001054518838#ZH-CN_TOPIC_0000001054518838__endSearch-java_lang_String-java_lang_String-ohos_data_search_SearchSession-) to end the session and release resources.
