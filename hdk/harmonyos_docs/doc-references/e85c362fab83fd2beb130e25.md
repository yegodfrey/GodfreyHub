# ItemAnimation

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.listcomponent.ItemAnimation
    
    public abstract class ItemAnimation
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
  
An abstract class that records the [ComponentOwner](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentowner-0000001172398146) information before and after the layout.

Four types of animation abstract APIs are provided based on the saved information, which are Disappearance, Appearance, Persistence, and Change.

#### [h2]isRunning

public final boolean isRunning​([ItemAnimation.ItemAnimationFinishedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemanimation_itemanimationfinishedlistener-0000001217877947) listener)

Checks whether any component animation is running and if yes, registers a listener to observe the animation status. A callback is invoked when the animation ends, if any. If no animation is running, the callback is invoked immediately.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
listener | Indicates the listener to register. A callback is invoked if no animation is running or the running animation ends. If this parameter is set to null, this method is equivalent to isRunning().  
  
**Returns:**

7
