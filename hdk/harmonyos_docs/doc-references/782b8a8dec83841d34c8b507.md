# Overview  
  
Provides the following classes for enabling communication between processes on the same device or on different devices: 

    * [IPCSkeleton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ipcskeleton-0000001054238969): Provides IPC interfaces to obtain services, read and write objects, and obtain the UID and PID.
    * [IRemoteBroker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremotebroker-0000001054518982): Provides the holder of a remote proxy.
    * [IRemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970): Provides interfaces to manage remote objects. This class must be inherited and implemented by both service providers and users.
    * [IRemoteObject.DeathRecipient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject_deathrecipient-0000001054358949): Represents an inner class of [IRemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970) that subscribes to death notifications of a [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299).
    * [MessageOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageoption-0000001054678939): Provides an identifier used by the sendRequest interface to synchronously or asynchronously send [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) messages.
    * [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924): Provides the message data and inherits from the [Parcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018) class.
    * [RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984): Reports IPC exceptions and inherits from the [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) class.
    * [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299): Implements and manages remote objects.
    * [RemoteProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteproxy-0000001054440257): Implements and manages remote proxies.
    * [RemoteObjectCallbackList](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228): Manages the list of callbacks and automatically removes a callback from the list if the process hosting the callback dies.
    * [ReliableFileDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reliablefiledescriptor-0000001054358958): Wraps reliable file descriptors that can be accessed from multiple threads.

---|---

#### Class Summary

Class | Description  
---|---  
[IPCSkeleton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ipcskeleton-0000001054238969) | Provides static interfaces in the IPC skeleton to obtain services, read and write objects, obtain the UID and PID, obtain the IDs of local and peer devices, and check whether an interface call is made on the same device.  
[MessageOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageoption-0000001054678939) | Defines options for sending messages together with sendRequest.

[ReliableFileDescriptor.AutoCloseFileInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reliablefiledescriptor_autoclosefileinputstream-0000001120951645) | Represents a file input stream whose file descriptor is automatically closed when this stream is closed.  
[ReliableFileDescriptor.AutoCloseFileOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reliablefiledescriptor_autoclosefileoutputstream-0000001078032078) | Represents a file output stream whose file descriptor is automatically closed when this stream is closed.

[RemoteProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteproxy-0000001054440257) | Implements [IRemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970) proxy objects.
