# LightAgent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.light.agent.LightAgent
    
    public class LightAgent
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Manages lights on hardware devices. 

This class allows you to query a light based on its ID, check whether the light supports a specific blinking effect, enable the light to blink with a certain effect, and turn on or off the light.
