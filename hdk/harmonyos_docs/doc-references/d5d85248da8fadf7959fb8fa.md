Immutable in-memory representation of grammar.  This object represents a set of constraints that can be checked/ enforced against an XML document.  A [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001060519193) object is thread safe and applications are encouraged to share it across many parsers in many threads.  A [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001060519193) object is immutable in the sense that it shouldn't change the set of constraints once it is created. In other words, if an application validates the same document twice against the same [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001060519193), it must always produce the same result.  A [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001060519193) object is usually created from SchemaFactory.  Two kinds of validators can be created from a [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001060519193) object. One is [Validator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validator-0000001060388832), which provides highly-level validation operations that cover typical use cases. The other is [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147), which works on top of SAX for better modularity.  This specification does not refine the [Object.equals(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446#ZH-CN_TOPIC_0000001054678446__equals-java_lang_Object-) method.
