# InstantiationException  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.ReflectiveOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reflectiveoperationexception-0000001054199726) |---|---|---|---java.lang.InstantiationException
    
    public class InstantiationException
    extends [ReflectiveOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reflectiveoperationexception-0000001054199726)  
  
---  
Thrown when an application tries to create an instance of a class using the newInstance method in class Class, but the specified class object cannot be instantiated. The instantiation can fail for a variety of reasons including but not limited to: 
    * the class object represents an abstract class, an interface, an array class, a primitive type, or void 
    * the class has no nullary constructor 

**Since:**

JDK1.0
