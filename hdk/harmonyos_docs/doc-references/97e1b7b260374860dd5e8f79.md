# Image.Component

Describes image color components. 

This class provides methods for obtaining image color component attributes, and reading and writing color component data.

#### [h2]getBuffer

public [ByteBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771) getBuffer​()

Obtains the [ByteBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771) object of the current color component.
