# PipedOutputStream  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403) |---|---java.io.PipedOutputStream
    
    public class PipedOutputStream
    extends [OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403)  
  
---  
A piped output stream can be connected to a piped input stream to create a communications pipe. The piped output stream is the sending end of the pipe. Typically, data is written to a PipedOutputStream object by one thread and data is read from the connected PipedInputStream by some other thread. Attempting to use both objects from a single thread is not recommended as it may deadlock the thread. The pipe is said to be __broken_ _ if a thread that was reading data bytes from the connected piped input stream is no longer alive.

JDK1.0

#### [h2]connect

public void connect​([PipedInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pipedinputstream-0000001054358422) snk) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Connects this piped output stream to a receiver. If this object is already connected to some other piped input stream, an IOException is thrown. 

If snk is an unconnected piped input stream and src is an unconnected piped output stream, they may be connected by either the call: 
    
    src.connect(snk)

or the call: 
    
    snk.connect(src)

The two calls have the same effect. 

**Parameters:**
