Allows your application to interact with media sessions to control media playback, for example, to start or stop playback, or play the next media item. You can register a callback to receive changes, for example, of metadata and playback states from a media session.**Since:** 3**See Also:** [AVSession](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avsession-0000001054838902)Nested Class Summary Modifier and Type | Class | Description
