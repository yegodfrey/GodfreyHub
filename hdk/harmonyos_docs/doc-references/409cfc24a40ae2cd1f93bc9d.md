# NetworkState

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.telephony.NetworkState
    
    public final class NetworkState
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Records information about the network state of a device and provides methods for obtaining the information 

Applications can obtain the following network state information: 

    * Operator name, including the operator name in the long alphanumeric format, operator name in the short alphanumeric format, and public land mobile network (PLMN) code 
    * Network status, including in_service, out_of_service, emergency_only, and power_off 
    * Roaming status 
    * 5G non-standalone (NSA) registration status
