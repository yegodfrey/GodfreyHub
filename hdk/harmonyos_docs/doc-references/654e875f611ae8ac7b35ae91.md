# LinearShader

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.render.Shader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746) |---|---ohos.agp.render.LinearShader

Represents a shader that shades colors in linear manner. 

This class inherits from [Shader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746). You can use the methods in this class to configure the direction of the shading colors, for example, from left to right, from top to bottom, or from the upper left corner to the lower right corner.

#### Field Detail

#### [h2]points

public [Point](https://developer.harmonyos.com/cn/docs/documentation/doc-references/point-0000001054358735)[] points

Indicates the coordinates of the start and end points of the shading line. 

The points array contains two elements, representing the coordinates of the start and end points of the shading line respectively. For example. If the points value is {(200,200), (400, 500)}, the shading area is defined by the enclosing rectangle of these two coordinates, and the colors will be shaded along the line from the start point to the end point.

**Since:**

3

#### [h2]stops

public float[] stops

Indicates the positions corresponding the shading colors in the [Shader#shaderColors](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746#ZH-CN_TOPIC_0000001054518746__shaderColors) array. 

The positions of colors in stops increase monotonically from 0 to 1.0. When stops is null, the colors are evenly shaded.
