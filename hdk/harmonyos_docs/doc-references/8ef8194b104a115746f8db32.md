# InvalidPreferencesFormatException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---java.util.prefs.InvalidPreferencesFormatException
    
    public class InvalidPreferencesFormatException
    extends [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708)  
  
---  
Thrown to indicate that an operation could not complete because the input did not conform to the appropriate XML document type for a collection of preferences, as per the [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054518652) specification.

1.4
