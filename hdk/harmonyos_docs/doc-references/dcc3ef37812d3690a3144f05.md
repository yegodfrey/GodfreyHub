The value can be any of the following: [Shader.TileMode.CLAMP_TILEMODE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader_tilemode-0000001054200008#ZH-CN_TOPIC_0000001054200008__CLAMP_TILEMODE): copies the edge color. [Shader.TileMode.REPEAT_TILEMODE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader_tilemode-0000001054200008#ZH-CN_TOPIC_0000001054200008__REPEAT_TILEMODE): repeats the image vertically. [Shader.TileMode.MIRROR_TILEMODE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader_tilemode-0000001054200008#ZH-CN_TOPIC_0000001054200008__MIRROR_TILEMODE): repeats the image vertically, alternating mirror images.
