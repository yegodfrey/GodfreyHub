# InputFilter

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.text.InputFilter
    
    public abstract class InputFilter
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
An abstract class that provides methods to filter the input text based on the specified criteria. The derived class needs to implement the [filter(java.lang.CharSequence,ohos.agp.text.InputFilter.Range,java.lang.CharSequence,ohos.agp.text.InputFilter.Range)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputfilter-0000001217877963#ZH-CN_TOPIC_0000001217877963__filter-java_lang_CharSequence-ohos_agp_text_InputFilter_Range-java_lang_CharSequence-ohos_agp_text_InputFilter_Range-) method. Both plain text and [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706) are supported.

#### [h2]filter

public abstract [CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442) filter​([CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442) source, [InputFilter.Range](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputfilter_range-0000001217996535) sourceRange, [CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442) dest, [InputFilter.Range](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputfilter_range-0000001217996535) destRange)

Filters the input text, which can be plain text or [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706). If the source is rich text, the text itself will change. In other cases, the text will not change. Depending on the derived class of [InputFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputfilter-0000001217877963), determine whether to pass null to dest and destRange. For example, pass null if the derived class is [CharInputFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charinputfilter-0000001172398158) or [UpperCaseFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uppercasefilter-0000001172556714). For [LengthFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lengthfilter-0000001172716656), do not pass null to dest and destRange, because these two parameters restrict the source text together with sourceRange. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
source  |  Indicates that source strings to be filtered.  
sourceRange  |  Indicates the filtering range of the source text. Only text in this range is filtered.  
dest  |  Indicates the destination text.  
destRange  |  Indicates the filtering range of the destination text.  
  
**Returns:**

Returns text after filtering; returns null if the input source text is null or the specified [Range](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputfilter_range-0000001217996535) is invalid.
