# Overview  
  
Classes for matching character sequences against patterns specified by regular expressions. 

An instance of the [Pattern](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pattern-0000001054439927) class represents a regular expression that is specified in string form in a syntax similar to that used by Perl. 

Instances of the [Matcher](https://developer.harmonyos.com/cn/docs/documentation/doc-references/matcher-0000001054119898) class are used to match character sequences against a given pattern. Input is provided to matchers via the [CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442) interface in order to support matching against characters from a wide variety of input sources. 

Unless otherwise noted, passing a null argument to a method in any class or interface in this package will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown. 

**Related Documentation**

An excellent tutorial and overview of regular expressions is [_Mastering Regular Expressions_ , Jeffrey E. F. Friedl, O'Reilly and Associates, 1997.](http://www.oreilly.com/catalog/regex/)
