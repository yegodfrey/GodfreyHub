# Overview  
  
Manages vibrators on hardware devices. 

This package provides basic operations for vibrators, including querying whether a vibrator exists or supports a specific vibration effect, setting vibrator parameters such as the vibration duration, intensity, and vibration counts, customizing a vibration effect, and controlling the start and stop of a vibrator's vibration.
