# Picker.ElementFormatter
    
    public static interface Picker.ElementFormatter  
  
---  
Formats the left and right compound element objects for every item of [Picker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picker-0000001054119976). 

The [leftElement(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picker_elementformatter-0000001054678679#ZH-CN_TOPIC_0000001054678679__leftElement-int-) interface needs to be implemented to display an element object on the left of every item. 

The [rightElement(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picker_elementformatter-0000001054678679#ZH-CN_TOPIC_0000001054678679__rightElement-int-) interface needs to be implemented to display an element object on the right of every item. 

null is returned if no element object is required on either side of the item.
