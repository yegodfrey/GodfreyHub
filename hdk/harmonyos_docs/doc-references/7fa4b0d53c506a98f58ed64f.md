# Component.MouseEventListener
    
    public static interface Component.MouseEventListener  
  
---  
Provides a callback to be invoked when a mouse event is dispatched from a component. 

This callback will be invoked before the component receives the event.

#### [h2]onMouseEvent

boolean onMouseEvent​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, [MouseEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mouseevent-0000001054200230) event)

Processes a mouse event dispatched to a component. 

The listener responds to a mouse event before the component receives the event.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component to which the mouse event is dispatched.  
event  |  Indicates all information about the mouse event.  
  
**Returns:**

Returns true if the listener has processed the event; returns false otherwise.
