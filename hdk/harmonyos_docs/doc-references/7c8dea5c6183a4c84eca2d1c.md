# DefaultHandler

Default base class for SAX2 event handlers. 

This module, both source code and documentation, is in the Public Domain, and comes with **NO WARRANTY**. See <http://www.saxproject.org> for further information. 

This class is available as a convenience base class for SAX2 applications: it provides default implementations for all of the callbacks in the four core SAX2 handler classes:

    * [EntityResolver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/entityresolver-0000001060519205)
    * [DTDHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dtdhandler-0000001060157257)
    * [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797)
    * [ErrorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/errorhandler-0000001059908837)

Application writers can extend this class when they need to implement only part of an interface; parser writers can instantiate this class to provide default handlers when the application has not supplied its own.

This class replaces the deprecated SAX1 [HandlerBase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/handlerbase-0000001061156882) class.

**Since:**

SAX 2.0
