Represents an index schema. The index schema supports the following index fields: identifier, title, subtitle, name, alternateName, category, dateCreate, keywords, description, thumbnailUrl, url, potentialAction, reserved1, and reserved2. All other schemas will inherit this class, for example, [ContactItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contactitem-0000001078480112), [MessageItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageitem-0000001120951637), [DocumentItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documentitem-0000001120712377), [EmailItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/emailitem-0000001121107271), and [ContactItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contactitem-0000001078480112). **Since:** 5Constructor Summary Constructor | Description
