# LongUnaryOperator
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface LongUnaryOperator  
  
---  
Represents an operation on a single long-valued operand that produces a long-valued result. This is the primitive type specialization of [UnaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unaryoperator-0000001054518644) for long. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsLong(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longunaryoperator-0000001054518642#ZH-CN_TOPIC_0000001054518642__applyAsLong-long-).

**Since:**

1.8

[UnaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unaryoperator-0000001054518644)
