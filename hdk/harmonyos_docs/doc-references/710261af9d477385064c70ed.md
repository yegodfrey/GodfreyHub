# KeyGenAlgorithmParaSpec

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.security.keystore.KeyGenAlgorithmParaSpec
    
    public class KeyGenAlgorithmParaSpec
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [AlgorithmParameterSpec](https://developer.harmonyos.com/cn/docs/documentation/doc-references/algorithmparameterspec-0000001054358527)

Sets algorithm parameters for key generation. 

The following parameters can be set: key alias, length, usage(purposes), parameter set for key encryption, attribute set for key access control, and key accessibility period after user authentication.
