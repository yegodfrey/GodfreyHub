# LightweightSet

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.LightweightSet<E>
    
    public final class LightweightSet<E>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Collection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563)<E>, [Set](https://developer.harmonyos.com/cn/docs/documentation/doc-references/set-0000001054439873)<E>  
  
---  
Provides a container that implements the [Collection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563) and [Set](https://developer.harmonyos.com/cn/docs/documentation/doc-references/set-0000001054439873) interfaces. 

The LightweightSet container uses less memory than the [HashSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/hashset-0000001054678594) container, but may show poor performance when reaching a large size. 

It is recommended that you use this container when less memory is required. 

Note: The thread is secure only when data is read from the LightweightSet container.

1
