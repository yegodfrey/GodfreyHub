# Overview  
  
Provides constant and utility classes specific to automatic speech recognition (ASR).

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[AsrError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrerror-0000001054678764) | Defines result codes for invoking the ASR capability.  
[AsrEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrevent-0000001054358743) | Stores events to be reported during ASR.  
[AsrResultKey](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrresultkey-0000001054558765) | Stores the keywords in ASR callback results.
