# CommonEventSupport

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.commonevent.CommonEventSupport
    
    public class CommonEventSupport
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a series of static system-level constants of common events. 

You need to use these constants as the input values of action when you call [Intent.setAction(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019#ZH-CN_TOPIC_0000001054120019__setAction-java_lang_String-) in [CommonEventData#CommonEventData(Intent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventdata-0000001054558837#ZH-CN_TOPIC_0000001054558837__CommonEventData-ohos_aafwk_content_Intent-) to set the common event content to be published, or when you call [MatchingSkills#addEvent(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/matchingskills-0000001054120094#ZH-CN_TOPIC_0000001054120094__addEvent-java_lang_String-) in [CommonEventSubscribeInfo#CommonEventSubscribeInfo(MatchingSkills)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscribeinfo-0000001054838790#ZH-CN_TOPIC_0000001054838790__CommonEventSubscribeInfo-ohos_event_commonevent_MatchingSkills-) to set the filter criteria for subscribing to common events.
