# ImageRichStyle

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.text.richstyles.RichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richstyle-0000001218158007) |---|---ohos.agp.text.richstyles.ImageRichStyle
    
    public class ImageRichStyle
    extends [RichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richstyle-0000001218158007)  
  
---  
Implements rich styles for images inserted into the text. This class must be used in a [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706) instance. 

An inserted image replaces the text in a given range.
