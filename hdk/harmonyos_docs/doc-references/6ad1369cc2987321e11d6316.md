# LongToDoubleFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface LongToDoubleFunction  
  
---  
Represents a function that accepts a long-valued argument and produces a double-valued result. This is the long-to-double primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsDouble(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longtodoublefunction-0000001054439915#ZH-CN_TOPIC_0000001054439915__applyAsDouble-long-).
