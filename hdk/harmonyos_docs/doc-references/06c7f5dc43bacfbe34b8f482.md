#### Element Detail

#### [h2]value

[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) value

The name of the required permission when a permission is required. If more than one permission is required, specify [all()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__all--) or [any()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__any--). 

If this parameter is specified, both [any()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__any--) and [all()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__all--) must be empty.

#### [h2]any

[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460)[] any

Specifies a list of permission names, where at least one permission name is required. 

If this parameter is specified, both [all()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__all--) and [value()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__value--) must be empty.

#### [h2]all

[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460)[] all

Specifies a list of all required permission names. 

If this parameter is specified, both [any()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__any--) and [value()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/needspermission-0000001078032080#ZH-CN_TOPIC_0000001078032080__value--) must be empty.

#### [h2]partial

boolean partial

If this value is true, permission is not necessarily required in all cases.
