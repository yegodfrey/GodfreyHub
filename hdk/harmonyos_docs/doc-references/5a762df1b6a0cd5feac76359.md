# PhotoItem

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.data.search.model.IndexData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/indexdata-0000001054120157) |---|---[ohos.data.search.schema.Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001121107273)<[PhotoItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/photoitem-0000001078480114)> |---|---|---ohos.data.search.schema.PhotoItem

Represents the index schema for photo items. 

This schema is used to create indexes for photo items. It supports index fields size, height, width, photoCategory, shootingMode, shooting location (represented by country, province, city, district, road, latitude, and longitute), shootingDate, tag, feature, ocrText, holiday, and all the fields in [CommonItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commonitem-0000001078320140). Among these fields, identifier is mandatory and can be set via the [CommonItem#setIdentifier(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001121107273#ZH-CN_TOPIC_0000001121107273__setIdentifier-java_lang_String-) method.
