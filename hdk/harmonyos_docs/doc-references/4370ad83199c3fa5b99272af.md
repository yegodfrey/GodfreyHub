#### Method Detail

#### [h2]onForwardHover

boolean onForwardHover​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, [MultimodalEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodalevent-0000001054518970) event)

Decide whether forward a mouse hover event to child component or not. In case of no listener, mouse hover event will be forwarded to children in default. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component container which the mouse hover event is forwarded.  
event  |  Indicates the forwarded hover event.  
  
**Returns:**

Returns true if the listener agree to forward mouse hover event to child component; returns false otherwise.
