# GeneralReceiver

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.app.GeneralReceiver
    
    public class GeneralReceiver
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Provides generic callback methods for receiving results from other processes during inter-process communication (IPC). 

You can create a child class instance, override the [onReceive(int, ohos.utils.PacMap)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/generalreceiver-0000001054238779#ZH-CN_TOPIC_0000001054238779__onReceive-int-ohos_utils_PacMap-) method, and send the child class instance to the peer end through IPC. The peer end then uses [sendResult(int, ohos.utils.PacMap)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/generalreceiver-0000001054238779#ZH-CN_TOPIC_0000001054238779__sendResult-int-ohos_utils_PacMap-) to send the result back.
