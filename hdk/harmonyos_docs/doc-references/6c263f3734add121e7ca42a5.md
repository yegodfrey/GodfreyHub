TabList.TabSelectedListener
    
    public static interface TabList.TabSelectedListener  
  
---  
Provides a tab selected listener. This interface must be associated with a [TabList](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tablist-0000001054238721) before being implemented to process tab selected events.
