Set the size and class type of the deferred surface when configuring the camera for the first time. After the surface is ready, add it to the camera configuration by calling [CameraConfig.Builder#addDeferredSurface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig_builder-0000001054120170#ZH-CN_TOPIC_0000001054120170__addDeferredSurface-ohos_agp_graphics_Surface-). This reduces camera startup latency caused by UI loading for complex applications, improving application startup performance. Only one surface can be used as the deferred surface, which is usually used for preview.
