# Overview  
  
Provide utility classes for international calendar, time, address, and region, as well as locale matching.

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[CalendarUtils](https://developer.harmonyos.com/cn/docs/documentation/doc-references/calendarutils-0000001054120179) | A utility class for Calendar, with the method for obtaining the local calendar name.  
[LocalesFallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/localesfallback-0000001054120108) | Provides methods for determining the prioritized order for locale matching.  
[TextRecognitionUtils](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textrecognitionutils-0000001054440137) | Recognizes and returns time, date, phone number, and address information in a given text.
