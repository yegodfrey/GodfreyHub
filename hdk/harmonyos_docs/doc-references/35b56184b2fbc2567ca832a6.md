Indicates that an unknown kind of element was encountered. This can occur if the language evolves and new kinds of elements are added to the Element hierarchy. May be thrown by an [element visitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementvisitor-0000001123534698) to indicate that the visitor was created for a prior version of the language.**Since:** 1.6**See Also:** [ElementVisitor.visitUnknown(javax.lang.model.element.Element, P)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementvisitor-0000001123534698#ZH-CN_TOPIC_0000001123534698__visitUnknown-javax_lang_model_element_Element-P-), Constructor Summary Constructor | Description
