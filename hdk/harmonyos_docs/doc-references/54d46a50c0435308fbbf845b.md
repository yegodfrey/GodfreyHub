#### [h2]addSurface

[FrameConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926) addSurface​([Surface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/surface-0000001054120059) surface)

Adds a surface as frame capture output. 

The output surface to be added must have been added by calling [CameraConfig.Builder#addSurface(Surface)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig_builder-0000001054120170#ZH-CN_TOPIC_0000001054120170__addSurface-ohos_agp_graphics_Surface-), and the camera have been successfully configured with [CameraConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig-0000001054120241). Otherwise, frame capture methods defined in [Camera](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866) may throw parameter exceptions.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
surface  |  Indicates an output surface to be added.

#### [h2]setFaceDetection

[FrameConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926) setFaceDetection​(int type, boolean isEnable)

Sets face detection and returns the result through a callback. 

Only a supported type of face detection can be set using this method. The supported face detection types can be obtained by calling [CameraAbility#getSupportedFaceDetection()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraability-0000001054358900#ZH-CN_TOPIC_0000001054358900__getSupportedFaceDetection--). 

The face detection result can be obtained by [FrameResult#getFaceDetectionResult()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameresult-0000001054678914#ZH-CN_TOPIC_0000001054678914__getFaceDetectionResult--).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
type  |  Indicates the face detection type. The face detection type to set must be one or more supported types. Both Metadata.FaceDetectionType.FACE_DETECTION and Metadata.FaceDetectionType.FACE_SMILE_DETECTION can be enabled simultaneously by calling setFaceDetection(FaceDetectionType.FACE_DETECTION | FaceDetectionType.FACE_SMILE_DETECTION, true). An invalid detection type will be ignored.   
isEnable  |  Indicates whether face detection is enabled. true means detection is enabled, while false means it is disabled.  
  
**Returns:**

Returns a [Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926) object.

**Since:**

1

**See Also:**

[Metadata.FaceDetectionType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/metadata_facedetectiontype-0000001054358908)

#### [h2]setAfMode

[FrameConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926) setAfMode​(int afMode, [Rect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rect-0000001054558757) rect)

Sets the AF mode. 

Only a supported AF mode can be set using this method. The supported AF modes can be obtained by [CameraAbility#getSupportedAfMode()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraability-0000001054358900#ZH-CN_TOPIC_0000001054358900__getSupportedAfMode--). 

The AF result can be obtained by [FrameResult#getAfResult()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameresult-0000001054678914#ZH-CN_TOPIC_0000001054678914__getAfResult--).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
afMode  |  Indicates the AF mode to set. An invalid AF mode will be ignored.  
rect  |  Indicates a rectangular area for AF. If the input value is null, the area is the same as the preview area. The central coordinate system is adopted, which ranges from (-1000, -1000) to (1000, 1000), to describe the AF area. The value range and direction are consistent with those of the preview area, regardless of zooming, rotation direction, and other factors alike.  If the rectangle AF area exceeds the valid range, the AF mode will not take effect.  
  
**Returns:**

Returns a [Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926) object.

**Since:**

1
