#### Method Detail

#### [h2]onForwardTouch

boolean onForwardTouch​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, [TouchEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/touchevent-0000001054558959) event)

Decide whether forward a touch event to child component or not. In case of no listener, touch event will be forwarded to children in default. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component from which the touch event is forwarded.  
event  |  Indicates all information about the touch event.  
  
**Returns:**

Returns true if the listener agree to forward touch event to child component; returns false otherwise.
