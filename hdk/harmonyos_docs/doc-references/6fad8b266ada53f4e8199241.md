# DataObserver

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.abilityjet.activedata.DataObserver<T>
    
    public abstract class DataObserver<T>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A base class of observers that receive notifications upon data changes of [ActiveData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/activedata-0000001054120017). 

Observers of ActiveData must inherit this class and override the [onChanged(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054119946#ZH-CN_TOPIC_0000001054119946__onChanged-T-) method. In this way, ActiveData can notify observers of data changes by using [onChanged(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054119946#ZH-CN_TOPIC_0000001054119946__onChanged-T-).

DataObserver holds a [Lifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967) object by using the [setLifecycle(ohos.aafwk.ability.Lifecycle)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054119946#ZH-CN_TOPIC_0000001054119946__setLifecycle-ohos_aafwk_ability_Lifecycle-) method. The object indicates the lifecycle of the matching Ability or AbilitySlice. DataObserver also allows ActiveData to observe its lifecycle changes. Therefore, DataObserver and ActiveData observe each other. DataObserver observes data changes of ActiveData, and ActiveData observes lifecycle changes of DataObserver.
