Provides Serial Port Profile (SPP) client sockets. To use this class, you must use [DataListenSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datalistensocket-0000001172398174) to create an [SppServerSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200). When a new connection is accepted by the server, [SppServerSocket#accept](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200#ZH-CN_TOPIC_0000001172238200__accept--) returns a new [SppClientSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppclientsocket-0000001218076501) to manage the data link.  On the client, you can use [SppClientSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppclientsocket-0000001218076501) to start a new socket connection. **Since:** 7Field Summary Modifier and Type | Field | Description
