# IndexedPropertyChangeEvent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.EventObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventobject-0000001054119921) |---|---[java.beans.PropertyChangeEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertychangeevent-0000001054358405) |---|---|---java.beans.IndexedPropertyChangeEvent
    
    public class IndexedPropertyChangeEvent
    extends [PropertyChangeEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertychangeevent-0000001054358405)  
  
---  
An "IndexedPropertyChange" event gets delivered whenever a component that conforms to the JavaBeans™ specification (a "bean") changes a bound indexed property. This class is an extension of PropertyChangeEvent but contains the index of the property that has changed. 

Null values may be provided for the old and the new values if their true values are not known. 

An event source may send a null object as the name to indicate that an arbitrary set of if its properties have changed. In this case the old and new values should also be null.

**Since:**

1.5
