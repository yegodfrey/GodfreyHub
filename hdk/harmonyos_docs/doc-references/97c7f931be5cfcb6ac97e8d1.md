Provides the entry for using camera functions. In general, the camera workflow is as follows: 
                * [Mandatory] Call [CameraKit#getInstance(Context)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__getInstance-ohos_app_Context-) to obtain a CameraKit instance. 
                * [Optional] Register a callback to monitor camera usage states using [CameraKit#registerCameraDeviceCallback(CameraDeviceCallback, EventHandler)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__registerCameraDeviceCallback-ohos_media_camera_device_CameraDeviceCallback-ohos_eventhandler_EventHandler-) and unregister the callback by [CameraKit#unregisterCameraDeviceCallback(CameraDeviceCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__unregisterCameraDeviceCallback-ohos_media_camera_device_CameraDeviceCallback-). 
                * [Mandatory] Get all the supported logical cameras by calling [CameraKit#getCameraIds()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__getCameraIds--). 
                * [Optional] Get more information about a physical camera by calling [CameraKit#getCameraInfo(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__getCameraInfo-java_lang_String-). The information includes the camera facing direction, physical cameras that belong to the logical camera, and connection types of physical cameras. 
                * [Optional] Get static abilities of a logical or physical camera by calling [CameraKit#getCameraAbility(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__getCameraAbility-java_lang_String-) and query the supported abilities and their configuration ranges through a specific ability querying method. For example, you can query the support for the zoom function by using [CameraAbility#getSupportedZoom()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraability-0000001054358900#ZH-CN_TOPIC_0000001054358900__getSupportedZoom--). 
                * [Mandatory] Create a logical or physical camera by calling [CameraKit#createCamera(String, CameraStateCallback, EventHandler)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__createCamera-java_lang_String-ohos_media_camera_device_CameraStateCallback-ohos_eventhandler_EventHandler-). 
                * [Mandatory] Start running the camera by calling methods provided in Camera.
