Displays detailed caution information when a caution detection rule is applied. When one of the detection rules defined in [HiChecker.Rule](https://developer.harmonyos.com/cn/docs/documentation/doc-references/hichecker_rule-0000001078320148) is applied, the system creates a Caution object as the parameter of HiChecker.OnCautionListenser#onCautionFound(Caution).
