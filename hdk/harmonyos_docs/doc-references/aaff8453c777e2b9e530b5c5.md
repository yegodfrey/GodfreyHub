# Component.DraggedListener
    
    public static interface Component.DraggedListener  
  
---

#### [h2]onDragPreAccept

default boolean onDragPreAccept​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, int dragDirection)

Accepts the drag event dispatched to a component. 

This method supports the [Component.DRAG_HORIZONTAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_HORIZONTAL), [Component.DRAG_VERTICAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_VERTICAL) and [Component.DRAG_HORIZONTAL_VERTICAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_HORIZONTAL_VERTICAL). When [Component.DRAG_HORIZONTAL_VERTICAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_HORIZONTAL_VERTICAL) is set, the drag direction may be rough.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component to which a drag event is dispatched.  
dragDirection  |  Indicates the drag direction, which can be [Component.DRAG_UP](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_UP), [Component.DRAG_DOWN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_DOWN), [Component.DRAG_LEFT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_LEFT), or [Component.DRAG_RIGHT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_RIGHT).  
  
**Returns:**

Returns true (default value) if the current drag event is accepted; returns false otherwise.
