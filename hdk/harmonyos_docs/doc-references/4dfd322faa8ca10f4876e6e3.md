# RadioContainer.CheckedStateChangedListener
    
    public static interface RadioContainer.CheckedStateChangedListener  
  
---  
Provides callback methods to process change events of a radio button container. 

For example, you can use this interface to select another radio button in the radio container, or deselect all radio buttons in the container.

#### [h2]onCheckedChanged

void onCheckedChanged​([RadioContainer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radiocontainer-0000001054678720) container, int checkedId)

Callback to process change events of a radio button container. 

When the state of a radio button in the group changes from deselected to selected or vice versa, the value of checkedId indicates the ID of the selected radio button. If all radio buttons are deselected, the value of checkedId is [RadioContainer.INVALID_ID](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radiocontainer-0000001054678720#ZH-CN_TOPIC_0000001054678720__INVALID_ID).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
container  |  Indicates the radio button container where the state of a radio button changes.  
checkedId  |  Indicates the ID of the most recently selected radio button.
