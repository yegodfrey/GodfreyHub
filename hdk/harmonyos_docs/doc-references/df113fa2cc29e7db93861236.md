# IntentAgent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.intentagent.IntentAgent
    
    public final class IntentAgent
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Provides a pending intent mechanism to perform an action only when certain conditions are met or certain events are triggered. For example, after you receive a notification, a new ability will be triggered only if you click this notification. The actions to be performed include abilities and common events. 

This class does not provide constructors. Instead, you need to use the [IntentAgentHelper#getIntentAgent(Context, IntentAgentInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagenthelper-0000001054358826#ZH-CN_TOPIC_0000001054358826__getIntentAgent-ohos_app_Context-ohos_event_intentagent_IntentAgentInfo-) method to obtain an IntentAgent object, and set the action to perform in [IntentAgentInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagentinfo-0000001054120167). After obtaining the IntentAgent object, you can call the [IntentAgentHelper#triggerIntentAgent(Context, IntentAgent, IntentAgent.OnCompleted, EventHandler, TriggerInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagenthelper-0000001054358826#ZH-CN_TOPIC_0000001054358826__triggerIntentAgent-ohos_app_Context-ohos_event_intentagent_IntentAgent-ohos_event_intentagent_IntentAgent_OnCompleted-ohos_eventhandler_EventHandler-ohos_event_intentagent_TriggerInfo-) method to perform the action specified for the IntentAgent object immediately and call [IntentAgentHelper#cancel(IntentAgent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagenthelper-0000001054358826#ZH-CN_TOPIC_0000001054358826__cancel-ohos_event_intentagent_IntentAgent-) to cancel the IntentAgent object.
