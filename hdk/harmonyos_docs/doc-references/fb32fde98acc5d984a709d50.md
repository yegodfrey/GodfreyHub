[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.ability.continuation.ContinuationDeviceInfo

Defines the information about the device selected by the user. 

You can obtain a ContinuationDeviceInfo object from the hop task management service when the user selects a device from the device list.
