A character stream that collects its output in a string buffer, which can then be used to construct a string.  Closing a StringWriter has no effect. The methods in this class can be called after the stream has been closed without generating an IOException. **Since:** JDK1.1Field Summary Fields inherited from class java.io.[Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710)
