# Overview  
  
Provides utility classes about mathematics for the 3D engine. It provides common operations such as vector, quaternion, and matrix in 3D scenes. 

For example, you can use this package to complete operations for a binary vector, ternary vector, quaternary vector, quaternion, and 4x4 matrix.

**Since:**

3
