# Picture

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.render.Picture
    
    public class Picture
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Records drawing calls and then draw objects by playing the calls back to Canvas through [Canvas#drawPicture](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731#ZH-CN_TOPIC_0000001054238731__drawPicture-ohos_agp_render_Picture-). 

The recorded drawing calls can be played back via [Canvas#drawPicture](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731#ZH-CN_TOPIC_0000001054238731__drawPicture-ohos_agp_render_Picture-). Drawing objects using a Picture instance can be faster than calling equivalent methods. This approach is applicable to the scenario where some objects need to be drawn for multiple times.

#### [h2]beginRecording

public [Canvas](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731) beginRecording​(int width, int height)

Starts recording. 

After you call this method, a Canvas instance used for recording drawing operations will be returned. This method must be used together with [Picture#endRecording](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picture-0000001060268769#ZH-CN_TOPIC_0000001060268769__endRecording--).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
width  |  Indicates the width of the picture whose coordinate in the upper left corner starts from (0,0). The drawing that exceeds the width may or may not be drawn.  
height  |  Indicates the height of the picture whose coordinate in the upper left corner starts from (0,0). The drawing that exceeds the height may or may not be drawn.  
  
**Returns:**

Returns a Canvas instance that records drawing calls. All drawings in the Canvas are stored in this Picture.

3
