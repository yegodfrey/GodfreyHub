# Overview  
  
Provide methods for the natural language understanding (NLU) service. 

For example, you can use the methods in this package to recognize entities, attach part of speech (POS) tags, and extract keywords.

**Since:**

3

Interface | Description  
---|---  
[OnResultListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/onresultlistener-0000001054440061)<T> | Provides a callback for observing NLU method calls.
