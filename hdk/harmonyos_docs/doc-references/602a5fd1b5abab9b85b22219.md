# Overview  
  
Provides classes related to the following camera operations: 
    * Camera feature query 
    * Camera configuration 
    * Frame capture 
    * Camera state listening 

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Camera](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866) | Interface for using the camera.  
[CameraAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraability-0000001054358900) | Queries static abilities of the camera.  
[CameraConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig-0000001054120241) | Provides methods to configure the camera, such as adding or removing a surface, and setting the camera running mode.  
[CameraConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig_builder-0000001054120170) | Used to create a [CameraConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig-0000001054120241) instance.  
[CameraInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerainfo-0000001054440199) | Gets logical camera information, such as the facing type of the camera, connected physical cameras, and link type.  
[FrameConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig-0000001054200186) | Provides methods for frame capture configuration, image processing, and image output.  
[FrameConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926) | Provides frame configuration [Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926) objects.  
[FrameResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameresult-0000001054678914) | Describes results generated during frame capture.  
  
#### Class Summary

Class | Description  
---|---  
[CameraDeviceCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameradevicecallback-0000001054558915) | Provides callbacks for camera usage states.  
[CameraStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerastatecallback-0000001054238913) | Provides callbacks for camera running states.  
[FrameStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/framestatecallback-0000001054678883) | Provides callbacks for the frame processing states.
