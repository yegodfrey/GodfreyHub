# ElementNameEx

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.interwork.bundle.ElementNameEx
    
    public class ElementNameEx
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001), [ParcelableEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcelableex-0000001054678859)  
  
---  
Contains basic [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) information, which uniquely identifies an ability. In an Ohos process, your ability basic information is stored in a ElementNameEx object. This object will be marshalled and then transmitted to a process in another platform. After receiving the marshalled object, that process will unmarshal it and then read the data.
