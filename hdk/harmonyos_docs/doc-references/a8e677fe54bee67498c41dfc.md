A static inner class that uses the singleton pattern to implement abstract methods of the SEOperatorAbs abstract class and provide pan-payment functions related to secure keys and vehicle keys. This class provides interfaces to create, delete, and update supplementary security domains, modify configurations, and query and change switch status. Supplementary secure domain management with secure communication between applications associated with the outside world.
