# Overview  
  
Access to date and time using fields and units, and date time adjusters. 

This package expands on the base package to provide additional functionality for more powerful use cases. Support is included for: 

    * Units of date-time, such as years, months, days and hours
    * Fields of date-time, such as month-of-year, day-of-week or hour-of-day
    * Date-time adjustment functions
    * Different definitions of weeks
**Fields and Units**

Dates and times are expressed in terms of fields and units. A unit is used to measure an amount of time, such as years, days or minutes. All units implement [TemporalUnit](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalunit-0000001054518592). The set of well known units is defined in [ChronoUnit](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronounit-0000001054439867), such as DAYS. The unit interface is designed to allow application defined units. 

A field is used to express part of a larger date-time, such as year, month-of-year or second-of-minute. All fields implement [TemporalField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalfield-0000001054439865). The set of well known fields are defined in [ChronoField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronofield-0000001054119838), such as HOUR_OF_DAY. Additional fields are defined by [JulianFields](https://developer.harmonyos.com/cn/docs/documentation/doc-references/julianfields-0000001054558581), [WeekFields](https://developer.harmonyos.com/cn/docs/documentation/doc-references/weekfields-0000001054358568) and [IsoFields](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isofields-0000001054358559). The field interface is designed to allow application defined fields. 

This package provides tools that allow the units and fields of date and time to be accessed in a general way most suited for frameworks. [Temporal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532) provides the abstraction for date time types that support fields. Its methods support getting the value of a field, creating a new date time with the value of a field modified, and querying for additional information, typically used to extract the offset or time-zone. 

One use of fields in application code is to retrieve fields for which there is no convenience method. For example, getting the day-of-month is common enough that there is a method on LocalDate called getDayOfMonth(). However for more unusual fields it is necessary to use the field. For example, date.get(ChronoField.ALIGNED_WEEK_OF_MONTH). The fields also provide access to the range of valid values. 

**Adjustment and Query**

A key part of the date-time problem space is adjusting a date to a new, related value, such as the "last day of the month", or "next Wednesday". These are modeled as functions that adjust a base date-time. The functions implement [TemporalAdjuster](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporaladjuster-0000001054119907) and operate on Temporal. A set of common functions are provided in [TemporalAdjusters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporaladjusters-0000001054238579). For example, to find the first occurrence of a day-of-week after a given date, use [TemporalAdjusters.next(DayOfWeek)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporaladjusters-0000001054238579#ZH-CN_TOPIC_0000001054238579__next-java_time_DayOfWeek-), such as date.with(next(MONDAY)). Applications can also define adjusters by implementing [TemporalAdjuster](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporaladjuster-0000001054119907). 

The [TemporalAmount](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalamount-0000001054119836) interface models amounts of relative time. 

In addition to adjusting a date-time, an interface is provided to enable querying via [TemporalQuery](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalquery-0000001054199852). The most common implementations of the query interface are method references. The from(TemporalAccessor) methods on major classes can all be used, such as LocalDate::from or Month::from. Further implementations are provided in [TemporalQueries](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalqueries-0000001054678549) as static methods. Applications can also define queries by implementing [TemporalQuery](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalquery-0000001054199852). 

**Weeks**

Different locales have different definitions of the week. For example, in Europe the week typically starts on a Monday, while in the US it starts on a Sunday. The [WeekFields](https://developer.harmonyos.com/cn/docs/documentation/doc-references/weekfields-0000001054358568) class models this distinction. 

The ISO calendar system defines an additional week-based division of years. This defines a year based on whole Monday to Monday weeks. This is modeled in [IsoFields](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isofields-0000001054358559). 

**Package specification**

Unless otherwise noted, passing a null argument to a constructor or method in any class or interface in this package will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown. The Javadoc "@param" definition is used to summarise the null-behavior. The "@throws [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710)" is not explicitly documented in each method. 

All calculations should check for numeric overflow and throw either an [ArithmeticException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/arithmeticexception-0000001054358429) or a [DateTimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datetimeexception-0000001054199844).

#### Interface Summary

---|---  
[Temporal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532) | Framework-level interface defining read-write access to a temporal object, such as a date, time, offset or some combination of these.  
[TemporalAccessor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalaccessor-0000001054358566) | Framework-level interface defining read-only access to a temporal object, such as a date, time, offset or some combination of these.  
[TemporalAdjuster](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporaladjuster-0000001054119907) | Strategy for adjusting a temporal object.  
[TemporalAmount](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalamount-0000001054119836) | Framework-level interface defining an amount of time, such as "6 hours", "8 days" or "2 years and 3 months".  
[TemporalField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalfield-0000001054439865) | A field of date-time, such as month-of-year or hour-of-minute.  
[TemporalQuery](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalquery-0000001054199852)<R> | Strategy for querying a temporal object.  
[TemporalUnit](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalunit-0000001054518592) | A unit of date-time, such as Days or Hours.
