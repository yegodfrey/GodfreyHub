# Overview  
  
#### Interface Summary

Interface | Description  
---|---  
[AttributeList](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributelist-0000001060996902) | This interface has been replaced by the SAX2 [Attributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributes-0000001060519100) interface, which includes Namespace support.  
[Attributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributes-0000001060519100) | Interface for a list of XML attributes.  
[ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) | Receive notification of the logical content of a document.  
[DocumentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documenthandler-0000001060679092) | This interface has been replaced by the SAX2 [ContentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contenthandler-0000001060268797) interface, which includes Namespace support.  
[DTDHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dtdhandler-0000001060157257) | Receive notification of basic DTD-related events.  
[EntityResolver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/entityresolver-0000001060519205) | Basic interface for resolving entities.  
[ErrorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/errorhandler-0000001059908837) | Basic interface for SAX error handlers.  
[Locator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001060388844) | Interface for associating a SAX event with a document location.  
[Parser](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parser-0000001060039159) | This interface has been replaced by the SAX2 [XMLReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlreader-0000001060837300) interface, which includes Namespace support.  
[XMLReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlreader-0000001060837300) | Interface for reading an XML document using callbacks.  
  
#### Class Summary

Class | Description  
---|---  
[HandlerBase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/handlerbase-0000001061156882) | This class works with the deprecated [DocumentHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documenthandler-0000001060679092) interface.  
[InputSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputsource-0000001060996904) | A single input source for an XML entity.  
  
#### Exception Summary

Exception | Description  
---|---  
[SAXException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/saxexception-0000001060268799) | Encapsulate a general SAX error or warning.  
[SAXNotRecognizedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/saxnotrecognizedexception-0000001060679094) | Exception class for an unrecognized identifier.  
[SAXNotSupportedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/saxnotsupportedexception-0000001060157259) | Exception class for an unsupported operation.  
[SAXParseException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/saxparseexception-0000001060519207) | Encapsulate an XML parse error or warning.
