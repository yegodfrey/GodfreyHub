    public class CharArrayWriter
    extends [Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710)  
  
---  
This class implements a character buffer that can be used as an Writer. The buffer automatically grows when data is written to the stream. The data can be retrieved using toCharArray() and toString().  Note: Invoking close() on this class has no effect, and methods of this class can be called after the stream has closed without generating an IOException. **Since:** JDK1.1Field Summary Modifier and Type | Field | Description
