# Camera
    
    public interface Camera  
  
---  
Interface for using the camera. 

A camera object can be obtained only in the following way: 

Create a camera by calling [CameraKit.createCamera(String, CameraStateCallback, EventHandler)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__createCamera-java_lang_String-ohos_media_camera_device_CameraStateCallback-ohos_eventhandler_EventHandler-), and get camera running states by calling [CameraStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerastatecallback-0000001054238913). 

The recommended operation steps are as follows: 

    * Creating a camera: Call [CameraKit.createCamera(String, CameraStateCallback, EventHandler)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerakit-0000001054358891#ZH-CN_TOPIC_0000001054358891__createCamera-java_lang_String-ohos_media_camera_device_CameraStateCallback-ohos_eventhandler_EventHandler-). If the camera is successfully created, [CameraStateCallback#onCreated(Camera)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerastatecallback-0000001054238913#ZH-CN_TOPIC_0000001054238913__onCreated-ohos_media_camera_device_Camera-) is called. Otherwise, [CameraStateCallback#onCreateFailed(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerastatecallback-0000001054238913#ZH-CN_TOPIC_0000001054238913__onCreateFailed-java_lang_String-int-) is called. 
    * Configuring the camera: Get a [CameraConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig_builder-0000001054120170) instance by calling [Camera#getCameraConfigBuilder()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__getCameraConfigBuilder--), and then configure the camera by calling [Camera#configure(CameraConfig)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__configure-ohos_media_camera_device_CameraConfig-). If the camera is successfully configured, [CameraStateCallback#onConfigured(Camera)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerastatecallback-0000001054238913#ZH-CN_TOPIC_0000001054238913__onConfigured-ohos_media_camera_device_Camera-) is called. Otherwise, [CameraStateCallback#onConfigureFailed(Camera, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerastatecallback-0000001054238913#ZH-CN_TOPIC_0000001054238913__onConfigureFailed-ohos_media_camera_device_Camera-int-) is called. 
    * Starting looping-frame capture: After the configuration is complete, the camera is operable. Create a [FrameConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig-0000001054200186) instance by [FrameConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926), and then call [Camera#triggerLoopingCapture(FrameConfig)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__triggerLoopingCapture-ohos_media_camera_device_FrameConfig-) to start looping-frame capture. Looping-frame capture is commonly used for preview or recording. Call [Camera#triggerLoopingCapture(FrameConfig)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__triggerLoopingCapture-ohos_media_camera_device_FrameConfig-) to update configuration of looping-frame capture. 
    * Starting single-frame capture: Create a [FrameConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig-0000001054200186) instance by [FrameConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig_builder-0000001054518926), and then call [Camera#triggerSingleCapture(FrameConfig)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__triggerSingleCapture-ohos_media_camera_device_FrameConfig-) to start single-frame capture. Single-frame capture is commonly used for taking a picture. 
    * Stopping looping-frame capture: Call [Camera#stopLoopingCapture()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__stopLoopingCapture--). 
    * Releasing the camera: Call [Camera#release()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__release--).

#### [h2]configure

void configure​([CameraConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig-0000001054120241) config)

Configures the camera. 

Before using this method, call [Camera#getCameraConfigBuilder()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camera-0000001054838866#ZH-CN_TOPIC_0000001054838866__getCameraConfigBuilder--) to obtain a [CameraConfig.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameraconfig_builder-0000001054120170) instance. This method is mainly used to set a surface for preview, taking pictures, or recording. The preview surface must be configured, and the other two surfaces are optional. 

If the camera is successfully configured, [CameraStateCallback#onConfigured(Camera)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/camerastatecallback-0000001054238913#ZH-CN_TOPIC_0000001054238913__onConfigured-ohos_media_camera_device_Camera-) will be called. In this case, the camera becomes operable.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
config  |  Indicates camera configuration parameters.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) |  Throws this exception if camera configuration is null.  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  Throws this exception if a parameter value is invalid. For example, the camera configuration is null, or the surface is null.  
[IllegalStateException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalstateexception-0000001054678452) |  Throws this exception if the camera is released or if an error occurs.

#### [h2]triggerSingleCapture

int triggerSingleCapture​([FrameConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameconfig-0000001054200186) frameConfig)

Starts single-frame capture. 

This method is commonly used for taking a picture. 

Before taking a picture, the camera must start looping-frame capture. The configuration of this capture will be inserted into the looping capture queue. Surfaces in the looping-frame capture configuration should also be included in this single-frame capture to obtain continuous preview or video images.
