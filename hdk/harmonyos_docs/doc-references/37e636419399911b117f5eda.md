#### [h2]onContentScrolled

void onContentScrolled​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, int scrollX, int scrollY, int oldScrollX, int oldScrollY)

Processes a scrolling event dispatched to a component. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component to which the scrolling event is dispatched.  
scrollX  |  Indicates the X position after scrolling.  
scrollY  |  Indicates the Y position after scrolling.  
oldScrollX  |  Indicates the X position before scrolling  
oldScrollY  |  Indicates the Y position before scrolling.
