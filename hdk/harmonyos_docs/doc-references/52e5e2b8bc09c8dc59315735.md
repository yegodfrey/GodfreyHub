# Iterator
    
    public interface Iterator<E>  
  
---  
An iterator over a collection. Iterator takes the place of [Enumeration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/enumeration-0000001054678553) in the Java Collections Framework. Iterators differ from enumerations in two ways: 
    * Iterators allow the caller to remove elements from the underlying collection during the iteration with well-defined semantics. 
    * Method names have been improved. 

This interface is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).

#### [h2]remove

default void remove​()

Removes from the underlying collection the last element returned by this iterator (optional operation). This method can be called only once per call to [next()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913#ZH-CN_TOPIC_0000001054119913__next--). The behavior of an iterator is unspecified if the underlying collection is modified while the iteration is in progress in any way other than by calling this method. 

**Throws:**

Throw Name | Throw Description  
---|---  
[UnsupportedOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unsupportedoperationexception-0000001054238453) |  if the remove operation is not supported by this iterator  
[IllegalStateException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalstateexception-0000001054678452) |  if the next method has not yet been called, or the remove method has already been called after the last call to the next method
