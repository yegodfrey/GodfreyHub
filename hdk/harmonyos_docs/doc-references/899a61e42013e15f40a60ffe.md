# BrokenBarrierException  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---java.util.concurrent.BrokenBarrierException
    
    public class BrokenBarrierException
    extends [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708)  
  
---  
Exception thrown when a thread tries to wait upon a barrier that is in a broken state, or which enters the broken state while the thread is waiting.
