Inherits from [ISensorDataCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isensordatacallback-0000001054238985) and receives data of orientation sensors. 

This interface inherits all methods from its parent interface. When detecting any orientation sensor data changes, it provides data for the application layer to call.
