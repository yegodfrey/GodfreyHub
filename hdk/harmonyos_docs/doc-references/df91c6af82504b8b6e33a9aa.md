Polls this queue to see if a reference object is available. If one is available without further delay then it is removed from the queue and returned. Otherwise this method immediately returns null. 

**Returns:**

A reference object, if one was immediately available, otherwise null

#### [h2]remove

public [Reference](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reference-0000001054358445)<? extends [T](https://developer.harmonyos.com/cn/docs/documentation/doc-references/referencequeue-0000001054558467)> remove​(long timeout) throws [IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724), [InterruptedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/interruptedexception-0000001054678421)

Removes the next reference object in this queue, blocking until either one becomes available or the given timeout period expires. 

This method does not offer real-time guarantees: It schedules the timeout as if by invoking the [Object#wait(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446#ZH-CN_TOPIC_0000001054678446__wait-long-) method.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
timeout  |  If positive, block for up to timeout milliseconds while waiting for a reference to be added to this queue. If zero, block indefinitely.  
  
**Returns:**

A reference object, if one was available within the specified timeout period, otherwise null

**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  If the value of the timeout argument is negative  
[InterruptedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/interruptedexception-0000001054678421) |  If the timeout wait is interrupted
