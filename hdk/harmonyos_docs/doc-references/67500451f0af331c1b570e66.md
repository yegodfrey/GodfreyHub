# DatabaseHelper

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.data.DatabaseHelper
    
    public class DatabaseHelper
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a multi mode-data-access framework to operate application data in databases. A valid context should be passed in so that the database file can be created in the specified path. For more path details, see [Context#getDatabaseDir()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065#ZH-CN_TOPIC_0000001054440065__getDatabaseDir--) and [Context#getPreferencesDir()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065#ZH-CN_TOPIC_0000001054440065__getPreferencesDir--). 

This class provides methods for constructing and deleting ORM, RDB, and Preferences databases. It is the main entry class in the database scenario.
