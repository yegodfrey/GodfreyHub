#### [h2]CharArrayReader

public CharArrayReader​(char[] buf, int offset, int length)

Creates a CharArrayReader from the specified array of chars. 

The resulting reader will start reading at the given offset. The total number of char values that can be read from this reader will be either length or buf.length-offset, whichever is smaller.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
buf  |  Input buffer (not copied)  
offset  |  Offset of the first char to read  
length  |  Number of chars to read  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  If offset is negative or greater than buf.length, or if length is negative, or if the sum of these two values is negative.

#### [h2]close

public void close​()

Closes the stream and releases any system resources associated with it. Once the stream has been closed, further read(), ready(), mark(), reset(), or skip() invocations will throw an IOException. Closing a previously closed stream has no effect.
