# ForkJoinWorkerThread

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Thread](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447) |---|---java.util.concurrent.ForkJoinWorkerThread
    
    public class ForkJoinWorkerThread
    extends [Thread](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447)  
  
---  
A thread managed by a [ForkJoinPool](https://developer.harmonyos.com/cn/docs/documentation/doc-references/forkjoinpool-0000001054119870), which executes [ForkJoinTask](https://developer.harmonyos.com/cn/docs/documentation/doc-references/forkjointask-0000001054439899)s. This class is subclassable solely for the sake of adding functionality -- there are no overridable methods dealing with scheduling or execution. However, you can override initialization and termination methods surrounding the main task processing loop. If you do create such a subclass, you will also need to supply a custom [ForkJoinPool.ForkJoinWorkerThreadFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/forkjoinpool_forkjoinworkerthreadfactory-0000001054238607) to [ForkJoinPool#ForkJoinPool](https://developer.harmonyos.com/cn/docs/documentation/doc-references/forkjoinpool-0000001054119870#ZH-CN_TOPIC_0000001054119870__ForkJoinPool-int-java_util_concurrent_ForkJoinPool_ForkJoinWorkerThreadFactory-java_lang_Thread_UncaughtExceptionHandler-boolean-) in a ForkJoinPool.

**Since:**

1.7

#### [h2]getPoolIndex

public int getPoolIndex​()

Returns the unique index number of this thread in its pool. The returned value ranges from zero to the maximum number of threads (minus one) that may exist in the pool, and does not change during the lifetime of the thread. This method may be useful for applications that track status or collect results per-worker-thread rather than per-task. 

**Returns:**

the index number

#### [h2]onStart

protected void onStart​()

Initializes internal state after construction but before processing any tasks. If you override this method, you must invoke super.onStart() at the beginning of the method. Initialization requires care: Most fields must have legal default values, to ensure that attempted accesses from other threads work correctly even before this thread starts processing tasks.
