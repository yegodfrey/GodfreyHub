# RawFileDescriptor

#### 概述

提供rawfile文件描述符信息。

RawFileDescriptor是[OH_ResourceManager_GetRawFileDescriptor()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfile-0000001360445118#ZH-CN_TOPIC_0000001445347080__ga8313a7d4bb361a98ced485346a9be4b1)的输出参数，涵盖了rawfile文件的文件描述符以及在HAP包中的起始位置和长度。

**起始版本：**

8

**相关模块：**

[Rawfile](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfile-0000001360445118)
