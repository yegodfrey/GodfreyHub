# AbilitySlice.FormCallback
    
    public static interface AbilitySlice.FormCallback  
  
---  
Provides callbacks that will be invoked when a [Form](https://developer.harmonyos.com/cn/docs/documentation/doc-references/form-0000001071233243) instance is obtained or when the Form provider is uninstalled. 

This interface must be implemented to listen for the Form acquisition result and uninstallation event of the form provider if your application needs to call [AbilitySlice.acquireForm(ohos.aafwk.content.Intent,ohos.aafwk.ability.AbilitySlice.FormCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireForm-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilitySlice_FormCallback-) to obtain a Form instance. 

**Since:**

5

#### [h2]onAcquired

void onAcquired​(int result, [Form](https://developer.harmonyos.com/cn/docs/documentation/doc-references/form-0000001071233243) form)

Called to notify the application that the Form instance has been obtained after the application called the asynchronous method [AbilitySlice.acquireForm(ohos.aafwk.content.Intent,ohos.aafwk.ability.AbilitySlice.FormCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireForm-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilitySlice_FormCallback-). The application must present the form information on a specific page in this callback. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
result  |  Specifies whether the asynchronous form acquisition process is successful. [FormCallback#OHOS_FORM_ACQUIRE_SUCCESS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice_formcallback-0000001071073303#ZH-CN_TOPIC_0000001071073303__OHOS_FORM_ACQUIRE_SUCCESS) indicates that the form is successfully obtained, and other values indicate that the process fails.  
form  |  Indicates the obtained Form instance.  
  
**Since:**

5
