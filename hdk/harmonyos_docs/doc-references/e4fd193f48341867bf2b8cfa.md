Provides the mapping between colors and states of a [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) object. [StateColor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/statecolor-0000001172716626) is created using the XML file in the color directory. The XML file contains a state-container field. Each item under this field defines a color and its associated states. The items are matched in sequence in the XML file. Therefore, you are advised to place items with more constraints at the front and place items with no state attributes or items whose state attribute is ComponentState.COMPONENT_STATE_EMPTY at the end as default items. If the state attribute in an item has not been configured, the value is false by default. The ohos:color attribute is mandatory for each item, and its value can be a hex value or a referenced value. The ohos:alpha attribute is optional, and its value can be a floating-point value in the range from 0 to 1 or a referenced value. **Since:** 7Constructor Summary Constructor | Description
