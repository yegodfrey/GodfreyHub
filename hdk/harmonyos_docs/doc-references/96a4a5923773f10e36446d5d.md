    public interface Appendable  
  
---  
An object to which char sequences and values can be appended. The Appendable interface must be implemented by any class whose instances are intended to receive formatted output from a [Formatter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formatter-0000001054439879).  The characters to be appended should be valid Unicode characters as described in [Unicode Character Representation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/character-0000001054199716#ZH-CN_TOPIC_0000001054199716__unicode). Note that supplementary characters may be composed of multiple 16-bit char values.  Appendables are not necessarily safe for multithreaded access. Thread safety is the responsibility of classes that extend and implement this interface.  Since this interface may be implemented by existing classes with different styles of error handling there is no guarantee that errors will be propagated to the invoker. **Since:** 1.5Method Summary Modifier and Type | Method | Description
