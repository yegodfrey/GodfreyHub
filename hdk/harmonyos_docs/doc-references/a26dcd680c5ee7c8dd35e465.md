# Overview  
  
Provides APIs of image-related functions, including encoding and decoding, image processing, and image receiving.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[ImageReceiver.IImageArrivalListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagereceiver_iimagearrivallistener-0000001054358918) | Callback interface used when new image data is received.  
[ImageSource.DecodeEventListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagesource_decodeeventlistener-0000001060996894) | Listens for the events occurred during image decoding.
