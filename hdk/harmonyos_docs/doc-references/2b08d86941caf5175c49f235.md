A wrapper class of changed indexes. This class wraps indexes that are inserted, updated, and deleted in the index library. If the client has registered a listener for index changes, callbacks will be invoked to send notifications to the client when an index change occurs. You can call [ChangedIndexContent#getInsertedItems()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/changedindexcontent-0000001054358816#ZH-CN_TOPIC_0000001054358816__getInsertedItems--), [ChangedIndexContent#getUpdatedItems()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/changedindexcontent-0000001054358816#ZH-CN_TOPIC_0000001054358816__getUpdatedItems--), and [ChangedIndexContent#getDeletedItems()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/changedindexcontent-0000001054358816#ZH-CN_TOPIC_0000001054358816__getDeletedItems--) to obtain the inserted, updated, and deleted indexes.
