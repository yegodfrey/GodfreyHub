# Overview  
  
Provides managers of 3D scene resources, including mesh descriptors, material descriptors, and animation playback resources.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[AnimationPlayback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/animationplayback-0000001054838700) | Controls animation playback.  
[GpuResourceHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gpuresourcehandle-0000001054358734) | Provides methods of determining whether a GPU resource handle is valid and obtaining the engine to which the handle belongs.  
[RenderDataStorePod](https://developer.harmonyos.com/cn/docs/documentation/doc-references/renderdatastorepod-0000001054120075) | Represents the plain old data (POD) object that stores rendering data.  
[ResourceHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcehandle-0000001054120004) | Provides methods of managing resource handles.  
[ResourceManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054440033) | Manages resources such as meshes, textures, and materials.  
[ResourceManager.ResourceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager_resourceinfo-0000001054200020) | Provides methods of obtaining the URI, name, and resource handle of a resource.  
  
#### Class Summary

Class | Description  
---|---  
[MaterialDesc](https://developer.harmonyos.com/cn/docs/documentation/doc-references/materialdesc-0000001054678748) | Describes properties of a material.  
[MeshDesc](https://developer.harmonyos.com/cn/docs/documentation/doc-references/meshdesc-0000001054358727) | Describes properties of a mesh.  
[MeshDesc.PrimitiveDesc](https://developer.harmonyos.com/cn/docs/documentation/doc-references/meshdesc_primitivedesc-0000001054558749) | Describes properties of a primitive used in a mesh.  
  
#### Enum Summary

Enum | Description  
---|---  
[AnimationPlayback.State](https://developer.harmonyos.com/cn/docs/documentation/doc-references/animationplayback_state-0000001054678717) | Enumerates animation playback states.  
[ImageFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imageformat-0000001054838702) | Enumerates image data formats used by the 3D engine.  
[MaterialDesc.MaterialAlphaMode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/materialdesc_materialalphamode-0000001054358736) | Describes available alpha rendering modes of materials.  
[MaterialDesc.MaterialType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/materialdesc_materialtype-0000001054120077) | Enumerates material types.
