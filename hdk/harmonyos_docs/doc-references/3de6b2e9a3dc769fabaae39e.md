This class implements an encoder for encoding byte data using the Base64 encoding scheme as specified in RFC 4648 and RFC 2045.  Instances of [Encoder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/base64_encoder-0000001054119919) class are safe for use by multiple concurrent threads.  Unless otherwise noted, passing a null argument to a method of this class will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown. **Since:** 1.8**See Also:** [Base64.Decoder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/base64_decoder-0000001054358578)Method Summary Modifier and Type | Method | Description
