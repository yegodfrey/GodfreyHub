# OnPermissionChangedCallback

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.rpc.RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) |---|---ohos.bundle.OnPermissionChangedCallback

Provides callback methods that can be called upon permission changes. You need to implement this class and call [onChanged(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/onpermissionchangedcallback-0000001054358784#ZH-CN_TOPIC_0000001054358784__onChanged-int-) when the application permission changes.
