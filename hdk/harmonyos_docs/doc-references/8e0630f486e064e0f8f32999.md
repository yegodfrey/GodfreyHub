# IllegalAccessException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.ReflectiveOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reflectiveoperationexception-0000001054199726) |---|---|---|---java.lang.IllegalAccessException
    
    public class IllegalAccessException
    extends [ReflectiveOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reflectiveoperationexception-0000001054199726)  
  
---  
An IllegalAccessException is thrown when an application tries to reflectively create an instance (other than an array), set or get a field, or invoke a method, but the currently executing method does not have access to the definition of the specified class, field, method or constructor.

**Since:**

JDK1.0
