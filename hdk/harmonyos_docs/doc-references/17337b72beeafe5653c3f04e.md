# AbstractQueue

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.AbstractCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractcollection-0000001054358576)<E> |---|---java.util.AbstractQueue<E>
    
    public abstract class AbstractQueue<E>
    extends [AbstractCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractcollection-0000001054358576)<E>
    implements [Queue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915)<E>  
  
---  
This class provides skeletal implementations of some [Queue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915) operations. The implementations in this class are appropriate when the base implementation does not allow null elements. Methods [add](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602#ZH-CN_TOPIC_0000001054518602__add-E-), [remove](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602#ZH-CN_TOPIC_0000001054518602__remove--), and [element](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602#ZH-CN_TOPIC_0000001054518602__element--) are based on [offer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915#ZH-CN_TOPIC_0000001054119915__offer-E-), [poll](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915#ZH-CN_TOPIC_0000001054119915__poll--), and [peek](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915#ZH-CN_TOPIC_0000001054119915__peek--), respectively, but throw exceptions instead of indicating failure via false or null returns. 

A Queue implementation that extends this class must minimally define a method [Queue#offer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915#ZH-CN_TOPIC_0000001054119915__offer-E-) which does not permit insertion of null elements, along with methods [Queue#peek](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915#ZH-CN_TOPIC_0000001054119915__peek--), [Queue#poll](https://developer.harmonyos.com/cn/docs/documentation/doc-references/queue-0000001054119915#ZH-CN_TOPIC_0000001054119915__poll--), [Collection#size](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563#ZH-CN_TOPIC_0000001054358563__size--), and [Collection#iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563#ZH-CN_TOPIC_0000001054358563__iterator--). Typically, additional methods will be overridden as well. If these requirements cannot be met, consider instead subclassing [AbstractCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractcollection-0000001054358576). 

This class is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).

#### [h2]addAll

public boolean addAll​([Collection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563)<? extends [E](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602)> c)

Adds all of the elements in the specified collection to this queue. Attempts to addAll of a queue to itself result in IllegalArgumentException. Further, the behavior of this operation is undefined if the specified collection is modified while the operation is in progress. 

This implementation iterates over the specified collection, and adds each element returned by the iterator to this queue, in turn. A runtime exception encountered while trying to add an element (including, in particular, a null element) may result in only some of the elements having been successfully added when the associated exception is thrown.
