# Overview  
  
Provides a class for obtaining basic [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) information that can be used to uniquely identify an ability. 

You can obtain basic information about [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) instances from [ElementNameEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementnameex-0000001060519084) objects.

**Since:**

3
