#### [h2]setOrientation

public void setOrientation​(int orientation)

Sets the layout orientation. 

If you do not set the layout orientation, [Component.VERTICAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__VERTICAL) is used by default.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
orientation  |  Indicates the layout orientation to set. [Component.HORIZONTAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__HORIZONTAL) indicates that components are horizontally arranged, [Component.VERTICAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__VERTICAL) indicates that components are vertically arranged.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  Throws the exception if the param values does not correspond to [Component.HORIZONTAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__HORIZONTAL) or [Component.VERTICAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__VERTICAL).  
  
**Since:**

5

public int getOrientation​()
