# Manifest

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.jar.Manifest
    
    public class Manifest
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421)  
  
---  
The Manifest class is used to maintain Manifest entry names and their associated Attributes. There are main Manifest Attributes as well as per-entry Attributes. For information on the Manifest format, please see the [ Manifest format specification](https://docs.oracle.com/javase/8/docs/technotes/guides/jar/jar.html).

#### [h2]getEntries

public [Map](https://developer.harmonyos.com/cn/docs/documentation/doc-references/map-0000001054199858)<[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460),[Attributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributes-0000001054358620)> getEntries​()

Returns a Map of the entries contained in this Manifest. Each entry is represented by a String name (key) and associated Attributes (value). The Map permits the null key, but no entry with a null key is created by [read(java.io.InputStream)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manifest-0000001054678634#ZH-CN_TOPIC_0000001054678634__read-java_io_InputStream-), nor is such an entry written by using [write(java.io.OutputStream)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manifest-0000001054678634#ZH-CN_TOPIC_0000001054678634__write-java_io_OutputStream-).

#### [h2]getAttributes

public [Attributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributes-0000001054358620) getAttributes​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) name)

Returns the Attributes for the specified entry name. This method is defined as: 
    
    return (Attributes)getEntries().get(name)
     

Though null is a valid name, when getAttributes(null) is invoked on a Manifest obtained from a jar file, null will be returned. While jar files themselves do not allow null-named attributes, it is possible to invoke [getEntries()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manifest-0000001054678634#ZH-CN_TOPIC_0000001054678634__getEntries--) on a Manifest, and on that result, invoke put with a null key and an arbitrary value. Subsequent invocations of getAttributes(null) will return the just-put value. 

Note that this method does not return the manifest's main attributes; see [getMainAttributes()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manifest-0000001054678634#ZH-CN_TOPIC_0000001054678634__getMainAttributes--).
