# StorageInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.storageinfomgr.StorageInfo
    
    public final class StorageInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Provides the storage information of an application. 

The storage information includes the application size, application data size, and application cached data size. The information is usually returned at the request of [StorageInfoManager#queryInfoByPackageName(UUID, String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageinfomanager-0000001054558989#ZH-CN_TOPIC_0000001054558989__queryInfoByPackageName-java_util_UUID-java_lang_String-int-) and [StorageInfoManager#queryInfoByUid(UUID, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageinfomanager-0000001054558989#ZH-CN_TOPIC_0000001054558989__queryInfoByUid-java_util_UUID-int-). This class also provides the [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001) interface, with which you can marshal data into or unmarshal data from a parcel. Specifically, if storage information is transmitted across processes, the sender can marshal data to the [Parcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018) and transmit the data, and the receiver can unmarshal the data from the [Parcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018) to obtain the storage information.

#### [h2]PRODUCER

Default constructor used to create a [StorageInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageinfo-0000001054358967) object. 

When you use this constructor to create a [StorageInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageinfo-0000001054358967) object, also call its member method [Sequenceable.Producer.createFromParcel(Parcel)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable_producer-0000001054678971#ZH-CN_TOPIC_0000001054678971__createFromParcel-ohos_utils_Parcel-). If the input parameter is empty, the operation will fail and null will be returned. 

If application storage status information has been stored in the parcel object in [Parcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018) but you want to use the StorageInfo object instead, run the following statement: StorageInfo info = StorageInfo.PRODUCER.createFromParcel(parcel).
