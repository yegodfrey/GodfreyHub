# PosixFileAttributes
    
    public interface PosixFileAttributes
    extends [BasicFileAttributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributes-0000001054678481)  
  
---  
File attributes associated with files on file systems used by operating systems that implement the Portable Operating System Interface (POSIX) family of standards. 

The POSIX attributes of a file are retrieved using a [PosixFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfileattributeview-0000001054558515) by invoking its [PosixFileAttributeView#readAttributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfileattributeview-0000001054558515#ZH-CN_TOPIC_0000001054558515__readAttributes--) method.

**Since:**

1.7

#### [h2]permissions

[Set](https://developer.harmonyos.com/cn/docs/documentation/doc-references/set-0000001054439873)<[PosixFilePermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfilepermission-0000001054238515)> permissions​()

Returns the permissions of the file. The file permissions are returned as a set of [PosixFilePermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfilepermission-0000001054238515) elements. The returned set is a copy of the file permissions and is modifiable. This allows the result to be modified and passed to the [PosixFileAttributeView#setPermissions](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfileattributeview-0000001054558515#ZH-CN_TOPIC_0000001054558515__setPermissions-java_util_Set-) method to update the file's permissions. 

**Returns:**

the file permissions
