#### [h2]DESKeySpec

public DESKeySpec​(byte[] key) throws [InvalidKeyException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/invalidkeyexception-0000001054119859)

Creates a DESKeySpec object using the first 8 bytes in key as the key material for the DES key. 

The bytes that constitute the DES key are those between key[0] and key[7] inclusive.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
key  |  the buffer with the DES key material. The first 8 bytes of the buffer are copied to protect against subsequent modification.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) |  if the given key material is null  
[InvalidKeyException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/invalidkeyexception-0000001054119859) |  if the given key material is shorter than 8 bytes.

public DESKeySpec​(byte[] key, int offset) throws [InvalidKeyException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/invalidkeyexception-0000001054119859)
