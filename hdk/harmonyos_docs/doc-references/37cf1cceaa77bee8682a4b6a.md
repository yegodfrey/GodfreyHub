A thin wrapper around the java.util.Date class that allows the JDBC API to identify this as an SQL TIME value. The Time class adds formatting and parsing operations to support the JDBC escape syntax for time values.  The date components should be set to the "zero epoch" value of January 1, 1970 and should not be accessed. Constructor Summary Constructor | Description
