# PrimitiveIterator
    
    public interface PrimitiveIterator<T,T_CONS>
    extends [Iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913)<T>  
  
---  
A base type for primitive specializations of Iterator. Specialized subtypes are provided for [OfInt](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator_ofint-0000001054838540), [OfLong](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator_oflong-0000001054358574), and [OfDouble](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator_ofdouble-0000001054678555) values. 

The specialized subtype default implementations of [Iterator#next](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913#ZH-CN_TOPIC_0000001054119913__next--) and [Iterator#forEachRemaining(java.util.function.Consumer)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913#ZH-CN_TOPIC_0000001054119913__forEachRemaining-java_util_function_Consumer-) box primitive values to instances of their corresponding wrapper class. Such boxing may offset any advantages gained when using the primitive specializations. To avoid boxing, the corresponding primitive-based methods should be used. For example, [PrimitiveIterator.OfInt#nextInt()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator_ofint-0000001054838540#ZH-CN_TOPIC_0000001054838540__nextInt--) and [PrimitiveIterator.OfInt#forEachRemaining(java.util.function.IntConsumer)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator_ofint-0000001054838540#ZH-CN_TOPIC_0000001054838540__forEachRemaining-java_util_function_IntConsumer-) should be used in preference to [PrimitiveIterator.OfInt#next()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator_ofint-0000001054838540#ZH-CN_TOPIC_0000001054838540__next--) and [PrimitiveIterator.OfInt#forEachRemaining(java.util.function.Consumer)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator_ofint-0000001054838540#ZH-CN_TOPIC_0000001054838540__forEachRemaining-java_util_function_Consumer-). 

Iteration of primitive values using boxing-based methods [Iterator#next](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913#ZH-CN_TOPIC_0000001054119913__next--) and [Iterator#forEachRemaining(java.util.function.Consumer)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913#ZH-CN_TOPIC_0000001054119913__forEachRemaining-java_util_function_Consumer-), does not affect the order in which the values, transformed to boxed values, are encountered.

#### [h2]forEachRemaining

void forEachRemaining​([T_CONS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/primitiveiterator-0000001054238585) action)

Performs the given action for each remaining element, in the order elements occur when iterating, until all elements have been processed or the action throws an exception. Errors or runtime exceptions thrown by the action are relayed to the caller. 

**Parameters:**
