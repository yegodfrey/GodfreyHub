# ConnectException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.io.IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |---|---|---|---[java.net.SocketException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketexception-0000001054678484) |---|---|---|---|---java.net.ConnectException
    
    public class ConnectException
    extends [SocketException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketexception-0000001054678484)  
  
---  
Signals that an error occurred while attempting to connect a socket to a remote address and port. Typically, the connection was refused remotely (e.g., no process is listening on the remote address/port).

**Since:**

JDK1.1
