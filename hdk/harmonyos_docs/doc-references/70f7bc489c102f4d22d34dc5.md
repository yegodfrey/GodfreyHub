#### [h2]createKeyEvent

public static [Optional](https://developer.harmonyos.com/cn/docs/documentation/doc-references/optional-0000001054558597)<[KeyEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285)> createKeyEvent​(int action, int keyCode)

Creates a KeyEvent object based on the specified action and keycode. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
action  |  Indicates the action taken for the key. The value can be [KeyEvent.KEY_PRESSED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285#ZH-CN_TOPIC_0000001054120285__KEY_PRESSED) or [KeyEvent.KEY_RELEASED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285#ZH-CN_TOPIC_0000001054120285__KEY_RELEASED).  
keyCode  |  Indicates the keycode for the key. For details about the keycodes, see [KeyEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285).  
  
**Returns:**

Returns a KeyEvent object; returns an empty object if action is not a valid value, or the keyCode value is less than or equal to 0 or greater than the maximum keycode ([KeyEvent.NOW_MAX_KEY](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285#ZH-CN_TOPIC_0000001054120285__NOW_MAX_KEY)) defined in the system.
