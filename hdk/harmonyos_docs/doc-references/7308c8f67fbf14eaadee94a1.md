# ObjDoubleConsumer
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface ObjDoubleConsumer<T>  
  
---  
Represents an operation that accepts an object-valued and a double-valued argument, and returns no result. This is the (reference, double) specialization of [BiConsumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/biconsumer-0000001054838578). Unlike most other functional interfaces, ObjDoubleConsumer is expected to operate via side-effects. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [accept(java.lang.Object,double)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objdoubleconsumer-0000001054678630#ZH-CN_TOPIC_0000001054678630__accept-T-double-).
