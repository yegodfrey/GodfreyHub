# Month

A month-of-year, such as 'July'. 

Month is an enum representing the 12 months of the year - January, February, March, April, May, June, July, August, September, October, November and December. 

In addition to the textual enum name, each month-of-year has an int value. The int value follows normal usage and the ISO-8601 standard, from 1 (January) to 12 (December). It is recommended that applications use the enum rather than the int value to ensure code clarity. 

**Do not use ordinal() to obtain the numeric representation of Month. Use getValue() instead.**

This enum represents a common concept that is found in many calendar systems. As such, this enum may be used by any calendar system that has the month-of-year concept defined exactly equivalent to the ISO-8601 calendar system.

#### [h2]adjustInto

public [Temporal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532) adjustInto​([Temporal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532) temporal)

Adjusts the specified temporal object to have this month-of-year. 

This returns a temporal object of the same observable type as the input with the month-of-year changed to be the same as this. 

The adjustment is equivalent to using [Temporal#with(TemporalField, long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532#ZH-CN_TOPIC_0000001054838532__with-java_time_temporal_TemporalField-long-) passing [ChronoField#MONTH_OF_YEAR](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronofield-0000001054119838#ZH-CN_TOPIC_0000001054119838__MONTH_OF_YEAR) as the field. If the specified temporal object does not use the ISO calendar system then a DateTimeException is thrown. 

In most cases, it is clearer to reverse the calling pattern by using [Temporal#with(TemporalAdjuster)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532#ZH-CN_TOPIC_0000001054838532__with-java_time_temporal_TemporalAdjuster-): 
    
    // these two lines are equivalent, but the second approach is recommended
       temporal = thisMonth.adjustInto(temporal);
       temporal = temporal.with(thisMonth);
     

For example, given a date in May, the following are output: 
    
    dateInMay.with(JANUARY);    // four months earlier
       dateInMay.with(APRIL);      // one months earlier
       dateInMay.with(MAY);        // same date
       dateInMay.with(JUNE);       // one month later
       dateInMay.with(DECEMBER);   // seven months later
     

This instance is immutable and unaffected by this method call.
