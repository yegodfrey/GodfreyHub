#### [h2]getSecKeyAuthDuration

public int getSecKeyAuthDuration​()

Obtains the validity period of user authentication for a key. 

If a key requires user authentication (see [KeyStoreConstants#FLAG_KEY_ACCESSIBLE_NEEDED_USER_AUTH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystoreconstants-0000001054238973#ZH-CN_TOPIC_0000001054238973__FLAG_KEY_ACCESSIBLE_NEEDED_USER_AUTH)), this method can be used to obtain the validity period of user authentication.
