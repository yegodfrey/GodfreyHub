# KeyEvent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.multimodalinput.event.MultimodalEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodalevent-0000001054518970) |---|---ohos.multimodalinput.event.KeyEvent

---  
Defines all key events. 

This class extends the [MultimodalEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodalevent-0000001054518970) class. It defines the keycodes and methods for various key events. 

The keycodes are as follows: 

    * -1: unknown keycode, which is the default value 
    * 1 to 1000: keycodes for common keys 
    * 1001 to 1999: keycodes for internal key devices 
    * 2000 to 3000: keycodes for external key devices (mainly external keyboards) 
    * 10001 to the value specified by [NOW_MAX_KEY](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285#ZH-CN_TOPIC_0000001054120285__NOW_MAX_KEY): keycodes for vehicle keys
