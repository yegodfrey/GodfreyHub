# Overview  
  
Interfaces and classes providing access to file and file system attributes. 

An attribute view provides a read-only or updatable view of the non-opaque values, or metadata, associated with objects in a file system. The [FileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileattributeview-0000001054439799) interface is extended by several other interfaces that that views to specific sets of file attributes. FileAttributeViews are selected by invoking the [Files.getFileAttributeView(java.nio.file.Path, java.lang.Class<V>, java.nio.file.LinkOption...)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__getFileAttributeView-java_nio_file_Path-java_lang_Class-java_nio_file_LinkOption___-) method with a type-token to identify the required view. Views can also be identified by name. The [FileStoreAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filestoreattributeview-0000001054518526) interface provides access to file store attributes. A FileStoreAttributeView of a given type is obtained by invoking the [FileStore.getFileStoreAttributeView(java.lang.Class<V>)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filestore-0000001054358485#ZH-CN_TOPIC_0000001054358485__getFileStoreAttributeView-java_lang_Class-) method. 

The [BasicFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributeview-0000001054838466) class defines methods to read and update a basic set of file attributes that are common to many file systems. 

The [PosixFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfileattributeview-0000001054558515) interface extends BasicFileAttributeView by defining methods to access the file attributes commonly used by file systems and operating systems that implement the Portable Operating System Interface (POSIX) family of standards. 

The [DosFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dosfileattributeview-0000001054119841) class extends BasicFileAttributeView by defining methods to access the legacy "DOS" file attributes supported on file systems such as File Allocation Tabl (FAT), commonly used in consumer devices. 

The [AclFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclfileattributeview-0000001054558513) class defines methods to read and write the Access Control List (ACL) file attribute. The ACL model used by this file attribute view is based on the model defined by [_RFC 3530: Network File System (NFS) version 4 Protocol_](http://www.ietf.org/rfc/rfc3530.txt). 

In addition to attribute views, this package also defines classes and interfaces that are used when accessing attributes: 

    * The [UserPrincipal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/userprincipal-0000001054678483) and [GroupPrincipal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/groupprincipal-0000001054678514) interfaces represent an identity or group identity. 
    * The [UserPrincipalLookupService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/userprincipallookupservice-0000001054199788) interface defines methods to lookup user or group principals. 
    * The [FileAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileattribute-0000001054119770) interface represents the value of an attribute for cases where the attribute value is required to be set atomically when creating an object in the file system. 

Unless otherwise noted, passing a null argument to a constructor or method in any class or interface in this package will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown.

**Since:**

1.7

[FileStoreAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filestoreattributeview-0000001054518526) | An attribute view that is a read-only or updatable view of the attributes of a [FileStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filestore-0000001054358485).

[PosixFileAttributes](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfileattributes-0000001054358493) | File attributes associated with files on file systems used by operating systems that implement the Portable Operating System Interface (POSIX) family of standards.  
[PosixFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/posixfileattributeview-0000001054558515) | A file attribute view that provides a view of the file attributes commonly associated with files on file systems used by operating systems that implement the Portable Operating System Interface (POSIX) family of standards.  
[UserDefinedFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/userdefinedfileattributeview-0000001054238513) | A file attribute view that provides a view of a file's user-defined attributes, sometimes known as extended attributes.  
[UserPrincipal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/userprincipal-0000001054678483) | A Principal representing an identity used to determine access rights to objects in a file system.
