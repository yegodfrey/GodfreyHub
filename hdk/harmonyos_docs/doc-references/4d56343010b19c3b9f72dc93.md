# LongPlainArray

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.LongPlainArray<E>
    
    public class LongPlainArray<E>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421)  
  
---  
A basic collection class to store the data structures that use the primitive data type long as the key and any object as the value. 

Values in this class are directly stored in arrays, without being wrapped into other types. This simplifies the data storage structure and saves memory. All key-value pairs in this class are sorted in ascending order when they are stored, and the binary search algorithm is used to efficiently search for a specified key. In such data storage structures, keys and values can be iterated over based on indexes. This class implements the [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421) interface and supports shallow copy of stored values. 

Pay attention to the following when using the LongPlainArray class: 

    * This class is non-thread safe.
    * The stored value cannot be a null object.
    * Values are not stored in the same sequence as they are inserted.
