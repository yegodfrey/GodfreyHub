# FilterReader

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.Reader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435) |---|---java.io.FilterReader
    
    public abstract class FilterReader
    extends [Reader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435)  
  
---  
Abstract class for reading filtered character streams. The abstract class FilterReader itself provides default methods that pass all requests to the contained stream. Subclasses of FilterReader should override some of these methods and may also provide additional methods and fields.

**Since:**

JDK1.1
