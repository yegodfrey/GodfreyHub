# Overview  
  
Provides interfaces and classes for interacting with the hop task management service for ability hopping. 

You can register the ability to be hopped with the hop task management service, manage devices that support hopping through the hop task management service, provide a list of candidate devices for the user, and start hopping based on the selected device information.

**Since:**

5

#### Interface Summary

Interface | Description  
---|---  
[IContinuationDeviceCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icontinuationdevicecallback-0000001091482852) | Provides callbacks for listening for device connection state changes.  
[IContinuationRegisterManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icontinuationregistermanager-0000001138987467) | Provides methods for interacting with the hop task management service, including methods for registering and unregistering the ability to hop, updating the device connection state, and showing the list of devices that can be selected for hopping.  
[RequestCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestcallback-0000001138830321) | Provides a callback for listening for connection state changes of the hop task management service.
