Provides basic URL query analysis capabilities, including filtering invalid characters and obtaining query parameter pairs. A simple example is as follows: 
    
    UrlQueryFilter urlFilter = new UrlQueryFilter();
     String url = "http://www.xxx:port/xxxx/xxxx?name=tom&name=lily&age=20";
     urlFilter.parseUrl(url);
