# EventRunner

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.eventhandler.EventRunner
    
    public final class EventRunner
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Creates and manages the event queue in the current thread. 

After you call the [run()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventrunner-0000001054678846#ZH-CN_TOPIC_0000001054678846__run--) method, the EventRunner will continuously retrieve events from the event queue and dispatch the events to the matching [EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858). Then the [EventHandler#processEvent(InnerEvent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858#ZH-CN_TOPIC_0000001054518858__processEvent-ohos_eventhandler_InnerEvent-) method will be called to process the events.
