# Overview  
  
Provides a mechanism for pending execution. 

[IntentAgentEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagentex-0000001060519189) provides a pending intent mechanism to perform an action only when certain conditions are met or certain events are triggered. For example, after you receive a notification, a new ability will be triggered only if you click this notification. The actions to be performed include abilities and common events. 

When you send an [IntentAgentEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagentex-0000001060519189) to another application, the application is granted all the permissions you have. 

You can obtain a different [IntentAgentEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagentex-0000001060519189) only if a different request code is carried in the [IntentAgentInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagentinfo-0000001054120167) object or the intents in the previous and new [IntentAgentInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagentinfo-0000001054120167) objects are found different by using [Intent.equals(Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019#ZH-CN_TOPIC_0000001054120019__equals-java_lang_Object-).
