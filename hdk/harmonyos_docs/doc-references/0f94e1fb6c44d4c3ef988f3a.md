# ProgressBar.BarObserver
    
    public static interface ProgressBar.BarObserver  
  
---  
Provides a text observer to listen for changes of progress bars in a component. 

The [onBarChanged(int, int, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/progressbar_barobserver-0000001060039125#ZH-CN_TOPIC_0000001060039125__onBarChanged-int-int-int-) method is called each time the progress bar changes.

#### Method Detail

#### [h2]onBarChanged

void onBarChanged​(int before, int after, int count)

Called when the progress bar changes. 

For example, if the verification progress moves from 0 to 20, then the value of before is 0, the value of after is 20, and the value of count is 20.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
before  |  Indicates the previous position in the progress bar.  
after  |  Indicates the current position in the progress bar.  
count  |  Indicates the difference between the previous position and the current position.
