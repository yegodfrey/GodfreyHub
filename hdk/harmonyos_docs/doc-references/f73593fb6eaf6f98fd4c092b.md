# FileReader  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.Reader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435) |---|---[java.io.InputStreamReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstreamreader-0000001054119761) |---|---|---java.io.FileReader
    
    public class FileReader
    extends [InputStreamReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstreamreader-0000001054119761)  
  
---  
Convenience class for reading character files. The constructors of this class assume that the default character encoding and the default byte-buffer size are appropriate. To specify these values yourself, construct an InputStreamReader on a FileInputStream. 

FileReader is meant for reading streams of characters. For reading streams of raw bytes, consider using a FileInputStream.

**Since:**

JDK1.1
