Base class used to access the media browser service.  The media browser service enables your application to browse and play media items from another application.  To extend this class, you need to configure the **config.json** for your project with **"actions"** in the **"skills"** attribute set to [SERVICE_ACTION](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserservice-0000001054558949#ZH-CN_TOPIC_0000001054558949__SERVICE_ACTION).  Example code: 
    
    {
       "name": ".MyAVBrowserService",
       "skills": [
         {
           "actions": [
             "action.media.browse.AVBrowserService"
           ]
         }
       ],
       "type": "service",
     }
