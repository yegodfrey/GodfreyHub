# BaseStream
    
    public interface BaseStream<T,S extends BaseStream<T,S>>
    extends [AutoCloseable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/autocloseable-0000001054518454)  
  
---  
Base interface for streams, which are sequences of elements supporting sequential and parallel aggregate operations. The following example illustrates an aggregate operation using the stream types [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and [IntStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intstream-0000001054119971), computing the sum of the weights of the red widgets: 
    
    int sum = widgets.stream()
                          .filter(w -> w.getColor() == RED)
                          .mapToInt(w -> w.getWeight())
                          .sum();
     

See the class documentation for [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and the package documentation for [java.util.stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621) for additional specification of streams, stream operations, stream pipelines, and parallelism, which governs the behavior of all stream types.

#### [h2]onClose

[S](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basestream-0000001054238641) onClose​([Runnable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runnable-0000001054838396) closeHandler)

Returns an equivalent stream with an additional close handler. Close handlers are run when the [close()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basestream-0000001054238641#ZH-CN_TOPIC_0000001054238641__close--) method is called on the stream, and are executed in the order they were added. All close handlers are run, even if earlier close handlers throw exceptions. If any close handler throws an exception, the first exception thrown will be relayed to the caller of close(), with any remaining exceptions added to that exception as suppressed exceptions (unless one of the remaining exceptions is the same exception as the first exception, since an exception cannot suppress itself.) May return itself. 

This is an [intermediate operation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621#ZH-CN_TOPIC_0000001054358621__StreamOps).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
closeHandler  |  A task to execute when the stream is closed  
  
**Returns:**

a stream with a handler that is run if the stream is closed
