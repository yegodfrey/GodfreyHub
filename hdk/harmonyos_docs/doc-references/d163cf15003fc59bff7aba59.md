# Overview  
  
Defines common media objects, attributes, and fields, such as audio and video attributes.

**Since:**

1

#### Class Summary

Class | Description  
---|---  
[AudioProperty](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audioproperty-0000001054440209) | Describes audio properties, which are used for audio recording.  
[AudioProperty.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audioproperty_builder-0000001054200196) | Static inner class of AudioProperty to create an AudioProperty object.  
[AudioStreamProperty](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiostreamproperty-0000001218076509) | Describes audio stream properties.  
[AudioStreamProperty.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiostreamproperty_builder-0000001172238210) | Provides a builder for constructing an AudioStreamProperty instance.  
[AVDescription](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avdescription-0000001054518936) | Represents descriptive information about media items.  
[AVDescription.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avdescription_builder-0000001054678924) | Static inner class used to create [AVDescription](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avdescription-0000001054518936) objects.  
[AVMetadata](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avmetadata-0000001054358903) | Represents media metadata, which is used for media data display.  
[AVMetadata.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avmetadata_builder-0000001054558925) | Builder class used to create [AVMetadata](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avmetadata-0000001054358903) objects.  
[BufferInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bufferinfo-0000001054238923) | Describes buffer metadata, including the start offset, size, timestamp, and type of buffer data.  
[Format](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054678893) | Saves and sets media metadata, such as the media playback duration.  
[Format.FormatArrays](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format_formatarrays-0000001054838878) | Saves key-value pairs in the format list created based on the formatMap object.  
[Format.Key](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format_key-0000001172556736)<T> | Defines types of codec property keys.  
[Source](https://developer.harmonyos.com/cn/docs/documentation/doc-references/source-0000001054358912) | Describes the media data source, which can be a URI or file descriptor.  
[Source.AudioSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/source_audiosource-0000001054120253) | Describes the audio source.  
[Source.VideoSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/source_videosource-0000001054120182) | Describes the video source, including the camera and surface.  
[StorageProperty](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty-0000001054440211) | Obtains storage properties of audio and video files.  
[StorageProperty.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty_builder-0000001054200198) | Static inner class of [StorageProperty](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty-0000001054440211) used to create a StorageProperty object.  
[VideoProperty](https://developer.harmonyos.com/cn/docs/documentation/doc-references/videoproperty-0000001054518938) | Describes video properties.  
[VideoProperty.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/videoproperty_builder-0000001054678926) | Static inner class of [VideoProperty](https://developer.harmonyos.com/cn/docs/documentation/doc-references/videoproperty-0000001054518938) used to create a VideoProperty object.
