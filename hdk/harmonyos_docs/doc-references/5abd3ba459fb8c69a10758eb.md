The default value will be [STANDARD_ELEMENT_COMPARISON](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchiterator_elementcomparisontype-0000001054120130#ZH-CN_TOPIC_0000001054120130__STANDARD_ELEMENT_COMPARISON). [h2]PATTERN_BASE_WEIGHT_IS_WILDCARD public static final [SearchIterator.ElementComparisonType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchiterator_elementcomparisontype-0000001054120130) PATTERN_BASE_WEIGHT_IS_WILDCARD Collation element comparison is modified to effectively provide behavior between the specified strength and strength - 1.  Collation elements in the pattern that have the base weight for the specified strength are treated as "wildcards" that match an element with any other weight at that collation level in the searched text. For example, with a secondary-strength English collator, a plain 'e' in the pattern will match a plain e or an e with any diacritic in the searched text, but an e with diacritic in the pattern will only match an e with the same diacritic in the searched text. [h2]ANY_BASE_WEIGHT_IS_WILDCARD public static final [SearchIterator.ElementComparisonType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchiterator_elementcomparisontype-0000001054120130) ANY_BASE_WEIGHT_IS_WILDCARD Collation element comparison is modified to effectively provide behavior between the specified strength and strength - 1.  Collation elements in either the pattern or the searched text that have the base weight for the specified strength are treated as "wildcards" that match an element with any other weight at that collation level. For example, with a secondary-strength English collator, a plain 'e' in the pattern will match a plain e or an e with any diacritic in the searched text, but an e with diacritic in the pattern will only match an e with the same diacritic or a plain e in the searched text.
