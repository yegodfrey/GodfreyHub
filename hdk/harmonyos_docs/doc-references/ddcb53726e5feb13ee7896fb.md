# OptionalLong

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.OptionalLong
    
    public final class OptionalLong
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A container object which may or may not contain a long value. If a value is present, isPresent() will return true and getAsLong() will return the value. 

Additional methods that depend on the presence or absence of a contained value are provided, such as [orElse()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/optionallong-0000001054838550#ZH-CN_TOPIC_0000001054838550__orElse-long-) (return a default value if value not present) and [ifPresent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/optionallong-0000001054838550#ZH-CN_TOPIC_0000001054838550__ifPresent-java_util_function_LongConsumer-) (execute a block of code if the value is present). 

This is a value-based class; use of identity-sensitive operations (including reference equality (==), identity hash code, or synchronization) on instances of OptionalLong may have unpredictable results and should be avoided.

**Since:**

1.8
