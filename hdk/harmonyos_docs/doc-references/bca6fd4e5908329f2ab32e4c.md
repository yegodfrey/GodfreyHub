# DataTruncation

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.sql.SQLException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sqlexception-0000001054518572) |---|---|---|---[java.sql.SQLWarning](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sqlwarning-0000001054518574) |---|---|---|---|---java.sql.DataTruncation

An exception thrown as a DataTruncation exception (on writes) or reported as a DataTruncation warning (on reads) when a data values is unexpectedly truncated for reasons other than its having exceeded MaxFieldSize. 

The SQLstate for a DataTruncation during read is 01004. 

The SQLstate for a DataTruncation during write is 22001.

#### [h2]DataTruncation

public DataTruncation​(int index, boolean parameter, boolean read, int dataSize, int transferSize)

Creates a DataTruncation object with the SQLState initialized to 01004 when read is set to true and 22001 when read is set to false, the reason set to "Data truncation", the vendor code set to 0, and the other fields set to the given values. The cause is not initialized, and may subsequently be initialized by a call to the [Throwable#initCause(java.lang.Throwable)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__initCause-java_lang_Throwable-) method. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
index  |  The index of the parameter or column value  
parameter  |  true if a parameter value was truncated  
read  |  true if a read was truncated  
dataSize  |  the original size of the data  
transferSize  |  the size after truncation

---|---
