# Overview  
  
Provides high-level classes of the overall OHOS application development model. 

An OHOS application is defined using OHOS's core component **Ability**. The **Ability** has three types of templates, including Page, Service, and Data. 

    * **Ability** using the Page template represents an ability with UIs and must include **AbilitySlice** , which is the minimum unit for page display. For example, you can use such abilities to take photos, and view maps.
    * **Ability** using the Service template represents a no-UI ability running in the background. For example, you can use such abilities to enable music play and map navigation in the background. 
    * **Ability** using the Data template represents a no-UI ability for inter-application data operations and access. For example, you can use such abilities to search for contacts and access images, audio clips, and video clips.
