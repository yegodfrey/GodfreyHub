Method Detail [h2]login public abstract void login​([Subject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/subject-0000001054678637) subject, [CallbackHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callbackhandler-0000001054678670) handler) throws [LoginException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/loginexception-0000001054119928) Log in to this provider.  The provider relies on a CallbackHandler to obtain authentication information from the caller (a PIN, for example). If the caller passes a null handler to this method, the provider uses the handler set in the setCallbackHandler method. If no handler was set in that method, the provider queries the _auth.login.defaultCallbackHandler_ security property for the fully qualified class name of a default handler implementation. If the security property is not set, the provider is assumed to have alternative means for obtaining authentication information. **Parameters:** Parameter Name | Parameter Description

subject  |  the Subject which may contain principals/credentials used for authentication, or may be populated with additional principals/credentials after successful authentication has completed. This parameter may be null.  
handler  |  the CallbackHandler used by this provider to obtain authentication information from the caller, which may be null

[h2]setCallbackHandler public abstract void setCallbackHandler​([CallbackHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callbackhandler-0000001054678670) handler) Set a CallbackHandler.
