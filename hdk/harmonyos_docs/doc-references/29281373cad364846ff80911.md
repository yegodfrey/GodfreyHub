# EnumConstantNotPresentException  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466) |---|---|---|---java.lang.EnumConstantNotPresentException
    
    public class EnumConstantNotPresentException
    extends [RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466)  
  
---  
Thrown when an application tries to access an enum constant by name and the enum type contains no constant with the specified name. This exception can be thrown by the [API used to read annotations reflectively](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotatedelement-0000001054119724).

**Since:**

1.5
