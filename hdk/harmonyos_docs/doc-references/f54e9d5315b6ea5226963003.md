# IContinuationRegisterManager
    
    public interface IContinuationRegisterManager  
  
---  
Provides methods for interacting with the hop task management service, including methods for registering and unregistering the ability to hop, updating the device connection state, and showing the list of devices that can be selected for hopping.

#### [h2]register

void register​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) bundleName, [ExtraParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/extraparams-0000001091930936) parameter, [IContinuationDeviceCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icontinuationdevicecallback-0000001091482852) deviceCallback, [RequestCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestcallback-0000001138830321) requestCallback)

Registers an ability to be hopped with the hop task management service and obtains the registration token assigned to the ability. 

You can use [IContinuationDeviceCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icontinuationdevicecallback-0000001091482852) to listen for the device connection state changes after the user selects a device for ability hopping and implement your own processing logic. When the device is connected, [IContinuationDeviceCallback#onConnected](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icontinuationdevicecallback-0000001091482852#ZH-CN_TOPIC_0000001091482852__onConnected-ohos_aafwk_ability_continuation_ContinuationDeviceInfo-) is called to initiate the ability hopping process; when the device is disconnected, [IContinuationDeviceCallback#onDisconnected](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icontinuationdevicecallback-0000001091482852#ZH-CN_TOPIC_0000001091482852__onDisconnected-java_lang_String-) is called to perform related operations, for example, notify the user of the disconnection. In addition, you can obtain the registration token via [RequestCallback#onResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestcallback-0000001138830321#ZH-CN_TOPIC_0000001138830321__onResult-int-). 

To use this method, you must dynamically request the ohos.permission.DISTRIBUTED_DATASYNC permission from the user. The ohos.permission.DISTRIBUTED_DATASYNC permission is of the user_grant level.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
bundleName  |  Indicates the bundle name of the application whose ability is to be hopped.  
parameter  |  Indicates the [ExtraParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/extraparams-0000001091930936) object containing the extra parameters used to filter the list of available devices. This parameter can be null.  
deviceCallback  |  Indicates the callback to be invoked when the connection state of the selected device changes.  
requestCallback  |  Indicates the callback to be invoked when the hop task management service is connected.

#### [h2]updateConnectStatus

void updateConnectStatus​(int token, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) deviceId, int status, [RequestCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestcallback-0000001138830321) requestCallback)

Updates the connection state of the device where the specified ability is successfully hopped. 

After the hopping is successful, you can call this method in the UI thread to update the connection state of the hopped ability and the device connection state on the screen showing available devices.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
token  |  Indicates the registration token of the ability.  
deviceId  |  Indicates the ID of the device whose connection state is to be updated.  
status  |  Indicates the connection state to update, which can be [DeviceConnectState#FAILURE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceconnectstate-0000001091611334#ZH-CN_TOPIC_0000001091611334__FAILURE), [DeviceConnectState#IDLE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceconnectstate-0000001091611334#ZH-CN_TOPIC_0000001091611334__IDLE), [DeviceConnectState#CONNECTING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceconnectstate-0000001091611334#ZH-CN_TOPIC_0000001091611334__CONNECTING), [DeviceConnectState#CONNECTED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceconnectstate-0000001091611334#ZH-CN_TOPIC_0000001091611334__CONNECTED), or [DeviceConnectState#DIS_CONNECTING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceconnectstate-0000001091611334#ZH-CN_TOPIC_0000001091611334__DIS_CONNECTING).
