Saves data and observes data changes. ActiveData can be used to save Component data in the Model or record database data in the Model. ActiveData is essentially a data class, and observers are added to observe its data changes. When a data change occurs, the ActiveData object can notify its observers of the change. While the ActiveData is being observed, it also observes lifecycle changes of the [DataObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054119946). Generally, a [DataObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054119946) can be notified of data changes only when the AbilitySlice hosting the observer is in the foreground (ACTIVE state) since it does not need to know real-time data changes in other states. After it returns to the foreground, the [DataObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054119946) will be notified the most recent data changes.  ActiveData can also notify an observer of data changes even when the AbilitySlice is in the background state. To enable this function, set the always parameter in the [addObserver(ohos.aafwk.abilityjet.activedata.DataObserver,boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/activedata-0000001054120017#ZH-CN_TOPIC_0000001054120017__addObserver-ohos_aafwk_abilityjet_activedata_DataObserver-boolean-) method to true when you add the observer. You do not need to maintain the observers. When the lifecycle of an AbilitySlice is destroyed, the related observer is automatically removed. Therefore, ActiveData can be seen as an observable data type that can observe lifecycle states. The biggest advantage of ActiveData is that it serves as a lifecycle observer and notifies other observers of data changes based on the lifecycle of an object. Example code of using ActiveData:
    
    public class MainAbility extends Ability {
            private ActiveData fruitPrice;
    
            @Override
            protected void onStart() {
                super.onStart();
                subscribe();
            }
    
            @Override
            protected void onActive() {
                if(fruitPrice.getData().empty()) {
                    // setData will notify Observer in subscribe.
                    fruitPrice.setData(String("10"));
                }
    
                private void subscribe() {
                    final DataObserver priceObserver = new DataObserver() {
                        @Override
                        public void onChanged(@Nullable final String s) {
                            String price = "Fruit price is " + s;
                            Text.setText(price);
                        }
                    };
                    fruitPrice.addObserver(priceObserver);
                }
            }
     }
