# DosFileAttributeView
    
    public interface DosFileAttributeView
    extends [BasicFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributeview-0000001054838466)  
  
---  
A file attribute view that provides a view of the legacy "DOS" file attributes. These attributes are supported by file systems such as the File Allocation Table (FAT) format commonly used in consumer devices. 

A DosFileAttributeView is a [BasicFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributeview-0000001054838466) that additionally supports access to the set of DOS attribute flags that are used to indicate if the file is read-only, hidden, a system file, or archived. 

Where dynamic access to file attributes is required, the attributes supported by this attribute view are as defined by BasicFileAttributeView, and in addition, the following attributes are supported: 

The [getAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__getAttribute-java_nio_file_Path-java_lang_String-java_nio_file_LinkOption___-) method may be used to read any of these attributes, or any of the attributes defined by [BasicFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributeview-0000001054838466) as if by invoking the [readAttributes()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dosfileattributeview-0000001054119841#ZH-CN_TOPIC_0000001054119841__readAttributes--) method. 

The [setAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__setAttribute-java_nio_file_Path-java_lang_String-java_lang_Object-java_nio_file_LinkOption___-) method may be used to update the file's last modified time, last access time or create time attributes as defined by [BasicFileAttributeView](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributeview-0000001054838466). It may also be used to update the DOS attributes as if by invoking the [setReadOnly](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dosfileattributeview-0000001054119841#ZH-CN_TOPIC_0000001054119841__setReadOnly-boolean-), [setHidden](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dosfileattributeview-0000001054119841#ZH-CN_TOPIC_0000001054119841__setHidden-boolean-), [setSystem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dosfileattributeview-0000001054119841#ZH-CN_TOPIC_0000001054119841__setSystem-boolean-), and [setArchive](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dosfileattributeview-0000001054119841#ZH-CN_TOPIC_0000001054119841__setArchive-boolean-) methods respectively.
