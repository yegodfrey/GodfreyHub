AbstractExecutorService [java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.concurrent.AbstractExecutorService

    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

---  
Provides default implementations of [ExecutorService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/executorservice-0000001054558609) execution methods. This class implements the submit, invokeAny and invokeAll methods using a [RunnableFuture](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runnablefuture-0000001054119937) returned by newTaskFor, which defaults to the [FutureTask](https://developer.harmonyos.com/cn/docs/documentation/doc-references/futuretask-0000001054518626) class provided in this package. For example, the implementation of submit(Runnable) creates an associated RunnableFuture that is executed and returned. Subclasses may override the newTaskFor methods to return RunnableFuture implementations other than FutureTask. **Extension example**. Here is a sketch of a class that customizes [ThreadPoolExecutor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/threadpoolexecutor-0000001054518628) to use a CustomTask class instead of the default FutureTask: 
    
    public class CustomThreadPoolExecutor extends ThreadPoolExecutor {
    
       static class CustomTask<V> implements RunnableFuture<V> {...}
    
       protected <V> RunnableFuture<V> newTaskFor(Callable<V> c) {
           return new CustomTask<V>(c);
       }
       protected <V> RunnableFuture<V> newTaskFor(Runnable r, V v) {
           return new CustomTask<V>(r, v);
       }
       // ... add constructors, etc.
     }
