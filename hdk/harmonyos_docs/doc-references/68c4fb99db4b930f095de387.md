# Node

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.global.resource.solidxml.Node
    
    public abstract class Node
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Describes a node in a solid XML document. 

Node instances can be obtained only using the [SolidXml#getRoot()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/solidxml-0000001054678855#ZH-CN_TOPIC_0000001054678855__getRoot--), [getChild()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/node-0000001054558887#ZH-CN_TOPIC_0000001054558887__getChild--), or [getSibling()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/node-0000001054558887#ZH-CN_TOPIC_0000001054558887__getSibling--) method.
