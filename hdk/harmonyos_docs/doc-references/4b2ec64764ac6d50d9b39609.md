# Overview  
  
Defines resource types and provides functions for processing resources. 

For example, you can read resources from the input stream, obtain resources of different types, and obtain [RawFileEntry](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfileentry-0000001054518896) and [ConfigManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/configmanager-0000001054440133) instances of a given [ResourceManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863).
