Describes options of the incremental data source. 

The options include image data source options provided by [SourceOptions](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagesource_sourceoptions-0000001054120261) and the data update mode defined by [UpdateMode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagesource_updatemode-0000001054518946).
