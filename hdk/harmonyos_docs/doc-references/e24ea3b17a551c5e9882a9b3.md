# ProviderFormInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.ability.ProviderFormInfo
    
    public class ProviderFormInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)

Provides methods for the [Form](https://developer.harmonyos.com/cn/docs/documentation/doc-references/form-0000001071233243) provider to set form information such as the content to be displayed on the remote form and the trigger events. 

A form displays brief information about a Page ability on the UI of another application and provides basic interactive features. 

The following two roles are involved in the presentation of a form depending on who provides or displays the content: 

    * **Provider** : Provides the form content to be displayed. The form provider controls the display content, display logic, and component click events triggered on a form. 
      * The form provider uses the standard pattern, which allows it to create and manage multiple Form instances uniquely identified by their form ID. 
      * A provider can provide display contents for multiple clients. 
    * **Client:** Displays the form content. The form client controls the form layout. 
      * A client can display the content provided by multiple form providers. 
      * Clients display forms on AbilitySlice objects. Only one client can connect to the Form Manager Service on a single AbilitySlice. 
      * Clients can use the layout component provided by an AbilitySlice to lay out Form instances displayed on the ability slice. 
The typical interaction process for a client to display a form is as follows: 
    1. The client calls [AbilitySlice#acquireForm(Intent, AbilitySlice.FormCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireForm-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilitySlice_FormCallback-) to send a request to the Form Manager Service through the form framework to request the form to be displayed. 
    2. The Form Manager Service calls [Ability#onCreateForm(Intent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onCreateForm-ohos_aafwk_content_Intent-) on the form provider to notify the form provider to create a Form instance. When creating a Form instance, specify the form name and grid style in an Intent object. You can also set attributes of components and register a listener for click events. 
    3. The form framework calls [AbilitySlice.FormCallback#onAcquired(int, Form)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice_formcallback-0000001071073303#ZH-CN_TOPIC_0000001071073303__onAcquired-int-ohos_aafwk_ability_Form-) on the client to notify the client in an asynchronous way that the form display request has been processed. 
    4. The client calls [Form#getComponent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/form-0000001071233243#ZH-CN_TOPIC_0000001071233243__getComponent--) to obtain the root component of the form, and uses the layout method provided in AbilitySlice to inflate the form content to the layout of the client. 

The form provider provides the following functions: 

    * **Creating a form:** After the client calls [AbilitySlice#acquireForm(Intent, AbilitySlice.FormCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__acquireForm-ohos_aafwk_content_Intent-ohos_aafwk_ability_AbilitySlice_FormCallback-), the form framework then calls [Ability#onCreateForm(Intent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onCreateForm-ohos_aafwk_content_Intent-) on the form provider to notify the provider to create a Form instance. 
    * **Setting the binding data for a JS form:** The form provider calls [setJsBindingData(ohos.aafwk.ability.FormBindingData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/providerforminfo-0000001071833380#ZH-CN_TOPIC_0000001071833380__setJsBindingData-ohos_aafwk_ability_FormBindingData-) to set the values of variables in the JavaScript code for a JS form. 
    * **Setting the layout for a Java form:** The form provider calls methods defined in [ComponentProvider](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001) to set the layout and click events for a form, and uses [mergeActions(ohos.agp.components.ComponentProvider)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/providerforminfo-0000001071833380#ZH-CN_TOPIC_0000001071833380__mergeActions-ohos_agp_components_ComponentProvider-) to merge the specified actions to the created form. 
    * **Updating a form:** The form framework calls [Ability#onUpdateForm(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onUpdateForm-int-) on the form provider to notify the form provider to update a Form instance. The form provider then obtains the latest form data and calls [Ability#updateForm(int, FormBindingData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__updateForm-int-ohos_aafwk_ability_FormBindingData-) or [Ability#updateForm(int, ComponentProvider)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__updateForm-int-ohos_agp_components_ComponentProvider-) to update a JS form or Java form, respectively. 
    * **Deleting a form:** The form framework calls [Ability#onDeleteForm(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onDeleteForm-int-) on the form provider to notify the form provider to delete a Form instance. The form provider then deletes the persistent form instance data. 
    * **Triggering a JS form event:** The form framework calls [Ability#onTriggerFormEvent(int, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__onTriggerFormEvent-int-java_lang_String-) on the form provider to notify the form provider that a JS form event has been triggered. This callback must be overridden to perform operations after the specified event is triggered.
