The subclass of [SQLException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sqlexception-0000001054518572) is thrown when one or more client info properties could not be set on a Connection. In addition to the information provided by SQLException, a SQLClientInfoException provides a list of client info properties that were not set. Some databases do not allow multiple client info properties to be set atomically. For those databases, it is possible that some of the client info properties had been set even though the Connection.setClientInfo method threw an exception. An application can use the getFailedProperties method to retrieve a list of client info properties that were not set. The properties are identified by passing a Map<String,ClientInfoStatus> to the appropriate SQLClientInfoException constructor. **Since:** 1.6**See Also:** [ClientInfoStatus](https://developer.harmonyos.com/cn/docs/documentation/doc-references/clientinfostatus-0000001054678527), [Connection.setClientInfo(java.lang.String, java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/connection-0000001054358533#ZH-CN_TOPIC_0000001054358533__setClientInfo-java_lang_String-java_lang_String-), Constructor Summary Constructor | Description
