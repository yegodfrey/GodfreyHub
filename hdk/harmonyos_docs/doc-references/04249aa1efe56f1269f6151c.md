A global register used to store the [IAbilityDelegator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942) and [IAbilityDelegatorArgs](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegatorargs-0000001054439971) objects registered during application startup.  The application registers the [IAbilityDelegator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942) and [IAbilityDelegatorArgs](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegatorargs-0000001054439971) objects when parsing [TestRunner](https://developer.harmonyos.com/cn/docs/documentation/doc-references/testrunner-0000001054238685) parameters. When writing test cases, you can use this class to obtain the [IAbilityDelegator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942) and [IAbilityDelegatorArgs](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegatorargs-0000001054439971) objects of your own application. [IAbilityDelegator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942) can be used to control the lifecycle states of abilities; and [IAbilityDelegatorArgs](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegatorargs-0000001054439971) is used to store all parameters for unit testing. **Since:** 3Method Summary Modifier and Type | Method | Description
