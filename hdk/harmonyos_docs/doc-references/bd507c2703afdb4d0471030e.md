# LongConsumer
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface LongConsumer  
  
---  
Represents an operation that accepts a single long-valued argument and returns no result. This is the primitive type specialization of [Consumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/consumer-0000001054199898) for long. Unlike most other functional interfaces, LongConsumer is expected to operate via side-effects. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [accept(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longconsumer-0000001054838582#ZH-CN_TOPIC_0000001054838582__accept-long-).

Returns a composed LongConsumer that performs, in sequence, this operation followed by the after operation. If performing either operation throws an exception, it is relayed to the caller of the composed operation.
