# ModuleInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.bundle.ModuleInfo
    
    public class ModuleInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Stores module information about an application. 

An application can have multiple modules, and each ability belongs to a specific module. You can use this class to obtain the name and source directory of a module.
