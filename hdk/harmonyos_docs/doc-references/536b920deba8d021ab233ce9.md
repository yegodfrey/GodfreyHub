# Overview  
  
Provides [RdbStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore-0000001054518828) interfaces to perform basic operations on databases. 

This package enables external modules, such as [ohos.data.orm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054678779),to perform operations on databases.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[DataObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054200088) | Represents a data observer.  
[RdbStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore-0000001054518828) | Provides methods for managing the relational database (RDB).  
[Statement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/statement-0000001054678816) | Provides methods for setting values for precompiled SQL statements and executing precompiled SQL statements.  
[TransactionObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transactionobserver-0000001054358795) | Provides callback methods that can be called when transactions are started, committed, or rolled back.
