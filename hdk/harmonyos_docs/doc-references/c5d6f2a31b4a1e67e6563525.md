#### [h2]CONTINUE

public static final [FileVisitResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitresult-0000001054518520) CONTINUE

Continue. When returned from a [FileVisitor#preVisitDirectory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitor-0000001054678504#ZH-CN_TOPIC_0000001054678504__preVisitDirectory-T-java_nio_file_attribute_BasicFileAttributes-) method then the entries in the directory should also be visited.

Terminate. 

#### [h2]SKIP_SUBTREE

public static final [FileVisitResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitresult-0000001054518520) SKIP_SUBTREE

Continue without visiting the entries in this directory. This result is only meaningful when returned from the [FileVisitor#preVisitDirectory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitor-0000001054678504#ZH-CN_TOPIC_0000001054678504__preVisitDirectory-T-java_nio_file_attribute_BasicFileAttributes-) method; otherwise this result type is the same as returning [CONTINUE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitresult-0000001054518520#ZH-CN_TOPIC_0000001054518520__CONTINUE). 

#### [h2]SKIP_SIBLINGS

public static final [FileVisitResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitresult-0000001054518520) SKIP_SIBLINGS

Continue without visiting the siblings of this file or directory. If returned from the [FileVisitor#preVisitDirectory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitor-0000001054678504#ZH-CN_TOPIC_0000001054678504__preVisitDirectory-T-java_nio_file_attribute_BasicFileAttributes-) method then the entries in the directory are also skipped and the [FileVisitor#postVisitDirectory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filevisitor-0000001054678504#ZH-CN_TOPIC_0000001054678504__postVisitDirectory-T-java_io_IOException-) method is not invoked.
