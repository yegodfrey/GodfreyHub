FomattableFlags are passed to the [Formattable#formatTo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formattable-0000001054358572#ZH-CN_TOPIC_0000001054358572__formatTo-java_util_Formatter-int-int-int-) method and modify the output format for [Formattable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formattable-0000001054358572). Implementations of [Formattable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formattable-0000001054358572) are responsible for interpreting and validating any flags.

#### Field Detail

#### [h2]ALTERNATE

public static final int ALTERNATE

Requires the output to use an alternate form. The definition of the form is specified by the Formattable. 

This flag corresponds to '#' ('\u0023') in the format specifier.

**See Also:**

[Constant Field Values](https://developer.harmonyos.com/cn/docs/documentation/doc-references/constant-values-0000001054359004#ZH-CN_TOPIC_0000001054359004__java_util_FormattableFlags_ALTERNATE)

#### [h2]LEFT_JUSTIFY

public static final int LEFT_JUSTIFY

Left-justifies the output. Spaces ('\u0020') will be added at the end of the converted value as required to fill the minimum width of the field. If this flag is not set then the output will be right-justified. 

This flag corresponds to '-' ('\u002d') in the format specifier.

**See Also:**

[Constant Field Values](https://developer.harmonyos.com/cn/docs/documentation/doc-references/constant-values-0000001054359004#ZH-CN_TOPIC_0000001054359004__java_util_FormattableFlags_LEFT_JUSTIFY)

#### [h2]UPPERCASE

public static final int UPPERCASE

Converts the output to upper case according to the rules of the [locale](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852) given during creation of the formatter argument of the [Formattable#formatTo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formattable-0000001054358572#ZH-CN_TOPIC_0000001054358572__formatTo-java_util_Formatter-int-int-int-) method. The output should be equivalent the following invocation of [String#toUpperCase(java.util.Locale)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460#ZH-CN_TOPIC_0000001054518460__toUpperCase-java_util_Locale-)
    
    out.toUpperCase() 

This flag corresponds to 'S' ('\u0053') in the format specifier.
