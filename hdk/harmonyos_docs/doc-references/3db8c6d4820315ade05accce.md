# DatagramSocket

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.net.DatagramSocket

    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

This class represents a socket for sending and receiving datagram packets. 

A datagram socket is the sending or receiving point for a packet delivery service. Each packet sent or received on a datagram socket is individually addressed and routed. Multiple packets sent from one machine to another may be routed differently, and may arrive in any order. 

Where possible, a newly constructed DatagramSocket has the [SocketOptions#SO_BROADCAST](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketoptions-0000001054358462#ZH-CN_TOPIC_0000001054358462__SO_BROADCAST) socket option enabled so as to allow the transmission of broadcast datagrams. In order to receive broadcast packets a DatagramSocket should be bound to the wildcard address. In some implementations, broadcast packets may also be received when a DatagramSocket is bound to a more specific address. 

Example: DatagramSocket s = new DatagramSocket(null); s.bind(new InetSocketAddress(8888)); Which is equivalent to: DatagramSocket s = new DatagramSocket(8888); Both cases will create a DatagramSocket able to receive broadcasts on UDP port 8888.

#### [h2]connect

public void connect​([InetAddress](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inetaddress-0000001054518490) address, int port)

Connects the socket to a remote address for this socket. When a socket is connected to a remote address, packets may only be sent to or received from that address. By default a datagram socket is not connected. 

If the remote destination to which the socket is connected does not exist, or is otherwise unreachable, and if an ICMP destination unreachable packet has been received for that address, then a subsequent call to send or receive may throw a PortUnreachableException. Note, there is no guarantee that the exception will be thrown. 

If a security manager has been installed then it is invoked to check access to the remote address. Specifically, if the given address is a [InetAddress#isMulticastAddress](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inetaddress-0000001054518490#ZH-CN_TOPIC_0000001054518490__isMulticastAddress--), the security manager's [checkMulticast](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkMulticast-java_net_InetAddress-) method is invoked with the given address. Otherwise, the security manager's [checkConnect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkConnect-java_lang_String-int-) and [checkAccept](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkAccept-java_lang_String-int-) methods are invoked, with the given address and port, to verify that datagrams are permitted to be sent and received respectively. 

When a socket is connected, [receive](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datagramsocket-0000001054678445#ZH-CN_TOPIC_0000001054678445__receive-java_net_DatagramPacket-) and [send](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datagramsocket-0000001054678445#ZH-CN_TOPIC_0000001054678445__send-java_net_DatagramPacket-) **will not perform any security checks** on incoming and outgoing packets, other than matching the packet's and the socket's address and port. On a send operation, if the packet's address is set and the packet's address and the socket's address do not match, an IllegalArgumentException will be thrown. A socket connected to a multicast address may only be used to send packets.

#### [h2]setTrafficClass

public void setTrafficClass​(int tc) throws [SocketException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketexception-0000001054678484)

Sets traffic class or type-of-service octet in the IP datagram header for datagrams sent from this DatagramSocket. As the underlying network implementation may ignore this value applications should consider it a hint. 

The tc **must** be in the range 0 <= tc <= 255 or an IllegalArgumentException will be thrown. 

Notes: 

For Internet Protocol v4 the value consists of an integer, the least significant 8 bits of which represent the value of the TOS octet in IP packets sent by the socket. RFC 1349 defines the TOS values as follows:

    * IPTOS_RELIABILITY (0x04)
    * IPTOS_THROUGHPUT (0x08)
    * IPTOS_LOWDELAY (0x10)
The last low order bit is always ignored as this corresponds to the MBZ (must be zero) bit. 

Setting bits in the precedence field may result in a SocketException indicating that the operation is not permitted. 

for Internet Protocol v6 tc is the value that would be placed into the sin6_flowinfo field of the IP header.

#### [h2]setDatagramSocketImplFactory

public static void setDatagramSocketImplFactory​([DatagramSocketImplFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datagramsocketimplfactory-0000001054358453) fac) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Sets the datagram socket implementation factory for the application. The factory can be specified only once. 

When an application creates a new datagram socket, the socket implementation factory's createDatagramSocketImpl method is called to create the actual datagram socket implementation. 

Passing null to the method is a no-op unless the factory was already set. 

If there is a security manager, this method first calls the security manager's checkSetFactory method to ensure the operation is allowed. This could result in a SecurityException.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
fac  |  the desired factory.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |  if an I/O error occurs when setting the datagram socket factory.  
[SocketException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketexception-0000001054678484) |  if the factory is already defined.  
[SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) |  if a security manager exists and its checkSetFactory method doesn't allow the operation.  
  
**Since:**
