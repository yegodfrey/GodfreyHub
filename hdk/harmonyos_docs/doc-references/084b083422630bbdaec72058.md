# EntityHelper  
      
    public interface EntityHelper<T>  
  
---  
Provides the helper interface for operating [OrmObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormobject-0000001054120141) objects. 

The ORM annotation processor automatically generates a helper class inherited from EntityHelper for each entity class that is inherited from [OrmObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormobject-0000001054120141) and annotated with @Entity. In this case, your application does not need to implement and invoke this method.
