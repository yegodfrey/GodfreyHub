# ProcessBuilder.Redirect

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.lang.ProcessBuilder.Redirect
    
    public abstract static class ProcessBuilder.Redirect
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Represents a source of subprocess input or a destination of subprocess output. Each Redirect instance is one of the following: 
    * the special value [Redirect.PIPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415#ZH-CN_TOPIC_0000001054678415__PIPE)
    * the special value [Redirect.INHERIT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415#ZH-CN_TOPIC_0000001054678415__INHERIT)
    * a redirection to read from a file, created by an invocation of [Redirect#from](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415#ZH-CN_TOPIC_0000001054678415__from-java_io_File-)
    * a redirection to write to a file, created by an invocation of [Redirect#to](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415#ZH-CN_TOPIC_0000001054678415__to-java_io_File-)
    * a redirection to append to a file, created by an invocation of [Redirect#appendTo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415#ZH-CN_TOPIC_0000001054678415__appendTo-java_io_File-)

Each of the above categories has an associated unique [Type](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect_type-0000001054199722).

**Since:**

1.7

#### [h2]INHERIT

public static final [ProcessBuilder.Redirect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415) INHERIT

Indicates that subprocess I/O source or destination will be the same as those of the current process. This is the normal behavior of most operating system command interpreters (shells). 

It will always be true that 
    
    Redirect.INHERIT.file() == null &&
     Redirect.INHERIT.type() == Redirect.Type.INHERIT
     

#### [h2]PIPE

public static final [ProcessBuilder.Redirect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415) PIPE

Indicates that subprocess I/O will be connected to the current Java process over a pipe. This is the default handling of subprocess standard I/O. 

It will always be true that 
    
    Redirect.PIPE.file() == null &&
     Redirect.PIPE.type() == Redirect.Type.PIPE

#### [h2]appendTo

public static [ProcessBuilder.Redirect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder_redirect-0000001054678415) appendTo​([File](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759) file)

Returns a redirect to append to the specified file. Each write operation first advances the position to the end of the file and then writes the requested data. Whether the advancement of the position and the writing of the data are done in a single atomic operation is system-dependent and therefore unspecified. 

It will always be true that 
    
    Redirect.appendTo(file).file() == file &&
     Redirect.appendTo(file).type() == Redirect.Type.APPEND
