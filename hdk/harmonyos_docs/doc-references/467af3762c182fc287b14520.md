# Preferences.PreferencesObserver
    
    public static interface Preferences.PreferencesObserver  
  
---  
Provides an interface to listen for preference data changes. 

The observer of [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793) must implement the [PreferencesObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences_preferencesobserver-0000001054558815) interface. You can use the [Preferences#registerObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793#ZH-CN_TOPIC_0000001054358793__registerObserver-ohos_data_preferences_Preferences_PreferencesObserver-) method to register an observer for the [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793) object, and use the [Preferences#unregisterObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054358793#ZH-CN_TOPIC_0000001054358793__unregisterObserver-ohos_data_preferences_Preferences_PreferencesObserver-) method to unregister the observer.
