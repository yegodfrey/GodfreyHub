# IntToLongFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface IntToLongFunction  
  
---  
Represents a function that accepts an int-valued argument and produces a long-valued result. This is the int-to-long primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsLong(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inttolongfunction-0000001054558629#ZH-CN_TOPIC_0000001054558629__applyAsLong-int-).
