# AbstractProcessor

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---javax.annotation.processing.AbstractProcessor
    
    public abstract class AbstractProcessor
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Processor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processor-0000001170214349)  
  
---  
An abstract annotation processor designed to be a convenient superclass for most concrete annotation processors. This class examines annotation values to compute the [options](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractprocessor-0000001170334455#ZH-CN_TOPIC_0000001170334455__getSupportedOptions--), [annotation types](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractprocessor-0000001170334455#ZH-CN_TOPIC_0000001170334455__getSupportedAnnotationTypes--), and [source version](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractprocessor-0000001170334455#ZH-CN_TOPIC_0000001170334455__getSupportedSourceVersion--) supported by its subtypes. 

The getter methods may [issue warnings](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messager-0000001123534684#ZH-CN_TOPIC_0000001123534684__printMessage-javax_tools_Diagnostic_Kind-java_lang_CharSequence-) about noteworthy conditions using the facilities available after the processor has been [initialized](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractprocessor-0000001170334455#ZH-CN_TOPIC_0000001170334455__isInitialized--). 

Subclasses are free to override the implementation and specification of any of the methods in this class as long as the general [Processor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processor-0000001170214349) contract for that method is obeyed.

**Since:**

1.6

#### [h2]process

public abstract boolean process​([Set](https://developer.harmonyos.com/cn/docs/documentation/doc-references/set-0000001054439873)<? extends [TypeElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typeelement-0000001170214365)> annotations, [RoundEnvironment](https://developer.harmonyos.com/cn/docs/documentation/doc-references/roundenvironment-0000001123694518) roundEnv)

Processes a set of annotation types on type elements originating from the prior round and returns whether or not these annotation types are claimed by this processor. If true is returned, the annotation types are claimed and subsequent processors will not be asked to process them; if false is returned, the annotation types are unclaimed and subsequent processors may be asked to process them. A processor may always return the same boolean value or may vary the result based on chosen criteria. 

The input set will be empty if the processor supports "*" and the root elements have no annotations. A Processor must gracefully handle an empty set of annotations.

**Specified by:**
