# Overview  
  
The classes and interfaces in this package have been superseded by classes in the java.security package. See that package and, for example, java.security.Permission for details.

**Since:**

JDK1.1

#### Interface Summary

Interface | Description  
---|---  
[Acl](https://developer.harmonyos.com/cn/docs/documentation/doc-references/acl-0000001054199806) | Interface representing an Access Control List (ACL).  
[AclEntry](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry-0000001054518546) | This is the interface used for representing one entry in an Access Control List (ACL).  
[Group](https://developer.harmonyos.com/cn/docs/documentation/doc-references/group-0000001054678534) | This interface is used to represent a group of principals.  
[Owner](https://developer.harmonyos.com/cn/docs/documentation/doc-references/owner-0000001054358513) | Interface for managing owners of Access Control Lists (ACLs) or ACL configurations.  
[Permission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permission-0000001054558535) | This interface represents a permission, such as that used to grant a particular type of access to a resource.  
  
#### Exception Summary

Exception | Description  
---|---  
[AclNotFoundException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclnotfoundexception-0000001054678503) | This is an exception that is thrown whenever a reference is made to a non-existent ACL (Access Control List).  
[LastOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lastownerexception-0000001054838488) | This is an exception that is thrown whenever an attempt is made to delete the last owner of an Access Control List.  
[NotOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notownerexception-0000001054358522) | This is an exception that is thrown whenever the modification of an object (such as an Access Control List) is only allowed to be done by an owner of the object, but the Principal attempting the modification is not an owner.
