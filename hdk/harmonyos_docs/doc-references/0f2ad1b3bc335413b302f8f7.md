# CommonEventHandle
    
    public interface CommonEventHandle
    extends [StandardizedEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardizedeventhandle-0000001139715265)  
  
---  
Provides methods for handling standard common events. 

Common events include the actions of showing a menu, sending, copying, pasting, cutting, undoing, refreshing, starting dragging, canceling, confirming, moving, going to the previous or next element, printing, and going back.

**Since:**

5

**See Also:**

[StandardizedEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardizedeventhandle-0000001139715265)
