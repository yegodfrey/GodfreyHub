# ListComponentPool

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.listcomponent.ListComponentPool
    
    public class ListComponentPool
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
  
Implements the caching of components to improve the sliding performance of the ListComponent. A ListComponentPool can be used by one or more ListComponent objects.

You can create a ListComponentPool object and use [ListComponent.setListCachedPool(ListComponentPool)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcomponent-0000001218157973#ZH-CN_TOPIC_0000001218157973__setListCachedPool-ohos_agp_components_listcomponent_ListComponentPool-) to bind it to a ListComponent.
