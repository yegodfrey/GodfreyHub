# 设置主题样式

卡片支持修改的主题如下：

名称 | 描述  
---|---  
app_background | 设置卡片背板颜色。  
  
比如修改根节点的背景为透明：
    
    {
      "style": {
        "app_background": "#00000000"
      }
    }
