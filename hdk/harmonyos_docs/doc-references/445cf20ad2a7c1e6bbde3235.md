# Destroyable  
      
    public interface Destroyable  
  
---  
Objects such as credentials may optionally implement this interface to provide the capability to destroy its contents.

#### [h2]destroy

default void destroy​() throws [DestroyFailedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/destroyfailedexception-0000001054119997)

Destroy this Object. 

Sensitive information associated with this Object is destroyed or cleared. Subsequent calls to certain methods on this Object will result in an IllegalStateException being thrown. 

The default implementation throws DestroyFailedException.

**Throws:**

Throw Name | Throw Description  
---|---  
[DestroyFailedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/destroyfailedexception-0000001054119997) |  if the destroy operation fails.   
[SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) |  if the caller does not have permission to destroy this Object.  
  
#### [h2]isDestroyed

default boolean isDestroyed​()

Determine if this Object has been destroyed. 

The default implementation returns false.

**Returns:**

true if this Object has been destroyed, false otherwise.
