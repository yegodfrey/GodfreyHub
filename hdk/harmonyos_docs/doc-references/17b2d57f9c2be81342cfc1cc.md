# Component.ClickedListener
    
    public static interface Component.ClickedListener  
  
---  
Provides callbacks to be invoked when a component is clicked. 

Note that this listener monitors different events from those monitored by [TouchEventListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_toucheventlistener-0000001054358687). This class listens to a complete click event, covering the entire process from [TouchEvent#PRIMARY_POINT_DOWN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/touchevent-0000001054558959#ZH-CN_TOPIC_0000001054558959__PRIMARY_POINT_DOWN) to [TouchEvent#PRIMARY_POINT_UP](https://developer.harmonyos.com/cn/docs/documentation/doc-references/touchevent-0000001054558959#ZH-CN_TOPIC_0000001054558959__PRIMARY_POINT_UP), whereas [TouchEventListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_toucheventlistener-0000001054358687) listens to every press and release event.
