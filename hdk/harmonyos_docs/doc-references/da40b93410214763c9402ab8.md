# Component.DrawTask
    
    public static interface Component.DrawTask

Implements a draw task. 

You can use [Component.addDrawTask(ohos.agp.components.Component.DrawTask)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__addDrawTask-ohos_agp_components_Component_DrawTask-) and [Component.addDrawTask(ohos.agp.components.Component.DrawTask,int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__addDrawTask-ohos_agp_components_Component_DrawTask-int-) to add a draw task in a control, and invoke the callback when the control is updated by [Component.invalidate()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__invalidate--).

#### [h2]onDraw

void onDraw​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, [Canvas](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731) canvas)

Called when a component is updated through a draw task. 

The draw task uses the attributes of the parent canvas for drawing an object, such as alpha, width, and height.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the parent canvas.  
canvas  |  Indicates the canvas used for drawing in this draw task.
