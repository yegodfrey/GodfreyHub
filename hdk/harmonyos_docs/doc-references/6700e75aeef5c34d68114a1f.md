SearchBar.FoldListener
    
    public static interface SearchBar.FoldListener  
  
---  
Provides callbacks to be invoked when the user closes the search bar. If the [onFold()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchbar_foldlistener-0000001054439997#ZH-CN_TOPIC_0000001054439997__onFold--) method returns true, clicking the close button of the search bar will collapse the search bar to an icon. Method Summary Modifier and Type | Method | Description  
---|---|---  
boolean | [onFold](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchbar_foldlistener-0000001054439997#ZH-CN_TOPIC_0000001054439997__onFold--)​() |  Called when the user closes the [SearchBar](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchbar-0000001054358708).   
Method Detail [h2]onFold boolean onFold​() Called when the user closes the [SearchBar](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchbar-0000001054358708). **Returns:** Returns true if the listener wants to override the default behavior of clearing the text field and dismissing it; returns false otherwise.
