Field Detail [h2]TYPE_DOCUMENT_TEXT_DETECT public static final int TYPE_DOCUMENT_TEXT_DETECT Implements text detection and recognition using the legacy method, rather than using the neural network or deep learning method. This method can detect and recognize Simplified Chinese, English, and traditional Chinese texts only in horizontal layouts. The method features fast processing speed and can deliver a high precision only for simple background images that contain text in common system fonts. It is recommended that you use this method if you want to detect text in a document or screenshot quickly. [h2]TYPE_SCENE_TEXT_DETECT public static final int TYPE_SCENE_TEXT_DETECT Implements text detection and recognition using the deep learning method. This method can detect and recognize Chinese, English, Japan, Korean, Russian, Spanish, Italian, German, French, and Portuguese texts only in horizontal layouts. The supported languages can be customized as needed. The method features slow processing speed but can deliver a high precision for complex background images that contain tilted or curved texts. It is recommended that you use this method if you want to detect text in an image that has a complex background or contains diverse text types. Note that this method may not be applicable if you have high requirements on the processing speed.
