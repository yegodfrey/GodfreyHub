#### [h2]Builder

public Builder​([RawFont](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfont-0000001172398162) font)

Creates a [FontFamily](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fontfamily-0000001172238186) instance using the specified font object. A [FontFamily](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fontfamily-0000001172238186) is a collection of [RawFont](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfont-0000001172398162)s. font is the first element of the [FontFamily](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fontfamily-0000001172238186). 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
font  |  Indicates the [RawFont](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfont-0000001172398162) object.

---|---
