A layout manager that allows the user to swipe left and right as well as up and down to turn pages. 

As a container class, it allows you to add other components. A [PageSliderProvider](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pagesliderprovider-0000001054120047) must be set to generate pages that the component shows.
