# JavaCompiler.CompilationTask
    
    public static interface JavaCompiler.CompilationTask
    extends [Callable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callable-0000001054358594)<[Boolean](https://developer.harmonyos.com/cn/docs/documentation/doc-references/boolean-0000001054119700)>  
  
---  
Interface representing a future for a compilation task. The compilation task has not yet started. To start the task, call the [call](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javacompiler_compilationtask-0000001170214403#ZH-CN_TOPIC_0000001170214403__call--) method. 

Before calling the call method, additional aspects of the task can be configured, for example, by calling the [setProcessors](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javacompiler_compilationtask-0000001170214403#ZH-CN_TOPIC_0000001170214403__setProcessors-java_lang_Iterable-) method.

#### [h2]call

[Boolean](https://developer.harmonyos.com/cn/docs/documentation/doc-references/boolean-0000001054119700) call​()

Performs this compilation task. The compilation may only be performed once. Subsequent calls to this method throw IllegalStateException.
