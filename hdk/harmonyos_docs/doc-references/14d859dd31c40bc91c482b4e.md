# MalformedParametersException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466) |---|---|---|---java.lang.reflect.MalformedParametersException
    
    public class MalformedParametersException
    extends [RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466)  
  
---  
Thrown when [the java.lang.reflect package](https://developer.harmonyos.com/cn/docs/documentation/doc-references/executable-0000001054439755#ZH-CN_TOPIC_0000001054439755__getParameters--) attempts to read method parameters from a class file and determines that one or more parameters are malformed. 

The following is a list of conditions under which this exception can be thrown: 

    * The number of parameters (parameter_count) is wrong for the method 
    * A constant pool index is out of bounds. 
    * A constant pool index does not refer to a UTF-8 entry 
    * A parameter's name is "", or contains an illegal character 
    * The flags field contains an illegal flag (something other than FINAL, SYNTHETIC, or MANDATED) 
See [Executable.getParameters()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/executable-0000001054439755#ZH-CN_TOPIC_0000001054439755__getParameters--) for more information.
