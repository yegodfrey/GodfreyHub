# ComponentPadding

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.window.service.ComponentPadding
    
    public class ComponentPadding
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Describe window padding. 

After a listener is set via [Window#setOnApplyComponentPaddingListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/window-0000001054358748#ZH-CN_TOPIC_0000001054358748__setOnApplyComponentPaddingListener-ohos_agp_window_service_IApplyComponentPaddingListener-), the callback [IApplyComponentPaddingListener#notifyPaddingChange(ComponentPadding padding)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iapplycomponentpaddinglistener-0000001091611342#ZH-CN_TOPIC_0000001091611342__notifyPaddingChange-ohos_agp_window_service_ComponentPadding-) will be invoked upon padding changes. Applications will use the new padding values passed to the callback for layout. 

**Since:**

5
