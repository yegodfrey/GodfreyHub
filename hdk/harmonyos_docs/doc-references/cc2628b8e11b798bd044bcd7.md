Provides access to the search service. The fusion search service provides the index and search capabilities. Applications can customize index attributes and index data structures.  This class provides methods for connecting to the fusion search service, setting the index attributes, adding, deleting, updating, and clearing indexes, listening to index changes, and obtaining search sessions.  Before using the fusion search service, an application must create a SearchAbility instance and call [connect(ohos.data.search.connect.ServiceConnectCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchability-0000001054518838#ZH-CN_TOPIC_0000001054518838__connect-ohos_data_search_connect_ServiceConnectCallback-) to connect to the service. The application must call [disconnect()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchability-0000001054518838#ZH-CN_TOPIC_0000001054518838__disconnect--) to disconnect from the service to release resources. **Since:** 3Constructor Summary Constructor | Description
