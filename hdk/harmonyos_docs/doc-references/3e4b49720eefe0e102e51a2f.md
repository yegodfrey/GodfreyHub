The class implements a buffered output stream. [h2]write public void write​(byte[] b, int off, int len) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) Writes len bytes from the specified byte array starting at offset off to this buffered output stream.  Ordinarily this method stores bytes from the given array into this stream's buffer, flushing the buffer to the underlying output stream as needed. If the requested length is at least as large as this stream's buffer, however, then this method will flush the buffer and write the bytes directly to the underlying output stream. Thus redundant BufferedOutputStreams will not copy data unnecessarily. **Overrides:** [write](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filteroutputstream-0000001054238431#ZH-CN_TOPIC_0000001054238431__write-byte:A-int-int-) in class [FilterOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filteroutputstream-0000001054238431) **Parameters:** Parameter Name | Parameter Description
