# Overview  
  
#### Enum Summary

Enum | Description  
---|---  
[AlignContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aligncontent-0000001218157981) | Enumerates the alignment modes for all components in a multi-line FlexLayout along the cross axis.  
[AlignItems](https://developer.harmonyos.com/cn/docs/documentation/doc-references/alignitems-0000001217877945) | Enumerates the alignment modes for all components in a single-line FlexLayout along the cross axis.  
[AlignSelf](https://developer.harmonyos.com/cn/docs/documentation/doc-references/alignself-0000001217996519) | Enumerates the alignment modes for a single component along the cross axis.  
[FlexDirection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/flexdirection-0000001172716640) | Enumerates the directions for the main axis in the FlexLayout.  
[FlexWrap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/flexwrap-0000001172398144) | Enumerates the flex wrap modes of the FlexLayout, which can be single-line or multi-line.  
[JustifyContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/justifycontent-0000001218076473) | Enumerates the alignment modes for all components along the main axis.
