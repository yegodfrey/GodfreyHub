#### [h2]KvManagerConfig

public KvManagerConfig​([Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) context)

A constructor used to create a [KvManagerConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvmanagerconfig-0000001054358783) instance based on the application context. 

The input parameter context is used to obtain the package name of the caller. By default, the same-account networking is used.

**Parameters:**

Parameter Name | Parameter Description
