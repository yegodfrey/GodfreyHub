# OnClickListener

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.aafwk.ability.ViewListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/viewlistener-0000001054358670) |---|---ohos.aafwk.ability.OnClickListener
    
    public abstract class OnClickListener
    extends [ViewListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/viewlistener-0000001054358670)

Provides callback methods that are registered with the [AbilityForm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952) supplier for listening for click events. This class inherits from [ViewListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/viewlistener-0000001054358670) and provides methods to be called back when a clickable component, such as a button or image, is clicked.

Description copied from class: [ViewListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/viewlistener-0000001054358670#ZH-CN_TOPIC_0000001054358670__onTouchEvent-ohos_aafwk_ability_AbilityForm-ohos_aafwk_ability_ViewsStatus-)

A callback method registered with the AbilityForm supplier for you to implement callbacks upon touch events. 

Generally, this method is triggered in the following scenario: 

    1. The developer of the supplier uses [AbilityForm#registerViewListener(int, ViewListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityform-0000001054199952#ZH-CN_TOPIC_0000001054199952__registerViewListener-int-ohos_aafwk_ability_ViewListener-) to register a callback method upon touch events.
    2. When a touch event is dispatched to a component on the client, the event is sent to the supplier through the AbilityForm framework, and the AbilityForm framework triggers the registered callback method [ViewListener#onTouchEvent(AbilityForm, ViewsStatus)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/viewlistener-0000001054358670#ZH-CN_TOPIC_0000001054358670__onTouchEvent-ohos_aafwk_ability_AbilityForm-ohos_aafwk_ability_ViewsStatus-).
