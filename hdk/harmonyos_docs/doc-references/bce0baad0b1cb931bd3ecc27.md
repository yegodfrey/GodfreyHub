A selectable channel for stream-oriented listening sockets.  A server-socket channel is created by invoking the [open](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serversocketchannel-0000001054119750#ZH-CN_TOPIC_0000001054119750__open--) method of this class. It is not possible to create a channel for an arbitrary, pre-existing [ServerSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serversocket-0000001054518492). A newly-created server-socket channel is open but not yet bound. An attempt to invoke the [accept](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serversocketchannel-0000001054119750#ZH-CN_TOPIC_0000001054119750__accept--) method of an unbound server-socket channel will cause a [NotYetBoundException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notyetboundexception-0000001054678465) to be thrown. A server-socket channel can be bound by invoking one of the [bind](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serversocketchannel-0000001054119750#ZH-CN_TOPIC_0000001054119750__bind-java_net_SocketAddress-int-) methods defined by this class.  Socket options are configured using the [setOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serversocketchannel-0000001054119750#ZH-CN_TOPIC_0000001054119750__setOption-java_net_SocketOption-T-) method.
