#### [h2]publishReminder

public static int publishReminder​([ReminderRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419) reminderReq) throws [ReminderManager.AppLimitExceedsException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remindermanager_applimitexceedsexception-0000001123534754), [ReminderManager.SysLimitExceedsException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remindermanager_syslimitexceedsexception-0000001170334523), [RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984)

Publishes a scheduled reminder. 

Third-party applications can call this method to publish a scheduled reminder. After this method is called, the timing and pop-up notification functions of the calling application will be performed by the system service agent in the background, even when the application is frozen or exits. You can call the [ReminderRequest#setIntentAgent(String, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419#ZH-CN_TOPIC_0000001170214419__setIntentAgent-java_lang_String-java_lang_String-) method to specify whether to start the application after the pop-up notification is taped. 

The background agent maintains an ordered list of reminders for all third-party applications. The list is updated based on the scheduled trigger time of each reminder. The system starts only one most recent scheduled reminder at a time. If a reminder with a more recent trigger time is added, the new scheduled reminder will be put on top of the list. The next reminder is triggered only after the current reminder is complete. 

One application can create a maximum of 30 valid reminders, and the total number of valid reminders in the system cannot exceed 2000. The minimum snooze interval for a reminder is 5 minutes. 

**Permissions:** ohos.permission.PUBLISH_AGENT_REMINDER

**Parameters:**

Parameter Name | Parameter Description  
---|---  
reminderReq  |  Indicates the reminder instance to publish. This parameter cannot be null. Otherwise, an exception will be thrown due to invalid parameters, causing the application to crash.  
  
**Returns:**

Returns the unique reminder ID.

**Throws:**

Throw Name | Throw Description  
---|---  
[RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984) |  Throws this exception upon an inter-process communication error.  
[ReminderManager.AppLimitExceedsException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remindermanager_applimitexceedsexception-0000001123534754) |  Throws this exception if the number of valid reminders of the current application in the system exceeds 30 (excluding those that have expired and will not be triggered again.)  
[ReminderManager.SysLimitExceedsException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remindermanager_syslimitexceedsexception-0000001170334523) |  Throws this exception if the total number of valid reminders in the system exceeds 2000 (excluding those that have expired and will not be triggered again.)
