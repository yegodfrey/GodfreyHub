# JapaneseEra

An era in the Japanese Imperial calendar system. 

The Japanese government defines the official name and start date of each era. Eras are consecutive and their date ranges do not overlap, so the end date of one era is always the day before the start date of the next era. 

The Java SE Platform supports all eras defined by the Japanese government, beginning with the Meiji era. Each era is identified in the Platform by an integer value and a name. The [of(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/japaneseera-0000001054238573#ZH-CN_TOPIC_0000001054238573__of-int-) and [valueOf(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/japaneseera-0000001054238573#ZH-CN_TOPIC_0000001054238573__valueOf-java_lang_String-) methods may be used to obtain a singleton instance of JapaneseEra for each era. The [values()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/japaneseera-0000001054238573#ZH-CN_TOPIC_0000001054238573__values--) method returns the singleton instances of all supported eras. 

For convenience, this class declares a number of public static final fields that refer to singleton instances returned by the values() method.

#### [h2]of

public static [JapaneseEra](https://developer.harmonyos.com/cn/docs/documentation/doc-references/japaneseera-0000001054238573) of​(int japaneseEra)

Obtains an instance of JapaneseEra from an int value. 
    * The value 1 is associated with the 'Showa' era, because it contains 1970-01-01 (ISO calendar system).
    * The values -1 and 0 are associated with two earlier eras, Meiji and Taisho, respectively.
    * A value greater than 1 is associated with a later era, beginning with Heisei (2).

Every instance of JapaneseEra that is returned from the [values()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/japaneseera-0000001054238573#ZH-CN_TOPIC_0000001054238573__values--) method has an int value (available via [Era#getValue()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/era-0000001054119901#ZH-CN_TOPIC_0000001054119901__getValue--) which is accepted by this method.

#### [h2]range

public [ValueRange](https://developer.harmonyos.com/cn/docs/documentation/doc-references/valuerange-0000001054838534) range​([TemporalField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalfield-0000001054439865) field)

Gets the range of valid values for the specified field. 

The range object expresses the minimum and maximum valid values for a field. This era is used to enhance the accuracy of the returned range. If it is not possible to return the range, because the field is not supported or for some other reason, an exception is thrown. 

If the field is a [ChronoField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronofield-0000001054119838) then the query is implemented here. The ERA field returns the range. All other ChronoField instances will throw an UnsupportedTemporalTypeException. 

If the field is not a ChronoField, then the result of this method is obtained by invoking TemporalField.rangeRefinedBy(TemporalAccessor) passing this as the argument. Whether the range can be obtained is determined by the field. 

The range of valid Japanese eras can change over time due to the nature of the Japanese calendar system.
