    extends [RdbException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbexception-0000001054558821)

Represents an exception indicating that the database file is locked. 

This exception usually occurs when multiple threads access the database concurrently. This class is inherited from RuntimeException. You must handle this exception by yourself.
