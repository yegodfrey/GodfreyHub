Represents internal abilities that are integrated into the JS UI framework. Internal abilities are applicable to services that are closely related to ability service logics and require low response latency.  Internal abilities can be called only by the local ability. For details about how to process requests to a remote ability, see [(int, MessageParcel, MessageParcel, MessageOption)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299#ZH-CN_TOPIC_0000001054120299__onRemoteRequest-int-ohos_rpc_MessageParcel-ohos_rpc_MessageParcel-ohos_rpc_MessageOption-).  The bundleName and abilityName are used to map internal abilities on the JavaScript side and the Java side. When you register an internal ability handler with the local ability, ensure that the bundle and ability names are the same as those on the JavaScript side, and note that the names are case sensitive. If abilityType is set to an internal ability on the JavaScript side, AceInternalAbilityHandler#onRemoteRequest(int, MessageParcel, MessageParcel) will be called when a call request from JavaScript is received. You can use the onRemoteRequest method to implement functions provided by the internal ability. The functions are differentiated by service codes and requested with different data structures.
