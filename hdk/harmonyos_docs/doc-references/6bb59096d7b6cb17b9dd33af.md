# Overview  
  
Provides a class that defines custom properties for an ability, which can be passed as an input parameter in the call when you start the ability. 

This package provides an [AbilityStartSetting](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitystartsetting-0000001060519066) class for you to customize properties used for starting an ability.
