# EnumSet

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.AbstractCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractcollection-0000001054358576)<E> |---|---[java.util.AbstractSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractset-0000001054358569)<E> |---|---|---java.util.EnumSet<E>
    
    public abstract class EnumSet<E extends [Enum](https://developer.harmonyos.com/cn/docs/documentation/doc-references/enum-0000001054838398)<E>>

    implements [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421), [Serializable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serializable-0000001054358416)  
  
---  
A specialized [Set](https://developer.harmonyos.com/cn/docs/documentation/doc-references/set-0000001054439873) implementation for use with enum types. All of the elements in an enum set must come from a single enum type that is specified, explicitly or implicitly, when the set is created. Enum sets are represented internally as bit vectors. This representation is extremely compact and efficient. The space and time performance of this class should be good enough to allow its use as a high-quality, typesafe alternative to traditional int-based "bit flags." Even bulk operations (such as containsAll and retainAll) should run very quickly if their argument is also an enum set. 

The iterator returned by the iterator method traverses the elements in their _natural order_ (the order in which the enum constants are declared). The returned iterator is _weakly consistent_ : it will never throw [ConcurrentModificationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentmodificationexception-0000001054558603) and it may or may not show the effects of any modifications to the set that occur while the iteration is in progress. 

Null elements are not permitted. Attempts to insert a null element will throw [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710). Attempts to test for the presence of a null element or to remove one will, however, function properly. 

Like most collection implementations, EnumSet is not synchronized. If multiple threads access an enum set concurrently, and at least one of the threads modifies the set, it should be synchronized externally. This is typically accomplished by synchronizing on some object that naturally encapsulates the enum set. If no such object exists, the set should be "wrapped" using the [Collections#synchronizedSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collections-0000001054518604#ZH-CN_TOPIC_0000001054518604__synchronizedSet-java_util_Set-) method. This is best done at creation time, to prevent accidental unsynchronized access: 
    
    Set<MyEnum> s = Collections.synchronizedSet(EnumSet.noneOf(MyEnum.class));
     

Implementation note: All basic operations execute in constant time. They are likely (though not guaranteed) to be much faster than their [HashSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/hashset-0000001054678594) counterparts. Even bulk operations execute in constant time if their argument is also an enum set. 

This class is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).
