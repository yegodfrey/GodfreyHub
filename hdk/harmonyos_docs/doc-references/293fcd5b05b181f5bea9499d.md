# Overview  
  
Provides task-related functions. 

You can revoke a task and obtain the task priority.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Revocable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/revocable-0000001054238781) | Revokes an asynchronous task that is dispatched by calling [TaskDispatcher.asyncDispatch(java.lang.Runnable)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__asyncDispatch-java_lang_Runnable-), [TaskDispatcher.delayDispatch(java.lang.Runnable, long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__delayDispatch-java_lang_Runnable-long-), or [TaskDispatcher.asyncGroupDispatch(ohos.app.dispatcher.Group, java.lang.Runnable)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskdispatcher-0000001054518794#ZH-CN_TOPIC_0000001054518794__asyncGroupDispatch-ohos_app_dispatcher_Group-java_lang_Runnable-).  
  
#### Enum Summary

Enum | Description  
---|---  
[TaskPriority](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskpriority-0000001054838736) | Specifies the priority of all tasks in a specific task dispatcher when the task dispatcher is being obtained or created.
