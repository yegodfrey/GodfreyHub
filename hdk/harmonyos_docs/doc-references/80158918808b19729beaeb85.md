# Pair

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.Pair<F,S>
    
    public class Pair<F,S>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides a data container that saves any two objects as one object. 

By packing two parameters into one, Pair container makes parameter transfer easier.
