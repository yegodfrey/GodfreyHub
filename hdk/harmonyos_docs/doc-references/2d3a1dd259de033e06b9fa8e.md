# IntervalTimer

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.IntervalTimer
    
    public abstract class IntervalTimer
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a timer for task execution that lasts for a while and repeats at regular intervals. 

Example code: 
    
    new IntervalTimer(60000, 3000) {
        @Override
         public void onInterval(long remain) {
             // This method will be called at the 3000th millisecond and repeatedly called every 3000 milliseconds.
         }
    
        @Override
         public void onFinish() {
             // This method will be called at the 60000th millisecond.
         }
     }.schedule();
     

Note: [IntervalTimer#onInterval(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intervaltimer-0000001054239003#ZH-CN_TOPIC_0000001054239003__onInterval-long-) is synchronized. If the execution duration of this method is longer than the interval, the next call waits until the previous callback is complete. For example, if the interval is 3000 milliseconds, and the [IntervalTimer#onInterval(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intervaltimer-0000001054239003#ZH-CN_TOPIC_0000001054239003__onInterval-long-) callback lasts 4000 milliseconds, the first call is at the 3000th millisecond, and the next call is at the 9000th millisecond.

#### [h2]IntervalTimer

public IntervalTimer​(long duration, long interval)

Creates an IntervalTimer with a given work duration and interval. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
duration  |  Indicates the work duration of the interval timer, in milliseconds, which cannot be less than the interval. When the work duration is over, [IntervalTimer#onFinish()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intervaltimer-0000001054239003#ZH-CN_TOPIC_0000001054239003__onFinish--) will be called to notify that the interval timer has gone off.  
interval  |  Indicates the interval time, in milliseconds, which is within the range of (1, duration]. Every time an interval starts, [IntervalTimer#onInterval(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intervaltimer-0000001054239003#ZH-CN_TOPIC_0000001054239003__onInterval-long-) is called to notify the remaining work time of the interval timer.
