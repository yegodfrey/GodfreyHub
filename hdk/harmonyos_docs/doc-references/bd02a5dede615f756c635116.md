# Overview  
  
Provides APIs to applications for managing wallpapers, obtaining wallpaper color information, and receiving color change notifications.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[IWallpaperColorsChangedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iwallpapercolorschangedlistener-0000001054440241) | Provides the listener for wallpaper color changes.  
  
#### Class Summary

Class | Description  
---|---  
[WallpaperColorsCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wallpapercolorscollection-0000001054518968) | Provides dominant colors of the wallpaper.  
[WallpaperController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wallpapercontroller-0000001054678956) | Provides the access to the wallpaper management service.
