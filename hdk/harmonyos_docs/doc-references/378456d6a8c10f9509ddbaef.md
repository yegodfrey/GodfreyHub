Constructs notifications that include a picture attachment. 

This class is used with [NotificationContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationcontent-0000001054678842) and [NotificationRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854). Example code: 
    
    NotificationRequest request = new NotificationRequest();
     NotificationPictureContent pictureContent = new NotificationPictureContent();
     NotificationContent notificationContent = new NotificationContent(pictureContent);
     request.setContent(notificationContent);

Sets the brief text to be included in a picture-attached notification. 

The brief text is a summary of a picture-attached notification and is displayed in the first line of the notification. Similar to [setAdditionalText(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationpicturecontent-0000001054120171#ZH-CN_TOPIC_0000001054120171__setAdditionalText-java_lang_String-), the font of the brief text is also smaller than the notification text. 

The positions where the brief text and additional text will display may conflict. If both texts are set, only the additional text will be displayed.
