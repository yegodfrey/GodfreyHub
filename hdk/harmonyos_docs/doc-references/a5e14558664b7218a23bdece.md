# IPasteDataChangedListener
    
    public interface IPasteDataChangedListener  
  
---  
An interface to define a listener for pasteboard content changes. 

Use [SystemPasteboard#addPasteDataChangedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/systempasteboard-0000001054518964#ZH-CN_TOPIC_0000001054518964__addPasteDataChangedListener-ohos_miscservices_pasteboard_IPasteDataChangedListener-) to register a listener. Use [SystemPasteboard#removePasteDataChangedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/systempasteboard-0000001054518964#ZH-CN_TOPIC_0000001054518964__removePasteDataChangedListener-ohos_miscservices_pasteboard_IPasteDataChangedListener-) to remove the listener.
