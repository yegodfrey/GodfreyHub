# Overview  
  
Provides for system input and output through data streams, serialization and the file system. Unless otherwise noted, passing a null argument to a constructor or method in any class or interface in this package will cause a NullPointerException to be thrown. **Package Specification**
    * [ Java Object Serialization Specification ](https://docs.oracle.com/javase/8/docs/platform/serialization/spec/serialTOC.html)
**Related Documentation** For overviews, tutorials, examples, guides, and tool documentation, please see: 
    * [Serialization Enhancements](https://docs.oracle.com/javase/8/docs/technotes/guides/serialization)

**Since:**

JDK1.0
