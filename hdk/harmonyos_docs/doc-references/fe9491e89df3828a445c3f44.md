# Overview  
  
Provides public classes or interfaces. 

These classes or interfaces can be used by the classes or interfaces in ohos.data.distributed.device or ohos.data.distributed.user.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[KvManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvmanager-0000001054238801) | Provides interfaces to manage a KvStore database, including obtaining, closing, and deleting the KvStore.  
[KvStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstore-0000001054678771) | Represents a key-value distributed database and provides methods for adding, deleting, modifying, querying, and subscribing to distributed data.  
[KvStoreObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstoreobserver-0000001054838756) | Listens for data changes in the KvStore database.  
[KvStoreResultSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstoreresultset-0000001054358790) | Provide methods to obtain the result set of the KvStore database.  
[KvStoreServiceDeathRecipient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstoreservicedeathrecipient-0000001054120131) | Provides the callback that is invoked when the KvStore service stops running.  
[SyncCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/synccallback-0000001054120060) | A callback interface used to receive database synchronization results.
