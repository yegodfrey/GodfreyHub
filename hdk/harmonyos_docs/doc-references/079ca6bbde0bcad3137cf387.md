# DisplayResizeController

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.accessibility.ability.DisplayResizeController
    
    public class DisplayResizeController
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a controller for the display resizing operations. 

This controller offers the following functions: 

    1. Registering a listener to observe the display resizing operations. 
    2. Controlling the display resizing.
