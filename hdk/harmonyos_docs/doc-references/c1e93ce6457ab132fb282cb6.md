Savepoint
    
    public interface Savepoint  
  
---  
The representation of a savepoint, which is a point within the current transaction that can be referenced from the Connection.rollback method. When a transaction is rolled back to a savepoint all changes made after that savepoint are undone.  Savepoints can be either named or unnamed.
