# Overview  
  
Provides methods to implement biometric authentication. 

The methods include checking the authentication capability, and performing and canceling authentication. Biometrics, such as human face and fingerprint, can be used for authentication. Before performing authentication, check whether a device supports biometric authentication based on the authentication type, security level, and whether local authentication is used. If biometric authentication is not supported, consider using other authentication capabilities.
