# OsHelperErrnoException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---ohos.system.OsHelperErrnoException
    
    public final class OsHelperErrnoException
    extends [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708)  
  
---  
Provides a checked exception that is thrown if an [OsHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/oshelper-0000001054200264) method fails. Each OsHelperErrnoException instance contains an errno value indicating the error type. For details about the error types, see [OsHelperConstants](https://developer.harmonyos.com/cn/docs/documentation/doc-references/oshelperconstants-0000001054519004).
