# Overview  
  
Enables your applications to use OS account-related functions provided by the OS. 

This package provides basic account-related functions, including querying and updating the distributed information of an OS account in a distributed system, creating, removing, and starting an OS account, updating OS account information, and querying information about the current OS account or all OS accounts.
