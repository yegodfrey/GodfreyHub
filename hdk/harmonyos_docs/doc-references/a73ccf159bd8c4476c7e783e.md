# Options

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.data.distributed.common.Options
    
    public class Options
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides configuration options for creating a KvStore. 

You can determine whether to create another database if a KvStore database is missing, whether to encrypt the database, and the database type.
