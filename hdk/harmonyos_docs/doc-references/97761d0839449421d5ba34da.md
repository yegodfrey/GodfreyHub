# OutputStreamWriter  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710) |---|---java.io.OutputStreamWriter
    
    public class OutputStreamWriter
    extends [Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710)  
  
---  
An OutputStreamWriter is a bridge from character streams to byte streams: Characters written to it are encoded into bytes using a specified [charset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charset-0000001054678500). The charset that it uses may be specified by name or may be given explicitly, or the platform's default charset may be accepted. 

Each invocation of a write() method causes the encoding converter to be invoked on the given character(s). The resulting bytes are accumulated in a buffer before being written to the underlying output stream. The size of this buffer may be specified, but by default it is large enough for most purposes. Note that the characters passed to the write() methods are not buffered. 

For top efficiency, consider wrapping an OutputStreamWriter within a BufferedWriter so as to avoid frequent converter invocations. For example: 
    
    Writer out
       = new BufferedWriter(new OutputStreamWriter(System.out));
     

A _surrogate pair_ is a character represented by a sequence of two char values: A _high_ surrogate in the range '\uD800' to '\uDBFF' followed by a _low_ surrogate in the range '\uDC00' to '\uDFFF'. 

A _malformed surrogate element_ is a high surrogate that is not followed by a low surrogate or a low surrogate that is not preceded by a high surrogate. 

This class always replaces malformed surrogate elements and unmappable character sequences with the charset's default _substitution sequence_. The [CharsetEncoder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetencoder-0000001054558501) class should be used when more control over the encoding process is required.

#### [h2]getEncoding

public [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) getEncoding​()

Returns the name of the character encoding being used by this stream. 

If the encoding has an historical name then that name is returned; otherwise the encoding's canonical name is returned. 

If this instance was created with the [OutputStreamWriter(java.io.OutputStream,java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstreamwriter-0000001054838388#ZH-CN_TOPIC_0000001054838388__OutputStreamWriter-java_io_OutputStream-java_lang_String-) constructor then the returned name, being unique for the encoding, may differ from the name passed to the constructor. This method may return null if the stream has been closed. 

**Returns:**

The historical name of this encoding, or possibly null if the stream has been closed
