#### [h2]dataListenInsecureRfcomm

public [SppServerSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200) dataListenInsecureRfcomm​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) name, [UUID](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uuid-0000001054358588) uuid) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Creates an insecure RFCOMM Bluetooth server listening socket based on the service record. 

This connection mode does not require link key authentication and may encounter man-in-the-middle attacks. For Bluetooth 2.1 devices, the link will be forcibly encrypted. For devices using earlier Bluetooth versions, the link will not be encrypted. If you need an encrypted communication channel, use [dataListenRfcomm(java.lang.String, java.util.UUID)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datalistensocket-0000001172398174#ZH-CN_TOPIC_0000001172398174__dataListenRfcomm-java_lang_String-java_util_UUID-). 

Use [SppServerSocket#accept](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200#ZH-CN_TOPIC_0000001172238200__accept--) to retrieve incoming connections from devices. 

The system will assign an unused RFCOMM channel. 

The system registers a Service Discovery Protocol (SDP) record with the local SDP server, records the service name, and automatically assigns a channel. Remote Bluetooth devices can use the same UUID to query the SDP server and identify the channel to connect to. This SDP record will be removed if the socket is disabled or the application exits unexpectedly.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
name  |  Indicates the service name in the SDP record.  
uuid  |  Indicates the UUID in the SDP record.  
  
**Returns:**

Returns an insecure RFCOMM [SppServerSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200).

**Throws:**

Throw Name | Throw Description  
---|---  
[IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |  Throws this exception if an error occurs, for example, Bluetooth is disabled or unavailable.
