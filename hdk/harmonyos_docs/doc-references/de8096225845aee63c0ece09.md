SSLSessionBindingListener
    
    public interface SSLSessionBindingListener
    extends [EventListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventlistener-0000001054838538)  
  
---  
This interface is implemented by objects which want to know when they are being bound or unbound from a SSLSession. When either event occurs via [SSLSession#putValue(String, Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsession-0000001054238659#ZH-CN_TOPIC_0000001054238659__putValue-java_lang_String-java_lang_Object-) or [SSLSession#removeValue(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsession-0000001054238659#ZH-CN_TOPIC_0000001054238659__removeValue-java_lang_String-), the event is communicated through a SSLSessionBindingEvent identifying the session.**Since:** 1.4**See Also:** [SSLSession](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsession-0000001054238659), [SSLSessionBindingEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsessionbindingevent-0000001054678633)Method Summary Modifier and Type | Method | Description
