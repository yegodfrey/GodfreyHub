# KeyManagerFactory  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---javax.net.ssl.KeyManagerFactory
    
    public class KeyManagerFactory
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
This class acts as a factory for key managers based on a source of key material. Each key manager manages a specific type of key material for use by secure sockets. The key material is based on a KeyStore and/or provider specific sources.

**Since:**

1.4

#### [h2]getInstance

public static final [KeyManagerFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keymanagerfactory-0000001054558663) getInstance​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) algorithm) throws [NoSuchAlgorithmException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nosuchalgorithmexception-0000001054678532)

Returns a KeyManagerFactory object that acts as a factory for key managers. 

This method traverses the list of registered security Providers, starting with the most preferred Provider. A new KeyManagerFactory object encapsulating the KeyManagerFactorySpi implementation from the first Provider that supports the specified algorithm is returned. 

Note that the list of registered providers may be retrieved via the [Security#getProviders()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/security-0000001054238527#ZH-CN_TOPIC_0000001054238527__getProviders--) method.

**Parameters:**

**Returns:**

the new KeyManagerFactory object.

---|---

#### [h2]init

Initializes this factory with a source of key material. 

The provider typically uses a KeyStore for obtaining key material for use during secure socket negotiations. The KeyStore is generally password-protected. 

For more flexible initialization, please see [init(javax.net.ssl.ManagerFactoryParameters)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keymanagerfactory-0000001054558663#ZH-CN_TOPIC_0000001054558663__init-javax_net_ssl_ManagerFactoryParameters-). 

**Parameters:**

---|---

**Throws:**

Throw Name | Throw Description  
---|---
