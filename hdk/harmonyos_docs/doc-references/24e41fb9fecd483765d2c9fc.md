# PowerManager.RunningLock

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.powermanager.PowerManager.RunningLock
    
    public final class PowerManager.RunningLock
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a mechanism to prevent the system from hibernating so that the applications can run in the background or when the screen is off. 

[PowerManager#createRunningLock(String, RunningLockType)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager-0000001054238967#ZH-CN_TOPIC_0000001054238967__createRunningLock-java_lang_String-ohos_powermanager_PowerManager_RunningLockType-) can be called to obtain a [RunningLock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglock-0000001054678937). 

[lock(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglock-0000001054678937#ZH-CN_TOPIC_0000001054678937__lock-long-) can be called to set the lock duration, during which the system will not hibernate. After the lock duration times out, the lock is automatically released and the system hibernates if no other [RunningLock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglock-0000001054678937) is set. 

The following is an example of how to use [RunningLock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglock-0000001054678937).

@Step1: Obtain the [PowerManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager-0000001054238967) object, create a global [RunningLock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglock-0000001054678937) object for it, and set the [RunningLockType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglocktype-0000001054120297). If the [RunningLock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglock-0000001054678937) object is damaged, the lock duration will become invalid. 

@Step2: Set a lock duration greater than 0 in milliseconds 
    
    PowerManager powerManager = new PowerManager();
     PowerManager.RunningLock runningLock =
         powerManager.createRunningLock("test", PowerManager.RunningLockType.BACKGROUND);
    
     runningLock.lock(5000);
