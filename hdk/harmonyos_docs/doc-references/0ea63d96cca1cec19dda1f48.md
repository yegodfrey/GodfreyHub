Thrown to indicate that a program has attempted to access an element of an annotation whose type has changed after the annotation was compiled (or serialized). This exception can be thrown by the [API used to read annotations reflectively](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotatedelement-0000001054119724).**Since:** 1.5**See Also:** [AnnotatedElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotatedelement-0000001054119724), Constructor Summary Constructor | Description
