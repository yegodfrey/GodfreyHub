Provides interfaces to generate ByTrace logs. This class traces the start, end, and value changes of key processes that last for at least 3 ms.  Example: To trace a name verification that is expected to complete within 5 ms: 
    
    ByTrace.startTrace("checkName", "5");
     Bytrace.finishTrace("checkName");
     

To trace the number of layers, which is 3: 
    
    Bytrace.count("curLayer", 3);
