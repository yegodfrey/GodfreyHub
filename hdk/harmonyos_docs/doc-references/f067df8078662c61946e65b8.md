---  
Represents an operation on a single operand that produces a result of the same type as its operand. This is a specialization of Function for the case where the operand and result are of the same type. This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [Function.apply(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955#ZH-CN_TOPIC_0000001054119955__apply-T-). **Since:** 1.8**See Also:** [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955)Method Summary Modifier and Type | Method | Description
