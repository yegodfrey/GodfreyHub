# PSource  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---javax.crypto.spec.PSource
    
    public class PSource
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
This class specifies the source for encoding input P in OAEP Padding, as defined in the [PKCS#1 v2.2](https://tools.ietf.org/rfc/rfc8017.txt) standard. 
    
    PSourceAlgorithm ::= AlgorithmIdentifier {
       {PKCS1PSourceAlgorithms}
     }
     

where 
    
    PKCS1PSourceAlgorithms    ALGORITHM-IDENTIFIER ::= {
       { OID id-pSpecified PARAMETERS EncodingParameters },
       ...  -- Allows for future expansion --
     }
     EncodingParameters ::= OCTET STRING(SIZE(0..MAX))
     

**Since:**

1.5
