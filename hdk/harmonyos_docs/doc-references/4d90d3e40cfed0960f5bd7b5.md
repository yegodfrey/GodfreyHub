# Overview  
  
Provides predicates to set query conditions for database or non-database such as XML file in cross-device or cross-scenario data transmission. 

This package provides [DataAbilityPredicates](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilitypredicates-0000001054200074) to set the query conditions for cross-device or cross-process scenarios, such as [DataAbilityPredicates.equalTo(java.lang.String, byte)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilitypredicates-0000001054200074#ZH-CN_TOPIC_0000001054200074__equalTo-java_lang_String-byte-), [DataAbilityPredicates.greaterThan(java.lang.String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilitypredicates-0000001054200074#ZH-CN_TOPIC_0000001054200074__greaterThan-java_lang_String-int-) or [DataAbilityPredicates.lessThan(java.lang.String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilitypredicates-0000001054200074#ZH-CN_TOPIC_0000001054200074__lessThan-java_lang_String-int-). This package also provides util class including methods for converting between [DataAbilityPredicates](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilitypredicates-0000001054200074) and [RdbPredicates](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbpredicates-0000001054120074) or [OrmPredicates](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormpredicates-0000001054120070). The latter two predicates provide conditions for operations on local databases.
