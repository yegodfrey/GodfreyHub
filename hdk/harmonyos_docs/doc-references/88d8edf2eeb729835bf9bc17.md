# JavaFileObject
    
    public interface JavaFileObject
    extends [FileObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileobject-0000001123534738)  
  
---  
File abstraction for tools operating on Java™ programming language source and class files. 

All methods in this interface might throw a SecurityException if a security exception occurs. 

Unless explicitly allowed, all methods in this interface might throw a NullPointerException if given a null argument.

**Since:**

1.6

#### [h2]getNestingKind

[NestingKind](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nestingkind-0000001123534704) getNestingKind​()

Provides a hint about the nesting level of the class represented by this file object. This method may return [NestingKind.MEMBER](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nestingkind-0000001123534704#ZH-CN_TOPIC_0000001123534704__MEMBER) to mean [NestingKind.LOCAL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nestingkind-0000001123534704#ZH-CN_TOPIC_0000001123534704__LOCAL) or [NestingKind.ANONYMOUS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nestingkind-0000001123534704#ZH-CN_TOPIC_0000001123534704__ANONYMOUS). If the nesting level is not known or this file object does not represent a class file this method returns null. 

**Returns:**

the nesting kind, or null if the nesting kind is not known
