# Overview  
  
Provides methods for performing indexing and search operations provided by the fusion search service. 
    * After creating a [SearchAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchability-0000001054518838) instance and connecting to the fusion search service, you can add, delete, and update indexes. 
    * After obtaining a search session using [SearchAbility#beginSearch](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchability-0000001054518838#ZH-CN_TOPIC_0000001054518838__beginSearch-java_lang_String-java_lang_String-), you can perform search operations.
