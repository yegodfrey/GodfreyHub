# PrintWriter

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710) |---|---java.io.PrintWriter
    
    public class PrintWriter
    extends [Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710)  
  
---  
Prints formatted representations of objects to a text-output stream. This class implements all of the print methods found in [PrintStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/printstream-0000001054199708). It does not contain methods for writing raw bytes, for which a program should use unencoded byte streams. 

Unlike the [PrintStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/printstream-0000001054199708) class, if automatic flushing is enabled it will be done only when one of the println, printf, or format methods is invoked, rather than whenever a newline character happens to be output. These methods use the platform's own notion of line separator rather than the newline character. 

Methods in this class never throw I/O exceptions, although some of its constructors may. The client may inquire as to whether any errors have occurred by invoking [checkError()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/printwriter-0000001054518448#ZH-CN_TOPIC_0000001054518448__checkError--).

The locale always used is the one returned by [Locale.getDefault()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852#ZH-CN_TOPIC_0000001054119852__getDefault--), regardless of any previous invocations of other formatting methods on this object.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
format  |  A format string as described in [Format string syntax](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formatter-0000001054439879#ZH-CN_TOPIC_0000001054439879__syntax).  
args  |  Arguments referenced by the format specifiers in the format string. If there are more arguments than format specifiers, the extra arguments are ignored. The number of arguments is variable and may be zero. The maximum number of arguments is limited by the maximum dimension of a Java array as defined by 《The Java™ Virtual Machine Specification》. The behaviour on a null argument depends on the [conversion](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formatter-0000001054439879#ZH-CN_TOPIC_0000001054439879__syntax).

For specification of all possible formatting errors, see the [Details](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formatter-0000001054439879#ZH-CN_TOPIC_0000001054439879__detail) section of the Formatter class specification.

#### [h2]append

public [PrintWriter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/printwriter-0000001054518448) append​([CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442) csq)

Appends the specified character sequence to this writer. 

An invocation of this method of the form out.append(csq) behaves in exactly the same way as the invocation 
    
    out.write(csq.toString()) 

Depending on the specification of toString for the character sequence csq, the entire sequence may not be appended. For instance, invoking the toString method of a character buffer will return a subsequence whose content depends upon the buffer's position and limit.
