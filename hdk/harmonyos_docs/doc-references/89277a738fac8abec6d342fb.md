# InvalidClassException  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.io.IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |---|---|---|---[java.io.ObjectStreamException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstreamexception-0000001054439725) |---|---|---|---|---java.io.InvalidClassException
    
    public class InvalidClassException
    extends [ObjectStreamException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstreamexception-0000001054439725)  
  
---  
Thrown when the Serialization runtime detects one of the following problems with a Class. 
    * The serial version of the class does not match that of the class descriptor read from the stream 
    * The class contains unknown datatypes 
    * The class does not have an accessible no-arg constructor 

**Since:**

JDK1.1
