StandardizedEventHandle  
      
    public interface StandardizedEventHandle  
  
---  
Represents the base interface of all types of standard events. A standard event is used to indicate the user intent. Its definition is irrelevant of the input device type. To facilitate your application development using standard event APIs, the system classifies standard events into standard key events, standard touch events, standard common events (such as copy and paste), standard media events (such as playback and pause), standard system events (such as muting and printing), and standard call events (such as call answering and rejection).
