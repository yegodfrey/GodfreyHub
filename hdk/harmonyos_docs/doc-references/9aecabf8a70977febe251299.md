# ObjIntConsumer
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface ObjIntConsumer<T>  
  
---  
Represents an operation that accepts an object-valued and a int-valued argument, and returns no result. This is the (reference, int) specialization of [BiConsumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/biconsumer-0000001054838578). Unlike most other functional interfaces, ObjIntConsumer is expected to operate via side-effects. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [accept(java.lang.Object,int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objintconsumer-0000001054358609#ZH-CN_TOPIC_0000001054358609__accept-T-int-).
