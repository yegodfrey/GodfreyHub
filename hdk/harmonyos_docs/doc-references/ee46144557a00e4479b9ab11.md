# Overview  
  
Provides classes related to the DeviceKvStore database that manages data by device. 

The classes include [DeviceKvStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicekvstore-0000001054200080) database management, synchronization callback.

**Since:**

1

Interface | Description  
---|---  
[DeviceChangeCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicechangecallback-0000001054440093) | Represents the callback for device status changes.  
[DeviceKvStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicekvstore-0000001054200080) | Manages distributed data by device in a distributed system.
