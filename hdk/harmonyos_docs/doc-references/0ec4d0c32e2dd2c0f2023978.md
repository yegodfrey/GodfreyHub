# Function
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface Function<T,R>  
  
---  
Represents a function that accepts one argument and produces a result. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [apply(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955#ZH-CN_TOPIC_0000001054119955__apply-T-).

**Since:**

1.8
