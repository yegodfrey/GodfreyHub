Provides component conversion tool. 

You can use the tool to define a component in an XML file, and then call the [parse(int, ohos.agp.components.ComponentContainer, boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/layoutscatter-0000001054199990#ZH-CN_TOPIC_0000001054199990__parse-int-ohos_agp_components_ComponentContainer-boolean-) method to generate a [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) object using this file.
