# IntUnaryOperator
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface IntUnaryOperator  
  
---  
Represents an operation on a single int-valued operand that produces an int-valued result. This is the primitive type specialization of [UnaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unaryoperator-0000001054518644) for int. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsInt(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intunaryoperator-0000001054238627#ZH-CN_TOPIC_0000001054238627__applyAsInt-int-).

**Since:**

1.8

[UnaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unaryoperator-0000001054518644)
