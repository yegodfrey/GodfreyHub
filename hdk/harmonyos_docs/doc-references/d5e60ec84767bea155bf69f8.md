# Overview  
  
Provides a framework for deferring works that do not need to be processed immediately. 

This framework allows you to specify trigger conditions for the works set using [WorkInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workinfo-0000001054239015) and [WorkScheduler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workscheduler-0000001054838970). When these conditions are met, the framework attempts to batch process the works without increasing power consumption or affecting system performance. For details, see [WorkInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workinfo-0000001054239015) and [WorkScheduler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workscheduler-0000001054838970).
