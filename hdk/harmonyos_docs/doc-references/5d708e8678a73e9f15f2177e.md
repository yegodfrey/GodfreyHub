Defines system pasteboard operations, including copying, pasting, and setting listeners for pasteboard content changes. This class facilitates short-term data exchange between user applications. For example, an application program uses this interface to paste copied data to the system pasteboard, and another program obtains the pasted data from the pasteboard.  In the distributed pasteboard scenario, the pasted data can be written across devices. For example, an application program on device A uses this interface to store data copied form device A to the system pasteboard of device B. An application program on device B can read and paste the copied data in the system pasteboard if the data is allowed to share between devices.  Note that the following conditions must be met for cross-device data writing: 
    * The writing and reading device must meet the networking requirements. For details, see the ohos Developer Guide.
    * The distributed pasteboard function is enabled on both the writing and reading devices in the network. Currently, only plain text and HTML text are supported, and the maximum size is 64 KB.
