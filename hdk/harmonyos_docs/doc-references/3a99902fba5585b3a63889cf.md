# MorphingSystem  
      
    public interface MorphingSystem  
  
---  
Controls the morphing targets of [MorphComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/morphcomponent-0000001054120069). 

This interface is used to set and obtain the name list and weight list of morphing targets.
