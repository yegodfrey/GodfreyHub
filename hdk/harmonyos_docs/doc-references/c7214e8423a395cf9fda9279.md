# KvStore
    
    public interface KvStore  
  
---  
Represents a key-value distributed database and provides methods for adding, deleting, modifying, querying, and subscribing to distributed data. 

You can create distributed databases of different types by [KvManager#getKvStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvmanager-0000001054238801#ZH-CN_TOPIC_0000001054238801__getKvStore-ohos_data_distributed_common_Options-java_lang_String-) with input parameter Options. Distributed database types are defined in KvStoreType, including SingleKvStore, and DeviceKvStore.
