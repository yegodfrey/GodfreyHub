An abstract class that implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001) to ensure that the states of all child classes of the [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) are saved in method chaining mode. All component states must inherit this class.
