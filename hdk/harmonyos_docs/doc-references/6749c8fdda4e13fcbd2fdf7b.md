Provides methods of starting, stopping, canceling, and updating a work and implementing the service logic for the Particle Ability. You must implement [onWorkStart(ohos.workscheduler.WorkInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workscheduler-0000001054838970#ZH-CN_TOPIC_0000001054838970__onWorkStart-ohos_workscheduler_WorkInfo-) and [onWorkStop(ohos.workscheduler.WorkInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workscheduler-0000001054838970#ZH-CN_TOPIC_0000001054838970__onWorkStop-ohos_workscheduler_WorkInfo-) for each work. This ensures that the service logic can be successfully implemented if the triggering condition is met after a work is started by WorkSchedulerService. Once WorkInfo is defined, you can manage the work status using methods such as [stopWork(ohos.workscheduler.WorkInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workscheduler-0000001054838970#ZH-CN_TOPIC_0000001054838970__stopWork-ohos_workscheduler_WorkInfo-) and [stopAndCancelWork(ohos.workscheduler.WorkInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/workscheduler-0000001054838970#ZH-CN_TOPIC_0000001054838970__stopAndCancelWork-ohos_workscheduler_WorkInfo-). **Since:** 3Nested Class Summary Nested classes/interfaces inherited from class ohos.aafwk.ability.[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007)
