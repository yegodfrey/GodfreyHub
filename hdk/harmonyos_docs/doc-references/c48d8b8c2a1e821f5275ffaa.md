A processor that checks an XML document against [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001060519193). A validator object is not thread-safe and not reentrant. In other words, it is the application's responsibility to make sure that one [Validator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validator-0000001060388832) object is not used from more than one thread at any given time, and while the validate method is invoked, applications may not recursively call the validate method.  **Since:** 1.5Constructor Summary Modifier | Constructor | Description
