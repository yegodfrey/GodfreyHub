# InflaterInputStream

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.InputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420) |---|---[java.io.FilterInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filterinputstream-0000001054558433) |---|---|---java.util.zip.InflaterInputStream
    
    public class InflaterInputStream
    extends [FilterInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filterinputstream-0000001054558433)  
  
---  
This class implements a stream filter for uncompressing data in the "deflate" compression format. It is also used as the basis for other decompression filters, such as GZIPInputStream.

**See Also:**

[Inflater](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inflater-0000001054119904)
