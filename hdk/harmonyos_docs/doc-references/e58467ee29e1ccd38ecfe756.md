# Overview  
  
Provides time line curves for controlling the animation progress, such as Cubic Bézier curves.

**Since:**

5

[CubicBezierCurve](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cubicbeziercurve-0000001138987471) | Represents a cubic Bezier curve, which is a type of timeline curve.
