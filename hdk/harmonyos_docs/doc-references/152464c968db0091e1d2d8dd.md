AccessibilityStateObserver
    
    public interface AccessibilityStateObserver  
  
---  
Observes the accessibility status. This interface is called to register an observer for listening to accessibility status changes. When the accessibility status has changed, a callback is triggered to send the status change event specified by [AccessibilityStateEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitystateevent-0000001054838646). **Since:** 1**See Also:** [AccessibilitySystemAbilityClient.subscribeStateObserver(AccessibilityStateObserver, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitysystemabilityclient-0000001054358680#ZH-CN_TOPIC_0000001054358680__subscribeStateObserver-ohos_accessibility_AccessibilityStateObserver-int-), [AccessibilityStateEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitystateevent-0000001054838646)Method Summary Modifier and Type | Method | Description
