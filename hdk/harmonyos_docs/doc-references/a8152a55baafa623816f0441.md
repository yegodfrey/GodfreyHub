# Overview  
  
Provides 3D capabilities and features. 

This package contains 3D elements such as the 3D scene, component, entity, engine, and rendering. 

Note: To use this package, ensure that the hardware device supports OpenGL ES or Vulkan. If OpenGL ES is used, the device must support APIs of the version 3.2 or later. If Vulkan is used, the device must support APIs of the version 1.0 or later.

**Since:**

3
