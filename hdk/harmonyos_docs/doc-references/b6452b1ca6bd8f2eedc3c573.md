# IDownloadListener
    
    public interface IDownloadListener  
  
---  
Provides callbacks to listen for download session status. 

Application programs can implement this interface and register listeners with the system by calling [DownloadSession#addListener(IDownloadListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/downloadsession-0000001054358929#ZH-CN_TOPIC_0000001054358929__addListener-ohos_miscservices_download_IDownloadListener-). 

An application program can use the callbacks to listen to a download session for state changes. To remove the listeners, call [DownloadSession#removeListener(IDownloadListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/downloadsession-0000001054358929#ZH-CN_TOPIC_0000001054358929__removeListener-ohos_miscservices_download_IDownloadListener-).
