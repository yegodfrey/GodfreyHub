Provides a client for interacting with the accessibility ability.  The client provides functions such as sending accessibility events specified by [AccessibilityEventInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityeventinfo-0000001054678661) to the accessibility ability, querying the accessibility status, and sending accessibility status change notifications.  For example, when a view control gains the focus, this class will send an [AccessibilityEventInfo#TYPE_VIEW_FOCUSED_EVENT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityeventinfo-0000001054678661#ZH-CN_TOPIC_0000001054678661__TYPE_VIEW_FOCUSED_EVENT) event to notify the accessibility ability. **Since:** 1**See Also:** [AccessibilityEventInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityeventinfo-0000001054678661), [AccessibilityStateObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitystateobserver-0000001054358671), [AccessibilityAbilityInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityabilityinfo-0000001054238691)Field Summary Modifier and Type | Field | Description
