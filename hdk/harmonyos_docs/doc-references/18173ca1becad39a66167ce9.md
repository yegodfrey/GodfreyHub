LoadingProgress 用于显示加载动效的组件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172421.02619184443126685251916571675864:50001231000000:2800:FE790F6BD93E79078C1F15AD62145BEA05D2D6CA4DC3EFF77CB0962427773228.png?needInitFileName=true?needInitFileName=true?needInitFileName=true) 该组件从API Version 8开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。 子组件无 接口LoadingProgress() 创建加载进展组件。 属性 名称 | 参数类型 | 描述  
---|---|---  
color | [ResourceColor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-types-0000001281480778#ZH-CN_TOPIC_0000001281480778__resourcecolor8) | 设置加载进度条前景色。  
示例
    
    // xxx.ets
    @Entry
    @Component
    struct LoadingProgressExample {
      build() {
        Column({ space: 5 }) {
          Text('Orbital LoadingProgress ').fontSize(9).fontColor(0xCCCCCC).width('90%')
          LoadingProgress()
            .color(Color.Blue)
        }.width('100%').margin({ top: 5 })
      }
    }
