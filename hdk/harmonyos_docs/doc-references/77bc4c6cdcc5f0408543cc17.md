# Overview  
  
Provides classes for managing bundle usage information and state data. 

You can use the classes provided in this package to query bundle usage information, state data, and attributes of the usage and state data.

**Since:**

4

#### Class Summary

Class | Description  
---|---  
[BundleActiveInfos](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleactiveinfos-0000001060996882) | Provides methods for querying attributes of bundle usage information.  
[BundleActiveInfosMgr](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleactiveinfosmgr-0000001060519080) | Provides methods for managing bundle usage statistics, including the methods for querying bundle usage information and state data.  
[BundleActiveStates](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleactivestates-0000001060268777) | Provides methods for querying data that contains a single or multiple bundle states.  
[BundleActiveStates.State](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleactivestates_state-0000001060679072) | Provides methods for querying attributes of bundle state data.
