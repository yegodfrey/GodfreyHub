# Overview  
  
Provides classes and interfaces for parsing and managing certificates, certificate revocation lists (CRLs), and certification paths. It contains support for X.509 v3 certificates and X.509 v2 CRLs. **Package Specification**
    * [**Java™ Cryptography Architecture (JCA) Reference Guide**](https://docs.oracle.com/javase/8/docs/technotes/guides/security/crypto/CryptoSpec.html)
    * RFC 5280: Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile 
    * RFC 2560: X.509 Internet Public Key Infrastructure Online Certificate Status Protocol - OCSP 
    * [**Java™ Cryptography Architecture Standard Algorithm Name Documentation**](https://docs.oracle.com/javase/8/docs/technotes/guides/security/StandardNames.html)
**Related Documentation** For information about X.509 certificates and CRLs, please see: 
    * [ http://www.ietf.org/rfc/rfc5280.txt](http://www.ietf.org/rfc/rfc5280.txt)
    * [**Java™ PKI Programmer's Guide**](https://docs.oracle.com/javase/8/docs/technotes/guides/security/certpath/CertPathProgGuide.html)
    * [**X.509 Certificates and Certificate Revocation Lists (CRLs)**](https://docs.oracle.com/javase/8/docs/technotes/guides/security/cert3.html)

**Since:**

1.2
