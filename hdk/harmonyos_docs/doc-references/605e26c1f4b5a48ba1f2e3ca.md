边框设置 设置组件边框样式。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172413.54029345466266339514562186655536:50001231000000:2800:E3DFBE49BB2AC90FA17A9C25F571679B0C1FF21E6CFD27FC4FE10B28110E7A1C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true) 从API Version 7开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。 属性 名称 | 参数类型 | 描述  
---|---|---  
border | { width?: [Length](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-types-0000001281480778#ZH-CN_TOPIC_0000001281480778__length), color?: [ResourceColor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-types-0000001281480778#ZH-CN_TOPIC_0000001281480778__resourcecolor), radius?: [Length](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-types-0000001281480778#ZH-CN_TOPIC_0000001281480778__length), style?: [BorderStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-appendix-enums-0000001281201130#ZH-CN_TOPIC_0000001281201130__borderstyle) } | 统一边框样式设置接口。  
borderStyle | [BorderStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-appendix-enums-0000001281201130#ZH-CN_TOPIC_0000001281201130__borderstyle) | 设置元素的边框样式。 默认值：BorderStyle.Solid  
borderWidth | [Length](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-types-0000001281480778#ZH-CN_TOPIC_0000001281480778__length) | 设置元素的边框宽度。  
borderColor | [ResourceColor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-types-0000001281480778#ZH-CN_TOPIC_0000001281480778__resourcecolor) | 设置元素的边框颜色。  
borderRadius | [Length](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-types-0000001281480778#ZH-CN_TOPIC_0000001281480778__length) | 设置元素的边框圆角半径。  
示例
    
    // xxx.ets
    @Entry
    @Component
    struct BorderExample {
      build() {
        Flex({ justifyContent: FlexAlign.SpaceAround, alignItems: ItemAlign.Center }) {
          // 线段
          Text('dashed')
            .borderStyle(BorderStyle.Dashed).borderWidth(5).borderColor(0xAFEEEE).borderRadius(10)
            .width(120).height(120).textAlign(TextAlign.Center).fontSize(16)
          // 点线
          Text('dotted')
            .border({ width: 5, color: 0x317AF7, radius: 10, style: BorderStyle.Dotted })
            .width(120).height(120).textAlign(TextAlign.Center).fontSize(16)
        }.width('100%').height(150)
      }
    }
