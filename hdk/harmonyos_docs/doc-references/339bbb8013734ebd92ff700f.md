# BinaryOperator
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface BinaryOperator<T>
    extends [BiFunction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bifunction-0000001054358612)<T,T,T>  
  
---  
Represents an operation upon two operands of the same type, producing a result of the same type as the operands. This is a specialization of [BiFunction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bifunction-0000001054358612) for the case where the operands and the result are all of the same type. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [BiFunction.apply(java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bifunction-0000001054358612#ZH-CN_TOPIC_0000001054358612__apply-T-U-).
