# RadioInfoManager

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.telephony.RadioInfoManager
    
    public class RadioInfoManager
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides interfaces for applications to obtain the network state, cell information, signal information, and device ID of the wireless cellular network (WCN), and provides a callback registration mechanism to listen for changes of the network, cell, and signal status of the WCN. 

This class is a singleton class. Applications can use the getInstance method to obtain an instance and then use the instance to invoke the method for obtaining WCN information and registering a listener.

#### [h2]getSignalInfoList

public [List](https://developer.harmonyos.com/cn/docs/documentation/doc-references/list-0000001054119842)<[SignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/signalinformation-0000001054838950)> getSignalInfoList​(int slotId)

Obtains the list of signal strength information of the registered network corresponding to a specified SIM card. 

If the specified SIM card camps on one or more networks, the signal strength of these networks is reported, as listed below: 

    * [GsmSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gsmsignalinformation-0000001054440281)
    * [CdmaSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cdmasignalinformation-0000001054358982)
    * [TdscdmaSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tdscdmasignalinformation-0000001054120325)
    * [LteSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ltesignalinformation-0000001054200268)
    * [WcdmaSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wcdmasignalinformation-0000001054200270)
    * [NrSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nrsignalinformation-0000001054678996)
For example, if the device camps on both the CDMA and LTE networks, [CdmaSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cdmasignalinformation-0000001054358982) and [LteSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ltesignalinformation-0000001054200268) instances are returned. If an empty list is returned, there is no signal. 

A device can use [SignalInformation#getNetworkType()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/signalinformation-0000001054838950#ZH-CN_TOPIC_0000001054838950__getNetworkType--) to obtain RAT of the signal instance and then use the corresponding child class to obtain detailed signal information.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
slotId  |  Indicates the card slot index number, ranging from 0 to the maximum card slot index number supported by the device.  
  
**Returns:**

Returns the instance list of the child classes derived from [SignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/signalinformation-0000001054838950).

**Since:**

1

Checks whether the device is registered with a 5G non-standalone (NSA) network. 

Requires Permission: ohos.permission.GET_NETWORK_INFO.

**Returns:**

Returns true if the device is registered with a 5G NSA network; returns false otherwise.

#### [h2]addObserver

public void addObserver​([RadioStateObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radiostateobserver-0000001054558997) observer, int mask)

Registers an observer to receive notifications of changes in a specified radio state. 

To register an observer, pass a [RadioStateObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radiostateobserver-0000001054558997) and an observer mask of the concerned state. When the specified state changes, the callback method in [RadioStateObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radiostateobserver-0000001054558997) is invoked. It is also invoked upon the first registration of the observer. 

NOTE: The slot ID that you want to observe is declared in [RadioStateObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radiostateobserver-0000001054558997). 

Requires Permission: OBSERVE_MASK_SERVICE_STATE needs ohos.permission.GET_NETWORK_INFO and OBSERVE_MASK_CELL_INFO needs ohos.permission.LOCATION.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
observer  |  Indicates the RadioStateObserver to register.  
mask  |  Indicates the mask of the concerned state, as specified in [RadioStateObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/radiostateobserver-0000001054558997).  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) |  Throws this exception if the caller does not have the permission.  
  
**Since:**

1
