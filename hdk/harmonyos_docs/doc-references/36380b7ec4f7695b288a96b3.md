# Overview  
  
Provides classes for managing data of the same account. 

Provides methods for you to manage the [SingleKvStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/singlekvstore-0000001054558811) defined in [KvStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstore-0000001054678771). You can use these methods to implement basic distributed data capabilities.
