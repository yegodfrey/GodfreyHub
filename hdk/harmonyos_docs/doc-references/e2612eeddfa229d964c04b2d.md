# PreferenceChangeEvent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.EventObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventobject-0000001054119921) |---|---java.util.prefs.PreferenceChangeEvent
    
    public class PreferenceChangeEvent
    extends [EventObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventobject-0000001054119921)  
  
---  
An event emitted by a Preferences node to indicate that a preference has been added, removed or has had its value changed.

Note, that although PreferenceChangeEvent inherits Serializable interface from EventObject, it is not intended to be Serializable. Appropriate serialization methods are implemented to throw NotSerializableException.

1.4
