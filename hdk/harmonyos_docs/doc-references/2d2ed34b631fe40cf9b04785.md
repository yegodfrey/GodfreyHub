# Overview  
  
Provides library support for the Java programming language annotation facility.

**Since:**

1.5

#### Interface Summary

Interface | Description  
---|---  
[Annotation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotation-0000001054358439) | The common interface extended by all annotation types.  
  
#### Enum Summary

Enum | Description  
---|---  
[ElementType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementtype-0000001054238459) | The constants of this enumerated type provide a simple classification of the syntactic locations where annotations may appear in a Java program.  
[RetentionPolicy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retentionpolicy-0000001054678429) | Annotation retention policy.  
  
#### Exception Summary

Exception | Description  
---|---  
[AnnotationTypeMismatchException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotationtypemismatchexception-0000001054358448) | Thrown to indicate that a program has attempted to access an element of an annotation whose type has changed after the annotation was compiled (or serialized).  
[IncompleteAnnotationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/incompleteannotationexception-0000001054119789) | Thrown to indicate that a program has attempted to access an element of an annotation type that was added to the annotation type definition after the annotation was compiled (or serialized).  
  
#### Error Summary

Error | Description  
---|---  
[AnnotationFormatError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotationformaterror-0000001054439747) | Thrown when the annotation parser attempts to read an annotation from a class file and determines that the annotation is malformed.  
  
#### Annotation Types Summary

Annotation Type | Description  
---|---  
[Documented](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documented-0000001054518474) | Indicates that annotations with a type are to be documented by javadoc and similar tools by default.  
[Inherited](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inherited-0000001054678462) | Indicates that an annotation type is automatically inherited.  
[Native](https://developer.harmonyos.com/cn/docs/documentation/doc-references/native-0000001054358441) | Indicates that a field defining a constant value may be referenced from native code.  
[Repeatable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/repeatable-0000001054558463) | The annotation type java.lang.annotation.Repeatable is used to indicate that the annotation type whose declaration it (meta-)annotates is repeatable.  
[Retention](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retention-0000001054238461) | Indicates how long annotations with the annotated type are to be retained.  
[Target](https://developer.harmonyos.com/cn/docs/documentation/doc-references/target-0000001054678431) | Indicates the contexts in which an annotation type is applicable.
