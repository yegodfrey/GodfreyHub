# Overview  
  
#### Interface Summary

Interface | Description  
---|---  
[ItemAnimation.ItemAnimationFinishedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemanimation_itemanimationfinishedlistener-0000001217877947) | Implements the listening for the completion of all component animations.

Class | Description  
---|---

[ItemTouchExpandCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemtouchexpandcallback-0000001172716644) | Functions as a bridge between users and the [ItemTouchExpand](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemtouchexpand-0000001217996523) object.  
[ItemTouchExpandCallback.ItemTouchExpandCallbackCleaner](https://developer.harmonyos.com/cn/docs/documentation/doc-references/touchexpandcallback_itemtouchexpandcallbackcleaner-0000001172398148) | Implements the release of the [ItemTouchExpandCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemtouchexpandcallback-0000001172716644) object.
