# OrmMigration

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.data.orm.OrmMigration
    
    public abstract class OrmMigration
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Upgrades and downgrades databases. 

If you need to modify the database structure, for example, add a table or field, you need to create a database class, specify the new database version, and then prepare an SQL statement for upgrading or downgrading between the start and end versions specified by [OrmMigration(int, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormmigration-0000001054358800#ZH-CN_TOPIC_0000001054358800__OrmMigration-int-int-). The ORM annotation processor will identify the start and end version, and execute the specified SQL statement to complete the upgrade or downgrade.
