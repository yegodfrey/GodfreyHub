# Predicate

#### [h2]and

default [Predicate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/predicate-0000001054238629)<[T](https://developer.harmonyos.com/cn/docs/documentation/doc-references/predicate-0000001054238629)> and​([Predicate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/predicate-0000001054238629)<? super [T](https://developer.harmonyos.com/cn/docs/documentation/doc-references/predicate-0000001054238629)> other)

Returns a composed predicate that represents a short-circuiting logical AND of this predicate and another. When evaluating the composed predicate, if this predicate is false, then the other predicate is not evaluated. 

Any exceptions thrown during evaluation of either predicate are relayed to the caller; if evaluation of this predicate throws an exception, the other predicate will not be evaluated.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
other  |  a predicate that will be logically-ANDed with this predicate  
  
**Returns:**
