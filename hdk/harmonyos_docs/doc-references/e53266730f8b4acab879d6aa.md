# InputMethodAbility

Input method ability used to develop an input method application. 

You should extend this class to implement the input method ability. Processes such as enabling and hiding the input method are encapsulated in this class. This allows you to complete the development only by implementing specific APIs, without extra efforts on internal processes. 

InputMethodAbility inherits from the Ability class. The lifecycle (such as startup and connection) of the input method ability is the same as that of a generic ability. In addition, lifecycle callbacks related to the input method service are supported, for example, callbacks for creating the keyboard component container ([onCreateKeyboardContainer()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputmethodability-0000001060388838#ZH-CN_TOPIC_0000001060388838__onCreateKeyboardContainer--)) and for displaying the keyboard window ([onShowKeyboard()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputmethodability-0000001060388838#ZH-CN_TOPIC_0000001060388838__onShowKeyboard--)). As an ability, an InputMethodAbility object only can be connected to specific system services supported by the framework. 

Applications developed based on the input method ability is able to adjust the input method window size (via [KeyboardController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyboardcontroller-0000001060039153)), and perform many operations such as text input and deletion in the client application (via [TextInputClient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textinputclient-0000001060837294)).
