# Overview  
  
Provides common methods and attributes of dialog boxes. 

Methods and attributes in this package can be further extended as needed.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[BaseDialog.DialogListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basedialog_dialoglistener-0000001054120014) | Represents the listener for events of a dialog box.  
[BaseDialog.DisplayCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basedialog_displaycallback-0000001060679070) | Represents the callback that is invoked when a dialog box is displayed.  
[BaseDialog.RemoveCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basedialog_removecallback-0000001060157235) | Represents the callback that is invoked when a dialog box is removed.  
[CommonDialog.DestroyedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commondialog_destroyedlistener-0000001054440043) | Interface that listens for dialog destruction events.  
[IDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idialog-0000001054200030) | A universal interface for [BaseDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basedialog-0000001054238757).  
[IDialog.CheckBoxClickedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idialog_checkboxclickedlistener-0000001054518770) | Listens for click events related to the check box in a component.  
[IDialog.ClickedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idialog_clickedlistener-0000001054678758) | Listens for click events of buttons in a dialog box.  
[IDialog.ItemClickedListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idialog_itemclickedlistener-0000001054358737) | Provides the click event listener for list items.  
[IDialog.KeyboardCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idialog_keyboardcallback-0000001060519183) | Listens for Keyboard.  
  
#### Class Summary

Class | Description  
---|---  
[BaseDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basedialog-0000001054238757) | Implements class of the IDialog  
[CommonDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commondialog-0000001054678727) | Creates a common dialog box.  
[DisplayDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/displaydialog-0000001054838712) | Displays the content of a dialog box on that of a remote screen.  
[DisplayDialog.DialogProvider](https://developer.harmonyos.com/cn/docs/documentation/doc-references/displaydialog_dialogprovider-0000001054358746) | Encapsulates the information about a remote screen, including its height, width, IP address, port, and density in DPI.  
[ListDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listdialog-0000001054120087) | Creates a ListDialog instance.  
[PopupDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/popupdialog-0000001054120016) | Creates popup dialogs that are used with specific components.  
[ToastDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/toastdialog-0000001054440045) | Provides a toast dialog box above a window to notify simple feedback for an operation.
