# BootstrapMethodError

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Error](https://developer.harmonyos.com/cn/docs/documentation/doc-references/error-0000001054199728) |---|---|---[java.lang.LinkageError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkageerror-0000001054678425) |---|---|---|---java.lang.BootstrapMethodError
    
    public class BootstrapMethodError
    extends [LinkageError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkageerror-0000001054678425)  
  
---  
Thrown to indicate that an invokedynamic instruction has failed to find its bootstrap method, or the bootstrap method has failed to provide a [call site](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callsite-0000001054199736) with a [target](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callsite-0000001054199736#ZH-CN_TOPIC_0000001054199736__getTarget--) of the correct [method type](https://developer.harmonyos.com/cn/docs/documentation/doc-references/methodhandle-0000001054678464#ZH-CN_TOPIC_0000001054678464__type--).

**Since:**

1.7
