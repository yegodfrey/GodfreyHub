# PropertyKey  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.media.camera.params.PropertyKey
    
    public final class PropertyKey

Defines camera property keys. 

Property keys, for example, [PropertyKey#SENSOR_ORIENTATION](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertykey-0000001054678887#ZH-CN_TOPIC_0000001054678887__SENSOR_ORIENTATION), are used to describe the camera's inherent information. They are not for controlling the camera.

#### [h2]PARTIAL_RESULT_COUNT

public static final [PropertyKey.Key](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertykey_key-0000001054838872)<[Integer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/integer-0000001054119702)> PARTIAL_RESULT_COUNT

Indicates the number of times a frame capture result is returned. The camera can return all results at a time. In this case, this number is 1. The camera can also return the results multiple times, and each time a part is returned. This number describes how many times it takes to return all the results. 

**Since:**

1

#### [h2]SENSOR_ORIENTATION

public static final [PropertyKey.Key](https://developer.harmonyos.com/cn/docs/documentation/doc-references/propertykey_key-0000001054838872)<[Integer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/integer-0000001054119702)> SENSOR_ORIENTATION

The orientation of the sensor relative to the device. 

Indicates the clockwise degrees that the output image needs to be rotated to be upright in the system coordinate.

The orientation value should be 0, 90, 180 or 270.

1
