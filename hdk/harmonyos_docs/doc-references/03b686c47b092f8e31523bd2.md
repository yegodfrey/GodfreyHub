BiConsumer  
      
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface BiConsumer<T,U>  
  
---  
Represents an operation that accepts two input arguments and returns no result. This is the two-arity specialization of [Consumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/consumer-0000001054199898). Unlike most other functional interfaces, BiConsumer is expected to operate via side-effects. This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [accept(java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/biconsumer-0000001054838578#ZH-CN_TOPIC_0000001054838578__accept-T-U-). **Since:** 1.8**See Also:** [Consumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/consumer-0000001054199898)Method Summary Modifier and Type | Method | Description
