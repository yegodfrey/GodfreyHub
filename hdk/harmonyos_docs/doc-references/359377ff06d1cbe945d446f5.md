# NotificationUserInput

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationUserInput

Defines the user input, which will be passed together with an intent in a sent IntentAgent. You should always use [NotificationUserInput.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationuserinput_builder-0000001054238843) to create instances of this class. You can call [NotificationActionButton.Builder#addNotificationUserInput(NotificationUserInput)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationactionbutton_builder-0000001054120098#ZH-CN_TOPIC_0000001054120098__addNotificationUserInput-ohos_event_notification_NotificationUserInput-) to add a NotificationUserInput object to a NotificationActionButton.
