#### [h2]canGo

boolean canGo​(int steps)

Checks whether the current page can go forward or backward by a specified number of steps. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
steps  |  Indicates the number of steps . A negative value indicates going backward, and a positive value indicates going forward.  
  
**Returns:**

Returns true if the current page can go forward or backward by a specified number of steps; returns false otherwise.

**Since:**

7
