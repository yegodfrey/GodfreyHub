# CommonEventPublishInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.commonevent.CommonEventPublishInfo
    
    public final class CommonEventPublishInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Provides information for publishing common events, including setting subscriber filter criteria, common event type and mode. 

If you call the [CommonEventManager#publishCommonEvent(CommonEventData, CommonEventPublishInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventmanager-0000001054238835#ZH-CN_TOPIC_0000001054238835__publishCommonEvent-ohos_event_commonevent_CommonEventData-ohos_event_commonevent_CommonEventPublishInfo-) or [CommonEventManager#publishCommonEvent(CommonEventData, CommonEventPublishInfo, CommonEventSubscriber)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventmanager-0000001054238835#ZH-CN_TOPIC_0000001054238835__publishCommonEvent-ohos_event_commonevent_CommonEventData-ohos_event_commonevent_CommonEventPublishInfo-ohos_event_commonevent_CommonEventSubscriber-) method to publish a common event, you can publish the common event only to related subscribers by setting the filter criteria, including the user ID and permissions. 

If you call the [setOrdered(boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventpublishinfo-0000001054678805#ZH-CN_TOPIC_0000001054678805__setOrdered-boolean-) method with a value of true, an ordered common event will be published. If you call the [setSticky(boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventpublishinfo-0000001054678805#ZH-CN_TOPIC_0000001054678805__setSticky-boolean-) method with a value of true, a sticky common event will be published. If you call either of the two methods with a value of false, a standard common event will be published by default. You can allow only specified subscribers to receive a common event by calling the [setSubscriberPermissions(java.lang.String[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventpublishinfo-0000001054678805#ZH-CN_TOPIC_0000001054678805__setSubscriberPermissions-java_lang_String:A-) method.

#### [h2]setOrdered

public void setOrdered​(boolean ordered)

Sets whether the type of a common event is ordered or not. 

An ordered common event is received by subscribers in descending priority. Specifically, a highest-priority subscriber receives the event, then high-priority subscribers, and finally low-priority subscribers. priority limit -1000~1000 and the highest priority is 1000.
