# DeviceManager

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.distributedhardware.devicemanager.DeviceManager
    
    public class DeviceManager
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides methods for managing devices, including the methods for querying information about local and trusted devices, subscribing to device online and offline notifications, and obtaining devices selected by users. 

You can call [getLocalDeviceInfo()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__getLocalDeviceInfo--) to query basic information about a local device. 

After trusted devices have been networked, [getTrustedDeviceList(java.lang.String,java.util.Map)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__getTrustedDeviceList-java_lang_String-java_util_Map-) can be called to obtain the trusted device list. 

You can call [registerDeviceStateCallback(java.lang.String,java.util.Map,ohos.distributedhardware.devicemanager.DeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__registerDeviceStateCallback-java_lang_String-java_util_Map-ohos_distributedhardware_devicemanager_DeviceStateCallback-) to register device state callbacks to listen for state changes of a device. When a trusted device goes online or offline, the particular callback defined in [DeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333) will be called to notify your application of the online or offline device information. 

If your application no longer needs to be notified of device state changes, you can call [unregisterDeviceStateCallback(java.lang.String,ohos.distributedhardware.devicemanager.DeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__unregisterDeviceStateCallback-java_lang_String-ohos_distributedhardware_devicemanager_DeviceStateCallback-) to unregister all previously registered callbacks to stop listening for state changes of a trusted device. 

After [selectDeviceList(java.lang.String,java.util.Map,ohos.distributedhardware.devicemanager.SelectDeviceListListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__selectDeviceList-java_lang_String-java_util_Map-ohos_distributedhardware_devicemanager_SelectDeviceListListener-) is called, the list of available devices will be displayed on the screen for the user to select. After the user chooses a desired device, [SelectDeviceListListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/selectdevicelistlistener-0000001091930948) will be triggered to notify your application of the information and state of the selected device.

#### [h2]SORT_TYPE

public static final [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) SORT_TYPE

Indicates the field name for the sorting type. 

If this field is not specified during device query, the devices are not sorted by default. In this case, [SIFT_FILTER](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__SIFT_FILTER) must be specified. 

    * The following sorting types are supported: 
    * **0** : Most recently used (MRU)
    * **1** : Most frequently used (MFU)
    * **2** : AI mode. Currently, it is implemented by the combination of MRU and MFU. (The top 1 device is sorted using MRU, and top 2 to top N are sorted using MFU based on the number of times that a device is selected.)

#### [h2]TARGET_PACKAGE_NAME

public static final [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) TARGET_PACKAGE_NAME

Indicates the field name for the target application bundle name. 

If this field is specified during trusted device query, application-level trusted devices are filtered to ensure that the specified application is in the group of application-level trusted devices and a list containing both device- and application-level trusted devices will be returned. If this field is not specified, only a list of device-level trusted devices will be provided. Device-level trusted devices include devices with the same account or those with different accounts but in the public group.
