# DelayQueue

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.AbstractCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractcollection-0000001054358576)<E> |---|---[java.util.AbstractQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602)<E> |---|---|---java.util.concurrent.DelayQueue<E>
    
    public class DelayQueue<E extends [Delayed](https://developer.harmonyos.com/cn/docs/documentation/doc-references/delayed-0000001054678608)>
    extends [AbstractQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602)<E>
    implements [BlockingQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/blockingqueue-0000001054838560)<E>  
  
---  
An unbounded [BlockingQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/blockingqueue-0000001054838560) of Delayed elements, in which an element can only be taken when its delay has expired. The head of the queue is that Delayed element whose delay expired furthest in the past. If no delay has expired there is no head and poll will return null. Expiration occurs when an element's getDelay(TimeUnit.NANOSECONDS) method returns a value less than or equal to zero. Even though unexpired elements cannot be removed using take or poll, they are otherwise treated as normal elements. For example, the size method returns the count of both expired and unexpired elements. This queue does not permit null elements. 

This class and its iterator implement all of the optional methods of the [Collection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563) and [Iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913) interfaces. The Iterator provided in method [iterator()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/delayqueue-0000001054678581#ZH-CN_TOPIC_0000001054678581__iterator--) is not guaranteed to traverse the elements of the DelayQueue in any particular order. 

This class is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).

#### [h2]toArray

public <T> T[] toArray​(T[] a)

Returns an array containing all of the elements in this queue; the runtime type of the returned array is that of the specified array. The returned array elements are in no particular order. If the queue fits in the specified array, it is returned therein. Otherwise, a new array is allocated with the runtime type of the specified array and the size of this queue. 

If this queue fits in the specified array with room to spare (i.e., the array has more elements than this queue), the element in the array immediately following the end of the queue is set to null. 

Like the [toArray()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/delayqueue-0000001054678581#ZH-CN_TOPIC_0000001054678581__toArray--) method, this method acts as bridge between array-based and collection-based APIs. Further, this method allows precise control over the runtime type of the output array, and may, under certain circumstances, be used to save allocation costs. 

The following code can be used to dump a delay queue into a newly allocated array of Delayed: 
    
    Delayed[] a = q.toArray(new Delayed[0]);

Note that toArray(new Object[0]) is identical in function to toArray().
