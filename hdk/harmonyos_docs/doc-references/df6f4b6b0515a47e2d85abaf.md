#### [h2]COMPOSE

public static final [Normalizer2.Mode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/normalizer2_mode-0000001054358851) COMPOSE

Decomposition followed by composition. Same as standard NFC when using an "nfc" instance. Same as standard NFKC when using an "nfkc" instance. For details about standard Unicode normalization forms see http://www.unicode.org/unicode/reports/tr15/ 

#### [h2]DECOMPOSE

public static final [Normalizer2.Mode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/normalizer2_mode-0000001054358851) DECOMPOSE

Map, and reorder canonically. Same as standard NFD when using an "nfc" instance. Same as standard NFKD when using an "nfkc" instance. For details about standard Unicode normalization forms see http://www.unicode.org/unicode/reports/tr15/ 

#### [h2]FCD

public static final [Normalizer2.Mode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/normalizer2_mode-0000001054358851) FCD

"Fast C or D" form. If a string is in this form, then further decomposition _without reordering_ would yield the same form as DECOMPOSE. Text in "Fast C or D" form can be processed efficiently with data tables that are "canonically closed", that is, that provide equivalent data for equivalent text, without having to be fully normalized. Not a standard Unicode normalization form. Not a unique form: Different FCD strings can be canonically equivalent. For details see http://www.unicode.org/notes/tn5/#FCD 

#### [h2]COMPOSE_CONTIGUOUS

public static final [Normalizer2.Mode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/normalizer2_mode-0000001054358851) COMPOSE_CONTIGUOUS

Compose only contiguously. Also known as "FCC" or "Fast C Contiguous". The result will often but not always be in NFC. The result will conform to FCD which is useful for processing. Not a standard Unicode normalization form. For details see http://www.unicode.org/notes/tn5/#FCC
