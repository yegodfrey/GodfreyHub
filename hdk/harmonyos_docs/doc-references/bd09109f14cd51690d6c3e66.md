A thread state. A thread can be in one of the following states: 
    * [NEW](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread_state-0000001054518462#ZH-CN_TOPIC_0000001054518462__NEW) A thread that has not yet started is in this state. 
    * [RUNNABLE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread_state-0000001054518462#ZH-CN_TOPIC_0000001054518462__RUNNABLE) A thread executing in the Java virtual machine is in this state. 
    * [BLOCKED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread_state-0000001054518462#ZH-CN_TOPIC_0000001054518462__BLOCKED) A thread that is blocked waiting for a monitor lock is in this state. 
    * [WAITING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread_state-0000001054518462#ZH-CN_TOPIC_0000001054518462__WAITING) A thread that is waiting indefinitely for another thread to perform a particular action is in this state. 
    * [TIMED_WAITING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread_state-0000001054518462#ZH-CN_TOPIC_0000001054518462__TIMED_WAITING) A thread that is waiting for another thread to perform an action for up to a specified waiting time is in this state. 
    * [TERMINATED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread_state-0000001054518462#ZH-CN_TOPIC_0000001054518462__TERMINATED) A thread that has exited is in this state. 
A thread can be in only one state at a given point in time. [h2]WAITING public static final [Thread.State](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread_state-0000001054518462) WAITING Thread state for a waiting thread. A thread is in the waiting state due to calling one of the following methods: 
    * [Object#wait()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446#ZH-CN_TOPIC_0000001054678446__wait--) with no timeout
    * [Thread.join](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__join--) with no timeout
    * [LockSupport#park()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locksupport-0000001054119880#ZH-CN_TOPIC_0000001054119880__park--)
A thread in the waiting state is waiting for another thread to perform a particular action. For example, a thread that has called Object.wait() on an object is waiting for another thread to call Object.notify() or Object.notifyAll() on that object. A thread that has called Thread.join() is waiting for a specified thread to terminate.
