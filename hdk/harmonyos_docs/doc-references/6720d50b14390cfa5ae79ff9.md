# FileNotFoundException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.io.IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |---|---|---|---java.io.FileNotFoundException
    
    public class FileNotFoundException
    extends [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)  
  
---  
Signals that an attempt to open the file denoted by a specified pathname has failed. 

This exception will be thrown by the [FileInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileinputstream-0000001054439717), [FileOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fileoutputstream-0000001054199704), and [RandomAccessFile](https://developer.harmonyos.com/cn/docs/documentation/doc-references/randomaccessfile-0000001054558437) constructors when a file with the specified pathname does not exist. It will also be thrown by these constructors if the file does exist but for some reason is inaccessible, for example when an attempt is made to open a read-only file for writing.

**Since:**

JDK1.0
