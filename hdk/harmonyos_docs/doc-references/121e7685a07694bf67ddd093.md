# JarOutputStream

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403) |---|---[java.io.FilterOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filteroutputstream-0000001054238431) |---|---|---[java.util.zip.DeflaterOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deflateroutputstream-0000001054838600) |---|---|---|---[java.util.zip.ZipOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zipoutputstream-0000001054558649) |---|---|---|---|---java.util.jar.JarOutputStream
    
    public class JarOutputStream
    extends [ZipOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zipoutputstream-0000001054558649)  
  
---  
The JarOutputStream class is used to write the contents of a JAR file to any output stream. It extends the class java.util.zip.ZipOutputStream with support for writing an optional Manifest entry. The Manifest can be used to specify meta-information about the JAR file and its entries.

**Since:**

1.2

Begins writing a new JAR file entry and positions the stream to the start of the entry data. This method will also close any previous entry.
