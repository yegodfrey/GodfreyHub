Represents the index schema for place items. 

This schema is used to create indexes for place items. It supports index fields longitude, latitude, country, province, city, district, road, postalCode, and all the fields in [CommonItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commonitem-0000001078320140). Among these fields, identifier is mandatory and can be set via the [CommonItem#setIdentifier(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001121107273#ZH-CN_TOPIC_0000001121107273__setIdentifier-java_lang_String-) method.
