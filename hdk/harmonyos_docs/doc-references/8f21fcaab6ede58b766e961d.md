# LightweightMap  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.LightweightMap<K,V>
    
    public final class LightweightMap<K,V>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Map](https://developer.harmonyos.com/cn/docs/documentation/doc-references/map-0000001054199858)<K,V>  
  
---  
Provides a container that implements the [Map](https://developer.harmonyos.com/cn/docs/documentation/doc-references/map-0000001054199858) interfaces. 

The LightweightMap container uses less memory than the [HashMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/hashmap-0000001054518606) container, but may show poor performance when reaching a large size. 

It is recommended that you use this container when less memory is required. 

Note: The thread is secure only when data is read from the LightweightMap container.
