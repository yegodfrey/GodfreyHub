# RawFileDescriptor

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.global.resource.BaseFileDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basefiledescriptor-0000001054120211) |---|---ohos.global.resource.RawFileDescriptor
    
    public abstract class RawFileDescriptor
    extends [BaseFileDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basefiledescriptor-0000001054120211)  
  
---  
Provides the file descriptor of a raw file from RawFileEntry. 

You can use the file descriptor to read data, obtain the data start position, and obtain the length of the raw file. This class inherits from BaseFileDescriptor. The RawFileDescriptor instance can be obtained only by using the [RawFileEntry.openRawFileDescriptor()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rawfileentry-0000001054518896#ZH-CN_TOPIC_0000001054518896__openRawFileDescriptor--) method.
