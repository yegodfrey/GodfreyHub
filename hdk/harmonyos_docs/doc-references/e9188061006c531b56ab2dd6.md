# Path

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.render.Path
    
    public class Path
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Represents a multiple-contoured path as a geometric compound of straight line segments, quadratic curves, and cubic curves. 

A path can be used by [Canvas#drawPath(Path, Paint)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731#ZH-CN_TOPIC_0000001054238731__drawPath-ohos_agp_render_Path-ohos_agp_render_Paint-) in [Canvas](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731), and can also be used for clipping.
