#### [h2]setFlexBasisFraction

public void setFlexBasisFraction​(float flexBasisFraction)

Sets the fraction value, which determines the initial main size of the component relative to its container's main size.

This setting is effective only when the FlexLayout's main size is determined, for example, the EstimateSpec for the layout is [EstimateSpec#PRECISE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_estimatespec-0000001078032058#ZH-CN_TOPIC_0000001078032058__PRECISE) during the measure process. It will override the dimension specified by [ComponentContainer.LayoutConfig.width](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentcontainer_layoutconfig-0000001054119972#ZH-CN_TOPIC_0000001054119972__width) or [ComponentContainer.LayoutConfig.height](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentcontainer_layoutconfig-0000001054119972#ZH-CN_TOPIC_0000001054119972__height).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
flexBasisFraction | Indicates the fraction value to set, which must be in range of [0.0, 1.0].  
  
**Since:**

7

#### [h2]getFlexBasisFraction

public float getFlexBasisFraction​()

Obtains the fraction value, which determines the main size of the component relative to its FlexLayout.

**Returns:**

Returns the fraction value if any; returns -1.0 otherwise.
