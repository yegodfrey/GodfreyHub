Unchecked exception thrown when a character with an invalid Unicode code point as defined by [Character#isValidCodePoint](https://developer.harmonyos.com/cn/docs/documentation/doc-references/character-0000001054199716#ZH-CN_TOPIC_0000001054199716__isValidCodePoint-int-) is passed to the [Formatter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/formatter-0000001054439879). 

Unless otherwise specified, passing a null argument to any method or constructor in this class will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown.

1.5
