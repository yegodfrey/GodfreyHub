# Overview  
  
Provides interfaces of the distributed file manager. This package provides interfaces for basic operations on distributed files or directories, including copying and moving distributed files or directories between trusted devices of the same account, querying and setting attributes of a distributed file or directory, querying files in a distributed directory, and creating and deleting a distributed file or directory.
