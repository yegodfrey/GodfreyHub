# Objects  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.Objects
    
    public final class Objects
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
This class consists of static utility methods for operating on objects. These utilities include null-safe or null-tolerant methods for computing the hash code of an object, returning a string for an object, and comparing two objects.

#### [h2]hash

public static int hash​([Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)... values)

Generates a hash code for a sequence of input values. The hash code is generated as if all the input values were placed into an array, and that array were hashed by calling [Arrays#hashCode(Object[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/arrays-0000001054678559#ZH-CN_TOPIC_0000001054678559__hashCode-java_lang_Object:A-). 

This method is useful for implementing [Object#hashCode()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446#ZH-CN_TOPIC_0000001054678446__hashCode--) on objects containing multiple fields. For example, if an object that has three fields, x, y, and z, one could write: 
    
    @Override public int hashCode() {
         return Objects.hash(x, y, z);
     }
     

**Warning: When a single object reference is supplied, the returned value does not equal the hash code of that object reference.** This value can be computed by calling [hashCode(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objects-0000001054678596#ZH-CN_TOPIC_0000001054678596__hashCode-java_lang_Object-). 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
values  |  the values to be hashed  
  
**Returns:**

a hash value of the sequence of input values

**See Also:**

[Arrays.hashCode(Object[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/arrays-0000001054678559#ZH-CN_TOPIC_0000001054678559__hashCode-java_lang_Object:A-), [List.hashCode()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/list-0000001054119842#ZH-CN_TOPIC_0000001054119842__hashCode--)

#### [h2]compare

public static <T> int compare​(T a, T b, [Comparator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparator-0000001054558585)<? super T> c)

Returns 0 if the arguments are identical and c.compare(a, b) otherwise. Consequently, if both arguments are null 0 is returned. 

Note that if one of the arguments is null, a NullPointerException may or may not be thrown depending on what ordering policy, if any, the [Comparator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparator-0000001054558585) chooses to have for null values.

#### [h2]requireNonNull

public static <T> T requireNonNull​(T obj, [Supplier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/supplier-0000001054678599)<[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460)> messageSupplier)

Checks that the specified object reference is not null and throws a customized [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) if it is. 

Unlike the method [requireNonNull(java.lang.Object,java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objects-0000001054678596#ZH-CN_TOPIC_0000001054678596__requireNonNull-T-java_lang_String-), this method allows creation of the message to be deferred until after the null check is made. While this may confer a performance advantage in the non-null case, when deciding to call this method care should be taken that the costs of creating the message supplier are less than the cost of just creating the string message directly.
