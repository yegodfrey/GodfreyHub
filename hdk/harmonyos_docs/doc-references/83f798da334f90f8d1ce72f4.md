# Overview  
  
Utility classes commonly used by controls. 

This package provides common utility classes with their constant/variable definitions as well as classes for representing rectangles and points.

**Since:**

5

#### Class Summary

Class | Description  
---|---  
[DimensFloat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dimensfloat-0000001120712389) | Represents any paired values related to the X and Y axes.  
[Point](https://developer.harmonyos.com/cn/docs/documentation/doc-references/point-0000001121107283) | A utility class that creates instances for recording pixels.  
[Rect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rect-0000001120847539) | Represents a rectangle area.  
[RectFloat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rectfloat-0000001120951649) | Indicates a rectangle that uses float coordinates.
