# CombinedResultSet

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.data.resultset.AbsResultSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/absresultset-0000001054440109) |---|---ohos.data.resultset.CombinedResultSet
    
    public class CombinedResultSet
    extends [AbsResultSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/absresultset-0000001054440109)  
  
---  
Represents a linear result set that combines multiple result sets. 

Different types of result sets can be combined in a CombinedResultSet. When the [getAllColumnNames()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/combinedresultset-0000001054518836#ZH-CN_TOPIC_0000001054518836__getAllColumnNames--) or [getColumnTypeForIndex(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/combinedresultset-0000001054518836#ZH-CN_TOPIC_0000001054518836__getColumnTypeForIndex-int-) method is called, column names or the column type in the original result set matching the row of the CombinedResultSet is returned.
