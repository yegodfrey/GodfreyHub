# ILifecycle
    
    public interface ILifecycle  
  
---  
Generates a [Lifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967) object. Each [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) or [AbilitySlice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680), which has a lifecycle, must implement this interface to generate its own [Lifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967) object. Lifecycle observers then observe [Lifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967) objects and receive notifications upon lifecycle changes.
