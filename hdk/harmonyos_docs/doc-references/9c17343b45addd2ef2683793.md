# DataObserver
    
    public interface DataObserver

Represents a data observer. 

The data observer is used as an input parameter for the [ResultSet.registerObserver(ohos.data.rdb.DataObserver)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resultset-0000001054838776#ZH-CN_TOPIC_0000001054838776__registerObserver-ohos_data_rdb_DataObserver-) and [ResultSet.unregisterObserver(ohos.data.rdb.DataObserver)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resultset-0000001054838776#ZH-CN_TOPIC_0000001054838776__unregisterObserver-ohos_data_rdb_DataObserver-) methods.
