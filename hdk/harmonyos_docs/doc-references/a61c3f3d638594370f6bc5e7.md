# LayoutAlignment

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.utils.LayoutAlignment
    
    public class LayoutAlignment
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A utility class used to define the horizontal and vertical alignments for components. 

This class controls the alignment of a component with its parent component, for example, vertically centered or horizontally left-aligned.

**Since:**

3
