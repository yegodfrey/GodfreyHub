# CommonEventSubscriber  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.commonevent.CommonEventSubscriber
    
    public abstract class CommonEventSubscriber
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides methods that will be called back when a subscriber receives a new common event. 

CommonEventSubscriber is an abstract class. If you want your application to receive common events from other applications, you must first inherit this class and implement the [onReceiveEvent(ohos.event.commonevent.CommonEventData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscriber-0000001054358824#ZH-CN_TOPIC_0000001054358824__onReceiveEvent-ohos_event_commonevent_CommonEventData-) method. Then, you can use methods provided in [CommonEventManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventmanager-0000001054238835) to subscribe to or unsubscribe from certain common events. The received common events will be stored in [CommonEventData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventdata-0000001054558837).

#### [h2]goAsyncCommonEvent

public final [AsyncCommonEventResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynccommoneventresult-0000001054358815) goAsyncCommonEvent​()

Enables asynchronous processing for the current ordered common event. 

This method is called using the [onReceiveEvent(ohos.event.commonevent.CommonEventData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscriber-0000001054358824#ZH-CN_TOPIC_0000001054358824__onReceiveEvent-ohos_event_commonevent_CommonEventData-) callback method. The common event remains active after being returned from [onReceiveEvent(ohos.event.commonevent.CommonEventData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscriber-0000001054358824#ZH-CN_TOPIC_0000001054358824__onReceiveEvent-ohos_event_commonevent_CommonEventData-). That is, the common event can continue to perform its time-consuming operations on another thread instead of the main thread. However, this does not mean that time-consuming operations can be executed by calling the callback method. In addition, your application is required to call [AsyncCommonEventResult#finishCommonEvent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynccommoneventresult-0000001054358815#ZH-CN_TOPIC_0000001054358815__finishCommonEvent--) to finish processing the ordered common event before it is complete.

**Returns:**

Returns the asynchronous result of the current ordered common event.

**Since:**

2
