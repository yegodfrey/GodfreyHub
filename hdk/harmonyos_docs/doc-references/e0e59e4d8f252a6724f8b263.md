Stores the detection results of text in a given image. Text detection utility classes store textual content of different levels. The specific class for storing textual content is subject to its particular level. Specifically, text elements stored in TextElement are combined into a text line stored in TextLine; text lines are combined into a text block stored in TextBlock; text blocks are combined into text stored in Text of a given image. **Since:** 1Constructor Summary Constructor | Description
