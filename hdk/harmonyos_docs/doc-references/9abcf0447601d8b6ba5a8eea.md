#### [h2]onContourRefreshed

void onContourRefreshed​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component)

Provides a callback for users to set a custom [Contour](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contour-0000001078032066) object for a component. 

This callback will be triggered when the [Element](https://developer.harmonyos.com/cn/docs/documentation/doc-references/element-0000001054358705) of the component is updated, the size of the component is changed, or the [Component#setContourRefreshedListener(ContourRefreshedListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__setContourRefreshedListener-ohos_agp_components_Component_ContourRefreshedListener-) or [Component#refreshContour()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__refreshContour--) method is called. 

You need to pass or create a custom [Contour](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contour-0000001078032066) object and call the [Component#setContour(Contour)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__setContour-ohos_agp_utils_Contour-) method to set this object in the component.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component for which the custom [Contour](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contour-0000001078032066) object is set.
