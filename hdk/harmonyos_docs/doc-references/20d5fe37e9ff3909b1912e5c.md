#### Enum Constant Detail

#### [h2]CONCURRENT

public static final [Collector.Characteristics](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collector_characteristics-0000001054838598) CONCURRENT

Indicates that this collector is concurrent, meaning that the result container can support the accumulator function being called concurrently with the same result container from multiple threads. 

If a CONCURRENT collector is not also UNORDERED, then it should only be evaluated concurrently if applied to an unordered data source.

#### [h2]UNORDERED

public static final [Collector.Characteristics](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collector_characteristics-0000001054838598) UNORDERED

Indicates that the collection operation does not commit to preserving the encounter order of input elements. (This might be true if the result container has no intrinsic order, such as a [Set](https://developer.harmonyos.com/cn/docs/documentation/doc-references/set-0000001054439873).) 

#### [h2]IDENTITY_FINISH

public static final [Collector.Characteristics](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collector_characteristics-0000001054838598) IDENTITY_FINISH

Indicates that the finisher function is the identity function and can be elided. If set, it must be the case that an unchecked cast from A to R will succeed.
