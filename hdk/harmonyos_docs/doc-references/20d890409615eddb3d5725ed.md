# NotificationSubscriber

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationSubscriber
    
    public abstract class NotificationSubscriber
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides methods that will be called back when the subscriber receives a new notification or a notification is canceled. 

NotificationSubscriber is an abstract class. If you want to monitor notifications in your application, you must first inherit this class and implement related methods. For example, if you want to be notified when a notification is received, override the [onConsumed(ohos.event.notification.NotificationRequest)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationsubscriber-0000001054358823#ZH-CN_TOPIC_0000001054358823__onConsumed-ohos_event_notification_NotificationRequest-); if you want to be notified when a notification is canceled, override the [onCanceled(ohos.event.notification.NotificationRequest)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationsubscriber-0000001054358823#ZH-CN_TOPIC_0000001054358823__onCanceled-ohos_event_notification_NotificationRequest-) method. Note that your application must have system-level permission to subscribe to notifications.
