Thread.UncaughtExceptionHandler
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public static interface Thread.UncaughtExceptionHandler  
  
---  
Interface for handlers invoked when a Thread abruptly terminates due to an uncaught exception. When a thread is about to terminate due to an uncaught exception the Java Virtual Machine will query the thread for its UncaughtExceptionHandler using [Thread.getUncaughtExceptionHandler()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__getUncaughtExceptionHandler--) and will invoke the handler's uncaughtException method, passing the thread and the exception as arguments. If a thread has not had its UncaughtExceptionHandler explicitly set, then its ThreadGroup object acts as its UncaughtExceptionHandler. If the ThreadGroup object has no special requirements for dealing with the exception, it can forward the invocation to the [default uncaught exception handler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__getDefaultUncaughtExceptionHandler--). **Since:** 1.5**See Also:** [Thread.setDefaultUncaughtExceptionHandler(java.lang.Thread.UncaughtExceptionHandler)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__setDefaultUncaughtExceptionHandler-java_lang_Thread_UncaughtExceptionHandler-), [Thread.setUncaughtExceptionHandler(java.lang.Thread.UncaughtExceptionHandler)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__setUncaughtExceptionHandler-java_lang_Thread_UncaughtExceptionHandler-), [ThreadGroup.uncaughtException(java.lang.Thread, java.lang.Throwable)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/threadgroup-0000001054678417#ZH-CN_TOPIC_0000001054678417__uncaughtException-java_lang_Thread-java_lang_Throwable-)Method Summary Modifier and Type | Method | Description
