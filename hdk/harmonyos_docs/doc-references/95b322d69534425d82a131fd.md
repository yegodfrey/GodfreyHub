# IntentParams

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.content.IntentParams
    
    public class IntentParams
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Stores extra parameter information passed to an [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007). 

Parameter information in [IntentParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentparams-0000001054439977) is saved in the form of key-value pairs. The keys are of the String type, and the values are saved as objects of the Object type. You can use the [setParam(java.lang.String,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentparams-0000001054439977#ZH-CN_TOPIC_0000001054439977__setParam-java_lang_String-T-) method to set parameters.
