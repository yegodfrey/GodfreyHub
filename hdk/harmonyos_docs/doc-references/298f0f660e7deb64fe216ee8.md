# PasteData

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.miscservices.pasteboard.PasteData
    
    public class PasteData

    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Represents pasted data on the pasteboard. 

This class provides data records defined by PasteData.Record, and data properties defined by PasteData.DataProperty. 

PasteData.Record contains complex data which is created and added using SystemPasteboard by an application. Data in a Record can be a description of plain text, HTML text, an intent, or a URI. A PasteData object contains one Record instance or a limited number of them. A PasteData object contains one Record instance or a combination of them. 

The size of the pasted data transferred each time within a device cannot exceed 500 KB. Data transferred among devices each time cannot exceed 64 KB, and the data must be in the text format. 

DataProperty describes properties of pasted data, such as MIME types and storage timestamp. 

SystemPasteboard can transfer objects through data URIs, and a recipient uses [DataAbilityHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681) to read the object identified by the URI. This transfers complex binary objects between applications, such as images and media files.
