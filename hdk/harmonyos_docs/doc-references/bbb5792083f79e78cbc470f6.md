AudioInterrupt.InterruptListener
    
    public static interface AudioInterrupt.InterruptListener

Listens for an audio interruption message.  If an application needs to receive audio interruption messages, a listener must be set. After the listener is set, [InterruptListener#onInterrupt(int, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiointerrupt_interruptlistener-0000001054120231#ZH-CN_TOPIC_0000001054120231__onInterrupt-int-int-) will be called to notify the application, if audio is interrupted. **Since:** 1Method Summary Modifier and Type | Method | Description
