# PixelMapHolder

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.render.PixelMapHolder
    
    public class PixelMapHolder
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides container for [PixelMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelmap-0000001054120190). 

[PixelMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelmap-0000001054120190) is the decoded image data. PixelMapHolder uses [PixelMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelmap-0000001054120190) to generate data required by the rendering backend, and provides the data as the input parameters for methods in [Canvas](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731).

2

public void uploadTexture​()

#### [h2]resetPixelMap

public void resetPixelMap​([PixelMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelmap-0000001054120190) pixelMap)

Resets the [PixelMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelmap-0000001054120190) object stored in a container. 

The [PixelMapHolder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelmapholder-0000001054119990) updates the backend rendering data when the [PixelMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelmap-0000001054120190) object stored in it is reset.

#### [h2]release

public void release​()

Clears the PixelMap object in PixelMapHolder when no image needs to be rendered, and releases the backend rendering data in the container.
