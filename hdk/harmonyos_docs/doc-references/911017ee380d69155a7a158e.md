# Overview  
  
Provides classes and interface relating to fonts. It contains support for representing Type 1, Type 1 Multiple Master fonts, OpenType fonts, and TrueType fonts. 

**Since:**

1.2

#### Class Summary

Class | Description  
---|---  
[NumericShaper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/numericshaper-0000001054238423) | The NumericShaper class is used to convert Latin-1 (European) digits to other Unicode decimal digits.  
[TextAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textattribute-0000001054678393) | The TextAttribute class defines attribute keys and attribute values used for text rendering.  
  
#### Enum Summary

Enum | Description  
---|---  
[NumericShaper.Range](https://developer.harmonyos.com/cn/docs/documentation/doc-references/numericshaper_range-0000001054358412) | A NumericShaper.Range represents a Unicode range of a script having its own decimal digits.
