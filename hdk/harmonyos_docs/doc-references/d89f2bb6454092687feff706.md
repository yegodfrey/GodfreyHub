# Overview  
  
Executes or configures Wi-Fi. 

  * [WifiDevice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifidevice-0000001054838966): Provides methods for obtaining Wi-Fi status and information, such as checking whether Wi-Fi is enabled, obtaining the list of information about access points detected in a Wi-Fi scan, and checking whether a Wi-Fi connection has been set up. 
  * [WifiLinkedInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifilinkedinfo-0000001054120341): Provides information about the peer hotspot connected to the current device, such as SSID, BSSID, and RSSI of the peer hotspot. 
  * [WifiScanInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifiscaninfo-0000001054120270): Stores information about the scanned Wi-Fi hotspot, such as SSID and BSSID. 
  * [IpInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ipinfo-0000001054678981): Provides information about a Wi-Fi connection that has been set up, such as the IP address, gateway address, and DNS server address. 
  * [WifiEvents](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifievents-0000001054359000): Provides the constants used for Wi-Fi management, such as the broadcast name, encryption mode, and frequency band.
