#### [h2]convertToText

public [CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442) convertToText​([Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) context)

Forcibly converts the content in a pasteboard Record object to text. 

This method follows the following conversion rules: 

    * If the content mimeType is [PasteData.MIMETYPE_TEXT_PLAIN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pastedata-0000001054120208#ZH-CN_TOPIC_0000001054120208__MIMETYPE_TEXT_PLAIN), this method returns the plain text. 
    * If the content mimeType is [PasteData.MIMETYPE_TEXT_HTML](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pastedata-0000001054120208#ZH-CN_TOPIC_0000001054120208__MIMETYPE_TEXT_HTML), this method removes HTML elements, such as tags and tabs, and returns the plain text only. 
    * If the content mimeType is [PasteData.MIMETYPE_TEXT_URI](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pastedata-0000001054120208#ZH-CN_TOPIC_0000001054120208__MIMETYPE_TEXT_URI), this method reads and returns the text contained in the URI. If the reading fails, null is returned. 
    * If the content mimeType is [PasteData.MIMETYPE_TEXT_INTENT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pastedata-0000001054120208#ZH-CN_TOPIC_0000001054120208__MIMETYPE_TEXT_INTENT), this method converts the Intent to a URI of the text format. For details, see [Intent.toUri()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019#ZH-CN_TOPIC_0000001054120019__toUri--). 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
context  |  Indicates the caller context, which is used to obtain information such as [DataAbilityHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681).  
  
**Returns:**

Returns the text representation of the Record object if the operation is successful; returns null otherwise.

4
