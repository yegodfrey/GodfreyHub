# DocumentationTool.DocumentationTask
    
    public static interface DocumentationTool.DocumentationTask
    extends [Callable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callable-0000001054358594)<[Boolean](https://developer.harmonyos.com/cn/docs/documentation/doc-references/boolean-0000001054119700)>  
  
---  
Interface representing a future for a documentation task. The task has not yet started. To start the task, call the [call](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documentationtool_documentationtask-0000001123694570#ZH-CN_TOPIC_0000001123694570__call--) method. 

Before calling the call method, additional aspects of the task can be configured, for example, by calling the [setLocale](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documentationtool_documentationtask-0000001123694570#ZH-CN_TOPIC_0000001123694570__setLocale-java_util_Locale-) method.
