This class provides access to the type information determined by [ValidatorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147).  Some schema languages, such as W3C XML Schema, encourages a validator to report the "type" it assigns to each attribute/element. Those applications who wish to access this type information can invoke methods defined on this "interface" to access such type information.  Implementation of this "interface" can be obtained through the [ValidatorHandler#getTypeInfoProvider()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/validatorhandler-0000001060039147#ZH-CN_TOPIC_0000001060039147__getTypeInfoProvider--) method. **Since:** 1.5**See Also:** [TypeInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typeinfo-0000001060679090)Constructor Summary Modifier | Constructor | Description

[h2]isIdAttribute public abstract boolean isIdAttribute​(int index) Returns true if the specified attribute is determined to be ID.  Exacly how an attribute is "determined to be ID" is up to the schema language. In case of W3C XML Schema, this means that the actual type of the attribute is the built-in ID type or its derived type.  A ohos.javax.xml.parsers.DocumentBuilder uses this information to properly implement ohos.org.w3c.dom.Attr#isId().
