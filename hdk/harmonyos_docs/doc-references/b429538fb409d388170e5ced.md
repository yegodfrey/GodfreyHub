# ManipulationEvent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.multimodalinput.event.MultimodalEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodalevent-0000001054518970) |---|---ohos.multimodalinput.event.ManipulationEvent

Reports manipulation events. 

ManipulationEvent defines and abstracts all manipulation events, such as finger touch events. Such an event carries information including the event location and phase. Generally, the events are used as the input of the callback to capture and process the events. The callback divides an action into three phases: start, operating, and end. For example, for one finger touch, start means that a finger touches the screen, operating means that the finger moves on the screen, and end means that the finger lifts up from the screen.

#### [h2]getPointerPosition

public abstract [MmiPoint](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mmipoint-0000001054440243) getPointerPosition​(int index)

Obtains the x and y coordinates of a pointer index relative to the offset position during touch control or trajectory tracking in an event. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
index  |  Indicates the pointer index mapping to the pointer action in the event. The value ranges from 0 to [getPointerCount()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manipulationevent-0000001054120214#ZH-CN_TOPIC_0000001054120214__getPointerCount--)-1. For the mouse and stylus, only a single pointer action is supported. When the location information is obtained, the pointer index is set to 0.  
  
**Returns:**

Returns the x and y coordinates of the pointer index. If a control's position has been specified, the x and y coordinates relative to the control are returned. If a control's position has not been specified, the x and y coordinates relative to the screen are returned.

#### [h2]getForce

public abstract float getForce​(int index)

Obtains the touch pressure of the finger with a specified index. 

The touch pressure of a finger generally ranges from 0 to 1.0. Depending on the calibration of the input device, a value greater than 1 may be generated sometimes.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
index  |  Indicates the index of the touch finger. The value ranges from 0 to [getPointerCount()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manipulationevent-0000001054120214#ZH-CN_TOPIC_0000001054120214__getPointerCount--)-1. The position of the touch finger in the current event can be obtained based on its unique ID. For the mouse and stylus action events, only a single pointer action is supported. When the pressure information is obtained, the index is set to 0. For the mouse action event, the touch pressure is 1.0 when the left button is pressed and is 0 in other cases.  
  
**Returns:**

Returns the touch pressure.

**Since:**

1
