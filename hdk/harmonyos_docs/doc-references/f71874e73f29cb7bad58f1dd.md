# ContactAttributes  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.sysappcomponents.contact.ContactAttributes
    
    public class ContactAttributes
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides contact attributes for contact query. 

You create a ContactAttributes object, set the attributes, and pass it to a query method. The method returns the Contact object matching the attributes.
