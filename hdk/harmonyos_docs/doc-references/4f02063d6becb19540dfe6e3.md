#### [h2]getAllInputDeviceID

public static int[] getAllInputDeviceID​()

Obtains the IDs of all input devices on a bearer device. 

For example, the bearer device is a smart TV, to which a keyboard, mouse, and remote control are connected. This function is used to obtain the IDs of the keyboard, mouse, and remote control.

**Returns:**

Returns the IDs of all input devices on the bearer device.
