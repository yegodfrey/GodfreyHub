Defines the flags for used by the flags component of an ACL [AclEntry](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentry-0000001054358502).  In this release, this class does not define flags related to [AclEntryType#AUDIT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentrytype-0000001054558517#ZH-CN_TOPIC_0000001054558517__AUDIT) and [AclEntryType#ALARM](https://developer.harmonyos.com/cn/docs/documentation/doc-references/aclentrytype-0000001054558517#ZH-CN_TOPIC_0000001054558517__ALARM) entry types. **Since:** 1.7Enum Constant Summary Enum Constant | Description
