#### [h2]PROTOCOL_VERSION_1

static final int PROTOCOL_VERSION_1

A Stream Protocol Version. 

All externalizable data is written in JDK 1.1 external data format after calling this method. This version is needed to write streams containing Externalizable data that can be read by pre-JDK 1.1.6 JVMs.

**Since:**

1.2

**See Also:**

[ObjectOutputStream.useProtocolVersion(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectoutputstream-0000001054678434#ZH-CN_TOPIC_0000001054678434__useProtocolVersion-int-), [Constant Field Values](https://developer.harmonyos.com/cn/docs/documentation/doc-references/constant-values-0000001054359004#ZH-CN_TOPIC_0000001054359004__java_io_ObjectStreamConstants_PROTOCOL_VERSION_1)

#### [h2]PROTOCOL_VERSION_2

static final int PROTOCOL_VERSION_2

A Stream Protocol Version. 

This protocol is written by JVM 1.2. Externalizable data is written in block data mode and is terminated with TC_ENDBLOCKDATA. Externalizable class descriptor flags has SC_BLOCK_DATA enabled. JVM 1.1.6 and greater can read this format change. Enables writing a nonSerializable class descriptor into the stream. The serialVersionUID of a nonSerializable class is set to 0L.

**Since:**

1.2

**See Also:**

[ObjectOutputStream.useProtocolVersion(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectoutputstream-0000001054678434#ZH-CN_TOPIC_0000001054678434__useProtocolVersion-int-), [SC_BLOCK_DATA](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstreamconstants-0000001054838382#ZH-CN_TOPIC_0000001054838382__SC_BLOCK_DATA), [Constant Field Values](https://developer.harmonyos.com/cn/docs/documentation/doc-references/constant-values-0000001054359004#ZH-CN_TOPIC_0000001054359004__java_io_ObjectStreamConstants_PROTOCOL_VERSION_2)
