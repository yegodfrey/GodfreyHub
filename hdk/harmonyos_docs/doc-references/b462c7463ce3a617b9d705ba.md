# ImageSource.DecodeEventListener
    
    public static interface ImageSource.DecodeEventListener  
  
---  
Listens for the events occurred during image decoding. 

To listen for the events, you should implement the [onDecodeEvent(ohos.media.image.ImageSource, ohos.media.image.common.DecodeEvent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagesource_decodeeventlistener-0000001060996894#ZH-CN_TOPIC_0000001060996894__onDecodeEvent-ohos_media_image_ImageSource-ohos_media_image_common_DecodeEvent-) method, which obtains the [ImageSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagesource-0000001054238931) and [DecodeEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/decodeevent-0000001060157249).
