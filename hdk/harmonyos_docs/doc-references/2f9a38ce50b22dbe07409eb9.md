An exception indicating one of a variety of problems retrieving certificates and CRLs from a CertStore.  A CertStoreException provides support for wrapping exceptions. The [getCause](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method returns the throwable, if any, that caused this exception to be thrown.  **Concurrent Access** Unless otherwise specified, the methods defined in this class are not thread-safe. Multiple threads that need to access a single object concurrently should synchronize amongst themselves and provide the necessary locking. Multiple threads each manipulating separate objects need not synchronize. **Since:** 1.4**See Also:** [CertStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/certstore-0000001054119796), Constructor Summary Constructor | Description
