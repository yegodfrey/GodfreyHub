# JS侧接口说明

#### 支持设备

**表1** API的设备支持情况API | 手机 | 平板 | 智慧屏 | 智能穿戴  
---|---|---|---|---  
createLocalParticleAbility | 支持 | 支持 | 支持 | 支持  
  
#### 导入模块

无需导入。

#### createLocalParticleAbility

createLocalParticleAbility(name: string): Promise<Object>

获取Java接口实例，该Java示例对象需要调用register进行注册，否则无法获取该对象，获取到该实例后，可以调用Java侧的同名函数。

    * 参数 

参数名 | 类型 | 必填 | 说明  
---|---|---|---  
name | string | 是 | Java接口名称，含包路径，如com.example.test.TimeInterfaceImpl.  
  
    * 返回值

返回一个Promise对象，resolve返回结果是与PA端返回值一致的Object类型，reject回调返回结构如下，错误码类型详见[表2](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-apis-fa-calls-pa-result-0000000000617997#ZH-CN_TOPIC_0000001127125086__t25aa35bbcd7d4e62b34f69d2425a6752)。

参数名 | 类型 | 说明  
---|---|---  
code | number | 错误码  
data | string | 错误信息
