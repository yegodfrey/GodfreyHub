Statement
    
    public interface Statement
    extends [Wrapper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wrapper-0000001054358544), [AutoCloseable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/autocloseable-0000001054518454)  
  
---  
The object used for executing a static SQL statement and returning the results it produces.  By default, only one ResultSet object per Statement object can be open at the same time. Therefore, if the reading of one ResultSet object is interleaved with the reading of another, each must have been generated by different Statement objects. All execution methods in the Statement interface implicitly close a current ResultSet object of the statement if an open one exists. **See Also:** [Connection.createStatement()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/connection-0000001054358533#ZH-CN_TOPIC_0000001054358533__createStatement--), [ResultSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resultset-0000001054119812)Field Summary Modifier and Type | Field | Description
