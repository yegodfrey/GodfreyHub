Format a LogRecord into a standard XML format.  The DTD specification is provided as Appendix A to the Java Logging APIs specification.  The XMLFormatter can be used with arbitrary character encodings, but it is recommended that it normally be used with UTF-8. The character encoding can be set on the output Handler. **Since:** 1.4Constructor Summary Constructor | Description
