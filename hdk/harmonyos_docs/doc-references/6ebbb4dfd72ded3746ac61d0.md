# Overview  
  
Provides you with some utility classes to facilitate your network access. 

Currently, you can use classes in this package to create a Uri object and parse the URI.

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009) | Helps to construct and parse a Uniform Resource Identifier (URI) based on RFC 2396.  
[Uri.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri_builder-0000001054239007) | Quickly constructs a Uniform Resource Identifier (URI) object.  
[UrlQueryFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/urlqueryfilter-0000001060039173) | Provides basic URL query analysis capabilities, including filtering invalid characters and obtaining query parameter pairs.  
[UrlQueryFilter.ValueFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/urlqueryfilter_valuefilter-0000001060837314) | Represents a filter used to filter out invalid characters in a query string and replace them with spaces or underscores (_).
