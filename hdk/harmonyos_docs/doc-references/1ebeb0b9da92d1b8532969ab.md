# Overview  
  
Defines the basic data structure of the fusion search service. Related classes include: 
    * [ChangedIndexContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/changedindexcontent-0000001054358816): wraps changed index data and invokes callbacks to notify index data changes. 
    * [IndexData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/indexdata-0000001054120157): represents a container that stores index data. This class is used for adding, deleting, and updating indexes, as well as performing pagination search. 
    * [IndexForm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/indexform-0000001054120086): defines the index attribute. Your application must set the index attribute before performing indexing and search operations. 
    * [Recommendation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recommendation-0000001054440115): represents the group search result. 
    * [IndexType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/indextype-0000001054558829): represents the index type of an index attribute. 
    * [SearchableEntity](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchableentity-0000001054200102): defines searchability meta-data for an Ability. 
    * [SearchErrorCode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searcherrorcode-0000001054238827): provides error codes related to [IndexForm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/indexform-0000001054120086). 
    * [SearchParameter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/searchparameter-0000001054678797): defines keywords of search types supported by fusion search.
