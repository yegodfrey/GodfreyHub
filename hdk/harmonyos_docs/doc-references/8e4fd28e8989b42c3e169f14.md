Enumerates horizontal layout directions. The layout direction can be [LTR](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_layoutdirection-0000001054358703#ZH-CN_TOPIC_0000001054358703__LTR) or [RTL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_layoutdirection-0000001054358703#ZH-CN_TOPIC_0000001054358703__RTL). It can also be inherited ([INHERIT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_layoutdirection-0000001054358703#ZH-CN_TOPIC_0000001054358703__INHERIT)) from a parent component or deduced from the locale settings ([LOCALE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_layoutdirection-0000001054358703#ZH-CN_TOPIC_0000001054358703__LOCALE)).
