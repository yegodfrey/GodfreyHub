Quickly constructs a Uniform Resource Identifier (URI) object. The standard URI format is as follows:  [scheme:]scheme-specific-part[#fragment]  An opaque URI must be an absolute URI, and its scheme-specific-part field cannot start with a slash (/). An opaque URI does not need to be parsed.  A hierarchical URI can be an absolute URI, but its scheme-specific-part field must start with a slash (/). It can also be a relative URI. The standard format of a hierarchical URI is as follows:  [scheme:][//authority][path][?query][#fragment]  If the URI is of the server type, its authority field can be parsed in the following format:  [user-info@]host[:port] **Since:** 1Constructor Summary Constructor | Description
