# Overview  
  
This package allows applications to store and retrieve user and system preference and configuration data. This data is stored persistently in an implementation-dependent backing store. There are two separate trees of preference nodes, one for user preferences and one for system preferences. 

**Since:**

JDK1.4

#### Interface Summary

Interface | Description  
---|---  
[NodeChangeListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nodechangelistener-0000001054678607) | A listener for receiving preference node change events.  
[PreferenceChangeListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferencechangelistener-0000001054838592) | A listener for receiving preference change events.  
[PreferencesFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferencesfactory-0000001054358626) | A factory object that generates Preferences objects.  
  
#### Class Summary

Class | Description  
---|---  
[AbstractPreferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractpreferences-0000001054119896) | This class provides a skeletal implementation of the [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054518652) class, greatly easing the task of implementing it.  
[NodeChangeEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nodechangeevent-0000001054439925) | An event emitted by a Preferences node to indicate that a child of that node has been added or removed.  
[PreferenceChangeEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferencechangeevent-0000001054199912) | An event emitted by a Preferences node to indicate that a preference has been added, removed or has had its value changed.  
[Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054518652) | A node in a hierarchical collection of preference data.  
  
#### Exception Summary

Exception | Description  
---|---  
[BackingStoreException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/backingstoreexception-0000001054358619) | Thrown to indicate that a preferences operation could not complete because of a failure in the backing store, or a failure to contact the backing store.  
[InvalidPreferencesFormatException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/invalidpreferencesformatexception-0000001054558641) | Thrown to indicate that an operation could not complete because the input did not conform to the appropriate XML document type for a collection of preferences, as per the [Preferences](https://developer.harmonyos.com/cn/docs/documentation/doc-references/preferences-0000001054518652) specification.
