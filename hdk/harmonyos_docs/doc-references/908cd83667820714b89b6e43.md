# FieldNode

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.data.distributed.common.FieldNode
    
    public class FieldNode
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Represents a node of a [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001054838758) instance. 

Through the [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001054838758) instance, you can define the fields contained in the values stored in a database. 

A FieldNode of the [Schema](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001054838758) instance is either a leaf or a non-leaf node. 

The leaf node must have a value; the non-leaf node must have a child FieldNode.
