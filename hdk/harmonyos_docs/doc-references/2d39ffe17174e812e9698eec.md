#### [h2]alphaType

public [AlphaType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/alphatype-0000001054838890) alphaType

Indicates the expected alpha type of the pixel map to be created. When the value is [AlphaType#UNKNOWN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/alphatype-0000001054838890#ZH-CN_TOPIC_0000001054838890__UNKNOWN): 
    * If there is a source pixel map, its alpha type will be used for the creation.
    * If there is no source pixel map, either [AlphaType#PREMUL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/alphatype-0000001054838890#ZH-CN_TOPIC_0000001054838890__PREMUL) (for the alpha channel is included in the pixel format) or [AlphaType#OPAQUE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/alphatype-0000001054838890#ZH-CN_TOPIC_0000001054838890__OPAQUE) (for the alpha channel not included in the pixel format) will be used for the creation.

**Since:**

3

#### [h2]editable

public boolean editable

Specifies whether pixel values of the pixel map to be created can be edited. Value true means that the values can be edited, and false means the opposite. The default value is false. 

**Since:**

3

#### [h2]pixelFormat

public [PixelFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelformat-0000001054120194) pixelFormat

Indicates the expected format of the pixel map to be created. When the value is [PixelFormat#UNKNOWN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelformat-0000001054120194#ZH-CN_TOPIC_0000001054120194__UNKNOWN): 
    * If there is a source pixel map, its format will be used for the creation.
    * If there is no source pixel map, [PixelFormat#ARGB_8888](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pixelformat-0000001054120194#ZH-CN_TOPIC_0000001054120194__ARGB_8888) will be used.
. 

**Since:**

3

#### [h2]releaseSource

public boolean releaseSource

Specifies whether the source pixel map will be automatically released after a new one is created based on the source one. Value true means that the source one will be released except that it is directly returned as the new pixel map, and false means that the source one will not be released. 

**Since:**

3

#### [h2]scaleMode

public [ScaleMode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/scalemode-0000001054440223) scaleMode

Indicates the scaling effect used when the aspect ratio of the original image is different from that of the target image. The default value is [ScaleMode#FIT_TARGET_SIZE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/scalemode-0000001054440223#ZH-CN_TOPIC_0000001054440223__FIT_TARGET_SIZE). 

**Since:**

3

#### [h2]size

public [Size](https://developer.harmonyos.com/cn/docs/documentation/doc-references/size-0000001054238935) size

Indicates the expected size of the pixel map to be created. If the value is null and there is a source pixel map, the size of the source pixel map will be used for the creation. 

**Since:**

3

#### [h2]useSourceIfMatch

public boolean useSourceIfMatch

Specifies whether the source pixel map will be directly returned as a new one when the source one matches the initialization options for creating the new one. Value true means that the source pixel map will be returned, and false means the opposite. The default value is false. 

**Since:**

3
