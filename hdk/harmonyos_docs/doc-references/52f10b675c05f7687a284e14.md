# CommonPattern

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.CommonPattern
    
    public class CommonPattern
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides methods for obtaining regular expressions used to verify common patterns. 

Before conducting regular expression verification on common patterns, you need to use the methods in this class to obtain the matched regular expressions first.
