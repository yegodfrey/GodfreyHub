A wrapper class of [DataObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054200088). The DataObserverAsyncWrapper instance notifies the wrapped [DataObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataobserver-0000001054200088) instance asynchronously. 

The observer is used as an input parameter for the [ResultSet.registerObserver(ohos.data.rdb.DataObserver)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resultset-0000001054838776#ZH-CN_TOPIC_0000001054838776__registerObserver-ohos_data_rdb_DataObserver-) and [ResultSet.unregisterObserver(ohos.data.rdb.DataObserver)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resultset-0000001054838776#ZH-CN_TOPIC_0000001054838776__unregisterObserver-ohos_data_rdb_DataObserver-) methods.
