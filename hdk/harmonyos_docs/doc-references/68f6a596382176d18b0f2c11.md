AudioDeviceChangeObserver
    
    public interface AudioDeviceChangeObserver  
  
---  
Provides a callback to listen for device state changes caused by disconnection and connection. You should register the callback via [AudioManager#setAudioDeviceChangeObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiomanager-0000001054838858#ZH-CN_TOPIC_0000001054838858__setAudioDeviceChangeObserver-ohos_media_audio_AudioDeviceChangeObserver-) to receive notifications about the changes. **Since:** 4Method Summary Modifier and Type | Method | Description  
---|---|---

Method Detail [h2]onAudioDeviceChange void onAudioDeviceChange​(int reason, [AudioDeviceDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiodevicedescriptor-0000001054238903)[] devices) Called upon device state changes to receive the change reason and device information. **Parameters:** Parameter Name | Parameter Description  
---|---  
reason  |  Indicates the change reason. The value can be [AudioDeviceChangeType#DEVICE_AVAILABLE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiodevicechangetype-0000001060268787#ZH-CN_TOPIC_0000001060268787__DEVICE_AVAILABLE) (for connection) or ([AudioDeviceChangeType#DEVICE_UNAVAILABLE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiodevicechangetype-0000001060268787#ZH-CN_TOPIC_0000001060268787__DEVICE_UNAVAILABLE) (for disconnection).  
devices  |  Indicates a list of device information, including device types and audio formats supported by the devices.
