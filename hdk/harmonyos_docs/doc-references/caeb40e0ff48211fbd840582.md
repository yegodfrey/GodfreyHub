Represents a filter used to filter out invalid characters in a query string and replace them with spaces or underscores (_). The filtering policy uses int values to control filtering. Each bit of the int value represents whether a character in the string will be filtered out. If the value of a bit is 1, the character is valid. If the value is 0, the character is invalid and will be filtered out.**Since:** 4Field Summary Modifier and Type | Field | Description
