#### [h2]getReceiverType

[TypeMirror](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typemirror-0000001123534712) getReceiverType​()

Returns the receiver type of this executable, or [NoType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notype-0000001123534710) with kind [NONE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typekind-0000001170214379#ZH-CN_TOPIC_0000001170214379__NONE) if the executable has no receiver type. An executable which is an instance method, or a constructor of an inner class, has a receiver type derived from the [declaring type](https://developer.harmonyos.com/cn/docs/documentation/doc-references/element-0000001123694530#ZH-CN_TOPIC_0000001123694530__getEnclosingElement--). An executable which is a static method, or a constructor of a non-inner class, or an initializer (static or instance), has no receiver type. 

**Returns:**

the receiver type of this executable

1.8
