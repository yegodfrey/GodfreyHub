# Overview  
  
Provides a universal NFC control module. 

NfcController: Provides interfaces for NFC management, including enabling and disabling NFC, and querying the NFC capabilities and status. 

NfcPermissionException: Provides the NFC permission exception, which is thrown when an NFC application does not have permissions to access an NFC interface.
