# Configuration  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.global.configuration.Configuration
    
    public class Configuration
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides the configuration of the resource manager. 

You can use [ResourceManager.getConfiguration()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863#ZH-CN_TOPIC_0000001054358863__getConfiguration--) to obtain the configuration and [ResourceManager.updateConfiguration(Configuration, DeviceCapability)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863#ZH-CN_TOPIC_0000001054358863__updateConfiguration-ohos_global_configuration_Configuration-ohos_global_configuration_DeviceCapability-) to update the configuration.
