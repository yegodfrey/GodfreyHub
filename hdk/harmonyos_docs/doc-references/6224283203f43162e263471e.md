WatchEvent
    
    public interface WatchEvent<T>  
  
---  
An event or a repeated event for an object that is registered with a [WatchService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchservice-0000001054199778).  An event is classified by its [kind](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchevent-0000001054358492#ZH-CN_TOPIC_0000001054358492__kind--) and has a [count](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchevent-0000001054358492#ZH-CN_TOPIC_0000001054358492__count--) to indicate the number of times that the event has been observed. This allows for efficient representation of repeated events. The [context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchevent-0000001054358492#ZH-CN_TOPIC_0000001054358492__context--) method returns any context associated with the event. In the case of a repeated event then the context is the same for all events.
