# ConcurrentSkipListSet  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.AbstractCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractcollection-0000001054358576)<E> |---|---[java.util.AbstractSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractset-0000001054358569)<E> |---|---|---java.util.concurrent.ConcurrentSkipListSet<E>
    
    public class ConcurrentSkipListSet<E>
    extends [AbstractSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractset-0000001054358569)<E>
    implements [NavigableSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/navigableset-0000001054358565)<E>, [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421), [Serializable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serializable-0000001054358416)

A scalable concurrent [NavigableSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/navigableset-0000001054358565) implementation based on a [ConcurrentSkipListMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentskiplistmap-0000001054439897). The elements of the set are kept sorted according to their [Comparable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparable-0000001054558443), or by a [Comparator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparator-0000001054558585) provided at set creation time, depending on which constructor is used. 

This implementation provides expected average _log(n)_ time cost for the contains, add, and remove operations and their variants. Insertion, removal, and access operations safely execute concurrently by multiple threads. 

Iterators and spliterators are [_weakly consistent_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054558607#ZH-CN_TOPIC_0000001054558607__Weakly). 

Ascending ordered views and their iterators are faster than descending ones. 

Beware that, unlike in most collections, the size method is not a constant-time operation. Because of the asynchronous nature of these sets, determining the current number of elements requires a traversal of the elements, and so may report inaccurate results if this collection is modified during traversal. Additionally, the bulk operations addAll, removeAll, retainAll, containsAll, equals, and toArray are not guaranteed to be performed atomically. For example, an iterator operating concurrently with an addAll operation might view only some of the added elements. 

This class and its iterators implement all of the optional methods of the [Set](https://developer.harmonyos.com/cn/docs/documentation/doc-references/set-0000001054439873) and [Iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913) interfaces. Like most other concurrent collection implementations, this class does not permit the use of null elements, because null arguments and return values cannot be reliably distinguished from the absence of elements. 

This class is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).
