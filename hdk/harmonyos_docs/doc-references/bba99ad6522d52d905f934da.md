# DeviceKvStore
    
    public interface DeviceKvStore
    extends [KvStore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstore-0000001054678771)  
  
---  
Manages distributed data by device in a distributed system. 

To create a DeviceKvStore database, you can use the [KvManager.getKvStore(Options, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvmanager-0000001054238801#ZH-CN_TOPIC_0000001054238801__getKvStore-ohos_data_distributed_common_Options-java_lang_String-) method with KvStoreType set to DEVICE_COLLABORATION for the input parameter Options. This database manages distributed data by device, and cannot modify data synchronized from remote devices. When an application writes a key-value pair entry into the database, the system automatically adds the ID of the device running the application to the key.

[KvStoreResultSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstoreresultset-0000001054358790) getResultSet​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) deviceId, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) keyPrefix) throws [KvStoreException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstoreexception-0000001054838760)

Obtains the KvStoreResultSet object matching the specified device ID and key prefix. 

The KvStoreResultSet object can be used to query all key-value pairs that meet the search criteria. Each KvStore instance can have a maximum of four KvStoreResultSet objects at the same time. If you have created four objects, calling this method will return a failure. Therefore, you are advised to call the closeResultSet method to close unnecessary KvStoreResultSet objects in a timely manner.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
deviceId  |  Identifies the device whose data is to be queried.  
keyPrefix  |  Indicates the key prefix to match.  
  
**Returns:**

Returns the KvStoreResultSet objects.

**Throws:**

Throw Name | Throw Description  
---|---  
[KvStoreException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/kvstoreexception-0000001054838760) |  Throws this exception if any of the following errors occurs: INVALID_ARGUMENT, SERVER_UNAVAILABLE, IPC_ERROR, and DB_ERROR.  
  
**Since:**
