# Overview  
  
Provides interfaces related to the screen lock. Applications can call the provided methods to unlock the screen and check the lock status.

**Since:**

3

#### Interface Summary

---|---  
[UnlockScreenCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unlockscreencallback-0000001054120281) | Provides callbacks for screen lock changes.
