A char buffer.  This class defines four categories of operations upon char buffers: 
                * Absolute and relative [_get_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__get--) and [_put_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__put-char-) methods that read and write single chars; 
                * Relative [_bulk get_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__get-char:A-) methods that transfer contiguous sequences of chars from this buffer into an array; and
                * Relative [_bulk put_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__put-char:A-) methods that transfer contiguous sequences of chars from a char array, a string, or some other char buffer into this buffer; and 
                * Methods for [compacting](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__compact--), [duplicating](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__duplicate--), and [slicing](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__slice--) a char buffer. 
Char buffers can be created either by [_allocation_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__allocate-int-), which allocates space for the buffer's content, by [_wrapping_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__wrap-char:A-) an existing char array or string into a buffer, or by creating a [_view_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771#ZH-CN_TOPIC_0000001054439771__views) of an existing byte buffer.  Like a byte buffer, a char buffer is either [_direct_ or _non-direct_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771#ZH-CN_TOPIC_0000001054439771__direct). A char buffer created via the wrap methods of this class will be non-direct. A char buffer created as a view of a byte buffer will be direct if, and only if, the byte buffer itself is direct. Whether or not a char buffer is direct may be determined by invoking the [isDirect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charbuffer-0000001054518498#ZH-CN_TOPIC_0000001054518498__isDirect--) method.  This class implements the [CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442) interface so that character buffers may be used wherever character sequences are accepted, for example in the regular-expression package [java.util.regex](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054678609).  Methods in this class that do not otherwise have a value to return are specified to return the buffer upon which they are invoked. This allows method invocations to be chained. The sequence of statements 
    
    cb.put("text/");
     cb.put(subtype);
     cb.put("; charset=");
     cb.put(enc);

can, for example, be replaced by the single statement 
    
    cb.put("text/").put(subtype).put("; charset=").put(enc);
