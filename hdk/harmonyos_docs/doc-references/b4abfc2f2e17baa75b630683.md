#### [h2]getVolumeAdjustMode

public int getVolumeAdjustMode​()

Obtains the volume adjustment mode of this media session. 

The adjustment mode can be one of the following: 

    * AVVolumeHandler#ADJUST_MODE_FORBID_ALL: Volume adjustment is not allowed.
    * AVVolumeHandler#ADJUST_MODE_ALLOW_SCROLL: Only adjustment based on volume steps is supported.
    * AVVolumeHandler#ADJUST_MODE_ALLOW_ALL: Both adjustment based on volume steps and direct volume setting are supported.

**Returns:**

Returns the volume adjustment mode.

**Since:**

6
