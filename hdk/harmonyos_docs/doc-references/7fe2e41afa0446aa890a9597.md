# NotificationSlot

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationSlot
    
    public final class NotificationSlot
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Defines a public notification theme, which is a collection of features including notification tone, vibration, lock screen display, and level. You can associate this class with an application, so that all notifications released by the application have the features of the notification theme. 

An application can be associated with one or more NotificationSlot instances.

public void setEnableVibration​(boolean vibration)

Sets whether to enable vibration when a notification is received. 

setEnableVibration(boolean) must be set before the [NotificationHelper#addNotificationSlot(NotificationSlot)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationhelper-0000001054200114#ZH-CN_TOPIC_0000001054200114__addNotificationSlot-ohos_event_notification_NotificationSlot-) method is called. Otherwise, the settings will not take effect.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
vibration  |  Indicates whether to enable vibration when a notification is received. If the value is true, vibration is enabled; if the value is false, vibration is disabled.

#### [h2]setLockscreenVisibleness

public void setLockscreenVisibleness​(int visibleness)

Sets whether and how to display notifications on the lock screen. 

This method specifies different effects for displaying notifications on the lock screen in order to protect user privacy. 

The setting takes effect only when the lock screen notifications function is enabled for an application in system notification settings.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
visibleness  |  Specifies the notification display effect on the lock screen, which can be set to [NotificationRequest#VISIBLENESS_TYPE_PUBLIC](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__VISIBLENESS_TYPE_PUBLIC), [NotificationRequest#VISIBLENESS_TYPE_PRIVATE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__VISIBLENESS_TYPE_PRIVATE), or [NotificationRequest#VISIBLENESS_TYPE_SECRET](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__VISIBLENESS_TYPE_SECRET).

public void setVibrationStyle​(long[] vibrationValues)

Sets the vibration style for notifications in this NotificationSlot. 

If an empty array or null is passed to this method, the system then calls [setEnableVibration(boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationslot-0000001054120100#ZH-CN_TOPIC_0000001054120100__setEnableVibration-boolean-) with the input parameter set to false.
