Indicates the security level of the data to access. Currently, biometric authentication provides 3D facial authentication (the highest security level supported is S3) and 2D facial authentication (the highest security level supported is S2). S4 is not supported in the current version. Applications can choose the appropriate security level based on the security requirements for the data to access. If the authentication security capability of the device is higher than or equal to the security level required by the application, biometric authentication is supported; if the authentication security capability of the device is lower than the security level required by the application, biometric authentication is not supported.
