Obtains the home location of a phone number based on the number, defaultRegion and the region specified by Locale. 

**Parameters:**

Parameter Name | Parameter Description  
---|---

defaultRegion  |  Indicates the region selected for parsing the phone number.  
locale  |  Indicates Locale associated with the phone number.  
  
**Returns:**

Returns the home location of the phone number in the specified region if obtained; returns an empty string if the format of the phone number is incorrect.
