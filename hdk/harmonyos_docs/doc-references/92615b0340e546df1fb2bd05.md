# RemoteObjectCallbackList

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.rpc.RemoteObjectCallbackList<E>
    
    public class RemoteObjectCallbackList<E extends [IRemoteBroker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremotebroker-0000001054518982)>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Stores and maintains a list of remote callbacks from a service to its clients. 

In details, this class: 

    * Stores a set of registered [IRemoteBroker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremotebroker-0000001054518982) callbacks in a Map container. Each callback is uniquely identified by an [IRemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970) (obtained by calling [IRemoteBroker#asObject()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremotebroker-0000001054518982#ZH-CN_TOPIC_0000001054518982__asObject--).
    * Attaches an [IRemoteObject.DeathRecipient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject_deathrecipient-0000001054358949) object to each registered callback so that a callback is automatically removed from the list when the process hosting the callback dies.
    * Locks and backs up the callback list to deal with multi-thread calls, and iterates over a backup of the list without keeping the backup locked.

When constructing a RemoteObjectCallbackList instance, you need to pass E to specify the callback type. E is inherited from [IRemoteBroker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremotebroker-0000001054518982).

#### [h2]unregisterAll

public void unregisterAll​()

Removes all previously added callbacks from this RemoteObjectCallbackList. 

After removing all callbacks from this RemoteObjectCallbackList and marking the list as unavailable, calling [register(E)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__register-E-) to add callbacks to this list will fail. This method is used to prevent clients from registering callbacks after the service has stopped.

**Since:**

3

#### [h2]startBroadcast

public int startBroadcast​()

Starts a broadcast. 

This method creates a copy of the callback list and starts invoking registered callbacks. You can retrieve callbacks from the list using [getBroadcastInterface(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__getBroadcastInterface-int-) and [getBroadcastCookie(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__getBroadcastCookie-int-). 

Only one broadcast is allowed at a time. Ensure that you always call this method from the same thread and that you call [stopBroadcast()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__stopBroadcast--) after calling this method.

**Returns:**

Returns the number of callbacks in the list, which is also the upper limit that can be accessed with [getBroadcastInterface(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__getBroadcastInterface-int-) and [getBroadcastCookie(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__getBroadcastCookie-int-); otherwise returns -1 if another broadcast is running.

**Since:**

3

#### [h2]getBroadcastInterface

public [E](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228) getBroadcastInterface​(int index)

Obtains the callback matching the given index in the broadcast. 

This method can be called only after a broadcast is started, and its data is no longer valid after [stopBroadcast()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__stopBroadcast--) is called. 

If the returned callback has disappeared when you call it, the RemoteException will be thrown. You need to catch this exception, but you can handle it by simply ignoring it because the callback list automatically removes invalid callbacks.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
index  |  Indicates the callback index. It cannot exceed the return value of [startBroadcast()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobjectcallbacklist-0000001054120228#ZH-CN_TOPIC_0000001054120228__startBroadcast--).  
  
**Returns:**

Returns the callback matching the given index.
