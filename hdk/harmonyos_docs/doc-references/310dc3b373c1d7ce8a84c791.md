# IAbilityDelegatorArgs
    
    public interface IAbilityDelegatorArgs  
  
---  
Stores unit testing-related parameters, including the class loader, test case names, and test runner name. 

You can call [AbilityDelegatorRegistry#getArguments](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitydelegatorregistry-0000001054358665#ZH-CN_TOPIC_0000001054358665__getArguments--) to obtain an IAbilityDelegatorArgs object.
