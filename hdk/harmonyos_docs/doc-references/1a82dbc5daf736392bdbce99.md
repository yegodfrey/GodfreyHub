# stack

堆叠容器，子组件按照顺序依次入栈，后一个子组件覆盖前一个子组件。

#### 子组件

支持添加子组件。

#### 属性

支持[通用属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-common-attributes-0000001161259599)。

#### 样式

支持[通用样式](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-common-styles-0000001161339585)。

#### 事件

支持[通用事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-common-events-0000001115139690)。

#### 示例
    
    <!-- xxx.hml -->
    <stack class="stack-parent">
      <div class="back-child bd-radius"></div>
      <div class="positioned-child bd-radius"></div>
      <div class="front-child bd-radius"></div>
    </stack>
    
    /* xxx.css */
    .stack-parent {
      width: 400px;
      height: 400px;
      margin: 50px;
      background-color: #ffffff;
      border-width: 1px;
      border-style: solid;
    }
    .back-child {
      width: 300px;
      height: 300px;
      background-color: #3f56ea;
    }
    .front-child {
      width: 100px;
      height: 100px;
      background-color: #00bfc9;
    }
    .positioned-child {
      width: 100px;
      height: 100px;
      left: 50px;
      top: 50px;
      background-color: #47cc47;
    }
    .bd-radius {
      border-radius: 16px;
    }
