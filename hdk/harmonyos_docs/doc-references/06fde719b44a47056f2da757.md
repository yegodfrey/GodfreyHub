# DigestInputStream

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.InputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420) |---|---[java.io.FilterInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filterinputstream-0000001054558433) |---|---|---java.security.DigestInputStream
    
    public class DigestInputStream
    extends [FilterInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filterinputstream-0000001054558433)  
  
---  
A transparent stream that updates the associated message digest using the bits going through the stream. 

To complete the message digest computation, call one of the digest methods on the associated message digest after your calls to one of this digest input stream's [read](https://developer.harmonyos.com/cn/docs/documentation/doc-references/digestinputstream-0000001054838476#ZH-CN_TOPIC_0000001054838476__read--) methods. 

It is possible to turn this stream on or off (see [on](https://developer.harmonyos.com/cn/docs/documentation/doc-references/digestinputstream-0000001054838476#ZH-CN_TOPIC_0000001054838476__on-boolean-)). When it is on, a call to one of the read methods results in an update on the message digest. But when it is off, the message digest is not updated. The default is for the stream to be on. 

Note that digest objects can compute only one digest (see [MessageDigest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messagedigest-0000001054358505)), so that in order to compute intermediate digests, a caller should retain a handle onto the digest object, and clone it for each digest to be computed, leaving the orginal digest untouched.

#### [h2]read

public int read​() throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Reads a byte, and updates the message digest (if the digest function is on). That is, this method reads a byte from the input stream, blocking until the byte is actually read. If the digest function is on (see [on](https://developer.harmonyos.com/cn/docs/documentation/doc-references/digestinputstream-0000001054838476#ZH-CN_TOPIC_0000001054838476__on-boolean-)), this method will then call update on the message digest associated with this stream, passing it the byte read.

#### [h2]read

public int read​(byte[] b, int off, int len) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Reads into a byte array, and updates the message digest (if the digest function is on). That is, this method reads up to len bytes from the input stream into the array b, starting at offset off. This method blocks until the data is actually read. If the digest function is on (see [on](https://developer.harmonyos.com/cn/docs/documentation/doc-references/digestinputstream-0000001054838476#ZH-CN_TOPIC_0000001054838476__on-boolean-)), this method will then call update on the message digest associated with this stream, passing it the data.

#### [h2]on

public void on​(boolean on)
