Inherits from [SensorBase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sensorbase-0000001054238981) and describes environment sensors on hardware devices. This class describes the sensor types in the environment category, such as the temperature, humidity, barometric pressure, and magnetic field sensors.
