#### [h2]DEFAULT

public static final [Player.AudioHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_audiohandler-0000001121107279) DEFAULT

Indicates the default handling mode. The system processes the audio according to the audio parameters even if the values may be unusual. For example, if the audio pitch is set to a value much greater than the common range but is still valid, the system processes the audio based on the parameters. 

#### [h2]MUTE

public static final [Player.AudioHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_audiohandler-0000001121107279) MUTE

Indicates the mute mode in which the system processes the audio in the same way as the default handling mode. 

#### [h2]ERROR

public static final [Player.AudioHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_audiohandler-0000001121107279) ERROR
