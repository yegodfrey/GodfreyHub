    extends [RdbException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbexception-0000001054558821)

Represents an exception indicating that the SQLite database operation has ended. 

This exception is thrown if your application calls a query method after the SQLite database operation has ended. This class is inherited from RuntimeException. You must handle this exception by yourself.
