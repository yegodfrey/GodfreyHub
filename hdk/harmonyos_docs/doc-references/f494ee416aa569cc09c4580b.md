# Overview  
  
Provides automatic speech recognition (ASR) classes, including those about the data structure, configurations, and functions specific to ASR.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[AsrListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrlistener-0000001054558763) | Provides callbacks for observing the process and result of ASR method calls.  
  
#### Class Summary

Class | Description  
---|---  
[AsrClient](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731) | Provides methods for invoking the automatic speech recognition (ASR) engine service.  
[AsrIntent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent-0000001054838716) | Provides input parameters for executing ASR engine methods.  
  
#### Enum Summary

Enum | Description  
---|---  
[AsrIntent.AsrAudioSrcType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent_asraudiosrctype-0000001054120091) | Enumerates ASR audio source types.  
[AsrIntent.AsrEngineType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent_asrenginetype-0000001054120020) | Enumerates ASR engine types.
