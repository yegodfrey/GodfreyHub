# AbstractQueuedLongSynchronizer.ConditionObject  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.concurrent.locks.AbstractQueuedLongSynchronizer.ConditionObject

    implements [Condition](https://developer.harmonyos.com/cn/docs/documentation/doc-references/condition-0000001054518634), [Serializable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serializable-0000001054358416)  
  
---  
Condition implementation for a [AbstractQueuedLongSynchronizer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueuedlongsynchronizer-0000001054678591) serving as the basis of a [Lock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lock-0000001054678622) implementation. 

Method documentation for this class describes mechanics, not behavioral specifications from the point of view of Lock and Condition users. Exported versions of this class will in general need to be accompanied by documentation describing condition semantics that rely on those of the associated AbstractQueuedLongSynchronizer. 

This class is Serializable, but all fields are transient, so deserialized conditions have no waiters.

1.6
