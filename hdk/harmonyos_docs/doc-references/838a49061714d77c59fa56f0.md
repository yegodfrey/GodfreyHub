#### [h2]getSecKeyUsagePurposes

public int getSecKeyUsagePurposes​()

Obtains the purposes for using a key. For details, see the declaration in [KeyStoreConstants](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystoreconstants-0000001054238973).

#### [h2]getSecKeyAuthDuration

public int getSecKeyAuthDuration​()

Obtains the validity period for user authentication with a key. 

If a key requires user authentication (see [KeyStoreConstants#FLAG_KEY_ACCESSIBLE_NEEDED_USER_AUTH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystoreconstants-0000001054238973#ZH-CN_TOPIC_0000001054238973__FLAG_KEY_ACCESSIBLE_NEEDED_USER_AUTH)), this method can be used to obtain the validity period of user authentication.

**Returns:**

Returns the validity period for user authentication in seconds; returns -1 if user authentication is required every time the key is used.

1
