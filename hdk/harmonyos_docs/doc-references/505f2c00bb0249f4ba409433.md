# PrivateKey
    
    public interface PrivateKey
    extends [Key](https://developer.harmonyos.com/cn/docs/documentation/doc-references/key-0000001054358506), [Destroyable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/destroyable-0000001054678668)  
  
---  
A private key. The purpose of this interface is to group (and provide type safety for) all private key interfaces. 

Note: The specialized private key interfaces extend this interface. See, for example, the DSAPrivateKey interface in [java.security.interfaces](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054119873). 

Implementations should override the default destroy and isDestroyed methods from the [Destroyable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/destroyable-0000001054678668) interface to enable sensitive key information to be destroyed, cleared, or in the case where such information is immutable, unreferenced. Finally, since PrivateKey is Serializable, implementations should also override [ObjectOutputStream.writeObject(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectoutputstream-0000001054678434#ZH-CN_TOPIC_0000001054678434__writeObject-java_lang_Object-) to prevent keys that have been destroyed from being serialized.
