# AsrClient

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.ai.asr.AsrClient
    
    public class AsrClient
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides methods for invoking the automatic speech recognition (ASR) engine service. 

For example, you use these methods to initialize the ASR engine service, start speech recognition, stop speech recognition, and recognize PCM streams.

#### [h2]init

public void init​([AsrIntent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent-0000001054838716) intent, [AsrListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrlistener-0000001054558763) asrListener)

Initializes the ASR engine service. 

An ASR listener is passed to this method for observing the process and result of an ASR method call, and initialization parameters are passed for initializing the ASR engine. You must use this method and obtain the result of [AsrListener#onInit(PacMap)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrlistener-0000001054558763#ZH-CN_TOPIC_0000001054558763__onInit-ohos_utils_PacMap-)} before calling the ASR methods such as [startListening(ohos.ai.asr.AsrIntent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__startListening-ohos_ai_asr_AsrIntent-) and @link #stopListening()}. 

Before re-initializing the ASR service, use [destroy()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__destroy--) to release the ASR engine.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
intent  |  Indicates ASR initialization parameters, which are defined in [AsrIntent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent-0000001054838716). This parameter cannot be null. Generally, you need to set the audio source type during initialization, otherwise the default audio source type [AsrIntent.AsrAudioSrcType#ASR_SRC_TYPE_FILE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent_asraudiosrctype-0000001054120091#ZH-CN_TOPIC_0000001054120091__ASR_SRC_TYPE_FILE) is used.  
asrListener  |  Indicates the listener to observe the process and result of ASR method calls. This parameter cannot be null.

#### [h2]startListening

public void startListening​([AsrIntent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent-0000001054838716) asrIntent)

Starts reading and recognizing speech data. 

If an audio file is detected, this method reads the file and performs speech recognition with the file path specified using [AsrIntent#setFilePath(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent-0000001054838716#ZH-CN_TOPIC_0000001054838716__setFilePath-java_lang_String-); if PCM streams are detected, this method works with [writePcm(byte[],int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__writePcm-byte:A-int-) to perform speech recognition. 

Before using this method, you need to call [init(ohos.ai.asr.AsrIntent,ohos.ai.asr.AsrListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__init-ohos_ai_asr_AsrIntent-ohos_ai_asr_AsrListener-) to initialize the ASR engine service.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
asrIntent  |  Indicates ASR parameters. You can set the pre-VAD threshold, post-VAD threshold, recognition timeout threshold, and file path (only for audio files). This parameter cannot be null. Unless otherwise specified, the default parameter values are used. For details about the parameters and their default values, see [AsrIntent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrintent-0000001054838716).  
  
**Since:**

3

#### [h2]stopListening

public void stopListening​()

Stops speech recognition. 

After you call this method, the obtained speech data will be recognized, and new data will not. Generally, you do not need to call this method because the ASR engine server automatically stops speech recognition upon detecting that speech recognition is complete. Alternatively, you can use this method to manually stop speech recognition at a specific moment. 

Before using this method, you need to call [init(ohos.ai.asr.AsrIntent,ohos.ai.asr.AsrListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__init-ohos_ai_asr_AsrIntent-ohos_ai_asr_AsrListener-) to initialize the ASR engine service.

**Since:**

3

#### [h2]writePcm

public void writePcm​(byte[] bytes, int length)

Writes the PCM audio stream into a byte array and performs speech recognition. 

Before using this method, you need to call [init(ohos.ai.asr.AsrIntent,ohos.ai.asr.AsrListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__init-ohos_ai_asr_AsrIntent-ohos_ai_asr_AsrListener-) to initialize the ASR engine service and call [startListening(ohos.ai.asr.AsrIntent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__startListening-ohos_ai_asr_AsrIntent-) to obtain the PCM stream, which will be passed to the ASR engine. The size of the PCM stream cannot exceed 800 KB. In addition, the duration of the PCM-encoded audio to play cannot exceed 20s.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
bytes  |  Indicates the PCM stream. This parameter cannot be null. Its length must be greater than 0, and its size must be less than or equal to 800 KB.  
length  |  Indicates the valid length of the PCM audio stream, either 1280 or 640 bytes.  
  
**Since:**

3

#### [h2]cancel

public void cancel​()

Cancels speech recognition. 

Once speech recognition is canceled, the obtained speech data will no longer be recognized. 

Before using this method, you need to call [init(ohos.ai.asr.AsrIntent,ohos.ai.asr.AsrListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__init-ohos_ai_asr_AsrIntent-ohos_ai_asr_AsrListener-) to initialize the ASR engine service.

**Since:**

3

#### [h2]destroy

public void destroy​()

Destroys the ASR service by canceling all ongoing ASR tasks. 

The destroyed ASR service can no longer be used. To use the ASR service again, you need to call [createAsrClient(ohos.app.Context)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asrclient-0000001054678731#ZH-CN_TOPIC_0000001054678731__createAsrClient-ohos_app_Context-) to create another AsrClient instance.
