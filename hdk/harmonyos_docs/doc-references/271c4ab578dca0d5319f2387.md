# Overview  
  
Provides classes to implement watch complications. 

Complication are components used to display data on the watch face.

**Since:**

5

#### Class Summary

Class | Description  
---|---  
[Complication](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complication-0000001138263643) | Defines complication data types.  
[ComplicationCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationcallback-0000001091417890) | Sends complication data to the watch face.  
[ComplicationDataRefresh](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationdatarefresh-0000001138365357) | Notifies the watch face to refresh complication data.  
[ComplicationEntity](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationentity-0000001091546376) | Provides methods related to complication data.  
[ComplicationEntity.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationentity_builder-0000001138568183) | A builder class for [ComplicationEntity](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationentity-0000001091546376) objects.  
[ComplicationProviderAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationproviderability-0000001091865966) | A base class for implementing complication data refresh.  
[ComplicationTemplate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationtemplate-0000001091706036) | Defines complication templates.  
[ListValue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listvalue-0000001138482519) | Provides methods related to a [ListValue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listvalue-0000001138482519) object.  
[RangedValue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rangedvalue-0000001138263645) | Provides methods related to a [RangedValue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rangedvalue-0000001138263645) object which consists of the maximum, minimum, and current values.
