# AsynchronousServerSocketChannel

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.nio.channels.AsynchronousServerSocketChannel
    
    public abstract class AsynchronousServerSocketChannel
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [AsynchronousChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannel-0000001054238487), [NetworkChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/networkchannel-0000001054199762)  
  
---  
An asynchronous channel for stream-oriented listening sockets. 

An asynchronous server-socket channel is created by invoking the [open](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronousserversocketchannel-0000001054358478#ZH-CN_TOPIC_0000001054358478__open-java_nio_channels_AsynchronousChannelGroup-) method of this class. A newly-created asynchronous server-socket channel is open but not yet bound. It can be bound to a local address and configured to listen for connections by invoking the [bind](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronousserversocketchannel-0000001054358478#ZH-CN_TOPIC_0000001054358478__bind-java_net_SocketAddress-int-) method. Once bound, the [accept](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronousserversocketchannel-0000001054358478#ZH-CN_TOPIC_0000001054358478__accept-A-java_nio_channels_CompletionHandler-) method is used to initiate the accepting of connections to the channel's socket. An attempt to invoke the accept method on an unbound channel will cause a [NotYetBoundException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notyetboundexception-0000001054678465) to be thrown. 

Channels of this type are safe for use by multiple concurrent threads though at most one accept operation can be outstanding at any time. If a thread initiates an accept operation before a previous accept operation has completed then an [AcceptPendingException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/acceptpendingexception-0000001054518506) will be thrown. 

Socket options are configured using the [setOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronousserversocketchannel-0000001054358478#ZH-CN_TOPIC_0000001054358478__setOption-java_net_SocketOption-T-) method. Channels of this type support the following options: 

Additional (implementation specific) options may also be supported. 

**Usage Example:**
    
    final AsynchronousServerSocketChannel listener =
          AsynchronousServerSocketChannel.open().bind(new InetSocketAddress(5000));
    
      listener.accept(null, new CompletionHandler<AsynchronousSocketChannel,Void>() {
          public void completed(AsynchronousSocketChannel ch, Void att) {
              // accept the next connection
              listener.accept(null, this);
    
              // handle this connection
              handle(ch);
          }
          public void failed(Throwable exc, Void att) {
              ...
          }
      });

#### [h2]accept

public abstract <A> void accept​(A attachment, [CompletionHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completionhandler-0000001054358476)<[AsynchronousSocketChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronoussocketchannel-0000001054119819),? super A> handler)

Accepts a connection. 

This method initiates an asynchronous operation to accept a connection made to this channel's socket. The handler parameter is a completion handler that is invoked when a connection is accepted (or the operation fails). The result passed to the completion handler is the [AsynchronousSocketChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronoussocketchannel-0000001054119819) to the new connection. 

When a new connection is accepted then the resulting AsynchronousSocketChannel will be bound to the same [AsynchronousChannelGroup](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459) as this channel. If the group is [AsynchronousChannelGroup#isShutdown](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__isShutdown--) and a connection is accepted, then the connection is closed, and the operation completes with an IOException and cause [ShutdownChannelGroupException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shutdownchannelgroupexception-0000001054119754). 

To allow for concurrent handling of new connections, the completion handler is not invoked directly by the initiating thread when a new connection is accepted immediately (see [Threading](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__threading)). 

If a security manager has been installed then it verifies that the address and port number of the connection's remote endpoint are permitted by the security manager's [SecurityManager#checkAccept](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkAccept-java_lang_String-int-) method. The permission check is performed with privileges that are restricted by the calling context of this method. If the permission check fails then the connection is closed and the operation completes with a [SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454).
