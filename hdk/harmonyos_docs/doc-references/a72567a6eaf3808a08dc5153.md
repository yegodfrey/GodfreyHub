# NotificationSorting

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationSorting
    
    public class NotificationSorting
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Provides sorting information about an active notification. 

When a new notification arrives, the sorting of existing active notifications such as their respective priority or time order will change, and the sorting information about the current notification will change accordingly. This information is only a snapshot and changes in real time. You can only obtain but cannot set information in this class.
