# CourierEx

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.eventhandler.Courier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/courier-0000001054200118) |---|---ohos.interwork.eventhandler.CourierEx
    
    public final class CourierEx
    extends [Courier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/courier-0000001054200118)  
  
---  
Represents a reference to a specific event handler. This class implements inter-process communication (IPC) based on [InnerEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/innerevent-0000001054358825) objects by creating a CourierEx that points to a specific event handler in a process and handing the CourierEx to another process.
