# DoubleUnaryOperator
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface DoubleUnaryOperator  
  
---  
Represents an operation on a single double-valued operand that produces a double-valued result. This is the primitive type specialization of [UnaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unaryoperator-0000001054518644) for double. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsDouble(double)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doubleunaryoperator-0000001054358614#ZH-CN_TOPIC_0000001054358614__applyAsDouble-double-).

**Since:**

1.8

[UnaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unaryoperator-0000001054518644)
