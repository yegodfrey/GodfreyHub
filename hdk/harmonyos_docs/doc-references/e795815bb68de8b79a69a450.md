#### [h2]getBundleInfo

[BundleInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleinfo-0000001054120052) getBundleInfo​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) bundleName, int flags) throws [RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984)

Obtains the [BundleInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleinfo-0000001054120052) based on a given bundle name. 

To use this method, you need to request the ohos.permission.GET_BUNDLE_INFO_PRIVILEGED or ohos.permission.GET_BUNDLE_INFO permission from the system. The ohos.permission.GET_BUNDLE_INFO_PRIVILEGED permission is of the signature|privileged level, and the ohos.permission.GET_BUNDLE_INFO permission is of the normal level.

Information contained in the [BundleInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleinfo-0000001054120052) object to be returned varies depending on the value of the flags parameter. 

    * 0x00000000: Returns the basic [BundleInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleinfo-0000001054120052) object.
    * 0x00000001: Returns the [BundleInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleinfo-0000001054120052) object with abilityInfo specified. 
    * Other value: Returns the same result as 0x00000000.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
bundleName  |  Indicates the application bundle name to be queried.  
flags  |  Indicates the flag used to specify information contained in the [BundleInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleinfo-0000001054120052) that will be returned.  
  
**Returns:**

Returns the [BundleInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bundleinfo-0000001054120052) object.

**Throws:**

Throw Name | Throw Description  
---|---  
[RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984) |  Throws this exception if the system failed to obtain the bundle manager service.  
[SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) |  Throws this exception if your application does not have required permissions.
