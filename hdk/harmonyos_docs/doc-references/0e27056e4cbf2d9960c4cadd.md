# Overview  
  
This package provides the classes necessary for services to interact with applications in order to retrieve information (authentication data including usernames or passwords, for example) or to display information (error and warning messages, for example).

**Since:**

JDK1.4

#### Interface Summary

Interface | Description  
---|---  
[Callback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callback-0000001054518682) |  Implementations of this interface are passed to a CallbackHandler, allowing underlying security services the ability to interact with a calling application to retrieve specific authentication data such as usernames and passwords, or to display certain information, such as error and warning messages.  
[CallbackHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callbackhandler-0000001054678670) |  An application implements a CallbackHandler and passes it to underlying security services so that they may interact with the application to retrieve specific authentication data, such as usernames and passwords, or to display certain information, such as error and warning messages.  
  
#### Class Summary

Class | Description  
---|---  
[PasswordCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/passwordcallback-0000001054558671) |  Underlying security services instantiate and pass a PasswordCallback to the handle method of a CallbackHandler to retrieve password information.  
  
#### Exception Summary

Exception | Description  
---|---  
[UnsupportedCallbackException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unsupportedcallbackexception-0000001054678639) | Signals that a CallbackHandler does not recognize a particular Callback.
