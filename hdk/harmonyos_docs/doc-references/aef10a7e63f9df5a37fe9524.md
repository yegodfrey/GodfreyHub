# Overview  
  
Reads and writes NFC tags. 

[TagInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taginfo-0000001054838920): creates tags and obtains tag information. 

[TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954): controls tag read and write. Classes for different types of tags inherit from this abstract class to control connections to tags, read data from tags, and write data to tags. 

[NfcATag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfcatag-0000001054238965): inherits from the [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) abstract class to control connections to NFC-A tags, read data from NFC-A tags, and write data to NFC-A tags. 

[IsoDepTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isodeptag-0000001054440251): inherits from the [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) abstract class to control connections to ISO-DEP tags, read data from ISO-DEP tags, and write data to ISO-DEP tags 

[MifareClassicTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mifareclassictag-0000001054518978): inherits from the [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) abstract class to control connections to Mifare Classic tags, and read data from and write data to Mifare Classic tags. 

[NdefTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ndeftag-0000001054558967): inherits from the [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) abstract class to control connections to NDEF tags, and read data from and write data to NDEF tags. 

[NdefMessage](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ndefmessage-0000001054358945): represents the NDEF message. 

[MessageRecord](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messagerecord-0000001054200238): represents the NDEF message record. 

[MifareUltralightTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mifareultralighttag-0000001054678966): inherits from the [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) abstract class to control connections to MIFARE Ultralight tags, and read data from and write data to MIFARE Ultralight tags. 

[NfcBTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfcbtag-0000001054678935): inherits from the [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) abstract class to control connections to NFC-B tags, and read data from and write data to NFC-B tags.

#### Class Summary

Class | Description  
---|---  
[IsoDepTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isodeptag-0000001054440251) | Provides interfaces to obtain IsoDepTag objects and tag information.  
[MessageRecord](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messagerecord-0000001054200238) | Represents an NDEF record.  
[MifareClassicTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mifareclassictag-0000001054518978) | Provides interfaces to create MifareClassic tags and obtain the tag information.  
[MifareUltralightTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mifareultralighttag-0000001054678966) | Provides interfaces to create a MIFARE Ultralight tag and perform I/O operations on the tag.  
[NdefMessage](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ndefmessage-0000001054358945) | Represents an NDEF message, which is a container for one or more [MessageRecord](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messagerecord-0000001054200238) objects.  
[NdefTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ndeftag-0000001054558967) | Provides interfaces to create an NdefTag object, control connections to the NDEF tag, and read data from and write data to the NDEF tag.  
[NfcATag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfcatag-0000001054238965) | Provides interfaces to control the read and write of tags that support the NFC-A technology.  
[NfcBTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfcbtag-0000001054678935) | Provides interfaces to create an NfcBTag and perform I/O operations on the tag.  
[NfcFTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfcftag-0000001071481858) | Provides methods for creating an NFC-F tag, obtaining tag information, and controlling tag read and write.  
[NfcVTag](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nfcvtag-0000001071641456) | Provides methods for creating an NFC-V tag, obtaining tag information, and controlling tag read and write.  
[TagInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taginfo-0000001054838920) | Provides tag information.  
[TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) | Controls tag read and write.
