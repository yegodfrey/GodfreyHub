Provides Serial Port Profile (SPP) server sockets. The SPP socket interface has two roles: [SppServerSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200) and [SppClientSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppclientsocket-0000001218076501). To create an [SppServerSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200), use [DataListenSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datalistensocket-0000001172398174) to create a listening SPP server. When a connection is accepted by [SppServerSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200), it returns a new [SppClientSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppclientsocket-0000001218076501) for data transmission.  The most common transmission channel of SPP is RFCOMM, which is established by Bluetooth BR/EDR. To create an RFCOMM SPP in traditional Bluetooth, use [DataListenSocket#dataListenRfcomm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datalistensocket-0000001172398174#ZH-CN_TOPIC_0000001172398174__dataListenRfcomm-java_lang_String-java_util_UUID-) or [DataListenSocket#dataListenInsecureRfcomm](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datalistensocket-0000001172398174#ZH-CN_TOPIC_0000001172398174__dataListenInsecureRfcomm-java_lang_String-java_util_UUID-). The server listens for a new BR/EDR connection.  After an [SppClientSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppclientsocket-0000001218076501) instance is created, call [accept()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppserversocket-0000001172238200#ZH-CN_TOPIC_0000001172238200__accept--) to allow for a new remote connection. An [SppClientSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sppclientsocket-0000001218076501) will be returned, from which you can obtain [InputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420) or [OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403) to read and write data. **Since:** 7Method Summary Modifier and Type | Method | Description
