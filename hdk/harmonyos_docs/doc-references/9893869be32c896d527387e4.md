Enumerated Unicode category types from the UnicodeData.txt file. Used as return results from [UCharacter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ucharacter-0000001054120112) Equivalent to icu's UCharCategory. Refer to [ Unicode Consortium](http://www.unicode.org/Public/UNIDATA/UCD.html) for more information about UnicodeData.txt.  NOTE: the UCharacterCategory values are not compatible with those returned by java.lang.Character.getType. UCharacterCategory values match the ones used in ICU4C, while java.lang.Character type values, though similar, skip the value 17.
