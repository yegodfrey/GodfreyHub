# GeoAddress  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.location.GeoAddress

Represents a data class that describes geographic locations. 

A geographic location consists of some parameters of an eXtensible Address Language (xAL) address, such as the longitude, latitude, country code, and administrative region name.

#### [h2]getDescriptions

public [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) getDescriptions​(int index)

Obtains the description identified by a specified index. 

Descriptions in the GeoAddress object are numbered from 0. The maximum number of descriptions is equal to the value set by [getDescriptionsSize()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/geoaddress-0000001054518914#ZH-CN_TOPIC_0000001054518914__getDescriptionsSize--) minus 1. If the obtained index is smaller than 0 or greater than the maximum number, the value is null, indicating that no matching index has been found.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
index  |  Specifies the index of the description, which must be greater than or equal to 0.  
  
**Returns:**

Returns the description identified by the specified index. The value is null if no matching description exists.

**Since:**

1

#### [h2]setDescriptions

public void setDescriptions​(int index, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) description) throws [IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724)

Sets the description identified by a specified index on the address list. 

Descriptions in the GeoAddress object are numbered from 0. You can modify a description identified by a specified index or append a description to the existing list. The index of the newly added description is equal to the number of descriptions obtained by [getDescriptionsSize()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/geoaddress-0000001054518914#ZH-CN_TOPIC_0000001054518914__getDescriptionsSize--).

**Parameters:**
