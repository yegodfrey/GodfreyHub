Provides abilities for you to manage and perform operations on your OS accounts.  This class provides basic account-related functions, including querying and updating the distributed information of an OS account in a distributed system, creating, removing, and starting an OS account, updating OS account information, and querying information about the current OS account or all OS accounts. The distributed information refers to the account information that is used on a distributed network.
