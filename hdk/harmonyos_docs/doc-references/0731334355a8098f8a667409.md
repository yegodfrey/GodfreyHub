# LruBuffer

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.LruBuffer<K,V>
    
    public class LruBuffer<K,V>

A cache class that uses the least recently used (LRU) algorithm to remove the least recently accessed values when the capacity is insufficient for storing new values. 

You can specify the capacity of a buffer. When the number of key-value pairs in the buffer exceeds its preset capacity, the LRU algorithm takes effect. Specifically, the least recently accessed key-value pairs will be removed to make room for new key-value pairs. You can also reset the buffer capacity. If the newly set buffer capacity is less than the number of already stored key-value pairs, the LRU algorithm is triggered to remove the least recently accessed key-value pairs. The following methods have an access token: [put(java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lrubuffer-0000001054120333#ZH-CN_TOPIC_0000001054120333__put-K-V-), [get(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lrubuffer-0000001054120333#ZH-CN_TOPIC_0000001054120333__get-K-), [contains(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lrubuffer-0000001054120333#ZH-CN_TOPIC_0000001054120333__contains-K-).If one of them has been successfully called and has executed an actual operation for a value, this value will be marked as a recently accessed value and therefore its automatic clearance upon a full buffer will be postponed. 

Most methods of this class support the synchronized mechanism and therefore can be used in multi-thread or concurrency scenarios. This class also provides the [getMatchCount()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lrubuffer-0000001054120333#ZH-CN_TOPIC_0000001054120333__getMatchCount--), [getMissCount()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lrubuffer-0000001054120333#ZH-CN_TOPIC_0000001054120333__getMissCount--), and [getPutCount()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lrubuffer-0000001054120333#ZH-CN_TOPIC_0000001054120333__getPutCount--) methods for you to obtain access statistics on stored key-value pairs, including the total numbers of matched queried key-value pairs, unmatched queried key-value pairs, and added key-value pairs. 

In addition, you can override the [afterRemoval(boolean,java.lang.Object,java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lrubuffer-0000001054120333#ZH-CN_TOPIC_0000001054120333__afterRemoval-boolean-K-V-V-) method in this class to perform subsequent operations after the stored key-value pairs are deleted or automatically cleared. Note: The buffer capacity cannot be set to 0, and the key or value cannot be null.
