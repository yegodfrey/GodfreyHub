#### [h2]onValueChanged

void onValueChanged​([DatePicker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datepicker-0000001054678716) component, int year, int monthOfYear, int dayOfMonth)

Processes date changed events of a date picker. 

This method is invoked upon a date changed event triggered by [DatePicker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datepicker-0000001054678716). It passes the latest date to process date changed events.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component (a [DatePicker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datepicker-0000001054678716) instance) associated with the listener.  
year  |  Indicates the year (0 or greater) set by the user.  
monthOfYear  |  Indicates the month (1 to 12) set by the user.  
dayOfMonth  |  Indicates the day (1 to the total days in the month) set by the user.
