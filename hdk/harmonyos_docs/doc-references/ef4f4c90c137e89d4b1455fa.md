Encapsulate an XML parse error or warning.  This module, both source code and documentation, is in the Public Domain, and comes with **NO WARRANTY**. See <http://www.saxproject.org> for further information.  This exception may include information for locating the error in the original XML document, as if it came from a [Locator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001060388844) object. Note that although the application will receive a SAXParseException as the argument to the handlers in the [ErrorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/errorhandler-0000001059908837) interface, the application is not actually required to throw the exception; instead, it can simply read the information in it and take a different action. Since this exception is a subclass of [SAXException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/saxexception-0000001060268799), it inherits the ability to wrap another exception. **Since:** SAX 1.0**See Also:** [SAXException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/saxexception-0000001060268799), [Locator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001060388844), [ErrorHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/errorhandler-0000001059908837), Constructor Summary Constructor | Description
