# ICategoryLightDataCallback  
      
    public interface ICategoryLightDataCallback
    extends [ISensorDataCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isensordatacallback-0000001054238985)<[CategoryLightData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/categorylightdata-0000001054358963),[CategoryLight](https://developer.harmonyos.com/cn/docs/documentation/doc-references/categorylight-0000001054518994)>

Inherits from [ISensorDataCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isensordatacallback-0000001054238985) and receives data of light sensors. 

This interface inherits all methods from its parent interface. When detecting any light sensor data changes, it provides data for the application layer to call.
