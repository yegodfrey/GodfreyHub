A class that can be used to compute the Adler-32 checksum of a data stream. An Adler-32 checksum is almost as reliable as a CRC-32 but can be computed much faster.  Passing a null argument to a method in this class will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown. **See Also:** [Checksum](https://developer.harmonyos.com/cn/docs/documentation/doc-references/checksum-0000001054439931)Constructor Summary Constructor | Description
