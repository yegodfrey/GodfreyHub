# CopyOption  
      
    public interface CopyOption  
  
---  
An object that configures how to copy or move a file. 

Objects of this type may be used with the [Files#copy(Path,Path,CopyOption[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__copy-java_nio_file_Path-java_nio_file_Path-java_nio_file_CopyOption___-), [Files#copy(java.io.InputStream,Path,CopyOption[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__copy-java_io_InputStream-java_nio_file_Path-java_nio_file_CopyOption___-) and [Files#move](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__move-java_nio_file_Path-java_nio_file_Path-java_nio_file_CopyOption___-) methods to configure how a file is copied or moved. 

The [StandardCopyOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardcopyoption-0000001054358487) enumeration type defines the _standard_ options.

1.7
