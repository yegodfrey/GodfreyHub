# Component.MousePointerStyleListener
    
    public static interface Component.MousePointerStyleListener  
  
---  
Provides a listener to observe mouse pointer style changes. 

In the scenario where an external mouse or touchpad is connected, implement methods to change the mouse pointer style and register a listener to observe the changes triggered when the mouse pointer is placed over a component.

#### [h2]onUpdatePointerStyle

[MousePointerStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mousepointerstyle-0000001217877943) onUpdatePointerStyle​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, [MouseEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mouseevent-0000001054200230) event)

Called when the mouse pointer style changes. 

After the listener for mouse pointer style changes is registered, the listener is called when the mouse pointer is placed over the component. You can override the method to return the mouse pointer style displayed over the component.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component that currently processes the mouse pointer style.  
event  |  Indicates the mouse event received by the component.  
  
**Returns:**

Returns a mouse pointer style displayed over the component.
