# PKCS8EncodedKeySpec

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.security.spec.EncodedKeySpec](https://developer.harmonyos.com/cn/docs/documentation/doc-references/encodedkeyspec-0000001054678519) |---|---java.security.spec.PKCS8EncodedKeySpec

    extends [EncodedKeySpec](https://developer.harmonyos.com/cn/docs/documentation/doc-references/encodedkeyspec-0000001054678519)  
  
---  
This class represents the ASN.1 encoding of a private key, encoded according to the ASN.1 type PrivateKeyInfo. The PrivateKeyInfo syntax is defined in the PKCS#8 standard as follows: 
    
    PrivateKeyInfo ::= SEQUENCE {
       version Version,
       privateKeyAlgorithm PrivateKeyAlgorithmIdentifier,
       privateKey PrivateKey,
       attributes [0] IMPLICIT Attributes OPTIONAL }
    
     Version ::= INTEGER
    
     PrivateKeyAlgorithmIdentifier ::= AlgorithmIdentifier
    
     PrivateKey ::= OCTET STRING
    
     Attributes ::= SET OF Attribute
