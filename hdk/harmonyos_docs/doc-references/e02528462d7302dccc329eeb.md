# FileWatcher  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.FileWatcher
    
    public class FileWatcher
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides the capability of monitoring status changes of a specified file directory. 

To monitor files, you need to first implement the [FileWatcher.EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filewatcher_eventhandler-0000001054559003) class that processes the events of status changes on the monitored file directory. Then, you should use the [addWatch(java.nio.file.Path,ohos.utils.FileWatcher.EventHandler,boolean,java.nio.file.WatchEvent.Kind...)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filewatcher-0000001054200276#ZH-CN_TOPIC_0000001054200276__addWatch-java_nio_file_Path-ohos_utils_FileWatcher_EventHandler-boolean-java_nio_file_WatchEvent_Kind___-) method to add the file directory to be monitored and the associated event handler. When a file in the specified directory is changed, the event handler will be triggered to process the event. 

The following events defined in [StandardWatchEventKinds](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardwatcheventkinds-0000001054119835) are supported by FileWatcher: 

    * StandardWatchEventKinds.ENTRY_CREATE
    * StandardWatchEventKinds.ENTRY_DELETE
    * StandardWatchEventKinds.ENTRY_MODIFY
