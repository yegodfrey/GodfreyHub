# InnerEvent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.eventhandler.InnerEvent
    
    public final class InnerEvent
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Defines the structure of an event that can be sent to [EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858). 

An InnerEvent object contains an extra integer field and an extra object field to carry specific data. 

The constructor of InnerEvent is private. Therefore, you need to call the [get()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/innerevent-0000001054358825#ZH-CN_TOPIC_0000001054358825__get--) method to create an InnerEvent instance. The method will pull InnerEvent instances from a pool of recycled objects.

#### [h2]eventId

public int eventId

Indicates the event ID, which identifies the event type and determines the event handler. 

Each [EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858) has a unique namespace for storing event IDs. Therefore, event IDs of different [EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858) objects do not affect each other even if the IDs are the same.
