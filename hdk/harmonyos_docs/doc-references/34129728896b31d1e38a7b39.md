# ContinuationState

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Enum](https://developer.harmonyos.com/cn/docs/documentation/doc-references/enum-0000001054838398)<[ContinuationState](https://developer.harmonyos.com/cn/docs/documentation/doc-references/continuationstate-0000001054439969)> |---|---ohos.aafwk.ability.ContinuationState
    
    public enum ContinuationState
    extends [Enum](https://developer.harmonyos.com/cn/docs/documentation/doc-references/enum-0000001054838398)<[ContinuationState](https://developer.harmonyos.com/cn/docs/documentation/doc-references/continuationstate-0000001054439969)>  
  
---  
Enumerates the migration states of an [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) that has implemented [IAbilityContinuation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitycontinuation-0000001054358657) and is in a reversible migration process that allows the ability to be migrated back. 

The following example describes state changes in a migration process: 

The initial state of FooAbility on device A is [LOCAL_RUNNING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/continuationstate-0000001054439969#ZH-CN_TOPIC_0000001054439969__LOCAL_RUNNING). If it is migrated to device B in a reversible way, its state on device A becomes [REMOTE_RUNNING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/continuationstate-0000001054439969#ZH-CN_TOPIC_0000001054439969__REMOTE_RUNNING) and that on device B becomes [REPLICA_RUNNING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/continuationstate-0000001054439969#ZH-CN_TOPIC_0000001054439969__REPLICA_RUNNING). If it is migrated to device B in a non-reversible way, its states on both devices are [LOCAL_RUNNING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/continuationstate-0000001054439969#ZH-CN_TOPIC_0000001054439969__LOCAL_RUNNING).
