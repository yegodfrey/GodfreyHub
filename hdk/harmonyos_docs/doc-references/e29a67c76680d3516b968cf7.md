# Overview  
  
Provides classes and methods for you to manage accounts of applications running the OS. 

With the application account management function, you can add or delete an application account, update account information, authorize access to an application account, and subscribe to or unsubscribe from account change events.

**Since:**

4

#### Interface Summary

Interface | Description  
---|---  
[IAppAccountSubscriber](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iappaccountsubscriber-0000001054199970) | Provides a callback to receive notifications on account change events.  
  
#### Class Summary

Class | Description  
---|---

[AppAccountAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/appaccountability-0000001054358677) | Provides methods for managing application accounts.
