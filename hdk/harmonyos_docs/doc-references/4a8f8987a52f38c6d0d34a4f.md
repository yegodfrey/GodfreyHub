# DeflaterOutputStream

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403) |---|---[java.io.FilterOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filteroutputstream-0000001054238431) |---|---|---java.util.zip.DeflaterOutputStream
    
    public class DeflaterOutputStream
    extends [FilterOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filteroutputstream-0000001054238431)  
  
---  
This class implements an output stream filter for compressing data in the "deflate" compression format. It is also used as the basis for other types of compression filters, such as GZIPOutputStream.

#### [h2]flush

public void flush​() throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Flushes the compressed output stream. If [syncFlush](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deflateroutputstream-0000001054838600#ZH-CN_TOPIC_0000001054838600__DeflaterOutputStream-java_io_OutputStream-java_util_zip_Deflater-int-boolean-) is true when this compressed output stream is constructed, this method first flushes the underlying compressor with the flush mode [Deflater#SYNC_FLUSH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deflater-0000001054238645#ZH-CN_TOPIC_0000001054238645__SYNC_FLUSH) to force all pending data to be flushed out to the output stream and then flushes the output stream. Otherwise this method only flushes the output stream without flushing the compressor.
