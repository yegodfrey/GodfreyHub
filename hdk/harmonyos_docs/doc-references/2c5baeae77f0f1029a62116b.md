# Overview  
  
Provides APIs for obtaining detailed information about media resources that have been searched for.

**Since:**

5

#### Class Summary

Class | Description  
---|---  
[AlbumList](https://developer.harmonyos.com/cn/docs/documentation/doc-references/albumlist-0000001138830339) | Represents an AlbumList object that stores album data, which can be accessed via methods provided in this class.  
[AlbumListInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/albumlistinfo-0000001138728617) | Represents an AlbumListInfo object that stores information of each photo in an album, which can be accessed via methods provided in this class.  
[FetchResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fetchresult-0000001091930954)<Type> | Represents a result set that contains either [AlbumList](https://developer.harmonyos.com/cn/docs/documentation/doc-references/albumlist-0000001138830339) or [AlbumListInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/albumlistinfo-0000001138728617) instances, and provides methods to get an instance at a specified position in the FetchResult instance.
