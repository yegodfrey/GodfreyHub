# Insets

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.render.Insets
    
    public class Insets
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Provides a wrapper class representing the offsets for the left, top, right, and bottom bounds of a rectangle. 

A positive value indicates that the bound approaches the rectangle center, while a negative value indicates that the bound moves away from the rectangle center.
