Provides various draw calls to draw 2D graphics. This class draws text, image, and basic graphics such as rectangle, circle, and line. It uses attributes in [Paint](https://developer.harmonyos.com/cn/docs/documentation/doc-references/paint-0000001054358720), such as color, paint style, and line thickness.
