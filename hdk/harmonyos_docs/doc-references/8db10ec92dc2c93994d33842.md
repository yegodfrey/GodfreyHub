# NetworkSecurityPolicy

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.security.NetworkSecurityPolicy
    
    public class NetworkSecurityPolicy
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides methods for querying network security policies. For example, you can call the [isPlaintextAccessAllowed()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/networksecuritypolicy-0000001060411197#ZH-CN_TOPIC_0000001060411197__isPlaintextAccessAllowed--) method in this class to check whether plaintext is allowed for accessing a process. 

An application can declare its network security settings in a security configuration file without modifying the code. 

Calling methods in this class has the following advantages: 

    * Secure: It determines whether to disable plaintext-based access to a specified target to prevent an application from accidentally using plaintext.
    * Convenient: An XML configuration file is used to set whether an application can access a specified domain using plaintext.

#### [h2]isPlaintextAccessAllowed

public boolean isPlaintextAccessAllowed​()

Checks whether plaintext is allowed for all network communications with this process. 

If plaintext is not allowed, the platform's components (such as HTTP and FTP stacks) will refuse plaintext HTTP requests from this process. 

Theoretically, a network security policy is needed whenever possible. However, not all components support the network security policy. An example is the java.net.Socket API, which is unable to determine whether the network traffic is plaintext. Generally, most network traffic from applications is handled by higher-level network stacks or components that support the network security policy.

**Returns:**

Returns true if plaintext is allowed for all network communications with this process; returns false otherwise.

**Since:**

3
