Enumerates the font padding strategies. Font padding is the space between the ascent and top, or between the descent and bottom. Font designers don't guarantee that all glyphs are constrained between ascent and decent, so using padding can guarantee that the upper and lower edges of the text are not clipped. **Since:** 7Enum Constant Summary Enum Constant | Description
