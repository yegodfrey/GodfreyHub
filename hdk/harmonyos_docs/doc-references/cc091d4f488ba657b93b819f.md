# PixelMapShader

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.render.Shader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746) |---|---ohos.agp.render.PixelMapShader

Draws pixelmaps into textures. 

This class inherits from [Shader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746). You can specify a tile mode for the pixelmap to draw repeated or mirrored pixelmap when the object you need to draw is larger than the shading area defined by the pixelmap shader.

#### [h2]PixelMapShader

**Parameters:**

Parameter Name | Parameter Description  
---|---  
holder  |  Indicates the pixelmap holder where the pixelmap is to be rendered into texture.  
horizontalTileMode  |  Indicates the tile mode used to shade pixelmaps in horizontal direction when the drawn object exceeds the shading area defined by the pixelmap shader.  
verticalTileMode  |  Indicates the tile mode used to shade pixelmaps in vertical direction when the drawn object exceeds the shading area defined by the pixelmap shader.
