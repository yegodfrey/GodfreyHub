# Overview  
  
Provides transition-specific classes that include methods for creating and setting the transition effect.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[TransitionScheduler.ITransitionEndListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitionscheduler_itransitionendlistener-0000001054518766) | Represents the listener for monitoring the end of a transition.  
  
#### Class Summary

Class | Description  
---|---  
[Transition](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transition-0000001054358733) | Creates and sets a transition effect.  
[TransitionAlpha](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitionalpha-0000001054558755) | Creates the fading effect alpha for a transition.  
[TransitionComponents](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitioncomponents-0000001054238753) | Sets the components for a transition, including the start or end components.  
[TransitionDefault](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitiondefault-0000001172398172) | Implements the default transition effect.  
[TransitionGroup](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitiongroup-0000001218076499) | Implements a transition group, which includes one or more transition effects that can be played sequentially or simultaneously.  
[TransitionGroup.Sequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitiongroup_sequence-0000001172238198) | const of sequence  
[TransitionMove](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitionmove-0000001054678723) | Creates the move effect for a transition.  
[TransitionRotation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitionrotation-0000001172556724) | Creates the transition rotation effect.  
[TransitionScheduler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitionscheduler-0000001054838708) | Creates a transition scheduler.  
[TransitionZoomingMove](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transitionzoomingmove-0000001060388820) | Represents the animation for a zoom move.
