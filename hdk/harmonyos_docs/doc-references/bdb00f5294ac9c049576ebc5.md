#### [h2]getSignalLevel

public int getSignalLevel​()

Obtains the number of signal bars of the LTE network. 

The number of signal bars ranges from 0 to 4 or from 0 to 5. A larger value indicates better signal quality. The maximum value (4 or 5 bars) is determined by the lower-layer configuration.

**Specified by:**

[getSignalLevel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/signalinformation-0000001054838950#ZH-CN_TOPIC_0000001054838950__getSignalLevel--) in class [SignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/signalinformation-0000001054838950)
