# Overview  
  
Provides index schemas specific to different types of data. 

The index schemas include [CommonItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commonitem-0000001078320140), [AppItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/appitem-0000001078160532), [DocumentItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documentitem-0000001120712377), [VideoItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/videoitem-0000001120847529), [MusicItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/musicitem-0000001078032070), [ContactItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/contactitem-0000001078480112), [MessageItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageitem-0000001120951637), [PhotoItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/photoitem-0000001078480114), [EmailItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/emailitem-0000001121107271), [EventItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventitem-0000001120847527), [NotepadItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notepaditem-0000001078160534), [NoticeItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/noticeitem-0000001078320142), [PlaceItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/placeitem-0000001120712379), [ActionItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/actionitem-0000001078032068). Some index fields in these index schemas are based on the fields in //schema.org.
