# JarFile  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.zip.ZipFile](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zipfile-0000001054678648) |---|---java.util.jar.JarFile
    
    public class JarFile
    extends [ZipFile](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zipfile-0000001054678648)  
  
---  
The JarFile class is used to read the contents of a jar file from any file that can be opened with java.io.RandomAccessFile. It extends the class java.util.zip.ZipFile with support for reading an optional Manifest entry. The Manifest can be used to specify meta-information about the jar file and its entries. 

Unless otherwise noted, passing a null argument to a constructor or method in this class will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown. If the verify flag is on when opening a signed jar file, the content of the file is verified against its signature embedded inside the file. Please note that the verification process does not include validating the signer's certificate. A caller should inspect the return value of [JarEntry#getCodeSigners()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/jarentry-0000001054119890#ZH-CN_TOPIC_0000001054119890__getCodeSigners--) to further determine if the signature can be trusted.
