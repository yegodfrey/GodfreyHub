# span

作为<[text](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-basic-text-0000001106708462)>子组件提供文本修饰能力。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172646.96027901556276836149305370851810:50001231000000:2800:C081E2785D40008C7EBCAB5B243852456255A0F8C9DB9009F0FB96759A91D0C8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    * 文本的展示内容需要写在元素标签内。
    * 从 API Version 6 开始支持字符串拼接操作。
      * 支持变量跟变量：{{key1}}{{key2}}等
      * 支持常量跟变量： "my name is {{name}}， i am from {{city}}." "key1 {{key1}}"

#### 子组件

支持子组件[<span>](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-basic-span-0000001152828581)。

#### 属性

支持[通用属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-common-attributes-0000001161259599)。

#### 样式

名称 | 类型 | 默认值 | 必填 | 描述  
---|---|---|---|---  
color | <color> | - | 否 | 设置文本段落的文本颜色  
font-size | <length> | 30px | 否 | 设置文本段落的文本尺寸  
font-style | string | normal | 否 | 设置文本段落的字体样式，见[text组件font-style的样式属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-basic-text-0000001106708462#ZH-CN_TOPIC_0000001130994958__zh-cn_topic_0000001153163257_s579f1e14b863476b8650d7ef39d7f1f8)。  
font-weight | number | string | normal | 否 | 设置文本段落的字体粗细，见[text组件font-weight的样式属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-basic-text-0000001106708462#ZH-CN_TOPIC_0000001130994958__zh-cn_topic_0000001153163257_s579f1e14b863476b8650d7ef39d7f1f8)。  
text-decoration | string | none | 否 | 设置文本段落的文本修饰，见[text组件text-decoration样式属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-basic-text-0000001106708462#ZH-CN_TOPIC_0000001130994958__zh-cn_topic_0000001153163257_s579f1e14b863476b8650d7ef39d7f1f8)。  
font-family | string | sans-serif | 否 | 设置文本段落的字体列表，用逗号分隔，每个字体用字体名或者字体族名设置。列表中第一个系统中存在的或者通过[自定义字体](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-service-widget-common-customizing-font-0000001115139692)指定的字体，会被选中作为文本的字体。  
  
#### 事件

不支持。
