# Overview  
  
Provides basic Bluetooth Low Energy (BLE) capabilities. 

The related classes are as follows: 

    * BleCentralManager: starts, stops, and calls back BLE scanning.
    * BlePeripheralDevice: provides the types of BLE peripheral devices and related operations.
    * BlePeripheralCallback: defines the callback used to send notifications when services are discovered or the peripheral device status changes.
    * BleScanFilter: represents the BLE scanning filter.
    * GattService: represents the Bluetooth GATT service.
    * GattCharacteristic: represents the Bluetooth GATT characteristic, which is a basic data element used to construct a GATT service.
    * GattDescriptor: represents a Bluetooth GATT descriptor, which contains additional information and attributes of a GATT characteristic.
