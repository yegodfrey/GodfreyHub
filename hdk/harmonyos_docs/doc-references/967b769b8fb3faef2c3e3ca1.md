# Owner  
      
    public interface Owner  
  
---  
Interface for managing owners of Access Control Lists (ACLs) or ACL configurations. (Note that the Acl interface in the java.security.acl package extends this Owner interface.) The initial owner Principal should be specified as an argument to the constructor of the class implementing this interface.

[Acl](https://developer.harmonyos.com/cn/docs/documentation/doc-references/acl-0000001054199806)

#### [h2]addOwner

boolean addOwner​([Principal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/principal-0000001054678520) caller, [Principal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/principal-0000001054678520) owner) throws [NotOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notownerexception-0000001054358522)

Adds an owner. Only owners can modify ACL contents. The caller principal must be an owner of the ACL in order to invoke this method. That is, only an owner can add another owner. The initial owner is configured at ACL construction time. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
caller  |  the principal invoking this method. It must be an owner of the ACL.  
owner  |  the owner that should be added to the list of owners.  
  
**Returns:**

true if successful, false if owner is already an owner.

**Throws:**

Throw Name | Throw Description  
---|---  
[NotOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notownerexception-0000001054358522) |  if the caller principal is not an owner of the ACL.  
  
#### [h2]deleteOwner

boolean deleteOwner​([Principal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/principal-0000001054678520) caller, [Principal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/principal-0000001054678520) owner) throws [LastOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lastownerexception-0000001054838488), [NotOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notownerexception-0000001054358522)

Deletes an owner. If this is the last owner in the ACL, an exception is raised.

The caller principal must be an owner of the ACL in order to invoke this method.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
caller  |  the principal invoking this method. It must be an owner of the ACL.  
owner  |  the owner to be removed from the list of owners.  
  
**Returns:**

true if the owner is removed, false if the owner is not part of the list of owners.

**Throws:**

Throw Name | Throw Description  
---|---  
[NotOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notownerexception-0000001054358522) |  if the caller principal is not an owner of the ACL.  
[LastOwnerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lastownerexception-0000001054838488) |  if there is only one owner left, so that deleteOwner would leave the ACL owner-less.
