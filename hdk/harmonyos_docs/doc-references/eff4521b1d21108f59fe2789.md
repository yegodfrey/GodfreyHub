# NumericShaper.Range

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Enum](https://developer.harmonyos.com/cn/docs/documentation/doc-references/enum-0000001054838398)<[NumericShaper.Range](https://developer.harmonyos.com/cn/docs/documentation/doc-references/numericshaper_range-0000001054358412)> |---|---java.awt.font.NumericShaper.Range
    
    public static enum NumericShaper.Range
    extends [Enum](https://developer.harmonyos.com/cn/docs/documentation/doc-references/enum-0000001054838398)<[NumericShaper.Range](https://developer.harmonyos.com/cn/docs/documentation/doc-references/numericshaper_range-0000001054358412)>  
  
---  
A NumericShaper.Range represents a Unicode range of a script having its own decimal digits. For example, the [NumericShaper.Range#THAI](https://developer.harmonyos.com/cn/docs/documentation/doc-references/numericshaper_range-0000001054358412#ZH-CN_TOPIC_0000001054358412__THAI) range has the Thai digits, THAI DIGIT ZERO (U+0E50) to THAI DIGIT NINE (U+0E59). 

The Range enum replaces the traditional bit mask-based values (e.g., [NumericShaper#ARABIC](https://developer.harmonyos.com/cn/docs/documentation/doc-references/numericshaper-0000001054238423#ZH-CN_TOPIC_0000001054238423__ARABIC)), and supports more Unicode ranges than the bit mask-based ones. For example, the following code using the bit mask: 
    
    NumericShaper.getContextualShaper(NumericShaper.ARABIC |
                                         NumericShaper.TAMIL,
                                       NumericShaper.EUROPEAN);
     

can be written using this enum as: 
    
    NumericShaper.getContextualShaper(EnumSet.of(
                                         NumericShaper.Range.ARABIC,
                                         NumericShaper.Range.TAMIL),
                                       NumericShaper.Range.EUROPEAN);
