Defines the display format of the column representing a.m. and p.m. in a [TimePicker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timepicker-0000001054119980). For example, the column can be displayed at the start or in the end of the time picker by using [START](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timepicker_ampmorder-0000001054838678#ZH-CN_TOPIC_0000001054838678__START) or [END](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timepicker_ampmorder-0000001054838678#ZH-CN_TOPIC_0000001054838678__END). The direction (left-to-right or right-to-left) of [START](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timepicker_ampmorder-0000001054838678#ZH-CN_TOPIC_0000001054838678__START) and [END](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timepicker_ampmorder-0000001054838678#ZH-CN_TOPIC_0000001054838678__END) values depends on the specified [Component.isRtl()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__isRtl--) value. If you do not want to use a relative direction, you can specify the [LEFT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timepicker_ampmorder-0000001054838678#ZH-CN_TOPIC_0000001054838678__LEFT) or [RIGHT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timepicker_ampmorder-0000001054838678#ZH-CN_TOPIC_0000001054838678__RIGHT) value for the column. **Since:** 3Enum Constant Summary Enum Constant | Description
