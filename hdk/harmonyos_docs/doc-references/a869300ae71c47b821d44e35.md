Obtains storage properties of audio and video files. The information is for audio and video recording. 
    * [getRecorderMaxDurationMs()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty-0000001054440211#ZH-CN_TOPIC_0000001054440211__getRecorderMaxDurationMs--) obtains the maximum duration (in milliseconds) of a recording session. 
    * [getRecorderMaxFileSizeBytes()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty-0000001054440211#ZH-CN_TOPIC_0000001054440211__getRecorderMaxFileSizeBytes--) obtains the maximum file size (in bytes) of a recording session. 
    * [getRecorderFd()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty-0000001054440211#ZH-CN_TOPIC_0000001054440211__getRecorderFd--) obtains the file descriptor of a file to be written. 
    * [getRecorderFile()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty-0000001054440211#ZH-CN_TOPIC_0000001054440211__getRecorderFile--) obtains a file object to be written. 
    * [getRecorderPath()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageproperty-0000001054440211#ZH-CN_TOPIC_0000001054440211__getRecorderPath--) obtains the path of an output file to be generated.
