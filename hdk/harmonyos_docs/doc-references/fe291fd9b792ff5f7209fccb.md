# ConfigManager

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.global.config.ConfigManager
    
    public abstract class ConfigManager
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Manages globalization configurations. Different types of globalization configurations declared in [ConfigType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/configtype-0000001054518860) can be obtained from ConfigManager. 

ConfigManager instances can be obtained only by using the [ResourceManager.getConfigManager()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054358863#ZH-CN_TOPIC_0000001054358863__getConfigManager--) method.
