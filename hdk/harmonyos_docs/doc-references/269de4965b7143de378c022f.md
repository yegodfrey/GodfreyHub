#### [h2]onResult

void onResult​(int result)

Called when the hop task management service is successfully connected. 

If this callback is invoked for the [IContinuationRegisterManager#register](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icontinuationregistermanager-0000001138987467#ZH-CN_TOPIC_0000001138987467__register-java_lang_String-ohos_aafwk_ability_continuation_ExtraParams-ohos_aafwk_ability_continuation_IContinuationDeviceCallback-ohos_aafwk_ability_continuation_RequestCallback-) method, the return value is the registration token assigned to the particular ability after it is successfully registered with the hop task management service.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
result  |  Indicates the result returned if the connection is successful. -1 indicates that the connection fails or the hop task management service does not exist.
