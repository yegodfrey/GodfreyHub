Method Detail [h2]getDefault public static [SocketFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketfactory-0000001054119987) getDefault​() Returns the default SSL socket factory. The first time this method is called, the security property "ssl.SocketFactory.provider" is examined. If it is non-null, a class by that name is loaded and instantiated. If that is successful and the object is an instance of SSLSocketFactory, it is made the default SSL socket factory.  Otherwise, this method returns SSLContext.getDefault().getSocketFactory().
