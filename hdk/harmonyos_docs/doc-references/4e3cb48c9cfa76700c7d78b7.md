# LongBuffer

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.nio.Buffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/buffer-0000001054119742) |---|---java.nio.LongBuffer
    
    public abstract class LongBuffer
    extends [Buffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/buffer-0000001054119742)
    implements [Comparable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparable-0000001054558443)<[LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485)>  
  
---  
A long buffer. 

This class defines four categories of operations upon long buffers: 

    * Absolute and relative [_get_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__get--) and [_put_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__put-long-) methods that read and write single longs; 

    * Relative [_bulk get_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__get-long:A-) methods that transfer contiguous sequences of longs from this buffer into an array; and

    * Relative [_bulk put_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__put-long:A-) methods that transfer contiguous sequences of longs from a long array or some other long buffer into this buffer; and 

    * Methods for [compacting](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__compact--), [duplicating](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__duplicate--), and [slicing](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__slice--) a long buffer. 

Long buffers can be created either by [_allocation_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__allocate-int-), which allocates space for the buffer's content, by [_wrapping_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__wrap-long:A-) an existing long array into a buffer, or by creating a [_view_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771#ZH-CN_TOPIC_0000001054439771__views) of an existing byte buffer. 

Like a byte buffer, a long buffer is either [_direct_ or _non-direct_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771#ZH-CN_TOPIC_0000001054439771__direct). A long buffer created via the wrap methods of this class will be non-direct. A long buffer created as a view of a byte buffer will be direct if, and only if, the byte buffer itself is direct. Whether or not a long buffer is direct may be determined by invoking the [isDirect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__isDirect--) method. 

Methods in this class that do not otherwise have a value to return are specified to return the buffer upon which they are invoked. This allows method invocations to be chained.

1.4

#### [h2]wrap

public static [LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485) wrap​(long[] array, int offset, int length)

Wraps a long array into a buffer. 

The new buffer will be backed by the given long array; that is, modifications to the buffer will cause the array to be modified and vice versa. The new buffer's capacity will be array.length, its position will be offset, its limit will be offset + length, and its mark will be undefined. Its [backing array](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__array--) will be the given array, and its [array offset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485#ZH-CN_TOPIC_0000001054238485__arrayOffset--) will be zero. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
array  |  The array that will back the new buffer  
offset  |  The offset of the subarray to be used; must be non-negative and no larger than array.length. The new buffer's position will be set to this value.  
length  |  The length of the subarray to be used; must be non-negative and no larger than array.length - offset. The new buffer's limit will be set to offset + length.

#### [h2]slice

public abstract [LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485) slice​()

Creates a new long buffer whose content is a shared subsequence of this buffer's content. 

The content of the new buffer will start at this buffer's current position. Changes to this buffer's content will be visible in the new buffer, and vice versa; the two buffers' position, limit, and mark values will be independent. 

The new buffer's position will be zero, its capacity and its limit will be the number of longs remaining in this buffer, and its mark will be undefined. The new buffer will be direct if, and only if, this buffer is direct, and it will be read-only if, and only if, this buffer is read-only. 

**Returns:**

The new long buffer

#### [h2]get

public [LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485) get​(long[] dst, int offset, int length)

Relative bulk _get_ method. 

This method transfers longs from this buffer into the given destination array. If there are fewer longs remaining in the buffer than are required to satisfy the request, that is, if length > remaining(), then no longs are transferred and a [BufferUnderflowException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bufferunderflowexception-0000001054119744) is thrown. 

Otherwise, this method copies length longs from this buffer into the given array, starting at the current position of this buffer and at the given offset in the array. The position of this buffer is then incremented by length. 

In other words, an invocation of this method of the form src.get(dst, off, len) has exactly the same effect as the loop 
    
    for (int i = off; i < off + len; i++)
             dst[i] = src.get():
     

except that it first checks that there are sufficient longs in this buffer and it is potentially much more efficient. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
dst  |  The array into which longs are to be written  
offset  |  The offset within the array of the first long to be written; must be non-negative and no larger than dst.length  
length  |  The maximum number of longs to be written to the given array; must be non-negative and no larger than dst.length - offset  
  
**Returns:**

This buffer

**Throws:**

Throw Name | Throw Description  
---|---  
[BufferUnderflowException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bufferunderflowexception-0000001054119744) |  If there are fewer than length longs remaining in this buffer  
[IndexOutOfBoundsException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/indexoutofboundsexception-0000001054558453) |  If the preconditions on the offset and length parameters do not hold

#### [h2]put

public [LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485) put​([LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485) src)

Relative bulk _put_ method _(optional operation)_. 

This method transfers the longs remaining in the given source buffer into this buffer. If there are more longs remaining in the source buffer than in this buffer, that is, if src.remaining() > remaining(), then no longs are transferred and a [BufferOverflowException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bufferoverflowexception-0000001054119815) is thrown. 

Otherwise, this method copies _n_ = src.remaining() longs from the given buffer into this buffer, starting at each buffer's current position. The positions of both buffers are then incremented by _n_. 

In other words, an invocation of this method of the form dst.put(src) has exactly the same effect as the loop 
    
    while (src.hasRemaining())
             dst.put(src.get()); 

except that it first checks that there is sufficient space in this buffer and it is potentially much more efficient.

Parameter Name | Parameter Description  
---|---  
src  |  The source buffer from which longs are to be read; must not be this buffer  
  
**Returns:**

This buffer

**Throws:**

#### [h2]put

public [LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485) put​(long[] src, int offset, int length)

Relative bulk _put_ method _(optional operation)_. 

This method transfers longs into this buffer from the given source array. If there are more longs to be copied from the array than remain in this buffer, that is, if length > remaining(), then no longs are transferred and a [BufferOverflowException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bufferoverflowexception-0000001054119815) is thrown. 

Otherwise, this method copies length longs from the given array into this buffer, starting at the given offset in the array and at the current position of this buffer. The position of this buffer is then incremented by length. 

In other words, an invocation of this method of the form dst.put(src, off, len) has exactly the same effect as the loop 
    
    for (int i = off; i < off + len; i++)
             dst.put(a[i]);
     

except that it first checks that there is sufficient space in this buffer and it is potentially much more efficient.

#### [h2]compact

public abstract [LongBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longbuffer-0000001054238485) compact​()

Compacts this buffer _(optional operation)_. 

The longs between the buffer's current position and its limit, if any, are copied to the beginning of the buffer. That is, the long at index _p_ = position() is copied to index zero, the long at index _p_ \+ 1 is copied to index one, and so forth until the long at index limit() - 1 is copied to index _n_ = limit() - 1 - _p_. The buffer's position is then set to _n+1_ and its limit is set to its capacity. The mark, if defined, is discarded. 

The buffer's position is set to the number of longs copied, rather than to zero, so that an invocation of this method can be followed immediately by an invocation of another relative _put_ method.

This buffer
