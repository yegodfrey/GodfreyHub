Provides the oneshot timer function. There are two types of oneshot timers. The difference lies in the action after a oneshot timer goes off. The system sends an [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019) object to an application, or invokes the [ITimerListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_itimerlistener-0000001054518966) callback. **Since:** 1Method Summary Modifier and Type | Method | Description
