#### [h2]createRationalFromString

public static [RationalNumber](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rationalnumber-0000001054838960) createRationalFromString​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) rationalString) throws [NumberFormatException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/numberformatexception-0000001054439739)

Creates a RationalNumber object based on a given string. 

The given string must be in the format <i>Numerator</i>/<i>Denominator</i>, for example, 3/5. To create an object representing an NaN value, pass NaN to this method. To create an object representing a positive infinity value, pass PositiveInfinity. To create an object representing a negative infinity value, pass NegativeInfinity.

**Parameters:**

**Returns:**
