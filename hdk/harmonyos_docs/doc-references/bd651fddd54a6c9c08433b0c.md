# PipeFileWriter  
      
    public interface PipeFileWriter<T>  
  
---  
Provides methods that can be called by background threads to write data into a pipe. 

You must implement this interface first if you want to call {@link ohos.aafwk.ability.Ability#createPipeFile(Uri, String, PacMap, T, PipeFileWriter Ability#createPipeFile(Uri, String, PacMap, T, PipeFileWriter} to transmit pipe data.

#### [h2]write

void write​([FileDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filedescriptor-0000001054119688) output, [Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009) uri, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) mimeType, [PacMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pacmap-0000001054440291) pacMap, [T](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pipefilewriter-0000001060039121) args)

Called by a background thread to write data into a pipe identified by the specified FileDescriptor. 

**Note:** The calling background thread may be blocked if data reading on the client is slow.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
output  |  Indicates the FileDescriptor object into which the data is to be written. The system will close this object after it returns from this method.  
uri  |  Indicates the source Uri object whose data will be written.  
mimeType  |  Indicates the MIME type of the data to write.  
pacMap  |  Indicates the [PacMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pacmap-0000001054440291) object containing the additional parameters to be passed in this call. This parameter can be null.  
args  |  Indicates the custom parameters that specify the data shared to the client. The type of this parameter is the same as the generic type in PipeFileWriter<T>.
