Implements the alignment style, which allows you to specify the text alignment mode for a section. To perform text alignment, you need to add the alignment style to the [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706) object. This API applies only to horizontal text alignment.
