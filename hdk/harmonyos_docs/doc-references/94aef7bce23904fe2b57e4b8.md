# IntStream
    
    public interface IntStream
    extends [BaseStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basestream-0000001054238641)<[Integer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/integer-0000001054119702),[IntStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intstream-0000001054119971)>  
  
---  
A sequence of primitive int-valued elements supporting sequential and parallel aggregate operations. This is the int primitive specialization of [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656). 

The following example illustrates an aggregate operation using [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and [IntStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intstream-0000001054119971), computing the sum of the weights of the red widgets: 
    
    int sum = widgets.stream()
                          .filter(w -> w.getColor() == RED)
                          .mapToInt(w -> w.getWeight())
                          .sum();
     

See the class documentation for [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and the package documentation for [java.util.stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621) for additional specification of streams, stream operations, stream pipelines, and parallelism.

#### [h2]iterate

static [IntStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intstream-0000001054119971) iterate​(int seed, [IntUnaryOperator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intunaryoperator-0000001054238627) f)

Returns an infinite sequential ordered IntStream produced by iterative application of a function f to an initial element seed, producing a Stream consisting of seed, f(seed), f(f(seed)), etc. 

The first element (position 0) in the IntStream will be the provided seed. For n > 0, the element at position n, will be the result of applying the function f to the element at position n - 1.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
seed  |  the initial element  
f  |  a function to be applied to the previous element to produce a new element  
  
**Returns:**

A new sequential IntStream

#### [h2]concat

static [IntStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intstream-0000001054119971) concat​([IntStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intstream-0000001054119971) a, [IntStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intstream-0000001054119971) b)

Creates a lazily concatenated stream whose elements are all the elements of the first stream followed by all the elements of the second stream. The resulting stream is ordered if both of the input streams are ordered, and parallel if either of the input streams is parallel. When the resulting stream is closed, the close handlers for both input streams are invoked. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
a  |  the first stream  
b  |  the second stream  
  
**Returns:**

the concatenation of the two input streams
