# ProcessBuilder

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.lang.ProcessBuilder
    
    public final class ProcessBuilder
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
This class is used to create operating system processes. 

Each ProcessBuilder instance manages a collection of process attributes. The [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) method creates a new [Process](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447) instance with those attributes. The [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) method can be invoked repeatedly from the same instance to create new subprocesses with identical or related attributes. 

Each process builder manages these process attributes: 

    * a _command_ , a list of strings which signifies the external program file to be invoked and its arguments, if any. Which string lists represent a valid operating system command is system-dependent. For example, it is common for each conceptual argument to be an element in this list, but there are operating systems where programs are expected to tokenize command line strings themselves - on such a system a Java implementation might require commands to contain exactly two elements. 
    * an _environment_ , which is a system-dependent mapping from _variables_ to _values_. The initial value is a copy of the environment of the current process (see [System#getenv()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__getenv--)). 
    * a _working directory_. The default value is the current working directory of the current process, usually the directory named by the system property user.dir. 
    * _a source of _standard input__. By default, the subprocess reads input from a pipe. Java code can access this pipe via the output stream returned by [Process#getOutputStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getOutputStream--). However, standard input may be redirected to another source using [redirectInput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__redirectInput-java_lang_ProcessBuilder_Redirect-). In this case, [Process#getOutputStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getOutputStream--) will return a _null output stream_ , for which: 
      * the [OutputStream#write(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403#ZH-CN_TOPIC_0000001054678403__write-int-) methods always throw IOException 
      * the [OutputStream#close()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403#ZH-CN_TOPIC_0000001054678403__close--) method does nothing 
    * _a destination for _standard output_ and _standard error__. By default, the subprocess writes standard output and standard error to pipes. Java code can access these pipes via the input streams returned by [Process#getInputStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getInputStream--) and [Process#getErrorStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getErrorStream--). However, standard output and standard error may be redirected to other destinations using [redirectOutput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__redirectOutput-java_lang_ProcessBuilder_Redirect-) and [redirectError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__redirectError-java_lang_ProcessBuilder_Redirect-). In this case, [Process#getInputStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getInputStream--) and/or [Process#getErrorStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getErrorStream--) will return a _null input stream_ , for which: 
      * the [InputStream#read()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420#ZH-CN_TOPIC_0000001054358420__read--) methods always return -1 
      * the [InputStream#available()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420#ZH-CN_TOPIC_0000001054358420__available--) method always returns 0 
      * the [InputStream#close()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420#ZH-CN_TOPIC_0000001054358420__close--) method does nothing 
    * a _redirectErrorStream_ property. Initially, this property is false, meaning that the standard output and error output of a subprocess are sent to two separate streams, which can be accessed using the [Process#getInputStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getInputStream--) and [Process#getErrorStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getErrorStream--) methods. 

If the value is set to true, then: 

      * standard error is merged with the standard output and always sent to the same destination (this makes it easier to correlate error messages with the corresponding output) 
      * the common destination of standard error and standard output can be redirected using [redirectOutput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__redirectOutput-java_lang_ProcessBuilder_Redirect-)
      * any redirection set by the [redirectError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__redirectError-java_lang_ProcessBuilder_Redirect-) method is ignored when creating a subprocess 
      * the stream returned from [Process#getErrorStream()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447#ZH-CN_TOPIC_0000001054558447__getErrorStream--) will always be a null input stream

Modifying a process builder's attributes will affect processes subsequently started by that object's [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) method, but will never affect previously started processes or the Java process itself. 

Most error checking is performed by the [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) method. It is possible to modify the state of an object so that [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) will fail. For example, setting the command attribute to an empty list will not throw an exception unless [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) is invoked. 

**Note that this class is not synchronized.** If multiple threads access a ProcessBuilder instance concurrently, and at least one of the threads modifies one of the attributes structurally, it _must_ be synchronized externally. 

Starting a new process which uses the default working directory and environment is easy: 
    
    Process p = new ProcessBuilder("myCommand", "myArg").start();
     

Here is an example that starts a process with a modified working directory and environment, and redirects standard output and error to be appended to a log file: 
    
    ProcessBuilder pb =
       new ProcessBuilder("myCommand", "myArg1", "myArg2");
     Map<String, String> env = pb.environment();
     env.put("VAR1", "myValue");
     env.remove("OTHERVAR");
     env.put("VAR2", env.get("VAR1") + "suffix");
     pb.directory(new File("myDir"));
     File log = new File("log");
     pb.redirectErrorStream(true);
     pb.redirectOutput(Redirect.appendTo(log));
     Process p = pb.start();
     assert pb.redirectInput() == Redirect.PIPE;
     assert pb.redirectOutput().file() == log;
     assert p.getInputStream().read() == -1;
     

To start a process with an explicit set of environment variables, first call [Map.clear()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/map-0000001054199858#ZH-CN_TOPIC_0000001054199858__clear--) before adding environment variables.

#### [h2]environment

public [Map](https://developer.harmonyos.com/cn/docs/documentation/doc-references/map-0000001054199858)<[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460),[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460)> environment​()

Returns a string map view of this process builder's environment. Whenever a process builder is created, the environment is initialized to a copy of the current process environment (see [System#getenv()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__getenv--)). Subprocesses subsequently started by this object's [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) method will use this map as their environment. 

The returned object may be modified using ordinary [Map](https://developer.harmonyos.com/cn/docs/documentation/doc-references/map-0000001054199858) operations. These modifications will be visible to subprocesses started via the [start()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__start--) method. Two ProcessBuilder instances always contain independent process environments, so changes to the returned map will never be reflected in any other ProcessBuilder instance or the values returned by [System#getenv](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__getenv-java_lang_String-). 

If the system does not support environment variables, an empty map is returned. 

The returned map does not permit null keys or values. Attempting to insert or query the presence of a null key or value will throw a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710). Attempting to query the presence of a key or value which is not of type [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) will throw a [ClassCastException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/classcastexception-0000001054678419). 

The behavior of the returned map is system-dependent. A system may not allow modifications to environment variables or may forbid certain variable names or values. For this reason, attempts to modify the map may fail with [UnsupportedOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unsupportedoperationexception-0000001054238453) or [IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) if the modification is not permitted by the operating system. 

Since the external format of environment variable names and values is system-dependent, there may not be a one-to-one mapping between them and Java's Unicode strings. Nevertheless, the map is implemented in such a way that environment variables which are not modified by Java code will have an unmodified native representation in the subprocess. 

The returned map and its collection views may not obey the general contract of the [Object#equals](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446#ZH-CN_TOPIC_0000001054678446__equals-java_lang_Object-) and [Object#hashCode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446#ZH-CN_TOPIC_0000001054678446__hashCode--) methods. 

The returned map is typically case-sensitive on all platforms. 

If a security manager exists, its [SecurityManager#checkPermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkPermission-java_security_Permission-) method is called with a [RuntimePermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimepermission-0000001054358434)("getenv.*") permission. This may result in a [SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) being thrown. 

When passing information to a Java subprocess, [system properties](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__EnvironmentVSSystemProperties) are generally preferred over environment variables.

#### [h2]start

public [Process](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447) start​() throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Starts a new process using the attributes of this process builder. 

The new process will invoke the command and arguments given by [command()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__command--), in a working directory as given by [directory()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__directory--), with a process environment as given by [environment()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__environment--). 

This method checks that the command is a valid operating system command. Which commands are valid is system-dependent, but at the very least the command must be a non-empty list of non-null strings. 

A minimal set of system dependent environment variables may be required to start a process on some operating systems. As a result, the subprocess may inherit additional environment variable settings beyond those in the process builder's [environment()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__environment--). 

If there is a security manager, its [SecurityManager#checkExec](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkExec-java_lang_String-) method is called with the first component of this object's command array as its argument. This may result in a [SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) being thrown. 

Starting an operating system process is highly system-dependent. Among the many things that can go wrong are: 

    * The operating system program file was not found. 
    * Access to the program file was denied. 
    * The working directory does not exist. 

In such cases an exception will be thrown. The exact nature of the exception is system-dependent, but it will always be a subclass of [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426). 

Subsequent modifications to this process builder will not affect the returned [Process](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447).

**Returns:**

a new [Process](https://developer.harmonyos.com/cn/docs/documentation/doc-references/process-0000001054558447) object for managing the subprocess

**Throws:**

---|---  
[NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) |  if an element of the command list is null  
[IndexOutOfBoundsException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/indexoutofboundsexception-0000001054558453) |  if the command is an empty list (has size 0)  
[SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) |  if a security manager exists and 
    * its [SecurityManager#checkExec](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkExec-java_lang_String-) method doesn't allow creation of the subprocess, or 
    * the standard input to the subprocess was [redirected from a file](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processbuilder-0000001054238445#ZH-CN_TOPIC_0000001054238445__redirectInput-java_lang_ProcessBuilder_Redirect-) and the security manager's [SecurityManager#checkRead](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securitymanager-0000001054119775#ZH-CN_TOPIC_0000001054119775__checkRead-java_io_FileDescriptor-) method denies read access to the file, or
