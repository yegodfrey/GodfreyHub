# PageSlider.PageChangedListener
    
    public static interface PageSlider.PageChangedListener  
  
---  
Provides a listener to observe page change events. 

This interface is triggered when the selected page is changed.

#### [h2]onPageSliding

void onPageSliding​(int itemPos, float itemPosOffset, int itemPosOffsetPixels)

Called when the page is sliding. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
itemPos  |  Indicates the position index of the displayed page.  
itemPosOffset  |  Indicates the position offset of the page. The value range is (0, 1]. 0 indicates that the same page is being displayed; 1 indicates that the target page is being displayed.  
itemPosOffsetPixels  |  Indicates the number of position offset pixels of the displayed page.
