# NotificationRequest.NotificationMediaContent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationRequest.NotificationMediaContent
    
    public static final class NotificationRequest.NotificationMediaContent

    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)

Constructs a media playback notification that can interact with associated audio sessions. 

Before constructing this notification, you should first initialize a NotificationMediaContent object, and call [setAVToken(ohos.media.common.sessioncore.AVToken)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationmediacontent-0000001054678811#ZH-CN_TOPIC_0000001054678811__setAVToken-ohos_media_common_sessioncore_AVToken-) to attach an AVToken to it for setting up an interaction channel with the associated [AVSession](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avsession-0000001054838902). You can call [setShownActions(int[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationmediacontent-0000001054678811#ZH-CN_TOPIC_0000001054678811__setShownActions-int:A-) to request the [NotificationActionButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationactionbutton-0000001054120169) objects to be displayed in this notification. Then, you should initialize a [NotificationRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854) object and call [NotificationRequest#setContent(NotificationContent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__setContent-ohos_event_notification_NotificationRequest_NotificationContent-) to set it to a media playback notification and attach the previously constructed NotificationMediaContent object to it. Additionally, you should call [NotificationRequest#addActionButton(NotificationActionButton)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__addActionButton-ohos_event_notification_NotificationActionButton-) so that media control buttons will be displayed in this notification after it is published.

#### [h2]setShownActions

public [NotificationRequest.NotificationMediaContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationmediacontent-0000001054678811) setShownActions​(int[] actions)

Sets up to three [NotificationActionButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationactionbutton-0000001054120169) objects to be shown in this media playback notification. 

Before publishing this notification, you should also call [NotificationRequest#addActionButton(NotificationActionButton)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__addActionButton-ohos_event_notification_NotificationActionButton-) to add specified NotificationActionButton objects for this notification so that this method can take effect. The added action buttons will be assigned sequence numbers in the order they were added. The sequence numbers specified in the value of actions for this method must match those assigned to added action buttons. Otherwise, the notification will fail to publish. By default, the sequence number starts from 0. If you want to show three action buttons, the value of actions should be 0, 1, 2.

**Parameters:**

actions  |  Indicates the list of sequence numbers representing the [NotificationActionButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationactionbutton-0000001054120169) objects to be shown in this notification.
