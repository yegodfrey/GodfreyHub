# PickFilesParams
    
    public interface PickFilesParams  
  
---

#### [h2]isLiveMedia

boolean isLiveMedia​()

Checks whether the to-be-selected file (for example, photos taken with cameras) contains live media content. You can call [getMimeTypes()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pickfilesparams-0000001138728605#ZH-CN_TOPIC_0000001138728605__getMimeTypes--) to obtain the MIME types suitable for the live media content. 

**Returns:**

Returns true if the file contains live media content; returns false otherwise.

**Since:**

5
