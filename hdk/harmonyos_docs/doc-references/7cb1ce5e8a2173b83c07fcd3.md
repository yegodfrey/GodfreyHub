# Exchanger

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.concurrent.Exchanger<V>
    
    public class Exchanger<V>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A synchronization point at which threads can pair and swap elements within pairs. Each thread presents some object on entry to the [exchange](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exchanger-0000001054838566#ZH-CN_TOPIC_0000001054838566__exchange-V-) method, matches with a partner thread, and receives its partner's object on return. An Exchanger may be viewed as a bidirectional form of a [SynchronousQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/synchronousqueue-0000001054439901). Exchangers may be useful in applications such as genetic algorithms and pipeline designs. 

**Sample Usage:** Here are the highlights of a class that uses an Exchanger to swap buffers between threads so that the thread filling the buffer gets a freshly emptied one when it needs it, handing off the filled one to the thread emptying the buffer. 
    
    class FillAndEmpty {
       Exchanger<DataBuffer> exchanger = new Exchanger<DataBuffer>();
       DataBuffer initialEmptyBuffer = ... a made-up type
       DataBuffer initialFullBuffer = ...
    
       class FillingLoop implements Runnable {
         public void run() {
           DataBuffer currentBuffer = initialEmptyBuffer;
           try {
             while (currentBuffer != null) {
               addToBuffer(currentBuffer);
               if (currentBuffer.isFull())
                 currentBuffer = exchanger.exchange(currentBuffer);
             }
           } catch (InterruptedException ex) { ... handle ... }
         }
       }
    
       class EmptyingLoop implements Runnable {
         public void run() {
           DataBuffer currentBuffer = initialFullBuffer;
           try {
             while (currentBuffer != null) {
               takeFromBuffer(currentBuffer);
               if (currentBuffer.isEmpty())
                 currentBuffer = exchanger.exchange(currentBuffer);
             }
           } catch (InterruptedException ex) { ... handle ...}
         }
       }
    
       void start() {
         new Thread(new FillingLoop()).start();
         new Thread(new EmptyingLoop()).start();
       }
     }

Memory consistency effects: For each pair of threads that successfully exchange objects via an Exchanger, actions prior to the exchange() in each thread [_happen-before_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054558607#ZH-CN_TOPIC_0000001054558607__MemoryVisibility) those subsequent to a return from the corresponding exchange() in the other thread.

#### [h2]exchange

public [V](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exchanger-0000001054838566) exchange​([V](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exchanger-0000001054838566) x) throws [InterruptedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/interruptedexception-0000001054678421)

Waits for another thread to arrive at this exchange point (unless the current thread is [Thread#interrupt](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__interrupt--)), and then transfers the given object to it, receiving its object in return. 

If another thread is already waiting at the exchange point then it is resumed for thread scheduling purposes and receives the object passed in by the current thread. The current thread returns immediately, receiving the object passed to the exchange by that other thread. 

If no other thread is already waiting at the exchange then the current thread is disabled for thread scheduling purposes and lies dormant until one of two things happens: 

    * Some other thread enters the exchange; or 
    * Some other thread [Thread#interrupt](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__interrupt--) the current thread. 

If the current thread: 

    * has its interrupted status set on entry to this method; or 
    * is [Thread#interrupt](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__interrupt--) while waiting for the exchange, 
then [InterruptedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/interruptedexception-0000001054678421) is thrown and the current thread's interrupted status is cleared.

#### [h2]exchange

public [V](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exchanger-0000001054838566) exchange​([V](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exchanger-0000001054838566) x, long timeout, [TimeUnit](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timeunit-0000001054838570) unit) throws [InterruptedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/interruptedexception-0000001054678421), [TimeoutException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timeoutexception-0000001054678618)

Waits for another thread to arrive at this exchange point (unless the current thread is [Thread#interrupt](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__interrupt--) or the specified waiting time elapses), and then transfers the given object to it, receiving its object in return. 

If another thread is already waiting at the exchange point then it is resumed for thread scheduling purposes and receives the object passed in by the current thread. The current thread returns immediately, receiving the object passed to the exchange by that other thread. 

If no other thread is already waiting at the exchange then the current thread is disabled for thread scheduling purposes and lies dormant until one of three things happens: 

    * Some other thread enters the exchange; or 
    * Some other thread [Thread#interrupt](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__interrupt--) the current thread; or 
    * The specified waiting time elapses. 

If the current thread: 

    * has its interrupted status set on entry to this method; or 
    * is [Thread#interrupt](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__interrupt--) while waiting for the exchange, 
then [InterruptedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/interruptedexception-0000001054678421) is thrown and the current thread's interrupted status is cleared. 

If the specified waiting time elapses then [TimeoutException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timeoutexception-0000001054678618) is thrown. If the time is less than or equal to zero, the method will not wait at all.
