An annotation used to indicate what annotation types an annotation processor supports. The [Processor.getSupportedAnnotationTypes()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processor-0000001170214349#ZH-CN_TOPIC_0000001170214349__getSupportedAnnotationTypes--) method can construct its result from the value of this annotation, as done by [AbstractProcessor.getSupportedAnnotationTypes()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractprocessor-0000001170334455#ZH-CN_TOPIC_0000001170334455__getSupportedAnnotationTypes--).
