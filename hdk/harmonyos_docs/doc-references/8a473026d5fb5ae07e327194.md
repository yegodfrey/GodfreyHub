# ItemTouchExpandCallback  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.listcomponent.ItemTouchExpandCallback
    
    public abstract class ItemTouchExpandCallback
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
  
Functions as a bridge between users and the [ItemTouchExpand](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemtouchexpand-0000001217996523) object.

You can use this class to customize the behavior of the ItemTouchExpand object, for example, dragging or swiping. A callback is invoked when the customized behavior is executed.

public long getAnimationTimePeriod​([ListComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listcomponent-0000001218157973) listContainer, int animationType, float xCoordinateOffset, float yCoordinateOffset)

Obtains the duration of an animation.

This method is called by the ItemTouchCallback instance when the operation on a component is complete.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
listContainer | Indicates the ListComponent bound to the ItemTouchExpand instance.  
animationType | Indicates the animation type, which can be [ItemTouchExpand#DRAG_ANIMATION_TYPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemtouchexpand-0000001217996523#ZH-CN_TOPIC_0000001217996523__DRAG_ANIMATION_TYPE), [ItemTouchExpand#SWIPE_CANCEL_ANIMATION_TYPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemtouchexpand-0000001217996523#ZH-CN_TOPIC_0000001217996523__SWIPE_CANCEL_ANIMATION_TYPE), or [ItemTouchExpand#SWIPE_SUCCESS_ANIMATION_TYPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itemtouchexpand-0000001217996523#ZH-CN_TOPIC_0000001217996523__SWIPE_SUCCESS_ANIMATION_TYPE).  
xCoordinateOffset | Indicates the distance that the animation will move in the horizontal direction.  
yCoordinateOffset | Indicates the distance that the animation will move in the vertical direction.  
  
**Returns:**

Returns the duration if obtained; returns 0 if an exception occurs.
