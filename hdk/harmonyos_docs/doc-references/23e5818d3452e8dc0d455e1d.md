# NetStatusCallback

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.net.NetStatusCallback

    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides interfaces to listen for status changes of data networks. 

You can register a child class that inherits this class to listen for status changes of data networks.
