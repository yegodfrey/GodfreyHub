# IDataAbilityObserver  
      
    public interface IDataAbilityObserver  
  
---  
Registers an observer for monitoring specified data. 

[IDataAbilityObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idataabilityobserver-0000001054558679) provides a callback method [onChange()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idataabilityobserver-0000001054558679#ZH-CN_TOPIC_0000001054558679__onChange--). After you implement this interface and override the callback method, you can call the [DataAbilityHelper#registerObserver(Uri, IDataAbilityObserver)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681#ZH-CN_TOPIC_0000001054558681__registerObserver-ohos_utils_net_Uri-ohos_aafwk_ability_IDataAbilityObserver-) method to register an observer for data monitoring. The [onChange()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idataabilityobserver-0000001054558679#ZH-CN_TOPIC_0000001054558679__onChange--) method will be called if data matching the given [Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009) changes.
