# FilterWriter

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710) |---|---java.io.FilterWriter
    
    public abstract class FilterWriter
    extends [Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710)  
  
---  
Abstract class for writing filtered character streams. The abstract class FilterWriter itself provides default methods that pass all requests to the contained stream. Subclasses of FilterWriter should override some of these methods and may also provide additional methods and fields.

**Since:**

JDK1.1
