#### [h2]withInterruptionAllowed

public [DataAbilityOperation.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityoperation_builder-0000001054678649) withInterruptionAllowed​(boolean interrupted)

Sets an interrupt flag bit for a batch operation, which can be insert, update, delete, or assert. 

You can override the [Ability#executeBatch(ArrayList)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__executeBatch-java_util_ArrayList-) method in your Data ability class to check whether the interrupted flag bit allows operation interruption. If operation interruption is allowed, you can then call the [RdbStore.giveConnectionTemporarily(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstore-0000001054518828#ZH-CN_TOPIC_0000001054518828__giveConnectionTemporarily-long-) method to release the connection to the database, thereby allowing other operations to access the database.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
interrupted  |  Specifies whether a batch operation can be interrupted. The value true indicates that the operation can be interrupted, and false indicates the opposite.  
  
**Returns:**

Returns a DataAbilityOperation.Builder object containing the given interrupted parameter.

**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  Throws this exception if mType is invalid.
