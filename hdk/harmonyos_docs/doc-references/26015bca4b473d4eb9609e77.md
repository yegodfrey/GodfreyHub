# Overview  
  
Defines the hardware capabilities and software capabilities used in the system. 

The standard capability name is in the format of **SystemCapability**._xxx_._xxx_ , **SystemCapability**._xxx_._xxx_._xxx_ for example, SystemCapability.PowerMgr.BatteryManager for SystemCapability.PowerMgr.BATTERY_MANAGER and SystemCapability.Data.Preferences for SystemCapability.Data.PREFERENCES.

**Since:**

5
