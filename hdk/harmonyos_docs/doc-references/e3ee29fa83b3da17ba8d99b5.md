# DownloadConfig

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.miscservices.download.DownloadConfig

Defines configuration of download sessions. 

This class provides parameters for download session configuration, such as URIs, network types, storage paths, and DownloadConfig. 

Use [DownloadConfig.Builder#Builder(Context, Uri)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/downloadconfig_builder-0000001054678950#ZH-CN_TOPIC_0000001054678950__Builder-ohos_app_Context-ohos_utils_net_Uri-) to create a Builder using the parameters. Example code: 
    
    DownloadConfig.Builder builder = new DownloadConfig.Builder(Context,DOWNLOAD_URI);
     builder.setTitle("Download")
     DownloadConfig config = builder.build();
