# Overview  
  
Provides interfaces for encoding and decoding audio and video data. Encoding refers to a process of converting audio signals or videos from one format to another by using a compression technology. Decoding refers to the process of restoring audio or video data to its original format by using a decompression technology.

**Since:**

1
