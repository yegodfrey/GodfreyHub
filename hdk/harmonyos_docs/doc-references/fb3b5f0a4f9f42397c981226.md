# Overview  
  
Provides classes dedicated to computer vision (CV) text detection, including data structure, configuration, key, and interface classes.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[ITextDetector](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itextdetector-0000001054200044) | Detects and recognizes text in a given image, also known as Optical Character Recognition(OCR).  
  
#### Class Summary

Class | Description  
---|---  
[Text](https://developer.harmonyos.com/cn/docs/documentation/doc-references/text-0000001054678772) | Stores the detection results of text in a given image.  
[TextBlock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textblock-0000001054358751) | Stores the detection result of text blocks.  
[TextConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textconfiguration-0000001054558773) | Configures parameters for [Text](https://developer.harmonyos.com/cn/docs/documentation/doc-references/text-0000001054678772).  
[TextConfiguration.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textconfiguration_builder-0000001054238771) | A nested class used to create a [TextConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textconfiguration-0000001054558773) object.  
[TextDetectType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textdetecttype-0000001054678741) | Enumerates text detection types.  
[TextElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textelement-0000001054838726) | Stores the detection result of a text element.  
[TextLine](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textline-0000001054358760) | Stores the detection result of text lines.  
[TextParamKey](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textparamkey-0000001054120101) | Defines parameter keys and constant values for [Text](https://developer.harmonyos.com/cn/docs/documentation/doc-references/text-0000001054678772).  
  
#### Enum Summary

Enum | Description  
---|---  
[TextConfiguration.TextShape](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textconfiguration_textshape-0000001054440059) | An enumeration class used to store text shapes.
