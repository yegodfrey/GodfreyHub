# Overview  
  
Provides interfaces for multiplexing audio and video files to media files. For example, an audio file and a video file can be mixed to form a media file.

**Since:**

1

#### Class Summary

Class | Description  
---|---  
[Muxer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/muxer-0000001054358917) | Writes data to and multiplexes media streams.  
[Muxer.MediaFileFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/muxer_mediafileformat-0000001054558939) | Provides media file formats, including the MPEG-4, WebM, 3GPP, and HEIF.
