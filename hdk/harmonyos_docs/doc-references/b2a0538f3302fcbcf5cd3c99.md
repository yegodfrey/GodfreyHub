# DataOutputStream  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403) |---|---[java.io.FilterOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filteroutputstream-0000001054238431) |---|---|---java.io.DataOutputStream
    
    public class DataOutputStream
    extends [FilterOutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filteroutputstream-0000001054238431)
    implements [DataOutput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataoutput-0000001054439713)  
  
---  
A data output stream lets an application write primitive Java data types to an output stream in a portable way. An application can then use a data input stream to read the data back in.

**Since:**

JDK1.0

#### [h2]writeUTF

public final void writeUTF​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) str) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Writes a string to the underlying output stream using [modified UTF-8](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datainput-0000001054119684#ZH-CN_TOPIC_0000001054119684__modified-utf-8) encoding in a machine-independent manner. 

First, two bytes are written to the output stream as if by the writeShort method giving the number of bytes to follow. This value is the number of bytes actually written out, not the length of the string. Following the length, each character of the string is output, in sequence, using the modified UTF-8 encoding for the character. If no exception is thrown, the counter written is incremented by the total number of bytes written to the output stream. This will be at least two plus the length of str, and at most two plus thrice the length of str.
