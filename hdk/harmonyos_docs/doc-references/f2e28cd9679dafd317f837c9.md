Watchable
    
    public interface Watchable  
  
---  
An object that may be registered with a watch service so that it can be watched for changes and events.  This interface defines the [register](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchable-0000001054838458#ZH-CN_TOPIC_0000001054838458__register-java_nio_file_WatchService-java_nio_file_WatchEvent_Kind:A-java_nio_file_WatchEvent_Modifier___-) method to register the object with a [WatchService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchservice-0000001054199778) returning a [WatchKey](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchkey-0000001054439791) to represent the registration. An object may be registered with more than one watch service. Registration with a watch service is cancelled by invoking the key's [WatchKey#cancel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchkey-0000001054439791#ZH-CN_TOPIC_0000001054439791__cancel--) method. **Since:** 1.7**See Also:** [Path.register(java.nio.file.WatchService, java.nio.file.WatchEvent.Kind<?>[], java.nio.file.WatchEvent.Modifier...)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/path-0000001054558505#ZH-CN_TOPIC_0000001054558505__register-java_nio_file_WatchService-java_nio_file_WatchEvent_Kind:A-java_nio_file_WatchEvent_Modifier___-)Method Summary Modifier and Type | Method | Description

Method Detail [h2]register [WatchKey](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchkey-0000001054439791) register​([WatchService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchservice-0000001054199778) watcher, [WatchEvent.Kind](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchevent_kind-0000001054119833)<?>[] events, [WatchEvent.Modifier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/watchevent_modifier-0000001054119762)... modifiers) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) Registers an object with a watch service.  If the file system object identified by this object is currently registered with the watch service then the watch key, representing that registration, is returned after changing the event set or modifiers to those specified by the events and modifiers parameters. Changing the event set does not cause pending events for the object to be discarded. Objects are automatically registered for the [StandardWatchEventKinds#OVERFLOW](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardwatcheventkinds-0000001054119835#ZH-CN_TOPIC_0000001054119835__OVERFLOW) event. This event is not required to be present in the array of events.  Otherwise the file system object has not yet been registered with the given watch service, so it is registered and the resulting new key is returned.  Implementations of this interface should specify the events they support. **Parameters:** Parameter Name | Parameter Description

watcher  |  the watch service to which this object is to be registered  
events  |  the events for which this object should be registered  
modifiers  |  the modifiers, if any, that modify how the object is registered
