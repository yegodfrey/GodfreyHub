Specifies the priority of all tasks in a specific task dispatcher when the task dispatcher is being obtained or created. TaskPriority is designed to ensure better responsiveness for applications. By default, all tasks posted using [#getUITaskDispatcher](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) are run with the [HIGH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskpriority-0000001054838736#ZH-CN_TOPIC_0000001054838736__HIGH) priority. To run tasks that do not need to wait for the result, you can adopt the [LOW](https://developer.harmonyos.com/cn/docs/documentation/doc-references/taskpriority-0000001054838736#ZH-CN_TOPIC_0000001054838736__LOW) priority. **Since:** 1Enum Constant Summary Enum Constant | Description
