# Overview  
  
Defines the types and vibration effects of vibrators. 

This package defines the vibrator types and vibration effects and provides interfaces for creating a one-shot vibration, a periodic vibration based on the specified timing sequence, and a periodic vibration based on the specified timing sequence and intensity.
