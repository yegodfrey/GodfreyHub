# DoubleToIntFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface DoubleToIntFunction  
  
---  
Represents a function that accepts a double-valued argument and produces an int-valued result. This is the double-to-int primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsInt(double)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doubletointfunction-0000001054678595#ZH-CN_TOPIC_0000001054678595__applyAsInt-double-).
