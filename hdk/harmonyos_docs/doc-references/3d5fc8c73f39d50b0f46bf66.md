# IRemoteObject.DeathRecipient
    
    public static interface IRemoteObject.DeathRecipient  
  
---  
Represents an inner class of [IRemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970) that subscribes to death notifications of a [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299). 

When a death notification is received, the [DeathRecipient#onRemoteDied](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject_deathrecipient-0000001054358949#ZH-CN_TOPIC_0000001054358949__onRemoteDied--) method is called to perform subsequent operations. 

    * RemoteObject
    * The process where the [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) resides dies.
    * The device where the [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) resides is shut down or restarted.
    * When the [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) and [RemoteProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteproxy-0000001054440257) reside on different devices, the [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) is removed from the network.

#### Method Detail

#### [h2]onRemoteDied

void onRemoteDied​()

Called to perform subsequent operations when a death notification of the [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) is received. 

This method is usually used to clear resources of [RemoteProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteproxy-0000001054440257) or notify other objects of the death of [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299). You can override this method to determine the subsequent operations.
