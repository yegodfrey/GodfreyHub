# ChronoPeriod
    
    public interface ChronoPeriod
    extends [TemporalAmount](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalamount-0000001054119836)  
  
---  
A date-based amount of time, such as '3 years, 4 months and 5 days' in an arbitrary chronology, intended for advanced globalization use cases. 

This interface models a date-based amount of time in a calendar system. While most calendar systems use years, months and days, some do not. Therefore, this interface operates solely in terms of a set of supported units that are defined by the Chronology. The set of supported units is fixed for a given chronology. The amount of a supported unit may be set to zero. 

The period is modeled as a directed amount of time, meaning that individual parts of the period may be negative.

1.8

#### [h2]between

static [ChronoPeriod](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronoperiod-0000001054838526) between​([ChronoLocalDate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronolocaldate-0000001054558573) startDateInclusive, [ChronoLocalDate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronolocaldate-0000001054558573) endDateExclusive)

Obtains a ChronoPeriod consisting of amount of time between two dates. 

The start date is included, but the end date is not. The period is calculated using [ChronoLocalDate#until(ChronoLocalDate)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronolocaldate-0000001054558573#ZH-CN_TOPIC_0000001054558573__until-java_time_chrono_ChronoLocalDate-). As such, the calculation is chronology specific. 

The chronology of the first date is used. The chronology of the second date is ignored, with the date being converted to the target chronology system before the calculation starts. 

The result of this method can be a negative period if the end is before the start. In most cases, the positive/negative sign will be the same in each of the supported fields.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
startDateInclusive  |  the start date, inclusive, specifying the chronology of the calculation, not null  
endDateExclusive  |  the end date, exclusive, in any chronology, not null  
  
**Returns:**

the period between this date and the end date, not null

**See Also:**

[ChronoLocalDate.until(ChronoLocalDate)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronolocaldate-0000001054558573#ZH-CN_TOPIC_0000001054558573__until-java_time_chrono_ChronoLocalDate-)
