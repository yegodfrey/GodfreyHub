# Overview  
  
Provides bundle-related functions. 

You can obtain information about an ability, an application, or a bundle, and install or uninstall an application.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[IBackupSessionCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ibackupsessioncallback-0000001054678794) | Provides callback methods to be called upon backup or restore is proceduring.  
[IBundleInstaller](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ibundleinstaller-0000001054358773) | Installs and uninstalls applications.  
[IBundleManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ibundlemanager-0000001054558795) | Obtains information related to the application bundle.  
[ICleanCacheCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icleancachecallback-0000001054238793) | Provides a callback that can be invoked for application cache clearing.  
[IInstallerCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinstallercallback-0000001054678763) | Provides callback methods to be called upon bundle installation or uninstallation.
