Formats the value of [Picker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picker-0000001054119976) and converts it into a string.

#### [h2]format

[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) format​(int value)

The child class of [Picker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/picker-0000001054119976) must implement java.lang.String format(int value) to achieve different formatting results.
