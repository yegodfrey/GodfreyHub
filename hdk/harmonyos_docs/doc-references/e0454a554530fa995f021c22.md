# Overview  
  
Provides methods for operating database result sets. 

This package also provides methods for accessing database result sets across processes. Related classes include SharedResultSet and SharedBlock.

**Since:**

2

#### Interface Summary

Interface | Description  
---|---  
[ResultSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resultset-0000001054838776) | Provides methods for accessing a database result set generated by querying the database.  
[ResultSetHook](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resultsethook-0000001054358810) | Provides the method for creating a result set.  
[SharedResultSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sharedresultset-0000001054120151) | Provides methods for accessing a database result set obtained by querying the database across processes.
