# NotificationRequest.NotificationContent

Sets the content of a notification to be passed to the [NotificationRequest#setContent(NotificationRequest.NotificationContent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__setContent-ohos_event_notification_NotificationRequest_NotificationContent-) method. The content type can be [NotificationRequest.NotificationNormalContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationnormalcontent-0000001054358830), [NotificationRequest.NotificationLongTextContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationlongtextcontent-0000001054238841), or [NotificationRequest.NotificationPictureContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationpicturecontent-0000001054120171). You can use a constructor of this class to specify the type to use.
