#### [h2]importScene

[Entity](https://developer.harmonyos.com/cn/docs/documentation/doc-references/entity-0000001054119994) importScene​(int sceneIndex, [GltfData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfdata-0000001054440029) data, [GltfImportData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfimportdata-0000001054518756) importData, [Entity](https://developer.harmonyos.com/cn/docs/documentation/doc-references/entity-0000001054119994) rootEntity, int flags)

Imports a glTF scene from specified glTF data and resources. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
sceneIndex  |  Indicates the index of the glTF scene to be imported.  
data  |  Indicates the glTF data that contains structure information of the glTF scene to be created.  
importData  |  Indicates the glTF resources that have been loaded, such as meshes and skins.  
rootEntity  |  Indicates the root entity of the glTF scene to be imported. This parameter can be null.  
flags  |  Indicates the flag that specifies the resources to be imported, which can be set using [getDefaultResourceImportFlags()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfloader-0000001054678744#ZH-CN_TOPIC_0000001054678744__getDefaultResourceImportFlags--).  
  
**Returns:**

Returns the root entity of the glTF scene.
