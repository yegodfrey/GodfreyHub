点击控制 设置组件是否可以响应点击事件、触摸事件等手指交互事件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172416.63636759147264379798102858252094:50001231000000:2800:F6CC59743C6CAF0F66CB0EEDDACC6228D9B29A75F2D3F2189F7D4F5F69FD3D6D.png?needInitFileName=true?needInitFileName=true?needInitFileName=true) 从API Version 7开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。 属性 **名称** | **参数类型** | **默认值** | **描述**  
---|---|---|---  
touchable | boolean | true | 设置当前组件是否可以响应点击事件、触摸事件等手指交互事件。  
示例
    
    // xxx.ets
    @Entry
    @Component
    struct TouchAbleExample {
      @State text1: string = ''
      @State text2: string = ''
    
      build() {
        Stack() {
          Rect()
            .fill(Color.Gray).width(150).height(150)
            .onClick(() => {
              console.info(this.text1 = 'Rect Clicked')
            })
            .overlay(this.text1, { align: Alignment.Bottom, offset: { x: 0, y: 20 } })
          Ellipse()
            .fill(Color.Pink).width(150).height(80)
            .touchable(false) // 点击Ellipse区域，不会打印 “Ellipse Clicked”
            .onClick(() => {
              console.info(this.text2 = 'Ellipse Clicked')
            })
            .overlay(this.text2, { align: Alignment.Bottom, offset: { x: 0, y: 20 } })
        }.margin(100)
      }
    }
