# DataAbilityHelper

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.ability.DataAbilityHelper
    
    public class DataAbilityHelper

Helps applications to access data. 

[DataAbilityHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681) is a helper class for data operations. It uses [IDataAbilityObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idataabilityobserver-0000001054558679) to register an observer for monitoring data. You can call [creator(ohos.app.Context)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681#ZH-CN_TOPIC_0000001054558681__creator-ohos_app_Context-) to create a [DataAbilityHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681) instance without specifying the [Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009) or call [creator(ohos.app.Context,ohos.utils.net.Uri,boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681#ZH-CN_TOPIC_0000001054558681__creator-ohos_app_Context-ohos_utils_net_Uri-boolean-) to create one with a given [Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009).
