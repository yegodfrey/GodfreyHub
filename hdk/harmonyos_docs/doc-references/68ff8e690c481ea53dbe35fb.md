# Overview  
  
This package includes basic elements and features related to graphics. 

It includes the Surface, and SurfaceOps classes.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[SurfaceOps](https://developer.harmonyos.com/cn/docs/documentation/doc-references/surfaceops-0000001054678699) | Provides methods of adding or removing a callback for a surface Ops.  
[SurfaceOps.Callback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/surfaceops_callback-0000001054838684) | Represents the callback of the surface ops.  
[TextureHolder.OnNewFrameCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textureholder_onnewframecallback-0000001060679062) | Interface definition for being notified that a new stream frame is available.  
[TextureHolderListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textureholderlistener-0000001217996531) | Provides callbacks to listen for the creation, destruction, update, and size changes of [TextureHolder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textureholder-0000001060157227) objects.  
  
#### Class Summary

Class | Description  
---|---  
[Surface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/surface-0000001054120059) | Processes data in the buffer that is managed by a screen compositor, and uses the data for drawing on the screen.  
[TextureHolder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textureholder-0000001060157227) | Captures frames from an image stream as an texture.  
  
#### Enum Summary

Enum | Description  
---|---  
[Surface.PixelFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/surface_pixelformat-0000001054440017) | Enumerates the pixel format of raw image data.
