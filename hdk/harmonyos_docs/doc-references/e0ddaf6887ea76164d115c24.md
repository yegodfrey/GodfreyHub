# Overview  
  
Provides utils classes and methods for animation effects.

**Since:**

5

#### Interface Summary

Interface | Description  
---|---  
[TypeEstimator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typeestimator-0000001218157965)<T> | Interface for use with the [AnimatorValue.setEstimator(TypeEstimator)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/animatorvalue-0000001054518714#ZH-CN_TOPIC_0000001054518714__setEstimator-ohos_agp_animation_util_TypeEstimator-) function.

Class | Description
