# Overview  
  
Provides functions of asynchronously adding, deleting, modifying, and querying data of the database. 

This package contains the [RdbStoreAsyncHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstoreasynchandler-0000001054358788) and [DataAbilityAsyncHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityasynchandler-0000001054238799) classes. RdbStoreAsyncHandler applies to the intra-process scenario and DataAbilityAsyncHandler applies to the cross-process or cross-device scenario.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[DeleteCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deletecallback-0000001054200072) | Processes the data deletion result when data is deleted from the database.  
[InsertCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/insertcallback-0000001054518812) | Processes the data insertion result when data is inserted into the database.  
[QueryCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/querycallback-0000001054678800) | Processes the data query result when a data query is performed in the database.  
[UpdateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/updatecallback-0000001054358779) | Processes the data update result when data is updated in the database.  
  
#### Class Summary

Class | Description  
---|---  
[DataAbilityAsyncHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityasynchandler-0000001054238799) | Provides interfaces to asynchronously add, delete, modify, and query data of the database in the cross-process or cross-device scenario with a [DataAbilityHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dataabilityhelper-0000001054558681) instance.  
[JobParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/jobparams-0000001054678769) | Represents the parameters of the task to asynchronously add, delete, modify, or query data.  
[JobParams.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/jobparams_builder-0000001054838754) | Constructs a [JobParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/jobparams-0000001054678769) instance using a builder.  
[RdbStoreAsyncHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbstoreasynchandler-0000001054358788) | Provides interfaces to asynchronously add, delete, modify, and query data of the local database.
