# Pattern  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.global.resource.solidxml.Pattern
    
    public abstract class Pattern
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides resource attributes for a specific pattern. 

A hash map returned by [Pattern#getPatternHash](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pattern-0000001054238885#ZH-CN_TOPIC_0000001054238885__getPatternHash--) stores the pattern attributes. You can call [Element.getPattern()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/element-0000001054120140#ZH-CN_TOPIC_0000001054120140__getPattern--) to obtain the Pattern instance based on the resource ID.
