# ListAdornment

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.listcomponent.ListAdornment
    
    public abstract class ListAdornment
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
  
Implements special drawing and layout offsets for components in the provider's data set.

You can customize the drawing (for example, using a divider) before or after the ListComponent is drawn.
