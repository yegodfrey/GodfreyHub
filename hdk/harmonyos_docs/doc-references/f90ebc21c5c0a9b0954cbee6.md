Represents the Wi-Fi P2P configuration for setting up a connection. With the Wi-Fi P2P configuration, you can use [WifiP2pController#createGroup(WifiP2pConfig, WifiP2pCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pcontroller-0000001054120272#ZH-CN_TOPIC_0000001054120272__createGroup-ohos_wifi_p2p_WifiP2pConfig-ohos_wifi_p2p_WifiP2pCallback-) to create a P2P group and use [WifiP2pController#connect(WifiP2pConfig, WifiP2pCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wifip2pcontroller-0000001054120272#ZH-CN_TOPIC_0000001054120272__connect-ohos_wifi_p2p_WifiP2pConfig-ohos_wifi_p2p_WifiP2pCallback-) to initiate a connection to a device. The Wi-Fi P2P configuration contains the device address, passphrase, and band of the P2P group owner. **Since:** 3Nested Class Summary Nested classes/interfaces inherited from interface ohos.utils.[Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)
