# Element.OnLayoutDirectionChangeListener
    
    public static interface Element.OnLayoutDirectionChangeListener

Provides a callback to listen for element layout direction changes. 

This class receives a notification when the [Element](https://developer.harmonyos.com/cn/docs/documentation/doc-references/element-0000001054358705) layout direction changes.
