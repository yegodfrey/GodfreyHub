#### [h2]setBearerPrivateIdentifier

public [NetSpecifier.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/netspecifier_builder-0000001054838914) setBearerPrivateIdentifier​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) bearerPrivateIdentifier)

Sets an optional parameter of a bearer network. For the cellular network, the parameter can be the SN of the primary or secondary SIM card or the carrier SPN. For the Bluetooth network, the parameter can be the device ID. For the Wi-Fi network, the parameter can be the SSID or BSSID.
