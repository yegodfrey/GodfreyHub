# Reader  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.nfc.oma.Reader
    
    public final class Reader
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides interfaces to obtain information about secure elements. 

The interfaces can be used to obtain the name of a secure element, check whether the secure element is available, and enable a session on the secure element. The getReaders() method in [SEService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/seservice-0000001054678933) can be used to obtain all available secure elements on a device.
