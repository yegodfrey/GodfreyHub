# A2dpSink

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.bluetooth.A2dpSink
    
    public final class A2dpSink
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [ProfileBase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/profilebase-0000001054358767)  
  
---  
Manages A2DP sink profiles. 

The static method [getProfile(ohos.app.Context)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsink-0000001054238787#ZH-CN_TOPIC_0000001054238787__getProfile-ohos_app_Context-) is used to obtain [A2dpSink](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsink-0000001054238787) instances. 

You can use [getDevicesByStates(int[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsink-0000001054238787#ZH-CN_TOPIC_0000001054238787__getDevicesByStates-int:A-) to obtain devices in the specified state, use [getDeviceState(ohos.bluetooth.BluetoothRemoteDevice)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsink-0000001054238787#ZH-CN_TOPIC_0000001054238787__getDeviceState-ohos_bluetooth_BluetoothRemoteDevice-) to obtain the status of a peer device, and use [getPlayingState(ohos.bluetooth.BluetoothRemoteDevice)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsink-0000001054238787#ZH-CN_TOPIC_0000001054238787__getPlayingState-ohos_bluetooth_BluetoothRemoteDevice-) to obtain the [A2dpSink](https://developer.harmonyos.com/cn/docs/documentation/doc-references/a2dpsink-0000001054238787) playing status of a device.
