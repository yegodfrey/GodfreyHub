#### [h2]get

public static [Path](https://developer.harmonyos.com/cn/docs/documentation/doc-references/path-0000001054558505) get​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) first, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460)... more)

Converts a path string, or a sequence of strings that when joined form a path string, to a Path. If more does not specify any elements then the value of the first parameter is the path string to convert. If more specifies one or more elements then each non-empty string, including first, is considered to be a sequence of name elements (see [Path](https://developer.harmonyos.com/cn/docs/documentation/doc-references/path-0000001054558505)) and is joined to form a path string. The details as to how the Strings are joined is provider specific but typically they will be joined using the [FileSystem#getSeparator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filesystem-0000001054558507#ZH-CN_TOPIC_0000001054558507__getSeparator--) as the separator. For example, if the name separator is "/" and getPath("/foo","bar","gus") is invoked, then the path string "/foo/bar/gus" is converted to a Path. A Path representing an empty path is returned if first is the empty string and more does not contain any non-empty strings. 

The Path is obtained by invoking the [FileSystem#getPath](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filesystem-0000001054558507#ZH-CN_TOPIC_0000001054558507__getPath-java_lang_String-java_lang_String___-) method of the [FileSystems#getDefault](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filesystems-0000001054238505#ZH-CN_TOPIC_0000001054238505__getDefault--) [FileSystem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filesystem-0000001054558507). 

Note that while this method is very convenient, using it will imply an assumed reference to the default FileSystem and limit the utility of the calling code. Hence it should not be used in library code intended for flexible reuse. A more flexible alternative is to use an existing Path instance as an anchor, such as: 
    
    Path dir = ...
         Path path = dir.resolve("file");

#### [h2]get

public static [Path](https://developer.harmonyos.com/cn/docs/documentation/doc-references/path-0000001054558505) get​([URI](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434) uri)

Converts the given URI to a [Path](https://developer.harmonyos.com/cn/docs/documentation/doc-references/path-0000001054558505) object. 

This method iterates over the [FileSystemProvider#installedProviders()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filesystemprovider-0000001054439803#ZH-CN_TOPIC_0000001054439803__installedProviders--) providers to locate the provider that is identified by the URI [URI#getScheme](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434#ZH-CN_TOPIC_0000001054838434__getScheme--) of the given URI. URI schemes are compared without regard to case. If the provider is found then its [FileSystemProvider#getPath](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filesystemprovider-0000001054439803#ZH-CN_TOPIC_0000001054439803__getPath-java_net_URI-) method is invoked to convert the URI. 

In the case of the default provider, identified by the URI scheme "file", the given URI has a non-empty path component, and undefined query and fragment components. Whether the authority component may be present is platform specific. The returned Path is associated with the [FileSystems#getDefault](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filesystems-0000001054238505#ZH-CN_TOPIC_0000001054238505__getDefault--) file system. 

The default provider provides a similar round-trip guarantee to the [File](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759) class. For a given Path _p_ it is guaranteed that 

Paths.get(_p_.[Path#toUri()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/path-0000001054558505#ZH-CN_TOPIC_0000001054558505__toUri--)()).equals( _p_.[Path#toAbsolutePath()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/path-0000001054558505#ZH-CN_TOPIC_0000001054558505__toAbsolutePath--)()) 

so long as the original Path, the URI, and the new Path are all created in (possibly different invocations of) the same Java virtual machine. Whether other providers make any guarantees is provider specific and therefore unspecified.
