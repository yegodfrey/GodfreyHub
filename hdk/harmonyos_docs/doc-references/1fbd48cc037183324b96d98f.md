#### [h2]isDefaultForm

public boolean isDefaultForm​()

Checks whether this form is a default form. 

A form is considered a default form if no form name is specified. Specifically, the system determines whether a form is a default form based on the value of the isDefault attribute defined under forms in the **config.json** file of the Ohos application.

**Returns:**

Returns true if this form is a default form; returns false otherwise.

**Since:**

5
