A container class of [Element](https://developer.harmonyos.com/cn/docs/documentation/doc-references/element-0000001054358705) that contains multiple Element objects. 

Only one [Element](https://developer.harmonyos.com/cn/docs/documentation/doc-references/element-0000001054358705) object in the ElementContainer is valid. You can subclass this class to create an ElementContainer or directly use one of its child classes.
