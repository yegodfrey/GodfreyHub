# dialog

自定义弹窗容器。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172500.66100027386655719522845068202175:50001231000000:2800:7BDFD447F961748699DABF5B04AC83586DC1AA543D542E0713DA09CE7BB801BA.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

从API version 4开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。

#### 权限列表

无

#### 子组件

支持单个子组件。

#### 示例

#### 属性

除支持[通用属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-attributes-0000001281480654)外，支持如下属性：

名称 | 类型 | 默认值 | 必填 | 描述  
---|---|---|---|---  
dragable7+ | boolean | false | 否 | 设置对话框是否支持拖拽。  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172500.24463585726148478898406824104158:50001231000000:2800:B50C5FEAD4680B8AB6EC30E13E5D86A434CE9927215AE61A2046270BBCCFD3F9.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

弹窗类组件不支持focusable、click-effect属性。

#### 样式

仅支持[通用样式](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-styles-0000001281201106)中的width、height、margin、margin-[left|top|right|bottom]、margin-[start|end]样式。

#### 事件

不支持[通用事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-events-0000001333720913)，仅支持如下事件：

名称 | 参数 | 描述  
---|---|---  
cancel | - | 用户点击非dialog区域触发取消弹窗时触发的事件。  
show7+ | - | 对话框弹出时触发该事件。  
close7+ | - | 对话框关闭时触发该事件。  
  
#### 方法

不支持[通用方法](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-methods-0000001333321161)，仅支持如下方法。

名称 | 参数 | 描述  
---|---|---  
show | - | 弹出对话框。  
close | - | 关闭对话框。

dialog属性、样式均不支持动态更新。
