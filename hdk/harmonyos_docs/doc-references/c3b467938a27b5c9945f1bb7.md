# RdbStoreAsyncHandler

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.eventhandler.EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858) |---|---ohos.data.async.RdbStoreAsyncHandler
    
    public class RdbStoreAsyncHandler
    extends [EventHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventhandler-0000001054518858)  
  
---  
Provides interfaces to asynchronously add, delete, modify, and query data of the local database. 

This class provides two threads, a work thread and a callback thread. The work thread implements data operations; the callback thread processes data operation results.
