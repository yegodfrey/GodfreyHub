#### [h2]setDisposeMode

public void setDisposeMode​(boolean isDisposeMode)

Sets dynamic decoding for this frame animation. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
isDisposeMode  |  Specifies whether to enable dynamic decoding for this frame animation. The value true means to enable dynamic decoding, and false means the opposite. If you enable dynamic decoding, you must also call [setPreDecodeFrames(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/frameanimationelement-0000001054358714#ZH-CN_TOPIC_0000001054358714__setPreDecodeFrames-int-) to set the number of frames to be decoded. Enabling dynamic decoding saves random-access memory (RAM) but may consumes more power.  
  
**Since:**

4
