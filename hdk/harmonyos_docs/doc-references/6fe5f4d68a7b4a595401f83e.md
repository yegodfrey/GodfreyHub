# NetManager

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.net.NetManager
    
    public final class NetManager
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides interfaces to manage and use data networks. 

This class provides interfaces to activate and query data networks and bind NICs to processes, as well as callback interfaces to listen for status changes.

#### [h2]setupSpecificNet

public boolean setupSpecificNet​([NetSpecifier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/netspecifier-0000001054678929) netSpecifier, [NetStatusCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/netstatuscallback-0000001054358948) callback)

Activates a data network matching [NetSpecifier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/netspecifier-0000001054678929). A network is automatically deactivated when the application exits. It can also be manually deactivated by using [removeNetStatusCallback(ohos.net.NetStatusCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/netmanager-0000001054238959#ZH-CN_TOPIC_0000001054238959__removeNetStatusCallback-ohos_net_NetStatusCallback-). 

To call this method, you must have the ohos.permission.SET_NETWORK_INFO permission.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
netSpecifier  |  Indicates the network specifier. See [NetSpecifier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/netspecifier-0000001054678929).  
callback  |  Indicates the callback to notify the application of network status changes. For details, see [NetStatusCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/netstatuscallback-0000001054358948).  
  
**Returns:**

Returns true if the network is activated; returns false otherwise.
