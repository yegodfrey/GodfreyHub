#### [h2]canShowFloating

public static boolean canShowFloating​([Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) context)

Checks whether a specified application can draw over other applications. 

To draw over other applications, an application must declare the ohos.permission.SYSTEM_FLOAT_ WINDOW permission and get an explicit approval from end users. To achieve so, the application must display a dialog box to ask end users for the permission.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
context  |  Indicates the application context.  
  
**Returns:**

Returns true if the application can draw over other applications; returns false otherwise.

**Since:**

3

#### [h2]checkSetPermission

public static boolean checkSetPermission​([Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) context)

Checks whether a specified application has permission to modify system settings based on the application context. 

To modify system settings, an application must declare the ohos.permission.MODIFY_SETTINGS permission and get an explicit approval from end users. To achieve so, the application must display a dialog box to ask end users for the permission.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
context  |  Indicates the application context.  
  
**Returns:**

Returns true if the application has permission to modify system settings; returns false otherwise.

**Since:**

3
