# Overview  
  
Provides a surface component. 

The parent class of SurfaceProvider is [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683). SurfaceProvider provides a dedicated drawing Surface, which is one of the basic components of a Component. It is commonly used where images need to be drawn quickly, such as in the case of video playback.
