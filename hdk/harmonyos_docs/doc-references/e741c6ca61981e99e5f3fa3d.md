#### [h2]RINGER_MODE_VIBRATE

public static final [AudioManager.AudioRingMode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiomanager_audioringmode-0000001054678877) RINGER_MODE_VIBRATE

#### [h2]RINGER_MODE_NORMAL

public static final [AudioManager.AudioRingMode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/audiomanager_audioringmode-0000001054678877) RINGER_MODE_NORMAL

Indicates that the ringer mode is restored to the previous setting. A device will be audible if the previous mode was sound. It will vibrate if the previous mode was vibration.
