# Debug.HeapInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.hiviewdfx.Debug.HeapInfo
    
    public static class Debug.HeapInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides the static native heap memory used by the current process of your application. 

You can use the [Debug#getNativeHeapInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/debug-0000001054558889#ZH-CN_TOPIC_0000001054558889__getNativeHeapInfo-ohos_hiviewdfx_Debug_HeapInfo-) method to obtain the statistics about the native heap memory. 

Example code for obtaining the statistics about the native heap memory: 
    
    Debug.HeapInfo heapInfo =new Debug.HeapInfo();
     Debug.getNativeHeapInfo(heapInfo);
     long heapSize = heapInfo.nativeHeapSize ;
     long allocateHeapSize = heapInfo.nativeHeapAllocatedSize;
     long freeHeapSize = heapInfo.nativeHeapFreeSize;
