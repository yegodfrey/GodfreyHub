# DatePicker.DateOrder
    
    public static interface DatePicker.DateOrder  
  
---  
Defines the display format of [DatePicker](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datepicker-0000001054678716) components. 

For example, the date can be displayed in the format of year-month-day, or month-day-year.

**Since:**

1
