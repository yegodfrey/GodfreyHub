# NoClassDefFoundError

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Error](https://developer.harmonyos.com/cn/docs/documentation/doc-references/error-0000001054199728) |---|---|---[java.lang.LinkageError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkageerror-0000001054678425) |---|---|---|---java.lang.NoClassDefFoundError
    
    public class NoClassDefFoundError
    extends [LinkageError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkageerror-0000001054678425)  
  
---  
Thrown if the Java Virtual Machine or a ClassLoader instance tries to load in the definition of a class (as part of a normal method call or as part of creating a new instance using the new expression) and no definition of the class could be found. 

The searched-for class definition existed when the currently executing class was compiled, but the definition can no longer be found.

**Since:**

JDK1.0
