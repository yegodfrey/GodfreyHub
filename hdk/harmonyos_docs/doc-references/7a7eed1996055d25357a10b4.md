# Metadata

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.media.camera.params.Metadata
    
    public final class Metadata
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Describes values of camera properties, configuration parameters, and frame capture results. 

Property keys only describe inherent properties of the camera and are not used for controlling the camera. 

Parameter keys describe parameters allowed to be set. 

Result keys describe the returnable results related to parameter settings.
