# MeshBuilder
    
    public interface MeshBuilder  
  
---  
A utility class for creating 3D mesh resources from raw data. 

You can pass a MeshBuilder object to [ResourceManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/resourcemanager-0000001054440033) to create a mesh resource.

#### [h2]allocate

void allocate​()

Allocates memory for the current mesh. 

This method should be called after all primitives have been added to this mesh and before data is being fed to primitives.

#### [h2]getVertexCount

int getVertexCount​()

Obtains the vertex count. 

This method should be called after [allocate()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/meshbuilder-0000001054238749#ZH-CN_TOPIC_0000001054238749__allocate--) has been called.

**Returns:**

Returns the total vertex count in the current mesh.

#### [h2]getIndexCount

int getIndexCount​()

Obtains the index count. 

16-bit indices are packed (two per one 32-bit slot), and there might be paddings involved.

**Returns:**

Returns the total index count in the current mesh.
