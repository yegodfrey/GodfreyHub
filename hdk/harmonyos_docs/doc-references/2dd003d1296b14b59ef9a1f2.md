Represents the media item information returned from the [AVBrowserService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserservice-0000001054558949), which contains [AVElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avelement-0000001054358907) instances to sent.  You need to call [sendAVElement(ohos.media.common.sessioncore.AVElement)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserresult-0000001054120184#ZH-CN_TOPIC_0000001054120184__sendAVElement-ohos_media_common_sessioncore_AVElement-) or [sendAVElementList(java.util.List<ohos.media.common.sessioncore.AVElement>)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserresult-0000001054120184#ZH-CN_TOPIC_0000001054120184__sendAVElementList-java_util_List-) to send the information to your application. If you need to delay sending the information, call [detachForRetrieveAsync()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserresult-0000001054120184#ZH-CN_TOPIC_0000001054120184__detachForRetrieveAsync--) before the information is returned to detach it from the media browser service. After the process of the information is complete, call [sendAVElement(ohos.media.common.sessioncore.AVElement)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserresult-0000001054120184#ZH-CN_TOPIC_0000001054120184__sendAVElement-ohos_media_common_sessioncore_AVElement-) or [sendAVElementList(java.util.List<ohos.media.common.sessioncore.AVElement>)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserresult-0000001054120184#ZH-CN_TOPIC_0000001054120184__sendAVElementList-java_util_List-) to send the information. **Since:** 3Method Summary Modifier and Type | Method | Description
