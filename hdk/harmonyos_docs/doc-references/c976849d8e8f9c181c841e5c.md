# Overview  
  
Provides interfaces and classes for registering and unregistering device state callbacks, obtaining information about all devices or a specified device on the distributed network, querying application information, and initializing the distributed execution framework. You can use this package to perform the following operations: 
    * Call [DeviceManager#registerDeviceStateCallback(IDeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__registerDeviceStateCallback-ohos_distributedschedule_interwork_IDeviceStateCallback-) to register device state callbacks so that your application can receive notifications when a device on the distributed network becomes online or offline and call [DeviceManager#unregisterDeviceStateCallback(IDeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__unregisterDeviceStateCallback-ohos_distributedschedule_interwork_IDeviceStateCallback-) to unregister these callbacks.
    * Call [DeviceManager#getDeviceList(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__getDeviceList-int-) to obtain information about all devices on the distributed network.
    * Call [DeviceManager#getDeviceInfo(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__getDeviceInfo-java_lang_String-) to obtain information about a specified device on the distributed network.
    * Call [DeviceManager#queryRemoteAbilityByIntent(Intent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__queryRemoteAbilityByIntent-ohos_aafwk_content_Intent-) to obtain [AbilityInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityinfo-0000001054358782) information about a non-HarmonyOS application on the distributed network.
    * Call [DeviceManager#initDistributedEnvironment(String, IInitCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__initDistributedEnvironment-java_lang_String-ohos_distributedschedule_interwork_IInitCallback-) to initialize the distributed execution framework on a device with a callback specified to notify your application of the initialization result. After the cross-device task is complete, call [DeviceManager#unInitDistributedEnvironment(String, IInitCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__unInitDistributedEnvironment-java_lang_String-ohos_distributedschedule_interwork_IInitCallback-) to deactivate the distributed execution framework.

#### Interface Summary

Interface | Description  
---|---  
[IDeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831) | Provides callbacks that can be invoked when the state of a device on the distributed network changes to online or offline.  
[IInitCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280) | Provides callbacks to be invoked upon a successful or failed attempt to initialize the distributed execution framework.  
  
#### Class Summary

Class | Description  
---|---  
[DeviceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceinfo-0000001054838786) | Provides methods for setting and obtaining the network ID, device name, device type, and device state of a device on the distributed network.  
[DeviceManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820) | Provides methods for managing devices on the distributed network, including registering and unregistering callbacks for notifications of device online and offline, obtaining information about all remote devices or a specified remote device, querying information about an remote application based on a specified [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019), and initializing the distributed execution framework for a device.

Enum | Description  
---|---  
[DeviceInfo.DeviceState](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceinfo_devicestate-0000001054120090) | Enumerates online and offline states of a device on the distributed network.  
[DeviceInfo.DeviceType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceinfo_devicetype-0000001054440119) | Enumerates types of a device on the distributed network.
