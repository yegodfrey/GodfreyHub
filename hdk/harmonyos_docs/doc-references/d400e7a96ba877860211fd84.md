# LocalParticleAbility  
      
    public interface LocalParticleAbility  
  
---  
Represents local particle abilities (PA) that are integrated into the JS UI framework. 

Local PAs are applicable to services that are closely related to ability service logics and require low response latency. 

Local PAs can be called only by a local ability. 

You can register a LocalParticleAbility instance with a plug-in manager via the default register method. Alternatively, you can create a LocalParticleAbility instance via createLocalParticleAbility using JavaScript, which automatically completes the registration.
