Inherits from [SensorAgent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sensoragent-0000001054838934) and manages body sensors on hardware devices. This class is used to obtain all body sensors, a type of sensors in the body sensor category, and the first sensor of a specific type, and set or release the sensor data callback.  When you need to obtain the health data such as the heart rate, you can call this class to obtain a specific sensor and set the sensor data callback.
