# Overview  
  
Provides classes that define input events, such as key and manipulation events.

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[BuiltinKeyEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/builtinkeyevent-0000001054678925) | Defines the key events of internal input devices.  
[CompositeEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/compositeevent-0000001054838910) | Defines composite events specific to common devices.  
[EventCreator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventcreator-0000001060268793) | Provides methods for creating events.  
[KeyBoardEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyboardevent-0000001054358944) | Defines all keyboard events.  
[KeyEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285) | Defines all key events.  
[ManipulationEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manipulationevent-0000001054120214) | Reports manipulation events.  
[MmiPoint](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mmipoint-0000001054440243) | Represents the x, y, or z coordinate in a given coordinate system.  
[MouseEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mouseevent-0000001054200230) | Reports mouse events.  
[MultimodalEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodalevent-0000001054518970) | Represents the base class of all event types.  
[RotationEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rotationevent-0000001054678958) | Defines events generated by rotation components, for example, a digital watch crown on a smart watch.  
[SpeechEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/speechevent-0000001054358937) | Defines speech events.  
[StylusEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stylusevent-0000001092813452) | Reports stylus events.  
[TouchEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/touchevent-0000001054558959) | Defines touch events and mapped standard events.
