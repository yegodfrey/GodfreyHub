# DateFormat.Field  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.text.AttributedCharacterIterator.Attribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attributedcharacteriterator_attribute-0000001054119891) |---|---[java.text.Format.Field](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format_field-0000001054199838) |---|---|---java.text.DateFormat.Field
    
    public static class DateFormat.Field
    extends [Format.Field](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format_field-0000001054199838)  
  
---  
Defines constants that are used as attribute keys in the AttributedCharacterIterator returned from DateFormat.formatToCharacterIterator and as field identifiers in FieldPosition. 

The class also provides two methods to map between its constants and the corresponding Calendar constants.

**Since:**

1.4

#### [h2]getCalendarField

public int getCalendarField​()

Returns the Calendar field associated with this attribute. For example, if this represents the hours field of a Calendar, this would return Calendar.HOUR. If there is no corresponding Calendar constant, this will return -1.
