# ConcurrentSkipListMap

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.AbstractMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractmap-0000001054119846)<K,V> |---|---java.util.concurrent.ConcurrentSkipListMap<K,V>
    
    public class ConcurrentSkipListMap<K,V>
    extends [AbstractMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractmap-0000001054119846)<K,V>
    implements [ConcurrentNavigableMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620)<K,V>, [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421), [Serializable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serializable-0000001054358416)  
  
---  
A scalable concurrent [ConcurrentNavigableMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620) implementation. The map is sorted according to the [Comparable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparable-0000001054558443) of its keys, or by a [Comparator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparator-0000001054558585) provided at map creation time, depending on which constructor is used. 

This class implements a concurrent variant of [SkipLists](http://en.wikipedia.org/wiki/Skip_list) providing expected average _log(n)_ time cost for the containsKey, get, put and remove operations and their variants. Insertion, removal, update, and access operations safely execute concurrently by multiple threads. 

Iterators and spliterators are [_weakly consistent_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054558607#ZH-CN_TOPIC_0000001054558607__Weakly). 

Ascending key ordered views and their iterators are faster than descending ones. 

All Map.Entry pairs returned by methods in this class and its views represent snapshots of mappings at the time they were produced. They do not support the Entry.setValue method. (Note however that it is possible to change mappings in the associated map using put, putIfAbsent, or replace, depending on exactly which effect you need.) 

Beware that, unlike in most collections, the size method is not a constant-time operation. Because of the asynchronous nature of these maps, determining the current number of elements requires a traversal of the elements, and so may report inaccurate results if this collection is modified during traversal. Additionally, the bulk operations putAll, equals, toArray, containsValue, and clear are not guaranteed to be performed atomically. For example, an iterator operating concurrently with a putAll operation might view only some of the added elements. 

This class and its views and iterators implement all of the optional methods of the [Map](https://developer.harmonyos.com/cn/docs/documentation/doc-references/map-0000001054199858) and [Iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913) interfaces. Like most other concurrent collections, this class does not permit the use of null keys or values because some null return values cannot be reliably distinguished from the absence of elements. 

This class is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).
