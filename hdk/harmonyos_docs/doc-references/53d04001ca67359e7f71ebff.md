ZSONWriter [java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.zson.ZSONWriter  
      
    public class ZSONWriter
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [AutoCloseable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/autocloseable-0000001054518454), [Flushable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/flushable-0000001054358407)  
  
---  
Provides methods for writing data into streams of JSON files.  You can call methods in this class to write data by item or by object.  Writing data by item refers to writing data items into the output JSON stream one by one. An example is provided as follows: 
    
    StringWriter stringWriter = new StringWriter();
     try (ZSONWriter writer = new ZSONWriter(stringWriter)) {
         writer.startObject();
         writer.writeName("id");
         writer.writeString("ca31221a-bd9a-4e82-acbe-f43a3ca9461c");
         writer.writeName("active");
         writer.writeBoolean(false);
         writer.writeName("age");
         writer.writeNumber(21);
         writer.writeName("name");
         writer.writeString("Gibbs Leblanc");
         writer.writeName("time");
         writer.writeNumber(1600066331510L);
         writer.writeName("tags");
         writer.startArray();
         writer.writeString("mollit");
         writer.writeString("labore");
         writer.endArray();
         writer.endObject();
         writer.flush();
     }
     

The output is as follows: 
    
    {"id":"ca31221a-bd9a-4e82-acbe-f43a3ca9461c","active":false,"age":21,"name":"Gibbs Leblanc","time":1600066331510,"tags":["mollit","labore"]}"
     

Writing data by object refers to writing an entire object into the output JSON stream. An example is provided as follows: 
    
    StringWriter stringWriter = new StringWriter();
     try (ZSONWriter writer = new ZSONWriter(stringWriter)) {
         writer.startObject();
         writer.writeName("friends");
         writer.startArray();
         Profile bullockProfile = new Profile(0, "Alexander Bullock");
         writer.writeObject(bullockProfile);
         Profile noelProfile = new Profile(1, "Santos Noel");
         writer.writeObject(noelProfile);
         writer.endArray();
         writer.endObject();
         writer.flush();
     }
     
    
    public static class Profile {
         private final int id;
         private final String name;
    
         public Profile(int id, String name) {
             this.id = id;
             this.name = name;
         }
    
         public int getId() {
             return id;
         }
    
         public String getName() {
             return name;
         }
     }
     

The output is as follows: 
    
    {"friends":[{"id":0,"name":"Alexander Bullock"},{"id":1,"name":"Santos Noel"}]}
