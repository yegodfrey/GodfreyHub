SSLSessionContext  
      
    public interface SSLSessionContext  
  
---  
A SSLSessionContext represents a set of SSLSessions associated with a single entity. For example, it could be associated with a server or client who participates in many sessions concurrently.  Not all environments will contain session contexts.  There are SSLSessionContext parameters that affect how sessions are stored: 
    * Sessions can be set to expire after a specified time limit. 
    * The number of sessions that can be stored in context can be limited.
