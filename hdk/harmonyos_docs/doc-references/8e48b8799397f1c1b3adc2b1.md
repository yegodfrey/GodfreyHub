# Overview  
  
Provides interfaces and classes for distributed hardware management, including querying information about local and trusted devices, subscribing to device online and offline notifications, and presenting devices on the UI for the user to select.

**Since:**

4

#### Interface Summary

Interface | Description  
---|---  
[DeviceManager.DeviceManagerCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager_devicemanagercallback-0000001138987479) | Provides callbacks for getting [DeviceManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016) instance.  
[DeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333) | Provides callbacks that can be invoked when the state of a monitored device changes to online or offline.  
[ReturnCode](https://developer.harmonyos.com/cn/docs/documentation/doc-references/returncode-0000001138728611) | Defines the return codes for operations related to device management.  
[SelectDeviceListListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/selectdevicelistlistener-0000001091930948) | Provides callbacks that can be invoked when a device is selected.
