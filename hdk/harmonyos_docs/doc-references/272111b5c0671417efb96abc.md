# OrmObjectObserver
    
    public interface OrmObjectObserver  
  
---  
Represents the observer of object relational mapping (ORM) databases. 

If you want to listen for data changes in an ORM database, call the registration interface provided in [OrmContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormcontext-0000001054120139) to register an observer, and then specify the callback for receiving the change content as needed.
