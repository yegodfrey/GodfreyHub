# Overview  
  
Provides classes dedicated to computer vision (CV) document rectification, including data structure, configuration, key, and interface classes.

**Since:**

1

Interface | Description  
---|---  
[IDocRefine](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idocrefine-0000001054200040) | Provides document refinement (DocRefine) function.
