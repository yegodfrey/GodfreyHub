Provides the storage information of an application. The storage information includes the application size, application data size, and application cached data size. The information is usually returned at the request of [StorageInfoManager#queryInfoByPackageName(UUID, String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageinfomanager-0000001054558989#ZH-CN_TOPIC_0000001054558989__queryInfoByPackageName-java_util_UUID-java_lang_String-int-) and [StorageInfoManager#queryInfoByUid(UUID, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageinfomanager-0000001054558989#ZH-CN_TOPIC_0000001054558989__queryInfoByUid-java_util_UUID-int-). This class also provides the [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001) interface, with which you can marshal data into or unmarshal data from a parcel. Specifically, if storage information is transmitted across processes, the sender can marshal data to the [Parcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018) and transmit the data, and the receiver can unmarshal the data from the [Parcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018) to obtain the storage information. **Since:** 3**See Also:** [StorageInfoManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/storageinfomanager-0000001054558989), [Parcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018), [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)Nested Class Summary Nested classes/interfaces inherited from interface ohos.utils.[Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)
