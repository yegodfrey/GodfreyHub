Creates an Intent data class to send after a timer is triggered. This class is used when you set a timer. After the timer is triggered, the system starts a component in a ability type, and this class is used to specify parameters for the [RepeatTimer#getTimer(Context context, TimerIntent operation)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_repeattimer-0000001054678923#ZH-CN_TOPIC_0000001054678923__getTimer-ohos_app_Context-ohos_miscservices_timeutility_Timer_TimerIntent-) or [OneShotTimer#getTimer(Context context, TimerIntent operation)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_oneshottimer-0000001054238953#ZH-CN_TOPIC_0000001054238953__getTimer-ohos_app_Context-ohos_miscservices_timeutility_Timer_TimerIntent-) method. The constructor of this class accepts two parameters Intent and ability type, respectively representing the intent and its type sent by the system when the timer is triggered. The intent cannot be null, and the intent type must be valid. Otherwise, the getTimer return value will be null, and the timer setting will fail. **Since:** 1Constructor Summary Constructor | Description
