# LauncherShortcutInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.bundle.LauncherShortcutInfo
    
    public class LauncherShortcutInfo
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides information about the shortcut of the launcher ability of an application launched from the home screen. 

This class provides methods for obtaining the shortcut ID, icon, and bundle name of the application to which the shortcut belongs.
