Enumerates the text justification strategies. Text justification makes each line look full by stretching word spacing (spaces in DBC case). This strategy does not apply to the last line of a paragraph. If a line does not contain any blank space, no action is performed. Currently, word spacing cannot be used for justification. **Since:** 7Enum Constant Summary Enum Constant | Description
