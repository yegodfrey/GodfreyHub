# ObjectAttribute

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.ObjectAttribute<O,T>
    
    public abstract class ObjectAttribute<O,T>

---  
An abstract class of object attributes. 

The ObjectAttribute class has the following characteristics: 

    * You can override the [get(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectattribute-0000001054120262#ZH-CN_TOPIC_0000001054120262__get-O-) and [set(java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectattribute-0000001054120262#ZH-CN_TOPIC_0000001054120262__set-O-T-) methods to implement general-purpose setter and getter methods, thereby making the code cleaner.
    * References to object attributes are flattened. For example, object A needs to hold a reference to object B to access one of its attributes, but object B has multiple other attributes that should be hidden from object A. In this case, you can use the ObjectAttribute class to encapsulate only the accessible attribute of object B and transfer it to object A.
    * You can override the [set(java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectattribute-0000001054120262#ZH-CN_TOPIC_0000001054120262__set-O-T-) method to set an object attribute to read-only.

#### [h2]isReadOnly

public boolean isReadOnly​()

Checks whether the attribute encapsulated in the current ObjectAttribute object is read-only. 

If true is returned, an UnsupportedOperationException exception will be thrown when you call the [set(java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectattribute-0000001054120262#ZH-CN_TOPIC_0000001054120262__set-O-T-) method.

**Returns:**

Returns true if the attribute is read-only, indicating that the attribute value cannot be updated by the [set(java.lang.Object,java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectattribute-0000001054120262#ZH-CN_TOPIC_0000001054120262__set-O-T-) method.
