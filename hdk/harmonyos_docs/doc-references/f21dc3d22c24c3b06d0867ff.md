# Fraction

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.app.AbilityContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitycontext-0000001054358759) |---|---ohos.aafwk.ability.fraction.Fraction

    extends [AbilityContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitycontext-0000001054358759)
    implements [ILifecycle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ilifecycle-0000001054238677)  
  
---  
Provides lifecycle callbacks of a fraction. 

A Fraction can be placed in a container (an [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007)) as a part of its UI and cannot be used independently. The lifecycle state of a Fraction depends on its container. If the container is destroyed, all fractions in it will also be destroyed. You can use the Fraction to define a variety of layouts to enrich the user interface of your application.
