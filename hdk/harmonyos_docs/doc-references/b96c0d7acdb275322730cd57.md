# FaultLogger

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.hiviewdfx.FaultLogger
    
    public final class FaultLogger
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Manages the logging of application faults. Applications can use this class to query their fault records. 

Applications may become unavailable due to code defects or runtime exceptions. Such situations are considered application faults. When a fault occurs, the fault information is recorded for locating the cause and fixing the fault. Sample code for querying fault records is as follows: 
    
    Optional<FaultLogger.FaultLogQueryResult> resultOpt = FaultLogger.querySelfFaultLog(FaultLogger.FAULT_TYPE_NO_SPECIFIC, 10);
        if (resultOpt.isPresent()) {
            FaultLogger.FaultLogQueryResult result = resultOpt.get();
            while (result.hasNext()) {
                Optional<FaultLogger.FaultLogInfo> infoOpt = result.next();
                infoOpt.ifPresent((info) -> {
                    // Obtain detailed fault information.
                });
            }
            // Destroy the query result.
            result.destroy();
        }
     

A fault query may be time-consuming. Do not query fault records in the main thread or in performance-sensitive scenarios, for example, during application startup.
