# Overview  
  
Provides methods for processing a phone number based on the specified region code, for example, the method for obtaining the formatting result based on the input string representation of a phone number.

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[InputFormatter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputformatter-0000001055200086) | Formats the string representation of a phone number.  
[PhoneNumberAttribution](https://developer.harmonyos.com/cn/docs/documentation/doc-references/phonenumberattribution-0000001055360066) | Provides methods for obtaining the home location of a phone number.
