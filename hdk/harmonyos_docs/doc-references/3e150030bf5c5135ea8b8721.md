# IOException  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---java.io.IOException
    
    public class IOException
    extends [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708)  
  
---  
Signals that an I/O exception of some sort has occurred. This class is the general class of exceptions produced by failed or interrupted I/O operations.

**Since:**

JDK1.0

#### [h2]IOException

public IOException​([Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) cause)

Constructs an IOException with the specified cause and a detail message of (cause==null ? null : cause.toString()) (which typically contains the class and detail message of cause). This constructor is useful for IO exceptions that are little more than wrappers for other throwables. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
cause  |  The cause (which is saved for later retrieval by the [Throwable.getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method). (A null value is permitted, and indicates that the cause is nonexistent or unknown.)  
  
**Since:**

1.6
