An abstract parent class that obtains signal information.  Based on the network types defined by [getNetworkType()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/signalinformation-0000001054838950#ZH-CN_TOPIC_0000001054838950__getNetworkType--), which are GSM, CDMA, WCDMA, TD-SCDMA, LTE, and NR, the parent class contains the following child classes, which inherit from the parent class: 
    * [GsmSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gsmsignalinformation-0000001054440281)
    * [CdmaSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cdmasignalinformation-0000001054358982)
    * [WcdmaSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wcdmasignalinformation-0000001054200270)
    * [TdscdmaSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tdscdmasignalinformation-0000001054120325)
    * [LteSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ltesignalinformation-0000001054200268)
    * [NrSignalInformation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nrsignalinformation-0000001054678996)
