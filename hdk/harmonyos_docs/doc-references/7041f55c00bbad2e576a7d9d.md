# ImageRichStyle.ImageAlignment

---  
Enumerates vertical alignment modes of an image in the line where the image is located. If an image is higher than the text in the line where the image is located, the height of the line is increased to that of the image. In this case, the image positions in the alignment modes [ImageAlignment#TOP](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagerichstyle_imagealignment-0000001217877973#ZH-CN_TOPIC_0000001217877973__TOP), [ImageAlignment#CENTER](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagerichstyle_imagealignment-0000001217877973#ZH-CN_TOPIC_0000001217877973__CENTER), and [ImageAlignment#BOTTOM](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagerichstyle_imagealignment-0000001217877973#ZH-CN_TOPIC_0000001217877973__BOTTOM) are the same.
