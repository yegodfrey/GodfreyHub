# 版本说明

HarmonyOS提供了丰富的JS API，开发者通过查阅接口文档，可以全面地了解接口，更好地开发应用。

不同API版本的SDK支持的功能有一定差异。为了方便开发者确认SDK支持的功能，文档中的API均标记了支持版本，具体说明请见版本号标识。

除此之外，HarmonyOS提供了Beta API供开发者尝鲜体验。在体验过程中可能会出现功能不稳定的情况，开发者可以直接在网页反馈，我们将在后续版本中进行优化。Beta API的标识请见Beta API标识。

从API Version 6 开始，API Version 3-5的接口将不再维护。建议开发者使用最新版本的SDK进行应用开发。具体SDK和API版本对应关系请参考[系统版本说明](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/harmonyos_release_definitions-0000001092857972)。

#### 版本号标识

版本号标识帮助开发者快速识别API的起始版本，确认SDK对应支持的功能。

当前文档采用如下方式标记API的起始版本：

    * 章节正文前说明本模块首批接口的起始版本，如：本模块首批接口从API version 6开始支持。

即无标记的API，其起始版本与所在模块的起始版本一致。

    * 模块中的非首批接口，即后续版本中新增的方法、属性、自定义类型等，采用上角标标记起始版本号，如：“featureAbility.startAbilityForResult7+”表示从API Version 7开始支持featureAbility.startAbilityForResult方法。
