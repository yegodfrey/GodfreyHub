# Overview  
  
Provides interfaces related to the telephony service. 

The interfaces are used for making calls, obtaining call states, sending Short Message Service (SMS) messages, parsing raw data in Intent of SMS messages, and setting and querying data service states, basic information about operator networks, and basic information about SIM cards.
