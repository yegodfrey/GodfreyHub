# ICategoryOtherDataCallback  
      
    public interface ICategoryOtherDataCallback
    extends [ISensorDataCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isensordatacallback-0000001054238985)<[CategoryOtherData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/categoryotherdata-0000001054678953),[CategoryOther](https://developer.harmonyos.com/cn/docs/documentation/doc-references/categoryother-0000001054558983)>  
  
---  
Inherits from [ISensorDataCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isensordatacallback-0000001054238985) and receives data of sensors in the other category. 

This interface inherits all methods from its parent interface. When detecting any sensor data changes, it provides data for the application layer to call.
