# DeviceStateCallback
    
    public interface DeviceStateCallback  
  
---  
Provides callbacks that can be invoked when the state of a monitored device changes to online or offline. 

Before calling [DeviceManager#registerDeviceStateCallback(String, Map, DeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__registerDeviceStateCallback-java_lang_String-java_util_Map-ohos_distributedhardware_devicemanager_DeviceStateCallback-) to register device state callbacks, you must first create a class to implement this interface and override the [DeviceStateCallback#onDeviceOffline(DeviceInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333#ZH-CN_TOPIC_0000001138830333__onDeviceOffline-ohos_distributedhardware_devicemanager_DeviceInfo-) and [DeviceStateCallback#onDeviceOnline(DeviceInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333#ZH-CN_TOPIC_0000001138830333__onDeviceOnline-ohos_distributedhardware_devicemanager_DeviceInfo-) methods. 

    * When a monitored device goes online, [DeviceStateCallback#onDeviceOnline(DeviceInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333#ZH-CN_TOPIC_0000001138830333__onDeviceOnline-ohos_distributedhardware_devicemanager_DeviceInfo-) will be called to notify your application of the online device information.
    * When a monitored device goes offline, [DeviceStateCallback#onDeviceOffline(DeviceInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333#ZH-CN_TOPIC_0000001138830333__onDeviceOffline-ohos_distributedhardware_devicemanager_DeviceInfo-) will be called to notify your application of the offline device information.
    * If your application no longer needs to receive these notifications, you can call [DeviceManager#unregisterDeviceStateCallback(String, DeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__unregisterDeviceStateCallback-java_lang_String-ohos_distributedhardware_devicemanager_DeviceStateCallback-) to unregister all previously registered callbacks.

#### [h2]onDeviceOffline

void onDeviceOffline​([DeviceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceinfo-0000001091611346) deviceInfo)

Called when a device being monitored goes offline. 

If your application needs to be notified when a device goes offline, you must implement the [DeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333) interface, override this callback, and then call [DeviceManager#registerDeviceStateCallback(String, Map, DeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__registerDeviceStateCallback-java_lang_String-java_util_Map-ohos_distributedhardware_devicemanager_DeviceStateCallback-) to register the callback object. After being registered, this callback will be invoked when a device goes offline and your application will be notified of the offline device information.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
deviceInfo  |  Indicates the offline device information. For details, see [DeviceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceinfo-0000001091611346).  
  
**Since:**

4

#### [h2]onDeviceOnline

void onDeviceOnline​([DeviceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceinfo-0000001091611346) deviceInfo)

If your application needs to be notified when a device goes online, you must implement the [DeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicestatecallback-0000001138830333) interface, override this callback, and then call [DeviceManager#registerDeviceStateCallback(String, Map, DeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001091771016#ZH-CN_TOPIC_0000001091771016__registerDeviceStateCallback-java_lang_String-java_util_Map-ohos_distributedhardware_devicemanager_DeviceStateCallback-) to register the callback object. After being registered, this callback will be invoked when a device goes online and your application will be notified of the online device information.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
deviceInfo  |  Indicates the online device information. For details, see [DeviceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deviceinfo-0000001091611346).
