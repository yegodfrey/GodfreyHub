# FontSizeRichStyle

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.text.richstyles.RichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richstyle-0000001218158007) |---|---ohos.agp.text.richstyles.FontSizeRichStyle
    
    public class FontSizeRichStyle
    extends [RichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richstyle-0000001218158007)  
  
---  
Implements rich styles for font sizes. This class must be used in a [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706) instance. 

This class supports both relative size and absolute size. It also supports different units for the absolute size.
