# ClickRichStyle

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.text.richstyles.RichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richstyle-0000001218158007) |---|---ohos.agp.text.richstyles.ClickRichStyle
    
    public class ClickRichStyle
    extends [RichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richstyle-0000001218158007)  
  
---  
Implements the click style, which allows you to specify the text click behavior. You need to implement the [ClickListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/clickrichstyle_clicklistener-0000001217996539) API and add the click behavior action to the [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706) object.
