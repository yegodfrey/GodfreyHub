# CRC32

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.zip.CRC32
    
    public class CRC32
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Checksum](https://developer.harmonyos.com/cn/docs/documentation/doc-references/checksum-0000001054439931)

A class that can be used to compute the CRC-32 of a data stream. 

Passing a null argument to a method in this class will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown.

#### [h2]update

public void update​([ByteBuffer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/bytebuffer-0000001054439771) buffer)

Updates the checksum with the bytes from the specified buffer. The checksum is updated using buffer.[remaining()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/buffer-0000001054119742#ZH-CN_TOPIC_0000001054119742__remaining--) bytes starting at buffer.[position()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/buffer-0000001054119742#ZH-CN_TOPIC_0000001054119742__position--) Upon return, the buffer's position will be updated to its limit; its limit will not have been changed. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
buffer  |  the ByteBuffer to update the checksum with
