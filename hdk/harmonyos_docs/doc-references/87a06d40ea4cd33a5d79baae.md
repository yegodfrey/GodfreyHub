# NotificationRequest.NotificationMultiLineContent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationRequest.NotificationMultiLineContent

Constructs a notification that includes multiple lines of text. 

This multi-line notification is different from a long-text notification constructed by [NotificationLongTextContent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest_notificationlongtextcontent-0000001054238841). The long-text notification displays notification content only with a single line in the notification bar and hides the text exceeding the allowed display length. By contrast, the multi-line notification can display up to seven independent lines of text in the notification bar.
