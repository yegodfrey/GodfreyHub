# DeviceManager

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.distributedschedule.interwork.DeviceManager
    
    public class DeviceManager
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides methods for managing devices on the distributed network, including registering and unregistering callbacks for notifications of device online and offline, obtaining information about all remote devices or a specified remote device, querying information about an remote application based on a specified [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019), and initializing the distributed execution framework for a device. 

If your application needs to be notified when a device on the distributed network becomes online or offline, call [DeviceManager#registerDeviceStateCallback(IDeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__registerDeviceStateCallback-ohos_distributedschedule_interwork_IDeviceStateCallback-) to register device state callbacks. If such notifications are no longer required, call [DeviceManager#unregisterDeviceStateCallback(IDeviceStateCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__unregisterDeviceStateCallback-ohos_distributedschedule_interwork_IDeviceStateCallback-) to unregister these callbacks. 

To obtain information about all remote devices on the distributed network, call [DeviceManager#getDeviceList(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__getDeviceList-int-). To obtain information about a specified remote device, call [DeviceManager#getDeviceInfo(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__getDeviceInfo-java_lang_String-).

To query information about a non-HarmonyOS remote application on the distributed network, call [DeviceManager#queryRemoteAbilityByIntent(Intent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__queryRemoteAbilityByIntent-ohos_aafwk_content_Intent-).

If your application needs to invoke a component of a non-HarmonyOS application installed on a remote device, call [DeviceManager#initDistributedEnvironment(String, IInitCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__initDistributedEnvironment-java_lang_String-ohos_distributedschedule_interwork_IInitCallback-) to initialize the distributed execution framework. In this way, your application will be notified of the initialization result through the specified callback. After the cross-device task is complete, call [DeviceManager#unInitDistributedEnvironment(String, IInitCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__unInitDistributedEnvironment-java_lang_String-ohos_distributedschedule_interwork_IInitCallback-) to deactivate the distributed execution framework and unregister the previously registered callbacks.

#### [h2]registerDeviceStateCallback

public static boolean registerDeviceStateCallback​([IDeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831) callback)

Registers a custom device state callback so that the application can be notified upon state changes of devices on the distributed network. 

To register a callback for device state changes, you should first implement the [IDeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831) interface and override the [IDeviceStateCallback#onDeviceOnline(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831#ZH-CN_TOPIC_0000001054238831__onDeviceOnline-java_lang_String-int-) and [IDeviceStateCallback#onDeviceOffline(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831#ZH-CN_TOPIC_0000001054238831__onDeviceOffline-java_lang_String-int-) methods. The two methods will be called upon device state changes. 

Do not repeatedly register the same device state callback for an application. Otherwise, the registration fails. 

Each process can register a maximum of 10 device state callbacks.

To use this method, your application must have gained the ohos.permission.DISTRIBUTED_DEVICE_STATE_CHANGE permission.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
callback  |  Indicates the callback object to register. You must first implement the [IDeviceStateCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idevicestatecallback-0000001054238831) interface.  
  
**Returns:**

Returns true if the registration is successful; returns false otherwise.

**Throws:**

Throw Name | Throw Description  
---|---  
[SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) |  Throws this exception if your application does not have the required permissions.

#### [h2]initDistributedEnvironment

public static void initDistributedEnvironment​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) deviceId, [IInitCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280) callback) throws [RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984)

Initializes the distributed execution framework on the specified device and registers callbacks for notifying the initialization result. 

To enable your application to invoke a component of a non-HarmonyOS application installed on a remote device on the distributed network, you should first call this method to initialize the distributed execution framework on the specified device. If the initialization is successful, your application will be notified through [IInitCallback#onInitSuccess(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280#ZH-CN_TOPIC_0000001060837280__onInitSuccess-java_lang_String-). If the initialization fails, your application will be notified through [IInitCallback#onInitFailure(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280#ZH-CN_TOPIC_0000001060837280__onInitFailure-java_lang_String-int-).

To use this method, your application must have gained the ohos.permission.DISTRIBUTED_DATASYNC permission.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
deviceId  |  Indicates the network ID of the device on which the distributed execution framework will be initialized.  
callback  |  Indicates the callback to be invoked upon a successful or failed initialization attempt.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  Throws this exception if argument is null.  
[RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984) |  Throws this exception if the IPC communication exception happens.
