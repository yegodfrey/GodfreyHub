# ExtraParams

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.ability.continuation.ExtraParams

Defines the extra parameters used to sort out the list of available devices. 

You can pass an ExtraParams object when calling methods for device filtering to the methods used for interacting with the hop task management service.

targetBundleName  |  Indicates the bundle name of the target application where the ability will be hopped.
