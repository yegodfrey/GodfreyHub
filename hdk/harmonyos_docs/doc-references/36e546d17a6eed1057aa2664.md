SearchBar.QueryListener
    
    public static interface SearchBar.QueryListener  
  
---  
Provides callbacks to be invoked when the query text is changed by the user or when the user submits the query. This method is invoked only when the user starts to enter text in the search bar. It will not be invoked when the text is still being edited in the input method window. Method Summary Modifier and Type | Method | Description
