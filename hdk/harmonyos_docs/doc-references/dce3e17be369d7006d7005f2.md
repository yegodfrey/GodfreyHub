# KeyPair  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.security.KeyPair
    
    public final class KeyPair
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Serializable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serializable-0000001054358416)

This class is a simple holder for a key pair (a public key and a private key). It does not enforce any security, and, when initialized, should be treated like a PrivateKey.

Constructs a key pair from the given public key and private key. 

Note that this constructor only stores references to the public and private key components in the generated key pair. This is safe, because Key objects are immutable.

**Parameters:**
