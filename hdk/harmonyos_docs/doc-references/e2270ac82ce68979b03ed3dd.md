# Overview  
  
Provides a TextureProvider component. 

The parent class of TextureProvider is [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683). TextureProvider is a basic component and applies to scenarios where fast playback is required, for example, video playback.

**Since:**

7
