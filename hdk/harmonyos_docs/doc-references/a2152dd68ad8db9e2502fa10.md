Get interface and endpoint information about a USB device.  When using this class, a USB device is attached to a USB host. According to the USB protocol specifications, a device contains one or more configurations, a configuration contains one or more interfaces, and an interface contains one or more endpoints. **Since:** 5Constructor Summary Constructor | Description
