# OutOfMemoryError

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Error](https://developer.harmonyos.com/cn/docs/documentation/doc-references/error-0000001054199728) |---|---|---[java.lang.VirtualMachineError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/virtualmachineerror-0000001054238457) |---|---|---|---java.lang.OutOfMemoryError
    
    public class OutOfMemoryError
    extends [VirtualMachineError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/virtualmachineerror-0000001054238457)  
  
---  
Thrown when the Java Virtual Machine cannot allocate an object because it is out of memory, and no more memory could be made available by the garbage collector. OutOfMemoryError objects may be constructed by the virtual machine as if [Throwable#Throwable(String, Throwable, boolean, boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__Throwable-java_lang_String-java_lang_Throwable-boolean-boolean-).

JDK1.0
