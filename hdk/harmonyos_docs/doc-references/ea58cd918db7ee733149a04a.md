An annotation used to indicate what options an annotation processor supports. The [Processor.getSupportedOptions()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processor-0000001170214349#ZH-CN_TOPIC_0000001170214349__getSupportedOptions--) method can construct its result from the value of this annotation, as done by [AbstractProcessor.getSupportedOptions()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractprocessor-0000001170334455#ZH-CN_TOPIC_0000001170334455__getSupportedOptions--).
