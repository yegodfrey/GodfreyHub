# MatchingSkills

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.commonevent.MatchingSkills
    
    public class MatchingSkills

---  
Encapsulates particular common events to which a subscriber wants to subscribe. 

MatchingSkills includes the following filters: event as an intent action standing for a common event, entity as a category, scheme as a filter for matching certain common events such as bundle installation and uninstallation, and [IntentParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentparams-0000001054439977) as extra parameters. You can use [addEvent(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/matchingskills-0000001054120094#ZH-CN_TOPIC_0000001054120094__addEvent-java_lang_String-), [addEntity(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/matchingskills-0000001054120094#ZH-CN_TOPIC_0000001054120094__addEntity-java_lang_String-), [addScheme(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/matchingskills-0000001054120094#ZH-CN_TOPIC_0000001054120094__addScheme-java_lang_String-), and [setIntentParams(ohos.aafwk.content.IntentParams)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/matchingskills-0000001054120094#ZH-CN_TOPIC_0000001054120094__setIntentParams-ohos_aafwk_content_IntentParams-) to set these filters. MatchingSkills information is defined in the <skills></skills> tag of **config.json**.

**Matching Rules**

An Intent matches a MatchingSkills object only when the action and all entities defined in the Intent match the event and all entities in the MatchingSkills object.

    * **Match of event** \-- Events match only if the action attribute of an Intent matches an event specified in the MatchingSkills object.

    * **Match of entities** \-- Entities match only if all entity attributes of an Intent match all entities specified in the MatchingSkills object.
