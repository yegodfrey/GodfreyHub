# FileAbility  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.app.AbilityContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitycontext-0000001054358759) |---|---[ohos.aafwk.ability.Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) |---|---|---ohos.data.file.FileAbility
    
    public class FileAbility
    extends [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007)  
  
---  
FileAbility is a special implementions of IDataAbility that facilitates secure sharing of a files associated with an app by creating a dataability://[Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009) for a file instead of file:/// [Uri](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054559009). You can include a FileAbility in your app by specifying it entirely in Json. To specify the FileAbility component itself, add a /Resources/rawfile/fileability.json in you app. You should adjust path conversion rules for example, you can only share the files in the fileability.json path.
