Represents the index schema for actions that can be performed within an application. This schema is used to create indexes for in-app actions. For example, after an index is added for the action of creating a note in a notepad application, the application user can search for this action in a global search. This allows for immediate access to action items within this application.  The schema supports index field actionName and all the fields in [CommonItem](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commonitem-0000001078320140). Among these fields, identifier is mandatory and can be set via the [CommonItem#setIdentifier(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/schema-0000001121107273#ZH-CN_TOPIC_0000001121107273__setIdentifier-java_lang_String-) method. **Since:** 5Field Summary Modifier and Type | Field | Description
