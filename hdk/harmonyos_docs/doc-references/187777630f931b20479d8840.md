# LineHeightRichStyle

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.text.richstyles.RichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richstyle-0000001218158007) |---|---ohos.agp.text.richstyles.LineHeightRichStyle

Defines rich styles for the line height. This class must be used in a [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706) instance. 

You can adjust the line height by adjusting the line spacing or adjusting the ascent/descent in a proportion.

#### [h2]LineHeightRichStyle

public LineHeightRichStyle​(float lineHeight, boolean isScaleMode)

A constructor used to create a [LineHeightRichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lineheightrichstyle-0000001172238194) instance with the specified lineHeight and adjustment mode. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
lineHeight  |  lineHeight Indicates the line height, in pixels.  
isScaleMode  |  Specifies whether to adjust the line height by scaling the ascent/descent in certain proportion. The value true means to adjust the line height by scaling the ascent/descent, and false means to adjust the line spacing.  
  
**Throws:**

---|---
