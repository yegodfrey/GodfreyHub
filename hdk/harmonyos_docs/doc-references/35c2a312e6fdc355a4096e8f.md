# IllegalStateException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.lang.RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466) |---|---|---|---java.lang.IllegalStateException
    
    public class IllegalStateException
    extends [RuntimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runtimeexception-0000001054518466)  
  
---  
Signals that a method has been invoked at an illegal or inappropriate time. In other words, the Java environment or Java application is not in an appropriate state for the requested operation.

**Since:**

JDK1.1

#### [h2]IllegalStateException

public IllegalStateException​([Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) cause)

Constructs a new exception with the specified cause and a detail message of (cause==null ? null : cause.toString()) (which typically contains the class and detail message of cause). This constructor is useful for exceptions that are little more than wrappers for other throwables (for example, [PrivilegedActionException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/privilegedactionexception-0000001054558533)). 

**Parameters:**

(A null value is permitted, and indicates that the cause is nonexistent or unknown.)
