# Component.EstimateSpec  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.Component.EstimateSpec

Defines the measure specifications of a component. 

A EstimateSpec encapsulates the arrangement requirements that a child component inherits from the parent. Each EstimateSpec indicates the requirement for either the width or height as well as a mode. There are three possible modes for EstimateSpec: [UNCONSTRAINT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_estimatespec-0000001078032058#ZH-CN_TOPIC_0000001078032058__UNCONSTRAINT), [PRECISE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_estimatespec-0000001078032058#ZH-CN_TOPIC_0000001078032058__PRECISE), and [NOT_EXCEED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component_estimatespec-0000001078032058#ZH-CN_TOPIC_0000001078032058__NOT_EXCEED).
