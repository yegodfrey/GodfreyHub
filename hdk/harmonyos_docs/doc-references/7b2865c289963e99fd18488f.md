---  
Instances of this class represent a secure socket protocol implementation which acts as a factory for secure socket factories or SSLEngines. This class is initialized with an optional set of key and trust managers and source of secure random bytes.  Every implementation of the Java platform is required to support the following standard SSLContext protocol: 
    * TLSv1
This protocol is described in the [ SSLContext section](https://docs.oracle.com/javase/8/docs/technotes/guides/security/StandardNames.html#SSLContext) of the Java Cryptography Architecture Standard Algorithm Name Documentation.
