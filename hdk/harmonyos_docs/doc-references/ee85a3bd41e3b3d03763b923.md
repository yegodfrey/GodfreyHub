# Overview  
  
#### Interface Summary

Interface | Description  
---|---  
[Attribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attribute-0000001054678865) | An interface that contains information about an attribute.  
[Characters](https://developer.harmonyos.com/cn/docs/documentation/doc-references/characters-0000001054838850) | This describes the interface to Characters events.  
[EndElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/endelement-0000001054358884) | An interface for the end element event.  
[StartDocument](https://developer.harmonyos.com/cn/docs/documentation/doc-references/startdocument-0000001054120225) | An interface for the start document event  
[StartElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/startelement-0000001054120154) | The StartElement interface provides access to information about start elements.  
[XMLEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlevent-0000001054440183) | This is the base event interface for handling markup events.
