Provides methods for detecting application or service timeouts. This class defines a mechanism for detecting time-consuming service processing. An application or a service uses this mechanism to check whether a key service procedure times out. For example, if a procedure is not completed within 5 seconds as expected, the application is notified of the timeout. Upon receiving the notification, the application will take proper measures. 
    
    // Start timeout detection.
        int id = XCollie.getInstance().setTimeout("ServiceTimeout", 5, new Runnable(){
            @Override
            public void run () {
                // do something
            }
        }, XCollie.XCOLLIE_FLAG_NOOP);
        // Do something.
        // Cancel timeout detection.
        XCollie.getInstance().cancelTimeout(id);
