# Overview  
  
Provides common classes for media sessions.

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[AVBrowserResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserresult-0000001054120184) | Represents the media item information returned from the [AVBrowserService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserservice-0000001054558949), which contains [AVElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avelement-0000001054358907) instances to sent.  
[AVBrowserRoot](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserroot-0000001054440213) | Represents information about the root media item.  
[AVCallerUserInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avcalleruserinfo-0000001054200200) | Provides user information of an application.  
[AVConnectionCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avconnectioncallback-0000001054518940) | Provides callbacks for state changes to the connection between the [AVBrowser](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowser-0000001054358927) and [AVBrowserService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserservice-0000001054558949).  
[AVControllerCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avcontrollercallback-0000001054678928) | Provides callbacks to receive changes, for example, of playback states or media metadata from [AVSession](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avsession-0000001054838902),You can use [AVController.setAVControllerCallback(AVControllerCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avcontroller-0000001054238947#ZH-CN_TOPIC_0000001054238947__setAVControllerCallback-ohos_media_common_sessioncore_AVControllerCallback-),to register a callback with the media session.  
[AVElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avelement-0000001054358907) | Stores the A/V element.  
[AVElementCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avelementcallback-0000001054558929) | Provides callbacks to listen for AVElement instances.  
[AVPlaybackInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avplaybackinfo-0000001218158021) | Describes playback information of media sessions.  
[AVPlaybackState](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avplaybackstate-0000001054238927) | Manages the playback state of a media session.  
[AVPlaybackState.AVPlaybackCustomAction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avplaybackstate_avplaybackcustomaction-0000001054678897) | Extends [AVController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avcontroller-0000001054238947) actions, for example, an action for setting loop playback.  
[AVPlaybackState.AVPlaybackCustomAction.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avplaybackstate_avplaybackcustomaction_builder-0000001054838882) | Builder for [AVPlaybackCustomAction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avplaybackstate_avplaybackcustomaction-0000001054678897) objects.  
[AVPlaybackState.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avplaybackstate_builder-0000001054358916) | A static inner class of [AVPlaybackState](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avplaybackstate-0000001054238927) to construct instances.  
[AVQueueElement](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avqueueelement-0000001054120257) | Represents elements that constitute a playback queue.  
[AVSessionCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avsessioncallback-0000001054120186) | Provides callbacks to control media playback.  
[AVSubscriptionCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avsubscriptioncallback-0000001054440215) | Provides callbacks for media subscription results.  
[AVToken](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avtoken-0000001054200202) | Represents the token that identifies a running session.
