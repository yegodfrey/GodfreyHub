# Recorder.AudioEncoder

Describes the audio encoding format. 

The available audio encoding formats include the adaptive multi-rate narrowband (AMR-NB), adaptive multi-rate wideband (AMR-WB), advanced audio coding low complexity (AAC-LC), high-efficiency advanced audio coding (HE-AAC), advanced audio coding enhanced low delay (AAC-ELD), and Opus.
