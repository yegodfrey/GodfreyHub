# CompositeEvent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.multimodalinput.event.MultimodalEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodalevent-0000001054518970) |---|---ohos.multimodalinput.event.CompositeEvent

Defines composite events specific to common devices. 

An example of input device can be the mouse. For mouse, [MouseEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/mouseevent-0000001054200230) falls into two types: [KeyEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285) and [ManipulationEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/manipulationevent-0000001054120214). With CompositeEvent, you can combine all mouse events into a composite event, making event processing easier.
