Enumerates states of a tile.  A tile has various states in its lifecycle. When the tile state changes, [TileAbility#onStatusChanged(TileStatus)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tileability-0000001070942146#ZH-CN_TOPIC_0000001070942146__onStatusChanged-ohos_wearable_tile_TileStatus-) is called to notify the TileAbility, so that different operations are performed as defined. **Since:** 4Nested Class Summary Nested classes/interfaces inherited from interface ohos.utils.Sequenceable

[h2]TILE_UPDATE public static final [TileStatus](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tilestatus-0000001071142011) TILE_UPDATE Indicates that the tile is in the updated state. In this case, a valid TileEntity object should be returned. The system passes TILE_UPDATE to the TileAbility in the following cases: 
    * This tile is added to the visible list.
    * The TileAbility calls [TileAbility#notifyDataChanged(Context, ElementName)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tileability-0000001070942146#ZH-CN_TOPIC_0000001070942146__notifyDataChanged-ohos_app_Context-ohos_bundle_ElementName-).
