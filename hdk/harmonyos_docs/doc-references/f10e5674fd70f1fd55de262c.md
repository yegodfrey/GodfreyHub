# DayOfWeek

A day-of-week, such as 'Tuesday'. 

DayOfWeek is an enum representing the 7 days of the week - Monday, Tuesday, Wednesday, Thursday, Friday, Saturday and Sunday. 

In addition to the textual enum name, each day-of-week has an int value. The int value follows the ISO-8601 standard, from 1 (Monday) to 7 (Sunday). It is recommended that applications use the enum rather than the int value to ensure code clarity. 

This enum provides access to the localized textual form of the day-of-week. Some locales also assign different numeric values to the days, declaring Sunday to have the value 1, however this class provides no support for this. See [WeekFields](https://developer.harmonyos.com/cn/docs/documentation/doc-references/weekfields-0000001054358568) for localized week-numbering. 

**Do not use ordinal() to obtain the numeric representation of DayOfWeek. Use getValue() instead.**

This enum represents a common concept that is found in many calendar systems. As such, this enum may be used by any calendar system that has the day-of-week concept defined exactly equivalent to the ISO calendar system.

#### [h2]adjustInto

public [Temporal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532) adjustInto​([Temporal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532) temporal)

Adjusts the specified temporal object to have this day-of-week. 

This returns a temporal object of the same observable type as the input with the day-of-week changed to be the same as this. 

The adjustment is equivalent to using [Temporal#with(TemporalField, long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532#ZH-CN_TOPIC_0000001054838532__with-java_time_temporal_TemporalField-long-) passing [ChronoField#DAY_OF_WEEK](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronofield-0000001054119838#ZH-CN_TOPIC_0000001054119838__DAY_OF_WEEK) as the field. Note that this adjusts forwards or backwards within a Monday to Sunday week. See [WeekFields.dayOfWeek()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/weekfields-0000001054358568#ZH-CN_TOPIC_0000001054358568__dayOfWeek--) for localized week start days. See TemporalAdjuster for other adjusters with more control, such as next(MONDAY). 

In most cases, it is clearer to reverse the calling pattern by using [Temporal#with(TemporalAdjuster)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532#ZH-CN_TOPIC_0000001054838532__with-java_time_temporal_TemporalAdjuster-): 
    
    // these two lines are equivalent, but the second approach is recommended
       temporal = thisDayOfWeek.adjustInto(temporal);
       temporal = temporal.with(thisDayOfWeek);
     

For example, given a date that is a Wednesday, the following are output: 
    
    dateOnWed.with(MONDAY);     // two days earlier
       dateOnWed.with(TUESDAY);    // one day earlier
       dateOnWed.with(WEDNESDAY);  // same date
       dateOnWed.with(THURSDAY);   // one day later
       dateOnWed.with(FRIDAY);     // two days later
       dateOnWed.with(SATURDAY);   // three days later
       dateOnWed.with(SUNDAY);     // four days later
     

This instance is immutable and unaffected by this method call.

[adjustInto](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporaladjuster-0000001054119907#ZH-CN_TOPIC_0000001054119907__adjustInto-java_time_temporal_Temporal-) in interface [TemporalAdjuster](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporaladjuster-0000001054119907)
