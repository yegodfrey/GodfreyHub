# piece

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172506.82889590602620412906975424518511:50001231000000:2800:005265C2B58A0A0D4887F82029EA30B3B8F16DD72AA314A556DE156BACAEDC33.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

从API version 5开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。

一种块状的入口，可包含图片和文本。常用于展示收件人，例如：邮件收件人或信息收件人。

#### 子组件

无

#### 属性

除支持[通用属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-attributes-0000001281480654)外，还支持如下属性：

名称 | 类型 | 默认值 | 必填 | 描述  
---|---|---|---|---  
content | string | - | 是 | 操作块文本内容。  
closable | boolean | false | 否 | 设置当前操作块是否显示删除图标，当显示删除图标时，点击删除图标会触发close事件。  
icon | string | - | 否 | 操作块删除图标的url，支持本地路径。  
  
#### 样式

支持[通用样式](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-styles-0000001281201106)。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172506.41543480303497908273922687947766:50001231000000:2800:A8A422DE0B041E294C3BB390AEF4411983619B4180762DD350D10D3C0C05814F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

文本和图片默认在整个piece组件中居中。

#### 事件

除支持[通用事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-events-0000001333720913)外，还支持如下事件：

名称 | 参数 | 描述  
---|---|---  
close | - | 当piece组件点击删除图标触发，此时可以通过渲染属性if删除该组件。  
  
#### 方法

支持[通用方法](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-methods-0000001333321161)。

#### 示例
    
    <!-- xxx.hml-->
    <div class="container" >
      <piece if="{{first}}" content="example"></piece>
      <piece if="{{second}}" content="example" closable="true" onclose="closeSecond"></piece>
    </div>
    
    /* xxx.css */
    .container {
      width: 100%;
      height: 100%;
      align-items: center;
      justify-content: center;
    }
    
    // xxx.js
    export default {
      data: {
        first: true,
        second: true
      },
      closeSecond(e) {
        this.second = false;
      }
    }
