A ConstantCallSite is a [CallSite](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callsite-0000001054199736) whose target is permanent, and can never be changed. An invokedynamic instruction linked to a ConstantCallSite is permanently bound to the call site's target.

#### [h2]ConstantCallSite

protected ConstantCallSite​([MethodType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/methodtype-0000001054238463) targetType, [MethodHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/methodhandle-0000001054678464) createTargetHook) throws [Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436)

Creates a call site with a permanent target, possibly bound to the call site itself. 

During construction of the call site, the createTargetHook is invoked to produce the actual target, as if by a call of the form (MethodHandle) createTargetHook.invoke(this). 

Note that user code cannot perform such an action directly in a subclass constructor, since the target must be fixed before the ConstantCallSite constructor returns. 

The hook is said to bind the call site to a target method handle, and a typical action would be someTarget.bindTo(this). However, the hook is free to take any action whatever, including ignoring the call site and returning a constant target. 

The result returned by the hook must be a method handle of exactly the same type as the call site. 

While the hook is being called, the new ConstantCallSite object is in a partially constructed state. In this state, a call to getTarget, or any other attempt to use the target, will result in an IllegalStateException. It is legal at all times to obtain the call site's type using the type method.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
targetType  |  the type of the method handle to be permanently associated with this call site  
createTargetHook  |  a method handle to invoke (on the call site) to produce the call site's target  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[WrongMethodTypeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/wrongmethodtypeexception-0000001054119722) |  if the hook cannot be invoked on the required arguments, or if the target returned by the hook is not of the given targetType  
[NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) |  if the hook returns a null value  
[ClassCastException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/classcastexception-0000001054678419) |  if the hook returns something other than a MethodHandle  
[Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |  anything else thrown by the hook function
