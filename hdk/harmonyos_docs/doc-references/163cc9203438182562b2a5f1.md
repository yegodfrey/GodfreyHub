# ImageBitmap对象

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172515.32400774764622523517290516441557:50001231000000:2800:34E666383B10A532F605B3DAC5112E9039D299B5B360173A8D7A4678DE7180D6.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

从API version 7开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。

ImageBitmap对象由OffscreenCanvas对象的transferToImageBitmap()方法生成，存储了offscreen canvas渲染的像素数据。

#### 属性

属性 | 类型 | 描述  
---|---|---  
width | number | ImageBitmap的像素宽度。  
height | number | ImageBitmap的像素高度。
