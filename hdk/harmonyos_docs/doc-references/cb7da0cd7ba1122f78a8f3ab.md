# Overview  
  
Provides utility classes for the 3D engine. 

This package includes utility classes regarding the 3D mesh builder and 3D scene.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[MeshBuilder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/meshbuilder-0000001054238749) | A utility class for creating 3D mesh resources from raw data.  
[SceneUtil](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sceneutil-0000001054678719) | Adds 3D objects to a scene, such as casting rays.  
[SceneUtil.RayCastResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sceneutil_raycastresult-0000001054838704) | Represents the ray-cast result.  
  
#### Class Summary

Class | Description  
---|---  
[BoundingBox](https://developer.harmonyos.com/cn/docs/documentation/doc-references/boundingbox-0000001054120079) | Defines the bounds of objects, such as a 3D mesh.  
[MeshBuilder.Primitive](https://developer.harmonyos.com/cn/docs/documentation/doc-references/meshbuilder_primitive-0000001054120008) | Represents the primitive used to build a mesh.  
[MeshBuilder.VertexData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/meshbuilder_vertexdata-0000001054440037) | Provides the vertex data for creating a mesh.
