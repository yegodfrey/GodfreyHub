#### 函数说明

#### [h2]OH_AccessPixels()
    
    int32_t OH_AccessPixels (napi_env env, napi_value value, void ** addrPtr )

**描述：**

获取**PixelMap** 对象数据的内存地址，并锁定该内存。

函数执行成功后，***addrPtr** 就是获取的待访问的内存地址。访问操作完成后,必须要使用[OH_UnAccessPixels](https://developer.harmonyos.com/cn/docs/documentation/doc-references/image-0000001410005161#ZH-CN_TOPIC_0000001495467081__gaa83ee67c6f5865e2dcd5d8e87b17e438)来释放锁, 否则的话资源无法被释放。待解锁后，内存地址就不可以再被访问和操作。

**参数：**

Name | 描述  
---|---  
env | napi的环境指针。  
value | 应用层的 **PixelMap** 对象。  
addrPtr | 用于指向的内存地址的双指针对象。  
  
**参见：**

OH_UnAccessPixels

**返回：**

操作成功则返回 [OHOS_IMAGE_RESULT_SUCCESS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/image-0000001410005161#ZH-CN_TOPIC_0000001495467081__gga06fc87d81c62e9abb8790b6e5713c55ba222d7a9c2a213fcd4bff171ddecfd466); 如果操作失败，则返回错误码。

**起始版本：**

8

#### [h2]OH_GetImageInfo()
    
    int32_t OH_GetImageInfo (napi_env env, napi_value value, OhosPixelMapInfo * info )

**描述：**

获取 **PixelMap** 的信息，并记录信息到[OhosPixelMapInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/_ohos_pixel_map_info-0000001410285389)结构中。

**参数：**

Name | 描述  
---|---  
env | napi的环境指针。  
value | 应用层的 **PixelMap** 对象。  
info | 用于保存信息的指针对象。更多细节, 参看 [OhosPixelMapInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/_ohos_pixel_map_info-0000001410285389)。  
  
**返回：**

如果获取并保存信息成功，则返回**0** ; 如果操作失败，则返回错误码。

**参见：**

[OhosPixelMapInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/_ohos_pixel_map_info-0000001410285389)
