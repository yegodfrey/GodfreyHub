# DisplayNotch

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.window.service.DisplayNotch
    
    public class DisplayNotch
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Represent a display notch, which cannot be used for displaying content. 

You can use the methods in this class to obtain the notch size and safe padding on a device.
