# ListIterator
    
    public interface ListIterator<E>
    extends [Iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913)<E>  
  
---  
An iterator for lists that allows the programmer to traverse the list in either direction, modify the list during iteration, and obtain the iterator's current position in the list. A ListIterator has no current element; its _cursor position_ always lies between the element that would be returned by a call to previous() and the element that would be returned by a call to next(). An iterator for a list of length n has n+1 possible cursor positions, as illustrated by the carets (^) below: 
    
    Element(0)   Element(1)   Element(2)   ... Element(n-1)
     cursor positions:  ^            ^            ^            ^                  ^
     

Note that the [remove()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listiterator-0000001054439871#ZH-CN_TOPIC_0000001054439871__remove--) and [set(java.lang.Object)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listiterator-0000001054439871#ZH-CN_TOPIC_0000001054439871__set-E-) methods are _not_ defined in terms of the cursor position; they are defined to operate on the last element returned by a call to [next()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listiterator-0000001054439871#ZH-CN_TOPIC_0000001054439871__next--) or [previous()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listiterator-0000001054439871#ZH-CN_TOPIC_0000001054439871__previous--). 

This interface is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).

#### [h2]add

void add​([E](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listiterator-0000001054439871) e)

Inserts the specified element into the list (optional operation). The element is inserted immediately before the element that would be returned by [next()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listiterator-0000001054439871#ZH-CN_TOPIC_0000001054439871__next--), if any, and after the element that would be returned by [previous()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/listiterator-0000001054439871#ZH-CN_TOPIC_0000001054439871__previous--), if any. (If the list contains no elements, the new element becomes the sole element on the list.) The new element is inserted before the implicit cursor: a subsequent call to next would be unaffected, and a subsequent call to previous would return the new element. (This call increases by one the value that would be returned by a call to nextIndex or previousIndex.) 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
e  |  the element to insert  
  
**Throws:**

Throw Name | Throw Description  
---|---

[ClassCastException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/classcastexception-0000001054678419) |  if the class of the specified element prevents it from being added to this list  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  if some aspect of this element prevents it from being added to this list
