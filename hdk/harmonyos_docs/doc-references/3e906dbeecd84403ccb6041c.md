# JarInputStream  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.InputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstream-0000001054358420) |---|---[java.io.FilterInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filterinputstream-0000001054558433) |---|---|---[java.util.zip.InflaterInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inflaterinputstream-0000001054439933) |---|---|---|---[java.util.zip.ZipInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zipinputstream-0000001054358627) |---|---|---|---|---java.util.jar.JarInputStream
    
    public class JarInputStream
    extends [ZipInputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zipinputstream-0000001054358627)  
  
---  
The JarInputStream class is used to read the contents of a JAR file from any input stream. It extends the class java.util.zip.ZipInputStream with support for reading an optional Manifest entry. The Manifest can be used to store meta-information about the JAR file and its entries.

1.2
