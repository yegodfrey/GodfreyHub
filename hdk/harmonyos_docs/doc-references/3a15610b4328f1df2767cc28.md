Defines Time objects used for obtaining and setting the system time and time zone. This class can be used to obtain the system time, system uptime (including or excluding deep sleep time), thread uptime, and the system time zone.  Obtain the [SystemPermission#SET_TIME](https://developer.harmonyos.com/cn/docs/documentation/doc-references/systempermission-0000001054238971#ZH-CN_TOPIC_0000001054238971__SET_TIME) permission to set system time. Obtain the [SystemPermission#SET_TIME_ZONE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/systempermission-0000001054238971#ZH-CN_TOPIC_0000001054238971__SET_TIME_ZONE) permission to set the system time zone. **Since:** 1Constructor Summary Constructor | Description
