# GestureResultListener

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.accessibility.ability.GestureResultListener

    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides a listener to observe the result of sending gestures to the screen. 

You can override this class to make responses when a gesture is completed or cancelled.
