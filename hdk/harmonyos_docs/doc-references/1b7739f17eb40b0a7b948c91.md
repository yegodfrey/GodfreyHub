# CodingErrorAction

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.nio.charset.CodingErrorAction
    
    public class CodingErrorAction
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A typesafe enumeration for coding-error actions. 

Instances of this class are used to specify how malformed-input and unmappable-character errors are to be handled by charset [decoders](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetdecoder-0000001054358479#ZH-CN_TOPIC_0000001054358479__cae) and [encoders](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsetencoder-0000001054558501#ZH-CN_TOPIC_0000001054558501__cae). 

**Since:**

1.4
