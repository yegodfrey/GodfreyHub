Defines the API that wraps an [XMLReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlreader-0000001060837300) implementation class. In JAXP 1.0, this class wrapped the [Parser](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parser-0000001060039159) interface, however this interface was replaced by the [XMLReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlreader-0000001060837300). For ease of transition, this class continues to support the same name and interface as well as supporting new methods. An instance of this class can be obtained from the [SAXParserFactory.newSAXParser()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/saxparserfactory-0000001060837286#ZH-CN_TOPIC_0000001060837286__newSAXParser--) method. Once an instance of this class is obtained, XML can be parsed from a variety of input sources. These input sources are InputStreams, Files, URLs, and SAX InputSources. This static method creates a new factory instance based on a system property setting or uses the platform default if no property has been defined. The system property that controls which Factory implementation to create is named "ohos.javax.xml.parsers.SAXParserFactory". This property names a class that is a concrete subclass of this abstract class. If no property is defined, a platform default will be used. As the content is parsed by the underlying parser, methods of the given [HandlerBase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/handlerbase-0000001061156882) or the [DefaultHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/defaulthandler-0000001060837302) are called. Implementors of this class which wrap an underlaying implementation can consider using the ohos.org.xml.sax.helpers.ParserAdapter class to initially adapt their SAX1 implementation to work under this revised class.
