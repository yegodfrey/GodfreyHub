# Overview  
  
Utilities to assist in the processing of [program elements](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001170214359) and [types](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001170334475). 

Unless otherwise specified in a particular implementation, the collections returned by methods in this package should be expected to be unmodifiable by the caller and unsafe for concurrent access. 

Unless otherwise specified, methods in this package will throw a NullPointerException if given a null argument.

**Since:**

1.6

#### Interface Summary

Interface | Description  
---|---  
[Elements](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elements-0000001170214383) | Utility methods for operating on program elements.  
[Types](https://developer.harmonyos.com/cn/docs/documentation/doc-references/types-0000001123694552) | Utility methods for operating on types.
