# Messager
    
    public interface Messager  
  
---  
A Messager provides the way for an annotation processor to report error messages, warnings, and other notices. Elements, annotations, and annotation values can be passed to provide a location hint for the message. However, such location hints may be unavailable or only approximate. 

Printing a message with an [error kind](https://developer.harmonyos.com/cn/docs/documentation/doc-references/diagnostic_kind-0000001170334515#ZH-CN_TOPIC_0000001170334515__ERROR) will [raise an error](https://developer.harmonyos.com/cn/docs/documentation/doc-references/roundenvironment-0000001123694518#ZH-CN_TOPIC_0000001123694518__errorRaised--). 

Note that the messages "printed" by methods in this interface may or may not appear as textual output to a location like [System.out](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__out) or [System.err](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__err). Implementations may choose to present this information in a different fashion, such as messages in a window.
