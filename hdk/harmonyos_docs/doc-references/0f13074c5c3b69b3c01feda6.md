# Overview  
  
Provides interfaces for reading and setting the system time and time zone as well as the interfaces for implementing system timers, such as creating and stopping a timer. 

For details about timer interfaces, see [Timer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer-0000001054558955).

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Timer.ITimerListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_itimerlistener-0000001054518966) | Provides a callback for a timer.  
  
#### Class Summary

Class | Description  
---|---  
[Time](https://developer.harmonyos.com/cn/docs/documentation/doc-references/time-0000001054358933) | Defines Time objects used for obtaining and setting the system time and time zone.  
[Timer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer-0000001054558955) | Provides applications with access to the timer system.  
[Timer.OneShotTimer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_oneshottimer-0000001054238953) | Provides the oneshot timer function.  
[Timer.RepeatTimer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_repeattimer-0000001054678923) | Provides a repeating timer with a fixed interval for applications.  
[Timer.TimerIntent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_timerintent-0000001054838908) | Creates an Intent data class to send after a timer is triggered.
