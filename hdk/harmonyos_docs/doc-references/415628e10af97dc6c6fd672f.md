# ProxySelector  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.net.ProxySelector
    
    public abstract class ProxySelector
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Selects the proxy server to use, if any, when connecting to the network resource referenced by a URL. A proxy selector is a concrete sub-class of this class and is registered by invoking the [setDefault](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxyselector-0000001054119736#ZH-CN_TOPIC_0000001054119736__setDefault-java_net_ProxySelector-) method. The currently registered proxy selector can be retrieved by calling [getDefault](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxyselector-0000001054119736#ZH-CN_TOPIC_0000001054119736__getDefault--) method. 

When a proxy selector is registered, for instance, a subclass of URLConnection class should call the [select](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxyselector-0000001054119736#ZH-CN_TOPIC_0000001054119736__select-java_net_URI-) method for each URL request so that the proxy selector can decide if a direct, or proxied connection should be used. The [select](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxyselector-0000001054119736#ZH-CN_TOPIC_0000001054119736__select-java_net_URI-) method returns an iterator over a collection with the preferred connection approach. 

If a connection cannot be established to a proxy (PROXY or SOCKS) servers then the caller should call the proxy selector's [connectFailed](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxyselector-0000001054119736#ZH-CN_TOPIC_0000001054119736__connectFailed-java_net_URI-java_net_SocketAddress-java_io_IOException-) method to notify the proxy selector that the proxy server is unavailable. 

The default proxy selector does enforce a [ set of System Properties](https://docs.oracle.com/javase/8/docs/api/java/net/doc-files/net-properties.html#Proxies) related to proxy settings.

**Since:**

1.5

#### [h2]select

public abstract [List](https://developer.harmonyos.com/cn/docs/documentation/doc-references/list-0000001054119842)<[Proxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxy-0000001054119807)> select​([URI](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434) uri)

Selects all the applicable proxies based on the protocol to access the resource with and a destination address to access the resource at. The format of the URI is defined as follow: 
    * http URI for http connections
    * https URI for https connections 
    * socket://host:port for tcp client sockets connections

**Parameters:**

Parameter Name | Parameter Description  
---|---  
uri  |  The URI that a connection is required to  
  
**Returns:**

a List of Proxies. Each element in the the List is of type [Proxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxy-0000001054119807); when no proxy is available, the list will contain one element of type [Proxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxy-0000001054119807) that represents a direct connection.

**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  if the argument is null  
  
#### [h2]connectFailed

public abstract void connectFailed​([URI](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434) uri, [SocketAddress](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketaddress-0000001054358459) sa, [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) ioe)

Called to indicate that a connection could not be established to a proxy/socks server. An implementation of this method can temporarily remove the proxies or reorder the sequence of proxies returned by [select(java.net.URI)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/proxyselector-0000001054119736#ZH-CN_TOPIC_0000001054119736__select-java_net_URI-), using the address and the IOException caught when trying to connect. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
uri  |  The URI that the proxy at sa failed to serve.  
sa  |  The socket address of the proxy/SOCKS server  
ioe  |  The I/O exception thrown when the connect failed.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  if either argument is null
