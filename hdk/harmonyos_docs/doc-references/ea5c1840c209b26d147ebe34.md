#### [h2]connect

public void connect​([PipedWriter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pipedwriter-0000001054439721) src) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Causes this piped reader to be connected to the piped writer src. If this object is already connected to some other piped writer, an IOException is thrown. 

If src is an unconnected piped writer and snk is an unconnected piped reader, they may be connected by either the call: 
    
    snk.connect(src) 

or the call: 
    
    src.connect(snk) 

The two calls have the same effect.

**Parameters:**

---|---  
src  |  The piped writer to connect to.

Throw Name | Throw Description

#### [h2]read

public int read​(char[] cbuf, int off, int len) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Reads up to len characters of data from this piped stream into an array of characters. Less than len characters will be read if the end of the data stream is reached or if len exceeds the pipe's buffer size. This method blocks until at least one character of input is available. 

**Specified by:**

[read](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435#ZH-CN_TOPIC_0000001054238435__read-char:A-int-int-) in class [Reader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435)

**Parameters:**

Parameter Name | Parameter Description

off  |  the start offset of the data.  
len  |  the maximum number of characters read.  
  
**Returns:**
