# LongSupplier
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface LongSupplier  
  
---  
Represents a supplier of long-valued results. This is the long-producing primitive specialization of [Supplier](https://developer.harmonyos.com/cn/docs/documentation/doc-references/supplier-0000001054678599). 

There is no requirement that a distinct result be returned each time the supplier is invoked. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [getAsLong()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longsupplier-0000001054119886#ZH-CN_TOPIC_0000001054119886__getAsLong--).
