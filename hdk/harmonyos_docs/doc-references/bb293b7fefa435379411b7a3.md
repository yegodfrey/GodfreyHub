# InstantiationError

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Error](https://developer.harmonyos.com/cn/docs/documentation/doc-references/error-0000001054199728) |---|---|---[java.lang.LinkageError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/linkageerror-0000001054678425) |---|---|---|---[java.lang.IncompatibleClassChangeError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/incompatibleclasschangeerror-0000001054358435) |---|---|---|---|---java.lang.InstantiationError
    
    public class InstantiationError
    extends [IncompatibleClassChangeError](https://developer.harmonyos.com/cn/docs/documentation/doc-references/incompatibleclasschangeerror-0000001054358435)  
  
---  
Thrown when an application tries to use the Java new construct to instantiate an abstract class or an interface. 

Normally, this error is caught by the compiler; this error can only occur at run time if the definition of a class has incompatibly changed.

**Since:**

JDK1.0
