# Overview  
  
Contains the configuration and interface classes of the computer vision (CV) single image super-resolution (SISR) and text image super-resolution functions.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[IImageSuperResolution](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iimagesuperresolution-0000001054518782) | Provides the single image super-resolution (SISR) function.  
[ITxtImageSuperResolution](https://developer.harmonyos.com/cn/docs/documentation/doc-references/itxtimagesuperresolution-0000001054678770) | Provides the text image super-resolution (TISR) function.  
  
#### Class Summary

Class | Description  
---|---  
[SisrConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sisrconfiguration-0000001054558771) | Sets basic parameters required for single image super-resolution (SISR).  
[SisrConfiguration.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sisrconfiguration_builder-0000001054238769) | A nested class used to create a [SisrConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sisrconfiguration-0000001054558771) object.  
[SrParamKey](https://developer.harmonyos.com/cn/docs/documentation/doc-references/srparamkey-0000001054678739) | A utility class that defines parameter keys and constant values of [IImageSuperResolution](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iimagesuperresolution-0000001054518782).  
[TxtImageSuperResolutionConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/txtimagesuperresolutionconfiguration-0000001054838724) | A configuration class for text image super-resolution.  
[TxtImageSuperResolutionConfiguration.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/txtimagesuperresolutionconfiguration_builder-0000001054358758) | A nested class used to create a [TxtImageSuperResolutionConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/txtimagesuperresolutionconfiguration-0000001054838724) object.
