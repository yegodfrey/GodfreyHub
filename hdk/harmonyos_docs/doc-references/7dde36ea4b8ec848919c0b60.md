# AbilityAgent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.ability.assistance.AbilityAgent
    
    public class AbilityAgent
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides methods to listen for the lifecycle of and send messages to the peer ability. After your application successfully calls the [Ability#startAssistAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__startAssistAbility-ohos_aafwk_content_Intent-ohos_aafwk_ability_assistance_IAssistanceChannel-) method, the framework returns the agent object of the peer ability to your application.

7
