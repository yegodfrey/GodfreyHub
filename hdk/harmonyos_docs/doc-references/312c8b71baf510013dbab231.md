# InterruptedException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---java.lang.InterruptedException
    
    public class InterruptedException
    extends [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708)  
  
---  
Thrown when a thread is waiting, sleeping, or otherwise occupied, and the thread is interrupted, either before or during the activity. Occasionally a method may wish to test whether the current thread has been interrupted, and if so, to immediately throw this exception. The following code can be used to achieve this effect: 
    
    if (Thread.interrupted())  // Clears interrupted status!
          throw new InterruptedException();

JDK1.0
