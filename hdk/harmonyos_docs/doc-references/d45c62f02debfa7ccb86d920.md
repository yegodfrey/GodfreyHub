# Overview  
  
Provides ORM interfaces to perform basic operations on databases. 

This operations include adding, deleting, modifying, and querying database objects.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[EntityHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/entityhelper-0000001054358798)<T> | Provides the helper interface for operating [OrmObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormobject-0000001054120141) objects.  
[OrmContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormcontext-0000001054120139) | An interface provided by the object relational mapping (ORM) system for operating ORM database entities defined in [OrmObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormobject-0000001054120141).  
[OrmObjectObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormobjectobserver-0000001054120068) | Represents the observer of object relational mapping (ORM) databases.
