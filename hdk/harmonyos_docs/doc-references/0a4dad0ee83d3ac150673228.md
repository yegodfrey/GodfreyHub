# Overview  
  
Defines the base class for common computer vision (CV) classes, including data structure, callback method, and configuration classes.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[ConnectionCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/connectioncallback-0000001054358752) | Provides a callback method for receiving service status changes.  
[ICvBase](https://developer.harmonyos.com/cn/docs/documentation/doc-references/icvbase-0000001054120093) | Parent interface of basic CV ability interfaces.  
[VisionCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/visioncallback-0000001054120022)<T> | A callback template class of plug-in methods.  
  
#### Class Summary

Class | Description  
---|---  
[BoundingBox](https://developer.harmonyos.com/cn/docs/documentation/doc-references/boundingbox-0000001054200038) | Provides a bounding box that determines the rectangle of the detected text.  
[CvPoint](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cvpoint-0000001054518778) | Describes location information of an image in a two-dimensional coordinate system.  
[CvRect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cvrect-0000001054678766) | Describes the rectangle area of images.  
[ImageResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imageresult-0000001054358745) | Stores images.  
[ParamKey](https://developer.harmonyos.com/cn/docs/documentation/doc-references/paramkey-0000001054558767) | Provides keys passed to PacMap.  
[VisionConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/visionconfiguration-0000001054238765) | Defines common configurations for CV abilities.  
[VisionConfiguration.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/visionconfiguration_builder-0000001054678735)<T extends [VisionConfiguration.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/visionconfiguration_builder-0000001054678735)<T>> | A nested class used to create a [VisionConfiguration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/visionconfiguration-0000001054238765) object.  
[VisionImage](https://developer.harmonyos.com/cn/docs/documentation/doc-references/visionimage-0000001054838720) | Constructs an input image for text detection methods.  
[VisionManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/visionmanager-0000001054358754) | Provides methods for initializing HUAWEI HiAI Engine services and CV abilities.
