# Component.RotationEventListener
    
    public static interface Component.RotationEventListener  
  
---  
Provides a callback to be invoked when a rotation event is dispatched from a component. 

This callback will be invoked before the component receives the event.

#### [h2]onRotationEvent

boolean onRotationEvent​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, [RotationEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rotationevent-0000001054678958) event)

Rotates a knob event dispatched to a component. 

The listener responds to a rotation event before the component receives the event.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component to which the rotation event is dispatched.  
event  |  Indicates all information about the rotation event.  
  
**Returns:**

Returns true if the listener has processed the event; returns false otherwise.
