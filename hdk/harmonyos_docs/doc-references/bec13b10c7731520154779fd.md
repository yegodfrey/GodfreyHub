#### [h2]onUnconsumedKeyEvent

boolean onUnconsumedKeyEvent​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, [KeyEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285) event)

Called when a keyboard event is dispatched to this component if it has not been consumed by focused component. If there are multiple listeners from different components, notification will be sent to each listener from top to bottom (by z-order) before the key event is claimed consuming by any listener. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates the component to which the key event is dispatched.  
event  |  Indicates all information about the key event.  
  
**Returns:**

Returns true if the listener has consumed the event; returns false otherwise.
