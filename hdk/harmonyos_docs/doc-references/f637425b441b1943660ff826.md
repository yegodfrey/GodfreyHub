Constructor Detail [h2]SubscriptRichStyle public SubscriptRichStyle​() A constructor used to create a [SubscriptRichStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/subscriptrichstyle-0000001172716664) instance. This method displays the text defined by [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706) as subscripts. The method reduces the text size to 2/3 of the original size and aligns the descent of the text with that of the line where the text is located. The line height, however, is not affected. You can use [RichText.removeRichStyle(RichStyle)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706#ZH-CN_TOPIC_0000001054838706__removeRichStyle-ohos_agp_text_richstyles_RichStyle-) to cancel this style. **Since:** 7 **See Also:** [RichText.removeRichStyle(RichStyle)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706#ZH-CN_TOPIC_0000001054838706__removeRichStyle-ohos_agp_text_richstyles_RichStyle-)
