# DoublePredicate
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface DoublePredicate  
  
---  
Represents a predicate (boolean-valued function) of one double-valued argument. This is the double-consuming primitive type specialization of [Predicate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/predicate-0000001054238629). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [test(double)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublepredicate-0000001054558627#ZH-CN_TOPIC_0000001054558627__test-double-).

**Since:**

1.8

#### [h2]and

default [DoublePredicate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublepredicate-0000001054558627) and​([DoublePredicate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doublepredicate-0000001054558627) other)

Returns a composed predicate that represents a short-circuiting logical AND of this predicate and another. When evaluating the composed predicate, if this predicate is false, then the other predicate is not evaluated. 

Any exceptions thrown during evaluation of either predicate are relayed to the caller; if evaluation of this predicate throws an exception, the other predicate will not be evaluated.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
other  |  a predicate that will be logically-ANDed with this predicate  
  
**Returns:**

a composed predicate that represents the short-circuiting logical AND of this predicate and the other predicate
