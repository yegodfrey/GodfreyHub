# RadialShader

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.render.Shader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746) |---|---ohos.agp.render.RadialShader

    extends [Shader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746)

Represents a shader that shades colors in radial manner around a center point. 

This class inherits from [Shader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746). You can use the methods in this class to configure the position of each color.

#### Field Detail

#### [h2]stops

public float[] stops

Indicates the positions corresponding the shading colors in the [Shader#shaderColors](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shader-0000001054518746#ZH-CN_TOPIC_0000001054518746__shaderColors) array. 

Color stops values monotonically increase from 0 to 1.0. If the stops parameter is null, the colors will be evenly shaded.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
newPoint  |  Indicates the coordinate of the center point of the radial shader.  
newRadius  |  Indicates the radius of the radial shader.  
newStops  |  Indicates the positions corresponding to the colors in newColors. This parameter can be null.  
newColors  |  Indicates the array of radial shading colors.  
newTileMode  |  Indicates the tile mode used to shade colors when the drawn object exceeds the shading area defined by the radial shader.
