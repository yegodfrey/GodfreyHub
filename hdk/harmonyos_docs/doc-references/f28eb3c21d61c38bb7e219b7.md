# IntersectionType  
      
    public interface IntersectionType
    extends [TypeMirror](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typemirror-0000001123534712)  
  
---  
Represents an intersection type. 

An intersection type can be either implicitly or explicitly declared in a program. For example, the bound of the type parameter <T extends Number & Runnable> is an (implicit) intersection type. As of [RELEASE_8](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sourceversion-0000001170214357#ZH-CN_TOPIC_0000001170214357__RELEASE_8), this is represented by an IntersectionType with Number and Runnable as its bounds.

**Since:**

1.8
