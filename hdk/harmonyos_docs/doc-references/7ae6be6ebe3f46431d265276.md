# MifareUltralightTag

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.nfc.tag.TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) |---|---ohos.nfc.tag.MifareUltralightTag
    
    public class MifareUltralightTag
    extends [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954)  
  
---  
Provides interfaces to create a MIFARE Ultralight tag and perform I/O operations on the tag. 

This class inherits from the [TagManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/tagmanager-0000001054358954) abstract class and provides interfaces to create a MIFARE Ultralight tag, obtain the tag type, and read and write pages of the tag.
