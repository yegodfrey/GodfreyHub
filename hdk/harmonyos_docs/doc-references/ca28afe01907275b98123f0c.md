# Overview  
  
Service-provider classes for the [java.nio.file](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054119831) package. 

Only developers who are defining new file system providers or file type detectors should need to make direct use of this package. 

Unless otherwise noted, passing a null argument to a constructor or method in any class or interface in this package will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown.

**Since:**

1.7
