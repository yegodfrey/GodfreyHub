# IntentConstants

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.IntentConstants
    
    public final class IntentConstants
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Defines the [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019)-related constants used in the system, including the actions, entities, and flags contained in the intents passed to methods for starting an ability. 

In the description below, a Page, Service, or Data ability indicates an ability using the respective template, whereas the ability alone indicates an ability using any type of templates. 

**Since:**

3
