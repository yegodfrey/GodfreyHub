# Overview  
  
Provides basic 3D components, including the camera, light, node, and scene.

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[CameraComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cameracomponent-0000001054678709) | Represents the camera component.  
[LightComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lightcomponent-0000001054838694) | Represents the light component.  
[LocalMatrixComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/localmatrixcomponent-0000001054358728) | Contains the local transform of an entity in a matrix.  
[MorphComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/morphcomponent-0000001054120069) | Represents the morphing component.  
[NodeComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nodecomponent-0000001054119998) | Represents the node component that describes hierarchical relationships among objects.  
[RenderMeshComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rendermeshcomponent-0000001054440027) | Represents the rendering mesh component.  
[SceneComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/scenecomponent-0000001054200014) | Represent the scene component.  
[SkinComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/skincomponent-0000001054518754) | Represents the skin component used to map skeletal joint data to a mesh.  
[TransformComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transformcomponent-0000001054678742) | Stores and modifies information about objects.  
[WorldMatrixComponent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/worldmatrixcomponent-0000001054358721) | Contains the world transform of an entity in a matrix.
