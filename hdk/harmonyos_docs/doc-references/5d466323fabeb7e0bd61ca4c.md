# InterruptedIOException  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.io.IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |---|---|---|---java.io.InterruptedIOException
    
    public class InterruptedIOException
    extends [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)  
  
---  
Signals that an I/O operation has been interrupted. An InterruptedIOException is thrown to indicate that an input or output transfer has been terminated because the thread performing it was interrupted. The field [bytesTransferred](https://developer.harmonyos.com/cn/docs/documentation/doc-references/interruptedioexception-0000001054238437#ZH-CN_TOPIC_0000001054238437__bytesTransferred) indicates how many bytes were successfully transferred before the interruption occurred.
