# CommonEventData

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.commonevent.CommonEventData
    
    public final class CommonEventData
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Carries common events, for example, publishing common event contents and storing common events received after subscription. 

To publish a common event, call the [CommonEventData(ohos.aafwk.content.Intent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventdata-0000001054558837#ZH-CN_TOPIC_0000001054558837__CommonEventData-ohos_aafwk_content_Intent-) or [CommonEventData(ohos.aafwk.content.Intent,int,java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventdata-0000001054558837#ZH-CN_TOPIC_0000001054558837__CommonEventData-ohos_aafwk_content_Intent-int-java_lang_String-) method to initialize the Intent attribute, set Action and IntentParams of the common event based on [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019), and then use the [CommonEventManager#publishCommonEvent(CommonEventData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventmanager-0000001054238835#ZH-CN_TOPIC_0000001054238835__publishCommonEvent-ohos_event_commonevent_CommonEventData-) method with CommonEventData as the input parameter to finish the publishing. To subscribe to a common event, you need to inherit the class [CommonEventSubscriber](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscriber-0000001054358824) and override the [CommonEventSubscriber#onReceiveEvent(CommonEventData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscriber-0000001054358824#ZH-CN_TOPIC_0000001054358824__onReceiveEvent-ohos_event_commonevent_CommonEventData-) callback method. After a common event is received, CommonEventData stores the received common event object.
