# NotSerializableException  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.io.IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |---|---|---|---[java.io.ObjectStreamException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstreamexception-0000001054439725) |---|---|---|---|---java.io.NotSerializableException
    
    public class NotSerializableException
    extends [ObjectStreamException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstreamexception-0000001054439725)  
  
---  
Thrown when an instance is required to have a Serializable interface. The serialization runtime or the class of the instance can throw this exception. The argument should be the name of the class.

**Since:**

JDK1.1
