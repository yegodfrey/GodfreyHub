Provides a BaseItemProvider object to associate an [ComponentProvider](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001) item with the fundamental data of the component.  A provider provides access to data items and creates a [Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) for each item in the dataset. When the content in a dataset changes, the subscriber is notified to respond to the changes, and the updated content is refreshed on the screen synchronously. **Since:** 3Constructor Summary Constructor | Description
