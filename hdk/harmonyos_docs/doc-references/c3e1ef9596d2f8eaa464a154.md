#### [h2]onArrange

boolean onArrange​(int left, int top, int width, int height)

Notifies the component-container to set the children positions and sizes when layouting 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
left  |  Indicates the left edge's relative position, in pixels.  
top  |  Indicates the top edge's relative position, in pixels.  
width  |  Indicates the component width, in pixels.  
height  |  Indicates the component height, in pixels.  
  
**Returns:**

Should return True if this component has handled layouting in onArrange(), and there's no need to start layouting on native side, false otherwise.
