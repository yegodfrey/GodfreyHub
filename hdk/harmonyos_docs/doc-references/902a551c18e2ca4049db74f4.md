# Overview  
  
Provides capabilities of querying OHOS system permissions and network security policies. 

    * [NetworkSecurityPolicy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/networksecuritypolicy-0000001060411197): provides methods for querying network security policies, for example, checking whether plaintext is allowed for accessing a process.
    * [SystemPermission](https://developer.harmonyos.com/cn/docs/documentation/doc-references/systempermission-0000001054238971): provides OHOS system permissions, including the description, grant mode, and available scope of each permission.
