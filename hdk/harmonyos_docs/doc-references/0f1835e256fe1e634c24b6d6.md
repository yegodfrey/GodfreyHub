# FutureTask  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.concurrent.FutureTask<V>
    
    public class FutureTask<V>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [RunnableFuture](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runnablefuture-0000001054119937)<V>  
  
---  
A cancellable asynchronous computation. This class provides a base implementation of [Future](https://developer.harmonyos.com/cn/docs/documentation/doc-references/future-0000001054838562), with methods to start and cancel a computation, query to see if the computation is complete, and retrieve the result of the computation. The result can only be retrieved when the computation has completed; the get methods will block if the computation has not yet completed. Once the computation has completed, the computation cannot be restarted or cancelled (unless the computation is invoked using [runAndReset()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/futuretask-0000001054518626#ZH-CN_TOPIC_0000001054518626__runAndReset--)). 

A FutureTask can be used to wrap a [Callable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callable-0000001054358594) or [Runnable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/runnable-0000001054838396) object. Because FutureTask implements Runnable, a FutureTask can be submitted to an [Executor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/executor-0000001054358587) for execution. 

In addition to serving as a standalone class, this class provides protected functionality that may be useful when creating customized task classes.

#### [h2]cancel

public boolean cancel​(boolean mayInterruptIfRunning)

Description copied from interface: [Future](https://developer.harmonyos.com/cn/docs/documentation/doc-references/future-0000001054838562#ZH-CN_TOPIC_0000001054838562__cancel-boolean-)

Attempts to cancel execution of this task. This attempt will fail if the task has already completed, has already been cancelled, or could not be cancelled for some other reason. If successful, and this task has not started when cancel is called, this task should never run. If the task has already started, then the mayInterruptIfRunning parameter determines whether the thread executing this task should be interrupted in an attempt to stop the task. 

After this method returns, subsequent calls to [Future.isDone()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/future-0000001054838562#ZH-CN_TOPIC_0000001054838562__isDone--) will always return true. Subsequent calls to [Future.isCancelled()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/future-0000001054838562#ZH-CN_TOPIC_0000001054838562__isCancelled--) will always return true if this method returned true.

#### [h2]done

protected void done​()

Protected method invoked when this task transitions to state isDone (whether normally or via cancellation). The default implementation does nothing. Subclasses may override this method to invoke completion callbacks or perform bookkeeping. Note that you can query status inside the implementation of this method to determine whether this task has been cancelled.

#### [h2]runAndReset

protected boolean runAndReset​()

Executes the computation without setting its result, and then resets this future to initial state, failing to do so if the computation encounters an exception or is cancelled. This is designed for use with tasks that intrinsically execute more than once. 

**Returns:**

true if successfully run and reset
