Encapsulates the asynchronous result of the current ordered common event. An AsyncCommonEventResult object is returned by [CommonEventSubscriber#goAsyncCommonEvent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscriber-0000001054358824#ZH-CN_TOPIC_0000001054358824__goAsyncCommonEvent--) in the [CommonEventSubscriber#onReceiveEvent(CommonEventData)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/commoneventsubscriber-0000001054358824#ZH-CN_TOPIC_0000001054358824__onReceiveEvent-ohos_event_commonevent_CommonEventData-) callback method. This allows your application to process the current common event on another thread instead of the main thread. However, this requires that your application call the [finishCommonEvent()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynccommoneventresult-0000001054358815#ZH-CN_TOPIC_0000001054358815__finishCommonEvent--) method when processing of the common event is complete. **Since:** 2Method Summary Modifier and Type | Method | Description
