A [ReminderRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419) child class used for creating reminders for calendar events. 

You can use this class to publish calendar event reminders at a specified time (accurate to minute) on a particular day or on particular days in the specific months.

#### [h2]ReminderRequestCalendar

public ReminderRequestCalendar​([LocalDateTime](https://developer.harmonyos.com/cn/docs/documentation/doc-references/localdatetime-0000001054119897) dateTime, int[] repeatMonths, int[] repeatDays)

A constructor used to create a ReminderRequestCalendar instance. The calendar event reminder will be triggered at a specified time. 

Ensure that the input parameters meet the following requirements. Otherwise, the application may crash due to an illegal parameter exception. 

    * The dateTime parameter cannot be null. 
    * The repeatMonths parameter cannot be null. 
    * The repeatDays parameter cannot be null. 
    * The length of the repeatMonths array cannot exceed 12. 
    * The length of the repeatDays array cannot exceed 31. 
    * There must be at least one valid reminder time. Ensure that the time specified by dateTime does not expire, or repeatMonths and repeatDays are valid.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
dateTime  |  Indicates the date and time when this calendar event reminder will be triggered. The time is accurate to minute. For example, the value LocalDateTime.of(2021, 3, 3, 16, 15) indicates that the reminder will be triggered at 16:15 on March 3, 2021.  
repeatMonths  |  Indicates the months in which this reminder will be repeated. For example, the value {2, 4} indicates that the reminder will be triggered on particular days in February and April.  
repeatDays  |  Indicates the days in a month when this reminder will be repeated. For example, the value {2, 4} indicates that the reminder will be triggered on the second and fourth days of the specific months. The repeatMonths and repeatDays parameters must both be set to implement repeated reminders. By default, this reminder is not snoozed. You can call [ReminderRequest.setTimeInterval(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419#ZH-CN_TOPIC_0000001170214419__setTimeInterval-long-) to set the snooze interval. If a snooze interval is set, this reminder will be snoozed for three times by default. You can call [ReminderRequest.setSnoozeTimes(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reminderrequest-0000001170214419#ZH-CN_TOPIC_0000001170214419__setSnoozeTimes-int-) to change the snooze times.
