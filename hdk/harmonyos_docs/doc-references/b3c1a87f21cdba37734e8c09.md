#### [h2]subMap

[ConcurrentNavigableMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620)<[K](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620),[V](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620)> subMap​([K](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620) fromKey, boolean fromInclusive, [K](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620) toKey, boolean toInclusive)

Description copied from interface: [NavigableMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/navigablemap-0000001054678586#ZH-CN_TOPIC_0000001054678586__subMap-K-boolean-K-boolean-)

Returns a view of the portion of this map whose keys range from fromKey to toKey. If fromKey and toKey are equal, the returned map is empty unless fromInclusive and toInclusive are both true. The returned map is backed by this map, so changes in the returned map are reflected in this map, and vice-versa. The returned map supports all optional map operations that this map supports. 

The returned map will throw an IllegalArgumentException on an attempt to insert a key outside of its range, or to construct a submap either of whose endpoints lie outside its range.

Description copied from interface: [NavigableMap](https://developer.harmonyos.com/cn/docs/documentation/doc-references/navigablemap-0000001054678586#ZH-CN_TOPIC_0000001054678586__subMap-K-K-)

Returns a view of the portion of this map whose keys range from fromKey, inclusive, to toKey, exclusive. (If fromKey and toKey are equal, the returned map is empty.) The returned map is backed by this map, so changes in the returned map are reflected in this map, and vice-versa. The returned map supports all optional map operations that this map supports. 

The returned map will throw an IllegalArgumentException on an attempt to insert a key outside its range. 

Equivalent to subMap(fromKey, true, toKey, false).

#### [h2]navigableKeySet

[NavigableSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/navigableset-0000001054358565)<[K](https://developer.harmonyos.com/cn/docs/documentation/doc-references/concurrentnavigablemap-0000001054518620)> navigableKeySet​()

Returns a [NavigableSet](https://developer.harmonyos.com/cn/docs/documentation/doc-references/navigableset-0000001054358565) view of the keys contained in this map. The set's iterator returns the keys in ascending order. The set is backed by the map, so changes to the map are reflected in the set, and vice-versa. The set supports element removal, which removes the corresponding mapping from the map, via the Iterator.remove, Set.remove, removeAll, retainAll, and clear operations. It does not support the add or addAll operations. 

The view's iterators and spliterators are [_weakly consistent_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054558607#ZH-CN_TOPIC_0000001054558607__Weakly).

**Specified by:**
