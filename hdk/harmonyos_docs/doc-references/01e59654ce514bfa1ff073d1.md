XMLStreamWriter
    
    public interface XMLStreamWriter  
  
---  
The XMLStreamWriter interface specifies how to write XML. The XMLStreamWriter does not perform well formedness checking on its input. However the writeCharacters method is required to escape & , < and > For attribute values the writeAttribute method will escape the above characters plus " to ensure that all character content and attribute values are well formed. Each NAMESPACE and ATTRIBUTE must be individually written. **Since:** 1.6**See Also:** [XMLOutputFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmloutputfactory-0000001054120152), [XMLStreamReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlstreamreader-0000001054678863)Method Summary Modifier and Type | Method | Description
