Indicates the rendering mode. 

The rendering mode controls how the engine renders a frame of image. It can be set by using [Engine.setRenderMode(ohos.agp.render.render3d.Engine.RenderMode)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/engine-0000001054838690#ZH-CN_TOPIC_0000001054838690__setRenderMode-ohos_agp_render_render3d_Engine_RenderMode-). When the content on the screen does not change, the rendering can be skipped to save GPU and CPU resources.
