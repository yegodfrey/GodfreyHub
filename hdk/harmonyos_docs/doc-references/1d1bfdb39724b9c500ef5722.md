# DecimalFormatSymbols

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.text.DecimalFormatSymbols
    
    public class DecimalFormatSymbols
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421), [Serializable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serializable-0000001054358416)  
  
---  
This class represents the set of symbols (such as the decimal separator, the grouping separator, and so on) needed by DecimalFormat to format numbers. DecimalFormat creates for itself an instance of DecimalFormatSymbols from its locale data. If you need to change any of these symbols, you can get the DecimalFormatSymbols object from your DecimalFormat and modify it.

#### [h2]DecimalFormatSymbols

public DecimalFormatSymbols​()

Create a DecimalFormatSymbols object for the default [FORMAT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale_category-0000001054518614#ZH-CN_TOPIC_0000001054518614__FORMAT) locale. This constructor can only construct instances for the locales supported by the Java runtime environment, not for those supported by installed DecimalFormatSymbolsProvider implementations. For full locale coverage, use the [getInstance](https://developer.harmonyos.com/cn/docs/documentation/doc-references/decimalformatsymbols-0000001054119893#ZH-CN_TOPIC_0000001054119893__getInstance-java_util_Locale-) method. 

This is equivalent to calling [DecimalFormatSymbols(Locale.getDefault(Locale.Category.FORMAT))](https://developer.harmonyos.com/cn/docs/documentation/doc-references/decimalformatsymbols-0000001054119893#ZH-CN_TOPIC_0000001054119893__DecimalFormatSymbols-java_util_Locale-).

#### [h2]DecimalFormatSymbols

public DecimalFormatSymbols​([Locale](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852) locale)

Create a DecimalFormatSymbols object for the given locale. This constructor can only construct instances for the locales supported by the Java runtime environment, not for those supported by installed DecimalFormatSymbolsProvider implementations. For full locale coverage, use the [getInstance](https://developer.harmonyos.com/cn/docs/documentation/doc-references/decimalformatsymbols-0000001054119893#ZH-CN_TOPIC_0000001054119893__getInstance-java_util_Locale-) method. If the specified locale contains the [Locale.UNICODE_LOCALE_EXTENSION](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852#ZH-CN_TOPIC_0000001054119852__UNICODE_LOCALE_EXTENSION) for the numbering system, the instance is initialized with the specified numbering system if the JRE implementation supports it. For example, 
    
    NumberFormat.getNumberInstance(Locale.forLanguageTag("th-TH-u-nu-thai"))
     

This may return a NumberFormat instance with the Thai numbering system, instead of the Latin numbering system.

#### [h2]getAvailableLocales

public static [Locale](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852)[] getAvailableLocales​()

Returns an array of all locales for which the getInstance methods of this class can return localized instances. The returned array represents the union of locales supported by the Java runtime and by installed DecimalFormatSymbolsProvider implementations. It must contain at least a Locale instance equal to [Locale.US](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852#ZH-CN_TOPIC_0000001054119852__US).
