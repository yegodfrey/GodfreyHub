# Overview  
  
Manages notifications, such as notification publishing, canceling, subscription, unsubscription, and notification slot management. 

The following functions are supported: 

    * Publishes notifications. 
    * Cancels one or all published notifications. 
    * Subscribes to or unsubscribes from notifications. 
    * Creates, cancels, and queries notification slots. 
    * Creates filter criteria for notification subscription and unsubscription. 

The application must have system permissions for notification subscription and unsubscription.
