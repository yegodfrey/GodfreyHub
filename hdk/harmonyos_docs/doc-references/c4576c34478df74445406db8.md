# ComponentState  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.ComponentState
    
    public class ComponentState
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Defines the component state. 

The component state can be [COMPONENT_STATE_FOCUSED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_FOCUSED), [COMPONENT_STATE_SELECTED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_SELECTED), [COMPONENT_STATE_WINDOW_FOCUSED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_WINDOW_FOCUSED), [COMPONENT_STATE_DISABLED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_DISABLED), [COMPONENT_STATE_CHECKED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_CHECKED), [COMPONENT_STATE_DRAG_ENTERED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_DRAG_ENTERED), [COMPONENT_STATE_DRAG_RESPONDED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_DRAG_RESPONDED), [COMPONENT_STATE_PRESSED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_PRESSED) or [COMPONENT_STATE_HOVERED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentstate-0000001054199988#ZH-CN_TOPIC_0000001054199988__COMPONENT_STATE_HOVERED).
