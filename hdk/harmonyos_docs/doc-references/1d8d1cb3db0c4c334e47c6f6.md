# Font.Builder

Provides a builder to create a [Font](https://developer.harmonyos.com/cn/docs/documentation/doc-references/font-0000001054238751) instance. 

You can use it to create a [Font](https://developer.harmonyos.com/cn/docs/documentation/doc-references/font-0000001054238751) instance by specifying the text style.
