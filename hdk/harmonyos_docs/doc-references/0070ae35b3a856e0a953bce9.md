# PrivilegedActionException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---java.security.PrivilegedActionException
    
    public class PrivilegedActionException
    extends [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708)  
  
---  
This exception is thrown by doPrivileged(PrivilegedExceptionAction) and doPrivileged(PrivilegedExceptionAction, AccessControlContext context) to indicate that the action being performed threw a checked exception. The exception thrown by the action can be obtained by calling the getException method. In effect, an PrivilegedActionException is a "wrapper" for an exception thrown by a privileged action. 

As of release 1.4, this exception has been retrofitted to conform to the general purpose exception-chaining mechanism. The "exception thrown by the privileged computation" that is provided at construction time and accessed via the [getException()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/privilegedactionexception-0000001054558533#ZH-CN_TOPIC_0000001054558533__getException--) method is now known as the _cause_ , and may be accessed via the [Throwable#getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method, as well as the aforementioned "legacy method."

#### [h2]getException

public [Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) getException​()

Returns the exception thrown by the privileged computation that resulted in this PrivilegedActionException. 

This method predates the general-purpose exception chaining facility. The [Throwable#getCause()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getCause--) method is now the preferred means of obtaining this information.
