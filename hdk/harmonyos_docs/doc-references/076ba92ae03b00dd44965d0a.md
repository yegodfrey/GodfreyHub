#### [h2]startLocating

public void startLocating​([RequestParam](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestparam-0000001054238901) request, [LocatorCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locatorcallback-0000001054120158) callback) throws [IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724)

Sends location requests to the system.

The system starts the location service based on the input location request parameters and reports the location result to the application through the callback passed in this method.

The system reports the location results to the application in real time until the application proactively stops the location service through [stopLocating(ohos.location.LocatorCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903#ZH-CN_TOPIC_0000001054558903__stopLocating-ohos_location_LocatorCallback-).

To use this method, your application needs to apply for the ohos.permission.LOCATION permission from the user. If the location access permission has not been granted by the user when this method is called, the system returns [ERROR_PERMISSION_NOT_GRANTED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903#ZH-CN_TOPIC_0000001054558903__ERROR_PERMISSION_NOT_GRANTED) to the application through LocatorCallback.

If the location service is disabled when this method is called, the system returns error code [ERROR_SWITCH_UNOPEN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903#ZH-CN_TOPIC_0000001054558903__ERROR_SWITCH_UNOPEN) through LocatorCallback.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
request | Indicates the location request parameters.  
callback | Indicates the callback for reporting the location result.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) | Throws this exception if the specified RequestParam object or the specified LocatorCallback object is null.  
  
**Since:**

1

#### [h2]requestOnce

public void requestOnce​([RequestParam](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestparam-0000001054238901) request, [LocatorCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locatorcallback-0000001054120158) callback) throws [IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724)

Sends a single location request to the system.

The system starts the location service based on the input location request parameters and reports the location result to the application through the callback passed in this method.

This location request is automatically stopped after the system reports the location result. If the location cannot be completed within a reasonable amount of time due to environment issues, you can call [stopLocating(ohos.location.LocatorCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903#ZH-CN_TOPIC_0000001054558903__stopLocating-ohos_location_LocatorCallback-) to enable the application to proactively stop the location request.

To use this method, your application needs to apply for the ohos.permission.LOCATION permission from the user. If the location access permission has not been granted by the user when this method is called, the system returns [ERROR_PERMISSION_NOT_GRANTED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903#ZH-CN_TOPIC_0000001054558903__ERROR_PERMISSION_NOT_GRANTED) to the application through LocatorCallback.

If the location service is disabled when this method is called, the system returns error code [ERROR_SWITCH_UNOPEN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903#ZH-CN_TOPIC_0000001054558903__ERROR_SWITCH_UNOPEN) through LocatorCallback.

**Parameters:**

---|---  
request | Indicates the location request parameters.  
callback | Indicates the callback for reporting the location result.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) | Throws this exception if the specified RequestParam object or the specified LocatorCallback object is null.
