# Overview  
  
Implements management of NFC OMA channels. 

This package consists of classes that provide the interfaces to perform OMA channel operations. 

SEService: Provides access to secure elements on a device. You can use the interfaces provided by this class to obtain the name of a secure element, check whether the secure element is available, and enable a session on the secure element. 

Reader: Provides interfaces to obtain information about secure elements. 

Session: Provides interfaces to create Session objects and manage these objects. 

Channel: Provides interfaces to create Channel objects and obtain Channel information. 

Aid: Provides interfaces to create Aid objects and obtain Aid information.
