# Overview  
  
Allows you to send and process InnerEvent and Runnable objects on asynchronous threads. 

Specifically, you can use this package to: 

    * Dispatch and process InnerEvent and Runnable objects among threads. 
    * Delay the processing InnerEvent and Runnable objects.

1
