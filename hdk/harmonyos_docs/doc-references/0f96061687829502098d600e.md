# Compiler

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.lang.Compiler
    
    public final class Compiler
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
The Compiler class is provided to support Java-to-native-code compilers and related services. By design, the Compiler class does nothing; it serves as a placeholder for a JIT compiler implementation. 

When the Java Virtual Machine first starts, it determines if the system property java.compiler exists. (System properties are accessible through [System#getProperty(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__getProperty-java_lang_String-) and [System#getProperty(String, String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__getProperty-java_lang_String-java_lang_String-). If so, it is assumed to be the name of a library (with a platform-dependent exact location and type); [System#loadLibrary](https://developer.harmonyos.com/cn/docs/documentation/doc-references/system-0000001054558449#ZH-CN_TOPIC_0000001054558449__loadLibrary-java_lang_String-) is called to load that library. If this loading succeeds, the function named java_lang_Compiler_start() in that library is called. 

If no compiler is available, these methods do nothing.

**Since:**

JDK1.0
