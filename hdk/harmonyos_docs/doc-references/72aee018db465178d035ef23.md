# PhantomReference

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.ref.Reference](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reference-0000001054358445)<T> |---|---java.lang.ref.PhantomReference<T>
    
    public class PhantomReference<T>
    extends [Reference](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reference-0000001054358445)<T>

Phantom reference objects, which are enqueued after the collector determines that their referents may otherwise be reclaimed. Phantom references are most often used for scheduling pre-mortem cleanup actions in a more flexible way than is possible with the Java finalization mechanism. 

If the garbage collector determines at a certain point in time that the referent of a phantom reference is [phantom reachable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054199738#ZH-CN_TOPIC_0000001054199738__reachability), then at that time or at some later time it will enqueue the reference. 

In order to ensure that a reclaimable object remains so, the referent of a phantom reference may not be retrieved: The get method of a phantom reference always returns null. 

Unlike soft and weak references, phantom references are not automatically cleared by the garbage collector as they are enqueued. An object that is reachable via phantom references will remain so until all such references are cleared or themselves become unreachable.

#### [h2]PhantomReference

public PhantomReference​([T](https://developer.harmonyos.com/cn/docs/documentation/doc-references/phantomreference-0000001054678466) referent, [ReferenceQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/referencequeue-0000001054558467)<? super [T](https://developer.harmonyos.com/cn/docs/documentation/doc-references/phantomreference-0000001054678466)> q)

Creates a new phantom reference that refers to the given object and is registered with the given queue. 

It is possible to create a phantom reference with a null queue, but such a reference is completely useless: Its get method will always return null and, since it does not have a queue, it will never be enqueued.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
referent  |  the object the new phantom reference will refer to  
q  |  the queue with which the reference is to be registered, or null if registration is not required
