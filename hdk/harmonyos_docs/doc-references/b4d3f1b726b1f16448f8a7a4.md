# Overview  
  
Provides a collection of classes and methods for applications to obtain device locations. 

By using location APIs, an application can: 

    * Send a location request to the system to obtain the device location on a real-time basis. 

[RequestParam](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestparam-0000001054238901) allows your application to specify location request parameters. After a [LocatorCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locatorcallback-0000001054120158) object is instantiated, your application can initiate a location request by calling [Locator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903). If the location request is successful, your application can then call [LocatorCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locatorcallback-0000001054120158) to obtain the [Location](https://developer.harmonyos.com/cn/docs/documentation/doc-references/location-0000001054358881) information. 

    * Obtain the location result cached in the system. 

[Locator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903) allows the application to directly obtain [Location](https://developer.harmonyos.com/cn/docs/documentation/doc-references/location-0000001054358881) information cached in the system. 

    * Obtain the possible address based on a specified location. 

[GeoConvert](https://developer.harmonyos.com/cn/docs/documentation/doc-references/geoconvert-0000001054678902) allows your application to convert location coordinates and location description into [GeoAddress](https://developer.harmonyos.com/cn/docs/documentation/doc-references/geoaddress-0000001054518914) information.

#### Interface Summary

Interface | Description  
---|---  
[LocatorCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locatorcallback-0000001054120158) | Provides a callback interface for the system to report the device location.  
[SwitchCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/switchcallback-0000001054440187) | Provides a callback interface for the system to report the location service switch status.  
  
#### Class Summary

Class | Description  
---|---  
[GeoAddress](https://developer.harmonyos.com/cn/docs/documentation/doc-references/geoaddress-0000001054518914) | Represents a data class that describes geographic locations.  
[GeoConvert](https://developer.harmonyos.com/cn/docs/documentation/doc-references/geoconvert-0000001054678902) | Implements mutual conversion between geographic location and address information.  
[Location](https://developer.harmonyos.com/cn/docs/documentation/doc-references/location-0000001054358881) | Represents a data class that provides information about geographic locations.  
[Locator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locator-0000001054558903) | Provides interfaces for initiating location requests, ending the location service, and obtaining the location result cached by the system.  
[RequestParam](https://developer.harmonyos.com/cn/docs/documentation/doc-references/requestparam-0000001054238901) | Provides data classes for configuring parameters in location requests.
