An abstract class that provides the application context for the current object and obtains the application environment information. This class implements the [Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) interface. Applications can use AbilityContext to obtain resources, start abilities, create or get thread models, and obtain the application package information and running information. [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) is a child class of AbilityContext. Therefore, an ability is an instance of AbilityContext.  **Since:** 1Field Summary Fields inherited from interface ohos.app.[Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065)

An abstract class that provides the application context for the current object and obtains the application environment information. This class implements the [Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065) interface. Applications can use AbilityContext to obtain resources, start abilities, create or get thread models, and obtain the application package information and running information. [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) is a child class of AbilityContext. Therefore, an ability is an instance of AbilityContext.  **Since:** 1Field Summary Fields inherited from interface ohos.app.[Context](https://developer.harmonyos.com/cn/docs/documentation/doc-references/context-0000001054440065)
