#### [h2]crossJoin

Adds a cross join condition to a SQL statement. 

In SQLite, you can use cross joins to associate two unrelated tables. The cross join joins every row from the first table with every row from the second table, and the result set is the product of rows in both tables. Exercise caution when using cross joins during application development because they will exert heavy load on memory and subsequent data processing.

#### [h2]innerJoin

public <J extends [OrmObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormobject-0000001054120141)> [OrmPredicates](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormpredicates-0000001054120070) innerJoin​([Class](https://developer.harmonyos.com/cn/docs/documentation/doc-references/class-0000001054358423)<J> clz)

Adds an inner join condition to a SQL statement. 

In SQLite, you can use inner joins to query data from two related tables. The inner join selects all the rows to display in the result set from the related tables only if both tables meet the conditions specified in the ON clause. The inner joins are syntactically equivalent to the cross joins. Note that inner joins must be used together with [OrmPredicates#on(String...)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormpredicates-0000001054120070#ZH-CN_TOPIC_0000001054120070__on-java_lang_String___-). Otherwise, use [OrmPredicates#crossJoin](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormpredicates-0000001054120070#ZH-CN_TOPIC_0000001054120070__crossJoin-java_lang_Class-) instead.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
clz  |  Indicates the names of the class to join.  
  
**Returns:**

Returns the predicate with the inner join condition.
