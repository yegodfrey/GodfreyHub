# ExemptionMechanism  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---javax.crypto.ExemptionMechanism
    
    public class ExemptionMechanism
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
This class provides the functionality of an exemption mechanism, examples of which are _key recovery_ , _key weakening_ , and _key escrow_. 

Applications or applets that use an exemption mechanism may be granted stronger encryption capabilities than those which don't.

**Since:**

1.4

public final int genExemptionBlob​(byte[] output, int outputOffset) throws [ExemptionMechanismException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exemptionmechanismexception-0000001054439939), [IllegalStateException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalstateexception-0000001054678452), [ShortBufferException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shortbufferexception-0000001054678654)

Generates the exemption mechanism key blob, and stores the result in the output buffer, starting at outputOffset inclusive. 

If the output buffer is too small to hold the result, a ShortBufferException is thrown. In this case, repeat this call with a larger output buffer. Use [getOutputSize](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exemptionmechanism-0000001054358638#ZH-CN_TOPIC_0000001054358638__getOutputSize-int-) to determine how big the output buffer should be.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
output  |  the buffer for the result  
outputOffset  |  the offset in output where the result is stored  
  
**Returns:**

the number of bytes stored in output

**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalStateException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalstateexception-0000001054678452) |  if this exemption mechanism is in a wrong state (e.g., has not been initialized).  
[ShortBufferException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shortbufferexception-0000001054678654) |  if the given output buffer is too small to hold the result.  
[ExemptionMechanismException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exemptionmechanismexception-0000001054439939) |  if problem(s) encountered in the process of generating.
