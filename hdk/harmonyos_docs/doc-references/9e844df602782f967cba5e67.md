# NotificationRequest

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationRequest
    
    public final class NotificationRequest
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Carries notifications. 

In terms of notification publishing, you must call the [setContent(ohos.event.notification.NotificationRequest.NotificationContent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__setContent-ohos_event_notification_NotificationRequest_NotificationContent-) method to specify the notification content, and call the [setDeliveryTime(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__setDeliveryTime-long-) method to set when to deliver the notification, respectively. NotificationRequest is used as an input parameter in the [NotificationHelper#publishNotification(NotificationRequest)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationhelper-0000001054200114#ZH-CN_TOPIC_0000001054200114__publishNotification-ohos_event_notification_NotificationRequest-) method to publish a notification. In terms of notification subscription, you can inherit the [NotificationSubscriber](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationsubscriber-0000001054358823) class and override the callback methods [NotificationSubscriber#onConsumed(NotificationRequest)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationsubscriber-0000001054358823#ZH-CN_TOPIC_0000001054358823__onConsumed-ohos_event_notification_NotificationRequest-) and [NotificationSubscriber#onCanceled(NotificationRequest)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationsubscriber-0000001054358823#ZH-CN_TOPIC_0000001054358823__onCanceled-ohos_event_notification_NotificationRequest-). The received or deleted notifications can be stored in the NotificationRequest object.
