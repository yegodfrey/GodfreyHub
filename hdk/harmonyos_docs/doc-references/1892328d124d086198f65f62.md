# KeyStore.Builder

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.security.KeyStore.Builder
    
    public abstract static class KeyStore.Builder
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A description of a to-be-instantiated KeyStore object. 

An instance of this class encapsulates the information needed to instantiate and initialize a KeyStore object. That process is triggered when the [getKeyStore()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_builder-0000001054358512#ZH-CN_TOPIC_0000001054358512__getKeyStore--) method is called. 

This makes it possible to decouple configuration from KeyStore object creation and e.g. delay a password prompt until it is needed.

#### [h2]newInstance

public static [KeyStore.Builder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_builder-0000001054358512) newInstance​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) type, [Provider](https://developer.harmonyos.com/cn/docs/documentation/doc-references/provider-0000001054199800) provider, [File](https://developer.harmonyos.com/cn/docs/documentation/doc-references/file-0000001054119759) file, [KeyStore.ProtectionParameter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_protectionparameter-0000001054199792) protection)

Returns a new Builder object. 

The first call to the [getKeyStore()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_builder-0000001054358512#ZH-CN_TOPIC_0000001054358512__getKeyStore--) method on the returned builder will create a KeyStore of type type and call its [KeyStore#load](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore-0000001054838478#ZH-CN_TOPIC_0000001054838478__load-java_io_InputStream-char:A-) method. The inputStream argument is constructed from file. If protection is a PasswordProtection, the password is obtained by calling the getPassword method. Otherwise, if protection is a CallbackHandlerProtection, the password is obtained by invoking the CallbackHandler. 

Subsequent calls to [getKeyStore()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_builder-0000001054358512#ZH-CN_TOPIC_0000001054358512__getKeyStore--) return the same object as the initial call. If the initial call to failed with a KeyStoreException, subsequent calls also throw a KeyStoreException. 

The KeyStore is instantiated from provider if non-null. Otherwise, all installed providers are searched. 

Calls to [getProtectionParameter()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_builder-0000001054358512#ZH-CN_TOPIC_0000001054358512__getProtectionParameter-java_lang_String-) will return a [KeyStore.PasswordProtection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_passwordprotection-0000001054119782) object encapsulating the password that was used to invoke the load method. 

Note that the [getKeyStore()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keystore_builder-0000001054358512#ZH-CN_TOPIC_0000001054358512__getKeyStore--) method is executed within the [AccessControlContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accesscontrolcontext-0000001054358508) of the code invoking this method.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
type  |  the type of KeyStore to be constructed  
provider  |  the provider from which the KeyStore is to be instantiated (or null)  
file  |  the File that contains the KeyStore data  
protection  |  the ProtectionParameter securing the KeyStore data  
  
**Returns:**

a new Builder object

**Throws:**
