# drawing_types.h  
  
#### 概述

文件中定义了用于绘制2d图形的数据类型，包括画布、画笔、画刷、位图和路径。

**起始版本：**

8

**相关模块：**

[Drawing](https://developer.harmonyos.com/cn/docs/documentation/doc-references/_drawing-0000001410125457)
