# ObjLongConsumer  
      
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface ObjLongConsumer<T>  
  
---  
Represents an operation that accepts an object-valued and a long-valued argument, and returns no result. This is the (reference, long) specialization of [BiConsumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/biconsumer-0000001054838578). Unlike most other functional interfaces, ObjLongConsumer is expected to operate via side-effects. 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [accept(java.lang.Object,long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objlongconsumer-0000001054558631#ZH-CN_TOPIC_0000001054558631__accept-T-long-).
