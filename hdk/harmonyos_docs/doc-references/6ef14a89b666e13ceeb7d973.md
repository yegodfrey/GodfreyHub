# Override
    
    [@Target](https://developer.harmonyos.com/cn/docs/documentation/doc-references/target-0000001054678431)([METHOD](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementtype-0000001054238459#ZH-CN_TOPIC_0000001054238459__METHOD))
    [@Retention](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retention-0000001054238461)([SOURCE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/retentionpolicy-0000001054678429#ZH-CN_TOPIC_0000001054678429__SOURCE))
    public @interface Override  
  
---  
Indicates that a method declaration is intended to override a method declaration in a supertype. If a method is annotated with this annotation type compilers are required to generate an error message unless at least one of the following conditions hold: 
    * The method does override or implement a method declared in a supertype. 
    * The method has a signature that is override-equivalent to that of any public method declared in [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446).

1.5
