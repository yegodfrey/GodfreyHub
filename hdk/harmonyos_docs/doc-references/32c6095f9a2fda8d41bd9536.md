# ChronoZonedDateTime
    
    public interface ChronoZonedDateTime<D extends [ChronoLocalDate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronolocaldate-0000001054558573)>
    extends [Temporal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporal-0000001054838532), [Comparable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparable-0000001054558443)<[ChronoZonedDateTime](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronozoneddatetime-0000001054358560)<?>>  
  
---  
A date-time with a time-zone in an arbitrary chronology, intended for advanced globalization use cases. 

**Most applications should declare method signatures, fields and variables as[ZonedDateTime](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zoneddatetime-0000001054238569), not this interface.**

A ChronoZonedDateTime is the abstract representation of an offset date-time where the Chronology chronology, or calendar system, is pluggable. The date-time is defined in terms of fields expressed by [TemporalField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalfield-0000001054439865), where most common implementations are defined in [ChronoField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronofield-0000001054119838). The chronology defines how the calendar system operates and the meaning of the standard fields. 

**When to use this interface** The design of the API encourages the use of ZonedDateTime rather than this interface, even in the case where the application needs to deal with multiple calendar systems. The rationale for this is explored in detail in [ChronoLocalDate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronolocaldate-0000001054558573). 

Ensure that the discussion in ChronoLocalDate has been read and understood before using this interface.

Obtains an instance of ChronoZonedDateTime from a temporal object. 

This creates a zoned date-time based on the specified temporal. A TemporalAccessor represents an arbitrary set of date and time information, which this factory converts to an instance of ChronoZonedDateTime. 

The conversion extracts and combines the chronology, date, time and zone from the temporal object. The behavior is equivalent to using [Chronology#zonedDateTime(TemporalAccessor)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/chronology-0000001054678541#ZH-CN_TOPIC_0000001054678541__zonedDateTime-java_time_temporal_TemporalAccessor-) with the extracted chronology. Implementations are permitted to perform optimizations such as accessing those fields that are equivalent to the relevant objects. 

This method matches the signature of the functional interface [TemporalQuery](https://developer.harmonyos.com/cn/docs/documentation/doc-references/temporalquery-0000001054199852) allowing it to be used as a query via method reference, ChronoZonedDateTime::from.

Gets the range of valid values for the specified field. 

All fields can be expressed as a long integer. This method returns an object that describes the valid range for that value. The value of this temporal object is used to enhance the accuracy of the returned range.
