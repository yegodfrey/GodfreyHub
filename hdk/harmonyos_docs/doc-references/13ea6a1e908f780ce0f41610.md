Tool
    
    public interface Tool  
  
---  
Common interface for tools that can be invoked from a program. A tool is traditionally a command line program such as a compiler. The set of tools available with a platform is defined by the vendor. Tools can be located using [ServiceLoader.load(Class)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serviceloader-0000001054558599#ZH-CN_TOPIC_0000001054558599__load-java_lang_Class-). **Since:** 1.6Method Summary Modifier and Type | Method | Description
