A default implementation class for text layout, which supports both plain text and rich text. In addition, the text layout can be edited. [TextLayout](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout-0000001172238188) does not directly generate layouts in the constructor. Instead, it generates layouts only when you explicitly call [doLayout()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout-0000001172238188#ZH-CN_TOPIC_0000001172238188__doLayout--). You can use setters to change your input data and call [doLayout()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/textlayout-0000001172238188#ZH-CN_TOPIC_0000001172238188__doLayout--) to lay out the text.
