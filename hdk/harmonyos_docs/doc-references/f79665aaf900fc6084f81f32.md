# DateFormat

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.text.Format](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054439851) |---|---java.text.DateFormat
    
    public abstract class DateFormat
    extends [Format](https://developer.harmonyos.com/cn/docs/documentation/doc-references/format-0000001054439851)  
  
---  
DateFormat is an abstract class for date/time formatting subclasses which formats and parses dates or time in a language-independent manner. The date/time formatting subclass, such as [SimpleDateFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/simpledateformat-0000001054358554), allows for formatting (i.e., date → text), parsing (text → date), and normalization. The date is represented as a Date object or as the milliseconds since January 1, 1970, 00:00:00 GMT. 

DateFormat provides many class methods for obtaining default date/time formatters based on the default or a given locale and a number of formatting styles. The formatting styles include [FULL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__FULL), [LONG](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__LONG), [MEDIUM](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__MEDIUM), and [SHORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__SHORT). More detail and examples of using these styles are provided in the method descriptions. 

DateFormat helps you to format and parse dates for any locale. Your code can be completely independent of the locale conventions for months, days of the week, or even the calendar format: lunar vs. solar. 

To format a date for the current Locale, use one of the static factory methods: 
    
    myString = DateFormat.getDateInstance().format(myDate);
     

If you are formatting multiple dates, it is more efficient to get the format and use it multiple times so that the system doesn't have to fetch the information about the local language and country conventions multiple times. 
    
    DateFormat df = DateFormat.getDateInstance();
     for (int i = 0; i < myDate.length; ++i) {
         output.println(df.format(myDate[i]) + "; ");
     }
     

To format a date for a different Locale, specify it in the call to [getDateInstance()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__getDateInstance-int-java_util_Locale-). 
    
    DateFormat df = DateFormat.getDateInstance(DateFormat.LONG, Locale.FRANCE);
     

You can use a DateFormat to parse also. 
    
    myDate = df.parse(myString);
     

Use getDateInstance to get the normal date format for that country. There are other static factory methods available. Use getTimeInstance to get the time format for that country. Use getDateTimeInstance to get a date and time format. You can pass in different options to these factory methods to control the length of the result; from [SHORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__SHORT) to [MEDIUM](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__MEDIUM) to [LONG](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__LONG) to [FULL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__FULL). The exact result depends on the locale, but generally: 

    * [SHORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__SHORT) is completely numeric, such as 12.13.52 or 3:30pm 
    * [MEDIUM](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__MEDIUM) is longer, such as Jan 12, 1952 
    * [LONG](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__LONG) is longer, such as January 12, 1952 or 3:30:32pm 
    * [FULL](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__FULL) is pretty completely specified, such as Tuesday, April 12, 1952 AD or 3:30:42pm PST. 

You can also set the time zone on the format if you wish. If you want even more control over the format or parsing, (or want to give your users more control), you can try casting the DateFormat you get from the factory methods to a [SimpleDateFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/simpledateformat-0000001054358554). This will work for the majority of countries; just remember to put it in a try block in case you encounter an unusual one. 

You can also use forms of the parse and format methods with [ParsePosition](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parseposition-0000001054678535) and [FieldPosition](https://developer.harmonyos.com/cn/docs/documentation/doc-references/fieldposition-0000001054119822) to allow you to 

    * progressively parse through pieces of a string. 
    * align any particular field, or find out where it is for selection on the screen. 
**_Synchronization_**

Date formats are not synchronized. It is recommended to create separate format instances for each thread. If multiple threads access a format concurrently, it must be synchronized externally.

#### [h2]parse

Parse a date/time string according to the given parse position. For example, a time text "07/10/96 4:5 PM, PDT" will be parsed into a Date that is equivalent to Date(837039900000L). 

By default, parsing is lenient: If the input is not in the form used by this object's format method but can still be parsed as a date, then the parse succeeds. Clients may insist on strict adherence to the format by calling [setLenient(false)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__setLenient-boolean-). 

This parsing operation uses the [calendar](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__calendar) to produce a Date. As a result, the calendar's date-time fields and the TimeZone value may have been overwritten, depending on subclass implementations. Any TimeZone value that has previously been set by a call to [setTimeZone](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__setTimeZone-java_util_TimeZone-) may need to be restored for further operations.

**Parameters:**

Parameter Name | Parameter Description  
---|---

pos  |  On input, the position at which to start parsing; on output, the position at which parsing terminated, or the start position if the parse failed.  
  
**Returns:**

#### [h2]setLenient

public void setLenient​(boolean lenient)

Specify whether or not date/time parsing is to be lenient. With lenient parsing, the parser may use heuristics to interpret inputs that do not precisely match this object's format. With strict parsing, inputs must match this object's format. 

This method is equivalent to the following call. 
    
    getCalendar().setLenient(lenient)
     

This leniency value is overwritten by a call to [setCalendar()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/dateformat-0000001054238563#ZH-CN_TOPIC_0000001054238563__setCalendar-java_util_Calendar-).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
lenient  |  when true, parsing is lenient  
  
**See Also:**

[Calendar.setLenient(boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/calendar-0000001054439877#ZH-CN_TOPIC_0000001054439877__setLenient-boolean-)
