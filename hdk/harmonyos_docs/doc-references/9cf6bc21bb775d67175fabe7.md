[DocumentationTool.DocumentationTask](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documentationtool_documentationtask-0000001123694570) getTask​([Writer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/writer-0000001054199710) out, [JavaFileManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javafilemanager-0000001123694572) fileManager, [DiagnosticListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/diagnosticlistener-0000001170334505)<? super [JavaFileObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javafileobject-0000001170334509)> diagnosticListener, [Class](https://developer.harmonyos.com/cn/docs/documentation/doc-references/class-0000001054358423)<?> docletClass, [Iterable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterable-0000001054238441)<[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460)> options, [Iterable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterable-0000001054238441)<? extends [JavaFileObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javafileobject-0000001170334509)> compilationUnits)

Creates a future for a documentation task with the given components and arguments. The task might not have completed as described in the DocumentationTask interface. 

If a file manager is provided, it must be able to handle all locations defined in [DocumentationTool.Location](https://developer.harmonyos.com/cn/docs/documentation/doc-references/documentationtool_location-0000001170214411), as well as [StandardLocation.SOURCE_PATH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardlocation-0000001123534748#ZH-CN_TOPIC_0000001123534748__SOURCE_PATH), [StandardLocation.CLASS_PATH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardlocation-0000001123534748#ZH-CN_TOPIC_0000001123534748__CLASS_PATH), and [StandardLocation.PLATFORM_CLASS_PATH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardlocation-0000001123534748#ZH-CN_TOPIC_0000001123534748__PLATFORM_CLASS_PATH).

#### [h2]getStandardFileManager

[StandardJavaFileManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardjavafilemanager-0000001123694574) getStandardFileManager​([DiagnosticListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/diagnosticlistener-0000001170334505)<? super [JavaFileObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/javafileobject-0000001170334509)> diagnosticListener, [Locale](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852) locale, [Charset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charset-0000001054678500) charset)

Gets a new instance of the standard file manager implementation for this tool. The file manager will use the given diagnostic listener for producing any non-fatal diagnostics. Fatal errors will be signaled with the appropriate exceptions. 

The standard file manager will be automatically reopened if it is accessed after calls to flush or close. The standard file manager must be usable with other tools.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
diagnosticListener  |  a diagnostic listener for non-fatal diagnostics; if null use the compiler's default method for reporting diagnostics  
locale  |  the locale to apply when formatting diagnostics; null means the [default locale](https://developer.harmonyos.com/cn/docs/documentation/doc-references/locale-0000001054119852#ZH-CN_TOPIC_0000001054119852__getDefault--).  
charset  |  the character set used for decoding bytes; if null use the platform default  
  
**Returns:**

the standard file manager
