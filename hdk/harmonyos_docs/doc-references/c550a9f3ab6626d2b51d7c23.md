Instances of this class represent a matcher that performs match operations on an [SNIServerName](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sniservername-0000001054119991) instance.  Servers can use Server Name Indication (SNI) information to decide if specific [SSLSocket](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslsocket-0000001054838618) or [SSLEngine](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sslengine-0000001054199936) instances should accept a connection. For example, when multiple "virtual" or "name-based" servers are hosted on a single underlying network address, the server application can use SNI information to determine whether this server is the exact server that the client wants to access. Instances of this class can be used by a server to verify the acceptable server names of a particular type, such as host names.  SNIMatcher objects are immutable.
