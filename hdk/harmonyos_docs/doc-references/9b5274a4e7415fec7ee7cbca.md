# Field

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.reflect.AccessibleObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleobject-0000001054358456) |---|---java.lang.reflect.Field
    
    public final class Field
    extends [AccessibleObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleobject-0000001054358456)
    implements [Member](https://developer.harmonyos.com/cn/docs/documentation/doc-references/member-0000001054678468)  
  
---  
A Field provides information about, and dynamic access to, a single field of a class or an interface. The reflected field may be a class (static) field or an instance field. 

A Field permits widening conversions to occur during a get or set access operation, but throws an IllegalArgumentException if a narrowing conversion would occur.

#### [h2]get

public [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) get​([Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) obj) throws [IllegalAccessException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalaccessexception-0000001054439737), [IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724)

Returns the value of the field represented by this Field, on the specified object. The value is automatically wrapped in an object if it has a primitive type. 

The underlying field's value is obtained as follows: 

If the underlying field is a static field, the obj argument is ignored; it may be null. 

Otherwise, the underlying field is an instance field. If the specified obj argument is null, the method throws a NullPointerException. If the specified object is not an instance of the class or interface declaring the underlying field, the method throws an IllegalArgumentException. 

If this Field object is enforcing Java language access control, and the underlying field is inaccessible, the method throws an IllegalAccessException. If the underlying field is static, the class that declared the field is initialized if it has not already been initialized. 

Otherwise, the value is retrieved from the underlying instance or static field. If the field has a primitive type, the value is wrapped in an object before being returned, otherwise it is returned as is.

#### [h2]getAnnotationsByType

public <T extends [Annotation](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotation-0000001054358439)> T[] getAnnotationsByType​([Class](https://developer.harmonyos.com/cn/docs/documentation/doc-references/class-0000001054358423)<T> annotationClass)

Returns annotations that are associated with this element. If there are no annotations associated with this element, the return value is an array of length 0. The difference between this method and [AnnotatedElement.getAnnotation(java.lang.Class)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotatedelement-0000001054119724#ZH-CN_TOPIC_0000001054119724__getAnnotation-java_lang_Class-) is that this method detects if its argument is a repeatable annotation type (JLS 9.6), and if so, attempts to find one or more annotations of that type by "looking through" a container annotation. The caller of this method is free to modify the returned array; it will have no effect on the arrays returned to other callers.
