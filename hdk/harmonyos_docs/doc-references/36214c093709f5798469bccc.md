# DataBindingUtil

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.abilityjet.databinding.DataBindingUtil
    
    public class DataBindingUtil
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
A utility class of [DataBinding](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databinding-0000001054678690) that obtains DataBinding objects. 

You can define attributes of the class to be bound in a layout file. After compilation, the corresponding DataBinding child class will be automatically generated. You can call the [createBinding(int,ohos.app.Context,java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/databindingutil-0000001054358669#ZH-CN_TOPIC_0000001054358669__createBinding-int-ohos_app_Context-java_lang_String-) method to obtain the generated DataBinding child class object for further initialization and binding.
