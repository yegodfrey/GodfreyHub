# LinkedTransferQueue  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.AbstractCollection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractcollection-0000001054358576)<E> |---|---[java.util.AbstractQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602)<E> |---|---|---java.util.concurrent.LinkedTransferQueue<E>

    extends [AbstractQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueue-0000001054518602)<E>
    implements [TransferQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transferqueue-0000001054678610)<E>, [Serializable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/serializable-0000001054358416)

An unbounded [TransferQueue](https://developer.harmonyos.com/cn/docs/documentation/doc-references/transferqueue-0000001054678610) based on linked nodes. This queue orders elements FIFO (first-in-first-out) with respect to any given producer. The head of the queue is that element that has been on the queue the longest time for some producer. The tail of the queue is that element that has been on the queue the shortest time for some producer. 

Beware that, unlike in most collections, the size method is NOT a constant-time operation. Because of the asynchronous nature of these queues, determining the current number of elements requires a traversal of the elements, and so may report inaccurate results if this collection is modified during traversal. Additionally, the bulk operations addAll, removeAll, retainAll, containsAll, equals, and toArray are not guaranteed to be performed atomically. For example, an iterator operating concurrently with an addAll operation might view only some of the added elements. 

This class and its iterator implement all of the optional methods of the [Collection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/collection-0000001054358563) and [Iterator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iterator-0000001054119913) interfaces. 

Memory consistency effects: As with other concurrent collections, actions in a thread prior to placing an object into a LinkedTransferQueue [_happen-before_](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054558607#ZH-CN_TOPIC_0000001054558607__MemoryVisibility) actions subsequent to the access or removal of that element from the LinkedTransferQueue in another thread. 

This class is a member of the [ Java Collections Framework](https://docs.oracle.com/javase/8/docs/technotes/guides/collections/index.html).
