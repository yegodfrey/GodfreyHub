# CodecDescriptionList

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.media.codec.CodecDescriptionList
    
    public class CodecDescriptionList
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a MIME type list of media formats supported by codecs that are available for a device. You can use a method in this class to check whether the device supports the codec for a specified MIME type.
