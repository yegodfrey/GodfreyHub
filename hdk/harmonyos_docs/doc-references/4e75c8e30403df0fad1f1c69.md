# Paint  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.render.Paint
    
    public class Paint
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Describes drawing style and color. 

This class provides style, color, and drawing mode for drawing geometric graphics, text, and pixelMaps. It provides parameters for the [Canvas](https://developer.harmonyos.com/cn/docs/documentation/doc-references/canvas-0000001054238731) class. A Paint object must be destroyed after it has been used.
