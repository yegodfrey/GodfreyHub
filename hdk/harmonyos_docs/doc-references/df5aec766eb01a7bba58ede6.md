TimeZoneFormat supports time zone display name formatting and parsing. An instance of TimeZoneFormat works as a subformatter of [SimpleDateFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/simpledateformat-0000001054518880), but you can also directly get a new instance of TimeZoneFormat and formatting/parsing time zone display names.  ICU implements the time zone display names defined by [UTS#35 Unicode Locale Data Markup Language (LDML)](http://www.unicode.org/reports/tr35/). [TimeZoneNames](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timezonenames-0000001054558869) represents the time zone display name data model and this class implements the algorithm for actual formatting and parsing. **See Also:** [SimpleDateFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/simpledateformat-0000001054518880), [TimeZoneNames](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timezonenames-0000001054558869), Nested Class Summary Modifier and Type | Class | Description
