# IntSummaryStatistics  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.IntSummaryStatistics

A state object for collecting statistics such as count, min, max, sum, and average. 

This class is designed to work with (though does not require) [streams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621). For example, you can compute summary statistics on a stream of ints with: 
    
    IntSummaryStatistics stats = intStream.collect(IntSummaryStatistics::new,
                                                    IntSummaryStatistics::accept,
                                                    IntSummaryStatistics::combine);
     

IntSummaryStatistics can be used as a [reduction](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656#ZH-CN_TOPIC_0000001054518656__collect-java_util_stream_Collector-) target for a [stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656). For example: 
    
    IntSummaryStatistics stats = people.stream()
                                        .collect(Collectors.summarizingInt(Person::getDependents));
    

This computes, in a single pass, the count of people, as well as the minimum, maximum, sum, and average of their number of dependents.
