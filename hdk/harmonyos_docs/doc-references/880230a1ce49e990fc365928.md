# MultiPathManager

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.smartcomm.MultiPathManager
    
    public class MultiPathManager
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Manages multiple paths in smart communication. 

This class uses the singleton pattern. The getInstance method can be used to obtain the MultiPathManager object. 

This class provides methods to manage multiple paths, for example, enabling or disabling multipath.

#### [h2]enableMultipathFlow

[@Deprecated](https://developer.harmonyos.com/cn/docs/documentation/doc-references/deprecated-0000001054838412) public int enableMultipathFlow​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) packageName, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) flowParamJson, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) multipathParamJson, [IMultiPathCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imultipathcallback-0000001054120315) callback) throws [RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984)

Deprecated. 

Enables multipath. 

This method can enable multipath based on an application or a combination of IP address and port number. If an application is specified, multipath is enabled for all flows from the application; if a combination of IP address and port number is specified, multipath is enabled for all flows from the application to the IP address and port number.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
packageName  |  Indicates the package name of the application for which multipath is enabled.  
flowParamJson  |  Indicates flow parameters in JSON format. The parameters include [MULTIPATH_FLOW_SCALE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_FLOW_SCALE), [MULTIPATH_IP_ADDRESS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_IP_ADDRESS), [MULTIPATH_IP_PORT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_IP_PORT), [MULTIPATH_IP_CARRIER](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_IP_CARRIER), [MULTIPATH_IP_DEPLOYTYPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_IP_DEPLOYTYPE), [MULTIPATH_IP_GROUP](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_IP_GROUP), and [MULTIPATH_FLOW_TYPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_FLOW_TYPE).  
multipathParamJson  |  Indicates multipath parameters in JSON format. The parameters include [MULTIPATH_POLICY_TYPE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_POLICY_TYPE), [MULTIPATH_USER_ID](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_USER_ID), [MULTIPATH_SCENARIO_FLAG](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_SCENARIO_FLAG), [MULTIPATH_PARAM_RTT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_PARAM_RTT), and [MULTIPATH_PARAM_BANDWIDTH](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multipathmanager-0000001054440273#ZH-CN_TOPIC_0000001054440273__MULTIPATH_PARAM_BANDWIDTH).
