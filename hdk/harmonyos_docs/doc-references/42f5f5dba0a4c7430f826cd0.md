#### Method Detail

#### [h2]canAcceptScroll

boolean canAcceptScroll​([Component](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683) component, int direction, boolean acceptInDefault)

Invoked before component accept scrolling gesture. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
component  |  Indicates a component which is ready to accept scrolling gesture.  
direction  |  Indicates the dragging direction. The value can be one of the following: [Component.DRAG_UP](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_UP), [Component.DRAG_DOWN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_DOWN), [Component.DRAG_LEFT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_LEFT), or [Component.DRAG_RIGHT](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_RIGHT).  
acceptInDefault  |  Indicates the suggested result. If a ListContainer has reached bottom for example, then the default suggested result is false when a [Component.DRAG_UP](https://developer.harmonyos.com/cn/docs/documentation/doc-references/component-0000001054678683#ZH-CN_TOPIC_0000001054678683__DRAG_UP) gesture is ready.  
  
**Returns:**

Returns true if this component can be scrolled in the specified direction, false otherwise.
