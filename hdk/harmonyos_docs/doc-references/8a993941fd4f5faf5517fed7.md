#### [h2]applyToSource

public long applyToSource​([ImageSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/imagesource-0000001054238931) source) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Applies the configured Exif properties to the source file. 

This method requires the permission to modify the source file represented by the ImageSource object. The configured Exif properties do not take effect until this method is called. 

This method is applicable to the ImageSource object that has been created based on a File object or a specified file path.

**Specified by:**

[applyToSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filter-0000001060268789#ZH-CN_TOPIC_0000001060268789__applyToSource-ohos_media_image_ImageSource-) in class [Filter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filter-0000001060268789)

**Parameters:**

Parameter Name | Parameter Description  
---|---  
source  |  Indicates the image source file to which the properties will be applied.  
  
**Returns:**

Returns the size (in bytes) of the image file edited based on the Exif properties if the operation is successful; returns -1 otherwise.

**Throws:**

Throw Name | Throw Description  
---|---  
[IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |  Throws this exception if the modification permission has not been obtained.  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  Throws this exception if the image source is empty.  
[IllegalStateException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalstateexception-0000001054678452) |  Throws this exception if the ImageSource object has been released.
