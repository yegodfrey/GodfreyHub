# PowerManager

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.powermanager.PowerManager
    
    public class PowerManager
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides interfaces to manage power. 

The interfaces can be used to restart the system, use [RunningLock](https://developer.harmonyos.com/cn/docs/documentation/doc-references/powermanager_runninglock-0000001054678937), and obtain the power status [DevicePowerStatusInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicepowerstatusinfo-0000001054558969).
