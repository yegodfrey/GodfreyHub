    public static interface AbsButton.CheckedStateChangedListener

Provides the state change listener for a [AbsButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/absbutton-0000001054120041) instance. Method Detail [h2]onCheckedChanged void onCheckedChanged​([AbsButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/absbutton-0000001054120041) button, boolean isChecked) Called back to process state change events of an [AbsButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/absbutton-0000001054120041) item. This method is invoked when an [AbsButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/absbutton-0000001054120041) item switches between the checked and unchecked states. It passes the AbsButton item and its current state to process state change events. **Parameters:** Parameter Name | Parameter Description  
---|---  
button  |  Indicates the AbsButton item.  
isChecked  |  Indicates the current state of the absButton. true indicates checked; false indicates unchecked.
