public [CacheRequest](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cacherequest-0000001054199748) put​([URI](https://developer.harmonyos.com/cn/docs/documentation/doc-references/uri-0000001054838434) uri, [URLConnection](https://developer.harmonyos.com/cn/docs/documentation/doc-references/urlconnection-0000001054119738) conn) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Description copied from class: [ResponseCache](https://developer.harmonyos.com/cn/docs/documentation/doc-references/responsecache-0000001054439765#ZH-CN_TOPIC_0000001054439765__put-java_net_URI-java_net_URLConnection-)

The protocol handler calls this method after a resource has been retrieved, and the ResponseCache must decide whether or not to store the resource in its cache. If the resource is to be cached, then put() must return a CacheRequest object which contains an OutputStream that the protocol handler will use to write the resource into the cache. If the resource is not to be cached, then put must return null. 

**Specified by:**
