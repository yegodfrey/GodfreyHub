# AccessibilityStateEvent  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.accessibility.AccessibilityStateEvent
    
    public class AccessibilityStateEvent
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides accessibility status events. 

If you have registered a status change observer, it will receive an event when the accessibility status has changed. Then you can process the event based on the result in the callback. 

For example, you can determine the accessibility status based on the event type in [AccessibilityStateEvent#EVENT_ACCESSIBILITY_STATE_CHANGED](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilitystateevent-0000001054838646#ZH-CN_TOPIC_0000001054838646__EVENT_ACCESSIBILITY_STATE_CHANGED).
