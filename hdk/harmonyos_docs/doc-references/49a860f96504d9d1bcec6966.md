# NotificationSlotGroup

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationSlotGroup
    
    public final class NotificationSlotGroup
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Manages multiple notification slots with the same name in an application. For example, a social networking service (SNS) application may support both personal and enterprise accounts, and each account may require multiple notification slots with the same functionality and name. You can bind notification slots with the same name that belong to a single account to a notification slot group to manage their respective information.
