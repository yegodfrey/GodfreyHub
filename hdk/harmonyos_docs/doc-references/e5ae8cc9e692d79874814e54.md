# IInitCallback
    
    public interface IInitCallback  
  
---  
Provides callbacks to be invoked upon a successful or failed attempt to initialize the distributed execution framework. 

Before calling [DeviceManager#initDistributedEnvironment(String, IInitCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__initDistributedEnvironment-java_lang_String-ohos_distributedschedule_interwork_IInitCallback-) to initialize the distributed execution framework, you must create a class to implement this interface and override the [IInitCallback#onInitSuccess(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280#ZH-CN_TOPIC_0000001060837280__onInitSuccess-java_lang_String-) and [IInitCallback#onInitFailure(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280#ZH-CN_TOPIC_0000001060837280__onInitFailure-java_lang_String-int-) methods for your application to receive the initialization result. If the initialization is successful, your application will be notified through [IInitCallback#onInitSuccess(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280#ZH-CN_TOPIC_0000001060837280__onInitSuccess-java_lang_String-). If the initialization fails, your application will be notified of the initialization failure and error code through [IInitCallback#onInitFailure(String, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iinitcallback-0000001060837280#ZH-CN_TOPIC_0000001060837280__onInitFailure-java_lang_String-int-). After the cross-device task is complete, your application can call [DeviceManager#unInitDistributedEnvironment(String, IInitCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/devicemanager-0000001054358820#ZH-CN_TOPIC_0000001054358820__unInitDistributedEnvironment-java_lang_String-ohos_distributedschedule_interwork_IInitCallback-) to deactivate the distributed execution framework and unregister the previously registered callbacks.
