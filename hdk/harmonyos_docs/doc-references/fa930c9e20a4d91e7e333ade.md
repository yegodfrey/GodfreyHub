#### [h2]format

public abstract [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) format​([MeasureOptions.Unit](https://developer.harmonyos.com/cn/docs/documentation/doc-references/measureoptions_unit-0000001120847531) unit, double value, [MeasureOptions.Usage](https://developer.harmonyos.com/cn/docs/documentation/doc-references/measureoptions_usage-0000001120951641) usage, [MeasureOptions.FormatStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/measureoptions_formatstyle-0000001120712381) formatStyle, [MeasureOptions.Style](https://developer.harmonyos.com/cn/docs/documentation/doc-references/measureoptions_style-0000001121107275) style) throws [NotSupportConvertException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notsupportconvertexception-0000001078160538)

Selects a preferred unit in the specified application scenario based on the locale of the MeasureFormatter object and formats the preferred unit according to the specified formatting style. 

If there are multiple preferred units, the style parameter determines whether to automatically select a proper one. The value of the input unit is then converted to that of the preferred unit.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
unit  |  Indicates the input unit.  
value  |  Indicates the value of the unit.  
usage  |  Indicates the application scenario of the unit.  
formatStyle  |  Indicates the formatting style.  
style  |  Specifies whether to automatically select a proper unit.  
  
**Returns:**

Returns the string representation of the formatted preferred unit.

**Throws:**

Throw Name | Throw Description  
---|---  
[NotSupportConvertException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notsupportconvertexception-0000001078160538) |  Throws this exception if any input parameter is invalid.  
  
**Since:**
