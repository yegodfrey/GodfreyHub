# OrmContext
    
    public interface OrmContext
    extends [AutoCloseable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/autocloseable-0000001054518454)  
  
---  
An interface provided by the object relational mapping (ORM) system for operating ORM database entities defined in [OrmObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormobject-0000001054120141). 

Applications can use this interface to create, retrieve, update, and delete database entities.

#### [h2]changeEncryptKey

void changeEncryptKey​(byte[] newEncryptKey)

Changes the encryption key of an encrypted object-relational mapping (ORM) database that is opened. 

This method applies only to an encrypted ORM database and cannot be used to change it to an unencrypted one. Before calling this method, ensure that the database is opened and that no transaction is using the database connection. For the maximum size of the encryption key, see [OrmConfig#MAX_ENCRYPT_KEY_SIZE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormconfig-0000001054238811#ZH-CN_TOPIC_0000001054238811__MAX_ENCRYPT_KEY_SIZE).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
newEncryptKey  |  Indicates the new encryption key of the ORM database.  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[IllegalArgumentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalargumentexception-0000001054199724) |  Throws this exception if the new encryption key is null or an empty string.  
[IllegalStateException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/illegalstateexception-0000001054678452) |  Throws this exception if the database is not opened or not encrypted, or a transaction is using the database connection.  
[RdbException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/rdbexception-0000001054558821) |  Throws this exception if changing the encryption key of the encrypted ORM database fails.  
  
**Since:**

#### [h2]restore

boolean restore​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) srcPath, byte[] srcEncryptKey, byte[] destEncryptKey)

Restores a database from a specified encrypted or unencrypted database file. 

When being called, this method deletes the original data and generates an encrypted or unencrypted database, as defined by your application. If both srcEncryptKey and destEncryptKey are null, this method is equivalent to the [OrmContext#restore(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormcontext-0000001054120139#ZH-CN_TOPIC_0000001054120139__restore-java_lang_String-) method. For the maximum size of the encryption key, see [OrmConfig#MAX_ENCRYPT_KEY_SIZE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ormconfig-0000001054238811#ZH-CN_TOPIC_0000001054238811__MAX_ENCRYPT_KEY_SIZE).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
srcPath  |  Indicates the path that stores the source database file. Ensure that your application has write permissions to this path.  
srcEncryptKey  |  Indicates the encryption key of the source database. If the database is unencrypted, set the value of this parameter to null.  
destEncryptKey  |  Indicates the encryption key of the restored database.If you want the database to be unencrypted, set the value of this parameter to null.  
  
**Returns:**

Returns true if the database is restored successfully; returns false otherwise.

**Since:**

3
