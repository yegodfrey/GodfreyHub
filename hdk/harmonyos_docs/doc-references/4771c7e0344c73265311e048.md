# select

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172508.67945057710300213112045131346380:50001231000000:2800:80BFEB46CB96F5BE2E72BB7D0CE02A7878077EFE7A2C8D2C186B6FCC2AD7FAB8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

从API version 4开始支持。后续版本如有新增内容，则采用上角标单独标记该内容的起始版本。

下拉选择按钮，可让用户在多个选项之间选择。

#### 权限列表

无

#### 子组件

支持<[option](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-basic-option-0000001333800497)>。

#### 属性

支持[通用属性](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-attributes-0000001281480654)。

#### 样式

除支持[通用样式](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-styles-0000001281201106)外，还支持如下样式：

名称 | 类型 | 默认值 | 必填 | 描述  
---|---|---|---|---  
font-family | string | sans-serif | 否 | 字体列表，用逗号分隔，每个字体用字体名或者字体族名设置。列表中第一个系统中存在的或者通过[自定义字体](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-customizing-font-0000001281361074)指定的字体，会被选中作为文本的字体。  
  
#### 事件

除支持[通用事件](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-events-0000001333720913)外，还支持如下事件：

名称 | 参数 | 描述  
---|---|---  
change | {newValue: newValue} | 下拉选择新值后触发该事件，newValue的值为子组件option的value属性值。  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230804172508.71425272032121809215252204896185:50001231000000:2800:A4B92A9E6CAE80B123D17F1BA8ED279F7F6D3E9A89C97762AC508CBA34FE6757.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    * select组件不支持click事件。

#### 方法

支持[通用方法](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-components-common-methods-0000001333321161)。

#### 示例
    
    <!-- xxx.hml -->
    <div class="container">
      <select @change="changeFruit">
        <option value="bananaValue">
          Banana
        </option>
        <option value="appleValue" selected="true">
          Apple
        </option>
        <option value="pearValue">
          Pear
        </option>
      </select>
    </div>
    
    /* xxx.css */
    .container {
      display: flex;
      justify-content: center;
      align-items: center;
    }
