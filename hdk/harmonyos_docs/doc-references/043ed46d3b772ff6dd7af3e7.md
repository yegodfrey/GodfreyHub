# MediaEventHandle
    
    public interface MediaEventHandle
    extends [StandardizedEventHandle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardizedeventhandle-0000001139715265)

Media events include playback and pause.

#### [h2]onMediaControl

boolean onMediaControl​([MultimodalEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/multimodalevent-0000001054518970) multimodalEvent)

Called when a media control event occurs, either playback or pause. 

This method is used when the specific media intent in the passed event cannot be determined. For example, it is undetermined whether the intent is to execute the playback or pause command because the current playback status cannot be obtained.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
multimodalEvent  |  Indicates the multimodal input event information that contains the intent of playback or pause.  
  
**Returns:**

Returns true if the event is handled; returns false otherwise.

**Since:**

5
