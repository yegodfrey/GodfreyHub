# PageSliderProvider

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.PageSliderProvider
    
    public abstract class PageSliderProvider
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides the page adapter to manage page components. 

This class provides the page item management functions, such as calculating the number of available components and creating a component at a specified position. You need to inherit and implement [PageSliderProvider](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pagesliderprovider-0000001054120047) to display multiple components on different pages.
