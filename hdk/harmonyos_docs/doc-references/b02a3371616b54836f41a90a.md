# PacMapEx

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.interwork.utils.PacMapEx
    
    public class PacMapEx
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [ParcelableEx](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcelableex-0000001054678859), [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Defines the structure for the data packets transmitted between processes across platforms. In an ohos process, your application data is stored as key-value pairs in a PacMapEx object. This object will be marshalled and then transmitted to a process in another platform. After receiving the marshalled object, that process will unmarshal it and then read the data.
