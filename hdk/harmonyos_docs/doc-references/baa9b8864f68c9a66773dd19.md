# HiChecker.OnCautionListener
    
    public static interface HiChecker.OnCautionListener

Obtains and handles cautions. You need to implement this interface when defining a caution callback via [HiChecker#setCautionListener(Executor executor, OnCautionListener listener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/hichecker-0000001078032076#ZH-CN_TOPIC_0000001078032076__setCautionListener-java_util_concurrent_Executor-ohos_hiviewdfx_HiChecker_OnCautionListener-).

#### [h2]onCautionFound

void onCautionFound​([Caution](https://developer.harmonyos.com/cn/docs/documentation/doc-references/caution-0000001120712383) caution)

Called when a caution is generated. 

This caution callback is invoked to notify your application that a caution was generated.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
caution  |  Indicates the Caution object, which contains the caution detection rule obtained via [Caution#getTriggerRule()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/caution-0000001120712383#ZH-CN_TOPIC_0000001120712383__getTriggerRule--), the custom caution message obtained via [Caution#getCustomMessage()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/caution-0000001120712383#ZH-CN_TOPIC_0000001120712383__getCustomMessage--), and the stack information obtained via [Throwable#getStackTrace()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436#ZH-CN_TOPIC_0000001054358436__getStackTrace--).
