# CompletableFuture

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.concurrent.CompletableFuture<T>
    
    public class CompletableFuture<T>
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Future](https://developer.harmonyos.com/cn/docs/documentation/doc-references/future-0000001054838562)<T>, [CompletionStage](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completionstage-0000001054439893)<T>  
  
---  
A [Future](https://developer.harmonyos.com/cn/docs/documentation/doc-references/future-0000001054838562) that may be explicitly completed (setting its value and status), and may be used as a [CompletionStage](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completionstage-0000001054439893), supporting dependent functions and actions that trigger upon its completion. 

When two or more threads attempt to [complete](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__complete-T-), [completeExceptionally](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__completeExceptionally-java_lang_Throwable-), or [cancel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__cancel-boolean-) a CompletableFuture, only one of them succeeds. 

In addition to these and related methods for directly manipulating status and results, CompletableFuture implements interface [CompletionStage](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completionstage-0000001054439893) with the following policies: 

    * Actions supplied for dependent completions of non-async methods may be performed by the thread that completes the current CompletableFuture, or by any other caller of a completion method.
    * All async methods without an explicit Executor argument are performed using the [ForkJoinPool#commonPool()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/forkjoinpool-0000001054119870#ZH-CN_TOPIC_0000001054119870__commonPool--) (unless it does not support a parallelism level of at least two, in which case, a new Thread is created to run each task). To simplify monitoring, debugging, and tracking, all generated asynchronous tasks are instances of the marker interface [AsynchronousCompletionTask](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture_asynchronouscompletiontask-0000001054119935). 
    * All CompletionStage methods are implemented independently of other public methods, so the behavior of one method is not impacted by overrides of others in subclasses. 

CompletableFuture also implements [Future](https://developer.harmonyos.com/cn/docs/documentation/doc-references/future-0000001054838562) with the following policies: 

    * Since (unlike [FutureTask](https://developer.harmonyos.com/cn/docs/documentation/doc-references/futuretask-0000001054518626)) this class has no direct control over the computation that causes it to be completed, cancellation is treated as just another form of exceptional completion. Method [cancel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__cancel-boolean-) has the same effect as completeExceptionally(new CancellationException()). Method [isCompletedExceptionally()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__isCompletedExceptionally--) can be used to determine if a CompletableFuture completed in any exceptional fashion.
    * In case of exceptional completion with a CompletionException, methods [get()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__get--) and [get(long,java.util.concurrent.TimeUnit)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__get-long-java_util_concurrent_TimeUnit-) throw an [ExecutionException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/executionexception-0000001054199890) with the same cause as held in the corresponding CompletionException. To simplify usage in most contexts, this class also defines methods [join()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__join--) and [getNow(T)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completablefuture-0000001054678579#ZH-CN_TOPIC_0000001054678579__getNow-T-) that instead throw the CompletionException directly in these cases.

Returns a new CompletableFuture that is completed when all of the given CompletableFutures complete. If any of the given CompletableFutures complete exceptionally, then the returned CompletableFuture also does so, with a CompletionException holding this exception as its cause. Otherwise, the results, if any, of the given CompletableFutures are not reflected in the returned CompletableFuture, but may be obtained by inspecting them individually. If no CompletableFutures are provided, returns a CompletableFuture completed with the value null. 

Among the applications of this method is to await completion of a set of independent CompletableFutures before continuing a program, as in: CompletableFuture.allOf(c1, c2, c3).join();.
