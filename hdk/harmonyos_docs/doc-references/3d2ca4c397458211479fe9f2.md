# NotificationActionButton

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.event.notification.NotificationActionButton
    
    public class NotificationActionButton
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Sequenceable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/sequenceable-0000001054239001)  
  
---  
Encapsulates an action button to be displayed in a notification. You can call [NotificationRequest#addActionButton](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notificationrequest-0000001054518854#ZH-CN_TOPIC_0000001054518854__addActionButton-ohos_event_notification_NotificationActionButton-) to add action buttons to a notification. 

A NotificationActionButton object must include an icon, a title, and an associated [IntentAgent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentagent-0000001054678807) defining the action to trigger when the action button is clicked.
