# FileTime  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.nio.file.attribute.FileTime
    
    public final class FileTime
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Comparable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparable-0000001054558443)<[FileTime](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filetime-0000001054119772)>  
  
---  
Represents the value of a file's time stamp attribute. For example, it may represent the time that the file was last [BasicFileAttributes#lastModifiedTime()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributes-0000001054678481#ZH-CN_TOPIC_0000001054678481__lastModifiedTime--), [BasicFileAttributes#lastAccessTime()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributes-0000001054678481#ZH-CN_TOPIC_0000001054678481__lastAccessTime--), or [BasicFileAttributes#creationTime()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basicfileattributes-0000001054678481#ZH-CN_TOPIC_0000001054678481__creationTime--). 

Instances of this class are immutable.

#### [h2]toInstant

public [Instant](https://developer.harmonyos.com/cn/docs/documentation/doc-references/instant-0000001054838522) toInstant​()

Converts this FileTime object to an Instant. 

The conversion creates an Instant that represents the same point on the time-line as this FileTime. 

FileTime can store points on the time-line further in the future and further in the past than Instant. Conversion from such further time points saturates to [Instant#MIN](https://developer.harmonyos.com/cn/docs/documentation/doc-references/instant-0000001054838522#ZH-CN_TOPIC_0000001054838522__MIN) if earlier than Instant.MIN or [Instant#MAX](https://developer.harmonyos.com/cn/docs/documentation/doc-references/instant-0000001054838522#ZH-CN_TOPIC_0000001054838522__MAX) if later than Instant.MAX.

#### [h2]toString

public [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) toString​()

Returns the string representation of this FileTime. The string is returned in the [ISO 8601](http://www.w3.org/TR/NOTE-datetime) format: 
    
    YYYY-MM-DDThh:mm:ss[.s+]Z
     

where "[.s+]" represents a dot followed by one of more digits for the decimal fraction of a second. It is only present when the decimal fraction of a second is not zero. For example, FileTime.fromMillis(1234567890000L).toString() yields "2009-02-13T23:31:30Z", and FileTime.fromMillis(1234567890123L).toString() yields "2009-02-13T23:31:30.123Z". 

A FileTime is primarily intended to represent the value of a file's time stamp. Where used to represent _extreme values_ , where the year is less than "0001" or greater than "9999" then this method deviates from ISO 8601 in the same manner as the [XML Schema language](http://www.w3.org/TR/xmlschema-2/#deviantformats). That is, the year may be expanded to more than four digits and may be negative-signed. If more than four digits then leading zeros are not present. The year before "0001" is "-0001".
