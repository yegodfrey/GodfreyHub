Implements a character filter, which supports filtering of plain text and [RichText](https://developer.harmonyos.com/cn/docs/documentation/doc-references/richtext-0000001054838706). This API can filter characters that are not in the valid character set you specified. To specify a valid character set, you are advised to use a regular expression, for example, [\\\\+-\\\\.\\\d], for its powerful functions. In a simplest case, if you want to explicitly state which characters are valid, for example, abcde, then you need to set the regular expression to [abcde]. For ease of use and understanding, the following two use cases are provided: [CharInputFilter#NUMBER](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charinputfilter-0000001172398158#ZH-CN_TOPIC_0000001172398158__NUMBER) and [CharInputFilter#ALPHABET](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charinputfilter-0000001172398158#ZH-CN_TOPIC_0000001172398158__ALPHABET).
