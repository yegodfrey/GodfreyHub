# IntToDoubleFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface IntToDoubleFunction  
  
---  
Represents a function that accepts an int-valued argument and produces a double-valued result. This is the int-to-double primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsDouble(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inttodoublefunction-0000001054358607#ZH-CN_TOPIC_0000001054358607__applyAsDouble-int-).
