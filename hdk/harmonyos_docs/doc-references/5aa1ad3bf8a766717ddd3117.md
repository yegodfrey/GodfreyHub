# LongStream  
      
    public interface LongStream
    extends [BaseStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/basestream-0000001054238641)<[Long](https://developer.harmonyos.com/cn/docs/documentation/doc-references/long-0000001054439731),[LongStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longstream-0000001054439929)>  
  
---  
A sequence of primitive long-valued elements supporting sequential and parallel aggregate operations. This is the long primitive specialization of [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656). 

The following example illustrates an aggregate operation using [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and [LongStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longstream-0000001054439929), computing the sum of the weights of the red widgets: 
    
    long sum = widgets.stream()
                           .filter(w -> w.getColor() == RED)
                           .mapToLong(w -> w.getWeight())
                           .sum();
     

See the class documentation for [Stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656) and the package documentation for [java.util.stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621) for additional specification of streams, stream operations, stream pipelines, and parallelism.

#### [h2]concat

static [LongStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longstream-0000001054439929) concat​([LongStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longstream-0000001054439929) a, [LongStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longstream-0000001054439929) b)

Creates a lazily concatenated stream whose elements are all the elements of the first stream followed by all the elements of the second stream. The resulting stream is ordered if both of the input streams are ordered, and parallel if either of the input streams is parallel. When the resulting stream is closed, the close handlers for both input streams are invoked. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
a  |  the first stream  
b  |  the second stream  
  
**Returns:**

the concatenation of the two input streams
