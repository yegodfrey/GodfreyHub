# Contour  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.utils.Contour
    
    public class Contour
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Describes the contour of a component. 

You can clip or draw a shadow by using a contour, which takes the form of a right-angled rectangle, a rounded rectangle, an oval, or a convex polygon.

**Since:**

5
