#### [h2]getCallingPid

public static int getCallingPid​()

Obtains the PID of a proxy. 

This method is static. The PID is a positive integer during the communication between the [RemoteProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteproxy-0000001054440257) object and [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) object, and resumes to 0 when the communication ends. If this method is called from the [RemoteProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteproxy-0000001054440257) object, 0 is returned; if this method is called from the [RemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteobject-0000001054120299) object, the PID of the corresponding [RemoteProxy](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteproxy-0000001054440257) object is returned.

**Returns:**

Returns the PID of the proxy.
