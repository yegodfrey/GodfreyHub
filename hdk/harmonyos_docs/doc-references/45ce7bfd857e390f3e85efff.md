# OptionalDataException

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.lang.Throwable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/throwable-0000001054358436) |---|---[java.lang.Exception](https://developer.harmonyos.com/cn/docs/documentation/doc-references/exception-0000001054119708) |---|---|---[java.io.IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426) |---|---|---|---[java.io.ObjectStreamException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstreamexception-0000001054439725) |---|---|---|---|---java.io.OptionalDataException
    
    public class OptionalDataException
    extends [ObjectStreamException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/objectstreamexception-0000001054439725)  
  
---  
Exception indicating the failure of an object read operation due to unread primitive data, or the end of data belonging to a serialized object in the stream. This exception may be thrown in two cases: 
    * An attempt was made to read an object when the next element in the stream is primitive data. In this case, the OptionalDataException's length field is set to the number of bytes of primitive data immediately readable from the stream, and the eof field is set to false. 
    * An attempt was made to read past the end of data consumable by a class-defined readObject or readExternal method. In this case, the OptionalDataException's eof field is set to true, and the length field is set to 0. 

**Since:**

JDK1.1
