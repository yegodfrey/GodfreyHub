An observer class used to monitor call service state updates. The call service states include the call state, voice mailbox state, and unconditional call forwarding (CFU) setting state. To monitor a specific type of updates, you must inherit this class and override the methods corresponding to OBSERVE_flags in mask transferred by [DistributedCallManager#addObserver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/distributedcallmanager-0000001054518844#ZH-CN_TOPIC_0000001054518844__addObserver-ohos_dcall_CallStateObserver-int-). enable  |  Specifies whether the CFU function is enabled. The value true indicates that the CFU function is enabled, and the value false indicates that the CFU function is disabled.  
[h2]onCallStateUpdated public void onCallStateUpdated​(int state, [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) number) Receives a call state change. This callback is invoked when the call state of a specified card updates and the observer is added to monitor the updates. **Parameters:** Parameter Name | Parameter Description  
---|---  
state  |  Indicates the call state. The following call states are possible: 
                * [CallStateObserver#CALL_STATE_IDLE](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callstateobserver-0000001054200104#ZH-CN_TOPIC_0000001054200104__CALL_STATE_IDLE)
                * [CallStateObserver#CALL_STATE_RINGING](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callstateobserver-0000001054200104#ZH-CN_TOPIC_0000001054200104__CALL_STATE_RINGING)
                * [CallStateObserver#CALL_STATE_OFFHOOK](https://developer.harmonyos.com/cn/docs/documentation/doc-references/callstateobserver-0000001054200104#ZH-CN_TOPIC_0000001054200104__CALL_STATE_OFFHOOK)  
number  |  Indicates the called number. The value is an empty string if the application does not have the ohos.permission#READ_CALL_LOG READ_CALL_LOG permission.
