# ReliableFileDescriptor  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.rpc.ReliableFileDescriptor
    
    public class ReliableFileDescriptor
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Wraps a reliable [FileDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filedescriptor-0000001054119688) that can be accessed from multiple threads. 

This class provides methods for creating a reliable data pipe and obtaining the wrapped [FileDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filedescriptor-0000001054119688) or native file descriptor.

#### [h2]getNativeFd

public int getNativeFd​()

Obtains the native file descriptor wrapped in this ReliableFileDescriptor. 

This ReliableFileDescriptor still owns the file descriptor, which must be closed through this ReliableFileDescriptor.

**Returns:**

Returns the native file descriptor wrapped in this ReliableFileDescriptor. Do not use the return value to close the file descriptor or pass the return value to any method that assumes ownership of the file descriptor. Otherwise, the file descriptor will be closed repeatedly.

**Since:**

3
