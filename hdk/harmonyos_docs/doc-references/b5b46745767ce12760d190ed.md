A grouping of asynchronous channels for the purpose of resource sharing.  An asynchronous channel group encapsulates the mechanics required to handle the completion of I/O operations initiated by [AsynchronousChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannel-0000001054238487) that are bound to the group. A group has an associated thread pool to which tasks are submitted to handle I/O events and dispatch to [CompletionHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/completionhandler-0000001054358476) that consume the result of asynchronous operations performed on channels in the group. In addition to handling I/O events, the pooled threads may also execute other tasks required to support the execution of asynchronous I/O operations.  An asynchronous channel group is created by invoking the [withFixedThreadPool](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__withFixedThreadPool-int-java_util_concurrent_ThreadFactory-) or [withCachedThreadPool](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__withCachedThreadPool-java_util_concurrent_ExecutorService-int-) methods defined here. Channels are bound to a group by specifying the group when constructing the channel. The associated thread pool is owned by the group; termination of the group results in the shutdown of the associated thread pool.  In addition to groups created explicitly, the Java virtual machine maintains a system-wide default group that is constructed automatically. Asynchronous channels that do not specify a group at construction time are bound to the default group. The default group has an associated thread pool that creates new threads as needed. The default group may be configured by means of system properties defined in the table below. Where the [ThreadFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/threadfactory-0000001054518622) for the default group is not configured then the pooled threads of the default group are [Thread#isDaemon](https://developer.harmonyos.com/cn/docs/documentation/doc-references/thread-0000001054238447#ZH-CN_TOPIC_0000001054238447__isDaemon--) threads.  __**Threading** The completion handler for an I/O operation initiated on a channel bound to a group is guaranteed to be invoked by one of the pooled threads in the group. This ensures that the completion handler is run by a thread with the expected identity.  Where an I/O operation completes immediately, and the initiating thread is one of the pooled threads in the group then the completion handler may be invoked directly by the initiating thread. To avoid stack overflow, an implementation may impose a limit as to the number of activations on the thread stack. Some I/O operations may prohibit invoking the completion handler directly by the initiating thread (see [AsynchronousServerSocketChannel#accept(Object,CompletionHandler)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronousserversocketchannel-0000001054358478#ZH-CN_TOPIC_0000001054358478__accept-A-java_nio_channels_CompletionHandler-)).  **Shutdown and Termination** The [shutdown](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__shutdown--) method is used to initiate an orderly shutdown of a group. An orderly shutdown marks the group as shutdown; further attempts to construct a channel that binds to the group will throw [ShutdownChannelGroupException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shutdownchannelgroupexception-0000001054119754). Whether or not a group is shutdown can be tested using the [isShutdown](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__isShutdown--) method. Once shutdown, the group terminates when all asynchronous channels that are bound to the group are closed, all actively executing completion handlers have run to completion, and resources used by the group are released. No attempt is made to stop or interrupt threads that are executing completion handlers. The [isTerminated](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__isTerminated--) method is used to test if the group has terminated, and the [awaitTermination](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__awaitTermination-long-java_util_concurrent_TimeUnit-) method can be used to block until the group has terminated.  The [shutdownNow](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannelgroup-0000001054678459#ZH-CN_TOPIC_0000001054678459__shutdownNow--) method can be used to initiate a forceful shutdown of the group. In addition to the actions performed by an orderly shutdown, the shutdownNow method closes all open channels in the group as if by invoking the [AsynchronousChannel#close](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouschannel-0000001054238487#ZH-CN_TOPIC_0000001054238487__close--) method. **Since:** 1.7**See Also:** [AsynchronousSocketChannel.open(AsynchronousChannelGroup)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronoussocketchannel-0000001054119819#ZH-CN_TOPIC_0000001054119819__open-java_nio_channels_AsynchronousChannelGroup-), [AsynchronousServerSocketChannel.open(AsynchronousChannelGroup)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronousserversocketchannel-0000001054358478#ZH-CN_TOPIC_0000001054358478__open-java_nio_channels_AsynchronousChannelGroup-)Constructor Summary Modifier | Constructor | Description
