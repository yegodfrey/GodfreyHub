# DoubleToLongFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface DoubleToLongFunction  
  
---  
Represents a function that accepts a double-valued argument and produces a long-valued result. This is the double-to-long primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsLong(double)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/doubletolongfunction-0000001054838580#ZH-CN_TOPIC_0000001054838580__applyAsLong-double-).
