# LongToIntFunction
    
    [@FunctionalInterface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/functionalinterface-0000001054358446)
    public interface LongToIntFunction  
  
---  
Represents a function that accepts a long-valued argument and produces an int-valued result. This is the long-to-int primitive specialization for [Function](https://developer.harmonyos.com/cn/docs/documentation/doc-references/function-0000001054119955). 

This is a [functional interface](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054238623) whose functional method is [applyAsInt(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longtointfunction-0000001054199902#ZH-CN_TOPIC_0000001054199902__applyAsInt-long-).
