# InputStreamReader

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.Reader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435) |---|---java.io.InputStreamReader
    
    public class InputStreamReader
    extends [Reader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/reader-0000001054238435)  
  
---  
An InputStreamReader is a bridge from byte streams to character streams: It reads bytes and decodes them into characters using a specified [charset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charset-0000001054678500). The charset that it uses may be specified by name or may be given explicitly, or the platform's default charset may be accepted. 

Each invocation of one of an InputStreamReader's read() methods may cause one or more bytes to be read from the underlying byte-input stream. To enable the efficient conversion of bytes to characters, more bytes may be read ahead from the underlying stream than are necessary to satisfy the current read operation. 

For top efficiency, consider wrapping an InputStreamReader within a BufferedReader. For example: 
    
    BufferedReader in
       = new BufferedReader(new InputStreamReader(System.in));

#### [h2]getEncoding

public [String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) getEncoding​()

Returns the name of the character encoding being used by this stream. 

If the encoding has an historical name then that name is returned; otherwise the encoding's canonical name is returned. 

If this instance was created with the [InputStreamReader(java.io.InputStream,java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/inputstreamreader-0000001054119761#ZH-CN_TOPIC_0000001054119761__InputStreamReader-java_io_InputStream-java_lang_String-) constructor then the returned name, being unique for the encoding, may differ from the name passed to the constructor. This method will return null if the stream has been closed. 

**Returns:**

The historical name of this encoding, or null if the stream has been closed

[Charset](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charset-0000001054678500)
