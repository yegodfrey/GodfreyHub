# Pipe

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.nio.channels.Pipe

    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

A pair of channels that implements a unidirectional pipe. 

A pipe consists of a pair of channels: A writable [Pipe.SinkChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pipe_sinkchannel-0000001054238491) channel and a readable [Pipe.SourceChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pipe_sourcechannel-0000001054678461) channel. Once some bytes are written to the sink channel they can be read from source channel in exactlyAthe order in which they were written. 

Whether or not a thread writing bytes to a pipe will block until another thread reads those bytes, or some previously-written bytes, from the pipe is system-dependent and therefore unspecified. Many pipe implementations will buffer up to a certain number of bytes between the sink and source channels, but such buffering should not be assumed.

1.4
