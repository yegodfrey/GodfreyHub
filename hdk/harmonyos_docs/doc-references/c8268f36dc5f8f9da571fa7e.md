# Overview  
  
Provides interfaces for audio and video recording.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Recorder.IRecorderListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_irecorderlistener-0000001054200218) | Listens for errors, alarms, and info events related to audio and video recording.  
  
#### Class Summary

Class | Description  
---|---  
[Recorder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder-0000001054678946) | Records videos and audios.  
[Recorder.AudioEncoder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_audioencoder-0000001054358925) | Describes the audio encoding format.  
[Recorder.AudioSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_audiosource-0000001054558947) | Describes the audio source.  
[Recorder.OrientationHint](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_orientationhint-0000001054238945) | Describes the rotation angle used during video playback.  
[Recorder.OutputFormat](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_outputformat-0000001054678915) | Describes the format of the output media.  
[Recorder.RecorderOnErrorType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_recorderonerrortype-0000001054838900) | Describes recording framework errors.  
[Recorder.RecorderOnInfoType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_recorderoninfotype-0000001054358934) | Describes recording framework info events and alarms.  
[Recorder.VideoEncoder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_videoencoder-0000001054120275) | Describes the available video encoding formats, including H.264 and high efficiency video coding (HEVC).  
[Recorder.VideoSource](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorder_videosource-0000001054120204) | Describes the video source, including the camera and surface.  
[RecorderProfile](https://developer.harmonyos.com/cn/docs/documentation/doc-references/recorderprofile-0000001054440233) | Describes the coding and decoding capabilities of the system.
