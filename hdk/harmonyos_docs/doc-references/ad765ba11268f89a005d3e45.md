# FilterOutputStream  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403) |---|---java.io.FilterOutputStream
    
    public class FilterOutputStream
    extends [OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403)  
  
---  
This class is the superclass of all classes that filter output streams. These streams sit on top of an already existing output stream (the _underlying_ output stream) which it uses as its basic sink of data, but possibly transforming the data along the way or providing additional functionality. 

The class FilterOutputStream itself simply overrides all methods of OutputStream with versions that pass all requests to the underlying output stream. Subclasses of FilterOutputStream may further override some of these methods as well as provide additional methods and fields.

**Since:**

JDK1.0

public void write​(byte[] b, int off, int len) throws [IOException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ioexception-0000001054358426)

Writes len bytes from the specified byte array starting at offset off to this output stream. 

The write method of FilterOutputStream calls the write method of one argument on each byte to output. 

Note that this method does not call the write method of its underlying input stream with the same arguments. Subclasses of FilterOutputStream should provide a more efficient implementation of this method.
