# InlaidElement

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.agp.components.element.Element](https://developer.harmonyos.com/cn/docs/documentation/doc-references/element-0000001054358705) |---|---[ohos.agp.components.element.ElementWrapper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementwrapper-0000001172556692) |---|---|---ohos.agp.components.element.InlaidElement

    extends [ElementWrapper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementwrapper-0000001172556692)  
  
---  
Inlays an element with another element based on a specific distance or proportion from the content bounds. 

This class can be used when Component requires a background that is smaller than the Component's actual bounds.
