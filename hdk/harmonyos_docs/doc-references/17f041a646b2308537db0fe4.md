# Overview  
  
Provides some necessary annotation classes for processing JSON structured data. 

These annotation classes, as the extended functions for JSON processing, make it easier to parse JSON data. For example, you can use the [ZSONField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zsonfield-0000001054559011) class to rename class properties.

**Since:**

3

#### Annotation Types Summary

Annotation Type | Description  
---|---  
[ZSONField](https://developer.harmonyos.com/cn/docs/documentation/doc-references/zsonfield-0000001054559011) | An annotation class that denotes the function of renaming class properties.
