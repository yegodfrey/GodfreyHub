# Overview  
  
Provides the glTF data processing capability. 

This package provides glTF data, as well as the methods for importing, exporting, and loading the glTF data.

**Since:**

3

#### Interface Summary

Interface | Description  
---|---  
[GltfData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfdata-0000001054440029) | Represents the glTF data obtained from a glTF file.  
[GltfExporter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfexporter-0000001054200016) | Provides methods for exporting 3D models, animations, and materials to a glTF file.  
[GltfImportData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfimportdata-0000001054518756) | Provides methods for importing data from a glTF file.  
[GltfLoader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfloader-0000001054678744) | Imports 3D models and related data (such as animations and materials) from a glTF file.  
[GltfLoader.ImportListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfloader_importlistener-0000001054358723) | Listener for asynchronous import result.
