# IRemoteObject
    
    public interface IRemoteObject  
  
---  
A remote object interface that must be implemented by service providers and users. 

This interface can be used to query or obtain an interface descriptor, add or remove a death notification, dump object status to a specific file, and send messages.

#### [h2]sendRequest

boolean sendRequest​(int code, [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) data, [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) reply, [MessageOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageoption-0000001054678939) option) throws [RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984)

Sends a [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) message to the peer process in synchronous or asynchronous mode. 

If asynchronous mode is set for option, a response is returned immediately. If synchronous mode is set for option, the interface will wait for a response from the peer process until the request times out. The user must prepare reply for receiving the execution result given by the peer process.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
code  |  Indicates the message code, which is determined by both sides of the communication. If the interface is generated by the IDL tool, the message code is automatically generated by IDL.  
data  |  Indicates the [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) object sent to the peer process.  
reply  |  Indicates the [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) object returned by the peer process.  
option  |  Indicates the synchronous or asynchronous mode to send messages.  
  
**Returns:**

Returns true if the method is called successfully; returns false otherwise.

**Throws:**

Throw Name | Throw Description  
---|---  
[RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984) |  Throws this exception if the method fails to be called.
