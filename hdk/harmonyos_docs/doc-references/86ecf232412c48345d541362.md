# IAbilityContinuation
    
    public interface IAbilityContinuation  
  
---  
Enables an [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) to implement migration in a distributed system. 

You can use the migration capability provided by the Ability to migrate data between a local device and a remote device in a distributed system. The ability or ability slice that implements this interface has the migration capability. You can initiate a migration request by calling [Ability#continueAbility()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__continueAbility--) or [AbilitySlice#continueAbility()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__continueAbility--) on the local device, and then implement the methods provided in this interface to save or restore application data. The saved data is managed by the distributed data management module. The remote device can obtain and restore the saved data when starting the ability. In this way, the ability on the local device is migrated to the remote device.

#### Method Detail

#### [h2]onStartContinuation

boolean onStartContinuation​()

Asks a user whether to start the migration. 

This method is called back when a local ability initiates a migration request.

If the Ability does not implement this method, this Ability cannot be migrated, and false is returned. If the AbilitySlice does not implement this method, it does not affect whether its host ability can be migrated, and true is returned by default.

**Returns:**

Returns true if the user allows the migration; returns false otherwise.

**Since:**

1

#### [h2]onSaveData

boolean onSaveData​([IntentParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentparams-0000001054439977) saveData)

Saves the user data (carried in the [IntentParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentparams-0000001054439977) object) of a local ability generated during runtime. After the migration is triggered and the local ability is ready, this method is called when the Distributed Scheduler Service requests data from the local ability. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
saveData  |  Indicates the user data to save.  
  
**Returns:**

Returns true if the data is successfully saved; returns false otherwise.

**Since:**

1

#### [h2]onRestoreData

boolean onRestoreData​([IntentParams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intentparams-0000001054439977) restoreData)

Restores the user data saved during the migration for an ability on the remote device immediately after the ability is created on the remote device. Lifecycle scheduling for the ability starts only after the user data is restored. 

**Parameters:**

Parameter Name | Parameter Description  
---|---  
restoreData  |  Indicates the user data to restore.  
  
**Returns:**

Returns true if the data is successfully restored; returns false otherwise.

#### [h2]onCompleteContinuation

void onCompleteContinuation​(int result)

Called back when a local ability migration is complete. 

You can define the processing logic after the migration is complete. For example, you can display a prompt to notify the user of the successful migration and then exit the local ability.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
result  |  Indicates the migration result code. The value 0 indicates that the migration is successful, and -1 indicates that the migration fails.  
  
**Since:**

1

#### [h2]onRemoteTerminated

default void onRemoteTerminated​()

Called to notify the local device when a running ability on the remote device is destroyed after a reversible migration is performed for the ability from the local device to the remote device. A reversible migration is triggered by calling [Ability#continueAbilityReversibly()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__continueAbilityReversibly--) or [Ability#continueAbilityReversibly(String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__continueAbilityReversibly-java_lang_String-).

default void onFailedContinuation​(int errorCode)

Called when an error occurred during the migration process of a local ability.
