# DownloadSession.DownloadInfo

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.miscservices.download.DownloadSession.DownloadInfo

    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)

Provides methods for obtaining download session information and status. 

Applications can call [DownloadSession.query()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/downloadsession-0000001054358929#ZH-CN_TOPIC_0000001054358929__query--) to query real-time download information, including download links, storage paths, downloads size in bytes, and failure causes.
