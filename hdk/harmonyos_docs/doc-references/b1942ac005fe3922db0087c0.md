# Complication  
  
java.lang.Object |---ohos.wearable.complication.Complication
    
    public class Complication
    extends java.lang.Object  
  
---  
Defines complication data types. 

Complications are components used to display data on the watch face. The type of data displayed can be a launcher icon, a long text string, simple data, ranged data, and list data.

#### [h2]TYPE_RANGED

public static final int TYPE_RANGED

Indicates a complication that displays ranged data. 

The watch face displays a template that may contain an icon, a title and ranged data, as defined in [ComplicationTemplate](https://developer.harmonyos.com/cn/docs/documentation/doc-references/complicationtemplate-0000001091706036). The ranged data includes maximum, minimum and current values, all of which are of the float type.
