# Overview  
  
Provides the NFC card emulation module. 

CardEmulation: Provides methods for enabling and disabling card emulation, querying the card emulation status, checking whether a secure element supports NFC card emulation, obtaining the NFCC or eSE information, and customizing radio frequency (RF) parameters, and setting a preferred foreground application. 

HostService: Defines an abstract class that is inherited by the NFC host application. 

OffHostService: Defines an abstract class that is inherited by the NFC off-host application.
