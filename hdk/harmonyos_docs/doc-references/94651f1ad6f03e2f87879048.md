# Overview  
  
Provides classes to print and parse dates and times. 

Printing and parsing is based around the [DateTimeFormatter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datetimeformatter-0000001054678545) class. Instances are generally obtained from [DateTimeFormatter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datetimeformatter-0000001054678545), however [DateTimeFormatterBuilder](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datetimeformatterbuilder-0000001054838530) can be used if more power is needed. 

Localization occurs by calling [withLocale(Locale)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datetimeformatter-0000001054678545#ZH-CN_TOPIC_0000001054678545__withLocale-java_util_Locale-) on the formatter. Further customization is possible using [DecimalStyle](https://developer.harmonyos.com/cn/docs/documentation/doc-references/decimalstyle-0000001054358564). 

**Package specification**

Unless otherwise noted, passing a null argument to a constructor or method in any class or interface in this package will cause a [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710) to be thrown. The Javadoc "@param" definition is used to summarise the null-behavior. The "@throws [NullPointerException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nullpointerexception-0000001054119710)" is not explicitly documented in each method. 

All calculations should check for numeric overflow and throw either an [ArithmeticException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/arithmeticexception-0000001054358429) or a [DateTimeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/datetimeexception-0000001054199844).
