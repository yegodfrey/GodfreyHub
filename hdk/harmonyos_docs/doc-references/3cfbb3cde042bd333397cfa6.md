# Overview  
  
Provides interfaces to audio and video session.

**Since:**

3

#### Class Summary

Class | Description  
---|---  
[AVBrowser](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowser-0000001054358927) | Browses media data provided by the [AVBrowserService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserservice-0000001054558949).  
[AVBrowserService](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avbrowserservice-0000001054558949) | Base class used to access the media browser service.  
[AVController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avcontroller-0000001054238947) | Allows your application to interact with media sessions to control media playback, for example, to start or stop playback, or play the next media item.  
[AVController.PlayControls](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avcontroller_playcontrols-0000001054678917) | An inner class of AVController to send media playback requests to the AVSession and allow your application to send commands to the media session.  
[AVSession](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avsession-0000001054838902) | Represents the media session provided for your application to control media playback.  
[AVSessionManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avsessionmanager-0000001217877985) | Manages media sessions.  
[AVVolumeHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/avvolumehandler-0000001217996557) | Provides methods to control volume.
