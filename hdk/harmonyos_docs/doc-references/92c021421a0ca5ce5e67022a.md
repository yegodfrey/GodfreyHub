# Lifecycle

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.ability.Lifecycle
    
    public class Lifecycle
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides a class for you to observe the lifecycle of an [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) or [AbilitySlice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680). 

[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) and [AbilitySlice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680) have their own lifecycle and dispatch their lifecycle states to Lifecycle for management. You can call the [Lifecycle#getLifecycleState()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967#ZH-CN_TOPIC_0000001054439967__getLifecycleState--) method to obtain their current lifecycle state or call [Lifecycle#addObserver(ILifecycleObserver)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle-0000001054439967#ZH-CN_TOPIC_0000001054439967__addObserver-ohos_aafwk_ability_ILifecycleObserver-) to add a lifecycle observer to observe lifecycle changes in real-time. This class allows you to implement lifecycle callbacks of [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) and [AbilitySlice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680) using methods from other classes. In this way, [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) and [AbilitySlice](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680) can take only their own responsibilities, enabling a decoupled application architecture.

You can call [Ability#getLifecycle()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__getLifecycle--) and [AbilitySlice#getLifecycle()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilityslice-0000001054678680#ZH-CN_TOPIC_0000001054678680__getLifecycle--) to obtain Lifecycle objects.

#### [h2]getLifecycleState

public [Lifecycle.Event](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lifecycle_event-0000001054199956) getLifecycleState​()

Obtains the current lifecycle event. 

Lifecycle events drive lifecycle state changes. Therefore, you are able to know the lifecycle state once you obtain the lifecycle event. For example, if the ON_ACTIVE event is received, the ability or ability slice is in the ACTIVE state; if the ON_FOREGROUND event is received, the ability or ability slice is changing from the BACKGROUND state to INACTIVE.

**Returns:**

Returns the current lifecycle event.
