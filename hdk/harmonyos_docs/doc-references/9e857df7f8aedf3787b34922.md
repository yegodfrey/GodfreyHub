#### [h2]clickKey

boolean clickKey​([IDialog](https://developer.harmonyos.com/cn/docs/documentation/doc-references/idialog-0000001054200030) dialog, [KeyEvent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/keyevent-0000001054120285) event)

**Parameters:**

Parameter Name | Parameter Description  
---|---
