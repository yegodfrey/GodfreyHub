# Overview  
  
Provides classes that leverage Java's annotation mechanism to annotate desired variables and types, so as to eliminate circular reference and improve performance. 

The related classes are as follows: [Permanent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permanent-0000001054358401), [Unowned](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unowned-0000001054558423), [UnownedLocal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unownedlocal-0000001054238421), [UnownedOuter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unownedouter-0000001054678391), and [Weak](https://developer.harmonyos.com/cn/docs/documentation/doc-references/weak-0000001054838376).

#### Annotation Types Summary

Annotation Type | Description  
---|---  
[Permanent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/permanent-0000001054358401) | Annotates persistent memory objects.  
[Unowned](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unowned-0000001054558423) | Annotates an object without ownership to eliminate circular reference.  
[UnownedLocal](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unownedlocal-0000001054238421) | Annotates a method or a single local variable.  
[UnownedOuter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unownedouter-0000001054678391) | Annotates a class to eliminate circular reference.  
[Weak](https://developer.harmonyos.com/cn/docs/documentation/doc-references/weak-0000001054838376) | Annotates weak reference objects.
