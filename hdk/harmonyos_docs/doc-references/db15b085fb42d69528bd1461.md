# AccessibleAbility

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[ohos.app.AbilityContext](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitycontext-0000001054358759) |---|---[ohos.aafwk.ability.Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) |---|---|---ohos.accessibility.ability.AccessibleAbility
    
    public abstract class AccessibleAbility
    extends [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007)  
  
---  
Provides capabilities for you to develop your own accessibility application. 

The accessibility application helps users use their devices and programs easily. [AccessibilityEventInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibilityeventinfo-0000001054678661) will be called to send events when the UI status has any changes, for example, a button is clicked or focus is gained. You can inherit this class to handle your interested events.
