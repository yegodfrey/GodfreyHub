Method Detail [h2]onRemoteRequest boolean onRemoteRequest​(int code, [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) data, [MessageParcel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924) reply, [MessageOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageoption-0000001054678939) option) throws [RemoteException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/remoteexception-0000001054518984) Called when an internal ability request is received from the local ability. You can implement this method to process the request, such as calling, subscribing, and unsubscribing the internal ability. You need to specify the service code and request data of the internal ability. The request data structures vary depending on the request types. 
                * For a callAbility request, the data type is JSON object string. Call [Parcel.readString()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parcel-0000001054519018#ZH-CN_TOPIC_0000001054519018__readString--) to read the string and parse the JSON object to obtain the data.
                * For a subscribeAbilityEvent request, the data type is [IRemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970). Call [MessageParcel.readRemoteObject()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/messageparcel-0000001054838924#ZH-CN_TOPIC_0000001054838924__readRemoteObject--) to obtain the object, and call [IRemoteObject.sendRequest(int, MessageParcel, MessageParcel, MessageOption)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970#ZH-CN_TOPIC_0000001054678970__sendRequest-int-ohos_rpc_MessageParcel-ohos_rpc_MessageParcel-ohos_rpc_MessageOption-) provided by the object to report events, which are distinguished by service codes. The request data needs to be serialized into a JSON object or JSON array string.
                * For a unsubscribeAbilityEvent request, set the request data to null.
Before publishing your JavaScript APIs, ensure that the service codes and request data structures are forward-compatible. **Parameters:** Parameter Name | Parameter Description
