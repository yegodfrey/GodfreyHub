# Overview  
  
Provides interfaces to control audio and video playback.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[Player.IPlayerCallback](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_iplayercallback-0000001054358923) | Provides media player callbacks upon completion of playback, playback position changes, and video size changes.  
  
#### Class Summary

Class | Description  
---|---  
[Player](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player-0000001054238943) | Controls audio and video playback.  
[Player.DeviceInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_deviceinfo-0000001054678913) | Provides information about a device that plays an audio or video file.  
[Player.MediaTimedMetaData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_mediatimedmetadata-0000001054838898) | Represents media timed metadata.  
[Player.MediaTimeInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_mediatimeinfo-0000001054358932) | Represents media time information.  
[Player.StreamInfo](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_streaminfo-0000001059908829) | Provides descriptions of the media stream metadata contained in media files.  
  
#### Enum Summary

Enum | Description  
---|---  
[Player.AudioHandler](https://developer.harmonyos.com/cn/docs/documentation/doc-references/player_audiohandler-0000001121107279) | Enumerates handling modes for audio parameters whose values are out of common ranges.
