# IAbilityDelegator
    
    public interface IAbilityDelegator  
  
---  
A global test utility interface used for adding [IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958) objects and control lifecycle states of abilities. 

You can call [addAbilityMonitor(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942#ZH-CN_TOPIC_0000001054119942__addAbilityMonitor-java_lang_String-) to add IAbilityMonitor objects to monitor the lifecycle states of specified abilities. You can also call method such as [triggerClickEvent(ohos.aafwk.ability.Ability,ohos.agp.components.Component)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942#ZH-CN_TOPIC_0000001054119942__triggerClickEvent-ohos_aafwk_ability_Ability-ohos_agp_components_Component-) to control the lifecycle states of abilities and dispatch input events.

#### Method Detail

#### [h2]waitAbilityMonitor

[Optional](https://developer.harmonyos.com/cn/docs/documentation/doc-references/optional-0000001054558597)<[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007)> waitAbilityMonitor​([IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958) monitor)

Waits for and returns the Ability object that matches the conditions set in the given [IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958). 

If a matched ability is successfully obtained, the specified IAbilityMonitor object becomes invalid. Otherwise, you can continue to use it in [waitAbilityMonitor(ohos.aafwk.ability.delegation.IAbilityMonitor)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942#ZH-CN_TOPIC_0000001054119942__waitAbilityMonitor-ohos_aafwk_ability_delegation_IAbilityMonitor-) or [waitAbilityMonitor(ohos.aafwk.ability.delegation.IAbilityMonitor,long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942#ZH-CN_TOPIC_0000001054119942__waitAbilityMonitor-ohos_aafwk_ability_delegation_IAbilityMonitor-long-) to obtain abilities.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
monitor  |  Indicates the [IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958) object used for monitoring lifecycle state changes of an ability.  
  
**Returns:**

Returns an Optional object containing the Ability object if its lifecycle state has changed and it matches the given monitor; returns an empty Optional object otherwise.

**Since:**

3

#### [h2]waitAbilityMonitor

[Optional](https://developer.harmonyos.com/cn/docs/documentation/doc-references/optional-0000001054558597)<[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007)> waitAbilityMonitor​([IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958) monitor, long timeout)
