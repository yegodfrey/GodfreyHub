# Name
    
    public interface Name
    extends [CharSequence](https://developer.harmonyos.com/cn/docs/documentation/doc-references/charsequence-0000001054678442)  
  
---  
An immutable sequence of characters. When created by the same implementation, objects implementing this interface must obey the general [equals contract](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446#ZH-CN_TOPIC_0000001054678446__equals-java_lang_Object-) when compared with each other. Therefore, Name objects from the same implementation are usable in collections while Names from different implementations may not work properly in collections. 

An empty Name has a length of zero. 

In the context of [annotation processing](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processingenvironment-0000001170334453), the guarantees for "the same" implementation must include contexts where the [API mediated](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001123534682) side effects of [processors](https://developer.harmonyos.com/cn/docs/documentation/doc-references/processor-0000001170214349) could be visible to each other, including successive annotation processing [rounds](https://developer.harmonyos.com/cn/docs/documentation/doc-references/roundenvironment-0000001123694518).
