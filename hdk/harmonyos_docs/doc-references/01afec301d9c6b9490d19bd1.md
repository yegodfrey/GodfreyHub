# Query

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.data.distributed.common.Query
    
    public class Query
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Represents a database query using a predicate. 

This class provides a constructor used to create a Query instance, which is used to query data matching specified conditions in the database. 

This class also provides methods for adding predicates to the Query instance.
