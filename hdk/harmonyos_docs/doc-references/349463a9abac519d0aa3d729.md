# ItemAnimation.ItemAnimationFinishedListener
    
    public static interface ItemAnimation.ItemAnimationFinishedListener  
  
---  
  
Implements the listening for the completion of all component animations.

When the provider is updated, animations are triggered. A callback is invoked when all component animations finish running.
