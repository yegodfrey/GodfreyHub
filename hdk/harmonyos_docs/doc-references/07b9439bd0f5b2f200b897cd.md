Provides remote components for cross-process display. 

This class provides a set of basic operations for modifying the content of remote components. It is commonly used for developing notifications displayed in the notification bar as well as widgets on the desktop or home screen.

#### [h2]setApplyType

public boolean setApplyType​(int applyType)

Sets the operation type. 

The operation type can be [APPLY_TYPE_LAYOUT_AND_ACTIONS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001#ZH-CN_TOPIC_0000001054440001__APPLY_TYPE_LAYOUT_AND_ACTIONS) or [APPLY_TYPE_ACTIONS_ONLY](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001#ZH-CN_TOPIC_0000001054440001__APPLY_TYPE_ACTIONS_ONLY). The [APPLY_TYPE_LAYOUT_AND_ACTIONS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001#ZH-CN_TOPIC_0000001054440001__APPLY_TYPE_LAYOUT_AND_ACTIONS) type means to inflate the layout and apply all of the actions, whereas the [APPLY_TYPE_ACTIONS_ONLY](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001#ZH-CN_TOPIC_0000001054440001__APPLY_TYPE_ACTIONS_ONLY) type means to apply all of the actions only.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
applyType  |  Indicates the operation type, which can only be [APPLY_TYPE_LAYOUT_AND_ACTIONS](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001#ZH-CN_TOPIC_0000001054440001__APPLY_TYPE_LAYOUT_AND_ACTIONS) or [APPLY_TYPE_ACTIONS_ONLY](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001#ZH-CN_TOPIC_0000001054440001__APPLY_TYPE_ACTIONS_ONLY). A value other than these two will cause failure to invoke the current method.  
  
**Returns:**

Returns true if the operation type is set successfully; returns false otherwise.

#### [h2]setImageContent

public [ComponentProvider.Action](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider_action-0000001060679060) setImageContent​(int componentId, int resId)

Sets the content to be displayed on a specified image component. 

This method is equivalent to[Image#setPixelMap(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/image-0000001054120045#ZH-CN_TOPIC_0000001054120045__setPixelMap-int-). You need to call [applyAction(ohos.agp.components.ComponentContainer)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider-0000001054440001#ZH-CN_TOPIC_0000001054440001__applyAction-ohos_agp_components_ComponentContainer-) for the method to take effect.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
componentId  |  Indicates the ID of the image component.  
resId  |  Indicates the resource ID of the content to be displayed on the image component. The content can be an image in the PNG, SVG, or another applicable format.  
  
**Returns:**

Returns an [Action](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentprovider_action-0000001060679060) object.

**Since:**
