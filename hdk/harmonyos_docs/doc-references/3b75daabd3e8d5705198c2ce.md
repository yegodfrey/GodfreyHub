#### [h2]EXPOSURE_FPS_RANGE

public static final [ParameterKey.Key](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parameterkey_key-0000001054238917)<[Scope](https://developer.harmonyos.com/cn/docs/documentation/doc-references/scope-0000001054358994)<[Integer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/integer-0000001054119702)>> EXPOSURE_FPS_RANGE

Indicates the key of a frame rate range that the AE can reach. 

This key can be used to set the frame rate range for image sampling. To set a specific frame rate, ensure that the upper and lower limits of the range are the same. For example, you can use [30,30] to set the sampling frame rate to 30 fps.
