This class acts as a factory for trust managers based on a source of trust material. Each trust manager manages a specific type of trust material for use by secure sockets. The trust material is based on a KeyStore and/or provider specific sources.**Since:** 1.4**See Also:** [TrustManager](https://developer.harmonyos.com/cn/docs/documentation/doc-references/trustmanager-0000001054358648)Constructor Summary Modifier | Constructor | Description
