Provides applications with access to the timer system. Applications may need to perform an action at a specified time. Register [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019) or [ITimerListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/timer_itimerlistener-0000001054518966) with the timer system. When the registered timer goes off, the system sends the Intentto the application or calls the listener. Timers will be invalid after the system is powered off or restarted. **Since:** 1Nested Class Summary Modifier and Type | Class | Description
