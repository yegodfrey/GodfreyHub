# ComponentTransition

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.agp.components.ComponentTransition
    
    public class ComponentTransition
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Provides an animation for the layout change of a ComponentContainer object. 

To perform layout transition on a layout container, create a ComponentTransition object, and then set a ComponentContainer object using [ComponentContainer#setComponentTransition](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componentcontainer-0000001054120043#ZH-CN_TOPIC_0000001054120043__setComponentTransition-ohos_agp_components_ComponentTransition-).

#### [h2]CHANGING

public static final int CHANGING

Indicates the animation running on components changed by layout modification, instead of by adding or removing a component to or from the layout container. 

By default, this transition type is disabled. You can invoke [addTransitionType(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/componenttransition-0000001060157225#ZH-CN_TOPIC_0000001060157225__addTransitionType-int-) to enable it.

public void addTransitionType​(int type)
