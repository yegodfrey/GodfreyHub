A selectable channel for stream-oriented connecting sockets.  A socket channel is created by invoking one of the [open](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__open--) methods of this class. It is not possible to create a channel for an arbitrary, pre-existing socket. A newly-created socket channel is open but not yet connected. An attempt to invoke an I/O operation upon an unconnected channel will cause a [NotYetConnectedException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/notyetconnectedexception-0000001054838450) to be thrown. A socket channel can be connected by invoking its [connect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__connect-java_net_SocketAddress-) method; once connected, a socket channel remains connected until it is closed. Whether or not a socket channel is connected may be determined by invoking its [isConnected](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__isConnected--) method.  Socket channels support _non-blocking connection:_ A socket channel may be created and the process of establishing the link to the remote socket may be initiated via the [connect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__connect-java_net_SocketAddress-) method for later completion by the [finishConnect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__finishConnect--) method. Whether or not a connection operation is in progress may be determined by invoking the [isConnectionPending](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__isConnectionPending--) method.  Socket channels support _asynchronous shutdown,_ which is similar to the asynchronous close operation specified in the [Channel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/channel-0000001054838442) class. If the input side of a socket is shut down by one thread while another thread is blocked in a read operation on the socket's channel, then the read operation in the blocked thread will complete without reading any bytes and will return -1. If the output side of a socket is shut down by one thread while another thread is blocked in a write operation on the socket's channel, then the blocked thread will receive an [AsynchronousCloseException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronouscloseexception-0000001054558495).  Socket options are configured using the [setOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__setOption-java_net_SocketOption-T-) method. Socket channels support the following options:  Additional (implementation specific) options may also be supported.  Socket channels are safe for use by multiple concurrent threads. They support concurrent reading and writing, though at most one thread may be reading and at most one thread may be writing at any given time. The [connect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__connect-java_net_SocketAddress-) and [finishConnect](https://developer.harmonyos.com/cn/docs/documentation/doc-references/socketchannel-0000001054439779#ZH-CN_TOPIC_0000001054439779__finishConnect--) methods are mutually synchronized against each other, and an attempt to initiate a read or write operation while an invocation of one of these methods is in progress will block until that invocation is complete.  **Since:** 1.4Constructor Summary Modifier | Constructor | Description
