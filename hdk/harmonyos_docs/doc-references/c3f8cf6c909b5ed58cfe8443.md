Text.TextObserver
    
    public static interface Text.TextObserver

Provides a text observer to observe text changes in a component. The [onTextUpdated(java.lang.String, int, int, int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/text_textobserver-0000001054558713#ZH-CN_TOPIC_0000001054558713__onTextUpdated-java_lang_String-int-int-int-) method in this class is called each time the text changes. ---|---|---

Method Detail [h2]onTextUpdated void onTextUpdated​([String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) text, int start, int before, int count) Called back when the text is changed. This method is used to process the changed text, for example, to verify the input LOV to get LOVE, for which text is LOVE, start is 3, before is 3, and count is 1. **Parameters:** Parameter Name | Parameter Description  
---|---  
text  |  Indicates the current text.

before  |  Indicates the length of the old text.  
count  |  Indicates the length of the text to be added.
