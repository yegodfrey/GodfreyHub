Enumerates alpha types of the texture. A pixel has multiple levels of transparency. In a simple alpha blending, alpha weighting is performed on the drawing color and the target color to obtain a new color. For example, if the alpha value is a number from 0 to 1, the formula for calculating the value of the new color is as follows: New color = Drawing color x Alpha value + Target color x (1 - Alpha value). **Since:** 3Enum Constant Summary Enum Constant | Description
