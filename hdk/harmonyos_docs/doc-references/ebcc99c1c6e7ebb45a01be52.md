TypeMirror
    
    public interface TypeMirror
    extends [AnnotatedConstruct](https://developer.harmonyos.com/cn/docs/documentation/doc-references/annotatedconstruct-0000001123534692)  
  
---  
Represents a type in the Java programming language. Types include primitive types, declared types (class and interface types), array types, type variables, and the null type. Also represented are wildcard type arguments, the signature and return types of executables, and pseudo-types corresponding to packages and to the keyword void.  Types should be compared using the utility methods in [Types](https://developer.harmonyos.com/cn/docs/documentation/doc-references/types-0000001123694552). There is no guarantee that any particular type will always be represented by the same object.  To implement operations based on the class of an TypeMirror object, either use a [visitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typevisitor-0000001170214377) or use the result of the [getKind()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typemirror-0000001123534712#ZH-CN_TOPIC_0000001123534712__getKind--) method.
