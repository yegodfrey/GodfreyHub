# NodeChangeEvent

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.EventObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventobject-0000001054119921) |---|---java.util.prefs.NodeChangeEvent
    
    public class NodeChangeEvent
    extends [EventObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventobject-0000001054119921)  
  
---  
An event emitted by a Preferences node to indicate that a child of that node has been added or removed.

Note, that although NodeChangeEvent inherits Serializable interface from java.util.EventObject, it is not intended to be Serializable. Appropriate serialization methods are implemented to throw NotSerializableException.

**Since:**

1.4
