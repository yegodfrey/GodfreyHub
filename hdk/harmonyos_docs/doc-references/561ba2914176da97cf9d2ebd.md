# AbstractQueuedLongSynchronizer

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.util.concurrent.locks.AbstractOwnableSynchronizer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractownablesynchronizer-0000001054238621) |---|---java.util.concurrent.locks.AbstractQueuedLongSynchronizer

A version of [AbstractQueuedSynchronizer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueuedsynchronizer-0000001054358610) in which synchronization state is maintained as a long. This class has exactly the same structure, properties, and methods as AbstractQueuedSynchronizer with the exception that all state-related parameters and results are defined as long rather than int. This class may be useful when creating synchronizers such as multilevel locks and barriers that require 64 bits of state. 

See [AbstractQueuedSynchronizer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueuedsynchronizer-0000001054358610) for usage notes and examples.

#### [h2]tryAcquire

protected boolean tryAcquire​(long arg)

Attempts to acquire in exclusive mode. This method should query if the state of the object permits it to be acquired in the exclusive mode, and if so to acquire it. 

This method is always invoked by the thread performing acquire. If this method reports failure, the acquire method may queue the thread, if it is not already queued, until it is signalled by a release from some other thread. This can be used to implement method [Lock#tryLock()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/lock-0000001054678622#ZH-CN_TOPIC_0000001054678622__tryLock--). 

The default implementation throws [UnsupportedOperationException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unsupportedoperationexception-0000001054238453).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
arg  |  the acquire argument. This value is always the one passed to an acquire method, or is the value saved on entry to a condition wait. The value is otherwise uninterpreted and can represent anything you like.  
  
**Returns:**

true if successful. Upon success, this object has been acquired.

**Throws:**

Throw Name | Throw Description

#### [h2]hasQueuedPredecessors

public final boolean hasQueuedPredecessors​()

Queries whether any threads have been waiting to acquire longer than the current thread. 

An invocation of this method is equivalent to (but may be more efficient than): 
    
    getFirstQueuedThread() != Thread.currentThread() &&
     hasQueuedThreads()

Note that because cancellations due to interrupts and timeouts may occur at any time, a true return does not guarantee that some other thread will acquire before the current thread. Likewise, it is possible for another thread to win a race to enqueue after this method has returned false, due to the queue being empty. 

This method is designed to be used by a fair synchronizer to avoid [barging](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueuedsynchronizer-0000001054358610#ZH-CN_TOPIC_0000001054358610__barging). Such a synchronizer's [tryAcquire(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueuedlongsynchronizer-0000001054678591#ZH-CN_TOPIC_0000001054678591__tryAcquire-long-) method should return false, and its [tryAcquireShared(long)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abstractqueuedlongsynchronizer-0000001054678591#ZH-CN_TOPIC_0000001054678591__tryAcquireShared-long-) method should return a negative value, if this method returns true (unless this is a reentrant acquire). For example, the tryAcquire method for a fair, reentrant, exclusive mode synchronizer might look like this: 
    
    protected boolean tryAcquire(int arg) {
       if (isHeldExclusively()) {
         // A reentrant acquire; increment hold count
         return true;
       } else if (hasQueuedPredecessors()) {
         return false;
       } else {
         // try to acquire normally
       }
     }

**Returns:**

true if there is a queued thread preceding the current thread, and false if the current thread is at the head of the queue or the queue is empty

**Since:**

1.7
