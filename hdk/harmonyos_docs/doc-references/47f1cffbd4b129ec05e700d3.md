UnlockScreenCallback
    
    public interface UnlockScreenCallback  
  
---  
Provides callbacks for screen lock changes. The callbacks will be invoked after your application calls [ScreenLockController#unlockScreen(Context, UnlockScreenCallback)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/screenlockcontroller-0000001054238951#ZH-CN_TOPIC_0000001054238951__unlockScreen-ohos_app_Context-ohos_miscservices_screenlock_interfaces_UnlockScreenCallback-) to attempt to unlock the device screen. **Since:** 3Method Summary Modifier and Type | Method | Description  
---|---|---  
void | [onUnlockFailed](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unlockscreencallback-0000001054120281#ZH-CN_TOPIC_0000001054120281__onUnlockFailed--)​() |  Called when the screen fails to be unlocked.   
void | [onUnlockSucceeded](https://developer.harmonyos.com/cn/docs/documentation/doc-references/unlockscreencallback-0000001054120281#ZH-CN_TOPIC_0000001054120281__onUnlockSucceeded--)​() |  Called when the screen is successfully unlocked.
