# OnResultListener
    
    public interface OnResultListener<T>  
  
---  
Provides a callback for observing NLU method calls. 

The caller determines how to implement this interface when using [NluClient#init(Context, OnResultListener, boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nluclient-0000001054518788#ZH-CN_TOPIC_0000001054518788__init-ohos_app_Context-ohos_ai_nlu_OnResultListener-boolean-) to initialize the NLU engine.

#### [h2]onResult

void onResult​([T](https://developer.harmonyos.com/cn/docs/documentation/doc-references/onresultlistener-0000001054440061) result)

Called after the NLU engine is initialized or NLU text is parsed. 

After the NLU engine is initialized by using [NluClient#init(Context, OnResultListener, boolean)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/nluclient-0000001054518788#ZH-CN_TOPIC_0000001054518788__init-ohos_app_Context-ohos_ai_nlu_OnResultListener-boolean-), the NLU enginer server invokes this callback to process the initialization result data and parsed text. The caller determines how to implement this callback.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
result  |  Indicates the NLU initialization result data.
