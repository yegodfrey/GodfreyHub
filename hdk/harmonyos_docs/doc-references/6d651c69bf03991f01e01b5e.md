# Ability.WindowAttributeHelper

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.aafwk.ability.Ability.WindowAttributeHelper
    
    public static class Ability.WindowAttributeHelper
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)  
  
---  
Helps you use an [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019) to set window attributes for the current application. 

This class encapsulates padding settings of a window in an [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019), and you do not need to care about how the data is stored.

#### [h2]WindowAttributeHelper

public WindowAttributeHelper​([Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019) intentAttribute)

A parameterized constructor used to create a WindowAttributeHelper instance. 

The [Intent](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intent-0000001054120019) carried in the instance automatically stores the attribute settings after a setting method provided by [WindowAttributeHelper](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability_windowattributehelper-0000001054439965) is called.

**Parameters:**

Parameter Name | Parameter Description  
---|---
