# Delayed
    
    public interface Delayed
    extends [Comparable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/comparable-0000001054558443)<[Delayed](https://developer.harmonyos.com/cn/docs/documentation/doc-references/delayed-0000001054678608)>  
  
---  
A mix-in style interface for marking objects that should be acted upon after a given delay. 

An implementation of this interface must define a compareTo method that provides an ordering consistent with its getDelay method.

**Since:**

1.5
