# Overview  
  
Contains two types of interfaces: SystemRestore as a public interface used for system restore, and ISystemRestoreProgressListener as an interface used for progress callback. 

[ISystemRestoreProgressListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/isystemrestoreprogresslistener-0000001054200266) Calls back the system restore progress. You must define how to implement this interface. 

[SystemRestore](https://developer.harmonyos.com/cn/docs/documentation/doc-references/systemrestore-0000001054678994) Contains interfaces related to system restore, for example, restoring factory settings, clearing the cache partition, and installing and verifying an OTA upgrade package.
