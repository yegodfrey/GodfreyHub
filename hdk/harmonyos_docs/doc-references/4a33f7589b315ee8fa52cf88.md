# OpenOption
    
    public interface OpenOption  
  
---  
An object that configures how to open or create a file. 

Objects of this type are used by methods such as [Files#newOutputStream(Path,OpenOption[])](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__newOutputStream-java_nio_file_Path-java_nio_file_OpenOption___-), [Files#newByteChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/files-0000001054678506#ZH-CN_TOPIC_0000001054678506__newByteChannel-java_nio_file_Path-java_util_Set-java_nio_file_attribute_FileAttribute___-), [FileChannel.open](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filechannel-0000001054199764#ZH-CN_TOPIC_0000001054199764__open-java_nio_file_Path-java_util_Set-java_nio_file_attribute_FileAttribute___-), and [AsynchronousFileChannel.open](https://developer.harmonyos.com/cn/docs/documentation/doc-references/asynchronousfilechannel-0000001054838444#ZH-CN_TOPIC_0000001054838444__open-java_nio_file_Path-java_util_Set-java_util_concurrent_ExecutorService-java_nio_file_attribute_FileAttribute___-) when opening or creating a file. 

The [StandardOpenOption](https://developer.harmonyos.com/cn/docs/documentation/doc-references/standardopenoption-0000001054558509) enumeration type defines the _standard_ options.
