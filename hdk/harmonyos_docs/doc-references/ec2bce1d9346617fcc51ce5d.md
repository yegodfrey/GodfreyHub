# Overview  
  
Provides an accessibility service development framework for you to develop your own accessibility applications. 

To develop an accessibility application, you must create an accessibility service that inherits the [AccessibleAbility](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663) class. This class provides the following basic accessibility service capabilities: 

    * Setting up a service connection using [AccessibleAbility.onAbilityConnected()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__onAbilityConnected--)
    * Handling service interrupts using [AccessibleAbility.onInterrupt()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__onInterrupt--)
    * Handling accessibility events using [AccessibleAbility.onAccessibilityEvent(ohos.accessibility.AccessibilityEventInfo)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__onAccessibilityEvent-ohos_accessibility_AccessibilityEventInfo-)
    * Handling key events using [AccessibleAbility.onKeyPressEvent(ohos.multimodalinput.event.KeyEvent)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__onKeyPressEvent-ohos_multimodalinput_event_KeyEvent-)
    * Searching for the root node of the current window using [AccessibleAbility.getRootAccessibilityInfo()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__getRootAccessibilityInfo--)
    * Obtaining information about the current window using [AccessibleAbility.getWindows()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__getWindows--)
    * Searching for the currently selected node using [AccessibleAbility.gainFocus(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__gainFocus-int-)
    * Performing a global action using [AccessibleAbility.performCommonAction(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__performCommonAction-int-),
    * Disabling the accessibility service using [AccessibleAbility.disableAbility()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__disableAbility--)

Using the methods provided in this package, you can perform the following operations: 

    * Call the [AccessibleAbility.getSoftKeyBoardController()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__getSoftKeyBoardController--) method to obtain the [SoftKeyBoardController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/softkeyboardcontroller-0000001054199968) object for controlling the show/hide mode of the soft keyboard.
    * Inherit the [SoftKeyBoardListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/softkeyboardlistener-0000001054678694) method to listen for changes of the soft keyboard's show/hide mode and implement some customized operations.
    * Call the [AccessibleAbility.getDisplayResizeController()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__getDisplayResizeController--) method to obtain the [DisplayResizeController](https://developer.harmonyos.com/cn/docs/documentation/doc-references/displayresizecontroller-0000001054838648) object for controlling the display resizing and obtaining the resizing scale of the display resizing rectangle.
    * Inherit the [DisplayResizeListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/displayresizelistener-0000001054518706) method to listen for the display resizing operations and implement some customized operations.
    * Override the [AccessibleAbility.onGesture(int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__onGesture-int-) method to listen for the current gesture and implement some customized logics.
    * Call the [AccessibleAbility.gestureSimulate(java.util.List, ohos.accessibility.ability.GestureResultListener)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/accessibleability-0000001054678663#ZH-CN_TOPIC_0000001054678663__gestureSimulate-java_util_List-ohos_accessibility_ability_GestureResultListener-) method to define a user gesture by simply passing the start position of this gesture path and the duration in which this gesture path continues.
    * Use the [GestureResultListener](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gestureresultlistener-0000001054119952) method to listen for whether the gesture is successfully defined and implement some customized operations.
