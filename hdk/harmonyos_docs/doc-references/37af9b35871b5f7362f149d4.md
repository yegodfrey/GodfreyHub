# Overview  
  
Provides functions for processing solid XML files. 

For example, you can obtain nodes and their attributes from a solid XML file.

**Since:**

1

#### Class Summary

Class | Description  
---|---  
[Attribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attribute-0000001054358865) | Describes an attribute of a node in a solid XML document.  
[Node](https://developer.harmonyos.com/cn/docs/documentation/doc-references/node-0000001054558887) | Describes a node in a solid XML document.  
[Pattern](https://developer.harmonyos.com/cn/docs/documentation/doc-references/pattern-0000001054238885) | Provides resource attributes for a specific pattern.  
[SolidXml](https://developer.harmonyos.com/cn/docs/documentation/doc-references/solidxml-0000001054678855) | Describes a solid XML document, a type of compressed XML documents.  
[Theme](https://developer.harmonyos.com/cn/docs/documentation/doc-references/theme-0000001054838840) | Provides resource attributes for a specific theme.  
[TypedAttribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typedattribute-0000001054358874) | Represents a wrapper class for [Attribute](https://developer.harmonyos.com/cn/docs/documentation/doc-references/attribute-0000001054358865) and dereferences an XML attribute value.  
[TypedAttribute.AttrData](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typedattribute_attrdata-0000001060519187) | Defines attribute data, including the name, value, and type of the attribute represented by TypedAttribute.
