XMLEventAllocator  
      
    public interface XMLEventAllocator  
  
---  
This interface defines a class that allows a user to register a way to allocate events given an XMLStreamReader. An implementation is not required to use the XMLEventFactory implementation but this is recommended. The XMLEventAllocator can be set on an XMLInputFactory using the property "javax.xml.stream.allocator"**Since:** 1.6**See Also:** [XMLInputFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlinputfactory-0000001054120223)Method Summary Modifier and Type | Method | Description
