# FileOutputStream  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---[java.io.OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403) |---|---java.io.FileOutputStream
    
    public class FileOutputStream
    extends [OutputStream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/outputstream-0000001054678403)  
  
---  
A file output stream is an output stream for writing data to a File or to a FileDescriptor. Whether or not a file is available or may be created depends upon the underlying platform. Some platforms, in particular, allow a file to be opened for writing by only one FileOutputStream (or other file-writing object) at a time. In such situations the constructors in this class will fail if the file involved is already open. 

FileOutputStream is meant for writing streams of raw bytes such as image data. For writing streams of characters, consider using FileWriter.

#### [h2]FileOutputStream

public FileOutputStream​([FileDescriptor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filedescriptor-0000001054119688) fdObj)

Creates a file output stream to write to the specified file descriptor, which represents an existing connection to an actual file in the file system. 

First, if there is a security manager, its checkWrite method is called with the file descriptor fdObj argument as its argument. 

If fdObj is null then a NullPointerException is thrown. 

This constructor does not throw an exception if fdObj is [invalid](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filedescriptor-0000001054119688#ZH-CN_TOPIC_0000001054119688__valid--). However, if the methods are invoked on the resulting stream to attempt I/O on the stream, an IOException is thrown.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
fdObj  |  the file descriptor to be opened for writing  
  
**Throws:**

Throw Name | Throw Description  
---|---  
[SecurityException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/securityexception-0000001054678454) |  if a security manager exists and its checkWrite method denies write access to the file descriptor

#### [h2]getChannel

public [FileChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filechannel-0000001054199764) getChannel​()

Returns the unique [FileChannel](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filechannel-0000001054199764) object associated with this file output stream. 

The initial [position](https://developer.harmonyos.com/cn/docs/documentation/doc-references/filechannel-0000001054199764#ZH-CN_TOPIC_0000001054199764__position--) of the returned channel will be equal to the number of bytes written to the file so far unless this stream is in append mode, in which case it will be equal to the size of the file. Writing bytes to this stream will increment the channel's position accordingly. Changing the channel's position, either explicitly or by writing, will change this stream's file position.

**Returns:**

the file channel associated with this file output stream

**Since:**

1.4
