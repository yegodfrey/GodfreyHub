# LongSummaryStatistics  
  
[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---java.util.LongSummaryStatistics
    
    public class LongSummaryStatistics
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [LongConsumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/longconsumer-0000001054838582), [IntConsumer](https://developer.harmonyos.com/cn/docs/documentation/doc-references/intconsumer-0000001054439913)  
  
---  
A state object for collecting statistics such as count, min, max, sum, and average. 

This class is designed to work with (though does not require) [streams](https://developer.harmonyos.com/cn/docs/documentation/doc-references/overview-0000001054358621). For example, you can compute summary statistics on a stream of longs with: 
    
    LongSummaryStatistics stats = longStream.collect(LongSummaryStatistics::new,
                                                      LongSummaryStatistics::accept,
                                                      LongSummaryStatistics::combine);
     

LongSummaryStatistics can be used as a [Stream.collect(Collector)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656#ZH-CN_TOPIC_0000001054518656__collect-java_util_stream_Collector-) reduction} target for a [stream](https://developer.harmonyos.com/cn/docs/documentation/doc-references/stream-0000001054518656). For example: 
    
    LongSummaryStatistics stats = people.stream()
                                         .collect(Collectors.summarizingLong(Person::getAge));
    

This computes, in a single pass, the count of people, as well as the minimum, maximum, sum, and average of their ages.
