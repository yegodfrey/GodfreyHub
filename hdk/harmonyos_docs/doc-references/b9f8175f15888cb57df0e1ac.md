# IAbilityConnection
    
    public interface IAbilityConnection  
  
---  
Provides callback methods that are called when a remote ability using the Service template is connected or disconnected. 

You must override the methods of this interface to implement your processing logic for the connection and disconnection of an ability using the Service template (Service ability for short).

#### [h2]onAbilityConnectDone

void onAbilityConnectDone​([ElementName](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementname-0000001054200068) element, [IRemoteObject](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iremoteobject-0000001054678970) remote, int resultCode)

Called back after an ability connects to a Service ability. 

This method is called back to receive the connection result after an ability calls the [Ability#connectAbility(Intent, IAbilityConnection)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007#ZH-CN_TOPIC_0000001054120007__connectAbility-ohos_aafwk_content_Intent-ohos_aafwk_ability_IAbilityConnection-) method to connect it to a Service ability.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
element  |  Indicates information about the connected Service ability.  
remote  |  Indicates the remote proxy object of the Service ability.  
resultCode  |  Indicates the connection result code. The value 0 indicates a successful connection, and any other value indicates a connection failure.

#### [h2]onAbilityDisconnectDone

void onAbilityDisconnectDone​([ElementName](https://developer.harmonyos.com/cn/docs/documentation/doc-references/elementname-0000001054200068) element, int resultCode)

Called back after the connected Service ability crashes or is killed. 

This method is called back to receive the disconnection result after the connected Service ability crashes or is killed. If the Service ability exits unexpectedly, all its connections are disconnected, and each ability previously connected to it will call [onAbilityDisconnectDone(ohos.bundle.ElementName,int)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilityconnection-0000001054678678#ZH-CN_TOPIC_0000001054678678__onAbilityDisconnectDone-ohos_bundle_ElementName-int-).

**Parameters:**

Parameter Name | Parameter Description  
---|---  
element  |  Indicates information about the disconnected Service ability.  
resultCode  |  Indicates the disconnection result code.
