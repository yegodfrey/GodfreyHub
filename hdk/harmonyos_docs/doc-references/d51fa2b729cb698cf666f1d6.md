#### [h2]getGenericComponentType

[Type](https://developer.harmonyos.com/cn/docs/documentation/doc-references/type-0000001054558469) getGenericComponentType​()

Returns a Type object representing the component type of this array. This method creates the component type of the array. See the declaration of [ParameterizedType](https://developer.harmonyos.com/cn/docs/documentation/doc-references/parameterizedtype-0000001054358447) for the semantics of the creation process for parameterized types and see [TypeVariable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typevariable-0000001054238467) for the creation process for type variables. 

**Returns:**

a Type object representing the component type of this array

**Throws:**

Throw Name | Throw Description  
---|---  
[TypeNotPresentException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/typenotpresentexception-0000001054558455) |  if the underlying array type's component type refers to a non-existent type declaration  
[MalformedParameterizedTypeException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/malformedparameterizedtypeexception-0000001054358458) |  if the underlying array type's component type refers to a parameterized type that cannot be instantiated for any reason
