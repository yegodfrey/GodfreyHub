# Overview  
  
Provides classes for you to test your OHOS applications. 

OHOS allows you to implement test code to monitor the running status of your OHOS applications. You can control the lifecycle of abilities and simulate input events to test applications.

**Since:**

1

#### Interface Summary

Interface | Description  
---|---  
[IAbilityDelegator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942) | A global test utility interface used for adding [IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958) objects and control lifecycle states of abilities.  
[IAbilityDelegatorArgs](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegatorargs-0000001054439971) | Stores unit testing-related parameters, including the class loader, test case names, and test runner name.  
[IAbilityMonitor](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitymonitor-0000001054199958) | Provides methods for matching monitored [Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ability-0000001054120007) objects that meet specified conditions.  
  
#### Class Summary

Class | Description  
---|---  
[AbilityDelegatorRegistry](https://developer.harmonyos.com/cn/docs/documentation/doc-references/abilitydelegatorregistry-0000001054358665) | A global register used to store the [IAbilityDelegator](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegator-0000001054119942) and [IAbilityDelegatorArgs](https://developer.harmonyos.com/cn/docs/documentation/doc-references/iabilitydelegatorargs-0000001054439971) objects registered during application startup.  
[ShellCmdResult](https://developer.harmonyos.com/cn/docs/documentation/doc-references/shellcmdresult-0000001172398124) | A object that records the result of shell command executes.  
[TestRunner](https://developer.harmonyos.com/cn/docs/documentation/doc-references/testrunner-0000001054238685) | Base class for the test framework.
