# Overview  
  
Provides functions related to the WebView component, 

such as [WebView.load(java.lang.String)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/webview-0000001078480106#ZH-CN_TOPIC_0000001078480106__load-java_lang_String-). This package also provides callbacks to obtain the web page information and control web page redirects. For details, see WebAgent and BrowserAgent. WebConfig in the package is used to provide web-page-related setting options.

**Since:**

5
