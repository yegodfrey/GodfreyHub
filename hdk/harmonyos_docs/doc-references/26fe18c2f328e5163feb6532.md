# GltfData
    
    public interface GltfData  
  
---  
Represents the glTF data obtained from a glTF file. 

This class also provides methods for operating the glTF data.

#### Method Detail

#### [h2]isValid

boolean isValid​()

Checks whether the glTF data is valid. If the glTF data is valid, it must be loaded correctly. 

**Returns:**

Returns true if the glTF data is valid; returns false otherwise.

#### [h2]getError

[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460) getError​()

Obtains the error message if an error occurs in obtaining the glTF data. 

**Returns:**

Returns the error message if it is obtained; returns an empty string if the glTF data is valid.

#### [h2]releaseBuffers

void releaseBuffers​()

Releases glTF data buffers. This method is used to release the memory occupied by the glTF data that has been loaded. The released glTF data buffers can be automatically loaded again as needed. 

#### [h2]release

void release​()

Releases the glTF data. The released glTF data can no longer be used. 

#### [h2]getSceneCount

int getSceneCount​()

Obtains the number of scenes where glTF data is imported. 

**Returns:**

Returns the number of scenes where glTF data is imported.

#### [h2]getDefaultSceneIndex

int getDefaultSceneIndex​()

Obtains the default scene index. 

**Returns:**

Returns the default scene index if it is found; returns [INVALID_INDEX](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfdata-0000001054440029#ZH-CN_TOPIC_0000001054440029__INVALID_INDEX) if the default scene is not specified.

#### [h2]getThumbnailCount

int getThumbnailCount​()

Obtains the number of available thumbnails. 

**Returns:**

Returns the number of available thumbnails.

#### [h2]getExternalUris

[List](https://developer.harmonyos.com/cn/docs/documentation/doc-references/list-0000001054119842)<[String](https://developer.harmonyos.com/cn/docs/documentation/doc-references/string-0000001054518460)> getExternalUris​()

Obtains the URIs of the indexes of a parsed glTF file. The URIs are relative to [getBaseUri()](https://developer.harmonyos.com/cn/docs/documentation/doc-references/gltfdata-0000001054440029#ZH-CN_TOPIC_0000001054440029__getBaseUri--). For example, the URI can be the name of an image or .bin file used by the glTF file. 

**Returns:**

Returns the URIs of the indexes of the parsed glTF file.
