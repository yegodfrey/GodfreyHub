# Overview  
  
#### Interface Summary

Interface | Description  
---|---  
[EventFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/eventfilter-0000001054120150) | This interface declares a simple filter interface that one can create to filter XMLEventReaders  
[Location](https://developer.harmonyos.com/cn/docs/documentation/doc-references/location-0000001054440179) | Provides information on the location of an event.  
[StreamFilter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/streamfilter-0000001054200166) | This interface declares a simple filter interface that one can create to filter XMLStreamReaders  
[XMLEventReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmleventreader-0000001054518906) | This is the top level interface for parsing XML Events.  
[XMLEventWriter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmleventwriter-0000001054678894) | This is the top level interface for writing XML documents.  
[XMLReporter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlreporter-0000001054358873) | This interface is used to report non-fatal errors.  
[XMLResolver](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlresolver-0000001054558895) | This interface is used to resolve resources during an XML parse.  
[XMLStreamConstants](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlstreamconstants-0000001054238893) | This interface declares the constants used in this API.  
[XMLStreamReader](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlstreamreader-0000001054678863) | The XMLStreamReader interface allows forward, read-only access to XML.  
[XMLStreamWriter](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlstreamwriter-0000001054838848) | The XMLStreamWriter interface specifies how to write XML.  
  
#### Class Summary

Class | Description  
---|---  
[XMLInputFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlinputfactory-0000001054120223) | Defines an abstract implementation of a factory for getting streams.  
[XMLOutputFactory](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmloutputfactory-0000001054120152) | Defines an abstract implementation of a factory for getting XMLEventWriters and XMLStreamWriters.

Exception | Description  
---|---  
[XMLStreamException](https://developer.harmonyos.com/cn/docs/documentation/doc-references/xmlstreamexception-0000001054200168) | The base exception for unexpected processing errors.

Error | Description
