# PlainIntArray

[java.lang.Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446) |---ohos.utils.PlainIntArray
    
    public class PlainIntArray
    extends [Object](https://developer.harmonyos.com/cn/docs/documentation/doc-references/object-0000001054678446)
    implements [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421)  
  
---  
A basic collection class to store the data structures that use the primitive data type int as the key and value. 

Values in this class are directly stored in arrays, without being wrapped into other types or automatically boxed. This simplifies the data storage structure and saves memory. All keys in this class are sorted in ascending order when they are stored, and the binary search algorithm is used to efficiently search for a specified key. In such data storage structures, keys and values can be iterated over based on indexes. This class implements the [Cloneable](https://developer.harmonyos.com/cn/docs/documentation/doc-references/cloneable-0000001054358421) interface. 

Pay attention to the following when using the PlainIntArray class: 

    * This class is non-thread safe.
    * Values are not stored in the same sequence as they are inserted.

#### [h2]locate

public int locate​(int key)

Searches for the index of a specified key. 

The binary search algorithm is used for searching. If no result is found, a negative value is returned. However, you can invert this negative value to obtain the index where the key should be stored in the array.

**Parameters:**

Parameter Name | Parameter Description  
---|---  
key  |  Indicates the key to search for.  
  
**Returns:**

Returns the index of the key; returns a negative value if no result is found.

public void append​(int key, int value)

Appends a key-value pair to PlainIntArray.
