Provides methods for processing objects of JSON structured data.  Based on the standard JSON data structure, this class encapsulates a series of read and write methods for different data types, for example, primitive data types like int and float as well as some custom data types. It also provides methods for conversion between strings and objects. With these methods, you can process JSON structured data easily. **Since:** 1Constructor Summary Constructor | Description
