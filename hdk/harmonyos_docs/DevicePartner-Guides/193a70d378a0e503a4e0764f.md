# 运行逻辑

先判断当前连接状态是Wi-Fi状态或蓝牙状态，操作步骤如下：

1. App.vue 获取初始化数据

   <br />

   此步骤主要通过 getDevInfoAll 方法获取设备所有服务状态信息，getDevInfoAll 方法中会返回status字段，如果是online则是wifi，offline则是蓝牙

   ```
   initApp() {
       ...
       this.$store.dispatch("getDevInfoAll"); // 获取当前设备的所有服务状态
       ....
   }
   ```

   <br />

2. 通过 online字段进行判断, 在项目文件 src \> store \> actions.js :

   <br />

   ```
   // desc 向云端获取缓存的所有数据
     getDevInfoAll({ commit, dispatch }) {
       return new Promise((resolve, reject) => {
         ...
         window.Ag.getDevCacheAllRes = res => {
           let data = JSON.hParse(res);
           console.hLog(new Time().logTime + 'app本地缓存', data);
           commit('commitAppData', {
             devId: data.devId,
             devName: data.devName,
             sn: data.devInfo.sn,
             deviceModel: data.devInfo.model,
             netStatus: data.status,
             role: data.role,
             roomName: data.roomName,
             bleMac: data.devInfo.bleMac,
             online: data.status
           });
         };
        ...
     }
   ```

   <br />
