# 蓝牙开发概述

模板提供通用蓝牙协议解析代码，供合作伙伴参考。对于私有蓝牙协议的合作伙伴，华为提供通用蓝牙解析框架，供合作伙伴快速完成蓝牙适配。蓝牙框架如下图所示。

![](https://media:101783481642872992)

不同设备类型的蓝牙协议要求如下：  

|设备类型|采集数据|蓝牙协议|
|:---|:-----------|:--------------------------------------------------------------------------------------------------------------------|
|血压计|收缩压、舒张压、心率|[BLP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=243125&_ga=1.123872906.1469285867.1479213658)|
|血糖仪|血糖值|[GLP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=248025)|
|体脂秤|体重、体脂率等体成分数据|私有协议|

![](https://media:101783481642916993)  
标准蓝牙协议，参考：<https://www.bluetooth.com/specifications/adopted-specifications>
