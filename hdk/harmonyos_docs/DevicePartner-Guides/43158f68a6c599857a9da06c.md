# 界面交互开发

#### 界面布局

请参阅[UI控件库](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/JS控件使用示例/通用配置)，将所需组件引入entry/src/main/js/dashboard/index/index.hml中，完成对界面的布局。以引入TitleBar为例：

```
<element name='titleBar' src='../../../share/common/components/titleBar/TitleBar'></element>
<!--Import any component here if you would like to use it in dashboard-->

<div>
...
    <titlebar
        config='{{ titlesBarConfig }}'
        show-obj='{{ isFullScreen }}'>
    </titlebar>
</div>
```

控件库包含以下类型的控件：

* 实时状态组件：
  * 实时状态组件的设计指南与样式，请参阅[实时状态](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-5-0000001209981469)。
  * 组件库中对应提供的实时状态组件为\<deviceStatusCard\>，并已集成至模板中，请按照readme中的指导，增加对应的状态组，并将状态组分配至实时状态组件中，以在不同状态间进行展示与切换。
  * 模板代码中已提供的对应组件，请参阅[JS控件使用示例-实时状态](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/JS控件使用示例/实时状态#DeviceStatusCard)。
* 信息展示组件：
  * 信息展示组件的设计指南与样式，请参阅[信息展示](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-7-0000001164740126)。
  * 信息展示组件不是必选组件，如您的UX设计中没有包含信息展示组件，可以略过此部分。
  * 组件库中提供了设备信息组件\<infomationPanel\>，请参阅[JS控件使用示例-设备信息](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/JS控件使用示例/设备展示和设备信息#设备信息-InformationPanel)。
* 功能控制组件：
  * 功能控制组件的设计指南与样式，请参阅[功能控制](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-6-0000001209821519)。
* 模板代码中已提供的对应组件，请参阅[JS控件使用示例-功能控制](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/JS控件使用示例/功能控制)。  

#### 绑定状态

对于大部分设备控制组件，您需要绑定启用、禁用状态，可以在该组件外边嵌套一层基础容器，然后通过disable字段实现组件的启用、禁用状态切换，例如：

```
...
<div disabled="toggleSwitchEnable" >
   <toggleSwitch></toggleSwitch>
</div>
...
```

index.js中相关代码：

```
export default{
    data:{
        toggleSwitchEnable:true
    }
}
```

如果在index.js中修改了toggleSwitchEnable的值，toggleSwitch的启用状态也将自动更改。  

#### 处理组件事件

子组件可以通过绑定的事件向上传递事件，例如：

```
<toggleSwitch
    config='{{ toggleSwitchConfig }}'
    data='{{ toggleSwitchData }}'
    @on-change='onToggleSwitchClicked'>
</toggleSwitch>
```

index.js中相关代码：

```
import ToggleSwitchParam from '../../../share/common/components/toggleSwitch/ToggleSwitchParams';
...
export default {
  data: {
    toggleSwitchConfig: undefined,
    toggleSwitchData: undefined,
  },
 onInit() {
	initToggleSwitch();
  },
 initToggleSwitch() {
    this.toggleSwitchConfig = ToggleSwitchParam.getToggleSwitchConfig(
      {
        title: 'Toggle Switch',
        subTitle: 'SubTitle',
        initialState: false
      }
    );
    this.toggleSwitchData = ToggleSwitchParam.getToggleSwitchData({
      defaultState: false,
    });
  },
  // 开关状态事件处理
  onToggleSwitchClicked(changeEvent) {
    console.debug(JS_TAG + 'onToggleSwitchClick ToggleSwitchState = ' + changeEvent.detail.value);
  },
  // 手动修改显示内容
  changeToggleSwitch() {
    this.toggleSwitchData = ToggleSwitchParam.getToggleSwitchData({
      defaultState: false,
    });
  },
}
```

子组件状态变化之后会通过绑定的事件调用onToggleSwitchClicked方法，进而对子组件上报事件进行处理。关于该部分的详细内容，请参阅[JS控件使用示例-通用配置](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/JS控件使用示例/通用配置)。
