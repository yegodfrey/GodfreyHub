# 可靠性规范

本章节主要适用于鸿蒙智联生态设备可靠性规范，用于定义设备连接、运行、设备可靠性规范。

#### 设备控制成功率

鸿蒙智联采用鸿蒙推荐模组控制成功率需要达到99.9%，测试次数需要满足 1000次。

#### 连接稳定性

  * 测试设备添加注册到云端后，保持连接状态，通过智慧生活App进行设备操作，每台每5分钟操作一次，设备响应正确才算成功，操作成功率≥99.9%。
  * 设备持续运行期间，统计设备的重启、断连等异常次数，满足以下条件：20台样机，7*24小时，在挂机周期内业务中断≤1台次（断连1分钟内能自动回连）。



#### 回连可靠性

  1. 路由器断网（与光猫连接断开）恢复正常后，设备能自动回连，测试不低于20台次，回连成功率100%。
  2. 路由器重启后，设备能自动回连，测试不低于20台次，回连成功率100%。
  3. 更换新路由，路由SSID与密码保持不变，设备能自动连接，测试不低于20台次，回连成功率100%。



#### 升级可靠性

  1. 升级测试设备一次性升级成功率，测试200次*5台，成功率99%。
  2. 升级失败后可以自动重启或自动恢复并可再次升级；不能有无法自动恢复的问题（如死机、业务异常等）。



#### 支持异常可恢复

  * BLE设备异常后，设备须支持通过软件组件、设备重启等授权自恢复能力，设备检测到异常后能通过自恢复手段支持主控侧（网关、手机、平板）与BLE子设备建立连接。
  * BLE Mesh设备遵循协议规范与BLE Mesh 网关建立心跳连接，如果心跳异常则BLE Mesh 子设备支持通过软件组件、设备重启等手段完成设备连接恢复，恢复后与网关建立BLE Mesh 心跳连接；
  * Wi-Fi 设备在网络异常下支持一直尝试重连路由器，如果多次重连失败则支持重启等方式完成恢复连接；设备未上线时，区分第一次配网和回连，根据历史表优先并着重尝试上次优选并连接的AP，设备已上线后，能够根据业务感知和主路由建议，自主切换最优AP；
  * PLC 设备需要遵循设备永远在线，如果设备侧连接异常则PLC 子设备通过自恢复手段完成与主机连接。



鸿蒙智联生态设备死机导致重启< 0.2次/千小时。

#### 设备闲时静默要求

设备闲时（无业务触发场景）除常连接所需要的心跳交互以及告警信息之外，建议减少不必要的信令交互，减轻智能网络负载。
