# OTA升级

## Device Partner平台是否支持固件升级

支持，具体操作请参考[OTA升级](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ota-upgrade-0000001113552170)。

## OTA升级时，对于固件包大小有限制吗

上传的固件包不能超过25MB。除此之外，还需要满足固件包模板要求和命名要求。详见[OTA升级操作-基本信息配置说明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ota-upgrade-0000001113552170#ZH-CN_TOPIC_0000001113552170__table32975614186)。

## OTA升级时，选择启用"循环升级"会有什么效果

如果固件测试版本启用"循环升级"功能，则设备在升级到最新版本后，还可以继续检测到最新版本，并执行升级操作。详见[OTA升级操作-基本信息配置说明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ota-upgrade-0000001113552170#ZH-CN_TOPIC_0000001113552170__table32975614186)。

## 产品存在MCU时，如何进行OTA升级

MCU与模组的OTA升级类似，在Device Partner平台上传固件包时，根据实际情况选择"产品是否存在MCU"、"固件类型"等，详见[OTA升级操作](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ota-upgrade-0000001113552170#section20747151013316)。

## 模组固件和MCU固件均需进行OTA升级，应该如何操作？

模组和MCU需要分两次上传和发布固件包。当前版本的产品中最多支持同时保有两个固件版本：一个模组固件、一个MCU固件。

## 平台对于OTA固件包是否有格式要求

* 如果采用华为OTA，则必须按照平台界面中要求上传固件包。
* 如果采用开发者自有OTA，平台仅归档伙伴创建的固件版本信息，不提供固件包的测试与发布服务，所以对开发者自有OTA的固件包没有具体的格式要求。

## 在智慧生活App中OTA升级失败，设备侧日志显示update progress [1000]

**问题描述**

在智慧生活App对设备执行固件升级操作，显示升级失败，设备日志打印update progress [1000] 。

**可能原因**

当前设备接入的网络状态不佳或网络受限。

**解决措施**

确保设备接入稳定可用的网络。

## 当设备包含MCU时，设备开发过程中的软件版本号该如何配置

当设备带有MCU时，智慧生活App显示中的固件版本号格式应为"*模组固件版本号* (*MCU版本号*)"，例如v1.1.0(R-1.0)。

设备开发过程中，在代码中配置的软件版本号、以及Device Partner平台填写的软件版本号，均需要按照上述格式配置、并确保取值一致，否则将无法通过认证。

## 设备固件需要支持通过FA进行OTA升级，对于FA侧的OTA升级入口呈现有什么要求

OTA升级功能需要满足如下条件：

1. 在FA界面上可以查看当前设备固件版本信息。


2. 在FA界面上操作，可以触发设备固件OTA升级到新的设备固件版本。


3. 在固件版本升级后，通过FA界面可以查看固件版本信息变更为新版本。

具体的OTA升级入口由伙伴自行实现，常见的实现方式举例如下：

* 可以提供一个OTA查询按钮。单击查询按钮，检查是否存在新版本设备固件，并提示用户升级。
* 可以主动在FA界面上显示出有新版本设备固件，让用户选择是否升级。

## 固件部署后，检测不到新版本

**问题现象**

在Device Partner 平台部署固件或MCU新版本后，智慧生活App无法检测到新版本，OTA升级提示"已是最新版本"。

**可能原因**

1. 平台部署的OTA版本与设备当前版本相同，未触发升级提示。
2. 测试环境问题导致OTA检测失败。
3. DNS解析失败，无法连接OTA 服务器。
4. 网络不通畅导致版本检测超时。
5. OTA同步未完成，平台配置未生效。

**解决措施**

1. 检查DNS解析日志。

   查看设备日志中是否出现DNS解析失败：

   ```screen
   LD_WARN:hilink_m2m.c:891, DNS resolve failed!
   LD_INFO:hilink_m2m.c:868, dns timeout
   ```

2. 确认平台版本配置。

   1. 登录Device Partner平台。

   2. 进入"产品开发 > 固件管理"。

   3. 查看已部署的固件版本。

   4. 确认版本状态为"已发布"

   5. 对比设备当前版本与平台版本

3. 检查网络连通性。

   验证设备网络是否正常：

   LD_ERR:hilink_udp_adapter.c:405, getaddrinfo error: -300

   LD_ERR:hilink_http.c:424, gethostbyname failed

4. 检查与OTA服务器是否建立连接成功。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/7jSmqjtzSau_Fp-WTivUBQ/zh-cn_image_0000002594064558.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=63BFB9403A96CF80B69AAC0CEB179372092388A2DD5FC3FA328B9764BD733BA3)堆栈空间不足导致tls失败。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/N-GrBJ99Q2unhWZilTLJIQ/zh-cn_image_0000002594224484.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=16C300BACCE953E695F497D823DF47A20E7E9EEC2C23E611BCC8FB917345A11D)在mbedtls_config.h文件中将MBEDTLS_SSL_IN_CONTENT_LEN大小改为8K。

## 固件升级完成，固件版本未改变

**问题现象**

智慧生活App显示固件或MCU升级成功，但通过H5页面或设备信息查看时，实际固件版本并未改变，仍为旧版本。

**可能原因**

* 设备部署OTA升级包错误，部署的升级包同设备当前系统一致。
* 设备下载完成OTA升级包后，未实际进行OTA升级。
* 设备下载完成OTA升级，但设备实际进行OTA升级失败。

**解决措施**

* 在OTA升级过程中，鸿蒙智联SDK负责下载和校验，不进行实际的设备升级功能，此能力需模组或MCU侧实现。
* 修改代码版本号，本地设备重新刷机，并再次进行升级验证。
* 如升级成功后版本号未更新，则需伙伴检查设备是否有进行实际的升级操作，或实际的升级过程是否正常。
* 如升级成功后版本号已更新，则伙伴部署的版本同设备之前的版本相同。

## 智慧生活App中的固件版本号"不带括弧"与"带括弧"，有什么差异

智慧生活App中的固件版本号后面"不带括弧"与"带括弧"，分别代表了设备"不含MCU"与"包含MCU"两种情况：

* 当设备不含MCU时，软件版本号与模组固件版本号一致。例如，固件版本号是v1.1.0，则智慧生活App中显示的软件版本号为v1.1.0。
* 当设备包含MCU时，软件版本号的格式为"*模组固件版本号* (*MCU版本号*)"。例如，固件版本号是v1.1.0，MCU版本号是R-1.0，则智慧生活App中显示的软件版本号为v1.1.0(R-1.0)。

## 智慧生活App上已添加的设备搜索不到OTA升级包

**问题现象**

在Device Partner平台上传了设备的OTA固件包且测试版本已发布成功，但智慧生活App上已添加的设备搜索不到升级包。

**可能原因**

* 原因一：设备使用鸿蒙智联SDK的OTA能力，但在Device Partner平台新增OTA固件时选用了"自有OTA"。
* 原因二：上传的OTA固件包格式错误。
* 原因三：待升级设备的SN未添加到"测试设备SN列表"下的设备SN组中。
* 原因四：测试固件版本超过90天期限。

**解决措施**

登录[Device Partner平台](https://devicepartner.huawei.com/cn/)，进入"管理中心"，并执行如下操作：

1. 在新增OTA固件时选择"华为OTA"。
   1. 选择"产品开发 > 集成开发 > 固件检查与帮助"，在"HiLink SDK版本检查"中选择当前使用的HiLink SDK版本号。
   2. 选择"OTA升级 > 新增固件版本"，在"基本信息"OTA方式选择中勾选"华为OTA"。
2. 确保上传的OTA固件包格式正确。
   1. 在"OTA升级 > 新增固件版本 > 基本信息"中，固件上传下方点击"下载固件包模板"。
   2. 参考固件包模板生成OTA固件包并上传。
3. 将待升级设备的SN添加到"测试设备SN列表"下的设备SN组中。
   1. 选择"OTA升级 > 设备SN管理 > 添加设备SN组"，在"设备SN号"输入框中填写待升级设备SN，填写完成后点击"确定"。
   2. 在"新增固件版本 > 基本信息"中，按页面提示填写需要发布的OTA固件信息。
   3. 在"新增固件版本 > 编辑固件"中，勾选包含待升级设备SN的设备SN组，再点击"确定"。
   4. 在新增的固件版本中，点击"测试发布"，等待OTA固件发布完成。
4. 测试固件只在OTA服务器保存90天。如果超期了，在Device Partner平台删除过期的固件版本，重新上传OTA固件包且发布成功。

## 固件升级失败

可以检测到版本，点击升级页面显示升级失败，导致此问题的原因比较多，请按照下列章节排查。

**可能原因一**

在服务器上部署的OTA固件包大于设备的flash空间，设备无法完成固件更新。

**解决措施**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/ngJGt8AkSfKSg3XEVLruJw/zh-cn_image_0000002624624111.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=17BE9C429258521EA3AAA2E76D0D72D94CEE5B11652F551CD4EC6D210CC9FC27 "点击放大")

**解决方案**

* 优化Flash分区配置，重新规划Flash分区。
* 压缩固件体积，优化固件以减少Flash占用。
* 优化日志和配置存储，减少非固件数据占用。

**可能原因二**

HILINK_NotifyOtaData接口未正确适配。

**解决措施**

对应日志打印：

```screen
LD_ERR:hilink_ota_update_process.c:163, notify ota data failed
```

**解决方案**

正确实现 HILINK_NotifyOtaData 接口，确保接口实现符合规范。
