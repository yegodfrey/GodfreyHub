# 账号授权

## 调用账号SDK接口getSignInIntent()时返回错误码，如何处理

调用账号SDK接口getSignInIntent()时，返回错误码（例如6003、907135702、907135000），请参考[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/error-code-0000001050045846)。

## 华为账号授权页面不显示伙伴logo

**问题现象**

华为账号授权页面伙伴logo显示空白。

**可能原因**

华为开发者联盟平台的应用信息中没有上传应用图标。

**解决措施**

1. 登录[华为开发者联盟平台](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)。
2. 单击"我的项目"，单击应用所在项目。
3. 在上侧Tab栏中选择HarmonyOS应用。
4. 单击上侧Tab栏选择"我的应用"，在"应用信息"按照要求添加应用图标。
5. 完善应用信息后，提交审核即可。

## 开发配网FA的华为账号登录功能时，调用signIn接口报错

**问题现象**

开发配网FA的华为账号登录功能时，调用signIn接口，返回err，{"status":"FAILED","resultCode":"-1","data":"null"}。Log日志错误信息如下：

```screen
app Log:  jsBridge log: json parse failed,interface is not exists or register.
```

**可能原因**

使用signIn接口时HmsBridge未全局注册。

**解决措施**

1. 在"entry\build.gradle"文件中添加依赖包。

   ```screen
   dependencies {
     implementation 'com.huawei.hms:jsb-ohos-adapter:5.3.0.303'
   }
   ```


2. 在MyApplication.java中注册HmsBridge。

   ```screen
   public void onInitialize(){
     HmsBridge.getInstance().initBridge(this);
     super.onInitialize();
   }
   ```

## 运动健康health kit权限已申请，应用依然获取不到相关数据

**问题现象**

已申请health kit心率数据的权限，但是FA无法获取到心率数据。

**可能原因**

* 原因一：提交的读取心率数据的权限申请，未通过审批。


* 原因二：FA工程代码的权限文件中未配置该权限URL。

**解决措施**

1. 确认提交的权限申请已通过审核。 Health Kit申请表格中的权限不应超过5个。如果超过5个，需要提供每个权限的详细用途。详见**[申请Health Kit服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/apply-kitservice-0000001050071707)。**

2. 确认代码工程中entry目录的"config.js"文件，已配置相应权限URL。详见**[Health Kit权限列表](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/scope-list-0000001055419280)** 。

   ```screen
   // 心率的kit权限是https://www.huawei.com/healthkit/heartrate.read
   scopeList: [
   "https://www.huawei.com/healthkit/heartrate.read"
   ]
   ```

## 在账号登录FA界面单击"华为账号快捷登录"，没有响应

**问题现象**

在账号登录FA界面单击"华为账号快捷登录"，没有响应。

**可能原因**

* 原因一：没有在AppGalley Connect网站添加应用指纹证书。
* 原因二："config.json"文件中"metaData"下"customizeData"没有配置appid或者appid配置错误。

**解决措施**

1. 在AppGalley Connect网站[添加应用指纹证书](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/atomic-service-account-authorization-0000001136537752#section1786874213591)。


2. 在"config.json"文件中配置appid即为Client ID。

   ```screen
   "metaData": {
   "customizeData": [  
     {"name": "com.huawei.hms.client.appid",
      "value": "*********"
      }
   ]},
   ```

## 账号登录FA页面请求手机号，调用http请求失败

**问题现象**

在华为账号登录的FA页面，点击"登录"后无响应。控制台的日志报错信息为"java.lang.SecurityException:Permission deneied (missing INTERNET permission?) "。

**可能原因**

* 原因一：未配置访问手机网络的权限。
* 原因二：双连场景下，未申请获取手机号的权限。

**解决措施**

1. 确认"config.json"文件中没有配置访问手机网络的权限。可参考以下示例添加权限：

   ```screen
   "reqPermissions": [
      {
        "name": "ohos.permission.INTERNET"
      }
   ]
   ```


2. （仅双连场景涉及）确认已申请到获取手机号的权限。 如果不具备该权限，需要联系华为技术支持人员进行申请，并提供原子化服务的App ID、App名称、发布区域、用户规模、预估的调用量（次/分钟）信息。
