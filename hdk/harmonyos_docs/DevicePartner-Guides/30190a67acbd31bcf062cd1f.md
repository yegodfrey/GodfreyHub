# 服务拓展

服务扩展控件主要用于放置设备的服务，如玩法、食谱、场景等。服务扩展控件一般按照使用频率和重要级别排序，合作伙伴也可根据业务需求进行自由排序。  

#### 类型1：网格类场景

图片：场景图片，合作伙伴可以自定义

主标题：场景的名称

副标题：场景的辅助说明

布局为一排两个，点击后开启此场景。食谱类点击后可跳转食谱详情页。

![](https://media:101783481625268758 "点击放大")

样式标注

![](https://media:101783481625313759 "点击放大")

* 图⽚：⼤⼩160x92vp，圆⻆10vp。
* 主标题⽂字⼤⼩：14sp，#000000，90%不透明度。
* 副标题⽂字⼤⼩：12sp，#000000，60%不透明度。
* 左标签文字大小：10sp，#FFFFFF；背板色：#61CFBE；左上、右下圆角弧度10vp。
* 右标签文字大小：10sp，#FFFFFF；背板色：#00000040%不透明度；圆角弧度4vp。
* 布局：⼀排两个

深色模式

![](https://media:101783481625357760 "点击放大")

* 主标题文本颜色：#FFFFFF 86%不透明度
* 副标题文本颜色：#FFFFFF 60%不透明度

<br />

界面用语超长处理

* 子标题文本支持换一行；主文本支持换一行；副文本支持换一行。

![](https://media:101783481625408761 "点击放大")

* 依然超长，"..."截断处理。

![](https://media:101783481625457762 "点击放大")  

#### 类型2：列表类场景

图片：玩法的图片，合作伙伴可自定义。

主标题：玩法的名称。

副标题：玩法的辅助说明。

执行按钮：点击"开启"立即执行此场景，有音乐的场景下图标变成动效图标；点击其他场景，立即中止执行此场景。

![](https://media:101783481625503763 "点击放大")

样式标注

![](https://media:101783481625551764 "点击放大")

* 图⽚⼤⼩：90x50vp，圆⻆10vp
* 主标题⽂字⼤⼩：16sp，#000000，90%不透明度
* 副标题⽂字⼤⼩：14sp，#000000，60%不透明度
* 图标⼤⼩：16x16vp，，#000000，60%不透明度
* 按钮⼤⼩：68X28vp
* 按钮⽂字：12sp，#0A59F7
* 按钮背景⾊：#000000 5%不透明度
* 聚焦状态：点击按钮后立即执行此场景，按钮呈现聚焦状态，出现蓝色边框，边框粗细2dp，距离按钮间距2dp，颜色#0A59F7
* 布局：⼀排⼀个

深色模式

![](https://media:101783481625593765 "点击放大")

* 主标题文字：#FFFFFF 86%不透明度
* 副标题文字：#FFFFFF 60%不透明度
* 图标颜色：#FFFFFF 60%不透明度
* 按钮文字：#5291FF
* 按钮背景色：#FFFFFF 10%不透明度
* 聚焦状态：点击按钮后立即执行此场景，按钮呈现聚焦状态，出现蓝色边框，边框粗细2dp，距离按钮间距2dp，颜色#5291FF  

界面用语超长处理

* 子标题文本支持换一行；主文本支持换一行；副文本支持换一行。

![](https://media:101783481625763766 "点击放大")

* 依然超长，"..."截断处理。

![](https://media:101783481625831767 "点击放大")
