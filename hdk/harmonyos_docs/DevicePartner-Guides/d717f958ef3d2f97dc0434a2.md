# 设备授权  
  
采用OpenHarmony系统的HarmonyOS Connect生态产品，在固件开发中的功能调测、生产试制、产品量产过程中，均需要使用设备授权证书。本章节指导合作伙伴为HarmonyOS Connect设备申请对应的授权证书。当前只支持设备软证书（曾用名为“激活码”，以下代称“软证书”）。软证书具有唯一性：一台设备只能预置一个软证书，一个软证书也只能对应一台设备。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142623.83045738973181273263364966273784:50001231000000:2800:5597B9AE3ED7FE0B78046B2C4FFF917C4AFA57D37183D92250D019EB9EF1D480.png)

  * 为了提高生产效率，伙伴应当在固件设计和实现时预留软证书读写接口，以便在设备生产时批量写入软证书。
  * 在设备授权页的“基本信息”中，可以下载ACKey、productKey。在产品集成开发时，需要将这两个秘钥写入固件代码中对应的GetAcKey()、GetProdKey()接口，以便固件能够正确处理软证书。具体实现方式请参考产品方案所配套的《设备集成开发指导》。



#### 软证书生成机制

由于软证书对于设备非常重要，平台采用了非对称加密传输的方式管理证书，以确保只有持有私钥的申请人员才能解密软证书文件。整体流程如下：

  1. 合作伙伴在本地生成私钥和公钥文件，参见准备工作。
  2. 申请软证书时，平台需要合作伙伴提供公钥。
  3. 平台根据申请额数量，生成一批软证书。为了方便处理，平台会把这一批软证书包装为一个txt文件。同时为了提高传输效率，平台还会对txt文件进行压缩生成zip文件。
  4. 平台最后根据伙伴上传的公钥对zip文件进行加密，生成以“.lic”为后缀名的加密文件，并在平台上提供链接给合作伙伴下载。
  5. 合作伙伴下载lic文件后，使用自己本地保存的私钥文件解密出zip文件。最后通过解压zip文件得到txt文件，即可从txt文件中逐一获取到设备软证书。



#### 准备工作

在申请软证书前，需要基于RSA算法生成**私钥** 和**公钥。** 公钥需要在申请软证书时提供给平台，用于平台加密软证书文件；私钥用于合作伙伴解密申请到的软证书文件。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142623.28206368274543557983633194561777:50001231000000:2800:284EF3EAF4D9DEF39CECCA8BC6981A44C1FF9269D177E1BDBD7FF8D159D4E712.png)

  * 私钥是解密软证书文件的唯一凭证，伙伴生成私钥文件后务必妥善保存。私钥丢失将无法解密lic文件，私钥泄露将面临软证书被盗用的风险。
  * 私钥与公钥的生成只需要执行一次，后续在申请软证书的过程中可以重复使用。
  * 平台当前支持密钥长度1024、2048、3072、4096，推荐使用3072或4096。如果用户有历史兼容性原因，仍可使用1024。



  1. 准备一台安装有**OpenSSL** 的PC。Linux系统的PC通常自带OpenSSL，推荐使用。
  2. 在命令行窗口中，执行如下命令，生成私钥。
         
         **openssl genrsa -out rsa_private_key.pem 1024**
         **openssl pkcs8 -topk8 -inform PEM -in rsa_private_key.pem -outform PEM -nocrypt >> privatekey.txt**

命令执行成功后，得到“rsa_private_key.pem”（标准格式）和“privatekey.txt”（pkcs8格式）两个私钥文件。前者用于生成公钥文件；后者用于解密软证书文件。

  3. 继续执行如下命令，生成私钥对应的公钥。
         
         **openssl rsa -in rsa_private_key.pem -pubout -out rsa_public_key.pem**

命令执行成功后，得到“rsa_public_key.pem”文件。用文件编辑器打开该文件，拷贝公钥信息（**不要拷贝第一行和最后一行** ，即“BEGIN PUBLIC KEY”、“END PUBLIC KEY”所在的两行信息），以备后续获取软证书使用。




#### 获取软证书

软证书作为设备凭据，需要依据实际设备数量为产品申请软证书或提升额度。

  1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/  )，单击右上角的“管理中心”。
  2. 在左侧导航栏中，选择“量产管理 > 设备授权”。
  3. 在“软证书（激活码）概览”中，检查软证书额度。

     * 如果剩余额度充足，可以直接申请软证书（激活码）。
     * 如果剩余额度不够，请先提升软证书额度。待满足额度需求后，再申请软证书（激活码）。

软证书的剩余额度= 总额度-已申请。企业实名认证通过后，将获得默认分配的500个软证书额度。

     1. 单击“提升额度”。
     2. 选择“使用阶段”，填写需要新增的软证书数量，并单击“确认”提交申请。

     3. 在“提升额度记录”页签，查看审批状态。

     2. 根据填写申请信息，并单击“确认”，提交申请。

  6. 用配对私钥对下载的lic文件进行解密，从而获取到软证书。支持以下两种方式，推荐采用方式一。

     * **【方式一】：使用平台提供的解密工具**
       1. 准备JAVA运行环境JRE。

          1. 在“设备授权”页面顶部，单击“解密工具”下载链接，获取“解密工具.zip”文件。

     * **【方式二】：自行开发解密工具**
       1. 生成解密工具。

由于lic文件采用的加密算法的是“RSA”，解密时也需采用同样的算法进行处理。

将下面代码编译后生成jar文件（本例假定生成的文件名为“RsaDec.jar”）。
              
              import java.io.ByteArrayInputStream;
              import java.io.ByteArrayOutputStream;
              import java.io.File;
              import java.security.Key;
              import java.security.KeyFactory;
              import java.security.spec.PKCS8EncodedKeySpec;
              
              import javax.crypto.Cipher;
              
              import org.apache.commons.codec.binary.Base64;
              import org.apache.commons.io.FileUtils;
              
              public class RsaDec {
              
                  public static byte[] decrypt(byte[] byteDatas, String privateKeyStr) throws Exception {
                      byte[] keyBytes = Base64.decodeBase64(privateKeyStr);
                      PKCS8EncodedKeySpec pkcs8KeySpec = new PKCS8EncodedKeySpec(keyBytes);
                      KeyFactory keyFactory = KeyFactory.getInstance("RSA");
                      Key privateKey = keyFactory.generatePrivate(pkcs8KeySpec);
                      Cipher cipher = Cipher.getInstance(keyFactory.getAlgorithm());
                      cipher.init(Cipher.DECRYPT_MODE, privateKey);
              
                      ByteArrayOutputStream out = new ByteArrayOutputStream();
                      int inputLen = byteDatas.length;
                      int offSet = 0;
                      byte[] cache;
                      int i = 0;
              
                      while (inputLen - offSet > 0) {
                          if (inputLen - offSet > 128) {
                              cache = cipher.doFinal(byteDatas, offSet, 128);
                          } else {
                              cache = cipher.doFinal(byteDatas, offSet, inputLen - offSet);
                          }
                          out.write(cache, 0, cache.length);
                          i++;
                          offSet = i * 128;
                      }
              
                      byte[] decryptedData = out.toByteArray();
                      out.close();
                      return decryptedData;
                  }
              
                  public static void main(String[] args) {
                      File sourceFile = new File(args[0]);
                      File targetFile = new File(args[1]);
                      File privateKeyFile = new File(args[2]);
              
                      try {
                          String privateKey =
                              FileUtils.readFileToString(privateKeyFile).replaceAll("\\s", "").replaceAll("---+[a-zA-Z]+---+", "");
                          byte[] bytes = decrypt(FileUtils.readFileToByteArray(sourceFile), privateKey);
                          ByteArrayInputStream in = new ByteArrayInputStream(bytes);
                          FileUtils.copyInputStreamToFile(in, targetFile);
                      } catch (Exception e) {
                          e.printStackTrace();
                      }
                  }
              }

       2. 将解密所需的以下三个文件放到同一个本地文件夹（本例中的文件路径为“D:\rsa_dec”），包括：
              
              rsa_dec
                |--RsaDec.jar      // 上一步骤生成的文件
                |--privatekey.txt  // 本地保存的私钥文件
                |--authorized.lic  // 下载的软证书文件

       3. 进入解密文件所在文件夹，并执行命令解密lic文件。

这里假设解密后文件命名为“authorized.zip”，命令中文件名需要替换为实际采用的文件名。
              
              cd /d d:\rsa_dec
              java -cp .;lib\commons-codec-1.11.jar;lib\commons-io-2.6.jar;**RsaDec.jar********RsaDec****authorized.lic _authorized.zip_ privatekey.txt**

       4. 解压“authorized.zip”，获取txt文件，即可查看软证书。
