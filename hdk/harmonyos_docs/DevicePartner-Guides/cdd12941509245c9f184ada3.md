# 智能场景

智能场景是在APP中实现智能家居设备间联动的功能，让不同设备（如门锁、灯、空调、传感器等）自动执行任务，实现"开门即开灯"、"人来灯亮"等个性化、自动化体验，带来便捷、安全和舒适的智能生活。

设备在离线状态下，智能场景卡片状态仍与设备在线时保持一致，正常展示。  
![](https://media:101783481625951769)  
所有单品必须包含智能场景控件。  

#### 双场景推荐样式

对应智能产品推荐场景大于两个以上，最多仅展示两个。

![](https://media:101783481626003770 "点击放大")

标注样式

![](https://media:101783481626063771 "点击放大")

* 内容型子标题文本大小：16sp，颜色#000000，90%不透明度
* 卡片内主标题文本大小：16sp，颜色#000000，90%不透明度
* 卡片内副标题文本大小：12sp，颜色#000000，60%不透明度
* 标题大小：40x40vp、12x24vp（固定图表，不可修改）
* 按钮：大小 56x24vp、背板颜色 #000000，5%不透明度、文字大小 12sp，颜色 #0A59F7
* 卡片背板：大小 146x128vp、颜色 #000000，3%不透明度

<br />

深色模式

![](https://media:101783481626115772 "点击放大")

* 内容型子标题文本大小：16sp，颜色#FFFFFF，86%不透明度
* 卡片内主标题文本大小：16sp，颜色#FFFFFF，86%不透明度
* 卡片内副标题文本大小：12sp，颜色#FFFFFF，60%不透明度
* 按钮：大小 56x24vp、背板颜色 #FFFFFF，5%不透明度、文字大小 12sp，颜色 #5291FF
* 卡片背板：大小 146x128vp、颜色#FFFFFF，3%不透明度
