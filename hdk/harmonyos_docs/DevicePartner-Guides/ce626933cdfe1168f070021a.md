# 云端服务申请（仅部分品类支持）

如果需要支持用户查看某个功能近期的历史记录（比如，显示最近一周的刷牙记录）和统计数据（比如，统计最近一周的用水量），则需要申请云端服务的功能权限。权限申请通过后，才能使用历史记录和统计数据功能。  

#### 支持的品类

* 支持申请历史记录权限的品类： 人体感应、红外探测器、门磁、紧急按钮、燃气探测器、烟感、水浸探测器、场景面板、智能门锁、声光报警器、门铃、净水器、智能插座、智能笔、牙刷、智能水杯、智能枕头、保险箱、跳绳、户外单车、运动小器械、血糖仪、血压计、垃圾处理器、电动自行车、室内单车、电吹风、电动剃须刀、脱毛仪、智能保密柜、智能台灯、冲牙器、温湿度传感器、其他。

<!-- -->

* 支持申请统计数据权限的品类： 空气检测器、新风、空气净化器、直饮水机、智能照明、智能台灯、净水器、万能遥控器、消毒盒、智能插座、温湿度传感器、智能插排、宠物智能喂食器、智能水杯、吸尘器、跑步机、养生壶、保险箱、消毒柜、其他。

#### 操作步骤

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中选择"产品开发"，单击待开发的产品，进入产品开发流程。
3. 选择"交互设计"，单击智慧生活App卡片右上方的"进入开发"，进入"云端服务"配置页面。

   <br />

   ![](https://media:101783481594232308)  
   如果智慧生活App卡片中未包含"云端服务"，表明当前品类不支持云端服务，可以跳过本章节。

   ![](https://media:101783481594261309)

   <br />

4. 单击"添加"，根据[表1](#ZH-CN_TOPIC_0000001087684232__table182411829503)，填写相关信息。

   <br />

   ![](https://media:101783481594283310)  
   关于历史记录权限的限制条件：
   * 当前App界面仅支持显示一个功能点（数据类型非int型）的历史记录，请选择一个核心功能项来申请历史记录权限。
   * 一个功能可能存在多个属性，而线上开发H5方式仅支持显示一个属性的历史记录。如果需要显示多属性，则需采用线下开发H5方式。

   ![](https://media:101783481594317311 "点击放大")  

   |配置项|说明|
   |:-----|:---------------------------------------------------------------------------------------------------|
   |数据权限分类|选择需要申请的权限类型，可以选择"历史记录"或"统计数据"。|
   |功能标识|选择物模型定义中所添加的品类功能、通用功能或自定义功能。|
   |记录时长|* 当"数据权限分类"为"历史记录"时，默认显示为一周，可以选择一个月、三个月或自定义天数 （最多支持180天）。 <!-- --> * 当"数据权限分类"为"统计数据"时，不涉及该参数。|
   |属性|选择功能对应的属性。 * 当"数据权限分类"为"历史记录"时，可以显示所有类型的属性。 * 当"数据权限分类"为"统计数据"时，只能显示"操作权限"为"report"或"get/report"的属性。|
   [表1 配置项说明]

   <br />

5. 单击"确认"提交申请，并联系华为产品经理转审核人员进行审核。
6. 查看审核状态。

   <br />

   当审核状态显示"审核通过"时，表明权限申请成功。  
   ![](https://media:101783481594340312)  
   已申请历史数据/统计数据权限的功能，请勿在"物模型定义"中删除，否则会导致已申请的"云端服务"失效。

   <br />
