# 适配nps和跳转到H5设置页

智选项目需适配NPS需求。由于该功能目前缺乏JSAPI支持，完全依赖App原生标题栏实现，因此H5首页必须使用原生标题栏，不可替换为H5标题栏。

在 src-\>store-\>actions.js 里有写入隐藏标题栏的方法。

```
 hiddenTitle({ commit }, param) {
    const { hiddenTitle } = param;
    return new Promise((resolve, reject) => {
      window.hilink &&
        window.hilink.setTitleVisible(
          !hiddenTitle,
          "Ag.hiddenTitileRes"
        );
      window.Ag.hiddenTitileRes = res => {
        let data = JSON.hParse(res);
        Ag.isError(data)
          ? reject(new Error("hiddenTitile error"))
          : resolve();
      };
    });
  }
```

首页必须使用标题栏，二级页面不使用标题栏，参考src-\>views-\>Home.vue。

```
deactivated() { // 离开home页面隐藏标题栏
    this.$store.dispatch('hiddenTitle', { hiddenTitle: true });
  },
  activated() { // home也不隐藏标题栏
    this.$store.dispatch('hiddenTitle', { hiddenTitle: false });
  }
```

如果设置页是H5自己写的，不跳转到原生的设置页，可通过下面方式实现：

重写标题栏右上角点击方法 jsapi：overrideSettingClick，告诉App点击标题栏右上角的四个点图标，不进入原生设置页。

参考 src -\> views -\> Home.vue created。

```
// 通知app点击导航栏上的四个点按钮，跳转的逻辑由h5来控制: 挂载goSetting方法在window上
    this.$store.dispatch('overrideSettingClick', { isOverride: true });
    window.goSetting = () => {
      this.$router.jumpTo('Settings');
    }
```
