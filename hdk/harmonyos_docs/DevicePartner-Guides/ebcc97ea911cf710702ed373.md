# 术语  
  
  * **HarmonyOS Connect**

HarmonyOS Connect是华为全新推出的智能硬件生态品牌，将原“Works With HUAWEI HiLink”和“Powered by HarmonyOS”品牌进行融合，统一消费者和伙伴的品牌认知。

  * **HUAWEI HiCar**

HUAWEI HiCar是华为提供的人-车-家全场景智慧互联解决方案。

  * **OpenHarmony**

OpenHarmony是开放原子开源基金会旗下的[开源项目](https://gitee.com/openharmony)，定位是一款面向全场景的开源分布式操作系统。华为在2020年9月10日HDC大会上宣布捐赠给开放原子基金会并正式开源。

  * **ProdID**

又称为“产品ID”或“ProductID”，为产品的唯一标识符，是由数字和字母组成的、长度为4位的字符串。

  * **Works With HUAWEI HiLink**

Works With HUAWEI HiLink是华为授予支持HiLink协议规范的生态产品的技术认证标识，现已全面升级为HarmonyOS Connect。

  * **智慧生活**

智慧生活是指华为的智慧生活App，是消费者管理全场景设备的主入口。
