# 准备工作及运行demo

#### 获取开发资料

1. 下载profile

* 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)，单击右上角的"管理中心"。
* 在左侧导航栏中，选择"产品开发"，并选择一款产品、进入开发页面。
* 选择"产品定义 \> 物模型定义"，单击右上角下载Profile文件

![](https://media:101783481641987979 "点击放大")

2. 获取H5 Demo与UX设计规范

* 选择"交互设计"，单击智慧生活App卡片右上方的"进入开发"
* 选择"App开发 \> App设计 \> 线下自开发"，即可下载H5 双连双控Demo、获取UX设计规范

![](https://media:101783481642033980 "点击放大")  

#### 搭建开发环境

本章节以Vue框架开发H5为例，介绍操作步骤。

1. 配置开发环境

* [下载Node.js安装包](https://nodejs.org/zh-cn/download/)，并安装。
* 在VSCode的命令窗口中执行以下命令，安装脚手架工具Cli。

  ```
  npm install -g @vue/cli
  ```

<!-- -->

* 执行以下命令，检查是否安装成功。如果返回版本号，则表示脚手架工具Cli安装成功。

  ```
  vue --version
  ```

#### 运行demo

使用方法

```
# 安装依赖  VSCode在菜单中选择“Terminal > New Terminal”，并执行如下命令加载依赖包
  npm install  
# 运行H5项目
  npm run dev  
# 打包服务  
npm run build
```
