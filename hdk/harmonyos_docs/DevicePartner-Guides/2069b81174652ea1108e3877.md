# 标题栏

标题栏放在界面顶部，用于呈现界面名称和操作入口。

标题栏一般由左侧图标、标题，右侧功能图标组成。标题栏的元素构成分为左右两部分。

![](https://media:101783481613973556 "点击放大")

标题栏是页面的基本控件，具有返回上一级界面、放置其他操作的功能。  

#### 构成

1. 返回图标：点击返回到智慧生活App首页。
2. 更多图标：不常用的功能设置都应用放进"更多"中。
3. 特性图标：可以是玩法、服务信息等，设备合作伙伴可以根据推送内容进行定制，最多两个。

![](https://media:101783481614019557 "点击放大")  

#### 标注样式

浅色模式

![](https://media:101783481614055558 "点击放大")

* 主标题文本大小：20sp，medium。
* 主标题文本颜色：90%不透明；#000000。
* 副标题文本大小：14sp，regular。
* 副标题文本颜色：60%不透明度；#000000。
* 图标大小：40×40vp。
* 图标背板颜色：5%不透明度、#000000；内图形颜色：#000000
* 返回按钮热区大小：40x40vp

深色模式

![](https://media:101783481614093559 "点击放大")

* 主标题文本颜色：86%不透明度；#FFFFFF。
* 副标题文本颜色：60%不透明度；#FFFFFF。
* 图标背板颜色：10%不透明度、#000000；内图形颜色：#FFFFFF  

#### 界面写作规则

* 标题简洁明了。
* 标题和进入该页面的上一级界面的功能选项名称保持一致。
* 无标点，以名词短语为主。
