# 配置必选项

#### 配置资源文件

图1 登录界面   
![](https://media:101783481646181022)  
图2 设备控制界面   
![](https://media:101783481646208023)

详细的页面设计要求可查阅[设计规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-overview-0000001198252447)。

您需要将模板代码中的默认信息，替换为您的产品信息。  
![](https://media:101783481646237024)  
每个图片文件大小建议不超过500KB，总HAP包大小不可超过10M。  

|项目|替换文件/字段|要求|
|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|FA名称|entry/src/main/js/share/i18n/en-US.json和zh-CN.json里custom_FA_name字段|即[创建HarmonyOS应用](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-for-health-kit-0000001126264886#section17341840271)时的应用名称|
|FA icon|entry/src/main/resources/media/icon.png|* 格式：PNG * 尺寸：216\*216px|
|企业名称|entry/src/main/js/share/i18n/zh-CN.json和en-US.json里custom_company_name字段|-|
|企业文字Logo|entry/src/main/js/share/common/img/customised/logo_stripe.png|* 格式：PNG格式，透明背景 * 尺寸：280\*72px * 文件大小：500KB以内 * 图片颜色：#999999|
|企业Logo|entry/src/main/js/share/common/img/customised/logo_full.png|* 格式：PNG格式，透明背景 * 尺寸：368\*368px * 文件大小：500KB以内|
|设备名称|entry/src/main/js/share/i18n/en-US.json和zh-CN.json里resoureces.设备id.device_name字段|即[创建产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-creating-product-0000001172184761)时的产品/设备名称|
|设备展示图|* 文件路径：entry/src/main/js/share/common/img/customised/设备id/device.png * 配置路径：entry/src/main/js/share/i18n/en-US.json和zh-CN.json里resoureces.设备id.device_image字段|* 格式：PNG格式，透明背景 * 尺寸：请参考[图片尺寸要求](#ZH-CN_TOPIC_0000001172144683__fig86225260469)|
|连接失败指导信息|entry/src/main/js/share/i18n/en-US.json和zh-CN.json里resources.设备id.connect_help_items字段： * text_step：提示标题 * text_connect：提示内容 * image_src：提示图 根据设备实际情况决定要添加的连接失败帮助步骤数量。|* 提示图格式：PNG格式，透明背景 * 提示图尺寸：至少为608\*608px|
|菜单数据|entry/src/main/js/share/i18n/en-US.json和zh-CN.json里resources.productId.menu_options字段： * label：名称 * uri：路由page地址 请参阅[JS控件使用示例-页面配置](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/JS控件使用示例/页面配置)|-|
|设置页数据|entry/src/main/js/share/i18n/en-US.json和zh-CN.json里resources.productId.setting_items字段： * label：名称 * rightText：描述 * router : 路由参数 请参阅[JS控件使用示例-页面配置](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/JS控件使用示例/页面配置)|-|
|原子化服务功能的简要描述|entry/src/main/resources/base/element/string.json和en_US/element/string.json里的main_ability_description字段|-|

#### 设置配置文件中的其余字段

模板工程中的配置文件（entry\\src\\main\\js\\share\\common\\config.js）是用于控制帐号授权、系统授权和设备交互流程的，需要根据您的设备和服务自行配置，请参阅[config.js配置指南](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/config.js配置指南)。
