# 配置受限权限

#### 配置APP_ID和APP_SECRET

如果您的项目中涉及到通过华为运动健康服务（Health Kit）读写数据，您还需要配置相关鉴权字段以连接到华为运动健康服务。请确保您在[设置配置文件中的其余字段](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-item-config-0000001172144683#section28554511114)中配置好如下字段：

* clientId
* clientSecret
* redirectUri  

#### 配置Scope权限列表

配置文件（entry\\src\\main\\js\\share\\common\\config.js）中的requireScopeList字段是用来配置申请的Scope权限列表，如您申请了受限权限（Health Kit、用户手机号获取等），请于此处添加您所申请的受限权限的Scope。

例如，您需要获取用户手机号：

```
const data ={
  requireScopeList: [
    "https://www.huawei.com/auth/account/mobile.number"
  ],
  ......
}
```

或者，您需要读取用户身高、体重数据：

```
const data ={
  requireScopeList: [
    "https://www.huawei.com/healthkit/heightweight.read"
  ],
  ......
}
```

同时，由于大部分受限权限还需要用户手动勾选授权，您需要在mandatoryScopeList中，配置必需权限。登录完成后，原子化服务将对必需权限进行检查，如用户不授予必需权限，则无法进行下一步操作。

```
const data ={
  mandatoryScopeList: [
    "https://www.huawei.com/auth/account/base.profile",
    "https://www.huawei.com/healthkit/heightweight.read"
  ], 
  ......
}
```
