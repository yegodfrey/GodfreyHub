# 接入流程

图1 H5方案接入流程   
![](https://media:101783481603045457)  

|序号|步骤|说明|责任方|
|:-------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------|
|1|沟通合作|通过[商务合作联系邮箱](mailto:harmonyosbd@huawei.com)沟通合作意向，签署合作协议后，启动接入流程。|合作伙伴|
|2 <br />|接入准备 <br />|[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)（以下简称"合作伙伴平台"）： 1. [成为合作伙伴](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-dp-pre-0000001239194127#section1143215158455) 2. 产品定义：包括[创建产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-dp-pre-0000001239194127#section85281334204617)和[产品定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-dp-pre-0000001239194127#section116533234620) 3. 交互设计：包括[功能定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-dp-pre-0000001239194127#section260774414376)、[资源配置](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-dp-pre-0000001239194127#section7895815175312)|合作伙伴|
|2 <br />|接入准备 <br />|开发者联盟： 1. [申请帐号服务](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-developer-pre-0000001227542091#section743643018402)：因Health Kit服务需要用到帐号服务的能力，需先申请帐号服务才能申请Health Kit服务。 2. [申请Health Kit服务](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-developer-pre-0000001227542091#section294219555403)：申请Health Kit读写权限。 Health Kit权限申请后审核周期约15个工作日，可同步开发H5。|合作伙伴|
|3|开发准备|[获取开发资源](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-obtain-dev-resource-0000001238364333)：联系华为技术接口人提供UX设计稿、依赖包。|合作伙伴、华为|
|3|开发准备|完成[开发环境搭建](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-environment-0000001225215931)并创建一个Hello World工程来验证环境是否已配置完成。|合作伙伴|
|3|开发准备|[获取模板代码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-obtain-template-code-0000001195771710)。|合作伙伴|
|4|功能开发|1. [工程配置](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-config-0000001238564443) 2. [登录与鉴权](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-account-0000001182012560) 3. 根据设备不同选择方案： * 蓝牙设备：根据[蓝牙设备](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-data-bluetooth-0000001193444984)章节的指导完成开发。 * GPRS设备：根据[GPRS设备](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-data-gprs-0000001238364915)章节的指导完成开发。|合作伙伴|
|5|功能调试|1. [生成资源包](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-resourcezip-0000001182543252)：将开发完成的项目打包生成H5.zip包，上传到合作伙伴平台。在合作伙伴平台下载资源包，用于调测验证。 2. [调测验证](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-local-debug-0000001179417744)：按测试用例完成自验证。 3. 上传检视视频、提交审核。|合作伙伴|
|6|翻译|1. 在合作伙伴平台上[提交翻译字符串](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-translation-0000001239644959#section1498933855112)。 2. 翻译回稿（华为提供）。 3. [更新H5.zip](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-translation-0000001239644959#section112006430517)，重新提交到合作伙伴平台。|合作伙伴、华为|
|7 <br />|认证上线 <br />|1. 完成自动化测试，并提交测试报告。 2. 提交认证申请和样机投递。|合作伙伴|
|7 <br />|认证上线 <br />|审核通过，发放证书。|华为|
|7 <br />|认证上线 <br />|上线运动健康App。|华为|
