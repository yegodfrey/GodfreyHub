# 字体

为了使HarmonyOS设备控制服务在多个设备上运行时保持一致的视觉体验，提升内容的清晰度和阅读的舒适性，建议使用HarmonyOS系统字体。

（自开发H5单品使用系统默认字体，字体不加粗）  

|Scale Category|Size|Font Weight|Case|典型使用场景|
|:-------------|:---|:----------|:-------|:-----------------------|
|H1|30|Medium|Sentence|强调型App bar标题|
|H2|30|Medium|Sentence|带子页签的App bar普通标题|
|H3|24|Medium|Sentence|带子页签的App bar普通标题|
|H4|20|Medium|Sentence|普通App bar标题|
|H5|20|Medium|Sentence|弹出框标题|
|Subtitle1|16|Medium|Sentence|内容区或设置项的分组标题|
|Subtitle2|14|Medium|Sentence|段落文本的分组标题|
|Button1|16|Medium|All caps|内容区的大文本按钮|
|Button2|14|Medium|All caps|列表内的小文本按钮|
|Body 1|16|Regular|Sentence|列表正文/段落文本|
|Body 2|14|Regular|Sentence|列表辅助文本/宫格描述文本/段落文本|
|Body 3|12|Regular|Sentence|功能入口icon说明文本/段落文本|
|Caption|10|Regular|Sentence|toolbar/ tabbar描述文本/内容来源|
|OVERLINE|14|Regular|All caps|强调型标题下的描述|
