# 设计自检表

设计自检表详细列举出了在全场景设备设计和开发过程中应当注意的设计规则，提交审核前请再次检查各项是否符合规则要求，这将帮助应用减少用户舆情、提升用户体验的一致性。  
![](https://media:101783481597865366)  
自检表要求分为"必选"与"推荐"两类。

* 必选：表示已总结出的较优解决方案或效果，相关设计需要按照此原则统一执行。
* 推荐：表示可以根据应用品牌风格或业务特殊性，基于要求做适量修改。  

|类型|条目|说明|要求|
|:---|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-|
|界面选择|卡片|检查卡片的宽度、高度、类别、内容，保证符合规范。 检查卡片的调用和交互逻辑是否合理。|必选|
|界面选择|控制面板|检查控制面板的宽度、高度、内容，保证符合规范。 检查控制面板的调用和交互逻辑是否合理。|必选|
|界面选择|登录弹窗|检查登录弹窗内容是否包含以下必选信息：合作伙伴应用图标、应用名称、FA版本号、登录按钮区、隐私声明。|必选|
|界面选择|设备设置页|检查设备设置页中是否包含以下必选信息：设备名称、设备信息、关于。|必选|
|界面选择|全屏页面|检查全屏页面的页面结构及内容。|必选|
|文字|字号|界面字号是否符合规范，请参考[字体](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-visual-font-0000001198373791)与对应[控件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-1-0000001189262580)章节。|必选|
|文字|文字层级|主副文本是否有字号、字重、颜色差异，请参考[字体](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-visual-font-0000001198373791)与对应[控件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-1-0000001189262580)章节。|必选|
|文字|文字超长处理|涉及具体控件请检查多语言适配是否生效；多语言适配是否影响界面原有布局；多语言处理方式请参照对应[控件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-1-0000001189262580)。|必选|
|色彩|使用规范色板|请使用规范色板进行标注和交付。|必选|
|色彩|控件状态|按键及列表的状态样式是否符合规范，请参考"控件"章节。|必选|
|运营内容|App跳转|不允许跳转到非自有品牌的App页面。|必选|
|运营内容|图像质量|保证图片内容主体突出、真实可信。|必选|
|品牌露出|设备合作伙伴logo|使用大小适中且为非彩色logo。|必选|
|品牌露出|设备图片|HarmonyOS设备展示为正视实拍图，需要有高光和反光，边缘轮廓清晰，PNG格式透明底。|必选|
|控件|标题栏|标题栏样式、字号、多语言显示、布局是否符合控件要求。|必选|
|控件|开关按钮|按钮样式、颜色、宽度、高度是否符合控件规范。|推荐|
|控件|档位选择按钮|交互逻辑、字号、颜色、状态是否符合控件规范。关注"未启用、已启用、离线"三种状态。|推荐|
|控件|温度按钮|按钮样式、颜色、状态是否符合控件规范。温度按钮点击一次调整温度，关注"默认、点击、离线"三种状态。|必选|
|控件|Switch开关|开关样式、颜色、状态是否符合控件规范。具有展开设置项及变形状态下，关注交互逻辑和布局。关注"未启用、已启用、离线"三种状态。|推荐|
|控件|滑杆|滑杆样式、颜色、状态是否符合控件规范。最小值放左边，最大值放右边。关注"未启用、已启用、离线"三种状态。|推荐|
|控件|倒计时组件|调用与定时组件做好区分。组件样式、颜色、点击状态是否符合控件规范。关注"未启用、已启用、离线"三种状态。|必选|
|控件|定时组件|调用与倒计时组件做好区分。组件样式、颜色、点击状态是否符合控件规范。关注"未启用、已启用、离线"三种状态。|必选|
|控件|颜色选择|检查颜色选择组件的交互逻辑。|推荐|
|控件|色温选择|检查色温选择组件的交互逻辑。|推荐|
|控件|信息展示|检查字号、颜色、图标样式是否符合规范。一般按照使用频率和重要级别排序，合作伙伴也可根据业务自由排序。|必选|
|控件|小图标|小图标大小、颜色、线条粗细、圆角处理符合规范。|必选|
