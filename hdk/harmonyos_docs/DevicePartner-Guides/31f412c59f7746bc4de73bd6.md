# 蓝牙靠近发现认证

#### 简介

蓝牙靠近发现是华为开放给HarmonyOS Connect生态合作伙伴的一项核心原子能力，用于提升华为产品与HarmonyOS Connect生态产品的极简快速连接体验。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142624.11700479652289330138155601642575:50001231000000:2800:0496F28C96733ED0AF0272579CE8B4BE26B12BD1BFF64A9DB3EC34E47FCEE8D7.png)

当伙伴提交预约认证申请之后，方可申请蓝牙靠近发现测试。

#### 蓝牙靠近发现送测场景

按照表1 靠近发现送测场景，判断是否需要送测蓝牙靠近发现样机。

  * 如果需要送测，则需自测蓝牙靠近发现并送测靠近发现样机。
  * 如果需要邮件说明变更情况或评估是否需要重新送测，请按如下要求发送邮件。 
    * **收件人：**[huaweiopenlab@huawei.com](mailto:huaweiopenlab@huawei.com)
    * **抄送人：** 认证测试经理及产品的华为技术支持人员（可咨询产品经理）
    * **主题：** 【蓝牙靠近发现认证申请】企业名称+产品名称
    * **邮件内容：** 提供产品ID、以及变更详情或评估材料



**表1** 靠近发现送测场景  送测场景 |  是否需要送测  
---|---  
靠近发现首次认证测试 |  / |  需要送测  
靠近发现升级认证测试 （内部结构发生变更） |  硬件（模组、蓝牙天线布局结构等）变更 |  需要送测  
软件（蓝牙芯片发射功率）变更 |  需要送测  
产品继承性认证测试 |  / |  需要提供该产品与被继承性产品的配置及硬件信息，根据材料评估是否需要送测 **确认满足以下条件：**

  * 原型机产品必须通过华为靠近发现认证测试；
  * 继承性产品与原型机产品不存在蓝牙天线、模组芯片、模组位置变更，且设备结构及材质保持一致。

**填写材料并提交审核：**

  1. 根据产品实际情况完成《[继承性产品的蓝牙靠近发现免认证申请模板.xlsx](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142625.09626172230963594500397326074693:50001231000000:2800:BDA29684A8030C5DBB517C7CBD263381C2B4AE7FCA1697205B5897728C052DDE.xlsx?needInitFileName=true)》的填写。
  2. 上述表格信息填写完成后，由产品经理将相关材料通过邮件方式传递华为靠近发现审核责任人。 
     * 如审核通过，则可以继承原型机认证测试结论，无需送测。
     * 如审核不通过，则会说明不支持继承原型机的原因，需要送测蓝牙靠近发现。

  
  
#### 自测蓝牙靠近发现

  1. 准备华为Mate 40Pro一台作为测试设备。
  2. 请合作伙伴对照《[生态厂商自检checklist_靠近发现.xlsx](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142625.59047270944330105987992831584411:50001231000000:2800:8F1E894EB278646A22DC939B4A3B676AFB1FB22BD22708CC91BCC2DC5B0B48D8.xlsx?needInitFileName=true)》，检查产品软硬件规范及UX逻辑，并记录自检结果。
  3. 如上述自检结果通过，获取《[蓝牙靠近发现KPI自测试报告模板.xlsx](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142625.53101375245164596922921148822991:50001231000000:2800:D5C65F5051C1478BFFB626A3D89B318E2A004BC5B842D5D89E2A65D839942DFD.xlsx?needInitFileName=true)》，用于记录待测设备靠近发现KPI测试结果，并完成自测。
  4. 请使用HW AirLink工具完成蓝牙靠近发现测试，并完成对应自测试报告材料。 

为保证测试结果一致性，将被测产品和手机均放置于非金属支架上，手机与设备处于同一水平线，然后以被测产品为中心，保持手机顶部朝向设备，遍历8个角度测试靠近发现成功率、靠近发现时长、靠近发现最远距离。

#### 使用AirLink工具开展蓝牙靠近发现自测

#### [h2]获取并配置AirLink工具

  1. [获取AirLink工具](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/nfc-tag-generation-0000001208456327#section16493141114151)。
  2. 在手机上安装AirLink工具，并打开工具。
  3. 在AirLink工具界面，点击“ADD”，并输入蓝牙邀请码“c1cbe595”，即可打开BLE靠近发现功能。 

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142624.78169895666116221051331903208510:50001231000000:2800:88FB4BB9B27601F7DFA20F18E3F3AE09F8DEDE08D3FB8CCABCAFE5B0C805FD89.png)

为避免测试过程中周围蓝牙设备信号干扰影响，建议点击“config”![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142624.92947566384982524126245623628831:50001231000000:2800:81A76B5C245CA5C05FB81BC5C8EB175493B00BCB7F71D13BC677216A9FDF231F.png)填写待测设备“Bluetooth Address”（Bluetooth Address英文字母要求大写），以便过滤筛选到对应设备蓝牙广播。




#### [h2]靠近发现成功率测试

  1. 将设备设置为发送靠近发现广播模式（一般需要操作设备按键/菜单将设备配置到可发现广播模式）。
  2. 进入手机AirLink的Succ rate test成功率测试界面。
  3. 选择测试角度方位后，固定手机与设备距离20cm/50cm。
  4. 点击“TEST”开始测试，手机搜索到设备靠近发现广播后显示find，未搜到显示fail，每个角度测试20次，查看Avg Succ Rate动态成功率。 

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142624.96332577050255820048415717620121:50001231000000:2800:8682E62E278B2CE5ABFA80F8AE9BA087D4915ACE85152FD105ECEF2F81493ECE.jpg)




![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142625.30679542397575722203172191894948:50001231000000:2800:53B6A65022861FB75CF9260928BA05CD668475AE1EEE817468E0D059AF1954ED.png)

  * 小设备/便于携带类设备测试时取手机与设备距离20cm点位。
  * 大设备/固定位置使用类设备时取手机与设备距离50cm点位。



#### [h2]靠近发现时长测试

  1. 将设备设置为发送靠近发现广播模式。
  2. 进入手机 AirLink的Scan time test时长测试界面。
  3. 选择测试角度方位后，固定手机与设备距离20cm/50cm。
  4. 点击“TEST”开始测试，手机搜索到设备靠近发现广播后显示find，未搜到显示fail，每个角度测试20次，查看AvgTime平均时长。 

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142625.37318720592868439184908653369642:50001231000000:2800:0249A30E26AFB43D90155AC86ECDF1DC790F9802042B4D7FC55D0D5781BDA5B4.jpg)




#### [h2]靠近发现最远弹框距离测试

  1. 将设备设置为发送靠近发现广播模式。
  2. 进入手机 AirLink的distance test距离测试界面。
  3. 选择测试角度方位后，点击“TEST”开始测试。
  4. 将手机由远及近靠近被测设备，如从100cm/200cm开始靠近，手机出现“find，please input distance”后，输入距离，每个角度测试20次，查看AvgDistance平均最远距离。

#### 送测靠近发现样机

  1. 确认蓝牙靠近发现已满足如下两个条件： 
     * 产品靠近发现checklist已完成自检。
     * 产品靠近发现KPI结果已通过自测。
  2. 按照如下要求，发送自测报告邮件。 

**收件人：** 华为技术支持人员（可咨询产品经理）

**主题：** 【蓝牙靠近发现认证申请】企业名称+产品名称

**附件：** 蓝牙靠近发现KPI自测试报告模板.xlsx、生态厂商自检checklist_靠近发现.xlsx

**邮件内容：**

XXX产品申请送测，产品ID为XXXX，认证测试型号为XXXX

  3. 联系产品经理咨询靠近发现送测地址，并按照如下要求送测样机。 
     * 样机要求投递2台，一台为持续发送靠近发现广播样机，另一台为正常发送靠近发现广播样机。
