# 图标

图标根据不同使用场景，分为系统图标与控制图标两种。

![](https://media:101783481612145540 "点击放大")  

#### 系统图标

图标需遵循化繁为简的原则，避免喧宾夺主而干扰到用户的注意力，同时需遵循相应的比重及数学关系。所有图标的尺寸单位和网格系统均遵循HarmonyOS统一规范，详见[HarmonyOS视觉基础概念](https://developer.harmonyos.com/cn/docs/design/des-guides/basic-0000001055539104)。

![](https://media:101783481612223541 "点击放大")  

#### 控制图标

控制图标位于功能控制区，主要用于对设备的操控和设备功能入口。

![](https://media:101783481612322542 "点击放大")  

#### 图标大小布局

图标设计以24vp为标准尺寸，中央22vp为绘制活动区域，上下左右各留1vp的空隙。图标应在22vp的活动区域内进行绘制。

![](https://media:101783481612368543 "点击放大")  

#### 关键形状

关键线的形状是网格的基础。利用这些核心形状做为向导，即可使整个相关产品的图标保持一致的视觉比例。

#### 圆角规则

图形中的常规圆角大小值为3vp，当图形夹角小于90度时，可根据具体情况将圆角值调整为2vp。
