## HarmonyOS Connect极小硬件方案，靠近发现广播偶尔无法拉起FA

**问题描述**

HarmonyOS Connect极小硬件方案，触发靠近发现广播，偶尔手机没有反应，没有出现靠近发现水波纹。

**可能原因**

靠近发现拉起FA时，有个防骚扰机制，在一次亮屏周期内，手机只会拉起一次FA，除非手机的蓝牙状态发生变化（连接设备成功后又断开）或者广播内容发生变化。

**解决措施**

此为正常情况，手机拉起一次FA后，没有连接设备，直接取消了应用。如果再次拉起FA，可以尝试如下操作：

* 开关一下手机蓝牙开关。
* 锁屏重新亮屏。
* 关闭靠近发现广播（间隔5s）重新触发。

## HarmonyOS Connect极小硬件方案，设备代理注册超过标准5秒

**问题描述**

HarmonyOS Connect极小硬件方案，添加设备代理注册过程超过标准5秒。

**可能原因**

设备侧在代理注册中未回复"authSetup"。

**解决措施**

设备侧在代理注册中，接收到"authCode"后，回复如下消息：

```screen
{"errcode":"0"}
```

## 蓝牙靠近发现弹框有时不出现，如何排查？

原因一：在1分钟内频繁点击弹框上的取消按钮会触发防骚扰机制，就会导致不再触发弹框。

原因二：智慧生活基础服务缓存影响。

原因三：一个亮屏周期内已弹过框。

原因四：手机蓝牙连接状态发生了更改。

原因五：与广播的功率大小，广播发送的频率，周边环境影响等有关。

解决措施：

1.测试弹框成功率时，靠近发现弹框"左边是取消，右边是连接"，不要在1分钟内 频繁点击弹框上的 取消按钮，否则会导致不再触发弹框，建议通过手机侧滑返回，关闭弹框。

2.如果遇到之前可以弹框，后续一直无法触发弹框的情况，可以清理智慧生活基础服务App的缓存，步骤：手机 设置>应用和服务>应用管理>搜 智慧生活基础服务>存储>删除数据）。

3.若一个亮屏周期内若已弹过框，需要手机息屏再亮屏一次，可再次触发弹框。

4.如果手机蓝牙连接状态发生了更改，需要将手机蓝牙关闭后再打开，可再次触发弹框。

5.低概率触发弹框：和设备广播发送的周期有关，广播需要间隔20ms发送一次。

## 智慧生活App添加设备失败，设备侧日志显示"Hardware result is [14002]"

**问题现象**

使用智慧生活App添加设备失败，关键设备侧日志参考如下：

```screen
ERROR [KitFramework]: Read ticket failed
ERROR [KitFramework]: Read ticket failed
......
INFO [KitFramework]: Hardware result is [14002]
INFO [KitFramework]: Symbol authentication succeed
WARN [KitFramework]: Write ticket failed
......
INFO [KitFramework]: Start active symbol
ERROR [KitFramework]: Invalid parameter
ERROR [KitFramework]: Active symbol failed, ret = -1
```

**可能原因**

* 原因一：软证书被使用过，已经失效。
* 原因二：软证书和设备固件中配置的产品信息不匹配。

**解决措施**

1. 从已获取的软证书中重新选择一个软证书，确认其未被使用后，重新写入设备，再进行设备配网。
2. 在平台提交产品信息并重新申请设备软证书。
   1. 登录[Device Partner平台](https://devicepartner.huawei.com/cn/)，进入"管理中心"。
   2. 在"产品开发 > 产品定义 > 软硬件定义"页面，单击"编辑"后，再单击"提交"重新触发产品信息同步。
   3. 重新[申请设备软证书](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/device-authorization-0000001134626077)并写入设备。

## IOS版智慧生活App在产品开发阶段创建场景时执行任务里搜索不到智能设备

**可能原因**

**解决措施**

1. 智慧生活App-我的-设置-关于-开发者设置-choose cloud-哆啦云-选择沙箱环境。
2. 智慧生活App-我的-设置-关于-切换服务器-选择沙箱环境。

## 模组待配网的超时时间是多久？如何配置？

超时时间默认为10分钟。修改方法如下：

* 极速常规/秒控配网：在超时时间函数"HILINK_SetNetConfigTimeout(unsigned long netConfigTimeout)"中配置。
* 蓝牙辅助配网：在BLE配网广播控制函数"BLE_CfgNetAdvCtrl(unsigned int advSecond)"中配置，其中的蓝牙广播时间必须与极速常规/秒控配网中的超时时间保持一致。

## 智慧生活App Debug版本扫描设备显示为"未知设备"

**问题现象**

智慧生活App Debug版本环境设置为"认证沙箱"时能够正常扫描设备，但切换至"商用环境"后扫描设备显示为"未知设备"。

**可能原因**

登录智慧生活App的华为账号未申请测试权限。

**解决措施**

1. 进入手机"设置 > 应用和服务 > 应用管理"，在应用列表中选择智慧生活，进入智慧生活应用信息页面后，选择"存储"并点击"删除数据"。
2. 登录[Device Partner平台](https://devicepartner.huawei.com/cn/)，进入"管理中心"，在"账号管理 > 基本资料 > 申请测试权限"页面，点击"立即申请测试权限"。
3. 使用步骤2中的同一账号登录智慧生活App。
4. 使用智慧生活App重新扫描设备。

**问题现象**

设备断电重启后，在智慧生活App中无法找到设备卡片，需要重新给设备配网。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/A4zlSc0MSIedYHtAaeqRkw/zh-cn_image_0000002624866717.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=FF2764689FD8C52F8AD4DF8A89B1475E3926424A909BD96B028C60F040B907AF "点击放大")

**可能原因**

KitFramework SDK包里的"oem_auth_result_storage.c"文件认证业务相关接口没有实现，未保存认证信息，导致已配网设备需要重新配网。

**解决措施**

实现"oem_auth_result_storage.c"文件中认证业务相关接口，具体实现参考芯片商已适配的KitFramework SDK服务包。

## 模组在STA模式下连接路由器热点，路由器断电重启或模组离开热点范围再返回后，无法重连热点

**问题现象**

1. 模组短距测试中，执行如下命令设置模组打开STA模式。

   ```screen
   AT+STARTSTA
   ```

2. 执行如下命令，扫描模组周围热点。

   ```screen
   AT+SCAN
   ```

3. 执行如下命令，查看扫描结果。

   ```screen
   AT+SCANRESULT
   ```

4. 参考执行如下命令，连接热点。命令中的四个值分别代表SSID、MAC、热点类型以及密码，请根据实际情况修改。

   ```screen
   AT+CONN="hisilicon",1a:01:f1:c9:7c:92,3,"123456789"
   ```

5. 执行如下命令，打开DHCP。

   ```screen
   AT+DHCP=wlan0,1
   ```

6. 路由器断电重启或者模组离开热点范围再返回，此时发现模组无法重新连接该热点。

**可能原因**

模组未配置重连策略。

**解决措施**

参考如下命令执行重连策略，命令中的参数需要根据实际情况修改，具体取值参见芯片手册。

```screen
AT+RECONN=1,10,3600,5
```

## 设备在SoftAp配网模式下，智慧生活App扫描不到

**问题现象**

设备在 SoftAp 配网模式下，智慧生活App无法扫描到设备。

**可能原因**

1. 设备配网模式不是SoftAp配网。

2. 设备未进入配网状态，SoftAp 热点未正常拉起。

3. 设备热点名称（SSID）不符合命名规范。

4. 智慧生活 App 缓存问题导致设备列表未刷新。

**解决措施**

步骤 1：确认配网模式。

查看设备日志，确认当前配网模式为 SoftAp：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/MXAY64-NSwacjrh7cMutWQ/zh-cn_image_0000002624475271.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=AE10A5A0143135F7825E7B2F8B373EF74124A965D18CEE3BDC0E84EEB13D123E "点击放大")

步骤 2：检查设备配网状态。

查看设备日志，确认设备是否已进入配网状态：

设备的状态为 HLINK_NotifyDevStatus=5，即 HLINK_LINK_UNDER_AUTO_CONFIG，表明设备当前正处于待配网状态，尚未完成配网流程。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5d/v3/Kza-nytwRXK7b-oMIc2Syw/zh-cn_image_0000002594195660.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=E60B53742C5A4CA4C9476EA2A10CA2A03320856A240863CFECCE43CC9BBC21CF "点击放大")

步骤 3：验证热点是否正常拉起。

查看设备日志，确认 SoftAp 热点是否成功启动：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/s39qAHqIRYST3O-4XUYhvQ/zh-cn_image_0000002624595137.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=BEF06F7CD1799041858378DCDCF4D8BB3580BAA27C66263A3A6B36D2A03AC3EC "点击放大")

步骤 4：检查 SSID 命名规范。

确认设备热点名称符合规范格式： **Hi-AA...AA-BB...BB-XYYYYR** **NNN**

|字段|长度（字节）|说明|
|:------|:------|:-----------------------------------------|
|Hi-|3|固定前缀，作为设备识别的标识。|
|AA...AA|长度之和≤17|企业英文名（可简写）。字符串可以由字母、数字或空格组成。例如HUAWEI。|
|BB...BB|长度之和≤17|品类英文名（可简写）。字符串可以由字母、数字或空格组成。例如Smart TV或TV。|
|-X|2|设备识别的标识。其中，-为固定分割符；X为SoftAP版本号。|
|YYYY|4|产品ID，需要与Device Partner平台上的ProdID保持一致。|
|R|1|设备subProdId|
|NNN|3|SN后三字节|

步骤 5：等待 10-15 秒后，重启智慧生活 App，重新扫描设备。

当以上均正常时，可清除智慧生活App缓存，再扫描测试。

## 设备在蓝牙配网模式下，智慧生活App无法扫描到设备

**问题现象**

设备在蓝牙配网模式下，智慧生活App无法扫描到设备。

**可能原因**

1. 设备未进入蓝牙辅助配网模式。

2. 设备蓝牙协议栈初始化异常，未正常拉起蓝牙广播。

3. 蓝牙广播数据格式不符合规范。

4. 智慧生活 App 缓存问题导致设备列表未刷新。

**解决措施**

步骤 1：确认配网模式。

查看设备日志，确认当前配网模式为蓝牙靠近发现：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/a1BwzvMkTNCJVGWoeqrcUg/zh-cn_image_0000002624485679.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=0406A81B5007FF53076D8527A7225AD589892B634D9D31F8739E822BB46B51ED "点击放大")

## 蓝牙广播数据中 MPP 字段显示异常

**可能原因**

广播数据包末尾三个字段为 MPP（Manufacturer Specific Data），若 MPP 配置参数不符合规范，可能导致显示异常，不会影响配网功能。

**解决措施**

检查设备代码中MPP字段，若设备无需接入蓝牙网关，应移除 MPP 字段配置。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/SfT-Dt6JQZKGt9eAAWzMtw/zh-cn_image_0000002624485683.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=BE906B26A96E28216077DCDEE5A5FE5EAA5542F2678D521B012529D315A29039)
