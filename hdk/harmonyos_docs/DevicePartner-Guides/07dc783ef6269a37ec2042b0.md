# UX/UI设计规范概述

在开发原子化服务或接入智慧生活App之前，需要参考本章节完成UX/UI设计。  
![](https://media:101783481592918300)  
* 对于原子化服务与智慧生活App H5，除了在连接体验上和特殊设备上的视觉要求有所不同，其他方面的要求均是一致的。
* 如果智慧生活App H5采用线上方式开发，则默认满足设计规范，无需进行UX/UI设计。

![](https://media:101783481593127301 "点击放大")  

#### 简介

UX设计与UI设计主要关注的内容如下：  

|分类|说明|主要规范|
|:---|:--------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|UX设计|侧重于全量交互流程与页面布局的设计。|参考[连接体验](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-connect-fa-tag-0000001227361813)、[服务体验](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-service-entry-0000001198373789)、[控件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-3-0000001164421582)等章节。|
|UI设计|侧重于页面视觉风格（色彩、字体、图标、图片）与各类控件的设计，功能展示必须与UX保持一致。|参考[视觉风格](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-visual-color-0000001152454072)、[控件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-3-0000001164421582)、[多端适配](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-multi-foldable-0000001198373795)等章节。|
[表1 UX/UI设计说明]

* [连接体验](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-connect-fa-tag-0000001227361813)：原子化服务与智慧生活App的连接规范有所差异，需要根据设备所支持的连接方式选择对应的规范。为保证体验的一致性，需严格按照标准流程进行设计。
* [服务体验](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-service-entry-0000001198373789)：连接完成后，可从多个入口打开控制界面。使用标准控件，并发挥设备特点设计界面，需要保证不同软件底层开发的用户体验一致。
* [视觉风格](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-visual-color-0000001152454072)：了解并设计符合HarmonyOS视觉风格的服务界面，包含色彩、字体、图标、布局等关键视觉设计的概念和规则。
* [控件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-3-0000001164421582)：了解控件的特点，以及控件的不同显示状态，确保应用正确使用控件。
* [多端适配](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-multi-foldable-0000001198373795)：了解不同设备下控件自适应变化的特点，保证在不同设备上的基本用户体验。
