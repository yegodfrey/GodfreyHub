# 控制面板

控制面板主要用于快捷控制的场景。当手机"碰一碰"未连接的设备时，会先展示设备连接弹窗，设备连接完成后，手机上即会展示控制面板。当手机"碰一碰"已连接的设备时，手机上会直接展示控制面板。

<br />

1. 控制面板内容 控制面板内容包括：设备图片、设备名+设备品牌名、功能控制区、"查看更多"按钮，所有内容都必选。

   ![](https://media:101783481605062478 "点击放大")
2. 控制面板大小 控制面板使用手机系统中可滑动的面板控件，可滑动面板有2个常用高度：默认尺寸（屏幕的2/3高度）、类全屏尺寸（最大高度=屏幕高度-信号栏高度-固定间距）。面板初始高度由功能区内容而定，最高不超过默认尺寸。面板展开高度也由功能区内容而定，最高不超过类全屏尺寸。

   ![](https://media:101783481605167479 "点击放大")
3. 交互规则 控制面板的高度根据面板内容自适应调整：

   * 内容较少的面板 面板内容较少时，不需要将面板展开。

     ![](https://media:101783481605242480 "点击放大")
   * 内容较多的面板 面板内容较多时，拖动控制面板操作条，可将面板调至最大高度(非全屏)。

     ![](https://media:101783481605323481 "点击放大")

     面板达到最大高度后，支持滚动查看更多内容。

     ![](https://media:101783481605408482 "点击放大")

   <br />

   * 跳转全屏 点击设备图片或面板底部的"查看更多"按钮，可进入设备全屏页面查看更多内容。

     ![](https://media:101783481605501483 "点击放大")
   * 退出 面板为默认高度时，下滑即可退出。面板为最大高度时，可点击操作条或下滑退出。灭屏、锁屏、点击面板以外区域不会退出面板。

![](https://media:101783481605590484 "点击放大")
