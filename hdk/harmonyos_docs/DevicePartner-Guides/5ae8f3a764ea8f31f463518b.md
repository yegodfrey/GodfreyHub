# 原型机认证

介绍如何开展原型机认证，包含创建认证申请、预约认证、样机投递、技术认证、品牌授权，共五个环节。产品通过认证之后，即可获得HarmonyOS Connect授权。

## 适用范围

适用于全新开发的产品首次认证。

## 前提条件

已完成产品开发，包括产品定义、交互设计、集成开发、产品自测试等环节。

## 操作步骤

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中，选择"产品认证"，单击"创建认证申请"。

   > 说明
   >
   > 除了上述方式，也可以在"产品定义"或"产品自测试"完成后，通过页面下方的"提交认证申请"创建认证申请。

3. 在"新增认证申请"页面，配置产品的认证信息。

   1. 认证方式选择"原型机认证"。
   2. 选择本次认证产品。
      1. 单击"选择本次认证产品"。
      2. 在右侧页面中，选择待认证的产品，可以通过产品名称或产品ID进行筛选。
      3. 单击"确定"。
   3. 选择认证测试版本。 不同认证测试版本的差异，详见[认证标准的版本变更说明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/version-vhange-description-0000002622764811)。

   4. 选择是否"授权华为代为申请OHCA认证"。
      * 是：表示授权华为代为申请OHCA认证。仅支持采用OpenHarmony操作系统的产品。
      * 否：表示不授权华为代为申请OHCA认证，或者产品未采用OpenHarmony操作系统。
   5. 单击"下一步"。

4. 提交预约认证申请。

   1. 确认"产品自测结果"中的信息是否准确。如需修改或补充，可以前往"自测试"页面编辑。
   2. 完善产品认证资料。
      1. 上传设备图片和认证材料（包括法规与商品资质材料、上市营销材料等）。 说明
         >
         > 1.具体认证材料上传请以实际页面为准。
         >
         > 2.上市营销材料上传后会自动进行AI预审，若预审不通过，将鼠标放在"预审失败"后面的图标上面，会提示预审失败的原因，伙伴可根据失败原因进行相应的修改（预审结果仅供参考，不影响流程进行）。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/qQF1KPoKQKe7h6QxkZSPpg/zh-cn_image_0000002663913193.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CF12B8F369C2281DDF079826817297E7E2C614D67BD8C7B968F1B549335F22C "点击放大")

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/WOEaPFRaTmqjC2H1ERh0pQ/zh-cn_image_0000002663993275.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=42C1DB0A2FEE7CEB13C332545D485783CB5CC5D6F63ACE591E1ED0B1D43359FF "点击放大")
      2. 确认"认证测试版本"是否正确。
      3. 配置设备信息。 注意
         >
         > 此处配置的设备信息必须与设备OpenHarmony固件包中保持一致，具体取值可通过表1设备参数说明中API来查询。如果不一致，将无法通过认证。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/vxxQ61zSRZK4Qk9Bc2mGCg/zh-cn_image_0000002622925825.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=3780961B4A72B0B47D03049F34E7DEE7613A67EBE1FED617274057A1AFC3216E "点击放大")

         |参数|对应API|说明|
         |:----------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
         |软件版本号|GetDisplayVersion()|表示整个系统的软件版本号，而非OpenHarmony版本号。不超过64个字符。|
         |硬件设备版本号|GetHardwareModel()|表示设备硬件版本号，不超过32个字符。|
         |系统API Level|GetSdkApiVersion()|表示设备当前版本API级别。版本预置值，通常是整数，无需修改。|
         |版本ID|GetVersionId()|在所有设备范围中用于唯一标识版本。最大支持255个字符。 由多个字段拼接而成：$(设备类型) + '/' + $(公司英文名简称) + '/' + $(品牌英文名称) + '/' + $(产品系列英文名称) + '/' + $( 操作系统及版本号 ) + '/' + $(型号) + '/' + $(内部软件子型号) + '/' + $(系统软件API level ) + '/' + $(差异版本号) + '/' + $(构建类型)|
         |安全补丁级别|GetSecurityPatchTag()|表示当前OS的安全补丁级别。按实际情况填写，例如2020-12-01。不超过64个字符。|
         |版本Hash|GetBuildRootHash()|默认为空。|
         [**表1**设备参数说明]

      4. 填写认证联系人信息，选择测评机构与预约认证时间。 注意
         >
         > 在选择测评机构之前，请先联系测评机构的接口人，确认预约认证时间和认证相关事宜。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/xNnbOht1QUuXAk_q5tqFbQ/zh-cn_image_0000002592446404.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=FE55AE804F7CB6CF7B9CB5C7DE5CB813EE2672FD4CAC2EA75E01E459433EFEEF "点击放大")
   3. 单击"提交"。预约认证提交成功后，可以查看"预约认证结论"。
      * 如果"华为预约审核"中所有认证项显示"通过"，可以继续下一步。
      * 如果"华为预约审核"中存在认证项显示"不通过"，请单击提示信息中的"补充材料"，尽快根据意见修改，并重新上传认证材料。 说明
        >
        > 1.对于"HarmonyOS Connect 品牌审核"、"产品配网图认证"、"硬件/国家/行业/商品资质"三个认证项，如果未通过材料审核，伙伴重新提交认证时，只需提交未通过的认证项的相关材料即可，已通过的认证项无需重复审核。
        >
        > 2."项目信息/功能定义认证"、"产品配网图"、"商务资质和投资关系审核"这三个认证项有预审结论后，就可以走到机构认证阶段，其他预审项与机构认证并行。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/zO6kCqa6S0ms4Ym514vtdw/zh-cn_image_0000002622765963.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=2B7AC68C10C7165EA8B14B805319A48C2143C21292ACCE63E9805650B43C51D6 "点击放大")

5. 根据平台流程指引，进入"样机投递"环节，完成样机投递。

   > 说明
   >
   > 根据认证产品的实际情况，华为认证测试团队将决定是否需要寄送样机。如果无需寄送样机，可以忽略当前步骤，直接进入"技术认证"环节。
   1. 按照"样机投递"页面显示的地址，完成样机投递。
   2. 填写样机寄送的快递单号。
   3. 上传"样机清单"。


   4. 单击"提交"，可以在"技术认证"页面查询认证进展。

6. 在"技术认证"页面，查看认证结果。

   * 如果预审材料审核失败，则需要单击上方的"补充材料"，根据审核意见上传认证材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b3/v3/Gnv-_9j0TK6xCKVO1CzXvA/zh-cn_image_0000002592606312.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=33545882DC3341BEF67D94AB3D0276D004E68C3DC0C582796EA74AA3045BBEDE "点击放大")

   * 如果存在认证项显示"未通过"，则需要根据测试意见修改后，重新提交认证申请。
   * 如果所有认证项均显示"通过"，则可等待授权发证。在"技术认证"页面，可以获取认证证书。
