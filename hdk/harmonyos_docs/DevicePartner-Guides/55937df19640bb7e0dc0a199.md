# FAQ

#### 如何申请更多HarmonyOS权限

请在entry模块下config.json里补充需要申请的权限，权限名请参考[权限列表](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/security-permissions-available-0000001051089272)。

如果申请的属于[敏感权限](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/security-permissions-available-0000001051089272#ZH-CN_TOPIC_0000001073014298__section1727613371109)，需要动态申请权限，具体操作请参考[动态申请权限开发步骤](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/security-permissions-guidelines-0000000000029886#ZH-CN_TOPIC_0000001072906209__section7431121314439)。
