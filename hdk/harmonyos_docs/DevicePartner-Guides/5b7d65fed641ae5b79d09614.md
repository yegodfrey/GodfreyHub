# 开发准备

#### 注册开发者帐号

进入[华为开发者联盟网站](https://developer.huawei.com/consumer/cn/)，点击右上角"注册"成为企业开发者并完成实名认证。详细操作请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。  
![](https://media:101783481634067870)  
当前需注册为企业开发者帐号，个人开发者暂不支持。

#### 生成密钥和证书请求文件

搭建完开发环境后，您需要使用DevEco Studio生成密钥文件（.p12文件）与证书请求文件（.csr）。  
![](https://media:101783481634163873)  
* 密钥文件可用于关联您的OAuth凭证及打包项目时进行签名，有关OAuth凭证的相关知识，请参阅[配置华为帐号服务](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-for-health-kit-0000001126264886#section1694101312384)。
* 证书请求文件用于向华为请求签发调试证书、发布证书。

1. 在DevEco Studio主菜单栏点击Build \> Generate Key and CSR。
2. 在Key Store File中，点击New创建密钥库文件。

   <br />

   ![](https://media:101783481634212874 "点击放大")

   <br />

3. 在Create Key Store窗口中，填写密钥库信息后，点击OK。

   <br />

   * Key Store File：选择密钥库文件存储路径，并设置文件名称，点击OK。
   * Password：设置密钥库密码，必须由大写字母、小写字母、数字和特殊符号中的两种以上字符的组合，长度至少为8位。请记住该密码，后续签名配置需要使用。
   * Confirm Password：再次输入密钥库密码。

   ![](https://media:101783481634437875)

   <br />

4. 在Generate Key界面中，继续填写密钥信息后，点击Next。

   <br />

   * Alias：密钥的别名信息，用于标识密钥名称。请记住该别名，后续签名配置需要使用。
   * Password：密钥对应的密码，与密钥库密码保持一致，无需手动输入。
   * Validity：证书有效期，建议设置为25年及以上，覆盖应用的完整生命周期。
   * Certificate：输入证书基本信息，如组织、城市或地区、国家码等。

   ![](https://media:101783481634472876 "点击放大")

   <br />

5. 在Generate CSR界面，选择密钥，设置CSR文件存储路径并设置文件名称，点击OK。

   <br />

   ![](https://media:101783481634502877 "点击放大")

   <br />

6. 点击Finish按钮，创建CSR文件成功，可以在存储路径下获取生成的密钥库文件（.p12）和证书请求文件（.csr）。

   <br />

   ![](https://media:101783481634529878)

   <br />

#### 申请数字证书和Profile文件

您需要通过使用上一章节生成的证书请求文件，向华为申请签发调试证书与发布证书，并根据调试证书或发布证书申请对应的Profile文件。  
![](https://media:101783481634564879)  
* 调试证书仅用于将工程打包安装至调试手机时使用，不可用于上架发布；发布证书仅用于上架发布，不可用于安装调试。
* 创建Profile文件前，请先完成[创建HarmonyOS应用](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-for-health-kit-0000001126264886#section17341840271)，生成的Profile文件与您的项目绑定，如您更换了HarmonyOS应用（如更换包名，更换开发者等），您需要重新申请Profile文件。

* 在AppGallery Connect网站中申请调试证书和Profile文件。请参考：[申请调试证书和Profile文件](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-manual-0000001177608893)
* 在AppGallery Connect网站中申请发布证书和Profile文件。请参考：[申请发布证书和Profile文件](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-releaseapp-0000001126380068)

证书和Profile文件申请完成后，将用于在DevEco Studio中进行[配置签名](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-environment-config-0000001226320161#section922418946211103)。
