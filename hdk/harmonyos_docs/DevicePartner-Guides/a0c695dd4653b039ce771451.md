# 跳转类型列表

如果从H5应用跳转到运动健康App页面，则使用如下参数：  

|字段Key|字段值|描述|
|:---------|:--|:------|
|healthType|2|体重。|
|healthType|4|体温。|
|healthType|5|血氧。|
|healthType|8|血糖。|
|healthType|9|血压。|
|healthType|20|跳绳。|
|healthType|50|血糖历史记录。|
|healthType|51|体重历史记录。|
|healthType|80|设备详情页。|

* 示例：

  ```
  // 跳转到体温页面
  window.location.href = "huaweischeme://healthapp/basicHealth?healthType=4"
  ```
