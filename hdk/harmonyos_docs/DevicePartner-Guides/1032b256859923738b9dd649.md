# 单品配置

## 使用js自带的setStorage与getStorage问题

**问题现象**

部分设备在首次进入H5页面时，会显示使用指南引导气泡且该引导仅在首次访问时显示，后续访问不再重复弹出。但在iOS平台下，该引导气泡在每次进入页面时均会重复弹出。

**问题根因**

iOS平台在H5页面销毁或App切换时，会清理WebView的临时存储数据storage。由于当前实现使用了不稳定的临时存储接口，导致存储的"已显示引导"状态数据在每次页面重新加载时被清除，从而无法正确判断是否为首次访问。

**解决方案**

建议弃用不稳定的临时存储接口storage，改用App提供的持久化存储JS API：hilink.setStorageSync 和 hilink.getStorageSync。

1. 存储数据示例：

```screen
hilink.setStorageSync(
  "key",        // string，存储的键名
  "value",      // string，存储的值
  "resultCallback" // function，存储成功或失败时的回调函数
);
```

2. 获取数据示例：

```screen
hilink.getStorageSync(
  "key",        // string，获取的键名
  "resultCallback" // function，获取成功或失败时的回调函数
);
```

> 注意
>
> 使用 hilink.setStorageSync 和 hilink.getStorageSync 可确保数据在App生命周期内持久化存储，避免因页面刷新或切换导致的数据丢失。
>
> 请确保在不同平台调用时，严格使用上述App提供的持久化存储API，以保证数据一致性。

## NPS功能需适配原生标题栏

**问题现象**

当前NPS（净推荐值）问卷调查功能依赖原生标题栏展示，H5端缺乏对应的UI组件或API直接渲染该标题栏。导致H5页面无法独立实现该功能，必须与App端配合，通过原生标题栏承载相关交互或展示内容。

**解决方案**

1. 启用原生标题栏：

调用App提供的JS API hilink.setTitleVisible，将第一个参数设置为 true，以显示原生标题栏。

```screen
hilink.setTitleVisible(
  true,           // boolean，true表示显示标题栏，false表示隐藏
  "resultCallback" // function，回调函数，用于接收操作成功或失败的结果
);
```

2. 预留标题栏空间：

为避免H5内容被原生标题栏遮挡，需在CSS中为页面顶部预留空间。预留高度应为"状态栏高度 + 标题栏高度（约56px）"。

步骤如下：

第一步：获取状态栏高度

调用 hilink.getStatusBarHeight 获取当前设备的状态栏高度。

第二步：设置CSS样式

将获取到的状态栏高度加上标题栏固定高度56px，作为页面根容器或内容区域的 margin-top 值。

示例代码逻辑：

```screen
hilink.getStatusBarHeight(function(result) {
  if (result.code === 0) {
    var statusBarHeight = result.data; // 假设返回数据在data字段中
    var titleBarHeight = 56; // 原生标题栏固定高度
    var totalTopHeight = statusBarHeight + titleBarHeight + 'px';
    // 设置页面容器或body的margin-top
    document.body.style.marginTop = totalTopHeight;
    // 或者针对特定容器：
    // document.querySelector('.content-container').style.marginTop = totalTopHeight;
  }
});
```

> 注意
>
> * 确保在页面加载初期调用 hilink.getStatusBarHeight 和 hilink.setTitleVisible，以避免布局闪烁。
> * 标题栏高度56px为经验值，若实际UI设计有差异，请根据设计稿调整该数值。
> * 需兼容不同机型，确保 margin-top 计算准确，防止内容被遮挡或留白过大。

## 易维与智慧生活H5包适配规范

**问题现象**

易维App与智慧生活App共用同一套H5代码包。由于两者底层环境存在差异，需在H5层进行适配兼容。

**排查步骤**

一、环境识别机制

通过检测 window.hilink.isAiInstall 的值区分当前运行环境：

1. 有返回值：当前为易维环境。

2. 返回 undefined：当前为智慧生活环境。

二、接口适配策略

1. 规则类接口

易维 App 中未实现"哆啦"相关功能，故 getRules 等规则接口在易维中调用将返回错误码。建议在易维环境中屏蔽此类接口的调用。

2. 涉云类接口

易维 App 设备数据不经过云端，涉云接口统一返回空数据。建议在易维环境中设备详情页隐藏涉云页面，或在触发相关操作时提示"装维 App 当前不支持该功能"。

三、设置页删除入口显示逻辑

需确保"易维添加的设备"在"智慧生活 H5"中不显示删除入口，而"智慧生活添加的设备"正常显示。判断逻辑如下：

1. 条件一（环境判断）

window.hilink.isAiInstall === undefined，即当前处于智慧生活环境。

2. 条件二（设备来源判断）

通过 getDevInfoAll 或 getDevCacheAll 接口获取设备快照，检查 devInfo.setupType 字段。若 setupType === 1，表示该设备由易维添加。

3. 最终判定规则

当同时满足上述两个条件（即：智慧生活环境 && 设备由易维添加）时，隐藏设置页的删除入口。

代码示例：

```screen
const isSmartLifeEnv = window.hilink.isAiInstall === undefined;
const isAddedByYiWei = devInfo.setupType === 1;
if (isSmartLifeEnv && isAddedByYiWei) {
  // 隐藏删除按钮
} else {
  // 显示删除按钮
}
```

## 设备历史记录页面的图表数据出现断点问题分析与解决方案

**问题现象**：

设备历史记录的页面中，图表数据显示不连贯，出现明显的断点现象。具体表现可参考相关截图。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/S56mPdcgRPy6dF4p5Jk0FA/zh-cn_image_0000002661665347.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=96ED12444147B778FD2ED71A82214A99849F422BD0A81277FB18E0F81AB69B22 "点击放大")

**问题根因**

设备上报频率过高，引发云侧限流进而导致部分数据丢失。

**排查步骤**

1. 检查设备的上报频率设置，确认是否超过云平台的限流阈值。

2. 适当降低设备的数据上报频率，或采用数据聚合上报的方式，以减少单次请求的数据量或请求频次。

3. 优化设备端的网络重连机制，确保在网络波动时能更稳定地保持连接，减少因连接中断导致的数据缺失。

## 设备离线时强制进入设备详情页的解决方案

**问题现象**

当前部分品类设备在离线状态下，点击设备卡片会跳转到通用的离线页面，而无法进入设备详情页，导致无法查看该类设备的历史数据（例如空净品类查看 PM2.5 历史记录），影响用户体验。

**解决方案**

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)。

2. 单击页面右上角的"管理中心"。

3. 在左侧导航栏中，选择"产品开发"。

4. 选择目标产品，点击进入该产品的开发页面。

5. 在页面中找到并选择"产品定义"，然后点击"物模型定义"。

6. 在"默认功能"的新建功能列表中，找到并选择"低功耗产品休眠查看"选项进行配置。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/okleL1tETcCwB85GOBSj1A/zh-cn_image_0000002631466216.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=7DF08078CA69537040A2F67220A0AC65A8DDABE35EDC801C06688C64903490C0 "点击放大")
> 注意
>
> 配置完成后，请确保保存并生效该设置。此功能主要适用于需要保留离线数据查看需求（如历史曲线、状态记录等）的设备品类。配置后，用户点击离线设备卡片将直接跳转至设备详情页，而非通用离线提示页。

## 设置页语音控制说明显示空白问题的排查与解决

第一步：启用语音功能

## 智慧生活App设备热门问题配置指南

**问题现象**

智慧生活App中，进入"我的"页面，点击"帮助与反馈"，选择特定设备后，发现热门问题列表中仅显示一条"智慧生活App提示设备离线"，缺乏其他预设的热门问题内容。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/sHhDb5t3TKqybVxKEK-QnA/zh-cn_image_0000002631660998.jpg?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=80927BD7E71D478B51EB8BD33FBF96B1A7267C1401CBAAD1899C7E57C762973C "点击放大")

**解决方案**

该现象通常是因为offeringCode平台当前不支持直接通过界面配置热门问题。解决方法是联系DTSE（技术支持工程师），在单品的profile文件中配置相关的offeringCode编码。

操作步骤

第一步：确认问题范围

确认受影响的设备型号及对应的offeringCode。检查该设备在offeringCode平台上的配置状态，确认是否缺少热门问题配置入口。

第二步：联系DTSE

联系负责该设备项目的DTSE工程师，说明问题现象及需求。提供设备型号、offeringCode以及需要配置的热门问题列表内容。

第三步：配置profile文件

DTSE工程师将在单品的profile文件中添加或修改相关配置，包括热门问题的标题、内容链接等字段。确保配置符合App端的展示规范。

第四步：验证配置效果

配置完成后，等待系统同步或重新发布版本。在智慧生活App中再次进入"帮助与反馈"，选择对应设备，验证热门问题列表是否显示正常。
