# 二级页面

#### 类型1：列表页

列表包含一系列相同宽度的列表项。适合连续、多行呈现同类数据。

列表单体卡片、组合卡片的起始与结尾都需要增加4vp。

规格

* 当列表为单行文本，且没有左侧元素时，列表高度默认为48vp。
* 当列表为双行文本，且没有左侧元素时，列表高度默认为64vp。
* 当列表为三行文本，列表默认高度为96vp。

#### 类型2：子页签

子页签通常放在内容区上方，展示不同的分类。页签名称应简洁明了，清晰描述分类的内容。

子页签展示数量不宜过多，建议3-5个，以免界面拥挤。分类过多的可横向滑动查看超出屏幕部分。

新增分段按钮，分段按钮最多可分为3个。

#### 类型3：进度页

此类页面通常用来展示：滤芯剩余、刷头剩余时长等场景。由半圆图形、数值文本和辅助文本组成，图形可根据设备状态改变颜色。

新增按钮样式，如按钮文本过长，可上下排版。⚠️注意：按钮和屏幕底部间距改为 16vp。

#### 类型4：空内容页面

应用在整个页面或局部区域无内容。

* 在空内容的区域显示内容相关图标+文字："没有XXX"。
* 若需增加额外说明，说明文字在"没有XXX"下方，如果不超过一行，居中显示，如果超过一行，则居左显示。

插画资源大小

* 局部区域，资源大小96x96vp。
* 整个页面，资源大小120\*120vp。

#### 手动检查更新-固件升级页面

全场景自有业务的应用具备独立更新能力时，当手动检查更新时，使用此流程页面进行版本更新。

* 左图为"检查更新中"状态，点击"检查更新"，按钮置灰，文本字符串"正在检查..."。
* 中图为"正在更新"状态，更新中，显示新版本内容，依据设备情况，可添加注意事项提示。
* 右图为"更新完成"态，界面显示"更新成功"，按钮显示"完成"。
