# 全屏界面

在控制面板上点击"查看更多"后，即可跳转全屏的主界面布局。[查看全屏界面详细布局及其标注](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-component-1-0000001189262580)。

设备控制主界面由设备展示区、实时状态栏、信息展示区、主控区、服务扩展区和售后服务组成。通过明确的区域划分，帮助用户更好的理解设备功能，同时通过使用相同的页面框架，多种不同的设备具有一致的操作界面，帮助用户快速上手使用。

![](https://media:101783481610120526 "点击放大")

1. 设备展示区 设备展示区展示设备外观；当设备上有运行状态时，还可以直观地获取到设备状态。

   ![](https://media:101783481610992527 "点击放大")
2. 实时状态栏 实时状态控件用于展示设备的工作状态和主要功能控件（例如"开关"）。

   ![](https://media:101783481611058528 "点击放大")
3. 信息展示区 信息展示区用于展示设备的信息，一般按照使用频率和重要级别排序。

   ![](https://media:101783481611133529 "点击放大")
4. 主控区 主控区放置设备的控制功能，如设置颜色、设置温度、设置亮度、倒计时、定时等功能。

   ![](https://media:101783481611210530 "点击放大")

   有服务扩展内容时，主控区最多展示3排功能，展示不下的功能将被收起。点击"展开更多"，即可查看被收起的功能。

   主控区功能按使用频率和重要级别排序，使用频率和重要级别高的排在前面，设备合作伙伴可根据用户习惯自定义顺序。

   ![](https://media:101783481611292531 "点击放大")
5. 服务扩展区 服务扩展区用于放置设备玩法、食谱、商品推荐等，一般按照使用频率和重要级别排序。

   ![](https://media:101783481611368532 "点击放大")

<!-- -->

6. 智能场景 智能场景用于实现智能家居设备间联动的功能。

   ![](https://media:101783481611444533 "点击放大")

<!-- -->

7. 售后服务区 售后服务主要用于展示客服热线、热门问题、在线咨询等服务。

   ![](https://media:101783481611522534 "点击放大")
8. 增值服务区 卡片内容分为HarmonyOS Connect、服务、福利三大类。

   * HarmonyOS Connect分为产品耗材类卡片及套餐推荐类卡片。
   * 服务卡片分为三方服务卡片2X2卡片和2X4卡片样式以及伙伴服务卡片。
   * 福利卡片为2x4卡片样式。

   增值服务非必选项，伙伴可参考以下样式进行组合。

   ![](https://media:101783481611672535 "点击放大")

   HarmonyOS Connect：产品耗材类

   ![](https://media:101783481611762536 "点击放大")

   HarmonyOS Connect：套餐推荐类

   ![](https://media:101783481611878537 "点击放大")

   服务卡片：伙伴服务卡片

   ![](https://media:101783481611981538 "点击放大")

   服务卡片：2x2卡片、2x4卡片

   ![](https://media:101783481612072539 "点击放大")
