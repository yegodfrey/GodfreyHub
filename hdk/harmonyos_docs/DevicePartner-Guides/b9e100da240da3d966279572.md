# 一镜到底动画适配

1. 手机一镜到底动画：九宫格点击卡片，插件主页从卡片大小放大到全屏的一个启动动画，退出时有个缩小的动画，伙伴参考[一镜到底动效](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-one-shot-to-the-end)进行操作。
2. 平板、pc、tv以及折叠屏展开时插件hsp主页面显示为弹框模式，所以没有动画效果。

#### 从九宫格进入查询详情页面的动画适配

只有插件首页设置geometryTransition属性，值为华为deviceId，其他页面不能设置，示例如下：

```
@Component
struct XXXPluginLaunchPage {

     //替代路由router，用于跳转页面，退出页面
     routerStack: NavPathStack = new NavPathStack();
     //页面启动参数
     params?: Record<string, Object>;
     deviceId: string = ''

      aboutToAppear(): void {
          if (this.params != null) {
             this.deviceId = this.params['deviceId']as string
          }
      }

        build() {
               NavDestination() {
                  Column() {
                   }
                   //在NavDestination下面的一级子组件下面增加这个方法，才有一镜到底动画，参数传设备id
                   .geometryTransition(this.deviceId)
               }
               //增加透明度
                .backgroundColor(Color.Transparent)
                .hideTitleBar(true)
                .onReady((data) => {
                    //获取路由栈routerStack 
                   this.routerStack = data.pathStack
                })
        }
}
```

#### 插件首页退出返回到九宫格动画适配

插件首页返回九宫格动画适配，涉及侧滑返回和标题栏返回按钮返回，返回时使用animateTo动画，示例如下：

```
finishPages(): boolean | void {
    animateTo({
      duration: 300,
      curve: Curve.Sharp,
      onFinish: () => {
        AppStorage.set<string>('doScaleAnimDevId', this.deviceId);
      }
    }, () => {

	//在这里执行退出插件路由操作，在手机和平板上逻辑不一样，下面的平板适配，会具体的讲解
    })
    return true
  }
```
