# 应用开发概述

#### 简介

在[产品定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-0000001134540425)环节，合作伙伴已定义了产品支持的交互方式，即明确了用户可以采用什么方式来添加设备、控制设备或管理设备。例如，智慧生活App、运动健康App、原子化服务（FA）、小艺语音等。

本章节针对不同交互方式，介绍如何进行应用设计与开发，参见[表1](#ZH-CN_TOPIC_0000001134281543__table19155101320455)。  

|交互方式|相关资源|简介|
|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------|
|原子化服务|[UX设计规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-overview-0000001198252447)|介绍HarmonyOS Connect的UX/UI设计需要遵循的规范，包含了连接体验、设备控制、视觉风格等部分。|
|原子化服务|[原子化服务开发](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/atomic-service-overview-0000001136377936)|介绍原子化服务的整个开发流程，包括接入准备、功能开发以及发布上架。|
|智慧生活App <br />|[UX设计规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-overview-0000001198252447)|介绍HarmonyOS Connect UX设计规范，包含了连接体验、设备控制、视觉风格等部分。|

#### 交互设计入口

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中选择"产品开发"，单击待开发的产品，进入产品开发流程。
3. 选择"交互设计"，即可进入交互设计页面，如[图1](#ZH-CN_TOPIC_0000001134281543__fig153542099413)所示。

   <br />

   ![](https://media:101783481592266290)  
   * 根据已定义的产品交互方式的不同，实际界面显示会有所差异。
     * 智慧生活App、运动健康App、FA：如果需要修改交互方式，可以返回"产品定义"页面进行编辑。
     * 小艺语音：仅适用于采用"HarmonyOS Connect直连方案（Wi-Fi/Combo）"开发方案的部分产品品类。当产品支持小艺语音功能时，会自动显示小艺语音功能卡片，无需配置。
   * 如果产品支持多种交互方式，需要逐个完成多种方式的设计与开发。
