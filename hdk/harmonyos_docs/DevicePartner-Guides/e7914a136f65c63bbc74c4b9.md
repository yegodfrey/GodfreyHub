# 合作计划

[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )针对不同类型的合作伙伴，分别制定了专门的合作计划。伙伴可以根据业务需求和合作意向，选择加入匹配的合作伙伴计划，获取对应的业务能力和技术支持等。平台将根据伙伴已加入的合作计划，在"管理中心"的导航栏中展示支持的能力。  
![](https://media:201787206625763654)  
仅项目空间的主账号可以查看并管理"合作计划"。  

#### 查看合作计划

登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，进入"管理中心"。在左侧导航栏选择"账号管理 \> 合作计划"，可以查看"可加入计划"和"已加入计划"。  
![](https://media:201787206625790655)  
首次进入"合作计划"页面时，仅显示"可加入计划"。在"可加入计划"中可以选择加入相应的合作计划，具体操作参见[加入合作伙伴计划](#section179081923980)。

* 合作计划申请成功后，会在"已加入计划"中呈现。
* 合作计划已申请、未完成审批时，在"可加入计划"中可以查看审批状态。

![](https://media:201787206625852656)  

#### 加入合作伙伴计划

在完成企业实名认证后，必须加入合作计划，才能够使用平台提供的服务和能力。具体加入方式如下：

* HarmonyOS Connect生态产品合作伙伴 此计划需要申请加入，操作步骤如下：

  1. 单击"申请"。
  2. 根据界面提示信息，填写"主营业务"和"需求描述"。
  3. 单击"确定"提交申请，等待审批完成。 审批结果将以邮件形式发送到邮箱。如果未提供联系邮箱，也可以登录管理中心查看审批进展。与此同时，也可以继续申请其他计划。

  4. 审批通过后，进入管理中心，签署《HarmonyOS Connect生态产品合作协议》之后，即可加入当前计划。  
     ![](https://media:201787206625889657)  
     签署《HarmonyOS Connect生态产品合作协议》时，可以根据实际需要，同时选择签署下方的《华为合作伙伴付费服务协议》及《鲸鸿动能广告服务协议》。
     * 同意签约后，可以享受商家专属广告权益。
     * 不同意签约，并不影响成为HarmonyOS Connect生态产品合作伙伴。如果后续有相关诉求，可以登录[鲸鸿动能](https://ads.huawei.com/usermgtportal/home/index.html#/)官网进行签约。

     ![](https://media:201787206625932658)
* HarmonyOSConnect生态解决方案合作伙伴 此计划需要申请加入，操作步骤如下：

  1. 单击"申请"。
  2. 根据界面提示信息，填写"主营业务"和"需求描述"。
  3. 单击"确定"提交申请，等待审批完成。 审批结果将以邮件形式发送到邮箱。如果未提供联系邮箱，也可以登录管理中心查看审批进展。与此同时，也可以继续申请其他计划。

  4. 审批通过后，进入管理中心，签署《HarmonyOS Connect生态解决方案合作协议》之后，即可加入当前计划。
* HUAWEI HiCar汽车硬件合作伙伴 HUAWEI HiCar（以下简称HiCar）是华为提供的人-车-家全场景智慧互联（HUAWEI HiCar Smart Connection）解决方案，成为HUAWEI HiCar合作伙伴可查看[合作准入申请](https://device.harmonyos.com/cn/docs/devicepartner/DP-HiCar-Guides/apply-cooperation)，完成华为帐号注册与企业实名认证，并加入合作伙伴计划，成为HUAWEI HiCar汽车硬件合作伙伴。

* 实验室 此计划当前只支持定向邀请，暂不可公开或申请加入。
