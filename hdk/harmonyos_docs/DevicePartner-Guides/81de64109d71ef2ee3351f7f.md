# 安全红线要求

1. 提供给华为合入智慧生活的插件需要开启混淆配置。
2. 严禁将password在代码里面明文编码，必须存在服务器，插件通过需通过安全网络请求获取加密后的数据，完成解密操作后方可使用。
3. 严禁使用不安全的加密算法，例如：将md5作为加密算法使用。
4. ip、mac、sn、deviceId、url等敏感数据不能在日志里面明文打印，必现脱敏处理后再打印，例如将deviceId后面的使用\*打印：300bee6c-\*\*\*\*\*\*。
5. 严禁ip、url等在代码里面硬编码，必现写在配置文件resources/rawfile下面，然后代码里面读取。
