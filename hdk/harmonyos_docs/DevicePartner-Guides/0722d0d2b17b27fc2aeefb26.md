# 接入运动健康App方案介绍

#### 接入运动健康App的价值

运动和健康领域的智能设备通过接入华为运动健康App，可以为用户提供更多智能体验。

1. 华为运动健康App提供专业的运动记录、减脂塑型训练、科学睡眠和健康管理等功能，能给用户提供更多科学的运动健康指引。
2. 运动健康也是一个数据接入和服务汇聚的开放平台，通过引入优秀的三方服务和应用，构建可持续发展的生态环境，为用户提供更加丰富和专业的运动健康服务，实现多方共赢。您的设备借助华为运动健康平台接入更广阔的生态。
3. 与华为心率手表、手环形成硬件互助，可实现将华为心率手表的心率数据和步数等在设备上实时显示。
4. 华为手机"碰一碰"即自动连接设备，并实时同步数据，为用户带来便捷的连接体验。  

#### 选择接入方案

接入运动健康App当前支持两种接入方案，不同设备类型支持的方案如下，请根据设备的蓝牙协议选择Native方案或H5方案。  

|设备分类|设备类型|蓝牙协议|接入方案|碰一碰|
|:---|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|:--------|:-------------|
|运动设备|跑步机、走步机、椭圆机、划船机、智能单车|FTMP（Fitness Machine Profile）|Native|支持|
|运动设备|智能跳绳|华为自定义蓝牙协议|Native|支持|
|健康设备|心率设备|[HRP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=239865)（Heart Rate Profile）|Native|不支持|
|健康设备|体脂秤|[WSP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=293525)（Weight Scale Profile）、私有协议|Native、H5|支持|
|健康设备|血压计|[BLP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=243125&_ga=1.123872906.1469285867.1479213658)（Blood Pressure Profile）、私有协议|Native、H5|Native支持；H5不支持|
|健康设备|血糖仪|[GLP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=248025)（Glucose Profile）、私有协议|Native、H5|支持|
|健康设备|体温计|私有协议|H5|支持|
|健康设备|血氧仪|私有协议|H5|不支持|
|健康设备|筋膜枪|私有协议|H5|支持|
|健康设备|心电设备|私有协议|H5|不支持|
