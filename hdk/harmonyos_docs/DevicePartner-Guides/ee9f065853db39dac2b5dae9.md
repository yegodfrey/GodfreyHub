# GPRS设备

![](https://media:101783481648605043)  
为提供更简便的接入体验，GPRS设备接入流程进行了优化。在2022年5月30日之后接入的伙伴，请按照本章节的指导完成数据交互环节的开发，可参阅[模板](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-obtain-template-code-0000001195771710)；在2022年5月30日之前已经启动接入的伙伴，仍可按照[历史文档-GPRS设备](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-data-gprs-0000001313608673)完成接入流程。

#### 绑定设备

在用户授权完成之后，伙伴需要调用Health Kit云的[设备绑定](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/devices-binding-0000001230987242)接口进行绑定设备。

完成设备绑定后，H5页面需要跳转到设备详情页，流程如下。

![](https://media:101783481648676045)

1. 获取设备信息。

   <br />

   绑定设备需要sn和prodId，通过[getDeviceInfo](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-device-0000001227598363#section13582191319428)接口获得。

   示例代码如下：

   ```
   window.getDeviceInfo = (response) => {
       let res = JSON.parse(response);
       if (res.errCode == 0) {
           // 包含设备sn和prodId
       } else if (res.errCode == 1001) {
           // 没有获取设备读取权限
       } else {
           // 获取异常
       }
   };
   try {
       window.hilink.getDeviceInfo("getDeviceInfo");
   } catch (err) {
       log.info("catch err: " + err);
   }
   ```

   <br />

2. 设备绑定，伙伴H5需要在伙伴云和Health Kit进行绑定。

   <br />

   * 由伙伴H5调用伙伴云接口完成设备绑定，需将授权后获得的AT上传至伙伴云。
   * 由伙伴H5调用Health Kit的[设备绑定](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/devices-binding-0000001230987242)接口进行绑定。

   <br />

3. 绑定完成后，需要先判断在设备绑定前是否存在未上传到Health Kit云的历史数据。

   <br />

   * 如果存在历史数据，则需要进入同步历史数据页面，H5模板已提供该页面供伙伴使用。 在同步历史数据页面，伙伴需实现用户点击同步按钮时，伙伴云上传该设备的历史数据到Health Kit云。

   * 如果没有历史数据，请按[步骤4](#ZH-CN_TOPIC_0000001238364915__li62151228113011)跳转到设备详情页。

   <br />

4. 若没有历史数据，或已完成历史数据同步（或用户点击不同步）后，通过如下url跳转到设备详情页。

   <br />

   ```
   huaweischeme://healthapp/basicHealth?healthType=80&deviceId=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx&sn=xxxxxxxxxxx
   ```

   其中，healthTytp=80表示跳转到详情页，deviceId可通过[getDeviceId](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-device-0000001227598363#section57863745810)接口获得，sn可通过[getDeviceInfo](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-device-0000001227598363#section13582191319428)接口获得。

   <br />

#### 数据上传到Health Kit云

将设备数据上传到伙伴自有云上，再由伙伴自有云通过REST API，将数据传到Health Kit云，支持对数据进行增、删、改、查等操作。请参考Health Kit REST的[开发指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/overview-restful-api-0000001050071695)和[API参考](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/datacollectors_create-0000001050114852#section984123664716)。  

#### 解绑设备

解绑操作不需要H5实现，由运动健康App调用Health Kit的解绑接口实现设备和App的解绑，Health Kit发送订阅消息通知伙伴云设备已完成解绑。伙伴只需实现[订阅数据](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/subscription-0000001078496860)即可。
