# 产品自测试

伙伴可以基于[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )开展产品自测，并上传自测结果。

## 前提条件

已完成产品的[设备开发](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/device-development-overview-0000001088003830)与[应用开发](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/design-and-development-overview-0000001134281543)。

## 操作步骤

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在平台左侧导航栏中选择"产品开发"，单击产品卡片，进入产品开发流程。
3. 选择"自测试"页签，进入自测试环节。
4. 在"体验测试"页面，通过DevEco Certification Centre（以下简称"DECC"）工具来测试产品的体验特征。

   1. 配置产品规格。
      1. 单击"设置规格"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/VnuyPUR4R-GwdAPQ-Nmp_A/zh-cn_image_0000002592436276.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=8C8E6D049826D1AD703E6520E49805B4970B0F1290910DF9CC489382D756CBFE "点击放大")

      2. 选择认证测试版本号。 不同认证测试版本的差异，详见[认证标准的版本变更说明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/version-vhange-description-0000002622764811)。

      3. 根据产品实际情况，配置产品的软硬件规格（规格项会根据产品定义信息自动匹配筛选）。 务必确保所有规格项均配置正确，否则会影响产品认证。

      4. 配置完成后，单击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/qhkRhYwPRFCTZ8iDnIbbUA/zh-cn_image_0000002641741336.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=FBC9B0E037BFCE3774F5A1FB9B445F7E8A48F8E60B030671A0F6A68DCBDF9659)

   2. 下载"测试工具安装包"以及《认证测试指导文档》。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/YqvyGmGIR2SezJKdJ2zlqw/zh-cn_image_0000002622915717.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=47A4A8276C472FB3100250B8657D6AC2A3F19E10DB127243C714C3EFBC6244C6)


   3. 根据指引，安装DECC测试工具。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/XcDflg1NQveYRa6ovMK4Yw/zh-cn_image_0000002622755851.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=9705235DAE0140ACDAFF3CB1C072DFF2B3C485CAECBE113F531A17F8A4ACDB02 "点击放大")


   4. 打开DECC工具，并使用与平台相同的帐号进行登录。
   5. 在工具中选择所创建的项目，DECC工具将根据认证产品软硬件规格中的集成开放能力来筛选测试用例。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/e7m4rExXTSGuG2BzrIzXmQ/zh-cn_image_0000002592436278.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=54D7A7D03AE045E781C0E6D5A07BB371E2308EDDF4A8DD970F260F4A8E8A8665 "点击放大")


   6. 按照工具指引和测试指导，完成设备自测试。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/FxYBOFStRYCl1qkjNzNMog/zh-cn_image_0000002592596198.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=14B737676FD827C69AA069209509B58DF6395A520C1E044F6369088FF3C1748E "点击放大")


   7. 通过工具上传测试结果至Device Partner平台。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a0/v3/FSpJV6n4T5ycas6Kkn_8bg/zh-cn_image_0000002622915719.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=231F702D9DA682327E77963B76124ACF18708185702F62D1F492E75F6433D59C "点击放大")

5. 在"OpenHarmony兼容性"页面，开展兼容性测试。

   > 说明
   >
   > 仅采用OpenHarmony的产品需要执行"兼容性测试"，其他操作系统的产品不涉及该环节。
   >
   > 兼容性测试报告上传后会自动进行AI预审，若预审不通过，会提示预审失败的原因，伙伴可根据失败原因进行相应的修改（预审结果仅供参考，不影响流程进行）。
   1. 下载兼容性测试指导。
   2. 选择报告类型并上传对应报告。
   3. 单击"提交"完成上传。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/fVG4ASYFRJKMhm-uOipomg/zh-cn_image_0000002622755853.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=F9DBEEF71197A4067EDD23AAA34DED0826857F58EDD946880642B5932CCDF9F3)

6. 在"其他产品报告"页面，上传测试报告并检测设备版本信息。

   1. 上传其他需提供的测试报告，并单击"提交"。 说明
      >
      > 不同开发方案所需上传的报告可能存在差异，请以实际界面为准。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/w_aJSOqiTLC-A8CqO5xBjA/zh-cn_image_0000002592436280.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=F02040179917B35C84EE69F0E43B9E580CF2E3262396C50E5D350454EA814411 "点击放大")
   2. 检测设备版本信息。 选择或填写设备SN号/UDID，并单击"获取"，可以获取设备上报给云端的版本信息。确认设备信息的准确性，并单击"提交"。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/pumHZusFSROcqXkGcQLX1Q/zh-cn_image_0000002592596202.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=50227E5CC10E6A4EAEC921A0E6E074C95E9B5B06874D70D279DB9E576035ED89 "点击放大")

7. 待产品开发操作全部执行完成后，可以单击页面底部的"提交认证申请"，进行产品认证。
