# 交互设计

#### App设计

* 进入App设计后，点击"升级为高级模式" 进入高级模式显示公版UI设计，并可对UI组件进行在线编辑。
* 可以在页面左侧通过拖/拽的形式，增加新增物模型对应的控件或重新选择原有控件样式。在右上角"组件逻辑配置"中可修改组件间受相互状态影响的逻辑。

![](https://media:801788415715647905 "点击放大")  
![](https://media:801788415715676906)  
1. 点击右上角"保存"图标功能仅保存页面编辑情况，不会应用于产品实际使用。
2. 页面下方"部署"按钮，会将当前设计应用于产品实际使用。
3. 每次修改物模型、物模型参数后均需要在交互设计页面再次部署后生效。

![](https://media:801788415715728907 "点击放大")

<br />

#### 页面配置

* 页面配置中产品图、配网指导描述为公版方案预置案例内容，需要根据产品实际情况进行替换。

产品图：

![](https://media:801788415715841908 "点击放大")

指导图：

![](https://media:801788415715912909 "点击放大")  
![](https://media:801788415715939910)  
产品图以及指导图中，产品背景请设置为透明，便于在系统切换深色模式时，提升用户体验。  

#### 多端适配

* 多端适配中包含中控屏开发、手机半模态、以及HarmonyOS NEXT交互页面配置。

![](https://media:801788415716220916 "点击放大")
