# 协议管理

登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，进入"管理中心"。在左侧导航栏选择"账号管理 \> 协议管理"，可以查看当前已签署的协议或者下载协议文件。  

#### 协议简介

|协议名称|主要用途|
|:--------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------|
|[华为智能硬件合作伙伴服务协议](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/devicepartneragreement-0000001091265548)|本协议是合作伙伴加入"华为智能硬件合作伙伴计划"的L1层协议，确立其作为华为智能硬件合作伙伴时享有的权利和承担的义务，是基础性的约定。|
|HarmonyOS Connect生态产品合作协议|本协议以《华为智能硬件合作伙伴服务协议》为基础，进一步确立合作伙伴与华为进行HarmonyOS Connect生态产品合作时享有的权利与承担的义务。|
|HarmonyOS Connect生态解决方案合作协议|本协议以《华为智能硬件合作伙伴服务协议》为基础，进一步确立合作伙伴与华为进行HarmonyOS Connect生态解决方案合作时享有的权利和承担的义务。|
|[关于华为智能硬件合作伙伴平台与隐私的声明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/privacystatement-0000001143256409)|本协议是华为与合作伙伴开展合作时关于隐私与安全的基础性约定。|
[表1 协议清单]

#### 协议相关操作

下载协议：单击"下载"，可以下载并查看协议内容。已签署的协议均支持下载。

解除协议：仅支持解除《关于华为智能硬件合作伙伴平台与隐私的声明》协议。单击"解除签署"，在确认提示框中单击"确定"，即可解除签署。  
![](https://media:201787206625479647)  
* 解除签署不会影响解除前基于合作伙伴同意的个人数据的合法性效力，也不影响基于其他正当性基础处理合作伙伴的个人数据。
* 解除签署后，无法再在平台内进行其他操作，必须再次同意签署，同意隐私声明中平台搜集个人数据的事项，才可进行业务操作。
