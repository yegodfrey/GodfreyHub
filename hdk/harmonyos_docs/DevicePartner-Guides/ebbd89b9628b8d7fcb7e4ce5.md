# HarmonyOS服务开放平台准备工作

1. 创建项目与服务、申请调测证书、并完成调测。参见[HarmonyOS服务开放平台 \> 调试HarmonyOS服务](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-0000001172419675)的"创建项目"至"本地开发和自测试"章节。
2. 申请发布证书与发布Profile。参见[HarmonyOS服务开放平台 \> 发布HarmonyOS服务](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-releaseservice-0000001126539888)的"申请发布证书"至"申请Profile"章节。
3. 使用发布证书对应的私钥，对HarmonyOS服务发布包进行签名。参见[配置签名信息](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/publish_app-0000001053223745#section280162182818)。
