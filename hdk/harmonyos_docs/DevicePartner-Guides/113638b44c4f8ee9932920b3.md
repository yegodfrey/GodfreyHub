# 登录与鉴权

本章节介绍运行在运动健康App的H5应用如何基于[华为帐号服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/account-guide-v4)进行登录与鉴权。

每个H5应用运行在运动健康App提供的独立容器中，当它需要运行与用户个人帐号相关联的业务时，需要调用登录接口登录华为帐号。登录成功后，才能访问运动健康App中的个人用户数据。

#### 开发步骤

登录授权分为：AT(AccessToken)模式或[AuthCode模式](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section1022911426469)，其中GPRS设备仅支持使用AuthCode模式。  

#### AT模式

调用登录接口[BasicLib.account.signIn](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-account-0000001181901252#section123194615477)进行登录，在then中处理登录成功的操作，在catch中处理登录失败或用户取消的操作：

```
BasicLib.account
.signIn({
  appid: "xxx", // 联盟上申请到的App ID
  useAuthCode: false,
  scopes: [
    "https://www.huawei.com/auth/account/base.profile",
    "https://www.huawei.com/healthkit/extend/device.read"
    // 根据业务添加所需SCOPE
  ],
})
.then((signInResult) => {
  // 登录成功，signInResult结果中包含了openId、AT、用户帐号基本信息
})
.catch((err) => {
  // 登录失败
});
```

如果用户授予了业务必需的权限，开发者无需关注AccessToken如何处理，即可在then方法中访问运动健康App对应的数据接口。  

#### AuthCode模式

使用AuthCode模式，可以与服务器共享AuthCode，定期使用AuthCode来获取AccessToken，以实现更复杂的业务逻辑。  
图2 AuthCode模式   
![](https://media:101783481636708917)  
![](https://media:101783481636733918)  
* AuthCode模式下需要严格保证时序，必须调用完bindAppId和bindAccessToken之后，才可以调用数据接口，否则会鉴权不通过。
* 服务器上需要定时刷新（或者调用时刷新）AccessToken，否则AT过期就会导致鉴权失败。

1. 使用AuthCode模式，仅需要将[BasicLib.account.signIn](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/health-app-api-account-0000001181901252#section123194615477)的useAuthCode参数设置为true。

   <br />

   ```
   BasicLib.account
   .signIn({
     appid: "xxx", // 联盟上申请到的App ID
     useAuthCode: true,
     scopes: [
       "https://www.huawei.com/auth/account/base.profile",
       "https://www.huawei.com/healthkit/extend/device.read",
       // 根据业务添加所需SCOPE
     ],
     redirectUrl: 'hms://redirect_uri'   // 值为在开发者联盟上申请appid时设置的回调地址
   })
   .then((signInResult) => {
     // 登录成功，signInResult结果中包含了openId、AuthCode、用户帐号基本信息
   })
   .catch((err) => {
     // 登录失败
   });
   ```

   <br />

2. 请参考[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)，将AuthCode上传到伙伴服务器，访问华为帐号云接口进行鉴权，获取AccessToken，再返回给H5应用使用。
3. H5应用获取到AccessToken之后，将其绑定到H5框架中，以供后续鉴权使用。

   <br />

   ```
   BasicLib.account.bindAccessToken(yourAt) // 传入拿到的AT，要求在有效期内
   ```

   <br />

至此，登录授权完成，如果用户授予了数据接口所需要的权限，那么后续可正常调用数据接口；如果用户未授权，则返回1001错误。
