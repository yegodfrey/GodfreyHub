# 信息展示

信息展示控件位于主控区，用于展示设备的信息，不响应用户的操作。信息展示控件一般按照使用频率和重要级别排序，合作伙伴也可根据业务需求进行自由排序。

![](https://media:101783481624025729 "点击放大")

类型

1. 空气指数
2. 设备信息
3. 安防设备列表
4. 门锁列表

#### 类型1：空气指数

构成

1. 主标题：指数评价信息。
2. 副标题：指数名称。
3. 数值：指数数值。

#### 类型2：设备信息

主要用于呈现设备相关的信息，一排可以放两个或三个信息参数，多于三个时可左右滑动。合作伙伴可根据功能自由定制。

构成

1. 主标题：检查到的数据值+单位。
2. 副标题：显示数据名称，如可点击进入下一层级，则使用箭头表示。

![](https://media:101783481624475737 "点击放大")

状态  

|在线|离线|
|![](https://media:101783481624507738 "点击放大")|![](https://media:101783481624535739 "点击放大")|
|:-------------------------------------------|:-------------------------------------------|
|主标题：检查到的数据值+单位 副标题：数据名称|开启状态+整体40%不透明度|

浅色模式

![](https://media:101783481624574740 "点击放大")

* 主标题数字大小：24sp，颜色#000000，90%不透明度，单位大小12sp，颜色#000000，60%不透明度
* 副标题文字大小：12sp，颜色#000000，60%不透明度
* 导航点大小12x8vp，选中颜色#0A59F7，圆点大小8x8vp，颜色#000000，10%不透明度

<br />

深色模式

![](https://media:101783481624612741 "点击放大")

* 主标题数字：颜色#FFFFFF，86%不透明度，单位颜色#FFFFFF，60%不透明度
* 副标题文字：颜色#FFFFFF，60%不透明度
* 导航点选中颜色：#317AF7，未选中颜色#FFFFFF，20%不透明度

<br />

界面用语超长处理

* 主文本和单位文本不支持换行，副文本支持换一行。

![](https://media:101783481624645742 "点击放大")

* 继续超长时，文字逐级缩小，主文本最小字号为14sp，单位文本和副文本最小字号为9sp。

![](https://media:101783481624680743 "点击放大")

* 依然超长，"..."截断处理。

![](https://media:101783481624717744 "点击放大")  

<br />
