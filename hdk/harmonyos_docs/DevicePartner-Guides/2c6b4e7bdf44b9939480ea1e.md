# 开发H5功能（BLE）

本章节介绍蓝牙BLE设备如何按照UI设计文件和Profile文件，实现H5功能开发。

H5页面根据Profile文件实现数据的组装，调用智慧生活App提供的JSAPI将数据传递给App的DeviceWebManage模块，该模块将最终配置数据下发给设备。因此，功能实现必须与Profile文件一致，才能保证功能的正常交互。  

#### 前提条件

* 已获取产品的Profile文件。获取方式参见[下载Profile文件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-offline-preparations-0000001241445441#ZH-CN_TOPIC_0000001241445441__li17977131171610)。
* 已获取"H5 Demo \> Vue Project"中的"BLE Demo"文件夹。获取方式参见[下载H5 Demo](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-offline-preparations-0000001241445441#ZH-CN_TOPIC_0000001241445441__li5952229182214)。
* 已获取[《蓝牙设备JSAPI接口参考》](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/bluetooth-overview-0000001090562401)。  

#### 设备与H5交互

以H5页面下发开关的命令为例：

1. 下发数据时，在[《蓝牙设备JSAPI接口参考》](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/bluetooth-overview-0000001090562401)中找到下发命令到设备接口：hilink.sendCommand()。
2. 根据接口文档，下发开关命令。命令中提交数据的json_body字段必须和profile一一对应。
   1. 在Profile文件中，查找开关对应的数据如下：  

      |服务 sid|服务(中文)|服务类型 ServiceType|属性|属性类型 Character Type|操作权限|数据类型|数据约束 (IT系统录入时使用)|取值范围|
      |:-----|:-----|:---------------|:-|:------------------|:-------------|:---|:---------------|:------|
      |switch|开关|-|-|-|-|-|-|-|
      |-|-|-|switch||PUT/REPORT/GET|bool|-|0-关 1-开|

   2. 在项目文件中，打开"src \> components \> HomeMode.vue"，在script标签中，添加如下代码：

      ```
      methods: {
          clickCell() {
              if (typeof hilink != "undefined") {
                  hilink.sendCommand(devId, mac, "switch", "on: 0",'SmartHomeUI.callback.sendCommandCallback');
              }
          }
      }
      ```

在Demo代码和工程中，使用了VUE工程内置Promise框架来封装HiLink接口和参数，因此调用[《蓝牙设备JSAPI接口参考》](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/bluetooth-overview-0000001090562401)中接口时传递的参数会相对简单。  
在util文件夹下的index.js文件中参考如下代码封装智慧生活App JSAPI接口和参数，调用方法名和智慧生活App JSAPI接口名相同。

```
export function generatePromise(args = {}) {
    //框架参数及回调方法
    let {
        type,
        method,
        params = [],
        callback,
        onCallback,
        afterHilinkCalled
    } = args;

    return new Promise((resolve, reject) => {
        try {
            //判断当前的hilink接口是否存在，method为hilink接口名
            if (
                !window.hilink ||
                !window.hilink[method]
            ) {
                console.hLog(`No ${method}`)
                return;
            }
            if (type === 'sync') {
                let value = window.hilink[method](...params);
                resolve(value);
            } else {
                //判断回调方法名
                let callbackName = callback ? callback : `${method}Callback`;
                //解析回调数据
                window[CALLBACKS][callbackName] = (res) => {
                    let result = jsonParse(res);
                    resolve(result);
                    if (onCallback && typeof onCallback === 'function') {
                        onCallback(result);
                    };
                }
		//hilink接口调用和参数传递
                window.hilink[method](...params, `${CALLBACKS}.${callbackName}`);
                if (afterHilinkCalled && typeof afterHilinkCalled === 'function') {
                    afterHilinkCalled();
                };
            }
        } catch (err) {
            console.hLog(err);
        }
    });
}
```

#### 设备连接

智慧生活App的H5卡片进入App.vue页面时，需要启动监听蓝牙的变化状态及数据的变化状态，使页面初始化状态正确。当设备的某个数据发生变化时，需要上报给H5。H5自动触发该函数，接收变化的数据，刷新界面。

1. 监听蓝牙状态变化。

   <br />

   在App.vue的初始化时，调用onBluetoothAdapterStateChange方法，监听蓝牙状态。手机主动打开或关闭蓝牙模块会触发此方法，拿到接口回调后，如果蓝牙是关闭状态，则调用openBluetoothAdapter方法来打开蓝牙连接提示框。

   ```
   onBluetoothAdapterStateChange({ state, dispatch }, payload = {}) { 
       let { callback } = payload; 
       // hilink.onBluetoothAdapterStateChange(callbackName)接口，蓝牙状态发生变化通过此callback返回
       return generatePromise({ 
           method: 'onBluetoothAdapterStateChange', 
           callback, 
           onCallback: (res = {}) => { 
               if (res.available === undefined) { 
                   return; 
               } 
               state.bleOn = res.available; 
               if (!res.available) { 
                   dispatch('openBluetoothAdapter') 
               } 
           } 
       }); 
   },
   ```

   <br />

2. 获取手机蓝牙状态。

   <br />

   在App.vue的初始化时，调用getBluetoothAdapterState方法，获取手机当前的蓝牙状态。手机蓝牙打开时才可进行后续步骤，若手机蓝牙状态为未开启，则调用openBluetoothAdapter方法，提示用户打开手机蓝牙功能。

   ```
   getBluetoothAdapterState({ state, dispatch }) { 
       // hilink.getBluetoothAdapterState(callbackName)接口，获取手机蓝牙当前状态
       return generatePromise({ 
           method: 'getBluetoothAdapterState' 
       }).then((res = {}) => { 
           if (res.available === undefined) { 
               return; 
           } 
           state.bleOn = res.available; 
           if (!res.available) { 
               dispatch('openBluetoothAdapter') 
           } 
       }); 
   },
   ```

   <br />

3. 获取云侧的设备缓存信息，并保存到本地。

   <br />

   1. 在App.vue的初始化时，调用getCurrentRegisteredDevice方法获取设备信息。调用成功后，在回调中将获取云侧缓存数据，保存到store文件夹下的index.js的对应数据。

      ```
      this.getCurrentRegisteredDevice() 
      .then((res = true) => { 
           if (res) { 
                this.loading = false; 
           } else { 
            this.$router.push('/security'); 
            setTimeout(() => { 
                     this.loading = false;

          } 
      });
      ```

   2. 调用getCurrentRegisteredDevice方法，使H5保存获取到的云侧缓存的设备信息。

      ```
      getCurrentRegisteredDevice({ state, commit, dispatch }) { 
          //hilink.getBluetoothAdapterState(callbackName)接口，获取手机蓝牙当前状态
          return generatePromise({ 
              method: 'getCurrentRegisteredDevice' 
          }).then((res = {}) => { 
              // 获取到devId和MAC后订阅设备消息 
              state.devId = res.hilinkDevId; 
              state.mac = res.deviceId; 
              state.role = res.role; 

              if ( 
                  res.hilinkDeviceEntity && 
                  res.hilinkDeviceEntity.services 
              ) { 
                  let result = res.hilinkDeviceEntity, 
                      services = result.services, 
                      devInfo = result.devInfo || {}; 
                  // 更新设备ID,名称 
                  commit('UPDATE_DEVICE_INFO', { 
                      devId: result.devId, 
                      devName: result.devName, 
                      otaVersion: devInfo.fwv && 
                          devInfo.hwv && 
                          `${devInfo.fwv}(${devInfo.hwv})` || 
                          '' 
                  }); 
                  for (var i = 0; i < services.length; i++) { 
                      commit('UPDATE_CLOUD_DATA', services[i]); 
                  } 
              } 
          }); 
      },
      ```

4. 订阅蓝牙事件。

   <br />

   1. 在store文件夹中的index.js中，编写canConnect方法，判断当前蓝牙状态，devId和MAC值是否为空。

      ```
      canConnect(state) {
          if (
              state.bleOn &&
              state.devId &&
              state.mac
          ) {
              return true;
          }
          return false;
      },
      ```

   2. 在App.vue中的watch监听中调用canConnect方法，如果获取到devId和MAC值，则调用actionBle中的subscribeBleEvent订阅蓝牙事件接口。

      ```
      canConnect: {
          handler(val) {
              if (!val) return;
              //订阅蓝牙事件接口
              this.subscribeBleEvent();
          },
      }
      ```

   3. 如果已连接并获取到值后，调用subscribeBleEvent接口，订阅蓝牙消息，并处理设备返回的消息数据，根据实时的数据来刷新页面显示。  
      ![](https://media:101783481639374953)  
      数据格式必须与Profile规范保持一致。

      ```
      subscribeBleEvent({ state, commit, dispatch }, payload = {}) {
          /**
           * 订阅蓝牙消息
           * 调用subscribeBleEvent接口所需要传递的参数
           * @param deviceId 设备ID
           * @param bleMac 设备MAC地址
           * @param resultCallback 回调
           */
          let { params = [state.devId, state.mac] } = payload;
          
          //hilink.subscribeBleEvent(String deviceId, String bleMac, final String resultCallback)接口，订阅蓝牙事件
          return generatePromise({
              method: 'subscribeBleEvent',
              params,
              onCallback: (res = {}) => {
                  if (res.type === 'ConnectionStateChange') {
                      switch (res.newStatus) {
                          case 0: // 已断连
                          case 1: // 连接中
                          case 2: // 已连接
                          case 3: // 断连中
                              state.connectStatus = res.newStatus;
                              if (res.newStatus === 0) {
                                  state.connectOk = 0;
                                  try {
                                      window.connectBreakCallback()
                                  } catch (error) {
                                      console.log(error);
                                  }
                              }
                              break;
                          default:
                              break;
                      }
                  } else if (res.type === 'CharacteristicChanged') {
                      commit('UPDATE_STATE', {
                          name: 'NoControl',
                          value: true
                      });
                      let content = (
                          res.content &&
                          res.content.vendor
                      ) ? res.content.vendor : res.content;

                      //根据不同的数据格式添加对应的数据格式
                      //如果格式不正确会导致控制按钮无法点击或者按钮状态和文字描述不一致
                      if(content.sid === "deviceStatus"){
                          for(let i = 0; i< content.data.length; i++)
                          {
                              let sid = content && content.data[i].sid;
                              let data = content && content.data[i];
                              if (
                                  !content ||
                                  !sid ||
                                  !data
                              ) {
                                  return;
                              }
                              // 更新设备上报
                              commit('UPDATE_DEVICE_DATA', content.data[i]);
                          }
                      }
                      else if(content.services !== undefined){
                          for(let i =0; i<content.services.length; i++)
                          {
                              let sid = content && content.services[i].sid;
                              let data = content && content.services[i];
                              if (
                                  !content ||
                                  !sid ||
                                  !data
                              ) {
                                  return;
                              }
                              // 更新设备上报
                              commit('UPDATE_DEVICE_DATA', content.services[i]);
                          }
                      }
                      else{
                          let sid = content && content.sid;
                          let data = content && content.data;
                          if (
                              !content ||
                              !sid ||
                              !data
                          ) {
                              return;
                              }
                              // 更新设备上报
                              commit('UPDATE_DEVICE_DATA', content);
                      }
                  }
              }
          });
      },
      ```

   <br />

5. 连接蓝牙，更新H5页面显示。

   <br />

   1. 连接蓝牙过程和订阅蓝牙事件过程类似，需要先获取到deviceID和MAC值，再进行蓝牙连接。在App.vue中的watch监听中调用canConnect方法，调用subscribeBleEvent订阅蓝牙事件接口后，增加调用连接蓝牙接口。若某些设备在连接蓝牙过程中失败率较高，可以将蓝牙连接逻辑改为三次连接机制，增加蓝牙连接成功率。

      ```
      canConnect: {
          handler(val) {
              if (!val) return;
              //订阅蓝牙接口
              this.subscribeBleEvent();
              //连接蓝牙接口
              this.connectBle();
              var that = this;
              if (this.connectOk !== 2) {
                  this.UPDATE_STATE({
                    name: "connectOk",
                    value: 1,
                  });
                  var i = 1;
                  var timer = setInterval(function () {
                    if (i === 2) {
                      clearInterval(timer);
                    }
                    i++;
                    that.setintervalFunction();
                  }, 9000);
                }
              },
            },
      ```

      action.js中添加如下函数：

      ```
          // 设置两次回调重连
          setintervalFunction({state, getters, dispatch}) {
              if (!state.bleOn) {
                  dispatch('openBluetoothAdapter');
                  return;
              }
              // 规避重连失败，需要先断连再重连
              dispatch('disconnectBle').then((res = {}) => {
                  console.hLog(`断连回调:${JSON.stringify(res)}`);
                  dispatch('subscribeBleEvent');
                  dispatch('connectBle');
              });
          },
      ```

      <br />

   2. 连接蓝牙，根据连接状态回调更新H5页面显示。
      * 连接成功：

        ```
        connectBle({ state, commit, dispatch }, payload = {}) {
            /**
             * 连接蓝牙
             * 调用connectBle接口所需要传递的参数
             * @param deviceId 设备ID
             * @param bleMac 设备蓝牙MAC地址
             * @param resultCallback 回调
             */
            commit('UPDATE_STATE', {
                name: "connectOk",
                value: 1 // 设备连接中
            });
            let { params = [state.devId, state.mac] } = payload;

            return Promise.race([
                //hilink.connectBle(String deviceId, String bleMac, final String resultCallback)接口，连接蓝牙
                generatePromise({
                    method: 'connectBle',
                    params,
                    callback: `connectBleCallback${new Date().getTime()}`
                }),
            ]).then((res = {}) => {
                commit('UPDATE_STATE', {
                    name: "connectOk",
                    value: res.errcode === 0 ? 2 : 0
                });
                if (res.errcode === 0) {
                    // 连接成功后，给设备同步时间
                   // formatUTCDate该方式是将本地时间转成UTC时间，需要自己实现
                    dispatch("sendCommand", {
                        data: {
                            sid: 'deviceTime',
                            data: {
                                time: formatUTCDate(new Date(), true)
                            }
                        },
                        toast: false
                    });
                    // 连接成功后重新连接的次数归零
                    commit('UPDATE_STATE', {
                        name: 'reConnectCount',
                        value: 0
                    });
                }
            });
        },
        ```

      * 连接失败： 连接失败有三种情况，详细说明如下：

        * 连接超时：设备侧响应超时，连接失败
        * 蓝牙关闭：当前手机蓝牙未开启，连接失败。
        * 异常连接：手机侧或设备侧异常，导致连接失败。

        当设备正常连接失败或者异常断开连接时，需要进行设备重连。具体步骤如下。
        1. 断开蓝牙连接。  
           判断蓝牙状态，如果是已连接状态，则调用disconnectBle接口，实现断开蓝牙。

           ```
           disconnectBle({ state }, payload = {}) {
               /**
                * 断开蓝牙
                * 调用disconnectBle接口所需要传递的参数
                * @param deviceId 设备ID
                * @param mac 设备MAC地址
                * @param resultCallback 回调
                * 
                */
               let { params = [state.devId, state.mac] } = payload;
               //hilink.disconnectBle(String deviceId, String bleMac, final String resultCallback)接口，断开蓝牙连接
               return generatePromise({
                   method: 'disconnectBle',
                   params
               });
           },
           ```

        2. 重新连接。  
           在HomeStatusBar.vue文件中编写reconnect方法，首先判断当前的蓝牙开启状态，然后先断开连接再重新调用subscribrBleEvent接口订阅蓝牙消息和connectBle接口连接蓝牙，并刷新重连次数。

           ```
           reconnect() {
               if(!this.bleOn) {
                   this.$store.dispatch('openBluetoothAdapter');
                   return;
               }

               // 规避重连失败，需要先断连再重连
               this.disconnectBle().then((res = {}) => {
                   this.subscribeBleEvent();
                   this.connectBle();  
                   // 记录重新连接的次数
                   this.UPDATE_STATE({
                       name: 'isReconnect',
                       value: true
                   });
               });
           },
           ```

#### 设备控制

在完成设备连接之后，就可以进行设备控制操作。设备控制通过给设备发送控制命令，以进行设备数据通信，解析数据，获取信息，完成设备控制。

1. 发送控制指令。

   <br />

   调用sendCommand接口，发送deviceID和MAC，以及需要控制的sid和data。sid取值在profile中查找相对应的值。

   ```
   sendCommand({ state , commit }, payload = {}) {
       /**
        * 修改蓝牙设备属性
        * 调用sendCommand接口所需要传递的参数
        * @param deviceId 设备ID
        * @param bleMac 设备MAC地址
        * @param serviceId sid
        * @param data 下发命令数据
        * @param resultCallback 回调
        */
       if (state.controlling) {
           console.hLog('受控中');
           commit('UPDATE_STATE', {
               name: 'NoControl',
               value: true
           });
           Toast(i18n.t('controlling'));
           return;
       }
       commit('UPDATE_STATE', {
           name: 'NoControl',
           value: false
       });
       let { params = [state.devId, state.mac], data = '{}', toast = true } = payload;
       let orignData = data;
       typeof data === 'string' && (data = JSON.parse(data))
       let serviceId = data.sid;
       data = typeof data.data === 'string' ? data.data : JSON.stringify(data.data);
       let method = 'sendCommand';
       let param = method === 'sendCommand' ? [...params, serviceId, data] : [...params, JSON.stringify(orignData)]
       //hilink.sendCommand (String deviceId, String bleMac, String serviceId, String data, final String resultCallback)接口，下发蓝牙设备控制命令或查询设备状态
       return generatePromise({
           method: method,
           params: param,
           afterHilinkCalled:() => {
               state.controlling = true;
           }
       }).then((res = {}) => {
           state.controlling = false;
           console.hLog('下发回调:', JSON.stringify(res));
           if (res.errcode !== 0 && toast) {
               Toast(i18n.t('control_fail'))
           }
           return res;
       });
   },
   ```

   <br />

2. 控制成功，H5页面刷新。

   <br />

   控制成功后，设备侧会通过subscribeBleEvent订阅蓝牙接口推送对应的数据，H5通过解析数据对页面进行刷新。

   以设备开关为例，代码参考如下。

   ```
   //控制设备开关
   controlAppliance(){
       this.sendCommand({
           data: {
               sid: 'switch',
               data: {
                   on: Number(!this.Switch)
               }
           }
       })
   }
   ```

#### 设备删除

点击设备删除，首先判断是否为共享设备：

* 共享设备：没有删除权限。
* 非共享设备：先给设备发重置命令，再删除蓝牙信息，最后删除云端设备。删除成功后退出到智慧生活设备列表界面。

1. 下发重置命令。

   <br />

   调用async FactorsetReset接口，下发重置命令，使蓝牙设备恢复出厂设置。

   ```
   async FactorsetReset(){
       // 下发重置
       let reset = await this.sendCommand({
           data: {
               sid: 'factoryReset',
               data: {
                   on: 1
               }
           }
       });
       if (reset && reset.errcode) {
           this.$toast(this.$t('reset_fail'));
           return;
       }
       // 删除蓝牙信息
       let clear = await this.clearBleRegInfo();
       if (clear && clear.errcode) {
           this.$toast(this.$t('reset_fail'));
           return;
       }
       // 删除云端设备
       let delDev = await this.deleteDevice();
       if (delDev && delDev.errcode) {
           this.$toast(this.$t('reset_fail'));
           return;
       }
       this.finishDeviceActivity();
   }
   ```

   <br />

2. 删除蓝牙信息。

   <br />

   调用clearBleRegInfo接口，清除设备缓存，清除用户注册信息。

   ```
   clearBleRegInfo({ state }, payload = {}) {
       /**
        * 清除BLE用户注册信息
        * 调用clearBleRegInfo接口所需要传递的参数
        * @param deviceId 设备ID
        * @param bleMac 设备MAC地址
        * @param resultCallback 回调
        */
       let { params = [state.devId, state.mac] } = payload;
       //hilink.clearBleRegInfo(String deviceId, String bleMac, final String resultCallback)接口，删除设备侧BLE用户信息
       return generatePromise({
           method: 'clearBleRegInfo',
           params: [...params]
       });
   }
   ```

   <br />

   ```
   // 获取app版本
   getAppVersionCode() {
       try {
           if (window.hilink.getSystemInfoSync) {
               window.hilink.getSystemInfoSync('bleAppVersionCodeCallback');
               window.bleAppVersionCodeCallback = res => {
                   const data = jsonParse(res);
                   let version = String(data.version);
                   if (version.length >= 10 && !version.includes('.')) {
                       version = version.slice(3);
                   }
                   window.APPVersionCode = version;
               };
           }
       } catch (error) {
           console.log('getAppVersionCode error');
        }
   },
   // 当前app版本是否大于等于目标版本(13.0.5.310)
   isLaterAppVersion({ dispatch }, targetVersion) {
       const curVersion = String(window.APPVersionCode || '13.0.0.0');
       let isLater = false;
       if (curVersion.includes('.')) {
           const target = targetVersion.split('.');
           const current = curVersion.split('.');
           let length = current.length;
           if (current.length >= target.length) {
               isLater = true;
               length = target.length;
           }
           for (let i = 0; i < length; i++) {
               if (Number(current[i]) !== Number(target[i])) {
                   isLater = Number(current[i]) > Number(target[i]);
                   break;
               }
           }
       } else {
           let newVersion = String(targetVersion).replace(/\./g, '');
           isLater = Number(curVersion) >= Number(newVersion);
       }
       return isLater;
   }
   ```
