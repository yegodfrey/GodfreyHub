# 自定义流程开发

如果您需要进行自定义流程，请参阅本章节进行开发，如您不需要自定义流程，请跳过本章节。  

#### 自定义配对流程

entry/src/main/js/connection/pages/index/index.js文件蓝牙回调处理部分供伙伴自定义流程：

```
  bleConnectionStateCallback(connectionState) {
    console.debug(JS_TAG + 'Connection state changed: ' + JSON.stringify(connectionState));
    this.deviceConnected = connectionState.isConnected;
    // 可以在设备上报已连接状态时，启动发现服务，并自行增加读特征值、写描述符的过程
    if (!this.deviceConnected) {
      this.onDevcieConnectFailed();
    }
  },
  bleServiceDiscoveredCallback(bleServiceDiscoveredResult) {
      this.deviceConnected && bleServiceDiscoveredResult.isDiscoverySuccess ?
      this.onServiceDiscoveredSuccess() : this.onServiceDiscoveredFailed();
  },
  bledevicefoundcallback(foundDevices) {
    console.debug(JS_TAG + 'bluetoothDeviceFoundCallback: ' + JSON.stringify(foundDevices))
    // 可以将此处修改为自定义的配对逻辑
    for (let device of foundDevices) {
      if (device.deviceId == this.macAddress) {
        this.onTargetDeviceFound(device.deviceId);
        return;
      }
    }
  },
  bleCharacteristicChangeCallback(bleCharacteristicChangeValue) {
    // 特征值变化上报回调，可以在此处根据上报的特征值变化数据，增加自定义处理逻辑
    console.debug(JS_TAG + 'change data: ' + JSON.stringify(bleCharacteristicChangeValue.characteristicData));
  },
  ...
  enableNotifyAndIndicate() {
    // 自定义增加需要监听的Notify或者Indicate特征值列表
    hekOperator.notifyBleCharacteristicValueChange({
      deviceId: this.macAddress,
      serviceId: config.serviceUuid,
      characteristicId: config.characterUuid,
      enableNotify: true, // true for notify, and false for indicate
      success: () => {
        console.debug(JS_TAG + 'Enable notify and indicate success!');
      },
      fail: (errorCode, errorMessage) => {
        console.error(JS_TAG + 'Enable notify and indicate error, errorCode is ' + errorCode + ', message is ' + JSON.stringify(errorMessage));
        this.onEnableNotifyFailed(errorCode, errorMessage);
      }
    });
  }
```

#### 自定义解析流程

src/main/js/sdashboard/pages/index/index.js文件的最后部分供伙伴自定义蓝牙交互流程：

```
  async enableNotifyAndIndicate() {
    // 自定义增加需要监听的Notify或者Indicate特征值列表
    hekOperator.notifyBleCharacteristicValueChange({
      deviceId: this.macAddress,
      serviceId: SERVICE_UUID,
      characteristicId: CHARACTER_UUID,
      enableNotify: ENABLE_NOTIFY,
      success: () => {
        console.debug(JS_TAG + 'Enable notify and indicate success!');
      },
      fail: (code, err) => {
        console.error(JS_TAG + 'Enable notify and indicate error, code is ' + code + ', message is ' + JSON.stringify(err))
      }
    });
  },
  onBleCharacteristicValueChange(callbackJson) {
    // 监听的特征值变化时的回调，根据上报的特征值UUID，解析数据，自行增加相应的处理逻辑
    let result = dataParser.dealWithCharacteristicValue(bleCharacteristicChangeValue.deviceId, callbackJson.data.characteristicId,
      callbackJson.data.changeData);
    console.debug(JS_TAG + 'onBleCharacteristicValueChange result = ' + result);
  }
```
