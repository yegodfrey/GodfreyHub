# 认证标准的版本变更说明

由于认证标准处于持续优化的过程中，每套认证标准均存在一定的有效期。

* 优先推荐采用最新版本的认证标准，当前最新的认证标准是V2.2版本。
* 对于自测试阶段已经采用V2.1版本的产品，在预约认证的时候也支持继续沿用历史版本的认证标准。
* V2.0以前的版本已下线，V2.0按公告计划实施下线。
