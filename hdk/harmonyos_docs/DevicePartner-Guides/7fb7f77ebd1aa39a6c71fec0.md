# 成为合作伙伴

本章节介绍如何成为华为智能硬件生态合作伙伴。成为合作伙伴之后，可以依托平台提供的能力、服务与解决方案，实现全场景生态的共建、共享和共赢。  
![](https://media:201787206625538648)  
本章节仅适用于企业账号，不适用于个人账号。

企业账号的所有者加入合作伙伴计划之后，可以[邀请成员](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/team-account-0000001165794929#section185000910571)加入团队，共同参与项目开发与管理。  

#### 操作流程

|序号|步骤|说明|
|:-|:--------------------------------|:-----------------------------------------|
|1|[注册华为账号](#section124845573434)|支持通过手机号码或电子邮箱注册华为账号。|
|2|[完成企业实名认证](#section1429545219459)|必须完成企业实名认证，支持对公银行打款认证和企业资料人工审核认证两种方式。|
|3|[签署协议](#section15936423144510)|首次登录平台管理中心，需要签署协议，才能加入合作计划。|
|4|[加入合作伙伴计划](#section5521953154618)|根据业务需求和合作意向，选择加入匹配的合作伙伴计划，获取对应的业务能力和技术支持等。|
[表1 操作流程说明]

#### 注册华为账号

1. 打开[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn)。
2. 注册华为账号。

   <br />

   ![](https://media:201787206625570649)  
   如果已有华为账号，请跳过该步骤，直接[登录平台管理中心](#ZH-CN_TOPIC_0000001134281535__li417754734512)。
   1. 单击右上角的"注册"，进入注册页面。
   2. 通过电子邮箱或手机号码注册华为账号。
      * 如果选择"手机号码注册"，输入正确的手机号码和验证码，设置密码后，单击"注册"。
      * 如果选择"电子邮箱注册"，输入正确的电子邮箱地址和验证码，设置密码后，单击"注册"。
   3. 阅读[《华为帐号用户协议》](https://id1.cloud.huawei.com/AMW/portal/agreements/userAgreement/zh-CN_userAgreement.html?version=china)和[《关于华为帐号与隐私的声明》](https://id1.cloud.huawei.com/AMW/portal/agreements/accPrivacyStatement/zh-CN_accPrivacyStatement.html)，单击"同意"。

      注册成功后进入实名认证页面，[完成企业实名认证](#section1429545219459)。

   <br />

3. 登录平台管理中心。

   <br />

   1. 单击[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn)右上角的"管理中心"，进入登录页面。
   2. 输入账号、密码和短信验证码后，单击"授权并登录"。
      * 如果未完成实名认证或实名认证失败，单击"企业实名认证"，进入实名认证页面，执行[完成企业实名认证](#section1429545219459)。
      * 如果已完成实名认证，但未签署协议，执行[签署协议](#section15936423144510)。
      * 如果实名认证审核中，请等待实名认证通过。

   <br />

#### 完成企业实名认证

伙伴登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn)的管理中心后，如果界面提示"尚未认证"，则需要单击"企业实名认证"，完成企业实名认证。  
企业账号的实名认证可采用以下任一方式：

* 方式一：对公银行打款认证
  1. 选择"对公银行打款认证"。
  2. 完善企业基本信息和企业银行账户信息。  
     ![](https://media:201787206625601650)  
     企业基本信息必须和企业营业执照上信息保持一致。
  3. 勾选"我已阅读并同意《华为开发者联盟与隐私的声明》"和"我已阅读并同意《开发者联盟企业认证信息共享协议》"，单击"下一步"。 系统会发送邮件和短信通知您已发起打款申请。通知发出后30分钟\~3工作日内，尾号为0505的联盟账户将向您提供的银行账户打一笔小于1元的款项。

  4. 输入打款金额。 在收到打款申请通知后的3个工作日内，请关注对公账户。

     收到打款后，登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/develop/)，单击右上角的"管理中心"。在左侧菜单栏选择"开发者中心 \> 设置 \> 开发者信息"进入打款金额页面，输入打款金额。
  5. 单击"提交认证"，系统自动审核。
     * 如果填写的金额正确，实名认证通过。
     * 如填写的金额错误，实名认证失败。根据报错提示信息，重新输入金额或者重新打款认证。 输入金额错误达到两次后，可以选择"重新打款认证"，之前填写的认证信息会保留，需要重新获取验证码。

* 方式二：企业资料人工审核认证
  1. 选择"企业资料人工审核认证"。
  2. 完善企业信息。（标有红色星号\*的项目是必填项）  
     ![](https://media:201787206625633651)  
     企业基本信息必须和企业营业执照上信息保持一致。
  3. 勾选"我已阅读并同意《华为开发者联盟与隐私的声明》"和"我已阅读并同意《开发者联盟企业认证信息共享协议》"，单击"下一步"。
  4. 等待审核。 审核结果会在1\~2个工作日发送至联系人邮箱，也可以在平台可以查看审核进展。

#### 签署协议

企业实名认证通过后，首次登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn)的管理中心，需要签署协议，才能加入合作计划。

1. 阅读《关于华为智能硬件合作伙伴门户与隐私的声明》，勾选"我已阅读并同意以上内容"，单击"同意" 。
2. 阅读《华为智能硬件合作伙伴服务协议》，勾选"我已阅读并同意以上内容"，单击"同意"，完成协议签署。  

#### 加入合作伙伴计划

根据业务需求和合作意向，选择加入匹配的合作伙伴计划，获取对应的业务能力和技术支持等。

1. 在管理中心左侧导航栏中，选择"账号管理 \> 合作计划"。
2. 选择需要加入的合作计划。

   <br />

   * HarmonyOS Connect生态产品合作伙伴 此计划需要申请加入，操作步骤如下：

     1. 单击"申请"。
     2. 根据界面提示信息，填写"主营业务"和"需求描述"。
     3. 单击"确定"提交申请，等待审批完成。 审批结果将以邮件形式发送到邮箱。如果未提供联系邮箱，也可以登录管理中心查看审批进展。与此同时，也可以继续申请其他计划。

     4. 审批通过后，进入管理中心，签署《HarmonyOS Connect生态产品合作协议》之后，即可加入当前计划。  
        ![](https://media:201787206625658652)  
        签署《HarmonyOS Connect生态产品合作协议》时，可以根据实际需要，同时选择签署下方的《华为合作伙伴付费服务协议》及《鲸鸿动能广告服务协议》。
        * 同意签约后，可以享受商家专属广告权益。
        * 不同意签约，并不影响成为HarmonyOS Connect生态产品合作伙伴。如果后续有相关诉求，可以登录[鲸鸿动能](https://ads.huawei.com/usermgtportal/home/index.html#/)官网进行签约。

        ![](https://media:201787206625703653)
   * HarmonyOSConnect生态解决方案合作伙伴 此计划需要申请加入，操作步骤如下：

     1. 单击"申请"。
     2. 根据界面提示信息，填写"主营业务"和"需求描述"。
     3. 单击"确定"提交申请，等待审批完成。 审批结果将以邮件形式发送到邮箱。如果未提供联系邮箱，也可以登录管理中心查看审批进展。与此同时，也可以继续申请其他计划。

     4. 审批通过后，进入管理中心，签署《HarmonyOS Connect生态解决方案合作协议》之后，即可加入当前计划。
   * HUAWEI HiCar汽车硬件合作伙伴 HUAWEI HiCar（以下简称HiCar）是华为提供的人-车-家全场景智慧互联（HUAWEI HiCar Smart Connection）解决方案，成为HUAWEI HiCar合作伙伴可查看[合作准入申请](https://device.harmonyos.com/cn/docs/devicepartner/DP-HiCar-Guides/apply-cooperation)，完成华为帐号注册与企业实名认证，并加入合作伙伴计划，成为HUAWEI HiCar汽车硬件合作伙伴。

   * 实验室 此计划当前只支持定向邀请，暂不可公开或申请加入。

   <br />
