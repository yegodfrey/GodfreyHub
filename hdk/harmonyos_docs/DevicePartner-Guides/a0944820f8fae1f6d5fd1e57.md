# 概述  
  
星闪（NearLink），新一代无线短距通信技术。面向万物互联时代，星闪引入关键技术和创新理念，赋予智能终端新的连接方式。与传统短距传输技术方案相比，星闪时延低，同步精度高，抗干扰能力强。在功耗、速度、覆盖范围和连接性能全面领先，可以在智能终端、智能家居、智能汽车、智能制造等各类细分场景下实现更极致的用户体验。

合作伙伴在开发星闪SLE设备时，需要严格遵循该规范，以确保设备能够顺利接入HarmonyOS Connect生态。如无特殊说明，本规范中的“设备”特指星闪SLE设备。

本规范适用于采用“HarmonyOS Connect极小硬件方案（星闪）”的场景。

本规范中未规定的内容，与标准星闪协议规范一致。

#### 网络架构

星闪SLE设备支持通过直连模式与网关模式两种方式实现连接控制，如图1所示。

  * 直连模式：手机等设备的智慧生活App可以直接连接星闪SLE设备，并将获取到的设备信息注册到HarmonyOS Connect云。直连模式只能在一定范围内对星闪SLE设备进行连接和控制，不支持远程控制与多设备联动。
  * 网关模式：如果希望实现星闪SLE设备的远程控制与场景联动，则需要通过星闪SLE网关将设备接入网络。此时，用户可以通过手机应用（比如智慧生活App），发送控制指令，经过路由器，再经过网关，控制家中的设备。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/uWUzzfuiRa62yv5mIIceSA/zh-cn_image_0000002484824534.png?HW-CC-KV=V1&HW-CC-Date=20261005T090900Z&HW-CC-Expire=86400&HW-CC-Sign=38935A97DC782777DE8C97703946DFCCC61DD1D8E382B2B95D7C910B7C23737F)

如果同时支持上述两种模式，必须确保在不同场景下直连模式与网关模式能够平滑切换，避免对用户体验的影响。例如：

  * 当星闪SLE设备通过智慧生活App完成连接和代理注册后，如果家中新增接入星闪SLE网关，设备需要支持从直连模式自动切换至网关模式，无需用户恢复出厂设置。
  * 当星闪SLE设备接入星闪SLE网关后，如果网关下电，设备需要支持从网关模式自动切换至直连模式，重新恢复与手机的连接。



整体流程

设备接入流程主要包括设备发现、设备连接与注册、设备控制等阶段，如图2所示。其中，主控设备可以表示手机（或平板）、星闪网关等设备。

设备升级流程在升级流程中展开详细介绍。

  1. 设备发现：支持通过星闪靠近发现、星闪碰一碰、或NFC碰一碰的方式来发现设备。
     * 星闪靠近发现：遵循[星闪广播规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/device-development-specifications-0000002516863645)。
     * 星闪碰一碰：遵循[星闪广播规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/device-development-specifications-0000002516863645)。
     * NFC碰一碰：遵循NFC标签认证要求。
  2. 设备连接与注册、以及设备控制：遵循[设备连接控制规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/development-specifications-0000002516983629)。
  3. 设备升级：遵循[设备升级规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/device-upgrade-specifications-0000002484823692)。
