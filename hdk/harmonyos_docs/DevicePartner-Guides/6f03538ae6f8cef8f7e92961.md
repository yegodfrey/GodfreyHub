# 服务上架

1. 开发者完成原子化服务开发后，需要打包成APP，并发布到华为应用市场。具体操作请参考[应用发布](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/publish_app-0000001053223745#section6406135115814)。
2. 提供以下信息给到华为技术接口人，申请应用访问服务权限。

   <br />

   * 包名：[创建HarmonyOS应用](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-for-health-kit-0000001126264886#section17341840271)时的包名，例如com.huawei.health.ecology.fa。
   * [SHA256证书指纹](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-for-health-kit-0000001126264886#ZH-CN_TOPIC_0000001126264886__li1033121644812)：由"\*\*\*.p12"文件生成。
   * prodId、deviceTypeId和manufacturerId：在Device Partner平台的"产品开发"页面，单击"导出"可以获得产品基础信息，如[图1](#ZH-CN_TOPIC_0000001126105074__zh-cn_topic_0000001182777251_fig1714965694915)所示。  
     图1 导出产品信息

   <br />
