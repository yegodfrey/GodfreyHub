# 标准协议

标准蓝牙BLE设备连接流程如下图所示：

![](https://media:101783481646519026)

其中，通过config.js中的scanRequired字段，可以控制配对流程：

* scanRequired为true时，原子化服务将尝试搜索设备，并连接搜索到的设备。
* scanRequired为false时，服务直接通过蓝牙mac地址尝试连接设备，此方式要求设备NFC卡片中包含完整的蓝牙mac地址。
