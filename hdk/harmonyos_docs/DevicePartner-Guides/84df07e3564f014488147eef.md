# 简介

目前支持体脂秤、血糖仪、血压计和心率设备通过Native方案接入华为运动健康App。  

#### 健康设备接入运动健康App的使用体验

#### 手机一碰联健康设备使用体验

当前血压计、血糖仪支持一碰联功能，后续其他健康设备将逐步支持。  
图1 血压计一碰联   
![](https://media:101783481642394985)

* 秒级互联。通过手机NFC一碰联或者二维码扫描快速连接健康设备。
* 一步直达。手机NFC一碰联，无需打开App，直达健康测量页面。
* 健康数据同步。自动同步健康测量数据到App，省去手工记录的操作。  

#### 华为运动健康App添加健康设备的使用体验

用户打开运动健康App，点击"添加设备"，选择某一款设备后，可以看到该设备的详细信息。对于已经拥有设备的用户，可以在该页面进行绑定设备的操作。  
图2 添加设备   
![](https://media:101783481642431986 "点击放大")

用户通过运动健康App绑定设备后，根据操作指导进行测量。测量结束后，数据会传输到手机并在运动健康App上呈现出来。
