# 日志获取

## 如何从DevEco Studio导出原子化服务项目日志

原子化服务功能调试失败时，可以从DevEco Studio中导出项目日志用于问题定位。

1. 确认原子化服务项目处于运行状态。
   1. 在DevEco Studio中打开原子化服务项目。
   2. 选择"Run > run"。


2. 在电脑中运行cmd命令。


3. 执行如下命令，清理历史日志。

   ```screen
   hdc shell hilogcat -c
   ```


4. 执行如下命令，将日志文件导出到指定文件路径中。以D盘的"log.txt"文件为例。

   ```screen
   hdc shell hilogcat start hilog > D:\log.txt
   ```


5. 重新执行一遍引起当前问题的操作。


6. 按**Ctrl+C键**，结束日志导出。

如果无法自助解决问题，可以压缩日志文件，提供问题现象录屏，发给华为技术支持人员进行定位。

## 如何获取智慧生活App（Android）和智慧生活基础服务的日志

* 方式一：通过命令方式获取日志。
  1. 在电脑中运行cmd命令。
  2. （可选）执行如下命令，清除智慧生活App和智慧生活基础服务历史日志。 说明
     >
     > 针对必现的场景，建议先清除历史日志，再复现问题获取日志。

     ```screen
     adb shell rm -r /sdcard/Android/data/com.huawei.smarthome/files/Log/*
     adb shell rm -r /sdcard/Android/data/com.huawei.hilink.framework/files/Log/com.huawei.hilink.framework/*
     ```

  3. 重新执行一遍引起当前问题的操作。
  4. 执行如下命令，获取智慧生活App和智慧生活基础服务的日志。

     ```screen
     adb pull /sdcard/Android/data/com.huawei.smarthome/files/Log/  D:\smarthomeLog
     adb pull  /sdcard/Android/data/com.huawei.hilink.framework/files/Log/com.huawei.hilink.framework/  D:\hilinkSVCLog
     ```

* 方式二：通过手机中的文件管理方式获取日志。
  1. 打开手机的"文件管理"应用，进入"浏览"页面。
  2. 在"位置"列表中，选择"我的手机"。
  3. 进入"Android > data > com.huawei.smarthome > files > Log"文件夹。此文件夹中的文件即为智慧生活App日志。
  4. 进入"Android > data > com.huawei.hilink.framework > files > Log > com.huawei.hilink.framework"文件夹。此文件夹中的文件即为智慧生活基础服务日志。

如果无法自助解决问题，可以压缩日志文件夹，提供问题现象录屏，发给华为技术支持人员进行定位。

## 如何抓取HarmonyOS手机蓝牙HCI日志

1. 确认手机已进入开发者模式并开启"USB调试"功能。
   1. 在手机中打开"设置 "。
   2. 选择"关于手机"，查找版本号。
   3. 快速点击"版本号"多次，直到提示开发者模式已打开，返回上一层。
   4. 选择"系统和更新 > 开发人员选项"，并开启"USB调试"。
2. 在电脑中运行cmd命令。


3. 在命令行中输入如下命令，导出的文件即为手机蓝牙HCI日志。

   ```screen
   hdc file recv /data/log/bt ./
   ```

如果无法自助解决问题，可以压缩日志文件夹，提供问题现象录屏，发给华为技术支持人员进行定位。

## HarmonyOS 5 及以上系统手机如何获取智慧生活App日志

1.打开智慧生活App，登录华为帐号。

2.依次点击我的 > 帮助与服务，在设备问题中选择需要反馈的智能家居设备。

3.进入到设备的热门问题页面，点击页面下方的反馈问题，在问题与建议界面填写相关信息，并勾选"共享应用日志信息，以准确诊断问题"后点击提交。

4.点击"提交"之后，请勿退出智慧生活App，否则会导致日志提交失败。日志提交成功后，会有提示成功的内容，记录问题编号反馈给产品经理/技术支持以便于准确定位。
> 注意
>
> 1. 提交日志时，请确保设备处于在线状态。
> 2. HarmonyOS 5及以上版本需在反馈问题页面，点击下一步跳转打开智能检测后，再填写相关信息。
> 3. 注意描写清楚问题现象，如果问题现象过于复杂不好描述，可以截图或录像说明。

## 如何获取系统HiLog日志

1.使用华为手机，打开拨号键盘，输入*#*#2846579#*#*（PAD 无拨号盘，使用计算器输入"()()2846579()()"），进入工程菜单页面。

2.选择后台设置。

3.选择AP LOG设置，打开AP LOG （问题解决后关闭）。

4.使用 adb pull /data/log/hilogs/。

## 如何获取鸿蒙智联 SDK debug版本日志

1. 设备侧集成编译鸿蒙智联SDK的"lib/debug"目录下的库文件。
2. 在模组侧接上串口，通过串口打印输出设备侧鸿蒙智联 SDK日志，确保获取的日志内容有"LD_"开头的字样。如：LD_INFO、LD_DEBUG、LD_WARN等。
3. 日志需增加时间戳：设备侧日志加上时间戳，SecureCRT软件，点击 "选项 > 会话选项 > 日志文件"，在每行(E)设置"[%Y%M%D_%h:%m:%s:%t]"。

## 认证测试问题/HiLink&短距用例问题/DECC工具问题，需提供哪些日志及如何获取日志

1. 需开发者提供：用例编号、用例失败日志log、完整DECC用例失败截图、智慧生活App界面截图或录屏（如涉及）。
2. 获取DECC用户日志：用例失败页点击右下角【查看报告】获取日志。
3. 获取智慧生活App日志：路径Android\data\com.huawei.smarthome\files\Log。
4. 获取DECC工具日志：在DECC主界面左侧菜单中的 【系统菜单】--【收集日志】等待收集到日志。
5. 获取cmd窗口日志，在执行用例过程中，会自动打开cmd窗口，将里面的内容保存下来。
6. 启动appium服务失败或未成功启动智慧生活APP需要cmd窗口日志）。
7. 涉及智慧生活App上可信认证测试工具失败时，请补充提供可信认证工具控制台日志：
   * 多次点击可信认证工具版本号下的beta，会出现一个vConsole控制台；
   * 进行认证测试的时候点击打开vConsole ；
   * 针对报错项截图并完整记录日志。
8. 短距用例：浏览器版本、手机型号、路由器型号。

## 如何获取鸿蒙智联SDK设备控制日志

解决方案

* 在 HILINK_PutCharState 函数入口打印：svcId、payload，设备收到的控制svcId和控制内容报文。
* 在 HILINK_GetCharState 函数入口打印：svcId、in，出口增加打印：out，设备控制结果上报及报文组装。

示例：

```screen
int HILINK_PutCharState(const char *svcId, const char *payload, unsigned int len)
{
    if (svcId != NULL) {
        printf("HILINK_PutCharState svcId : %s\r\n", svcId);
    }
    if (payload != NULL) {
        printf("HILINK_PutCharState payload : %s\r\n", payload);
    }
......
return 0;
}

int HILINK_GetCharState(const char *svcId, const char *in, unsigned int inLen, char **out, unsigned int *outLen)
{
    if (svcId != NULL) {
        printf("HILINK_GetCharState svcId : %s\r\n", svcId);
    }
    if (in != NULL) {
        printf("HILINK_GetCharState in : %s\r\n", in);
    }
//获取设备状态，并组装上报报文*out
......
printf("HILINK_GetCharState, *out : %s\r\n", *out);
return 0;
}
```
