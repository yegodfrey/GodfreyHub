# 设备配网

#### 入参说明

碰一碰根据设备的配网状态分为首碰和二碰。

* 首碰表示设备未配网，此时手机与设备碰一碰后，将启动配网流程。
* 二碰表示设备已配网，此时手机与设备碰一碰后，将启动控制流程。

当进行碰一碰操作时，由智慧生活基础服务拉起原子化服务。程序从[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ability-ability-overview-0000000000029852)开始执行，需要在Ability的onStart方法中对intent传入的参数进行解析，据此判断是启动配网流程还是启动控制流程。

#### 设备配网

设备配网分为极速配网（NAN）和常规配网（SoftAP）、蓝牙配网三种方式。其中，极速配网（NAN）方式在配网的过程中就可以拉起设备控制界面，当前只有Hi3861芯片支持。

不同的配网方式要传递的参数不一样、跳转的页面也不一样，需要先对智慧生活基础服务传递过来的参数进行解析，再根据解析出来的字段判断是极速配网（NAN）、常规配网（SoftAP）、蓝牙配网。示例步骤如下：

1. 在"entry"目录下的"MainAbility"文件中，意图配置的Ability的onStart方法中对intent携带的参数进行解析，代码示例如下：

   <br />

   ```
   public class MainAbility extends AceAbility {
       private static final int DIALOG_MODAL = 3;
       private static final int PRODUCT_INFO_START = 0;
       private static final int PRODUCT_INFO_MIDDLE = 4;
       private static final int PRODUCT_INFO_END = 6;
       private static final int SOFTAP_NET_CONFIG_COMPLETE = 1;
       private static final int SOFTAP_NET_CONFIGURING = 0;
       ...

       @Override
       public void onStart(Intent intent) {
           intent.setParam("window_modal", DIALOG_MODAL);
           String deviceId = intent.getStringParam("deviceId");
           String nanSessionId = intent.getStringParam("nanSessionId");
           String uuid = intent.getStringParam("uuid");

           String productInfo = intent.getStringParam("productInfo");
           String productId = (productInfo != null && productInfo.length() >= PRODUCT_INFO_MIDDLE)
                   ? productInfo.substring(PRODUCT_INFO_START, PRODUCT_INFO_MIDDLE) : null;
           String subModelId = (productInfo != null && productInfo.length() >= PRODUCT_INFO_END)
                   ? productInfo.substring(PRODUCT_INFO_MIDDLE, PRODUCT_INFO_END) : null;

           String sourceFA = intent.getStringParam("source");
           // fastcontrol字段的值来区分秒控和普通控制；秒控：true；普通控制：false
           boolean isFastControl = intent.getBooleanParam("fastControl", false);
           // businessStage字段用于标识业务进行的阶段，该字段值为1的时候，表示FA调用智慧生活基础服务的SoftAP配网流程完成后回拉FA的阶段
           int businessStage = intent.getIntParam("businessStage", SOFTAP_NET_CONFIGURING);

           Object businessInfo = intent.getParams().getParam("businessInfo");
           if (businessInfo != null) {
               ZSONObject objectBusinessInfo = ZSONObject.classToZSON(businessInfo);
               // 91字段是Demo中NFC里面烧录的业务自定义内容
               String data91 = objectBusinessInfo.getZSONObject("params").getString("91");
           }

           // 如果nanSessionId为有效值，fastControl为true，直接进入秒控界面
           if (!TextTool.isNullOrEmpty(nanSessionId) && !TextTool.isEqual(STATUS_NAN_DEVICE_NOT_FOUND, nanSessionId) && fastControl) {
               // TODO: 已经从智慧生活基础服务的配网界面重新拉起原子化服务，设备正在进行NAN配网，跳转半模态秒控页面
           } else if (businessStage == SOFTAP_NET_CONFIG_COMPLETE && TextTool.isNullOrEmpty(deviceId)) {
               // TODO: 已经从智慧生活基础服务的配网界面重新拉起原子化服务，设备已经配网完成，进入半模态控制界面
           }
           // TODO: 通过NFC标签碰一碰拉起原子化服务场景，包括：帐号授权、设备配网等过程
           super.onStart(intent);
       }

       ...
   }
   ```

2. 在"entry"目录下的"CommonOperatorUtil.java"文件中，根据解析的参数数据进行跳转判断逻辑，其中拉起配网页面逻辑代码示例如下：

   <br />

   ```
   private static final String HILINK_NET_CONFIG_URI = "hilink://hilinksvc.huawei.com/device?action=deviceAdd&prodId=%s&fromApp=%s";

   /**
    * 打开配网界面
    *
    * @param context 上下文对象
    */
   private void openHiLinkNetConfig(Context context) {
       context.getUITaskDispatcher().asyncDispatch(() -> {
           String uriStr = String.format(Locale.ROOT, HILINK_NET_CONFIG_URI, productId, context.getBundleName());
           Intent intent = new Intent();
           intent.setParam("uuid", uuid);
           Operation operation = new Intent.OperationBuilder()
                   .withDeviceId("")
                   .withFlags(Intent.FLAG_ABILITY_NEW_MISSION | Intent.FLAG_NOT_OHOS_COMPONENT)
                   .withAction("android.intent.action.VIEW")
                   .withUri(Uri.parse(uriStr))
                   .build();
           intent.setOperation(operation);
           context.startAbility(intent);
           // 拉起网络设置页面的同时，关闭当前界面
           context.terminateAbility();
       });
   }
   ```
