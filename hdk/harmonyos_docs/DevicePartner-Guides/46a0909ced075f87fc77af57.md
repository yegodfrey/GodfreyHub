# 认证流程

伙伴可以基于[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)开展产品认证，产品通过认证之后，即可获得鸿蒙电脑外设兼容性认证。

## 前提条件

已完成产品的设备开发和应用开发。

## 操作步骤

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)，单击右上角的"管理中心"。
2. 在平台左侧导航栏中选择"鸿蒙电脑外设兼容性认证"， 单击"+"号创建，根据界面提示，配置产品的基本信息。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/7U2JS-EkShmWByyg5dM09g/zh-cn_image_0000002623665519.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=09494E53D287A36211E82868F77030F3D19B7E709E2C71A432DB446B03A5B3A5 "点击放大")

3. 产品创建成功，进入"产品定义"页面，配置产品的软硬件规格。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/okEL5OqkQeqIJ42z0Y_MDQ/zh-cn_image_0000002593066166.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=FA71667A70C936047C4D76D4A8F9C095852DF56536F1FD91C776AAFF4C8CE142 "点击放大")

4. 产品定义成功后， 在"产品测试"页面，选择认证测试标准版本号，并对产品进行自测试。

   选择认证测试版本号。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/MrDEi8u7QGyZoyChYibHcw/zh-cn_image_0000002623505715.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=AB195F380CD5F481EB77B1420DCDC02BD841201C78874022D13FD9EC6A9675AC "点击放大")

5. 产品自测试结束后，在"产品测试"页面手动上传产品测试报告。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/HvdQ23PnTOSanxK8DRiCXw/zh-cn_image_0000002623505795.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=0976C4F232623D67C1ABE9FEEE1D05401E21128274E3E26144A23CD58A083817 "点击放大")

6. 待产品测试操作全部执行完成后，可以单击页面底部的"提交"，进入"外设认证"环节。
7. 点击"预约认证"页面，提交认证申请。

   1. 完善产品认证资料和联系人资料。
   2. 单击"提交"。预约认证提交成功后，可以查看"预约认证结论"。
   3. 认证预约审核通过后，单击页面上方的"样机寄送"，进入"样机寄送"环节。

   > 说明
   >
   > 具体认证材料上传请以实际页面为准。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/eUfdHfVqS3KgR1-Il5lIDg/zh-cn_image_0000002623505941.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=8ADE47DDF1BAA1CE956F065F94B444A95377103BE8A72C22594D01AE5EEE0F59 "点击放大")

8. 根据平台流程指引，进入"样机寄送"环节，完成样机寄送。

   1. 按照"样机寄送"页面显示的地址，完成样机寄送 。
   2. 填写样机寄送的快递单号。
   3. 上传"样机清单"。
   4. 单击"提交"，可以在"样机寄送"页面查询进展。

   > 说明
   >
   > 根据认证产品的实际情况，华为认证测试团队将决定是否需要寄送样机。如果无需寄送样机，可以忽略当前步骤，直接进入"技术认证"环节。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/HYWVuwJETWOQDd2cy4RATA/zh-cn_image_0000002593227208.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=D8548759BACC625426B4F97CBAB49C4A66D939FE7F1C144B053524A6D31597F5 "点击放大")

9. 等待机构复测后，可以在"证书颁发"页面查询认证结果。如果认证失败，可回到产品测试环节，重新提交自测试结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/CcxApg8RRHuNKqWxoghi3A/zh-cn_image_0000002593227240.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=6810C6AECD8EBF392E7B29FCAC2451EEA060FAFDCF252C0C865B2FDFCEDD150B "点击放大")
