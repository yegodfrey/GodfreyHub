# 开发H5功能（Wi-Fi/Combo）

本章节介绍如何按照UI设计文件和Profile文件，实现H5功能开发。

H5页面根据Profile文件实现数据的组装，调用智慧生活App提供的JSAPI将数据传递给App的DeviceWebManage模块，该模块将最终配置数据下发给设备。因此，功能实现必须与Profile文件一致，才能保证功能的正常交互。  

#### 前提条件

* 已获取产品的Profile文件。获取方式参见[下载Profile文件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-offline-preparations-0000001241445441#ZH-CN_TOPIC_0000001241445441__li17977131171610)。
* 已获取"H5 Demo \> Vue Project"中的"Wi-Fi Demo"文件夹。获取方式参见[下载H5 Demo](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-offline-preparations-0000001241445441#ZH-CN_TOPIC_0000001241445441__li5952229182214)。
* 已获取[Wi-Fi设备JSAPI接口参考](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/wifi-overview-0000001077756430)。  

#### 设备与H5交互

以H5页面下发熄屏开关的命令为例：

1. 下发数据时，在[《Wi-Fi设备JSAPI接口参考》](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/wifi-overview-0000001077756430)中找到下发命令到设备接口：hilink.setDeviceInfo()。
2. 根据接口文档，下发开关命令。命令中提交数据的json_body字段必须和profile一一对应。
   1. 在profile文件中，查找熄屏开关对应的数据如下：  

      |服务 sid|服务(中文)|服务类型 ServiceType|属性|属性类型 Character Type|操作权限|数据类型|数据约束 (IT系统录入时使用)|取值范围|
      |:-----------|:-----|:---------------|:-|:------------------|:-------------|:---|:---------------|:------|
      |screenSwitch|熄屏开关|-|-|-|-|-|-|-|
      |-|-|-|screenSwitch||PUT/REPORT/GET|bool|-|0-关 1-开|

   2. 在项目文件中，打开"src \> components \> HomeMode.vue"，在script标签中，添加如下代码：

      ```
      methods: {
          clickCell() {
              let json_data = JSON.stringify({ screenSwitch: { on:1- this.screenSwitchOn} });
              if (typeof hilink != 'undefined') {
                  hilink.setDeviceInfo('0', json_data, 'switchResult');
              }
          }
      }
      ```

#### 获取设备状态

调用getDevCacheAll接口获取缓存设备状态全集，点击进入设备页面获取设备全部状态，使页面初始化状态正确。

在项目文件中，打开"src \> store \> action.js"，添加如下方法：

```
JSON.hParse = function (res) {
    let data, dataStr = res;
    // 去除object外多余的 "
    dataStr = dataStr.replace(/"{/g, '{');
    dataStr = dataStr.replace(/}"/g, '}');
    // \\ -普通反斜杠; \n -换行符; \r -回车符; \t -制表符; \f -换页符; \t -垂直制表符;
    dataStr = dataStr.replace(/\\|\n|\r|\t|\f|\t/g, '');
    data = JSON.parse(dataStr);
    return data;
};

// desc 向云端获取缓存的所有数据
getDevInfoAll({ commit, dispatch }) {
    return new Promise((resolve, reject) => {
        if (!window.hilink) {
             commit('commitAppData', { hasGetAllData: true });
             return;
         }
         window.hilink.getDevCacheAll('0', '', 'Ag.getDevCacheAllRes');
         window.Ag.getDevCacheAllRes = res=> {
             let data = JSON.hParse(res);
             if (typeof data.role !== 'undefined' && data.role !== 'owner') {
                 state.shareDevice = true;
             }
             commit('commitAppData', {
                 devId: data.devId,
                 devName: data.devName,
                 sn: data.devInfo.sn,
                 deviceModel: data.devInfo.model,
                 netStatus: data.light.on,
                 role: data.role,
                 roomName: data.roomName
             });
         };
    });
}
```

#### 控制设备

调用setDeviceInfo接口下发指令给设备，控制设备。

在项目文件中，打开"src \> store \> action.js"，添加如下方法：

```
// desc 下发指令统一通道
// param type:Object,required:true,default:{sid:{cha:1}}
setDevInfo({ commit }, param) {
    return new Promise((resolve, reject) => {
        commit('commitAppData', { showTaskToast:true });
        if (window.hilink) {
            window.hilink.setDeviceInfo('0', JSON.stringify(param), 'Ag.setDevInfoRes');
        } else { // 模拟下发用
            setTimeout(() => {
                commit('commitAppData', { showTaskToast:false });
                resolve();
            }, 100);
            setTimeout(() => {
                commit('commitMock', param);
            }, 300);
        }
        window.Ag.setDevInfoRes = res=> {
            commit('commitAppData', { showTaskToast:false });
            let data = JSON.hParse(res);
            Ag.isError(data) ? reject(newError('error')) : resolve();
        };
    });
}
```

#### 删除设备

点击设备删除后，需要判断是否为共享设备：

* 共享设备：没有删除权限。
* 非共享设备：先删除所有云上用户，再删除设备，调用deleteDevice接口删除成功后退出到智慧生活设备列表界面。

```
submit() {
    this.deleteDevice = false;
    //判断是否为共享设备
    if(this.shareDevice) {
        try {
          window.hilink.refuseSharedDevice('delShareDevice');
          window.delShareDevice= res=>{
              if (JSON.parse(res).errcode===0) {
                  window.hilink.finishDeviceActivity(); // 跳回九宫格页面
              }
          };
        } catch (error) {
             // console.log('删除失败!')
          }
        return;
   }
   let jsonNum = { // 删除设备时删除所有用户
        'type':'userList',
        'data': {
             'userList': []
         }
    };
    catchFn(() =>window.hilink.postDeviceExtendData(JSON.stringify(jsonNum),'postDeviceExtendDataRuselt'), '清空云端的扩展数据');
    window.postDeviceExtendDataRuselt = (res) => { // 删除所有用户
    };
    window.hilink.deleteDevice(true, 'deleteDevices'); // 删除当前设备
        
    window.hilink.finishDeviceActivity();
    }
```

   // 获取app版本
   getAppVersionCode() {
       return new Promise((resolve, reject) => {
           window.hilink && window.hilink.getAppVersionCode('Ag.appVersionCodeCallback');
           window.Ag.appVersionCodeCallback = res => {
               let version = Number(res);
               window.APPVersionCode = version;
               Ag.isError(version) ? reject(new Error('getAppVersionCode error')) : resolve();
           };
       });
   },
   // 当前app版本是否大于等于目标版本(13.0.5.310)
   isLaterAppVersion({ dispatch }, targetVersion) {
       const curVersion = String(window.APPVersionCode || '13.0.0.0');
       let isLater = false;
       if (curVersion.includes('.')) {
           const target = targetVersion.split('.');
           const current = curVersion.split('.');
           let length = current.length;
           if (current.length >= target.length) {
               isLater = true;
               length = target.length;
           }
           for (let i = 0; i < length; i++) {
               if (Number(current[i]) !== Number(target[i])) {
                   isLater = Number(current[i]) > Number(target[i]);
                   break;
               }
           }
       } else {
           let newVersion = String(targetVersion).replace(/\./g, '');
           isLater = Number(curVersion) >= Number(newVersion);
       }
       return isLater;
   }
