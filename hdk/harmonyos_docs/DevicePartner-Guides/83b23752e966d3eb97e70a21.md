# 蓝牙信道配置

当产品通信方式为"蓝牙BLE"，且智慧生活App H5采用[线上开发](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-dev-overview-0000001367032228#ZH-CN_TOPIC_0000001367032228__li9904134143211)方式时，需要按照本章节配置蓝牙信道。其他情形可以跳过本章节。  

#### 适用品类

除了以下品类之外，其他采用蓝牙BLE的品类均支持智慧生活App的线上设计：

智能照明、智能插座、空气净化器、净水器、智能插排、智能空调、新风、窗帘、晾衣机、豆浆机、空气检测器、电饭煲、油烟机、加湿器、风扇、取暖器、香薰机、智能开关、智能台灯、洗碗机、养生壶、洗衣机、浴霸、开窗器、开关控制器、智能床垫、卷帘、音乐热水器、N路调光模块、手势开关、料理机、直饮水机、电磁炉、热水壶、电压力锅、百叶窗、除湿机、干鞋器、垃圾处理器、烤箱、冰箱、燃气灶、智能马桶盖、电蒸箱、吸尘器、场景面板、窗帘控制器、中控主机、门锁、流媒体后视镜、车载屏。  

#### 操作步骤

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中选择"产品开发"，单击开发中的产品，进入"产品定义"页面。
3. 选择"蓝牙信道配置"，进入蓝牙信道配置流程。
4. 根据[表1](#ZH-CN_TOPIC_0000001238815193__table971620813483)，填写蓝牙信道配置内容。

   <br />

   ![](https://media:201787206628301731)  
   * 平台界面默认显示"信道1"，如果需要添加更多信道，单击右上角的"添加信道"进行添加。
   * ServiceUuid与CharactristicUuid的取值可参考[蓝牙技术联盟](https://www.bluetooth.com/specifications/assigned-numbers/)中关于"16-bit UUIDs"的规范。  

   |参数||说明|示例|
   |:-|-----|:----------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------|
   |length||表示蓝牙数据长度。 需要填写字符串长度，而不是字节长度。取值范围为1\~100之间的整数。|当数据为"FF01", length为"4"。 <br />|
   |writeServiceUuid||表示数据给蓝牙的服务ID。 需要填写128位全地址值，而不是16位地址。|0000fa02-0000-1000-8000-00805f9b34fb 其中，fa02表示16位的蓝牙UUID。|
   |writeCharactristicUuid||表示数据给蓝牙的特征值ID。 需要填写128位全地址值，而不是16位地址。|0000ba02-0000-1000-8000-00805f9b34fb 其中，ba02表示16位的蓝牙UUID。|
   |notifyServiceUuid||表示蓝牙上报数据的服务ID。 需要填写128位全地址值，而不是16位地址。|0000fa02-0000-1000-8000-00805f9b34fb 其中，fa02表示16位的蓝牙UUID。|
   |notifyCharactristicUuid||表示蓝牙上报数据的特征值ID。 需要填写128位全地址值，而不是16位地址。|0000ba02-0000-1000-8000-00805f9b34fb 其中，ba02表示16位的蓝牙UUID。|
   |属性|属性值|选择功能定义页面的属性值 。 配置蓝牙信道配置的属性，需要对功能定义页面中品类功能、通用功能、自定义功能三个页签里面的所有属性进行配置。（仅限int、enum、bool三个类型）|当选择"Switch On"时，表示开关功能。|
   |属性|地址开始值|选择的属性值对应数据中的开始位置。|如果数据"FF01"中的01位置表示Switch On开关功能，那么数据的第2位到第3位表示开关功能，开始值填"2", 结束值填"3"。 取值范围为\[0，length-1\]的正整数。 说明： 同一个信道，属性的开始地址和结束地址不允许有重复区间。|
   |属性|地址结束值|选择的属性值对应数据中的结束位置。|如果数据"FF01"中的01位置表示Switch On开关功能，那么数据的第2位到第3位表示开关功能，开始值填"2", 结束值填"3"。 取值范围为\[0，length-1\]的正整数。 说明： 同一个信道，属性的开始地址和结束地址不允许有重复区间。|
   [表1 蓝牙信道配置参数说明]

   <br />

5. 单击"提交"，保存蓝牙信道配置。

   <br />

   蓝牙信道配置在保存后还可进行修改，编辑并保存后将覆盖原内容。
