# 折叠屏、Pad 等设备适配

#### 半模态面板窗口显示

<br />

折叠屏展开、平板横竖屏均适配为半模态面板窗口显示，居中显示在屏幕中央。同分辨率的情况下，窗口大小统一为 480x560vp。

![](https://media:101783481608608506 "点击放大")  

#### 适配效果展示

<br />

* 适配时，规范基本和手机适配规范一致，但显示窗口因宽度和手机设备不一致，所以主要需做宽度适配。
* 在折叠屏和平板中，弹窗大小和在手机中显示时保持一致。

![](https://media:101783481608827507 "点击放大")
