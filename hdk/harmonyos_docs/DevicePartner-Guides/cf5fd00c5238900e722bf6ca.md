# 上传检视视频

1. 在"测量页面开发"内，按照[检视视频要求](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/download-0000001199581175#section0702134085015)上传检视视频。
2. 单击"提交审核"，等待审核结果通知。
