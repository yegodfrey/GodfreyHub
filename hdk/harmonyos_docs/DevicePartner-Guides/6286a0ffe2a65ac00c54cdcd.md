# App设计（公版卡片）

公版卡片可以基于产品物模型定义，自动生成满足UX/UI设计规范的H5界面，从而提升产品H5开发效率，减少审核流程。

如果产品不支持公版卡片、或者生成的公版卡片不能满足伙伴要求，可以采用线上开发H5或线下开发H5方式。  

#### 支持公版卡片的品类

当前仅支持牙刷、智能水杯。更多品类会陆续开放。  

#### 前提条件

已[创建产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-0000001134540425)并完成[产品定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-specifications-0000001194015922)（包括软硬件定义与物模型定义）。  

#### 操作步骤

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中选择"产品开发"，单击待开发的产品，进入产品开发流程。
3. 选择"交互设计"，单击智慧生活App卡片右上方的"进入开发"。
4. 选择"App开发 \> App设计 \> 公版卡片"。

   <br />

   ![](https://media:101783481608930508 "点击放大")

   <br />

5. 在公版卡片模式下，预览卡片功能的效果。

   <br />

   ![](https://media:101783481608957509)  
   "公版卡片"模式下的组件渲染支持品类功能、通用功能、以及部分自定义功能。其中，自定义功能必须同时满足如下条件：
   * 数据类型不能为"字符型"。
   * 操作权限同时包含GET、PUT、REPORT三种。

   <br />

6. 确认卡片效果能够满足需求后，单击"下一步"保存提交。

   <br />

   如果卡片效果无法满足需求，可以选择切换到"线上开发"模式或者采用"线下自开发"。

   <br />
