# 本地调试

#### App添加设备功能测试

1. 获取[测试版运动健康App](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/download-0000001199581175#section1728195116396)，将其安装在手机上。可以通过以下两种方式进行安装。

   <br />

   * 通过adb方式安装测试程序。

     ```
     adb install -r E:\HealthSDK\HuaweiHealth-test.apk
     ```

     <br />

     提示Success表示安装成功。如果安装失败，请检查手机上是否已经存在运动健康程序，卸载后再执行以上安装步骤即可。

   <!-- -->

   * 如果无法通过adb方式安装测试程序，可以将apk拷贝到手机存储中安装。

   ![](https://media:101783481636794919)  
   运动健康App安装成功之后，建议关闭应用市场里的自动更新应用，操作方式：进入应用市场，点击"我的 \> 设置 \> 自动更新应用"。建议关闭手机设置中的WLAN下自动更新，操作方式：点击"设置 \> 系统和更新 \> 软件更新"，右上角点击"本机设置 \> WLAN下自动更新"。

   <br />

2. 将[资源包](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-resourcezip-0000001182543252#section15924745191913)（资源包文件名为：UUID值）导入到手机本地。手机上打开安装后的运动健康App，选择"我的 \> 设置 \> 设备测试 \> 设备接入"，在弹出的文件浏览框中选中"文件管理"，然后在相应的目录下找到导入的资源包，点击资源包。

   <br />

   图1 导入资源包   
   ![](https://media:101783481636829920)

   <br />

3. 在"我的设备"页面点击"添加"。

   <br />

   图2 添加设备   
   ![](https://media:101783481636862921)

   <br />

4. 选择对应的设备类型和产品，找到导入资源的设备。

   <br />

   图3 找到对应的设备   
   ![](https://media:101783481636894922)

   <br />

5. 点击"开始配对"，根据操作完成绑定设备后跳转到H5页面。以体温计为例：

   <br />

   图4 配对设备   
   ![](https://media:101783481636923923)

   <br />

#### 一碰联功能测试

1. 在手机上下载并安装最新版华为运动健康App。打开手机的蓝牙及NFC，用手机NFC部位碰一碰设备上的NFC标签，连接设备。或者打开运动健康App，扫描设备上的二维码连接设备。

   <br />

   图5 扫一扫/一碰联   
   ![](https://media:101783481636972924 "点击放大")

   <br />

2. 按照测试用例进行测试，确保所有的用例正常测试通过。测试用例：

   <br />

   * [运动设备接入预测试用例及报告模板.zip](https://media:101783481637035925)
   * [健康设备接入预测试用例及报告模板.zip](https://media:101783481637090926)

   <br />
