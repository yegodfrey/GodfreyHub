# 蓝牙模块功能开发

#### 产品功能规范

智能跳绳要实现以下所有功能。  

|类别|功能|详细说明|
|:---|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|功能规范|设置跳绳时钟信息|支持由App设置跳绳的时间信息，将跳绳设备的时钟设置为与App同步。|
|功能规范|查询跳绳电池电量|支持查询跳绳设备的电量（用户可以在App上方便查看电量是否充足，尽快更换电池）。|
|功能规范|三种跳绳模式|支持设置跳绳的运动模式，不同运动模式支持设置模式相关参数： * 自由跳绳：用户随意跳绳，除非主动通过App暂停、停止运动，跳绳跟随暂停、停止。跳绳自己计时、计数。 * 定时计数：定时截止后，跳绳运动自动停止。最后上报的运动时间，需要等于设定的时间。 * 定数计时：达到指定的个数后，跳绳运动自动停止。最后上报的跳绳个数需要等于设定的个数。|
|功能规范|启动\&暂停跳绳|支持用户从App上暂停、恢复、停止跳绳。|
|功能规范|跳绳上报数据|运动状态、时间、次数、速度、跘绳次数、当前连跳、卡路里。|
|功能规范|同步离线跳绳运动记录|允许App通过指令同步跳绳离线生成的历史跳绳数据到App，同步后删除历史数据，避免重复同步： * 规格：40条。 * 离线跳绳历史数据项：起始时间、运动时间、次数、最快速度、平均速度、跘绳次数、最大连跳、卡路里。|
|功能规范|离线跳绳（未连接蓝牙）|1. 自动检测跳绳运动开始，满足如下条件，则进入离线跳绳状态： * 蓝牙未连接。 * 跳绳速度正常（排除常见姿势调整，手柄调整的场景，避免误识别）。 * 跳绳一定次数，建议3次。 2. 自动检测跳绳运动结束，满足如下条件，则离线跳绳结束： 停止跳绳，无新次数，持续6s。|
|功能规范|在线跳绳（连接上蓝牙）|1. 连接上蓝牙后，不会再触发离线跳绳记录。 2. 连接上蓝牙后，在收到App的启动跳绳（设置跳绳模式）指令前，不计时，不计数，所有跳绳数据不记录。 3. 收到App的启动跳绳（设置跳绳模式）指令后，正式开始计时、计数。 4. 收到App的暂停指令后，不再计时、不再计数，暂停期间跳绳数据不记录。 5. 收到App的恢复指令后，马上开始继续计时、计数。 6. 收到App的停止指令后，马上停止计时、计数，单次运动停止。|
|功能规范|在线跳绳过程中断开蓝牙|1. 检测到蓝牙中断后，需继续计时、计数，等待App蓝牙重连，确保重连成功后，能上报最新的数据。 2. 等待App蓝牙重连时间：5s。 3. 5s超时后，则进入离线跳绳检测逻辑，以决定是否开始一次离线运动记录。|
|功能规范|离线跳绳过程中途连接上蓝牙|1. 离线跳绳过程中，为避免周边其他人连接上手柄蓝牙获取运动数据，要求离线跳绳过程中，不允许蓝牙连接。 2. 离线跳绳结束后（用户停止跳绳6s，则当次离线跳绳运动结束），才允许蓝牙连接。|
|其他规范|绑定指示灯|设备上有明显的蓝牙指示灯，指示蓝牙连接是否正常，并且有手动开启广播的方法（通常绿色代表连接、红色代表断开、红色闪烁代表连接中）。|
|其他规范|时钟|跳绳有自己的时钟，以支持离线跳绳时，能记录运动起始时间。|
|其他规范|产品说明书|产品说明书中有运动健康App与跳绳设备联动使用指导，最终上线的使用指导经华为技术支持人员评审。|
[表1 智能跳绳功能规范]

#### 低功耗蓝牙规范

智能跳绳要按照如下要求完成蓝牙模块功能开发。  

#### 总体说明

1. 支持低功耗蓝牙4.2及以上版本协议栈，支持Secure Simple Paring安全机制。
2. 实现Rope Service服务，包含2个characteristic，RopeControl为控制通道，RopeData为数据通道。
3. 蓝牙广播名称由厂家自定义，建议XX-YY-ZZZZZ格式，其中XX为品牌简称，YY为型号，ZZZZZ为内部编号，蓝牙名称总长度不超过15字节，蓝牙广播间隔\<100ms，蓝牙广播AD Type包含华为厂家自定义AD Type。
