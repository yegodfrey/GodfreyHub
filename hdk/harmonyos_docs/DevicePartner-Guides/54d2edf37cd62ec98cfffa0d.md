# 可粘贴平面尺寸不足24mm的碰靠设备

#### 设备定义

如果设备机身上可粘贴或印刷标签的平面尺寸小于24mm，请勿在机身上使用高、宽为24mm以上的圆形标签。

#### 图案印刷尺寸

对于该类设备，应该在合适的位置，印刷如图所示的图案，无需标签的圆形外圈。印刷图案宽高等比，宽度最小为6mm。

#### 辅助信息规范

图案下方允许使用辅助信息以指导用户交互方式，此处辅助信息规范与使用标签时的规范一致。

设备仅支持碰一碰连接时，标准辅助信息为“HarmonyOS手机碰一碰”；设备仅支持靠近发现时，标准辅助信息为“HarmonyOS手机靠近”；设备同时支持碰一碰连接和靠近发现时，标准辅助信息为“HarmonyOS手机碰一碰/靠近”。辅助信息支持换行。

辅助信息可打印在纸上并粘贴在满足标签安全空间的位置(推荐使用透明贴纸)，也可以丝印在机身表面。
