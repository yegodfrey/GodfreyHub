# 错误码

|错误码|说明|
|:--------------------------------------------------|:----------------|
|[1](#ZH-CN_TOPIC_0000001228137869__li1786120407019)|未获得授权。|
|2|参数异常。|
|[10](#ZH-CN_TOPIC_0000001228137869__li111222522003)|调用接口时未通过config验证。|
|12|接口不存在。|
|13|参数格式错误。|
|1001|隐私权限校验异常。|

* 错误码1：
  * 用户点击拒绝：属于正常场景，用户如果拒绝，请按照业务处理策略进行跳转。
  * SCOPE权限设置错误：调用登录接口时使用了未在联盟上申请的权限。
* 错误码10：
  * 使用了错误的appid：请检查代码中传入的appid与申请的是否一致。
  * 创建免安装/H5应用时没有配置正确的安全URL： 需要在开发者联盟网站配置安全URL。该安全URL指的是进行登录操作（一般是调用signIn接口）的H5页面所在的URL。

    URL获取方式：进入H5页面， 通过方法window.location.href获取当前页面的URL，比如：获取的URL是https://www.example.com/test/index.html，则安全url可以配置为： https://www.example.com/\*

    ![](https://media:101783481625099755)
  * 传入的scope参数的权限类型与申请的范围不一致，或者尚未审批通过。
    * 请确保选择的是"免安装/H5应用" ![](https://media:101783481625127756)

    * 请确保代码中传入的scopes参数的权限，是所申请的App ID拥有的权限。
* 宿主层集成JS SDK的问题：查看logcat日志，出现isUrlValid error之类的报错，说明宿主层集成帐号JSSDK有问题，没有正确设置URL。
