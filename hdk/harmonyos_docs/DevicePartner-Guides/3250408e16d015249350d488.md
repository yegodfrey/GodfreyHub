# 兼容等级

鸿蒙外设认证分为官方认证和兼容适配，推荐"**官方认证**"。

官方认证：该产品满足鸿蒙外设认证级标准，并与鸿蒙操作系统完成互认证测试。

兼容适配：经华为自测，该产品满足鸿蒙外设通用兼容性标准，尚未或不需要与鸿蒙操作系统完成互认证测试。

|**分级**|**分级说明**|**功能**|**安全**|**性能**|**可靠性**|**发证说明**|
|:-----|:----------------------|:-----|:-----|:-----|:------|:-------|
|兼容适配|外设产品达成功能、安全要求，确保设备可基本运行|√|√|/|/|不予发证|
|认证适配|外设产品达成功能、安全、性能、可靠性要求|√|√|√|√|核准后可发证|
