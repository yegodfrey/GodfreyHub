# 协议规范

#### 云云对接的鸿蒙应用支持华为账号一键登录

伙伴的云云对接鸿蒙应用，需支持使用华为账号的手机号免认证一键登录，用户首次可以一键登录应用，首次登录后可以打开应用，支持半模态或全页面登录风格。使用华为账号登录后自动完成华为账号绑定，设备自动同步到华为智慧生活显示，设备数据同步成功率>=98%。

#### 支持云云设备在华为智慧生活上分享

从伙伴账号同步到华为智慧生活app的设备，需要支持分享给其它智慧生活账号上使用。从而实现一个设备能被多个用户使用。

#### 对现网用户体验造成影响的操作行为需知会华为侧

云云设备接入后，对存量现网用户体验造成影响的操作行为需要提前30日知会华为侧，具体可以与华为侧接口的生态产品经理沟通或者提IR单咨询，避免操作引起用户舆情问题。

#### 下线流程规范

云云设备下线需提前知会到用户侧，按照以下流程下线：

1.先下架连接三方平台的品牌入口，不允许再新增设备。

2.需提前30日给账号上已添加了此设备的用户发送push消息，提醒用户设备下线消息。

3.连续发送3次后云侧下线此设备信息。

#### 支持的范围列表需及时刷新维护

云云设备支持的型号列表需及时维护刷新，下线的设备型号需删除，新增的设备型号需添加到范围列表中，不允许将还未支持的型号写到范围列表中。

#### 隐私政策要求

云云对接平台登录页面，需要有隐私政策说明和同意选项，允许登录后智慧生活App可访问和控制设备，且同意选项默认为不勾选，需用户主动勾选后，才可登录。

登录页面如果用户未勾选同意隐私，不能获取到手机验证码，需提示用户同意隐私选项。

#### 支持靠近发现弹窗

OpenHarmony系统的云云设备建议支持首次蓝牙靠近发现弹窗，当手机首次靠近未连接的蓝牙设备时会出现设备连接弹框，引导用户完成设备的连接。
