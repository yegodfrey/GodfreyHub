# 平板适配

平板上插件详情页面是通过半模态展示的和手机上不同。智慧生活在启动插件页面时会通过@Provide('isShowBindSheet') 提供一个isShowBindSheet参数：是否是半模态，插件首页通过@Consume('isShowBindSheet') isShowBindSheet: boolean 获取这个字段用于判断当前插件首页是正常的全屏页面，还是半模态。在退出插件时，如果插件首页是路由栈上的第0个页面，则需要把路由栈清空。  
![](https://media:101783481649253055)  
能通过设备类型判断是否是半模态，因为在折叠屏折叠状态，打开设备详情页面是手机形态，折叠屏展开时是半模态。

示例代码：

```
//首页面
@Component
struct HQPluginLaunchPage {

   //判断是否是半模态
   @Consume('isShowBindSheet') isShowBindSheet: boolean;
}
在页面返回到九宫格的一镜到底动画执行操作里判断是否是半模态还是手机，做不同的处理：
finishPages(): boolean | void {
    animateTo({
      duration: 300,
      curve: Curve.Sharp,
      onFinish: () => {
        AppStorage.set<string>('doScaleAnimDevId', this.deviceId);
      }
    }, () => {
	let indexs = routerUtils.routerStack.getIndexByName("HQPluginMainPage")
	 if (indexs.length == 0 ) {
	    console.log(TAG, "未知异常情况");
          return
         }
        let mainPluginPageIndex = indexs[0]
        if (isShowBindSheet) {
          if (mainPluginPageIndex  == 0) {
            //插件首页在路由栈底部，需要清除栈关闭半模态
            AppStorage.setOrCreate('isDeviceShowBindSheet', false);
            this.routerStack.clear();
          } else {
            //推回到插件首页的上一个页面
            this.routerStack.popToIndex(mainPluginPageIndex -1)
          }
        } else {
           //手机，一级一级的推出到插件首页，如果直接popToIndex到插件首页退出，会没有退出动画
          let routerSize = routerUtils.routerStack.size()
          for (let index = routerSize; index >= mainPluginPageIndex; index--) {
            routerUtils.routerStack?.popToIndex(index-1,false)
          }
        }
    })
    return true
  }
```
