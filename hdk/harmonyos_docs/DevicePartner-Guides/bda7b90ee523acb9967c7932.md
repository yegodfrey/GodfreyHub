# 路由跳转

智慧生活目前基于 Navigation 组件配合 NavPathStack 实现路由管理，不支持使用 router API。获取路由栈的方式如下：

```
build{
  NavDestination() {
  }.onReady((data) => {
   //拿到路由栈，使用这个路由栈进行页面跳转 
    this.routerStack = data.pathStack 
   } 
 }
```
