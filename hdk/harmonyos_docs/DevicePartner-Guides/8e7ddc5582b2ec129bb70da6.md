# 系列化认证

## 适用范围

* **典型适用场景** ：使用相同的外观结构、外观材质和智能化部件，并具备相同的HarmonyOS Connect生态产品体验的同一类产品。

  产品相同的智能化部件指参与或影响产品感知、分析、推理、决策、控制功能与体验的部件，包括不限于产品装载的软件版本、硬件通信模块， NFC标签与标签附着的外壳材质，产品电控模块，产品配套的万能卡片（FA与智慧生活设备控制卡片）。


* **明确不适用场景**：软件版本不同、通信模组不同、射频天线布局不同、产品电控模块不同、产品配套的万能卡片不同。

## 前提条件

创建产品时，需满足如下要求：

* 已选择系列化开发方案。
* 已签署《HarmonyOS Connect系列化生态产品等效认证协议》。
* 已按照《HarmonyOS Connect系列化生态产品等效认证须知》完成自检。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/4iO8vnrDS8SzFk3FkhIyfg/zh-cn_image_0000002592606344.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=979F4312F60905472962FD402BF304697B8F5640E1E2A1A4902B09895DF83D55 "点击放大")

* 已完成系列化产品信息的录入、以及子型号的添加。

## 操作步骤

在创建系列化产品后，即可以提交系列化认证申请（建议在产品开发和自测前完成），否则会影响产品的后续系列化认证流程。

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中，选择"产品认证"，单击"创建认证申请"。
3. 在"新增认证申请"页面，配置产品的认证信息。

   1. 认证方式选择"系列化认证"。
   2. 选择本次认证产品。支持通过产品名称或产品ID进行筛选。
   3. 选择认证测试版本。 不同认证测试版本的差异，详见[认证标准的版本变更说明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/version-vhange-description-0000002622764811)。

   4. 单击"去填写"，按要求填写系列化认证申请表，若有一些图片等举证材料，单击"上传补充材料"，将举证材料上传至平台。 华为审核人员将根据提交的申请信息，判别是否可以采用系列化认证。

      > 说明
      >
      > 如果产品不满足系列化认证要求，申请将被驳回。伙伴可以在"产品开发"将"系列化开发"选项修改为"否"，继续针对单款产品开展原型认证。
   5. 选择是否"授权华为代为申请OHCA认证"。
      * 是：表示授权华为代为申请OHCA认证。仅支持采用OpenHarmony操作系统的产品。
      * 否：表示不授权华为代为申请OHCA认证，或者产品未采用OpenHarmony操作系统。
   6. 单击"下一步"，提交认证预审。
      * 如果审核未通过，则该产品表明不支持系列化认证。
      * 如果审核通过，则需要根据审核结果，启动认证材料的准备，并继续认证流程。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/MjWRg-4uQza10N-NXCny1Q/zh-cn_image_0000002671797679.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=24DA2F9E1C73634CAE64410AFD708D5FE94E0693C8C7918EF4717A24B9C7DF5A "点击放大")

4. 提交预约认证申请。

   1. 确认"产品自测结果"中的信息是否完整、准确。如需修改或补充，可以前往"自测试"页面编辑。 系列化认证可以在一款产品上完成全量的自测试，并上传相关的自测试材料。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/RH_ek8T6S9K7OBOn-Tf94w/zh-cn_image_0000002592446442.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E0424630CAFA472E133EC0D6926D47F8809A748D2352418A5E689D0FEFA2F47 "点击放大")
   2. 在"预约认证"页面，完善产品认证材料。
      1. 上传设备图片和认证材料（包括法规与商品资质材料、上市营销材料等）。 说明
         >
         > 具体认证材料上传请以实际页面为准。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/bqcOA4x-Shea-vU5fUD-oQ/zh-cn_image_0000002665373237.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=97FE3A5A5F0D37199F4E83BA0030B8FAB69ACE73D88820C0A8D825193C4F2CF1 "点击放大")
      2. 确认"认证测试版本"是否正确。
      3. 配置设备信息。 注意
         >
         > 此处配置的设备信息必须与设备OpenHarmony固件包中保持一致，具体取值可通过[表2](#ZH-CN_TOPIC_0000002622924679__table16625193116571)中API来查询。如果不一致，将无法通过认证。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/NEYB6HU1SV2jqzDC2D9OTQ/zh-cn_image_0000002592606348.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=5B3E82DFAFEE5363833BEB3B2E6B0FD8D04BD78C403AD7752791ACFE09553E22 "点击放大")

         |:----------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
         |软件版本号|GetDisplayVersion()|表示整个系统的软件版本号，而非OpenHarmony版本号。不超过64个字符。|
         |硬件设备版本号|GetHardwareModel()|表示设备硬件版本号，不超过32个字符。|
         |系统API Level|GetSdkApiVersion()|表示设备当前版本API级别。版本预置值，通常是整数，无需修改。|
         |版本ID|GetVersionId()|在所有设备范围中用于唯一标识版本。不超过127个字符。 由多个字段拼接而成：$(设备类型) + '/' + $(公司英文名简称) + '/' + $(品牌英文名称) + '/' + $(产品系列英文名称) + '/' + $( 操作系统及版本号 ) + '/' + $(型号) + '/' + $(内部软件子型号) + '/' + $(系统软件API level ) + '/' + $(差异版本号) + '/' + $(构建类型)|
         |安全补丁级别|GetSecurityPatchTag()|表示当前OS的安全补丁级别。按实际情况填写，例如2020-12-01。不超过64个字符。|
         |版本Hash|GetBuildRootHash()|默认为空。|
         [**表2**设备参数说明]

      4. 填写认证联系人信息，选择认证机构与预约认证时间。 注意
         > * 三方委托机构的系列化认证能力已经成熟，需选择三方委托机构提交系列化认证。如果选择HarmonyOS认证实验室，将会被驳回。
         > * 提交预约认证之前，请先联系测评机构的接口人，确认预约认证时间和认证相关事宜。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/e_r8M4Q9SM6RCJx7RaHuuA/zh-cn_image_0000002622925865.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=D6FDC0ED84A965EFD1DCC934E92BCFA6535BA099A15531BEBB8F5FC37EEE7CAD "点击放大")
   3. 单击"提交"。预约认证提交成功后，可以查看"预约认证结论"。
      * 如果"华为预约审核"中所有认证项显示"通过"，可以继续下一步。
      * 如果"华为预约审核"中存在认证项显示"不通过"，请单击提示信息中的"补充材料"，尽快根据意见修改，并重新上传认证材料。 说明
        >
        > 对于"HarmonyOS Connect 品牌审核"、"产品配网图认证"、"硬件/国家/行业/商品资质"三个认证项，如果未通过材料审核，伙伴重新提交认证时，只需提交未通过的认证项的相关材料即可，已通过的认证项无需重复审核。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/GhbjZi3iQFmS7CpocBy7iA/zh-cn_image_0000002592446446.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=7B22774948AF56463A3500775B35087CBB68029858D3D413CE98460AC4D9687E "点击放大")

5. 完成样机投递。

   > 说明
   > * 根据认证产品的实际情况，华为认证测试团队将决定是否需要寄送样机。如果无需寄送样机，可以忽略当前步骤，直接进入"技术认证"环节。如需寄送样机，需同时寄送主型号以及所有子型号。
   1. 按照"样机投递"页面显示的地址，完成样机投递。
   2. 填写样机寄送的快递单号。


   3. 单击"提交"，可以在"技术认证"页面查询认证进展。

6. 查看认证结果。

   * 如果预审材料审核失败，则需要单击上方的"补充材料"，根据审核意见上传认证材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/c5yjexuJSEWxpSbfm0_e0w/zh-cn_image_0000002622766005.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=5E71C01CD118C4027C34D56614AF91EFA804F7E7166B8F6E9A558463DDA39FDD "点击放大")

   * 如果"技术认证"页面存在认证项显示"未通过"，则需要根据测试意见修改后，重新提交认证申请。
   * 如果"技术认证"页面的所有认证项均显示"通过"，则可等待授权发证。在"技术认证"页面，可以获取认证证书。
