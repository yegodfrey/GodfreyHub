# 升级认证

介绍如何开展升级认证。

## 适用范围

待认证产品曾通过HarmonyOS Connect认证，仅基于已认证产品做了软件缺陷修复或固件升级，可以采用升级认证。

* 典型适用场景包括设备侧固件SDK变更、手机侧卡片变更或卡片图文资源变更、或设备侧和手机侧软件不变仅因HarmonyOS Connect认证标准变更（含配套法规标准变更）所导致的升级

  |典型适用场景|场景说明|场景适用举例|
  |:---------------|:---------------------------------------------------------------------|:-------------------------------------------------------------------------------------|
  |设备侧SDK版本升级|同型号产品仅固件镜像的HiLink SDK版本或芯片SDK版本新增特性导致的升级。|已通过HarmonyOS Connect认证的产品升级HiLink SDK版本支持全屋特性。 已通过HarmonyOS Connect认证的产品升级芯片SDK版本优化性能。|
  |设备侧SDK补丁升级|同型号产品仅固件镜像的HiLink SDK版本或芯片SDK版本修复缺陷或漏洞导致的升级。|已通过HarmonyOS Connect认证的产品的OpenHarmony升级安全漏洞补丁可选用的认证模式。|
  |手机侧H5或FA卡片升级|同型号产品设备侧固件镜像相同，仅手机侧H5或FA卡片变更（含新增特性）导致的升级。|产品的智慧生活H5卡片升级，支持更丰富的管理功能。|
  |手机侧H5或FA卡片图文差异升级|同型号产品设备侧固件镜像相同，仅手机侧卡片仅因外观设计存在差异，仅需替换手机侧卡片图文信息的升级。|产品的智慧生活H5卡片替换图片。|
  |认证标准升级|同型号产品设备侧与手机侧软件均相同，仅因HarmonyOS Connect认证标准变更（含配套法规标准变更）所导致的升级 可选用的认证模式。|整机从认证A标升级认证S标。|
  [**表1**升级认证典型适用场景]


* **明确不适用场景**：待认证产品与已认证的产品的品类不同、制造商不同、硬件不同、或PID不同，均不支持升级认证。

## 操作步骤

在已授权产品选择升级后，即可以提交升级认证申请（建议在产品开发和自测前完成），否则会影响产品的后续升级认证流程。

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中，选择"产品开发"。

   1. 在"产品开发"页面，查找到所需升级的产品卡片。
   2. 将鼠标移动到卡片右上方的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/z4ijPTOHR8W8vqTk2JfO7Q/zh-cn_image_0000002622925843.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=89C2C4C066B33CEDC382FF703BF10A3FCD381A127A12D20DBE76412DBC5D5789)，选择"升级"。
   3. 在弹出的窗口中，补充升级说明，并单击"提交"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/I3sXB6WIQQilxr6ONh6qYA/zh-cn_image_0000002592446422.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=16359A436EE36D0BFDF363BA321F71C374EB7B2063C46EFD13CC4A9C51A77080 "点击放大")

3. 在左侧导航栏中，选择"产品认证"，单击"创建认证申请"。
4. 在"新增认证申请"页面，配置产品的认证信息。

   1. 认证方式选择"升级认证"。
   2. 选择本次认证产品。
      1. 单击"选择本次认证产品"。
      2. 在右侧页面中，选择待认证的产品，可以通过产品名称或产品ID进行筛选。
      3. 单击"确定"。
   3. 选择认证测试版本。 不同认证测试版本的差异，详见[认证标准的版本变更说明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/version-vhange-description-0000002622764811)。

   4. 单击"去填写"，按要求填写升级认证申请表，若有一些图片、代码等举证材料，单击"上传补充材料"，将举证材料上传至平台。 华为审核人员将根据提交的申请信息，判别是否可以采用升级认证。

   5. 选择是否"授权华为代为申请OHCA认证"。
      * 是：表示授权华为代为申请OHCA认证。仅支持采用OpenHarmony操作系统的产品。
      * 否：表示不授权华为代为申请OHCA认证，或者产品未采用OpenHarmony操作系统。
   6. 单击"下一步"，提交认证预审。
      * 如果审核未通过，则该产品表明不支持升级认证。
      * 如果审核通过，则需要根据审核结果，启动认证材料的准备，并继续认证流程。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/dFAC497SRT6CSXeq83p5eQ/zh-cn_image_0000002672411853.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=EA8B735BB4C4B352D7731C0ED22AC22A67DE51B74DA2D43F7FDF805E15A735F5 "点击放大")

5. 提交预约认证申请。

   1. 进入"预约认证"页面，单击"产品自测试结果"栏中的"编辑"，跳转至自测试页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/PcAiSFH0SYWD1Tt2OFp3qA/zh-cn_image_0000002592606332.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=A42053B6FAD1FB7C721478660F0AFE559ADF205D91DF44B45A1E760BE7EE5488)

   2. 在"自测试"页面，完成产品自测，上传产品测试报告，并单击"提交"。 "自测试"页面提交的测试报告，将会自动同步至"预约认证"页面。

   3. 重新进入"产品认证 > 预约认证"页面，完善产品认证材料。
      1. 上传设备图片和认证材料（包括法规与商品资质材料、上市营销材料等）。 说明
         >
         > 具体认证材料上传请以实际页面为准。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/2s1dqTDyTsGGtXYEFngflA/zh-cn_image_0000002635253724.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=1FE26984CD90F5AE412E95270718686DD744EA06FB5572EDC4060429B8BD2F2C "点击放大")
      2. 确认"认证测试版本"是否正确。
      3. 配置设备信息。 注意
         >
         > 此处配置的设备信息必须与设备OpenHarmony固件包中保持一致，具体取值可通过[表3](#ZH-CN_TOPIC_0000002592605166__table16625193116571)中API来查询。如果不一致，将无法通过认证。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/KhotyLPBQOSFfP_hZMTqhA/zh-cn_image_0000002592446426.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=21BB6AE184636CED82FB2644765278DAA2AC2519DF5F9F69D31538FB5025AAB3 "点击放大")

         |软件版本号|GetDisplayVersion()|表示整个系统的软件版本号，而非OpenHarmony版本号。不超过64个字符。 > 注意 > 请确保软件版本号与[OTA升级](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ota-upgrade-0000001113552170)中的固件发布版本号保持一致。|
         |硬件设备版本号|GetHardwareModel()|表示设备硬件版本号，不超过32个字符。|
         |系统API Level|GetSdkApiVersion()|表示设备当前版本API级别。版本预置值，通常是整数，无需修改。|
         |版本ID|GetVersionId()|在所有设备范围中用于唯一标识版本。最大支持255个字符。 由多个字段拼接而成：$(设备类型) + '/' + $(公司英文名简称) + '/' + $(品牌英文名称) + '/' + $(产品系列英文名称) + '/' + $( 操作系统及版本号 ) + '/' + $(型号) + '/' + $(内部软件子型号) + '/' + $(系统软件API level ) + '/' + $(差异版本号) + '/' + $(构建类型)|
         |安全补丁级别|GetSecurityPatchTag()|表示当前OS的安全补丁级别。按实际情况填写，例如2020-12-01。不超过64个字符。|
         |版本Hash|GetBuildRootHash()|默认为空。|

      4. 填写认证联系人信息，选择测评机构与预约认证时间。 注意
         > * **升级认证目前只能选择** **HarmonyOS认证实验室**。
         > * 提交预约认证之前，请先联系测评机构的接口人，确认预约认证时间和认证相关事宜。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/4tQG30t-Rjq014HBvG2u2A/zh-cn_image_0000002622765993.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=715991610AF0E1F5322E61558AF0113235409B42DECEEDB4A99B0FE8DAA6BD2D "点击放大")
   4. 单击"提交"。预约认证提交成功后，可以查看"预约认证结论"。
      * 如果"华为预约审核"中所有认证项显示"通过"，可以继续下一步。
      * 如果"华为预约审核"中存在认证项显示"不通过"，请单击提示信息中的"补充材料"，尽快根据意见修改，并重新上传认证材料。 说明
        >
        > 对于"HarmonyOS Connect 品牌审核"、"产品配网图认证"、"硬件/国家/行业/商品资质"三个认证项，如果未通过材料审核，伙伴重新提交认证时，只需提交未通过的认证项的相关材料即可，已通过的认证项无需重复审核。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/-15BfV7MRHSRzj_7yVEuJQ/zh-cn_image_0000002592606338.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=B70307ED8B29D9EC18D1186F6F015A5EE0DBC5D6DCD5B20BDA8C04CB17E515C4 "点击放大")

6. 根据平台流程指引，进入"样机投递"环节，完成样机投递。

   > 说明
   >
   > 根据认证产品的实际情况，华为认证测试团队将决定是否需要寄送样机。如果无需寄送样机，可以忽略当前步骤，直接进入"技术认证"环节。
   1. 按照"样机投递"页面显示的地址，完成样机投递。
   2. 填写样机寄送的快递单号。
   3. 上传"样机清单"。


   4. 单击"提交"，可以在"技术认证"页面查询认证进展。

7. 在"技术认证"页面，查看认证结果。

   * 如果显示预审材料审核失败，则需点击上方的"补充材料"，根据驳回意见重新上传认证材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/4bGriqU2QYSIdRUKBKDHRQ/zh-cn_image_0000002622925857.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=64791862254DFB7AE48404A21655EE1E2A5B74E44C12BABF687845DA98E76B2A "点击放大")

   * 如果存在认证项显示"未通过"，则需要根据测试意见修改后，重新提交认证申请。
   * 如果所有认证项均显示"通过"，则可等待授权发证。在"技术认证"页面，可以获取认证证书。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/BDmxqQRBR8edbruuyK-_rg/zh-cn_image_0000002592446438.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=B20EF8044C1CC4A893B774E5C5490DCD7B9534AA63FFAE408BBFC281F9FB71FA)
