# PC适配

pc上插件是一个单独的Ability弹框，宽高固定。和手机上的差别是：

1. 在手机上进入插件详情页面插件页面内容是包含状态栏高度的，所以手机上不做沉浸式时需要设置状态栏高度偏移。但是在pc上，插件是一个单独Ability，页面不包含状态栏，不需要设置状态栏偏移。
2. 手机上列表页面不需要显示滚动条，pc上列表需要显示滚动条，不然滚动不方便。
3. pc上有插件详情页面右上角关闭按钮，用户在任何页面可以将整个插件关闭，在关闭插件时需要将整个插件业务逻辑停止并释放内存。
