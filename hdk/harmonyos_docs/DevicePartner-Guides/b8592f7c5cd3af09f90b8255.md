# 配置工程环境

#### 配置依赖项

1. 在DevEco Studio中打开模板工程，等待Gradle同步完成。
2. 进入模板根目录下entry目录中，运行：

   ```
   npm install
   ```

3. 将@Health-ecology-kit文件夹拷贝到/entry/node_modules目录下。  

#### 配置应用包名

您需要修改模板代码的包名为您在[创建HarmonyOS应用](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-for-health-kit-0000001126264886#section17341840271)时的应用包名。

* 修改entry/src/main/config.json中的bundleName：

  ```
  {
    "app": {
      "bundleName": "com.huawei.health.ecology.fa",
      ......
    },
  }
  ```

* 修改entry模块下的包名为您的包名：
  * 使用Refactor -\> Rename更改包名最后一组信息，如可以将包名com.huawei.health.ecology.fa更改为com.huawei.health.ecology.xxx
  * 使用Refactor -\> Move Package更改包名前的信息，如可以将包名com.huawei.health.ecology.fa更改为xxx.xxx.xxx.fa

#### 配置签名

1. 在DevEco Studio工具界面，选择"File \> Project Structure \> Project \> Signing Configs"，取消"Automatically generate signing"勾选。

   <br />

   ![](https://media:101783481642699990 "点击放大")

   <br />

2. 对Debug和Release签名中的项目进行配置：

   <br />

   |项目|内容|
   |:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |Store File(\*.p12)|生成的[密钥文件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-development-preparations-0000001172144685#ZH-CN_TOPIC_0000001172144685__li49151615191413)（p12）|
   |Store Password|生成密钥文件时输入的[密钥库密码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-development-preparations-0000001172144685#ZH-CN_TOPIC_0000001172144685__li842917421940)|
   |Key Alias|生成密钥文件时输入的[密钥的别名信息](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-development-preparations-0000001172144685#ZH-CN_TOPIC_0000001172144685__li11429124212413)|
   |Key Password|生成密钥文件时输入的[密钥对应的密码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-development-preparations-0000001172144685#ZH-CN_TOPIC_0000001172144685__li642910421149)|
   |Profile File(\*.p7b)|获取到的Profile文件，需对应选择调试与发布类型|
   |CertPath File(\*.cer)|获取到的证书文件，需对应选择调试与发布类型|
