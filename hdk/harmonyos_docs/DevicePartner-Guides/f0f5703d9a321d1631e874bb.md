# 开发UI界面

本章节介绍如何基于UI设计稿进行H5 UI界面开发，包括控件开发、暗黑模式适配以及多端适配：

* 控件开发：按照UI设计稿以及[Profile文件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-offline-preparations-0000001241445441#ZH-CN_TOPIC_0000001241445441__li17977131171610)，完成页面控件的开发。
* 暗黑模式适配：默认UI界面设计基于白色模式，还需要针对暗黑模式（深色模式）进行适配。
* 多端适配：默认基于手机进行开发，为了保证H5项目在不同的终端（平板和折叠屏）上呈现良好的显示效果，还需进行平板和折叠屏的适配开发。

#### H5页面控件开发

基于UI设计稿，完成页面的控件开发。以净水器的熄屏控件开发为例，UI设计稿中的控件图如下：

![](https://media:101783481635539892)

1. 通过调用navigator和isScreenSpreade方法判断设备类型为手机、平板还是折叠屏，并设置根节点字体大小。

   <br />

   在项目文件中，选择"src \> store"，右键新建一个"action.js"文件，添加如下方法：

   ```
   // desc 获取手机信息，包含系统和屏幕
   getPhoneInfo({ commit }) {
       let type = 'android';
       let version = '10.0.0';
       let isPad = false;
       let isFold = false;
       let isPortrait = true;
       let isDarkMode = false;
       let font;
       let changeScreen =  false;
       try {
           let ua = navigator.userAgent.toLowerCase();
           let reg, matchInfo;
           if (ua.indexOf('like mac os x') > 0) {
               reg = /os [\d._]+/gi;
               type = 'ios';
           } else if (ua.indexOf('android') > 0) {
               reg = /android [\d._]+/gi;
               type = 'android';
           } else if (ua.indexOf('harmony') > 0) {
               reg = /harmony [\d._]+/gi;
               type = 'harmony';
           }
           matchInfo = ua.match(reg);
           version = String(matchInfo).replace(/[^0-9|_.]/gi, '').replace(/_/gi, '.');
           let isUaPad = /(?:ipad|playbook)/.test(ua) || (['android', 'harmony'].indexOf(type) !== -1 && !/(?:mobile)/.test(ua));
           let getPadLandscape = window.hilink && window.hilink.getPadLandscape && window.hilink.getPadLandscape();
           let isScreenSpreaded = window.hilink && window.hilink.isScreenSpreaded && window.hilink.isScreenSpreaded(); // 折叠屏展开
           //判断横竖屏
           if (window.orientation === 180 || window.orientation === 0) {
               isPortrait = true;
           } elseif (window.orientation === 90 || window.orientation === -90) {
               isPortrait = false;
           }
           isPad = isUaPad || getPadLandscape === 1 || getPadLandscape === 0;
           let browserWidth = document.documentElement.clientWidth;
           
           if (isPad) {
               if (isPortrait || getPadLandscape === 1) {
               // 10为rem换算单位，编写样式尺寸=（设计稿尺寸/10）rem
               // 平板竖屏设计稿宽度为800
                   font = (browserWidth / 800) * 10;
                   window.deviceType = 'pad-S';
                   changeScreen = true;
               } else {
               // 平板横屏设计稿宽度为422.752
                   font = (browserWidth / 422.752) * 10;
                   window.deviceType = 'phone';
                   commit('commitAppData', { statusBarHeight:12 });
               }
           } else {
               if (window.screen.width > 500 || isScreenSpreaded) {
               // 折叠屏设计稿宽度为677
                   font = (browserWidth / 677) * 10;
                   isFold = window.deviceType = 'phone-FoldScreen';
                   changeScreen = true;
               } else {
              //手机设计稿宽度为360
                   font = (browserWidth / 360) * 10;
                   window.deviceType = 'phone'
               }
           }
           document.documentElement.style.fontSize = font + 'px';
           if (type === 'ios') {
               window.hilink.getDarkMode('Ag.getDarkMode');
               window.Ag.getDarkMode = res=> {
                   Number(res) === 2 && (state.isDarkMode = true);
               };
           } else {
               window.hilink && window.hilink.getDarkMode && window.hilink.getDarkMode() === 2 && (isDarkMode = true);
           }
       } catch (err) {
           console.hLog('通过 navigator.userAgent 获取系统类型和版本报错,使用默认配置android 和 10');
       }
       console.hLog(new Time().logTime,
           `获取type为${type + version}, ${(isPad ? '平板' : '非平板') + ',' + (isFold? '折叠屏' : '非折叠屏') + ',' + (isPortrait ? '竖屏' : '横屏')}
   }`
       );                
          
       commit('commitAppData', { type, version, isPad, isDarkMode,  isFold, isPortrait, changeScreen});
   }
   ```

   <br />

2. 在项目文件中，打开"src \> App.vue "，设置设备控制页样式并调用getPhoneInfo方法。

   <br />

   ```
   // 在script标签中添加如下代码：
   export default {
       name:'App',
       methods: {
           initApp() {
               this.$store.dispatch('getPhoneInfo');
           }
       },
       created() {
           this.initApp();
           window.onResume = () => { // 手机后台恢复
               this.initApp();
           };
       }
   }
   // 在style标签中添加如下代码：
   /* 重置浏览器默认样式 */
   body{
       margin: 0;
       padding: 0;
   }
   /* 对id="app"的容器设置样式 */
   #app {
       width: 100vw;
       height: 100vh;
       overflow: hidden;
       background-color: #f1f3f5;
   }
   ```

#### 多端适配

各类设备的显示屏幕大小不一、分辨率不一、最佳可视效果的横竖设置也不同，为了保证H5项目在不同的终端（手机、平板和折叠屏）上呈现相同的显示效果，需要进行多端适配的界面开发。

1. 确认已完成[设备类型的判断](#ZH-CN_TOPIC_0000001196845512__li155201569393)。
2. 在"src \> App.vue "组件中，参考[多端适配设计规范](https://developer.harmonyos.com/cn/docs/design/des-guides/grid-0000001152294268)，针对折叠屏、平板样式的不同点进行适配开发。

   <br />

   以平板竖屏为例：

   ```
   <template>
       <div id="app"
            :class="{appDark :isDarkMode, widthLong:changeScreen , portrait_pad:isPad  && changeScreen}">
           <!--portrait_pad:isPad &&changeScreen是平板 -->
           <!--widthLong:changeScreen是大屏幕 -->
           <transition :name="transitionName">
               <keep-alive>
                   <router-viewclass="Router" />
               </keep-alive>
           </transition>
       </div>
   </template>
   <script>
       import { mapState } from 'vuex';
       export default {
           computed: {
               ...mapState(['isDarkMode', 'isPad', 'changeScreen'])
           },
       }
   </script>
   // 当设备为平板时，margin=24px
   <style lang="less" scoped>
   #app.widthLong {
       .home_cell_box
       {
          margin:0 1.2rem
       }
   }
   #app.portrait_pad {
       .home_cell_box
       {
          margin:0 2.4rem
       }
   }
   </style>
   ```

   <br />

#### 暗黑模式

设备包含正常模式和深色模式，两种模式在UI界面需呈现不一样的色彩设置。通过调用getDarkMode接口，获取当前模式：1表示正常模式，2表示深色模式。

1. 打开"src \> store \>action.js"，在多端适配添加的getPhoneInfo方法中，添加如下代码：

   <br />

   ```
   if(type =='ios') { // iOS平台：入参需要resultCallback回调    
       window.hilink.getDarkMode('Ag.getDarkMode');
       window.Ag.getDarkMode = res=> {
           Number(res) === 2 && (this.$store.state.isDarkMode = true);
       }
   } else { // Android平台：入参不需要resultCallback回调
       window.hilink && window.hilink.getDarkMode && window.hilink.getDarkMode() === 2 && (this.$store.state.isDarkMode = true);
   }
   ```

   <br />

2. 在"src \> App.vue "组件的中style标签中，添加如下代码：

   <br />

   ```
   #app {
       background-color: #F1F3F5; /* 白色模式下的背景色 */
   }
   .appDark
   {
       background: #000 !important; /* 暗黑模式下的背景色 */
   }
   ```

   <br />
