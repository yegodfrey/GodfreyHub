# 工程配置

在获取到华为技术支持人员提供的UX设计稿和模板代码后，按以下步骤进行操作。

1. 进入项目根目录，依次安装依赖包，使用npm install \[tgz\]命令进行安装。输入如下命令：

   <br />

   ![](https://media:101783481633492859)  
   依赖包版本号以实际为准。
   1. 安装h5pro-runtime依赖包：

      ```
      npm install ./h5pro-runtime-0.3.5.tgz
      ```

   2. 安装h5pro-basic-lib依赖包：

      ```
      npm install ./h5pro-basic-lib-0.8.56.tgz
      ```

   3. 安装h5pro-hilink依赖包：

      ```
      npm install ./h5pro-hilink-0.0.6.tgz
      ```

   4. （蓝牙设备请根据业务实际选择，如果需要访问运动健康数据则需执行此步骤；GPRS设备不需要该步骤）安装h5pro-health-engine依赖包：

      ```
      npm install ./h5pro-health-engine-0.9.2.tgz
      ```

   5. 如果需要安装其他依赖包，请在完成上述步骤后，再进行其他依赖包的安装。

   <br />

2. 修改manifest.json配置文件。

   <br />

   修改根目录下的manifest.json文件中app_name、pkg_name、app_id、cert_print字段值。
   * app_name：建议填写在合作伙伴平台上创建产品时填写的产品名称。
   * pkg_name："com.huawei.health.device.${uuid}", uuid替换成从合作伙伴平台下载的zip包解压后的文件夹名称。

     ![](https://media:101783481633531860 "点击放大")

     <br />

   * app_id：替换成从开发者联盟网站应用服务、服务信息下的App ID。
   * cert_print：替换成从开发者联盟网站应用服务、服务信息下的App SECRET。
   * version：按实际情况填写。  
     ![](https://media:101783481633560861)  
     * uuid获取方式：[获取资源包](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-resourcezip-0000001182543252#section15924745191913)后解压资源包，找到product.xml文件里的uuid字段。
     * app_id获取方式：进入开发者联盟网站[管理中心](https://developer.huawei.com/consumer/cn/console#/serviceCards/AppService)，单击"帐号"，选择您的产品，在"服务信息"下找到App ID。
     * cert_print获取方式：进入开发者联盟网站[管理中心](https://developer.huawei.com/consumer/cn/console#/serviceCards/AppService)，单击"帐号"，选择您的产品，在"服务信息"下找到App SECRET。

   ![](https://media:101783481633616862)

   <br />

3. 配置AppId全局变量。

   <br />

   修改项目src\\assets\\js\\global.js中的APP_ID，和manifest.json文件中的app_id值保持一致：

   ```
   export default {
       APP_ID: "xxxxxxx",
       ......
   }
   ```

   <br />

4. 配置蓝牙设备 UUID（非蓝牙设备忽略这一步）。

   <br />

   修改项目src\\assets\\js\\global.js中的SERVICE_ID和CHARACTERISTIC_ID：
   * SERVICE_ID：蓝牙设备特征值对应服务的 UUID（不使用4位的简写，用完整写法的UUID）。
   * CHARACTERISTIC_ID：蓝牙设备特征值的 UUID（不使用4位的简写，用完整写法的UUID）。

   ```
   export default {
       SERVICE_ID: "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxx",
       CHARACTERISTIC_ID: "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxx",
       ......
   }
   ```

   <br />

5. 配置Scope权限列表。

   <br />

   对应的权限在华为开发者联盟申请Health Kit服务时根据业务需要申请。

   修改src\\data\\index.js中登录授权接口login方法，在入参scopes中添加业务所需权限，请参见Scopes权限列表：  

   |领域分类|类型分类|数据类型|读权限|写权限|
   |:----------------|:------------|:-----|:------------------------------------------------------|:-------------------------------------------------------|
   |原子化数据 <br />|健康数据|睡眠数据|"https://www.huawei.com/healthkit/sleep.read"|"https://www.huawei.com/healthkit/sleep.write"|
   |原子化数据 <br />|受限健康数据 <br />|血糖数据|"https://www.huawei.com/healthkit/bloodglucose.read"|"https://www.huawei.com/healthkit/bloodglucose.write"|
   |原子化数据 <br />|受限健康数据 <br />|血压数据|"https://www.huawei.com/healthkit/bloodpressure.read"|"https://www.huawei.com/healthkit/bloodpressure.write"|
   |原子化数据 <br />|受限健康数据 <br />|体温数据|"https://www.huawei.com/healthkit/bodytemperature.read"|"https://www.huawei.com/healthkit/bodytemperature.write"|
   |原子化数据 <br />|受限健康数据 <br />|体脂数据|"https://www.huawei.com/healthkit/heightweight.read"|"https://www.huawei.com/healthkit/heightweight.write"|
   |运动健康解决方案数据 <br />|设备信息|设备信息管理|"https://www.huawei.com/healthkit/extend/device.read"|"https://www.huawei.com/healthkit/extend/device.write"|
   |运动健康解决方案数据 <br />|用户信息|昵称头像|"https://www.huawei.com/auth/account/base.profile"||

   以血糖模板代码为例：

   ```
   scopes: [
       "https://www.huawei.com/auth/account/base.profile",    // 获取用户的昵称、头像等个人信息。
       "https://www.huawei.com/healthkit/extend/device.read"  // 获取设备信息
       "https://www.huawei.com/healthkit/bloodglucose.read",    // 读取血糖数据
       "https://www.huawei.com/healthkit/bloodglucose.write",    // 写入血糖数据
       "https://www.huawei.com/healthkit/extend/device.read"    // 读取设备信息
       "https://www.huawei.com/healthkit/extend/device.write"    // 写入设备信息
   ]
   ```

   <br />
