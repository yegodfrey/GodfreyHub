# UX多端适配和鸿蒙平板、折叠屏适配

UX出图：一套手机，一套平板（内含竖屏和横屏），一套折叠屏。

每套都是按一倍图出的，一倍图是最小作图尺寸，在同一类型上不同分辨率则要以一倍图为基准缩放。

比如手机一倍图的宽是360，不同手机不同的分辨率都是根据这个360缩放。

```
手机一倍图标准宽是360
pad竖屏一倍图标准宽是800
pad横屏一倍图标准宽是424
折叠屏一倍图标准宽是720（以前是677）
```

鸿蒙平板和折叠屏比较特殊，折叠屏展开、平板横竖屏均适配为半模态面板窗口显示，居中显示在屏幕中央。同分辨率的情况下，窗口大小统一为 480x560vp。

参考代码：src -\> App.vue ：

```
 let browserWidth = document.documentElement.clientWidth;
        let font;
        if (this.isPad) {
          // 平板竖屏一倍图：800*1282
          if (this.isPortrait) {
            font = (browserWidth / 800) * 10;
          } else {
            // pad横屏：424*752
            font = (browserWidth / 424) * 10;
          }
        } else if (this.isScreenSpreaded) {
          // 折叠屏：720*1152（之前用677宽）
          font = (browserWidth / 720) * 10;
        } else if (this.os == 'HarmonOS Next' && (this.isRealHarmonPad || this.isRealHarmScreenSpreaded)) {
          // 鸿蒙 平板和折叠屏统一用480
          font = (browserWidth / 480) * 10;
        } else {
          // 手机1倍图 360
          font = (browserWidth / 360) * 10;
        }
        document.documentElement.style.fontSize = font + "px";
```
