# 账号管理

## 企业实名认证，是否一定需法人手持身份证进行申请

不需要。您可以选择对公银行打款认证的方式，完成实名认证。

## 平台是否支持团队成员协同开发

可以。为了便于项目协作，平台支持项目空间所有者（主账号）邀请其他成员（子账号）加入团队，共同参与项目开发与管理，高效完成项目认证。具体操作参见团队账号。

## 如何申请找回账号

如果忘记登录账号、或者实名认证时提示账号已被注册，可以通过如下认证方式申请找回。将所需材料邮件至[devConnect@huawei.com](mailto:devConnect@huawei.com)或者[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)反馈，会有工作人员进行处理。

* **找回企业账号**

  |认证方式|所需提供的材料|
  |:-------|:-----------------------------------------------|
  |人工审核认证|1. 三证合一的营业执照 2. 法定代表人身份证正反面扫描件（或法定代表人手持身份证正反面照片）|
  |对公银行打款认证|1. 三证合一的营业执照 2. 法定代表人身份证正反面扫描件 3. 认证时提供的企业对公账号|

* **找回个人账号**

  |认证方式|所需提供的材料|
  |:------|:-------------------------------------|
  |人工审核认证|1. 身份证正反面扫描件 2. 手持身份证照片|
  |个人银行卡认证|1. 身份证正反面扫描件 2. 手持身份证照片 3. 认证时提供的银行卡卡号|

## 如何修改企业名称

主账号对应的**企业名称**最终将体现在HarmonyOS Connect证书中。在提交认证测试之前，请确保当前的企业名称准确无误。

如果需要修改账号信息中的企业名称，可以执行如下操作。

1. 使用主账号登录[开发者信息设置](https://developer.huawei.com/consumer/cn/console#/mysetting/modUserInfoPer)页面，可以查看当前的企业信息。
2. 单击企业名称旁边的"变更名称"。
3. 在企业证件中，上传由当地工商局出具的《更名函》、按模板填写并上传《合作伙伴直接更名及承诺书》，并提交审核。
4. 等待审核通过后，再次确认开发者信息中的企业名称已更改成功。 注意
   >
   > 请确保认证测试中提交的所有材料中涉及的企业名称，均与平台中显示的企业名称保持一致。否则，将导致认证不通过。

## 使用委托开发的公司信息完成了企业实名认证，如何改成品牌商的公司信息

企业实名认证后，不支持主体变更。

品牌商必须[完成企业实名认证并加入合作计划](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/join-us-0000001134281535)，待产品创建完成后可以[委托其他企业开发产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-management-0000001182172051#section14411856772)。

## 主账号邀请子账号进入团队空间，被邀请者接收邮件邀请后，提示"服务暂不支持"

**问题现象**

被邀请者接收到加入项目的邮件邀请。登录Device Partner平台时，提示"服务暂不支持"。

**可能原因**

子账号在加入团队空间时，未完成实名认证，登录管理中心。

**解决措施**

1. 管理员重新发起邀请。
   1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn)，单击右上角的"管理中心"。 说明
      >
      > 建议使用谷歌浏览器访问，否则可能影响"团队账号"功能的使用。
   2. 在左侧的导航栏中选择"账号管理 > 团队账号"，可以查看团队空间列表。
   3. 找到所需管理的团队空间，单击"成员管理"。
   4. 在成员列表底部，找到状态为"邀请待确认"的成员，单击"重新邀请"。


2. 被邀请者接收邮件后，单击邮件中的 "此处"接受邀请。
3. 在弹出的页面中，完成个人实名认证。


4. 重新登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn)。

## 在平台"基本资料"中申请测试权限，提示"昵称中不能存在特殊符号"

**问题现象**

在Device Partner平台"团队账号 > 基本资料"页面，单击右上方"申请测试权限"，提示"昵称中不能存在特殊符号"。

**可能原因**

Device Partner平台的账号名称可能含有特殊符号或者空格。

**解决措施**

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，进入"管理中心"。
2. 在左侧导航栏选择"账号管理 > 基本资料"。
3. 单击右上角的"账号设置"，在"个人信息"编辑昵称（修改为不带特殊符号和空格的昵称），并单击"保存"。
4. 重新登录账号，即可申请测试权限。
