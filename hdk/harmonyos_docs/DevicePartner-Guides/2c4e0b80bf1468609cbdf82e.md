# 场景联动概述

[智慧场景联动](https://devicepartner.huawei.com/console/duola/homepage)是华为面向消费者领域的智能软硬件开放生态服务，通过聚合“1+8+N”设备能力和应用服务能力，赋能开发者进行一站式的场景开发和运营，为消费者打造更好的智慧全场景生活体验。

#### 前提条件

只有加入“HarmonyOS Connect服务合作伙伴”合作计划、并签署《场景联动服务合作协议》，才能使用场景联动服务。具体步骤如下：

  1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/)，单击右上角“管理中心”。
  2. 在左侧导航栏中，选择“帐号管理 > 合作计划”。
  3. 单击“HarmonyOS Connect服务合作伙伴”卡片的“立即加入”，即可加入当前计划。
  4. 在左侧导航栏中，选择“增值服务 > 场景联动”。

首次进入场景联动页面，需要签署《场景联动服务合作协议》。签署完成后，即可使用该功能。




#### 场景联动创建流程

  1. 在智慧生活App创建场景，创建的场景将自动同步到平台。
  2. 在平台关联已创建的场景，并完成场景信息和运营资源的配置。
  3. 在平台提交预览后，平台将自动下发场景到智慧生活App，伙伴可以在App中完成测试验证。
  4. 在平台提交审核后，审核人员将在5个工作日内完成审核并发布上线。

#### [h2]案例1：一键点亮环闪壳

环闪保护壳可以与拍照类App进行场景联动，为用户带来更便捷的拍照体验。

  * **触发条件：** 用户打开指定的拍照类App，并点按环闪保护壳的开关，自动触发执行场景。
  * **执行任务：** 环闪保护壳的补光灯将自动点亮，无需复杂操作，一键到位。



#### [h2]案例2：音乐灯光秀

用户无法陪伴家人身边一起过节，可以借助家中的智能设备（例如音箱、智能灯、传感器等），为爱人或孩子送上节日祝福，创造一种浪漫氛围。

  * **触发条件：** 在指定时间段内，人体传感器（或门窗传感器、摄像头等设备）识别并判断“有人在家”或“有人到家”时，自动触发执行场景。
  * **执行任务：** 自动播放指定的祝福录音，然后缓缓响起了美妙的音乐，同时智能灯可以按照预先编排的脚本、跟随音乐律动。



#### [h2]案例3：温馨回家

当用户拖着疲倦的身体回家时，家中智能设备纷纷按照预先的设定有序地忙碌了起来，让主人感受到无比的放松与温馨。

  * **触发条件：** 智能门锁（或人体传感器）判断主人回家，自动触发执行场景。
  * **执行任务：** 玄关自然亮起温暖的灯光，智能音箱语音播报“主人，辛苦一天，休息一下吧”，智慧屏自动开启并切换到主人最喜欢的节目，智能养生壶奉上一杯温度恰到好处的茶水。
