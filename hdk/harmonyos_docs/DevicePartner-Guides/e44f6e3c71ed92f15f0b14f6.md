# 适配pc端鼠标事件

现象：某些组件点击方法使用是touch事件(比如亮度条拖动),在手机端没问题，pc上使用鼠标拖动无效。

根因：Vue提供的Vant是一个面向移动端的组件库，因此默认只适配了移动端设备，意味着组件只监听了移动端的touch事件，没有监听桌面端的mouse事件。

如果需要在桌面端使用Vant，可以引入@vant/touch-emulator，该库会在桌面端自动将mouse事件转换成对应的touch事件，使得组件能够在桌面端使用。

```
安装模块
npm i @vant/touch-emulator -S
src -> main.js 引入模块
import '@vant/touch-emulator'
```
