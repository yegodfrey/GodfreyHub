# 概述

本文档用于描述三方伙伴设备通过HarmonyOS Connect云云对接方式接入华为生态的规范，让三方伙伴规范接入。如需了解云云对接套餐设备开发详细指导，实现伙伴自有云平台与华为云平台对接，可参考《HarmonyOS Connect云云对接套餐设备指导书》，此文档集成在Device Partner管理中心-产品开发-集成开发-开发工具-设备集成开发指导文档下载。
