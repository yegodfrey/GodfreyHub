# 简介

公版方案是华为鸿蒙智联平台推出的一套标准化、模块化预开发解决方案，涵盖产品定义和交互设计等核心环节。该方案通过提供统一的技术框架和开发模板，帮助相关品类开发者快速完成产品开发，并支持其他品类开发者高效体验完整开发流程。目前该方案已应用于全屋智能领域，并配套提供业务培训等支持，旨在降低开发门槛、提升开发效率。当前已上线浴霸、吸顶灯品类公版方案，后续会逐步丰富更多品类。  

#### 适用情况

公版方案为可编辑的模版，允许开发者基于现有模版上进行自定义编辑修改。适用于设备智能化开发经验较少，期望快速开发，以及期望快速体验设备开发全流程的开发者。  

#### 开发范围

公版方案模版预开发内容包括：产品定义，交互设计，自测试。  

|名称|标准开发流程|公版方案预开发范围|
|:---|:--------------------------------------|:--------------------------------------|
|产品定义|软硬件定义 物模型定义|物模型定义|
|交互设计|App开发（App设计、页面配置、组件逻辑配置） 多端适配 产品配置 小艺语音|App开发（App设计、页面配置、组件逻辑配置） 多端适配 产品配置 小艺语音|
|自测试|体验测试 OpenHarmony兼容性 其他产品报告|不涉及，需开发者自行完成测试|
