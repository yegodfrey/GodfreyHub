# 总览

鸿蒙南向生态范围分为两种：鸿蒙智选以及鸿蒙智联。鸿蒙智选规范在鸿蒙智联规范基础上增加智选产品要求。 鸿蒙智联分为鸿蒙智联直连云模式以及鸿蒙智联云云对接，本次规范重点为鸿蒙智联通用以及直连云部分规范，针对鸿蒙智联云云模式在《鸿蒙智联云云对接接入规范》中体现。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/znb8_ewASEu1kj4oghi96w/zh-cn_image_0000002421688580.png?HW-CC-KV=V1&HW-CC-Date=20261005T090902Z&HW-CC-Expire=86400&HW-CC-Sign=8CF5C56D374D5E9CA559539F8CE9CD2136E4FD07FF7E725674B2030FAAB82D49)

鸿蒙智联规范聚焦为连接、GUI控制、语音控制、体验一致性、运维、可靠性以及安全隐私、UX等规范，确保设备接入体验保证一致,该规范用语支撑鸿蒙智联生态产品接入。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/p0yeWpB9QnO6RKdZRK2FTQ/zh-cn_image_0000002455287305.png?HW-CC-KV=V1&HW-CC-Date=20261005T090902Z&HW-CC-Expire=86400&HW-CC-Sign=C63F806079BDCE35E5A23149C57BABAF1B10670BAA410E6A3D2C4D30DE61D159)

鸿蒙智联规范分为8大部分

  * 连接体验：主要为鸿蒙智联发现、配网、连接能力。
  * GUI控制：主要为鸿蒙智联手机、平板、中控屏、场景联动能力。
  * VUI语音控制：通过小艺语音控制设备。
  * 体验一致性：鸿蒙智联生态设备在配网、升级、Push消息、上下电等体验一致。
  * 运维规范：设备升级、打点、日志等规范。
  * 可靠性规范：设备连接成功率、稳定性、回连、异常可恢复等规范。
  * 安全隐私：设备数据安全、安全隐私申明规范。
  * UX设计： UX设计规范。
