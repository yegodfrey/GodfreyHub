# 插件本地调试

当前无法在智慧生活环境下进行调试插件，只能在本地工程模拟从智慧生活首页点击卡片跳转到插件首页。在4.1章节创建了一个Empty Ability，在这个module里面有个index.ets，在这里拉起插件页面进行本地开发调试,示例如下：

