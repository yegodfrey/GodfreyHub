# 提交翻译

在平台提交需翻译的字符串，待华为提供译文回稿，合作伙伴获取到回稿后，将相应字符串更新。  

#### 提交翻译字符串

在[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)的"产品开发 \> 交互设计 \> 运动健康App \> [资源配置](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-dp-pre-0000001239194127#section7895815175312) \> 国际化"页面内，下载"H5界面字符串翻译模板"，按模板填写表格、提供截图。

表格填写要求

* 字符串id：可以分辨出企业名称、设备型号，不要超过32个字符。比如：IDS_device_huawei_gt2_H5_1001。
* 中文字符串：字符串中除专有名词外的所有数字，需要用占位符表示。比如：%1$s、建议静坐%2$s分钟后开始测量。
* 英文字符串：只需提供中文字符串的初版翻译，华为会给出准确翻译。
* 字符串所在界面路径：英文路径。将运动健康App切换成英文，记录进入该字符串所在界面的英文路径。
* 如有包括用户协议、使用条款、隐私声明、免责声明，以及其他和法律相关的内容，请在"备注"列进行说明。

![](https://media:101783481622733700)  
需要写明该字符串中的数字是常量还是变量。比如：%1$s=1=fixed number，%2$s=unfixed number

字符串所在界面截图要求

所有截图均为英文界面截图，不能出现中文字符串。  
![](https://media:101783481622764701)  
H5要具备随运动健康App切换语言的能力。使用BasicLib.option.getLocale()方法获取启动时手机语言设置：

```
var locale = BasicLib.option.getLocale() // 语言标识
```

1. 将所有中文字符串翻译成英文字符串。
   * 只需提供初版翻译，华为会给出准确翻译。
   * 如涉及操作步骤的，请提供上一步骤的页面截图，用于翻译时参考。
   * 专有名词不需要翻译也需要注明。
2. 将运动健康App切换成英文，对英文界面进行截图。
3. 将界面上的英文字符串用红框标出，一张图只标一个字符串。图片名称用EcologyDevice_加上字符串id命名，后缀名为.png。  

#### 翻译回稿

![](https://media:101783481622796702)  
小语种下单复数情况最多有6种，如涉及到单复数情况回稿会有6条，具体情况请查看回稿中的Index列。

1. 修改模板代码目录src/assets/i18n/lang中的多语言js文件，添加翻译回稿的字符串。

   <br />

   以中文 zh_CN.js 示例：

   ```
   module.exports = {
       // Language = 中文-中国
       translation_test_01: '开启', 
       translation_test_02: '{number}块饼干', 
       translation_test_03: '当前血压为收缩压 {0}，舒张压 {1}。'// 多个占位符使用方法
       ......
   }
   ```

   <br />

2. 在代码中使用多语言字符串，示例如下（单复数）。

   <br />

   * 在html中使用：

     ```
     <div>{{$t("translation_test_01")}}</div>
     <div>{{$t("translation_test_02",{number: 3})}}</div>
     <div>{{$t("translation_test_03",[120,70])}}</div>
     ```

   * 在js中使用：

     ```
     this.$t("translation_test_01")
     this.$t("translation_test_02",{number: 3})
     this.$t("translation_test_03",[120,70])
     ```

   <br />
