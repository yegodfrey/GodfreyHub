# 配置依赖模块

#### 设置HAP包安装方式

当前工程中一个设备存在多个模块（entry和device模块），且存在模块间的调用，在调试阶段需要同时安装多个模块的hap包到设备中。此时，需要在待调试模块的设置项（在DevEco Studio选择"Run \> Edit Configurations"），勾选"Deploy Multi Hap Packages"。例如entry模块调用device模块，在调试entry模块时，需要同时安装device模块，应该在entry模块的调试设置项中勾选"Deploy Multi Hap Packages"后再启动调试。

#### 添加设备配网与设备控制的依赖模块

1. 在项目目录的"build.gradle"文件中添加maven仓库路径和依赖路径。

   <br />

   ```
   buildscript {
       repositories {
           ...
           maven {
               url 'https://repo.harmonyos.com/maven/public/'
           }
           jcenter()
       }
       dependencies {
           ...
           classpath 'com.huawei.ailifeability:hilink_engine-sdk-ohos-host-netconfig:12.0.2.306'
           classpath 'com.huawei.ailifefeatureability:hilink_engine-sdk-ohos-host-devicecontrol:12.0.2.306'
       }
   }

   allprojects {
       repositories {
           ...
           maven {
               url 'https://repo.harmonyos.com/maven/public/'
           }
           jcenter()
       }
   }
   ```

   <br />

2. 在项目中device目录的"build.gradle"文件中添加依赖。

   <br />

   ```
   dependencies {
       ...
       implementation 'com.huawei.ailifeability:hilink_engine-sdk-ohos-host-netconfig:12.0.2.306'
       implementation 'com.huawei.ailifefeatureability:hilink_engine-sdk-ohos-host-devicecontrol:12.0.2.306'
   }
   ```

   <br />

#### 配置应用权限

配置应用运行时向系统申请的所需权限。

在项目中entry目录的"config.json"文件中添加应用运行时需要向系统申请的权限项。权限项详细描述参见[HarmonyOS应用开发 \> 开发 \> 安全 \> 权限 \> 应用权限列表](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/security-permissions-available-0000001051089272)。

```
"reqPermissions": [
  {
    "name": "ohos.permission.INTERNET"
  },
  {
    "name": "ohos.permission.GET_WIFI_INFO"
  },
  {
    "name": "com.huawei.hilink.framework.permission.BIND_AI_LIFE_CORE_SERVICE"
  }
],
```
