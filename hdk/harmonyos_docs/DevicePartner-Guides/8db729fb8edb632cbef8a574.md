# 了解合作历程与所需资源

围绕[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，根据伙伴接入HarmonyOS Connect生态的合作历程提供了全流程的文档资源，便于伙伴正确获取所需指导、快速完成任务。

#### 了解平台

[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )（以下简称"Device Partner平台"、"合作伙伴平台"或"平台"）是面向AIoT产业链伙伴（以下简称"伙伴"）的一站式服务平台。平台将华为面向消费者体验长期积累的芯片设计、操作系统、连接、云、AI和用户体验设计能力，向生态伙伴全面开放，与伙伴联合创新，共同为消费者提供高品质的智能硬件产品，提升消费者在家居、影音娱乐、运动健康、出行、教育、办公等全场景的智慧生活体验。

通过平台，伙伴可以根据企业身处的行业与产业分工，加入对应的合作计划，获取最新的产品、服务与解决方案。同时，伙伴也可以通过平台更好地进行产业合作，完成产品开发、销售和运营，实现产品的全生命周期管理。  

#### 面向的合作伙伴类型

平台通过广泛的合作来联合行业力量，共同优化产业链效率，实现产业共赢。面向如下几类合作伙伴，具体加入方式参见[成为合作伙伴](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/join-us-0000001134281535)。

* HarmonyOS Connect生态产品合作伙伴 生态产品合作伙伴是基于HarmonyOS Connect技术完成智能硬件产品的开发、认证、量产和推广的合作伙伴。产品可申请获得HarmonyOS Connect认证技术标识。

<!-- -->

* HarmonyOS Connect生态解决方案合作伙伴 生态解决方案合作伙伴是指具备智能硬件解决方案开发、模组生产或芯片设计等服务能力，并通过华为资质审核的生态解决方案商，为HarmonyOS Connect生态产品伙伴提供上述服务，支撑生态产品快速上市。

* HUAWEI HiCar汽车硬件合作伙伴 汽车硬件设备厂商通过获取平台提供的HiCar开放能力与技术支持，快速将车载设备接入HiCar，共享手机丰富的应用生态和服务。
