# 继承性认证

介绍如何开展继承认证。

## 适用范围

已有产品通过HarmonyOS Connect认证，且新产品与已认证产品的品类和功能均保持一致，仅存在不影响软硬件功能特性的改动，可以采用继承认证。

简化继承性认证场景：如果产品仅发生外观、型号、产品名称、非电配件替代等变化，且所有变化明确不影响各项软硬件功能特性，可以申请简化继承性认证。

## 前提条件

已完成产品创建环节。

## 操作步骤

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中，选择"产品认证"，单击"创建认证申请"。
3. 在"新增认证申请"页面，配置产品的认证信息。

   1. 认证方式选择"继承认证"。
   2. 选择继承设备（即已认证的原型机）、以及本次认证产品。支持通过产品名称或产品ID进行筛选。
   3. 选择认证测试版本。 不同认证测试版本的差异，详见[认证标准的版本变更说明](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/version-vhange-description-0000002622764811)。

   4. 单击"去填写"，按要求填写继承性资格申请表，若有一些图片等举证材料，单击"上传补充材料"，将举证材料上传至平台。 华为审核人员将根据提交的申请信息，判别是否可以采用简化继承认证。

   5. 选择是否"授权华为代为申请OHCA认证"。
      * 是：表示授权华为代为申请OHCA认证。仅支持采用OpenHarmony操作系统的产品。
      * 否：表示不授权华为代为申请OHCA认证，或者产品未采用OpenHarmony操作系统。
   6. 单击"下一步"，提交认证预审。
      * 如果审核未通过，则该产品表明不支持继承认证。
      * 如果审核通过，则需要根据审核结果，启动认证材料的准备，并继续认证流程。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/1sVNZq6fR3Gh1XHv5flhZg/zh-cn_image_0000002635248084.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=BC8D8F8D0A9DF05F345F9446C64376DA68BC798ECC2EB63E38CE84B41F3D438B)

4. 提交预约认证申请。

   1. 进入"预约认证"页面，单击"产品自测试结果"栏中的"编辑"，跳转至自测试页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/1Cz2d-66QmiwCf5oGREbiw/zh-cn_image_0000002592606314.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=2972F0992409B3A534BB15A8CCDF5AA2EB3E918B07A8EFDEAD8A7F8F43FE3386)

   2. 在"自测试 > 其他产品报告 > 测试报告上传"中，上传产品测试报告，并单击"提交"。 "自测试"页面提交的测试报告，将会自动同步至"预约认证"页面。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/V-YHSF9zR9a4dyMFsB5RBQ/zh-cn_image_0000002622925829.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=12F9C4553BEEA6FC8D1AD0501CB90BA7015F54CB6F76E148B7F672A8C75B823A)
   3. 在"预约认证"页面，完善产品认证材料。
      1. 上传设备图片和认证材料（包括法规与商品资质材料、上市营销材料等）。 说明
         >
         > 具体认证材料上传请以实际页面为准。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/NGiVF0DcROKYqZ8ABgPOtA/zh-cn_image_0000002635252124.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=48EAD121AC7A24E25E1EFD53083E258F0BA1C1857CB2FE353D136A0B0FEE2760 "点击放大")
      2. 确认"认证测试版本"是否正确。
      3. 配置设备信息。 注意
         >
         > 此处配置的设备信息必须与设备OpenHarmony固件包中保持一致，具体取值可通过表2设备参数说明中API来查询。如果不一致，将无法通过认证。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/VhwHQbPWRm6H36_RPkrRzg/zh-cn_image_0000002622765971.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=DE4FF54D07E489EBB965DF0E90E6B9931944017E1CA8A9AE72F8DB391D56FB8F "点击放大")

         |参数|对应API|说明|
         |:----------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
         |软件版本号|GetDisplayVersion()|表示整个系统的软件版本号，而非OpenHarmony版本号。不超过64个字符。|
         |硬件设备版本号|GetHardwareModel()|表示设备硬件版本号，不超过32个字符。|
         |系统API Level|GetSdkApiVersion()|表示设备当前版本API级别。版本预置值，通常是整数，无需修改。|
         |版本ID|GetVersionId()|在所有设备范围中用于唯一标识版本。不超过127个字符。 由多个字段拼接而成：$(设备类型) + '/' + $(公司英文名简称) + '/' + $(品牌英文名称) + '/' + $(产品系列英文名称) + '/' + $( 操作系统及版本号 ) + '/' + $(型号) + '/' + $(内部软件子型号) + '/' + $(系统软件API level ) + '/' + $(差异版本号) + '/' + $(构建类型)|
         |安全补丁级别|GetSecurityPatchTag()|表示当前OS的安全补丁级别。按实际情况填写，例如2020-12-01。不超过64个字符。|
         |版本Hash|GetBuildRootHash()|默认为空。|
         [**表2**设备参数说明]

      4. 填写认证联系人信息，选择测评机构与预约认证时间。 注意
         > * **继承认证目前只能选择** **HarmonyOS认证实验室**。
         > * 提交预约认证之前，请先联系测评机构的接口人，确认预约认证时间和认证相关事宜。

         ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/rhHn11ecTS-E_fP0o9hvfw/zh-cn_image_0000002592606318.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=937F79AB74EFD0EFFBA5D646E0D4EE136A5FF6135C0C8CABDB3E6DB9D5D027DD "点击放大")
   4. 单击"提交"。预约认证提交成功后，可以查看"预约认证结论"。
      * 如果"华为预约审核"中所有认证项显示"通过"，可以继续下一步。
      * 如果"华为预约审核"中存在认证项显示"不通过"，请单击提示信息中的"补充材料"，尽快根据意见修改，并重新上传认证材料。 说明
        >
        > 对于"HarmonyOS Connect 品牌审核"、"产品配网图认证"、"硬件/国家/行业/商品资质"三个认证项，如果未通过材料审核，伙伴重新提交认证时，只需提交未通过的认证项的相关材料即可，已通过的认证项无需重复审核。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/MsAEtkGBQXeuUQBvbjI8NA/zh-cn_image_0000002622925835.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=D3B190F311A9791B87C59588950E25421BF09D471CD25C8AB9DE8ABC688468D6 "点击放大")

5. 根据平台流程指引，进入"样机投递"环节，完成样机投递。

   > 说明
   >
   > 根据认证产品的实际情况，华为认证测试团队将决定是否需要寄送样机。如果无需寄送样机，可以忽略当前步骤，直接进入"技术认证"环节。
   1. 按照"样机投递"页面显示的地址，完成样机投递。
   2. 填写样机寄送的快递单号。
   3. 上传"样机清单"。


   4. 单击"提交"，可以在"技术认证"页面查询认证进展。

6. 在"技术认证"页面，查看认证结果。

   * 如果预审材料审核失败，则需要单击上方的"补充材料"，根据审核意见上传认证材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/F19Mjx71SPajB_5Do6NJ1A/zh-cn_image_0000002592446412.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=77F74E4A9F96335EEFC3CE01C489F0E0A0A176A5F93C14EF5D738E482BC8EB25 "点击放大")

   * 如果存在认证项显示"未通过"，则需要根据测试意见修改后，重新提交认证申请。
   * 如果所有认证项均显示"通过"，则可等待授权发证。在"技术认证"页面，可以获取认证证书。
