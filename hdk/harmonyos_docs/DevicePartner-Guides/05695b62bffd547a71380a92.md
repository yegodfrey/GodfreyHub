# 获取支持与帮助

#### 支持渠道

为助力伙伴快速接入HarmonyOS Connect生态，我们提供了文档中心（包括指南、API参考与FAQ等）、视频课程、智能客服、在线提单等多种支持渠道，为伙伴提供全方位的技术支持。

* [文档中心](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/document-introduction-0000001163067907)：内容涵盖成为HarmonyOS Connect合作伙伴、产品定义、设备开发、应用开发、量产管理、渠道推广、运营运维等合作历程。其中，[常见问题](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/faq-overview-0000001265081417)汇总了较为常见的FAQ，可以帮助伙伴自助解决问题。
* [视频课程](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/video-resources-0000001168711032)：覆盖Device Partner平台使用、开发工具、解决方案、UX设计、设备开发、应用开发、认证测试等40多个系列课程。
* [智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top?appId=20090)：自助输入、智能联想，智能匹配相关回答。  
  ![](https://media:201787206625229641)  
  伙伴联系产品经理在客服系统录入产品ID后，还可开通人工客服。人工客服目前支持标准开发方案的技术咨询，涵盖UX/UI设计、设备开发、智慧生活App H5开发、FA开发等问题。
* [在线提单](#section9874613539)：当上述方式均无法帮助您解决问题，还可以通过在线提单的方式反馈问题。

我们为伙伴提供了丰富便捷的文档获取方式：

#### 如何使用文档

通常情况下，借助官方文档，可以获取所需的大部分信息。  

#### 了解开发历程，直达所需资源

[合作历程与常用资源](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/obtain-resources-0000001463340909#section141461710499)中汇聚了合作伙伴常用的资源，便于了解接入历程的全貌。伙伴可以根据所需执行的任务，快速跳转对应的节点。  

#### 善用文档目录，快速获取指导

通过文档目录可以了解整体框架和设计思路，有助于伙伴快速找到所需内容。

* 第一章节"从这里开始"是引导，适用于所有伙伴在接入生态的开始阶段学习。
* 中间的若干个章节是主体。仅"方案中心"章节适用于生态解决方案合作伙伴，用于模组认证和上架。其他章节均适用于生态产品合作伙伴，涵盖了产品的整个生命周期，包括产品开发、测试认证、量产管理、渠道推广、运营运维等。
* 最后两个章节"通用参考"与"常见问题"属于参考，供必要时查阅。

当一个节点中包含多个内容模块时，可以通过页面右侧栏的页内导航，了解当前节点的主要内容、并快速跳转到所需的内容模块。  

#### 灵活运用搜索，精准定位内容

* 在整本手册中搜索：在页面右上方的搜索框中，输入关键字，进行全局搜索。在搜索结果页面，添加文档相关的限制条件，可以快速筛选。
* 在手册目录中搜索：在手册左侧导航栏上方的搜索框中，输入关键字，可以快速查找到标题中包含关键字的节点。
* 在单个页面中搜索：按Ctrl+F快捷键，输入关键字，可以在当前页面进行搜索。  

#### 如何在线提单

查阅文档后，仍不能解决的问题，可以通过以下方式进行反馈：  
方式一：通过[HarmonyOS Connect在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)反馈问题。

1. 登录[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)页面，选择"HarmonyOS Connect"问题板块。
2. 选择问题分类。 ![](https://media:201787206625352644 "点击放大")

<!-- -->

3. 在"创建问题"页面，描述问题详情并单击"提交问题"。 提交问题后，通常会在2\~5个工作日内收到回复。有时需要您进一步澄清问题，请及时关注进展并予以回复，以便更好地解决问题。

方式二：通过官网的文档中心反馈问题。  
![](https://media:201787206625385645)  
* 文档修改和版本更新发布需要一定的周期，非紧急问题可以通过该途径反馈。
* 文档反馈系统不支持问题答复。如果问题描述得越清晰，将越有可能得以解决。

1. 选中文档页面中的具体内容，单击"意见反馈"。 ![](https://media:201787206625411646)

2. 在弹出的窗口中，描述问题情况，并单击"确定"。
