# 入口

对于已经连接的设备，用户可以通过多种入口来触发设备控制。

1. 碰一碰 碰一碰已连接设备时，立即拉起控制面板进行快捷控制。无需再次进行设备连接。

   ![](https://media:101783481598198367 "点击放大")

<!-- -->

2. 控制中心 从手机主屏幕右上角向下滑动，打开控制中心，即可使用已添加到控制中心的设备控制服务。点击此处的卡片，可进入设备全屏页面使用更多功能。

   ![](https://media:101783481598362368 "点击放大")

<!-- -->

3. 智慧生活App 通过碰一碰、靠近、扫一扫连接成功或在智慧生活App中完成连接的设备，即会自动在智慧生活中显示相应的服务。

   ![](https://media:101783481598503369 "点击放大")

<!-- -->

4. 负一屏 在手机负一屏可以添加智慧生活的卡片，将常用的设备服务显示在此卡片中，作为设备功能的快捷入口。

![](https://media:101783481598706370 "点击放大")
