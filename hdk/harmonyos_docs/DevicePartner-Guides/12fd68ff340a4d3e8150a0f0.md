# 准备工作

#### 前提条件

已[创建产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-0000001134540425)并完成[产品定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-specifications-0000001194015922)（包括软硬件定义与物模型定义）。开发插件需要掌握HarmonyOS应用开发知识，[学习HarmonyOS应用开发](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_tutorials_QuickStart_ide)。  

#### 搭建开发环境

为确保最佳兼容性，建议您将智慧生活应用与 DevEco Studio 保持版本一致。截至 2026 年 6 月 2 日，若两者版本不匹配，可能会出现未知的兼容性问题。插件使用DevEco Studio 6.1.0 Release 进行开发。

![](https://media:101783481633244856)

创建应用相关信息：

bundleName：com.huawei.hmos.ailife（包名是固定的）

Comatible SDK：6.1.0(23）（如果不接入tv选择5.0.4(16））

Device type：phone、table、2in1、TV（TV是按需选择，不接入TV可以不勾选）

![](https://media:101783481633298857)

entity\`模块主要用于本地调试和开发测试，方便开发者在本地环境快速验证功能和调试代码。\*\*请注意，插件相关的代码不得写入该模块。

修改项目根路径下面的build-profile.json，设置compatibleSdkVersion为16，useNormalizedOHMUrl设置为false，如下所示：

```
{
"products":[
{
"targetSdkVersion":"6.1.0(23)",
"compatibleSdkVersion":"5.0.4(16)",
 "buildOption":{
  "strictMode":{
   "useNormalizedOHMUrl": false
}
}
}
]
}
```
