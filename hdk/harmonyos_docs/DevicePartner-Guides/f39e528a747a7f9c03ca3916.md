# 产品配置

平台提供了场景联动、产品国际化、消息通知等配置功能，以帮助用户更好地了解和使用产品。  

#### 场景介绍

|配置项|适用场景|说明|
|:--------------------------------|:-------------------------------------------------------------|:------------------------------------------------|
|[场景联动](#section071661935011)|可选。仅适用于通信类型为"Wi-Fi"的产品、且仅支持品类功能的联动。|通过设置用户可以配置的设备条件与设备执行动作，可以方便用户根据产品功能来自定义场景。|
|[产品国际化](#section14716919105014)|必选。适用于所有产品。|通过配置智慧生活App相关界面与产品功能的英文描述，可以满足英文用户的使用需求。|
|[消息通知](#section16473219133914)|可选。仅适用于通信类型为"Wi-Fi"，且在物模型中定义了支持消息通知功能（例如"错误和故障服务"、"滤芯耗材"等）的产品。|通过配置消息推送功能，可以将设备故障通知、耗材使用情况等消息发送给用户。|
|[全屋推荐（可选）](#section6484173475010)|可选。仅适用于全屋推荐品类。|软硬件规格定义时已勾选"全屋推荐"且华为产品经理审核通过，才会在产品配置页面生成"全屋推荐"模块。|

#### 操作步骤

#### 进入产品配置

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在平台左侧导航栏中选择"产品开发"，单击待开发的产品，进入产品开发流程。
3. 选择"交互设计"，单击智慧生活App卡片右上方的"进入开发"。
4. 选择"产品配置"。  

#### 配置场景联动（可选）

通过设置用户可以配置的设备条件与设备执行动作，可以方便用户根据产品功能来自定义场景。

1. 在"产品配置"页签下，选择"场景联动"。
2. 配置场景联动的条件与动作，支持如下两种方式：

   <br />

   ![](https://media:101783481595712336)  
   "高级编写"与"编辑"功能两者只能二选一。如果使用"高级编写"后，需要重新使用"编辑"功能，需要先清空"高级编写"窗口所有的配置数据。
   * 编辑：单击右上角的"编辑"，设置用户可以配置的动作执行条件、以及满足条件时可执行的动作。  
     ![](https://media:101783481595742337)  
     配置项中仅支持品类功能。根据产品功能定义的不同，条件和动作支持的可选项也会有所差异，以界面实际显示的选项为准。

     ![](https://media:101783481595781338 "点击放大")

   <!-- -->

   * 高级编写：通过代码编辑的方式配置场景联动。

     1. 单击右上角的"高级编写"，在弹出的窗口中可以查看或编辑场景联动的ifttt配置数据。 ![](https://media:101783481595819339 "点击放大")

     2. 编辑配置。支持对触发条件/执行动作进行动态显示和动态过滤。  

        |分类|说明|配置操作|
        |:---|:----------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
        |动态显示|根据设备状态动态显示提示信息。 <br />|1. 在conditionUIInfo/actionUIInfo结构中，与name字段并列的位置，增加alias字段。 2. 配置alias字段的取值，格式为${sid.cid}或${sid.cid\[0\~n\]}。 * ${sid.cid}：当cid为string类型时，采用此格式。 * ${sid.cid\[0\~n\]}：当cid为string数组类型时，采用此格式。 应用实际显示时，会使用${sid.cid}的当前配置替换别名定义中的变量，并将此别名用于此条件或动作的名称显示。|
        |动态过滤|根据设备状态过滤不适用的选项。 <br /> <br />|1. 在conditionUIInfo/actionUIInfo结构中，与name字段并列的位置，增加enable字段。 2. 配置enable字段的取值，格式为${sid.cid}或${sid.cid\[0\~n\]}。 * ${sid.cid}：当cid为bool类型时，采用此格式。 * ${sid.cid\[0\~n\]}：当cid为bool数组类型时，采用此格式。 如果${sid.cid}/${sid.cid\[0\~n\]}的当前配置值为false，此条件或动作将不会显示。|
        [表2 动态显示与动态过滤配置说明]

        ![](https://media:101783481595888340)  
        enable和alias配置项可以独立使用或一起使用。

        示例：
        * 动态显示：一个单键开关支持开关命名功能（对应profile接口：sid：switch，cid：name），用户可对此开关设置一个别名如："玄关灯"。通过使用动态显示功能，当用户配置场景时，选择开关动作时，可以看到"玄关灯"的提示信息。
        * 动态过滤：若此设备支持开关禁用功能（对应profile接口：sid：switch，cid：enable，0-禁用，1-启用），同时也支持开关状态（对应profile接口：sid：switch，cid：on，0-关，1-开）。通过使用动态过滤功能，当按键被禁用时用户配置场景时，被禁用的按键在界面上不显示。

        在编辑时，只需要增加enable/alias行，其余配置保持不变。

        ```
        "actionUIInfo": [
          {
            "deviceCmd": [
              {
                "propertyinfo": [
                  {
                    "type": "ACTION_VALUE",
                    "value": 1,
                    "characteristic": "on"
                  }
                ],
                "sid": "switch"
              }
            ],
            "name": "打开开关",
            "alias": "打开开关(${switch.name})",
            "enable": "${switch.enable}",
            "promptInfo": 0,
            "type": "",
            "conflict": 1
          },
        ```

        <br />

     3. 复制全量脚本内容，切换到英文后，粘贴替换掉原有内容。  
        ![](https://media:101783481595914341)  
        "中文"和"英文"脚本中的配置必须保持一致，否则会导致不同语言环境的功能存在差异。
     4. 配置完成后点击"确认"。

   <br />

3. 单击"保存"，完成信息提交。

<br />

#### 配置产品国际化（必选）

通过配置智慧生活App相关界面与产品功能的英文描述（当前国际化只支持英文），可以满足智慧生活App英文用户的使用需求。

1. 在"产品配置"页签下，选择"产品国际化"。
2. 单击右上角的"编辑"，分别配置"功能定义"、"App界面显示"及"配网引导"相关的英文信息。

   <br />

   ![](https://media:101783481595940342)  
   * 在配置"配网引导"的英文信息之前，需要先在"App开发 \> 页面配置 \> 配网指导页"完成中文信息的配置，详见[配网指导页](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ai-life-app-page-config-0000001367031904#ZH-CN_TOPIC_0000001367031904__li371444164510)。
   * 伙伴需要自行确保英文信息的准确性。
   * 功能定义：用于配置场景联动时的内容展示，主要为产品功能相关的英文描述。对于含有单位的功能，还需要同步配置对应单位的英文描述，例如时间的单位"分钟"对应的英文描述为"min"。
   * App界面显示：包含"产品基本信息"、"App首页状态栏"和"App界面设计"三个部分。
     * 产品基本信息：用于智慧生活App九宫格中的产品信息展示。
     * App首页状态栏：用于智慧生活App的九宫格中的产品状态展示。
     * App界面设计：用于H5页面中功能名称的展示，仅当为线上开发H5时需要配置。
   * 配网引导：在智慧生活App中，用于手动添加设备时对应的引导信息的内容展示。

   <br />

3. 单击"保存"，完成信息提交。  

#### 配置消息通知（可选）

当产品的某些重要性能发生变更（比如发生故障、需要更新耗材）时，需要以消息通知的方式提醒用户关注和处理。智慧生活App消息中心最多支持5条消息通知，手机消息推送最多支持10条消息通知。

当前支持两种消息通知方式（详见[表3](#ZH-CN_TOPIC_0000001119877078__table96547281420)），伙伴可以根据实际需要进行选择。  

|通知方式|适用范围|通知查看方式|
|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------|
|智慧生活App消息中心|物模型定义中已选择"错误和故障服务"、"滤芯耗材"功能。|用户可以进入智慧生活App"我的"页面，点击右上角的消息通知图标查看消息。|
|手机消息推送|需要同时满足如下条件： * 创建产品时，所选品类支持手机消息推送。例如门锁。 * 物模型定义时，所选功能支持手机消息推送。例如，门锁支持告警事件中低电量告警、撬门告警的消息推送。 * 当前ProdID的产品已开通手机消息推送权限。 说明： 如果某个品类、某个功能、或某款产品期望使用手机消息推送，可以联系产品经理配置相关权限。|用户可以通过手机通知栏，及时获取消息通知。|
[表3 通知方式说明]

1. 在"产品配置"页签下，选择"消息通知"。
2. 单击右上角的"新建通知"。

   <br />

   ![](https://media:101783481595965343)  
   如果"消息通知"界面右上方没有"新建通知"，表明该产品已配置的功能不支持消息通知。

   <br />

3. 配置通知触发条件和通知内容。

   <br />

   ![](https://media:101783481596002344)  

   |配置项|是否必填|说明|
   |:---|:---|:------------------------------------------------------------------------------------------------|
   |触发条件|是|* 功能名称：支持的功能以界面实际显示为准。 * 属性：从每个功能中选择可作为消息通知触发的属性。 * 关系：选择 \>、≧、\<、≦、=、!= 等。 * 取值范围：每个功能-属性下包含的内容。|
   |通知标题|否|简要概括该条消息通知的内容，需要与触发条件-取值范围匹配。不超过16个字，提供中英文版本，中英文版本需严格匹配。|
   |通知内容|是|详细描述该条通知的具体内容，包括触发场景/原因、最终结果、以及解决方案等。不超过64个字，提供中英文版本，中英文版本需严格匹配。|
   |通知范围|是|选择该条通知的接受对象。若该设备可实现共享，可对通知对象进行选择，选择后该条消息将推送至指定用户帐号中。|
   |通知方式|是|自动匹配，无需手动填写。|
   [表4 配置说明]

   <br />

4. 单击"确定"提交。

   <br />

   * 如果通知方式为"智慧生活App消息中心"，提交后即可生效。
   * 如果通知方式为"手机消息推送"，提交后还需联系产品经理进行审核。审核通过后，消息通知功能方可正式生效。

   <br />

#### 全屋推荐（可选）

软硬件规格定义时已勾选"全屋推荐"且华为产品经理审核通过，才会在产品配置页面生成"全屋推荐"模块（如下图所示）。

单击"生成全屋配置文件"，平台自动完成文件配置，一键式使产品具备全屋易维，中控屏等接入能力。

![](https://media:101783481596044345 "点击放大")
