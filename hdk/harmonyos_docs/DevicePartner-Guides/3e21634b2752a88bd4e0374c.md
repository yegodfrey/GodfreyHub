# 简介

目前支持有氧健身器材（跑步机、走步机、椭圆机、划船机、智能单车）和智能跳绳设备通过Native方案接入华为运动健康App。

不同设备类型请分别参考以下指导：

* [有氧健身器材](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/fitness-access-overview-0000001154676954)接入指导
* [智能跳绳设备](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/skipping-rope-overview-0000001200556725)接入指导
