# 入驻华为商城

[华为商城](https://www.vmall.com/)为HarmonyOS Connect认证产品提供电商销售平台。

有合作意向或已完成HarmonyOS Connect认证的伙伴，均可参考[商家入驻要求](https://developer.huawei.com/consumer/cn/doc/distribution/vmall/requirement-0000001054564952)和[商家入驻流程](https://developer.huawei.com/consumer/cn/doc/distribution/vmall/apply-0000001053564973)，提交入驻意向申请。入驻成功后，可以按照进一步指引，将符合条件的产品上架到华为商城。

在入驻过程中遇到任何问题，可以发送邮件至[VMALLBD@huawei.com](mailto:VMALLBD@huawei.com)，获取更多帮助。
