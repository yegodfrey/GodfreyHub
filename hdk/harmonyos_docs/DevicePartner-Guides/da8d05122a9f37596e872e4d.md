# 典型问题

#### 视觉风格类

1. 登录栏的图标、文字、字重、色号需与设计规范一致，避免信息层次模糊，造成视觉障碍。 ![](https://media:101783481596763352 "点击放大")

2. 登录界面中的应用图标可以是合作伙伴的智慧生活App应用图标或企业Logo，而非产品设备图。 ![](https://media:101783481596844353 "点击放大")

3. 状态栏和控制区的图标不应有阴影效果。 ![](https://media:101783481596924354 "点击放大")

4. 界面中的标题、副标题、控件等信息色彩搭配需与HarmonyOS色彩风格一致。 ![](https://media:101783481597012355 "点击放大")

#### 页面布局类

1. 产品图实物大小应按产品形状落在layout内，需预留一定空间避免与其他元素重叠。 ![](https://media:101783481597096356 "点击放大")

2. 带标题栏的二级界面不支持半模态。 ![](https://media:101783481597179357 "点击放大")

3. 隐私声明页面下方，需有操作按钮并固定在弹窗底部。 ![](https://media:101783481597270358 "点击放大")

4. 分割线尺寸不宜过粗，超过文字边距，线条应为轻盈优美，起到上下文分割作用，使文字阅读更轻松。 ![](https://media:101783481597348359 "点击放大")

   ![](https://media:101783481597418360 "点击放大")
5. 合理分布文本字距排版，使页面内容预览轻松无障碍。 ![](https://media:101783481597497361 "点击放大")

#### 交互类问题

1. 设备控制页面内包含了设备的状态和功能控制，其中设备状态须必选并首位排序，功能控制可根据业务需求进行自由排序。 ![](https://media:101783481597573362 "点击放大")

2. 当半模态可滑动最大高度不可扩展时，指示区图标应为向下滑动关闭。 ![](https://media:101783481597655363 "点击放大")

3. 设备出现异常或故障时，提示文本在半模态和全屏状态下有不同的样式，而不是在半模态下同时出现异常提示。 ![](https://media:101783481597738364 "点击放大")

4. 半模态下拉起连接弹窗，半模态应收起后，弹出连接帮助，而不是叠加在半模态顶层。 ![](https://media:101783481597810365 "点击放大")
