# 环境搭建

#### 环境要求

|工具名称|用途说明|版本要求|
|:------|:---------|:-------------------------------------------------|
|Node.js|提供npm环境|v11及以下版本，更高版本存在兼容性问题。|
|Vue CLI|vue.js开发环境|建议使用vue-cli 3.12.0。 vue-cli版本不能太高，vue-cli4.x以上不可用。|

#### 全局环境搭建

1. 安装Node.js，[点击下载](https://nodejs.org/zh-cn/download/)。
2. 配置vue.js开发环境。

   <br />

   ```
   npm install -g @vue/cli@3.12.0
   ```

   <br />

3. vue.js环境安装好后，开始安装H5应用脚手架工具，将tgz压缩包保存到本地并执行以下命令：

   <br />

   ```
   npm install –g ./h5pro-cli-0.4.4.tgz
   ```

   安装脚手架后在命令窗口中输入 h5pro-cli --version，如果打印出版本号，则脚手架工具安装成功。

   ![](https://media:101783481636527912)

   <br />

#### 项目创建运行

环境搭建完成后，创建一个Hello World工程来验证环境是否已配置完成。实际开发项目时，请使用模板代码，请参见[获取模板代码](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-obtain-template-code-0000001195771710)。

1. 在命令窗口输入命令h5pro-cli init \<项目名\>（如h5pro-cli init hello），创建一个H5应用。

   <br />

   ```
   h5pro-cli init <项目名>
   ```

   ![](https://media:101783481636551913)

   此时一个Hello World的H5应用已创建完成。

   <br />

2. 进入项目根目录，使用npm install \[tgz\]命令依次安装依赖包。依次输入如下命令：

   <br />

   ![](https://media:101783481636577914)  
   依赖包版本号以实际为准。  
   1. 安装h5pro-runtime依赖包：

      ```
      npm install ./h5pro-runtime-0.3.5.tgz
      ```

   2. 安装h5pro-basic-lib依赖包：

      ```
      npm install ./h5pro-basic-lib-0.8.56.tgz
      ```

   3. （根据业务实际选择，如果需要访问运动健康数据）安装h5pro-health-engine依赖包：

      ```
      npm install ./h5pro-health-engine-0.9.2.tgz
      ```

   4. 如果需要安装其他依赖包，请在完成上述步骤后，再进行其他依赖包的安装。

   <br />

3. 项目依赖安装完成后，输入以下命令运行工程。

   <br />

   ```
   npm run serve
   ```

   ![](https://media:101783481636602915)

   即可在浏览器里查看运行效果。

   <br />
