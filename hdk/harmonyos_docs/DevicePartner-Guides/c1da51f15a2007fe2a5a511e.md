# 生产商用NFC标签

#### 生成商用标签码流

[申请NFC标签码流](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/nfc-tag-generation-0000001208456327#section26501556201219)中申请的标签码流仅为样例，伙伴需要根据实际的设备参数信息，替换样例码流中的设备信息相关字段，才能生成可用的码流信息。

#### 打印商用标签

商用标签需要满足[打印NFC标签样品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/nfc-tag-generation-0000001208456327#section9932142517476)中的设计要求与选型要求。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260228142626.45067776260198335581699222995329:50001231000000:2800:DCCBCBC70C03D07489E7AA47CF63F59BE1E5A944466E80B1D6AE3548E3B50D7A.png)

标签需贴在不小于标签尺寸规范规定空间的平面上，不得贴于曲面，不得弯曲、折叠标签。

如果机身上没有符合此原则的平面，请勿在机身上粘贴该标签，建议在产品说明书中介绍此功能，或使用可撕除的透明塑料膜引导用户了解此功能。

#### 烧录商用标签

通过批量烧录工具（自行获取），将生成的商用标签码流批量烧录至物理标签中。
