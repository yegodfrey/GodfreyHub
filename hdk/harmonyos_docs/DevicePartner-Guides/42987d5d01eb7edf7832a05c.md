# 概述

合作伙伴在开发蓝牙Mesh设备时，需要严格遵循该规范，以确保设备能够顺利接入HarmonyOS Connect生态。

如无特殊说明，本规范中的“设备”特指蓝牙Mesh设备。

  * 本规范适用于采用“HarmonyOS Connect BLE Mesh方案”的场景。蓝牙Mesh开发方案目前处于试点开放状态。
  * 本规范中未规定的内容，与标准蓝牙协议规范一致。



#### 网络架构

与Wi-Fi设备不同，蓝牙设备（含蓝牙Mesh设备与蓝牙BLE设备）无法直接联网，需要借助网关间接地连接路由器，才能实现设备的联网和远程智能控制。蓝牙设备接入网络后，用户可以通过手机应用（比如智慧生活App），发送控制指令，经过路由器，再经过网关，控制家中的蓝牙设备，如图1所示。

#### 名词解释

  * **蓝牙Mesh网关：** 蓝牙Mesh设备不具备直接联网能力，蓝牙Mesh网关主要解决了蓝牙Mesh设备的联网问题。通过蓝牙Mesh网关，蓝牙Mesh设备可以间接地连接路由器，实现所有联网数据的上传与下发，以及与云端的互联互通。
  * **蓝牙Mesh设备：** 是指支持蓝牙Mesh通信的设备。常见的蓝牙Mesh设备包括灯、插座/开关、传感器等。
    * **长上电设备：** 蓝牙扫描长开的设备，通常指持续供电的设备。
    * **低功耗设备：** 蓝牙扫描会关闭的设备。针对此类设备，网关需要采取特定发包机制。
      * **浅度休眠低功耗设备：** 蓝牙扫描会间隔打开和关闭，关闭时间在5S内的设备。针对此类设备，网关采取多次重传的机制。
      * **深度休眠低功耗设备：** 蓝牙扫描会间隔打开和关闭，关闭时间大于5S的设备。例如传感器产品，蓝牙扫描关闭大约30分钟。
