# 文章创作

介绍如何快捷创建文章，助力场景和智能硬件的推广。

#### 创建文章

  1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/)，单击右上角“管理中心”。
  2. 在左侧导航栏中，选择“增值服务 > 场景联动”。
  3. 在“文章创作”模块中单击“去创建”，进入“创建文章”页面。
  4. 设置文章信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.82058002886830979058861858519391:50530401094331:2800:8DB0CC9A35D4258C95BA408F58AB0851CD16E1C5A00A39E99D625AE2CA31DC61.png?needInitFileName=true?needInitFileName=true)

文章信息在文章发布后，支持二次编辑和提交更新申请，审核通过后将覆盖原数据。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.75451226929227684875692114648113:50530401094331:2800:F8460A214B00657B4310DE7A7C592FE5073F20AACA3C490EA3ED24A2548BE443.png?needInitFileName=true?needInitFileName=true)

     * **封面标题：** 40个字内，后续文章管理、文章发布等环节，均采用该字段作为文章的重要识标。
     * **封面图片：** 建议尺寸1440*810px，单击“上传图片”选择并上传本地图片，将在智慧生活App场景市场等页面进行展示。
     * **关联作者：** 选择已用的作者号。若无可用作者号，则需要[创建作者号](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/scenario-linkage-author-0000001164335845#section45681023183617)。
  5. 编辑文章内容。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.03918284892073534105525558086641:50530401094331:2800:B38788BDC8BF433D844B74E32BB2ADD68BE837503BA9002C3261E6FA9E10CF8F.png?needInitFileName=true?needInitFileName=true)

文章内容在文章发布后，支持二次编辑并提交更新申请，审核通过后将覆盖原数据。

     1. 设置置顶图片与文章主标题。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.25907472162154925404893711963936:50530401094331:2800:785BF3010F8C1C1395E1B2D3578AFD9B4C5C24279E6B624FDFB66705771C6599.png?needInitFileName=true?needInitFileName=true)

        * **置顶图片：** 建议尺寸1440*810px，单击“上传图片”选择并上传本地图片，将在文章详情页面作为置顶图片进行展示。
        * **文章主标题：** 40个字内，将作为文章详情页图内的主标题进行展示。
     2. 根据文章内容编排，添加所需的内容模块，支持添加文本、场景、图片、链接等多种元素。 
        * **添加文本：** 200个字内，展示为一段文本，支持整段加粗。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.77753992088945416815458317356437:50530401094331:2800:5B4DC1306CA9FC3C9E7616108FAB6A003F1739B44B2B110E9B64A361801AC37B.png?needInitFileName=true?needInitFileName=true)

        * **添加场景：** 支持场景详情（1个场景）、场景列表（1~10个场景）和场景缩略图（1~10个场景）的三种场景推荐样式。先选择样式，再选择推荐场景。 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.59398976080756359256717159077191:50530401094331:2800:A2C34C5DFA9FA3A982A5CD3BA2DA081F44CD8543ECD1DD12E15A24EBDE287335.png?needInitFileName=true?needInitFileName=true)

仅支持选择自己且已发布的场景，不支持选择官方或第三方的场景。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.29289661565840206097903991585230:50530401094331:2800:234D1796E1652BEC134296E00842E7E3820431FE68D5813FE6016F93929B6E1D.png?needInitFileName=true?needInitFileName=true)

        * **添加图片：** 建议尺寸1440*810px，单击“上传图片”选择并上传本地图片，将在文章详情页面作为文章插图进行展示。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.31500980947632263582657181257474:50530401094331:2800:4D2786DA9F7AC148006D089CBD662FD672D53E2F1C357B69751AFD066512122C.png?needInitFileName=true?needInitFileName=true)

        * **添加链接：**
          * 运营图片：建议尺寸1312*554px，单击“上传图片”选择并上传本地图片，将在文章详情页面作为商品导购图或活动介绍图进行展示。
          * VMALL链接：请粘贴VMALL的商品链接、活动H5链接等。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.54270644051561602365627946392901:50530401094331:2800:ABC99A0520E984F1ED4DC29B591D3495CA62D32EFBC19AECC52AE0F25594E899.png?needInitFileName=true?needInitFileName=true)

     3. 确认信息无误后，单击“提交预览”，下发预览文章至智慧生活App场景市场页面。
  6. 提交审核。
     1. 打开智慧生活App，选择“场景 > 发现”，在“文章预览”专栏找到预览文章。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.91995509237889580104610762581848:50530401094331:2800:6D59D8664342C39E43F38B6F45FC2C194B80AAD9BCC0E0270407CD6305F22FE9.png?needInitFileName=true?needInitFileName=true)

     2. 检查封面图片、封面标题和作者号是否正确。
     3. 单击封面进入文章详情页，检查置顶图片、文本、图片、场景推荐和商品链接是否正确。
     4. 完成自检后，回到平台单击“提交审核”，进入审核状态。



#### 管理文章

  1. 在平台管理中心的左侧导航栏中，选择“增值服务 > 场景联动”。
  2. 在“文章创作”模块中单击“去管理”，可以查看文章列表。不同状态的文章支持的操作，详见表1。![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.21323612830207268090849820850381:50530401094331:2800:E419DED50662628A0E561727C1730765BAEE3D03993B43948ABD0E8690312246.png?needInitFileName=true?needInitFileName=true)

**表1** 不同状态的文章支持的操作  **状态** | **状态说明** | **查看** 详情 | **编辑** | **提交审核** | **下架** | **撤回** | **删除**  
---|---|---|---|---|---|---|---  
**草稿** | 文章创作的过程中可以保存为“草稿”。 | √ | √ | - | - | - | √  
**预览中** | 文章提交预览后，状态为“预览中”。 | √ | √ | √ | - | - | √  
**审核中** | 文章提交审核后，状态为“审核中”。 | √ | - | - | - | √ | -  
**驳回** | 文章审核被驳回后，状态为“驳回”。 | √ | √ | - | - | - | √  
**已发布** | 文章审核通过后，状态为“已发布”。 | √ | √ | - | √ | - | -  
**已下架** | 文章下架后，状态为“已下架”。 | √ | - | - | - | - | -  
  
  3. 搜索和管理文章：单击“全部作者”或“全部状态”选择目标作者或状态，或在输入框输入搜索词，搜索目标文章。
  4. 查看文章详情。
     1. 在列表的操作区域单击“查看”，进入文章详情页面。
     2. 单击“审批历史”，可以查看该文章的历史审批记录。
