# 创建和配置工程

1. 启动DevEco Studio，选择"Empty Ability(JS)"模板，并单击"Next"。

   <br />

   图1 选择模板   
   ![](https://media:101783481603992467 "点击放大")

   <br />

2. 在Project Type中选择Service，Package Name填写与在HarmonyOS服务开放平台创建的HarmonyOS应用一样的包名。在填写好其它信息之后，单击"Finish"，会自动生成基于"Empty Ability(JS)"的模板工程代码。

   <br />

   图2 配置工程并创建   
   ![](https://media:101783481604042468 "点击放大")

   <br />
