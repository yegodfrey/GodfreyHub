# 合作伙伴平台准备工作

#### 成为合作伙伴

请参见[成为合作伙伴](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/join-us-0000001134281535)完成以下步骤：

1. 注册华为帐号
2. 完成企业实名认证
3. 签署协议
4. 加入合作伙伴计划  

#### 产品定义

#### 创建产品

请参考[创建一款产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-0000001134540425)完成产品的创建，其中"开发方案"请根据设备类型的不同选择以下方案：

* 蓝牙设备选择"标准开发方案"中的"HarmonyOS Connect非华为开放协议方案（BLE）"
* GPRS设备选择"自定义开发方案"，连接方式选择"直连接入"，通信类型选择"其它"  

#### 软硬件定义

请参考[软硬件定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-specifications-0000001194015922)完成产品的定义，其中需注意以下选项：

* 连接方式："碰一碰（NFC）"
* 交互方式："运动健康APP"
* 操作系统：如果产品不涉及操作系统，直接选择"Others"。  

#### 功能定义

1. 产品定义完成后，选择"交互设计"页签，并单击"运动健康App"模块的"进入开发"，进入"功能定义"页面。
2. 选择"开发方式"为"H5页面开发"，并联系华为技术支持人员确认是否选择自定义设备详情页。
3. 选择设备的"测量方式"：

   <br />

   * 通过App按钮触发测量
   * 在设备上启动测量，结果自动上传到手机（私有协议设备不支持。若有特别需求选择此方式，需提前与华为技术支持人员沟通）

   <br />

4. 选择"产品协议类型"为"私有协议类型"。
5. 保存后单击下一步，进入"资源配置"。  

#### 资源配置

1. 上传产品图。图片格式的具体要求请参见[设计规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/download-0000001199581175#section323004318222)。

   <br />

   |项目|图片要求|
   |:-----------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
   |用于运动健康App|* 图片规格： PNG格式，分辨率288\*288px，透明背景、无投影、无锯齿，边缘轮廓清晰，有高光及反光的实物图。 * 图片形态要求： 覆盖产品全景正面视图。|
   |用于智慧生活App（接入运动健康APP后，可同步在智慧生活APP里展示设备卡片入口）|* 图片规格： * PNG格式，分辨率256\*256px，透明背景、⽆锯⻮， 边缘轮廓清晰，有高光及反光的实物图。 * 图⽚统⼀添加投影，投影要求：10%不透明度 000000，y：6，模糊：8。 * 图片形态要求： 覆盖产品全景正面视图。|

   ![](https://media:101783481633397858)  
   进入"华为运动健康App \> 设备 \> 添加设备"中，可参考已上市设备的描述和图片。

   <br />

2. 填写产品扫描绑定规则，填写完后请单击"保存"。

   <br />

   |项目|填写说明|
   |:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |医疗器械产品|选择产品是否为医疗器械。若为医疗器械，需上传医疗器械注册证件，要求PNG格式，大小为5M以内。|
   |产品名称特征|XX-YY格式。XX为品牌简称，YY为型号。 蓝牙设备广播名称为XX-YY-ZZZZZ格式，ZZZZZ为内部编号。蓝牙设备广播名称总长度不超过15字节。如蓝牙设备广播名称为"HUAWEI-FIT-0123"，则产品名称特征为"HUAWEI-FIT"。 说明： 字符区分大小写。如果有多组名称，可以用";"隔开，如"hw-metis;HUAWEI-FIT"。|
   |匹配规则|选择"前包含"。运动健康App扫描设备时将根据这一规则查找匹配的设备。|
   |绑定时需要输入配对码|对于需要输入配对码的蓝牙设备，则需要勾选"绑定时需要输入配对码"。|

   <br />

3. 单击右上方"编辑"按钮，填写产品卖点，填写完后请单击"保存"。

   <br />

   |项目|填写说明|
   |:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |购买链接（可选）|如有华为VMALL销售链接，则提供链接，否则为空，可以不填。|
   |产品卖点描述|要求描述与图片内容相互对应。 产品卖点图： * 图片规格：分辨率800\*800px，PNG或JPG格式，透明背景、无投影、无锯齿，边缘轮廓需清晰，有高光及反光的实物图。 * 图片上除了产品本身商标、标识以外，不能有任何文字说明。 * 图片形态要求： 图片中包含覆盖全景正面视图（如：血压计、血糖仪、体脂秤等）。 * 数量：1-2张即可，如需添加更多张，请单击"添加"按钮。|

   <br />

4. 单击右上方"编辑"按钮，填写配置向导信息，填写完后请单击"保存"。

   <br />

   |项目|填写说明|
   |:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |绑定向导界面|以图文形式指导用户完成手机与设备的绑定过程。（注：操作步骤，可根据设备的操作流程逐步添加） * 描述： 用一句话清楚描述如何操作唤醒设备，可达到被连接的状态；描述上一步操作后，设备的反馈信息。 * 图片： * 规格：分辨率800\*800px，PNG格式，透明背景、无投影、无锯齿，边缘轮廓需清晰，需有高光及反光的实物图。 * 图片上除了产品本身商标、标识以外，不能有任何文字说明。 * 图片内容：产品全貌或近景+操作部位特写（高亮标记）或者插画手势辅助表示。 绑定向导示例，以血压计绑定为例： * 描述：长按通信键2秒以上，直到屏幕上显示"P"。 * 对应的图片内容：产品全貌+屏幕上显示"P"标识+通信键位置标识。|

   <br />

5. 单击右上方"编辑"按钮，填写国际化信息。具体的界面字符串与功能开发完成后，在此处上传提交翻译。完整的翻译流程请参见[提交翻译](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-translation-0000001239644959)。
6. 单击"下一步"，进入"测量页面开发"。待完成功能开发后，在"测量页面开发"中[上传H5文件](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-resourcezip-0000001182543252#section1683718315194)，并在完成功能调试后，按检视视频要求[上传检视视频](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-app-h5-upload-review-video-0000001239194183)。
