# 获取模板代码

华为提供全流程模板代码以减少开发者的开发周期，请将gitee中[模板代码工程](https://gitee.com/hms-core/hms-health-device-demo)拉取至本地，或下载至本地解压。  
模板代码工程结构如下（其中用粗体表示的目录或文件可根据不同设备实际情况修改）：

```
├─node_modules
│  └─@huawei
│      ├─h5pro-basic-lib      // 为H5应用提供基础API
│      ├─h5pro-cli        // H5应用脚手架工具，用于应用打包
│      ├─h5pro-health-engine      // 提供支持Health Kit能力组件API
│      ├─h5pro-hilink     // 提供蓝牙相关接口、设备绑定、解绑相关接口
│      └─h5pro-runtime       // H5应用底层运行时库
├─public
│   index.html      // 入口页面
│  
├─src
│  │  App.vue     // 根组件
│  │  main.js     // 入口js文件
│  │
│  ├─assets
│  │  │  base.css     // 公共样式文件
│  │  │  
│  │  ├─i18n      // 多语言字符串     
│  │  ├─image     // 图片资源目录（设备图等）
│  │  │  │  
│  │  │  └─dark     // 深色模式图片资源目录
│  │  │          
│  │  └─js
│  │      directives.js     // 指令集合
│  │      global.js     // 存放appid等数据
│  │      jsInjection.js      // 封装的接口请求方法
│  │      log.js      // 日志打印方法
│  │          
│  ├─components     // 项目公共组件
│  │   ConnectModule.vue      // 连接模块
│  │   HeadLine.vue     // 标题栏
│  │   MiddleModule.vue     // 左文字右图标通用组件
│  │   SelectModule.vue     // 下拉框
│  │      
│  ├─router
│  │   index.js     // 路由定义
│  │      
│  ├─views      // 路由页面
│  │   mainView.vue     // 路由首页
│  │      
│  └─vuex     // 状态管理
│      mutations.js     // 修改store里状态的方法
│      state.js     // 管理的状态集合
│      store.js     // vuex实例化
│  manifest.json      // 配置文件
│  package.json     // npm包配置文件
│  README.md      // 项目介绍
│  vue.config.js      // webpack配置
```
