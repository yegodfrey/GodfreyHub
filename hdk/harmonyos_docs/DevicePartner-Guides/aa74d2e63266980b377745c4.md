# 大字体适配

在大字体模式下，单框架插件详情页面可能会出现显示异常。

解决措施，二选一：

1. 字体大小不使用fv，使用vp。fv=vp \* Scale系数，在不缩放时fv=vp。
2. 在组件上设置最大支持的放大倍数属性maxFontScale，适配需要显示的最大缩放倍数。如果不设置，智慧生活默认支持最大缩放倍数：3.2倍。
