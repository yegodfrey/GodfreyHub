# 创建插件应用

插件与智慧生活应用运行于同一进程，因此插件可访问智慧生活的全局状态。为避免因键名冲突导致数据混乱，请在 AppStorage 中创建变量时，务必使用特定前缀以区分宿主应用及其他插件。
