# 其他

## 在AGC上填了两个SHA256指纹证书，如何确认哪个是当前包名对应的指纹证书

* 方式一：使用当前应用对应签名的.p12文件和密码重新生成指纹证书。将生成的指纹证书与AGC上的指纹证书进行对比。


* 方式二：对打包的应用进行解压，多层解压hap包，最终取到"META-INF"目录下的*.EC文件。使用JDK的keytool命令"keytool -printcert -*file* *(文件名)*"查看该EC文件，可以得到指纹证书的信息。将获取的指纹证书信息与AGC上的指纹证书信息进行对比。

## FA卡片的暗黑模式适配无法生效

**问题现象**

暗黑模式适配无法生效，FA卡片只能显示浅色主题。

**可能原因**

"config.json"文件中的主题样式配置了浅色模式、而非自适应模式，导致暗黑模式适配无法生效。

**解决措施**

请确认"config.json"文件中的**colorMode**字段值配置为"auto"。

```screen
"abilities": [{
    "forms": [{
        "colorMode": "auto",
        ......
    }]
    ......
}]
```

## FA开发过程中，如何判断当前设备类型（如手机/平板等）

在FA页面获取当前设备类型，操作步骤如下：

1. 导入模块。

   ```screen
   import deviceInfo from '@ohos.deviceInfo';
   ```

2. 获取设备类型。API详见[设备信息(新)](https://developer.harmonyos.com/cn/docs/documentation/doc-references/js-apis-device-info-0000001139910745)。

   ```screen
   var deviceTypeInfo = deviceInfo.deviceType; 
   ```

   设备类型的取值如下：
   * default：智能手机
   * tablet：平板
   * tv：智慧屏
   * wearable：智能穿戴
   * liteWearable：轻量级智能穿戴
   * smartVision：智慧视觉设备

## FA开发过程中，如何设置沉浸式状态栏和导航栏

* 在Ability或者AbilitySlice中添加如下代码，可以设置状态栏为透明：

  ```screen
  getWindow().addFlags(WindowManager.LayoutConfig.MARK_TRANSLUCENT_STATUS);
  ```

* 在Ability或者AbilitySlice中添加如下代码，可以设置导航栏为透明：

  ```screen
  getWindow().addFlags(WindowManager.LayoutConfig.MARK_TRANSLUCENT_NAVIGATION);
  ```

更多配置请参考**[WindowManager.LayoutConfig](https://developer.harmonyos.com/cn/docs/documentation/doc-references/windowmanager_layoutconfig-0000001054120018)**。

## FA如何跳转至Vmall

1. 确认产品已上架Vmall商城。


2. 获取到产品在Vmall的链接。


3. 参考如下代码，实现链接跳转。

   ```screen
   String url = "vmall://com.vmall.client/product/detail?prdId=xxxxxxxxxx"
   Intent intent = new Intent();
   Operation operation = new Intent.OperationBuilder()
            .withAction(IntentConstants.ACTION_VIEW_DATA)       
            .withFlags(Intent.FLAG_ABILITY_NEW_MISSION)       
            .withUri(Uri.parse(url)).build();
   intent.setOperation(operation);
   context.startAbility(intent, 0);
   ```

  * 设备已经通过认证，需要与华为技术支持人员联系，配置商用环境云端权限。
  * 设备还未通过认证，执行如下操作：
    1. 确保用于调测的华为账号已经在Device Partner平台上申请了测试权限。

    2. 清除智慧生活基础服务缓存后再试。 在手机中选择"系统设置 > 应用和服务 > 应用管理 > 智慧生活基础服务 > 存储"，并分别点击"清除缓存"和"删除数据"。

```screen
LocaleProfile lp = this.getResourceManager().getConfiguration().getLocaleProfile();
Locale[] lls = lp.getLocales();
for (int i = 0; i < lls.length; i++) 
{    
    LogUtil.info(TAG,"Locale:" + lls[i].getCountry());
}
```

相关API请参考[Configuration](https://developer.harmonyos.com/cn/docs/documentation/doc-references/configuration-0000001054238847)。

## 如何查询手机的UDID

HarmonyOS真机调试前，需要申请应用调试证书并注册调试设备。添加手机为调试设备时，可以按如下操作获取手机的UDID：

1. 打开"设置 > 关于手机"，多次点击版本号，打开开发者模式。
2. 打开"设置 > 系统和更新"，在最下方找到"开发人员选项"，打开"USB调试"开关。


3. 使用PC连接手机后，在PC中运行cmd命令。
4. 执行如下命令，返回值即为手机的UDID。

   ```screen
   hdc shell bm get -udid
   ```

## 手机碰一碰拉起FA，提示"该服务暂不支持免安装，需前往应用市场下载"

**问题现象**

原子化服务已上架应用市场，且"config.json"文件中已配置"installationfree"为"true"。碰一碰拉起FA时，手机提示"该服务暂不支持免安装，需前往应用市场下载"。

**可能原因**

提交的.hap包文件大小超过大小限制，详见[应用打包注意事项](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-releaseapp-0000001126380068#section1754010232299)。

**解决措施**

修改原子化服务代码并重新编译打包，确保.hap包文件不超过10MB，并重新上架应用市场。
> 说明
>
> 编译打包完成后，当.hap包文件大小超过10MB时，DevEco工具会给出错误提示。请谨慎处理报错提醒，以免造成不必要的后果。

## 线上开发智慧生活App H5时，设备定时功能未正常执行

**问题描述**

当前手机端时间为9:48，并且设备的定时功能已经手动打开，在设备的定时功能中设定定时范围为"9:49关闭，9:50开启"。

当手机时间到9:49时，该功能并未执行关闭。

**可能原因**

设备的定时功能未按照"先开后关"的执行逻辑。

**解决措施**

目前定时功能的执行流程是"先开后关"，所以正常执行该功能的前提是：当前功能处于关闭状态，并且设定的定时范围是先开后关。

例如，当前手机时间为9:48，定时范围设定"9:49开启，9:50关闭"，按照"先开后关"的逻辑执行即可。

## 线下开发智慧生活App H5时，如何获取Wi-Fi设备状态

可以通过以下两种方式来获取：

* 方式一：参考[获取当前设备信息](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/obtain-current-device-info-0000001077436854)，通过响应消息中的"status"参数实时获取设备状态。
* 方式二：当设备状态发生变化时，主动上报设备信息，从中获取设备状态。可参考以下代码：

  ```screen
  // 接收设备上报数据
  window.deviceEventCallback = res => {
      let data = JSON.hParse(res);
      // 根据上报的数据，获取Wi-Fi设备状态
      if (data.sid === 'switch') {
  	status = data.data.on == 1 ? '在线' : '离线';
      }
  }
  ```

## 系统无法识别hdc命令，如何处理

1. 确认手机已进入开发者模式并开启"USB调试"功能。
   1. 在手机中打开"设置 "。
   2. 选择"关于手机"，查找版本号。
   3. 快速点击"版本号"多次，直到提示开发者模式已打开，返回上一层。
   4. 选择"系统和更新 > 开发人员选项"，并开启"USB调试"。
2. 确认已安装了[DevEco Studio软件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/software_install-0000001053582415)，并找到对应的toolchains，配置环境变量（例如"C:\Users\UserName\AppData\Local\Huawei\Sdk\toolchains"）。
3. 如果adb命令可用、hdc命令无法使用，可以执行**adb kill-server** 命令，停止adb进程。 说明
   >
   > hdc命令使用完成后，如果需要使用adb命令，可以执行**hdc kill**命令，停止hdc进程。

## 在功能调测阶段，使用智慧生活App扫描设备时，显示"未知设备"

**问题现象**

在功能调测阶段，使用智慧生活App扫描设备时，显示"未知设备"。在Device Partner平台查看产品状态，发现该产品处于"已暂停"状态。

**可能原因**

Device Partner平台上的产品超过14天未操作时，产品状态会切换为"已暂停"，云侧会清除该产品的数据来释放空间。智慧生活App获取不到该产品的数据，导致无法识别设备。

**解决措施**

在Device Partner平台重启"已暂停"的产品。

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航中选择"产品开发"，双击"已暂停"的产品。该产品状态将切换为"开发中"。

## 在原子化服务开发中，如何获取并传递MAC地址和SN号

1. 获取MAC地址和SN号。
   1. 打开配网FA的entry模块的Ability类（即com.huawei.suitedemo.MainAbility）。
   2. 在"onStart"方法中加入以下两行代码，即可获取MAC地址和SN号。

      ```screen
      String bleMac = intent.getStringParam("bleMac"); // 此处以蓝牙MAC为例
      String sn = intent.getStringParam("sn");
      ```

2. 传递MAC地址和SN号。 从配网FA跳转至控制FA时，在intent中添加MAC和SN两个参数，即可进行传递。

## 智慧生活App是否支持多个账号同时绑定同一台设备

不支持，设备只能归属于一个账号，可以通过智慧生活App中的设备分享功能供多个账号使用。参见[智慧生活App共享设备](https://consumer.huawei.com/cn/support/content/zh-cn00757522/)。
