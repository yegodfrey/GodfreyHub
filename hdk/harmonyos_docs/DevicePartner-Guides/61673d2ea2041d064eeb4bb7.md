# 双连双控H5开发指导

双连双控设备是一款融合Wi-Fi与蓝牙技术的智能硬件，支持两种配网模式：用户可通过智慧生活App扫描添加设备，若选择"输入Wi-Fi"，将通过Wi-Fi通道完成配网；若选择"稍后设置网络"，则通过蓝牙方式建立连接。在功能运行方面，设备优先采用Wi-Fi通道传输控制指令；当处于非Wi-Fi环境时，可自动切换至蓝牙通道，确保指令响应不受影响。该设计实现了双连接方式的无缝互补，保障设备在不同网络环境下均能稳定运行。
