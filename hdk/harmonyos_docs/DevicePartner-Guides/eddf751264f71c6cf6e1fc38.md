# 进入H5闪白屏

在dark暗黑模式下，进入H5会闪白屏一下，然后正常显示。

src -\> App.vue 增加一个加载圈。

loading 初始值为true，getDevInfoAll获取完快照里将loading值置为false，加载一遍数据之后才消失。

```
<div v-if="loading" id="loading">
      <img src="./assets/img/loading.png" />
    </div>
```
