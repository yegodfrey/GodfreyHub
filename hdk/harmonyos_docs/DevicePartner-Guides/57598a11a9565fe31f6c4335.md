# 多端适配

本章节介绍如何基于低代码开发工具，通过在线编辑的方式，生成适用于不同智能终端（中控屏）的卡片界面样式，可以帮助伙伴减少适配开发工作，提升开发效率。  

#### 适用范围

* 仅支持中控屏的页面编排与效果预览，编排生成的配置文件将同时对中控屏及手机半模态生效。
* 仅支持（自2022年9月24日以后）在平台新创建的产品，暂不支持存量产品。  

#### 功能简介

多端适配界面由组件区（左）、预览区（中）、编辑区（右），以及右上方的操作按钮组成。组件区中会显示该产品已定义的功能列表（包括核心功能与基础功能），其中，核心功能会在预览区默认展示。

* 添加组件：从组件区某个功能中选择所需的组件样式，将组件拖拽到预览区相应位置后释放。例如，将窗帘电机组件的样式4拖拽到预览区，将会显示下图所示效果。
* 移除组件：将预览区中的组件拖拽出预览区灰色背景，确认删除后，即可移除组件。
* 调整组件布局：在预览区通过拖动组件，可以调整组件呈现顺序。
* 编辑组件效果：在预览区中选择需要编辑的组件，并在编辑区对该组件的具体显示效果进行编辑。例如，显示/取消显示枚举选项、调整选项显示顺序、修改功能名称等。
* 其他功能：通过右上方的功能按钮，还可以进行保存、刷新、重置、下载等操作。

#### 前提条件

已[创建产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-0000001134540425)并完成[产品定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-specifications-0000001194015922)（包括软硬件定义与物模型定义）。  

#### 使用多端适配编排页面

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中选择"产品开发"，单击待开发的产品，进入产品开发流程。
3. 选择"交互设计"，单击智慧生活App卡片右上方的"进入开发"。
4. 选择"多端适配"，进入工具界面。

   <br />

   ![](https://media:101783481594684315)  
   如果智慧生活App卡片不包含"多端适配"页签，表明当前产品不支持多端适配功能，可以跳过本章节。

   <br />

5. 选择需要展示的功能组件。

   <br />

   从组件区功能中选择所需的组件样式，将组件拖拽到预览区相应位置后释放。

   <br />

6. 编辑组件的样式。

   <br />

   在预览区中选择需要编辑的组件，并在编辑区对该组件的具体显示效果进行编辑。

   <br />

7. 完成编排后，单击"下一步"进行提交。  

#### 使用多端仿真工具验证功能

平台提供多端仿真工具，可以帮助伙伴快速体验多端适配效果，提升开发效率。  
![](https://media:101783481594712316)  
该工具仅在华为手机上运行。

1. 通过手机登录华为帐号，并添加设备。
   * 认证阶段：在Device Partner平台下载debug智慧生活App，登录对应华为帐号，绑定真实设备。
   * 商用阶段：通过智慧生活App绑定真实设备到对应华为帐号。
2. 请使用华为手机扫描下方二维码，下载智慧生活基础服务beta版本并安装或前往集成开发-测试工具-安卓 App-智慧生活基础服务Beta版（安卓）下载安装。 ![](https://media:101783481594739317 "点击放大")

<!-- -->

3. 安装完成后，点击桌面应用图标，进入"智慧生活基础服务"应用。
4. 选择所需云环境，并点击"确定"。 默认为"商用环境"，设备认证阶段需要选择"认证沙箱"环境，请根据设备注册的实际环境选择确定。

5. 为了使新的环境配置生效，应用会自动关闭，需要手动重新进入应用。
6. 点击"多端适配仿真测试环境"，将显示调试可用的设备列表页面。离线设备不在设备列表显示。
7. 从设备列表中，选择需要调试的设备。蓝牙设备需要手动输入MAC地址。
8. 根据实际调测诉求，选择对应功能（"中控屏仿真页面"或"半模态仿真页面"），进入多端仿真展示页面。 商用环境具备设备实际控制能力，认证沙箱环境中虚拟设备只展示效果。
