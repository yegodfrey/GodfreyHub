# 获取模板代码

华为提供全流程模板代码以减少开发者的开发周期，请将gitee中[模板代码工程](https://gitee.com/hms-core/hms-health-device-fa-demo)拉取至本地，或下载至本地解压。

模板代码工程结构如下（其中需要您修改的代码和文件用粗体表示，具体修改方法请参见[功能开发](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-environment-config-0000001226320161)章节）：

```
└─entry
  ├─node_modules
  │  ├─@health-ecology-kit  // 蓝牙和WIFI JS SDK
  │  └─@hmscore  // HMS帐号登录JS SDK
  └─src
      └─main
        │  config.json   // 应用权限、appid及应用信息配置文件
        ├─java
        │  └─com.huawei.health.ecology.fa
        │     │  MyApplication.java  // 应用主入口
        │     ├─ability
        │     │      JumpAbility.java  // 用于跳转的Ability
        │     │      MainAbility.java  // 原子化服务主入口
        │     ├─central // 应用上下文能力PA接口实现
        │     └─utils // 日志打印、资源转换等工具
        ├─js
        │  ├─connection  // 登录连接页面实例
        │  │  │  app.js
        │  │  ├─common // 用于存放公共资源文件
        │  │  │  └─components  // 登录流程UI控件
        │  │  │     ├─connectFailedDialog  // 连接失败弹窗
        │  │  │     ├─connectingDialog  // 正在连接弹窗
        │  │  │     ├─loginDialog  // 登录弹窗
        │  │  │     ├─permissionForbiddenDialog  // 权限开启提示弹窗
        │  │  │     └─privacyDialog  // 隐私协议内容弹窗
        │  │  └─pages  
        │  │      └─index // 登录页面布局和交互
        │  ├─dashboard  // 设备控制页面实例
        │  │  │  app.js
        │  │  └─pages
        │  │      ├─about  // 关于页面
        │  │      ├─guide  // 使用说明页面
        │  │      ├─index  // 设备交互页面
        │  │      └─settings  // 设备设置页面
        │  ├─hints  // API版本兼容页面实例
        │  ├─share  // 多实例共享资源目录
        │  │  ├─common
        │  │  │  │  config.js  // 配置文件
        │  │  │  │  dataParser.js  // 数据解析类，私有协议伙伴可修改
        │  │  │  │  state.js  // 状态定义类
        │  │  │  ├─components  // 设备控制功能的UI控件
        │  │  │  │  ├─adjusterButton  // 加减调节器按钮
        │  │  │  │  ├─alertHint  // 异常提示栏
        │  │  │  │  ├─countdownButton  // 倒计时组件
        │  │  │  │  ├─deviceDisplay  // 设备展示
        │  │  │  │  ├─deviceStatusCard  // 设备实时状态
        │  │  │  │  ├─dialog  // 弹窗组件
        │  │  │  │  ├─informationPanel  // 设备实时数据
        │  │  │  │  ├─menuButton  // 档位选择按钮
        │  │  │  │  ├─modesSwitchPanel  // 模式切换组件
        │  │  │  │  ├─privacyDialogContent  // 隐私弹窗内容
        │  │  │  │  ├─sliderBar  // 滑动条     
        │  │  │  │  ├─titleBar  // 标题栏
        │  │  │  │  ├─toggleButton  // 开关按钮 
        │  │  │  │  └─toggleSwitch  // Switch开关
        │  │  │  ├─img
        │  │  │  │  ├─base  // 原子化服务基础图片资源，不供开发者修改
        │  │  │  │  └─customised
        │  │  │  │      │  logo_full.png   // 企业完整的LOGO
        │  │  │  │      │  logo_stripe.png  // 企业的横条/文字LOGO
        │  │  │  │      └─A001
        │  │  │  │              device.png   // 设备实物展示图
        │  │  │  │              guide_1.png  // 使用指南图片
        │  │  │  │              guide_2.png
        │  │  │  │              guide_3.png
        │  │  │  │              help_1.png   // 重连帮助示意图
        │  │  │  │              help_2.png
        │  │  │  └─scripts
        │  │  │          centralOperator.js // 应用上下文能力接口
        │  │  │          HuaweiAccount.js // 华为帐号登录接口
        │  │  │          permissionHelper.js // 权限相关接口封装
        │  │  └─i18n  // 多语言字符串
        │  └─style  // 公共样式、颜色字体
        └─resources  // 存放资源配置文件 
            ├─base // 默认场景下资源
            │  ├─element
            │  ├─graphic
            │  ├─layout
            │  └─media
            │          icon.png // 应用图标
            ├─dark
            │  └─element
            ├─rawfile  // 资源文件（如音频文件）存放目录
            └─zh_CN  // 中文场景下字符串资源
                └─element
```
