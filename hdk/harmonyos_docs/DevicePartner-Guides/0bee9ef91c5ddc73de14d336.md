# 准备工作

#### 前提条件

已[创建产品](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-0000001134540425)并完成[产品定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-specifications-0000001194015922)（包括软硬件定义与物模型定义）。  

#### 获取开发资料

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 在左侧导航栏中，选择"产品开发"，并选择一款产品、进入开发页面。
3. 选择"产品定义 \> 物模型定义"，单击右上角下载Profile文件。

   <br />

   ![](https://media:101783481632922850)  
   如果未展现Profile下载入口，可以在"产品定义 \> 物模型定义"下方单击"提交"后，重新查看。

   ![](https://media:101783481632962851 "点击放大")

   <br />

<!-- -->

4. 获取H5 Demo与UX设计规范。

   <br />

   1. 选择"交互设计"，单击智慧生活App卡片右上方的"进入开发"。
   2. 选择"App开发 \> App设计 \> 线下自开发"，即可下载H5 Demo、获取UX设计规范。

   ![](https://media:101783481632996852)

   <br />

#### UX与UI设计

开发H5之前，需要完成UX设计与UI设计。

1. 参考[UX设计规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-overview-0000001198252447)，完成产品交互流程设计，输出UX设计稿。
2. 提交UX设计稿审核。

   <br />

   1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
   2. 在左侧导航栏中，选择"产品开发"，并进入产品开发页面。
   3. 选择"交互设计"，单击智慧生活App卡片右上方的"进入开发"。
   4. 选择"App开发 \> App设计 \> 线下自开发"。
   5. 上传UX设计稿，并提交审核。

      审核人员会在1\~3个工作日内进行审核并反馈意见，伙伴可以在"审核记录"中查看反馈意见。

   <br />

3. 待UX审核通过后，参考[UX设计规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-overview-0000001198252447)以及Profile文件，完成UI设计。

   <br />

   ![](https://media:101783481633022853)  
   UI设计稿的界面功能控件必须与品类Profile保持一致。

   <br />

#### 搭建开发环境

本章节以Vue框架开发H5为例，介绍操作步骤。

1. 配置开发环境。

   <br />

   1. [下载Node.js安装包](https://nodejs.org/zh-cn/download/)，并安装。
   2. 在命令窗口中执行以下命令，安装脚手架工具。

      ```
      npm install -g @vue/cli
      ```

   3. 执行以下命令，检查是否安装成功。如果返回版本号，则表示脚手架工具安装成功。

      ```
      vue --version
      ```

      执行结果会返回版本号信息。

      ```
      2.9.6
      ```

   <br />

2. 在命令窗口执行如下命令，构建H5项目。

   <br />

   命令中的"h5_001"表示项目名称 。

   ```
   vue init webpack h5_001
   ```

   ![](https://media:101783481633053854)  
   H5开发过程中需要遵循的要求参见[H5开发包的要求](#section573073717223)。  

   |目录/文件|说明|
   |:-----------|:--------------------------------------------------------------------------------------------------------------------|
   |build|项目构建（webpack）相关代码。|
   |config|配置目录，包括端口号等。|
   |dist|项目打包文件。|
   |node_modules|npm加载的项目依赖模块。|
   |src|功能开发目录，包含了如下目录或文件： * assets：资源文件夹，如logo等。 * components：组件文件夹。 * App.vue：项目入口文件。 * main.js：项目核心文件。 * store：全局变量及方法文件夹。|
   |static|静态资源目录，如图片、字体等。|
   |test|初始测试目录，用于测试工程是否可以运行。可以根据需要进行删除。|
   |index.html|首页入口文件，用于添加meta信息或统计代码。|
   |package.json|项目配置文件。|
   |README.md|项目说明文档。|
   |其他文件|配置文件，包括语法配置、git配置等。例如：.gitignore文件。|
   [表1 项目文件夹目录说明]

   <br />

3. 使用编辑器打开项目。本节以VSCode编辑器为例：

   <br />

   在菜单中选择"Terminal \> New Terminal"，并执行如下命令加载依赖包。

   ```
   npm install
   ```

   <br />

4. 执行如下命令，运行H5项目。

   <br />

   ```
   npm run dev
   ```

   ![](https://media:101783481633085855)

   在浏览器中访问http://localhost:8100，可以预览项目的运行效果。

   <br />

5. 执行如下命令，对当前项目进行打包。

   <br />

   ```
   npm run build
   ```

   打包完成后，会在"/dist"目录下生成项目文件。

   ```
   ├─h5_001
   │  │─dist
   │  │   └─static
   │  │      index.html
   ```

   至此环境搭建完成，项目可以在本地运行。

   <br />

#### H5开发包的要求

在H5开发过程中，开发包必须遵循如下要求：

* 开发包目录层级不超过10级。
* 开发包中的文件夹名称仅支持字母、数字。文件名称仅支持字母、数字和三种特殊字符（点号". "、中划线"-"以及下划线"_"），不支持空格，文件后缀均为小写。
* 开发包内只能包含以下的文件格式： .json、.js、.css、.png、.jpg、.mp3、.gif、.html、.mp4、.svg、.scss、.styl、.map、.mov、.gz、.ttf、.woff、.woff2、.zip、.eot、.less。

  其中，.mp3、.mp4、.zip格式的单个文件不超过20M，.json、.js格式单个文件不超过10M，其他格式单个文件不超过2M。
* H5开发包中不允许引入外部链接（例如[https://cdn.xxx](https://cdn.xxx/)），所需的资源应作为离线资源直接打包到H5开发包中。
* 正式上架的H5开发包中需要去掉vConsole等调试代码。
