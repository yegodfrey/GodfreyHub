# 集成华为帐号服务

集成华为帐号服务后，原子化服务可以实现华为帐号登录、静默登录、退出和取消授权等功能。

1. [准备开发环境](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-preparations-environment-0000001195338707)。
2. 生成签名证书指纹。

   <br />

   * 方式一：自动生成签名证书指纹。  
     ![](https://media:101783481614401565)  
     DevEco Studio 3.0 Beta2 3.0.0.803及以上版本，才支持自动生成签名证书指纹。

     在IDE完成签名之后，点击"Store file(\*.p12)"后的图标，自动生成签名证书指纹，弹出"SHA-256 certificate fingerprint"窗口。

     ![](https://media:101783481614439566 "点击放大")
   * 方式二：手动配置配置证书指纹。参见[配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-config-app-signing-0000001199412499#section19843722408)的"手动配置配置证书指纹"章节。

   <br />

3. 配置签名证书指纹。

   <br />

   1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
   2. 在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。
   3. 在"项目设置 \> 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。 ![](https://media:101783481614477567)

      ![](https://media:101783481614499568)  
      在"项目设置"页面的"应用"区域，点击"Client Secret"后面的![](https://media:101783481614526569)即可复制Client Secret。
   4. 配置完成后，点击"保存"。

   <br />

4. 集成HMS Core SDK。

   <br />

   1. 在工程"entry"目录下的"build.gradle"文件的"dependencies"中添加如下编译依赖。

      ```
      dependencies {
          implementation 'com.huawei.hms:jsb-ohos-adapter:5.3.0.303'
      }
      ```

   2. 在工程"entry"目录下的"config.json"文件中添加如下配置。

      ```
      "deviceConfig": {
          "default": {
              "allowComponentsProxy": true
          }
      }
      ```

   3. 下载HMS Core SDK、初始化模块和同步工程。参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-integration-hms-core-sdk-0000001149139136#section5534151123313)的"下载HMS Core SDK"、"初始化模块"和"同步工程"章节。

   <br />

5. 完成华为帐号服务功能的开发。参见[华为帐号服务 \> HarmonyOS（JavaScript）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-login-0000001151310900)的"应用开发"章节。
