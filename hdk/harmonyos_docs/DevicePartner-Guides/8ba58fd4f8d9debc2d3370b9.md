# JSAPI使用说明

一、接口挂载说明

智慧生活App将对应的API接口挂载在window.hilink对象上。

H5调用方式通常为：window.hilink.接口名称(参数)  
![](https://media:101783481645664012)  
Android和HarmonyOS 5.0 及以上系统的双连双控蓝牙接口，需挂载在 window.blehilink 对象上。iOS 设备则继续使用 window.hilink。具体实现可参考 src \> utils \> index.js 文件中的封装逻辑。

二、核心封装逻辑（src/utils/index.js）

该模块通过判断当前平台类型，自动选择正确的 hilink 对象，并统一处理同步/异步调用及回调注册。

关键代码片段如下：

```
let {
    type,
    method,
    params = [],
    callback,
    onCallback,
    afterHilinkCalled
  } = args;

  return new Promise((resolve, reject) => {
    // 双连双控，安卓和鸿蒙的蓝牙接口是挂在在bleHilink对象上的，iOS是hilink对象
    let isIOS = getters.isIos();
    let hilink = isIOS ? window.hilink : window.blehilink;
    try {
      // 判断当前的hilink接口是否存在，method为hilink接口名
      if (
        !hilink
        || !hilink[method]
      ) {
        console.hLog(`No ${method}`);
        return;
      }
      if (type === 'sync') {
        let value = hilink[method](...params);
        resolve(value);
      } else {
        // 判断回调方法名
        let callbackName = callback || `${method}Callback`;
        // 解析回调数据
        window[CALLBACKS][callbackName] = (res) => {
          let result = jsonParse(res);
          resolve(result);
          if (onCallback && typeof onCallback === 'function') {
            onCallback(result);
          };
        };
        hilink[method](...params, `${CALLBACKS}.${callbackName}`);
        if (afterHilinkCalled && typeof afterHilinkCalled === 'function') {
          afterHilinkCalled();
        };
      }
    } catch (err) {
      console.hLog(err);
    }
  });
}
```

三、使用示例：查询设备状态

接口描述

方法名：hilink.getDevCacheAll

从智慧生活App本地缓存中，查询当前设备的全部状态。例如，用于H5设备详情页面的设备状态查询。

此接口仅涉及本地调用，不涉及网络请求。

请求参数  

|参数|类型|是否必选|说明|
|:-------------|:-----|:---|:----------------------|
|devId|String|是|取值为"0"，表示当前设备，暂不支持其他取值。|
|json_body|String|否|留空表示获取设备的全部状态。|
|resultCallback|String|是|JS回调。|

2. H5 调用方式

```
hilink.getDevCacheAll("0", "", "resultCallback");
```

3. Web 页面实现回调接收函数

在 HTML/JS 中定义对应的全局函数，用于接收 App 返回的数据：

```
window.resultCallback = function(resultStr) {
  var result = resultStr; // 解析请求的返回结果
  console.log("设备状态数据:", result);
};
```
