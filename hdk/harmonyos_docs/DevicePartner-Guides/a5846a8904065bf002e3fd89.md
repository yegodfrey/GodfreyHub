# UX设计规范

本章节主要适用于鸿蒙智联生态设备UX 设计体验一致性规范。

鸿蒙智联生态设备UX设计规范走线下开发需要通过鸿蒙智联UX审核。建议走线上开发，线上通过拖拉拽方式快速开发设备详情页，可以免UX审核步骤。
