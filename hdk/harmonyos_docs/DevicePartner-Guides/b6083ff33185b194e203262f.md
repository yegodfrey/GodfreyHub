# 查看平台最新动态

合作伙伴可以通过公告中心，及时关注平台的最新动态（例如平台功能的升级，文档、规范、工具的更新等），以更好地适配项目开展。  

#### 查看公告

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn)，单击右上角的"管理中心"。
2. 查看公告详情，可以选择以下任一方式。

   <br />

   * 管理中心上方会循环展示最新的5条公告，单击标题可以跳转查看详情。![](https://media:201787206625984659)
   * 将鼠标移动到右上方的![](https://media:201787206626010660)，在下拉框中单击需要查看的公告标题，即可跳转到相应的"公告详情"页面。

     ![](https://media:201787206626037661)

   <br />

3. （可选）查看更多公告信息。

   <br />

   1. 单击公告详情页面上方面包屑中的"公告中心"，可以查看完整的公告列表。 ![](https://media:201787206626068662)

   2. 单击所需查看的公告所在行的"查看"，即以跳转到相应的"公告详情"页面。

   <br />

#### 订阅公告

伙伴可以通过订阅平台公告，及时获取平台的最新动态。

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，进入"管理中心"。
2. 单击界面右上方的![](https://media:201787206626097663)，进入公告中心。
3. 在公告中心页面，单击"订阅"。
4. 在弹出的窗口中，输入电子邮箱，并单击"订阅"。

   <br />

   * 订阅成功后，如果平台发布公告信息，将会及时推送至伙伴预留的邮箱。
   * 订阅成功后，如果需要取消订阅公告，单击界面右上方的"订阅"，在弹出的窗口中单击"取消订阅"即可。

   <br />
