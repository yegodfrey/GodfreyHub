# 创建产品

在华为智能硬件合作伙伴平台创建产品，获取产品ID，用于[申请NFC标签码流](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-nfc-tag-0000001126105076#section1969227113813)、[关联标签](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-ability-access-0000001126105072)。

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，单击右上角的"管理中心"。
2. 如之前未选择合作类型，请选择加入HarmonyOS Connect生态产品合作伙伴。
3. 在"产品开发"页面，单击"+"号，新建一款产品。
4. 选择产品品类，可以在搜索框中输入品类名称来查找，也可以通过按照品类的分类来查找。
5. 选择方案为"HarmonyOS Connect（BLE）"。
6. 根据界面提示，配置产品的基本信息。

   <br />

   * 产品名称（传播名）：后续的认证证书发放、产品上架等环节，均采用该字段作为产品的重要标识。产品创建成功后不可修改，请谨慎填写。
   * 接入方式：选择"直连接入"。
   * 通信类型：选择"蓝牙BLE"。

   <br />

7. 确认信息无误后，单击"创建"。
8. 在弹出的确认窗口中，单击"确定"。
9. 完善联系人信息，以便及时接收最新的产品动态。

   <br />

   1. 单击"新增联系人"。
   2. 输入联系人的姓名、角色、邮箱、联系电话，并单击![](https://media:101783481639133949)，保存当前联系人的信息。

      联系人信息可以添加一条或多条。
   3. 联系人信息全部添加完成后，单击"确认"。 产品创建成功后，进入产品定义页面，配置产品的软硬件规格。

   <br />

完成以上步骤后，在产品开发页面上可以获取四位字母数字组合的ProdID，即产品ID。请保存该ID，用于[申请NFC标签码流](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-applying-nfc-tag-0000001126105076#section1969227113813)、[关联标签](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/health-fa-ability-access-0000001126105072)。
