# 深色模式适配

系统组件使用的资源放在resources/base、resources/dark路径下会自动适配。

![](https://media:101783481645745014)

自己绘制的组件获取在代码中需要手动赋值的资源，无法使用上面的方式。需要监听智慧生活提供AppStore的字段，示例如下：

```
@StorageProp("currentColorMode")@Watch("currentColorModeChange") currentColorMode:ConfigurationConstant.ColorMode=ConfigurationConstant.ColorMode.COLOR_MODE_NOT_SET;  currentColorModeChange(changedPropertyName: string) {   //暗黑模式切换 }
```
