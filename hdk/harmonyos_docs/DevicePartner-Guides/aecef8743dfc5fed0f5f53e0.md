# 弹出窗

弹出框是一种模态窗口，在弹出框消失之前，用户无法操作其他界面内容，干扰性比较强。通常用来展示用户当前需要的或用户必须关注的信息或操作，其他情况不建议使用弹出框，可考虑通知等其他非模态窗口。

弹出框的内容通常是不同控件进行组合布局。如：文本、列表、输入框、网格、图标或图片。常用于选择或确认信息。

当需要从单个维度或多个维度单选进行组合做选择时使用，分为：时间选择器和其他选择器。

多个滑动选择器可组合使用，界面用语不超长时，选择器的宽度平均分。

#### 类型6：色温选择\&样式选择

* 左图：点击色温按钮时弹出色温选择弹出框，用于选择特定的色温。色温选择采用了标准的冷暖色盘，滑动圆圈选择色温。
* 中+右图：点击颜色按钮时弹出颜色选择弹出框，用于选择特定的颜色。颜色选择采用了标准的RGB色盘，合作伙伴也可以根据灯的性能不同，定制色盘。点击加号收藏当前色盘中选择的颜色，长按收藏的颜色删除该颜色。 滑动色盘中的圆圈选择颜色，颜色选择后，会影响banner区域和按钮区域的色值，需要进行数据交换。

#### 界面用语超长处理

弹出框标题

1. 逐级缩小字号最小到15sp。

![](https://media:101783481629950812 "点击放大")

2. 继续超长时，换行处理，支持换一行。

<!-- -->

3. 继续超长时，使用"..."截断处理。

![](https://media:101783481629985813 "点击放大")

弹出框按钮

1. 按钮不支持换行。
2. 字符串超长，先在均分区域自适应显示。

![](https://media:101783481630023814 "点击放大")

3. 继续超长时，考虑改变布局，左右变上下（若是上下布局，则不考虑此方式）。

![](https://media:101783481630179815 "点击放大")

4. 继续超长时，缩小文本。按钮文本同时逐级缩小，最小字号为9sp。
5. 继续超长时，使用"..."截断处理。

![](https://media:101783481630217816 "点击放大")
