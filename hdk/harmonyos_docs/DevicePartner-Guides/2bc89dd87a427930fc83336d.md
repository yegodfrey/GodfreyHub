# 场景开发

介绍如何快捷创建场景，实现从智能设备之间的互联互通到衣食住娱的全场景打造，提升消费者的全场景体验。

#### 创建场景

  1. **在智慧生活App创建场景** 。
     1. 使用华为手机，在桌面选择“设置 > 登录华为帐号”，使用与合作伙伴平台一致的企业开发者帐号进行登录。若已登录其他帐号，请先退出当前帐号，再重新登录。 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172644.32056570876751686461370586477568:50530401094331:2800:B706BDE8F5B9C81AC7866A03E110D5F2B426B94A1EAF12B04ACB8EC4F5D0F822.png?needInitFileName=true?needInitFileName=true)

        * 建议使用操作系统为EMUI 11.1或HarmonyOS 2.0以上版本的华为手机。
        * 建议使用最新版本的智慧生活App。
        * 如果采用老款手机、低版本操作系统或三方手机，部分系统能力将不可见，无法创建场景。

     2. 打开智慧生活App，单击“+”号，创建场景。
     3. 根据界面提示信息，配置场景图标、场景名称、触发条件和执行任务。 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172644.88111396572694988740241630113020:50530401094331:2800:E8D817EBBFE46390C9AB5AAEB9A587D28A0BE0BC9D4C365C765934F017799258.png?needInitFileName=true?needInitFileName=true)

场景图标和场景名称仅用于开发者自己识别，后续需要在平台中重新设置，最终发布以平台结果为准。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172644.72273692309527671053506738645668:50530401094331:2800:9515FB18173C38BBEDBF43719261D06E0381370392B4CF87F1846C8DE90F0A66.png?needInitFileName=true?needInitFileName=true)![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172644.18203943125923968673010315752296:50530401094331:2800:6051C45914376F5C7AFBB088B9204B88237F77E8304427190022943890971DE5.png?needInitFileName=true?needInitFileName=true)
        * **场景图标：** 单击“编辑”，从30多个icon中选择其一。
        * **场景名称：** 最多可填写10个中文字符。
        * **触发条件：** 单击“+”，选择添加“手动点击”、“指定时间”、“指定位置”、“智能设备”或“系统功能”等条件。
        * **执行任务：** 单击“+”，选择添加“智能设备”、“系统功能”、“影音娱乐”或“控制场景”等任务。

     4. 确认信息无误后，单击“√”。

场景创建成功后，进入“场景 > 我的场景”页面，完成新场景的自检：测试场景是否正常执行、查看场景执行日志定位和排除异常。



  2. **在平台关联场景** 。
     1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/)，单击右上角“管理中心”。
     2. 在左侧导航栏中，选择“增值服务 > 场景联动”。
     3. 在“场景开发”模块中单击“去创建”，进入“创建场景”页面。
     4. 单击“选择场景”，关联App场景，场景发布后不可修改，请谨慎选择。 
        * **授权关联：** 此功能需要开发者授权该账号在智慧生活App上的信息，以获取相关场景，需要开发者同意授权。同意授权后，开发者也可取消授权。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172644.01117532711913074208944569442441:50530401094331:2800:C733AA8C57EF4AE2B38A7E607E97B073668838F4825FE0BCAE1013E73BEB2C96.png?needInitFileName=true?needInitFileName=true)

        * **泛化流程：** 系统会自动对所选场景的触发条件和执行任务进行泛化，并转化为场景流程。如“**连接 HUAWEI Sound X** ”将泛化为“**连接 指定音箱** ”。
     5. 根据界面提示信息，配置场景信息。 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172644.37461963254107887095436887595943:50530401094331:2800:FAC8915651CE1A7EEB56CF996C7C06FA49FA4F4390CE7AAB39D3BBFFFC142C3E.png?needInitFileName=true?needInitFileName=true)

场景信息在场景发布后，支持二次编辑并提交更新申请，审核通过后将覆盖原数据。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.36806726150925261953728482851791:50530401094331:2800:259E94C1CF7066F1993702A317F1F3481366FE8D85EDF9FA85C5506D7A3C2A3B.png?needInitFileName=true?needInitFileName=true)

        * **场景名称：** 10个字内，后续场景管理、场景发布等环节，均采用该字段作为场景的重要识标。
        * **场景简介：** 26个字内，将在场景详情页面进行展示。
        * **场景副标题：** 26个字内，将在场景发现页面进行展示。
        * **关联作者：** 选择已有的作者号，若无可用作者号则需要去作者号管理的页面进行创建。
        * **置顶图片：** 建议尺寸1440*810px，单击“上传图片”选择并上传本地图片，将在场景详情页面进行展示。
     6. 确认信息无误后，单击“确定&下一步”，开始配置运营资源。
  3. 配置运营资源。
     1. 根据界面提示信息，配置运营素材。 

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.07150398808154316034139561710963:50530401094331:2800:7D6FCA3F356320CC09EF9F227E33A3D5B099833C167374307AACEFAD795FE73D.png?needInitFileName=true?needInitFileName=true)

运营资源在场景发布后，支持二次编辑并提交更新申请，审核通过后将覆盖原数据。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.13361629789518611641394783095532:50530401094331:2800:E9392C41E6ED0D80C22A4D6BD5EBE124651F0DE9CCCA0CC4A93717E5C7801756.png?needInitFileName=true?needInitFileName=true)

        * **封面图片：** 将在智慧生活App场景市场等页面进行展示，建议尺寸624*834px，单击“上传图片”选择并上传本地图片，平台提供在线裁剪功能。
        * **场景图标：** 单击“选择图标”从平台提供的30+icon中选择。
     2. 确认信息无误后，单击“提交预览”，下发预览场景至智慧生活App场景市场页面。
  4. 提交审核。
     1. 打开智慧生活App，选择“场景 > 发现”，在“场景预览”专栏找到预览场景。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.94522024199573533963713198865576:50530401094331:2800:635771D4CEEB1EAEC88645885C76AA7A251D252F085668B968685D2B32C4F3DF.png?needInitFileName=true?needInitFileName=true)

     2. 检查场景基本信息、运营资源、场景触发条件和执行任务是否正确，单击“添加到我的场景”。
     3. 选择“场景 > 我的场景”，完成新场景的自检：测试场景是否正常执行、查看“场景执行日志”定位和排除异常。
     4. 完成自检后，回到平台点击“提交审核”，进入审核状态。



#### 管理场景

  1. 在管理中心的左侧导航栏中，选择“增值服务 > 场景联动”。
  2. 在“场景开发”模块中单击“去管理”，可以查看场景列表。不同状态的场景支持的操作，详见表1。![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.63468654554469602985702748046062:50530401094331:2800:D3A06301F3590EE356F8F88D403D9DA59C56D854C082632B95B6B9C6689E2B69.png?needInitFileName=true?needInitFileName=true)

**表1** 不同状态的场景支持的操作  **状态** | **状态说明** | **查看** 详情 | **编辑** | **提交审核** | **下架** | **撤回** | **删除**  
---|---|---|---|---|---|---|---  
**草稿** | 场景开发的过程中可以保存为“草稿”。 | √ | √ | - | - | - | √  
**预览中** | 场景提交预览后，状态为“预览中”。 | √ | √ | √ | - | - | √  
**审核中** | 场景提交审核后，状态为“审核中”。 | √ | - | - | - | √ | -  
**驳回** | 场景审核被驳回后，状态为“驳回”。 | √ | √ | - | - | - | √  
**已发布** | 场景审核通过后，状态为“已发布”。 | √ | √ | - | √ | - | -  
**已下架** | 场景下架后，状态为“已下架”。 | √ | - | - | - | - | -  
  
  3. 搜索目标场景：单击“全部作者”或“全部状态”选择目标作者或状态，或在输入框输入搜索词，搜索目标场景。
  4. 查看场景详情。
     1. 在列表的操作区域单击“查看”，进入场景详情页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220402172645.89307136257556219535832839724362:50530401094331:2800:EC52450E3D0AA99E756983A87171FBB9EC0AAFF352EE4684D82F2A3639943D5C.png?needInitFileName=true?needInitFileName=true)

     2. 单击“审批历史”，可以查看该场景的历史审批记录。
