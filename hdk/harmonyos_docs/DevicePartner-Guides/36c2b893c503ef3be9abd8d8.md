# 调测验证

#### 原子化服务自验证

由于原子化服务是通过碰一碰拉起的，所以在模板里删去了应用图标入口，在调测阶段，可通过先添加应用图标入口，并在代码中指定待连接产品的MAC地址的方式在真机上测试界面效果，并在发布前删去应用图标入口。

1. 添加图标。

   <br />

   将entry/src/config.json中的installationFree改为false，示例代码：

   ```
   ......
   "distro": {
     "deliveryWithInstall": true,
     "moduleName": "entry",
     "moduleType": "entry",
     "installationFree": false
   },
   ......
   ```

   <br />

2. 设置调试用的MAC地址及设备ProductId。

   <br />

   打开entry/src/main/js/connection/common/scripts/constants.js，修改data中对应的字段。示例代码：

   ```
   const data ={
       ......
       customDefaultData:{
           productId: "A001",
           deviceMac: "00:00:00:00:00:00"
       }
       ......
   }
   ```

   <br />

#### 碰一碰自验证

请参阅[调试应用](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/atomic-service-app-debugging-0000001182777249)完成碰一碰拉起原子化服务验证。
