# 插件启动参数

当智慧生活应用拉起插件主页面时，会自动向插件页面传递一组参数，用于初始化页面显示状态。开发者可根据这些参数实现页面的个性化配置。

常见参数列表如下：  

|参数名称|参数类型|说明|
|:-----------|:--------|:--------------------------------------------------|
|deviceId|string|华为设备id|
|role|string|角色，标识当前用户是设备的分享者还是设备的所有者，值：owner-设备的所有者，family-分享用户|
|deviceName|string|华为设备名称，在智慧生活九宫格显示|
|sn|string|设备序列号|
|mac|string|设备mac地址|
|productId|string|dp平台创建的产品id|
|deviceRoom|string|设备所属的房间|
|roomList|Array\[\]|当前家庭的家庭列表，用于修改家庭时显示的数据源|
|deviceStatus|string|WIFI设备会传，online-在线，offline-离线|
[表1]

插件首页获取参数，示例：

PluginMainPage.ets

```
@Builder
export function PluginMainPageBuilder(name: string, param: object) {
    //跳转插件首页
    PluginMainPage({ params: param as Record<string, Object>})
}

@Component
struct PluginMainPage{
 params:Record<string, Object>={}

aboutToAppear()  {
 //获取传递过来的参数
 let deviceId=params['deviceId'] as string
 let deviceName=params['deviceName']as string
 let roomList=params['roomList']as Array[]
}

build{
  ........
}
}
```
