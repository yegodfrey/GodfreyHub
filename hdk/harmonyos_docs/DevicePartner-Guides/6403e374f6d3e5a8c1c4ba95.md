# 设备控制

#### 设备控制分类

设备控制是在蓝牙注册成功后，通过GATT服务通信协议进行通讯，以达到设备控制的目的。

蓝牙设备只有在设备注册成功之后才能进行设备控制。  

#### 跳转到设备控制界面

无论是进入到注册界面，还是进入到设备控制界面，都是首先由智慧生活基础服务拉起意图里配置好的Ability，再在onStart函数里面，解析传递过来的参数。关于参数解析，请参考设备注册的[步骤1](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/atomic-service-device-networking-0000001165828400#ZH-CN_TOPIC_0000001165828400__zh-cn_topic_0000001182617327_li919714588583)。

解析完成之后，再根据传递的参数不同，进行不同的跳转，请参考设备注册的[步骤2](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/atomic-service-device-networking-0000001165828400#ZH-CN_TOPIC_0000001165828400__zh-cn_topic_0000001182617327_li1766316299407)。

在"entry"目录下的"MainAbility.java"文件中，关于跳转到设备控制界面，代码示例如下：

```
// 跳转到设备控制页示例代码
private static final String BUNDLE_NAME = "{your package name}";
private static final String DEVICE_ABILITY_NAME = "{your package name}.DeviceAbility";
private void openDevicePage() {
    Intent intent = new Intent();
    ElementName elementName = new ElementName("", BUNDLE_NAME, DEVICE_ABILITY_NAME);
    intent.setElement(elementName);
    intent.addFlags(Intent.FLAG_ABILITY_NEW_MISSION);
    intent.addFlags(Intent.FLAG_INSTALL_ON_DEMAND);
    mContext.startAbility(intent, 0);
}
```

#### 蓝牙设备控制

1. 在device工程中新建Service Ability。
2. 在"device"目录下的"BleServiceAbility.java"文件中，找到新建的Service Ability类文件，在onStart函数中初始化应用。示例代码如下：

   <br />

   ```
   @Override
   public void onStart() { 
       AiLifeServiceHelper.initApplication(this); 
       super.onStart(); 
   }
   ```

   <br />

3. 在"device"目录下的"BleRemoteObj.java"文件中，进入到控制界面后，当Service Ability收到JS UI发送过来的连接请求时，添加连接设备管理服务的操作。示例代码如下：

   <br />

   ```
     
   public void connectAiLifeService() {

           terminateAbility();

   ```

   <br />

6. 在"device"目录下的"HiLinkDeviceHelper.java"文件中，下发设备控制命令，示例代码如下：

   <br />

   ```
   private HiLinkDevice mHiLinkDevice = null; // 通过步骤3获取 
   private CommandParam commandParam = null;  
   private void sendCommand(String serviceId, String param) {  
       commandParam = new CommandParam.Builder() 
           .mode(ApiParameter.CommandMode.MODE_BLE) // 控制方式  
           .type(ApiParameter.CommandType.SERVICE_ID)
           .serviceId(serviceId); 
       if (!TextUtils.isEmpty(param)) {
           ZSONObject zsonObject = ZSONObject.stringToZSON(param);
           for (String key : zsonObject.keySet()) {
               builder.addCharastic(key, zsonObject.get(key));
           }
       }
       mHiLinkDevice.sendCommand(commandParam, new DataCallback<String>() {  
           @Override  
           public void onSuccess(String s) { // 下发命令成功  
           }  

           @Override  
           public void onFailure(int i, String s) {// 下发命令失败  
           }  
       }); 
   }
   ```
