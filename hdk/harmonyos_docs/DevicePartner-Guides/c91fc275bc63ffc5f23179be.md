# 私有协议开发概述

对于开发者定义的私有协议，合作伙伴可根据自己定义的蓝牙协议时序，使用封装后的JS接口实现以下函数，以进行数据通信，解析数据，获取测量结果。  

|函数名称|函数含义|
|:-----------------------------|:------|
|onBleConnectionStateChange|连接状态回调|
|onBleDevicesFound|设备发现回调|
|onBleServiceDiscovered|服务发现回调|
|onBleCharacteristicValueChange|特征值变化回调|

JS接口定义详见[API参考](https://gitee.com/hms-core/hms-health-device-fa-demo/wikis/API接口/蓝牙JS API)。  

|BLE常用接口|HUAWEI JS BLE API|
|:--------|:---------------------------------|
|打开蓝牙适配器|openBluetoothAdapter|
|关闭蓝牙适配器|closeBluetoothAdapter|
|获取蓝牙适配器状态|getBluetoothAdapterState|
|使能特征值上报|notifyBleCharacteristicValueChange|
|给特征值写数据|writeBleCharacteristicValue|
|读特征值数据|readBleCharacteristicValue|
