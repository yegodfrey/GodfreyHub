# 设备离线

## 设备断网断电后依然在线

**问题现象**

设备实际已经断网或断电，但智慧生活App仍显示设备在线状态，无法实时反映设备真实状态。

**可能原因**

在设备断网时，在三次无法收到云端心跳响应（50秒*3=150秒）后，才会通知设备离线状态。此现象属于正常情况。

**解决措施**

日志分析--云组网：连续三次心跳超时后标记为离线，属于正常情况。

## 设备配网完成后，出现非预期的离线现象

**问题现象**

设备配网成功后，在正常使用过程中出现非预期的离线现象，设备状态频繁切换或长时间无法恢复在线。

**可能原因**

1. 网络环境不稳定，导致心跳超时。
2. 设备与云端TCP连接异常断开。
3. 路由器配置问题（如 NAT 类型、防火墙规则）。

**解决措施**

1. 查看设备日志中的错误信息，确认是否出现以下错误日志：

   cloud mode heartbeat reach max times

2. 检查 TCP 连接状态，验证设备与云端的 TCP 连接：

   tcp connect crash

3. 分析网络环境，检查路由器配置和网络质量：

   * Wi-Fi 信号强度（RSSI）。
   * 网络延迟（Ping 测试）。
   * NAT 类型。
   * 防火墙规则。

## 智慧生活App添加设备成功后，设备频繁离线

**问题现象**

在智慧生活App中添加设备成功后，设备和路由器电源正常，但设备频繁离线。

**可能原因**

可能是固件配置文件"hilink_device_sdk.c"与Device Partner平台的Profile文件中定义的功能不一致。
> 说明
>
> 不同开发方案中的固件配置文件名称可能存在差异，此处以"HarmonyOS Connect直连方案（Wi-Fi/Combo）"中的固件配置文件"hilink_device_sdk.c"为例。

**解决措施**

检查固件配置文件"hilink_device_sdk.c"与平台Profile中定义的功能是否完全一致。

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/ )，进入"管理中心"。
2. 在左侧菜单栏选择"产品开发"，在右侧的产品开发页面中选择对应的产品。
3. 单击对应的产品进入"产品定义 > 物模型定义"页面。
4. 在界面右上角"下载Profile（Excel）"或者"下载Profile（Json）"。
5. 检查固件配置文件"hilink_device_sdk.c"与Profile中定义的功能是否完全一致。如果不一致，需要修改配置文件"hilink_device_sdk.c"。

## 设备重启后，智慧生活App显示设备离线

**问题现象**

设备配网成功，智慧生活App添加设备成功且能正常控制。然而，设备重启后，智慧生活App显示设备处于离线状态。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/I_AEAyJfRhy4AB_Uk2zfeQ/zh-cn_image_0000002594347328.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=8FD64813E5DF8DCBF9A69C1D8E9FB4CE156D146711BB39434D719120833FC568 "点击放大")

**可能原因**

设备MAC地址未固定，设备重启后，已添加的设备因MAC地址发生改变，导致云端拒绝设备登录。

**解决措施**

使用AT指令固定模组的MAC地址。Hi3861芯片的指令示例如下:

```screen
AT+EFUSEMAC=<mac>[,type]
```

* 当type=0时，表示写入到eFuse（特殊存储区域，只能写入3次）。


* 当type=1时，表示写入到navram（此存储区域建议写入次数不超过20次），navrkeyiam的MAC地址配置优先级更高，会覆盖eFuse的MAC，优先读取此区域。

## 设备处于开机状态且手机网络正常，但智慧生活App上设备卡片显示离线状态

**问题现象**

设备处于开机状态且手机网络正常，但智慧生活App上设备卡片显示离线状态，且串口工具不停重复打印设备侧日志"+NOTICE:SCANFINISH/+NOTICE:DISCONNECTED"。

**可能原因**

设备已连接的热点的SSID或密码发生变更。

**解决措施**

* 方式一：将热点SSID和密码改回，模组即可重新连接热点，恢复正常。
* 方式二：将模组重置，重新给模组配网。

## 设备在断电重启后无法上线

**问题现象**

设备在OTA升级过程中或升级完成后断电，重新上电后无法上线，智慧生活App显示设备离线或提示设备不存在。

**可能原因**

合作伙伴在设备重新上电后，HILINK_GetMacAddr获取的MAC地址与配网时记录的 MAC 地址不一致，导致设备 ID（devid）错误，云端返回错误码4998，导致离线。

**解决措施**

1. 查看设备日志中的错误信息。

   确认是否出现错误码 4998：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/oKZPkhpxTT6nTpGHBZiZLA/zh-cn_image_0000002624623609.png?HW-CC-KV=V1&HW-CC-Date=20260924T071230Z&HW-CC-Expire=31536000000&HW-CC-Sign=9E9244995FE67E96EC8B8437E267B184E703D1586DA84B3F7F948250B472A755)

2. 验证MAC地址一致性。

   检查设备当前MAC地址与配网时记录的MAC地址。

   确保MAC地址持久化，保存MAC地址到非易失性存储。
