# 入口标签

使用手机碰、靠、扫设备上的标签，可以实现设备的首次连接。标签需遵循[标签设计规范](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/ux-design-specifications-nfc-overview-0000001183940042)。

1. 碰一碰 "碰一碰"连接支持无源NFC设备或蓝牙设备。当用户首次"碰一碰"设备时，会触发连接流程，系统会通过系统弹框引导用户连接设备。

   ![](https://media:101783481630525817 "点击放大")

<!-- -->

2. 靠近 靠近连接支持蓝牙和WLAN设备。

   ![](https://media:101783481630781818 "点击放大")
3. 扫一扫 用户可以通过扫一扫多功能码连接设备。

![](https://media:101783481631049819 "点击放大")
