# OTA升级

对于已完成设备开发和自测的产品，Device Partner平台提供OTA升级服务，合作伙伴可以发布固件版本，便于用户快速升级产品。当合作伙伴使用自有OTA服务时，平台仅归档伙伴创建的固件版本信息。

#### 基本概念

  * **OTA**

即空中下载技术（全称为Over-the-Air）。待升级的设备可以通过网络（包括Wi-Fi、3G、4G等），自动下载升级包，完成固件包的升级。

  * **华为OTA**

即华为在线升级技术。如果设备支持“华为OTA”，则开发者可以利用华为OTA技术完成固件包的测试与发布。OTA升级包通过平台上传至华为服务器后，平台会推送升级消息至设备端，终端用户可以通过手机或设备下载最新的OTA升级包，并完成设备的在线升级。

  * **开发者自有OTA**

如果设备不支持“华为OTA”，则平台仅归档伙伴创建的固件版本信息，不提供固件包的测试与发布服务，开发者需要依赖自有OTA能力完成固件包的测试与发布。




#### 准备工作

  1. 在[Device Partner平台](https://devicepartner.huawei.com/console/product/home#/)左侧导航中选择“产品开发”，进入当前产品的开发页面。
  2. 确认已完成[产品定义](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/product-definition-specifications-0000001194015922)中的软硬件规格定义。

     * 通信类型为Wi-Fi：确认“操作系统”与“系统类型”配置正确。
     * 通信类型为蓝牙BLE：确认芯片的RAM大小配置正确。仅当蓝牙芯片RAM≥128KB时支持华为OTA。

  3. （仅Wi-Fi通信的产品涉及）选择 “集成开发 ”，在“固件检查与帮助 > HiLink SDK版本检查”中选择实际使用的HiLink SDK版本号，并单击“提交”。![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241121093315.14830966846366285909576397545648:50001231000000:2800:9D3084FE640980CFCF577913E45E1977875F623C47D8934DB6BFD3C44DE65BBB.png?needInitFileName=true?needInitFileName=true)



#### OTA升级操作

以下仅针对**华为OTA** 方式的操作展开介绍。

  1. 在[Device Partner平台](https://devicepartner.huawei.com/console/product/home#/)左侧导航中，选择“运营运维 > OTA升级”。
  2. 在产品列表中选择需要OTA升级的产品，进入固件版本管理页面。
  3. 管理设备SN号。

     1. 在固件版本管理页面，单击“设备SN管理”。
     2. 在测试设备SN列表中，单击“添加设备SN组”。
     3. 添加用于自测的设备SN号（批量输入时需将不同SN号分行复制在输入框），按**Enter** 键结束。 

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241121093315.58248004739835047488302585109037:50001231000000:2800:87ABF7E3172CCC15823308587B00F40EC59F91B4DAD8923F84B4C0E4FC2A6519.png?needInitFileName=true?needInitFileName=true)

        * 此处的设备SN号是指设备集成开发完成后**用于自测的设备SN** ，不能设置为最终用户的设备SN，否则，最终用户的设备也将升级为本次创建的固件。
        * 一个SN组最多支持添加**500** 个SN号，最多支持创建**10** 个SN组（即5000个SN号）。
        * SN号不能设置为all、不能含有符号*、不区分英文的大小写。
        * 如果没有自定义设备的SN，则设备SN默认为去除了符号“:” 的设备 MAC 地址。例如，MAC地址为“00:E0:4C:XX:YY:ZZ”，则SN为“00E04CXXYYZZ”。

     4. 单击“确定”。

  4. 新增固件版本，分为两种场景：

     * **采用OpenHarmony系统且操作系统内存 ≥ 128 MiB：**
       1. 在固件版本管理页面，单击“新增固件版本”。
       2. 在“基本信息”页签，配置固件信息（固件版本号与版本中英文描述），并上传固件文件。

       3. 在“升级规则”页签，单击“新增”，参考表1配置固件包的升级规则。

     * **其他场景：**
       1. 在固件版本管理页面，单击“新增固件版本”。

          * 如果设置的SDK版本号与产品实际集成的SDK版本号不一致，将导致固件发布流程异常。

          * 固件包名为package.zip。
          * 固件包大小不超过25MB。
          * 固件包内文件清单及命名要求，参考固件包模板。  
备注 | 需要平台在部署固件时需要注意的事项，不对最终用户体现。

     1. 在固件版本管理页面，单击操作列中的“测试发布”。
     2. 选择用于当前固件包测试的设备SN组，并单击“提交”。

        * 测试固件包发布后，如需新增设备SN，可以在固件包对应的设备SN组中直接添加SN号，无需重新发布固件包。

  6. 开展固件包测试。

如果固件包升级失败，可能是上传的OTA固件包存在问题，请重新上传固件包。

  7. 自测成功后，在“产品认证”节点，上传测试报告，填写固件升级后的目标版本号等信息，提交认证测试。

#### 管理固件版本

  * **支持对商用发布的固件执行停用操作**
    1. 选择“运营运维> OTA升级”，选择产品进入固件版本管理列表。
    2. 找到“商用版本发布成功”状态的固件，单击操作列中的停用。
    3. 输入停用原因，并单击“提交”，触发商用版本停用。即终端用户设备暂时无法更新最新固件。
  * **支持对已停用的商用版本执行重启操作**
    1. 选择“运营运维> OTA升级”，选择产品进入固件版本管理列表。
    2. 找到“商用版本停用成功”状态的固件，单击操作列中的重启。
    3. 输入发布时间、失效时间以及设备SN尾号分批策略，并单击“提交”，再次执行商用版本发布。
