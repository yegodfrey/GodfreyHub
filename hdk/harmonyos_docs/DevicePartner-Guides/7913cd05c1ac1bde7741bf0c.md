# 概览

基于不同的入口、技术方案，连接流程也会有所区分。[前往下载连接流程及界面模板](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/uxdesign-overview-0000001198252447#section17523174117116)。

碰一碰、靠近、扫一扫是用户触达设备控制服务的开端。首次使用时用户需要完成设备连接后使用原子化服务，再次使用时用户即可直达服务，无需再次连接。

![](https://media:101783481640255974 "点击放大")

首次使用

当手机"碰一碰"未连接的HarmonyOS Connect设备时，需要先完成设备连接。连接完成后拉起控制面板。设备连接有多种技术方案，不同的技术方案会带来略有区别的用户体验。如连接过程含有华为设备云和厂商设备云的对接过程，则会经历帐号绑定流程。在Wi-Fi连接过程中，可根据设备能力和实际网络状态，由服务选择softAP连接和NaN秒控连接两种方式。蓝牙连接通过蓝牙配对方式完成设备连接。

![](https://media:101783481640318975 "点击放大")

再次使用

当用户已经完成设备连接后，再次碰一碰、靠近或扫一扫该设备时，系统将立即拉起控制面板进行快捷控制，无需再次进行设备连接。

![](https://media:101783481640566976 "点击放大")

以下为各种不同技术方案下的首次连接交互流程：  

#### HarmonyOS Connect直连方案（Wi-Fi/Combo）

以SoftAP方式为例，连接完成后拉起控制面板。

![](https://media:101783481641381977 "点击放大")  

#### HarmonyOS Connect极小硬件方案（BLE）

通过蓝牙连接设备，拉起控制面板。

![](https://media:101783481641893978 "点击放大")
