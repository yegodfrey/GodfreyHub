# 业务介绍

#### 业务简介

华为基于HarmonyOS的碰一碰、[原子化服务](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/atomic-service-overview-0000001136377936#section10506103831718)等能力，为合作伙伴提供运动健康原子化服务全流程模板代码和API，包括UI模板、蓝牙协议解析框架、数据读取与存储能力、结果数据解读与图表展示等，开发者只需修改模板代码中的配置项和蓝牙协议解析部分，即可完成原子化服务的开发，极大地缩短开发者的开发周期。

合作伙伴基于模板代码，即可快速构建具有碰一碰连接配对、数据测量与解读等能力的原子化服务，给用户提供极速连接，服务免安装，数据跟人走等新体验，即：

* 碰一碰极速连接 用户碰一碰NFC标签，即可启动原子化服务并完成蓝牙连接。

* 服务免安装 无需下载App，基于HarmonyOS的原子化服务，碰一碰即可启动，直接进入用户最关心的功能。

* 数据跟人走 碰一碰绑定华为帐号，运动健康数据可以共享给设备和服务。

* 健康顾问 结合用户多维度运动健康数据，给出关联分析结果。

* 服务找人 提供场景化服务，根据用户的个性化数据，精准推荐适合用户的相关服务。

#### 页面介绍

原子化服务页面提供5个区域：

1. 设备展示区域 展示设备的名称、图片、企业LOGO等信息

2. 基础信息区域 展示设备的连接状态、单次测量数据等基础信息

3. 数据解读及健康服务区域 结合用户历史测量数据给出历史趋势波动分析、以及结合用户多维度数据给出关联分析结果

4. 精品服务区域 结合用户画像与三方联合运营，提供相关联的专业精品服务

5. 关联生态设备区域 结合设备关联性和场景化解决方案，推荐相应的生态设备
