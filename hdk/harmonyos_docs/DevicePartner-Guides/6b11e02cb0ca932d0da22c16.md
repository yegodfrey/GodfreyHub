# 图片

使用场景：平台认证流程中设备配网以及线上开发提交素材处使用（此处平台提交图片单位为px）。  

#### 一、icon_B

应用场景：多设备控制中心、首页、设备分类页、设备列表页共用图。  

|--------------------------------------------|--------------------------------------------|--------------------------------------------|--------------------------------------------|
|![](https://media:101783481614704570 "点击放大")|![](https://media:101783481615056571 "点击放大")|![](https://media:101783481615132572 "点击放大")|![](https://media:101783481615213573 "点击放大")|
|多设备控制中心|首页|设备分类页|设备列表页|

切图大小：256\*256px

具体要求如下：

1. 图片均为正视实拍图，需有高光及反光，边缘轮廓需清晰，PNG格式透明底。
2. 根据产品形状，按照出图规范辅助图形输出。
3. 图片统一添加投影，#000000，10%不透明度，y:6，模糊：8。  
   ![](https://media:101783481615241574)  
   对于带显示屏的设备，图片中的显示屏不能包含具体的数字（如温度值、湿度值、时间、信号强度、空气质量等），避免因该数值与实际值不吻合给用户造成困扰。

![](https://media:101783481615343575 "点击放大")  

#### 二、icon_C（重置说明图，图上无文字内容）

切图大小：1440X1728px，卡片背景（第一二步均分上下空间）。

![](https://media:101783481615389576 "点击放大")

具体要求如下：

1. 文字描述：第一步描述清楚如何操作，看到什么反馈（例如：接通设备电源，指示灯亮起）。
2. 图片状态：突出显示接通设备电源后的状态（例如图例,显示出指示灯亮起状态）。
3. 文字规格：说明文字最多支持70个中文字符。
4. 产品图片：图片大小范围在608X608px内（上下距离128px，右边距96px）。
5. 文字描述：第二步要描述清楚如何操作，看到什么反馈（例如：长按设备开关，保持5秒，指示灯闪烁三次后），结尾用"即重置成功，进入配网状态"。
6. 图片状态：根据文字描述显示重要操作的开关（例如图例，用手势指出需要操作的开关）。
7. 文字规格：说明文字最多支持70个中文字符。
8. 产品图片：图片大小范围在608X608px内（上下距离128px，右边距96px）。
