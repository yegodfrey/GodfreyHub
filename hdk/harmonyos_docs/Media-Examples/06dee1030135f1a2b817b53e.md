# 示例代码

本路径包含以下Java示例代码工程，实现的能力如下：

* "uidemo"：呈现了视频编辑UI SDK提供的能力。
* "sdkdemo"：呈现了视频编辑原子能力SDK和AI SDK提供的能力。
* "screenrecorddemo"：呈现了屏幕录制SDK提供的能力。

**但UI SDK和原子能力SDK您只能选择其中一种方式集成，不可同时使用。** 详情请阅读示例工程中的"README"文件。Demo中没有配置API Key和AGC文件，请按照开发准备中的[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001101108580)和[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347)两个步骤配置，您才能访问网络素材。

|:-----------------|:-----------------------------------------------------|:------------------------------------------------------|
|Android Studio示例代码|[链接](https://gitee.com/hms-core/hms-video-editor-demo)|[链接](https://github.com/HMS-Core/hms-video-editor-demo)|

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。
>
> 2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。
