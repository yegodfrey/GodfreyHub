# 示例代码

该Android Studio工程包含Video Kit对外所有接口的使用示例，通过Demo您可以实现：

* 播放指定视频
* 调整视频进度
* 调整视频码率
* 调节播放速度
* 视频预加载
* 循环播放
* 音频视频切换功能
* HDR Vivid渲染转码能力
* HDR亮度调节能力

|名称|Gitee|GitHub|
|:-----------------|:------------------------------------------------------|:-------------------------------------------------------|
|Android Studio示例代码|[链接](https://gitee.com/hms-core/hms-video-demo-android)|[链接](https://github.com/HMS-Core/hms-video-demo-android)|

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。
>
> 2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。
