# 客户端示例代码

#### WisePlay DRM Demo

WisePlay DRM demo展示了如何使用WisePlay DRM API来构建您的视频应用，主要提供了License获取和管理的代码演示。  

|名称|Gitee|GitHub|
|:----------------|:-------------------------------------------------|:--------------------------------------------------|
|WisePlay DRM Demo|[链接](https://gitee.com/hms-core/hms-wiseplay-demo)|[链接](https://github.com/HMS-Core/hms-wiseplay-demo)|

WisePlay DRM对视频应用提供了一套基于Android标准接口的API，支持MPEG-DASH和HLS。这个Demo主要演示了以下场景：

1. 获取在线License。
2. 下载离线License。
3. 使用离线License。
4. 删除已下载的离线License。  

#### 基于ExoPlayer的WisePlay DRM Demo

该示例代码演示了如何基于开源播放器ExoPlayer进行修改，以支持在线播放WisePlay DRM加密内容。  

|名称|Gitee|GitHub|
|:----------------------------|:-----------------------------------------------------------|:------------------------------------------------------------|
|基于ExoPlayer的WisePlay DRM Demo|[链接](https://gitee.com/hms-core/hms-wiseplay-demo-exoplayer)|[链接](https://github.com/HMS-Core/hms-wiseplay-demo-exoplayer)|

关于ExoPlayer的更多介绍，请参考其官网：[ExoPlayer官网](https://exoplayer.dev/)。Demo代码基于ExoPlayer的代码标签为[r2.11.4](https://github.com/google/ExoPlayer/releases/tag/r2.11.4)。Demo具体说明和使用方法请参考代码仓中的README.md或README_ZH.md文档。

1. 演示了如何在线播放WisePlay加密片源，比如使用SM4加密的HLS片源。

2. 支持WisePlayDrmSDK软解，实现Provision、License和片源解密等相关功能。
