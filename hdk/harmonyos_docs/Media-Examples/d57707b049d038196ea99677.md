# 示例代码

本路径下包含了三个Java示例代码工程，实现的能力如下：

* "app"：呈现所有的音频编辑服务能力。
* "base_audioeditor"：呈现所有的音频编辑原子能力。
* "aidubbing_audioeditor"：呈现AI配音能力。

详情请阅读示例工程中的"README"文件。

|名称|Gitee|GitHub|
|:-----------------|:-----------------------------------------------------|:------------------------------------------------------|
|Android Studio示例代码|[链接](https://gitee.com/hms-core/hms-audio-editor-demo)|[链接](https://github.com/HMS-Core/hms-audio-editor-demo)|

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。
>
> 2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。

您可以通过手机浏览器的扫码功能扫描下方二维码直接下载Demo APK。
