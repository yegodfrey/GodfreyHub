# 示例代码

该Android Studio工程包含了各接口的使用示例，实现以下功能：

* 播放音频：播放、暂停、上一首、下一首、停止播放、拖拽进度条、设置和获取播放模式
* 管理音频队列：读取专辑列表、保存列表、删除列表的音频内容、增加列表的音频内容
* 管理音频配置：设置缓存空间大小、获取缓存空间大小、获取当前已缓存文件大小、清空缓存功能
* 管理音效：10段均衡开放设置，可自定义调节各频段音量、11种常规典型音效（流行、古典、摇滚、爵士、舞曲等）和5种高级音效（绝美人声、空灵轻音、3D旋转、超重低音、车载音效）设置
