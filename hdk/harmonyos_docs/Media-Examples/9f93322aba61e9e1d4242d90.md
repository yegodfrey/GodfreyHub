# 示例代码

## 场景智能设计

该Android Studio工程包含场景智能设计服务示例代码，实现以下功能：

* 图像颜色滤镜
* 贴纸花字
* 图文智能排版
* 图像主题标签
* 图片裁剪

|Kotlin示例代码|[链接](https://gitee.com/hms-core/hms-image-vision-kotlin)|[链接](https://github.com/HMS-Core/hms-image-vision-kotlin)|

## 场景动效

该Android Studio工程包含场景动效服务示例代码，实现以下功能：

* 位移、旋转、等5种基础动效
* 跟手粒子、水波纹等9种高级动效

> 说明
>
> 在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。
>
> 1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。
>
> 2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。
