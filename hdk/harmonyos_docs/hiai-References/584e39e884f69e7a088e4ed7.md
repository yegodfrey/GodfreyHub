# OnProcessDone

#### 接口定义

```
virtual void OnProcessDone(const AiContext& context, int32_t result, const std::vector<std::shared_ptr<AiTensor>>& poutTensor, int32_t piStamp) = 0;
```

#### 功能介绍

OnProcessDone回调虚函数。  

#### 参数

|名称|类型|描述|
|:---------|:----------------------------------------|:------------|
|context|const AiContext \&|用户自定义可扩展上下文。|
|result|int32_t|推理结果。|
|poutTensor|const vector\<shared_ptr\<AiTensor\>\> \&|推理后的输出Tensor。|
|piStamp|int32_t|异步处理标识。|
