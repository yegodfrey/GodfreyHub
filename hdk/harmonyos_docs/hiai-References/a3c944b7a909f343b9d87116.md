# SetMax

## 函数功能

设置最大的T对象指针。

## 函数原型

```cpp
void SetMax(T *max)
```

## 参数说明

|参数|输入/输出|说明|
|:--|:----|:--------|
|max|输入|最大的T对象指针。|

## 返回值

无

## 约束说明

无

## 调用示例

```cpp
Range<int> range; 
int max = 1024; 
range.SetMax(&max);
```
