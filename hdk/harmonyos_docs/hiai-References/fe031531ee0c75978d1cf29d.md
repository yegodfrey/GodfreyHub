# Build

## 接口定义

```screen
Status Build(const hiai::ModelBuildOptions& options, const std::string& modelName, const std::shared_ptr<ge::Model>& model, std::shared_ptr<hiai::IBuiltModel>& builtModel);
```

## 功能介绍

对通过IR API生成的模型进行在线编译。

## 参数

|名称|类型|描述|
|:----------|:--------------------------------------------------------------------------------------------------------------------------|:-----------|
|options|const [ModelBuildOptions](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbuildoptions-0000001139374903)&|模型的编译参数。|
|modelName|const std::string&|模型名称。|
|modelBuffer|const std::shared_ptr<IBuffer>&|IR API生成的模型。|
|builtModel|std::shared_ptr<IBuiltModel>&|编译完成的模型对象。|

## 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|

> 说明
>
> 该接口集成在libhiai_ir_build.so，建议使用builtModel的save相关接口，保存模型。
