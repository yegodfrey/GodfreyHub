# CreateModelBuilder

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃。

## 接口定义

```screen
HIAI_MB_API_EXPORT std::shared_ptr<IModelBuilder> CreateModelBuilder();
```

## 功能介绍

创建模型编译实例指针。

## 返回

|类型|描述|
|:-----------------------------|:-------------------|
|std::shared_ptr<IModelBuilder>|* 非空指针：成功。 * 空指针：失败。|
