# Overview

提供人脸识别SDK，包含机器学习人脸检测服务类和接口。  

#### Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLFace](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlface-0000001050169393)|表示由人脸分析器（[MLFaceAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceanalyzer-0000001050167440)）检测到的人脸。人脸的属性包括宽高、旋转度、是否睁眼、是否微笑、人脸关键点和轮廓等。|
|[MLFaceAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceanalyzer-0000001050167440)|人脸分析器：用于获取图片中人脸对象信息（[MLFace](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlface-0000001050169393)）。|
|[MLFaceAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceanalyzersetting-0000001050169395)|人脸分析配置器：用于设置人脸分析器的属性。|
|[MLFaceAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceanalyzersettingfactory-0000001050167442)|创建人脸分析配置器（[MLFaceAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceanalyzersetting-0000001050169395)）的实例。|
|[MLFaceEmotion](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceemotion-0000001050169397)|人脸表情类，包含人脸七种表情：微笑、无表情、愤怒、厌恶、惊恐、悲伤和惊讶。|
|[MLFaceFeature](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfacefeature-0000001050167444)|人脸特征类，包含七种人脸特征： * 左眼睁开的程度。 * 右眼睁开的程度。 * 戴眼镜的可能性。 * 性别的可能性。 * 戴帽子的可能性。 * 有胡子的可能性。 * 年龄。|
|[MLFaceKeyPoint](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfacekeypoint-0000001050169399)|人脸关键点，表示检测到的人脸上的一个点。关键点类型包括： * TYPE_BOTTOM_OF_MOUTH：值为1，代表下嘴唇的中心点。 * TYPE_LEFT_CHEEK：值为2，代表左脸颊的中心点。 * TYPE_LEFT_EAR：值为3，代表左耳屏的中心点。 * TYPE_TIP_OF_LEFT_EAR：值为4，代表左耳顶点。 * TYPE_LEFT_EYE：值为5，代表左眼球的中心点。 * TYPE_LEFT_SIDE_OF_MOUTH：值为6，代表左嘴角位置点。 * TYPE_TIP_OF_NOSE：值为7，代表鼻尖中心点。 * TYPE_RIGHT_CHEEK：值为8，代表右脸颊的中心点。 * TYPE_RIGHT_EAR：值为9，代表右耳屏的中心点。 * TYPE_TIP_OF_RIGHT_EAR：值为10，代表右耳顶点。 * TYPE_RIGHT_EYE：值为11，代表右眼球的中心点。 * TYPE_RIGHT_SIDE_OF_MOUTH：值为12，代表右嘴角位置点。|
|[MLFaceShape](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceshape-0000001050167446)|人脸关键轮廓，包含检测到的人脸关键轮廓（例如嘴巴）上的一组点。轮廓类型包括： * TYPE_ALL：值为0，代表人脸所有轮廓。 * TYPE_FACE：值为1，代表脸部总体轮廓。 * TYPE_LEFT_EYE：值为2，代表左眼的轮廓。 * TYPE_RIGHT_EYE：值为3，代表右眼的轮廓。 * TYPE_BOTTOM_OF_LEFT_EYEBROW：值为4，代表左眉的底部轮廓。 * TYPE_BOTTOM_OF_RIGHT_EYEBROW：值为5，代表右眉的底部轮廓。 * TYPE_TOP_OF_LEFT_EYEBROW：值为6，代表左眉的顶部轮廓。 * TYPE_TOP_OF_RIGHT_EYEBROW：值为7，代表右眉的顶部轮廓。 * TYPE_BOTTOM_OF_LOWER_LIP：值为8，代表下嘴唇的底部轮廓。 * TYPE_TOP_OF_LOWER_LIP：值为9，代表下嘴唇的顶部轮廓。 * TYPE_TOP_OF_UPPER_LIP：值为10，代表上嘴唇的顶部轮廓。 * TYPE_BOTTOM_OF_UPPER_LIP：值为11，代表上嘴唇的底部轮廓。 * TYPE_BOTTOM_OF_NOSE：值为12，代表鼻子的底部轮廓。 * TYPE_BRIDGE_OF_NOSE：值为13，代表鼻梁的轮廓。|
|[MLMaxSizeFaceTransactor](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlmaxsizefacetransactor-0000001050169401)|最大人脸处理器，在某一时刻只处理当前图像中最大的人脸。|
|[MLMaxSizeFaceTransactor.Creator](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlmaxsizefacetransactorcreator-0000001050167448)|创建最大人脸处理器的实例。|
