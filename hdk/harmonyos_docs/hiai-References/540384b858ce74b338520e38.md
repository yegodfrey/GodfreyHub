# 获取计算能力增强版本号

#### 接口定义

```
static const char* GetComputeCapabilityVersion();
```

#### 功能介绍

获取计算能力增强版本号。  

#### 返回

|类型|描述|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|char\*|执行成功，返回相应的计算能力增强版本号。 版本号名称以\<major\>.\<middle\>.\<minor\>.\<point\>的形式构成。 * \<major\>：平台主版本，XX两位数表示（不足两位不补位）。如10表示android Q版本。 * \<middle\>：局部架构、重大特性，XX两位数表示（不足两位不补位）。 * \<minor\>：规划的新特性版本，XX两位数表示（不足两位不补位）。 * \<point\>：编译构建的版本号，XXX三位数表示（不足三位不补位）。 例如：某手机计算能力返回的版本号是11.0.6.202，如果返回nullptr或00.00.00.000表示执行失败。|
