# Overview

此包为文本识别组件，可用于从图片中识别出文本信息。

提供了文本检测的核心API，主要包含以下类：

* 属性设置类MLRemoteTextSetting：提供设置云端分析器参数的API。
* 属性设置类MLLocalTextSetting：提供设置本地分析器参数的API。
* 文本信息类MLText：提供从检测结果获取文本信息的API。
* 分析器类MLTextAnalyzer：提供创建分析器及执行文本检测的API。
