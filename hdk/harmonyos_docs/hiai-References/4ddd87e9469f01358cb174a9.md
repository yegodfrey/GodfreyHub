# SaveToFile

## 接口定义

```screen
static bool SaveToFile(const ge::Graph& irGraph, const std::string& file);
```

## 功能介绍

构建好的模型Dump接口，输入模型对象和保存模型路径，生成构建好的模型。

## 参数

|名称|输入/输出|类型|描述|
|:------|:----|:-----------|:--------------------------------------------|
|irGraph|输入|ge::Graph&|graph对象。|
|file|输入|std::string&|模型保存路径。 > 说明 > 注意保存模型文件路径的权限，如果为无权限目录，模型保存失败。|

## 返回

|类型|描述|
|:---|:---------------------------------|
|bool|* true：构建模型保存成功。 * false：构建模型保存失败。|

> 说明
>
> * 本接口为CANN DDK 100.510.020.010新增的可选接口。
> * 本接口使用需要引入model_dumper.h头文件。
> * 本接口使用生成的OM模型仅用于debug，可视化，不支持推理。
> * 本接口主场景是dump刚构建好的graph， 编译后的graph也可以dump。
