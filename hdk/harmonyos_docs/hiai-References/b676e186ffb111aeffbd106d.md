# GetSubgraphNames

#### 函数功能

获取一个算子的子图名称列表。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150659.35278051412082092277471917462821:50001231000000:2800:7A80E126569850353971F17B86804B7A1CF87D6F45D09FB479A0897FDFCAADFA.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
std::vector<std::string> GetSubgraphNames() const;
graphStatus GetSubgraphNames(std::vector<AscendString> &names) const;
```

#### 参数说明

|参数名|输入/输出|描述|
|:----|:----|:-------------|
|names|输出|获取一个算子的子图名称列表。|

#### 返回值

|类型|描述|
|:----------|:---------------------------------|
|graphStatus|GRAPH_FAILED：失败。 GRAPH_SUCCESS：成功。|

#### 异常处理

无

无
