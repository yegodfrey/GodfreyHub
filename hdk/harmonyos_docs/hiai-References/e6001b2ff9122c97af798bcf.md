# Overview

此套接口用于单算子Tensor和Buffer的管理，以及单算子执行器的创建、加载、推理计算，具体参见[单算子开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/single-operator-development-0000001890402068)。

|API|描述|
|:-------------|:--------------------------------------------------------------------------|
|单算子Tensor管理类|用于单算子TensorDesc、Buffer、Tensor的创建、查询、销毁。该类接口在single_op_tensor.h中定义。|
|单算子Executor管理类|用于单算子执行配置、单算子描述的创建和销毁以及单算子执行器的创建、查询、加载、推理计算、销毁。该类接口在single_op_manager.h中定义。|
|枚举类|枚举值定义。该类接口在single_op_types.h中定义。|
