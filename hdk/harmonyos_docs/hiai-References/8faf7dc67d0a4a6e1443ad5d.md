# GetValueType

#### 接口定义

```
ValueType GetValueType() const;
```

#### 功能介绍

获取当前属性值的类型。  

#### 返回

|类型|描述|
|:---------------------------------------------------------------------------------------------------|:----------------------------|
|[ValueType](https://developer.huawei.com/consumer/cn/doc/hiai-References/valuetype-0000001333764609)|返回对应的属性类型。具体参见attr_value.h文件。|
