# Overview

提供ML Kit SDK基础实现类及接口方法。  

#### Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------|
|[LensEngine.PhotographListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/lensengine-photographlistener-0000001159336164)|获得图像数据后的回调接口。|
|[LensEngine.ShutterListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/lensengine-shutterlistener-0000001205016203)|按下快门后的回调接口。|
|[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlanalyzer-mltransactor-0000001159656216)|分析处理器需要实现的通用接口，用于处理检测结果。|
|[MLCompositeTransactor.TrailerFactor](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlcompositetransactor-trailerfactor-0000001205176183)|目标跟踪器工厂接口，实现类可用于创建特定目标的跟踪器实例。|

#### Class Summary

|Class|Description|
|:------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[LensEngine](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/lensengine-0000001050169367)|相机引擎LensEngine封装了相机初始化、帧获取以及控制逻辑功能。|
|[LensEngine.Creator](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/lensenginecreator-0000001050167414)|相机引擎构造器，用于创建相机引擎实例。|
|[MLAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlanalyzer-0000001050169371)|分析器抽象类，所有分析器必须继承该类。例如：[MLFaceAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceanalyzer-0000001050167440)（人脸分析器）、[MLObjectAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlobjectanalyzer-0000001050169461)（对象分析器）、[MLTextAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mltextanalyzer-0000001050167460)（文本分析器）等。|
|[MLAnalyzer.Result](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlanalyzerresult-0000001050169373)|分析结果封装类，包含三组数据： * 分析结果。 * 图片元数据。 * 该数据是否可用。|
|[MLApplication](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlapplication-0000001050167420)|App信息类，用于存储集成了ML Kit SDK的App基本信息。通常情况下，应用开发者不与这个类直接交互， ML Kit SDK会结合开发者申请的agconnect-services.json，完成ML Kit的初始化，不需要开发者编写额外的代码。|
|[MLApplicationSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlapplicationsetting-0000001050169375)|App信息配置类，用于指定应用初始化需要的应用ID，API秘钥等信息。|
|[MLApplicationSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlapplicationsettingfactory-0000001050167422)|创建App信息配置类的实例，用于设置App属性。|
|[MLCompositeAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlaompositeanalyzer-0000001050169377)|多类型分析器，继承自MLAnalyzer，可集成多种类型的分析器，同时检测不同类型对象，如：在同一张图片上同时实现人脸检测和文字识别。|
|[MLCompositeAnalyzer.Creator](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlcompositeanalyzercreator-0000001050167424)|创建多类型分析器的实例，允许添加不同类型的分析器。|
|[MLCompositeTransactor](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlcompositetransactor-0000001050169379)|多类型分析结果处理器，支持对多个目标的检测结果进行独立处理。|
|[MLCompositeTransactor.Creator](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlcompositetransactorcreator-0000001050167426)|多类型分析结果处理器实例构建器。|
|[MLCoordinate](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlcoordinate-0000001050167428)|经纬度数据类，包含经度信息和纬度信息。|
|[MLFrame](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlframe-0000001050167430)|MLFrame封装了源自相机的视频帧或静态图片数据，以及相关的数据处理逻辑。支持byte、ByteBuffer、Bitmap不同存储方案。|
|[MLFrame.Creator](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlframecreator-0000001050169385)|帧构建器。|
|[MLFrame.Property](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlframeproperty-0000001050167432)|帧元数据。|
|[MLPosition](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlposition-0000001050169387)|点数据类，表示图像中的二维或三维点，以浮点精度指定（float），(0,0)表示图像左上角像素点，向右为x正向，向下为y正向。只有x、y同时有值，才构成一个有效坐标。|
|[MLProminentTransactor](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlprominenttransactor-0000001050167434)|特定目标分析结果处理器抽象类，实现以下功能： * 设定需要跟踪的目标，目标在连续帧中状态发生变化时，自动调用目标跟踪器中的对应处理逻辑。 * 设定连续帧对同一目标的匹配策略，可以设置最大面积、最宽、最高等匹配策略。|
|[MLResultTrailer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlresulttrailer-0000001050169389)|目标跟踪器抽象类，支持对特定目标连续帧检测结果进行跟踪，识别目标出现、变化、消失、处理完成等场景。每个场景对应有一个处理方法，可以在其中实现自定义的处理逻辑。|
