# HiAI_SingleOpBuffer_Destroy

## 接口定义

```screen
HIAI_Status HiAI_SingleOpBuffer_Destroy(HiAI_SingleOpBuffer** buffer);
```

## 功能介绍

用于释放调用HiAI_SingleOpBuffer_Create创建的HiAI_SingleOpBuffer对象。

## 参数

|名称|类型|描述|
|:-----|:--------------------|:---------------------------------------------------------|
|buffer|HiAI_SingleOpBuffer**|指向HiAI_SingleOpBuffer对象的二级指针。buffer和*buffer不能是空指针，否则返回错误码。|

## 返回

|类型|描述|
|:----------|:---------------------------------------------|
|HIAI_Status|函数执行的结果状态。执行成功返回HIAI_SUCCESS，失败返回HIAI_FAILURE。|
