# GetPaddingPara

#### 接口定义

```
AippPaddingPara GetPaddingPara(uint32_t batchIndex);
```

#### 功能介绍

获取AIPP参数中的Padding参数。  

#### 参数

|名称|类型|描述|
|:---------|:-------|:---------------------------------------|
|batchIndex|uint32_t|batch下标，标识获取第几个batch中的Padding参数，取值需\>=0。|

#### 返回

|类型|描述|
|:---------------------------------------------------------------------------------------------------------------|:---------|
|[AippPaddingPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aipppaddingpara-0000001283790237)|Padding参数。|
