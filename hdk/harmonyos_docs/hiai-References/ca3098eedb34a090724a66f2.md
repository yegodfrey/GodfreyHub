# IsValid

#### 接口定义

```
bool IsValid() const;
```

#### 功能介绍

判断Graph对象是否有效。  

#### 返回

|类型|描述|
|:---|:----------------------------------------------|
|bool|* true：构建Graph对象有效，非空。 * false：构建Graph对象无效，空指针。|
