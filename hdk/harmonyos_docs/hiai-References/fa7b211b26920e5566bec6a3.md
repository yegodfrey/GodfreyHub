# CheckModelCompatibility

#### 接口定义

```
AIStatus CheckModelCompatibility(AiModelDescription& pmodelDesc, bool& pisModelCompatibility);
```

#### 功能介绍

检查模型兼容性。  

#### 参数

|名称|类型|描述|
|:--------------------|:--------------------|:--------------------------------------------|
|pmodelDesc|AiModelDescription \&|模型描述。|
|pisModelCompatibility|bool \&|兼容性检查标识。 * True：模型兼容性检查通过。 * False：模型兼容性检查失败。|

#### 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|
