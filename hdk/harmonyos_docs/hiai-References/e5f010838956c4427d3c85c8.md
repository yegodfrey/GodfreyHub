# HiAI_SingleOpExecutor_GetWorkspaceSize

#### 接口定义

```
size_t HiAI_SingleOpExecutor_GetWorkspaceSize(const HiAI_SingleOpExecutor* executor);
```

#### 功能介绍

用于查询HiAI_SingleOpExecutor所需的ION内存工作空间的字节大小。在成功创建HiAI_SingleOpExecutor后，调用该接口获取执行器所需的ION内存工作空间的字节大小，然后需要调用HiAI_SingleOpBuffer_Create申请足够的工作空间内存，将分配的工作空间传入HiAI_SingleOpExecutor_Init接口。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150637.64284774332918450311197921227834:50001231000000:2800:C531947EE0327EA5D7CF87A76733A7BECABD7E16257C451AA5817E04B3A8AD12.png)  
同一个执行器的工作空间内存和输入、输出Tensor内存不能复用，不同执行器的工作空间内存可以复用。  

#### 参数

|名称|类型|描述|
|:-------|:----------------------------|:-------------------------------------------|
|executor|const HiAI_SingleOpExecutor\*|指向HiAI_SingleOpExecutor对象的指针。该值不能为空指针，否则返回0。|

#### 返回

|类型|描述|
|:-----|:---------|
|size_t|工作空间的字节大小。|
