# CreateModelBuff(ge::Model& irModel,ModelBufferData& output)

## 接口定义

```screen
bool CreateModelBuff(ge::Model& irModel,ModelBufferData& output);
```

## 功能介绍

创建模型Buffer。

## 参数

|名称|输入/输出|类型|描述|
|:------|:----|:----------------------------------------------------------------------------------------------------------------|:-------|
|irModel|输入|ge::Model&|模型对象。|
|output|输出|[ModelBufferData](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbufferdata-0000001281245160)&|模型结构体对象。|

## 返回

|类型|描述|
|:---|:-----------------------------------------|
|bool|* true：创建模型Buffer成功。 * false：创建模型Buffer失败。|

> 说明
>
> 模型构建时的接口调用顺序如下：CreateModelBuff > BuildIRModel > ReleaseModelBuff。
