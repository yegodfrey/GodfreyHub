# CreateNativeHandle

#### 接口定义

```
HIAI_UTIL_API_EXPORT Status CreateNativeHandle(NativeHandle& nativeHandle, const buffer_handle_t handle, int offset = -1, int size = -1);
```

#### 功能介绍

根据buffer_handle_t结构体信息，生成[NativeHandle](https://developer.huawei.com/consumer/cn/doc/hiai-References/nativehandle-0000001139236033)的结构信息。以便调用[Init](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001051490692#section84731652202415)接口初始化Tensor。  

#### 参数

|名称|类型|描述|
|:-----------|:-----------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------|
|nativeHandle|[NativeHandle](https://developer.huawei.com/consumer/cn/doc/hiai-References/nativehandle-0000001139236033)\&|输出[NativeHandle](https://developer.huawei.com/consumer/cn/doc/hiai-References/nativehandle-0000001139236033)的结构体信息。|
|handle|buffer_handle_t|输入buffer_handle_t结构体信息。|
|offset|int|可选输入，默认值为-1。 * 设置为-1表示无效值，NativeHandle的offset值等于buffer_handle_t中的offset值。 * 设置不为-1时，NativeHandle的offset值等于设置的offset值。|
|size|int|可选输入，默认值为-1。 * 设置为-1表示无效值，NativeHandle的size值等于buffer_handle_t中的size值。 * 设置不为-1时，NativeHandle的size值等于设置的size值。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
