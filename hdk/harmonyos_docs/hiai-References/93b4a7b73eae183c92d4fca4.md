# GetAttr

#### 接口定义

```
GraphErrCodeStatus GetAttr(const string& name, AttrValue& value) const;
```

#### 功能介绍

获取属性值。  

#### 参数

|名称|输入/输出|类型|描述|
|:----|:----|:-------------|:----|
|name|输入|const string\&|属性名称。|
|value|输出|AttrValue\&|属性值。|

#### 返回值

|类型|描述|
|:-----------------|:-----------------------------------------------|
|GraphErrCodeStatus|* GRAPH_SUCCESS：获取属性值成功。 * GRAPH_FAILED：获取属性值失败。|
