# GetSize

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetSize](https://developer.huawei.com/consumer/cn/doc/hiai-References/getsize-0000001052609432)替代。

## 接口定义

```screen
virtual size_t GetSize() const = 0;
```

## 功能介绍

获取buffer中Data的大小。

## 返回

|类型|描述|
|:-----|:----|
|size_t|数据大小。|
