# GetItem

#### 接口定义

```
const AttrValue& GetItem(const string& key) const;
```

#### 功能介绍

获取对应名称的属性值。  

#### 参数

|名称|输入/输出|类型|描述|
|:--|:----|:-------------|:----|
|key|输入|const string\&|属性名称。|

#### 返回

|类型|描述|
|:----------------|:-------|
|const AttrValue\&|获取到的属性值。|
