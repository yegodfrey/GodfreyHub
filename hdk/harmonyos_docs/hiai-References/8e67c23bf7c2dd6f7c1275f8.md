# operator=

## 接口定义

```screen
Tensor& operator=(const Tensor& other) = delete;
```

## 功能介绍

重载"="赋值操作符。

## 参数

|名称|输入/输出|类型|描述|
|:----|:----|:------------|:----------------|
|other|输入|const Tensor&|不可更改的Tensor对象的引用。|

## 返回

|类型|描述|
|:------|:-----------|
|Tensor&|Tensor对象的引用。|
