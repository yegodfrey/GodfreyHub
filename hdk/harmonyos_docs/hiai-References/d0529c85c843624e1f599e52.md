#### Public Methods

#### detect

|Method|
|:--------------------------------------------------------------------------------------------------------------|
|public int detect(VisionImage image, Label label, IVisionCallback cb) 根据传入的图片进行标签检测，检测结果为Label，返回结果码resultcode。|

Parameters  

|Name|Description|
|:----|:----------------------------------------------------------------------|
|image|图片数据，image暂只支持封装Bitmap类型的图片数据（小于2000万像素），后续会扩展支持文件路径、bytebuffer形式的图片数据。|
|label|标签结果java类。|
|cb|回调函数接口对象，目前暂不支持异步处理。 * 传入null, 表示同步处理。 * 传入非null，即回调函数接口对象，用于异步返回结果。|

Return  

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------|
|int|[HwResultCode错误码](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/return-codes-0000001053441989)。|

标签结果字段label内容说明：  

|Field|Required|Type|Description|
|:-------------------|:-------|:---------------|:------------------------------|
|label|是|Label|标签结果。|
|+category|是|int32|图片类别。|
|+categoryProbability|是|int32|图片类别置信度。|
|+labelContents|是|LabelContent\[\]|标签列表。|
|++labelId|是|int32|标签ID。|
|++probability|是|int32|标签置信度，范围：-1及 0\~1，-1表示算法未提供置信度。|
