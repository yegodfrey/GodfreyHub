# SetCscPara(AiTensorImage_Format targetFormat, ImageType imageType=JPEG)

## 接口定义

```screen
AIStatus SetCscPara(AiTensorImage_Format targetFormat, ImageType imageType = JPEG);
```

## 功能介绍

设置AIPP Color Space Conversion色域转换参数。

## 参数

|名称|类型|描述|
|:-----------|:-----------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|targetFormat|[AiTensorImage_Format](https://developer.huawei.com/consumer/cn/doc/hiai-References/format-0000001051490704)|转换后的图片类型，系统根据转换后的图片类型自动填充CSC参数。取值范围： * AiTensorImage_RGB888_U8 * AiTensorImage_BGR888_U8 * AiTensorImage_YUV444SP_U8 * AiTensorImage_YVU444SP_U8 * AiTensorImage_YUV400_U8|
|imageType|[ImageType](https://developer.huawei.com/consumer/cn/doc/hiai-References/imagetype-0000001333699845)|图片格式，默认JPEG。|

## 返回

|类型|描述|
|:-------|:------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败|
