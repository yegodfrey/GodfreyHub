# SetDynamicShapeConfig

## 接口定义

```screen
AIStatus SetDynamicShapeConfig(const DynamicShapeConfig& dynamicShape);
```

## 功能介绍

设置模型动态多shape配置。

## 参数

|名称|类型|描述|
|:-----------|:------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|dynamicShape|const DynamicShapeConfig&|动态多shape配置。 ```screen struct DynamicShapeConfig { bool enable = false; uint32_t maxCachedNum; CacheMode cacheMode = CacheMode::CACHE_BUILDED_MODEL; }; ``` * enable： true表示使能，false表示去使能。 * cacheMode：缓存模式，CACHE_BUILDED_MODEL表示缓存多份模型文件，CACHE_LOADED_MODEL表示加载多份模型。 * maxCachedNum：最大缓存数目，介于2和10之间可选配置。|

## 返回

|类型|描述|
|:-------|:-----------------------------|
|AIStatus|* AI_SUCCESS：设置成功。 * 其他值：设置失败。|
