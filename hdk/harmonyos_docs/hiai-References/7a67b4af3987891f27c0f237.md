# Overview

提供图像超分辨率SDK，包含机器学习图像超分辨率服务类和接口。具体使用方法可参见：[图像超分辨率开发步骤](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/imagesuper-resolution-0000001051546182#section19397413132813)。  

#### Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLImageSuperResolutionAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesuperresolutionanalyzer-0000001052253899)|图像超分分析器，通过调用asyncAnalyseFrame()接口进行图像超分。创建图像超分分析器有两种方式： * MLImageSuperResolutionAnalyzerFactory.getInstance().getImageSuperResolutionAnalyzer() * MLImageSuperResolutionAnalyzerFactory.getInstance().getImageSuperResolutionAnalyzer(MLImageSuperResolutionAnalyzerSetting） 前者使用MLImageSuperResolutionAnalyzeSetting中设置的默认值，后者可自定义配置项。|
|[MLImageSuperResolutionAnalyzerFactory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesuperresolutionanalyzerfactory-0000001052053874)|图像超分工厂类，用于创建图像超分分析器。|
|[MLImageSuperResolutionAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesuperresolutionanalyzersetting-0000001052693876)|图像超分配置器，用于设置图像超分分析器的属性。|
|[MLImageSuperResolutionAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesuperresolutionanalyzersettingfactory-0000001051255205)|创建图像超分配置器的实例，用于设置图像超分分析器的属性。|
|[MLImageSuperResolutionResult](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesuperresolutionresult-0000001051535126)|图像超分结果类。|
