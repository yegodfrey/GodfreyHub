#### 接口定义

```
Shape& operator=(const Shape& other);
Shape& operator=(Shape&& other);
```

#### 功能介绍

重载"="赋值操作符。  

#### 参数

|名称|输入/输出|类型|描述|
|:----|:----|:------------|:---------------|
|other|输入|const Shape\&|不可更改的shape对象的引用。|
|other|输入|Shape\&\&|Shape对象的右值引用。|

#### 返回

|类型|描述|
|:------|:----------|
|Shape\&|Shape对象的引用。|
