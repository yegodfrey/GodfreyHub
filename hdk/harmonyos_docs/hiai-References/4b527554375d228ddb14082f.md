# MLRemoteLangDetector

|Class Info|
|:---------------------------------------------------------------------------------------------------------|
|MLRemoteLangDetector 云侧语种检测器，根据提供的文本，进行云侧语种检测。调用云端API获取检测结果。 云侧语种检测器有使用默认的参数配置和使用自定义的参数配置两种创建方式，根据实际情况二选一。|

**Sample code:**

```screen
/* 方式1：使用默认的参数配置创建语种检测器。   */
MLRemoteLangDetector * mlRemoteLangDetector = [[MLLangDetectorFactory getInstance] getRemoteLangDetector];
/*   方式2：使用自定义的参数配置创建语种检测器。 */
// 设置0.01为语种检测的最信度阈值
MLRemoteLangDetectorSetting *setting = [[MLRemoteLangDetectorSetting alloc] initWithTrustThreshold: 0.01];            
MLRemoteLangDetector *mlRemoteLangDetector = [[MLRemoteLangDetector alloc] initWithSetting:setting];

  //返回多个语种检测结果，包括语种编码以及置信度，sourceText表示待检测的文本，长度需小于5000个字符。
   [mlRemoteLangDetector probabilityDetect:@"sourceText" addOnSuccessListener:^(NSArray * _Nonnull mlDetectedLangs) {
          // 成功处理逻辑，比如进行相关的界面展示
      } addOnFilureListener:^(MLLangDetectionException * _Nonnull exception) {
          // 失败处理逻辑
         int errorCode = exception.code;
       // 获取报错信息，开发者可以结合错误码，快速定位问题。
        NSString *errorMessage = exception.message;
      }];

   // 返回置信度最高的语种编码，sourceText表示待检测的文本，长度需小于5000个字符。
   [mlRemoteLangDetector firstBestDetect:@"sourceText" addOnSuccessListener:^(NSString * _Nonnull mlDetectedLangs) {
         // 成功的处理逻辑，比如进行相关的界面展示
   } addOnFilureListener:^(MLLangDetectionException *exception) {
             // 失败处理逻辑
             int errorCode =exception.code;
             // 获取报错信息，开发者可以结合错误码，快速定位问题。
             NSString * errorMessage = exception.message;
    }];
```
