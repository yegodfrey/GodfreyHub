# Overview

提供HUAWEI HiAI Engine 人体识别、图片识别、视频技术、Model Creator的基础实现类及接口方法。  

#### Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[PoseEstimationDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/pose-estimation-detector-0000001054814950)|[人体关键点识别](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/skeleton-ocr-introduction-0000001054263137)接口，主要检测人体的一些关键点，如关节，五官等，通过关键点描述人体骨骼信息。|
|[AestheticsScoreDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/aesthetics-score-detector-0000001054096375)|[美学评分](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/aesthetic-score-introduction-0000001054030737)接口，评价图像的综合美学分数，分数越高说明图像越"美"。|
|[LabelDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/label-detector-0000001054096401)|[图片分类标签](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/image-category-label-introduction-0000001054031637)接口，检测给定图片中的标签信息，对图像分类。|
|[ImageSuperResolution](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/image-super-resolution-0000001054372493)|[图像超分辨率](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/image-super-resolution-introduction-0000001053970397)接口，基于深度学习在计算机视觉中的广泛应用，将图片进行智能放大，或者在分辨率不变的情况下，去除压缩噪声，获得比传统图像处理更加清晰、锐利、干净的照片。|
|[SceneDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/scene-detector-0000001054096362)|[场景检测](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/scene-detection-introduction-0000001053850371)接口，检测给定图片主体内容对应的场景，如图片主体是猫/狗/绿色植物/焰火等。|
|[DocRefine](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/hiai-vision-image-overview-0000001053961838)|[文档检测校正](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/document-correction-introduction-0000001054290390)接口，检测图片中的文档，返回文档四边形的四个点坐标。|
|[TxtImageSuperResolution](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/txt-image-super-resolution-0000001054180704)|[文字图像超分](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/character-image-super-resolution-introduction-0000001054051662)接口，可以对包含文字的图像进行3倍放大，同时增强图像中文字清晰度。|
|[ImageSegmentation](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/image-segmentation-0000001054539425)|[人像分割](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/portrait-segmentation-introduction-0000001053971672)接口，可以利用其进行图像前景背景替换和背景虚化等美化。|
|[ImageSegmentation](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/image-segmentation-0000001054539425)|[图像语义分割](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/image-semantic-segmentation-introduction-0000001054610398)接口，对拍照图像进行像素级的识别和分割，从而获得图像中物体的类别信息以及精确位置信息。|
|[ImageSegmentation](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/image-segmentation-0000001054539425)|[视频人像分割](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/videoportrait-ocr-introduction-0000001054468190)接口，支持实时视频流的实时处理，开发者将实时视频流的每一帧图像传输到HUAWEI HiAI Engine，算法对图中的人像进行分割，并将字节数组的掩码结果，返回给用户。|
|[AestheticsScoreDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/aesthetics-score-detector-0000001054096375)|[视频总结](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/video-summary-introduction-0000001054796828)接口，可应用于个人相册管理、自动照片编辑、相机辅助拍照等图像拍摄、管理分类等软件。审美引擎算法支持从客观、主观、摄影学维度和人像审美维度等多种维度对图像进行综合评分。|
|[AestheticsScoreDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/aesthetics-score-detector-0000001054096375)|[视频封面](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/video-cover-introduction-0000001054170692)接口，可应用于个人相册管理、自动照片编辑、相机辅助拍照等图像拍摄、管理分类等软件。审美引擎算法支持从客观、主观、摄影学和人像审美等多种维度对视频进行处理，可获取美学得分最高的静态封面和动态封面。|
