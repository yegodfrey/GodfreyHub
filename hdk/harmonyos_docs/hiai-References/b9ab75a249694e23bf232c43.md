# FindOpByName

#### 接口定义

```
ge::Operator FindOpByName(const string& name) const;
```

#### 功能介绍

根据算子的名称，返回Graph中的算子实例。  

#### 参数

|名称|输入/输出|类型|描述|
|:---|:----|:-------------|:--------|
|name|输入|const string\&|需指定的算子名称。|

#### 返回

|类型|描述|
|:-----------|:-------------------------------------------------|
|ge::Operator|如果Graph中包含对应名称算子，返回Graph中的这个算子；否则返回type为"NULL"的算子。|
