# MLImageSegmentation

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------|
|MLImageSegmentation 表示由图像分割检测器（MLImageSegmentationAnalyzer）图像分割后的各个像素点分类。对象的属性包括： * 当前图像分割后各个像素点的标志。 * 透明背景人像前景图。 * 人像为白色，背景为黑色的灰度图。 * 切割原图。|

#### Public Methods

#### getForeground

|Method|
|:------------------------------------------------------------------------------------------|
|- (UIImage \*)getForeground 获取透明背景人像前景图，可直接查看分割效果（人像分割静态图片边缘毛刺进行了优化处理，显示效果优于像素分类标记二次处理的结果）。|

Returns  

|Type|Description|
|:---------|:----------------------------------|
|UIImage \*|人像前景抠图。 * 识别正常：原图同尺寸图片。 * 识别错误：nil。|
