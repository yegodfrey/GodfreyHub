# SetFormat

## 接口定义

```screen
void SetFormat(Format format);
```

## 功能介绍

设置TensorDesc所描述的Tensor的format信息。

## 参数

|名称|输入/输出|类型|描述|
|:-----|:----|:-----|:------------|
|format|输入|Format|需设置的format信息。|
