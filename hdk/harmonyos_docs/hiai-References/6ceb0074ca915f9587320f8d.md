# GetValue

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/getpara-0000001052490757)替代。

## 接口定义

```screen
std::string GetValue(const std::string& key) const;
```

## 功能介绍

获取指定参数值。

## 参数

|名称|类型|描述|
|:--|:-----------------|:------|
|key|const std::string&|指定参数名称。|

## 返回

|类型|描述|
|:----------|:------|
|std::string|指定参数的值。|
