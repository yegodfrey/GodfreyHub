# SetCustomData

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150642.29029175750102789091403375070378:50001231000000:2800:A619C3CF65971F5F2050C4CFF6145EC83B1D420D1F9D726CC29268B610048E58.png)  
此接口从DDK 5.0.1.0版本起废弃。  

#### 接口定义

```
virtual void SetCustomData(const CustomModelData& customModelData) = 0;
```

#### 功能介绍

在模型里设置用户自定义数据。  

#### 参数

|名称|类型|描述|
|:--------------|:-----------------------------------------------------------------------------------------------------------------|:-----------------------|
|customModelData|[CustomModelData](https://developer.huawei.com/consumer/cn/doc/hiai-References/custommodeldata-0000001333300073)\&|用户输入的自定义数据，包含type和value。|
