# SetResizePara(uint32_t batchIndex, AippResizePara resizePara)

#### 接口定义

```
AIStatus SetResizePara(uint32_t batchIndex, AippResizePara resizePara);
```

#### 功能介绍

设置AIPP Resize图片缩放参数，为特定下标的batch设置Resize参数。  

#### 参数

|名称|类型|描述|
|:---------|:-------------------------------------------------------------------------------------------------------------|:-------------------------------------|
|batchIndex|uint32_t|batch下标，标识为第几个batch设置Resize参数，取值需\>=0。|
|resizePara|[AippResizePara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippresizepara-0000001245217314)|Resize图片缩放参数。|

#### 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
