# GetInputAippIndex

#### 接口定义

```
int32_t GetInputAippIndex();
```

#### 功能介绍

获取AIPP参数中的inputAippIndex参数，inputAippIndex参数用于标识AIPP配置参数在输入Data有多个输出分支时作用于第几个分支。  

#### 返回

|类型|描述|
|:------|:----------------|
|int32_t|inputAippIndex参数。|
