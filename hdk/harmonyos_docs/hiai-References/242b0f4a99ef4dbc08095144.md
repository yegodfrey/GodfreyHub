# MLFaceEmotion

|Class Info|
|:------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.MLFaceEmotion 人脸表情类，包含人脸七种表情：微笑、无表情、愤怒、厌恶、惊恐、悲伤和惊讶。所有表情的程度值相加等于1。|

### getAngryProbability()

|Method|
|:--------------------------------------------|
|public float getAngryProbability() 获取人脸愤怒的程度。|

**Returns**

|Type|Description|
|:----|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|float|返回人脸愤怒的程度，以0.0-1.0表示。如果通过方法MLFaceAnalyzerSetting.Factory.setFeatureType(MLFaceAnalyzerSetting.TYPE_FEATURES)启用了"人脸表情和特征检测"功能，则返回人脸愤怒的程度；否则，返回-1。|
