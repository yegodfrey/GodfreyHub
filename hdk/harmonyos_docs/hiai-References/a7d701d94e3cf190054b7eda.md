# SetInputs

## 接口定义

```screen
Graph& SetInputs(std::vector<Operator>& inputs);
```

## 功能介绍

设置Graph内的输入算子。

## 参数

|名称|输入/输出|类型|描述|
|:-----|:----|:---------------------|:-----------|
|inputs|输入|std::vector<Operator>&|Graph内的输入算子。|

## 返回

|类型|描述|
|:-----|:-------|
|Graph&|返回调用者本身。|
