# DeviceConfigMode

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150635.05432354867911519529968231864622:50001231000000:2800:AA0C232206F322949809F8DF96D1FF23EFCE537CEC122AD4E32F2ECCF1870929.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[ExecuteDeviceSelectMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/executedeviceselectmode-0000001281459574)替代。  

|Enum Info|
|:--------|
|异构设置策略。|

|Enum Value and Description|Value|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----|
|AUTO 不指定异构策略，此时[modelDeviceOrder](https://developer.huawei.com/consumer/cn/doc/hiai-References/modeldeviceconfig-0000001208193789#ZH-CN_TOPIC_0000001208193789__p116081021416)与[opDeviceOrder](https://developer.huawei.com/consumer/cn/doc/hiai-References/modeldeviceconfig-0000001208193789#ZH-CN_TOPIC_0000001208193789__p36622111011)均无效。|0|
|MODEL_LEVEL 设置模型级指定运行设备参数，此时[modelDeviceOrder](https://developer.huawei.com/consumer/cn/doc/hiai-References/modeldeviceconfig-0000001208193789#ZH-CN_TOPIC_0000001208193789__p116081021416)有效。|1|
|OP_LEVEL 设置算子级指定运行设备参数，此时[opDeviceOrder](https://developer.huawei.com/consumer/cn/doc/hiai-References/modeldeviceconfig-0000001208193789#ZH-CN_TOPIC_0000001208193789__p36622111011)有效。|2|
