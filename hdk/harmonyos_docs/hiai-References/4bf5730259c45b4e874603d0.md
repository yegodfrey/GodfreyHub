# CreateModelBuff(ge::Model& irModel, ModelBufferData& output, uint32_t customSize)

## 接口定义

```screen
bool CreateModelBuff(ge::Model& irModel, ModelBufferData& output, uint32_t customSize);
```

## 功能介绍

按指定大小创建模型Buffer。

## 参数

|名称|输入/输出|类型|描述|
|:---------|:----|:----------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------|
|irModel|输入|ge::Model&|模型对象。|
|output|输出|[ModelBufferData](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbufferdata-0000001281245160)&|模型结构体对象。|
|customSize|输入|uint32_t|用户指定Buffer大小，单位字节，必须为非负整数，建议范围200M以内，当customSize设置为0时，接口内部根据irModel自动计算合适的Buffer大小。|

## 返回

|类型|描述|
|:---|:-----------------------------------------|
|bool|* true：创建模型Buffer成功。 * false：创建模型Buffer失败。|
