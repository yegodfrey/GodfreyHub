# HiAI_SingleOpExecutor_PreCheckConvolution

#### 接口定义

```
HiAI_SingleOp_SupportStatus HiAI_SingleOpExecutor_PreCheckConvolution(const HiAI_SingleOpOptions* options, const HiAI_SingleOpDescriptor* opDesc, const HiAI_SingleOpTensorDesc* input, const HiAI_SingleOpTensorDesc* output, const HiAI_SingleOpTensor* filter, const HiAI_SingleOpTensor* bias);
```

#### 功能介绍

用于预查询卷积算子的支持状态。根据该接口的返回值确定是否调用[HiAI_SingleOpExecutor_CreateConvolution](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-createconvolution-0000001890254466)来创建卷积执行器。  

#### 参数

|名称|类型|描述|
|:------|:------------------------|:-------------------------------------------------------|
|options|HiAI_SingleOpOptions\*|指向HiAI_SingleOpOptions对象的指针。该值不能为空指针，否则接口调用失败。|
|opDesc|HiAI_SingleOpDescriptor\*|指向卷积算子对应的HiAI_SingleOpDescriptor对象的指针。该值不能为空指针，否则接口调用失败。|
|input|HiAI_SingleOpTensorDesc\*|指向输入Tensor描述的指针。该值不能为空指针，否则接口调用失败。|
|output|HiAI_SingleOpTensorDesc\*|指向输出Tensor描述的指针。该值不能为空指针，否则接口调用失败。|
|filter|HiAI_SingleOpTensor\*|指向卷积核Tensor的指针。该值不能为空指针，否则接口调用失败。|
|bias|HiAI_SingleOpTensor\*|指向偏置Tensor的指针。如果卷积没有偏置，则该值可以是空指针。|

#### 返回

|类型|描述|
|:---------------------------------------------------------------------------------------------------------------------------------------|:----|
|[HiAI_SingleOp_SupportStatus](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-supportstatus-0000001890414454)|支持状态。|
