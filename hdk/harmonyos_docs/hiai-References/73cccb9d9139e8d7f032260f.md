# HiAI_SingleOpExecutor_Destroy

#### 接口定义

```
HIAI_Status HiAI_SingleOpExecutor_Destroy(HiAI_SingleOpExecutor** executor);
```

#### 功能介绍

用于销毁HiAI_SingleOpExecutor对象，释放执行器占用的内存。当不再使用HiAI_SingleOpExecutor对象时，调用该接口销毁，否则会造成内存泄漏。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150637.97354269188437217355686009277720:50001231000000:2800:36EEF4B3BA4FEDE37E6B815289D0F40A46FFFCECAA674A839DC2C758E8BF1CC8.png)  
该接口不会释放传递给HiAI_SingleOpExecutor_Init的工作空间内存，工作空间所属的HiAI_SingleOpBuffer需要单独释放。  

#### 参数

|名称|类型|描述|
|:-------|:------------------------|:----------------------------------------------------------------|
|executor|HiAI_SingleOpExecutor\*\*|指向HiAI_SingleOpExecutor对象的二级指针。executor和\*executor不能是空指针，否则返回错误码。|

#### 返回

|类型|描述|
|:----------|:---------------------------------------------|
|HIAI_Status|函数执行的结果状态。执行成功返回HIAI_SUCCESS，失败返回HIAI_FAILURE。|
