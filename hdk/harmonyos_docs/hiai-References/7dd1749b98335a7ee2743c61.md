# GetDtcPara

## 接口定义

```screen
AippDtcPara GetDtcPara(uint32_t batchIndex);
```

## 功能介绍

获取AIPP参数中的Data Type Conversion数据类型转换参数。

## 参数

|名称|类型|描述|
|:---------|:-------|:----------------------------------|
|batchIndex|uint32_t|batch下标，标识获取第几个batch中的DTC参数，取值需>=0。|

## 返回

|类型|描述|
|:-------------------------------------------------------------------------------------------------------|:-----|
|[AippDtcPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippdtcpara-0000001291851965)|DTC参数。|
