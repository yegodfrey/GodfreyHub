# RestoreFromFile

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150634.78472539334179220431160376391064:50001231000000:2800:E1FA81AE1F37CEAF8ECBEFB30A6581A705E59221C2E72BDD2209A9358D1E907C.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[ReadBinaryProto(const string path)](https://developer.huawei.com/consumer/cn/doc/hiai-References/readbinary-const-0000001052249416)替代。  

#### 接口定义

```
virtual Status RestoreFromFile(const char* file) = 0;
```

#### 功能介绍

从文件中获取模型。  

#### 参数

|名称|类型|描述|
|:---|:-----------|:-----------|
|file|const char\*|模型的文件名，包含路径。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
