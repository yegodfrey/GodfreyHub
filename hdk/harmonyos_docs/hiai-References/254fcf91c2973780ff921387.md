# REG_OP

#### 接口定义

```
REG_OP(x)
```

#### 功能介绍

注册算子类型，同时自动生成算子类型的两个构造函数。

例如，注册算子的类型名称Conv2D，可调用"REG_OP(Conv2D)"接口，调用该接口后，定义了算子的类型名称Conv2D，同时产生Conv2D的两个构造函数，其中，Conv2D(const string\& name)需指定算子名称，Conv2D()使用默认算子名称，例如"Conv2D_XX"（编号XX唯一）。

```
class Conv2D : public Operator {
    typedef Conv2D _THIS_TYPE;
public:
    static constexpr const char* TYPE_NAME = "Conv2D";
    explicit Conv2D(const string& name);
    explicit Conv2D();
}
```

#### 参数

|名称|输入/输出|类型|描述|
|:-|:----|:-|:---------------------------------------|
|x|输入|-|宏参数，被注册算子的类型名称。 说明： 注册的算子类型名称需保持唯一，不能重复。|
