# Save

## 接口定义

```screen
GraphErrCodeStatus Save(Buffer& buffer) const;
```

## 功能介绍

将模型对象序列化。

## 参数

|名称|输入/输出|类型|描述|
|:-----|:----|:------|:-----------|
|buffer|输入|Buffer&|序列化输出的对象的引用。|

## 返回

|类型|描述|
|:-----------------|:---------------------------------------|
|GraphErrCodeStatus|序列化成功，返回GRAPH_SUCCESS，否则，返回GRAPH_FAILED。|
