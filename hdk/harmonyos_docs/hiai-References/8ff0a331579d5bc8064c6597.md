# MLDocument

|Class Info|
|:------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.document.MLDocument 表示图像检测出的文档信息。包含两个属性： * 图像中检测到的所有文本内容。 * 图像中检测到的所有文本区块，包含文本内容、文本区块边界和语种等信息。|
