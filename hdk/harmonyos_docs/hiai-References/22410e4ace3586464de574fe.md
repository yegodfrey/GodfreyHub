# CheckOpByName

#### 接口定义

```
GraphErrCodeStatus CheckOpByName(const string& name) const;
```

#### 功能介绍

在Graph中检查指定名称的算子是否存在。  

#### 参数

|名称|输入/输出|类型|描述|
|:---|:----|:-------------|:--------|
|name|输入|const string\&|需指定的算子名称。|

#### 返回

|类型|描述|
|:-----------------|:-----------------------------------------------------|
|GraphErrCodeStatus|* GRAPH_SUCCESS： 指定名称的算子存在。 * GRAPH_FAILED：指定名称的算子不存在。|
