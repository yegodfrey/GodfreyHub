# OPTIONAL_OUTPUT

## 接口定义

```screen
OPTIONAL_OUTPUT(x, t)
```

## 功能介绍

注册可选算子输出信息。

注册可选算子输出信息成功后，自动生成算子输出的相关接口，用于获取算子输出的名称、获取算子输出的对应描述等。

例如，注册算子输出b，算子输出接收的数据类型为TensorType{DT_FLOAT}，可调用"OPTIONAL_OUTPUT(b, TensorType{DT_FLOAT})"接口，注册算子输出成功后，自动生成以下相关接口：
> 注意
>
> TensorDesc get_output_desc_b()该接口已废弃，不再生成。

```screen
static constexpr const string OUTPUT_NAME_b = "b"; // 输出的名称，即"b"
TensorDesc get_output_desc_b();                    // 返回输出b对应的描述
GraphErrCodeStatus update_output_desc_b(const TensorDesc& tensorDesc);
                                                  // 设置输出b对应的描述，包括Shape、DataType、Format等信息
```

## 参数

|名称|输入/输出|类型|描述|
|:-|:----|:-|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x|输入|-|宏参数，算子输入的名称。|
|t|输入|-|算子输入接收的数据类型，可以是TensorType定义的一个或多个，如果多个，通过","分隔，例如： ```screen TensorType{DT_FLOAT} TensorType({DT_FLOAT, DT_INT8}) ``` 关于TensorType类，请参见[TensorType类说明](https://developer.huawei.com/consumer/cn/doc/hiai-References/input-0000001052569451#section6543132714216)。 > 说明 > 对于同一个算子，注册的算子属性名称需保持唯一，不能重复。|
