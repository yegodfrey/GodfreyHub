# HiAI_SingleOpTensor_Destroy

## 接口定义

```screen
HIAI_Status HiAI_SingleOpTensor_Destroy(HiAI_SingleOpTensor** tensor);
```

## 功能介绍

用于释放HiAI_SingleOpTensor对象。

## 参数

|名称|类型|描述|
|:-----|:--------------------|:---------------------------------------------------------|
|tensor|HiAI_SingleOpTensor**|指向HiAI_SingleOpTensor对象的二级指针。tensor和*tensor不能是空指针，否则返回错误码。|

## 返回

|类型|描述|
|:----------|:---------------------------------------------|
|HIAI_Status|函数执行的结果状态。执行成功返回HIAI_SUCCESS，失败返回HIAI_FAILURE。|
