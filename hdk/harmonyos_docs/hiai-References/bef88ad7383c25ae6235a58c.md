# GetDims

## 接口定义

```screen
const std::vector<int64_t> GetDims() const;
```

## 功能介绍

获取Shape所有维度组成的向量。

## 返回

|类型|描述|
|:-------------------|:---------------|
|std::vector<int64_t>|Shape的所有维度组成的向量。|
