Parameters  

|Name|Description|
|:----------|:--------------------------------------------|
|requestJson|JSON格式的自然语言处理请求。|
|reqType|请求类型， 取值可以从com.huawei.nlu.sdk.NLPConstants选择。|

requestJson的JSON格式如下：  

|Parameter|Required|Type|Description|
|:----------|:-------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|text|是|String|待分析的文本，UTF-8编码，字数小于等于500字。|
|type|否|long|分词的粒度，默认为0。 0：基本词，粒度较小，如"我要看速度与激情"，分成"我/要/看/速度/与/激情"； 1：在基本词的基础上，做实体合并，如"我要去江宁万达广场看速度与激情"，分成"我/要/去/江宁万达广场/看/速度/与/激情"，如"明天下午3点一起看电影"，分成"明天/下午/3点/一起/看/电影"； 9223372036854775807（2的63次方减1）：在type为1的基础上，把实体时间、地点等整体结构合并，出现符号隔开不合并，并把一些常用短语合并，如"形容词+的"，"单字动词+单字名词"等，简化句子成分，如"明天下午三点到五点我在江宁瑞都金逸影城看电影"，分成"明天下午三点/到/五点/我/在/江宁瑞都金逸影城/看/电影"。|
|callPkg|否|String|调用者名称。|
|callType|否|int|调用者类型，默认0。0：应用 1：快应用。|
|callVersion|否|String|调用者版本号。|
|callState|否|int|调用者状态，默认-1，未知；0：前台；1：后台。|

|public ResponseResult getAssistantIntention(String requestJson, int reqType) [助手类意图识别](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/intent-recognition-introduction-0000001054209279)，同步接口，该接口主要针对助手场景下的意图识别，分析用户的意图。分为系统设置类、出行类、生活类、娱乐类、联系社交类、手机应用控制类、系统应用操作类。|

Parameters  

|Name|Description|
|:----------|:--------------------------------------------|
|requestJson|JSON格式的自然语言处理请求。|
|reqType|请求类型， 取值可以从com.huawei.nlu.sdk.NLPConstants选择。|

requestJson的JSON格式如下：  

|Parameter|Required|Type|Description|
|:----------|:-------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|text|否|String|待分析的文本，utf-8，文本长度不超过50个字符。|
|category|否|String|需要分析的意图类别，默认分析所有类，多个用半角逗号","隔开，如需要系统设置类和出行类，传"systemSetting,trip"。|
|module|否|String|用来指定具体分析哪些意图模块，默认都分析。 分析多个意图模块用半角逗号","隔开，如分析订火车票和订机票意图，传"bookTrainTicket,bookAirTicket"。 备注：分析时category与module取并集，如category为"systemSetting",module为"bookTrainTicket"，则分析系统设置类的所有意图，以及订火车票"bookTrainTicket"意图。|
|callPkg|否|String|调用者名称。|
|callType|否|int|调用者类型，默认0。0：应用 1：快应用。|
|callVersion|否|String|调用者版本号。|
|callState|否|int|调用者状态，默认-1，未知；0：前台；1：后台。|

Return  

|Type|Description|
|:-------------|:---------------------------------------------------------------|
|ResponseResult|处理响应结果。包含如下属性： * code，错误码。 * message，错误信息。 * intentions，关键字列表结果。|

ResponseResult的JSON格式如下：  

|Parameter|Required|Type|Description|
|:----------|:-------|:--------|:--------------------------------------------------------------------------------|
|code|是|int|* 0：成功； * 1：系统正在初始化； * 2：参数错误； * 3：系统忙； * 4：系统异常； * 5：任务超时； * 6：其它错误； * -10：引擎关闭。|
|message|是|String|错误信息。|
|keywords|否|JSONArray|意图列表，数组里的类型为JSON对象。|
|+name|否|String|意图名，如："openWlan"。|
|+attributes|否|JSONArray|意图对应的属性。|
