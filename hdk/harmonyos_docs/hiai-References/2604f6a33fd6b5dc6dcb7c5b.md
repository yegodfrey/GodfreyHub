## Public Methods

### getAudioData()

|Method|
|:-----------------------------------------|
|public byte[] getAudioData() 获取音频分片中的音频数据。|

**Returns**

|Type|Description|
|:-----|:----------|
|byte[]|音频数据的字节数组。|

### getAudioFormat()

|Method|
|:-------------------------------------------------------------------------------------------------------------------------|
|public int getAudioFormat() 获取音频分片中音频数据的编码格式，当前支持两种格式： * FORMAT_PCM_16BIT，采样深度为16位的PCM数据。 * FORMAT_PCM_8BIT，采样深度为8位的PCM数据。|

**Returns**

|Type|Description|
|:---|:----------|
|int|编码格式类型常量。|

### getChannelInfo()

|Method|
|:---------------------------------------------------------------------------|
|public int getChannelInfo() 获取音频分片中音频数据的声道信息，当前是单声道音频。 CHANNEL_OUT_MONO：单声道。|

**Returns**

|Type|Description|
|:---|:----------|
|int|声道信息。|

### getSampleRateInHz()

|Method|
|:----------------------------------------------------------------------------------------------|
|public int getSampleRateInHz() 获取音频分片中音频数据的音频采样率，当前仅支持[SAMPLE_RATE_16K](#section5244192512586)。|

**Returns**

|Type|Description|
|:---|:----------|
|int|采样率大小。|
