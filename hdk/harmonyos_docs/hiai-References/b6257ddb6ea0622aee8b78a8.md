# Overview

提供图像分割SDK，包含ML Kit图像分割服务类和接口。

## Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLImageSegmentation](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ios-mlimagesegmentation-0000001054502201)|表示由图像分割检测器（MLImageSegmentationAnalyzer）图像分割后的各个像素点分类。 对象的属性包括： * 当前图像分割后各个像素点的标志。 * 透明背景人像前景图。 * 人像为白色，背景为黑色的灰度图。 * 分割原图。|
|[MLImageSegmentationAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ios-mlimagesegmentationanalyzer-0000001054182211)|图像分割检测器：用于获取图片中图像分割信息（MLImageSegmentation)。|
|[MLImageSegmentationSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ios-mlimagesegmentationsetting-0000001054541521)|图像分割检测器设置类：用于设置检测器（MLImageSegmentationAnalyzer)属性。属性包括： * 检测模式（人像检测模式、图像多类别检测模式），默认为人像检测模式。 * 是否支持精细检测（人像模式和图像多分类检测模式都支持，默认为精细模式）。 * 支持的能力场景，默认为所有能力场景。|

## Enum Value Summary

|Enum|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------|
|[MLImageSegmentationScene](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ios-mlimagesegmentationscene-0000001054221539)|图像分割场景，用户可以自由组合需要的能力场景。|
|[MLImageSegmentationClassification](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ios-mlimagesegmentationclassification-0000001054622173)|图像分割分类：算法提供的图像分割11大分类。|
|[MLImageSegmentationAnalyzerType](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ios-mlimagesegmentationanalyzertype-0000001054368475)|检测模式的枚举类（人像检测模式、图像多类别检测模式）。|
