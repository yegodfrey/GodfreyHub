# MLFace

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.MLFace 表示由人脸分析器（[MLFaceAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlfaceanalyzer-0000001050167440)）检测到的人脸。人脸的属性包括宽高、旋转度、是否睁眼、是否微笑、人脸关键点和轮廓等。|
