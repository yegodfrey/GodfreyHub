# SetVersion

## 接口定义

```screen
void SetVersion(uint32_t version)
```

## 功能介绍

设置模型的版本号。

## 参数

|名称|输入/输出|类型|描述|
|:------|:----|:-------|:------|
|version|输入|uint32_t|模型的版本号。|
