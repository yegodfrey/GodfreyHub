# data

#### 接口定义

```
inline std::uint8_t* data();
inline const std::uint8_t* data() const;
```

#### 功能介绍

获取Buffer中存放的数据的指针。  

#### 返回

|类型|描述|
|:--------|:-----------------|
|uint8_t\*|返回Buffer中存放的数据的指针。|
