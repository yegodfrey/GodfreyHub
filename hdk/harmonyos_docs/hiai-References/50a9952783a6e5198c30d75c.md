# MLSimultaneousInterpretationListener

|Interface Info|
|:------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.si.speech.MLSimultaneousInterpretationListener 当识别发生后，使用该接口从MLSimultaneousInterpretationListener接收数据和事件通知。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------------------|
|void|[onError](#section43771976592)(int error, String errorMessage) 网络错误或者识别错误后会调用该接口。|
|void|[onRecognizingResults](#section146961838182616)(Bundle recognizingResults) 按句子为单元，输出持续不断的识别结果。|
|void|[onResults](#section119211738102810)(Bundle results) 按句子为单元输出完整的识别结果。|
|void|[onStartListening](#section3774114782913)() 录音器开始接收声音。|
|void|[onState](#section18106130153117)(int state, Bundle params) 通知应用状态发生改变。|
|void|[onVoiceDataReceived](#section12310111123211)(byte\[\] data) 返回给用户原始的PCM音频流。|

#### Public Methods

#### onError

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onError(int error, String errorMessage) 网络错误或者识别错误后会调用该接口。返回的错误码可以参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-error-0000001307309509)进行处理。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|error|参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-error-0000001307309509)。 * ERR_NO_NETWORK。 * ERR_SERVICE_UNAVAILABLE。|
|errorMessage|错误消息。|

#### onRecognizingResults

|Method|
|:----------------------------------------------------------------------------------------------------------------|
|public void onRecognizingResults(Bundle recognizingResults) 同传识别器会通过该接口持续返回语音识别过程中的结果。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|recognizingResults|同传识别过程中返回的结果。目前Bundle中携带了识别后的文本信息，文本信息以String类型保存在以[MLSimultaneousInterpretationConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384).[RESULTS_RECOGNIZING](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384#section129981614173713)；[MLSimultaneousInterpretationConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384). [RESULTS_TRANS_RECOGNIZING](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384#section43481529173917)为key的value中。|

#### onResults

|Method|
|:-----------------------------------------------------------------------------------|
|public void onResults(Bundle results) 从同传识别器接收到最终的语音识别结果。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|results|语音识别返回的结果。 目前Bundle中携带了识别后的文本信息，文本信息以String类型保存在以[MLSimultaneousInterpretationConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384). [RESULTS_RECOGNIZED](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384#section419515171332)；[MLSimultaneousInterpretationConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384). [RESULTS_TRANS_RECOGNIZED](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384#section206041140125817)为key的value中。|

#### onVoiceDataReceived

|Method|
|:----------------------------------------------------------------------------------------|
|public void onVoiceDataReceived(byte\[\] data) 返回给用户原始的PCM音频流。该接口并非运行在主线程中，返回结果需要在子线程中处理。|
