# Return Codes

|Return Code|Value|Description|
|:-----------------------------------------|:----|:-------------|
|AIRESULT_SUCCESS|0|执行成功。|
|AIRESULT_ENGINE_HAS_USED|1|使用中重新调用。|
|AIRESULT_UNKOWN|-1|未知错误。|
|AIRESULT_UNSUPPORTED|-2|功能或接口不支持。|
|AIRESULT_MEMORY_ALLOC_ERROR|-3|内存分配失败或创建对象失败。|
|AIRESULT_LIBRARY_FAILED|-4|so初始化失败。|
|AIRESULT_NO_PERMMISION|-5|调用者缺少权限。|
|AIRESULT_AIENGINE_CLOSED|-10|引擎开关已经关闭|
|AIRESULT_FAILED|101|执行失败。|
|AIRESULT_INPUT_ILLEGAL|200|输入参数不合法。|
|AIRESULT_INPUT_ILLEGAL_NULL|201|输入参数不合法（为空）。|
|AIRESULT_INPUT_VALID|210|输入参数合法。|
|AIRESULT_INPUT_RESIZE|211|输入图片变更尺寸。|
|AIRESULT_SERVICE_BIND_EXCEPTION|500|服务绑定异常。|
|AIRESULT_SERVICE_BIND_EXCEPTION_DISCONNECT|521|服务绑定异常中断。|
|AIRESULT_SERVICE_BIND_CONNECTED|522|服务绑定成功。|
|AIRESULT_MODEL_EXCEPTION|600|模型文件异常。|
|AIRESULT_MODEL_NON_EXISTED|601|模型文件不存在。|
|AIRESULT_MODEL_LOAD_FAILED|602|模型文件加载失败。|
|AIRESULT_ASYNC_MODE|700|异步访问模式。|
|AIRESULT_CV_NPU_ERROR|1001|神经网络处理单元错误。|
|AIRESULT_CALL_TIMES_LIMIT|2002|调用次数超过限制。|
|AIRESULT_USER_CANCELLED|3000|取消调用。|
|AIRESULT_INTERRUPT_BY_HIGH_PRIORITY|3001|调用被任务打断。|
|AIRESULT_GET_CLOUD_RESULT_FAIL|3002|云端获取结果失败。|
