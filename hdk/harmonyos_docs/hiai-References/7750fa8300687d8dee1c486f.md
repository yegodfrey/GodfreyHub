# SetModelPriority

## 接口定义

```screen
AIStatus SetModelPriority(const std::string& modelName, ModelPriority modelPriority);
```

## 功能介绍

设置模型优先级。

## 参数

|名称|类型|描述|
|:------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------|
|modelName|const std::string&|模型名称。|
|modelPriority|ModelPriority|模型优先级，取值请参见[ModelPriority](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelpriority-0000001059203110)。|

## 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|

> 说明
>
> * 本接口为CANN DDK V500新增接口。
> * CANN DDK V500对应Kirin平台映射关系见[支持的平台](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/supported-platforms-0000001052830507)。
> * 此接口功能在其他平台不支持。
> * 本接口需要在模型加载后、模型执行前调用。
