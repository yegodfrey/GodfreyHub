# Overview

提供手部关键点识别SDK，包含机器学习手部关键点服务类和接口。

## Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLHandKeypoint](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlhandkeypoint-0000001052421228)|关键点数据描述类。属于手部关键点数据（MLHandKeypoints）的一部分。包括每个手指关键点的位置、置信度以及点的类型。|
|[MLHandKeypointAnalyzer](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlhandkeypointanalyzer-0000001051821251)|手部关键点分析器，通过调用手部关键点API接口检测手部关键点(MLHandKeypoints）。 创建手部关键点分析器有两种方式： * MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer() * MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer(MLHandKeypointAnalyzerSetting） 前者使用MLHandKeypointAnalyzerSetting中设置的默认值，后者可自定义配置项。|
|[MLHandKeypointAnalyzerFactory](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlhandkeypointanalyzerfactory-0000001052061263)|手部关键点分析工厂类。|
|[MLHandKeypointAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlhandkeypointanalyzersetting-0000001051621265)|手部关键点分析配置器：用于设置手部关键点分析器的属性。|
|[MLHandKeypointAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlhandkeypointanalyzersetting-factory-0000001052261257)|创建手部关键点分析配置器的实例，用于设置手部关键点分析器的属性。|
|[MLHandKeypoints](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlhandkeypoints-0000001052061228)|表示由手部关键点分析器（MLHandKeypointAnalyzer）检测到的手部关键点数据。包括手部区域位置，置信度，以及每个手指关键点的位置、置信度和类型。|
