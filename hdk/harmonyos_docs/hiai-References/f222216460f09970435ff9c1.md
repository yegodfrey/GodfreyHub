# SetInputFormat

## 接口定义

```screen
AIStatus SetInputFormat(AiTensorImage_Format inputFormat);
```

## 功能介绍

设置AIPP的inputFormat参数，设置输入图片的类型。

## 参数

|名称|类型|描述|
|:----------|:-----------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|inputFormat|[AiTensorImage_Format](https://developer.huawei.com/consumer/cn/doc/hiai-References/format-0000001051490704)|输入图片类型。枚举类型取值范围： * AiTensorImage_YUV420SP_U8 * AiTensorImage_XRGB8888_U8 * AiTensorImage_YUV400_U8 * AiTensorImage_ARGB8888_U8 * AiTensorImage_YUYV_U8 * AiTensorImage_YUV422SP_U8 * AiTensorImage_AYUV444_U8 * AiTensorImage_RGB888_U8|

## 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
