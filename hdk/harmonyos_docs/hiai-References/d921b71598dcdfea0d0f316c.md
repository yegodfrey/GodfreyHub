# Overview

#### Class Summary

|Class Name|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[ML3DFace](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dface-0000001062726640)|表示由3D人脸检测器（[ML3DFaceAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dfaceanalyzer-0000001062568432)）检测到的人脸。人脸的属性包括宽高、旋转度、3D坐标点及投影矩阵等。|
|[ML3DFaceAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dfaceanalyzer-0000001062568432)|人脸分析器（不支持人脸特性、表情识别）：用于获取图片中3D人脸对象信息（ML3DFace）。 创建人脸检测器有两种方式：MLAnalyzerFactory.getInstance().get3DFaceAnalyzer()和MLAnalyzerFactory.getInstance().get3DFaceAnalyzer(ML3DFaceAnalyzerSetting）。前者使用ML3DFaceAnalyzerSetting中设置的默认值，后者可自定义配置项。|
|[ML3DFaceAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dfaceanalyzersetting-0000001062408450)|3D人脸检测配置器：用于设置人脸检测器的属性，其属性包括： * 设置分析器对速度/精度的偏好模式，用于选择执行面部检测时的精度或速度优先。 * 是否启用面部跟踪功能。|
|[ML3DFaceAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dfaceanalyzersetting-factory-0000001061448479)|创建人脸检测配置器（[ML3DFaceAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dfaceanalyzersetting-0000001062408450)）的工厂类。|
