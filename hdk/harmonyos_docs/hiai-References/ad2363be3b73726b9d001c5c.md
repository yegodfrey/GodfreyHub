# HiAI_SingleOpTensorDesc_Create

#### 接口定义

```
HiAI_SingleOpTensorDesc* HiAI_SingleOpTensorDesc_Create(const int64_t* dims, size_t dimNum, HiAI_SingleOp_DataType dataType, HiAI_SingleOp_Format format, bool isVirtual);
```

#### 功能介绍

用于根据传入的维度、数据类型、排布格式等参数创建HiAI_SingleOpTensorDesc对象。  

#### 参数

|名称|类型|描述|
|:--------|:-----------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|dims|const int64_t\*|张量维度列表。该值不能为空指针，否则返回空指针。|
|dimNum|size_t|张量维度数量。该值不能为0，否则返回空指针。|
|dataType|[HiAI_SingleOp_DataType](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-datatype-0000001934134237)|张量数据类型。|
|format|[HiAI_SingleOp_Format](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-format-0000001890254506)|张量排布格式。|
|isVirtual|bool|张量是否是虚拟张量。 * true：该张量为虚拟张量。 * false：该张量为非虚拟张量。 虚拟张量是相连的CANN单算子之间的中间张量，其中的数据仅暂时存在，不经非CANN单算子内存读取或写入。例如，若CANN单算子A的输出张量T1仅作为CANN单算子B的输入张量，且用户只读取单算子B的输出张量T2，不会读取或写入T1，那么T1需要被设置为虚拟张量，而T2则是非虚拟张量。|

#### 返回

|类型|描述|
|:------------------------|:---------------------------------------------|
|HiAI_SingleOpTensorDesc\*|成功返回创建完成的HiAI_SingleOpTensorDesc对象指针，否则，返回空指针。|
