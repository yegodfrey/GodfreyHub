# GetMemBufferData

#### 接口定义

```
void* GetMemBufferData();
```

#### 功能介绍

获取通用MemBuffer的内存地址。  

#### 返回

|类型|描述|
|:-----|:--------------|
|void\*|MemBuffer的内存地址。|
