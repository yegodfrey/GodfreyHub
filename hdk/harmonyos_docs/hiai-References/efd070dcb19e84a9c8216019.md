# Overview

提供HUAWEI HiAI Engine 人脸识别的基础实现类及接口方法。  

#### Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[FaceComparator](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/face-comparator-0000001054278817)|[人脸比对](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/facial-comparison-introduction-0000001053859748)接口，对比输入的两张人脸图片是否是同一个人，并给出人脸比对分数。|
|[FaceDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/face-detector-0000001053958835)|[人脸检测](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/face-detection-introduction-0000001053711588)接口，检测给定图片中的人脸位置、特征点（左右眼中心、鼻子、左右嘴角）和姿态（pitch，roll，yaw）信息。|
|[FaceParsing](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/face-parsing-0000001054158841)|[人脸解析](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/face-parsing-introduction-0000001054260975)接口，对输入图片中的人脸做解析，给出人脸的各个面部区域解析结果，共计16类。具体有：背景、头发、脸部皮肤、左/右眉毛、左/右眼睛 、鼻子、上嘴唇/嘴内部/下嘴唇、左/右耳朵 、脖子、眼镜和墨镜。不同的部位用不同颜色予以标注。|
|[FaceAttributesDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/face-attributes-detector-0000001053839127)|[人脸属性](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/face-attributes-introduction-0000001053941079)接口，对输入图片中的人脸做属性识别，给出人脸的性别属性。|
|[HeadposeDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/head-pose-detector-0000001054759116)|[人脸朝向识别](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/face-orientation-recognition-introduction-0000001054741166)接口，识别图像中人脸的朝向信息，并给出具体的朝向类别和置信度。|
|[FaceLandMarkDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/headpose-detector-0000001054279138)|[五官特征检测](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/facial-feature-detection-introduction-0000001054022505)接口，对输入图像进行人脸五官特征检测，返回代表五官轮廓位置的关键点坐标（目前数量为276个landmark点）。可以为美颜处理、人脸建模、表情识别等后续算法进一步处理提供输入。|
