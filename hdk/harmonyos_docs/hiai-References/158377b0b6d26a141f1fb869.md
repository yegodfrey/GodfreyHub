# Overview

此包提供了实时声音识别SDK，开发者集成此SDK，即可获取华为ML Kit提供的实时声音识别能力。具体使用方法可参见：[声音识别开发步骤](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/sound-detection-0000001055282786#section1538393817134)。  

#### Interface Summary

|Interface|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLSoundDetectListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsounddetectlistener-0000001205036625)|当识别到声音后，使用此回调从[MLSoundDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsounddector-0000001054212812)接收数据和事件通知。|

#### Class Summary

|Class Name|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:--------------|
|[MLSoundDetectConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsounddectconstants-0000001054132798)|实时声音识别服务配置常量定义。|
|[MLSoundDetector](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsounddector-0000001054212812)|语音检测。|
