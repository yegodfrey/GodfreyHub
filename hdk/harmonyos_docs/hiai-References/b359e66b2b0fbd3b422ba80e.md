# SetDtcPara(AippDtcPara dtcPara)

## 接口定义

```screen
AIStatus SetDtcPara(AippDtcPara dtcPara);
```

## 功能介绍

设置AIPP DTC数据类型转换参数，为所有的batch设置相同的DTC参数。

## 参数

|名称|类型|描述|
|:------|:-------------------------------------------------------------------------------------------------------|:-----------|
|dtcPara|[AippDtcPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippdtcpara-0000001291851965)|DTC数据类型转换参数。|

## 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
