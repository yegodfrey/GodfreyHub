### faceCompare(Frame frame1, Frame frame2, IVisionCallback cb)

|Method|
|:---------------------------------------------------------------------------------------------------------------------|
|public JSONObject faceCompare(Frame frame1, Frame frame2, IVisionCallback cb) 用于EMUI 10.0以下版本。输入两张人脸图片进行人脸比对，返回JSON对象。|

**Parameters**

|Name|Description|
|:-----|:-------------------------------------------------------------------------------------|
|frame1|图片1的Frame对象。 图片数据，Frame暂只支持封装Bitmap类型的图片数据（要求小于2000万像素），后续会扩展支持文件路径、bytebuffer形式的图片数据。|
|frame2|图片2的Frame对象。 图片数据，Frame暂只支持封装Bitmap类型的图片数据（要求小于2000万像素），后续会扩展支持文件路径、bytebuffer形式的图片数据。|
|cb|回调接口对象。目前暂不支持异步处理。 * 传入空，表示同步处理。 * 传入非空，表示异步处理，用于异步返回结果。|

**Return**

|Type|Description|
|:---------|:-----------------------------------------------------------------------------------------|
|JSONObject|人脸比对结果的JSON对象。 结果说明： * resultCode：错误码。 * isSamePerson：是否为同一人关键词，结果以该参数为准。 * score：人脸比对的分数。|

**示例代码：**

```screen
// 其中以isSamePerson结果为准，来判断是否为同一个人。
FaceCompareResult result = faceComparator.convertResult(jsonObject);
boolean isSamePerson = result.isSamePerson()；
float score = result.getSocre();
```

### faceCompare(VisionImage image1, VisionImage image2, final FaceCompareResult compareResult, final VisionCallback<FaceCompareResult> compareCallback)

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public int faceCompare(VisionImage image1, VisionImage image2, final FaceCompareResult compareResult, final VisionCallback<FaceCompareResult> compareCallback) 用于EMUI 10.0及以上版本。输入两张人脸图片进行人脸比对，返回执行返回码。|

**Parameters**

|Name|Description|
|:--------------|:-------------------------------------------------------------------------------------------------|
|image1|图片1的VisionImage对象。 图片数据，VisionImage暂只支持封装Bitmap类型的图片数据（要求小于2000万像素），后续会扩展支持文件路径、bytebuffer形式的图片数据。|
|image2|图片2的VisionImage对象。 图片数据，VisionImage暂只支持封装Bitmap类型的图片数据（要求小于2000万像素），后续会扩展支持文件路径、bytebuffer形式的图片数据。|
|compareResult|人脸比对结果。 结果说明： * resultCode：错误码。 * isSamePerson：是否为同一人关键词，结果以该参数为准。 * score：人脸比对的分数。|
|compareCallback|回调接口对象。目前暂不支持异步处理。 * 传入空, 表示同步处理。 * 传入非空，表示异步处理，用于异步返回结果。|

**Return**

|Type|Description|
|:---|:----------|
|int|人脸比对执行返回码。|

**示例代码：**

```screen
// 以isSamePerson结果为准，来判断是否为同一人。
FaceCompareResult result = new FaceCompareResult();
resultCode = mFaceComparator.faceCompare(image1, image2, result, null);
boolean isSamePerson = result.isSamePerson();
float score = result.getSocre();
```
