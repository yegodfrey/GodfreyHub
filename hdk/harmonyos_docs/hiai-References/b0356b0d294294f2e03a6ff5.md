# SetGraphBuilder

#### 接口定义

```
Operator& SetGraphBuilder(const string& name, const GraphBuilderFn& graphBuilderFn);
```

#### 功能介绍

设置图的构建函数。  

#### 参数

|名称|输入/输出|类型|描述|
|:-------------|:----|:---------------------|:--------|
|name|输入|const string\&|图的名称。|
|graphBuilderFn|输入|const GraphBuilderFn\&|图构建函数的指针。|

#### 返回

|类型|描述|
|:---------|:----------------------------------------|
|Operator\&|获取属性值成功，返回GRAPH_SUCCESS，否则返回GRAPH_FAILED。|
