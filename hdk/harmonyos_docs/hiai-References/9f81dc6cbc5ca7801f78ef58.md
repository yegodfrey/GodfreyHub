# GetPlatformVersion

#### 接口定义

```
const string& GetPlatformVersion() const;
```

#### 功能介绍

获取用户自定义模型的版本号，版本号是常量。  

#### 返回

|类型|描述|
|:-------------|:-----|
|const string\&|模型版本号。|
