# MLImageSegmentationSetting

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|MLImageSegmentationSetting 图像分割检测器设置类：用于设置检测器（MLImageSegmentationAnalyzer)属性。属性包括： * 检测模式（人像检测模式、图像多类别检测模式），默认为人像检测模式。 * 是否支持精细检测（人像模式和图像多分类检测模式都支持，默认为精细模式）。 * 支持返回结果的种类，默认返回所有结果。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:------------------------------|:-------------------------------------------------------------------------------|
|MLImageSegmentationAnalyzerType|[getAnalyzerType](#section1726413212314) 获取检测模式。|
|MLImageSegmentationScene|[getScene](#section164141834112310) 用户所需能力场景，用户可以根据自身需求选择需要返回的结果，从而减少不必要能力的处理时间。|
|BOOL|[isExact](#section17012316241) 是否是精细检测。|

#### Public Methods

#### getAnalyzerType

|Method|
|:---------------------------------------------------------|
|- (MLImageSegmentationAnalyzerType)getAnalyzerType 获取检测模式。|

Returns  

|Type|Description|
|:------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|MLImageSegmentationAnalyzerType|返回检测模式结果。 * MLImageSegmentationAnalyzerTypeBody：人像检测模式（支持人和背景的区分）。 * MLImageSegmentationAnalyzerTypeImage：图像多类别模式（支持MLImageSegmentationClassification中所有物品分类）。|

#### getScene

|Method|
|:--------------------------------------------------------------------------------|
|- (MLImageSegmentationScene)getScene 用户所需能力场景，用户可以根据自身需求选择需要返回的结果，从而减少不必要能力的处理时间。|

Returns  

|Type|Description|
|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|MLImageSegmentationScene|* MLImageSegmentationSceneAll：全部能力场景。 * MLImageSegmentationSceneMaskOnly：只要像素标记能力。 * MLImageSegmentationSceneForegroundOnly：只要人像前景抠图能力。 * MLImageSegmentationSceneGrayscaleOnly：只要人像为白色，背景为黑色灰度图能力。|

#### isExact

|Method|
|:-----------------------|
|- (BOOL)isExact 是否是精细检测。|

Returns  

|Type|Description|
|:---|:-------------------------------------|
|BOOL|返回当前是否是精细检测模式。 * YES：精细检测。 * NO：非精细检测。|
