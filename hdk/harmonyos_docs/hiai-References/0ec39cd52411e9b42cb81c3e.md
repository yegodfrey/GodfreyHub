# Overview

提供图像分类SDK，包含机器学习图像分类服务类和接口。

## Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------|
|[MLImageClassification](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/imageclassification-0000001050169467)|表示由图像分类器（MLImageClassificationAnalyzer）识别出的图像类别。包含三种属性： * 类别唯一id。 * 类别名称。 * 类别的置信度。|
|[MLImageClassificationAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/imageclassificationanalyzer-0000001050167514)|图像分类器：用于在提供的图像中查找图像类别（MLImageClassification）。|
|[MLImageClassificationAnalyzer.ImageClassificationType](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/imageclassificationtype-0000001050169469)|图像分类器类型的抽象接口，实现注解。|
|[MLLocalClassificationAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/localclassificationanalyzersetting-0000001050167516)|图像分类配置器：用于设置设备端图像分类器的属性。|
|[MLLocalClassificationAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mllocalclassificationanalyzersf-0000001050169471)|创建设备端图像分类配置器的实例。|
|[MLRemoteClassificationAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlremoteclassificationanalyzers-0000001050167518)|图像分类配置器：用于设置云端图像分类器的属性。|
|[MLRemoteClassificationAnalyzerSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlremoteclassificationanalyzersf-0000001050169473)|创建云端图像分类配置器的实例。|
