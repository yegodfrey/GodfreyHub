# Buffer

#### 接口定义

```
explicit Buffer(std::size_t size, std::uint8_t defaultVal = 0);
```

#### 功能介绍

Buffer初始化。  

#### 参数

|名称|输入/输出|类型|描述|
|:---------|:----|:---------------|:-------|
|size|输入|std::size_t size|拷贝数据的大小。|
|defaultVal|输入|std::uint8_t|数据默认值。|

#### 返回

|类型|描述|
|:-----|:---------|
|Buffer|buffer初始化。|
