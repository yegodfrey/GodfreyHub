# HiAI_SingleOpDescriptor_CreateConvolution

#### 接口定义

```
HiAI_SingleOpDescriptor* HiAI_SingleOpDescriptor_CreateConvolution(HiAI_SingleOp_ConvMode convMode, const int64_t strides[2], const int64_t dilations[2], const int64_t pads[4], int64_t groups, HiAI_SingleOp_PadMode padMode);
```

#### 功能介绍

用于根据传入的参数创建卷积类的HiAI_SingleOpDescriptor对象。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150630.79772998041237796720197682178701:50001231000000:2800:0D058526470EF24F78D76FB5729B56DA526FAF406E3C1CB08FE6BA4E6F2CA4EF.png)  
当不再使用HiAI_SingleOpDescriptor对象时，调用[HiAI_SingleOpDescriptor_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopdescriptor-destroy-0000001890414414)销毁，否则会造成内存泄漏。  

#### 参数

|名称|类型|描述|
|:--------|:-----------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|convMode|[HiAI_SingleOp_ConvMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-convmode-0000001890414462)|卷积模式。|
|strides|int64_t\*|卷积核在高度和宽度上的移动步幅，是一个长度为2的int数组\[strideHeight, strideWidth\]。|
|dilations|int64_t\*|卷积核在高度和宽度上的扩张率，是一个长度为2的int数组\[dilationHeight, dilationWidth\]。|
|pads|int64_t\*|各个轴起始和末尾的填充长度，是一个长度为4的int数组 \[h_begin, h_end, w_begin, w_end\]。该值仅在padMode为HIAI_SINGLEOP_PAD_MODE_SPECIFIC时生效。|
|groups|int64_t|输入通道被划分成的组数。若convMode为HIAI_SINGLEOP_CONV_MODE_DEPTHWISE，groups不生效。|
|padMode|[HiAI_SingleOp_PadMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-padmode-0000001934134245)|输入的填充方式。对于HIAI_SINGLEOP_CONV_MODE_CONVOLUTION和HIAI_SINGLEOP_CONV_MODE_DEPTHWISE，支持0(SPECIFIC)，1 (SAME)，2(SAME_UPPER)，3(SAME_LOWER)和4(VALID)。对于HIAI_SINGLEOP_CONV_MODE_TRANSPOSE, 支持0 (SPECIFIC)，1 (SAME)和4 (VALID)。|

#### 返回

|类型|描述|
|:------------------------|:-------------------------------------------|
|HiAI_SingleOpDescriptor\*|指向HiAI_SingleOpDescriptor对象的指针，如果创建失败则返回空指针。|
