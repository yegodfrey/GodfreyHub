# ML3DFaceAnalyzer

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.face3d.ML3DFaceAnalyzer 人脸分析器：用于获取图片中3D人脸对象信息（[ML3DFace](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dface-0000001062726640)）。 创建人脸检测器有两种方式：MLAnalyzerFactory.getInstance().get3DFaceAnalyzer()和MLAnalyzerFactory.getInstance().get3DFaceAnalyzer(ML3DFaceAnalyzerSetting）。前者使用ML3DFaceAnalyzerSetting中设置的默认值，后者可自定义配置项。 说明： 此类不支持人脸特性、表情识别。|
