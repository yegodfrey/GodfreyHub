# Overview

ML Kit的身份证识别检测组件，此包提供了身份证识别检测的标准模式，核心API如下：

* MLIdCard：身份证识别结果的具体信息。
* MLIcrAnalyzer：端侧身份证识别检测器，用于在提供的图像中，识别身份证信息，调用端侧API，检测模型在端侧运行。
