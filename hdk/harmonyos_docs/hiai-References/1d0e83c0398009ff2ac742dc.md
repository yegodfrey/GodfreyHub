# MLMaxSizeFaceTransactor

|Class Info|
|:----------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.MLMaxSizeFaceTransactor 最大人脸处理器，在某一时刻只处理图像中面积最大的人脸。|

**Sample code：**

```screen
// 创建人脸分析器。
MLFaceAnalyzer analyzer = MLAnalyzerFactory.getInstance().getFaceAnalyzer();
// 创建最大人脸处理器，用于筛选出一张最大的人脸，将结果传递给MLResultTrailer处理。MLResultTrailer是一个基类，需要开发者根据业务逻辑继承实现。
MLMaxSizeFaceTransactor transactor = new MLMaxSizeFaceTransactor.Creator(analyzer, new MLResultTrailer<MLFace>()).create();
analyzer.setTransactor(transactor);
// 该处理器仅用于实时视频检测，对单张图像检测无效。
LensEngine lensEngine = new LensEngine.Creator(context, analyzer)
   .applyDisplayDimension(640, 480)
   .create();
```
