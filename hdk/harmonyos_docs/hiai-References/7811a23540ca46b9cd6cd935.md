# Overview

提供ML Kit SDK基础实现类及接口方法。  

#### Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------|
|[MLApplication](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlapplication-harmonyos-0000001201420740)|App信息类，用于存储集成了ML Kit SDK的App基本信息。通常情况下，应用开发者不与这个类直接交互， ML Kit SDK会结合开发者申请的agconnect-services.json，完成ML Kit的初始化，不需要开发者编写额外的代码。|
