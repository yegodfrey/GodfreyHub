# HiAI_SingleOpTensorDesc_GetDataType

## 接口定义

```screen
HiAI_SingleOp_DataType HiAI_SingleOpTensorDesc_GetDataType(const HiAI_SingleOpTensorDesc* tensorDesc);
```

## 功能介绍

用于获取指定HiAI_SingleOpTensorDesc对象的数据类型。

## 参数

|名称|类型|描述|
|:---------|:-----------------------------|:----------------------------------------------------------------------|
|tensorDesc|const HiAI_SingleOpTensorDesc*|指向HiAI_SingleOpTensorDesc对象的指针。该值不能为空指针，否则返回HIAI_SINGLEOP_DT_UNDEFINED。|

## 返回

|类型|描述|
|:-----------------------------------------------------------------------------------------------------------------------------|:-------|
|[HiAI_SingleOp_DataType](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-datatype-0000001934134237)|张量的数据类型。|
