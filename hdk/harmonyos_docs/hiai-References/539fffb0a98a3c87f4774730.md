# 获取版本号

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetVersion](https://developer.huawei.com/consumer/cn/doc/hiai-References/getversion-0000001051650680)替代。

## 接口定义

```screen
HIAI_UTIL_API_EXPORT static const char* GetVersion();
```

## 功能介绍

获取版本号。

## 返回

|类型|描述|
|:----------|:---|
|const char*|版本号。|
