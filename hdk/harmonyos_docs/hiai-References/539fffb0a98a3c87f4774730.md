# 获取版本号

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150626.79139324654921280240105683310744:50001231000000:2800:3AF73AC1DB25676D38CA5BF2313A434F71D385D6582077B63AA8BF7FE5269D6E.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetVersion](https://developer.huawei.com/consumer/cn/doc/hiai-References/getversion-0000001051650680)替代。  

#### 接口定义

```
HIAI_UTIL_API_EXPORT static const char* GetVersion();
```

#### 功能介绍

获取版本号。  

#### 返回

|类型|描述|
|:-----------|:---|
|const char\*|版本号。|
