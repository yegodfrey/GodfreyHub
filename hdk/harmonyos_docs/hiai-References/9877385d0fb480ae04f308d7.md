# MLText.Base

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.text.MLText.Base 文本信息的父类，表示图像检测出的基本文本信息。包含5个属性： * 检测出的文本内容。 * 文本的边框。 * 文本边框的顶点。 * 检测结果的置信度。 * 检测到的所有语种。|

#### getContents()

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public List\<? extends [MLText.Base](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mltextbase-harmonyos-0000001245837645)\> getContents() 获取当前文本对象包含的低一级的文本对象，当前方法需要在子类中重写。 文本对象分为文本区块（Block）、文本行（TextLine）、文本元素（Word）： * 文本区块（Block）是最高级的文本对象，可包含多个低一级的文本行（TextLine）对象。 * 文本行对象可包含多个最低级的文本元素（Word）对象。 * 文本元素（Word）对象是一组字符组成的词。 如果当前文本对象为最低级文本对象（Word）则返回空。|

Returns  

|Type|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------|
|List\<? extends [MLText.Base](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mltextbase-harmonyos-0000001245837645)\>|返回当前文本对象包含的低一级的文本对象，例如：如果当前对象是文本行（TextLine），则返回文本元素（Word）集合。|
