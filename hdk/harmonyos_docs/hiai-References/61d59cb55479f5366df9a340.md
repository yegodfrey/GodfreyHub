# Overview

此包提供了实时语音识别SDK，开发者集成此SDK，即可获取华为ML Kit提供的实时语音识别能力，开发丰富多彩的语音识别应用。具体使用方法可参见：

[实时语音识别开发步骤](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/real-time-transcription-harmonyos-0000001204197358#section1538393817134)。  

#### Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLAsrListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrlistener-harmonyos-0000001249269741)|当识别相关事件发生后，使用该接口从[MLAsrRecognizer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrrecognizer-harmonyos-0000001249149695)接收数据和事件通知。|

#### Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLAsrConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrconstant-harmonyos-0000001204669692)|实时语音识别服务配置常量定义。|
|[MLAsrRecognizer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrrecognizer-harmonyos-0000001249149695)|语音识别器。通过[startRecognizing](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrrecognizer-harmonyos-0000001249149695#section296513052713)开始收听识别语音，开始前需要先设置监听器[setAsrListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrrecognizer-harmonyos-0000001249149695#section19121231278)。|
