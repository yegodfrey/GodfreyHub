# MLImageSegmentationSetting

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.imgseg.MLImageSegmentationSetting 图像分割检测器设置类：用于设置检测器（MLImageSegmentationAnalyzer)属性。 属性包括： * 检测模式（人像检测模式、图像多类别检测模式、头发检测模式），默认为人像检测模式。 * 是否支持精细检测（人像模式和图像多分类检测模式都支持，默认为精细模式）。 * 支持返回结果的种类，默认返回所有结果。|
