# Batch

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetBatchCount](https://developer.huawei.com/consumer/cn/doc/hiai-References/getbatchcount-0000001052809449)替代。

## 接口定义

```screen
virtual int32_t Batch() const = 0;
```

## 功能介绍

获取输入图像的batch大小。

## 返回

|类型|描述|
|:------|:--------------|
|int32_t|返回输入图像的batch大小。|
