# SetCscPara(AippCscPara cscPara)

#### 接口定义

```
AIStatus SetCscPara(AippCscPara cscPara);
```

#### 功能介绍

设置AIPP Color Space Conversion色域转换参数。  

#### 参数

|名称|类型|描述|
|:------|:-------------------------------------------------------------------------------------------------------|:-------|
|cscPara|[AippCscPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippcscpara-0000001244372196)|CSC转换参数。|

#### 返回

|类型|描述|
|:-------|:------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败|
