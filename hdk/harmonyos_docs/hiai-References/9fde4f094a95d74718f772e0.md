# MLFaceKeyPoint

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.MLFaceKeyPoint 人脸关键点，表示检测到的人脸上的一个点。关键点类型包括： TYPE_BOTTOM_OF_MOUTH：值为1，代表下嘴唇的中心点。 TYPE_LEFT_CHEEK：值为2，代表左脸颊的中心点。 TYPE_LEFT_EAR：值为3，代表左耳屏的中心点。 TYPE_TIP_OF_LEFT_EAR：值为4，代表左耳顶点。 TYPE_LEFT_EYE：值为5，代表左眼球的中心点。 TYPE_LEFT_SIDE_OF_MOUTH：值为6，代表左嘴角位置点。 TYPE_TIP_OF_NOSE：值为7，代表鼻尖中心点。 TYPE_RIGHT_CHEEK：值为8，代表右脸颊的中心点。 TYPE_RIGHT_EAR：值为9，代表右耳屏的中心点。 TYPE_TIP_OF_RIGHT_EAR：值为10，代表右耳顶点。 TYPE_RIGHT_EYE：值为11，代表右眼球的中心点。 TYPE_RIGHT_SIDE_OF_MOUTH：值为12，代表右嘴角位置点。 > 注意 > 文中所说的"左"、"右"，均指的是面向图像时你的左右，并非图像中人脸的左右。|
