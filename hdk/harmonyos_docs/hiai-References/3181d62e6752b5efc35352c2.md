# ML3DFace

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.face3d.ML3DFace 表示由3D人脸检测器（[ML3DFaceAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ml3dfaceanalyzer-0000001062568432)）检测到的人脸。人脸的属性包括宽高、旋转度、3D坐标点及投影矩阵等。 说明： 此类不支持人脸特性、表情识别。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------|
|int|[LANDMARK_FIVE](#section289934410414) 人脸关键点标注类型，表示5个人脸关键点。 * 0：右眼中心点。 * 1：左眼中心点。 * 2：鼻尖。 * 3：嘴唇相交处的右嘴角。 * 4：嘴唇相交处的左嘴角。|

|Method|

Returns
