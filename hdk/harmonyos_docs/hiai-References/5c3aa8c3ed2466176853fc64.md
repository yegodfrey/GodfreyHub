# GetContent

>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetAllKeys](https://developer.huawei.com/consumer/cn/doc/hiai-References/getallkeys-0000001052609440)替代。

## 接口定义

```screen
const std::map<std::string, std::string>& GetContent() const;
```

## 功能介绍

获取上下文中的所有参数和对应值。

## 返回

|类型|描述|
|:----------------------------------------|:------|
|const std::map<std::string, std::string>&|参数和对应值。|
