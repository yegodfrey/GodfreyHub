# GetCscPara

#### 接口定义

```
AippCscPara GetCscPara();
```

#### 功能介绍

获取AIPP参数中的Color Space Conversion色域转换参数。  

#### 返回

|类型|描述|
|:-------------------------------------------------------------------------------------------------------|:------|
|[AippCscPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippcscpara-0000001244372196)|色域转换参数。|
