# SetWidth

## 接口定义

```screen
void SetWidth(const uint32_t width);
```

## 功能介绍

设置输入Tensor宽度。

## 参数

|名称|类型|描述|
|:----|:-------------|:-------------|
|width|const uint32_t|模型输入Tensor的宽度。|
