# HiAI_SingleOpOptions_Destroy

## 接口定义

```screen
void HiAI_SingleOpOptions_Destroy(HiAI_SingleOpOptions** options);
```

## 功能介绍

用于释放调用HiAI_SingleOpOptions_Create创建的HiAI_SingleOpOptions对象。

## 参数

|名称|类型|描述|
|:------|:---------------------|:-----------------------------------------------------------|
|options|HiAI_SingleOpOptions**|指向HiAI_SingleOpOptions对象的二级指针。options和*options不能是空指针，否则销毁失败。|
