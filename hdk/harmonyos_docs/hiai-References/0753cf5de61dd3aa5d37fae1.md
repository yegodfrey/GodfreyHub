# MLIcrAnalyzer

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.card.icr.MLIcrAnalyzer 端侧身份证检测器：用于在提供的图像中，识别身份证信息。端侧身份证检测器，调用端侧API，检测模型在端侧运行。创建端侧身份证检测器有两种方式，根据实际情况二选一。 ```screen // 方式1：使用默认的参数配置。 MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer(); // 方式2：使用自定义的参数配置。 MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer(setting); ```|

**Sample code:**

```screen
// 方式1：使用默认的参数配置.默认识别正面。
MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer();
// 方式2：使用自定义的参数配置。
// setSideType 设置身份证正面或反面。
// MLIcrAnalyzerSetting.FRONT：值为"FRONT"，即正面。
// MLIcrAnalyzerSetting.BACK：值为"BACK"，即反面。
MLIcrAnalyzerSetting settings = new MLIcrAnalyzerSetting.Factory()
   .setSideType(MLIcrAnalyzerSetting.FRONT)
   .create();
MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer(settings);
// 通过Bitmap构造MLFrame，，建议图片尺寸不小于512*512。
MLFrame mlFrame = new MLFrame.Creator().setBitmap(bitmap).create();
// 将创建的MLFrame对象传递给 asyncAnalyseFrame 方法进行卡证识别。
Task<MLIdCard> task = analyzer.asyncAnalyseFrame(mlFrame);
task.addOnSuccessListener(new OnSuccessListener<MLIdCard>() {
   public void onSuccess(MLIdCard idCard) {
       //检测成功的处理逻辑。
}})
.addOnFailureListener(new OnFailureListener() {
   public void onFailure(Exception e) {
       //检测失败的处理逻辑。
}});
```
