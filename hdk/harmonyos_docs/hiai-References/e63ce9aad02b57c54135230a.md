# SetValue

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150631.28637660731757262372094916132056:50001231000000:2800:56E101AC99D6E0B8D73624BB3486A84845B1CBD0D4DC2F2F42287342968FF678.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[SetPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/setpara-0000001052570735)替代。  

#### 接口定义

```
void SetValue(const std::string& key, const std::string& value);
```

#### 功能介绍

设置自定义的参数。  

#### 参数

|名称|类型|描述|
|:----|:------------------|:------|
|key|const std::string\&|指定参数名称。|
|value|const std::string\&|参数对应的值。|
