# IsEqual

#### 接口定义

```
bool IsEqual(const TensorDimension& dim);
```

#### 功能介绍

判断与输入Tensor的尺寸结构信息是否相同。  

#### 参数

|名称|类型|描述|
|:--|:----------------------|:----------------|
|dim|const TensorDimension\&|需判断的Tensor尺寸结构信息。|

#### 返回

|类型|描述|
|:---|:-------------------------------------------|
|bool|与输入Tensor尺寸结构信息是否相同。 * true：相同。 * false：不相同。|
