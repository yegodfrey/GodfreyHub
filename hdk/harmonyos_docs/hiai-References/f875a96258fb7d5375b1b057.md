# DelInputWithOriginalType

#### 函数功能

根据算子类型，删除算子指定输入边。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150657.89772547446862504508840419197933:50001231000000:2800:CC1A4D22F33E67BF090F757B2A155BB788CCF870A6CB279BC2C2C7F0E884444A.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
OpRegistrationData &DelInputWithOriginalType(int32_t input_idx, const std::string &ori_type)
OpRegistrationData &DelInputWithOriginalType(int32_t input_idx, const char_t *ori_type)
```

#### 参数说明

|参数|输入/输出|说明|
|:--------|:----|:-----------|
|input_idx|输入|需要删除的输入边编号。|
|ori_type|输入|删除节点的原始算子类型。|
