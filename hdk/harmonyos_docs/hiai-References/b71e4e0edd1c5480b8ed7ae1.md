# SetChannel

#### 接口定义

```
void SetChannel(const uint32_t channel);
```

#### 功能介绍

设置输入Tensor通道数。  

#### 参数

|名称|类型|描述|
|:------|:-------------|:--------------|
|channel|const uint32_t|模型输入Tensor的通道数。|
