# FaceParsing

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hiai.vision.face.FaceParsing CV引擎的FaceParsing封装了对输入图片中的人脸做解析的能力，给出人脸的各个面部区域解析结果，共计16类。具体有：背景、头发、脸部皮肤、左/右眉毛 、左/右眼睛 、鼻子、上嘴唇/嘴内部/下嘴唇、左/右耳朵 、脖子、眼镜和墨镜。不同的部位用不同颜色予以标注。|
