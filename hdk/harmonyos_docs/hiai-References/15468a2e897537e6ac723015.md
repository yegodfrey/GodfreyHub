# GetTotalDimNum

#### 接口定义

```
int64_t GetTotalDimNum() const;
```

#### 功能介绍

获取Shape中所有dim的累乘结果。  

#### 返回

|类型|描述|
|:------|:------------|
|int64_t|返回所有dim的累乘结果。|
