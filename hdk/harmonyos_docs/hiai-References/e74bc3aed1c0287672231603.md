# BuildOptions

|Struct Info|
|:------------------------|
|struct BuildOptions 编译参数。|

|Qualifier and Type|Field and Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|bool|useOriginFormat 是否使用原始Format，默认值为false，不使用。 * true：使用。 * false：不使用。|
|[ExecuteDeviceSelectMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/executedeviceselectmode-0000001281459574)|mode 选择异构的模式，默认值为AUTO。|
|[WeightDataType](https://developer.huawei.com/consumer/cn/doc/hiai-References/weighdatatype-0000001333300065)|weightDataType 权值数据类型。默认值为FP32。|
|std::map<std::string, std::vector<[OpExecuteDevice](https://developer.huawei.com/consumer/cn/doc/hiai-References/opexecutedevice-0000001225896829)>>|opExecuteDeviceConfig 算子的异构信息集合。 当SupportDevice出现多种硬件时，可以修改ExecuteDevice为可支持的硬件设备。比如Reshape算子的SupportDevice为CPU:NPU，那么此算子的ExecuteDevice可以修改为CPU或者NPU。 * ExecuteDevice：算子执行硬件。 * OpName：算子名称。 * SupportDevice：算子的可执行硬件。 * Type：算子的类型。|
|std::vector<std::vector<int64_t>>|inputShapes 根据新指定的shape参数进行编译。|
|[TuningStrategy](https://developer.huawei.com/consumer/cn/doc/hiai-References/tuningstrategy-0000001333619929)|tuningStrategy 调优策略配置，默认值为TuningStrategy::OFF。 在[DDK侧异构](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/heterogeneity-0000001276923990#ZH-CN_TOPIC_0000001276923990__li17566325173710)场景下，IR在线编译时需要和SetTuningStrategy配合使用，请参见[代码示例](#section48431317191218)。|
|vector<[ExecuteDevice](https://developer.huawei.com/consumer/cn/doc/hiai-References/executedevice-0000002014720312)>|modelDeviceOrder 模型级指定运行设备的优先级列表，当高优先级设备能够支持模型整体运行需要时，则不再继续使用低优先级设备。 例如：当设置NPU设备优先级最高时，则优先使用NPU侧的设备能力(包含CPU ROM)，否则会使用DDK侧设备能力（CPU APP等）。|
|[DeviceMemoryReusePlan](https://developer.huawei.com/consumer/cn/doc/hiai-References/devicememoryreuseplan-0000002050722333)|deviceMemoryReusePlan 设备内存重用计划。默认值为UNSET，表示不设置。|
|string|quantizeConfig 量化配置buffer，传入量化配置，支持在模型编译过程中对模型做在线量化。量化配置由DDK提供的模型轻量化工具生成。该功能需Rom版本配套支持，起始支持版本为100.515.020.XXX。|

## 代码示例

```screen
auto irBuilderV1 = std::make_shared<hiai::HiaiIrBuild>();
hiai::BuildOptions buildOptions;
buildOptions.tuningStrategy = hiai::TuningStrategy::ON_DEVICE_TUNING;
irBuilderV1->BuildIRModel(model, omBuf, buildOptions);
auto modelDescV1 = std::make_shared<hiai::AiModelDescription>("model", 3, 0, 0, 0);
modelDescV1->SetModelBuffer(omBuf.data, omBuf.length);
modelDescV1->SetTuningStrategy(hiai::TuningStrategy::ON_DEVICE_TUNING);
auto clientV1 = std::make_shared<hiai::AiModelMngerClient>();
std::vector<std::shared_ptr<hiai::AiModelDescription>> modelDescVec;
modelDescVec.push_back(modelDescV1);
clientV1->Init(nullptr);
clientV1->Load(modelDescVec);
```
