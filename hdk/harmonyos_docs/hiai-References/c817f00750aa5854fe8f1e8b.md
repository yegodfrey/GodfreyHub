# GetResizePara

## 接口定义

```screen
AippResizePara GetResizePara(uint32_t batchIndex);
```

## 功能介绍

获取AIPP参数中的Resize参数。

## 参数

|名称|类型|描述|
|:---------|:-------|:-------------------------------------|
|batchIndex|uint32_t|batch下标，标识获取第几个batch中的Resize参数，取值需>=0。|

## 返回

|类型|描述|
|:-------------------------------------------------------------------------------------------------------------|:--------|
|[AippResizePara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippresizepara-0000001245217314)|Resize参数。|
