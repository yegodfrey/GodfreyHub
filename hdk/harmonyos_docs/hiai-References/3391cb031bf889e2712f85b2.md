# GetOutput

## 接口定义

```screen
OpAnchor GetOutput(const uint32_t outIndex) const;
```

## 功能介绍

获取算子输出节点的Anchor信息。

## 参数

|名称|输入/输出|类型|描述|
|:-------|:----|:-------------|:---------|
|outIndex|输入|const uint32_t|算子输出节点的索引。|

## 返回

|类型|描述|
|:-------|:---------------|
|OpAnchor|算子输出节点的Anchor信息。|
