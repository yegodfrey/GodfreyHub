# GetMemBufferSize

## 接口定义

```screen
uint32_t GetMemBufferSize();
```

## 功能介绍

获取通用MemBuffer的内存大小（单位：byte）。

## 返回

|类型|描述|
|:-------|:----|
|uint32_t|内存大小。|
