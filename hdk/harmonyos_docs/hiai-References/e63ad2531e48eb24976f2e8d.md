### speak(String text, int mode)

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String speak(String text, int mode) 实时语音合成并播放API。 * 排队模式（QUEUE_APPEND）：生成语音合成任务。如果当前正在播放，则将任务放在队列中顺序执行；如果当前处于播放暂停状态，则恢复播放，再将任务放入队列中顺序执行；如果当前无播放任务，则立即执行。 * 清空模式（QUEUE_FLUSH）：立即停止正在进行的语音合成任务以及播放，并清空正在排队的语音合成任务，立即执行此次语音合成任务并播放。 注意 > 排队模式和清空模式二者选其一，如果都选清空模式会覆盖排队模式 * 实时流输出模式（OPEN_STREAM）：将文本合成的语音数据流通过[onAudioAvailable](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlttscallback-0000001205036619#section18852205617712)回调输出。即音频流在往内部播放器发送的时候，同时拷贝了一份透传给App。 * 外部播放模式（EXTERNAL_PLAYBACK）：屏蔽内部自带播放器播放音频的能力，同时将文本合成的语音数据流通过[onAudioAvailable](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlttscallback-0000001205036619#section18852205617712)回调输出。此时回调接口中播放相关回调接口将会失效，仅能监听语音合成相关回调接口。|

**Parameters**

|Name|Description|
|:---|:-------------------------------------------------------------------------|
|text|传入待转语音的文本，文本长度最大500字符，即text.length()不能大于500，text文本编码格式为UTF-8。|
|mode|语音合成任务播放模式。当前有四种类型：QUEUE_APPEND、QUEUE_FLUSH、OPEN_STREAM、EXTERNAL_PLAYBACK。|

**Returns**

|Type|Description|
|:-----|:-----------------|
|String|taskID 返回语音合成任务ID。|

**Sample code：**

```screen
MLTtsEngine mlTtsEngine = new MLTtsEngine(null);
String text = "Hello world";
// 排队模式进行语音合成，使用SDK内置播放器播放语音。
String id = mlTtsEngine.speak(text, MLTtsEngine.QUEUE_APPEND); 
// 排队模式进行语音合成，将合成的语音流通过onAudioAvailable回调输出，同时使用SDK内置播放器播放语音。
String id = mlTtsEngine.speak(text, MLTtsEngine.QUEUE_APPEND | MLTtsEngine.OPEN_STREAM); 
// 排队模型进行语音合成，将合成的语音流通过onAudioAvailable回调输出，输出语音流不播放，由开发者控制。
String id = mlTtsEngine.speak(text, MLTtsEngine.QUEUE_APPEND | MLTtsEngine.OPEN_STREAM | MLTtsEngine.EXTERNAL_PLAYBACK); 
```
