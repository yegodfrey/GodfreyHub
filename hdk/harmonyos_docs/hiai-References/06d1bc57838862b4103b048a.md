# HiAI_SingleOpDescriptor_CreateActivation

## 接口定义

```screen
HiAI_SingleOpDescriptor* HiAI_SingleOpDescriptor_CreateActivation(HiAI_SingleOp_ActivationType activationType, float coef);
```

## 功能介绍

用于根据传入的参数创建激活函数类的HiAI_SingleOpDescriptor对象。
> 注意
>
> 当不再使用HiAI_SingleOpDescriptor对象时，调用[HiAI_SingleOpDescriptor_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopdescriptor-destroy-0000001890414414)销毁，否则会造成内存泄漏。

## 参数

|名称|类型|描述|
|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------|
|activationType|[HiAI_SingleOp_ActivationType](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-activationtype-0000001890254514)|激活模式。|
|coef|float|如果激活模式为带系数的激活类型，该值表示系数。否则，该值不会生效。|

## 返回

|类型|描述|
|:-----------------------|:-------------------------------------------|
|HiAI_SingleOpDescriptor*|指向HiAI_SingleOpDescriptor对象的指针，如果创建失败则返回空指针。|
