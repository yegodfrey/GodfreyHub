# Overview

此包提供了人脸比对服务， 核心类如下：

* 使用以下3个类构造人脸比对分析器：
  * MLFaceVerificationAnalyzerSetting：人脸比对分析配置器。
  * MLFaceVerificationAnalyzerFactory：人脸比对检测工厂类。
  * MLFaceVerificationAnalyzer：人脸比对分析器。
* 以下3个类用于封装人脸比对分析的结果：
  * MLFaceInfo：用于封装人脸比对业务在输入图片中检测出来的人脸信息。
  * MLFaceTemplateResult：用于封装人脸比对业务中设置的模板结果信息。
  * MLFaceVerificationResult：用于封装人脸比对的结果信息。
