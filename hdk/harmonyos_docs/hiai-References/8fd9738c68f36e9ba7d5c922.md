# HiAI_SingleOpTensorDesc_GetDimension

#### 接口定义

```
int64_t HiAI_SingleOpTensorDesc_GetDimension(const HiAI_SingleOpTensorDesc* tensorDesc, size_t index);
```

#### 功能介绍

用于获取指定HiAI_SingleOpTensorDesc对象的某个维度的长度。  

#### 参数

|名称|类型|描述|
|:---------|:------------------------------|:---------------------------------------------|
|tensorDesc|const HiAI_SingleOpTensorDesc\*|指向HiAI_SingleOpTensorDesc对象的指针。该值不能为空指针，否则返回0。|
|index|size_t|维度的索引值。索引从0开始。|

#### 返回

|类型|描述|
|:------|:-----------------------------|
|int64_t|张量的索引为index的维度的长度，如果执行失败，则返回0。|
