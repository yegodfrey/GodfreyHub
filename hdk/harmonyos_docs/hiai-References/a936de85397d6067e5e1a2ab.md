# MLAsrListener

|Interface Info|
|:----------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.asr.MLAsrListener 当识别发生后，使用该接口从MLAsrRecognizer接收数据和事件通知。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|void|[onError](#section1817312256914)(int error, String errorMessage) 网络错误或者识别错误后会调用该接口。|
|void|[onRecognizingResults](#section1526433941313)(Bundle recognizingResults) 当用户配置语音识别模式为MLAsrConstants.FEATURE_WORDFLUX时，语音识别器会通过该接口持续返回语音识别的结果。|
|void|[onResults](#section19348143218182)(Bundle results) 从语音识别器接收到最终的语音识别结果。|
|void|[onStartListening](#section851125513189)() 录音器开始接收声音。|
|void|[onStartingOfSpeech](#section164411327198)() 语音识别器检测到用户开始讲话。|
|void|[onState](#section13785538342)(int state, Bundle params) 通知应用状态发生改变。|
|void|[onVoiceDataReceived](#section58317132193)(byte\[\] data,float energy, Bundle params) 返回给用户原始的PCM音频流和音频能量。|

#### Public Methods

#### onError

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onError(int error, String errorMessage) 网络错误或者识别错误后会调用该接口。返回的错误码可以参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdkasr-errorcode-0000001058129301)进行处理。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|error|错误码，见[MLAsrConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrconstants-0000001050169559)中错误码。 * [ERR_NO_NETWORK](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrconstants-0000001050169559#section1367221315149)。 * [ERR_NO_UNDERSTAND](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrconstants-0000001050169559#section16139154011419)。 * [ERR_SERVICE_UNAVAILABLE](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrconstants-0000001050169559#section339211817156)。|
|errorMessage|错误消息。|

#### onRecognizingResults

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onRecognizingResults(Bundle recognizingResults) 当用户配置语音识别模式为MLAsrConstants.FEATURE_WORDFLUX时，语音识别器会通过该接口持续返回语音识别过程中的结果。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:-----------------|:--------------------------------------------------------------------------------------------------|
|recognizingResults|语音识别过程中返回的结果。 目前Bundle中携带了识别后的文本信息，文本信息以String类型保存在以MLAsrRecognizer.RESULTS_RECOGNIZING为key的value中。|

#### onResults

|Method|
|:-----------------------------------------------------------------------------------|
|public void onResults(Bundle results) 从语音识别器接收到最终的语音识别结果。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:------|:----------------------------------------------------------------------------------------------|
|results|语音识别返回的结果。 目前Bundle中携带了识别后的文本信息，文本信息以String类型保存在以MLAsrRecognizer.RESULTS_RECOGNIZED为key的value中。|

#### onStartListening

|Method|
|:----------------------------------------|
|public void onStartListening() 录音器开始接收声音。|

#### onStartingOfSpeech

|Method|
|:-------------------------------------------------------|
|public void onStartingOfSpeech() 用户开始讲话，即语音识别器检测到用户开始讲话。|

#### onState

|Method|
|:-----------------------------------------------------------------------------------|
|public void onState(int state, Bundle params) 通知应用状态发生改变。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:-----|:----------------------------------------------------------------------------------------------------------------------------|
|state|状态码见[MLAsrConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrconstants-0000001050169559)。|
|params|保留字段。|

#### onVoiceDataReceived

|Method|
|:--------------------------------------------------------------------------------------------------------------------------|
|public void onVoiceDataReceived(byte\[\] data, float energy, Bundle params) 返回给用户原始的PCM音频流和音频能量。该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:-----|:---------------------------------------|
|data|PCM音频流，PCM音频采集格式为16000Hz采样率，16bit位深，单声道。|
|energy|音频流的能量值。|
|params|保留字段。|
