# SetInputIndex

## 接口定义

```screen
AIStatus SetInputIndex(uint32_t inputIndex);
```

## 功能介绍

设置AIPP inputIndex参数。

## 参数

|名称|类型|描述|
|:---------|:-------|:----------------------------------------------------|
|inputIndex|uint32_t|用于标识此AIPP参数作用于模型的第几个输入，取值需>=0。如果模型有多个输入，必须显式指定作用于第几个。|

## 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
