# Overview

ML Kit的拍照购商品检测插件。

通过自动识别图片或者相机拍摄中的物品，在线检索第三方应用程序中的类似商品，将结果呈现给用户。

例如，在购物类应用中，可以使用扫一扫功能，快速找到其拍摄的商品信息。
