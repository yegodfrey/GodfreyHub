# Overview

此包提供了实时语音识别SDK，开发者集成此SDK，即可获取华为ML Kit提供的实时语音识别能力，开发者可以定义自己的拾音界面，开发丰富多彩的语音识别应用。具体使用方法可参见：[实时语音识别开发步骤](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/ml-asr-0000001050066212#section664654991819)。

## Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLAsrListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlasrlistener-0000001204518089)|当识别相关事件发生后，使用该接口从[MLAsrRecognizer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlasrrecognizer-0000001050697922)接收数据和事件通知。|
|[MLAsrRecognizer.LanguageCallback](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlasrrecognizer-languagecallback-0000001159518078)|支持的语种查询结果回调。|

## Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLAsrConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/asrconstants-0000001050169559)|实时语音识别服务配置常量定义。|
|[MLAsrRecognizer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlasrrecognizer-0000001050697922)|语音识别器。通过[startRecognizing](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlasrrecognizer-0000001050697922#section296513052713)开始收听识别语音，开始前需要先设置监听器[setAsrListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlasrrecognizer-0000001050697922#section19121231278)。|
