# MLHandKeypointAnalyzerSetting.Factory

|Class Info|
|:-------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.handkeypoint.MLHandKeypointAnalyzerSetting.Factory 创建手部关键点分析配置器的实例，用于设置手部关键点分析器的属性。|

Sample code：

```
MLHandKeypointAnalyzerSetting settings = new MLHandKeypointAnalyzerSetting
            .Factory()
            // 设置结果返回模式，默认手部关键点和手部区域信息都返回。
            .setSceneType(MLHandKeypointAnalyzerSetting.TYPE_ALL)
            // 设置同一张图片中最多支持检测到的人手数量，默认最多支持检测到的人手数量为10个。
            .setMaxHandResults(1)
            .create();
```
