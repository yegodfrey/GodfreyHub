# Load

#### 接口定义

```
GraphErrCodeStatus Load(const uint8_t* data, size_t len);
```

#### 功能介绍

加载序列化数据，反序列化构建模型对象。  

#### 参数

|名称|输入/输出|类型|描述|
|:---|:----|:---------------|:-------|
|data|输入|const uint8_t \*|序列化数据指针。|
|len|输入|size_t|序列化数据长度。|

#### 返回

|类型|描述|
|:-----------------|:--------------------------------------|
|GraphErrCodeStatus|执行成功，返回GRAPH_SUCCESS，否则，返回GRAPH_FAILED。|
