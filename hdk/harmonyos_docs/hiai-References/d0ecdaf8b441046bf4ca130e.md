# FaceLandMarkDetector

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hiai.vision.face.FaceLandMarkDetector 本接口可以对输入图像进行人脸五官特征检测，返回代表五官轮廓位置的关键点坐标（目前数量为68个五官的各特征点坐标点）。可以为美颜处理、人脸建模、表情识别等后续算法进一步处理提供输入。|

**Parameters**

|Name|Description|
|:-------------------|:----------------------------------------------------------------------------|
|image|图片数据，VisionImage支持封装Bitmap类型的图片数据，后续会扩展支持文件路径、bytebuffer形式的图片数据。图片尺寸最小为64x64。|

|:---|:----------|
