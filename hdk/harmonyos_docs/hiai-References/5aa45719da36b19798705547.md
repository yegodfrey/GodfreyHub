# CreateBuiltModel

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150627.37863768464720839218889748606734:50001231000000:2800:681276E35002D0717730B546F8ADA5CFA6574749B5C719054BFDC6CE371FFDA6.png)  
此接口从DDK 5.0.1.0版本起废弃。  

#### 接口定义

```
HIAI_M_API_EXPORT std::shared_ptr<IBuiltModel> CreateBuiltModel();
```

#### 功能介绍

创建已编译模型实例指针。  

#### 返回

|类型|描述|
|:-----------------------------|:-------------------|
|std::shared_ptr\<IBuiltModel\>|* 非空指针：成功。 * 空指针：失败。|
