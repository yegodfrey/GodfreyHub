# CreateBuiltModel

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃。

## 接口定义

```screen
HIAI_M_API_EXPORT std::shared_ptr<IBuiltModel> CreateBuiltModel();
```

## 功能介绍

创建已编译模型实例指针。

## 返回

|类型|描述|
|:---------------------------|:-------------------|
|std::shared_ptr<IBuiltModel>|* 非空指针：成功。 * 空指针：失败。|
