# MLImageSegmentationAnalyzer

|Class Info|
|:----------------------------------------------------------------------|
|MLImageSegmentationAnalyzer 图像分割检测器：用于获取图片中图像分割信息（MLImageSegmentation)。|

|Qualifier and Type|Method Name and Description|
|:---------------------|:-----------------------------------------------------------------------------------------------------------|
|MLImageSegmentation \*|[analyseFrame:](#section1726413212314) 调用同步方式对采集的图像进行图像分割。|

#### asyncAnalyseFrame:addOnSuccessListener:addOnFailureListener:

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (void)asyncAnalyseFrame:(MLFrame \*)frame addOnSuccessListener:(void (\^)(MLImageSegmentation \*imagesegmentation))successHandler addOnFailureListener:(void (\^)(NSInteger errCode, NSString \*errMsg))failureHandler 对提供的图像进行图像分割，异步调用方式。|

Parameters  

|Name|Description|
|:-------------|:-----------------------|
|frame|待检测图像。|
|successHandler|成功回调的block，可进行成功回调的操作成功。|
|failureHandler|失败回调的block，可进行失败回调的操作。|

Sample code：

```
// 创建使用默认配置的图像分割器。
MLImageSegmentationAnalyzer *analyzer = [MLImageSegmentationAnalyzer sharedInstance];
// 通过bitmap创建MLFrame,建议图片尺寸不小于224*224。
MLFrame *frame = [[MLFrame alloc] initWithImage:image];
[analyzer asyncAnalyseFrame:frame addOnSuccessListener:^(MLImageSegmentation * _Nonnull imagesegmentation) {
    // 对检测结果进行处理。

} addOnFailureListener:^(NSInteger errCode, NSString *errMsg) {
    // 检测失败。

}];
```
