# SetFloatList

## 接口定义

```screen
bool SetFloatList(const std::vector<float>& val);
```

## 功能介绍

设置指定模板类型的参数值。

## 参数

|名称|输入/输出|类型|描述|
|:--|:----|:------------------------|:---|
|val|输入|const std::vector<float>&|属性值。|

## 返回

|类型|描述|
|:---|:-------------------------|
|bool|* true：设置成功。 * false：设置失败。|
