# MLImageClassification

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.classification.MLImageClassification 表示由图像分类器（MLImageClassificationAnalyzer）识别出的图像类别。包含三种属性： * 类别唯一id。 * 类别名称。 * 类别的置信度。|
