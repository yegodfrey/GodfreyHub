# SetPaddingPara(uint32_t batchIndex, AippPaddingPara paddingPara)

## 接口定义

```screen
AIStatus SetPaddingPara(uint32_t batchIndex, AippPaddingPara paddingPara);
```

## 功能介绍

设置AIPP Padding图片补边参数，为特定下标的batch设置Padding参数。

## 参数

|名称|类型|描述|
|:----------|:---------------------------------------------------------------------------------------------------------------|:-------------------------------------|
|batchIndex|uint32_t|batch下标，标识为第几个batch设置Padding参数，取值需>=0。|
|paddingPara|[AippPaddingPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aipppaddingpara-0000001283790237)|Padding图片补边参数。|

## 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
