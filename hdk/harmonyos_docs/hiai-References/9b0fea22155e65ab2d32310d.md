# Overview

此包为文档识别组件，可用于从文档图片中，识别出带段落格式的文本信息。  
此包提供了文档检测的核心API，包含以下类：

* 属性设置类 MLDocumentSetting：提供设置检测器参数的API。
* 文档信息类 MLDocument：提供从检测结果获取文档信息的API。
* 检测器类 MLDocumentAnalyzer：提供创建检测器及执行文档检测的API。
