# Overview

此包提供了实时语音转写SDK，开发者集成此SDK，即可获取华为ML Kit提供的实时语音转写能力，开发丰富多彩的语音识别应用。具体使用方法可参见：[实时语音转写开发步骤](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/real-time-transcription-harmonyos-0000001204197358#section1538393817134)。

## Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLSpeechRealTimeTranscription.LanguageCallback](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsprealtralan-harmonyos-0000001204355384)|支持的语种查询结果回调。|
|[MLSpeechRealTimeTranscriptionListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspereatimetralis-harmonyos-0000001249235331)|实时语音转写监听器，通过该监听器获取到转写结果和错误码。通过[setRealTimeTranscriptionListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsperetimetra-harmonyos-0000001204518822#section10867151145417)(MLSpeechRealTimeTranscriptionListener)设置监听。|
