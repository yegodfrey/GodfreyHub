# OnRunDone

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[OnProcessDone](https://developer.huawei.com/consumer/cn/doc/hiai-References/onprocessdone-0000001052809455)替代。

## 接口定义

```screen
virtual void OnRunDone(const Context& context, Status result, std::vector<std::shared_ptr<INDTensorBuffer>>& outputs) = 0;
```

## 功能介绍

OnRunDone回调虚函数。

## 参数

|名称|类型|描述|
|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------|:------------|
|context|const Context &|用户自定义可扩展上下文。|
|result|Status|推理结果。|
|outputs|std::vector<std::shared_ptr<[INDTensorBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/createndtensorbuffer-0000001092056038)>>&|推理后的输出Tensor。|
