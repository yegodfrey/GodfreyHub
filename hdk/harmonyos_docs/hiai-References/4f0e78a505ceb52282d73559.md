# MemBufferDestroy

#### 接口定义

```
void MemBufferDestroy(MemBuffer* membuf);
```

#### 功能介绍

注销MemBuffer内存，通过上述MemBuffer申请的内存最终都需要由此接口进行释放。  

#### 参数

|名称|类型|描述|
|:-----|:----------|:--------------|
|membuf|MemBuffer\*|创建的MemBuffer内存。|
