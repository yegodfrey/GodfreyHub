# GetSubgraph

#### 函数功能

根据子图名称获取算子对应的子图。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150658.64485437271957429393924768768373:50001231000000:2800:D652E2DA0F18D0437FFF9B2BEBAC1E906EFE87B33454A30DCAEA61E742A6864F.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
Graph GetSubgraph(const std::string &name) const;
Graph GetSubgraph(const char_t *name) const;
```

#### 参数说明

|参数名|输入/输出|描述|
|:---|:----|:----|
|name|输入|子图名称。|

#### 返回值

Graph对象。  

#### 异常处理

无

无
