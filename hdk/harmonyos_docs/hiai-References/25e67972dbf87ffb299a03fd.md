# HiAI_SingleOpBuffer_GetData

#### 接口定义

```
void* HiAI_SingleOpBuffer_GetData(const HiAI_SingleOpBuffer* buffer);
```

#### 功能介绍

用于获取指定HiAI_SingleOpBuffer对象的内存地址。  

#### 参数

|名称|类型|描述|
|:-----|:--------------------------|:-------------------------------------------|
|buffer|const HiAI_SingleOpBuffer\*|指向HiAI_SingleOpBuffer对象的指针。该值不能为空指针，否则返回空指针。|

#### 返回

|类型|描述|
|:-----|:-----------|
|void\*|Buffer的内存地址。|
