## JsonObject对象的数据结构定义

1. 表格识别的结果是一个JsonObject对象，该JsonObject对象的数据结构格式如下：

   ```codeblock
   {
     "retCode": 0,
     "tableContent": {
         "tableCount": 1,
         "tables": [
         {
             "tableID": 1,
             
             
             "tableBody": [
              {
                   "startRow": 1,
                   "endRow": 1,
                   "startCol": 1,
                   "endCol": 3,
                   "cellCoordinate": {
                       "topLeft_x": 111.0,
                       "topLeft_y": 112.0,
                       "topRight_x": 121.0,
                       "topRight_y": 122.0,
                       "bottomLeft_x": 131.0,
                       "bottomLeft_y": 132.0,
                       "bottomRight_x": 141.0,
                       "bottomRight_y": 142.0
                     },
                     "textInfo": "1,1-6"
                },
             ...
           ]
         }
       ]
     }
   }
   ```

2. JsonObject对象中的字段说明：

   |字段名|字段类型|字段说明|
   |:-------------|:---------|:---------------------|
   |retCode|int32|表格识别返回码 * 0：成功 * -1：失败|
   |tableContent|JsonObject|表格识别的结果|
   |tableCount|int32|检测到的表格个数，目前只支持一个表格|
   |tables|JsonArray|检测到的所有表格的信息|
   |tableID|int32|表格ID|
   |tableBody|JsonArray|表格的信息|
   |startRow|int32|单元格的开始行|
   |endRow|int32|单元格的结束行|
   |startCol|int32|单元格的开始列|
   |endCol|int32|单元格的结束列|
   |cellCoordinate|JsonObject|单元格的位置信息|
   |topLeft_x|double|单元格的左上角点的横坐标|
   |topLeft_y|double|单元格的左上角点的纵坐标|
   |topRight_x|double|单元格的右上角点的横坐标|
   |topRight_y|double|单元格的右上角点的纵坐标|
   |bottomLeft_x|double|单元格的左下角点的横坐标|
   |bottomLeft_y|double|单元格的左下角点的纵坐标|
   |bottomRight_x|double|单元格的右下角点的横坐标|
   |bottomRight_y|double|单元格的右下角点的纵坐标|
   |textInfo|String|单元格内的文本信息|
