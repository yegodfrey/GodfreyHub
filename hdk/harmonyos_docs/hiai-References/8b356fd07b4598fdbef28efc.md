# SaveToBuffer

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150635.74983489817488862163525360217535:50001231000000:2800:76AB8A0F795F5FEFA01DF344BD6C92EE681146E49213417641BB6C57EB50EA7C.png)  
此接口从DDK 5.0.1.0版本起废弃。  

#### 接口定义

```
virtual Status SaveToBuffer(std::shared_ptr<IBuffer>& buffer) const = 0;
```

#### 功能介绍

返回保存模型的buffer，内存由libhiai.so释放。  

#### 参数

|名称|类型|描述|
|:-----|:------------------------------------------------------------------------------------------------------------------------------|:-----------|
|buffer|std::shared_ptr\<[IBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/createlocalbuffer-0000001139126323)\>\&|保存模型的buffer。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
