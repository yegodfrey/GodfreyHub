# 错误码

|错误码|值|描述|解决方法|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:-|:----------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
|[INNER](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section19934251154718)|2|* 模型未正确初始化。 * 输入数据未使用小字节序。 * 输入数据未设置为Direct ByteBuffer。 * 加载模型文件失败。|* 推理器状态不对，检查之前是否有异常退出。 * 将ByteBuffer设置为小字节序byteBuffer.order(ByteOrder.nativeOrder())。 * 创建ByteBuffer的时候调用ByteBuffer.allocateDirect接口。 * 检查模型文件的路径是否正确。|
|[INACTIVE](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section3521439194710)|3|模型文件不正确或不存在。|* 模型文件不存在。 * 模型文件加载失败，检查进行转换时的模型参数是否正确。 * 推理器版本不匹配，升级sdk。|
|[INACTIVE](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section3521439194710)|3|模型输入或输出的参数为空。|检查模型的输入或输出的参数是否正确设置。|
|[INACTIVE](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section3521439194710)|3|不支持的数据类型。|检查设置的数据类型是否正确。|
|[ILLEGAL_PARAMETER](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section17921153094717)|5|* 模型输入参数的索引设置不正确。 * 实际输入参数的个数与模型要求输入参数的个数不匹配。 * 推理对象的入参字节长度与模型要求的输入长度不匹配。 * 推理结果与设置的输出参数的长度不匹配。|* 检查模型输入参数索引值是否超过了模型输入参数个数。 * 检查模型输入参数与要求输入的个数是否匹配。 * 检查入参与原始模型的长度是否正确匹配。 * 模型推理结果与设置的模型输出长度是否匹配。|

若上述方式无法解决，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。
