# RunAsync

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[Process](https://developer.huawei.com/consumer/cn/doc/hiai-References/process-0000001051809424)替代。

## 接口定义

```screen
virtual Status RunAsync(const Context& context, const std::vector<std::shared_ptr<INDTensorBuffer>>& inputs, std::vector<std::shared_ptr<INDTensorBuffer>>& outputs, int32_t timeout) = 0;
```

## 功能介绍

模型异步推理。

## 参数

|名称|类型|描述|
|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------|
|context|const [Context](https://developer.huawei.com/consumer/cn/doc/hiai-References/getvalue-0000001139140571)&|模型运行上下文，可设置推理标志符。|
|inputs|const std::vector<std::shared_ptr<[INDTensorBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/createndtensorbuffer-0000001092056038)>>&|模型输入信息及数据。|
|outputs|std::vector<std::shared_ptr<[INDTensorBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/createndtensorbuffer-0000001092056038)>>&|模型输出信息及数据。|
|timeout|int32_t|推理的超时时间（单位：毫秒），建议大于1000ms。若推理超时，则回调返回失败。 > 注意 > 多次调用下发时，推理时间会进行累加，建议超时根据单个模型执行时间预估设置。|

## 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
