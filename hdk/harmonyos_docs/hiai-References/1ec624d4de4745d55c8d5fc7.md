# HiAI_SingleOpExecutor_Init

## 接口定义

```screen
HIAI_Status HiAI_SingleOpExecutor_Init(HiAI_SingleOpExecutor* executor, void* workspace, size_t workspaceSize);
```

## 功能介绍

用于加载HiAI_SingleOpExecutor。在调用该接口之前，需要申请执行器所需的工作空间内存。

## 参数

|名称|类型|描述|
|:------------|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|executor|HiAI_SingleOpExecutor*|指向HiAI_SingleOpExecutor对象的指针。该值不能为空指针，否则返回错误码。|
|workspace|void*|工作空间地址。当workspaceSize不为0时，该值必须为HiAI_SingleOpBuffer中的内存地址，否则返回错误码。|
|workspaceSize|size_t|提供的workspace的字节大小。该值必须大于等于[HiAI_SingleOpExecutor_GetWorkSpaceSize](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-getworkspacesize-0000001934134213)获取的所需工作空间大小，否则返回错误码。|

## 返回

|类型|描述|
|:----------|:---------------------------------------------|
|HIAI_Status|函数执行的结果状态。执行成功返回HIAI_SUCCESS，失败返回HIAI_FAILURE。|
