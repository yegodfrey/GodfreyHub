# GetOpsTypeList

#### 函数功能

获取系统支持的所有算子类型列表。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150648.10417201699366257734656860378762:50001231000000:2800:6581AEA254B7C98050300CB42D602E3E36AEE513B3EE1995573D0E5419C1A9A3.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
static graphStatus GetOpsTypeList(std::vector<std::string> &all_ops);
static graphStatus GetOpsTypeList(std::vector<AscendString> &all_ops);
```

#### 参数说明

|参数名|输入/输出|描述|
|:------|:----|:------|
|all_ops|输出|算子类型列表。|

#### 返回值

|类型|描述|
|:----------|:-----------------------------|
|graphStatus|* SUCCESS：执行成功。 * FAILED：执行失败。|

#### 约束说明

无
