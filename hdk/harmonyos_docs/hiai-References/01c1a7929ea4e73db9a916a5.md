#### longRecognize(android.net.Uri uri, MLRemoteAftSetting setting)

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String longRecognize(android.net.Uri uri, [MLRemoteAftSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlremoteaftsetting-0000001051055392) setting) 云侧长语音文件转写。|

Parameters  

|Name|Description|
|:------|:-------------------------------------------------|
|uri|音频文件URI，仅支持本地音频。 支持"content://"和"file://"开头的URI路径。|
|setting|云侧语音转写配置。|

Returns  

|Type|Description|
|:-----|:--------------|
|String|taskId语音转写任务ID。|

Sample code：

```
MLRemoteAftEngine engine = MLRemoteAftEngine.getInstance();
// 引擎初始化，传入当前context。
engine.init(this);
MLRemoteAftSetting setting = new MLRemoteAftSetting.Factory()
.setLanguageCode("zh")
.enablePunctuation(true)
.enableWordTimeOffset(true)
.enableSentenceTimeOffset(true)
.create();
// 将侦听器回调（aftListener）传入音频文件转写引擎中。
engine.setAftListener(aftListener);
// 将音频资源传入音频文件转写引擎进行长语音转写。
engine.longRecognize(uri, setting);
```

#### shortRecognize(android.net.Uri uri, MLRemoteAftSetting setting)

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String shortRecognize(android.net.Uri uri, [MLRemoteAftSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlremoteaftsetting-0000001051055392) setting) 云侧短语音文件转写。|

Parameters  

|Name|Description|
|:------|:---------------------------------------------------|
|uri|短语音文件URI，仅支持本地音频。 支持"content://"和 "file://"开头的URI路径。|
|setting|云侧语音转写配置。|

Returns  

|Type|Description|
|:-----|:--------------|
|String|taskId语音转写任务ID。|

Sample code：

```
MLRemoteAftEngine engine = MLRemoteAftEngine.getInstance();
// 引擎初始化，传入当前context。
engine.init(this);
MLRemoteAftSetting setting = new MLRemoteAftSetting.Factory()
//设置转写语言编码
.setLanguageCode("zh")
// 设置是否输出句子出现在音频文件中的时间偏移值,默认为false。
// true: 除返回整个音频的文字转写结果外,连带输出句子在音频中的时间偏移信息。
// false: 仅返回整个音频的文字转写结果。
 .enableSentenceTimeOffset(true)
// 设置是否在转写输出的文本中自动增加标点符号,默认为false。
// true：转写结果文字中自动添加标点符号。
// false：转写结果文字中不自动添加标点符号。
 .enablePunctuation(true)
.create();
// 将侦听器回调（aftListener）传入音频文件转写引擎中。
engine.setAftListener(aftListener);
// 将音频资源传入音频文件转写引擎进行短语音转写。
engine.shortRecognize(uri, setting);
```
