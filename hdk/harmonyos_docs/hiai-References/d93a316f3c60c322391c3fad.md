# SetAttr

## 接口定义

```screen
GraphErrCodeStatus SetAttr(const string& name, const AttrValue& value);
```

## 功能介绍

设置属性值。

## 参数

|名称|输入/输出|类型|描述|
|:----|:----|:---------------|:----|
|name|输入|const string&|属性名称。|
|value|输入|const AttrValue&|属性值。|

## 返回

|类型|描述|
|:-----------------|:-----------------------------------|
|GraphErrCodeStatus|成功返回GRAPH_SUCCESS，否则，返回GRAPH_FAILED。|
