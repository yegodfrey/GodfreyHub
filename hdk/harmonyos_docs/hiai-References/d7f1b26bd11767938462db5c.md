# CreateModelManager

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150627.40352609778395379624318302692374:50001231000000:2800:262EBA6DBE7340D2ED6344C938A2004A085744BD9214B792B8F7B28A03FE9A3B.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[Init](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001052570723)替代。  

#### 接口定义

```
HIAI_MM_API_EXPORT std::shared_ptr<IModelManager> CreateModelManager();
```

#### 功能介绍

创建模型管理实例指针。  

#### 返回

|类型|描述|
|:-------------------------------|:-----------------------|
|std::shared_ptr\<IModelManager\>|* 非空指针：创建成功。 * 空指针：创建失败。|
