# SetResizePara(AippResizePara resizePara)

## 接口定义

```screen
AIStatus SetResizePara(AippResizePara resizePara);
```

## 功能介绍

设置AIPP Resize图片缩放参数，为所有的batch设置相同的Resize参数。

## 参数

|名称|类型|描述|
|:---------|:-------------------------------------------------------------------------------------------------------------|:------------|
|resizePara|[AippResizePara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippresizepara-0000001245217314)|Resize图片缩放参数。|

## 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
