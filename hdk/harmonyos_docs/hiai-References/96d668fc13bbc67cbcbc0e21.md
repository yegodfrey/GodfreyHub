# ImageSegmentation

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hiai.vision.image.segmentation.ImageSegmentation 本接口可以对输入图像中包含人像的部分进行人像分割检测，分割结果表现为人像和背景区分呈现。 * 图片人像分割：人像区域为白色，背景为黑色。可以利用其进行图像前景背景替换和背景虚化等美化。 * 图像语义分割：对拍照图像进行像素级的识别和分割，从而获得图像中物体的类别信息以及精确位置信息。 * 视频人像分割：支持实时视频流（如手机Camera）的实时处理，开发者将实时视频流的每一帧图像传输到HiAiEngine，算法对图中的人像进行分割，并将字节数组的掩码结果，返回给用户。|
