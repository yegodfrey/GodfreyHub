# Ovreview

此包提供了同声传译SDK，开发者集成此SDK，即可获取华为ML Kit提供的同声传译识别能力，开发丰富多彩的同声传译应用。具体使用方法可参见：同声传译开发步骤。  

#### Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLSimultaneousInterpretationListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-mlsimlistener-0000001307109497)|当识别相关事件发生后，使用该接口从[MLSimultaneousInterpretationListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-mlsimlistener-0000001307109497)接收数据和事件通知。|

#### Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------|
|[MLSimultaneousInterpretationConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-constants-0000001259589384)|同声传译服务配置常量定义。|
|[MLSimultaneousInterpretationRecognizer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdk-si-recognizer-0000001307429561)|同传识别器。通过startRecognizing开始收听识别语音，开始前需要先设置监听器setMLSimultaneousInterpretationListener。|
|[MLSimultaneousInterpretationConfig](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/si-class-config-0000001318354685)|同声传译识别服务配置器。|
|[MLSimultaneousInterpretationConfig.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/si-class-configfactory-0000001318035605)|同声传译识别服务配置器工厂。|
