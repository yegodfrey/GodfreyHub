# GetDynamicInputNum

#### 函数功能

获取算子的动态Input的实际个数。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150655.87327980249427576539240688159418:50001231000000:2800:B49D7B77FC87CD41AEB78063CDDC8D0B492674E666028046B41A7AAB5FC283F7.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
int32_t GetDynamicInputNum(const std::string &name) const;
int32_t GetDynamicInputNum(const char_t *name) const;
```

#### 参数说明

|参数名|输入/输出|描述|
|:---|:----|:-----------|
|name|输入|算子的动态Input名。|

#### 返回值

|类型|描述|
|:--|:----------------------------------------|
|int|实际动态Input的个数。 当name非法，或者算子无动态Input时，返回-1。|

#### 约束说明

无
