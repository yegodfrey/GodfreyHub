# MLDocumentSetting

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.document.MLDocumentSetting 文档检测器设置类：用于设置文档检测器（[MLDocumentAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mldocumentanalyzer-0000001050167474)）的属性。 检测器属性包括： * 预置的语种，正确地预置检测器语种，可以使检测更快速更准确。 * 是否校验证书指纹，设置为true后只允许能通过校验的已注册应用访问文档检测的云端API接口。 * 文本行边界返回格式，可设置为NGON或者ARC。NGON：返回四边形行边界的四个顶点坐标；ARC：返回文本行文字排列为弧形的多边形边界的顶点，最多可返回多达72个顶点的坐标。|
