# ModelDeviceConfig

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃。

|Struct Info|
|:-----------------------------------|
|struct ModelDeviceConfig 模型运行设备设置策略。|

## Public Attribute Summary

|Qualifier and Type|Field and Description|
|:--------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|[DeviceConfigMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/deviceconfigmode-0000001162952374)|deviceConfigMode 控制整体异构设置策略。具体请参见[DeviceConfigMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/deviceconfigmode-0000001162952374)。|
|[FallBackMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/fallbackmode-0000001163112320)|fallBackMode 当用户设定模型级运行设备/算子级运行设备无法满足时，是否允许按自动异构策略运行于其他设备，默认值ENABLE，表示允许。|
|vector<[ExecuteDevice](https://developer.huawei.com/consumer/cn/doc/hiai-References/executedevice-0000001208592331)>|modelDeviceOrder 模型级指定运行设备的优先级列表，当高优先级设备能够支持模型整体运行需要时，则不再继续使用低优先级设备。 例如：当设置NPU设备优先级最高时，则优先使用NPU侧的设备能力(包含CPU ROM)，否则会使用DDK侧设备能力（CPU APP等）。|
|map<string, vector<[ExecuteDevice](https://developer.huawei.com/consumer/cn/doc/hiai-References/executedevice-0000001208592331)>>|opDeviceOrder 算子级指定运行设备的优先级列表，系统会按算子配置的设备异构。|
|[DeviceMemoryReusePlan](https://developer.huawei.com/consumer/cn/doc/hiai-References/devicememoryreuseplan-0000001280980078)|deviceMemoryReusePlan 设备内存重用计划。默认值为UNSET，表示不设置。|
