# Overview

提供文字图像超分辨率SDK，包含机器学习文字图像超分辨率服务类和接口。具体使用方法可参见：[文字图像超分辨率开发步骤](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/text-image-super-resolution-0000001055442768#section1538393817134)。  

#### Class Summary

|Class|Description|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLTextImageSuperResolutionAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mltextimagesuperresolutionanalyzer-0000001054651947)|文字图像超分分析器，通过调用asyncAnalyseFrame()接口进行文字图像超分。文字图像超分分析器使用工厂模式，通过MLTextSuperResolutionAnalyzerFactory.getInstance().getTextSuperResolutionAnalyzer()方式创建。|
|[MLTextImageSuperResolutionAnalyzerFactory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mltextimagesuperesolutionanalyzerfactory-0000001054811946)|文字图像超分工厂类，用于创建文字图像超分分析器。|
|[MLTextImageSuperResolution](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mltextimagesuperresolutionresult-0000001054331970)|文字图像超分结果类，包含超分后的图片信息。|
