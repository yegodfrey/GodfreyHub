# GetInputDims

#### 接口定义

```
AIStatus GetInputDims(std::vector<TensorDimension>& inputDims) const;
```

#### 功能介绍

获取模型输入Shape。  

#### 参数

|名称|类型|描述|
|:--------|:-------------------------------|:----------------|
|inputDims|std::vector\<TensorDimension\>\&|输入Tensor的Shape信息。|

#### 返回

|类型|描述|
|:-------|:-----------------------------|
|AIStatus|* AI_SUCCESS：获取成功。 * 其他值：获取失败。|
