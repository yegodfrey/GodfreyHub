# HiAI_SingleOpTensor_GetTensorDesc

## 接口定义

```screen
HiAI_SingleOpTensorDesc* HiAI_SingleOpTensor_GetTensorDesc(const HiAI_SingleOpTensor* tensor);
```

## 功能介绍

用于获取指定HiAI_SingleOpTensor对象的HiAI_SingleOpTensorDesc。

## 参数

|名称|类型|描述|
|:-----|:-------------------------|:-------------------------------------------|
|tensor|const HiAI_SingleOpTensor*|指向HiAI_SingleOpTensor对象的指针。该值不能为空指针，否则返回空指针。|

## 返回

|类型|描述|
|:-----------------------|:------------------------------|
|HiAI_SingleOpTensorDesc*|指向HiAI_SingleOpTensorDesc对象的指针。|
