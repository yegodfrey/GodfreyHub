# CopyFrom

## 接口定义

```screen
static void CopyFrom(const std::uint8_t* data, std::size_t bufferSize, Buffer& buffer);
```

## 功能介绍

根据data中指针所指向的地址，拷贝bufferSize大小的数据，并将数据地址存放到Buffer中。

## 参数

|名称|输入/输出|类型|描述|
|:---------|:----|:------------------|:----------|
|data|输入|const std::uint8_t*|存放要拷贝的数据指针。|
|bufferSize|输入|size_t|拷贝数据的大小。|
|buffer|输入|Buffer&|存放数据地址|

## 返回

|类型|描述|
|:---|:-----------------|
|void|用于存放拷贝数据的Buffer对象。|
