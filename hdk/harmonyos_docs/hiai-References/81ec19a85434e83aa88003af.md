# Overview

|API|描述|
|:-------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------|
|[模型管家类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getversion-0000001051650680)|模型加载、推理、卸载、模型信息获取、兼容性检查接口。该类接口在HiAiModelManagerService.h中定义。|
|[模型编译类](https://developer.huawei.com/consumer/cn/doc/hiai-References/buildmodel-0000001053089431)|模型编译接口。该类接口在AiModelBuilder.h中定义。|
|[模型描述类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getname-0000001052969437)|模型名称、内存、模型框架接口。该类接口在HiAiModelManagerService.h中定义。|
|[模型Tensor创建类](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001051490692)|模型Tensor创建接口。该类接口在AippTensor.h、AiTensor.h中定义。|
|[AIPP对外接口类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getmodelaipp-para1-0000001052889434)|AIPP接口。该类接口在HiAiAippPara.h中定义。|
|[用户自定义上下文类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getpara-0000001052490757)|用户自定义上下文增删改查接口。该类接口在HiAiModelManagerType.h中定义。|
|[异步回调注册类](https://developer.huawei.com/consumer/cn/doc/hiai-References/onprocessdone-0000001052809455)|异步回调接口。该类接口在HiAiModelManagerService.h中定义。|
|[Tensor尺寸描述结构类](https://developer.huawei.com/consumer/cn/doc/hiai-References/setnumber-0000001052249428)|Tensor相关Setter和Getter接口。该类接口在AiTensor.h中定义。|
|[MemBuffer通用CANN内存buffer类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getmembufferdata-0000001052689469)|MemBuffer内存地址和大小接口。该类接口在MemBuffer.h中定义。|
|[枚举类](https://developer.huawei.com/consumer/cn/doc/hiai-References/frequency-0000001052889444)|枚举值定义。该类接口在hiai_base_types_cpt.h、HiAiModelBuilderType.h中定义。|
|[结构体类](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippchannelswappara-0000001245377102)|结构体类定义。该类接口在HiAiAippPara.h、HiAiModelBuilderType.h中定义。|

> 说明
>
> * 模型管家是线程非安全的，不支持多线程共享同一个模型管家，每个线程可以创建各自的模型管家实例。
> * 一个APP最多创建256个模型管家实例。
> * 一个模型管家实例只能调用一次Load，并且同步模式最多加载63个模型，异步模式最多加载31个模型。
> * 异步推理场景下，模型推理接口的任务队列最大长度为512。
