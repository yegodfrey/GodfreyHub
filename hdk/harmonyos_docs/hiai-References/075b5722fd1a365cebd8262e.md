# SetAttr

## 接口定义

```screen
Operator& SetAttr(const string& name, AttrValue&& attrValue);
```

## 功能介绍

设置算子属性的属性值。

## 参数

|名称|输入/输出|类型|描述|
|:--------|:----|:------------|:-------|
|name|输入|const string&|属性名称。|
|attrValue|输入|AttrValue&&|需设置的属性值。|

## 返回

|类型|描述|
|:--------|:------|
|Operator&|算子对象本身。|
