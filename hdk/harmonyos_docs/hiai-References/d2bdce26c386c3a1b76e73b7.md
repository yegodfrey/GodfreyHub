# Overview

此包为动作活体检测组件，可用于实时捕捉相机预览流中的人脸及动作，并判断是否为活体。

此包提供了动作活体检测的核心API，包含以下类：

* 动作活体检测类MLInteractiveLivenessCapture：提供动作活体检测实例。
* 检测回调接口MLInteractiveLivenessCapture.Callback：提供检测完成以后，结果回调API。
* 检测结果类MLInteractiveLivenessCaptureResult：回调返回的检测结果信息类。
* 动作活体检测异常类MLInteractiveLivenessCaptureError：包含检测错误时的错误码。
