# MLTtsConfig

|Class Info|
|:------------------------------------------------------|
|com.huawei.hms.mlsdk.tts.MLTtsConfig 通过此配置类来对TTS引擎进行配置。|

Sample code：

```
// 1.创建新的配置项，不是必须设置，不设置则使用默认值
MLTtsConfig mlTtsConfig = new MLTtsConfig()
    .setVolume(1.5f)
    .setSpeed(1.5f)
    .setLanguage(MLTtsConstants.TTS_ZH_HANS)
    .setPerson(MLTtsConstants.TTS_SPEAKER_FEMALE_ZH)
    .setSynthesizeMode(MLTtsConstants.TTS_ONLINE_MODE);
 
// 2.查看自定义配置的值；
    mlTtsConfig.getLanguage();//获取自定义语言，返回null表示未自定义
    mlTtsConfig.getPerson();//获取发音人名称，返回null表示未自定义
    mlTtsConfig.getSpeed();//获取当前自定义语速，返回0表示未自定义
    mlTtsConfig.getVolume();//获取当前自定义音量，返回0表示未自定义
    mlTtsConfig.getSynthesizeMode();//获取语音合成模式,返回null表示未自定义
 
// 3.更新配置：
    //a.未定义的配置，则继承当前引擎的上一次配置，若之前未配置过，则使用默认配置；
    //b.自定义的配置，使用当前定义的配置；
 
// 4.更新方式：
// a.初始化时设置：
    MLTtsEngine mlTtsEngine =  = new MLTtsEngine(mlTtsConfig);
// b.过程中更新；
    mlTtsEngine.updateConfig(mlTtsConfig);
```
