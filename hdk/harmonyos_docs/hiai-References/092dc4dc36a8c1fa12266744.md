# ParamType

## 函数功能

定义算子参数类型。

## 函数原型

```cpp
OpParamDef &ParamType(Option param_type);
```

## 参数说明

|参数|输入/输出|说明|
|:---------|:----|:----------------------------------------|
|param_type|输入|参数类型，Option取值为：OPTIONAL（可选）、REQUIRED（必选）。|

## 返回值

[OpParamDef](https://developer.huawei.com/consumer/cn/doc/hiai-References/cannkit-opparamdef-0000002158595449)算子定义。

## 约束说明

无
