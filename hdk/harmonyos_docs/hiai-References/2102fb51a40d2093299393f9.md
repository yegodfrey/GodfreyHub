# TextDetector

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hiai.vision.text.TextDetector 检测并识别给定图片中的文字信息。目前支持手机截屏简单背景的文字提取，手机截屏复杂背景中的文字提取，以及聚焦拍照场景图片中的文字提取，其中，聚焦拍照场景着重为文档翻拍，胶片翻拍，以及广告牌、路牌、商品包装翻拍等自然光场景。|

#### detect

|Method|
|:------------------------------------------------------------------------------------------------------|
|int detect(VisionImage image, Text text, final VisionCallback\<Text\> visionCallBack) 文本检测识别，返回文本Text类。|

Parameters  

|Name|Description|
|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
|image|图片数据，Frame支持通过Bitmap或文件路径等形式完成图片数据的封装。 其中：手机截屏OCR API目前支持的图片尺寸为：width小于1440px，height小于15210px。 调用聚焦拍照OCR API的图片建议尺寸为：分辨率大于720p，长边短边比小于2:1。|
|text|文本结果，详细参数参考Text类结果说明。|
|visionCallBack|异步处理时，用于返回结果的callback函数。|

Return  

|Type|Description|
|:---|:--------------------|
|int|返回结果表示此次文字检测识别成功或者异常。|

程序正常终止并得到返回结果，其中结果返回为0。 结果码含义参考[Return Codes](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/return-codes-0000001053441989)。
