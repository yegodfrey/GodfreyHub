# SetShape

## 接口定义

```screen
void SetShape(const Shape& shape);
```

## 功能介绍

设置TensorDesc的shape。

## 参数

|名称|输入/输出|类型|描述|
|:----|:----|:-----------|:----------------------|
|shape|输入|const Shape&|需向TensorDesc设置的shape对象。|
