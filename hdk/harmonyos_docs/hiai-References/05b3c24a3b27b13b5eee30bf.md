# CardDetector

|Class Info|
|:---------------------------------------------------------------------------------------------------|
|com.huawei.hiai.vision.text.CardDetecor 用户输入银行卡正面正对图片，输出银行卡号。算法实时性高，可在1000ms内返回结果，实际体验更佳，大约在200ms左右。|

#### setCardType

|Method|
|:--------------------------------------------|
|public void setCardType(int cardType) 设置证件类型。|

Parameters  

|Name|Description|
|:-------|:---------------------------------------------------------------------------------|
|cardType|使用setCardType(int cardType)设置识别卡证类型，这里cardType设置为VisionCardConfiguration.BANKCARD。|

卡证类型：  

|Type|Name|Description|
|:---|:------------------------------------|:----------|
|int|VisionCardConfiguration.IDCARD|身份证。|
|int|VisionCardConfiguration.PASSPORT|护照。|
|int|VisionCardConfiguration.DRIVERLICENSE|驾驶证。|
|int|VisionCardConfiguration.CARLICENSE|行驶证。|
|int|VisionCardConfiguration.BANKCARD|银行卡。|
