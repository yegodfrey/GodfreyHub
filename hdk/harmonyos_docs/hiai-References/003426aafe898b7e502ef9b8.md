# operator=

#### 接口定义

```
Buffer& operator=(const Buffer& other);
```

#### 功能介绍

重载"="赋值操作符。  

#### 参数

|名称|输入/输出|类型|描述|
|:----|:----|:-------------|:--------------------|
|other|输入|const Buffer\&|Buffer类型的操作数的const引用。|

#### 返回

|类型|描述|
|:-------|:-----------|
|Buffer\&|Buffer类型的引用。|
