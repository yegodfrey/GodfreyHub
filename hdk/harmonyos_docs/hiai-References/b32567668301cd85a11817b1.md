# LensEngine.PhotographListener

|Interface Info|
|:----------------------------------------------------------------------|
|com.huawei.hms.mlsdk.common.LensEngine.PhotographListener 获得图像数据后的回调接口。|

Sample code:

```
// lenEngine为相机引擎实例，需要先启动
lensEngine.run();
// 执行lensEngine.photograph()相机拍一次照
lensEngine.photograph(new LensEngine.ShutterListener() {
    @Override
    public void clickShutter() {
        // 按下快门时该方法被调用
    }
}, new LensEngine.PhotographListener() {
    @Override
    public void takenPhotograph(byte[] data) {
        // 拍照完成后，该方法被调用
        // data参数及对应相片图像数据，可在这里获取并做进一步处理
    }
});
```
