# HIAI_CreateAiPPTensorFromHandle

#### 接口定义

```
HIAI_TENSOR_API_EXPORT std::shared_ptr<AippTensor> HIAI_CreateAiPPTensorFromHandle(void* nativeHandle, const TensorDimension* dim, AiTensorImage_Format imageFormat = AiTensorImage_INVALID);
```

#### 功能介绍

根据buffer_handle_t，TensorDimension，imageFormat，创建AippTensor。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150644.04939739863806328546934679813738:50001231000000:2800:8FB6A67F4277A948E99BDC83559BD162FF6E673F702225AE66DD6A5A5C462915.png)  
要求NDK不低于r20b，API Level不低于26。  

#### 参数

|名称|类型|描述|
|:----------|:-----------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
|handle|buffer_handle_t\&|buffer_handle_t结构体信息。|
|dim|const TensorDimension\*|输入Tensor的尺寸结构信息。|
|imageFormat|[AiTensorImage_Format](https://developer.huawei.com/consumer/cn/doc/hiai-References/format-0000001051490704)|handle中存储的ImageFormat信息，支持如下格式。 * AiTensorImage_YUV422SP_U8 * AiTensorImage_YUV420SP_U8 * AiTensorImage_YUYV_U8 * AiTensorImage_YUV400_U8|

#### 返回

|类型|描述|
|:----------------------------|:----------------------|
|std::shared_ptr\<AippTensor\>|AippTenso shared_ptr指针。|
