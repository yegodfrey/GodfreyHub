# Overview

ML Kit的图片商品检测API。通过自动识别图片或者相机拍摄中的物品，在线检索第三方应用程序中的类似商品，将结果呈现给用户。例如，在购物类应用中，可以使用扫一扫功能，快速找到其拍摄的商品信息。

## Class Summary

|Class|Description|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------|
|[MLRemoteProductVisionSearchAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlremoteproductvisionsearchanalyzer-0000001050167554)|拍照购检测器：用于在提供的图像中，识别商品信息。拍照购检测器，调用云端API，检测模型在云端运行。|
|[MLRemoteProductVisionSearchAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlremoteproductvisionsearchanalyzers-0000001050169509)|拍照购配置器：用于设置云端拍照购的属性。 云端拍照购的属性包括： * 返回商品数量的最大值。 * 置信度阈值（目前不支持设置，预留）。 * 商品集ID。 * 站点区域。|
