# HiAI_SingleOpTensorDesc_Destroy

## 接口定义

```screen
void HiAI_SingleOpTensorDesc_Destroy(HiAI_SingleOpTensorDesc** tensorDesc);
```

## 功能介绍

用于释放调用HiAI_SingleOpTensorDesc_Create创建的HiAI_SingleOpTensorDesc对象。

## 参数

|名称|类型|描述|
|:---------|:------------------------|:-------------------------------------------------------------|
|tensorDesc|HiAI_SingleOpTensorDesc**|指向HiAI_SingleOpTensorDesc对象的二级指针。tensorDesc和*tensorDesc不能为空指针。|
