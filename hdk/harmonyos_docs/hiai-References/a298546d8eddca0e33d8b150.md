# GetInputTensorDescs

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150630.35752394234987173261864550633992:50001231000000:2800:BEC360C65484D88688F158A2361543FF0565DE369ACABA34D85A9DEC06BFE9DF.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetModelIOTensorDim](https://developer.huawei.com/consumer/cn/doc/hiai-References/getmodel-0000001052969435)替代。  

#### 接口定义

```
virtual std::vector<NDTensorDesc> GetInputTensorDescs() const = 0;
```

#### 功能介绍

查询模型的输入描述，包含维度、数据类型、格式。  

#### 返回

|类型|描述|
|:------------------------------------------------------------------------------------------------------------------------|:-------|
|std::vector\<[NDTensorDesc](https://developer.huawei.com/consumer/cn/doc/hiai-References/ndtensordesc-0000001092063032)\>|模型的输入描述。|
