# MutableTensorDesc

## 接口定义

```screen
TensorDesc& MutableTensorDesc();
```

## 功能介绍

获取当前Tensor的描述符，可修改。

## 返回

|类型|描述|
|:----------|:----------------|
|TensorDesc&|当前Tensor的描述符，可修改。|
