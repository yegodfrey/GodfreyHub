# PoseEstimationDetector

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hiai.vision.image.detector.PoseEstimationDetector 用户输入单张内容为人像的图片，可得到图片中每一个人身体上14个关键点的坐标信息。算法实时性高，可在70ms内返回结果。结果中人体姿态信息包括：头、颈、左右肩、左右肘、左右手腕、左右髋、左右膝、左右脚踝。|
