# ReadBinaryProto(const string path)

#### 接口定义

```
MemBuffer* ReadBinaryProto(const std::string path);
```

#### 功能介绍

从文件读取OM离线模型proto信息。  

#### 参数

|名称|类型|描述|
|:---|:-----------|:------|
|path|const string|模型文件路径。|

#### 返回

|类型|描述|
|:----------|:----------------------------|
|MemBuffer\*|MemBuffer地址，如果为nullptr表示读取失败。|
