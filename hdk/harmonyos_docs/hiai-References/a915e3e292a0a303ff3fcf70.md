# DelInputWithCond

#### 函数功能

根据算子属性，删除算子指定输入边。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150656.22454464261717207359845127030237:50001231000000:2800:B64B77AC7CE5DCF84FE66515E0088EF952EA67C3B724F76AB1CA3B2C3EDC39A3.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
OpRegistrationData &DelInputWithCond(int32_t inputIdx, const std::string &attrName, bool attrValue);
OpRegistrationData &DelInputWithCond(int32_t input_idx, const char_t *attr_name, bool attr_value);
```

#### 参数说明

|参数|输入/输出|说明|
|:--------|:----|:----------|
|inputIdx|输入|需要删除的输入边编号。|
|attrName|输入|属性名字。|
|attrValue|输入|属性的值。|
