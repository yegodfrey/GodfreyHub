# Rotation

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃。

## 接口定义

```screen
virtual int32_t Rotation() const = 0;
```

## 功能介绍

获取输入图像的旋转角度。

## 返回

|类型|描述|
|:------|:-----------|
|int32_t|返回输入图像的旋转角度。|
