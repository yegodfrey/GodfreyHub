# AddOp

## 接口定义

```screen
GraphErrCodeStatus AddOp(ge::Operator& op);
```

## 功能介绍

在Graph中增加算子。

## 参数

|名称|输入/输出|类型|描述|
|:-|:----|:------------|:------------------------------------|
|op|输入|ge::Operator&|添加算子op到Graph中，可以保证op生命周期和Graph生命周期一致。|

## 返回

|类型|描述|
|:-----------------|:------------------------------------------|
|GraphErrCodeStatus|* GRAPH_SUCCESS：操作成功。 * GRAPH_FAILED： 操作失败。|
