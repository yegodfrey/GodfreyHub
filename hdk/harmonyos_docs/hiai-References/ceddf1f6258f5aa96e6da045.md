# OutputMemBufferCreate

#### 接口定义

```
MemBuffer* OutputMemBufferCreate(const int32_t framework, const std::vector<MemBuffer*>& pinputMemBuffer);
```

#### 功能介绍

为在线编译输出模型创建MemBuffer。  

#### 参数

|名称|类型|描述|
|:--------------|:-----------------------------|:---------------|
|framework|const int32_t|模型平台类型。|
|pinputMemBuffer|const vector\<MemBuffer \*\>\&|输入的OM离线模型buffer。|

#### 返回

|类型|描述|
|:----------|:----------------------------|
|MemBuffer\*|MemBuffer地址，如果为nullptr表示创建失败。|
