# MLProductVisionSearchCapture

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlplugin.productvisionsearch.MLProductVisionSearchCapture 拍照购插件检测器：内置相机拍照与图片选择功能，并对获取到的图像检测，识别商品信息。|

**Sample code：**

```screen
// 创建拍照购插件检测器配置
MLProductVisionSearchCaptureConfig config = new MLProductVisionSearchCaptureConfig.Factory()
    .setLargestNumOfReturns(16) // 检测结果最大数量
    .setProductFragment(productFragment) // 可通过继承MLProductVisionSearchCapture.AbstractProductFragment（Fragment）, 实现商品详细信息的展示
    .setProductSetId("productSetId") // 商品集ID（请https://developer.huawei.com/consumer/cn/support/feedback/#/获取配置指导）
    .setRegion(MLProductVisionSearchCaptureConfig.REGION_DR_CHINA) // 站点区域
    .create();
// 创建拍照购插件检测器对象
MLProductVisionSearchCapture capture = MLProductVisionSearchCaptureFactory.getInstance().create(config);
// 启动拍照购插件检测
capture.startCapture(this);
```
