# HiAI_SingleOpOptions_Create

#### 接口定义

```
HiAI_SingleOpOptions* HiAI_SingleOpOptions_Create();
```

#### 功能介绍

创建HiAI_SingleOpOptions对象。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150627.99655052469188128150297126044322:50001231000000:2800:394863FD692A4769DCFA2B50CBBA08075AFA8A36C989A4BB7F7B5D020F20C0C5.png)  
当不再使用HiAI_SingleOpOptions对象时，调用[HiAI_SingleOpOptions_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopoptions-destroy-0000001890414410)销毁，否则会造成内存泄漏。  

#### 返回

|类型|描述|
|:---------------------|:----------------------------------------|
|HiAI_SingleOpOptions\*|指向HiAI_SingleOpOptions对象的指针，如果创建失败则返回空指针。|
