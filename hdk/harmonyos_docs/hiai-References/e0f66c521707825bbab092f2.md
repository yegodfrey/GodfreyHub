# GetParseParamFn

#### 函数功能

获取解析算子属性的函数。  

#### 函数原型

```
ParseParamFunc GetParseParamFn() const
```

#### 参数说明

无  

#### 约束说明

GetParseParamFn接口后续版本将会废弃，请使用[ParseParamsByOperatorFn](https://developer.huawei.com/consumer/cn/doc/hiai-References/cannkit-parseparamsbyoperatorfn-0000002123078170)接口获取算子属性。
