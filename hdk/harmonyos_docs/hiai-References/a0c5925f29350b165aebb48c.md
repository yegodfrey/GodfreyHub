#### setSpeed(float speed)

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [MLTtsConfig](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ttsconfig-harmonyos-0000001248118181) setSpeed(float speed) 设置语速。 说明： * 在中英文场景下生效。 * bee音色的英文场景不支持设置语速。|

Parameters  

|Name|Description|
|:----|:------------------------------------------------------------------------------------------------------|
|speed|语速配置，范围(0, 5\]，1.0表示正常语速, 小于1.0表示降低语速，0.5表示正常语速的一半；大于1.0表示加快语速，比如1.5表示是正常语速的1.5倍；默认为1.0正常语速；不设置默认为 1.0。|

Returns  

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------------|:----------|
|[MLTtsConfig](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ttsconfig-harmonyos-0000001248118181)|设置语速后的配置实例。|
