# Overview

此包提供了实时语音转写SDK，开发者集成此SDK，即可获取华为ML Kit提供的实时语音转写能力，开发丰富多彩的语音识别应用。具体使用方法可参见：[实时语音转写开发步骤](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/real-time-transcription-0000001054964200#section1538393817134)。  

#### Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLSpeechRealTimeTranscription.LanguageCallback](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscription-languagecallback-0000001204518099)|支持的语种查询结果回调。|
|[MLSpeechRealTimeTranscriptionListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscriptionlistener-0000001159518088)|实时语音转写监听器，通过该监听器获取到转写结果和错误码。通过[setRealTimeTranscriptionListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscription-0000001054795529#section10867151145417)(MLSpeechRealTimeTranscriptionListener)设置监听。|

#### Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLSpeechRealTimeTranscription](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscription-0000001054795529)|语音识别器。通过[startRecognizing](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscription-0000001054795529#section1844544185412)([MLSpeechRealTimeTranscriptionConfig](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscriptionconfig-0000001054868899) config)开始收听识别语音，开始前先设置监听器[setRealTimeTranscriptionListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscription-0000001054795529#section10867151145417)(MLSpeechRealTimeTranscriptionListener listener)。|
|[MLSpeechRealTimeTranscriptionConfig](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscriptionconfig-0000001054868899)|实时语音转写配置参数。|
|[MLSpeechRealTimeTranscriptionConfig.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscriptionconfig-builder-0000001055108818)|构造类。|
|[MLSpeechRealTimeTranscriptionConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscriptionconstants-0000001055035448)|实时语音转写服务配置常量。|
|[MLSpeechRealTimeTranscriptionResult](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspeechrealtimetranscriptionresult-0000001055228851)|实时语音转写结果描述类，通过该类获取到实时语音转写结果。|
