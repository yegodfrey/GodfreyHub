# GetData

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/getbuffer-0000001051809428)替代。

## 接口定义

```screen
virtual void* GetData() = 0;
```

## 功能介绍

获取buffer中Data地址。

## 返回

|类型|描述|
|:----|:----|
|void*|数据地址。|
