# HiAI_SingleOpBuffer_GetSize

## 接口定义

```screen
size_t HiAI_SingleOpBuffer_GetSize(const HiAI_SingleOpBuffer* buffer);
```

## 功能介绍

用于获取指定HiAI_SingleOpBuffer对象的字节大小。

## 参数

|名称|类型|描述|
|:-----|:-------------------------|:-----------------------------------------|
|buffer|const HiAI_SingleOpBuffer*|指向HiAI_SingleOpBuffer对象的指针。该值不能为空指针，否则返回0。|

## 返回

|类型|描述|
|:-----|:-----------|
|size_t|Buffer的字节大小。|
