# Overview

ML Kit的图片商品检测API。通过自动识别图片或者相机拍摄中的物品，在线检索第三方应用程序中的类似商品，将结果呈现给用户。例如，在购物类应用中，可以使用扫一扫功能，快速找到其拍摄的商品信息。  

#### Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLProductVisionSearch](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlproductvisionsearch-0000001050169505)|拍照购结果描述，表示图像拍照购识别结果的具体信息，包括： * type：商品类别（参见[拍照购商品类别清单](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230822150311.89723908061492955731803396506307:50001231000000:2800:0103F627A36DF796DBAA40B3CFA19B62B5C5E532BBF9204792F1783A0CF5E359.xlsx?needInitFileName=true)）。 * border：轴对齐矩形边界框，包括left、top、right、bottom 4个值。其中left、top的值构成矩形边界区域的左上顶点坐标，right、bottom的值构成矩形边界区域的右下顶点坐标，目前没有倾斜度。 * productList：商品信息列表，按照置信度降序排序。|
|[MLVisionSearchProduct](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlvisionsearchproduct-0000001050167552)|商品信息描述，包括： * productId：商品ID。 * imageList：商品图片列表。 * productUrl：商品URL。 * customContent：自定义商品信息。|
|[MLVisionSearchProductImage](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/visionsearchproductimage-0000001050169507)|商品图片信息描述，包括： * productId：商品ID。 * imageId：商品图片ID。 * possibility：置信度。|
