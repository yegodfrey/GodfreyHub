# SetInputShape

## 接口定义

```screen
AIStatus SetInputShape(AippInputShape inputShape);
```

## 功能介绍

设置AIPP输入图片尺寸inputShape参数。

## 参数

|名称|类型|描述|
|:---------|:-------------------------------------------------------------------------------------------------------------|:------|
|inputShape|[AippInputShape](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippinputshape-0000001291616705)|输入图片尺寸。|

## 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
