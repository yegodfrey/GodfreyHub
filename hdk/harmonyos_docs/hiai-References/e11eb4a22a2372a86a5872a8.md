# IsValid

## 接口定义

```screen
bool IsValid() const;
```

## 功能介绍

判断模型中Graph对象是否有效，如果Graph对象为空指针，则无效。

## 返回

|类型|描述|
|:---|:------------------------------------|
|bool|Model中Graph对象是否有效，true表示有效，false表示无效。|
