# Overview

MLKit的图片地标检测组件。  
此包提供了地标检测的标准模式，核心API如下：

* MLRemoteLandmark：地标识别的信息描述，表示图像地标识别结果的具体信息。
* MLRemoteLandmarkAnalyzer：地标分析器，用于在提供的图像中，识别地标，调用云端API，分析模型在云端运行。
