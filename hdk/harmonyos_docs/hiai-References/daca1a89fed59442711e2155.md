# 错误码

|错误码|值|描述|解决方法|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:-|:------------|:--------------------------------------------------|
|[INACTIVE](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section3521439194710)|3|下载条件不满足。|检测是否满足download接口传入的MLModelDownloadStrategy实例所设置的条件。|
|[ILLEGAL_PARAMETER](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section17921153094717)|5|传入的离线模型类型不支持。|检查传入的离线模型类型是否正确。|
|[NO_FOUND](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section589113318485)|7|模型还没有下载。|本地模型还未下载，请先下载模型。|
|[DUPLICATE_FOUND](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section14791190323)|8|模型正在下载。|当前模型正在下载中，请等待下载完成。|
|[HASH_MISS](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section376022412472)|18|完整性校验失败。|从服务器下载模型失败，请重试。|

若上述方式无法解决，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。
