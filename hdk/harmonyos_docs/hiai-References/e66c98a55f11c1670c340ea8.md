# MLFaceFeature

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.MLFaceFeature 人脸特征类，包含七种人脸特征： * 左眼睁开的程度。 * 右眼睁开的程度。 * 戴眼镜的可能性。 * 性别的可能性。 * 戴帽子的可能性。 * 有胡子的可能性。 * 年龄。|

#### getAge()

|Method|
|:--------------------------|
|public int getAge() 获取人脸年龄。|

Returns  

|Type|Description|
|:---|:----------------------------------------------------------------------------------------------------------------------------|
|int|返回人脸年龄。如果通过方法MLFaceAnalyzerSetting.Factory.setFeatureType(MLFaceAnalyzerSetting.TYPE_FEATURES)启用了"人脸表情和特征检测"功能，则返回年龄；否则，返回-1。|

#### getLeftEyeOpenProbability()

|Method|
|:----------------------------------------------------|
|public float getLeftEyeOpenProbability() 获取人脸左眼睁开的程度。|

Returns  

|Type|Description|
|:----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|float|返回人脸在图像左侧眼睛睁开的程度，以0.0-1.0表示。未启用该特征检测方法，则返回-1，"人脸表情和特征检测"功能需要通过方法MLFaceAnalyzerSetting.Factory.setFeatureType(MLFaceAnalyzerSetting.TYPE_FEATURES)启用。 注意： 使用视频流前置摄像头时，由于镜像预览，实际返回预览界面右侧眼睛睁开的程度。|
