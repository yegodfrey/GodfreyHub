# MLImageSegmentation

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.imgseg.MLImageSegmentation 表示由图像分割检测器（MLImageSegmentationAnalyzer）图像分割后的各个像素点分类。 对象的属性包括： * 当前图像分割后各个像素点的标志。 * 透明背景人像前景图。 * 人像为白色，背景为黑色的灰度图。 * 切割原图。|

|Bitmap|[original](#section16457155292615) 切割原图。||
