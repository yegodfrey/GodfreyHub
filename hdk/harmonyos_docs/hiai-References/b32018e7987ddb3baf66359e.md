# GetFormat

## 接口定义

```screen
Format GetFormat() const;
```

## 功能介绍

获取TensorDesc所描述的Tensor的format信息。

## 返回

|类型|描述|
|:-----|:-----------------------------|
|Format|TensorDesc所描述的Tensor的format信息。|
