# 错误码

|错误码|值|描述|解决方法|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:-|:-------------------------------|:---------------------------------------------------------------------|
|[ILLEGAL_PARAMETER](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section17921153094717)|5|* 识别的图片或视频流格式不正确。 * 识别的图片分辨率不支持。|* 检查识别的图片分辨率（最小224\*224，最大4096\*4960）。 * 检查图片格式是否为RGBA8888，视频流是否为NV21。|

若上述方式无法解决，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。
