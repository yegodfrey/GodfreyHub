### create

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [MLBcrCaptureConfig](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlbcrcaptureconfig-0000001050169525) create() 创建银行卡检测插件配置器的实例，支持设置银行卡识别期望返回的结果类型。|

**Returns**

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------------------|:------------------|
|[MLBcrCaptureConfig](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlbcrcaptureconfig-0000001050169525)|返回新创建的银行卡检测插件配置器实例。|

**Java sample code：**

```screen
MLBcrCaptureConfig config = new MLBcrCaptureConfig.Factory()
     // 设置银行卡识别期望返回的结果类型。
     // MLBcrCaptureConfig.SIMPLE_RESULT：仅识别卡号、生效期和持卡人（限信用卡）信息。
     // MLBcrCaptureConfig.ALL_RESULT：识别卡号、生效期、持卡人（限信用卡）、发卡行和卡类别等信息。
     .setResultType(MLBcrCaptureConfig.RESULT_SIMPLE)
     // 设置插件页面屏幕方位。
     // MLBcrCaptureConfig.ORIENTATION_AUTO: 自适应模式，由物理感应器决定显示方向。
     // MLBcrCaptureConfig.ORIENTATION_LANDSCAPE: 横屏，显示时宽度大于高度。
     // MLBcrCaptureConfig.ORIENTATION_PORTRAIT: 竖屏，显示时高度大于宽度。
     .setOrientation(MLBcrCaptureConfig.ORIENTATION_AUTO)
     .create();
```
