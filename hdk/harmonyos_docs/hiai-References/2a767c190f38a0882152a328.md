# MLSoundDetectListener

|Interface Info|
|:-------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.sounddect.MLSoundDetectListener 当识别到声音后，使用此回调从MLSoundDetector接收数据和事件通知。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------|
|void|[onSoundFailResult](#section13269469245)(int errCode) 通过回调返回错误码，并根据异常做相应的处理。|
|void|[onSoundSuccessResult](#section97283293276)(Bundle result) 识别成功后会调用该方法。|

#### Public Methods

#### onSoundFailResult(int errCode)

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onSoundFailResult(int errCode) 通过回调返回错误码，并根据异常做相应的处理。接口返回的错误码可以参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsdksounddect-errorcode-0000001058479006)进行处理。|

Parameters  

|Name|Description|
|:------|:----------|
|errCode|错误码。|

#### onSoundSuccessResult(Bundle result)

|Method|
|:-----------------------------------------------------------|
|public void onSoundSuccessResult(Bundle result) 识别成功后会调用该方法。|

Parameters  

|Name|Description|
|:-----|:------------------------------------------------------------------------------------------------------------------------------------------|
|result|识别结果，结果为Bundle，可以通过result.getInt(MLSoundDetector.RESULTS_RECOGNIZED)获取声音类型，获取到的声音类型为int，其为MLSoundDetectConstants中定义的SOUND_EVENT_TYPE_xxx类型。|
