# MLTextAnalyzer

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.text.MLTextAnalyzer 文本分析器：检测图像中的文本信息（MLText）。 文本分析器有两种类型，一种是设备端分析器，即在设备上运行检测模型，返回检测结果；另一种是云端分析器，即调用云端API进行检测，检测模型在云端运行。创建设备端图像分析器方式为MLAnalyzerFactory.getInstance().getLocalTextAnalyzer()和MLAnalyzerFactory.getInstance().getLocalTextAnalyzer(MLLocalTextSetting settings)。前者使用默认配置，后者使用自定义配置。 创建云端图像分析器有两种方式MLAnalyzerFactory.getInstance().getRemoteTextAnalyzer()和MLAnalyzerFactory.getInstance().getRemoteTextAnalyzer(MLRemoteTextSetting settings)。前者使用默认配置，后者使用自定义配置。|

**Sample code:**

```screen
// 本地文本检测示例。
MLTextAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalTextAnalyzer();
// 通过Bitmap创建MLFrame。
MLFrame frame = MLFrame.fromBitmap(bitmap);
// 图像检测。
Task<MLText> task = analyzer.asyncAnalyseFrame(frame);
task.addOnSuccessListener(new OnSuccessListener<MLText>() {
    @Override
    public void onSuccess(MLText text) {
        // 检测成功。
    }
}).addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        // 检测失败。
    }
});
```

```screen
// 云端文本检测示例。
MLTextAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteTextAnalyzer();
// 通过Bitmap创建MLFrame。
MLFrame frame = MLFrame.fromBitmap(bitmap);
// 图像检测。
Task<MLText> task = analyzer.asyncAnalyseFrame(frame);
task.addOnSuccessListener(new OnSuccessListener<MLText>() {
    @Override
    public void onSuccess(MLText text) {
        // 检测成功。
    }
}).addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        // 识别失败,获取相关异常信息。
        try {        
            MLException mlException = (MLException) e;
            // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。        
            int errorCode = mlException.getErrCode();
            // 获取报错信息，开发者可以结合错误码，快速定位问题。        
            String errorMessage = mlException.getMessage();    
        } catch (Exception error) {
            // 转换错误处理。  
        }
    }
});
```
