# Cancel

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[Cancel](https://developer.huawei.com/consumer/cn/doc/hiai-References/cancel-0000001057482169)替代。

## 接口定义

```screen
virtual Status Cancel() = 0;
```

## 功能介绍

取消模型异步推理任务。

## 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
