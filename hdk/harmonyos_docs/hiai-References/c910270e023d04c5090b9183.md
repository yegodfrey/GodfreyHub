# SetDtcPara(uint32_t batchIndex, AippDtcPara dtcPara)

#### 接口定义

```
AIStatus SetDtcPara(uint32_t batchIndex, AippDtcPara dtcPara);
```

#### 功能介绍

设置AIPP DTC数据类型转换参数，为特定下标的batch设置DTC参数。  

#### 参数

|名称|类型|描述|
|:---------|:-------------------------------------------------------------------------------------------------------|:----------------------------------|
|batchIndex|uint32_t|batch下标，标识为第几个batch设置DTC参数，取值需\>=0。|
|dtcPara|[AippDtcPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippdtcpara-0000001291851965)|DTC数据类型转换参数。|

#### 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
