# BuildModel

## BuildModel(const vector<MemBuffer*>& pinputMemBuffer, MemBuffer* poutputModelBuffer, uint32_t& poutputModelSize)

### 接口定义

```screen
AIStatus BuildModel(const std::vector<MemBuffer*>& pinputMemBuffer, MemBuffer* poutputModelBuffer, uint32_t& poutputModelSize);
```

### 功能介绍

OM离线模型在线编译接口。建议将编译后的模型文件（poutputModelBuffer）本地保存，以便于后续加载该模型文件时提升加载性能。

### 参数

|名称|类型|描述|
|:-----------------|:--------------------------|:---------------|
|pinputMemBuffer|const vector<MemBuffer *> &|输入的OM离线模型buffer。|
|poutputModelBuffer|MemBuffer *|输出模型buffer。|
|poutputModelSize|uint32_t &|输出模型大小（单位：byte）。|

### 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|

## BuildModel(const vector<MemBuffer *> &input_membuffer, MemBuffer *output_model_buffer, uint32_t &output_model_size, const BuildOptions &options)

### 接口定义

```screen
AIStatus BuildModel(const vector<MemBuffer *> &input_membuffer, MemBuffer *output_model_buffer, uint32_t &output_model_size, const BuildOptions &options);
```

### 功能介绍

OM离线模型在线编译接口。本接口为CANN DDK V320新增，用于异构模型分段。建议将编译后的模型文件（output_model_buffer）本地保存，以便于后续加载该模型文件时提升加载性能。

### 参数

|名称|类型|描述|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------|:---------------|
|pinputMemBuffer|const vector<MemBuffer *> &|输入的OM离线模型buffer。|
|poutputModelBuffer|MemBuffer *|输出模型buffer。|
|poutputModelSize|uint32_t &|输出模型大小（单位：byte）。|
|options|const [BuildOptions](https://developer.huawei.com/consumer/cn/doc/hiai-References/buildoptions-0000001226017497) &|输入编译配置参数。|

### 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|
