# HiAI_SingleOpBuffer_Create

## 接口定义

```screen
HiAI_SingleOpBuffer* HiAI_SingleOpBuffer_Create(size_t dataSize);
```

## 功能介绍

用于根据指定的dataSize申请对应大小的ION内存，并创建HiAI_SingleOpBuffer对象。
> 注意
>
> 当不再使用HiAI_SingleOpBuffer对象时，调用HiAI_SingleOpBuffer_Destroy销毁，否则会造成内存泄漏。

## 参数

|名称|类型|描述|
|:-------|:-----|:-------------------------|
|dataSize|size_t|要申请的内存字节大小。该值不能为0，否则返回空指针。|

## 返回

|类型|描述|
|:-------------------|:---------------------------------------|
|HiAI_SingleOpBuffer*|指向HiAI_SingleOpBuffer对象的指针，如果创建失败则返回空指针。|
