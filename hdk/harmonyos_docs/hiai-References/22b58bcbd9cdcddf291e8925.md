# SetData

## 接口定义

```screen
GraphErrCodeStatus SetData(const Buffer& data);
GraphErrCodeStatus SetData(const uint8_t* data, size_t size);
```

## 功能介绍

向Tensor中设置数据。

## 参数

|名称|输入/输出|类型|描述|
|:---|:----|:----------------------------|:-----------|
|data|输入|const Buffer& 或const uint8_t*|需设置的数据。|
|size|输入|size_t|数据的长度，单位为字节。|

## 返回

|类型|描述|
|:-----------------|:-------------------------------------|
|GraphErrCodeStatus|设置成功返回GRAPH_SUCCESS，否则，返回GRAPH_FAILED。|
