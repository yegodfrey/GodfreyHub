# Overview

#### API列表

|API|描述|
|:-------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------|
|[属性类](https://developer.huawei.com/consumer/cn/doc/hiai-References/setattr-0000001052808157)|用于存放Operator的属性值。该类接口在attr_value.h、attributes_holder.h中定义。|
|[Tensor类](https://developer.huawei.com/consumer/cn/doc/hiai-References/gettensordesc-0000001052608146)|用于设置/获取Tensor数据以及实现对Tensor的描述。该类接口在tensor.h中定义。|
|[TensorDesc类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getname-0000001052569443)|用于描述Tensor的信息，包括Shape、DataType、Format等。该类接口在tensor.h中定义。|
|[Shape类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getdimnum-0000001051808154)|用于Tensor的形状描述。该类接口在shape.h中定义。|
|[缓存类](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001138680893)|用于实现模型数据的序列化和反序列化功能。该类接口在buffer.h中定义。|
|[Operator类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getname-0000001053088163)|用于存取算子属性、设置输入/输出。该类接口在operator.h中定义。|
|[Operator注册类](https://developer.huawei.com/consumer/cn/doc/hiai-References/usage-instruction-0000001054147872)|用于设置算子注册时的输入输出、校验属性、获取维度等。该类接口在operator_hiai_reg.h中定义。|
|[Graph类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getimpl-0000001052808173)|用于设置图的Input/Output、校验图的有效性。该类接口在graph.h中定义。|
|[Model类](https://developer.huawei.com/consumer/cn/doc/hiai-References/setname-0000001051489424)|用于存取模型版本号和属性以及模型内部Graph。该类接口在model.h中定义。|
|[模型构建类](https://developer.huawei.com/consumer/cn/doc/hiai-References/createmodelbuff1-0000001051489426)|用于模型构建。在hiai_ir_build.h中提供了此类接口的声明。|
|[Model Dump类](https://developer.huawei.com/consumer/cn/doc/hiai-References/savetofile-0000001180047737)|用于生成构建好的模型，在model_dumper.h中提供了此类接口的声明。|
|[枚举类](https://developer.huawei.com/consumer/cn/doc/hiai-References/valuetype-0000001333764609)|枚举值定义。该类接口在attr_value.h、types.h中定义。|
|[结构体类](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbufferdata-0000001281245160)|结构体类。该类接口在hiai_ir_build.h中定义。|
