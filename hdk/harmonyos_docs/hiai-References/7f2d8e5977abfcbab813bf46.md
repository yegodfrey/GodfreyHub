# ColorSpace

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃。

## 接口定义

```screen
virtual ImageColorSpace ColorSpace() const = 0;
```

## 功能介绍

获取输入图像的格式。

## 返回

|类型|描述|
|:---------------------------------------------------------------------------------------------------------------|:---------|
|[ImageColorSpace](https://developer.huawei.com/consumer/cn/doc/hiai-References/imagecolorspace-0000001229873709)|返回输入图像的格式。|
