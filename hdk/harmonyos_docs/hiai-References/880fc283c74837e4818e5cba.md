# SetDynamicInput

#### 接口定义

```
Operator& SetDynamicInput(const string& name, int32_t index, const Operator& outOp);
Operator& SetDynamicInput(const string& name, int32_t index, const Operator& outOp, const std::string& outName);
Operator& SetDynamicInput(const string& name, int32_t index, const ge::OpAnchor& opAnchor);
```

#### 功能介绍

设置当前算子的动态Input信息。  

#### 参数

|名称|输入/输出|类型|描述|
|:-------|:----|:-------------------|:-----------------------|
|name|输入|const string\&|当前算子输入边的目的动态输入节点的名称。|
|outOp|输入|const Operator\&|当前算子输入边的起始节点所在的源算子对象的引用。|
|index|输入|int32|当前算子输入边的目的动态输入节点的索引。|
|outName|输入|const string\&|当前算子输入边的起始节点名称。|
|opAnchor|输入|const ge::OpAnchor\&|当前算子输入边的起始节点的Anchor信息|

#### 返回

|类型|描述|
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
|Operator\&|当前被设置Input的算子对象引用。 说明： 对于接口Operator\& SetDynamicInput(const string\& name, int32_t index, const Operator\& outOp)，要求Operator\& outOp只存在一个输出。|
