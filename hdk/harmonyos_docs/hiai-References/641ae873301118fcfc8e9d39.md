# Return Codes

|Return Code|Value|Description|
|:------------------------------------|:----|:--------------------------|
|SUCCESS|0|执行成功。|
|ERROR_NETWORK_TIMEOUT|1|网络超时，当前不会返回该错误，已无联网相关业务。|
|ERROR_NETWORK|2|其他网络错误，当前不会返回该错误，已无联网相关业务。|
|ERROR_AUDIO|3|音频录音相关错误。|
|ERROR_SERVER|4|服务器相关错误，当前不会返回该错误，已无联网相关业务。|
|ERROR_CLIENT|5|其他客户端错误。|
|ERROR_SPEECH_TIMEOUT|6|没有声音。|
|ERROR_NO_MATCH|7|未匹配识别结果。|
|ERROR_RECOGNIZER_BUSY|8|识别引擎正忙，当前只支持单个应用调用。|
|ERROR_CLIENT_INSUFFICIENT_PERMISSIONS|9|客户端缺少录音或网络权限。|
|ERROR_INVALID_PARAMS|10|客户端参数输入错误。|
|ERROR_UNKNOWN|11|未知错误。|
|ERROR_SERVER_INSUFFICIENT_PERMISSIONS|12|服务端缺少录音权限。|
|ERROR_GET_MODEL_PATH|13|模型路径获取失败。|
|ERROR_AI_ENGINE_CLOSED|14|HUAWEI HiAI Engine设置项关闭。|
|ERROR_RESULT_UNSUPPORTED|15|当前接口不支持。|
|ERROR_MODEL_NOT_MATCH|16|模型引擎不匹配。|
|ERROR_UPDATE_LEXICON_NAME|17|更新词图输入的类型错误。|
|ERROR_UPDATE_LEXICON_ITEM_NUM|18|更新词图输入的类型条数超出限制。|
|ERROR_UPDATE_LEXICON_ITEM_LENGTH|19|更新词图输入的单条字数超出限制。|
|ERROR_UPDATE_LEXICON_OTHER|20|更新词图其他的错误。|
|ERROR_AUDIO_FILE_FORMAT|21|文件格式错误。|
|ERROR_REPEAT_REQEST|22|重复请求错误。|
|ERROR_INIT_FAIL|23|初始化失败。|
|ERROR_UPDATE_LEXICON|24|更新字典失败。|
|ERROR_AUDIO_FILE_EXCEPTION|25|文件路径异常。|
|ERROR_OPUS_INIT|26|OPUS编码库初始化异常。|
|ERROR_AUTH_FAILED|27|鉴权失败。|
