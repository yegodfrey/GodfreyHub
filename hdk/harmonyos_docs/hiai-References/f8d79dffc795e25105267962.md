# TuningStrategy

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[TuningStrategy](https://developer.huawei.com/consumer/cn/doc/hiai-References/tuningstrategy-0000001333619929)替代。

|Enum Info|
|:----------|
|模型优化策略配置选项。|

|Enum Value and Description|Value|
|:------------------------------------------------|:----|
|OFF 不支持深度融合场景，也不支持编译前可变shape。|0|
|ON_DEVICE_TUNING 支持编译前可变shape场景深度融合优化模型。|1|
|ON_DEVICE_PREPROCESS_TUNING NPU算子库动态升级场景深度融合优化模型。|2|
|ON_CLOUD_TUNING 未来场景的预留，目前不使用。|3|
