# CreateLocalBuffer

此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[Init](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001051490692)替代。  

#### CreateLocalBuffer(size_t size)

#### 接口定义

```
HIAI_TENSOR_API_EXPORT std::shared_ptr<IBuffer> CreateLocalBuffer(size_t size);
```

#### 功能介绍

根据指定大小，申请内存，创建IBuffer。  

#### 参数

|名称|类型|描述|
|:---|:-----|:---------|
|size|size_t|指定申请内存的大小。|

#### 返回

|类型|描述|
|:-------------------------|:----------|
|std::shared_ptr\<IBuffer\>|IBuffer的指针。|

#### CreateLocalBuffer(void\* data, size_t size, bool shouldOwn = false)

#### 接口定义

```
std::shared_ptr<IBuffer> CreateLocalBuffer(void* data, size_t size, bool shouldOwn = false);
```

#### 功能介绍

根据提供的data和size，无申请内存，创建IBuffer。  

#### 参数

|名称|类型|描述|
|:--------|:-----|:----------------------------|
|data|void\*|数据地址。|
|size|size_t|指定申请内存的大小。|
|shouldOwn|bool|data的内存是否由IBuffer释放，默认为false。|

#### 返回

|类型|描述|
|:-------------------------|:----------|
|std::shared_ptr\<IBuffer\>|IBuffer的指针。|
