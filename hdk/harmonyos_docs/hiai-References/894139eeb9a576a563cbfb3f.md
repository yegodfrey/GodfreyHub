# HiAI_SingleOp_PadMode

|Enum Info|
|:--------|
|填充模式枚举。|

#### Enum Value Summary

|Enum Value and Description|Value|
|:-------------------------------------------------------------------------------|:----|
|HIAI_SINGLEOP_PAD_MODE_SPECIFIC 如果填充算法未设置，将根据参数pads采用显示填充。|0|
|HIAI_SINGLEOP_PAD_MODE_SAME 对输入进行填充使输出维度与输入维度相同。输出维度由ceil(输入维度 / 步长)确定。|1|
|HIAI_SINGLEOP_PAD_MODE_SAME_UPPER 使用SAME_UPPER填充模式，当填充长度为奇数时，起始的填充长度小于等于末尾的填充长度。|2|
|HIAI_SINGLEOP_PAD_MODE_SAME_LOWER 使用SAME_LOWER填充模式，当填充长度为奇数时，起始的填充长度大于等于末尾的填充长度。|3|
|HIAI_SINGLEOP_PAD_MODE_VALID 不填充，输出维度由ceil((输入维度 - 滤波器维度 + 1) / 步长)确定。|4|
