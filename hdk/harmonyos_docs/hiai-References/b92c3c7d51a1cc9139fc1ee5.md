# SetCropPara(uint32_t batchIndex, AippCropPara cropPara)

## 接口定义

```screen
AIStatus SetCropPara(uint32_t batchIndex, AippCropPara cropPara);
```

## 功能介绍

设置AIPP Crop图片裁剪参数，为特定下标的batch设置Crop参数。

## 参数

|名称|类型|描述|
|:---------|:---------------------------------------------------------------------------------------------------------|:----------------------------------|
|batchIndex|uint32_t|batch下标，标识为第几个batch设置Crop参数，取值需>=0。|
|cropPara|[AippCropPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippcroppara-0000001291497277)|Crop图片裁剪参数。|

## 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
