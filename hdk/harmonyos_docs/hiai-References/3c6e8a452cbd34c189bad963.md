# GetTuningStrategy

#### 接口定义

```
TuningStrategy GetTuningStrategy() const;
```

#### 功能介绍

获取模型优化策略。  

#### 返回

|类型|描述|
|:-------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------|
|[TuningStrategy](https://developer.huawei.com/consumer/cn/doc/hiai-References/tuningstrategy-0000001333619929)|模型优化策略。 ``` enum class TuningStrategy { OFF = 0, ON_DEVICE_TUNING, ON_DEVICE_PREPROCESS_TUNING, ON_CLOUD_TUNING }; ```|
