# HiAI_SingleOpExecutor_Execute

## 接口定义

```screen
HIAI_Status HiAI_SingleOpExecutor_Execute(HiAI_SingleOpExecutor* executor, HiAI_SingleOpTensor* inputs[], int32_t inputNum, HiAI_SingleOpTensor* outputs[], int32_t outputNum);
```

## 功能介绍

用于执行同步运算推理。在调用该接口前，需要先通过[HiAI_SingleOpTensor_CreateFromTensorDesc](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-createfromtensordesc-0000001890254446)或[HiAI_SingleOpTensor_CreateFromSingleOpBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-createfromsingleopbuffer-0000001890414402)接口创建输入和输出Tensor并填充输入Tensor数据。执行器会通过执行推理产生推理结果，并将结果写入输出Tensor中。

## 参数

|名称|类型|描述|
|:--------|:---------------------|:---------------------------------------------|
|executor|HiAI_SingleOpExecutor*|指向HiAI_SingleOpExecutor对象的指针。该值不能为空指针，否则返回错误码。|
|inputs|HiAI_SingleOpTensor**|输入Tensor的数组。|
|inputNum|int32_t|输入Tensor的数量。|
|outputs|HiAI_SingleOpTensor**|输出Tensor的数组。|
|outputNum|int32_t|输出Tensor的数量。|

## 返回

|类型|描述|
|:----------|:---------------------------------------------|
|HIAI_Status|函数执行的结果状态。执行成功返回HIAI_SUCCESS，失败返回HIAI_FAILURE。|
