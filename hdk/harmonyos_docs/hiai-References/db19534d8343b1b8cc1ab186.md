#### detect

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------|
|public int detect(VisionImage image, List\<Barcode\> barcodes, VisionCallback\<List\<Barcode\>\> barCodeCallback) 根据传入的图像，返回输出码检测的结果。|

Parameters  

|Name|Description|
|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|image|图片数据，使用bitmap，通过VisionImage. fromBitmap接口传参。|
|barcodes|返回的结果类。 * 码中包含的信息类型，根据具体类型内部成员包含不同格式的信息。 ``` {"resultCode":0,"barcode":"[{\"contentTypes\":[9],\"text\":{\"languageType\":1,\"text\":\"huawei BarcodeDemo\"}}]"} ``` * Barcode将包含该码信息的Java对象。对于不能识别的码、不支持的码类型，解析结果中contentTypes返回值为0，Barcode结果为null。可使用BarCode.getContentType()方法获取二维码/条码的类型。详细码类型说明（也可以在Barcode类中引用到）。 * contentTypes定义如下： ``` public static final int TYPE_UNKNOWN = 0; // 未知的码类型。 public static final int TYPE_PHONE = 1; // 包含电话信息的二维码。 public static final int TYPE_GEO_POINT = 2; // 包含地理位置信息的二维码。 public static final int TYPE_URL = 3; // 包含网址信息的二维码。 public static final int TYPE_EMAIL = 4; // 包含邮件信息的二维码。 public static final int TYPE_CONTACT_INFO = 5; // 包含联系人信息的二维码。 public static final int TYPE_SMS = 6; // 包含短信信息的二维码。 public static final int TYPE_CALENDAR_EVENT = 7; // 包含日程事件信息的二维码。 public static final int TYPE_WIFI = 8; // 包含wifi信息的二维码。 public static final int TYPE_TEXT = 9; // 包含文本信息的二维码。 public static final int TYPE_PRODUCT = 10; // 包含商品信息的条码。 public static final int TYPE_ISBN = 11; // 包含书籍ISBN信息的条码。 ```|
|barCodeCallback|回调接口对象。 * 传入空, 表示同步处理。 * 传入非空，表示异步处理，用于异步返回结果。|

Return  

|Type|Description|
|:---|:----------|
|int|码检测执行返回码。|
