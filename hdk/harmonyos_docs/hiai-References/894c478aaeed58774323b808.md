# 说明

|Name|Description|
|:--------|:---------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，提供华为机器学习服务能力。包含文本类、语音语言类、图像类、人脸人体类、自然语言处理类、自定义模型。|
|iOS|基于Swift语言开发的独立iOS应用程序接口，提供华为机器学习服务能力。包含语音语言类、图像类。|
|HarmonyOS|基于Java语言开发的独立HarmonyOS应用程序接口，包含了部分MLKit功能。|
