# DeviceMemoryReusePlan

|Enum Info|
|:--------------------------|
|设备内存复用配置选项，从参数控制模型运行时的内存申请。|

|Enum Value and Description|Value|
|:----------------------------|:----|
|UNSET 不使用。|0|
|LOW 低内存复用率。申请的内存较高但模型推理性能有收益。|1|
|HIGH 高内存复用率。模型申请的内存较低。|2|
