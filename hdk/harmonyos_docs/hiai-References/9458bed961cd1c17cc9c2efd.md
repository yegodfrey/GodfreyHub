# GetOpType

#### 函数功能

获取算子类型。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150659.20948117574237673856696794097109:50001231000000:2800:28EBE5D1FD207C9C95F65C949865FBFA9293C3D94E6B8AF1DB3822A54C3BA686.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
std::string GetOpType() const;
graphStatus GetOpType(AscendString &type) const;
```

#### 参数说明

|参数名|输入/输出|描述|
|:---|:----|:----|
|type|输出|算子类型。|

#### 返回值

|类型|描述|
|:----------|:---------------------------------|
|graphStatus|GRAPH_FAILED：失败。 GRAPH_SUCCESS：成功。|

#### 异常处理

无

无
