# GetAllKeys

#### 接口定义

```
AIStatus GetAllKeys(std::vector<std::string>& keys);
```

#### 功能介绍

获取已添加的所有参数key。  

#### 参数

|名称|类型|描述|
|:---|:------------------|:-------|
|keys|vector\<string\> \&|所有关键字类型。|

#### 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|
