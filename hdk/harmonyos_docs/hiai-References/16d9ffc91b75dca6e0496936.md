# MLImageSuperResolutionAnalyzer

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.imagesuperresolution.MLImageSuperResolutionAnalyzer 图像超分分析器，通过调用asyncAnalyseFrame()接口进行图像超分。创建图像超分分析器有两种方式： * MLImageSuperResolutionAnalyzerFactory.getInstance().getImageSuperResolutionAnalyzer() * MLImageSuperResolutionAnalyzerFactory.getInstance().getImageSuperResolutionAnalyzer(MLImageSuperResolutionAnalyzerSetting） 前者使用MLImageSuperResolutionAnalyzeSetting中设置的默认值，后者可自定义配置项。 注意：创建图像超分分析器使用单例模式，1x超分和3x超分之间切换，需要调用stop()先释放原来的模型资源，然后再创建新的分析器。|

```screen
            // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
            int errorCode = mlException.getErrCode();
            // 获取报错信息，开发者可以结合错误码，快速定位问题。
            String errorMessage = mlException.getMessage();
            }
        } else {
            // 其他异常。
    }
});
```
