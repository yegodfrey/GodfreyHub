# Overview

提供图像分割SDK，包含ML Kit图像分割服务类和接口。

## Class Summary

|Class|Description|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|[MLImageSegmentation](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesegmentation-0000001050167560)|表示由图像分割检测器（MLImageSegmentationAnalyzer）图像分割后的各个像素点分类。 对象的属性包括： * 当前图像分割后各个像素点的标志。 * 透明背景人像前景图。 * 人像为白色，背景为黑色的灰度图。 * 分割原图。|
|[MLImageSegmentationAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesegmentationanalyzer-0000001050169515)|图像分割检测器：用于获取图片中图像分割信息（MLImageSegmentation)。|
|[MLImageSegmentationClassification](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/segmentationclassification-0000001050167562)|图像分割分类：算法提供的图像分割11大分类。|
|[MLImageSegmentationScene](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesegmentationanalyzerscene-0000001050169517)|图像分割场景，用户可以自由组合需要的能力场景。|
|[MLImageSegmentationSetting](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesegmentationanalyzers-0000001050167564)|图像分割检测器设置类：用于设置检测器（MLImageSegmentationAnalyzer)属性。 属性包括： * 检测模式（人像检测模式、图像多类别检测模式），默认为人像检测模式。 * 是否支持精细检测（人像模式和图像多分类检测模式都支持，默认为精细模式） * 支持的能力场景，默认为所有能力场景。|
|[MLImageSegmentationSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesegmentationanalyzersf-0000001050169519)|创建图像分割配置器的实例，用于设置图像分割的属性。|
