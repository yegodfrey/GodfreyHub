# HiAI_SingleOpExecutor_UpdateOutputTensorDesc

## 接口定义

```screen
HIAI_Status HiAI_SingleOpExecutor_UpdateOutputTensorDesc(const HiAI_SingleOpExecutor* executor, uint32_t index, HiAI_SingleOpTensorDesc* output);
```

## 功能介绍

用于更新HiAI_SingleOpExecutor的输出Tensor描述。如果在创建HiAI_SingleOpExecutor时，输入参数output数据类型为HIAI_SINGLEOP_DT_UNDEFINED，且排布格式为HIAI_SINGLEOP_FORMAT_RESERVED，那么在成功创建HiAI_SingleOpExecutor后，调用该接口将输出Tensor描述更新为硬件适配最优的数据类型和排布格式。

## 参数

|名称|类型|描述|
|:-------|:---------------------------|:---------------------------------------------|
|executor|const HiAI_SingleOpExecutor*|指向HiAI_SingleOpExecutor对象的指针。该值不能为空指针，否则返回错误码。|
|index|uint32_t|输出Tensor描述的索引，与创建executor时的输出顺序一致。索引值从0开始。|
|output|HiAI_SingleOpTensorDesc*|需要更新的HiAI_SingleOpTensorDesc对象的指针。|

## 返回

|类型|描述|
|:----------|:---------------------------------------------|
|HIAI_Status|函数执行的结果状态。执行成功返回HIAI_SUCCESS，失败返回HIAI_FAILURE。|
