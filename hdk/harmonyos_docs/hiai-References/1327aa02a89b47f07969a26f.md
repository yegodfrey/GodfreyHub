# SetInput

#### 接口定义

```
Operator& SetInput(const string& name, const Operator& outOp);
Operator& SetInput(const string& name, const Operator& outOp, const string& outName);
Operator& SetInput(int32_t index, const Operator& outOp, int32_t outIndex);
Operator& SetInput(const string& name, const ge::OpAnchor& opAnchor);
```

#### 功能介绍

设置当前算子的Input信息。  

#### 参数

|名称|输入/输出|类型|描述|
|:-------|:----|:-------------------|:-----------------------|
|name|输入|const string\&|当前算子输入边的目的节点名称。|
|outOp|输入|const Operator\&|当前算子输入边的起始节点所在的源算子对象的引用。|
|outName|输入|const string\&|当前算子输入边的起始节点名称。|
|index|输入|int32|当前算子输入边的目的节点的索引。|
|outIndex|输入|int32|当前算子输入边的起始节点的索引。|
|opAnchor|输入|const ge::OpAnchor\&|当前算子输入边的起始节点的Anchor信息|

#### 返回

|类型|描述|
|:---------|:---------------------------------------------------------------------------------------------------------------------|
|Operator\&|当前被设置Input的算子对象引用。 说明： 对于接口Operator\& SetInput(const string\& name, const Operator\& outOp)，要求Operator\& outOp只存在一个输出。|
