# Init

## Init(const TensorDimension* dim)

### 接口定义

```screen
AIStatus Init(const TensorDimension* dim);
```

### 功能介绍

根据Tensor的尺寸进行初始化。

### 参数

|名称|类型|描述|
|:--|:---------------------|:---------------|
|dim|const TensorDimension*|输入Tensor的尺寸结构信息。|

### 返回

|类型|描述|
|:-------|:----------------------------------------------------------------------------------|
|AIStatus|初始化结果。 * AI_SUCCESS：成功。 * AI_INVALID_PARA：dim为空。 * AI_FAILED：Tensor size为0或者申请内存失败。|

> 说明
>
> [Init](#section1531164213188)(uint32_t number, uint32_t height, uint32_t width, AiTensorImage_Format format)和[Init](#section69201456112113)(const TensorDimension* dim, HIAI_DataType DataType)为CANN DDK V310新增接口，其中[Init](#section1531164213188)(uint32_t number, uint32_t height, uint32_t width, AiTensorImage_Format format)接口仅支持AIPP模型。

## Init(uint32_t number, uint32_t height, uint32_t width, AiTensorImage_Format format)

### 接口定义

```screen
AIStatus Init(uint32_t number, uint32_t height, uint32_t width, AiTensorImage_Format format);
```

### 功能介绍

根据NHW和图片的格式初始化Tensor。

### 参数

|名称|类型|描述|
|:-----|:-----------------------------------------------------------------------------------------------------------|:-----------------------------|
|number|uint32_t|输入的Tensor的数量。|
|height|uint32_t|输入的Tensor的高度。|
|width|uint32_t|输入的Tensor的宽度。|
|format|[AiTensorImage_Format](https://developer.huawei.com/consumer/cn/doc/hiai-References/format-0000001051490704)|输入图片的格式AiTensorImage_Format类型。|

### 返回

|类型|描述|
|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|AIStatus|* AIStatus::AI_SUCCESS：成功。 * Others：失败。如下： * AIStatus::AI_INVALID_PARA：N, H, W中任意一个为0或者format不在所支持的范围内。 * AIStatus::AI_FAILED：Tensor size为0或者申请内存失败。|

## Init(const TensorDimension* dim, HIAI_DataType pdataType)

### 接口定义

```screen
AIStatus Init(const TensorDimension* dim, HIAI_DataType pdataType);
```

### 功能介绍

根据Tensor的尺寸和DataType初始化Tensor。

### 参数

|名称|类型|描述|
|:--------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|dim|const TensorDimension*|输入Tensor的尺寸结构信息。|
|pdataType|HIAI_DataType|枚举类型。包含如下类型： * HIAI_DATATYPE_UINT8 * HIAI_DATATYPE_FLOAT32 * HIAI_DATATYPE_FLOAT16 * HIAI_DATATYPE_INT32 * HIAI_DATATYPE_INT8 * HIAI_DATATYPE_INT16 * HIAI_DATATYPE_BOOL * HIAI_DATATYPE_INT64 * HIAI_DATATYPE_UINT32 * HIAI_DATATYPE_DOUBLE 具体说明请参见[HIAI_DataType](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-datatype-0000001051809440)。|

### 返回

|类型|描述|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
|AIStatus|* AIStatus::AI_SUCCESS：成功。 * Others：失败。如下： * AIStatus::AI_INVALID_PARA：dim为空或者DataType不在可支持范围。 * AIStatus::AI_FAILED：Tensor size为0或者申请内存失败。|

## Init(const NativeHandle& handle, const TensorDimension* dim, HIAI_DataType pdataType)

### 接口定义

```screen
AIStatus Init(const NativeHandle& handle, const TensorDimension* dim, HIAI_DataType pdataType);
```

### 功能介绍

根据NativeHandle，TensorDimension和DataType初始化Tensor。

### 参数

|名称|类型|描述|
|:--------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|handle|const NativeHandle&|输入NativeHandle的结构信息，NativeHandle只支持ION内存。|
|dim|const TensorDimension*|输入Tensor的尺寸结构信息。|
|pdataType|HIAI_DataType|枚举类型，包含如下类型： * HIAI_DATATYPE_UINT8 * HIAI_DATATYPE_FLOAT32 * HIAI_DATATYPE_FLOAT16 * HIAI_DATATYPE_INT32 * HIAI_DATATYPE_INT8 * HIAI_DATATYPE_INT16 * HIAI_DATATYPE_BOOL * HIAI_DATATYPE_INT64 * HIAI_DATATYPE_UINT32 * HIAI_DATATYPE_DOUBLE 具体说明请参见[HIAI_DataType](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-datatype-0000001051809440)。|

### 返回

|类型|描述|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
|AIStatus|* AIStatus::AI_SUCCESS：成功。 * Others：失败。如下： * AIStatus::AI_INVALID_PARA：dim为空或者DataType不在可支持范围。 * AIStatus::AI_FAILED：Tensor size为0或者申请内存失败。|

## Init(const void* data, const TensorDimension* dim, HIAI_DataType pdataType)

### 接口定义

```screen
AIStatus Init(const void* data, const TensorDimension* dim, HIAI_DataType pdataType);
```

### 功能介绍

根据用户传入的数据data，TensorDimension和DataType初始化Tensor，支持CPU输入输出内存零拷贝，CPU零拷贝场景下使用。

### 参数

|名称|类型|描述|
|:--------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|data|void*|用户的通过malloc或者new分配的内存，里面包含用户的输入数据|
|dim|const TensorDimension*|输入Tensor的尺寸结构信息。|
|pdataType|HIAI_DataType|枚举类型，包含如下类型： * HIAI_DATATYPE_UINT8 * HIAI_DATATYPE_FLOAT32 * HIAI_DATATYPE_FLOAT16 * HIAI_DATATYPE_INT32 * HIAI_DATATYPE_INT8 * HIAI_DATATYPE_INT16 * HIAI_DATATYPE_BOOL * HIAI_DATATYPE_INT64 * HIAI_DATATYPE_UINT32 * HIAI_DATATYPE_DOUBLE 具体说明请参见[HIAI_DataType](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-datatype-0000001051809440)。|

### 返回

|类型|描述|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
|AIStatus|* AIStatus::AI_SUCCESS：成功。 * Others：失败。如下： * AIStatus::AI_INVALID_PARA：dim为空或者DataType不在可支持范围。 * AIStatus::AI_FAILED：Tensor size为0或者申请内存失败。|
