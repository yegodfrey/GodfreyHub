# BuildIRModel(ge::Model\& irModel, ModelBufferData\& output, const BuildOptions\& options)

#### 接口定义

```
BuildIRModel(ge::Model& irModel, ModelBufferData& output,const BuildOptions& options);
```

#### 功能介绍

模型构建接口，输入模型对象和模型构建接口配置，输出模型。  

#### 参数

|名称|输入/输出|类型|描述|
|:------|:----|:-----------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|irModel|输入|ge::Model\&|模型对象。|
|output|输出|[ModelBufferData](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbufferdata-0000001281245160)\&|模型结构体对象。|
|options|输入|const [BuildOptions](https://developer.huawei.com/consumer/cn/doc/hiai-References/buildoptions-0000001226017497)\&|模型构建接口配置。 ``` struct BuildOptions { bool useOriginFormat = false; WeightDataType weightDataType = FP32; ExecuteDeviceSelectMode mode = AUTO; std::map<string, vector<OpExecuteDevice>> opExecuteDeviceConfig; }; ``` 说明： useOriginFormat仅支持基于yolo、inception的业务网络转换设置为true，其它网络转换使用默认值false。|

#### 返回

|类型|描述|
|:---|:-----------------------------|
|bool|* true：构建模型成功。 * false：构建模型失败。|
