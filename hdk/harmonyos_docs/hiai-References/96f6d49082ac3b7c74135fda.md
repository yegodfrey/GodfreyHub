# GetVersion

## 接口定义

```screen
char* GetVersion();
```

## 功能介绍

获取手机ROM中的CANN版本号。

## 返回

|类型|描述|
|:----|:-----------------|
|char*|执行成功，返回相应的CANN版本号。|
