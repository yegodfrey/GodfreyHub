### detect

|Method|
|:--------------------------------------------------------------------------------|
|public JSONObject detect(Frame frame, IVisionCallback cb) 用于EMUI 10.0以下版本。人脸朝向识别。|

**Parameters**

|Name|Description|
|:----|:----------------------------------------------------------------------------------------------|
|frame|图片数据，Frame目前支持封装Bitmap和文件路径形式给出的图片数据，后续会扩展支持bytebuffer形式的图片数据。人脸朝向识别目前支持图片尺寸要求height/width=3/4。|
|cb|回调函数接口对象，目前暂不支持异步处理。 * 传入null, 表示同步处理。 * 传入非null，即回调函数接口对象，用于异步返回结果。|

**Return**

|Type|Description|
|:---------|:--------------------------------------------------------|
|JSONObject|人脸朝向识别结果的JSON对象。可以通过convertResult()方法将其转换为JSON对应的Java类结果。|

### detect

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|public resultCode detect(VisionImage image, HeadPoseResult headPoseResult, VisionCallback<HeadPoseResult> headPoseCallback) 用于EMUI 10.0及以上版本。人脸朝向识别。|

**Parameters**

|Name|Description|
|:---------------|:-----------------------------------------------------------------------------------------------------|
|image|图片数据，VisionImage目前支持封装Bitmap、文件路径形式给出的图片数据，后续会扩展支持bytebuffer形式的图片数据。 人脸朝向识别目前支持图片尺寸要求height/width=3/4。|
|headPoseResult|HeadPose结果类。|
|headPoseCallback|Headpose回调函数类： * 传入null, 表示同步处理。 * 传入非null，即回调函数接口对象，表示异步处理，用于异步返回结果。|

**Return**

|Type|Description|
|:---------|:-----------|
|resultCode|人脸朝向识别结果返回码。|

人脸朝向识别HeadPoseResult示例结果：

```screen
{
    "resultCode": 0,
    "headposevl": "{\"confidence\":0.99997175,\"headpose\":3}"
}
```

字段resultCode说明：

返回码的取值请参见 [com.huawei.hiai.common.HwHiAIResultCode](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/return-codes-0000001053441989)。

字段headposevl说明：

|Field|Required|Type|Description|
|:---------|:-------|:---|:----------------------------------------------------------------------|
|confidence|是|int|人脸朝向识别置信度，范围[0~1]。|
|headpose|是|int|人脸朝向的类别编号，[0, 1, 2, 3, 4]。说明如下： 0：没有人脸。 1：人脸朝上。 2：人脸朝右。 3：人脸朝下。 4：人脸朝左。|

### convertResult

|Method|
|:--------------------------------------------------------------------------------------------------------|
|public HeadPoseResult convertResult(JSONObject object) detect直接返回JSONObject结果，可以通过此方法将其转换为JSON对应的Java类结果。|

**Parameters**

|Name|Description|
|:-----|:-----------------|
|object|detect返回的JSON对象结果。|

**Return**

示例结果：

```screen
HeadPoseResult result = headposeDetector.convertResult(jsonObject);
if (null != result) {
    int headpose = result.getHeadpose();
    float confidence = result.getConfidence();
}
```
