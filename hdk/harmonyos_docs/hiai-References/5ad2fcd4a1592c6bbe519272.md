# GetModelIOTensorDim

#### 接口定义

```
AIStatus GetModelIOTensorDim(const std::string& pmodelName, std::vector<TensorDimension>& pinputTensor, std::vector<TensorDimension>& poutputTensor);
```

#### 功能介绍

获取模型输入输出Tensor信息。  

#### 参数

|名称|类型|描述|
|:------------|:--------------------------|:----------------|
|pmodelName|const string\&|模型名称。|
|pinputTensor|vector\<TensorDimension\>\&|存储模型输入节点Tensor信息。|
|poutputTensor|vector\<TensorDimension\>\&|存储模型输出节点Tensor信息。|

#### 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|
