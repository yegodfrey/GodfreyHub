# GetName

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetName](https://developer.huawei.com/consumer/cn/doc/hiai-References/getname-0000001052969437)替代。

## 接口定义

```screen
virtual std::string GetName() const = 0;
```

## 功能介绍

获取模型名称。

## 返回

|类型|描述|
|:----------|:----|
|std::string|模型名称。|
