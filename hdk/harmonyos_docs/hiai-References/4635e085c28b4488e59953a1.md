# Overview

此包提供了文本转语音服务，核心API如下：

* MLTtsCallback：文本转语音的回调接口，用来通知播放状态、告警事件、错误事件。
* MLTtsConfig：配置类，用来设置语音合成相关配置。
* MLTtsEngine：文本转语音合成引擎，通过调用speak接口实现文本合成语音并播放。
* MLTtsError：错误事件描述类。
* MLTtsSpeaker：发音人信息。
* MLTtsWarn：告警事件描述类。
* MLTtsConstants：TTS SDK常量定义类。
* MLTtsAudioFragment：音频数据描述类。

|Interface|Description|
