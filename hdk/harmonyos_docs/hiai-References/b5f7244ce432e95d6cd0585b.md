# ML3DFaceAnalyzerSetting

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.face3d.ML3DFaceAnalyzerSetting 3D人脸检测配置器：用于设置人脸检测器的属性，其属性包括： * 设置分析器对速度/精度的偏好模式，用于选择执行面部检测时的精度或速度优先。 * 是否启用面部跟踪功能。 说明： 此类不支持人脸特性、表情识别。|
