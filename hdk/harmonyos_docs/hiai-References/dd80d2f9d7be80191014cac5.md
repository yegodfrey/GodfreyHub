# GetSubgraphBuilder

#### 函数功能

根据子图名称获取算子对应的子图构建的函数对象。  

#### 函数原型

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150658.32580326649953693270375021251958:50001231000000:2800:6BEF63E9284EFC303D9264535A72AA375F32E1747F776E405993F8CADFD096AB.png)  
数据类型为string的接口后续版本会废弃，建议使用数据类型为非string的接口。

```
SubgraphBuilder GetSubgraphBuilder(const std::string &name) const;
SubgraphBuilder GetSubgraphBuilder(const char_t *name) const;
```

#### 参数说明

|参数名|输入/输出|描述|
|:---|:----|:----|
|name|输入|子图名称。|

#### 返回值

SubgraphBuilder对象。  

#### 异常处理

无

无
