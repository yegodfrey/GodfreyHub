# IsEmpty

## 接口定义

```screen
bool IsEmpty() const;
```

## 功能介绍

判断属性值是否设置。

## 返回

|类型|描述|
|:---|:-----------------------------|
|bool|* true：未设置属性值。 * false：已设置属性值。|
