# MLLocalTextSetting

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.text.MLLocalTextSetting 文本分析器设置类：设置文本分析器（MLTextAnalyzer）本地检测的属性，用于调用本地算法API接口检测图像中的文本。分析器属性包括： * 预置的语种。正确地预置检测语种，可以使检测更快速更准确。 * 本地算法检测模式：分为独立检测模式和追踪检测模式。|

|Field|
