# SetModelBuffer

## 接口定义

```screen
AIStatus SetModelBuffer(const void* data, uint32_t size);
```

## 功能介绍

设置模型内存。

## 参数

|名称|类型|描述|
|:---|:----------|:-------------|
|data|const void*|模型buffer地址。|
|size|uint32_t|模型大小（单位：byte）。|

## 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|
