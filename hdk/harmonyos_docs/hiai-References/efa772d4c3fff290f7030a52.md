# HiAI_SingleOpTensor_CreateFromSingleOpBuffer

## 接口定义

```screen
HiAI_SingleOpTensor* HiAI_SingleOpTensor_CreateFromSingleOpBuffer(const HiAI_SingleOpTensorDesc *desc, void* data, size_t dataSize);
```

## 功能介绍

复用HiAI_SingleOpBuffer的ION内存，所复用的内存地址和大小由data和dataSize确定。dataSize必须等于通过HiAI_SingleOpTensorDesc_GetByteSize计算得到的desc的字节大小。当调用[HiAI_SingleOpTensor_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-destroy-0000001934134189)接口销毁该接口创建的Tensor时，不会释放该Tensor数据的内存。
> 注意
>
> * 该接口会将desc拷贝到HiAI_SingleOpTensor中。因此，当desc不再使用时，请使用[HiAI_SingleOpTensorDesc_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensordesc-destroy-0000001890414394)销毁desc。
> * 当不再使用HiAI_SingleOpTensor对象时，调用[HiAI_SingleOpTensor_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-destroy-0000001934134189)销毁，否则会造成内存泄漏。

## 参数

|名称|类型|描述|
|:-------|:-----------------------------|:-------------------------------------------------|
|desc|const HiAI_SingleOpTensorDesc*|指向HiAI_SingleOpTensorDesc对象的指针。该值不能为空指针，否则返回空指针。|
|data|void*|Tensor数据地址。该值必须是HiAI_SingleOpBuffer中的内存地址，否则返回空指针。|
|dataSize|size_t|Tensor数据大小。该值不能为0，否则返回空指针。|

## 返回

|类型|描述|
|:-------------------|:---------------------------------------|
|HiAI_SingleOpTensor*|指向HiAI_SingleOpTensor对象的指针，如果创建失败则返回空指针。|
