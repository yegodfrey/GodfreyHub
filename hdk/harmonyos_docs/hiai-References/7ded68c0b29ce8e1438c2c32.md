# Width

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[GetInputShape](https://developer.huawei.com/consumer/cn/doc/hiai-References/getinputshape-0000001052490753)替代。

## 接口定义

```screen
virtual int32_t Width() const = 0;
```

## 功能介绍

获取输入图像的宽度。

## 返回

|类型|描述|
|:------|:---------|
|int32_t|返回输入图像的宽度。|
