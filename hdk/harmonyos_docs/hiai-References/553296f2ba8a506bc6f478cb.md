# GetAippParas(uint32_t index)

## 接口定义

```screen
std::shared_ptr<AippPara> GetAippParas(uint32_t index) const;
```

## 功能介绍

获取特定AippPara对象指针。

## 参数

|名称|类型|描述|
|:----|:-------|:-----------|
|index|uint32_t|输入下标，取值需>=0。|

## 返回

|类型|描述|
|:------------------------|:------------|
|std::shared_ptr<AippPara>|AippPara对象指针。|
