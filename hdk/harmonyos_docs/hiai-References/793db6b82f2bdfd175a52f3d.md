# InputMemBufferCreate(const string path)

## 接口定义

```screen
MemBuffer* InputMemBufferCreate(const std::string path);
```

## 功能介绍

从文件创建OM模型MemBuffer。

## 参数

|名称|类型|描述|
|:---|:-----------|:------|
|path|const string|模型文件路径。|

## 返回

|类型|描述|
|:---------|:----------------------------|
|MemBuffer*|MemBuffer地址，如果为nullptr表示创建失败。|
