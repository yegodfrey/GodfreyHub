# GetModelAippPara(const std::string\& modelName, uint32_t index, std::vector\<std::shared_ptr\<AippPara\>\>\& aippPara)

#### 接口定义

```
AIStatus GetModelAippPara(const std::string& modelName, uint32_t index, std::vector<std::shared_ptr<AippPara>>& aippPara);
```

#### 功能介绍

获取模型中某个输入的AIPP配置信息。  

#### 参数

|名称|类型|描述|
|:--------|:-------------------------------------------|:---------------------------------------|
|modelName|const std::string\&|模型名称。|
|index|uint32_t|输入下标，取值需\>=0。|
|aippPara|std::vector\<std::shared_ptr\<AippPara\>\>\&|下标为index的模型输入对应的AIPP配置参数，保存在AippPara对象中。|

#### 返回

|类型|描述|
|:-------|:-----------------------------|
|AIStatus|* AI_SUCCESS：获取成功。 * 其他值：获取失败。|
