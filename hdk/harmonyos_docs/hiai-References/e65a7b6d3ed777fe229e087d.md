# SetOutputs

#### 接口定义

```
Graph& SetOutputs(std::vector<Operator>& outputs);
```

#### 功能介绍

设置Graph关联的输出算子。  

#### 参数

|名称|输入/输出|类型|描述|
|:------|:----|:------------------------|:-------------|
|outputs|输入|std::vector\<Operator\>\&|与Graph关联的输出算子。|

#### 返回

|类型|描述|
|:------|:-------|
|Graph\&|返回调用者本身。|
