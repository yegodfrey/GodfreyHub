# MLGestureAnalyzer

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.gesture.MLGestureAnalyzer 手势分析器，通过调用手势API接口检测手势(MLGesture）。创建手势分析器有两种方式： * MLGestureAnalyzerFactory.getInstance().getGestureAnalyzer() * MLGestureAnalyzerFactory.getInstance().getGestureAnalyzer(MLGestureAnalyzerSetting） 前者使用MLGestureAnalyzerSetting中设置的默认值，后者可自定义配置项。|

Sample Code:

```
// 创建手势分析器。
MLGestureAnalyzer analyzer = MLGestureAnalyzerFactory.getInstance().getGestureAnalyzer();
// 通过bitmap创建MLFrame，建议图片尺寸不小于320*320像素，不大于1920*1920像素。
MLFrame frame = MLFrame.fromBitmap(bitmap);
Task<List<MLGesture>> task = analyzer.asyncAnalyseFrame(frame);
task.addOnSuccessListener(new OnSuccessListener<List<MLGesture>>() {
    public void onSuccess(List<MLGesture> results) {
        // 对检测结果进行处理。
    }
}).addOnFailureListener(new OnFailureListener() {
    public void onFailure(Exception e) {
        // 检测失败。
    }
});
```
