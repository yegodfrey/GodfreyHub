# MLSpeechRealTimeTranscriptionListener

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.speechrtt.MLSpeechRealTimeTranscriptionListener 语音转写监听器，通过该监听器获取到转写结果和错误码。通过[setRealTimeTranscriptionListener](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlsperetimetra-harmonyos-0000001204518822#section10867151145417)(MLSpeechRealTimeTranscriptionListener)设置监听。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------|
|void|[onError](#section480263211503)(int error, String errorMessage) 网络错误或者识别错误后会调用该接口。|
|void|[onRecognizingResults](#section945031710508)(Bundle recognizingResults) 从语音识别器识别到的持续不断的文字。|
|void|[onStartListening](#section791598145017)() 录音器开始接收声音。|
|void|[onStartingOfSpeech](#section106207020507)() 用户开始讲话，即语音识别器检测到用户开始讲话。|
|void|[onState](#section441085064916)(int state, Bundle params) 通知应用状态发生改变。|
|void|[onVoiceDataReceived](#section1640722710498)(byte\[\] data, float energy, Bundle params) 返回给用户原始的PCM音频流和音频能量，该接口并非运行在主线程中，返回结果需要在子线程中处理。|

#### onVoiceDataReceived(byte\[\] data, float energy, Bundle params)

|Method|
|:--------------------------------------------------------------------------------------------------------------------------|
|public void onVoiceDataReceived(byte\[\] data, float energy, Bundle params) 返回给用户原始的PCM音频流和音频能量，该接口并非运行在主线程中，返回结果需要在子线程中处理。|

Parameters  

|Name|Description|
|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|data|pcm音频流，pcm音频采集格式为16000Hz采样率，16bit位深，单声道。|
|energy|音频流的能量值。|
|params|音频数据格式，参见[MLSpeechRealTimeTranscriptionConstants](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspereatimetracinstant-harmonyos-0000001249278859)类下的[WAVE_PAINE_ENCODING](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspereatimetracinstant-harmonyos-0000001249278859#section144941120185119)、[WAVE_PAINE_SAMPLE_RATE](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspereatimetracinstant-harmonyos-0000001249278859#section152381435116)、[WAVE_PAINE_BIT_WIDTH](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspereatimetracinstant-harmonyos-0000001249278859#section2350103212513)、[WAVE_PAINE_CHANNEL_COUNT](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlspereatimetracinstant-harmonyos-0000001249278859#section1683272645113)。|
