# SetDim

#### 接口定义

```
GraphErrCodeStatus SetDim(size_t idx, int64_t value);
```

#### 功能介绍

将Shape中第idx维度的值设置为value。  

#### 参数

|名称|输入/输出|类型|描述|
|:----|:----|:------|:-----------------|
|idx|输入|size_t|Shape维度的索引，索引从0开始。|
|value|输入|int64_t|需设置的值。|

#### 返回

|类型|描述|
|:-----------------|:-------------------------------------|
|GraphErrCodeStatus|设置成功返回GRAPH_SUCCESS，否则，返回GRAPH_FAILED。|
