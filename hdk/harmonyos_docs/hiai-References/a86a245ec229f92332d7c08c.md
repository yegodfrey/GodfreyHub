# MLImageSegmentationScene

|Enum Info|
|:-----------------------------------------------|
|MLImageSegmentationScene 图像分割场景，用户可以自由组合需要的能力场景。|

## Enum Value Summary

|Enum Value and Description|
|:-------------------------------------------------------|
|MLImageSegmentationSceneAll 默认获取所有结果。|
|MLImageSegmentationSceneMaskOnly 获取像素级标记信息。|
|MLImageSegmentationSceneForegroundOnly 获取前景人像抠图，背景透明。|
|MLImageSegmentationSceneGrayscaleOnly 获取人像为白色，背景为黑色的灰度图。|
