# HiAI_SingleOpTensorDesc_GetByteSize

#### 接口定义

```
size_t HiAI_SingleOpTensorDesc_GetByteSize(const HiAI_SingleOpTensorDesc* tensorDesc);
```

#### 功能介绍

用于获取基于HiAI_SingleOpTensorDesc的维度和数据类型计算得到的数据占用字节数。  

#### 参数

|名称|类型|描述|
|:---------|:------------------------------|:---------------------------------------------|
|tensorDesc|const HiAI_SingleOpTensorDesc\*|指向HiAI_SingleOpTensorDesc对象的指针。该值不能为空指针，否则返回0。|

#### 返回

|类型|描述|
|:-----|:--------|
|size_t|张量的数据字节数。|
