# MLHandKeypointAnalyzer

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.handkeypoint.MLHandKeypointAnalyzer 手部关键点分析器，通过调用手部关键点API接口检测手部关键点(MLHandKeypoints）。 创建手部关键点分析器有两种方式： * MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer() * MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer(MLHandKeypointAnalyzerSetting） 前者使用MLHandKeypointAnalyzerSetting中设置的默认值，后者可自定义配置项。|

**Sample code：**

```screen
// 创建手部关键点分析器。
MLHandKeypointAnalyzer analyzer = MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer();
// 通过bitmap创建MLFrame，建议图片尺寸不小于320*320像素，不大于1920*1920像素。
MLFrame frame = MLFrame.fromBitmap(bitmap);
Task<List<MLHandKeypoints>> task = analyzer.asyncAnalyseFrame(frame);
task.addOnSuccessListener(new OnSuccessListener<List<MLHandKeypoints>>() {
    public void onSuccess(List<MLHandKeypoints> results) {
        // 对检测结果进行处理。
    }
}).addOnFailureListener(new OnFailureListener() {
    public void onFailure(Exception e) {
        // 检测失败。
    }
});
```
