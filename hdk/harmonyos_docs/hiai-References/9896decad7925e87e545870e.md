### detectImage

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public int detectImage(VisionImage image, AestheticsScore aestheticsScore, final VisionCallback<AestheticsScore> scoreVisionCallback) 实现根据传入的VisionImage图片或者图片的地址得到美学分数。支持根据AEModelConfiguration对象中DetectImageConf参数控制运行评分模型。 支持同步和异步模式： * 同步模式：int返回图片评分结果码； * 异步模式：通过IvisionCallback回调接口返回图片评分结果。|

**Parameters**

|Name|Description|
|:------------------|:---------------------------------|
|image|需要识别的图片。|
|aestheticsScore|返回的美学评分值，返回的图片和视频帧的评价分数范围为0-100分。|
|scoreVisionCallback|异步模式通过IvisionCallback回调接口返回图片评分结果。|

**Return**

|Type|Description|
|:---|:-------------|
|int|同步模式返回图片评分结果码。|

结果说明（支持图片和视频评分）：

|Field|Required|Type|Description|
|:-----------------------------|:-------|:-----|:--------------------------------------------------------------------------------------------------------------------------------|
|resultCode|是|int|返回结果码。|
|aestheticsScore|否|String|美学评分返回值，兼容原有接口的图片评分，仅图片评分时返回，视频评分时不返回。|
|+score|否|float|图片评价的分数（兼容原有接口的图片评分）。|
|aestheticsScoreList|是|array|新版审美引擎扩展字段，美学评分详细返回值，图片评分时返回一个节点，对视频评分，返回多个节点。|
|+score|是|float|根据OSP模型和HF模型综合评价的分数，如果是图片评分，与aestheticsScore里的score值相同。|
|+OSPScore|是|  |OSP模型评价的详细分数，当前包括4个子维度：ospOverall, objective, subjective, photography。|
|++OSP维度1 ++OSP维度2 ... ++OSP维度n|是|float|OSP模型按子维度分别评价的分数，目前支持4个维度。|
|+HFScore|是|float|HF模型评价的详细分数，当前包括1个子维度：human。|
|++HF维度1 ... ++HF维度n|是|float|HF模型按子维度分别评价的分数，目前支持1个维度。|
|+frameTimeStamp|否|long|视频评分的帧标识，为相对视频起点的时间戳，单位μs，仅视频评分有效。|
|+histResult|否|array|视频评分产生的用于视频切割的中间过程数据（float类型），仅用于视频大爆炸后台处理模式下调用getVideoSummerization()时使用，需通过mSummerizationParm.mVideoFragmentScore回传给审美引擎用于视频总结。|

### detectVideo

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|JSONObject detectVideo (Video video, IVisionCallback cb) 新增接口，实现根据传入的视频地址完成视频帧的美学评分，支持同步和异步模式： * 同步模式：JSONObject返回视频所有处理帧的评分； * 异步模式：通过IvisionCallback回调接口返回视频处理帧评分结果。 异步模式下支持处理状态主动上报机制：审美引擎周期上报处理状态给上层应用，上报周期通过AEModelConfiguration对象中的mDetectVideoStatReptInterval参数设定。已加入队列，开始处理，处理完成3个关键状态需固定上报，不受上报周期约束。|

**Parameters**

|Name|Description|
|:----|:---------------------------------------------------------------------------------------------------------------|
|video|待美学评分的视频数据，Video类暂只支持封装视频文件路径类型的输入数据，后续可扩展支持其他形式的视频输入数据。 > 说明 > 输入视频的规格：视频总长度最短为5秒，最长为10分钟，清晰度支持480p，720p和1080p。|
|cb|回调函数接口对象。 * 传入null, 表示同步处理。 * 传入非null，即回调函数接口对象，表示异步处理，用于异步返回结果。|

**Return**

|Type|Description|
|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|JSONObject|定义参考图像评分中的JSONObject的定义，视频评分返回的是aestheticsScoreList多节点，aestheticsScore不返回。 > 说明 > 审美引擎模型计算在NPU层面都是顺序执行，所有任务FIFO执行，不会出现上层应用执行多个视频评分任务时占用过多RAM的问题。|

### getVideoSummerization

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public JSONObject getVideoSummerization(Video[] video, IVisionCallback cb) 获取输入源视频的最美视频总结的帧区间的列表。输出视频总结的总帧数、每个片段的最小帧数、视频总结方式、总结的附件参数通过AEModelConfiguration参数设定。 支持同步和异步模式。 getVideoSummerization()支持视频大爆炸业务的两种视频总结方式的调用： * 方式1（前台处理方式）: 应用层直接调用getVideoSummerization()进行视频总结，对应AEModelConfiguration配置里的mSummerizationConf.mSummerizationMode = 1视频总结模式；某一人脸聚类的待总结的视频片段通过附加参数的方式设置到mSummerizationConf.mVideoFragment变量中。 * 方式2（后台处理方式）: 应用层先调用detectVideo()进行审美评分，然后调用getVideoSummerization()进行视频总结,对应AEModelConfiguration配置里的mSummerizationConf.mSummerizationMode = 2视频总结模式；某一人脸聚类的待总结的视频片段及片段内帧的评分数据通过附加参数的方式设置到mSummerizationConf. mSummerizationParm.mVideoFragment和mSummerizationConf. mSummerizationParm.mVideoFragmentScore变量中。|

**Parameters**

|Name|Description|
|:----|:----------------------------------------------------------------------------------------|
|video|待完成精彩视频总结的源视频地址，支持输入多个地址路径，个数最多限制为10个。输入的多个视频总长度最短要求为5秒，最大要求不超过10分钟，清晰度支持480p，720p和1080p。|
|cb|回调函数接口对象。 * 传入null, 表示同步处理。 * 传入非null，即回调函数接口对象，表示异步处理，用于异步返回结果。|

**Return**

|Type|Description|
|:---------|:-----------------------------------|
|JSONObject|精彩视频总结时返回JSON对象中的videoSummerization。|

|videoSummerization|否|array|最美视频总结的帧区间列表，支持返回多个区间。|
|+startFrameTimeStamp|否|long|开始帧时间戳，相对视频起点的时间戳，单位μs。|
|+endFrameTimeStamp|否|long|结束帧时间戳，相对视频起点的时间戳，单位μs。|


mProcessingStatus：视频评分处理状态，即已加入队列、开始处理、处理中、处理完成。

mProcessPercent：处理进度百分比，仅当状态为处理中有效。

异步方式：

遵守CV引擎异步返回方式的统一框架。通过回调IVisionCallback的onDetectedResult()方法异步返回审美引擎评分结果，结果数据通过AnnotateResult对象返回，数据格式为JSON对象格式；通过回调的onDetectedInfo()方法上报审美引擎视频类相关评分的处理状态，状态数据通过InfoResult对象返回，数据格式为JSON对象格式。

* 图像评分、视频评分、精彩视频总结异步结果上报的JSON对象格式： 参见前面各接口章节描述。


* 视频评分处理状态上报的JSON对象格式：

|Field|Required|Type|Description|
|:---------------|:-------|:----|:--------------------------------------------------------------------------------------------------------------------------------------------|
|resultCode|是|int|[错误码](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/return-codes-0000001053441989)。|
|processingStatus|是|int|视频评分处理状态： 1. 已加入队列AIRESULT_ENQUEUE = 1； 2. 开始处理AIREULT_STARTPROCESS = 2； 3. 处理中AIRESULT_PROCCESSING = 3； 4. 处理完成AIRESULT_PROCESSCOMPLETE = 4。|
|processPercent|否|float|视频评分处理进度百分比，仅当状态为处理中有效。|

* 异步方式下的CV引擎框架增加mRequestId参数： CV引擎框架的IVisionCallback接口实现类VisionCallback中扩展mRequestID参数，调用API时应用通过IvisionCallback对象传入本次API请求的mRequestID，审美引擎记录mRequestID，审美引擎异步返回评分结果时，应用可通过请求时传入的回调对象IVisionCallback获取到该mRequestID。
