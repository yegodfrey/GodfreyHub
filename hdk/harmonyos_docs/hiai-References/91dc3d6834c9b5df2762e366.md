# SetPriority

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150634.94661459653610739112159947780621:50001231000000:2800:40510D59282629662807021AB730A0BDA03D70924F71DD59691DDB1B734EB465.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[SetModelPriority](https://developer.huawei.com/consumer/cn/doc/hiai-References/setmodelpriority-0000001058722086)替代。  

#### 接口定义

```
virtual Status SetPriority(ModelPriority priority) = 0;
```

#### 功能介绍

设置模型优先级。  

#### 参数

|名称|类型|描述|
|:-------|:-----------------------------------------------------------------------------------------------------------|:-----|
|priority|[ModelPriority](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelpriority-0000001092070292)|模型优先级。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
