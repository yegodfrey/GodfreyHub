人脸属性字段说明：

|Field|Required|Type|Description|
|:--------------|:-------|:---------|:-----------|
|resultCode|是|int|人脸属性执行结果返回码。|
|face_attributes|是|JSONObject|人脸属性结果。|
|+sex|是|String|性别。|

人脸属性列表示例结果：

```screen
返回值：int
示例返回结果（list）: 
{
    "resultCode": 0,
    "face_attributes": "{"age":19.0,"dress":{"beard":0,"glass":0,"hat":0},"emotion":0,"sex":"female"}",
    "face_emotion_attributes": "[{"age":19.0,"dress":{"beard":0,"glass":0,"hat":0},"emotion":0,"sex":"female"}]"
}
resultCode：错误码
```

face_attributes：兼容以前的版本人脸属性信息，返回单人脸属性信息。

face_emotion_attributes：人脸属性信息关键字，人脸属性对象列表，如果没有人脸，为空列表。

常见返回码说明：

|resultCode|Description|
|:---------|:-------------|
|0|成功。|
|-1|未知错误。|
|-2|不支持的功能或接口。|
|-3|内存分配失败或创建对象失败。|
|101|失败。|
|200|输入参数不合法。|
|201|输入参数不合法（为空）。|
|210|输入参数合法。|
|500|服务绑定异常。|
|521|服务绑定异常断开。|
|522|服务已连接。|
|600|模型文件异常。|
|601|模型文件不存在。|
|602|模型加载失败。|
|1001|神经网络处理单元错误。|

FaceAttributesInfo内容说明：

|Field|Required|Type|Description|
|:----------------------|:-------|:-------------------|:----------------------------------------------------|
|face_emotion_attributes|true|FaceAttributesInfo[]|人脸表情属性列表，如果没有人脸，列表为空。|
|+age|false|Float|年龄。|
|+sex|false|String|性别。|
|+emotion|false|Int32|表情： 0：高兴。 1：伤心。 2：惊讶。 3：愤怒。 4：嘟嘴。 5：鬼脸。 6：中性。 -1：未识别。|
|+dress|false|DressInfo|穿戴信息：包括戴眼镜、留胡须、戴帽子。|
|++beard|false|Int32|留胡须： 0：不留胡。 1：留胡须。 -1：未识别。|
|++glass|false|Int32|戴眼镜： 0：太阳镜。 1：不戴眼镜。 2：戴眼镜。 -1：未识别。|
|++hat|false|Int32|戴帽子： 0：不戴帽子。 1：戴帽子。 -1：未识别，当前版本不支持戴帽子。|
