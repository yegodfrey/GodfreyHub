# MemBufferExportFile

#### 接口定义

```
AIStatus MemBufferExportFile(MemBuffer* membuf, const uint32_t pbuildSize, const std::string pbuildPath);
```

#### 功能介绍

将buffer里的模型导出到文件。  

#### 参数

|名称|类型|描述|
|:---------|:-------------|:---------------|
|membuf|MemBuffer\*|存储离线模型信息内存指针。|
|pbuildSize|const uint32_t|离线模型大小（单位：byte）。|
|pbuildPath|const string|离线模型导出文件存储路径。|

#### 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|
