# MLObject

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.objects.MLObject 对象属性类，表示由对象分析器(MLObjectAnalyzer)检测到的对象，对象的属性包括： * 对象分类（包括：家具、货物、食物、地点、植物、人脸和其他分类）。 * 对象边界框，表示图片中的对象位置。 * 对象ID，用整数表示，视频流模式下，每个被检测到的对象都会有一个ID，图片模式下，此ID为空。 * 检测结果置信度，取值0.0-1.0，越大越可信，当对象被归类为其他分类（TYPE_OTHER）时，该属性为空。|
