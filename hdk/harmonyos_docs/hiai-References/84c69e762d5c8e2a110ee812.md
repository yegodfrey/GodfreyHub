#### speak(String text, int mode)

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String speak(String text, int mode) 实时语音合成并播放API。 * 清空模式（QUEUE_FLUSH）：立即停止正在进行的语音合成任务以及播放，并清空正在排队的语音合成任务，立即执行此次语音合成任务并播放。 注意： 排队模式和清空模式二者选其一，如果都选清空模式会覆盖排队模式 * 实时流输出模式（OPEN_STREAM）：将文本合成的语音数据流通过[onAudioAvailable](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ttscallback-harmonyos-0000001247878189#section18852205617712)回调输出。即音频流在往内部播放器发送的时候，同时拷贝了一份透传给App。 * 外部播放模式（EXTERNAL_PLAYBACK）：屏蔽内部自带播放器播放音频的能力，同时将文本合成的语音数据流通过[onAudioAvailable](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/ttscallback-harmonyos-0000001247878189#section18852205617712)回调输出。此时回调接口中播放相关回调接口将会失效，仅能监听语音合成相关回调接口。|

Parameters  

|Name|Description|
|:---|:-------------------------------------------------------------------------|
|text|传入待转语音的文本，文本长度最大500字符，即text.length()不能大于500，text文本编码格式为UTF-8。|
|mode|语音合成任务播放模式。当前有四种类型：QUEUE_APPEND、QUEUE_FLUSH、OPEN_STREAM、EXTERNAL_PLAYBACK。|

Returns  

|Type|Description|
|:-----|:-----------------|
|String|taskID 返回语音合成任务ID。|
