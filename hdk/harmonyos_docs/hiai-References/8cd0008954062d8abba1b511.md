# MLFaceAnalyzerSetting

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.face.MLFaceAnalyzerSetting 人脸分析配置器：用于设置人脸分析器的属性。 人脸分析器的属性包括： * 是否检测人脸关键点。 * 是否检测人脸轮廓。 * 是否检测面部特征和表情，例如"微笑"和"戴帽子"等。 * 设置分析器对速度/精度的偏好模式，用于选择执行面部检测时的精度或速度优先。 * 是否启用面部跟踪功能。 * 设置人脸最小占比阈值。 * 是否仅检测面积最大的人脸。|
