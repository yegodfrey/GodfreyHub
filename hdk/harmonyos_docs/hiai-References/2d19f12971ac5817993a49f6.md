# HasAttr

#### 接口定义

```
bool HasAttr(const string& name) const;
```

#### 功能介绍

判断是否有name对应名称的属性。  

#### 参数

|名称|输入/输出|类型|描述|
|:---|:----|:-------------|:----|
|name|输入|const string\&|属性名称。|

#### 返回

|类型|描述|
|:---|:---------------------------------------|
|bool|* true：有名称为name的属性。 * false：无名称为name的属性。|
