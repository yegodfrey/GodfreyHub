# Init(uint32_t batchCount)

#### 接口定义

```
AIStatus Init(uint32_t batchCount = 1);
```

#### 功能介绍

用于AippPara对象的初始化。  

#### 参数

|名称|类型|描述|
|:---------|:-------|:-----------------------------|
|batchCount|uint32_t|模型输入的batch大小，对应NCHW维度的N维，默认为1。|

#### 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
