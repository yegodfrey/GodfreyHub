# AsrListener

|Interface Info|
|:------------------------------------------------------------------------------------------|
|public interface AsrListener 语音识别监听回调接口，通过回调可以知道识别引擎是否初始化，获取识别结果，获取音量的变化等，用户可以根据回调结果做相应的操作。|

|Qualifier and Type|Method Name|
|:-----------------|:------------------------------------------------------------------------------------------------------|
|void|[onInit](#section15754148155010)(Bundle params) 当终端初始化以便让用户开始讲话时调用。|
|void|[onBeginningOfSpeech](#section71371345184410)() 当用户开始讲话时调用。|
|void|[onRmsChanged](#section1560344774414)(float rmsdB) 音频流中的声级已更改。无法保证将调用此方法。|
|void|[onBufferReceived](#section6878153235610)(byte\[\] buffer) 收到了更多的声音。此功能的目的是允许向用户提供有关捕获音频的反馈。无法保证将调用此方法。|
|void|[onEndOfSpeech](#section53761648134418)() 在用户停止讲话后调用。|
