# Overview

ML Kit的图片商品检测API。能够通过图片或者相机拍摄自动识别物品，并将结果呈现给用户。

用户通过拍摄商品图片，在预先建立的商品图片库中在线检索同款或相似商品，返回相似商品ID和相关信息。当前支持10大类商品的搜索，包括：服装（上装、裙装、下装、内衣）、箱包、鞋子、数码家电、家居、玩具、美妆、配饰、食品、其它。
