# SetInputDims

## 接口定义

```screen
AIStatus SetInputDims(const std::vector<TensorDimension>& inputDims);
```

## 功能介绍

设置模型输入Shape。

## 参数

|名称|类型|描述|
|:--------|:----------------------------------|:----------------|
|inputDims|const std::vector<TensorDimension>&|输入Tensor的Shape信息。|

## 返回

|类型|描述|
|:-------|:-----------------------------|
|AIStatus|* AI_SUCCESS：设置成功。 * 其他值：设置失败。|
