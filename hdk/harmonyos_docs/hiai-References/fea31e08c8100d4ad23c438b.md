# Overview

ML Kit的卡证分析器实例工厂，可以创建不同卡证类别的分析器实例。

## Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
|[MLCardAnalyzerFactory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlcardanalyzerfactory-0000001050167502)|检测器工厂类，负责创建各种类型的检测器，内置默认的检测器配置，也允许指定不同类型检测器配置。|
