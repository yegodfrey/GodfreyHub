# 错误码

|错误码|值|描述|解决方法|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|:-|:-----------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|[INNER](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section19934251154718)|2|可能由以下场景导致： * agc文件配置错误。 * 网络原因导致的请求失败。 * 输入图片的格式规格不匹配。 * 获取指纹证书失败。|* [配置agc文件](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/add-appgallery-0000001050038080)。 * 检查网络连接。|
|[INACTIVE](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section3521439194710)|3|服务不可用。|检查是否可以正常访问Internet。|
|[ILLEGAL_PARAMETER](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section17921153094717)|5|参数非法。|检查设置的参数是否合法。|
|[AUTHENTICATION_REQUIRED](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section484114119468)|15|请求鉴权失败。|请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)进行配置。|
|[TOKEN_INVALID](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlexception-0000001050169383#section47861857181315)|19|Token失效或者Token非法。|请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)进行配置。|

若上述方式无法解决，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。
