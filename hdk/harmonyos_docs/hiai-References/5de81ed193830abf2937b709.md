# GetCropPara

#### 接口定义

```
AippCropPara GetCropPara(uint32_t batchIndex);
```

#### 功能介绍

获取AIPP参数中的Crop参数。  

#### 参数

|名称|类型|描述|
|:---------|:-------|:------------------------------------|
|batchIndex|uint32_t|batch下标，标识获取第几个batch中的Crop参数，取值需\>=0。|

#### 返回

|类型|描述|
|:---------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------|
|[AippCropPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aippcroppara-0000001291497277)|Crop参数，如果batchIndex超过了AippPara的batchCount，返回模型AippCropPara参数值。|
