# MLCompositeAnalyzer

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.common.MLCompositeAnalyzer 多类型分析器，继承自[MLAnalyzer](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlanalyzer-0000001050169371)，可集成多种类型的分析器，同时分析不同类型对象，如：在同一张图片上同时实现人脸检测和文字识别。|

Sample code：

```
// 创建多类型分析器的实例
MLCompositeAnalyzer analyzer = new MLCompositeAnalyzer.Creator()
.add(faceAnalyzer)
.add(objectAnalyzer)
.create();
// 根据多类型分析器实例创建LensEngine实例
LensEngine mLensEngine = new LensEngine.Creator(getAppContext(), analyzer)
.setLensType(LensEngine.BACK_LENS)
.applyDisplayDimension(640, 480)
.applyFps(30.0f)
.enableAutomaticFocus(true)
.create();
```
