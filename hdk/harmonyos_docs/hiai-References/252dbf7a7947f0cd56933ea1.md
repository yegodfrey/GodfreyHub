# MLImageSegmentationSetting.Factory

|Class Info|
|:---------------------------------------------------------------------------------------|
|com.huawei.hms.mlsdk.imgseg.MLImageSegmentationSetting.Factory 创建图像分割配置器的实例，用于设置图像分割的属性。|

Sample code：

```
MLImageSegmentationSetting settingoptions = new MLImageSegmentationSetting
              .Factory()
              .setExact(true)
              .setAnalyzerType(MLImageSegmentationSetting.IMAGE_SEG)
              .setScene(MLImageSegmentationScene.ALL)
              .create();
```

#### setScene(int scene)

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [MLImageSegmentationSetting.Factory](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mlimagesegmentationanalyzersf-0000001050169519) setScene(int scene) 设置返回结果种类，只有在MLImageSegmentationSetting.BODY_SEG模式下，此项配置才生效，MLImageSegmentationSetting.IMAGE_SEG模式下，返回结果中只包含像素级标记信息。支持设置MLImageSegmentationScene.ALL（返回所有分割结果，包括：像素级标记信息、背景透明的人像图和人像为白色，背景为黑色的灰度图），MLImageSegmentationScene.MASK_ONLY（只返回像素级标记信息），MLImageSegmentationScene.FOREGROUND_ONLY（只返回背景透明的人像图），MLImageSegmentationScene.GRAYSCALE_ONLY（只返回人像为白色，背景为黑色的灰度图）。|

Parameters  

|Name|Description|
|:----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|scene|用户选择返回结果种类。 * MLImageSegmentationScene.ALL(0)：返回所有分割结果，包括：像素级标记信息、背景透明的人像图和人像为白色，背景为黑色的灰度图。 * MLImageSegmentationScene.MASK_ONLY (1)：只返回像素级标记信息。 * MLImageSegmentationScene. FOREGROUND_ONLY (2)：只返回背景透明的人像图。 * MLImageSegmentationScene. GRAYSCALE_ONLY (3)：只返回人像为白色，背景为黑色的灰度图。|

Returns
