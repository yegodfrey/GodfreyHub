# SetName

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃。

## 接口定义

```screen
virtual void SetName(const std::string& name) = 0;
```

## 功能介绍

## 参数

|名称|类型|描述|
|:---|:-----------------|:----|
|name|const std::string&|模型名称。|
