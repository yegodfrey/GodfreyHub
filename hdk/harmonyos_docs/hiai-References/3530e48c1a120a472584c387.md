# HiAI_SingleOpTensorDesc_GetDimensionCount

#### 接口定义

```
size_t HiAI_SingleOpTensorDesc_GetDimensionCount(const HiAI_SingleOpTensorDesc* tensorDesc);
```

#### 功能介绍

用于获取指定HiAI_SingleOpTensorDesc对象的维度数量。  

#### 参数

|名称|类型|描述|
|:---------|:------------------------------|:---------------------------------------------|
|tensorDesc|const HiAI_SingleOpTensorDesc\*|指向HiAI_SingleOpTensorDesc对象的指针。该值不能为空指针，否则返回0。|

#### 返回

|类型|描述|
|:-----|:-------------------|
|size_t|张量的维度数量，如果执行失败，则返回0。|
