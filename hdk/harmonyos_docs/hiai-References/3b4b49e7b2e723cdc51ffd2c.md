# SetHeight

## 接口定义

```screen
void SetHeight(const uint32_t height);
```

## 功能介绍

设置输入Tensor高度。

## 参数

|名称|类型|描述|
|:-----|:-------------|:-------------|
|height|const uint32_t|模型输入Tensor的高度。|
