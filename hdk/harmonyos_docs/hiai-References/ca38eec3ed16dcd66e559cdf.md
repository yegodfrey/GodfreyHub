# RemoveValue

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[DelPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/delpara-0000001051490700)替代。

## 接口定义

```screen
void RemoveValue(const std::string& key);
```

## 功能介绍

删除指定参数。

## 参数

|名称|类型|描述|
|:--|:-----------------|:------|
|key|const std::string&|指定参数名称。|
