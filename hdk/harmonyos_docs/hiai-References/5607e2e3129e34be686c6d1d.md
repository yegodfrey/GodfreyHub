# MLModelInputOutputSettings.Factory

|Class Info|
|:-------------------------------------------------------------|
|MLModelInputOutputSettings.Factory 创建输入输出格式对象实例，用于输入输出格式对象的属性。|

**Sample code** **：**

```screen
MLModelInputOutputSettings setting = new MLModelInputOutputSettings
            .Factory()
            .setInputFormat(0, MLModelDataType.FLOAT32, new int[] {1, 3, 224, 224,})
            .setOutputFormat(0, MLModelDataType.FLOAT32, new int[] {1, 410})
            .create();
```
