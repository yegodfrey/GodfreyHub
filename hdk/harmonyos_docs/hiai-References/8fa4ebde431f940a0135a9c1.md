# FallBackMode

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150636.42954293095813968851931599634764:50001231000000:2800:82F1559B76448E83892A4A86D3CA0FB52C926910844ED391AA7F5691A7FFEFCA.png)  
此接口从DDK 5.0.1.0版本起废弃。  

|Enum Info|
|:---------------------------------------------|
|表示当用户设定模型级运行设备/算子级运行设备无法满足时，是否允许尝试异构到CPU上继续运行。|

|Enum Value and Description|Value|
|:-------------------------|:----|
|ENABLE 允许。|0|
|DISABLE 不允许。|1|
