# RestoreFromBuffer

> 说明
>
> 此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[ReadBinaryProto(void* data, uint32_t size)](https://developer.huawei.com/consumer/cn/doc/hiai-References/readbinary-void-0000001052889430)替代。

## 接口定义

```screen
virtual Status RestoreFromBuffer(const std::shared_ptr<IBuffer>& buffer) = 0;
```

## 功能介绍

从buffer中获取模型。

## 参数

|名称|类型|描述|
|:-----|:---------------------------------------------------------------------------------------------------------------------------------|:---------|
|buffer|const std::shared_ptr<[IBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/createlocalbuffer-0000001139126323)>&|模型的buffer。|

## 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
