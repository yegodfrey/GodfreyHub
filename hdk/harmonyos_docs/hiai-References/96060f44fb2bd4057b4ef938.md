# GetInputIndex

#### 接口定义

```
int32_t GetInputIndex();
```

#### 功能介绍

获取AIPP参数中的inputIndex参数，inputIndex参数用于标识AIPP配置参数作用于第几个模型输入。  

#### 返回

|类型|描述|
|:------|:------------|
|int32_t|inputIndex参数。|
