#### 接口定义

```
virtual const CustomModelData& GetCustomData() = 0;
```

#### 功能介绍

从模型中获取用户自定义数据。  

#### 返回

|类型|描述|
|:-----------------------------------------------------------------------------------------------------------------|:------------------------|
|[CustomModelData](https://developer.huawei.com/consumer/cn/doc/hiai-References/custommodeldata-0000001333300073)\&|返回模型中的自定义数据，包含type和value。|
