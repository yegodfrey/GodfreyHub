# HiAI_SingleOpTensorDesc_GetFormat

## 接口定义

```screen
HiAI_SingleOp_Format HiAI_SingleOpTensorDesc_GetFormat(const HiAI_SingleOpTensorDesc* tensorDesc);
```

## 功能介绍

用于获取指定HiAI_SingleOpTensorDesc对象的排布格式。

## 参数

|名称|类型|描述|
|:---------|:-----------------------------|:-------------------------------------------------------------------------|
|tensorDesc|const HiAI_SingleOpTensorDesc*|指向HiAI_SingleOpTensorDesc对象的指针。该值不能为空指针，否则返回HIAI_SINGLEOP_FORMAT_RESERVED。|

## 返回

|类型|描述|
|:-------------------------------------------------------------------------------------------------------------------------|:-------|
|[HiAI_SingleOp_Format](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleop-format-0000001890254506)|张量的排布格式。|
