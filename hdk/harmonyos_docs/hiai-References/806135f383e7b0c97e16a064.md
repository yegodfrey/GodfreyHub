# 使能计算能力增强

#### 接口定义

```
static bool Enable(void* env, void* context)
```

#### 功能介绍

使能计算能力增强，该接口的作用和调用请参见[NPU算子库动态升级集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/integration-0000001105764366)。  

#### 参数

|名称|类型|描述|
|:------|:-----|:-------------------|
|env|void\*|Android应用层JNIEnv对象。|
|context|void\*|Android应用层Context对象。|

#### 返回

|类型|描述|
|:---|:-------------------------------------------------|
|bool|* true：使能计算能力增强成功。 * false：使能计算能力增强失败，回退到CANN通用流程。|
