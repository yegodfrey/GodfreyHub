# SetDataType

#### 接口定义

```
void SetDataType(DataType dataType);
```

#### 功能介绍

设置TensorDesc所描述的Tensor的数据类型。  

#### 参数

|名称|输入/输出|类型|描述|
|:-------|:----|:-------------------------------------------------------------------------------------------------|:--------|
|dataType|输入|[DataType](https://developer.huawei.com/consumer/cn/doc/hiai-References/datatype-0000001333525105)|需设置的dt信息。|
