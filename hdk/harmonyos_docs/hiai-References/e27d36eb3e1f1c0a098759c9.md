# GetAllOpName

#### 接口定义

```
GraphErrCodeStatus GetAllOpName(std::vector<string>& opName) const;
```

#### 功能介绍

返回Graph中所有算子的名称。  

#### 参数

|名称|输入/输出|类型|描述|
|:-----|:----|:----------------------|:----------------|
|opName|输出|std::vector\<string\>\&|返回Graph中的所有算子的名称。|

#### 返回

|类型|描述|
|:-----------------|:------------------------------------------|
|GraphErrCodeStatus|* GRAPH_SUCCESS：操作成功。 * GRAPH_FAILED： 操作失败。|
