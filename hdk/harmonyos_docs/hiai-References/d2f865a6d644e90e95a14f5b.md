# SetPaddingPara(AippPaddingPara paddingPara)

#### 接口定义

```
AIStatus SetPaddingPara(AippPaddingPara paddingPara);
```

#### 功能介绍

设置AIPP Padding图片补边参数，为所有的batch设置相同的Padding参数。  

#### 参数

|名称|类型|描述|
|:----------|:---------------------------------------------------------------------------------------------------------------|:-------------|
|paddingPara|[AippPaddingPara](https://developer.huawei.com/consumer/cn/doc/hiai-References/aipppaddingpara-0000001283790237)|Padding图片补边参数。|

#### 返回

|类型|描述|
|:-------|:-------------------------|
|AIStatus|* AI_SUCCESS：成功。 * 其他值：失败。|
