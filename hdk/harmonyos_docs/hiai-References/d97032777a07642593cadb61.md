# BuildIRModel(ge::Model& irModel, ModelBufferData& output)

## 接口定义

```screen
bool BuildIRModel(ge::Model& irModel, ModelBufferData& output);
```

## 功能介绍

模型构建接口，输入模型对象，输出模型。

## 参数

|名称|输入/输出|类型|描述|
|:------|:----|:----------------------------------------------------------------------------------------------------------------|:-------|
|irModel|输入|ge::Model&|模型对象。|
|output|输出|[ModelBufferData](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbufferdata-0000001281245160)&|模型结构体对象。|

## 返回

|类型|描述|
|:---|:-----------------------------|
|bool|* true：构建模型成功。 * false：构建模型失败。|
