# HiAI_SingleOpDescriptor_Destroy

## 接口定义

```screen
void HiAI_SingleOpDescriptor_Destroy(HiAI_SingleOpDescriptor** opDesc);
```

## 功能介绍

用于释放HiAI_SingleOpDescriptor对象。

## 参数

|名称|类型|描述|
|:-----|:------------------------|:------------------------------------------------------------|
|opDesc|HiAI_SingleOpDescriptor**|指向HiAI_SingleOpDescriptor对象的二级指针。opDesc和*opDesc不能是空指针，否则销毁失败。|
