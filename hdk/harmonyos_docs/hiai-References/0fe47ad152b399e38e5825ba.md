# SetPlatformVersion

## 接口定义

```screen
void SetPlatformVersion(const std::string& version);
```

## 功能介绍

设置用户自定义模型的版本号。

## 参数

|名称↵|输入/输出|类型|描述|
|:------|:----|:-----------------|:-----------|
|version|输入|const std::string&|用户自定义模型的版本号。|
