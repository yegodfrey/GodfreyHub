# operator==

#### 接口定义

```
bool operator==(const Shape& other) const;
```

#### 功能介绍

重载"=="等于操作符。  

#### 参数

|名称|输入/输出|类型|描述|
|:----|:----|:------------|:-----------|
|other|输入|const Shape\&|操作数的const引用。|

#### 返回

|类型|描述|
|:---|:-------------------------------|
|bool|* true：判断结果为相等。 * false：判断结果为不等。|
