# Overview

ML Kit 提供的文本嵌入组件，核心API如下：

* MLTextEmbeddingAnalyzer：文本嵌入分析器。
* MLTextEmbeddingAnalyzerFactory：分析器工厂类，负责创建分析器。
* MLTextEmbeddingSetting：文本嵌入分析器的配置文件：用于配置文本嵌入分析器的属性。
* MLTextEmbeddingSetting.Factory：创建文本嵌入配置文件的实例。
* MLVocabularyVersion：词典信息实体类。
* MLTextEmbeddingException：文本嵌入异常状态封装类。
