# CheckCompatibility

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150628.64387259279315042965150001110917:50001231000000:2800:06B4E1959EE123CA32EC20CA9A9E3B028419F315BE5A54D06CC638040E90071B.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[CheckModelCompatibility](https://developer.huawei.com/consumer/cn/doc/hiai-References/checkmodel-0000001052609428)替代。  

#### 接口定义

```
virtual Status CheckCompatibility(bool& compatible) const = 0;
```

#### 功能介绍

对模型进行兼容性检查。  

#### 参数

|名称|类型|描述|
|:---------|:-----|:----------------------------|
|compatible|bool\&|是否兼容。 * true：兼容。 * false：不兼容。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
