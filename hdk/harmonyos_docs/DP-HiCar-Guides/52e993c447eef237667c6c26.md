# 集成认证

#### 新建车型

在车机申请审核通过后，点击车机卡片进入车机详情页，点击”+”新建车型。依次填写车型信息、开发计划、量产计划、委托测试机构等信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195004.28883472432402645182329843529203:50001231000000:2800:0995FA402026D2A873C33ADA7F85B2CC345683E3102B22B8AB9A9003FDB2E17B.png)![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195004.96810007446327074572550840403582:50001231000000:2800:E5DAA2ABC9B0D973A264886489BA90EB0AA9808BC07560B453FE901A778ADA09.png)

其中，关于验收测试方式请注意：

  * 首次验收测试：选择该方式后，可直接进入集成认证阶段。
  * 等效验收测试：仅当已有车型完成首次验收测试之后，才可以选择等效验收测试方式。选择等效验收测试方式之后，需要审核通过后才可以进入集成认证阶段。



更多关于验收测试方式的说明，请参见[验收测试介绍](https://device.harmonyos.com/cn/docs/devicepartner/DP-HiCar-Guides/overview-0000001099658348)。

#### 交互设计

通过车型卡片切换到“交互设计”页签，根据设计规范完成全量功能页面布局和交互流程设计，并将设计文件打包上传，提交审核。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195004.14972358088181073003789751386808:50001231000000:2800:28AAF467EFD6733D34BD6413B5455D84C9959D2EBD07CF26CE3651FBFE8869CE.png)

#### 集成开发

通过车型卡片切换到“集成开发”页签，可以下载日志工具、指导文档和SDK软件包。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195004.86173196125281172424289854882910:50001231000000:2800:AD1C00B65595EBD6561A2131354149C5779C2162C66954598292D50ECFE623B5.png)

集成开发和调测过程中，如果您遇到问题，或者对HiCar SDK软件包或指导文档有需求和优化建议，您可以：

  * 发送主题为“【HUAWEI HiCar SDK 需求/问题反馈-车型项目代号-合作申请方公司简称】”的邮件至 huaweihicar@huawei.com 及华为方技术接口人邮箱。
  * 通过“社区 > 论坛 > 其他版块 > 软件能力开放”版块发起讨论。您也可以在这里与志趣相投的开发者朋友分享经验和知识。
  * 对于需要分析日志的问题，请伙伴侧先进行初步分析和定界。**仅定界在需要华为侧配合分析的问题可通过CEPM系统提单，没有初步分析结论或没有按照提单规范填写信息的问题会被打回，请在CEPM上提交时提供完整车机日志、手机日志、SDK代码/日志分析工具结果，华为将在3日内反馈进展，反馈不完整的问题单华为将在7日内反馈。**
  * CEPM问题提单系统升级说明： 

A、自8/12日起仅允许已获得《HUAWEI HiCar集成开发伙伴者结课证书》的华为个人开发者账号提交问题单，您现有的权限将于8/12零点失效。

B、**如需获得提单权限，请您尽快在华为开发者学堂中完成考试并获取证书** （考试链接：<https://developer.huawei.com/consumer/cn/training/exam-home/101722242098586782> ）。

C、请伙伴侧接口人按以下邮件模板形式提交至 huaweihicar@huawei.com统一重新申请权限。

D、CEPM问题协同操作指导参考[CEPM问题协同操作指导.pdf](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195005.26926666775221549694706921265270:50001231000000:2800:F213B8A6628E5D562FF7182D33776D966FFD5B142A2DE333222C637CBCBB35C2.pdf?needInitFileName=true)。




#### 自测试

通过车型卡片切换到“自测试”页签，请按照自测试用例严格测试并提交测试报告。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195004.01616611701902141851893908970350:50001231000000:2800:D0C686B26727B40F784D53BF0FBBBB5056AF64B09F3BD9067A85B2C7D2D9C8E7.png)

#### 车型认证

完成“交互设计”、“集成开发”、“自测试”之后，在“自测试”环节提交预约后，自动进入到“车型认证”环节。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195004.01568080167037999060488447483058:50001231000000:2800:45017E72E9EB829E4842F85847CE7CB2F77449B5B7AD7143D076AE9E03CD7B99.png)

后续操作：

  * 页面显示【验收预约不通过】：验收预约被驳回，请查看具体原因，重新编辑预约信息后重新提交。
  * 页面显示【样机寄送】：验收预约通过，请按照要求寄送样机，并上传寄送清单及相关说明信息。
  * 页面显示【样机待签收】：样机寄送后，显示该状态。
  * 页面显示【委托测试机构样机签收异常】：委托测试机构并未正常收到样机，请根据界面信息处理。
  * 页面显示【车型验收通过】：验收测试通过后，页面显示该信息。
