# 支持的车型

已通过HUAWEI HiCar认证的前装车型和后装车载系统累计500+款。其他更多车型陆续接入中，敬请期待。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195006.04560484594419489606330837437616:50001231000000:2800:4B52BC75B9B83ABB40606F1DF62B89AC547C951B888515E5C557116CD30DA99E.png)

  1. HUAWEI HiCar在2020年及后续的新车型中作为标配或选配提供。部分制造商为旧款车型提供了软件更新服务。某些车型可能仅在特定配置下才支持HUAWEI HiCar，支持情况可能会有所变化，请联系经销商了解详情。
  2. 如您的车型不在支持车型清单中，可能由于该车型尚未完成HUAWEI HiCar认证，请联系经销商了解详情。
  3. 部分车型在上市更新后不再符合HUAWEI HiCar认证要求导致用户体验不佳，会被标识“重新认证中”字样。待车型重新认证完成之后，将会去除相关字样。
  4. 手机系统升级至HarmonyOS 5版本后，如需通过有线连接方式使用HUAWEI HiCar，请将手机系统升级至5.0.0.126 SP8及以上版本。
