# 合作准入申请  
  
#### 成为HUAWEI HiCar合作伙伴

请参考[成为合作伙伴](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/join-us-0000001134281535)，完成华为帐号注册与企业实名认证，并加入合作伙伴计划，成为HUAWEI HiCar汽车硬件合作伙伴。

#### 新建申请

  1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)，点击右上角“管理中心”，在左侧导航栏中，切换到“HUAWEI HiCar产品开发”。
  2. 单击“+”，新建一款车机。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195003.23489352422424464242803442597110:50001231000000:2800:D08A35E00104EDD487B06AC6A8BEAEA27696F41E4E4EB1E45A982CD749BA840A.png)

  3. 在“车机详情”页面完善“车机信息”和“附件信息”。

其中附件信息填写时，请注意：

     * 下载模板后填写上传。
     * 若车机操作系统为Linux，请在当前页面的“附件”区域上传《HUAWEI HiCar生态Linux版本HiCar SDK编译工具入库声明》。
     * 其它证书在合作准入阶段为非必填项，但需提前规划，确保认证阶段可以提供，以免影响认证进度。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195003.76969921409248292935800494451019:50001231000000:2800:F1829EDA5AC8965617736A5085158770086ED2130FFEEA8A273D061FA921B12E.png)

  4. 确保信息无误后，点击“提交申请”。
  5. 在弹出的联系人信息窗口中，完善联系人信息。建议填写项目经理、产品经理、认证/测试经理等联系人。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195003.11540059793775277964994313498811:50001231000000:2800:E1EFFCC21B9412263578A36FA8FB1C364E8A03C035B8C5507F153D44953EC627.png)

  6. 点击“确认”后，进入待审核页面。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195003.25147026042033006762647582416335:50001231000000:2800:8602A74D701CFD6C69617C48313BE4E9352DE65DFE5A622EB535413304EF31B1.png)




#### 后续处理

#### [h2]审核未通过

如果车机审核未通过，请查看备注、附件、审核记录和详情，重新编辑并提交。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195004.59295225883779259160768562410355:50001231000000:2800:9122E402A77C77B90B8A67A27ECEBA203993FBE4A68BB62A54AB3945312B0DBC.png)

#### [h2]审核通过

车机审核通过后，点击车机卡片，可以为该车机创建不同的车型，并进入集成认证阶段。详情请参见[集成认证](https://device.harmonyos.com/cn/docs/devicepartner/DP-HiCar-Guides/integration-and-certification)。
