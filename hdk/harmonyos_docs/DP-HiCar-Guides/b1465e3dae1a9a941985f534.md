# 准备工作

在进入开发和自测试环节之前，需要完成一系列准备工作，便于后续工作可以高效有序开展。

#### 学习视频课程并完成考试

请按照如下步骤完成视频课程权限申请。

  1. 登录[开发者联盟网站个人中心](https://developer.huawei.com/consumer/cn/personalcenter/myInfo/)，获取开发者ID。

a.登录账号需完成实名认证。

b.获取路径：个人中心-个人信息-开发者ID

**图1** 开发者ID  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195007.03702453638656806583737779384490:50001231000000:2800:B38AF2667DC7E516CCCE9E601CCBE1E6276ABAE1B9B82DE3EB89651E0775FB38.png)

  2. 发送邮件申请学习资源及考试权限。

邮件关键信息如下所示：

     * 邮件收件人：huaweihicar@huawei.com、对应华为BD和华为产品经理、华为项目经理
     * 邮件标题：**【HUAWEIHiCar赋能材料和考试权限开通】【公司名称】HUAWEI HiCar集成开发伙伴赋能**
     * 邮件内容：开发者ID信息。如为多人申请权限，可汇总后一并发送。发送内容请参考[线上定向赋能资料和考试权限—邮件反馈模板2025V1.xlsx](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195007.42904410899207595534631392510967:50001231000000:2800:512EE6B5FD9A616D9AF39EC75861CC53158AC61A51B94AC0302243D9B7290391.xlsx?needInitFileName=true)。

  3. 完成资源学习及通过考试，将考试通过后的结课证书保存在本地便于后续申请项目相关权限。

#### FAQ

问题：访问CEPM系统时提示403错误，如下图所示。该如何解决？

**图6** 403错误  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030195007.54018966435939389695613001151490:50001231000000:2800:2348F742B05067CBDDE93588A3C3F754CA8130180DC2402188E54D513DD393DB.png)

问题原因：未签署隐私协议时会出现403页面错误。

解决方法：请联系对应华为产品经理添加访问白名单后，访问[链接](https://workplace.cbgcpm.huawei.com/#/group/smart-selection/Issue_Collaboration_Main)签署隐私协议。
