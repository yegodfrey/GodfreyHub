# 对比度

按照**W3C** （**https://w3c.github.io/WCAG21-zh/index.html#non-text-content** ）对比度的定义，对比度范围为**1-21** 。

对比度表示两种颜色明度之间的差异程度，通常写为 **1:1** 或 **21:1** 。两个数之间的比值越高，颜色之间的相对明度差异就越大。
