# 工具栏

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221228180427.61877306273830011254026869080604:50531227102803:2800:C7E9C952BD566413EB409E5864F6F8A2330C3051333405909D7D7A7F0C569528.png?needInitFileName=true?needInitFileName=true)

#### 如何使用

工具栏在界面底部悬浮显示，用于展示针对当前界面的操作选项，当工具栏出现时默认获焦在第一个选项上，用户使用遥控器左右键切换不用的操作选项。工具栏最少支持一个操作按键，最多支持六个操作按键。

#### 界面写作规则

不要使用词组来命名工具栏的功能项，如“删除图片“请使用“删除“代替，“播放视频“请使用“播放“来表达指令。

图标的使用请遵循通用规则，确保寓意与文本一致，减少界面对用户产生的困惑。
