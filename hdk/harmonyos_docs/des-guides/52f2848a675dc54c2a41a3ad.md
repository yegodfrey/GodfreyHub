# 小型设备  
  
如果设备机身上可粘贴多功能码的平面尺寸小于多功能码最小尺寸(40mm)，请勿在机身上使用该多功能码。建议在产品说明书中介绍此功能，并将标签附在包装盒内，让用户根据自身需求选择位置粘贴。
