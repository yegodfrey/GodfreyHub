# 一致性

#### **唤醒一致**

在全场景下，所有的设备都可以通过说"小艺小艺"或者按压物理AI键来唤醒语音助手。

#### **应答反馈一致**

在不同的设备上，唤醒语音助手后，都需要给予应答反馈来提醒用户--语音助手已被唤醒。

语音助手的应答反馈不受设备形态的限制，需要保证一致性的体验，因此，在设计应答反馈时，需要遵循以下两点原则：

     * VUI 为主模态交互场景下（语音唤醒，语音优先设备）： 应答语+视觉反馈。注：应答语要控制在2个字以内，如"唉！" "在呢" "我在" "来了
     * GUI 为主模态交互场景（按键/触摸唤醒）： 提示音+视觉反馈

#### **视觉形象一致**

各设备上需要采用统一的小艺形象。

**视觉设计**

语音优先、交互一致、状态清晰和技能友好的总原则，在视觉设计上的体现为：

     * 在带屏设备上展示一致的关键元素和信息。
     * 为不同设备媒体的最优体验呈现不同的视觉样式。
     * 有明确的视觉状态和主次分明的界面布局。

**智慧形象的界面位置与视觉体量**
