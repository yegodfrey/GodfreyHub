# 内容加载

内容加载指获取内容并呈现出来。

#### 类型

     * 局部加载 
     * 上拉加载 
     * H5 界面加载 

#### 局部加载

界面内部分内容需要加载，分区域加载和数值加载 。

     * 区域加载：在需要加载区域内加载，不要弹框显示加载。 
     * 数值加载：数值暂未获取到的，显示“--”，全部数据获取到后，再显示数据。 

#### 上拉加载

在内容已刷新的页面，进行上拉加载更多内容的操作。使用应用有邮件、应用市场等。

     * 上拉加载：上拉时，屏幕下端区域显示加载动画（非模态）+ “正在加载…”。 
     * 加载完成：显示加载出的内容。 
     * 加载失败后的提示：“加载失败，点击重试”
