# 动效  
  
触发端(手机/折叠屏/平板)的动效请参照[HarmonyOS动效设计指南](https://developer.harmonyos.com/cn/docs/design/des-guides/overview-0000001158153643)。

对于带屏设备，当触发端进行设备连接流程时，带屏设备端需显示连接动效以提示用户设备正在进行连接。
