# 可滑动面板

可滑动面板是一种轻量的内容展示窗口。

#### 交互

可滑动面板可点击和滑动调整面板大小。

#### 点击

点击可滑动面板的控制柄可全屏和折叠态切换。

#### 滑动

双指滑动面板的控制柄可全屏、半屏和折叠态三种尺寸切换。

屏幕朗读播报三态：全屏、半屏、折叠。
