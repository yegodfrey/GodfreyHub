# 单选框

用于从多个互斥的选项中选择一项。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612120219.74223435356040603682624415391879:50001231000000:2800:8402395D9EF7103A428AC3E6BCBFE8187BD47E580BD3ECC363982949C5B31C5E.png?needInitFileName=true?needInitFileName=true)

#### 如何使用

     * 作为组合类控件，在列表中，多与文字进行组合出现，统一放右边。
     * 单选框主要用于单项选择，点击可选中或取消选中。
