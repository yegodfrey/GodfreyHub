# 进度条

用于显示内容加载或操作处理进度。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612120218.60379072222969230247059360619089:50001231000000:2800:C2B3C77816898CECA000B5A73C05F55883685F1ECC3327D0AB4936C821E63CDB.png?needInitFileName=true?needInitFileName=true)

#### 类型

     * 有明显进度
     * 无明显进度

#### [h2]有明显进度

     * 明显进度主要是通过文本说明当前操作，根据使用场景及执行任务的不同调整信息布局。
     * 线性进度相对圆形进度多样的布局方式，主要采用“上方文本 + 下方线形进度指示”形式。
     * **圆形进度：实时性进度显示**
