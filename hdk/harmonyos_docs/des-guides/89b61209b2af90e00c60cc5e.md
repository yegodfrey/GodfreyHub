# 间隔参数

本节对通用性的元素间隔进行了定义。主要元素有文本的边距，控件之间的上下左右间距，文本的间距，段落的间距等。

*[vp：中文全称虚拟像素，英文为 Virtual pixels，指一台设备针对应用而言所具有的虚拟尺寸](https://developer.harmonyos.com/cn/docs/design/des-guides/basic-0000001055539104)。

#### 间隔类型

     * 屏幕边缘间隔
     * 控件间隔
     * 文本间隔
