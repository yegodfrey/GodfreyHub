# 标题栏  
  
标题栏放在在界面顶部，用于呈现界面名称和操作入口。

**图标**

     1. 返回图标：点击返回到智慧生活 APP 首页；
     2. 更多图标：不常用的功能设置都应用放进“更多”中；
     3. 特性图标：可以是玩法、服务信息等，设备厂商可以根据推送内容进行定制，最多两个。

首先占位。当字符串变长时，字符串可自适应延伸；

**双行标题字符超长样式**

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163422.56322349527929746857405040437882:50521020090149:2800:6E4574425D519319569306057DD85E50F849638B2C91D87F801D3D306E470B0A.png?needInitFileName=true?needInitFileName=true)

首先占位。当字符串变长时，字符串可自适应延伸；

其次缩小文字。逐级缩小文本大小，主标题文本最小到14fp，辅助文本最小到10fp。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163422.76607667639990760539694726356069:50521020090149:2800:DABBFF9EB9257DD6FB6572D9E3D2DC8352C68033D897B91C6BFA0E264B2AFD3D.png?needInitFileName=true?needInitFileName=true)

再次换行，带副标题的标题栏，文本不支持换行;

最后截断，依然超长，采用“截断＋…”方式。
