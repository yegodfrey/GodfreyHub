# 隐私声明

隐私声明，即应用或原子化服务需收集用户的个人数据时，对用户（即数据主体）的告知。

隐私声明需包括以下信息：

     1. 数据控制者需提供数据控制者的身份信息和联系方式；
     2. 处理个人数据的目的；
     3. 个人数据的存储期限或决定存储期限的标准；
     4. 用户的访问、更正、清除，限制、拒绝、撤销等权利及细则；
     5. 自动化决策（包括识别分析、用户画像）及可能对用户造成的后果；
     6. 数据处理过程中包含的第三方 SDK ；
     7. 用户、应用或原子化服务所在地区法规要求提供的隐私保护信息。

**第三方 SDK 列表规则**

     1. 该列表用于告知用户，在应用程序中会使用哪些第三方 SDK 访问个人数据；
     2. 该列表的链接位于完整的隐私声明中，点击后跳转至独立页面；
     3. 开发者需要在此列表中展示出应用程序内使用到的所有第三方 SDK 及其使用目的、收集的数据类型、该 SDK 的隐私声明或开发指南（效果图仅供参考）；

**使用场景** ：

应用内隐私声明需考虑的 3 个场景：首次启动、更新提示、后期查看。

     1. **首次启动** ：首次启动获得用户同意后，应用才能开始运行。
     2. **更新提示** ：及时提醒各类声明的更新情况，用户同意后才可继续运行。
     3. **后期查看** ：需向用户提供可随时查看隐私声明或撤销用户协议的入口，通常情况下，入口位于关于或者设置页面底部。为满足相关法规对于操作步骤的要求，用户对协议或声明的撤销路径需要在应用开启后 4 步内完成。

**建议形式：**

隐私提示（如：启动页或其他位置提示用户了解隐私声明的弹框） + 隐私声明 + 用户选项（同意、拒绝等）

具体界面呈现样式由应用开发者自定义。
