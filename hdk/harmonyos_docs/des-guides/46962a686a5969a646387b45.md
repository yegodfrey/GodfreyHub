# 界面样式  
  
#### 控制面板

控制面板主要用于快捷控制的场景。当手机“碰一碰”未连接的设备时，会先展示设备连接弹窗，设备连接完成后，手机上即会展示控制面板。当手机“碰一碰”已连接的设备时，手机上即会直接展示控制面板。

**1.控制面板内容**

控制面板内容包括：设备图片、设备名+设备品牌名、功能控制区、“查看更多”按钮，所有内容都必选。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163415.52982175386241255392516316915835:50521020090149:2800:7F40D8B5B6CEBBA610D48FE2271AA885BF5416E7F50D402F6F5CCDD4B85B7B81.png?needInitFileName=true?needInitFileName=true)

**2.控制面板大小**

控制面板使用手机系统中可滑动的面板控件，可滑动面板有2个常用高度：默认尺寸（屏幕的2/3高度）、类全屏尺寸（最大高度=屏幕高度-信号栏-固定间距）。面板初始高度由功能区内容而定，最高不超过默认尺寸。面板展开高度也由功能区内容而定，最高不超过类全屏尺寸。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163415.14699111054973960370043388079481:50521020090149:2800:EE10F7D54D549D283EB084DCCD5789A22692A826EBBCA428B3369158D971EA6A.png?needInitFileName=true?needInitFileName=true)

**3.交互规则**

控制面板的高度根据面板内容自适应调整：

(1)内容较少的面板

面板内容较少时，不需要将面板展开。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163415.45841294772547785674448589453146:50521020090149:2800:C195B57B772D8FAF94FB17F8661E0FD1D23D27A0041069461CEDCB90D7CC73AD.png?needInitFileName=true?needInitFileName=true)

(2)内容较多的面板

面板内容较多时，拖动控制面板操作条，可将面板调至最大高度(非全屏)。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.39458615758793011795607080391514:50521020090149:2800:BCE08902A0E6F9C74C02DC4558943E045E36938F46EB0DD26BE20C196EE984C2.png?needInitFileName=true?needInitFileName=true)

面板达到最大高度后，支持滚动查看更多内容。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.84999210448786615844965636273964:50521020090149:2800:85D290DB8D96C256684E9E910440303332AD7C0D204766DB42053EFA37331BAA.png?needInitFileName=true?needInitFileName=true)

(3)跳转全屏

点击设备图片或面板底部的“查看更多”按钮，可进入设备全屏页面查看更多内容。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.68174806779723098742226227801555:50521020090149:2800:F8752D70F21537C6BD069585E9860D98A4E521542D6B5793652D2462EDB4BC89.png?needInitFileName=true?needInitFileName=true)

(4)退出

面板为默认高度时，下滑即可退出。面板为最大高度时，可点击操作条或下滑即可退出。灭屏、锁屏、点击面板以外区域不会退出面板。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.47560718253276829773693952190132:50521020090149:2800:7D7231C884D8B8A14D6A6B63570E2E2529FE5016DF1D2CDEEDCFE637C1D26485.png?needInitFileName=true?needInitFileName=true)

#### 主界面布局

在控制面板上点击“查看更多”后，即可跳转全屏的主界面布局。

设备控制主界面由设备展示区、实时状态栏、主控区、服务扩展区组成。通过明确的区域划分，帮助用户更好的理解设备功能，同时通过使用相同的页面框架，多种不同的设备具有一致的操作界面，帮助用户快速上手使用。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.26560314914155438024947909199090:50521020090149:2800:90FB3C3BB23CDC0FA9EB5BAE00449232C2405237050833278B58A936EB151605.png?needInitFileName=true?needInitFileName=true)

**1.****设备展示区**

设备展示区展示设备当前的运行状态，用户可以直观的获取设备的当前状态。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.87478887119230744083597265021423:50521020090149:2800:0988DC00080E25E4C7FE45B0067C45A6F59280BA523680DE8FA87BFDA355D4AE.png?needInitFileName=true?needInitFileName=true)

**2.实时状态栏**

实时状态栏展示设备当前的工作状态，并可进行设备的主要操作。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.20547691459363762547915642799712:50521020090149:2800:10A7E18FF5DD7C6CD611518EEFDFF69D7DE89A3E6DF0F637D2B74EAE18D77728.png?needInitFileName=true?needInitFileName=true)

**3.主控区**

主控区放置设备的控制功能，如设置颜色、设置温度、设置亮度、倒计时、定时等功能。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163416.38537898269370879807951356435204:50521020090149:2800:4C069614E2C184F56005ADC22980ED50F0035FF6A3E5A791EAB232C25772CAA5.png?needInitFileName=true?needInitFileName=true)

有服务扩展内容时，主控区最多展示 3 排功能，展示不下的功能将被收起。点击“展开更多”，即可查看被收起的功能。

主控区功能按使用频率和重要级别排序，使用频率和重要级别高的排在前面，设备厂商可根据用户习惯自定义顺序。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163417.04123554220979144053025749933454:50521020090149:2800:08C760D9AAA885ED2D98E6A14FF1BBE5C2931919727C05EB4A414F681DDF15F7.png?needInitFileName=true?needInitFileName=true)

**4.服务拓展区**

服务扩展区用于放置设备玩法、食谱、商品推荐等。
