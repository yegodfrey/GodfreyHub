# 滑动条  
  
用来快速调节设置值，如音量、亮度、色彩饱和度。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612120220.71560263009308437853170548183845:50001231000000:2800:301B4BE1A1BE8A7A3CD65735A27ECEF0F753911ADC6E0C7882FA3815E4FEB411.png?needInitFileName=true?needInitFileName=true)

#### 如何使用

     * 用于连续数值变化的调节（如音量、亮度）。整体控件独占界面；控件的任何区域均可连续滑动；上下图标区域支持点击，每次点击增减 5%。
     * 用于档位变化的调节（如字体大小）。整体控件独占界面；控件的任何区域均可连续滑动，每次滑动或滚动调节一个档位；上下图标区域支持点击，每次点击变化增减一个档位。
