# 设备展示

设备展示控件用于展示设备当前的运行状态，用户可以直观了解设备的当前状态。

**构成**

设备图片：由厂商根据设备提供，以商业摄影图片为主；

Logo 或文字：设备厂商公司 Logo 或名称。

**设备图片**

图片品质要求：均为正视实拍图，需有高光及反光, 边缘轮廓清晰，PNG 格式透明底。
