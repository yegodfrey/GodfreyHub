# 入口

对于已经连接的设备，用户可以通过多种入口来触发设备控制。

**1.碰一碰**

碰一碰已连接设备时，立即拉起控制面板进行快捷控制。无需再次进行设备连接。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163414.49601319585920999419958623976404:50521020090149:2800:0853BCE8429FED81E34DDB59A0DB6EEE9576353C137912FAD4132D16ED05E74C.png?needInitFileName=true?needInitFileName=true)

**2.控制中心**

从手机主屏幕右上角向下滑动，打开控制中心，即可使用已添加到控制中心的设备控制服务。点击此处的卡片，可进入设备全屏页面使用更多功能。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163415.42279374266258951908160438878367:50521020090149:2800:7515F19BF30AFB543F040D92E2BE0539EA669D16F94432A80B730250B4FE8B22.png?needInitFileName=true?needInitFileName=true)

**3\. 智慧生活App**

通过碰一碰、靠近、扫一扫连接成功或在智慧生活中完成连接的设备，即会自动在智慧生活中显示相应的服务。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211021163415.55779687449472629215558439227348:50521020090149:2800:0FCD1AA277BBF265D3361345563DCD14D117373272CC81F254208A0630301BE7.png?needInitFileName=true?needInitFileName=true)

**4.负一屏**

在手机负一屏可以添加智慧生活的卡片，将常用的设备服务显示在此卡片中，作为设备功能的快捷入口。
