# 气泡提示

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221228180428.45584695838725449481533396467105:50531227102803:2800:23DDFFA7E062F6043031BC53B4B53052D92AAE7E780818686D7B7A13E880B50D.png?needInitFileName=true?needInitFileName=true)

#### 如何使用

气泡提示是智慧屏上的一种轻量级提示控件，对界面中其他元素的影响较小，可用来作为界面引导或者指示说明。气泡提示在界面元素的上方或下方出现，由于智慧屏的整体尺寸较长，多数界面元素横排展示，且贴近屏幕边缘较多，故不允许在元素的左右展示气泡。气泡提示状态为长期显示，用户移动遥控器按键或点击返回则可以取消气泡的显示。如用户进入应用时已经展示过气泡，则再次进入时不再显示。

可以指定气泡的箭头在 X 轴的对应位置。
