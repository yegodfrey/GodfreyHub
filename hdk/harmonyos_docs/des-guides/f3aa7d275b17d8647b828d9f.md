# 系统图标

系统图标主要用于功能性引导、系统导航、栏目聚合以及状态指示。

#### 图标样式

在手机设备中，系统图标根据不同场景使用描边图形与填充图形两种样式，两种样式使用同一结构图形，使他们具有一致性的视觉体验。
