# 设计原则  
  
#### 平板操作分析

平板尺寸（大于 8 寸）较大无法单手握持，人因研究分析平板操作基本采用两种方式：

     * 一手握持，另一手操作：此时操作区域范围大，除握持方位易操作性一般外，大面积均为易操作区（分析如图）。
     * 平放或支架放置，点击操作：此时操作区域全屏无障碍。

综合分析，平板操作区对显示布局基本无操作难易的约束。

#### 平板设计原则

因为屏幕相对手机大且布局操作区不受限制的因素，而且可以给用户配比更多的配件操作，对平板建议如下设计原则：

     1. 需要考虑高效利用大尺寸屏幕，针对大尺寸屏幕优化界面结构，同时展示更多有效内容。
     2. 可以利用大屏幕的优势来同时完成多种任务，并且结合上下文来聚焦当前任务，提高生产力效率。
     3. 因为平板的输入方式更加多样，不同的操作方式特点需要在设计中考虑。例如手写笔、键盘、鼠标。触控板等多种交互方式，需要在设计中增加对于这些配件的控件设计等。

#### 输入方式

平板因为尺寸的大小的差异，平板的输入方式会更加多样，不同的操作方式特点需要在设计中考虑。例如手写笔、键盘、鼠标、触控板等多种交互方式，需要在设计中增加对于这些配件的控件设计等。详见[输入方式](https://developer.harmonyos.com/cn/docs/design/des-guides/hci-touch-based-0000001054007748)。
