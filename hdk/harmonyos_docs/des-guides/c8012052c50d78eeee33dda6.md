# 概述

在不同形态的设备上，语音对话设计会有一定的差异性呈现，但同时也需要确保体验上的一致性。

因此，本章节会从一致性、差异性、协同唤醒和内容分发等纬度来介绍华为全场景智能终端设备上的语音交互体验设计。
