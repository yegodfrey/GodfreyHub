# 典型案例总览

应用在折叠屏上适配显示时，有以下建议：

（1）页面采用的样式及交互结构应与页面内容和典型场景相匹配。

（2）在同一个应用内，或同一个操作流程中，界面样式应趋向于稳定一致的布局和交互结构，避免页面形式的频繁变化。

我们从一些常见的特征型场景入手，整理出比较适合于该场景的界面设计样式。应用开发者可以参考这些样例，结合自己应用的业务类型及具体的业务场景，进行折叠屏上的最佳界面适配和创新设计。
