# 色彩

色彩作为一种视觉语言，能够有效传达和引起情感共鸣。和谐一致的色彩搭配能够赋予应用界面足够的生动性，并提供用户视觉感官连续性体验。同时，充分理解不同色彩对用户产生的心理效应，合理的运用色彩有助于传达关键状态信息，提供即时的状态反馈以及呈现数据可视化的解决方式。至此我们针对智能穿戴整理了如下五种色彩类型，用于指导和规范色彩应用。

#### 类型

     * 系统色
     * 文本、图标、控件颜色
     * 多彩色板
     * 运动健康数据
     * 不透明度
