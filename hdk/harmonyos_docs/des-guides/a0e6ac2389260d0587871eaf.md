# 进度条

用于显示内容加载或操作处理进度。屏幕朗读需要把进度播报出来。

#### 有明显进度进度条

焦点停留在有明显进度条时需要实时播报进度。

例如应用市场下载应用，如果焦点停留在进度按钮，播报：等待下载，正在下载，下载 10%，50%，80%，安装中，安装完成（2 秒播报一次），单指双击即可打开应用。

焦点停留在无明显进度条只需播报一次即可。
