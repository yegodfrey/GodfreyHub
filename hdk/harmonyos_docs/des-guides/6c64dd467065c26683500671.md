# 概述

本规范用于指导华为全场景智能终端设备上语音交互设计体验，并为设计师和开发者提供清晰明了、简单易用的体验设计指导；依据本规范的语音交互设计，能够保障用户在全场景设备下一致的语音对话体验。

**核心价值**

**一个小艺，一个生态系统**

“小艺（Celia）”是语音助手在华为设备中的名字。小艺存在于各种设备中，可以回答用户的问题、控制家居设备、执行日常任务等；并且，小艺可以通过不同设备感知用户的使用场景，推荐用户可能需要的服务，使用户感到亲切、舒适和信任。

规范分为四个部分，如果你刚开始接触语音对话设计，建议从头开始阅读，以便完整了解华为全场景智能终端设备上AI设计的必要原则和关键体验指导。

**概要简介**

了解本规范的受众和基本目标以及使用方法。

**语音交互设计**

以手机为主，介绍语音交互的设计原则、交互架构、视觉元素以及角色和对话设计。

**多设备下的语音体验**

从一致性、差异性、协同唤醒和内容分发等维度介绍华为全场景智能终端设备上的语音交互体验设计。

**设计自查表**

提供AI设计中的经典案例、设计走查表和名词解释等供设计师和开发者查阅。
