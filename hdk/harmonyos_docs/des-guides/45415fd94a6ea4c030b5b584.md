# 分隔器

可用于列表或界面布局。使用分隔器包含两种类型：分隔条和分隔线。

分隔条用来将界面进行分组。分隔条可以和子标题一起使用，通过子标题告诉用户分组的内容是什么，子标题位于分隔条下方。

分隔线用来将界面元素隔开，使单个元素更加容易识别。

#### 类型

     * 分隔条
     * 分隔线

#### 如何使用

#### [h2]分隔条

     * 分隔页面中不同类型的内容。
     * 仅用于效率型界面。
     * 分隔条不能放在界面内容最上方。
