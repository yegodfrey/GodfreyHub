# 视觉风格

**智慧语音视觉形象**

随着 AI 人工智能的大潮涌入，用户对于智能产品的预期则包含更多的情感互动与智能化的元素。华为智慧语音助手迫切需要一个全新且统一的视觉形象，为用户建立情感连接的纽带。

**设计原则**

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230718142602.25253393139149905620214680934844:50001231000000:2800:B2B594F6577A8406FE3E7D21B4A56273B3CE1F24C79C11555A42DA53467C9643.png?needInitFileName=true?needInitFileName=true)

     * 清晰：减少歧义，帮助用户准确理解和使用产品
     * 一致：界面入口与操作方式一致，减轻用户的认知与记忆负荷，使界面操作符合直觉与预期，易于学习与使用
     * 高效：操作流程顺畅，轻松方便，智能
     * 美观：精心打磨颜色、质感、尺寸、图标等元素，让用户在使用界面时感觉愉悦舒畅。

理想情况下对话交互界面VUI能够让用户感觉到系统拥有“智能”，可以理解用户并使用同样的对话方式与用户进行交谈。但现实存在困难。设计团队进行了大体量的用户问卷以及用户倾向性调研。我们发现活泼、有趣、又可靠的性格形象是大多数用户所希望的。传统冷静、严肃的机械化形象并不受欢迎。

**智慧形象**

小艺形象的设计融合了年轻、科技、时尚三种不同的风格。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230718142602.47209402266158162343399667128961:50001231000000:2800:B0C4CF1D45382173EE7F87E80025A3194D52D484C4078CC3532E424B13DB051E.jpg?needInitFileName=true?needInitFileName=true)

**语音对话状态**

用户在不同的设备上唤醒语音助手，Avatar 静默、聆听、思考的状态清晰、一致，以帮助用户建立小艺的形象并形成统一的印象。

作为语音交互的入口图标，小艺的图标有两种颜色样式供选择。需要注意的是不管在什么界面使用该图标，应该确保有足够的对比度。不要使用除这两种以外的样式或颜色。

**应用图标**

作为语音助手的应用图标，将跟其它应用图标一起出现在桌面界面。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230718142602.83703406024000775168757140057187:50001231000000:2800:349E12791619D524C1D873EBBEB47E66AF9CD1437825EEE00431F3D628A36E3B.jpg?needInitFileName=true?needInitFileName=true)

**功能图标**

其他应用可以根据业务需要，在应用界面中增加语音交互的入口。为确保视觉界面协调，规范中提供线形与面形的图标，业务方可根据实际情况进行选择使用，以匹配应用界面的视觉设计风格。
