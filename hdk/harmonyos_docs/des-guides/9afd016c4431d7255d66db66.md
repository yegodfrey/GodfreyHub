# 插画

比起文字，插画可以用来表达更丰富的信息，通过视觉图像满足用户情感诉求的同时，更起到增强视觉冲击力和趣味性的作用。

HarmonyOS插画是友好的、令人愉悦的，容易被理解的。包含场景型和功能型两种类型。主要使用在以下场景：帮助引导页、启动页和欢迎页。
