# 异常提示

对系统或应用使用过程中出现的错误或风险进行提示。

#### 原则

     * 一致性：当智能手表与手机遭遇相同的异常场景，在设备能力范围内，处理机制与手机保持一致，界面图标、文字描述也应尽量与手机保持一致。
     * 及时性：当智能手表遭遇异常场景，需要及时告知用户，并清楚说明异常发生的原因以及可采取的解决方法。

#### 类型

     * 模态异常提示
     * 非模态异常提示

#### [h2]模态异常提示

模态异常提示使用完整的界面告诉用户异常信息，确保用户了解当前处境以及可执行的操作。常用的模态异常提示包含以下 3 种：

     * **界面仅结果告知，无法在当前界面直接发起刷新或重试**

#### [h2]非模态异常提示

非模态异常提示通常以轻量级关键信息呈现为主，不强制用户操作。根据使用场景主要包含以下两种非模态异常提示：

     * **前台应用提示**

首先：根据具体操作项或内容相结合的方式进行提醒。

其次：选用不打断用户当前操作的提示方式，使用**“** 即时反馈**”** 进行提示（例如：切换歌曲，格式不支持弹出提示）。

     * **后台应用提示**

后台进行的任务，若出现错误、异常或风险，使用消息通知，然后自动转移到通知栏显示。

异常情况，弹出消息通知进行提示。
