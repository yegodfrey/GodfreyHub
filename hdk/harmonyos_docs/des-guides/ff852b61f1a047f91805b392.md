# 滑动条

#### 如何使用

滑动条用于在播控界面控制内容的播放进度，在镜像控屏下可以通过触碰事件操作进度条。在智慧屏上滑动条本身不会获焦，通过遥控器的左右键进行拖拽进度的动作。
