# 弹出框

弹出框是一种模态窗口，在弹出框消失之前，用户无法操作其他界面内容，干扰性比较强。无障碍模式下，弹出框出现时焦点自动聚焦到弹出框。

#### 焦点顺序

弹出框弹出后一般焦点会聚焦到标题，然后到说明文本，最后聚焦到操作按钮。
