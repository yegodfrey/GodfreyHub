# 原子化服务

该标签可打印用于北向服务场景。比如：线下点单、商户海报、地铁广告等。

#### 使用原则

标签需贴在不小于标签尺寸规范规定空间的平面上，不得贴于曲面，不得弯曲、折叠标签。标签应贴于方便用户碰靠或扫描处。

#### 辅助信息

辅助信息是用于引导用户扫或碰码的文字描述。字串应保证简单易懂、描述准确。辅助信息放置位置应与标签有强相关性，如放置于标签的正下方。

以下为标准的辅助信息模版：“HarmonyOS手机碰一碰【描述服务相关功能】”。可在该描述下添加详细指引，引导用户打开手机的NFC功能，详细指引的描述可以为“控制中心中打开NFC”。
