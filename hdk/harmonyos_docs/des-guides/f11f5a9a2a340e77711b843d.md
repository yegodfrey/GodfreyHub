# 标题栏

标题栏布局在智能手表的界面顶部，用于呈现界面名称及指导操作入口。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612120214.51658783645550263695866689779938:50001231000000:2800:DC10A5D35B5BB048A8B28E4FE4775AE73812AD2BA26300CF73BE0C55059FA0DC.png?needInitFileName=true?needInitFileName=true)

#### 类型

     * 单行标题
     * 双行标题

#### [h2]单行标题

一般带标题的应用均使用单行标题。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612120215.21336021379491024451447420126902:50001231000000:2800:2B595CE4ADB2B994280FBEA7B39AE5D476B3D5209AB5B950C1BED0D7CECADF6D.png?needInitFileName=true?needInitFileName=true)

#### [h2]双行标题

副标题描述相关内容。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612120215.46774941568582661245966018558144:50001231000000:2800:BB8E9410DDE514CF38C364045E5570327D91E0A904EE64E0E102C15A897043BE.png?needInitFileName=true?needInitFileName=true)

#### 如何使用

     * 为保证用户路线的不迷失，对于应用的非空界面，进入时应该在顶部显示标题，尤其是多个层级的应用。
     * 特殊场景下，因为顶部空间的问题，允许一些应用不显示标题。
     * 空界面中，不显示标题，界面内以**“** 暂无**..."** 描述，如**“** 暂无闹钟**”** ，**“** 暂无联系人**”** 等。

#### 交互规则

     * 为更大程度呈现应用内容，一般情况下，标题栏随页面滑动不在顶部做固定占位，且滑动过程中标题不可获取其他范围焦点。
     * 切屏导航样式中的应用标题，不跟随手指滑动，而是进行单屏页面切换，例如活动记录。

#### 界面显示规则

     * 标题文字应尽量简短精悍，居中对齐排列。
     * 标题和进入该页面的上一级界面的功能选项名称保持一致。
     * 超长文本状态下可缩小字号，且最多显示 3 行，若仍超长则做单行跑马灯处理。
