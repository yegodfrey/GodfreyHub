# 多端协同交互定义  
  
#### 协同入口

多端协同入口有两种类型，不同入口对应的操作略有差异：

     * 智能推荐
     * 手动协同

#### [h2]智能推荐

系统根据场景和可用设备，主动推荐最适合的设备进行协同。

**原则**

     * 不干扰当前操作。
     * 方便操作，提升效率。
     * 符合用户场景。

**推荐气泡**

当检测到用户周围有更合适的设备时，当前设备上会出现推荐气泡，用户点击推荐气泡可以进行多端协同。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210602174613.88103656619678522852820758305888:50520601135357:2800:5E2C36C804EE4D9EE4CE58C3A69BC6F660D587CA05E4FB22DD424073ABA3824F.jpg?needInitFileName=true?needInitFileName=true)

例如当用户使用手机玩游戏时，系统监测到周边有智慧屏，为了提供更沉浸的游戏体验，系统会推荐用户将游戏协同到智慧屏上，而手机则作为遥控器进行游戏操控。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210602174613.22965145107094111147266150680780:50520601135357:2800:5C8957B78921026B806A00DB9F2365C1B2115587AB6418B23758D2A9E2E64034.png?needInitFileName=true?needInitFileName=true)

#### [h2]手动协同

提供应用内协同的入口，用户手动选择合适的设备进行协同。

**原则**

     * 符合场景
     * 明确表达含义

**流转图标**

一般情况下，多端协同使用流转图标作为手动发起的入口。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210602174614.02903469478677794346055938638962:50520601135357:2800:8C756AF62165B0030DF5FA71ACEB47AF5DE42E9CCF4E2B6D047BB6FC40CDBD37.jpg?needInitFileName=true?needInitFileName=true)

我们提供了多种图标颜色以适应不同的界面背景，并提供了在界面中如何放置流转图标的建议，详见[服务流转规范](https://developer.harmonyos.com/cn/docs/design/des-guides/service-hop-icon-0000001136140831)。

点击流转图标后，会拉起系统提供的流转面板进行设备的选择。在流转面板中，开发者需要提供图标、名称及标题。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210602174614.63555999025279454811413964259819:50520601135357:2800:1209BA9E2E7E07F3DFF16FEBFC7980E6B8C340C4171C6377B9AB86E91A20BA33.jpg?needInitFileName=true?needInitFileName=true)

**业务图标**

当应用跨设备的场景是应用当前功能的必要特性时采用业务图标入口，点击后显示设备选择列表。例如，K歌应用定义了多个手机作为麦克风唱歌的功能，命名为合唱，点击合唱图标可以进入选择其他手机麦克风的界面，添加其他设备的麦克风后可以为用户提供多手机合唱K歌的体验。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210602174614.60726026718764290503655709462210:50520601135357:2800:E24FCC1028D492F8F2C7258CE4D34BA5E73194DBBA392933C0FEB64E3697B586.png?needInitFileName=true?needInitFileName=true)

在使用业务图标的场景，点击业务图标后，应用需要显示设备选择列表进行设备的选择。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210602174614.16563070225753638778938538507712:50520601135357:2800:5DA735C0391D10EECBE592C5F3284C0CCA5097B028AF30CF174443F79A3E7C2D.png?needInitFileName=true?needInitFileName=true)

#### 协同控制

#### [h2]设备切换

多端协同中时，流转图标为点亮状态，再次点击图标，打开设备流转面板，可通过流转面板控制协同到其他设备。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210602174615.91615386843643580975806720805864:50520601135357:2800:164CA22D16A0269FB839651ED1F2862176F51D92094110D2FCFA30B45F840B16.png?needInitFileName=true?needInitFileName=true)

#### [h2]退出协同

在打开流转面板时，也可以通过点击“结束流转”按钮或者再次点击正在流转的设备以结束迁移，把任务拉回到原设备上。
