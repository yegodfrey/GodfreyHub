# 搜索框

#### 如何使用

搜索框是一种不可获焦的文本输入样式，此搜索框必须与键盘一同使用，且界面内必须出现可操作的键盘。

智慧屏提供的是递进式搜索模式，首次进入搜索界面后默认获焦在键盘上，通过点击键盘可显示对应的字符在搜索框内，同时右侧出现对应联想词和搜索结果。

搜索框的设计规格与[文本框](https://developer.harmonyos.com/cn/docs/design/des-guides/text-field-0000001052527852)一致。
