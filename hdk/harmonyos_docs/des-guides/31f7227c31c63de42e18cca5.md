# 设计原则

#### 概述

HarmonyOS 手机/折叠屏/平板设计指南用于指导系统/应用设计，确保给用户提供清晰一致、简单易用的使用体验，对齐设计语言，拉通体验设计的方向，帮助设计师统一设计品质。
