# 热区

热区大小为点击的识别区域，某些情景可能会与控件可视大小不一致（比如一些较小的控件）。手表空间有限，为保证点击的准确率，可点击区域建议 46*46vp 或以上，特殊场景单边应不小于 46vp。

#### 类型

     * 图标
     * 列表
     * 选择器：单选、多选、开关
     * 按钮：圆形按钮、弧形按钮、胶囊按钮、文本按钮
     * 标题 + 图标
