# Pattern  
  
我们定义了几类常用pattern。建议在相应的功能场景下使用这些模板，保证体验的一致性。

#### 新手指引

刚进入某界面时，通过新手指导引导用户使用不容易发现的功能，点击屏幕任何区域或导航键提示信息将消失。

#### 时间提示

实时状态栏上可以展示设定倒计时/预约信息，给用户传递明确的信息。

#### 故障提示

设备出现的异常/故障时，通过明显的故障提示告知用户，点击后跳转到故障解决说明页面。
