# 数据可视化  
  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221228180427.92755238630578087969813127734946:50531227102803:2800:17D813EDA9E9574827FE7D557B2E00AF663EE79695CDFB49EC511F14617DFDF7.png?needInitFileName=true?needInitFileName=true)

将传统数据转换成可视化的图形，把隐藏在数据中的信息以更加直观、友好、视觉化的方式直接展现于用户面前，提升用户获取数据信息的效率。

#### 类别

     * 进度类
     * 占比类

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221228180428.80962590024545652299488985316693:50531227102803:2800:5583CF11C5C3D2751F55C88459118614D7CFF45CB7DC7C0B92C5A9867E0B2CFB.png?needInitFileName=true?needInitFileName=true)

#### 如何使用

进度类分为加载进度类和实时进度类两种。

加载进度类，在数据无明显进度加载时使用，如获取网络数据时的加载。用于在用户操作完成后，提示当前界面还在运行中，目的是减缓用户等待中的焦虑感。

实时进度类，在数据有明显进度加载时使用，如安装包的下载。用于用户操作完成后，提示当前界面的实际进展。目的是给予用户进展的预期。

占比类适合在有多个数据总和时使用，可突出数据总和后各个数据的占比，从而突出表现各自份额。整个环形代表临界值（灰色部分），每个数据则分段截取环形，加起来为数据总和（彩色部分）。
