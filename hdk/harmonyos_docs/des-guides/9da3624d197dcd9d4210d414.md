# 色彩  
  
两个需要区分的颜色或相邻颜色，需要具有足够大的色彩差异（△**Euv >= 20 (ISO9421-307)**）。

无障碍的色板应该满足红色盲、绿色盲、蓝色盲的识别需求，可以通过模拟不同类似色彩缺陷的视觉效果，找到安全的色板。需要避免的色相：

纯红 **(100,0,0%)** 建议使用朱砂色**(80,40,0%)** 或橙色**(90,60,0%)** 代替。纯绿**(0,50,0%)** 会跟红色和棕色混淆，建议使用蓝绿色代替。亮绿色**(0,100,0%)** 会跟亮黄色**(100,100,0%)** 混淆，避免使用黄和绿中间的颜色。

对于色盲或看不到颜色差异的用户，除了颜色差异外还需要增加额外的提示元素（如文字、图形、声音等），以确保他们能接收到和正常人等量的信息。

色盲症分不同的类型（包括红绿色盲、蓝黄色盲和单色色盲）。对于重要的状态，可以同时使用多个视觉提示。如：使用下划线、指示符、图案或文本等元素来描述操作和内容。
