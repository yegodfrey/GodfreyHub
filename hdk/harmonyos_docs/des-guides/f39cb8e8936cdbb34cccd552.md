# 概述

HarmonyOS Connect标签用于通过了HarmonyOS Connect认证的三方设备产品及原子化服务，用户通过碰一碰、靠近或扫一扫该标签连接并控制设备或使用原子化服务。本文档用于指导厂商如何在不同场景下使用HarmonyOS Connect标签。

HarmonyOS Connect标签具有两种形态，一种为NFC标签，另一种为多功能码。NFC标签为物理打印标签，支持手机碰一碰或靠近使用相关服务。多功能码可以为物理打印的标签，支持手机碰一碰、靠近及扫一扫使用相应服务，也可以为屏幕上呈现的电子标签，支持扫一扫。
