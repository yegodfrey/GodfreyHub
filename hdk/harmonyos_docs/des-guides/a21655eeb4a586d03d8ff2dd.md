# 多选

用于内容项的选择，用户可以通过点击选择某项、多项或所有项。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230612120219.02637737173486247227683974561862:50001231000000:2800:4AD0801F38256B39C97240CC8620DC2B5845BED6BB071EE018A4BE69E74EFC11.png?needInitFileName=true?needInitFileName=true)

#### 如何使用

     * 作为组合类控件，在列表中，多与文字进行组合出现，统一放右边。
     * 多选可用于多项选择，点击可选中或取消选中。
