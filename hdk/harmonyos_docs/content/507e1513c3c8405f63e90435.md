# 3D软体<Scene3D>

## 功能概述

3D软体在3D实时渲染功能的基础上，增加软体功能，使用3D软体功能时，isPhysicalScene属性需设置为true，表示3D物理仿真场景。3D软体主题可结合传感器、用户交互，体验3D软体的实时互动，为用户提供3D空间感体验。
> 注意
>
> 1、软体个数：支持单个无骨骼动画软体，且暂不支持凹体自碰撞，出现自碰撞穿模情况需要设计师调整硬度值；
>
> 2、面片数：需要根据想要达到的渲染帧率控制
>
> * 面片数：14000，帧率：20fps
> * 面片数：10000，帧率：40fps
> * 面片数：5000，帧率：80fps
>
> 3、材质：
>
> * 支持pbr材质（基础颜色、粗糙度、法线、金属度）
> * 支持透明材质，不支持次表面散射
> * 贴图数量：1张自烘焙贴图
> * 贴图分辨率：512*512
>
> 4、光源：
>
> * 光源类型：点光源、方向光
> * 光源数量：1盏
>
> 5、3D软体相关物理仿真参数均可在AGPEditor工具中编辑和调试，调试完成后生成的模型文件中已经包含了相关仿真参数值，不需要在脚本中重复定义相关参数。Camera相机和Light光源同理，在AGPEditor可编辑的参数直接编辑保存即可，不需要在脚本中重复定义。
