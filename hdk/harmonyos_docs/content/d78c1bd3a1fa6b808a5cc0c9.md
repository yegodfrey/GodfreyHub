# 数据开放：生活事件感知<ScenarioElements>

## 功能概述

生活事件感知数据开放，可以获取到对应的生活事件感知数据分类是否有相关的通知消息，如：是否有短信通知。

使用生活事件感知数据开放能力时，首先，需要配置ScenarioElements标签，订阅相应的数据分类ID，然后，系统会将生活事件感知数据赋值给到全局变量#ScenarioElements.ID，该变量表示是否有当前数据分类相关的通知消息，1表示有，0表示没有。

## XML规范

```screen
<ScenarioElements categories="30000320,30000050,30000374,30000364" />
```

## 参数说明

|----------|------|------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**参数**|**类型**|**选项**|**注释**|
|categories|字符串|必填|需使用的生活事件感知数据分类（完整的服务分类列表详见[全局变量场景](https://developer.huawei.com/consumer/cn/doc/content/themes-engine-next-base-globalvar-0000002471235030)数据）以逗号分隔，如需要知道是否有航空客运和快递的通知，则填写 " 30000374,30000050"。默认为空，表示不使用任何生活事件感知数据分类。|

## 应用示例

示例：有通讯消息时，文本显示您有新消息待查看，无通讯消息时，文本展示暂无消息。

```screen
<?xml version="1.0" encoding="utf-8"?>
<Lockscreen frameRate="60" screenWidth="1080" version="1">
    <ScenarioElements categories="30000320,30000050,30000374,30000364" />
    <Group visibility="eq(#ScenarioElements.30000320,1)">
        <Text text="您有新消息待查看" />
    </Group>
    <Group visibility="eq(#ScenarioElements.30000320,0)">
        <Text text="暂无消息" />
    </Group>
</Lockscreen>
```
