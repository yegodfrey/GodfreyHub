# 资源上架规范

|-------------|----------------------------------|
|资源上架规范 \*资源画面涉及以下内容不可上架||
|相似资源|使用相似度高或相同素材的画面|
|相似资源|使用相似度高或相同样式的模板|
|低劣质画面 （无上架空间）|色彩单一：纯色或几个简单色块拼接的设计|
|低劣质画面 （无上架空间）|配色不佳：配色艳俗或颜色搭配呈现效果不佳|
|低劣质画面 （无上架空间）|画面单一：元素单一，内容单调，画面整体无设计|
|低劣质画面 （无上架空间）|画面杂乱：画面元素过多过杂，遮挡信息功能或功能信息显示不清晰|
|低劣质画面 （无上架空间）|画面低幼：适用于幼儿、低龄儿童的卡通图，简单绘制的画风幼稚的图片|
|低劣质画面 （无上架空间）|笔触简陋：笔法粗劣，元素形象设计潦草|
|低劣质画面 （无上架空间）|低质量图片：设计图及摄影图存在噪点、马赛克、清晰度低、高曝光等问题、|
|低劣质画面 （无上架空间）|非主流画面：非主流风格图片或文字|
