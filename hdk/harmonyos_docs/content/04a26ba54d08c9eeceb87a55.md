# 多分辨率机型适配（普通手机、平板、折叠屏）

为了使动态主题更好地适配不同分辨率的终端设备（普通手机、平板、折叠屏），引擎提供了以下多分辨率机型适配的方案：

[设计不同分辨率的脚本文件，以适配平板、折叠屏的不同状态](#section129052316616)

[背景等比缩放，居中裁剪，以适配同设备类型的不同机型](#section1141831673)

<br />

#### 设计不同分辨率的脚本文件，以适配平板、折叠屏的不同状态

场景描述：普通手机仅有一个状态，动态主题只需设计一个脚本文件即可。平板、折叠屏具有多个状态（平板横屏态/竖屏态、折叠态/展开横屏态/展开竖屏态），且不同状态下分辨率差别较大，无法通过一个脚本文件进行适配。

适配方案：设计不同分辨率的脚本文件，使动态主题在平板、折叠屏不同状态的分辨率下应用时，都能有比较好的显示效果。脚本文件命名为：屏幕高度_屏幕宽度_manifest.xml，同时每个脚本文件中的screenWidth参数需根据不同状态分辨率的宽赋值。

#### 背景等比缩放，居中裁剪，以适配同设备类型的不同机型

场景描述：普通手机、折叠屏、平板的不同机型分辨率有轻微差别，可能出现背景拉伸变形的问题。

适配方案：用于背景的标签（[图片\<Image\>](https://developer.huawei.com/consumer/cn/doc/content/image-0000001073948153)、[视频\<Video\>](https://developer.huawei.com/consumer/cn/doc/content/video-0000001073497817)、[流体动效\<FluidsView\>](https://developer.huawei.com/consumer/cn/doc/content/fluidsview-0000001194289627)和[视频桌面\<LiveWallpaper\>](https://developer.huawei.com/consumer/cn/doc/content/livewallpaper-0000001073967005)）通过使用特定参数值isBackground="true" 且 scaleType="center_crop"，实现背景等比缩放，居中裁剪的适配效果，使动态主题在同设备类型的不同机型上应用时，背景都不会拉伸变形。

<br />

#### 图片\<Image\>作为背景适配

适配方案：设置 isBackground="true"且scaleType="center_crop"。

* isBackground="true" 该图片作为背景图使用。

* scaleType="center_crop" 该图片等比缩放并居中充满整个屏幕，多余部分裁剪。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173442.78752918434735804860355119491352:50001231000000:2800:2146D5861C5A6CD9790665B84389B51CD7B4CCB2C983F51568EB10796BCF3733.png)  
详情请看[图片\<Image\>](https://developer.huawei.com/consumer/cn/doc/content/image-0000001073948153)。

```
     <!-- 该图片作为背景图使用，等比缩放并居中充满整个屏幕，多余部分裁剪-->
     <Image x="0" y="0" src="dong.jpg" scaleType="center_crop" isBackground="true"/>
```

<br />

#### 视频\<Video\>作为背景适配

适配方案：设置 isBackground="true"且scaleType="center_crop"。

* isBackground="true" 该视频作为背景使用。

* scaleType="center_crop" 该视频等比缩放并居中充满整个屏幕，多余部分裁剪。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173442.28863925405196011254446160408876:50001231000000:2800:421E6FAE918A60F244873351DD4F92D9A17452C3BB2E5DB5D65E13A7DD289177.png)  
详情请查看[视频\<Video\>](https://developer.huawei.com/consumer/cn/doc/content/video-0000001073497817)。

```
    <!--解决视频加载中出现黑屏问题，配置一个image在视频加载完成前显示，图片为视频第一帧，以实现比较平滑的过渡效果-->
    <Image  scaleType="center_crop" isBackground="true" src="video_first.png" />
    <!--该视频作为背景使用，等比缩放并居中充满整个屏幕，多余部分裁剪-->
    <Video name="js"  src="video.mp4" play="true" sound="1" looping="true" scaleType="center_crop" isBackground="true"/>
```

#### 流体动效\<FluidsView\>背景适配

适配方案：设置scaleType="center_crop"。

* scaleType="center_crop" 流体动效的背景图等比缩放并居中充满整个屏幕，多余部分裁剪。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173442.29809354852520592370046693558810:50001231000000:2800:9EB35031BD587148186918AC0A9E1A7165DB70F4F4305DCEA970C926ED028845.png)  
1. 如果在流体动效标签\<FluidsView\>的背景图之外，还使用了其他 \<Image\>作为背景，则\<FluidsView\>背景图和\<Image\>的缩放方式需保持一致。
2. 详情请查看[流体动效\<FluidsView\>](https://developer.huawei.com/consumer/cn/doc/content/fluidsview-0000001194289627)。

```
         <!--图片作为背景图使用，等比缩放并居中充满整个屏幕，多余部分裁剪-->
         <Image src="aaa2.png"  align="center"  scaleType="center_crop" isBackground="true"/>
         <!--<FluidsView>背景图和<Image>的缩放方式需保持一致-->
         <FluidsView scaleType="center_crop"  bgSrc="aaa1.png"  gravityRatio="" viscosity = "" color = "" waterAlpha=""	srcid="" persist="" waterAlphaThreshold="">
	     <CircleShape type="" radius="" xPosition="" yPosition=""/>
	     <PolygonShape type="" hx="" hy="" angle="" xPosition="" yPosition=""/>
         </FluidsView>
```

#### 视频桌面\<LiveWallpaper\>背景适配

适配方案：设置scaleType="center_crop"。

* scaleType="center_crop" 该视频作为桌面背景，等比缩放并居中充满整个屏幕，多余部分裁剪。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173442.74642702814399264445202822876706:50001231000000:2800:D2CF23985CF056680426D5D48525BC3B9EE558077B0F98C7BE596B1221B9DFBF.png)  
详情请查看[视频桌面\<LiveWallpaper\>](https://developer.huawei.com/consumer/cn/doc/content/livewallpaper-0000001073967005)。

```
        <LiveWallpaper version="1" frameRate="30" screenWidth="1080"  >
             <!--视频作为桌面背景，等比缩放并居中充满整个屏幕，多余部分裁剪-->
             <VideoWallpaper src="xianwanzi.mp4" timeSequences="0,10.5,20.9" haveVideoVoice="true" scaleType="center_crop"/>
        </LiveWallpaper>
```
