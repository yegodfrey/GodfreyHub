# 功能概述

表达式可用于绑定表盘图层上的各类数据（如日期、时间、电量、步数、心率等）、属性（如x坐标、y坐标、字号、颜色等）的变量值，并搭配上数学公式、函数运算、条件语句来定义表盘内容的变化方式。可以用来设计高自定义的、更动态的、数据变化感知的、更具创意的表盘内容。

![](https://media:801785297267244603 "点击放大")  
![](https://media:801785297267283604)  
用到了表达式的表盘仅在搭载穿戴鸿蒙HarmonyOS 7.0及以上版本的设备支持上表，系统版本低于 7.0的穿戴设备不兼容该能力。
