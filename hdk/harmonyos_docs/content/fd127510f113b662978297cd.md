# 样式自定义

## 功能介绍

**样式自定义** ：支持设计师为**背景** 、**时间** 和**日期**制作多个不同的自定义选项，然后将这些自定义选项自由组合起来，形成多个自定义样式。用户实际应用时，可自行切换组合好的自定义样式。
> 说明
>
> "样式自由组合"表盘与["颜色自由组合"表盘](https://developer.huawei.com/consumer/cn/doc/content/color-customize-0000001459125433)功能互斥，只能选择其中一种进行制作。例如：当制作了"样式自由组合"后，再切换到"颜色自由组合"，会提示"暂未达到使用该功能条件"。反之亦然。

## 常见问题

**1、提示"自定义样式未保存、请在图层区自有组合中进行保存"如何解决？**

Theme Studio提示：
