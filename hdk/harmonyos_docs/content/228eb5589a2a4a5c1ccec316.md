# 样式自定义

#### 功能介绍

样式自定义：支持设计师为背景、时间和日期制作多个不同的自定义选项，然后将这些自定义选项自由组合起来，形成多个自定义样式。用户实际应用时，可自行切换组合好的自定义样式。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142629.96219794818009002702478857617142:50001231000000:2800:9C36797D33B9922CE94FBAF512B784689E3CEF8A34701DF61BEF6F0BA370CA6D.png)  
"样式自定义"与["颜色自定义"](https://developer.huawei.com/consumer/cn/doc/content/color-customize-pro-0000001633687085)互斥，只能选择其中一种进行制作。例如：当制作了"样式自定义"后，再切换到"颜色自定义"，会提示"暂未达到使用该功能条件"。反之亦然。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142629.38553696882424671255707007778524:50001231000000:2800:C892EFC1CE466E4A15C9F674ADF6080668DD92E3FDC89FB5038867CDD019C346.png "点击放大")

<br />

样式自定义表盘示例：以下示例表盘中，背景制作了2个自定义选项，时间也制作了2个自定义选项，将它们自由组合为4个自定义样式，提供给用户切换。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142630.27265808702029645508439570965515:50001231000000:2800:2B34F27C53632E95FD5991399708A56CEF7E4EBC2AE81E47CDC8FCCEC03ECAE4.png "点击放大")

<br />

样式自定义表盘使用方法：长按表盘 \> 点击"设置" \> 上下滑动，切换样式。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142630.87253351881603318141015811021931:50001231000000:2800:5FCA48A3E1AAAEA488019B62B4E58B548E65F55C9DABF1FF238DF0A632B5ACE8.png "点击放大")

#### 相关问题

1、提示"自定义样式组合尚未保存"如何解决？

Theme Studio Pro提示：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142632.00141518890976045762007152236283:50001231000000:2800:AC4F9C5AC0188C0A18BABDA375F5945EC3E0B3FDF6F4AC739CFB4B379357349A.png "点击放大")

问题原因：自定义样式表盘需要对自定义样式的组合进行保存，以达到上表之后自由切换的效果。

Theme Studio Pro 解决方式：

1、点击"高级功能"\>![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142632.36053961826988036650539915308633:50001231000000:2800:6E108E1D9547CEA34D81DA0C5DE01489AEEBF21EE2CB5A6DA1DDE0865A26840E.png "点击放大")\>"创建新组合"。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142632.37439721303351735928199904607331:50001231000000:2800:750EDB61CDBB69EB9F551C9991BDEEBC83AA63A280894B41D01E01919E1D073D.png "点击放大")

2、选择背景/时间/日期中对应的自定义选项进行组合，点击"确定"，形成自定义样式。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142633.91106862905934272041937943513840:50001231000000:2800:8D9A28EC4C77C58A0B3111FFED8CAF2F3990663F9FBF93BB8E1703B731F79978.png "点击放大")

<br />

2、如何设置"默认"的自定义样式？

在当前自定义样式上右键，选择"设置为默认"。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142633.45857823875715299531180861161874:50001231000000:2800:37DC244D30E61D6E7CF2716B518FAD661BAAF70BF524752D551CA9F3E189D92F.png "点击放大")

<br />

3、自定义样式的校验信息在哪里？

工具将对每一个自定义样式进行规范校验。

自定义样式的校验信息显示在底部校验区，鼠标悬浮至自定义名称即可查看全部。
