# 制作示例

#### 创建作品

通过新建作品入口，选择支持表达式的规范版本，Watch系列用1.18.z，GT/Fit系列用2.18.z，手环Band系列暂不支持表达式。

![](https://media:801785297274267755 "点击放大")  
![](https://media:801785297274291756)  
在制作2.y规范版本的含表达式能力表盘时，由于穿戴设备的软硬能力限制，对表达式的使用也有限制：

1、整个表盘作品内，单个表达式的非空字符（不包含空格）长度不超过200字符；

2、整个表盘作品内，表达式的个数不超过12个，如果写满12个表达式，则单条表达式长度不超过80非空字符；

3、整个表盘作品内，表达式不含非空字符（不包含空格）总长度不超过1000字符；

#### 赋值型表达式操作说明

释义：顾名思义，通过数学函数搭配全局变量的运算，使得图层上带有数值的属性如位置的x，y坐标，可随着表达式运算一起动态变化，赋予一个可变的动态数值，在表上实现不一样的动态效果。

功能入口：在支持使用表达式的图层的属性栏中，鼠标点击属性栏后展示Tags按钮。

![](https://media:801785297274517758 "点击放大")

呈现方式：点击Tags按钮，在属性栏下方拉起固定大小悬浮面板。

面板布局：面板上方为表达式输入框，输入框下方区域展示支持表达式的全局变量和函数，支持滚轮下拉滑动，可直接点击变量会自动填写到上方输入框中。

![](https://media:801785297274743759 "点击放大")  
![](https://media:801785297274766760)  
表达式使用标识：如果当前图层控件使用了表达式，则在图层栏对该图层增加特定颜色的标识。

![](https://media:801785297274970761 "点击放大")  

#### 赋值型表达式制作案例

案例表盘设计理念：通过时间变化，让时钟高低位选图在y坐标轴上下摆动，实现数字漂浮拖动的动效。

![](https://media:801785297275002762 "点击放大")

表达式示例：60 \* sin((1000 \* (#hour \* 3600 + #minute \* 60 + #second) + #milli) \* 0.03 / 100 \* 2 \* 3.14)

表达式示例写法解释：

1、60 倍的正弦摆动值，让元素在±60°/±60 像素范围内平滑来回摆动；

2、1000 是放大系数，数值越大，摆动速度越快；

3、#hour \* 3600 + #minute \* 60 + #second) + #milli → 把小时、分钟、秒、毫秒全部换算成数值；

4、0.03是基础速度系数，/100用于微调减速，控制摆动的快慢节奏；

5、2 \* 3.14是一个完整圆的弧度值，正弦函数必须用弧度计算，这一步把时间转成标准圆周角度；

添加选图素材：【时间】→【时钟高位】→【批量替换】

![](https://media:801785297275124763 "点击放大")

添加表达式：【位置y】→【Tags面板】→【输入框】

![](https://media:801785297275229764 "点击放大")

效果预览：通过画布下方播放条播放按钮，实时预览动效。

![](https://media:801785297275342765 "点击放大")  

#### 枚举属性赋值

功能入口：在支持使用表达式的图层的属性栏中，带有枚举值的属性（文本数据的字体、颜色）的Tags按钮拉起面板。

呈现方式：唤起Tags面板，支持下拉选择枚举属性的目标值，表达式生效时会将当前属性枚举值变为目标值内的属性值。

![](https://media:801785297275470766 "点击放大")

表达式上限：最多允许使用12个表达式条件，如果创建超过12个会有校验提示。

![](https://media:801785297275598767 "点击放大")

![](https://media:801785297275702768 "点击放大")  

#### 替换素材表达式

功能入口：在属性栏中，有替换资源的入口。点击"+"可以展开批量替换资源的上传入口，展开状态下点击"+"则是增加一组替换资源的空位，至少需要先上传默认资源后，才能上传替换资源。

![](https://media:801785297275819769 "点击放大")

![](https://media:801785297275881770 "点击放大")

![](https://media:801785297275970771 "点击放大")

替换条件：通过条件判断表达式，来定义资源替换的条件，在生效的情况下会将当前图层资源替换为替换资源。

表达式示例：gt(#heart,80)

表达式示例写法解释：当心率变量#heart高于80的时候，将背景替换为当前上传的替换素材背景（点击画布左下角播放预览可以模拟表盘实时变化效果）。

![](https://media:801785297276045772 "点击放大")

替换资源组数上限：选图资源最多允许替换5组不同的资源，通过点击资源页签切换资源；序列帧、视频资源最多允许替换一组资源。

![](https://media:801785297276143773 "点击放大")  

#### 控制视频、单组序列帧动画开始/结束播放

功能入口：在属性栏中控制播放开始、播放停止表达式输入框。

控制逻辑：表达式生效时触发播放或停止，不生效时则触发反向的效果，两者仅能选择控制其一；只能在单组序列帧、视频的属性栏中有表达式播放启停控制。

![](https://media:801785297276222774 "点击放大")

表达式示例：gt(#heart,80)

表达式示例写法解释：当心率变量#heart高于80的时候，将背景层的序列帧动画播放出来，表达式用于控制序列帧动画播放，如果条件不满足，则不播放。

![](https://media:801785297276337775 "点击放大")  

#### 控制图层显隐性

功能入口：在的属性栏最下方有控制显隐性的入口

呈现方式：常驻，不填写则不控制显隐

表达式显隐控制逻辑：用于控制当前图层素材（单图、选图、视频、序列帧动画等）的隐藏或者显示，如果显隐控制输入了表达式，当表达式条件满足才展示，否则隐藏；如果没有填写，则不对图层做显隐控制，默认都是常态展示。

![](https://media:801785297276408776 "点击放大")

表达式显隐控制逻辑：用于控制当前图层素材（单图、选图、视频、序列帧动画等）的隐藏或者显示，如果显隐控制输入了表达式，当表达式条件满足才展示，否则隐藏；如果没有填写，则不对图层做显隐控制，默认都是常态展示。

表达式示例：gt(#heart,80)

表达式示例写法解释：当心率变量#heart高于80的时候，将背景层的序列帧动画展示出来，当心率未高于80时，序列帧动画则是隐藏在图层中，不展示，满足条件后以彩蛋形式展示给到表盘用户。
