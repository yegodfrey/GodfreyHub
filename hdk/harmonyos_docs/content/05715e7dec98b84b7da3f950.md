# 制作实例

## 说明

1. 下文以466*466分辨率为例进行演示，其他分辨率的制作方法类似，只是支持的能力集有一些差异，详见：
   * [466*466能力集](https://developer.huawei.com/consumer/cn/doc/content/466-capability-0000001881726154)
   * [390*390/454*454能力集](https://developer.huawei.com/consumer/cn/doc/content/454-capability-0000001580733885)
   * [280*456/336*480能力集](https://developer.huawei.com/consumer/cn/doc/content/280-capability-0000001592176765)
   * [194*368能力集](https://developer.huawei.com/consumer/cn/doc/content/194-capability-0000001591976781)
2. 466*466有两种制作模式：WATCH系列+GT系列（2.y.z）和WATCH系列（1.y.z）制作模式。两种制作模式支持不同的能力集，需点击【切类型】进行切换，详见制作模式切换。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142643.59321018737627619355845421681552:50001231000000:2800:00B6AE88ECEC0693AE2EA3625645C0405F1BFEDE63A0E70A4A9A2BA55FF8DA28.png "点击放大")

## 背景

### 单图

**通过单图控件，制作表盘静态背景。**

**切图准备** **：**

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142643.70183602176668043557767116623727:50001231000000:2800:6185FDA0B1A3A91090F24522EE5F1C818C0B2A5C3486F6F41B0CB0D01602231D.png "点击放大")
> 说明
>
> **切图说明：**
>
> * 背景避免白色像素过多，饱和度/亮度过高，否则会导致手表功耗过大，耗电量较快。Theme Studio支持亮度校验，亮度过高不可导出。
> * 设计背景时，静态元素尽量与背景融合以减少图层及图片大小。

**制作步骤：**

1. 添加"背景">"单图"控件。
2. 导入表盘背景图。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142643.48422596185600791447052682304541:50001231000000:2800:4B8A7AA3104A9C6E8244243C7240ED5F743C8D2859D40192ECD76C4044F79288.png "点击放大")

### 动图

**通过动图控件，上传动图资源，制作表盘动态背景。**

**动图准备：**

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142644.72748689167241339615523008037015:50001231000000:2800:AEE2FB6E5D3D776A4AC2FA986DD9864C2B9933ECD1909BC8E7AC3F9335157BF1.png)
> 说明
>
> **动图规格：**
>
> * 动图尺寸：466*466
> * 动图大小：≤10M
> * 动图时长：5-10s
> * 动图格式：GIF
> * 动图帧率：15-30帧/秒

**制作步骤：**

1. 添加"背景">"动图"控件。
2. 导入动图资源和动图预览图。

### 单组序列帧

**通过单组序列帧控件，上传单组序列帧资源，制作表盘动态背景。**

**单组序列帧准备：**

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142644.45105291659491662843085990975976:50001231000000:2800:B419D548562A6A3C98026DC4310E52E8372662F086B39348DA3AE37D4C220AB4.png "点击放大")
> 说明
>
> **单组序列帧规格：**
>
> * 单组序列帧帧数："WATCH系列+GT系列"须≤30帧，"WATCH系列"可>30帧
> * 单组序列帧单张大小：建议小于40KB
> * 单组序列帧格式：PNG
> * 单组序列帧每帧的尺寸大小必须保持一致
> * 单组序列帧尺寸："WATCH系列+GT系列"须≤200px*200px，"WATCH系列"可>200px*200px
> * 素材首尾能相接循环，不能有明显跳帧痕迹

**制作步骤：**

1. 选择"背景">"单组序列帧"控件，导入单组序列帧资源。 播放模式：单次播放：在表盘上序列帧只播放一次；循环播放：在表盘上循环播放不暂停。

   位置：单组序列帧在表盘中的位置。

   帧间隔：每帧与每帧的间隔时间。

   延时播放：在设置的时间过后，再播放序列帧。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142644.97189271023223004640699778210597:50001231000000:2800:C502D4E308D604F83393330496122FBF18722EC22FEA07ADBF85201442E92D1D.png "点击放大")
2. 检测单组序列帧播放是否流畅**。**

   **播放**：点击播放按钮，预览单组序列帧动效是否流畅。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142644.63626046452399792554055922522067:50001231000000:2800:FF5917F952F49713656639AC6ED84D17790FAB48F58667C388304515FAD38E68.png "点击放大")

时间一般有两种展示方式：模拟时钟和数字时钟。

## 熄屏表盘制作

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250710142652.24089682076686257977443239948213:50001231000000:2800:DFA2CEE4B7BBD0F29AF255AE452651A3C013AF8D8C5CFB0B89DE59CCCDB75122.png "点击放大")

默认为[亮屏表盘](https://developer.huawei.com/consumer/cn/doc/content/watch-face-introduction-0000001566918497#section0147798445)制作模式，点击【半亮模式】则切换到[熄屏表盘](https://developer.huawei.com/consumer/cn/doc/content/watch-face-introduction-0000001566918497#section2023216179448)制作模式。

**熄屏表盘要求：**

1. 图层数量不超过30层。
2. 序列帧、视频、GIF控件不可用。
3. 熄屏表盘不可以单独导出，必须与亮屏表盘一起导出。
4. 屏幕非黑像素点不超过整体屏幕面积的10%或20%，详见[分辨率与版本号](https://developer.huawei.com/consumer/cn/doc/content/resolution-version-0000001252603441#section1756815468317)。
5. 非黑像素点区域尽量分散，不要出现大块集中展示。任意200px*200px范围，非黑像素点占比不能超过60%。
