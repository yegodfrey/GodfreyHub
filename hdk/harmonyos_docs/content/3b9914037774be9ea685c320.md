# 脚本规范

1. 参数值的内容不能为空 描述：没有参数值的属性可以直接删除，如果声明了属性，该属性的值不能为空，否则会导致加载失败显示默认锁屏。

   错误示范：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173446.06339245749807374247337013775641:50001231000000:2800:8960CCBD5219F7A8895E549B4B7626CA03CA8F920007DDBD0943F1D3BCA3DC2F.png)

   图中visibility和h属性为空值，会导致引擎报错，请直接删除这两个属性或填充属性值。

   <br />

2. Lockscreen和Root等根标签写法不能有误 描述：根标签的编写必须依据文档中的描述，如果错误的编写会导致加载失败显示默认锁屏。

   正确示范：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173446.32700819080121334608141444519182:50001231000000:2800:8F5FD20F88980BB4D00F5C5CD663BACA8E06E7400423958F529474C98A324615.png)

   <br />

3. 文档中不支持表达式的字符串布尔值，属性只能为"true"和"false" 描述：对于不能使用expression的布尔值属性，注意写法为"true"和"false"其他的写法会导致加载错误显示默认锁屏。

   错误示范：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173446.15061516495227101967938548014106:50001231000000:2800:F5031F7049CA47B7CB564ED97B7CA824D500EC4D84C56582176100F92644DB91.png)

   <br />

4. 文档中没有明确支持表达式的数值类型，属性值只能为数字类型 描述：对于文档中约束是不支持表达式的数值类型的，参数值只能写为数字，写其他类型（例如字符串、表达式等）会加载错误显示默认锁屏。

   错误示范：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173446.59890394017312084945998023911645:50001231000000:2800:254FBBB7A5630A837431745A30FF12EFA5D158E8C3E569B511A0BF0068237BB2.png)

   图中time属性值为数值类型，不支持表达式，上图在数值属性中写入了表达式导致加载错误显示默认锁屏。

   <br />

5. 变速函数的属性值必须与文档中变速函数类型的字符串匹配 描述：使用变速函数需要参照文档，变速函数的具体的写法需要与文档保持一致，否则会导致加载失败显示默认锁屏。

   正确示范：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218173446.95391585315039829912689056951370:50001231000000:2800:5C3D6FF8904DB7C52CFD43632AE3F0A64F8FAB63A3F63AFBE11FBE8B60FBC9C2.png)

   <br />

6. 禁止使用特殊字符 描述：避免在文档中属性值使用特殊字符, \<（小于符号） \>（大于符号） \&（与符号） '（单引号） "（双引号），特殊字符会直接导致加载错误显示默认锁屏。

#### 与华为主题动态引擎（原掌酷引擎）差异部分

1. variable变量中的const常量属性，如果设置为true，则变量初始化后不可再改变。 建议：variable中的const属性为设置该变量为常量，在值初始化之后禁止该值再次改变，如果没有该需求，请勿设置variable的const属性或者设置const="false"。

   <br />

2. xsdVersion如果有值的话默认不持久化，如果无xsdVersion则默认持久化。 建议：由于默认持久化会导致部分不需要持久化的变量被存为变量，对于某些快速变化的变量会影响引擎性能。推荐不使用默认持久化，而通过显示声明按需持久化变量。

   <br />

3. 华为官方主题引擎与华为主题动态引擎（原掌酷引擎）差异化的新增标签、功能和属性，请按照开发文档中的描述开发。 建议：新增标签、功能和属性请按照开发文档中的描述进行开发。华为官方主题引擎标签和属性与其他引擎有些许差异，代码迁移时请根据开发规范进行检视。
