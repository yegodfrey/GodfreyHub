# 景深

## 功能介绍

**景深功能**：轻晃手表时，表盘上使用了景深功能的图层能够随着手表晃动，产生位移和景深，带来手表屏幕内有3D深度的视觉感受。

**景深表盘** **示例**：轻晃手表时，左上方的树叶、下方的老虎、草堆、花朵等图层就随着手表晃动，产生了位移和景深，带来生动有趣且富有互动性的动态效果。

## 制作实操

1. **新建表盘制作项目。**

   点击【+】，选择手表类型为【智能手表】，分辨率为【466 *466】，然后输入表盘英文名。点击【确认】后，即可新建一个表盘制作项目。

   当前仅智能系列支持制作"景深"表盘，图层的"景深效果"默认关闭。

   点击【切类型】，取消勾选【轻智能系列】，点击【确定】保存。此时图层的"景深效果"入口就会展示出来。

   > 在背景中添加图片资源时，该图片资源超出表盘圆形区域的部分会被裁剪。如果对该图片资源设置景深效果，则晃动手表图片位移时，可能会出现漏出黑色边缘的情况。因此，**如果设计中有超出表盘圆形区域的图片资源，并且想要为该图片设置景深效果，则该图片建议不添加在背景中，可以根据设计需要，添加在时间、日期或控件中**，这样超出表盘圆形区域的部分不会被裁剪，实现比较好的景深效果。

   > 4. 弧形图、视频、GIF控件不支持景深效果。
