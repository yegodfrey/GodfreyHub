# 视频下线

该接口可进行视频下线，仅已发布（status为2）的视频支持下线动作。

Scope：https://www.huawei.com/contentconnect/video

**请求地址**

POST /mosopenapi/v2/foruser/video/offline

**请求参数说明**

参数名称 | 参数类型 | 参数描述 | 参数示例 | 是否必须  
---|---|---|---|---  
upResourceId | string | UP主的id标识，upResourceId和tpUserCode不能同时为空。 | 492456389055106944 为/list/users接口获取的upInfos中的upResourceId。 | false  
tpUserCode | string | UP主的第三方标识，upResourceId和tpUserCode不能同时为空。 | hwvrmgjxmt | false  
contentId | string | 百花号视频id，contentId和tpVideoId不能同时为空。 | 592456389155106956 | false  
tpVideoId | string | 第三方视频标识，contentId和tpVideoId不能同时为空。 | video123456 | false  
  
**请求样例**
    
    {
      "upResourceId": "674482848291436800",
      "contentId": "844077628465060865"
    }

**响应参数**

无

**响应样例**
    
    {
      "data": [],
      "retCode": 0,
      "retMsg": "success"
    }
