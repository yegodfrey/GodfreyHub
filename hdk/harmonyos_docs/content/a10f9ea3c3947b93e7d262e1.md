# 1.0.20版本功能介绍（2021-5-29）

## 1. 版本特性

[AOD预览视频](#section3158181962916)

## 2. AOD预览视频

### 2.1 概述

为了更好地展示动态AOD的详情，引导用户购买下载，主题联盟提供上传动态AOD预览视频通道。上传后可以在主题App上展示视频，用户可预览效果。

### 2.2 预览视频规范

* 视频分辨率1080*1920px。
* MP4格式，编解码制式为H.264。
* 大小在20M以内，时长建议5s以内。
