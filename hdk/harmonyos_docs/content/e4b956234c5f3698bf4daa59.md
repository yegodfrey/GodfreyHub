# 3D实时渲染<Scene3D>

## 功能概述

3D实时渲染支持通过方向传感器、屏幕滑动展示3D模型不同角度的视角变化，让3D模型可以立体呈现。

**设计约束**

1. 不支持3D动态模型。

2. 最多支持3个3D模型。

3. 不可用于视图组。

4. 折叠屏展开态横屏和竖屏建议各写一个json。

5. 离轴渲染时贴合屏幕的面需要放置在xy0平面，如下图所示，物体平面口需要放置在0平面，离轴渲染的offset是基于0平面计算的。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/8s3R8QvTTzmuBByn60VEbw/zh-cn_image_0000002655404639.png?HW-CC-KV=V1&HW-CC-Date=20260924T094631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B7512DAB92880C60C2423DF19947987546164C521B6A51D4C694255021621F9)

**性能约束**

模型设计时建议模型面片数建议控制在5万以内，模型贴图大小建议控制在2千以内，模型贴图个数尽量通过sprite sheet优化至一个，如要提升其中某个点，建议相应的降低其他标准，不然可能存在性能问题（内存、功耗、帧率等）。

3D模型加载比较耗时，建议添加1s+的进场过渡动画（如视频、帧动画、垫底图等），为提升渲染性能，建议过渡动画渲染即将结束时再将3D组件置为可见，且3D组件出现的时候建议不要做其他的其他的动效。

3D模型内存占用比较大，主题包设计时需考虑整体内存需控制在350M以内，不同资源内存占用可参照以下计算：

1）图片占用内存大小（M）= 宽度（像素）×高度（像素）× 颜色深度（位）/ （8 × 1024 × 1024 ）

2）3M透明适配占用内存大小230M左右，2M透明适配占用内存大小170M左右

## XML规范

```screen
<Scene3D x="0" y="0" width="" height="" renderWidth="" renderHeight="" visibility="">
  <SceneModel3D name="" src="" visible=""/>
  <Camera3D name="" path="" projection="" positionX="" positionY="" positionZ="" fov=""/>
</Scene3D>
```

## 参数说明

**Scene3D**

|---------------|------|------|------------------------------------------------------------------|
|**参数**|**类型**|**选项**|**注释**|
|x|数值|选填|相对于屏幕左上角的x坐标，默认值为0。|
|y|数值|选填|相对于屏幕左上角的y坐标，默认值为0。|
|width|数值|选填|3D模型宽度，默认取虚拟屏幕宽高。|
|height|数值|选填|3D模型高度，默认取虚拟屏幕宽高。|
|renderWidth|数值|选填|渲染分辨率宽度（0~1），默认0.5|
|renderHeight|数值|选填|渲染分辨率高度（0~1），默认0.5|
|visibility|数值|选填|元素可见性，<=0 不可见 >0可见，true为可见，false为不可见，默认为1，支持表达式|
|sceneType|数值|选填|场景类型，默认为0，isPhysicalScene为true时，sceneType默认为1 0：实时渲染 1：刚体仿真 2：软体仿真|
|interactionMode|字符串|选填|仿真交互模式，支持摇晃、点击和滑动，默认为1，多种仿真交互模式以英文逗号分隔。 1：摇晃 2：点击（包括长按） 3：滑动|

**SceneModel3D**

|-------|------|------|-------------------|
|**参数**|**类型**|**选项**|**注释**|
|name|字符串|必填|区分不同模型，该值的唯一要求是不能重复|
|src|字符串|必填|3D模型资源路径|
|visible|数值|必填|模型是否可见，1可见，0不可见|

**Camera3D**

|----------------------|------|------|----------------------------------------------------------------------------------------------|
|**参数**|**类型**|**选项**|**注释**|
|name|字符串|必填|用于创建相机时作为相机名称参数|
|path|字符串|选填|模型中相机节点路径，未填入则创建一个相机|
|projection|数值|必填|投影方式，0：表示正交投影，1：表示透视投影，2：表示离轴投影|
|positionX|数值|选填|创建相机时，相机x轴初始位置，默认为0，不使用模型中相机时该值必填，使用模型中的相机时，该值不生效|
|positionY|数值|选填|创建相机时，相机y轴初始位置，默认为0，不使用模型中相机时该值必填，使用模型中的相机时，该值不生效|
|positionZ|数值|选填|创建相机时，相机z轴初始位置，默认为0.06m，不使用模型中相机时该值必填，使用模型中的相机时，该值不生效|
|fov|数值|选填|创建相机时，相机视场，默认为π/2，不使用模型中相机时该值必填，使用模型中的相机时，该值不生效|
|interactionMode|字符串|选填|相机交互模式，支持响应手指滑动和摇晃调整相机视角绕原点旋转，默认为不响应用户交互，当仿真场景以及相机投影方式为离轴投影时该参数不生效。 1：摇晃 2：滑动 多种相机交互模式以英文逗号分隔。|
|interactionSensitivity|数值|选填|交互响应灵敏度，仅interactionMode非0时生效，默认值20，取值范围0~100|
