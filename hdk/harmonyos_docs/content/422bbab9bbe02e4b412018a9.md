# Pura X主题设计指导及规范

Pura X主题就是一套用于改变Pura X手机界面视觉效果的元素集合，其中内屏包含熄屏显示、锁屏、桌面、图标、应用（含控制中心、通知中心、播控中心、音量条、文件夹、耳机弹窗、充电动效换肤）、百变卡片，外屏包含熄屏显示、锁屏和桌面。

## 3. 外屏（sub_screen）

### 3.1 熄屏显示（aod）

全屏熄屏显示是系统对锁屏壁纸进行压暗后的效果，无需设计师单独设计。

### 3.2 锁屏（lock）

**静态锁屏**

锁屏壁纸尺寸为：1440×1440px，格式为.jpg。

不同机型分辨率存在差异，桌面壁纸按等比缩放，居中裁剪。

### 3.4 预览文件（preview）

**封面图**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/wIQ9x9toSoCLp56FUziQmw/zh-cn_image_0000002472972392.png?HW-CC-KV=V1&HW-CC-Date=20260924T094631Z&HW-CC-Expire=31536000000&HW-CC-Sign=5B89115866DD68E377CCE81CB1EC437B1E78C6156022A88AE790EAE3CF0C9386 "点击放大")

说明：

1. 封面图为必做项。
2. 封面图尺寸为960 x 960 px，格式为jpg。
3. 顶部和底部80px的范围内，不允许出现任何内容，包括状态栏信息等。
4. 封面图所展示的内容应该与锁屏内容保持一致。

**详情图**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/JGOll5jETCmtLr8Lq0bjZA/zh-cn_image_0000002505293579.png?HW-CC-KV=V1&HW-CC-Date=20260924T094631Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD7FB75D3AD2885CA1FE8914EFB7F1813E89FAE37FCFC6F4C572667C1415700F)

说明：

1. 详情图为必做项。
2. 详情图尺寸为1440 x 1440 px，格式为jpg。
3. 详情图所展示的内容应该与手机的实际效果相同。
4. 详情图中熄屏显示、锁屏、桌面为必做，最多支持20张。
5. 上传主题联盟时，详情图需按熄屏显示、锁屏、桌面的顺序依次上传，主题商店将按上传的顺序进行展示。

**预览视频**

预览视频要求如下：

1. 预览视频为选做项。
2. 视频尺寸为：1440 × 1440px。
3. 视频格式为MP4，编解码制式要求为H.264/H.265，视频大小建议在15MB以内，时长建议在15秒以内。

为保证预览效果，请提供能循环播放的视频，确保首尾衔接部分流畅，不会出现画面跳动或者闪烁。
