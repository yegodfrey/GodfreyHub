# 命令：碰一碰长连接发送<CollaborationSendCommand>

## 功能概述

CollaborationSendCommand 是碰一碰协同框架中的发送消息命令能力，用于在长连接模式下主动向对端设备发送数据。该能力配合 CollaborationCommands 节点和 DataShare 节点使用，支持在锁屏和百变卡片场景下实现设备间持续的数据交互。

## 支持范围

**起始规范版本：**HarmonyOS 7.0

**是否平台特性：**否

|  |锁屏（Lockscreen）|桌面（Wallpaper）|一镜到底（LongTake）|百变卡片（Widget）|充电动效（ChargingSkin）|
|:---|:------------:|:-----------:|:------------:|:----------:|:----------------:|
|是否支持|√|x|x|x|x|
[**表1** **支持根标签**]

|  |直板机|折叠屏|平板|
|:---|:-:|:-:|:-:|
|是否支持|√|√|x|
[**表2** **支持设备类型**]

## XML规范

```screen
<CollaborationSendCommand name="connected_colSendMessage" dataName="dancingData"/>
```

## 参数说明

|--------|------|------|----------------------------------------------------------------------------------|
|**参数**|**类型**|**选项**|**注释**|
|name|字符串|必填|发送消息的命名名称，用于标识不同的发送消息操作|
|dataName|字符串|必填|发送接收的对应 DataShare 的 name 数据,必须与 CollaborationCommands 中定义的 DataShare 节点的 name 属性一致|
