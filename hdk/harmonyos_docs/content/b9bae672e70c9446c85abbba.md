# 内容上架流程

#### 1. 上架流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250620110715.14473849878259045578505615437490:50001231000000:2800:4D08DEB0ABF6A287C17005FB96AF58E9D3D17F017F74056DEB7D5BF68E91E2B9.png "点击放大")

1.1 开发者通过开发者联盟上传作品。

1.2 官方团队对作品质量与内容进行测试审核。

1.3 运营团队对作品的内容质量进一步审核。

1.4 作品质量与内容审核测试过关便可上架。  

#### 2. 角色

|角色|说明|
|:---|:-----------------------------|
|开发者|作品提供方，负责提供内容资源。|
|官方测试|官方的测试人员，负责对开发者上传的内容进行测试反馈。|
|运营审核|官方的审核团队，负责对开发者上传的内容进行初审、终审、上架。|
