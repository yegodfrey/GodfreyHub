# 单卡-大卡

**样例图：**

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251218103605.40206756390559080824201355471476:50001231000000:2800:FF954458865DB5D840E38C056F34581A1147058D9B2B941C965861E9932E852E.png)

**设计要求：**

详情图需设计**2张** ，包含**1张卡片效果图** 和**1张玩法说明图**。

卡片效果图展示卡片实际效果，卡片可展示的最大宽度为背景宽度的80%，卡片需上下左右居中，具体可参考下图示例。

玩法说明图展示卡片实际效果并对卡片玩法进行介绍。卡片可展示的最大宽度为背景宽度的80%，可展示最大高度为背景高度的80%，展示区域需上下左右居中，具体可参考下图示例。
