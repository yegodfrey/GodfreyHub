# 写法规范

|分类|表达式|释义|
|:---:|:-------------:|:--------------------------------------------------------------------------:|
|数学表达式|+|两个数相加，例如2+3结果为5|
|数学表达式|-|两个数相减，例如3-2结果为1|
|数学表达式|*|两个数相乘，例如3*2结果为6|
|数学表达式|/|两个数相除，例如3/2结果为1.5|
|数学表达式|%|两个数取模，例如3%2结果为1|
|关系表达式|eq(x,y)|条件判断，x是否与y相等，当x、y相等时，此表达式值为1，否则为0（x，y都可以为表达式，下同）|
|关系表达式|ne(x,y)|条件判断，x是否与y不相等，当x、y不相等时，此表达式值为1，否则为0|
|关系表达式|ge(x,y)|条件判断，x是否大于等于y，当x大于等于y时，此表达式值为1，否则为0|
|关系表达式|gt(x,y)|条件判断，x是否大于y，当x大于y时，此表达式值为1，否则为0|
|关系表达式|le(x,y)|条件判断，x是否小于等于y，当x小于等于y时，此表达式值为1，否则为0|
|关系表达式|lt(x,y)|条件判断，x是否小于y，当x小于y时，此表达式值为1，否则为0|
|关系表达式|isnull(x)|条件判断，是否变量没有值，如果没有值返回1，有值返回0。x为全局变量，用于判断绑定的变量是否查到数据，例如：isnull(#var)|
|关系表达式|not(x)|条件判断，x是否等于0，若等于0则返回1，如果不等于0则返回0|
|函数表达式|int(x)|舍弃掉小数部分，例如int(4.5)=4, int(-4.5)=-4|
|函数表达式|rand(x,y)|取0到1之间的随机数，返回值为float|
|函数表达式|int(rand()*a+b)|得到的是b到b+a之间的随机整数|
|函数表达式|sin(x)|三角函数正弦值，x为弧度值，返回sin(x)的值|
|函数表达式|cos(x)|三角函数余弦值，x为弧度值，返回cos(x)的值|
|函数表达式|asin(x)|反三角函数，当x为[-1, 1]时返回区间为[-pi/2，pi/2]的值，如果输入的绝对值超过1，返回的是0|
|函数表达式|acos(x)|反三角函数，当x为[-1, 1]时返回区间为[-pi/2，pi/2]的值，如果输入的绝对值超过1，返回的是0|
|函数表达式|tan(x)|正切值，返回x的正切值，当x的绝对值趋近pi/2的倍数可能因为精度问题导致不正常值|
|函数表达式|atan(x)|反正切值，返回x的反正切值|
|函数表达式|sqrt(x)|开平方函数，x为正数，如果输入x为负数则返回结果是0|
|函数表达式|abs(x)|返回一个数的绝对值|
|函数表达式|min(x, y)|返回x和y中的最小值|
|函数表达式|max(x, y)|返回x和y中的最大值|
|函数表达式|round(x)|对输入的值四舍五入取整。负数时，小数点后<=0.5时向右取整，小数部分>0.5，则向左取整，例如round(4.5)=5, round(-4.5)=-4|
|函数表达式|pow(x,y)|幂方函数，表示x的y次方的值，例如pow(2,3)=8|
|函数表达式|ceil(x)|用于对数值进行向上取整，即返回大于或等于该参数的最小整数。例如：ceil(2.3)=3，ceil(-2.3)=-2|
|函数表达式|floor(x)|用于对数值进行向下取整，即返回小于或等于该参数的最大整数。例如：floor(2.3)=2，floor(-2.3)=-3|
|函数表达式|cbrt(x)|开立方函数|
