# 网格化<MeshImage>

## 动效概述

网格化动效支持将输入图片划分为多个子网格区域，并在子网格区域中操作对应的局部图片：支持局部位移，旋转，缩放，水波荡漾效果和全局透明度变化。其中，位移、旋转、缩放可以与透明度组合使用，其他组合不支持。

## XML规范

```screen
<MeshImage mesh="" center_point="" sensor="" src="">  
    <!--位移-->  
    <Translation duration="" repeat="" delay="" factor="" values="" max_distance_x="" max_distance_y="" no_move_distance_x="" no_move_distance_y=""/>   
    <!--水波荡漾-->  
    <SinMotion a="" factor_k="" no_move_distance_x="" no_move_distance_y=""/>   
    <!--旋转-->  
    <Rotate duration="" repeat="" delay="" values="" no_move_distance_x="" no_move_distance_y=""/>   
    <!--缩放-->  
    <Scale duration="" repeat="" delay="" values="" no_move_distance_x="" no_move_distance_y=""/>   
    <!--透明度-->  
    <Alpha duration="" repeat="" delay="" values=""/>   
</MeshImage>  
```

* **MeshImage**

网格化动画标签，划分网格数量，设置网格中心点。

|参 数|类 型|选 项|注 释|
|:-----------|:--|:--|:-------------------------------------------------------------------------------------------------------------------|
|mesh|字符串|必填|用英文逗号分开的两个正整数，表示图片x,y轴上划分的网格数，如："20,20"表示图片x,y轴上分别划分20个网格。 x,y轴网格数取值范围为[2,屏幕宽度/高度的二分之一]的整数，且x,y轴网格数至少有一个大于等于2。|
|center_point|数值|选填|网格中心点编号，可指定具体数字。不设置时程序默认计算公式为：(int) (((meshX+ 1) * (meshY+ 1)) / 2 + 0.5）。如：mesh="6,6"，共划分为36个网格，共49个顶点，则第25个顶点为中心点。|
|sensor|字符串|选填|是否支持通过加速度传感器来控制网格化的位移、旋转.、缩放、透明度动效。true/false，默认为false。为true时，晃动手机触发动效开始。|
|src|字符串|必填|图片资源名称，支持变量，如@abc。|

* Translation：实现局部位移效果，详见[网格化-位移<MeshImage-Translation>](https://developer.huawei.com/consumer/cn/doc/content/meshimage-translation-0000001074502054)。
* SinMotion：实现局部水波荡漾效果，详见[网格化-水波纹<MeshImage-SinMotion>](https://developer.huawei.com/consumer/cn/doc/content/meshimage-sinmotion-0000001074662024)。
