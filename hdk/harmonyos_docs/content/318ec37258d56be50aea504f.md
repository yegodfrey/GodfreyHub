# 命令：碰一碰长连接断开<CollaborationDisconnectCommand>

## 功能概述

CollaborationDisconnectCommand 是碰一碰协同框架中的主动断开连接命令能力，用于在长连接模式下主动断开设备间的连接。该能力配合 CollaborationCommands 节点使用，支持在锁屏和百变卡片场景下实现主动断开连接功能。系统会对长连接的断开有兜底的处理，在锁屏灭屏时，会自动断开。
