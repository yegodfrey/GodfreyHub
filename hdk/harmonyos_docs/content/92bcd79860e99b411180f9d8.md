# 制作实例

## 说明

本章节以466*466分辨率作品为示例，466*466分辨率的设备类型支持两种规范版本："2.y"和"1.y"。关于版本号的介绍可以参考 [分辨率与版本号](https://developer.huawei.com/consumer/cn/doc/content/resolution-version-0000001252603441)。

两种规范版本支持不同的[能力集](https://developer.huawei.com/consumer/cn/doc/content/466-capability-0000001881726154)，请根据需要进行选择。

### 视频

**通过视频控件，上传视频资源，制作表盘动态背景。**当前466*466分辨率下的1.y/2.10规范版本，408*480分辨率下2.11规范版本可以使用视频素材。

**视频准备：**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dd/v3/15sbyHm_QuKpdpJCrbLRlQ/zh-cn_image_0000001633687177.png?HW-CC-KV=V1&HW-CC-Date=20260920T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=F418C8294C5BB0B7B4A4117D24E9F4510A960DB4351AA3C26F4DA858102FF5BA)
> 说明
>
> **Watch系列视频资源规格：**
>
> * 视频尺寸：466*466
> * 视频大小：≤10M
> * 视频时长：5-10s（不能少于1s）
> * 视频格式：mp4
> * 视频编码：H.264
> * 视频帧率：25-30帧
> * 最多可以添加3个视频
> * 建议素材首尾能相接循环，不能有明显跳帧痕迹
> * 视频不能带音频
>
> **Watch GT/FIT系列视频规格：**
>
> * 视频尺寸：466*466（GT）/ 408*480（FIT）
> * 视频大小：≤10M
> * 视频时长：1-5s（不能少于1s，建议3秒左右）
> * 视频格式：mp4
> * 视频编码：H.264
> * 视频帧率：视频格式要求 24帧，建议码率不超过6000
> * 最多可以添加1个视频
> * 视频不能带音频
> * 视频不能包含B帧（如需去除 B 帧，建议以下两种PR工具实现方式：在H.264格式下的导出高级设置内将关键帧距离配置为1，或者将编码设置里配置文件设置为"基线"）

### 单组序列帧

**通过单组序列帧控件，上传单组序列帧资源，制作表盘动态背景。**

**单组序列帧准备：**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/abHrRskfQMmvmRpZJrBf1Q/zh-cn_image_0000002563793328.png?HW-CC-KV=V1&HW-CC-Date=20260920T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=D9F2B630786A02575477E9D91D38B8D31DBA75C8F26ABBC61BC75CB0510B1E5B "点击放大")
> 说明
>
> **单组序列帧规格：**
>
> * 单组序列帧帧数："WATCH系列+GT系列+FIT系列"须≤30帧，"WATCH系列"可>30帧
> * 单组序列帧单张大小：建议小于40KB
> * 单组序列帧格式：PNG
> * 单组序列帧每帧的尺寸大小必须保持一致
> * 单组序列帧尺寸："WATCH系列+GT系列+FIT系列"规范版本为2.1时，须≤200px*200px，如规范版本为2.4及以上时，可>200px*200px；"WATCH系列"可>200px*200px
> * 素材首尾能相接循环，不能有明显跳帧痕迹

**制作步骤：**

1. 选择"背景">"单组序列帧"控件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b/v3/HgvBQlWTR9ORyLFReMB9Ww/zh-cn_image_0000002594231381.png?HW-CC-KV=V1&HW-CC-Date=20260920T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=2DA5571269E0AA436394E60CE4AF9CD341778DDD4498719D9998FF4B3C03106D "点击放大")

   播放模式：单次播放：在表盘上序列帧只播放一次；循环播放：在表盘上循环播放不暂停。

   帧间隔：每帧与每帧的间隔时间。

   播放延时：在设置的时间过后，再播放序列帧。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/XiGROc4KR7WFocYPcm7P0A/zh-cn_image_0000001633927185.png?HW-CC-KV=V1&HW-CC-Date=20260920T081231Z&HW-CC-Expire=31536000000&HW-CC-Sign=F6701DC8EDE6E61A51EB9769A6534EECD42660148EC67BA2BAE4BAB916228292 "点击放大")

## 熄屏模式制作

默认为全亮模式，点击切换至"熄屏模式"。

**熄屏模式要求：**

1. 图层数量不超过30层。
2. 序列帧、视频、GIF控件不可用。
3. 熄屏表盘不可以单独导出，必须与亮屏表盘一起导出。
4. 屏幕非黑像素点不超过整体屏幕面积的20%，详见[分辨率与版本号](https://developer.huawei.com/consumer/cn/doc/content/resolution-version-0000001252603441#section1756815468317)。
5. 非黑像素点区域尽量分散，不要出现大块集中展示。任意200px*200px范围，非黑像素点占比不能超过60%。
