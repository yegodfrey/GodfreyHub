# 平板主题设计指导及规范

平板主题就是一套用于改变平板界面视觉效果的元素集合，包含熄屏显示、锁屏、桌面、图标、应用（含控制中心、通知中心、播控中心、音量条、文件夹、耳机弹窗、充电动效换肤）、百变卡片。

## 1. 快速指引-必做设计项总计

|设计项||是否必做|
|:---|-------|:------------|
|熄屏显示|/|必做|
|锁屏|/|必做|
|桌面|/|必做|
|图标|/|必做（93个）|
|应用|控制中心|必做|
|应用|通知中心|必做|
|应用|播控中心|必做|
|应用|音量条|必做|
|应用|文件夹|必做|
|应用|充电动效换肤|必做|
|应用|耳机弹窗|必做|
|百变卡片|/|选做|
|预览文件|封面图|必做|
|预览文件|百变卡片封面图|仅当含百变卡片时，为必做。|
|预览文件|详情图|必做|
|预览文件|预览视频|必做|
[**表1**]

制作完主题后，各位创作者们可以根据[主题测试审核规范](https://developer.huawei.com/consumer/cn/doc/content/harmonyos5-theme-test-0000002318301165)进行自检测试。自检无误后可参考[内容上传指南](https://developer.huawei.com/consumer/cn/doc/content/uploadguide-0000001054359939)将主题包上传至主题联盟。

## 2. 平板与直板机主题规范差异点

|设计项||直板机|平板|
|:---|------|:--------------------|:------------------------------------------------|
|熄屏显示|/|规范一致||
|锁屏|/|设计1套锁屏样式|按平板横屏态、平板竖屏态设计2套锁屏样式|
|桌面|静态桌面|规范一致||
|桌面|可交互桌面|设计1套桌面样式|按平板横屏态、平板竖屏态设计2套桌面样式|
|桌面|视频桌面|提供1个视频文件，分辨率1080×2340|按平板横屏态(分辨率2560×1600)、平板竖屏态(分辨率1600×2560)提供2个视频文件|
|图标|/|规范一致||
|应用|控制中心|规范一致||
|应用|通知中心|规范一致||
|应用|播控中心|规范一致||
|应用|音量条|规范一致||
|应用|文件夹|规范一致||
|应用|耳机弹窗|规范一致||
|应用|充电动效换肤|设计1套充电动效换肤样式|按平板横屏态、平板竖屏态设计2套充电动效换肤样式|
|百变卡片|/|规范一致||
|预览文件|封面图|1张，分辨率960 x 1920|2张 横屏态：1张，分辨率1920 x 1280 竖屏态：1张，分辨率1280 x 1920|
|预览文件|详情图|不超过20张，分辨率1440 x 3120|横屏态不超过20张，分辨率3120 x 2080 竖屏态不超过20张，分辨率2080 x 3120|
|预览文件|预览视频|1个，分辨率1440 x 3120|2个 横屏态：1个，分辨率3120 x 2080 竖屏态：1个，分辨率2080 x 3120|
