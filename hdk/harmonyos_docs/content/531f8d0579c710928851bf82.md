# 数据开放：天气数据对象<WeatherObject>

## 功能概述

天气数据对象是在主题引擎中已经预定好的固定数据类型，可供在声明变量时使用。

## 支持范围

**起始规范版本：**HarmonyOS 7.0

**是否平台特性：**否

|  |锁屏（Lockscreen）|桌面（Wallpaper）|一镜到底（LongTake）|百变卡片（Widget）|充电动效（ChargingSkin）|
|:---|:------------:|:-----------:|:------------:|:----------:|:----------------:|
|是否支持|√|√|√|√|x|
[**表1** **支持根标签**]

|  |直板机|折叠屏|平板|
|:---|:-:|:-:|:-:|
|是否支持|√|√|√|
[**表2** **支持设备类型**]

## XML规范

```screen
<Weather>
    <Var name="Weather.weekly" type="WeatherObject[]"/>
</Weather>
```

## 参数说明

|--------------|------|------------------------------|
|**参数**|**类型**|**注释**|
|date|字符串|日期，固定格式为yyyy/mm/dd，默认值为空字符串|
|weatherIcon|数值|天气现象类型编号，详见：天气现象类型，默认值为0，表示未定义|
|weatherIconDes|字符串|天气现象类型描述，详见：天气现象类型，默认值为空字符串|
|aqivalue|数值|空气质量指数值：详见：空气质量类别，默认值为0，表示未定义|
|aqivaluetext|字符串|空气质量等级划分枚举值：详见：空气质量类别，默认值为空字符串|
|maxtemp|数值|最高温度，默认值为0|
|mintemp|数值|最低温度，默认值为0|

## 应用示例

**示例一：**文本展示一周的天气现象

    <Var name="w" const="true" expression="#screen_width"/>
    <Var name="h" const="true" expression="#screen_height"/>
    <Weather>
	<Var name="Weather.weekly" type="WeatherObject[]"/>
    </Weather>
