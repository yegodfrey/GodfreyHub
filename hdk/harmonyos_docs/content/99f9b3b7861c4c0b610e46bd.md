# HarmonyOS 5 百变卡片测试审核规范

|----|-----|----------------------------------------|
|检查项||详细描述|
|作品类型|单卡-中卡|仅含1张卡片|
|作品类型|单卡-中卡|卡片尺寸2\*4|
|作品类型|单卡-中卡|仅允许制作异形卡片|
|作品类型|单卡-中卡|设计风格和谐统一，设计精美，功能不限|
|作品类型|单卡-大卡|仅含1张卡片|
|作品类型|单卡-大卡|仅允许制作异形卡片|
|作品类型|单卡-大卡|卡片尺寸4\*4|
|作品类型|单卡-大卡|设计风格和谐统一，设计精美，功能不限|
|作品类型|卡片套装|卡片数量不少于4张，最多20张|
|作品类型|卡片套装|卡片尺寸不限|
|作品类型|卡片套装|设计风格和谐统一，设计精美，功能不限|
|功能验证||不允许将多个虚拟卡片组合在一张卡片上，以免误导最终用户。|
|功能验证||每张百变卡片设计的动效时长不允许连续超过15秒|
|功能验证||卡片添加到桌面后，功能与玩法说明一致。|
|功能验证||桌面-长按百变卡片组件-点击更多卡片-点击关闭，这个过程中，组件图案不能闪烁。|
|功能验证||不允许将多个虚拟卡片组合在一张卡片上，以免误导用户。|
|功能验证||每张百变卡片设计的动效时长不允许连续超过15秒。|
|功能卡片|时钟|能正确显示当前时间，且支持跳转到时钟APP|
|功能卡片|天气|必须包含当前天气、气象描述（多云，下雨等）、华为天气APP跳转|
|功能卡片|日历|至少包含当前一周内的日期情况，且支持华为日历APP跳转|
|功能卡片|音乐播放器|需要支持以下功能及信息显示：歌词、歌曲名、收藏功能、暂停/播放/上下首等播控功能|
|功能卡片|步数|支持今日步数显示，且支持华为运动健康APP跳转|
