# 详情图

详情图，用于主题市场的百变卡片详情页展示。

详情图为必做项，尺寸为1440×2160 px。  

|分类|数量|格式|图片规格|
|:----|:----|:--|:--------------------|
|单卡-中卡|2张|JPG|需要包含1张卡片效果图和1张玩法说明图|
|单卡-大卡|2张|JPG|需要包含1张卡片效果图和1张玩法说明图|
|卡片套装|不少于2张|JPG|至少包含1张卡片组合效果图和1张玩法说明图|
