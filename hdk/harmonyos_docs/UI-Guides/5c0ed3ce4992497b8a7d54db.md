# SDK数据安全说明  
  
#### SDK工作方式

移动端SDK需要在应用编译打包时，被加载在您的应用当中。

SDK会随着客户应用的调用而启动，不会自动启动，也不会在后台做任何额外动作。

#### SDK权限说明

SDK运行时，不会调用系统权限。

#### SDK收集数据

SDK不会收集用户数据。

#### SDK数据安全保护

SDK不会收集用户个人数据。
