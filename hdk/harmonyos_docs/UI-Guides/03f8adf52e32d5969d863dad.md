# 在HUAWEI DevEco Studio项目中集成SDK

#### 开发前准备

华为UI Engine是提供给应用开发者进行多设备UI开发的解决方案套餐，其提炼了常见的多端UI设计思路，提炼其中的公共能力，尽可能覆盖TOP频率的需求，解决布局、交互、元素拼装等需求。

华为UI Engine深度集成于HUAWEI DevEco Studio（华为IDE）开发工具中，开发者可以通过此IDE工具获取华为UI Engine所属控件能力，安装请选择1.0.6.1201及以上版本，建议用最新的版本。

#### 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

HUAWEI DevEco Studio目前处于Beta阶段，需要向华为申请试用权限。同时也期待您在使用过程中给我们反馈您宝贵的意见，我们将持续进行优化，提升您的使用体验。

在使用HUAWEI DevEco Studio进行应用开发前，您应该提前知道如何“获取Beta权限”和“获取技术支持”通道。

#### 获取Beta权限

您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。

     1. 访问[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
     2. 注册华为开发者联盟帐号，并点击右上角头像旁边的下拉图标，点击“立即前往实名认证”上传信息进行[实名认证](https://developer.huawei.com/consumer/cn/verified/enrollment)。
     3. 实名认证后，在开发者联盟网站中选择“开发 > 开发工具 > HUAWEI DevEco Studio”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210616101401.93119921689447760003366399168073:50520615084203:2800:07B6AC4384561965DC072D1E533756F395DC1654162AB300027A08C4AC8527AA.png?needInitFileName=true?needInitFileName=true)

     4. 点击“试用申请”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210616101401.27499374492641487825717591778115:50520615084203:2800:D3053DDB537EE21F475092380D2E52C84CCA4C7CA783325102AF2C08FB2C1E52.png?needInitFileName=true?needInitFileName=true)

     5. 点击“我要报名”，并填写报名信息后，提交给华为进行审核。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210616101401.75062979564238720640961684602002:50520615084203:2800:D0606829954D1A598F0CA34BC898DA02CB7F896C0795715E5005E48D8F607A7E.png?needInitFileName=true?needInitFileName=true)

提交申请后，华为将在三个工作日内对您的申请进行处理，并会及时通知您审批结果，请耐心等待。

#### 获取技术支持

您在使用HUAWEI DevEco Studio时，如果您有任何的问题或建议，都可以通过如下两种方式与我们取得联系。

     * 在线工单：登录华为开发者联盟，在菜单栏选择“支持 > 技术支持 > 在线提单”，进入在线提单页面，选择“HMS Capabilities & Tools > 开发工具 > HUAWEI DevEco Studio”提交工单。
     * 人工服务：您可以通过扫描如下二维码添加“华为DevEco小助手”，然后向我们的小助手进行反馈。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210616101401.55112020396927093978395919589135:50520615084203:2800:7A8EE7AB36743C7B248203DADA3C19C3535EA7A8C62A6A0604665067F66E6C8E.png?needInitFileName=true?needInitFileName=true)

#### 安装和配置HUAWEI DevEco Studio

获取Beta权限后，您就可以下载HUAWEI DevEco Studio软件进行开发了。

     1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
     2. 点击右上角““管理中心””，然后在““应用服务 > 开发服务””中，勾选“HUAWEI DevEco Studio”卡片，然后点击“关闭”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210616101401.61340733454622040053311296190959:50520615084203:2800:A9480D61A009D1D281D8E7268889FC84605A83E413DE53BCC968FDD94F7DED6B.png?needInitFileName=true?needInitFileName=true)

     3. 在开发服务中，点击“HUAWEI DevEco Studio”卡片，阅读和签署Beta保密协议。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210616101401.03587533437825320558443422444865:50520615084203:2800:ACE28D475643105E48C75186AF4EB5775818DD810A24697E1C5E2122BC8F7DD5.png?needInitFileName=true?needInitFileName=true)

     4. 下载HUAWEI DevEco Studio软件包。

软件包下载完成后，请参见[DevEco Studio使用指南](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/service-introduction-0000000000017290)中的[安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/install-0000001050028630)和[配置DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/config-guide-0000000000034467)完成环境的安装和配置。
