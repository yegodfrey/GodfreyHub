# 文件系统

文件系统提供了基于元服务和用户维度的独立存储空间，同时也为开发者提供了一套用于管理这些文件的操作接口。通过[has.getFileSystemManager](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-file-introduction#hasgetfilesystemmanager)可以获取到全局唯一的文件系统管理器，所有文件系统的管理操作通过[FileSystemManager](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-file-filesystem-manager)来调用。

沙箱大小：

* HarmonyOS SDK版本≥6.1.0(23)，沙箱大小为1G。

* HarmonyOS SDK版本\<6.1.0(23)，沙箱大小为200MB。

清理机制：

* 临时文件只在当前生命周期可用，关闭元服务会被清理，下次冷启动不可用。

* 本地存储在HAP包被卸载时清理。

沙箱已满对开发者影响：

当前元服务沙箱空间资源存在限制，当沙箱资源被耗尽时，涉及写入文件的相关API因文件无法写入而导致接口调用失败。
