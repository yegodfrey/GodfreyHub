# Image

图片对象。 由[Canvas.createImage](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-class#canvascreateimage)创建，可用于在Canvas中绘制图片。

起始版本： 2.0.2

属性：  

|名称|类型|只读|描述|
|:------|:-------|:-|:----------------|
|src|string|否|图片的URL。|
|width|number|是|图片的真实宽度。单位：px。|
|height|number|是|图片的真实高度。单位：px。|
|onload|function|否|图片加载完成时触发的回调函数。|
|onerror|function|否|图片加载发生错误时触发的回调函数。|
