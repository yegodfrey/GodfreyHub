# 激励视频广告

## has.createRewardedVideoAd

has.createRewardedVideoAd(Object object): RewardedVideoAd

创建激励视频广告实例。每次调用该方法创建都会返回一个全新的实例，激励视频广告实例不允许跨页面使用。

**起始版本：** 2.0.2

**参数：**

参数为Object对象，包括以下字段。

|参数|类型|默认值|必填|描述|
|:---------|:------|:----|:-|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|adUnitId|string|-|是|广告单元id。 如果仅调测广告，可使用测试广告位ID：testx9dtjwj8hp； 如果要接入正式广告，则需要申请正式的广告位ID。可在应用发布前进入[流量变现官网](https://developer.huawei.com/consumer/cn/monetize)，点击"开始变现"，登录[鲸鸿动能媒体服务平台](https://developer.huawei.com/consumer/cn/service/ads/publisher/html/index.html?lang=zh)进行申请，具体操作详情请参见[展示位创建](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/zhanshiweichuangjian-0000001132700049)。|
|isMute|boolean|false|否|广告视频播放是否静音。 -true：静音播放； -false：非静音播放。|
|customData|string|-|否|媒体自定义数据。用于服务端通知媒体服务器某位用户因为与激励视频广告互动而应予以奖励，从而规避欺骗的行为（不填则不会通知）。|
|userId|string|-|否|媒体自定义用户id。用于服务端通知媒体服务器某位用户因为与激励视频广告互动而应予以奖励，从而规避欺骗的行为（不填则不会通知）。|

**返回值**：

返回[RewardedVideoAd](#rewardedvideoad)实例对象。

**错误码信息：**

|错误码|错误信息|
|:-------|:-------------------|
|17000901|adId already exists.|

**示例：**

```js
const rewardedVideoAd = has.createRewardedVideoAd({
  adUnitId: 'testx9dtjwj8hp' // 此处的adUnitId仅供测试，请开发者更换为正式的广告id。
});
```

## RewardedVideoAd

激励视频广告实例。层级在开发者内容之上，默认隐藏，需要调用[RewardedVideoAd.show](#rewardedvideoadshow)将其显示。

### RewardedVideoAd.load

RewardedVideoAd.load(): Promise<void>

加载激励视频广告。

**起始版本：** 2.0.2

**错误码信息：**

|错误码|错误信息|
|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|101|context is undefined.|
|17000301|1. RewardedVideoAd load params invalid. 2. RewardedVideoAd load failed.|
|17000601|1. can't invoke load() while is showed. 2. loadAd error. 更多错误信息参考：[广告服务框架错误码](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-ads)|

**示例：**

```js
const rewardedVideoAd = has.createRewardedVideoAd({
  adUnitId: 'testx9dtjwj8hp' // 此处的adUnitId仅供测试，请开发者更换为正式的广告id。
});
rewardedVideoAd.load().then(() => {
  console.info('RewardedVideoAd load success');
}).catch((err) => {
  console.error('RewardedVideoAd load fail', err);
});
```

### RewardedVideoAd.show

RewardedVideoAd.show(): Promise<void>

显示激励视频广告。需要先调用[RewardedVideoAd.load](#rewardedvideoadload)加载激励视频广告。

**起始版本：** 2.0.2

**错误码信息：**

|错误码|错误信息|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|101|context is undefined.|
|17000401|1. RewardedVideoAd show params invalid 2. RewardedVideoAd show failed.|
|17000701|1. 当前正在播放激励视频广告或者插屏广告，不允许再次展示。2. showAd failed, should loadAd first. 3. showAd error.|
|17001004|1. registerPPSReceiver error. 2. createSubscriber failed. 更多错误信息参考：[广告服务框架错误码](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-ads)|

**示例：**

```js
const rewardedVideoAd = has.createRewardedVideoAd({
  adUnitId: 'testx9dtjwj8hp' // 此处的adUnitId仅供测试，请开发者更换为正式的广告id。
});
rewardedVideoAd.onLoad((res) => {
  console.info('RewardedVideoAd onLoad callback triggered');
  rewardedVideoAd.show().then(() => {
    console.info('RewardedVideoAd show success');
  }).catch((err) => {
    console.error('RewardedVideoAd show fail', err);
  });
  rewardedVideoAd.offLoad();
});
rewardedVideoAd.load();
```

**错误码信息：**


### RewardedVideoAd.onLoad

RewardedVideoAd.onLoad(function callback)

监听激励视频广告加载事件。

**起始版本：** 2.0.2

**参数：**

|参数|类型|必填|描述|
|:-------|:-------|:-|:---------------|
|callback|function|是|激励视频广告加载事件的监听函数。|

**示例：**

```js
const rewardedVideoAdOnLoadFn = function() {
  console.info('RewardedVideoAd onLoad callback triggered');
};
const rewardedVideoAd = has.createRewardedVideoAd({
  adUnitId: 'testx9dtjwj8hp' // 此处的adUnitId仅供测试，请开发者更换为正式的广告id。
});
rewardedVideoAd.onLoad(rewardedVideoAdOnLoadFn);
```

### RewardedVideoAd.offLoad

RewardedVideoAd.offLoad(function callback)

移除激励视频广告加载事件的监听函数。

**起始版本：** 2.0.2

**参数：**

|参数|类型|必填|描述|
|:-------|:-------|:-|:----------------------------------------------------------------------|
|callback|function|否|[RewardedVideoAd.onLoad](#rewardedvideoadonload)传入的监听函数，不传此参数则移除所有监听函数。|

**示例：**

```js
const rewardedVideoAdOnLoadFn = function() {
  console.info('RewardedVideoAd onLoad callback triggered');
};
const rewardedVideoAd = has.createRewardedVideoAd({
  adUnitId: 'testx9dtjwj8hp' // 此处的adUnitId仅供测试，请开发者更换为正式的广告id。
});
rewardedVideoAd.onLoad(rewardedVideoAdOnLoadFn);
rewardedVideoAd.offLoad(rewardedVideoAdOnLoadFn);
rewardedVideoAd.offLoad();
```

### RewardedVideoAd.onClose

RewardedVideoAd.onClose(function callback)

监听激励视频广告关闭事件。

**起始版本：** 2.0.2

**参数：**

|参数|类型|必填|描述|
|:-------|:-------|:-|:---------------|
|callback|function|是|激励视频广告关闭事件的监听函数。|

**返回值：**

|参数|类型|描述|
|:-----------|:------|:--------------------|
|isEnded|boolean|视频是否是在用户完整观看的情况下被关闭的。|
|isRewarded|boolean|是否有观看广告的奖励。|
|rewardType|string|奖励物品的名称。|
|rewardAmount|number|奖励数量。|

**示例：**

```js
const rewardedVideoAdOnCloseFn = function(res) {
  console.info('RewardedVideoAd onClose callback triggered', res);
};
const rewardedVideoAd = has.createRewardedVideoAd({
  adUnitId: 'testx9dtjwj8hp' // 此处的adUnitId仅供测试，请开发者更换为正式的广告id。
});
rewardedVideoAd.onClose(rewardedVideoAdOnCloseFn);
```
