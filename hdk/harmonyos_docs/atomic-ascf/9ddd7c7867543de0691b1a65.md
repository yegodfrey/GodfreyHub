# web-view组件控制

#### has.createWebViewContext

has.createWebViewContext(): WebViewContext

创建一个[WebViewContext](#webviewcontext)对象，用于向[web-view](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/components-web-view)组件发送消息。

起始版本： 2.0.4

返回值：

返回[WebViewContext](#webviewcontext)对象。

示例：

```
const webViewContext = has.createWebViewContext();
```

#### WebViewContext

web-view组件控制实例。

起始版本： 2.0.4  

#### WebViewContext.postMessage

WebViewContext.postMessage(Object object)

向web-view组件发送消息。

起始版本： 2.0.4

参数：

参数为Object对象，包括以下字段。  

|参数|类型|必填|描述|
|:-------|:---------------|:-|:------------------------|
|data|string \| object|是|需要发给网页的消息。|
|success|function|否|接口调用成功的回调函数。|
|fail|function|否|接口调用失败的回调函数。|
|complete|function|否|接口调用结束的回调函数（调用成功、失败都会执行）。|

示例：

```
const webViewContext = has.createWebViewContext();
webViewContext.postMessage({
  data: 'msg to H5',
  success: () => {
    console.info('postMessage success');
  },
  fail: (err) => {
    console.error('postMessage fail', err);
  },
  complete: (res) => {
    console.info('postMessage complete', res);
  }
});
```
