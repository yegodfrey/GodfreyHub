# 点击跳转分包页面无响应

问题现象：

元服务调试正常启动后，使用路由接口跳转分包页面时无响应，无法正常跳转到分包页面。

问题定位：

可以通过搜索关键字fetch module，分包下载失败时会因为找不到对应的页面资源而跳转失败。

关键错误日志格式如下:

```
PageManager --> goToPage -> fetch module 分包名 failed
```

分析结论：

元服务调试启动时，未对分包进行配置，导致元服务启动时缺少分包，无法进行页面跳转。

解决措施：

* 方案一： 配置元服务启动方式，将所有分包都勾选上再启动。

  操作步骤：编辑"运行调试配置" -\> 点击"部署多HAP/HSP" -\> 勾选"所有模块"
* 方案二： 编译时配置disableSubpackages参数为true，调试时将分包合并到主包中进行编译构建，完成编译后再重新启动元服务。

  ```
  ascf compile ./ -c -m --disableSubpackages=true
  ```
