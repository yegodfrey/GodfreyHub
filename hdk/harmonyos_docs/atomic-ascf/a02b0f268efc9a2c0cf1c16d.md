# 使用HarmonyOS开发助手开发

HarmonyOS开发助手是一款专为HarmonyOS应用和元服务开发者设计的AI插件，支持在VS Code上安装使用。它以自然语言对话为核心交互方式，提供一站式开发元服务功能。  

#### 环境要求

为保证功能正常运行，请确保您的电脑配置满足如下要求：

* 操作系统：支持 Windows、macOS 12+（Intel / Apple Silicon）。
* VS Code：最低版本VS Code 1.85.0，推荐版本VS Code 1.90+（建议使用近半年内的稳定版）。
* Node.js：最低版本Node.js 18.x，推荐版本Node.js 20.x LTS。
* DevEco Studio：需安装最新版[DevEco Studio](https://developer.huawei.com/consumer/cn/download/)。  

#### 安装使用

1. 打开VS Code，点击左侧活动栏的扩展面板按钮。

   ![](https://media:901788330596518736)
2. 在顶部搜索框中输入关键词"HarmonyOS Dev Assistant"，找到插件"HarmonyOS Dev Assistant for VS Code"，点击"安装"。

   ![](https://media:901788330596572737)
3. 点击"信任发布者和安装"。

   ![](https://media:901788330596610738)
4. 等待插件安装，完成后左侧活动栏将展示插件图标。![](https://media:901788330596634739)，点击图标，打开HarmonyOS开发助手登录界面。

![](https://media:901788330596676740)  

#### 登录插件

使用HarmonyOS开发助手，需要使用[已实名认证](https://developer.huawei.com/consumer/cn/doc/start/rna-0000001062530373)的华为开发者账号登录。

1. 点击插件主界面"华为账号登录"按钮。

   ![](https://media:901788330596742741)
2. 在弹出的账号登录页面，输入已实名认证的华为开发者账号信息。

   ![](https://media:901788330596776742)
3. 返回编辑器，此时若当前账号团队尚未签署插件相关隐私声明与使用条款，点击蓝色链接阅读协议内容后点击"同意"。

   ![](https://media:901788330596808743)
4. 进入主界面，接下来您需要先[对插件进行必要配置](#配置插件)，方可正式使用插件。

![](https://media:901788330596856744)  

#### 配置插件

在正式使用插件前，您需要先配置AI模型与DevEco Studio安装路径。  

#### 配置模型

1. 首次登录插件，界面会提示您当前未配置模型，点击"去配置"链接，前往模型配置界面。

   ![](https://media:901788330596889745)  
   后续如需修改模型配置，可点击插件右上角设置按钮进入模型配置界面操作。

   ![](https://media:901788330596928746)
2. 点击"添加模型"。

   ![](https://media:901788330596973747)
3. 选择模型，并输入对应的API Key，点击"保存"。

![](https://media:901788330597004748)  

#### 配置DevEco Studio安装路径

1. 点击插件右上角设置按钮。

   ![](https://media:901788330597058749)
2. 在"基础配置 \> 安装路径"栏，设置本地DevEco Studio的安装路径。

![](https://media:901788330597095750)  

#### 转换小程序项目为ASCF项目

#### 前提条件

* 已[登录插件](#登录插件)。
* 已[完成插件的配置](#配置插件)。
* 如果需要运行到模拟器上，确保DevEco Studio已安装所需要版本的模拟器。  

#### 转换元服务

1. 在VS Code中打开待转换的工程的上一级目录。

2. 进入插件界面，在左下角切换模式为"元服务转换"，在对话框中输入类似下述提示词：当前是一个XXX小程序，帮我转换为ASCF元服务工程。

   ![](https://media:901788330597140751)
3. 等待"待办清单"中各任务的执行完成。

   ![](https://media:901788330597182752)
4. 进入资源管理器界面，查看转换生成的元服务。

![](https://media:901788330597216753)  

#### 关联元服务

将生成的元服务工程与AGC上的元服务关联，支持关联已有的元服务，或者新建一个元服务进行关联。  

#### 关联已有的元服务

1. 点击插件右上角设置按钮。

   ![](https://media:901788330597245754)
2. 在"关联元服务"页签，点击"关联元服务"。

   ![](https://media:901788330597486755)
3. 选择AGC上元服务所属的团队以及元服务名称，点击"关联"。

   ![](https://media:901788330597517756)
4. 界面展示元服务的详细信息，表示元服务已成功关联。

![](https://media:901788330597545757)  

#### 关联新建的元服务

1. 点击插件右上角设置按钮。

   ![](https://media:901788330597577758)
2. 在"关联元服务"页签，点击"关联元服务"。

   ![](https://media:901788330597611759)
3. 点击"创建元服务"，浏览器将打开AGC控制台页面。

   ![](https://media:901788330597637760)
4. 在"应用开发基础信息"页面，填写待创建的元服务名称，分类仅支持选择"应用"，完成后点击"下一步"。

   ![](https://media:901788330597676761)
5. 进入"所属项目信息"页面，为元服务选择所属的项目后，点击"下一步"。

   * 如需将元服务添加到已有项目，点击下拉框进行选择。
   * 如需将元服务添加到新项目，直接在框中填写新项目名称。

   ![](https://media:901788330597713762)
6. 进入"云开发数据处理位置"页面，设置或管理项目的数据处理位置。

   * 如项目尚未设置数据处理位置：

     * 点击"启用"。

       ![](https://media:901788330597747763)
     * 在"启用"栏为您的项目勾选一个或多个数据处理位置，并在"设为默认"栏将其中一个设置为默认数据处理位置。

       ![](https://media:901788330597789764)
   * 如项目已设置过数据处理位置，可点击"管理"启用新的数据处理位置、取消已启用的数据处理位置，或修改默认数据处理位置。

     ![](https://media:901788330597829765)
7. 点击"确认"，元服务创建完成。

   ![](https://media:901788330597858766)
8. 返回HarmonyOS开发助手界面，点击"关联元服务"，选择正确的团队和刚刚创建的元服务，点击"关联"。

   ![](https://media:901788330597896767)
9. 界面展示元服务的详细信息，表示元服务已成功关联。

![](https://media:901788330597928768)  

#### 运行元服务

#### 在模拟器上运行元服务

1. 在插件对话框中输入类似下述提示词：将包推送到模拟器上运行调试。

   ![](https://media:901788330597960769)
2. 插件将拉起DevEco Studio中的模拟器运行元服务。

![](https://media:901788330598038770)  

#### 在真机上运行元服务

1. 将真机与PC连接。

2. 配置应用签名。

   * 打开插件配置界面，在"关联元服务"页签点击"添加签名"。

     ![](https://media:901788330598077771)
   * 输入签名信息。

     ![](https://media:901788330598109772)  

     |参数|说明|
     |:----------|:-----------------------------------------------------------------------------------------------------|
     |密钥名称|输入密钥名称。|
     |密钥密码|输入密钥密码，必须由大写字母（A-Z）、小写字母（a-z）、数字（0-9）和特殊符号（\`\~!@#$%\^\&\*()_+\|\[\];:'",\<.\>/?）中的两种以上字符的组合，长度为8-32位。|
     |签名类型|选择调试签名。|
     |调试设备|选择已在AGC注册的设备。如需使用本地设备调试，可点击"使用本地设备"，当前连接的真机设备将被添加到调试设备列表。之后，您可以在列表中勾选该设备。|
     |证书名称|输入证书名称。 说明： 每个账号仅支持创建3个调试证书。|
     |Provision名称|输入Provision名称。|
     |签名存储地址|选择签名存储地址，默认存储在当前工程的.cert文件夹下。|

   * 在对话框中输入类似下述提示词：已完成签名，帮我运行到真机上。

     ![](https://media:901788330598144773)
   * 插件将元服务推送到连接的真机上运行。

![](https://media:901788330598201774)  

#### 上架自检

1. 为元服务配置发布签名。

   * 打开插件配置界面，在"关联元服务"页签点击"添加签名"。

     ![](https://media:901788330598233775)
   * 输入签名信息。

     ![](https://media:901788330598271776)  

     |参数|说明|
     |:----------|:-----------------------------------------------------------------------------------------------------|
     |密钥密码|输入密钥密码，必须由大写字母（A-Z）、小写字母（a-z）、数字（0-9）和特殊符号（\`\~!@#$%\^\&\*()_+\|\[\];:'",\<.\>/?）中的两种以上字符的组合，长度为8-32位。|
     |签名类型|选择发布签名。|
     |证书名称|输入证书名称。 说明： 每个账号仅支持创建3个发布证书。|
     |Provision名称|输入Provision名称。|
     |签名存储地址|选择签名存储地址，默认存储在当前工程的.cert文件夹下。|

2. 在插件对话框中输入类似下述提示词：帮我打包用于最终上架。

   ![](https://media:901788330598302777)
3. 等待"待办清单"中各任务的执行完成。

   ![](https://media:901788330598335778)
4. 进入资源管理器界面，在"build \> outputs \> release"目录下获取带签名的元服务软件包。

   ![](https://media:901788330598386779)
5. 打开插件配置界面，在"关联元服务"页签的"上架自检"区域，点击文件选择按钮。

   ![](https://media:901788330598410780)
6. 选择刚刚编译生成的带签名的元服务软件包，点击"提交自检"。

   ![](https://media:901788330598438781)
7. 等待自检结果。

   ![](https://media:901788330598464782)
8. 报告生成后，点击"报告"可查看详细信息。

![](https://media:901788330598500783)
