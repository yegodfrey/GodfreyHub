# 使用HarmonyOS开发助手开发

HarmonyOS开发助手是一款专为HarmonyOS应用和元服务开发者设计的AI插件，支持在VS Code上安装使用。它以自然语言对话为核心交互方式，提供一站式开发元服务功能。

## 环境要求

为保证功能正常运行，请确保您的电脑配置满足如下要求：

* 操作系统：支持 Windows、macOS 12+（Intel / Apple Silicon）。
* VS Code：最低版本VS Code 1.85.0，推荐版本VS Code 1.90+（建议使用近半年内的稳定版）。
* Node.js：最低版本Node.js 18.x，推荐版本Node.js 20.x LTS。
* DevEco Studio：需安装最新版[DevEco Studio](https://developer.huawei.com/consumer/cn/download/)。

## 转换小程序项目为ASCF项目

### 前提条件

* 已[登录插件](#登录插件)。
* 已[完成插件的配置](#配置插件)。
* 如果需要运行到模拟器上，确保DevEco Studio已安装所需要版本的模拟器。
