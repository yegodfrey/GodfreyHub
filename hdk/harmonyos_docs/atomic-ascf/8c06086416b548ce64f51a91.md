# 构建元服务

构建元服务需要先配置好签名。可以使用[自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto)或[手动方式](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual)完成签名。详情请参见[签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing)。

开发者可以根据需要，选择使用本地真机运行服务，详情请参见[服务运行](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-device)。
