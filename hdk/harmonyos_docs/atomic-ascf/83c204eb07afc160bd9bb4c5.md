# 生命周期

## has.getLaunchOptionsSync

has.getLaunchOptionsSync(): Object

获取元服务启动时的参数。与[App定义的回调参数](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/logical-layer-app)一致。

**起始版本：** 1.0.0

**返回值：**

返回Object对象，包括以下字段。

|参数|类型|描述|
|:-----------|:-----|:----------|
|path|string|启动元服务页面的路径。|
|scene|string|场景值。|
|query|Object|启动元服务页面的参数。|
|referrerInfo|Object|来源信息。|

**referrerInfo说明：**

|参数|类型|描述|
|:----------|:-----|:--------------|
|packageName|string|来源应用或元服务的包名。|
|extraData|Object|来源应用或元服务传过来的参数。|

**示例：**

```js
const launchOptions = has.getLaunchOptionsSync();
console.info(launchOptions.path);
```

## has.getEnterOptionsSync

has.getEnterOptionsSync(): Object

获取元服务启动时的参数。如果当前是冷启动，则返回值与[App.onLaunch](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/logical-layer-app)的回调参数一致；如果当前是热启动，则返回值与[App.onShow](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/logical-layer-app)一致。

**起始版本：** 1.0.4

**返回值：**

返回Object对象，包括以下字段。

|参数|类型|描述|
|:-----------|:-----|:----------|
|path|string|启动元服务页面的路径。|
|scene|string|场景值。|
|query|Object|启动元服务页面的参数。|
|referrerInfo|Object|来源信息。|

**referrerInfo说明：**

|参数|类型|描述|
|:----------|:-----|:--------------|
|packageName|string|来源应用或元服务的包名。|
|extraData|Object|来源应用或元服务传过来的参数。|

**示例：**

```js
const enterOptions = has.getEnterOptionsSync();
console.info(enterOptions.path);
```
