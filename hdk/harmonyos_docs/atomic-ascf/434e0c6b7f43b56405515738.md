# devtool工具手动安装

**问题现象：**

devtool工具安装失败，例如下图中的错误。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/QZExqH3FSE-EhoG6CfIkGw/zh-cn_image_0000002733333764.png?HW-CC-KV=V1&HW-CC-Date=20260917T065900Z&HW-CC-Expire=31536000000&HW-CC-Sign=2498B14F18F9ECC775124DB1CBD7013FC8D7E3A717D9258C8D3481D2E98F5F76 "点击放大")

或者

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/MtQ78Al6QL62HLr5UXXewA/zh-cn_image_0000002762893267.png?HW-CC-KV=V1&HW-CC-Date=20260917T065900Z&HW-CC-Expire=31536000000&HW-CC-Sign=76898C5C1AA1D93646ED32CEEF294AE5F76AC5C4C5604DE5EA1FA806C8121B5F "点击放大")

**解决措施：**

手动安装devtool到指定缓存目录。参考ascf缓存目录：

win："C:\Users\你的用户名\AppData\Local\ascf-cache\Cache"

mac："/users/你的用户名/Library/caches/ascf-cache"

下面以Windows为例，首先随便新建一个文件夹，在当前的文件夹下安装devtool工具，安装命令如下：

```bash
npm install chrome-devtools-built@1.20253003.0
```

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/EmL9eNSYRxuv-jbXeUYB7Q/zh-cn_image_0000002763053155.png?HW-CC-KV=V1&HW-CC-Date=20260917T065900Z&HW-CC-Expire=31536000000&HW-CC-Sign=9AFA23F81928A7A6A12B929E44FCB4C7073F6804140772CB6CC8A115EC2A1E9D "点击放大")

进入到"node_modules"目录中，将"chrome-devtools-built"文件夹重命名为"chrome-devtools"并复制到缓存目录下即可。
