# devtool工具手动安装

**问题现象：**

devtool工具安装失败，例如下图中的错误。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/QZExqH3FSE-EhoG6CfIkGw/zh-cn_image_0000002733333764.png?HW-CC-KV=V1&HW-CC-Date=20261008T170020Z&HW-CC-Expire=31536000000&HW-CC-Sign=276DDFEB03F24CA2CFA368682024FA7CEB1C04E31817E8B7802F420373125A2D "点击放大")

或者

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/MtQ78Al6QL62HLr5UXXewA/zh-cn_image_0000002762893267.png?HW-CC-KV=V1&HW-CC-Date=20261008T170020Z&HW-CC-Expire=31536000000&HW-CC-Sign=752595B9532507DC063E3C06F98616B09D87BDE3DE0F8D583D2F2ACD1CB2F827 "点击放大")

**解决措施：**

手动安装devtool到指定缓存目录。参考ascf缓存目录：

win："C:\Users\你的用户名\AppData\Local\ascf-cache\Cache"

mac："/users/你的用户名/Library/caches/ascf-cache"

下面以Windows为例，首先随便新建一个文件夹，在当前的文件夹下安装devtool工具，安装命令如下：

```bash
npm install chrome-devtools-built@1.20253003.0
```

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/EmL9eNSYRxuv-jbXeUYB7Q/zh-cn_image_0000002763053155.png?HW-CC-KV=V1&HW-CC-Date=20261008T170020Z&HW-CC-Expire=31536000000&HW-CC-Sign=A249D7D5B7D7D3353FB94D6B92AE742FCEB1D7C99B68281CE816E829144EAFB7 "点击放大")

进入到"node_modules"目录中，将"chrome-devtools-built"文件夹重命名为"chrome-devtools"并复制到缓存目录下即可。
