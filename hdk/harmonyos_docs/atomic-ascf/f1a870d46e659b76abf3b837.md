# CanvasRenderingContext2D

说明：

如使用CanvasRenderingContext2D，ASCF运行时版本需更新到2.0.2及以上。

CanvasRenderingContext2D绘图上下文。

属性：  

|名称|类型|描述|
|:-----------------------|:------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|direction|string|在绘制文本时，描述当前文本方向，默认值为'ltr'。 合法值： -'ltr'：文字方向为从左到右； -'rtl'：文字方向为从右到左； -'inherit'：文字方向从相应的canvas元素或Document继承。|
|filter|string|提供模糊、灰度等过滤效果。|
|fillStyle|string\|CanvasGradient\|CanvasPattern|指定形状内部的颜色、渐变或图案，默认值为'#000000'。|
|font|string|指定绘制文字所使用的字体属性，包括字体粗细、大小和字体风格（ctx.font = 'bold 48px serif'）。默认字体为10像素的无衬线体（sans-serif）。|
|globalAlpha|number|全局画笔透明度，默认值为1。范围：0-1，0表示完全透明，1表示完全不透明。|
|lineCap|string|线条的末端样式，默认值为'butt'。 合法值： -'butt'：线条末端呈方形。 -'round'：线条末端呈圆形。 -'square'：线条末端呈正方形。|
|lineDashOffset|number|虚线偏移量，默认值为0。|
|lineJoin|string|线条的交点样式，默认值为'miter'。 合法值： -'bevel'：斜角。 -'round'：圆角。 -'miter'：尖角。|
|lineWidth|number|线条的宽度，默认值为1。|
|miterLimit|number|最大斜接长度，默认值为10。|
|shadowBlur|number|阴影的模糊级别，默认值为0。|
|shadowColor|string|阴影的颜色，默认值为完全透明的黑色。|
|shadowOffsetX|number|阴影相对于形状在水平方向的偏移，默认值为0。|
|shadowOffsetY|number|阴影相对于形状在竖直方向的偏移，默认值为0。|
|strokeStyle|string\|CanvasGradient\|CanvasPattern|描边颜色，默认值为'#000000'。|
|textAlign|string|文本对齐方式，默认值为'start'。 合法值： -'left'：文本左对齐； -'right'：文本右对齐； -'center'：文本居中对齐 -'start'：文本对齐界线开始的地方； -'end'：文本对齐界线结束的地方。|
|textBaseline|string|绘制文本时使用的文本基线，默认值为'alphabetic'。 合法值： -'top'：文本基线在文本块的顶部； -'hanging'：文本基线是悬挂基线； -'middle'：文本基线在文本块的中间； -'alphabetic'：文本基线是标准的字母基线； -'ideographic'：文字基线是表意字基线； -'bottom'：文本基线在文本块的底部。|
|imageSmoothingEnabled|boolean|图片是否平滑，默认值为true。|
|imageSmoothingQuality|string|图像在缩放时的平滑质量，默认值为'low'。 合法值： -'low'：低质量； -'medium'：中等质量； -'high'：高质量。|
|globalCompositeOperation|string|在绘制新形状时应用的合成操作的类型，默认值为'source-over'。 目前支持的操作如下： -'source-over'：在现有画布上绘制新图形； -'source-atop'：只在与现有画布内容重叠的地方绘制新图形； -'source-in'：仅在新形状和目标画布重叠的地方绘制新形状； -'source-out'：仅保留现有画布内容和新形状不重叠的部分； -'destination-over'：在现有画布内容的后面绘制新的图形； -'destination-atop'：现有画布仅在新形状重叠的区域保留，新形状会在画布内容之后绘制； -'destination-in'：现有画布内容会在新形状和现有画布内容重叠的区域保留，其他所有内容都将变为透明； -'destination-out'：现有内容会在不与新形状重叠的区域保留； -'lighter'：在两个形状重叠的区域，颜色通过将颜色值相加来确定； -'copy'：仅显示新形状； -'xor'：在两个形状重叠的区域，形状会变为透明，在其他所有区域正常绘制。|

#### CanvasRenderingContext2D.arc

CanvasRenderingContext2D.arc(number x, number y, number r, number sAngle, number eAngle, boolean counterclockwise)

将一个圆弧添加到当前子路径中。

起始版本： 2.0.2

参数：  

|参数|类型|默认值|必填|描述|
|:---------------|:------|:----|:-|:-----------------|
|x|number|-|是|圆心的x坐标。|
|y|number|-|是|圆心的y坐标。|
|r|number|-|是|圆的半径。|
|sAngle|number|-|是|起始弧度，单位弧度（在3点钟方向）。|
|eAngle|number|-|是|终止弧度。|
|counterclockwise|boolean|false|否|弧度的方向是否是逆时针。|

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    ctx.arc(100, 75, 50, 0, 2 * Math.PI);
    ctx.stroke();
  })
  .exec();
```

#### CanvasRenderingContext2D.arcTo

CanvasRenderingContext2D.arcTo(number x1, number y1, number x2, number y2, number radius)

通过给定的控制点和半径向当前子路径添加一个圆弧。

起始版本： 2.0.2

参数：  

|参数|类型|必填|描述|
|:-----|:-----|:-|:-----------|
|x1|number|是|第一个控制点的x轴坐标。|
|y1|number|是|第一个控制点的y轴坐标。|
|x2|number|是|第二个控制点的x轴坐标。|
|y2|number|是|第二个控制点的y轴坐标。|
|radius|number|是|圆弧的半径。|

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;

    ctx.arcTo(200, 130, 50, 20, 40);
    ctx.stroke();
  })
  .exec();
```

#### CanvasRenderingContext2D.beginPath

CanvasRenderingContext2D.beginPath()

开始创建一个新的路径。

起始版本： 2.0.2

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    // 第一条路径
    ctx.beginPath();
    ctx.strokeStyle = 'blue';
    ctx.moveTo(20, 20);
    ctx.lineTo(200, 20);
    ctx.stroke();
    // 第二条路径
    ctx.beginPath();
    ctx.strokeStyle = 'green';
    ctx.moveTo(20, 20);
    ctx.lineTo(120, 120);
    ctx.stroke();
  })
  .exec();
```

#### CanvasRenderingContext2D.clip

CanvasRenderingContext2D.clip(Path2D path, string fillRule)

使用当前路径或指定的Path2D路径剪切画布。

起始版本： 2.0.2

参数：  

|参数|类型|默认值|必填|描述|
|:-------|:-----|:--------|:-|:---------------------------------------------------------------------------|
|path|Path2D|-|否|指定裁剪的路径，不传将使用当前路径裁剪画布。|
|fillRule|string|'nonzero'|否|填充规则，用于判断一个点是否在路径内，默认值为'nonzero'。 合法值： -'nonzero'：非零环绕规则； -'evenodd'：奇偶环绕规则。|

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    // 创建裁剪路径
    const region = canvas.createPath2D();
    region.rect(80, 10, 20, 130);
    region.rect(40, 50, 100, 50);
    ctx.clip(region, 'nonzero');
    // 绘制被裁剪的内容
    ctx.fillStyle = 'blue';
    ctx.fillRect(0, 0, canvas.width, canvas.height);
  })
  .exec();
```

#### CanvasRenderingContext2D.closePath

CanvasRenderingContext2D.closePath()

关闭一个路径，会连接起点和终点。如果关闭路径后没有调用fill或者stroke并开启了新的路径，那么之前的路径将不会被渲染。

起始版本： 2.0.2

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    ctx.beginPath();
    ctx.moveTo(20, 140);
    ctx.lineTo(120, 10);
    ctx.lineTo(220, 140);
    ctx.closePath();
    ctx.stroke();
  })
  .exec();
```

#### CanvasRenderingContext2D.createConicGradient

CanvasRenderingContext2D.createConicGradient(number startAngle, number x, number y): CanvasGradient

围绕指定坐标点创建渐变。

起始版本： 2.0.2

参数：  

|参数|类型|必填|描述|
|:---------|:-----|:-|:----------------------------------|
|startAngle|number|是|渐变开始的角度，单位：弧度。角度从从中心向右水平线开始，并顺时针旋转。|
|x|number|是|渐变中心的x轴坐标。|
|y|number|是|渐变中心的y轴坐标。|

返回值：

返回[CanvasGradient](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-gradient)对象。

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    const gradient = ctx.createConicGradient(0, 100, 100);
    // 添加五个色标
    gradient.addColorStop(0, 'red');
    gradient.addColorStop(0.25, 'orange');
    gradient.addColorStop(0.5, 'yellow');
    gradient.addColorStop(0.75, 'green');
    gradient.addColorStop(1, 'blue');
    // 设置填充样式并绘制矩形
    ctx.fillStyle = gradient;
    ctx.fillRect(20, 10, 150, 130);
  })
  .exec();
```

#### CanvasRenderingContext2D.createPattern

CanvasRenderingContext2D.createPattern(Image image, string repetition): CanvasPattern

使用指定的图像或重复创建图案。

起始版本： 2.0.2

参数：  

|参数|类型|必填|描述|
|:---------|:----------------------------------------------------------------------------------|:-|:-----------------------------------------------------------------------------------------------|
|image|[Image](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-image)|是|元图像，即图案的原始图像源。|
|repetition|string|是|如何重复图像。 合法值： -'repeat'：两个方向都重复； -'repeat-x'：仅水平方向重复； -'repeat-y'：仅垂直方向重复； -'no-repeat'：两个方向都不重复。|

返回值：

[CanvasPattern](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-pattern)图案对象。

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    const img = canvas.createImage();
    img.src = 'https://www.example.com/xxxx.png'; // 此处仅为样例，请开发者更换为可用图片资源地址
    img.onload = () => {
      const pattern = ctx.createPattern(img, 'repeat');
      ctx.fillStyle = pattern;
      ctx.fillRect(0, 0, 200, 150);
    },
    img.onerror = (err) => {
      console.error('createImage error', err);
    };
  })
  .exec();
```

#### CanvasRenderingContext2D.drawImage

CanvasRenderingContext2D.drawImage(Image image, number sx, number sy, number sWidth, number sHeight, number dx, number dy, number dWidth, number dHeight)

绘制图片到画布。

起始版本： 2.0.2

参数：

当前支持三种入参方式，请开发者根据实际情况选择。

* CanvasRenderingContext2D.drawImage(Image image, number dx, number dy)

* CanvasRenderingContext2D.drawImage(Image image, number dx, number dy, number dWidth, number dHeight)

* CanvasRenderingContext2D.drawImage(Image image, number sx, number sy, number sWidth, number sHeight, number dx, number dy, number dWidth, number dHeight)

|参数|类型|必填|描述|
|:------|:----------------------------------------------------------------------------------|:-|:--------------------------|
|image|[Image](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-image)|是|要绘制的内容。|
|sx|number|否|需要绘制到画布中源图像的矩形选择框的左上角x坐标。|
|sy|number|否|需要绘制到画布中源图像的矩形选择框的左上角y坐标。|
|sWidth|number|否|需要绘制到画布中源图像的矩形选择框的宽度。|
|sHeight|number|否|需要绘制到画布中源图像的矩形选择框的高度。|
|dx|number|是|图像的左上角在目标canvas上x轴的位置。|
|dy|number|是|图像的左上角在目标canvas上y轴的位置。|
|dWidth|number|否|在目标画布上绘制图像的宽度，允许对绘制的图像进行缩放。|
|dHeight|number|否|在目标画布上绘制图像的高度，允许对绘制的图像进行缩放。|

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    const img = canvas.createImage();
    img.src = 'https://www.example.com/xxxx.png'; // 此处仅为样例，请开发者更换为可用图片资源地址
    img.onload = () => {
      ctx.drawImage(img, 0, 0);
    };
    img.onerror = (err) => {
      console.error('createImage err', err);
    };
  })
  .exec();
```

#### CanvasRenderingContext2D.fill

CanvasRenderingContext2D.fill(Path2D path, string fillRule)

填充当前路径或指定Path2D路径。

has.createSelectorQuery().select('#myCanvas')

参数：

当前支持两种入参方式，请开发者根据实际情况选择。

* CanvasRenderingContext2D.putImageData(ImageData imageData, number dx, number dy)

* CanvasRenderingContext2D.putImageData(ImageData imageData, number dx, number dy, number dirtyX, number dirtyY, number dirtyWidth, number dirtyHeight)

|参数|类型|必填|描述|
|:----------|:--------|:-|:--------------------------|
|imageData|ImageData|是|待绘制的ImageData对象。|
|dx|number|是|图像数据的水平位置。|
|dy|number|是|图像数据的垂直位置。|
|dirtyX|number|否|提取图像数据的左上角的水平位置。|
|dirtyY|number|否|提取图像数据的左上角的垂直位置。|
|dirtyWidth|number|否|要绘制的矩形的宽度。默认为图像数据的宽度，单位：px。|
|dirtyHeight|number|否|要绘制的矩形的高度。默认为图像数据的高度，单位：px。|

示例：

```
has.createSelectorQuery().select('#myCanvas')
  .node((res) => {
    const canvas = res.node;
    const ctx = canvas.getContext('2d');
    const imageData = ctx.getImageData(0, 0, 100, 100);
    ctx.putImageData(imageData, 50, 50);
  })
  .exec();
```
