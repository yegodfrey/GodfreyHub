# js

支持ES6的module标准，使用import引入js依赖，同时支持CommonJs规范，使用require引入js依赖。  
![](https://media:901788330616066914)  
* 不支持使用eval执行JS代码。
* 不支持使用new Function创建函数，new Function('return this')除外。
