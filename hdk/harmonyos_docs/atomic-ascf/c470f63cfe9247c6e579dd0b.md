# ImageData

用于描述一个矩形区域内的像素信息。对于Canvas可以使用[has.canvasGetImageData](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-global#hascanvasgetimagedata)获取，对于CanvasRenderingContext2D可以使用[CanvasRenderingContext2D.createImageData](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-rendering-context-2d#canvasrenderingcontext2dcreateimagedata)创建。

**起始版本：** 1.0.3

**属性：**

|名称|类型|只读|描述|
|:-----|:----------------|:-|:----------------------------|
|width|number|是|图像数据矩形的宽度，单位：px。|
|height|number|是|图像数据矩形的高度，单位：px。|
|data|Uint8ClampedArray|否|图像像素点数据，一维数组，每四项表示一个像素点的rgba。|
