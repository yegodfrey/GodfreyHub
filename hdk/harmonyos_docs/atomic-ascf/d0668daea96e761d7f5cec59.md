# video组件全屏播放时出现被页面内容遮挡的情况

**问题现象：**

开发者在页面里对一个组件使用了position: absolute绝对布局，设置css样式z-index值为100000，同时在页面里使用video组件加载视频。用户点击全屏播放后，自定义内容显示在了视频上面。

例如：创建一个ASCF页面，内容如下：

```html
<view class="page">
  <view class="nav-title">自定义内容</view>
  <video src="https://www.example.com/demo.mp4" controls="true"></video>
</view>
```

对应的样式代码如下：

```css
.nav-title {
  width: 100%;
  height: 50px;
  background: white;
  color: red;
  font-size: 24px;
  padding-top: 18px;
  position: absolute;
  top: 0;
  left: 0;
  z-index: 100000;
}
```

**可能原因：**

video组件全屏播放是通过position: absolute实现的。为确保全屏视频不被遮挡，为其设置了固定的z-index层级（值为99999）。当页面中其他组件也设置了z-index时，页面渲染时会比较各组件的层级大小，层级更高的组件会显示在最上层。因此，如果其他组件的z-index值大于99999，就会遮挡全屏播放的视频。

**解决措施：**

检查css样式是否设置了z-index且设置的值大于99999，如果有，将z-index设置为小于99999的值。
