# 模拟器运行问题处理

**问题现象：**

模拟器运行ASCF框架无法正常启动，提示"Failed to install the HAP or HSP because the dependent module does not exist."错误。

报错信息：

```text
Install Failed: error: failed to install bundle.

code:9568305

error: Failed to install the HAP or HSP because the dependent module does not exist.
```

**可能原因：**

项目中所依赖的运行时的版本可能高于模拟器版本。

**解决措施：**

对于模拟器中的ASCF运行时，是不能安装和升级的，所以框架指定的版本号不能高于模拟器中预置的版本号，需要修改项目配置。

1. 获取模拟器ASCF运行时的版本号。

   hdc环境配置请参考[可选命令行直接执行hdc程序](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc#可选命令行直接执行hdc程序)，使用如下命令读取版本号：

   ```bash
   hdc shell bm dump-shared -n com.huawei.hms.ascfruntime
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dd/v3/vDcJtTgRR42Rv2OhbOAbyQ/zh-cn_image_0000002733333768.png?HW-CC-KV=V1&HW-CC-Date=20260917T065900Z&HW-CC-Expire=31536000000&HW-CC-Sign=7231A6807FD9B9C7C50964F4642B5DB8BED0D3B1CB2593BD85C01E76A4B93BCC "点击放大")
2. 修改项目配置。

   例如此时的versionName为"1.0.10.300"，则需要将entry/oh-package.json5配置文件中的版本字段"@atomicservice/ascfapi": "^1.0.6"改为"@atomicservice/ascfapi": "1.0.10"，然后同步项目即可。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/aUkwfZwhRR2xzJVARPQFnA/zh-cn_image_0000002762893271.png?HW-CC-KV=V1&HW-CC-Date=20260917T065900Z&HW-CC-Expire=31536000000&HW-CC-Sign=5E022BD4144A711EB8B07BCE8A0AD10370773F5AB2FD9387020F449F463F30FB "点击放大")

查询当前是否是模拟器的方法：

```bash
hdc shell param get const.product.model
```

结果为emulator，当前是模拟器环境。
