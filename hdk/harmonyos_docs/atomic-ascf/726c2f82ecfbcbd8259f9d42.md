# 代码编辑

## 支持文件类型

工具当前支持hxml, js, hjs, css, json 等文件的编辑，支持基本的语法高亮和代码格式化等功能。

## 代码格式化

hxml代码格式化（按下快捷键Ctrl+Alt+L可自动格式化代码）

## 自动补全

### hxml引号补全

在符号"="右侧输入一个双引号或单引号时，会自动补全另一个。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/JUsQHF7OTh-jRQPxzBvzdA/zh-cn_image_0000002733493590.gif?HW-CC-KV=V1&HW-CC-Date=20260917T065900Z&HW-CC-Expire=31536000000&HW-CC-Sign=C0187BBA2E81DA0B21AF672AF9E3589F07EEA8AFBBC4187F9A9212F747E55585)

### hxml括号补全

在符号">"右侧或双引号内部输入一个左括号时，会自动补全剩下的括号。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/Zugf1IbtQ5eJQVqu3Ixt0Q/zh-cn_image_0000002733333728.gif?HW-CC-KV=V1&HW-CC-Date=20260917T065900Z&HW-CC-Expire=31536000000&HW-CC-Sign=7ABFC4E7DAA17B4389158F5989C307BCD8323A239D50A6F9C0FDB20922ED5D61)
