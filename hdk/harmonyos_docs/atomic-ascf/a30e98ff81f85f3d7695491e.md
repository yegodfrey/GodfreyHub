# CanvasPattern

由[CanvasRenderingContext2D.createPattern()](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-rendering-context-2d#canvasrenderingcontext2dcreatepattern)方法创建的图案，可用于设置[CanvasRenderingContext2D](https://developer.huawei.com/consumer/cn/doc/atomic-ascf/apis-canvas-rendering-context-2d)的两个属性：fillStyle、strokeStyle。

起始版本： 2.0.2
