#### connect

client连接到华为移动服务。 这个方法立即返回，连接服务在后台进行。  

|Google API|To HMS API|
|:----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|abstract void connect()|abstract void connect(android.app.Activity activity) activity内部已做判空处理。 对应HMS类：com.huawei.hms.api.HuaweiApiClient 说明：如果该接口是用于fitness业务，请将GoogleApiClient替换为HiHealthKitClient，使用HiHealthKitClient.connect()接口来连接华为运动健康服务。可以参见[add接口](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/health-conversion-0000001050062171#section1922515491422)中To HMS API内容修改。|
