# 瓶颈分析

Graphics Profiler内置自动瓶颈检测算法，可以一目了然地识别DDR或GPU瓶颈。瓶颈分析需要在trace采集时开启GPU Counters和DDR Counters。当满足这些条件时，Bottleneck轨迹将显示在时间轴上，该时间轴描绘了应用程序受到GPU或DDR限制的时间范围。
