# APM

## 准备工作

1. 您若需要应用支持APM，必须完成接入准备，请参见[AppGallery Connect开发服务使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-android-0000001058210705)。
2. 华为性能管理详情请参见[性能管理服务简介](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-apm-introduction-0000001052247254)，API详情请参见[性能管理服务API参考](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-apm-api-overview-0000001052246892)。

## newHttpMetric (java.net.URL url, java.lang.String httpMethod)

属于com.google.firebase.perf.FirebasePerformance中方法，下面给出简易的代码转换示例。

在To HMS API模式下的代码修改示例：

```screen
NetworkMeasure networkMeasure = (com.huawei.agconnect.apms.APMS) this.getInstance().createNetworkMeasure(String url, String httpMethod);
```

(com.huawei.agconnect.apms.APMS) this.getInstance().enableCollection(boolean enable);
