# 测试（华为快服务助手）

测试前，请确保工程内包含卡片。运行工程到华为快服务助手上进行测试的步骤如下：

1. 通过USB线将手机连接到电脑，开启手机USB调试模式。
2. 点击"实时编译"按钮，选择连接的设备后，点击"确定"启动编译。
3. 菜单选择"工具 -\> 运行快服务助手"，如果手机上未安装快服务助手，右下角将会出现提示安装，点击"安装"。 快服务助手安装完毕后，快服务卡片将会推送到快服务助手，可以进行测试。
