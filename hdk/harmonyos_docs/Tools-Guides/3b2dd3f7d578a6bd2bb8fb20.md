# SmartCoder

SmartCoder是HMS Toolkit插件推出的一款智能辅助编程助手，助您快速查找、轻松集成HMS Core，提升您的HMS Core编程体验和效率。

## 主要功能

HMS Core领域内支持智能搜索、智能问答和智能代码补全功能。

## 主要特点

* 提供HMS Core官方资源的搜索平台（目前支持Account Kit、Ads Kit、Analytics Kit、In-App Purchases、Push Kit资源）
* 实现HMS Core领域内无文档开发，搜索和查找在IDE内进行
* 智能问答提供专业的引导和反馈，帮助解决HMS Core领域内常见问题
* AI辅助的智能代码补全，让代码输入更快更智能
* 提高HMS Core开发效率30%以上

## 智能搜索

搜索引擎采用语义搜索技术

覆盖HMS Core官方多种类型资源：

* Kit：Kit官网文档
* Template： Kit官方集成步骤
* Snippet：示例代码片段
* API：官方API Reference

## 智能代码补全

提供HMS Core领域内的词补全、API补全和代码片段补全，让代码输入更快更智能。

您可以选择打开或者关闭智能代码补全功能，通过"HMS Toolkit > Settings > Code Completion "设置。

### 词补全

结合AI技术与程序分析技术，根据上文信息，预测最可能需要的词并补全。

### API补全

HMS Core领域内的AI辅助API补全。

* 支持单个API补全
* 支持API调用链补全
* 支持API悬浮框富文档展示

### 代码片段补全

代码编辑区输入"hms"激活代码片段补全功能。快速完成代码片段的匹配，并自动补全，提高代码输入效率。

* 支持代码补全右侧悬浮框信息展示。
* 支持代码补全二次编辑，用"Tab"切换编辑区。
* import功能：当用户触发代码片段补全功能时，工具会自动将目标代码片段需要的依赖自动导入到import区。
