# Health Kit手工转换指导书

## add接口

Google API SensorsApi类中add接口已经废弃：

|类型|废弃API|替换API|
|:-|:------------------------------------------------------------------|:----------------------------------------------------|
|方法|SensorsApi.add(GoogleApiClient, SensorRequest, OnDataPointListener)|SensorsClient.add(SensorRequest, OnDataPointListener)|
|方法|SensorsApi.add(GoogleApiClient, SensorRequest, PendingIntent)|SensorsClient.add(SensorRequest, PendingIntent)|

您需要先将使用到的Google API SensorsApi类中已废弃API升级到替换API，然后使用工具自动转换。若不升级API，可以按照以下指导手工转换：

您在使用add接口时，需要手动修改如下代码：

首先需要import HiHealthKitClient：

```screen
import com.huawei.hms.hihealth.HuaweiHiHealth;
import com.huawei.hms.hihealth.HiHealthKitClient;
import com.google.android.gms.common.api.GoogleApiClient;
```

* Add HMS API 在Client的构造和连接上，需要实现代码如下：

  ```screen
  if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
      HiHealthKitClient hmsApiClient = new HiHealthKitClient.Builder(this)
          .addApi(HuaweiHiHealth.SENSORS_MANAGER)
          .build();
      hmsApiClient.connect();
  } else {
      GoogleApiClient googleApiClient = new GoogleApiClient.Builder(this)
          .addApi(com.google.android.gms.fitness.Fitness.SENSORS_API)
          .build();
      googleApiClient.connect();
  }
  ```

  add接口在Google API的使用示例如下：

  ```screen
  SensorsApi sensorsApi;
  sensorsApi.add(GoogleApiClient googleApiClient,SensorRequest request, OnDataPointListener listener); 
  ```

  需要替换上面的示例代码，参考如下：

  ```screen
  if (org.xms.g.utils.GlobalEnvSetting.isHms()) {   
      com.huawei.hms.support.api.client.PendingResult<com.huawei.hms.support.api.client.Status> pendingResult = 
      HuaweiHiHealth.SENSORSMANAGER.register(hmsApiClient,
      (com.huawei.hms.hihealth.options.SensorOptions) request.getHInstance(),
      (com.huawei.hms.hihealth.options.OnSamplePointListener) listener.getHInstanceOnDataPointListener());
  } else {			
      com.google.android.gms.common.api.PendingResult<com.google.android.gms.common.api.Status>pendingResult= 
      com.google.android.gms.fitness.Fitness.SensorsApi.add(googleApiClient, 
      (com.google.android.gms.fitness.request.SensorRequest) request.getGInstance(), 
      (com.google.android.gms.fitness.request.OnDataPointListener) listener.getGInstanceOnDataPointListener());
  }
  ```

  需要转换的几个点：
  1. 需要增加Google API和HMS的判断逻辑：[org.xms.g.utils.GlobalEnvSetting.isHms](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/appendix-0000001050061063#section414983018507)()为True时为HMS工程。
  2. 接口调用需要替换成Google API和HMS的静态类调用。
  3. 参数一需要分别换成经过对应的ApiClient。
  4. 在调用过程中，除了基础数据类型，其他的数据类型都需要增加全路径。
  5. 其中的变量request, listener是可以由工具自动转化的，在使用时，需要通过接口getGInstance和getHInstance分别获取对应的Google API和HMS的对象，经过强制类型转化之后再使用。
* To HMS API 在Client的构造和连接上，需要实现代码如下：

  ```screen
  HiHealthKitClient hmsApiClient = new HiHealthKitClient.Builder(this)
      .addApi(HuaweiHiHealth.SENSORS_MANAGER)
      .build();
  hmsApiClient.connect();
  ```

  add接口在Google API的使用示例如下：

  ```screen
  SensorsApi sensorsApi;
  sensorsApi.add(GoogleApiClient googleApiClient,SensorRequest request, OnDataPointListener listener); 
  ```

  示例代码需要替换为：

  ```screen
  HuaweiHiHealth.SENSORSMANAGER.register(hmsApiClient, SensorOptions options, OnSamplePointListener sensorListener);
  ```

  add接口还有另一种以PendingIntent作为入参的形式，在Google API的使用示例如下：

  ```screen
  SensorsApi sensorsApi;
  sensorsApi.add(GoogleApiClient googleApiClient,SensorRequest request,PendingIntent pendingIntent); 
  ```


* Add HMS API

  需要替换上面的示例代码，参考如下：

  ```screen
  if(org.xms.g.utils.GlobalEnvSetting.isHms()) {
      com.huawei.hms.support.api.client.PendingResult<com.huawei.hms.support.api.client.Status> pendingResult = 
      HuaweiHiHealth.SENSORSMANAGER.register(hmsApiClient, (com.huawei.hms.hihealth.options.SensorOptions)request.getHInstance(), pendingIntent);
  } else {	
      com.google.android.gms.common.api.PendingResult<com.google.android.gms.common.api.Status>pendingResult= 
      com.google.android.gms.fitness.Fitness.SensorsApi.add(googleApiClient, 
      (com.google.android.gms.fitness.request.SensorRequest) request.getGInstance(), pendingIntent);
  }
  ```

* To HMS API 示例代码需要替换为：

  ```screen
  PendingResult<Status> pendingResult = HuaweiHiHealth.SENSORSMANAGER.register(hmsApiClient, SensorOptions options, pendingIntent);
  ```

* Add HMS API

  在Client的构造和连接上，需要实现代码如下：

  claimBleDevice接口在Google API的使用示例如下：

  ```screen
  BleApi bleApi;
  bleApi.claimBleDevice(GoogleApiClient googleApiClient, BleDevice bleApiDevice);
  ```

  需要替换上面的示例代码，参考如下：

  ```screen

      HuaweiHiHealth.BLEMANAGER.saveDevice(hmsApiClient,
      (com.huawei.hms.hihealth.data.BleDeviceInfo)bleApiDevice.getHInstance());
  } else {
      com.google.android.gms.fitness.Fitness.BleApi.claimBleDevice(googleApiClient,
      (com.google.android.gms.fitness.data.BleDevice)bleApiDevice.getGInstance());

  ```

  需要转换的几个点：
  1. 需要增加Google API和HMS的判断逻辑：[org.xms.g.utils.GlobalEnvSetting.isHms](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/appendix-0000001050061063#section414983018507)()为True时为HMS工程。
  2. 接口调用需要替换成Google API和HMS的静态类调用。
  3. 参数一需要分别换成经过对应的ApiClient。
  4. 在调用过程中，除了基础数据类型，其他的数据类型都需要增加全路径。
  5. 其中的变量bleApiDevice，是可以由工具自动转化的，在使用时，需要通过接口getGInstance和getHInstance分别获取对应的Google API和HMS的对象，经过强制类型转化之后再使用。
* To HMS API

  在Client的构造和连接上，需要实现代码如下：

  ```screen
  HiHealthKitClient hmsApiClient = new HiHealthKitClient.Builder(this)
          .addApi(HuaweiHiHealth.BLE_MANAGER)
          .build();
  hmsApiClient.connect();
  ```

  claimBleDevice接口在Google API的使用示例如下：

  ```screen
  BleApi bleApi;
  bleApi.claimBleDevice(GoogleApiClient googleApiClient, BleDevice bleApiDevice);
  ```

  示例代码需要替换为：

  ```screen
  HuaweiHiHealth.BLEMANAGER.saveDevice(hmsApiClient, BleDeviceInfo bleApiDevice);
  ```

  claimBleDevice接口还有另一种以Address作为入参的形式，在Google API的使用示例如下：

  ```screen
  BleApi bleApi;
  bleApi.claimBleDevice(GoogleApiClient googleApiClient, String deviceAddress);
  ```


* Add HMS API 需要替换上面的示例代码，参考如下：

  ```screen
  if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
      HuaweiHiHealth.BLEMANAGER.saveDevice(hmsApiClient, ((com.huawei.hms.hihealth.data.BleDeviceInfo) bleApiDevice.getHInstance()).getDeviceAddress());
  } else {
      com.google.android.gms.fitness.Fitness.BleApi.claimBleDevice(googleApiClient,((com.google.android.gms.fitness.data.BleDevice) bleApiDevice.getGInstance()).getAddress());
  }
  ```


* To HMS API 示例代码需要替换为：

  ```screen
  HuaweiHiHealth.BLEMANAGER.saveDevice(hmsApiClient, bleApiDevice.getDeviceAddress());
  ```

## Scopes.FITNESS_NUTRITION_READ属性

如果代码中使用new Scope(Scopes.FITNESS_NUTRITION_READ)方法构造Scope对象时，在HMS中可以直接使用如下属性：

```screen
HuaweiHiHealth.SCOPE_HEALTHKIT_NUTRITION_READ
```

在Google API的调用示例如下：

```screen
GoogleApiClient googleApiClient = new GoogleApiClient.Builder(this).addApi(Fitness.HISTORY_API)
                    .addScope(new Scope(Scopes.FITNESS_NUTRITION_READ))
                    .build();
```

* Add HMS API 需要替换成如下代码：

  ```screen
  if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
      HiHealthKitClient hmsApiClient = new HiHealthKitClient.Builder(this).addApi(HuaweiHiHealth.DATA_MANAGER)
                          .addScope(HuaweiHiHealth.SCOPE_HEALTHKIT_NUTRITION_READ)
                          .build();
  } else {
      GoogleApiClient googleApiClient = new GoogleApiClient.Builder(this).addApi(com.google.android.gms.fitness.Fitness.HISTORY_API)
                          .addScope(new com.google.android.gms.common.api.Scope(com.google.android.gms.common.Scopes.FITNESS_NUTRITION_READ))
                          .build();
  }
  ```


* To HMS API 需要替换成如下代码：

  ```screen
  HiHealthKitClient hmsApiClient = new HiHealthKitClient.Builder(this).addApi(HuaweiHiHealth.DATA_MANAGER)

  ```
