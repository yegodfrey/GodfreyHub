# 抓帧

## 连接手机设备

1. 在工具左下角，点击"Replay Context"，从下拉菜单中选择设备进行连接。
2. 连接成功后，在Replay Context之后显示设备名称和Remote server ready。同时设备上显示已成功打开的com.huawei.squid界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/2gvuXyoTSemrMhYDX-raVA/zh-cn_image_0000001890772098.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=2F29F996E37498790A5B9E5F1DBB09B662BE257F441DE0BDEB31910715EB1622)

## 单帧抓取

1. 打开"Launch Application"窗口，Program界面的Executable Path中，从设备已安装应用列表中选择要调试抓帧的应用。如果应用启动需要参数配置才能运行，在Program界面的Intent Arguments中配置应用参数，默认不带参数配置启动应用。在Capture Options配置抓帧的选项。点击"Launch"按钮，开始启动调试抓帧的应用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/-7afuHczS1yq9iDsSMXcRg/zh-cn_image_0000001878262346.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=0031E2F18622E061129AA646A2F6B2BFEE4A1852C5BB625CA8A86315C9DEA2CA)

2. 当调试的应用启动运行后，Frame Profiler打开该调试应用进程抓帧的界面。当Connection Status显示Established， API显示OpenGL ES (Active) 或Vulkan (Active) ，表示抓帧应用启动成功。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/d8WO1hObQAuiaYENuAqyIw/zh-cn_image_0000001924141773.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=2B36C8A7B46AC139AB8588F897DDD498F638938BC8F7709D023F06DFA1BDCFBA)

   同时设备界面显示API协议、连接者用户名、帧率和已抓帧的数量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f/v3/YCq57fefRwOFkv-YXLFcJw/zh-cn_image_0000001924261373.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=BDFEC98028B68EAABEE68B029DC1C1D730B8B74C749253DF39317B0D9E36DB4D)

3. 在调试应用进程抓帧的界面，点击"Capture Frame(s) Immediately"，立即抓取当前显示的帧。抓取的帧在Captures collected列表显示如下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b/v3/NHzBxuVQSayESguFiiGSQw/zh-cn_image_0000001878102466.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=1754C3B542D1D48557A93A77315D9C9765391032435F8C3A598F11F106F79ABE)
   > 说明
   >
   > 在抓帧功能启动后，由于工具会分析GPU的API执行序列，建立资源间的依赖关系，分析游戏运行的资源数量及API调用的数量，抓帧功能运行阶段对运行会有不同程度的影响，所以在抓帧触发后界面会存在短暂的卡顿情况。

4. 选中抓取的帧，点击鼠标右键，点击"Save"选择保存到计算机上，或者点击"Open in... > This instance"直接回放该帧。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/1xT2UiYySFSxDBZudz-a4g/zh-cn_image_0000001878262350.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=84E6A5381B47ED187E18838309F9A723C97DB5065AB717215FB3404B8C324F01) ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/UlG6nomsSp-lAF25ORFLDQ/zh-cn_image_0000001924141777.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=5EC45AE2535509A16C2CB9A866AE850DE96067C60C86E7DF27F640159A7778C8)

## 延时抓取

1. 同[单帧抓取](#section12121153217120)中启动调试抓帧的应用。
2. 设置最大文件大小：超过设置大小后自动清空，重新抓取。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/JTkjn4_wSUqk84ejtYiQ1Q/zh-cn_image_0000001117832750.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=751F6AB78346662BD5EFDF174AC73DA41DCAAEA0346E128B858FEC6214616655)

3. 点击"Deferring Capture"延时抓取，超过设置的最大文件大小后，Delay size自动刷新。
4. 点击"Capture Stop"停止抓帧，并且显示抓取到的缩略图。

## 连续帧抓取

1. 同[单帧抓取](#section12121153217120)启动调试抓帧的应用。长时间抓取连续帧，文件过大可能导致闪退，建议减小最大文件大小，且保存文件后删除临时文件。
2. 点击"Sequential Frame(s) Start"按钮即可开始抓帧。

   抓连续帧前可以进行设置。
   1. 设置连续帧帧数，需要设置为大于10的数，点击"Sequential Frame(s) Start"后，到达设置帧数后停止抓帧。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/wQ0joLkaRHOmW_WiG6X1GA/zh-cn_image_0000001856249185.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=392C3C724AC792F8D0A9BF74D867307EF98F20AD21FEF84542AD4FFE266FA75C)
   2. 设置每隔多少帧获取一张截图，将在"TraceOutline"窗口展示。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/LB6RQ1ZZTcSwKl4YWDCIRg/zh-cn_image_0000001856169169.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=AE5B06E39844B50078B41EC90E9EABDB71FAE3A72C19AD3C19E1486635DB542D)
   3. 设置最大文件大小。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/Hh1cOEG-TPeSOywX_LKFBg/zh-cn_image_0000001809530388.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=BA1386253E1F3A91FD525C680750209EEA19729601A027166D5008137C71ED5A)

3. 再次点击"Sequential Frame(s) Stop"按钮停止抓帧，并且显示抓取到的缩略图。
4. 选中需要保存的帧，右键选中点击"Save"保存为sqd类型的文件。点击"Open in..."选择"This instance"或者双击缩略图，会跳转到"TraceOutline"界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0d/v3/VtCPQixeRmmWQzw9qCFwwA/zh-cn_image_0000001809370548.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=97CC9B4FAD9759DEB21411276A9C4E9B7890B15BEF53200A806ADAE6960FC014) ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/bpPMY27HQcqmkmK-nEjZNw/zh-cn_image_0000001856249189.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D48A291E6C2B51AB5D27921906A7E28B5032EEA6BE0C87D4592F746287BDA03)
   > 说明
   >
   > 任何超时操作会导致连接切换到local，要解决该问题，可以上调超时时间的数值：打开FrameProfiler主菜单"Tools > Settings > Core > Config Editor"，设置"RemoteServer > TimeoutMS"为50000。
   >
   > 重新打开工具即可生效，若仍有问题可将C:\Users\xxx\AppData\Roaming\squid\squid.conf文件删除。
   >
   > 抓取vulkan连续帧前，为提高连续帧抓取流畅性，可以打开FrameProfiler主菜单"Tools > Settings > Core > Config Editor"，启用"Vulkan > Debug > ForceToNotUseCoherentMemory"，减少连续帧体积，但该选项会强制改变内存类型，部分游戏不支持，可能会导致游戏闪退等异常。

## Vulkan跨平台抓取回放

1. 勾选"Override Vulkan GPU capabilities"。

   勾选"Launch application"窗口中的"Override Vulkan GPU capabilities"，点击"Launch"，运行应用程序，进行抓取并保存关键帧。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/vE_gq51TTXSjkU-RE9zdzg/zh-cn_image_0000001880998218.png?HW-CC-KV=V1&HW-CC-Date=20261008T185100Z&HW-CC-Expire=31536000000&HW-CC-Sign=66DE5FADC9B9F9286EEB3002E4482C485D741DA6776422EBBBDB1E08707ABA71)
   > 说明
   >
   > 勾选"Override Vulkan GPU capabilities"选项可能会导致无法运行应用程序，甚至产生崩溃。这意味着需要分析的应用程序不能用来与目标回放平台中的一组Vulkan扩展、功能和属性一起使用，也无法直接在目标平台上运行该应用。工具无法处理这种情况，对于这种应用程序来说，无法进行跨平台分析。
2. 在目标平台回放关键帧。 打开工具连接目标设备，选择打开上一步保存的关键帧文件，可以正常回放。
