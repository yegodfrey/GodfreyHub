# 公共API手工转换指导书

#### 方法返回值类型是非集合类型

public java.lang.Object getExtra(java.lang.String name)

public java.lang.Object getExtra(java.lang.String name, java.lang.Object defaultValue)

public java.io.Serializable getSerializable(java.lang.String key)

public \<T extends android.os.Parcelable\> T getParcelable(java.lang.String key)

public java.lang.Object get(java.lang.String key)

如果方法返回值是非XMS类型，您不需要进行手工转换。

如果方法返回值是XMS类型，您需要进行手工转换。

例如：

转换前的代码，Detector是已经转换成XMS的类型，

```
Bundle bundle = new Bundle();
Detector detector = null;
detector = (Detector) bundle.getParcelable("key");
```

需要对bundle.getParcelable()进行手工转换，如下所示：

```
Bundle bundle = new Bundle();
Detector detector = null;
if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
    detector = (Detector) Utils.getXmsObjectWithHmsObject(bundle.getParcelable("key"));
} else {
    detector = (Detector) Utils.getXmsObjectWithGmsObject(bundle.getParcelable("key"));
}
```

#### 方法返回值类型是数组

public android.os.Parcelable\[\] getParcelableArray(java.lang.String key)

如果返回值数组元素类型不是XMS类型，您不需要进行手工转换；

如果返回值数组元素类型是XMS类型，您需要进行手工转换。

```
        } else {
            return (Detector) Utils.getXmsObjectWithGmsObject(parcelable);
        }
    }
});
```

#### toJson方法入参对象类型是Type

public java.lang.String toJson(java.lang.Object src, java.lang.reflect.Type typeOfSrc)

void toJson(java.lang.Object src, java.lang.reflect.Type typeOfSrc, java.lang.Appendable writer)

void toJson(java.lang.Object src, java.lang.reflect.Type typeOfSrc, JsonWriter writer)

如果src是非XMS类型，或者src是集合类型（ArrayList，Set，Map，数组等），元素不是XMS类型，您不需要做任何变动；

如果src是XMS类型，或者src是集合类型（ArrayList，Set，Map，数组等），元素是XMS类型，您需要进行手工转换。

例如：

src是ArrayList类型，并且元素是XMS类型，调用Utils中的mapList2GH方法，如：

```
Gson gson = new Gson();
List<DataSource> dataSourceList = new ArrayList<>(); // 此处new仅供示例用，实际代码中要取对应的ArrayList对象
gson.toJson(Utils.mapList2GH(dataSourceList, org.xms.g.utils.GlobalEnvSetting.isHms()), ArrayList.class);
```

src是Map类型，并且元素是XMS类型，调用Utils中的converMap方法，如：
