# 出现Graphics Profiler Server connection timed out报错应如何解决？

![](https://media:201778750889630158)

问题原因：部分设备上，后台进程的电源策略可能会阻止Graphics Profiler server在后台运行。

解决方法：手动在设备的设置中找到"应用启动管理"页面，对Graphics Profiler启用"允许后台运行"选项。
