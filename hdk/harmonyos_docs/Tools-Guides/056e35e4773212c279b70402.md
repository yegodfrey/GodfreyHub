# 出现Graphics Profiler Server connection timed out报错应如何解决？

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/y6I4Xj33TSSetF-Mc0mzzQ/zh-cn_image_0000002380485216.png?HW-CC-KV=V1&HW-CC-Date=20261008T161652Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E317FFAF3C273F300262B5A78FFE8AD3BC7F5593E9BE94704C5D7D472E5472F)

问题原因：部分设备上，后台进程的电源策略可能会阻止Graphics Profiler server在后台运行。

解决方法：手动在设备的设置中找到"应用启动管理"页面，对Graphics Profiler启用"允许后台运行"选项。
