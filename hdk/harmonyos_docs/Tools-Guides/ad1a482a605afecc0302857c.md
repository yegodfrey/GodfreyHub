# EGL外部纹理

OpenGL ES API允许使用纹理和缓冲区分配使用EGLimage概念的应用程序之外，最常见的用例是视频帧处理，而无需将数据复制到CPU或从CPU复制数据。大多数使用视频的OpenGL ES应用程序都使用EGL外部纹理。  

#### 支持扩展

* GL_OES_EGL_image
* GL_OES_EGL_image_external
* GL_OES_EGL_image_external_essl3 ("samplerExternalOES" type in shader reflections).
* EGL_ANDROID_image_native_buffer
* EGL_KHR_gl_texture_2D_image
* EGL_KHR_image_base
* EGL_OES_image
* EGL_OES_image_base
* EGL_OHOS_image_native_buffer  

#### 限制条件

* Android和OHOS native buffers由2D纹理模拟，"eglCreateImageKHR"调用的"target"参数在回放时始终为"EGL_GL_TEXTURE_2D_KHR"。
* "glEGLImageTargetTexture2DOES"仅支持"target"参数"GL_TEXTURE_EXTERNAL_OES"和"GL_TEXTURE_2D"。
* "eglCreateImageKHR"的"attr_list"只能包含"EGL_IMAGE_PRESERVED_KHR"、"EGL_NONE"、"EGL_GL_TEXTURE_LEVEL_KHR"属性，其他值将被忽略。
* 不支持并忽略"eglCreateImageKHR"的"attr_list"中的非零"EGL_GL_TEXTURE_LEVEL_KHR"值。
