# Cloud Debugging

HMS Toolkit为您提供Cloud Debugging功能，即远程真机调试功能。覆盖多种华为机型，7*24小时不间断测试。可以解决您在进行应用调试时无设备、设备类型不全、Bug无法复现等问题，让您随时随地直观的了解App在华为设备上的运行表现，帮助您打造更好的应用使用体验。

Cloud Debugging功能每次使用时您可以选择最长2小时的指定机型体验时长，到期前，您可以先释放设备资源，然后再重新申请该设备即可。第一次使用时，HMS Toolkit会为用户分配24小时的Cloud Debugging时长，到期后系统会自动提醒用户是否续申请，一次可以续申请8小时。请您合理高效的利用设备资源，及时释放空闲的设备。
> 说明
>
> * 使用Cloud Debugging功能，需要注册华为帐号并进行实名认证后，登录使用。
> * 云调试服务已于2023年6月30日起在中国、亚洲、非洲和拉丁美洲下架，当前仅在欧洲、俄罗斯可用。
> * 如果您在使用过程中发生画面连接通道断开的问题，解决方法请参见[使用Cloud Debugging功能时，画面连接通道断开，导致用户使用阻塞，应该如何解决](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/faq-0000001050061059#section1624117381269)。

Cloud Debugging支持预约测试、续时和音频传输功能。

* 预约测试 选择设备后，点击"RESERVED"，选择预约测试的日期和时间段。最多可以提前72小时预约，预约成功后，设备将在预约时间开始后锁定10分钟，过期则被释放，请及时使用。

  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240104215407.24666426997372398015100353276815:50001231000000:2800:EF041759CC60BCBE68F7B9D70C7D6573B89BA101B4675AD220CD16348668E1EE.png?needInitFileName=true?needInitFileName=true "点击放大")

  预约成功后可以在"Reservation record"页面点击"abandon"随时取消预约。

  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240104215407.82215441731083473501668861611495:50001231000000:2800:93CE733B8148B12D1734FD173C2BEF19416A79F1AE0CC6E57EE8EC00F56277B3.png?needInitFileName=true?needInitFileName=true "点击放大")
* 续时 启动测试后，您可以点击"Apply Device Time"来申请续时，最多可以续时2小时。

  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240104215408.94734126479410470627039879419165:50001231000000:2800:2202A36660610174DB7F858CE5DC160AE4CC5D3D576D17EB563BE66B3FC5AD4B.png?needInitFileName=true?needInitFileName=true "点击放大")
* 远程真机P40、P40 Pro、Mate 30、Mate 30 Pro在中国区域内支持音频传输。
