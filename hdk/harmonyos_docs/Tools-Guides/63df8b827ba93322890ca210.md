# 主界面

华为快应用IDE主界面包括5大区域：编辑区（区域1）、菜单区（区域2）、快捷运行区（区域3）、资源区（区域4、5）、控制台区（区域6）。
> 说明
>
> 海外版本不存在开发者登录和提交测试的能力。

菜单栏包含如下功能：

* 文件：新建项目、导入项目、打开项目、打开RPK、最近打开、新建文件、新建卡片、新建页面、保存、另存为、全部保存、自动保存、首选项等功能，其中首选项包含设置、快捷方式、主题、语言等功能。
* 编辑：剪切、复制、粘贴、查找等功能。
* 查看：资源管理器、搜索等功能。
* 构建：构建快应用、清除构建、打包正式版本。
* 工具：生成证书、支付签名校验、webview调试工具、运行快服务助手、远程真机（海外版本暂不支持）、模拟器、局域网连接。
* Npm：启动第三方Npm库。
* Hap：启动联盟工具。
* 应用发布：发布应用、快服务卡片发布指导。
* 帮助：文档、FAQ、检查更新（IDE在每次打开项目或者每隔24小时会自动触发）、检查快服务助手更新、切换开发人员工具、打开进程管理器、问题反馈、论坛、关于等功能。
