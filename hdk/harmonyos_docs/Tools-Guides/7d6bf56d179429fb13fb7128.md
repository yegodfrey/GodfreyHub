# 概述

Graphics Profiler（图形性能调优）是专为GPU分析和优化提供的一种调试工具，可帮助OpenGL ES游戏或Vulkan游戏以及其他GPU应用提升性能及解决绘制和计算问题。用于HarmonyOS的性能分析工具，提供了系统级和应用程序级的跟踪记录和分析，其中包括马良 GPU性能指标、GPU and driver events、OpenGL ES和Vulkan命令及其参数，以及来自操作系统的数据。实现UI可视化、支持Multi-GB数量级的数据抓取、基于时间轴显示数据内容和可以进行SQL数据查询。

图形性能调优工具包含插件Frame Profiler（帧分析工具）：通过捕获基于Vulkan或OpenGL ES的单帧或者连续帧，分析渲染和计算管道流水线上不同阶段的图形标准API协议执行序列。对于调用关系进行层层分解，使调试用户清楚了解输入及输出的资源关系，以此识别、定位和解决应用程序的渲染和计算问题。

## 支持的平台

|Graphics Profiler|运行环境要求|
|:----------------|:------------------------------------------------------------------------------------------|
|主机系统|操作系统：Windows10 x64、Windows11 x64、Mac ARM、Mac-x86 内存：8GB及以上 硬盘存储：100GB及以上|
|依赖软件|adb版本（HarmonyOS 4.0及以下版本）：1.0.39及以上 hdc版本（HarmonyOS 5.0及以上版本）：1.3.0a及以上|
|目标设备|Windows支持马良 GPU的HarmonyOS4.0及以下版本、HarmonyOS 5.0及以上版本系统设备 MacOS支持马良 GPU的HarmonyOS 5.0及以上系统设备|
|系统字体|推荐缩放与布局：100%|
|分辨率|推荐使用1920 * 1080分辨率|
|API|OpenGL ES 2.0 - 3.2、Vulkan 1.0 - 1.3|

* 主机系统：工具运行的平台。
* 目标设备：分析的应用程序运行的系统平台。

> 说明
>
> * MacOS仅支持FrameProfiler相关功能。
> * MacOS暂不支持外部纹理场景及Overdraw分析。
