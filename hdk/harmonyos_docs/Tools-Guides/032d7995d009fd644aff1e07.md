# 监测项预设置

工具支持四种默认presets配置：

1. Overview包含CPU Load、Scheduling details、GPU Counters
2. GPU bound analysis包含GPU Counters、GPU and Driver Events、GPU Memory、Frames per second、Scheduling details、DDR Counters、GPU API Events、Atrace userspace annotations（Graphics、Graphics (HAL)）、HiTrace categories（Graphic Module）
3. CPU bound analysis包含CPU Load、CPU Frequency、Detailed CPU Counters、Scheduling details、Callstack sampling、Frames per second
4. System analysis包含CPU Load、CPU Frequency、Scheduling details、GPU Counters、GPU Memory、DDR Counters、Frames per second、Atrace userspace annotations（Graphics）、HiTrace categories（Graphic Module、ACE development framework、Commercial version tag、Device frequencies）

   用户也可按以下步骤来自定义配置模板。


1. 点击"Record new trace"连接设备，勾选模板需要的监测项，点击"Presets"，选中"Unnamed"，点击下图中的图标。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/LIAr3xS7SEurAo-2qaJ0ng/zh-cn_image_0000002145819700.png?HW-CC-KV=V1&HW-CC-Date=20261008T143539Z&HW-CC-Expire=31536000000&HW-CC-Sign=0FC3140209EEAA2AC96EF6773B9BD9A7F894248E6E1F542125514F390B2FBA1A)

2. 输入模板名称，点击"Save"保存。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/S0gVP7qJTa6uf_9vsVvziQ/zh-cn_image_0000002145977844.png?HW-CC-KV=V1&HW-CC-Date=20261008T143539Z&HW-CC-Expire=31536000000&HW-CC-Sign=3CC7DE2B376EE4B8B757A40421D209F9E2F26724787AD02D5F8F9BB3D16321F5)

3. 选中trace模板，点击右侧"√"图标，自动勾选预设的监测项。如果需要删除该trace模板，请点击删除图标。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e0/v3/t_GnneGHTgmBo6wC5YqxGw/zh-cn_image_0000002181219001.png?HW-CC-KV=V1&HW-CC-Date=20261008T143539Z&HW-CC-Expire=31536000000&HW-CC-Sign=CDF93D5EFD145985D8DE6BE6C8404E4718BBF8C4D8B744DC0945F35A445EE6DB)
