# Location Kit手工转换指导书

目前Google API中使用GoogleApiClient类的API均已被废弃，在Add HMS API和To HMS API的场景下，都需要您进行手工转换。以下内容可以帮助您将这些已废弃的API手工转换成最新的实现。  

#### ActivityIdentificationData(int var1, int var2)

|Google API|Add HMS API|To HMS API|
|:---------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|new DetectedActivity(activityType, confidence)|ActivityIdentificationData(identificationActivity, possibility) 说明：构造方法抛出新异常ApiException，表示ActivityIdentificationData构造对象失败，您自行处理。|new [ActivityIdentificationData](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationdata-0000001050706134#ZH-CN_TOPIC_0000001050706134__section483016191826)(identificationActivity, possibility) 说明：方法抛出新异常ApiException，表示[ActivityIdentificationData](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationdata-0000001050706134)构造对象失败，您自行处理。|

DetectedActivity()的实现如下：

```
import com.google.android.gms.location.DetectedActivity;
import java.util.ArrayList;
import java.util.HashMap;
 
HashMap<Integer, Integer> detectedActivitiesMap = new HashMap<>();
for (DetectedActivity activity : detectedActivities) {
    detectedActivitiesMap.put(activity.getType(), activity.getConfidence());
}
// Every time we detect new activities, we want to reset the confidence level of ALL
// activities that we monitor. Since we cannot directly change the confidence
// of a DetectedActivity, we use a temporary list of DetectedActivity objects. If an
// activity was freshly detected, we use its confidence level. Otherwise, we set the
// confidence level to zero.
ArrayList<DetectedActivity> tempList = new ArrayList<>();
for (int i = 0; i < Constants.MONITORED_ACTIVITIES.length; i++) {
    int confidence = detectedActivitiesMap.containsKey(Constants.MONITORED_ACTIVITIES[i])
        ? detectedActivitiesMap.get(Constants.MONITORED_ACTIVITIES[i]) : 0;
    tempList.add(new DetectedActivity(Constants.MONITORED_ACTIVITIES[i], confidence));
}
// Remove all items.
clear();
// Adding the new list items notifies attached observers that the underlying data has
// changed and views reflecting the data should refresh.
for (DetectedActivity detectedActivity : tempList) {
    add(detectedActivity);
}
```

DetectedActivityService.class：

```
import java.util.ArrayList;
import org.xms.g.location.ActivityRecognitionResult;
import org.xms.g.location.DetectedActivity;
import android.app.IntentService;
import android.content.Intent;
import android.util.Log;
public class DetectedActivityService extends IntentService {
    protected static final String TAG = "DetectedActivityService";
    public DetectedActivityService() {
        super(TAG);
    }
    @Override
    public void onCreate() {
        super.onCreate();
    }
    @Override
    protected void onHandleIntent(Intent intent) {
        ActivityRecognitionResult result = ActivityRecognitionResult.extractResult(intent);
        if (result != null) {
            ArrayList<DetectedActivity> detectedActivities =
                (ArrayList<DetectedActivity>) result.getProbableActivities();
            for (DetectedActivity detectedActivity : detectedActivities) {
                Log.i(TAG, detectedActivity.getType() + " " + detectedActivity.getConfidence() + "%");
            }
        }
    }
}
```
