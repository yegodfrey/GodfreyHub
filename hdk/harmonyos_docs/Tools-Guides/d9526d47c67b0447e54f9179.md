# Account Kit手工转换指导书

## 开发准备

您若需要应用支持Account Kit，必须完成接入准备，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050196065)。

必备步骤主要包括：

1. 在华为开发者联盟（AppGallery Connect）上创建应用。
2. 开通华为帐号服务。

## GoogleSignIn.getAccountForScopes方法

使用com.google.android.gms.auth.api.signin.GoogleSignIn类的getAccountForScopes方法时，需要按以下方式转换：

* Google API原调用示例

  ```screen
  GoogleSignInAccount account = GoogleSignIn.getAccountForScopes(this, scope);
  ```


* Add HMS API

  ```screen
  ExtensionSignInAccount account = null;
  com.google.android.gms.auth.api.signin.GoogleSignInAccount gReturn = null;
  com.huawei.hms.support.hwid.result.AuthHuaweiId hReturn = null;
  if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
      List<com.huawei.hms.support.api.entity.auth.Scope> scopeList = new ArrayList<>();
      scopeList.add((com.huawei.hms.support.api.entity.auth.Scope) scope.getHInstance());
      try {
          hReturn = com.huawei.hms.support.hwid.HuaweiIdAuthManager.getAuthResultWithScopes(scopeList);
      } catch (com.huawei.hms.support.hwid.common.HuaweiIdAuthException e) {
          // handle exception
      }
  } else {
      gReturn = com.google.android.gms.auth.api.signin.GoogleSignIn.getAccountForScopes(this,
          (com.google.android.gms.common.api.Scope) scope.getGInstance());
  }
  if (hReturn != null || gReturn != null) {
      account = new org.xms.g.auth.api.signin.ExtensionSignInAccount(gReturn, hReturn);
  }
  ```


* To HMS API

  ```screen
  List<com.huawei.hms.support.api.entity.auth.Scope> scopeList = new ArrayList<>();
  scopeList.add(scope);
  try {
      com.huawei.hms.support.hwid.result.AuthHuaweiId account =
      com.huawei.hms.support.hwid.HuaweiIdAuthManager.getAuthResultWithScopes(scopeList);
  } catch (com.huawei.hms.support.hwid.common.HuaweiIdAuthException e) {
      // handle exception
  }
  ```

## GoogleSignIn.requestPermissions(Fragment, int, GoogleSignInAccount, GoogleSignInOptionsExtension)方法

使用com.google.android.gms.auth.api.signin.GoogleSignIn类的requestPermissions(Fragment, int, GoogleSignInAccount, GoogleSignInOptionsExtension)方法时，需要按以下方式转换：

* Google API原调用示例

  ```screen
  GoogleSignIn.requestPermissions(fragment, RC_REQUEST_PERMISSION, googleSignInAccount, mGoogleSignInOptionsExtension);
  ```


* Add HMS API

  ```screen
  ExtensionSignIn.requestPermissions(fragment.getActivity(), RC_REQUEST_PERMISSION, googleSignInAccount, mGoogleSignInOptionsExtension);
  ```


* To HMS API

  ```screen
  com.huawei.hms.support.hwid.HuaweiIdAuthManager.addAuthScopes(fragment.getActivity(), RC_REQUEST_PERMISSION, huaweiIdAuthExtendedParams);
  ```

## 使用涉及常量的switch语句

如果在您的代码中使用了Google API中的常量进行switch语句判断，需要修改为if else语句，参考转换方式如下：

* Google API原调用示例

  ```screen
  switch (code) {
      case CommonStatusCodes.SUCCESS:
      // ...
      case CommonStatusCodes.CANCELED:
      // ...
  }
  ```

* Add HMS API

  ```screen
  if (code == CommonStatusCodes.getSUCCESS()) {
      // ...
  } else if (code == CommonStatusCodes.getCANCELED()) {
      // ...
  }
  ```
