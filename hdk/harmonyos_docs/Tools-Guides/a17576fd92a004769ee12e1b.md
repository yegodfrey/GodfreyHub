# Shader Analysis界面

点击"File > Open Capture"，打开rdc文件，点击"Window > Shader Analysis"，然后再点击"Analyze Shaders"即可查看。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/IXPzSJp7RECESfKHHf0ZbA/zh-cn_image_0000002509323595.png?HW-CC-KV=V1&HW-CC-Date=20261008T172749Z&HW-CC-Expire=31536000000&HW-CC-Sign=696D47062A95E45244CFAFC149422D0BBC58CE1F30AD1564D61B9F63A8C08F56)

双击提示窗口的某一行信息，可以跳转到对应的shader profiler窗口，点击提示窗口中Shader ID的资源链接，可以跳转到Resource Inspector窗口。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/liq8ZmegTQafIjKkJWDNYw/zh-cn_image_0000002477243644.png?HW-CC-KV=V1&HW-CC-Date=20261008T172749Z&HW-CC-Expire=31536000000&HW-CC-Sign=C9A8F94B3955EFB95F298FCB7C4AC30FCAD89B1AE11C503877A389A36CAFA7F1)

|指标|描述|
|:-------------------------------------|:--------------|
|EID|事件ID|
|Shader ID|着色器ID|
|Stage|渲染管线的阶段（VS/FS）|
|Duration|持续时间占比|
|Average Time (cycles)|平均时间（周期）|
|Invocations|着色器调用次数|
|EU Cycles|执行单元执行命令的周期数|
|SIMD|SIMD模式|
|Registers|在着色器中使用的通用寄存器数量|
|Constant registers|在着色器中使用的常量寄存器数量|
|Private memory usage per- thread(Byte)|私有内存使用量|
|Nested depth|嵌套深度层级|
|Memory instructions|内存指令数量|
|Memory Read instructions|内存读取指令数量|
|Memory Write instructions|内存写入指令数量|
|ALU instructions|ALU指令数量|
|ALU 32-bit instructions|ALU 32位指令数量|
|ALU 16-bit instructions|ALU 16位指令数量|
|ALU 16-bit ratio (%)|ALU 16位指令所占百分比|
|Control flow instructions|控制流指令数量|
