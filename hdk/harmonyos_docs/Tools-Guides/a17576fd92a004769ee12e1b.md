# Shader Analysis界面

点击"File \> Open Capture"，打开rdc文件，点击"Window \> Shader Analysis"，然后再点击"Analyze Shaders"即可查看。

![](https://media:201778750904653478)

双击提示窗口的某一行信息，可以跳转到对应的shader profiler窗口，点击提示窗口中Shader ID的资源链接，可以跳转到Resource Inspector窗口。![](https://media:201778750904702479)  

|指标|描述|
|:-------------------------------------|:--------------|
|EID|事件ID|
|Shader ID|着色器ID|
|Stage|渲染管线的阶段（VS/FS）|
|Duration|持续时间占比|
|Average Time (cycles)|平均时间（周期）|
|Invocations|着色器调用次数|
|EU Cycles|执行单元执行命令的周期数|
|SIMD|SIMD模式|
|Registers|在着色器中使用的通用寄存器数量|
|Constant registers|在着色器中使用的常量寄存器数量|
|Private memory usage per- thread(Byte)|私有内存使用量|
|Nested depth|嵌套深度层级|
|Memory instructions|内存指令数量|
|Memory Read instructions|内存读取指令数量|
|Memory Write instructions|内存写入指令数量|
|ALU instructions|ALU指令数量|
|ALU 32-bit instructions|ALU 32位指令数量|
|ALU 16-bit instructions|ALU 16位指令数量|
|ALU 16-bit ratio (%)|ALU 16位指令所占百分比|
|Control flow instructions|控制流指令数量|
