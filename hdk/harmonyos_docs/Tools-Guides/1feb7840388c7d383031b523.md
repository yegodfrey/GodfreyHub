# Gradle信息维护

## 配置defaultConfig{}区块minSdkVersion

```screen
defaultConfig {
    minSdkVersion 10     //编译支持的最低版本，该版本号不能小于HMS服务支持的最低版本号
    targetSdkVersion 23
}
```

## 配置android{}区块JDK版本

您在使用HMS Core相关服务时，需要考虑在app的build.gradle中添加compileOptions。

由于HMS Core服务使用JDK 1.8版本，为了兼容建议JDK版本不应低于1.8。

```screen
//Java版本8
android{
    compileOptions {
         sourceCompatibility JavaVersion.VERSION_1_8
         targetCompatibility JavaVersion.VERSION_1_8
     }
}
```

## 添加对xmsadapter模块的依赖

Convertor工具在做Add HMS API转换时，可以将新生成的代码作为一个独立的module来管理，该module默认命名为xmsadapter。

使用HMS接口时需要依赖这个module，所以要在已有模块中添加对xmsadapter的依赖。

1. 模块级的build.gradle的dependencies{}节点中需要添加。

   ```screen
   implementation project(':xmsadapter')
   ```

2. 项目级的settings.gradle中需添加。

   ```screen
   include ':xmsadapter'
   ```
