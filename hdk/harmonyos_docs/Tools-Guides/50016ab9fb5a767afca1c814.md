# 智能抓帧界面

智能抓帧是指可以在设置特定状态下自动触发抓帧的功能，可以设置的状态有如下图中的选项。

![](https://media:201778750898186332)

智能抓帧界面。

![](https://media:201778750898218333)

每个选项表示的意义如下。

* Frame Number：设置特定帧号，例如指定抓取第1000帧。
* RT Clear：glclear的调用次数，例如某一帧超过100次后就开始抓帧。
* Error Gets：glGetError的调用次数，例如某一帧超过100次后就开始抓帧。
* Use Program Calls：一帧中使用Program的数量，例如某一帧超过100个后就开始抓帧。
* BindBuffer Calls：一帧中glBindBuffer的数量，例如某一帧超过100个后就开始抓帧。
* BindTexture Calls：一帧中glBindTexture的数量，例如某一帧超过100个后就开始抓帧。
* RT Changes： 一帧中RT改变的数量，简单统计为frame切换次数，例如某一帧超过100次后就开始抓帧。
* Draw Calls：一帧中Drawcall的数量，例如某一帧超过100个后就开始抓帧。
* Vertex Count：一帧中Vertex的数量，例如某一帧超过10000个后就开始抓帧。
* Indexed Vertex Count：一帧中索引定点的数量，例如某一帧超过10000个后就开始抓帧。
* FPS：当帧率低于设定值时进行抓帧。
* Frame Time：判断当前帧的时长，满足条件进行抓帧。
* GPU Frequency：GPU频率低于某个值开始抓帧。
* USE DifferentShader：当前帧使用了以前都未使用过的Shader，进行抓帧。
