#### ux文件定义跳转

template 支持 class 和 id 的跳转、变量跳转、方法跳转、自定义组件跳转，script 支持接口的跳转等。

mac 下按住 command + 左键， windows 下 ctrl + 左键，光标将直接跳转到定义处。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250807165406.34985103746851915282606662386982:50001231000000:2800:97D2CA57D8E3D3079DC03D0319E9FBA240DCB232AE2934DFD2820D01BE903C15.gif)  

#### ux文件链接跳转

mac 下按住 command + 左键， windows 下 ctrl + 左键，光标将直接跳转到链接的文件。
