# 运行环境的Adb、Hdc如何配置？

**处理步骤**

1. 如果提示adb或hdc找不到。需要在"控制面板 > 系统和安全 > 系统"中，打开"高级系统配置 > 高级 > 环境变量"。
2. 在弹出的"系统变量"中添加一个adbtools或hdctools的路径，下面以adb为例。

   1. 点击"新建"按钮。
   2. 新增变量名，名称为"adbtools"，并将安装了adbtools工具的完整路径填入"变量值"中。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/Zzmg7vGXRv-9CqTT7eVmtA/zh-cn_image_0000002443043868.png?HW-CC-KV=V1&HW-CC-Date=20261008T150142Z&HW-CC-Expire=31536000000&HW-CC-Sign=998FE0B3395EA83124FA593B830652F86346A2F4CDE18CADA390471B49569B86)
   3. 添加完成后，点击"确定"按钮，系统变量已增加adbtools。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/zk5ucwdqQhSniUfERLvHwA/zh-cn_image_0000002443203880.png?HW-CC-KV=V1&HW-CC-Date=20261008T150142Z&HW-CC-Expire=31536000000&HW-CC-Sign=9119C06098536554199C430D0FF9A8736568AF03AB5E4578B6DE452EB7D997F9)
      > 注意
      >
      > hdc不支持中文安装路径，工具会进行提示。

3. 添加完adbtools或hdctools路径后，需要添加一个系统Path的值，将刚才设定的路径加入其中。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/jvc6PQkfT_WQHWkD7Ma0cg/zh-cn_image_0000002443204156.png?HW-CC-KV=V1&HW-CC-Date=20261008T150142Z&HW-CC-Expire=31536000000&HW-CC-Sign=18CBF05719B45DB09715B2A6ED3520521856C7FCE0EFDE3DF2BF6A7764C33D96)

4. 找到系统变量Path，并双击，在弹出的界面中添加一个%adbtools%或%hdctools%并保存，或者将adbtool或hdctool绝对路径添加到Path变量，下图以adb为例。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/Nz-6dqkAQ0SlfI7qVGlhHQ/zh-cn_image_0000002476444089.png?HW-CC-KV=V1&HW-CC-Date=20261008T150142Z&HW-CC-Expire=31536000000&HW-CC-Sign=3A4F6484FC1D259EAB1BED1531AAF93DC35C0FF0BE359A36F1AF80715DAFCF2A)

5. 重新打开应用程序或重新启动一个cmd命令端执行adb devices或hdc list targets。
6. 启动运行Frame Profiler。
