# 运行Frame Profiler工具

1. 打开Graphics Profiler的UI界面，点击"Navigation"下的"Record new frame"，运行Frame Profiler。
2. 检查版本是否正确。假设目标平台的版本与主机平台的工具版本不匹配时，连接管理界面会提示错误的版本。
3. 在选择目标平台后，会弹框提示要求更换目标平台，点击"OK"按钮即可。
