# Repository

Repository提供HMS Core开放能力的管理功能，您可以对资源进行下载，并对XMS代码进行一键升级。

## 资源下载

您可以根据使用到的HMS Core开放能力进行对应资源的下载，HMS Toolkit会自动将该能力的依赖信息写入对应模块下的build.gradle文件中。

1. 在菜单栏中选择"HMS > Repository"或者在工具栏中点击如下图标。

## xmsadapter一键升级

您可以对xmsadapter代码进行一键升级。

1. 在菜单栏中选择"HMS > Repository"或者在工具栏中点击如下图标。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174809.68570094790253468215875378711628:50001231000000:2800:0377875BD5FE3E4466CFF674D171BC0B427CF330564072F6CEF58FBF641628A6.png?needInitFileName=true?needInitFileName=true "点击放大")
2. "Module"选择"xmsadapter"。关于HMS和GMS的升级情况以及界面的几个按钮功能说明如下：

   |HMS/GMS版本升级情况||按钮功能|||
   |HMS版本是否需要升级|GMS版本是否选择升级|Update All|Apply|OK|
   |:----------|:----------|:---------------------|:---------------------|:----------------------------|
   |否|否|不显示|置灰|关闭当前页面|
   |否|是|不显示|GMS升级为选择的版本|GMS升级为选择的版本，关闭当前页面|
   |是|否|HMS升级为最新版本|置灰|HMS升级为最新版本，关闭当前页面|
   |是|是|HMS升级为最新版本，GMS升级为选择的版本|HMS升级为最新版本，GMS升级为选择的版本|HMS升级为最新版本，GMS升级为选择的版本，关闭当前页面|

   > 说明
   > * 当HMS Kit所取版本号非官方最新时，或者GMS Kit所取版本号不在工具的支持范围内，则会提示（UNAVAILABLE）信息。
   > * 当GMS Kit的依赖存在且HMS Kit的依赖不存在时，缺失部分会提示missing信息（HMS Kit的依赖存在且GMS Kit的依赖不存在时亦然）。
   > * 由于HMS Framework存在隐式依赖，当GMS Framework Kit存在且HMS Framework Kit未显式声明时，会默认显示HMS对应最新版本号。
   > * 由于FirebaseCore Kit在HMS中不对标，版本号默认置为"---"。
