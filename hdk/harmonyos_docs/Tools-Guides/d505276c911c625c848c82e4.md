# 查看及分析纹理

本章节主要介绍如何使用用户友好的名称标注资源，以便在整个帧中更易于跟踪资源的使用，以及按名称而不是按用法查找和跟踪纹理的功能。

## 用名称标注资源

当资源被赋予有意义的名称时，便于浏览和调试数据帧，同时将调试信息包括在着色器中并标记分层的用户定义区域。

这样做的方法因API而异。

* 在OpenGL ES中，可以使用GL_KHR_debug-glObjectLabel。

  ```screen
  // Creating an example resource - a 2D Texture.
  GLuint tex2d = 0;
  glGenTextures(1, &tex2d);
  glBindTexture(GL_TEXTURE_2D, tex2d);
  // apply the name, -1 means NULL terminated
  glObjectLabel(GL_TEXTURE, tex2d, -1, "Example Texture");
  ```


* 在Vulkan中，可以启用Frame Profiler提供的VK_EXT_debug_marker扩展，并使用vkDebugMarkerSetObjectNameEXT函数。

  ```screen
  // At creation time, request the VK_EXT_debug_marker extension and use vkGetInstanceProcAddr to obtain vkDebugMarkerSetObjectNameEXT
  // create the image
  VkImage tex2d;
  vkCreateImage(device, &createInfo, NULL, &tex2d);
  // set the name
  VkDebugMarkerObjectNameInfoEXT nameInfo = {};
  nameInfo.sType = VK_STRUCTURE_TYPE_DEBUG_MARKER_OBJECT_NAME_INFO_EXT;
  nameInfo.objectType = VK_DEBUG_REPORT_OBJECT_TYPE_IMAGE_EXT;
  nameInfo.object = (uint64_t)tex2d;
  // this cast may vary by platform/compiler
  nameInfo.pObjectName = "Swapchain Image 252";
  vkDebugMarkerSetObjectNameEXT(device, &nameInfo);
  ```

## 纹理查看器中的纹理列表

在纹理查看器中，打开捕获中所有纹理的可过滤列表。 可以使用纹理列表图标打开它，点击此按钮将在纹理查看器上打开一个侧栏，其中列出了所有纹理。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/LG7Z2x6BQwGhDbLEOAUpaA/zh-cn_image_0000001050755953.png?HW-CC-KV=V1&HW-CC-Date=20260909T165036Z&HW-CC-Expire=31536000000&HW-CC-Sign=7FF4F58FEE7036E65F8772E13FD247F708E569750A6C025290174A64F4C35469)

可以使用自定义字符串过滤该纹理列表，缩小显示纹理列表的范围。从此处选择并打开其中一个纹理时，将在纹理查看器中打开一个新选项卡。
