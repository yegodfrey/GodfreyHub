# 版本更新说明

#### 1.4.0.322（2021-06-24）

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|新增特性 更新PC版本，更新内容如下： * 人脸锚点，在编辑时选择人脸部位将模型快速定位到人脸 * 2D控件 * 新增音频控件 * 按钮、文本框、图片、文本面板控件增加透明度属性 * 图片控件增加宽高设置 * 3D控件 * 序列帧图片，修改贴图设置方式，配置参数增加刷新间隔、是否循环和是否朝向相机 * 标签，可以给场景部件增加说明 * 动作库，支持为人形模型快速绑定动作库动画（人形模型骨骼需按给定标准设计） * 屏幕贴图，选择一组序列帧图片，图片会覆盖屏幕并按时间间隔播放 * BlendShape表情查看 * 支持RSDZ格式文件导入和导出 修改特性 * 克隆功能支持带蒙皮的节点 * 移除默认灯光组，移除环境贴图属性，支持设置场景HDR环境贴图 * 动画时间轴操作优化 * 动画事件增加重置和循环选项，交互类型增加顺序播放|

#### 1.4.0.320（2021-04-27）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|新增特性 新增Android平板版本，PC版未同步以下更新 * AR预览，支持将场景放入真实环境中 * 人脸锚点，在AR预览中，调用前置摄像头识别人脸，将场景的组件附着在人脸上 * 2D控件 * 新增音频控件 * 新增手势控件，在AR预览通过手势触发事件 * 按钮、文本框、图片、文本面板控件增加透明度属性 * 图片控件增加宽高设置 * 3D控件 序列帧图片，修改贴图设置方式，配置参数增加刷新间隔、是否循环和是否朝向相机 * 动作库，支持为人形模型快速绑定动作库动画（人形模型骨骼需按给定标准设计） * 模型库 在线模型库：增加在线模型，需要联网使用 * BlendShape表情查看 * 支持RSDZ格式文件导入和导出 修改特性 * 克隆功能支持带蒙皮的节点 * 移除默认灯光组，移除环境贴图属性，支持设置场景HDR环境贴图 * 动画时间轴操作优化 * 动画事件增加重置和循环选项，交互类型增加顺序播放|

|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
