# C++ 语言支持

**C++ 语言规范**

C++语言规范支持到C++17标准，C++语言规范请参考官网：[https://clang.llvm.org/cxx_status.html](https://clang.llvm.org/cxx_status.html)。

**C++ 库**

在工具链中，将llvm-project项目中的libcxx和libcxxabi作为C++库使用。这些库被编成RISCV32架构下的静态和动态共享库，并依赖于MUSL C语言库。C++库规范请参考官网：

[https://releases.llvm.org/15.0.4/projects/libcxx/docs/ReleaseNotes.html](https://releases.llvm.org/15.0.4/projects/libcxx/docs/ReleaseNotes.html)。

**C++ 规范限制**

1.不支持C++异常处理。

2.不支持模板<class_Tp>abs(std::Complex<_Tp>&x)。

3.如果要使用char_traits<char>，必须包含<__string>。

4.如果要使用函数std::copy，必须包含<algorithm>。

5.在std::map<key, value>中，如果在key或value中使用关键字'const'，则不能使用运算符'='在两个实例之间设置值。
