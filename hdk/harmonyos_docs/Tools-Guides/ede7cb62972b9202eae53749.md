# 使用CLI工具

Graphics Profiler包含两个命令行工具：trace_recorder和trace_processor，位于Graphics Profiler安装目录中的cli文件夹中。这两个工具与GUI应用程序共享基础设施，因此可以使用Graphics Profiler设置页面配置首选跟踪目录和ADB参数，并确保命令行工具也使用它们。

由于共享基础结构，当另一个工具或GUI已经启动时，当前命令行工具则无法使用。
> 说明
>
> HarmonyOS 5.0及以上版本设备不支持使用CLI工具。

## Trace Recorder

trace_recorder可以通过使用提供的跟踪配置捕获跟踪，获取配置文件最简单的方法是从GUI复制它。参照录制配置部分内容进行配置，点击"Recording config"，然后点击"Copy to clipboard"按钮复制配置文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/Xc9fvSykRMWmjAex-_2_sQ/zh-cn_image_0000001828144864.png?HW-CC-KV=V1&HW-CC-Date=20260909T133343Z&HW-CC-Expire=31536000000&HW-CC-Sign=A5CC4B6E057BA17F79BF6EE8861FBD25E2FC867C55E4493FA88A0624E49A0E64)

创建配置文件后，trace_recorder record <path to trace config> -d <device UID>，如果省略设备UID，则将使用列表中的第一个可用设备。可以在GUI界面中查看设备UID，也可以通过调用 trace_recorder devices命令查看。可以等待跟踪会话结束或在录制过程中通过"Ctrl+C"停止跟踪会话。在Ring Buffer模式下，跟踪会话不会自行停止，这种模式是为手动终止而设计的，因此必须使用"Ctrl+C"来结束录制。

## Trace Processor

trace_processor可以使用SQL查询从捕获的跟踪中获取数据。

查询命令如下：

trace_processor query -f <path to SQL file> -o <output JSON path> <path to the trace file>

或者，可以将跟踪导出为SQLite数据库：

trace_processor export <path to the trace file> <output database file>

生成的数据库可以与sqlite3 Python包一起使用。

## 出错处理

可以在脚本中处理CLI退出代码，Graphics Profiler CLI工具可能返回的代码如下。

|代码|含义|
|:-|:------------|
|0|一切按照预期进行|
|1|程序内部错误|
|2|获取设备列表时出错|
|3|找不到可供录制使用的设备|
|4|所选设备不可用于录制|
|5|无法找到或打开跟踪配置文件|
|6|跟踪录制失败|
|7|SQL查询执行失败|
|8|跟踪导出失败|
