# AR预览

对于Android版本，点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.86687873128836547978627959672242:50520704031946:2800:A1A86BBE35013533212D57ABCF1F7CB077B567B7A4FF79C77A19517D028D9AF9.png?needInitFileName=true?needInitFileName=true)可以进入AR界面把场景中的模型放置到真实的环境中。点击模型可以拖拽并改变位置。点击右上角循环图标可以重新放置模型，点击右下角相机图标可以截图，点击左上角图标可以退出AR预览。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.42471938174705028035449933096526:50520704031946:2800:CFC327698943FD8E0E2D268F0E54C97996AC67AF7E3FB9A4523713556F8C51C4.png?needInitFileName=true?needInitFileName=true "点击放大")
> 说明
>
> AR预览功能需要安装HUAWEI AR Engine，目前暂不支持透明图层、贴图重复系数，后续版本迭代更新解决。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.40822215513526629296363359645452:50520704031946:2800:AA588B2E287FBF0FE9B483C2EA5E639B0A5D2AB7A62F8B8D863BD27AAA883E2C.png?needInitFileName=true?needInitFileName=true "点击放大")

AR预览默认使用后置摄像头，锚点为平面锚点，可以识别平面并将场景放置在平面上。

当场景内有人脸锚点时，使用前置摄像头，会自动识别人脸并将场景中的物体附着在人脸。

当场景内有手势控件时，开启手势识别，使用前置摄像头，可以通过手势触发事件。

当场景内同时存在人脸锚点和手势控件时，AR预览只有人脸锚点生效。
