# 新建卡片项目

1. 进入新建卡片项目界面有如下三种方式。
   * 打开华为快应用IDE，在欢迎界面导航选择"新建项目 > 卡片"。
   * 进入主界面，菜单选择"文件 > 新建项目 > 卡片"。
   * 进入主界面，执行快捷键 **Ctrl + Shift + J**。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100008.85572237533490716213841224436503:50001231000000:2800:AFABBCBDA99BE0B10EC4EA9458F6BBF679C6ED9EC6BAA28F7CFCAE08D8B88582.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
2. 选择平台和设备后，点击"下一步"。
3. 选择适合的模板，点击"下一步"。
   * 通用模板：若用户之前未下载卡片模板，默认显示空白模板；若用户已下载卡片模板，显示通用模板下的所有模板。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100008.73639870513384003756886826749983:50001231000000:2800:7ED3BD55DD47E8B337E3A057B30F78B25E47238081102B4E2C55370347D50929.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   * 垂直模板：若用户之前未在通用模板下点击更多模板下载，模板列表默认显示为空，若用户已点击下载卡片模板，显示垂直模板下的所有模板。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100008.29679644294952981816721649161554:50001231000000:2800:37EF73CEBD142FA37814F414C4C5F3FEFBC3E80A21FC3F6C9263B321C792B75F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

4. 配置卡片信息，点击"确定"。
   * 项目名称：工程名称，用于指定工程文件夹名称。
   * 包名：发布的快应用为以.rpk为后缀的文件，此处即定义发布后的包名。推荐采用com.company.module的格式，例如：com.huawei.carddemo。
   * 卡片名称：卡片的名称，卡片提交审核时使用。
   * ID：卡片的唯一标识。
   * 卡片路径：卡片目录路径。 说明
     >
     > 已在manifest.json中配置过的路径，不可作为新建卡片的路径。
     >
     > 例如：manifest.json中path配置了/c1，则不能在src/c1路径新建卡片。需更改文件夹或者新建文件夹，如src/c2。
   * 卡片文件名：项目中的卡片文件名称。
   * 最小平台版本号：非必填，默认1000，用于平台版本管理。
   * 工作空间：项目工程存储路径。

工程初始化成功后，会在工程目录下生成卡片工程结构。

|------ .quickapp 配置文件目录

| |------ launch.json 配置文件

|------ src项目源文件

| |------ common 公用的资源文件和组件文件

| |------ component 卡片引用的组件分包，拖拽的组件也会添加到这个目录

|------ css 公共样式目录

|------ basic.scss 华为卡片基础样式库

|------ i18n 国际化目录

|------ hello\world 卡片页面目录

| |------ index.ux 页面文件，文件名不必与父文件夹相同

| |------ app.ux APP文件（编译自动修改，请勿改动）

| |------ manifest.json 项目配置文件（如：应用描述、接口声明、页面路由等）
