# 工具安装

#### PC版本安装

1. 下载[HUAWEI Reality Studio安装包](https://developer.huawei.com/consumer/cn/doc/development/Tools-Library/sdk-download-0000001050162780)。
2. 在Windows10 64位操作系统的设备上，双击HUAWEI Reality Studio的exe安装包，打开安装程序。
3. 点击"下一步"，选择安装路径，点击"安装"。
4. 安装成功，点击"完成"关闭安装界面。  

#### Android版本安装

1. 在华为应用市场搜索"HUAWEI Reality Studio"。
2. 点击"下载"，然后在应用安装界面点击"安装"。

   安装完成后，点击应用图标即可打开HUAWEI Reality Studio。
