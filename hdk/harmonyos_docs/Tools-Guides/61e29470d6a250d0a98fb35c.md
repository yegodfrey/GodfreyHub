# 连续帧功能支持多contexts抓取吗？

连续帧目前不支持多contexts的抓取，可能出现多contexts的情况如下。

* 有较大的场景切换，例如：从游戏主界面开始抓取，进入具体游戏场景后停止抓取。
* 游戏的教学关卡。
