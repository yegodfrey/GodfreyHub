# 查看及调试资源

图形绘制资源查看器"Resource Inspector"是一个查看资源的窗口，使用该功能需要先回放一个rdc文件。

1. 打开"Resource Inspector"窗口，"Resource List"中展示抓取帧的rdc文件里面的所有资源信息。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/ouTbvNh1QL6AJ6xUvpHRRw/zh-cn_image_0000001232272513.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=D3B9EFB6543625E0DEF678B4F11DF68B6C12D94F1A1A4463CFB556524BE3CB19)

2. 在"Resource List"中双击需要查看的资源信息，就可以在"Related Resources"获取该资源相关的父子资源信息，在"Usage in Frame"获取选中的资源在帧中的使用位置（EID）和使用方式（Usage）的信息，在"Resource Initialisation Parameters"获取调用的API的相关信息。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/eG8lrSMJRBqkhYvlQaCV5g/zh-cn_image_0000001186312884.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=8016F10A155B53D7DED8BC240567DB4ACC62DA6CB1049F23EA3AC4E8C5E04426)

3. 点击链接即可跳转到对应的资源信息。
4. 点击右上角的"View Contents"，可以查看对应资源中的信息。

   Contents大致分为三类：Buffer、Shader、Image。
   * 选定Buffer相关资源

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/m1Py0KU_QS6rM4jl0iyoBQ/zh-cn_image_0000001232192467.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=D5A57913A4CE981A432FCBAF1C024E72667FB78BCD646008EA3B986A9EFD5236)

     点击右上角的"View Contents"，即可跳转到对应的"BufferView"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/QGpEAj2JQd-qTHX0qzieTw/zh-cn_image_0000001231950959.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=616656EC73C331EBBAE41B77C2CBB0E4EA1E58F3001C9492E1B0401CD5113175)
   * 选定Shader相关资源

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/Z9fjukyIS72bHywmkFQDWw/zh-cn_image_0000001232272515.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=EA64853F2274BD3C66E573B265BF700AAE880F6C8C84CFABD71324B5684637E8)

     点击右上角的"View Contents"，即可跳转到对应的"ShaderViewer"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/qR5rrQTBRZafLkZGPtFZFQ/zh-cn_image_0000001186312886.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=D17E16EEB1B8032164D8CD0483C45E747776BA5778CF1BC74EACDCF206B77D5A)
   * 选定Image相关资源

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/HvNtAO21TrOWC_SKmQjA-g/zh-cn_image_0000001186472858.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=B3E2400EC080B7DCCF9D9B5FCCE47BC1F98EE04ADC123CCEF87E35E65CB813A3)

     点击右上角的"View Contents"，即可跳转到对应的"Texture Viewer"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/WxkCSwlLTPy3IOZddL0hfw/zh-cn_image_0000001186631416.png?HW-CC-KV=V1&HW-CC-Date=20261008T184541Z&HW-CC-Expire=31536000000&HW-CC-Sign=4BFC76997921F7FBF8E026BB5BDC59F5681B004E95DE3A0392A6459E370981EA)
