# 查看及调试资源

图形绘制资源查看器"Resource Inspector"是一个查看资源的窗口，使用该功能需要先回放一个rdc文件。

1. 打开"Resource Inspector"窗口，"Resource List"中展示抓取帧的rdc文件里面的所有资源信息。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/ouTbvNh1QL6AJ6xUvpHRRw/zh-cn_image_0000001232272513.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=858BA5213CD60480A83FB995479C9722CCCE3F3A8228F9EB230C2DAA215E8E4A)

2. 在"Resource List"中双击需要查看的资源信息，就可以在"Related Resources"获取该资源相关的父子资源信息，在"Usage in Frame"获取选中的资源在帧中的使用位置（EID）和使用方式（Usage）的信息，在"Resource Initialisation Parameters"获取调用的API的相关信息。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/eG8lrSMJRBqkhYvlQaCV5g/zh-cn_image_0000001186312884.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=2CE5C075F3C6446F9AABC599035FF5E3013535DA63564C6DCCB65B5C3CA76101)

3. 点击链接即可跳转到对应的资源信息。
4. 点击右上角的"View Contents"，可以查看对应资源中的信息。

   Contents大致分为三类：Buffer、Shader、Image。
   * 选定Buffer相关资源

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/m1Py0KU_QS6rM4jl0iyoBQ/zh-cn_image_0000001232192467.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=C854050080E1BF6DE0F9CD77840313ABEEA58B86BA1945C95E4C7F2EF9170D16)

     点击右上角的"View Contents"，即可跳转到对应的"BufferView"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/QGpEAj2JQd-qTHX0qzieTw/zh-cn_image_0000001231950959.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=9FBB3A6B00DE82AD315889B53E52F49369144C24B047D6B04F34ACB5A30F1CFD)
   * 选定Shader相关资源

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/Z9fjukyIS72bHywmkFQDWw/zh-cn_image_0000001232272515.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=6CD8895A622B6334DD387159A3C5DE877B2AFAEF37AA916F70A20F5EE6EADCB7)

     点击右上角的"View Contents"，即可跳转到对应的"ShaderViewer"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/qR5rrQTBRZafLkZGPtFZFQ/zh-cn_image_0000001186312886.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=2846806D46D141341C1BD81C4E22969B211EE365B2A35CC4111B836E8E629058)
   * 选定Image相关资源

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/HvNtAO21TrOWC_SKmQjA-g/zh-cn_image_0000001186472858.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=993437122A98DB8E2A7ADEEF7B642841BB2581F4F405CF69CC4809570DDCAED7)

     点击右上角的"View Contents"，即可跳转到对应的"Texture Viewer"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/WxkCSwlLTPy3IOZddL0hfw/zh-cn_image_0000001186631416.png?HW-CC-KV=V1&HW-CC-Date=20260909T174447Z&HW-CC-Expire=31536000000&HW-CC-Sign=042F29B15B880308A3E4FF9FE9C7BB24C11526D9BFB08F5E509C6F8504C02D95)
