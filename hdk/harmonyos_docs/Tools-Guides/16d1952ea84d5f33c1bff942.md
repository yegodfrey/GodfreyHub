# 抓取截图

* 支持抓取设备屏幕截图。截图时间间隔建议大于2s，HarmonyOS 5.0及以上版本设备截图时间间隔建议大于1s。

使用方式：任选一个指标，点击"Start Recording"之后会跳转到抓trace界面，点击"Save"可以对当前界面进行截图。点击"Save"之后会显示截图的时间戳。在当前界面最多会显示五个时间戳，大于五个之后，只是会滚动覆盖前面时间戳，不会丢失截图数据，不影响Show timeline界面的图片展示。
