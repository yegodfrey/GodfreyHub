# 连上设备后进行抓帧，Frame Profiler卡死，并且长时间不恢复？

1. 打开设置界面并将timeout配置为默认值（"Tools > Settings > Core > Config Editor > RemoteServer"，点击下图中红框标志的返回按钮进行重置）。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/Ja3J5SoNTkmzz9HcBvn7cg/zh-cn_image_0000002414084573.png?HW-CC-KV=V1&HW-CC-Date=20260909T143916Z&HW-CC-Expire=31536000000&HW-CC-Sign=E682759B80A2A1BB9B5F17B95ED9DB861C03D261D6DC215657560505A06D7FE5)
2. 后台打开应用。
3. 在CMD中输入"adb shell settings put global cached_apps_freezer disabled"命令。
