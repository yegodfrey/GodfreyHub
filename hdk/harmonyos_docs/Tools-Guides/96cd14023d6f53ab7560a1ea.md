# 连上设备后进行抓帧，Frame Profiler卡死，并且长时间不恢复？

1. 打开设置界面并将timeout配置为默认值（"Tools \> Settings \> Core \> Config Editor \> RemoteServer"，点击下图中红框标志的返回按钮进行重置）。![](https://media:201778750889576157)
2. 后台打开应用。
3. 在CMD中输入"adb shell settings put global cached_apps_freezer disabled"命令。
