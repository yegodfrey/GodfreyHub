# 查看已有动画列表

点击场景树的动画列表，可以查看已有的动画，每个动画都有四个图标，功能依次为播放动画、复制动画、编辑动画、删除动画。

勾选"自动播放"可以在进入预览界面时自动播放动画，勾选"循环"则可以在自动播放的基础上循环播放动画。
