# FIDO Kit手工转换指导书

#### 开发准备

您若需要应用支持FIDO Kit，必须完成接入准备，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/config-agc-0000001050262772)。  

#### GlobalEnvSetting类中的接口

GlobalEnvSetting初始化：

```
GlobalEnvSetting.init();
```

GlobalEnvSetting判断：

```
if(GlobalEnvSetting.isHms());
```

#### Fido类中的字符串

|FIDO2_KEY_RESPONSE_EXTRA|FIDO2_KEY_ERROR_EXTRA|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|The key used by the calling [Activity](https://developer.android.google.cn/reference/android/app/Activity.html) to retrieve [AuthenticatorAttestationResponse](https://developers.google.com/android/reference/com/google/android/gms/fido/fido2/api/common/AuthenticatorAttestationResponse) or [AuthenticatorAssertionResponse](https://developers.google.com/android/reference/com/google/android/gms/fido/fido2/api/common/AuthenticatorAssertionResponse) from the Intent received by [onActivityResult(int, int, Intent)](https://developer.android.google.cn/reference/android/app/Activity.html#onActivityResult(int, int, android.content.Intent)) after launching [Fido2PendingIntent](https://developers.google.com/android/reference/com/google/android/gms/fido/fido2/Fido2PendingIntent).|The key used by the calling [Activity](https://developer.android.google.cn/reference/android/app/Activity.html) to retrieve [AuthenticatorErrorResponse](https://developers.google.com/android/reference/com/google/android/gms/fido/fido2/api/common/AuthenticatorErrorResponse) from the Intent received by [onActivityResult(int, int, Intent)](https://developer.android.google.cn/reference/android/app/Activity.html#onActivityResult(int, int, android.content.Intent)) after launching [Fido2PendingIntent](https://developers.google.com/android/reference/com/google/android/gms/fido/fido2/Fido2PendingIntent).|

GMS服务迁移到HMS Core服务时，org.xms.g.fido.Fido类中缺少以上两个关键的注册和认证的回复判断值，有如下两种解决方式：

1. 引入com.google.android.gms.fido.Fido.FIDO2_KEY_RESPONSE_EXTRA和com.google.android.gms.fido.Fido.FIDO2_KEY_ERROR_EXTRA。
2. org.xms.g.fido.Fido类中添加：

   ```
   // TODO start USER_CUSTOM_CODE_IN_CLASS_BODY_org.xms.g.fido.Fido
   public static final String FIDO2_KEY_RESPONSE_EXTRA = "FIDO2_RESPONSE_EXTRA";
   public static final String FIDO2_KEY_ERROR_EXTRA = "FIDO2_ERROR_EXTRA";
   // TODO end USER_CUSTOM_CODE_IN_CLASS_BODY_org.xms.g.fido.Fido
   ```

* getRegisterIntent()接口示例。  
  Google API调用示例：

  ```
  private void reg2Fido2Client(PublicKeyCredentialCreationOptions publicKeyCredentialCreationOptions) {   
      com.google.android.gms.fido.fido2.Fido2ApiClient fido2ApiClient = 
           com.google.android.gms.fido.Fido.getFido2ApiClient(this); 
      Task<Fido2PendingIntent> result =
           fido2ApiClient.getRegisterIntent(publicKeyCredentialCreationOptions); 
      result.addOnSuccessListener(new OnSuccessListener<Fido2PendingIntent>() {
          @Override        
          public void onSuccess(Fido2PendingIntent fido2PendingIntent) {
              if (fido2PendingIntent.hasPendingIntent()) {
                  try { 
                      fido2PendingIntent.launchPendingIntent(Fido2DemoMainActivity.this,0);                    
                      Log.i("Reg2Fido2Client", "Register request is sent out");                
                  } catch (IntentSender.SendIntentException e) {                    
                      Log.e("Reg2Fido2Client", "Error launching pending intent for register request", e);    
                  }            
             }        
          }    
      });
  }
  ```

      Fido2ApiClient fido2ApiClient = Fido.getFido2ApiClient(this.getApplicationContext());
