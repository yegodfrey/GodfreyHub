# 使用场景资源管理器管理资源

场景资源管理器显示了场景的所有内容，并可以实现快捷操作。

* 场景展示场景内模型的层级。
* 动画列表展示制作完成的动画。
* 屏幕展示场景内的2D控件。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150014.98967099021626807490460417963787:50520704031946:2800:931B20CF2C611C060EA9D488FF06453645EE897A2F0C36CB14D38DE8525F569D.png?needInitFileName=true?needInitFileName=true "点击放大")

## 使用搜索框搜索3D节点和2D控件

在搜索框可以根据名称搜索Scene节点下的3D节点和屏幕节点下的2D控件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150014.38326913605708368672433457905031:50520704031946:2800:D9F074A5889A6EAFB0FA7B88AC6C91DA7AA679EDB29A53A034BCEDA9F8D7BBE9.png?needInitFileName=true?needInitFileName=true)

## 使用场景树快速定位到节点

点击场景树下的节点可以快速选中节点并打开属性栏。

双击场景树中的3D节点可以让选中的节点移到相机中央。

场景树由三部分组成：

* 场景节点下放置模型节点。
* 动画列表节点下放置所有已完成的动画。
* 屏幕节点下放置按钮、文本框等2D控件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150014.67458065968546549859195062803017:50520704031946:2800:35B4A7376ADE45142A3D6ACB2542C073627C99972BF05347CE5579B409DB4AC7.png?needInitFileName=true?needInitFileName=true)

## 移动节点

长按场景资源管理器的3D节点，可以将该节点拖入其他节点。

## 使用快捷功能

点击场景树上方的"场景树功能"打开快捷功能菜单。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150014.95234445686432130783687965108650:50520704031946:2800:9B9676D86BA1A07785B8733216585869AABCCC71BC354EA58D3C9132AB52FFDC.png?needInitFileName=true?needInitFileName=true)

|功能|说明|
|:-----|:----------------------|
|显示节点|将选中的3D节点中所有的节点显示属性改为显示。|
|隐藏节点|将选中的3D节点及其子节点的显示属性改为隐藏。|
|全部收起|将展开的节点全部收起。|
|显示隐藏部件|显示选中节点下所有隐藏的部件。|
|显示完整场景|显示场景树所有部件，包括隐藏的部件。|
