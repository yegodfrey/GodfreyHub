# Auth Service

## 准备工作

1. 您若需要应用支持Auth Service，必须完成接入准备，请参见[AppGallery Connect开发服务使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-android-0000001058210705)。
2. 华为认证服务详情请参见[认证服务简介](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-auth-introduction-0000001053732605)，相关API详情请参见[认证服务API参考](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agc-auth-service-api-overview-0000001054403973)。

## onAuthStateChanged(FirebaseAuth)

属于FirebaseAuth.AuthStateListener中方法。当用户身份验证状态更改时，此API将在UI线程中被调用，入参代表了被监听的用户实例。而在AGC中，使用OnTokenListener.onChanged(TokenSnapshot)来监听用户身份验证状态的更改。下面给出简易的代码示例。

使用Firebase的onAuthStateChanged(FirebaseAuth)方法的代码场景：

```screen
FirebaseAuth auth = FirebaseAuth.getInstance();
//本示例使用了addAuthStateListener()做示范，实际上其他用到FirebaseAuth.AuthStateListener接口作为入参监听器的都可以参照此模式修改
auth.addAuthStateListener(new FirebaseAuth.AuthStateListener() {
    @Override
    public void onAuthStateChanged(@NonNull FirebaseAuth firebaseAuth) {
        //业务代码
    }
});
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionAuth、GlobalEnvSetting等类）：

```screen
ExtensionAuth auth = ExtensionAuth.getInstance();
if (GlobalEnvSetting.isHms()) {
    ((com.huawei.agconnect.auth.AGConnectAuth) auth.getHInstance()).addTokenListener(new com.huawei.agconnect.core.service.auth.OnTokenListener() {
        @Override
        public void onChanged(com.huawei.agconnect.core.service.auth.TokenSnapshot tokenSnapshot) {
            //业务代码
        }
    });
} else {
    ((com.google.firebase.auth.FirebaseAuth)auth.getGInstance()).addAuthStateListener(new com.google.firebase.auth.FirebaseAuth.AuthStateListener() {
        @Override
        public void onAuthStateChanged(@NonNull com.google.firebase.auth.FirebaseAuth firebaseAuth) {
            //业务代码
        }
    });
}
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectAuth auth = AGConnectAuth.getInstance();
auth.addTokenListener(new com.huawei.agconnect.core.service.auth.OnTokenListener() {
    @Override
    public void onChanged(com.huawei.agconnect.core.service.auth.TokenSnapshot tokenSnapshot) {
        //业务代码
    }
});
```

```screen

auth.addIdTokenListener(new FirebaseAuth.IdTokenListener(){
    @Override

    //业务代码
```

## delete()

属于FirebaseUser中方法。此API的作用是删除当前当前用户记录，操作成功的话用户将被删除。在Firebase中这个API的返回值是一个GMS的Task<Void>对象，而在AGC中，使用[AGConnectAuth.deleteUser](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectauth-0000001054482530#section154883587214)()提供此功能，但是无返回值。下面给出简易的代码示例。

使用Firebase的delete()方法的代码场景：

```screen
FirebaseAuth auth = FirebaseAuth.getInstance();
Task<Void> delete = auth.getCurrentUser().delete();
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionAuth、GlobalEnvSetting等类）：

```screen
ExtensionAuth auth = ExtensionAuth.getInstance();
if (GlobalEnvSetting.isHms()) {
    ((com.huawei.agconnect.auth.AGConnectAuth) auth.getHInstance()).deleteUser();
} else {
    com.google.android.gms.tasks.Task<Void> delete = 
        ((com.google.firebase.auth.FirebaseAuth) auth.getGInstance()).getCurrentUser().delete();
    //根据后续业务需求处理这个Task对象
}
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectAuth auth = AGConnectAuth.getInstance();
auth.deleteUser();
```

## getMetadata()

属于FirebaseUser中方法。此API的作用是返回当前用户的数据信息，返回值是FirebaseUserMetadata对象。而在AGC中，使用[AGConnectUser.getUserExtra](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectuser-0000001054522513#section191819193315)()提供此功能，但是返回值是HMS的[Task<AGConnectUserExtra>](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectuserextra-0000001054403795)对象，下面给出简易的代码示例。

使用Firebase的getMetadata()方法的代码场景：

```screen
FirebaseUser user = FirebaseAuth.getInstance().getCurrentUser();
FirebaseUserMetadata userMetadata = user.getMetadata();
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionUser、GlobalEnvSetting等类）：

```screen
ExtensionUser user = ExtensionAuth.getInstance().getCurrentUser();
if (GlobalEnvSetting.isHms()) {
    com.huawei.hmf.tasks.Task<com.huawei.agconnect.auth.AGConnectUserExtra> userExtra = 
        ((com.huawei.agconnect.auth.AGConnectUser) user.getHInstance()).getUserExtra();
    //根据后续业务需求处理这个Task对象，下面给出简易处理示例
    userExtra.addOnCompleteListener(task -> {
        com.huawei.agconnect.auth.AGConnectUserExtra agConnectUserExtra = task.getResult();
        //根据需求处理获取的用户信息
    });
} else {
    com.google.firebase.auth.FirebaseUserMetadata userMetadata = 
        ((com.google.firebase.auth.FirebaseUser) user.getGInstance()).getMetadata();
    //根据后续业务需求处理这个FirebaseUserMetadata对象
}
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
Task<AGConnectUserExtra> userExtra =
        user.getUserExtra();
//根据后续业务需求处理这个Task对象，下面给出简易处理示例
userExtra.addOnCompleteListener(task -> {
    AGConnectUserExtra agConnectUserExtra = task.getResult();
    //根据需求处理获取的用户信息
});
```

## updateEmail(String)

属于FirebaseUser中方法。此API的作用是更新该用户的邮箱地址。在Firebase中，只需要一个新的邮箱地址作为入参，同时要求用户近期登录过；而在AGC中，提供此功能的API为[AGConnectUser.updateEmail(String, String)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectuser-0000001054522513#section541614352513)，该API还需要一个额外的验证码作为入参，因此调用此接口之前，请调用[EmailAuthProvider.requestVerifyCode(String, VerifyCodeSettings)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/emailauthprovider-0000001054322501#section182856211160)函数来为新邮箱申请验证码，从而确定新邮箱为用户所有。下面给出简易的代码示例。

使用Firebase的updateEmail(String)方法的代码场景：

```screen
//此处email用于获取用户输入的邮箱，您可以根据需求自行设计具体形式
EditText email = new EditText(this);
String newEmailAddress = email.getText().toString();
FirebaseUser user = FirebaseAuth.getInstance().getCurrentUser();
//Firebase更新Email前要求用户近期登录过，可能需要调用FirebaseUser.reauthenticate(AuthCredential)重新登录
//AGC中做涉及到安全性的相关操作时，通过验证码验证身份，不需要重新登录，因此未提供重登录的API
Task<Void> updateEmail = user.updateEmail(newEmailAddress);
//处理更新结果(GMS的Task对象):...
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionUser、GlobalEnvSetting等类）：

```screen
//由于AGC中需要申请验证码来验证邮箱，相比于Firebase需要多一个按钮
//建议在用户触发更新邮箱这一操作时就根据是否是HMS环境分别跳转到不同的函数中进行处理，本例未做跳转
EditText email = new EditText(this);
String newEmailAddress = email.getText().toString();
ExtensionUser user = ExtensionAuth.getInstance().getCurrentUser();
Task<Void> updateEmail = null;
if (GlobalEnvSetting.isHms()) {
    //下面的代码用于申请验证码，需要在用户输入完邮箱之后触发，请根据您的界面UI设计妥善设计代码
    com.huawei.agconnect.auth.VerifyCodeSettings settings = com.huawei.agconnect.auth.VerifyCodeSettings.newBuilder()
        .action(ACTION_REGISTER_LOGIN) //ACTION_REGISTER_LOGIN/ACTION_RESET_PASSWORD
        .sendInterval(30) //最小发送间隔，30-120s
        .locale(Locale.SIMPLIFIED_CHINESE) //可选，设置的locale必须包含language和country
        // 不设置默认为Locale.getDefault(),
        .build();
    
    com.huawei.hmf.tasks.Task<com.huawei.agconnect.auth.VerifyCodeResult> verifyCodeResultTask = com.huawei.agconnect.auth.EmailAuthProvider.requestVerifyCode(newEmailAddress, settings);
    verifyCodeResultTask.addOnCompleteListener(task -> {
        com.huawei.agconnect.auth.VerifyCodeResult codeResult = task.getResult();
    });
    //下面的代码假设您已正确的处理了上述申请验证码的流程，verifyCode存储用户输入的验证码，您可以根据需要自行设计具体形式
    //后续代码最好通过另一个按钮触发，确保是在用户收到验证码并且完成输入后进行
EditText oldEmail = new EditText(this);
String oldEmailAddress = oldEmail.getText().toString();
EditText password = new EditText(this);
String passwordStr = password.getText().toString();
EditText verifyCode = new EditText(this);
String verifyCodeStr = verifyCode.getText().toString();
AGConnectAuthCredential authCredential = EmailAuthProvider.credentialWithPassword(oldEmailAddress,passwordStr);
AGConnectAuth.getInstance().signOut();
AGConnectAuth.getInstance().signIn(authCredential).addOnCompleteListener(task -> {
    if (task.isSuccessful()) {
        //更新邮箱，获取XMS的Task返回对象    
        AGConnectUser reLoginUser=AGConnectAuth.getInstance().getCurrentUser();
        reLoginUser.updateEmail(newEmailAddress, verifyCodeStr)
            .addOnSuccessListener(aVoid -> {
                Log.e(TAG, "updateEmail success");
            })
            .addOnFailureListener(e -> {
                Log.e(TAG, "updateEmail failure" + e.getMessage());
            });
    }
});
} else {
    //如果之前有重登录相关的代码逻辑，请在此处实现
    com.google.android.gms.tasks.Task<Void> update = ((com.google.firebase.auth.FirebaseUser) user.getGInstance()).updateEmail(newEmailAddress);
    updateEmail = (org.xms.g.tasks.Task) Utils.getXmsObjectWithGmsObject(update);
}
//处理更新结果(XMS的Task对象):...
```

## updatePassword(String)

属于FirebaseUser中方法。此API的作用是更新该用户的密码。在Firebase中，需要新密码作为入参，同时要求用户近期登录过；而在AGC中，提供此功能的API为[AGConnectUser.updatePassword(String, String, int)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectuser-0000001054522513#section6607104182911)，该API还需要一个验证码和一个标识提供者类型的int值作为入参。当前AGC只支持通过邮箱更新密码，因此调用此接口之前，请调用[EmailAuthProvider.requestVerifyCode(String, VerifyCodeSettings)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/emailauthprovider-0000001054322501#section182856211160)函数来为新邮箱申请验证码，从而确定新邮箱为用户所有，Email方式对应的int值是12。下面给出简易的代码示例。

使用Firebase的updatePassword(String)方法的代码场景：

```screen
//此处password用于获取用户输入的新密码，您可以根据需求自行设计具体形式
EditText password = new EditText(this);
String newPassword = password.getText().toString();
FirebaseUser user = FirebaseAuth.getInstance().getCurrentUser();
//Firebase更新Password前要求用户近期登录过，可能需要调用FirebaseUser.reauthenticate(AuthCredential)重新登录
//AGC中做涉及到安全性的相关操作时，通过验证码验证身份，不需要重新登录，因此未提供重登录的API
Task<Void> updatePassword = user.updatePassword(newPassword);
//处理更新结果(GMS的Task对象):...
```

## getProfile()

属于AdditionalUserInfo中方法。如果用户的提供者是Facebook、GitHub、Google、Twitter、Microsoft或者Yahoo的话，此API的作用为获取包含特定IDP的用户数据的Map。而在AGC中，使用[AGConnectUser.getProviderInfo](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectuser-0000001054522513#section16558105211418)()来获取，但是返回值是包含Map的List，且支持的提供者范围不同，需提前识别范围。下面给出简易的代码示例。

使用Firebase的getProfile()方法的代码场景：

```screen
FirebaseUser firebaseUser = FirebaseAuth.getInstance().getCurrentUser();
Map<String, Object> profile = firebaseUser.linkWithCredential(FacebookAuthProvider.getCredential(""))
    .getResult().getAdditionalUserInfo().getProfile();
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionUser、GlobalEnvSetting等类）：

```screen
ExtensionUser extensionUser = ExtensionAuth.getInstance().getCurrentUser();
if (GlobalEnvSetting.isHms()) {
    List<Map<String, String>> profilesAgc = ((AGConnectUser) extensionUser.getHInstance()).getProviderInfo();
    //根据业务需求处理这个List
} else {
    Map<String, Object> profileFirebase = ((FirebaseUser) extensionUser.getGInstance())
        .linkWithCredential(com.google.firebase.auth.FacebookAuthProvider.getCredential("")).getResult().getAdditionalUserInfo().getProfile();
    //根据业务需求处理这个Map
}
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectUser agConnectUser = AGConnectAuth.getInstance().getCurrentUser();
```

## 手机业务相关APIs

在Firebase中，使用手机相关API时，需要先调用verifyPhoneNumber()方法验证手机号，在此方法中可以直接通过验证获取凭证，也可以通过onCodeSent回调自行构造凭证，获取到的凭证可以用于登录或者是更新用户手机号等功能。而在AGC中，通过手机号和密码可以直接获取凭证，也可以在密码之外增加验证码来获取凭证。验证码通过接口[PhoneAuthProvider.verifyPhoneCode](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/phoneauthprovider-0000001054083788#section152201139172417)()发送给用户，而在更新用户手机号时，是一定需要验证码来保证新手机号是属于用户的。下面给出简易的代码示例和示例适用的相关接口列表。

|:----------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|PhoneAuthProvider.verifyPhoneNumber|[PhoneAuthProvider.requestVerifyCode](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/phoneauthprovider-0000001054083788#section14619414125812)|

|PhoneAuthProvider.getCredential(String,String)|[PhoneAuthProvider.credentialWithPassword](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/phoneauthprovider-0000001054083788#section042085095819)/[PhoneAuthProvider.credentialWithVerifyCode](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/phoneauthprovider-0000001054083788#section79451137232)|

## getCredentialWithLink(String email, String emailLink)

属于EmailAuthProvider中方法。该API的作用是返回包装电子邮件登录链接的AuthCredential的新实例。而在AGC目前并不支持链接的方式。如果您想通过链接获取凭证，请转用邮箱和密码，修改为使用[getCredential](https://firebase.google.com/docs/reference/android/com/google/firebase/auth/EmailAuthProvider#getCredential(java.lang.String, java.lang.String))(String email, String password)后，即可用工具自动转换。

```screen
String emailLink = "emailLink";//简化流程，此处假设您已获取到了Firebase API所需的link
```

## Task<AuthResult> reauthenticateAndRetrieveData(AuthCredential)

属于FirebaseUser中方法。该API的作用是使用给定的凭据重新认证用户，并返回该帐户的配置文件数据。而在AGC中暂未提供重新认证的相关接口，因此您可以使用登出接口[AGConnectAuth.signOut](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectauth-0000001054482530#section1445773192310)()和登录接口[AGConnectAuth.signIn](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectauth-0000001054482530#section298148131715)(AGConnectAuthCredential credential)来模拟实现重新认证的流程。下面给出简易的代码示例。

使用Firebase的reauthenticateAndRetrieveData(AuthCredential)方法的代码场景：

```screen
FirebaseAuth auth = FirebaseAuth.getInstance();
Task<AuthResult> authResult = auth.getCurrentUser()
    .reauthenticateAndRetrieveData(authCredential);//这里假设您已经获取到了重新认证所需的凭证
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectAuth auth = AGConnectAuth.getInstance();
auth.signOut();//登出当前帐户
Task<SignInResult> signInResult = auth.signIn(authCredential);//重新认证登录
```

## getAuthTimestamp()

属于GetTokenResult中方法。该API的作用是返回自时间戳记以来的认证时间戳记（以秒为单位）。而在AGC中则是通过[AGConnectUserExtra.getLastSignInTime](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectuserextra-0000001054403795#section1699141104111)()来获取最近一次登录时间。下面给出简易的代码示例。

使用Firebase的getAuthTimestamp()方法的代码场景：

```screen
FirebaseUser user = FirebaseAuth.getInstance().getCurrentUser();
user.getIdToken(true).addOnSuccessListener(new OnSuccessListener<GetTokenResult>() {
    @Override
    public void onSuccess (GetTokenResult getTokenResult){
        long authTimestamp = getTokenResult.getAuthTimestamp();
    }
});
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionUser、GlobalEnvSetting等类）：

```screen
ExtensionUser user = ExtensionAuth.getInstance().getCurrentUser();
user.getIdToken(true).addOnSuccessListener(new OnSuccessListener<GetTokenResult>() {
    @Override
    public void onSuccess (GetTokenResult getTokenResult){
        if (GlobalEnvSetting.isHms()) {
            String lastSignInTime = ((AGConnectUser) user.getHInstance()).getUserExtra().getResult().getLastSignInTime();
        } else {
            long authTimestamp = ((com.google.firebase.auth.GetTokenResult) getTokenResult.getGInstance()).getAuthTimestamp();
        }
    }
});
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectUser user = AGConnectAuth.getInstance().getCurrentUser();
String lastSignInTime = user.getUserExtra().getResult().getLastSignInTime();
```

## getCredential(String email, String password)

属于EmailAuthProvider中的方法，在Firebase中可通过此API用邮箱和密码获取登录凭证。而在AGC中，通过[EmailAuthProvider.credentialWithPassword(String email, String password)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/emailauthprovider-0000001054322501#section35311719195420)也可以获取凭证，但是要注意的是，如果需要关联Emali帐号，需要调用[EmailAuthProvider.credentialWithVerifyCode(String email, String password, String verifyCode)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/emailauthprovider-0000001054322501#section648110229154)接口，确保Email为用户所有。下面给出简易的代码示例。

使用Firebase的getCredential(String email, String password)方法的代码场景：

```screen
EditText email = new EditText(this);
EditText password = new EditText(this);
String emailStr = email.getText().toString();
String passwordStr = password.getText().toString();
AuthCredential authCredential = EmailAuthProvider.getCredential(emailStr, passwordStr);
// 场景一：凭证用于登录
FirebaseAuth.getInstance().signInWithCredential(authCredential);
//场景二：凭证用于关联帐号
FirebaseAuth.getInstance().getCurrentUser().linkWithCredential(authCredential);   
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到GlobalEnvSetting等类）：

```screen
EditText email = new EditText(this);
EditText password = new EditText(this);
String emailStr = email.getText().toString();
String passwordStr = password.getText().toString();
// 场景一：凭证用于登录
if (GlobalEnvSetting.isHms()) {
    AGConnectAuthCredential authCredential = com.huawei.agconnect.auth.EmailAuthProvider.credentialWithPassword(emailStr, passwordStr);
    AGConnectAuth.getInstance().signIn(authCredential);
} else {
    com.google.firebase.auth.AuthCredential authCredential = com.google.firebase.auth.EmailAuthProvider.getCredential(emailStr, passwordStr);
    FirebaseAuth.getInstance().signInWithCredential(authCredential); 
}
//场景二：凭证用于关联帐号
if (GlobalEnvSetting.isHms()) {
    //关联帐号时需要调用带验证码的接口来获取凭证，因此先发送验证码
    com.huawei.agconnect.auth.VerifyCodeSettings settings = com.huawei.agconnect.auth.VerifyCodeSettings.newBuilder()
        .action(ACTION_REGISTER_LOGIN) //ACTION_REGISTER_LOGIN/ACTION_RESET_PASSWORD
        .sendInterval(30) //最小发送间隔，30-120s
        .locale(Locale.SIMPLIFIED_CHINESE) //可选，设置的locale必须包含language和country
        // 不设置默认为Locale.getDefault(),
        .build();
   //发送验证码
    com.huawei.hmf.tasks.Task<com.huawei.agconnect.auth.VerifyCodeResult> verifyCodeResultTask = 
        com.huawei.agconnect.auth.EmailAuthProvider.requestVerifyCode(emailStr, settings);
    verifyCodeResultTask.addOnCompleteListener(task -> {
        Log.i("Example","onVerifySuccess");
        //成功发送验证码后，需要用户输入验证码后调用相关API进行登录，下面给出简易代码示例，请根据需要自行封装
        String verifyCode = "Input Verify Code By User";//需要界面配合让用户输入，此处简化
        com.huawei.agconnect.auth.AGConnectAuthCredential agConnectAuthCredential = 
            com.huawei.agconnect.auth.EmailAuthProvider.credentialWithVerifyCode(emailStr, passwordStr,verifyCode);
        AGConnectAuth.getInstance().getCurrentUser().link(agConnectAuthCredential);
    });
} else {
    com.google.firebase.auth.AuthCredential authCredential = com.google.firebase.auth.EmailAuthProvider.getCredential(emailStr, passwordStr);
    FirebaseAuth.getInstance().getCurrentUser().linkWithCredential(authCredential);
}
```
