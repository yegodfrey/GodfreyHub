# 分析trace

Graphics Profiler包含一个强大的查询引擎，可以进行广泛的跟踪分析。所有trace在内部由一组SQL表表示，可以直接查询这些表，也可以使用指标进行查询。

当打开trace时，单击侧栏上的查询(SQL)。可以输入一个SQL查询并使用"Ctrl+Enter"来运行它。
