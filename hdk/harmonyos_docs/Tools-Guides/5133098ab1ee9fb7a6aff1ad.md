# 遇到多线程渲染的情况下，无法抓帧？

若出现抓取按钮置灰的情况下，表示当前窗口是多线程渲染的，进行抓帧的时候可能抓取的并不是想要绘制的窗口，需要点击"Cycle Active Window"，进行切换，然后重新抓取，回放。
