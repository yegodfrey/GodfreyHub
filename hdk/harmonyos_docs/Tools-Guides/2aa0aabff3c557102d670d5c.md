# Getting Started

Getting Started提供了HMS Core各个Kit的功能介绍课程、查看或下载Demo的功能，帮助您更方便、快捷地了解Kit。  

#### Training

在菜单栏中选择"HMS \> Getting Started \> Training"，可跳转至华为开发者学院。您可以通过选择课程分类来查看学习对应Kit的课程。
