# 欢迎界面

打开华为快应用IDE会显示欢迎界面，欢迎界面分为五部分：

* 最近打开：展示最近打开过的工程。如果首次打开或者使用后清空用户数据，则呈现没有记录。
* 新建项目：可以 [新建快应用](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-project-quickapp-0000001148016705)、[新建卡片](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-project-card-0000001101576704) 项目，其中快应用项目又分为标准的快应用和云开发快应用。
* 导入项目：可以导入 [小程序](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-import-project-0000001147936549#section236861618512)、[HTML5应用](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-import-project-0000001147936549#section115446571053)、[HTML5游戏](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-import-project-0000001147936549#section1362682019614)、[uni-app](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-import-project-0000001147936549#section1625923513611)。
* 打开项目：可以打开本地任意类型的快应用项目。
* 打开RPK：可以打开本地的快应用rpk包。
