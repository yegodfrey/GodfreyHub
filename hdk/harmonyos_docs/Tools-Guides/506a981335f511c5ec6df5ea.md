# 时间轴展示

* 使用顶部的概述快速更改查看区域。
* 按住"Ctrl"键并滚动鼠标滚轮，或使用"W"和"S"键，可以对时间轴放大和缩小。
* 通过按住"Shift"键并拖动时间轴，或使用"A"和"D"键，可以在时间轴左右移动。
* 单击"切片"或选择多个元素以查看详细信息。
* 使用顶部的搜索来查找轨迹或切片。
