# 时间轴展示

* 使用顶部的概述快速更改查看区域。
* 按住"Ctrl"键并滚动鼠标滚轮，或使用"W"和"S"键，可以对时间轴放大和缩小。
* 通过按住"Shift"键并拖动时间轴，或使用"A"和"D"键，可以在时间轴左右移动。
* 单击"切片"或选择多个元素以查看详细信息。
* 使用顶部的搜索来查找轨迹或切片。
* counter轨道高度可调节。 ![](https://media:201778750891792208)

* 轨道位置可重新排序。
* 折叠/展开所有轨道。 ![](https://media:201778750891821209)

* 取消所有置顶轨道。 ![](https://media:201778750892063210)

* 可以更改基于周期的跟踪的度量单位。除了以周期为单位的默认可视化之外，还添加了以百分比为单位的利用率和以us为单位的持续时间。 ![](https://media:201778750892099211)

* 标准化可见范围内的trace值。 ![](https://media:201778750892146212)

* 记录并保留用户标记置顶的轨道，工具加载新trace或者重启时会保留该用户习惯。 ![](https://media:201778750892182213)
