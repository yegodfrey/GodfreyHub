# 场景节点属性

在场景资源管理器点击场景节点，可以打开场景节点属性面板。功能如下：

|功能|说明|
|:-----|:------------------------------------|
|显示|是否在显示视图显示场景节点。|
|显示网格|是否显示网格。|
|显示人脸锚点|添加人脸锚点后，可以选择是否启用人脸锚点，取消勾选后该参数不会保存到文件。|
|环境贴图|修改环境贴图，影响模型反光。|
