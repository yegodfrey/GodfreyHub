# Performance Counter查看器

Performance Counter支持图形化展示counter数据、展示鼠标位置对应EID的缩略图、查看各项counter的平均值等功能，可通过"Performance Counter Viewer"窗口和"Performance Counter"窗口查看。  

#### Performance Counter Viewer窗口

![](https://media:201778750903736454)  

|按钮|功能说明|
|:----------------------|:---------------------------------------------|
|Capture counters|选择想要查看的数据项。|
|Sync with Event Browser|点击该按钮后，下图中的数据项自动与"Event Browser"窗口中选中的EID同步选中。|
|Save|保存数据。|

#### OpenGL ES counters

点击"File \> Open Capture"，选择需要回放的OpenGL ES的rdc文件，点击"Window \> Performance Counter Viewer \> Capture counters"，此时"Performance counter selection"窗口有四种度量收集模式。

![](https://media:201778750903766455)  

|模式|说明|
|:---------|:----------------------------------------|
|Draw Call|为每个Draw（或其他GPU事件）收集指标。|
|Program|为使用着色器集的相邻GPU事件序列收集指标。|
|RenderPass|为在同一renderpass中执行的一系列GPU事件收集指标，非绘制事件单独测量。|
|Frame|为整个帧收集指标。|

#### Vulkan counters

点击"File \> Open Capture"，选择需要回放的Vulkan的rdc文件，点击"Window \> Performance Counter Viewer \> Capture counters"，此时"Performance counter selection"窗口有六种度量收集模式。

![](https://media:201778750903804456)  

|模式|说明|
|:-------------|:----------------------------------------|
|Job Chain|以GPU实际任务执行方式拆分任务，为每个任务收集指标。|
|Draw Call|为每个Draw（或其他GPU事件）收集指标。|
|Program|为使用着色器集的相邻GPU事件序列收集指标。|
|Render Pass|为在同一renderpass中执行的一系列GPU事件收集指标，非绘制事件单独测量。|
|Command Buffer|将Vulkan命令缓冲区内的所有绘制调用作为单个区域进行测量。|
|Frame|为整个帧收集指标。|
