# 马良GPU性能优化提示界面

可通过主菜单"Window > Errors and Warnings"，进入白皮书信息提示查看窗口，进入后如下图所示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6/v3/0-RnzV-vT-WGrmqg0O6A-Q/zh-cn_image_0000002563634484.png?HW-CC-KV=V1&HW-CC-Date=20261008T143616Z&HW-CC-Expire=31536000000&HW-CC-Sign=27048A5A4B727EAAB45BF45A157A431CE131038C242387E1AF7EE716079107A4)

通过主菜单"File > Open Capture with Options"打开对话窗如下图所示，按照下图步骤选择关键帧，勾选Show Maleoon GPU performance optimization tips复选框，点击Open再打开关键帧。打开关键帧后工具下方会描述提示信息，详细信息在"Errors and Warnings"窗口下展示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/t0_XPSA6R5aCleKpGD1m_Q/zh-cn_image_0000002571151426.png?HW-CC-KV=V1&HW-CC-Date=20261008T143616Z&HW-CC-Expire=31536000000&HW-CC-Sign=92231A692BB987612300C84E46BBE92E1705F83490BA9025A569E05F48220AEE)

目前支持可检测到的问题提示信息如下表所示。

|序号|描述|
|:-|:----------------------------------------------------|
|1|识别临时保存的attachment，使用growable的内存可以节省内存开销（vulkan）|
|2|无法深度剔除和深度值更新提示（gles、vulkan）|
|3|renderpass开始阶段未clear提示/中间出现flush或者finish给出性能提示(gles)|
|4|如果使用了glreadpixels给出性能问题提示（gles）|
|5|multisample attachment loadOp/storeOp设置问题提示（vulkan）|
|6|解析multisample image为singlesample image的推荐用法提示（vulkan）|
|7|使用feedback loops检测（gles、vulkan）|
|8|loadtile问题提示（vulkan）|
