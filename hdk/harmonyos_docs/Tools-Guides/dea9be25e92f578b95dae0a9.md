## 开发准备

您若需要应用支持Push Kit，必须执行以下步骤并成功获取到token。

参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-config-agc-0000001050170137)中的操作，通过[onNewToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hmsmessageservice-0000001050173839#section814414561477)方法，正常获取token，验证功能是否成功添加。

## 优先使用HMS判断

若您期望用户优先使用HMS（Add HMS API场景，To HMS API无需理会），可设置：

```screen
GlobalEnvSetting.useHms();
```

使用HMS前提：

```screen
//当isHmsAvailable和isEmui都返回true时,HMS才可用
if (isHmsAvailable(getApplicationContext()) &&isEmui()) {
    GlobalEnvSetting.useHms();
}
public static boolean isHmsAvailable(android.content.Context context) {
    return Arrays
         .asList(com.huawei.hms.api.ConnectionResult.SUCCESS, com.huawei.hms.api.ConnectionResult.SERVICE_UPDATING,
             com.huawei.hms.api.ConnectionResult.SERVICE_VERSION_UPDATE_REQUIRED)
         .contains(HuaweiApiAvailability.getInstance().isHuaweiMobileServicesAvailable(context));
 }
public static boolean isEmui() {
    try {
        Class<?> clazz = Class.forName("android.os.SystemProperties");
        Method method = clazz.getDeclaredMethod("getInt", String.class, int.class);
        return (Integer) method.invoke(clazz, "ro.build.hw_emui_api_level", 0) > HwBuildEx.VersionCodes.EMUI_4_1;
    } catch (ClassNotFoundException | NoSuchMethodException | IllegalAccessException | IllegalArgumentException | InvocationTargetException | ClassCastException e) {
        return false;
    }
}
```

## 接收消息

HMS在收到通知栏、透传消息、发送上线消息、获取token、发送异常的场景下，您可通过本步骤处理相应结果。

在manifest文件中添加如下内容（若已存在，无需添加）：

```screen
<service android:name=".DemoHmsMessageService"
            android:exported="false">
            <intent-filter>
            <action android:name="com.huawei.push.action.MESSAGING_EVENT"/>
            </intent-filter>
 </service>
```

新建类DemoHmsMessageService继承com.huawei.hms.push.HmsMessageService。

将已有的FirebaseMessagingService子类中的代码拷贝到新建类中，修改RemoteMessage的包为com.huawei.hms.push.RemoteMessage，修改RemoteMessage.Notification的包为com.huawei.hms.push.RemoteMessage.Notification。

## token保存使用

若您期望能保存或者使用获取的token，则可以调用[getToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)(String var1,String var2)方法后，通过[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hmsmessageservice-0000001050173839)或FirebaseMessagingService的实现类中的[onNewToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hmsmessageservice-0000001050173839#section343314205)获取到token。
> 说明
>
> 保存token时，注意区分Google API、HMS的token。
