# 1. 简介

区域文化相当重要。我们的产品或者资料在进入不同的市场，也在进入不同的文化。了解、尊重并且照顾到各地的文化，可以更好地协助我们的产品为当地的用户服务。否则带来的shock估计是相当难受滴！

# 2. 全球化通用需求-图片/图标

我们为大家整理了一些和区域文化相关的案例，本次分享的是图片/图标原则。

## 2.1 需求描述

注意其他文化中的特定性别角色和种族传统习俗，尽量采用不会反映出性别、种族、肤色、宗教、政治的图片。

例如：在苏丹，手机终端上禁止使用穿着暴露的女性图案或形象；在欧洲，禁止使用法西斯标志的图案或形象。

## 2.2 建议方案

1、 产品在使用图片时，避免使用与人体部位有关的图像，不要显示皮肤，更不要使用身体部位来表达某一概念。

2、 注意其他文化中的特定性别角色和种族传统习俗，尽量采用不会反映出性别、种族的图片
