# 通用配置

1. 在快捷运行区的下拉窗口选择"编辑配置"进入配置界面。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250807165406.29248141101409025489546865932118:50001231000000:2800:32644B55AEB0820DDFE1C871F03A2021DCA7AD5C5262686C9D86355EEAB6BF4F.png)

   配置界面分为两个区域，区域一可供选择所配置页面或卡片文件以及新增页面配置，区域二展示具体的配置。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250807165407.03957262989278942099773956779576:50001231000000:2800:1E84D5CFCA7BD02B9C4928B5B62D173BF99A2899692B474156FCFCD52868EECF.png)
   * 名称：调试页面或者卡片的别名，修改后会同步在快捷运行区的下拉窗口中更新。
   * 运行平台：指定选择页面或者卡片需要运行的加载器平台。
     * 平台：当前加载器支持的平台。
     * 平台版本号：当前IDE支持该平台快应用的最小版本号。若选中此平台，则配置文件中最小平台版本号需大于等于此版本号。
     * 版本号：所选加载器在IDE和更新服务中的最新版本号。若无法连接更新服务器，则显示预置值。
     * 支持系统：平台加载器支持的操作系统。
     * 配置：平台加载器启动时的相关配置，比如发布地区、分辨率。

     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250807165407.59549739098735746931651277289649:50001231000000:2800:267D50EC88819917C83B39B3AB8F4D07B9635F89A8F3944D74FEA6F8EC7B692C.png)
     * 状态：分为更新、下载和已下载三个状态。
