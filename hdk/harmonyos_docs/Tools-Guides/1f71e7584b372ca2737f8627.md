# Cloud Testing

HMS Toolkit为您提供专业的App云测能力，可支持原生应用、混合应用和游戏类应用的自动化测试。App云测通过卓越的DFX经验沉淀，实现支持App的兼容性测试、稳定性测试、性能测试和功耗测试功能。更多更详细的介绍请参见[云测试业务介绍](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/introduction-0000001073015422)。

* 使用Cloud Testing功能，需要华为Vmall帐号进行实名认证后，通过登录进行授权的方式进行使用。支持的浏览器为IE浏览器和Chrome浏览器。
* 云测试服务已在中国大陆、亚洲其他地区、非洲、拉美下架。当前，仅可在欧洲和俄罗斯使用云测试服务。

1. 在菜单栏中选择"HMS \> Cloud Testing"或者在工具栏点击如下图标。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240104215408.44947797421748781205875013538016:50001231000000:2800:D8DE3E0D128333455B71103310AABDA70A5676F0CE9B7C723F9B133ED6078542.png?needInitFileName=true?needInitFileName=true "点击放大")

   <br />

2. 在"Cloud Testing"中，点击"New Task"。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240104215408.44160920475953269219876337672377:50001231000000:2800:1B716B912663FF7D5345708F0C155BDE28A0A8208E9761EEE66A90C06970EEEA.png?needInitFileName=true?needInitFileName=true "点击放大")

   <br />

3. 配置各项任务参数，点击"Confirm"，启动测试任务。

   <br />

   * Select Category：选择测试类别。测试类别包括"Compatibility Test"（兼容性测试）、"Stability Test"（稳定性测试）、"Performance Test"（性能测试）和"Consumption Test"（功耗测试）。
   * Please Select Apk File：选择需要测试的APK文件。
   * Test Devices：选择用于测试应用的远程真机。测试稳定性（"Stability Test"）时，只能选择一个设备进行测试，其他测试项可以同时选择多个设备。
   * Test Duration：（可选）仅测试类别选择"Stability Test"生效，设置测试周期，范围为10\~60分钟。

   * Application Classification：（可选）仅测试类别选择"Performance Test"和"Consumption Test"生效，设置应用分类信息。
