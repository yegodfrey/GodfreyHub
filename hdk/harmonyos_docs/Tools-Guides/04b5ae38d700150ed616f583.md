# App Linking

## 准备工作

1. 您若需要应用支持App Linking，必须完成接入准备，请参见[AppGallery Connect开发服务使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-android-0000001058210705)。
2. 华为App Linking服务详情请参见[App Linking服务简介](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215)，相关API详情请参见[App Linking API参考](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/applinking-overview-0000001054820901)。

## createDynamicLink()

此API功能为创建一个动态链接。Firebase中，在获取到FirebaseDynamicLinks的实例对象后，通过这个对象来创建动态链接，创建的动态链接是一个Builder对象。而在AGC中，这个动态链接的Builder对象可以直接创建。下面给出简易的代码示例。

使用Firebase的createDynamicLink()的代码场景：

```screen
DynamicLink.Builder builder = FirebaseDynamicLinks.getInstance().createDynamicLink();
```

To HMS API模式下的源码修改方案：

```screen
AppLinking.Builder builder = new AppLinking.Builder();
```

## getPreviewLink()

此API功能为获取预览链接以显示链接流程图。在Firebase中，该方法为抽象方法。对应AGC中[getTestUrl](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/shortapplinking-0000001055060796#section24023472551)()为非抽象方法。下面给出简易的代码示例。

使用Firebase的getPreviewLink()的代码场景：

```screen
TextView shortTextView = new TextView(this);
public void onSuccess(ShortDynamicLink shortDynamicLink) {
    shortTextView.setText(shortDynamicLink.getPreviewLink().toString());
}
```

To HMS API模式下的源码修改方案：

```screen
TextView shortTextView = new TextView(this);
public void onSuccess(ShortAppLinking shortAppLinking) {
    shortTextView.setText(shortAppLinking.getTestUrl().toString());
}
```

## getShortLink()

此API功能为获取shortDynamicLink值。在Firebase中，该方法为抽象方法。对应AGC中[getShortUrl](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/shortapplinking-0000001055060796#section109627504455)()为非抽象方法。下面给出简易的代码示例。

使用Firebase的getShortLink()的代码场景：

```screen
TextView shortTextView = new TextView(this);
public void onSuccess(ShortDynamicLink shortDynamicLink) {
    shortTextView.setText(shortDynamicLink.getShortLink().toString());
}
```

To HMS API模式下的源码修改方案：

```screen
TextView shortTextView = new TextView(this);
public void onSuccess(ShortAppLinking shortAppLinking) {
    shortTextView.setText(shortAppLinking.getShortUrl().toString());
}
```

## setFallbackUrl(Uri fallbackUrl)

该API功能为设置在用户未安装应用时要打开的链接。在Firebase中为final方法，入参为android.net.Uri类型，在AGC中为普通方法，入参为java.lang.String类型。下面给出简易的代码示例。

使用Firebase的setFallbackUrl()的代码场景：

```screen
String url = "url";//url值由您自己设置
DynamicLink.AndroidParameters.Builder builder = new DynamicLink.AndroidParameters.Builder();
builder.setFallbackUrl(android.net.Uri.parse(url));
```

To HMS API模式下的源码修改方案：

```screen
String url = "url";//url值由您自己设置
AppLinking.AndroidLinkInfo.Builder builder = new AppLinking.AndroidLinkInfo.Builder();
builder.setFallbackUrl(url);
```

## buildShortDynamicLink(int suffix)

该API的作用是根据参数创建短动态链接。入参为动态链接期望长度，类型为int型，在AGC中入参类型为LENGTH。下面给出简易的代码示例。

使用Firebase的buildShortDynamicLink()的代码场景：

```screen
int suffix;//suffix值由您自己设置
com.google.android.gms.tasks.Task<ShortDynamicLink> shortLinkTask = FirebaseDynamicLinks.getInstance().createDynamicLink().buildShortDynamicLink(suffix);
```

To HMS API模式下的源码修改方案：

```screen
ShortAppLinking.LENGTH length = null;//ShortAppLinking.LENGTH值由您自己设置
com.huawei.hmf.tasks.Task<ShortAppLinking> shortLinkTask = new AppLinking.Builder().buildShortAppLinking(length);
```

## setImageUrl(android.net.Uri)

该API作用为设置meta-tag图片链接。入参为android.net.Uri类型，在AGC中入参为java.lang.String。下面给出简易的代码示例。

使用Firebase的setImageUrl()的代码场景：

```screen
String url = "url";//url值由您自己设置
DynamicLink.SocialMetaTagParameters.Builder builder = new DynamicLink.SocialMetaTagParameters.Builder().setImageUrl(android.net.Uri.parse(url));
```

To HMS API模式下的源码修改方案：

```screen
String url = "url";//url值由您自己设置
AppLinking.SocialCardInfo.Builder builder = new AppLinking.SocialCardInfo.Builder().setImageUrl(url);
```

## getMinimumAppVersion()

该API的作用是请求可以直接与versionCode比较的可处理动态链接的最小应用版本，返回值为int类型。 而AGC中对应的返回值为long型。下面给出简易代码示例。

使用Firebase的getMinimumAppVersion()方法的代码场景：

```screen
PendingDynamicLinkData pendingDynamicLinkData;//pendingDynamicLinkData值由您自己设置
int example = pendingDynamicLinkData.getMinimumAppVersion();
```

在To HMS API模式下的代码修改示例：

```screen
ResolvedLinkData resolvedLinkData;//resolvedLinkData值由您自己设置
int example = (int)resolvedLinkData.getMinimumAppVersion();
```

## getInstance(FirebaseApp firebaseApp)

该API的作用是将FirebaseDynamiclinks实例化，返回的是给定FirebaseApp的Firebase动态链接实例，是带FirebaseApp参数的实例化用法。 而AGC中FirebaseApp对应的方法是默认直接支持的，所以转换之后，该API将替换为无参。下面给出简易代码示例。

使用Firebase的getInstance()方法的代码场景：

```screen
FirebaseDynamicLinks config = FirebaseDynamicLinks.getInstance(com.google.firebase.FirebaseApp.getInstance());
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectAppLinking agConnectAppLinkingconfig = AGConnectAppLinking.getInstance();
```

## 常量

ShortDynamicLink.Suffix类作用为短动态链路长度的路径生成选项。其方法返回为int型值，而AGC中对应的ShortAppLinking.LENGTH方法为枚举类，其对应关系如下：

|Firebase|AppGallery-connect|
|:------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ShortDynamicLink.Suffix int SHORT = 2|[ShortAppLinking.LENGTH SHORT](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/shortapplinking-length-0000001055180837)|
|ShortDynamicLink.Suffix int UNGUESSABLE = 1|[ShortAppLinking.LENGTH LONG](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/shortapplinking-length-0000001055180837)|

## getUpdateAppIntent(Context)

该API的作用是提供将应用程序更新为Play商店中的版本的一个Intent。而在AGC中暂时未提供相应相关接口，但是您可以根据下面的代码示例，来达成在AGC中的这一功能。下面给出简易的代码示例。

使用Firebase的getUpdateAppIntent(Context)方法的代码场景：

```screen
Context context = this;
FirebaseDynamicLinks dynamicLinks = FirebaseDynamicLinks.getInstance();
PendingDynamicLinkData data = dynamicLinks.getDynamicLink(Uri.parse("")).getResult();
Intent intent = data.getUpdateAppIntent(context);
```

在To HMS API模式下的代码修改示例：

```screen
AGConnectAppLinking dynamicLinks = AGConnectAppLinking.getInstance();
ResolvedLinkData data = dynamicLinks.getAppLinking(this,Uri.parse("v")).getResult();
Context context = this;
Intent intent;
String packageName;
int versionCode = 0;

if (data.getMinimumAppVersion() != 0) {
    packageName = context.getApplicationContext().getPackageName();

    try {
        versionCode = context
                .getPackageManager()
                .getPackageInfo(packageName, 0)
                .versionCode;
    } catch (PackageManager.NameNotFoundException e) {
        Log.i("NameNotFoundException",e.getMessage());
    }

    if ( versionCode != 0 && versionCode < data.getMinimumAppVersion()) {
        intent =  new Intent("com.huawei.appmarket.intent.action.AppDetail")
                .putExtra("APP_PACKAGENAME", packageName)
                .setPackage("com.huawei.appmarket");
    }
}
```
