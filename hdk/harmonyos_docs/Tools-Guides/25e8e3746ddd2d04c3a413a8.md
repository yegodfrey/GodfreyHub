# 一键式日志收集

当使用工具报错时，用户可通过一键式日志收集功能获取log以及关键帧等。

点击"Tools -\> Collect Diagnostic Data"按钮，选择保存文件路径，在所选路径下会自动创建tools_dfx_data文件夹保存日志。
