# 界面概览

## PC版本界面概览

首次打开Reality Studio时界面如下，在打开时应用会自动创建一个空场景。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150011.58719353011221628745424235734505:50520704031946:2800:EA74C7C4C25D9880E353711808300CB7482A2972773082ACABB2AA907CCF340D.png?needInitFileName=true?needInitFileName=true "点击放大")

界面分布如图所示：

1. 菜单栏，包括保存、场景编辑和预览功能
2. 场景资源管理器，对场景资源进行管理
3. 显示视图，显示整个场景
4. 命令面板，增加组件到场景中
5. 属性栏，显示选中节点可编辑的属性

## Android版本界面概览

首次打开HUAWEI Reality Studio界面如下，在打开时应用会自动创建一个空场景。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150011.62461794559964490842838113061705:50520704031946:2800:A2F022CE06CC53F1A8455B3512722737A4A32F86D512864BE5A77AB618F8A859.png?needInitFileName=true?needInitFileName=true "点击放大")

界面分布如图所示：

1. 菜单栏，包括新建场景、导入、导出选中项、保存场景、聚焦、撤销、回退撤销、视角变化、其他、AR预览和场景预览
2. 场景资源管理器，对场景资源进行管理，包括搜索、打开场景资源管理器、删除节点、克隆节点
3. 显示视图，显示整个场景
4. 属性栏，显示选中节点可编辑的属性
5. 功能面板，显示命令面板对应项的详情
6. 命令面板，增加组件到场景中
