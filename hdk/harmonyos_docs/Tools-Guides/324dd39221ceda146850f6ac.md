# 计算切片的CPU时间

如果收集包括调度信息（即来自ftrace）和用户空间切片（即来自atrace）的跟踪，则可以计算每个用户空间切片在CPU上运行的实际时间：这通常称为切片的"CPU时间"。

首先，设置视图以简化后续查询。
