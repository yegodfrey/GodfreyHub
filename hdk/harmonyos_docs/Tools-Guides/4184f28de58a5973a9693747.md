# 1. 简介

区域文化相当重要。我们的产品或者资料在进入不同的市场，也在进入不同的文化。了解、尊重并且照顾到各地的文化，可以更好地协助我们的产品为当地的用户服务。否则带来的shock估计是相当难受滴！

# 2. 全球化通用需求-禁忌用词

我们为大家整理了一些和区域文化相关的案例，本次分享的是禁忌用词原则。

## 2.1 需求描述

用户希望产品界面、资料和语音等不能有引起反感、误解、不安及政治宗教文化冲突的用词用语出现。

例如：在网站填写个人信息时，"国家列表"应该改为"国家和地区列表"，尤其列表中出现了存有争议的地区和国家名字。

## 2.2 建议方案

1、建立一份术语表单，使用行业通用的术语用词。

2、在无通用术语使用的情况下，产品自行表达的用词参考语言区域及国的用词禁忌，避免使用本地人不喜欢或禁忌的用语用词数字等。
