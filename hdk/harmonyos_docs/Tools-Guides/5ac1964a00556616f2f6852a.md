# 图形绘制资源查看器

Resource Inspector（图形绘制资源查看器）是调出当前显示帧中API对象的完整列表以及查看对象之间的父子关系的窗口。整个用户界面中都存在资源检查器的链接，该链接由粗体资源命名。

Resource Inspector窗口主要包含以下几个部分：Resource List、Related Resources、Usage in Frame、Resource Initialisation Parameters以及Rename resource。

![](https://media:201778750902789436)  

|编号|功能说明|
|:---------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|Resource List|显示抓取的当前帧中包含的所有资源信息。|
|Related Resources|查看相关资源，对于选定的资源，可查看该资源依赖的父资源或子资源。|
|Usage in Frame|查看资源在帧中位置和使用方法，例如纹理和缓冲区，在该列表下，每个条目都列出了EID范围和用途类型。|
|Resource Initialisation Parameters|在使用任何API对象之前，必须完全按照抓取的应用程序来进行资源初始化，该部分列出了用于初始化对象的函数调用，这些函数调用通常至少包含一个创建函数。|
|Rename resource|重命名资源，请点击名称旁边的"Rename resource"按钮，点击后会打开一个编辑文本框用于更改名称。 ![](https://media:201778750902818437) 设置完成后，按Enter键保存。 ![](https://media:201778750902852438)|

若要取消重命名，点击"Reset name"按钮，可将名称还原。资源名称在整个用户界面中一样，因此每次进行重命名操作时，将全部更新。

右上角的"View Contents"按钮，可以查看对应资源中的信息。

* 选中Resource List的Buffer，跳转到[数据缓存查看器](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/data-cache-viewer-0000001050981479)界面。
* 选中Resource List的Texture，跳转到[纹理查看器](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/texture-viewer-0000001051061404)界面。
* 选中Resource List的Shader，跳转到[Shader查看器](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/shader-viewer-0000001051061406)界面。
