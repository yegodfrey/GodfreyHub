# 2D控件属性

2D控件可以在属性栏改变2D控件的名称，面板上的显示文字、字体大小、位置等。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.59734559664538206618356874532032:50520704031946:2800:6C849BEDEFF2617D3AFF2E20894AF6255F56C7DB6B9017620378F8602D4CF6A9.png?needInitFileName=true?needInitFileName=true "点击放大")

除了修改UI参数，2D控件还有以下属性：

* 外链：用户可通过输入外部链接后在预览模式点击控件后打开指定外部链接。外链需要以"http://"或"https://"开头。
* 克隆功能：点击"克隆"即可复制当前控件，3D节点与2D控件均支持克隆。
