# VK_HUAWEI_cluster_culling_shader

VK_HUAWEI_cluster_culling_shader是华为自研的扩展。Cluster Culling Shaders（CCS）类似于现有的计算着色器，主要是提供一个执行环境，以便在GPU上更有效地执行粗层几何剔除和LOD选择。  
![](https://media:201778750895889292)  
* CCS不适用于几何体或细分着色器，但IA和顶点着色器都保留。
* 顶点着色器仍然用于顶点位置着色，而不是直接从计算着色器输出变换后的顶点。  
涉及接口如下：

* vkCmdDrawClusterHUAWEI
* vkCmdDrawClusterIndirectHUAWEI
* 扩展VkPhysicalDeviceClusterCullingShaderFeaturesHUAWEI：VkPhysicalDeviceClusterCullingShaderVrsFeaturesHUAWEI
* 扩展VkPhysicalDeviceFeatures2, VkDeviceCreateInfo：VkPhysicalDeviceClusterCullingShaderFeaturesHUAWEI
* 扩展VkPhysicalDeviceProperties2：VkPhysicalDeviceClusterCullingShaderPropertiesHUAWEI
