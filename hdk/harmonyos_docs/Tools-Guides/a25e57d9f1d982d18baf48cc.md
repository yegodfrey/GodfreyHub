# 查看Performance Counter

## 查看图形化Counter数据

1. 使用工具打开一个rdc文件。
2. 选择主菜单"Window > > Performance Counter Viewer"，打开窗口。
3. 点击"Performance Counter Viewer"窗口中的"Capture counters"按钮，下拉框选择索要查看的粒度，勾选目标选项，点击"Sample counters"按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/BPlajOyZTC-kyw7rXvzFiQ/zh-cn_image_0000002601551129.png?HW-CC-KV=V1&HW-CC-Date=20260909T172039Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F20A0DE50E1F39D45E45D72629C6EF2F586554C7EAE5E4CBFE747FE8484A372)

4. 以表格形式展示上述勾选选项数据。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/X39C4Vv5QUeX7dMWSdNq5A/zh-cn_image_0000002275369589.png?HW-CC-KV=V1&HW-CC-Date=20260909T172039Z&HW-CC-Expire=31536000000&HW-CC-Sign=F4799F846398C2B8CD068C632CAC7EE0B467889FA8377E1AADE5CCB18AE4D5AA)

## Top Shader近似值

将Vulkan pipelines/OpenGL ES programs按EU Active分类。

1. 打开任意Vulkan或OpenGL ES 的rdc文件，并在"Program"模式下收集counter。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/Dg5lam6bTC2YYinltCrtoA/zh-cn_image_0000002272848593.png?HW-CC-KV=V1&HW-CC-Date=20260909T172039Z&HW-CC-Expire=31536000000&HW-CC-Sign=992639A5556A941C9FDEB676BEDCDFEDB300D902B5906EC59B407DF7ABB01B29)

2. 指标收集完成后，勾选"Group by Program"。此选项允许在多个非连续范围中使用同一pipeline/program的Draw聚合counter。

   生成的表包含所有使用的pipelines/programs，并按EU Cycles度量排序。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/FaXy4Uf5Toa7hxfPmsJSOg/zh-cn_image_0000002569014304.png?HW-CC-KV=V1&HW-CC-Date=20260909T172039Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8CAD86A759D1F764B8DD1F01D0F8B39F5BB2EE94AD38FB3A6EE3B9453204879)

## 查看OpenGL ES多帧基于frame的counter数据

1. 打开一个OpenGL ES多帧rdc文件，选择基于frame收集counter。
2. 点击"Sample counters"，查看基于frame的counters收集。
