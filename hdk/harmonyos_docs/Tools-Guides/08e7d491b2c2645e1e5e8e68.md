# 打开trace文件

#### 打开trace

工具支持打开已录制的trace文件，所有录制的trace文件都会保存到本地指定目录（"C:\\Users\\\<用户个人账户文件夹\>\\.graphicsprofiler\\traces"），以便共享或打开。

单击"Show files list"，可看到trace文件列表，trace文件按字母、文件大小和日期进行排序。如果有新增文件未显示在该界面中，可以尝试单击"Reload files"按钮。

![](https://media:201778750887782133)

通过"Open trace folder"按钮直接访问trace文件的所属文件夹。

![](https://media:201778750887816134)  

#### 删除trace

用户根据需要还可以删除不需要的trace文件。

![](https://media:201778750887849135)

![](https://media:201778750887880136)  

#### 导入trace

通过"Import trace file"按钮可以打开其他文件夹下的trace文件，也可以将trace文件拖拽至工具页面直接打开。

![](https://media:201778750887917137)
