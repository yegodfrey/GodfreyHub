# 打开trace文件

## 打开trace

工具支持打开已录制的trace文件，所有录制的trace文件都会保存到本地指定目录（"C:\Users\<用户个人账户文件夹>\.graphicsprofiler\traces"），以便共享或打开。

单击"Show files list"，可看到trace文件列表，trace文件按字母、文件大小和日期进行排序。如果有新增文件未显示在该界面中，可以尝试单击"Reload files"按钮。

通过"Open trace folder"按钮直接访问trace文件的所属文件夹。
