# GPU Counters

GPU counters提供了不同GPU硬件块利用率的详细信息，这些信息可用于识别GPU利用率的低效率以及执行图形和计算工作负载性能瓶颈的根本原因。

|:---------------------------------|:------------------------------|

|Tiler Active|Tiler执行命令时，GPU活动时间的百分比|
|Shader Core Active|Shader Core执行任务时，GPU活动时间的百分比|

|EU Active|执行单元有执行指令时，Shader Core活动时间的百分比|
|EU Cycles|执行单元执行命令的周期数|
|EU Utilization|执行单元在执行指令时，Shader Core活动时间的百分比|
|EU Stall|执行单元指令执行暂停时，Shader Core活动时间的百分比|
|EU Idle|执行单元空闲状态时，Shader Core活动时间的百分比|
|Texture Unit Active|纹理单元有采样请求时，Shader Core活动时间的百分比|
|Texture Unit Utilization|纹理单元进行纹理采样时，Shader Core活动时间的百分比|
|Concurrent Warps|每个周期每个执行单元分配用于执行的线程束的平均数量|
|Instructions Executed|在所有执行单元上执行的指令总数|
|Instructions Diverged|被控制流分叉的指令百分比|
|Instructions per Shader Invocation|着色器调用中执行的平均指令数|
|Half-float Instructions|半精度浮点指令百分比|
|External Memory Read|从外部存储器读取通过存储器接口的流量|
|External Memory Read by L2 Cache|从外部存储器到L2高速缓存的读取流量通过存储器接口|
|External Memory Read by TU|从外部存储器到纹理单元的读取流量通过存储器接口传递|
|External Memory Read by LSC|从外部存储器到Load/Store缓存的读取流量通过存储器接口|
|External Memory Write|通过内存接口写入流量通过存储器接口|
|External Memory Write by L2 cache|通过内存接口从L2缓存到外部存储器的写入流量|
|External Memory Traffic|通过内存接口从外部内存读取和写入的总流量|
|External Memory Read Bandwidth|通过内存接口从外部读数据的带宽|
|External Memory Write Bandwidth|通过内存接口写外部存储器带宽|
|External Memory Bandwidth|通过内存接口读写数据带宽|
|Drawcalls Count|已执行的绘制调用数|
|Vertex Count|binning阶段处理的顶点数|
|Primitive Count|binning阶段组装的基本体的数量|
|Primitives Clipped|binning阶段剪裁的基本体的数量|
|Primitives Culled|binning阶段剔除的基本体的数量|
|Quads Shaded|片段着色器着色的四边形数|
|Texels Sampled|纹理单元采样的总像素元数|
|Compute Shader Invocations|计算着色器调用数|
|Power Consumption|GPU功耗估计值|

## GPU System Counters

许多常见的GPU counters适用于任何类型的GPU，并且可以由系统而不是GPU制造商提供。例如，GPU Frequency和GPU Load counters显示整体GPU利用率，GPU Memory counter显示整体GPU内存消耗。

## 细粒度GPU Counters

"GPU Counters"监测项可配置Poll interval，允许以最低100us的Poll interval收集指标。

打开跟踪文件，在时间轴上选中某个counter，点击可查看采样耗时，90%以上样本的GPU指标和指定采样耗时相差不超过5%。
