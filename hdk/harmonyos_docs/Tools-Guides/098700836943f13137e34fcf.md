# GPU Counters

GPU counters提供了不同GPU硬件块利用率的详细信息，这些信息可用于识别GPU利用率的低效率以及执行图形和计算工作负载性能瓶颈的根本原因。

![](https://media:201778750890026168)

![](https://media:201778750890069169 "点击放大")

|Shader Core Active|Shader Core执行任务时，GPU活动时间的百分比|

|EU Active|执行单元有执行指令时，Shader Core活动时间的百分比|

#### GPU System Counters

许多常见的GPU counters适用于任何类型的GPU，并且可以由系统而不是GPU制造商提供。例如，GPU Frequency和GPU Load counters显示整体GPU利用率，GPU Memory counter显示整体GPU内存消耗。

![](https://media:201778750890127171)

#### 细粒度GPU Counters

"GPU Counters"监测项可配置Poll interval，允许以最低100us的Poll interval收集指标。

打开跟踪文件，在时间轴上选中某个counter，点击可查看采样耗时，90%以上样本的GPU指标和指定采样耗时相差不超过5%。
