# 其他功能

#### 撤销功能

在显示视图内进行的节点位移、旋转、缩放操作支持撤销功能，其中快捷键"ctrl+z"是撤销；快捷键"ctrl+y"是恢复。  

#### 删除功能

点击显示视图中的节点或者在左侧场景资源管理器选中节点，按下键盘的"Del"键，弹出删除对话框，点击"确定"后即可删除选中节点。
