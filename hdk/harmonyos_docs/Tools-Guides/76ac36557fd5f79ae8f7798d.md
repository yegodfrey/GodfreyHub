# 资源依赖图查看器

资源依赖图展示"Dependent Viewer"是用图像和连线方式展示RenderPass间的资源依赖关系。下面为例图。

![](https://media:201778750903559450)

依赖图展示的数据以RenderPass做区分，展示的每个RenderPass中的基本信息，输入信息，以及输出信息。

基本信息：FBO、DrawCalls、DisPath、Vertices等数值。

输入信息：数据块中展示的输入信息为GPU生成的Buffer与Texture信息，包含了基本的资源ID，以及大小和Usage。

输出信息：数据块中展示的输出信息为此RenderPass中修改或生成的Texture和Buffer信息，Texture以缩略图展示，并附上基本信息。Buffer则展示出Buffer的类型等基本信息。

数据块之间的关联关系以连线表示，通常为一个RenderPass的输出用作另一个RenderPass的输入，特殊场景为Copy场景，会是RenderPass的输出连到另一个RenderPass的输出。
