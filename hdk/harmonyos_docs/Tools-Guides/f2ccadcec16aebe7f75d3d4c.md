# 开始录制

点击"Start Recording"按钮，等待trace录制，点击"Stop Recording"按钮停止录制。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/NkV4QwylQ0K6aVLn7QOcgg/zh-cn_image_0000001839530452.png?HW-CC-KV=V1&HW-CC-Date=20260909T141941Z&HW-CC-Expire=31536000000&HW-CC-Sign=12D508F139255B7A047E5E6969EDF1611276993334C7EBEAB1B9DF61C75B8CA0)

录制完成后会自动打开刚刚抓取到所需数据的trace文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/7U0Y8sGkS2uS-m939LqAfg/zh-cn_image_0000001837854673.png?HW-CC-KV=V1&HW-CC-Date=20260909T141941Z&HW-CC-Expire=31536000000&HW-CC-Sign=22E6F477694FEB24F08575541741A2AE57E865E3DF068E22F12444D1DFEA0B10)

启用的数据源的不同，trace文件看起来会有所不同。
