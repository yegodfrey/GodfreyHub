# 开始录制

点击"Start Recording"按钮，等待trace录制，点击"Stop Recording"按钮停止录制。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/NkV4QwylQ0K6aVLn7QOcgg/zh-cn_image_0000001839530452.png?HW-CC-KV=V1&HW-CC-Date=20261008T151832Z&HW-CC-Expire=31536000000&HW-CC-Sign=178B73D1F919246E41A5717E27A16864808F54C8F33CBF71AA20D276A1EEEDC5)

录制完成后会自动打开刚刚抓取到所需数据的trace文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/7U0Y8sGkS2uS-m939LqAfg/zh-cn_image_0000001837854673.png?HW-CC-KV=V1&HW-CC-Date=20261008T151832Z&HW-CC-Expire=31536000000&HW-CC-Sign=7C34DC90043481C1583C87974B55D0BB6960ADF95D26761384EA0D3CB11EE28F)

启用的数据源的不同，trace文件看起来会有所不同。
