# Model Creator

HUAWEI HiAI是面向移动终端的AI计算平台，构建"服务能力开放"、"应用能力开放"和"芯片能力开放"的三层AI生态。通过云端芯结合的三层开放平台为用户和开发者带来更好的移动体验。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240514142607.58935585161564605693577621263491:50001231000000:2800:95CB551260078D0D871C034C0D56D26615B06270708EA227BFB2650057CFB1F6.png?needInitFileName=true?needInitFileName=true "点击放大")

其中HMS Toolkit可以快速实现用户已有AI模型转换和迁移，将模型移植到HUAWEI HiAI平台，以便更好的运行在华为海思芯片上，获得更好的性能。详细的HUAWEI HiAI Foundation的功能介绍可参见[HUAWEI HiAI Foundation业务介绍](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/introduction-0000001051486804)。

HUAWEI HiAI Foundation提供的Model Creator功能，为您提供图像分类、文本分类、表格分类、物体检测等迁移学习能力，通过深度的机器学习和模型训练，可以很好的帮助用户对图片、文本等进行精确的识别。当前支持图像分类、文本分类和物体检测的能力，表格分类的能力即将上线，敬请期待。

Model Creator训练框架采用TensorFlow，推理框架采用HUAWEI HiAI DDK(NPU机型)、TensorFlow Lite(CPU机型)。

Model Creator不支持macOS M系列处理器（包括M1、M2、M3)。  

#### 图像分类

图像分类是利用迁移学习算法在具有良好泛化能力的基座分类模型的基础上，针对特定领域（如汽车、动物等）百张级数据进行分钟级的学习训练，自动生成图像分类识别的新模型，该生成的新模型可以自动识别图像所属的类别。HMS Toolkit还提供一键生成模型调用的API文件和模型调用Demo示例工程的功能，方便您在应用程序中快速验证和调用图像分类AI模型。  

#### 资源准备

使用图像分类迁移学习能力前，您需要按照要求准备用于训练的图像资源。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240514142608.60029123652079224571450006446418:50001231000000:2800:37E34866365F7E4800F20C08A851D7DCB5746112583E37B0B6E1822C0D1270F7.png?needInitFileName=true?needInitFileName=true "点击放大")  
图像资源需要满足以下条件：

* 训练图像需要按照图像进行分类，在每个分类的目录下，放入合适的清晰图像。  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240514142608.06732886715773929494946317807331:50001231000000:2800:A737A8EC131F87A8CAE59CA3FDDD1C12D7B2A922C3F0002A7A6C84F18C111625.png?needInitFileName=true?needInitFileName=true)  
  图像存储路径和分类名称只能包含：字母、数字、下划线和中文，不能包括空格、特殊字符等符号。
* 图像分类数量约束：至少需要有2个以上的图像类别，上限为1000类。
* 每一类图像要求，训练数据：图像下限为10张。
* 图像格式只能是：bmp、jpg、jpeg、png和gif。

#### 文本分类

文本分类是利用迁移学习算法在具有良好泛化能力的基座分类模型的基础上，针对特定领域（如体育、娱乐、教育等）的文本数据进行分钟级的学习训练，自动生成文本分类识别的新模型。该生成的新模型可以自动识别文字所属的类别。HMS Toolkit还提供一键生成模型调用的API文件和模型调用的Demo示例工程的功能，方便您在应用程序中快速验证和调用文本分类新模型。  

#### 资源准备

使用文本分类迁移学习能力前，您需要按照要求准备用于训练的文本资源。文本资源可以是JSON文件，也可以是文件夹分类的txt文件。

* JSON格式训练文本：JSON文本格式为\[{"label": " ", "text": " "},{"label": " ", "text": " "}\]。
* txt格式训练文本：按照文档的类别进行分类，每一类使用txt文档存放文本内容。  
文本资源训练文件除上述2种格式要求外，还需要满足以下条件：

* 文本存储路径和分类名称只能包含：字母、数字、下划线和中文，不能包括空格、特殊字符等符号。
* 文本类别数量约束：至少需要有2个以上的文本类别。
* 文本数量的约束：每一类别的文本数量至少20条，数量越多新模型的精度越高。
* 文本大小的约束：文本资源不能超过10 MB。
* 文本的编码格式：只能为UTF-8（支持unicode和GBK格式编码转换）。

#### 弱监督目标检测

弱监督目标检测是利用迁移学习算法在具有良好泛化能力的基座分类模型的基础上，针对易于识别的特定分类的图片进行分钟级的学习训练，自动分析图片的特征，从而自动从识别模型中提取出图片中的目标物体，并在图片中标识出来。HMS Toolkit还提供一键生成模型调用的API文件和模型调用Demo示例工程的功能，方便您在应用程序中快速验证和调用图像分类AI模型。  

#### 资源准备

使用图像分类迁移学习能力前，您需要按照要求准备用于训练的图像资源。

* 训练图像需要按照图像进行分类，在每个分类的目录下，放入合适的清晰图像。  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240514142608.56299777291406382872477169276372:50001231000000:2800:8C14485856F19AFFBD2E1F0FF2DC758938DD21989B783F5A111A9E3D4CA9C98B.png?needInitFileName=true?needInitFileName=true)  
  图像存储路径和分类名称只能包含：字母、数字、下划线和中文，不能包括空格、特殊字符等符号。
* 训练数据集中，不同类别下的样本数据，建议图片的背景风格保持一致。
* 图像分类数量约束：至少需要有2个以上的图像类别。
* 每一类图像至少需要20张，多于200张训练效果更佳。
* 图像格式只能是bmp、jpg、jpeg、png和gif。

#### 声音分类

声音分类是利用迁移学习算法在具有良好泛化能力的基座分类模型的基础上，针对特定领域的声音数据进行分钟级的学习训练，自动生成声音分类识别的新模型。该生成的新模型可以自动识别声音所属的类别。HMS Toolkit还提供一键生成模型调用的Demo示例工程的功能，方便你在应用程序中快速验证和调用声音分类新模型。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240514142609.71352982879953980402519756190608:50001231000000:2800:C0850DBBBE18036EA18CF17A640016FF08F2A842D5706DE9872559332A4D5413.png?needInitFileName=true?needInitFileName=true)  
Sound Classification仅支持Windows系统。

#### 资源准备

使用声音分类迁移学习能力前，你需要按照要求准备用于训练的声音资源。声音资源为文件夹分类的wav文件。声音资源训练文件还需要满足以下条件：

* 声音训练资源存储路径和分类名称只能包含：字母、数字、下划线和中文，不能包括空格、特殊字符等符号。
* 类别数量约束：至少需要有2个以上的声音类别。
* 单类数量的约束：每一类别的声音文件数量至少10条，数量越多新模型的精度越高。
* 存储大小的约束：声音资源不能超过20 MB。声音的编码格式：只能为 WAV 格式文件。
