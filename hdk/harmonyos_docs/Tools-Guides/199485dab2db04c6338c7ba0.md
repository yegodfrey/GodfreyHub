# 配置Country/Region

如果您是首次使用HMS Toolkit，请先根据界面弹窗设置您开发的应用适用的Country/Region，用于获取该区域可使用的Kit包资源。

如果您在后续使用中需要更改区域，可按如下步骤操作：

1. 在工具栏中选择"HMS \> Settings \> Select Country/Region"，进入"Country/Region Configuration"页面。
