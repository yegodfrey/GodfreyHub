# 使用显示视图查看场景

在显示视图中，您可以看到场景的所有内容，包括3D节点和2D控件，也可以轻松地调整模型的位置、旋转、缩放属性。

下图从1到4分别为：显示比例、模型控制轴、本地坐标系、视图变化。

## 显示比例

左上角下拉框支持4种手机比例的横屏和竖屏展示，在视图直接看到在手机端展示时的效果。
> 说明
>
> 该功能只在PC版本可用。

## 模型控制轴

视图中央有移动和缩放两个选项卡，从场景树或视图中点击模型会自动显示"移动"控制轴，"移动"控制轴集合了位移和旋转功能，操作移动控制轴可更改模型的位置和朝向。如果想要缩放模型可以点击"缩放"选项卡。

## 本地坐标系

勾选时控制轴由全局坐标系切换成节点本地坐标系。

## 视图变化

右上角视图下拉框可以快速切换视角，默认是自由视图，您也可以切换到前视图，左视图和上视图。

## 聚焦

双击视图中的3D节点可以让选中的节点移到相机中央。
