# 连接工具无响应如何解决？

使用工具期间插拔连接设备的USB，再次连接设备抓帧时，可能会出现页面无响应或者工具断连问题，需要用户进入设备"设置 -> 应用启动管理"，开启允许后台活动。GraphicsProfiler连接无响应时，也可以尝试该操作。
