# 帧抓取界面

帧抓取的调试应用的启动界面如下。

![](https://media:201778750895479280)  

#### Program

* Executable Path选项可以从被连接的手机已安装应用列表中选择要调试抓帧的应用。 ![](https://media:201778750895509281)

<!-- -->

* Intent Arguments可以配置应用启动需要的参数。
  * Intent Arguments用于设备侧应用抓取。

<!-- -->

* Environment Variables配置环境变量与Linux export配置功能是一致的，可以设置全局生效的变量。  

#### Capture Options

![](https://media:201778750895542282)

* Allow Fullscreen：默认打开，不会干扰应用全屏模式显示。未打开该选项时，Frame Profiler尝试将显示窗口修改为当前等效的窗口模式。

<!-- -->

* Allow VSync：默认打开，Frame Profiler允许应用对VSync的使用。未打开该选项时，Frame Profiler禁止对VSync的使用。
* Debugger Delay：默认为0秒。Frame Profiler启动应用进程后延时X秒附加一个传统的调试器。
* Collect Callstacks：默认关闭，打开此选项时，Frame Profiler在抓帧期间，保存应用调用的每个API的调用栈。

<!-- -->

* Only Action stacks：默认关闭，仅当Collect Callstacks开关打开有效时，可以减少CPU负载，为每个API捕获调用堆栈的文件大小和内存开销。
* Enable API Validation：默认关闭，在打开此选项时，Frame Profiler启用对应用API的调试。OpenGL ES启用ARB_debug_output，Vulkan启用VK_LAYER_LUNARG_standard_validation调试层并使用VK_EXT_debug_report获取任何的警告或错误。
* Capture Child Processes：默认关闭，在打开此选项时，Frame Profiler hook到已运行的目标应用进程中。目标应用中的子进程将以与父进程相同的方式注入Frame Profiler。
* Ref all Resources：默认关闭，在打开此选项时，Frame Profiler抓帧时捕获所有活动资源，无论抓取的这一帧是否使用活动资源，都保存在Trace中。

<!-- -->

* Capture all Cmd Lists：默认关闭，抓取所有的API信息会导致文件过大，运行卡顿。
* Verify Buffer Access：默认关闭，校验buffer是否可以访问，有时会存在应用层设置错误的情况。
* Auto Start：默认关闭。  

#### Queue Capture

![](https://media:201778750895580283)

在Queue Capture中配置开始抓帧的帧数X，#Frames配置连续抓取的帧数Y，抓取帧数不超过1000帧。当选中"Queue Capture"后，从"Executable Path"选择启动的应用运行到X帧时，开始连续抓取Y帧。  

#### Vulkan cross-GPU support

![](https://media:201778750895607284)

勾选"Override Vulkan GPU capabilities"，在下拉框中指定目标回放平台，在进行抓取vulkan关键帧操作，就可以在目标回放平台打开抓取到的关键帧。  

#### Clear known cache locations

![](https://media:201778750895635285)

勾选"Clear known cache locations"，将在启动应用程序之前从磁盘清除目标应用程序缓存数据。该功能仅支持在HarmonyOS设备上使用。  

#### Save/Load Settings

上述的抓帧参数配置可以保存为本地文件，下次抓帧时不需要配置这些抓帧参数，可以直接加载配置文件。

![](https://media:201778750895660286)  

#### LiveCapture窗口

![](https://media:201778750895697287)

* Status
  * Target：显示当前抓帧应用和进程ID。
  * Connection Status：显示Frame Profiler与设备之间当前抓帧应用的连接状态。
  * API：显示当前抓帧应用使用的API是OpenGL ES或Vulkan。
* Tools
  * Capture Frame(s) Immediately：立即抓取当前显示的帧。
  * Intelligent Capture：设置智能抓帧的参数，详见[智能抓帧](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/intel-frame-capture-0000001854174893)部分介绍。
  * Deferring Capture：点击进行延时抓取，可在问题场景复现时，点击stop停止抓帧。
  * Capture Specific Frame(s)：抓取特定的帧，例如设置为1000，点击按钮后自动抓取第1000帧。多次点击该按钮，会直接抓取当前帧。
  * Cycle Active Window：激活当前显示的window为抓帧的窗口。
  * Capture 1 Sequential Frame(s)：配置需要抓取的帧数量。

  ![](https://media:201778750895724288)  
  Capture 1 Sequential Frame(s)，初始值为1，此时可以抓单帧也可以抓连续帧。当修改后值大于10，例如：Capture 11 Sequential Frame(s)，自动切换至抓取连续帧模式。
* Captures collected Captures collected主要展示已抓取的帧的缩略图，选中某一帧右键点击，可以保存到本地，或者直接打开回放。

<!-- -->

* Status Bar
  * Preview：显示Captures collected选中的抓取帧的绘制结果。
  * Open：打开回放Captures collected选中的抓取帧。
  * Save：保存Captures collected选中的抓取帧。
* Delete：删除Captures collected选中的抓取帧。
