# C 语言支持

**C 语言规范**

C语言规范目前支持到标准C17，C语言规范详情请参考官网：[https://clang.llvm.org/c_status.html](https://clang.llvm.org/c_status.html)。

**C 库**

在工具链中，C语言库使用开源 MUSL (1.2.3)，包含RISCV32架构下的静态和动态库。POSIX/GUN/BSD规范接口由特殊宏控制，编译器没有定义此宏(_POSIX_SOURCE, _GNU_SOURCE, _BSD_SOURCE)。您必须在源代码中或在编译的命令行中自己定义此宏。C库规范详情，请参考官网: [https://musl.libc.org](https://musl.libc.org)。
