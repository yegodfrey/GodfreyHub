# 渲染流水管线查看器

渲染流水管线查看器指的是"Pipeline State"窗口。

![](https://media:201778750901857418)

渲染流水管线窗口主要分为以下几个区域。

* 控制栏区域  
  ![](https://media:201778750901885419)
  * Show Unused Items：显示当前流水管线未使用的资源。
  * Show Empty Items：显示当前流水管线的空资源。
  * Export：导出当前流水管线的选中资源。
  * Extensions：扩展插件按钮。
* 渲染流水管线状态示意图  
  ![](https://media:201778750901913420)
  * VTX：Vertex Input ，顶点缓存区数据状态。
  * VS：Vertex Shader，顶点着色程序状态，从OpenGL ES 3.2开始，支持了一项新的特性，Tessellation Shader，这是一个新的Shader，发生在顶点处理阶段，曲面细分可以在显卡上动态生成新的顶点和面。
  * TCS：Tessellation Control Shader，一个可编程管线，用GLSL编写的着色器程序，可选，如果没有TCS，会使用系统默认的参数。
  * TES：Tessellation Evaluation Shader，一个可编程管线，用GLSL编写的着色器程序，如果没有这个Shader，则不发生曲面细分。它获取Tessellation Control的结果，进一步产生每个细分的顶点的绝对坐标，生成顶点真实的坐标。
  * GS：Geometry Shader，是继Vertex Shader和Fragment Shader之后，由Shader Model 4（第四代显卡着色架构）正式引入的第三个着色器。在OpenGL3.x中也成为核心，使图形程序用户在可编程渲染管道（programable render pipline）下能够更大的发挥自由度。
  * RS：Rasterizer，光栅化是将每个独立的片元分解为片段的离散元素的过程。
  * FS：Fragment Shader，将光栅化生成的片段使用可编程着色器程序进行处理，转换为一组颜色、深度值、模板值的阶段。
  * FB：FrameBuffer，帧缓存区对象，渲染管线流水最终需要将生成的图像存放到帧缓存区中，从而在不干扰主屏幕的情况下进行渲染。
  * CS：Compute Shader，在GPU运行却又在普通渲染管线之外的程序，通过Compute Shader将大量可以并行的计算放到GPU中计算从而节省CPU资源。
* 内容窗口区域，内容窗口区域会根据关注的管线状态变化。
  * 顶点缓存区详情查看
    * Vertex Attribute Format：每个顶点缓存区都有对应的格式、名称、Slot编号、相对偏移量、网格跳转按钮。
    * Vertex Array Object：展示对应的资源编号关系。
    * Buffers：用于展示关联的缓冲区资源编号，缓冲区每个数据的步长、偏移、实例除数、缓冲区长度、缓冲区跳转按钮。
    * Mesh View：用于展示顶点的几何网格组成图像。
    * Primitive Topology：几何组成的原型，顶点被存储在一个名为顶点缓存区的数据结构中，是一段连续的内存，顶点被一个挨一个的存储在缓存区中，使用Primitive Topology来展示这一串顶点数据。

    ![](https://media:201778750901951421)
  * 顶点着色程序/片段着色程序
    * Shader：顶点/片段着色程序使用的对应Program编号和Shader编号展示跳转按钮、着色程序编辑按钮、着色程序保存按钮。
    * Texture：使用到的输入纹理的信息展示，Slot编号、纹理资源编号、纹理的类型、纹理的宽高、纹理的深度信息、Mipmap的大小、纹理格式、纹理查看跳转按钮。
    * Samplers：顶点/片段着色程序针对不同的纹理使用的采样器，Slot编号、纹理资源编号、Wrap模式设置格式、Filter设置格式、Level of Detail采样范围、Level of Detail采样偏差。
    * Uniforms and UBOs：存储着色语言中Uniform类型变量的缓冲区对象，Slot编号、缓冲区资源编号、缓冲区字节取值范围、缓冲区大小、缓冲区查看跳转按钮。

    ![](https://media:201778750901992422)
  * 光栅化窗口
    * Rasterizer State：当前流水管线下的各种模式设置的状态。
    * Multisample State：当前流水管线下的抗锯齿采样的设置状态。
    * Viewports：当前流水管线下的视窗大小设置状态。
    * Scissor Regions：当前流水管线下的裁剪视窗的设置状态。

    ![](https://media:201778750902028423)
  * 帧缓存区输出内容展示窗口
    * Framebuffer：当前渲染流水管线输出的纹理列表，绘制的FrameBufferObject对象编号、Slot编号、输出的对应资源编号、输出的纹理格式、纹理的宽高、纹理的是否带深度信息、Mipmap的大小、纹理查看跳转按钮。
    * Target Blends：输出纹理与缓冲区的融合算法选用状态展示，片段着色器获取片段颜色输出，并与这些输出到颜色缓冲区中的颜色组合，混合参数允许以各种方式组合每个输出的源颜色和目标颜色。
    * Blend State：当前启用了Blend后功能生效，glEnable(GL_BLEND)。 ![](https://media:201778750902057424)

    * Depth State：深度测试的设置状态。
    * Stencil State：模板测试的设置状态。 ![](https://media:201778750902098425)

  * 计算着色器
    * 窗口整体布局与顶点/片段着色器类似，Shader\~Uniforms and UBOs的描述请参见顶点/片段着色器。
    * Read/Write Bindings：SSBO（Shader Storage Buffer Object）着色器存储缓存对象，类似于统一缓冲区对象，Slot编号，对应缓存区资源编号，数据的格式，缓冲区的读写权限设置，查看BufferXX的跳转按钮。 ![](https://media:201778750902137426)

#### Subpass Shading

vkCmdSubpassShadingHUAWEI命令在"Event Browser"中显示为GPU事件。这也意味着可以为此命令收集GPU性能计数器。

Khronos组织的标准扩展链接：<https://registry.khronos.org/vulkan/specs/1.3-extensions/man/html/VK_HUAWEI_subpass_shading.html>

![](https://media:201778750902169427)

当用户选择vkCmdSubpassShadingHUAWEI命令时，"Pipeline State"窗口具有"Subpass shading"阶段，而不是"Compute Shader"阶段。

![](https://media:201778750902199428)
