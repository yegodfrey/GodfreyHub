# Vulkan shader profiler

Vulkan shader profiler (vulkan-spirv) 功能能够对着色器执行进行深入分析，并帮助检测着色器代码中的问题区域。当前版本的着色器分析器支持对Vulkan帧的分析，因为它使用的是SPIR-V代码进行操作。

1. 点击"File > Open Capture"，打开rdc文件，在Event Browser中选择某一个绘制索引。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/ZjGYMch2QVCvSuzKF7hv0g/zh-cn_image_0000002477407252.png?HW-CC-KV=V1&HW-CC-Date=20260909T142314Z&HW-CC-Expire=31536000000&HW-CC-Sign=BDED513ECF5581D021DE4322986ADC5F4DAC6D74255F70723F664D2EBEAB2DAA)

2. 点击"Window > Pipeline State"进入Pipeline State界面，点击"VS"或"FS"，再点击"Profile"，着色器分析模块视图会自动打开。
