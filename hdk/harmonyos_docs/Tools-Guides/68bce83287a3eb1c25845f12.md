# Vulkan shader profiler

Vulkan shader profiler (vulkan-spirv) 功能能够对着色器执行进行深入分析，并帮助检测着色器代码中的问题区域。当前版本的着色器分析器支持对Vulkan帧的分析，因为它使用的是SPIR-V代码进行操作。

1. 点击"File \> Open Capture"，打开rdc文件，在Event Browser中选择某一个绘制索引。

   <br />

   ![](https://media:201778750903608451)

   <br />

2. 点击"Window \> Pipeline State"进入Pipeline State界面，点击"VS"或"FS"，再点击"Profile"，着色器分析模块视图会自动打开。

   <br />

   ![](https://media:201778750903643452)

   ![](https://media:201778750903672453)

   <br />
