# Analytics Kit手工转换指导书

#### 转换前须知

* Google Analytics SDK迁移至Analytics Kit SDK请参见[Analytics Kit SDK简介](#section1991119378538)至[迁移步骤](#section1096534395710)章节。
* 其他章节为API手工转换指导。  

#### Analytics Kit SDK简介

华为分析服务预置大量分析模型，可帮助您清晰地了解用户的行为方式，从而实现用户、产品、内容的深度洞察，让您实现基于数据驱动的运营，可以就应用营销和产品优化制定明智的决策。

Analytics Kit采集端侧数据，用于支持Analytics功能：

* 提供埋点与上报接口，支持代码级自定义事件埋点与上报。
* 支持用户属性设置，最多保存25个用户属性。
* 支持自动事件采集与Session计算，预置事件ID与事件参数。  

#### 数据模型对比

Google Analytics SDK封装了不同种类的事件匹配类型方便您使用，例如：屏幕视图，事件，社交，电子商务等。您在设置事件的操作类型后通过track()上报事件。

Analytics Kit SDK是基于事件分析数据模型，所有事件均使用事件名称和事件参数进行分类。分析数据模型采用了Event-Param-User模型来记录数据，通过不同的参数对事件进行描述，同时对用户的特征也进行了描述。

#### 迁移步骤

#### 集成SDK

集成SDK步骤请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876)。  

#### 初始化

配置导入成功后，在第一个Activity的onCreate中初始化Analytics Kit，获得[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219)实例。若agconnect-services.json文件不正确，则无法进行打点。

获取[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219)实例后就可以调用[onEvent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section15204518184114)打点数据了。

```
@Override 
protected void onCreate(Bundle savedInstanceState) { 
    super.onCreate(savedInstanceState); 
    setContentView(R.layout.activity_main); 
    HiAnalyticsTools.enableLog(); 
    HiAnalyticsInstance instance = HiAnalytics.getInstance(this); 
    Bundle bundle = new Bundle();
    bundle.putString(CATEGORY, "screen");
    bundle.putString(PRODUCTNAME, "screen name");
    instance.onEvent(VIEWPRODUCT, bundle);
}
```

#### 数据模型迁移

根据[事件映射参考](#section1774122416554)与[事件属性映射参考](#section199894005619)的事件模型映射参考表，将Google Analytics SDK定义的事件转换为Analytics Kit SDK中对应的预制模型。相关事件模型参数请参见[预置事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-predefined-events-general-0000001051997159)。

以下是Google Analytics SDK打点用户购买商品事件迁移到Analytics Kit SDK示例。

```
Context context = this;
// Google Analytics SDK打点用户购买商品事件
HitBuilders.ScreenViewBuilder builder = new HitBuilders.ScreenViewBuilder();
builder.setProductAction(
    new ProductAction(ProductAction.ACTION_PURCHASE)
        .setTransactionId("TT-1234")
        .setTransactionRevenue(3.14)
        .setTransactionCouponCode("EXTRA100"))
    .addProduct(new Product().setId("PID-4321").setName("Water Monkeys!"));
Tracker tracker = new Tracker(); // 获取Tracker
tracker.send(builder.build());
// Analytics Kit SDK打点用户购买商品事件
Bundle purchaseBundle = new Bundle();
purchaseBundle.putString(TRANSACTIONID, "TT-1234");
purchaseBundle.putDouble(REVENUE, 3.14);
purchaseBundle.putString(VOUCHER, "EXTRA100");
HiAnalyticsInstance instance = HiAnalytics.getInstance(context);
instance.onEvent(COMPLETEPURCHASE, purchaseBundle );
```

#### 注意事项

* HMS Core Analytics SDK默认会自动采集Activity页面事件，所以从Google Analytics SDK迁移到HMS Core Analytics SDK后，不需要手动埋点。非Activity的页面事件采集请使用[pageStart](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section111581350115113)(String pageName, String pageClassOverride)和[pageEnd](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section8959745205416)(String pageName)接口。
* HMS Core Analytics SDK不支持自动上报未捕获的异常，对应功能可参考crash SDK。

#### setCurrentScreen(Activity, String, String)

HMS Core Analytics SDK默认会自动采集Activity页面事件，不需要手动埋点；非Activity的页面事件采集建议使用[pageStart](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section111581350115113)(String pageName, String pageClassOverride)和[pageEnd](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section8959745205416)(String pageName)接口。
