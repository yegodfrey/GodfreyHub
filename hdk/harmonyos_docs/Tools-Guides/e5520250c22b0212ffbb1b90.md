#### 查看云测试报告

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250807165405.00321093505335811994519318804215:50001231000000:2800:EC1B136B97802AC69EC6E52B488F06F62FBBDF930654B680AE675A9DB0A27E58.gif)

兼容性测试会执行10-20分钟，具体根据实际手机的空闲情况确定。

测试会对9大问题进行检测：

* 崩溃：运行过程中出现类似"xx应用 已停止运行"的弹窗
* 无响应：运行过程中出现"xx应用 无响应"的弹窗
* 闪退：运行过程中某个操作导致非正常退出到桌面
* 运行错误：运行过程中某个操作产生了不符合预期的结果，可能是应用界面或后台逻辑不符合预期
* UI异常：页面控件显示不完全
* 无法回退：应用进入某个页面后无法退出该页面且无法退出应用(只能强行杀进程关闭)
* 黑白屏：页面存在全黑屏或全白屏
* js异常：java script 运行时出现异常
* 华为帐号登录：支持华为帐号登录
