# 前提条件

## 使用GraphicsProfiler抓trace前提条件

Graphics Profiler允许指定存储trace文件的目录，指定本地ADB或HDC可执行文件以及在分析会话期间使用的远程ADB服务器地址。可以点击侧边栏上的"Settings"打开设置以上参数的界面。

* HarmonyOS 4.0及以下版本：将 adb 设置到环境变量 Path 中，或在"Settings"窗格的"ADB path"字段中指定具有 adb 的文件夹。
* HarmonyOS 5.0及以上版本：将 hdc 设置到环境变量 Path 中，或在"Settings"窗格的"HDC path"字段中指定具有 hdc 的文件夹。

## 使用FrameProfiler抓帧前提条件

> 注意
>
> 对于HarmonyOS 5.0以上版本设备，用户需要按照如下步骤重新打包hap。
>
> 对于HarmonyOS 6.0以上版本设备，无须打包hap，可直接通过FrameProfiler界面[抓帧](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/frame-capture-0000001050701440)。

**OpenGL ES应用：**

* 请将位于<installation_folder>/frame_profiler/sdk路径的"libsquid.so"文件复制到hap的libs/arm64-v8a文件夹中。

**Vulkan应用：**
> 说明
>
> Vulkan应用打包工具so抓帧需要将工具UI界面中 tools → settings → core → config editor →capture 的DisableVulkanSystemLayerFlag选项勾选上。

* 请将位于<installation_folder>/frame_profiler/sdk路径的"libsquid.so"文件复制到hap的libs/arm64-v8a文件夹中。
* 请将位于<installation_folder>/frame_profiler/sdk路径下"squid.json"文件复制到hap的src/main/resource/rawfile文件夹中。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/u6tJv_i6Sfe7CLLttazrWA/zh-cn_image_0000002555783004.png?HW-CC-KV=V1&HW-CC-Date=20261008T171408Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B7C2B030CE2A6CD52AD5CF2169FA145956951B7B4E0DBD951321999789F2C09)

* 请在src\main\ets\pages\Index.ets文件中添加代码(由于Vulkan-Loader模块不支持直接读取rawfile)。

```screen
// 在Index.ets文件开头添加头文件依赖 
import fs from '@ohos.file.fs';  
// 在Index.ets文件中找到aboutToAppear(): void 函数，在函数开头添加以下代码 
{     
    let path = getContext(this).filesDir;     
    if (!fs.accessSync(path)) {         
        fs.mkdirSync(path);     
    }      
    let buffer = getContext(this).resourceManager.getRawFileContentSync('squid.json');     
    let file = fs.openSync(path + '/squid.json', fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE);     
    fs.writeSync(file.fd, buffer.buffer); 
}
```

* 连接工具拉起打包好的应用，查看UI界面log日志，有如下打印内容即为打包成功。
