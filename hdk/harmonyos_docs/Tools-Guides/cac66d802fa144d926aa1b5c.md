# Render Load

勾选"Render Load"，调整汇聚间隔"Aggregation Interval"，点击"Start Recording"抓取trace，查看并行度的counter曲线。勾选"Render Load"后，只收集必要数据，并按照汇聚间隔进行计算，最后展示渲染负载的指标数据。
> 说明
>
> 仅支持马良 920 GPU设备上使用。
