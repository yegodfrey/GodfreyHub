# 查看资源依赖图

打开"Window \> Dependent Viewer"窗口，查看资源依赖图。  

#### 支持用户操作

![](https://media:201778750902456429)  

|编号|功能说明|
|:-|:---------------------------------------------------------------------------------------------------------------------------------|
|1|"Ctrl+鼠标滚轮"支持展示数据的缩放。|
|2|"Ctrl+鼠标左键/右键"支持拖动视图。|
|3|"Alt+鼠标左键点击"支持同时选中多个RenderPass或RenderPass中的Texture、Buffer。|
|4|点击"RenderPass"时，会修改整个程序的当前EID，同步到"Event Browser"等关注EID切换的窗口。同样，外部的EID变换也会同步到"Dependent Viewer"窗口，跳转到EID对应的RenderPass数据块位置并标注为选中状态。|

#### 工具栏

"Dependent Viewer"的工具栏如图所示。

![](https://media:201778750902483430)

* "ShowBezierLine"：显示与隐藏无用的连接线，选中的线会高亮并保存，不会隐藏掉。
* "Export Html"：将缩略图导出成html格式的表格。点击html中右上角"showBtn"可以隐藏和展示Cpu上load的资源信息。

  ![](https://media:201778750902526431)

<!-- -->

* "Export Csv"：将缩略图导出成csv格式的表格。
* "Export Svg"：将缩略图导出成svg格式的图片。
* "Show/Hide Inspect"：用于展示或收起资源的关联Frame。

![](https://media:201778750902573432)  

#### 右键菜单

"Dependent Viewer"支持全局右键点击菜单，全局的菜单支持如下操作。

* Expand All：全部展开。
* Collapse All：全部收起。
* Input：列出界面上的输入，支持缩略图展示。 ![](https://media:201778750902600433)

<!-- -->

* Output：列出界面上的输出，支持缩略图展示。 ![](https://media:201778750902629434)

<!-- -->

* All Resources：跳转到展示此RenderPass所用到所有资源的窗口。窗口对Input与Output资源做了区分，并且也对Texture和Buffer做了区分展示。 ![](https://media:201778750902723435)

<!-- -->

* View Contents：跳转到Texture Viewer窗口并展示此Texture的大图。
