# 查看资源依赖图

打开"Window > Dependent Viewer"窗口，查看资源依赖图。

## 支持用户操作

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/fwLDc0qlRKuhGVAUsvMWsA/zh-cn_image_0000002412436821.png?HW-CC-KV=V1&HW-CC-Date=20260909T143046Z&HW-CC-Expire=31536000000&HW-CC-Sign=691796B861913675C870B196CA1DE3C8D5360FC2153C1F45FFCCDA20A5292B27)

|编号|功能说明|
|:-|:---------------------------------------------------------------------------------------------------------------------------------|
|1|"Ctrl+鼠标滚轮"支持展示数据的缩放。|
|2|"Ctrl+鼠标左键/右键"支持拖动视图。|
|3|"Alt+鼠标左键点击"支持同时选中多个RenderPass或RenderPass中的Texture、Buffer。|
|4|点击"RenderPass"时，会修改整个程序的当前EID，同步到"Event Browser"等关注EID切换的窗口。同样，外部的EID变换也会同步到"Dependent Viewer"窗口，跳转到EID对应的RenderPass数据块位置并标注为选中状态。|

## 工具栏

"Dependent Viewer"的工具栏如图所示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/37f1hVl_RgiH2166wSWcXw/zh-cn_image_0000001298185662.png?HW-CC-KV=V1&HW-CC-Date=20260909T143046Z&HW-CC-Expire=31536000000&HW-CC-Sign=93A66231A03F905697CC36B976CC521F86E692A0BFBD6B4F27BA7B04A8BE4080)

* "ShowBezierLine"：显示与隐藏无用的连接线，选中的线会高亮并保存，不会隐藏掉。
* "Export Html"：将缩略图导出成html格式的表格。点击html中右上角"showBtn"可以隐藏和展示Cpu上load的资源信息。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/P1fADFqiSPmEVqsQlUGrRg/zh-cn_image_0000002412442841.png?HW-CC-KV=V1&HW-CC-Date=20260909T143046Z&HW-CC-Expire=31536000000&HW-CC-Sign=87C61920ECB15DFA1B1861F0E8C017212435714F260B9FFA5787279041698D43)


* "Export Csv"：将缩略图导出成csv格式的表格。
* "Export Svg"：将缩略图导出成svg格式的图片。
* "Show/Hide Inspect"：用于展示或收起资源的关联Frame。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/9vLGh6n4SomTrZlUEa5wJA/zh-cn_image_0000002378883748.png?HW-CC-KV=V1&HW-CC-Date=20260909T143046Z&HW-CC-Expire=31536000000&HW-CC-Sign=F5014C7D64DFBD702C4E7F471B0432EBCDA976337D0B8DFC335FE2B6E81E2070)

## 右键菜单

"Dependent Viewer"支持全局右键点击菜单，全局的菜单支持如下操作。

* Expand All：全部展开。
* Collapse All：全部收起。
* Input：列出界面上的输入，支持缩略图展示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/7CQ3prI6SDW2GCcxa16cwQ/zh-cn_image_0000002378872996.png?HW-CC-KV=V1&HW-CC-Date=20260909T143046Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D247D5F7BC4B1D876D64255427A6DEBC6E2B708E26167AACA8EC09FFD9127EB)


* Output：列出界面上的输出，支持缩略图展示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/eWOwv4-wQX63QMGEeb7G9g/zh-cn_image_0000002378873184.png?HW-CC-KV=V1&HW-CC-Date=20260909T143046Z&HW-CC-Expire=31536000000&HW-CC-Sign=AF1F8EE7B103038C546B18471D5C3E0729142788054F39A4C3E11A1D175482C3)


* All Resources：跳转到展示此RenderPass所用到所有资源的窗口。窗口对Input与Output资源做了区分，并且也对Texture和Buffer做了区分展示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/2HFxrV-uRFmzRE176xtU_A/zh-cn_image_0000002412435493.png?HW-CC-KV=V1&HW-CC-Date=20260909T143046Z&HW-CC-Expire=31536000000&HW-CC-Sign=0A7FDBFD28279AACA388709E90F6CA18C349FB78A5AFBB72CFD75D38D2830403)


* View Contents：跳转到Texture Viewer窗口并展示此Texture的大图。
