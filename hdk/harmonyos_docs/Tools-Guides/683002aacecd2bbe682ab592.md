# 查看资源依赖图

打开"Window > Dependent Viewer"窗口，查看资源依赖图。

## 支持用户操作

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/fwLDc0qlRKuhGVAUsvMWsA/zh-cn_image_0000002412436821.png?HW-CC-KV=V1&HW-CC-Date=20261008T152926Z&HW-CC-Expire=31536000000&HW-CC-Sign=5505B6C745EF9DB6373BE9A4476B2325292E39985F98D98757286CB2625ADBBF)

|编号|功能说明|
|:-|:---------------------------------------------------------------------------------------------------------------------------------|
|1|"Ctrl+鼠标滚轮"支持展示数据的缩放。|
|2|"Ctrl+鼠标左键/右键"支持拖动视图。|
|3|"Alt+鼠标左键点击"支持同时选中多个RenderPass或RenderPass中的Texture、Buffer。|
|4|点击"RenderPass"时，会修改整个程序的当前EID，同步到"Event Browser"等关注EID切换的窗口。同样，外部的EID变换也会同步到"Dependent Viewer"窗口，跳转到EID对应的RenderPass数据块位置并标注为选中状态。|

## 工具栏

"Dependent Viewer"的工具栏如图所示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/37f1hVl_RgiH2166wSWcXw/zh-cn_image_0000001298185662.png?HW-CC-KV=V1&HW-CC-Date=20261008T152926Z&HW-CC-Expire=31536000000&HW-CC-Sign=69050A07495DCDA3901BA56B8DC3E98A1AD387F71AA8C26FB322567409EA8135)

* "ShowBezierLine"：显示与隐藏无用的连接线，选中的线会高亮并保存，不会隐藏掉。
* "Export Html"：将缩略图导出成html格式的表格。点击html中右上角"showBtn"可以隐藏和展示Cpu上load的资源信息。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/P1fADFqiSPmEVqsQlUGrRg/zh-cn_image_0000002412442841.png?HW-CC-KV=V1&HW-CC-Date=20261008T152926Z&HW-CC-Expire=31536000000&HW-CC-Sign=4F6EFAA88009999D12D22B848391D6992517AC23856CCCA6581237C12595E5DF)


* "Export Csv"：将缩略图导出成csv格式的表格。
* "Export Svg"：将缩略图导出成svg格式的图片。
* "Show/Hide Inspect"：用于展示或收起资源的关联Frame。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/9vLGh6n4SomTrZlUEa5wJA/zh-cn_image_0000002378883748.png?HW-CC-KV=V1&HW-CC-Date=20261008T152926Z&HW-CC-Expire=31536000000&HW-CC-Sign=CCCC60A6365654F0C108AF15C0E7F5D253D0AA9481414851B63FF966439E6323)

## 右键菜单

"Dependent Viewer"支持全局右键点击菜单，全局的菜单支持如下操作。

* Expand All：全部展开。
* Collapse All：全部收起。
* Input：列出界面上的输入，支持缩略图展示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/7CQ3prI6SDW2GCcxa16cwQ/zh-cn_image_0000002378872996.png?HW-CC-KV=V1&HW-CC-Date=20261008T152926Z&HW-CC-Expire=31536000000&HW-CC-Sign=A4EEA896B566843BB5FFF09423B570D339280DA4B21ACE16F9E57F4E054E4B16)


* Output：列出界面上的输出，支持缩略图展示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/eWOwv4-wQX63QMGEeb7G9g/zh-cn_image_0000002378873184.png?HW-CC-KV=V1&HW-CC-Date=20261008T152926Z&HW-CC-Expire=31536000000&HW-CC-Sign=0E3EB7E0009949F321216AE619903BA2D147E5C9D0390DE8FE9F7D5BAC966979)


* All Resources：跳转到展示此RenderPass所用到所有资源的窗口。窗口对Input与Output资源做了区分，并且也对Texture和Buffer做了区分展示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/2HFxrV-uRFmzRE176xtU_A/zh-cn_image_0000002412435493.png?HW-CC-KV=V1&HW-CC-Date=20261008T152926Z&HW-CC-Expire=31536000000&HW-CC-Sign=D2428749D3CFC206B0B3CAD9873564B66430F62FF036BCBA3360DB29BCF3C923)


* View Contents：跳转到Texture Viewer窗口并展示此Texture的大图。
