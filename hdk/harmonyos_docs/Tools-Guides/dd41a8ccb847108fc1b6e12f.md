# 概述

本文档聚焦于Bisheng Mobile MCU工具链的使用，该工具链包含编译器、汇编器、链接器、其他二进制工具以及标准C/C++库（musl、libc++）。在下述说明中，仅介绍运行于Linux操作系统平台上的工具链，运行于Windows平台上的工具链基本同理。
