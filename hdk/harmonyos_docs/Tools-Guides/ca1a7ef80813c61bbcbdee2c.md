# 发布快应用体验版本

通过发布体验版本，华为快应用IDE会生成体验码，其他用户使用"快应用研发助手"通过扫描二维码或者输入体验码，就可提前体验开发完的快应用。

1. 使用IDE打开待体验的项目工程，使用华为帐号登录IDE。
2. 点击![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100017.85138833125441704232075723753862:50001231000000:2800:FD2A4AD6E774AE73F3F7D6C7AE0C7D58EB2D7635587A910BCC4A96A243957095.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)发布版本。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100017.83302283053477192146807893844814:50001231000000:2800:5013DEBC371EC8025CA74CDAF4899EDD83418633FF44A4E94FE0C17D4CD0BC45.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
3. 在"版本发布"页面选择"体验版"后，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100018.95761609797495514864754176602599:50001231000000:2800:491864771A6F1D55951F7F06D7E74D7FC109EF24D6163B23AD75995FA892AA6C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

4. 如果没有登录，IDE右下角会弹出登录的提示。点击右上角"登录"，在登录页面输入已注册并认证的华为帐号和密码并登录。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100018.97900619731032427671351950805257:50001231000000:2800:7AFF64C21D46507F3D937107D45CA5A406B562CDC9F6BFE411FF7FFCA69387CD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

5. 如果没有签名，则右下角弹出如下提示框，引导构建签名。可以创建新的签名，也可以导入已有签名。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100018.29774083307136884762293689432633:50001231000000:2800:B69563575A1A518DD6EAF66A1544D81632002CBC3BB07C5F677E565F3DEA2521.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

6. 在"发布体验版本"页面，可对版本名和版本号进行编辑，点击"下一步"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100018.71716179080014658542197765096517:50001231000000:2800:BFB64EB449B4402636D53172E3D89CA609F3289ED115B85887B3112302CEDBEC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

7. 体验版本的有效期为7天，用于获取体验版本的体验码有效期可以设置为15分钟、30分钟和60分钟三种，设置完成点击"提交"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100018.52841713076105576454154475875236:50001231000000:2800:395A502666956F55670A156DDE522F36E98D2E78BF0980252693BBF77F73E4D8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

8. 生成体验版本的二维码和体验码。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100018.99499013694263645303543656308146:50001231000000:2800:36E57F0C40B635955EEC054BE55475B361F25EB39282B0259BF0D238EF371A9F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

9. 打开待体验的快应用。
   * 场景1：扫码体验
     * 手机浏览器扫描二维码。
     * 在华为应用市场搜索并打开"快应用研发助手"，使用华为帐号登录。 在"快应用研发助手"中点击"+"，选择"扫描二维码添加"。

   * 场景2：体验码体验 在华为应用市场搜索并打开"快应用研发助手"，使用华为帐号登录。

     在"快应用研发助手"中点击"+"，选择"输入体验码添加"。
