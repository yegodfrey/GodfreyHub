# RPK操作

1. 进入RPK操作界面有如下两种方式：
   * 打开华为快应用IDE，在欢迎界面导航选择"打开RPK"。
   * 进入主界面，菜单选择"文件 \> 打开RPK"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.10852031396875493729770108589892:50001231000000:2800:5186EA78553310EA8784EADB5CF775C1D1DE5561A4738062D5A1E7D39190A654.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
2. 选择rpk文件存放的路径，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.15706231064620114087527693549190:50001231000000:2800:E2301CDD4E4D699313AFA960AE798A7630845E4BDA780245C08930F4A2683E2E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3. 进入rpk文件的操作界面。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.24224396360894468977965905544307:50001231000000:2800:4490A2180BB6E80FAC9114821E5F9B634074DE1483AE23AF681C40562A185872.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   快应用项目有3种类型的rpk，分别为debug包、release包、体验版本。
   * debug包只支持"本地运行"。
   * release包和体验版本支持"本地运行"、"发布体验版本"、"云测试"、"前往AGC发布"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.89805453316681670840810308060405:50001231000000:2800:A5582406A6B8B86D60418400ED7300D4B7924F286BF61E6FCCD65A7EB671165F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
   * 点击"本地运行"。
     1. 进入配置界面，选择运行平台，点击"确定"。具体操作请参见"[通用配置](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/ide-set-common-param-0000001148584193)"。

        ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.50298220825940387966672896320130:50001231000000:2800:86976C2B008306824A5D6D009F1705ABB2419B74C6E808A549F110AE4D804A81.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
     2. 选择运行设备，点击"确认"。具体操作请参见"[连接调试设备](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/ide-link-device-0000001101576706)"。

        ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.57853620475664067643639196161022:50001231000000:2800:0DD8C390D7980CB2E1B19577C92A4E1564382E4B8A9320BC4A3F89F04E80DC61.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
     3. 控制台输出运行日志，终端设备投屏。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.88901565937240607748742061112309:50001231000000:2800:6F521B4747FBF5471B2A986BD45C45BD1A4D665E13F74B387A677024934D50A5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   * 点击"发布体验版本"，登录后选择存放签名的文件夹，即可发布。具体操作请参见"[发布体验版本](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/ide-release-quickapp-trial-version-0000001368867756)"。

     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.58608118804265552673252131024114:50001231000000:2800:80E621056697069D5AFED4CB72C54AC94B37C6B39AF458B79DDEF8CE86D9A71C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
   * 点击"云测试"，登录后弹出云测试窗口，上传RPK即可。具体操作请参见"[云测试（兼容性测试）](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/ide-cloud-testing-0000001148136675)"。
   * 点击"前往AGC发布"，跳转至AppGallery Connect，提交应用上架。
