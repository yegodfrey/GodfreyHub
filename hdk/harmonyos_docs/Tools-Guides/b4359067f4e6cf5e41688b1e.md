# 延迟trace抓取

为了给用户更多的灵活性，"Stop when full"跟踪模式支持延迟trace抓取，支持用户在应用拉起后的任意时间开启trace抓取。

1. 在启动跟踪会话之前，请关闭"Record trace from start"，右上角的"Start Recording"按钮变为"Start Session"按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/22/v3/bikZaF7URJqp0bdLcV9n1A/zh-cn_image_0000002272956429.png?HW-CC-KV=V1&HW-CC-Date=20260909T181813Z&HW-CC-Expire=31536000000&HW-CC-Sign=90CC6C53302240C85CA7D024EE44FC44E098B49C9C0937E6D789C9347B34B04E)

2. 点击"Start Session"按钮，应用启动，等待需要抓取的场景，点击"Start Recording"按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/qdjDZNSCQLOctAwfnhXmJw/zh-cn_image_0000002272957889.png?HW-CC-KV=V1&HW-CC-Date=20260909T181813Z&HW-CC-Expire=31536000000&HW-CC-Sign=394D36E045C76F24190D44A1615D29316B3BACE09593ED81B1B6C0634990AD8B)

3. 当缓冲区已满或达到时间限制时，跟踪收集将自动停止，也可以手动停止跟踪记录。
