# Cloud Storage

## getApp()

属于FirebaseStorage中方法，而在AGC中，属于[AGCStorageManagement](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcstoragemanagement-0000001054967269)中的方法，下面给出简易的代码转换示例。

在To HMS API模式下的代码修改示例：

```screen
com.huawei.agconnect.AGConnectInstance hReturn = com.huawei.agconnect.AGConnectInstance.getInstance();
```

## putFile(java.io.File file)

属于StorageReference中方法，而在AGC中，属于[StorageReference](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/storagereference-0000001054767243)中的方法，下面给出简易的代码转换示例。

在To HMS API模式下的代码修改示例：

```screen
File file = new File("path/to/images/rivers.jpg");
StorageReference storageRef = AGCStorageManagement.getInstance().getStorageReference("images/rivers.jpg");
UploadTask uploadTask = storageRef.putFile(file);
```

## putFile(java.io.File file, com.huawei.agconnect.cloud.storage.core.FileMetadata metadata)

属于StorageReference中方法，而在AGC中，属于[StorageReference](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/storagereference-0000001054767243)中的方法，下面给出简易的代码转换示例。

在To HMS API模式下的代码修改示例：

```screen
FileMetadata metadata = new FileMetadata();
metadata.setContentType("image/jpg");
File file = new File("path/to/images/rivers.jpg");
StorageReference storageRef = AGCStorageManagement.getInstance().getStorageReference("images/rivers.jpg");
UploadTask uploadTask = storageRef.putFile(file, metadata);
```

## putFile(java.io.File file, com.huawei.agconnect.cloud.storage.core.FileMetadata metadata, java.lang.Long offset)

属于StorageReference中方法，而在AGC中，属于[StorageReference](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/storagereference-0000001054767243)中的方法，下面给出简易的代码转换示例。

在To HMS API模式下的代码修改示例：

```screen
FileMetadata metadata = new FileMetadata();
metadata.setContentType("image/jpg");

long offset = 0L;
```
