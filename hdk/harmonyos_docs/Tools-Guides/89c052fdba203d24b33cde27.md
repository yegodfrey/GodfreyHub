# Map Kit手工转换指导书

## 转换前须知

* Add HMS API 场景下，需要参见全部章节完成转换工作。
* To HMS API场景下，只需要参见[开发准备](#section1680817974518)、[gradle配置文件](#section11710153784519)、[地图样式功能setMapStyle()](#section1645569546)。若使用了废弃接口，还需参见[部分废弃接口替代方案](#section1373884910515)。
* 使用工具转换完成后，需要同步工程，重新加载依赖，确保新引入的依赖下载完成。

### 开发准备

* 您若需要应用支持Map Kit，必须先完成[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-sdk-config-agc-0000001061560289)中的以下步骤：
  1. AppGallery Connect配置
  2. 集成HMS Core SDK
  3. 配置混淆脚本
  4. 权限申请
* 您若需要应用支持Map.getMylocaiton()、Map.setOnMyLocationChangeListener()等已不推荐使用方法，可以使用Location Kit对应方法替代，请参见Location的[API文档](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/overview-0000001051066102)以及[部分废弃接口替代方案](#section1373884910515)的示例代码。

### gradle配置文件

* 在Add HMS API场景或者To HMS API的场景中，module中的gradle文件里的defaultConfig{}配置，需要确保minSdkVerison的版本大于等于19，targetSdkVerison的版本大于等于29，compileSdkVersion的版本大于等于29，buildTooslVerison的版本大于等于 '29.0.2'。

  ```screen
  compileSdkVersion 29
  buildToolsVersion '29.0.2'
  defaultConfig {
  minSdkVersion 19
  targetSdkVersion 29
  }
  ```


* module中gradle文件引入androidx.appcompat:appcompat依赖。

  ```screen
  implementation 'androidx.appcompat:appcompat:1.1.0'
  implementation 'androidx.recyclerview:recyclerview:1.1.0'
  ```

* 确保初始实例化SupportMapFragment的Activity继承的AppCompatActivity为adnroidx.appcompat:appcompat包中的。

  ```screen
  public class CameraDemoActivity extends androidx.appcompat.app.AppCompatActivity
  ```

* Add HMS API场景中，module中gradle文件引入的google的base和basement插件的版本需大于等于17.1.0。

  ```screen
  implementation 'com.google.android.gms:play-services-base:17.1.0'
  implementation 'com.google.android.gms:play-services-basement:17.1.0'
  ```

* 在android配置项中增加JDK 1.8依赖。

  ```screen
  compileOptions {sourceCompatibility JavaVersion.VERSION_1_8    targetCompatibility JavaVersion.VERSION_1_8}
  ```

### switch-case到if-else转化

工具转化完成后，某些使用switch-case选择语句会出现"case expressions must be constant expression"，switch中case必须为常量异常。此类方法需要转化成if-else形式，以此方式解决switch异常问题。

原代码示例：

```screen
switch(reason) {
    //REASON_GESTURE:手势
    caseOnCameraMoveStartedListener.REASON_GESTURE:
        currPolylineOptions.color(Color.BLUE);
        reasonText = "GESTURE";
        break;
    //REASON_API_ANIMATION:api动画
    caseOnCameraMoveStartedListener.REASON_API_ANIMATION:
        currPolylineOptions.color(Color.RED);
        reasonText = "API_ANIMATION";
        break;
    //REASON_DEVELOPER_ANIMATION:开发者动画
    caseOnCameraMoveStartedListener.REASON_DEVELOPER_ANIMATION:
        currPolylineOptions.color(Color.GREEN);
        reasonText = "DEVELOPER_ANIMATION";
        break;
}
```

修改后代码示例：

```screen
if(OnCameraMoveStartedListener.getREASON_GESTURE() == reason) {
    this.currPolylineOptions.color(Color.*BLUE*);
    reasonText = "GESTURE";
} else if(OnCameraMoveStartedListener.getREASON_API_ANIMATION() == reason) {
    this.currPolylineOptions.color(Color.*RED*);
    reasonText = "API_ANIMATION";
} else if(OnCameraMoveStartedListener.getREASON_DEVELOPER_ANIMATION() == reason) {
    this.currPolylineOptions.color(Color.*GREEN*);
    reasonText = "DEVELOPER_ANIMATION";
} else{
    reasonText = "UNKNOWN_REASON";
}
```

## fragment

工具Add HMS API转换完成后，对于使用fragment展示的activity，我们提供配置ClassLoader（简单，仅需导入资源和修改配置文件）和手写代码（复杂，手工转换工作量大）两种手工转换方式来实现兼容Google API和HMS。

目前ClassLoader方案暂时不支持用户工程使用插件化或者热修复框架，不支持用户自定义ClassLoader，若您的应用存在上述情况，请使用手写代码方案。

更多关于ClassLoader方案的原理介绍，请参见[XClassLoader方案基本原理介绍](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/appendix-0000001050061063#section5205143711162)。

### 手写代码方式

1. 修改layout资源文件。

   Add HMS API场景下，Google API和HMS需要使用独立的layout资源文件，在各自的资源文件中<fragment/>class路径不同。

   ```screen
   <fragment
   android:id="@+id/map"
   android:layout_width="match_parent"
   android:layout_height="match_parent"
   class="com.huawei.hms.maps.SupportMapFragment"/>
   ```

   Google API layout资源文件中Fragment定义参考：

   ```screen
   <fragment
   android:id="@+id/map"
   android:layout_width="match_parent"
   android:layout_height="match_parent"
   class="com.google.android.gms.maps.SupportMapFragment"/>
   ```

   资源文件参考：
   * basic_demo：原始layout资源文件。
   * basic_demo_hms：HMS的layout资源文件。

## fragment的特殊场景（OnMapAndViewReadyListener）

Marker等部分Demo实现了OnMapAndViewReadyListener.OnGlobalLayoutAndMapReadyListener接口。其使用的Fragment支持Add HMS API场景的转换，在OnMapAndViewReadyListener类中进行，修改参考如下。

* 构造函数修改。构造函数中mapFragment的参数类型要从SupportMapFragment类型转换成父类Fragment。

  ```screen
  publicOnMapAndViewReadyListener(
           Fragment mapFragment, OnGlobalLayoutAndMapReadyListener devCallback) {}
  ```

* OnMapAndViewReadyListener兼容Google API和HMS示例代码如下：

  ```screen
  public classOnMapAndViewReadyListener implementsOnGlobalLayoutListener, OnMapReadyCallback {
      /**
  * A listener that needs to wait for both the GoogleMap and the View to be initialized.
  */
  public interfaceOnGlobalLayoutAndMapReadyListener {
          voidonMapReady(ExtensionMap googleMap);
      }
      private finalView mapView;
      private finalOnGlobalLayoutAndMapReadyListener devCallback;
      private booleanisViewReady;
      private booleanisMapReady;
      privateExtensionMap googleMap;
      publicOnMapAndViewReadyListener(
          Fragment mapFragment, OnGlobalLayoutAndMapReadyListener devCallback) {
              //hms处理
  if(org.xms.g.utils.GlobalEnvSetting.isHms()) {
                  com.huawei.hms.maps.SupportMapFragment hMapFragment = (com.huawei.hms.maps.SupportMapFragment) mapFragment;
                  mapView= mapFragment.getView();
                  this.devCallback= devCallback;
                  registerListeners();
               // GoogleMap. Note if the GoogleMap is already ready it will still fire the callback later.
  hMapFragment.getMapAsync(this.getHInstanceOnMapReadyCallback());
              } else{
               //gms处理
  com.google.android.gms.maps.SupportMapFragment gMapFragment = (com.google.android.gms.maps.SupportMapFragment) mapFragment;
              mapView= mapFragment.getView();
               this.devCallback= devCallback;
                  registerListeners();
               // GoogleMap. Note if the GoogleMap is already ready it will still fire the callback later.
  gMapFragment.getMapAsync(this.getGInstanceOnMapReadyCallback());
              }
          }
      private voidregisterListeners() {
          isViewReady= false;
          isMapReady= false;
          googleMap= null;
          // View layout.
  if((mapView.getWidth() != 0) && (mapView.getHeight() != 0)) {
              // View has already completed layout.
  isViewReady= true;
          } else{
              // Map has not undergone layout, register a View observer.
  mapView.getViewTreeObserver().addOnGlobalLayoutListener(this);
          }
      }
      @Override
      public voidonMapReady(ExtensionMap googleMap) {
          // NOTE: The GoogleMap API specifies the listener is removed just prior to invocation.
  this.googleMap= googleMap;
          isMapReady= true;
          fireCallbackIfReady();
      }
      @SuppressWarnings("deprecation")  // We use the new method when supported
  @SuppressLint("NewApi")  // We check which build version we are using.
  @Override
      public voidonGlobalLayout() {
          // Remove our listener.
  if(Build.VERSION.*SDK_INT*< Build.VERSION_CODES.*JELLY_BEAN*) {
              mapView.getViewTreeObserver().removeGlobalOnLayoutListener(this);
          } else{
              mapView.getViewTreeObserver().removeOnGlobalLayoutListener(this);
          }
          isViewReady= true;
          fireCallbackIfReady();
      }
      private voidfireCallbackIfReady() {
          if(isViewReady&& isMapReady) {
              devCallback.onMapReady(googleMap);
          }
      }
  }
  ```

## streetViewPanoramaFragment

Add HMS API场景下，streeViewPanoramaFragment相对[fragment](#section7696125884610)的fragment在调用方式上略微有些不同，但基本思想都是根据系统类型做if-else处理。具体参考如下。

activity中onCreate修改示例。

原代码示例：

```screen
protected voidonCreate(finalBundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.street_view_panorama_basic_demo);
    SupportStreetViewPanoramaFragment streetViewPanoramaFragment =
             (SupportStreetViewPanoramaFragment)
                     getSupportFragmentManager().findFragmentById(R.id.streetviewpanorama);
//设置一个回调对象，该对象将在GoogleMap实例准备好使用时被触发
    streetViewPanoramaFragment.getStreetViewPanoramaAsync(
        newOnStreetViewPanoramaReadyCallback() {
//当街景全景图准备好使用时调用
            @Override
            public voidonStreetViewPanoramaReady(StreetViewPanorama panorama) {
                // Only set the panorama to SYDNEY on startup (when no panoramas have been
// loaded which is when the savedInstanceState is null).
if(savedInstanceState == null) {
                    panorama.setPosition(SYDNEY);
                }
            }
        });
}
```

### HuaweiMap.setOnMyLocationListener()

此接口可以使用Location Kit中的[FusedLocationProviderClient.requestLocationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/fusedlocationproviderclient-0000001050746169#ZH-CN_TOPIC_0000001050746169__section1210118391289)([LocationRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationrequest-0000001050986189) request, [LocationCallback](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationcallback-0000001050706140) callback, Looper looper)方法替代。接口描述请参见[FusedLocationProviderClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/fusedlocationproviderclient-0000001050746169)。

To HMS API示例代码：

```screen

* this is an Example
* using location kit requestLocationUpdates(Request,LocationCallback,Looper) ,replace HuaweiMap.setOnMyLocationChangeListener()

private void setOnMyLocationChangeListener(){

    com.huawei.hms.location.LocationRequest request = new  com.huawei.hms.location.LocationRequest();
//设置位置更新的时间（单位为毫秒）
    request.setInterval(2000);
//调用[requestLocationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References-V5/fusedlocationproviderclient-0000001050746169-V5#ZH-CN_TOPIC_0000001050746169__section1210118391289)()进行持续定位
    LocationServices
           .getFusedLocationProviderClient(this).requestLocationUpdates(request, new LocationCallback() {
        @Override
        public void onLocationResult(  com.huawei.hms.location.LocationResult locationResult) {
            if (locationResult != null) {
//处理位置回调结果
                List<Location> locations = locationResult.getLocations();
                if (!locations.isEmpty()) {
                    for (Location location : locations) {
                        Log.i(TAG,
                                "onLocationResult location[Longitude,Latitude,Accuracy]:"
                                        + location.getLongitude() + "," + location.getLatitude() + ","
                                        + location.getAccuracy());
                    }
                }
            }
        }
        @Override
        public void onLocationAvailability(LocationAvailability locationAvailability) {
            if (locationAvailability != null) {
//定位是否可用
                boolean flag = locationAvailability.isLocationAvailable();
                Log.i(TAG, "onLocationAvailability isLocationAvailable:" + flag);
            }
        }
    }, android.os.Looper.myLooper()).addOnSuccessListener(new OnSuccessListener<Void>() {
        @Override
        public void onSuccess(Void param0) {
            Log.d(TAG,"onSuccess.....");
        }
    });
}
```
