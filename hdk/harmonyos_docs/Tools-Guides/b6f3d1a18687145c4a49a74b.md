# Shader查看器

Shader查看器是基于Resource Inspector下的功能，该功能支持查看rdc文件的Shader信息。点击主菜单"Window > > "Resource Inspector"，打开"Resource Inspector"，在窗口右侧Resource List中点击选中对应的Shader，然后点击"View Contents"弹出反汇编Shader界面。如下图。
