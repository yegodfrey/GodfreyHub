# 如何抓取使用GL program binary的应用程序？

Frame Profiler不支持GL program binary抓取，如果应用程序使用GL program binary，抓取到的帧将不包含使用这些GL program binary渲染的几何体。建议在不使用GL program binary的情况下运行应用程序，使用特殊的应用程序版本或在运行应用程序之前清除磁盘上的program binary文件，工具检测GL program binary的使用情况，并在这种情况下显示相应的警告。

如果带有编译着色器程序的应用程序缓存在抓取之前不为空，则设备屏幕上可能会显示以下消息："Failed to capture GL program binary data. Please clear the application cache and restart it. Please follow the documentation."。表明应用程序继续使用缓存的或预编译的二进制数据。尝试清除应用程序的User data 和 Cache 。
