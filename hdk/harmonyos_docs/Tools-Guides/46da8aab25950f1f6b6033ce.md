# 导入&导出帧文件

## 导出帧文件

1. 在非抓取状态下，选中截取的帧文件，鼠标右击选择"Save"选项进行导出帧文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/PYtueBzgRqSM0ZeMqSOsxw/zh-cn_image_0000001186791712.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=6B556B87ADBBE6BD9F79588C987F46139CCBA8EE31E95CCC1E11EA04DE8BB0F8)

2. 选择保存目录，自动生成文件名，也可进行编辑，点击保存，即可将截取的帧文件保存到本地。

## 导入帧文件

1. 在非抓取状态下，先与对应的移动设备连接。
2. 在主菜单中选择"File > Open Capture"进入文件路径，选择需要打开的帧文件。
3. 打开选中的帧文件，并打开"Texture Viewer"窗口。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/yVZklhHrR92p3zi89x2rUw/zh-cn_image_0000001232272891.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=2FA7B64CDB6680DF4BDC09354A6880AA479BA21F751B852BAC7210FCDEEA4C0B)
