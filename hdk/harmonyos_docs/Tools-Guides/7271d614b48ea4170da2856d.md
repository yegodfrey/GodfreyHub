# 网格查看器

网格查看器主要用于查看顶点Shader(VS) 位置坐标的数据，以及在不同阶段可视化表示VS Input、VS Output等位置坐标数据。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/A9o51-zxTKC0yJuY0z8HMA/zh-cn_image_0000001186646632.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=7111444A3BE7596400E8EC57E7C655A026F1FFC121AD1DF19FD7D15BCD9B54E6)

* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/M-sEnWyATt-WoYohKJ0tUQ/zh-cn_image_0000001186813944.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E80E2454D7FD0EA0FC013D0E38B1CC21A3541CB3CA8CD0DD9A8204F4B3409A4)：同步视图按钮，每个顶点都有一个显示网格数据的显示器，其格式来自管道着色器输入或输出的相关阶段，或顶点输入属性。可以选择同步视图按钮，并指定一个将保持一致的偏移量，以便在不同的事件之间移动时可以看到同一行。
* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/EIRVxal0REi61vm6ECcvoA/zh-cn_image_0000001186973928.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2020C76FB04CB3C6B26F3F67F7122ADDB2922E431519E257F2987A73E9B6E7A)：重置按钮，点击此按钮，重置照相机到其默认位置。对于"VS In"，此功能将重置为距对象一定半径的一个圆球。对于"VS Out"，此设置将重置为从投影眼睛观看的视图。
* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/vIDXzExwQEC7ZrA1ze-HOQ/zh-cn_image_0000001186652482.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=809A47A0632F9FA450338D8386CA04529115707C5F6E4C1A5FD17AF5166CE2DA)：自动适应按钮，点击此按钮将适合的摄像头轴线对齐边界框，自动适应照相机的网格坐标数据。
* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/mYQ9PI1SQh2zaoTOsz25UA/zh-cn_image_0000001232092091.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=38353A8B6025CCA7FB5BF6802BD6F65E978EBE399DAA02D8FE1D2B42B12BF326)：设置按钮，点击该按钮，手动配置顶点管道使用的投影。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/dzPzXWocRr642V_b5E4MgQ/zh-cn_image_0000001050701478.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=F2DA7EF5644B2327494A34D13880244409149697D69873B7D48D3101DD7744FD)


* Solid Shading："Solid Colour"仅将每个三角形显示为纯色，"Flat Shaded"将基于三角形法线执行基本的平面照明计算，以更好地了解网格的拓扑，"Secondary"显示选定的辅助网格元素。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fe/v3/VcMuxCjYTdaZFhHbmwK95g/zh-cn_image_0000001186812400.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=A1AAD5771E2FE1A9F9DB656C810EBE8646AFCF54D6C627CB9E562DBB399FE7B0)
* Show：投影后的输出通常是"VS Out"，也可能是"GS/DS Out"，显示输出时，在网格视图上方的下拉菜单中，选择显示"This draw"、"Previous instances"、"All instances"或"Whole pass"，缩小或扩展显示的网格输出。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/CWIlzBi5Squpm7NCjyerYw/zh-cn_image_0000001050981525.png?HW-CC-KV=V1&HW-CC-Date=20260909T144429Z&HW-CC-Expire=31536000000&HW-CC-Sign=5D55272DCEB370CF0B59FF8B0EF55C67922E6C1A690684FFC276C1EA6739210A)
