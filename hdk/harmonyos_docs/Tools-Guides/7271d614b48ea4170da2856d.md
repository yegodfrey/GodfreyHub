# 网格查看器

网格查看器主要用于查看顶点Shader(VS) 位置坐标的数据，以及在不同阶段可视化表示VS Input、VS Output等位置坐标数据。

![](https://media:201778750901431406)

* ![](https://media:201778750901459407)：同步视图按钮，每个顶点都有一个显示网格数据的显示器，其格式来自管道着色器输入或输出的相关阶段，或顶点输入属性。可以选择同步视图按钮，并指定一个将保持一致的偏移量，以便在不同的事件之间移动时可以看到同一行。
* ![](https://media:201778750901485408)：重置按钮，点击此按钮，重置照相机到其默认位置。对于"VS In"，此功能将重置为距对象一定半径的一个圆球。对于"VS Out"，此设置将重置为从投影眼睛观看的视图。
* ![](https://media:201778750901511409)：自动适应按钮，点击此按钮将适合的摄像头轴线对齐边界框，自动适应照相机的网格坐标数据。
* ![](https://media:201778750901550410)：设置按钮，点击该按钮，手动配置顶点管道使用的投影。

  ![](https://media:201778750901580411)

<!-- -->

* Solid Shading："Solid Colour"仅将每个三角形显示为纯色，"Flat Shaded"将基于三角形法线执行基本的平面照明计算，以更好地了解网格的拓扑，"Secondary"显示选定的辅助网格元素。

  ![](https://media:201778750901608412)
* Show：投影后的输出通常是"VS Out"，也可能是"GS/DS Out"，显示输出时，在网格视图上方的下拉菜单中，选择显示"This draw"、"Previous instances"、"All instances"或"Whole pass"，缩小或扩展显示的网格输出。

![](https://media:201778750901634413)
