# 网格查看器

网格查看器主要用于查看顶点Shader(VS) 位置坐标的数据，以及在不同阶段可视化表示VS Input、VS Output等位置坐标数据。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/A9o51-zxTKC0yJuY0z8HMA/zh-cn_image_0000001186646632.png?HW-CC-KV=V1&HW-CC-Date=20261008T154323Z&HW-CC-Expire=31536000000&HW-CC-Sign=B6B4E963DFC879B48712F8BC3321E963D4BEF6B5FE5F439057B9106AB3252017)

* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/M-sEnWyATt-WoYohKJ0tUQ/zh-cn_image_0000001186813944.png?HW-CC-KV=V1&HW-CC-Date=20261008T154323Z&HW-CC-Expire=31536000000&HW-CC-Sign=02BCA2BA59A8352CC16802B224D572A01E058AB88880E5D100CB116D2F8C9FE9)：同步视图按钮，每个顶点都有一个显示网格数据的显示器，其格式来自管道着色器输入或输出的相关阶段，或顶点输入属性。可以选择同步视图按钮，并指定一个将保持一致的偏移量，以便在不同的事件之间移动时可以看到同一行。
* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/EIRVxal0REi61vm6ECcvoA/zh-cn_image_0000001186973928.png?HW-CC-KV=V1&HW-CC-Date=20261008T154323Z&HW-CC-Expire=31536000000&HW-CC-Sign=E6FB88083A6264F58B5C2F5F7C661C60B175FDA2F84E8A9AA6043C935E193196)：重置按钮，点击此按钮，重置照相机到其默认位置。对于"VS In"，此功能将重置为距对象一定半径的一个圆球。对于"VS Out"，此设置将重置为从投影眼睛观看的视图。
* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/vIDXzExwQEC7ZrA1ze-HOQ/zh-cn_image_0000001186652482.png?HW-CC-KV=V1&HW-CC-Date=20261008T154323Z&HW-CC-Expire=31536000000&HW-CC-Sign=D470558A387A71E30EB1B0A9A86C30BEBF3EDA43119B1EA3CC10804F79265115)：自动适应按钮，点击此按钮将适合的摄像头轴线对齐边界框，自动适应照相机的网格坐标数据。
* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/mYQ9PI1SQh2zaoTOsz25UA/zh-cn_image_0000001232092091.png?HW-CC-KV=V1&HW-CC-Date=20261008T154323Z&HW-CC-Expire=31536000000&HW-CC-Sign=4FDEDA803F819C24B17CC1102B8FD8DC08F5335762F7B0DAC8A5835B7A88137A)：设置按钮，点击该按钮，手动配置顶点管道使用的投影。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/dzPzXWocRr642V_b5E4MgQ/zh-cn_image_0000001050701478.png?HW-CC-KV=V1&HW-CC-Date=20261008T154323Z&HW-CC-Expire=31536000000&HW-CC-Sign=DFA26835194168198063E2E97BB2C6ABF59274B516BE45B3F7E6B617573C4CDF)


* Solid Shading："Solid Colour"仅将每个三角形显示为纯色，"Flat Shaded"将基于三角形法线执行基本的平面照明计算，以更好地了解网格的拓扑，"Secondary"显示选定的辅助网格元素。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fe/v3/VcMuxCjYTdaZFhHbmwK95g/zh-cn_image_0000001186812400.png?HW-CC-KV=V1&HW-CC-Date=20261008T154323Z&HW-CC-Expire=31536000000&HW-CC-Sign=CB96A48A722C1784FBE6912C619A854CAACCE03BAFC9771A357239791B9575DE)
* Show：投影后的输出通常是"VS Out"，也可能是"GS/DS Out"，显示输出时，在网格视图上方的下拉菜单中，选择显示"This draw"、"Previous instances"、"All instances"或"Whole pass"，缩小或扩展显示的网格输出。
