# 菜单介绍

|**菜单栏**|**常用功能**|描述|
|:------|:-------------------------|:------------------------------------------------------------------------------|
|File|Launch Application|调出连接手机应用的窗口。|
|File|Attach to Running Instance|连接已经运行的手机。|
|File|Open Capture|选择回放的文件。|
|File|Open Capture with Options|选择回放的文件并可修改回放的参数。|
|File|Save Capture|保存当前回放的rdc文件。|
|File|Save Capture As|保存当前回放的rdc文件。|
|File|Close Capture|关闭当前回放的文件。|
|File|Import From|导入其它形式的文件。|
|File|Export As|将当前回放的文件以其它形式导出。|
|File|Recent Captures|显示关于文件的历史记录。|
|File|Recent Captures Settings|关于文件的历史记录相关设置。|
|Window|Save Layout|保存当前窗口布局。|
|Window|Load Layout|打开之前保存的窗口布局。|
|Window|Launch Application|调出连接手机应用的窗口。|
|Window|Event Browser|显示回放API信息的窗口。|
|Window|Texture Viewer|显示回放图片信息的窗口。|
|Window|Pipeline State|显示管线详细信息的窗口。|
|Window|API Inspector|查看帧的API参数信息的窗口。|
|Window|Mesh Viewer|网络查看器的窗口。|
|Window|Errors and Warnings|显示错误和报警的窗口。|
|Window|Timeline|事件时间轴的窗口。|
|Window|Statistics Viewer|显示应用信息以及draw call等数据的窗口。|
|Window|Performance Counter Viewer|显示捕获GPU计数器的结果。|
|Window|Resource Inspector|显示帧中API的完整列表以及查看对象之间的父子关系的窗口。|
|Window|Capture Comments|回放文件添加注释的窗口。|
|Window|Diagnostic Log|显示Log信息的窗口。|
|Window|Dependent Viewer|显示资源依赖图的窗口。|
|Tools|Resolve Symbols|解析符号。|
|Tools|Recompress Capture|重新压缩帧文件。|
|Tools|Start Replay Loop|该功能可以将当前回放的界面单独提取为一个窗口，结合Event Browser功能可以拆分出单Draw的绘制图片。需要连接手机，且在回放状态，否则该功能不生效。|
|Tools|Settings|该功能为工具的设置，如背景色、字体大小等。|
|Tools|Manage Remote Servers|显示管理设备的窗口。|
|Help|View Documentation|打开Graphics Profiler的用户手册。|
|Help|View Diagnostic Log File|打开日志。|
|Help|Build/Release Downloads|打开Graphics Profiler的下载页面。|
|Help|About|查看当前版本的信息。|

## Mac设备与Windows设备上工具界面区别

Mac设备下运行工具，"Preferences"对应Windows中的"Tools->Settings"；"About FrameProfiler"对应Windows下的"Help->About"。
