# 未激活状态无法执行抓取如何操作？

当启动应用成功后，如果点击"Capture Frame(s) Immediately"不生效，查看Status内的API的情况如果是Not Presenting状态，这时是无法抓取的。

解决办法：

1. 如果设备处于Inactive window状态，则可以在工具界面点击"Cycle Active Window"尝试来激活窗口。
2. 在设备切换用户界面使状态转换到可抓取的状态。
