# 1. 服务内容

［问题一］多语言服务提供什么服务？

多语言服务主要为出海应用提供多语言规范性和禁忌的检查，满足海外用户的使用习惯和文化诉求。多语言规范性检查提供四种工具检查：   
1. 字串资源存储规范性检查：检查字串资源是否按照字串资源存放规范存放，避免在不同的安卓版本上出现资源调用的问题而导致未翻译和调用出错的问题；   
2. 字串未翻译检查：检查版本中针对选定的语言是否存在缺失翻译的问题；   
3. 拼写检查：低级错误对于本地用户来讲是很难接受的，拼写检查工具可以快速识别存在风险的字串；   
4. 禁忌检查：根据选定的区域和语言检查是否存在禁忌图片和禁忌用词，减少和本地文化冲突的风险。

# 2. 服务获取

［问题一］多语言服务从哪里获取？

多语言服务在云测试提供了相关服务。在云测，可以通过"开发者联盟官网" > "开发" > "开发工具" > "多语言服务"，而后找到多语言服务。
