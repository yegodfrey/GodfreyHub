# 事件时间轴

选择主菜单"Window > Timeline"，打开事件时间轴，如下图所示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/02/v3/Ig6ylHwRQWmajRwv3xjj-Q/zh-cn_image_0000002601550869.png?HW-CC-KV=V1&HW-CC-Date=20260909T183401Z&HW-CC-Expire=31536000000&HW-CC-Sign=E12F28E99EE1BBB4D7C8E94F77675FC47403FEB01D6D1894C610E77D3AE8A39A)

|编号|功能说明|
|:-|:----------------------------------------------|
|1|EID对应的EventBrowser里的EID，鼠标滚轮滚动对Timeline进行放大和缩小。|
|2|点击三角标时，会做出标记，同时打开的EventBrowser会跳转到对应的EID上。|
