# 事件时间轴

选择主菜单"Window \> Timeline"，打开事件时间轴，如下图所示。

![](https://media:201778750903225446)  

|编号|功能说明|
|:-|:----------------------------------------------|
|1|EID对应的EventBrowser里的EID，鼠标滚轮滚动对Timeline进行放大和缩小。|
|2|点击三角标时，会做出标记，同时打开的EventBrowser会跳转到对应的EID上。|
