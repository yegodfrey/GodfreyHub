# 骨骼制作规范

动作库使用BVH格式文件作为动作文件，并且采用MotionBuilder输出BVH动作文件。

为了可以正常使用动作库，我们做如下规定：

1. 所有骨骼在世界坐标系中，必须+Y轴垂直于ZX面向上，+Z轴垂直于XY面向前。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150019.25990343871088388719703353260911:50520704031946:2800:BA095CEA7B9A84E7EBAEF30A88C174980B75A44E277A95CC2231DE813954CD0C.jpg?needInitFileName=true?needInitFileName=true "点击放大")

2. 所有骨骼的数量（72根骨骼，这里包括了末端骨骼）和名称必须和以下模板保持一致。

   |Hip|所有骨骼的根节点|
   |Pelvis|盆骨|
   |Spine|腰椎|
   |Spine1|胸椎|
   |Neck|脖子|
   |Head|头|
   |RightEye|右眼，连接到Head|
   |RightEyeEnd|右眼末端骨骼，与右眼骨骼连接|
   |LeftEye|左眼，连接到Head|
   |LeftEyeEnd|左眼末端骨骼，与左眼骨骼连接|
   |Jaw|下颌，连接到Head|
