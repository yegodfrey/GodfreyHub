# 配置录制

1. 打开Graphics Profiler，点击侧边栏的"Record new trace"，进入录制页面。
2. 设备允许进行USB调试，在列表中找到设备并选中。

   <br />

   ![](https://media:201778750891588203)

   <br />

3. 设备成功配对后，可配置菜单和录制trace进程。

   <br />

   ![](https://media:201778750891615204)  
   HarmonyOS 5.0及以上版本设备不支持Ring buffer模式。

   ![](https://media:201778750891646205)

   点击"Recording mode"后，有以下三种模式选项
   * Stop when full模式：捕获数据直到内存缓冲区填满时停止。一旦缓冲区已满或达到指定的时间限制，录制将自动停止。支持[延迟trace抓取](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/deferred-trace-recording-0000002272036033)。
   * Ring buffer模式：当缓冲区写满时，新数据开始覆盖旧数据，没有时间限制，录制要手动停止。
   * Long trace模式：允许捕获大量数据，但会产生一些I/O开销。内存缓冲区充当中间存储，来自它的数据定期被刷新到磁盘。当达到最大文件大小或达到指定的时间限制时，录制自动停止。

   以上三种模式都可以手动停止录制。

   <br />

4. 打开需要跟踪的监测项。此菜单仅显示Graphics Profiler支持的，并且在连接设备上可用的监测项，具体监测项说明参考[Trace数据源](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/cpu-load-0000001932087413)。可以在类别名称的下方查看每个类别中启用了多少个监测项。
5. 在"Application to profile"页面选择"System tracing"或者选择需要分析的应用程序，点击"Start Recording"按钮开始抓取信息。

   <br />

   ![](https://media:201778750891693206)

   <br />

#### 应用拉起功能优化

"Application to profile"页面在7.1.1.203及以前版本，如果用户选择需要分析的应用程序，在抓取trace时，必定重启该应用，这种方式会导致游戏场景丢失。7.2.0.300及以后版本支持应用程序不重启，也可以正常抓取trace。

当同时出现以下两种情况时，工具会弹窗提示选择是否重启应用，如下图所示。

* 选中GPU API Events监测项。
* 在抓取trace之前，选中的应用已经正在运行。

![](https://media:201778750891725207)
