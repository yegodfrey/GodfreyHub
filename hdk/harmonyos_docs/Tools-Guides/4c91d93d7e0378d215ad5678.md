# 动画制作流程

在HUAWEI Reality Studio中您可以通过点击和拖拽，轻松制作动画。

1. 调出动画时间轴。

   目前可以制作的动画包括：
   * 位移
   * 缩放
   * 旋转
   * 显隐
   * 透明度（组节点没有此动画）

   下面以位移动画为例，其他动画制作方式类似。

   点击左侧场景树中的"动画列表"，此时在屏幕右侧的动画组中，点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.50901935695296162309191778000184:50520704031946:2800:D299661BEC525CFF44EB2B366F27357DC3B780A827810BA823D84D4E6149EB63.png?needInitFileName=true?needInitFileName=true)，视图中下部出现时间轴，如下图所示：

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.37082321315790449860875972135461:50520704031946:2800:26673B30FAEF612C9B9E8674BC8A5FCBC7FF771D389C21EADBC7A7EE3F2B06A1.png?needInitFileName=true?needInitFileName=true "点击放大")  
   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.53122508918479307933211959140678:50520704031946:2800:80FADF0079F6E2AB5B0B7B867DC22BF5EAF4DDADC450990B49460244DE9821E5.png?needInitFileName=true?needInitFileName=true)  
   时间轴中的各自对应：
   * 位置：3D属性中的位置。
   * 旋转：3D属性中的旋转。
   * 缩放：3D属性中的缩放。
   * 显隐：3D属性中的显示。
   * 透明度（组节点没有此动画）：3D属性材质参数中的透明度。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.56661936747223311818464404061657:50520704031946:2800:1264E6A7E313712CCC607522CA475F989796ADE3A5811C85BC546116E04FE6A9.png?needInitFileName=true?needInitFileName=true "点击放大")
2. 添加3D节点。

   点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.36104559804020081094903497160847:50520704031946:2800:DE811766F3D23298DEAB1615245B1029027672EC76377CE2E05FC125964CDEBC.png?needInitFileName=true?needInitFileName=true)，可以将多个3D节点加入到时间轴里。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.79284781322197711077172110219795:50520704031946:2800:85E5C2DD2D5B8D1FD379E70F15C6B42D1E9CE07BFCBCD811C42DF84A4C232DF1.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 添加关键帧。

   在时间轴上，将红色时间轴拖动到关键帧的时间点，如1秒，也可以在"当前时间"输入框输入时间。拖动节点的控制轴，移动节点位置。例如，将节点向上移动。在"位置"线上，选点击择轨道，然后点击轨道首部的虚心的圆，打上关键帧后该圆会变成实心状态。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.80233580007593832692236033779232:50520704031946:2800:19250FB3A198A2BAA899D0FCA9BF05F24CDB59C24CD9AECF70012EE31ADA4396.png?needInitFileName=true?needInitFileName=true "点击放大")  
   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.08763365051023072417015798667944:50520704031946:2800:5706B4B70936BEC5F283123C33638C00064E24CF85735F27B1935CA71A0EFA7D.png?needInitFileName=true?needInitFileName=true)  
   删除关键帧：当圆为实心时，再次点击首部关键帧按钮，可以删除当前关键帧。

   删除节点：点击要删除的节点的任意轨道，点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.80160868861028927259935495841285:50520704031946:2800:4F8C51767F2C993C206EADF50802C8B645CF783795C203B0DBF4B6788153021B.png?needInitFileName=true?needInitFileName=true)，即可将该节点从轨道删除。
4. 保存动画。

   点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.64084390024690225300491548321493:50520704031946:2800:4856E42ABD5F2432CCDE3C273297B1D02F61A1F5BFE63866084DE6993B0E303E.png?needInitFileName=true?needInitFileName=true "点击放大")保存动画，将其命名为"Displacement"，如下图所示：
