# Device Frequencies

这些计数器显示所有可用硬件组件的频率，如CPU、GPU、DDR、NPU等。

在HarmonyOS上，这些计数器从sys/devfreq/\*/curfreq系统文件中轮询。  
![](https://media:201778750890941189)  
HarmonyOS 5.0及以上版本设备不支持该监控项。

![](https://media:201778750890977190)  
![](https://media:201778750891022191)  
从该数据源捕获的某些频率计数器（如CPU、GPU和DDR）可能会与使用其他数据源捕获的相应计数器重复。

![](https://media:201778750891050192)
