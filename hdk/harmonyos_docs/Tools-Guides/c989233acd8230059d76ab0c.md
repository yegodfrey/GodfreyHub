# Device Frequencies

这些计数器显示所有可用硬件组件的频率，如CPU、GPU、DDR、NPU等。

在HarmonyOS上，这些计数器从sys/devfreq/*/curfreq系统文件中轮询。
> 说明
>
> HarmonyOS 5.0及以上版本设备不支持该监控项。
