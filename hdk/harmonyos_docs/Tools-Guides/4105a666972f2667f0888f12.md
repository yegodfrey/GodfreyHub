# OCR模板标注

HMS Toolkit提供OCR（Optical Character Recognition，光学字符识别）模板标注的能力，您可以使用HMS Toolkit创建图片识别的模板。例如，您可以创建一张身份证的图片识别模板，可以应用在政府事务、金融保险、社交等场景，通过身份证图片自动识别和提取身份信息，减少人工录入的成本和输入错误的风险。创建模板的具体操作如下，创建完成后可参见[HUAWEI HiAI Engine开发指南](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/templateocr-development-guide-0000001054319016)用于App进行调用。

1. 在Coding Assistant中，选择"Other \> Image Label"。
2. 点击"Create Template"，开始创建OCR模板。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174818.36673916592869249825330974123558:50001231000000:2800:CBA109F2B8305D748F77382E88FE2C4435EFBF41889999F0870B97D89FCB2735.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 输入模板的基本信息，包括输入模板名称、模板描述和选择图片，然后点击"Create Template"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174818.45388054219486151837322238908345:50001231000000:2800:E70D679518A9E768561F65517488210C7C1EFE17264EADB4A84517CF2E4EEF85.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 在弹出的对话框中，如果点击"Ok"，需要输入模板的版本描述信息，如果点击"Cancel"，则工具会自动生成默认版本信息。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174818.94763918902416214869353693490802:50001231000000:2800:4C97199184E36C30911EF8BBDF93A86098E389055B39E9F2AD479E9A1F83F5D2.png?needInitFileName=true?needInitFileName=true "点击放大")
5. 基本信息设置完成后，进入到OCR模板的具体设置界面，如下图所示。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174818.34625841659575707107593584607588:50001231000000:2800:9D37406B1A79FA6C9B30C8F92AC9F618F4FBF4D17D29A8B40C0CDB50D6242F30.png?needInitFileName=true?needInitFileName=true "点击放大")

   ①：图片编辑区域，使用鼠标选择需要标记的模板区域，用于下一步的参考区域和标识区域标记，可通过鼠标快速选择。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174818.40424291518313018549651330064346:50001231000000:2800:498270C84177D325B7AA1605FF56C6CCB61AA2FCD0F609A4D46B31D4F5C21359.gif?needInitFileName=true?needInitFileName=true "点击放大")

   ②：图片标识区域，在编辑区域选取的区域中，设置图片参考标识并设置属性标签。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174818.17049583333478458149378587878039:50001231000000:2800:CB8962BC52B0513CD7269AAD8EAA8D40C1E42B3434601C7A6AE863EBAEB9DE54.gif?needInitFileName=true?needInitFileName=true "点击放大")

   ③：图标识别区域，在编辑区域选取的区域中，设置图片识别区域并设置属性标签。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174818.00521608515409396810259770783368:50001231000000:2800:D0DDF96E8D0C086E45DA186FE4A09D68E46BD2807D4FDB5977810BE21CFAC848.gif?needInitFileName=true?needInitFileName=true "点击放大")

   ④：可以对图片进行局部放大，以便更好的选取图片关键区域。

   ⑤：图片局部放大之后，点击该按钮可以返回放大前的默认编辑界面。

   ⑥：删除一个Object，与⑨中的Object管理界面的删除功能相同。

   ⑦：一键清除编辑区域的所有Object。

   ⑧：将OCR模板导出，生成一个JSON文件，用于App进行调用。

   ⑨：编辑区域的Object管理，可以删除Object，也可以对②和③中的Object对应的属性进行修改。
