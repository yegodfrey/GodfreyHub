# 导出纹理

纹理导出可以保存当前纹理为多种格式，包括".dds"、".exr"、".png"、".jpg"、".bmp"等。

1. 点击Actions工具栏中"Open Texture List"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/0NpLvZ7MQxWOH1pAJkvMFw/zh-cn_image_0000001058805462.png?HW-CC-KV=V1&HW-CC-Date=20260909T182129Z&HW-CC-Expire=31536000000&HW-CC-Sign=25D3F7D6569611E6ECFF7A57C407FA2EAF143694990F349837899E0666BAC89A)，打开抓取过程中存在的所有纹理的纹理列表，展示所有纹理。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/bLmKNB8oSRWLgUBM2vOkfg/zh-cn_image_0000001649086958.png?HW-CC-KV=V1&HW-CC-Date=20260909T182129Z&HW-CC-Expire=31536000000&HW-CC-Sign=8DAC2B1857054002D72625DDF74E1C65885C90F88A527CA8F42A31146CAE2651)

2. 选择"Texture List"中想要保存的纹理，点击Actions工具栏中"Save selected Texture"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/8hKdlqdfSrSHSgcMwH01UQ/zh-cn_image_0000001058645567.png?HW-CC-KV=V1&HW-CC-Date=20260909T182129Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4391B09F5C644279AFFB655F1EA3C940CD7EB21B2A955B2DC4B6E64344B9AD0)。

   1. 选择想要的导出格式。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/qYnclq9SStSGSO9Hd0levw/zh-cn_image_0000001058923651.png?HW-CC-KV=V1&HW-CC-Date=20260909T182129Z&HW-CC-Expire=31536000000&HW-CC-Sign=899C76F7A9F1E81536D7B1F7C77B4F5E685B6195C8B2F8B2E3FDF0388E2B2331)

   2. 确定存放路径。
   3. 点击"Save"保存纹理。
