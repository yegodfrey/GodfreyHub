# 导出纹理

纹理导出可以保存当前纹理为多种格式，包括".dds"、".exr"、".png"、".jpg"、".bmp"等。

1. 点击Actions工具栏中"Open Texture List"![](https://media:201778750897335319)，打开抓取过程中存在的所有纹理的纹理列表，展示所有纹理。

   <br />

   ![](https://media:201778750897474320)

   <br />

2. 选择"Texture List"中想要保存的纹理，点击Actions工具栏中"Save selected Texture"![](https://media:201778750897500321)。

   <br />

   1. 选择想要的导出格式。 ![](https://media:201778750897531322)

   2. 确定存放路径。
   3. 点击"Save"保存纹理。

   <br />
