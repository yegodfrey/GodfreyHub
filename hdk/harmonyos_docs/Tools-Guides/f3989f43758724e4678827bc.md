# 导出纹理

纹理导出可以保存当前纹理为多种格式，包括".dds"、".exr"、".png"、".jpg"、".bmp"等。

1. 点击Actions工具栏中"Open Texture List"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/0NpLvZ7MQxWOH1pAJkvMFw/zh-cn_image_0000001058805462.png?HW-CC-KV=V1&HW-CC-Date=20261008T192301Z&HW-CC-Expire=31536000000&HW-CC-Sign=D452113402D4327A8E09C274FE08FA31D7877CE07C5164FDE01FF89473B5B43D)，打开抓取过程中存在的所有纹理的纹理列表，展示所有纹理。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/bLmKNB8oSRWLgUBM2vOkfg/zh-cn_image_0000001649086958.png?HW-CC-KV=V1&HW-CC-Date=20261008T192301Z&HW-CC-Expire=31536000000&HW-CC-Sign=7BFA633CBD1667CCBF3D301A62671952CE10BDFE5F5317F3D01DE7848B5FCE56)

2. 选择"Texture List"中想要保存的纹理，点击Actions工具栏中"Save selected Texture"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/8hKdlqdfSrSHSgcMwH01UQ/zh-cn_image_0000001058645567.png?HW-CC-KV=V1&HW-CC-Date=20261008T192301Z&HW-CC-Expire=31536000000&HW-CC-Sign=D71016B73BA2FD9A1A9755CA44487FC0EE636C9EACBD3DA9AE1CB9E728CF4E21)。

   1. 选择想要的导出格式。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/qYnclq9SStSGSO9Hd0levw/zh-cn_image_0000001058923651.png?HW-CC-KV=V1&HW-CC-Date=20261008T192301Z&HW-CC-Expire=31536000000&HW-CC-Sign=6C47697AC6647FA3757B6921888282B38B56C6F7CAC779C4AA52EB9903D980F9)

   2. 确定存放路径。
   3. 点击"Save"保存纹理。
