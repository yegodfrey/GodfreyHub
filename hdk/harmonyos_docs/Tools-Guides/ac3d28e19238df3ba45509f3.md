# AI Create

AI Create功能为您提供图像分类和文本分类的迁移学习能力，通过深度的机器学习和模型训练，可以很好的帮助用户对图像、文本进行精确的识别。AI Create训练框架采用MindSpore，推理框架采用MindSpore Lite。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174816.75309681705026527005958854717376:50001231000000:2800:C87ED9E4375A1A89341BF6788037577AA8EF4C7D4EB93F161640753506DE1A43.png?needInitFileName=true?needInitFileName=true)  
AI Create功能当前只支持Windows系统。

#### 图像分类

图像分类是利用迁移学习算法在具有良好泛化能力的基座分类模型的基础上，针对特定领域（如汽车、动物等）百张级数据进行分钟级的学习训练，自动生成图像分类识别的新模型，该生成的新模型可以自动识别图像所属的类别。HMS Toolkit还提供一键生成模型调用Demo示例工程的功能，方便您在应用程序中快速验证和调用图像分类AI模型。  

#### 资源准备

使用图像分类迁移学习能力前，您需要按照要求准备用于训练的图像资源。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174816.57661648471511637947067625226162:50001231000000:2800:322DBA1963BC4A2F69202FF7316459C44C4DC7F36E2E1C881A7126951B9E51F9.png?needInitFileName=true?needInitFileName=true "点击放大")

图像资源需要满足以下条件：

* 训练图像需要按照图像进行分类，在每个分类的目录下，放入合适的清晰图像。  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174816.89416036920854421542900643990607:50001231000000:2800:FC4D2642C8993AE7D1E3D34EE8ABDEB68D4227D4ACE7E33A99A5964971BB88A0.png?needInitFileName=true?needInitFileName=true)  
  图像存储路径和分类名称只能包含：字母、数字、下划线和中文，不能包括空格、特殊字符等符号。
* 图像分类数量约束：至少需要有2个以上的图像类别，上限为1000类。
* 每一类图像要求，训练数据：图像下限为10张。
* 图像格式只能是：bmp、jpg、jpeg、png和gif。  

#### 模型训练

1. 在Coding Assistant中，选择"AI \> AI Create \> Image"。
2. 设置图像训练模型的操作类型和模型部署位置，然后点击"Confirm"。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174816.62588372208684461195490155895411:50001231000000:2800:393B2B08E56247063F38FC383524FE66E202ED705232482D8B42477F672A657E.png?needInitFileName=true?needInitFileName=true)  
   点击"Confirm"后，HMS Toolkit会检测训练环境是否已准备完毕，如果环境未就绪，工具会自动进行下载和配置，请耐心等待。
   * Operation type：操作类型，固定选择"New Model"。
   * Model Deployment Location：模型部署位置，固定选择"Deployment Cloud"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174816.60394888319268249098521748583945:50001231000000:2800:F8E315111D7ED213C73C436E0F06581F00BC2249285E3195E71DC0124E391D0F.png?needInitFileName=true?needInitFileName=true "点击放大")

#### 文本分类

文本分类是利用迁移学习算法在具有良好泛化能力的基座分类模型的基础上，针对特定领域（如体育、娱乐、教育等）的文本数据进行分钟级的学习训练，自动生成文本分类识别的新模型。该生成的新模型可以自动识别文字所属的类别。HMS Toolkit还提供一键生成模型调用的Demo示例工程的功能，方便您在应用程序中快速验证和调用文本分类新模型。  

#### 资源准备

使用文本分类迁移学习能力前，您需要按照要求准备用于训练的文本资源。文本资源可以是JSON文件，也可以是文件夹分类的txt文件。

* JSON格式训练文本：JSON文本格式为\[{"label": " ", "text": " "},{"label": " ", "text": " "}\]。
* txt格式训练文本：按照文档的类别进行分类，每一类使用txt文档存放文本内容。  
文本资源训练文件除上述2种格式要求外，还需要满足以下条件：

* 文本存储路径和分类名称只能包含：字母、数字、下划线和中文，不能包括空格、特殊字符等符号。
* 文本类别数量约束：至少需要有2个以上的文本类别。
* 文本数量的约束：每一类别的文本数量至少20条，数量越多新模型的精度越高。
* 文本大小的约束：文本资源不能超过10 MB。
* 文本的编码格式：只能为UTF-8。

#### 弱监督目标检测

弱监督目标检测是利用迁移学习算法在具有良好泛化能力的基座分类模型的基础上，针对易于识别的特定分类的图片进行分钟级的学习训练，自动分析图片的特征，从而自动从识别模型中提取出图片中的目标物体，并在图片中标识出来。HMS Toolkit还提供一键生成模型调用Demo示例工程的功能，方便您在应用程序中快速验证和调用图像分类AI模型。  

#### 资源准备

使用图像分类迁移学习能力前，您需要按照要求准备用于训练的图像资源。

* 训练图像需要按照图像进行分类，在每个分类的目录下，放入合适的清晰图像。  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174817.63463046299905026497335899314775:50001231000000:2800:C647FEE0F04BEEC12DA3CD727E4DC84FEF509577099E37E33F85FFB6D86F5AC3.png?needInitFileName=true?needInitFileName=true)  
  图像存储路径和分类名称只能包含：字母、数字、下划线和中文，不能包括空格、特殊字符等符号。
* 训练数据集中，不同类别下的样本数据，建议图片的背景风格保持一致。
* 图像分类数量约束：至少需要有2个以上的图像类别。
* 每一类图像至少需要20张，多于200张训练效果更佳。
* 图像格式只能是bmp、jpg、jpeg、png和gif。
