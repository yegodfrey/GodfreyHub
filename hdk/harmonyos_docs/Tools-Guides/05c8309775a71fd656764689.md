# Low memory killer

HarmonyOS框架会在需要内存时杀死应用程序和服务，特别是后台应用程序，为新打开的应用程序腾出空间，这就是Low-memory Kills（LMK）。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/zj5_av1vRm-4nK_WrvSx3w/zh-cn_image_0000002567533726.png?HW-CC-KV=V1&HW-CC-Date=20261008T182439Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD721A90898AB2589F553DC265EDE249693083D6BE6F474B1E09F3DCC132D033)
> 说明
>
> HarmonyOS 5.0及以上版本设备不支持该监控项。

## UI

较新的用户空间LMK以计数器的形式出现在lmkd轨道下的UI中。计数器的值是被杀死进程的PID（在下面的示例中，PID=27985）。
