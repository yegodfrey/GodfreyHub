# 打开项目

1. 进入打开项目界面。
   * 打开华为快应用IDE，在欢迎界面导航选择"打开项目"。
   * 进入主界面，菜单选择"文件 > 打开项目"。

2. 选择项目（快应用项目、卡片项目）存放的路径，点击"确定"。
