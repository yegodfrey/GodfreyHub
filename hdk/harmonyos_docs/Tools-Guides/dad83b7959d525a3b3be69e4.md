# 工具安装

* 在windows操作系统的设备上安装工具

1. 下载[GraphicsProfiler安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/toolkit-download-0000001050819189)。
2. 在Windows10或者Windows11 64位操作系统的设备上，运行"graphicsprofiler_setup.exe"，推荐用管理员权限安装。
3. 双击"graphicsprofiler_setup.exe"，单击"I Agree"。

   <br />

   ![](https://media:201778750886873116)

   <br />

4. 选定安装位置，选择安装目录后，单击"Install"。

   <br />

   ![](https://media:201778750886900117)

   <br />

5. 等待安装，安装完毕后，单击"Finish"。

   <br />

   ![](https://media:201778750886928118)

   <br />

<br />

* 在macOS操作系统的设备上安装工具

1. 下载[GraphicsProfiler安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/toolkit-download-0000001050819189)。
2. 在macOS操作系统的设备上双击"GraphicsProfiler-7.xxx-Mac(ARM).dmg"

   <br />

   ![](https://media:201778750886952119 "点击放大")

   <br />

3. 然后双击"FrameProfiler.app"即可打开工具直接使用

   <br />

   ![](https://media:201778750886981120 "点击放大")

   ![](https://media:201778750887031121 "点击放大")

   <br />
