# 工具安装

* 在windows操作系统的设备上安装工具

1. 下载[GraphicsProfiler安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/toolkit-download-0000001050819189)。
2. 在Windows10或者Windows11 64位操作系统的设备上，运行"graphicsprofiler_setup.exe"，推荐用管理员权限安装。
3. 双击"graphicsprofiler_setup.exe"，单击"I Agree"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0e/v3/5JZ0NHzVQdC99TVCPPT5vQ/zh-cn_image_0000001659512920.png?HW-CC-KV=V1&HW-CC-Date=20261008T171337Z&HW-CC-Expire=31536000000&HW-CC-Sign=D8B520D3DD5A75205850D4EDE3AB8FE783BE11939E30BAC7C3DD108E307DD76E)

4. 选定安装位置，选择安装目录后，单击"Install"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e/v3/SOpDJTvMSXmRvKxnvBtH9A/zh-cn_image_0000001659672724.png?HW-CC-KV=V1&HW-CC-Date=20261008T171337Z&HW-CC-Expire=31536000000&HW-CC-Sign=2458B09C4447F2727CF59D4B96066DF095718CE010A34EF13B5D172722106456)

5. 等待安装，安装完毕后，单击"Finish"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/ViRaB__6TyOieETUhxht2A/zh-cn_image_0000001707912797.png?HW-CC-KV=V1&HW-CC-Date=20261008T171337Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2006136069FC0CE8EC957D4DAA6C77292B97622AB9F744D246E7738E631E727)

* 在macOS操作系统的设备上安装工具

1. 下载[GraphicsProfiler安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/toolkit-download-0000001050819189)。
2. 在macOS操作系统的设备上双击"GraphicsProfiler-7.xxx-Mac(ARM).dmg"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/Ske32LnuSEKzN3z9I3ra_w/zh-cn_image_0000002496506393.png?HW-CC-KV=V1&HW-CC-Date=20261008T171337Z&HW-CC-Expire=31536000000&HW-CC-Sign=9A3C0556D4CA6F4530DCCC97B32F4F7FC7E7CB7F30E0CFD1C224599F55A03F4D "点击放大")

3. 然后双击"FrameProfiler.app"即可打开工具直接使用
