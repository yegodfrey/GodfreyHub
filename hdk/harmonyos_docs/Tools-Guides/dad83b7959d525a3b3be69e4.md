# 工具安装

* 在windows操作系统的设备上安装工具

1. 下载[GraphicsProfiler安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/toolkit-download-0000001050819189)。
2. 在Windows10或者Windows11 64位操作系统的设备上，运行"graphicsprofiler_setup.exe"，推荐用管理员权限安装。
3. 双击"graphicsprofiler_setup.exe"，单击"I Agree"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0e/v3/5JZ0NHzVQdC99TVCPPT5vQ/zh-cn_image_0000001659512920.png?HW-CC-KV=V1&HW-CC-Date=20260909T161517Z&HW-CC-Expire=31536000000&HW-CC-Sign=68BBDF2A4CD8126B18B84E8D6EF3CFD8B23811452A2D5D60C06F5010AC60D3FC)

4. 选定安装位置，选择安装目录后，单击"Install"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e/v3/SOpDJTvMSXmRvKxnvBtH9A/zh-cn_image_0000001659672724.png?HW-CC-KV=V1&HW-CC-Date=20260909T161517Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C62DB523C3F4E0A04475CE038CE640085D77E5E0ABB6AAB960AA479EC92D07C)

5. 等待安装，安装完毕后，单击"Finish"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/ViRaB__6TyOieETUhxht2A/zh-cn_image_0000001707912797.png?HW-CC-KV=V1&HW-CC-Date=20260909T161517Z&HW-CC-Expire=31536000000&HW-CC-Sign=B11E1C269F177B6DAE40212FFEF5261B33D1076AE70F99D130B35978273932BB)

* 在macOS操作系统的设备上安装工具

1. 下载[GraphicsProfiler安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/toolkit-download-0000001050819189)。
2. 在macOS操作系统的设备上双击"GraphicsProfiler-7.xxx-Mac(ARM).dmg"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/Ske32LnuSEKzN3z9I3ra_w/zh-cn_image_0000002496506393.png?HW-CC-KV=V1&HW-CC-Date=20260909T161517Z&HW-CC-Expire=31536000000&HW-CC-Sign=50FE06B68A62849B53632FB1F7C4ADE7E93B5D17A0127E57EF0CEDC676E87816 "点击放大")

3. 然后双击"FrameProfiler.app"即可打开工具直接使用
