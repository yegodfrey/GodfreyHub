# 1. 概述

多语言服务会分期开发全球化能力评估、多语言规范性检查、禁忌检查、全球化特性评估等服务。旨在帮助开发者提前评估和识别自身应用存在的问题，以便及早发现并解决问题，以符合海外用户对语言、文化、习惯的诉求。

本期会开放的内容包含资源文件规范性、翻译完整性、拼写错误、本地禁忌检查，帮助应用快速发现问题并提前修改，以保证应用在安装到端测时能正确的显示资源，减少出现文化禁忌的风险，帮助应用获得本地用户的认可度。

# 2. 功能特点

## 2.1 多语言规范性检查

检查资源文件规范性、翻译完整性、拼写错误等问题。

## 2.2 禁忌检查

检查资源文件中不符合各地文化要求的禁忌内容。
