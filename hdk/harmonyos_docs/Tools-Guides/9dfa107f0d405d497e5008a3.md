# Vulkan shader debug

Vulkan shader debug (vulkan-spirv) 功能仅支持vulkan关键帧debug分析。不支持光线追踪、网格、几何体、细分曲面、集群剔除和子通道着色器。仅支持片段着色器、计算着色器和顶点着色器。

## **Debug Vertex Shader** **：**

1. 点击"File > Open Capture"，打开rdc文件，在Event Browser中选择某一个绘制索引。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/tabrVshrSI6abwdp5ZifXQ/zh-cn_image_0000002601409343.png?HW-CC-KV=V1&HW-CC-Date=20261008T164923Z&HW-CC-Expire=31536000000&HW-CC-Sign=B81AA4AD3D131E7A2EBDF624FE04A2C41FA577EDBEB9C9F5D69DB74FF89AF128)

2. 点击"Window > Mesh Viewer"进入网格查看器，选择某一顶点，单击鼠标右键点击"Debug this Vertex"，调试着色器模块视图会自动打开。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/vg-sXptiRmyZNIUYGq0mgg/zh-cn_image_0000002570706944.png?HW-CC-KV=V1&HW-CC-Date=20261008T164923Z&HW-CC-Expire=31536000000&HW-CC-Sign=A1E1BDE86D462B238AB445635137C075F64AEE086716F707CB10D9DF0E3361FA)

## **Debug Fragment Shader** **：**

1. 点击"File > Open Capture"，打开rdc文件，在Event Browser中选择某一个绘制索引。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/WTUCix_2TpGt999OdSlZDA/zh-cn_image_0000002570889822.png?HW-CC-KV=V1&HW-CC-Date=20261008T164923Z&HW-CC-Expire=31536000000&HW-CC-Sign=1D105FDD98B4AD95C2DFE207A7AB3F5CFC3D5D87F437367FE4149D2C7A896118)

2. 点击"Window > Texture Viewer"打开纹理查看器，鼠标右键点击选择一个像素，在界面右下角点击"Debug"，默认情况下，按下"Debug"按钮将调试最后一次通过深度测试的调用，着色器模块的调试视图会自动打开。如果像素点包含来自不同图元（重绘）的贡献，并且你想选择某个特定的调用进行调试，请先点击"History"按钮来选择你要调试的调用。请注意，如果所选的绘制调用对像素没有贡献，则将打开像素历史记录视图，而不是着色器调试视图。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/HQqjwHhFTyuAsKELQHjgqg/zh-cn_image_0000002477413416.png?HW-CC-KV=V1&HW-CC-Date=20261008T164923Z&HW-CC-Expire=31536000000&HW-CC-Sign=77DFA6DC2E3A0B1223FDC53B43D44C06253BB26A09501652B3767A4BE360C9E8)

## **Debug Compute Shader** **：**

1. 点击"File > Open Capture"，打开rdc文件，在Event Browser的搜索框中搜索"dispatch"，选择某一个调度。
2. 点击"Window > Pipeline State"进入Pipeline State界面，点击"CS"，再点击"Debug"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/KmCb7HSCSUWBRoQtJikg4g/zh-cn_image_0000002509333367.png?HW-CC-KV=V1&HW-CC-Date=20261008T164923Z&HW-CC-Expire=31536000000&HW-CC-Sign=BC3FB128EDA4C3D2C4A5000079CDF6FD497F9197F76D19CB5FED723280128232)

3. 输入组ID和线程ID，然后点击"Debug"，调试着色器模块视图会自动打开。
