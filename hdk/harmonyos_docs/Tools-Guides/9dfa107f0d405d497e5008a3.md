# Vulkan shader debug

Vulkan shader debug (vulkan-spirv) 功能仅支持vulkan关键帧debug分析。不支持光线追踪、网格、几何体、细分曲面、集群剔除和子通道着色器。仅支持片段着色器、计算着色器和顶点着色器。

## **Debug Vertex Shader** **：**

1. 点击"File > Open Capture"，打开rdc文件，在Event Browser中选择某一个绘制索引。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/tabrVshrSI6abwdp5ZifXQ/zh-cn_image_0000002601409343.png?HW-CC-KV=V1&HW-CC-Date=20260909T155027Z&HW-CC-Expire=31536000000&HW-CC-Sign=832C2E2FCB2C1029677D833454A2B9F8FD1ECCB8B9C2C8C88A74EA87C7436A95)

2. 点击"Window > Mesh Viewer"进入网格查看器，选择某一顶点，单击鼠标右键点击"Debug this Vertex"，调试着色器模块视图会自动打开。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/vg-sXptiRmyZNIUYGq0mgg/zh-cn_image_0000002570706944.png?HW-CC-KV=V1&HW-CC-Date=20260909T155027Z&HW-CC-Expire=31536000000&HW-CC-Sign=B28946EFDC149CC7EF8C3492195CDE249EB1EA21AA8D7FD4C7467980A1242DC7)

## **Debug Fragment Shader** **：**

1. 点击"File > Open Capture"，打开rdc文件，在Event Browser中选择某一个绘制索引。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/WTUCix_2TpGt999OdSlZDA/zh-cn_image_0000002570889822.png?HW-CC-KV=V1&HW-CC-Date=20260909T155027Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D8D09664E9B2E6E40B20072FACDC56763CF0708D4436F969B0A486D3BFA93BA)

2. 点击"Window > Texture Viewer"打开纹理查看器，鼠标右键点击选择一个像素，在界面右下角点击"Debug"，默认情况下，按下"Debug"按钮将调试最后一次通过深度测试的调用，着色器模块的调试视图会自动打开。如果像素点包含来自不同图元（重绘）的贡献，并且你想选择某个特定的调用进行调试，请先点击"History"按钮来选择你要调试的调用。请注意，如果所选的绘制调用对像素没有贡献，则将打开像素历史记录视图，而不是着色器调试视图。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/HQqjwHhFTyuAsKELQHjgqg/zh-cn_image_0000002477413416.png?HW-CC-KV=V1&HW-CC-Date=20260909T155027Z&HW-CC-Expire=31536000000&HW-CC-Sign=55761A3CD5E47CE67189A099974EBFE998A7820E930260FAA4992BB5B8F96E66)

## **Debug Compute Shader** **：**

1. 点击"File > Open Capture"，打开rdc文件，在Event Browser的搜索框中搜索"dispatch"，选择某一个调度。
2. 点击"Window > Pipeline State"进入Pipeline State界面，点击"CS"，再点击"Debug"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/KmCb7HSCSUWBRoQtJikg4g/zh-cn_image_0000002509333367.png?HW-CC-KV=V1&HW-CC-Date=20260909T155027Z&HW-CC-Expire=31536000000&HW-CC-Sign=F30BBB10AB611C819A0CF4B228ADD4DAD11A6E385CDE74CFCAA670DAD89215F0)

3. 输入组ID和线程ID，然后点击"Debug"，调试着色器模块视图会自动打开。
