# Awareness Kit手工转换指导书

## 开发准备

您若需要应用支持Awareness Kit，必须完成接入准备，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101)。

## BeaconStateResult类中的接口

Google API BeaconStateResult类中getBeaconState()接口HMS不再支持：

|类型|BeaconStateResult类中的Google API|
|:-|:---------------------------------|
|方法|BeaconStateResult.getBeaconState()|

您需要使用HMS中的[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-beaconstatusresponse-0000001050166011)中的[getBeaconStatus](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-beaconstatusresponse-0000001050166011#section41551858114)()接口来代替。

|Google API|To HMS API|Add HMS API|
|:---------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------|
|BeaconStateResult.getBeaconState()|[BeaconStatusResponse.getBeaconStatus](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-beaconstatusresponse-0000001050166011#section41551858114)()|BeaconStateResponse.getBeaconState()|

BeaconStateResult类中getBeaconState()接口Google API实现方法：

```screen
GoogleApiClient mGoogleApiClient;
mGoogleApiClient = new GoogleApiClient.Builder(this).addApi(Awareness.API).build();
mGoogleApiClient.connect();
// 发起请求
Awareness.SnapshotApi.getBeaconState(mGoogleApiClient, BEACON_TYPE_FILTERS).setResultCallback(new ResultCallback<BeaconStateResult>() {
    @Override
    public void onResult(@NonNull BeaconStateResult beaconStateResult) {
        // 得到结果
        if (beaconStateResult.getStatus().isSuccess()) {
            BeaconState beaconState = beaconStateResult.getBeaconState();
             }
        }
});
```

BeaconStateResult类中getBeaconState()接口To HMS API方法：

```screen
// 发起请求
Awareness.getCaptureClient(this).getBeaconStatus(BEACON_TYPE_FILTERS).addOnSuccessListener(new OnSuccessListener<BeaconStatusResponse>() {
    @Override
    public void onSuccess(BeaconStatusResponse beaconStatusResponse) {
        // 得到结果
        BeaconStatus beaconStatus = beaconStatusResponse.getBeaconStatus();
        }
});
```

BeaconStateResult类中getBeaconState()接口Add HMS API方法：

```screen
Awareness.getSnapshotClient(this).getBeaconState(BEACON_TYPE_FILTERS).addOnSuccessListener(new OnSuccessListener<BeaconStateResponse>() {
        @Override
    public void onSuccess(BeaconStateResponse param0) {

        }

```

## DetectedActivityResult/DetectedActivityResponse类中的接口

您需要使用HMS中的[BehaviorResponse](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-behaviorresponse-0000001050164058)中的[getBehaviorStatus](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-behaviorresponse-0000001050164058#section15190213174)()接口来代替。

|Google API|To HMS API|Add HMS API|

DetectedActivityResult类中getActivityRecognitionResult()接口Google API实现方法：

```screen
GoogleApiClient mGoogleApiClient;
mGoogleApiClient = new GoogleApiClient.Builder(this).addApi(Awareness.API).build();
mGoogleApiClient.connect();
// 发起请求
Awareness.SnapshotApi.getDetectedActivity(mGoogleApiClient).setResultCallback(new ResultCallback<DetectedActivityResult>() {
    @Override
    public void onResult(@NonNull DetectedActivityResult detectedActivityResult) {
        // 得到结果
        if (detectedActivityResult.getStatus().isSuccess()) {
            ActivityRecognitionResult activityRecognitionResult = detectedActivityResult.getActivityRecognitionResult();
            long time = activityRecognitionResult.getTime();
            long elapsedTime = activityRecognitionResult.getElapsedRealtimeMillis();
            DetectedActivity detectedActivity = activityRecognitionResult.getMostProbableActivity();
            List<DetectedActivity> detectedActivities = activityRecognitionResult.getProbableActivities();
       }
   }
});
```

DetectedActivityResult类中getActivityRecognitionResult()接口To HMS API方法：

```screen
// 发起请求
Awareness.getCaptureClient(this).getBehavior().addOnSuccessListener(new OnSuccessListener<BehaviorResponse>() {
    @Override
    public void onSuccess(BehaviorResponse behaviorResponse) {
        // 得到结果

        long elapsedTime = behaviorStatus.getElapsedRealtimeMillis();
        DetectedBehavior detectedBehavior = behaviorStatus.getMostLikelyBehavior();
```
