# 绑定事件

3D节点和2D控件都可以增加事件，在预览界面点击包含事件的节点会触发事件，事件包括2D事件和3D事件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.71914846303716712302420095623150:50520704031946:2800:37003AAAAE60DD104687A1E5154A5BBDF79DF5E03927809A5FC4A4162B872F3B.png?needInitFileName=true?needInitFileName=true "点击放大")
> 说明
>
> 组节点不能增加事件。

## 2D事件

2D事件包含动作和部件，类型包含：

* 播放：播放视频控件。
* 暂停：暂停播放视频控件。
* 显示：显示不可见的2D控件。
* 隐藏：隐藏2D控件。
* 运行：让其他控件执行Tab控件子标签绑定的2D和3D事件。

选择部件，即将当前控件和被绑定控件按选择的类型绑定起来。

点击按钮显示文本面板设置方法：

1. 新建按钮控件和文本面板。
2. 将文本面板的"可见性"选框取消勾选。
3. 点击按钮属性的2D事件属性栏的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.60532979657245117567024929569285:50520704031946:2800:AEA250858379EA6CF06C38FB9EE1259CD032B9DAC40A8773472F299700F4AEB5.png?needInitFileName=true?needInitFileName=true)。
4. "动作"下拉框选择"显示"，"部件"下拉框选择"文本面板"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.79957171474939905684800466078389:50520704031946:2800:0BA45B20FEBC3DBC65F153D4AE8112DEB6F4AC88365185C188C616B1A592C84D.png?needInitFileName=true?needInitFileName=true)

> 说明
>
> 2D事件中5种类型只针对2D控件，播放和暂停只对视频控件有效。运行可以让其他控件执行Tab控件子标签绑定的2D和3D事件。

## 3D事件

3D事件即动画事件，让动画以设定好的规则播放。点击3D事件属性框右上角![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.09164682413989156269824039068158:50520704031946:2800:3A5F794799E082D47DFA378DE0FA9DD23AE42CAB5D79CC13D3058251C977E921.png?needInitFileName=true?needInitFileName=true)可以将已有的动画增加进来，可以增加多个动画。动画的制作方法请参见[动画制作流程](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/animation-procedure-0000001050162760)。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.25262753034625455578804033956170:50520704031946:2800:733810E2A87D49DB673105BDB1E8BDE1E62B78EE7F46A55C8DABDDEFE3123139.png?needInitFileName=true?needInitFileName=true "点击放大")

|属性|说明|
|:---|:---------------------------------------------------------------------------------|
|交互类型|* 依次播放：指动画按照添加的先后顺序依次播放，每次需要点击才会播放下一个动画。 * 整体播放：同时播放列表中的所有动画。 * 顺序播放：依序播放列表中的所有动画。|
|动作|选择指定动画。|
|速度|速度为1即正常速度，为2即2倍速播放，依次类推，数值不能超过10。|
|延迟|延迟播放动画，数字为延迟的秒数，数值不能超过20。|
|顺序|* 顺序播放即从头到尾播放。 * 倒序播放即从尾到头播放。 * 间隔播放即奇数次触发事件，动画从头到尾播放；偶数次触发事件，从尾到头播放。|
|循环|勾选可以让动画循环播放。|
|重置|播放下一个动画时是否重置前面播放过的动画相关节点的位置、旋转、缩放、可见性和透明度状态为动画未播放时的状态。取消勾选可以保留前面播放过动画相关节点的状态。|

点击按钮播放动画设置方法：

1. 新建按钮控件。
2. 在按钮的动画列表属性中点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150016.65621108678725532125975169313092:50520704031946:2800:B3A300EB6916BA54DC884A6034687F4FEA60F22327D0A827AD68C79EBF742D9F.png?needInitFileName=true?needInitFileName=true)添加3D事件。
3. 在"动作"下拉框中选择想要使用的动画。
