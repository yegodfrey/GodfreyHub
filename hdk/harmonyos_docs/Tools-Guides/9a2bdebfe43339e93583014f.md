# Safety Detect手工转换指导书

#### 开发准备

您若需要应用支持Safety Detect，必须完成接入准备，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/config-agc-0000001050416303)。  

#### lookupUri(String var1, String var2, int... var3)

|Google API|HMS API|
|:-------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Task\<SafetyNetApi.SafeBrowsingResponse\> lookupUri(java.lang.String var1, java.lang.String var2, int... var3)|Task\<[UrlCheckResponse](https://developer.huawei.com/consumer/cn/doc/development/Security-References/urlcheckresponseapi-0000001050415407)\> [urlCheck](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section945817404417)(String uri, String appid, int... threatTypes)|

您需要在[urlCheck](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section945817404417)方法的第二个参数手动修改为开发者联盟申请的appid。[urlCheck](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section945817404417)方法参考：  

#### Add HMS API

在生成的类org.xms.g.safetynet.SafetyNetClient中添加如下代码提供路由：

```
public org.xms.g.tasks.Task<org.xms.g.safetynet.SafetyNetApi.SafeBrowsingResponse> lookupUri(
        java.lang.String param0, java.lang.String param1, int... param2) {
    com.google.android.gms.tasks.Task gReturn = null;
    com.huawei.hmf.tasks.Task hReturn = null;
    if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
        hReturn = ((com.huawei.hms.support.api.safetydetect.SafetyDetectClient)this.getHInstance())
            .urlCheck(param0, "appid", param2);
    } else {
        gReturn = ((com.google.android.gms.safetynet.SafetyNetClient)this.getGInstance())
            .lookupUri(param0, param1, param2);
    }
    return new org.xms.g.tasks.Task.XImpl(gReturn, hReturn);
}
```

#### To HMS API

1. 将Google API "lookupUri" 转换为 HMS API "[urlCheck](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section945817404417)"。
2. [urlCheck](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section945817404417)方法第二个参数需要修改为您申请的appid。
3. addOnSuccessListener(Activity, OnSuccessListener) 需要手动转换，使用HMS对应方法Task\<TResult\> addOnSuccessListener(OnSuccessListener\<TResult\> var1)，去掉第一个Activity参数。
4. addOnFailureListener(Activity, OnSuccessListener) 需要手动转换，使用HMS对应方法Task\<TResult\> addOnFailureListener(OnSuccessListener\<TResult\> var1)，去掉第一个Activity参数。
5. 需要在AndroidManifest.xml中配置appid。

示例如下：

```
SafetyNet.getClient(this).lookupUri(url,
    BuildConfig.API_KEY,
    com.google.android.gms.safetynet.SafeBrowsingThreat.TYPE_POTENTIALLY_HARMFUL_APPLICATION,
    com.google.android.gms.safetynet.SafeBrowsingThreat.TYPE_SOCIAL_ENGINEERING)
    .addOnSuccessListener(getActivity(), mSuccessListener)
    .addOnFailureListener(getActivity(), mFailureListener);
```

转换为：

```
SafetyDetect.getClient(getActivity()).urlCheck(url,
    "appid",
    com.huawei.hms.support.api.entity.safetydetect.UrlCheckThreat.MALWARE,//此类型URL被标记为包含潜在有害应用的页面的URL（篡改首页、网页挂马、恶意应用下载链接等）
    com.huawei.hms.support.api.entity.safetydetect.UrlCheckThreat.PHISHING)//此类型的URL被标记为钓鱼、欺诈网站
    .addOnSuccessListener(mSuccessListener)
    .addOnFailureListener(mFailureListener);
```

#### MaliciousAppsData

|Google API|HMS API|
|:---------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

|public final int apkCategory|public int [getApkCategory](https://developer.huawei.com/consumer/cn/doc/development/Security-References/maliciousappsdataapi-0000001050259892#section175432715814)()|

#### To HMS API

您需要使用[MaliciousAppsData](https://developer.huawei.com/consumer/cn/doc/development/Security-References/maliciousappsdataapi-0000001050259892)替换代码中所有的的HarmfulAppsData，执行以下四个步骤：

1. 首先需要import HMS的[MaliciousAppsData](https://developer.huawei.com/consumer/cn/doc/development/Security-References/maliciousappsdataapi-0000001050259892)，去掉HarmfulAppsData的import。

   ```
   import com.huawei.hms.support.api.entity.safetydetect.MaliciousAppsData;
   ```

2. 示例代码中HarmfulAppsData的：

   ```
   apkPackageName
   ```

   替换为[MaliciousAppsData](https://developer.huawei.com/consumer/cn/doc/development/Security-References/maliciousappsdataapi-0000001050259892)的：

   ```
   getApkPackageName()
   ```

   如下示例代码：

   ```
   Log.e(TAG,"  APK: " + harmfulApp.apkPackageName);
   ```

   替换为

   ```
   Log.e(TAG,"  APK: " + harmfulApp.getApkPackageName());
   ```

3. 将示例代码中HarmfulAppsData的：

   ```
   apkSha256 //byte[]
   ```

   替换为[MaliciousAppsData](https://developer.huawei.com/consumer/cn/doc/development/Security-References/maliciousappsdataapi-0000001050259892)的：

   ```
   getApkSha256() //String类型，返回Base64编码后的sha256值
   ```

   请您关注替换后的返回参数类型转换，根据业务逻辑进行对应的处理。

   如下示例代码：

   ```
    Log.e(TAG, "  SHA-256: " + harmfulApp.apkSha256);
   ```

   替换为：

   ```
   Log.e(TAG,"  SHA-256: " + Base64.encode(harmfulApp.getApkSha256()));
   ```

4. 将示例代码中HarmfulAppsData中的：

   ```
   apkCategory
   ```

   替换为[MaliciousAppsData](https://developer.huawei.com/consumer/cn/doc/development/Security-References/maliciousappsdataapi-0000001050259892)的:

   ```
   getApkCategory()
   ```

   如下示例代码：

   ```
   Log.e(TAG,"  Category: " + harmfulApp.apkCategory);
   ```

   替换为

   ```
   Log.e(TAG,"  Category: " + harmfulApp.getApkCategory());
   ```

#### Add HMS API

1. 使用hms的[userDetection](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section19175202210716)方法，在注册listener时，不要传递当前的activity，此处和Google API不同，您需要手动修改代码判断使用hms或gms场景，如下所示。

   如果您使用的gms方案不需要传递activity，可以不做该判断。

   ```
   if(GlobalEnvSetting.isHms()){
       client.verifyWithRecaptcha(SITE_KEY)
           .addOnSuccessListener(mSuccessListener)
           .addOnFailureListener(mFailureListener);
   }else{
       client.verifyWithRecaptcha(SITE_KEY)
           .addOnSuccessListener(getActivity(), mSuccessListener)
           .addOnFailureListener(getActivity(), mFailureListener);
   }
   ```

2. 在生成的类 org.xms.g.safetynet.SafetyNetClient中添加如下代码提供路由。

   ```
   public org.xms.g.tasks.Task<org.xms.g.safetynet.SafetyNetApi.RecaptchaTokenResponse> 
           verifyWithRecaptcha(java.lang.String param0) {
       com.google.android.gms.tasks.Task gReturn = null;
       com.huawei.hmf.tasks.Task hReturn = null;
       if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
           hReturn = ((com.huawei.hms.support.api.safetydetect.SafetyDetectClient)this.getHInstance())
               .userDetection("appid");
       } else {
           gReturn = ((com.google.android.gms.safetynet.SafetyNetClient)this.getGInstance())
               .verifyWithRecaptcha(param0);
       }
       return new org.xms.g.tasks.Task.XImpl(gReturn, hReturn);
   }
   ```

#### To HMS API

1. Google API "verifyWithRecaptcha" 转换为 HMS API "[userDetection](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section19175202210716)"。
2. [userDetection](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section19175202210716)方法的参数需要修改为您申请的appid。
3. addOnSuccessListener(Activity, OnSuccessListener) 需要手动转换，使用hms对应方法Task\<TResult\> addOnSuccessListener(OnSuccessListener\<TResult\> var1)，去掉第一个Activity参数。
4. addOnFailureListener(Activity, OnSuccessListener) 需要手动转换，使用hms对应方法Task\<TResult\> addOnFailureListener(OnSuccessListener\<TResult\> var1)，去掉第一个Activity参数。
5. 需要在AndroidManifest.xml中配置appid。

[虚假用户检测API](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/userdetect-0000001050154382)示例如下：

```
SafetyNet.getClient(this).verifyWithRecaptcha(SITE_KEY)
    .addOnSuccessListener(getActivity(), mSuccessListener)
    .addOnFailureListener(getActivity(), mFailureListener);
```

转换为：

```
SafetyDetect.getClient(getActivity()).userDetection("appid")
    .addOnSuccessListener(mSuccessListener)
    .addOnFailureListener(mFailureListener);
```

#### 后续步骤

代码经过Add HMS API或者To HMS API转换后，若使用HMS接口，进行二次认证时，均需要将谷歌服务器替换为您自己的App服务器。Add HMS API的情况需要您同时配置谷歌服务器和自己的App服务器，并根据是否使用HMS的情况做对应的判断。配置和使用您自行搭建的服务器进行二次认证的详细步骤请参见[虚假用户检测API](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/userdetect-0000001050154382)。
