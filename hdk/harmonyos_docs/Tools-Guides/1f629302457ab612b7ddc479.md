# Vulkan Nativebuffer

HardwareBuffer是Android操作系统提供的一种用于共享和传递图形和图像数据的高性能、低延迟的跨进程内存缓冲区，是一种底层的内存buffer对象，可在不同进程间共享，可映射到不同硬件系统，如GPU、传感器等。从构造函数可以看出，其可以指定format和usage，用来让底层选择最合适的实现。

NativeBuffer是HarmonyOS 5.0及以上版本系统专用的具备Hardwarebuffer类似特性的内存缓冲区。
