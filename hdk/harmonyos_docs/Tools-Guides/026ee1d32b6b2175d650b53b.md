# Power consumption

> 说明
>
> 仅支持马良 920 GPU设备上使用。HarmonyOS 6.1以上版本支持该功能。

Power consumption功能对数据进行整合分析，生成功耗拟合信息。

在Power Consumption功能下，有3个开关：CPU Power Consumption、GPU Power Consumption、DDR Power Consumption，用来抓取CPU、GPU、DDR的功耗拟合数据。
