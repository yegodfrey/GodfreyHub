# 一键式环境恢复

一键式环境恢复功能使用bat脚本实现，帮助快速恢复初始状态。

bat文件在[工具包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/toolkit-download-0000001050819189)的路径为："\\frame_profiler\\plugins\\dfxtools\\ClearToolsSetting.bat"，使用时双击bat文件即可。该特性支持多设备，在连接多设备时，需要手动输入设备号。  
![](https://media:201778750903172445)  
连接多设备时，不支持HarmonyOS 4.0及以下版本和HarmonyOS 5.0及以上版本 2种设备同时接入场景。
