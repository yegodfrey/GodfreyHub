# Extension工具

Coding Assistant还提供了系列化的extension工具，帮助您更加高效地开发、调试应用程序。Extension工具包括通用工具和Kit专项工具。  

#### 通用工具

#### Configuration Wizard

HMS Core Kit配置向导，具体可参见[Configuration Wizard](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/config-wizard-0000001050059098)。  

#### Cloud Debugging

云调试，具体可参见[Cloud Debugging](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/cloud-debugging-0000001051084360)。  

#### Error Codes

在工具栏中选择"HMS \> Coding Assistant"，选择Kit名称，点击工具栏中的"Error Codes"，进入错误码日志解析工具，您可以根据Logcat日志自动进行解析。在调试运行前，请确保"Auto Analysis"开关为打开状态。

#### Integrity Check

完整性检查工具。在调用HMS Core各Kit能力后，可以使用完整性检查工具检查环境是否就绪、接口是否被调用等。使用方法如下：

1. 进入完整性检查页面，有以下两种入口方式： 方式一：选择菜单栏中的"HMS \> Coding Assistant \> Integrity Check"。

   方式二：选择菜单栏中的"HMS \> Coding Assistant"，然后在Kit列表中点击需要进行完整性检查的Kit，在Kit卡片的工具栏中点击"Integrity Check"工具。
2. 选择团队名称、对应的工程模块、需要使用的Kit（入口方式一支持多选，建议每次不超过5个Kit）和证书类型，点击"Generate"生成SHA256证书指纹，然后点击"Next"。

#### Account Kit专项工具

#### ID Token Validity

ID Token Validity工具仅用于调试阶段验证华为帐号服务器向应用返回的ID Token的合法性。

用户使用华为帐号登录应用并进行授权，确认允许授权后，HUAWEI Account SDK会向应用返回ID Token信息，应用需要对返回的ID Token信息进行校验。校验方法如下：

1. 在Coding Assistant中调用Account Kit的"Sign in with a HUAWEI ID（ID Token）"，调用方法可以参见[Kit集成向导](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/coding-assistant-0000001050061057)。
2. 使用远程真机或者真机设备运行您的应用。
3. 在设备上打开应用，并使用华为帐号登录应用并进行授权。
4. 登录授权成功后，HMS Toolkit会自动打开"ID Token Validity"工具，并将返回的ID Token信息自动填充到工具中，点击"Start to verify"进行验证。

#### HuaweiIdAuthButton

HuaweiIdAuthButton工具用于在您的应用中快速添加一个华为风格的登录按钮，可以方便您快速地实现符合[华为帐号图标使用规范](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-specifications-0000001050048916)的登录按钮。

HuaweiIdAuthButton和一般的界面类一样，有两种使用方式，一种是在布局xml文件中进行声明，另外一种是在Java代码中创建HuaweiIdAuthButton类的实例，并动态添加到布局中，您可以根据自己的需要选择使用。使用方法如下：

1. 在Account Kit卡片的工具栏中，点击"HuaweiIdAuthButton"工具。
2. 您可以选择"Through the Layout XML File"和"Through Instance Creation with Java Code"两种方式进行添加。
   * Through the Layout XML File：输入您想要添加的登录图标的id，然后点击下拉框选择按钮图标的theme、color_policy、corner_radius。在您操作的过程中，下方的代码展示框内会自动生成对应的xml代码，同时UI example处会展示对应生成的华为帐号登录图标。您可以通过复制或者拖拽的方式将xml代码添加到您的layout文件中。添加完成后，您可以通过修改自定义参数，来调整按钮风格，具体可参见[通过布局xml文件使用](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/huaweiidauthbutton-0000001050179025#section12327542111)。
   * Through Instance Creation with Java Code：您可以通过点击下拉框选择登录按钮图标的theme、color_policy、corner_radius。同样，在您操作的过程中，下方的代码展示框内会自动生成对应的java代码，UI example处也会展示对应生成的华为帐号登录图标。您可以通过复制或者拖拽的方式将java代码添加到您的工程中。

#### Location Kit专项工具

Location Kit提供场景仿真工具（Scenario Simulation），可以为您模拟融合定位服务、活动识别服务、地理围栏服务和运动计步服务。  

#### Location

在Location Kit卡片的工具栏中，点击"Scenario Simulation"工具，再点击"Location"，选择对应场景模拟的卡片。

* 融合定位服务：在工具中模拟一个具体的位置点信息。
* 活动识别服务：在模拟工具中选择起点位置和终点位置，工具根据运动方式规划线路，并模拟规划路线的运动轨迹。
* 地理围栏服务：与活动识别相比，工具可以在起点或终点设置地理围栏半径。

其中调试设备可有多种选择，您可以选择本地真机、远程真机或模拟器。

当调试设备选择远程真机或模拟器时使用方法如下：

* Fused Location（融合定位服务） 在模拟工具中，点击"Remote Device Manager"（远程真机）或"Simulator Manager"（模拟器）选择一个调试设备，在地图中选择一个位置，或者在Simulated position中输入地址，点击"Run"开始模拟，工具会将位置数据注入到仿真器设备中，可以在仿真器中查看位置的变化。同时，您可以在Scenario Simulation工具的地图中看到位置的闪烁。

  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174812.86431454529111089792840793729317:50001231000000:2800:29B3111B5E45DB3C18A9CB16D3BADE38748C82D697F805A1E809FBFF29FB1897.png?needInitFileName=true?needInitFileName=true "点击放大")
* Trajectory（活动识别服务） 在模拟工具中，点击"Remote Device Manager"（远程真机）或"Simulator Manager"（模拟器）选择一个调试设备，设置起点和终点位置（也可以在地图中，点击右键进行选择）、运动方式（Travel mode），点击"Run"开始模拟，工具会将运动轨迹注入到仿真器中，在仿真器中可以查看位置的不断移动。同时，您也可以在Scenario Simulation工具的地图中查看运动轨迹（蓝色表示规划路径，橙色表示已经过的路径）。

* Geofence（地理围栏服务） 在模拟工具中，点击"Remote Device Manager"（远程真机）或"Simulator Manager"（模拟器）选择一个调试设备，设置起点和终点位置（也可以在地图中，点击右键进行选择）、运动方式（Travel mode）、地理围栏半径，点击"Run"开始模拟，工具会将运动轨迹注入到仿真器中，可以模拟进入围栏、离开围栏和驻留围栏三种状态。同时，您也可以在Scenario Simulation工具的地图中查看运动轨迹（红色圆圈表示地理围栏范围，蓝色表示规划路径，橙色表示已经过的路径）。

当Debug Device选择本地真机时，使用方法和选择远程真机或模拟器类似，以Fused Location为例简单说明：

1. 在"USB"下面选择一个本地真机，在地图中选择一个位置，或者在Simulated position中输入地址。点击"Run"开始模拟。
2. 安装"Location Spoofer"的App并允许获取您本地真机的位置信息，确保手机联网正常。
3. 工具会将位置数据注入到您的本地真机中，可以在本地真机中查看位置的变化。同时，您可以在Scenario Simulation工具的地图中看到位置的闪烁。

#### Map Kit专项工具

#### Develop

Map Kit提供场景模拟工具（Develop），可以为您提供端云位置数据比对服务、距离测量服务和路径规划服务。

* 端云位置数据比对服务：详细比对终端设备侧获取的位置数据与云端存储的位置数据，可帮助您进行终端侧位置数据的精确度分析。
* 距离测量服务：在模拟工具中选择起点位置和终点位置，测量起点与终点之间的直线距离。
* 路径规划服务：在模拟工具中选择起点位置和终点位置，工具根据设定的运动方式自动规划行进线路。

场景模拟工具的使用方法如下：

1. 在Map Kit卡片的工具栏中，点击Develop工具，进入场景模拟工具的页面。
2. 选择对应服务的卡片，如Data Comparison（端云位置数据比对）、Distance Calculation（距离测量）和Path Planning（路径规划）。
   * Data Comparison（端云位置数据比对）：
     1. 首先确定模拟地点的位置。Develop工具提供了两种输入地点信息的方式： Simulated position：通过输入地点名称来确定模拟地点的位置。

        Latitude and Longitude：通过输入地点的经纬度来确定模拟地点的位置。

        确定了模拟地点的位置之后，工具会自动查询云端存储的该模拟地点的位置数据。
     2. 获取终端设备侧的模拟地点的位置数据。 Method of Obtaining Device-Side Data：获取终端设备侧的位置数据，可以选择从日志中解析（Log scraping），或者选择手动输入（Manual input）。选择从日志中解析时，需要您将工程运行起来后，点击"Start"，工具会弹出一个窗口展示从日志中解析出的位置数据列表，选择相应的位置数据后点击"Capture"即可抓取该条位置数据，并注入到下图的对比界面中。

     对比界面如图所示。左侧框中的是云端数据，右侧框中的是终端设备侧的数据。点击"Run"即可开始进行端云位置数据比对，橙色表示左右两侧的数据存在差异。

     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174813.64202361814447277247617599169936:50001231000000:2800:FBC2C4D9DE22137071108F27A997514CDC0027742DE5AA20D093941515F34B80.png?needInitFileName=true?needInitFileName=true "点击放大")
   * Distance Calculation（距离测量）：在工具中，输入起点和终点的位置信息（可以输入地点，也可以输入经纬度信息），点击"Run"即可测量起点和终点之间的直线距离。

#### Listener

华为Map SDK支持在地图上绘制标记、覆盖物以及形状。同时，您可以通过使用如HuaweiMap.OnMarkerDragListener等方法来侦听标记、覆盖物以及形状上的点击、长按、拖动等事件。侦听事件的详细说明请参见[Map Kit侦听事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-sdk-event-listening-0000001062565230)。
