# 启动抓取失败如何操作？

当之前已经运行过抓取程序并没有完全退出时，执行Launch新的应用程序，提示如下弹框。

![](https://media:201778750888259140)

设备界面提示没有远程访问连接到抓取程序。

![](https://media:201778750888437141)

解决办法：

1. 结束设备正在运行的应用。
2. 再次在设备上启动需要运行的应用。
