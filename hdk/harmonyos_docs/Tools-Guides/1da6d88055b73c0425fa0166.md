# 启动抓取失败如何操作？

当之前已经运行过抓取程序并没有完全退出时，执行Launch新的应用程序，提示如下弹框。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/KhTHMHOxTYWJLWOcAlZDBQ/zh-cn_image_0000002380485212.png?HW-CC-KV=V1&HW-CC-Date=20260909T130714Z&HW-CC-Expire=31536000000&HW-CC-Sign=DCE57BF695F176B2AC300825C160E95FFA9EB8238363C8EFA2BDEB3870D787DE)

设备界面提示没有远程访问连接到抓取程序。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/403rmZ7iQ7yWXYXKNIQQ0w/zh-cn_image_0000002413964757.png?HW-CC-KV=V1&HW-CC-Date=20260909T130714Z&HW-CC-Expire=31536000000&HW-CC-Sign=C3CC49989976D54F9354D41C9DED29FE2ABFA10144F0A903770C6977D66FABAA)

解决办法：

1. 结束设备正在运行的应用。
2. 再次在设备上启动需要运行的应用。
