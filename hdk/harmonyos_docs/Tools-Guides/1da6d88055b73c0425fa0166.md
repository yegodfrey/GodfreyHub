# 启动抓取失败如何操作？

当之前已经运行过抓取程序并没有完全退出时，执行Launch新的应用程序，提示如下弹框。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/KhTHMHOxTYWJLWOcAlZDBQ/zh-cn_image_0000002380485212.png?HW-CC-KV=V1&HW-CC-Date=20261008T140718Z&HW-CC-Expire=31536000000&HW-CC-Sign=284CB4BF054187F15C6F18B163F65C1CA56383C0692B1DFB058D2D065B3B7810)

设备界面提示没有远程访问连接到抓取程序。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/403rmZ7iQ7yWXYXKNIQQ0w/zh-cn_image_0000002413964757.png?HW-CC-KV=V1&HW-CC-Date=20261008T140718Z&HW-CC-Expire=31536000000&HW-CC-Sign=08A3F8EE2FDA296A8F56A14B199863FE650701067E362ACBED179A09AAE6E348)

解决办法：

1. 结束设备正在运行的应用。
2. 再次在设备上启动需要运行的应用。
