# 增加组件

1. 点击左上角"导入"，导入VR眼镜模型。
2. 点击命令面板的相机展开相机列表，添加"透视相机"。
3. 点击命令面板打开灯光列表，选择"点光源"。
4. 点击模型出现控制轴，调整至合适的位置。
5. 点击命令面板的2D控件展开列表，添加"按钮"，修改"按钮文本"属性为"Exterior"。如下图所示。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.08451792210660244847952123806652:50520704031946:2800:F85E6D8DF531A57FFC249B7F613D2A369F2C7BDCC7690798FD4B569F1976DB7F.png?needInitFileName=true?needInitFileName=true "点击放大")
6. 点击命令面板的3D控件展开列表，添加"序列帧图片"，修改"名称"属性为"Serial frame image"，点击"贴图"的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150017.43887619957309531218072503979039:50520704031946:2800:FD1FFF694951AFFD215D3B9CC87CBE0192B5951F6B409D69F142DE36D1C4A5FA.png?needInitFileName=true?needInitFileName=true "点击放大")给序列帧图片增加贴图。如下图所示。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150018.14882512511883451160536745018540:50520704031946:2800:86B8D334D91ABFBD8F66453DA8286812B1B1E64F81ACEFF75A6CE272F09ADE45.png?needInitFileName=true?needInitFileName=true "点击放大")
7. 点击命令面板的2D控件展开列表，添加"文本面板"，修改属性如下图所示。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150018.94379814632082397804619633994803:50520704031946:2800:E60BDB49D6B95E49A78FAE4F52AD3AE2C97BF1F7132E4533127F9AEAB8631CE8.png?needInitFileName=true?needInitFileName=true "点击放大")
8. 修改完成后，将文本面板的"可见性"选框取消勾选。
