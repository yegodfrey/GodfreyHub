# 反馈问题

使用华为快应用IDE如果遇到问题，可以通过工单系统反馈给我们。

1. 使用华为帐号登录[工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
2. 问题分类选择"HMS Core"，在弹出窗口选择"快应用"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100019.80005503666816876378249976827318:50001231000000:2800:A36E18CC8810774AE610A404885FD24F1BBB833706DDAD7D8D1512A4E50F6038.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3. 填写问题信息后，点击"提交问题"，等待华为的处理。
   * 是否包含终端用户数据：根据实际情况填写。一般选择"不存在"。
   * 概述：问题的简短描述。
   * 产品名称：可不填。
   * APP ID：可不填。
   * 问题发生时间：问题发生的时间，请尽量填写准确。
   * 包名：可不填。
   * 日志：可不填。
   * 问题发生页面URL：可不填。
   * 问题描述：请尽量详细描述
   * 上传附件：需要上传的文件，如LOG文件
   * 申明：必须勾选
