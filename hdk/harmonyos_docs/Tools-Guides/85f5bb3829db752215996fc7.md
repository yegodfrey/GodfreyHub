# Remote Configuration

#### 准备工作

1. 您若需要应用支持Remote Configuration，必须完成接入准备，请参见[AppGallery Connect开发服务使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-android-0000001058210705)。
2. 华为远程配置服务详情请参见[远程配置服务简介](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-remoteconfig-introduction-0000001055149778)，相关API详情请参见[远程配置API参考](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-overview-0000001055692839)。  

#### fetchAndActivate()

此API的功能是获取云端配置并激活。在Firebase中此功能由FirebaseRemoteConfig.fetchAndActivate()一次性完成，返回值是存储了操作是否成功的GMS的Task对象。而在AGC中，操作的粒度更精确，分为了获取配置和激活配置两步来完成：[AGConnectConfig.fetch](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section1176012013115)()完成获取配置的操作，返回值是存储了配置数据的HMS的Task对象，再通过此对象的addOnSuccessListner()方法，成功获取配置后，在onSuccess()的回调中用[AGConnectConfig.apply](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section486198212)(ConfigValues)完成激活配置。下面给出简易的代码示例。

使用Firebase的fetchAndActivate()方法的代码场景：

```
FirebaseRemoteConfig config = FirebaseRemoteConfig.getInstance();
config.fetchAndActivate().addOnCompleteListener(new OnCompleteListener<Boolean>(){           
    @Override            
    public void onComplete(Task<Boolean> task) {                
        if (task.isSuccessful()) {                            
            Log.d("TAG", "FirebaseRemoteConfig fetched");                
        } else {                    
            Log.d("TAG", "FirebaseRemoteConfig error:" + task.getResult());                
        }            
    }        
});
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionRemoteConfig、GlobalEnvSetting等类）：

```
ExtensionRemoteConfig config = ExtensionRemoteConfig.getInstance();
if (GlobalEnvSetting.isHms()) {
    ((com.huawei.agconnect.remoteconfig.AGConnectConfig) config.getHInstance()).fetch()
        .addOnSuccessListener(new com.huawei.hmf.tasks.OnSuccessListener<com.huawei.agconnect.remoteconfig.ConfigValues>() {
            @Override
            public void onSuccess(ConfigValues configValues) {
                com.huawei.agconnect.remoteconfig.AGConnectConfig.getInstance().apply(configValues);
                Log.d("TAG", "AppGallery-connect RemoteConfig fetched and activated");
            }
        }).addOnFailureListener(new com.huawei.hmf.tasks.OnFailureListener(){
            @Override
            public void onFailure(Exception e){
                Log.d("TAG", "AppGallery-connect RemoteConfig error:" + e.getMessage());
         }
    });
} else {
    ((com.google.firebase.remoteconfig.FirebaseRemoteConfig) config.getGInstance()).fetchAndActivate()
        .addOnCompleteListener(new com.google.android.gms.tasks.OnCompleteListener<Boolean>() {
            @Override
            public void onComplete(com.google.android.gms.tasks.Task<Boolean> task) {
                if (task.isSuccessful()) {
                    Log.d("TAG", "FirebaseRemoteConfig fetched");
                } else {
                    Log.d("TAG", "FirebaseRemoteConfig error:" + task.getResult());
                }
            }
    });
}
```

在To HMS API模式下的代码修改示例：

```
AGConnectConfig config = AGConnectConfig.getInstance();
config.fetch().addOnSuccessListener(new com.huawei.hmf.tasks.OnSuccessListener<com.huawei.agconnect.remoteconfig.ConfigValues>() {
    @Override
    public void onSuccess(com.huawei.agconnect.remoteconfig.ConfigValues configValues) {
        config.apply(configValues);
        Log.d("TAG", "AppGallery-connect RemoteConfig fetched and activated");
    }
}).addOnFailureListener(new com.huawei.hmf.tasks.OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        Log.d("TAG", "AppGallery-connect RemoteConfig error:" + e.getMessage());
    }
});
```

#### activate()

此API的作用是激活最近一次获取的配置信息，返回值是存储了激活结果是否成功的信息的GMS的Task对象。在AGC中，通过[AGConnectConfig.apply](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section486198212)(ConfigValues)方法来激活配置信息。与Firebase不同的是，AGC中的激活方法需要的ConfigValues对象是由fetch方法返回的，因此两者需要配合使用。下面给出简易代码示例。

使用Firebase的activate()方法的代码场景：

```
FirebaseRemoteConfig config = FirebaseRemoteConfig.getInstance();
config.activate().addOnCompleteListener(new OnCompleteListener<Boolean>(){           
    @Override            
    public void onComplete(Task<Boolean> task) {                
        if (task.isSuccessful()) {                                       
            Log.d("TAG", "FirebaseRemoteConfig fetched");                
        } else {                    
            Log.d("TAG", "FirebaseRemoteConfig error:" + task.getResult());                
        }            
    }        
});
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionRemoteConfig、GlobalEnvSetting等类）：

```
ExtensionRemoteConfig config = ExtensionRemoteConfig.getInstance();
if (GlobalEnvSetting.isHms()) {
    ((com.huawei.agconnect.remoteconfig.AGConnectConfig) config.getHInstance()).fetch()
        .addOnSuccessListener(new com.huawei.hmf.tasks.OnSuccessListener<com.huawei.agconnect.remoteconfig.ConfigValues>() {
            @Override
            public void onSuccess(ConfigValues configValues) {
                com.huawei.agconnect.remoteconfig.AGConnectConfig.getInstance().apply(configValues);
                Log.d("TAG", "AppGallery-connect RemoteConfig fetched and activated");
            }
        }).addOnFailureListener(new com.huawei.hmf.tasks.OnFailureListener(){
            @Override
            public void onFailure(Exception e){
                Log.d("TAG", "AppGallery-connect RemoteConfig error:" + e.getMessage());
         }
    });
} else {
    ((com.google.firebase.remoteconfig.FirebaseRemoteConfig) config.getGInstance()).activate()
        .addOnCompleteListener(new com.google.android.gms.tasks.OnCompleteListener<Boolean>() {
            @Override
            public void onComplete(com.google.android.gms.tasks.Task<Boolean> task) {
                if (task.isSuccessful()) {
                    Log.d("TAG", "FirebaseRemoteConfig activated");
                } else {
                    Log.d("TAG", "FirebaseRemoteConfig error:" + task.getResult());
                }
            }
    });
}
```

在To HMS API模式下的代码修改示例：

```
AGConnectConfig config = AGConnectConfig.getInstance();
config.fetch().addOnSuccessListener(new com.huawei.hmf.tasks.OnSuccessListener<com.huawei.agconnect.remoteconfig.ConfigValues>() {
    @Override
    public void onSuccess(com.huawei.agconnect.remoteconfig.ConfigValues configValues) {
        config.apply(configValues);
        Log.d("TAG", "AppGallery-connect RemoteConfig fetched and activated");
    }
}).addOnFailureListener(new com.huawei.hmf.tasks.OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        Log.d("TAG", "AppGallery-connect RemoteConfig error:" + e.getMessage());
    }
});
```

此API功能与activate()相同，已经被废弃，代码修改方案与activate()相同。  

#### fetch(long)

此API的功能是根据输入的时间间隔，定期获取云端配置信息。在Firebase中返回值是一个GMS的Task\<Void\>对象，代表了fetch这个操作。而在AGC中，[fetch](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section412593515111)(long)的返回值是HMS的[Task\<ConfigValues\>](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-configvalues-0000001057570920)对象，包含了从云端获取的配置信息，用于后续激活。下面给出简易的代码示例。

使用Firebase的fetch(long)方法的代码场景：

```
long time = 1;
FirebaseRemoteConfig config = FirebaseRemoteConfig.getInstance();
Task<Void> fetch = config.fetch(time);
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionRemoteConfig、GlobalEnvSetting等类）：

```
long time = 1;
ExtensionRemoteConfig config = ExtensionRemoteConfig.getInstance();
if (GlobalEnvSetting.isHms()) {
    com.huawei.hmf.tasks.Task<com.huawei.agconnect.remoteconfig.ConfigValues> fetch = 
        ((com.huawei.agconnect.remoteconfig.AGConnectConfig) config.getHInstance()).fetch(time);
    // 根据后续业务逻辑决定如何处理这个存储了配置信息的Task对象
} else {
    com.google.android.gms.tasks.Task<Void> fetch = 
        ((com.google.firebase.remoteconfig.FirebaseRemoteConfig) config.getGInstance()).fetch(time);
}
```

在To HMS API模式下的代码修改示例：

```
long time = 1;
AGConnectConfig config = AGConnectConfig.getInstance();
com.huawei.hmf.tasks.Task<com.huawei.agconnect.remoteconfig.ConfigValues> fetch = config.fetch(time);
```

ExtensionRemoteConfig config = ExtensionRemoteConfig.getInstance();
if (GlobalEnvSetting.isHms()) {

#### getAll()

此API的功能是获取所有的云端配置信息，返回值是一个Map对象。在Firebase中，Map的Value值是FirebaseRemoteConfigValue对象；而在AGC中，使用[AGConectConfig.getMergedAll](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section743811341720)()实现这个功能，但是返回的Map中的Value是Object对象。您需要根据具体的业务需求进行后续的处理。下面给出简易的代码示例。

使用Firebase的getAll()方法的代码场景：

```
FirebaseRemoteConfig config = FirebaseRemoteConfig.getInstance();
Map<String, FirebaseRemoteConfigValue> map = config.getAll();
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionRemoteConfig、GlobalEnvSetting等类）：

```
ExtensionRemoteConfig config = ExtensionRemoteConfig.getInstance();
if (GlobalEnvSetting.isHms()) {
    Map<String, Object> mapAGC = ((com.huawei.agconnect.remoteconfig.AGConnectConfig) config.getHInstance()).getMergedAll();
    //根据业务需求处理mapAGC，如果您需要String类型的Value值，可以直接使用toString()方法
    //如果需要其他基本类型的Value值，可以使用类似Double.parseDouble(Object.toString())的一系列方法来处理
} else {
    Map<String, com.google.firebase.remoteconfig.FirebaseRemoteConfigValue> mapFirebase = ((com.google.firebase.remoteconfig.FirebaseRemoteConfig) config.getGInstance()).getAll();
    //根据业务需求处理mapFirebase
}
```

在To HMS API模式下的代码修改示例：

```
AGConnectConfig config = AGConnectConfig.getInstance();
java.util.Map<String, Object> mapAGC = config.getMergedAll();
```

#### reset()

此API的作用是删除所有已经激活的/获取的，以及默认的配置信息，并且重置所有Firebase的远程配置设置，返回值是一个GMS的Task对象，代表了删除这个任务。而在AGC中，使用[AGConectConfig.clearAll](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section011016145315)()提供这个功能，区别在于此API没有返回值。下面给出简易的代码示例。

使用Firebase的reset()方法的代码场景：

```
FirebaseRemoteConfig config = FirebaseRemoteConfig.getInstance();
Task<Void> res = config.reset();
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionRemoteConfig、GlobalEnvSetting等类）：

```
ExtensionRemoteConfig config = ExtensionRemoteConfig.getInstance();
if (GlobalEnvSetting.isHms()) {
    ((com.huawei.agconnect.remoteconfig.AGConnectConfig)config.getHInstance()).clearAll();
} else {
    com.google.android.gms.tasks.Task<Void> res = ((com.google.firebase.remoteconfig.FirebaseRemoteConfig) config.getGInstance()).reset();
    //根据后续业务需求处理这个Task对象
}
```

在To HMS API模式下的代码修改示例：

```
AGConnectConfig config = AGConnectConfig.getInstance();
config.clearAll();
```

#### getSource()

此API的作用是获取FirebaseRemoteConfigValue对象的来源，返回值是int。而在AGC中，返回值是枚举类型SOURCE。除此之外，在Firebase中，方法的调用对象就是存储了配置信息的对象，因此此功能不需要入参，而在AGC中，方法的调用对象并不是存储了配置信息的对象，因此需要给方法传入Key值来获取该Key值所对应的来源。

下面给出对应关系。  

|Firebase|AppGallery-connect|
|:----------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[VALUE_SOURCE_REMOTE](https://firebase.google.com/docs/reference/android/com/google/firebase/remoteconfig/FirebaseRemoteConfig#VALUE_SOURCE_REMOTE)|[SOURCE.REMOTE](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#ZH-CN_TOPIC_0000001108194208__section17978105118564)|
|[VALUE_SOURCE_DEFAULT](https://firebase.google.com/docs/reference/android/com/google/firebase/remoteconfig/FirebaseRemoteConfig#VALUE_SOURCE_DEFAULT)|[SOURCE.DEFAULT](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#ZH-CN_TOPIC_0000001108194208__section17978105118564)|
|[VALUE_SOURCE_STATIC](https://firebase.google.com/docs/reference/android/com/google/firebase/remoteconfig/FirebaseRemoteConfig#VALUE_SOURCE_STATIC)|[SOURCE.STATIC](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#ZH-CN_TOPIC_0000001108194208__section17978105118564)|

下面给出简易代码示例。

使用Firebase的getSource()方法的代码场景：

```
FirebaseRemoteConfig config = FirebaseRemoteConfig.getInstance();
int res = config.getValue("Example").getSource();
```

在Add HMS API模式下的代码修改示例（在插件转换后，生成的xmsadapter模块中会包含下面用到的ExtensionRemoteConfig、GlobalEnvSetting等类）：

```
ExtensionRemoteConfig config = ExtensionRemoteConfig.getInstance();
if (GlobalEnvSetting.isHms()) {
    com.huawei.agconnect.remoteconfig.AGConnectConfig.SOURCE sourceAGC = ((com.huawei.agconnect.remoteconfig.AGConnectConfig)config.getHInstance()).getSource("Example");
    //根据后续业务需求处理这个枚举类型的结果
} else {
    int sourceFirebase = ((com.google.firebase.remoteconfig.FirebaseRemoteConfig) config.getGInstance()).getValue("Example").getSource();
    //根据后续业务需求处理这个int值
}
```

在To HMS API模式下的代码修改示例：

```
AGConnectConfig config = AGConnectConfig.getInstance();
com.huawei.agconnect.remoteconfig.AGConnectConfig.SOURCE sourceAGC = config.getSource("Example");
//根据后续业务需求处理这个枚举类型的结果
```

#### setConfigSettingsAsync(FirebaseRemoteConfigSettings settings)

该API的作用是异步更改此FirebaseRemoteConfig实例的设置。 而在AGC中，当前仅支持设置开发者模式，因此没有提供Builder类。对于此API的转换，如果是Add HMS API模式，建议先转换为使用同步接口setConfigSettings(FirebaseRemoteConfigSettings)，然后就可以用工具自动转换了。下面给出简易代码示例。

使用Firebase的setConfigSettingsAsync(FirebaseRemoteConfigSettings)的代码场景：

```
FirebaseRemoteConfigSettings firebaseRemoteConfigSettings = new FirebaseRemoteConfigSettings.Builder().setDeveloperModeEnabled(true).build();
FirebaseRemoteConfig remoteConfig = FirebaseRemoteConfig.getInstance();
Task<Void> setAsync = remoteConfig.setConfigSettingsAsync(firebaseRemoteConfigSettings);
```

在Add HMS API模式下的代码修改示例，将原始代码修改为示例样式后再使用工具进行自动转换：

```
FirebaseRemoteConfigSettings firebaseRemoteConfigSettings = new FirebaseRemoteConfigSettings.Builder().setDeveloperModeEnabled(true).build();
FirebaseRemoteConfig remoteConfig = FirebaseRemoteConfig.getInstance();
remoteConfig.setConfigSettings(firebaseRemoteConfigSettings);
```

在To HMS API模式下的代码修改示例：

```
//需要先将开发者模式的设置值获取出来放入isDeveloperMode
Boolean isDeveloperMode = true;
AGConnectConfig remoteConfig = AGConnectConfig.getInstance();
remoteConfig.setDeveloperMode(isDeveloperMode);
```

#### setDefaultsAsync(Map\<String, Object\>)

该API的作用是使用给定的Map异步设置默认配置。而在AGC中，当前仅提供同步设置默认配置的API。您可以先将代码修改为使用同步接口FirebaseRemoteConfig.setDefaults(Map\<String,Object\>)，然后就可以使用工具进行自动转换。下面给出简易代码示例。

使用异步接口setDefaultsAsync(Map\<String, Object\>)的代码场景：

```
Map<String, Object> defaults = new HashMap<>();
FirebaseRemoteConfig remoteConfig = FirebaseRemoteConfig.getInstance();
Task<Void> setAsync = remoteConfig.setDefaultsAsync(defaults);
```

代码修改示例如下，修改后可以用工具自动转换：

```
Map<String, Object> defaults = new HashMap<>();
FirebaseRemoteConfig remoteConfig = FirebaseRemoteConfig.getInstance();
remoteConfig.setDefaults(defaults);
```

#### setDefaultsAsync(int)

该API的作用是使用给定的int值异步设置默认配置。而在AGC中，当前仅提供同步设置默认配置的API。您可以先将代码修改为使用同步接口FirebaseRemoteConfig.setDefaults(int)，然后就可以使用工具进行自动转换。下面给出简易代码示例。

使用异步接口setDefaultsAsync(int)的代码场景：

```
int defaults = 0;
FirebaseRemoteConfig remoteConfig = FirebaseRemoteConfig.getInstance();

```

代码修改示例如下，修改后可以用工具自动转换：

int defaults = 0;
FirebaseRemoteConfig remoteConfig = FirebaseRemoteConfig.getInstance();
remoteConfig.setDefaults(defaults);
```

#### FirebaseRemoteConfigServerException()

该API是返回与Firebase远程配置服务器交互的内部事件，FirebaseRemoteConfigServerException(int httpStatusCode, java.lang.String detailMessage)该用法使用HTTP状态码和给定的消息创建出FirebaseRemoteConfig服务异常。在AGC对应的方法实现[AGCConfigException(java.lang.String msg, int code)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agcconfigexception-0000001057332742#section14219195014131)中，参数的位置发生了变化，第一个参数msg为异常消息，第二个参数为[异常错误码](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agcconfigexception-0000001057332742#ZH-CN_TOPIC_0000001155273815__section1113522131518)。下面给出简易代码示例。

使用Firebase的FirebaseRemoteConfigServerException()方法的代码场景：

```
FirebaseRemoteConfigServerException firebaseRemoteConfigServerException = new FirebaseRemoteConfigServerException(1, "test");
```

在To HMS API模式下的代码修改示例：

```
AGCConfigException firebaseRemoteConfigServerException = new AGCConfigException("test", 1);
```

#### getKeysByPrefix(String prefix)

该API的作用为返回具有给定前缀的所有FirebaseRemoteConfig参数键的集合。此功能在AGC中可由其他接口组合实现，通过[getMergedAll](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section743811341720)返回全部数据，再根据前缀过滤对应的Key值。下面给出简易代码示例。

使用Firebase的getKeysByPrefix(String prefix)方法的代码场景：

```
java.lang.String prefix = "test";
java.util.Set<String> hReturn = FirebaseRemoteConfig.getKeysByPrefix(prefix);
```

在To HMS API模式下的代码修改示例：

```
java.lang.String prefix = "test";
java.util.Set<String> keySet = AGConnectConfig.getInstance().getMergedAll().keySet();
java.util.Set<String> hReturn = new HashSet<>();
for (String key : keySet) {
    if (key.startsWith(prefix)) {
        hReturn.add(key);
    }
}
```

String key = "test";

```

#### getInstance(FirebaseApp app)

该API的作用是将FirebaseRemoteConfig实例化，返回的是给定FirebaseApp的Firebase远程配置实例，是带FirebaseApp参数的实例化用法。 而AGC中FirebaseApp对应的方法是默认直接支持的，所以转换之后，该API将替换为无参。下面给出简易代码示例。

使用Firebase的getInstance(FirebaseApp app)方法的代码场景：

```
FirebaseRemoteConfig config = FirebaseRemoteConfig.getInstance(com.google.firebase.FirebaseApp.getInstance());
```

在To HMS API模式下的代码修改示例：

```
AGConnectConfig config = AGConnectConfig.getInstance();
```

#### setDefaults(int)

属于FirebaseRemoteConfig中的方法。该API的作用是使用XML资源设置默认配置。而在AGC中也有提供相应能力的方法，但是AGC支持的XML资源文件格式与Firebase支持的XML资源文件格式不同。因此需要先将Firebase格式的XML资源读取成一个Map后，再调用[AGConnectConfig.applyDefault](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/android-remoteconfig-agconnectconfig-0000001056852785#section42628541407)(Map\<String,Object\>)来完成配置。您可以使用下面的代码来读取Firebase格式的XML资源（需要借助AGC的相关接口），或者您也可以借助工具将XML资源修改为AGC的格式。

读取Firebase格式的XML资源的代码示例：

```
public Map<java.lang.String, java.lang.Object> readXml2Map(int resId) {
    Map<java.lang.String, java.lang.Object> defaultsMap = new HashMap<>();
    Context context = AGConnectInstance.getInstance().getContext();
    try {
        Resources resources = context.getResources();
        if (resources == null) {
            return defaultsMap;
        }
        XmlResourceParser xmlParser = resources.getXml(resId);
        String curTag = null;
        String key = null;
        String value = null;
        int eventType = xmlParser.getEventType();
        while (eventType != XmlResourceParser.END_DOCUMENT) {
            if (eventType == XmlResourceParser.START_TAG) {
                curTag = xmlParser.getName();
            } else if (eventType == XmlResourceParser.END_TAG) {
                if (xmlParser.getName().equals("entry")) {
                    if (key != null && value != null) {
                        defaultsMap.put(key, value);
                    }
                    key = null;
                    value = null;
                }
                curTag = null;
            } else if (eventType == XmlResourceParser.TEXT) {
                if (curTag != null) {
                    if ("key".equals(curTag)) {
                        key = xmlParser.getText();
                    } else if ("value".equals(curTag)) {
                        value = xmlParser.getText();
                    }
                }
            }
            eventType = xmlParser.next();
        }
    } catch (XmlPullParserException e) {
        Log.e("readXml2Map", "parse default values xml failed", e);
    }catch (IOException e){
        Log.e("readXml2Map", "parse default values xml failed", e);
    }
    return defaultsMap;
}
```

使用Firebase的setDefaults(int)方法的代码场景：

```
FirebaseRemoteConfig remoteConfig = FirebaseRemoteConfig.getInstance();
remoteConfig.setDefaults(R.id.XML);
```

在To HMS API模式下的代码修改示例：

```
AGConnectConfig remoteConfig = AGConnectConfig.getInstance();
remoteConfig.applyDefault(readXml2Map(R.id.XML));
```
