# App Messaging

#### 准备工作

1. 您若需要应用支持App Messaging，必须完成接入准备，请参见[AppGallery Connect开发服务使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-android-0000001058210705)。
2. 华为应用内消息服务详情请参见[应用内消息服务简介](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-appmessage-introduction-0000001071884501)，相关API详情请参见[应用内消息服务API参考](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/appmessaging-overview-android-0000001059632677)。
3. 鉴于FirebaseInAppMessaging与AGCAppMessaging都为零代码集成，通过Add HMS API策略转换代码后，为防止设备可以同时显示Firebase和AGC控制台的消息，需在必要的代码位置（如Application子类的OnCreate生命周期）添加如下代码：

   ```
   if (GlobalEnvSetting.isHms()) {
       com.google.firebase.inappmessaging.FirebaseInAppMessaging.getInstance().setMessagesSuppressed(true);
   } else {
       com.huawei.agconnect.appmessaging.AGConnectAppMessaging.getInstance().setDisplayEnable(false);
   }
   ```

#### setMessageDisplayComponent(FirebaseInAppMessagingDisplay)

属于FirebaseInAppMessaging中方法。当您需要展示自定义布局的消息时，此API可以帮助您实现这一目的，入参代表了实现自定义布局消息展示的实例。特别注意：Firebase在使用该接口时，需删除firebase-inappmessaging-display依赖，否则设置展示自定义布局消息失败。而在AGC中，用[addCustomView(AGConnectAppMessagingDisplay)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessaging-android-0000001057483901#section18491751124520)来实现展示自定义布局消息的目的。下面给出简易的代码示例。

使用Firebase的setMessageDisplayComponent(FirebaseInAppMessagingDisplay)方法的代码场景：

```
FirebaseInAppMessaging Msg = FirebaseInAppMessaging.getInstance();
//本示例中FirebaseInAppMessagingDisplayImpl类实现了FirebaseInAppMessagingDisplay接口
Msg.setMessageDisplayComponent(new FirebaseInAppMessagingDisplayImpl());
```

在Add HMS API模式下的代码修改示例（在插件转换后）：

```
ExtensionInAppMessaging msg = ExtensionInAppMessaging.getInstance();
if (GlobalEnvSetting.isHms()) {
  //本示例中CustomView实现了AGConnectAppMessagingDisplay接口
    ((com.huawei.agconnect.appmessaging.AGConnectAppMessaging)msg.getHInstance())
           .addCustomView(new AGConnectAppMessagingDisplay());
} else {
  //本示例中MessageDisplayComponent类实现了FirebaseInAppMessagingDisplay接口
    ((com.google.firebase.inappmessaging.FirebaseInAppMessaging)msg.getGInstance())
          .setMessageDisplayComponent(new MessageDisplayComponent());
}
```

在To HMS API模式下的代码修改示例：

```
//本示例中CustomView实现了AGConnectAppMessagingDisplay接口
AGConnectAppMessaging msg = AGConnectAppMessaging.getInstance();
msg.addCustomView(new AGConnectAppMessagingDisplay());
```

#### displayMessage(InAppMessage, FirebaseInAppMessagingDisplayCallbacks)

属于FirebaseInAppMessagingDisplay中方法。当您需要展示自定义布局的消息时，必须实现接口中的此方法，入参InAppMessage代表了展示的应用内消息的实例，入参FirebaseInappMessagingDisplayCallbacks代表了服务内部用来监听消息展示事件的接口。而在AGC中，则必须实现接口[displayMessage(AppMessage, AGConnectAppMessagingCallback)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessagingdisplay-android-0000001059201572#section166841212133516)。下面给出简易的代码示例。

使用Firebase的displayMessage(InAppMessage, FirebaseInAppMessagingDisplayCallbacks)方法的代码场景：

```
public class GCustomView implements FirebaseInAppMessagingDisplay {
    public void displayMessage(InAppMessage inAppMessage, FirebaseInAppMessagingDisplayCallbacks callback) {
    //业务代码
    }
}
```

在Add HMS API模式下的代码修改示例（在插件转换后）：

该模式下需要您分别创建两个类，分别实现Firebase的FirebaseInAppMessagingDisplay接口和AGC的[AGConnectAppMessagingDisplay](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessagingdisplay-android-0000001059201572)接口。具体实现的代码场景如下：

```
public class GCustomView implements FirebaseInAppMessagingDisplay {
    public void displayMessage(InAppMessage inAppMessage, FirebaseInAppMessagingDisplayCallbacks callback) {
    //业务代码
    }
}
public class HCustomView implements AGConnectAppMessagingDisplay{
    public void displayMessage(AppMessage appMessage, AGConnectAppMessagingCallback callback) {
    //业务代码
    }
}
```

在To HMS API模式下的代码修改示例：

```
public class HCustomView implements AGConnectAppMessagingDisplay{
    public void displayMessage(AppMessage appMessage, AGConnectAppMessagingCallback callback) {
    //业务代码
    }
}
```

#### Task\<Void\> messageClicked(Action action)

属于FirebaseInAppMessagingDisplayCallbacks中方法。您可以在displayMessage(InAppMessage, FirebaseInAppMessagingDisplayCallbacks)中调用该接口，通知服务内部已执行消息点击操作。而在AGC中，可以在[displayMessage(AppMessage, AGConnectAppMessagingCallback)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessagingdisplay-android-0000001059201572#section166841212133516)中调用接口[onMessageClick(AppMessage)](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessagingonclicklistener-android-0000001059041586#section1949116516345)。FirebaseInAppMessagingDisplayCallbacks中的其余方法，例如Task\<Void\> impressionDetected()、Task\<Void\> messageDismissed(FirebaseInAppMessageDisplayCallbacks.InAppMessagingDismissType)和该接口转换方式相同。下面给出简易的代码示例。

使用Firebase的Task\<Void\> messageClicked( Action action)方法的代码场景：

```
public class GCustomView implements FirebaseInAppMessagingDisplay {
    public void displayMessage(InAppMessage inAppMessage, FirebaseInAppMessagingDisplayCallbacks callback) {
        //业务代码
        Button click = view.findViewById(R.id.click);
        click.setOnClickListener(new View.OnClickListener(){
            public void onClick(View v) {
                callback.messageClicked(inAppMessage.getAction())
                              .addOnCompleteListener(new OnCompleteListener<Void>(){
                                  public void onComplete(@NonNull Task<Void> task){
                                          //业务代码
                                    }
                                });
                       //业务代码
             }
        });
    }
}
```

在Add HMS API模式下的代码修改示例（在插件转换后）：

该模式下由于您已经分别创建两个类，分别实现Firebase的FirebaseInAppMessagingDisplay接口和AGC的[AGConnectAppMessagingDisplay](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessagingdisplay-android-0000001059201572)接口，所以只需要分别在Firebase和AGC的类里使用对应的接口方法。具体实现的代码场景如下：

```
public class GCustomView implements FirebaseInAppMessagingDisplay {
    public void displayMessage(InAppMessage inAppMessage, FirebaseInAppMessagingDisplayCallbacks callback) {
        //业务代码
        Button click = view.findViewById(R.id.click);
        click.setOnClickListener(new View.OnClickListener(){
            public void onClick(View v) {
                callback.messageClicked(inAppMessage.getAction())
                              .addOnCompleteListener(new OnCompleteListener<Void>(){
                                  public void onComplete(@NonNull Task<Void> task){
                                          //业务代码
                                    }
                                });
                       //业务代码
             }
        });
    }
}

public class HCustomView implements AGConnectAppMessagingDisplay {
    @Override
    public void displayMessage(AppMessage appMessage, AGConnectAppMessagingCallback callback) {
        //业务代码
        Button click = view.findViewById(R.id.click);
        click.setOnClickListener(new View.OnClickListener(){
            @Override
            public void onClick(View v) {
                callback.onMessageClick(appMessage);
                //业务代码
            }
        });
    }
}
```

在To HMS API模式下的代码修改示例：

```
public class HCustomView implements AGConnectAppMessagingDisplay {
    @Override
    public void displayMessage(AppMessage appMessage, AGConnectAppMessagingCallback callback) {
        //业务代码
        Button click = view.findViewById(R.id.click);
        click.setOnClickListener(new View.OnClickListener(){
            @Override
            public void onClick(View v) {
                callback.onMessageClick(appMessage);
                //业务代码
            }
        });
    }
}
```

#### areMessagesSuppressed()

GMS中属于com.google.firebase.inappmessaging.FirebaseInAppMessaging中方法，用于是否展示消息，返回true不展示，false展示，代码示例：

```
private FirebaseInAppMessaging firebase= FirebaseInAppMessaging.getInstance();
   /**
    * 初始化设置
    */
private void initAction() {
    if (firebase.areMessagesSuppressed()) {
        Log.i("TAG", "禁止显示消息");
    } else {
        Log.i("TAG", "允许显示消息");     
    }
}
```

在AGC中，属于[com.huawei.agconnect.appmessaging.AGConnectAppMessaging](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessaging-android-0000001057483901)中的方法，与其相反，返回true代表展示，下面给出简单示例。  
在To HMS API模式下的代码修改示例：

```
private AGConnectAppMessaging   firebase = AGConnectAppMessaging.getInstance();
         /**
          * 初始化设置
          */
private void initAction() {
    if (!firebase.isDisplayEnable()) {
        Log.i("TAG", "禁止显示消息");
    } else {
        Log.i("TAG", "允许显示消息");
    }
}
```

#### setMessagesSuppressed(java.lang.Boolean)

GMS中属于com.google.firebase.inappmessaging.FirebaseInAppMessaging中方法，开启消息显示，true关闭消息显示，代码示例：

```
private FirebaseInAppMessaging firebase= FirebaseInAppMessaging.getInstance();
CheckBox checkBox = new CheckBox(this);
boolean isChecked = checkBox.isChecked();
if (isChecked) {
    firebase.setMessagesSuppressed(false);
    Log.i("TAG", "开启消息显示");
} else {
    firebase.setMessagesSuppressed(true);
    Log.i("TAG", "关闭消息显示");
}
```

在AGC中，属于[com.huawei.agconnect.appmessaging.AGConnectAppMessaging](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agconnectappmessaging-android-0000001057483901)中的方法，与其相反，true开启消息显示，下面给出简单示例。

在To HMS API模式下的代码修改示例：

```
private AGConnectAppMessaging   firebase = AGConnectAppMessaging.getInstance();
CheckBox checkBox1 = new CheckBox(this);
boolean isChecked1 = checkBox1.isChecked();
if (isChecked1) {
    firebase.setDisplayEnable(true);
    Log.i("TAG", "开启消息显示");
} else {
    firebase.setDisplayEnable(false);
    Log.i("TAG", "关闭消息显示");
}
```
