# Atrace userspace annotations

在HarmonyOS上，本机和托管应用程序可以将自定义切片和计数器跟踪点注入到跟踪中。

atrace事件有两种类型：系统事件和应用事件。

系统事件：仅由操作系统内部使用libcutils触发。这些事件按类别分组，例如"am"（ActivityManager）、"pm"(PackageManager)。这些类别可用于跨多个进程启用事件组，而不必担心哪个特定系统进程触发这些事件。

应用事件：具有与系统事件相同的语义。但是，与系统事件不同的是，它们没有任何标记过滤功能（所有应用程序事件共享相同的标记ATRACE_TAG_APP），但可以在每个应用的基础上启用。
> 说明
>
> HarmonyOS 5.0及以上版本不支持该监测项，支持[HiTrace categories](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/harmonyos-application-0000001888193242)模拟atrace事件。
