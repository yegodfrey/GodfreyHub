# 纹理查看器

纹理查看器在选定事件（[API事件列表](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/api-event-list-0000001050701432)）中显示当前状态下输入纹理或颜色/深度缓冲区的内容，并提供控件以不同的方式进行调整和检查。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/Q4EXtJDJQvOWKwttkKFYcQ/zh-cn_image_0000002570993084.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=D705FAEFCF5D9E77F6D7FB999CF25483B60A0DE34DD72E272ABB7506AA0B84BF)

## 主纹理显示

主纹理显示占据了窗口的最大部分，是显示纹理的容器。它是一个选项卡式控件，始终出现在第一个选项卡，显示当前管线状态上的特定纹理，例如输入纹理或颜色/深度输出。

鼠标滚轮可用于放大和缩小纹理。

鼠标位于在图像上方时，信息状态栏（红色区域2）将显示鼠标指向的当前像素，点击鼠标右键或按住鼠标右键将选中指向的像素并在状态栏中显示其信息。

## 信息状态栏

主纹理显示下方的状态栏包含当前可见纹理的信息。

* 名称（如果适用，将使用自动生成的名称）。


* 尺寸-宽度、高度、深度和数组大小（如果适用）。


* Mip计数。


* MSAA采样数量和质量（如果适用）。
* 格式-例如R8G8B8A8_UNORM。

在此信息之后，有一些基于像素的显示。光标下方的像素显示为色样，随后显示其坐标，然后显示任意拾取的像素并显示其数值。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/koIiR6QyRjKuugdJl_twVg/zh-cn_image_0000001050995959.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F34935CABDEDA6827A99B76FA1FDABCF6129F199544816D338DE1068B7DC27E)

## 工具栏

工具栏用于选择要查看的纹理的Mip、切片、面和如何显示纹理以及是否应用变换或叠加。

### 通道选择器

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/IvbwIDCgRHqe0eBY7Ierfw/zh-cn_image_0000001186813406.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=283C9BB843FABBD47BA90E2946CE52F51259956124C935D779179EC40B185F4B)

有四个选项：

* 选择"RGBA"时，右键点击纹理查看器中的一个通道按钮（R，G，B，A）将选择该通道。这些通道选择默认情况下会保存为每个纹理状态，因此切换到其他纹理将恢复为默认的RGB。
* 选择"RGBM"时，RGB值将乘以指定的乘数，然后乘以alpha值，用于通过使用alpha通道作为缩放因子将HDR值打包为8位RGBA图像。
* 选择"YUVA decode"时，将使用Rec进行默认的全范围转换，以转换YUVA数据。
* 选择"Custom"后，将在下拉列表中填充可用于解码和显示纹理的自定义着色器。选择自定义着色器时，原始图像将通过该着色器传递，然后在主显示器上使用常规控件进行显示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9f/v3/Qqbv5nk6SVS5rrcCqPTXXw/zh-cn_image_0000001186651930.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=2EC582ADB84900332C3871E647E2FD1B1813C96476BFB80BDF7AD8A9E6B2A265)"棋盘背景"按钮：点击此按钮，选择棋盘格图案作为主显示背景，默认主显示背景为棋盘格图案。

当显示带有Alpha通道的纹理时，主显示的背景会改变，以使半透明部分更加明显。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/Ha2KutBQTemYDbw2wdgFkg/zh-cn_image_0000001232091549.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=4CBEA716C3B70A48FAC6543B62E1F63181A925000EF5EFC21D8895BE5AE64412)"Gamma显示"按钮：当线性数据被"过度校正"时，可以通过切换此选项来覆盖此行为。

### 子资源选择

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/wZrZHZnTQsqfpu3nBPUOLg/zh-cn_image_0000001186811854.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=A048601D89E42E4F205C02A80A2F39AEBC3A6681774A57799DE2470773CA970C)

纹理查看器的主显示每次最多只能显示图像的单个2D子资源。

对于具有Mip贴图的纹理，可以从控件1选择要显示的Mip级别，图像的整体大小将保持不变，将从选择的Mip级别进行点采样。

对于3D纹理和2D Array纹理，可以从下拉列表中选择要在此处显示的切片。

对于立方体贴图，则可以选择面。

对于立方体贴图数组，将控件1、2组合在一起以显示第一个和第二个立方体贴图的面列表。

对于多重采样纹理，选择单个样本以查看整个图像，或查看默认解析的图像。
> 说明
>
> Mip和Slice/Face选项默认情况下会保存为每个纹理状态，因此切换到其他纹理将还原为默认的第一个切片或面以及顶部Mip。

### 可视范围控制

可视范围控制在简化显示和检查值范围非常狭窄的图像时非常有用，并且对于查看任何HDR图像都是必需的，因为它可用于将更大范围的图像映射到LDR以进行显示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/9x5aYa78QdO2ereh6LpOog/zh-cn_image_0000001232212985.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=B190AEF467B00CA04A580A1819A611D3CAA766AC53A513575E6770D84A13B251)

主要控件是黑点和白点滑块。 黑点和白点滑块值显示在控件两侧的文本框中。这些是当前的绝对黑白值，输入纹理中的这些值在输出时分别映射为0和1。

可以通过点击和拖动黑点和白点滑块来简单地进行调整。

还有其他四个按钮可用于控制范围。

* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/3D-FDSQAQo-0u07cUo2a8Q/zh-cn_image_0000001231971481.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=964711BFD7D4C9693B7273510BA693B42A69F1FC90FF0ED3AF3782791F035C24)zoom放大：此按钮会将极端值放大到可拖动滑块选择的任何精细值。当从某个较大的范围开始并使用滑块将其向下拖动到一个更合理的范围时，点击"缩放"以将范围缩小到仅一个选定范围，就可以再次进行精细控制。


* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/Jrqy7_K9TlO03y5ny7gX7g/zh-cn_image_0000001186813408.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=62FB501717E7775B53ACD63AD1970F72CD4D7951CAD3CCFCB0648645C7403CA7)自动调整：此按钮会自动将范围控件调整为纹理中任何可见通道的最小值和最大值。右键点击此按钮将使其始终自动适配，直到禁用它为止。当移至其他事件或其他纹理时，范围将再次自动调整。
* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/5ddjrS0ZTcaFmVbPAVqVxQ/zh-cn_image_0000001186493386.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=0BB9A4F83DB9C15D5FB8DB52E738EB130F2B428FFAB46E3FD8CD584BB86DCDA9)重置：将范围重置为默认的[0, 1]，当新纹理不适用范围设置时，可重置为默认值。


* ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/CuBCFL6rSXu2yU6VjTIglw/zh-cn_image_0000001186651932.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=91CCB055A2A6690F1FD8C3DE76B7D9492B450A46B5E821E51DF78BF926080FED)直方图：这是一个拨动开关。启用后，它将把范围控件的细条更改为包含范围值直方图的粗条，以显示值的分布。直方图基于所有可见通道的直线数值平均值，并且会随着白点和黑点的移动而更新。

### 渲染叠加

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/dzTMjOdzTzildgmJqkJI_Q/zh-cn_image_0000001186811858.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=B85F1C2C257770DCBD0F08B55B481817E6797A7A71EA215B46001B9924476458)

渲染叠加可以快速诊断问题，查找所需内容。下拉菜单有以下内容可选。

|参数值|说明|
|:----------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Highlight Drawcall|会显示出当前Drawcall覆盖的区域。仅以平色突出显示当前Drawcall，其余所有内容变暗。这样可以使绘制的所有内容突出，在快速浏览框架时，快速定位当前对象在屏幕上的位置。|
|Wireframe Mesh|将在图像上方渲染当前调用的线框网格。|
|Depth Test|将在绘图调用上进行覆盖，红色部分覆盖未通过深度测试的任何区域，绿色部分覆盖通过深度测试的区域。如果Drawcall自身重绘，则只要一个像素上的至少一个通过深度测试，该像素为绿色。|
|Stencil Test|执行与深度测试相似，是用于模板测试的执行。|
|Backface Cull|具有背面剔除功能。|
|Viewport/Scissor Region|在图像上显示与视口和剪切区域相对应的彩色叠加层。|
|NaN/INF/-ve Display|将以灰度渲染图像（使用典型的亮度计算-点（col.xyz，float3（0.2126，0.7152，0.0722）.xxx），红色像素突出显示所有NaN，绿色像素突出显示所有无穷大，蓝色像素表示任何负值。请注意，在多通道纹理中仅一个或某些通道通过的情况下，该像素仍将突出显示（因此{0.5，-1.0，0.0}将突出显示蓝色）。|
|Histogram Clipping|将以红色突出显示当前黑点以下的任何值（作用于当前图片），并以绿色突出显示白点以上的任何值。|
|Clear Before Pass|为了使绘制结果容易看清，尤其是在混合且仅进行细微更改的情况下，当前目标在通道前被清除。如果当前的API没有传递的概念，则将其定义为具有相同渲染目标集的所有Drawcall。|
|Clear Before Draw|工作原理与上述"Clear Before Pass"相似，但在选择的绘制之前立即清除。|
|Triangle Size (Pass)|将显示网格中的像素区域中的三角形的可视化程度，该三角形在"通过"中覆盖了所选绘图，最多不超过4x4像素（16平方像素）。如果当前的API没有传递的概念，则将其定义为具有相同渲染目标集的所有Drawcall。|
|Triangle Size (Draw)|将显示与上述"Triangle Size (Pass)"选项类似的可视化效果，但仅限于当前的绘制调用。|

> 说明
>
> 在应用了图像控件后，这些覆盖层全部渲染。因此，范围控件，通道控件和自定义着色器不会影响覆盖。

要打开特定的纹理并观看Outputs区域，可以在右键中选中菜单"Open new Locked Tab"在新的标签页中打开它，也可以双击它，或按名称打开它。

## 像素上下文显示

默认情况下，像素上下文显示是纹理查看器右下方的一个小面板。

每当拾取像素时，其周围纹理的一小部分区域就会以最大缩放比例渲染到此面板，提供所选像素附近的一些背景信息，用于进行精细优化。

拾取后，可以使用键盘上的箭头键调整所选像素区域。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/fRFhBawKTqaNtVnY07YK8g/zh-cn_image_0000001050995973.png?HW-CC-KV=V1&HW-CC-Date=20260909T161738Z&HW-CC-Expire=31536000000&HW-CC-Sign=4EB3459EF24263B77321AE466E058A1DB4CC50F8B43DB7713ECE49861885D4E3)

选择要调试的绘图调用，就可以启动像素调试器，还可以启动"像素历史记录"视图，该视图显示自帧开始到当前选定事件以来纹理发生的所有修改。
