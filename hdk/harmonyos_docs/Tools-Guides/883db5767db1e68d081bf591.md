# GPU memory统计

1. 点击"File \> Open Capture"，打开rdc文件。
2. 点击"Window \> Statistics Viewer"，按照Textures和Buffers的memory占用大小进行排序展示。

   <br />

   ![](https://media:201778750903355448)

   <br />

3. 点击其中的资源链接，自动跳转到"Resource Inspector"页面。
