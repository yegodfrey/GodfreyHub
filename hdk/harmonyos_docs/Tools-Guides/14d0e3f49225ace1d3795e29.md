# Scan Kit手工转换指导书

## 开发准备

您若需要应用支持Scan Kit，必须完成接入准备，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-config-agc-0000001050043955)。

## FirebaseVision.getVisionBarcodeDetector

|Google API|To HMS API|
|:---------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|FirebaseVision. getVisionBarcodeDetector()|new [com.huawei.hms.ml.scan.HmsScanAnalyzer.Creator().create()](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/scan-analyzer-creator4-0000001050167915#section1671510413568)|
|FirebaseVision.getVisionBarcodeDetector (com.google.firebase.ml.vision.barcode.FirebaseVisionBarcodeDetectorOptions options)|new [com.huawei.hms.ml.scan.HmsScanAnalyzer.Creator().setHmsScanTypes(com.huawei.hms.ml.scan.HmsScanAnalyzerOptions options).create()](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/scan-analyzer-creator4-0000001050167915#section1671510413568) 说明：options可自动转化，入参复用即可。|

To HMS API方法示例：

```screen
HmsScanAnalyzerOptions options = new HmsScanAnalyzerOptions.Creator().create();
HmsScanAnalyzer analyzer = newHmsScanAnalyzer.Creator().setHmsScanTypes(options).create();
```
