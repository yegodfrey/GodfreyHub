# Kit集成向导

Coding Assistant支持切换中英文，默认为英文，您可通过以下方法进行切换。

1. 在工具栏中选择"HMS > Settings > Select Language"，进入"Coding Assistant Language Configuration"页面。
2. 在"Language"中进行更改。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174809.78883082834643882462216545439131:50001231000000:2800:0FBF3C4FBF5AE4C2CE3C28126098A34A0E9EDFDAB8AADD0CFA8548AD1EFA93E2.png?needInitFileName=true?needInitFileName=true)
3. 更改完成后，重新进入Coding Assistant即可生效。

Coding Assistant提供了各Kit开放能力的API接口和代码样例，方便您快速集成Kit能力。集成方法有如下两种：

* 支持场景直接集成，您只需要通过简单的拖拽场景卡片即可完成对应场景的集成。
* 支持通过简单的拖拽API接口的代码样例即可完成对应接口的调用。

同时，在Coding Assistant还针对特定的Kit，提供了特殊的优化和集成，当前包括：Analytics Kit和AI Tool，具体的集成方法请参见[Analytics Kit集成指导](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/analytics-0000001053422075)和[AI Tool](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/model-creator-0000001055213855)。
> 说明
>
> 在使用Coding Assistant调用各Kit前，请确保已按照[Configuration Wizard](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/config-wizard-0000001050059098)章节，完成对应Kit的环境设置。

## 场景集成

以下以Push Kit为例进行说明。

您可以通过"HMS > Coding Assistant"或者在工具栏中点击如下图标打开Coding Assistant，然后在Kit列表中点击"Push Kit"。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174809.69474903030235159935523432578887:50001231000000:2800:D0B02B1DF9FEFE349EB65FEDF3178C6F20A0CE3D4327E47C23A9C69B65412846.png?needInitFileName=true?needInitFileName=true "点击放大")

您需要调用某一个Push Kit的场景时，可以在场景列表中找到对应的场景卡片，然后将场景卡片拖拽到代码编辑区，如下图所示。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230320174810.70559520127803517586010388595335:50001231000000:2800:430EB219B540DB0E260B616E2FA40E7403D5E9ABE8FBF9309F446DCD534B329B.gif?needInitFileName=true?needInitFileName=true "点击放大")

当您直接拖动场景卡片时，工具会自动生成对应的Activity文件和XML布局文件，并在AndroidManifest.xml、项目级的build.gradle和应用级的build.gradle文件中写入配置信息和工程运行所需要的依赖。如果需要打开该Activity，需要您在代码中主动调用该Activity，完成后，您可以直接在设备中运行应用。
> 说明
>
> 场景集成拖拽当前只支持java，只支持部分Kit拖拽。

## API接口调用

对于不支持场景集成的Kit，您可以在对应的API接口列表中，点击某一个API接口进入详情页，然后选择拖拽的方式将接口对应的代码样例片段拖到代码中，这种方式需要您清楚需要拖拽代码的位置。同样的，工具会自动在项目级的build.gradle和应用级的build.gradle文件中写入工程运行所需要的依赖。
