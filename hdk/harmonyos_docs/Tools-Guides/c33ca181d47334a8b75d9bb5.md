# 裁剪关键帧

下面将采用OpenGL ES（Vulkan同样操作）的应用展示裁剪关键帧功能，包含裁剪和回放。主要功能体现在"Event Browser"窗口和"Texture Viewer"窗口，下图左侧是"Event Browser"，右侧是选中Draw的结果展示。

## 裁剪过程

1. 点击"裁剪"按钮，左键选中需要裁剪的Draw，可以选择单个、多个连续、多个不连续的Draw进行裁剪。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/mJhpANolSXyPXrG86cctEg/zh-cn_image_0000001681482569.png?HW-CC-KV=V1&HW-CC-Date=20260909T153801Z&HW-CC-Expire=31536000000&HW-CC-Sign=09A2AFC20290940687BADFDEA13F69F5C4A6617658F76BCB81F24A552075F6D2)

2. 再次点击"裁剪"按钮，对当前选中的Draw进行裁剪，弹出对话框选择保存文件的路径和名称，确认保存路径后，有弹窗提示建议在裁剪之前关闭设备上的所有后台进程，点击"OK"确认。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/zDGvr9BkTeOYuBDzs-3fsw/zh-cn_image_0000002245726582.png?HW-CC-KV=V1&HW-CC-Date=20260909T153801Z&HW-CC-Expire=31536000000&HW-CC-Sign=975A51BBF11B5C8F34F2E4A301B219BED3FC61B409EDEBE57B98AFD870314FA9 "点击放大") 说明
   >
   > 保存路径不能为磁盘根目录。

## 回放过程

1. 点击"File > Open Capture"，或者双击裁剪获得的rdc文件。
2. 打开裁剪获得的rdc文件，显示相关依赖资源与相关Draw。
