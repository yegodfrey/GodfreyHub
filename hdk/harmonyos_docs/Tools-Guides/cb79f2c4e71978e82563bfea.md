# 使用API事件书签

使用该功能需要获取至少一个rdc格式的文件，原有的rdc文件或者利用工具当场获取的rdc文件执行回放功能。文件的抓取与回放可以参见[抓帧](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/frame-capture-0000001050701440)。

API事件书签选项基于Event Browser功能，该功能可以标记EID，方便快速查找。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/AasUgnxsSfmTpg-072nVYQ/zh-cn_image_0000001050701514.png?HW-CC-KV=V1&HW-CC-Date=20260909T175938Z&HW-CC-Expire=31536000000&HW-CC-Sign=919C943379089C8322057B2F9A76D61D208B67900996E384DE6C0F5CB0140C7C) 按钮将允许将特定的EID加入书签中，快捷键是"Ctrl+B "。选择需要标记的EID，然后点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/xL9fBmhsRSeVpUvvUhN6nw/zh-cn_image_0000001051061486.png?HW-CC-KV=V1&HW-CC-Date=20260909T175938Z&HW-CC-Expire=31536000000&HW-CC-Sign=4157B1F1ABB3D76AE4CF96DC8D94C54AFAC23F11955597250DB8C11B66338FB5)按钮，或者使用快捷键"Ctrl+B "，如下图所示，点击Bookmarks处标记的编号即可跳转到对应内容。
