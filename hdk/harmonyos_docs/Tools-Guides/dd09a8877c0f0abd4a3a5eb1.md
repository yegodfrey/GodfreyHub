# Trace元素

trace被可视化为包含事件的时间轴，所有事件都被放置在水平轨道上。

轨道将相同上下文的事件组合在一起，上下文可以是单个执行线程，也可以是单个CPU核。

![](https://media:201778750889755161)

轨道主要包含两种类型的事件。

* 切片：表示嵌套的、有时间限制的操作。例如，切片可以覆盖函数执行的时间段，从网络加载文件所花费的时间，或者完成用户任务的时间。 ![](https://media:201778750889782162)

* 计数器：它是随时间变化的数值的快照。例如，可以记录进程在执行过程中的瞬时内存使用情况。 ![](https://media:201778750889813163)

线程和进程的系统标识符（例如pid、tgid、tid）可以在跟踪过程中被操作系统重用。这意味着它们不能作为唯一标识符。为了解决这个问题，Graphics Profiler对线程使用utid（唯一的tid），对进程使用upid（唯一的pid）。
