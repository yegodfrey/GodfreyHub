# Trace元素

trace被可视化为包含事件的时间轴，所有事件都被放置在水平轨道上。

轨道将相同上下文的事件组合在一起，上下文可以是单个执行线程，也可以是单个CPU核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/i1OBhOEyTKW8csExlE7Zwg/zh-cn_image_0000001791215194.png?HW-CC-KV=V1&HW-CC-Date=20261008T160207Z&HW-CC-Expire=31536000000&HW-CC-Sign=6BE7CFC4C66C451AAA181F2A06AE8D5553DC1180C63AAA5A82A828C0B7A72F18)

轨道主要包含两种类型的事件。

* 切片：表示嵌套的、有时间限制的操作。例如，切片可以覆盖函数执行的时间段，从网络加载文件所花费的时间，或者完成用户任务的时间。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/m1Tq4vDXQ8yvm2gSCeyIyw/zh-cn_image_0000001791055494.png?HW-CC-KV=V1&HW-CC-Date=20261008T160207Z&HW-CC-Expire=31536000000&HW-CC-Sign=A07CB64A988DC16DA38E1EED20356152959E4A7AA749D4F05C60D23DF27B11A5)

* 计数器：它是随时间变化的数值的快照。例如，可以记录进程在执行过程中的瞬时内存使用情况。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/OJGuL7pqSSC0Y0aHIDMaeQ/zh-cn_image_0000001837974633.png?HW-CC-KV=V1&HW-CC-Date=20261008T160207Z&HW-CC-Expire=31536000000&HW-CC-Sign=674318C583FC42FBB72B90D7C43718268F276169E1996F2F73D5CD9D6E89EA2B)

线程和进程的系统标识符（例如pid、tgid、tid）可以在跟踪过程中被操作系统重用。这意味着它们不能作为唯一标识符。为了解决这个问题，Graphics Profiler对线程使用utid（唯一的tid），对进程使用upid（唯一的pid）。
