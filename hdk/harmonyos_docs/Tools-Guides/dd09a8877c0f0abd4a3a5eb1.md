# Trace元素

trace被可视化为包含事件的时间轴，所有事件都被放置在水平轨道上。

轨道将相同上下文的事件组合在一起，上下文可以是单个执行线程，也可以是单个CPU核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/i1OBhOEyTKW8csExlE7Zwg/zh-cn_image_0000001791215194.png?HW-CC-KV=V1&HW-CC-Date=20260909T150318Z&HW-CC-Expire=31536000000&HW-CC-Sign=D6F905934F339A1EE4305682C9C41F0A83A5A914CB4D9B5AFCFD2AA965D05F09)

轨道主要包含两种类型的事件。

* 切片：表示嵌套的、有时间限制的操作。例如，切片可以覆盖函数执行的时间段，从网络加载文件所花费的时间，或者完成用户任务的时间。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/m1Tq4vDXQ8yvm2gSCeyIyw/zh-cn_image_0000001791055494.png?HW-CC-KV=V1&HW-CC-Date=20260909T150318Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2C476955CDB821AED9FC883F2EC431A2BCBD4EB7165A940089BD515EAD5F240)

* 计数器：它是随时间变化的数值的快照。例如，可以记录进程在执行过程中的瞬时内存使用情况。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/OJGuL7pqSSC0Y0aHIDMaeQ/zh-cn_image_0000001837974633.png?HW-CC-KV=V1&HW-CC-Date=20260909T150318Z&HW-CC-Expire=31536000000&HW-CC-Sign=3D992C42B301CC277B73A54F5269B5B3E73E5F2EAE93E4536F4C20AE4255CC46)

线程和进程的系统标识符（例如pid、tgid、tid）可以在跟踪过程中被操作系统重用。这意味着它们不能作为唯一标识符。为了解决这个问题，Graphics Profiler对线程使用utid（唯一的tid），对进程使用upid（唯一的pid）。
