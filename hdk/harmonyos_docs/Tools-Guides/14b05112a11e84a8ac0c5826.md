# GPU API Events

GPU API Events将图形和计算应用程序的执行流显示为OpenGL ES，Vulkan和OpenCL的API调用序列，必须选择应用程序并且仅支持可分析的应用程序。
> 说明
>
> HarmonyOS 5.0及以上版本设备不支持该监控项。

## Debug Regions

用户可以在API序列前后插入EXT_debug_marker、VK_EXT_debug_marker等API，从而形成一个Debug Regions区域，主要用于识别引擎定义的pass行为。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/bu_hYUdXSwyp2XWML-T5ew/zh-cn_image_0000001886136520.png?HW-CC-KV=V1&HW-CC-Date=20261008T171029Z&HW-CC-Expire=31536000000&HW-CC-Sign=631AD938ADD81498D380AC95B997ACCB3C88FDFF6A1C8B1AB107150FB57B2E59)

## CPU Frames

使用CPU Frames便于测量FPS和发现异常帧，可以查看构成CPU上每个图形帧的所有图形API。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/oOuzKjVPTaeoSuc9rwyuXw/zh-cn_image_0000001886296420.png?HW-CC-KV=V1&HW-CC-Date=20261008T171029Z&HW-CC-Expire=31536000000&HW-CC-Sign=3ADD3D149FD9F8BA23FFEBA2D20CC99210B16A9AF6FE471EA52438BA002367A2)

通过选择适当的类别，可以将API调用轨迹、Debug Regions和CPU Frames包含在trace中。
