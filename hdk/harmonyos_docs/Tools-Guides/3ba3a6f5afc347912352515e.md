# 设备端侧hap抓帧

> 说明
>
> 仅支持HarmonyOS 6.1以上版本设备使用该功能。

1. 进入工具安装目录"\Graphics Profiler\frame_profiler\plugins\ohos"，手动安装hap包 hdc install squid.hap。
2. 安装好hap包后，执行同级目录下脚本python3 squid_exec.py，选择1，输入要抓帧的应用包名。
3. 根据脚本完成操作后，手机上点开squid.hap，点击左上角选择你需要抓帧的应用，点击launch app，即可拉起，点击手机悬浮球capture抓帧，抓完帧之后，在工具UI界面，点击菜单栏tools→remote host manager，双击应用进程，会自动跳转到抓帧页面，在手机端抓到的帧会在预览窗口生成，可以右击进行保存，也可通过抓帧页面继续抓帧。

4. 抓帧结束，重新执行脚本python3 squid_exec.py，选择2，清空数据退出。

> 说明
>
> 若出现无法抓帧现象，请kill掉squid.hap进程，重新使用
