# Nearby Service手工转换指导书

#### 开发准备

您若需要应用支持Nearby Service，必须完成接入准备，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/config-agc-0000001050040578 )。

以下表格展示了Google API支持的AdvertisingOptions/DiscoveryOptions类与HMS支持的[BroadcastOption](https://developer.huawei.com/consumer/cn/doc/development/system-References/broadcastoption-0000001050132579)/[ScanOption](https://developer.huawei.com/consumer/cn/doc/development/system-References/scanoption-0000001050130634)类的差异点：

|DiscoveryOptions(com.google.android.gms.nearby.connection.Strategy strategy)|[com.huawei.hms.nearby.discovery.ScanOption build](https://developer.huawei.com/consumer/cn/doc/development/system-References/scanoption-builder-0000001050130636#section10513926113419)()|

#### AppMetadata类及AppIdentifier类

在Google API中AppMetadata类及AppIdentifier类为已废弃类。请参见[Connections类及其内部接口、抽象类](#section33534134157)中Connections类转换示例，先将使用到的已废弃AppMetadata类及AppIdentifier类及其相关代码升级到Google API提供的新API，然后使用工具转换插件即可。  

#### PayloadTransferUpdate类的构造方法

以下表格展示了Google API支持的PayloadTransferUpdate与HMS支持的[TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/development/system-References/transferstateupdate-0000001050132605)的差异点：  

|类型|Google API中的PayloadTransferUpdate|HMS中的TransferStateUpdate|
|:---------|:---------------------------------------|:-----------------------------|
|包路径|com.google.android.gms.nearby.connection|com.huawei.hms.nearby.transfer|
|内部静态final类|PayloadTransferUpdate.Builder（已废弃）|不支持|

Google API中PayloadTransferUpdate的内部静态final类PayloadTransferUpdate.Builder提供如下接口：  

|类型|Google APIs|
|:---|:-----------------------------------------------------------------------------|
|实例方法|PayloadTransferUpdate build()|
|实例方法|PayloadTransferUpdate.Builder setBytesTransferred(long)|
|实例方法|PayloadTransferUpdate.Builder setPayloadId(long)|
|实例方法|PayloadTransferUpdate.Builder setStatus(int)|
|实例方法|PayloadTransferUpdate.Builder setTotalBytes(long)|
|构造方法|Builder()|
|构造方法|Builder(com.google.android.gms.nearby.connection.PayloadTransferUpdate origin)|

如上表所示，Google API中的PayloadTransferUpdate支持Build模式。例如，在Google API中可通过以下代码构造PayloadTransferUpdate实例：

```
Long bytesTransferred = 10L;
Long payloadId = 123L;
int status = PayloadTransferUpdate.Status.SUCCESS;
Long totalBytes = 1000L;
PayloadTransferUpdate payloadTransferUpdate =
    new PayloadTransferUpdate.Builder().setBytesTransferred(bytesTransferred)
        .setPayloadId(payloadId)
        .setStatus(status)
        .setTotalBytes(totalBytes)
        .build();
```

PayloadTransferUpdate.Builder模式构造PayloadTransferUpdate实例的方式在Google API中已废弃，HMS不支持这种方式。存量代码在切换到HMS时，需要修改为：

```
Long bytesTransferred = 10L;
Long payloadId = 123L;
int status = TransferStateUpdate.Status.TRANSFER_STATE_SUCCESS;
Long totalBytes = 1000L;
TransferStateUpdate transferStateUpdate =
    new TransferStateUpdate(status, payloadId, totalBytes, bytesTransferred);
```

其中，Google API中的PayloadTransferUpdate与HMS中[TransferStateUpdate](https://developer.huawei.com/consumer/cn/doc/development/system-References/transferstateupdate-0000001050132605)的内部接口[Status](https://developer.huawei.com/consumer/cn/doc/development/system-References/tra-status-0000001050132607)区别如下：  

|类型|Google API中的PayloadTransferUpdate.Status|HMS中的TransferStateUpdate.Status|
|:---|:---------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口常量|public static final int CANCELED = 4|public static final int [TRANSFER_STATE_CANCELED](https://developer.huawei.com/consumer/cn/doc/development/system-References/tra-status-0000001050132607#section33064718192) = 4|
|接口常量|public static final int FAILURE = 2|public static final int [TRANSFER_STATE_FAILURE](https://developer.huawei.com/consumer/cn/doc/development/system-References/tra-status-0000001050132607#section10554193021817) = 2|
|接口常量|public static final int IN_PROGRESS = 3|public static final int [TRANSFER_STATE_IN_PROGRESS](https://developer.huawei.com/consumer/cn/doc/development/system-References/tra-status-0000001050132607#section678744610188) = 3|
|接口常量|public static final int SUCCESS = 1|public static final int [TRANSFER_STATE_SUCCESS](https://developer.huawei.com/consumer/cn/doc/development/system-References/tra-status-0000001050132607#section94355131713) = 1|

#### Connections类及其内部接口、抽象类

以下表格展示了Google API已废弃的Connections类及其内部接口、抽象类：  

|类型|Google API中的Connections|
|:------|:------------------------------------------|
|内部静态接口|Connections.ConnectionResponseCallback（已废弃）|
|内部静态接口|Connections.MessageListener（已废弃）|
|内部静态抽象类|Connections.ConnectionRequestListener（已废弃）|
|内部静态抽象类|Connections.EndpointDiscoveryListener（已废弃）|
|内部静态接口|Connections.StartAdvertisingResult|

请您先将使用到的已废弃Connections类及其内部接口、抽象类升级到Google API提供的新API（ConnectionsClient），然后使用工具转换插件即可。

以Google API中已废弃类Connections的startAdvertising接口为例，展示了将Connections及相关已废弃API升级到新的Google API或者修改为HMS的方法。  
例如，使用已废弃的Google API的代码如下所示：

```
final String localEndpointName = "Endpoint Name"; // 设备名称
String serviceId = "com.xxx.xxx.xxx"; // 建议使用App的包名作为serviceId
AppIdentifier appIdentifier = new AppIdentifier(serviceId);
List<AppIdentifier> appIdentifiers = new ArrayList<>();
appIdentifiers.add(appIdentifier);
AppMetadata appMetadata = new AppMetadata((appIdentifiers));
Long durationMillis = 1000L;
Connections.ConnectionRequestListener connectionRequestListener = new Connections.ConnectionRequestListener() {
@Override
    public void onConnectionRequest(String remoteEndpointId, String remoteEndpointName, byte[] handshakeData) {
        super.onConnectionRequest(remoteEndpointId, remoteEndpointName, handshakeData);
        // 添加接收到连接请求后的处理逻辑
    }
};
GoogleApiClient googleApiClient = new GoogleApiClient.Builder(this).addApi(Nearby.CONNECTIONS_API).build();
Nearby.Connections.startAdvertising(googleApiClient, localEndpointName, appMetadata, durationMillis, connectionRequestListener);
```

#### ConnectionsClient.getConnectionsClient方法

HMS通过[DiscoveryEngine](https://developer.huawei.com/consumer/cn/doc/development/system-References/discoveryengine-0000001050132591)和[TransferEngine](https://developer.huawei.com/consumer/cn/doc/development/system-References/transferengine-0000001050130658)两个类分别提供发现操作和传输操作相关API。Google API中的ConnectionsClient.getConnectionsClient方法的转换方法可参考如下表：  

|Google API中getConnectionsClient|HMS中getConnectionsClient|
|:-------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.google.android.gms.nearby.connection.ConnectionsClient getConnectionsClient(android.content.Context)|[com.huawei.hms.nearby.discovery.DiscoveryEngine getDiscoveryEngine](https://developer.huawei.com/consumer/cn/doc/development/system-References/nearby-0000001050130624#section6249205917599) (android.content.Context context); [com.huawei.hms.nearby.transfer.TransferEngine getTransferEngine](https://developer.huawei.com/consumer/cn/doc/development/system-References/nearby-0000001050130624#section07191349797) (android.content.Context context);|
|com.google.android.gms.nearby.connection.ConnectionsClient getConnectionsClient(android.app.Activity activity)|[com.huawei.hms.nearby.discovery.DiscoveryEngine getDiscoveryEngine](https://developer.huawei.com/consumer/cn/doc/development/system-References/nearby-0000001050130624#section1217685016812) (android.app.Activity activity); [com.huawei.hms.nearby.transfer.TransferEngine getTransferEngine](https://developer.huawei.com/consumer/cn/doc/development/system-References/nearby-0000001050130624#section732993431015) (android.app.Activity activity);|

使用Google API的代码如下所示：

```
public static final Map<String, ConnectionsClient> mConnectionsClients = new HashMap<>();
public ConnectionsClient getConnectionsClientSingleton(final String serviceId) {
    ConnectionsClient mConnectionsClient = mConnectionsClients.get(serviceId);
    if (mConnectionsClient == null) {
        mConnectionsClient = Nearby.getConnectionsClient(this);
        mConnectionsClients.put(serviceId, mConnectionsClient);
        }
    return mConnectionsClient;
    }
```

使用HMS API的代码如下所示：

```
public static final Map<String, TransferEngine> mTransferEngines = new HashMap<>();
public static final Map<String, DiscoveryEngine> mDiscoveryEngines = new HashMap<>();
public TransferEngine getTransferEngineSingleton(final String serviceId) {
    TransferEngine mTransferEngine = mTransferEngines.get(serviceId);
    if (mTransferEngine == null) {
        mTransferEngine = Nearby.getTransferEngine(this);
        mTransferEngines.put(serviceId, mTransferEngine);
    }
    return mTransferEngine;
}
public DiscoveryEngine getDiscoveryEngineSingleton(final String serviceId) {
    DiscoveryEngine mDiscoveryEngine = mDiscoveryEngines.get(serviceId);
    if (mDiscoveryEngine == null) {
        mDiscoveryEngine = Nearby.getDiscoveryEngine(this);
        mDiscoveryEngines.put(serviceId, mDiscoveryEngine);
    }
    return mDiscoveryEngine;
}
```

#### Messages.handleIntent方法

以下表格展示了Google API支持的Messages.handleIntent与HMS支持的[MessageEngine.handleIntent](https://developer.huawei.com/consumer/cn/doc/development/system-References/messageengine-0000001050130686#section13936130282)的差异点：  

|类型|Google API中的Messages.handleIntent|HMS中的MessageEngine.handleIntent|
|:--|:-------------------------------------|:------------------------------|
|包路径|com.google.android.gms.nearby.messages|com.huawei.hms.nearby.message|

两者只是类名不同，方法名和参数可以一一对应。

例如：在Google API中可通过以下代码调用Messages.handleIntent的方法：

```
handleIntent(android.content.Intent intent, com.google.android.gms.nearby.messages.MessageListener messageListener)
```

由于Messages类的方法handleIntent()在Google API中已废弃，存量代码在转换到HMS时，需要修改为：

```
handleIntent (android.content.Intent intent, com.huawei.hms.nearby.message.MessageHandler handler)
```
