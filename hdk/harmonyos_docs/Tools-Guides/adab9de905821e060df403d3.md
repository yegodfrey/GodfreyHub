# 卡片

#### 添加卡片

1. 选择新建卡片的入口。
   * 打开项目，菜单选择"文件 \> 新建卡片"。
   * 在左侧资源管理器中，在src文件夹上右键选择"新建卡片"。
2. 选择模板后，点击"下一步"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100010.35734483123282545888691187982133:50001231000000:2800:9ACB5C2EA6BCCCAC77E266C22BB6E76987E83964D291EFB19EAA4F342F93DDBD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3. 填写卡片相关信息，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100010.45560799893701630063784269961612:50001231000000:2800:1248C8978FC3A19C38AE27D50A82E165877F6B724C7AA4274BB2A2CA752CB94E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

4. 新建卡片成功后，可在 manifest.json 和 launch.json 文件中看到 card 的相关配置。

#### 基础样式库

basic.scss基础样式文件在卡片模板项目的路径：\\src\\common\\css\\basic.scss。

除了基础样式表basic.scss定义的样式变量，更加建议使用样式智能提示出来的"Hag"前缀的主题ID样式（涉及卡片字体大小，颜色，间距，圆角等等样式规则）来编写样式，以便于适配HAG卡片编写规则，避免卡片UI不适配EMUI的问题。

#### 智能提示

#### 样式属性\&样式值

输入样式关键字或按代码提示快捷键"Alt+/"，即可触发样式智能提示，提示项是当前卡片/组件所支持的样式。

在样式key后输入"："或按代码提示快捷键"Alt+/"，就会触发样式属性的值提示，提示项为当前卡片/组件所支持的值以及引入的变量。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100010.16354941870216736203326507147090:50001231000000:2800:7AC3A3446E956F55C41D69593AEF2387510D46B3DD12E68CC434E64B0AE00FDB.gif?needInitFileName=true?needInitFileName=true?needInitFileName=true)

#### 方法

长度/大小的样式的值最好引用 dpConvert 方法， 例如 font-weight、 margin、 border-radius、 padding等。

输入样式属性关键字后，再输入 dpConvert 部分关键字，即可触发 dpConvert 的方法提示项，方法的入参也可以是变量。

#### UX检查

打开卡片工程、打开卡片文件、拖拽组件、 编辑卡片或组件时， 都会实时触发卡片UX前端规范检查。  

#### 实时检查特性

* 定位提示 严重类错误以红色波浪线提示，警告类错误以绿色波浪线提示。

* 错误信息 鼠标悬浮于错误处，可提示具体错误信息和修正意见。"问题"面板显示所有打开文件的错误（所在文件、错误数量、错误信息和行列号）。

* 错误跳转 在"问题"面板，双击某个错误，即可打开错误所在文件，鼠标停留在错误位置。
