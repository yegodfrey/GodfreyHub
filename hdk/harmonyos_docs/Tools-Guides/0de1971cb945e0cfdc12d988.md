# 工具自动升级

1. 启动工具，进入欢迎页面，检测到存在新版本时，会出现"Update Now"更新按钮，点击更新按钮，进行版本更新。

   <br />

   ![](https://media:201778750889296150)

   已经是最新版本时，只会显示当前工具版本号信息。

   进入其他界面后，可以通过点击About页面的"Update New Version"进行版本更新。

   ![](https://media:201778750889336151)

   <br />

2. 下载过程中，会显示下载进度。

   <br />

   欢迎页面显示如下图：

   ![](https://media:201778750889381152)

   About页面显示如下图：

   ![](https://media:201778750889421153)

   <br />

3. 下载完成后，更新按钮自动变成安装按钮，点击进行安装。

   <br />

   欢迎页面显示如下图：![](https://media:201778750889472154)

   About页面显示如下图：

   ![](https://media:201778750889514155)

   <br />
