# 工具自动升级

1. 启动工具，进入欢迎页面，检测到存在新版本时，会出现"Update Now"更新按钮，点击更新按钮，进行版本更新。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/qLgTs-zFSNW5rYY933fzNA/zh-cn_image_0000002602651233.png?HW-CC-KV=V1&HW-CC-Date=20260909T182139Z&HW-CC-Expire=31536000000&HW-CC-Sign=298BE2E814B7909B9650C335DDDF48C0FEF1BEDAAE07DFC37CACCDEDBED67EC7)

   已经是最新版本时，只会显示当前工具版本号信息。

   进入其他界面后，可以通过点击About页面的"Update New Version"进行版本更新。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/RDX-Z0s1SHisE-rwauAj_w/zh-cn_image_0000002572170590.png?HW-CC-KV=V1&HW-CC-Date=20260909T182139Z&HW-CC-Expire=31536000000&HW-CC-Sign=D53570ACC870551CC8111E85862F4F725E921E7837786DC6086D92DEB8FE9442)

2. 下载过程中，会显示下载进度。

   欢迎页面显示如下图：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/gVTuUOQ9RMClzdtt3neKoA/zh-cn_image_0000002602766315.png?HW-CC-KV=V1&HW-CC-Date=20260909T182139Z&HW-CC-Expire=31536000000&HW-CC-Sign=01D505336BE28BE91A79584A62360763C5893AA7E6F4E4F26864C409BD56807A)

   About页面显示如下图：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/snL6u2sGQF2obbcNCbcL6w/zh-cn_image_0000002572011480.png?HW-CC-KV=V1&HW-CC-Date=20260909T182139Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB899BC512211725765B840FB2358B9CD74E71732E5E5B48597F5F437CD3EB03)

3. 下载完成后，更新按钮自动变成安装按钮，点击进行安装。

   欢迎页面显示如下图：![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/SOXhchGzQQeoUi0vzTaWAQ/zh-cn_image_0000002602766499.png?HW-CC-KV=V1&HW-CC-Date=20260909T182139Z&HW-CC-Expire=31536000000&HW-CC-Sign=364AEE153438D37D9E536658BB5596EB789E45F45C0C3FC3998E93B747A69511)
