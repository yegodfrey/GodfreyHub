# 工具自动升级

1. 启动工具，进入欢迎页面，检测到存在新版本时，会出现"Update Now"更新按钮，点击更新按钮，进行版本更新。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/qLgTs-zFSNW5rYY933fzNA/zh-cn_image_0000002602651233.png?HW-CC-KV=V1&HW-CC-Date=20261008T192311Z&HW-CC-Expire=31536000000&HW-CC-Sign=C23A42F620C01DEA0DBC394EB29AF0138CB3DDBC17EE602719B2D9988CE32D78)

   已经是最新版本时，只会显示当前工具版本号信息。

   进入其他界面后，可以通过点击About页面的"Update New Version"进行版本更新。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/RDX-Z0s1SHisE-rwauAj_w/zh-cn_image_0000002572170590.png?HW-CC-KV=V1&HW-CC-Date=20261008T192311Z&HW-CC-Expire=31536000000&HW-CC-Sign=1B72C8882DEBA2A0E918D6E93103DD8A096CF7ACCDD85E5C5CCEAA45C12B5926)

2. 下载过程中，会显示下载进度。

   欢迎页面显示如下图：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/gVTuUOQ9RMClzdtt3neKoA/zh-cn_image_0000002602766315.png?HW-CC-KV=V1&HW-CC-Date=20261008T192311Z&HW-CC-Expire=31536000000&HW-CC-Sign=CF65BEB941143908BEB0B0609DD59C59773E442523D6A456D73F947DEF5A05F1)

   About页面显示如下图：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/snL6u2sGQF2obbcNCbcL6w/zh-cn_image_0000002572011480.png?HW-CC-KV=V1&HW-CC-Date=20261008T192311Z&HW-CC-Expire=31536000000&HW-CC-Sign=B3A9DF2E22AEA68AEE280BB11F2D80F7172C76ABCA37C8FCFB39AEF7EB81B164)

3. 下载完成后，更新按钮自动变成安装按钮，点击进行安装。
