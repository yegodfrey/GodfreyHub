# 日志查看器

通过选择主菜单"Window > Diagnostic Log"，进入日志查看器页面，以查看错误操作打印的日志详细信息。进入日志查看器后如下图所示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/kN9td4l4QT-tHIO6z_V1KQ/zh-cn_image_0000001050701490.png?HW-CC-KV=V1&HW-CC-Date=20260909T153703Z&HW-CC-Expire=31536000000&HW-CC-Sign=35BEC96791F9B7A8D1C98A5A55873DAC09ED32F587104125C3F7671687534B7C)

|编号|功能说明|
|:----------------------|:------------------------------------------------|
|Follow new messages|点击后会锁定关注新消息，更新打印的日志。|
|Open in external editor|用记事本格式打开日志。|
|Save|用于保存记录的日志。|
|Clear|清空日志，想要查看清空前的日志可以点击"Open in external editor"进行查看。|
|Filter|筛选器，可以筛选不同进程的日志，日志的种类，以及通过表达式进行相应的筛选操作。|
