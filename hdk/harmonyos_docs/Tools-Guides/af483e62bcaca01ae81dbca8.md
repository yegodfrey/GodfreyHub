# Disc I/O Metrics

这些计数器显示已装载磁盘利用率的详细信息，例如在一段时间内读取或写入的字节数。这些信息可以帮助估计磁盘I/O操作是否会导致性能问题。

这些计数器从proc/diskstats系统文件轮询。  
![](https://media:201778750893268232)  
HarmonyOS 5.0及以上版本设备不支持该监控项。
