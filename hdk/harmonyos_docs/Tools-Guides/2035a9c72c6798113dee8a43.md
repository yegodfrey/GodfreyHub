# 创建场景

在打开HUAWEI Reality Studio时，会自动创建新场景，您也可以导入已编辑完成的3D场景文件或者其他模型继续编辑。

与场景相关的按钮在应用的上方。

功能包括：新建场景、导入、导出选中项、保存场景、场景另存为和场景预览。

#### 新建场景

当想要重新制作场景时，点击左上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150011.44827789334237096333184322181591:50520704031946:2800:7D484299573A07B653B0D2C7A7CA6F74266B530DACD7FE407022892BCDCD37BB.png?needInitFileName=true?needInitFileName=true)创建空场景。  

#### 导入

点击左上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150011.86280880405395647726649790530042:50520704031946:2800:F26A52AF441C7FBB86BE466DED4A14B190EC5FC97BE8C46BA86A7AA2E340AA54.png?needInitFileName=true?needInitFileName=true)可以导入已有的模型加载进入场景。  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150011.27573979058483945845790577246066:50520704031946:2800:E1918D84852F5AB70449779A83C52E98A2953AD2A9194878069017852A87494F.png?needInitFileName=true?needInitFileName=true)  
模型支持以下格式：

RSDZ、GLB、glTF 2.0及以上版本、OBJ。

不支持加载经过DRACO压缩过的glTF格式。  

#### 导出选中项

您可以选择部分节点导出为3D场景文件，文件格式可以选择RSDZ或GLB。

1. 在显示视图或场景资源管理器中点击选取模型。
2. 点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150011.47092496877192219688466167923311:50520704031946:2800:63DD400CF1F6E835F02CA474E54234B69D6F2C22E0A92FF1853C90A2AFF9F0F5.png?needInitFileName=true?needInitFileName=true)，导出模型。  

#### 保存场景

点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150011.83619832290955198246339596055569:50520704031946:2800:142A639B552F790BF9766D746487D0FCAB77C828715012F7C931F71D430ED8CA.png?needInitFileName=true?needInitFileName=true)将编辑好的场景保存成3D场景文件，文件格式可以选择RSDZ或GLB。若未输入过文件名，则提示输入文件名。若之前已经保存过场景，则以上一次输入的文件名覆盖保存。  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150012.40292516536476026312378762877288:50520704031946:2800:4647F84AC74BE4207A0A61D471786B5090DA1D97B7115EEA92CBA6B85BEC7A10.png?needInitFileName=true?needInitFileName=true)  
该功能只在PC版本可用。  

#### 场景另存为

点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150012.10849604438472175837520691332503:50520704031946:2800:EECB9E7A613EF5C88BAF331D28F024A26A27777FAFBA4AA99728588799AADF59.png?needInitFileName=true?needInitFileName=true)将当前场景存为新的3D场景文件，文件格式可以选择RSDZ或GLB。
