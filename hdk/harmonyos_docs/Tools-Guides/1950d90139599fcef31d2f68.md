# 页面

## 添加页面

1. 选择新建页面的入口。
   * 打开项目，菜单选择"文件 > 新建页面"。
   * 在左侧资源管理器中，在src文件夹上右键选择"新建页面"。
   * 点击"资源管理器"旁白的+，选择"新建页面"。
2. 在弹出窗口填写页面路径、页面文件名、选择页面分类，目前页面分六个类别，每个分类下面有不同的页面模板。比如：选择阅读分类，阅读下方有11个模板可供选择，默认选中第一个，点击左右的箭头，查看其它模板。选中一个模板，点击"高级选项"可选填其中参数。填写完毕后点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100011.08159451025978140542617674160397:50001231000000:2800:2AF1184694ECD0A8DE8C5918155990AC17861866AA38167CA9961A128C1D14F4.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
