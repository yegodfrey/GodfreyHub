# 连接调试设备

## 本地真机

### USB连接

**环境准备**

1. 请确保手机已经通过USB连接电脑，并打开"开发者模式"。具体操作请参照"[华为手机如何打开开发者选项](https://developer.huawei.com/consumer/cn/doc/quickapp-open-developer-option)"处理。
2. 请确认adb与手机连接成功。
   1. 打开终端Terminal。
   2. 执行 **adb devices** 命令。
      * 若 List of devices attached 下出现手机信息并且以device结尾，则说明adb已监控到手机。
      * 若List of devices attached 无信息输出，手机编号后结尾为offline，则表示adb没有与手机连接成功，此时进行调试、预览、inspect均会提示无法找到手机的错误。建议重启手机或者撤销USB的授权后重新插入手机。

**设备接入**

2. 选择调试的设备后，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100011.42581078647024450369941657209301:50001231000000:2800:FF2AD4B0B4D7665BDF613DD48A9B7FE3130D59B7CF86026637B99AB0393D962B.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

### 局域网连接

**环境准备**

1. 保证PC和手机处在同一局域网，如果有必要的话，需要关闭防火墙。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100011.93376725499979843122905428695889:50001231000000:2800:B0D259F18873727AB76B438BCA83E0136DFD8FBEF76F2A55450ED8C7F91C622C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2. 开启网络ADB端口（TV设备不需要操作）。
   1. 打开终端Terminal。
   2. 执行命令。

      ```screen
      adb usb
      adb tcpip 5555
      ```

   > 说明
   > * 5555为端口号，可修改为任意可用的端口。
   3. 命令执行完成，请拔掉数据线，断开PC和手机的连接。
3. 查找设备IP地址。 在手机中，选择"设置 > 系统 > 关于手机 > 状态信息"，查看"IP地址"，获取IPV4地址。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100011.72332696505791462500846607305091:50001231000000:2800:3326A06931D8F5404DB386DAE9968A492CCD1CD90A60255481A960BE80CB24D9.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

**设备接入**

1. 点击如下"运行"、"调试"、"检查"或者"无设备"，进入"选择运行设备"页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100011.97693403070135186529422431537503:50001231000000:2800:6A8047E3B11F1B7AB6C839BB1C6DCE02A158168A868D2CE831772B9615F786AB.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2. 选择"局域网连接"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100011.44000214035010256914921803468671:50001231000000:2800:B4FD4472123D8434E4F33E94A2D20D8FF617DFD387192B54721DE893FEFBB7C9.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3. 配置IP信息，点击"连接"。
   * 设备IP：通过局域网连接的设备IP地址，手工输入，格式为IP:Port，例如127.0.0.1:5555。
   * PC IP：PC的IP地址，IDE会自动获取填充。 注意
     >
     > 设备 IP与PC IP请务必保证在同一网段，且设备完成adb授权。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230510100011.45676100954821180644103372221015:50001231000000:2800:37EA0D5FA617327D0F21C840F6BEC5A68321E45B4BB8EB44A435E8038A40FB9A.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   设备连接信息会在IDE右下角弹出提示窗口，连接成功后会在**"** 选择运行设备**"**界面已连接区域显示设备信息。

通过不同连接方式**本地真机** **/局域网设备** **/远程真机**连接多个设备时，默认会使用第一个接入设备进行连接。

>
> 若勾选了"默认使用当前选择设备"，后续开发过程中会一直使用该设备进行开发调试，直到该设备断开连接才可重新选择。
