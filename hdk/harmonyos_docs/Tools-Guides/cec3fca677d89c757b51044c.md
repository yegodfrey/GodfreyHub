# GPU and Driver Events

用于监控命令缓冲生命周期、队列提交、任务调度及GPU执行过程中的关键性能指标，包括命令列表生命周期、队列提交与任务链关系、任务链依赖展示、命令列表依赖关系展示等。便于理解GPU任务瓶颈，以及具体Vulkan/OpenGL ES命令所处的命令缓冲区。
> 说明
>
> * Application to profile选择System tracing时，点击"Start Recording"后需要手动启动应用，才能采集到数据。
