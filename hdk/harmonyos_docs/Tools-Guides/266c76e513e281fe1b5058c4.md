# Wallet Kit手工转换指导书

**概述**

1. 在HMS中，优惠券、礼品卡、会员卡均对应[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象，不做区分。
2. [PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)采用[builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326#section17786343145011)模式，参数的设置均通过[builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326#section17786343145011)提供，需要在[builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326#section17786343145011)中设置好参数之后，再通过[build](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section1938620235212)()方法构建[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象，如下：

   ```screen
   PassObject loyaltyObject = PassObject.getBuilder().setSerialNumber("12345")
       .addImageList(new ArrayList<>())
       //... 其他设置由您根据情况自己选择添加
       .build();
   ```

3. [PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)的大部分属性都是用了通用的[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)和[CommonField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-commonfield-0000001051066296)接口，分别通过[PassObject.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375)的[addAppendFields](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section10602443175112)()方法和[addCommonFields](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section16610137145117)()方法进行设置，采用（key/label/value）的键值结构，不提供单独的get/set方法。其中Key值常用属性定义在[WalletPassConstant](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-constant-walletpasscontant-0000001050986377)类中。

## addInfoModuleDataLabeValueRow(LabelValueRow row)

LabelValue信息在HMS中，被合并到textData中。

To HMS API转换参考如下代码，将LabelValueRow对象中的LabelValue列表转换为HMS中的[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)列表，LabelValue中的label和value属性，分别赋值给[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)中的label和value属性，最后调用[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象的[addTextList](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section9425957155119)()方法，将[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)对象列表赋予[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象：

```screen
// 下面的row1/row2对应LabelValueRow中LabelValueLie表中的对象
AppendField row1= AppendField.getBuilder().setKey("uniqueKey1") // 此处key值可以随意指定，但必须保证在一个对象中是唯一的
    .setLabel("Next Reward") // label值对应LabelValue中的label
    .setValue("2 coffees")   // value值对应LabelValue中的value
    .build();
AppendField row2= AppendField.getBuilder().setKey("uniqueKey2")
    .setLabel("Member Since")
    .setValue("01/15/2013")
    .build();
ArrayList<AppendField> textList = new java.util.ArrayList<>();
textList.add(row1);
textList.add(row2);
PassObject.getBuilder().addTextList(textList);
```

## addImageModuleDataMainImageUri(UriData uriData)

To HMS API替换如下：

* 说明 参数类型为UriData的两个属性uri与description分别与HMS中[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)的属性value和label一一对应。把参数uriData转换成类型为[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)的image，key值用户可以自已指定，但不能重复。构建一个ArrayList<[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)> imageList，把image放入imageList中，最后通过[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)的[addImageList](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section310617530517)()方法把imageList赋给[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象。

* 代码示例

  ```screen
  UriData uriData = new UriData("www.huaweitest.com", "huawei net");// 此处new仅供示例用，实际代码中要取对应的UriData对象
  PassObject.Builder passBuilder = PassObject.getBuilder();
  ArrayList<AppendField> imageList = new ArrayList<>();
  AppendField.Builder image = AppendField.getBuilder();
  AppendField imageField = image.setKey("image" + image.hashCode())     
      .setValue(uriData.getUri())
      .setLabel(uriData.getDescription())
      .build();
  imageList.add(imageField);
  passBuilder.addImageList(imageList);
  ```

## addLinksModuleDataUri(UriData uriData)

Add HMS API和To HMS API请统一按如下指导转换。

会员卡、礼品卡、优惠券转换方法均相同，以会员卡为例说明：

将LoyaltyWalletObject中的：

```screen
public LoyaltyWalletObject.Builder addLinksModuleDataUri(UriData uriData);
```

按以下指导：

参数uriData 属性uri值类型目前可分为Nearby stores、Main page、Hotline三种类型，构建HMS中[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)对象时，对应HMS的key值常量为：

[WalletPassConstant.PASS_APPEND_FIELD_KEY_NEARBY_LOCATIONS](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-constant-walletpasscontant-0000001050986377#section928694441416)，

[WalletPassConstant.PASS_APPEND_FIELD_KEY_MAINPAGE](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-constant-walletpasscontant-0000001050986377#section1387119418143)，

[WalletPassConstant.PASS_APPEND_FIELD_KEY_HOTLINE](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-constant-walletpasscontant-0000001050986377#section1541512208152)。

HMS中的[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)对象的value可取参数uriData的uri值，Label值可取uriData的description值。

构建一个类型为[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)对象实例hotlineAppendField，放入List<[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)> appendFields中，最后通过[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)的[addAppendFields](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section10602443175112)()方法将appendFields赋给[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象。

Hotline示例代码：

```screen
PassObject.Builder passBuilder = PassObject.getBuilder();
ArrayList<AppendField> appendFields = new ArrayList<>();
String hotlineLabel = "hotline";
String hotlineValue = "4000";
AppendField hotlineAppendField = AppendField.getBuilder() 
    .setKey(WalletPassConstant.PASS_APPEND_FIELD_KEY_HOTLINE)        
    .setLabel(hotlineLabel)        
    .setValue(hotlineValue)        
    .build();
appendFields.add(hotlineAppendField);
passBuilder.addAppendFields(appendFields);
```

## addLocation(LatLng latLng)

To HMS API替换如下：

* 说明 参数类型为LatLng的两个属性longitude与latitude分别与HMS中[Location](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-location-0000001050706324)的属性longitude和latitude一一对应。把参数latLng转换成类型为[Location](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-location-0000001050706324)的location。构建一个ArrayList<[Location](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-location-0000001050706324)> locations，把location放入locations 中，最后通过[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象的[addLocationList](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section15729172818515)()方法将locations值赋给[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象。

* 代码示例

  ```screen
  LatLng latLng = new LatLng(22.545167,114.056641);// 此处new仅供示例用，实际代码中要取对应的LatLng对象
  PassObject.Builder passBuilder = PassObject.getBuilder();
  ArrayList<Location> locations = new ArrayList<>();
  Location location = new Location(String.valueOf(latLng.getLongitude()), String.valueOf(latLng.getLatitude()));
  locations.add(location);
  passBuilder.addLocationList(locations);
  ```

To HMS API替换如下：

* 说明 参数类型为WalletObjectMessage的两个属性body和header分别与HMS中[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)的属性value和label一一对应。把参数walletObjectMessage转换成类型为[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)的field，key值用户可以自已指定，但不能重复。构建一个ArrayList<[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)> messageList，把field放入messageList中，最后通过[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象的[addMessageList](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section5450164814519)()方法将messageList值赋给[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象。

  ```screen

      .setBody("Thanks for saving your gift card.")

      .setValue(walletObjectMessage.getBody())
  ```

## CreateWalletObjectsRequest.Builder build()

**Add HMS API**

调用build创建Request之前，需要执行以下步骤：

1. 您将PassObject对象转换成的json字符串发送到自己的服务器，并接收返回的JWE数据串。
2. 将示例代码中的getJweFromAppServer(passObjectJson)进行替换为从服务器获取的加密JWE。
3. 您拿到JWE后需要使用CreateWalletPassRequest.Builder的setContent()方法将数据传送给request。

会员卡、优惠券和礼品卡示例代码：

```screen
if (org.xms.g.utils.GlobalEnvSetting.isHms()) {
    String passObjectJson = ((com.huawei.hms.wallet
.pass
.PassObject) (wob.getHInstance())).toJson();  
    String jweString = getJweFromAppServer(passObjectJson);
    ((com.huawei.hms.wallet.CreateWalletPassRequest.Builder) (build.getHInstance())).setContent(jweString);
}
//wob是PassObject的对象实例。
//build是CreateWalletPassRequest的对象实例。
```

**To HMS API**

调用build创建Request之前，需要执行以下步骤：

1. 您将[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象转换成的json字符串发送到自己的服务器，并接收返回的JWE数据串。
2. 将示例代码中的getJweFromAppServer(passObjectJson)进行替换为从服务器获取的加密JWE。
3. 您拿到JWE后需要使用[CreateWalletPassRequest.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-createwalletpasss-0000001050145792)的[setContent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-createwalletpasss-0000001050145792#section83145512118)()方法将数据传送给request。

会员卡、优惠券和礼品卡示例代码：

```screen
PassObject passObject = new PassObject();  // 此处new仅供示例用，实际代码中要取对应的卡券PassObject对象
String passObjectJson = passObject.toJson();  
String jweString = getJweFromAppServer(passObjectJson);  
CreateWalletPassRequest.Builder builder =  CreateWalletPassRequest.getBuilder();
builder.setContent(jweString);
```

## GiftCardWalletObject.Builder build()、LoyaltyWalletObject.Builder build()和OfferWalletObject.Builder build()

您在创建GiftCardWalletObject之前，需要手动设置[PassTypeIdentifier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326#section558018250491)。[PassTypeIdentifier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326#section558018250491)的值为用户在AppGallery网站上注册WalletKit卡券服务时的服务号，示例代码中GiftCardWalletObject、LoyaltyWalletObject、OfferWalletObject的[PassTypeIdentifier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326#section558018250491)的值分别是："hwpass.type.giftcard.hmspublic"，"hwpass.type.loyalty.hmspublic"和"hwpass.type.offer.hmspublic"。

* Add HMS API替换 优惠券示例参考

  注释：wob是[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象的实例。


* To HMS API替换

  ```screen
  PassObject.Builder passBuilder = PassObject.getBuilder();
  passBuilder.setPassTypeIdentifier("hwpass.type.offer.hmspublic");
  ```

## setLoyaltyPoints(LoyaltyPoints loyaltyPoints)

To HMS API替换如下：

* 说明 构建一个[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)对象balance，key值为[PASS_APPEND_FIELD_KEY_POINTS](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-constant-walletpasscontant-0000001050986377#section61351323121518)（值为"points"），value和label值为loyaltyPoints对象中属性loyaltyPointsBalance的对象value值和label值。 构建一个ArrayList<[AppendField](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-appendfield-0000001050706322)> balanceList ，把balance 加入balanceList。最后通过[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象的[addAppendFields](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section10602443175112)()方法将balanceList 值赋给[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象。如果积分类型为货币时，还需要通过[PassObject.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375)的[setCurrencyCode](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-builder-0000001050986375#section68501355165019)()方法设置货币类型。

  > 说明
  >
  > 因为HMS中没有类与LoyaltyPointsBalance对应，所以需要在这里将LoyaltyPointsBalance中的label和Value数据赋值到HMS的[PassObject](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-hms-wallet-pass-passobject-0000001050706326)对象中。
* 代码示例

  ```screen
  LoyaltyPoints loyaltyPoints = LoyaltyPoints.newBuilder().build(); // 此处new仅供示例用，实际代码中要取对应的LoyaltyPoints对象
  PassObject.Builder passBuilder = PassObject.getBuilder();
  LoyaltyPointsBalance gBalance = loyaltyPoints.getBalance();
  int balanceType = gBalance.getType();
  String value = "";
  if (balanceType == LoyaltyPointsBalance.Type.getDOUBLE()) 
  {
      value = String.valueOf(gBalance.getDouble());
  } else if (balanceType == LoyaltyPointsBalance.Type.getINT()) {
      value = String.valueOf(gBalance.getInt());
  } else if (balanceType == LoyaltyPointsBalance.Type.getSTRING()) {
      value = gBalance.getString();
  } else if (balanceType == LoyaltyPointsBalance.Type.getMONEY()) {
      value = String.valueOf(gBalance.getCurrencyMicros());
      passBuilder.setCurrencyCode(gBalance.getCurrencyCode());
  }
  ArrayList<AppendField> balanceList = new ArrayList<>();
  AppendField balance = AppendField.getBuilder().setKey(WalletPassConstant.PASS_APPEND_FIELD_KEY_POINTS)  
      .setValue(value) 
      .setLabel(loyaltyPoints.getLabel())
      .build();
  balanceList.add(balance);
  passBuilder.addAppendFields(balanceList);
  ```

```screen
SimpleDateFormat format = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'");
```
