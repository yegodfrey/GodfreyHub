# Battery drain \& power rails

在HarmonyOS上，有捆绑的数据源，可以从设备电源管理单元检索电源计数器。此数据源要求设备上存在电源管理硬件。

现代智能手机配备了电源监控IC，能够测量流入和流出电池的电荷。观察整个设备（SoC、显示器、无线电和所有其他硬件单元的联合）从电池中消耗的总电荷和瞬时电荷。以下为简化框图。

![](https://media:201778750890286175)

剩余电池容量（以%为单位）。

剩余电池电量（以μAh为单位）。

瞬时电流（以微安μA为单位，通常是小时间窗口内的平均值）。

这些计数器的存在和分辨率取决于设备制造商。
