# API事件列表

API Inspector模块需要结合Event Browser功能使用 。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/QlQJ5NC-QOaKgsvVTtFRRw/zh-cn_image_0000001050741491.png?HW-CC-KV=V1&HW-CC-Date=20261008T174610Z&HW-CC-Expire=31536000000&HW-CC-Sign=E78156443D4912378C1A7830E3C1B90422DF95CAC78E950B8A3F988848021AF3)

1. 调出"Event Browser"与"API Inspector"界面。
2. 选中"Event Browser"中对应的"Event"，此时应该在"Texture Viewer"中回放一张rdc图片，否则此处没有数据。
3. 双击"API Inspector"界面中的"Event"，对应的信息会展开。
4. 查看各Event信息。

API Inspector详细介绍了当前Drawcall及当前Drawcall的所有API调用。

双击Callstack分隔符可以展开Callstack部分，然后以相同的方式折叠起来。打开后，可通过点击并拖动分隔符来调整其大小。

当调用堆栈尚未准备好显示时，本部分将显示No Callstack available。
