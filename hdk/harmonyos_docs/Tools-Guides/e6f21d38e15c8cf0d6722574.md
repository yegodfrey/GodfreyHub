# 动画制作

制作动画。点击动画列表，在右侧弹出属性栏上部点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150018.34338527037534860712245483173430:50520704031946:2800:C25E8F8C38D3E99C7C90231349B48F557A9015EF01E97F2CBE3E00E182997D85.png?needInitFileName=true?needInitFileName=true)，打开时间轴。点击时间轴的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150018.92978754309704760777525843410354:50520704031946:2800:1C72263FAE5AB26DEE32A6D42F984B1C3198D4F8BB989CC8B00773A219F5B033.png?needInitFileName=true?needInitFileName=true "点击放大")添加动画。在动画中我们制作了相机位移，灯光位移，序列帧图片由隐藏到显示的动作。具体动画制作流程请参见[动画制作流程](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/animation-procedure-0000001050162760)。

其中"Serial frame image"由隐藏到显示的功能，需要将"Serial frame image"的"显示"选框取消勾选，在时间轴第0帧点击红点添加关键帧，之后移动时间线到指定时间，将"Serial frame image"的"显示"选框勾选，再次添加关键帧。

动画制作完成，点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210701150018.35665124390745804365890083120767:50520704031946:2800:7AA6D49E871434441EB3E964140C2AB3F9B9F06F993F1BC433DCE467A4D4B0A7.png?needInitFileName=true?needInitFileName=true "点击放大")，命名为"animation1"。
