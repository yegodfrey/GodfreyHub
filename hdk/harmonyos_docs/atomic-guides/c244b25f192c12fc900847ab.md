# 下架服务卡片（FormKit）

1. 对于已通过审核、服务状态为"已上架"的FormKit卡，开发者可点击"下架"进行下架FormKit卡的操作。 ![](https://media:801788423687358609 "点击放大")

2. 下架后，FormKit卡状态由"已上架"变更为"已下架"，后续可进行编辑操作。 ![](https://media:801788423687411610 "点击放大")
