# 首次核准（备案）

在华为云核准（备案）系统中首次核准（备案）主体信息和元服务信息。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，填写主办单位信息、互联网信息，完成后点击"验证核准（备案）类型"，其中**"元服务包名"使用"com.atomicservice.***"格式的包名** 。在弹出的窗口中点击"下一步"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/S0Hy0G2cTH-Q2m0fpKdq_g/zh-cn_image_0000002446413690.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=3FA8C1B9C23AD7A339C58231F24E119B5B2227C21C611BC00B65BD36D2458CE3 "点击放大")
2. 在"主体信息"页面填写主办单位信息、负责人信息，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/14OUYx5eSjKsfYih7m_oyg/zh-cn_image_0000002275320622.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=086C6DAD21819DE1E637EADE61601FF4C6F8B60951884B4D074615D3B2912987 "点击放大")

3. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"；请确保"服务内容"所选内容与联盟的类目/标签信息一致（路径：[我的元服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myApp)-进入相应元服务-应用信息-应用分类）。

   在"备注"处，建议说明元服务具体内容，否则可能会被通信管理局驳回，在广东、江西、河南、福建、天津等地区需特别注意。

   **特别注意** ："元服务包名"处，**确保是包名**：com.atomicservice.XXXXXXXXXXXXXX 格式。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/Bi-AALG4RMaXHQGnslB8Tw/zh-cn_image_0000002479654937.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=FDEEA33770B7C6220B8A573F9F38C17925E3A609A060C135A40ECC00EDD34C3B "点击放大")

   请参考这个路径来获取包名：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/aOKVTMfGRk27auTNqsgEWg/zh-cn_image_0000002312412621.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=2DDFFB5607BBCECC3DDD74F13DCAF954C65CDE2A9FA7B1433B20F565488DABBB "点击放大")

4. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/kIwVsG6uTU2-li1HMt-iZQ/zh-cn_image_0000002275263808.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=7B8BD92EA02353480C78A13C500AA57ADAE83167A14D78B7DF3B9952ADBDCDC3 "点击放大")

5. 在"真实性核验"页面由互联网信息负责人进行人脸视频核验，完成后提交初审；其中"免下载App核验"方式可通过浏览器等扫码工具扫描核验二维码进行验证。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/SLjylR0tSVSc0iNTHxuSCw/zh-cn_image_0000002311309053.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=A2FBC7A69DE400CD07304D4C0C4527F4763B41AD7A0F15DAA357E086B6188A77 "点击放大")

6. 所有信息完成填写后，对内容进行预览确认并提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/LsIuxWeRQcOvxedFVg_h7Q/zh-cn_image_0000002275320626.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=D7E950C7655B38B2BA90AA1503CA27305C43513EC0A3F1E2629ABE34DA58E93A "点击放大")

7. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2/v3/T0AumoUIT0ulRWPDEjrEYQ/zh-cn_image_0000002309913429.png?HW-CC-KV=V1&HW-CC-Date=20261008T173323Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB9E1D54E3C01685D7354F74277FC20F256A7AF4C1FFC7E08C46B465F89D7B51 "点击放大")

8. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-service-filing-sms)。若初审被驳回，请点击"继续核准（备案）"修改信息后重新提交审核。
