# 批量导出门店

1. 在服务直达主界面，选择"门店管理"页签，根据门店状态或门店名称/编码筛选出需要导出的门店。 ![](https://media:801788423682189514 "点击放大")

2. 点击"导出"。
   * 没有勾选项时，点击"导出"可导出全部门店。
   * 存在已勾选的门店时，点击"导出"仅导出已勾选门店。

   ![](https://media:801788423682233515 "点击放大")
3. 导出完成后，点击"任务管理"，下载导出结果。 ![](https://media:801788423682276516 "点击放大")
