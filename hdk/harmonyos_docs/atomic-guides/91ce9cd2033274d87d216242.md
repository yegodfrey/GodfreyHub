# 新增互联网信息

在华为云核准（备案）系统中已核准（备案）的主体下新增元服务信息。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的核准（备案）"，右侧页面点击"新增互联网信息"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/zNQgVggGS_uH8Iwb4GAWXQ/zh-cn_image_0000002275263812.png?HW-CC-KV=V1&HW-CC-Date=20261008T155826Z&HW-CC-Expire=31536000000&HW-CC-Sign=DEBA11823379B2677334D79D064B8A10CE69471F3942337FA3D415DD6FF1D3F3 "点击放大")
2. 在"产品验证"页面填写元服务信息，完成后点击"验证"。在弹出的窗口中点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/qxn7aI_aTHqQY7Fel-6r2w/zh-cn_image_0000002479730361.png?HW-CC-KV=V1&HW-CC-Date=20261008T155826Z&HW-CC-Expire=31536000000&HW-CC-Sign=D9E24657DFA769B1B1C910BFA5C6038EDECBB1582162E7164AA870746A07CD76 "点击放大")

3. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料" ；请确保"服务内容"所选内容与联盟的类目/标签信息一致（路径：[我的元服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myApp)-进入相应元服务-应用信息-应用分类）。

   在"备注"处，建议说明元服务具体内容，否则可能会被通信管理局驳回，在广东、江西、河南、福建、天津等地区需特别注意。

   **特别注意** ："元服务包名/ID"处，**确保是包名**：com.atomicservice.XXXXXXXXXXXXXX 格式。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/mZvAs68uQlKGVV76UyyG2A/zh-cn_image_0000002275320630.png?HW-CC-KV=V1&HW-CC-Date=20261008T155826Z&HW-CC-Expire=31536000000&HW-CC-Sign=27D1ACC5BAE8C79641E5B54D9F7B2F2A9CD00666E0D58C1846448C156F292BED "点击放大")
4. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/mg5W-BO4RRi-z4p9krD1qQ/zh-cn_image_0000002309913433.png?HW-CC-KV=V1&HW-CC-Date=20261008T155826Z&HW-CC-Expire=31536000000&HW-CC-Sign=64CE3DA2E17B0A5A06A55A6BC3FC1941B178610FB4E0C04ECE7D13D3535F9B15 "点击放大")

5. 在"真实性核验"页面由互联网信息负责人进行人脸视频认证，完成后提交初审；其中"免下载App核验"方式可通过浏览器等扫码工具扫描核验二维码进行验证。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/5kRH2a5ORY2lMWihfbVdkg/zh-cn_image_0000002311314777.png?HW-CC-KV=V1&HW-CC-Date=20261008T155826Z&HW-CC-Expire=31536000000&HW-CC-Sign=06F48AEB1DD48D7BC7EC67E0BBABEC5B96A02B2279CEF9318A6A62CC9D020B40 "点击放大")

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。
7. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-service-filing-sms)。
