# 常见问题

#### 未配置业务域名导致页面白屏

按元服务生态要求，AtomicServiceEnhancedWeb组件针对在线网页访问添加了域名校验，需要先完成[业务域名配置](https://developer.huawei.com/consumer/cn/doc/atomic-guides/agc-help-harmonyos-business-domain)，才可正常访问。

页面白屏时，可通过下面方法排查是否域名校验拦截导致：

* 在日志中搜索关键字：DomainControl：
  * checkUrl日志为h5页面的业务域名校验结果，ret=true代表业务域名校验通过，ret=false代表业务域名校验未通过。
  * checkUrlBlockList日志为页面请求的图片/css/js/接口等网络资源校验结果，ret=true代表校验通过，ret=false代表被全局域名黑名单拦截，豁免管控开关对该类域名不生效。

```
[ASCF Main]: DomainControl --> checkUrl -> ret=true url=https://www.example.com/
[ASCF Main]: DomainControl --> checkUrl -> ret=true url=https://www.example.com/
[ASCF Main]: DomainControl --> checkUrlBlockList -> ret=true url=https://www.example.com/example.css
[ASCF Main]: DomainControl --> checkUrlBlockList -> ret=false url=https://www.example.com/example.js
```

#### 配置了业务域名页面还是白屏

按上面方法查看日志，过滤关键字DomainControl，检查是否被域名校验拦截。

被域名校验拦截：

* 检查访问的在线网页地址，只支持https协议，不支持http协议，不支持IP地址或localhost。
* 检查[业务域名配置](https://developer.huawei.com/consumer/cn/doc/atomic-guides/agc-help-harmonyos-business-domain)是否正确配置，包括：业务域名是否添加成功、是否已[下载配置文件](https://developer.huawei.com/consumer/cn/doc/atomic-guides/agc-help-harmonyos-business-domain#section47197261774)并放置到域名根目录下。
* 检查访问的在线网页地址域名前缀和配置的业务域名是否完全匹配。

未被域名校验拦截：

* 检查手机网络是否连通。
* 检查访问的在线网页地址是否可正常访问。
* 上面两项检查无误后，打开[调试工具](https://developer.huawei.com/consumer/cn/doc/atomic-faqs/faqs-technology-30)进行页面调试，检查是否页面js执行报错或页面网络请求失败。  

#### 本地调试如何跳过业务域名管控

访问rawfile下的本地网页，可以直接访问。

本地调试访问在线网页，若未配置业务域名，可以打开手机设置 -\> 系统 -\> 开发者选项 -\> 开发中元服务豁免管控的开关，打开后可跳过业务域名校验，直接访问在线网页。

如果开启了元服务豁免管控后，网页请求还是失败，参考[开启元服务豁免管控，元服务网络请求失败](https://developer.huawei.com/consumer/cn/doc/atomic-faqs/faqs-technology-70)。

说明

元服务上架前，需先完成业务域名配置，否则无法正常访问在线网页。

#### ArkTS和h5如何实现双向通信

ArkTS到h5通信：

* 方式一：[通过src传递参数](https://developer.huawei.com/consumer/cn/doc/atomic-guides/web-upgraded-to-atomicserviceweb#通过src传递参数)。
* 方式二：实时消息通信，下个版本开始支持，敬请期待。

h5到ArkTS的通信：

* 方式一：[通过路由传参](https://developer.huawei.com/consumer/cn/doc/atomic-guides/web-upgraded-to-atomicserviceweb#通过路由传参)。
* 方式二：实时消息通信，下个版本开始支持，敬请期待。  

#### Web组件的runJavaScript()、registerJavaScriptProxy()无法使用

当前暂不支持，可通过[ArkTS和h5如何实现双向通信](#arkts和h5如何实现双向通信)中的方式实现。  

#### 自定义协议不支持

当前只支持以下自定义协议，其它自定义协议暂不支持。

* tel协议：唤起系统拨号界面。
* mailto协议：唤起系统默认邮件客户端。
