# 生成元服务图标

DevEco Studio支持Image Asset功能，帮助开发者生成统一的元服务图标样式。
> 说明
>
> DevEco Studio 5.0.3.800及以上版本支持使用元服务图标生成能力。

1. 在工程中选中模块或文件，右键单击**New > Image Asset**，进入图标配置页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/71sAQst7R0Kr4jdRsklzEg/zh-cn_image_0000002152570048.png?HW-CC-KV=V1&HW-CC-Date=20261008T183148Z&HW-CC-Expire=31536000000&HW-CC-Sign=A323760AC2E71C3E983473A211A859DE15AA439F825D8D34D0833CB1133FBA24)

2. 在Path中选择本地图片路径。图片尺寸及要求如下：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/AkbyOsDyQ6CnTVHO4SwS4g/zh-cn_image_0000002188008905.png?HW-CC-KV=V1&HW-CC-Date=20261008T183148Z&HW-CC-Expire=31536000000&HW-CC-Sign=60BE28F0517F1ECB474A94029DBCDBEBD1BDA5A078842FEB68EB598FAD1F7C0E)
   * 图标格式：.png、.jpeg、.jpg格式的静态图片资源；
   * 图标尺寸：1024 x 1024 px （正方形）；
   * 图标背景：不透明；
   * 质量要求：图标内容需清晰可辨，避免存在模糊、锯齿、拉伸等问题。详见[元服务图标设计规范](https://developer.huawei.com/consumer/cn/doc/design-guides/ux-guidelines-overview-0000001900384976)。

3. 在预览界面可以配置图标颜色、名称、保存路径等。

   * **Color**：推荐使用的图标颜色。选择不同颜色，右边图标预览区域可查看相应的效果。
   * **Name**：生成的图标名称。
   * **Res Directory**：生成的512px*512px尺寸图标在工程中的保存位置。
   * **Save to**：生成的216px*216px尺寸图标需要指定本地文件夹的保存位置。后续在AppGallery Connect上架元服务时，需使用该图标。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/pa6SdaZcQd2pvyPDJ2Zpbg/zh-cn_image_0000002188087185.png?HW-CC-KV=V1&HW-CC-Date=20261008T183148Z&HW-CC-Expire=31536000000&HW-CC-Sign=16D97A5188DC13EE6B54AE275351234E66C8DF7933646965ACF0C12191584547)

4. 点击Finish，保存配置并在相应模块目录**src > main > resources > base > media**路径下生成元服务图标。可在模块级module.json5中的icon字段中配置元服务图标。
