# 批量任务管理

1. 进入"门店管理"页签， 点击任务管理。 ![](https://media:801788423689085640 "点击放大")

2. 可在此查询"门店导入/导出/修改/删除"的操作结果，并且能下载结果文件查看详情。  
   ![](https://media:801788423689110641)  
   导出时"导入成功"列对应导出成功数。

   ![](https://media:801788423689157642 "点击放大")
3. 回到门店管理页。

![](https://media:801788423689189643 "点击放大")
