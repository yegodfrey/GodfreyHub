# 批量任务管理

1. 进入"门店管理"页签， 点击任务管理。 ![](https://media:801788423687931620 "点击放大")

2. 可在此查询"门店导入/导出/修改/删除"的操作结果，并且能下载结果文件查看详情。  
   ![](https://media:801788423687957621)  
   导出时"导入成功"列对应导入成功数。

   ![](https://media:801788423688004622 "点击放大")
3. 回到门店管理页。 ![](https://media:801788423688033623 "点击放大")
