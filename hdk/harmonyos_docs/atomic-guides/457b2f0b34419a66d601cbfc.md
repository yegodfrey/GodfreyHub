# 转移核准（备案）

在华为云核准（备案系）统中将主体及主体下的互联网信息全部转移到目标账号下。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的核准（备案）"，右侧页面点击"转移核准（备案）"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/wXSa9F8OSnqoaIQI-9AAWQ/zh-cn_image_0000002309840357.png?HW-CC-KV=V1&HW-CC-Date=20260917T065300Z&HW-CC-Expire=31536000000&HW-CC-Sign=2A0609F3BE11440F9CE24409909A9D86CF9F93DC91A0E2B4CE03070281238BE9 "点击放大")
2. 在"转移核准（备案）"填写目标账号后，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/15313cooS2WTx-G_agPJYQ/zh-cn_image_0000002275320634.png?HW-CC-KV=V1&HW-CC-Date=20260917T065300Z&HW-CC-Expire=31536000000&HW-CC-Sign=EBD1D8FCEB3A1A228BB673AF319489D61D178EA4183C974A394D5F351D4D8208 "点击放大")

提交转移申请后需要几分钟才能转移成功，请耐心等待。
