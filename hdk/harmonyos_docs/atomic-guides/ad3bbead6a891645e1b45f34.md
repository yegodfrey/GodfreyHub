# 配置签名和指纹

请先参考" [元服务开发准备](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-dev-preparation) "章节，完成以下操作步骤：

1. 创建元服务、使用DevEco Studio创建元服务工程（如已完成，请跳过此步骤）。

2. 配置签名信息。针对开发调试场景，从DevEco Studio 26.0.0 Beta2版本开始，新增了更高效的自动签名方案，开发者可以选择以下其中一种方式进行调试阶段的应用签名。

   * [自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto)：

     元服务运行的HarmonyOS系统版本低于HarmonyOS 6.0.0(20)时，仅未成年人模式接口支持自动签名。

     元服务运行的HarmonyOS系统版本为HarmonyOS 6.0.0(20)及以上时，所有接口均支持使用自动签名方式进行配置。

     ![](https://media:801788423698469827)
   * [手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual)：

     所有接口均支持使用手动签名方式配置签名。
3. 添加公钥指纹。

   ![](https://media:801788423698494828)  
   发布阶段，请参考[发布应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app)，重新配置用于元服务发布的签名信息、添加公钥指纹（必选）。
   * 检查是否需要配置公钥指纹：元服务仅接入未成年人模式或compatibleSdkVersion\>=20不需要配置公钥指纹，其他场景均需配置。

     ![](https://media:801788423698677829)
   * 检查公钥指纹是否配置成功：请在[开发与服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject)中选择对应的项目和元服务，检查是否已成功配置该元服务的公钥指纹。

     ![](https://media:801788423698719830)
   * 公钥指纹最迟会在25小时后生效。

     （可选） 配置公钥指纹10分钟后，您可通过修改元服务工程 \> app.json5中的versionCode触发公钥指纹生效。
