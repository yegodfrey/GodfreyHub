# 媒体会话

元服务媒体会话的开发方式与应用媒体会话的开发方式相同，针对元服务，AVSession Kit（音视频播控服务）当前仅开放支持[使用投播组件AVCastPicker](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/distributed-playback-guide)。
