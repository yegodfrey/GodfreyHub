# 取消接入

取消接入将在工信部删除元服务在华为接入商的核准（备案）信息，若元服务还需使用，建议在新的接入商完成核准（备案）后再取消接入，否则元服务可能会被通管局清理。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的核准（备案）"，右侧页面选择"更多 > 取消接入"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/fhHD_mLlTfOEUojCASgigQ/zh-cn_image_0000002275263828.png?HW-CC-KV=V1&HW-CC-Date=20260917T065300Z&HW-CC-Expire=31536000000&HW-CC-Sign=48719D58DFD3833B2B70684D42011FB429D8406E5DAD2671831718037CB1DB48 "点击放大")
2. 在"取消接入"页面验证负责人的手机/邮箱，选择注销原因后点击"下一步，提交审核"，在弹出的"确认要取消接入互联网信息"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0a/v3/WYpwpEy3QR65dH4qfeDBSg/zh-cn_image_0000002309840369.png?HW-CC-KV=V1&HW-CC-Date=20260917T065300Z&HW-CC-Expire=31536000000&HW-CC-Sign=A93B4718061BB3CD3191DF30A7E1AABBED4C331D92DAECC5127B4E6138F6F064 "点击放大")
