# 1\. 接口定义  
  
        
      1. void HMSAgent.Pay.getProductDetails(ProductDetailRequest request, GetProductDetailsHandler handler);
    
    

# 2\. 接口描述  


此接口用于开发者从华为PMS系统获取商品详情，以保证和华为支付收银台显示的商品信息一致。请开发者避免从自有服务端获取商品信息，否则可能导致应用内商品价格和收银台价格不一致。

# 3\. 参数

成员名| 参数类型| 是否必填| 说明  
---|---|---|---  
request| ProductDetailRequest| 是| 查询商品请求参数  
handler| GetProductDetailsHandler| 是| 接口调用结果回调  
  
**表5-3    ProductDetailRequest说明**

参数| 类型| 是否必选| 描述  
---|---|---|---  
applicationID| String| 是| 应用ID。在华为开发者联盟上获取的AppID。  
requestId| String(0,32)| 是| 查询标识号。用于查询商品信息  
merchantId| String| 是| 商户id，来源：华为开发者联盟“移动应用详情页”的“支付ID”。  
productNos| String| 是| 商品No。  
需要获取价格信息的商品No列表，多个No以竖线分割，一次查询最多支持20个No。  
注意：所查询的productNo必须属于对应的packageName，且在应用内唯一。  
  
  


# 4\. 返回值  


查询结果通过GetProductDetailsHandler中的onResult方法回调
      
      1. public interface GetProductDetailsHandler{
        2.     /**
        3.      * 查询结果回调
        4.      * @param retCode 结果码
        5.      * @param productDetail支付结果信息
        6.      */
        7.     void onResult(int retCode, ProductDetailResult productDetail);
        8. }
    
    

回调参数包括retCode   和ProductDetailResult，retCode是查询结果的错误码，融合了各个阶段的错误码，如果只需要判断错误码可直接使用。retCode取值和意义参考“[retCode业务错误码说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiiap_api_reference_errorcode)”。

roductDetail是ProductDetailResult的实例，包含了查询结果信息，ProductDetailResult各字段意义如表5-4所示。

**表 5-4    ProductDetailResult说明**

名称| 类型| 说明  
---|---|---  
requestId| String| 商户订单号。开发者应用在发起支付请求前生成，用来唯一标识一次请求。  
该字段由字母和数字组成，必须在商户内唯一，用于唯一标识一个商户订单。  
productList| List<ProductDetail>| 成功商品信息列表，值为包含ProductDetail对象数组。  
failList| List<ProductFailObject>| 失败商品信息列表，值为包含ProductFailObject对象的N数组，其中ProductFailObject中的id为商品ID，code定义为PayStatusCodes，请参见“支付结果码建议处理方式”。  
  
**表5-5    ProductDetail说明**

名称| 类型| 说明  
---|---|---  
productNo| String| 商品No。  
microsPrice| long| 商品微单位价格。  
值为商品实际价格乘以1,000,000。例如某个商品实际价格是1.99美元，则该商品对应的微单位价格为：1.99*1000000       = 1990000。  
price| String| 商品展示价格。包含商品实际价格和货币单位，例如“$1.99”。  
currency| String| 币种，用于支付的币种，如USD、CNY、MYR。符合ISO       4217，默认CNY，参见：<http://www.iso.org/iso/home/standards/currency_codes.html>。  
country| String| 国家码，用于区分国家信息，如US、CN、MY，符合ISO       3166标准，默认CN，参见：<http://www.iso.org/iso/home/standards/country_codes.html>。  
productName| String| 商品名称。  
productDesc| String| 商品描述。  
  
**表5-6    ProductFailObject说明**

名称| 类型| 说明  
---|---|---  
productNo| String| 商品No。  
code| int| 错误码请参见“[业务错误码-表retCode说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiiap_api_reference_errorcode)”。  
msg| String| 错误描述。
