# 1\. 接口定义  
  
接口访问地址：[https://login.cloud.huawei.com/oauth2/v2/token](https://login.cloud.huawei.com/oauth2/v2/token)

消息流向：应用服务器-> oauth2服务器

# 2\. 接口描述

此接口为了获取访问的ACCESSTOKEN，ACCESSTOKEN是发送PUSH 消息的必须参数。  


接口请求报文样例：
      
      1. POST /oauth2/v2/token HTTP/1.1
        2. Host: Login.cloud.huawei.com
        3. Content-Type: application/x-www-form-urlencoded
        4. grant_type=client_credentials&client_secret=申请应用时获得的应用密钥&client_id=申请应用时获得的应用ID
    
    

  


# 3\. 参数

**表3-1 请求AccessToken参数列表**

字段| 是否可选| 意义  
---|---|---  
grant_type| 必选| 固定值“client_credentials”       
client_id| 必选| 申请应用时获得的应用 ID，对应华为开发者联盟网站申请应用的时候获取的AppID。  
client_secret| 必选| 申请应用时获得的应用密钥，对应华为开发者联盟网站申请应用的时候获取的AppSecret。  
scope| 可选| 以空格分隔的权限列表，若不传递此参数，默认权限包括（nsp.auth nsp.user nsp.vfs nsp.ping openpush.message）  
  
# 4\. 返回值

**表4-1 返回报文参数**

字段| 意义  
---|---  
access_token| 要获取的Access Token。  
expires_in| Access Token的有效期，单位：秒。     例：当前Access Token的有效期是1个小时，下发值为3600       
scope| Access Token的访问范围，即用户实际授予的权限列表（用户在授权页面时，有可能会取消掉某些请求的权限）。  
error| 错误码。详细含义请参见下面“HTTP协议错误码”和“业务级错误码”  
error_description| 错误描述信息，用来帮助理解和解决发生的错误。
