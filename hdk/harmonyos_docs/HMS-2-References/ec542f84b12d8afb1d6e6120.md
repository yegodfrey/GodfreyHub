# 1\. 接口说明

该接口为获取华为帐号用户信息接口。通过传入accessToken到华为服务器上获取华为帐号用户信息。包含用户名显示信息，OpenId，头像等。

为了方便客户端给用户显示帐号，以便用户每次进入时清楚当前登录的华为帐号，用户名不返回昵称，而是匿名帐号；只有客户端明确填写需要返回昵称时，才优先返回昵称。如果需要返回第3方帐号，则返回格式：第3方帐号昵称（第3方帐号昵称），例如：aaaa（QQ昵称）

# 2\. 使用方法

**请求**

  http请求方式：Post。  
  Content-Type: application/x-www-form-urlencoded  
  接口访问Url：<https://account.cloud.huawei.com/rest.php?nsp_svc=GOpen.User.getInfo>

请求参数：

参数| 是否必选| 类型| 说明  
---|---|---|---  
appid| 是| String| 应用的appID。  
access_token| 是| String| AccessToken。  
getNickName | 否| int| 是否优先返回昵称0否（缺省） 1是  
  
**响应**

  Content-Type: text/plain; charset=UTF-8  
 响应返回值：

参数| 类型| 是否必选| 说明  
---|---|---|---  
openID| Str‍ing| 是| 用户openID。  
displayName| String| 否| getNickName为0或者不传，按照：手机帐号（带星号）、邮箱帐号（带星号）、老帐号（带星号）、昵称（空，缺省值除外）、第三方昵称、昵称（缺省值）的先后顺序返回；getNickName为1，按照：昵称（空，缺省值除外）、第三方昵称、昵称（缺省值）、手机帐号（带星号）、邮箱帐号（带星号）、老帐号（带星号）的先后顺序返回。  
headPictureURL| String| 否| 用户头像Url。
