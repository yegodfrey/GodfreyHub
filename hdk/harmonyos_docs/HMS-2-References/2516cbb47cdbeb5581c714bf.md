# 1\. 接口定义  
      
    
    void HMSAgent.Pay.productPay(ProductPayRequest requ, final ProductPayHandler handler)；

# 2\. 接口描述

开发者在华为PMS创建商品后，使用此接口调用华为支付收银台，显示商品、价格和支付方式，消费者在收银台里输入支付密码后，可以购买商品或订阅服务。  
华为会根据国际汇率变动进行商品价格档调整，为了保证应用内商品价格显示一致，请开发者同时使用[getProductDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiiap_api_reference_oversea_c1)接口获取商品详情，避免从自有服务端获取价格，以免在汇率变动价格调整时，导致价格显示不一致。  
支付接口的接入详见[开发指南](https://developer.huawei.com/consumer/cn/service/hms/catalog/huaweiiap_oversea.html?page=hmssdk_huaweiiap_devguide_oversea)，如果开发者未按接入规范导致的消费者投诉或经济损失，由开发者自行承担。  
举例：某应用使用华为PMS定价系统，商品定价选择档位1，即0.99美元对应6.00元人民币，2019年1月，因美元对人民币汇率变动，PMS调整定价档位1，调整为0.99美元对应7.00元人民币。此时，如果开发者同时使用getProductDetails和productPay接口，可以保证应用内价格同步显示为7元人民币，如果需要，开发者也可以在PMS里调整商品价格档。

sign                      |  String                      |  是 |  否 |  1、取相关参数字段，按参数名的ASCII码的增序排序，若遇到相同首字母，则看第二个字母，以此类推。  
【注意】参与签名的参数原则如下：  
a）所有ProductPayRequest携带，标识为“参与签名”且参数值不为null或者“”的参数必须参与签名，签名时参数值必须与ProductPayRequest传递的保持一致。  
b）sign参数不参与签名。  
2、排序完成之后，再把所有参数名和参数值的键值对以“&”字符连接起来，得到的字符串即为待签名串。  
3、将待签名字符串使用RSA私钥进行签名，得到的字符串即为sign参数的值。                       
  
# 4\. 返回值

支付结果通过GetProductDetailsHandler中的onResult方法回调
    
    
    public interface GetPurchaseInfoHandler
    {
        /**
         * 查询结果回调
         * @param retCode 结果码
         * @param purchaseInfo查询结果信息
         */
        void onResult(int retCode, PurchaseInfoResult purchaseInfo);
    }

回调参数包括retCode       和payInfo，retCode是查询结果的错误码，融合了各个阶段的错误码，如果只需要判断错误码可直接使用。retCode取值和意义参考“[retCode业务错误码说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiiap_api_reference_errorcode)”。

payInfo是ProductPayResultInfo的实例，包含了支付结果信息，ProductPayResultInfo各字段意义如表5-8所示。
