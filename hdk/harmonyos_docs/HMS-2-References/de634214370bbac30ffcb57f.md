# 接口功能

该接口用于开发者服务器根据accessToken从华为服务器获取用户的华为帐号信息，包括用户openId、用户昵称、用户头像等。

# 调用场景

当应用调用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口完成华为帐号登录授权后，如果开发者对用户唯一标识安全性要求较高，不能在应用客户端保存用户的openId，则不能直接获取signIn接口返回的openId。应用客户端需要先获取signIn接口返回的accessToken并传递给应用服务端，应用服务端再根据accessToken调用此接口从华为服务器直接获取用户的openId。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 开发者服务器->华为服务器  
接口URL| https://account.cloud.huawei.com/rest.php?nsp_svc=GOpen.User.getInfo  
数据格式| 请求：Content-Type:  application/x-www-form-urlencoded  
响应：Content-Type:  text/plain  
  
# 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
appid| M| string| 应用ID，在创建应用后由华为开发者联盟为应用分配的唯一标识。应用ID的查询方法请参见[查询应用ID](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_queryappid)。  
access_token| M| string| 用户的accessToken，调用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口时返回给应用客户端。**注意** ：accessToken有有效期，如果应用发现accessToken已失效（NSP_STATUS=6），需要再次调用signIn接口重新获取accessToken。  
getNickName| O| int| 返回参数中的displayName是否优先返回用户昵称。  
取值范围：  
● 0：不优先返回用户昵称。按照手机帐号（带星号）、邮箱帐号（带星号）、老帐号（非邮箱、非手机帐号，带星号）、昵称（空，缺省值除外）、第三方昵称、昵称（不设置昵称时的缺省值）的优先级返回。  
● 1：优先返回用户昵称。按照昵称（空，缺省值除外）、第三方昵称、昵称（不设置昵称时的缺省值）、手机帐号（带星号）、邮箱帐号（带星号）、老帐号（非邮箱、非手机帐号，带星号）的优先级返回。  
如果不传该参数，默认值为0。  
为了方便应用客户端给用户显示帐号，以便用户每次进入时清楚当前登录的华为帐号，可以将此参数传入0或不传该参数，优先获取用户的华为匿名帐号信息而不是用户昵称。  
  
# 返回参数

参数名称| 必选(M)/可选(O)| 类型| 参数含义  
---|---|---|---  
openID| M| string| 应用内用户的唯一标识，由应用的服务端保存。  
displayName| M| string| 根据getNickName参数指定的优先级，返回用于在应用客户端展示的用户名。说明：第三方昵称的格式为“第三方帐号昵称（第三方名称+昵称）”，例如“aaa（QQ昵称）”。  
headPictureURL| O| string| 如果用户的华为帐号设置了头像，则返回头像的url，否则不返回该参数。  
  
# 返回码

返回码在响应消息头部的NSP_STATUS字段，错误描述为JSON格式。

错误码| 错误描述| 错误原因  
---|---|---  
102| {"error":"invalid  session"}| accessToken格式不合法，如没有urlencode。  
6| {"error":"session  timeout"}| acessToken过期。  
105| {"error":"param  error"}| 参数错误，请检查请求参数格式是否正确。  
70001201| {"error":"getNickName:  Integer value should between 0 and 1"}| getNickName值非法，只能传入0或1。  
70001401| {"error":"system  error"}| 系统错误，请联系华为技术支持处理。
