# 1\. 接口定义  
        
      1.   void HMSAgent.Push.enableReceiveNotifyMsg(boolean enable, EnableReceiveNotifyMsgHandler handler);
    
    

  


# 2\. 接口描述

透传消息指华为PUSH服务收到消息后透传给开发者应用处理的消息。  
开启、关闭Push透传消息，在sharepreference文件里保存boolean变量，接收消息后若为关闭则丢弃。若不调用该方法则默认为开启。

# 3\. 参数

参数名| 参数类型      | 是否必选   | 说明  
---|---|---|---  
enable| boolean| 必选| ●  true：开启透传消息  
●  false：关闭透传消息  
handler| EnableReceiveNormalMsgHandler| 可选       | 接口调用回调，可传null  
  
# 4\. 返回值

HMS SDK会通过EnableReceiveNormalMsg的onResult方法返回请求的结果。

**表 4-1 onResult()方法参数说明**

参数名| 参数类型      | 说明  
---|---|---  
retCode     | int       | 结果返回码。具体的状态码请参见“表4-2 状态码说明”。    
  
  


**表4-2 状态码说明**

类型     | 返回码     | 意义     | 处理方式       
---|---|---|---  
通用错误码     | 参见“[通用错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweipush_api_reference_errorcode)”。       
业务错误码     | 0     | 成功     | -
