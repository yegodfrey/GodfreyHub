# 1\. 接口定义  
  
接口访问地址：https://api.push.hicloud.com/pushsend.do?nsp_ctx=%7b%22ver%22%3a%221%22%2c+%22appId%22%3a%2210923253325%22%7d

其中nsp_ctx为url-encoding编码，解码后为： nsp_ctx={"ver":"1", "appId":"10923253325"}  
ver：用来解决大版本升级的兼容问题;  


appId：用户在联盟申请的APPID;     

消息流向：应用服务器->PUSH服务器

# 2\. 接口描述

此接口用来发送PUSH消息。  


接口请求报文样例：
      
      1. POST https://api.push.hicloud.com/pushsend.do? nsp_ctx=%7b%22ver%22%3a%221%22%2c+%22appId%22%3a%2210923253325%22%7d
        2. Content-Type: application/x-www-form-urlencoded
        3. access_token=accessToken&
        4. nsp_svc=openpush.message.api.send&
        5. nsp_ts=1472020575&
        6. device_token_list=%5B%2200000000000000000000000000000000%22%2C%2200000000000000000000000000000000%22%5D&
        7. payload=JSON_FORMAT_STRING&
        8. expire_time=2013-09-30T19%3A55
    
    

各参数意义参考表3-1 Send push message 请求参数列表。

# 3\. 参数

**表3-1 Send push message 请求参数列表**  


参数名称| 是否必选| 描述  
---|---|---  
access_token| 必选| 使用OAuth2进行鉴权时的AccessToken。  
nsp_svc| 必选| 本接口固定为openpush.message.api.send。  
nsp_ts| 必选| 服务请求时间戳，自GMT 时间 1970-1-1 0:0:0至今的秒数。如果传入的时间与服务器时间相差5分钟以上，服务器可能会拒绝请求。  
device_token_list| 必选| JSON数值字符串，单次最多只是100个。例如(未编码前)：    ["12345xxxxxxxxxxxxx23456","2234567xxxxxxxxxx123456","086200503xxxxxxxxxxxxxxx300CN01"]  
expire_time| 可选| 格式ISO 8601[ **格式为：yyyy-MM-dd'T'HH:mm:ssXXX**]：2013-06-03T17:30，采用本地时间精确到分钟。此值为发出去消息的超期时间，即：如果用户没有在线，此消息会保存到PUSH服务器的时间。  
payload| 必选| 描述投递消息的JSON结构体，描述PUSH消息的：类型、内容、显示、点击动作、报表统计和扩展信息具体参考下面的详细说明。  
  
**表3-2 Payload 说明**  


参数名称| 类型| 父项目| 是否必选| 描述  
---|---|---|---|---  
hps| JSON Object|   
| 必选| 华为Push消息总结构体  
msg| JSON Object| hps| 必选|     PUSH消息定义。包括： 消息类型type 消息内容body 消息动作action  
type| Integer| msg| 必选| 取值含义和说明：1 透传异步消息3 系统通知栏异步消息注意：2和4以后为保留后续扩展使用  
body| JSON Object/String    | msg| 必选| 消息内容。注意：对于透传类的消息可以是字符串，不必是JSON Object。  
content| String    | body| 必选| 消息内容体  
title| String    | body| 必选| 消息标题  
action| JSON Object    | msg| 可选| 消息点击动作  
type| Integer    | action| 可选|  1 自定义行为：行为由参数intent定义2 打开URL：URL地址由参数url定义3 打开APP：默认值，打开App的首页注意：富媒体消息开放API不支持。  
param| JSON Object    | action| 可选| 关于消息点击动作的参数  
intent | String    | param| 可选| Action的type为1的时候表示自定义行为。  
开发者可以自定义Intent，用户收到通知栏消息后点击通知栏消息打开应用定义的这个Intent页面，该过程通过context.startActivity(intent)实现，具体代码如下：  

      
      1. Intent intent = new Intent(Intent.ACTION_VIEW);
        2. intent.setData(Uri.parse("unitehnreader://nativepage/book/detail?bid=357735?closeback=1&startinner=0"));
        3. intent.addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP); 
        4. String intentUri = intent.toUri(Intent.URI_INTENT_SCHEME); 
        5. Log.d("intentUri", intentUri);
    
    

其中intent.addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP);是应用必须添加的选项，如果不添加该选项有可能会显示重复的消息，其他为应用自己的配置项。生成的intentUri字符串即为intent参数需要填写的值。  
url| String    | param| 可选| Action的type为2的时候表示打开URL地址  
appPkgName| String    | param| 可选| 需要拉起的应用包名，必须和注册推送的包名一致。  
ext| JSON Object    | hps| 可选| 扩展信息，含BI消息统计，特定展示风格，消息折叠。  
biTag| String    | ext| 可选| 设置消息标签，如果带了这个标签，会在回执中推送给CP用于检测某种类型消息的到达率和状态。    注意：BigTag不能携带下面几个保留字符：逗号‘，’，竖线‘|’，长度不能超过100个字符。      
customize| JSON Object    | ext| 可选| 用于触发onEvent点击事件，扩展样例：[{"season":"Spring"},{"weather":"raining"}]      
说明：这个字段类型必须是JSON Array，里面是key-value的一组扩展信息。      
badgeAddNum    | String    | ext    | 可选    | 应用角标累加数字非应用角标显示数字，大于0小于100的正整数。      
badgeClass    | String    | ext    | 可选    | 桌面图标对应的应用入口Activity类    例如“com.test.badge.MainActivity”

# 4\. 返回值

**表4-1 返回报文参数**  


字段| 描述  
---|---  
code| 错误码，详见 表5-3。  
msg| 错误码描述。  
requestId| 请求标识，由PUSH服务器唯一分配。  
ext| 扩展信息(暂未使用)。

# 5\. 错误码说明

**表5-1 HTTP协议错误码**  


错误码| 描述  
---|---  
200| 成功  
500| 服务器系统错误  
503| 流量控制错误，发送流量过高  
  
**表5-2 系统级错误码(通过扩展HTTP协议头 NSP_STATUS)**  


错误码| 取值描述  
---|---  
6| session过期  
102| 无效的SESSION_KEY  
105| 参数错误  
111| 系统、服务处理忙  
112| 找不到对应服务  
113| 请求服务失败  
114| 服务不可达、无路由  
199| 未知错误  
403| 无权限  
  
**表5-3 应用级错误码**  


结果码| 描述  
---|---  
80000000| 成功  
80100000| 参数检查错误  
80100002| 不合法的token列表  
80100003| 不合法的payload  
80100004| 不合法的超时时间  
80100012| 缓存类型设置错误  
80100013| 缓存重发参数设置错误  
80300002| 无权限下发消息给参数中的token列表  
80300004| 认证类错误  
80300005| 认证类错误(本地配置的组和请求的组不一致)  
80300007| 认证类错误(请求中所有的TOKEN都是非法TOKEN)  
80300008| 认证类错误(请求消息体过大)  
80300010| 认证类错误(TOKEN数量过大)  
81000001| 未知错误
