# 1. 接口功能

应用调用此接口可以向华为游戏中心申请注册硬件开放能力。

# 2. 调用场景

在应用需要使用以下能力前，需要调用本接口先注册，只有注册通过的应用才可以建立游戏和手机系统之间的通讯机制。  
● 查询设备运行温度，主动调整适配设备状态，从而保障用户的流畅体验。  


● 向OS输入运行场景，系统调控资源适配游戏场景，从而保障用户的流畅体验。

# 3. 接口约束

● 在调用本接口前开发者必须先向华为游戏中心提交开放硬件能力申请并通过审核。  
合作伙伴提交权限申请邮箱：game.business@huawei.com，华为游戏中心在3个工作日内回复。  
● 本接口只支持在中国大陆地区发布的应用。  


● 本接口只支持特定的华为手机（目前支持EMUI8.2及以上版本），并且HMS Core的版本需要大于2.6.1。

# 4. 调用方法
      
      1. HMSAgent.Game.registerHardwareCapability(RegisterHardwareCapabilityHandler handler);
    
    

# 5. 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
handler| M| RegisterHardwareCapabilityHandler| 接口调用后的回调结果，注册结束后通过此回调实例回调给应用。回调结果中包含的具体参数参见结果回调。  
  
# 6. 结果回调
      
      1. public interface RegisterHardwareCapabilityHandler{ 
        2.         /** 
        3.         * 结果回调 
        4.         * @param retCode 返回码 
        5.          */ 
        6.        void onResult(int retCode); 
        7. }
    
    

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
retCode| M| int| 回调结果中的返回码，应用可以根据返回码判断注册是否成功或失败后如何处理，具体返回码处理参见返回码。  
  
# 7. 返回码

类型| 返回码常量| 返回码值| 返回码说明| 处理建议  
---|---|---|---|---  
通用返回码| 参见[通用返回码](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_errorcode)。  
业务返回码| GameStatusCodes.GAME_STATE_SUCCESS| 0| 注册成功。|   
GameStatusCodes.GAME_STATE_REGISTER_FAIL| 7011| 注册失败。| 只有特定特备才支持该功能。（目前支持EMUI8.2及以上版本），并且华为移动服务的版本需要大于2.6.1。
