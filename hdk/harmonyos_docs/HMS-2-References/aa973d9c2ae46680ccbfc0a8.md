# 1\. 接口定义  
        
      1.     void HMSAgent.Push.deleteToken(String token,DeleteTokenHandler handler) ;
    
    

  


# 2\. 接口描述

应用调用注销TOKEN接口成功之后，客户端就不会再接收到PUSH消息。  
建议APP集成时暂时不要依赖deleteToken接口；如果应用要实现注销TOKEN后不接收PUSH消息，需要自行上报失效TOKEN到应用自己的服务器，并且在推送消息时判断是失效TOKEN就不进行推送。

  


# 3\. 参数

参数名                 | 参数类型              | 是否必选   | 说明                   
---|---|---|---  
token                 | String | 必选          | 要注销的push token。                   
handler| DeleteTokenHandler| 可选          | 接口调用回调，可传null。
