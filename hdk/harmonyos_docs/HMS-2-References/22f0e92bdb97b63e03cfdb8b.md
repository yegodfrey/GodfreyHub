# 1. 接口功能

应用调用此接口可以将用户的游戏角色信息保存到华为游戏服务器。

# 2. 调用场景

当用户登录成功完成选择区服信息进入游戏后，或者用户的等级发生变化时，应用可以调用此接口存储用户的角色信息。

发布地区包含中国大陆的网络游戏（请向华为游戏运营人员确认游戏是否属于网络游戏），必须调用本接口保存玩家信息，但仅支持保存中国大陆用户的角色信息。如果游戏本身不具有游戏等级、角色名称、游戏区服、游戏公会这些信息，则可以不调用此接口。

# 3. 接口约束

● 此接口必须在用户登录成功，即login接口调用成功后，才能调用。  


● 本接口目前只支持保存中国大陆用户的玩家信息。

# 4. 调用方法
      
      1. HMSAgent.Game.savePlayerInfo(GamePlayerInfo gamePlayerInfo, SaveInfoHandler handler);
    
    

# 5. 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
gamePlayerInfo| M| GamePlayerInfo| 需要保存的角色信息。  
handler| M| SaveInfoHandler| 接口调用后的回调结果，注册结束后通过此回调实例回调给应用。回调结果中包含的具体参数参见结果回调。  
  
**GamePlayerInfo**

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
rank| O| string| 游戏等级。  
当前玩家在游戏中的等级，需要和玩家在游戏中实际等级保持一致。  
role| O| string| 角色名称。  
玩家在游戏中创建的角色名称，需要和玩家在游戏中的实际角色名称保持一致，如果没有角色名称可不设置此属性。  
area| O| string| 游戏区服。  
玩家登录游戏时选择的区服，需要和玩家实际进入游戏区服名称保持一致，如果没有区服信息可不设置此属性。  
sociaty| O| string| 游戏公会。  
玩家在游戏中所属公会，如果没有加入公会可不设置此属性。
