# 1\. 接口说明

该接口为华为access token鉴权接口。通过传入accessToken到华为服务器上获取用户的union_id、open_id、expire_in、client_id、scope等信息。

# 2\. 使用方法

**请求**

  http请求方式：Post。  
  Content-Type: application/x-www-form-urlencoded  
  接口访问Url：[https://api.cloud.huawei.com/rest.php?nsp_fmt=JSON&nsp_svc=huawei.oauth2.user.getTokenInfo](https://api.cloud.huawei.com/rest.php?nsp_fmt=JSON&nsp_svc=huawei.oauth2.user.getTokenInfo)  
请求参数：

参数| 是否必选| 说明  
---|---|---  
nsp_svc| 是| 接口名称。  
固定设为huawei.oauth2.user.getTokenInfo。  
nsp_fmt| 是| 固定设为JSON。  
  
  Body参数：

参数| 类型| 是否必选| 说明  
---|---|---|---  
open_id| String| 是| 固定值“OPENID”。请求中传入该字段，接口才会返回OpenId。  
access_token| String| 是| AccessToken。  
  
**响应**

  Content-Type: text/plain; charset=UTF-8  
 响应返回值：

参数| 类型| 是否必选| 说明  
---|---|---|---  
union_id| String| 否| 该字段需要在联盟portal上开通权限才能返回。参见[UnionId](https://wo.hicloud.com/dsm/hms/cn/doc/hmssdk_huaweiid_devguide_unionId.html)说明文档。  
scope| String| 是| 用户同意列表。  
open_id| String| 否| OpenId。  
expire_in| int| 是  
| AccessToken过期时间 (以秒为单位)。  
client_id| String| 是  
| 应用的AppID。  
  
****

****

****错误码说明：

错误码在头部的NSP_STATUS字段，错误描述为Json格式

错误码| 错误描述| 错误原因  
---|---|---  
102 | {"error":"invalid session"}| AccessToken格式不合法，如没有urlencode。  
6| {"error":"session timeout"}| AccessToken过期。  
  
****
