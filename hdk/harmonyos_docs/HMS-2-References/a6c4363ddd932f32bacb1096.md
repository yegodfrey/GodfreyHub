# 1\. 接口定义  
        
      1. void HMSAgent.Push.enableReceiveNotifyMsg(boolean enable, EnableReceiveNotifyMsgHandler handler);
    
    

  


# 2\. 接口描述

通知栏消息指在接收到消息后由华为PUSH服务解析消息内容并展示在通知栏的消息。     

开启、关闭PUSH透传消息，在sharepreference文件里保存boolean变量，接收消息后若为关闭则丢弃。若不调用该方法则默认为开启。     

接口使用限制：当是中国大陆地区的华为手机，必须满足EMUI版本不低于EMUI5.1；当是海外地区的华为手机或者非华为品牌手机，则必须满足华为移动服务的版本不低于2.5.0。     

# 3\. 参数

参数名| 参数类型| 是否必选| 说明  
---|---|---|---  
enable| boolean| 必选| ●  true：开启透传消息；  
●  false：关闭透传消息  
handler| EnableReceiveNotifyMsgHandler| 可选| 接口调用回调，可传null。
