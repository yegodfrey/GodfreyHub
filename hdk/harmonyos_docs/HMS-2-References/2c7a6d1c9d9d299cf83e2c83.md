# 接口功能  
  
应用在多次使用accessToken访问网关服务器返回accessToken失效时，可调用此接口通过注销授权的方式清除HMS SDK缓存。

# 调用场景

在华为帐号登录授权时，应用为了更高的安全性，需要使用[signIn](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_app_api_reference_c1)接口返回的accessToken访问网关服务器获取用户的唯一标识。如果网关服务器返回accessToken失效（NSP_STATUS=6），应用需要重新调用signIn接口获取新的accessToken，并再次访问网关服务器。如果仍然返回accessToken失效，此时应用可以尝试调用signOut接口通过注销授权的方式清除HMS SDK的缓存，然后再次重新获取accessToken。

注意：

本接口不用于华为账号的登出，除以上场景外其他情况不要调用此接口。

  


# 接口约束

调用本接口前，必须已经提前为应用申请华为帐号服务，参见[申请帐号服务](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_prepare_apply_account_service)。

# 调用方法

HMSAgent.Hwid.signOut(SignOutHandler handler) ;

# 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
handler| M| SignOutHandler| 接口调用后的回调结果，通过此回调实例回调给应用。回调结果中包含的具体参数参见结果回调。
