# 1\. 接口定义  
  
        
      1. void HMSAgent.Pay.getOrderDetail(OrderRequestrequest,GetOrderHandler handler);
    
    

# 2\. 接口描述  


查询订单详情，所有调用pay接口的订单均可查询，用于在丢单的情况下复核订单。

●   支付过程异常中断（关机、程序崩溃等）

●   支付结果码为-1005、30005、30002  
● 结果码为0但是验签失败  
对于有应用服务器的非单机应用,开发者需要在自己的服务器上实现支付成功回调处理的能力，然后访问自己的服务器确认订单是否支付成功，不需要使用此接口。

# 3\. 参数

参数名| 参数类型| 是否必填| 说明  
---|---|---|---  
request| OrderRequest| 是| 查询订单参数。  
handler| GetOrderHandler| 是| 查询订单回调。  
  
**表5-12    OrderRequest说明**

参数| 类型| 是否必选| 是否参与签名| 说明  
---|---|---|---|---  
merchantId| String| 是| 是| 商户ID。在华为开发者联盟上获取的“支付ID”。  
requestId| String| 是| 是| 商户订单号。开发者应用在支付前生成，用来唯一标识一次支付请求。注意：该字段中不能包含特殊字符，包括# " & / ? $ ^ *:) \ < > , | .,不支持中文。  
keyType| String| 是| 是| 固定值，请填写：1 商户秘钥  
time| String| 是| 是| 距离1970年的毫秒数。  
sign| String| 是| 否| 1、取上述参数字段，按参数名的ASCII码的增序排序，若遇到相同首字母，则看第二个字母，以此类推。  
【注意】：  
a）sign参数不参与签名  
b）没有值的参数，包括null和“”两种情况,都不需要参与签名  
2、排序完成之后，再把所有参数名和参数值的键值对以“&”字符连接起来，得到的字符串即为待签名串。  
3、将待签名字符串使用RSA私钥进行签名，得到的字符串即为sign参数的值。  
  
# 4\. 返回值

查询结果通过GetOrderHandler中的onResult方法回调
      
      1. public interface GetOrderHandler
        2. {
        3.     /**
        4.      * 查询结果回调
        5.      * @param retCode 结果码
        6.      * @param checkPayResult查询结果信息
        7.      */
        8.     void onResult(int retCode, OrderResut checkPayResult);
        9. }
    
    

回调参数包括retCode和checkPayResult，retCode是查询结果的错误码，融合了各个阶段的错误码，如果只需要判断错误码可直接使用。retCode取值和意义参考“[retCode业务错误码说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_huaweiiap_api_reference_errorcode)”。

checkPayResult是OrderResult的实例，包含了查询结果的信息，详见表5-13。

表5-13   OrderResult说明

参数| 类型| 是否必选| 是否参与签名| 说明  
---|---|---|---|---  
returnCode| Int| 是| 是| 返回码，详细请参见“表4-1 retCode说明”。当有业务返回码时，会将此值赋值给retCode。  
returnDesc| String| 是| 是| 错误描述信息。  
requestId| String| 否| 是| 商户订单号。  
orderID| String| 否| 是| 华为支付平台订单号。  
orderTime| String| 否| 是| 下单时间，yyyy-MM-dd       HH:mm:ss  
tradeTime| String| 否| 是| 支付时间，yyyy-MM-dd       HH:mm:ss  
status| String| 否| 是| 状态。  
0：失败（订单失败）  
1：成功（完成支付）

sign| String| 否| 否| 响应的签名字符串。
