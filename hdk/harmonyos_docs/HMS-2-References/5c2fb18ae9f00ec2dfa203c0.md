# 1\. 接口定义  
        
      1. HMSAgent.Hwid.signOut(SignOutHandler handler)
    
    

# 2\. 接口描述

该接口不用于取消授权，除以下情况，请不要调用此接口。  
当signIn获取的accessToken在访问网关时返回失效，重新获取的accessToken访问仍然失效时，可调用此接口清除HMS Core APK的缓存，然后再次调用signIn获取新的accesstoken。

# 3\. 参数说明

参数名| 参数类型| 是否必填| 说明  
---|---|---|---  
handler| SignOutHandler| 是| signOut结果通过此实例回调给调用方。  
  
# 4\. 结果回调

        3.      * 登出结果回调
