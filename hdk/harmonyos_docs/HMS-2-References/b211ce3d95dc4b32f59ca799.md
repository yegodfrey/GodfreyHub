# 1. 接口功能  
  
应用调用此接口连接HMS Core（APK）。

# 2. 调用场景

用户打开应用，应用在完成HMS SDK初始化后，调用此接口请求连接HMS Core（APK）。

# 3. 接口约束

● 请务必在应用启动后自动调用此接口，而不是在用户进行登录、支付等操作时才调用，否则后续审核过程中将被驳回。  


● 当前移动设备必须已经安装HMS Core（APK）。

# 4. 调用方法
      
      1. HMSAgent.connect(Activity activity,ConnectHandler handler);
    
    

# 5. 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
activity| M| Activity| 当前Activity对象。  
handler| M| ConnectHandler| 接口调用后的回调结果，通过此回调实例回调给应用。回调结果中包含的具体参数参见结果回调。  
  
# 6. 结果回调
      
      1. public interface ConnectHandler { 
        2.         /** 
        3.         * 连接HMS Core（APK）回调 
        4.         * @param rst 返回码 
        5.        */ 
        6.        void onConnect(int rst);
        7. }
    
    

参数名称| 类型| 参数含义  
---|---|---  
rst| int| 返回结果码，可参见[通用返回码](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_errorcode)。  
  
# 7. 调用示例
      
      1. HMSAgent.connect(this, new ConnectHandler() {
        2.      @Override
        3.      public void onConnect(int rst) {
        4.          showLog("HMS connect end:" + rst);
        5.       }
        6. });
