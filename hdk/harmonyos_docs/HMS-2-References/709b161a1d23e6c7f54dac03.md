# 1. 接口功能

应用调用此接口在游戏界面中显示游戏浮标。

# 2. 调用场景

发布地区包含中国大陆的联运游戏，要求必须集成游戏浮标，游戏的所有界面都需要展示游戏浮标，一般建议在游戏界面的onResume方法中调用本接口。

# 3. 接口约束

本接口当前只支持中国大陆用户，非中国大陆用户目前不支持展示游戏浮标。

# 4. 调用方法
      
      1. HMSAgent.Game.showFloatWindow(Activity activity);
    
    

# 5. 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
activity| M| Activity| 需要显示浮标的Activity实例。  
  
  


# 6. 结果回调

无。

# 7. 返回码

无。

# 8. 调用示例
      
      1. protected void onResume()
        2. {
        3.     Super.onResume();
        4.     HMSAgent.Game.showFloatWindow(this);
        5. }
