# 1. 接口功能

应用需要使用HMS SDK的能力，必须先调用此接口初始化HMS SDK。

# 2. 调用场景

用户打开应用，应用在启动过程中在应用的初始化方法中调用此接口对HMS SDK进行初始化。

# 3. 接口约束

应用必须在调用其他所有HMS SDK接口之前调用init接口。

# 4. 调用方法
      
      1. HMSAgent.init(Application application);
    
    

# 5. 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
application| M| Application| 当前Application对象。  
  
  


# 6. 结果回调

无。

# 7. 返回码

无。

# 8. 调用示例
      
      1. public class MyApplication extends Application {
        2.     @Override
        3.     public void onCreate() {
        4.         super.onCreate();
        5.         HMSAgent.init(this);
        6.     }
        7. }
