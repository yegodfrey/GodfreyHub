# 1. 接口功能

应用调用此接口可以隐藏已经在游戏界面中显示的游戏浮标。

# 2. 调用场景

当用户操作触发游戏页面的onPause方法，例如切换游戏界面、切换应用等，应用需要在onPause中调用本接口隐藏游戏浮标。

# 3. 接口约束

● 本接口当前只支持中国大陆用户，非中国大陆用户无法使用浮标。  


● 同一个游戏界面必须已经调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c12)接口显示浮标以后，才能调用本接口隐藏浮标。

# 4. 调用方法
      
      1. HMSAgent.Game.showFloatWindow(Activity activity);
    
    

# 5. 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
activity| M| Activity| 需要隐藏浮标的Activity实例。必须与调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_c12)接口时传入的Activity示例一致。  
  
# 6. 结果回调

无。

# 7. 返回码

无。

# 8. 调用示例
      
      1. protected void onPause()
        2. {
        3.     super.onPause();
        4.     HMSAgent.Game.hideFloatWindow(this);
        5. }
