# 1. 接口功能

应用调用此接口向HMS SDK检查华为应用市场该应用是否有更新。如果应用版本有更新，HMS SDK会向用户拉起升级确认页面，用户确认升级后HMS SDK会使用AppGalleryKit静默安装能力对应用进行升级。

# 2. 调用场景

● 用户启动应用后，应用调用[init](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_init)接口和[connect](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_game_connect)接口完成HMS SDK初始化后，需要调用此接口检查更新。  


● 用户在应用中主动触发检查升级操作，应用需要调用此接口检查更新。

# 3. 接口约束

请务必在应用启动时调用connect接口成功后调用此接口，否则后续审核过程中将被驳回。

# 4. 调用方法
      
      1. HMSAgent.checkUpdate(Activity activity, CheckUpdateHandler handler);
    
    

# 5. 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
activity| M| Activity| 当前Activity对象。  
handler| M| CheckUpdateHandler| 接口调用后的回调结果，通过此回调实例回调给应用。回调结果中包含的具体参数参见结果回调。  
  
# 6. 结果回调
      
      1. public interface CheckUpdateHandler { 
        2.         /** 
        3.         * 更新应用回调 
        4.         * @param rst 返回码 
        5.        */ 
        6.         public void onResult(int rst); 
        7. }
    
    

参数名称| 必选(M)/可选(O)| 类型| 参数含义  
---|---|---|---  
rst| M| int| 返回结果码。  
● 0：无升级版本。  
● 1：有升级版本。  
● -1：升级检查的请求出错，需联系华为技术支持定位。  
● 其他：HMS SDK错误，参见[通用返回码](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_errorcode)。  
  
# 7. 调用示例
      
      1. HMSAgent.checkUpdate(this, new CheckUpdateHandler() {
        2.     @Override
        3.     public void onResult(int rst) {
        4.         showLog("check app update end:" + rst);
        5.     }
        6. });
