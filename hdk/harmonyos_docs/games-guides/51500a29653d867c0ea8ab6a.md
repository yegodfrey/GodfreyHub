# 转移核准（备案）

> 说明
>
> 若主账号[开启"账号管理功能"开关](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-account-0000001885962814#ZH-CN_TOPIC_0000001885962814__li1536716016483)，该核准（备案）方式仅限在主账号下操作。

在华为云核准（备案）系统中将主体及主体下的互联网信息全部转移到目标账号下。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面点击"转移备案"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/79DZ4poqTAy5yIh03riRwg/zh-cn_image_0000001935645274.png?HW-CC-KV=V1&HW-CC-Date=20261008T164927Z&HW-CC-Expire=31536000000&HW-CC-Sign=B514139EE61F403EC6320AAB3A1CC2FDF341DA5E88D72FF7A5D1B5E28A044304)
2. 在"转移备案"填写目标账号后，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/8LuL0H3KSyqAcdMiZ4ubIg/zh-cn_image_0000001962844129.png?HW-CC-KV=V1&HW-CC-Date=20261008T164927Z&HW-CC-Expire=31536000000&HW-CC-Sign=98DB08FE6B3DB0BE2E0B9FECF747A249567150A0DDF6868B1C8C783261B139EF)

3. 提交转移申请后需要几分钟才能转移成功，请耐心等待。
