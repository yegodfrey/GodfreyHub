# Deeplink

Deeplink入口实现快速启动快游戏，提高裂变传播的概率，让用户体验更简洁顺畅，同时全链路跟踪、标记渠道数据，为后续的推广评估、营销分析提供数据支撑，为您解决拉新、促活、留存、转化等问题。
> 说明
>
> * 点击短信的deeplink不能直接打开快游戏。
> * 不同的手机设备厂商对该能力可能有不同限制，使用前请和相应厂商确认。

## 使用场景

* 社交分享 通过社交软件分享Deeplink，用户点击后直接打开对应的快游戏。

* 广告推广 通过广告页面推广Deeplink，用户点击后直接打开对应的快游戏。

* 活动运营 通过运营活动嵌入Deeplink，方便用户参与个性化活动。

## 前提条件

* 快游戏已上架。
* 手机已安装[华为快应用加载器](https://developer.huawei.com/consumer/cn/doc/Tools-Library/quickapp-ide-download-0000001101172926#section9347192715112)，且华为快应用加载器有待测试快游戏的使用记录。
* 已下载adb.exe工具包，且保证adb命令可以正常运行。

## Deeplink格式

目前deeplink格式支持如下三种：

* hap://app/<package>/[?key=value]
* https://hapjs.org/app/<package>/[?key=value]
* hwfastapp://<package>/[?key=value]

> 说明
>
> * hwfastapp开头的deeplink格式仅适用于华为手机。
> * deeplink前后不能有空格。
> * deeplink不支持失败回调。若在网页中使用，确保deeplink跳转失败后，仍有合适的H5页面为用户提供服务。

|参数要求|参数|说明|
|:-----------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|固定参数，无需替换。|hap|将从"快应用中心"客户端打开对应的快游戏。|
|固定参数，无需替换。|hapjs.org|将从"快应用中心"客户端打开对应的快游戏。|
|固定参数，无需替换。|hwfastapp|将从"快应用中心"客户端打开对应的快游戏。|
|必要参数。|package|需替换成待打开的快游戏包名。|
|非必要参数，可根据实际情况进行替换。|key=value|需要传递的参数，多个参数用&连接。您可以传递自定义参数，或根据实际情况传递如下参数： * gameGiftId：快游戏[接入礼包服务](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-runtime-gifts-kit-0000002317894844)时传递的游戏礼包ID，即您在AGC控制台成功[创建礼包](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-develop-gifts-0000002351893565)后生成的礼包ID。 * giftUri：快游戏[接入礼包服务](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-runtime-gifts-kit-0000002317894844)时传递的礼包页面地址，即您在[创建礼包](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-develop-gifts-0000002351893565)时设置的跳转地址，用户点击后由游戏自行根据礼包地址展示对应的礼包页面。 * userEntry：用于标记不同渠道平台打开快游戏的数据，取值如下： * 101：巨量平台。 * 102：腾讯平台。 * 900~999：自定义其它渠道平台。 > 说明 > 参数值可能被其它应用获取，建议不要传递安全敏感度较高的数据。|

## 使用示例

* 在快游戏中调用deeplink打开另一个快游戏。
  * 若无需传递参数，仅需将com.test.quickgame替换成待测试的快游戏包名。

    ```screen
    qg.openDeeplink({
           uri: 'hap://app/com.test.quickgame'
    })
    ```

  * 若需要传递参数，参数以key=value拼接在快游戏包名后面，多个参数以&连接。

    ```screen
    qg.openDeeplink({
           uri: 'hap://app/com.test.quickgame/?source=net&name=aa'
    })
    ```

    参数值可在游戏启动页面使用[qg.getLaunchOptionsSync](https://developer.huawei.com/consumer/cn/doc/games-references/games-api-quickgame-runtime-lifecycle-0000002365996968#section4844135503910)获取。

    ```screen
    let res = qg.getLaunchOptionsSync();
    console.log("getLaunchOptionsSync:" + JSON.stringify(res));
    ```

* 使用加载器打开网页，再在网页中点击deeplink打开对应的快游戏。 说明
  >
  > 若使用华为手机自带浏览器进行测试，需把链接换成https://hapjs.org/app/<package>。

  ```screen
  <html>
      <head>
          <meta charset="UTF-8">
          <title></title>
      </head>
      <body>
          <a href="hap://app/com.example.quickgame">跳转到新的快游戏</a>
      </body>
  </html>
  ```

## 跳转测试

您可以先在本地测试deeplink跳转的准确性。
> 说明
>
> 测试前，请确保华为快应用加载器中有待测试快游戏的使用记录。

### 使用adb命令测试

若无需传递参数，您可以在终端输入adb命令行进行测试。

```screen
// 测试前，请将com.test.quickgame更换成已上架的快游戏包名
adb shell am start -a android.intent.action.VIEW -d hap://app/com.test.quickgame
```

### 在网页中测试

若需要传递多个参数，您可以在本地网页中测试携带多个参数的deeplink。

```screen
<!DOCTYPE html>
<html>    
    <head>
        <meta charset="UTF-8">
        <title></title>
    </head> 
    <body>
         <a>以下是hap链接形式</a><br/>
         <a href="hap://app/com.test.quickgame/?source=net&name=aa">打开快游戏</a><br/><br/>
         <a>以下是https链接形式</a><br/>
         <a href="https://hapjs.org/app/com.test.quickgame/?source=net&name=aa">打开快游戏</a><br/>
         <a>以下是hwfastapp链接形式</a><br/>
         <a href="hwfastapp://com.test.quickgame/?source=net&name=aa">打开快游戏</a><br/><br/>
 </html>
```

以上超链接均可正常拉起快游戏，且在onShow中收到的数据为：

```screen
{"referrerInfo":{"extraData":{"packageName":"com.android.htmlviewer"},"type":"deeplink"},"query":"{\"name\":\"aa\",\"source\":\"net\"}"}
```
