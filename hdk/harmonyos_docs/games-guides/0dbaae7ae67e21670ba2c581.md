# 集成SDK

使用联机对战服务相关功能，必须集成联机对战SDK。

## 开发准备

您可选择下列引擎之一进行开发：

* Cocos Creator：2.4.4及以上版本
* 白鹭：5.4.1版本
* LayaAir：2.12.2版本

## 开发步骤

目前，联机对战服务JS SDK支持[Cocos Creator](#section151784012910)、[白鹭](#section205145111117)、[LayaAir](#section27087503112)游戏开发引擎进行游戏开发。

### Cocos Creator

1. 打开您的Cocos Creator工程，其目录示例如下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/m4uAaFPjRw2lh8RwtoqEqg/zh-cn_image_0000002395350761.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=5A7BD535ED11C003EC27A2CAA7F5BE1E3DF739E19E224AE34C3B7D232AEB934B)

2. 下载联机对战服务[SDK脚本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gameobe-sdkdownload-jssdk-0000001226603167)，建议单独创建目录用于存放SDK脚本。
3. 在资源管理器中，点击存放联机对战SDK脚本目录（如示例中的GOBE目录）中的js文件，并勾选"属性检查器"中的"导入为插件"，点击右上角的"应用"，将js脚本设置成"导入为插件"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/unjdBD0CSQ-kSWv8zkTkZg/zh-cn_image_0000002361510960.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=4820673D83E0F1C8A0929E49E575196708334918BE0EC0A752AA7991376186E2)

4. 在项目任意目录下，新建一个后缀名为.js或.ts的文件，用于后续实例化Client对象。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/jatYMWciQ42JPqxZsrIetQ/zh-cn_image_0000002395190909.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=764C77D749F1BDD5FC7751CF5B8E9ACB81AE0FC58531A981886EEF633F36676E)

5. 若需要使用Cocos Creator引擎发布Android/HarmonyOS 5.0及以上游戏，则需要从JS SDK包体中取出endpoint-cert.cert证书，放到Cocos Creator工程目录下，然后在实例化Client对象时需传入对应的平台类型和证书路径（如下示例中，JS SDK提供的证书放在了resources目录下）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/Z5nhLPhnQgS88r75lOcsxg/zh-cn_image_0000002361670828.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D5B206131DCF3E6C194AD96DE7E80F3D41EF7547864CC2DFFFB57F7C8501B59)

### 白鹭

> 说明
>
> 由于Wing长期未更新，旧的环境可能引入不可预期的问题，因此推荐您使用VSCode + Chrome开发调试。

1. 打开您的Egret项目，其目录示例如下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/tdacZJSkRtCq__184n8o2Q/zh-cn_image_0000002395350781.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=B647908D163605942522AE9AF9B85E8C24D78152B93073773C881368A37C96EE)

2. 下载联机对战服务[SDK脚本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gameobe-sdkdownload-jssdk-0000001226603167)，在./libs目录下创建GOBE文件夹，将GOBE.js、GOBE.d.ts拷贝到GOBE文件夹，同时创建GOBE.js的副本并重命名为GOBE.min.js，用于发布时使用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/j-EUenPKTW2QdqZaBtqsmg/zh-cn_image_0000002361510964.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=1EB25A934B5377F346CB8BB5AE739B5B2C77E83D407894509588651B6D172F77)
3. 编辑egretProperties.json文件，在modules数组中新增GOBE库的描述。

   ```screen
   { 
       "name":"GOBE", 
       "path": "./libs/GOBE" 
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/DdlZs2d2QOOaUOmUhm_BYg/zh-cn_image_0000002395190913.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=E0A2E40D4C0CD274DDC0C106C1DB60F6CCC00477BDB95CFD2D8016B9A2B1334B)
4. 使用如下命令编译或直接运行项目，完成联机对战SDK导入。
   * 编译

     ```screen
     egret build GOBE
     ```

   * 运行项目

     ```screen
     egret run -a
     ```

### Laya

1. 使用VSCode打开您的LayaAir工程，其目录示例如下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/1GfxKpczQ7-eBHRP3KEgSQ/zh-cn_image_0000002361670832.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=096F4677D1F149B435D694ACF0FD55864B26E97D23DC15D8E9DE3C2737EF4A69)

   * 将**GOBE.d.ts** 拷贝到**./libs** 目录下。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/k-RSgHDsROe8uGNTSKQ_Zg/zh-cn_image_0000002395350785.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=738912578C8805837C5FEF252BB0E2D4C7C41C599C4E738470768D1117E616E7)

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/WFRYCSpsSGuUgVUZ6d_cig/zh-cn_image_0000002361510968.png?HW-CC-KV=V1&HW-CC-Date=20261008T174926Z&HW-CC-Expire=31536000000&HW-CC-Sign=AE074A58AE126A1FE4AD0A9408B9F53D648945581B38882A8F52866C9CE1862D)
