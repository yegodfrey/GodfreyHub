# 集成SDK

使用联机对战服务相关功能，必须集成联机对战SDK。

## 开发准备

您可选择下列引擎之一进行开发：

* Cocos Creator：2.4.4及以上版本
* 白鹭：5.4.1版本
* LayaAir：2.12.2版本

## 开发步骤

目前，联机对战服务JS SDK支持[Cocos Creator](#section151784012910)、[白鹭](#section205145111117)、[LayaAir](#section27087503112)游戏开发引擎进行游戏开发。

### Cocos Creator

1. 打开您的Cocos Creator工程，其目录示例如下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/m4uAaFPjRw2lh8RwtoqEqg/zh-cn_image_0000002395350761.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=FBA2F0018CEBD65DDF0F45D0F820C2C1AC6DFAE8998DA00275D665C409AC9A98)

2. 下载联机对战服务[SDK脚本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gameobe-sdkdownload-jssdk-0000001226603167)，建议单独创建目录用于存放SDK脚本。
3. 在资源管理器中，点击存放联机对战SDK脚本目录（如示例中的GOBE目录）中的js文件，并勾选"属性检查器"中的"导入为插件"，点击右上角的"应用"，将js脚本设置成"导入为插件"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/unjdBD0CSQ-kSWv8zkTkZg/zh-cn_image_0000002361510960.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4DDFCAF34E0B60AD7D63964BDC92C160A53CD975A2DD8C4C0F595BF77F85DF3)

4. 在项目任意目录下，新建一个后缀名为.js或.ts的文件，用于后续实例化Client对象。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/jatYMWciQ42JPqxZsrIetQ/zh-cn_image_0000002395190909.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=F87BA43AE48427DA8E1051E0D872E8944E036FD9E068AC1524811239073C0863)

5. 若需要使用Cocos Creator引擎发布Android/HarmonyOS 5.0及以上游戏，则需要从JS SDK包体中取出endpoint-cert.cert证书，放到Cocos Creator工程目录下，然后在实例化Client对象时需传入对应的平台类型和证书路径（如下示例中，JS SDK提供的证书放在了resources目录下）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/Z5nhLPhnQgS88r75lOcsxg/zh-cn_image_0000002361670828.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=1D3E674A7B60F176E6B872BF0DBB25FB1280E864A8B43C9001C4FB330BCD7EB0)

### 白鹭

> 说明
>
> 由于Wing长期未更新，旧的环境可能引入不可预期的问题，因此推荐您使用VSCode + Chrome开发调试。

1. 打开您的Egret项目，其目录示例如下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/tdacZJSkRtCq__184n8o2Q/zh-cn_image_0000002395350781.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=14FB72FA04E93BBBE4B4FE5B34173CF355822F6C55F6E6F43684A1B1A4C29FD0)

2. 下载联机对战服务[SDK脚本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gameobe-sdkdownload-jssdk-0000001226603167)，在./libs目录下创建GOBE文件夹，将GOBE.js、GOBE.d.ts拷贝到GOBE文件夹，同时创建GOBE.js的副本并重命名为GOBE.min.js，用于发布时使用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/j-EUenPKTW2QdqZaBtqsmg/zh-cn_image_0000002361510964.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=57046B76843A0A55F4378235952A3856E3A5501EBCB580A35AFBDF231A7054FB)
3. 编辑egretProperties.json文件，在modules数组中新增GOBE库的描述。

   ```screen
   { 
       "name":"GOBE", 
       "path": "./libs/GOBE" 
   }
   ```

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/DdlZs2d2QOOaUOmUhm_BYg/zh-cn_image_0000002395190913.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=2148646AE6DCF2AACAE32179E95A9AE87339ADF1712A12F6F3AE1F27166C47A2)
4. 使用如下命令编译或直接运行项目，完成联机对战SDK导入。
   * 编译

     ```screen
     egret build GOBE
     ```

   * 运行项目

     ```screen
     egret run -a
     ```

### Laya

1. 使用VSCode打开您的LayaAir工程，其目录示例如下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/1GfxKpczQ7-eBHRP3KEgSQ/zh-cn_image_0000002361670832.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=602869C02564B4EA480C8EB44576239FA975452A8EED8722EA0321140E0E81B1)

2. 下载联机对战服务[SDK脚本](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gameobe-sdkdownload-jssdk-0000001226603167)，并将下列不同文件拷贝到对应目录下。
   * 将**GOBE.d.ts** 拷贝到**./libs** 目录下。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/k-RSgHDsROe8uGNTSKQ_Zg/zh-cn_image_0000002395350785.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=2DCD518A813AE5FD87BF30D7B5FA7F3296B591845BE28CCFC640FD28DBE6E376)
   * 将**GOBE.js** 拷贝到**./bin/libs** 目录下。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/WFRYCSpsSGuUgVUZ6d_cig/zh-cn_image_0000002361510968.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=3A270EFE119D344A5BF78B3CC6CA8903E34210CB59562B7E008F0D5CC803D340)
