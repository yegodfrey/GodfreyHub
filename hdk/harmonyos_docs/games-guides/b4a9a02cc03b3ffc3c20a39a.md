# 登录认证

## 前提条件

已在开发者联盟网站上[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/games-guides/ailod-agc-0000002477235912#section61391351162414)。

## 操作步骤

1. 在顶部菜单栏选择"AILOD > Settings"，点击"Sign in"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/I27n_6BIRVq9_3lM-9KOpw/zh-cn_image_0000002510558585.png?HW-CC-KV=V1&HW-CC-Date=20261008T154207Z&HW-CC-Expire=31536000000&HW-CC-Sign=27B4E45F34865418C0FA5F06FB346C050C94B458A1DC4CBF8CEDF91B1D9A398D)

2. 在弹出的"华为账号登录"页面，输入已实名认证的华为账号，完成后点击"授权并登录"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/xIzmxBiuSOq7Iz8L-f5FqQ/zh-cn_image_0000002476879446.png?HW-CC-KV=V1&HW-CC-Date=20261008T154207Z&HW-CC-Expire=31536000000&HW-CC-Sign=93567EDDC96D37556F1A4F401178210B2108BF3ED7D97F558B51667F6CEC5172)

3. 登录成功后，请携带**Open Id** 信息联系运营（QQ：2851508860）申请使用权限。

   后续再使用相同华为账号登录AILOD时，**Open Id**不会变，您无需重复联系运营申请权限。
