# 登录认证

#### 前提条件

已在开发者联盟网站上[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/games-guides/ailod-agc-0000002477235912#section61391351162414)。  

#### 操作步骤

1. 在顶部菜单栏选择"AILOD \> Settings"，点击"Sign in"。 ![](https://media:401781143647526705)

2. 在弹出的"华为账号登录"页面，输入已实名认证的华为账号，完成后点击"授权并登录"。 ![](https://media:401781143647567706)

3. 登录成功后，请携带Open Id信息联系运营（QQ：2851508860）申请使用权限。 后续再使用相同华为账号登录AILOD时，Open Id不会变，您无需重复联系运营申请权限。
