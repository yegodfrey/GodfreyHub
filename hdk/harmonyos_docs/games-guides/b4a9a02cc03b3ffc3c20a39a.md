# 登录认证

## 前提条件

已在开发者联盟网站上[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/games-guides/ailod-agc-0000002477235912#section61391351162414)。

## 操作步骤

1. 在顶部菜单栏选择"AILOD > Settings"，点击"Sign in"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/I27n_6BIRVq9_3lM-9KOpw/zh-cn_image_0000002510558585.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=138C5845CA9AB6FF1D93F7BD84FA3625405ECD3B9DC68C12E045C0D2CCEE5A69)

2. 在弹出的"华为账号登录"页面，输入已实名认证的华为账号，完成后点击"授权并登录"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/xIzmxBiuSOq7Iz8L-f5FqQ/zh-cn_image_0000002476879446.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=147BA7C1E3FAF6F3E271F3B20CF7E56559927A28082718873965B0375C2390FE)

3. 登录成功后，请携带**Open Id** 信息联系运营（QQ：2851508860）申请使用权限。

   后续再使用相同华为账号登录AILOD时，**Open Id**不会变，您无需重复联系运营申请权限。
