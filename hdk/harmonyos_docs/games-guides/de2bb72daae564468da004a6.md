# 动态渲染SDK介绍

为了解决手机游戏过程中带来的发热发烫问题，提升游戏过程中的手机电池电量续航，华为推出了动态渲染组件（Dynamic Rendering）。

该工具通过获取并汇总系统和游戏状态信息，识别玩家所处环境和游戏场景，例如玩家挂机场景（如静置挂机、运动挂机）、系统组件（如虚拟键盘）覆盖游戏画面、物体（如手掌）覆盖游戏画面等场景，动态渲染SDK返回针对这些场景的分辨率、帧率、屏幕亮度建议，由游戏引擎根据建议降低游戏渲染分辨率、渲染帧率和屏幕亮度，以降低游戏发热，提升玩家手机续航。

## 工作原理

动态渲染SDK提供基于游戏引擎的引擎插件扩展，游戏开发者可以通过游戏引擎使能动态渲染SDK。

在您获得玩家授权（如适用）的前提下，该SDK通过游戏引擎收集游戏场景信息，另外还通过系统能力收集HarmonyOS系统的环境光、陀螺仪、触控等系统信息，将系统和游戏状态信息输入到SDK内部的场景识别模块，识别玩家所处的游戏场景和设备所处环境，再根据场景识别结果返回给游戏引擎建议的分辨率、帧率和屏幕亮度，由游戏引擎根据实际情况修改游戏渲染分辨率、帧率和游戏应用的屏幕亮度。

## 典型应用场景

动态渲染SDK支持识别如下游戏场景：

|游戏场景|说明|关闭条件|
|:--------|:---------------------------------------------------------------------------------------|:-----------------------|
|手机倒扣识别|出于隐私保护，玩家部分场景下会将手机倒扣下来但仍然运行游戏。 该算法将会识别到该场景，并且自动降低游戏帧率和分辨率。|玩家拿起手机，触碰屏幕等均会跳出场景判断。|
|手机颠簸场景识别|部分玩家在玩放置挂机类游戏时，会将手机放在背包或者口袋，而玩家进行其他活动，例如跑步，骑车等。 该算法将识别到该场景，并且自动降低分辨率、屏幕亮度、帧率操作，从而提升手机续航。|玩家将手机从口袋或背包中拿出。|
|相机运动识别|根据人因体验测试，人眼在运动过程中的可见分辨率会降低，且人眼的可视角度<10度。 该算法会根据玩家游戏内虚拟摄像头运动的速度，以人眼无法感知的速度，短时间内降低游戏分辨率。|在玩家视角恢复正常后，可对覆盖的区域降低分辨率。|
|键盘/手指遮挡识别|以键盘为例，当玩家在聊天框输入文字、输入账号密码或搜索时，虚拟键盘通常会遮挡屏幕下半部分甚至更大区域。 该算法利用Vulkan和UE5的VRS机制，可对覆盖的区域降低分辨率。|在玩家退出遮挡状态后，可对覆盖的区域降低分辨率。|
