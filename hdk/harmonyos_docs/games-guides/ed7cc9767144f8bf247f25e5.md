# 开发者群组使用细则

本文约定了开发者及其关联公司在使用华为数字商品及联运服务（以下简称"服务"）时，通过开发者群组使用服务和开展活动的具体规则。

**一、定义**

1. 关联公司：与开发者使用服务时所签署协议中的用语具有相同含义。
2. 开发者群组：开发者及其所有关联公司主体拥有一个唯一的开发者群组，简称群组（即华为开发者联盟官网-管理中心-账号组）。开发者及其所有关联公司主体的账号需如实申请加入群组。
3. 关联：指开发者创建或加入对应的开发者群组。

**二、关联关系申请与应用**

1. 开发者可在华为平台上申请加入已有开发者群组，或新建开发者群组并加入。
2. 为保证激励准确发放，每个开发者主体必须关联一个开发者群组，一个开发者群组内可以仅有一个开发者主体。
3. 开发者群组关联需经过华为审核，审核通过后次月生效。

**三、结算**

1. 为保证激励发放的公平公正，同时确保正确计算开发者的流水总额、分成结算金额、激励金额及推广金额，开发者及其所有关联公司主体需要在华为平台上，如实进行关联。**若开发者未关联开发者群组，为保障开发者的激励正常发放，开发者与使用服务相关的结算将暂时停止，开发者关联开发者群组并生效后，将按照服务协议约定的结算周期一并计算流水总额、分成结算金额、激励金额及推广金额。**
2. 华为允许开发者及其所有关联公司主体进行关联关系变更及App转移，转移涉及的流水总额将同步计入变更、转移前后的开发者群组，用于计算各开发者群组累计流水总额。
3. 在2026年12月31日之前，若开发者及其关联公司未创建群组并进行关联，则华为有权按照双方服务协议结算条款中列明的分成系数对2026年1月1日至2026年12月31日产生的流水金额进行结算。

**四、其他**

1. 若您创建的为单主体群组，您须保证该主体与现有及后续新增群组内所有主体均不符合"关联公司"定义。**华为有权对此进行核查，如发现该主体存在未声明的关联关系，华为保留追回相关权益及依据平台规则予以处罚的权利。**
2. 华为会不定期审视开发者关联关系是否正确，**对于关系不正确的情形，华为将提出整改意见并暂停开发者与使用服务相关的结算，直至开发者申诉成功或修正关联关系。**
3. **对于通过恶意行为（包括但不限于掩盖关联公司事实捏造独立开发者群组）获取激励的情形，华为有权采取取消开发者的激励资格，并追回开发者不当获利等措施。**华为的审核不影响或免除开发者的责任。
4. 对于通过不定期审视，发现关联关系不正确且已对激励金结算产生实质影响的群组，华为将通过正式邮件通知及商务沟通等方式与相关开发者确认激励金扣减方案。 **经华为及华为商务充分沟通后，开发者需在20个工作日内，以邮件形式对激励金扣减方案进行有效确认及回复。** **（若双方未能按期协商达成一致，开发者可主动向对应商务申请，酌情延长期限。）**

   **逾期未予确认及回复的，华为将按照以下规则对差异金额进行追回：**

   **基于修正后的群组关系，按群组成员加入时间先后顺序依次从当期待结算金额扣减（早加入者优先扣减）；若所有群组成员的结算金额不足抵扣，剩余差额将顺延至后续结算周期，沿用上述扣减顺序执行，直至差异金额全部扣清。**
