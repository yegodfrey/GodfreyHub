# 国产游戏小程序核准准备

国产游戏小程序是指纯广告变现快游戏（IAA），若这类快游戏未注册在江苏省，且在履行核准手续前没有拿到国家/省份相关主管部门审核同意的前置审批文件，例如游戏版号、国家/省级新闻出版广电总局关于****游戏的批复文件、省级新闻出版部门出具的游戏核准批复文件，需要前往AGC控制台申请前置审批文件。在AGC控制台为国产游戏小程序申请前置审批文件的操作步骤如下。

1. 下载模板文件，并根据实际情况进行填写。

2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，为快游戏新建核准。

3. 在"国产小程序核准"页面填写信息，完成后点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/w8mamCw_R3CBqgMkrrvGXQ/zh-cn_image_0000002542745930.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=F8B750BDCCB7BDCA8FF7F83E4BF5ED9B8339427FDBFDC72C0968833B8F43A830)

4. 您提交的申请需华为工作人员与管局共同审批，完成审批大概需要20~30个工作日，请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/UtNS88zrQAqFQaL4NV4PAw/zh-cn_image_0000002542586280.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=49803A35319A8254B220D350AAEE139EB32006D230833E9A230828A9AADF6F95)

   > 说明
   >
   > 仅能有一条正在审批中的申请。
5. 完成审批后，请前往AGC控制台，在快游戏核准详情页最底部下载管局签署的准予核准通知书。
