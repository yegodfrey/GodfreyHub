# 新增接入

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面接入快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/VuGJ7jINSW-kl8oJB1OugA/zh-cn_image_0000001885068697.png?HW-CC-KV=V1&HW-CC-Date=20261008T181628Z&HW-CC-Expire=31536000000&HW-CC-Sign=26887344E73D52CE7C6E083BCEF50DB4FFC805DFAD87E3F5082D1766AEE35BF5)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/4_ur1WNKRf6BkL9sWTD8Lw/zh-cn_image_0000001838749110.png?HW-CC-KV=V1&HW-CC-Date=20261008T181628Z&HW-CC-Expire=31536000000&HW-CC-Sign=A094CF6E5C83BD2C6170919BD3BD505D731DC3277011EF63C097D99ED8856E69)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/daR-OgZaSkKYhlBsGaPpyQ/zh-cn_image_0000001838749298.png?HW-CC-KV=V1&HW-CC-Date=20261008T181628Z&HW-CC-Expire=31536000000&HW-CC-Sign=AA9831973BAA60C0F1714D6E3399F7344F674E18879F12272F3F638185FEAD8D)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dd/v3/_ToapBmYQvyorHu4QXxXvw/zh-cn_image_0000001803737948.png?HW-CC-KV=V1&HW-CC-Date=20261008T181628Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F069BB6C234DECC0E7ACC669C149C34637182C8C99CF2BF8BFA2D9EDF28C43B)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/LemAnfSLRDGvBt4KY4yM5w/zh-cn_image_0000001838908218.png?HW-CC-KV=V1&HW-CC-Date=20261008T181628Z&HW-CC-Expire=31536000000&HW-CC-Sign=DA122FD3FF561CDD01882285F5BC7622555D221AA7B294AB614182FA15A67A71)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
