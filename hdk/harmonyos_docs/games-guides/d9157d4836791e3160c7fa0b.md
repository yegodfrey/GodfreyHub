# 新增接入

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面接入快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/VuGJ7jINSW-kl8oJB1OugA/zh-cn_image_0000001885068697.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=1553B1123A9E89E3818014DC0471F4071FA1FB55CA0C30B702F745C4C093A4E1)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/4_ur1WNKRf6BkL9sWTD8Lw/zh-cn_image_0000001838749110.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=A319406C0B102A39692C6770DB9D95E7D9F8E04EDD656DB7FB3271CC8223D6CB)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/daR-OgZaSkKYhlBsGaPpyQ/zh-cn_image_0000001838749298.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=9757DE76B1ABB2B8851DFFBA8261D75152991F808D45CBAB37893EABE6C7448C)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dd/v3/_ToapBmYQvyorHu4QXxXvw/zh-cn_image_0000001803737948.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=6711BCE6061BA575BB884586EFCA2907CE078C83C76B1BE899FE217D498056FB)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/LemAnfSLRDGvBt4KY4yM5w/zh-cn_image_0000001838908218.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2F3DE056609191183ED1262DC86AEB590207A51A52E6477E558CDDB155B8815)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
