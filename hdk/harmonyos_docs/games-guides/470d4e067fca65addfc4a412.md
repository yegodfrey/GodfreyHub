# 变更核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

3. 根据提示补充提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/p4u0HGwKTROzZThDMozu3w/zh-cn_image_0000001803578172.png?HW-CC-KV=V1&HW-CC-Date=20261008T182100Z&HW-CC-Expire=31536000000&HW-CC-Sign=E23C049C57261A493FD45B2E8EAC139E18B682096740D99B9FAC7AB26A1F3499)

5. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
6. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
