# 托管代码到实时服务器

代码开发及本地调试完成后，需将代码托管到联机对战的实时服务器上。同时，在实时服务器的运行过程中，您还可以随时在AGC控制台查看服务器的运行日志。

## 上传代码到实时服务器

1. 在联机对战服务页面，选择"实时服务器 > 托管实时服务器"。
2. 点击"生产环境"对应"操作"列的"上传代码"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/lbUVVdaWQsy_Mb_9q-G8xw/zh-cn_image_0000002542719627.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=A56EC8F761DC106F6F300BD6583E68D07C32A4E6B0415B899FACB3F3615FF16B)

3. 自定义一个服务名称（长度64的字符串），选择开发语言，点击"选择文件"上传您的index.js文件（最大支持3MB）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/ocyrCdWnT1uRaYsfIhAFxg/zh-cn_image_0000002395350841.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=C8AEEFA0E71B6E8BDF9811EDD9F48A15017CC9BE18BB1E882474367CA983D0EB)

4. 点击"部署"，即可查看到部署结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/bhGFQi63QLO1aDKRAvjZ2A/zh-cn_image_0000002361511036.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A782D4AE55D094D0C0ED22B8D5EA3D6A05864792B703BDC232C7D4CDA65C0C9)

## 查看运行日志

> 说明
>
> 当前，日志功能需人工开通，可通过联系企业QQ：2851508860 / 2851508868进行申请，您需要向华为运营人员提供项目ID信息。

1. 在联机对战服务页面，选择"实时服务器 > 托管实时服务器"。
2. 点击"生产环境"对应"操作"列的"查看日志"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/82iyMR49TVyNdW_6HiTaAA/zh-cn_image_0000002542599613.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=C49E440ED291C01B68AAF1182DE2473861ABE958C2C06DBD3C09163B5467EFC1)

3. 跳转到相同项目下的"云监控 > 日志服务"页面，在下拉选项中选择"云函数"，即可查看日志详情。您还可以通过右上角的时间筛选，查看不同时间段的数据，具体操作请参考[日志服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/cloudfunction-0000001432886916)。 说明
   >
   > 实时服务器日志中的message（消息内容）格式为"productId|message"。
