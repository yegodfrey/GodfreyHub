# 托管代码到实时服务器

代码开发及本地调试完成后，需将代码托管到联机对战的实时服务器上。同时，在实时服务器的运行过程中，您还可以随时在AGC控制台查看服务器的运行日志。

## 上传代码到实时服务器

1. 在联机对战服务页面，选择"实时服务器 > 托管实时服务器"。
2. 点击"生产环境"对应"操作"列的"上传代码"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/lbUVVdaWQsy_Mb_9q-G8xw/zh-cn_image_0000002542719627.png?HW-CC-KV=V1&HW-CC-Date=20261008T175423Z&HW-CC-Expire=31536000000&HW-CC-Sign=1B98B04355C5B77700E9F4FFA34A6470BE74A5989E9B3F987E421BFFE7E62FFF)

3. 自定义一个服务名称（长度64的字符串），选择开发语言，点击"选择文件"上传您的index.js文件（最大支持3MB）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/ocyrCdWnT1uRaYsfIhAFxg/zh-cn_image_0000002395350841.png?HW-CC-KV=V1&HW-CC-Date=20261008T175423Z&HW-CC-Expire=31536000000&HW-CC-Sign=2CF4DC2AA132C453E9692DF34FE440B0950DF37CA5B9ED560F2FB767E8BAD657)

4. 点击"部署"，即可查看到部署结果。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/bhGFQi63QLO1aDKRAvjZ2A/zh-cn_image_0000002361511036.png?HW-CC-KV=V1&HW-CC-Date=20261008T175423Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C3EFF2B61270C110D0C9E779D92E98DCB0F0720BD03CBD42B322EECCA85CEB3)

## 查看运行日志

> 说明
>
> 当前，日志功能需人工开通，可通过联系企业QQ：2851508860 / 2851508868进行申请，您需要向华为运营人员提供项目ID信息。

1. 在联机对战服务页面，选择"实时服务器 > 托管实时服务器"。
2. 点击"生产环境"对应"操作"列的"查看日志"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/82iyMR49TVyNdW_6HiTaAA/zh-cn_image_0000002542599613.png?HW-CC-KV=V1&HW-CC-Date=20261008T175423Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6F92D1A274E0DF0CC6F03E3E421A669342EEE79EDF506C5C2F32E01CE09C779)

3. 跳转到相同项目下的"云监控 > 日志服务"页面，在下拉选项中选择"云函数"，即可查看日志详情。您还可以通过右上角的时间筛选，查看不同时间段的数据，具体操作请参考[日志服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/cloudfunction-0000001432886916)。 说明
   >
   > 实时服务器日志中的message（消息内容）格式为"productId|message"。
