# 取消接入

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面取消快游戏接入。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/iIt4zyIWSpOM9CBrzb12_w/zh-cn_image_0000001885072261.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=322601507BA5A764F315233FD83FF9BCC761F9BD09EE5425410095C5032FBAE0)

2. 验证负责人的手机/邮箱，选择取消接入原因后点击"提交初审"，在弹出的"确定要取消接入互联网信息"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/7Lfbd3nQS6uP7q6RTrmgxA/zh-cn_image_0000001838911434.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=F0FEF710177149CF0656C485C29D37A59EDEE84FFB8B5E3B37EBEC1521577199)

3. 提交申请后，华为平台将自动审核您的申请，您需耐心等待通管局的审核。
