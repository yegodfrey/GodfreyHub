# 取消接入

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面取消快游戏接入。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/iIt4zyIWSpOM9CBrzb12_w/zh-cn_image_0000001885072261.png?HW-CC-KV=V1&HW-CC-Date=20261008T191354Z&HW-CC-Expire=31536000000&HW-CC-Sign=8385D0C4A1A995A930162CA13EAA4F339C5D52082501E221B8CBDCA29B33C3C1)

2. 验证负责人的手机/邮箱，选择取消接入原因后点击"提交初审"，在弹出的"确定要取消接入互联网信息"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/7Lfbd3nQS6uP7q6RTrmgxA/zh-cn_image_0000001838911434.png?HW-CC-KV=V1&HW-CC-Date=20261008T191354Z&HW-CC-Expire=31536000000&HW-CC-Sign=8B39CDA8D348867C3C13134B95FD0E38CA737AE2BE314122BB02B4A4C27EC615)

3. 提交申请后，华为平台将自动审核您的申请，您需耐心等待通管局的审核。
