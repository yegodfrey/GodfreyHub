# 变更核准（备案）

## 变更核准（备案）

在华为云核准（备案）系统中可以同时修改主体信息和快游戏信息。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面点击"变更备案"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/0ogzm1ruTLi2t8plvbI4CQ/zh-cn_image_0000001935646546.png?HW-CC-KV=V1&HW-CC-Date=20261008T150047Z&HW-CC-Expire=31536000000&HW-CC-Sign=873CC0F95B993F7349B25EE74253366E412247B2573B2BD4324E9C0CEAE0C9E4)
2. 在"主体信息"页面修改主办单位信息、负责人信息，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/-KK3Ft6QQA-SMJFUMmpifg/zh-cn_image_0000001935806002.png?HW-CC-KV=V1&HW-CC-Date=20261008T150047Z&HW-CC-Expire=31536000000&HW-CC-Sign=6ECEA94921C71B2FC1AA125EFFCEDA3EA2B80A0A0B5D25DFB1F2C7DC1BA6322C)

3. 在"互联网信息"页面勾选并修改快游戏信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/zrQIHQZKSqK1YmlyjxhFfg/zh-cn_image_0000001935646682.png?HW-CC-KV=V1&HW-CC-Date=20261008T150047Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A9DF909463F99CD91C2A894A75BFADE186619494EBF87D93398CF390A4A3807)

4. 在"上传资料"页面根据提示补充附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/r3gu9BUXRIekIWVMVnjU1w/zh-cn_image_0000001962845193.png?HW-CC-KV=V1&HW-CC-Date=20261008T150047Z&HW-CC-Expire=31536000000&HW-CC-Sign=0065C8C2925E7BCF463FEE83F2515CA9E0502C3ACB062C66173E9B6F00D7264D)

5. 在"真实性核验"页面由互联网信息负责人进行人脸视频认证，完成后点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/G4-4uq1dTgWv6st8KNByXg/zh-cn_image_0000001962845273.png?HW-CC-KV=V1&HW-CC-Date=20261008T150047Z&HW-CC-Expire=31536000000&HW-CC-Sign=848D778A1A46A3E428A4EB5E164D2BFB2C02762044C167F2AC8EA9A32D32623B)

6. 在"预览资料"页面核对填写的信息，完成后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/bF6Ub7LLSUirCpqxlDv7YA/zh-cn_image_0000002009925237.png?HW-CC-KV=V1&HW-CC-Date=20261008T150047Z&HW-CC-Expire=31536000000&HW-CC-Sign=A52D5F687B619CBC18ED8EEBC12560CF25B8440F4B0A3EC2B6D6B09313FCED70)

7. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
8. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
