# 鲸鸿动能激励政策（广告激励）

鲸鸿动能搭建鸿蒙生态全场景营销增长平台，全面升级HarmonyOS 5.0及以上系统级广告变现能力，提供多类专项激励与月度激励。汇聚亿级流量，激发营销新动能。

更多鲸鸿动能平台介绍请参见[广告投放知识图谱](https://developer.huawei.com/consumer/cn/doc/promotion/ads-ggtfzstp-0000002285988928)。
> 说明
>
> 如下两个鲸鸿动能激励政策（广告激励）政策可叠加使用。

## 一、2026年鲸鸿动能游戏行业激励政策

> 说明
>
> 2026年鲸鸿动能游戏行业激励政策的完整细则请以[2026年鲸鸿动能游戏行业激励政策](https://developer.huawei.com/consumer/cn/doc/promotion/ads-yxhyydjl-0000002160474788)为准。

政策周期：2026年7月1日-2026年12月31日。

无需报名，默认符合规则的产品均可参与。

* IAA游戏

  |**月度投放消耗额X（万元）**|**现金消耗部分返货比例**|**时长达标返货比例**|
  |:---------------|:-------------|:-----------|
  |10≤X＜300|30%|5%|
  |300≤X|40%|5%|
  |1、通过鲸鸿动能竞价广告买量带来的IAA游戏新用户，对该用户在该IAA游戏内产生的广告变现收入分成比调整为华为：开发者=1:9；该分成比例持续生效180天，到期后恢复为基础分成。 2、若某游戏用户的平均月活跃时长≥30min，该游戏投放现金部分可额外享受5%的返货激励。 3、该政策适用于全量华为终端用户。|||
