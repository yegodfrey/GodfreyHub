# 游戏侵权投诉方案

在华为应用市场/游戏中心上架的游戏均是由个人开发者或企业开发者提供的，为了保护您的版权、隐私、商标、专利等合法权益，华为应用市场制定侵权投诉通知和反通知方案，具体流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/V7Ts0dAITPmrSFKjhDaaXw/zh-cn_image_0000002415449805.png?HW-CC-KV=V1&HW-CC-Date=20260920T025430Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC0459601344AC0B54D5B372940E96DFAC08F8FE43C5F40B4DE456B0883D55F9)

* 若认为华为应用市场/游戏中心的某项应用或游戏侵犯了您的知识产权，您可以按[投诉通知](https://developer.huawei.com/consumer/cn/doc/app/50120#section1659416348287)流程进行处理。
* 若被投诉方认为未侵犯知识产权，应在3个工作日内按[投诉反通知](https://developer.huawei.com/consumer/cn/doc/app/50120#section14984122018294)流程进行处理。
