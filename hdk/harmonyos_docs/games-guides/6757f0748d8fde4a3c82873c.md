# 华为快游戏外部买量指南

### 广告主自主归因

广告归因是为了找出哪些广告触点对用户最终的转化行为起到了决定性的作用。投放平台会给广告主提供广告点击用户的OAID/IMEI等设备信息，广告主需将达到转化目标的用户信息与投放平台的广告点击信息进行匹配，并自主归因。

### 转化回传（可选）

广告主完成归因后，将发生转化行为的用户信息回传给投放平台，投放平台会关联转化用户与广告计划，并以此计算一次转化，同时跟踪每个广告计划的转化效果。
