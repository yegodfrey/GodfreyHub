# 打开API开关

您需在AppGallery Connect控制台打开对应服务的API开关：

* 快游戏必须打开**游戏服务** API开关。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/BbYNPzSpTuq3eAjg3779FA/zh-cn_image_0000002399803473.png?HW-CC-KV=V1&HW-CC-Date=20261008T185319Z&HW-CC-Expire=31536000000&HW-CC-Sign=953D09A691872CAEFBA08EA446BEB4DB0FE8F62B6E14399EE654AAE36AC0E05F)
* 快游戏必须接入账号登录服务，您需要打开**华为账号** API开关。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/nAlPL6oMT9OfSmt8GPzeLg/zh-cn_image_0000002366163680.png?HW-CC-KV=V1&HW-CC-Date=20261008T185319Z&HW-CC-Expire=31536000000&HW-CC-Sign=2383BD8BB9D01F55A15A4799EAA65FCA09B9924A2729D6F8347B749A705BC52C)
* 若快游戏接入华为支付服务，您需要先**[开通商户服务](https://developer.huawei.com/consumer/cn/doc/start/merchant-service-0000001053025967#section3513222624)** ，再打开**应用内支付服务** API开关。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/oe-EOx0jQE-Bb3U7CZ8hcQ/zh-cn_image_0000002399683573.png?HW-CC-KV=V1&HW-CC-Date=20261008T185319Z&HW-CC-Expire=31536000000&HW-CC-Sign=82250BD2E9EA3DAFD7FEB7F467F89A7C2B771DF550CB72FAAB18CF43B9873F89)
