# 本地查看

测试报告生成并保存到本地后，支持在报告列表中点击并在报告详情页查看相关数据。

1. 在主界面右侧点击"测试报告"进入报告列表页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/p-PAoSgvTzqmdJ9T-QJ_mQ/zh-cn_image_0000002382174221.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=9CB5308F1A1FE10D7843DF6470253215765E9E4670A81817EE1F9244036C5997)

2. 在报告列表页面，您可以将测试报告[上传至云端](https://developer.huawei.com/consumer/cn/doc/games-guides/games-hismartperf-cloudview-0000002321404213#section1365144213172)进行查看，同时还可以直接点击并打开查看。如需在本地查看数据测试报告，可打开对应报告文件夹查看保存在本地的Excel表格。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/H6j5Hq3ERXiq_Doy_KNehQ/zh-cn_image_0000002348294028.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=82620014D31A8A22F738D013F70971E4FD84F71AB4E73A2C5DB3B253007763A6)
3. 在测试报告详情页，您可以查看采集到的数据项，数据项的详细解析请参见[数据解析](https://developer.huawei.com/consumer/cn/doc/games-guides/games-hismartperf-system-data-0000002321404217)。为了方便查看数据，在测试报告详情页支持如下操作：
   * 在"**测试详情** "、"**GPU counter** "版块，鼠标悬停曲线任一时间点，您可以查看数据项该时间点的数据。左键点击曲线出现固定实线，您可以横向对比数据，右键取消固定实线。拖动曲线下方时间轴，所有曲线的时间轴随之变动。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/KkXoaB6RReKWJJmGgwhAsQ/zh-cn_image_0000002348294024.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=F88EAE466128561B8626E75DD7336585F0DCF100DCFAB2300AD5937A8D100991)
   * 在"**测试详情** "和"**GPU counter** "版块，框选曲线任一区间的数据后，支持展示该区间的平均值，也支持保存该区间的测试报告至本地或云端。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/JjeKFCpBRd2h-9f_2jqJSw/zh-cn_image_0000002348453804.gif?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=F497CB109B5F1E9567068D258F9F3EFD10D03744A45BAF743701A6AA02028C1D)
