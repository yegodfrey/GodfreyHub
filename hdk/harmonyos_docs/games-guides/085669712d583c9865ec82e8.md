# 导入Package

在团结Editor中导入PGD Package，为接下来的游戏开发做准备。

## 前提条件

[下载PGD C# Package](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/sdk-0000002468289653)。

PGD动态库运行的目标框架为.NET Standard 2.1。

## 导入方式一：使用团结Editor

1. 在团结Hub打开项目工程。
2. 进入团结Editor，点击"Window > Package Manager"，打开Package Manager，点击左上角"Add Package From Disk"，将本地下载好的PGD导入团结工程。 说明
   >
   > com.huawei.pgd为示例包名，请以实际下载的PGD Package文件名为准。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/5YNXJPYUQ4ClOiBKtJZaLA/zh-cn_image_0000002532549685.png?HW-CC-KV=V1&HW-CC-Date=20261008T150417Z&HW-CC-Expire=31536000000&HW-CC-Sign=2BFDDD267E2EC8B09946F3684B0068B42DBD5ADECD606FE729C060B92AFA8ED2)
3. 导入成功后，在"Window > Package Manager"中查看。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/e7Fp-O2hTLW5vt6UU6Wa8g/zh-cn_image_0000002532469643.png?HW-CC-KV=V1&HW-CC-Date=20261008T150417Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E6534115EEAFF26D52D9391F06542BACFC15A7992D45E56B3C132F9678049AF)

## 导入方式二：使用资源管理器

此处以Windows操作系统的资源管理器为例，My project为游戏项目工程。

1. 将PGD Package放入My project项目工程的文件夹内。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/zjjfeDxOTz6pB3N_ik2Dhg/zh-cn_image_0000002500789616.png?HW-CC-KV=V1&HW-CC-Date=20261008T150417Z&HW-CC-Expire=31536000000&HW-CC-Sign=EF35C4B4093107082028B3F5BB5D2E0B85DDB604D1F04B5F2F6A4555B21EEE0D "点击放大")

2. 打开当前项目工程文件夹内的Packages，修改manifest.json文件，在dependencies内新增com.huawei.pgd的依赖，并配置到com.huawei.pgd所在的文件夹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/FdllBXzhSu6XCRHFuJW7jA/zh-cn_image_0000002500629768.png?HW-CC-KV=V1&HW-CC-Date=20261008T150417Z&HW-CC-Expire=31536000000&HW-CC-Sign=7AF2143FDC2C7C92F259F537517C1A7426071C8EA8F566FC31939A7D6857DD6E "点击放大")

   "com.huawei.pgd"建议使用相对路径，请根据实际情况填写正确路径。
