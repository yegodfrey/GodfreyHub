# 键鼠转触控映射设置使用指导

若HarmonyOS游戏支持输入转触控能力，玩家连接键鼠外设后可在游戏内自行设置键鼠触控映射关系，实现用键鼠操作畅玩手游。

## 打开设置界面

玩家连接键鼠外设进入游戏后，按"Ctrl+Shift+I"键即可打开设置界面，设置界面如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/x6qCtZbNQaaIFp4IEEw-Vg/zh-cn_image_0000002566169017.png?HW-CC-KV=V1&HW-CC-Date=20261008T144245Z&HW-CC-Expire=31536000000&HW-CC-Sign=23CD94FAAC4C235D22EA97021F32091F37F3543C3059012C21B8DF1F046CC463)

## 触控映射

用鼠标将设置面板上的辅助按键拖放至游戏界面，点击已放置按键图标编辑映射键值及设置属性（点击叉号取消设置），即可实现触控映射。直接点击游戏界面空白区域可快捷放置"普通点击"按键。
