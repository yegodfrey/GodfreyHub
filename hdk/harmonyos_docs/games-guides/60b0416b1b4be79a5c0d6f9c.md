# 系统能力适配

引擎中的系统能力需要调用HarmonyOS 5.0及以上系统接口实现。常见系统能力参考如下：

* 权限申请，请参考[应用权限申请](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-permission-application)。
* 位置服务，请参考[位置服务开发](https://developer.huawei.com/consumer/cn/doc/atomic-guides/atomic-location-development)。
* 传感器相关，请参考[Sensor Service Kit（传感器服务）](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/sensor-service-kit)。
* Webview支持，请参考[ArkWeb（方舟Web）](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkweb-api)。
* 网络状态感知，请参考[网络状态感知场景](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/network-information-query-connection-management#网络状态感知场景)。
