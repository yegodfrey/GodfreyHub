# CPU trace

CPU trace展示CPU调度、频点、进程线程时间片、绘帧、perf等数据的性能功耗，展示方式为泳道图，支持图形用户界面GUI操作、分析数据。

## CPU工作状态

CPU的工作状态主要有"0"、"1"、"2"、"3"。"0"表示"工作中"；"1"、"2"、"3"表示"不在工作状态"，且数值越大代表CPU睡眠程度越深，功耗也越低。

* 查看任一核心CPU的idle状态信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/H_kM9JRCSCuuRcqgwU2s1A/zh-cn_image_0000002348294160.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB1ECB963E050B0F1159AA2C48A0A2053306F41874FBEC5DED8A3C9D1D54C36C)

* 框选多个CPU的idle状态。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/gdvLtbHuREWSAXkRSVKnMQ/zh-cn_image_0000002348294156.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=43FA44958373E4D6ADF1D7F5D70D1CE87E7110FEFBEE43391B7D13492B6DCC54)

## Hiperf数据

Hiperf性能数据体现了进程的函数调用情况，在测试过程中测试工具会每隔一段时间去访问CPU的运行栈。您可以框选查看Hiperf数据。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/n189AN0wQIuz8pOnKKoA3Q/zh-cn_image_0000002348453940.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=821A088DE5CCA91974DEE94E9725B154784206317DCE9A7FB80989BAEE2047A4)

您也可以切换到火焰图进行可视化观察。观察调用函数的运行时长，若函数的实际运行时长偏离预估时长，建议优化。
