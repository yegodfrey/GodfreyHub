# 生成并配置证书指纹

证书指纹可以保证快游戏的完整性和安全性。在快应用IDE中生成，并在AGC控制台进行配置。下载快应用IDE请[前往快应用IDE下载页](https://developer.huawei.com/consumer/cn/doc/Tools-Library/quickapp-ide-download-0000001101172926#section8185184915)。

1. 在华为快应用IDE菜单栏选择"工具 > 生成证书"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/ZnHMJBsRRJGnrjNtEAan9A/zh-cn_image_0000002510070406.png?HW-CC-KV=V1&HW-CC-Date=20260920T025431Z&HW-CC-Expire=31536000000&HW-CC-Sign=777A9D0E5216FACF2DC525E192E81AE808110DE60852561ED5FDD2278A8C2645)

2. 右下角弹出提示窗口，点击"创建签名"创建签名文件。您也可以点击"导入签名"导入本地已有的签名文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/gf1-HWfJQcmVPje3LGmOxQ/zh-cn_image_0000002509910414.png?HW-CC-KV=V1&HW-CC-Date=20260920T025431Z&HW-CC-Expire=31536000000&HW-CC-Sign=584CF6514EECDA2566FF8ED8B3D01CF7326749D3D64B7E1BEC554D1972DF2336)

3. 在弹出的"创建新的签名"窗口中点击"创建"即可成功创建签名文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/LcfuW7MiQAOS74KIDFTkHg/zh-cn_image_0000002541550393.png?HW-CC-KV=V1&HW-CC-Date=20260920T025431Z&HW-CC-Expire=31536000000&HW-CC-Sign=9DDF8D84D2C503EA1C9D7E535F0795ADFF2A1BD0F9B3AC7BF9FA5F06886F8EE4)

4. 您可以在菜单中再次选择"工具 > 生成证书"查看证书信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/Jloe4DvcTnCKuLZNHyPxYg/zh-cn_image_0000002541510401.png?HW-CC-KV=V1&HW-CC-Date=20260920T025431Z&HW-CC-Expire=31536000000&HW-CC-Sign=244D34E9843E7D23CBA57862A9C979627F19BC881AC43756579ACEC13171684C)

5. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"，在项目卡片列表中选择待配置证书指纹的项目及项目下的快游戏。
6. 在"项目设置 > 常规"页面的"应用"区域，在"SHA256证书指纹"后面填写生成的SHA256指纹，完成后点击"保存"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/WYkVe9_4QL6xatxlsmMkjQ/zh-cn_image_0000002510070408.png?HW-CC-KV=V1&HW-CC-Date=20260920T025431Z&HW-CC-Expire=31536000000&HW-CC-Sign=13DAC4ABBCD6CCE761CCC66E866F3E4305D46329203E24D765299B024429528A)
