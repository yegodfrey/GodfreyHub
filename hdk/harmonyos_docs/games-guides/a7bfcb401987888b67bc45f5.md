# 游戏代码适配

如果游戏中有针对不同平台进行适配的代码，需要先判断HarmonyOS 5.0及以上平台并添加对应的适配代码。

```screen
checkHarmonyOS() {
let os = Laya.Browser.window.
conch.config.getOS();
return os == 'Conch-ohos';
}
```
