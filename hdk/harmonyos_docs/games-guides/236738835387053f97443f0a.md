# 接入动态渲染SDK

请按照不同版本的游戏引擎接入动态渲染SDK。

## 4.26(含)至5.0(不含)游戏引擎的接入指导

### 前提条件

* 已安装4.26(含)至5.0(不含)版本的游戏引擎，且游戏引擎已适配OpenHarmony平台（arm64-v8a）。
* 已[下载动态渲染dynamicrender-ue4](https://developer.huawei.com/consumer/cn/doc/games-guides/pgp-dynamic-render-download-0000002649796230)。

### 第一步：导入插件

将完整**dynamicrender** 文件夹复制到如下任一位置**（游戏引擎或游戏工程）**：

* 游戏引擎：Engine/Plugins/dynamicrender-ue4-16.3.1.300 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dd/v3/b8MSr_3jShio3Np62xImpg/zh-cn_image_0000002722861925.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2B52022C942788C2E2128C69E0754A941ED97285E03F33E1D14B64355149EB3)

* 游戏工程：YourProject/Plugins/dynamicrender-ue4-16.3.1.300 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/F__J8E-uSQGuUy8DsM2GKA/zh-cn_image_0000002722981867.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=8635C45E0DA01EB216FBBFD084E0923DB46EF567DEBD4BFFFA4051F649610A37)

### 第二步：启用插件

* 方式一 打开Editor，选择"Plugins > DynamicRender"，勾选Dynamic Render，启用插件。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/b-oJayVVQEi5JFZ2tOKPIQ/zh-cn_image_0000002721282567.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=EF5A701CC8782B8E5DB27E016DE5EB5CFE42D62ABF0FA6908D74C1DAAFBAAC58)
* 方式二

  在项目根目录的**.uproject** 文件中添加插件依赖，启用插件。示例如下：

  ```screen
  "Plugins": [
  {
    "Name": "DynamicRender",
    "Enabled": true
  }
  ]
  ```

### 插件配置项说明

DynamicRender插件的配置文件路径在YourProject/config/DefaultDynamicRender.ini路径下。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/eMzWC4uITVKiwa9mg2uIkA/zh-cn_image_0000002691603812.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=C9594CEF120636FC06FE4D6785220368DF6853049C770134FC87DFEA98CA6BAD)

|配置项|默认值|CVar|ini|说明|
|:--------------------------|:----|:-----------------------------------------|:---------------------------|:----------------------------------------|
|Enable Dynamic Render|true|r.DynamicRender.Enable|bEnableDynamicRende|动态渲染总开关。|
|Detection Interval (Frames)|6|r.DynamicRender.FramesToSkip|FramesToSkip|检测间隔。 默认每6帧检测一次。|
|Idle|false|r.DynamicRender.System.Idle.Enable|bEnableIdleHeuristic|挂机检测。 当系统判断当前处于挂机状态降低分辨率和帧率。 需注意当前挂机暂未开放。|
|Device Motion|true|r.DynamicRender.System.DeviceMotion.Enable|bEnableCameraMotionHeuristic|设备颠簸检测。 当系统判断当前处于运动中并且在口袋里时降低分辨率和帧率。|
|Camera Motion|true|r.DynamicRender.System.CameraMotion.Enable|bEnableDeviceMotionHeuristic|相机运动检测。 当系统判断玩家视角处于快速转动时降低分辨率。|
|Face Down|true|r.DynamicRender.System.FaceDown.Enable|bEnableFaceDownHeuristic|倒扣检测。 当系统判断当前处于倒扣状态时，降低分辨率和帧率。|

## 5.x游戏引擎的接入指导
