# 接入动态渲染SDK

请按照不同版本的游戏引擎接入动态渲染SDK。  

#### 4.26(含)至5.0(不含)游戏引擎的接入指导

#### 前提条件

* 已安装4.26(含)至5.0(不含)版本的游戏引擎，且游戏引擎已适配OpenHarmony平台（arm64-v8a）。
* 已[下载动态渲染dynamicrender-ue4](https://developer.huawei.com/consumer/cn/doc/games-guides/pgp-dynamic-render-download-0000002649796230)。  

#### 第一步：导入插件

将完整dynamicrender文件夹复制到如下任一位置（游戏引擎或游戏工程）：

* 游戏引擎：Engine/Plugins/dynamicrender-ue4-16.3.1.300 ![](https://media:801788333997965915)

* 游戏工程：YourProject/Plugins/dynamicrender-ue4-16.3.1.300 ![](https://media:801788333997988916)

#### 第二步：启用插件

* 方式一 打开Editor，选择"Plugins \> DynamicRender"，勾选Dynamic Render，启用插件。

  ![](https://media:801788333998018917)
* 方式二  
  在项目根目录的.uproject文件中添加插件依赖，启用插件。示例如下：

  ```
  "Plugins": [
  {
    "Name": "DynamicRender",
    "Enabled": true
  }
  ]
  ```

#### 插件配置项说明

DynamicRender插件的配置文件路径在YourProject/config/DefaultDynamicRender.ini路径下。  
![](https://media:801788333998049918)  

|配置项|默认值|CVar|ini|说明|
|:--------------------------|:----|:-----------------------------------------|:---------------------------|:----------------------------------------|
|Enable Dynamic Render|true|r.DynamicRender.Enable|bEnableDynamicRende|动态渲染总开关。|
|Detection Interval (Frames)|6|r.DynamicRender.FramesToSkip|FramesToSkip|检测间隔。 默认每6帧检测一次。|
|Idle|false|r.DynamicRender.System.Idle.Enable|bEnableIdleHeuristic|挂机检测。 当系统判断当前处于挂机状态降低分辨率和帧率。 需注意当前挂机暂未开放。|
|Device Motion|true|r.DynamicRender.System.DeviceMotion.Enable|bEnableCameraMotionHeuristic|设备颠簸检测。 当系统判断当前处于运动中并且在口袋里时降低分辨率和帧率。|
|Camera Motion|true|r.DynamicRender.System.CameraMotion.Enable|bEnableDeviceMotionHeuristic|相机运动检测。 当系统判断玩家视角处于快速转动时降低分辨率。|
|Face Down|true|r.DynamicRender.System.FaceDown.Enable|bEnableFaceDownHeuristic|倒扣检测。 当系统判断当前处于倒扣状态时，降低分辨率和帧率。|

#### 5.x游戏引擎的接入指导

#### 前提条件

* 已安装5.x版本的游戏引擎，且游戏引擎已适配OpenHarmony平台（arm64-v8a）。
* 已[下载动态渲染dynamicrender-ue5](https://developer.huawei.com/consumer/cn/doc/games-guides/pgp-dynamic-render-download-0000002649796230)。
* 触摸和键盘遮挡启发式需要使用Vulkan后端，否则不生效。  

#### 第一步：导入插件

将完整dynamicrender文件夹复制到如下任一位置（游戏引擎或游戏工程）：

* 游戏引擎：Engine/Plugins/dynamicrender-ue5-16.3.1.300 ![](https://media:801788333998080919)

<!-- -->

* 游戏工程：YourProject/Plugins/dynamicrender-ue5-16.3.1.300 ![](https://media:801788333998108920)

#### 第二步：启用插件

* 方式一 打开Editor，选择"Plugins \> DynamicRender"，勾选Dynamic Render，启用插件。

  ![](https://media:801788333998146921)
* 方式二  
  在项目根目录的.uproject文件中添加插件依赖，启用插件。示例如下：

  ```
  "Plugins": [
  {
    "Name": "DynamicRender",

  }
  ]
  ```

#### 插件配置项说明

DynamicRender插件的配置文件路径在YourProject/config/DefaultDynamicRender.ini路径下。

![](https://media:801788333998182922)  

|配置项|默认值|CVar|ini|说明|
|:--------------------------|:----|:-----------------------------------------|:---------------------------|:----------------------------------------|
|Enable Dynamic Render|true|r.DynamicRender.Enable|bEnableDynamicRende|动态渲染总开关。|
|Detection Interval (Frames)|6|r.DynamicRender.FramesToSkip|FramesToSkip|检测间隔。 默认每6帧检测一次。|
|Idle|false|r.DynamicRender.System.Idle.Enable|bEnableIdleHeuristic|挂机检测。 当系统判断当前处于挂机状态降低分辨率和帧率。 需注意当前挂机暂未开放。|
|Face Down|true|r.DynamicRender.System.FaceDown.Enable|bEnableFaceDownHeuristic|倒扣检测。 当系统判断当前处于倒扣状态时，降低分辨率和帧率。|
|Device Motion|true|r.DynamicRender.System.DeviceMotion.Enable|bEnableDeviceMotionHeuristic|设备颠簸检测。 当系统判断当前处于运动中并且在口袋里时降低分辨率和帧率。|
|Camera Motion|true|r.DynamicRender.System.CameraMotion.Enable|bEnableCameraMotionHeuristic|相机运动检测。 当系统判断玩家视角处于快速转动时降低分辨率。|
|Touch VRS|true|r.DynamicRender.TouchVRS.Enable|bEnableTouchVRSHeuristic|触控遮挡检测。 当系统判断玩家手指触摸屏幕是降低触控处分辨率|
|Keyboard VRS|true|r.DynamicRender.KeyboardVRS.Enable|bEnableKeyboardVRSHeuristic|虚拟键盘检测。 当系统判断弹出虚拟键盘时降低遮挡部分的分辨率|
