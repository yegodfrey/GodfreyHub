# 成功案例

#### 工具介绍

华为游戏性能调优工具HiSmartPerf依托华为芯片和操作系统的优势，通过工具监测，准确、高效地采集到游戏运行时的CPU、GPU等性能数据，了解游戏的性能状况。您可以使用工具测试特定的游戏场景、固定的游戏环境等，分析问题、调优程序，在游戏优化之后，使用工具再次验证优化收益。  

#### 案例说明

使用游戏性能调优工具帮助一款即将上线华为游戏中心的新游戏进行性能测试，重点关注在高画质配置下游戏的性能表现，整体性能如下：

![](https://media:801788333996914895)

通过FPS发现在某一时段场景下存在掉帧问题：

![](https://media:801788333996961896)GPU频率也在这段时间内达到设备负载峰值：

![](https://media:801788333997000897)继续跟进GPU counter数据，可以观察到这段时间运行Cycle明显高于其他时段：

![](https://media:801788333997051898)在GPU counter数据中进一步跟进观察，定位到这段场景下Overdraw过高的问题：

![](https://media:801788333997107899)继续对该游戏的战斗场景进行测试，整体性能情况如下：

![](https://media:801788333997162900)

发现在一段时间后，帧率发生了明显的降低：

![](https://media:801788333997201901)

定位到是由于温度过高引起的温控保护，Soc温度达到了64°C：

![](https://media:801788333997241902)继续查看功耗数据，发现功耗在温控保护前一直处于较高状态，达到了3W：

![](https://media:801788333997281903)

进一步跟进其他数据，发现在温控保护前GPU频率也一直处于满负荷状态，具有可进一步优化的空间：

![](https://media:801788333997320904)

通过游戏性能调优工具，有效地帮助CP定位到游戏在某段场景下Overdraw过高导致的掉帧问题，以及在高画质战斗场景下存在的高GPU负载高功耗问题，帮助CP在游戏上线前针对性地采取优化措施。
