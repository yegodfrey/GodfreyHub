# 认领核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/kCFftUWvRkWO4J7-38lqGw/zh-cn_image_0000001939010557.png?HW-CC-KV=V1&HW-CC-Date=20261008T161932Z&HW-CC-Expire=31536000000&HW-CC-Sign=05F2BFECE4A51CE5952FE292AFBDFEA304E00C9E743C8E7569FC83DA50314546)

2. 填写待认领的主办单位和快游戏信息后，提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/8vEuZh5bRv2CV5S60vUmBA/zh-cn_image_0000001939041085.png?HW-CC-KV=V1&HW-CC-Date=20261008T161932Z&HW-CC-Expire=31536000000&HW-CC-Sign=023D05AF80156529FC09275BF2F6AF0D9B5B78804166CCB29C66ABAC0B7F21BD)

3. 华为工作人员将在1~2个工作日内完成审核，审核结果将以短信或邮件形式通知，在此期间请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/NQg6Dr9BTeCzHQuFw1NixA/zh-cn_image_0000001900091012.png?HW-CC-KV=V1&HW-CC-Date=20261008T161932Z&HW-CC-Expire=31536000000&HW-CC-Sign=C2147C252CD586B6E513E824D0C69187AA27E0FB1F7944312A35C40173314DA2)
