# 认领核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/kCFftUWvRkWO4J7-38lqGw/zh-cn_image_0000001939010557.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=8214D29F73EF2532D1CB1E64BA742EBA5F9339FFCD1B27D431E7D9659A0689E1)

2. 填写待认领的主办单位和快游戏信息后，提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/8vEuZh5bRv2CV5S60vUmBA/zh-cn_image_0000001939041085.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=60CB59A173E5EA5EF610659ADEC8096BC60D40D40B328BB36EE12D0071619BB5)

3. 华为工作人员将在1~2个工作日内完成审核，审核结果将以短信或邮件形式通知，在此期间请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/NQg6Dr9BTeCzHQuFw1NixA/zh-cn_image_0000001900091012.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B4E3A17003EBB1B0942C3CCD3C6C429C2E32D0E50C7A08388D6646738D9FE51)
