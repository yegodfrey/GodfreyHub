# 应用质量管理（APMS）

应用质量管理服务（Application Performance Management Service，简称APMS）是华为面向鸿蒙应用开发者打造的智能化运维平台，构建了涵盖"故障指标---故障告警---故障分析---质量报告"的全链路质量保障体系。平台提供可视化多维指标大盘，实时聚合稳定性、性能、功耗等关键运行指标，实现对应用健康状态的全局洞察。支持对关键指标设置告警规则，提供短信、邮件、Webhook等多种触达方式，确保开发者能够及时感知并响应故障。平台基于鸿蒙应用故障模式库，深度分析端侧事件与日志数据，自动完成根因诊断与聚类，助力开发者高效故障定位与定界。质量报告提供应用在真实用户环境中的运行质量全貌，帮助开发者从"被动救火"转向"主动治理"，持续提升应用质量和用户体验。更多介绍及接入指导请参见[应用质量管理（APMS）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-apms-0000002235870062)。
