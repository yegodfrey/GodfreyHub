# 内容创作管理

游戏内容创作帮助开发者创作优质内容提升游戏曝光度与玩家互动，开发者可以在AGC控制台创建并管理自己游戏的图文或视频内容，提交上线有机会展示到游戏中心客户端不同区位，让更多的玩家注意到游戏讯息，提升关注度。

#### 内容管理

您可以在"内容管理"创建并管理自己游戏的内容作品。根据主体部分所属类型，内容可分为"文章"、"内容"和"动态"。  

#### 功能入口

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，在首页左上角"全部服务"中搜索"游戏内容创作"，点击进入"内容创作管理"页面。  

#### 创建内容

1. 进入"内容创作管理"页面后，点击"游戏内容创作 \> 内容管理 \> 文章"。
2. 点击右上角"发布"，进入内容编辑页面。 ![](https://media:101783060611487265)

3. 在内容编辑界面进行内容创作。
   * 发文章 ![](https://media:101783060611526266)

     |参数|说明|
     |:----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
     |标题|1\~60个字符。 说明： Harmony 4.0及以下版本游戏中心客户端暂不支持展示以下功能：标题式样、背景色、引言、文字对齐和视频。|
     |正文|使用编辑器进行内容主体撰写。最多10000个字符。右侧可预览查看内容展示效果。支持如下功能组件： * ![](https://media:101783060611551267) 游戏组件：支持通过AppId搜索游戏插入正文。 * ![](https://media:101783060611602268) 插入活动：支持通过活动ID在正文中插入活动。 * ![](https://media:101783060611627269) 插入投票：支持添加文字类型、图片类型或帖子类型投票。 * ![](https://media:101783060611653270) 插入话题：支持搜索已有话题或新建话题插入正文。 * ![](https://media:101783060611678271) 导入：支持选择docx类型文档导入内容到正文中。 说明： 正文中插入图片不超过三十张。单张图片不超过10M。|
     |封面图片|只能上传1张图片，要求如下： * 尺寸大小不能低于160\*160 px。 * 单张图片的大小不超过10MB。 * 格式支持jpg、bmp、png。|
     |相关文章|选择相关文章，最多添加10个。|
     |发布至论坛|选择需要发布的论坛。 说明： 内容一旦发布或保存草稿，论坛版块信息不可更新。|
     |发布时间|可选"立即发布"或"定时发布（仅支持指定2h-7天内）"。|
     |-|勾选是否包含AI生产内容。|

   * 发视频 ![](https://media:101783060611718272)

     |参数|说明|
     |:----|:------------------------------------------------------------------------------|
     |标题|1\~60个字符。 说明： Harmony 4.0及以下版本游戏中心客户端暂不支持展示以下功能:标题式样、背景色、引言、文字对齐和视频。|
     |视频简介|1\~1000个字符。|
     |话题|插入话题。搜索已有话题或新建话题插入视频简介中。|
     |投票|插入投票。支持添加文字类型、图片类型或帖子类型投票。|
     |视频|添加视频，最大支持1GB视频文件，推荐使用mp4、mov格式。|
     | |说明： <br />|
     |封面图片|只能上传1张图片，要求如下： * 尺寸大小不能低于160 x 160 px。 * 单张图片的大小不超过1MB。 * 格式支持jpg、bmp、png、webp。|
     |相关文章|选择相关文章，最多添加10个。|
     |发布至论坛|选择需要发布的论坛。 说明： 内容一旦发布或保存草稿，论坛版块信息不可更新。|
     |发布时间|可选"立即发布"或"定时发布（仅支持指定2h-7天内）"|
     |-|勾选是否包含AI生产内容。|

   * 发动态  
     ![](https://media:101783060611750273)  

     |参数|说明|
     |:----|:-------------------------------------------------------------------|
     |标题|1\~60个字符。 说明： Harmony 4.0及以下版本游戏中心客户端暂不支持展示以下功能:标题式样、背景色、引言、文字对齐和视频。|
     |正文|1\~1000个字符。|
     |话题|插入话题。搜索已有话题或新建话题插入动态正文中。|
     |投票|插入投票。支持添加文字类型、图片类型或帖子类型投票。|
     |图片|最多可上传9张图片。|
     |发布至论坛|选择需要发布的论坛。 说明： 内容一旦发布或保存草稿，论坛版块信息不可更新。|
     |发布时间|可选"立即发布"或"定时发布（仅支持指定2h-7天内）"|
     |-|勾选是否包含AI生产内容。|

4. 点击"保存草稿"将已编辑内容保存，或点击"发表"将内容提交审核。  

#### 管理内容

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，在首页选择"全部服务"，并搜索"游戏内容创作"，点击进入"游戏内容创作 \> 内容管理 \> 文章"页面。
2. 页面展示已创建的内容列表，可切换页签查看动态、文章和视频内容。点击操作列的"编辑"和"删除"可对内容进行二次编辑或删除操作。 ![](https://media:101783060611781274)
