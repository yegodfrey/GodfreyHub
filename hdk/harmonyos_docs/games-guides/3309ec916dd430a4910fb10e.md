# 业务介绍

为了在游戏程序中充分发挥麒麟芯片和HarmonyOS 6.0及以上操作系统的软硬协同优势，进一步提升游戏运行性能表现、降低能耗，华为推出了基于游戏引擎的花瓣游戏管线（PGP，Petal Game Pipeline）。

该管线工具涵盖一系列解决方案SDK，例如[动态渲染SDK](https://developer.huawei.com/consumer/cn/doc/games-guides/pgp-dynamic-render-0000002648317738)，通过将麒麟芯片和HarmonyOS基础能力固化到游戏引擎中，并针对性优化引擎的渲染管线、资产管线等核心流程，充分释放硬件和操作系统性能潜力，让游戏运行更流畅、画面表现更优秀、整体功耗进一步降低。
