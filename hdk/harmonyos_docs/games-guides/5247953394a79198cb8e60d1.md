# 音视频适配

## 音频

音频适配建议引擎使用OHAudio，不推荐使用OpenSL ES。若之前已使用OpenSL ES，请参考[从OpenSL ES切换到OHAudio(C/C++)](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/replace-opensles-by-ohaudio)进行切换。

* 音频播放功能参考[推荐使用OHAudio开发音频播放功能(C/C++)](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/using-ohaudio-for-playback)
* 音频录制功能参考[推荐使用OHAudio开发音频录制功能(C/C++)](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/using-ohaudio-for-recording)

适配过程中，需要关注引擎音频使用的音频流类型，游戏建议使用STREAM_USAGE_GAME音频流。常用的音频流类型及介绍请参见[使用合适的音频流类型](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/using-right-sourcetype-for-recording)。

## 视频

请参考[AVCodec Kit简介](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/avcodec-kit-intro)，了解音视频编解码服务，重点是视频部分。

请参考[视频解码](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/video-decoding)，在引擎中解码获取引擎渲染的原始像素数据。
