# 游戏代码适配

HarmonyOS 5.0及以上平台因为安全问题屏蔽部分游戏项目中原来的函数、方法，若您有用到，需对游戏代码中不匹配的函数、方法等进行手动修改适配。  

#### Cocos Creator 2.X

#### 添加cc.sys.OS_OPENHARMONY平台

游戏代码中可能有Android、iOS等多种平台的判断和处理逻辑，需在平台判断分支处加上对HarmonyOS 5.0及以上平台的处理。您可以全局搜索关键字cc.sys.os，具体修改内容可根据实际情况进行分析。  
例如：

```
if(cc.sys.os == cc.sys.OS_ANDROID){
// 游戏逻辑
}
```

修改为：

```
if(cc.sys.os == cc.sys.OS_ANDROID || cc.sys.os == cc.sys.OS_OPENHARMONY){
// 游戏逻辑
}
```

#### 支持WebAssembly功能

HarmonyOS平台不支持WebAssembly功能，请按照如下代码修改引擎底层代码，可以在HarmonyOS平台上支持WebAssembly功能。

```
// 在该路径下的文件中进行修改：resources\cocos2d-x\cocos\scripting\js-bindings\jswrapper\jsvm\ScriptEngine.cpp
void ScriptEngine::mainLoopUpdate() {
    // empty implementation
    // Run all tasks
    JSVM_Status status{};
    for (bool runTasks = true; runTasks;) {
        // Execute one foreground task (if one exists), then microtasks.
        NODE_API_CALL(status, _env, OH_JSVM_PumpMessageLoop(_vm, &runTasks));
        if (runTasks) {
            NODE_API_CALL(status, _env, OH_JSVM_PerformMicrotaskCheckpoint(_vm));
        }
    }
}


// 在该路径下的文件中进行如下修改：resources\cocos2d-x\cocos\platform\openharmony\OpenHarmonyPlatform.cpp
void OpenHarmonyPlatform::tick() {
    EventDispatcher::dispatchTickEvent(dt);	
    se::ScriptEngine::getInstance()->mainLoopUpdate(); // 增加这一行
}
```

#### Cocos Creator 3.X

#### 添加sys.OS_OPENHARMONY平台

游戏代码中可能有Android、iOS等多种平台的判断和处理逻辑，需在平台判断分支处加上对HarmonyOS 5.0及以上平台的处理。您可以全局搜索关键字sys.os，具体修改内容可根据实际情况进行分析。  
例如：

```
if(sys.os == sys.OS_ANDROID){
// 游戏逻辑
}
```

修改为：

```
if(sys.os == sys.OS_ANDROID || sys.os == sys.OS_OPENHARMONY){
// 游戏逻辑
}
```

#### 支持WebAssembly功能

* Cocos Creator 3.8.8及以上版本已支持WebAssembly功能。
* Cocos Creator 3.8.7版本不支持WebAssembly功能，请添加如下代码以支持WebAssembly功能。

  ```
  // 在该路径下的文件中进行修改：native/cocos/bindings/jswrapper/jsvm/ScriptEngine.cpp
  void ScriptEngine::mainLoopUpdate() {
      // empty implementation
      // Run all tasks
      JSVM_Status status{};
      for (bool runTasks = true; runTasks;) {
          // Execute one foreground task (if one exists), then microtasks.
          NODE_API_CALL(status, _env, OH_JSVM_PumpMessageLoop(_vm, &runTasks));
          if (runTasks) {
              NODE_API_CALL(status, _env, OH_JSVM_PerformMicrotaskCheckpoint(_vm));
          }
      }
  }
  ```
