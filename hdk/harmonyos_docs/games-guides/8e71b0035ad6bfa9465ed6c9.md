# 分享报告

工具支持在本地或云端分享测试报告。
> 说明
>
> 报告必须[上传](https://developer.huawei.com/consumer/cn/doc/games-guides/games-hismartperf-cloudview-0000002321404213#section1365144213172)后才能分享。

1. 在数据报告列表中，选择对应的测试报告，点击分享。
   * 本地分享 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/bWSl9DM-QPGrQKuTzKhvwg/zh-cn_image_0000002348454260.png?HW-CC-KV=V1&HW-CC-Date=20261008T163044Z&HW-CC-Expire=31536000000&HW-CC-Sign=89A51493AA21780023E1F038C850CB614419BFB4EDA97FEC623F61C40E721C21)

   * 云端分享 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/Ek6cP6KATGumvnc0V5Vbqw/zh-cn_image_0000002348294484.png?HW-CC-KV=V1&HW-CC-Date=20261008T163044Z&HW-CC-Expire=31536000000&HW-CC-Sign=638EF2306052FD11BE86081562533163B70CFFE422C78E692E1AB69AD40B200F)

2. 在"分享设置"弹窗中选择"开启分享"，则非团队成员无需登录账号可通过二维码、网址链接访问该测试报告，其他团队账号可通过"分享码"访问该测试报告。 说明
   >
   > 若选择"关闭分享"，非团队成员无法访问该测试报告，可通过邀请其加入团队后查看此报告。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/aRKyk5cjQ2CeF0HSViGdvw/zh-cn_image_0000002382054977.png?HW-CC-KV=V1&HW-CC-Date=20261008T163044Z&HW-CC-Expire=31536000000&HW-CC-Sign=F87C541C63EA91F2E90E322522A0A62DD20B43DC8223352BB61157CB4C870CAF)
3. 如获取到其他团队分享的二维码或网址，可直接扫描二维码或点击网址查看测试报告。报告为html格式，用户点击链接后在浏览器中打开，与云端界面一致，不支持前进、后退、收藏等操作 。 说明
   >
   > 在测试报告被设置关闭分享后，则无法再通过分享过的二维码、网址继续查看。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/jjUJS7bLQ_KWPICYWO9Lvg/zh-cn_image_0000002348454264.png?HW-CC-KV=V1&HW-CC-Date=20261008T163044Z&HW-CC-Expire=31536000000&HW-CC-Sign=2C7245990406EACFC3DB7BE73E974E074F006AB29929917D85DB964355030CAE)
4. 如获取到其他团队发送的分享码，可点击"添加报告"，输入"分享码"并点击"确定"，将测试报告导入到列表后查看。 说明
   >
   > 在测试报告被设置为关闭分享后，可继续查看已导入的报告，如取消导入则无法再通过分享码继续查看。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/1X17BOMVS9m4Ikg4NqXTKQ/zh-cn_image_0000002454274274.png?HW-CC-KV=V1&HW-CC-Date=20261008T163044Z&HW-CC-Expire=31536000000&HW-CC-Sign=7597481DD7E2623490FADE866E3BB17390142C8D82CA349E7E6C2633F4FBF198)
