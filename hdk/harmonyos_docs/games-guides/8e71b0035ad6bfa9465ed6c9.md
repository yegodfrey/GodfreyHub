# 分享报告

工具支持在本地或云端分享测试报告。
> 说明
>
> 报告必须[上传](https://developer.huawei.com/consumer/cn/doc/games-guides/games-hismartperf-cloudview-0000002321404213#section1365144213172)后才能分享。

1. 在数据报告列表中，选择对应的测试报告，点击分享。
   * 本地分享 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/bWSl9DM-QPGrQKuTzKhvwg/zh-cn_image_0000002348454260.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=DEAA67EB7183CD502A354F7173E575EA5156F178E03D91353EE623DE3BDDA472)

   * 云端分享 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/Ek6cP6KATGumvnc0V5Vbqw/zh-cn_image_0000002348294484.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=AB82BB2903AC13C162F37C250BFEB267A62BC053C9A4FB348F26F5CE9674B1E4)

2. 在"分享设置"弹窗中选择"开启分享"，则非团队成员无需登录账号可通过二维码、网址链接访问该测试报告，其他团队账号可通过"分享码"访问该测试报告。 说明
   >
   > 若选择"关闭分享"，非团队成员无法访问该测试报告，可通过邀请其加入团队后查看此报告。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/aRKyk5cjQ2CeF0HSViGdvw/zh-cn_image_0000002382054977.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=7F5CBEDD1B5CFD04B7293CE7EE8EB70686F0AAF359A2950D0DD8738E3ABC9960)
3. 如获取到其他团队分享的二维码或网址，可直接扫描二维码或点击网址查看测试报告。报告为html格式，用户点击链接后在浏览器中打开，与云端界面一致，不支持前进、后退、收藏等操作 。 说明
   >
   > 在测试报告被设置关闭分享后，则无法再通过分享过的二维码、网址继续查看。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/jjUJS7bLQ_KWPICYWO9Lvg/zh-cn_image_0000002348454264.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=7CF919F3B296B964B1BA759562043226BFCABB27612B8A6BFDF6630E271D1AF9)
4. 如获取到其他团队发送的分享码，可点击"添加报告"，输入"分享码"并点击"确定"，将测试报告导入到列表后查看。 说明
   >
   > 在测试报告被设置为关闭分享后，可继续查看已导入的报告，如取消导入则无法再通过分享码继续查看。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/1X17BOMVS9m4Ikg4NqXTKQ/zh-cn_image_0000002454274274.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=F3A89990D4EF371D6B5070C17A3D4747FD189485BFD37FF721BDC65BF1D7FD61)
