# 导入Package

## 前提条件

已前往[下载地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/ailod-sdk-0000002476766086)下载AILOD Package。

## 操作步骤

1. 在团结Hub中打开您的游戏工程。
2. 进入团结Editor，在顶部菜单栏选择"Window > Package Manager"，在弹出的"Package Manager"窗口上，点击"Add package from disk"，将已下载的AILOD Package导入您的游戏工程。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/RI4he4qZTteKGoUV0QJMJQ/zh-cn_image_0000002477021756.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=19D758E9B7A8D1869497A914FE9397E0500FAAFC04CEC4B5BE4B67EEFD68AEEB)

3. Package导入成功后，您可以前往"Window > Package Manager"查看AILOD Package。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/-UNZ70b4Q8-Ceed9CxoKkw/zh-cn_image_0000002480222290.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=5E85419D4CB1FC2A532AEA4BB3628AAC84C96FFFBF330F8EE9514BE488048826)
