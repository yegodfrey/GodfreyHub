# 导入Package

## 前提条件

已前往[下载地址](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/ailod-sdk-0000002476766086)下载AILOD Package。

## 操作步骤

1. 在团结Hub中打开您的游戏工程。
2. 进入团结Editor，在顶部菜单栏选择"Window > Package Manager"，在弹出的"Package Manager"窗口上，点击"Add package from disk"，将已下载的AILOD Package导入您的游戏工程。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/RI4he4qZTteKGoUV0QJMJQ/zh-cn_image_0000002477021756.png?HW-CC-KV=V1&HW-CC-Date=20261008T155211Z&HW-CC-Expire=31536000000&HW-CC-Sign=511AF0201B247B50B356789F9FD048826D67490B5C2994223660C0A9798A248C)

Package导入成功后，您可以前往"Window > Package Manager"查看AILOD Package。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/-UNZ70b4Q8-Ceed9CxoKkw/zh-cn_image_0000002480222290.png?HW-CC-KV=V1&HW-CC-Date=20261008T155211Z&HW-CC-Expire=31536000000&HW-CC-Sign=59117CA8E428B9FD08E52B1387E325CED852B9A277723D2CA05002D510568466)
