# 构建发布工程

以Laya2.0为例打包构建HarmonyOS 5.0及以上工程：

* 打开LayaAir IDE > 点击左上角LOGO图标 > 工具 > app构建，如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/jELaW6G4QD68OkKgFhE4cg/zh-cn_image_0000002348454436.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=E2E3199ADC82185F18AB0A3333BE067BA606A300A09A67A01A50183A4F236153)

* 在构建项目配置界面选择最新的Native版本（当前2.13.8）、选择项目类型（ohos），如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/JnrZSgG8SkO1_qGlVZDSDw/zh-cn_image_0000002382174849.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=A9C2AC613EE1CE51CAB378778154EB5FE3A1A0BDB656A71913F92D7BA1C90B09)


* 配置完成后点击开始创建可在指定的输出路径输出HarmonyOS 5.0及以上工程项目，如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/04/v3/dAWVVocOQ_qorno-QDd3vQ/zh-cn_image_0000002348294660.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A8B16618BA585131B2986367C436EE7D1C4F0FC9C5F16C193DB07649D5F0306)
