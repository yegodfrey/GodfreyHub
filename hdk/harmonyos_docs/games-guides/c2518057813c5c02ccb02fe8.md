# 构建发布工程

以Laya2.0为例打包构建HarmonyOS 5.0及以上工程：

* 打开LayaAir IDE \> 点击左上角LOGO图标 \> 工具 \> app构建，如图所示： ![](https://media:401781143597724954)

* 在构建项目配置界面选择最新的Native版本（当前2.13.8）、选择项目类型（ohos），如图所示： ![](https://media:401781143597766955)

<!-- -->

* 配置完成后点击开始创建可在指定的输出路径输出HarmonyOS 5.0及以上工程项目，如图所示： ![](https://media:401781143597794956)

* 使用DevEco Studio工具打开并连接设备构建hap/app运行，如图所示： ![](https://media:401781143597824957)
