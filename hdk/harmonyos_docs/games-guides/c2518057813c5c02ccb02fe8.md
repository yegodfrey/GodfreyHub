# 构建发布工程

以Laya2.0为例打包构建HarmonyOS 5.0及以上工程：

* 打开LayaAir IDE > 点击左上角LOGO图标 > 工具 > app构建，如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/jELaW6G4QD68OkKgFhE4cg/zh-cn_image_0000002348454436.png?HW-CC-KV=V1&HW-CC-Date=20261008T165021Z&HW-CC-Expire=31536000000&HW-CC-Sign=EF514408285584003EB812B1C98E4AFB89781684DC456AB1FB35DF5210E1E422)

* 在构建项目配置界面选择最新的Native版本（当前2.13.8）、选择项目类型（ohos），如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/JnrZSgG8SkO1_qGlVZDSDw/zh-cn_image_0000002382174849.png?HW-CC-KV=V1&HW-CC-Date=20261008T165021Z&HW-CC-Expire=31536000000&HW-CC-Sign=2F23BECA05F0DA9EA13348C2E1516CB367A94CAA2428B73F9F112673A5D641AD)


* 配置完成后点击开始创建可在指定的输出路径输出HarmonyOS 5.0及以上工程项目，如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/04/v3/dAWVVocOQ_qorno-QDd3vQ/zh-cn_image_0000002348294660.png?HW-CC-KV=V1&HW-CC-Date=20261008T165021Z&HW-CC-Expire=31536000000&HW-CC-Sign=E3E902A8E6DFAD153CA34F158EB56AF72B0BC060CEEAD694B16052ABBE6BE2F7)
