# 准备游戏信息

1. 在项目列表中选择您的项目，进入"项目设置"的"常规"页签。
2. 记录项目下的"Client ID"和"Client Secret"，以及应用下的"APP ID"信息。 说明
   >
   > "Client ID"、"Client Secret"和"APP ID"信息主要用于SDK接入校验。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/fQTVALaJR3GEpqP6kNaUMA/zh-cn_image_0000002395350733.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C538FD6CFD43509178CFB24BE03F610B43751FCEBBCA74FFB095FB6CC99D309)

   |参数|说明|
   |:------------|:----------------------|
   |Client ID|客户端ID，集成项目级SDK鉴权时的唯一标识。|
   |Client Secret|客户端密钥，集成项目级SDK鉴权时的密钥。|
   |APP ID|应用ID。|
