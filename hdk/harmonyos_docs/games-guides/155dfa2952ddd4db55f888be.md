# 批量修改商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要批量修改商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营>商品管理"。
4. 下载表格，批量修改商品信息并上传。 注意
   >
   > 请按照规范批量修改商品信息，否则会在上传时报错，具体错误信息可参见[常见错误说明](https://developer.huawei.com/consumer/cn/doc/games-guides/games-center-mistakes-0000002320646013#ZH-CN_TOPIC_0000002382054161)。
   * 方法一：

   a）点击页面右上角![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/Jrse8jTdTgaYdf_4MF08KQ/zh-cn_image_0000001931836388.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=C486875269BB11D92F8A72C59B92F09F5FE071250D7B45878403C0A27B160719 "点击放大")，下载商品模板并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/e7C91MxeR5Kni1b_SZEkmA/zh-cn_image_0000001959074937.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A487C48C1482BCD5900098ABC9AF41D2DBC2F19EBC779EDFF12D592768C03BD "点击放大")选择上传已填写的商品模板。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/g_GszTDDQ2eKNa3wj2KEDQ/zh-cn_image_0000002449458877.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=1FB50B46B220BD2ADF816D0CD5EAA030A023318C13FB52A02AFF61CBD75802CC)
   * 方法二：

   a）点击"导出商品"，下载商品信息表格并保存到本地。

   b）按规范修改商品信息。

   c）点击"批量操作"下拉选项中的 "修改商品"，并在弹出的添加框中点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/GBKZaMUiSaW1eYP3FH_tBw/zh-cn_image_0000001933997360.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=98FC1748C7844EE54822DD08182E76755EFA7768AAD91DB190BB659FFE951825 "点击放大")选择上传已修改的商品信息表格。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/hFyHT3tpTTOD2WqsAhDdzA/zh-cn_image_0000002415820428.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=070277323BDA9B428963F493A616C166CEEB260DCA209BEC6D57FB5448802EA8)

5. 在确认页面可查看商品信息修改前后对比图，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/yigHRGIrQbO4DoJsnfd8cg/zh-cn_image_0000001931995772.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A5E3019DFA41222A5A4B4F8F045268780DB4893C5956D52A32290DCC32B4FED "点击放大")

   > 说明
   >
   > 已通过审核的数字商品，如果仅修改其价格和商品销售范围，则无需重新提交审核，新价格和新的商品销售范围立即生效；如果还修改了其他基本信息或审核信息，则需要再次提交审核，数字商品方可生效。
