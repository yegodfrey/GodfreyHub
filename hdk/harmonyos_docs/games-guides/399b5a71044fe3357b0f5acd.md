# HiSmartPerf FAQ

## 如何解决一直显示"正在连接采集器"

手机连接HiSmartPerf-Editor工具后，界面一直显示"正在连接采集器"，这是因为工具的安装路径可能有中文。您需要卸载工具重新安装，且保证安装路径中没有**中文** 和**空格**。

## 手机设备如何成功连接电脑

1. 打开手机的"设置"应用，进入"关于手机"页面。
2. 快速、连续、多次点击"软件版本"，直到提示"您正处于开发者模式！"或"您已处于开发者模式，无需进行此操作"，表示您已进入当前手机设备的开发者模式。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/eCI6vNxMQJuSbbWPn0AibA/zh-cn_image_0000002382055221.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=26A04F28B93011BC1E8F0ACE204E71DE9C7F0AC1F5DCD5EF4A9C0F7CD03F3C29)

3. 在"开发人员选项"页面打开"USB调试"、"仅充电模式下允许ADB调试"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/jUBcclA2SVOcmPzbE5Ez5A/zh-cn_image_0000002382174913.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=E87CC3D25CB79E41189C410C942070FACC061E7F9071293C04AC621A76DB88F2)

4. 在底部弹出的"是否允许USB调试？"窗口上点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/9rJKUAMDRE2DSM0amo_rcA/zh-cn_image_0000002382174921.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=DE298DF5061A2EDC07739A7EFE451C84354CABEB035C14158825BE35FBC3202C)

5. 使用USB数据线连接手机与电脑，并在弹出的"USB连接方式"窗口上选择"仅充电"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/GF7K-x6_TaGzD_MtzrFIfg/zh-cn_image_0000002382055217.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=0159F62F519820122877A040DEEA3CE197FD52F1BA40F87C571156E4E6D978C1)

6. 继续在"是否允许USB调试？"窗口上点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/OTmyisDITnOatSprC5pz2w/zh-cn_image_0000002382174917.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=C05692C6932F0AA0F82F3DFF4EAA05B5A785114713C1C85758FB0F8904092637)
