# HiSmartPerf FAQ

## 如何解决一直显示"正在连接采集器"

手机连接HiSmartPerf-Editor工具后，界面一直显示"正在连接采集器"，这是因为工具的安装路径可能有中文。您需要卸载工具重新安装，且保证安装路径中没有**中文** 和**空格**。

## 手机设备如何成功连接电脑

1. 打开手机的"设置"应用，进入"关于手机"页面。
2. 快速、连续、多次点击"软件版本"，直到提示"您正处于开发者模式！"或"您已处于开发者模式，无需进行此操作"，表示您已进入当前手机设备的开发者模式。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/eCI6vNxMQJuSbbWPn0AibA/zh-cn_image_0000002382055221.png?HW-CC-KV=V1&HW-CC-Date=20261008T160647Z&HW-CC-Expire=31536000000&HW-CC-Sign=D89CE55EB12AA2B611331C4CD378DDD06436523642FFF72FB55D6765D3D4B3DA)

3. 在"开发人员选项"页面打开"USB调试"、"仅充电模式下允许ADB调试"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/jUBcclA2SVOcmPzbE5Ez5A/zh-cn_image_0000002382174913.png?HW-CC-KV=V1&HW-CC-Date=20261008T160647Z&HW-CC-Expire=31536000000&HW-CC-Sign=2F11B090822DFE961EEE58C9E7C2D5756B8F44883F2A9EC6F4BC0F48E703CE7E)

4. 在底部弹出的"是否允许USB调试？"窗口上点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/9rJKUAMDRE2DSM0amo_rcA/zh-cn_image_0000002382174921.png?HW-CC-KV=V1&HW-CC-Date=20261008T160647Z&HW-CC-Expire=31536000000&HW-CC-Sign=04636D2201D25354DF6C550656B948326900E434D13C017D56772B2154947EDA)

5. 使用USB数据线连接手机与电脑，并在弹出的"USB连接方式"窗口上选择"仅充电"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/GF7K-x6_TaGzD_MtzrFIfg/zh-cn_image_0000002382055217.png?HW-CC-KV=V1&HW-CC-Date=20261008T160647Z&HW-CC-Expire=31536000000&HW-CC-Sign=4994368F16506CC2835917CC72B12285E2E12F6C00E8D9C7B84D43B4A5FBB874)

6. 继续在"是否允许USB调试？"窗口上点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/OTmyisDITnOatSprC5pz2w/zh-cn_image_0000002382174917.png?HW-CC-KV=V1&HW-CC-Date=20261008T160647Z&HW-CC-Expire=31536000000&HW-CC-Sign=216B44C4B613A0E33E1C33AFCAC2700E7C3993DD18FE2C9C1E46518D22E1428C)
