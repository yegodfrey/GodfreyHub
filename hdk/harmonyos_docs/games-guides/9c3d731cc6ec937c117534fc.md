# 删除数字商品

如果您想将冗余的商品从商品列表中去除，您可以选择删除该商品。
> 说明
>
> * 审核中或生效状态的数字商品无法删除。
> * 正在生效中的商品发生修改后，即使处于待提交状态，也将无法删除。

## 删除单个数字商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要删除的商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营 > 商品管理"。
4. 在商品列表中，您可以直接点击待删除商品对应"操作"列下的"删除"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/JcaeBrnaTeCVzJ1L8JKloQ/zh-cn_image_0000002452535413.png?HW-CC-KV=V1&HW-CC-Date=20261008T154820Z&HW-CC-Expire=31536000000&HW-CC-Sign=172D2727B5E6039A9C1EBFCBCA6388590A9CF0AFED221F9780F0EE0ED11B90A5)

5. 您还可以点击待删除商品对应"操作"列下的"编辑"，进入商品信息详情页后，点击"编辑商品"页面右上角的"删除商品"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/sMgo5EiRRLqQXynbmxbaWg/zh-cn_image_0000002452535429.png?HW-CC-KV=V1&HW-CC-Date=20261008T154820Z&HW-CC-Expire=31536000000&HW-CC-Sign=0D8CF8337198BF32624A7E8BF6C877FB10C91C9BCCE6378A68A15FE5BBFD0CDA)

## 批量删除数字商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要删除的商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营 > 商品管理"。
4. 在商品列表中，您可以勾选待删除商品，点击"批量操作 > 删除商品"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/_IjElMDZTyicsGBy8IAINw/zh-cn_image_0000002452575721.png?HW-CC-KV=V1&HW-CC-Date=20261008T154820Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C5CDA7567B14D72AA7CD8AB15FDD7C9ABDE975028358187893C57C08981085D)

> 注意
>
> 删除商品后，该商品将无法支付购买，且此商品ID将无法在该应用下继续创建商品时使用。
