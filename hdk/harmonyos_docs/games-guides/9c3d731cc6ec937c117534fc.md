# 删除数字商品

如果您想将冗余的商品从商品列表中去除，您可以选择删除该商品。
> 说明
>
> * 审核中或生效状态的数字商品无法删除。
> * 正在生效中的商品发生修改后，即使处于待提交状态，也将无法删除。

## 删除单个数字商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要删除的商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营 > 商品管理"。
4. 在商品列表中，您可以直接点击待删除商品对应"操作"列下的"删除"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/JcaeBrnaTeCVzJ1L8JKloQ/zh-cn_image_0000002452535413.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=08F04D32CF55031ECF13C6988D5954060ABE69AEEFB3D3BD3664A9D0160A0F3C)

5. 您还可以点击待删除商品对应"操作"列下的"编辑"，进入商品信息详情页后，点击"编辑商品"页面右上角的"删除商品"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/sMgo5EiRRLqQXynbmxbaWg/zh-cn_image_0000002452535429.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=CDA9E334F1E5015BA116FA7295E8356E3A83E02AF221C20FE9632D423CBD5E55)

## 批量删除数字商品

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"APP与元服务"。
2. 在应用列表中点击需要删除的商品的应用。
3. 在"运营"页签下的左侧导航栏中，选择"产品运营 > 商品管理"。
4. 在商品列表中，您可以勾选待删除商品，点击"批量操作 > 删除商品"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/_IjElMDZTyicsGBy8IAINw/zh-cn_image_0000002452575721.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=DFE871A93F33188C8A87A92054CD44FCA0E2EB302958B92F6A1B84CAF282A860)

> 注意
>
> 删除商品后，该商品将无法支付购买，且此商品ID将无法在该应用下继续创建商品时使用。
