# 首次核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/pq3XDHGIRA-Ip0HKf74hJw/zh-cn_image_0000001803578168.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E21A6AC5CAF7F71429922CFEE7C87EAF85BA5E6F7BF7733DCD6F43E208BA5A2)

2. 填写主办单位和快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/GqNufccBS2-KUKfv7FHQ7g/zh-cn_image_0000001838739578.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=49DCC59A685A9ED46F712EEE270E9E31ACE15E153165293FD28936EEA45484E1)

3. 填写主办单位和快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/2OU7kk2pRaWBYvhJu0HWAA/zh-cn_image_0000001884979137.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=ED8F03A09C0A2AD68A15F977454611F1C2F28C0DB53A22D2A02C3A90CB53D581)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/0LdkpRrzQuuEmXP07omFFQ/zh-cn_image_0000001850416933.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=5C3345264EA8E7395E1E5A9CF99BB47927CB6D4A90E511D544E11781FA835DEB)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/FlDAhcSwQ-SC7bRTvo3X9A/zh-cn_image_0000001838898818.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=7DCF697826E8A46DBD4F2F91911E6C93A45A88C8D03CA516FEA4BE1B40D8ED5B)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
