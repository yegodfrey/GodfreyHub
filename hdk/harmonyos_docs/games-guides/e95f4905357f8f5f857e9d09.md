# 首次核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/pq3XDHGIRA-Ip0HKf74hJw/zh-cn_image_0000001803578168.png?HW-CC-KV=V1&HW-CC-Date=20261008T143044Z&HW-CC-Expire=31536000000&HW-CC-Sign=F2D099934C5BE22CCB958B9D4FDFA5727DF9F1A11426AD5B6B772559F1B569E5)

2. 填写主办单位和快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/GqNufccBS2-KUKfv7FHQ7g/zh-cn_image_0000001838739578.png?HW-CC-KV=V1&HW-CC-Date=20261008T143044Z&HW-CC-Expire=31536000000&HW-CC-Sign=93CF36D105AA8B1EDFC3E63493CD532A4FDEEE73120F89970FCBFCCD0392A806)

3. 填写主办单位和快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/2OU7kk2pRaWBYvhJu0HWAA/zh-cn_image_0000001884979137.png?HW-CC-KV=V1&HW-CC-Date=20261008T143044Z&HW-CC-Expire=31536000000&HW-CC-Sign=33DA3EE34D9CD681A652418076C369C28851609E0617DA656B5BE777D5553600)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/0LdkpRrzQuuEmXP07omFFQ/zh-cn_image_0000001850416933.png?HW-CC-KV=V1&HW-CC-Date=20261008T143044Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B45C5D39D008AE7DAE20532E481DD10B6A6FDCD0DF0A9C0F6CBC426D6A6EDFE)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/FlDAhcSwQ-SC7bRTvo3X9A/zh-cn_image_0000001838898818.png?HW-CC-KV=V1&HW-CC-Date=20261008T143044Z&HW-CC-Expire=31536000000&HW-CC-Sign=636838845E71CE57A7BCBC7AE2D25D321EA6AE702AD14C871EDF7D663FC6A663)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
