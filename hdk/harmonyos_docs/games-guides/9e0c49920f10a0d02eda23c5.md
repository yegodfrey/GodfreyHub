# 版本升级

若打开工具时未升级工具版本，您可以在"版本升级"页面进行升级。

1. 打开"版本升级"页面，点击"立即升级"。 说明
   >
   > 若页面出现如下告警信息，建议您立即升级工具版本，否则可能影响您使用工具。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3f/v3/GeyqqmrESrS7vfEPf19czA/zh-cn_image_0000002382174293.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=A5945C29540D3B7A9BD6F6F262F653D7DD3963160421AD78FC7BDAA779D911DC)
2. 请耐心等待最新版本的下载。工具成功下载后，您可以根据提示安装工具。
