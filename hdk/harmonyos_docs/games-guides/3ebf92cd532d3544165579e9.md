# 新增接入

在华为云核准（备案）系统中接入已在其它接入商核准（备案）成功的快游戏。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面点击"新增互联网信息"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/Ie-RkvQsRYOgRHpqgmh4TA/zh-cn_image_0000001962842717.png?HW-CC-KV=V1&HW-CC-Date=20261008T145144Z&HW-CC-Expire=31536000000&HW-CC-Sign=81123DBDC9BECEE797823BC953777412570F225402A96A4BF8AC8D1D6597EF94)
2. 在"产品验证"页面填写快游戏信息，完成后点击"验证"。在弹出的窗口中点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/OBSwLn-xQ7WPCZ1xLweeJw/zh-cn_image_0000001962722953.png?HW-CC-KV=V1&HW-CC-Date=20261008T145144Z&HW-CC-Expire=31536000000&HW-CC-Sign=F92107F43A808237C7357F374DA944162005D0B2A708D19E5DAF94093B04F00D)

3. 在"主体信息"页面校对主办单位、负责人信息，若有误请及时修改，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/z7-wGBNxSZurunwPb98ByQ/zh-cn_image_0000001962847341.png?HW-CC-KV=V1&HW-CC-Date=20261008T145144Z&HW-CC-Expire=31536000000&HW-CC-Sign=211BD1887C60A69BD6DD49221956493EAE47103A463116D83B760BBA0BA815D6)

4. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/qWU7ENTJRvuNyAA79UTY3w/zh-cn_image_0000001935803746.png?HW-CC-KV=V1&HW-CC-Date=20261008T145144Z&HW-CC-Expire=31536000000&HW-CC-Sign=9FADB12C50F9C17018AC2CD75E109AE0C905FD104F1BA3B1EA453A68D71E0E7A)

5. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/TuwddJc8SMWRoCLv5YFjPA/zh-cn_image_0000001935803810.png?HW-CC-KV=V1&HW-CC-Date=20261008T145144Z&HW-CC-Expire=31536000000&HW-CC-Sign=9E53E96B4166B51EDA4FC8402FD2FFA3EC050BCC2924849D958DAA167EFDDD07)

6. 在"真实性核验"页面由互联网信息负责人进行人脸视频认证，完成后点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/ysT7n623RSuR74CYFZAvjg/zh-cn_image_0000001935644598.png?HW-CC-KV=V1&HW-CC-Date=20261008T145144Z&HW-CC-Expire=31536000000&HW-CC-Sign=7092339CA0235C1FC3516AE2A2AA2FBAF53E009CA8747EFBF5A6D18952DC30DF)

7. 在"预览资料"页面核对填写的信息，完成后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/LDXRWOIKRj2WPmIac28chw/zh-cn_image_0000001975487350.png?HW-CC-KV=V1&HW-CC-Date=20261008T145144Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2E0B577C037149A2D53E9C1D4483BE98C2DC08FD7A7AB8CC8A955D5D4212409)

8. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
9. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
