# 新增互联网信息

## 前提条件

已前往应用市场下载最新版本的华为云App。

1. 在华为云App的"ICP备案"界面新增快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/Qlf8HY-6QXC5cZ3haGVMnw/zh-cn_image_0000001885060045.png?HW-CC-KV=V1&HW-CC-Date=20261008T181523Z&HW-CC-Expire=31536000000&HW-CC-Sign=E5D1A308E6A99F8A23D3BA2FF69292B1370F4EC5D07B5FE85950695DF7C57169)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/FhTROOSLQn2sKVrU93u73Q/zh-cn_image_0000001884985613.png?HW-CC-KV=V1&HW-CC-Date=20261008T181523Z&HW-CC-Expire=31536000000&HW-CC-Sign=39D98D1782FA81C2FD8A56F9670E8BE5E64AAC4B71BD11276AC9F0C7EDB3C792)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/OsJBDsM2R0C36nZLIcRHSg/zh-cn_image_0000001885067009.png?HW-CC-KV=V1&HW-CC-Date=20261008T181523Z&HW-CC-Expire=31536000000&HW-CC-Sign=5C2DD3A6C259973B2E14C939E3F439FDBB9023F3B33AB4CFC38DA9D17BB2B05F)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/CT8kzZF4S0WOtCsb6bjroA/zh-cn_image_0000001850456961.png?HW-CC-KV=V1&HW-CC-Date=20261008T181523Z&HW-CC-Expire=31536000000&HW-CC-Sign=C2D87B26ABDE0F4D8110102B3CA9347E5F81ADE05FFB7061EE31FA605CB85119)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/TX8SANtEQjCO54d9L19Thw/zh-cn_image_0000001884992033.png?HW-CC-KV=V1&HW-CC-Date=20261008T181523Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C52405D1437059D56ADA4C384581B0141BA15CBD401C6F8DD82F9D6607318EF)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
