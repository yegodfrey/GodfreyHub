# 新增互联网信息

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面新增快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/Qlf8HY-6QXC5cZ3haGVMnw/zh-cn_image_0000001885060045.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=968FABA84D9450BB458A3DA6DB10240035B01A3FBB234A80008747642495ACA5)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/FhTROOSLQn2sKVrU93u73Q/zh-cn_image_0000001884985613.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=67C900B72EDB8197BBDDB7B2E2B0EE8C27B19E79AA7DE8EDAFBFE8522B07D565)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/OsJBDsM2R0C36nZLIcRHSg/zh-cn_image_0000001885067009.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=D6FB48EBE883089F4D22112C3E5890114AF924F0892819C2CD6E56591AA30AB8)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/CT8kzZF4S0WOtCsb6bjroA/zh-cn_image_0000001850456961.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=D76C682FA017A839F96BECD9CC2FE8F331AC909E6A83CA1B4997ADDBF306A074)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/TX8SANtEQjCO54d9L19Thw/zh-cn_image_0000001884992033.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=02861A61ACC824D8546F25F654316FF52B23398FBBC7EC7AC8C4DBE0062CE868)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
