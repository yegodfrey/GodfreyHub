# 确保AILOD端云连通

AILOD为端云协同工作，因此在使用期间需要保持网络畅通。

1. 在顶部菜单栏选择"AILOD > Settings"，点击"Test Connection"，测试是否可以连接Huawei AILOD cloud platform。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/pbSIsWRDQeCdTN5156VJsA/zh-cn_image_0000002510398615.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=07D5571B584EADADB5E50366AB3390AD00F2FF97F6CD29835A961AFB6CC8F927)

2. 若连接失败请前往[FAQ](https://developer.huawei.com/consumer/cn/doc/games-guides/ailod-faq-0000002509054397#section1871719355282)查看解决方案。
