# 首次核准（备案）

在华为云核准（备案）系统中首次核准（备案）主体信息和快游戏信息。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，填写主办单位信息、互联网信息，完成后点击"验证备案类型"。在弹出的窗口中点击"下一步"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/i2gC6mU4QA-MX3-udf_Mrg/zh-cn_image_0000001935643102.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=15E9EDF7717D8FD4C9BEBB44C1EE4278871C96DC353C7428CB8AC13E03607E4A)
2. 在"主体信息"页面填写主办单位信息、负责人信息，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/Hw5brzN1RziqgfzFt55w0A/zh-cn_image_0000001962721953.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B027DAEE46B39E79B8C79F4F8F22E91BA505344484EF22F73CAC4FBC33245ED)

3. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/jMNehGSDR4ymoL24m_1gSg/zh-cn_image_0000001962721973.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=64069BBCC090FCCBE21B30C24A5460540E70DE5717581DB42797C32ED939965E)

4. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/MUmb15gQQV-XAly1vgZW7g/zh-cn_image_0000001935802862.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=1BE777F30445DC484574309B59FAE2FC4B65831535D4784191FF4A8B9650F092)

5. 在"真实性核验"页面由互联网信息负责人进行人脸视频核验，完成后点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/fSR9O59kTymVl-nf92tMVw/zh-cn_image_0000001935643570.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=69A1DDE52E3F8CE95E249FF6EF0E1E99502DBCDFD2727A9413CD941FEB12B1F3)

6. 在"预览资料"页面核对填写的信息，完成后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0d/v3/-af0v_7yQWeqFFRFhJTcdQ/zh-cn_image_0000002012039173.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=AFC74B21DF1B3F13B8E1FC8C1EDE78BAE696322F34550800D7BBA8905D2E7707)

7. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/SNmwE97aTP-q5Ytz6-X_yw/zh-cn_image_0000001840856621.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=7C2DBAB2F5CFCCD7DCB67E59F6907446C0DFD414CD5B5D32FA277BA1717566E9)

8. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。若初审被驳回，请点击"继续备案"修改信息后重新提交审核。
