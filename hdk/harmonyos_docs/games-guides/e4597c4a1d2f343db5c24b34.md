# 生成签名证书

1. [打开项目](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-tool-open-0000002317894968)进入工具主界面后，在顶部菜单栏选择"工具 > 生成证书"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/yPwulUo1RT2k2Iu1PCwa_Q/zh-cn_image_0000002399696745.png?HW-CC-KV=V1&HW-CC-Date=20261008T145520Z&HW-CC-Expire=31536000000&HW-CC-Sign=BB7A89F30F3EA24ED9378F610C93F93025CAE05417F85BBB4C13C6CCDDB2785C)

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/7hVQhgMAQHacSOKPW8Nkgg/zh-cn_image_0000002399816617.png?HW-CC-KV=V1&HW-CC-Date=20261008T145520Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E8313072CCA4C07253C773CCC95E1058EA731F7A56B026063167268B7EAFD0B)
