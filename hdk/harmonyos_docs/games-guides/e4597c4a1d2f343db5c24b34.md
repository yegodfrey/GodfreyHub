# 生成签名证书

1. [打开项目](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-tool-open-0000002317894968)进入工具主界面后，在顶部菜单栏选择"工具 > 生成证书"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/yPwulUo1RT2k2Iu1PCwa_Q/zh-cn_image_0000002399696745.png?HW-CC-KV=V1&HW-CC-Date=20260920T025431Z&HW-CC-Expire=31536000000&HW-CC-Sign=521BFF83FF4A65B21F032D58D035AD101B1E997ADFAACCB26BD5CD49E640775E)

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/7hVQhgMAQHacSOKPW8Nkgg/zh-cn_image_0000002399816617.png?HW-CC-KV=V1&HW-CC-Date=20260920T025431Z&HW-CC-Expire=31536000000&HW-CC-Sign=CF40ABE4D3F6FE4E437C81246F890D49BF6A0471E0ED06A6063E76F7403ED4B3)
