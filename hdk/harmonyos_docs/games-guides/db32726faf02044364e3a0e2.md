# 注销核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 注销主体

1. 在华为云App的"ICP备案"界面注销主体。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/YPq_v8GFTLiv-jgV8zF-dw/zh-cn_image_0000001885071157.png?HW-CC-KV=V1&HW-CC-Date=20261008T174404Z&HW-CC-Expire=31536000000&HW-CC-Sign=E24DCC1BD64E5F1E4C802973BF230A7C364E68D0DF45535190E1323E5ABECC03)

2. 验证负责人的手机/邮箱，并选择注销原因后点击"提交初审"，在弹出的"确定要注销主体"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/h9DttRdxTN2KxdepRcosbw/zh-cn_image_0000001838751606.png?HW-CC-KV=V1&HW-CC-Date=20261008T174404Z&HW-CC-Expire=31536000000&HW-CC-Sign=B3CF1268F5DAA25BDD92FA858E3B2A2BA3343935BC6422F65A99B38FC36CDDA0)

3. 提交申请后，华为平台将自动审核您的申请。您需前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。

## 注销互联网信息

1. 在华为云App的"ICP备案"界面注销快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/WubSRbfKReCAHsvxsS_icw/zh-cn_image_0000001884991081.png?HW-CC-KV=V1&HW-CC-Date=20261008T174404Z&HW-CC-Expire=31536000000&HW-CC-Sign=DA760C1BCCD9BAA548BE6C1714BB439DE77C318C08B9BABFACBDE15C549F4D3D)

2. 验证负责人的手机/邮箱，选择注销原因后点击"提交初审"，在弹出的"确定要注销互联网信息"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/FI2KsONgSqKuFR2pvYuOlw/zh-cn_image_0000001838910814.png?HW-CC-KV=V1&HW-CC-Date=20261008T174404Z&HW-CC-Expire=31536000000&HW-CC-Sign=56D8070709B65336077672FD5E1596CC970B665F9146159E941C2C240BBE1F50)

3. 提交申请后，华为平台将自动审核您的申请。您需前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
