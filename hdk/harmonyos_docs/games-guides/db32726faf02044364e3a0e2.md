# 注销核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 注销主体

1. 在华为云App的"ICP备案"界面注销主体。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/YPq_v8GFTLiv-jgV8zF-dw/zh-cn_image_0000001885071157.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE65AFFE8A0609B5732F6270698680A4186DC03334C3B172B97A788EC40AA25E)

2. 验证负责人的手机/邮箱，并选择注销原因后点击"提交初审"，在弹出的"确定要注销主体"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/h9DttRdxTN2KxdepRcosbw/zh-cn_image_0000001838751606.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D7625648A5A6B1CAFA6DDD1D4B4EA5A3D1330BC1E6CA2B4881932FD1B968B1A)

3. 提交申请后，华为平台将自动审核您的申请。您需前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。

## 注销互联网信息

1. 在华为云App的"ICP备案"界面注销快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/WubSRbfKReCAHsvxsS_icw/zh-cn_image_0000001884991081.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=6790DBBBA4326B45B95120AA5CA026592653C038A44FCC2DB7DA6CADEC9C339B)

2. 验证负责人的手机/邮箱，选择注销原因后点击"提交初审"，在弹出的"确定要注销互联网信息"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/FI2KsONgSqKuFR2pvYuOlw/zh-cn_image_0000001838910814.png?HW-CC-KV=V1&HW-CC-Date=20260920T025432Z&HW-CC-Expire=31536000000&HW-CC-Sign=85DC85386F4E1131812BD488FC2C1FE5C87349D394E97946680A2EFF1AF8D85B)

3. 提交申请后，华为平台将自动审核您的申请。您需前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/games-guides/quickgame-filing-sms-verify-0000001818117885)。
