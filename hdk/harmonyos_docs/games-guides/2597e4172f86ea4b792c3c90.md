# 生成睫毛图

快游戏开发者工具支持睫毛图工具，帮助您生成统一的小游戏图标样式。

1. 在快游戏开发者工具中打开需要生成小游戏图标的项目，点击"工具 > 睫毛图工具"，进入生成睫毛图页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0e/v3/FEt0SAAIS22O_-OB35HxCQ/zh-cn_image_0000002624524071.png?HW-CC-KV=V1&HW-CC-Date=20261008T165605Z&HW-CC-Expire=31536000000&HW-CC-Sign=8071D9FFBA534444E73C4A3674B4B861047FBFFA62B36CAC51FFDB61DF232652)

2. 点击"选择图片"，选择用于制作睫毛图的本地图片。图片尺寸及要求如下：

   |参数|要求|
   |:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |图片格式|格式为PNG、JPEG或JPG的静态图片资源。|
   |图片尺寸|大小为1024px*1024px的正方形图片。|
   |图片背景|不透明。|
   |质量要求|图标内容需清晰可辨，避免存在模糊、锯齿、拉伸等问题。详情请参见[元服务图标设计规范](https://developer.huawei.com/consumer/cn/doc/design-guides/ux-guidelines-overview-0000001900384976#section158386422413)。|

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/CSjm32xIQGKtPmE7qJdo7w/zh-cn_image_0000002594244456.png?HW-CC-KV=V1&HW-CC-Date=20261008T165605Z&HW-CC-Expire=31536000000&HW-CC-Sign=990746E2CFB371F390D914F1BA54BDDD81B9CB1383F6397AF292E653E036CFF7)
3. 图片导入后可以选择图片外圈颜色。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/C_Jo4rP5SvSjMQVfRrJUVQ/zh-cn_image_0000002624643913.png?HW-CC-KV=V1&HW-CC-Date=20261008T165605Z&HW-CC-Expire=31536000000&HW-CC-Sign=F5BF551048E7775B7297FBD38702FA86D7FA255E4A26DE58A7C44412E58A4521)

4. 下载生成的睫毛图，并保存至您选择的位置。
   * 点击"下载元服务图标(512 * 512 px)"，此时保存的图标尺寸为512px*512px。可在小游戏module.json5文件的icon字段中配置该图标作为小游戏图标。
   * 点击"下载元服务AppGallery Connect上架图片（216 * 216 px）"，此时保存的图标尺寸为216px*216px。后续在AppGallery Connect上架小游戏时，需使用该图标作为应用图标上传。
