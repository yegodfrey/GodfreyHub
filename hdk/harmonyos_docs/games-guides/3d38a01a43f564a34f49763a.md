# C#（小游戏）

## 前提条件

* 您已[下载游戏多媒体SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Library/gamemme-sdkdownload-csharp-minigame-0000001825274857)。
* 您已下载微信开发者工具。
* 您已下载快游戏开发者工具。

## 导出为微信小游戏

1. 使用团结引擎完成游戏多媒体功能开发后，[导出WebGL并转换为小游戏项目](https://github.com/wechat-miniprogram/minigame-unity-webgl-transform/blob/main/Design/Transform.md)。 注意
   >
   > 首次使用团结引擎导出WebGL并转换为小游戏项目前，需安装小游戏团结引擎适配插件。
2. 使用微信开发者工具导入该项目。 说明
   >
   > 游戏集成游戏多媒体SDK后，如需发布到微信小游戏平台，还必须进行服务器域名配置，跟指定的域名进行网络通信，具体域名请参见[FAQ](https://developer.huawei.com/consumer/cn/doc/games-guides/games-gamemme-faq-0000002304632344#section1890854563118)。
3. 将游戏多媒体SDK中的GMMEForMiniGames.js文件（获取路径：Plugins > js > GMMEForMiniGames.js）放在微信小游戏项目的根目录下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/0f36ftggTbWcmdli2mMvoA/zh-cn_image_0000002372037726.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=E2FD3F09A74DF944F914832B7E1B92B5D9A74A7E357D68C094DD50D5C54F47B8)

4. 在项目的game.js文件头部新增如下代码。

   ```screen
   import * as GMMEForMiniGames from 'GMMEForMiniGames.js'
   window.GMMEForMiniGames = GMMEForMiniGames;
   ```

## 导出为华为快游戏

1. 使用Unity完成游戏多媒体功能开发后，[导出为WebGL项目](https://github.com/Petal-Gaming-Services/UnityToQuickGame/blob/main/doc/第二步-发布WebGL项目.md)。
2. 使用[快游戏开发者工具](https://developer.huawei.com/consumer/cn/doc/games-guides/games-quickgame-developer-tool-0000002351933781)导入此项目。
3. 在工具主界面的顶部菜单栏选择"构建 > Unity游戏转换快游戏"，填写信息完成转换。
4. 将游戏多媒体JS SDK中的GMMEForMiniGames.js放在快游戏项目的根目录下。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/7xBHNOvaSC-GT5CFSajTKw/zh-cn_image_0000002405717365.png?HW-CC-KV=V1&HW-CC-Date=20260920T025433Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D7A7CD7FAE737EA9AA429FC8D8F43FD06BD4B46BBB6E10591D77F714D7E05D0)

5. 在项目的game.js文件头部新增如下代码。

   ```screen
   require("GMMEForMiniGames.js");
   window.GMMEForMiniGames = GMMEForMiniGames;
   ```
