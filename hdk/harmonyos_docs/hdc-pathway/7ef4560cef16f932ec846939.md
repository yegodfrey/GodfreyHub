# 问题反馈与咨询

HarmonyOS 开发者中心提供问题反馈渠道，帮助您更高效地解决在账号管理、财务结算、应用上架、投放、开放能力接入等工作过程中遇到的问题。

当您遇到问题时，可以按照以下顺序寻求帮助。

     1. 请先仔细阅读文档中的说明和注意事项，检查是否满足限制条件。
     2. 查看业务对应FAQ。
     3. 通过AI助手查找问题解决方案。
     4. 登录[Stack Overflow社区](https://stackoverflow.com/questions/tagged/appgallery-connect)和[华为开发者社区](https://developer.huawei.com/consumer/cn/forum/)参与问题讨论。
     5. 如果以上方法仍未解决您的问题，可以通过快速评价、快速提单或我的消息与我们进行联系。

#### AI助手

AI助手是24小时在线服务平台，提供自助式智慧应答，海量知识库即问即答。

登录[HarmonyOS 开发者中心](https://developer.huawei.com/consumer/cn/hdc-console)，点击首页右下角悬浮窗的第一个图标，即可触发AI助手。

#### 快速提单

您可以在统一工单平台上快速提交工单，针对开发过程中遇到的具体问题进行咨询。

     1. 登录[HarmonyOS 开发者中心](https://developer.huawei.com/consumer/cn/hdc-console)，点击首页右下角悬浮窗的第二个图标，即可跳转至“统一工单平台”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/Ar47kVDhQfeWI_chlxTXLQ/zh-cn_image_0000002668533632.png?HW-CC-KV=V1&HW-CC-Date=20261005T092420Z&HW-CC-Expire=86400&HW-CC-Sign=F02EBD1EDAAAA2B3B42AD3AFB5184DEB4E6ED869575E006823797A91C130C34F)

     2. 在“新建工单”页面，按照页面引导描述问题，提交后，我们将在1-2个工作日内给予回复。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/Id8ihLuDRbWt_mwQ7kII6Q/zh-cn_image_0000002705265497.png?HW-CC-KV=V1&HW-CC-Date=20261005T092420Z&HW-CC-Expire=86400&HW-CC-Sign=134E4D0A8D985553445D00F3890E284D1F9C626AC094B334A0819D4D80128E92)

后续，您可以在“工单 > [我的工单](https://developer.huawei.com/consumer/cn/support/feedback/#/ticketlist)”跟踪问题进展。

#### 我的消息

“我的消息”是HarmonyOS 开发者中心为用户提供的官方消息接收平台，用于接收账号、产品、服务及应用等通知消息，同时也是您与华为客服进行问题咨询和在线答疑的渠道。该平台旨在提升您参与活动、提交申诉或反馈问题的效率，帮助您更高效地解决问题并优化产品价值。

     1. 登录[HarmonyOS 开发者中心](https://developer.huawei.com/consumer/cn/hdc-console)，点击首页右上角的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/YMCT9ol_RD65K-iYcRJEiA/zh-cn_image_0000002675421916.png?HW-CC-KV=V1&HW-CC-Date=20261005T092420Z&HW-CC-Expire=86400&HW-CC-Sign=C59D603B9FE24CC3A419F1D98D169075DE54E9E34E5B0DBB77FFCAA771BD894B)，进入“我的消息”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/NKt0uClrTZ-key_Fr5sp4g/zh-cn_image_0000002675580716.png?HW-CC-KV=V1&HW-CC-Date=20261005T092420Z&HW-CC-Expire=86400&HW-CC-Sign=56FAA17C44B6B9A1E74323B9D24C4CAE6829263C90C3170FC42904D32FF5673B)

     2. 点击左上方的“我的消息”和“应用消息”按钮可以查看不同模块的消息；点击右上方的“消息设置”可以选择消息订阅渠道。
        * “我的消息”页面默认展示全部“产品消息”、“账号消息”、“财务消息”、“活动消息”、“服务消息”或者“其他”消息。
        * “应用消息”页面默认展示全部类型的应用相关消息，您可以查看并处理“应用审核”、“服务申请”等消息，也可以点击右上方的“申诉反馈”提交申诉请求或反馈问题。

具体操作请参见[互动中心使用指南](https://developer.huawei.com/consumer/cn/doc/app/agc-help-interaction-center-0000002276985946)。
