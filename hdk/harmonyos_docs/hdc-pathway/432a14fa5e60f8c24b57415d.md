# 应用开发者工作流程

若您是一名应用（HarmonyOS应用/元服务/游戏）开发者，请按如下流程操作：

     1. 完成[应用开发准备](https://developer.huawei.com/consumer/cn/doc/hdc-pathway/hdc-appdeveloper-prep-0000002678281369)。
     2. 参考对应应用类型的典型工作流程，完成应用开发与上架等工作。
        * [HarmonyOS应用工作流程](https://developer.huawei.com/consumer/cn/doc/hdc-pathway/hdc-appdeveloper-app-0000002648201620)
        * [元服务工作流程](https://developer.huawei.com/consumer/cn/doc/hdc-pathway/hdc-appdeveloper-atomic-0000002678441223)
        * [HarmonyOS游戏工作流程](https://developer.huawei.com/consumer/cn/doc/hdc-pathway/hdc-appdeveloper-game-0000002648361522)
