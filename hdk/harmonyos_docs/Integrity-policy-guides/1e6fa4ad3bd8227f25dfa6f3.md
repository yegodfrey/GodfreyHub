# 1. 前言

为了保障合作伙伴与华为软件技术有限公司及其子公司、关联公司（以下统称为“**华为公司** ”）在业务往来中的合法权益，充分体现公平、公正、廉洁、诚信合作的精神，反对商业欺诈，在信任、诚实、坦率与正直的基础上构筑相互之间的合作关系，合作伙伴诚信廉洁政策如下：

# 2. 总体原则

**（1）不以任何方式行贿华为公司人员，包括但不限于：**

（ⅰ）以任何形式向华为公司人员馈赠现金、有价证券及支付凭证、通讯器材、交通工具、非低值文化用品以及其他贵重物品等，除非该等馈赠符合商业行为惯例。

（ⅱ）未经华为公司事先书面同意，组织华为公司人员参加旅游、高消费娱乐、以旅游为目的在风景区召开的会议等活动。

（ⅲ）利用服务商或代理商或中间人行贿华为公司人员。

（ⅳ）直接或间接向华为公司员工提供全职或兼职岗位，包括顾问、董事和股东等。

（ⅴ）与华为公司员工及其直系亲属发生任何借款/贷款往来，若华为公司员工及其亲属在日常业务过程中向合作伙伴提出借款请求，合作伙伴应向华为公司主管部门实名报告。

（ⅵ）通过华为公司员工实施向相关方输送不正当利益，拉拢华为公司员工参与合作伙伴的利益分配；若华为公司员工及其亲属主动要求参与利益输送和利益分配，合作伙伴必须拒绝，并向华为公司主管部门实名投诉。

（ⅶ）相关法律法规明确规定为行贿的行为。

**（2）支持华为公司的廉洁诚信建设** 。若华为公司人员在日常业务过程中有索贿行为，合作伙伴必须拒绝，并向华为公司主管部门实名投诉。若合作伙伴对华为公司人员的索贿行为不拒绝、不申报，并满足其要求的，则该行为应视同合作伙伴的行贿行为。

**投诉渠道：**

Email：**BCGcomplain@huawei.com**

**（3）主动申报与华为公司人员关联关系：**

合作伙伴不得让华为公司在职员工担任其顾问、董事和股东等。同时，合作伙伴应严格按照华为公司要求的方式主动申报与华为公司人员是否有关联关系。

**（4）在与华为公司的业务往来过程中，坚持诚信原则** ，至少做到以下几个方面：

（ⅰ）向华为公司提供的文件、资料、数据、陈述和口头陈述等应保证真实、准确。

（ⅱ）不接受华为公司员工个人业务承诺，对于非华为公司正式书面承诺内容，均视为无效承诺；

（ⅲ）严格遵守向华为公司做出的承诺、双方签署的合同、协议和备忘录等，不隐瞒任何可能对华为公司利益造成影响的信息。

**3.  鉴于合作伙伴违反本政策会给华为公司造成经济损失、商誉损害并可能给华为公司带来各种不利法律后果，若合作伙伴或合作伙伴相关业务人员违反《合作伙伴诚信廉洁政策》中的任何一项或多项条款，华为公司不承担相关法律责任，并有权终止与合作伙伴的业务合作并保留进一步追究其法律责任的权利。**
