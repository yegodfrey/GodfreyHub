# 性能优化概述

在应用运行期间，可能出现响应速度慢、应用崩溃或耗电量过高、发烫、交互延迟等现象。这些现象表明应用可能存在性能问题，其原因可能是业务逻辑、应用代码对系统API的误用等，造成对系统资源不合理使用，比如对CPU、GPU及其他外设等器件的冗余占用，进而引发性能问题。

通常，进行性能优化的关键点是“降负载”，包括：

  * 永久降负载：将原本不合理的冗余处理进行彻底清理。

  * 临时降负载：避免在关键时间段内扎堆产生负载。可以考虑采用懒加载等延迟处理机制，错峰运行。




在遇到这些问题时，首先需要对应用的运行情况和设备的资源消耗情况进行监测，以初步确定可能存在的性能问题及问题出现的位置，进而有针对性地降低负载。

DevEco Profiler提供实时监控（Realtime Monitor）能力，提供全方位的设备资源监测。其覆盖了系统事件、异常报告、CPU占用、内存占用、实时帧率、GPU使用率以及能耗等多个维度的数据，自顶向下逐层展开分析，结合代码进行白盒分析，明确不合理的负载出现位置，从而帮助识别性能瓶颈，定界问题所在，提高解决问题的效率。
