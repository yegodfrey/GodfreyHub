# 代码编辑

在编写仓颉应用阶段，可以通过掌握代码编写的各种常用技巧，来提升编码效率。 本章内容着重介绍仓颉提供的代码编辑功能，ArkTS 与 C++ 等代码编辑能力可参见对应的[代码编辑](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-code-edit)章节。

#### 适用范围

代码编辑章节介绍的各个特性适用范围如下：

  1. 仓颉模块cjpm.toml文件中src-dir字段配置路径下的所有.cj文件，如下图entry模块的src/main/cangjie目录中.cj文件。
