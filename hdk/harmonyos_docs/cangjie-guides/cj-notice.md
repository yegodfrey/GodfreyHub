# 仓颉编程语言

仓颉编程语言是HarmonyOS应用开发的现代高级语言。是一款静态类型、静态编译、高性能多线程编程语言，通过现代化的语言特性设计、全方位的编译优化和运行时实现、以及DevEco Studio工具链支持，为鸿蒙应用开发者打造友好的开发体验和优秀的性能表现。

HarmonyOS仓颉语言开发者体验版现正式面向开发者开放招募，请您[单击此处](https://developer.huawei.com/consumer/cn/activityDetail/cangjie-beta/)查看活动详情。如您已报名并通过审核，请直接[下载DevEco Studio](https://developer.huawei.com/consumer/cn/download/)并[参阅相关文档使用](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-start-application-development-overview)。
