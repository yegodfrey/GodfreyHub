# 命令行构建工具（hvigorw）

hvigor通过hvigorw工具，实现命令行交互。该工具支持仓颉语言编写的HarmonyOS应用。工具的使用方法请参见[hvigorw](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hvigor-commandline)。
