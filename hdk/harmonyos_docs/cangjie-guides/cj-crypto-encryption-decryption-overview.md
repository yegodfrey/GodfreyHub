# 加解密介绍

在数据存储或传输场景中，可以使用加解密操作用于保证数据的机密性，防止敏感数据泄露。

加解密操作的典型场景包括：

  1. 使用对称密钥的加解密操作。

  2. 使用非对称密钥的加解密操作。
