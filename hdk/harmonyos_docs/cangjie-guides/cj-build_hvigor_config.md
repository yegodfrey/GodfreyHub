# hvigor-config.json5文件

hvigor提供hvigor-config.json5文件，以指定hvigor的版本、构建依赖以及构建行为的配置参数，具体配置可以查看[hvigor-config.json5](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-hvigor-set-options)。
