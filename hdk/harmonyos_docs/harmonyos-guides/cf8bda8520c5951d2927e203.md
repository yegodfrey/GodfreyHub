# User Authentication Kit术语

## M

### 模系统弹窗

系统级弹窗，由应用拉起后固定居中显示于桌面，位置与源应用无关。在用户完成交互之前，整个系统将被"模住"，即无法进行其他操作。适用于需要阻断全局操作的高优先级认证场景。

### 模应用弹窗

仅在应用范围内生效的弹窗，由应用拉起后在应用界面居中显示。拉起后，在用户完成交互之前，拉起弹窗的应用界面将被"模住"，无法进行应用内操作；其余界面不受影响，可正常操作。
