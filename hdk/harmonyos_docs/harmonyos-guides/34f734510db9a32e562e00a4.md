# 配置调试签名

针对开发调试场景，DevEco Studio提供[自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto)和[手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual)两种调试签名方式，帮助开发者高效进行应用调试。

自动签名适用于大部分调试场景，但部分调试场景须使用手动签名，具体为跨设备调试、跨应用交互调试、断网情况下调试、多用户共同开发且需要共享密钥、kit需要配置指纹。  
* [自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto)  
* [手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual)
