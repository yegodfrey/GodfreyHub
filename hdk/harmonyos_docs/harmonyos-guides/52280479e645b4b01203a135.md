# 部署云侧工程

您也可选择在云函数和云数据库全部开发完成后，将整个云工程资源统一部署到AGC云端。

1. 右击云开发工程（"CloudProgram"），选择"Deploy Cloud Program"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/EiHLSSWySHeL7WvBl2gSWQ/zh-cn_image_0000002214858797.png?HW-CC-KV=V1&HW-CC-Date=20260928T063032Z&HW-CC-Expire=31536000000&HW-CC-Sign=B455E0103ED54DA193913F25E7E7186825CC31BBDB632DCB5F349F4F3E2E168D)
2. 您可在底部状态栏右侧查看云工程打包与部署进度。 请您耐心等待，直至出现"Deploy successfully"消息，表示云工程已成功部署。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/Ik99zaNMQiGg_oSPGiKt5A/zh-cn_image_0000002179338472.png?HW-CC-KV=V1&HW-CC-Date=20260928T063032Z&HW-CC-Expire=31536000000&HW-CC-Sign=B573A6979D67561D5D1A9AC32809D3E8376B82B07B3FA8EA4558ADEEC53F0179)
3. 在菜单栏选择"Tools > CloudDev"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/4NlPq-gUQBCNuFdPqdWItg/zh-cn_image_0000002214858789.png?HW-CC-KV=V1&HW-CC-Date=20260928T063032Z&HW-CC-Expire=31536000000&HW-CC-Sign=97C3F1B4D4167DB52C0CDBCBF40E004F7368B938A6FF1CBDD309A9F6FBA9FB4B)

4. 在打开的CloudDev面板中，点击"Go to console"，打开当前项目的AGC云开发子控制台。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/6ec4xLBUQ0eJeaehicYiNQ/zh-cn_image_0000002179498156.png?HW-CC-KV=V1&HW-CC-Date=20260928T063032Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C800A3E87A32DC68A60652F1450CF9B2A49E5E11D4A154D58CA9D48C145F1A9)

5. 分别进入云函数与云数据库服务菜单，可查看到您刚刚部署的云函数与云数据库资源。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/6YHSynSwQriaHO1ZlST7qw/zh-cn_image_0000002467759440.png?HW-CC-KV=V1&HW-CC-Date=20260928T063032Z&HW-CC-Expire=31536000000&HW-CC-Sign=3256D2D3C50D76FF7E05BF1651C9934540279E337420134DB25D5E73D0F20AA7)
