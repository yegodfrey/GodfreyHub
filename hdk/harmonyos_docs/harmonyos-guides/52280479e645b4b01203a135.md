# 部署云侧工程

您也可选择在云函数和云数据库全部开发完成后，将整个云工程资源统一部署到AGC云端。

1. 右击云开发工程（"CloudProgram"），选择"Deploy Cloud Program"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/Zr0qJ61qRMK9hQD1ITh6_A/zh-cn_image_0000002214858797.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=EF188873CB5C9E0459D34B99ED93CC8734FD9983C2CC7D36EE00F0DD2EB727B4)
2. 您可在底部状态栏右侧查看云工程打包与部署进度。 请您耐心等待，直至出现"Deploy successfully"消息，表示云工程已成功部署。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/Kj5uHr3yQLG0hixPfyAVOQ/zh-cn_image_0000002179338472.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=254F81839D78E4B93D9CD63B607F253B8AC5F0571E0E57AA64193BA4C7D491C6)
3. 在菜单栏选择"Tools > CloudDev"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/VzqaVjvWTqqhIYRTjAloeA/zh-cn_image_0000002214858789.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=4B1403D94ABF3ED49AAC07C7B47C5EBF27D4E610EC3DB65036695CA399A7DD8F)

4. 在打开的CloudDev面板中，点击"Go to console"，打开当前项目的AGC云开发子控制台。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/I9UiZ9nGRGiVQFGQBQG8pg/zh-cn_image_0000002179498156.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=C16FD20D9095ADECE095A8309D37D7526BEAE5623A9BE4547CF224BDF1E1A654)

5. 分别进入云函数与云数据库服务菜单，可查看到您刚刚部署的云函数与云数据库资源。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/prvqTuiSSvyp5ItVwlFs-Q/zh-cn_image_0000002467759440.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=63964AC7E70CCB9F73CC51B1677FBC4B756D52C6781367066D14BED6F390DB43)
