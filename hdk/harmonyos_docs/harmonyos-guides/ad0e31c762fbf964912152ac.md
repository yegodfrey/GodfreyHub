# 代码分析

CodeGenie支持在**对话框中**输入对代码段和代码文件分析要求，帮助开发者快速理解代码逻辑、代码功能、技术细节和潜在问题等，提升开发效率。

DevEco Studio 6.0.2 Beta1之前版本，分析代码文件时需要通过**Files** 入口选中文件；分析代码片段时，选中代码段后需点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/wu6r_JYnQN-UealJHqFtlQ/zh-cn_image_0000002701822562.png?HW-CC-KV=V1&HW-CC-Date=20261010T073009Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1614A4400A4AA7065EB7538BC3F67178F447A1E5AC21636DE6B81F95E580D3B)图标开启光标上下文功能。

在DevEco Studio 6.0.2 Beta1版本，分析代码文件时，支持在对话框输入要分析的代码文件或直接分析当前文件；分析代码片段时，选中代码段后直接分析，无需开启![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/Pu1U0THpR2mnpfiVZUNr7A/zh-cn_image_0000002731381857.png?HW-CC-KV=V1&HW-CC-Date=20261010T073009Z&HW-CC-Expire=31536000000&HW-CC-Sign=5AC670745DE83FAD2DF2589237152282E087A7C4D8F9EC399425F2C218D394EE)图标。

从DevEco Studio 6.0.2 Release版本开始，使用HarmonyOS Ask智能体分析代码文件。

1. 选择HarmonyOS Ask智能体，在对话框中输入"**/** "，点击**Project**。
2. 在对话框输入**@** 符号选择**Files** ，或点击**@** **Add Context** > **Files**，或在对话框输入文件路径，指定需要分析的代码文件。未指定代码文件时，分析当前代码文件。
3. 在对话框输入描述，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/-53i-jjfT5isgSqNGpR06Q/zh-cn_image_0000002701662638.png?HW-CC-KV=V1&HW-CC-Date=20261010T073009Z&HW-CC-Expire=31536000000&HW-CC-Sign=4D55D8E2B0553CACFD0751B202BE4175B4FF95CF8B276CCD7BEC787BF4C744FF)发送后等待回复。
