# 堆栈可视化

在native调试窗口中，点击**Layout Settings** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/_AtZfTUkRtuGHnqImV9MXQ/zh-cn_image_0000002731542421.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=7BC69AFA7DD34FFB62EC74085F9C0D08B1C32545551A3C85ADA0E239BDC9ED66)，勾选**Parallel Stacks**，打开并行栈视图。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/ISpHbqvPSFaeb4N5e_sfWw/zh-cn_image_0000002701663228.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=AA476C6C1889599BB32DCD61386AFF8E682CE745998533C302FBBB70FAA81A3E)

在程序停下时，并行栈视图可以同时展示多个线程的调用栈信息，合并重复调用栈，帮助您更好地理解程序的并发执行情况，以及发现潜在的多线程问题。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/EzluLDT1QJuLskLfKKG7nA/zh-cn_image_0000002731382447.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=49F83AC29A606EB89CAED813AA256AC96D9CECA19AB8335176EF5C0E2439D0DC)

## 调用栈跳转

您可以在视图上对某一个调用栈双击来跳转到对应堆栈，Frames页签中会随之跳转，此时可以查看该堆栈的变量等信息。

## 线程信息查看

在多个线程合并的位置处悬停鼠标，可以显示这些线程的具体信息。
