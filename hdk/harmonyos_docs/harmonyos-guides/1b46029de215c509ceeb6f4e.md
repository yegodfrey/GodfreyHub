# 堆栈可视化

在native调试窗口中，点击**Layout Settings** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/vSWDN3rhSPObffP0MXWg_Q/zh-cn_image_0000002731542421.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=DE5010485B027183C589D349DA0E3C16D8FFFCE6A077E2C1A6ADB04ED4363792)，勾选**Parallel Stacks**，打开并行栈视图。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1a/v3/ht9DY3CbQre1jYQ1xnKNLA/zh-cn_image_0000002701663228.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=24C796AEF7C5CA7FDD0CDFA9BB71BC2266439C67EDB29974795A8FDF78A3E852)

在程序停下时，并行栈视图可以同时展示多个线程的调用栈信息，合并重复调用栈，帮助您更好地理解程序的并发执行情况，以及发现潜在的多线程问题。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/gOAUEAJATEqKXfArU-IkHQ/zh-cn_image_0000002731382447.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=934EDB3BD38C83C07715A8847B84233A785CBD4B553A902C37ED1D1DDEB0B8D5)

## 调用栈跳转

您可以在视图上对某一个调用栈双击来跳转到对应堆栈，Frames页签中会随之跳转，此时可以查看该堆栈的变量等信息。

## 线程信息查看

在多个线程合并的位置处悬停鼠标，可以显示这些线程的具体信息。
