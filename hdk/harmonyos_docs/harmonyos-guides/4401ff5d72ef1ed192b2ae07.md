# 更新出行凭证

当出行凭证信息发生变更时，如登机口变更、延误信息等，更新钱包中的凭证数据。

## 交互流程

## 服务端开发

1. 用户进入钱包卡详情页面后，钱包服务器向开发者服务器主动触发[检测更新](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/wallet-rest-api-public#检测更新)。
2. 开发者服务器检测到变化，通知钱包服务器进行[出行凭证数据更新](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/wallet-rest-api-travel#出行凭证数据更新)，钱包服务端给钱包推送更新通知。
