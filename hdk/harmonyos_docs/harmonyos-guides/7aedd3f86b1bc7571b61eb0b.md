# 打印表达式

开发者可以通过Evaluate and log能力在代码执行到断点行时打印开发者指定的表达式。

1. 在需要打印表达式结果的地方设置断点。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/R6FMRGuESwaaHRRckYsboA/zh-cn_image_0000002701662972.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=980BA83CF2CC676505B994040BEC550DC8608882DADDDE50918E6B1E320CF0EE)

2. 右键断点，然后点击**More**按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b3/v3/YjbXlK4ARi-WntKwqUYudQ/zh-cn_image_0000002731382195.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=BB64D2EB8430E65F485E80A045384E3DDA00BB5BFD9A503D6567F235D59D19F7)

3. 勾选**Evaluate and log**复选框，并在下方输入框输入要打印的表达式。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/49/v3/lYgTtBQjRfWn7QdImHcRsg/zh-cn_image_0000002701822890.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=069ADB245D638001BD9F59F7943885DCA5A080D21A04663CBD56E01013E46092)

4. 启动调试，程序运行到断点时，切换到调试的Console窗口，表达式的打印结果将在这里展示。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/jJsqavgyQ0-NSDKwjvEIVw/zh-cn_image_0000002731382193.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=178E7096B05F5ED71E76533B95FD6A0263A07F2F82E9E840C6556CE5112D1E92)
