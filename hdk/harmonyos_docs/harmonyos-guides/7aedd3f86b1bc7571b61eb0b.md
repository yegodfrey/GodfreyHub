# 打印表达式

开发者可以通过Evaluate and log能力在代码执行到断点行时打印开发者指定的表达式。

1. 在需要打印表达式结果的地方设置断点。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/dinKA7sYQc6mT8RWykRKZA/zh-cn_image_0000002701662972.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=A2109214F0FA666F9F76E4542AF2F1F12F8903529435313CC63ECCBB98D6217A)

2. 右键断点，然后点击**More**按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/_YhQD7hqSv-aRsBa78e6Pw/zh-cn_image_0000002731382195.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=8D44D1909E3B2A5E09D4F3850145FDB9276EEF817C8D6282855ED31D61B12D8F)

3. 勾选**Evaluate and log**复选框，并在下方输入框输入要打印的表达式。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/SW37R7moRFir9-3xAvOIJA/zh-cn_image_0000002701822890.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=0EB58B32DB5EAE24A83DC8B676BC4B1A1A5E7B3B743A7547364B7A1F5D4A8B73)

4. 启动调试，程序运行到断点时，切换到调试的Console窗口，表达式的打印结果将在这里展示。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/OfCWN1zCTQKJWf6HExXhsw/zh-cn_image_0000002731382193.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=04C27C28452B8DBBEE93583E04D43A8C6C7D3907355879D9AE717FDFD6A09303)
