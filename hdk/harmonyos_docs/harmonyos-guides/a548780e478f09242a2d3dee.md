# 开发准备

## 基本准备工作

请先参考"[应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview)"完成基本准备工作后再继续进行以下开发活动。

## 开通熄屏导航服务

使用熄屏导航功能需要先开通熄屏导航服务，具体请参见下方开通熄屏导航服务步骤。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"开发与服务"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/_BMtaGBxQoyPz6h-0GZFgA/zh-cn_image_0000002733434698.png?HW-CC-KV=V1&HW-CC-Date=20260917T084600Z&HW-CC-Expire=31536000000&HW-CC-Sign=B10C006CA0183089FDCD9A67ECB23EF92DBBD9D5070CB6A70476FE3241B13CAF)
2. 在项目列表中找到需要开通服务的应用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/eVeeHXlXSTiNMprUSNroeg/zh-cn_image_0000002762994221.png?HW-CC-KV=V1&HW-CC-Date=20260917T084600Z&HW-CC-Expire=31536000000&HW-CC-Sign=440D70181FA3BF16D995DFB5884BAA82B4B658073969396FFDDB7E589A5C364C)
3. 进入"开放能力管理"页签，找到"熄屏导航服务"，点击"申请"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/2kxPR117TdW9Vm5m97HcvA/zh-cn_image_0000002762834335.png?HW-CC-KV=V1&HW-CC-Date=20260917T084600Z&HW-CC-Expire=31536000000&HW-CC-Sign=0E3812B95D747FA1F34B890C31F0F5E7DE6FEC3D4F8F1CAA4D11C4BA1CB83301)
4. 确认您已满足开通熄屏导航服务的所有条件后，点击"下一步"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/HKstsKZHR1Gfe8HUg-Ymew/zh-cn_image_0000002733274820.png?HW-CC-KV=V1&HW-CC-Date=20260917T084600Z&HW-CC-Expire=31536000000&HW-CC-Sign=CD2947DC38D76C8ECE2D28E88D1348CBAC68C629BF78A09D9DF42ACC5BD7BAD4)
5. 填写熄屏导航服务申请相关参数。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/Mx8mKQ3QSAenxx8sDFVKhA/zh-cn_image_0000002733434700.png?HW-CC-KV=V1&HW-CC-Date=20260917T084600Z&HW-CC-Expire=31536000000&HW-CC-Sign=D986DBC7CD19335ADC6C5DDDA7FCF11B6FC85B3F1E40FF22027A311E6B37A10C)
   > 说明
   >
   > "申请原因"一栏填写要求如下：
   > * **应用介绍**：说明应用类型，例如：XXX应用属于XXX类型的应用。
   > * **使用场景**：说明权限使用场景，例如：在XXX场景下，需要使用XX能力。
   > * **申请用途**：描述该权限的用途，例如：用户使用XXX功能后，进行XXX操作，提供XXX服务。
   > * **场景使用承诺：** 需补充填写以下承诺内容"承诺仅在获批场景内使用该能力，如超范围使用，华为有权收回该能力。"。

6. 系统将推送消息到互动中心，请等待审核。3个工作日内审核结果会通过站内消息的形式发送到[互动中心](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/interactive)，审核通过后，熄屏导航服务默认勾选生效。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/31/v3/q5i5qJTsSrOEb4WQE6aJCQ/zh-cn_image_0000002762994223.png?HW-CC-KV=V1&HW-CC-Date=20260917T084600Z&HW-CC-Expire=31536000000&HW-CC-Sign=5B3F6A7E8615933338F074D3C754C7747A1043F15591776323B023981C74E44F)
