# 截屏

在调试过程中，可以通过多种方式截取屏幕截图。

## 通过DevEco Studio截屏

1. 连接真机设备或模拟器，并在其中运行应用。
2. 在DevEco Studio底部切换到**Log**页签。
3. 点击左侧工具栏中![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/04/v3/BEvL7CCrTVaR3e22TPnbLg/zh-cn_image_0000002701663696.png?HW-CC-KV=V1&HW-CC-Date=20260915T011702Z&HW-CC-Expire=31536000000&HW-CC-Sign=26C93670632C9D1D9911D06A0FE9469ABFEDDE62D8F327D96FE4E341A5EEDD7C)，即可截取屏幕截图。

   截图的图片将直接显示在DevEco Studio中。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e2/v3/8WwEd8aPQRC2JSmqMaU7bA/zh-cn_image_0000002731382919.png?HW-CC-KV=V1&HW-CC-Date=20260915T011702Z&HW-CC-Expire=31536000000&HW-CC-Sign=47166B8F2FD46A07D2D4FE7A977D8F2667D0744D194FF2A5550FE34A4FFE706D)

4. （可选）在图片显示区域右击，选择**Copy Path/Reference...**可以查看截屏的本地存储路径或者在菜单栏下方查看本地存储路径。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/5rm1LiwCSnW-CGPnVfI7kA/zh-cn_image_0000002731542891.png?HW-CC-KV=V1&HW-CC-Date=20260915T011702Z&HW-CC-Expire=31536000000&HW-CC-Sign=FF24BC0A6999D17A301B8A5D26750310DE54A88C68D8A3FF121457AA60A0FD9D)

## 通过命令行方式截屏

hdc是可以用于调试的命令行工具，通过该工具可以实现截屏功能。更多关于命令行工具hdc的说明请参见[hdc工具使用指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc)。

```bash
hdc shell snapshot_display -f /data/local/tmp/0.jpeg  // -f参数指定图片在设备上的存储路径，如不指定，会在命令执行完成后显示图片默认存储路径。
hdc file recv /data/local/tmp/0.jpeg  // 将图片从设备发送到本地目录，本示例将图片发送到当前执行hdc命令的目录。
```
