# 剪贴板粘贴框遮挡智能填充选择框

**现象描述**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ef/v3/wZzMWV3xRAaKu3Af2FXsMw/zh-cn_image_0000002733275590.jpg?HW-CC-KV=V1&HW-CC-Date=20260917T084552Z&HW-CC-Expire=31536000000&HW-CC-Sign=0E09A245595884CFC2ACDE73556AC60D9A01721AC1C2B943F4C1D53329F76688)

**解决措施**

在代码文件中设置.selectionMenuHidden(true)，使剪贴板粘贴框隐藏。

```TypeScript
Row() {
  Text('姓名：').textAlign(TextAlign.End).width('25%')
  TextInput().width('75%').contentType(ContentType.PERSON_FULL_NAME).selectionMenuHidden(true)
}
```
