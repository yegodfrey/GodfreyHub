# 多进程调试

部分设备上，UIAbility支持以独立进程的方式运行并调试，详细请参考[动态指定进程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/isolation-process-development-guideline#动态指定进程)，可按照以下步骤对UIAbility进行调试。

## 编译构建配置

1. 新建一个Ability，该Ability继承AbilityStage，作为独立进程的入口。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/TKcZwhW7RXmOmYcSX8A7HQ/zh-cn_image_0000002731542065.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1597721C37FBA9C3A2647D3F37C4EC6515B3FE07B17BC3C4270D2BE47703DFA)

2. 右键ets目录，新建其它需要作为独立进程启动的UIAbility。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/kOm9J-_yRSCBvbvfxGwAQA/zh-cn_image_0000002731382091.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=6DD10E72307CCA72587DC4FE72EF06B44031C8BFED8C4256E619D3A88B2821BF "点击放大")

3. 修改module.json5配置文件，增加独立进程入口及isolationProcess配置项。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/92gKNNRRRXihxFdB2j6hLg/zh-cn_image_0000002701662864.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=6E2A95178A179E0F038963F20F508FBF101CFACFF7158C755599417BC011889A)

## 调试

1. 编写跳转UIAbility的代码。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/cprAforMTxavkY2zvO6hzg/zh-cn_image_0000002701662868.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=B60339AD09F0C5C32E472B1530E2AD09205F552D6D20084F8951679896F02832)

2. 在跳转的UIAbility中或独立进程入口处设置断点，启动调试。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/miApcLfHT32VyKU1pygJGQ/zh-cn_image_0000002701822790.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=DECD75C767B5BD00459B59DE90AB9C6D335621D5F5E551F2BE2CE48E1A75C823)

   跳转到以独立进程启动的UIAbility时将会新启动一个调试会话窗口。
