# 多进程调试

部分设备上，UIAbility支持以独立进程的方式运行并调试，详细请参考[动态指定进程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/isolation-process-development-guideline#动态指定进程)，可按照以下步骤对UIAbility进行调试。

## 编译构建配置

1. 新建一个Ability，该Ability继承AbilityStage，作为独立进程的入口。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/aeMbD7JXQOqgYrS7kn2xcg/zh-cn_image_0000002731542065.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=65640C20F28639E0A91BA315CF013789F0227715E7CE95F59C61FEEFCB5C59EF)

2. 右键ets目录，新建其它需要作为独立进程启动的UIAbility。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/ZOswgfiJS9mJijHRyeEnlQ/zh-cn_image_0000002731382091.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=F3DBE0FB5B32CD490C28848BB78F346766FB4F785ED63DE477CDBE0225133AB0 "点击放大")

3. 修改module.json5配置文件，增加独立进程入口及isolationProcess配置项。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/npOP7GllTfe2cFlb1QUffA/zh-cn_image_0000002701662864.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=99351108EBC69EA756B6491FF7DEAF6B952DD171FF8B068056CA68A698D0B63F)

## 调试

1. 编写跳转UIAbility的代码。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/4HGzcBGMRkyYqJhja_nc1g/zh-cn_image_0000002701662868.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=4466B6854D3BE3412944B0B8366D489E51650AA7E88DB1D30876C70E0DB63483)

2. 在跳转的UIAbility中或独立进程入口处设置断点，启动调试。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/0NrTd_kgQ2WCni7ykKcXww/zh-cn_image_0000002701822790.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=10A345C2670A7E3079586F6D41D5294F68264992DB857D125C42C0E89FE44198)
