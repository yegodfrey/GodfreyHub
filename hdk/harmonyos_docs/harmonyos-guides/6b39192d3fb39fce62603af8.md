# 启动和关闭模拟器

在设备管理器页面，单击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/NUzWWfOxSXeCg9GjxWJsIA/zh-cn_image_0000002701661932.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=13E717D63BB34FE0C669F7DEEB33A5C7ABC4C9DE5B95D95A5FB5C5D80C1AD3BF)即可启动模拟器。模拟器启动时会默认携带之前运行时的用户数据，包括用户上传的文件，安装的应用等。如果是新创建的模拟器，则不会携带用户数据。如果想清除之前运行时的用户数据，点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/9cNLaKKfRtCZ-ZelV-d4qg/zh-cn_image_0000002731541117.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=8700664F9C66D9E0C5E5151DF6B1030ED6F4DC5EC04E614C94AF133D63335A50)**> Wipe User Data**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/LcaCW3lkRhaOdm-IqCCPZQ/zh-cn_image_0000002701821860.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=4FAB933029D96B4AD9BA6C037E6F652BD61E2C21535F5C6862C32AE24284B88D "点击放大")

从DevEco Studio 6.1.0 Beta1版本开始，如果创建模拟器时选择热启动，则启动模拟器时会加载上次关闭时保存的快照，启动后会恢复至上次关闭时的状态。热启动后，多屏状态会恢复为单屏状态。

从26.0.0版本开始，如果热启动后出现异常，可点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/eKyZSMM2RmiN2zplI8EL6g/zh-cn_image_0000002731541139.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=F708760ABF6A85C760A6F7C94C88F48C7CE0E33E42A5122B1211680E97A016CF)**> Cold Boot**，本次将以冷启动方式启动模拟器，并且会保留之前的用户数据，关闭模拟器时仍会保存快照。

例如推包运行后关闭模拟器，再次启动时会显示在上次运行的界面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/vrcQpGWOTGa445HiEzUr3Q/zh-cn_image_0000002731381189.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=D11E56710F1459505B7F53217F607DE00454F7FCAB33AC59C04AF7BC438107C3 "点击放大")

在模拟器运行期间，可以点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/A1OyPbMHRpqVutg7iaa1JA/zh-cn_image_0000002701821874.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=A099E24FBE6B5C638898E302D8F6A7E8607E7BB44AFCE73CE6A383C3F0FFDA5E)**> Show on Disk** 显示模拟器在本地生成的用户数据。点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/hmI6FYCdRnG3saWygTj7Pg/zh-cn_image_0000002701821854.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=4DEE67C64FBBDF9F83211430C7C461A9BA558FE01598F51263945DB26714DBD4)**> Generate logs** 可以生成模拟器自启动到此刻的所有日志信息。想要关闭运行中的模拟器，可以在设备管理器页面点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/1hs6kxyxQQqIbtffIINOpw/zh-cn_image_0000002731541111.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=218B9EA317EC49348ADD284E862CE2D4508AC199A8F7ABBAA557459792064EFA)，或者点击模拟器工具栏上的关闭按钮![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/ZM3wijIZQI-FbQnNjH2SAg/zh-cn_image_0000002731541163.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=A80F7900D54B7A06B72B161F1A670489331AC77123ECCF6F0DA8124C0BE66F5D)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/3G0aqvOdRbSSgfTFJNyEXg/zh-cn_image_0000002731381151.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=1AA492093D8884BD9C9582D46C3D7CCAAF36F31423383FFB3870894B0AA0E4E5 "点击放大")

模拟器关闭后，点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/Oiob8cwRRK2p6RZr_orAFg/zh-cn_image_0000002731541153.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=B10DC335CF9AF15AB438ED67874214B22CCF578746C9C94A031ABC7A97051EC2)**> Delete**可以删除模拟器，并清除模拟器的用户数据和配置信息。
