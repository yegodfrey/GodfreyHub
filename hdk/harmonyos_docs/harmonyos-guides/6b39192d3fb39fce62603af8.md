# 启动和关闭模拟器

在设备管理器页面，单击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/JxKtBpY4RBaD99Qn6EdAiA/zh-cn_image_0000002701661932.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=B23978166DD9470FA404263B1DD5179739D27E67ED5D8429BC395BDB3032446A)即可启动模拟器。模拟器启动时会默认携带之前运行时的用户数据，包括用户上传的文件，安装的应用等。如果是新创建的模拟器，则不会携带用户数据。如果想清除之前运行时的用户数据，点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/05/v3/pGLDXaK0Rz2to7q3oK7tfA/zh-cn_image_0000002731541117.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=51F28AC5C1404D69A46EAB85B9B09BFB7DFDE9A0F600DEC634430D919984D9BE)**> Wipe User Data**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/Ry-1ZwTWRCa_aoDmZE5fZA/zh-cn_image_0000002701821860.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=41A7C7A900A34F52B7E77C4918C066B0AEB079AF3943AFDEF0F2D97CE4DC2155 "点击放大")

从DevEco Studio 6.1.0 Beta1版本开始，如果创建模拟器时选择热启动，则启动模拟器时会加载上次关闭时保存的快照，启动后会恢复至上次关闭时的状态。热启动后，多屏状态会恢复为单屏状态。

从26.0.0版本开始，如果热启动后出现异常，可点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/vDttA2nCSm-8SpumvNMTPw/zh-cn_image_0000002731541139.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=6CEA08509C4CE503B35EE8A337EC2D5074D4556CFAEFBF77BCADC0981DA22F58)**> Cold Boot**，本次将以冷启动方式启动模拟器，并且会保留之前的用户数据，关闭模拟器时仍会保存快照。

例如推包运行后关闭模拟器，再次启动时会显示在上次运行的界面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/12/v3/BKHQdlDiTqqoZJAhJ44cOw/zh-cn_image_0000002731381189.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=CDE6E97839B82B3C9C192A2049F38C5F164BD1E153F55492302D5FB1AD8AC3BA "点击放大")

在模拟器运行期间，可以点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/70RRhYerSvaM5ACOtUqKnQ/zh-cn_image_0000002701821874.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=A869CF6452CD302F7F541D85C33E2D107C04AC06C37964FEC92292783D07D40A)**> Show on Disk** 显示模拟器在本地生成的用户数据。点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/NTCelToeRnmVepYLiY4k8Q/zh-cn_image_0000002701821854.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=67CD93CEE6F2AA65251976B4F222B0018C69E97BABBA9DF85B7F43B3BB4BA316)**> Generate logs** 可以生成模拟器自启动到此刻的所有日志信息。想要关闭运行中的模拟器，可以在设备管理器页面点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/qPkR5sGMROWtzqesnrc8-g/zh-cn_image_0000002731541111.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=4AD8FF27313830FA9DF23217A683C662AE0410C09FD27E2B8E3717AAD2ADF260)，或者点击模拟器工具栏上的关闭按钮![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/wLzYgz2USeuJgnxf-1NVbg/zh-cn_image_0000002731541163.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=E15EA1F02AC07452B0B214E4725D9BF98C5A5C36788039F64CB2B0879FF8CCF6)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/V5kDuMh7TiOqAlyomQ4PKw/zh-cn_image_0000002731381151.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=27B77FA3A7C2AFFC76768373C4F3C76A931E390313A0CBBFCBBDA2118FC600F4 "点击放大")

模拟器关闭后，点击**Actions >** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/FTka70RdR3qFTh6kvfxNcw/zh-cn_image_0000002731541153.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=E561F659B255E216AE9352E215070C99EA12762994E4E3B919F5006761D0F720)**> Delete**可以删除模拟器，并清除模拟器的用户数据和配置信息。
