# 配置签名

在DevEco Studio上，参考[创建一个新的工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-create-new-project)和[自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto)完成工程应用的创建及签名配置，从而确保能顺利完成项目的编译与开发。
> 说明
>
> 如果开发者DevEco Studio版本低于6.0.0 Beta5，请使用[手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual)完成工程应用的签名配置。
