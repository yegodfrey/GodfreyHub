# 更新园区卡

当园区卡信息发生变更时，如园区卡权限、信息变更等，更新钱包中的园区卡数据。

## 服务端开发

开发者服务器通知钱包服务端进行[园区卡数据更新](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/wallet-rest-api-park#园区卡数据更新)，钱包服务端给钱包推送更新通知。
