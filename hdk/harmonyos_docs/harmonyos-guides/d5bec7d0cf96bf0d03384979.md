# 使用工具栏

工具栏上集成了模拟器的各种调试工具和控制选项，其中的扩展菜单栏包含了更加丰富的功能。注意，部分工具栏按键需要在模拟器开机亮屏后才能使用。以下对工具栏的各个按键功能作简要说明：  

|按键|功能描述|
|:---------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|关闭![](https://media:401788752121693575)|关闭模拟器。|
|最小化![](https://media:401788752121848576)|最小化模拟器窗口。|
|更多![](https://media:401788752122183577)|打开侧边扩展菜单。|
|电源![](https://media:401788752122217578)|模拟电源，可模拟亮灭屏操作，从DevEco Studio 6.1.0 Beta1版本开始支持。|
|置顶![](https://media:401788752122299579)|将模拟器置于所有打开窗口的顶层。|
|左旋转![](https://media:401788752122332580)|将设备屏幕逆时针旋转90度。|
|右旋转![](https://media:401788752122367581)|将设备屏幕顺时针旋转90度。|
|增大音量![](https://media:401788752122409582)|调高设备音量，长按可持续调高设备音量。|
|减小音量![](https://media:401788752122438583)|调低设备音量，长按可持续调低设备音量。|
|截屏![](https://media:401788752122468584)|生成当前屏幕的截图，并将图片保存在本地计算机。|
|返回![](https://media:401788752122501585)|返回上一屏幕或关闭对话框、选项菜单、通知面板或屏幕键盘。|
|主屏![](https://media:401788752122537586)|返回Home界面。|
|最近![](https://media:401788752122569587)|点击可打开最近使用过的应用的缩略图列表。要打开某个应用，请点击其缩略图。要从列表中删除缩略图，请向上滑动缩略图。|
|摇一摇![](https://media:401788752122709588)|触发设备摇一摇操作，详情参考[摇一摇](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-more-features#section1241612419541)。|
|多屏![](https://media:401788752122949589)|打开多屏面板，可以动态增删屏幕，详情参考[多屏](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-more-features#section9744191415368)。|
|电池![](https://media:401788752123193590)|打开电池模拟面板，详情参考[电池](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-more-features#section169214910812)。|
|GPS![](https://media:401788752123225591)|打开GPS模拟面板，详情参考[GPS定位](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-more-features#section81566471211)。|
|虚拟传感器![](https://media:401788752123258592)|打开虚拟传感器面板，详情参考[虚拟传感器](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-more-features#section830415558395)。|
|网络![](https://media:401788752123301593)|打开网络面板，详情参考[网络](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-more-features#section206461549731)。|
|虚拟相机![](https://media:401788752123341594)|打开虚拟相机面板，详情参考[3.6-摄像头](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-emulator-more-features#section11725194916439)。|
|设置![](https://media:401788752123374595)|打开设置面板。可设置模拟器主题、截屏保存路径、模拟器使用语言。|
|Bug报告![](https://media:401788752123406596)|打开Bug报告面板。点击保存并发送按钮可以将Bug日志传递给我们。|
|关于![](https://media:401788752123439597)|打开关于面板。可以查看模拟器相关信息及许可证。|
|展开![](https://media:401788752123481598)|仅支持可折叠设备。切换设备形态至展开态。|
|悬停![](https://media:401788752123649599)|仅支持可折叠设备。切换设备形态至悬停态，并显示折痕避让区。|
|折叠![](https://media:401788752123799600)|仅支持可折叠设备。切换设备形态至折叠态。|
|三屏![](https://media:401788752123916601)|仅支持三折叠设备。切换设备形态至左展开，右展开状态。对应[FOLD_STATUS_EXPANDED_WITH_SECOND_EXPANDED](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-matext-guide#section15762231134610)状态。|
|双屏![](https://media:401788752123991602)|仅支持三折叠设备。切换设备形态至左折叠，右展开状态。对应FOLD_STATUS_EXPANDED状态。|
|单屏![](https://media:401788752124209603)|仅支持三折叠设备。切换设备形态至左折叠，右折叠状态。对应FOLD_STATUS_FOLDED状态。|
|左半折，右展开![](https://media:401788752124239604)|仅支持三折叠设备。切换设备形态至左半折，右展开状态，并显示折痕避让区。对应FOLD_STATUS_EXPANDED_WITH_SECOND_HALF_FOLDED状态。 从DevEco Studio 6.1.0 Beta2版本开始支持。|
|左展开，右半折![](https://media:401788752124272605)|仅支持三折叠设备。切换设备形态至左展开，右半折状态，并显示折痕避让区。对应FOLD_STATUS_HALF_FOLDED_WITH_SECOND_EXPANDED状态。 从DevEco Studio 6.1.0 Beta2版本开始支持。|
|左半折，右半折![](https://media:401788752124309606)|仅支持三折叠设备。切换设备形态至左半折，右半折状态，并显示折痕避让区。对应FOLD_STATUS_HALF_FOLDED_WITH_SECOND_HALF_FOLDED状态。 从DevEco Studio 6.1.0 Beta2版本开始支持。|
|左折叠，右半折![](https://media:401788752124343607)|仅支持三折叠设备。切换设备形态至左折叠，右半折状态，并显示折痕避让区。对应FOLD_STATUS_HALF_FOLDED状态。 从DevEco Studio 6.1.0 Beta2版本开始支持。|
|左半折，右折叠![](https://media:401788752124383608)|仅支持三折叠设备。切换设备形态至左半折，右折叠状态。对应FOLD_STATUS_FOLDED_WITH_SECOND_HALF_FOLDED状态。 从DevEco Studio 6.1.0 Beta2版本开始支持。|
|左展开，右折叠![](https://media:401788752124417609)|仅支持三折叠设备。切换设备形态至左展开，右折叠状态。对应FOLD_STATUS_FOLDED_WITH_SECOND_EXPANDED状态。 从DevEco Studio 6.1.0 Beta2版本开始支持。|
|横展![](https://media:401788752124452610 "点击放大")|仅支持折叠2in1设备。切换设备形态至横展状态。|
|竖展![](https://media:401788752124487611 "点击放大")|仅支持折叠2in1设备。切换设备形态至竖展状态。|
|悬停![](https://media:401788752124518612)|仅支持折叠2in1设备。切换设备形态至悬停状态。|
|磁吸![](https://media:401788752124560613)|仅支持折叠2in1设备。切换设备形态至磁吸状态。|
