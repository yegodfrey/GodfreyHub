# 基础内存：Allocation分析

#### 功能介绍

应用在开发过程中，可能因API使用错误、变量未及时释放、异常频繁创建/释放内存等情况引发各种内存问题。

DevEco Profiler提供了基础的Allocation内存场景分析功能。通过使用Allocation来分析应用或元服务在运行时的内存分配及使用情况，识别和定位内存泄漏、内存抖动以及内存溢出等问题，对应用或元服务的内存使用进行优化。

Allocation模板支持的泳道包括：Memory、ArkTS Allocation、ArkTS Snapshot、All Heap \& Anonymous VM、All Heap、All Anonymous VM、System Resources、Graphic Memory、Native Leaks。同时，Allocation模板支持离线符号解析能力，相关能力介绍请参考[离线符号解析](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-insight-session-time#section186881175012)。
