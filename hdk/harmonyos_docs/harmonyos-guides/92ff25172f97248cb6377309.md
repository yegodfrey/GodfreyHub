# 前台场景内存峰值占用

## 规则详情

应用/元服务前台场景峰值内存占用：应用在前台且亮屏使用过程的内存占用应≤1500MB。

## 检测逻辑

1. 执行hdc shell。
2. 执行hidumper --mem <进程pid>命令，获取如图Pss字段。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/ZqMyiEOYRn-Xat2grQel1g/zh-cn_image_0000002731381845.png?HW-CC-KV=V1&HW-CC-Date=20260928T063034Z&HW-CC-Expire=31536000000&HW-CC-Sign=47A241C2613B5947A0CB16538BC38ECBF843A88DF8DBAFD532D39736F2E85D6E)

## 计算逻辑

执行多轮测试，取最大Pss值为占用峰值，内存占用小于1500MB。
