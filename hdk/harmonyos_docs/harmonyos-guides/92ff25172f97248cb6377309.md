# 前台场景内存峰值占用

## 规则详情

应用/元服务前台场景峰值内存占用：应用在前台且亮屏使用过程的内存占用应≤1500MB。

## 检测逻辑

1. 执行hdc shell。
2. 执行hidumper --mem <进程pid>命令，获取如图Pss字段。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/8eWY9MhfTPieLmgIfu1SoQ/zh-cn_image_0000002731381845.png?HW-CC-KV=V1&HW-CC-Date=20261010T073012Z&HW-CC-Expire=31536000000&HW-CC-Sign=706E5F392A68BFCB4E6E855BE66F0A87E391CFC83536DC25F180EB6A02DB92A2)

## 计算逻辑

执行多轮测试，取最大Pss值为占用峰值，内存占用小于1500MB。
