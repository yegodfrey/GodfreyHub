# 使用云存储上传文件失败，提示"404:Product does not exist"

**问题现象**

使用云存储上传文件失败，HiLog提示"404:Product does not exist"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/hYOqvwZhQFyjp4OACq9-3g/zh-cn_image_0000002749493560.png?HW-CC-KV=V1&HW-CC-Date=20260929T121653Z&HW-CC-Expire=31536000000&HW-CC-Sign=5DCD2590C2AB09F5B90083F4BBEDF77E4E45AD876DC622A3837CD58A9046CF20)

**解决措施**

此错误由云存储服务端返回，原因是云存储服务未开通。请[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/cloudfoundation-enable-storage)。
