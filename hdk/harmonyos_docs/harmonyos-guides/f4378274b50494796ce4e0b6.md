# 使用云存储上传文件失败，提示"404:Product does not exist"

**问题现象**

使用云存储上传文件失败，HiLog提示"404:Product does not exist"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/Sujyfv6fSlS-l_Eoh3yx0A/zh-cn_image_0000002733275298.png?HW-CC-KV=V1&HW-CC-Date=20260917T084549Z&HW-CC-Expire=31536000000&HW-CC-Sign=D3FEEDD761D3CC9184C9904C9722808211CC1CE909A560C32EF883F69856C9E0)

**解决措施**

此错误由云存储服务端返回，原因是云存储服务未开通。请[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/cloudfoundation-enable-storage)。
