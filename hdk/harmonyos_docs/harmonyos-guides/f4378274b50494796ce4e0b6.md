# 使用云存储上传文件失败，提示"404:Product does not exist"

**问题现象**

使用云存储上传文件失败，HiLog提示"404:Product does not exist"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e0/v3/vJb3WDCsSC2c-SF7FJGBzA/zh-cn_image_0000002755024702.png?HW-CC-KV=V1&HW-CC-Date=20261009T092710Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F0B2F909FB9AEA4B2D4C308D897259678DFD1190E9E81967A8BA8F352FFA329)

**解决措施**

此错误由云存储服务端返回，原因是云存储服务未开通。请[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/cloudfoundation-enable-storage)。
