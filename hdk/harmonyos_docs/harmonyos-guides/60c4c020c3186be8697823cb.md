# 用户管理

用户管理页面可以新增用户、编辑用户信息、修改用户类型、重置用户密码，删除用户和搜索用户，页面效果如下图所示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/VFYwYG-WTaq99MPV1iM86w/zh-cn_image_0000002731381195.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=59CFE4AB22FC0ED7728872B30AEE596A04497970F6133283E76D3C11327A38A6 "点击放大")

1. 点击"新增"按钮，弹出新增用户面板，输入用户名（必填）、密码（必填）、邮箱（可选）和手机号（可选），新增用户首次登录将强制重置密码。填完用户信息后点击新增即可添加一个新用户，页面效果如下图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/l4lRHHPaTv2rNXRLuUSDJA/zh-cn_image_0000002731381539.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=7FA59FDEA816C11FBCCAB6EF61C6079292B726AD0014EB85D0B50DBCB015A944 "点击放大")

2. ohpm-repo从6.0.1版本开始，新增"编辑用户信息"按钮。 点击"编辑用户信息"按钮，再点击邮箱或手机号后的勾选框后，即可编辑用户的邮箱或手机号。点击确认修改用户信息，将出现密码输入框，由于管理员修改其他用户的信息是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/UxWNPdVlQ028rVcgh0R2Fw/zh-cn_image_0000002731541119.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=F71849B28F55849FF56039D038A164E203019AF4F8987E994E2F09E933FA407B "点击放大")

3. 点击"编辑类型"按钮，弹出编辑用户类型面板，在此面板中可以修改用户类型成管理员或用户。点击确认修改用户类型，将出现密码输入框，由于管理员修改其他用户的类型是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/lnLDB0jZQYmEDW4bfP5w8A/zh-cn_image_0000002731381545.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=58B692CE5317A2EF6FCE2EFBE09EBC0A52F73CB1DF1482F81E63D8E9BC30797C "点击放大")

4. 点击"重置密码"按钮，弹出重置用户密码面板，在此面板中可以通过点击生成新密码为用户生成随机新密码，并可通过点击复制图标将新密码复制进剪贴板（只有点击**确定** 按钮才会重置密码）。点击确认重置密码，将出现密码输入框，由于管理员对其他用户重置密码是敏感操作，故需要输入当前操作账户的密码进行再次验证，页面效果如下图所示：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/2gcQDn4SRBOD7OMDYYmQ9A/zh-cn_image_0000002701661934.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=09ADB04D4FC9EFED368DC6512AD2125FB54235642D4229963C6BCCE552CDE551 "点击放大")

5. 点击"删除"按钮，弹出删除提示，如果确定删除，需要点击按钮"是"，将出现密码输入框。由于管理员删除用户属于敏感操作，需要输入当前操作账户的密码进行再次验证，页面效果如下图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/cvpQowjTTFyfCkrsmny_Fg/zh-cn_image_0000002731381557.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=6111C35AE655F26369B3A31A12191897F9CE7B8784C9C6F490B2831F8CAB1392 "点击放大")

   当被删除的用户是某个三方包的唯一所有者时，禁止被删除。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/0lrTHOZ8QOigXvGZOGaVqQ/zh-cn_image_0000002701821858.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=0A61C8A1F6F2DB69EFD480C75B7D8218DF696EE8975CB899A0DA8BE822916A60 "点击放大")

6. 点击搜索框，支持指定用户类型（系统管理员/普通用户）和用户名模糊搜索，搜索页面效果如下图所示（以指定用户类型为系统管理员，用户名为admin为例）： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b2/v3/3lhgzE-OSpiul0fKBOAewA/zh-cn_image_0000002701661958.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=75ADCAC425F08DADD28D0E10631BDE9985C103E334D0230E316D8F371940B926 "点击放大")
