# 场景介绍

## 手机与穿戴设备分布式协同

* 重要通知实现腕上提醒，实现即时通知推送，如：在手机侧App中设置日程提醒、用药提醒、任务提醒等数据，可以同步到穿戴设备侧App中，不用打开手机，也可以随时在穿戴设备上查看重要信息。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/0uh9gLA1Rp6m0fPWj8myIw/zh-cn_image_0000002755024226.png?HW-CC-KV=V1&HW-CC-Date=20261009T092722Z&HW-CC-Expire=31536000000&HW-CC-Sign=B310A96DED1276DDFB2B6AE74E0FBFDDBD6F152AE4FD13A4BB9D332443115A40)
* 为手机应用带来全新的"腕上交互"，如：用手机侧App看视频、听音频时，可以通过穿戴设备侧App操控手机侧App，比如暂停，下一首，停止等。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/3oQDSBG3SbWbqxbRemL3Mw/zh-cn_image_0000002755184114.png?HW-CC-KV=V1&HW-CC-Date=20261009T092722Z&HW-CC-Expire=31536000000&HW-CC-Sign=88845338082D803DCC7785DE2FA73CDD7AF63A3E6BFAAC690EE307C3D4FC350B)
* 手机侧和穿戴侧的实时协同体验。如：在手机侧App开启导航，可以通过穿戴设备侧App提示用户左转、直行、右转等。在走路或骑行时，不用每次拿出手机查看路线。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/52/v3/bjf9XQxOQ1qvN1Lcbxh1hQ/zh-cn_image_0000002784582981.png?HW-CC-KV=V1&HW-CC-Date=20261009T092722Z&HW-CC-Expire=31536000000&HW-CC-Sign=5DAE200741905F12CB9DA7A4EBDF67AE2F68E13AC12ECCDD3C184476D1B57D4F)

## 手机与穿戴设备虚拟化

开发者在手机侧开发App，而不需要在穿戴设备侧开发App。

* 穿戴设备状态实时掌握，如：手机侧App实时获取穿戴设备侧连接状态、佩戴状态、电量状态等，给用户提供更多增值服务。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f/v3/KYiTvxC3QE6G7BIjpLpwaQ/zh-cn_image_0000002784663161.png?HW-CC-KV=V1&HW-CC-Date=20261009T092722Z&HW-CC-Expire=31536000000&HW-CC-Sign=C71381A312FB39BE02F206E3361CF21FE2238A668294463CCB4938D802515865)
* 穿戴设备传感器：手机侧App读取穿戴设备的传感器数据（如ECG、PPG、ACC数据等）。

  > 说明
  >
  > 传感器受限发布，仅限专业研究机构使用。
