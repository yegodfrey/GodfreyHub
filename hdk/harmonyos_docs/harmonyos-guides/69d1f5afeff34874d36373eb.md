# 场景介绍

## 手机与穿戴设备分布式协同

* 重要通知实现腕上提醒，实现即时通知推送，如：在手机侧App中设置日程提醒、用药提醒、任务提醒等数据，可以同步到穿戴设备侧App中，不用打开手机，也可以随时在穿戴设备上查看重要信息。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/Y05cn0LlSa6oXd0lxvvZUQ/zh-cn_image_0000002749493082.png?HW-CC-KV=V1&HW-CC-Date=20260929T121702Z&HW-CC-Expire=31536000000&HW-CC-Sign=309DA6C6B2D381C1C1D280AC6A991ABBF04418625B2C7FB10B39E0C7361B84BB)
* 为手机应用带来全新的"腕上交互"，如：用手机侧App看视频、听音频时，可以通过穿戴设备侧App操控手机侧App，比如暂停，下一首，停止等。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/XRuveoW0SaaHyTw-u1SmUQ/zh-cn_image_0000002779092141.png?HW-CC-KV=V1&HW-CC-Date=20260929T121702Z&HW-CC-Expire=31536000000&HW-CC-Sign=41043D01E7CDF82D0FE5D8C8AD8316DE6794A1C6ACB93BE31719E10A3CD6CCAB)
* 手机侧和穿戴侧的实时协同体验。如：在手机侧App开启导航，可以通过穿戴设备侧App提示用户左转、直行、右转等。在走路或骑行时，不用每次拿出手机查看路线。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/18HCyNOoSPeYeZNC_7jHvQ/zh-cn_image_0000002778932283.png?HW-CC-KV=V1&HW-CC-Date=20260929T121702Z&HW-CC-Expire=31536000000&HW-CC-Sign=B1EFD54DF98999AB0E8767A29BC72D131F6FDE307F5FB97F47FBF3222CA3AD27)

## 手机与穿戴设备虚拟化

开发者在手机侧开发App，而不需要在穿戴设备侧开发App。

* 穿戴设备状态实时掌握，如：手机侧App实时获取穿戴设备侧连接状态、佩戴状态、电量状态等，给用户提供更多增值服务。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0c/v3/G1B4ueuWSdSuOcTCOnzpDw/zh-cn_image_0000002749333200.png?HW-CC-KV=V1&HW-CC-Date=20260929T121702Z&HW-CC-Expire=31536000000&HW-CC-Sign=C685949373E70E0537F907DCD4AD7992F398984F963990F5DF0C8F8332E15A8F)
* 穿戴设备传感器：手机侧App读取穿戴设备的传感器数据（如ECG、PPG、ACC数据等）。

  > 说明
  >
  > 传感器受限发布，仅限专业研究机构使用。
