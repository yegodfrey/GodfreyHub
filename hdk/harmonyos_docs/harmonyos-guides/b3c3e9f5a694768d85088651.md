# 测试函数

> 说明
>
> 下文以函数latest版本为例介绍测试方法。如果需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5/v3/d0T7iea6Tpmx71fnVPBRug/zh-cn_image_0000002784583431.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=91953F29938C82765B1CF227830C1683AB915461A5B5343D351DC4BF0F5E3E61)
* 方式二：

  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/V3aj4kIZSIypiMnLNoIW-A/zh-cn_image_0000002784663611.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=5612FBDF3E6405D8E4F644F4C1BE220F78A7ECB637E0D32211E6604CE42FF37C)
  2. 选择"函数代码"页签，点击"测试函数"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/2rCw28hWT8ysekgiBiEwRw/zh-cn_image_0000002755024678.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=F78D72359AE62CACB43DD485C731C77F7641F0DBB8575199F2FEF7B947A1363C)
  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。

     * 使用默认测试事件：直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/dHDFOE36TButjYQKcLbDyA/zh-cn_image_0000002755184566.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=2788580CA5E9CB79F257346778C7BBA94255E467672357E8EE3CC94E8A82A135)
     * 创建新测试事件：如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。

          > 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/x6Be06IISfW73ri2Ro9zvw/zh-cn_image_0000002784583433.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=19893ECB8D52F728303E082DF417B4E72C51F4F648FE8006C3C5EEC6C273F5F8)
       2. 点击"测试"，函数处理事件并返回测试结果。

     * 使用已保存测试事件

       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dd/v3/DpxL76VHRAuBXvzqx3MS7Q/zh-cn_image_0000002784663613.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=A79DDDF897F672A71347F12C36615548B0CD1E46C289FD23D5D82D6C7A3FF5B9)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bc/v3/UOZfOHAgRuWkHXXnc9UZbA/zh-cn_image_0000002755024680.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=0E3218F1E5BB5342356A2FDBA38E883748FC087C0EFBFEC4E539A01D17714B31)
       2. （可选）如果需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/J7V5_z6iSE6svpLxAjtkpA/zh-cn_image_0000002755184568.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=81E1BB542CF15287FAFE451BF9A6582A538E66E97E5F3346E65A776DFFDE34BE)
  4. 查看测试结果。

     * 执行结果：展示测试后获得的响应结果。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/SHFFQdaaT-qljNdXGxxhyA/zh-cn_image_0000002784583435.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=2AD043067858C3968F6CDB53C796A73A02209CD26C5D4BFB63234DB9DF2CE14F)
     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/06/v3/AaquYiL5SS-79-C7eZOP0Q/zh-cn_image_0000002784663615.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=33057A6B92B79B65DE007C26EC669E278BC74B33AD202FBE9C13AF4D4919C16C)
     * 执行摘要：展示该次测试请求相关信息。

       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/gJ1CoOesRtuRhd9U2JpFLg/zh-cn_image_0000002755024682.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=3B3019474882C1D3F577DBAC50589913B48347B26663DD3669CCC4F52838340C)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，如果需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/C1_gSDD6QbSZS-VpXhpIsA/zh-cn_image_0000002755184570.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=4B83662F7AD3F7D0E894C17B6358364A4A665570EE71927DD52FDE195492BE8B)

     "代码输入类型"为".zip文件"的函数，测试过程中，如果需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/dnwfjQ_ZTxutggV3vdMIEw/zh-cn_image_0000002784583437.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=7E4FC70568ACBA20F37CF9A00A69C594629741E0FC94FD85F9BA8D17C7903D8C)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 如果代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/a4k8IHZpQ76sP5ZmNPJCnw/zh-cn_image_0000002784663617.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=E7BF68CF17CA7001B883A22D4A1C365EF57C014DF3C028C4AA2ACD975BDEF948)
  6. 函数测试无误后，可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
