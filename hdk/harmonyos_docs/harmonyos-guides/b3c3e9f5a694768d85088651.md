# 测试函数

> 说明
>
> 下文以函数latest版本为例介绍测试方法。如果需要测试函数的已发布版本，可在已发布版本详情页面选择"函数代码"页签，参考方式二进行测试。

函数创建后可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：

* 方式一：函数列表中点击函数名称右侧"操作"列的"测试"，在右侧弹出的"测试函数"界面进行测试。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/jh48S_amSsaS_jxVjpl8jQ/zh-cn_image_0000002778932733.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=46E9F9ACBEB96678DC60E8C362FBBF242DEB2C26CD2C05A3872A964AA2903F03)
* 方式二：

  1. 在函数列表中点击已创建的函数名称，进入函数详情页面。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/pEmfL-LLQ-KrFxSQaswwHQ/zh-cn_image_0000002749333652.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=D7D436F7B704DADC551A35CD8437DB4ECD751EC2A62DB50A37E78657B9AC60F8)
  2. 选择"函数代码"页签，点击"测试函数"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/Ivde5Zo_TxWigqojDskG6g/zh-cn_image_0000002749493536.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=FDBD62809B04B696CF8455274BAD9B18CEDFB6184A64BBD444CB6C0380F10AEB)
  3. 在右侧弹出的"测试函数"界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。

     * 使用默认测试事件：直接点击"测试"对函数进行测试。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/KUDQXd4QRVypk-ac__pJHA/zh-cn_image_0000002779092593.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=4DECCB5A20B92012310C4D7D7FBDE3AEF08E4554C29C13095EB72DCACE8AE60A)
     * 创建新测试事件：如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。

       1. 在"事件"文本框中输入JSON格式的事件参数，点击"保存"。然后在"提示"弹出框中输入事件名称，配置完成后点击弹出框右下角的"确认"。

          > 说明
          >
          > "事件"文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/wASyKgkTQGuPInxkBYqjbg/zh-cn_image_0000002778932735.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=9AD8DD666F6211EE2DB7CD87F25C6DF52223F8A41D366EB91516A191D5B58623)
       2. 点击"测试"，函数处理事件并返回测试结果。

     * 使用已保存测试事件

       1. 在"测试函数"界面，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/2yu3e-6YSrGK2J5joM92xQ/zh-cn_image_0000002749333654.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=65A252A0523435601E95B5AA1648116364783DA10189F2B7AFC63FB4AE102322)展开已保存的测试事件列表，选择已配置的事件名称右侧的"加载"，然后点击"测试"，函数处理事件并返回测试结果。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2/v3/JJO9BPPRTFG_j4UtjFWpww/zh-cn_image_0000002749493538.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=439C61FAFE13437C371DD12FC096D7707C568CB41CA5F3D5121DEBFDAD2730DE)
       2. （可选）如果需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的"删除"即可删除测试事件。

          ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/AziFCzGoS3Ordu9f6ROVaA/zh-cn_image_0000002779092595.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1C456C19A05412D2FA11FD295BF697766A3A8C5E4FC95E903E450AD4A408146)
  4. 查看测试结果。

     * 执行结果：展示测试后获得的响应结果。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/DR7cABKUSwe4gP1B6u6CvA/zh-cn_image_0000002778932737.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=66BEA0CC5C408A036B1A689E17C2E6301B6C3402E70C5C200E8475A1815EA3B5)
     * 运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ef/v3/69bBWWW0SLiAzbd0TMaYdA/zh-cn_image_0000002749333656.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=889A9E5905DD414D8779D0705D7EF00D2B03FD44B5A92AB81735077743C594EF)
     * 执行摘要：展示该次测试请求相关信息。

       * 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
       * 持续时间：函数执行的端到端时间。
       * 执行版本：该次调用测试的具体函数版本。

       ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/1WrDCeYRTLCu4n-eOyFPBw/zh-cn_image_0000002749493540.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=C01886C5C583C86B945EB53C2088D51EFD9C8D776CE6361D270967A1C3F3ACE3)
  5. "代码输入类型"为"在线编辑"的函数，测试过程中，如果需要修改函数入口文件代码，可直接在"函数代码"页签的代码编辑器中修改，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5c/v3/2RoZu9dsRg6-Vy0QD53Wng/zh-cn_image_0000002779092597.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=EFD5D5861550A97C67B0F9052FB3F851D649DE275BB712C71798AC4AFFE03E48)

     "代码输入类型"为".zip文件"的函数，测试过程中，如果需要修改函数代码文件，可在本地修改且打包完成后，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/xHho5n88SGSMcWuXW_17_w/zh-cn_image_0000002778932739.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=013ECAD69111934CD51E699329AC7CC22DB0D7418984DEBA2DE59B197CDA1368)重新上传函数部署包，然后点击页面底部的"提交"。当界面提示更新函数成功时，则可以点击"测试函数"对更改后的代码进行测试。
     > 说明
     >
     > 如果代码更新量比较大，需要调整函数内存配置，可点击"内存配置"下拉框进行调整，然后再上传函数部署包。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/yH_6V6_UQFO2jvD9aA2mNQ/zh-cn_image_0000002749333658.png?HW-CC-KV=V1&HW-CC-Date=20260929T121654Z&HW-CC-Expire=31536000000&HW-CC-Sign=86EFD00172636FAE93E35B40F8693801B0F66D3DBEA4FBEDDCF98BA1DB3132E6)
  6. 函数测试无误后，可在"函数代码"页签点击"导出函数"导出函数部署包。导出包以"函数名称+函数版本.zip"格式命名，可查看函数结构和文件内容。
