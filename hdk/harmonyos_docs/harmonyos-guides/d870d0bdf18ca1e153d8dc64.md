# 创建项目

本章以[Caffe SqueezeNet](https://github.com/forresti/SqueezeNet)模型集成为例，说明App集成操作过程。

1. 创建DevEco Studio项目，选择"Native C++"模板，点击"Next"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/3sBz3bZfQii1UbO6WK5BUg/zh-cn_image_0000002755025090.png?HW-CC-KV=V1&HW-CC-Date=20261009T092702Z&HW-CC-Expire=31536000000&HW-CC-Sign=BD51CDC834203C9B97B71E289677B012173C3F38F4F9719F40C831E838DDB248)
2. 按需填写"Project name"、"Save location"和"Module name"，选择"Compile SDK"为"5.1.0(18)"及以上版本，点击"Finish"。
