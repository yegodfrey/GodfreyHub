# 创建项目

本章以[Caffe SqueezeNet](https://github.com/forresti/SqueezeNet)模型集成为例，说明App集成操作过程。

1. 创建DevEco Studio项目，选择"Native C++"模板，点击"Next"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/xIJiON1hRqSPz4vw_NiE6w/zh-cn_image_0000002733275688.png?HW-CC-KV=V1&HW-CC-Date=20260917T084541Z&HW-CC-Expire=31536000000&HW-CC-Sign=4FDFF45FF2BC498EA70DC3C1D7DC461DD69FBD86258056EB4369E412FF848770)
2. 按需填写"Project name"、"Save location"和"Module name"，选择"Compile SDK"为"5.1.0(18)"及以上版本，点击"Finish"。
