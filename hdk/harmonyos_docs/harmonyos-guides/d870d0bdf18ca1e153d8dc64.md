# 创建项目

本章以[Caffe SqueezeNet](https://github.com/forresti/SqueezeNet)模型集成为例，说明App集成操作过程。

1. 创建DevEco Studio项目，选择"Native C++"模板，点击"Next"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/rnxY0fAlR66F8jnbh6rabA/zh-cn_image_0000002749493956.png?HW-CC-KV=V1&HW-CC-Date=20260929T121643Z&HW-CC-Expire=31536000000&HW-CC-Sign=04741455C856123C1CD8FE235CD8F83C0BC6EA66EC6ACE94EDB4E7C2597BCF13)
2. 按需填写"Project name"、"Save location"和"Module name"，选择"Compile SDK"为"5.1.0(18)"及以上版本，点击"Finish"。
