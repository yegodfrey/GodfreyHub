# @version

@version标签用于记录项目的版本。

## 语法

@version <version>

## 示例

使用 @version 标签：

```screen
/**
 * Calculates the square root of a number.
 * @version 1.2.3
 */
export function sqrt(x: number): number {
  return Math.sqrt(x);
}
```
