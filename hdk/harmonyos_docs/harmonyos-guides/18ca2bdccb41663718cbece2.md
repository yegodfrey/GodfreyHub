# 游戏官方账号图标大小是多少

游戏官方账号图标大小总和不超过35KB。若超过35KB，调用[unionLogin](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/gameservice-gameplayer#gameplayerunionlogin)接口时，会出现[1002000001](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-gameservice#section1002000001-游戏内部通用错误)错误码。
