# debug启动调试

可以按照如下方式启动调试会话。

1. 如果需要设置断点调试，找到需要暂停的代码片段，点击该代码行的左侧边线，或将光标置于该行上并按Ctrl + F8（macOS为Command+F8）。如果无法添加断点，请查看FAQ[调试过程中无法添加断点](https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-app-debugging-1)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/9_wpw0KlSPqk8miMRV9KpA/zh-cn_image_0000002701822706.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=70DD45C0998BD0B557B6F687CC42317B9212E84E611C8C7B8217A288AA888BC0)

   设置断点后，调试能够在正确的断点处中断，并高亮显示该行。

2. 在设备选择框中，选择调试的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/CubIBVc_QPuVjoPELCLCMw/zh-cn_image_0000002701662782.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=35DD4284EBC4C7F1A1B96B4BD442CE70F908717340DD0E64A3057AE7629EEF6A)

3. 选择启动调试的配置，在模块选择框中选择需要调试的模块。也可以通过Edit Configurations[配置调试参数](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-debug-configurations)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/r3wfXHaeR4qfvJwx5rNx8g/zh-cn_image_0000002731541975.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1E7FC12197E25086702B98659C1A9DBD7244415CA0FB56DB938705CBD6FDF54)

4. 在工具栏中，单击Debug![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/F1duzmJ8SE6aN57DQvafrw/zh-cn_image_0000002731382003.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=6FFA741CACC9C35E0AB55457FADC324992F5F814A2A15156F61217142E6F1675 "点击放大")。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/gvVM8ScOSrm0XJGlhARlGQ/zh-cn_image_0000002731382007.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=E37305600CAD731D6B0EF824EC384CD74C2DA3B0CB4DA755DAEA3412E3EBBF66)

   或者在工具栏中Run中选择Debug。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/UD-1xVZtSFCHw0jgzIBaEQ/zh-cn_image_0000002731541981.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=30332F0BB20F28331740BEC9FFCC876240D62E1533C9D93C9CB519E715C1A85C)

5. 启动调试后，开发者可以通过[调试器](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-debug-arkts-debugger)进行代码调试。

   如有断点会在断点处高亮，并展示当前断点处的Frames和Variables。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9f/v3/WKFBXiDYRW2I-t_GbpKPLw/zh-cn_image_0000002701822704.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=866D30D063A5F49A72EEC5E040340CEDD3643484B6896B9D48CF40ADE5B5C2C3)
