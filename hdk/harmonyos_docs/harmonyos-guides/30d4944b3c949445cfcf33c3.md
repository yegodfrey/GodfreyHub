# 本地知识库配置

从DevEco Studio 6.0.0 Beta5开始，CodeGenie允许用户导入设计文档和代码等文件形成文档集，多个文档集组合成本地知识库。智能问答时，根据用户输入内容检索本地知识库以提升AI生成的能力。  

#### 操作步骤

1. 点击File \> Settings（macOS为DevEco Studio \> Preferences/Settings） \> CodeGenie \> Knowledge \> Docs，或在DevEco Studio右侧边栏点击CodeGenie（或输入快捷键Alt/Option+U） \> @Add Context \> Docs \> Set Local Knowledge Base，进入配置页面。

   <br />

   ![](https://media:401788752221225036)

   <br />

2. 首次打开时，点击![](https://media:401788752221247037 "点击放大")按钮，填写相关信息，创建文档集。

   <br />

   * Knowledge Base Path：知识库保存路径。在同一个路径下保存的文档集，会形成一个知识库。
   * Document set name：文档集名称。
   * Description：可选，文档集描述。

   ![](https://media:401788752221284038)

   <br />

3. 点击![](https://media:401788752221309039 "点击放大")按钮，添加文档集中的文件，添加成功的文件在下方展示。

   <br />

   ![](https://media:401788752221341040)  
   1. 支持的文件格式：txt、md、json、html、cpp、ets、ts、js。
   2. 单个文档集中文件个数：不超过1000个。
   3. 单个文件大小：不超过10M。
   4. 单个知识库中文档集个数：不超过20个。
   5. 单个知识库大小：不超过50M。

   ![](https://media:401788752221371041)

   <br />

4. 点击"OK"，完成本地知识库配置和同步，在DevEco Studio页面下方Storing document set可查看同步进度。

   <br />

   ![](https://media:401788752221398042 "点击放大")

   <br />

5. 同步完成后，在对话框中输入@符号选择Docs ，或点击上方@Add Context \> Docs ，选择需要的文档集。

   <br />

   ![](https://media:401788752221434043)

   <br />

6. 选择代码文件进行问答，具体请参考[智能问答](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-harmonyos-ask)。
