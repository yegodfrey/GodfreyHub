# 自定义界面扫码黑屏现象

**问题现象**

自定义界面扫码启动相机却显示黑屏现象。

**解决措施**

* 权限校验错误码：201，没有申请相机权限，[向用户申请授权](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/request-user-authorization)。

* 参考ArkTS API错误码[1000500001](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-scan#section1000500001-内部错误)：如首次未调用[init](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/scan-customscan-api#init)初始化，直接调用[start](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/scan-customscan-api#start)启动扫码相机流，请参考自定义界面扫码的[业务流程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/scan-customscan#业务流程)。
