# 解析应用minidump/coredump文件

从26.0.0版本开始，DevEco Studio支持对应用minidump/coredump文件进行解析，展示堆栈信息，帮助开发者快速定位问题。

## 获取dump文件

* minidump文件：获取方式请参考[OH_HiAppEvent_SetEventConfig接口说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hiappevent-watcher-crash-events#oh_hiappevent_seteventconfig接口说明)。
* coredump文件
  1. 应用需要在module.json5中配置[ohos.permission.ALLOW_COREDUMP权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all#ohospermissionallow_coredump)，配置方式请参考[声明权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/declare-permissions)。
  2. 在2in1设备的任务管理器中右键应用进程，选择**创建转储文件** 。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e2/v3/SD3QEZAeT1ibH9FS_NRmKg/zh-cn_image_0000002701823714.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=A6FFF5337EED83A2A76C714C2650E1E618B9F8B11A4236EDF7174CAA36748598)

  3. 创建成功后，会提示coredump文件的保存位置。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/Rv_kFWCPQvmaSQrBw2GByQ/zh-cn_image_0000002701823712.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=9EAF0D2528D5018D875C37BCDDE33F2672DD6FAC00839CE2C617EAAD2CB05F01)

## 解析dump文件

1. 打开DevEco Studio的**Log** 窗口，点击**AnalyzeDump** 页签打开界面，选择要解析的dump文件和带调试信息的so目录（默认是模块下的build/{product}/intermediates/libs/{target}/{abi}，其中product和target默认是default，{abi}是设备CPU架构类型，如arm64-v8a），点击**Start Analyze** 开始解析。 说明
   >
   > 应用产生的dump，需要借助同一次构建生成的so文件中的符号信息才能解析。若使用源码变更后重新构建生成的so目录，可能会因符号不一致导致解析结果不准确或解析失败。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/eO1ae9MNQRqhXofj1Ma6ZQ/zh-cn_image_0000002731542983.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=563E5AF76BBA2540FB04C8DA8626B3C43272A1E6D1A3A4AB8F6084F8EA5E7969)
2. 等待解析成功后，默认会展示异常线程和对应的堆栈，展开堆栈可查看变量信息，支持切换查看不同线程的堆栈，点击堆栈中的超链接可以跳转到对应的源码。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/zQF7QXy-R0icRUuPBrQZHQ/zh-cn_image_0000002731542987.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=88A68C7D0D6C8D0DD3D62CE96294B536D00D9444F3B6D722D2A1459ED2EA8B80)

3. 支持查看指定地址的内存，填写内存地址，点击**View** 即可查看。也可以直接右键点击变量查看内存。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c/v3/JI4WXzd7QbimSXH0XJsdaQ/zh-cn_image_0000002731383011.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=C417BBD565E61984785D9EF55D931780C5B1355F96E74FB4D8746333EF3A362B)

   点击**Settings**，可设置进制、偏移量和展示的内存字节数量。
