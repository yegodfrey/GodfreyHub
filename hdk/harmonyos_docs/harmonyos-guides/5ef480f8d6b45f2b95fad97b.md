# 解析应用minidump/coredump文件

从26.0.0版本开始，DevEco Studio支持对应用minidump/coredump文件进行解析，展示堆栈信息，帮助开发者快速定位问题。

## 获取dump文件

* minidump文件：获取方式请参考[OH_HiAppEvent_SetEventConfig接口说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hiappevent-watcher-crash-events#oh_hiappevent_seteventconfig接口说明)。
* coredump文件
  1. 应用需要在module.json5中配置[ohos.permission.ALLOW_COREDUMP权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all#ohospermissionallow_coredump)，配置方式请参考[声明权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/declare-permissions)。
  2. 在2in1设备的任务管理器中右键应用进程，选择**创建转储文件** 。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/ChGzH-FKQpCGPkUsT-kjuA/zh-cn_image_0000002701823714.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=849D2DF7EA34F6193CEA7BF75FFD2714219557A20FAE876CDF01A4C292D57F6C)

  3. 创建成功后，会提示coredump文件的保存位置。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/07/v3/U31i_0pZTwK_0cBnSWIJvQ/zh-cn_image_0000002701823712.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=F27F0418E23CDACBA1F43AAB9DB3F63F041CB3649209C6E0FB56CE9AAD092A36)

## 解析dump文件

1. 打开DevEco Studio的**Log** 窗口，点击**AnalyzeDump** 页签打开界面，选择要解析的dump文件和带调试信息的so目录（默认是模块下的build/{product}/intermediates/libs/{target}/{abi}，其中product和target默认是default，{abi}是设备CPU架构类型，如arm64-v8a），点击**Start Analyze** 开始解析。 说明
   >
   > 应用产生的dump，需要借助同一次构建生成的so文件中的符号信息才能解析。若使用源码变更后重新构建生成的so目录，可能会因符号不一致导致解析结果不准确或解析失败。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/Jgg7ulWER-KjuTh_tII0mA/zh-cn_image_0000002731542983.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=3696E25F8005A5D061E3061C220BE2DD820EE6806BDCBAC2A25CD85A3D9B06D2)
2. 等待解析成功后，默认会展示异常线程和对应的堆栈，展开堆栈可查看变量信息，支持切换查看不同线程的堆栈，点击堆栈中的超链接可以跳转到对应的源码。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/FYamaRBfSJqhrAgguLsSzA/zh-cn_image_0000002731542987.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=6070D539F8E2D412DF298E13C7B6CE57DA49E30E394E8EFC25D6D1F61E8D0282)

3. 支持查看指定地址的内存，填写内存地址，点击**View** 即可查看。也可以直接右键点击变量查看内存。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/upcDYcOSR0OLUY-D38dZ5Q/zh-cn_image_0000002731383011.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=A719572AD40320EEBB2FB528886D86021B3CE18BAD75A228F21A3BC9A3FA46BF)

   点击**Settings**，可设置进制、偏移量和展示的内存字节数量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/L1IGJWTcRI6S2p7M7jlqmg/zh-cn_image_0000002701663790.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=8024DC81987C4FE6CCA442D432F0EB81EA275EB35407979F3B6E4652DB610587)
