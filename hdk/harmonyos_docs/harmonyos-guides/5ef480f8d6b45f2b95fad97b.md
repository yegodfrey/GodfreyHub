# 解析应用minidump/coredump文件

从26.0.0版本开始，DevEco Studio支持对应用minidump/coredump文件进行解析，展示堆栈信息，帮助开发者快速定位问题。

## 获取dump文件

* minidump文件：获取方式请参考[OH_HiAppEvent_SetEventConfig接口说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hiappevent-watcher-crash-events#oh_hiappevent_seteventconfig接口说明)。
* coredump文件
  1. 应用需要在module.json5中配置[ohos.permission.ALLOW_COREDUMP权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/permissions-for-all#ohospermissionallow_coredump)，配置方式请参考[声明权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/declare-permissions)。
  2. 在2in1设备的任务管理器中右键应用进程，选择**创建转储文件** 。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b/v3/kVQcOYxuSQmdX6xX0fRlsw/zh-cn_image_0000002701823714.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=C99F17DAABB8F3B82D88F3A491664388AF72EA6808652C1DFAEB5C6A3FE6E60B)

  3. 创建成功后，会提示coredump文件的保存位置。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/Xh5PECz7S9WEhZDhJDxbSg/zh-cn_image_0000002701823712.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=49BE61FAAF3C6B29D077824F0752B1781EB487C185D932E1B005DB9393985107)

## 解析dump文件

1. 打开DevEco Studio的**Log** 窗口，点击**AnalyzeDump** 页签打开界面，选择要解析的dump文件和带调试信息的so目录（默认是模块下的build/{product}/intermediates/libs/{target}/{abi}，其中product和target默认是default，{abi}是设备CPU架构类型，如arm64-v8a），点击**Start Analyze** 开始解析。 说明
   >
   > 应用产生的dump，需要借助同一次构建生成的so文件中的符号信息才能解析。若使用源码变更后重新构建生成的so目录，可能会因符号不一致导致解析结果不准确或解析失败。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/19mTefWnRCCpimzSccidtQ/zh-cn_image_0000002731542983.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=E67B71658E637FF22A1187CB5FD45FD74EF48FB26C6625B0BB3D81F167C8DABE)
2. 等待解析成功后，默认会展示异常线程和对应的堆栈，展开堆栈可查看变量信息，支持切换查看不同线程的堆栈，点击堆栈中的超链接可以跳转到对应的源码。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/SVUT7rdQSAycO8hYvsaGfQ/zh-cn_image_0000002731542987.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=71821CA7A099D94793296B1F2D4F392FF5CA23381B2131308570675C2AD1197E)

3. 支持查看指定地址的内存，填写内存地址，点击**View** 即可查看。也可以直接右键点击变量查看内存。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/9LUfEvRSSeKmwrMvt0zYKg/zh-cn_image_0000002731383011.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=BC3FA0D9EA38CFB6C9045D2B62EB6BC0D50F1E3A5CAC939C7A4C385994465E3D)

   点击**Settings**，可设置进制、偏移量和展示的内存字节数量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2/v3/251IvhxFQK2xAzcxEsvq7g/zh-cn_image_0000002701663790.png?HW-CC-KV=V1&HW-CC-Date=20260915T011703Z&HW-CC-Expire=31536000000&HW-CC-Sign=CB8570A1C628927DA79D1F0C8CCFD94CA569DFAC89C6BECE517BA92C8A169C1D)
