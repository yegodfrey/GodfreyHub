# 使用调试器

Debug界面有三个tab页，分别是"entry"、"entry(PandaDebugger)"和"entry(Native)"。

通常第一个tab页"entry"用于展示推包安装过程。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/2qiKE9kyT3a--g2U8ew9yg/zh-cn_image_0000002731543079.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=B3BF6DB51BE19F76BBF67684D2D6D24FF62E5567E9AEC6D81965CE64C3BCA7B5)

第二个tab页"entry(PandaDebugger)"和第三个tab页"entry(Native)"是调试器，用于调试Debugger功能，其中"entry(Native)"仅在涉及Native调试时才会拉起。调试器包含两个窗格，**[Debugger](#section1437520119316)** 和**[Console](#section327153017314)**。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/CM8uiZVXQu6_9-Hct4XQmg/zh-cn_image_0000002731383113.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=BFE7DE59F57DC70941CF67A60239A703CDA0CC9E27F1CB1BD782A6C172CE2A0F)

## Debugger窗格

Debugger显示两个独立的窗格：

* 左侧区域是Frames，当应用调试到某个断点时，Frames区会显示当前代码所引用的代码位置。
* 右侧区域是Variables，用于展示当前变量。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/qhq4_XJySf--BU1ggZUUJw/zh-cn_image_0000002731543025.png?HW-CC-KV=V1&HW-CC-Date=20261010T073010Z&HW-CC-Expire=31536000000&HW-CC-Sign=18EAB0395CE7AA8386A49F740AA74A485AE87726CA5D2A4475DD6AD2AFE8C788)

### Resume Program
