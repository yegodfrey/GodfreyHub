# 开发准备

#### 申请callerId

开发者将应用包名和appId发送至[HWwallet@huawei.com](mailto:HWwallet@huawei.com)邮箱，钱包会配置callerId并回复给开发者。

开发者需使用该callerId作为交通卡接口调用的入参。
