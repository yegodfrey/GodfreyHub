# 更新会员卡

当会员卡信息发生变更时，如会员信息修改、权益发生变更等，更新钱包中的会员卡数据。

## 服务端开发

开发者服务器通知钱包服务端进行[会员卡数据更新](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/wallet-rest-api-member#会员卡数据更新)，钱包服务端给钱包推送更新通知。
