# 等待调试

开发者可以通过将某个应用设置为"等待调试模式"，需要调试时拉起应用，即可快速进入调试状态。
> 说明
>
> * 应用设置为"等待调试模式"后，此时如果启动debug调试，将会取消当前的等待调试模式。
> * 设置"等待调试模式"前，需要将应用安装到设备上。

## 操作步骤

1. 在设备选择框中选择调试的设备，并点击**Run > Attach to Process by Name**。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/N83SSoBXSP6nkuErYsUvJQ/zh-cn_image_0000002701663814.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=71B3947754C5AFB94B3D4BDB7206B0480DE07E461CA12C59D233D3245BB34A6C)

2. 选择需要设置为"等待调试模式"的应用（默认为当前工程），选择调试类型，点击**Attach**，即可将该应用设置为"等待调试模式"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/BMGjQ9vZQmaRcsShMw1Avw/zh-cn_image_0000002701823736.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=9E6499AC30897C8ED9A1D0EF3A89D3FF817C526AA18ADD76689169D0171FBC94)

   此时DevEco Studio底部会显示一个等待进度条，在应用被拉起之前，一直处于等待状态。可通过进度条右侧的取消按钮进行取消。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/qysIJqG2S7WXVhtXiBzrig/zh-cn_image_0000002701663812.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=9EFAA379C2AD194D1EB9A2A42C6F4C1F4F6CDFD8ABEFAB714CC634CBAE5ABC15)

3. 拉起设备端应用，此时将会进入调试。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/T0qyE7HGTMaa_cGsBuXPmw/zh-cn_image_0000002731543013.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=224A9F4C64FEC226BEBCD988AFE037B68EBB463D38C183E2FBE7ADD1ED89CF67)
