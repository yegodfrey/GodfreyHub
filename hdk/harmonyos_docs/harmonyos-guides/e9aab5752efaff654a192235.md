# 智能步入

进行C++调试时，当前代码行有多个函数调用时，开发者可以使用Smart Step Into功能![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/QAUJi392RlyjQJxCdDfcZw/zh-cn_image_0000002731541867.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=37D5DA165DDB325BB91A87A2EBA3A573CAC2F7B01594BC2C32E8147CDFE27D17)直接Step Into到其中某一个函数的实现中。

## 操作步骤

通过点击调试窗口"entry-Native"调试器下的Debugger窗格中的按钮![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/VM3m90frTiago_V5ikxRxw/zh-cn_image_0000002731381895.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=2CFC67B8C2045D9FFD359474A13236AE30B43EED9DBD53EC5440A3834F040A3D)（或使用快捷键**Shift+F7**）触发Smart Step Into功能后，DevEco Studio会将当前代码中可以进行跳转的函数进行高亮显示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/msPHXX2MTxeOWhWPSxjLGw/zh-cn_image_0000002701662676.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=D1CBA5ABA51B2FEBAF80CE9174B34603E0AD3E5472A1B09C777D3F8CADE47676 "点击放大")

开发者点击需要跳转的函数，程序会运行到目标函数的实现内。
> 说明
>
> 已经执行完毕的函数不会高亮显示。
