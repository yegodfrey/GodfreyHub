# 滑动过程流畅

## 规则详情

应用的滑动过程卡顿率≤5ms/s；满帧30FPS的游戏类、地图类和视频类的应用帧率应≥ 29FPS。

## 检测逻辑

* 开始时间：以APP_LIST_FLING滑动泳道为例，泳道的起点（如图标记1）。
* 结束时间：以APP_LIST_FLING滑动泳道为例，泳道的终点（如图标记2）。 其他滑动泳道标记如下：

  H:APP_SWIPER_SCROLL

  H:WEB_LIST_FLING

* 查找滑动泳道：H:APP_LIST_FLING，如果是web页面，找H:WEB_LIST_FLING。
* 刷新率：查找关键词H:RSHardwareThread::CommitAndReleaseLayers rate，如下图： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/hyy-8fT7SCuvA2f1uWm41g/zh-cn_image_0000002731541815.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4F6EC627D625AF6BAD951769E96C58CB1A2BA73FD018694DDE9ADCAD3FBE9CF)

* 每帧标准时长(ms)：1000ms/刷新率。 总时长(s)：在以上泳道时间范围内，总时长 =【最后一个"H:Waiting for Present Fence xxxx" 时间（如图标记2）】 - 【第一个"H:Waiting for Present Fence xxxx" 时间（如图标记1）】。

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/U8_0bpflTQqPVzB26oQ4ZQ/zh-cn_image_0000002701822536.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC8040ADCD1BB2B9F2135DED140E7B68FE90D18072A0762C04570567DCABD393)
* 实际每帧时长：【下一个H:Waiting for Present Fence xxxx的起始时间（如图标记2）】 - 【当前H:Waiting for Present Fence xxxx的起始时间（如图标记1）】。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/iv0HIcHxT_q3jJMxDxEaIQ/zh-cn_image_0000002731541805.png?HW-CC-KV=V1&HW-CC-Date=20261010T073011Z&HW-CC-Expire=31536000000&HW-CC-Sign=005560CACF49277E829550AEE61ED5E2B81F5258D7428B1DD64AC33718DF25C0)

  每帧丢帧时间(ms)：max（【Waiting for Present Fence实际时长(ms)】- 【每帧时长(ms)】 * 1.5 , 0）；即每帧耗时大于标准耗时1.5倍时则判定为丢帧。

## 计算逻辑

卡顿率(即流畅度) = 【每帧丢帧时间累计总和(ms)】/ 总时长(s)，须小于等于5ms/s。
