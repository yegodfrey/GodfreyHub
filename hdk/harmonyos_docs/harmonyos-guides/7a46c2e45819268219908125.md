# Profile Manager

由于真机设备型号众多，不同设备型号的屏幕分辨率可能各不相同。因此，在HarmonyOS应用/元服务开发过程中，为了适配多种设备型号，可能需要查看不同设备上的界面显示效果。对此，DevEco Studio的预览器提供了Profile Manager功能，支持开发者自定义预览设备Profile（包含分辨率和语言），从而可以通过定义不同的预览设备Profile，查看HarmonyOS应用/元服务在不同设备上的预览显示效果。当前支持自定义设备分辨率及系统语言。

定义设备后，可以在Previewer右上角，单击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/ZvWfGOi4RsKLCs8z182uFg/zh-cn_image_0000002701662616.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=1D9F4C3B7EF34FD118E0E586B1B3CFFB7C936536AB2D41E8EA54A1CB10401E38 "点击放大")按钮，打开Profile管理器，切换预览设备。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/6v5HnZT1SYeyeScm9lpPiQ/zh-cn_image_0000002731381839.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=31751E8027D864A88E20EAC485398B9E41B0C9B1218EABDADED8A00C110EC1F1 "点击放大")

同时，Profile Manager还支持多设备预览功能，具体请参考[查看多端设备预览效果](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-previewer-multi-profile)。

下面以自定义一款Phone设备为例，介绍设备Profile Manager的使用方法。

1. 在预览器界面，打开Profile Manager界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/uEUiKfBERvi6FzJDnx7xow/zh-cn_image_0000002701822534.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F0A213BF723A5C90E6022107AD61C6B6DBDF8B27CEBDAFF18D1E46E7E8B53D3)

2. 在Profile Manager界面，单击**+ New Profile**按钮，添加设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/db/v3/iMJ82Xu-RsWyrbUSlXKgEw/zh-cn_image_0000002701662612.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=121791162582282DF17A39F0BF8C0938FD1FA3DEBAB1C492551A4EBFC22AE8CD)

3. 在**Create Profile** 界面，填写新增设备的信息，如**Profile ID** （设备型号）、**Device type** （设备类型）、**Resolution** （分辨率）和**Language and region**（语言和区域）等。其中Device type只能选择module.json5中deviceTypes字段已定义的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/Eo9GEeWZSDu3ULwQPYgZtg/zh-cn_image_0000002731381835.png?HW-CC-KV=V1&HW-CC-Date=20260928T063033Z&HW-CC-Expire=31536000000&HW-CC-Sign=9B59CA114104B0A203B1F5D36B1CB70AD507B72B1981E8AD7C7ED524A960D57E)

4. 设备信息填写完成后，单击**OK**完成创建。
