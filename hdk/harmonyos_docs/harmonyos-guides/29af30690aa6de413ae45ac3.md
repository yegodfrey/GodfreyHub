# 使用云存储上传文件失败，app日志提示""state":65"，upload进程日志提示"403 Forbidden"

**问题现象**

使用云存储上传文件失败，出现如下错误提示：

* app日志提示""state":65"

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/mciyc3FxQcGtK2ol3yaNpA/zh-cn_image_0000002755184590.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=3F2BE5959922FFC852852FD73D42FC5474BA958A3E1FB99C82B9D8DE9BD73B4D)
* upload进程的日志提示"403 Forbidden"（通过设置"No filters"模式、过滤"C01C50"关键字查找）

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b/v3/EmBWhoCJRvC-oJv4-OHgiA/zh-cn_image_0000002784583457.png?HW-CC-KV=V1&HW-CC-Date=20261009T092712Z&HW-CC-Expire=31536000000&HW-CC-Sign=4CEF1C70B79CD7AF7FAE38BF6C980112FD90EA4AB3F2A49C3222408F48AD392A)

**解决措施**

出现此问题，可按照如下步骤排查和解决：

1. 请确认应用的签名方式正确。当前Cloud Foundation Kit支持[关联注册应用进行自动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-auto#section6333421192714)和[手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing-manual)两种方式。

2. 请确认已通过[AuthProvider](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/cloudfoundation-cloudcommon#authprovider)获取用户凭据。未配置用户凭据的情况下，服务端会返回"403 Forbidden"错误。
