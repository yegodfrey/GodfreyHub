# 仓颉语言与ArkUI框架的关系

#### 仓颉语言和ArkUI框架的架构关系

在HarmonyOS应用开发生态中，仓颉与ArkUI框架之间是应用编程语言与UI框架的关系：

  * 仓颉作为HarmonyOS应用开发语言，是一款静态类型、静态编译的编程语言。仓颉语言通过现代语言特性的集成、全方位的编译优化和运行时实现、以及开箱即用的DevEco Studio工具链支持，为HarmonyOS应用开发者打造友好开发体验和卓越程序性能。
  * ArkUI是一套构建分布式应用界面的声明式UI开发框架。它使用简洁的UI信息语法、丰富的UI组件、以及实时界面预览工具，帮助开发者提升HarmonyOS应用界面开发效率。



仓颉实现的ArkUI框架与ArkTS实现的ArkUI框架，在功能以及规格上基本保持一致，为开发者带来一致的开发体验，降低开发者的学习以及切换成本。

#### 仓颉语言如何实现ArkUI的声明式开发范式

声明式UI是一种面向UI编程的开发范式，仓颉语言基于自身的语法扩展能力以及元编程能力，实现了ArkUI的声明式开发范式，详情请参见[《仓颉编程语言白皮书》](https://developer.huawei.com/consumer/cn/doc/cangjie-guides-V5/cj-wp-declarative-V5)。
