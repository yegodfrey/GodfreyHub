# ArkTS与仓颉混合开发应用时，如何在DevEco Studio中调试仓颉代码

调试混合工程时，需要首先将Debug type设置为Dual(ArkTS/JS + Cangjie)，然后在仓颉代码中设置断点开始调试即可。

设置Debug type的方法和启动调试的具体步骤见图示：

点击DevEco Studio上方菜单栏Run > Edit Configurations...
