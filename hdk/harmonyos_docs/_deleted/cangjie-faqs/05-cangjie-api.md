# HarmonyOS API有多少API提供了仓颉语言版本

在HarmonyOS 6.0.2中，有超过8000个HarmonyOS API开放了仓颉语言版本，满足开发者开发应用的基本需求。详情请参见[API参考](https://developer.huawei.com/consumer/cn/doc/cangjie-references/cj-development-intro)。

未来会有更多HarmonyOS API开放仓颉语言版本，敬请期待。
