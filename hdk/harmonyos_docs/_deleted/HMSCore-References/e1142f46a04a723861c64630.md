# Overview

集成ads-identifier SDK后，可使用相关API，获取OAID和"限制广告跟踪"开关。  

#### Class Summary

|Class|Description|
|:------------------------------------------------------------------------------------------------------------------------------------|:--------------------------|
|[AdvertisingIdClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/advertisingidclient-0000001050066889)|获取AdvertisingIdClient.Info。|
|[AdvertisingIdClient.Info](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/advertisingidclient-info-0000001050064942)|获取OAID和"限制广告跟踪"开关。|

#### Exception Summary

|Exception|Description|
|:--------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------|
|[AdIdVerifyException](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adidverifyexception-0000001184085596)|接口调用失败抛出AdIdVerifyException，通过getMessage可以获取异常信息描述。|
