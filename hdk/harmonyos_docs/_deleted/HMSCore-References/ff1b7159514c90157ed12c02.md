# 公共说明

接口协议：HTTPS

响应协议接口数据格式：JSON

协议接口数据字符编码：UTF-8

* 接口支持get、post、delete，查询类操作使用get，修改类操作为post、delete
* 编码：utf-8
* Post Content Type：application/json
* Get Content Type：application/x-www-form-urlencoded
* 认证信息基于请求Header指定，具体为：
  * 应用级AT：Authorization: Basic Base64(APPAT:atvalue) - 例如，发送请求的应用级AT为：thisIsAppAtValue

    - APPAT:atvalue则为：APPAT:thisIsAppAtValue

    - Base64(APPAT:atvalue)则计算方式为Base64("APPAT:thisIsAppAtValue")，值为：QVBQQVQ6dGhpc0lzQXBwQXRWYWx1ZQ==

    - 最终请求头Authorization的值为：Basic QVBQQVQ6dGhpc0lzQXBwQXRWYWx1ZQ==
  * 无认证信息：没有对应的Header
* 语言信息基于请求Header中Accept-Language指定，取值为标准的Locale

#### （可选）签名算法

如果您想增强服务端的安全能力，可使用IAP提供的安全能力，在相关接口中传入SHA256WithRSA/PSS签名算法。建议您使用SHA256WithRSA/PSS签名算法。

使用方式如下：

* 请求：请求头中指定HW-IAP-APPINFO为{"signatureAlgorithm":"SHA256WithRSA/PSS"}；
* 响应：如果响应体中包含signatureAlgorithm字段，须使用该签名算法（与签名同级）进行验签。

#### 站点选择

您需要在四个站点信息中选择一个（中国、德国、新加坡和俄罗斯），关于这四个站点的选择，有以下两点建议：

1. 建议您根据您的服务器部署所在地就近选择站点以便更快获取订单信息，例如： 如果您的服务器在中国大陆，建议您优先访问中国站点域名。

   如果您的服务器在亚洲、非洲或者拉丁美洲，建议您优先访问新加坡站点域名。

   如果您的服务器在俄罗斯，建议您优先访问俄罗斯站点域名。

   如果您的服务器在欧洲和北美洲，建议您优先访问德国站点域名。
2. 本质上选择任一站点都可以，华为服务器会进行站点间路由，请确保请求以application/json进行发送。  

#### 证书校验

如果服务端的证书未经验证或被篡改，客户端连接到的服务端可能不是预期的服务端，会导致中间人攻击、数据泄漏等安全问题。为保障连接安全，您的服务器在访问华为IAP服务器时，必须验证华为IAP服务器提供的证书。

验证包含两部分，首先是验证华为IAP服务器提供证书是否来自值得信任的来源，然后验证华为IAP服务器是否提供正确的证书。
