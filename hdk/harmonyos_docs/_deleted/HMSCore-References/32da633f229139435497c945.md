# 数据模型

#### ActivityRecord

|参数|参数类型|是否必选|说明|约束条件|
|:--------------|:--------------------------------------------------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------|
|appInfo|[AppInfo](#section982495714175)|是|创建该运动记录的AppInfo。|-|
|id|String|是|客户端生成的标识符。 特定用户拥有的所有运动记录中都是唯一的。|如果未指定标识符，将从开始时间和名称中创建一个。|
|modifyTime|Long|是|运动记录的最后修改时间。单位：毫秒|-|
|name|String|是|用户设定的运动记录名称。例如："周日骑行"|-|
|startTime|Long|是|运动记录开始时间(inclusive)。单位：毫秒|-|
|endTime|Long|是|运动记录结束时间。单位：毫秒 如果未指定标识该运动记录仍在进行中。|结束时间必须晚于开始时间。|
|timeZone|String|是|时区信息。|格式：+0800。|
|activeTime|Long|否|运动记录活跃时间。单位：毫秒|开始/结束时间标识了运动记录的完整持续时间；但运动记录活跃时间可以更短。|
|activitySummary|[ActivitySummary](#section1653018251396)|是|运动记录的概要汇总信息。|请参见数据模型。|
|activityType|Integer|是|运动记录对应的活动的类型 。支持的运动类型请参见[运动类型常量定义](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-fitness-record-data-0000001131831088#section18780175925413)。|-|
|deviceInfo|[DeviceInfo](#section135613218188)|否|集成各种传感器的硬件设备描述。例如：手表、手环等可穿戴设备。|-|
|cursor|String|否|查询分页标识。当查询结果大于一页时才包含。|-|
|desc|String|否|运动记录描述。|-|
|subDataRelation|List\<[SamplePointRelation](#section187077701614)\>|否|子数据关联关系。|-|
|details|List\<[SampleSet](#section13805555304)\>|否|运动记录明细。|-|
|metadata|String|否|扩展元，JSON格式字符串。|-|
|sourceType|Integer|否|数据来源类型 0：unknown（默认） 1：真实运动 2：用户手动输入 3：课程记录 4：可连接器械 5：自动识别|-|
|abnormal|Integer|否|异常运动记录标记位 0：不是 1：是|重要数据缺失、运动作弊等场景下，运动记录会被标记为异常运动记录。|
|duplicate|Integer|否|重复运动记录标记位 0：不是 1：是|同一时间段存在两条运动记录的场景下，其中一条会被标记为重复运动记录。|

#### PaceSummary

|参数|参数类型|是否必选|说明|约束条件|
|:----------|:-------------------|:---|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|avgPace|Double|是|平均配速。|单位是秒/公里。 说明： 运动类型划船机的单位是秒/500米。|
|bestPace|Double|是|最佳配速。|单位是秒/公里。 说明： 运动类型划船机的单位是秒/500米。|
|paceMap|Map\<String,Double\>|否|每公里配速表。|每公里的配速，单位是秒/公里。例如 "1.0":407.945 "2.0":473.98846 "2.170":473.98846 说明： 最后不满一公里的部分，按比例换算为整公里的配速存入。|
|partTimeMap|Map\<String,Double\>|否|分段累计时间表。|公制分段数据表（key：公里，value：秒） 其中公里保留到小数点后4位。 Value是一个累积到当前公里的时间如： * 1.0:3.0 * 2.0:6.0 <!-- --> * 3.0:9.0 * 21.0975:7020.0 <!-- --> * 42.195:18000.0 其中，21.0975，42.195分别为半马和全马的距离（仅半马全马小数点后不为0）。|
