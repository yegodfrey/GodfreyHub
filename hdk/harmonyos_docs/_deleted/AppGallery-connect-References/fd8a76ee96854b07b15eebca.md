# 版本状态码

|版本状态|状态说明|
|:--------------------|:-----|
|CREATING|创建中|
|CREATED|已创建|
|MERGING|归档中|
|FINALIZED|已归档|
|CREATE_VERSION_FAILED|创建版本失败|
|VERSION_PACKAGE_ERROR|版本包错误|
|DELETING|删除中|
|DELETED|已删除|
