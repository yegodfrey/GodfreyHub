# StorageManagement

|Interface Info|
|:----------------------------------------------------------|
|export interface StorageManagement 为浏览器客户端提供支持上传下载文件功能的管理类。|

#### Property Summary

|Name|Type|Description|
|:----------------|:-----|:-------------------|
|maxRequestTimeout|number|最大的请求超时时间，单位：秒。|
|maxUploadTimeout|number|上传文件请求的最大的超时时间，单位：秒。|
|maxRetryTimes|number|失败请求的最多重试次数。|
