# Transaction

|class info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.agconnect.cloud.database.Transaction Transaction类用来描述一个事务，事务内提供executeQuery()、executeUpsert()和executeDelete()方法，实现对云侧存储区数据的管理操作，包含数据的增、删、改、查等。 * 事务仅在联网的情况下进行，一旦离线该事务操作将失败。 * 一个事务内可以进行多次数据操作，查询操作必须在写入操作和删除操作之前进行。 * 一个事务中包含的写入和删除对象的总条数不能超过1000条，且一个事务内的多次写入操作和删除操作的数据总大小不能超过2MB。 * 一个事务中多次查询结果的总数据大小不能超过5MB，多次查询结果的总数据条数不能超过1000条。|

#### Public Methods

#### executeQuery

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public \<T extends CloudDBZoneObject\> List\<T\> executeQuery(CloudDBZoneQuery\<T\> cloudDBZoneQuery) throws AGConnectCloudDBException 调用此方法在事务中从云侧存储区查询获取满足特定条件的对象集合。事务是原子的，事务内的操作要么全部成功，要么全部失败。 调用本方法需要遵循以下约束： * 仅在正常连接网络时可调用该方法实现查询功能，一旦离线该操作将失败。 * 事务中的查询操作必须在写入操作之前，否则将导致事务执行异常。 * 仅在CloudDBZone的同步属性为缓存模式时，支持相关事务操作。 * 一个事务中多次查询结果的总数据大小不能超过5MB，否则会导致事务失败。 * 一个事务中多次查询结果的总数据条数不能超过1000条，否则会导致事务失败。|

#### executeDelete

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public Transaction executeDelete(List\<? extends CloudDBZoneObject\> objectList) 调用此方法在事务中批量删除云侧存储区中的一组对象。事务是原子的，事务内的操作要么全部成功，要么全部失败。删除操作只关注对象的主键是否一致，不考虑对象其它属性和存储的数据是否匹配。 调用本方法需要遵循以下约束： * 仅在正常连接网络时可调用该方法实现删除功能，一旦离线该操作将失败。 * 仅在CloudDBZone的数据同步属性为缓存模式时，支持相关事务操作。 * 一个事务内的多次写入和删除操作的数据总大小不能超过2MB，否则会导致事务失败。|
