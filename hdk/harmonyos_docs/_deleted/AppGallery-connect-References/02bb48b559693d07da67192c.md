# Overview

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------|
|[AGCStorageMetadata](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragemetadata-0000001172821637)|文件的元数据，不支持目录的元数据的相关操作。|
|[AGCStorage](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorage-0000001172981557)|为App提供支持上传下载文件功能的管理类。|
|[AGCStorageReference](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragereference-0000001126781968)|云端文件的引用，提供对象的列举、上传、下载、删除、元数据更新等各项操作的封装。|
|[AGCStorageTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragetask-0000001126941788)|任务的管理，提供存储任务的各种状态操作的封装。|
|[AGCStorageDownloadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragedownloadtask-0000001172821639)|下载任务。|
|[AGCStorageDownloadResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragedownloadresult-0000001172981559)|下载任务的结果信息。|
|[AGCStorageUploadTask](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorageuploadtask-0000001126781970)|上传任务。|
|[AGCStorageUploadResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstorageuploadresult-0000001126941790)|上传任务的结果信息。|
|[AGCStorageListResult](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcstoragelistresult-0000001172821641)|包含文件和子目录信息的列表。|
