# 批量上线商品促销活动

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180216.89109656164744197490766933671186:50001231000000:2800:01FECE4E1D9FBF2BADE68B7AB3C57F3F3DDAC8613B9E810EC451EDFA713AF50E.png)  
如果您前期已使用该接口为您的HarmonyOS 5.0及以上应用接入商品管理，请尽快切换至[HarmonyOS 5.0及以上 V2版本接口](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchactpromotion-harmonyosnext-0000002131508860)。  

#### 功能介绍

此接口用于批量上线商品促销活动。  

#### 使用约束

接口调用者的角色：账号持有者、管理员、APP管理员、运营。  

#### 接口原型

|承载协议|HTTPS PUT|
|接口方向|开发者服务器-\>数字商品服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/pms/product-price-service/v1/manage/product/promotion/batchActive|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|----------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Header

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806180216.93886296492756514469968555508647:50001231000000:2800:E46D8C9B0A135FEF2756AEE9E4BB4570BBE813341A112ABD310A718598DE7355.png)  
API Client和OAuth Client区别参见[使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)。

API Client方式  

|参数|必选(M)/可选(O)|类型|描述|
|:------------|:----------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String(header)|客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String(header)|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|
|appId|M|String(header)|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

OAuth Client方式  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|oauth2Token|M|String|认证信息，传入[获取用户授权码](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section949717114392)中获取的Access Token。|
|appId|M|String|应用ID，获取方法参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/appgallery_queryappinfo)。|

#### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------|:----------|:-------------|:------------------------------------|
|requestId|M|String(64)|请求序列，开发者自定义唯一标识符。|
|promotions|M|List\<String\>|商品促销ID列表，促销ID长度最大32字符，列表中不超过100个促销ID。|

#### 调用示例

```
"Java"
public static PromotionActiveResp batchActive(String domain, String clientId, String authorization, String appId,
    PromotionActiveReq req) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product/promotion/batchActive";
    HttpPut put = new HttpPut(url);
    setHttpHead(clientId, authorization, appId, put);
    StringEntity entity = new StringEntity(JSON.toJSONString(req), ContentType.create("application/json", "UTF-8"));
    put.setEntity(entity);
    String result = getApiResp(put);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, PromotionActiveResp.class);
    }
    return null;
}
```
