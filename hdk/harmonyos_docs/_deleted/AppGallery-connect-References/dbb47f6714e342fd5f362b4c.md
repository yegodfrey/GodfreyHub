# CloudDBZoneObjectList

|class info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.agconnect.cloud.database.CloudDBZoneObjectList CloudDBZoneObjectList类描述了一种存储CloudDBZoneObject的列表，支持get()、next()、size()和hasNext()等基础的列表操作方法。此列表依赖其所在的CloudDBZoneSnapshot对象，当CloudDBZoneSnapshot对象释放后，列表也将自动释放，且无法再访问列表中的数据。|

#### Public Method Summary

|Return type|Method name|
|:----------|:--------------------------------------------------------------------------------------------------------|
|int|[size](#section866017382011)() 获取CloudDBZoneObjectList对象所包含的对象个数。|
|E|[get](#section92368411211)(int index) throws AGConnectCloudDBException 根据下标获取CloudDBZoneObjectList中的某个对象。|
|E|[next](#section99311446112)() throws AGConnectCloudDBException 获取CloudDBZoneObjectList中的下一个对象。|
|boolean|[hasNext](#section4458182417115)() 判断CloudDBZoneObjectList中的下一个对象是否存在。|
