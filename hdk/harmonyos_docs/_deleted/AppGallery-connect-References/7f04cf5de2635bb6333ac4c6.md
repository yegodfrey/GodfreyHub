# FunctionResult

|Interface Info|
|:---------------------------------------------------|
|public interface FunctionResult 当函数执行成功后包含云函数执行结果的类。|

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------------------------------|
|String|[getValue](#section1057294918499)() 获取函数执行后的返回值，返回值为字符串类型。|
|\<T\> T|[getValue](#section826619237506)(Class\<T\> valueClass) throws AGCFunctionException 获取函数执行后的返回值，匹配为传入的参数类。|

|Method|
