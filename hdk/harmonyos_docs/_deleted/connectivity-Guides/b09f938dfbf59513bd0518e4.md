# 版本更新说明

#### 11.1.0.300（2021-06-18）

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.stylus.penengine:11.1.0.300 新增特性 * 一笔成形：提供将原始手绘笔迹的图形识别为规整图形的能力，新增接口[InstantShapeGenerator](https://developer.huawei.com/consumer/cn/doc/connectivity-References/instantshapegenerator-0000001120176928)。 * 双击功能：提供双击手写笔进行绘制工具切换或其他自定义功能的能力，不涉及API变更。 * 手写套件 1. 新增[resetChangedState](#ZH-CN_TOPIC_0000001059550256__section11824346189)、[clearStepChange](#ZH-CN_TOPIC_0000001059550256__section1821114212196)、[enableInstantShape](#ZH-CN_TOPIC_0000001059550256__section161817239217)、[enableCanvasScale](#ZH-CN_TOPIC_0000001059550256__section12142225192110)、[enableInstantTable](#ZH-CN_TOPIC_0000001059550256__section533582652116)、[enableDrag](#ZH-CN_TOPIC_0000001059550256__section2376162715216)接口，用于画布新增一笔成形、智能表格、画布缩放和手写笔双击功能 2. 新增[setPaintScrollable](#ZH-CN_TOPIC_0000001059550256__section7693175761419)、[setToolViewVisible](#ZH-CN_TOPIC_0000001059550256__section17129930192119)接口，用于设置画布不可滚动和工具栏隐藏功能 3. 套索新增缩放、旋转功能|

#### 11.0.0.300（2020-10-30）

|------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.stylus.penengine:11.0.0.300 新增特性 * 手写套件：提供画布和工具栏，工具栏自带4种笔刷，5档笔宽选择，橡皮擦和套索工具，100+种颜色选择。 * 报点预测：提供能够根据历史轨迹预测出下一绘画点的算法，提升手写跟手性。|
