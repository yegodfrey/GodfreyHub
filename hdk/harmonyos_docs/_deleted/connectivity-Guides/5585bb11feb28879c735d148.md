# FAQ

#### 申请Wear Engine服务时，应用包名下拉菜单里没有对应的包名

申请Wear Engine服务前，需要先完成"账号服务"的开通，请参见[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)。  

#### 如果工程已有APP ID，是否需要重新申请，填写新的APP ID

只要是在华为联盟网站申请的，就可以用，不用重新申请。但是要确保应用的包名、APP ID及证书指纹是匹配的，即确保和[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)时提供的一致。  

#### 没有弹出用户授权界面，是什么原因

1. 请确保运动健康App版本符合Wear Engine[限制要求](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/service-introduction-0000000000018585#section14370945135215)。首次使用运动健康App，请打开App同意相关的隐私声明。
2. 请确保手机侧第三方应用APP ID、包名、签名和[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)时提供的一致。
3. 请确保打包的应用已包含签名信息（Android Studio中点击"Build \> Generate Signed Bundle/APK"）。
4. 请确保已按照[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/requesting-user-authorization-0000001050819181)章节，完成功能开发。
5. 若是非华为手机，还需安装HMS Core（APK），并在手机设置界面的应用权限管理中，允许华为运动健康App在后台弹出界面。  

#### 接口调用时返回Scope unauthorized错误信息，是什么原因

1. 请确保已在华为开发者联盟网站完成了[申请Wear Engine服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-0000001050777982)，并已审批通过。
2. 如果已申请了Wear Engine服务并且通过审批，仍返回Scope unauthorized错误信息，可能是您在华为联盟网站上申请Wear Engine服务前已经调用过相关接口，申请审核通过后，本地已缓存的未申请权限的记录未更新（每24小时自动刷新一次）。请在应用管理中清除华为运动健康App数据，或卸载重装华为运动健康App后重试。
3. 请确保您的手机侧应用的APP ID、包名、SHA256证书指纹和[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)时提供的一致。
4. 如仍无法解决，请通过华为开发者联盟的"[在线提单](#section3519174901211)"获取人工帮助。  

#### 如何通过getBondedDevices()接口获取设备的连接状态

当[getBondedDevices](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#ZH-CN_TOPIC_0000001919950697__getBondedDevices--)()接口调用成功后，返回已配对设备的列表。设备信息中会携带设备的连接状态，通过[isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)()方法的返回值判断设备是否处于连接状态。  

#### 手机侧应用ping穿戴设备侧应用时，提示Invalid argument，是什么原因

ping属于P2P通信，需要在对端应用互相预置签名，指定要ping通信的穿戴设备侧应用包名；当没有指定包名时，默认需要ping通信的穿戴设备侧包名与手机侧应用的包名一致。  

#### getErrorMsgFromCode有什么用？如何使用

[getErrorMsgFromCode](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineerrorcode-0000001059980969#ZH-CN_TOPIC_0000001873951390__getErrorMsgFromCode-int-)方便开发者根据错误码获取到错误信息。

示例代码如下：

```
HiWear.getDeviceClient(context).ping(device, new PingCallback() {
    @Override
    public void onPingResult(int errorCode) {
        Log.d(TAG, "result error code is: " + errorCode);
        // 根据错误码来获取对应的错误信息
        String errorMessage = WearEngineErrorCode.getErrorMsgFromCode(errorCode);
        Log.d(TAG, "result error message is: " + errorMessage);
    }
});
```

#### 运动健康App已连接穿戴设备，应用调测助手中无法显示已连接的设备

请确认：

1.是否已下载并安装最新版本华为运动健康App。最新版运动健康App可在华为应用市场下载。

2.是否已开启设备管理权限。授权路径：华为运动健康App\>我的\>设置\>设备能力开放\>应用调测助手\>设备管理权限。

如仍无法解决，请通过华为开发者联盟的"[在线提单](#section3519174901211)"获取人工帮助。

运动健康App版本过低，请到华为应用市场下载最新版。  

#### 应用调测助手获取的穿戴设备侧UUID只有24位

运动健康App版本过低，请到华为应用市场下载最新版。

如仍无法解决，请通过华为开发者联盟的"[在线提单](#section3519174901211)"获取人工帮助。  

#### 运动健康已连接穿戴设备，应用调测助手中显示Scope unauthorized

手机需要联网来更新Scope权限信息。请确保手机已连接网络。  

#### 打开HR传感器后，没有立刻上报数据，是什么原因

设备底层计算HR数据需要一定的时间，不同的设备由于性能差异所需时间不同，等待一段时间后方可收到上报数据。  

#### HR传感器数据中，有值为0或255的数据，是什么原因

0和255为瞬时异常数据，出现异常数据的原因可能是手表佩戴的位置有误或佩戴较松，请开发者对此异常数据进行过滤。  

#### 手机和轻量级智能穿戴设备通信，提示错误码206，是什么原因

* 手机和穿戴设备的包名或证书指纹不匹配
  * 轻量级智能穿戴设备侧：需要把手机的包名和指纹信息配置到工程的config.json文件中，具体请参见[发送点对点消息](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052460491#section2060584113402)中步骤三的说明。
  * 手机侧：需要把轻量级智能穿戴设备侧应用的包名和指纹信息配置正确
* 轻量级智能穿戴设备侧应用不在前台
* 手机或轻量级智能穿戴设备侧应用没有注册消息接收器
* 发送的消息为空
* 蓝牙未连接  

#### 手机侧应用发送文件给穿戴设备侧应用时，提示错误码10，是什么原因

手机侧应用发送文件需要文件访问权限，请检查应用是否相关文件的访问权限。
