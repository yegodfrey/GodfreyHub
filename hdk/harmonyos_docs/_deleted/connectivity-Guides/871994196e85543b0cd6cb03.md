# Android Studio的接入流程

#### 创建工程

1. 新建项目。

   <br />

   ![](https://media:801773457108641419 "点击放大")

   <br />

2. 填写应用名称、包名等。

   <br />

   ![](https://media:801773457108688420 "点击放大")

   <br />

3. 等待工程编译成功。

   <br />

   ![](https://media:801773457108744421 "点击放大")

   <br />

#### 配置Maven仓地址

1. 添加Maven代码库。

   <br />

   * 在"allprojects \> repositories"中配置DeviceVirtualization Engine的Maven仓地址。
   * 在"buildscript \> repositories"中配置DeviceVirtualization Engine的Maven仓地址。

   ```
   buildscript {
       repositories {
           google()
           jcenter()
           maven {url 'https://developer.huawei.com/repo/'}
       }
   }
   allprojects {
       repositories {
           google()
           jcenter()
           maven {url 'https://developer.huawei.com/repo/'}
       }
   } 
   ```

   ![](https://media:801773457108772422)  
   Maven仓地址无法直接在浏览器中打开访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。

   <br />

#### 添加编译依赖

1. 打开应用级的"build.gradle"文件。

   <br />

   ![](https://media:801773457108803423)

   <br />

2. 在"dependencies"中添加如下编译依赖。

   <br />

   ```
   dependencies {
       compileOnly 'com.huawei.dmsdp:devicevirtualization:{version}'
   }
   ```

   ![](https://media:801773457108829424)  
   {version}替换为实际的Dv Engine版本号，具体版本号请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/version-change-history-0000001052667185)。例如：

   com.huawei.dmsdp:devicevirtualization:1.0.3.300

   <br />

#### 添加Appld信息

在自身应用"AndroidManifest.xml"中的\<application\>元素内添加开发者联盟创建应用时生成的appid信息，如果不添加则华为云端的鉴权认证会失败。  
![](https://media:801773457108862425)  
* 此处的android:name不可以替换

```
<meta-data
     android:name="com.huawei.hms.client.appid"
     android:value="appid=xxxxxxxxx"/>
```
