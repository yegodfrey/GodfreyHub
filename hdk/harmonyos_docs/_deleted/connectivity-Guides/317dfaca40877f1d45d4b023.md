# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[Codelab](https://developer.huawei.com/consumer/cn/codelab/CastEngine/index.html#2)快速体验Cast Engine 的开发过程。  

#### 开发环境

* 安装Android Studio 3.X及以上

* JDK 1.8.211及以上
* 您的应用应满足以下条件：

  * minSdkVersion 19
  * targetSdkVersion 29
  * compileSdkVersion 29
  * Gradle 4.6及以上

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：EMUI 10.1及以上的华为手机

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[华为智能硬件合作伙伴平台](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/document-introduction-0000001163067907)|在开发应用前，需要在[华为智能硬件合作伙伴平台](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/document-introduction-0000001163067907)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/config-agc-0000001051400684#ZH-CN_TOPIC_0000001051400684__section1464519554325)。|
|2|[添加权限](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/add-permissions-0000001052499676)|Cast Engine需在"AndroidManifest.xml"文件中添加权限。|
|3|[客户端开发](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/client-dev-0000001052079439)|您可根据业务需求，完成Cast Engine无线投屏功能的开发。|
|4|[开发后自检](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/pre-release-check-0000001051639443)|华为提供对应用自动检查的能力。|
