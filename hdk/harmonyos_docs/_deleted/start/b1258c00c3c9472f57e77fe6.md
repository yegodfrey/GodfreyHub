# 8. SDK用户权益保障基本要求

您需要在SDK提供服务的全生命周期内协助SDK使用者共同保障最终用户权益，不应发生违规侵害用户权益行为。  

#### 提供服务前要求

#### 配置能力

8.1 SDK向使用者提供功能服务应同时提供相关业务功能及是否处理个人信息的配置能力，具体要求请参见[SDK功能](https://developer.huawei.com/consumer/cn/doc/start/sdk-function-0000001867303614)中的[SDK配置能力提供要求](https://developer.huawei.com/consumer/cn/doc/start/sdk-function-0000001867303614#section9341204516442)。  

#### 合规使用说明

8.2 SDK应简洁、清晰、易懂地向SDK使用者提供合规使用说明。

8.3 应单独制定合规使用说明，或在SDK集成接入文档中设立单独章节进行介绍。

8.4 SDK涉及提供扩展业务功能的，应说明SDK各项扩展业务功能及对应关闭的配置方式、示例。

8.5 SDK涉及处理可选个人信息的，应说明各项可选个人信息使用目的、场景及对应关闭的配置方式、示例。

8.6 SDK收集个人信息频次、精度可配置的，应说明不同频次、精度使用目的、场景及对应选择的配置方式、示例。

8.7 说明SDK所需的系统权限与各业务功能间的关系，并说明权限申请时机。

8.8 说明SDK初始化及各项业务功能接口合规调用时机。

8.9 提供向最终用户披露条款的示例，包括自身SDK名称、公司名称、处理个人信息类型及目的、自身个人信息处理规则文本下载或展示链接等。

8.10 获取最终用户授权同意的建议方式，其中需要取得最终用户单独同意的，应显著提示并给出示例。

8.11 以嵌入接口形式向最终用户提供行使权利的，应提供接口调用方式、示例。

8.12 其他相关法律法规规章的合规要求对应的配置方式、示例。

8.13 应客观描述各项配置功能及其效果，不应通过扩大配置选项对业务功能影响等方式，诱导SDK使用者接受默认配置选项。  

#### 个人信息处理规则

8.14 应简洁、清晰、易懂地公开展示SDK个人信息处理规则。个人信息处理规则具体要求请参见[SDK处理个人信息](https://developer.huawei.com/consumer/cn/doc/start/sdk-process-personal-info-0000001913103005)中的[隐私告知](https://developer.huawei.com/consumer/cn/doc/start/sdk-process-personal-info-0000001913103005#section132mcpsimp)要求。

<br />

#### 提供服务过程中要求

8.15 个人处理规则变更应及时告知SDK使用者，不应使用热更新等远程控制方式擅自更改个人信息处理规则。

8.16 不应擅自变更SDK使用者各项业务功能及个人信息配置状态。

8.17 发生或可能发生个人信息泄露、篡改、丢失的，应通过邮件、电话等方式及时告知SDK使用者，并采取补救措施，需要更新SDK版本的，宜采用强制方式要求SDK使用者更新。

8.18 提供互联网弹窗信息服务的，不应出现欺骗、误导、强迫最终用户跳转、下载、浏览等行为。

8.19 建立最终用户诉求和投诉响应管理机制，并在接到诉求和投诉后15个工作日内进行响应。

8.20 定期对SDK个人信息保护能力进行评估。  

#### 停止服务要求

8.21 SDK停止服务前，应提前通知SDK使用者，告知对已处理个人信息的处理方式。

8.22 SDK停止服务后，应通知SDK开发者及时删除SDK相关代码，对已收集的个人信息进行删除或匿名化。
