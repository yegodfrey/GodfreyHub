# 7. 未成年人保护

如果您的SDK所服务的应用可供未成年人访问，请确保您的SDK不存在危害未成年人身心健康的内容和行为，并需遵守《中华人民共和国未成年人保护法》、《未成年人网络保护条例》及其他适用法律法规和行业标准。当您的SDK向未成年人收集任何个人信息和敏感数据时，您必须遵守适用的未成年人隐私保护法规，如欧盟《通用数据保护条例》（GDPR）、中国《个人信息保护法》、《App违法违规收集使用个人信息行为认定方法》 、《儿童个人信息网络保护规定》以及其他适用法律法规。如您的SDK含有危害未成年人身心健康、侵害未成年人个人信息安全或对未成年人实施违法犯罪行为等内容，华为公司有权对您的SDK进行下架、删除、断开相关服务、并保留进一步追责的权利，包括但不限于终止您与华为的协议和/或冻结、删除您的开发者账号，并不承担任何责任，保存有关记录，并向有关部门报告。

7.1 广告投放：如果您的SDK面向未成年人投放广告，需确保广告内容适合未成年人。

（1）不得含有或传播危害未成年人身心健康的内容，或利用其网络服务对未成年人实施违法犯罪行为；

（2）SDK必须根据相应的年龄段对广告素材进行分级；

（3）面向未成年人投放广告的行为应符合相关法规和行业标准的要求，不得发布医疗、药品、保健食品、医疗器械、化妆品、酒类、美容、婚恋、孕育广告以及不利于未成年人身心健康的网络游戏广告。面向儿童的应用广告不得含有劝诱儿童要求家长购买广告商品或者服务，以及可能引发儿童模仿不安全行为的内容。

7.2 数据收集和使用：如果您的SDK会向未成年人收集任何个人信息和敏感信息，包括但不限于身份验证信息、麦克风和摄像头传感器数据、设备数据以及广告使用情况数据，您必须向开发者披露这一行为，并且要求开发者以显著、清晰的方式获得监护人的合法授权。

7.3 隐私声明：提供SDK的商户必须在隐私声明中清晰的说明收集未成年人个人数据的范围和用途，以帮助监护人全面了解SDK如何收集、使用、披露、处理和存储未成年人个人信息。并建立便捷、合理、有效的公开反馈渠道，及时受理并处理涉及未成年人的投诉、举报。

7.4 遵守中华人民共和国《未成年人网络保护条例》，还应注意以下事项：

（1）不得通过自动化决策方式向未成年人进行商业营销；

（2）不得在首页首屏、弹窗、热搜等重点环节呈现可能影响未成年人身心健康的信息；

（3）建立健全网络欺凌行为的预警预防、识别监测和处置机制；

（4）建立健全防沉迷制度，合理限制未成年人网络消费行为，防范和抵制流量至上等不良价值倾向。防沉迷机制年度公示义务；

（5）若您的SDK所服务的应用涉及网络游戏、网络直播、网络音视频、网络社交等，还应满足相应的年龄分级，并不得设置以应援集资、投票打榜、刷量控评等为主题的网络社区、群组、话题。
