# 服务商上架SDK说明

![](https://media:301784877883815795)  
* 服务商账号登录后，可按照流程直接上架SDK商品。（上架的SDK展示"认证商户"标识）；
* SDK内容信息填写规范请参考：[SDK审核指南](https://developer.huawei.com/consumer/cn/doc/start/sdk-review-guide-0000001913103001)。

1. 在[伙伴SDK首页](https://developer.huawei.com/consumer/cn/market/landing/SDK)，登录服务商账号后，点击"我的"，进入卖家中心。
2. 进入卖家中心后，在左侧导航栏选择"商品管理"。
3. 选择"发布商品"。
4. 填写SDK信息。  

   |发布项|发布标准|
   |:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |SDK及其接口文档|点击"添加SDK"。 说明： 1、支持单独/批量添加SDK版本（如v1.0、v2.0等），每个版本需提交对应说明文档等必要信息； 2、支持已上架SDK版本更新：通过编辑入口进入，添加新增版本号（如原v1.0基础上新增v1.1），新版本需补充对应的说明文档等必要信息，历史版本信息保留展示。 1、填写SDK包名：如果SDK上架到OHPM仓库，则为仓库坐标名，一般等同于HarmonyOS模块中oh-package.json5文件中定义的name字段。 2、填写SDK版本号：如果SDK上架到OHPM仓库，则为仓库坐标版本号，一般等同于HarmonyOS模块中oh-package.json5文件中定义的version字段。 3、版本更新说明：根据SDK版本的实际变更情况，填写内容。 4、填写SDK的发布时间，以SDK服务商官网正式公告日期为准。 5、填写SDK获取地址：如果SDK上架到OHPM仓库，则为仓库地址，包括OHPM公仓地址或企业自建仓库地址；如果SDK托管到企业自有网站，则为下载页面地址。 6、SDK包是否签名：确认SDK签名状态，根据实际打包情况勾选"已签名"或"未签名"。 7、填写是否在全国SDK管理平台登记：根据实际情况，选择"已登记"或"未登记"。 8、上传接口文档：支持.docx/.pdf格式，不超过10M，如无文件可提供有效外链。 说明： 接口文档须包含以下内容：接口名称、调用方式、请求参数、返回参数、调用示例、错误码。 9、上传SDK Demo：支持zip格式，不超过100M。 10、上传使用指南：使用指南需区别于接口文档，请提供有效的SDK集成使用指导，格式统一、美观规范，支持pdf/docx/zip（≤10M，zip内须仅含pdf/docx）。 11、权限与隐私：针对权限名称、权限说明、权限使用目的及操作进行详细填写。 说明： 【敏感权限范围】HarmonyOS NEXT定义的user_grant权限：包括位置、相机、麦克风、图片和视频、音乐和音频、通讯录、日历、运动数据、蓝牙、星闪、身体传感器等。 提示：user_grant权限可能随操作系统版本更新发生变化，当前系统支持权限组请参考[应用权限组列表](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/app-permission-group-list-V5)。 12、是否涉及处理个人数据：请根据SDK实际功能情况填写是否涉及处理个人数据，若未涉及则隐私政策及合规使用指南为非必填项。 13、隐私政策：请填写对应SDK的隐私政策链接，[SDK隐私政策规范性参考](https://developer.huawei.com/consumer/cn/doc/start/sdk-privacy-policy-specifications-0000001867303626)。 14、合规使用指南：请填写对应SDK的合规使用指南，支持上传pdf/docx/zip格式（≤10M，zip内须仅含pdf/docx），如无文件可提供有效外链，[合规使用指南规范性参考](https://developer.huawei.com/consumer/cn/doc/start/sdk-compliance-specifications-0000001913103017)。|

5. 填写商品基础信息。  

   |发布项|发布标准|
   |:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |商品名称|1. 商品名称应描述准确，与内容相符，软件与软件著作权证书中软件名称相符。 2. 商品名称应与业界命名规范一致，不可以出现拼写错误，如：将wordpress拼成wordpess。 3. 商品名称不能扩大宣传，不可以直接借助华为名义，如：命名为"华为XXX"。 4. 商品名称仅用于对商品命名，介绍、价格、版本、电话号码等与命名无关内容，请勿出现在商品名称中。 5. SDK名称中无需包含鸿蒙版、HarmonyOS SDK， HarmonyOS NEXT、鸿蒙端等字样，直接使用实际SDK名即可。|
   |商品主图|1. 商品主图，用于上架后在商品详情页展示，只可上传1张。 2. 图片支持JPG/JPEG/PNG，尺寸为100x100px，大小不超过5M。|
   |商品简介|1. 在商品列表和详情页面展示，字数应不少于60字符且不超过180字符。 2. 商品简介不能只介绍公司信息，需要简要介绍商品信息。|
   |（可选）视频文件|如商品需附加视频，可填写此项。|
   |（可选）视频封面|如视频文件需添加封面，可填写此项。|
   |商品详情|1. 填写的详情，应当包括但不限于：SDK介绍（必填）、提供商介绍（必填）、核心优势（必填）、约束与限制（必填）、成功案例（选填）（缺少必填项可能会被驳回，可参考：[SDK审核政策](https://developer.huawei.com/consumer/cn/doc/start/sdk-gallery-policy-0000001913021977)）。 2. 商品说明应当保持字体、字号、字色一致，排版要规范，不能出现明显的空格、换行等不合理排版问题，保持页面信息整齐美观。 3. 支持插入图片和视频，图片支持JPG/JPEG/PNG格式，最大宽度不超过900px、每张图片大小不超过5M，如详情内容仅有图片或截图，没有文字说明，则驳回。 4. 避免使用广告法敏感词，如：国家级、最佳、极致、世界第一等。 5. SDK类商品会提供富文本内容，需按照提示内容进行填写，如不按照提示填写，可能会被驳回。|
   |（可选）商品资质|1. 上传商品取得的相关资质信息文件，软件商品必须上传与商品名称相符的软件著作权证书，且著作权人须与发布商品公司主体一致。 2. 商品如涉及开源部分，请如实提供商品开源声明。 3. 支持上传.zip/.docx/.pdf格式的文件（zip中只能包含pdf或docx），文件大小不超过10M。|
   |售后支持范围|参照样例按照实际服务内容表述，至少包含服务内容、服务时间、服务电话、服务邮箱4项内容。 说明： 如售后服务时间超过5\*8小时，请确保服务时间内及时响应各联系方式收到的各类售后问题； 售后服务邮箱，请确保邮件24小时内能得到答复。 参考样例： 售后服务时间：7 \* 8小时 售后服务内容：X系统使用问题 服务热线：010-864\*\*\*96 服务邮箱：xxx@qq.com|

   |发布项|发布标准|
   |:--------|:----------------------------------------------------------------------------------------------------------------------------------|

7. 填写商品售卖方式。  
   SDK类商品定价方式只支持"按需报价"，即按照买家的需求提出具体报价，最终协商一致即可出售该商品。  

   |发布项|发布标准|
   |:------|:---------------------------------------------------------------------------------|
   |商品规格及售价|* 规格信息必须完整。 * 规格命名应有一定规则，不能简单地以"规格1"、"规格2"类似命名。 * 同一商品不同版本，请以规格做区分，无需以不同的版本发布多个商品。|

9. 填写商品协议信息。  

   |发布项|发布标准|
   |:---------|:----------------------------------------------------|
   |最终用户协议|请上传商品关联的协议或者合同（商品上架时关联的合同信息，即《商品服务协议》），商品必须与所关联的合同一致。|
   |（可选)特殊商品协议|如商品需特殊协议，可填写此项。|

10.商品预检

商品预检旨在提升商品类SDK审核通过率，结合模型对SDK高频出现的问题进行系统性的预先检测并提供修改意见，可大幅降低上架时间成本，建议服务商对SDK类商品自主预检后再进行商品类SDK发布。

a.SDK类商品信息全部填写完毕后，点击【保存草稿】按钮，系统将弹窗提示"已保存，请在未上架SDK列表内，点击【操作】里的【预检】按钮对已添加SDK版本进行预检"；点击【确认】后，将进入到未上架列表；在未上架列表点击【操作】里的【预检】按钮进入预检页面。

![](https://media:301784877883844796)

![](https://media:301784877883882797 "点击放大")

<br />

b.SDK类商品信息全部填写完毕后，点击【发布商品】按钮，系统将弹窗提示"建议先完成预检以提升上架审核通过率（直接发布将中断进行中的预检），是否确认发布"；点击【确认】后，将提交审核并进入到审核列表；点击【取消】将回到商品信息填写页面。
