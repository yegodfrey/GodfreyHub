# 制作表盘

本文将介绍表盘制作工具Theme Studio Pro的界面、功能和使用方法。  

#### 新建作品

操作步骤：

1. 点击"新建作品" 。
2. 作品类型选择"手表表盘" 。
3. 输入表盘作品名称，选择设备类型，下拉选择对应能力集规范版本。

![](https://media:801785297267359606 "点击放大")

![](https://media:801785297267406607 "点击放大")  
![](https://media:801785297267435608)  
1. 设备类型：支持466\*466、408\*480、286\*482分辨率表盘制作。
2. 规范版本："466\*466"支持1.y和2.y；"408\*480"支持2.y；"286\*482"支持2.y。  

#### 作品管理

新建作品后，作品管理页面会自动生成一个作品。支持在作品管理页面复制作品、删除作品和重命名作品。

编辑过程中保存作品后（![](https://media:801785297267463609 "点击放大")为已保存），将自动生成表盘缩略图，显示在作品管理页面。

![](https://media:801785297267508610 "点击放大")  

#### 制作页面

表盘制作界面按红色线框划分为五个区域：

* [菜单栏](#section66771179404)
* [元素栏](#section138781830103420)\&[图层栏](#section14484153615342)
* [编辑预览区](#section791014383413)
* [属性栏](#section250116388345)\&高级功能栏

区域介绍

* 菜单栏：支持新建、导入、保存 、撤回/重做、对齐、导出等操作。
* 元素栏：支持选择表盘元素，包括单图、选图等。
* 图层栏：支持查看图层，调整图层状态、位置等。
* 编辑预览区： 所有的操作都可在编辑预览区完成，实时预览表盘效果。
* 属性栏：支持调整元素、图层的属性。
* 高级功能栏：支持表盘高级功能，包括景深、颜色自定义、样式自定义。
* 状态栏：支持查看当前表盘的版本号和校验结果。

#### 菜单栏

![](https://media:801785297267651614 "点击放大")

新建项目：新建一个表盘作品。

导入：从本地导入已有的表盘作品。

插入：将已制作完成的表盘资源包插入到当前表盘作品中。表盘资源包在跨分辨率插入时，会基于不同分辨率进行等比换算，请插入后检查并手动调整，以达到最佳效果。

背景：提供制作背景时，支持使用的元素类型。

时间：提供制作时间（时、分、秒）时，支持使用的元素类型。

日期：提供制作日期（月、日、星期）时，支持使用的元素类型。

控件：提供制作数据（天气、步数、心率等）时，支持使用的元素类型。

元素介绍

元素是表盘的功能选项，每个元素都有其独特作用。

通过添加一定数量的元素，进行表盘制作。

例如：新增一个组合图，选择数据类型为"步数"，添加数字图片，编辑预览区则显示步数。

![](https://media:801785297267766617 "点击放大")

#### 图层栏

每添加一个元素，都将自动生成一个对应的图层，显示在图层栏。

表盘图层栏显示已添加的所有图层。

![](https://media:801785297267808618 "点击放大")

<br />

图层分组

1. 基于元素添加的位置，元素图层自动分为背景、时间、日期和控件四组。
2. 多个图层叠加显示，背景在最底层，时间在最顶层。

<br />

图层相关操作

* 显示/隐藏图层：隐藏的图层不会显示在预览区中。
* 锁定/解锁图层：锁定图层以免其在画布上移动。
* 移动图层：移动图层位置，仅支持在当前分组中进行移动。
* 删除图层：删除当前图层（右键后删除/Delete快捷键）。
* 复制图层：通过复制快捷键Ctrl+C和粘贴快捷键Ctrl+V实现。
* 新增图层：在背景、时间、日期模块，直接添加。在控件右键，添加新容器和图层；在容器右键，为容器添加新图层。

<br />

容器介绍

背景、时间、日期无容器。控件有容器：初次从"控件"中添加一个元素后，同时会新建一个容器。

1. 容器是一组图层的细化分组，默认显示为"容器X"（X为阿拉伯数字），此时未关联数据类型。当该容器下的图层关联"数据类型"后，该容器将变为特定数据容器，显示为"容器X-XX数据"。例如："容器2-心率"、"容器3-天气"。 ![](https://media:801785297267832619 "点击放大")

2. 选中某个容器或者容器下的图层时（蓝色为选中状态），只能在当前容器下新建元素图层。且图层关联的数据类型，只能从该数据容器中进行选择。例如：选中"容器1-步数"，只能在此容器下新建元素图层，且只能选择步数相关的数据类型。 ![](https://media:801785297267866620 "点击放大")

3. 如需添加一个新容器，有以下两种方法：点击"元素"\>"控件"或选中"控件" 并右键，添加一个新容器。

   方法1：点击"元素"\>"控件"，添加新容器。

   ![](https://media:801785297267904621 "点击放大")

   ![](https://media:801785297267939622 "点击放大")

   方法2：选中"控件" 并右键，添加新容器。

   ![](https://media:801785297267970623 "点击放大")

   ![](https://media:801785297268009624 "点击放大")
4. 未打开自适应功能时，图层只能在当前容器的范围中移动。打开自适应功能后，容器框会跟随元素框而移动。如关闭自适应功能，需手动调整容器框大小，建议先选中容器，调整好容器的大小和位置，再选中图层，调整图层的大小和位置。 ![](https://media:801785297268054625 "点击放大")

<br />

容器跳转

容器变为数据容器后，点击当前容器的范围，可跳转至相关应用。哪些容器支持跳转？点击查看[跳转应用](https://developer.huawei.com/consumer/cn/doc/content/value-type-pro-0000001583966586#section1743413371488)。因此，多个数据容器的范围不可重叠，避免出现"点击重叠区域，跳转失误"的问题。

例如：点击天气容器，可跳转至天气应用页面，点击心率容器，可跳转至心率应用页面。因此，天气容器和心率容器的范围不可重叠。

![](https://media:801785297268086626 "点击放大")

数据类型介绍

在一系列属性中，关联"数据类型"非常重要。

* 关联"数据类型"前，元素与表盘支持的"数据类型"无联系。
* 关联"数据类型"后，元素与表盘支持的"数据类型"联系起来。

例如：元素关联数据类型"日期高位"，则通过该控件动态、实时显示当前实际日期高位。

* 占位图覆盖全量数据类型场景。
