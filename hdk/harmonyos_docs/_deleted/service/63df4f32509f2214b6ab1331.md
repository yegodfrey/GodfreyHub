# 基于意图框架创建端插件

插件创建方式选择"端插件-选择意图框架"进行创建。

![](https://media:301785143828379542 "点击放大")

<br />

当选择已有意图后，系统将自动填充以下字段：APP包名、APP名称、服务类型，只需要补充插件描述即可。

![](https://media:301785143828423543 "点击放大")
