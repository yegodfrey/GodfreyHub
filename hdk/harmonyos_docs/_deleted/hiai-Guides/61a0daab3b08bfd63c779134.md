# 版本更新说明

#### 6.0.1.0\&6.0.1.0 next（2025-12-31）

|---------------------------------------------------------------------------------|
|修改特性 新增基础核内同步API PipeBarrier，高阶API BroadCast。 新增LORA训练接口使模型以极低的资源成本学会特定的知识、风格或任务。|
