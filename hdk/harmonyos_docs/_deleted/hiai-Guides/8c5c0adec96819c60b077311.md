# 开发准备

#### Android环境要求

* 推荐使用Ubuntu 22.04及以上版本、MacOS 10.14及以上版本、Windows 10及以上版本安装应用开发环境[Android Studio](https://developer.android.com/studio/index.html)。
* 使用NDK进行Native代码编译，支持NDK r20b\~NDK r23c版本，建议使用NDK r23c版本进行集成。另外，可以使用[CMake](https://cmake.org/download/)进行Native代码编译。[NDK下载](https://github.com/android/ndk/wiki/Unsupported-Downloads)。
* Android API Level仅支持android-16及以上版本，可在Demo Application.mk中配置，例如：APP_PLATFORM := android-16，在集成libhiai_hcl_modelruntime.so及libcpucl.so场景仅支持android-19及以上版本。
* 使用Ubuntu 64位运行[Tools下载](https://developer.huawei.com/consumer/cn/doc/hiai-Library/tools-download-0000001060044334)中tools_omg模型转换工具。[ubuntu 22.04各镜像版本下载](https://mirrors.ustc.edu.cn/ubuntu-releases/16.04/)。
* MacOS环境下，请在[MocOS安装docker](https://gitee.com/huawei-hiai-foundation/ToolsDoc/blob/master/MAC安装Docker指导.md)后，在docker中运行[Tools下载](https://developer.huawei.com/consumer/cn/doc/hiai-Library/tools-download-0000001060044334)的tools_omg模型转换工具。
* 准备训练好的Caffe、TensorFlow、ONNX等模型或者从[Model Zoo](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-zoo-0000001187986457)中选择合适的模型。
* 准备搭载Kirin平台的设备用于测试App，具体平台与终端型号参见[支持的平台](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/supported-platforms-0000001052830507)。

Android NDK 16以上版本，已去除Ion功能模块，若App侧功能实现依赖Ion功能模块，请参考Android官方给出的[libion方案](https://source.android.com/docs/core/architecture/kernel/ion_abi_changes)。  

#### HarmonyOS环境要求

* 推荐使用[Ubuntu 22.04](https://mirrors.ustc.edu.cn/ubuntu-releases/22.04/)及以上版本、MacOS 10.14及以上版本、Windows 10安装应用开发环境[DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)。
* 使用Ubuntu 64位运行[Tools下载](https://developer.huawei.com/consumer/cn/doc/hiai-Library/tools-download-0000001060044334)中tools_omg模型转换工具。
* 准备训练好的tools_omg模型转换工具生成的[离线模型](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overall-parameter-0000001052966900)或者从[Model Zoo](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-zoo-0000001187986457)中选择合适的模型。  

#### 下载DDK

请[下载DDK](https://developer.huawei.com/consumer/cn/doc/hiai-Library/ddk-download-0000001053590180)，并解压。
