# SDK隐私声明

HUAWEI HiAI Engine SDK是由华为软件技术有限公司（以下简称"我们"或"华为"）面向应用开发者（以下简称"开发者"）提供的芯、端、云三层结合的AI能力开放平台。

开发者根据HUAWEI HiAI Engine SDK的开发文档和指南在其应用中集成了HUAWEI HiAI Engine SDK后，我们将通过被集成的HUAWEI HiAI Engine SDK向开发者的最终用户（以下简称"您"或"用户"）提供相关服务，处理开发者应用相关的数据，相关数据中可能包含您的个人信息。华为非常重视您的个人信息和隐私保护，我们将会按照法律要求和业界成熟的安全标准，为您的个人信息提供相应的安全保护措施。我们将通过本声明向您说明我们如何收集、使用、披露、保护、存储及传输您的个人信息。

请注意：我们要求集成HUAWEI HiAI Engine SDK的所有开发者严格遵循法律法规、开发者协议和HUAWEI HiAI Engine SDK合规使用指南的要求处理您的个人信息；在接入、使用各开放能力前，我们要求开发者在其产品应用的隐私政策中向您告知其集成SDK处理个人信息的基本情况，并获取您的同意或取得其他合法性基础。但我们无法控制开发者及其开发者应用如何处理开发者所控制的个人信息，也不对其行为负责。我们建议您认真阅读开发者应用相关用户协议及隐私政策，在确认充分了解并同意开发者如何处理您的个人信息后再使用开发者应用。  

#### 我们如何收集和使用您的个人信息

华为仅会根据本声明以下所述目的和方式收集和使用您的个人信息，如果我们要将收集的您的个人信息用于本声明未载明的其他目的，我们会以合理的方式自行或通过开发者明确向您告知，并再次获取您的同意或取得其他合法性基础。如果SDK存在扩展功能或收集和使用了可选个人信息，我们会在下文特别声明。

一、计算机视觉（CV）

计算机视觉是计算机能够模拟人的视觉系统感知周围环境，判断、识别、理解空间组成。能力包括人脸识别、人体识别、图片识别、码识别、视频技术和文本识别等，保障SDK安全稳定运行及结算。

计算机视觉相关能力在提供服务时，不保存任何个人数据，也不会发给其他第三方服务提供商处理。

二、自动语音识别（ASR）

自动语音识别是将人的声音转化为文本，便于计算机进一步进行解析理解。能力包括语音识别等，保障SDK安全稳定运行及结算。

自然语言识别相关能力在提供服务时，不保存任何个人数据，也不会发给其他第三方服务提供商处理。

三、自然语言理解（NLU）

自然语言理解与自动语音识别有机结合，让计算机理解人的声音或文本，进行沟通或自然的动作。能力包括分词、文本的实体识别、词性标注、关键字提取、助手类意图识别和IM类意图识别等，保障SDK安全稳定运行及结算。

自然语言理解相关能力在提供服务时，不保存任何个人数据，也不会发给其他第三方服务提供商处理。  

#### 设备权限调用

当您使用相应功能及服务时，我们会通过开发者应用向系统申请您设备的相应权限。您可以在设备的设置功能或"隐私设置"中查看权限状态，并可自行选择开启或关闭部分或全部权限。

开发者在集成、使用相应开放能力时，将自行决定权限的调用范围，因此开发者应对权限的调用及用途向您进行说明。您根据开发者应用的请求开启任一权限即代表授权我们可以处理相关个人信息来为您提供对应服务；一旦您关闭任一权限即代表您取消了授权，我们将不再基于对应权限继续处理相关个人信息，可能无法继续为您提供该权限所对应的服务。请注意，您关闭权限的决定不会影响此前基于您授权所进行的个人信息处理活动的效力。  

|权限|权限描述|使用目的|申请时机|
|:------------------------------------------------|:---------|:------------------------|:-------------------|
|获取访问网络权限：android.permission.INTERNET|获取访问网络|用于访问网络获取模型数据、能力插件以及用于业务打点|调用需要使用网络能力的接口时|
|获取麦克风权限：android.permission.RECORD_AUDIO|调用麦克风|用于音频接收|调用需要通过引擎录音获取数据能力的接口时|
|获取写存储权限：android.permission.WRITE_EXTERNAL_STORAGE|获取写入外部存储空间|用于加载数据模型和能力插件|调用需要写入存储数据能力的接口时|
|获取读存储权限：android.permission.READ_EXTERNAL_STORAGE|获取读取外部存储空间|用于读取设备存储的数据|调用需要读取存储数据能力的接口时|
|获取网络状态权限：android.permission.ACCESS_NETWORK_STATE|获取网络状态|用于查看网络连接状态信息|调用网络状态感知能力的接口时|
|获取Wi-Fi状态权限：android.permission.ACCESS_WIFI_STATE|获取Wi-Fi状态|用于查看Wi-Fi网络状态相关信息|调用Wi-Fi状态感知能力的接口时|

#### 对未成年人的保护

我们非常重视对未成年人个人信息的保护，华为将严格按照国家法律法规要求对未成年人提供服务并对未成年人提供保护。如果您是未成年人，需要您的父母或其他监护人同意您使用开发者应用并同意相关应用的服务条款。父母或其他监护人也应采取适当的预防措施来保护未成年人，包括监督其对开发者应用的使用。

特别地，如果您是儿童（不满十四周岁的未成年人），在您使用开发者应用和我们的服务前，请务必通知您的父母或其他监护人一起仔细阅读开发者应用隐私声明、本声明以及我们专门制定的《[华为消费者业务儿童隐私保护声明](https://consumer.huawei.com/cn/privacy/child-policy/)》，并在您的父母或其他监护人同意或指导后，使用开发者应用和我们的服务或向我们提供信息。如果您是儿童的父母或其他监护人，请确保您监护的儿童在您的同意或指导下使用开发者应用和我们的服务以及向我们提供信息。  

#### 管理您的个人信息

华为非常尊重您对个人信息的关注，我们将遵照相关法律法规的要求，协调、支持并保障您行使访问、复制、更正、删除等个人信息主体权利。

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本声明中"[如何联系我们](#section23611435114114)"章节中所述方式与我们取得联系，并行使您的相关权利。  

#### 信息存储地点及期限

处理您的个人信息后，会立即删除，不涉及个人信息存储。
