# 概述

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150613.23920539904679675372670855635494:50001231000000:2800:8DE8DB8383C16C59DF79DA8C90DEF25A32A303E3BCDEEA077142C80DD2EF3E30.png)  
暂不支持在HarmonyOS NEXT上使用。

系统调试工具可以对模型推理进行性能统计，并获取性能数据。

工具主要包括两个可执行程序：model_run_tool和data_proc_tool。

* model_run_tool用于开启性能统计(Profiling)功能并执行模型推理，生成性能数据。
* data_proc_tool将model_run_tool运行后生成的性能数据转换成csv文件取出，存放到用户指定的目录。
