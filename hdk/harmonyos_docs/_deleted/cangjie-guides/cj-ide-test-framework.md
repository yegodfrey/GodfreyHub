# 代码测试

DevEco Studio支持纯仓颉应用测试框架，提供测试用例执行能力，提供用例编写基础接口，输出测试结果，支持开发简洁易用的自动化测试脚本，支持代码覆盖率统计。

本章主要介绍纯仓颉场景下的应用测试框架，混合语言场景请参见[代码测试](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-code-test)。

  * **[Instrument Test](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-test-instrument-test)**  

  * **[Local Test](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-test-local-test)**
