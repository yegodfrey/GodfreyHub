# 模块管理

Module 是应用的基本功能单元，包含了源代码、资源文件、第三方库及应用配置文件，每一个 Module 都可以独立进行编译和运行。一个应用通常会包含一个或多个 Module，因此，可以在工程中创建多个 Module，Module 分为 Ability 和 Library 两种类型。通用的模块管理（添加/导入/删除 Module等操作）可参见[模块管理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-module-management)。本章内容介绍仓颉相关模块的管理说明。

  * **[添加供ArkTS调用的页面组件](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-module-add-page)**  

  * **[模块限制](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-module-limit)**  

  * **[仓颉引入ArkTS三方模块](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-module-bind-arkts)**
