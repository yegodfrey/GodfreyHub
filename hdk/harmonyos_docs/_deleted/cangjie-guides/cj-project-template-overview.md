# 工程模板介绍  
  
仓颉支持创建纯仓颉工程模板 [Cangjie] Empty Ability 和 Cangjie + ArkTS混合互操作工程模板 [Cangjie] Hybrid Ability，并自动生成对应的代码和资源模板。

**工程模板名称** | **说明**  
---|---  
[Cangjie] Empty Ability | 用于phone、tablet设备的仓颉模板，展示基础的 Hello Cangjie 功能。  
[Cangjie] Hybrid Ability | 用于phone、tablet设备的Cangjie + ArkTS互操作模板，展示基础的 Hello Cangjie 功能。
