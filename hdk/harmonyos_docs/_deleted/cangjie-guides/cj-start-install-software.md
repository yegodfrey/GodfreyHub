# 下载与安装DevEco Studio和仓颉插件

#### 下载DevEco Studio

请前往下载中心获取并下载配套版本的[DevEco Studio](https://developer.huawei.com/consumer/cn/download/deveco-studio)。

#### 安装DevEco Studio

DevEco Studio支持Windows和macOS系统，可以参考[下载与安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-software-install)进行下载与安装。

#### 下载仓颉插件

可以通过两种方式下载仓颉插件：

  * 自行前往下载中心获取并下载配套版本的[仓颉插件](https://developer.huawei.com/consumer/cn/download/deveco-studio-cangjie-plugin)。
  * 支持在DevEco Studio内自动下载并安装配套的最新版本仓颉插件。



#### [h2]手动下载仓颉插件

请前往下载中心获取并下载配套版本的[仓颉插件](https://developer.huawei.com/consumer/cn/download/deveco-studio-cangjie-plugin)。

#### 查看SDK中cjc编译器版本信息

安装插件并创建仓颉工程后，插件会完成SDK的初始化安装，之后即可通过以下方式查看cjc编译器版本信息。

#### [h2]macOS

macOS 系统下仓颉SDK默认安装在 $HOME/.cangjie-sdk/xx.xx/cangjie 目录下（xx.xx为DevEco Studio版本号的前两位，例如26.0）。

执行如下命令设置仓颉SDK工具链相关环境变量：
    
    
    source $HOME/.cangjie-sdk/xx.xx/cangjie/build-tools/envsetup.sh

请在以上命令环境中继续执行 cjc -v 命令：
    
    
    cjc -v

通过命令行结果可以看到仓颉编译器版本信息。

#### [h2]Windows

Windows 系统下仓颉SDK默认安装在 %USERPROFILE%.cangjie-sdk\xx.xx\cangjie 目录下（xx.xx为DevEco Studio版本号的前两位，例如26.0）。

仓颉为开发者提供了三种不同格式的安装脚本，分别是 envsetup.bat，envsetup.ps1 和 envsetup.sh，可以根据使用习惯及环境配置，选择一种执行：

  * 若使用 Windows 命令提示符（CMD）环境，请执行：
        
        %USERPROFILE%\.cangjie-sdk\xx.xx\cangjie\build-tools\envsetup.bat

  * 若使用 PowerShell 环境，请执行：
        
        . $env:USERPROFILE\.cangjie-sdk\xx.xx\cangjie\build-tools\envsetup.ps1

  * 若使用 MSYS shell、bash 等环境，请执行：
        
        source $USERPROFILE/.cangjie-sdk/xx.xx/cangjie/build-tools/envsetup.sh




请在以上命令环境中继续执行 cjc -v 命令：
    
    
    cjc -v

通过命令行结果可以看到仓颉编译器版本信息。
