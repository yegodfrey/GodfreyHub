# 使用本地真机运行应用

仓颉语言编写的HarmonyOS应用，支持在phone、tablet设备中运行，可以采用USB连接方式或者无线调试的连接方式，具体的运行操作请参见[使用本地真机运行应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-device)。
