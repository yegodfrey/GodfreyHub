# 概述

HMS Toolkit是一个IDE工具插件，提供一套含应用创建、编码和转换、调测、测试和发布的开发工具。可以帮助您以更低的开发成本和更高的开发效率集成HMS Core服务。

* 场景一：您目前已经开发了一个Android应用，集成和使用了GMS（Google Mobile Services）服务，想要快速迁移使用HMS Core服务和上线华为应用市场。 涉及HMS Toolkit的能力：Configuration Wizard、Convertor。

* 场景二：您准备开发一个新应用，想快速集成华为HMS Core服务和上线华为应用市场。 涉及HMS Toolkit的能力：Configuration Wizard、Repository，Coding Assistant。
