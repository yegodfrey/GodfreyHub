# 反馈与求助

如果您在使用过程中有任何的问题和建议，可以通过如下方式与我们取得联系。

* 在线提单：通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)与我们取得联系。
* 论坛反馈：登录[开发者联盟主题论坛](https://developer.huawei.com/consumer/cn/forum/blockdisplay?fid=0101211211623820128)，发布帖子反馈问题。
