# 抓帧

#### 连接手机设备

1. 在工具左下角，点击"Replay Context"，从下拉菜单中选择设备进行连接。
2. 连接成功后，在Replay Context之后显示设备名称和Remote server ready。同时设备上显示已成功打开的com.huawei.squid界面。

   <br />

   ![](https://media:201778750893898242)

   <br />

#### 单帧抓取

1. 打开"Launch Application"窗口，Program界面的Executable Path中，从设备已安装应用列表中选择要调试抓帧的应用。如果应用启动需要参数配置才能运行，在Program界面的Intent Arguments中配置应用参数，默认不带参数配置启动应用。在Capture Options配置抓帧的选项。点击"Launch"按钮，开始启动调试抓帧的应用。

   <br />

   ![](https://media:201778750893928243)

   <br />

2. 当调试的应用启动运行后，Frame Profiler打开该调试应用进程抓帧的界面。当Connection Status显示Established， API显示OpenGL ES (Active) 或Vulkan (Active) ，表示抓帧应用启动成功。

   <br />

   ![](https://media:201778750893956244)

   同时设备界面显示API协议、连接者用户名、帧率和已抓帧的数量。

   ![](https://media:201778750893988245)

   <br />

3. 在调试应用进程抓帧的界面，点击"Capture Frame(s) Immediately"，立即抓取当前显示的帧。抓取的帧在Captures collected列表显示如下。

   <br />

   ![](https://media:201778750894013246)  
   ![](https://media:201778750894041247)  
   在抓帧功能启动后，由于工具会分析GPU的API执行序列，建立资源间的依赖关系，分析游戏运行的资源数量及API调用的数量，抓帧功能运行阶段对运行会有不同程度的影响，所以在抓帧触发后界面会存在短暂的卡顿情况。

   <br />

4. 选中抓取的帧，点击鼠标右键，点击"Save"选择保存到计算机上，或者点击"Open in... \> This instance"直接回放该帧。

   <br />

   ![](https://media:201778750894069248) ![](https://media:201778750894097249)

   <br />

#### 延时抓取

1. 同[单帧抓取](#section12121153217120)中启动调试抓帧的应用。
2. 设置最大文件大小：超过设置大小后自动清空，重新抓取。 ![](https://media:201778750894125250)

3. 点击"Deferring Capture"延时抓取，超过设置的最大文件大小后，Delay size自动刷新。
4. 点击"Capture Stop"停止抓帧，并且显示抓取到的缩略图。  

#### 连续帧抓取

1. 同[单帧抓取](#section12121153217120)启动调试抓帧的应用。长时间抓取连续帧，文件过大可能导致闪退，建议减小最大文件大小，且保存文件后删除临时文件。
2. 点击"Sequential Frame(s) Start"按钮即可开始抓帧。

   抓连续帧前可以进行设置。
   1. 设置连续帧帧数，需要设置为大于10的数，点击"Sequential Frame(s) Start"后，到达设置帧数后停止抓帧。

      ![](https://media:201778750894154251)
   2. 设置每隔多少帧获取一张截图，将在"TraceOutline"窗口展示。

      ![](https://media:201778750894185252)
   3. 设置最大文件大小。 ![](https://media:201778750894218253)

3. 再次点击"Sequential Frame(s) Stop"按钮停止抓帧，并且显示抓取到的缩略图。
4. 选中需要保存的帧，右键选中点击"Save"保存为sqd类型的文件。点击"Open in..."选择"This instance"或者双击缩略图，会跳转到"TraceOutline"界面。

   ![](https://media:201778750894253254) ![](https://media:201778750894280255)  
   ![](https://media:201778750894315256)  
   任何超时操作会导致连接切换到local，要解决该问题，可以上调超时时间的数值：打开FrameProfiler主菜单"Tools \> Settings \> Core \> Config Editor"，设置"RemoteServer \> TimeoutMS"为50000。

   重新打开工具即可生效，若仍有问题可将C:\\Users\\xxx\\AppData\\Roaming\\squid\\squid.conf文件删除。

抓取vulkan连续帧前，为提高连续帧抓取流畅性，可以打开FrameProfiler主菜单"Tools \> Settings \> Core \> Config Editor"，启用"Vulkan \> Debug \> ForceToNotUseCoherentMemory"，减少连续帧体积，但该选项会强制改变内存类型，部分游戏不支持，可能会导致游戏闪退等异常。  

#### Vulkan跨平台抓取回放

1. 勾选"Override Vulkan GPU capabilities"。

   勾选"Launch application"窗口中的"Override Vulkan GPU capabilities"，点击"Launch"，运行应用程序，进行抓取并保存关键帧。

   ![](https://media:201778750894343257)  
   ![](https://media:201778750894469258)  
   勾选"Override Vulkan GPU capabilities"选项可能会导致无法运行应用程序，甚至产生崩溃。这意味着需要分析的应用程序不能用来与目标回放平台中的一组Vulkan扩展、功能和属性一起使用，也无法直接在目标平台上运行该应用。工具无法处理这种情况，对于这种应用程序来说，无法进行跨平台分析。
2. 在目标平台回放关键帧。 打开工具连接目标设备，选择打开上一步保存的关键帧文件，可以正常回放。
