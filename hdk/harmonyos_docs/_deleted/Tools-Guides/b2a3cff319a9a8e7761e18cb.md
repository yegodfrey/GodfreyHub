# 概述

Theme Studio是一款智能、高效、可视化的全场景主题/表盘制作工具，简化创作者内容制作，所有页面的修改内容可以实时预览，效果随时可见。让创作者主题/表盘创意设计更加高效便捷。  
主题工具亮点介绍

* 关联页面的颜色和图片一处修改，全局自动同步，保证风格统一。
* 实现一键同步正在编辑的主题至手机/平板/折叠屏，在真机上校验主题效果。
* 通过工具自动校验所有资源项目，能够可视化制作出符合规范的主题包。
* 无需手动编码，可视化便捷操作。提供位移、帧动画、旋转、缩放、渐隐等基础动效和水波纹、跟手粒子、多壁纸、充电特效、一镜到底等高级动效。
* 具体规范请参见[主题设计指导及规范](https://developer.huawei.com/consumer/cn/doc/distribution/content/themes-specification-0000001160896163)。  
表盘工具亮点介绍

* 交互界面简洁清晰，表盘各控件均可高效编辑。
* 所有操作均所见即所得，编辑区可自由设置数值和预览区可自由拖拽，高效且便捷。
* 具体规范请参见[表盘设计指导及规范](https://developer.huawei.com/consumer/cn/doc/content/watch-face-introduction-0000001566918497)。
