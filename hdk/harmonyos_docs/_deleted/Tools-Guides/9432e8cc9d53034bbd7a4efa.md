# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 11.0.14.300 macOS版本如何安装？

因macOS系统原因，打开一些应用文件的时候会失败，同时提示该应用文件"来自身份不明的开发者"，此时需要开启"设置"---"安全与隐私"中的"任何来源"来解决这一问题。

在"Launchpad"---"其他"---"终端"中使用spctl命令：（复制粘贴下面的代码到终端，再回车即可）

sudo spctl --master-disable

回车之后，终端需要用户输入开机锁屏的密码才能开始执行，这里输入密码到password：后面的时候密码是不显示的，输入密码后直接回车即可。

执行上述步骤之后，"允许任何来源"选项就会出现了。选择该选项后即可正常安装11.0.14.300 macOS版本。  

#### 点击截图按钮后查看预览截图不成功？

此问题是截图运算时需要时间，提示截图成功后需要在当前页面等待3-5秒。且目前全景锁屏暂不支持截图生成预览图功能，请制作全景锁屏时手动上传对应的预览图。  

#### 锁屏主题、图标主题、AOD主题无法同步至手机查验？

目前锁屏主题、图标主题、AOD主题暂不支持同步功能，我们会在后续更新支持。  

#### 安装工具后，未覆盖以前的版本？

主题开发工具名称有变动，请先卸载以前的版本工具后，再安装最新版本的主题开发工具。  

#### 如何打开手机USB调试？

在"设置 \> 关于手机"中多次点击"版本号"开启开发者模式，在"设置 \> 系统和更新"中找到"开发人员选项"，打开"USB调试"开关。  

#### 如何刷新工具？

当工具卡顿时，您可以使用Ctrl+R或Command+R刷新工具解决相应问题。  

#### 升级到11.0.13.300及以上版本后，录屏等涉及图片处理功能无法使用？

该版本涉及的开源软件FFmpeg暂时无法发布，请自行备份或下载该软件放到指定目录下即可恢复使用。

Windows系统安装过老版本工具

安装新版本前，去下列路径下备份ffmpeg.exe。安装Theme Studio 11.0.13.300版本后，再次将ffmpeg.exe放置下列路径位置，重启工具。

C:\\Users\\username\\AppData\\Local\\Programs\\ThemeStudio\\resources\\lib

若自定义安装工具，将ffmpeg.exe放置到安装路径ThemeStudio\\resources\\lib下。

Windows系统未安装过老版本工具

未安装过Theme Studio 11.0.13.300之前的版本，或者原版本安装内容被删除，可以下载：[软件包下载](https://github.com/GyanD/codexffmpeg/releases/download/5.1/ffmpeg-5.1-essentials_build.zip)

下载后将压缩包里面ffmpeg.exe解压后放在上述路径下，重启工具即可。

macOS系统安装过老版本工具

已安装过老工具，安装新版本前，去老版本安装程序包，右击并点击"显示包内容"，去路径（Contents/Resources/lib/libmac）下备份ffmpeg.exe。安装新版本后，再次将ffmpeg.exe放置下列路径位置，重启工具。
