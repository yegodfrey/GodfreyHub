# 服务端示例代码

压缩包里面包含了一个Eclipse工程，该工程包含了华为云空间服务端示例代码，供您参考实现华为云空间功能，主要包括以下功能：

* 获取用户信息
* 文件的上传、下载和搜索
* 对文件的评论、回复和查询历史版本
* 云端文件变化的查询、推送通知功能等
