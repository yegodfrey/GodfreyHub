# 示例代码

#### Android Studio示例代码

位置服务SDK提供位置查询服务，帮助您的用户更加方便地使用位置相关服务，以及帮助您快速获取用户，点击[了解更多](https://developer.huawei.com/consumer/cn/codelab/HMSSiteKit/index.html#0)。

该示例代码包含了大多数接口的使用方法，通过该Demo您可以实现：

* 关键字搜索：通过用户输入的关键字，返回地点列表。
* 周边搜索：基于用户设备位置进行地点查找。
* 地点详情：查询某个地点更详细的信息。
* 地点搜索建议：返回一个地点列表，从而实现地点预测功能。

在使用示例代码前请详细阅读示例工程中的"README"文件。您需要完成以下操作后才可以运行示例代码。

1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站下载自己应用的"agconnect-services.json"文件，拷贝到示例工程的应用级根目录下。

2. 修改示例工程中应用级"build.gradle"文件中的"applicationId"为您自己的应用包名。
