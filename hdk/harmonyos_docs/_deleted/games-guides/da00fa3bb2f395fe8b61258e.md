# 下载模型简化结果

模型简化任务执行成功后，您可以将生成的LOD模型下载并运用到游戏场景中。

1. 顶部菜单栏选择"AILOD \> Task History"。 ![](https://media:401781143598916980)

2. 在"Task History"窗口的任务列表中，查看任务执行状态，支持按模型名称模糊匹配查询，或按任务状态查询。 ![](https://media:401781143598948981)

   |参数|描述|
   |:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |Name|模型名称。|
   |Ratio|减面比例。|
   |Start Time|任务创建时间。|
   |Status|任务状态： * Success：任务执行成功，表示可以下载。 * Running：任务执行中，表示AILOD云端正在为原始模型生成LOD模型。您可以点击"Reload"，实时更新任务状态。 * Waiting：任务排队中，表示正在等待其他任务释放计算资源。若无需执行该任务，您可以点击"Cancel"，取消任务。 * Failed：任务执行失败。您可以点击"Delete"，删除任务。|

3. 在"Task History"窗口右侧点击"Download"，一键下载所有"Success"任务简化后的LOD模型。 LOD模型保存目录为"Assets/AILOD Data/{game object名称}_LOD/{面数比例}_{当前时间}"。

   同时，任务列表将自动删除已下载过LOD模型的任务。

   ![](https://media:401781143598982982)
