# 应用升级

您在华为应用市场升级应用后，可以通过华为应用市场提供的静默升级功能，方便、快捷、及时地在应用内提示用户升级应用。您可以在用户启动应用后主动检查新版本，或是提供应用升级检查入口，由用户主动触发升级检查操作，然后您可以调用华为提供的静默升级接口，向用户拉起升级提示框，由用户在华为应用市场完成应用升级。

* 如果您的应用是游戏应用，推荐您使用游戏服务的Game Service SDK的升级接口，具体开发步骤请参见[游戏升级](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/appgallerykit-game-update-0000001055756860)。
* 如果您的应用是非游戏应用，推荐您集成联运应用的App Service SDK的升级接口，具体开发步骤请参见[应用升级](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/appgallerykit-app-update-0000001055118286)。

需要说明的是，如果您的应用是非联运应用，同样可以调用App Service SDK的升级接口，接口使用不受限制。

* 游戏应用支持在发布应用时选择强制升级，非游戏应用不支持。
