# 使用入门

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-:|:---------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404)|在开发应用前，需要完成步骤：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404#section47264296)、[创建项目](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404#section196902382910)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404#section294363472920)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404#section2119133716579)、[获取API key](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404#section169441820428)。 如果您已经在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站创建了应用，可直接[获取API key](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404#section169441820428)使用本服务。|
|2|[Direction API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-diretions-api-introduction-0000001231972971)|提供步行、骑行、驾车路径规划接口。|
|2|[Matrix API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-matrix-api-introduction-0000001232294527)|提供一次计算多组起点和目的地的路线距离和时间计算功能，包括步行，骑行及驾车三种模式。|
|2|[Snap to Roads API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-snap-road-introduction-0000001186814894)|根据延路线收集的坐标点捕捉道路，返回用户实际驾车经过的道路坐标。|
