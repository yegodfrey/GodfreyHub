# 服务配额

地图服务付费API使用限制说明：

1. 同一个接口，一秒内被允许调用的次数（QPS）是固定的，当接口请求的QPS超过配额后，该接口返回错误码信息。
2. 如果您的应用需要修改QPS配额，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)申请修改配额。

#### 付费API默认QPS限制

|API|QPS限制|QPS_IP限制|
|:------------------|:-----------------------------|:------------------|
|Maps_JavaScript_API|100 QPS|1 QPS 每个IP地址每秒1个请求。|
|Directions_API|50 QPS|-|
|DistanceMatrix_API|1000 元素/秒 元素number=起点个数\*终点个数。|-|
|Maps_Static_API|500 QPS|-|
|Tile_API|500 QPS|-|
|Elevation_API|100 QPS|-|
|Roads_API|500 QPS|-|
