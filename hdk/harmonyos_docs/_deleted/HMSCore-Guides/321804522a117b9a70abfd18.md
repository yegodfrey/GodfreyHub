# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### Android SDK

#### 目前Navi Kit各个服务是否支持中国大陆？

支持，支持的范围请参见[支持的国家/地区](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/supported-countries-and-regions-0000001187087820)，如需使用，请联系我们（[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)）申请配额。  

#### 返回错误码010001或010002或010003可能的原因？

* 项目中App ID与[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)上不一致。
* 未配置指纹。需在本地生成签名证书指纹，然后在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置。
* 未配置应用的[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)配置文件，参见[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001214231910)。
* API密钥没有使用encode转码。

#### 如何应对集成SDK时的一些问题？

1. 如果集成6.4.1.301版本导航sdk的同时，在build文件中添加com.google.android.play:core:1.10.3依赖，会出现报错：More than one file was found with OS independent path 'core.properties'。 解决方案：在工程build.gradle中添加如下配置。

   ```
   packagingOptions {
       pickFirst 'core.properties'
   }
   ```

2. 如果集成6.9.0.301或6.10.0.300版本导航sdk的同时，在build文件中添加com.huawei.hms:hquic-provider:5.0.1.300依赖，会出现报错： Manifest merger failed : Attribute meta-data#com.huawei.hms.min_api_level:hquic-provider:huawei_module_quic@value value=(1) from \[com.huawei.hms:hquic-provider:5.0.1.300\] AndroidManifest.xml:17:13-30

   is also present at \[com.huawei.hms:network-embedded:6.0.8.300\] AndroidManifest.xml:35:13-30 value=(2).

   Suggestion: add 'tools:replace="android:value"' to \<meta-data\> element at AndroidManifest.xml:15:9-17:33 to override.

   解决方案：在工程AndroidManifest.xml中的\<application\>添加如下配置。

   ```
   <meta-data
       android:name="com.huawei.hms.min_api_level:hquic-provider:huawei_module_quic"
       android:value="1"
       tools:node="remove" />
   ```

#### REST API

#### 目前Navi Kit各个服务是否支持中国大陆？

支持，支持的范围请参见[支持的国家/地区](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/supported-countries-and-regions-0000001187087820)，如需使用，请联系我们（[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)）申请配额。  

#### 调用Web API返回错误码6的原因？

可能原因是API密钥中包含特殊字符，此时需要对特殊字符编码进行encodeURI编码。例如，原始API密钥：ABC/DFG+ ，转换结果：ABC%2FDFG%2B。  

#### 返回错误码010024的原因？

010024表示接口已经欠费，需要在"我的项目 \> 我的套餐"中对欠费的服务进行充值。  

#### 返回错误码010027的原因？

010027表示未订购付费套餐，有两种可能情况：

1. 您未通过[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)创建项目。检查使用的API密钥是否在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)存在，如果不存在重新到[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)上创建项目和应用，使用应用的API密钥作为认证凭证。
2. 您未升级到付费档。请到"[我的项目](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myProject) \> 我的套餐"，进行套餐升级。  

#### 返回错误码010010的可能原因？

010010表示参数非法，请排查您的URL请求中是否包含非法值、参数是否在取值范围内。
