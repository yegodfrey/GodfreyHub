# 业务简介

情景感知服务（Awareness Kit）为您提供获取用户当前时空、位置、活动状态、音频设备状态、环境光、天气、信标等情景感知组合能力。调用这些能力，您的App可以通过更高效的方式，洞悉用户当前所处的情景，为用户提供更加智慧和贴心的体验。

#### 服务优势

* 融合的感知能力：统一调用，可获取多维度、可持续演进的融合情景感知能力。
* 精确的感知结果：系统软硬件能力结合，从底层获取数据，更精确更高效。
* 更快的响应速度：本地独立芯片处理，云侧服务请求就近响应。
* 更低的系统消耗：感知能力共享，避免各应用与设备各自交互，降低系统开销。与EMUI（或Magic UI）和Kirin芯片配合，可获取更佳性能、速度及低功耗。  

#### Capture API、Barrier API和Donate API

* Capture API Capture API允许您的App请求用户当前状态，如用户当前时间状态、当前位置、活动状态、耳机是否插入。例如，您的App可以在打开时请求用户时间和位置，以便推荐附近适合周末的休闲娱乐活动。

* Barrier API 您的App可以设定情景状态的"围栏"，当用户状态达到预设情景状态时，服务会给您的App发送通知。例如：您可以设定音频设备状态围栏为"连接"，当音频设备成功连接设备后即触发围栏通知；或设定环境光围栏为"小于100lux"，当光照度小于100lux时即触发围栏通知。您可以组合使用情景感知能力的围栏，以达到不同的目的。例如：您可以设定当用户进入预设的商圈范围（地理围栏）且停留超过预设时长（时间围栏）时，为用户推荐附近的服务。

  App注册围栏成功后，由于Awareness Kit的围栏功能支持在系统后台常驻，即使App被关闭，当围栏被触发后，也可以智能启动App，洞悉当前用户所处的实际情景推荐相应的服务。
* Donate API 为了提升用户使用体验，通过规范精细化场景定义，以及场景化能力开放，现接受生态伙伴的服务/应用的标签捐赠。通过推荐前的信息校验，实现更准确的内容表达，吸引用户点击，满足用户一步直达的服务体验。

#### 支持其他方式获取情景感知能力

* 华为快应用：快应用可以通过快应用引擎集成Awareness Kit SDK获取情景感知能力。根据当前用户实际情景状态[调用接口](https://developer.huawei.com/consumer/cn/doc/quickapp-api-awareness)添加、删除或查询围栏。
* 华为推送服务：支持依据当前用户所处的实际情景自动推送消息，您可以基于当前用户实际情景触发消息，精确命中用户不同场景下的不同需求。详情请参见[推送服务开发指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/automated-notifications-0000001051072150)。
