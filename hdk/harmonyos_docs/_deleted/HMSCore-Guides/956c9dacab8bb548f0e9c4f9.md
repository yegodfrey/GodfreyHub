# 血压

此数据记录用户在某时刻的血压，每一条数据都代表该时刻的血压值。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。  

#### OAuth权限

联盟卡片申请的权限名称：健康数据 \> 血压数据

* 读权限：Scopes.HEALTHKIT_BLOODPRESSURE_READ
* 写权限：Scopes.HEALTHKIT_BLOODPRESSURE_WRITE  

#### 原子采样明细数据类型

* 名称：com.huawei.instantaneous.blood_pressure
* Android SDK类型常量：HealthDataTypes.DT_INSTANTANEOUS_BLOOD_PRESSURE

|字段列表|字段描述|Android SDK常量|类型|可选/必选|单位|取值范围|
|:-----------------------|:------|:------------------------------------------|:-----|:----|:---|:---------------------------------------------------------|
|systolic_pressure|收缩压，即高压|HealthFields.FIELD_SYSTOLIC_PRESSURE|double|M|mmHg|\[40.0, 300.0\]|
|diastolic_pressure|舒张压，即低压|HealthFields.FIELD_DIASTOLIC_PRESSURE|double|M|mmHg|\[30.0, 200.0\]|
|sphygmus|脉搏|HealthFields.FIELD_SPHYGMUS|double|O|次/分钟|\[30.0, 180.0\]|
|measurement_anomaly_flag|测量异常事件|HealthFields.FIELD_MEASUREMENT_ANOMALY_FLAG|int|O|-|取值如下： 1：正常 2：测量时未和心脏平齐 3：测量时有轻微抖动 4：测量前没有至少5min休息|
|before_measure_activity|测量前活动|HealthFields.FIELD_BEFORE_MEASURE_ACTIVITY|int|O|-|取值如下： 1：剧烈运动 2：吸烟 3：进食 4：饮酒 5：喝咖啡 6：无活动 7：起床后 8：睡前 100：自定义|
