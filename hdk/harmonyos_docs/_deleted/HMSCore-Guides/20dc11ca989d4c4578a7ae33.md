# 使用入门

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-:|:--------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001097891749)|在开发应用前，需要完成步骤：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001097891749#section47264296)、[创建项目](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001097891749#section18202758185016)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001097891749#section713884517510)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001097891749#section1950881975416)、[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001097891749#section527610250284)。 如果您已经在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站创建了应用，可直接[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001097891749#section527610250284)使用本服务。|
|2|[开通付费](#section1359519285410)|您可以随时变更订阅的按量付费套餐档次。|
|3|[位置搜索](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-place-search-0000001077969370)|提供丰富的位置搜索功能，包括关键字搜索、周边搜索、地点详情、地点搜索建议、自动补全。|
|3|[地理编码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-geocoding-0000001078097838)|提供正地理编码与逆地理编码接口，实现地址信息与经纬度坐标相互转换。|
|3|[获取时区](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-time-zone-0000001078257442)|通过坐标查询所在位置的所处时区。|

#### 开通付费

自2021年1月1日起，位置服务对部分接口制定了收费方案，详情请参见[服务定价](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/about-charging-0000001052557393)。请到"我的项目 \> 我的套餐"，进行套餐升级。
