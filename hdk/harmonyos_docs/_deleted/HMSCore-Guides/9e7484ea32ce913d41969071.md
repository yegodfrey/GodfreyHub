# 开发商品购买

本章节主要介绍接入华为应用内支付的客户端开发步骤，以帮助您快速了解华为应用内支付提供的客户端接口及其使用方法。  

#### 判断是否支持应用内支付

在使用应用内支付之前，您的应用需要向HMS Core（APK）发送[isEnvReady](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section0680174272414)请求，以此判断用户当前登录的华为帐号所在的服务地是否在华为IAP支持结算的国家/地区中。

如果您的应用未接入华为帐号的登录接口，您可以通过该接口完成登录操作。

开发步骤如下：

发起[isEnvReady](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section0680174272414)请求，并设置两个回调监听来接收接口请求的结果。

* 当接口请求成功时，您的应用将获取到一个[IsEnvReadyResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/isenvreadyresult-0000001050137693)实例对象，表示用户当前登录的华为帐号所在的服务地支持IAP。
* 当接口请求失败时，IAP会返回一个Exception对象，若该对象为[IapApiException](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapapiexception-0000001050135656)对象，可使用其[getStatusCode](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132#section32821622269)方法获取此次请求的返回码。

  当返回帐号未登录（[OrderStatusCode.ORDER_HWID_NOT_LOGIN](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-error-code-0000001050746111)）时，可使用[IapApiException](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapapiexception-0000001050135656)对象的[getStatus](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapapiexception-0000001050135656#section9538142335012)方法获取到一个[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象，然后通过[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象的[startResolutionForResult](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132#section04641751152411)方法拉起华为帐号登录页面，此后在Activity的onActivityResult方法中获取结果信息。从onActivityResult返回的Intent对象中解析出returnCode，当returnCode=[OrderStatusCode.ORDER_STATE_SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-error-code-0000001050746111)时，则表示当前帐号所在服务地支持IAP，其他则表示此次请求有异常。  
  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135217.41551785211120213205095069119323:50001231000000:2800:151334C82954DC2E5AE3AE387476CCF038E48BA068ADE91E6A69F6F7A09596B3.png)  
  [Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)不支持序列化，请勿对IAP接口返回的[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象执行序列化操作。  

  ```
  "Java"
  // 获取调用接口的Activity对象
  final Activity activity = getActivity();
  Task<IsEnvReadyResult> task = Iap.getIapClient(activity).isEnvReady();
  task.addOnSuccessListener(new OnSuccessListener<IsEnvReadyResult>() {
      @Override
      public void onSuccess(IsEnvReadyResult result) {
          // 获取接口请求的结果
          String carrierId = result.getCarrierId();
      }
  }).addOnFailureListener(new OnFailureListener() {
      @Override
      public void onFailure(Exception e) {
          if (e instanceof IapApiException) {
              IapApiException apiException = (IapApiException) e;
              Status status = apiException.getStatus();
              if (status.getStatusCode() == OrderStatusCode.ORDER_HWID_NOT_LOGIN) {
                  // 未登录帐号
                  if (status.hasResolution()) {
                      try {
                          // 6666是您自定义的常量
                          // 启动IAP返回的登录页面
                          status.startResolutionForResult(activity, 6666);
                      } catch (IntentSender.SendIntentException exp) {
                      }
                  }
              } else if (status.getStatusCode() == OrderStatusCode.ORDER_ACCOUNT_AREA_NOT_SUPPORTED) {
                  // 用户当前登录的华为帐号所在的服务地不在华为IAP支持结算的国家/地区中
              }
          } else {
              // 其他外部错误
          }
      }
  });
  @Override
  protected void onActivityResult(int requestCode, int resultCode, Intent data) {
      super.onActivityResult(requestCode, resultCode, data);
      if (requestCode == 6666) {
          if (data != null) {
              // 使用parseRespCodeFromIntent方法获取接口请求结果
              int returnCode = IapClientHelper.parseRespCodeFromIntent(data);
          }
      }
  }
  ```

#### 展示商品信息

若您的应用提供[PMS](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-0000001050033062#ZH-CN_TOPIC_0000001050033062__section1229343610526)商品，则需要在华为AppGallery Connect网站上完成商品的配置。商品配置完成后，您需要在您的应用中使用[obtainProductInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section339016011301)接口来获取此类商品的详细信息。

开发步骤如下：

1. 构建请求参数[ProductInfoReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productinforeq-0000001050137777)，发起[obtainProductInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section339016011301)请求并设置OnSuccessListener和OnFailureListener回调监听器以接收接口请求的结果。您需要在[ProductInfoReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productinforeq-0000001050137777)中携带您此前已在华为AppGallery Connect网站上定义并生效的商品ID，并根据实际配置的商品指定其priceType。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135217.70392157817783657733113466512264:50001231000000:2800:6EF1B9070780B9BD23B86F3B8C9E387CBDB358EFE3FF4676E52B512EAA1A159A.png)  
   [obtainProductInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section339016011301)每次只能查询一种类型的商品。

   <br />

2. 当接口请求成功时，IAP将返回一个[ProductInfoResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productinforesult-0000001050137785)对象，您的应用可通过该对象的[getProductInfoList](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productinforesult-0000001050137785#section1349214453915)方法获取到包含了单个商品信息的[ProductInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productinfo-0000001050135784)对象的列表。您可以使用[ProductInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/productinfo-0000001050135784)对象包含的商品价格、名称和描述等信息，向用户展示可供购买的商品列表。

   <br />

   ```
   "Java"
   List<String> productIdList = new ArrayList<>();
   // 查询的商品必须是您在AppGallery Connect网站配置的商品
   productIdList.add("ConsumeProduct1001");
   ProductInfoReq req = new ProductInfoReq();
   // priceType: 0：消耗型商品; 1：非消耗型商品; 2：订阅型商品
   req.setPriceType(0);
   req.setProductIds(productIdList);
   // 获取调用接口的Activity对象
   final Activity activity = getActivity();
   // 调用obtainProductInfo接口获取AppGallery Connect网站配置的商品的详情信息
   Task<ProductInfoResult> task = Iap.getIapClient(activity).obtainProductInfo(req);
   task.addOnSuccessListener(new OnSuccessListener<ProductInfoResult>() {
       @Override
       public void onSuccess(ProductInfoResult result) {
           // 获取接口请求成功时返回的商品详情信息
           List<ProductInfo> productList = result.getProductInfoList();
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           if (e instanceof IapApiException) {
               IapApiException apiException = (IapApiException) e;
               int returnCode = apiException.getStatusCode();
           } else {
               // 其他外部错误
           }
       }
   });
   ```

#### 发起购买

#### 购买PMS商品

[PMS](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-0000001050033062#ZH-CN_TOPIC_0000001050033062__section1229343610526)商品指在华为AppGallery Connect网站上配置的商品，支持消耗型、非消耗型和订阅型商品。您的应用可通过[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)接口发起此类商品的购买请求。开发步骤如下：

1. 构建请求参数[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842)，发起[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)请求。您需要在[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842)中携带您此前已在AppGallery Connect网站上定义并生效的商品ID。当接口请求成功时，您可获取到一个[PurchaseIntentResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentresult-0000001050135852)对象，其[getStatus](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/result-0000001050123085#section32821622269)方法返回了一个[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象，您的应用需要通过[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象的[startResolutionForResult](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132#section04641751152411)方法来启动华为IAP收银台。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135217.97548463581503727613196425308392:50001231000000:2800:450F824C7E77F7FD615C0869DFA79DD50C90E1F996034E86B65C87C1526F63FB.png)  
   [Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)不支持序列化，请勿对IAP接口返回的[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象执行序列化操作。

2. 在您的应用拉起收银台并且当用户完成支付后（成功购买商品或取消购买），华为IAP会通过onActivityResult方式将此次支付结果返回给您的应用。您可以使用[parsePurchaseResultInfoFromIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1317716106377)方法获取包含结果信息的[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseresultinfo-0000001050135886)对象。

   <br />

   * 当用户购买成功时，可从[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseresultinfo-0000001050135886)对象中获取到购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)及其签名数据，您需要使用在华为AppGallery Connect分配的公钥进行签名验证。为避免资金损失，您在验签成功后，必须校验[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的productId、price、currency等信息的一致性，验证一致后发货。验证方法和公钥获取请参见[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。  
     ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135217.95096225760659429777709467209284:50001231000000:2800:6DBD63838F0D8766EC7F031E43FEC6015C902F4DB8AF1545178E3660B1F8620B.png)  
     IAP SDK的[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)类可用于解析[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)字符串，您可使用该类构造一个[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)对象并从该对象中获取相关信息。
   * 用户购买消耗型商品时，如果返回以下支付异常则需要检查是否存在掉单情况，具体请参见[消耗型商品的补单流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/redelivering-consumables-0000001051356573)。
     * 支付失败（OrderStatusCode.ORDER_STATE_FAILED）
     * 已拥有该商品（OrderStatusCode.ORDER_PRODUCT_OWNED)
     * 默认返回码（OrderStatusCode.ORDER_STATE_DEFAULT_CODE）  

       ```
       "Java"
       @Override
       protected void onActivityResult(int requestCode, int resultCode, Intent data) {
           super.onActivityResult(requestCode, resultCode, data);
           if (requestCode == 6666) {
               if (data == null) {
                   Log.e("onActivityResult", "data is null");
                   return;
               }
               // 调用parsePurchaseResultInfoFromIntent方法解析支付结果数据
               PurchaseResultInfo purchaseResultInfo = Iap.getIapClient(this).parsePurchaseResultInfoFromIntent(data);
               switch(purchaseResultInfo.getReturnCode()) {
                   case OrderStatusCode.ORDER_STATE_CANCEL:
                       // 用户取消
                       break;
                   case OrderStatusCode.ORDER_STATE_FAILED:
                   case OrderStatusCode.ORDER_STATE_DEFAULT_CODE:
                   case OrderStatusCode.ORDER_PRODUCT_OWNED:
                       // 检查是否存在未发货商品
                       break;
                   case OrderStatusCode.ORDER_STATE_SUCCESS:
                       // 支付成功
                       String inAppPurchaseData = purchaseResultInfo.getInAppPurchaseData();
                       String inAppPurchaseDataSignature = purchaseResultInfo.getInAppDataSignature();
                       // 使用您应用的IAP公钥验证签名
                       // 若验签成功，必须校验InAppPurchaseData中的productId、price、currency等信息的一致性，验证一致后发货
                       // 若用户购买商品为消耗型商品，您需要在发货成功后调用consumeOwnedPurchase接口进行消耗
                       break;
                   default:
                       break;
               }
           }
       }
       ```

#### 购买非PMS商品

[非PMS商品支付](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-0000001050033062#ZH-CN_TOPIC_0000001050033062__section1229343610526)仅支持消耗型商品和非消耗型商品。您的应用可通过[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16712634155213)接口发起购买请求。开发步骤如下：

1. 构建请求参数[PurchaseIntentWithPriceReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentwithpricereq-0000001054093693)，发起[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16712634155213)请求。

   <br />

   * 当接口请求失败时，您的应用可获取到一个Exception对象。若该异常对象为[IapApiException](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapapiexception-0000001050135656)实例对象，使用其[getStatusCode](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132#section32821622269)方法获取此次请求的返回码，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-error-code-0000001050746111)。当返回下面的几种错误时，需要您进行处理：
     * 未登录（OrderStatusCode.ORDER_HWID_NOT_LOGIN） Iap在[IapApiException](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapapiexception-0000001050135656)对象中携带了一个[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象，可通过其[startResolutionForResult](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132#section04641751152411)方法拉起华为帐号登录页面，用户操作结果通过Activity的onActivityResult方法回调。onActivityResult方法返回的Intent对象中携带的returnCode字段即为登录的结果，您可使用[parseRespCodeFromIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclienthelper-0000001050135910#section1411517214208)方法获取该字段。

2. 在您的应用拉起收银台并且当用户完成支付后，华为IAP会通过onActivityResult方式将这次支付结果返回给您的应用。可使用[parsePurchaseResultInfoFromIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1317716106377)方法获取包含结果信息的[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseresultinfo-0000001050135886)对象。

   * 当用户购买成功时，可从[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseresultinfo-0000001050135886)对象中获取到购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)及其签名数据，您需要使用在华为AppGallery Connect分配的公钥进行签名验证。为避免资金损失，您在验签成功后，必须校验[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的productId、price、currency等信息的一致性，验证一致后发货。验证方法和公钥获取请参见[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。

     IAP SDK的[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)类可用于解析[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)字符串，您可使用该类构造一个[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)对象并从该对象中获取相关信息。
   * 用户购买消耗型商品时，如果返回以下支付异常则需要检查是否存在掉单情况，具体请参见[消耗型商品的补单流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/redelivering-consumables-0000001051356573)。
     * 支付失败（OrderStatusCode.ORDER_STATE_FAILED）
     * 已拥有该商品（OrderStatusCode.ORDER_PRODUCT_OWNED)
     * 默认返回码（OrderStatusCode.ORDER_STATE_DEFAULT_CODE）

#### 确认交易

用户完成一次支付之后，您需要根据购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)的purchaseState字段来判断订单是否已成功支付。若purchaseState为已支付（取值为0），您需要发放相应的商品或提供相应的服务，此后需要向华为IAP发送发货确认请求。

* 对于消耗型商品，您需要从[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125) JSON字符串中解析出purchaseToken信息，用于确认商品的发货状态。

  在成功发货并记录已发货的商品的purchaseToken之后，您的应用需要使用[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口消耗该商品，以此通知华为应用内支付服务器更新商品的发货状态。发送[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16784102213346)请求时，请在请求参数中携带purchaseToken。应用成功执行消耗之后，华为应用内支付服务器会将相应商品重新设置为可购买状态，用户即可再次购买该商品。

* 对于非消耗型商品，华为应用内支付服务器默认返回已确认的购买数据，在用户购买成功之后无需确认交易。您需要在用户购买成功之后持续向用户提供相应的商品服务。具体请参见[提供非消耗型商品对应的服务](#section1752543164411)。
* 对于订阅型商品，在用户购买成功后，无需您额外执行确认交易操作，但需要在订阅生效期间（InAppPurchaseData.subIsvalid = true）持续向用户提供相应的商品服务，具体请参见[提供订阅型商品对应的服务](#section1513211615471)。  

#### 提供非消耗型商品对应的服务

若您的应用为用户提供非消耗型商品，可在应用启动时通过[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section15126153542812)接口获取用户已购的非消耗型商品的购买信息，格式请参见[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)。若返回的购买信息列表不为空，请确认每个购买信息的purchaseState字段。若purchaseState为0，您需要提供相应的商品服务。

开发步骤如下：

1. 使用[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section15126153542812)获取用户已购非消耗型商品的信息。
2. 您的应用需要在请求参数[OwnedPurchasesReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ownedpurchasesreq-0000001050135762)中指定查询的priceType为1。
3. 为避免资金损失，您在验签成功后，必须校验每个[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的productId、price、currency等信息的一致性。验证方法请参考[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。
4. 验证成功后，您可从返回的每个商品信息中解析出purchaseState，用于判断当前商品的购买状态，以此作为您的应用的发货标志。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135218.01641442584336858255032414889608:50001231000000:2800:0C2227DF57B34A1C47957D6B259B0CD90712DD88D34227771B7825A12CD128DA.png)  
IAP SDK的[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)类可用于解析[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)字符串，您可使用该类构造一个[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)对象并从该对象中获取相关信息。  

```
"Java"
// 构造一个OwnedPurchasesReq对象

// priceType: 1：非消耗型商品

// 获取调用接口的Activity对象

// 调用obtainOwnedPurchases接口

task.addOnSuccessListener(new OnSuccessListener<OwnedPurchasesResult>() {
    @Override
    public void onSuccess(OwnedPurchasesResult result) {
```

#### 提供订阅型商品对应的服务

在应用提供服务前，始终应该先判断用户已购的订阅型商品的状态，以决定是否应该提供对应的服务。

可通过下面的方式获取购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)。

* 在商品购买完成后，可以从HMS Core（APK）返回信息里获取[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)的JSON字符串。
* 可以通过IapClient.[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section15126153542812)查询已购的订阅型商品。

对依赖当期续费情况的业务（比如：视频会员），若purchaseState为0且InApppurchaseData.subIsvalid为true，则始终应该为用户提供商品对应的服务。

开发步骤如下：

1. 使用[obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section15126153542812)获取用户已购订阅型商品的信息。您的应用需要在请求参数[OwnedPurchasesReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ownedpurchasesreq-0000001050135762)中指定查询的priceType为2。
2. 为避免资金损失，您在验签成功后，必须校验每个商品购买数据中的productId、price、currency等信息的一致性。验证方法请参考[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。
3. 验证成功后，您可从返回的每个商品购买数据中解析出purchaseState和subIsvalid，用于判断当前商品的购买状态，以此作为您的应用的发货标志。

对其他自定义业务，如果需要往期的续费情况（比如：杂志订阅），可以通过IapClient.[obtainOwnedPurchaseRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section769716459358)查询所有订阅型商品的收据，收据格式同[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)。

* 如果InAppPurchaseData.purchaseState=0，标识该订阅型商品为已购状态。
* 识别从InAppPurchaseData.purchaseTime到InAppPurchaseData.expirationDate这个时间区间，表示商品的有效时间段。

如果订阅型商品为已购状态，且商品有效时间段匹配上您合法的服务提供时间段，则应该提供商品对应的服务。

本质上，所有的订阅型商品都可以通过这种方式去判断是否应该提供服务。
