# 个人数据处理说明

最后修改时间： 2026/1/13

此文档针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

* 华为处理的个人数据清单。
* 指导开发者如何帮助最终用户实现对数据的控制。

#### 1. 华为处理的个人数据清单

|个人资料|使用目的|保留期|
|:---------------|:------------------------------------|:--|
|卡包信息|实现卡、证、券、票、钥匙等各类凭证电子化，并在华为钱包APP进行归集和展示|不存储|
|设备型号、操作系统、应用基本信息|用于判断当前设备是否支持接入的业务|不存储|

#### 2. 指导开发者如何帮助最终用户实现对数据的控制

钱包服务仅保存匿名化后的卡券数据，该数据无法识别到最终用户。因此，华为无法指导开发者如何帮助最终用户实现对数据的控制。
