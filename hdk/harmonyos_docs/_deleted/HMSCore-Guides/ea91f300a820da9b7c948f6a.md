# 业务介绍

导航服务（Navi Kit）主要提供合理的路线规划引擎、精准Turn-By-Turn导航，及其车道级引导，为您的应用带来全平台易用、易懂、易扩展的导航服务。

* [Android](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-brief-introduction-0000001214229560)：导航Android SDK是一套导航开发调用接口，您可以轻松地在自己的Android应用中加入导航相关的功能，包括：路线规划、开始导航等功能。
* [REST](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/service-introduction-0000001258630967)：导航REST API提供HTTP/HTTPS接口，您可以通过HTTP/HTTPS形式发起请求，获取返回JSON格式的数据。
