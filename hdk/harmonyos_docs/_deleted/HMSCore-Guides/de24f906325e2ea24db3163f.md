# 步数

此数据记录用户在一小段时间内的步数值，每一条数据都代表该时间段（开始时间-结束时间）内的累计步数增量。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。  

#### OAuth权限

联盟卡片申请的权限名称：日常活动 \> 步数数据

* 读权限：Scopes.HEALTHKIT_STEP_READ
* 写权限：Scopes.HEALTHKIT_STEP_WRITE  

#### 原子采样明细数据类型

* 名称：com.huawei.continuous.steps.delta
* Android SDK类型常量：DataType.DT_CONTINUOUS_STEPS_DELTA

|字段列表|描述|Android SDK常量|类型|可选/必选|单位|取值范围|
|:----------|:---|:----------------------|:--|:----|:-|:--------------------------------|
|steps_delta|步数增量|Field.FIELD_STEPS_DELTA|int|M|步|1分钟区间：(0, 500\] 1小时区间：(0, 30000\]|

#### 数据开放说明

|开放API|查询及时性|数据源|
|:-------------------------------------------------------------------------------------------------------------------------------|:----|:--------|
|[读取运动健康数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section0447440145418)|10分钟级|手机、手表、手环等|

![](https://media:901788166661857288)  
1. 如果通过[读取运动健康数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section0447440145418)查询步数详情数据为空，请参见FAQ：[查询步数明细数据时，查询不到数据，如何处理](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001467892241#section55161916123115)。
2. 华为智能穿戴设备与运动健康App产生的运动记录数据中不包含步数采样明细数据，仅包含步数统计数据。
3. 插入步数详情数据时，采样点时间间隔必须大于等于1分钟。
4. 如果插入步数详情数据需在运动健康App展示，采样点时间间隔需为1分钟。  

#### 原子采样统计数据类型

* 名称：com.huawei.continuous.steps.total
* Android SDK类型常量：DataType.DT_CONTINUOUS_STEPS_TOTAL

|字段列表|描述|Android SDK常量|类型|可选/必选|单位|
|:-------|:---|:-------------------|:--|:----|:-|
|steps|步数总值|Field.FIELD_STEPS|int|M|步|
|duration|步行时长|Field.FIELD_DURATION|int|O|分钟|
