# 个人数据处理说明

此文档针对华为作为最终用户数据处理者，您作为最终用户数据控制者的数据处理进行说明，包括：

1. 华为处理的个人数据清单。
2. 指导您如何帮助最终用户实现对数据的控制。

#### 华为处理的个人数据清单

最后修改时间：2020/10/27  

|个人数据|处理目的|存留期|
|:---|:-------------------------------------|:-----------------|
|IP地址|用户的IP地址，用于计算用户所属区域（国家/地区），以获得更准确的搜索结果。|数据匿名保存，留存6个月后自动删除。|

#### 指导您如何帮助最终用户实现对数据的控制

搜索服务将在最多6个月内自动删除个人数据，仅保存匿名化后的数据，该数据无法识别到最终用户。因此，华为无法指导您如何帮助最终用户实现对数据的控制。
