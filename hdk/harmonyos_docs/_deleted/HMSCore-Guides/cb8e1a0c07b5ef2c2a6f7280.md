# 错误码

|错误码|描述|解决方法|
|:-----------------------|:----------------------------------------------------------------------------------------------------------|:---------------|
|INDEXFORM_NOT_COMPATIBLE|调用SearchServiceAbility#getIndexFormVersion(String)，当现有索引和底层searchservice支持的索引格式不兼容时会返回这个错误码|setIndexForm重建索引|
|INDEXFORM_NOT_EXISTED|调用SearchServiceAbility#getIndexFormVersion(String)，当IndexForm不存在时会返回这个错误码|/|
|INDEXFORM_VERSION_ERR|调用SearchServiceAbility#setIndexForm(String,int,List)，当设置的版本号小于0时会返回这个错误码。|/|
|INDEXFORM_CONTENT_ERR|调用SearchServiceAbility#updateIndexForms(String,int,List)，当设置IndexForm格式不正确时会返回这个错误码|/|
|INDEXFORM_CONTENT_DIFF|调用SearchServiceAbility#setIndexForm(String,int,List)，当前设置的版本号与之前设置的相同但IndexForm格式不同时会返回这个错误码|/|
|FAIL|调用SearchServiceAbility#setIndexForm(String,int,List)和SearchServiceAbility#clearIndexForm(String)失败时会返回这个状态。|/|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/)提交问题，华为支持人员会及时处理。
