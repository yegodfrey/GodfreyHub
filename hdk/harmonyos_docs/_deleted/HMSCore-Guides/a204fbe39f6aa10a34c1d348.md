# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAccounts)快速体验一个应用的开发过程。  

#### 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上

* 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上

  * minSdkVersion 19及以上
  * targetSdkVersion 34（推荐）
  * compileSdkVersion 34（推荐）
  * Gradle 5.4.1及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：EMUI 3.0及以上的华为手机或Android 4.4及以上的非华为手机  

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:-------------|:-------------------------|:--------------|
|手机、平板、华为智慧屏、车机|EMUI 3.0及以上、Android 4.4及以上|4.0.0.300及以上|

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-tool-0000001096112066)|自动完成： [使用HMS Toolkit快速完成开发准备（推荐）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-tool-0000001096112066)：HMS Toolkit的"Configuration Wizard"为您提供配置向导，借助该工具可将开发准备中的所有步骤自动化完成。|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-tool-0000001096112066)|手动完成： 1. [配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050196065)：在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹、打开相关服务。 2. [集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/as-integration-hms-core-sdk-0000001050436235)：在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。 3. [配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-obfuscation-script-0000001056835760)：编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。 4. [添加权限](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/add-permissions-0000001061128116)：在"AndroidManifest.xml"文件中配置应用所需权限。|
|2|[场景化开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-scenario-summary-0000001115918594)|选择需要的场景进行接入开发。|
|3|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-self-check-0000001050195995)|华为提供对应用自动检查的能力。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/release-application-0000001050196293)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-tool-0000001096112066)了解HMS Toolkit集成Account Kit最佳实践。
