# 健康设备接入FAQ

#### SequenceNumber大小限制

三方设备在回传数据时，测量数据的记录条数sequencenum大小必须限制在1\~65535范围内，超出范围会导致数据存储出错。  

#### 蓝牙标准协议数据回传限制

三方设备使用标准蓝牙协议进行数据回传结束后，必须按照官方标准的方式携带结束符，否则回传数据会出现解析出错。  

#### 测量数据单位匹配限制

三方设备测量完成后传输的数据中，属性和单位必须正确匹配，否则在处理数据解析时会出现错误。
