# FAQ

#### 目前Search Kit各个服务是否支持中国大陆？

Search Kit的搜索数据覆盖不支持中国大陆，所以Search Kit Service功能模块不支持中国大陆，支持的范围请参见[支持的国家/地区](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/regions-0000001056871703)。
