# 设计及部署二维码和 NFC 标签

从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/sport-device-sdk-0000001051809026)的开发套件中获取"一碰联二维码样例及说明"。  

#### 设计标签

图1 二维码标签   
![](https://media:901788166628187641)

* 二维码大小：19mm \* 24mm；
* 二维码内容示例：https://url.cloud.huawei.com/1Lfn1eswP6?a=c\&pid=xxxx\&t=31\&n=Huawei-xxxx\&p=2\&k=x1x2x3x4x5x6  

  |参数|值|
  |:----|:----------------------------------------------------------|
  |pid|ProdID，即产品ID （在开发者联盟注册时可获取到）|
  |t|设备类型，跑步机 -- 31；椭圆机 -- 260；划船机 -- 261；智能单车 -- 259；走步机 -- 264|
  |n|被连接设备的蓝牙广播名称|
  |k|控制跑步机用的解锁码（椭圆机、划船机、智能单车、走步机不支持此参数）， 支持6个0-F的数字，如k=0A34F9|
  |其他参数l|不变|
  [表1 参数]

* 使用在线二维码生成工具生成二维码。

图2 NFC标签

![](https://media:901788166628222642)

* 标签芯片格式：NTAG213
* 标签线圈大小： 19mm \* 24mm（大件设备）；11mm \* 27mm（小件设备）。
* 标签NDEF格式（携带两个NDEF Record，按顺序存放）：
  1. Record1： - mime-type：huawei.sports/address

     - content： ftmp=1\&pid=xxxx\&t=x\&ble=xx:xx:xx:xx:xx:xx\&k=x1x2x3x4x5x6

     Record1参数解释：
     * 标签名是 Android 系统需要读的
     * ftmp=1，表示 ftmp 协议，也就是支持本蓝牙规范的运动设备
     * pid=xxxx，表示ProdID，即产品ID （在开发者联盟注册时可获取到）
     * t=x 表示设备类型。椭圆机 -- 260；划船机 -- 261；智能单车 -- 259；走步机 -- 264；不带此参数默认为跑步机
     * ble=xx:xx:xx:xx:xx:xx；表示蓝牙Mac 地址，后面由分号结尾
     * k=x1x2x3x4x5x6 控制跑步机的解锁码
  2. Record2： - mime-type：AAR

     - content：com.huawei.health

     Record2参数解释：
     * AAR：标准的 Android Application Record 类型定义
     * com.huawei.health： 运动健康App的包名

#### 部署标签

1. 从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/sport-device-sdk-0000001051809026)的开发套件中获取部署工具 sporthealthdeploytool_tool.apk，并安装在手机上。
2. 从开发套件中获取部署工具使用指南，根据使用指南和 sporthealthdeploytool_tool 将蓝牙模块信息写入二维码/NFC标签。

<!-- -->

3. 将标签粘贴在设备上。
