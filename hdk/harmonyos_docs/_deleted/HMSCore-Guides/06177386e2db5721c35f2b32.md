# 版本更新说明

#### 6.13.0.300（2023-09-06）

|----------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:iap:6.13.0.300 修改特性 适配Android 14系统，targetSdkVersion升级到34。|

#### SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）4.0.4.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
