# 开发准备

#### 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。  

#### 创建服务器应用

若您已注册过应用（如：移动应用，智慧屏应用等），且希望同时实现多种场景接入，则无需创建新的，请忽略此章节。

在华为开发者联盟，创建服务器应用，申请接入华为帐号。

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网，点击"管理中心"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220518105502.73947609510254449044350641977261:50001231000000:2800:323295DFE25D4C46BA7D24764EA870F54A81A42CCABA264819644E5CB8D607D2.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
2. 在"管理中心"页面，点击"帐号"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220518105502.83588566834578839371462070416636:50001231000000:2800:C7CE93F38FF377C5BA3182B690AC9F064102F250EFC14EBACF0F3A66DBBBD0C9.png?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
3. 在"帐号"页面，点击"申请帐号服务"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220518105502.22097681934748194119753282275119:50001231000000:2800:58D9D3A355B768073CC2974971FAF41B1D329D17BEBA6B8247E256857F4EA8A8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
4. 选择"服务器应用"，创建产品，配置应用的[回调地址](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/set-redirect-uri-0000001055126949)、访问地址，点击"提交"按钮。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220518105502.31220319810421580136372696032744:50001231000000:2800:6E1E4CB66770BADB510E5F52E83ECD9F524D5C70EACB5A098F5B8933BDCD812C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
