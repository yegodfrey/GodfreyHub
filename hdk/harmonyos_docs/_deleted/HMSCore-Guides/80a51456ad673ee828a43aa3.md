# 一碰联功能测试

1. 在手机上下载并安装最新版华为运动健康App。打开运动健康App，扫描运动设备上的[二维码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/label-0000001050145372)连接运动设备。或者打开手机的蓝牙及 NFC，用手机 NFC 部位碰一碰运动设备上的 NFC 标签，连接运动设备。

   <br />

   图1 连接运动设备   
   ![](https://media:901788166638524833 "点击放大")

   <br />

2. 从开发套件中获取运动设备的功能测试用例。按照测试用例进行测试， 确保所有的用例正常测试通过。

   <br />

   通过被测设备面板进行开始、调节速度、调节坡度、暂停、恢复并持续运动，最后停止。运动过程中的状态、运动数据会实时在App显示。

   ![](https://media:901788166638613834 "点击放大")

   如果运动健康App同时管理了华为心率手表、手环，将同步获取到心率信息（横屏暂时界面）。

   ![](https://media:901788166638729836 "点击放大")

   <br />
