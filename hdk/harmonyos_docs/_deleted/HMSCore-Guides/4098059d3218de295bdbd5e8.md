# 错误码

|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|

|[AWARENESS_TIMEOUT_CODE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/awareness-awarenessstatuscodes-0000001050164539#section2604955151315)|10003|超时错误。例如，更新围栏超时，获取时间属性超时，获取信标状态超时，bind服务连接超时，等待Intent超时等。|当出现超时错误时，请稍后重试。或者强制停止HMS Core之后重试。|

|[AWARENESS_BARRIER_PARAMETER_ERROR_CODE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/awareness-awarenessstatuscodes-0000001050164539#section48611020157)|10006|围栏参数无效错误（addBarrier入参有误）。 可能原因：在注册围栏时，传入参数不合法。例如，注册环境光围栏，要求传入的参数是个浮点数，且必须大于等于0。|在创建围栏时，请注意输入合法的参数，可以查看创建的围栏接口说明。|
|[AWARENESS_REQUEST_ERROR_CODE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/awareness-awarenessstatuscodes-0000001050164539#section1279941161513)|10007|请求参数错误（updateBarriers入参有误）。 可能原因有：在调用updateBarriers接口时，传入了null值或者不合法的参数；服务中没有应用的uid（Android应用程序的标识符），该情况是应用和Awareness服务连接断开或连接失败。|排查是否传入了不合法的参数；若无问题，可能是由于App与Awareness服务连接失败导致的，清理App缓存后重启。|
|[AWARENESS_AGC_FILE_ERROR](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/awareness-awarenessstatuscodes-0000001050164539#section154331442171513)|10008|AGC文件错误。 可能原因有：agconnect-service文件有缺失，比如"service/analytics"下未找到"collector_url"，或"client"下未找到"app_id"，或"client"下未找到"package_name"；agconnect-service文件有错误，比如"collector_url"不正确。|检查应用在AGC上是否有选择数据存储地，若未选择，请选择数据存储地后重新下载agconnect-service.json文件。|
|[AWARENESS_RESULT_INVALID_ERROR](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/awareness-awarenessstatuscodes-0000001050164539#section13838654168)|10009|从Awareness Kit返回的结果无效。例如，获取耳机状态未知。 可能因为是调用快照接口超时，导致返回的结果无效。 在headset快照中出现该问题可能原因：服务未找到设备的音频管理器，无法获取耳机状态。 在ambient快照中出现该问题可能原因：设备缺少光传感器或者服务无法获取设备的光传感器；设备光传感器不灵敏或是周围环境光无变化，从而导致服务获取光照度值超时。|请确认设备的相关功能是否正常。|
