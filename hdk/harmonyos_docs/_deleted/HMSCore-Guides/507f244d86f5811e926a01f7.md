# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 使用融合搜索服务是否收费？

使用融合搜索服务捐赠过来的内容，在搜索结果页不收费，首页"当下"模块需要付费。  

#### 融合搜索的开发周期要多久？

融合搜索开发周期在一周左右。  

#### 融合搜索接入对手机机型是否有要求？

是的，目前融合搜索的调用仅支持华为手机，系统要求HM 3.0及以上。  

#### 数据管理-当切换帐号时，索引数据如何更新？

建议个人帐号数据相关，通过一个域管理，切换帐号时，统一更新，比如关注店铺，浏览历史，加购等。  

#### 数据管理-卸载和清楚缓存，索引数据如何更新？

建议卸载和清存App或全搜缓存数据时，索引批量删除。  

#### 索引数有无限制？

建议索引数不超过1w条；  

#### Item过期时间如何设置？

默认Item过期时间为1个月，为了保障时效性，建议活动、商品类实体自行设定。  

#### 如果gradle版本号低于7.1，如何配置agconnect插件？

当gradle版本号低于7.1时，配置方法略有不同，可参考集成HMS Core SDK（https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050040084#section813910382284）
