# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### Awareness Kit调用异常怎么办？

1. 检查您使用的软、硬件是否满足要求，如ROM版本、手机型号等。
2. 检查是否开启了所需的权限，如调用Location能力时需要开启位置权限。
3. 检查您的网络状态，华为情景感知部分能力对网络有依赖，请检查您的设备是否可以正常连接网络。
4. 如还未解决，请[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)联系华为工程师支撑。  

#### Awareness Kit当前能力无法满足您的需求，您有新需求时应该怎么办？

[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)反馈您的需求。  

#### 哪些感知能力需要云端能力的支持？为何需要云端？

当前版本时间感知能力和天气感知能力需要云端能力的支持。时间感知涉及到工作日/休息日、节假日、日出日落等信息，这些信息在不同国家和地区间有差异，因此需要云端能力的支持。  

#### 是否支持可穿戴设备感知，如智能手表？

Awareness Kit提供的能力能够支持可穿戴Android设备的感知，但由于HMS 4.0未部署于手机以外的设备，所以目前不支持可穿戴设备的感知。  

#### 一个应用在一台手机上可以同时注册的围栏总数不能超过200个，如果业务上要求注册超过200个围栏，有什么方法？

Awareness Kit从1.0.5版本开始支持自动删除较早注册围栏的功能，在注册围栏时可以调用[updateBarriers(BarrierUpdateRequest request, boolean autoRemove)](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrierclient-0000001050162440#section17463542017)，让系统自动删除较早注册的围栏。  

#### 调用功能时出现的10010、10011和10012等状态码代表什么意思？

当您的应用调用Awareness Kit能力时，不仅应用需要获取相应权限，HMS Core也需要获取相应权限。若HMS Core没有获取相应的权限，将返回不同的状态码。

* 10010、10011：HMS Core无位置权限。

* 10012：HMS Core无活动识别权限。

更多状态码信息可参见[AwarenessStatusCodes](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-awarenessstatuscodes-0000001050164539)。  

#### Awareness Kit如何在App进程被回收后重启App？

在亮屏或灭屏场景下，App可以采用PendingIntent重启，当前有3种方式：Activity、Service、Broadcast。

推荐使用静态广播：围栏无论是true还是false，只要围栏状态有改变，PendingIntent都会触发，启动Activity和Service的系统资源消耗相比于广播更大，开发者可以在广播接收器中先做初步逻辑判断，再进行后续逻辑。  

#### 在Android 11上已经安装HMS Core（APK）最新版本，仍然提示升级，如何解决？

Android 11更改了应用查询用户在设备上已安装的其他应用以及与之交互的方式。您应用的targetSdkVersion是30或者更高版本，并且集成的Awareness Kit 3.1.0.300之前版本时，将无法访问HMS Core（APK），并且持续提示升级。

您可以通过以下两种方法解决。

* 方法一： 升级Awareness Kit的SDK版本至3.1.0.300及以上，版本信息请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/version-change-history-0000001050033093)。

* 方法二： 如果不升级SDK，需要在"AndroidManifest.xml"中manifest下添加\<queries\>标签。

  ```
  <manifest ...>
      ...
      <queries>
          <intent>
              <action android:name="com.huawei.hms.core.aidlservice" />
          </intent>
      </queries>
      ...
  </manifest>
  ```
