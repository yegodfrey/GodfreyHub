# 女性生理周期

记录用户在女性生理周期时间段（默认28天）内一天的身体状态，每一条数据代表该女性用户当天的状态。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。  

#### OAuth权限

联盟卡片申请的权限名称：健康数据 \> 生殖数据

* 读权限：https://www.huawei.com/healthkit/reproductive.read
* 写权限：https://www.huawei.com/healthkit/reproductive.write  

#### 女性生理周期数据类型

名称：com.huawei.health.record.menstrual_cycle  

|特征数据字段列表|描述|类型|可选/必选|单位|取值范围|
|:--------|:----|:-----|:----|:-|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
|recordDay|记录时间|int|M|天|\[20140101, 29991231\]|
|status|当日主状态|int|M|-|取值如下： 0：普通状态 1：经期 3：预测经期 4：易孕期|
|subStatus|当日子状态|int|M|-|取值如下： 以一个字节的Bit位代表不同的子状态 Bit 0：代表第一天 Bit 1：代表最后一天 Bit 2：预留 Bit 3：代表排卵日 举例： 0=0000 0000 代表正常的子状态 1=0000 0001 代表第一天 2=0000 0010 代表最后一天 8=0000 1000 代表排卵日|
|timeZone|时区|string|M|-|-|
|remarks|备注|string|O|-|-|

![](https://media:901788166625866606)  
当日状态举例：

* 如status取值为1，subStatus取值为2，则表示当天为经期最后一天；
* 如status取值为4，subStatus取值为1，则表示当天为易孕期第一天。  

#### 关联采样数据说明

女性生理周期记录当前允许关联[月经流量](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reproductive-0000001280598445#section81861238385)、[痛经程度](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reproductive-0000001280598445#section1196365383)、[身体症状](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reproductive-0000001280598445#section3112191016714)健康采样数据类型。
