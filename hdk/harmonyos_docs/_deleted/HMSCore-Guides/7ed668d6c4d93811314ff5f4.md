# 体重

此数据记录用户体重信息。  

#### OAuth权限

联盟卡片申请的权限名称：健康数据 \> 体脂数据

* 读权限：https://www.huawei.com/healthkit/heightweight.read
* 写权限：https://www.huawei.com/healthkit/heightweight.write  

#### 原子采样明细数据类型

* 名称：com.huawei.instantaneous.body_weight

|字段列表|字段描述|类型|可选/必选|单位|取值范围|
|:--------------------|:-----|:----|:----|:-----|:--------------------|
|body_weight|体重|float|M|千克|\[10.00,250.00\]|
|bmi|身体质量指数|float|O|千克/平方米|\[1.0,200.0\]|
|body_fat|体脂量|float|O|千克|\[10.0,250.0\]|
|body_fat_rate|体脂率|float|O|百分比|\[1.0,49.0\]|
|muscle_mass|肌肉量|float|O|千克|(0.1, 150)|
|basal_metabolism|基础代谢|float|O|千卡/天|(0,10000)|
|moisture|水分量|float|O|千克|(0, 500)，保留一位小数|
|moisture_rate|水分率|float|O|百分比|(0.0, 100.0\]，精确到0.1%|
|visceral_fat_level|内脏脂肪等级|float|O|-|\[1.0, 59.0\]，保留一位小数|
|bone_salt|骨盐量|float|O|千克|\[0.5, 5.0\]|
