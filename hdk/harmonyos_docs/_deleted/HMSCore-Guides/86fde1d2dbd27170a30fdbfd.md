# 业务介绍

#### 业务简介

Search Kit通过云侧API方式，全面开放Petal Search搜索能力，使能生态合作伙伴快速构建更好的移动应用搜索体验。

Petal Search是华为基于大数据、AI、NLP自然语言处理等新技术打造的移动搜索引擎，是华为在海外构建HMS生态的根服务。  

#### 场景介绍

搜索服务提供以下使用场景：

* 搜索引擎集成 集成Search Kit的云侧网页（webpage)、图片、视频、新闻搜索API，基于Petal Search的网页搜索、图片、视频、新闻垂域的结果和索引库，帮助您快速构建低成本搜索引擎。

#### 服务优势

* 快捷 将云侧API的搜索能力开放，支持不同应用快速集成Search Kit，构建自身的搜索能力。

* 高效 利用Petal Search构建的全球索引库和数据海量计算，存储资源，您可以快速获取自定义站点的搜索结果。

* 低成本 使用Search Kit搜索引擎和技术平台，您无需关注搜索引擎的技术实现和运行维护，即可在应用中提供搜索能力。

#### 您的职责

* 您对实施和维护您的站点/网站负有专属责任。
* 您对接收最终用户的查询并传递给华为以及您与华为之间任何数据的传递负有专属责任。
* 您负责接受和回应最终用户就他们的查询和他们在您的站点/网站上的活动提出的任何通信和任何修改或删除请求。
* 您的站点/网站向本公司发送的所有查询，均符合本公司提供的技术规范。
