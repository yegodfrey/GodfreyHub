# 取消授权

在实现[获取用户授权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/add-permissions-0000001050069726)后，为了提升应用隐私安全，开发者需要为应用提供入口，供用户取消对应用的授权。  
![](https://media:901788166645239009)  
1. 针对仅支持Android SDK接入的国家和地区（如俄罗斯），不能通过本章节提供的取消授权的方法实现取消授权，请参见[账号取消授权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cancelauthorization-0000001050050857)，实现取消授权。
2. 请注意取消授权接口[cancelAuthorization](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentscontroller-0000001060039068#section622417593110)(boolean deleteData)会取消应用对Health Service Kit的所有授权，若应用想实现取消部分授权，请参见[cancelAuthorization](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentscontroller-0000001060039068#section15306136195313)(String appId, List\<String\> scopes)。
3. 通过调用取消授权可以取消用户的华为账号对该应用的授权，调用静默登录会报2002错误，重新登录会展示授权界面进行授权。
4. 在您的应用未实现取消授权功能前，您可以通过以下方式手动取消对华为运动健康服务的授权：
   * 在"设置 \> 华为账号 \> 隐私中心 \> 控制对您账号的访问"选取您需要取消授权的应用，进行取消授权。
* 在"华为运动健康App \> 我的 \> 隐私管理 \> 数据分享与授权 \> 账号授权应用"选取您需要取消授权的应用，进行取消授权。  

#### 开发步骤

账号取消授权功能涉及应用的关键开发步骤如下：

1. 应用设置取消授权入口，此部分由应用自行开发。
2. 应用调用[cancelAuthorization](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentscontroller-0000001060039068#section622417593110)(boolean deleteData)方法，并处理返回结果。

   <br />

   ```
   // 日志Tag
   private static final String TAG = "HealthKitConsents";

   public void cancelAuthorization(View view) {
       // 1. 获取ConsentsController对象
       // 请注意此处的this为Activity对象
       ConsentsController mConsentsController = HuaweiHiHealth.getConsentsController(this);
       // 2. 是否删除用户数据,true为删除用户数据，false为不删除用户数据
       boolean clearUserData = true;
       // 3. 取消应用全部授权，是否删除用户数据
       Task<Void> task = mConsentsController.cancelAuthorization(clearUserData);
       task.addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void aVoid) {
               Log.i(TAG, "cancelAuthorization success");
               if(clearUserData){
                   Log.i(TAG, "clearUserData success");
               }
           }
       }).addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               Log.e(TAG, "cancelAuthorization exception");
           }
       });
   }
   ```
