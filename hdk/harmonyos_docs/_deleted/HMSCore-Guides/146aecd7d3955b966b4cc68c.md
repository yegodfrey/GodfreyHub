# 女性生理周期

记录用户在女性生理周期时间段（默认28天）内一天的身体状态，每一条数据代表该女性用户当天的状态。  

#### OAuth权限

联盟卡片申请的权限名称：健康数据 \> 生殖数据

* 读权限：Scopes.HEALTHKIT_REPRODUCTIVE_READ
* 写权限：Scopes.HEALTHKIT_REPRODUCTIVE_WRITE  

#### 女性生理周期数据类型

* 名称：com.huawei.health.record.menstrual_cycle
* Android SDK类型常量：HealthDataTypes.DT_HEALTH_RECORD_MENSTRUAL_CYCLE

|特征数据字段列表|描述|Android SDK常量|类型|可选/必选|单位|取值范围|
|:--------|:----|:----------------------------|:-----|:----|:-|:-----------------------------------|
|recordDay|记录时间|HealthFields.FIELD_RECORD_DAY|int|M|天|\[20140101, 29991231\]|
|status|当日主状态|HealthFields.FIELD_STATUS|int|M|-|取值如下： 0：普通状态 1：经期 2：排卵日 3：预测经期 4：易孕期|
|subStatus|当日子状态|HealthFields.FIELD_SUB_STATUS|int|M|-|取值如下： 0：普通状态 1：第一天 2：最后一天|
|timeZone|时区|HealthFields.FIELD_TIME_ZONE|string|M|-|-|
|remarks|备注|HealthFields.FIELD_REMARKS|string|O|-|-|

![](https://media:901788166659658261)  
当日状态举例：

* 如status取值为1，subStatus取值为2，则表示当天为经期最后一天；
* 如status取值为4，subStatus取值为1，则表示当天为易孕期第一天。  

#### 关联采样数据说明

女性生理周期记录当前允许关联[月经流量](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reproductive-health-0000001177336841#section10854141451919)、[痛经程度](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reproductive-health-0000001177336841#section5249141910136)和[身体症状](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reproductive-health-0000001177336841#section3112191016714)健康采样数据类型。
