# 读取历史数据

查询数据时，出于对用户的数据保护，只允许开发者查询在用户授权之后的数据。例如用户是在2022年2月14日授权，那么2022年2月14日之前的数据将不可查询。

如果需要查询用户授权前的数据，开发者需要得到用户"读取历史数据"相关的授权。  
![](https://media:901788166612849445)  
* 当开发者设置的查询时间早于可查询的用户数据时间范围，这将导致查询异常，返回错误码403。
* 当用户未授予应用""读取历史数据"权限时，开发者可查询的用户数据时间范围以用户授权时间为起点。
* 当用户授予应用"读取历史数据"（一周、一月、一年）权限时，开发者可查询的用户数据时间范围从用户授权时间向前推移对应的时间。

对于历史数据的开放，我们支持基于周、月、年三个时间粒度的开放策略，最多可以开放授权前一年的历史数据。建议开发者基于实际使用场景，最小化读取用户历史数据。  

|权限|权限描述|说明|
|:------------------------------------------------------|:-----------------|:---------------|
|https://www.huawei.com/healthkit/historydata.open.week|查看华为运动健康服务前一周的历史数据|只能读取用户授权前一周的历史数据|
|https://www.huawei.com/healthkit/historydata.open.month|查看华为运动健康服务前一月的历史数据|只能读取用户授权前一月的历史数据|
|https://www.huawei.com/healthkit/historydata.open.year|查看华为运动健康服务前一年的历史数据|只能读取用户授权前一年的历史数据|

需要开发者完成以下操作：

1. 在[Health Service Kit卡片](https://developer.huawei.com/consumer/cn/console#/openCard/AppService/1044)上申请"读取历史数据"的相关权限。
2. [生成授权码code](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058#ZH-CN_TOPIC_0000002516518878__li1118518134711)时，在scope中添加上述表格中的权限，供用户在登录华为账号之后为应用授予"读取历史数据"权限。

![](https://media:901788166612879446)  
若用户授予"读取历史数据"权限后未立即生效，建议[取消授权](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/cancel-scopes-0000001059462192)后，再重新触发认证授权流程。
