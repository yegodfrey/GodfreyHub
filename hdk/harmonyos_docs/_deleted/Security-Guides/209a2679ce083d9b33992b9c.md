# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 使用文件分级保护能力需要配置权限吗？

不需要。  

#### 文件分级保护能力有没有版本限制？

目前支持EMUI 11.0及以上版本。  

#### 文件设置不同风险等级后，对应的保护策略有什么不同？

1. 设置文件风险等级为S3或S4，设备在锁屏状态下不可读写文件数据，需解锁后，文件才可进行读写。特例：锁屏下新增文件，对于已经打开的文件可以继续读写，如：邮件附件、锁屏后需下载的电话录音等敏感信息，可设置label为S3，flag为1。
2. 具备锁屏功能的设备，设置文件风险等级为S2，开机首次解锁后，文件数据可读可写。
3. 设置文件风险等级为S1或者S0，设备仅上电后可访问文件数据，防止离线攻击。  

#### 设备设置锁屏密码，锁屏后是否可以对已设置标签的文件数据进行操作？

对于风险等级设置为S3、S4的文件，不推荐锁屏后进行操作。  

#### 设置风险等级的时间点？

推荐在创建空文件后，立刻通过setLabel方法设置文件的风险等级。需要注意，已经设置风险登记标签的文件不允许再次设置。  

#### 是否支持对目录设置风险等级？

不支持。  

#### 设置风险等级，对文件有哪些要求？

目前仅支持对文件设置标签。如果需要对存量文件设置风险等级，推荐文件小于20MB。
