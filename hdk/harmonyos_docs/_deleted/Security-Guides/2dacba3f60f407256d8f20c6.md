# 在Android Studio项目中集成DataSecurity Engine SDK

2. 填写应用名称、包名等，填写完成后，点击"Next"。

#### 添加DataSecurity Engine SDK的依赖库

1. 打开Android Studio项目级build.gradle文件。
2. 添加Maven代码库。
   * 在"allprojects -\> repositories"里面配置DataSecurity Engine的Maven仓地址。
   * 在"buildscript -\> repositories"里面配置DataSecurity Engine的Maven仓地址。

     ```
     allprojects {
         repositories {
             google()
             jcenter()
             // 添加Maven库
             maven {url 'https://developer.huawei.com/repo/'}
         }
     }
     buildscript {
         repositories {
             google()
             jcenter()
             // 添加Maven库
             maven {url 'https://developer.huawei.com/repo/'}
         }
     }
     ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115403.38218209038857794385410399099811:50001231000000:2800:AA5C2EC956DD83129AF5D4ABEC8565188DD5DD674C0FF8E4770FFCD9324BF0E9.png?needInitFileName=true?needInitFileName=true)  
   Maven无法直接在浏览器中打开访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。
3. 打开应用级的build.gradle文件，在"dependencies"中添加如下编译依赖。

   ```
   dependencies {
   implementation 'com.huawei.security:securitykit:{version}'
   }
   ```
