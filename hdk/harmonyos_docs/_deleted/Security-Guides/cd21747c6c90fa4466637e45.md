# 业务介绍

#### 业务简介

钥匙环服务（Keyring）提供凭据管理接口（Credentials Management API），为Android手机、平板提供用户认证凭据本地存储、跨应用、跨形态共享的能力。

钥匙环服务提供了[Android API](https://developer.huawei.com/consumer/cn/doc/Security-References/overview-0000001133344960)、[Web API](https://developer.huawei.com/consumer/cn/doc/Security-References/javascript-overview-0000001214568685)和[快应用API](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-access-keyring-kit-0000001161177180)，应用程序通过集成这些API来使用钥匙环服务。无论调用哪种形式的接口，所有的用户凭据最终都会存储在HMS Core的钥匙环服务中，以便实现统一的凭据管理能力和共享能力。

#### 场景介绍

自动登录

帮助您的应用保存用户认证凭据（简称：凭据），用于实现自动登录功能。

跨应用登录

帮助您的多款App共享凭据。每个应用都可以把凭据保存下来，共享给其它应用使用，因此，用户只需要登录一次，所有应用都可以处于登录状态。

跨形态登录

不但支持在同一种类型的应用间共享凭据，而且支持在Android应用、快应用、Web应用之间共享凭据。  

#### 提供服务

Keyring为您的Android应用、快应用、Web应用提供凭据本地安全存储和凭据共享授权的能力。

凭据本地安全存储

用户登录到您的应用后，您可以把用户的凭据保存在Keyring中，实现自动登录功能。凭据在Keyring中会被加密后存储在设备本地的存储中。保存凭据时，您可以设置读取此凭据的内容时是否通过锁屏密码或生物特征认证用户的身份。

用户下次打开应用时，您可以在Keyring中查找可用的凭据。查找到的凭据可能是本应用存储的凭据，也可能是其它应用授权给本应用使用的凭据。

凭据共享授权

如果您有多个应用，可以把某个应用的凭据授权给其他应用使用，这样，只要用户登录了其中的一个应用，您的所有应用都可以无缝登录。

保存凭据时，您可以设置凭据的共享关系，把凭据共享给其它应用使用。被授权使用凭据的应用可以是Android应用、快应用或者Web应用。
