# 个人数据处理说明

此文档针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

* 华为处理的个人数据清单。
* 指导开发者如何帮助最终用户实现对数据的控制。

#### 华为处理的个人数据清单

|个人数据清单|使用目的|存留期|
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------|
|生物数据：面容|FIDO（Fast Identity Online）Kit作为数据处理者，为用户提供如下能力，常用于免密登录和免密支付场景： BioAuthn本地生物特征认证能力调用Android和EMUI本地认证API，具体指纹和面容采集结果全部保存在端侧TEE（Trust Execution Environment）里，比对也是在端侧TEE里进行，面容和指纹敏感个人数据仅在用户手机端侧安全环境中处理。|面容、指纹只在端侧处理，没有在云端处理和保存。|
|生物数据：指纹|FIDO（Fast Identity Online）Kit作为数据处理者，为用户提供如下能力，常用于免密登录和免密支付场景： BioAuthn本地生物特征认证能力调用Android和EMUI本地认证API，具体指纹和面容采集结果全部保存在端侧TEE（Trust Execution Environment）里，比对也是在端侧TEE里进行，面容和指纹敏感个人数据仅在用户手机端侧安全环境中处理。|面容、指纹只在端侧处理，没有在云端处理和保存。|
|设备数据：设备证书|FIDO2客户端和认证器功能，支持使用外设和手机作为认证器，符合业界FIDO2规范。FIDO设备证书会上传到云端处理，主要用于对注册过程产生的用户公钥进行签名传输和验证签名，华为不做保存。 用户公私钥在注册过程中产生，用户私钥用于认证过程中对认证数据进行签名，保存在端侧TEE的安全存储中，没有任何接口可以直接获取，处理过程绝对安全可靠。|设备证书用于身份验证签名，华为没有保存。|
|密钥：用户私钥|FIDO2客户端和认证器功能，支持使用外设和手机作为认证器，符合业界FIDO2规范。FIDO设备证书会上传到云端处理，主要用于对注册过程产生的用户公钥进行签名传输和验证签名，华为不做保存。 用户公私钥在注册过程中产生，用户私钥用于认证过程中对认证数据进行签名，保存在端侧TEE的安全存储中，没有任何接口可以直接获取，处理过程绝对安全可靠。|用户私钥只在端侧处理，没有在云端处理和保存。|

#### 指导开发者如何帮助最终用户实现对数据的控制

BioAuthn本地生物特征认证能力涉及的面容和指纹敏感个人数据只在手机端侧处理；FIDO2认证能力涉及用户私钥只在端侧处理，设备证书在云端处理主要用于验签，云端没有保存；由数据控制者面向最终用户提供相应的数据主体权利及其相关解释。
