# 业务介绍

#### 业务简介

|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|FIDO提供基于[WebAuthn](https://www.w3.org/TR/webauthn/#webauthn-client)标准的FIDO2线上快速身份验证客户端能力和基于BioAuthn本地生物特征的指纹及面容认证能力。 FIDO2线上快速身份验证客户端： * 支持使用USB、NFC、蓝牙漫游认证器。 * 支持指纹和3D面容的平台认证器。 * 将系统完整性检测结果作为FIDO2认证的前置条件，保障认证结果更安全。 BioAuthn本地生物特征认证： * 将系统完整性检测结果作为使用本地生物特征认证的前置条件，保证生物特征认证更安全。 * 基于密钥校验机制，保障认证结果安全可信。| |

更多关于FIDO的背景知识，可以参见[FIDO规范介绍](https://developer.huawei.com/consumer/cn/doc/Security-Guides/fido-introduction-0000001051069996)。

#### 场景介绍

需要验证使用者是否是应用/服务的合法用户时，可以使用FIDO2线上快速身份验证能力。比如用户登录和用户支付时。

需要在设备本地验证使用者是否是机主时，可以使用BioAuthn本地生物特征认证能力。比如不使用FIDO2能力时，可以使用BioAuthn能力自主实现指纹和面容登录方案。  

#### 提供服务

FIDO2线上快速身份验证客户端：HMS Core开放基于WebAuthn标准的FIDO2客户端能力。

BioAuthn本地生物特征认证：HMS Core提供本地指纹、面容认证开放能力。
