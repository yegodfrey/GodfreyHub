#### SDK依赖说明

使用FIDO2客户端SDK，用户设备上请安装HMS Core（APK）6.1.0.300及以上版本。使用本版本BioAuthn SDK，BioAuthn-androidX SDK，用户设备上请安装HMS Core（APK）6.1.0.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
