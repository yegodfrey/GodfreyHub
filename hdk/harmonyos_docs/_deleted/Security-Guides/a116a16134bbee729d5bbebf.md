# 业务简介

#### 服务简介

iTrustee TEE（Trusted Execution Environment）是华为自主研发的可信执行环境解决方案，基于ARM Trustzone架构提供硬件隔离的程序运行环境，具有高安全、高扩展和高稳定性的特点。  

#### 场景介绍

iTrustee可信执行环境主要应用于对安全性要求较高的业务领域，例如金融、生物识别、数字版权保护、数字认证等。  

#### 服务特点

* 安全：基于ARM Trustzone架构提供硬件隔离的运行环境，包括CPU、运行内存、外围设备等硬件隔离，保障TEE的安全性。
* 方便：iTrustee提供了丰富的API接口。开发者可以轻松地完成安全存储、加解密、可信时钟、可信显示等相关功能的实现。
* 高效：iTrustee提供了等同REE（Rich Execution Environment）CPU的运算能力，保障程序运行的高效性。  

#### 受限说明

手机HarmonyOS 2.0到4.x版本。

仅限于中国大陆地区产品。
