# 使用入门

#### 开发环境

* 安装Android Studio 3.X及以上
* JDK 1.8.211及以上
* 您的应用应满足以下条件：

  * minSdkVersion 19
  * targetSdkVersion 29
  * compileSdkVersion 29
  * Gradle 4.6及以上

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用设备：详情请参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/introduction-0000001051219741#section035694215123)  

#### 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。  

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/login-0000001051659522)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/login-0000001051659522#section1539516833212)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/login-0000001051659522#section9369103155116)。|
|2|[集成本地认证SDK](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/androidstudio-process-0000001051659724)|在开发应用前，您需要将本地认证SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/config-obfuscation-scripts-0000001080325886)|编译APK前需要配置混淆配置文件，避免混淆本地认证SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/add-permissions-0000001129797541)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/app-dev-0000001051501502)|获取人脸识别实例后，调用人脸识别接口。|
|6|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/dev-self-check-0000001083535242)|华为提供对应用自动检查的能力。|
|7|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/release-application-0000001135564557)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|
