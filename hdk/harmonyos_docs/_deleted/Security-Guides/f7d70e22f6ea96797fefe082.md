# APUS浏览器App集成恶意URL检测功能，风险网站检测能力提升20%

#### 前言

APUS浏览器是一款功能丰富、设计简洁智能的浏览器App，用户可在浏览器内快速访问多个网站、下载视频、浏览新闻等。在结合了恶意URL检测功能后，APUS浏览器可以在用户浏览到恶意网站时，及时识别，并发出提醒、帮用户阻断对恶意网站的访问，从而防范被钓鱼、被盗号甚至被种木马的风险。

#### 业务挑战

确保用户在浏览器内的访问安全，对于用户个人隐私信息、财产安全保护至关重要。常见的恶意URL，例如钓鱼链接、假冒仿冒的网站链接，可能会盗取用户账号信息、诱导转账，导致设备被篡改及财产损失等情况发生。因此，APUS浏览器团队面临的挑战是需在App中增加恶意URL检测功能，在用户访问前，快速识别URL是否存在风险。

<br />

APUS浏览器技术负责人表示，"除了不断完善App的智能浏览功能，我们始终关注用户使用过程中的隐私和安全保护问题"，另外，"为了能够长期、持续地为用户提供安全浏览服务，我们需要一种运营简单、成本可控的检测方法。"  

#### 解决方案

"华为恶意URL检测恰好满足了我们这一需求，帮助我们快速评估URL是否存在风险，"APUS技术负责人说。华为开放安全检测服务，提供恶意URL检测等功能，可以检测URL类型是安全无风险、还是钓鱼或恶意软件链接。具体地，当用户在浏览器内访问未知风险的URL前，APUS浏览器App内集成的恶意URL检测，就会快速评估URL风险类型，"如果发现URL存在风险，我们就可以在App界面上作风险提示，并且拦截用户风险访问。"

<br />

"在App中结合恶意URL检测功能后，APUS浏览器对恶意网站的检测能力提升了20%，用户浏览未知URL时的风险大大降低了，"负责人说道，"这一功能集成简单，而且免运营，有助于我们控制安全浏览服务的实现成本。"

<br />

华为安全检测服务的接入，满足了APUS浏览器恶意URL检测能力的需求，帮助其实现了提供快速且安全的浏览服务的目标。  

#### 结果

结合恶意URL检测，APUS浏览器对恶意网站检测能力提升了20%。
