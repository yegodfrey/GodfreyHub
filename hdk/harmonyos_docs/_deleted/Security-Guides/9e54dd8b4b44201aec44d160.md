# 集成本地认证SDK

针对Android Studio开发环境，华为提供了Maven仓集成方式的本地认证SDK。您也可以下载本地认证SDK并集成到工程中。在开始开发前，您需要将本地认证SDK集成到您的Android Studio开发环境中。  

#### 使用Maven仓集成

1. 打开Android Studio项目级"build.gradle"文件，并添加Maven仓地址。

   ```
   allprojects {
       repositories {
           google()
           jcenter()
           /* 添加Maven仓地址 */
           maven {url 'https://developer.huawei.com/repo/'}
       }
   }
   ```

2. 打开模块级的"build.gradle"文件，添加SDK编译依赖。

   ```
   dependencies {
       /* 添加SDK编译依赖 */
       implementation 'com.huawei.security:localauthentication:{version}'
   ```

#### 下载SDK并集成

1. 在华为开发者社区下载华为人脸识别SDK，参见[SDK下载](https://developer.huawei.com/consumer/cn/doc/development/Security-Library/sdk-download-0000001051341710)。
2. 将下载好的"localauthentication-xxx.aar"放在模块目录中的"libs"下。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220524113202.57769888906152985171959912307823:50001231000000:2800:62B0FE85CABA27AED2DD32EF6AB70A921D45721615C7DC02A374C4CF4940D6EB.png?needInitFileName=true?needInitFileName=true)
3. 打开模块级的"build.gradle"文件，添加依赖目录和SDK编译依赖。

   ```
   repositories{
       flatDir{
           /* 添加依赖目录 */
           dirs 'libs'
       }
   }
   dependencies{
       /* 添加SDK编译依赖 */
       implementation(name:'localauthentication-1.1.1',ext:'aar')
   }
   ```
