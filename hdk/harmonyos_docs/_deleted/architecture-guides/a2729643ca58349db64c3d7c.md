# 组件拖拽移动及放大缩小

## 场景介绍

组件拖拽移动及放大缩小是实用工具类应用的高频使用场景之一，如用户可以通过拖拽实现对组件的移动以及放大缩小操作，自定义组件布局。

本示例通过[组合手势](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-combined-gestures)实现组件跟手拖拽移动效果，通过修改[Grid](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-grid)的属性实现组件的放大缩小效果。

## 实现思路

1. 本示例通过[组合手势](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-combined-gestures)实现组件跟手拖拽移动效果，当组件移动到对应位置时刷新组件排列。

   ```ts
   // 手势传出组件移动信息
   .gesture(
     GestureGroup(GestureMode.Sequence,
       LongPressGesture({ repeat: true })
         .onAction((event?: GestureEvent) => {
           if (this.selectedItem === undefined) {
             this.selectedItem = item;
             // 记录拖拽操作的起始坐标
             this.dragStartX = Number(event?.target.area.globalPosition.x) - item.width / 2;
             this.dragStartY = Number(event?.target.area.globalPosition.y) - item.height / 2;
           }
         })
       // ...
       PanGesture({ fingers: 1 })
         // ...
         .onActionUpdate(event => {
           // 记录偏移量
           this.offsetY = event.offsetY;
           this.offsetX = event.offsetX;
           this.getUIContext().animateTo({ curve: curves.interpolatingSpring(0, 1, 400, 38) }, () => {
             this.handleDrag(); // 处理拖拽函数
           })
         })
         // ...
     })
   )
   // ...
   // 将组件移动到首位，刷新组件排列
   let tmp = this.gridItems.splice(index, 1);
   this.gridItems.splice(0, 0, tmp[0]);
   this.positionMode = PositionMode.COLUMNS;
   this.setRowsColumns();
   ```


2. 本示例通过修改组件的宽高，同步修改[Grid](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-grid)的[rowsTemplate](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-grid#rowstemplate)以及[columnsTemplate](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-grid#columnstemplate)参数，实现组件的放大缩小效果。

   ```ts
   // 修改第一、二行的高度
   this.columnsFirstHeightTmp = this.columnsFirstHeight + this.offsetY;
   this.columnsSecondHeightTmp = this.columnsSecondHeight - this.offsetY;
   // ...
   // 同步修改grid的rowsTemplate以及columnsTemplate参数
   this.rowsT = this.columnsFirstHeightTmp + 'fr ' + this.columnsSecondHeightTmp + 'fr ' +
     (this.fullHeightTmp - this.columnsFirstHeightTmp - this.columnsSecondHeightTmp) + 'fr';
   this.columnsT = '1fr';
   ```

## 约束与限制

* 本示例支持API Version 20 Release及以上版本。
* 本示例支持HarmonyOS 6.0.0 Release SDK及以上版本。
* 本示例需要使用DevEco Studio 6.0.0 Release及以上版本进行编译运行。
