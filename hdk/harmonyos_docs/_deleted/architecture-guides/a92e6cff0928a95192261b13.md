# 图片绘制马赛克并保存

## 场景介绍

图片绘制马赛克并保存是拍摄美化类应用的高频使用场景之一，如用户可以通过绘制马赛克遮蔽敏感信息。

本示例基于[Canvas](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-canvas)和[PanGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)实现在图片上绘制马赛克的功能，基于[ComponentSnapshot](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-uicontext-componentsnapshot)和[SaveButton](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-security-components-savebutton)组件实现保存图片的功能。

## 实现思路

1. 通过[PhotoViewPicker](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-photoaccesshelper-photoviewpicker)拉起图库（相册），读取选中图片的数据。
2. 在选中的图片上叠加[Canvas](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-components-canvas-canvas)画布，手指滑动时通过触发[PanGesture](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-gestures-pangesture)事件实时绘制马赛克。

   ```ts
   Stack() {
     Image(this.isPixelMapChange ? this.pixelMapChanged : this.pixelMap)
     if (this.isSelected || this.viewModel.hasDrawn) {
       Canvas(this.viewModel.context)
         .gesture(
           PanGesture()
         )
     }
   }
   .id('mosaic');
   ```

3. 调用[ComponentSnapshot().get](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-uicontext-componentsnapshot#get12)接口根据组件id截取绘制马赛克后的图片，并通过[SaveButton](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-security-components-savebutton)保存图片。

   ```ts
   // 截图
   async screenShot(id: string): Promise<image.PixelMap | undefined> {
     return new Promise((resolve, reject) => {
       this.getUIContext().getComponentSnapshot().get(id, (error: Error, pixmap: image.PixelMap) => {
         if (error) {
           hilog.error(0x0000, 'MainPage', 'Screenshot error:' + error);
           reject(error);
         } else {
           this.isPixelMapChange = true;
           this.pixelMapChanged = pixmap;
           resolve(pixmap);
         }
       }, { scale: 2, waitUntilRenderFinished: true });
     });
   }
   // 保存图片至图库
   SaveButton({ text: SaveDescription.SAVE })
     .width(44)
     .height(27)
     .fontSize(14)
     .fontWeight(500)
     .fontColor(Color.White)
     .backgroundColor('#5291FF')
     .onClick(async (event: ClickEvent, result: SaveButtonOnClickResult) => {
       hilog.info(0X0000, 'testTag', '%{public}s', event.pressure);
       if (result !== SaveButtonOnClickResult.SUCCESS) {
         this.getUIContext().getPromptAction().showToast({ message: $r('app.string.save_failed') });
         return;
       }
       if (!this.viewModel.hasDrawn) {
         this.getUIContext().getPromptAction().showToast({ message: $r('app.string.save_disable') });
         return;
       }
       let screenshotPixelMap: image.PixelMap | undefined = undefined;
       screenshotPixelMap = await this.screenShot('mosaic');
       if (!screenshotPixelMap) {
         return;
       }
       let imagePackerApi: image.ImagePacker = image.createImagePacker();
       let packOpts: image.PackingOption = { format: 'image/png', quality: 98 };
       let arrayBuffer = await imagePackerApi.packToData(screenshotPixelMap, packOpts);
       let helper = photoAccessHelper.getPhotoAccessHelper(this.getUIContext().getHostContext()!);
       let uri = await helper.createAsset(photoAccessHelper.PhotoType.IMAGE, 'png');
       let file = await fileIo.open(uri, fileIo.OpenMode.READ_WRITE | fileIo.OpenMode.CREATE);
       await fileIo.write(file.fd, arrayBuffer);
       await fileIo.close(file.fd);
       this.getUIContext().getPromptAction().showToast({ message: $r('app.string.save_successfully') });
     });
   ```

## 约束与限制

* 本示例支持API Version 20 Release及以上版本。
* 本示例支持HarmonyOS 6.0.0 Release SDK及以上版本。
* 本示例需要使用DevEco Studio 6.0.0 Release及以上版本进行编译运行。

## 权限说明

允许修改用户公共目录的图片或视频文件：[ohos.permission.WRITE_IMAGEVIDEO](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/restricted-permissions#ohospermissionwrite_imagevideo)。
