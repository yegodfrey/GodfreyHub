# 多机位视频播放

## 场景介绍

多机位视频播放是影音娱乐类应用中的典型场景之一，如视频软件页面展示多个窗口视频同时播放。

本示例基于[Video](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-media-components-video)组件展示了主机位和多个副机位视频的播放。

## 实现思路

1. 使用[Video](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-media-components-video)组件创建视频播放组件。

   ```ts
   Video({
     src: $rawfile(this.videoName)
   })
     .autoPlay(true)
     .controls(false)
     .loop(true);
   ```

2. 通过[Grid](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-grid)组件实现多机位视频播放，点击副机位，可切换该副机位与主机位位置。

   ```ts
   VideoComponent({
     videoName: item,
     index: index,
     clearVideoByIndex: (index1: number) => {
       this.clearVideoByIndex(index1);
     }
   }).aspectRatio(16 / 9)
     .onClick(() => {
       if (index === 0) {
         return;
       }
       this.changeIndex(0, index);
     });
   ```

## 约束与限制

* 本示例支持API Version 20 Release及以上版本。
* 本示例支持HarmonyOS 6.0.0 Release SDK及以上版本。
* 本示例需要使用DevEco Studio 6.0.0 Release及以上版本进行编译运行。
