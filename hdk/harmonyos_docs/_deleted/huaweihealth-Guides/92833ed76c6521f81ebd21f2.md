# 查询日常活动状态

查询穿戴设备的日常活动状态。当用户佩戴穿戴设备进行日常活动后，行业应用可以通过本接口查询穿戴设备上记录的日常活动状态和对应活动时长。  
![](https://media:301785133821523103)  
* 不支持并发查询日常活动状态，需等待上一次查询结束后方可进行下一次查询。
* 此接口不可与心率历史数据或者血氧历史数据或者日常活动数据同时查询，需等待上一个任务结束后方可继续查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询日常活动状态。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.FITNESS_STATUS,
         startTime: 1736521200,
         endTime: 1736547600
       }
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 处理查询结果
         console.info(`Succeeded in querying FITNESS_STATUS data, result is ${data}.`);
       }).catch((error: BusinessError) => {
         // 处理查询异常
         console.info(`Failed to query FITNESS_STATUS data, code: ${error.code}, message: ${error.message}.`);
       })
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   ![](https://media:301785133821552104)  
   查询日常活动状态接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时且不少于1分钟。
   * 查询开始时间和当前时间间隔不超过7天（不包含当天）。  
   查询成功并且有日常活动状态数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)\[\]，查询成功日常活动状态数据为空返回\[\]，查询失败抛出BusinessError。

   ```
   // 返回的data样例
   [
       {
           "startTime": 1740367260,
           "endTime": 1740367320,
           "type": "fitnessStatus",
           "fields": {
               "statusType": 3,
               "duration": 1
           }
       },
       ...
   ]
   ```

   ![](https://media:301785133821578105)  
   在返回的日常活动状态数据中，startTime为状态的开始时间，结束时间由startTime+duration计算得出。  

   |返回值|类型|单位|含义|
   |:---------|:-----|:-|:---------------------------------------------------------------------------------------------------------------------------------------|
   |fields|object|-|包含日常活动状态数据对象。|
   |statusType|number|-|活动状态类型，请参考[日常活动状态](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/daily-activity-status-enumeration-0000002372186769)。|
   |duration|number|分钟|此种活动状态持续的时间。|
