# 调测验证

对照如下测试用例，进行功能的验证测试。  

|用例名称|预置条件|步骤|预期结果|
|:----------------------|:----------------------------------------------|:---------------------------------------------------------------------------------------|:----------------------------------------------------------------------------|
|获取正确的证书路径鉴权|1. 智能表安装行业app。 2. 以获取鉴权证书并保存到正确路径下。 3. 智能表已经联网。|1. 调用应用鉴权接口进行鉴权。|步骤1、鉴权通过，返回结果码0。|
|注册服务端连接状态监听|1. 智能表安装行业app。|1. 调用注册服务端连接状态监听接口。|步骤1、注册成功，返回结果码0；后台kill掉相应服务会有相应结果码返回。|
|获取Api Level|1. 智能表安装行业app。|1. 调用接口获取Api Level。|步骤1、返回服务端Api Level值。|
|订阅运动状态|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用订阅运动状态接口。 2. 以室内步行为例，设备开启室内步行。|步骤1、订阅成功，返回结果码0。 步骤2、开启室内步行，行业app收到设备上报的运动状态码15。|
|订阅睡眠状态|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用订阅睡眠状态接口。 2. 改变睡眠状态。|步骤1、订阅成功，返回结果码0。 步骤2、有对应的睡眠状态上报。|
|查询睡眠数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 进行一次午睡，30分钟\<睡眠时长\<2小时。 2. 调用查询睡眠数据接口。 3. 进行一次夜间睡眠，睡眠时长\>2小时。 4. 调用查询睡眠数据接口。|步骤2、有对应午睡睡眠数据返回。 步骤4、有对应夜间睡眠和午睡数据返回。|
|订阅日常活动数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用订阅日常活动数据接口。 2. 进行日常活动，比如散步、爬楼梯。|步骤1、订阅成功，返回结果码0。 步骤2、有对应的日常活动数据上报。|
|查询日常活动数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用查询日常活动数据接口。|步骤1、查询成功，返回日常活动数据。|
|订阅心率数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 设备连续测量心率开关为开。 2. 佩戴手表，调用订阅心率接口。|步骤2、有对应心率数据上报。|
|查询心率数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用查询心率数据接口。|步骤1、查询成功，返回最新一次心率数据。|
|查询静息心率数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，静坐一小时产生静息心率。 2. 调用查询静息心率数据接口。|步骤2、查询成功，返回最新一次静息心率数据。|
|查询心率历史数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，采集心率数据。 2. 调用查询心率历史数据接口。|步骤2、查询成功，返回心率历史数据。|
|查询血氧数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，进行血氧测量。 2. 调用查询血氧数据接口。|步骤2、查询成功，返回最新一次血氧数据。|
|查询压力数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 打开压力自动测量开关，佩戴手表，采集压力数据。 2. 调用查询压力数据接口。|步骤2、查询成功，返回压力数据。|
|查询体温数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，进行体温测量。 2. 调用查询体温数据接口。|步骤2、查询成功，返回最新一次测量的 体温数据。|
|订阅SOS事件|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用订阅SOS事件接口。 2. 连续按手表上键5次。|步骤1、订阅成功，返回结果码0。 步骤2、有SOS事件上报。|
|订阅跌倒事件|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用订阅跌倒事件接口。 2. 戴着手表跌倒。|步骤1、订阅成功，返回结果码0。 步骤2、有跌倒事件上报。|
|拉起血氧测量|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用拉起血氧测量接口，并进行血氧测量。|步骤1、拉起血氧测量成功，返回结果码0，测量结束返回结果码402。|
|拉起体温测量|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用拉起体温测量接口，并进行体温测量。|步骤1、拉起体温测量成功，返回结果码0，返回结果码0，测量结束返回结果码402。|
|拉起锻炼应用|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用拉起锻炼应用接口。|步骤1、拉起锻炼应用成功，返回结果码0。|
|设置设备信息和开关状态|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用设置接口。 2. 以设置用户基本信息接口为例。|步骤2、设置成功，返回结果码0。|
|订阅充电状态、佩戴状态、电量状态、心率告警提醒|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用订阅接口。 2. 以订阅佩戴状态为例，取消佩戴，然后再次佩戴手表。|步骤2、调用订阅佩戴状态接口成功返回结果码0。取消佩戴后接口返回结果码8，wearStatus为2。佩戴手表后接口返回结果码8，wearStatus为1。|
|订阅日常健康数据更新|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用订阅日常健康数据更新接口。 2. 进行日常活动，比如走路500步。|步骤1、订阅成功，返回结果码0。 步骤2、接口返回结果码10，表示日常健康数据更新了。|
|订阅单次运动数据更新|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用订阅单次运动数据更新接口。 2. 进行单次运动，比如户外跑步，跑步100m后结束运动。|步骤1、订阅成功，返回结果码0。 步骤2、接口返回结果码10，表示单次运动数据更新了。|
|订阅实时光传感器（PPG）|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，调用订阅实时光传感器接口。|步骤1、订阅成功，返回结果码0，然后收到PPG传感器数据，接口返回结果码8和PPG传感器数据。|
|查询设备SN|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用查询设备SN接口。|步骤1、查询设备SN成功，返回结果码0和设备SN。|
|查询日常健康数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，开启心率和血氧自动检测，进行日常活动。 2. 调用查询日常健康数据接口。|步骤2、查询日常健康数据成功，返回结果码0和日常健康数据。|
|查询日常活动状态数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，进行日常活动，比如跑步。 2. 调用查询日常活动状态接口。|步骤2、查询日常活动状态数据成功，返回结果码0和日常活动状态数据。|
|查询单次运动数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，打开锻炼应用进行运动，比如户外跑步，跑步大于100m后结束运动。 2. 调用查询单次运动数据接口。|步骤2、查询单次运动数据成功，返回结果码0和单次运动数据。|
|查询脉搏波心律失常分析数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，连接运动健康App后，在运动健康App中激活脉搏波心律失常分析功能。 2. 主动或者被动触发脉搏波心律失常分析测量。 3. 调用查询脉搏波心律失常分析数据接口。|步骤1、激活脉搏波心律失常分析功能成功。 步骤2、测量成功。 步骤3、查询脉搏波心律失常分析数据成功，返回结果码0和脉搏波心律失常分析数据。|
|查询睡眠呼吸暂停数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，连接运动健康App后，在运动健康App中激活睡眠呼吸暂停检测功能。 2. 开启科学睡眠开关，夜间佩戴手表睡觉。 3. 调用查询睡眠呼吸暂停数据接口。|步骤1、激活睡眠呼吸暂停检测功能成功。 步骤3、查询睡眠呼吸暂停数据成功，返回结果码0和睡眠呼吸暂停数据。|
|查询静息热量数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，在手表减脂塑形应用中设定减重目标。 2. 调用查询静息热量数据接口。|步骤2、查询静息热量数据成功，返回结果码0和静息热量数据。|
