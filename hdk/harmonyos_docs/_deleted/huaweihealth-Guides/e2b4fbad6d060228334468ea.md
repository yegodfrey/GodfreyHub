# 注册账号及申请账号服务

1. 注册成为企业开发者并完成实名认证，注册链接详细操作请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
2. 登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/)，点击进入"管理中心"。

   ![](https://media:301785133815031015 "点击放大")

   <br />

3. 点击"应用服务 \> 开发服务 \> 账号 "卡片。 ![](https://media:301785133815076016 "点击放大")

   <br />

   ![](https://media:301785133815133017)  
   如果无"账号"卡片。请点击"开发服务"右侧![](https://media:301785133815168018)图标添加卡片。
4. 点击"申请账号服务"，同意协议后，进入产品信息填写页面。 ![](https://media:301785133815215019)

   <br />

   |项目|填写说明|
   |:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |产品类型|选择"Android移动应用"。|
   |账号接入方式|默认为"SDK接入"。|
   |选择产品|* 如果此前已创建过产品，则从已创建的产品列表里选择。 * 如果未创建： * 请点击"创建产品"。填写如下信息： 图1 创建产品 ![](https://media:301785133815250020 "点击放大") 说明： 请您在创建产品时填写真实应用名称，以免影响后续审核流程。 * 创建成功后，生成应用ID以及密钥信息，用来标识应用。 图2 新建产品成功 ![](https://media:301785133815304021 "点击放大")|
   |应用包名|填写[应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)。如"com.huawei.healthdemoanna"，务必与APK包名一致，提交以后不能修改。|
   |SHA256证书指纹|填写证书指纹。签名证书指纹用于校验应用的真实性。 参见[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/generate-signature-cert-and-fingerprint-0000002372130841#section11131558123616)获取行业APP使用的签名文件的SHA256证书指纹。 注意： * 修改证书指纹后，需要重新[申请Health Industry SDK服务](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/apply-for-health-industry-sdk-service-0000002338292522)，待审核通过后重新下载新的证书。 * 建议开发者优先配置应用的多个应用市场的证书指纹，方便开发者的穿戴设备侧应用与不同应用市场下载的应用进行消息通信。|
   [表1 产品信息参数说明]

5. 点击"提交"，即可完成"账号服务"的开通，接下来请[申请Health Industry SDK服务](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/apply-for-health-industry-sdk-service-0000002338292522)。
