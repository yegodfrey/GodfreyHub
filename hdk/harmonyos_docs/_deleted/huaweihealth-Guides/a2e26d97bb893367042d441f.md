# 久坐提醒开关设置与查询

设置与查询穿戴设备的久坐提醒开关状态。开启久坐提醒开关后，在每天的8:00到21:00，用户每久坐一小时穿戴设备会产生久坐活动提醒。关闭久坐提醒开关后，穿戴设备不会产生久坐活动提醒。  
![](https://media:301785133828302196)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。  
![](https://media:301785133828332197)  
通过此接口设置的久坐提醒开关状态与用户在穿戴设备侧（路径：【活动记录】应用的最后一屏-\>【提醒设置】-\>【久坐提醒】）手动修改的状态会互相覆盖。查询久坐提醒开关状态以最后一次修改为准。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section477121014816)方法设置久坐提醒开关状态。

   <br />

   ```
   // 导入相关模块
   import {IndustryService, industryServiceClient} from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 久坐提醒开关状态值
       let value: boolean = true;
       // 调用Device对象的setSettingInfo方法设置久坐提醒开关状态
       device.setSettingInfo(IndustryService.SettingType.STAND_REMINDER_SWITCH, value).then(() => {
         // 设置久坐提醒开关状态成功
         console.info('Succeeded in setting standReminderSwitch.');
       }).catch((err: BusinessError) => {
         // 设置久坐提醒开关状态失败
         console.error(`Failed to set standReminderSwitch. Code is ${err.code}, message is ${err.message}.`);
       });
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1047641955517)方法查询久坐提醒开关状态。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询久坐提醒开关状态
   device.getSettingInfo(IndustryService.SettingType.STAND_REMINDER_SWITCH).then((result: boolean) => {
     // 查询久坐提醒开关状态成功，打印返回的状态值
     console.info(`Succeeded in getting standReminderSwitch, result is ${result}.`);
   }).catch((err: BusinessError) => {
     // 查询久坐提醒开关状态失败
     console.error(`Failed to get standReminderSwitch. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   <br />
