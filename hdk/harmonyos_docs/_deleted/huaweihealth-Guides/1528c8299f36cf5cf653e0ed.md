# 日志开关设置与查询

设置与查询日志开关状态。开启日志开关后，穿戴设备主动收集行业SDK日志。关闭日志开关后，不再收集行业SDK日志。  
![](https://media:301785133819346067)  
* 日志开关状态默认关闭。
* 当行业应用重启或者穿戴设备重启后，日志开关状态保持不变。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[setLogSwitch](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section191016293374)方法, 设置日志开关。

   <br />

   ```
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 调用industryServiceClient中的setLogSwitch方法, 设置日志开关
   industryServiceClient.setLogSwitch(getContext(this), true).then(() => {
     console.info(`Succeeded in setting logSwitch.`);
   }).catch((err: BusinessError) => {
     console.error(`Failed to set logSwitch. Code is ${err.code}, message is ${err.message}.`);
   })
   ```

   <br />

3. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[isLogEnabled](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section13483104324014)方法, 获取当前日志开关。

   <br />

   ```
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 调用industryServiceClient中的isLogEnabled方法, 获取当前日志开关
   industryServiceClient.isLogEnabled(getContext(this)).then((result)=>{
     console.info(`Succeeded in isLogEnabled, result is ${result}`);
   }).catch((err: BusinessError) => {
     console.error(`Failed to isLogEnabled. Code is ${err.code}, message is ${err.message}.`);
   })
   ```

   <br />
