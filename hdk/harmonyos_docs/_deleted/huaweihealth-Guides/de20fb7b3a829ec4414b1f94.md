# 设置证书路径

行业App设置证书路径后，行业App会在添加设备的时候读取证书内容，访问HEM鉴权地址进行权限校验，只有校验通过之后才会和设备建立配对关系。  
![](https://media:301785133820131080)  
* HEM（HUAWEI Enterprise Manager）是依托华为终端强大的平台和硬件能力提供的移动管理终端设备的解决方案，可以提供对设备的权限授权检测服务。
* 设置证书路径前请先把[证书](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/apply-for-health-industry-sdk-service-0000002338292522#ZH-CN_TOPIC_0000002678163989__li16905940101212)放到行业App开发工程的src/main/assets目录下（如没assets目录，需自行创建），证书文件的后缀为.cer。
* 开发者测试证书存在有效期限制，行业用户测试证书转商用证书后需提醒用户进行一次重新配对连接操作。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)的[getServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getServiceClient-android_content_Context-)方法获取[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952)对象。
2. 调用[setCertPath](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952#ZH-CN_TOPIC_0000002647924358__setCertPath-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法，设置证书路径。

   <br />

   ```
   // 获取ServiceClient对象
   ServiceClient serviceClient = IndustryWear.getServiceClient(this);

   // 填写证书名称，证书名称需要与src/main/assets目录下的证书文件名称保持一致
   String certPath = "industrycer.cer";

   // 设置证书路径
   serviceClient.setCertPath(certPath, new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [表1 ServiceCallback返回值]
