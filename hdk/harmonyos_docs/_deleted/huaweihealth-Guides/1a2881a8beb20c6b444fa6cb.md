# 用户基本信息设置与查询

设置与查询穿戴设备的用户基本信息。用户基本信息包含出生日期、性别、身高以及体重数据。  
![](https://media:301785133824915153)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发App里的用户基本信息给穿戴设备。  
![](https://media:301785133824942154)  
* 在用户没有自行设置过心率区间的情况下，设置用户基本信息时会调用[心率区间设置与查询](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-heart-rate-zones-0000002376514393)的设置接口设置一个默认心率区间。心率区间的最大心率值计算方法为：220 - 用户年龄，当计算的结果小于100时，则为100。心率区间值依次为最大心率的100%，90%，80%，70%，60%，50%，各个区间值四舍五入取整。
* 在用户未设置基本信息时，查询返回错误码9。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section184491929822)方法设置用户基本信息。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造用户基本信息
       let userInfo: IndustryService.UserBasicInfo = {
         dateOfBirth: '20000101',
         gender: IndustryService.Gender.MALE,
         height: 178,
         weight: 77
       }
       // 调用Device对象的setSettingInfo方法设置用户基本信息
       device.setSettingInfo(IndustryService.SettingType.USER_BASIC_INFO, userInfo).then(() => {
         // 设置用户基本信息成功
         console.info(`Succeeded in setting userBasicInfo.`);
       }).catch((err: BusinessError) => {
         // 设置用户基本信息失败
         console.error(`Failed to set userBasicInfo. Code is ${err.code}, message is ${err.message}.`);
       });
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section9399103045119)方法查询用户基本信息。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询用户基本信息
   device.getSettingInfo(IndustryService.SettingType.USER_BASIC_INFO).then((userInfo:IndustryService.UserBasicInfo) => {
     // 查询用户基本信息成功,打印返回的用户基本信息
     console.info(`Succeeded in getting userBasicInfo, result is ${JSON.stringify(userInfo)}.`);
   }).catch((err: BusinessError) => {
     // 查询用户基本信息失败
     console.error(`Failed to get userBasicInfo. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
