# 查询睡眠数据

穿戴设备提供实时监测睡眠与呼吸质量能力，用户入睡（夜间睡眠或者午睡）后，行业应用可以通过本接口查询穿戴设备上记录的睡眠数据。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询睡眠数据的ZSON格式的入参数据。

   <br />

   ```
   {
       "item": "sleepData"
   }
   ```

   <br />

<!-- -->

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询睡眠数据。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient deviceManageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询睡眠数据的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       zsonObject.put("item", "sleepData");
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询睡眠数据
   deviceManageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回最新一次测量到的睡眠数据，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />

<!-- -->

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含睡眠数据。

   <br />

   ```
   data样例：
   {
       "sleepTime":30,
       "napsTime":10,
       "napsStartTime":1680494400,
       "napsEndTime":1680495000,
       "longSleepTime":540,
       "longSleepStartTime":1680444000,
       "longSleepEndTime":1680476400
   }
   ```

   |返回值|取值|含义|
   |:-----------------|:-------|:----------------------|
   |sleepTime|int类型数据|当天睡眠总时长，单位：分钟。|
   |napsTime|int类型数据|零星小睡总时长，单位：分钟。|
   |napsStartTime|long类型数据|零星小睡开始时间，UTC时间戳，单位：秒。|
   |napsEndTime|long类型数据|零星小睡结束时间，UTC时间戳，单位：秒。|
   |longSleepTime|int类型数据|当天夜间睡眠总时长，单位：分钟。|
   |longSleepStartTime|long类型数据|当天夜间睡眠开始时间，UTC时间戳，单位：秒。|
   |longSleepEndTime|long类型数据|当天夜间睡眠结束时间，UTC时间戳，单位：秒。|
   [表2 data返回值]

   ![](https://media:301785133835566315)  
   * 查询时返回当天睡眠数据，此处当天表示前一天晚上20:00到当天晚上20:00的时间段。
   * 当天20:00-24:00产生的睡眠数据在当天20:00-24:00这个时间段查询不到，需要在当天24:00之后方可查询。
   * longSleepTime不包含睡眠过程中的清醒时间，故longSleepStartTime与longSleepEndTime的差值不一定为longSleepTime。

   <br />
