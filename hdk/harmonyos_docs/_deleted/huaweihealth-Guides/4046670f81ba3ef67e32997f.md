# 语言设置与查询

设置与查询穿戴设备的显示语言。  
![](https://media:301785133825941167)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。

<!-- -->

* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的语言给穿戴设备。  
![](https://media:301785133825986168)  
* 设置的语言不是支持的标准语言代码，会出现下列现象：
  * 接口调用成功，穿戴设备语言默认设置为英文。
* 在未设置语言时，查询返回错误码9。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section56514171767)方法设置语言。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 调用Device对象的setSettingInfo方法设置语言
       device.setSettingInfo(IndustryService.SettingType.LANGUAGE, 'en-US').then(() => {
         // 设置语言成功
         console.info('Succeeded in setting language.');
       }).catch((err: BusinessError) => {
         // 设置语言失败
         console.error(`Failed to set language. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section145611048534)方法查询语言。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询语言
   device.getSettingInfo(IndustryService.SettingType.LANGUAGE).then((result: string) => {
     // 查询语言成功，打印返回的语言值
     console.info(`Succeeded in getting language, result is ${result}.`);
   }).catch((err: BusinessError) => {
     // 查询语言失败
     console.error(`Failed to get language. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   <br />
