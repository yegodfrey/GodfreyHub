# 查询逐搏测量（RRI）数据

穿戴设备提供测量RRI能力，用户佩戴设备一段时间后，行业应用可以通过本接口查询穿戴设备上记录的RRI数据。  
![](https://media:301785133844106446)  
* RRI监测频率为10分钟测量一次。RRI测量要求用户处于非活动状态，活动状态下可能不出值。
* 不支持并发查询心率历史数据，需等待上一次查询结束后方可进行下一次查询。
* 此接口不可与血氧历史数据或者日常活动数据或者日常活动状态同时查询，需等待上一个任务结束后方可继续查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询逐搏测量数据的JSON格式的入参数据。

   <br />

   ```
   {
       "item": "rriData"
   }
   ```

   <br />

<!-- -->

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询逐搏测量数据。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询逐搏测量数据的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       jsonObject.put("item", "rriData");
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询逐搏测量数据
   manageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回逐搏测量数据，失败时返回错误信息。|
   [表1 ServiceCallback返回值]

   <br />

<!-- -->

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含逐搏测量数据。

   <br />

   ```
   {
       "dataType": "rriData",
       "totalCount": 1,
       "index": 0,
       "count": 1,
       "dataList": [
           {
               "startTime": 1774409495000,
               "detailData": [
                   {
                       "timestamp": 1774409495000,
                       "rri": 887,
                       "sqi": 100
                   },
                   {
                       "timestamp": 1774409495887,
                       "rri": 898,
                       "sqi": 100
                   },
                   {
                       "timestamp": 1774409496785,
                       "rri": 914,
                       "sqi": 100
                   }
               ]
           }
       ]
   }
   ```

   |返回值|取值|含义|
   |:--------|:-------|:------------------|
   |timestamp|long类型数据|rri数据发生的时间戳。(单位：ms)|
   |rri|int类型数据|rri数据值。|
   |sqi|int类型数据|rri置信度。|
   [表2 data返回值]

   <br />
