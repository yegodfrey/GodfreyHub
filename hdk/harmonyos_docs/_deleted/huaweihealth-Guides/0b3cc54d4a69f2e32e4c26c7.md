# 查询体温数据

穿戴设备提供测量体温能力，用户测量体温后，行业应用可以通过本接口查询穿戴设备上记录的体温数据。  
![](https://media:301785133840798396)  
受周围环境影响，体温测量精度可能会下降。测量结果仅供参考，不作为医疗诊断依据。  
![](https://media:301785133840866397)  
* 需要采集体温数据时，建议在查询时间段内测量一次或数次体温，否则穿戴设备侧可能返回空数据。
* 不支持并发查询体温数据，需等待上一次查询结束后方可进行下一次查询。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[queryHistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section535119272598)方法查询体温数据。

   <br />

   ```
   // 导入相关模块
   import { IndustryService, industryServiceClient } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造查询体温数据参数
       let queryParam: IndustryService.QueryOptions = {
         type: IndustryService.DataType.TEMPERATURE,
         startTime: 1736777580,
         endTime: 1736778180
       };

       // 调用Device对象的queryHistoryData方法查询体温数据
       device.queryHistoryData(queryParam).then((data: IndustryService.HistoryData[]) => {
         // 查询体温数据成功, 打印接口返回的体温数据
         console.info(`Succeeded in querying temperature data, result is ${data}.`);
       }).catch((err: BusinessError) => {
         // 查询体温数据失败
         console.error(`Failed to query temperature data. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   ![](https://media:301785133840943398)  
   查询体温数据接口参数要求：
   * 查询开始时间小于查询结束时间。
   * 查询结束时间不大于当前时间。
   * 查询开始时间和查询结束时间间隔不超过24小时。

   查询成功并且有体温数据返回IndustryService.[HistoryData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1335151184716)\[\]，查询成功体温数据为空返回\[\]，查询失败抛出BusinessError。  
   查询成功返回的体温历史数据样例：

   ```
   [{
       "startTime": 1736777580,
       "endTime": 1736777580,
       "type": "temperature",
       "fields": {
           "skinTemperature": "33.4",
           "bodyTemperature": "37.2"
       }
   },...
   ]
   ```

   |返回值|类型|单位|含义|
   |:--------------|:-----|:-----|:--------|
   |fields|object|-|包含体温数据对象。|
   |skinTemperature|number|摄氏度(℃)|皮肤温度。|
   |bodyTemperature|number|摄氏度(℃)|体内温度（体温）。|
   [表1 返回体温数据说明]

   ![](https://media:301785133841066399)  
   海外版本不支持查询体内温度。
