# 设置心率区间

设置穿戴设备在运动状态下的心率区间。当用户佩戴穿戴设备进行运动时，穿戴设备会根据用户实际心率判断当前所处的心率区间，提示对应的的运动状态。  
![](https://media:301785133837062339)  
* 心率区间由6个按降序排列的心率数值（单位：次/分钟）组成，分别代表最大心率（极限心率上限）、极限心率下限（无氧心率上限）、无氧心率下限（有氧心率上限）、有氧心率下限（燃脂心率上限）、燃脂心率下限（热身心率上限）、热身心率下限。这6个心率数值共组成5个心率区间，分别对应5种运动状态：极限、无氧耐力、有氧耐力、燃脂、热身。
* 设置心率区间会自动向设备下发最大运动心率，最大运动心率取值为心率区间的第一个心率值。
* 此接口和[设置最大运动心率](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-max-heart-rate-0000002372218949)会互相覆盖心率配置信息，设备侧最终的心率相关配置信息按照最后一次下发的配置为准。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于设置心率区间的JSON格式参数。

   <br />

   ```
   {
       "settingKey": "heartRateInterval",
       "settingValue": [210,180,150,120,90,70]
   }
   ```

   |参数|取值|含义|
   |:-----------|:----------------|:------|
   |settingKey|heartRateInterval|心率区间键值。|
   |settingValue|长度为6、降序排列的整数数组|心率区间值。|
   [表1 设置心率区间参数]

   ![](https://media:301785133837096340)  
   * settingValue的取值为一个长度为6、降序排列的整数数组，分别代表最大心率（极限心率上限）、极限心率下限（无氧心率上限）、无氧心率下限（有氧心率上限）、有氧心率下限（燃脂心率上限）、燃脂心率下限（热身心率上限）、热身心率下限。
   * 心率区间数值设置规则：
     * 最大心率 \> 极限心率下限 \> 无氧心率下限 \> 有氧心率下限 \> 燃脂心率下限 \> 热身心率下限。
     * 心率区间各个参数的可选值范围为：最大心率\*30% \~ 最大心率。
     * 最大心率取值范围：\[100, 220\]。

   <br />

4. 调用[set](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__set-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法设置心率区间。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于设置心率区间的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONArray intervalArray = new JSONArray();
       intervalArray.put(210);
       intervalArray.put(180);
       intervalArray.put(150);
       intervalArray.put(120);
       intervalArray.put(90);
       intervalArray.put(70);
       jsonObject.put("settingKey", "heartRateInterval");
       jsonObject.put("settingValue", intervalArray);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用set方法设置心率区间
   manageClient.set(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、2、3、4、5、6、7|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息。|
   [表2 ServiceCallback返回值]
