# 心率过高告警设置与查询

设置与查询穿戴设备在非运动状态下的心率过高告警开关状态和告警阈值（单位：次/分钟）。开启心率过高告警开关后，当穿戴设备检测到心率连续10分钟以上超过告警阈值时，将产生心率过高的告警。关闭心率过高告警开关后，穿戴设备将不会产生心率过高的告警。  
![](https://media:301785133838265356)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的心率过高告警开关状态和告警阈值给穿戴设备。  
![](https://media:301785133838296357)  
* 如果需要启用心率过高告警，请提前开启连续测量心率，参见[连续测量心率模式设置与查询](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/set-and-query-heart-rate-monitoring-mode-0000002342516586)。
* 在未设置心率过高告警时，查询返回错误码9。
* 当关闭心率过高告警开关时，若设置了告警阈值，则不会对告警阈值进行校验，查询返回告警开关为false，告警阈值为设置的告警阈值；若未设置告警阈值，查询返回告警开关为false，告警阈值为null。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1639374991110)方法设置心率过高告警开关和阈值。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 构造设置心率过高告警开关和阈值参数
       let info: IndustryService.AlertSetting = {
         switch: true,
         threshold: 130
       };
       // 调用Device对象的setSettingInfo方法设置心率过高告警开关和阈值
       device.setSettingInfo(IndustryService.SettingType.HIGH_HEART_RATE_ALERT, info).then(() => {
         // 设置心率过高告警开关和阈值成功
         console.info('Succeeded in setting highHeartRateAlert.');
       }).catch((err: BusinessError) => {
         // 设置心率过高告警开关和阈值失败
         console.error(`Failed to set highHeartRateAlert. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section15787757114)方法查询心率过高告警开关和阈值。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询心率过高告警开关和阈值
   device.getSettingInfo(IndustryService.SettingType.HIGH_HEART_RATE_ALERT).then((result: IndustryService.AlertSetting) => {
     // 查询心率过高告警开关和阈值成功，打印返回的心率过高告警开关和阈值
     console.info(`Succeeded in getting highHeartRateAlert, result is ${JSON.stringify(result)}.`);
   }).catch((err: BusinessError) => {
     // 查询心率过高告警开关和阈值失败
     console.error(`Failed to get highHeartRateAlert. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
