# 调测验证

对照如下测试用例，进行功能的验证测试。  

|用例名称|预置条件|步骤|预期结果|
|:--------------|:---------------------------------------|:-----------------------------------------------------------------------------------------|:-------------------------------------|
|监听行业应用与行业服务连接状态|1. 智能表安装行业app。|1. 调用监听行业应用与行业服务连接状态接口。|步骤1、注册监听成功。|
|获取服务端Api Level|1. 智能表安装行业app。|1. 调用获取服务端Api Level接口。|步骤1、获取服务端Api Level成功，返回服务端Api Level。|
|设置正确的证书路径并鉴权|1. 智能表安装行业app。 2. 设置正确的证书路径。 3. 智能表已经联网。|1. 调用鉴权接口进行鉴权。|步骤1、鉴权成功。|
|设置和查询设备信息或开关状态|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用设置接口。 2. 以设置用户基本信息接口为例。 3. 调用查询接口。 4. 以查询用户基本信息接口为例。|步骤2、设置成功。 步骤4、查询成功，返回用户基本信息。|
|查询体温数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，进行体温测量。 2. 调用查询体温数据接口。|步骤2、查询成功，返回体温数据。|
|查询压力数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 打开压力自动测量开关，佩戴手表，采集压力数据。 2. 调用查询压力数据接口。|步骤2、查询成功，返回压力数据。|
|查询心率历史数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，采集心率数据。 2. 调用查询心率历史数据接口。|步骤2、查询成功，返回心率历史数据。|
|查询血氧历史数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，进行血氧测量。 2. 调用查询血氧历史数据接口。|步骤2、查询成功，返回血氧历史数据。|
|查询睡眠历史数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 进行一次午睡，30分钟\<睡眠时长\<2小时。 2. 调用查询睡眠数据接口。 3. 进行一次夜间睡眠，睡眠时长\>2小时。 4. 调用查询睡眠数据接口。|步骤2、有对应午睡睡眠数据返回。 步骤4、有对应夜间睡眠和午睡数据返回。|
|查询睡眠呼吸暂停数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，连接运动健康App后，在运动健康App中激活睡眠呼吸暂停检测功能。 2. 开启科学睡眠开关，夜间佩戴手表睡觉。 3. 调用查询睡眠呼吸暂停数据接口。|步骤3、查询成功，返回睡眠呼吸暂停数据。|
|查询脉搏波心律失常分析数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，连接运动健康App后，在运动健康App中激活脉搏波心律失常分析功能。 2. 主动或者被动触发脉搏波心律失常分析测量。 3. 调用查询查询脉搏波心律失常分析数据接口。|步骤3、查询成功，返回脉搏波心律失常分析数据。|
|订阅心率数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 穿戴设备连续测量心率开关为开。 2. 佩戴手表，调用订阅心率接口。|步骤2、有对应心率数据上报。|
|订阅心率告警数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用订阅心率告警数据。 2. 触发心率告警。|步骤1、订阅成功。 步骤2、有心率告警事件上报。|
|订阅睡眠状态|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 调用订阅睡眠状态接口。 2. 改变睡眠状态。|步骤1、订阅成功。 步骤2、有对应的睡眠状态上报。|
|查询单次运动数据|1. 智能表安装行业app。 2. 行业app已鉴权成功。|1. 佩戴手表，打开锻炼应用进行运动，比如户外跑步，跑步大于100m后结束运动。 2. 调用查询单次运动数据接口。|步骤2、查询成功，返回单次运动数据。|
|订阅运动状态|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 调用订阅运动状态接口。 2. 以室内步行为例，穿戴设备开启室内步行。|步骤1、订阅成功。 步骤2、有运动状态码15上报。|
|订阅单次运动数据更新|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，调用订阅单次运动数据更新接口。 2. 进行单次运动，比如户外跑步，跑步100m后结束运动。|步骤1、订阅成功。 步骤2、有单次运动数据更新事件上报。|
|查询静息热量|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，在手表减脂塑形应用中设定减重目标。 2. 调用查询静息热量数据接口。|步骤2、查询成功，返回静息热量数据。|
|查询当天日常活动汇总数据|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，进行室外步行。 2. 调用查询当天日常活动汇总数据接口。|步骤2、查询成功，返回当天日常活动汇总数据。|
|查询日常活动状态|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，进行日常活动，比如跑步。 2. 调用查询日常活动状态接口。|步骤2、查询成功，返回日常活动状态数据。|
|查询日常活动数据|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，进行日常活动。 2. 调用查询日常活动数据接口。|步骤2、查询成功，返回日常活动数据。|
|订阅日常活动数据更新|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，调用订阅日常活动数据更新接口。 2. 进行日常活动，比如步数达到500步。|步骤1、订阅成功。 步骤2、有日常活动数据更新事件上报。|
|订阅SOS事件|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 调用订阅SOS事件接口。 2. 连续按手表上电源键5次。|步骤1、订阅成功。 步骤2、有SOS事件上报。|
|订阅跌倒事件|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 调用订阅跌倒事件接口。 2. 戴着手表跌倒。|步骤1、订阅成功。 步骤2、有跌倒事件上报。|
|拉起血氧测量|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，调用拉起血氧测量接口，并进行血氧测量。|步骤1、拉起血氧测量成功，测量中返回结果码401，测量结束返回结果码402。|
|拉起体温测量|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 佩戴手表，调用拉起体温测量接口，并进行体温测量。|步骤1、拉起体温测量成功，测量中返回结果码401，测量结束返回结果码402。|
|设置应用息屏不断网|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 设置息屏不断网开关为开。 2. 穿戴设备息屏，查看网络连接。|步骤1、设置成功。 步骤2、行业应用网络连接没有断开。|
|设置应用保活|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 设置保活开关为开。 2. 双击home键，上划移除行业app后台。|步骤1、设置成功。 步骤2、移除成功，立刻重新拉起应用。|
|设置应用开机自启动|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 设置自启开关为开。 2. 重启手表，观察行业app开机是否自启动。|步骤1、设置成功。 步骤2、行业应用开机自启动。|
|设置日志开关|1. 智能表安装行业app 2. 行业app已鉴权成功|1. 调用设置日志开关接口。 2. 调用查询日志开关接口。|步骤1、设置成功。 步骤2、查询成功，返回日志开关状态。|
