# 注册应用与服务的连接状态监听

行业App注册应用与Industry SDK服务端的连接状态监听，注册成功后可以监听服务连接状态的改变。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getServiceClient-android_content_Context-)方法，获取[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952)对象。
2. 调用[registerServiceConnectionListener](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952#ZH-CN_TOPIC_0000002647924358__registerServiceConnectionListener-com_huawei_health_industry_client_callback_ServiceCallback-)方法注册应用与服务的连接状态监听。

   <br />

   ```
   // 获取ServiceClient对象
   ServiceClient serviceClient = IndustryWear.getServiceClient(this);

   // 注册应用与服务的连接状态监听
   serviceClient.registerServiceConnectionListener(new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理连接状态变化信息
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:----------------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、3、8|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|* 0：服务端连接成功 * 1：服务端断开连接|接口调用成功时返回空字符串，失败时返回错误信息，当连接状态发生改变时返回服务端连接状态。|
   [表1 ServiceCallback返回值]
