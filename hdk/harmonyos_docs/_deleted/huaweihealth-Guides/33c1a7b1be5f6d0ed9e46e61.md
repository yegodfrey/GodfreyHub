# 订阅单次运动数据更新

订阅和取消订阅穿戴设备的单次运动数据更新事件。订阅成功后，当穿戴设备单次运动结束后，如果结束时间在订阅时间范围内，上报单次运动数据更新事件。取消订阅后，不再上报单次运动数据更新事件。  
![](https://media:301785133825018155)  
只有在穿戴设备亮屏时才上报单次运动数据更新事件，熄屏时不上报单次运动数据更新事件。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section141971612182616)方法订阅单次运动数据更新。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError, Callback } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 单次运动数据更新事件回调
       let callback: Callback<IndustryService.EventData> = (eventData: IndustryService.EventData) => {
         console.info(`report event: ${JSON.stringify(eventData)}`);
       };
       // 调用Device对象的subscribeEvent方法订阅单次运动数据更新
       device.subscribeEvent(IndustryService.EventType.WORKOUT_UPDATE_EVENT, callback).then(() => {
         // 订阅单次运动数据更新成功
         console.info('Succeeded in subscribing workoutUpdateEvent.');
       }).catch((err: BusinessError) => {
         // 订阅单次运动数据更新失败
         console.error(`Failed to subscribe workoutUpdateEvent. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   <br />

5. 单次运动数据有更新上报信息在Callback\<IndustryService.[EventData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7634104243910)\>中处理。单次运动数据有更新时eventData中包含事件类型（event）和事件状态（status）。

   <br />

   ```
   eventData样例：
   {
     event: 'workoutUpdateEvent',
     status: 10
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |status|10|表示单次运动数据有更新，支持上报更新事件的运动类型与[查询单次运动数据](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/query-workout-data-0000002342516602)支持的运动类型范围一致，请参考：[单次运动类型枚举](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/workout-type-enumeration-0000002381615405)。|
   [表1 事件状态值说明]

   <br />

6. 需要取消订阅时，调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[unSubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section29691015152720)方法取消订阅单次运动数据更新事件。

   <br />

   ```
   // 调用Device对象的unSubscribeEvent方法取消订阅事件。
   // 注意：这里的callback和订阅单次运动数据更新时的callback要为同一个对象。
   device.unSubscribeEvent(IndustryService.EventType.WORKOUT_UPDATE_EVENT, callback).then(() => {
     // 取消订阅单次运动数据更新成功
     console.info('Succeeded in unsubscribing workoutUpdateEvent.');
   }).catch((err: BusinessError) => {
     // 取消订阅单次运动数据更新失败
     console.error(`Failed to unsubscribe workoutUpdateEvent. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   ![](https://media:301785133825052156)  
   取消订阅传入的callback，要求和订阅时传入的callback为同一个对象。
