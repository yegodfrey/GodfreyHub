# 准备开发环境

#### 安装及配置HUAWEI DevEco Studio

1. 运行环境要求 为保证DevEco Studio正常运行，建议您的电脑配置满足如下要求：

   * 操作系统：Windows 10/11 64位或macOS(X86) 11/12/13/14 macOS(ARM) 12/13/14
   * 内存：Windows系统要求16GB及以上，macOS系统要求8GB及以上
   * 硬盘：100GB及以上
   * 分辨率：1280\*800像素及以上
2. 安装及配置过程
   1. 下载及安装DevEco Studio。具体操作请参见[下载软件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/ide-software-download-V5)与[安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/ide-software-install-V5#section1453284218345)。
   2. DevEco Studio安装完成后，可以通过运行Hello World工程来验证环境设置是否正确。具体操作请参见[创建和运行Hello World工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/ide-hello-world-V5)。
3. [配置代理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/ide-environment-config-V5)（可选），部分企业网络受限的情况下，需要配置代理访问网络。
