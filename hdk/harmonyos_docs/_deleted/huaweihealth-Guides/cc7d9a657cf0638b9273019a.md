# 获取服务的API level

Health Industry SDK的每个接口都有对应的API level，比如：0、2。各接口的API level可以查看[API参考文档](https://developer.huawei.com/consumer/cn/doc/health-References/overview-0000001199159886)。

Health Industry SDK客户端和服务端作为两个独立的整体也有对应的API level，是其支持的所有接口的最高API level，比如：客户端有40个接口，这些接口的API level有0、2两个值，则客户端作为一个整体其API level为2。

若服务端的API level比客户端低，则表示客户端的部分接口，服务端不支持，此时开发者需要升级服务端版本。若客户端的API level比服务端低或两者相同，则表示客户端的功能，服务端均支持。  

#### 获取客户端API Level

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getServiceClient-android_content_Context-)方法，获取[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952)对象。
2. 调用[getClientApiLevel](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952#ZH-CN_TOPIC_0000002647924358__getClientApiLevel--)方法获取客户端API Level。

   <br />

   ```
   // 获取ServiceClient对象 
   ServiceClient serviceClient = IndustryWear.getServiceClient(this); 

   // getClientApiLevel方法获取客户端API Level 
   int level = serviceClient.getClientApiLevel();
   ```

   <br />

#### 获取服务端API Level

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getServiceClient-android_content_Context-)方法，获取[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952)对象。
2. 调用[getServiceApiLevel](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952#ZH-CN_TOPIC_0000002647924358__getServiceApiLevel-com_huawei_health_industry_client_callback_ServiceCallback-)方法获取服务端API Level。

   <br />

   ```
   // 获取ServiceClient对象 
   ServiceClient serviceClient = IndustryWear.getServiceClient(this); 

   // getServiceClient方法获取服务端API Level 
   serviceClient.getServiceApiLevel(new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
   	// 处理返回信息 
       }
   });
   ```

   |参数|取值|含义|
   |:---------|:-|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回服务端API Level。|
   [表1 ServiceCallback返回值]

   <br />
