# 蓝牙断连提醒开关设置与查询

设置与查询穿戴设备的蓝牙断连提醒开关状态。开启蓝牙断连提醒开关后，当穿戴设备检测到和终端设备（例如：手机等）拉距断连时，穿戴设备会产生蓝牙断开连接的提醒。关闭蓝牙断连提醒开关后，穿戴设备不会产生蓝牙断连提醒。  
![](https://media:301785133828755203)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。  
![](https://media:301785133828787204)  
设置蓝牙断连提醒开关接口与运动健康App上的蓝牙断连提醒开关（路径：【设备】-\>已连接的【设备卡片】-\>【设备设置】-\>【蓝牙断开提醒】）是互相独立的，必须要同时开启蓝牙断连提醒开关后才生效。两者中有任何一个开关处于关闭状态，蓝牙断连提醒都不生效。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section477121014816)方法设置蓝牙断连提醒开关。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 蓝牙断连提醒开关状态值
       let value: boolean = true;
       // 调用Device对象的setSettingInfo方法设置蓝牙断连提醒开关状态
       device.setSettingInfo(IndustryService.SettingType.BT_DISCONNECTION_REMINDER_SWITCH, value).then(() => {
         // 设置蓝牙断连提醒开关状态成功
         console.info(`Succeeded in setting BTDisconnectionReminderSwitch.`);
       }).catch((error: BusinessError) => {
         // 设置蓝牙断连提醒开关状态失败
         console.info(`Failed to set BTDisconnectionReminderSwitch. Code is ${error.code}, message is ${error.message}.`);
       });
     })
     .catch((error: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${error.code}, message is ${error.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1047641955517)方法查询蓝牙断连提醒开关的状态。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询蓝牙断连提醒开关状态
   device.getSettingInfo(IndustryService.SettingType.BT_DISCONNECTION_REMINDER_SWITCH).then((value: boolean) => {
     // 查询蓝牙断连提醒开关状态成功，打印返回的状态值
     console.info(`Succeeded in getting BTDisconnectionReminderSwitch, value is ${value}.`);
   }).catch((error: BusinessError) => {
     // 查询蓝牙断连提醒开关状态失败
     console.error(`Failed to get BTDisconnectionReminderSwitch. Code is ${error.code}, message is ${error.message}.`);
   });
   ```
