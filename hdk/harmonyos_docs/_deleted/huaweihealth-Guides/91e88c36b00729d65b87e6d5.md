# 心率区间设置与查询

设置与查询穿戴设备在运动状态下的心率区间。当用户佩戴穿戴设备进行运动时，穿戴设备会根据用户实际心率判断当前所处的心率区间，提示对应的的运动状态。  
![](https://media:301785133829301209)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的心率区间给穿戴设备。  
![](https://media:301785133829329210)  
* 心率区间由6个按降序排列的心率数值（单位：次/分钟）组成，分别代表以下含义：最大心率（极限心率上限）、极限心率下限（无氧心率上限）、无氧心率下限（有氧心率上限）、有氧心率下限（燃脂心率上限）、燃脂心率下限（热身心率上限）、热身心率下限。这6个心率数值共组成5个心率区间，分别对应以下5种运动状态：极限、无氧耐力、有氧耐力、燃脂、热身。
* 心率区间数值设置规则：
  * 最大心率 \> 极限心率下限 \> 无氧心率下限 \> 有氧心率下限 \> 燃脂心率下限 \> 热身心率下限
  * 心率区间各个参数的可选值范围为：最大心率\*30% \~ 最大心率
  * 最大心率取值范围：\[100, 220\]
* 在未设置用户基本信息和心率区间时，查询返回错误码9。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section160512211115)方法设置心率区间。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 心率区间
       let value: number[] = [190,171,152,133,114,95];
       // 调用Device对象的setSettingInfo方法设置心率区间
       device.setSettingInfo(IndustryService.SettingType.HEART_RATE_ZONES, value).then(() => {
         // 设置心率区间成功
         console.info(`Succeeded in setting heartRateZones.`);
       }).catch((error: BusinessError) => {
         // 设置心率区间失败
         console.error(`Failed to set heartRateZones. Code is ${error.code}, message is ${error.message}.`);
       });
     })
     .catch((error: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${error.code}, message is ${error.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7856155813595)方法查询心率区间。查询成功时返回数据中包含一个长度为6、降序排列的整数数组，分别代表最大心率（极限心率上限）、极限心率下限（无氧心率上限）、无氧心率下限（有氧心率上限）、有氧心率下限（燃脂心率上限）、燃脂心率下限（热身心率上限）、热身心率下限。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询心率区间
   device.getSettingInfo(IndustryService.SettingType.HEART_RATE_ZONES).then((value: number[]) => {
     // 查询心率区间成功，打印返回的心率区间
     console.info(`Succeeded in getting heartRateZones, value is ${value}.`);
   }).catch((error: BusinessError) => {
     // 查询心率区间失败
     console.error(`Failed to get heartRateZones. Code is ${error.code}, message is ${error.message}.`);
   });
   ```
