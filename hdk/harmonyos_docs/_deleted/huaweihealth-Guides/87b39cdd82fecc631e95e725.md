# 订阅心率数据

订阅和取消订阅穿戴设备佩戴者的心率数据。订阅成功后，当穿戴设备测量到心率数据时上报当前心率。取消订阅后，不再上报心率。  
![](https://media:301785133844674459)  
* 解除佩戴后，穿戴设备会上报一次255。
* 穿戴设备被拿起时，会自动测量，如果穿戴设备发现未佩戴穿戴设备，或者佩戴姿势不对，会上报255。
* 穿戴设备从解佩戴到佩戴时，穿戴设备会上报一次最近的有效心率数据。
* 在心率测量方式设置为智能的情况下，如果穿戴设备处于低活动量、中活动量、中低活动量的状态下，每10分钟上报一次心率数据。
* 在心率测量方式设置为连续测量模式下，每5秒钟上报一次心率数据。
* 在穿戴设备侧订阅心率数据后，熄屏状态下不上报，亮屏状态下才上报。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。

<!-- -->

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[subscribeRealTimeData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section049515146113)方法订阅心率数据。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError, Callback } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 心率数据回调参数
       let callback: Callback<IndustryService.RealTimeData> = (realTimeData: IndustryService.RealTimeData) => {
         console.info(`report heartRate: ${JSON.stringify(realTimeData)}`);
       };
       // 调用Device对象的subscribeRealTimeData方法订阅心率数据
       device.subscribeRealTimeData(IndustryService.RealTimeDataType.HEART_RATE, callback).then(() => {
         // 订阅心率数据成功
         console.info('Succeeded in subscribing heartRate.');
       }).catch((err: BusinessError) => {
         // 订阅心率数据失败
         console.error(`Failed to subscribe heartRate. Code is ${err.code}, message is ${err.message}.`);
       });
     }).catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. 穿戴设备心率数据在Callback\<IndustryService.[RealTimeData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section12262172612114)\>中处理，穿戴设备产生心率数据时realTimeData数据中包含心率数据。

   <br />

   ```
   realTimeData样例：
   {
       "time": 1739411852,
       "errorCode": 0,
       "type": "heartRate",
       "fields": {
           "heartRate": 86
       }
   }
   ```

   |返回值|类型|单位|含义|
   |:--------|:-------------------------------------------|:--|:------------|
   |fields|Record\<string, object \| string \| number\>|-|包含实时数据的对象。|
   |heartRate|number|bpm|当前心率，255为无效值。|
   [表1 返回详细数据字段说明]

   <br />

<!-- -->

6. 需要取消订阅时，调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[unSubscribeRealTimeData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1638711819219)方法取消订阅心率数据。

   <br />

   ```
   // 调用unSubscribeRealTimeData方法取消订阅心率数据。
   // 注意：这里的callback和订阅心率数据时的callback要为同一个对象。
   device.unSubscribeRealTimeData(IndustryService.RealTimeDataType.HEART_RATE, callback).then(() => {
     // 取消订阅心率数据成功
     console.info('Succeeded in unsubscribing heartRate.');
   }).catch((err: BusinessError) => {
     // 取消订阅心率数据失败
     console.error(`Failed to unsubscribe heartRate. Code is ${err.code}, message is ${err.message}.`);
   });
   ```

   ![](https://media:301785133844709460)  
   取消订阅传入的callback，要求和订阅时传入的callback为同一个对象。

   <br />
