# 查询证书路径

查询当前配置的证书路径。  
![](https://media:301785133822135114)  
未设置证书路径时，查询返回错误码9。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)的[getServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getServiceClient-android_content_Context-)方法获取[ServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952)对象。
2. 调用[queryCertPath](https://developer.huawei.com/consumer/cn/doc/health-References/serviceclient-0000001434627952#ZH-CN_TOPIC_0000002647924358__queryCertPath-com_huawei_health_industry_client_callback_ServiceCallback-)方法，查询证书路径。

   <br />

   ```
   // 获取ServiceClient对象
   ServiceClient serviceClient = IndustryWear.getServiceClient(this);

   // 查询证书路径
   serviceClient.queryCertPath(new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 对返回值的处理
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:--------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、9|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用失败时返回错误信息，成功时返回以src/main/assets目录为根目录的相对路径字符串。|
   [表1 ServiceCallback返回值]
