# 订阅SOS事件

订阅和取消订阅穿戴设备的SOS事件。订阅成功后，当穿戴设备判断SOS触发时上报SOS事件。取消订阅后，不再上报SOS事件。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。

<!-- -->

4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[subscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section141971612182616)方法订阅SOS事件。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError, Callback } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // SOS事件回调
       let callback: Callback<IndustryService.EventData> = (eventData: IndustryService.EventData) => {
         // 处理SOS事件
         console.info(`report SOSEvent: ${JSON.stringify(eventData)}`);
       };
       // 调用Device对象的subscribeEvent方法订阅SOS事件
       device.subscribeEvent(IndustryService.EventType.SOS_EVENT, callback).then(() => {
         // 订阅SOS事件成功
         console.info('Succeeded in subscribing SOSEvent.');
       }).catch((err: BusinessError) => {
         // 订阅SOS事件失败
         console.error(`Failed to subscribe SOSEvent. Code is ${err.code}, message is ${err.message}.`);
       });
     })
     .catch((err: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${err.code}, message is ${err.message}.`);
     });
   ```

   <br />

5. SOS事件信息在Callback\<IndustryService.[EventData](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7634104243910)\>中处理，eventData中包含事件类型（event）和事件状态（status）。

   <br />

   ```
   eventData样例：
   {
     event: 'SOSEvent',
     status: 10
   }
   ```

   |返回值|取值|含义|
   |:-----|:-|:---------|
   |status|10|表示发生SOS事件。|
   [表1 事件状态值说明]

   <br />

6. 需要取消订阅时，调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[unSubscribeEvent](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section29691015152720)方法取消订阅SOS事件。

   <br />

   ```
   // 调用Device对象的unSubscribeEvent方法取消订阅SOS事件。注意：这里的callback和上述订阅SOS事件回调要为同一个对象
   device.unSubscribeEvent(IndustryService.EventType.SOS_EVENT, callback).then(() => {
     // 取消订阅SOS事件成功
     console.info('Succeeded in unsubscribing fallDetectedEvent.');
   }).catch((err: BusinessError) => {
     // 取消订阅SOS事件失败
     console.error(`Failed to unsubscribe fallDetectedEvent. Code is ${err.code}, message is ${err.message}.`);
   });
   ```
