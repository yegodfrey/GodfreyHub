# 查询每日静息热量消耗目标

穿戴设备提供体重管理功能，包括热量缺口评估、热量消耗监测及热量摄入记录。行业应用可通过本功能查询穿戴设备记录的每日静息热量消耗目标数据。  
![](https://media:301785133833728281)  
* 使用此接口前，需在手表端打开减脂塑型应用。若未打开应用，手表端将不会产生相关数据。
* 静息热量数据产生时间为每日00:00:00，因此查询时间需从00:00:00开始。
* 本接口返回的静息热量值为每日静息热量消耗目标（如果有运动包括运动后的静息热量消耗）。
* 不支持并发查询静息热量消耗目标，需等待上一次查询结束后方可进行下一次查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000001434945524#ZH-CN_TOPIC_0000002678163945__getDeviceManageClient-android_content_Context-)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693)对象。
2. 参见[获取设备列表](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/get-device-list-0000002372216449)章节，获取已配对的穿戴设备列表，并从设备列表中选定需要操作的设备，获取设备Id。
3. 构造用于查询每日静息热量消耗目标的JSON格式参数。

   <br />

   ```
   {
       "item":"dailyRestingCaloriesGoal",
       "value":
       {
           "startTime":1773158400,
           "endTime":1773213674
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:----------|:------|
   |startTime|UTC时间戳，单位：秒|查询开始时间。|
   |endTime|UTC时间戳，单位：秒|查询结束时间。|
   [表1 查询每日静息热量消耗目标参数]

   ![](https://media:301785133833755282)  
   接口要求查询开始时间和当前时间间隔不超过7天（不包含今天），且查询数据结束时间不超过当前时间戳。

   <br />

4. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000001485104693#ZH-CN_TOPIC_0000002648084250__query-java_lang_String-java_lang_String-com_huawei_health_industry_client_callback_ServiceCallback-)方法查询每日静息热量消耗目标。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(this);

   // 参考获取设备列表获取设备列表后选择需要操作的设备，获取设备Id
   String deviceId = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx";

   // 构造用于查询每日静息热量消耗目标的JSON格式的入参数据
   JSONObject jsonObject = new JSONObject();
   try {
       JSONObject valueObject = new JSONObject();
       valueObject.put("startTime", 1773158400);
       valueObject.put("endTime", 1773213674);
       jsonObject.put("item", "dailyRestingCaloriesGoal");
       jsonObject.put("value", valueObject);
   } catch (JSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询每日静息热量消耗目标
   manageClient.query(deviceId, jsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String result) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:----------------|:---------------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、6、7、11、30|接口调用结果返回码，参见[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002372870401)中的通用返回码。|
   |result|-|接口调用成功时返回每日静息热量消耗目标，失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />

5. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回result数据中包含每日静息热量消耗目标。

   <br />

   ```
   result样例：
   {
     "dataType": "dailyRestingCaloriesGoal",
     "totalCount": 4,
     "index": 0,
     "count": 4,
     "dataList": [
       {
         "startTime": 1678434120,
         "dailyRestingCaloriesGoal": 1817
       },
       ...
     ]
   }
   ```

   |返回值|取值|含义|
   |:-----------------------|:----------------------------------------|:--------------------|
   |dataType|dailyRestingCaloriesGoal|数据类型标识|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一个数据点在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|包含以下字段：startTime、dailyRestingCaloriesGoal|具体数据信息列表。|
   |startTime|long类型数据|数据产生的时间戳，UTC时间，单位：秒。|
   |dailyRestingCaloriesGoal|int类型数据|每日静息热量消耗目标，单位：千卡。|
   [表3 result返回值]
