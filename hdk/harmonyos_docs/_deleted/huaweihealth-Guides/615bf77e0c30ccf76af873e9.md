# 查询日常活动状态

查询穿戴设备用户的日常活动状态。当用户佩戴穿戴设备进行日常活动后，行业应用可以通过本接口查询穿戴设备上记录的日常活动状态和对应活动时长。  
![](https://media:301785133831881251)  
* 不支持并发查询日常活动状态，需等待上一次查询结束后方可进行下一次查询。
* 此接口不可与日常健康数据同时查询，需等待上一个任务结束后方可继续查询。

1. 调用[IndustryWear](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824)中的[getDeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/industrywear-0000002412777824#section181164592527)方法，获取[DeviceManageClient](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073)对象。
2. 构造用于查询日常活动状态的ZSON格式的入参数据。

   <br />

   ```
   {
       "item":"fitnessStatus",
       "value":
       {
           "startTime":1678671036,
           "endTime":1678696236
       }
   }
   ```

   |参数|取值|含义|
   |:--------|:----------|:-------------|
   |startTime|UTC时间戳，单位：秒|查询日常活动状态的开始时间。|
   |endTime|UTC时间戳，单位：秒|查询日常活动状态的结束时间。|
   [表1 查询日常活动状态参数]

   ![](https://media:301785133831927252)  
   * 接口要求查询开始时间和结束时间间隔不超过24小时且不少于1分钟，查询开始时间和当前时间间隔不超过7天。
   * 建议查询开始与结束时间传入整分的秒级时间戳，活动状态的持续时间以分为单位。

   <br />

3. 调用[query](https://developer.huawei.com/consumer/cn/doc/health-References/devicemanageclient-0000002446217073#ZH-CN_TOPIC_0000002678004135__getServiceClient-android_content_Context-)方法查询日常活动状态。

   <br />

   ```
   // 获取DeviceManageClient对象
   DeviceManageClient manageClient = IndustryWear.getDeviceManageClient(getContext());

   // 构造用于查询日常活动状态的ZSON格式的入参数据
   ZSONObject zsonObject = new ZSONObject();
   try {
       ZSONObject valueObject = new ZSONObject();
       valueObject.put("startTime", 1678671036);
       valueObject.put("endTime", 1678696236);
       zsonObject.put("item", "fitnessStatus");
       zsonObject.put("value", valueObject);
   } catch (ZSONException e) {
       e.printStackTrace();
   }

   // 调用query方法查询日常活动状态
   manageClient.query(zsonObject.toString(), new ServiceCallback() {
       @Override
       public void onResult(int statusCode, String data) {
           // 处理查询结果
       }
   });
   ```

   |返回值|取值|含义|
   |:---------|:------------|:--------------------------------------------------------------------------------------------------------------|
   |statusCode|0、1、2、3、5、6、7|接口调用结果返回码，参考[返回码](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/errorcode-0000002447302129)。|
   |data|-|接口调用成功时返回日常活动状态，失败时返回错误信息。|
   [表2 ServiceCallback返回值]

   <br />

4. 接口调用后返回的信息在ServiceCallback的onResult方法中处理，查询成功时返回data数据中包含日常活动状态。

   <br />

   ```
   data样例：
   {
     "dataType": "fitnessStatus",
     "totalCount": 4,
     "index": 0,
     "count": 4,
     "dataList": [
       {
         "statusType": 1,
         "startTime": 1678434120,
         "duration": 1
       },
       ...
     ]
   }
   ```

   |返回值|取值|含义|
   |:---------|:----------------------------------------------------------------------------------------------------------------------------------------|:----------------------|
   |dataType|fitnessStatus|日常活动状态标识。|
   |totalCount|int类型数据|当前数据类型的数据总条数。|
   |index|int类型数据|本次返回的第一个数据点在所有数据中的下标。|
   |count|int类型数据|本次返回的记录条数。|
   |dataList|包含以下字段：statusType、startTime、duration|具体数据信息列表。|
   |statusType|int类型数据，参见[日常活动状态枚举](https://developer.huawei.com/consumer/cn/doc/huaweihealth-Guides/daily-activity-status-enumeration-0000002372186769)|活动状态类型。|
   |startTime|long类型数据|当前数据点的开始时间戳，UTC时间，单位：秒。|
   |duration|int类型数据|此种活动状态持续的时间，单位：分。|
   [表3 data返回值]

   ![](https://media:301785133831958253)  
   * 如果单次调用回调方法时返回数据超过1M，会自动将本次待返回数据进行分页，数据分页后每一页数据将单独调用回调方法返回。
   * 当单次返回的数据中 index+count=totalCount 时，说明当前类型的数据已经全部查询完成。
   * 设备为HUAWEI WATCH H7546，此接口不再返回睡眠相关状态信息。

   <br />
