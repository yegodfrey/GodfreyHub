# 科学睡眠开关设置与查询

设置与查询穿戴设备的科学睡眠开关状态。开启科学睡眠开关后，在用户睡眠期间，穿戴设备将实时监测睡眠与呼吸质量。关闭科学睡眠开关后，穿戴设备将不会监测睡眠与呼吸质量。  
![](https://media:301785133829381211)  
* 穿戴侧行业SDK与手机侧行业SDK设置接口会相互冲突造成错误的结果，请避免两侧SDK对相同设置接口的使用。
* 穿戴侧行业SDK设置接口结果并不会同步到手机侧行业SDK，相应接口的设置-查询请保持在同一侧的SDK。
* 如果穿戴设备连接了运动健康App，穿戴设备断连后重新连接，运动健康App会下发自己的科学睡眠开关状态给穿戴设备。  
![](https://media:301785133829405212)  
在未设置科学睡眠开关时，查询返回错误码9。

1. 导入相关模块。
2. 调用[industryServiceClient](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section7749131442313)中的[getDeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section17822141183313)方法获取[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象。
3. 调用[DeviceManager](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section2045012381872)对象的[getDevices](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section1558035984613)方法获取穿戴设备列表。
4. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)对象的[setSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section988418811913)方法设置科学睡眠开关。

   <br />

   ```
   // 导入相关模块
   import { industryServiceClient, IndustryService } from '@huawei-cbg/health-industry-sdk';
   import { BusinessError } from '@ohos.base';

   // 通过industryServiceClient获取DeviceManager对象，然后通过DeviceManager对象获取Device对象
   industryServiceClient.getDeviceManager(getContext(this)).getDevices().then(devices => devices?.[0])
     .then((device: IndustryService.Device) => {
       // 科学睡眠开关状态值：true代表开启科学睡眠开关，false为关闭
       let value: boolean = true;
       // 调用Device对象的setSettingInfo方法设置科学睡眠开关状态
       device.setSettingInfo(IndustryService.SettingType.TRU_SLEEP_SWITCH, value).then(() => {
         // 设置科学睡眠开关状态成功
         console.info(`Succeeded in setting TruSleepSwitch.`);
       }).catch((error: BusinessError) => {
         // 设置科学睡眠开关状态失败
         console.error(`Failed to set TruSleepSwitch. Code is ${error.code}, message is ${error.message}.`);
       });
     })
     .catch((error: BusinessError) => {
       // 获取穿戴设备列表失败
       console.error(`Failed to get devices. Code is ${error.code}, message is ${error.message}.`);
     });
   ```

   <br />

5. 调用[Device](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section4106204316283)的[getSettingInfo](https://developer.huawei.com/consumer/cn/doc/health-References/industryservice-0000002441251357#section15162172713563)方法查询科学睡眠开关的状态。

   <br />

   ```
   // 调用Device对象的getSettingInfo方法查询科学睡眠开关状态
   device.getSettingInfo(IndustryService.SettingType.TRU_SLEEP_SWITCH).then((value: boolean) => {
     // 查询科学睡眠开关状态成功，打印返回的状态值
     console.info(`Succeeded in getting TruSleepSwitch, value is ${value}.`);
   }).catch((error: BusinessError) => {
     // 查询科学睡眠开关状态失败
     console.error(`Failed to get TruSleepSwitch. Code is ${error.code}, message is ${error.message}.`);
   });
   ```

   <br />
