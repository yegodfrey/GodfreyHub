# 生成自有账号凭据

开发者在接入AppGalleryConnect（简称AGC）认证服务时，除了需要对接非托管第三方账户，还可能需要对接开发者自己的自有账户，认证服务的Server SDK提供了将开发者的自建账户快速对接AGC认证服务的能力。

自有账户对接AGC认证服务，需要提供自有账号凭据JWT(Json Web Token)。  

#### 前提条件

您需要在您的开发工程中集成认证服务的Server SDK以及完成初始化，请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-integration-sdk-0000001333298505)。

<br />

#### 开发步骤

1. 调用[AGCAuth.generateKey](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/auth-serversdk-agcauth-0000001055003341#section178115201893)生成公私钥。  
   ![](https://media:201778133488585774)  
   公私钥仅需要生成一次保存好即可，无需多次调用。

   ```
   RSAKeyPair rsaKeyPair = agcAuth.generateKey();
   ```

   其中:
   * 私钥为[rsaKeyPair.getPrivateKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/auth-serversdk-rsakeypair-0000001055763280#section107961446101911)，在生成JWT时使用。
   * 公钥为[rsaKeyPair.getPublicKey()](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/auth-serversdk-rsakeypair-0000001055763280#section16471141391915)，需要配置到自有账号页面中，参见[2](#ZH-CN_TOPIC_0000001054048961__li9994755191615)。
2. 登录AppGallery Connect，在"开发与服务"下"云开发（Serverless）\> 认证服务"页面中点击"自有账号"后的"启用"。

   ![](https://media:201778133488634775 "点击放大")

   在输入框中配置上一步生成的公钥：

   ![](https://media:201778133488663776)
3. 调用[AGCAuth.sign](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/auth-serversdk-agcauth-0000001055003341#section16263156912)生成JWT。

   ```
   AGCAuthJwtToken token = agcAuth.sign(UID, DISPLAYNAME, PHOTOURL, privateKey);
   ```

   参数说明：  

   |参数|必选(M)/可选(O)|类型|说明|
   |:----------|:----------|:-----------|:---------|
   |UID|M|String(1024)|用户ID，唯一标识。|
   |DISPLAYNAME|O|String(1024)|用户昵称。|
   |PHOTOURL|O|String(2048)|头像地址。|
   |privateKey|M|String|私钥。|

4. 生成JWT后，传递给应用客户端对接AGC认证服务。
