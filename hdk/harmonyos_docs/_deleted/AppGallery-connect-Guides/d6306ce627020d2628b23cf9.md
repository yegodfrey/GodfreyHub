# 业务介绍

认证服务面向开发者提供多种用户认证的解决方案，简化开发者在用户账号和认证系统上的开发工作量，降低开发者的人力成本和安全风险。

虽然通过在应用客户端集成认证服务的SDK可以应对用户认证的大部分场景，但是您仍然可能有场景需要在您的服务器上处理用户认证相关的事务。  

#### 主要功能

您可以通过在您的服务器或工具中集成认证服务的Server SDK来支撑如下场景：  

|主要功能|功能描述|
|:------|:----------------------------------------------------------------------------------------------------------------------|
|用户迁移和备份|您可以将您的其他认证系统的用户导入到认证服务，也可以从认证服务导出用户以完成备份或者迁移工作。|
|自有账号对接|您可以将您自有的认证系统与认证服务对接，以便让认证服务来支撑您自有的认证系统所不具备的认证方式。您自有的认证系统可以通过Server SDK来为您的用户颁发JWT，认证服务可以基于该JWT来识别您自有的认证系统的用户，并统一管理您的用户。|
|撤销用户凭据|当用户向您报告设备丢失，或者您发现或怀疑有大量Token泄露，可来查找所有用户并撤销他们现有的用户凭据。|
|验证用户凭据|因为应用端并非可信环境，当用户在应用中访问开发者的业务服务器时，业务服务器需要调用Server SDK的接口对用户AccessToken进行认证，以便识别用户的身份并进一步提供相应的服务。|

#### 工作原理

您只需在您的服务器或工具中集成认证服务的Server SDK，并调用它提供的接口，与认证服务的通讯将由认证服务Server SDK来完成。

Server SDK需要使用API客户端作为访问凭据，您需要为Server SDK指定您要使用的API客户端凭据文件。了解详情，请参见[初始化](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-server-integration-sdk-0000001333298505#ZH-CN_TOPIC_0000001333298505__li1932016114418)。  

#### 实现流程

|步骤序号|步骤说明|步骤详情|
|:---|:--------------------|:---------------------------------------------------------|
|1|下载API客户端凭据文件|在"开发与服务 \> 项目设置 \> Server SDK"页面，点击"下载认证凭据"按钮，妥善保存下载的凭据文件。|
|2|引入认证服务Server SDK到您的工程|将认证服务Server SDK加入依赖，引入到您的服务器或工具的工程。|
|3|初始化访问实例|初始化访问实例时指定您的凭据文件。|
|4|功能开发|调用Server SDK的接口来实现您期望的功能。|

#### 相关概念

|名称|说明|
|:-----|:-----------------------------------------------------------------|
|自有认证系统|您的已有存量用户的认证系统。|
|自有账号|您的自有认证系统中的用户账号。|
|JWT|Json Web Token，请参见[RFC 7519](https://tools.ietf.org/html/rfc7519)。|
