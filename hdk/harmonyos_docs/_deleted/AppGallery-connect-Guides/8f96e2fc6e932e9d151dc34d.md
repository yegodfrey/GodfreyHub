# 管理商品状态

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250716103233.97302836206592642023387952639255:50001231000000:2800:41DC78D52354B3E4404A1F1EDCBF7C66E967404A8D8DDD91B08E167F9EE8677B.png)  
调用PMS API前请确认已经完成[使用入门](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114)中的服务端授权。

商品创建过程中指定了商品的状态信息，在商品创建成功后您可以调用[批量激活商品](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchactproduct-harmonyosnext-0000002131350712)接口或者[批量去激活商品](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-batchdeactproduct-harmonyosnext-0000002166748613)接口更新商品的状态信息。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250716103233.68037029941696043516414300632090:50001231000000:2800:A9D08FA13615BDC06A28A1C38FA37BC78B652611D99F6234DAA2C3B6B0F92E2C.png)  
批量接口每批最多支持100个，支持部分成功， 失败的会在响应中反馈错误信息。

以批量激活商品为例，示例代码如下：

```
public static ProductDeactiveResp batchActive(String domain, String clientId, String authorization,
                                              String appId, ProductDeactiveReq req) {
    String url = domain + "/api/pms/product-price-service/v1/manage/product/batchDeactive";
    HttpPut put = new HttpPut(url);
    setHttpHead(clientId, authorization, appId, put);
    StringEntity entity =
            new StringEntity(JSON.toJSONString(req), ContentType.create("application/json", "UTF-8"));
    put.setEntity(entity);
    String result = getApiResp(put);
    if (StringUtils.isNotEmpty(result)) {
        return JSON.parseObject(result, ProductDeactiveResp.class);
    }
    return null;
}
```

查询当前应用下是否存在激活的商品，您可以调用[查询是否有在线商品](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agcapi-isproductactive-android-0000002136087412)接口。
