# 使用入门

#### 基础知识准备

在使用SDK3.5.0 Unity插件之前，开发者需要对Unity平台及C#语言有一定基础。  

#### 开发环境

* 手机：华为旗舰手机，型号请参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/introduction-0000001097358942#section43314313363)
* 眼镜：HUAWEI VR 2、HUAWEI VR Glass
* 操作系统：EMUI 10.0及以上版本
* Unity版本：5.6.x 至 2019.2.x  

#### 开发流程

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|材料准备|在开发应用前，需要进行以下操作： 1. 在PC端安装Unity平台。 2. 配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dev-process-import-sdk-0000001205644941)。 3. 下载 [hvrsdk-unity-3.5.0.x 压缩包](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/unity-sdk-download-0000001142315529)。 4. 将VR Engine SDK集成到您的开发环境中。 5. 安装华为VR SDK服务APK至手机。 6. 准备好华为手机及华为VR头盔。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dev-process-import-sdk-0000001205644941)|您可以通过集成的HUAWEI VR Engine SDK，完成以下操作： 1. 添加预制件，完成[项目构建](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dev-process-import-sdk-0000001205644941)。 2. 根据您的开发应用的情况，编写[详细配置](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/configuration-manifest-0000001205526407)文件。 3. 开始编写您的应用程序逻辑代码。|
|3|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/pre-release-check-0000001097358504)|华为提供对应用自动检查的能力。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/app-release-0000001097890656)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
