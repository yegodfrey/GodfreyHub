# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[Codelabs](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_HWAREngine)快速体验一个应用的开发过程。  

#### 开发环境

* 在华为终端设备上的应用市场下载AR Engine服务端APK（需在华为应用市场，搜索"华为AR Engine"）并安装到终端设备。
* JDK 1.8.211及以上。
* 安装Android Studio 3.3及以上：
  * minSdkVersion 26及以上
  * targetSdkVersion 31（推荐）
  * compileSdkVersion 31（推荐）
  * Gradle 6.1.1及以上（推荐）
* 测试应用的设备：参见[AREngine特性软硬件依赖表](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/features-0000001060501339)。

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/preparations-0000001059812995)|在开发应用前，需要进行以下操作： 1. 配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/preparations-0000001059812995#section1877217473310)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/preparations-0000001059812995#section177745415332)。 2. 将AR Engine SDK集成到您的开发环境中。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dev-guide-java-0000001059882631)|您可以根据当前的开发语言，参见[应用开发（Java/Kotlin）](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dev-guide-java-0000001059882631)或[应用开发（NDK）](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dev-guide-ndk-0000001060242313)章节，完成运行前验证、创建AR场景、帧处理，实现虚拟世界与现实世界的融合。|
|3|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/pre-release-check-0000001064060805)|华为提供对应用自动检查的能力。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/app-release-0000001137249249)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
