# 开发准备

1. 下载[体积云插件SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)，并解压。压缩包内包含头文件，库文件以及资源文件。
   * 库文件包含PC端运行的动态链接库.dll文件以及Android平台运行的动态链接库.so文件。
   * 资源文件（./assets）包含用于渲染的三维噪声纹理（noise.bin）以及预置的三维形状纹理（shape.bin）。  
     ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211227101413.51128516625598749773321405128448:50521226030127:2800:A5DCA1E5BB3D61D0DC01444F9D25ADA90C9639AEDE746618355AF23C4F9E5102.png?needInitFileName=true?needInitFileName=true)  
     shape.bin文件可由用户调用离线烘焙功能自行生成。

<!-- -->

2. 调用体积云插件前，需要添加打点功能依赖aar包，可以通过修改代码工程的应用级build.gradle文件来实现，任意aar包版本号均可。

   ```
   implementation 'com.huawei.hms:stats:4.0.3.302'
   ```
