# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSSceneKit)快速体验一个应用的开发过程。  

#### 开发环境

* 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上。

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8（推荐）。
* HMS Core（APK）4.0.2.300及以上版本。
* 您的应用应满足以下条件：
  * minSdkVersion 19及以上。
  * targetSdkVersion 33（推荐）。
  * compileSdkVersion 33（推荐）。
  * Gradle 5.4.1及以上（推荐）。

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：Android 4.4及以上，推荐使用EMUI 10.0及以上版本。  

#### 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下图所示：  

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/config-agc-0000001064476684)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/integrating-sdk-0000001063754635)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|（可选）[添加权限](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/add-permissions-0000001063528677)|* 如您的应用涉及从外部存储读取文件的功能，需要添加从外部存储读取权限。 * 如您的应用使用[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-arview-0000001064191000)与[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-faceview-0000001063533225)特性，需要添加Camera权限。|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/client-dev-overview-0000001099931916)|* [原子化接口](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/fine-grained-overview-0000001073484401)：提供高自由度开发的基本步骤示例，实现素材加载、动画、阴影等功能。 * [2D流体模拟接口](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/2d-fluid-overview-0000001163900771)：提供2D流体物理模拟接口，包括创建流体粒子、模拟流体晃动的物理效果。 * [场景化接口](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-apis-overview-0000001100421004)：提供[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-sceneview-0000001064799076)、[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-arview-0000001064191000)、[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/scenario-faceview-0000001063533225)场景化接口，包括渲染场景、AR场景与面部AR场景。 * [离线简模插件](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/plugin-slimlod-0000001072000720)：提供模型简化的功能。 * [实时光追插件](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/plugin-rtcore-0000001086910938)：提供实时光追的光线模型加速结构构建与求交功能。 * [高效遮挡剔除插件](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/plugin-goodculling-0000001205366243)：提供3D模型遮挡剔除的功能。 * [动态漫反射全局光照插件](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/plugin-ddgi-0000001305319637)：提供更加自然的实时漫反射全局光照功能。|
|5|[开发后自检](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/pre-release-check-0000001050435817)|华为提供对应用自动检查的能力。|
|6|[上架申请](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/app-release-0000001053326234)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
