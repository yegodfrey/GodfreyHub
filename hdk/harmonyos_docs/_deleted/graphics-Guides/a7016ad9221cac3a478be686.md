# 业务简介

#### 功能介绍

开发者使用HUAWEI VR SDK 3.5和Unity进行华为VR设备的应用开发，HUAWEI VR SDK 3.5 for Unity（以下简称SDK3.5）提供的功能主要包括：

* 支持中心区渲染 支持中心区渲染功能，使应用的显示效果更加清晰，集成方法详见[2.5 应用开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/dev-process-import-sdk-0000001205644941)。

* 支持6DoF交互 配合华为VR GLASS 6DoF套件，支持用户与应用进行6DoF交互。

* 自由设定应用场景 通过接口函数，替换天空盒材质，实现应用场景的快速替换。

* 陀螺仪传感器精准数据捕获 华为VR眼镜提供更精准的陀螺仪传感器数据，可通过接口函数实时获取陀螺仪数据。

* 手柄支持 提供手柄交互功能，通过接口函数获取手柄状态、类型、姿态、触摸板和按键的状态，重置手柄姿态，预制手柄快捷键功能。

* 手机操控交互支持 提供手机操控交互功能，开发者无需额外集成，使用手势进行手机屏幕操作，替代部分手柄交互功能。

* 音量调节 提供VR模式下的音量调节功能，开发者无需额外集成，可通过华为手柄音量键或线控音量调节按键调节控制音量及显示。

* 来电接听、拒接及挂断 提供VR模式下的来电接听、拒接及挂断功能，开发者无需额外集成。当有来电时，启用来电模式，用户可根据弹框提示进行来电接听、拒接及挂断操作。

* 通知消息自动弹框 提供VR模式下的通知消息自动弹框功能，开发者无需额外集成。当有通知消息时，即显示对应弹框，通知消息种类包括：短信弹框，一般消息弹框（如微信等），低电量提示弹框，WLAN连接变化弹框，温度告警弹框。

* 设置界面 提供VR模式下的设置功能，开发者无需额外集成，设置界面功能有：免打扰模式，亮度调节。

* 锁定及解锁视角 提供VR模式下的锁定及解锁视角功能，通过接口函数，实现场景内的视角锁定及解锁的功能。

* 分场景设置相机渲染分辨率 提供VR模式下的分场景设置相机渲染分辨率功能，通过界面选择缩放因子，修改场景的渲染分辨率的功能。

* 3D音效 提供音频插件，实现3D音效功能。开发者可在3D虚拟场景中实现声音的方位渲染、距离模拟以及环境音效渲染，以达到更具沉浸感的声音体验。

* 2D下启动 提供2D界面提示功能，开发者需要通过特定设置（可参见[2D界面提示设置](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/configuration-set-prompt-0000001205644943)），在2D界面下启动VR应用。

* 应用内截图 提供VR模式下的截图功能，开发者无需额外集成，通过手柄快捷键（同时按下Home + Trigger），在应用过程中实现截图。

* 自适应分辨率 提供VR模式下自适应调节分辨率的功能，开发者无需额外集成，当手机温度过高时，可自适应降低分辨率以降低功耗。

* 前向兼容 开发者在SDK3.5.0上开发的应用可以同时支持在之前版本上使用。

* 触摸板轨迹点显示 提供VR模式下，触摸板显示触摸位置，开发者无需额外集成。

<!-- -->

* 手柄帮助信息显示 提供VR模式下的手柄帮助信息显示功能，开发者无需额外集成，当手柄靠近VR眼镜时会显示手柄按键及快捷键的提示信息，同时，支持开发者自定义提示信息。
