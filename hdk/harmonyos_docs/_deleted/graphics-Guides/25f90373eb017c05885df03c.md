# 开发后自检

#### 自检Checklist

为尽早发现问题，尽量减少您集成业务提交审核后被打回的概率，HMS业务提供了提交审核前自检checklist。请下载[图形引擎服务自检checklist](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240115092015.53720302544916172691429336569297:50001231000000:2800:41697CB4207920FFC1EC5F0A0C73687E8F757F9CD4637DDD1352DB7C26906795.xlsx?needInitFileName=true)进行自检，检查通过后，再提交上架应用。  

#### 自检工具

华为提供对应用自动检查的能力。您只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。您可以根据自检报告改进应用，自检通过即可提交应用上架申请，是您上架应用的好帮手。

自检步骤请参见AppGallery Connect帮助中心的[接入检测](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-self-check-0000001100158786)。
