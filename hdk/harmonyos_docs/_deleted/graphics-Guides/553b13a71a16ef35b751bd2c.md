# 业务简介

GPU扩展能力提供了全新的Smart Cache相关扩展以及基于Vulkan的Pre-rotation扩展，以减少特定场景的GPU开销，从而达到降低功耗，提升性能的目的。  

#### 场景介绍

GPU扩展能力通过提供如下扩展，帮助您在特定的场景，获得一定的收益：

* Smart Cache：华为实现的一个多模块之间共享cache的策略，以降低DDR读写的latency造成的性能功耗影响。
* Pre-rotation：减轻Vulkan应用中预处理旋转的开销。
