# 集成HMS Core SDK

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221216170202.77465578717419250955326953516030:50531215092732:2800:61C1DC5672B786EE32C771033B36BDAE55D08E8184C6CCAAFE9B500269104640.png?needInitFileName=true?needInitFileName=true)  
* 该工程仅提供了CG Kit Demo框架，需要自行准备CG Kit头文件、so文件以及模型和纹理文件等才能正确编译运行。
* CG Kit渲染框架目前的JNI模块只支持渲染流程控制。

1. 创建Android Studio Project。

   在Android Studio中创建一个工程"example"，选择"Native C++"，会默认生成一个native-lib.cpp文件及CmakeLists.txt文件，目录树如下：

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221216170202.71400188134782343342630232550464:50531215092732:2800:E5AA5CF8336BE12D37DAFCFEF58F9F26B47D23BA7C5CE5CD5E83010BCB32E616.png?needInitFileName=true?needInitFileName=true)
2. 修改"/app/build.gradle"文件，指定CMake编译C++文件。
   * 修改android层级下的"compileSdkVersion"和"buildToolsVersion"。
   * 修改defaultConfig层级下的编译参数"minSdkVersion"和"targetSdkVersion"。
   * 修改externalNativeBuild层级下的"cmake"选项。
   * 配置NDK过滤项，目前CG Kit只支持arm64-v8a和armeabi-v7，暂不支持x86和x86_64。

   ```
   android {
       compileSdkVersion 29
       buildToolsVersion "29.0.3"
       defaultConfig {
           applicationId "com.example.example"
           minSdkVersion 26
           targetSdkVersion 29
           versionCode 1
           versionName "1.0"
           testInstrumentationRunner "androidx.test.runner.AndroidJUnitRunner"

           externalNativeBuild {
               cmake {
                   cppFlags ""
               }
           }
           ndk {
               abiFilters 'armeabi-v7a', 'arm64-v8a'
           }
       }

       buildTypes {
           release {
               minifyEnabled false
               proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
           }
       }
       externalNativeBuild {
           cmake {
               path "src/main/cpp/CMakeLists.txt"
               version "3.10.2"
           }
       }
   }
   ```

3. 复制库和头文件。
   1. 下载[CG SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)、[插件开发框架SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)和[插件开发框架demo](https://developer.huawei.com/consumer/cn/doc/development/graphics-Examples/sample-code-0000001050160229#section1690641117411)，并解压。
   2. 复制SDK头文件目录（CGRenderingFramework）到Android Studio下的"src/main/cpp/include"。

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221216170202.53230771202733822097315467093911:50531215092732:2800:6431DB896C79A9F132FDAABF9A877E3A6230A83A366A8F7104B2B70C923333CC.png?needInitFileName=true?needInitFileName=true)
   3. 复制CG SDK、插件开发SDK的动态库和插件开发Demo包到资源库。
      * 将CG Kit的SDK中"libs\\arm64-v8a\\libcgkit.so"、"libs\\armeabi-v7a\\libcgkit.so"分别复制到Android Studio下的libs/arm64-v8a和libs/armeabi-v7a。
      * 如果需要使用JNI接口，需要将SDK中"libs\\java\\cgkit_jni.jar"导入到工程中。
      * 将插件开发框架SDK中的"libs\\arm64-v8a\\libPluginInterface.so"、"libs\\armeabi-v7a\\libPluginInterface.so"分别复制到Android Studio下的libs/arm64-v8a和libs/armeabi-v7a。
      * 执行插件开发框架Demo包中的build.bat文件，将编译生成的PluginDemo目录复制到Android Studio下的"app"目录，配置文件pluginList复制到Android Studio下的"assets"目录。

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221216170202.13317907890947388632265329298784:50531215092732:2800:6264532B0E336241E41180BDC20858321EB59DF52095A27D811245F55C3BD382.png?needInitFileName=true?needInitFileName=true)
   4. 修改"app/src/main/cpp/CMakeLists.txt"文件，请使用以下代码替换创建Android Studio Project后生成的CMakeLists.txt。

      其中SDK头文件目录为CGRenderingFramework，并需要在同级目录下新建MainApplication目录以存放MainApplication.h文件。  
      默认生成的native-lib.cpp需修改为MainApplication.cpp，并添加Main.cpp以匹配如下CMakeLists.txt文件。Main.cpp和MainApplication.cpp设置可参见[加载资源](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/demo-dev-process-0000001050197954#section14895172862514)。

      ```
      # CMake最低版本为3.10.2
      cmake_minimum_required(VERSION 3.10.2)

      # 头文件包含目录
      include_directories(${CMAKE_SOURCE_DIR}/include
              ${CMAKE_SOURCE_DIR}/include/CGRenderingFramework )

      # libmain.so源码文件清单
      add_library(
              main-lib
              SHARED
              source/Main.cpp
              source/MainApplication.cpp
              source/OSRPlugin.cpp )

      # libcgkit.so导入
      ADD_LIBRARY(
              cgkit
              SHARED
              IMPORTED)

      # libcgkit.so导入路径
      set_target_properties(cgkit
              PROPERTIES IMPORTED_LOCATION
              ${CMAKE_SOURCE_DIR}/../../../libs/${ANDROID_ABI}/libcgkit.so
              )

      # Vulkan头文件包含路径
      SET(
              VULKAN_INCLUDE_DIR
              "$ENV{VULKAN_SDK}/include")
              #"${ANDROID_NDK}/sources/third_party/vulkan/src/include")

      include_directories(${VULKAN_INCLUDE_DIR})

      # native_app_glue路径
      SET(
              NATIVE_APP_GLUE_DIR
              "${ANDROID_NDK}/sources/android/native_app_glue")

      FILE(
              GLOB NATIVE_APP_GLUE_FILLES
              "${NATIVE_APP_GLUE_DIR}/*.c"
              "${NATIVE_APP_GLUE_DIR}/*.h")

      # 导入native_app_glue
      ADD_LIBRARY(native_app_glue
              STATIC
              ${NATIVE_APP_GLUE_FILLES})

      TARGET_INCLUDE_DIRECTORIES(
              native_app_glue
              PUBLIC
              ${NATIVE_APP_GLUE_DIR})

      # 依赖log模块
      find_library(
              log-lib
              log )

      target_link_libraries(
              main-lib
              cgkit
              native_app_glue
              android
              ${log-lib} )

      SET(
              CMAKE_SHARED_LINKER_FLAGS
              "${CMAKE_SHARED_LINKER_FLAGS} -u ANativeActivity_onCreate")
      ```

   5. （可选）如果使用JNI接口需要做如下修改。  
      修改Androidmanifest.xml文件中的android:name。

      ```
      <activity android:name="com.huawei.hisi.cgkit.CGkitActivity"
      ```

      在MainApplication.cpp中增加如下信息。

      ```
      namespace CGKit {
      extern "C" {
      CGKIT_EXPORT CGKit::BaseApplication * create_application() {
          return CGKitMapApplication::GetInstance();
      }
      };
      ```

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221216170202.52321539387956816479401427294798:50531215092732:2800:86250DCAA3854AE3624DA951103D63DCAF4E7F07E0FF6049F7511EA862C0C751.png?needInitFileName=true?needInitFileName=true)  
      使用JNI接口时，[3.d](#ZH-CN_TOPIC_0000001050318908__li13856336161817)中不需要添加Main.cpp文件。
   6. 同步工程。 点击"Sync Project with Gradle Files"即可。
