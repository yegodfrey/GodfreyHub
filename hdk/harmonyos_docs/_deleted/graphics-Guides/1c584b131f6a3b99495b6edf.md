# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSCGKit)快速体验一个应用的开发过程。  

#### 开发环境

* [JDK](https://www.java.com/zh-CN/) 1.8.211及以上
* 安装[Android Studio](https://developer.android.com/studio?hl=zh-cn) 3.5及以上
  * minSdkVersion 26及以上
  * targetSdkVersion 29（推荐）
  * compileSdkVersion 29（推荐）
  * Gradle 3.5及以上（推荐）
* 测试应用的设备：EMUI 8.0及以上华为手机或Android 8.0及以上非华为手机。
* 使用[CMake](https://cmake.org/download/) 3.10.2及以上进行Native代码编译；另外也可以使用[NDK](https://developer.android.com/ndk/downloads/index.html)进行Native代码编译，需要Android API Level21及其以上版本。

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/access-preparation-0000001050197950)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/integrating-sdk-0000001050318908)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/demo-dev-process-0000001050197954)|您可以通过创建应用实例对象及加载资源完成渲染相应功能开发。在开发过程中可根据需要选择[GPU扩展能力](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/introduction-0000001050200029)、[插件开发框架](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/integrating-sdk-0000001057187071)、[离线超分插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/preparations-0000001055622663)、[遮挡剔除插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/preparations-0000001055147592)来增强渲染能力。|
|4|[GPU扩展能力](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/introduction-0000001050200029)（可选）|GPU扩展能力用于减少特定场景的GPU开销，从而降低功耗，提升性能。 说明： GPU扩展能力集成在ROM中，使用时只调用相关接口，无需集成SDK。|
|5|[插件开发框架](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/integrating-sdk-0000001057187071)（可选）|将第三方的渲染能力以插件形式接入CG Kit框架。|
|6|[离线超分插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/preparations-0000001055622663)（可选）|提升游戏截图（拍照）画质能力，提高画面分辨率，改善画面细节。|
|7|[遮挡剔除插件](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/preparations-0000001055147592)（可选）|在CPU侧对物体进行遮挡剔除，减小GPU侧的渲染压力，从而提高整体渲染性能。|
|8|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/pre-release-check-0000001050200037)|华为提供对应用自动检查的能力。|
|9|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/app-release-0000001050734403)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
