# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 多线程库是否支持Java调用？

多线程库当前没有提供Java接口，只提供了C接口。  

#### 多线程库支持在哪些品牌的手机集成？

Android 5.0及以上的手机都支持，对硬件没有约束。  

#### PerfGenius SDK使用时，多个so库关联和工程编译出的APK无法安装如何处理？

请在模块build.gradle的android配置项添加以下配置项。

```
packagingOptions {        
    // pick first so source        
    pickFirst 'lib/arm64-v8a/libc++_shared.so'       
    pickFirst 'lib/arm64-v8a/libPerfgeniusApi.so'        
    // don't compresses so source        
    doNotStrip "*/arm64-v8a/*.so"    
}
```
