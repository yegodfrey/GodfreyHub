# 开发准备

下载并解压[流体插件SDK](https://developer.huawei.com/consumer/cn/doc/development/graphics-Library/sdk-download-0000001050441521)，压缩包内包含头文件和库文件。

库文件包含手机端Android平台下运行所需的动态库".so"文件。
