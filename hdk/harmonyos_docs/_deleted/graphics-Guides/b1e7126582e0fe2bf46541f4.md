# 调用CG Kit插件框架接口

通过CG Kit插件框架进行离线超分插件调用时，可以参见[调用插件管理框架API](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/demo-dev-process-0000001050197954#section84245315545)，其中插件列表中需要加载的动态库文件为libcgkit_plugin_offlineSupRes.so。插件使用过程中，需要额外包含头文件OSRPluginCommon.h，以定义相关的结构体变量。插件实际的功能接口通过以下函数进行调用。

```
bool Execute(const Param &paramIn, Param &paramOut)
```

使用CGKit::Param进行接口的参数传递。  

#### 设置资源文件目录

插件加载成功后，需要设置资源文件的所在目录，设置成功后插件会自动加载资源文件。其示例代码如下。

```
char *assetsDir = MY_ASSETS_DIR;
char returnDir[1024];

// 该接口不对paramOut进行处理，故不进行初始化操作
Param paramIn, paramOut; 
Param pi0;
// 资源文件目录设置的操作码为6，见附表
pi0.Set<s32>(6); 
Param pi1;
// 设置为assetsDir的地址
pi1.Set<void *>((void *)assetsDir); 
paramIn.Set(0, pi0);
paramIn.Set(1, pi1);

bool success = plugin->Execute(paramIn, paramOut);
if (success) {
    std::cout << "  Successfully set assets directory to " << assetsDir << std::endl;
} else {
    std::cout << "  Fail to set assets directory to " << assetsDir << std::endl;
}
```

#### 查询能力支持

资源文件目录设置成功后调用查询接口，确认插件是否支持当前超分场景，查询结果保存在PluginConfig结构体中。查询图像处理超分能力对当前任务的支持情况，其示例代码如下，AI超分能力支持的查询请将操作码设置为0。

```
PluginConfig pluginConfig;

Param paramIn, paramOut;
Param pi0;
// 图像处理超分能力查询的操作码为1，见附表
pi0.Set<s32>(1); 
Param pi1;
// 输入图片宽度
pi1.Set<s32>(inBuffer.width); 
Param pi2;
// 输入图片高度
pi2.Set<s32>(inBuffer.height); 
Param pi3;
// 输入图片像素通道排列格式
pi3.Set<s32>(inBuffer.format); 
paramIn.Set(0, pi0);
paramIn.Set(1, pi1);
paramIn.Set(2, pi2);
paramIn.Set(3, pi3);
Param po0;
// 设置为pluginConfig的地址
po0.Set<void *>((void *)&pluginConfig); 
paramOut.Set(0, po0);

plugin->Execute(paramIn, paramOut);
std::cout << "Output Width: " << pluginConfig.output.width << std::endl
          << "Output Height: " << pluginConfig.output.height << std::endl
          << "Reference Time: " << pluginConfig.estimatedCostTime << std::endl;
```

#### 同步调用超分能力

确认超分能力可支持后，对超分能力进行同步调用，超分结果保存在BufferDescriptor结构体中。图像处理超分能力的同步调用示例代码如下，AI超分能力的同步调用请将操作码设置为2，同时不需要设置锐化程度和亮度调整开关。

```
BufferDescriptor inBuffer, outBuffer;
// 初始化inBuffer
// 初始化outBuffer，根据能力支持查询结果对outBuffer各字段进行赋值和相应的内存分配

Param paramIn, paramOut;
Param pi0;
// 图像处理超分同步调用的操作码为3，见附表
pi0.Set<s32>(3); 
Param pi1;
// 设置为inBuffer的地址
pi1.Set<void *>((void*)&inBuffer); 
Param pi2;
// 设置锐化程度
pi2.Set<f32>(0.8); 
Param pi3;
// 设置亮度调整开关
pi3.Set<bool>(false); 
Param pi4;
// 设置执行时间(ms)
pi4.Set<s32>(10000); 
paramIn.Set(0, pi0);
paramIn.Set(1, pi1);
paramIn.Set(2, pi2);
paramIn.Set(3, pi3);
paramIn.Set(4, pi4);
Param po0;
// 设置为outBuffer的地址
po0.Set<void *>((void *)&outBuffer); 
paramOut.Set(0, po0);

// 调用接口
bool success = plugin->Execute(paramIn, paramOut); 
if(success) {
    std::cout << "  SuperSamplingExecute success" << std::endl;
} else {
    std::cerr << "  SuperSamplingExecute failed" << std::endl;
}
```

#### 异步调用超分能力

异步调用与同步调用的区别在于需要传入回调函数指针。图像处理超分能力的异步调用示例代码如下，AI超分能力的异步调用请将操作码设置为4，同时不需要设置锐化程度和亮度调整开关。

```
BufferDescriptor inBuffer, outBuffer;
// 初始化inBuffer
// 初始化outBuffer，根据能力支持查询结果对outBuffer各字段进行赋值和相应的内存分配

Param paramIn, paramOut;
Param pi0;
// 图像处理超分异步调用的操作码为5，见附表
pi0.Set<s32>(5); 
Param pi1;
// 设置为inBuffer的地址
pi1.Set<void *>((void*)&inBuffer); 
Param pi2;
// 设置锐化程度
pi2.Set<f32>(0.8); 
Param pi3;
// 设置亮度调整开关
pi3.Set<bool>(false); 
Param pi4;
// 设置回调函数的指针
pi4.Set<void *>((void *)CallBack); 
paramIn.Set(0, pi0);
paramIn.Set(1, pi1);
paramIn.Set(2, pi2);
paramIn.Set(3, pi3);
paramIn.Set(4, pi4);
Param po0;
// 设置为outBuffer的地址
po0.Set<void *>((void *)&outBuffer); 
paramOut.Set(0, po0);

// 调用接口
bool success = plugin->Execute(paramIn, paramOut); 
if(success) {
    std::cout << "  SuperSamplingExecute success" << std::endl;
} else {
    std::cerr << "  SuperSamplingExecute failed" << std::endl;
}
```

#### 附表

CG Kit接口调用需要传递操作码，当前支持的操作码如下。  

|操作码|功能|
|:--|:------------|
|0|查询AI超分能力支持。|
|1|查询图像处理超分能力支持。|
|2|同步调用AI超分。|
|3|同步调用图像处理超分。|
|4|异步调用AI超分。|
|5|异步调用图像处理超分。|
|6|设置资源文件目录。|
