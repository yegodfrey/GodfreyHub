#### SDK依赖说明

* 最新版本SDK需要用户终端设备上安装AR Engine（APK）。如果用户终端设备没有安装，您的应用调用AR Engine能力时，应提醒用户安装。
* AR Engine的主要特性都可在支持的终端设备列表中使用，环境Mesh等高级特性依赖特定机型及OS版本，请参见[AREngine特性软硬件依赖表](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/features-0000001060501339)。

提示：您的应用在开发集成过程中，如有问题可通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)咨询。

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:arenginesdk:3.7.0.3 新增特性配套的最小AR Engine版本：4.0.1.100，该版本目前只在中国大陆发布。 新增特性 当您的应用希望减少运行时内存占用时，可使用[setMaxMapSize](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/config_base-0000001050119488#section163821425123315)()设置地图使用最大内存大小，该接口目前只在[ARWorldTrackingConfig](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/world_tracking_config-0000001050119510)下生效。 修改特性 添加queries标签，当您的应用配置的targetSdkVersion大于等于30时，为保证应用兼容性，请使用此版本。|

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230721164405.82149436001809441659274097582169:50001231000000:2800:AE761CB1820014DC9170074328FCF539A81E3FCDA6EACBE060606F9D9D454386.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
\<queries\>标签对工具的要求如下：

* Android Studio需升级至3.3或更高版本。
* Android Gradle插件需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。

当您的应用配置的targetSdkVersion大于等于30时，在Android 11及以上系统会提示AR Engine Service版本未安装，解决方案有以下两种：

* 升级您的应用使用的AR Engine SDK版本到3.7.0.3（推荐）。
* 如果不升级AR Engine SDK版本，需要在"AndroidManifest.xml"中manifest下添加\<queries\>标签。

  ```
  <manifest ...>
      ...
      <queries>
          <package android:name="com.huawei.arengine.service" />
      </queries>
      ...
  </manifest>
  ```
