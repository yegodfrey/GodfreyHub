# 个人数据处理说明

此文档针对华为作为最终用户数据处理者，您作为最终用户数据控制者的数据处理进行说明，包括：

* 华为处理的个人数据清单
* 指导您如何帮助最终用户实现对数据的控制

#### 华为处理的个人数据清单

|个人数据清单|使用目的|存留期|
|:------|:------------------------------------------------|:---------------------------------------------------------|
|相机捕获的图像|AR Engine通过分析相机捕获到的图像信息来实现运动跟踪、人体和人脸跟踪、环境跟踪等AR能力。|只有云识别在识别物体时需要上传图片信息至服务器，其余功能，相机捕获到的图像只在端侧处理，处理完成后即销毁，不会留存。|
|人脸信息|AR Engine通过分析相机捕获的人脸信息，来实现面部特征识别，提供人脸跟踪能力。|相机捕获到的人脸信息只在端侧处理，处理完成后即销毁，不会留存，也不会涉及数据上传。|
|骨骼信息|AR Engine通过分析相机捕获到的人体信息，来实现人体特征识别，提供人体跟踪能力。|相机捕获到的人体信息只在端侧处理，处理完成后即销毁，不会留存，也不会涉及数据上传。|

#### 指导您如何帮助最终用户实现对数据的控制

AR Engine云识别能力的相机图像数据需要上传图片信息至服务器，其它能力涉及的相机图像数据只在端侧设备处理；由数据控制者面向最终用户提供相应的数据主体权利及其相关解释。
