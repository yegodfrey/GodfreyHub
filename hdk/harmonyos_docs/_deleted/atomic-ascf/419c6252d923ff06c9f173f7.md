# 图标加桌

#### has.addShortcut

has.addShortcut(Object object)

创建桌面图标。调用后会弹出确认对话框，用户确认后创建桌面快捷方式。

快应用中心版本： 16.5.1  
![](https://media:201787209127361044)  
* 当前接口以快应用中心为载体，仅支持HarmonyOS 4及以下版本使用。

约束与限制：

* 元服务启动10s内不能调用加桌API，否则会回调失败。

* 元服务进程启动期间只能调用一次加桌API，重复调用会回调失败。

* 当前接口与面板里的加桌不共用次数。

* 若桌面图标已存在，会回调失败并返回错误码11002305。

参数：

参数为Object对象，包括以下字段。  

|参数|类型|必填|描述|
|:-------|:-------|:-|:-------------------------------------------|
|message|string|否|提示信息，展示在提示对话框上，向用户解释为什么需要创建快捷方式。不传则使用默认提示内容。|
|success|function|否|接口调用成功的回调函数。|
|fail|function|否|接口调用失败的回调函数。|
|complete|function|否|接口调用结束的回调函数（调用成功、失败都会执行）。|

错误码信息：  

|错误码|说明|
|:-------|:----------------------|
|11002301|通用错误。|
|11002302|用户拒绝创建桌面图标。|
|11002303|超过调用次数限制，每个进程仅允许调用一次。|
|11002304|未达到调用时机，元服务启动后10s内不可调用。|
|11002305|桌面图标已存在。|

示例：

```
has.addShortcut({
  message: '是否将元服务添加到桌面？',
  success: () => {
    console.info('addShortcut success');
  },
  fail: (err) => {
    console.error('addShortcut fail', err);
  },
  complete: (res) => {
    console.info('addShortcut complete', res);
  }
});
```

#### has.checkShortcut

has.checkShortcut(Object object)

获取桌面图标是否已存在。

快应用中心版本： 16.5.1  
![](https://media:201787209127398045)  
* 当前接口以快应用中心为载体，仅支持HarmonyOS 4及以下版本使用。

参数：

参数为Object对象，包括以下字段。  

|参数|类型|必填|描述|
|:-------|:-------|:-|:------------------------|
|success|function|否|接口调用成功的回调函数。|
|fail|function|否|接口调用失败的回调函数。|
|complete|function|否|接口调用结束的回调函数（调用成功、失败都会执行）。|

success返回值：  

|参数|类型|描述|
|:----|:-----|:---------------------------------------------|
|state|string|桌面图标创建状态。 - exist：桌面图标已存在。 - notExist：桌面图标不存在。|

错误码信息：  

|错误码|说明|
|:-------|:----|
|11002401|通用错误。|

示例：

```
has.checkShortcut({
  success: (res) => {
    console.info('checkShortcut success, state:', res.state);
  },
  fail: (err) => {
    console.error('checkShortcut fail', err);
  },
  complete: (res) => {
    console.info('checkShortcut complete', res);
  }
});
```
