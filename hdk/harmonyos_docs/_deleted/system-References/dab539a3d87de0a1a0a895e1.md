# Overview

Wireless Kit提供无线通信传输能力封装以及网络QoE能力开放。入口类为[WirelessClient](https://developer.huawei.com/consumer/cn/doc/development/system-References/wirelessclient-0000001051067902)。  

#### Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------|:-----------------|
|[IQoeCallBack](https://developer.huawei.com/consumer/cn/doc/development/system-References/iqoecallback-0000001050986863)|定义通信感知信息回调接口。|
|[IQoeService](https://developer.huawei.com/consumer/cn/doc/development/system-References/iqoeservice-0000001051066784)|定义和通信感知服务交互的接口。|
|[IWifiEnhanceService](https://developer.huawei.com/consumer/cn/doc/development/system-References/iwifienhanceservice-0000001054337634)|定义和Wi-Fi增强服务交互的接口。|
|[NetworkQoeClient](https://developer.huawei.com/consumer/cn/doc/development/system-References/networkqoeclient-0000001050987967)|定义通信感知能力接口。|
|[INetworkCallback](https://developer.huawei.com/consumer/cn/doc/development/system-References/inetworkcallback-0000001143941719)|定义双Wi-Fi服务回调接口。|
|[IDualWifiService](https://developer.huawei.com/consumer/cn/doc/development/system-References/idualwifiservice-0000001144301627)|定义和双Wi-Fi服务交互的接口。|
