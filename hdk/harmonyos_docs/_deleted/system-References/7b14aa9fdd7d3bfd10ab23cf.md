# 错误码

|错误码|值|描述|解决方法|
|:--------------------------------|:--|:-----------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|WirelessUtils.INPUT_PARAM_INVALID|1|入参无效。|检查入参的合法性，更改后重新填写API入参。|
|WirelessUtils.CONDITION_INVALID|2|条件无效。|检查使能接口时的条件是否符合。如Wi-Fi是否已打开。|
|WirelessUtils.INNER_ERROR|100|Wireless Kit内部异常。|当前手机版本不支持此API开放能力，应用不应该依赖这个API。|
|WirelessUtils.IN_PUNISH_TIME|101|[reportAppQuality](https://developer.huawei.com/consumer/cn/doc/development/system-References/iqoeservice-0000001051066784#section29691849561)接口调用太频繁。|10秒钟之后再调用[reportAppQuality](https://developer.huawei.com/consumer/cn/doc/development/system-References/iqoeservice-0000001051066784#section29691849561)接口。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
