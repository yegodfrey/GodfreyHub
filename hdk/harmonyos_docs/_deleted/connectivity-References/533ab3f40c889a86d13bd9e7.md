# Overview

提供用于Wear Engine权限管理功能的类。

开发者可以通过该客户端进行用户权限授权操作，例如：申请权限、查询权限。  

#### Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------|:----------|
|[AuthCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/authcallback-0000001059850647)|权限回调接口。|

#### Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------|
|[AuthClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/authclient-0000001059980967)|用于权限管理的客户端，开发者可以通过该客户端进行用户权限授权操作。|
|[Permission](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005)|Wear Engine的权限对象，封装了Wear Engine指定的权限，当前包含DEVICE_MANAGER、MOTION_SENSOR、NOTIFY、SENSOR和WEAR_USER_STATUS权限。|
