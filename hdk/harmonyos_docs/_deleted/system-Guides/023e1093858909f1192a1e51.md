# 上架申请

#### 了解上架规则

您完成集成服务，提交应用上架前，请先了解如下上架规则和审核常见问题：

* [华为应用市场审核指南](https://developer.huawei.com/consumer/cn/doc/distribution/app/50104)
* [应用审核FAQ](https://developer.huawei.com/consumer/cn/doc/distribution/app/50106)

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231121105012.72974915146181255947928356703996:50001231000000:2800:D57FE579B9FCC0DE4A3D337B4C4A521CB6D98B40396ACB06B60A50891173CDD7.png?needInitFileName=true?needInitFileName=true)  
按照应用市场的[隐私政策](https://developer.huawei.com/consumer/cn/doc/distribution/app/50104#h2-1656069583693-3)，所有上架App只要集成了第三方SDK，都需要在App的隐私政策中逐一明示SDK收集个人信息的目的、方式和范围，不然可能会导致上架不通过。本SDK的明示信息请参见开发指南"SDK隐私安全说明"章节。  

#### 提交上架申请

开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请，具体操作请参见[发布应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-releaseapkrpk-0000001106463276)。
