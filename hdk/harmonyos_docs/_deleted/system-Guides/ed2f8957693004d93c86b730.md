# 业务介绍

#### 业务简介

|-------------------------------------------------------------------------------------------------------------------------------------------------|-|
|无线传输服务（Wireless Kit）提供无线通信传输能力封装以及网络QoE能力开放，可以为开发者提供领先的、定制化的5G+Wi-Fi通信解决方案，包括通信资源调度、QoE信息实时反馈、弱信号预测、Wi-Fi高优先级发包以及双Wi-Fi等功能，为应用带来大带宽、低时延、高可靠的网络体验。| |

#### 场景介绍

* 提供网络QoE信息 您可以在App中集成Wireless SDK来获取网络QoE服务。在App中注册网络QoE信息感知后，Wireless Kit即可周期性反馈QoE信息给App。网络QoE信息包括数据传输的上下行空口时延、上下行空口实时带宽、上下行空口实时速率、网络QoE评估结果等级、上行空口丢包率等。

* 应用传输质量反馈 应用将传输卡顿和传输的统计信息通过Wireless Kit传输给无线通信业务模块，通信模块结合业务反馈，进行精细化调度，提高应用无线传输体验。

  例如：视频类App播放过程中卡顿，将卡顿信息上报后，Wireless Kit将信息反馈给无线通信业务模块。模块会记录播放卡顿信息，并根据当前网络情况，提高业务传输能力。
* 弱信号预测 通过机器学习方式分析用户在固定路线上移动时的蜂窝网络信号质量变化并基于学习结果预测出用户即将进入信号质量不佳区域的时间，以及恢复为正常信号水平的时间，三方应用可以据此预测信息提前做出应对措施，以提升应用在蜂窝网络下的业务体验。

* 提供Wi-Fi高优先级发包能力 您可以在App中集成Wireless SDK来获取Wi-Fi增强服务。在App中注册Wi-Fi增强服务后，可以使能Wi-Fi高优先级发包能力。

* 提供双Wi-Fi能力 您可以在App中集成Wireless SDK来获取双Wi-Fi服务。在App中注册双Wi-Fi服务后，当连接Wi-Fi时，可以开启、关闭Wi-Fi2能力，在连接Wi-Fi2后，可以获取Wi-Fi2的连接状态、网络链路属性和网口状态信息等。
