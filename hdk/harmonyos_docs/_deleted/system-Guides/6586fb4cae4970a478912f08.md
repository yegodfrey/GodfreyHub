# 业务介绍

HEM（HUAWEI Enterprise Manager，以下简称HEM）是依托华为终端强大的平台和硬件能力为您提供的移动管理终端设备的解决方案。通过该解决方案提供的设备部署服务（Device Deployment Service）可替代人工部署的方式来实现为企业客户的终端设备自动批量安装DPC（Device Policy Controller，设备策略管理器）App。  

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:--------|:-----------------|:--------------|
|华为手机/华为平板|HarmonyOS 2.0及以上版本|5.2.1.300及以上|

#### 角色介绍

|角色|说明|
|:----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|企业客户|可在HEM设备部署平台进行部署设备，也可在您已合作的EMM厂商提供的管理平台进行部署设备。具体操作详情参见[企业客户操作指导](https://developer.huawei.com/business/cn/doc/distribution/HEM/hem_user-guide_procedure-0000001190034425)。|
|EMM厂商|集成HEM开放的自动部署能力和移动设备管理能力，为企业客户提供定制化的移动设备解决方案。具体操作详情参见[EMM厂商操作指导](https://developer.huawei.com/business/cn/doc/distribution/HEM/developer_operation-procedure-0000001144194520)。|

#### 功能使用限制

|业务|使用限制说明|
|:--|:------------------------------------------|
|HEM|* 仅支持未激活的新终端设备 * 不支持BYOD（自带设备）场景 * 仅支持企业级设备|
