# 版本更新说明

#### 1.0.1.501（2021-05-11）

|-------------------------------------------------------------------------------|
|Android版本：com.huawei.device:hapticsengine:1.0.1.501 新增特性 此次版本更新hianalytics依赖方式。|

#### SDK依赖说明

* 系统预置振动类型：最新版本SDK需要用户终端设备版本在EMUI 9.0及以上，如果用户终端设备版本过低请升级版本。
* 自定义振动类型：最新版本SDK需要用户终端设备版本在EMUI 11.1.0及以上。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。  

#### 历史版本

#### 1.0.1.500（2021-01-19）

|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：Haptics Engine 1.0.1.500 新增特性 华为推出了全新的Haptics Engine 1.0.1.500版本，主要是新增马达振动波形自定义能力，应用开发者调用相应的API实现马达振动波形自定义业务，欢迎广大开发者接入使用，详见[Haptics Engine API参考](https://developer.huawei.com/consumer/cn/doc/development/system-References/overview-0000001088616777)。|

#### 1.0.1.300（2020-06-24）

|------------------------------------------------------------------------------------------------------------------------------|
|版本：Haptics Engine 1.0.1.300 新增特性 此次的版本是第一个稳定版本，主要是废弃、新增振动类型常量，提供新的振动能力，将华为线性马达振动能力封装成便于开发者使用的开放接口，帮助开发者快速实现应用内调用华为自研的线性马达振动能力。|

#### 1.0.0.400（2020-04-11）

|-----------------------------------------------------------------------------|
|版本：Haptics Engine 1.0.0.400 新增特性 此次的版本主要是已知问题修复，提升Haptics Engine算法能力，优化SDK架构。|
