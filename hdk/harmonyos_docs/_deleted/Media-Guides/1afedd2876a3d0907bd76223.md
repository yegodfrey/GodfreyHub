# SDK隐私安全说明

华为软件技术有限公司（以下简称"我们"或"华为"）将通过本文档向应用开发者和其用户说明SDK的隐私安全信息，包括图像服务SDK处理的个人信息范围、处理目的、权限使用情况、如何获取最新的SDK等。有关用户的个人信息主体权利、HMS Core其他服务如何收集和使用用户的个人信息，您可参阅[HMS Core开放能力隐私声明](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/privacy-0000001261262707)。

如果您是开发者，在接入、使用图像服务SDK和服务前，请按照本说明要求在您应用的隐私政策中向您的用户告知SDK相关信息，并获取用户的同意或取得其他合法性基础。

如果您是用户，在您使用集成了本SDK的应用前，请务必仔细阅读相关应用的隐私政策及本SDK安全隐私说明，确保您充分理解和同意之后再开始使用。  

#### SDK处理的个人信息

为了向应用开发者和其用户提供本SDK和服务，我们会收集、使用、存储服务所必需的如下个人信息。

基于不同的设备和系统及系统版本，以及开发者在集成、使用我们SDK产品时决定的权限，收集的设备信息会有所不同，因此开发者应对实际收集的个人信息向用户进行说明。  

|个人信息类型|个人信息清单|使用目的|存留期|
|:-----|:--------|:-------------------------------|:----------------|
|网络信息|运营商信息|用于统计分析与服务改进|5年。|
|设备信息|系统设置、系统属性|获取系统的屏幕宽高进行不同机型的尺寸适配|图像服务在处理图片数据后立即删除。|
|用户资产|相册、图片|图像服务处理用户相册中的图片信息，以提供图片编辑和动效渲染服务。|图像服务在处理图片数据后立即删除。|
|用户资产|文本|图像服务处理用户文本信息，以控制不同的图片编辑和动效渲染效果。|图像服务在处理文本数据后立即删除。|

如果您是开发者，在您接入、使用Image Kit SDK和服务前，我们要求您在隐私政策中向用户告知我们SDK的名称、SDK提供方名称、收集个人信息类型、使用目的、隐私政策链接，并获取用户的同意或取得其他合法性基础。您可以参考如下方式提供条款内容：

* 以文字方式向用户告知 第三方SDK名称：华为场景智能设计服务SDK、华为场景动效服务SDK

  第三方名称：华为软件技术有限公司

  收集个人信息类型：网络信息、设备信息、用户资产

  使用目的：为了统计分析与服务改进我们将获取您的运营商信息，为了对不同机型的尺寸适配我们将获取您的设备信息，访问用户的相册和图片以及用户输入的文本信息控制不同的图片编辑和动效渲染效果。

  隐私政策链接：[SDK隐私安全说明](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sdk-data-security-0000001050199029)

#### SDK延迟初始化

为了避免开发者的应用在未获取您的同意前，SDK提前启动收集使用您的个人信息。华为图像SDK提供了初始化接口[ImageVision.getInstance](https://developer.huawei.com/consumer/cn/doc/development/Media-References/vision-imagevision-0000001050199211#section5222194019283)和[ImageRender.getInstance](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerender-0000001050199303#section254292516422)，要求开发者的应用获取您的同意后才能调用此接口初始化SDK。  

#### SDK数据安全保护

SDK端侧采集消息本地加密，采集服务器采用HTTPS安全协议，并在上报数据时加密传输。  

#### SDK版本更新声明

为了向您提供最新的、安全的服务，我们会不时更新SDK版本。我们强烈建议开发者集成使用最新版本的SDK并向开发者提供了下载[链接](https://developer.huawei.com/consumer/cn/doc/development/Media-Library/sdk-download-0000001050439625)。  

#### SDK工作方式

* 场景智能设计SDK
  1. 场景智能设计SDK在应用打包时会被加载在您的应用当中，SDK会随着第三方应用启动而启动。当用户关闭应用时，SDK会随着第三方应用的关闭而关闭，不会在后台做任何额外动作。
  2. 对于颜色滤镜服务，SDK会将这部分信息传给相应服务APK侧进行渲染，SDK侧不对图片内容做分析且APK侧只在内存中渲染并返回处理后图片。
  3. 图文智能排版、图像主题标签服务，需要第三方应用传入图片信息，SDK会通过Image Kit APK把图片传到云侧，云侧处理完之后会立即销毁图片数据，不涉及图片保存。
  4. 当调用图片裁剪、贴纸花字服务时，需要第三方应用传入图片信息，SDK侧对图片进行处理并返回处理后的图片，不涉及图片保存。需要特别说明的是，贴纸花字服务需要读取您提供的资源文件，因此需要对应的读取权限。
* 场景动效SDK
  1. 场景动效SDK在应用打包时会被加载在您的应用当中，SDK会随着第三方应用启动而启动。当用户关闭应用时，SDK会随着第三方应用的关闭而关闭，不会在后台做任何额外动作。
  2. 当调用场景动效服务时，需要第三方应用传入待解析资源路径。SDK会将这部分信息传给场景动效服务APK侧进行解析和渲染，SDK侧不对图片和脚本内容做分析，且APK侧只在内存中渲染并返回视图。
  3. 在调用动效录制功能时，会在应用的内部存储中缓存图片，录制结束后销毁，不涉及图片保存。
