# 业务介绍

#### 业务简介

音频编辑服务（Audio Editor Kit）是华为帮助全球开发者快速构建各类应用音频能力的服务，本服务为您提供AI配音、音源分离、空间渲染、变声、多种音效等音频能力，您可依据应用场景，在App中轻松完成音频功能的集成。  

#### 支持的设备

|平台|设备类型|OS版本|
|:------|:----|:------------------------------|
|Android|华为手机|EMUI 5.0 \~ 11、HarmonyOS 2.0及以上|
|Android|非华为手机|Android 7.0 \~ 13|
|REST|-|-|

#### 场景介绍

* 支持多音频导入，能够生成并预览单音频或多音频的波形。
* 支持音频编辑基本操作，例如调整音量、调整音速音调、复制和删除音频等。
* 支持对音频添加特效功能，可新增多个特效，例如音乐风格、声场、均衡器、淡入淡出、变声、添加音效、环境效果等。
* 支持对音频进行变声，语音版变声-针对人声优化，语音不支持带背景音乐，变声类型包括大叔、萝莉、男生、女声、怪兽、卡通、机器人；通用版变声-支持人声和带背景音乐，变声类型包括大叔、萝莉、男生、女声、怪兽、颤音、赛博朋克、星际战争、混响、合成器。
* 支持对音频文件进行空间方位渲染，具体包括：固定摆位（一定空间内指定位置渲染）、动态渲染（支持在一定空间内指定位置、单周环绕时间和时针方向渲染）和扩展（支持按照半径和角度扩展）。
* 支持录制和导入音频功能。
* 支持音源分离功能，包括人声、伴奏、鼓、小提琴、贝斯、钢琴、木吉他、电吉他、弦乐、主唱、带伴唱伴奏和管弦乐的提取。
* 支持AI配音，中文：萝莉女童、乖萌女童、可爱男童、治愈童声、标准女声、知心女声、悬疑女声、资讯女声、清澈女声、亲切女声、温柔男声、磁性男声、悬疑男声、阳光男声。中文方言：东北男声、东北女声、天津男声、陕西女声、河南男声、台湾女声。英文：Male、Female带情感的音色。
* 支持声音美化，包括CD、清澈、剧场、录音棚效果。可提升声音质感，营造不同的氛围效果。
* 支持歌声合成功能，中文：抒情流行女声、民谣男声、国风女声。支持通过字级别输入歌词进行音素转换和预置曲目合成歌声，并调整细节参数音高、滑音、呼吸音、颤音等，让歌声更自然。
* 支持降噪功能，对音频中的稳态噪声或者突发噪声进行处理并对语音进行修复和增强，提升语音信号质量。
* 支持音频提取功能，从MP4等格式的视频中提取出音频进行编辑。
* 支持格式转换功能，支持音频转换为MP3、WAV、FLAC的格式；支持采样率、通道数、比特率转换。
* 支持格式获取功能，包括格式、采样率、声道数、位深、比特率和时长信息。
* 支持草稿功能，可以保存项目的编辑状态，包括轨道静音、独奏状态等（指针位置、预览波形显示隐藏除外）。此外还提供了草稿删除、复制和重命名功能。
* 支持空间效果功能，可以识别音频文件中的人声、管弦、鼓、吉他、贝斯、钢琴元素，并按照特定规则生成具有空间效果的音频。

#### 服务优势

* 简单接入 提供产品级SDK，接口简单易用、开放性强、稳定可靠，节省开发人力物力时间，帮助您快速实现自有App的音频编辑功能。

* 功能丰富 为开发者提供音频导入、编辑、特效、导出等服务，功能丰富，满足用户从简单到复杂的音频创作需求。

* 全球化 面向全球开放服务。
