# 业务介绍

|---------------------------------------------------------------|-|
|图像服务（Image Kit）为您提供图像智能编辑与设计、场景动效制作能力，高效地实现图片内容再生产，可以辅助设计师设计图片。| |

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:---|:----------|:----------------------------------------------|
|华为手机|EMUI 8.0及以上|4.0.2及以上；若未安装，或安装了其他版本的APK，功能可以正常使用，但不支持版本自动升级。|

#### 主要功能

* 提供小苍兰、蒹葭等24种独具特色的[颜色滤镜](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sample_filter-0000001057629349)，可完成图片后期处理，实现图片高质量内容生产。
* 提供图文智能排版功能，共有[9种智能排版样式](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/layout_styles-0000001055579860#ZH-CN_TOPIC_0000001055579860__p148830277492)，可以完成图像、文字的智能排版处理，实现图文内容高效生产。（图文智能排版服务已于2022/7/11下线，如使用将返回默认兜底版式[样式三](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/layout_styles-0000001055579860#section04235019433)。）
* 提供[贴纸花字](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sample_sticker-0000001057749345)处理功能，用户可对贴纸和花字进行缩放、拖动、删除操作，花字支持用户自定义文本输入，可实现图片个性化DIY。
* 提供[图像主题标签](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sample_label-0000001058429336)功能，支持用户原创内容场景下用户图片的标签生成，同时可支持对图片进行主体检测后再识别对应主体区域的标签，使图片内容更易被检索和发现。（图像主题标签服务已于2022/7/11下线，如使用将报错误码200300，详见[场景智能设计错误码](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/vision-errorcode-0000001050992673)。）
* 提供[图片裁剪](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sample_clip-0000001058877780)功能，实现图片大小调整 。

* 提供5种基础动效，并支持多动效叠加使用。
  * [位移](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-basic-animations-0000001050197020#section3314121517517)：在设定时间内，改变图片位置，实现图片位移动效。
  * [旋转](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-basic-animations-0000001050197020#section12551341853)：在设定时间内，改变图片旋转角度，实现图片旋转动效。
  * [缩放](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-basic-animations-0000001050197020#section2426447152)：在设定时间内，改变图片的宽高，实现图片缩放动效。
  * [透明度](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-basic-animations-0000001050197020#section168841646443)：在设定时间内，改变图片透明度，实现图片渐隐动效。
  * [帧动画](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-basic-animations-0000001050197020#section257819582515)：在设定时间内，由多张有序图片组成的连续动画效果。
* 提供9种效果炫酷的高级动效，并支持用户交互。
  * [跟手粒子](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section125719615820)：当手指在手机屏幕上滑动时，在滑动轨迹处会生成粒子。
  * [水波纹](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section1380611217910)：点击屏幕产生全屏水波纹效果，网格分的越多，水波效果越细腻。
  * [笔刷](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section197014364914)：当手指滑动屏幕时可以擦除覆盖图片或覆盖颜色所在的图层，显示出背景图片所在图层。
  * [跑马灯](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section19519320131020)：在屏幕的边框处展示跑马灯特效。
  * [粒子散落](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section313462315112)：提供图片粒子化散落和粒子图片散落两种不同的动效模式，其中图片粒子化是将图片转换成粒子并实现不同的散落动效，而粒子图片散落是按照一定的轨迹散落一定数量的图片，类似于散花的效果。支持多种散落模式。
  * [旋涡动效](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section7665545191115)：将图片分成网格，手指触摸屏幕时图片呈向心收缩的动画（如水池排水时旋涡效果），且旋涡中心随手指移动。
  * [下落动效](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section199772415198)：提供了一系列物体移动、旋转、透明度设置、移动区域设置的组合动效。
  * [翻书动效](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section443334091011)：用户手指从书页右下角移动时，呈现翻书效果，支持多张书页图片，实现连续翻书效果。
* [网格化](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-advanced-animations-0000001050439249#section206864017102)：网格化动效支持对输入图片划分为多个子网格区域，并在子网格区域中操作对应的局部图片。位移、旋转、缩放、水波荡漾效果支持局部渲染，透明度仅支持全局渲染；其中，位移、旋转、缩放可以与透明度组合使用，其他组合不支持。  

#### 工作原理

1. 您通过在App内集成图像服务SDK，向Image Kit发送图片编辑请求，并鉴定是否有权限。
2. Image Kit最终可以在图片中添加滤镜、动效等设计选项。
3. Image Kit将响应App的请求，对图片进行解析、环境配置、处理、渲染。  

#### 资源使用限制

* 图像智能编辑设计服务
  * 滤镜服务的待解析图片不大于15M，图片分辨率不超过8000\*8000，宽高比在1:3和3:1之间。
  * 图文智能排版服务中要求图片宽高比9:16，图片大小限制在10MB以内，如果宽高比不是9:16，则会被裁剪为9:16。
  * 图像主题标签服务中，建议图片分辨率大小224\*224，宽高比1:1。
  * 图片裁剪服务建议图片分辨率大于800\*800。
  * 对于图像智能编辑设计服务提供的能力，输入的图片分辨率越大，解析和响应时间、内存和CPU占用以及功耗都有可能相应增加。
* 场景动效服务 待解析图片不大于10M，随着图片增大，解析和响应时间、内存和CPU占用以及功耗都会相应增加（甚至出现卡顿、黑屏等异常情况）。同时，考虑到交互效果，目前只支持全屏显示动效视图（场景动效服务返回的视图需要在全屏展示）。在调用录制动效功能时，若用户手机性能较低，GIF压缩率需要限定在0.3及以下，帧率限定在20及以下。
