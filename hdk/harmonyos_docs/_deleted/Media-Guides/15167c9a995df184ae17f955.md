# 版本更新说明

#### 1.0.3.306（2022-08-03）

|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本场景智能设计服务：com.huawei.hms:image-vision:1.0.3.306 Android版本场景动效服务：com.huawei.hms:image-render:1.0.3.305 修改特性 * 场景智能设计服务：移除鉴权逻辑，不再需要鉴权。 * 场景智能设计服务：图文智能排版服务和图像主题标签服务已下线。 * 场景化动效服务：移除鉴权逻辑，不再需要鉴权。|

#### SDK依赖说明

* 最新版本SDK需要用户手机上安装HMS Core（APK）4.0.2及以上版本；同时，如果用户手机没有安装对应版本的Image Kit (APK)，您的应用调用Image SDK时，会自动引导用户更新Image Kit (APK)。
* 最新版fallback-SDK支持在未安装HMS Core（APK）的手机上使用，场景化动效服务需与SDK配套使用，场景智能设计只集成fallback-SDK即可，但均不支持升级Image Kit APK。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
