# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSPanoramaKit)快速体验一个应用的开发过程。  

#### 开发环境

* 安装Android Studio 3.6.1及以上

* JDK 1.8及以上
* 您的应用应满足以下条件：

  * minSdkVersion 19及以上
  * targetSdkVersion 30（推荐）
  * compileSdkVersion 30（推荐）
  * Gradle 5.4.1及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个Kit中的较高版本。
* 测试应用的设备：EMUI 4.0及以上的华为手机。

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-agc-0000001050258474)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-agc-0000001050258474#section1464519554325)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-agc-0000001050258474#section15850522183317)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-agc-0000001050258474#section147011294331)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-agc-0000001050258474#section19713716202718)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/integrating-sdk-0000001050284242)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-obfuscation-scripts-0000001050123524)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[使用入门](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/dev-process-0000001050414811)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[调用应用外全景展示](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/guideoutside-0000001050044229)|应用外全景展示调用说明。|
|5|[调用应用内全景展示](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/guideinside-0000001050042280)|应用内全景展示调用说明，该方式更灵活。|
|6|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/pre-release-check-0000001050695088)|华为提供对应用自动检查的能力。|
|7|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/app-release-0000001050265556)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。
