# FAQ

#### Android

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 音频编辑服务对设备和软件有哪些要求？

音频编辑服务支持EMUI 5.0 \~ 11或HarmonyOS 2.0及以上的华为手机和Android 7.0 \~ 13的非华为手机。音源分离（端侧）能力和空间效果能力只支持64位系统。  

#### 调用音频编辑服务收费吗？

音频编辑服务SDK当前提供的接口均免费。  

#### 音频编辑服务支持导入和导出哪些格式的音频？

音频编辑服务支持导入AAC、WAV、M4A、MP3、FLAC、AMR、WMA、AC3、AIFC、APE、AU、AIFF的音频；支持导出MP3、WAV、FLAC三种格式的音频。
