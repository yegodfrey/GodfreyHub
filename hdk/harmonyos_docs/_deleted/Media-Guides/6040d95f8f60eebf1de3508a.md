# 业务介绍

视频服务（Video Kit）提供视频播放、HDR Vivid视频处理服务，后续将提供视频编辑和视频托管服务，助力您快速构建视频特性，帮助您向用户提供视频媒体体验。  

#### 支持的设备

|SDK名称|设备类型|OS版本|HMS Core（APK）版本|
|:--------------|:------------------------------------------------------|:-------------------------|:--------------|
|Video SDK|华为手机、华为平板、非华为Android手机、非华为Android平板|EMUI 3.1及以上/Android 5.0及以上|4.0.1.300及以上|
|Video SDK|华为智慧屏|HarmonyOS 2.0及以上|-|
|HDR Vivid SDK|支持HDR Vivid格式视频解码能力的华为手机、华为平板、非华为Android手机、非华为Android平板|EMUI 5.0及以上/Android7.0及以上|-|
|HDR Ability SDK|仅支持实现了亮度接口的华为手机|HarmonyOS 3.0及以上|-|

#### 场景介绍

* 视频点播场景 您可以在App客户端直接集成Video Kit播放器SDK，并通过第三方提供的视频地址播放点播视频。

  点播视频的播放支持HTTP(S)、HLS、DASH协议和3GP、MP4、TS文件格式。暂不支持本地视频播放。

  例如：若您是一个工具类App的应用开发者，期望通过托管在第三方云平台上的视频宣传推广您的App，可以直接使用Video Kit播放器SDK提供的播放接口，实现视频内容的在线播放。

<!-- -->

* 视频直播场景 您可以在App客户端直接集成Video Kit播放器SDK，并通过第三方提供的直播视频地址播放直播视频。

  直播视频的播放支持HTTP(S)协议和FLV文件格式。
* HDR Vivid视频处理场景 您可以在App客户端直接集成HDR Vivid SDK，使用HDR Vivid SDK提供的HDR Vivid视频图像的OETF、Tonemapping、HDR2SDR等能力，助力您快速构建HDR Vivid视频的播放、分享特性，帮助您向用户提供HDR Vivid视频媒体体验。

您也可以在App客户端集成HDR Ability SDK，使用HDR Ability SDK提供的亮度相关能力，获得更好的HDR视频播放体验。HDR Ability SDK可以单独集成，也可以和HDR Vivid SDK配合使用。
