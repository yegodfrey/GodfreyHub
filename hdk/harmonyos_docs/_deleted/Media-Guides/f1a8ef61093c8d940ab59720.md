# 添加权限

在调用视频编辑能力时，您需要先在"AndroidManifest.xml"文件中申请如下权限。
在"AndroidManifest.xml"中添加后，对于Android 6.0及更高的版本，还需要在代码中动态申请权限。您可以根据实际需要自行判断动态权限申请在应用中的位置。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.48580873747829036737951680527616:50001231000000:2800:48763A82D464AE7E6F6D6A0501B78D814591147EEF92EA0A899502531FE3282F.png)  
请在用户同意隐私政策后，再进行权限申请。

* UI SDK

  ```
  <!--震动权限-->
  <uses-permission android:name="android.permission.VIBRATE" />
  <!--麦克风权限-->
  <uses-permission android:name="android.permission.RECORD_AUDIO" />
  <!--写存储（媒体和文件）权限-->
  <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
  <!--读存储（媒体和文件）权限-->
  <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
  <!--访问网络权限-->
  <uses-permission android:name="android.permission.INTERNET" />
  <!--侦听网络状态权限-->
  <uses-permission android:name="android.permission.CHANGE_NETWORK_STATE" />
  <!--查看网络状态权限-->
  <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
  <!--查看手机状态权限-->
  <uses-permission android:name="android.permission.READ_PHONE_STATE" />
  ```
