# 使用入门

#### 开发环境

* JDK 1.7及以上

* 安装Android Studio 3.X及以上
  * minSdkVersion 23及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 4.6及以上（推荐）
* 测试应用的设备：EMUI 11或HarmonyOS 2.0及以上的华为手机和平板，以及HarmonyOS 2.0.0.172及以上版本的华为智慧屏。

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。  

|序号|步骤|说明|
|:-|:------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050039992)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：注册成为开发者、创建应用、申请加入数字版权服务白名单、开通数字版权管理服务。|
|2|[加密视频内容](https://developer.huawei.com/consumer/cn/doc/Media-Guides/wiseplay-encrptflow-0000001050039994)|构建密钥管理模块，利用转码器加密视频内容。|
|3|[播放视频内容](https://developer.huawei.com/consumer/cn/doc/Media-Guides/wiseplay-encrptplayflow-0000001050041949)|调用DRM客户端和DRM服务端提供的接口，实现获取License并播放视频内容的能力。|
|4|[集成测试资源](https://developer.huawei.com/consumer/cn/doc/Media-Guides/wiseplay-resources-0000001057749543)|华为提供一个开放的调测环境。|
|5|[开发后自检](https://developer.huawei.com/consumer/cn/doc/Media-Guides/pre-release-check-0000001050041961)|华为提供对应用自动检查的能力。|
|6|[上架申请](https://developer.huawei.com/consumer/cn/doc/Media-Guides/app-release-0000001228866440)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
