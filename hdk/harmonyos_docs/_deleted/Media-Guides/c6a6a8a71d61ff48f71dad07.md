# 业务介绍

#### 业务简介

多媒体管线服务（AV Pipeline Kit，简称AV Pipeline）是面向移动端开发者的多媒体开放能力体系，在这个开放体系中包含一个轻量级的多媒体开发框架和一系列高性能的音视频处理插件。多媒体开发框架负责解析配置文件并将多个插件按照配置文件中的编排关系连接组成一个流水线（以下简称为Pipeline），实现特定的媒体业务，如播放、录制、编辑等。音视频处理插件负责完成特定的任务，例如解封装、解码、滤波等。

AV Pipeline框架旨在降低媒体应用的开发难度，通过定义插件的标准接口和数据流在插件之间的流转方式，您只需要按照标准接口完成插件开发，就可以迅速构建出新型的媒体场景。

AV Pipeline Kit已预置可应用在播放场景的Pipeline，如视频播放、视频超分、声音事件检测，并提供Java接口供您使用。同时，也支持开发者通过C++接口直接调用单个预置插件。若预置插件或预置Pipeline不满足使用要求，开发者可以自定义插件、自定义Pipeline。

#### 场景介绍

* 视频播放Pipeline 提供预置的基础播放Pipeline，您可以使用该Pipeline完成视频播放。

* 视频超分Pipeline 在播放视频的过程中，将低分辨率视频实时转换成高分辨率视频，改善视频清晰度，增加视频细节表现力，提升用户观看体验。

* 声音事件检测Pipeline 在播放音频流过程中，自动分辨声音中的事件内容，可以应用在工业安全监测、智慧城市安防、机器人巡检等机器听觉领域。

* 媒体资产管理 提供对封装媒体文件的解析能力，可以解析文件中包含的所有媒体流和信息以及读取压缩的数据流，为您的媒体应用带来更强的媒体解析能力。

* MediaFilter AV Pipeline的接入方式较为灵活，不仅支持调用已组建的Pipeline，也提供直接调用单个AI插件的方式。MediaFilter类适用于仅集成单个AI插件到应用中的场景。

* 自定义插件 AV Pipeline提供标准插件接口和定义插件间数据流转的方式，可帮助您快速开发出自定义插件并集成到Pipeline中，构建新的媒体场景。

* 自定义Pipeline AV Pipeline支持自行定义编排关系、自行构建其它媒体场景。例如将开发的自定义插件编排成自定义Pipeline。
