# 添加权限

在调用音频编辑能力时，您需要先在"AndroidManifest.xml"文件中申请如下权限。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240705122844.62883305222717597491454212077754:50001231000000:2800:D18A322DC5092675498374CFDCC8F1D25A461DBD923148D3839BEC0932B3173C.png?needInitFileName=true?needInitFileName=true)  
* 请在用户同意隐私政策后，再进行权限申请。
* 在Android 13开发环境下，请添加\<uses-permission android:name="android.permission.READ_MEDIA_AUDIO"/\>和\<uses-permission android:name="android.permission.READ_MEDIA_VIDEO"/\>这两个权限。

```
<!--震动权限-->
<uses-permission android:name="android.permission.VIBRATE" />
<!--麦克风权限-->
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<!--写存储（媒体和文件）权限-->
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
<!--读存储（媒体和文件）权限-->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
<!--网络权限-->
<uses-permission android:name="android.permission.INTERNET" />
<!--网络状态权限-->
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<!--网络状态变化权限-->
<uses-permission android:name="android.permission.CHANGE_NETWORK_STATE" />
```
