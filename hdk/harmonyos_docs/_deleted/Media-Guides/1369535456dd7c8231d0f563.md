# 版本更新说明

#### 1.0.15.304（2023-11-27）

|-----------------------------------------------------------------------|
|Android版本：com.huawei.hms:videokit-player:1.0.15.304 新增特性 依赖组件升级，优化内部逻辑。|

#### SDK依赖说明

* 最新版本Video SDK需要用户手机上安装HMS Core（APK）4.0.1.300及以上版本。
* 最新版本fallback SDK支持智慧屏和未安装HMS Core（APK）的手机上使用，可以集成相同版本的fallback SDK和Video SDK，功能可以正常使用。
* HDR Vivid SDK可以单独集成。
* HDR Ability SDK可以单独集成。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
