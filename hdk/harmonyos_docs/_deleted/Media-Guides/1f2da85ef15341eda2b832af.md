# SDK隐私安全说明

华为软件技术有限公司（以下简称"我们"或"华为"）将通过本文档向应用开发者和其用户说明SDK的隐私安全信息，包括全景服务SDK处理的个人信息范围、处理目的、权限使用情况、如何获取最新的SDK等。有关用户的个人信息主体权利、HMS Core其他服务如何收集和使用用户的个人信息，您可参阅[HMS Core开放能力隐私声明](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/privacy-0000001261262707)。

如果您是开发者，在接入、使用全景服务SDK前，请按照本说明要求在您应用的隐私政策中向您的用户告知SDK相关信息，并获取用户的同意或取得其他合法性基础。

如果您是用户，在您使用集成了本SDK的应用前，请务必仔细阅读相关应用的隐私政策及本SDK安全隐私说明，确保您充分理解和同意之后再开始使用。  

#### SDK处理的个人信息

全景服务（Panorama Kit）是华为为您提供的全景图片浏览和交互服务。您通过集成全景服务SDK，可以在Android手机上快速将球形展开的全景图片或柱状全景图片在模拟的三维空间中以可交互的方式展示，给用户带来沉浸感与真实感。

为了向应用开发者和其用户提供本SDK和服务，我们会收集、使用、存储服务所必需的如下个人信息。

基于不同的设备和系统（Android/iOS）及系统版本，以及开发者在集成、使用我们SDK产品时决定的权限，收集的设备信息会有所不同，因此开发者应对实际收集的个人信息向用户进行说明。  

|个人信息类型|个人信息清单|使用目的|存留期|
|:-----|:-------------|:-----------------|:----------|
|设备信息|传感器信息（旋转矢量传感器）|支持全景图片浏览和交互服务|处理图片数据后立即删除|
|网络信息|运营商信息|上报打点信息，用于统计分析及服务改进|5年|

如果您是开发者，在您接入、使用全景服务SDK前，我们要求您在隐私政策中向用户告知我们SDK的名称、SDK提供方名称、收集个人信息类型、使用目的、隐私政策链接，并获取用户的同意或取得其他合法性基础。您可以参考如下方式提供条款内容：

* 以文字方式向用户告知 第三方SDK名称：华为全景服务SDK

  第三方名称：华为软件技术有限公司

  收集个人信息类型：设备信息、网络信息

  使用目的：支持全景图片浏览和交互服务和上报打点信息，用于统计分析及服务改进

  隐私政策链接：[SDK隐私安全说明](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sdk-data-security-0000001050044235)

#### SDK权限说明

EMUI OS、HarmonyOS 2.0.0：  

|权限|权限描述|使用目的|
|:----------------------------------------------|:-----|:--------------------------|
|存储 读权限：android.permission.READ_EXTERNAL_STORAGE|读取外部存储|读取存储上文件给定的URI，获取图片资源进行解析并渲染|

HarmonyOS 2.0.1及之后版本：  

|权限|权限描述|使用目的|
|:-------------------------------------------------|:-----|:--------------------------|
|媒体与文件 读权限：android.permission.READ_EXTERNAL_STORAGE|读取外部存储|读取存储上文件给定的URI，获取图片资源进行解析并渲染|

#### SDK延迟初始化

为了避免开发者的应用在未获取您的同意前，SDK提前启动收集使用您的个人信息。华为全景服务SDK提供了初始化接口[getInstance](https://developer.huawei.com/consumer/cn/doc/development/Media-References/api-pano-0000001050124412)，要求开发者的应用获取您的同意后才能调用此接口初始化SDK。  

#### SDK数据安全保护

SDK端侧采集消息本地加密，采集服务器采用HTTPS安全协议，并在上报数据时加密传输。  

#### SDK版本更新声明

为了向您提供最新的、安全的服务，我们会不时更新SDK版本。我们强烈建议开发者集成使用最新版本的SDK并向开发者提供了下载[链接](https://developer.huawei.com/consumer/cn/doc/development/Media-Library/sdk-download-0000001050122324)。  

#### SDK工作方式

全景服务SDK在应用打包时会被集成进您的应用当中，SDK会随着相关接口的调用而启动和关闭，不会在后台做额外动作。全景服务SDK解码图片只会在运行时留存在内存中，而SDK本身并不对内容做分析，图片内容因为全景服务的原因被截取的风险低。
