# 业务介绍

|---------------------------------------------------------------------------------------------------------------|-|
|音频服务（Audio Kit）是华为公司在音频领域的能力集合，为您提供了基于HMS Core的音频播放能力，包括硬件及系统底层的音频编解码能力。 您可以基于Audio Kit快速搭建自己的音频播放能力，构建自己的音频应用。| |

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:--------|:-------------|:--------------|
|华为手机、华为平板|EMUI 4.0及以上|5.0.0.300及以上|
|荣耀手机、荣耀平板|Android 6.0及以上|5.0.0.300及以上|

#### 场景介绍

* 音频播放：
  * 提供本地音频及在线音频的解析和播放能力，最高可支持384kHz/24bit的高品质音频编码格式解析和播放，包括m4a/aac/amr/imy/wav/ogg/rtttl/mp3/ape/flac等音频格式。
  * 支持分块传输编码（chunked transfer encoding）模式（下文简称chunk模式）音频资源的播放。
  * 支持应用内指定文件目录下音频播放：包括Android工程目录"\\app\\src\\main\\res\\raw"和Android工程目录"\\app\\src\\main\\assets"文件夹中音频文件的播放。
* 播放操作：播放、暂停、上一首、下一首、停止播放、倍速播放、拖拽进度条。
* 音量调节：音量增加、音量减少。
* 播放列表管理：读取专辑列表、保存列表、删除列表、增加列表的音频内容。
* 播放模式管理：顺序播放、列表循环、单曲循环、随机播放。
* 保存播放进度：再次播放时从保存的进度开始继续播放。
* 音频内容缓存并加密。
* 音效管理：
  * 支持10段均衡开放设置，可自定义调节各频段音量。
* 支持11种常规典型音效（流行、古典、摇滚、爵士、舞曲等）和5种高级音效（绝美人声、空灵轻音、3D旋转、超重低音、车载音效）设置。
