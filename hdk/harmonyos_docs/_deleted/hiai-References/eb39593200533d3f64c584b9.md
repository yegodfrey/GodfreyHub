# Init

#### 接口定义

```
AIStatus Init(std::shared_ptr<AiModelManagerClientListener> listener);
```

#### 功能介绍

创建模型管家。  

#### 参数

|名称|类型|描述|
|:-------|:-----------------------------------------|:-------------------------------------------|
|listener|shared_ptr\<AiModelManagerClientListener\>|通知回调接口。 * nullptr：同步模型管家。 * 非nullptr：异步模型管家。|

#### 返回

|类型|描述|
|:-------|:----------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。|
