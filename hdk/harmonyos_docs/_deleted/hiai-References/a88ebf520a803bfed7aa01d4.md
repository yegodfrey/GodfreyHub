# Init

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150631.33692248710911610439021425361910:50001231000000:2800:417B84123DD91AA616D03D9B5197870C025852675E9F6A44C7B3E09BBAB79EF1.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[Load](https://developer.huawei.com/consumer/cn/doc/hiai-References/load-0000001051490688)替代。  

#### 接口定义

```
virtual Status Init(const ModelInitOptions& options, const std::shared_ptr<IBuiltModel>& builtModel, const std::shared_ptr<IModelManagerListener>& listener) = 0;
```

#### 功能介绍

加载模型。  

#### 参数

|名称|类型|描述|
|:---------|:------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------|
|options|const [ModelInitOptions](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelinitoptions-0000001138937761)\&|模型加载参数。|
|builtModel|const std::shared_ptr\<IBuiltModel\>\&|编译完成的模型的对象。|
|listener|std::shared_ptr\<[IModelManagerListener](https://developer.huawei.com/consumer/cn/doc/hiai-References/onrundone-0000001139476001)\>\&|异步回调监听。 * nullptr：同步。 * 非nullptr：异步。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
