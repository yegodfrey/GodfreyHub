# GetSize

#### 接口定义

```
virtual uint32_t GetSize() const;
```

#### 功能介绍

获取Tensor buffer内存大小（单位：byte）。  

#### 返回

|类型|描述|
|:-------|:---------------|
|uint32_t|tensor buffer大小。|
