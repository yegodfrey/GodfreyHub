# Build

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150627.38941151148273071250969498294258:50001231000000:2800:F6E9AF60F45800ADE29E24E3442D97D7A72C03BF32074119C5383F0770B61E0F.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[BuildModel](https://developer.huawei.com/consumer/cn/doc/hiai-References/buildmodel-0000001053089431)替代。  

#### Build(const ModelBuildOptions\& options, const std::string\& modelName, const std::shared_ptr\<IBuffer\>\& modelBuffer, std::shared_ptr\<IBuiltModel\>\& builtModel)

#### 接口定义

```
virtual Status Build(const ModelBuildOptions& options, const std::string& modelName, const std::shared_ptr<IBuffer>& modelBuffer, std::shared_ptr<IBuiltModel>& builtModel) = 0;
```

#### 功能介绍

对保存在内存中的模型进行在线编译。  

#### 参数

|名称|类型|描述|
|:----------|:------------------------------------------------------------------------------------------------------------------------------------|:------------|
|options|const [ModelBuildOptions](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbuildoptions-0000001139374903)\&|模型的编译参数。|
|modelName|const std::string\&|模型名称。|
|modelBuffer|const std::shared_ptr\<[IBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/createlocalbuffer-0000001139126323)\>\&|待编译模型的buffer。|
|builtModel|std::shared_ptr\<IBuiltModel\>\&|编译完成的模型对象。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|

#### Build(const ModelBuildOptions\& options, const std::string\& modelName, const std::string\& modelFile, std::shared_ptr\<IBuiltModel\>\& builtModel)

#### 接口定义

```
virtual Status Build(const ModelBuildOptions& options, const std::string& modelName, const std::string& modelFile, std::shared_ptr<IBuiltModel>& builtModel) = 0;
```

#### 功能介绍

对保存在文件中的模型进行在线编译。  

#### 参数

|名称|类型|描述|
|:---------|:---------------------------------------------------------------------------------------------------------------------------|:--------------|
|options|const [ModelBuildOptions](https://developer.huawei.com/consumer/cn/doc/hiai-References/modelbuildoptions-0000001139374903)\&|模型的编译参数。|
|modelName|const std::string\&|模型名称。|
|modelFile|const std::string\&|待编译模型的文件名，包含路径。|
|builtModel|std::shared_ptr\<IBuiltModel\>\&|编译完成的模型的对象。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
