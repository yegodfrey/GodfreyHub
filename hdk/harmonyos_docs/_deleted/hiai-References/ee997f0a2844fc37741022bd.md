# Cancel

#### 接口定义

```
void Cancel(const std::string& modelName);
```

#### 功能介绍

取消模型异步推理任务。  

#### 参数

|名称|类型|描述|
|:--------|:------------------|:----|
|modelName|const std::string\&|模型名称。|
