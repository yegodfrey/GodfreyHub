# SaveToFile

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150636.11467783803516385551193269612956:50001231000000:2800:185912694E9D9C130667E64207D8EE4FA9570C5A8F424774CE9D62059E108F81.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[MemBufferExportFile](https://developer.huawei.com/consumer/cn/doc/hiai-References/membufferexportfile-0000001051809426)替代。  

#### 接口定义

```
virtual Status SaveToFile(const char* file) const = 0;
```

#### 功能介绍

保存模型到指定的文件。  

#### 参数

|名称|类型|描述|
|:---|:-----------|:------------------|
|file|const char\*|用户指定的保存模型的文件名，包含路径。|

#### 返回

|类型|描述|
|:-----|:-------------------------|
|Status|* SUCCESS：成功。 * Others：失败。|
