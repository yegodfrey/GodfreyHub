# DeviceMemoryReusePlan

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150638.58475606642767033887102973918111:50001231000000:2800:BB780B91390E813F3897675EB989139BBE0BDBF8CEEE954DF007C33E25C2A4D5.png)  
此接口从DDK 5.0.1.0版本起废弃，请使用模型管家V1接口[DeviceMemoryReusePlan](https://developer.huawei.com/consumer/cn/doc/hiai-References/devicememoryreuseplan-0000002050722333)替代。  

|Enum Info|
|:--------------------------|
|设备内存复用配置选项，从参数控制模型运行时的内存申请。|

|Enum Value and Description|Value|
|:----------------------------|:----|
|UNSET 不使用。|0|
|LOW 低内存复用率。申请的内存较高但模型推理性能有收益。|1|
|HIGH 高内存复用率。模型申请的内存较低。|2|
