# SetTensorDimension

#### 接口定义

```
AIStatus SetTensorDimension(const TensorDimension* dim);
```

#### 功能介绍

设置Tensor的尺寸结构信息。  

#### 参数

|名称|类型|描述|
|:--|:----------------------|:---------------|
|dim|const TensorDimension\*|输入Tensor的尺寸结构信息。|

#### 返回

|类型|描述|
|:-------|:-------------------------------------------------------------------------------------------|
|AIStatus|* AI_SUCCESS：成功。 * Others：失败。如下： * AI_INVALID_PARA：dim为空。 * AI_FAILED：Tensor size为0或者申请内存失败。|
