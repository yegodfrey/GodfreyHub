# OS新增和增强特性

#### 6.1.0(23) Release（仓颉Beta1）关键特性

#### [h2]Cangjie Kit（仓颉）

  * class JSContext新增func requireArkModule(String)接口。开发仓颉与ArkTS混合应用时，仓颉侧可通过该接口加载ArkTS三方库。当模块被加载后，可以通过互操作接口访问导出的变量和调用导出的接口。（[指南](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-cangjie-load-arkts)）
