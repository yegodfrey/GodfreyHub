# DevEco Studio-Cangjie Plugin

本小节说明DevEco Studio安装配套仓颉插件后，和仓颉语言相关的功能新增和变更情况。

#### DevEco Studio-Cangjie Plugin 6.0.2 Beta2新增特性

无新增和增强特性。

#### DevEco Studio-Cangjie Plugin 6.0.2 Beta1新增特性

#### [h2]仓颉应用开发

支持端到端进行仓颉HarmonyOS应用开发和测试，具体能力集请参见[工具指南](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-ide-tools-overview)。

  * DevEco Studio支持开发API 22工程。
  * 新增仓颉HarmonyOS应用模板，支持创建仓颉模板应用。
  * 支持仓颉语言服务，包括代码高亮、代码跳转、查找引用、格式化、代码重构等能力。
  * 支持构建仓颉开发的HarmonyOS应用。
  * 支持连接真机设备或模拟器运行仓颉开发的HarmonyOS应用并对仓颉代码进行调试。
  * 支持对仓颉开发的HarmonyOS应用进行性能调优。



#### [h2]使能仓颉能力

  * 支持在DevEco Studio上使能仓颉开发能力，DevEco Studio上新增“Cangjie(Experiment)”页签，支持在IDE上下载安装DevEco Studio-Cangjie Plugin。
