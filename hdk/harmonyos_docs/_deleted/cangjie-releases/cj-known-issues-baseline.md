# 已解决和已知的问题

#### [h2]DevEco Studio-Cangjie Plugin 6.1.1 Beta1版本解决的问题

  * 修复了某些场景下出现的空指针异常报错。

  * 优化了仓颉语言服务崩溃场景下的打点日志。
