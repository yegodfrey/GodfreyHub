# DevEco Studio-Cangjie Plugin

本小节说明DevEco Studio安装配套仓颉插件后，和仓颉语言相关的功能新增和变更情况。

#### DevEco Studio-Cangjie Plugin 26.0.0 Beta2新增特性

  * 新增支持ArkTS到仓颉的跨语言单步调试
  * 新增支持调试仓颉代码时展示仓颉协程信息
  * 代码重构新增支持提取代码为字段、提取代码为入参以及提取接口



#### DevEco Studio-Cangjie Plugin 26.0.0 Beta1新增特性

#### [h2]仓颉应用开发

支持端到端进行仓颉HarmonyOS应用开发和测试，具体能力集请参见[工具指南](https://developer.huawei.com/consumer/cn/doc/cangjie-guides/cj-ide-tools-overview)。

  * 对编辑器易用性进行优化，新增支持自定义代码折叠规则，支持未使用符号置灰，支持quick fix快速实现抽象方法，支持双击大括号快速选中代码块


  * 新增支持ArkUI调优模板
  * 新增支持ArkWeb调优模板
  * 新增支持GPU调优模板
