# 接口功能  
  
当用户完成应用外PMS商品支付后，华为数字商品服务器调用此接口通知开发者服务器向用户发放对应的商品。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 华为服务器 -> 开发者服务器  
接口URL| URL为开发者在配置商品营销信息时配置的“接收发货通知地址”。  
数据格式| 请求：Content-Type: application/json响应：Content-Type: application/json  
  
# 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
data| M| DeliveryRequest| 通知发货的请求信息。  
sign| M| string| 华为服务器在发送通知时对**data** 中的所有参数使用SHA256WithRSA算法进行了签名，并在sign参数中返回签名后的字符串。开发者需要使用[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgalleryconnect_gettestKey)中获取的验签公钥对签名字符串进行验签，验签方法参见验签示例。说明：华为服务器端对sign进行了urlencode处理，开发者需要对sign进行urldecode处理才能获取真实的签名字符串。  
  
**DeliveryRequest**

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
developerId| M| string| 开发者帐号的CP ID，用于唯一标识当前开发者。  
appId| M| string| 需要发货的应用ID。  
orderId| M| string| 支付订单号。  
productNo| M| string| 需要发货的商品ID。  
openId| M| string| 用户的唯一标识。如果开发者使用unionId作为用户唯一标识，在获取openId后可根据openId和unionId的对应关系自行映射。  
count| M| string| 默认传1。  
ts| M| string| 通知发送时间的时间戳。  
  
# 返回参数

参数名称| 必选(M)/可选(O)| 类型| 参数含义  
---|---|---|---  
error| O| string| 处理失败时包含操作结果的JSON字符串，格式为“{"errorCode": xxx, "errorMsg": xxxx}”。

  * errorCode：错误码，具体取值请参见错误码。
  * errorMsg：错误码对应的描述信息。

  
data| O| string| 处理成功时包含操作结果的JSON字符串，格式为“{"reslut": 0}”。0表示处理成功，可以发货。  
  
# 错误码

错误码| 说明  
---|---  
1| 验签失败  
2| 超时  
3| 业务信息错误，例如报文无法解析  
4| IP白名单限制，开发者侧拒绝服务说明：开发者请勿设置白名单，此错误码仅仅用于异常监控。  
11| 商品不存在  
12| 用户不存在  
13| 商品库存不足  
94| 系统错误  
95| IO错误  
96| 错误的请求URL  
97| 错误的响应  
98| 参数错误  
99| 其他错误
