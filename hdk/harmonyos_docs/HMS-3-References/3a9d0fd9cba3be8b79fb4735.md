CLASS info  
---  
public class SmsRetriever  
开启读取短信的服务，直到读取到符合规则的短信或者服务超时（超时时间5分钟）。  
  
## Constant Summary

Type| Name| Desc  
---|---|---  
String| SMS_RETRIEVED_ACTION| 获取短信时Intent对应的action值。  
String| EXTRA_SMS_MESSAGE| Intent中获取到的短信字符串对应的key值。  
String| EXTRA_STATUS| Intent中获取到的状态码对应的key值，包含成功和超时两个状态。
