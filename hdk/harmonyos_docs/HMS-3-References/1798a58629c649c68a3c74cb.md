# 接口功能

应用可以调用本接口向华为支付服务器校验支付结果中的购买令牌，确认支付结果的准确性。

# 调用场景

在完成一笔支付后，华为支付服务器会返回商品订单详情JSON字符串[inAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/iap-InAppPurchaseData)和签名字符串inAppDataSignature。应用可以通过验证签名字符串方式确保订单详情的准确性。

如果应用对安全性要求较高，需要进一步到华为支付服务器验证订单信息，可以从[inAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/iap-InAppPurchaseData)中解析出purchaseToken参数（用于唯一标识商品和用户对应关系的购买令牌），并调用本接口向华为支付服务器发起校验请求。

注意：该接口只针对非订阅型商品，包括消耗型商品和非消耗型商品。

                                             

本节接口可选调用，应用有服务器校验要求时才需要调用。

# 接口约束

请求头需要使用AccessToken进行鉴权，这里使用开放平台鉴权提供的服务接口获取AccessToken。

响应体要求使用应用RSA支付公钥进行验证，具体参考[](https://developer.huawei.com/consumer/cn/service/hms/doc/hmssdk_jointOper_verifySignV3.html)[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/HMS-3-Guides/iap-verifying-signature-returned-result)。支付公钥获取请参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallery_querypaymentinfo)。

# 请求参数

**参数名称**                | 必选(M)/可选(O)| **数据类型**                | **参数描述**                  
---|---|---|---  
purchaseToken| M| String| 待下发商品的购买Token，发起购买和查询待消费商品信息时均会返回purchaseToken参数。                  
productId| M| String| 待下发商品ID。商品ID来源于开发者在AppGallery Connect中配置商品信息时设置的“商品ID”。                  
  
# 响应参数

**参数名称**                | 必选(M)/可选(O)| **数据类型**                | **参数描述**

responseCode| M| String| 返回码。                ●  0：成功                ●  其他：失败，具体参考接口错误码。                  
responseMessage| O| String| 响应描述。

# 接口错误码

**错误码**                | **含义**                  
---|---  
0| 成功                  
1| 用户按下了“返回”或者取消了对话                  
2| 网络连接丢失                  
3| Billing API版本不受所请求类型的支持                  
4| 请求的商品不可以购买                  
5| 向API提供的参数无效，此错误也可能说明应用未在IAP中针对应用内购买结算正确签署或设置，或者在清单中没有所需的权限                  
6| API操作期间发生致命错误                  
7| 由于已经拥有该商品，购买失败                  
8| 由于未拥有该商品，消耗失败                  
9| 商品已经消耗，不能再次消耗                  
  
错误码的类型，请以具体的响应参数类型为准。
