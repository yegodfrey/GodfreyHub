# Public Methods

## **public Task<Player> getCurrentPlayer()**

获取当前登录的玩家对象。

**返回值**  
返回[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/player-v3 "Player")类型的玩家对象。  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个ApiException实例对象，然后根据[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/apiexception-v3 "ApiException")实例中包含的getStatusCode()进行一些必要错误场景的处理。

**调用示例**
    
    
     复制
      
        1. Task<Player> task = client.getCurrentPlayer();
        2. task.addOnSuccessListener(new OnSuccessListener<Player>() {
        3.    @Override
        4.     public void onSuccess(Player player) {
        5.         String playerId = player.getPlayerId();
        6.     }
        7.     }).addOnFailureListener(new OnFailureListener() {
        8.     @Override
        9.     public void onFailure(Exception e) {
        10.         if  (e instanceof ApiException) {
        11.             (ApiException) e).getStatusCode()
        12.         }
        13.     }
        14. });
