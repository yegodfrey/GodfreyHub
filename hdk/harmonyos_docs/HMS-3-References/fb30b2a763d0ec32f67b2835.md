# **Public  Methods**

### public static Task<ProductOrderBuffer> getMissProductOrder(Context context)

查询当前登录的华为帐号未发货的订单信息。

**请求参数**

Return| Description  
---|---  
context| 客户端的Context。  
  
**返回值**

返回[ProductOrderBuffer](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productorderbuffer-v3)对象，从[ProductOrderBuffer](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productorderbuffer-v3)对象可以获取订单数据。

您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/apiexception)实例对象，然后根据[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/apiexception)实例中包含的getStatusCode()进行一些必要错误场景的处理。
