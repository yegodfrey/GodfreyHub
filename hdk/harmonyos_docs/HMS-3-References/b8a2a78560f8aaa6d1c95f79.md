sysIntegrity(byte[] nonce, String appid)  
发起一次对当前设备的系统安全检测请求。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
nonce| A cryptographic nonce used for anti-replay and tracking of requests.一个密码学的 nonce 值，用于防重放攻击。您必须确保每次调用 sysIntegrity 接口时传入的 nonce 值都是不同的。  
appId| 您在华为开发者联盟网站上申请的 appId。HMS Core 会对 appId 进行鉴权，你需要在华为开发者联盟网站的 API 管理上打开这个 appId 访问 Safety Detect 服务的开关。
