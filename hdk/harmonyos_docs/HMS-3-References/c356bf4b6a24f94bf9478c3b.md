# Public Methods

## **public static AchievementsClient getAchievementsClient(Activity activity, SignInHuaweiId account)**

获取Activity使用的[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievementsclient-v3 "AchievementsClient")实例。

**请求参数**

参数名| 参数说明  
---|---  
activity| 客户端的Activity。  
account| 登录成功的[SignInHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-signInhuaweiId "SignInHuaweiId")对象，未登录时传null。  
  
**返回值**  
返回[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievementsclient-v3 "AchievementsClient")类型的实例，应用可以调用[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievementsclient-v3 "AchievementsClient")的方法进行成就相关操作。

## **public static GamesClient getGamesClient(Activity activity, SignInHuaweiId account)**

**请求参数**

参数名| 参数说明  
---|---  
activity| 客户端的Activity。  
account| 登录成功的[SignInHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-signInhuaweiId "SignInHuaweiId")对象，未登录时传null。  
  
**返回值**  
返回[GamesClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/gamesclient-v3 "GamesClient")类型的实例，应用可以调用[GamesClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/gamesclient-v3 "GamesClient")的方法完成游戏相关基础功能。
