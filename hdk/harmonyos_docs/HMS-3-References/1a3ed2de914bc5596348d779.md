public [Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/tasks-V3)<Location> getLastLocation()  
返回最后一次请求的可用位置。如果某个位置不可用，则返回null。该接口并不会主动请求位置，将使用上一次请求的缓存位置。位置开关关闭时，缓存位置将被清除。

public [Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/tasks-V3)<void> requestLocationUpdates([LocationRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationrequest-v3) request，[LocationCallback](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationcallback-v3) callback，Looper looper)  
请求位置更新，并在指定的Looper线程上回调。该方法要求请求方进程存在才能持续回调。如进程被杀后仍然希望能够持续收到回调，请参考[requestLocationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3 "requestLocationUpdates") (LocationRequest request,PendingIntent callbackIntent) 。  
  
**Parameters**

---|---  
request| 位置请求对象。  
callback| 位置更新的回调。  
looper| 为空时默认为当前线程的looper对象。

public [Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/tasks-V3)<void> requestLocationUpdates([LocationRequest](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/locationrequest-v3) request，PendingIntent callbackIntent)  
请求方使用PendingIntent的方式，持续请求位置更新，HMS把位置更新的结果LocationResult和LocationAvailability封装到Intent中，调用传入的PendingIntent的send()发送给请求方。如果请求方进程被杀死，使用此方法，依然能够持续回调。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
request| 位置请求对象。  
callbackIntent| 每个位置请求更新关联的PendingIntent，构造PendingIntent时需设置Class、Action，不能构造空Intent。  
  
**Return**

type| desc  
---|---  
[Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/tasks-V3)<void>| 任务。通过addOnSuccesslistener()和addOnFailureListener()添加监听，然后通过onSuccess()和onFailure()方法获取任务执行结果。

public [Task](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/tasks-V3)<void> setMockMode(boolean isMockMode)  
设置位置提供者是否使用位置模拟模式。为true时，将不再使用GPS或网络位置，最终直接返回通过setMockLocation(Location)设置的位置信息。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
isMockMode| 如果为true，则位置提供者将设置为模拟模式。如果为false，它将返回到正常状态
