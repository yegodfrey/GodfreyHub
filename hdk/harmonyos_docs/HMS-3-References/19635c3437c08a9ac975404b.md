终端用户在应用客户端发起个人数据删除请求，应用服务端调用此接口能够协助用户删除在分析服务平台的数据。  
  
# Request

## HTTP request

> POST https://<URI>/analytics/gdpr/user_deletion_requests/v2

### Request body

参数名称| Value| Description  
---|---|---  
aaid| String| 通过HMS端侧接口获取。  
  
  


# Response

响应HTTP状态码：

状态码| 描述  
---|---  
200| 成功。  
400| 错误，具体错误详情见错误码说明。  
500| 服务器系统错误。  
  
调用成功情况下，返回如下:
    
    
    复制
      
        1. {
        2.   "result_code":"0",
        3.   "result_msg":"success"
        4. }
    
    

状态码说明：

Parameter name| Value| Description  
---|---|---  
result_code| String  
| 响应码，详见错误码说明。  
result_msg| String| 响应描述。  
  
错误码说明：

**错误码**| **原因**| **说明**  
---|---|---  
10020| invalidParameter| 非法参数。  
10032| dataExportError| 数据导出中，无法删除。  
10033| dataDeleted| 数据已删除。  
10008| tooFrequentRequest| 接口请求过于频繁。
