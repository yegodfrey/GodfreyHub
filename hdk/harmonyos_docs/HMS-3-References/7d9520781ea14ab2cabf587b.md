public void setAnalyticsCollectionEnabled(boolean isEnabled)  
是否打开打点采集能力。关闭后将不再记录任何数据。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
isEnabled| 是否打开采集开关。默认打开。True：打开；False：关闭。

public void setAutoCollectionEnabled(boolean isEnabled)  
是否自动采集系统事件。默认打开，关闭后将不再自动采集事件，自动采集事件包括系统级事件和基于Activity的页面事件。关闭后自动采集功能后，如果您还需要分析这些事件，则需要您自行在合适的位置调用logEvent接口上报数据。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
isEnabled| 是否自动采集事件。默认打开。True：打开；False：关闭。

public void setUserProperty(String name, String value)  
设置用户属性。用户属性值将在整个应用程序生命周期和会话期间保持不变。最多支持25个用户属性名称，如果后面设置属性有重复的name，则刷新。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
name| 用户属性的标识符。非空，长度不超过256字节，不支持空格和不可见字符。  
value| 属性值。非空，长度不超过256字节。

public void setMinimumSessionDuration(long milliseconds)  
设置重新开始新Session的最短时间间隔。此方法设置的时间间隔，用于指定App在后台运行多长后，再次切回前台时，需要生成新的会话。默认30秒。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
milliseconds| 最短Session刷新间隔。单位：毫秒

public void setSessionTimeoutDuration(long milliseconds)  
设置Session超时时长。App一直在前台运行，当两个相邻事件的时间间隔超过此方法设置的阈值时，将生成一个新的会话。默认30分钟。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
milliseconds| Session超时时长。单位：毫秒

public void setCurrentScreen(Activity activity, String screenName, String screenClassOverride)  
设置当前页面名称，用于标识当前可见的页面。注意：当setAutoCollectionEnabled接口设置为true时，不需要调用此接口，Analytics Kit会自动采集$HA_SCREEN_ENTER和$HA_SCREEN_EXIT事件中的$HA_CUR_ACTIVITY_NAME 参数即为当前页面的名称。若您需要覆盖自动采集的$HA_SCREEN_ENTER和$HA_SCREEN_EXIT事件，您可在Activity的onResume中调用此方法，并指定页面名称（ScreenName,必须）和类名（screenClassOverride，可选，若为null或空，Analytics Kit将根据传入的activity获取类名）。您也可以调用该接口记录非Activity的页面事件(如Fragment, 自定义View等)，并指定相关页面名称（ScreenName，必须）。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
activity| 当前活动Activity。  
screenName| 当前活动页面名称，必须；非空，长度不超过256字节。  
screenClassOverride| 页面类名，可选，若设置为null或空，则会使用当前活动Activity的类名；长度不超过256字节。
