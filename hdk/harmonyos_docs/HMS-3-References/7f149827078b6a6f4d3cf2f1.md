ProductOrderBuffer类返回玩家应用外商品支付的未发货订单信息，在调用[ProductClient.getMissProductOrder](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productclient-v3#getMissProductOrder)方法时会返回该数据对象。

# **Public  Method Summary**

Return| Description  
---|---  
[ProductOrderInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productorderinfo-v3)| get(int position)获取未发货订单信息中指定序列的订单信息。  
  
# **Public  Methods**

## public ProductOrderInfo get(int position)

获取未发货订单信息中指定序列的订单信息，以[ProductOrderInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productorderinfo-v3)对象形式返回。

**请求参数**

Parameter Name| Description  
---|---  
position| 需要获取的订单在订单列表中的位置，从0开始，表示获取第1条订单数据。  
  
**返回值**

返回包含某条订单信息的[ProductOrderInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productorderinfo-v3)对象。
