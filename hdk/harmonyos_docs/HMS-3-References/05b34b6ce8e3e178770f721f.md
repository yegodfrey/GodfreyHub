class info

com.huawei.hms.analytics. HiAnalyticsTools  
此类提供了打开调试日志的方法，以支持开发阶段的调试需求。  
  
## Public Method Summary

Interface name| Method name  
---|---  
enableLog| 打开调试日志  
enableLog(int level)| 打开调试日志，可自定义打印的最小日志级别。  
  
## Public Methods

Method  
---  
public static void enableLog()  
打开研发调试日志。请在初始化之前打开，正式发布时务必关闭。  
  
  


Method  
---  
public static void enableLog(int level)  
打开调试日志，可自定义打印的最小日志级别。  
(有效内容：[Log.DEBUG(3),Log.INFO(4),Log.WARN(5),Log.ERROR(6)])  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
level| 开启指定级别的调试日志。Log.DEBUG,Log.INFO,Log.WARN,Log.ERROR
