# 接口功能

当开发者服务器完成发货后，需要调用此接口向华为服务器发送发货完成通知。

# 接口原型

承载协议| HTTPS PUT  
---|---  
接口方向| 开发者服务器 -> 华为服务器  
接口URL| https://connect-api.cloud.huawei.com/usage/delivery/callback  
数据格式| 请求：Content-Type: application/json响应：Content-Type: application/json  
  
# 接口约束

调用本接口前必须要通过华为服务器的API客户端认证，详细方法参见[获取Token](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/appgallerykit_gettoken-v3)。

# 请求参数

**header参数：**

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
developerId| M| String| 开发者帐号的CP ID，用于唯一标识当前开发者。  
appId| M| String| 应用ID，获取方法请参考[查询应用信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallery_queryappinfo)。  
client_id| M| String| [创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallerykit-createapiclient)中生成的客户端ID。  
authorization| M| String| 认证信息，格式为“Authorization: Bearer ${access_token}”。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/appgallerykit_gettoken-v3)中获取的access_token。access_token的有效期由[获取Token](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/appgallerykit_gettoken-v3)返回的expires_in确定。  
productId| M| String| 应用所在产品的产品ID，查询方法参见[查询产品ID](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallery_queryproductinfo)。  
  
**body参数：**

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
orderId| M| String| 支付订单号。  
productNo| M| string| 已发货的商品ID。  
openId| M| string| 用户唯一标识，传入用户的openId。  
status| M| int| 发货状态，目前只支持**0** ，表示发货成功。  
ts| M| long| 通知发送时间的时间戳。  
  
# 返回参数

参数名称| 必选(M)/可选(O)| 类型| 参数含义  
---|---|---|---  
error| O| String| 处理失败时包含操作结果的JSON字符串，格式为“{"errorCode": xxx, "errorMsg": xxxx}”。

  * errorCode：错误码，具体取值请参见错误码。
  * errorMsg：错误码对应的描述信息。

  
data| O| string| 处理成功时包含操作结果的JSON字符串，格式为“{"reslut": 0}”。0表示成功。  
  
# 错误码

错误码| 说明  
---|---  
1| 鉴权失败  
2| 超时  
3| 业务信息错误，例如支付订单不存在  
11| 商品不存在  
12| 用户不存在  
94| 系统错误  
95| IO错误  
96| 错误的请求URL  
97| 错误的响应  
98| 参数错误  
99| 其他错误
