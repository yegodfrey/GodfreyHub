# 1 接口定义

    void HMSAgent.Pay.pay(PayReq request, PayHandler handler);

# 2 接口描述

    此接口用于开发者自行设置商品价格，而不是从华为开发者平台获取价格。此接口不提供商品信息自动全球化能力，需要开发者在接口中指定价格、币种和国家。

  


# 3 参数

sign| String| 是| 否| 1、取相关参数字段，按参数名的ASCII码的增序排序，若遇到相同首字母，则看第二个字母，以此类推。  
【注意】参与签名的参数原则如下：  
a）所有payreq携带，标识为“参与签名”且参数值不为null或者“”的参数必须参与签名，签名时参数值必须与payreq传递的保持一致。  
b）sign参数不参与签名。  
2、排序完成之后，再把所有参数名和参数值的键值对以“&”字符连接起来，得到的字符串即为待签名串。  
3、将待签名字符串使用RSA私钥进行签名，得到的字符串即为sign参数的值。  
  
 

# 4 返回值  


    支付结果通过PayHandler 中的onResult方法回调
      
      1. public interface PayHandler {
        2.     /**
        3.      * 支付结果回调
        4.      * @param retCode 结果码
        5.      * @param payInfo 支付结果信息
        6.      */
        7.     void onResult(int retCode, PayResultInfo payInfo);
        8. }
    
    

   

  回调参数包括retCode 和payInfo，retCode是查询结果的错误码，融合了各个阶段的错误码，如果只需要判断错误码可直接使用。retCode取值和意义参考“[retCode业务错误码说明](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-tv-errorCode#h1-1575614722451)”。 

    payInfo是PayResultInfo的实例，包含了支付结果信息，PayResultInfo各字段意义如表5-2所示。

    **表5-2 PayResultInfo说明**

参数名| 参数类型| 说明

errMsg| String| 信息描述
