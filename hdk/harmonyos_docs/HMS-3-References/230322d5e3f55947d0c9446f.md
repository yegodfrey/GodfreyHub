PlayerLevelInfo类用于返回玩家等级信息，当前仅支持返回中国大陆玩家等级信息。

# Public Method Summary

Return| Method  
---|---  
[PlayerLevel](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playerlevel-v3 "PlayerLevel")| getCurrentLevel()  
获取包含玩家当前等级信息的[PlayerLevel](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playerlevel-v3 "PlayerLevel")对象。  
  
# Public Methods

## **public PlayerLevel getCurrentLevel()**  


获取包含玩家当前等级信息的[PlayerLevel](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playerlevel-v3 "PlayerLevel")对象。当前仅支持获取中国大陆玩家等级信息。  


**返回值**  
包含玩家当前等级信息的[PlayerLevel](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playerlevel-v3 "PlayerLevel")对象。
