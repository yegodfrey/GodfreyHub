# **接口功能**

应用调用此接口可以隐藏已经在游戏界面中显示的游戏浮标。

# **调用场景**

当用户操作触发游戏页面的onPause方法，例如切换游戏界面、切换应用等，应用需要在onPause中调用本接口隐藏游戏浮标。

# **接口约束**

  * 调用本接口前必须已经初始化HuaweiApiClient对象并连接HMS Core（APK），具体参见[初始化HuaweiApiClient对象](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-apiclient "初始化HuaweiApiClient对象")。如果HuaweiApiClient.isConnected()为true表示当前已经连接，请勿重复连接。

  * 对于EMUI 9.1.1及以上版本的华为设备，HMS Core（APK）会自动展示游戏浮标而忽略本接口的请求，开发者无需关注。

  * 同一个游戏界面必须已经调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/showfloatwindow-v3 "showFloatWindow")接口显示浮标以后，才能调用本接口隐藏浮标。




# **调用方法**
    
    
     复制
      
        1. HuaweiGame.HuaweiGameApi.hideFloatWindow(HuaweiApiClient client, Activity activity);
    
    

# **请求参数**

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
client| M| HuaweiApiClient| 已连接HMS Core（APK）的HuaweiApiClient对象。如果未初始化HuaweiApiClient对象，对象的初始化方法请参见[初始化HuaweiApiClient对象](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-apiclient "初始化HuaweiApiClient对象")。  
activity| M| Activity| 需要隐藏浮标的Activity实例。必须与调用showFloatWindow接口时传入的Activity示例一致。  
  
# **返回值**

无。

# **返回码**

无。
