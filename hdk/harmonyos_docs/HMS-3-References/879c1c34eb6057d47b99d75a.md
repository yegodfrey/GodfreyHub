PlayerLevel类返回玩家当前等级的具体数字信息，在调用[PlayerLevelInfo](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/playerlevelInfo-v3 "PlayerLevelInfo")的getCurrentLevel()方法时获取。当前仅支持获取中国大陆玩家等级信息。

# Public Method Summary

Return| Method  
---|---  
int| getLevelNumber()  
获取玩家当前级别的数字信息。  
  
# Public Methods

## **public int getLevelNumber()**

获取包含玩家当前等级的级别数字，例如“10”表示玩家级别为10。当前仅支持获取中国大陆玩家等级信息。  


**返回值**  
玩家等级的数字。
