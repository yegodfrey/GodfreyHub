JosApps类中定义了获取JosAppsClient和AppUpdateClient对象的方法，用于游戏初始化和应用更新。

Return| Method  
---|---  
static [JosAppsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/josappsclient-v3 "JosAppsClient")| getJosAppsClient(Activity activity, [SignInHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-signInhuaweiId "SignInHuaweiId") account)  
获取用于游戏初始化和游戏登录公告的[JosAppsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/josappsclient-v3 "JosAppsClient")实例。  
static [AppUpdateClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/appupdateclient-v3 "AppUpdateClient")| getAppUpdateClient(Activity activity)

# Public Methods

## **public static JosAppsClient getJosAppsClient(Activity activity, SignInHuaweiId account)**

获取使用Activity的JosAppsClient实例。

**请求参数**

参数名| 参数说明  
---|---  
activity| 客户端的Activity。  
account| 登录成功的[SignInHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-signInhuaweiId "SignInHuaweiId")对象，未登录时传null。  
  
**返回值**  
返回[JosAppsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/josappsclient-v3 "JosAppsClient")类型的实例，应用可以调用[JosAppsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/josappsclient-v3 "JosAppsClient")的方法进行应用初始化相关操作。

## **public static AppUpdateClient getAppUpdateClient(Context context)**

获取使用Activity的[AppUpdateClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/appupdateclient-v3 "AppUpdateClient")实例。

**请求参数**

参数名| 参数说明  
---|---  
context| 客户端的Context。  
  
**返回值**  
返回[AppUpdateClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/appupdateclient-v3 "AppUpdateClient")类型的实例，应用可以调用[AppUpdateClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/appupdateclient-v3 "AppUpdateClient")的方法进行应用升级相关操作。

## public static ProductClient getProductClient(Context context)

获取用于未发货订单查询的[ProductClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productclient-v3 "ProductClient")实例。

**请求参数**

参数名| 参数说明  
---|---  
context| 客户端的Context。  
  
**返回值**

返回[ProductClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productclient-v3 "ProductClient")类型的实例，应用可以调用[ProductClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productclient-v3 "ProductClient")的方法进行未发货订单查询。
