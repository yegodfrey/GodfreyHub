CLASS info  
---  
public final class RemoteMessage extends Object implements Parcelable  
RemoteMessage类是一个消息实体类，通过[onMessageReceived](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/HmsMessageService#onMessageReceived)(RemoteMessage)方法接收服务端推送的消息。[RemoteMessage.Notification](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/RemoteMessage-Notification)类是一个数据类，代表通知消息详情。RemoteMessage消息实体中可能包含[RemoteMessage.Notification](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/RemoteMessage-Notification)数据实例，Notification类中成员属性定义可以参见服务端发送Push消息中的[AndroidNotification](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/push-server-send#AndroidNotification)结构体定义说明。

public String getData()  
获取消息的有效内容数据。getData方法获取到的是String类型，非Java自带Map数据类型，由开发者自行决定格式的解析规则。如果在控制台界面上传入的是键值对（key-value）格式，会转化成JSON格式的String，需要开发者自行解析。如果通过push传输的数据涉及高敏感，高保密性，建议开发者自己对消息体进行加解密处理，以保证消息的安全性。
