# **接口功能**

应用调用此接口可以查询用户当前的实名认证信息，包括是否实名，用户是否成年。

# **调用场景**

如果游戏需要进行防沉迷处理，应用可以通过此接口与[getPlayerCertificationIntent](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/getcertificationIntent-v3 "getCertificationIntent")接口配合实现，具体的处理流程可参考[游戏防沉迷](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-anti-indulgence-v3 "游戏防沉迷")。

# **接口约束**

  * 本接口目前仅对中国大陆用户有效，非中国大陆用户将返回7006错误码。

  * 如果接口返回7001或7006错误码，请联系华为技术支持定位错误原因，请勿直接对用户进行强制实名认证。

  * 调用本接口前必须已经初始化HuaweiApiClient对象并连接HMS Core（APK），具体参见[初始化HuaweiApiClient对象](https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/game-apiclient "初始化HuaweiApiClient对象")。如果HuaweiApiClient.isConnected()为true表示当前已经连接，请勿重复连接。

**PlayerCertificationInfo**

参数名称| 必选(M)/可选(O)| 类型| 获取方法| 参数说明  
---|---|---|---|---  
status| M| Status| certificationInfo.getStatus()| 包含查询结果业务返回码的对象，可通过certificationInfo.getStatus().getStatusCode()方式获取，具体请参见返回码。

● -1：未实名认证。
