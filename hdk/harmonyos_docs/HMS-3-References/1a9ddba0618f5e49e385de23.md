ProductOrderInfo类主要用于返回某个未发货订单的具体信息，在调用[ProductOrderBuffer.get](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/productorderbuffer-v3#get)方法时会返回该类型的实例。  


# Public Method Summary

Return| Description  
---|---  
abstract String| getTradeId()获取业务订单ID，业务订单号由华为服务器维护，开发者可无需关注。  
abstract String| getProductNo()获取未发货的商品ID。  
abstract String| getOrderId()获取未发货订单的支付订单ID。  
abstract String| getSign()获取订单的签名字符串，应用服务端可以参考[对掉单数据验签](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallerykit-missodersignature-v3)向华为服务器验证订单信息的有效性。  
  
# Public Methods

## public abstract String getTradeId()

获取业务订单ID。

## public abstract String getProductNo()

获取未发货的商品ID。

## public abstract String getOrderId()

获取支付订单ID。

## public abstract String getSign()

获取订单数据的签名字符串，应用服务端可以参考[对掉单数据验签](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallerykit-missodersignature-v3)验证订单信息的有效性。
