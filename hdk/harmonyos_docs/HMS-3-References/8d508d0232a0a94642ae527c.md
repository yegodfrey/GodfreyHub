Method  
---  
public String getInAppDataSignature();  
该方法返回使用支付私钥签署购买数据（getInAppPurchaseData方法返回的字符串）生成的签名字符串。签名算法为SHA256WITHRSA。  
  
**Return**

type| desc  
---|---  
String| 包含已使用应用私钥签署的购买数据（inAppPurchaseData）的签名字符串。签名算法为SHA256WITHRSA。  
支付成功后应用需要参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/iap-verifying-signature-returned-result)使用支付公钥对inAppPurchaseData的JSON字符串进行验签。  
公钥获取参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallery_querypaymentinfo)。
