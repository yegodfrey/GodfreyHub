public class HuaweiIdSignInResult extends Result  
开发者通过调用getSignInAccount()方法来获取SignInHuaweiId实例对象，进而得到该对象中封装的授权信息、用户信息等相关华为帐号所包含的内容。  
  
## Public Method Summary

Return| Method  
---|---  
[SignInHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-signInhuaweiId)| getSignInAccount()  
授权成功后，从授权结果信息HuaweiIdSignInResult中获取包含华为帐号授权信息的SignInHuaweiId对象，如果未授权则返回null。  
void| setSignInHuaweiId(SignInHuaweiId signInHuaweiId)  
设置HuaweiIdSignInResult对象实例。  
boolean| isSuccess()  
授权结束后，调用该方法判断返回结果是否授权成功。true表示授权成功，false表示授权失败。
