EventBuffer类返回玩家的事件列表信息，在调用[EventsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/eventsclient-v3)的load或loadByIds方法时会返回该数据对象。

# Public Method Summary

Event| get(int position)获取事件列表中指定序列的事件信息。  
---|---  
  
# **Public  Methods**

#### public Event get(int position)

获取事件列表中指定序列的事件信息，以Event对象形式返回。

**请求参数**

position| 需要获取的事件在事件列表中的位置，从0开始，表示获取第1条事件数据。  
---|---  
  
**返回值**

返回包含事件信息的Event对象。
