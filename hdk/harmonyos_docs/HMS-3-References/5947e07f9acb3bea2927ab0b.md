Safety Detect API 的返回实体基类

Return type| Method name  
---|---

## Public Methods

Method  
---  
public int  getRtnCode()  
返回 Safety Detect 响应的状态码，如果响应成功，则返回 0。具体的状态码对应的错误类型，请参考 [SafetyDetectStatusCode](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/safetydetectstatuscodes "SafetyDetectStatusCode")。  
  
  
**Return**  


type| desc  
---|---  
int| Safety Detect 响应的状态码  
Method  
---  
public String getErrorReason ()  
返回 Safety Detect 状态码的详细信息仅当 getRtnCode 返回不为 0 时，才返回非空值。  
  
  
**Return**  


type| desc  
---|---  
String| SafetyDetect返回异常时，获取错误原因。
