集成hms-ads-installreferrer SDK后，可使用相应API，获取转化跟踪参数。  
  
## Classes

Return type| Method name  
---|---  
[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030505 "InstallReferrerStateListener")| 建立服务链接的回调接口；当与服务完成建立时，将调用此侦听器的onInstallReferrerSetupFinished(int)方法。  
[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030506-v3 "InstallReferrerClient")| 抽象类，获取转化跟踪参数的客户端类。  
[InstallReferrerClient.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030507-v3 "InstallReferrerClient.Builder")| 用于创建InstallReferrerClient实例的Builder类。  
[ReferrerDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030508 "ReferrerDetails")| 描述转化跟踪参数。
