接口协议：HTTPS/HTTP

响应协议接口数据格式：JSON

协议接口数据字符编码：UTF-8

l   接口支持get、post、delete，查询类操作使用get，修改类操作为post、delete；

l   编码：utf-8；

l   Post Content Type：application/json；

l   Get Content Type：application/x-www-form-urlencoded；

l   认证信息基于请求Header指定，具体为：

    − 应用级AT：Authorization: Basic Base64(APPAT:atvalue)

n   例如，发送请求的应用级AT为: thisIsAppAtValue

n   则APPAT:atvalue为: APPAT:thisIsAppAtValue

n   Base64(APPAT:atvalue)则计算方式为Base64(“APPAT:thisIsAppAtValue”)，值为: QVBQQVQ6dGhpc0lzQXBwQXRWYWx1ZQ==

n   最终请求头Authorization的值为: Basic QVBQQVQ6dGhpc0lzQXBwQXRWYWx1ZQ==

    − 无认证信息：没有对应的Header

l   语言信息基于请求Header中Accept-Language指定，取值为标准的Locale。
