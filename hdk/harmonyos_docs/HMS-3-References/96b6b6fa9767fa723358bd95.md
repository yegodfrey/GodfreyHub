class info  
---  
public interface InstallReferrerStateListener  
建立服务链接的回调接口；当与服务完成建立时，将调用此侦听器的onInstallReferrerSetupFinished(int)方法。  
  
## Public Method Summary

Return type| Method name  
---|---  
abstract void| onInstallReferrerServiceDisconnected()  
abstract void| onInstallReferrerSetupFinished(int responseCode)  
  
## Public Methods

Method  
---  
abstract void onInstallReferrerServiceDisconnected()  
当服务断开连接时该方法被调用以通知监听者。  
  
Method  
---  
abstract void onInstallReferrerSetupFinished(int responseCode)  
当连接服务完成时调用以通知监听者，其中responseCode描述。  
  
**Parameters：**

Parameter name| Parameter desc  
---|---  
responseCode| 连接响应状态。-1：连接服务失败(打开成华为移动服务（APK）自启动权限)0：连接成华为移动服务（APK）服务成功(获取转化跟踪参数)1：服务不存在(下载安装最新成华为移动服务（APK）版本)2：服务不支持(升级成华为移动服务（APK）版本2.6.5及以上)3：开发者调用错误(开发者代码检视)
