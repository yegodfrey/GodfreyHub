**Event** 类返回具体事件通知信息，在调用EventBuffer的get方法时会返回Event类型的实例。  
  
# Public Method Summary

return type| description  
---|---  
abstract String| getDescription()获取事件描述。  
abstract void| getDescription(CharArrayBuffer dataOut)将事件描述信息加载到CharArrayBuffer中。  
abstract String| getEventId()获取事件ID。  
abstract String| getFormattedValue()获取事件数值对应的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。  
abstract void| getFormattedValue(CharArrayBuffer dataOut)将事件数值对应的本地化数字，加载到CharArrayBuffer。例如阿拉伯国家加载的就是阿拉伯语对应的数字。  
abstract Uri| getIconImageUri()获取事件图标的URI地址。  
abstract String| getName()获取事件的名称。  
abstract void| getName(CharArrayBuffer dataOut)将事件的名称加载到CharArrayBuffer中。  
abstract [Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/player-v3)| getPlayer()获取事件对应的当前登录玩家信息。  
abstract long| getValue()获取当前登录玩家的当前事件数值。  
abstract boolean| isVisible()是否显示该事件。  
  
# Public Methods

## public abstract String getDescription()

获取当前事件的描述信息。请根据实际情况选择使用getDescription()或getDescription(CharArrayBuffer dataOut)

**返回值**

当前事件的描述信息。

## public abstract void getDescription(CharArrayBuffer dataOut)

将事件的描述信息加载到**CharArrayBuffer** 中。

**请求参数**

parameter| description  
---|---  
dataOut| 需要加载事件描述信息的CharArrayBuffer对象。  
  
## public abstract String getEventId()  


获取当前事件的事件ID。

**返回值**

事件ID。

## public abstract String getFormattedValue()

获取事件数值对应的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。

**返回值**

返回本地化语言的数字。

## public abstract void getFormattedValue(CharArrayBuffer dataOut)

将事件数值对应的本地化数字，加载到CharArrayBuffer。例如阿拉伯国家加载的就是阿拉伯语对应的数字。

**请求参数**

parameter| description  
---|---  
dataOut| 需要加载本地化数字的CharArrayBuffer对象。  
  
## public abstract Uri getIconImageUri()  


获取事件图标的URI地址。

**返回值**

图标的URI地址。

## public abstract String getName()

获取当前事件的名称。

**返回值**

当前事件名称。

## public abstract void getName(CharArrayBuffer dataOut)

将事件名称加载到CharArrayBuffer。

**请求参数**

parameter| description  
---|---  
dataOut| 需要加载事件名称的CharArrayBuffer对象。  
  
## public abstract Player getPlayer()  


获取当前登录的玩家信息。

**返回值**

以[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/player-v3)对象方式返回玩家具体信息。

## public abstract long getValue()

获取当前登录玩家的当前事件数值。

**返回值**

当前登录玩家的数值。

## public abstract boolean isVisible()

是否显示该事件。

**返回值**

  * true：显示

  * false：不显示
