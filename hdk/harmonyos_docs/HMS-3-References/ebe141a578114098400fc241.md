您的应用可以通过url scheme方式跳转到华为IAP的管理订阅页面和订阅详情页面。管理订阅页面展示的是当前用户在您的应用已订阅的商品列表，订阅详细页展示的是用户已在您应用订阅的某个商品详情及该商品订阅组其他商品信息。

![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/23da1cf9fff241f7a16d726839255f221257759730027454598.png)     ![](https://obs.cn-north-2.myhwclouds.com/hms-ds-wf/b/4b3cdc4aa4334fa581a7bb04e1a2dce2-7005711207115774914.png)

  


scheme方式跳转 url路径：pay://com.huawei.hwid.external/subscriptions

url参数

参数| 必选(M)/可选(O)| 说明  
---|---|---  
package| M| 应用包名  
appid| M| 在华为开发者联盟注册应用时分配的appid  
sku| O| 商品id。注意：当传入该值时，会跳转到订阅详情页面，否则跳转到管理订阅页面  
  
  * 跳转到管理订阅页



    
    
    复制
      
        1. Intent intent = new Intent(Intent.ACTION_VIEW);
        2. intent.setData(Uri.parse("pay://com.huawei.hwid.external/subscriptions?package=com.huawei.demo&appid=1888888"));
        3. startActivity(intent);
    
    

  * 跳转到订阅详情页



    
    
    复制
      
        1. Intent intent = new Intent(Intent.ACTION_VIEW);
        2. intent.setData(Uri.parse("pay://com.huawei.hwid.external/subscriptions?package=com.huawei.demo&appid=1888888&sku=1234"));
        3. startActivity(intent);
