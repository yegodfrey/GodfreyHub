集成Analytics SDK后，可使用相关API，进行代码埋点与上报，实时数据埋点与上报，用户数属性设置，自动事件采集与Session计算等。  
  
## Classes

Class name| Class description  
---|---  
[HiAnalyticsTools](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/88249984)| 此类提供了打开调试日志的方法，以支持开发阶段的调试需求。  
[HiAnalytics](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/10702127)| 此类提供了获取Analytics Kit实例的方法。  
[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/64695092)| Analytics单例类，提供上报用户行为数据的公共方法。  
[HiAnalyticsInstallReceiver](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/17633291)| 此类为哑实现。  
[HiAnalyticsReceiver](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/49624754)| 此类为哑实现。
