Method

public String getPaymentSignature();  
该方法返回使用支付私钥签署购买数据（getPaymentData方法返回的字符串）生成的签名字符串。签名算法为SHA256WITHRSA。  
注意：应用在收到签名字符串后，需要参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/iap-verifying-signature-returned-result)对购买数据的JSON字符串校验签名，成功才继续拉起支付。公钥获取参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallery_querypaymentinfo)。  
  
**Return**

type| desc  
---|---  
String| 使用支付私钥签署购买订单数据（getPaymentData方法返回的字符串）生成的签名字符串。签名算法为SHA256WITHRSA。
