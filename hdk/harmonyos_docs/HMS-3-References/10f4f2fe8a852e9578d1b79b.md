# **1.接口信息**

**功能：** 华为push服务器调用此接口给开发者服务器推送回执消息。

**约束：** 开发者需要在AppGallery Connect上开通“消息回执”权益，回执权益开通[请参考消息回执章节开通回执权益](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/push-receipt-v3#receiptright)。

# **2.接口原型**

**承载协议**|  HTTPS POST  
---|---  
**接口方向**|  华为服务器->开发者回执消息接收服务器  
**接口URL**|  开发者的回执接收服务器的地址，由开发者定义，同AppGallery Connect上配置的回执地址一致，回执地址配置[请参考消息回执章节回执参数配置](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/push-receipt-v3#receiptconfig)。  
  
# 3.接口参数

**接口请求参数（HTTP header****）**

**参数**| **取值描述**| **样例**  
---|---|---  
X-HUAWEI-CALLBACK-ID| 消息头鉴权参数，可选字段。当回执配置中回调用户名与回调秘钥均已配置时为必须参数| timestamp=1563105451261;nonce=a07bfa17-6d82-4b53-a9a2-07cfef5ceef1;value=E4YeOsnMtHZ6592U8B9S37238E+Hwtjfrmpf8AQXF+c=1\. timestamp为系统UTC时间戳；2\. nonce为UUID随机数；3\. value为待加密字符串（timestamp+nonce+回调用户名）使用回调秘钥进行HmacSHA256加密后，经Base64编码后获得。  
  
 

**接口请求参数（HTTP body****）**

**参数值**| **取值类型**| **必选(M)/****可选(O)**| **参数说明**  
---|---|---|---  
statuses| array| M| 回执消息内容，具体字段请参考status结构体。为了提升性能，目前回执会对结果消息合并，最大为1000个结果。  
  
 

**status****结构体**

**参数值**| **取值类型**| **必选(M)/****可选(O)**| **参数说明**  
---|---|---|---  
token| string| M| TOKEN  
biTag| string| M| 开发者在发送消息请求时携带的biTag。  
status| integer| M| [请参考消息回执章节](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/push-receipt-v3)。  
timestamp| string| M| 消息到达终端的时间戳（本地时间）  
appid| string| M| 用户在AppGallery   Connect上的AppID  
requestId| string| M| 请求ID，在发送接口中返回的值。  
  
 

**接口响应参数**

**参数值**| **取值类型**| **必选(M)/****可选(O)**| **参数说明**  
---|---|---|---  
errno| string| M| 开发者服务端返回的处理结果状态。  
errmsg| string| M| 开发者处理结果的描述信息。
