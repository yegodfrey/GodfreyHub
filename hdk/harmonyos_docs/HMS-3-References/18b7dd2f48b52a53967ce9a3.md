public class HmsMessageService extends Service  
HUAWEI Push Kit中用于接收下行消息或者刷新的Token的基础类。  
为了接收华为推送的消息或者Token，开发者需要在App AndroidManifest.xml文件中声明[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/HmsMessageService)的实现类。在实现类中需要重写基类中的所有方法来处理SDK的回调事件。类中所有的回调方法需要开发者保证能够在10s内处理完成，超过10s由开发者自己起新任务（Job）处理。  
AndroidManifest.xml文件中需要包含：  

    
    
    复制
      
        1. <service
        2.       android:name=".YourHmsMessageService"
        3.       android:exported="false">
        4.       <intent-filter>
        5.             <action android:name="com.huawei.push.action.MESSAGING_EVENT" />
        6.       </intent-filter>
        7. </service>

public void onNewToken(String token)  
APP调用[getToken](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/push-HmsInstanceId#getToken)接口向服务端申请token，如果服务端当次没有返回token值，后续服务端返回token通过此接口返回。主要包含如下三种场景：  
1、申请Token如果当次调用失败，Push会自动重试申请，成功后则以onNewToken接口返回。  
2、如果服务端识别token过期，服务端刷新token也会以onNewToken方式返回。  
3、**华为设备上EMUI版本低于10.0申请token时，以onNewToken方式返回** 。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
token| APP调用[getToken](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/push-HmsInstanceId#getToken)接口向Push服务端申请的令牌。  
  
**Code Example**
    
    
     复制
      
        1. // This method callback must be completed in 10 seconds. Otherwise, you need to start a new Job for callback processing.
        2. @Override
        3. public void onNewToken(String token) {
        4.     Log.i(TAG, "received refresh token:" + token);
        5.     // send the token to your app server.
        6.     if (!TextUtils.isEmpty(token)) {
        7.         refreshedTokenToServer(token);
        8.     }
        9. }
        10. private void refreshedTokenToServer(String token) {
        11.     Log.i(TAG, "sending token to server. token:" + token);
        12. }
