public static class RemoteMessage.Notification implements Serializable  
RemoteMessage.Notification类是一个数据类，代表通知消息详情，类成员属性可通过对应的**get** 方法获取。Notification类中成员属性定义可以参见服务端发送Push消息中的[AndroidNotification](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/push-server-send#AndroidNotification)结构体定义说明。

public String getTitleLocalizationKey()  
获取通知消息显示标题的键。应用的字符串资源中标题字符串的键，用于将标题文字本地化为用户当前设置的本地化语言。  
  
**Return**

type| desc  
---|---  
String| 本地化标题的键  
Method  
---  
public String[] getTitleLocalizationArgs()  
获取通知消息显示标题的可变参数，请与getTitleLocalizationKey配套使用。getTitleLocalizationArgs获取到的参数个数必须大于等于getTitleLocalizationKey接口返回的key对应的参数个数， 并且类型必须一一对应匹配。  
  
**Return**

type| desc  
---|---  
String[]| 通知消息显示标题的可变参数
