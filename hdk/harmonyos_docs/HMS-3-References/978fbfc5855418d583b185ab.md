# Public Methods

## **public abstract String getAchievementId()**

获取当前成就的成就ID，该ID唯一标识一个成就。

**返回值**  
成就ID字符串。

## **public abstract int getCurrentSteps()**

获取当前玩家对该成就已完成的步数。

**返回值**  
当前玩家已完成的步数。

## **public abstract String getDescription()**

获取当前成就的描述信息。请根据实际情况选择使用getDescription()或getDescription(CharArrayBuffer   dataOut)。

**返回值**  
当前成就的描述信息。

## **public abstract void getDescription(CharArrayBuffer dataOut)**

将成就的描述信息加载到CharArrayBuffer中。

**请求参数**

参数名| 参数说明  
---|---  
dataOut| 需要加载成就描述信息的CharArrayBuffer对象。  
  
## **public abstract void getFormattedCurrentSteps(CharArrayBuffer dataOut)**

将当前玩家已完成的成就步长数对应的本地化数字，加载到CharArrayBuffer。例如阿拉伯国家返回的就是阿拉伯语对应的数字。

**请求参数**

参数名| 参数说明  
---|---  
dataOut| 需要加载成就步长数据的CharArrayBuffer对象。  
  
## **public abstract String getFormattedCurrentSteps()**

获取当前玩家已完成的成就步长数对应的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。

**返回值**  
返回本地化语言的数字。

## **public abstract void getFormattedTotalSteps(CharArrayBuffer dataOut)**

将当前成就的总步长数对应的本地化数字，加载到CharArrayBuffer。例如阿拉伯国家加载的就是阿拉伯语对应的数字。

**请求参数**

参数名| 参数说明  
---|---  
dataOut| 需要加载步长数据的CharArrayBuffer对象。  
  
## **public abstract String getFormattedTotalSteps()**

获取当前成就总步长数对应的本地化数字。例如阿拉伯国家返回的就是阿拉伯语对应的数字。

**返回值**  
返回本地化语言的数字。

## **public abstract long getLastUpdatedTimestamp()**

获取最近一次更新成就的时间戳。

**返回值**  
返回最近一次更新成就的时间戳字符串，即最近一次更新成就距离1970年1月1日0点的毫秒数。

## **public abstract void getName(CharArrayBuffer dataOut)**

将当前成就的名称加载到CharArrayBuffer中。

**请求参数**

参数名| 参数说明  
---|---  
dataOut| 需要加载成就名称的CharArrayBuffer对象。  
  
## **public abstract String getName()**

获取当前成就的名称。

**返回值**  
当前成就名称。

## **public abstract Player getPlayer()**

获取当前登录的玩家信息。

**返回值**  
以[Player](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/player-v3 "Player")对象方式返回玩家具体信息。

## **public abstract Uri getRevealedImageUri()**

获取揭示成就后未解锁时的图标URI地址。

**返回值**  
图标的URI地址。

## **public abstract int getState()**

获取成就状态。

**返回值**  
● 0：解锁  
● 1：显示  
● 2：隐藏

## **public abstract int getTotalSteps()**

获取解锁该成就所需的总步长。

**返回值**  
解锁该成就所需的步长数。

## **public abstract int getType()**

获取该成就的类型。

**返回值**  
● 0：标准，没有设置分步步长的成就。  
● 1：增量，设置了分步步长的成就。

## **public abstract Uri getUnlockedImageUri()**

获取成就解锁后图标的URI地址。

**返回值**  
图标的URI地址。
