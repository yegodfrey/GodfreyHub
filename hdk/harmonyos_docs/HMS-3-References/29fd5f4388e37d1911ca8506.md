## Public Methods

Method

public static AdvertisingIdClient.Info getAdvertisingIdInfo (Context context)  
获取OAID和“限制个性化广告”开关。  
如果用户手机中，“华为移动服务（APK）”版本在2.6.1及以下，无法获取OAID，将抛出IOException。

---|---  
context| Android的标准Context
