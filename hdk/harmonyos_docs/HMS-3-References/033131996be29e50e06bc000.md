public class SmsRetrieverClient extends HuaweiApi< NoOptions > implements SmsRetrieverApi  
SmsRetriever客户端，入口。**短信规则说明** 开启读取短信服务后，成功获取的短信内容参看下方样例：
    
    
    prefix_flag short message verification code is XXXXXX hash_value

其中，“prefix_flag”表示短信的前缀标记，包括“<#>”、“[#]”和“**”；“short message virification code is ”表示短信内容（内容可变）；“XXXXXX”表示验证码；“hash_value”表示由HMS SDK产生用于唯一标识当前应用程序的哈希值，该哈希值是通过应用包名生成的，具体请参考[Hash_value的获取](https://developer.huawei.com/consumer/cn/doc/account-hash-value?version=V1)。

## Public Methods

Method  
---  
public Task< Void > startSmsRetriever ()  
开启读取短信的服务，直到读取到符合规则的短信或者服务超时（超时时间5分钟）。  
当读取到符合规则的短信之后，会通过广播的方式通知到应用。其中广播Intent的action为[SmsRetriever.SMS_RETRIEVED_ACTION](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretriever#sms_retrieved_action)，通过key值[SmsRetriever.EXTRA_SMS_MESSAGE](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretriever#extra_sms_message)可以从Intent中取到短信内容，并通过key值[SmsRetriever.EXTRA_STATUS](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/account-smsretriever#extra_status)可以从Intent中取到Status状态来判断短信读取成功或者服务超时。  
  
**Return**

type| desc  
---|---  
Task< Void >| 用来检查请求是否成功、失败或已完成的Task对象。  
您需要在接口返回的Task中设置两个回调监听，使用OnSuccessListener可以获取到成功场景返回的数据，使用OnFailureListener可以获取到此次请求失败的相关信息。在OnFailureListener中您需要判断该方式回调的异常对象是否是一个ApiException实例对象，然后根据ApiException实例中包含的getStatusCode()进行一些必要错误场景的处理。
