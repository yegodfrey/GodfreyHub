class info  
---  
com.huawei.hms.analytics.type.HAParamType  
此接口提供了所有预定义参数的参数ID，包括预定义参数的ID常量和预定义用户属性的ID常量。  
name| description  
---|---  
String HA_ACHIEVEMENT_ID| 标识成就ID。  
String HA_AFFILIATION| 发生此交易的商店或所属机构。  
String HA_CHARACTER| 标识用户的角色。  
String HA_CHECKOUT_OPTION| 当前结算步骤中用户填写的结算选项  
String HA_CHECKOUT_STEP| 标识用户当前处于结算过程中的第几个步骤。  
String HA_CONTENT_TYPE| 标识用户选择的内容类型。  
String HA_COUPON| 用户在本次交易中使用的优惠券。  
String HA_CURRENCY| 标识收入的货币类型。与HA_VALUE一起使用。  
String HA_DESTINATION| 航班或旅行等的目的地。  
String HA_END_DATE| 项目的到达日期，结账日期或租赁结束日期。  
String HA_FLIGHT_NUMBER| 开发者交易系统生成的航班号。  
String HA_GROUP_ID| 用户加入的用户群组ID。  
String HA_INDEX| 列表中项目的索引。  
String HA_ITEM_BRAND| 商品品牌。  
String HA_ITEM_CATEGORY| 商品类别（字符串）。  
String HA_ITEM_ID| 商品ID 。  
String HA_ITEM_LIST| 呈现给用户的商品列表。  
String HA_ITEM_NAME| 商品名称（字符串）。  
String HA_ITEM_VARIANT| 商品特征。  
String HA_LEVEL| 游戏等级（字符串）。  
String HA_LEVEL_NAME| 游戏中关卡的名称（String）。  
String HA_LOCATION| 商品所在地标识。  
String HA_METHOD| 操作中使用的特定方法;例如，在sign_up或登录事件的上下文中的“facebook”或“email”。  
String HA_NUMBER_OF_NIGHTS| 针对预定酒店场景，标识用户入住天数。  
String HA_NUMBER_OF_PASSENGERS| 针对预定酒店场景，标识入住旅客人数。  
String HA_NUMBER_OF_ROOMS| 针对预定酒店场景，标识用户预定房间数。  
String HA_ORIGIN| 出发地。  
String HA_PRICE| 购买价格。  
String HA_QUANTITY| 购买数量。  
String HA_SCORE| 在游戏中得分。  
String HA_SEARCH_TERM| 使用的搜索字符串/关键字。  
String HA_SHIPPING| 本次交易产生的运输费。  
String HA_START_DATE| 出发日期，入住日期或租赁开始日期（字符串）。  
String HA_SUCCESS| 操作的结果（长）。  
String HA_TAX| 本次交易产生的税费。  
String HA_TERM| 营销活动的关键词。如：搜索广告的关键词。  
String HA_TRANSACTION_ID| 电子商务事务ID（字符串）。  
String HA_TRAVEL_CLASS| 针对预定酒店场景，标识用户预定房间等级。  
String HA_VALUE| 为每种事件类型自动累积的特定于上下文的数值。  
String HA_VIRTUAL_CURRENCY_NAME| 虚拟货币类型的名称（String）。  
String HA_RATING_VALUE| 对APP或是项目的内容的评级。  
String HA_MAX_RATING_VALUE| 对APP或是项目的内容的评级的最大值。  
String HA_PUSH_MSGID| Push的消息ID。  
String HA_PUSH_CMD_TYPE| Push的消息类型。  
String HA_PUSH_NOTIFYID| Push点击上报事件ID。  
String HA_CAMPAIGN_NAME| 活动详细信息名称；用于关键字分析,以确定特定的产品促销或战略营销活动。  
String HA_CAMPAIGN_CONTENT| 内容详细信息；用于 A/B 测试和内容定位广告,以区分指向同一网址的广告或链接。  
String HA_CAMPAIGN_CP1| 活动详细信息自定义参数。  
String HA_CAMPAIGN_MEDIUM| 运动细节;用于标识媒体,如电子邮件或每次点击费用(Cpc)。  
String HA_CAMPAIGN_SOURCE| 活动详细信息来源；用于标识搜索引擎、新闻稿或其他来源。  
String HA_ACLID| 广告网络生成的用于标记广告点击的参数。  
String HA_CAMPAIGN| 营销活动的名称。  
String HA_CONTENT| 营销活动的营销内容。  
String HA_CP1| 自定义参数。  
String HA_CREATIVE_NAME| 营销活动使用的创意素材名称。  
String HA_CREATIVE_SLOT| 创意素材被展示的位置信息。  
String HA_ITEM_LOCATION_ID| 商品所在地标识。  
String HA_MEDIUM| 营销活动的类型，如：CPC、Email等。  
String HA_SOURCE| 营销活动提供者的标识，如HUAWEI PPS等。
