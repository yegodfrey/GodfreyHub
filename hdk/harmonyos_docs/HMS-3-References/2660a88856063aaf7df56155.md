AnnotatedData类用于缓存数据对象，例如在调用[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievementsclient-v3 "AchievementsClient")的load方法时会返回该数据对象。  
  
# Public Method Summary

Return| Method  
---|---  
T| get()  
获取AnnotatedData中包含的数据对象。  
boolean| isStale()  
检查数据是否来自缓存。  
  
# Public Methods

## **public T get()**

返回当前AnnotatedData对象包含的数据数据。

**返回值**  
缓存中包含的数据对象。

## **public boolean isStale()**

获取数据是否来自缓存。

**返回值**  
● true：是。  
● false：否。
