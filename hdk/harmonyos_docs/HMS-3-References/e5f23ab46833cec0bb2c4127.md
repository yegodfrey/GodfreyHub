public static boolean hasLocationAvailability(Intent intent)  
检查Intent中是否包含LocationAvailability。如果Intent中包含LocationAvailability数据，则返回true 。这是一个工具方法功能，可以从intent接收者内部调用，以确保接获取到的intent中包含位置可用性数据。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
intent| 调用[requestLocationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/fusedlocationproviderclient-v3)接口，传递给服务端的Intent。  
  
**Return**

type| desc  
---|---  
boolean| 如果intent包含LocationAvailability，则为true ，否则为false。  
Method  
---  
public boolean isLocationAvailable()  
检查设备位置是否已知。如果设备位置已知，则返回true 。无法确定位置可能是由多种原因造成的，包括禁用位置设置或无法在设备环境中获取传感器数据。  
  
**Return**

type| desc  
---|---  
boolean| 设备位置是否已知：已知则为true ，否则为false。
