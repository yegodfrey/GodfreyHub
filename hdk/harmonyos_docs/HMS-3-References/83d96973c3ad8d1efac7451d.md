public String getDataSignature();  
该方法返回使用支付私钥签署消耗数据（getConsumePurchaseData方法返回的字符串）生成的签名字符串。签名算法为SHA256WITHRSA。  
应用在收到此签名字符串后，需要参考[对响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/iap-verifying-signature-returned-result)对[ConsumePurchaseData](https://developer.huawei.com/consumer/cn/doc/development/HMS-References/iap-ConsumePurchaseData)的JSON字符串进行验签。  
  
**Return**

type| desc  
---|---  
String| 使用支付私钥签署消耗数据（getConsumePurchaseData方法返回的字符串）生成的签名字符串。
