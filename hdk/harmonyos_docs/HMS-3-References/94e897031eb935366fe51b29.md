# **接口功能**  
  
应用调用此接口在游戏界面中显示游戏浮标。

# **调用场景**

发布地区包含中国大陆的联运游戏，要求必须集成游戏浮标，游戏的所有界面都需要展示游戏浮标，一般建议在游戏界面的onResume方法中调用本接口。

# **接口约束**

  * 调用本接口前必须已经初始化HuaweiApiClient对象并连接HMS Core（APK），具体参见[初始化HuaweiApiClient对象](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-apiclient "初始化HuaweiApiClient对象")。如果HuaweiApiClient.isConnected()为true表示当前已经连接，请勿重复连接。

  * 对于EMUI 9.1.1及以上版本的华为设备，HMS Core（APK）会自动展示游戏浮标而忽略本接口的请求，开发者无需关注。




# **调用方法**
    
    
     复制
      
        1. PendingResult<ShowFloatWindowResult> pendingRst = HuaweiGame.HuaweiGameApi.showFloatWindow(HuaweiApiClient client, Activity activity);
    
    

# **请求参数**

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
client| M| HuaweiApiClient| 连接HMS Core（APK）的HuaweiApiClient对象。如果未初始化HuaweiApiClient对象，对象的初始化方法请参见[初始化HuaweiApiClient对象](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/game-apiclient "初始化HuaweiApiClient对象")。  
activity| M| Activity| 需要显示浮标的Activity实例。  
  
# **返回值**
    
    
     复制
      
        1. PendingResult<ShowFloatWindowResult> pendingRst = HuaweiGame.HuaweiGameApi.showFloatWindow(client, curActivity);
        2. pendingRst.setResultCallback(**new** ResultCallback<ShowFloatWindowResult>() {
        3.     @Override
        4.    **public void** onResult(ShowFloatWindowResult showFloatWindowResult) {
        5.        **int** code = showFloatWindowResult.getStatus().getStatusCode();
        6.     }
        7. });
    
    

返回PendingResult类型的执行结果，开发者可以使用pendingRst.setResultCallback设置回调方法，并在onResult回调中接收调用结果，通过ShowFloatWindowResult.getStatus().getStatusCode()获取接口返回码。

# **返回码**

类型| 返回码常量| 返回码值| 返回码说明| 处理建议  
---|---|---|---|---  
HMS SDK框架错误码| 参见[HMS SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/hms-error-code "HMS SDK框架错误码")。  
业务返回码| GameStatusCodes.GAME_STATE_SUCCESS| 0| 查询成功。| 操作成功。  
GameStatusCodes.GAME_STATE_NO_SUPPORT| 7006| 当前区域不提供游戏服务。| 您所在的地区目前还不支持接入华为游戏服务。如果是非华为手机出现此错误码，请尝试升级HMS Core（APK）至最新版本。
