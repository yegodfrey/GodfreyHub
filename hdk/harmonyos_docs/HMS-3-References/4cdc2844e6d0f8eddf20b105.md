该类是HA SDK 预置事件ID列表及事件参数列表，代码埋点时,可直接调用预置事件及事件参数。  
  
## Classes

Class name| Class description  
---|---  
[HAEventType](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/81075247 "HAEventType")| 此接口提供了所有预定义事件的事件ID常量。  
[HAParamType](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/48214580 "HAParamType")| 此接口提供了所有预定义参数的参数ID，包括预定义参数的ID常量和预定义用户属性的ID常量。
