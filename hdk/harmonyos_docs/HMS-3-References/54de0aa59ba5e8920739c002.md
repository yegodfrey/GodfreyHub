public static boolean hasResult(Intent intent)  
如果Intent包含ActivityRecognitionResult，则返回true。这是一个工具函数，可以从intent接收器内部调用，以确保接收到的intent来自活动识别。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
intent| 调用[requestActivityUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/activityrecognitionclient)接口，传递给服务端的Intent。  
  
**Return**

type| desc  
---|---  
boolean| 如果intent包含ActivityRecognitionResult则返回true，intent为空或者intent中不包含ActivityRecognitionResult则返回false。
