包括了使用Huawei In-App Purchases接口的请求体。

Class name| Class description  
---|---

[ConsumePurchaseReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/ConsumePurchaseReq "ConsumePurchaseReq")| consumePurchase接口的请求信息。  
[GetBuyIntentReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/GetBuyIntentReq "GetBuyIntentReq")| getBuyIntent接口的请求信息。  
[GetBuyIntentWithPriceReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/GetBuyIntentWithPriceReq "GetBuyIntentWithPriceReq")| getBuyIntentWithPrice接口的请求信息。  
[SkuDetailReq](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/SkuDetailReq "SkuDetailReq")| getSkuDetail接口的请求信息。  
[SkuDetail](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/SkuDetail "SkuDetail")| 包含单个商品详细信息。
