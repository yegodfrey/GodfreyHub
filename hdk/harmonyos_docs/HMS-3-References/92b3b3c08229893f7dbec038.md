# 接口功能

用户在购买自动续费订阅型商品后，华为支付服务器调用此接口向开发者服务器发送订阅场景的关键事件通知。

# 调用场景

如果开发者在AGC申请支付服务时提前配置了开发者服务器的订阅通知地址，用户购买订阅型商品后，华为支付服务器会在订阅场景的某些关键事件发生时调用此接口通知开发者服务器。 主要涉及的场景如下：

l   用户第一次订阅成功。

l   因特殊原因运营客服主动取消用户的订阅。

l   已过期的订阅自动续期成功。

l   用户主动恢复一个已过期的订阅商品。

l   用户调整订阅商品降级或跨级且在下个续订生效。

若开发者服务器返回结果为非成功响应（返回的http status code值为200之外的值），将对本次关键事件的通知进行周期性重发。

重发机制：共2天，前3次每20秒尝试一次，4-5次每200秒尝试一次，6-16次每30分钟尝试一次，之后每3小时尝试一次，直到2天结束。

                                             

为保证可靠性，系统具备补偿机制，所以可能出现重发的通知比预期的多。

# 接口约束

不允许开发者服务器设置IP白名单用于限制华为侧的出口IP地址。IP白名单本身并不能提高安全性且会给业务发展带来约束，在消息层面已有更安全的RSA签名机制条件下，没有存在价值。开发者不遵守该约定而导致的后果将由开发者自行承担。

必须在开发前在AppGallery Connect中配置开发者服务器的回调地址，地址必须支持HTTPS协议且具有合法商用证书。

# 接口原型

承载协议| HTTPS POST  
---|---  
接口方向| 华为支付服务器   -> 开发者服务器  
接口URL| URL由开发者在申请支付服务时配置。  
数据格式| 请求消息：Content-Type:   application/json响应消息：Content-Type:   application/json  
  
# 请求参数

参数名称| 必选(M)/可选(O)| 类型| 参数说明  
---|---|---|---  
statusUpdateNotification| M| String| 通知消息，格式为JSON字符串，参考表1-20。  
notifycationSignature| M| String| 对statusUpdateNotification字段的签名字符串，签名算法为SHA256WithRSA。开发者服务器在收到签名字符串后，需要参考对响应消息验签的方法使用支付公钥对statusUpdateNotification的JSON字符串进行验签。公钥获取参考[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/appgallery_querypaymentinfo)。

# 返回参数

参数名称| 必选(M)/可选(O)| 类型| 参数含义  
---|---|---|---  
http status code| M| NA| 应答HTTP结果码，200表示成功，其余值表示失败，不支持重定向。  
errorCode| O| String| 处理失败错误码。错误码由开发者自行定义。  
errorMsg| O| String| 失败原因描述。
