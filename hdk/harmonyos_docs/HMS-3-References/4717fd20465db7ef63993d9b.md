应用服务端调用此接口能够查询数据删除请求任务在分析平台的执行进展。  
  
# Request

## HTTP request

> GET https://<URI>/analytics/gdpr/user_deletion_tasks/v2

### Parameters

参数名称| Value| Description  
---|---|---  
aaid| String| 通过HMS端侧接口获取。  
  
  


# Response

响应HTTP状态码：  


状态码| 描述  
---|---  
200| 成功。  
400| 错误，具体错误详情见错误码说明。  
500| 服务器系统错误。  
  
调用成功情况下，返回如下:
    
    
    复制
      
        1. {
        2.   "result_code":"0",
        3.   "result_msg":"success",
        4.   "task_list":[{
        5.     "request_id":"12345678",
        6.     "request_time":"datetime",
        7.     "status":"EXPORTING",
        8.     "status_time":"datetime"
        9.   }]
        10. }
    
    

Parameter name| Value| Description  
---|---|---  
result_code| String| 响应码，详见错误码说明。  
result_msg| String| 响应描述。  
task_list| TaskList| 任务列表。  
  
TaskList结构：

**参数名**| **值**| **说明**  
---|---|---  
request_id| String| 请求ID。  
request_time| DateTime| 请求时间。  
status| String| 任务状态：

  * DELETING: 删除中
  * PENDING: 等待删除
  * DELETED: 成功删除
  * IDMAPPING_NOT_FOUND: ID映射关系未找到
  * IDMAPPING_DEL_FAILED: 映射关系删除失败

  
status_time| DateTime| 状态最后更新时间。  
  
错误码说明：

**错误码**| **原因**| **说明**  
---|---|---  
10020| invalidParameter| 非法参数。  
10008| tooFrequentRequest| 接口请求过于频繁。
