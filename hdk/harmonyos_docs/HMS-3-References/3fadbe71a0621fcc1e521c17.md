## Public Methods

Method  
---  
public LocationRequest create()  
创建LocationRequest。  
Method  
---  
public LocationRequest setPriority(int priority)  
设置优先级，如果请求GPS位置，则值为100；如请求网络位置，则值为102或104；如不需要主动请求位置，仅需被动接收位置，则值为105。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
priority| 请求的优先级，默认为100。  
Method  
---  
public LocationRequest setInterval(long millis)  
请求位置回调的时间间隔。假如值为50000，则位置请求每隔50秒回调一次结果。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
millis| 回调时间间隔，以毫秒为单位，默认为3600000。  
Method  
---  
public LocationRequest setNumUpdates(int numUpdates)  
请求位置的回调次数，假如值为3时，则只回调3次结果给客户端。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
numUpdates| 位置请求回调次数，默认为Integer.MAX_VALUE。  
Method  
---  
public LocationRequest setFastestInterval(long millis)  
请求位置回调的最快时间间隔，取Interval和FastestInterval的较小值。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
millis| 请求的最快时间间隔，以毫秒为单位，默认为600000。如果有其他应用发起位置请求，满足fastestInterval周期后，同样会上报位置。  
Method  
---  
public boolean isFastestIntervalExplicitlySet()  
是否使用最快时间间隔。  
  
**Return**

Parameter name| Parameter desc  
---|---  
boolean| 如果使用最快时间间隔，则返回true;否则返回false。  
Method  
---  
public LocationRequest setExpirationTime(long millis)  
请求到期时间，该时间自开机启动算起，开机启动到当前时间可使用SystemClock.elapsedRealtime()获取。假如200秒后位置回调需要停止，则该参数值应为SystemClock.elapsedRealtime() + 200000。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
millis| 请求到期时间，以毫秒为单位，默认为Long.MAX_VALUE。  
Method  
---  
public LocationRequest setExpirationDuration(long millis)  
请求到期时间段，该参数与expirationTime的区别为，该参数不需要考虑开机启动时间。假如200秒后位置回调需要停止，则该参数值应为200000。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
millis| 请求到期时间，以毫秒为单位，默认为Long.MAX_VALUE。  
Method  
---  
public LocationRequest setSmallestDisplacement(float smallestDisplacement)  
位置更新的最小位移。两次回调位置之间的距离满足该参数的值，则进行位置回调。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
smallestDisplacement| 位置更新的最小位移，以米为单位，默认为0。  
Method  
---  
public LocationRequest setMaxWaitTime(long millis)  
设置最长等待时间。  
  
**Parameters**

Parameter name| Parameter desc  
---|---  
millis| 最长等待时间。
