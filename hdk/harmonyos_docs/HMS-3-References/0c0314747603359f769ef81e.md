JosAppsClient类定义了用于应用初始化的init方法和获取应用ID的getAppId方法。

# Public Method Summary

Return| Method  
---|---  
void| init()  
应用的初始化方法，在应用启动时调用。  
Task<String>| getAppId()  
获取应用的应用ID。  
  
# Public Methods

## **public void init()**

初始化应用。

## **public Task<void> getAppId()**

获取应用的应用ID。

**返回值**  
应用ID。
