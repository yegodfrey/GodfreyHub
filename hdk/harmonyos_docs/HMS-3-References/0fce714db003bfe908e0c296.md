AchievementBuffer类返回玩家的成就列表信息，在调用[AchievementsClient](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievementsclient-v3 "AchievementsClient")的load方法时会返回该数据对象。

# Public Method Summary

Return| Method  
---|---  
[Achievement](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievement-v3 "Achievement")| get(int position)  
获取成就列表中指定序列的成就信息。  
  
# Public Methods

## **public Achievement get(int position)**

获取成就列表中指定序列的成就信息，以[Achievement](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievement-v3 "Achievement")对象形式返回。

**请求参数**

参数名| 参数说明  
---|---  
position| 需要获取的成就在成就列表中的位置，从0开始，表示获取第1条成就数据。  
  
**返回值**  
返回包含成就信息的[Achievement](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/achievement-v3 "Achievement")对象。
