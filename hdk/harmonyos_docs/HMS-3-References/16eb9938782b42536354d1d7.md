static Builder newBuilder(Context context)  
创建一个[InstallReferrerClient.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030507-v3 "InstallReferrerClient.Builder")实例。  
如果用户手机中，“华为移动服务（APK）”版本在2.6.5及以下，无法获取转化跟踪参数，将抛出IOException。  
返回一个InstallReferrerClient.Builder实例对象。

Parameter name| Parameter desc  
---|---  
context| Android的标准Context。

void startConnection (InstallReferrerStateListener listener)  
开始连接转化跟踪参数服务。  
如果用户手机中，“华为移动服务（APK）”版本在2.6.5及以下，无法获取转化跟踪参数，将抛出IOException。  
  
**Parameters：**

Parameter name| Parameter desc  
---|---

---  
void endConnection()  
关闭连接并释放所有已持有的资源。  
如果用户手机中，“华为移动服务（APK）”版本在2.6.5及以下，无法获取转化跟踪参数，将抛出IOException。  
Method   
---  
boolean isReady()  
服务连接是否已经准备就绪。  
如果用户手机中，“华为移动服务（APK）”版本在2.6.5及以下，无法获取转化跟踪参数，将抛出IOException。  
true：已与服务建立链接，并准备就绪，可以调用。false：还未与服务建立链接，不可调用。  
Method   
---  
ReferrerDetails getInstallReferrer()  
获取转化跟踪参数。  
如果用户手机中，“华为移动服务（APK）”版本在2.6.5及以下，无法获取转化跟踪参数，将抛出IOException。  
返回一个[ReferrerDetails](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/3030508 "ReferrerDetails")对象。
