# Public Methods

#### public void increment(String eventId, int incrementAmount)

提交事件数据。

本方法的提交方式为异步提交，即应用客户端调用本方法时如果设备无网络，HMS SDK会先将数据缓存在本地，待网络恢复后提交到华为服务器。开发者无需关注此方法的执行结果。

**请求参数**

eventId| 需要提交数据的事件ID。由开发者在配置事件后获取。  
---|---  
incrementAmount| 在已有事件数值的基础上要增量增加的数值。  
  
### public Task<AnnotatedData<EventBuffer>> load (boolean forceReload)  


获取当前玩家的所有事件数据。

**请求参数**

forceReload| 获取服务器端还是本地缓存的事件列表。

  * true：服务器端。
  * false：本地缓存。

  
---|---  
  
**返回值**

返回[AnnotatedData](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/annotateddata-v3)对象，从[AnnotatedData](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/annotateddata-v3)对象可以获取[](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/EventBuffer-v3)[EventBuffer](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/eventbuffer-v3)数据。

#### public Task<AnnotatedData<EventBuffer>> loadByIds(boolean forceReload, String[] eventIds)

获取当前玩家指定事件数据，可支持获取一个或多个事件数据。

**请求参数**

forceReload| 获取服务器端还是本地缓存的事件列表。

  * true：服务器端。
  * false：本地缓存。

  
---|---  
eventIds| 需要获取数据的事件ID，格式为String数组形式。  
  
**返回值**

返回[AnnotatedData](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/annotateddata-v3)对象，从[AnnotatedData](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/annotateddata-v3)对象可以获取[EventBuffer](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-References/eventbuffer-v3)数据。
