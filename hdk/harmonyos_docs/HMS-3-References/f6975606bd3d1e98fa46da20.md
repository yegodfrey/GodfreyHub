该接口为华为access token鉴权接口。通过传入accessToken到华为服务器上获取用户的union_id、open_id、expire_in、scope等信息。

# **调用场景**

  * 应用的服务器已经获取到access token。可以使用该接口获取union_id open_id等信息。




# **接口约束**

  * 接口是3.0.0版本SDK新增接口。

  * 数据格式要设置为：Content-type: application/x-www-form-urlencoded。




# 请求参数

## HTTP请求

> POST https://api.cloud.huawei.com/rest.php?nsp_fmt=JSON&nsp_svc=huawei.oauth2.user.getTokenInfo

### 请求体

参数名称  
| 类型| 参数说明  
---|---|---  
open_id| String| 固定值“OPENID”。请求中传入该字段，接口才会返回open_id。  
access_token| String| 通过token接口，或者授权接口获取到的access_token。值得注意的是，该参数需经过UrlEncode处理后，再添加进请求消息中。  
  
# 返回参数

调用成功情况下,返回如下：
    
    
    复制
      
        1. {
        2.     "union_id": String,
        3.     "scope": String,
        4.     "open_id": Long,
        5.     "expire_in ": Long,
        6.     "client_id": String
        7. }
    
    

参数名称| 类型| 参数说明  
---|---|---  
union_id| String| 华为帐号用户的union_id。在同一个开发者帐号开发的应用中，每个华为帐号用户拥有唯一的union_id。特别地，如果当前开发者帐号转变为其他开发者帐号时，那么union_id会相应发生变化。（该字段长度为64位）  
scope| String| 用户授权scope列表。  
open_id| String| open_id，华为帐号用户在同一应用中的唯一标识。此外，同一个华为帐号用户在不同应用中的open_id不同。（该字段长度不能超过256位）  
expire_in| Long| AccessToken的过期时间，单位为秒。  
client_id| String| 应用的AppID。
