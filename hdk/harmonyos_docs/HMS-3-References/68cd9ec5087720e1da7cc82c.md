public Builder requestServerAuthCode()  
请求华为帐号用户授权应用获取Authorization Code。  
如果使用了requestServerAuthCode()， 就不需要调用requestIdToken(String clientId)方法了。  
当开发者的应用服务器使用Authorization Code 和华为OAuth服务器交换token时，idtoken将会在结果中返回。
