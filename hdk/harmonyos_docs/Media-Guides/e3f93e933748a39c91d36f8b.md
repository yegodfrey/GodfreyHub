# 术语

|术语|说明|
|:-----------------------|:------------------------------------------------------------------------------------------------------|
|编辑器实例（HuaweiVideoEditor)|视频编辑工程的管理器，负责整个运行环境的管理，内部包含唯一时间线，承载整个工程所有的资源、特效对象。|
|时间线（HVETimeline）|编辑场景的时间轴实体，由多个泳道组成，其长度由视频泳道的长度决定。|
|泳道（HVELane）|容纳资源的实体，分为视频泳道（Video Lane）、音频泳道（Audio Lane），贴纸文字泳道（Sticker Lane）、特效泳道（Effect Lane）。可随资源的增加不断扩展。|
|资源（HVEAsset）|容纳编辑内容的实体，分为视频资源（Video Asset）、音频资源（Audio Asset）、图片资源（Image Asset）、贴纸资源（Sticker Asset）和文字资源（Word Asset）。|
|特效（HVEEffect）|用于创建视频图像效果的特殊效果。|
|播放（PlayTimeline）|通过固定帧率驱动时间线向后推进，在预览窗口实时渲染视频图像，并同时播放声音。|
|定位（SeekTimeline）|指定渲染出时间线指定位置的画面。|
