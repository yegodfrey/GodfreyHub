# 快速开发

## 开发环境

* Android Studio开发环境：建议版本3.0.1及以上。
* 手机开发环境：系统软件版本不低于EMUI 10.0。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/login_registration-0000001053336366)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：注册成为开发者和创建应用，然后添加依赖。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/k-pop_feature-0000001126854126)|根据您想接入的编码能力，进行相应的代码开发。|
|3|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/self_check-0000001122807568)|华为提供对应用自动检查的能力。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/putaway_application-0000001122812722)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
