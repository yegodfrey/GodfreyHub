# 响度表

电平表右侧增加响度LKFS表和响度测量参数，用于实时监测渲染后信号响度。支持通过按钮切换扬声器和双耳监测模式。响度监测参数包含短期响度（Short-term）、瞬时响度（Momentary）、综合响度（Integrated）、范围（Range）、真峰值（True peak）。响度表可选择响度标准，响度标准会影响真峰值和综合响度值的警戒显示，可手动修改响度标准中的真峰值及综合响度的警戒值，修改后标准会变为自定义响度标准，真峰值调节范围是[-20, 0]，综合响度调节范围是[-46, 0]。

|序号|功能|描述|
|:-|:---------------|:---------------------------------------------------------------------------------------------|
|1|综合响度（Integrated）|整段音频的平均响度。|
|2|短期响度（Short-term）|提取3s以内的信号，表达的是3s内的平均响度。|
|3|瞬时响度（Momentary）|400ms内的响度，并每过100ms进行一次更新，响应相当灵敏。响度表柱状图显示Short term和Momentary，横线显示Short term Max和Momentary Max。|
|4|范围（Range）|以LU（响度单位）测量音频素材的响度的变化。|
|5|真峰值（True peak）|在模拟域中对数字信号的最大峰值的估计值。|

> 说明
>
> 短期响度、瞬时响度、综合响度和真峰值超出警戒值后变红，可重置数值（从当前播放内容开始测量）、暂停数值（保持当前的数值显示）。

|序号|区域|描述|
|:-|:------|:----------------------------------------------------------------------------------------------------|
|1|响度标准设置|包含EBU R-128、ITU-R BS.1770-4两种响度标准，默认标准为EBU R-128。用户手动修改数值后显示为自定义。 鼠标悬停变为上下箭头，可上下拖动调节参数值，双击文本框可手动输入数值。|
|2|响度表显示切换|点击可切换扬声器或双耳监测模式。 > 说明 > 打开双耳开关才可以监测双耳响度数值，双耳开关未打开时，响度表监测双耳数值为"--"。|
|3|响度表开关|开启响度表开关后，响度表进行响度监测。|
