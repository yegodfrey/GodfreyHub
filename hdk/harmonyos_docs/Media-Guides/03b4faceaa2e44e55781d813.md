# 业务介绍

三方应用支持动态照片分享，对外开放相关动态照片接口，基于对应接口实现生态应用接入动态照片。

## 环境准备

* Android Studio开发环境
  * 建议版本v3.0.1及以上
* 手机开发环境
  * 当前仅开放 mate70系列及matex6
  * 当前仅开放 HarmonyOS 4.3

## SDK使用(本地调试)

1.将LivePhotoKit.aar放在项目libs目录下

2.项目的build.gradle文件中添加依赖

    implementation fileTree(includes: ['*.aar'], dir: 'libs')

## 版本号

LivePhotoKit.aar当前最新版本1.1.7

# 1 接口介绍

### 1.1 工具类LivePhotoUtils

* 判断设备是否支持接入动态照片接口

        /**
         * 判断设备是否支持接入动态照片接口
         *
         * @param context context
         * @return 是否支持接入动态照片接口
         */
        public static boolean isDeviceSupportLivePhoto(Context context);

* 判断传入资源是否是动态照片 应用需要申请读取外部存储权限READ_EXTERNAL_STORAGE

        /**
         * 判断传入资源是否是动态照片
         *
         * @param context context
         * @param key key表示应用传入的uri或者path
         * @param isUri isUri为true表示uri，false表示path
         * @return 是否是动态照片
         */
        public static boolean isLivePhoto(Context context, String key, boolean isUri);

* 基于图片和视频合成动态照片

        /**
         * 基于图片和视频合成动态照片
         *
         * @param context context
         * @param out 输出流，写入合成后的动态照片数据
         * @param imagePath 图片路径
         * @param videoPath 视频路径(视频时长3.2s以内)
         * @return 状态码：-7(设备不支持接口调用)、-6(传入videoPath非视频资源)、-5(传入imagePath非图片资源)、-3(文件路径异常)、-2(输出流异常)、-1(视频长度时间过长>3.2s)、0(抛异常)、1(成功)
         */
        public static int saveLivePhoto(Context context, OutputStream out, String imagePath, String videoPath);

## 2.2 接口使用

### 2.2.1 在创建LivePhotoInfo实例前：

1.先判断设备是否支持动态照片分享接口

        /**
         * 判断设备是否支持接入动态照片接口
         *
         * @param context context
         * @return 是否支持接入动态照片接口
         */
        public static boolean isDeviceSupportLivePhoto(Context context) {
            return LivePhotoUtils.isDeviceSupportLivePhoto(context);
        }

2.判断给定的资源是否是动态照片

        /**
         * 判断传入资源是否是动态照片
         *
         * @param context context
         * @param livePhotoKey livePhotoKey表示应用传入文件的uri或者path
         * @param isUri isUri为true表示uri，false表示path
         * @return 是否是动态照片
         */
        public static boolean isLivePhoto(Context context, String livePhotoKey, boolean isUri) {
            return LivePhotoUtils.isLivePhoto(context, livePhotoKey, isUri);
        }

3.可以先提供一张图片资源和一个视频资源，合成一个动态照片格式资源，以便后续创建LivePhotoInfo。

        /**
         * 基于图片和视频合成动态照片示例
         *
         * @param context context
         * @param finalPath 合成动态照片的路径
         * @param imagePath 图片路径
         * @param videoPath 视频路径(视频时长3.2s以内)
         * @return 对应的状态码
         */
        public int saveLivePhotoDemo(Context context, String finalPath, String imagePath, String videoPath) {
            int stateCode = 0;
            FileOutputStream outputStream = null;
            try {
                //finalPath为动态照片保存位置
                outputStream = new FileOutputStream(finalPath);
                stateCode = LivePhotoUtils.saveLivePhoto(context, outputStream, imagePath, videoPath);
            } catch (IOException e) {
                Log.error(TAG, "saveLivePhoto: IOException");
            } finally {
                try {
                    if (outputStream != null) {
                        outputStream.close();
                    }
                } catch (IOException e) {
                    Log.error(TAG, "close outputStream: IOException");
                }
            }
            return stateCode;
        }

### 2.2.2 创建LivePhotoInfo实例后：

1.可以保存对应的动态照片中的图片或视频

        /**
         * 提取动态照片中图片示例
         *

         * @param imagePath 视频路径(视频时长3.2s以内)
         * @param context context
         * @return 对应的状态码
         */
        public int saveImage(String livePhotoPath, String imagePath, Context context) {
            int stateCode = 0;
            try {
                LivePhotoInfo livePhoto = new LivePhotoInfo(livePhotoPath, false, context);
                OutputStream imageOutputStream = new FileOutputStream(imagePath);
                stateCode = livePhoto.saveImage(imageOutputStream);
            } catch (ClassNotFoundException e) {
                Log.error(TAG, "LivePhoto class not found");
            } catch (FileNotFoundException e) {
                Log.error(TAG, "saveImage: IOException");
            }
            return stateCode;
        }

2.获取动态照片封面的帧序号、图片数据、视频数据、图片的偏移量、视频的偏移量、图片的长度、视频的长度

        /**
         * 获取动态照片中相关信息示例
         *
         * @param livePhotoPath 动态照片的路径
         * @param context context
         */
        public void getLivePhotoInfo(String livePhotoPath, Context context) {
            LivePhotoInfo livePhoto = null;
            try {
                livePhoto = new LivePhotoInfo(livePhotoPath, false, context);
            } catch (ClassNotFoundException e) {
                Log.error(TAG, "LivePhoto class not found");
            }
            if (livePhoto != null) {
                int coverPosition = livePhoto.getCoverPosition();//获取动态照片封面帧
                byte[] imageData = livePhoto.getImageData();//获取取动态照片图片数据
                byte[] videoData = livePhoto.getVideoData();//获取动态照片视频数据
                int imageOffset = livePhoto.getImageOffset();//获取动态照片中图片的偏移量
                int videoOffset = livePhoto.getVideoOffset();//获取动态照片中视频的偏移量
                int imageLength = livePhoto.getImageLength();//获取动态照片中图片的长度
                int videoLength = livePhoto.getVideoLength();//获取动态照片中视频的长度
            }
        }

# 状态码

|状态码|值|描述|解决方法|
|-----------------------|--|----------------|----------------|
|CALL_INTERFACE_FAIL|-7|设备不支持接口调用|进行设备校验|
|CALL_VIDEO_PATH_FAIL|-6|传入videoPath非视频资源|检查传入视频文件的路径|
|CALL_IMAGE_PATH_FAIL|-5|传入imagePath非图片资源|检查传入图片文件的路径|
|CALL_IS_LIVE_PHOTO_FAIL|-4|传入资源非动态照片|检查传入的资源是否为动态照片|
|CALL_PATH_FAIL|-3|文件路径为空|检查传入文件路径|
|CALL_STREAM_FAIL|-2|输出流为空|检查入参的输出流|
|CALL_VIDEO_FAIL|-1|视频时长超出限制|控制传入的视频长度不超过3.2s|
|CALL_FAIL|0|抛IO异常|检查IO流|
|CALL_SUCCESS|1|成功|/|
