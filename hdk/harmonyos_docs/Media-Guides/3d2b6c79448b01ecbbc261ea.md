# 上传应用证书

为了确保对加密视频的高级别保护，并确保DRM SDK不被盗用。对于使用DRM SDK的应用采用白名单管理。开发者需要指定集成DRM SDK的应用的包名并上传对应的应用证书，获取分配的"应用认证Key"和"应用认证Value"，并将其配置到应用的AndroidManifest.xml文件使用。

具体的操作步骤如下：

1. 开发者点击应用模块下的"新增"按钮。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.04007973498582753758760531649574:50001231000000:2800:40C51A3EFCF79095E75792FA997427B508AF205EDF9BE247F93CB13278BCB7BA.jpg)

   <br />

2. 在弹出的对话框中填写应用包名并上传应用证书

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.51383253375098876292130448795946:50001231000000:2800:CD816BB2AE08E2F3B0BCC51AAFDF6F0BE2398DB79ECE98BDB43B322A808C2FEC.jpg)  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.56745261656275370105136639828474:50001231000000:2800:82B4E1D9B77B2F30009BD9175428F78671CFDC56C65F8255F4686D422ECEB2C4.png)  
   1.应用证书目前仅支持der格式的证书。

   2.APP对应的应用证书，您可以通过如下命令，从APP的JKS文件中导出（此命令仅导出证书，不会导出私钥）

   keytool -exportcert -file \<filename\> -keystore \<keystore\> -alias \<alias\>

   其中：

   \<filename\> 为要输出的证书文件名

   \<keystore\> 为APP对应的Keystore文件

   \<alias\> 为您为APP证书保存在Keystore文件中设置的别名

   例如：

   ```
   keytool -exportcert -file testapp.der -keystore testapp.jks -alias testapp
   ```

   <br />

   <br />

3. 点击"确定"按钮后，系统会显示此证书的相关信息，如序列号、使用者、颁发者、有效期，请您再次确认。
4. 确认无误提交后，将等待管理员分配"应用认证Key"和"应用认证Value"，待管员处理状态的证书不允许删除。请您耐心等待。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110908.21904344121248076869528518311247:50001231000000:2800:47EB9F3A0E45BE0FFD55FF37AAA4575EC80458DA07D23901321F30E95FF7AC39.jpg)

   <br />

5. 管理员完成处理后，你可以查看并复制"应用认证Key"和"应用认证Value"。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110908.64529347921357319510783032496362:50001231000000:2800:1ABBD52C56C44914FD4713636DF3CF92C633194500AB0029A52EAC6A0FD6CBB0.jpg)

   <br />

6. 配置Manifest文件

   <br />

   您需要将复制的"应用认证Key"和"应用认证Value"配置到APP对应的AndroidManifest.xml文件中作为"manifest/application/meta-data"节点的两个属性值，"应用认证Key"对应于"android:name"，"应用认证Value"对应于"android:value"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110908.43284954100100311721829070830824:50001231000000:2800:CB0BE0C38DE3353C0A40201B479C7414D8052F18BC2BDB6CCA4F59695302D883.jpg)

   <br />

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110908.41206607791163552812209598522346:50001231000000:2800:D2184FB70706702B450ECCB52B6FB4A0BC7CA9650CD7542999A9EE8E80EDACB9.png)  
1. 开发者申请的一个DRM SDK可以应用于多个应用，每个应用可以绑定多个证书。
2. SDK的申请与应用证书的绑定，可以并行进行。也可以在完成SDK申请后随时追加应用/证书的绑定。
3. 每个用户在首次使用DRM能力时，都需要申请DRM证书（不同应用、不同用户的DRM证书均不相同）。正常使用的应用或证书，不能从开发者网站上删除，否则您的应用将无法成功申请到DRM证书，从而无法解密播放DRM视频。
