# 视频编辑AI能力SDK集成

## 集成准备

设置应用的鉴权信息。可以通过api_key或者Access Token来设置应用鉴权信息。

* （推荐）通过[setAccessToken](https://developer.huawei.com/consumer/cn/doc/Media-References/videoai-hveaiapplication-0000001286269898#section92907346177)方法设置Access Token，在应用启动时初始化设置一次即可，无需多次设置。

  ```screen
  HVEAIApplication.getInstance().setAccessToken("your access token");
  ```

  获取Access Token可参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/open-platform-oauth-0000001053629189)客户端模式。
* 通过[setApiKey](https://developer.huawei.com/consumer/cn/doc/Media-References/videoai-hveaiapplication-0000001286269898#section171221750121916)方法设置api_key，在应用启动时初始化设置一次即可，无需多次设置。

  ```screen
  HVEAIApplication.getInstance().setApiKey("your ApiKey");
  ```

  当您在AppGallery Connect上注册您的应用时，会给您的应用分配api_key，可参见[添加当前应用的AppGallery Connect配置文件](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347#section8388123603312)。
  > 注意
  >
  > 请勿将api_key硬编码在代码中，同时不要将api_key存储在应用的配置文件中。建议您将api_key存储在云侧，运行时获取。

## 一键动效

输入一张有天空或者水面的图片，驱动照片中的天空或者水面做出动态效果。

```screen
// 创建一键动效算法类实例
HVEAITimeLapse timeLapse = new HVEAITimeLapse();

// 初始化一键动效AI算法引擎
timeLapse.initEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化一键动效AI算法引擎进度
    }

    @Override
    public void onSuccess() {
        // 初始化一键动效AI算法引擎成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化一键动效AI算法引擎失败
    }
});

// 初始化一键动效AI算法引擎成功后进行检测图片信息
timeLapse.detectTimeLapse(imagePath, new HVETimeLapseDetectCallback() {
    @Override
    public void onResult(int state) {
        // 检测图片信息state作为下面HVEAITimeLapseOptions的setMotionType参数
    }
});

// 一键动效参数配置类
// state是detectTimeLapse返回的结果，skySpeed：天空的运动速度；skyAngle：天空的运动方向；waterSpeed：水面的运动速度；waterAngle：水面的运动方向
HVEAITimeLapseOptions options = new HVEAITimeLapseOptions.Builder().setMotionType(state)
    .setSkySpeed(skySpeed)
    .setSkyAngle(skyAngle)
    .setWaterAngle(waterAngle)
    .setWaterSpeed(waterSpeed)
    .build();

// 进行一键动效处理
timeLapse.process(imagePath, options, new HVEAIProcessCallback<String>() {
    @Override
    public void onProgress(int progress) {
        // 一键动效处理进度
    }

    @Override
    public void onSuccess(String result) {
        // 一键动效处理成功，result为处理后的资源路径
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 一键动效处理失败
    }
});

// 中断一键动效处理
timeLapse.interruptTimeLapse();

// 释放一键动效AI算法引擎
timeLapse.releaseEngine();
```

## 一键染发

输入一张单人或多人照片，检测人物并基于视频编辑服务提供的默认色卡样式，实现一键式染发。
> 说明
>
> 1. 支持图片资源。
> 2. 对于视频资源，您需自行处理视频编解码调用图像染发接口生成染发后的视频。
> 3. 建议下载视频编辑服务提供的默认色卡进行染发，色卡图规格为500*500px，使用非默认的色卡调用本服务染发接口无法保证染发效果。

```screen
// 创建一键染发算法类实例
HVEAIHairDyeing mHairDyeing = new HVEAIHairDyeing();

// 获取一键染发色卡列表
mHairDyeing.getAIHairColorList(new HVEAICloudListener<List<HVEAIColorBean>>() {
    @Override
    public void onAICloudSuccess(List<HVEAIColorBean> result) {
        // 请求成功回调
	HVEAIColorBean colorBean;
	if (result != null && result.size() > 0) {
	    colorBean = result.get(0);
	} else {
	    return;
	}
        // 获取色卡列表后，下载色卡图，colorBean为色卡数据类HVEAIColorBean对象，包含要下载的色卡信息
        mHairDyeing.downloadAIHairColor(colorBean, new HVEAIProcessCallback<Bitmap>() {
            @Override
            public void onProgress(int progress) {
                // 下载进度
            }

            @Override
            public void onSuccess(Bitmap result) {
                // 下载成功
            }

            @Override
            public void onError(int errorCode, String errorMessage) {
                // 下载失败
            }
        });
    }

    @Override
    public void onAICloudError(int errorCode, String errorMessage) {
        // 请求失败回调
    }
});

// 算法引擎初始化
mHairDyeing.initEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 算法加载进度
    }

    @Override
    public void onSuccess() {
        // 算法加载成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 算法加载失败
    }
});

// 图像一键染发处理，originBitmap为原图，colormapBitmap为色卡图
mHairDyeing.process(originBitmap, colormapBitmap, new HVEAIProcessCallback<Bitmap>() {
    @Override
    public void onProgress(int progress) {
        // 算法处理进度
    }

    @Override
    public void onSuccess(Bitmap result) {
        // 算法处理成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 算法处理失败
    }
});

// 释放算法引擎
mHairDyeing.releaseEngine();
```

## 头部分割

输入一张单人或多人（一般不超过5人）图片，人物占据画面主体区域（人物分辨率>320*320px），人物清晰可见（无虚化），检测人物并实现头部分割功能，返回被分割对象的mask数据（480*480的mask数组，每个值代表原图下采样到480*480的分辨率后对应像素的透明度，取值范围：[0, 127]）。根据此mask进行二次处理，可以达到头部分割的效果。
> 说明
>
> 1. 支持图片资源，以1080px为主，兼顾4K和720px。
> 2. 对于视频资源，您需自行处理视频编解码调用图像分割接口生成分割后的视频。

```screen
// 创建头部分割算法类实例
HVEAIBodySeg mAIBodySeg = new HVEAIBodySeg();

// 头部分割AI引擎初始化
mAIBodySeg.initEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度
    }

    @Override
    public void onSuccess() {
        // 初始化完成
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化失败
    }
});

// AI引擎初始化成功后，进行头部分割处理，bitmap为需要分割的图片
mAIBodySeg.process(bitmap, new HVEAIProcessCallback<byte[]>() {
    @Override
    public void onProgress(int progress) {
        // 头部分割处理进度
    }

    @Override
    public void onSuccess(byte[] result) {
        // 头部分割处理成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 头部分割处理失败
    }
});

// 释放头部分割AI引擎
mAIBodySeg.releaseEngine();
```

## 美颜

支持对图片，视频中的人脸进行实时美颜。
> 说明
>
> 1. 最多支持2个人脸（面积占比最大的2个人脸）。
> 2. 仅支持64位华为手机，麒麟985、麒麟990和麒麟9000芯片。

```screen
// 创建美颜算法类实例
HVEAIBeauty hveaiBeauty = new HVEAIBeauty();
 
// 初始化美颜AI算法引擎
hveaiBeauty.initEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化美颜AI算法引擎进度
    }
    @Override
    public void onSuccess() {
        // 初始化美颜AI算法引擎成功
    }
    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化美颜AI算法引擎失败
    }
});
 
// 初始化美颜算法opengl运行环境，需在opengl渲染线程里调用
hveaiBeauty.prepare();

// 设置需美颜处理的纹理的宽高（textureWidth：纹理的宽；textureHeight：纹理的高），初始化或纹理有变化后调用，需在opengl渲染线程里调用
// resize参数为需要处理的纹理宽高，取值需要大于0
hveaiBeauty.resize(textureWidth, textureHeight);

// 美颜参数配置，磨皮，美白，瘦脸，大眼，亮眼， 美颜程度范围：[0, 1]
HVEAIBeautyOptions options = new HVEAIBeautyOptions.Builder().setBigEye(1)
    .setBlurDegree(1)
    .setBrightEye(1)
    .setThinFace(1)
    .setWhiteDegree(1)
    .build();
 
// 更新美颜参数，初始化或有修改后更新
hveaiBeauty.updateOptions(options);
 
// 进行美颜处理，在opengl渲染线程里每帧调用，（inputTextureId：输入的纹理ID；outputTextureId：输出的纹理ID）
// 请确保输入正向朝上的人脸的纹理。
int outputTextureId = hveaiBeauty.process(inputTextureId);

// 释放美颜AI算法引擎
hveaiBeauty.releaseEngine();
```

## 目标分割

支持对输入的图片中的某个指定目标进行分割，返回被分割目标的mask数据（512*512的mask数组，每个值代表原图下采样到512*512的分辨率后对应像素的透明度，取值范围：[0, 127]）。根据此mask进行二次处理，可以达到目标分割的效果。
> 说明
>
> 仅支持视频资源，建议视频分辨率不超过2K，时长不超过10分钟。

```screen
// 创建目标分割AI算法引擎实例
HVEAIObjectSeg objectSeg = new HVEAIObjectSeg();

// 初始化目标分割AI算法引擎
objectSeg.initEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化目标分割AI算法引擎进度
    }

    @Override
    public void onSuccess() {
        // 初始化目标分割AI算法引擎成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化目标分割AI算法引擎失败
    }
});

// path是需要分割的图片，points为基于图片的坐标点集合，左上角为原点坐标，坐标点应位于需要分割的目标内，且个数建议大于等于2，需根据坐标点轨迹来确定选择的目标
objectSeg.objectSegImageDetect(path, points, new HVEAIProcessCallback<byte[]>() {
    @Override
    public void onProgress(int progress) {
        // 目标分割处理进度
    }

    @Override
    public void onSuccess(byte[] result) {
        // 目标分割处理成功，result为mask数组，大小为512*512
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 目标分割失败
    }
});

// 释放目标分割AI算法引擎
objectSeg.releaseEngine();
```
