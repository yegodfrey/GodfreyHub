# 应用开发

## 准备工作

* 从视频中解析视频信息，包括：分辨率、电光转换函数、色彩空间、颜色格式。存放到自定义变量中，如：VideoInfo m_videoInfo。

  ```screen
  struct VideoInfo {
      uint32_t width;
      uint32_t height;
      HdrVividTransFunc tf;
      HdrVividColorSpace colorSpace;
      HdrVividColorFormat colorFormat;
  };
  ```

* 创建SurfaceView，用于SDK处理后渲染画面。并将SurfaceView的Surface通过JNI方式，传递到Native层，存放到ANativeWindow *m_outputWindow指针变量中。

  ```screen
  // surface_view为布局文件layout中定义
  SurfaceView surfaceView = (SurfaceView) view.findViewById(R.id.surface_view); 
  ```

* 创建线程，从视频中解析视频流，创建AMediaCodec实例对视频流进行解码。

## 渲染转码

1. 创建并初始化[HdrVividRender](https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividrender-0000001276546000)实例，参数为JNI调用使用的JavaVM指针。

   ```screen
   HdrVividRender *m_hdrVividRender = HdrVividRenderInit(vm);
   ```

2. 渲染输入模式场景，通过调用SDK的接口构造ANativeWindow实例，并作为MediaCodec的输出。
   * 在Java层，通过JNI接口，调用Native层的[HdrVividRenderGenInputTexture](https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividkits-0000001276974582#section10543142784717)接口，创建一个纹理。
   * 使用该纹理的ID构造SurfaceTexture对象，

     ```screen
     SurfaceTexture nativeSurfaceTexture = new SurfaceTexture(nativeGetTextureId());
     ```

   * 调用nativeSurfaceTexture对象的setOnFrameAvailableListener方法，设置当一个新的图像帧可用于SurfaceTexture对象时的回调处理事件。
   * 通过JNI方式，将nativeSurfaceTexture对应的Surface，传递到Native层，存放到ANativeWindow *m_inputWindow指针变量中。
   * 调用解码器AMediaCodec_configure接口，将m_inputWindow作为参数传入解码器，解码后的数据，将设置到m_inputWindow的Buffer中。

   > 说明
   >
   > 渲染输入模式，需要将解码器关联到SDK创建的纹理上，解码器解码视频流后直接输出到纹理上。
3. 设置视频源的分辨率、电光转换函数。

   ```screen
   // m_videoInfo.width, m_videoInfo.height为从视频源中获取到的视频分辨率。例如：（3840, 2160）
   HdrVividRenderSetInputVideoSize(m_hdrVividRender, m_videoInfo.width, m_videoInfo.height);
   HdrVividRenderSetTransFunc(m_hdrVividRender, m_videoInfo.tf);
   ```

4. 设置输出参数。
   * 设置渲染的Surface的大小（渲染输出模式需要设置）。

     ```screen
     HdrVividRenderSetOutputSurfaceSize(m_hdrVividRender, ANativeWindow_getWidth(m_outputWindow), ANativeWindow_getHeight(m_outputWindow));
     ```

   * 设置输出Buffer的色彩空间（转码输出模式时设置，可选，如果不设置，默认为BT.709）。

     ```screen
     HdrVividRenderSetColorSpace(m_hdrVividRender, COLORSPACE_BT2020);
     ```

   * 设置输出Buffer的颜色格式（转码输出模式时设置，可选，如果不设置，默认为R8G8B8A8）。

     ```screen
     HdrVividRenderSetColorFormat(m_hdrVividRender, COLORFORMAT_R8G8B8A8);
     ```

5. 配置初始化参数。
   * 新建渲染转码对象。

     ```screen
     ANativeWindow *inputWindowPtr= nullptr;
     HdrVividInputCallback *inputCallbackPtr= nullptr;
     ANativeWindow *outputWindowPtr= nullptr;
     HdrVividOutputCallback *outputCallbackPtr= nullptr;
     ```

   * 渲染输入模式，对inputWindowPtr和inputCallbackPtr赋值。

     ```screen
     HdrVividInputCallback inputCallback;
     inputCallback.context = (void *) this;
     inputCallback.onGetTexImageInfo = OnGetTexImageInfo; 
     inputWindowPtr= m_inputWindow;
     inputCallbackPtr= &inputCallback;
     ```

     > 说明
     > * [onGetTexImageInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/c-vivid-inputcallback-0000001276494806#section11727mcpsimp)函数由SDK回调，需要在函数中调用[HdrVividRenderSetStaticMetaData](https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividkits-0000001276974582#section330592574720)设置静态元数据，调用[HdrVividRenderSetDynamicMetaData](https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividkits-0000001276974582#section1287392504714)设置动态元数据。
   * 渲染输出模式, 对outputWindowPtr赋值。

     ```screen
     outputWindowPtr = m_outputWindow;
     ```

   * 转码输出模式, 对outputCallbackPtr赋值。

     ```screen
     HdrVividOutputCallback outputCallback;
     outputCallback.context = (void *) this;
     outputCallback.onBufferAvailable = OnBufferAvailable;
     outputCallbackPtr= &outputCallback;
     ```

     > 说明
     > * [onBufferAvailable](https://developer.huawei.com/consumer/cn/doc/Media-References/c-outputcallback-0000001327494477#section11727mcpsimp)函数由SDK回调，对SDK输出的经过SDK转换的视频流进行处理。
   * 设置渲染转码参数。

     ```screen
     HdrVividRenderConfigure(m_hdrVividRender, inputWindowPtr, inputCallbackPtr, outputWindowPtr, outputCallbackPtr);
     ```

6. 启动处理流程。

   ```screen
   HdrVividRenderStart(m_hdrVividRender);
   ```

7. 渲染实例数据来源于缓冲输入模式场景，写入解码后的视频流数据。

   ```screen
   // yuvData为解码器输出的YUV420P10格式的视频图像数据，bufferInfo为构造的https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividbufferinfo-0000001276974586类型实例，hdrVividBuffer动态元数据。
   HdrVividRenderWrite(m_hdrVividRender, &yuvData, &bufferInfo, hdrVividBuffer);
   ```

8. 停止处理流程。

   ```screen
   HdrVividRenderStop(m_hdrVividRender);
   ```

9. 释放资源。

   ```screen
   HdrVividRenderRelease(m_hdrVividRender);
   ```

> 说明
>
> * 渲染输出模式，当Surface大小改变时，需要调用[HdrVividRenderSetOutputSurfaceSize](https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividkits-0000001276974582#section1718112313479)重新设置输出Surface的大小。
> * 渲染输出模式，当Surface销毁重新创建时（前后台切换），如果[HdrVividRender](https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividrender-0000001276546000)实例没有销毁，需要调用[HdrVividRenderSetOutputSurface](https://developer.huawei.com/consumer/cn/doc/Media-References/c-hdrvividkits-0000001276974582#section215711234477)接口设置新的输出Surface。
