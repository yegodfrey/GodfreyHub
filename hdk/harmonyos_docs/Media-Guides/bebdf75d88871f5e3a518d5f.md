# 场景介绍

华为视频能力（Video Engine）提供的电影级调色特性，可以为您的应用提供显示色彩调节能力。

## 主要功能

* 查询是否支持电影级调色特性
* 查询预设滤镜列表以及调色强度范围
* 使用预设滤镜
* 使用自定义3D-LUT滤镜

## 工作原理

电影级调色引擎将华为系统侧提供的基于芯片及算法的视频显示硬件能力，通过SDK的形式开放给开发者，您可通过调用SDK对应的接口，实现全屏幕的个性化色彩调节。
