# Send/Return模式

#### 配置Renderer参数

1. 新建Renderer工程，选择默认的7.1.2模式。偏好设置中选择"Send/Return模式"。
2. 点击"Renderer"，选择"[偏好设置](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117#section19946184416337)"。
3. 在传输模式中选择"Send/Return模式"，确认当前服务端口与各插件一致，然后点击"确定"。设置服务端口请参见FAQ。

当"Send/Return模式"开启时，控制条上的LTC时间码不可用。  

#### 配置DAW参数

1. 启动DAW，打开"驱动程序"。
   1. 选择"工作室 \> 工作室设置"页签。
   2. 在左侧的"设备"模块中，点击"音频系统"，然后在右侧ASIO驱动程序的下拉菜单中，选择"Petal Audio Bridge"。
   3. 待连接"Petal Audio Bridge"成功后，点击左侧菜单栏中的"音频系统"下方的"Petal Audio Bridge"。如果此时未开启麦克风权限，可在Mac系统的"系统偏好设置"中，选取"安全性与隐私"，选择边栏中的麦克风，在窗口右侧启用"Petal Vivid Renderer"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152642.05909595186957801168208267834020:50001231000000:2800:6C6819C6BEF42A398C05AB1D34CE120F61DCE62B3A156D2F905DE0ACDE67F394.png?needInitFileName=true?needInitFileName=true "点击放大")
2. 设置输出总线（以7.1.2为例）。
   1. 打开"音频连接"的"输出"页签。
   2. 配置声床总线。点击"添加总线"，弹出"添加输出总线"，点击"配置"下拉菜单（选择与Renderer对应的渲染模式，例如：7.1.2）并将"输出"设置为虚拟声卡的前10个通道，然后点击"添加总线"（7.1.2模式下最大可支持118个通道）。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152642.72340183627648757447565408163279:50001231000000:2800:C7FE4D2AA2B918D35BFFB03FDA9D26660B9969AC749F6CFE561EEF0C78E64ACC.png?needInitFileName=true?needInitFileName=true "点击放大")

   3. 设置总线名称。建议右键点击设置"Petal Vivid Bed"作为主混。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152642.72982027416654260679042634215650:50001231000000:2800:3324EEC536906DBD3E091143AE99129B8A3A628F9C81DF1974F369C21844E174.png?needInitFileName=true?needInitFileName=true "点击放大")

      由于渲染模式会影响静态声床数量以及总线输出，当选择渲染模式为7.1.2时，最多可创建118个单声道音轨，建议按顺序命名每个音轨（如Object 11、Object 12等），然后在"[偏好设置](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117#section19946184416337)"的"音频输出设备"中将它们分配给对应的Petal Vivid虚拟声卡输出。
   4. 创建单声道音轨，建议将其命名为"LTC" ，然后从"音频输出设备"下拉列表中将其分配给LTC输出。
   5. 确认轨道对应的输出是否正确,，轨道输出必须和Panner一致。
