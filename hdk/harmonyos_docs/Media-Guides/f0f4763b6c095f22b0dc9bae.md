# AI算法

#### 专属滤镜

支持用户自定义滤镜，对输入视频及图像应用自定义滤镜效果，支撑场景多样化的图像美化需求。

```
// 创建专属滤镜AI引擎
HVEExclusiveFilter filterEngine = new HVEExclusiveFilter();

// 初始化专属滤镜AI引擎
filterEngine.initExclusiveFilterEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度回调
    }

    @Override
    public void onSuccess() {
        // 初始化成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化失败
    }
});

// 创建单图模仿滤镜，指定一个Bitmap和滤镜的名字
// 返回滤镜ID，通过此ID，可以在数据库中查询滤镜相关的所有信息
String effectId = filterEngine.createExclusiveEffect(bitmap, "自定义滤镜01");

// 将滤镜添加到特效泳道中，起始位置0，时长3000ms
effectLane.appendEffect(new HVEEffect.Options(
    HVEEffect.CUSTOM_FILTER + effectName, effectId, ""), 0, 3000);

// 创建克隆滤镜，指定两个Bitmap和滤镜的名字
// 返回滤镜ID，通过此ID，可以在数据库中查询滤镜相关的所有信息
String effectId2 = filterEngine.imitateFilter(bitmap1, bitmap2, "自定义滤镜02");

// 将滤镜添加到特效泳道中，起始位置0，时长3000ms
effectLane.appendEffect(new HVEEffect.Options(
    HVEEffect.CUSTOM_FILTER + effectName, effectId2, ""), 0, 3000);
```

#### 一键染发

输入一张单人或多人照片，检测人物并基于参考色卡样式，实现一键式染发，头发染色程度可调节。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.26645237197113608087334288995196:50001231000000:2800:08DBB430D736C13E29275AF7AC2AB5E25EF1F5819B224E4854330BE7D4C5B3AB.png)  
1. 一键染发AI特效属于资源的内嵌特效，支持图片和视频资源；不可与其它AI内嵌特效共存。
2. 仅在支持4K编解码的芯片上支持4K高清素材实现一键式染发，例如：高通芯片（骁龙8系列及以上）。
3. 仅支持64位华为手机，版本为EMUI 10.0 \~ 11或HarmonyOS 2.0及以上。

```
// 初始化一键染发AI引擎
visibleAsset.initHairDyeingEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度
    }

    @Override
    public void onSuccess() {
        // 初始化成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化失败
    }
});

// 初始化成功后，添加一键染发AI特效，指定一键染发的色卡和默认强度
visibleAsset.addHairDyeingEffect(new HVEAIProcessCallback() {
    @Override
    public void onProgress(int progress) {
        // 一键染发AI特效处理进度
    }

    @Override
    public void onSuccess() {
        // 一键染发AI特效处理成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 一键染发AI特效处理失败
    }
}, colorPath, defaultStrength);

// 移除一键染发AI特效
visibleAsset.removeHairDyeingEffect();
```

#### 人物追踪

支持对用户输入视频画面中出现的某个特定人物进行自动追踪，生成主视角为特定人物的主角视频。当视频中包含人物时，您需要先选择指定人物才能进行追踪。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.91636593667460297170674243000033:50001231000000:2800:EDC670058F7D3FE28137BDD4B0E01C1944F288AAAB4746AA31C572E957B6AEA2.png)  
1. 人物追踪属于资源的内嵌特效，支持视频资源；不可与其它AI内嵌特效共存。
2. 仅支持64位华为手机，版本为EMUI 9.0 \~ 11或HarmonyOS 2.0及以上。

```
// 初始化人物追踪AI引擎
videoAsset.initHumanTrackingEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度

    @Override
    public void onSuccess() {
        // 初始化成功
    }

    @Override

        // 初始化失败
    }
});

// 初始化成功后，通过坐标点选中指定的人物进行追踪，返回选中人物的矩形框坐标点
List<Float> rects = videoAsset.selectHumanTrackingPerson(bitmap, position2D);

// 添加人物追踪AI特效
videoAsset.addHumanTrackingEffect(new HVEAIProcessCallback() {
    @Override
    public void onProgress(int progress) {
        // 人物追踪AI特效处理进度
    }

    @Override
    public void onSuccess() {
        // 人物追踪AI特效处理成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 人物追踪AI特效处理失败
    }
});

// 中断人物追踪AI特效处理
videoAsset.interruptHumanTracking();

// 移除人物追踪AI特效
videoAsset.removeHumanTrackingEffect();
```

#### 精彩片段

输入一个视频，识别出其中指定时长的精彩片段。建议时长为\[1, 5\]，单位：s。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.93570764788591766444653597294714:50001231000000:2800:F281D630A7011DD6F8E38023EDDE43B0FDB57C941E14B760F41EEC0D3886FD1C.png)  
不可与其它AI内嵌特效共存。

```
// 创建精彩片段处理对象
HVEVideoSelection hveVideoSelection = new HVEVideoSelection();

// 初始化精彩片段AI引擎
hveVideoSelection.initVideoSelectionEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度
    }

    @Override
    public void onSuccess() {
        // 初始化成功
    }

    @Override

    }

// 初始化成功后，提取精彩片段，filePath为视频的路径，duration为需要提取片段的长度
hveVideoSelection.getHighLight(filePath, duration, new HVEVideoSelectionCallback() {
    @Override
    public void onResult(long start) {
        // 精彩片段提取成功
    }

// 释放精彩片段AI引擎

#### 一键动效

输入一张有天空或者水面的图片，驱动照片中的天空或者水面做出动态效果。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.93457932577096968856023602524479:50001231000000:2800:E43B915CDC25097E92EF7861CA2AD1D311CA0C5F5EC75F627B0D84A93914A26C.png)  
不可与其它AI内嵌特效共存。

```
// 初始化一键动效AI引擎
imageAsset.initTimeLapseEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度
    }

    @Override
    public void onSuccess() {
        // 初始化成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化失败
    }
});

// 初始化成功后，检查图片中是否有天空或者水面
int motionType = -1;
imageAsset.detectTimeLapse(new HVETimeLapseDetectCallback() {
    @Override
    public void onResult(int state) {
        // 记录state作为添加一键动效AI特效的参数
        motionType = state;
    }
});

// skySpeed：天空的运动速度；skyAngle：天空的运动方向；waterSpeed：水面的运动速度；waterAngle：水面的运动方向
HVETimeLapseEffectOptions options = 
new HVETimeLapseEffectOptions.Builder().setMotionType(motionType)
    .setSkySpeed(skySpeed)
    .setSkyAngle(skyAngle)
    .setWaterAngle(waterAngle)
    .setWaterSpeed(waterSpeed)
    .build();

// 添加一键动效AI特效
imageAsset.addTimeLapseEffect(options, new HVEAIProcessCallback() {
    @Override
    public void onProgress(int progress) {
    }

    @Override
    public void onSuccess() {
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
    }
});

// 中断一键动效AI特效处理
imageAsset.interruptTimeLapse();

// 移除一键动效AI特效
imageAsset.removeTimeLapseEffect();
```

#### 人脸遮挡

支持对用户输入的视频或图片画面中出现的人脸进行识别并添加马赛克或贴纸特效遮挡人脸。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.69667693818984687685255722528343:50001231000000:2800:DE194AE71C5A1B7F43102F64E611D644590D68BF8091F37ABBA1A29108F46A21.png)  
1. 人脸遮挡属于资源的内嵌特效，支持视频和图片资源；不可与其它AI内嵌特效共存。
2. 建议视频资源时长范围介于(0, 180\]，单位：s。
3. 仅支持64位华为手机，版本为EMUI 10.0 \~ 11或HarmonyOS 2.0及以上且只支持麒麟9000和麒麟990芯片。

```
// 初始化人脸遮挡AI引擎
visibleAsset.initFacePrivacyEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度
    }

    @Override
    public void onSuccess() {
        // 初始化成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化失败
    }
});

// 初始化成功后，启动人脸遮挡的人脸检测
visibleAsset.startFacePrivacyDetect(new HVEAIProcessCallback() {
    @Override
    public void onProgress(int progress) {
        // 人脸检测进度
    }

    @Override
    public void onSuccess() {
        // 人脸检测成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 人脸检测失败
    }
});

// 获取人脸检测结果
List<HVEAIFaceTemplate> faceTemplateList = visibleAsset.getAIFaceTemplates();

// 中断人脸遮挡的人脸检测
visibleAsset.interruptFacePrivacyDetect();

// 添加人脸遮挡贴纸特效
List<HVEAIFaceStickerInput> faceStickerInputList = new ArrayList<>();

// localStickerPath：用户选择的贴纸路径；localStickerType：用户选择的贴纸类型
HVEAIFaceStickerInput aiFaceEffectInput = new HVEAIFaceStickerInput(faceTemplateList.get(i),
    localStickerPath, localStickerType);
faceStickerInputList.add(aiFaceEffectInput);
((HVEVisibleAsset) visibleAsset).addFacePrivacyEffect(faceStickerInputList);

// 移除人脸遮挡贴纸特效
visibleAsset.removeFacePrivacyEffect();
```

#### 人像和头部分割

支持对输入的视频或图片进行人像或头部分割，生成分割后的视频、图片或贴纸。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.88435377497119330886461430091511:50001231000000:2800:895FA8D0E0436B5291FD4EEE6B43DC425B7CFB3626D5BE6206FA89F8E8D7FFC8.png)  
1. 支持贴纸、图片和视频资源。
2. 仅支持64位华为手机，版本为EMUI 10.0 \~ 11或HarmonyOS 2.0及以上。
3. 不可与其它AI内嵌特效共存。

```
// 初始化分割AI引擎。segPart为int类型，值为1时，进行人像分割；值为其他时，进行头部分割

#### 目标分割

支持对输入的视频画面中指定的某个指定目标进行分割，生成分割后的视频图像。当视频中包含物体时，您需要先选择指定目标物体才能进行分割。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260204134810.55534829419122474666286406764200:50001231000000:2800:C6A4BF6A193F67979117E058DE95D587093D39B637802895E0FA60ED1670FB29.png)  
1. 目标分割属于资源的内嵌特效，仅支持视频资源；不可与其它AI内嵌特效共存。
2. 建议视频分辨率不超过2K，时长不超过10分钟。
3. 为了保证分割效果，需要先调用接口[selectSegmentationObject](https://developer.huawei.com/consumer/cn/doc/Media-References/hvevdeoasset-0000001155730670#section1372543419233)选择需要分割的目标。
4. 仅支持64位华为手机，版本为EMUI 10.0 \~ 11或HarmonyOS 2.0及以上。

```
// 初始化目标分割AI引擎
videoAsset.initSegmentationEngine(new HVEAIInitialCallback() {
    @Override
    public void onProgress(int progress) {
        // 初始化进度
    }

    @Override
    public void onSuccess() {
        // 初始化成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 初始化失败
    }
});

// 初始化成功后，选择需要分割的目标进行分割，返回选择分割目标的的处理结果
// bitmap包含需要分割的目标的视频帧图片；timeStamp为视频帧图片在时间线上的时间戳；points为基于视频帧图片的坐标点集合，左上角为原点坐标，坐标点应位于需要分割的目标内，且个数建议大于等于2，需根据坐标点轨迹来确定选择的目标
int result = videoAsset.selectSegmentationObject(bitmap, timeStamp, points);

// 目标分割的处理结果成功后，添加目标分割AI特效
videoAsset.addSegmentationEffect(new HVEAIProcessCallback() {
    @Override
    public void onProgress(int progress) {
        // 目标分割AI特效处理进度
    }

    @Override
    public void onSuccess() {
        // 目标分割AI特效处理成功
    }

    @Override
    public void onError(int errorCode, String errorMessage) {
        // 目标分割AI特效处理失败
    }
});

// 中断目标分割AI特效处理
videoAsset.interruptSegmentation();

// 移除目标分割AI特效
videoAsset.removeSegmentationEffect();

// 释放目标分割AI引擎
videoAsset.releaseSegmentationEngine();
```
