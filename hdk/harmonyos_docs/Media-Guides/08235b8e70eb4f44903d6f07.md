# 音频播放管理

您可以按照如下流程完成应用的基础播放开发工作。

|序号|步骤|说明|
|:-|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建总管理实例|通过接口[HwAudioManagerFactory](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiomanagerfactory-0000001050431727)对hwAudioManager实施初始化，初始化成功后得到hwAudioManager实例，包括播放、配置、队列、音效管理四个子实例。|
|2|创建播放列表|创建播放列表实例playItemList。|
|3|添加歌曲信息至播放列表|添加在线歌曲或本地歌曲至播放列表。|
|4|播放歌曲|调用[play](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioplayermanager-0000001050189514#section2573mcpsimp)方法播放歌曲，[pause](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioplayermanager-0000001050189514#section2723mcpsimp)方法暂停歌曲。|

1. 创建总管理实例。

   ```screen
   private HwAudioPlayerManager mHwAudioPlayerManager;
   private HwAudioConfigManager mHwAudioConfigManager;
   private HwAudioQueueManager mHwAudioQueueManager;
   private HwAudioEffectManager mHwAudioEffectManager;
   public void createHwAudioManager() {
       // 创建配置实例，包含各种播放相关的配置。其中context信息传入不可为空。
       HwAudioPlayerConfig hwAudioPlayerConfig = new HwAudioPlayerConfig(context);
       // 根据实际情况创建HwAudioManager所需的配置。
       hwAudioPlayerConfig.setDebugMode(true).setDebugPath("").setPlayCacheSize(20);
       // 执行创建管理实例的操作。
       HwAudioManagerFactory.createHwAudioManager(hwAudioPlayerConfig, new HwAudioConfigCallBack() {
   	    // Audio Kit通过回调返回管理实例。
   	    @Override
   	    public void onSuccess(HwAudioManager hwAudioManager) {
   		    try {
   			    Log.i(TAG, "createHwAudioManager onSuccess");
   			    // 获取播放管理实例。
   			    mHwAudioPlayerManager = hwAudioManager.getPlayerManager();
   			    // 获取配置管理实例。
   			    mHwAudioConfigManager = hwAudioManager.getConfigManager();
   			    // 获取队列管理实例。
   			    mHwAudioQueueManager = hwAudioManager.getQueueManager();
   			    // 获取音效管理实例。
   			    mHwAudioEffectManager = hwAudioManager.getEffectManager();
   		    } catch (Exception e) {
   			    Log.i(TAG, "player init fail");
   		    }
   	    }
   	    @Override
   	    public void onError(int errorCode) {
   		    Log.w(TAG, "init err:" + errorCode);
   	    }
       });
   }
   ```

2. 创建播放列表实例。

   ```screen
   List<HwAudioPlayItem> playItemList = new ArrayList<>();
   ```

3. 添加歌曲信息至播放列表。
   * 添加一首在线歌曲至播放列表。

     ```screen
     public List<HwAudioPlayItem> getOnlinePlayItemList() {
         // 设置音频在线URL。
         String path = "https://developer.huawei.com/config/file/HMSCore/AudioKit/Taoge-chengshilvren.mp3";
         // 创建音频对象，写入音频信息。
         HwAudioPlayItem item = new HwAudioPlayItem();
         // 设置音频标题。
         item.setAudioTitle("Playing input song");
         // 设置音频ID，作为音频文件的唯一标识，建议通过哈希值获取。
         item.setAudioId(String.valueOf(path.hashCode()));
         // 设置音频是否在线，0表示本地歌曲，1表示在线歌曲。
         item.setOnline(1);
         // 传入音频在线URL。
         item.setOnlinePath(path);
         playItemList.add(item);
         return playItemList;
     }
     ```

   * 添加一首本地歌曲至播放列表。

     ```screen
     public List<HwAudioPlayItem> getLocalPlayItemList() {
         // 设置音频本地路径。
         String path = "/sdcard/Music/amazing.mp3";
         // 创建音频对象，写入音频信息。
         HwAudioPlayItem item = new HwAudioPlayItem();
         // 设置音频标题。
         item.setAudioTitle("Playing input song");
         // 设置音频ID，作为音频文件的唯一标识，建议通过哈希值获取。
         item.setAudioId(String.valueOf(path.hashCode()));
         // 设置音频是否在线，0表示本地歌曲，1表示在线歌曲。
         item.setOnline(0);
         // 传入音频本地路径。
         item.setFilePath(path);
         playItemList.add(item);
         return playItemList; 
     }
     ```

   > 说明
   >
   > [HwAudioPlayItem](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioplayitem-0000001050299080)音频数据类中，"音频ID"、"音频是否在线"为必须设置的参数，在线歌曲还需设置"音频在线URL"，本地歌曲还需设置"音频本地路径"。
4. 常用播放操作。
   * 播放歌曲。

     ```screen
     public void playOnlineList() {
         if (mHwAudioPlayerManager != null) {
             // 播放在线列表歌曲。
             mHwAudioPlayerManager.playList(getOnlinePlayItemList(), 0, 0);
         }
     }
     public void playLocalList() {
         if (mHwAudioPlayerManager != null) {
             // 播放本地列表歌曲。
             mHwAudioPlayerManager.playList(getLocalPlayItemList(), 0, 0);
         }
     }
     ```

   * 播放Android工程目录"\app\src\main\res\raw"和Android工程目录"\app\src\main\assets"文件夹中的音频文件。

     ```java
     HwAudioPlayItem item = new HwAudioPlayItem();
     // Android工程目录\app\src\main\res\raw文件夹
     item.setFilePath("hms_res://audioFile");
     // Android工程目录\app\src\main\assets文件夹
     item.setFilePath("hms_assets://audioFile.mp3");
     ```

   * 支持chunk模式音频资源的播放，例如在线播放文件管理器下我的云盘内的音频文件。

     ```screen
     public List<HwAudioPlayItem> getChunkedOnlinePlayItemList() {
         // 在线chunk播放源URL。

         HwAudioPlayItem item = new HwAudioPlayItem();
         // 设置音频标题。

         // 设置音频ID，作为音频文件的唯一标识，建议通过哈希值获取。

         item.setOnlinePath(path);

     }
     ```

5. 其他使用示例如下，详细请参见[HwAudioPlayerManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioplayermanager-0000001050189514)。

   ```screen
   // 跳转到指定播放进度。
   mHwAudioPlayerManager.seekTo((int) pos);
   // 播放列表中指定位置，指定进度的音频。
   mHwAudioPlayerManager.playList(getOnlinePlayItemList(), 0, 30);
   // 是否正在播放方法，可实现同个按钮进行播放和暂停操作。
   if(mHwAudioPlayerManager.isPlaying()) {
       pause();
    } else {
       play(); 
   }
   // 是否正在缓冲。
   mHwAudioPlayerManager.isBuffering();
   //设置播放模式，默认值为0，顺序模式。
   mHwAudioPlayerManager.setPlayMode(mode);
   // 获取播放模式。
   return mHwAudioPlayerManager.getPlayMode();
   // 获取播放进度，单位：ms。
   return mHwAudioPlayerManager.getOffsetTime();
   // 获取缓冲进度，单位：ms。
   return mHwAudioPlayerManager.getBufferPercent();
   // 获取播放时长，单位：ms。
   return mHwAudioPlayerManager.getDuration();
   // 设置播放倍速，(0, 2]的浮点数。
   mHwAudioPlayerManager.setPlaySpeed(playSpeed);
   // 获取播放倍速。
   return mHwAudioPlayerManager.getPlaySpeed();
   ```
