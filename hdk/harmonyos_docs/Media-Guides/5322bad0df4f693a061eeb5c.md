# 安装指引

#### 安装环境

|软/硬件|最低配置|推荐配置|
|:-----|:-------|:-------------------|
|CPU|Intel i5|Intel i7（6核） / M1及以上|
|内存|4 GB|8 GB及更高|
|磁盘空间|5 GB|\> 35 GB|
|Mac OS|Mojave|Catalina / Big Sur|
|支持的DAW|Nuendo11/Cubase12||

#### 安装指导

1. 点击[版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/version_history-0000001320890977)中的安装包下载链接，下载"花瓣三维声"安装包。
2. 首次安装时需要在"系统偏好设置"中选择"安全性与隐私"，在通用面板点击"仍要打开"来允许被阻止的安装包。

3. 解压并打开安装包，在"介绍"页，点击"继续"安装。
