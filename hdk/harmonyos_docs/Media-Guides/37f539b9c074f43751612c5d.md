# 电平展示

电平展示区可展示当前渲染模式下对应扬声器或双耳监听的电平值。双耳监听除双耳模式下均默认为关闭状态，您可手动打开双耳监听。支持通过衰减值调节整体输出电平，电平表为双电平显示，顶部横线为峰值电平显示，电平柱为RMS电平显示。
