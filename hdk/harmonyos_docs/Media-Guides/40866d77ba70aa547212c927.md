# 视频播放Pipeline

## 背景信息

本节的接入方式为[从Java层接入](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/integrating-sdk-0000001156025441#section5461134384418)。

AV Pipeline框架依赖graph配置文件来编排各个插件，所有预置Pipeline的配置文件位置请参见[预置的graph配置路径](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/faq-0000001109351062#section1058174519170)。视频播放Pipeline由5个插件组成，编排关系如下图所示。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210812095804.90853964894802359174407969947581:50520811020908:2800:4C0B93569FCC2660297F0EF38641B04E245A13529617F18341AC2FEE739D1310.png?needInitFileName=true?needInitFileName=true)

以下为基础播放Pipeline的graph配置文件PlayerGraphAndroid.xml。

```screen
<?xml version="1.0"?>
<Nodes>    
    <node id="0" name="AVDemuxer" mime="media/demuxer" type="source">   
        <!-- 数据流从这里开始分两路，一路到视频解码插件node 1，一路到音频解码插件node 2 -->     
        <next id="1"/>        
        <next id="2"/>    
    </node>    
    <node id="1" name="MediaCodecDecoder" mime="video/avc" type="filter">    
        <!-- 视频解码后送给视频显示插件node 4 -->    
        <next id="4"/>    
    </node>    
    <node id="2" name="FFmpegNode" mime="audio/aac" type="filter">   
        <!-- 音频解码后送给音频播放插件node 3 -->     
        <next id="3"/>    
    </node>    
    <node id="3" name="AudioSinkOpenSL" mime="audio/sink" type="sink">    
    </node>    
    <node id="4" name="VideoSinkBasic" mime="video/sink" type="sink">    
    </node>
</Nodes>
```

## 开发步骤

1. 初始化AV Pipeline框架。

   ```screen
   Context context = getApplicationContext();
   boolean ret = AVPLoader.initFwk(context);
   if(!ret) return;
   ```

2. 创建[MediaPlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458)实例，播放过程的控制由该实例来完成。

   ```screen
   MediaPlayer mPlayer = MediaPlayer.create(MediaPlayer.PLAYER_TYPE_AV);
   if (mPlayer == null) return;
   ```

3. 设置graph配置文件，AV Pipeline框架依赖于该配置文件来编排各个插件。

   ```screen
   MediaMeta meta = new MediaMeta();
   meta.setString(MediaMeta.MEDIA_GRAPH_PATH, getExternalFilesDir(null).getPath() + "/PlayerGraphAndroid.xml");
   mPlayer.setParameter(meta);
   ```

4. 设置以下参数后调用[prepare](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section19760935181619)接口，启动[MediaPlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458)准备工作。

   （可选）若需要监听某些事件，通过[setOnPreparedListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section9390104010373)、[setOnErrorListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section13217151454118)等接口设置回调函数。

   ```cpp
   // 设置视频渲染的surface
   SurfaceView mSurfaceVideo = findViewById(R.id.surfaceViewup);
   SurfaceHolder mVideoHolder = mSurfaceVideo.getHolder();
   mVideoHolder.addCallback(new SurfaceHolder.Callback() {
       // 用户自定义回调函数内容，可参考https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAV-Pipeline-video-playback
   });
   mPlayer.setVideoDisplay(mVideoHolder.getSurface());
   // 设置待播放媒体文件的路径
   mPlayer.setDataSource(mFilePath);
   // 若需要监听某些事件，则还需要通过setXXXListener接口设置回调函数
   // 例如需要监听prepare完成的事件，需进行如下设置
   mPlayer.setOnPreparedListener(new MediaPlayer.OnPreparedListener() {
       @Override    
       public void onPrepared(MediaPlayer mp, int param1, int param2, MediaParcel parcel) {
           // 用户自定义回调函数内容
       }
   });
   mPlayer.prepare();
   ```

5. 调用[start](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section585394815162)开始播放。

   ```screen
   mPlayer.start();
   ```

6. 调用[stop](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section4722920112217)停止播放。

   ```screen
   mPlayer.stop();
   ```

7. 当不再使用[MediaPlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458)时，调用[reset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section13369848112019)、[release](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section6898112115314)销毁播放器。

   ```screen
   mPlayer.reset();
   mPlayer.release();
   ```
