# 花字

## 业务介绍

花字可装饰图片，点击可以应用在图片上，可根据喜好，对文字进行二次编辑。

## 制作流程

1. 设计规范。
   * 应用说明 花字资源包括了贴纸资源和字体资源，点击花字进行文字的二次编辑。

   * 切图和字体资源设计 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210716170712.35238381128304122994764201186475:50520715091657:2800:9CF4F92DB3E5051025964DC0A3493DA99CB91B777AB32EC91081F6CC6A3315E8.png?needInitFileName=true?needInitFileName=true "点击放大")

     如图所示切图，一款文字加一款贴纸（10.0版，目前只支持一处文字编辑）。

     |设计项|设计规范|
     |:----|:----------------------------------------------------------------------------------------------------------------------------------------------------|
     |花字-字体|* 命名规则：自由命名 * 字体格式：ttf|
     |花字-贴纸|* 命名规则：flowertext_sticker_1_editable.png。 * 贴纸格式：贴纸需为空白处是镂空透明效果的png。 * 贴纸图尺寸：100px≤高度(h)≤450px、 100px≤宽度(w)≤450px。 * 贴纸大小：小于30k（单张）。 * 贴纸分辨率：72像素/英寸。|

     > 说明
     >
     > 宽度或者高度的需有一个最大尺寸等于450px，设计需保证图片的显示清晰。


   * 风格描述文件（.xml）资源说明

     ```screen
     <?xml version="1.0" encoding="UTF-8"?>
     <HwTheme>
         #flowertext代表花字
         <item style="flowertext"/>
         #贴纸的默认位置
         <stickerposition>Default</stickerposition>
         #贴纸的大小设置   
         <stickerscreen>w="200" h="450"</stickerscreen>  
         #文字框的位置设置（根据图片原点位置定义）    
         <textposition>x="50" y="44"</textposition> 
         #文字框的大小设置
         <textscreen>w="98" h="373"</textscreen> 
         #文字的显示方式（0代表横向显示，1代表纵向显示）    
         <text display="1"/>    
         #字体的颜色设置                      
         <item fontcolor="#a1625a"/>
         #设置英文字体
         <font>Strawberry coconut water</font> 
         #设置中文字体
         <font-cn>草莓椰桨</font-cn>                        
     </HwTheme>
     ```

     > 说明
     > * 贴纸的默认位置在图片显示区域的中心位置。
     > * 贴纸大小单位px。
     > * 整体花字的默认宽高度为实际设计尺寸，有一个数值需要等于450px。
     > * 字体框大小＜贴纸尺寸大小。
     > * font-cn输入内容为可编辑区域的文字显示。
2. 打包结构。
   * 打包目录结构 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210716170712.30067151285396974750505990841099:50520715091657:2800:1923A25853C86988E12A41C5ED1F9EB1BB1C8EA4A401114B6CB5A77070393DB7.png?needInitFileName=true?needInitFileName=true "点击放大")


   * description文件规格说明

     ```screen
     <?xml version="1.0" encoding="UTF-8"?>
     <HwTheme>
         #装饰模板英文名
         <title>Today's recipe </title>   
         #装饰模板中文名               
         <title-cn>今日食谱</title-cn>  
         #装饰模板开发者名称                    
         <author>汉仪字库</author>  
         #装饰模板设计者名称                                 
         <designer>汉仪字库</designer>  
         #装饰模板分辨率
         <screen>FHD</screen>    
         #装饰模板版本号                                 
         <version>10.0.100</version>   
         #装饰模板的英文介绍
         <briefinfo-en>Today's recipe. Punch in~</briefinfo-en>
         #装饰模板的中文介绍
         <briefinfo-cn>今日食谱打卡~</briefinfo-cn>
         #装饰模板业务（5为花字，6为贴纸）       
         <formatType>5</formatType>                                 
     </HwTheme>
     ```

     > 说明
     > * 主题英文名、中文名，开发者名称，设计师名称四项待主题上线后均不可修改。
     > * 主题分辨率，不可修改。
     > * 版本号为10.0.100。后续有更新则更改为10.0.10X（X为阿拉伯数字），例如10.0.101。
     > * format Type装饰模板业务"5"代表花字、"6"代表贴纸。
     > * 简介不可为空。


   * 最终提供样例 样例包下载：[花字样例包.zip](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210716170713.96314449259302932003458915040135:50520715091657:2800:AFFAF1C127683E4BA178C543ACFADA9AB259CA368E148BEAEF51666DE04F0024.zip?needInitFileName=true)。

3. 自检自查。

   |检查项|详情描述|
   |:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |花字效果检视|* 操作模块，详情模块等效果正常，无显示不全情况。 * 点击应用后，贴纸可进行缩放、镜像，删除等操作。 * 花字的文字可再编辑。|
   |资源包|* 资源包格式：zip。 * 资源文件打包格式正确，打包层级正确，无多出的层级。|
   |资源切图|* 目前仅支持一款文字加一款贴纸。 * 贴纸命名：flowertext_sticker_1_editable.png。 * 字体命名自已本身的名称（可自由命名）。 * 贴纸尺寸以规范为准，设计需保证图片的显示清晰。 * 花字中贴纸资源切图需为空白处是镂空透明效果，切图单位PNG。 * 分辨率：72像素/英寸。 * 大小：小于30k（单张）。 * 字体文件格式.ttf。|
   |风格描述xml|* 花字的默认位置在图片显示区域的中心位置 。 * 花字的大小尺寸单位px。 * 整体花字的默认宽高度为实际设计尺寸，有一个数值需要等于450px。 * text display为文字的显示方式"0"代表横向显示，"1"代表纵向显示，默认为0。 * 字体框尺寸大小＜贴纸大小。 * font-cn输入内容为可编辑区域的文字显示。|
   |description|* 主题英文名，中文名，开发者名称，设计师名称四项待主题上线后均不可修改。 * 名称不允许包含其他相关产品名。 * 名称需和实际内容信息相符。 * 主题分辨率，不可修改。 * 版本号为10.0.100。后续有更新则更改为10.0.10X（X为阿拉伯数字），例如10.0.101。 * format Type装饰模板业务"5"代表花字。 * 简介不可为空。|
