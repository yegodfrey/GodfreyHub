# 自定义插件

## 背景信息

本节的接入方式为[从C++层接入](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/integrating-sdk-0000001156025441#section1143033914488)。

AV Pipeline预置媒体播放所需的插件，若预置插件不符合您的要求，可以自定义插件。为了便于AV Pipeline对插件的管理，自定义插件需要满足[INode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/inode-0000001113343414)的API约束后才能被成功加载。

## 开发步骤

自定义插件可以继承于[INode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/inode-0000001113343414)来实现，也可以继承于[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)来实现。NodeBase中定义了插件的公共逻辑（线程管理、状态管理等），从[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)中继承的插件只需要关注业务相关的逻辑即可。

1. 实现插件接口（详见[INode](https://developer.huawei.com/consumer/cn/doc/development/Media-References/inode-0000001113343414)或[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)接口）。 说明
   >
   > [NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)接口有默认实现，您可以按需重写。
2. 实现CreateNode函数，该函数参数列表请参见[NodeBase](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233)类的[Public Constructors](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233#section194671721171911)。

   底层框架会在业务启动时调用该函数来加载插件对应的动态库，创建该插件。
   * [Public Constructors](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233#section194671721171911)第2个参数isProcThreadCreated表示是否需要创建处理线程。可以通过该参数创建额外的线程来处理耗时的算法，以保证插件及时响应。
   * [Public Constructors](https://developer.huawei.com/consumer/cn/doc/development/Media-References/nodebase-0000001159703233#section194671721171911)第3个参数isAsync表示是否为异步。为了支持不同插件应用场景，插件可以是异步也可以是同步。

     ```screen
     extern "C" {
     AVPipeline::INode *CreateNode(const char *mime)
     {
         return CreateNode<NodeXXX>(mime, false, false);
     }
     }
     ```

3. 编译脚本，生成插件的动态库。

> 说明
>
> 基于以上操作生成的插件可以被底层框架加载运行，如果需要单独加载该插件，可以使用[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/mediafilter-0000001164320311)来实现。
