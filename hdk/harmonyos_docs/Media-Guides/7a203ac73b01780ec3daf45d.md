# 对象管理

对象管理区域可以在对象监控界面对128个对象进行监控及管理。您可以查看当前所有对象的连接状态、电平信号以及声像位置，还可以将对象静音，并且在分组界面对所有对象进行分组操作。

## 分组界面

分组界面中支持对所有对象进行分组操作。声床（包含静态声床及动态声床）默认为一组，该分组只可进行静音操作，不可编辑或删除。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152639.83401105865419014982737942581391:50001231000000:2800:74BA6DF780D14BC61EF99C0E0439CE32557A5B4216939274E4DCCBDF0BA84ABA.png?needInitFileName=true?needInitFileName=true "点击放大")

除默认声床分组外，Renderer分组界面还提供创建自定义分组操作，通过点击创建分组，您可进行自定义组别的创建及编辑。自定义分组支持静音、编辑和删除。
