#### 开发步骤

因为考虑到一些异常场景，您在使用时需要做一些场景限定：

* 电影级调色作用范围为手机全屏幕，为了保证用户体验，调用者应判断在视频全屏时才应用滤镜效果，退出全屏时主动关闭效果。
* 当前台activity不是设置滤镜的activity时，应主动关闭滤镜效果。如需再次使用滤镜，需重新设置。  

#### 查询机型是否支持电影级调色

1. 创建HiVideoKitDisplaySdk对象。

   ```
   HiVideoKitDisplaySdk mHiVideoKitDisplaySdk = new HiVideoKitDisplaySdk(this);
   ```

2. 在使用HiVideoKitDisplaySdk调用滤镜效果之前，需要先查询当前设备是否支持电影级调色特性。

   ```
   boolean isSupport = mHiVideoKitDisplaySdk.getSupported();
   ```

若返回false，则表示当前用户的手机不支持电影级调色特性（EMUI版本低于11.0/手机硬件不支持），请直接终止流程。  

#### 查询电影级调色引擎版本是否匹配

在使用HiVideoKitDisplaySdk调用滤镜效果之前，需要先查询当前设备中预置的电影级调色引擎APK（以下简称Engine）是否与SDK版本兼容。

返回true为完全兼容，返回false为手机设备预置的Engine的版本过低，会导致SDK中的新增特性无法使用，可提示用户更新Engine版本（Engine会在华为应用市场上架，可跳转到应用市场对应链接），或直接终止流程。

* 查询Engine版本与SDK版本是否兼容。

  ```
  boolean ret = mHiVideoKitDisplaySdk.checkHiVideoKitStatus();
  ```

* 查询Engine版本号与SDK版本号。

  ```
  String kitEngineVersion = mHiVideoKitDisplaySdk.getKitEngineVersion();
  String kitSdkVersion = mHiVideoKitDisplaySdk.getKitSdkversion();
  ```

  返回的版本号格式为"a.b.c"，对应的版本修改描述为：
  * a：新增或修改特性

#### 获取预设滤镜列表

* 使用getEffectList获取支持的预设滤镜列表，返回值为List\<String\>类型

  ```
  List<String> filters = new ArrayList<>();
  filters = mHiVideoKitDisplaySdk.getEffectList();
  ```

  如果filters不为空，其中包含的预设滤镜代号与中文名称的对应关系为：  

  |滤镜代号|中文名称|
  |:-----------------------------------------------|:---|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_OR|默认|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_A1|阳光|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_A2|清凉|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_A3|暖意|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_B1|动人|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_B2|焦糖|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_B3|复古|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_F1|青橙|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_F2|琥珀|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_F3|黑白|
  |HiVideoKitDisplaySdk.ACTION_FILM_COLOR_FILTER_O1|色彩还原|

* 使用getEffectRangeMax()获取支持的预设滤镜强度的最大值。滤镜设置范围为\[0, getEffectRangeMax()\]。

  ```
  int filterRangeMax = mHiVideoKitDisplaySdk.getEffectRangeMax();
  ```

#### 应用预设滤镜

```
int applyFilterNo = 0; // 拿到的filters滤镜的index
int level = 90; // 应用滤镜强度
int ret = mHiVideoKitDisplaySdk.setDefaultEffect(filters.get(applyFilterNo), level);
```

#### 应用3D-lut滤镜

```
int[] gmpLutHigh = {…}; // 17 * 17 * 17的数组
int[] gmpLutLow = {…}; // 17 * 17 * 17的数组
int ret = mHiVideoKitDisplaySdk.set3DLutEffect(gmpLutHigh, gmpLutLow);
```

* 输入数组说明 每一套3D-LUT配置参数对应一种调色滤镜。一套3D- LUT由17x17x17个（RGB）节点数据组成。使用gmpLutHigh和gmpLutLow共同拼接一套3D-lut输入。其中，一个节点数据的RGB对应方式为：

  R: gmpLutHigh\[i\] 的 0\~3 bit+ gmpLutLow\[i\] 的 24\~31bit

  G: gmpLutLow\[i\] 的 12\~23 bit

  B: gmpLutLow\[i\] 的 0\~11 bit

  例如：

  输入：RGB f35 f12 e56

  节点数据i对应的RGB为：

  ```
  int gmpLutHigh[i] = 0xf;         // 0000 0000 0000 0000 0000 0000 0000 1111
  int gmpLutLow[i] = 0x35f12e56;   // 0011 0101 1111 0001 0010 1110 0101 0110‬‬
  ```

  R: 1111 0011 0101 ‬

  G: 1111 0001 0010

  B: 1110 0101 0110‬
* 3D-LUT表格配置 传递3D-LUT表给SDK接口时，3D-LUT表为4913（17\*17\*17）长度的数组，其中存放的每个元素为36bit的整型，其排列格式如下：
