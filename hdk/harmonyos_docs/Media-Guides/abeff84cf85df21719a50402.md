# token获取方式

#### 概述

OAuth 2.0是一个开放授权协议，它允许您的应用在不获取用户名与密码的前提下，访问用户授权的资源（OAuth 2.0相关协议规范，请访问[OAuth 2.0官方网站](https://oauth.net/2/)）。

您可以[API Console操作指南](https://developer.huawei.com/consumer/cn/doc/start/api-0000001062522591)在华为开发者联盟[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)上创建OAuth 2.0客户端ID，通过该客户端ID接入华为帐号，生成凭证Access Token，调用华为公开API，访问用户授权的资源。  

#### 获取前准备

您首次集成华为帐号，请先完成[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)接入，生成OAuth 2.0客户端ID，具体步骤及支持此类鉴权的公开API类型表，请参见[API Console操作指南](https://developer.huawei.com/consumer/cn/doc/start/api-0000001062522591)。

若您已注册过，生成了客户端ID（如移动、智慧屏等客户端ID），且希望同时实现多种场景接入，则无需重新注册，请忽略此章节。

例如：某公司已经注册生成了APPID-1，完成App集成接入，但是Web也想接入华为帐号，则可忽略此章节，继续使用已有的APPID-1，实现接入。  

#### 获取步骤

1. 发送请求消息。

   ```
   POST /oauth2/v2/token HTTP/1.1
   Host: https://login.cloud.huawei.com
   即: url："https://login.cloud.huawei.com/oauth2/v2/token"
   Content-Type: application/x-www-form-urlencoded
   Charsert: UTF-8
   body体 : "grant_type=client_credentials&client_id=" + client_id + "&client_secret=" + client_secret
   ```

2. 获取响应值JSON。

   ```
   {
        ...
       "access_token": "<返回的凭证Access Token>"
        ...
   }
   #获取token参考方式：
   JSONObject jsonObject = new JSONObject(json);
   token = jsonObject.getString("access_token")
   ```

   如果token值有空格，则替换为"+"，最后token值进行encode编码，得到最终的token值。

   ```
   if (token != null && token.contains(" ")) { 
      token = token.replaceAll(" ", "+");   
      token = URLEncoder.encode(token, "UTF-8");
   }
   ```
