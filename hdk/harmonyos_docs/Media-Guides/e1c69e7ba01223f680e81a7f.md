# 华为WisePlay DRM简介

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 什么是WisePlay DRM？

华为WisePlay DRM提供免费、基于标准的数字化内容的版权保护能力，为合作伙伴提供高质量数字化内容服务的版权保护能力。  

#### WisePlay DRM获得了哪些第三方认证？

WisePlay DRM获得了国家广播电视总局广播电视科学研究院、Riscure相关评估认证。  

#### WisePlay DRM和ChinaDRM的关系？

WisePlay DRM采用的是ChinaDRM的行业标准；ChinaDRM作为行业标准，已经在视频行业被广泛接受。  

#### WisePlay DRM是否收费？

WisePlay DRM免费开放给合作伙伴使用。  

#### WisePlay DRM支持哪些内容加密场景？

WisePlay DRM支持点播内容在线播放、点播内容离线播放、直播内容播放。  

#### WisePlay DRM是否遵从支持CENC？

是的。  

#### WisePlay DRM支持的内容加密算法？

AES、SM4。  

#### WisePlay DRM支持哪些内容格式的加密？

支持DASH+fmp4、HLS+fmp4、HLS+TS内容格式。  

#### WisePlay DRM是否支持硬件级DRM加密？

是的，WisePlay DRM支持硬件级、软件级DRM加密能力。

硬件级和软件级主要是终端的安全级别不同。硬件级必须要提供在TEE层运行的TA。软件级不提供TEE层的TA，相关操作在REE层完成，基于软件来保护内容的安全。硬件级依赖终端的芯片能力。  

#### WisePlay DRM是否提供接口供开发者查询设备支持软件级或硬件级？

您可以通过MediaDrm类的public String getPropertyString (String propertyName)接口，获取 WisePlay DRM安全级别securityLevel属性的值，SW表示软件级，HW表示硬件级，EH表示增强硬件级。  

#### WisePlay DRM可以在哪些终端使用？

华为手机和平板（使用麒麟990芯片需EMUI 10.1或HarmonyOS 2.0及以上版本，其他芯片需EMUI 11.0或HarmonyOS 2.0及以上版本），以及华为智慧屏（HarmonyOS 2.0.0.172及以上版本）。  

#### WisePlay DRM是否支持非华为设备？

不支持。  

#### WisePlay DRM是否支持水印功能？

水印是独立于DRM的技术。

WisePlay DRM不包含水印功能，合作伙伴可以自行集成水印方案。  

#### WisePlay DRM支持哪些播放器？

WisePlay DRM对于播放器的选择没有限制条件。
