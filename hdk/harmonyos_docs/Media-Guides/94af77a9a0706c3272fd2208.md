# 开发后自检

## 自检Checklist

为尽早发现问题，尽量减少您集成业务提交审核后被打回的概率，HMS Core业务提供了提交审核前自检checklist。请下载[全景自验checklist .xlsx](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221116112011.28312352024545256567379684368636:50531115040138:2800:AEB46AED1EEBCFD3DD8B8F87E6C7761CFF210F7B76A7FD1AD5BD3C98B2C38885.xlsx?needInitFileName=true)进行自检，检查通过后，再提交上架应用。

## 自检工具

华为提供对应用自动检查的能力。您只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。您可以根据自检报告改进应用，自检通过即可提交应用上架申请，是您上架应用的好帮手。

自检步骤请参见AppGallery Connect帮助中心的[接入检测](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-self-check-0000001100158786)。
> 说明
>
> 目前在[开发者联盟](https://developer.huawei.com/consumer/cn/)实名认证过的企业或者个人的帐号才可以使用自检工具。
