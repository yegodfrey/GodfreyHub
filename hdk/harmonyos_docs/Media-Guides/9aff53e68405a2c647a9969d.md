# 1. 通用

［问题一］如何合理获取CameraKit实例？

在1.0.1版本中建议参考如下代码：

```linenums prettyprint prettyprinted
private static boolean isGetInstance = false;
            
if (!isGetInstance) {
            
    try {
            
        mCameraKit = CameraKit.getInstance(getApplicationContext());
            
    } catch (NoSuchMethodError e) {
            
        Log.w(TAG, "this version camerakit does not contain VersionInfoInterface");
            
    } finally {
            
        isGetInstance = true;
            
    }
            
}
            
if (mCameraKit == null) {
            
    return;
            
}
            
```

在1.0.2版本中直接简化如下代码即可

```linenums prettyprint prettyprinted
mCameraKit = CameraKit.getInstance(getApplicationContext());
            
if (mCameraKit == null) {
            
    return;
            
}
            
```

# 3. 超级夜景能力

［问题一］超级夜景拍摄流程与常规拍照有何区别？

超级夜景开始拍摄后首先会进入长曝光阶段，开发者可收到曝光开始的回调，及本次拍摄需要的曝光时间，当曝光时间结束或者调用stopPicture提前停止曝光后，可收到曝光结束的回调，随后可通过ActionDataCallback.onImageAvailable回调获取超级夜景照片。

［问题二］超级夜景拍摄曝光时间有多长？

超级夜景曝光时长由相机底层根据拍摄场景的亮度上报，拍摄越暗的场景，则底层建议的曝光时间越长，也可手动设置曝光时长。

［问题三］如何提前结束曝光？

允许用户在拍摄过程中提前结束曝光获取照片，开始拍摄夜景相片后，CameraKit会一次上报TakePictureResult.State.CAPTURE_EXPOSURE_BEGIN（曝光开始）和TakePictureResult.State.CAPTURE_EXPOSURE_END（曝光结束）状态，在开始曝光后到曝光结束前，允许调用stopPicture提前结束曝光，获取照片。

［问题四］前置相机是否支持超级夜景？

当前只有后置相机支持超级夜景模式。

# 5. 录像能力

［问题一］录像模式该怎么配置surface？

录像模式要求模式在confure时至少要配置一个预览surface和Record surface。

［问题二］录像模式什么时候可以拍照？

EMUI_10.0录像模式只有在录制过程中才允许拍照。从EMUI_10.1开始，允许录像模式在录像启动前的预览模式进行拍照，拍照出图后才可以切换其他模式。但是Mate 30 Pro、P40 Proc在广角时，不支持录像启动前的拍照。

［问题三］录制的startRecording(),pauseRecording(),resumeRecording(),stopRecording()录制接口如何和编码器配合完成录制功能？

CameraKit的录制接口设计保证流正常输出到配置的record surface上，应用可以利用编码器组合完成最终的视频编码和保存，例如可以用MediaRecorder，可以在调用完kit的录制接口后，紧接着调用对应的MediaRecorder的start() stop() pause() resume()完成编码录制。

［问题四］录像模式目前支持哪些算法效果？

不同机型支持的算法效果可能有所差异，要使用时先经过ModeCharacteristics.getSupportedParameters进行查询。

# 7. 超级慢动作能力

［问题一］进行超慢录制视频该使用哪个录像接口？

使用新增接口startRecording(file)，file为有效可写路径。

［问题二］超慢模式有哪几种工作模式？

超慢有两种工作模式，分别是自动模式和手动模式，自动模式支持运动检测，当检测到运动物体时，开启录制；手动模式则直接调用上述接口，完成一次录制。

# 8. 普通慢动作能力

［问题一］普通慢动作和超慢区别？

（1）普通慢动作支持帧率一般为120fp和240fps， 低于960fps，用户在进行Kit接口使用时，和录像模式相似，但在配置时需要设置fps，modeConfigureBuilder.setVideoFps(fps)；超慢帧率960fps以上，无需进行编码器等相关的配置，只需调用接口完成录制。

（2）普通慢动作模式录制过程无状态切换，但是超慢录制过程有状态切换，且严格按照顺序返回。

# 9. 专业拍照能力

［问题一］如何查询专业拍照提供的能力类型？

ModeCharacteristics提供能力查询机制。专业拍照能力可以通过getSupportedParameters接口查询。

［问题二］如何判断专业拍照提供的能力值范围？

通过ModeCharacteristics的getParameterRange接口，传入每个需要调节参数的tag，查询能力值范围。

［问题三］RAW格式支持的Zoom值的范围是多少，对于三方下发不支持的Zoom会返回什么？

目前RAW格式仅支持Zoom为1，下发其他的zoom，不会调整预览效果，会返回非法参数的提示。

# 10. 专业录像能力

［问题一］专业录像和普通录像有什么区别？

专业录像可以通过调节录像流中的参数值来得到特殊的效果，例如：提高ISO值可以在黑暗环境下提高视频的亮度值。可以通过白平衡值的设置来营造出日光、阴天等效果。

［问题二］60fps专业录像的时候，支持录像中抓拍吗？有什么影响？

对于aeFpsRange参数设置范围在30~60的时候，录像中也可以抓怕。但是抓拍过程可能有帧率波动，会影响最终的录像帧率。

［问题三］专业录像对于aeFpsRange这个参数的使用有哪些限制？

在使用广角的时候aeFpsRange暂不支持设置到30fps以上。

# 11. 双景模式

［问题一］双景录像模式如何创建和释放？

双景录像模式创建需要先将全部子模式创建完成后才可以开启，相应的，使用完双景录像模式后，需要将全部子模式一起释放。

［问题二］双景录像模式如何将两个videoSurface录制到一起？

首先需要根据支持的分辨率分别设置两个videoSurface的分辨率，开发指南中给出的样例是采用OpenGL将两个videoSurface中的录像流渲染到一个surface中，再送编码，生成录像文件。

［问题三］双击录像模式是否支持美颜和防抖？

目前双景录像模式前置摄像头支持美颜，后置支持防抖。

## **SDK** **延迟初始化**

为了避免开发者的应用在未获取您的同意前，SDK提前启动收集使用您的个人信息。华为Camera Engine SDK提供了初始化接口getInstance，要求开发者的应用获取您的同意后才能调用此接口初始化SDK。

## **SDK** **数据安全保护**

SDK仅在设备端侧处理音频数据，不上传至服务器，运行完成后Camera Engine中的数据删除。

## **SDK** **版本更新声明**

为了向您提供最新的、安全的服务，我们会不时更新SDK版本。我们强烈建议开发者集成使用最新版本的SDK并向开发者提供了下载[链接](https://developer.huawei.com/consumer/cn/devservice/doc/3180106)。

## **SDK** **工作方式**

SDK会根据客户应用的调用而开始运行，根据客户应用的调用指令停止运行。当用户关闭应用时，SDK会随着客户应用的关闭而关闭，不会在后台做任何额外动作。
