# 视频编辑UI SDK集成

视频编辑UI SDK提供产品级UI界面，集成接入简单、快速。在进行开发之前，您需要完成必要的[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001101108580)工作，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347#section939003693314)，并且完成了本服务的[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347)。

1. 设置应用的鉴权信息。可以通过api_key或者Access Token来设置应用鉴权信息。

   * （推荐）通过[setAccessToken](https://developer.huawei.com/consumer/cn/doc/Media-References/mediaapplication-0000001149508209#section92907346177)方法设置Access Token，在应用启动时初始化设置一次即可，无需多次设置。

     ```screen
     MediaApplication.getInstance().setAccessToken("your access token");
     ```

     获取Access Token可参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/open-platform-oauth-0000001053629189)客户端模式。
   * 通过[setApiKey](https://developer.huawei.com/consumer/cn/doc/Media-References/mediaapplication-0000001149508209#section171221750121916)方法设置api_key，在应用启动时初始化设置一次即可，无需多次设置。

     ```screen
     MediaApplication.getInstance().setApiKey("your ApiKey");
     ```

     当您在AppGallery Connect上注册您的应用时，会给您的应用分配api_key，可参见[添加当前应用的AppGallery Connect配置文件](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347#section8388123603312)。
     > 注意
     >
     > 请勿将api_key硬编码在代码中，同时不要将api_key存储在应用的配置文件中。建议您将api_key存储在云侧，运行时获取。

2. 设置唯一标识ID，即License ID。License ID是进行管控的有效凭证，您要保证设置License ID的唯一性。建议您设置其值时使用不涉及个人数据的唯一ID。

   ```screen
   MediaApplication.getInstance().setLicenseId("License ID");
   ```

3. 设置启动模式，进入Video Editor Kit UI界面。

   * 通过[START_MODE_IMPORT_FROM_MEDIA](https://developer.huawei.com/consumer/cn/doc/Media-References/mediaapplication-0000001149508209#section16381842800)启动模式，即通过导入视频/图片方式启动。

     ```screen
     VideoEditorLaunchOption option = new VideoEditorLaunchOption.Builder().setStartMode(START_MODE_IMPORT_FROM_MEDIA).build();
     MediaApplication.getInstance().launchEditorActivity(this, option);
     ```

   * 通过[START_MODE_IMPORT_FROM_DRAFT](https://developer.huawei.com/consumer/cn/doc/Media-References/mediaapplication-0000001149508209#section18526195318913)启动模式，即通过草稿方式启动。

     ```screen
     // 获取草稿列表
     List<DraftInfo> draftInfos = MediaApplication.getInstance().getDraftList();
     // 获取草稿列表中的某个草稿ID
     String draftId = draftInfos.get(i).getDraftId();
     VideoEditorLaunchOption option = new VideoEditorLaunchOption.Builder().setStartMode(START_MODE_IMPORT_FROM_DRAFT)
     // 设置草稿ID，此参数必须设置
     .setDraftId(draftId)
     .build();
     // 若草稿中的资源在本地被删除，会导致调用失败
     MediaApplication.getInstance().launchEditorActivity(this, option);
     ```

4. 通过[setOnMediaExportCallBack](https://developer.huawei.com/consumer/cn/doc/Media-References/mediaapplication-0000001149508209#section45701307214)方法设置导出的回调。

   ```screen
   MediaApplication.getInstance().setOnMediaExportCallBack(callBack);
   // 视频导出接口回调
   private static MediaExportCallBack callBack = new MediaExportCallBack() {
       @Override
       public void onMediaExportSuccess(MediaInfo mediaInfo) {
           // 导出成功
           String mediaPath = mediaInfo.getMediaPath();
       }
       @Override
       public void onMediaExportFailed(int errorCode) {
           // 导出失败
       }
   };
   ```

5. 编排素材数据。

   请参见[编排素材](https://developer.huawei.com/consumer/cn/doc/Media-Guides/operations-guide-0000001201961634)，编排您应用的素材数据。
