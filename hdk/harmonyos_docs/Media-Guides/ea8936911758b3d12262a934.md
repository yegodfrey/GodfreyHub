# 主界面

Petal Vivid Panner插件是为Petal Vivid三维声空间位置编辑操作工作流程而设计的。Petal Vivid Panner挂载于DAW中，可对已挂载该插件的音频进行空间位置编辑，并将编辑后的音频传入Petal Vivid [Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)进行空间渲染。Panner状态分为对象编辑、[动态声床](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/p_connection_status_area-0000001270171160#section65031848142815)及[静态声床](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/p_connection_status_area-0000001270171160#section11669565283)三种，默认为对象编辑模式。对象编辑模式下支持自由拖拽及设置步进关键点和轨迹的方式对音频进行空间位置的编辑，以独立对象的形式传入Petal Vivid Renderer进行空间渲染。
