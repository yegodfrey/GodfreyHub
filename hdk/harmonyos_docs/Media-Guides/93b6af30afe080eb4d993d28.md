# 直播播放开发

支持HTTP(S)+FLV的直播播放能力。  

#### 实现流程

|序号|步骤|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在初始化播放器成功时会返回[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例创建播放器实例。|
|2|设置视频类型|调用[setVideoType](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section18155152819401)设置视频类型为直播。|
|3|设置起播参数|调用[InitBufferTimeStrategy](https://developer.huawei.com/consumer/cn/doc/Media-References/init-buffer-time-0000001078724746)设置起播参数。|
|4|设置播放URL等参数|设置播放参数，包括：播放事件监听、播放URL，播放显示的View。|
|5|调用[ready](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section51567281717)，开始加载数据|播放参数设置完成后，调用[ready](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section51567281717)，开始加载数据。|
|6|在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)事件通知中调用[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)，开始播放|在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)事件通知中调用[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)，开始播放。|
|7|播放过程中刷新播放URL|直播播放过程中，调用[refreshPlayUrl](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1517416341302)刷新播放URL。|
|8|调用[release](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1232010561725)，退出当前播放，释放播放器实例|退出当前播放，调用[release](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1232010561725)释放播放器实例，重置播放器监听。|

#### 操作步骤

1. 创建播放器实例。 在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```
   WisePlayer player = VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 设置视频类型。 调用[setVideoType](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section18155152819401)设置视频类型为直播。

   ```
   player.setVideoType(1);
   ```

3. 设置起播参数。 调用[InitBufferTimeStrategy](https://developer.huawei.com/consumer/cn/doc/Media-References/init-buffer-time-0000001078724746)设置起播参数。

   ```
   // 直播设置参数"5:1000,Others:800,Window:4000"
   InitBufferTimeStrategy.Builder initBufferTimeStrategy = new InitBufferTimeStrategy.Builder(4000);
   try {
       initBufferTimeStrategy.append(5, Integer.MAX_VALUE, 1000);
       initBufferTimeStrategy.append(0, 5, 800);
       player.setInitBufferTimeStrategy(initBufferTimeStrategy.build());
   } catch (IllegalArgumentException | DownloadMultipleZoneException exception) {
       // TODO 异常处理
   }
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231128170818.27240663300046354080095263668914:50001231000000:2800:805681DBE59DE8F5DD2D19EC0CFB46A56CC004CFBB13C9E463857DE5CD713655.png?needInitFileName=true?needInitFileName=true)  
   建议App在使用直播播放时，设置上述参数值。
4. 设置播放URL等参数。
   1. 注册监听事件，后面App根据监听回调做相应的处理。监听事件的原型请参见[WisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766)。

      ```
      // 设置播放器错误信息上报监听器
      player.setErrorListener(errorListener);
      // 设置播放器媒体以及播放信息上报监听器
      player.setEventListener(eventListener);
      // 设置播放视频分辨率发生变化监听器
      player.setResolutionUpdatedListener(resolutionUpdatedListener);
      // 设置媒体内容已经完成准备监听器
      player.setReadyListener(readyListener);
      // 设置播放器缓冲相关事件的监听器
      player.setLoadingListener(loadingListener);
      // 设置播放完成监听器
      player.setPlayEndListener(playEndListener);
      // 设置seek操作完成的监听器
      player.setSeekEndListener(seekEndListener);
      ```

   2. 设置播放地址。  
      调用[setPlayUrl](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1544913455555)设置直播地址。

      ```
      player.setPlayUrl("https://xxxx/xxx.flv?xxxx");
      ```

   3. 设置View，用于显示视频画面。  
      播放器当前支持SurfaceView、TextureView，App要确保View可用，否则无法播放视频。

      ```
      player.setView(surfaceView);
      ```

5. 调用[ready](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section51567281717)，开始加载数据。

   ```
   player.ready();
   ```

6. 在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)事件通知中调用[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)，开始播放。

   App在播放Activity界面实现[WisePlayer.ReadyListener](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532)接口。收到[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)回调消息后，调用播放器[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)方法开始播放。此时可以通过[getCurrentTime](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section146632235617)接口，获取播放进度，用于进度条的展示。在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)回调之前，获取播放器参数是无效的。

   ```
   @Override
   public void onReady(WisePlayer wisePlayer) {
       player.start();
   }
   ```

   1. 播放器上报视频分辨率发生变化。  
      需要App注册[ResolutionUpdatedListener](https://developer.huawei.com/consumer/cn/doc/Media-References/on-videosize-changed-listener-0000001050421605)监听器。

      ```
      public void onResolutionUpdated(WisePlayer wp, int width, int height) {
          // App可以根据width、height调整View的大小
      }
      ```

   2. 挂起播放器，用于前后台切换场景。
      * 如果App使用SurfaceView显示播放画面，需要实现android.view.SurfaceHolder.Callback接口，在surfaceDestroyed时调用播放器[suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)接口。
      * 如果使用TextureView显示播放画面，需要实现android.view.TextureView.SurfaceTextureListener接口，在onSurfaceTextureDestroyed时调用播放器的[suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)接口。

      ```
      @Override 
      public void surfaceDestroyed(SurfaceHolder holder) {
          if (player != null) {
              player.suspend();
          }
      }
      ```

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231128170819.91137084962844731530020070280278:50001231000000:2800:9CBF11A62ED4CE5C6271CB4F196068F644CB6CBC7830CFF84A0C6CA1240AF3CF.png?needInitFileName=true?needInitFileName=true)  
      [suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)之后必须用[resume](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section322644813392)接口恢复播放。
   3. 恢复播放器，用于前后台切换场景。
      * 如果App使用SurfaceView显示播放画面，则在surfaceCreated时调用播放器设置显示的View，并且调用[resume](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section322644813392)接口。
      * 如果使用TextureView显示播放画面，则在onSurfaceTextureAvailable时调用播放器设置显示的View，并且调用[resume](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section322644813392)接口。

        ```
        @Override 
        public void surfaceCreated(SurfaceHolder holder) {
            if (player != null) {
                 player.setView(surfaceView); 
                 // 切换到前台需要调用resume接口，通过传入参数可以控制是否自动播放
                 player.resume(-1); 
            }
        }
        ```

   4. App通知播放器View尺寸发生改变，确保播放器界面展示正常。
      * 如果App使用SurfaceView显示播放画面，则在surfaceChanged时调用[setSurfaceChange](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14921121101013)接口。
      * 如果使用TextureView显示播放画面，则在onSurfaceTextureSizeChanged时调用[setSurfaceChange](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14921121101013)接口。

      ```
      @Override
      public void surfaceChanged(SurfaceHolder holder, int format, int w, int h) {
          if (player != null) {
              player.setSurfaceChange();
          }
      }
      ```

7. 播放过程中刷新播放URL。 直播播放过程中，调用[refreshPlayUrl](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1517416341302)刷新当前播放URL。

   在直播场景下，App需要定期刷新播放地址，或者用户手动更新播放地址切换线路等场景可以调用该接口将新的播放地址设置给播放器，实现刷新播放。点播场景下调用无效。

   ```
   player.refreshPlayUrl("https://xxxx/xxx.flv?xxxx");
   ```

8. 调用[release](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1232010561725)，退出当前播放，释放播放器实例。
   1. 停止播放。

      ```
      player.stop();
      ```

   2. 释放播放器实例。  
      App在退出播放时需要调用下面的接口。

      ```
      // 重置播放器错误信息上报监听器
      player.setErrorListener(null);
      // 重置播放器媒体以及播放信息上报监听器
      player.setEventListener(null);
      // 重置播放视频分辨率发生变化监听器
      player.setResolutionUpdatedListener(null);
      // 重置媒体内容已经完成准备监听器
      player.setReadyListener(null);
      // 重置播放器缓冲相关事件的监听器
      player.setLoadingListener(null);
      // 重置播放完成监听器
      player.setPlayEndListener(null);
      // 重置seek操作完成的监听器
      player.setSeekEndListener(null);
       
      // 释放播放器实例，并将播放器对象置为null
      player.release(); 
      player = null;
      ```

      * 在使用直播播放时，不支持如下方法调用：[seek](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section128567191026)、[getDuration](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14604742943)、[setPlaySpeed](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section34142531887)、[setCycleMode](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section20789145121020)、[switchBitrateSmooth](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section9401756390)、[setBitrateRange](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1840518588913)、[setBandwidthSwitchMode](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14450195214913)、[setPlayMode](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section432711221297)、[setBookmark](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14661174417814)。

      <!-- -->

      * 当前FLV直播调用[pause](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section23225616217)暂停后不能通过[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)恢复播放，App可以通过启动新的播放实例达到继续播放的目的。
      * 当前FLV直播调用[suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)暂停切后台，后续通过[resume](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section322644813392)切回前台的时候，会重新拉流，存在黑帧现象，App可以考虑在切换回前台的时候增加过渡画面。
      * 支持的协议约束：支持HTTP(S)+FLV协议，URL是http(s)://开头，且URL的action段为flv后缀，如xxxxx.flv，如果不是flv后缀则通过请求回应内容进行探测，优先判断头部几个字节进行FLV格式识别。
      * 当前的直播流中需要支持的音视频格式约束：

        音频：AAC/MP3

视频：H.264
