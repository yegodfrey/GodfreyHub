# 音频音效管理

音效管理类[HwAudioEffectManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioeffectmanager-0000001142597807)，可用于设置音效开关状态、设置音效生效等场景。

* 通过设置音效参数，自定义音效。

```java
public void main() {
    HwAudioEffectItem hwAudioEffectItem = createEffect("myAudioEffect");
    setHwAudioEffectItem(hwAudioEffectItem);
    insertEffect(hwAudioEffectItem);
}
// 创建自定义音效。
public HwAudioEffectItem createEffect(String effectName) {
    Log.i(TAG, "createEffect");
    if (mHwAudioEffectManager != null) {
        HwAudioEffectItem hwAudioEffectItem = mHwAudioEffectManager.createEffect(effectName);
        setHwAudioEffectItem(hwAudioEffectItem);
        return hwAudioEffectItem;
    }
    return null;
}
// 设置音效参数。
public HwAudioEffectItem setHwAudioEffectItem(HwAudioEffectItem hwAudioEffectItem){
    hwAudioEffectItem.setResId(String resId);
    hwAudioEffectItem.setType(int type);
    hwAudioEffectItem.setName(String name);
    hwAudioEffectItem.setCreateTime(String createTime);
    hwAudioEffectItem.setUpdateTime(String updateTime);
    hwAudioEffectItem.setEq31(int eq31);
    hwAudioEffectItem.setEq62(int eq62);
    hwAudioEffectItem.setEq125(int eq125);
    hwAudioEffectItem.setEq250(int eq250);
    hwAudioEffectItem.setEq500(int eq500);
    hwAudioEffectItem.setEq1k(int eq1k);
    hwAudioEffectItem.setEq2k(int eq2k);
    hwAudioEffectItem.setEq4k(int eq4k);
    hwAudioEffectItem.setEq8k(int eq8k);
    hwAudioEffectItem.setEq16k(int eq16k);
    hwAudioEffectItem.setEqUltraLowStress(int eqUltraLowStress);
    hwAudioEffectItem.setEqSuperEnvironmentalSoundEffect(int eqSuperEnvironmentalSoundEffect);
    hwAudioEffectItem.setEqSuperChannelBalance(int eqSuperChannelBalance);
    return hwAudioEffectItem;
}
// 数据库中插入音效对象。
public int insertEffect(HwAudioEffectItem hwAudioEffectItem) {
    Log.i(TAG, "insertEffect");
    if (mHwAudioEffectManager != null) {
        return mHwAudioEffectManager.insertEffect(hwAudioEffectItem);
    }
    return -1;
}
// 设置音效生效
private void setEffect(HwAudioEffectItem hwAudioEffectItem, SetSoundEffectCallback callback){
    if (hwAudioEffectItem != null) {
        mHwAudioEffectManager.setEffect(hwAudioEffectItem, callback);
    }
}
```

* 设置绝美人声精选音效生效。其他音效资源ID请参见[音效ResId参照表](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sound_effect_resid-0000001145729541)。

  ```java
  // 绝美人声音效ResId。
  String resId = "beautiful_voice";
  for (HwAudioEffectItem hwAudioEffectItem : SoundEffectUtils.hwAudioEffectItems) {
      if (resId.equals(hwAudioEffectItem.getName())) {
          // 设置音效生效。		
          mHwAudioEffectManager.setEffect(hwAudioEffectItem, new SetSoundEffectCallback(new SoundEffectListener)); 
          break;
      }
  }

  // 设置音效生效的回调信息。		
  private class SoundEffectListener implements SetSoundEffectListener {
      @Override
      public void onSuccess(int i) {
          Log.i(TAG, "onSuccess" + i);
          // sound effect set success
      }
      @Override
      public void onError(int i, String s) {
          Log.i(TAG, "onError" + i + ";" + s);
      }
  }
  ```
