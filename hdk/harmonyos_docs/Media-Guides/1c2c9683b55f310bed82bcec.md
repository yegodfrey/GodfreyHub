# 场景智能设计错误码

|错误码|值|描述|解决方法|
|:--------------------------------------------|:-----|:------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|EXECUTION_FAILED|-2|执行失败|请清理手机内存后重试。|
|UNKNOWN_ERROR|-1|未知错误|请清理手机内存后重试。|
|SUCCESS|0|执行成功|-|
|FILTER_INFERENCE_CALCULATE_FAILED|200200|滤镜接口推理失败|请清理手机内存后重试。|
|FILTER_INTERFACE_REQUEST_PARAMETER_ERROR|200201|滤镜请求参数错误|请检查参数格式，传入正确的参数。|
|FILTER_INTERFACE_REQUEST_TIMEOUT|200202|滤镜接口请求超时|请清理手机内存后重试。|
|ERROR_DYNAMIC_MODULE_NOT_EXIST|200203|Dynamic模块不存在|请重新安装HMS Core (APK)。|
|ERROR_DYNAMIC_MODULE_NEED_UPDATE|200204|查询的模块不可用，需要从远程下载该模块|根据弹出的升级提示框升级，升级完成后重新打开应用即可。|
|ERROR_DYNAMIC_MODULE_INIT_ERROR|200205|HMS Core（APK）内部错误|请重新安装HMS Core (APK)。|
|ERROR_DYNAMIC_MODULE_NOT_READY|200206|HMS Core框架未初始化完成|请等待5-10秒，框架初始化完成后重新打开应用即可。|
|ERROR_DYNAMIC_MODULE_NOT_PRESET_HSF|200207|设备未预置HSF，无法加载对应模块|请安装最新的HMS Core （APK）。|
|ERROR_REMOTE|200208|远程调用错误|请安装最新的HMS Core （APK）。|
|THEMETAG_INTERFACE_REQUEST_TIMEOUT|200300|功能不支持|功能不支持，详见[图像主题标签服务](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/render-service-dev_label-0000001054207306)。|
|THEMETAG_INTERFACE_REQUEST_PARAMETER_ERROR|200301|图像主题标签请求参数错误|请检查参数格式，传入正确的参数。|
|THEMETAG_INFERENCE_CALCULATE_FAILED|200302|图像主题标签推理计算失败|请检查当前应用是否依赖ML Kit，若依赖则可能是依赖的ML Kit与Image Kit依赖的ML Kit版本冲突。推荐使用云测推理功能，即[设置needObjectList为false](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/render-service-dev_label-0000001054207306#ZH-CN_TOPIC_0000001054207306__p1241343619332)。|
|SMARTLAYOUT_INTERFACE_REQUEST_PARAMETER_ERROR|200401|图文智能排版请求参数错误|请检查[参数格式](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/vision-service-dev_layout-0000001054447321#ZH-CN_TOPIC_0000001054447321__table469818247327)，传入正确的参数。|
|SMARTLAYOUT_INFERENCE_CALCULATE_FAILED|200402|图文智能排版推理计算失败|请检查网络状态是否正常。|
|NON_STICKER_FILE|200501|无法找到文件|请检查文件是否存在，且路径正确。|
|STICKER_EXCEEDS_LIMIT|200502|超出花字贴纸限制个数|贴纸花字个数超出50个，超出限制。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
