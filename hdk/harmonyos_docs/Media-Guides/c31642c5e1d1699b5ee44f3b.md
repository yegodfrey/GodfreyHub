# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSVideoKit)快速体验一个应用的开发过程。

## 开发环境

* [集成Video Kit SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026#ZH-CN_TOPIC_0000001050304026__p1340135171116)需满足以下条件：
  * JDK 1.8.211及以上


  * 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上

    * minSdkVersion 21及以上
    * targetSdkVersion 34（推荐）
    * compileSdkVersion 34（推荐）
    * Gradle 5.4.1及以上（推荐）

    如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值


  * 测试应用的设备

    * EMUI 3.1及以上的华为手机或平板

    * Android 5.0及以上的非华为手机或平板

    * HarmonyOS 2.0及以上的华为智慧屏
* [集成fallback SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026#ZH-CN_TOPIC_0000001050304026__p12727428593)需满足以下条件：
  * Android Studio最低支持版本：3.6.1。
  * com.android.tools.build:gradle最低支持版本：3.5.4。
* [集成HDR Vivid SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026#ZH-CN_TOPIC_0000001050304026__p740153420230)需满足以下条件：
  * minSdkVersion 24及以上，Android版本需要7.0以上。若启用广色域模式，Android版本必须不低于8.0，且实际要依赖于设备支持情况。
  * OpenGL ES版本必须不低于3.0：YUV 10bit处理用到GLSL texelFetch获取原始纹素信息。
  * 若OpenGL ES使用广色域模式，EGL版本不低于1.4。
  * 支持HDR Vivid格式视频解码能力的设备。判断设备是否支持HDR Vivid视频解码能力，可以参考[准备工作](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-hdr-0000001276893212#section8786756981)。
* [集成HDR Ability SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026#ZH-CN_TOPIC_0000001050304026__p11422261124)需满足以下条件：
  * HarmonyOS 3.0及以上。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050738427)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050738427#section1464519554325)、[创建应用](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050738427#section15850522183317)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050738427#section147011294331)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050738427#section19713716202718)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-obfuscation-scripts-0000001050194340)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/Media-Guides/add-permissions-0000001050439607)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[视频播放](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)|App可以通过集成[Video Kit播放器SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026#ZH-CN_TOPIC_0000001050304026__screen207898183216)，完成视频点播场景和视频直播场景。|
|6|[渲染转码](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-hdr-0000001276893212)|App可以通过集成[HDR Vivid SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026#ZH-CN_TOPIC_0000001050304026__p740153420230)，完成处理HDR Vivid视频图像的OETF、Tonemapping、HDR2SDR等的能力。|
|7|[HDR能力配置](https://developer.huawei.com/consumer/cn/doc/Media-Guides/url-hdrability-0000001310355002)|App可以通过集成[HDR Ability SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/android-studio-integrating-sdk-0000001050304026#ZH-CN_TOPIC_0000001050304026__p11422261124)，使用HDR Ability SDK提供的亮度相关能力，获得更好的HDR视频播放体验。|
|8|[开发后自检](https://developer.huawei.com/consumer/cn/doc/Media-Guides/pre-release-check-0000001050439611)|华为提供对应用自动检查的能力。|
|9|[上架申请](https://developer.huawei.com/consumer/cn/doc/Media-Guides/app-release-0000001050192072)|开发完成后您需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
