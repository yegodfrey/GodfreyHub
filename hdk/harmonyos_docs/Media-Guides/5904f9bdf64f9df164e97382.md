# 工程草稿

通过[HVEProjectManager](https://developer.huawei.com/consumer/cn/doc/Media-References/hveprojectmanager-0000001201930661)管理器可以查询本地草稿列表，对草稿进行复制、删除、重命名操作。

## 保存草稿

HuaweiVideoEditor对象表示一个完整的工程，将其序列化为JSON文件，保存到应用本地目录。

```screen
// 将HuaweiVideoEditor保存到本地
editor.saveProject();
```

## 恢复草稿

通过[HVEProjectManager](https://developer.huawei.com/consumer/cn/doc/Media-References/hveprojectmanager-0000001201930661)管理器获取草稿的ID，然后在创建HuaweiVideoEditor实例时，指定草稿ID即可。

```screen
// 通过草稿ID，创建HuaweiVideoEditor实例
HuaweiVideoEditor editor = HuaweiVideoEditor.create(getApplicationContext(), projectId);
```
