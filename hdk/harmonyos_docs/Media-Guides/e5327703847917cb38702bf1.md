# 基础播放开发

## 实现流程

|序号|步骤|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在初始化播放器成功时会返回[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例创建播放器实例。|
|2|设置播放URL等参数|设置播放参数，包括： * 必须设置的参数：播放事件监听、播放URL，播放显示的View。 * 可选设置参数：播放类型、书签播放、循环播放、起播码率、音量等。|
|3|调用[ready](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section51567281717)，开始加载数据|播放参数设置完成后，调用[ready](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section51567281717)，开始加载数据。|
|4|在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)事件通知中调用[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)，开始播放|在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)事件通知中调用[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)，开始播放。|
|5|调用[release](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1232010561725)，退出当前播放，释放播放器实例|退出当前播放，调用[release](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1232010561725)释放播放器实例，重置播放器监听。|

## 操作步骤

1. 创建播放器实例。 在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```screen
   WisePlayer player= VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 设置播放URL等参数。
   1. 注册监听事件，后面App根据监听回调做相应的处理。监听事件的原型请参见[WisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766)。

      ```java
      // 设置播放器错误信息上报监听器
      player.setErrorListener(errorListener);
      // 设置播放器媒体以及播放信息上报监听器
      player.setEventListener(eventListener);
      // 设置播放视频分辨率发生变化监听器
      player.setResolutionUpdatedListener(resolutionUpdatedListener);
      // 设置媒体内容已经完成准备监听器
      player.setReadyListener(readyListener);
      // 设置播放器缓冲相关事件的监听器
      player.setLoadingListener(loadingListener);
      // 设置播放完成监听器
      player.setPlayEndListener(playEndListener);
      // 设置seek操作完成的监听器
      player.setSeekEndListener(seekEndListener);
      ```

   2. 设置播放类型、书签播放、循环播放等参数，具体请查看[WisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766)方法。

      ```screen
      player.setVideoType(0);
      player.setBookmark(10000);
      player.setCycleMode(1);
      ```

   3. 设置播放地址。

      播放器提供了多个设置播放地址的接口，App按需调用。

      ```java
      // 方式1：设置单个播放地址
      player.setPlayUrl("https://videoplay-mos-dra.dbankcdn.com/P_VT/video_injection/92/v3/C072F990370950198572111872/MP4Mix_H.264_1920x1080_6000_HEAAC1_PVC_NoCut.mp4");

      // 方式2：设置多个播放地址（同一个视频内容，主备播放地址）
      player.setPlayUrl(new String[] {"https://videoplay-mos-dra.dbankcdn.com/P_VT/video_injection/92/v3/C072F990370950198572111872/MP4Mix_H.264_1920x1080_6000_HEAAC1_PVC_NoCut.mp4", "https://videoplay-mos-dra.dbankcdn.com/P_VT/video_injection/92/v3/C072F990370950198572111872/MP4Mix_H.264_1920x1080_6000_HEAAC1_PVC_NoCut.mp4"});
      ```

   4. 设置View，用于显示视频画面。

      播放器当前支持SurfaceView、TextureView，App要确保View可用，否则无法播放视频。

      ```screen
      // 方式1：SurfaceView显示界面
      SurfaceView surfaceView= (SurfaceView) findViewById(R.id.surface_view);
      SurfaceHolder surfaceHolder= surfaceView.getHolder();
      surfaceHolder.addCallback(this);
      surfaceHolder.setType(SurfaceHolder.SURFACE_TYPE_PUSH_BUFFERS);
      // SurfaceView监听回调
      @Override
      public void surfaceCreated(SurfaceHolder holder) {
          player.setView(surfaceView);
      }

      // 方式2：TextureView显示界面
      TextureView textureView= (TextureView) findViewById(R.id.texture_view);
      textureView.setSurfaceTextureListener(this);
      // TextureView监听回调
      @Override
      public void onSurfaceTextureAvailable(SurfaceTexture surface, int width, int height) {
          player.setView(textureView);
      }
      ```

3. 调用[ready](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section51567281717)，开始异步准备播放器和媒体资源。

   ```screen
   player.ready();
   ```

4. 在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)事件通知中调用[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)，开始播放。

   App在播放Activity界面实现[WisePlayer.ReadyListener](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532)接口。收到[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)回调消息后，调用播放器[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)方法开始播放。此时可以通过[getDuration](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14604742943)和[getCurrentTime](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section146632235617)接口，获取内容时长和播放进度，用于进度条的展示。在[onReady](https://developer.huawei.com/consumer/cn/doc/Media-References/on-prepared-listener-0000001050179532#section139823011526)回调之前，获取播放器参数是无效的。

   ```screen
   @Override
   public void onReady(WisePlayer wisePlayer) {
       player.start();
   }
   ```

   1. 播放器上报视频分辨率发生变化。

      需要App注册[ResolutionUpdatedListener](https://developer.huawei.com/consumer/cn/doc/Media-References/on-videosize-changed-listener-0000001050421605)监听器。

      ```screen
      public void onResolutionUpdated(WisePlayer wp, int width, int height) {
          // App可以根据width、height调整View的大小
      }
      ```

   2. （可选）拖动播放，应用于拖动进度条播放的场景。

      ```java
      // 拖动到3600000毫秒播放
      player.seek(3600000);
      ```

   3. 暂停播放、恢复播放。

      [pause](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section23225616217)之后必须用[start](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1724320122)恢复播放。

      ```screen
      player.pause();
      player.start();
      ```

   4. 挂起播放器，用于前后台切换场景。 说明
      >
      > [suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)之后必须用[resume](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section322644813392)接口恢复播放。
      * 如果App使用SurfaceView显示播放画面，需要实现android.view.SurfaceHolder.Callback接口，在surfaceDestroyed时调用播放器[suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)接口。
      * 如果使用TextureView显示播放画面，需要实现android.view.TextureView.SurfaceTextureListener接口，在onSurfaceTextureDestroyed时调用播放器的[suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)接口。

      ```screen
      @Override 
      public void surfaceDestroyed(SurfaceHolder holder) {
          if (player!= null) {
              player.suspend();
          }
      }
      ```

      > 说明
      >
      > 由于部分ROM原因在回调surfaceDestroyed时，surface已经被销毁了，所以业务要确保在surface销毁之前调用suspend停止解码器，避免出现解码器报错。例如：可以在Activity的onPause方法里调用[suspend](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1788394373916)接口。
   5. 恢复播放器，用于前后台切换场景。
      * 如果App使用SurfaceView显示播放画面，则在surfaceCreated时调用播放器设置显示的View，并且调用[resume](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section322644813392)接口。
      * 如果使用TextureView显示播放画面，则在onSurfaceTextureAvailable时调用播放器设置显示的View，并且调用[resume](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section322644813392)接口。

        ```screen
        @Override 
        public void surfaceCreated(SurfaceHolder holder) {
            if (player!= null) {
                 player.setView(surfaceView); 
                 // 切换到前台需要调用resume接口，通过传入参数可以控制是否自动播放
                 player.resume(-1); 
            }
        }
        ```

   6. App通知播放器View尺寸发生改变，确保播放器界面展示正常。
      * 如果App使用SurfaceView显示播放画面，则在surfaceChanged时调用[setSurfaceChange](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14921121101013)接口。
      * 如果使用TextureView显示播放画面，则在onSurfaceTextureSizeChanged时调用[setSurfaceChange](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section14921121101013)接口。

      ```screen
      @Override
      public void surfaceChanged(SurfaceHolder holder, int format, int w, int h) {
          if (player!= null) {
              player.setSurfaceChange();
          }
      }
      ```

5. 调用[release](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1232010561725)，退出当前播放，释放播放器实例。
   1. 停止播放。

      ```screen
      player.stop();
      ```

   2. 释放播放器实例。

      App在退出播放时需要调用下面的接口。

      ```java
      // 重置播放器错误信息上报监听器
      player.setErrorListener(null);
      // 重置播放器媒体以及播放信息上报监听器
      player.setEventListener(null);
      // 重置播放视频分辨率发生变化监听器
      player.setResolutionUpdatedListener(null);
      // 重置媒体内容已经完成准备监听器
      player.setReadyListener(null);
      // 重置播放器缓冲相关事件的监听器
      player.setLoadingListener(null);
      // 重置播放完成监听器
      player.setPlayEndListener(null);
      // 重置seek操作完成的监听器
      player.setSeekEndListener(null);
       
      // 释放播放器，并将播放器对象置为null
      player.release(); 
      player= null;
      ```
