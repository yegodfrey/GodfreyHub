# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## 如何获取华为音频服务的能力？

华为公司发布的手机和平板会预装HMS Core（APK），版本满足要求的前提下，您只需调用音频服务SDK就能获取音频调用能力。

## 音频服务是否包含服务端？

音频服务是一个纯客户端服务，聚焦于为您提供音频播放能力。

## 音频服务对设备和软件有哪些要求？

请参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/introduction-0000001050749665#section159948449318)。

## 调用音频服务收费吗？

音频服务SDK当前提供的接口均免费。

## 音频服务支持哪些格式的音频？

音频服务支持m4a/aac/amr/imy/wav/ogg/rtttl/mp3/ape/flac等Android系统的原生音频格式。

## 音频服务播放器状态回调支持哪些接口？

播放器回调支持播放器播放进度、缓冲进度、播放状态、播放错误等回调接口。

## 音频服务对通知栏支持能力如何？

音频服务支持自定义通知栏样式。

## 音频服务是否支持日志？

音频服务支持SDK日志打印，且日志路径可在接口[HwAudioPlayerConfig](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioplayerconfig-0000001050299072)中配置。

## 音频服务支持什么编码格式的解码和播放？

音频服务可支持384kHz/24bit高品质音频编码格式解析和播放，位宽及采样率向下兼容。

## 在Android 11上，已安装HMS Core（APK）最新版本，仍然提示升级，如何解决？

Android 11更改了应用查询用户在设备上已安装的其他应用以及与之交互的方式。您应用的targetSdkVersion是30或者更高版本，并且集成的Audio Kit 1.4.0.300之前版本时，将无法访问HMS Core（APK），并且持续提示升级。

您可以通过以下两种方法解决。

* 方法一： 升级Audio Kit的SDK至1.4.0.300及以上版本，版本信息请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/version-change-history-0000001050709634)。


* 方法二： 如果不升级SDK，需要在"AndroidManifest.xml"中manifest下添加<queries>标签。

  ```screen
  <manifest ...>
      ...
      <queries>
          <intent>
              <action android:name="com.huawei.hms.core.aidlservice" />
          </intent>
      </queries>
      ...
  </manifest>
  ```

  > 说明
  >
  > <queries>标签对工具的要求如下：
  > * Android Studio需升级至3.3或更高版本。
  > * [Android Gradle插件](https://developer.android.google.cn/studio/releases/gradle-plugin)需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。
