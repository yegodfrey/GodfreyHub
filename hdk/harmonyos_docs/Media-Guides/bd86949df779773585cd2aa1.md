# 声音事件检测Pipeline

## 背景信息

本节的接入方式为[从Java层接入](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/integrating-sdk-0000001156025441#section5461134384418)。

AV Pipeline框架支持在音频流播放过程中进行声音事件的检测。支持如下13种事件识别，检测到有效事件后会将对应的枚举值上报给底层框架，其中"Noise"为无效事件，不进行上报。

```screen
static const string g_events[] = {
    "Laughter",
    "Baby-cry",
    "Snoring",
    "Sneeze",
    "Children-playing",
    "Meow",
    "Bark",
    "Water",
    "Car-alarm",
    "Doorbell",
    "Knock",
    "Alarm",
    "Steam-whistle",
    "Noise"
};
```

声音事件检测Pipeline由4个插件组成，编排关系如下图所示。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210812095804.60621501635166988706515898113436:50520811020908:2800:A8AF64343741563B7ED5D99D10E6DBAFA4F1F575A5E88E23BB1894A91383C1CB.png?needInitFileName=true?needInitFileName=true)

SedAlg为声音事件检测的插件节点，该节点从上游节点FFmpegNode获取解码后的44.1k、双声道、16bit的pcm数据，数据满5s后，每1s检测一次。

以下为声音事件检测Pipeline的graph配置文件AudioPlayerGraphSD.xml。

```screen
<?xml version="1.0"?>
<Nodes>
    <node id="0" name="AVDemuxer" mime="media/demuxer" type="source">
        <!-- 解封装后得到的音频流送给音频解码插件node 1 --> 
        <next id="1"/>
    </node>
    <node id="1" name="FFmpegNode" mime="audio/aac" type="filter">
        <!-- 音频解码后的PCM送给声音事件检测插件node 2 --> 
        <next id="2"/>
    </node>
    <node id="2" name="SedAlg" mime="audio/detect" type="filter">
        <!-- 声音事件检测插件只做检测，不改变PCM流，送给音频播放插件node 3 -->
        <next id="3"/>
    </node>
    <node id="3" name="AudioSinkOpenSL" mime="audio/sink"  type="sink">
    </node>
</Nodes>
```

## 注意事项

* 本插件只支持对未经二次处理的音频流进行检测。
* 音频录制和保存时采样率/位宽应不低于32kHz/16bit， 以保证0Hz-16kHz频谱信息不丢失。
* 本插件检测时只支持返回一个声音事件的识别结果，不支持混杂场景（多个声音事件同时发生）声音识别。可区分的不同类型声音事件至少间隔2秒，可区分的相同声音事件至少间隔30秒。
* 待检测的声音事件在音频流中出现的起始位置不同，检测得分会存在波动，会导致检测结果存在差异。例如，在一个5s窗内，相同的事件出现在1s位置和在1.5s位置时得分不同，可能会因此导致无法正确检测出该事件。

## 开发步骤

1. [创建MediaPlayer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/video-playback-pipeline-0000001110539082)。[type](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section185722257517)需要设置为[PLAYER_TYPE_AUDIO](https://developer.huawei.com/consumer/cn/doc/development/Media-References/constant-values-0000001120875706#ZH-CN_TOPIC_0000001120875706__p8592810183415)，graph需要设置为AudioPlayerGraphSD.xml，使能声音事件检测插件。

   ```screen
   MediaMeta meta = new MediaMeta();
   meta.setString(MediaMeta.MEDIA_GRAPH_PATH, getExternalFilesDir(null).getPath() + "/AudioPlayerGraphSD.xml");
   mPlayer.setParameter(meta);
   ```

2. 调用[setOnMsgInfoListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section19177132620303)接口设置声音事件的回调函数，用于接收上报的声音事件。

   ```screen
   mPlayer.setOnMsgInfoListener(new MediaPlayer.OnMsgInfoListener() {
       @Override
       public void OnMsgInfo(MediaPlayer mp, int param1, int param2, MediaParcel parcel) {
           if (param1 != MediaPlayer.EVENT_INFO_SOUND_SED) return;
           Log.i(TAG, "got sound event:" + param2);
           if (param2 >= 0) {
               mEventView.setText(MediaPlayer.SoundEvent.values()[param2].name());
           }
       }
   });
   ```

3. 调用[start](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section585394815162)开始播放音频，将播放和调用声音事件检测功能。

   ```screen
   mPlayer.start();
   ```

4. 调用[stop](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediaplayer-0000001110596458#section4722920112217)停止播放音频。

   ```screen
   mPlayer.stop();
   ```
