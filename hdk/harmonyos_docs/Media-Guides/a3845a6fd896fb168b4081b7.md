# 业务介绍

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|全景服务（Panorama Kit）是华为为您提供的全景图片浏览和交互服务。您通过集成全景服务SDK，可以在Android手机上快速将球形展开的全景图片或柱状全景图片在模拟的三维空间中以可交互的方式展示，给用户带来沉浸感与真实感。 本视频课程介绍了全景服务的功能、优势以及商业价值。 更多视频请观看：[华为开发者学院](https://developer.huawei.com/consumer/cn/training/) -> [HMS Core慕课](https://developer.huawei.com/consumer/cn/training/detail/101583002419304220)。| |

## 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:---|:----------|:--------------|
|华为手机|EMUI 4.0及以上|4.0.0.300及以上|

> 说明
>
> 全景服务是通过终端陀螺仪传感器信息进行交互的。该交互方式仅手机类设备支持，非手机类设备不支持。

## 场景介绍

* 支持球形展开全景、非完全球形展开全景、柱状全景图的三维全景展示。
* 支持JPG、JPEG和PNG格式的全景图片解析及三维全景展示。
* 支持全景视频的展示与交互。
* 支持全景视角的调整，包括在视窗上直接滑动或通过手机传感器的姿态360度的调整视角。
* 支持业界主流全景相机拍摄的球状全景图的三维展示和交互。
* 额外扩展API开放能力，返回三维全景图层给调用者，让全景服务能被更加灵活的使用，比如可以在应用内的某个区域展示全景信息，而不是应用外的全屏窗口展示。

## 工作原理

1. 您通过在App内集成全景服务SDK，向HMS Core（APK）中的Panorama Kit发送加载平面图片请求，Panorama Kit将做基础的图片安全检查。
2. Panorama Kit将响应App的请求，对平面图片进行解析、解码、纹理渲染等。
3. Panorama Kit最终将二维的平面图在模拟的三维空间中展示，同时支持用户在视窗上直接滑动或通过手机的姿态360度调整视角。

## 功能使用限制

浏览的平面图片大小不大于20M，分辨率小于16384像素*8192像素。随着图片大小增加，响应时间、内存占用、CPU占用及能耗都会有相应的增加。
