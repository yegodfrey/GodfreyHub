# 流程介绍

SP服务侧如果不具备MultiDRM能力（一个视频内容被多种DRM保护），可以参见本章节构建自己的MultiDRM，华为开发者联盟提供密钥管理系统KMS（Key Management Service）示例代码可帮助SP快速构建MultiDRM能力。

华为提供KMS的示例代码，示例代码能够提供生成密钥和管理密钥的能力，以及生成WisePlay DRM加密索引信息的逻辑。

视频内容加密流程如下：

1. 视频运营平台向编码器下发创建内容编码任务，传递ContentID和加密类型等参数。
2. 编码器根据加密类型判断视频是否加密，如果是加密视频则调用getKeyInfo接口向KMS请求获取内容加密密钥Key、KeyID、PSSH Box信息。
3. KMS会生成内容加密密钥Key、KeyID、PSSH Box信息，建立KeyID和ContentID的对应关系，KMS会持久化Key信息，Key信息需要安全存储，不同SP的KMS可以有不同的实现方案。
4. 编码器从KMS获取密钥后，对内容进行转码和加密，视频分片使用AES-128-CTR/CBC方式加密，将PSSH Box信息写入到索引文件中。 说明
   >
   > 如果需要支持MultiDRM，则生成不同DRM类型的PSSH Box信息，并将它们都写到索引文件中。
5. 编码器对视频内容转码加密后，视频内容注入到CDN源站。
