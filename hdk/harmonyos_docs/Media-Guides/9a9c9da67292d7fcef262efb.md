# 特色功能

## 获取音频格式

调用[getAudioFormat](https://developer.huawei.com/consumer/cn/doc/Media-References/haeaudioexpansion-0000001110926740#section592718534216)接口获取音频格式。

```screen
// 音频格式获取接口
HAEAudioFormat audioFormat = HAEAudioExpansion.getInstance().getAudioFormat(inAudioPath);
```

## 转换音频格式

调用[transformAudio](https://developer.huawei.com/consumer/cn/doc/Media-References/haeaudioexpansion-0000001110926740#section19478224210)接口进行音频格式转换，转换后的音频文件导出到**目标路径**。

```screen
// 初始化音频格式转换配置
HAEAudioTransformConfig inAudioConfig = new HAEAudioTransformConfig();
// 设置比特率
inAudioConfig.setBitRate(bitRate); 
// 设置通道数
inAudioConfig.setChannels(channel); 
// 设置采样率
inAudioConfig.setSampleRate(sampleRate); 
// 音频格式转换接口，支持指定采样率、通道数和比特率
HAEAudioExpansion.getInstance().transformAudio(inAudioPath, outAudioPath,inAudioConfig, new OnTransformCallBack(){
    // 进度回调，取值为[0, 100]
    @Override
    public void onProgress(int progress) {
    }
    // 转换失败
    @Override
    public void onFail(int errorCode, String errorMsg) {
    }
    // 转换成功
    @Override
    public void onSuccess(String outPutPath) {
    }
    // 取消转换
    @Override
    public void onCancel() {
    }
});
// 取消转换任务接口
HAEAudioExpansion.getInstance().cancelTransformAudio();
```

## 提取音频

调用[extractAudio](https://developer.huawei.com/consumer/cn/doc/Media-References/haeaudioexpansion-0000001110926740#section13804172751918)接口进行音频提取，从视频中提取音频文件导出到指定目录。

```screen
// outAudioDir提取出的音频保存的文件夹路径，非必填
// outAudioName提取出的音频名称，不带后缀，非必填
HAEAudioExpansion.getInstance().extractAudio(context, inVideoPath, outAudioDir, outAudioName, new AudioExtractCallBack() {
    @Override
    public void onSuccess(String audioPath) {
    Log.d(TAG, "ExtractAudio onSuccess : " + audioPath);
    }
    @Override
    public void onProgress(int progress) {
    Log.d(TAG, "ExtractAudio onProgress : " + progress);
    }
    @Override
    public void onFail(int errCode) {
    Log.i(TAG, "ExtractAudio onFail : " + errCode);
    }
    @Override
    public void onCancel() {
    Log.d(TAG, "ExtractAudio onCancel.");
    }
});
// 取消音频提取任务接口
HAEAudioExpansion.getInstance().cancelExtractAudio();
```

## 文件接口

调用文件接口实现具体功能，请查看以下内容。

必要条件：创建文件接口回调。

```screen
private ChangeSoundCallback callBack = new ChangeSoundCallback() {
    @Override
    public void onSuccess(String outAudioPath) {
        // 处理成功
    }
    @Override
    public void onProgress(int progress) {
        // 进度回调处理
    }
    @Override
    public void onFail(int errorCode) {
        // 处理失败
    }
    @Override
    public void onCancel() {
        // 取消处理
    }
};
```

在创建完回调之后，您可根据自身需求集成以下功能：

### 变声（语音版-针对人声，不支持带背景音乐）

调用[applyAudioFile](https://developer.huawei.com/consumer/cn/doc/Media-References/haechangevoicefile-0000001145007222#section13680738155)接口对音频文件进行变声。

```screen
// 变声
HAEChangeVoiceFile haeChangeVoiceFile = new HAEChangeVoiceFile();
ChangeVoiceOption changeVoiceOption = new ChangeVoiceOption();
changeVoiceOption.setSpeakerSex(ChangeVoiceOption.SpeakerSex.MALE);
changeVoiceOption.setVoiceType(ChangeVoiceOption.VoiceType.CUTE);
haeChangeVoiceFile.changeVoiceOption(changeVoiceOption);
// 调用接口
haeChangeVoiceFile.applyAudioFile(inAudioPath, outAudioDir, outAudioName, callBack);
// 取消变声任务
haeChangeVoiceFile.cancel();
```

### 变声（通用版-支持带背景音乐）

调用[applyAudioFile](https://developer.huawei.com/consumer/cn/doc/Media-References/haechangevoicefile-0000001145007222#section13680738155)接口对音频文件进行变声。


### 空间渲染

调用[applyAudioFile](https://developer.huawei.com/consumer/cn/doc/Media-References/haespacerenderfile-0000001191086913#section147681019155614)接口进行空间方位渲染。 注意
>
> 如果输入音频采样率超过48KHZ，文件会被压缩。

```screen
// 空间方位渲染
// 固定摆位
HAESpaceRenderFile haeSpaceRenderFile = new HAESpaceRenderFile(SpaceRenderMode.POSITION);
haeSpaceRenderFile.setSpacePositionParams(new SpaceRenderPositionParams(x, y, z));
// 动态渲染
HAESpaceRenderFile haeSpaceRenderFile = new HAESpaceRenderFile(SpaceRenderMode.ROTATION);
haeSpaceRenderFile.setRotationParams(new SpaceRenderRotationParams(x, y, z, 环绕时间, 环绕方向));
// 扩展
HAESpaceRenderFile haeSpaceRenderFile = new HAESpaceRenderFile(SpaceRenderMode.EXTENSION);
haeSpaceRenderFile.setExtensionParams(new SpaceRenderExtensionParams(弧度, 角度));
// 调用接口
haeSpaceRenderFile.applyAudioFile(inAudioPath, outAudioDir, outAudioName, callBack);
// 取消空间方位渲染
haeSpaceRenderFile.cancel();
```

### 空间效果

调用[start3DRemixTask](https://developer.huawei.com/consumer/cn/doc/Media-References/hae3dremixfile-0000001409254012#section1155625817910)接口进行空间效果音频生成。

```screen
// 设置空间效果生成器属性
HAE3DRemixSetting setting = new HAE3DRemixSetting.Builder() 
    // 生成的空间音频效果文件保存的路径
    .setRemixOutDir(outputPath) 
    // 生成的空间音频效果文件名
    .setRemixOutName(name) 
    // 输入的原始音频文件路径
    .setRemixPath(filePath) 
    // 待生成的空间音频效果类型，取值为：HAE3DRemixSetting.RemixType中定义的枚举类型
    .setRemixType(remixType) 
    .build();
// 获取空间效果处理器实例
HAE3DRemixFile hae3DRemixFile = HAE3DRemixFile.getInstance();
// 开始空间效果处理
hae3DRemixFile.start3DRemixTask(setting, new RemixCallback() {
    @Override
    public void onFinish(RemixBean remixBean) {
        // 完成场景处理
    }
    @Override
    public void onFail(int i) {
        // 失败场景处理
    }
    @Override
    public void onCancel() {
        // 取消场景处理
    }
    @Override
    public void onProcess(RemixBean remixBean) {
        // 返回进度处理
    }
});
// 取消空间效果处理
hae3DRemixFile.cancel(new CancelCallback() {
    @Override
    public void onResult() {
        // 取消成功处理
    }
    @Override
    public void onFail(int i) {
        // 取消失败处理
    }
});
// 清除空间效果处理过程中生成的缓存数据，context为应用上下文
hae3DRemixFile.clearCache(context); 
```

## 流式接口

调用流式接口实现对音频流的处理，包括变声、环境效果、声场、均衡、降噪，最终结果需要您自行设置。

1. 设置变声效果（语音版-针对人声，不支持带背景音乐）。

   ```screen
   HAEChangeVoiceStream haeChangeVoiceStream = new HAEChangeVoiceStream();
   changeVoiceOption = new ChangeVoiceOption();
   changeVoiceOption.setSpeakerSex(ChangeVoiceOption.SpeakerSex.MALE);
   changeVoiceOption.setVoiceType(ChangeVoiceOption.VoiceType.CUTE);
   haeChangeVoiceStream.changeVoiceOption(changeVoiceOption);
   // 设置音频的格式参数，返回设置结果res（注：当res为HAEErrorCode.SUCCESS时才可进行后续操作）
   int res = haeChangeVoiceStream.setAudioFormat(BIT_DEPTH, CHANNEL_COUNT, SAMPLE_RATE);
   // 对pcm数据（buffer）进行变声操作，返回变声后的pcm数据（resultByte）
   while(buffer!=null){
       byte[] resultByte = haeChangeVoiceStream.applyPcmData(buffer);
   }
   // 变声结束后释放资源
   haeChangeVoiceStream.release();
   ```

2. 设置变声效果（通用版-支持带背景音乐）。

   ```screen
   HAEChangeVoiceStreamCommon haeChangeVoiceStreamCommon = new HAEChangeVoiceStreamCommon();
   ```

## 素材库功能

1. 创建素材管理类。

   ```screen
   HAEMaterialsManageFile materialsManageFile = new HAEMaterialsManageFile();
   ```

2. 获取素材类型。

   ```screen
   materialsManageFile.getFatherId(new MaterialsCallBack<List<MaterialMenu>>() {
       @Override
       public void onFinish(List<MaterialMenu> list) {
           // 目前有两个大类，包含音效和乐段
       }
       @Override
       public void onError(int errorCode) {
       }
   });
   ```

3. 获取素材栏目列表。

   ```screen
   // fatherId为选择的素材类型ID，目前支持音效和乐段
   materialsManageFile.getColumnsByFatherColumnId(fatherId, new MaterialsCallBack<List<MaterialsCutColumn>>() {
       @Override
       public void onFinish(List<MaterialsCutColumn> response) {
       }
       @Override
       public void onError(int errorCode) {
       }
   });
   ```

4. 根据栏目ID获取素材列表。

   ```screen
   // fatherId为选择的素材类型ID，columnId为栏目ID，page为当前页码，pageSize为每页素材个数
   materialsManageFile.getMaterialsByColumnId(fatherId, columnId, page, pageSize, new MaterialsCallBack<List<MaterialsCutContent>>() {
       @Override
       public void onFinish(List<MaterialsCutContent> response) {
       }
       @Override
       public void onError(int errorCode) {
       }
   });
   ```

5. 根据素材ID获取下载地址。

   ```screen
   // materialId是素材ID
   materialsManageFile.getDownLoadUrlById(materialId, new MaterialsCallBack<String>() {
       @Override
       public void onFinish(String downloadUrl) {   
       }
       @Override
       public void onError(int errorCode) {
       }
   });
   ```

6. 下载素材资源。

   ```screen
   // downloadUrl为下载地址，outAudioDir为下载文件夹，outAudioName为保存的文件名
   materialsManageFile.downloadResource(downloadUrl, outAudioDir, outAudioName, new MaterialsDownloadCallBack() {
       @Override
       public void onDownloadSuccess(File file) {}
       @Override
       public void onDownloading(int progress) {}
       @Override
       public void onDownloadFailed(int errorCode) {}
   });
   ```
