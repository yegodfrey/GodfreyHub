# 关键帧能力

支持用户使用关键帧能力。具备关键帧能力的资源和特效都会实现[HVEKeyFrameAbility](https://developer.huawei.com/consumer/cn/doc/Media-References/hveeeyframeability-0000001245615369)接口，包括[HVEAudioAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hveaudioasset-0000001156050672)、[HVEImageAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hveimageasset-0000001156929212)、[HVEStickerAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hvestickerasset-0000001202689207)、[HVEVideoAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hvevdeoasset-0000001155730670)、[HVEWordAsset](https://developer.huawei.com/consumer/cn/doc/Media-References/hvewordasset-0000001201930665)和[HVEEffect](https://developer.huawei.com/consumer/cn/doc/Media-References/hveeffect-0000001156929220)（色彩调节，滤镜调节以及蒙版三种特效支持关键帧能力，其中内嵌特效（如蒙版等）的关键帧跟随所属资源的关键帧能力，外联特效实现了[HVEKeyFrameAbility](https://developer.huawei.com/consumer/cn/doc/Media-References/hveeeyframeability-0000001245615369)接口）。  

#### 修改资源属性

```
// 在时间点time1添加关键帧1，此方法内部会将时间线的时间点转换为资源的时间点，从而添加到对应的资源上面
((HVEKeyFrameAbility) visibleAsset).addKeyFrame();

// 在另外一个时间点time2，添加关键帧2（此步骤可省略，改变资源属性后会自动添加关键帧2）
((HVEKeyFrameAbility) visibleAsset).addKeyFrame();

// 在time2改变资源的大小位置等属性（width, height为改变大小后资源的宽高）
visibleAsset.setSize(width, height);
```

#### 修改特效属性

#### 修改外联特效的属性

```
// 添加外联特效hveEffect。需要添加在特效泳道中，可以跨多个资源，可以任意调节其时间长度
// 创建一条特效泳道，然后往泳道上添加特效，通过构造HVEEffect.Options对象来创建特效
HVEEffectLane effectLane = timeline.appendEffectLane();

// 创建一个颜色调节特效，添加到0位置，时长为3000ms
HVEEffect hveEffect= effectLane.appendEffect(new HVEEffect.Options(HVEEffect.EFFECT_COLORADJUST, "", ""), 0, 3000);

// 在时间点time1添加关键帧1，此方法内部会将时间线的时间点转换为资源的时间点，从而添加到对应的资源上面
((HVEKeyFrameAbility) hveEffect).addKeyFrame();

// 在另外一个时间点time2，添加关键帧2（此步骤可省略，改变调节特效的强度后会自动添加关键帧2）
((HVEKeyFrameAbility) hveEffect).addKeyFrame();

// 在time2改变滤镜的强度（HVEEffect.FILTER_STRENTH_KEY为特效强度的Key，strength为特效强度的值）
hveEffect.setFloatVal(HVEEffect.FILTER_STRENTH_KEY, strength);
```

#### 修改内嵌特效的属性

```
// 给资源添加蒙版特效，需要添加在资源中，只能作用于单个资源，时间长度与资源一样，无法单独调节
// options是根据下载下来的特效素材生成的构造类HVEEffect.Options
HVEEffect hveEffect = visibleAsset.appendEffectUniqueOfType(options, HVEEffect.HVEEffectType.MASK);

// 在时间点time1添加关键帧1，此方法内部会将时间线的时间点转换为资源的时间点，从而添加到对应的资源上面
((HVEKeyFrameAbility) visibleAsset).addKeyFrame();

// 在另外一个时间点time2，添加关键帧2（此步骤可省略，改变资源内嵌特效属性后会自动添加关键帧2）
((HVEKeyFrameAbility) visibleAsset).addKeyFrame();

// 在time2改变资源内嵌特效的属性，例如oldHeight为蒙版原先的高度，newHeight为蒙版新的高度
float oldHeight = hveEffect.getFloatVal(HVEEffect.MASK_HEIGHT_KEY);
float newHeight = oldHeight/2;
hveEffect.setFloatVal(HVEEffect.MASK_HEIGHT_KEY, newHeight);
```

#### 选中或获取关键帧

```
// 获取当前对象中的全部关键帧的时间戳
List<Long> times = ((HVEKeyFrameAbility) visibleAsset).getAllKeyFrameTimestamp();

// 选中关键帧，i为关键帧的索引，0 ≤ i < times.size()
((HVEKeyFrameAbility) visibleAsset).selectKeyFrame(i);

// 获取当前对象上选中的关键帧
((HVEKeyFrameAbility) visibleAsset).getSelectedKeyFrame();
```

#### 移除关键帧

```
// 移除关键帧
((HVEKeyFrameAbility) visibleAsset).removeKeyFrame();
```
