# 素材管理

## 编排素材数据

请参见[编排素材](https://developer.huawei.com/consumer/cn/doc/Media-Guides/operations-guide-0000001201961634)，编排您应用的素材数据。

素材栏目编排好之后，可以采用素材管理模块提供的接口，进行查询下载指定素材。

## 查询顶层栏目

顶层栏目类型有多种，具体类型请参见[HVEMaterialConstant](https://developer.huawei.com/consumer/cn/doc/Media-References/hvematerialconstant-0000001165651670)。查询顶层栏目，只需要指定顶层栏目的ID列表。

```screen
// 创建顶层栏目查询请求
List<String> fatherColumn = new ArrayList<>();
fatherColumn.add(HVEMaterialConstant.CANVAS_FATHER_COLUMN);
HVETopColumnRequest canvasEvent = new HVETopColumnRequest(fatherColumn);

// 调用顶层栏目查询接口
HVEMaterialsManager.getTopColumnById(canvasEvent,
 new HVEMaterialsResponseCallback<HVETopColumnResponse>() {
        @Override
        public void onFinish(HVETopColumnResponse response) {
            // 请求完成，请求结果包含在response中
        }

        @Override
        public void onUpdate(HVETopColumnResponse response) {
            // 本地网络素材缓存有更新
            // 请求完成，请求结果包含在response中
        }

        @Override
        public void onError(Exception e) {
            // 请求失败
        }
});
```

## 查询子栏目信息

根据顶层栏目查询接口返回的[HVEChildColumnResponse](https://developer.huawei.com/consumer/cn/doc/Media-References/hvechildcolumnresponse-0000001206114627)结果，可以获取顶层栏目包含的子栏目列表，选择其中的一个子栏目进行查询素材信息。

```screen
// 获取顶层栏目下面的子栏目列表
List<HVEColumnInfo> cloumnList = topColumnInfo.getChildInfoList();

// 选中第一子栏目
HVEColumnInfo columnInfo = cloumnList.get(0);

// 创建子栏目查询请求，指定子栏目ID，分段查询的参数，是否强制从云侧获取最新数据
HVEChildColumnRequest request = new HVEChildColumnRequest(columnInfo.getColumnId(),
 Constant.PAGE_SIZE, Constant.PAGE_SIZE, false);

// 调用子栏目查询接口
HVEMaterialsManager.getChildColumnById(request,
new HVEMaterialsResponseCallback<HVEChildColumnResponse>() {
        @Override
        public void onFinish(HVEChildColumnResponse response) {
            // 请求完成，请求结果包含在response中
        }

        @Override
        public void onUpdate(HVEChildColumnResponse response) {
            // 本地网络素材缓存有更新
            // 请求完成，请求结果包含在response中
        }

        @Override
        public void onError(Exception e) {
            // 请求失败
        }
});
```

## 下载指定素材

根据子栏目查询接口返回的[HVEChildColumnResponse](https://developer.huawei.com/consumer/cn/doc/Media-References/hvechildcolumnresponse-0000001206114627)结果，可以获取素材列表，选择其中一个素材进行下载。

```screen
// 获取子栏目中素材列表
List<HVEMaterialInfo> materialInfos = response.getMaterialInfoList();

// 选择其中第一个素材
HVEMaterialInfo material = materialInfos.get(0);

// 场景素材下载请求，指定素材ID
HVEDownloadMaterialRequest request = new HVEDownloadMaterialRequest(material.getMaterialId());

// 调用素材下载接口
HVEMaterialsManager.downloadMaterialById(request, new HVEDownloadMaterialListener() {
    @Override
    public void onSuccess(String file) {
        // 素材下载成功，返回素材在本地的路径
    }

    @Override
    public void onProgress(int progress) {
        // 素材下载进度
    }

    @Override
    public void onFailed(Exception exception) {
        // 素材下载失败
    }

    @Override
    public void onAlreadyDownload(String file) {
        // 素材已经在本地存在，返回素材在本地的路径
    }
});
```
