# 媒体资产管理

本节的接入方式为[从Java层接入](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/integrating-sdk-0000001156025441#section5461134384418)。

AV Pipeline的媒体资产管理通过调用[Asset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560)类、[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)类、[Track](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512)类，可实现对媒体文件的信息提取、媒体流管理、Buffer读取等解析能力。

|类名|说明|是否可以直接构造|
|:------------------------------------------------------------------------------------------------------------------|:----------------------------------------|:----------------------|
|[Asset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560)|封装后的媒体资产。 一个Asset包含多个TrackGroup。|可以。|
|[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)|一种媒体类型。如视频类型或音频类型。 一个TrackGroup包含多个Track。|不可以，只能从Asset实例中获取。|
|[Track](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512)|一个媒体流。如视频流或音频流。|不可以，只能从TrackGroup实例中获取。|

## 获取文件级别媒体信息

Asset类代表一个媒体资产，通过该类可实现获取文件级别的媒体信息。

1. 创建[Asset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560)实例。

   [create](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section79808180113)接口是创建Asset的唯一入口。若创建失败会返回null，用户需要自行校验返回值。

   ```screen
   Asset asset = Asset.create();
   if (asset == null) {
       return;
   }
   ```

2. 设置本地媒体文件的绝对路径[setUrl](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section639454010917)。

   ```screen
   asset.setUrl("/sdcard/Download/xxx.mp4");
   ```

3. 获取媒体资产的信息。

   如调用[getDuration](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section16124172741319)获取总时长、[getBitRate](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section1954214383148)获取平均比特率、[getMetaData](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section1985362412010)获取元信息等。

   ```screen
   long duration = asset.getDuration();
   long bitRate = asset.getBitRate();
   MediaMeta.Fraction frameRate = asset.getFrameRate();
   ```

## 获取资源所包含的媒体类型

一个媒体资产一般包含多种媒体类型，例如视频类型、音频类型。相对应的，一个[Asset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560)实例包含多个[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)实例，来反映这种包含关系。

1. 调用[create](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section79808180113)创建[Asset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560)实例。
2. 调用[setUrl](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section639454010917)设置本地媒体文件的绝对路径。
3. 调用[getTrackGroupByType](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section18962153313310)或[getAllTrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section7717650173315)获取[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)实例。

   ```screen
   for (TrackGroup oneGroup : asset.getAllTrackGroup()) { 
       if (oneGroup == null) {
           continue;
       }
   }
   ```

## 管理同类型媒体流

[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)表示媒体资产中的一类媒体流，通过该类可实现对同类型媒体流的选择控制或获取Buffer。例如音频类型流包含两个不同语言的音频流：中文音频流和英文音频流，TrackGroup可实现选择1个音频流进行解析。

由于TrackGroup依附[Asset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560)而存在，因此它的构造函数是私有的，使用TrackGroup请按如下操作。

1. [获取TrackGroup实例](#section1615048102614)。
2. 查询媒体类型信息。

   ```screen
   // 查询媒体类型
   MediaType type = oneGroup.getTrackType(); 
   // 查询该媒体类型包含多少个流
   int cnt = oneGroup.getNumOfTracks(); 
   // 查询该媒体类型包含的所有流的实例
   Track[] tracks = oneGroup.getAllTracks(); 
   ```

## 获取媒体流级别信息

[Track](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512)表示一个具体的媒体流，通过该类实现对媒体流的解析，获取媒体流级别的信息。

由于Track依附于[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)而存在，因此它的构造函数是私有的，使用Track请按如下操作。

1. 获取[Track](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512)实例。
   1. [获取TrackGroup实例](#ZH-CN_TOPIC_0000001110379188__li31691110165310)。
   2. 调用[getTrackById](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471#section17821163693713)或[getAllTracks](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471#section185151916133913)获取Track实例。

   > 说明
   >
   > 在一个媒体文件中，每个Track都有一个唯一的id。例如某个文件的id=0对应一个音频流、id=1对应一个视频流、id=2对应又一个音频流。
2. 查询[Track](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512)实例所包含的信息。

   如调用[getNumOfFrames](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512#section11417152733218)获取该流包含的总帧数，[getStartTime](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512#section5783185610225)获取该流的起始时间戳，[getDuration](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512#section13655155722418)获取该流的持续时长等。

   ```screen
   long frames = oneTrack.getNumOfFrames();
   long startTime = oneTrack.getStartTime();
   long duration = oneTrack.getDuration();
   MediaMeta.Fraction timeScale = oneTrack.getTimeScale(); 
   MediaMeta meta = oneTrack.getMetaData();
   ```

   > 说明
   >
   > 与时间相关的属性（如起始时间戳、持续时长等）都从[getTimeScale](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512#section81718182189)接口中获取单位，用[Fraction](https://developer.huawei.com/consumer/cn/doc/development/Media-References/fraction-0000001110871708)表示。

## 获取sample数据

在[setUrl](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section639454010917)时，[Asset](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560)将每个[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)中默认选择的[Track](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512)所包含的帧数据缓存在内部，通过[getSample](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471#section4440820164714)获取每帧数据。

1. 调用[seekTo](https://developer.huawei.com/consumer/cn/doc/development/Media-References/asset-0000001110436560#section15944629172815)控制从哪个时间戳位置开始读取数据。

   ```screen
   asset.seekTo(50);
   ```

2. 调用[selectTrack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471#section10138162214406)控制当前[TrackGroup](https://developer.huawei.com/consumer/cn/doc/development/Media-References/trackgroup-0000001156948471)中需要读取哪个[Track](https://developer.huawei.com/consumer/cn/doc/development/Media-References/track-0000001110628512)。对于同一类TrackGroup，同一时间只能读取其中一个Track的sample数据。

   ```screen
   TrackGroup trackGroup = asset.getTrackGroupByType(MediaType.MT_VIDEO);
   trackGroup.selectTrack(trackID);
   ```

3. 获取数据。

   ```screen
   MediaBuffer buf = trackGroup.getSample();
   ```
