# 场景介绍

Video Engine提供视频的高级编码服务（只针对H.264, H.265格式），助力您快速构建视频编码的高级特性，帮助您向用户提供高清、低码、流畅的视频媒体体验。

您在调用Android的MediaCodec做视频编码时，可以给codec配置特定的参数，触发视频编码器的如下高级编码功能，满足特定场景的需求。

* 缩放/裁剪功能：编码场景下，实现图像分辨率的无缝切换。
* 动态码控：动态调整帧级QP（Quantizer Parameter，量化参数）范围，实现画质的自由切换。
* 非参考帧编码：通过丢弃非参考P帧，降低带宽，提升流畅度。
* 长期参考帧编码：网络不稳定时，编码端动态调整参考关系，提升解码端的流畅度。
* 感兴趣区域编码：提高特定区域的画质，带来更好的视觉体验。
