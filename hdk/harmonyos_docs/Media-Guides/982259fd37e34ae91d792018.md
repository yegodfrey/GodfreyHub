# 音箱校准

音箱调节区域可调节当前渲染模式下对应音箱的增益大小。您可通过手动输入或通过上下箭头调整。支持单击音箱图标对该音箱进行静音操作。

例如渲染模式您可选择7.1.2，再调试此渲染模式下的音箱。
