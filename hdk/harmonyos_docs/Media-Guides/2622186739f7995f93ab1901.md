# 操作步骤

## 操作

1. 当系统出现如下页面提示时，点击"好"，启动麦克风权限。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.62456948338534515853138143996570:50001231000000:2800:91504F6B5C432B759056D56358BB6D8F6F4ADC828B542DAC03E033626F65A59B.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   >
   > 如果点击"好"，则允许启动麦克风权限和录制音频文件，如果点击不允许，则无法访问麦克风权限，可在Mac系统的"系统偏好设置"中，选取"安全性与隐私"，选择边栏中的麦克风，在窗口右侧启用"Petal Vivid Renderer"。
2. 启动Petal Vivid [Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)，并选择Renderer渲染模式，例如7.1.2。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.21256938528899206263990405058604:50001231000000:2800:09E4CB19956FBA35CF44BE10A8796971B06D9DD7E206BD91CA9793F908CFA73D.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 启动DAW，新建DAW项目并使DAW总线配置与Petal Vivid [Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)模式相同。
4. 选择信号传输模式：[虚拟声卡模式](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/petal-audio-bridge-0000001399091073)或者[Send/Return模式](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/send-return-0000001404209037)。
5. 在DAW轨道上挂载Petal Vivid [Panner](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/p_home_screen-0000001270491016)插件，对轨道音频进行空间位置编辑。
6. 插件会自动分配连接Petal Vivid [Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)，并占用Renderer中的对象通道。您可手动选择或修改需要连接的对象序号。连接成功后，状态灯变为绿色![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.73029835250958121055784486579469:50001231000000:2800:6F4405E03A27730F90CF087AEBFF6C5F3DC02443AB9D8D5149C1D03A05A2A4DC.png?needInitFileName=true?needInitFileName=true) 。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.52589782023270114643188753059300:50001231000000:2800:3EC54AC38B9501C7F190EC1A3BA68E821AF97AF887DFA2A564562F02FB934534.png?needInitFileName=true?needInitFileName=true "点击放大")
7. 您可根据需求将[Panner](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/p_home_screen-0000001270491016)切换为[动态声床](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/p_connection_status_area-0000001270171160#section65031848142815)或[静态声床](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/p_connection_status_area-0000001270171160#section11669565283)模式。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.62022283162638717497299461612483:50001231000000:2800:ADD9C83E1E4AE77F4618867406E9A243F282D82F162B5B6D8CB86B26CF438AA4.png?needInitFileName=true?needInitFileName=true "点击放大")

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.07997446449855847196606352531523:50001231000000:2800:705CB5D41D9C960D60C4D8605E8C52D2DC49F1F32E9B148694239573FA2C7E30.png?needInitFileName=true?needInitFileName=true "点击放大")
8. 您可在[Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)上对对象进行监控或分组管理。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.03909342524334728882066527171751:50001231000000:2800:6A064D1242F0022556F34A1338871421AFFF1EC95816BEA08B41C1F0F4D5F5A6.png?needInitFileName=true?needInitFileName=true "点击放大")
9. 在DAW轨道上挂载[Return](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/return_main_screen-0000001323264517)插件并选择输出总线，Return插件会自动将[Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)输出通道映射到DAW轨道上（此步骤仅限于Send/Return模式）。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.68484492762857740033493824822041:50001231000000:2800:F8BF4DA47C81FDB0ED7D5AECB7A998EF4A4505014D86DB8D2C2EC04D8DC29961.png?needInitFileName=true?needInitFileName=true "点击放大")

   您可根据需求选择扬声器模式或双耳模式。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152641.65914076042226973253909462334830:50001231000000:2800:45B9F27CAC506915F3669059AF302908E15613DAFFBCB37FDC74379619658AE6.png?needInitFileName=true?needInitFileName=true "点击放大")
10. DAW进行播放，挂载[Return](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/return_main_screen-0000001323264517)插件的轨道便会收到[Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)渲染后的音频数据，并通过输出总线播放出来。
