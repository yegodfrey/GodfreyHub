# 空间编辑及展示区域

三维声空间编辑及展示区域可分为输入输出电平显示及音量推子（支持控制Panner输出音量）模块、三种显示视图（支持点击视图图标进行自由切换）模块和辅助编辑工具模块。对象编辑模式下可使用鼠标工具（支持自由拖拽）、拉伸工具及3D视图下的障碍物工具对音频对象进行自由编辑。
