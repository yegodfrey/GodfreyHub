# 集成调测资源

为了让您更便捷地完成WisePlay DRM的集成开发工作，华为提供了一个开放的调测环境。

您可以在不开通数字版权管理服务的情况下，直接使用下面信息对接WisePlay DRM Server调测环境，同时也建议在开发阶段使用该调测环境进行对接测试，测试成功后，再对接到商用环境。

**Access URL：**https://drmkit.hwcloudtest.cn:8080/drmproxy/v3/getLicense

**APP ID**：102771135

**PortalID：**TestForDeveloper
> 说明
>
> * 由于安全策略的原因，在接入WisePlay DRM Server调测环境前，需要您联系您的线下客户经理或者支持工程师，反馈将要连接到WisePlay DRM Server调测环境的服务器IP地址，并获取AES Key和Sign Key。
> * 调测环境**getLicense** 接口V2版本的Access URL为https://drmkit.hwcloudtest.cn:8080/drmproxy/**v2**/getLicense，建议优先使用V3版本。
