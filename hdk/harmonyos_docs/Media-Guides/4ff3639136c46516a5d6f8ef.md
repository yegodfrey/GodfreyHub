# 贴纸花字服务

## 场景介绍

贴纸花字服务为您提供贴纸花字的编辑功能，用户可对贴纸和花字进行缩放、拖动、删除操作，花字支持用户自定义文本输入。您可以DIY图片，得到更加特别的图片。

## 开发步骤

贴纸花字服务的所有接口的实现都是基于[StickerLayout](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sitckerlayout-0000001260365838)，是一个自定义View，import的包名为com.huawei.hms.image.vision.sticker.StickerLayout，直接可以集成在layout的XML中。

1. 获取到[StickerLayout](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sitckerlayout-0000001260365838)对象。

   通过findViewById获取到StickerLayout对象后，可以调用具体的逻辑方法。

   ```screen
   "Java"
   StickerLayout mStickerLayout = findViewById(R.id.sticker_container);
   ```

   ```screen
   "Kotlin"
   mStickerLayout = findViewById(R.id.sticker_container)
   ```

2. 提供资源文件。

   参见[贴纸](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sticks-0000001058566694)和[花字](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/art_fonts-0000001057636407)设计并生成贴纸、花字资源。
3. 添加贴纸花字。

   调用[addSticker](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sitckerlayout-0000001260365838#section166631215172212)接口，添加贴纸花字，传入资源文件路径和文件名，如果返回码为0，则为添加成功，贴纸花字总数最多可以添加50个。

   ```screen
   "Java"
   int resultCode = mStickerLayout.addSticker(rootPath, fileName);
   ```

   ```screen
   "Kotlin"
   val resultCode = mStickerLayout!!.addSticker(rootPath, fileName)
   ```

   请求接口参数描述：

   |参数列表|类型|M/O（必选/可选）|说明|
   |:-------|:-----|:---------|:------------------------|
   |rootPath|String|M|资源文件根目录。|
   |fileName|String|M|如果是贴纸，需要指定的文件名，其他可以传null。|

   代码示例：

   ```screen
   "Java"
   addSticker(rootPath + "贴纸1", "sticker_10_editable.png");
   addSticker(rootPath + "花字4", null);
   ```

   ```screen
   "Kotlin"
   addSticker(rootPath + "贴纸1", "sticker_10_editable.png");
   addSticker(rootPath + "花字4", "");
   ```

4. 更新花字的文本。

   您可以对花字文本进行编辑，通过回调方法[setStickerLayoutListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sitckerlayout-0000001260365838#section158298571178)(new [StickerLayout.StickerLayoutListener](https://developer.huawei.com/consumer/cn/doc/development/Media-References/stickerlayoutlistener-0000001307844057)()）获取花字文本编辑对象textEditInfo，textEditInfo调用setText，进行文字编辑，最后mStickerLayout调用[updateStickerText](https://developer.huawei.com/consumer/cn/doc/development/Media-References/sitckerlayout-0000001260365838#section179751901584)方法进行更新。

   ```screen
   "Java"
   //获取TextEditInfo对象
   mStickerLayout.setStickerLayoutListener(new StickerLayout.StickerLayoutListener() {
       @Override   
       public void onStickerLayoutClick() {
       }
       @Override 
       public void onStickerTouch(int index) {
       }
       @Override   
       public void onTextEdit(TextEditInfo textEditInfo) {
           StickerActivity.this.textEditInfo = textEditInfo;    
       }
       @Override
       public void needDisallowInterceptTouchEvent(boolean isNeed) {
       }
   });
   //更新花字文本为"花字测试"字样
   textEditInfo.setText("花字测试");
   mStickerLayout.updateStickerText(textEditInfo);
   ```

   ```screen
   "Kotlin"
   //获取TextEditInfo对象
   mStickerLayout?.setStickerLayoutListener(object : StickerLayoutListener {
       override fun onStickerLayoutClick() {    
       }
       override fun onStickerTouch(index: Int) {
       }
       override fun onTextEdit(textEditInfo: TextEditInfo) {
           this@StickerActivity.textEditInfo = textEditInfo
       }
       override fun needDisallowInterceptTouchEvent(isNeed: Boolean) {
       }
   })
   //更新花字文本为"花字测试"字样
   textEditInfo!!.text = "花字测试"
   mStickerLayout?.updateStickerText(textEditInfo)
   ```
