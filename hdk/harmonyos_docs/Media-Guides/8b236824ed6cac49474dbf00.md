# 助力唱鸭打造"AI创作歌姬",为用户带来更具创意的音乐玩法

#### 唱鸭App简介

唱鸭是一款将乐器和曲谱标记融合的新型弹唱软件，用户通过 App内的图标提示，不需要乐器知识，就可以轻松实现创作、弹唱音乐，降低了非专业音乐人"玩音乐"的难度。  

#### 合作方式

作为一款作为深受用户喜爱的音乐社区软件，唱鸭为满足用户不断增加的创意需求，与HMS Core音频编辑服务合作，集成其歌声合成技术推出了"AI创作歌姬"功能。

* 用户选择"AI创作歌姬"后，只需输入歌词，选择喜欢的音乐风格，就会自动生成动听的歌曲，并通过细腻自然、情感充沛的歌声演唱出来。
* 基于华为独创的AI Singer模型，歌声合成可以精准预测颤音、扰动和换气声等演唱技巧，让拟真的呼吸音与歌曲节奏完美契合，实现歌手级的高水准演唱，给用户带来了令人惊喜的新奇体验，释放更具创意的音乐创作力。

#### 合作价值

唱鸭创始人李阳说到："与HMS Core音频编辑服务的合作后，唱鸭让用户能够通过简单地输入歌词即可合成歌声，轻松完成各种类型的演唱，让没有专业学习音乐的人也能够享受到音乐互动的乐趣。AI技术赋能提升了我们的用户体验，也助力了唱鸭的业务创新。"
