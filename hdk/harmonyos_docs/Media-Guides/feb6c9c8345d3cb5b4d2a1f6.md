# 主界面

Petal Vivid Return挂载在DAW轨道上，可将Renderer渲染过的数据实时传输到轨道上，并在DAW上进行播放或渲染导出。支持扬声器模式和双耳模拟模式。

扬声器模式与Renderer上所选的渲染模式保持一致，基于插件挂载的轨道上的通道（Ch）数量，显示通道（Ch）数量，您可通过下拉菜单对通道（Ch）进行分配。建议轨道属性与渲染模式一致，否则会造成通道多次发送或丢失通道的结果（只支持Send/Return模式，虚拟声卡模式下不需要使用）。
