# 贴纸

## 业务介绍

贴纸可装饰图片，点击可以应用在图片上，可叠加多张使用。

## 制作流程

1. 设计制作。
   * 应用说明
     * 可叠加多个使用。
     * 可删除，同比缩小放大，旋转。
     * 只能整体缩放旋转，不可单独纵向拉升或横向拉升。
     * 当贴纸完全的挪出图片区域，贴纸将以默认状态重新出现在图片上。


   * 切图资源设计 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210716170712.23229342543244583527712396544673:50520715091657:2800:10936D5A0A4AAF6B2E6F73EC412A7384E45B0A38F90B66E8AFDD3796B56B0F90.png?needInitFileName=true?needInitFileName=true)

     如图所示切图，图中示范为20个贴纸命名样例。
     * 贴纸张数要求：20张至30张。
     * 命名要求：sticker_1_editable.png至sticker_*x* _editable.png （*x*代表数字）。
     * 格式：贴纸需为空白处是镂空透明效果的png图。
     * 贴纸设计尺寸：450px*450px。
     * 分辨率：72像素/英寸。
     * 大小：小于30k（单张）。


   * 风格描述文件（XML）资源说明

     ```screen
     <?xml version="1.0" encoding="utf-8"?>
     <HwTheme>
     	<item style="sticker"/>
     	<stickerposition>Default</stickerposition>
     	<stickerscreen>w="360" h="360"</stickerscreen>
     </HwTheme>
     ```

     > 说明
     > * 贴纸的默认位置在图片显示区域的中心位置。
     > * 贴纸大小单位px。
     > * 贴纸默认大小为360px*360px，当前image Kit不可以修改尺寸。
2. 打包结构。
   * 打包目录结构 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210716170712.39258846815065541846997941833968:50520715091657:2800:05820C8D7A039E548CE31BC6946DA2C73F9ABD6BD6AA9E3C3DBCDE01A52CCC73.png?needInitFileName=true?needInitFileName=true "点击放大")


   * description文件规格说明

     ```screen
     <HwTheme>
         <title>Kasuga Imagination</title>
         <title-cn>春日畅想曲</title-cn>
         <author>华为官方主题设计团队</author>
         <designer>华为官方主题设计团队</designer>
         <screen>FHD</screen>
         <version>10.0.100</version>
         <briefinfo-en>英文简介</briefinfo-en>
         <briefinfo-cn>中文简介</briefinfo-cn>
         <formatType>6</formatType>
     </HwTheme>
     ```

     > 说明
     > * 主题英文名，中文名，开发者名称，设计师名称四项待主题上线后均不可修改。
     > * 主题分辨率，不可修改。
     > * 版本号为10.0.100。后续有更新则更改为10.0.10X（X为阿拉伯数字），例如10.0.101。
     > * format Type装饰模板业务"5"代表花字、"6"代表贴纸。
     > * 简介不可为空。
     > * 制作者名称（author）必须等于设计师者名称（designer）。


   * 最终提供样例 贴纸样例包：[贴纸.zip](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20210716170712.03824610592436526550894245253246:50520715091657:2800:B276138906F3FB8E61BDCC6B5FF8C9DD896E1A6284EFC1C797CEA84361D4DCE7.zip?needInitFileName=true)。
