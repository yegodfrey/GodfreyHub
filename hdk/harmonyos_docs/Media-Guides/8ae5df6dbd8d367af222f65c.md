# 3D视图

Renderer 3D视图区域可展示当前播放中的音频状态。每一个小球代表一个声源对象（包括动态声床对象，外圈带有蓝色圆环的为动态声床对象；静态声床不在展示范围内），小球颜色代表声源对象当前的音量状态，可选择显示小球对应的对象数字编号或分组信息，支持全屏显示。
