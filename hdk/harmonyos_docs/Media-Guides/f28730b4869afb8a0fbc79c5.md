# 使用入门

## 开发环境

Android Studio开发环境：建议版本V3.0.1及以上。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:----------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/preparations-0000001058740907)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：注册成为开发者和创建应用。然后下载并集成电影级调色SDK。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/app-dev-0000001059303706)|根据您想接入的编码能力，进行相应的代码开发。|
|3|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/pre-release-check-0000001064620655)|华为提供对应用自动检查的能力。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/app-release-0000001070941446)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
