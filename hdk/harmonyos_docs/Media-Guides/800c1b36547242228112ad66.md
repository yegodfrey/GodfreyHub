# HDR能力配置

HDR能力接口类[HdrAbility](https://developer.huawei.com/consumer/cn/doc/Media-References/hdr-ability-class-0000001274843210)，可用于对HDR Vivid视频进行渲染转码处理过程中，进行亮度调节。  

#### 开发步骤

1. 初始化亮度调节功能。

   ```
   HdrAbility.init(getApplicationContext());
   ```

2. 打开设备的HDR能力，屏幕的峰值亮度会增加。

   ```
   HdrAbility.setHdrAbility(true);
   ```

3. 设置输出视频图像数据的白点的备选的最大峰值亮度。

   ```
   HdrAbility.setBrightness(600);
   ```

4. 打开视频图层高亮显示能力。

   ```
   HdrAbility.setHdrLayer(surfaceView, true);
   ```

5. 设置字幕/弹幕图层高亮显示能力。

   ```
   HdrAbility.setCaptionsLayer(captionView, 1.5f);
   ```
