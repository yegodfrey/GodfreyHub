#### 从KMS查询内容密钥信息

KMS支持通过KeyID、ContentID、PSSH Box和drmtype查询keyInfo。

该接口实现的主要步骤如下：

1. 基于SpringMVC定义一个queryKeyInfo接口，其中接口定义参考KMS接口规范样例。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.42023581345398983506122185878217:50001231000000:2800:5E7F0BF163E2A0DBEF6522EA67F751A6BA83CEB64EB603E7C49D77DE18C51B2D.png)  
   KMS接口规范样例请登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"我的项目 \> 构建 \> 数字版权管理服务 \> KMS API"。详情参见[开通数字版权管理服务](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050039992#section14208174317153)。

   ```
    @RequestMapping(value = "/queryKeyInfo")
    @ResponseBody
    public BaseRsp queryKeyInfo(@RequestBody QueryKeyInfoReq request) {
        return queryKeyInfoService.service(request);
    }
   ```

   <br />

2. 根据KeyID、ContentID或者PSSH Box查询存储在数据库中的内容加密密钥信息。

   <br />

   ```
   public QueryKeyInfoRsp doService(QueryKeyInfoReq req) throws KMSException {
       LOG.info("Start to query key info");    
       QueryKeyInfoRsp rsp = new QueryKeyInfoRsp();    
       rsp.setRetCode(KMSResultCode.SUCCESS);
       // queryKeyInfo by KeyID/ContentID/PSSH Box
       if (StringUtils.isNotBlank(req.getKeyId())) {        
           queryKeyInfoByKeyId(req.getKeyId(), rsp);    
       } else if (StringUtils.isNotBlank(req.getContentId())) {        
           queryKeyInfoByContentId(req.getContentId(), rsp);    
       } else if (StringUtils.isNotBlank(req.getPsshBox())) {        
           queryKeyInfoByPsshData(req.getPsshBox(), rsp);    
       }
       LOG.info("End to query key info");
       return rsp;
   }
   ```

   <br />

3. 给外部返回内容加密密钥信息和内容信息。

样例代码中仅实现了查询所属的所有的内容密钥信息，如果需要进行分页查询或者精确查询，需要进一步开发完善代码。  

#### MultiDRM路由分发

* MultiDRM路由能力 MultiDRM路由能力是SP视频运营平台针对不同终端所支持的DRM能力，路由到不同的DRM服务器获取License，从而使终端的DRM能顺利解析License以便播放DRM加密片源。服务端根据终端发送的getLicense请求中内容支持的DRM加密类型，向终端返回对应的License申请URL地址，终端根据服务端返回的申请License的URL地址和本身的DRM能力，选择合适的申请License的URL地址，然后使用该URL地址申请License。

  MultiDRM的路由能力主要为了满足SP视频运营平台能同时对接多种DRM服务器，从而可以在DRM能力互斥的多种终端上都能正常播放DRM加密影片。路由是指在获取License的过程中的路由，路由到不同的DRM服务器。
* MultiDRM路由实现原理 MultiDRM路由是MultiDRM Router根据请求终端的信息和内容本身的加密类型（ChinaDRM2.0或Other DRM）构造不同的申请License的URL地址返回给终端来实现的。主要流程如下（下图中终端和SP视频运营平台的交互流程仅供参考，SP也可以自行决定实现逻辑，最终目的是根据终端采用的DRM类型来决定路由到哪一个DRM Server）：

  <br />

  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.29666985698823012494513673011010:50001231000000:2800:68284B5FDE60194F80169739BC508E3DBC1088987DF71319ACB9B1AD59A88A07.png)

  在一个内容支持多种DRM加密类型时，MultiDRM Router模块可以同时返回多个申请License的URL地址，然后终端根据自身的DRM能力来选择使用哪个URL地址来申请License。也可以由终端主动上报支持的DRM能力，让MultiDRM Router根据终端上报的参数（DRM类型）自动选择一个License申请地址返回给终端。MultiDRM Router自动根据DRM类型路由的流程如下：

  <br />

* 开发MultiDRM路由能力 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.77985990073489317153198400963877:50001231000000:2800:AE2934FB7847B1393E8B9ED03E9D5ADDB07779418CF9DA9CE18441BC6B762ADD.png)

主要流程说明如下：

1. 视频App请求视频运营平台播放指定的视频。
2. 视频运营平台根据请求方支持的DRM类型返回播放URL地址以及getLicense的URL地址，getLicense的URL地址为对接Other DRM License Server的地址。
3. 视频App根据视频运营平台返回的URL地址获取License。
4. 视频运营平台的MultiDRM Router将License请求路由到Other DRM License Server获取License。
5. 视频App请求视频运营平台播放指定的视频。
6. 视频运营平台根据请求方支持的DRM类型返回播放URL地址以及getLicense的URL地址，getLicense的URL地址为对接WisePlay DRM License Server的地址。
7. 视频App根据视频运营平台返回的URL地址获取License。
8. 视频运营平台的MultiDRM Router将License请求路由到WisePlay DRM License Server获取License。  

#### 从DRM Server获取License

#### 对接Other DRM License Server申请License

MultiDRM Router模块提供接口https://domain/multidrm/otherdrm/getLicense接口，用于终端获取Other DRM License Server的License。对于原有支持Other DRM的系统，该功能应该原本就支持。其执行流程如下：

1. 支持Other DRM能力的终端播放加密影片，获取License的URL地址。
2. 视频运营平台指向MultiDRM Router的域名服务，并返回License的URL地址为https://domain/multidrm/otherdrm/getLicense。
3. 视频App使用返回的License的URL地址（https://domain/multidrm/otherdrm/getLicense）来获取License。
4. MultiDRM Router根据输入URL，构造调用Other DRM License Server的请求对象，请求Other DRM License Server获取License。  

#### 对接WisePlay DRM License Server申请License

MultiDRM Router对接WisePlay DRM License Server申请License，WisePlay DRM提供内容License获取接口getLicense。主要流程如下：

1. 支持ChinaDRM 2.0能力的终端播放加密影片，获取License的URL地址。
2. 视频运营平台指向MultiDRM Router的域名服务，并返回License的URL地址为https://domain/multidrm/chinadrm/getLicense。
3. 视频App使用返回的License的URL地址（https://domain/multidrm/chinadrm/getLicense）来获取License。
4. MultiDRM Router根据输入的URL地址，构造调用WisePlay DRM License Server的请求对象，发送请求消息给WisePlay DRM License Server。
