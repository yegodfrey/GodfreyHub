# 音频队列管理

音频队列管理类[HwAudioQueueManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioqueuemanager-0000001050431731)，可用于管理播放列表，包括保存列表、删除列表、增加列表的音频内容等。

```
// 获取当前音频在列表中的位置。
return mHwAudioQueueManager.getCurrentIndex();
// 获取当前音频对象。
return mHwAudioQueueManager.getCurrentPlayItem();
// 删除列表中指定位置的音频。
mHwAudioQueueManager.removeListByIndex(pos);
// 删除列表中指定的音频。
mHwAudioQueueManager.removeListByItem(HwAudioPlayItem item);
// 设置播放列表。
mHwAudioQueueManager.setPlaylist(java.util.List playlist);
// 获取播放列表。
return mHwAudioQueueManager.getAllPlaylist();
// 在播放列表指定位置添加音频。
mHwAudioQueueManager.addPlayItem(HwAudioPlayItem item, int position);
// 在播放列表指定位置添加播放列表。
mHwAudioQueueManager.addPlayItemList(java.util.List itemList, int position);
//判断当前播放队列是否为空。
return mHwAudioQueueManager.isQueueEmpty();
```
