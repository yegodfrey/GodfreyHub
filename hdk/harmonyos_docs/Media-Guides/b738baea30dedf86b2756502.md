# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 视频编辑服务的多种集成方式如何选择？

视频编辑服务提供多种集成方式：

* 视频编辑UI SDK：包含产品级的UI界面，只需要集成少量的接口使用，适合快速集成，定制化程度不高的场景。
* 视频编辑原子能力SDK：不包含UI界面，提供底层API，适合需要定制化UI界面的场景。
* AI能力SDK：提供多种AI算法能力，适用于只需要依赖对应AI功能的场景。
* 屏幕录制SDK：提供屏幕录制的能力，适用于需要快速、简单集成屏幕录制的场景。  

#### 视频编辑服务调用异常怎么办？

1. 查看对应的"错误码"信息。
2. 检查您使用的软、硬件是否满足要求，如Android版本等。
3. 检查是否开启了所需的权限，如使用录音功能时需要开启录音权限。
4. 检查您的网络状态，视频编辑服务部分能力对网络有依赖，请检查您的设备是否可以正常连接网络。
5. 如未解决，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，华为支持人员会及时处理。  

#### 一个License ID一天可以注册几次？

单个License ID每日只能注册三次。如已注册成功，设备卸载App并重新安装，将消耗一次注册机会，当三次机会消耗完后，只能等到24:00以后才能重新注册。  

#### 配额消耗的规则？

License ID每发生一次变更，就会消耗一个配额。License ID是进行管控的有效凭证，您要保证设置License ID的唯一性，否则可能导致占用多个配额，甚至鉴权失败。  
调用者可能要考虑以下场景：

* License ID建议使用不涉及个人数据的唯一ID。
* 同一用户在不同终端登录的场景。  

#### 视频编辑服务的视频编辑UI SDK支持哪些回调接口？

视频编辑服务支持导出成功、导出失败回调接口。  

#### UI SDK使用SDK28打包为什么会报错？

UI SDK当前只支持主流的SDK29、SDK30和SDK31版本。  

#### 原子能力SDK Demo下载后直接打包运行为什么访问不了网络素材？

Demo中没有配置API Key和AGC文件，请按照开发准备中的[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001101108580)和[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347)两个步骤配置。  

#### 编译失败后报"Missing 'package' key attribute on element package at \[XXX\] AndroidManifest.xml"错误？

请确保使用com.android.tools.build:gradle:3.4.3及以上版本。  

#### 如何正确的操作泳道中的某个资源，比如设置资源的size或position属性？

在操作泳道中的某个资源的时候，需要先调用[seekTimeLine](https://developer.huawei.com/consumer/cn/doc/Media-References/huaweivideoeditor-0000001157249152#section1465893813420)方法将时间线定位到这个资源的时间线内，触发资源上线，即选中此资源，才能对这个资源进行操作。

```
// 在视频泳道的末尾，添加视频资源
HVEVisibleAsset videoAsset = mVideoLane.appendVideoAsset(sourceFile.getAbsolutePath());
// 调用seekTimeLine接口触发资源上线
// 参数1：指定的时间点（单位：ms），可以是要操作的资源的开始时间或是这个资源时间点以内的时间，此处传入的是videoAsset资源的开始时间点。
// 参数2：seek完成的回调，可以对资源进行操作        
mEditor.seekTimeLine(videoAsset.getStartTime(),newHuaweiVideoEditor.SeekCallback(){
    @Override
    publicvoidonSeekFinished(){
        // 定位到videoAsset资源后，对videoAsset资源进行操作，如果涉及UI操作需要将线程切换到主线程。
    }
});
```
