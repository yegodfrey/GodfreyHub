# 游戏直播特性

使用游戏直播特性需要注意：

1、此特性最早兼容到EMUI 11.0.1。

2、必须在华为开发者网站申请签名授权。

请参阅：[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-create_app)  

#### 开发指导

1、开始录制前，需要初始化HwAudioKit。

在onCreate进行初始化即可（也可以自行决定初始化时机）

```
mHwAudioKit = new HwAudioKit(this, this);
mHwAudioKit.initialize();
```

在onDestroy进行销毁（也可以自行决定销毁的时机）

```
if (mHwAudioKit != null) {
    mHwAudioKit.destroy();
}
```

2、开始录制前（创建MediaProjection对象之前），必须调用HwAudioKit.requestVoiceRecording(Context context)申请录制。（此过程会鉴定应用是否有签名授权，若鉴定失败，则不允许应用进行录音双开与游戏VOIP下行音录制）

```
if (mHwAudioKit != null) {
    if (!mHwAudioKit.requestVoiceRecording(this)) {
        Log.e(TAG, "requestVoiceRecording failed");return;    
    }
}
```

同样的，在结束录制后，必须HwAudioKit.releaseVoiceRecording(Context context)取消录制申请。

```
if (mHwAudioKit != null) {
    mHwAudioKit.releaseVoiceRecording(this);
}
```

3、申请录制后，直播应用可以使用AudioRecord或MediaRecord进行MIC音录制，必须使用MediaProjection来进行屏幕录制，必须使用AudioPlaybackCaptureConfiguration的方式进行系统音录制。

4、构建AudioPlaybackCaptureConfiguration时，需要传入一个MediaProjection对象，这也是必须使用MediaProjection进行屏幕录制的原因之一。

5、为AudioPlaybackCaptureConfiguration设置参数，可以通过addMatchingUsage实现。安卓原生支持三种类型：USAGE_GAME，USAGE_UNKNOWN，USAGE_MEDIA。华为扩展一种类型：USAGE_VOICE_COMMUNICATION，但是通话类型的音频数据仅在游戏场景下才能够实现录制，且仅能录制游戏中的小队语音数据，其他场景下无法进行录制。
