# 版本更新说明

## 1.9.0.300（2022-12-27）

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|本次REST特性变更如下： **新增特性** * AI配音新增中文方言（河南男声、台湾女声、陕西女声），请参见[AI配音发音人说明](https://developer.huawei.com/consumer/cn/doc/Media-References/rest_api_public_description-0000001317085953#section1317103515473)。试听请前往[AI配音样例试听](https://developer.huawei.com/consumer/cn/doc/Media-Guides/synthesis_timbre_audition-0000001336283673#section19502121612912)。 * 歌声合成区分推荐歌词样式与最大歌词样式，请参见[歌声合成预置曲目说明](https://developer.huawei.com/consumer/cn/doc/Media-References/rest_api_public_description-0000001317085953#section457618201567)，智能填词规则也对应有修改，请参见[歌声合成填词规则说明](https://developer.huawei.com/consumer/cn/doc/Media-References/rest_api_public_description-0000001317085953#section57848524154)。|
