# 蓝牙耳机高级特性

华为部分蓝牙耳机支持全带录音以及K歌耳返特性。蓝牙全带录音是指通过蓝牙耳机录制48k采样率的高音质声音，可以高保真的保存声音的高频信息让音质更自然。蓝牙耳机K歌耳返特性是针对蓝牙耳机实现的K歌耳返特性，可以让蓝牙耳机体验有线耳机类似的K歌耳返特性。如果想采用这些功能，三方要做部分适配。一般流程如下：

1. 识别蓝牙耳机的连接并获取其高级特性信息。
2. 查询当前连接蓝牙耳机是否支持全带录音。
3. 使用全带录音的接口进行录音。
4. 查询当前连接蓝牙耳机是否支持K歌耳返。
5. 使用K歌耳返的接口进行耳返功能的配置。

#### 识别蓝牙耳机的连接并获取其高级特性

1、使用如下接口判断蓝牙耳机的连接：

```
public void registerAudioDeviceCallback(AudioDeviceCallback callback, Handler handler)
```

请参阅：[registerAudioDeviceCallback](https://developer.android.com/reference/android/media/AudioManager#registerAudioDeviceCallback(android.media.AudioDeviceCallback, android.os.Handler))

2、获取该蓝牙设备相关的高级特性

```
//@return 该设备相关的EnhancedDeviceInfo，用于设备相关的信息查询。如果该设备不支持高级特性则返回null。
EnhancedDeviceInfo mEnhancedDeviceInfo = mHwAudioKit.getEnhancedDeviceInfo(info.getType());
```

参考代码：

```
mAudioManager.registerAudioDeviceCallback(new AudioDeviceCallback() {
    @Override
    public void onAudioDevicesAdded(AudioDeviceInfo[] addedDevices) {
        for (AudioDeviceInfo info : addedDevices) {
            Log.d(TAG, "onAudioDevicesAdded: " + info.getType());
            if (mHwAudioKit != null) {
                int deviceType = info.getType();
                if (deviceType == AudioDeviceInfo.TYPE_BLUETOOTH_A2DP) {
                    try {mEnhancedDeviceInfo = mHwAudioKit.getEnhancedDeviceInfo(info.getType());
                        Log.d(TAG,"enhancedDeviceInfo：" + mEnhancedDeviceInfo.toString());
                    } catch (UnsupportedVersionException e) {
                        e.printStackTrace();
                    }
                }
            } else {
               mInfoTextView.setText(R.string.isInit);
            }
        }
    }
    @Override
    public void onAudioDevicesRemoved(AudioDeviceInfo[] removedDevices) {
    }
}, null);
```

#### 查询当前连接蓝牙耳机是否支持全带录音

```
//返回值：@return true表示支持全带录音，false表示不支持。
boolean ret = mEnhancedDeviceInfo. isFullbandRecordSupported ();
```

#### 使用全带录音的接口进行录音

三方使用Android原生的接口即可使用蓝牙全带录音：可以使用OpenSL进行录音，也可以使用AudioRecord、MediaRecord等接口进行录音。但需要注意的是：应用不能建立SCO（部分应用为了确保使用蓝牙耳机录音而建立了SCO），且使用的source为MediaRecorder.AudioSource.MIC（录音用）或MediaRecorder.AudioSource. CAMCORDER（录像用）。  

#### 查询当前连接蓝牙耳机是否支持K歌耳返

```
//返回值：@return true表示支持K歌耳返，false表示不支持。
boolean ret = mEnhancedDeviceInfo. isKaraokeSupported ();
```

#### 使用K歌耳返的接口进行耳返功能的配置

K歌耳返的接口与有线耳机相同，见[应用开发](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/k-pop_feature-0000001126854126)。  

#### 备注

1、 蓝牙耳机全带录音或者耳返可以使用AudioRecord、MediaRecord或者OpenSL录音；

2、 蓝牙耳机不会保存K歌的参数状态，当应用识别到蓝牙耳机接入或者断开的时候（比如在使用有线耳机K歌的过程中接入蓝牙耳机），请重新下发K歌的参数并打开耳返；
