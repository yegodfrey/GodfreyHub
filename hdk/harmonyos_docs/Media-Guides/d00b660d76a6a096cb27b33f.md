# K歌特性

## 流程概述

Audio Engine开发的基本方法是，首先创建基础AudioKit对象，通过该对象查询当前手机支持的各种具体能力；当查询到希望使用的能力时，再创建具体的开放能力进行开发。比如，当查询到支持K歌耳返能力时，创建具体K歌接口实例，然后使用该实例进行K歌使能、设置等功能开发；当不使用时，则释放该对象。

## 开发中注意事项

因为考虑到一些异常场景，需要开发者在使用时做一些场景限定：

* 录音之前先创建HwAudioKaraokeFeatureKit对象，在HwAudioKaraokeFeatureKit中会根据录音包名做音效优化。
* 调用者在使用耳返时，确保每次进入都要重新初始化，并设置对应的音量等参数，一般情况下，应用可以自己记录状态，以确保和其他应用不冲突。
* 调用者在处理后台等场景时，尽可能保证耳返处于关闭状态，以减少对其他应用的影响。
* 目前为了使用耳返时不影响其他应用，在使用Engine的应用退出到后台的时候，系统对耳返进行了强制关闭，使用Engine的应用再次回到界面之后要重新设置自己保存的状态。
* [getSupportedFeatures](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiokit-0000001063080095#ZH-CN_TOPIC_0000001063080095__getSupportedFeatures--)()接口与[isFeatureSupported](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiokit-0000001063080095#ZH-CN_TOPIC_0000001063080095__isFeatureSupported-com_huawei_multimedia_audiokit_interfaces_HwAudioKit_FeatureType-)(FeatureType type)接口必须等HwAudioKit调用[initialize](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiokit-0000001063080095#ZH-CN_TOPIC_0000001063080095__initialize--)()在[IAudioKitCabllback](https://developer.huawei.com/consumer/cn/doc/development/Media-References/iaudiokitcallback-0000001062922187)的onResult中返回ResultCode.AUDIO_KIT_SUCCESS方可使用。
* 只有完成对象创建在[IAudioKitCabllback](https://developer.huawei.com/consumer/cn/doc/development/Media-References/iaudiokitcallback-0000001062922187)的onResult中返回对应的值之后才能使用子功能的接口，如：K歌能力必须在调用HwAudioKit的[createFeature](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudiokit-0000001063080095#ZH-CN_TOPIC_0000001063080095__createFeature-com_huawei_multimedia_audiokit_interfaces_HwAudioKit_FeatureType-)(FeatureTypetype)创建对象，同时在[IAudioKitCabllback](https://developer.huawei.com/consumer/cn/doc/development/Media-References/iaudiokitcallback-0000001062922187)的onResult中返回ResultCode.KARAOKE_SUCCESS才可使用其接口。
* 重启手机第一次获取时延信息，必须先打开耳返再录音，然后调用获取时延信息的接口。
* 使用耳返的时候，需要有下行流。一般播放伴奏音即可满足需求，如果是清唱场景则需要应用播放一个静音流；
* 目前仅有线耳机以及特定型号的蓝牙耳机支持K歌耳返命令，当应用识别到设备切换的时候（有线耳机或者蓝牙耳机接入），需要重新设置对应的K歌参数，比如人声音量、混响级别、K歌状态的使能或关闭等；

## 开发步骤

### 创建录音

应用在使用K歌耳返能力开发时，一般需要应用创建自己的录音通道，然后创建华为的K歌耳返能力接口进行耳返的开发。当应用创建录音时，为了达到更好的耳返效果，建议使用低时延通路的录音进行开发。在Android上进行低时延录音开发，有多种方式，使用OpenSLES开发是一种比较常用的方式，且便于平台的移植。使用OpenSLES进行录音一般用到如下几个步骤：

1. 引用OpenSLES用到的头文件。

   ```screen
   // for native audio 
   #include<SLES/OpenSLES.h> 
   #include<SLES/OpenSLES_Android.h>
   ```

2. slCreateEngine创建实现Engine对象。

   ```screen
   SLresult result;
   SLObjectItf g_engineObject =NULL;
   SLEngineItf g_engineEngine; 
   result = slCreateEngine(&g_engineObject,0,NULL,0,NULL,NULL);
   result = (*g_engineObject)->Realize(g_engineObject,SL_BOOLEAN_FALSE); 
   result = (*g_engineObject)->GetInterface(g_engineObject,SL_IID_ENGINE,&g_engineEngine);
   ```

3. 然后基于Engine对象创建具体的Recorder对象，需要先配置audio source以及audio sink，然后进行实例化。

   ```screen
   // configure audio source 
   SLDataLocator_IODevice loc_dev = {SL_DATALOCATOR_IODEVICE,SL_IODEVICE_AUDIOINPUT,SL_DEFAULTDEVICEID_AUDIOINPUT,NULL};
   SLDataSource audioSrc = {&loc_dev,NULL};
   // configure audio sink 
   SLDataLocator_AndroidSimpleBufferQueue loc_bq = {SL_DATALOCATOR_ANDROIDSIMPLEBUFFERQUEUE,2}; 
   SLDataFormat_PCM format_pcm = {SL_DATAFORMAT_PCM,1,SL_SAMPLINGRATE_48,SL_PCMSAMPLEFORMAT_FIXED_16,SL_PCMSAMPLEFORMAT_FIXED_16,SL_SPEAKER_FRONT_CENTER,SL_BYTEORDER_LITTLEENDIAN};
   SLDataSink audioSnk = {&loc_bq,&format_pcm};
   // create audio recorder(requires the RECORD_AUDIO permission) 
   const SLInterfaceID id[1] = {SL_IID_ANDROIDSIMPLEBUFFERQUEUE}; 
   const SLboolean req[1] = {SL_BOOLEAN_TRUE}; 
   SLObjectItf recorderObject = NULL;
   result = (*engineEngine)->CreateAudioRecorder(engineEngine,&recorderObject,&audioSrc,&audioSnk,1,id,req);
   // realize the audio recorder 
   result = (*recorderObject)->Realize(recorderObject,SL_BOOLEAN_FALSE);
   ```

4. 可以进行callback注册，后续在callback中处理数据。

   ```screen
   SLAndroidSimpleBufferQueueItf recorderBufferQueue;
   // get the buffer queue interface 
   result = (*recorderObject)->GetInterface(recorderObject,SL_IID_ANDROIDSIMPLEBUFFERQUEUE, &recorderBufferQueue);
   // register callback on the buffer queue 
   result = (*recorderBufferQueue)->RegisterCallback(recorderBufferQueue,bqRecorderCallback,NULL);
   // this callback handler is called every time a buffer finishes recording 
   void bqRecorderCallback(SLAndroidSimpleBufferQueueItfbq, void*context) { 
   // enqueue an empty buffer to be filled by the recorder 
   result = (*recorderBufferQueue)->Enqueue(recorderBufferQueue,recorderBuffer,RECORDER_FRAMES*sizeof(short)); }
   ```

5. 启动录制。

   ```screen
   // enqueue an empty buffer to be filled by the recorder 
   result = (*recorderBufferQueue)->Enqueue(recorderBufferQueue,recorderBuffer,RECORDER_FRAMES*sizeof(short));
   // start recording 
   result = (*recorderRecord)->SetRecordState(recorderRecord,SL_RECORDSTATE_RECORDING);
   ```

6. 停止录制。

   ```screen
   // stop recording 
   result = (*recorderRecord)->SetRecordState(recorderRecord,SL_RECORDSTATE_STOPPED);  
   // clear buffer queue 
   result = (*recorderBufferQueue)->Clear(recorderBufferQueue);
   ```

   更多OpenSLES低延时开发方法请参见：[使用入门](https://developer.android.com/ndk/guides/audio/opensl/getting-started)。

### 能力创建

1. 导入需要的包。

   ```screen
   import com.huawei.multimedia.audiokit.config.ResultCode; 
   import com.huawei.multimedia.audiokit.interfaces.HwAudioKaraokeFeatureKit; 
   import com.huawei.multimedia.audiokit.interfaces.HwAudioKit; 
   import com.huawei.multimedia.audiokit.interfaces.IAudioKitCallback; 
   import com.huawei.multimedia.audiokit.utils.Constant;
   ```

2. 初始化HwAudioKit对象和HwKaraokeFeature对象。

   ```screen
   HwAudioKit mHwAudioKit; 
   HwAudioKaraokeFeatureKit mHwAudioKaraokeFeatureKit; 
   mHwAudioKit = new HwAudioKit(this, callBack); 
   mHwAudioKit.initialize(); 
   mHwAudioKaraokeFeatureKit = mHwAudioKit.createFeature(HwAudioKit.FeatureType.HWAUDIO_FEATURE_KARAOKE);
   ```

3. 实现callback。

   ```screen
   IAudioKitCabllback callBack = newe IAudioKitCallback() {
     public void onResult(intresultType) {
       switch(resultType) {
         case ResultCode.AUDIO_KIT_SUCCESS:        
   // HwAudioKit初始化成功，可以做一些查询，如：        
         mHwAudioKit.getSupportedFeatures();        
        break;      
        case ResultCode.KARAOKE_SUCCESS:        
   // HwAudioKaraokeFeatureKit初始化成功，使用Karaoke的一些接口，如：        
        int result =mHwAudioKaraokeFeatureKit.enableKaraokeFeature(enable);
        break;      
        case ResultCode.VENDOR_NOT_SUPPORTED:        
   //未安装Engine服务，不支持kit       
        break;     
        default:        
        break;     
     }
    } 
   }
   ```

### 打开耳返

打开或关闭耳返。

```screen
//enable为true：代表打开耳返。false：代表关闭耳返。返回int数值：0：表示成功。1806：表示产品不支持K歌。1805：表示未插耳机。
int result = mHwAudioKaraokeFeatureKit.enableKaraokeFeature(enable);
```

### 设置混响模式

```screen
//返回值：0：表示成功。1806：表示产品不支持K歌。1805：表示未插耳机。
int success = mHwAudioKaraokeFeatureKit.setParameter(HwAudioKaraokeFeatureKit.ParameName.CMD_SET_AUDIO_EFFECT_MODE_BASE,value);
```

### 设置声音音量

```screen
//返回值：0：表示成功。1806：表示产品不支持K歌。1805：表示未插耳机。
int success = mHwAudioKaraokeFeatureKit.setParameter(HwAudioKaraokeFeatureKit.ParameName.CMD_SET_VOCAL_VOLUME_BASE,value);
```

### 设置均衡器模式

```screen
//返回值：0：表示成功。1806：表示产品不支持K歌。1805：表示未插耳机。

```
