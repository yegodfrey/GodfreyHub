# 音频配置管理

音频配置管理类[HwAudioConfigManager](https://developer.huawei.com/consumer/cn/doc/development/Media-References/hwaudioconfigmanager-0000001050191649)，可用于缓冲区管理、通知栏设置和播放队列保存设置。

```
int SIZE_M = 1024 * 1024;
// 设置缓冲区大小。
mHwAudioConfigManager.setPlayCacheSize(size * SIZE_M);
// 获取缓冲区大小
mHwAudioConfigManager.getPlayCacheSize() / SIZE_M;
// 获取已使用缓冲区大小
mHwAudioConfigManager.getUsedCacheSize() / SIZE_M;
// 清除播放缓存，释放缓存空间。
mHwAudioConfigManager.clearPlayCache();
// 设置通知工厂，用于传入通知栏样式信息，例如当前歌曲的歌曲名、歌手名、图片等。
mHwAudioConfigManager.setNotificationFactory(
    new SubINotificationFactory((Application) context.getApplicationContext(), mHwAudioManager));
// 是否保存播放队列，默认不保存。
mHwAudioConfigManager.setSaveQueue(true);
// 停止缓冲。
mHwAudioConfigManager.stopDownload();
// 继续缓冲。
mHwAudioConfigManager.continueToDownloadIfNeed();
```
