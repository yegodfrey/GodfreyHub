# 业务介绍

#### 业务简介

华为视频能力（Video Engine）包含电影级调色和高级视频编码两个部分。电影级调色可以为您的应用提供显示色彩调节能力，高级视频编码助力您快速构建视频编码的高级特性，帮助您向用户提供高清、低码、流畅的视频媒体体验。  

#### 支持的设备

|特性|设备类型|OS版本|
|:-----|:--------------------------------|:-----------|
|电影级调色|基于Kirin芯片（Kirin 990及以上）的华为手机、华为平板|EMUI 11.0及以上|
|高级视频编码|基于Kirin芯片（Kirin 980及以上）的华为手机、华为平板|EMUI 11.0及以上|
