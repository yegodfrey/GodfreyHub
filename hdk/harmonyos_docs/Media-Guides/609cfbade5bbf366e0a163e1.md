# 简介

## 特效概述

图像服务（Image Kit）通过解析资源中的描述脚本文件，生成一个丰富多彩符合您预期的画面，展示在屏幕中，使图片变得生动有趣。

## 描述文件

* 描述文件概述 图像服务（Image Kit）的描述文件命名为manifest.xml，其内容需要包括在<Root></Root>标签中。

* xml规范

  ```screen
  ​<Root screenWidth=""> 
  </Root>
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:----------|:-|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |screenWidth|数值|M|描述文件的虚拟的屏幕宽度，根据该宽度和手机屏幕的宽高比能够计算出相应的虚拟的屏幕的高度。描述文件中的数值基于该虚拟的屏幕的宽高比，例如分辨率为1560*720的手机在设置screenWidth为1080的描述文件中，其#screen_width为1080，#screen_height为1920，能够保持在同一个屏幕宽高比例的手机中组件的相对位置保持不变。设定屏幕宽度标准。如果指定为720，视图中所有元素的位置都按720p的布局编写，1080p、480p等分辨率的手机会自动进行缩放。|
