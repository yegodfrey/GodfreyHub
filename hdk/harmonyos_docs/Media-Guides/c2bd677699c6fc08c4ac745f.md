# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://github.com/huaweicodelabs/AudioEditorKit)快速体验一个应用的开发过程。  

#### 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上
* 安装[Android Studio](https://developer.android.com/studio) 3.X及以上

  * minSdkVersion 24及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 4.6及以上（推荐）

<!-- -->

* 测试应用的设备：EMUI 5.0 \~ 11或HarmonyOS 2.0及以上的华为手机或Android 7.0 \~ 13的非华为手机

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001154009063)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001154009063#section26591429423)、[创建应用](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001154009063#section151717316429)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001154009063#section7627236426)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001154009063#section1435661425)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001154009063#section382112213818)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001154289127)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-obfuscation-scripts-0000001208592833)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/Media-Guides/add-permissions-0000001154228175)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[音频编辑UI SDK集成](https://developer.huawei.com/consumer/cn/doc/Media-Guides/client-dev-0000001107465102)|您可根据业务需求，完成音频编辑的产品级UI开发。|
|5|[音频编辑原子能力SDK集成](https://developer.huawei.com/consumer/cn/doc/Media-Guides/prerequisites-0000001179123512)|音频编辑的原子能力功能包括[基础功能](https://developer.huawei.com/consumer/cn/doc/Media-Guides/basic_functions-0000001224604517)和[特色功能](https://developer.huawei.com/consumer/cn/doc/Media-Guides/featured_functions-0000001178963356)集成。|
|5|[音频编辑AI配音SDK集成](https://developer.huawei.com/consumer/cn/doc/Media-Guides/aidubbing-sdk-0000001199997744)|音频编辑的AI配音能力的集成，您可根据个人需求进行不同音色的配置。|
|6|[开发后自检](https://developer.huawei.com/consumer/cn/doc/Media-Guides/pre-release-check-0000001154228781)|华为提供对应用自动检查的能力。|
|7|[上架申请](https://developer.huawei.com/consumer/cn/doc/Media-Guides/app-release-0000001655238457)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|
