# 流程介绍

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110906.41383617334613385211154296787285:50001231000000:2800:1BD0A0F6DD9320EFCA7EABC0A78DBA5BB08C1F63D1B192CCEC49235FD38D7F8B.png)

1. 视频App从CDN源站获取加密视频的索引和分片信息，根据当前加密影片的DRM类型是否为WisePlay DRM，并通过MediaDrm.isCryptoSchemeSupported判断当前终端支持的DRM类型。
2. 视频App确定如果终端支持WisePlay DRM，则调用new MediaDRM(UUID)初始化DRM接口。
3. 视频App调用MediaDrm.openSession()创建会话。
4. 视频App调用payload=MediaDrm.KeyRequest(sessionID,PSSH Box,keyType)获取License请求。
5. 视频App将payload请求和PSSH Box传递给视频运营平台。
6. 视频运营平台根据PSSH Box从KMS中获取内容解密的密钥信息。
7. 视频运营平台按照WisePlay DRM Server的获取License请求的格式要求，将payload参数、keyinfo信息发送到WisePlay DRM Server请求License；WisePlay DRM Server会对请求消息鉴权，并生成对应的License返回给视频运营平台，视频运营平台再返回给端侧。
8. 视频App收到License响应后，调用MediaDrm.provideKeyResponse(License)导入License信息。
9. 视频App调用MediaCrypto(uuid,sessionID)初始化视频解码接口。
10. 视频App循环调用Decrypt(subsample)导入加密视频分片文件，进行视频解密播放。
11. 视频播放完毕后，视频App调用MediaDrm.closeSession()关闭会话。
