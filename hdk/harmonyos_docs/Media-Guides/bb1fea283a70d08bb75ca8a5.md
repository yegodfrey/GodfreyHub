# 视频合并

支持用户选择一个ADM音频或MP4(AV3A)音频，和一个MP4视频进行合并导出，用户需要输入合并后的文件，并选择文件输出路径。

## 通道压缩

通道压缩选项可选10、12、14默认12。
> 说明
>
> * 添加的音频为MP4(AV3A)格式时，默认使用音频文件的参数；添加的音频为ADM格式时，需要设置通道压缩和码率参数。
> * 音频和视频仅可以添加一个文件，再次添加则覆盖上一次文件。

## 码率

码率根据选择不同的渲染模式而变化，具体变化见表格，单位：kbps*。*

|渲染模式|描述|
|:-----|:-------------------------------------------|
|立体声＆双耳|128kbps、144kbps、192kbps、256kbps、++320kbps++。|
|5.1|384kbps、448kbps、512kbps、++640kbps++。|
|7.1|256kbps、384kbps、480kbps、++576kbps++、640kbps。|
|5.1.2|152kbps、320kbps、480kbps、++576kbps++。|
|5.1.4|256kbps、384kbps、448kbps、++576kbps++、704kbps。|
|7.1.2|216kbps、384kbps、480kbps、++576kbps++、768kbps。|
|7.1.4|240kbps、384kbps、512kbps、++608kbps++、832kbps。|
