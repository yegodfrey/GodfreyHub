# 版本更新说明

#### 6.0.0.302（2021-07-15）

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本： 基础组件：com.huawei.hms:avpipelinesdk:6.0.0.302，com.huawei.hms:avpipeline-aidl:6.0.0.302，com.huawei.hms:avpipeline-fallback-base:6.0.0.302 超分插件：com.huawei.hms:avpipeline-fallback-cvfoundry:6.0.0.302 声音事件检测插件：com.huawei.hms:avpipeline-fallback-sounddetect:6.0.0.302 华为推出了全新的多媒体管线服务6.0.0.302版本，此次版本为AV Pipeline Kit首个商用版本，提供了视频播放、视频超分、声音事件检测、资产管理、用户自定义功能，欢迎广大开发者接入使用。|

#### SDK依赖说明

当您的手机安装了HMS Core（APK）5.2.0.300及以上版本时，AV Pipeline Kit将优先调用HMS Core（APK）内的动态加载模块实现更快的框架以及插件加载功能。如果未安装HMS Core（APK）5.2.0.300及以上版本，AV Pipeline Kit将使用内置动态加载模块完成框架及插件的加载功能。

温馨提示：您的应用在华为应用市场上架过程中，如有问题可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
