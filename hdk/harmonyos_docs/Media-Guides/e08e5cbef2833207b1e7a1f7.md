# 2. 通用模式开发步骤

## 2.1 模式创建

在应用启动，预览视图可用时，创建CameraKit模式。

```linenums prettyprint prettyprinted
// 在1.0.1版本中推荐捕获异常，1.0.2以后版本不需要，获取CameraKit实例
if (!isGetInstance) {
    try {
        mCameraKit = CameraKit.getInstance(getApplicationContext());
    } catch (NoSuchMethodError e) {
        Log.w(TAG, "this version camerakit does not contain VersionInfoInterface");
    } finally {
        isGetInstance = true;
    }
}
// 当手机不支持CameraKit或者CameraKit SDK版本与能力层不兼容时返回为空
if (mCameraKit == null) {
    return;
}
// 查询设备的摄像头列表，当前只有后置摄像头支持超级夜景
String[] cameraLists = mCameraKit.getCameraIdList();
// 查询当前摄像头支持模式
int[] modes = mCameraKit.getSupportedModes(cameraLists[0]);
// 创建模式
mCameraKit.createMode(cameraLists[0], mCurrentModeType, mModeStateCallback, mCameraKitHandler);
```

## 2.2 模式配置

应用通过模式特征和业务需求，配置模式的数据和状态监听器、预览Surface、拍照尺寸等参数。

```linenums prettyprint prettyprinted
// 配置预览Surface
modeConfigBuilder.addPreviewSurface(surface);
// 配置拍照参数
modeConfigBuilder.addCaptureImage(mCaptureSize, ImageFormat.JPEG);
// 配置Action数据监听
modeConfigBuilder.setDataCallback(actionDataCallback, mCameraKitHandler);
// 配置Action状态监听
modeConfigBuilder.setStateCallback(actionStateCallback, mCameraKitHandler);
// 配置模式
mMode.configure();
```

## 2.3 模式操作

### 2.3.1 启动模式预览

通过模式状态回调模式配置成功时，启动预览。

```linenums prettyprint prettyprinted
mMode.startPreview();
```

### 2.3.2 设置功能参数

```linenums prettyprint prettyprinted
// 查询模式支持的功能
List<CaptureRequest.Key> parameters = mModeCharacteristics.getSupportedParameters();
// 设置变焦
int zoomSetResult = mMode.setZoom(level);
```

### 2.3.3 调用模式拍照

通过UI点击触发当前模式拍照。

```linenums prettyprint prettyprinted
// 本示例默认竖屏拍摄，简化旋转角度设置逻辑
mMode.setImageRotation(90);
// 本示例默认照片存储路径
mFile = new File(getExternalFilesDir(null), "pic.jpg");
// 触发拍照，拍照结果通过ActionDataCallback.onImageAvailable异步回调
mMode.takePicture();
```

## 2.4 回调操作

### 2.4.1 模式状态回调

负责模式创建状态切换和流程控制。

```linenums prettyprint prettyprinted
private final ModeStateCallback mModeStateCallback = new ModeStateCallback() {
    @Override
    public void onCreated(Mode mode) {
        // 模式创建成功后配置模式
    }
    @Override
    public void onConfigured(Mode mode) {
        // 模式配置成功后启动预览
    }
    // ...
};
```

### 2.4.2 Action数据回调

用于异步处理Action数据。例如，拍照后JPEG的生成通过此回调通知应用。

```linenums prettyprint prettyprinted
private final ActionDataCallback actionDataCallback = new ActionDataCallback() {
    @Override
    public void onImageAvailable(Mode mode, @Type int type, Image image) {
        // 存储照片
    }
};
```

### 2.4.3 Action状态回调

用于异步处理Action状态。例如，预览启动、拍照的开始和结束。

```linenums prettyprint prettyprinted
private final ActionStateCallback actionStateCallback = new ActionStateCallback() {
    @Override
    public void onPreview(Mode mode, int state, PreviewResult result) {
        // 启动预览回调
    }
    @Override
    public void onTakePicture(Mode mode, int state, TakePictureResult result) {
        // 拍照动作回调
    }
};
```

## 2.5 模式释放

应用退出时，释放模式占用的资源。

```linenums prettyprint prettyprinted

```

## 3.2 超级夜景模式开发

mCurrentModeType需要设置成Mode.Type.SUPER_NIGHT_MODE

其他步骤参考：[通用模式参考](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/3180103#h1-2-)。

差异部分：

预览启动后配置感光度及曝光时间调节UI。

```linenums prettyprint prettyprinted
// 查询模式支持的功能
List<CaptureRequest.Key> parameters = mModeCharacteristics.getSupportedParameters();
// 如果支持设置感光度
if ((parameters != null) && (parameters.contains(RequestKey.HW_SUPER_NIGHT_ISO))) {
    // 查询支持感光度范围
    List<Long> values =
        mModeCharacteristics.getParameterRange(RequestKey.HW_SUPER_NIGHT_ISO);
    // 设置第1个感光值
    mMode.setParameter(RequestKey.HW_SUPER_NIGHT_ISO, values.get(0));
}
```

注：设置曝光时间（RequestKey.HW_SUPER_NIGHT_EXPOSURE）的方法与上例类似，如不设置这两个参数，自使用自动的感光度及曝光时长。

拍照完成后需要调用停止拍照接口

曝光开始后，可通过UI点击触发夜景模式停止曝光并拍照。

```linenums prettyprint prettyprinted
mMode.stopPicture();
```

用于异步处理Action状态。例如，预览启动、拍照的开始和结束。

```linenums prettyprint prettyprinted
private final ActionStateCallback actionStateCallback = new ActionStateCallback() {
    @Override
    public void onPreview(Mode mode, int state, PreviewResult result) {
        // 启动预览回调
    }
    @Override
    public void onTakePicture(Mode mode, int state, TakePictureResult result) {
        // 拍照动作回调
        switch (state) {
            case TakePictureResult.State.CAPTURE_STARTED:
                Log.d(TAG, "onState: STATE_CAPTURE_STARTED");
                break;
            case TakePictureResult.State.CAPTURE_EXPOSURE_BEGIN:
                /* 长曝光开始，可通过result获取本次超级夜景拍摄需要的曝光时间
                在收到该回调后，曝光时间计时结束前，允许调用stopPicture提前结束曝光 */
                break;
            case TakePictureResult.State.CAPTURE_EXPOSURE_END:
                // 长曝光结束，当曝光时长计时结束或提前结束曝光后，该状态被回调
                break;
            case TakePictureResult.State.CAPTURE_COMPLETED:
                // 拍照完成
                break;
            default:
                break;
        }
    }
};
```

## 3.6 拍照模式开发

mCurrentModeType需要设置为Mode.Type.NORMAL_MODE。

其他步骤参考：[通用模式参考](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/3180103#h1-2-)，预览启动后可以配置拍照能力。

1、拍照模式支持AI场景识别，下面示例说明：

```linenums prettyprint prettyprinted
// 查询模式是否支持AI能力，如果返回结果为true，则支持AI场景识别
modeCharacteristics. getSupportedSceneDetection();
// 打开AI场景识别功能，打开后也可以通过入参false进行关闭
mMode.setSceneDetection(true);
// 识别场景，并通过回调信息，感知识别到的场景
class ModeActionStateCallback extends ActionStateCallback {
    @Override
    public void onSceneDetection(Mode mode, @SceneDetectionResult.State int state,
        @Nullable SceneDetectionResult result) {
        // 确认要打开对应场景的效果，比如当前已经识别到场景"花卉"
        // 设置场景打开后，会针对花卉进行调参，使得花卉更加艳丽
        mMode.setParameter(RequestKey.HW_SCENE_EFFECT_ENABLE, true);
    }
}
// 关闭场景效果，在场景效果打开的情况下， 设置关闭，则会取消调参
mMode.setParameter(RequestKey.HW_SCENE_EFFECT_ENABLE, false);
```

2、拍照模式支持后置连拍，下面示例说明：

```linenums prettyprint prettyprinted
// 查询是否支持连拍，如果返回结果为true，则支持连拍
modeCharacteristics.isBurstSupported();
// 开始连拍
mMode.takePictureBurst();
// 或者
mMode.takePictureBurst (filename);
// 停止连拍
mMode.stopPicture();
```

## 3.7 超级慢动作模式开发

mCurrentModeType需要设置Mode.Type.SUPER_SLOW_MOTION。

其他步骤参考：[通用模式参考](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/3180103#h1-2-)。

模式配置步骤中，有如下差异，需要以下配置添加：

```linenums prettyprint prettyprinted
// 配置录像帧率
modeConfigBuilder.setVideoFps(recordFps);
// 配置录像分辨率
modeConfigBuilder.addVideoSize(recordSize);
/* */
// 这两个配置项要modeCharacteristics.getSupportedVideoSizes()返回的Map，成对设置。
// 超慢不支持拍照，不应该添加任何拍照相关的配置。
// 超慢要求录像分辨率和预览分辨率保持一致。
// 模式操作有如下差异，使用如下接口：
// 获取运动检测区域范围
modeCharacteristics.getParameterRange(RequestKey.HW_SUPER_SLOW_CHECK_AREA);
返回基于中心坐标系范围。
// 开始录像
mMode.startRecording(file);
// 若需要超慢工作在手动模式，则直接调用mMode.startRecording(file)接口，完成一次录制，中途不可停止，否则录制失败。
// 若需要超慢工作在自动模式,则首先下发一个运动检测框,即：
mMode.setParameter(RequestKey.HW_SUPER_SLOW_CHECK_AREA,rect);
// 检测框须是预览坐标系（预览左上角为顶点）下的一个正方形框转化到中心坐标系下的矩形框，才可下发，若是矩形框有效，则工作在自动模式，正方形框边长确认规则：在支持7680fps的手机上，其边长可取占分辨率较短边的比例[1/3, 1]的范围值，否则只能下发固定值，为分辨率较短边的1/3。
// 矩形框有效，则工作在自动模式，调用mMode.startRecording(file);此时检测到运动物体之前，即在状态回调未返回RecordingResult.State.RECORDING_STARTED状态之前，可调用mMode.stopRecording()停止录制，一旦检测到后，中途不可停止，否则录制失败。
// 调用mMode.stopRecording()接口，会有状态回调RecordingResult.State.RECORDING_STOPPED返回。
// 自动模式下，下发的检测区域无记忆，录制一次后工作模式自动转为手动模式，若是想再进行自动模式录制，则需再次下发检测区域。
// Action状态回调
class ModeActionStateCallback extends ActionStateCallback {
    @Override
    public void onRecording(Mode mode, int state, RecordingResult result) {
        switch (state) {
            // 出现IO错误
            case RecordingResult.State.ERROR_FILE_IO:
            // 内部出现未知错误
            case RecordingResult.State.ERROR_UNKNOWN:
            // 底层初始化未准备好
            case RecordingResult.State.ERROR_RECORDING_NOT_READY:
                break;
            // 底层准备就绪
            case RecordingResult.State.RECORDING_READY:
                break;
            // 录制开始，自动模式下才会返回
            case RecordingResult.State.RECORDING_STARTED:
                break;
            // 录制停止
            case RecordingResult.State.RECORDING_STOPPED:
                break;
            //录制完成
            case RecordingResult.State.RECORDING_COMPLETED:
                break;
            // 录制文件保存完毕
            case RecordingResult.State.RECORDING_FILE_SAVED:
                break;
            default:
                break;
        }
    }
}
```

此外，超慢模式支持的通用能力包含：

后置：闪光灯，zoom，autoFocus。

前置：前置不支持超慢。

## 3.11 双景模式

### 3.11.1 模式创建

应用启动，在onResume中初始化CameraKit对象。如果Texture可用，则开始创建双景模式。否则，在mSurfaceTextureListener的onSurfaceTextureAvailable中开始创建。

```linenums prettyprint prettyprinted
public void onResume() {
   // 申请对应权限
   if (!PermissionHelper.hasPermission(this)) {
   } else {
      // 初始化CameraKit对象
      if (!initCameraKit()) {}
   }
   if (mTextureView != null) {
      if (mTextureView.isAvailable()) {
        mBackgroundHandler.post(new Runnable() {
           @Override
           public void run() {
              // 如果Texture可用，则启动双景模式的创建
              startCamerakit();
           }
         });
       }
   // 监听Texture的状态
   mTextureView.setSurfaceTextureListener(mSurfaceTextureListener);
   }
}
private void startCamerakit() {
  // 获取双景模式支持的镜头组合
  mCameraLists = mCameraKit.getCameraIdList();
  if ((mCameraLists != null) && (mCameraLists.length > 0)) {
    // 如果之前的模式未释放，先释放掉
    if (modeStateCallbackList.size() != 0) {
       releaseMultiViewMode();
    }
    // 初始化模式创建方法的入参
    initialMultiView();
    // 调用接口，进行模式创建
    mCameraKit.createMultiViewMode(cameraTypeList, modeStateCallbackList, mHandlerList);
  }
}
```

创建模式时，初始化参数。

```linenums prettyprint prettyprinted
private void initialMultiView(){
   // 添加镜头组合
  cameraTypeList = new ArrayList<Integer>();
   cameraTypeList.add(Mode.CameraType.BACK_MAIN);
   if ("0".equals(mCurrentCameraId)){
      cameraTypeList.add(Mode.CameraType.BACK_WIDE);
   } else {
```

```linenums prettyprint prettyprinted
private void reshape() {
    //涉及到分辨率改动，需对mode释放再创建，如果当前有mode正在创建，则取消
    if (!isModeConfigured) {
       Log.w(TAG, "doOperation: cannot reshape while current mode is not configured");
       return;
    }
    if (mTwinsVideoExtension != null) {
       releaseTwinsVideoExtension();
    }
    if (mMediaRecorder != null) {
       releaseMediaRecorder();
    }
    // 如果当前是方形，则改成矩形
    if (mSmallViewSize.getHeight() == mSmallViewSize.getWidth()) {
       mMonoPreviewSize = new Size(1280, 720);
       mSmallViewSize = new Size(72 * 2, 128 * 2);
    } else {
       mMonoPreviewSize = new Size(1088, 1080);
       mSmallViewSize = new Size(160, 160);
    }
    startCamerakit();
}
```
