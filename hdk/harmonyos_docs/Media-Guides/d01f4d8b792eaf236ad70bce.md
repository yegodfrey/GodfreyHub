# 个人数据处理说明

此文档针对华为作为最终用户数据处理者，客户作为最终用户数据控制者的数据处理进行说明，包括：

* 华为处理的个人数据清单。
* 指导您如何帮助最终用户实现对数据的控制。

## 华为处理的个人数据清单

|**个人数据**|**处理目的**|**存留期**|
|:-------|:------------------------------|:----------------|
|图片|图像服务处理用户的图片信息，以提供图片编辑和动效渲染服务。|图像服务在处理图片数据后立即删除。|
|文本|图像服务处理用户文本信息，以控制不同的图片编辑和动效渲染效果。|图像服务在处理文本数据后立即删除。|

## 指导开发者如何帮助最终用户实现对数据的控制

图像服务为您的最终用户提供图片编辑和动效渲染能力，帮助用户高效地实现图像内容再生产。

图像服务在处理个人数据后立即删除，不会保存用户的个人数据。因此，建议您为最终用户提供个人数据控制操作，例如，用户可选择是否同意对其提供的图像数据进行处理。
