# 服务限额

为保证服务质量，音频编辑服务将在北京时间2022年6月27日00:00起，对以下云侧服务进行接口调用控制限额。以下均为缺省配额：

|云侧服务|并发数|调用次数|任务数|字符数/时长|
|:---|:--|:--------|:--------|:------------|
|AI配音|3|10,000次/月|10,000个/月|5,000,000字符/月|
|音源分离|1|1,000次/月|1,000个/月|10,000分钟/月|
|歌声合成|1|10次/月|10个/月|60分钟/月|

> 注意
>
> * 对调用次数、任务数、字符数/时长多个指标进行限额，任意一项达到使用上限，服务都无法继续使用。
> * 调用失败不计入限额调用量。

若以上限额无法满足您当前正常使用需求，您可通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/?ha_source=hms5)联系我们申请临时配额，我们根据当前资源进行配置，以保障您的业务稳定运行。
