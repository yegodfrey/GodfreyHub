# 助力网幂科技，为用户提供更全面高效的音频剪辑体验

#### 公司介绍

音频音乐剪辑是武汉网幂科技开发的一款手机音频剪辑应用，支持音乐剪辑、音频提取、伴奏人声提取、格式转换、手机铃声制作、拼接、变速、混音、录音、降噪等功能，目前音频音乐剪辑App在华为应用市场下载量已达4000万+。  

#### 业务挑战

随着音频剪辑应用不断增多，市场竞争愈发激烈，如何为用户提供差异化和优质的音频处理体验，已成为行业新的挑战。音频音乐剪辑App也面临着这样的难题：

1. 文字转语音效果不佳，多位用户反馈文字转语音失败和识别率低的问题。
2. 用户对添加音频效果功能需求强烈，但应用目前无法满足用户对音乐进行风格、声场、均衡器、变声的特效调节。  

#### 解决方案

音频编辑服务（Audio Editor Kit）助力网幂科技打造更全面高效的音频音乐剪辑，通过简单的集成方式让其应用获取强大的音频处理能力。

* 音频音乐剪辑集成了Audio Editor Kit的AI配音能力，解决了当前文字转语音效果不佳的难题，用户只需要输入文字，即可生成自然流畅、情感饱满的朗读语音。
* 音频音乐剪辑集成了Audio Editor Kit的音频特效能力，包括声场、环境音效、均衡器、变声、空间渲染等音频效果能力。结合App自身的UI设计风格，在App内组成了一个完整音频特效工具。

#### 合作收益

To 音频音乐剪辑

帮助音频音乐剪辑App解决了当前文字转语音效果不佳的难题，新增自然流畅的AI配音能力与空间音频渲染等音频特效能力，新功能在单月用户满意度提升32%（数据来源于应用"音频音乐剪辑"运营部门）。

To 用户

获得更全面高效的音频处理使用体验，满足其用户从简单到复杂的音频创作需求，助力提升用户音频音乐作品质量。
