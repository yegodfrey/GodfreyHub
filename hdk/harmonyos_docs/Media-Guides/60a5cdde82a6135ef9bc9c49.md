# 视频编辑屏幕录制SDK集成

#### 介绍

屏幕录制SDK提供录屏功能，集成简单且支持自定义录屏通知。  

#### 屏幕录制

1. 创建屏幕录制事件监听器[HVERecordListener](https://developer.huawei.com/consumer/cn/doc/Media-References/hverecordlistener-0000001286053358)实例，重写监听器的方法。

   ```
   HVERecordListener mHVERecordListener = new HVERecordListener(){
       @Override
       public void onRecordStateChange(HVERecordState recordingStateHve) {
           // 录屏状态变化
       }

       @Override
       public void onRecordProgress(int duration) {
           // 录屏进度
       }

       @Override
       public void onRecordError(HVEErrorCode err, String msg) {
           // 录屏错误
       }

       @Override
       public void onRecordComplete(HVERecordFile fileHve) {
           // 录屏完成
       }
   };
   ```

2. 使用应用上下文和[HVERecordListener](https://developer.huawei.com/consumer/cn/doc/Media-References/hverecordlistener-0000001286053358)实例，初始化[HVERecord](https://developer.huawei.com/consumer/cn/doc/Media-References/hverecord-0000001286213286)。

   ```
   HVERecord.init(this, mHVERecordListener);
   ```

3. （可选）创建[HVERecordConfiguration.Builder](https://developer.huawei.com/consumer/cn/doc/Media-References/hverecordconfiguration-builder-0000001286532870)实例，设置录屏配置。

   ```
   HVERecordConfiguration hveRecordConfiguration = new HVERecordConfiguration.Builder()
        .setMicStatus(true)
        .setOrientationMode(HVEOrientationMode.LANDSCAPE)
        .setResolutionMode(HVEResolutionMode.RES_480P)
        .setStorageFile(new File("/sdcard/DCIM/Camera"))
        .build();
   HVERecord.setConfigurations(hveRecordConfiguration);
   ```

4. 自定义录屏通知。在自定义录屏通知前，先创建用来指定通知布局的XML文件。XML文件需包含按钮等通知组件的ID。以下为指定录屏通知布局的XML文件使用示例。将自定义录屏通知的按钮对应ID命名为"btn_1"。可根据实际需要决定通知中的按钮数量。
   1. 将自定义通知布局传入[HVENotificationConfig](https://developer.huawei.com/consumer/cn/doc/Media-References/hvenotificationconfig-0000001339828397)的初始化方法。
   2. 使用XML文件中定义的按钮、textView等组件的ID及点击事件。调用[addClickEvent](https://developer.huawei.com/consumer/cn/doc/Media-References/hvenotificationconfig-0000001339828397#section460011655120)可新建点击事件。
   3. 调用[setDurationViewId](https://developer.huawei.com/consumer/cn/doc/Media-References/hvenotificationconfig-0000001339828397#section18276142216514)设置textView ID，用来指定录屏时长显示位置。
   4. 调用[setCallingIntent](https://developer.huawei.com/consumer/cn/doc/Media-References/hvenotificationconfig-0000001339828397#section146961413510)设置录屏通知点击时返回的intent。在示例中，intent用来打开一个Activity，这是intent的常见用法。
   5. 在[HVERecord](https://developer.huawei.com/consumer/cn/doc/Media-References/hverecord-0000001286213286)中设置通知配置。

   ```
   HVENotificationConfig notificationData = new HVENotificationConfig(R.layout.hms_scr_layout_custom_notification);
   notificationData.addClickEvent(R.id.btn_1, () -> { HVERecord.stopRecord(); });
   notificationData.setDurationViewId(R.id.duration);
   notificationData.setCallingIntent(new Intent(this, SettingsActivity.class)
       .addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP | Intent.FLAG_ACTIVITY_CLEAR_TASK));
   HVERecord.setNotificationConfig(notificationData);
   ```

5. 开始录屏。

   ```
   HVERecord.startRecord();
   ```

6. 停止录屏。

   ```
   HVERecord.stopRecord();
   ```
