# 高级动效

## 跟手粒子<ParticleView>

* 动效概述 当手指在屏幕上滑动时，在滑动轨迹处会生成跟手粒子。粒子形状、颜色由输入的粒子图片控制，而粒子数量和大小等可通过参数进行设置。此外，还可以通过Range子标签来设置跟手粒子响应区域，即只有当手指滑动处于Range区域时，才生成跟手粒子。

* XML规范

  ```screen
  <ParticleView w="" h="" count="" move_radius="" speek_sec="" reduce_size="" src="" set_path="">     
  <!--可通过多个Range标签指定多个矩形区域来响应跟手粒子-->
      <PathData>
          <Range rect=""/>
          <Range rect=""/>
      </PathData>
  </ParticleView>
  ```

* 参数说明 主标签ParticleView参数说明：

  |参数|类型|M/O（必选/可选）|说明|
  |:----------|:--|:---------|:--------------------------------------------------------------------------------|
  |w|数值|O|粒子宽度，单位为像素，取值正实数，默为60。支持变量。|
  |h|数值|O|粒子高度，单位为像素，宽高比例建议1:1，取值正实数，默为60。支持变量。|
  |count|数值|O|每次滑动产生的粒子数量，取值为正整数，建议范围[1,30]，默认为6；数值太大会造成卡顿现象。|
  |move_radius|数值|O|粒子在手指运动轨迹的基础上随机运动半径的反比例系数；数值越大，粒子随机运动半径越小；取值范围为（1，屏幕宽度），默认为16。支持变量。|
  |speek_sec|数值|O|单位时间粒子运动的距离，该值越大粒子消失越快。取值正实数，默认为2.5。支持变量。|
  |reduce_size|数值|O|每次运动时粒子宽高缩小的尺寸，数值越大，粒子消失越快，取值范围[0.1,5]，默认为3。|
  |set_path|字符串|O|是否设置跟手粒子响应区域，true/false；true表示设置，false表示不设置，默认false；如果为true，需要在PathData标签中设置矩形区域。|
  |src|字符串|M|粒子图片资源名称，生成跟手粒子时使用。|

  副标签PathData用于解析输入的特定Range矩形区域，Range标签参数如下：

  |参数|类型|M/O（必选/可选）|说明|
  |:---|:-|:---------|:------------------------------------------------------------------------------------|
  |rect|数值|O|指定在该矩形区域内可生成跟手粒子，示例：rect="left,top,right,bottom"，表示矩形左上右下对应的x、y坐标，支持在PathData中设置多个区域。|

  > 注意
  >
  > 如果指定区域，只在特定的区域内才产生跟手粒子。矩形区域坐标信息用Rect(left,top,right,bottom)表示，其中left、top相当于矩形左上角坐标<x1,y1>; right、bottom相当于矩形右下角坐标<x2,y2>；那么矩形的x轴范围为x1-x2，y轴范围为y1-y2。
* 应用示例 示例：该示例中未设置跟手粒子响应区域，默认全屏都可以产生跟手粒子。其中，生成的跟手粒子宽高为60像素，每次手指滑动产生6个粒子，运动轨迹上的粒子大小以3像素递减直至粒子宽高小于0时消失。

  ```screen
  <ParticleView w="60" h="60" count="6" move_radius="16" speek_sec="2.5" reduce_size="3.0" set_path="false" src="particle.png"/>
  ```

  示例：该示例中设置了四个跟手粒子响应区域，当手指移动到这些区域时才产生跟手粒子动效，在其它区域内滑动不会产生跟手粒子。

  ```screen
  <!--若要指定区域显示粒子，则set_path参数必须设为true-->
  <ParticleView w="60" h="60" count="6" move_radius="16" speek_sec="2.5" reduce_size="3.0" set_path="true" src="snow_flower.png">  
      <PathData>
          <Range rect="600,580,650,1230"/>
          <Range rect="650,1150,950,1230"/>
          <Range rect="650,580,950,630"/>  
          <Range rect="930,580,970,1230"/>
      </PathData>  
  </ParticleView>
  ```

## 水波纹<WaterWallpaper>

* 动效概述 点击屏幕产生全屏水波纹效果，网格分得越多，水波效果越细腻。网格分得越多，资源消耗越多。

* XML规范

  ```screen
  <WaterWallpaper xmesh="" ymesh="" src="" torsion="" color="" />
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:------|:--|:---------|:-------------------------------------------------|
  |xmesh|数值|O|x方向上分成多少网格，取值范围为1-100，默认值为27。|
  |ymesh|数值|O|y方向上分成多少网格，取值范围为1-100，默认值为48。|
  |src|字符串|M|图片资源名称。|
  |torsion|数值|O|扭曲度，值越大，图片扭曲变形越大，水波纹效果越明显；取值范围 1-10，默认值为2。支持变量。|
  |color|字符串|O|触摸处顶点颜色，支持6位16进制颜色表示，如#0000ff。颜色透明度较小，无特殊需求，建议不设置。|

* 应用示例 示例：将图片横向平均分为27格，纵向平均分为48格，扭曲程度为2，颜色设为蓝色，当手指触摸屏幕时屏幕上呈现浅蓝色水波。

  ```screen
  <WaterWallpaper xmesh="27" ymesh="48" src="bg.jpg" torsion="2" color="#0000ff" />
  ```

## 笔刷 <Paint>

* 动效概述 笔刷需要与Image标签共同使用，当手指滑动屏幕时可以擦除覆盖图片或覆盖颜色所在的图层，显示出背景图片所在图层。若color值不为空，则覆盖图层用颜色来填充，否则用Image图片来填充。注意，用Image图片填充时，需要保证背景图片与笔刷覆盖层图片宽高相同（实际图片资源的宽高），以保证笔刷图片完全覆盖背景图。

* XML规范

  ```screen
  <!--背景图片-->
  <Image x="" y="" w="" h="" src=""/>  ​ 
  <!--笔刷功能，参数说明主要针对下面Image和Paint标签中的参数进行说明--> 
  <Image x="" y="" w="" h="" src="">  
      <Paint weight="" color="" clear_percent=""/>  
  </Image>
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:------------|:--|:---------|:-----------------------------------------------------------|
  |x|数值|O|笔刷覆盖图层左上角相对于屏幕的x轴坐标，单位为像素，默认为0。支持变量。|
  |y|数值|O|笔刷覆盖图层左上角相对于屏幕的y轴坐标，单位为像素，默认为0。支持变量。|
  |w|数值|O|笔刷覆盖图层宽度，单位为像素。如果覆盖图层是图片，w无效，实际w为图片的宽度；如果是颜色覆盖则必须填写w，否则默认为0。|
  |h|数值|O|笔刷覆盖图层高度，单位为像素。如果覆盖图层是图片，h无效，实际h为图片的高度；如果是颜色覆盖则必须填写h，否则默认为0。|
  |src|字符串|O|笔刷覆盖层图片名称，若覆盖层为颜色填充则该值可不填写。|
  |weight|数值|M|笔刷的粗细，单位为像素，值越大，笔刷越粗，值越小，笔刷越细，取正实数，默认为0。|
  |color|字符串|O|如果覆盖图层想用颜色进行覆盖，则填写6或8位16进制颜色，如#afffffff。|
  |clear_percent|数值|O|当覆盖图层被笔刷刷掉这个比例后，整个覆盖图层自动清除，显示背景图层。取值范围为1-100，默认60。支持变量。|

* 应用示例 示例：覆盖图层用图片进行填充。可以看到笔刷功能中的Image设置了src，但是未设置color。

  ```screen
  <!--图片覆盖--> 
  <Image x="0" y="0" src="part.png">
      <Paint x="0" y="0" w="1080" h="2400" weight="200" clear_percent="50" /> 
  </Image>
  ```

  示例：覆盖图层是用颜色进行填充。可以看到笔刷功能中的Image未设置src，但是设置了color。

  ```screen
  <!--涂层覆盖，"刮刮乐"效果--> 
  <Image x="0" y="1000" w="1080" h="1240">
      <Paint x="0" y="1600" weight="40" color="#ADADAD" clear_percent="60"  /> 
  </Image>
  ```

## 网格化 <MeshImage>

* 动效概述 网格化动效支持对输入图片划分为多个子网格区域，并在子网格区域中操作对应的局部图片。位移、旋转、缩放、水波荡漾效果支持局部渲染，透明度仅支持全局渲染。其中，位移、旋转、缩放可以与透明度组合使用，其他组合不支持。

* XML规范

  ```screen
  <MeshImage mesh="" center_point="" src="" x="" y="" w="" h="">    
      <!--位移-->    
      <Translation duration="" repeat="" delay="" factor="" values="" max_distance_x="" max_distance_y="" no_move_distance_x="" no_move_distance_y=""/>     
      <!--旋转-->    
      <Rotate duration="" repeat="" delay="" values="" no_move_distance_x="" no_move_distance_y=""/>
      <!--缩放-->    
      <Scale duration="" repeat="" delay="" values="" no_move_distance_x="" no_move_distance_y=""/>
      <!--透明度-->    
      <Alpha duration="" repeat="" delay="" values=""/>     
      <!--水波荡漾-->    
      <SinMotion a="" factor_k="" no_move_distance_x="" no_move_distance_y=""/>  
  </MeshImage>
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:-----------|:--|:---------|:-------------------------------------------------------------------------|
  |mesh|字符串|M|用英文逗号分开的两个正整数，分别表示图片x、y轴上分的网格数，如："20,20"，x、y轴网格数取值范围为[2,屏幕宽度/高度的二分之一]的整数。|
  |center_point|数值|O|网格中心点编号，可指定具体数字。不设置时程序默认计算公式为：(int) (((meshX+ 1) * (meshY+ 1)) / 2 + 0.5）。|
  |src|字符串|M|图片资源名称。|
  |x|数值|O|图片左上角顶点x轴坐标，单位为像素，默认为0。支持变量。|
  |y|数值|O|图片左上角顶点y轴坐标，单位为像素，默认为0。支持变量。|
  |w|数值|M|图片宽度，单位为像素。|
  |h|数值|M|图片高度，单位为像素。|

  例如：mesh="m,n"，m=6，n=6，分为36个网格，共（m+1)*(n+1)=49个顶点，第25个顶点为中心点，中心点计算公式为：(int) （((meshX+ 1) * (meshY+ 1)) / 2 + 0.5）。 ​

  可以通过控制顶点、no_move_distance等参数控制局部区域，实现局部旋转、位移、缩放、水波荡漾效果。

### 网格化-位移

* 动效概述 可实现局部区域抖动效果，局部区域根据参数center_point、no_move_distance_x和no_move_distance_y计算。

  例如：图片w=1080，h=1920，meshx=6，meshy=6，则每个网格区域的宽为180，高为320，若center_point=25，no_move_distance_x=180，no_move_distance_y=320，则x轴方向上距离中心点25距离小于等于180，且y轴方向上距离中心点25距离小于等于320的所有网格顶点17、18、19、24、26、31、32、33组成的区域为可移动区域，当手指滑动图片时可移动区域与9、13、37、41组成的外圈有位移拉伸效果。
* XML规范

  ```screen
  <MeshImage mesh="" center_point="" src="" x="" y="" w="" h="">
      <Translation duration="" repeat="" delay="" factor="" values="" max_distance_x="" max_distance_y="" no_move_distance_x="" no_move_distance_y=""/>  
  </MeshImage>
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:-----------------|:--|:---------|:------------------------------------------------------------------------------------------------------------------------|
  |duration|数值|O|单次动画持续时间（毫秒），取值正整数，默认为2000。|
  |repeat|数值|O|动画重复次数，-1表示无限循环，0表示不重复，n表示重复n+1次，默认为0。|
  |delay|数值|O|动画延迟执行的毫秒数，即触发动画后需要delay毫秒才开始执行动画，取值正整数，默认为0。支持变量。|
  |factor|数值|O|动画回弹因子，取值0-1之间，值越大回弹幅度越小，默认为0.2。|
  |values|字符串|M|由多个0-1之间的实数构成的运动参数列表，实数个数最少2个，最多5个。示例："1.0,0,1.0"表示从当前位置运动到初始位置，然后又运动到当前位置，实数值越大移动距离越大，但受限于max_distance_x和max_distance_y。|
  |max_distance_x|数值|O|x轴最大运动距离，单位为像素，取值范围为(0，每个网格宽度)，默认为一个网格宽度。支持变量。|
  |max_distance_y|数值|O|y轴最大运动距离，单位为像素，取值范围为(0，每个网格高度)，默认为一个网格高度。支持变量。|
  |no_move_distance_x|数值|O|x轴方向不动的点，离中心点大于no_move_distance_x距离的点不动。设置的值需大于等于0，如果为0值则被认为是图片宽度，默认为图片宽度，单位为像素。支持变量。|
  |no_move_distance_y|数值|O|y轴方向不动的点，离中心点大于no_move_distance_y距离的点不动。设置的值需大于等于0，如果为0值则被认为是图片高度，默认为图片高度，单位为像素。支持变量。|

* 应用示例 示例：将宽339、高388的图片分成横20格、竖20格，共400个网格，每个网格宽16.95，高19.4。values设为1，0表示局部图片随手指产生位移抖动效果后恢复原位，位移大小与手指移动距离大小成正比，max_distance_x/y设为30，使得位移动画的x,y轴最大位移为30像素，动画过程持续2s。no_move_distance_x/y设置为121、138，根据每个网格的宽高可以算出中心点左右共14列和上下共14排相交的区域为局部移动区域，可以通过手指滑动该区域，滑动时该区域与包裹着该区域的网格顶点间有拉伸变形。

  ```screen
  <MeshImage x="200" y="500" w="339" h="388" mesh="20,20"  src="part.jpg">
      <Translation duration="2000" repeat="0" delay="0" factor="0.15" values="1.0,0" max_distance_x="30" max_distance_y="30" no_move_distance_x="121" no_move_distance_y="138"/>  
  </MeshImage>
  ```

### 网格化-旋转

* 动效概述 可实现图片局部旋转动画，旋转区域与位移区域计算方法一致。

* XML规范

  ```screen
  <MeshImage mesh="" center_point="" src="" x="" y="" w="" h="">  
      <Rotate duration="" repeat="" delay="" values="" no_move_distance_x="" no_move_distance_y=""/>  
  </MeshImage>
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:-----------------|:--|:---------|:-------------------------------------------------------------------------------------|
  |duration|数值|O|单次动画持续时间（毫秒），取值正整数，默认为2000。|
  |repeat|数值|O|动画重复次数，-1表示无限循环，0表示不重复，n表示重复n+1次，默认为0。|
  |delay|数值|O|动画延迟执行的毫秒数，即触发动画后需要delay毫秒才开始执行动画，取值正整数，默认为0。|
  |values|字符串|M|由多个0-360之间的实数构成的旋转参数列表，实数个数最少2个，最多5个。示例："0,360,0"表示从当前位置顺时针旋转360度，然后再逆时针旋转到当前位置。|
  |no_move_distance_x|数值|O|x轴方向不动的点，离中心点大于no_move_distance_x距离的点无旋转。设置的值需大于等于0，如果为0值则被认为是图片宽度，默认为图片宽度，单位为像素。支持变量。|
  |no_move_distance_y|数值|O|y轴方向不动的点，离中心点大于no_move_distance_y距离的点无旋转。设置的值需大于等于0，如果为0值则被认为是图片高度，默认为图片高度，单位为像素。支持变量。|

* 应用示例 示例：在该示例中，设置循环播放旋转动画，每次持续2.5s，点击图片后，局部区域开始由当前位置顺时针旋转360度，然后再逆时针旋转到180度后，再进一步旋转回到当前位置。

  ```screen
  <MeshImage x="100" y="1000" w="200" h="200" mesh="20,20" center_point="221" src="snow_flower.png">
      <Rotate duration="2500" repeat="-1" delay="0" values="0,360,180,0" no_move_distance_x="200" no_move_distance_y="200"/>  
  </MeshImage>
  ```

### 网格化-缩放

* 动效概述 实现图片局部区域缩放动画，缩放区域计算方式与局部位移动画一致。

* XML规范

  ```screen
  <MeshImage mesh="" center_point="" src="" x="" y="" w="" h="">  
      <Scale duration="" repeat="" delay="" values="" no_move_distance_x="" no_move_distance_y=""/>  
  </MeshImage>
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:-----------------|:-|:---------|:---------------------------------------------------------------------------------------|
  |duration|数值|O|单次动画持续时间（毫秒），取值正整数，默认为2000。|
  |repeat|数值|O|动画重复次数，-1表示无限循环，0表示不重复，n表示重复n+1次，默认为0。|
  |delay|数值|O|动画延迟执行的毫秒数，即触发动画后需要delay毫秒才开始执行动画，取值正整数，默认为0。|
  |values|数值|M|由多个0-1之间的实数构成的缩放参数列表，实数个数最少2个，最多5个。示例："1,0,1"表示从最大缩小到0，然后再放大到最大。1表示原始大小，缩放数值是原始大小的倍数。|
  |no_move_distance_x|数值|O|x轴方向不动的点，离中心点大于no_move_distance_x距离的点无缩放效果。设置的值需大于等于0，如果为0值则被认为是图片宽度，默认为图片宽度，单位为像素。支持变量。|
  |no_move_distance_y|数值|O|y轴方向不动的点，离中心点大于no_move_distance_y距离的点无缩放效果。设置的值需大于等于0，如果为0值则被认为是图片高度，默认为图片高度，单位为像素。支持变量。|

* 应用示例 示例：在该示例中，设置values为"1,0,1"，点击图片后，局部区域从当前大小缩小到0，再从0放大至原局部区域大小。动画时长为2s，只播放1次。

  ```screen
  <MeshImage x="100" y="500" w="318" h="200" mesh="20,20" center_point="221" src="love.png">
      <Scale duration="2000" repeat="0" delay="0" values="1,0,1" no_move_distance_x="200" no_move_distance_y="200"/>  
  </MeshImage>
  ```

### 网格化-透明度

* 动效概述 实现整张图片透明度动画，不支持局部透明度变换。可以与旋转、位移以及缩放动画进行组合。

* XML规范

  ```screen
  <MeshImage mesh="" center_point="" src="" x="" y="" w="" h=""> 
      <Alpha duration="" repeat="" delay="" values=""/>  
  </MeshImage>
  ```

* 参数说明

  |参数|类型|M/O（必选/可选）|说明|
  |:-------|:-|:---------|:---------------------------------------------------------------------|
  |duration|数值|O|单次动画持续时间（毫秒），取值正实数，默认为2000。|

## 下落动效<DropPhysicalView>

* 动效概述 下落动效提供了一系列物体移动、旋转、透明度设置、移动区域设置的组合动效。对单张图片进行复用，减小相关内存的消耗。其中下落的动效符合物理规律，提供重力以及空气密度的设置项，能够随着物体大小改变物体的运动轨迹。可以通过参数设置实现下雨下雪、流星等动效。

  ```screen
              <Position isRandom="" x="" y=""/>

  ```

* 参数说明 **<DropPhysicalView>**

  下落动效的总体框架是DropPhysicalView，其主要属性是定义了整个视图中所有粒子元素的下落状态。

  |参数|类型|M/O（必选/可选）|说明|
  |:---------|:-|:---------|:-----------------------------------------------------------------------------------------------|
  |gravityX|数值|O|x方向的重力数值，默认值为0。该值大于0物体向右移动，小于0物体向左移动，为0时无x轴位移效果。支持变量。|
  |gravityY|数值|O|y方向的重力数值，默认值为0。该值大于0物体向下移动，小于0物体向上移动，为0时无y轴位移效果。支持变量。|
  |airDensity|数值|O|空气密度，影响空气阻力的大小，值越大导致空气阻力越大，范围为正实数，默认值为12.93。面积较大的物体下落时所受的空气阻力较大，所以实际动效中w，h较小的物体比w，h大的物体移动速度略快一些。|

  **<ItemGroup>**

  ItemGroup提供了整个粒子组的运行范围和透明度限定等限定了粒子的运动轨迹以及表现形式。

  |y|数值|O|运行范围的y起点，单位为像素，默认为0。支持变量。|
  |width|数值|O|运行范围的宽度，单位为像素，默认为屏幕宽度。支持变量。|
  |height|数值|O|运行范围的高度，单位为像素，默认为屏幕高度。支持变量。|

  **子标签**

  **<Alpha>**

  |参数|类型|M/O（必选/可选）|说明|

  |参数|类型|M/O（必选/可选）|说明|
  |:----|:--|:---------|:--------------|

  **<Velocity>**

  |参数|类型|M/O（必选/可选）|说明|
  |:--------------|:--|:---------|:-----------------------------------------------------------------------------|
  |isRandom|字符串|M|初始速度是否随机，true/false。|
  |velocityX|数值|O|x方向初始速度，默认为0。不随机则x轴初始速度为该值，随机则x轴初始速度为lowestVelocityX+[(0,velocityX)间随机值]。支持变量。|
  |velocityY|数值|O|y方向初始速度，默认为0。不随机则y轴初始速度为该值，随机则x轴初始速度为lowestVelocityY+[(0,velocityY)间随机值]。支持变量。|
  |lowestVelocityX|数值|O|isRandom等于true时生效，为x轴随机初始速度最低值，默认为0。|
  |lowestVelocityY|数值|O|isRandom等于true时生效，为y轴随机初始速度最低值，默认为0。|

  **<Angle>**

  物体的初始旋转角度设置，不设置则随机角度，如果禁止随机角度必须显式注明isRandom等于false。

  |参数|类型|M/O（必选/可选）|说明|
  |:-------|:--|:---------|:----------------------------------------|
  |isRandom|字符串|M|初始旋转角度是否随机，true/false。|
  |angle|数值|O|-360-360整数，不随机时生效，给每个粒子统一赋予同一个角度的旋转，默认为0。|

  **<Position>**

  物体的初始位置，如果不设置则在ItemGroup的运行范围内随机生成，如果指定则初始位置为指定位置。

  |参数|类型|M/O（必选/可选）|说明|
  |:-------|:--|:---------|:-------------------------|
  |isRandom|字符串|O|位置是否随机，true/false，默认false。|
  |x|数值|O|初始位置的x坐标，不随机时有效，默认为0。|
  |y|数值|O|初始位置的y坐标，不随机时有效，默认为0。|

  **<AngleVelocity>**

  物体的旋转角速度，控制物体旋转速度的快慢，能够显式设置物体随机旋转速度的大小。如果不写标签则旋转速度的范围为0-30度。

  |参数|类型|M/O（必选/可选）|说明|
  |:------------------|:--|:---------|:-----------------------------------------------------------------------------------------------|
  |isRandom|字符串|O|角速度是否随机，true/false，默认false。|
  |angleVelocity|数值|O|物体旋转角速度，范围为-360-360，默认为0。不随机则物体的旋转角度为该值，如果随机则物体旋转角度为lowestAngleVelocity+[(0,angleVelocity)间随机值]。|
  |lowestAngleVelocity|数值|O|物体最低旋转角速度，范围为-360-360，默认为0。仅当isRandom等于true时生效，为随机速度的最小值。|

  **<Weight>**

  物体的大小设置，根据设置的值能够对生成的图大小进行缩放，如果不显式指定大小为不随机则大小在0-1之间随机。

  |参数|类型|M/O（必选/可选）|说明|
  |:-----------|:--|:---------|:-----------------------------------------------------------------------|
  |isRandom|字符串|O|是否随机缩放粒子，true/false，默认false。|
  |value|数值|O|粒子图片的缩放比例，默认为1。如果不随机则统一设置物体缩放比例为该值，随机则缩放比例是lowestWeight+[(0,value)间随机值]。|
  |lowestWeight|数值|O|仅当isRandom等于true的时候才生效，为随机尺寸的最小值，默认为0.1。|
