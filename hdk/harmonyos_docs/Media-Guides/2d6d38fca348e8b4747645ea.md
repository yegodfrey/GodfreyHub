# 版本更新说明

#### 1.0.1（2021-01-14）

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|首次发布。 新增特性 * 缩放/裁剪功能：编码场景下，实现图像分辨率的无缝切换。 * 动态码控：动态调整帧级QP（Quantizer Parameter，量化参数）范围，实现画质的自由切换。 * 非参考帧编码：通过丢弃非参考P帧，降低带宽，提升流畅度。 * 长期参考帧编码：网络不稳定时，编码端动态调整参考关系，提升解码端的流畅度。 * 感兴趣区域编码：提高特定区域的画质，带来更好的视觉体验。|
