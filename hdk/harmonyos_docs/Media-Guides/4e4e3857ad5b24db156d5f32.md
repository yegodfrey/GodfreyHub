# 功能介绍

#### 简介

AI配音功能支持将文字转换为自然饱满的朗读语音。多种音色可供选择，合成音色生动自然，风格多样，情感丰富，并提供调节语速、音量等功能。  

#### 应用

AI配音功能广泛应用于有声阅读、新闻播报、语音导航、音视频内容制作等领域。例如：

* 在阅读小说时，AI配音功能可以将大篇幅的文本转为语音输出，释放双眼，让文字开口说话，为阅读添加乐趣。
* 在语音导航中，可以基于导航数据录制语音片段进而合成为特定的导航语音，让导航更加个性化。
