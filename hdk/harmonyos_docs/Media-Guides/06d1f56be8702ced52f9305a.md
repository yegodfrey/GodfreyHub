# 申请DRM服务端证书托管

华为提供DRM服务端证书托管功能，允许您自行从规定的证书管理机构（当前合法的证书管理机构为寰宇信任（北京）技术有限公司）签发DRM服务端证书，并托管到华为WisePlay DRM系统中，用于后续在返回的内容License中进行签名和验证。

您也可以选择直接使用华为WisePlay DRM统一申请的DRM服务端证书为您的业务提供服务，无需使用DRM服务端证书托管功能，请直接跳过本章节。  

#### WisePlay服务端证书管理流程

操作流程描述如下：

1. 首先保证您已[开通华为数字版权管理服务](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001050039992#section14208174317153)，否则DRM服务端证书托管功能不可用。
2. 初始化公私钥对。

   <br />

   进入[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"我的项目 \> 构建 \> 数字版权管理服务"，请根据您的业务运行区域，选择所需托管DRM服务端证书的站点，点击"新增"按钮，根据业务需要可以选择RSA2048或SM2算法并初始化DRM服务端证书密钥对。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110906.20755719434990610362187481734835:50001231000000:2800:E74E6CB8965071B69A2293AB8DC073EF96550BD39A58E0B0276C9779B5987EEC.png)

   <br />

3. 导出DRM服务端证书请求CSR文件。

   <br />

   点击"下载CSR文件"图标按钮，在下载CSR文件对话框中依次填入以下信息，指定需要导出的CSR文件。
   * DRM服务提供商：证书的机构名称（Organization Name）
   * 通用名称：证书的通用名称（Common Name）
   * 国家名称：证书的国家信息（Country Name），请输入符合ISO3166的国家码，例如CN

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110906.10802984885362645639030452984424:50001231000000:2800:A7599111B15D46D69E194A07C03A88804F264CFA3629AC885B07892709BE9D1B.png)

   <br />

4. 上传证书

   <br />

   * 请您自行将DRM服务端证书请求CSR文件提交给规定的证书管理机构，购买并签发DRM服务端证书。
   * 完成后，点击"上传证书"图标按钮依次传入签发的DRM服务端证书、对应的服务端二级CA证书和根证书，上传成功即可完成托管证书到华为WisePlay DRM系统。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110906.92653031185834019145938510408642:50001231000000:2800:428AF702CDA7D4099BDA319DBFFA617C4A40BFD89FF12BEB28A61A19BCCE2BBC.png)

   <br />

5. 证书状态更新

   <br />

   初次上传DRM服务端证书成功托管后，证书状态自动从初始化更新为正常。

   请注意证书的生效时间和到期时间，如果托管的证书失效，将会影响到您的DRM业务正常运行，请从证书机构延期或重新签发证书，并将DRM服务端证书重新上传。  
   您也可以点击"更新状态"图标按钮手动变更托管证书状态，将正常状态的证书设置为暂停，或从暂停状态恢复。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110906.81277399277610606971981812776424:50001231000000:2800:4D4C0E5AB084EFB8CE41D7030A7185715A6A323FE3AB9FAC8A8AD6A9245CA826.png)  
   每个算法类型请至少保留一个正常状态的证书，否则可能影响您的业务。
