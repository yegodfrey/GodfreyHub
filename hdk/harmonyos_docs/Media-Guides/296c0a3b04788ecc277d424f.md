# 增强播放体验

## 预加载能力

预加载支持提前缓存需要播放的部分媒体内容，降低起播时延。在播放时会自动命中已经预加载好的内容。

### 实现流程

|序号|步骤|说明|
|:-|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建预加载实例|在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createPreloader](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section85065298232)创建预加载实例。|
|2|设置预加载路径及加载最大字节数|通过[Preloader](https://developer.huawei.com/consumer/cn/doc/Media-References/preloader-0000001052554589)实例，调用[initCache](https://developer.huawei.com/consumer/cn/doc/Media-References/preloader-0000001052554589#section139823011526)设置预加载缓存路径和预加载的最大字节数。|
|3|设置预加载的视频参数，开启预加载任务|设置[CacheInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/cache_info-0000001051793560)参数，通过[addCache](https://developer.huawei.com/consumer/cn/doc/Media-References/preloader-0000001052554589#section1932075914542)方法开启预加载任务。|

### 操作步骤

1. 创建预加载实例。

   在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createPreloader](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section85065298232)创建预加载实例。

   ```screen
   Preloader preloader= VideoKitApplication.getWisePlayerFactory().createPreloader();
   ```

2. 设置预加载缓存路径和预加载最大字节数。

   ```screen
   preloader.initCache(path, size);
   ```

   > 说明
   >
   > 设置预加载的缓存路径需要确保有读写权限。
3. 设置预加载参数，开启预加载任务。
   * 播放器提供接口类[CacheInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/cache_info-0000001051793560)，设置预加载参数。在调用[addCache](https://developer.huawei.com/consumer/cn/doc/Media-References/preloader-0000001052554589#section1932075914542)方法后会直接开启预加载任务。

     ```java
     // 方式1：设置加载参数，新增任务按最低优先级策略加入当前任务队列尾
     preloader.addCache(cacheInfo);

     // 方式2：设置加载参数，通过设置优先级，提前加载指定数据
     preloader.addCache(cacheInfo, priority);
     ```

   * 暂停预加载任务。

     ```screen
     preloader.pauseAllTasks();
     ```

   * 恢复预加载任务。

     ```screen
     preloader.resumeAllTasks();
     ```

   * 删除所有任务。

     删除所有预加载的任务，已经加载的缓存数据还是保存在初始化设置的路径下，需要调用[removeAllCache](https://developer.huawei.com/consumer/cn/doc/Media-References/preloader-0000001052554589#section177525175385)进行删除。

     ```screen
     preloader.removeAllTasks();
     ```

   * 删除缓存数据。

     删除本地已经缓存的数据，但是不会删除初始化设置的文件夹路径。

     ```screen
     preloader.removeAllCache();
     ```

     > 说明
     >
     > 播放器在开始播放时会默认暂停所有的预加载任务，App需要调用[resumeAllTasks](https://developer.huawei.com/consumer/cn/doc/Media-References/preloader-0000001052554589#section20723141512384)或者[addCache](https://developer.huawei.com/consumer/cn/doc/Media-References/preloader-0000001052554589#section1932075914542)接口恢复预加载任务。

## 获取关联推荐内容能力

关联推荐内容能力支持根据当前视频Video的ID，通过关联推荐的规则参数获取关联视频。

### 实现流程

|序号|步骤|说明|
|:-|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。|
|2|调用获取关联推荐接口|调用获取关联推荐接口[getRecommendVideoList](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1873173115133)，并在方法入参正确设置回调。|

### 操作步骤

1. 创建播放器实例。

   在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```screen
   WisePlayer player= VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 调用获取关联推荐接口[getRecommendVideoList](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1873173115133)，并在方法入参正确设置回调。

   ```screen
   RecommendOptions recommendOptions= new RecommendOptions();
   recommendOptions.setLanguage("zh_CN");
   WisePlayer.IRecommendVideoCallback recommendCallback= new WisePlayer.IRecommendVideoCallback() {
       @Override
       public void onSuccess(List<RecommendVideo> list) {
       }
       @Override
       public void onFailed(int what, int extra, Object obj) {
       }
   };
   // 关联推荐的视频ID，和华为视频服务器内容元数据开放接口中提供的视频ID相同
   String videoId= "xxx";
   player.getRecommendVideoList(videoId, recommendOptions, "xxxx", recommendCallback);
   ```

## 设置支持的国家/地区（GRS）

设置支持的国家/地区码（GRS），可用于获取鉴权地址和打点上报地址。

### 实现流程

|序号|步骤|说明|
|:-|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|设置国家/地区码（GRS）|设置国家/地区码（GRS），调用[WisePlayerFactory.initFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section1520491714114)方法，初始化播放器SDK。|
|2|更新国家/地区码（GRS）|调用[updateServeCountry](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section17471518311)方法，更新国家/地区码（GRS）。|

### 操作步骤

1. 设置国家/地区码（GRS），调用[WisePlayerFactory.initFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section1520491714114)方法，初始化播放器SDK。

   ```screen
   // setDeviceId方法需要传入手机的DeviceId
   // setServeCountry方法需要传入国家/地区码（GRS）
   WisePlayerFactoryOptionsExt factoryOptions= new WisePlayerFactoryOptionsExt.Builder().setDeviceId("xxx").setServeCountry("XX").build();
   ```

2. 调用[updateServeCountry](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section17471518311)方法，更新国家/地区码（GRS）。

   ```screen
   WisePlayerFactory.updateServeCountry("XX");
   ```

   > 说明
   > * GRS：全球路由服务（Global Router Service），用于获取鉴权地址和打点上报地址。GRS支持的国家/地区请参见[支持的国家/地区码（GRS）](https://developer.huawei.com/consumer/cn/doc/Media-Guides/country-region-code-0000001062504340)。
   > * 在一次播放过程中不支持服务国家/地区码（GRS）切换。
   > * [支持的国家/地区码（GRS）](https://developer.huawei.com/consumer/cn/doc/Media-Guides/country-region-code-0000001062504340)内容填写需要遵循ISO3166-1标准：大写字母，长度为2个字符。

## 设置内嵌多音轨切换

Video Kit提供App音轨能力：获取音轨信息列表、获取正在播放的音轨、切换音轨、设置起播前的音轨偏好。

### 实现流程

|序号|步骤|说明|
|:-|:------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。|
|2|获取音轨信息列表|调用[getAudioTracks](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section66771631131213)方法，获取音轨信息列表，返回[AudioTrackInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/audio-track-info-0000001124402881)数组，无内嵌音轨返回null。|
|3|获取正在播放的音轨，切换音轨，设置起播前的音轨偏好|获取正在播放的音轨，切换音轨，设置起播前的音轨偏好。|

### 操作步骤

1. 创建播放器实例。

   在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```screen
   WisePlayer player= VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 调用[getAudioTracks](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section66771631131213)方法，获取音轨信息列表，返回[AudioTrackInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/audio-track-info-0000001124402881)数组，无内嵌音轨返回null。

   ```screen
   AudioTrackInfo[] audioTrack= player.getAudioTracks();
   ```

3. 获取正在播放的音轨，切换音轨，设置起播前的音轨偏好。
   * 调用[getSelectedAudioTrack](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section1836811118517)方法，获取当前正在播放的音轨，返回[AudioTrackInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/audio-track-info-0000001124402881)对象。

     ```screen
     AudioTrackInfo audioTrackInfo= player.getSelectedAudioTrack();
     ```

   * 调用[selectAudioTrack](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section101364266149)方法，切换指定音轨。

     首先需要获取当前播放的视频支持的音轨信息列表，再指定切换的音轨ID。

     ```screen
     // i是需要切换指定音轨数组中的index
     int i = 0;
     AudioTrackInfo[] audioTrack= player.getAudioTracks();
     player.selectAudioTrack(audioTrack[i].getId());
     ```

   * 调用[presetAudioLanguage](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section8584841151512)方法，设置起播前的音轨偏好。

     ```screen
     String lang= "zh_CN,en_US,ar_AR";
     player.presetAudioLanguage(lang);
     ```

     > 说明
     >
     > [presetAudioLanguage](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section8584841151512)参数格式定义为：lang1,lang2,...
     >
     > 通过逗号分割多个描述，排在前面的优先级高，最多支持3个。如:"zh_CN,en_US,ar_AR"，优先级顺序 zh_CN > en_US > ar_AR。

## 起播参数设置

App在不同的媒体片源播放场景下，对起播的时延要求不一样。如短视频/小视频需要快速起播；长视频为了降低卡顿率，需缓冲多一些数据再起播，要求起播时延相对较长；直播场景下起播时延要求会比较小。所以Video Kit需要将起播时延的配置能力提供给App。
> 说明
>
> * 参数格式："15:800,9:2500,Others:4000,Window:10000"
> * 参数说明：下载速度是当前播放码率15倍及以上时，允许的最低缓冲值为800ms，即在该场景下，至少要缓冲0.8s数据起播；9倍到15倍之间，至少缓冲2.5s起播；0倍到9倍之间，至少缓冲4秒起播；Window表示起播观察窗口，表示根据当前的网速、片源码率和缓冲情况，一旦起播，则预测在起播观察窗口内不会卡顿。

* 点播建议参数设置

  ```screen
  // 点播设置参数"15:800,9:2500,Others:4000,Window:10000"
  InitBufferTimeStrategy.Builder initBufferTimeStrategy= new InitBufferTimeStrategy.Builder(10000);
  try {
      initBufferTimeStrategy.append(15, Integer.MAX_VALUE, 800);
      initBufferTimeStrategy.append(9, 15, 2500);
      initBufferTimeStrategy.append(0, 9, 4000);
      player.setInitBufferTimeStrategy(initBufferTimeStrategy.build());
  } catch (IllegalArgumentException | DownloadMultipleZoneException exception) {
      // TODO 异常处理
  }
  ```

* 小视频建议参数设置

  ```screen
  // 小视频设置参数"1:800,Others:1000,Window:2000"
  InitBufferTimeStrategy.Builder initBufferTimeStrategy= new InitBufferTimeStrategy.Builder(2000);
  try {
      initBufferTimeStrategy.append(1, Integer.MAX_VALUE, 800);
      initBufferTimeStrategy.append(0, 1, 1000);
      player.setInitBufferTimeStrategy(initBufferTimeStrategy.build());
  } catch (IllegalArgumentException | DownloadMultipleZoneException exception) {
      // TODO 异常处理
  }
  ```

* 直播建议参数设置

  ```screen
  // 直播设置参数"5:1000,Others:2000,Window:4000"
  InitBufferTimeStrategy.Builder initBufferTimeStrategy= new InitBufferTimeStrategy.Builder(4000);
  try {
      initBufferTimeStrategy.append(5, Integer.MAX_VALUE, 1000);
      initBufferTimeStrategy.append(0, 5, 2000);
      player.setInitBufferTimeStrategy(initBufferTimeStrategy.build());
  } catch (IllegalArgumentException | DownloadMultipleZoneException exception) {
      // TODO 异常处理
  }
  ```

## 设置启用单线程下载媒体文件

针对特定服务，单线程下载媒体文件的方式，相对于多线程分段下载会更快，此时建议开启该属性启用单线程下载。

### 实现流程

|序号|步骤|说明|
|:-|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。|
|2|设置单线程下载|通过播放器实例，调用[setProperties](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section149322020143710)设置单线程下载。|

### 操作步骤

1. 创建播放器实例。

   在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```screen
   WisePlayer player= VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 设置单线程下载。

   通过播放器实例，调用[setProperties](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section149322020143710)设置单线程下载。

   ```screen
   player.setProperties(PlayerConstants.Properties.SINGLE_LINK_DOWNLOAD, true);
   ```

   > 说明
   > * 该方法需要在[ready](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section51567281717)之前调用。
   > * 对于MP4场景，MP4只有一次请求，一次请求整个文件大小。
   > * 对于HLS/DASH场景（分片形式），多次请求，每次请求只请求一个分片大小。

## 设置SOCKS5代理

支持SOCKS5代理，通过代理方式将数据请求重定向到指定的服务器上。

### 实现流程

|序号|步骤|说明|
|:-|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。|
|2|设置代理数据|初始化[Proxy](https://developer.huawei.com/consumer/cn/doc/Media-References/proxy-0000001145518390)对象，设置代理类型、IP或者域名、端口号、用户名、密码。|
|3|设置播放器代理|使用播放器实例，调用[setProxy](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section7518162644111)设置请求的代理参数。|
|4|关闭播放器代理|使用播放器实例，调用[setProxy](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section7518162644111)，参数为null，关闭代理。|

### 操作步骤

1. 创建播放器实例。

   在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```screen
   WisePlayer player= VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 设置代理信息。

   初始化[Proxy](https://developer.huawei.com/consumer/cn/doc/Media-References/proxy-0000001145518390)对象，设置代理类型、IP或者域名、端口号、用户名、密码。

   ```screen
   Proxy socksProxy = new Proxy();
   socksProxy.setType(Proxy.Type.SOCKS);
   socksProxy.setHost("host");
   socksProxy.setPort("port");
   socksProxy.setUser("username");
   socksProxy.setPasswd("password");
   ```

   > 说明
   >
   > 初始化[Proxy](https://developer.huawei.com/consumer/cn/doc/Media-References/proxy-0000001145518390)对象，代理类型、IP或者域名、端口号、用户名、密码都不能为空。
3. 设置播放器代理。

   使用播放器实例，调用[setProxy](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section7518162644111)设置请求的代理参数。

   ```screen
   player.setProxy(socksProxy);
   ```

   > 说明
   >
   > 设置代理之后，播放器播放片源，都是从代理地址拉取媒体流信息。
4. 关闭播放器代理。

   使用播放器实例，调用[setProxy](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section7518162644111)，参数为null，关闭代理。

   ```screen
   player.setProxy(null);
   ```

   > 说明
   >
   > 关闭代理之后，播放器播放片源，都是从片源地址拉取媒体流信息。

## 设置设备唤醒状态

播放器默认在播放过程中不保持设备唤醒状态。需要保持唤醒状态，即播放过程一直保持常亮，调用此接口。

### 实现流程

|序号|步骤|说明|
|:-|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。|
|2|设置唤醒状态|通过播放器实例，调用[setWakeMode](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section078783744111)设置唤醒状态。|

### 操作步骤

1. 创建播放器实例。

   在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```screen
   WisePlayer player= VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 设置唤醒状态。

   通过播放器实例，调用[setWakeMode](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section078783744111)设置唤醒状态。

   ```screen
   // context为播放界面Activity上下文，例如：Video Kit示例代码使用PlayActivity为播放界面。
   Context context= PlayActivity.this;
   player.setWakeMode(context, PowerManager.FULL_WAKE_LOCK | PowerManager.ON_AFTER_RELEASE);
   ```

   > 说明
   >
   > 使用[setWakeMode](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section078783744111)方法需要申请android.permission.WAKE_LOCK权限。

## 设置字幕显示

播放器SDK已经具有显示字幕能力，如果App需要自定义字幕显示，需要根据播放器返回的字幕信息处理。

### 实现流程

|序号|步骤|说明|
|:-|:------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|创建播放器实例|在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。|
|2|设置字幕监听|通过播放器实例，调用[setSubtitleUpdateListener](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section208731496515)设置字幕监听。|
|3|处理字幕信息|通过[SubtitleUpdateListener](https://developer.huawei.com/consumer/cn/doc/Media-References/subtitle-update-listener-0000001160411175)回调方法[onSubtitleUpdate](https://developer.huawei.com/consumer/cn/doc/Media-References/subtitle-update-listener-0000001160411175#section139823011526)，接收字幕对象[SubtitleInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/video-subtitleinfo-0000001144288406)处理数据，显示字幕。|

### 操作步骤

1. 创建播放器实例。

   在[初始化播放器](https://developer.huawei.com/consumer/cn/doc/Media-Guides/init-player-0000001050199407)成功时会返回一个[WisePlayerFactory](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166)实例，App使用这个实例调用[createWisePlayer](https://developer.huawei.com/consumer/cn/doc/Media-References/wpf-0000001050197166#section81813501093)创建播放器实例。

   ```screen
   WisePlayer player= VideoKitApplication.getWisePlayerFactory().createWisePlayer();
   ```

2. 设置播放器字幕监听。

   通过播放器实例，调用[setSubtitleUpdateListener](https://developer.huawei.com/consumer/cn/doc/Media-References/wiseplayer-0000001050316766#section208731496515)设置播放器字幕监听。

   ```screen
   player.setSubtitleUpdateListener(new SubtitleUpdateListener() {
       @Override
       public void onSubtitleUpdate(WisePlayer wisePlayer, Parcelable[] subtitles) {

       }
   });
   ```

3. 处理字幕信息。

   通过[SubtitleUpdateListener](https://developer.huawei.com/consumer/cn/doc/Media-References/subtitle-update-listener-0000001160411175)回调方法[onSubtitleUpdate](https://developer.huawei.com/consumer/cn/doc/Media-References/subtitle-update-listener-0000001160411175#section139823011526)，接收字幕对象[SubtitleInfo](https://developer.huawei.com/consumer/cn/doc/Media-References/video-subtitleinfo-0000001144288406)处理数据，显示字幕。

   ```screen
   @Override
   public void onSubtitleUpdate(WisePlayer wisePlayer, Parcelable[] subtitles) {
       if (subtitles != null && subtitles.length > 0) {
           SubtitleInfo[] subtitleInfos= new SubtitleInfo[subtitles.length];
           for (int i = 0; i < subtitles.length; i++) {
               Parcelable parcelable= subtitles[i];
               if (parcelable instanceof SubtitleInfo) {
                   // 根据App需求定制字幕显示。
               }
           }
       }
   }
   ```

   > 说明
   >
   > 只有FrameLayout和RelativeLayout支持展示字幕，不是这两种布局并且需要展示字幕时，上报事件码[LAYOUT_NOT_SUPPORT_SUBTITLE](https://developer.huawei.com/consumer/cn/doc/Media-References/info-code-0000001050199191#ZH-CN_TOPIC_0000001050199191__p9541650114712)。
