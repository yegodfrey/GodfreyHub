# LTC码

## LTC同步

LTC是一种能转变成音频频率的数字信号，能记录在音频声轨上。Renderer需读取传输过来的LTC码数据解码并同步至Renderer时间码上。

LTC同步功能只在虚拟声卡模式下使用，时间格式为时、分、秒、帧。在Send/Return模式下，LTC同步功能不可用，时间格式为时、分、秒、毫秒。

Renderer上的三种时间码状态：

1. 虚拟声卡模式下：未开启LTC同步时，时间码与DAW不一致（可手动修改），点击录制开始走带，通过Renderer走带控制器操控暂停和停止。
2. 虚拟声卡模式下：开启LTC同步且DAW发送LTC数据到对应LTC通道时，Renderer时间码在录制时与DAW时间码显示完全一致。点击录制后变为预录制状态。DAW进行播放时Renderer开始录制，时间码开始与DAW同步。
3. Send/Return模式下：LTC功能不生效。DAW挂载Panner插件后，时间码采用采样点时间同步。点击录制后不进行走带录制，需要DAW播放才进行走带录制。
