# 申请SDK

SDK目前受限公开，请确保证您的"开发者类型"为"企业开发者"，并且您登录的开发者账号已经过实名认证。

SDK申请的具体操作流程描述如下：

1. 进入[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"我的项目 \> 构建 \> 数字版权管理服务"，切换到SDK页签，可以看到SDK状态为"未开通"。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.58274915869748015013329304745281:50001231000000:2800:A4F38C5E8A0EA12F21DE644019AB1C3367C13E86A92E339EA8B075604A93ED3C.jpg)

   <br />

2. 点击"开通"按钮，您的请求提交后台后，将由指定管理员处理，此时SDK状态变为"待制作"。此项工作可能花费几个工作日，请您耐心等待。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.18274809940689539929191216775953:50001231000000:2800:4C3C4F58210DF84AD7D72F14857052FD9FD693E4B8AF967B59CBDBAE026C9185.jpg)

   <br />

3. 管理员完成SDK的制作后，页面上的SDK状态会指示为"已生成"

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.19803239170350117049387863956793:50001231000000:2800:91C4DC7C3ED51E4D1C33131BC13528D9555BDACC23DE7BEB2771F9D64D1EAF51.jpg)

   <br />

4. 您可以直接点击"下载"按钮进行SDK下载操作。

   <br />

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.00657846583828741630146735691172:50001231000000:2800:290C989C94B04FBEF94FE4F107DDC2E8192A8C6BEDE5FB2FC99350D357691F86.jpg)  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303110907.93031919597537549492480332138085:50001231000000:2800:7FADD55E17CFB38465EF444E7B9A4611282B6BB4A16B8D1CD27135A972F94F9B.png)  
   1. 下载的SDK压缩包中，将包括C语言和JAVA语言版本的接口及运行依赖库，以及API接口说明。
   2. 成功申请到SDK后，请您定期关注本页面。若SDK有版本更新，您也可在本页面下载最新版本。
