# 添加权限

App需要在Manifest文件中添加读取外部存储的权限。

```screen
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
```

> 说明
>
> Android 6.0及以上需要动态申请读取和写入外部存储权限，如果您以Android 10.0（API级别29）或更高版本为目标平台，还需要在应用的清单文件中将"requestLegacyExternalStorage"设置为"true"。
