# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。  

#### 配置编码器失败

开发者在配置编码器阶段使能了长期参考帧编码的功能，但设置的buffer数量超过了最大值10，导致配置失败。  

#### 部分特性设置后不生效

1. 可能当前平台不支持此特性，请您严格按照[应用开发](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/codec-develop-0000001064498497)中的用法，先判断平台是否支持此特性。
2. 可能设置的参数不正确，请按照[API参考](https://developer.huawei.com/consumer/cn/doc/development/Media-References/codec-api-overview-0000001064061063)中的限制设置参数。
