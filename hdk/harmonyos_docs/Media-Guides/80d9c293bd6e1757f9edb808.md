# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAV-Pipeline-video-playback)快速体验一个应用的开发过程。  

#### 开发环境

* [JDK](https://www.java.com/zh-CN/) 1.8及以上
* 安装[Android Studio](https://developer.android.com/studio?hl=zh-cn) 4.0及以上
  * minSdkVersion 28及以上
  * targetSdkVersion 28（推荐）
  * compileSdkVersion 29（推荐）
  * Gradle 6.3及以上（推荐）
* 测试应用的设备

  * 如果仅使用AV Pipeline框架，请使用EMUI 9.0及以上的华为手机或Android 9.0 \~ 12及以上的非华为手机。

  * 如果使用视频超分Pipeline或者声音事件检测Pipeline请使用华为EMUI 10.0及以上设备。

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-agc-0000001156342567)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/integrating-sdk-0000001156025441)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/config-obfuscation-scripts-0000001108985562)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/add-permissions-0000001155785473)|在"AndroidManifest.xml"文件中配置应用所需权限。|
|5|[视频播放Pipeline](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/video-playback-pipeline-0000001110539082)|调用AV Pipeline框架预置的视频播放Pipeline，可以完成基本的播放业务。|
|6|[视频超分Pipeline](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/video-super-resolution-pipeline-0000001110501562)|调用AV Pipeline框架预置的视频超分Pipeline，在播放时实现更高画质的体验。|
|7|[声音事件检测Pipeline](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sound-event-detection-pipeline-0000001156821439)|调用AV Pipeline框架预置的声音事件检测Pipeline，在播放音频的同时自动分辨音频中的事件内容。|
|8|[媒体资产管理](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/media-asset-management-0000001110379188)|您可以通过媒体资产管理API对媒体文件进行信息提取、媒体流管理、Buffer读取等。|
|9|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/pre-release-check-0000001156175231)|华为提供对应用自动检查的能力。|
|10|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/app-release-0000001108985564)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|
