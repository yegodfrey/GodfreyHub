# 1. 注册认证

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn/)网站上注册成为开发者并完成实名认证，详见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

# 2.签署华为开发者SDK服务使用合作协议

[SDK下载](https://developer.huawei.com/consumer/cn/devservice/doc/3180106 "SDK下载")时会提示用户登录并签署华为媒体服务使用协议，请认真阅读并作出选择。

# 3. 环境准备

* Android Studio开发环境
  * 建议版本v3.0.1及以上
* 手机开发环境
  * 手机处理器不低于kirin 980的华为手机
  * 目前暂不支持高通平台
  * 系统软件版本不低于EMUI 10.0

### 4.1.2 添加依赖库

1. 打开AndroidStudio项目级build.gradle文件。

2. 在allprojects-\>repositories里面配置相机能力的maven仓地址。

```
allprojects {
    repositories {
        google()
        jcenter()
        maven {
            url 'https://developer.huawei.com/repo/'
        }
    }
}
```

3. 在buildscript-\>repositories里面增加配置。

```
buildscript {
    repositories {
        maven {
            url 'https://developer.huawei.com/repo/'
        }
        google()
        jcenter()
    }
}
```

4.Gradle 7.0版本后，allprojects-\> repositories配置已迁移到项目级settings.gradle文件中。  

settings gradle 文件配置示例如下:

```
dependencyResolutionManagement  {
    ...
    repositories {
        google()
        jcenter()
        maven {
           url 'https://developer.huawei.com/repo/'
       }
    }
}
```

说明：仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

5. 打开应用级的build.gradle文件。

6. 在"dependencies"中添加如下编译依赖。

```
dependencies {
    implementation 'com.huawei.multimedia:camerakit:1.1.5'
}
```
