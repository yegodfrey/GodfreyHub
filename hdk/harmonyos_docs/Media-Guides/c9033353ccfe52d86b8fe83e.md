# 业务介绍

## 业务简介

视频编辑服务（Video Editor Kit）是华为快速构建视频编辑能力的服务，提供以下集成方式：

* 视频编辑UI SDK，提供产品级UI界面，集成简单。
* 视频编辑原子能力SDK，提供数百个底层能力接口，包含多个AI算法能力接口，可根据业务场景灵活选择。
* 视频编辑AI能力SDK，提供图形图像、音视频领域相关的AI智能剪辑能力，包体更小、接口更灵活、集成更便捷。
* 视频编辑屏幕录制SDK，提供功能丰富的产品级录屏能力，接口简单、集成接入快速。

这些方式涵盖了导入、编辑、渲染、导出、媒体资源管理、录屏、AI智能剪辑、AI趣味玩法等视频编辑能力，为您提供性能优异、简单易用、高兼容性的接口，帮助您轻松地构建应用。

您可根据使用场景选择不同的集成方式获取视频编辑能力。
> 注意
>
> UI SDK和原子能力SDK不可同时使用。

## 功能介绍

* 支持多视频、多图片快速删除、混合导入，可自由调整片段排放顺序和时长，快速进入编辑界面。为了更好的编辑操作体验，建议导入1080p及以下的视频。
* 支持剪辑基本操作，包括分割、删除、音量、比例、变速、画布、旋转、裁剪、动画、蒙版、镜像、复制、替换。
* 支持添加滤镜，可自由调整亮度、对比度、饱和度、色调、色温、锐化等参数。
* 支持添加关键帧，可以对资源位置、大小、角度、音量和特效参数添加关键帧。
* 支持画中画功能，在视频中插入另一视频，使原视频全屏播出的同时，在画面的小面积区域上同时播出插入的另一视频。
* 支持添加音乐/音效、录音和本地视频音频提取，可对音频淡入淡出、音量调节、变速等。
* 支持保存创作作品草稿，在创作作品列表中可删除草稿。
* UI SDK支持记录操作步骤功能，在视频编辑过程中可对操作步骤进行撤销、恢复操作。
* 支持导出视频，可抽取视频中任意一帧画面或导入相册中的图片作为封面，设置导出视频的分辨率（最高支持4K）和帧率（最高支持60帧）后，最终打包生成为MP4格式的视频。
* 原子能力SDK提供多种AI算法接口，包含专属滤镜、一键染发、人物追踪、精彩片段、一键动效、人脸遮挡、人像分割、头部分割和目标分割。
* 提供内容丰富的素材库供您使用，后续会不断丰富更新，并且会提供免费内容供使用。
* 支持将高分辨率视频降采样到低分辨率。
* AI能力SDK包体积更小，集成更简单灵活。集成此SDK可独立调用动态照片、一键微笑、AI着色、一键动效、精彩片段、美颜、一键染发、头部分割和目标分割AI能力。
* 屏幕录制SDK，提供全屏录制手机桌面、实时录音、后台录制等能力，支持多分辨率选择、多存储路径选择，助力游戏、直播等App快速、轻松实现录屏功能。

## 服务优势

* 接入方式多样 视频编辑服务提供产品级视频编辑UI SDK、视频编辑原子能力SDK、AI能力SDK、录屏SDK，接口丰富、开放性强、稳定可靠，节省开发时间，帮助您快速实现自有App的视频编辑功能。

* 功能丰富 为开发者提供视频导入、编辑、特效、贴纸、滤镜、导出、素材库等服务，功能丰富，满足用户多样的短视频创作需求。

* 媒资管理 开发者可自由编排SDK内素材信息，如服务接入站点、素材/栏目增删等，快速管理App素材。
