# 主界面

Petal Vivid Renderer是花瓣三维声工具的渲染器，以独立应用的方式打开。Renderer中最多可对128个对象进行管理，并将128个通道的输入信号以适用于用户定义的监听模式进行渲染及导出。支持双耳、2.0、5.1至7.1.4渲染导出，且支持WAV、ADM及Audio Vivid最新标准AV3A格式渲染导出。

Renderer支持48 kHz和96 kHz采样率的音频文件：

* 当采样率为48 kHz时，建议设置Buffersize为1024，最大通道数为128通道。
* 当采样率为96 kHz时，建议设置Buffersize为2048，最大通道数为64通道。

|序号|区域|说明|
|:-|:-----|:--------------------------------------|
|1|录制渲染导出|包含录制相关控制功能及渲染导出功能。|
|2|对象管理|可对128个对象进行管理操作，包括静音、分组、整组静音等。|
|3|3D视图|在3D空间展示声源小球的位置、扩散值及状态。调节扩散值圆点大小会随之发生变化。|
|4|电平展示|显示当前扬声器监听和双耳监听的输出电平，调节监听音量大小。|
|5|响度表|用于实时监测渲染后信号响度。|
|6|音箱调节|可对当前监听系统的扬声器增益进行调节或对扬声器进行静音。|
