# 业务介绍

> 注意
>
> 花瓣三维声目前仅支持Mac OS系统，支持的DAW有Nuendo11和Cubase12。

花瓣三维声（Petal Vivid）是一款华为自研的VST3三维声插件工具，可在支持VST3的数字音频工作站（以下简称DAW）中加载使用，辅助您进行三维声制作。本工具支持双耳、2.0、5.1至7.1.4的三维声渲染导出，且支持导出WAV、ADM及Audio Vivid标准的MP4(AV3A)格式。

花瓣三维声安装程序组件由Petal Vivid [Panner](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/p_home_screen-0000001270491016)，Petal Vivid [Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)和Petal Vivid [Return](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/return_main_screen-0000001323264517)组成：

* Petal Vivid Panner支持对已挂载该插件的音频进行空间位置编辑并将编辑后的音频与空间位置信息传入Petal Vivid Renderer进行空间渲染。
* Petal Vivid Renderer支持对收到的多对象音频进行三维声混音，以及录制三维声母带并渲染导出。
* Petal Vivid Return支持将Petal Vivid Renderer渲染后的混音数据发送至DAW。
