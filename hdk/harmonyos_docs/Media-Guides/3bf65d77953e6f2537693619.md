# 步进功能区域

展开步进区域，您可开启"步进"开关，打开步进模式对声源点位进行步进模式编辑。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152637.59938436522262314213899837559912:50001231000000:2800:49C81B555CBCC33DBE3BDB0346D8E5F99978271DDFAED121302D4EB7D94498F6.png?needInitFileName=true?needInitFileName=true)  
在[Renderer](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/ren_menu-0000001320731117)渲染播放时不支持步进区编辑操作。

Panner步进功能通过编辑每个步进的移动轨迹，编辑成功后声源点位将按照设定的轨迹随时间移动，最多支持编辑8个步进点。步进模式下分为关键点编辑及轨迹编辑两种形态，两种形态可通过选用各自的特有工具进行切换，同一个步进不支持同时进行两种形态的编辑。

如下图使用了关键点编辑工具，通过新增关键点编辑移动轨迹。
