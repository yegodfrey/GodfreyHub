# 原理介绍

视频编辑原子能力SDK提供丰富的原子接口，不包含UI界面，接口使用灵活。在进行开发之前，您需要完成必要的[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Media-Guides/config-agc-0000001101108580)工作，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347#section939003693314)，并且完成了本服务的[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001147588347)。

## 总体结构

Video Editor Kit核心模块是Editor管理器。它负责生成、保存并维护视频编辑原子能力SDK引擎运行时的上下文环境。每个Editor保存唯一的时间线，包含若干个视频泳道，音频泳道，贴纸文字泳道，特效泳道。每条视频泳道上可以添加若干个资源或特效，且资源上还可以添加各种内嵌特效，资源之间可以设置不同的转场效果。各模块协同工作以生成最终的视频效果。
