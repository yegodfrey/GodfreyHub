# 版本更新说明

## 1.6.0.300（2022-10-27）

|--------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:audiokit-player:1.6.0.300 **新增特性** 支持适配Android 13（targetSdkVersion=33）平台。|

> 说明
>
> 建议您使用最新版本的SDK，体验更丰富的音频服务功能。

## SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）5.0.0.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
