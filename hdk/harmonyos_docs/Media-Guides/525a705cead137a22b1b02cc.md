# 场景动效服务

#### 服务介绍

场景动效服务为您提供5种基础动效和9种高级动效。对于基础动效，支持多种基础动效的叠加使用。对于高级动效来说，不仅效果炫酷还支持用户交互，简单易用、趣味性强。  

#### 应用场景

提供渲染功能，可实现锁屏、壁纸和主题设计的动态效果。  

#### 开发步骤

场景动效服务需要您提供资源文件（包括图片和manifest.xml脚本），服务会解析manifest脚本（脚本中会标识使用的图片信息）并生成视图返回给第三方应用。

1. 准备待解析的资源文件，其中manifest脚本可以参见[场景动效xml规范说明文档](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/xml-introduction-0000001050439245)进行撰写。
2. 导入场景动效服务包。  

   ```
   "Java"
   import com.huawei.hms.image.render.*;
   ```

   ```
   "Kotlin"
   import com.huawei.hms.image.render.*;
   ```

3. 获取服务实例。  
   通过调用[getInstance](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerender-0000001050199303#section110384415579)(Context context, [RenderCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rendercallback-0000001050754791) callback)方法获取实例，调用该方法时需要实现[ImageRender.RenderCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rendercallback-0000001050754791)接口的[onSuccess](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rendercallback-0000001050754791#section3923121819378)([ImageRenderImpl](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262) imageRender)和[onFailure](https://developer.huawei.com/consumer/cn/doc/development/Media-References/rendercallback-0000001050754791#section985104054019)(int errorCode)方法。

   ```
   "Java"
   ImageRenderImpl imageRenderAPI;
   // 获取ImageRender对象
   ImageRender.getInstance(context, new ImageRender.RenderCallBack() {
       // 获取场景动效服务实例成功回调，返回场景动效服务实例
       @Override
       public void onSuccess(ImageRenderImpl imageRender) {
           imageRenderAPI = imageRender;
           ...
       }
       // 获取场景动效服务实例失败回调，返回错误码
       @Override
       public void onFailure(int errorCode) {
           ...
       }
   });
   ```

   ```
   "Kotlin"
   private fun initImageRender() {
       // 获取ImageRender对象    
       ImageRender.getInstance(this, object : RenderCallBack {
           // 获取场景动效服务实例成功回调，返回场景动效服务实例
           override fun onSuccess(imageRender: ImageRenderImpl) {          
               imageRenderAPI = imageRender            
               useImageRender()        
           }
           // 获取场景动效服务实例失败回调，返回错误码
           override fun onFailure(i: Int) {                   
           }   
       })
   }
   ```

4. 服务初始化。  
   服务初始化时需您传递待解析资源路径sourcePath和认证所需信息。只有通过校验，第三方应用才能使用场景动效服务。

   ```
   "Java"
   // 初始化ImageRender
   int initResult = imageRenderAPI.doInit(sourcePath);
   ```

   ```
   "Kotlin"
   // 初始化ImageRender
   val initResult = imageRenderAPI!!.doInit(sourcePath)
   ```

5. 获取渲染视图。

   您调用获取视图接口，场景动效服务会解析资源路径中的图片和脚本，并返回渲染后的视图给您。对于返回的高级动效视图，如跟手粒子、水波纹等，支持与用户进行交互。

   目前支持2种获取视图方式，方式如下：
   * 第一种方式，直接调用[getRenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section610812125816)()方法，返回渲染后的视图封装实例[RenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/renderview-0000001050439505)。该方法是同步方法。  

     ```
     "Java"
     // 获取RenderView视图
     RenderView renderView = imageRenderAPI.getRenderView();
     if (renderView.getResultCode() == ResultCode.SUCCEED) {
         View view = renderView.getView();
         ...
     }
     ```

     ```
     "Kotlin"
     // 获取RenderView视图
     val renderView = imageRenderAPI!!.renderView
     if (renderView.resultCode == ResultCode.SUCCEED) {
         val view = renderView.getView()
         ...
     }
     ```

   <!-- -->

   * 第二种方式，调用[getRenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section12789201013108)([IParseCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/iparsecallback-0000001054858021) callBack)，传入脚本解析结束时的回调接口，在脚本解析结束时执行某些操作。该方法是异步方法。

6. 控制基础动画播放、停止和暂停、恢复。
   1. 播放动画。返回给您的基础动效视图（如旋转、位移、缩放等）默认不播放，需要调用[playAnimation](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderinterface-0000001050439501#section207934564566)()来播放动画。  

      ```
      "Java"
      // imageRender播放renderView动画
      if (null != imageRenderAPI) {
          imageRenderAPI.playAnimation();
      }
      ```

      ```
      "Kotlin"
      // imageRender播放renderView动画
      if (null != imageRenderAPI) {
          val playResult = imageRenderAPI!!.playAnimation()
      }
      ```

   2. 暂停动画。当您需要暂停基础动效时，调用该接口。 调用[pauseAnimation](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section529189173412)(boolean isEnable)接口实现暂停所有基础动画，并开始播放"暂停动画"（需要与基础动画的name属性配合使用）。

      ```
      "Java"
      // imageRender暂停renderView动画。传参为true时表示暂停所有基础动画，并开始播放“暂停动画”；传参为false时，表示暂停所有基础动画，并且不播放“暂停动画”。
      if (null != imageRenderAPI) {
          imageRenderAPI.pauseAnimation(true);
      }
      ```

      ```
      "Kotlin"
      // imageRender暂停renderView动画。传参为true时表示暂停所有基础动画，并开始播放“暂停动画”；传参为false时，表示暂停所有基础动画，并且不播放“暂停动画”。
      if (imageRenderAPI != null) {
          val result = imageRenderAPI!!.pauseAnimation(true)
      }
      ```

   3. 恢复动画。当您需要恢复暂停的基础动效时，调用该接口。  

      ```
      "Java"
      // imageRender恢复renderView动画
      if (null != imageRenderAPI) {
          imageRenderAPI.resumeAnimation();
      }
      ```

      ```
      "Kotlin"
      // imageRender恢复renderView动画
      if (imageRenderAPI != null) {
          val result = imageRenderAPI!!.resumeAnimation())
      }
      ```

   4. 停止动画。当您需要停止基础动效时，调用[stopAnimation](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section8548640105813)()。  

      ```
      "Java"
      // imageRender停止renderView动画
      if (null != imageRenderAPI) {
          imageRenderAPI.stopAnimation();
      }
      ```

      ```
      "Kotlin"
      // imageRender停止renderView动画
      if (null != imageRenderAPI) {
          val playResult = imageRenderAPI!!.stopAnimation()
      }
      ```

7. 您向Image Kit传递信息。

   您可通过[setKeyValueInfo](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section999080141192842)(String key, Object ...value)方法向Image Kit传递信息。

   其中key为String类型，目前只支持"SetVariable"。value为java.lang.Object类型，可传入多个参数，目前单个参数支持String、int、boolean和float类型，多个参数只支持String类型。  
   [RenderObject](https://developer.huawei.com/consumer/cn/doc/development/Media-References/renderobject-0000001054553469)为Image Kit返回给您的结果。

   ```
   "Java"
   // 设置manifest脚本中名为“var”的变量值为1
   String key = "SetVariable";
   String name = "var";
   String value = "1";
   RenderObject renderObject = imageRenderAPI.setKeyValueInfo(key, name, value);
   ```

   ```
   "Kotlin"
   // 设置manifest脚本中名为“var”的变量值为1
   var key = "SetVariable"
   var name = "var"var 
   value = "1"
   var renderObject: RenderObject = imageRenderAPI.setKeyValueInfo(key, name, value)
   ```

8. 录制动效。通过调用[startRecord](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section1741713043192842)和[stopRecord](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section1384017611109)接口录制动效。
   1. 开始录制。  
      通过调用[startRecord](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section1741713043192842)开始录制动效，支持视频MP4和GIF两种格式。入参json包括录制类型、压缩比和帧率信息。最终录制结果通过[IStreamCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/istreamcallback-0000001054922339)接口的回调方法返回。

      ```
      "Java"
      // 开始录制
      int resultCode = imageRenderAPI.startRecord(json, new IStreamCallBack () {
          // 在录制成功回调中，将视频或GIF字节数组保存成mp4或GIF文件
          @Override
          void onRecordSuccess(HashMap<String, Object> map) {
              ...
              String recordType = (String) hashMap.get("recordType");
              byte[] videoBytes = (byte[]) hashMap.get("videoBytes");
              byte[] gifBytes = (byte[]) hashMap.get("gifBytes");
              try {
                  if (recordType.equals("1")) {
                      if (videoBytes != null) {
                          // 保存mp4文件
                          saveFile(videoBytes, mp4Path);
                      }
                  } else if (recordType.equals("2")) {
                      ...
                  } else if (recordType.equals("3")) {
                      ...
                  }
              } catch (IOException e) {
                  ...
              }
              ...
          }

          // 录制失败回调
          @Override
          void onRecordFailure(HashMap<String, Object> map) {
              ...
          }

          // 录制进度回调，progress取值范围为0-100
          @Override
          void onProgress(int progress) {
              runOnUiThread(new Runnable() {
                  @Override
                  public void run() {
                      textProgress.setText("当前录制进度：" + progress + "%");
                  }
              });
          }
      });

      // 保存文件
      private void saveFile (byte[] bytes, String path) throws IOException {
          FileOutputStream fos = new FileOutputStream(new File(path));
          try {
              fos.write(bytes, 0, bytes.length);
              fos.close();
          } catch (IOException e) {
              Log.e(TAG, e.getMessage());
          } finally {
              try {
                  fos.close();
              } catch (IOException e) {
                  Log.e(TAG, e.getMessage());
              }
          }
      }
      ```

      ```
      "Kotlin"
      // 录制成功回调
      val start = imageRenderAPI!!.startRecord(result, object : IStreamCallBack {
          override fun onRecordSuccess(hashMap: HashMap<String, Any>) {

      }

      // 录制进度回调，progress取值范围为0-100
      override fun onProgress(progress: Int) { 
          showRecordProgress(progress)
      }
      private fun showRecordProgress(progress: Int) {
          runOnUiThread { 
              textProgress!!.text = "progress:$progress%" 
          }
      }

      // 保存文件
      private fun saveFile(bytes: ByteArray, path: String) {
          val fos = FileOutputStream(File(path))try {

              fos.close()
          } catch (e: IOException) {
              Log.e(TAG, e.message)
          } finally {
              try {
                  fos.close()
              } catch (e: IOException) {
                  Log.e(TAG, e.message)
              }
          }
      }
      ```

      入参Json：  

      |参数|类型|M/O（必选/可选）|说明|
      |:---------|:-----|:---------|:------------------------------------------------|
      |recordType|int|M|录制类型，取值{1，2，3}。 * 1：录制视频 * 2：录制GIF * 3：同时录制视频和GIF|
      |videoScale|double|O|视频压缩比，取值范围为\[0.5,1\]，只保留一位小数。录制视频时该参数必选。|
      |videoFps|int|O|视频帧率，取值范围为\[5,20\]。录制视频时该参数必选。|
      |gifScale|double|O|GIF压缩比，取值范围为\[0.1,0.5\]，只保留一位小数。录制GIF时该参数必选。|
      |gifFps|int|O|GIF的帧率，取值范围为\[10,20\]。录制GIF时该参数必选。|

      Json示例：

      ```
      {"recordType":3;
         video{
          "videoScale":0.5      
          "videoFps":16
         }
         gif{
          "gifScale":0.3
          "gifFps":16
         }
      }
      ```

   ```
   "Java"
   int resultCode = imageRenderAPI.stopRecord();
   ```

   ```
   "Kotlin"
   val result = imageRenderAPI!!.stopRecord()
   ```

9. 通过调用[unBindRenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section17188143833014)和[bindRenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section131908383308)接口实现多Activity复用同一个[RenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/renderview-0000001050439505)。

   一般是在A页面[getRenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section610812125816)()获取到renderView实例，并且已经显示renderView的情况下，A页面跳转到B页面，可以在A的onPause()中进行解绑，B的onResum()中调用[bindRenderView](https://developer.huawei.com/consumer/cn/doc/development/Media-References/imagerenderimpl-0000001050197262#section131908383308)接口进行绑定，在B页面中，不用进行初始化，renderView即可显示。
   * 解绑。

   ```
   "Java"
   // 获取渲染的视图
   RenderView renderView = imageRenderAPI.getRenderView();
   // 获取渲染视图view的哈希值
   String hashCode = String.valueOf(renderView.getView().hashCode());
   @Override
   protected void onPause() {
       super.onPause();
       if (null != imageRenderAPI) {
           // 在onPause方法中，调用unBindRenderView方法解绑已加载的视图
           int result = imageRenderAPI.unBindRenderView(hashCode);
       }
   }
   ```

   ```
   "Kotlin"
   // 获取渲染的视图
   var renderView: RenderView = imageRenderAPI.getRenderView()
   // 获取渲染视图view的哈希值
   var hashCode: kotlin.String = String.valueOf(renderView.getView().hashCode())
   override fun onPause() {
       super.onPause()   
       if (null != imageRenderAPI) {
           // 在onPause方法中，调用unBindRenderView方法解绑已加载的视图
           imageRenderAPI!!.unBindRenderView(hashCode)    
       }
   }
   ```

   * 绑定。需要实现[IBindCallBack](https://developer.huawei.com/consumer/cn/doc/development/Media-References/ibindcallback-0000001054888276)接口，在[onBind](https://developer.huawei.com/consumer/cn/doc/development/Media-References/ibindcallback-0000001054888276#ZH-CN_TOPIC_0000001054888276__onRecordSuccess-java_util_HashMap-)方法中将渲染视图加到容器中进行显示。

   ```
   "Java"
   @Override
   protected void onResume() {
       super.onResume();
       if(imageRenderAPI==null){
           return;
       }
       // 调用bindRenderView绑定视图，需传入资源存储路径，并实现IBindCallBack接口
       imageRenderAPI.bindRenderView(sourcePath, new IBindCallBack() {
           // 绑定视图回调，返回渲染的视图和结果码
           @Override
           public void onBind(RenderView renderView, int resultCode) {
               if (renderView != null) {
                   if (renderView.getResultCode() == ResultCode.SUCCEED) {
                       final View view = renderView.getView(); 
                       if (null != view) {
                           contentView.addView(view);
                       } else {
                           ...
                       }
                   }
               }
           }

           // 脚本解析结束回调
           @Override
           public void onParseEnd() {
               if (null != imageRenderAPI) {
                   String name = "var";
                   String value = "1";
                   imageRenderAPI.setKeyValueInfo("SetVariable", name, value); 
                   imageRenderAPI.playAnimation(); 
               }
           }
       });
   }
   ```

   ```
   "Kotlin"
   // 调用bindRenderView绑定视图，需传入资源存储路径，并实现IBindCallBack接口        
   override fun onResume() {
       super.onResume()    
       if (null != imageRenderAPI) {
          // 调用bindRenderView绑定视图，需传入资源存储路径，并实现IBindCallBack接口
           imageRenderAPI!!.bindRenderView(
               sourcePath,
                           object : IBindCallBack {
                   override fun onBind(renderView: RenderView, i: Int) {
                   if (renderView != null) {
                       if (renderView.getResultCode() == ResultCode.SUCCEED) {
                           val view = renderView.getView()
                           if (null != view) {
                               contentView!!.addView(view)
                               hashCode = view.hashCode().toString()
                               }
                           }
                       }
                   }
                   override fun onParseEnd() {}
               })
       }
   }
   ```

10. 释放渲染视图。  
    当不再需要场景动效视图时，调用该接口释放资源

    ```
    "Java"

    if (null != imageRenderAPI) {
        imageRenderAPI.removeRenderView();
    }
    ```

    ```
    "Kotlin"
    //销毁视图
    if (null != imageRenderAPI) {
        imageRenderAPI!!.removeRenderView()
    }
    ```
