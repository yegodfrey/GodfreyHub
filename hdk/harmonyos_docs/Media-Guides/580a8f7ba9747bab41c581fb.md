# SDK介绍

开发者除了使用华为终端上提供的系统级DRM能力外，还可以使用华为数字版权服务提供端侧的SDK集成到APP中，从而可以具备软件级DRM能力。当前SDK仅支持Android和HarmonyOS平台。支持C语言和JAVA语言接口API。
> 注意
>
> 1. 当前SDK仅开放给注册地为中国区开发者申请。开发者申请到SDK后，集成的APP不限于中国区，可在全球服务用户。
> 2. 每个SDK嵌入开发者独特的标识，仅限自用，严禁扩散。
