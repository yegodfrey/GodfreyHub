# 证书列表

Video Kit播放器SDK与服务端采用HTTPS通信，客户端会对服务器的证书进行合法性校验。

1.0.2.301及以上版本支持的证书列表如下，后续如果有新增证书，Video Kit播放器SDK会通过在线更新。

如果播放地址的根证书不在当前列表中，则会播放失败。
