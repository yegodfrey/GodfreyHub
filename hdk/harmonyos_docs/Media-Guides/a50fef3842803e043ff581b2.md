# 录制渲染导出

录制相关控制功能及渲染导出功能区域，包含启动录制、暂停录制、停止录制、重置录制、录制时间显示、选择时间段录制及渲染导出功能。

1. 点击录音开关![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152639.29129106052273339960408902998190:50001231000000:2800:D1F179A01ECE8FF1D1CB7BBF23CB21DC1B251AA0129812E13F3A20A7C58D4D86.png?needInitFileName=true?needInitFileName=true "点击放大")，Renderer将处于准备录制阶段，当DAW播放时便开始录制，录制的时间位置与DAW播放位置相同。
2. 再次点击录音开关，则暂停录音。
3. 点击停止键![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152639.66950557363888899374657813801117:50001231000000:2800:FE4D6FC16CB12082357497E0E05DEF4BC2CEBAD7DB578D071277B44F1CFF532D.png?needInitFileName=true?needInitFileName=true "点击放大")，则会停止录音并生成录音母版文件。
4. 停止后再次打开录音开关则会新建一个录音。
5. 录音支持选择时间段进行录制。
6. 渲染导出支持WAV、ADM及MP4(AV3A)格式导出。
   * WAV格式导出支持采样率44.1kHz、48kHz、88.2kHz、96kHz。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152639.60976616173193872871323082053067:50001231000000:2800:C7332C7F336DBCED869D59A0A1424F9C7E8DA4F67D5F9DBF4240E0D8B3138B87.png?needInitFileName=true?needInitFileName=true "点击放大")

   * ADM格式导出支持采样率44.1kHz、48kHz、88.2kHz、96kHz。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152639.50933764711367248610144114493492:50001231000000:2800:0C0BB4CA50FE2A57F5FDF063707455AA22983E4A070DF4DCA2D86CADCBA56855.png?needInitFileName=true?needInitFileName=true "点击放大")

   * MP4(AV3A)格式导出支持采样率44.1kHz、48kHz、96kHz。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152639.66143741966462431217368056193020:50001231000000:2800:290CA51369A7D7D9CD2E94847A20385547BED382E7BCF102F70C2D5A5A6067C2.png?needInitFileName=true?needInitFileName=true "点击放大")

7. 点击录制完成后，Renderer录制停止，显示录制文件正在处理中。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152639.11660134816068107522439928530375:50001231000000:2800:F36E5636B24B206D89FE8FD2231D95C29E0E77B4012E064BFB7479BC6CB60863.png?needInitFileName=true?needInitFileName=true "点击放大")

   渲染导出支持所有的渲染模式：双耳、2.0、5.1、5.1.2、7.1、7.1.2、7.1.4。
