# 集成HMS Core SDK

1. 创建Android Studio Project。

   在Android Studio中创建一个工程"example"，选择"Native C++"，会默认生成一个native-lib.cpp文件及CmakeLists.txt文件，目录树如下：

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231128170822.80774968256448660954043351226552:50001231000000:2800:8D14FCB073DFF37F3FF5B9D3E47B6D0CC4C6EA912F566A3CBABEF5179DF158F2.png?needInitFileName=true?needInitFileName=true)
2. 修改"/app/build.gradle"文件，指定CMake编译C++文件。
   * 修改android层级下的"compileSdkVersion"和"buildToolsVersion"。
   * 修改defaultConfig层级下的编译参数"minSdkVersion"和"targetSdkVersion"。
   * 修改externalNativeBuild层级下的"cmake"选项。
   * 配置NDK过滤项，目前HDR Vivid SDK只支持"arm64-v8a"和"armeabi-v7"，暂不支持x86和x86_64。
   * 在android层级下配置sourceSets，指定""jniLibs.srcDirs""路径。

     ```
     android {
         compileSdkVersion 31
         buildToolsVersion "30.0.3"

         defaultConfig {
             applicationId "com.huawei.hms.videokit.hdrvivid.videokitdemo"
             minSdkVersion 24
             targetSdkVersion 31
             versionCode 10014301
             versionName "1.0.14.301"

             testInstrumentationRunner "androidx.test.runner.AndroidJUnitRunner"
             externalNativeBuild {
                 cmake {
                     cppFlags ''
                 }
             }
             ndk {
                 abiFilters "armeabi-v7a", "arm64-v8a"
             }
         }

         buildTypes {
             release {
                 minifyEnabled false
                 proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
             }
         }
         compileOptions {
             sourceCompatibility JavaVersion.VERSION_1_8
             targetCompatibility JavaVersion.VERSION_1_8
         }

         sourceSets {
             main {
                 jniLibs.srcDirs = ['src/main/jniLibs']
             }
         }

         externalNativeBuild {
             cmake {
                 path file('src/main/cpp/CMakeLists.txt')
             }
         }
         buildFeatures {
             viewBinding true
         }
     }
     ```

3. 复制库和头文件。
   1. 下载[HDR Vivid SDK](https://developer.huawei.com/consumer/cn/doc/Media-Library/sdk-download-0000001050199313#ZH-CN_TOPIC_0000001050199313__p99161544308)，并解压。
   2. 复制SDK头文件HdrVividKits.h到Android Studio下的"src/main/cpp/include"。

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231128170822.97066790383996019948973231317789:50001231000000:2800:C4A808A31177506ABA03859C5197EB390D1608A5B4BCB3C95F27F0103990C98B.png?needInitFileName=true?needInitFileName=true)
   3. 复制SDK的动态库到资源库。
      * 将SDK中"android\\arm64-v8a\\libhdr_pro_engine.so"、"android\\arm64-v8a\\libvideokit_hdrvivid.so"复制到Android Studio下的"jniLibs/arm64-v8a"。
      * 将SDK中"android\\armeabi-v7a\\libhdr_pro_engine.so"、"android\\armeabi-v7a\\libvideokit_hdrvivid.so"复制到Android Studio下的"jniLibs/armeabi-v7a"。

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231128170822.88295831416961483843495105698259:50001231000000:2800:E7D86FA03484C90A02980E9945A36EC317213D4232111155DC87D257B0625988.png?needInitFileName=true?needInitFileName=true)
   4. 修改"app/src/main/cpp/CMakeLists.txt"文件，请使用以下代码替换创建Android Studio Project后生成的CMakeLists.txt。

      ```
      # CMake最低版本为3.10.2
      cmake_minimum_required(VERSION 3.10.2)

      # so导入路径
      link_directories(${CMAKE_CURRENT_SOURCE_DIR}/../jniLibs/${ANDROID_ABI})

      # 源码文件清单
      add_library(
              SimpleJni
              SHARED
              SimpleJni.cpp)

      # 头文件包含目录
      target_include_directories(SimpleJni PRIVATE
              ${CMAKE_CURRENT_SOURCE_DIR}/include)

      # 依赖log模块
      find_library(
              log-lib
              log)

      target_link_libraries(
              SimpleJni
              videokit_hdrvivid
              ${log-lib})
      ```

   5. 默认生成的"native-lib.cpp"需修改为"SimpleJni.cpp"，修改"MainActivity.java"中加载的so名称。

      ```
      System.loadLibrary("SimpleJni");
      ```

4. 同步工程，点击"Sync Project with Gradle Files"即可。
