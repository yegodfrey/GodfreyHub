# MediaFilter

## 背景信息

本节的接入方式为[从C++层接入](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/integrating-sdk-0000001156025441#section1143033914488)。

AV Pipeline提供高性能AI插件（包括视频超分插件和声音事件检测插件），也提供了包含这些插件的预置Pipeline（包括[视频超分Pipeline](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/video-super-resolution-pipeline-0000001110501562)、[声音事件检测Pipeline](https://developer.huawei.com/consumer/cn/doc/development/Media-Guides/sound-event-detection-pipeline-0000001156821439)）。

由于Pipeline形式的业务场景封装程度较高，若您需要直接使用单个AI插件，可采用MediaFilter类实现。

MediaFilter实现一个简单的Pipeline，由以下三部分组成。

* DataSource：接收用户写入的数据。
* DataSink：上报AI插件产生的buffer或事件。
* AI插件：进行AI处理。以视频超分插件为例，其配置文件CVFilterPipeline.xml如下。

```screen
<?xml version="1.0"?>
<Nodes>
    <node id="0" name="DataSource" mime="video/data-source" type="source">
        <next id="1"/>
    </node>
    <node id="1" name="CVFilter" mime="video/filter" type="filter">
        <next id="2"/>
    </node>
    <node id="2" name="DataSink" mime="video/data-sink" type="sink">
    </node>
</Nodes>
```

## 开发步骤

使用MediaFilter调用视频超分插件的操作如下。

1. 创建[MediaMeta](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediameta-0000001159875293)。写入视频超分插件所需的信息，例如graph路径、模型文件路径等。

   ```screen
   MediaMetaSP meta = MediaMeta::Create();
   // 设置配置文件的路径
   meta->SetValue<string>(MEDIA_GRAPH_PATH, "/sdcard/Download/CVFilterPipeline.xml"); 
   // 设置模型文件的路径
   meta->SetValue<string>(MEDIA_ASSETS_PATH_PREFIX, "/sdcard/Download");
   // 使能超分
   meta->SetValue<int32_t>(MEDIA_ENABLE_CV, 1);
   ```

2. 创建[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310)实例。

   ```screen
   // 用dlopen的方式打开libmediafilter.so
   void *phandle = dlopen("libmediafilter.so", RTLD_NOW | RTLD_GLOBAL);
   if (phandle == nullptr) {
       ALOGE("dlopen failed, %s", dlerror());
       return;
   }
   // 获取创建MediaFilter的函数的句柄
   void *sym = dlsym(phandle, "CreateMediaFilter");
   if (sym == nullptr) {
       ALOGE("get symbol failed, %s", dlerror());
       dlclose(phandle);
       return;
   }
   using CreateMediaFilterFunc = shared_ptr<MediaFilter>(*)(const MediaMetaSP &meta);
   auto fun = reinterpret_cast<CreateMediaFilterFunc>(sym);
   // 调用该函数，创建MediaFilter实例
   std::shared_ptr<MediaFilter> mFilter = fun(meta);
   if (mFilter == nullptr) {
       dlclose(phandle);
       return;
   }
   ```

3. 设置回调，并调用[Start](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310#section7652151312512)启动[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310)。

   ```screen
   struct MediaFilterTestBase : MMListener {
       void OnBuffer(MediaBufferSP buffer, MediaType type) override {
           // AI插件会将处理后的buffer通过该回调返回
       }
       void OnMessage(int msg, int param1, int param2, MediaParcelSP) override {
           // AI插件会将处理过程中产生的消息通过该回调返回
       }
   };
   mFilter->SetListener(make_shared<MediaFilterTestBase>());
   mFilter->Start();
   ```

4. 将待处理的数据构造成[MediaBuffer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediabuffer-0000001113395492)，通过[WriteBuffer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310#section83327129552)传递给[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310)。处理后的buffer会通过[OnBuffer](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mmlistener-0000001113385740#section727132014246)回调来返回。

   ```screen
   MediaBufferSP buffer;
   mFilter->WriteBuffer(buffer, MT_VIDEO);
   ```

5. 调用[Stop](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310#section1435810561515)停止处理，并销毁[MediaFilter](https://developer.huawei.com/consumer/cn/doc/development/Media-References/mediafilter-0000001113503310)。

   ```screen
   mFilter->Stop();
   mFilter.reset();
   ```
