# ADM批量转码

1. 点击"工具"，选择"格式转换"。
2. "格式转换"功能主页面如下图所示，请查看下方表格了解各功能。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152640.91594710863734154324282285511200:50001231000000:2800:E9C10A7CA0051392BFFA96B77E45F45D492403DB1C0286E470E888C534CB6CD1.png?needInitFileName=true?needInitFileName=true "点击放大")  

   |序号|功能|说明|
   |:-|:-----|:----------------------|
   |1|添加文件|可选择一个或者多个ADM文件。|
   |2|清空|三种状态：列表为空、列表有数据、列表正在转换。|
   |3|总数|最多可导入100个文件。|
   |4|输出文件路径|可选择文件路径。|
   |5|输出格式|MP4(AV3A)。|
   |6|取消|有任务时显示"取消"，可终止任务。|
   |7|立即转换|添加文件后，显示可操作状态。|
   |8| | |
   |9| | |
   |10| | |

3. 文件上传后，点击"立即转换"，格式转换才会启动。下图所示文件正在转换中，您可以查看待转换文件信息及目标格式转换进度及结果，并进行暂停、重启、删除等操作。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230918152640.58017559193734378763031744565848:50001231000000:2800:3D83A084495B3D0707E917E2E5C6729D6FBAD0CC8B617F79EABD02089A73B9CB.png?needInitFileName=true?needInitFileName=true "点击放大")

   |序号|功能|说明|
   |:-|:-|:------------------|
   |1|列表|名称、格式、时长、状态、进度、操作。|
   |2|状态|正在处理、已暂停、转换异常、正在等待。|
   |3|操作|暂停、重启、删除。|
