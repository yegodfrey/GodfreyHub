# 在Huawei DevEco Studio中集成DataSecurity Engine SDK

> 说明
>
> HUAWEI DevEco Studio目前处于Beta阶段，需要向华为申请试用权限。同时也期待您在使用过程中给我们反馈您宝贵的意见，我们将持续进行优化，提升您的使用体验。

在使用HUAWEI DevEco Studio进行应用开发前，您应该提前知道如何"[获取Beta权限](#section12701848131812)"和"[获取技术支持](#section76292349228)"通道。

## 获取Beta权限

您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。

1. 访问[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
2. 注册华为开发者联盟帐号，并点击右上角头像旁边的下拉图标，点击"立即前往实名认证"上传信息进行实名认证。
3. 实名认证后，在开发者联盟网站中选择"开发 > 开发工具 > HUAWEI DevEco Studio"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115404.44033518065856479506245290624721:50001231000000:2800:A74C34F53AECACEC87E1F7D551C32028518F8361DACBD3FB6BFDEE11BE34B310.png?needInitFileName=true?needInitFileName=true)
4. 点击"试用申请"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115404.77701869821026821629884830268922:50001231000000:2800:3730358034A6C4BE901E20835840C38218A43E275C70FF3CB8237B5064707133.png?needInitFileName=true?needInitFileName=true)
5. 点击"我要报名"，并填写报名信息后，提交给华为进行审核。 说明
   >
   > 提交申请后，华为将在三个工作日内对您的申请进行处理，并会及时通知您审批结果，请耐心等待。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115404.32648974903193610939623101784118:50001231000000:2800:4F2508D5366E64D6525454FDD127CD73CEDA5D0A044020BE46BB349A9FA63505.png?needInitFileName=true?needInitFileName=true)

## 获取技术支持

您在使用Huawei DevEco Studio时，如果您有任何的问题或建议，都可以通过如下两种方式与我们取得联系。

1. 在线工单：登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)，在菜单栏选择"支持 > 技术支持 > 在线提单"，进入在线提单页面提交工单。
2. 人工服务：您可以通过扫描如下二维码添加"华为DevEco小助手"，然后向我们的小助手进行反馈。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115404.99335192170463962928086792659181:50001231000000:2800:48770333B14A4208AEE0D6CE7D7253BA04EB84374AA5B7A7641F9FFA34F85B47.png?needInitFileName=true?needInitFileName=true)

## 安装和配置DevEco Studio

获取Beta权限后，您就可以下载HUAWEI DevEco Studio软件进行开发了。

1. 登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)。
2. 点击右上角"管理中心"，然后在"应用服务 > 开发服务"中，勾选"HUAWEI DevEco Studio"卡片，然后点击"关闭"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115404.11533707589946531728244010242662:50001231000000:2800:432472AC5E5D00F7C6448AEFA38C1283061492E25CE3C965125A27FA747908EF.png?needInitFileName=true?needInitFileName=true)
3. 在开发服务中，点击"HUAWEI DevEco Studio"卡片，阅读和签署Beta保密协议。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115405.72269232330787412996948814903151:50001231000000:2800:819C3FEF84D28FA4C43B623EA7529968066DE3C193893F707AC0093DBA8C58A0.png?needInitFileName=true?needInitFileName=true)
4. 下载DevEco Studio软件包。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115405.16865903178087311903459828668801:50001231000000:2800:A06E66F7028DC398F2C4E36F4FB3578FCA9F04407D9E1D9850928F87286955E9.png?needInitFileName=true?needInitFileName=true)

   软件包下载完成后，请根据DevEco Studio使用指南中的[安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/install-0000001050028630)和[配置DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/config-guide-0000000000034467)章节完成环境的安装和配置。

## 添加DataSecurity Engine SDK的依赖库

1. 在工具主界面，打开 "Tools > EMUI Kit > Kit Manager"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115405.35156072511417169664414338786109:50001231000000:2800:C7349304AEBD82CD966C7DA2E14B12D76081E09731A4FC0DBFAD99C26FCEF04D.png?needInitFileName=true?needInitFileName=true)
2. 勾选DataSecurity Engine，点击"Apply"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115405.77409552731288978215102481021236:50001231000000:2800:2CCA0228FF7B2669DDAA74CAB8C53CC2CFB803AB06D40520C1FE82730147825A.png?needInitFileName=true?needInitFileName=true)
3. 等待添加完成，在build.gradle配置文件中检查，依赖库已经添加成功。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115405.72482085887791964061525572823475:50001231000000:2800:17CBE65C07ABF98BD3A26524EC3EFF8418E4C6126DAD19166B8FD9BF1D6519F8.png?needInitFileName=true?needInitFileName=true)
4. 打开 "Tools > EMUI Kit > Kit Assistant"，在"Kit Assistant"界面，点击"Security"，可以显示DataSecurity Engine sSDK的全部功能。
