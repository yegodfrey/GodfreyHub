# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## Keyring客户端

### 使用Keyring有哪些约束条件？

* EMUI 5及以上的华为手机、平板以及Android 7.0及以上的非华为手机、平板才支持Keyring。
* 关闭锁屏密码后，之前保存的userAuth为true的凭据失效。
* Web应用只支持华为浏览器。
* 快应用只支持华为快应用引擎。
* 手机运行环境不安全的情况下，例如：被root或解锁后，不能使用。

## 安全问题

### 卸载Android应用后，用户如何删除凭据？

Android应用卸载后，它创建的凭据和共享关系都会删除。

## Android应用与快应用、Web应用间的共享问题

### 不同形态的应用之间是否可以共享凭据？

可以在Android应用、快应用、Web应用之间相互共享。

华为浏览器提供凭据管理的JS API，供Web应用使用。

华为快应用引擎提供凭据管理的JS API，供快应用使用。

### 如何保障授权的安全性？

Keyring会存储授权关系，授权关系由开发者进行定义，包括被授权的Android应用和快应用的包名、证书指纹，以及Web应用的域名，不在共享范围内的Android应用、快应用、Web应用不能读取。

## 开发相关问题

### 出现 "1212" 错误码的原因和处理建议？

Keyring在用户设备上是动态升级和安装的，当前已覆盖绝大部分活跃设备，当由于网络或其它原因Keyring未安装或更新到用户设备上，会返回1212错误码。

推荐您跳过Keyring相关功能，使用原有的登录流程，当Keyring升级安装完成后，您就可以使用了。

### 出现 "907135000：传入的参数错误" 错误码时如何处理？

* 检查agconnect-services.json文件中的app_id、package_name参数是否正确，build.gradle文件中证书签名是否配置。
* HMS Core缓存导致的，请先卸载并更新HMS Core，然后断开网络再连接，再打开App。

### 在Android 11上，已安装HMS Core（APK）最新版本，仍然提示升级，如何解决？

Android 11更改了应用查询用户在设备上已安装的其他应用以及与之交互的方式。您应用的targetSdkVersion是30或者更高版本，并且集成的Keyring 6.1.1.302之前版本时，将无法访问HMS Core（APK），并且持续提示升级。

您可以通过以下两种方法解决。

* 方法一： 升级Keyring 的SDK至6.1.1.302及以上版本，版本信息请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/version-change-history-0000001179180527)。


* 方法二： 如果不升级SDK，需要在"AndroidManifest.xml"中manifest下添加<queries>标签。

  ```screen
  <manifest ...>
      ...
      <queries>
          <intent>
              <action android:name="com.huawei.hms.core.aidlservice" />
          </intent>
      </queries>
      ...
  </manifest>
  ```

  > 说明
  >
  > <queries>标签对工具的要求如下：
  > * Android Studio需升级至3.3或更高版本。
  > * Android Gradle插件需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。
