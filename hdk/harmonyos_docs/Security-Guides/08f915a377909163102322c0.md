# 使用说明

#### 使用前准备

使用文件分级保护能力前，需要导入以下类：

```
import android.content.Context;
import com.huawei.fileprotect.HwSfpPolicyManager;
```

#### 设置标签

开发者根据数据的重要性，为文件设定安全等级标签，由系统提供配套的安全保护。

1. 获取[HwSfpPolicyManager](https://developer.huawei.com/consumer/cn/doc/Security-References/hwsfppolicymanager-0000001163500889)的实例，可调用设置和查询文件风险等级的方法。

   ```
   HwSfpPolicyManager policyManager = HwSfpPolicyManager.getDefault();
   if (policyManager == null) {
       return;
   }
   ```

2. 设置标签。

   输入上下文信息、需要设置风险等级的文件绝对路径和文件名称（filePath）、标签值（S0、S1、S2、S3、S4）以及标签的辅助信息flag，可设置文件的风险等级。具体参数的含义参见[setLabel](https://developer.huawei.com/consumer/cn/doc/Security-References/hwsfppolicymanager-0000001163500889#section9421173615720)。

   ```
   // 示例:设置风险等级为S3，标签值的辅助信息flag  = 0x0001.
   int flag  = 0x0001;
   int errorCode = policyManager.setLabel(context, filePath,
       HwSfpPolicyManager.LABEL_NAME_SECURITY_LEVEL,
       HwSfpPolicyManager.LABEL_VALUE_S3, flag);
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115405.53090467989615970103658862818440:50001231000000:2800:3365A107CFCF95B20C064F3DA60C9FFBE2FA271831CA2B67CA5EB77B9DC70B5C.png?needInitFileName=true?needInitFileName=true)  
   标签值的辅助信息flag，可取值的范围为0或1。仅当标签值为S3时有意义，具体含义如下：flag = 0 表示锁屏不可打开、不可读写文件；flag = 1表示锁屏下可以新增文件，对于已经打开的文件，可以继续读写该等级文件。

#### 获取标签

1. 获取[HwSfpPolicyManager](https://developer.huawei.com/consumer/cn/doc/Security-References/hwsfppolicymanager-0000001163500889)的实例，可调用查询文件风险等级的方法。

   ```
   HwSfpPolicyManager policyManager = HwSfpPolicyManager.getDefault();
   if (policyManager == null) {
       return;
   }
   ```

2. 输入文件绝对路径和文件名称（filePath），查询文件的风险等级。

   ```
   String label = policyManager.getLabel(context, filePath,
       HwSfpPolicyManager.LABEL_NAME_SECURITY_LEVEL);
   ```

#### 获取标签辅助信息

1. 获取[HwSfpPolicyManager](https://developer.huawei.com/consumer/cn/doc/Security-References/hwsfppolicymanager-0000001163500889)的实例，可调用查询文件风险等级辅助信息的方法。

   ```
   HwSfpPolicyManager policyManager = HwSfpPolicyManager.getDefault();
   if (policyManager == null) {
       return;
   }
   ```

2. 获取标签辅助信息flag。  
   方法返回值为0或者1表示方法调用成功，返回值为-1表示方法调用失败。

   ```
   int flag = policyManager.getFlag(context, filePath,
       HwSfpPolicyManager.LABEL_NAME_SECURITY_LEVEL);
   ```

#### 接口使用的约束与限制

1. 兼容版本为EMUI 11.0及以上。
2. CE类目录下的文件：CE目录下的文件不允许设置S1，S0风险等级标签，否则返回失败提示。可以设置S2-S4风险等级，且只能设置一次。如果文件已经设置了风险等级，那么返回失败提示。

   Credential Encrypted，凭据加密区（CE类）。用户开机进入设备时，需要验证用户合法性，如输入开机密码，首次解锁屏幕后，后续解密数据不需要再次输入开机密码。当前手机系统的一个CE路径：/data/user/0。
3. DE类目录下的文件：文件不允许设置风险等级S2-S4，只允许设置S1,S0风险等级标签，且只能设置一次。如果文件已经设置了风险等级，那么返回失败提示。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115406.20694086836761894214457580035436:50001231000000:2800:B03D736D49AABB5CCD9A3293C027E795D537B547E9817E2292FB8EE017200C35.png?needInitFileName=true?needInitFileName=true)  
   Device Encrypted，设备加密区（DE类）。在用户开机后，此区域数据即可访问，如蓝牙配对数据、闹钟、铃声等。当前手机系统的一个DE路径：/data/user_de/0。
4. 目前仅支持对类型为文件的数据设置标签，建议文件创建以后，立即创建标签。
