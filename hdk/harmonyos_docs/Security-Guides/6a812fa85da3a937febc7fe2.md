# 版本更新说明

## 6.7.0.305（2025-05-27）

|----------------------------------------------------------------|
|Android版本：com.huawei.hms:safetydetect:6.7.0.305 **修改特性** 框架版本更新。|

## SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）5.0.5.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
