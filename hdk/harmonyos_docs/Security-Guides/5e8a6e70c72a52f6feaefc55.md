# 在Huawei DevEco Studio中集成DataSecurity Engine SDK

> 说明
>
> HUAWEI DevEco Studio目前处于Beta阶段，需要向华为申请试用权限。同时也期待您在使用过程中给我们反馈您宝贵的意见，我们将持续进行优化，提升您的使用体验。

在使用HUAWEI DevEco Studio进行应用开发前，您应该提前知道如何"[获取Beta权限](#section12701848131812)"和"[获取技术支持](#section76292349228)"通道。

## 获取Beta权限

您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。

1. 访问[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
2. 注册华为开发者联盟帐号，并点击右上角头像旁边的下拉图标，点击"立即前往实名认证"上传信息进行实名认证。
3. 实名认证后，在开发者联盟网站中选择"开发 > 开发工具 > HUAWEI DevEco Studio"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.97467949706222136125905337690720:50001231000000:2800:5FDECF3A37E1A1AC3C89A2A92A225815EF469016CDCA72B1980946D9C0C780C4.png?needInitFileName=true?needInitFileName=true)
4. 点击"试用申请"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.98092920733577502955190928402743:50001231000000:2800:6464992CAC94FE8767AC4E162CA9DD688A8A7B458E1AF1EB99C612D6ACEE8A22.png?needInitFileName=true?needInitFileName=true)
5. 点击"我要报名"，并填写报名信息后，提交给华为进行审核。 说明
   >
   > 提交申请后，华为将在三个工作日内对您的申请进行处理，并会及时通知您审批结果，请耐心等待。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.63240080350187203746723642191474:50001231000000:2800:9CA75766E9E565731B2B679EEFD9FF592F19B550E2624F90FD0898D51675DFD6.png?needInitFileName=true?needInitFileName=true)

## 获取技术支持

您在使用Huawei DevEco Studio时，如果您有任何的问题或建议，都可以通过如下两种方式与我们取得联系。

1. 在线工单：登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)，在菜单栏选择"支持 > 技术支持 > 在线提单"，进入在线提单页面提交工单。
2. 人工服务：您可以通过扫描如下二维码添加"华为DevEco小助手"，然后向我们的小助手进行反馈。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.39399635409282929261873248682272:50001231000000:2800:A5FAEBFB7B40473C85C90FA3EBC9CEAC19862C8E3890AD46FDFE25EDA2A61E16.png?needInitFileName=true?needInitFileName=true)

## 安装和配置DevEco Studio

获取Beta权限后，您就可以下载HUAWEI DevEco Studio软件进行开发了。

1. 登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)。
2. 点击右上角"管理中心"，然后在"应用服务 > 开发服务"中，勾选"HUAWEI DevEco Studio"卡片，然后点击"关闭"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.26704159683845938369584997761679:50001231000000:2800:2517C019DE99559B277369DCAA4BDFB0C7E87E23905AD47B40775692D155C329.png?needInitFileName=true?needInitFileName=true)
3. 在开发服务中，点击"HUAWEI DevEco Studio"卡片，阅读和签署Beta保密协议。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.74897765028030446086348713524125:50001231000000:2800:83AAD45F9FE9C01AE23A26ED3A56D0C7BD00BBC3121F8129179E9E83A7201535.png?needInitFileName=true?needInitFileName=true)
4. 下载DevEco Studio软件包。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.51676023168726853710895536451171:50001231000000:2800:B05B427ECF1132B781212FD7D69EDF197EE253ED0FC0BF81546F3C13386261AC.png?needInitFileName=true?needInitFileName=true)

   软件包下载完成后，请根据DevEco Studio使用指南中的[安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/install-0000001050028630)和[配置DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/config-guide-0000000000034467)章节完成环境的安装和配置。

1. 打开DevEco Studio，新建项目，选择Phone，选择Empty Activity。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.66019135013346295325195168486800:50001231000000:2800:61FCE232C72591D59F2BBFFAF10CA7A7D47F1AFB71BC4BB208218F3BF849C308.png?needInitFileName=true?needInitFileName=true)

   >
   > 如果您在开发过程中使用到华为其他移动应用服务，包名请与AppGallery Connect中的应用保持一致。

## 添加DataSecurity Engine SDK的依赖库

1. 在工具主界面，打开 "Tools > EMUI Kit > Kit Manager"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.12853727867347358560496832737755:50001231000000:2800:A32662C314BE3F97453D94C4367EB0BE3BCE1705CDE111CF8F2A2399CC6A4B5A.png?needInitFileName=true?needInitFileName=true)
2. 勾选DataSecurity Engine，点击"Apply"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115402.42285140834915872883780156412434:50001231000000:2800:D7B11A2AA7441960B8CF7AF7B97763D8AB92BDEC0BAABF8FFF3CF34C2477ECD6.png?needInitFileName=true?needInitFileName=true)
3. 等待添加完成，在build.gradle配置文件中检查，依赖库已经添加成功。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231116115403.39841270943840831903676047738957:50001231000000:2800:5B1E49246B77A3E964AC28B0363759BB1F878C94C012A3FF3DEFC825875CA43C.png?needInitFileName=true?needInitFileName=true)
4. 打开 "Tools > EMUI Kit > Kit Assistant"，在"Kit Assistant"界面，点击"Security"，可以显示DataSecurity Engine SDK的全部功能。
