# 告别传统，华为FIDO服务让账号登录更安全便捷

华为账号为10亿+用户提供了简单、安全的登录授权功能。用户在手机、平板、智慧屏等设备上登录华为账号后，可访问其应用。FIDO服务使能华为账号，提供更加安全便捷的身份认证能力。  

#### 为什么选择FIDO登录

传统的输入账号、密码的登录方式操作繁琐，每次登录耗时较长，给用户带来极大不便。因此，华为账号逐步提供了多种认证方式，贴合不同用户的登录习惯。而华为FIDO提供指纹/面容识别的免密登录功能，可以避免传统密码登录的繁琐和易泄露风险，并有系统完整性检测+密钥校验机制保证结果安全可信，3D面容识别技术使准确性高。  

#### FIDO做了什么

华为FIDO服务提供FIDO2线上快速身份验证客户端实现。结合华为FIDO2，以及三方FIDO Server，开发者就可以在App中增加安全易用的免密认证功能。

<br />

FIDO认证框架体系成熟、符合欧盟GDPR数据保护条例要求，且华为FIDO将[系统完整性检测](https://developer.huawei.com/consumer/cn/doc/Security-Guides/dysintegritydevelopment-0000001050156331)结果作为FIDO认证的前置条件，即在登录认证前，先检测设备系统是否被恶意篡改，例如是否被root，从而确保用户是在系统环境安全的设备上登录华为账号。

<br />

具体来说，用户在一台设备上登录华为账号后，可在账号内开通指纹/人脸认证，之后就可以在该设备上通过轻按指纹，或人脸识别，快速登入账号，省去了同一设备上重新登录的繁琐认证；如果系统完整性检测发现用户手机已被篡改，例如被root，界面上会提示"设备已被root，使用华为账号可能存在安全风险"，从而进一步保障用户登录安全。
