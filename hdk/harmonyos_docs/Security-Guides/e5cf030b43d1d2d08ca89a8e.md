# 航班管家和高铁管家集成华为钥匙环服务，为两亿用户打造无缝登录体验

#### 前言

航班管家和高铁管家母公司------深圳市活力天汇科技股份有限公司，是国内最大的独立出行服务平台，先后推出航班管家App、 高铁管家App，注册用户群2.5亿+，为用户提供一站式出行服务。

#### 业务挑战

航班管家与高铁管家的产品形态不断丰富，除了App，还通过快应用的方式触达用户。流量来源渠道丰富了，紧接着便需要思考如何提升流量转化率。在转化过程中，用户注册登录是第一步，也是最为关键的一步。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230928103013.99829082088661785960496395411610:50001231000000:2800:742CA5330C067E19E45D83CB44DC9F807139560370B709DF987DB5E7823519F3.png?needInitFileName=true?needInitFileName=true)

此前主流登录方式大致有以下几种：

1. 帐号密码登录；
2. 手机号、短信验证码登录；
3. 第三方帐号授权登录。

但是，这几种方式普遍操作繁琐，甚至需要跳出产品页面。且如果用户已经注册过，下次改变了登录方式，若登录帐号不一样，又会带来新的难题，如：两个帐号间行程信息无法互通、后续合并帐号处理困难等等。这些问题不仅损害了用户体验，还增加了管家团队的帐号运营负担，与提升转化率的初衷背道而驰。  

#### 解决方案

华为钥匙环服务可有效应对此类问题，用户在同一开发者旗下产品的任意形态登录后，在其他形态均可实现一键登录，轻松连接App、快应用，过程安全流畅、高效便捷。

在接入之初，管家团队最关注功能安全性，而钥匙环服务的核心优势之一便是安全可靠，主要体现在几个方面：

1. 由开发者配置支持此服务的App、快应用，未经授权无法获取用户认证凭据；
2. 用户的个人数据加密隔离存储，跨设备共享场景采用端到端加密方案，可保障数据安全；
3. 用户卸载App后，登录信息也会被删除。

除此之外，钥匙环服务能够做到在符合隐私政策的前提下，保障用户体验不受影响。首先，钥匙环服务在端侧加密存储共享凭据，跨设备凭据共享场景采用端到端加密，华为不能主动对用户凭据做修改、删除等影响凭据安全的操作。其次，HMS Core隐私声明中已经做过说明，所以开发者的App不需要再告知用户帮助其保管凭据。  

#### 结果

航班管家和高铁管家10月份上线钥匙环服务以来，使用此服务的用户月度环比涨幅达80%；新设备上的用户，从打开App到登录成功的流量转化率提升了12%；原来使用手机号验证码登录的用户，可改用钥匙环服务一键登录，因此降低了短信成本2.5%。
