# 华为安全检测服务助力中原银行牢筑终端金融安全墙

## 前言

中原银行是河南省唯一一家网点覆盖全省的省属法人银行，也是当地商业银行数字化浪潮中的先锋单位。中原银行手机银行自从2015年上线以来，一直在稳步发展，如今中原银行App的用户规模已过千万。近年来，银行等金融机构的数字化转型已成为主流趋势，同时也给银行的风险管理体系带来了挑战，保障风险可控是银行数字化转型过程中面临的重大课题。

## 业务挑战

出于保护财产安全的需要，手机银行App普遍涉及居民身份等重要数据信息，同时，用户数据分析、精准营销等运营方式丰富了线上金融的服务形式，使得高质量的金融应用变得更有价值。受经济利益诱惑，一些安全与法律意识淡薄网络灰黑产人员，往往会想方设法对手机银行App展开攻击，试图窃取用户数据。常见的攻击形式如：破坏手机系统窃取用户敏感数据；引导用户下载仿冒手机银行的恶意应用，诱导交易实施诈骗。

## 解决方案

中原银行一直以来非常重视科技能力建设，以保障用户各项权益和驱动业务发展，本次在自研安全检测服务的基础之上，引入华为安全检测服务（HMS Core Safety Detect Kit），丰富用户终端的风控数据维度，为智能决策提供可靠保障。在移动应用业务安全保障措施中，环境安全检测服务为手机银行App提供了最直接威胁情报，可以有效避免业务在不安全环境中受到攻击。

中原银行App主要集成了华为安全检测服务的三大能力：系统完整性检测、应用安全检测和恶意Wi-Fi检测。其中，系统完整性检测可以快速检测设备运行环境是否安全（如设备是否被root），帮助中原银行App高效地作出风险决策；恶意Wi-Fi检测则能够识别当前用户访问的网络环境是否有风险，有助于降低风险交易发生的概率；应用安全检测则为中原银行App提供恶意应用列表，获取到当前用户手机上是否存在恶意应用，进一步丰富风控决策的数据维度。

中原银行的移动研发框架负责人彭松介绍：目前使用华为设备的用户日活跃量占中原银行App总的33.8%，在涉及个人业务交易时，华为安全检测服务结合银行内部风险策略，对于系统环境存在风险的用户，中原银行App会对用户进一步采取风险防控措施，有针对性地加强安全验证，防止用户遭到恶意攻击而产生资金损失，守护用户财产安全。

## 结果

通过华为安全检测服务获取相关数据，中原银行App能够为华为手机用户提供更可靠的安全保障。
