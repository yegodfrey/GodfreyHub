# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## 调用UserDetect发起检测后获取到的responseToken，有效期是多久？

2分钟。

## 恶意URL检测是否支持合规性检测，比如：色情、暴力、犯罪？

当前恶意URL检测只支持钓鱼行为和挂马行为。目前不支持检测恶意URL对应的网站内容。

## 使用Safety Detect提供应用安全检测有没有版本的限制？

EMUI 5.0及以上版本可以使用，EMUI 5.0以下无法支持应用安全检测，返回空列表（即手机无恶意应用）。

## Safety Detect SysIntegrity返回结果中basicIntegrity的取值代表什么意思？

basicIntegrity取值代表了当前系统的完整性，true代表当前设备没有被修改过。

## 哪些错误需要用户处理？

网络错误和EMUI版本不支持的错误需要用户处理，其中错误码19202需要用户升级EMUI版本，错误码19002需要用户检查当前设备是否可以访问网络。

## Safety Detect系统完整性检测结果是否必须在服务端进行验证？

否，可以不在服务端进行验证，但安全性会降低，建议在服务端对检查结果进行验证。

## 使用Android Studio的Java转Kotlin的工具转换Demo有哪些注意点？

如果您使用了Android Studio的Java转Kotlin的工具转换了SysIntegrity的Demo工程。代码String[] jwsSplit = jwsStr.split("\\."); 需要手动修改为val jwsSplit = jwsStr.split(".").toTypedArray()。

### 出现 "1212" 错误码的原因和处理建议？

Safety Detect在用户设备上是动态升级和安装的，当前已覆盖绝大部分活跃设备，当由于网络或其它原因Safety Detect未安装或更新到用户设备上，会返回1212错误码。

推荐您跳过Safety Detect相关功能，使用原有的登录流程，当Safety Detect升级安装完成后，您就可以使用了。

## 在Android 11上，已安装HMS Core（APK）最新版本，仍然提示升级，如何解决？

Android 11更改了应用查询用户在设备上已安装的其他应用以及与之交互的方式。您应用的targetSdkVersion是30或者更高版本，并且集成的Safety Detect Kit 6.1.0.300之前版本时，将无法访问HMS Core（APK），并且持续提示升级。

您可以通过以下两种方法解决。

* 方法一： 升级Safety Detect Kit的SDK至6.1.0.300及以上版本，版本信息请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/Security-Guides/version-change-history-0000001050156329)。


* 方法二： 如果不升级SDK，需要在"AndroidManifest.xml"中manifest下添加<queries>标签。

  ```screen
  <manifest ...>
      ...
      <queries>
          <intent>
              <action android:name="com.huawei.hms.core.aidlservice" />
          </intent>
      </queries>
      ...
  </manifest>
  ```

  > 说明
  >
  > <queries>标签对工具的要求如下：
  > * Android Studio需升级至3.3或更高版本。
  > * Android Gradle插件需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。
