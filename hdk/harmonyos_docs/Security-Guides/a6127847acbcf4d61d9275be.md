# 基本定义

#### Bundle参数字段

* BUNDLE_APPTAG：应用身份信息，如包名
* BUNDLE_BATCHASSET：可批量操作数据，如用户名
* BUNDLE_AEADASSET：单条操作数据，如密码
* BUNDLE_ASSETTYPE：数据类型
* BUNDLE_EXTINFO：扩展信息
* BUNDLE_ASSETHANDLE：数据索引值
* BUNDLE_SELECT_MODE：查询模式
* BUNDLE_AUTHENTICATELIMITATION：认证限制标识
* BUNDLE_SYNCLIMITATION：同步限制标识
* BUNDLE_ACCESSLIMITATION：访问限制标识  

#### AssetResult返回类字段

```
int resultCode; //返回码
List< String > resultInfo; //返回数据，String为UTF-8编码
```

#### Asset数据类型（BUNDLE_ASSETTYPE字段可填值）

ASSET_TYPE_USERNAME_PASSWORD：用户名密码

ASSET_TYPE_CREADIT_CARD：信用卡信息

ASSET_TYPE_TOKEN：App Token数据  

#### 查询类型（BUNDLE_SELECT_MODE字段可填值）

SELECT_ONCE：查询一次，用于精确查询

SELECT_FROM_BEGIN：从头批量查询

SELECT_CONTINUE：继续批量查询  

#### 返回码（AssetResult.resultCode）

```
SUCCESS = 0; // 成功
ERROR_CODE_INVALID_ARGUMENT = -1; // 非法入参
ERROR_CODE_PERMISSION_DENIED = -2; // 权限校验失败
ERROR_CODE_UNINITIALIZED = -3; // 未初始化
ERROR_CODE_DATABASE_ERROR = -4; // 数据库操作异常
ERROR_CODE_UNSECURED_ENVIRONMENT = -5; // 非安全环境
ERROR_CODE_SYSTEM_ERROR = -10; // 系统错
```
