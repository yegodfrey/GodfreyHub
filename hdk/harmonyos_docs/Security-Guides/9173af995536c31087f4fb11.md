# 开发准备

iTrustee提供了本地编译的SDK包，便于开发者更好地开发在iTrustee TEE环境中运行的安全应用。

## 登录注册

下载使用iTrustee SDK进行安全业务开发前，需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[账号注册认证](https://developer.huawei.com/consumer/cn/devservice/doc/20300)。

## 环境准备

**TA开发环境准备**

|工具名称|建议版本|说明|
|:----------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|arm-eabi|7.4|此工具用于在Linux开发环境下编译TA。 [下载](https://releases.linaro.org/components/toolchain/binaries/7.4-2019.02/arm-eabi/gcc-linaro-7.4.1-2019.02-x86_64_arm-eabi.tar.xz)|
|arm-linux-gnueabi|7.4|此工具用于在Linux开发环境下编译TA。 [下载](https://releases.linaro.org/components/toolchain/binaries/7.4-2019.02/arm-linux-gnueabi/gcc-linaro-7.4.1-2019.02-x86_64_arm-linux-gnueabi.tar.xz)|
|python|2.7或以上版本|此工具用于在Linux开发环境下对TA进行签名。|
|openssl|N/A|用于对构建过程中对TA加密签名。 [下载](https://wiki.openssl.org/index.php/Binaries)|

**CA开发环境准备**

支持在 Android 工程中编译 CA，也可以编译 APK 形式的 CA。

* 可执行文件形式 CA

可执行文件形式 CA需要使用 Android 工程编译。开发者下载或使用 Android 工程编译 CA 时，需要遵循其许可协议。

* APK 形式 CA

APK 形式 CA需要安装 Android Studio 进行开发。

**下载iTrustee SDK**

对应SDK包下载可通过[SDK下载](https://developer.huawei.com/consumer/cn/doc/Security-Library/ta-0000001117224006)

## iTrustee CA编译链接准备

**用户态CA接口库**

CA需要调用我们提供的API接口与TA通信，这些API接口封装在如下so库中。CA必须按照如下要求访问对应的so库：

* vendor侧Native CA需链接libteec_vendor.so；
* system侧Native CA需链接libteec.huawei.so；

## iTrustee TA编译环境准备

TA需要在Linux环境下进行编译打包。需要使用的工具链可在linaro网站下载。64位TA编译需要使用aarch64版本的交叉编译工具链，按照与32位工具链相同的方式下载、安装和配置。

|工具链下载路径|32位TA编译|64位TA编译|支持C++|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------|:------|:----|
|[aarch64-linux-gnu](https://releases.linaro.org/components/toolchain/binaries/7.4-2019.02/arm-eabi)|是|否|否|
|[arm-linux-gnueabi](https://releases.linaro.org/components/toolchain/binaries/7.4-2019.02/arm-linux-gnueabi/gcc-linaro-7.4.1-2019.02-x86_64_arm-linux-gnueabi.tar.xz)|是|否|是|
|[gcc-linaro_aarch64-linux-gnu](https://releases.linaro.org/components/toolchain/binaries/7.4-2019.02/arm-linux-gnueabi)|否|是|是|
