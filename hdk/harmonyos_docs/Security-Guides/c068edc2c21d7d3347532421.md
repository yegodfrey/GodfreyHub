# 电子钱包Koshelek App通过集成系统完整性检测，降低盗刷风险

#### 前言

Koshelek App是俄罗斯Cardsmobile旗下领先的电子支付卡包，可以将银行卡等导入App中，实现电子支付功能。在结合了设备系统完整性检测能力后，Koshelek在信用卡支付等环节更安全，有效降低了因手机系统环境风险导致的信用卡盗刷风险。

#### 业务挑战

确认手机系统环境安全，是在Koshelek App内使用信用卡支付的安全前提。如果手机系统环境存在风险，如手机被root或解锁，会使用户个人隐私信息、交易和输入密码环节面临安全威胁。因此，Koshelek团队面临的挑战是需在应用中增加安全检测能力，用于评估手机环境安全。

<br />

另外，"Koshelek建立用户档案，存储收到的用户信息"，以及用户输入的银行卡有关信息，Cardsmobile移动开发负责人说道，"这些信息都需要被安全妥善的保护。"  

#### 解决方案

"华为安全检测是我们应用保护系统中的重要一环，"开发负责人介绍说。安全检测服务是华为推出的多维度安全检测开放服务，提供系统完整性检测等功能，帮助应用快速构建安全能力，保护用户隐私及安全。例如，当用户在Koshelek App内支付和输入信用卡安全验证码时，App调用系统完整性检测功能，评估设备系统环境是否安全。

<br />

如果用户设备未能通过Safety Detect的系统完整性检测，则Koshelek可以在界面上提示用户安全风险、并禁止用户下一步操作，从而保证用户账户、个人信息和交易的安全性。"正是安全检测服务的出现，使CardsMobile能够满足国际支付体系的要求，"他说道，"华为安全检测使我们的开发更高效便捷。"

<br />

华为系统完整性检测功能的接入，满足了Koshelek在支付交易等方面安全检测能力的需求，帮助其实现了为用户提供更安全的、符合国际支付要求的银行卡令牌化服务目标。开发负责人说："在集成系统完整性检测能力后，App内因手机系统环境风险导致的信用卡盗刷概率下降了。"  

#### 结果

因设备风险导致的信用卡盗刷概率下降，能够满足国际支付体系要求。
