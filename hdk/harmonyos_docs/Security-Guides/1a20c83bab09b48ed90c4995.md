# 集成BioAuthn-AndroidX SDK

#### 指纹认证

华为提供安全的指纹认证能力。如果系统安全存在问题，回调方法[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887).[onAuthError](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887#section201341832462)()，会提供错误码[BioAuthnPrompt](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnprompt_x-0000001050267874).[ERROR_SYS_INTEGRITY_FAILED](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnprompt_x-0000001050267874#section128841023103115)。如果设备运行环境安全，则执行指纹认证。指纹认证的错误码详情，请参见[接口文档](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnprompt_x-0000001050267874#section18958105111313)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250428154808.70908846980961855961887490516694:50001231000000:2800:277F68CB61E8627B255A36D4A94D968B601F00231801C876244C563BA40C385E.png)  
EMUI 4.0及以上版本才支持指纹认证。

华为指纹认证能力使用方法，如以下代码片段所示：

1. 创建[BioAuthnPrompt](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnprompt_x-0000001050267874)，[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887)。

   <br />

   ```
   "Java"
   private BioAuthnPrompt createBioAuthnPrompt() {
        // call back
        BioAuthnCallback callback = new BioAuthnCallback() {
            @Override
            public void onAuthError(int errMsgId, CharSequence errString) {
                showResult("Authentication error. errorCode=" + errMsgId + ",errorMessage=" + errString);
            }
            @Override
            public void onAuthSucceeded(BioAuthnResult result) {
                showResult("Authentication succeeded. CryptoObject=" + result.getCryptoObject());
            }
            @Override
            public void onAuthFailed() {
                showResult("Authentication failed.");
            }
        };
        return new BioAuthnPrompt(this, ContextCompat.getMainExecutor(this), callback);
    }
   ```

   ```
   "Kotlin"
   private fun createBioAuthnPrompt(): BioAuthnPrompt {
        // call back
        val callback = object : BioAuthnCallback() {
            override fun onAuthError(errMsgId: Int, errString: CharSequence) {
                showResult("Authentication error. errorCode=$errMsgId,errorMessage=$errString")
            }
            override fun onAuthSucceeded(result: BioAuthnResult) {
                if (result.cryptoObject != null) {
                    showResult("Authentication succeeded. CryptoObject=" + result.cryptoObject!!)
                } else {
                    showResult("Authentication succeeded. CryptoObject=null")
                }
            }
            override fun onAuthFailed() {
                showResult("Authentication failed.")
            }
        }
        return BioAuthnPrompt(this, ContextCompat.getMainExecutor(this), callback)
    }
   ```

   <br />

2. 创建提示信息，并进行认证。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250428154808.45277626820858172730617983120470:50001231000000:2800:137140DD95387CE788FF7AD59A6066984951B944623299B3FB9222386E0B6AFA.png)  
   * 利用PromptInfo.Builder创建PromptInfo时，[setDeviceCredentialAllowed](https://developer.huawei.com/consumer/cn/doc/Security-References/promptinfobuilder_x-0000001050418939#section1942134313214)(true)和[setNegativeButtonText](https://developer.huawei.com/consumer/cn/doc/Security-References/promptinfobuilder_x-0000001050418939#section1345252211567)()互斥，只能二选一。[setDeviceCredentialAllowed](https://developer.huawei.com/consumer/cn/doc/Security-References/promptinfobuilder_x-0000001050418939#section1942134313214)(true)允许在指纹认证页面，切换到其他认证方式，如锁屏密码。
   * 使用[BioAuthnPrompt.PromptInfo.Builder.setDeviceCredentialAllowed](https://developer.huawei.com/consumer/cn/doc/Security-References/promptinfobuilder_x-0000001050418939#section1942134313214)(true)注意事项：
     1. 该功能不支持具有屏下指纹且运行EMUI 9.x系统的设备，例如Mate 20 Pro、P30、P30 Pro、Magic2，在这些设备上切换锁屏密码认证会立刻导致认证失败。
     2. 在EMUI 9.x及以下版本，可能会出现仅能开启一次指纹认证的问题。解决措施如下（选择一种即可）：
        * Activity不重复创建[BioAuthnPrompt](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnprompt_x-0000001050267874)对象。
        * 认证完成后，调用Activity.recreate()方法重绘界面。
   * 关闭Activity重新打开。  

   ```
   "Java"
   // build prompt info
   BioAuthnPrompt.PromptInfo.Builder builder =
        new BioAuthnPrompt.PromptInfo.Builder().setTitle("This is the title.")
            .setSubtitle("This is the subtitle")
            .setDescription("This is the description");
   // The user will first be prompted to authenticate with biometrics, but also given the option to
    // authenticate with their device PIN, pattern, or password. setNegativeButtonText(CharSequence) should
    // not be set if this is set to true.
   builder.setDeviceCredentialAllowed(true);
   // Set the text for the negative button. setDeviceCredentialAllowed(true) should not be set if this button text
    // is set.
    // builder.setNegativeButtonText("This is the 'Cancel' button.");
   BioAuthnPrompt.PromptInfo info = builder.build();
   resultTextView.setText("Start fingerprint authentication without CryptoObject.\nAuthenticating......\n");
    bioAuthnPrompt.auth(info);
   ```

   ```
   "Kotlin"
   // build prompt info
   val builder = BioAuthnPrompt.PromptInfo.Builder().setTitle("This is the title.")
            .setSubtitle("This is the subtitle")
            .setDescription("This is the description")
   // The user will first be prompted to authenticate with biometrics, but also given the option to
    // authenticate with their device PIN, pattern, or password. setNegativeButtonText(CharSequence) should
    // not be set if this is set to true.
   builder.setDeviceCredentialAllowed(true)
   // Set the text for the negative button. setDeviceCredentialAllowed(true) should not be set if this button text
    // is set.
    // builder.setNegativeButtonText("This is the 'Cancel' button.");
   val info = builder.build()
   resultTextView!!.text = "Start fingerprint authentication without CryptoObject.\nAuthenticating......\n"
    bioAuthnPrompt!!.auth(info)
   ```

#### 面容认证

华为提供安全的面容认证能力。如果系统安全存在问题，回调函数[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887).[onAuthError](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887#section201341832462)，会提供错误码[FaceManager](https://developer.huawei.com/consumer/cn/doc/Security-References/facemanager_x-0000001050418949).[FACE_ERROR_SYS_INTEGRITY_FAILED](https://developer.huawei.com/consumer/cn/doc/Security-References/facemanager_x-0000001050418949#section129141334710)。如果设备运行环境安全，则执行面容认证。面容认证的错误码详情，请参见[接口文档](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnandroidxoverview-0000001050178779)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250428154808.33811726929266641465744320509275:50001231000000:2800:8DF3B5E4B0C5A3BEC6990A82E870501953B0F2605B1C7E6616F1C4ADC44BC7E1.png)  
1. EMUI 10.0（API Level 29）以上版本才支持面容认证，另外请确保设备硬件支持面容认证。
2. EMUI 10.0及以上版本且调用[FaceManager](https://developer.huawei.com/consumer/cn/doc/Security-References/facemanager_x-0000001050418949)中的[getFaceModality](https://developer.huawei.com/consumer/cn/doc/Security-References/facemanager_x-0000001050418949#section1190062720515)接口返回"返回值：2"或"返回值：3"的支持面容认证。返回"返回值：1"的不支持面容认证。
3. 使用[CryptoObject](https://developer.huawei.com/consumer/cn/doc/Security-References/cryptoobject_x-0000001050178973)对象认证时，使用KeyGenParameterSpec.Builder创建key时setUserAuthenticationRequired()必须为false。当前版本中，KeyStore没有与面容认证结果关联。

华为面容认证能力使用方法，如以下代码片段所示：

1. 构造[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887)。

   <br />

   ```
   "Java"
   // call back
   BioAuthnCallback callback = new BioAuthnCallback() {
       @Override
       public void onAuthError(int errMsgId, CharSequence errString) {
           showResult("Authentication error. errorCode=" + errMsgId + ",errorMessage=" + errString
               + (errMsgId == 1012 ? " The camera permission may not be enabled." : ""));
       }
       @Override
       public void onAuthHelp(int helpMsgId, CharSequence helpString) {
           resultTextView
               .append("Authentication help. helpMsgId=" + helpMsgId + ",helpString=" + helpString + "\n");
       }
       @Override
       public void onAuthSucceeded(BioAuthnResult result) {
           showResult("Authentication succeeded. CryptoObject=" + result.getCryptoObject());
       }
       @Override
       public void onAuthFailed() {
           showResult("Authentication failed.");
       }
   };
   ```

   ```
   "Kotlin"
   // call back
   val callback = object : BioAuthnCallback() {
       override fun onAuthError(errMsgId: Int, errString: CharSequence) {
           showResult("Authentication error. errorCode=" + errMsgId + ",errorMessage=" + errString
                   + if (errMsgId == 1012) " The camera permission may not be enabled." else "")
       }
       override fun onAuthHelp(helpMsgId: Int, helpString: CharSequence) {
           resultTextView!!
                   .append("Authentication help. helpMsgId=$helpMsgId,helpString=$helpString\n")
       }
       override fun onAuthSucceeded(result: BioAuthnResult) {
           showResult("Authentication succeeded.")
       }
       override fun onAuthFailed() {
           showResult("Authentication failed.")
       }
   }
   ```

   <br />

2. 构造[FaceManager](https://developer.huawei.com/consumer/cn/doc/Security-References/facemanager_x-0000001050418949)，调用[auth](https://developer.huawei.com/consumer/cn/doc/Security-References/facemanager_x-0000001050418949#section39750555252)方法。

   <br />

   ```
   "Java"
   // Cancellation Signal
   CancellationSignal cancellationSignal = new CancellationSignal();
   FaceManager faceManager = new FaceManager(this);
   // flags
   int flags = 0;
   // Authentication message handler.
   Handler handler = null;
   // Recommended CryptoObject to be set to null. KeyStore is not associated with face authentication in current
   // version. KeyGenParameterSpec.Builder.setUserAuthenticationRequired() must be set false in this scenario.
   CryptoObject crypto = null;
   faceManager.auth(crypto, cancellationSignal, flags, callback, handler);
   ```

   ```
   "Kotlin"
   // Cancellation Signal
   val cancellationSignal = CancellationSignal()
   val faceManager = FaceManager(this) 
   // flags
   val flags = 0
   // Authentication message handler.
   val handler: Handler? = null
   // Recommended CryptoObject to be set to null. KeyStore is not associated with face authentication in current
   // version. KeyGenParameterSpec.Builder.setUserAuthenticationRequired() must be set false in this scenario.
   val crypto: CryptoObject? = null
   faceManager.auth(crypto, cancellationSignal, flags, callback, handler)
   ```
