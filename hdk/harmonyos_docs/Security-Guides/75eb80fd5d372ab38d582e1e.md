# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_Security-HMSCoreSafetyDetect)快速体验一个应用的开发过程。  

#### 开发环境

* JDK 1.7及以上
* 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上

  * minSdkVersion 19及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 5.4.1及以上（推荐）
* 测试应用的设备：详情请参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/Security-Guides/introduction-0000001050156325#section199351939122310)

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值  

#### 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。  

|序号|步骤|说明|
|:-|:----------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/Security-Guides/config-agc-0000001050416303)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹、打开相关服务。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/Security-Guides/android-integrating-sdk-0000001194983255)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/Security-Guides/config-obfuscation-scripts-0000001055268435)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[系统完整性检测API](https://developer.huawei.com/consumer/cn/doc/Security-Guides/dysintegritydevelopment-0000001050156331)|应用需要检测系统完整性时，调用系统完整性检测API，检测系统完整性是否被破坏，针对不安全设备采取相应的措施。|
|5|[应用安全检测API](https://developer.huawei.com/consumer/cn/doc/Security-Guides/appscheck-0000001050154380)|您可获取恶意应用列表，基于风险（风险应用/病毒应用）评估是否限制App行为。|
|6|[恶意URL检测API](https://developer.huawei.com/consumer/cn/doc/Security-Guides/urlcheck-0000001050156333)|用户访问网址时，判断用户访问的URL是否为恶意网址，对于恶意网址，由您评估提示或拦截用户的访问风险。|
|7|[虚假用户检测API](https://developer.huawei.com/consumer/cn/doc/Security-Guides/userdetect-0000001050154382)|可以帮助您App防范批量注册、撞库攻击、活动"薅羊毛"、内容爬虫等行为。|
|8|[恶意Wi-Fi检测API](https://developer.huawei.com/consumer/cn/doc/Security-Guides/wifidetect-0000001050156335)|您集成WifiDetect接口，当应用获取尝试连接的Wi-Fi存在ARP攻击、中间人攻击、DNS劫持等攻击时，您可以阻断操作或者进一步让用户认证确认。|
|9|[开发后自检](https://developer.huawei.com/consumer/cn/doc/Security-Guides/prereleasecheck-0000001050174352)|华为提供对应用自动检查的能力。|
|10|[上架申请](https://developer.huawei.com/consumer/cn/doc/Security-Guides/app-release-0000001245681381)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。
