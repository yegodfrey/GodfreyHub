# 隐私体验

#### 钥匙环服务是否符合用户隐私政策？

符合，关于 HMS Core与隐私的声明中已对钥匙环服务自身的隐私声明约束做出说明，用于了解我们是如何为用户提供钥匙环服务。详情如下：钥匙环服务为您提供认证凭据共享功能。如果您已经登录一个应用，借助该服务，仅需验证一下生物信息，而无需重复输入用户名、密码，就可以无缝登录它的关联应用。您的设备会通过安全的方式对您的生物特征数据（如指纹、面部信息）进行本地处理。  

#### App是否需要告知用户如何管理凭据？

使用钥匙环服务过程中，用户凭据始终保存在用户设备本地，不上传服务器，用户仍是实际数据控制者，华为不能主动对用户凭据做修改、删除等影响凭据安全的操作，其次HMS Core隐私声明已做过说明，故您的App不需要再告知用户。  

#### 非华为设备上使用钥匙环服务，自启动或关联启动HMS Core，App是否需要向用户明示获取用户同意？

* 当您在华为设备上使用钥匙环服务时，由于华为手机上HMS Core是常驻进程，且HMS Core作为系统的基础服务，不认定为关联启动，不需要明示用户。
* 当您在非华为设备上使用钥匙环服务时，会关联启动HMS Core应用，对此您需要向用户明示并获取其同意。  

#### 如果涉及用户有多账号，在前端是否需要弹窗给用户选择？

keyring可以保存多个用户凭据，但不提供界面，开发者可以按照应用界面风格自行设计选择界面。  

#### 用户在首次使用跨应用、跨形态登录时，如何告知用户App使用了凭据共享功能，以获得更佳的用户登录体验？

跨应用、跨形态的登录体验可显著提升用户体验同时帮助开发者显著提升流量转化率，可根据业务实际情况设计体验。
