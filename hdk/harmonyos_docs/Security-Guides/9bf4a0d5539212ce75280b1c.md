# 开发步骤

#### 使用前准备

导入相关类以使用Asset存储能力：

```
import android.os.Bundle;
import android.content.Context;
import com.huawei.android.util.NoExtAPIException;
import com.huawei.security.hwassetmanager.HwAssetManager;
```

#### 接口使用示例

使用场景代码前需获取Asset存储实例：

```
HwAssetManager assetManager = null; 
try { 
    assetManager = HwAssetManager.getInstance(); 
} catch (NoExtAPIException e) { 
    // handle the exception... 
}
```

#### 场景介绍

* 场景一：插入一条Asset数据

  ```
  Bundle bundle = new Bundle(); 
  // 可配置BUNDLE_ASSETTYPE，默认为HwAssetManager.ASSET_TYPE_USERNAME_PASSWORD 
  bundle.putInt(HwAssetManager.BUNDLE_ASSETTYPE, HwAssetManager.ASSET_TYPE_CREDIT_CARD); 
  bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); 
  bundle.putString(HwAssetManager.BUNDLE_BATCHASSET, "demo_batchasset"); 
  bundle.putString(HwAssetManager.BUNDLE_AEADASSET, "demo_aeadasset"); 
  bundle.putString(HwAssetManager.BUNDLE_EXTINFO, "demo_extinfo"); 
  try { 
      HwAssetManager.AssetResult result = assetManager.assetInsert(context, bundle); // context is ready. 
  } catch (NoExtAPIException e) { 
      // handle the exception... 
  }
  ```

* 场景二：删除一条Asset数据

  ```
  Bundle bundle = new Bundle(); 
  bundle.putString(HwAssetManager.BUNDLE_ASSETHANDLE, "demo_assethandle"); 
  bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); 
  try { 
      HwAssetManager.AssetResult result = assetManager.assetDelete(context, bundle); // context is ready. 
  } catch (NoExtAPIException e) { 
      // handle the exception... 
  }
  ```

* 场景三：更新一条Asset数据

  ```
  Bundle bundle = new Bundle(); 
  bundle.putString(HwAssetManager.BUNDLE_ASSETHANDLE, "demo_assethandle"); 
  bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); 
  bundle.putString(HwAssetManager.BUNDLE_BATCHASSET, "demo_batchasset"); 
  bundle.putString(HwAssetManager.BUNDLE_AEADASSET, "demo_aeadasset"); 
  bundle.putString(HwAssetManager.BUNDLE_EXTINFO, "demo_extinfo"); 
  try { 
      HwAssetManager.AssetResult result = assetManager.assetUpdate(context, bundle); // context is ready. 
  } catch (NoExtAPIException e) { 
      // handle the exception... 
  }
  ```

* 场景四：查询数据
  * 查询单条数据

    ```
    Bundle bundle = new Bundle(); 
    bundle.putString(HwAssetManager.BUNDLE_ASSETHANDLE, "demo_assethandle"); 
    bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); 
    bundle.putInt(HwAssetManager.BUNDLE_SELECT_MODE, HwAssetManager.SELECT_ONCE); 
    try { 
        HwAssetManager.AssetResult result = assetManager.assetSelect(context, bundle); // context is ready. 
    } catch (NoExtAPIException e) { 
        // handle the exception... 
    }
    ```

  * 批量从第一条数据开始查询

    ```
    Bundle bundle = new Bundle(); 
    bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); // 配置应用包名等信息，不指定则查询所有Asset数据 
    bundle.putInt(HwAssetManager.BUNDLE_SELECT_MODE, HwAssetManager.SELECT_FROM_BEGIN); // 配置查询模式为从头查询，一次最多10条 
    try { 
        HwAssetManager.AssetResult result = assetManager.assetSelect(context, bundle); // context is ready. 
    } catch (NoExtAPIException e) { 
        // handle the exception... 
    }
    ```

  * 批量继续查询数据

    ```
    Bundle bundle = new Bundle(); 
    bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); // 配置应用包名等信息，不指定则查询所有Asset数据 
    bundle.putInt(HwAssetManager.BUNDLE_SELECT_MODE, HwAssetManager.SELECT_CONTINUE); // 配置查询模式为继续查询，一次最多10条 
    try { 
        HwAssetManager.AssetResult result = assetManager.assetSelect(context, bundle); // context is ready. 
    } catch (NoExtAPIException e) { 
        // handle the exception... 
    }
    ```

#### 场景举例实现

例如：查询并删除一条用户短敏感数据。

1. 导入使用Asset存储能力的相关类。
2. 调用[HwAssetManager](https://developer.huawei.com/consumer/cn/doc/Security-References/hwassetmanager-0000001163500887)的[getInstance](https://developer.huawei.com/consumer/cn/doc/Security-References/hwassetmanager-0000001163500887#section18155152819401)方法获取Asset存储实例。

   ```
   HwAssetManager assetManager = null; 
   try { 
       assetManager = HwAssetManager.getInstance(); 
   } catch (NoExtAPIException e) { 
       // handle the exception... 
   }
   ```

3. 调用[HwAssetManager](https://developer.huawei.com/consumer/cn/doc/Security-References/hwassetmanager-0000001163500887)的[assetSelect](https://developer.huawei.com/consumer/cn/doc/Security-References/hwassetmanager-0000001163500887#section273281019574)方法查询一条用户短敏感数据记录。

   ```
   Bundle bundle = new Bundle(); 
   bundle.putString(HwAssetManager.BUNDLE_ASSETHANDLE, "demo_assethandle"); 
   bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); 
   bundle.putInt(HwAssetManager.BUNDLE_SELECT_MODE, HwAssetManager.SELECT_ONCE); 
   try { 
       HwAssetManager.AssetResult result = assetManager.assetSelect(context, bundle); // context is ready. 
   } catch (NoExtAPIException e) { 
       // handle the exception... 
   }
   ```

4. 调用[HwAssetManager](https://developer.huawei.com/consumer/cn/doc/Security-References/hwassetmanager-0000001163500887)的[assetDelete](https://developer.huawei.com/consumer/cn/doc/Security-References/hwassetmanager-0000001163500887#section116621115574)方法删除一条用户短敏感数据记录。

   ```
   Bundle bundle = new Bundle(); 
   bundle.putString(HwAssetManager.BUNDLE_ASSETHANDLE, "demo_assethandle"); 
   bundle.putString(HwAssetManager.BUNDLE_APPTAG, "demo_apptag"); 
   try { 
       HwAssetManager.AssetResult result = assetManager.assetDelete(context, bundle); // context is ready. 
   } catch (NoExtAPIException e) { 
       // handle the exception... 
   }
   ```

5. 查询数据库中记录是否已经被删除检验操作结果。
