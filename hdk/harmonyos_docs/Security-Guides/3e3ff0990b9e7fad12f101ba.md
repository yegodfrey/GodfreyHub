# 虚假用户检测API

## 系统特性

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|1. 基于实时风险分析引擎识别：API会在合法范围内采集相关数据并上传到实时风险分析引擎来识别当前用户是否为虚假用户。 2. 非中国大陆地区提供验证码检测，若当前检测结果是可疑或风险用户，弹出验证码对用户进行二次验证。 3. 中国大陆地区不提供验证码检测，通过[nocaptcha云侧](https://developer.huawei.com/consumer/cn/doc/Security-References/result-0000001058290700)接口获取检测结果。| |

## 业务流程

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251017092006.73864743649900665955143736267235:50001231000000:2800:D7A803A183703A08A866D2FB6584F2B382E111DBF3A05B63F8B8F199A33C317B.png)

1. 您的App集成HMS Core SDK调用HMS Safety Detect service。
2. Safety Detect评估设备运行环境风险，如果风险等级为中或高，弹出验证码进行验证，并返回一个responseToken给您的App。
3. 您的App提交responseToken至App服务端。
4. App服务端发送responseToken至Safety Detect服务端获取检测结果。

## 典型场景

可以帮助您App防范批量注册、撞库攻击、活动"薅羊毛"、内容爬虫等行为。

## 应用开发

### 初始化虚假用户检测

UserDetect提供了行为检测能力，如果您希望您的虚假用户检测功能具备该能力，可以通过调用[initUserDetect](https://developer.huawei.com/consumer/cn/doc/Security-References/safetydetectclientapi-0000001050175445#section991714817915)接口初始化虚假用户检测，示例代码如下：

```screen
"Java"
private void initUserDetect() {
    // Replace with your activity or context as a parameter.
    SafetyDetectClient client = SafetyDetect.getClient(MainActivity.this);
    client.initUserDetect().addOnSuccessListener(new OnSuccessListener<Void>() {
        @Override
        public void onSuccess(Void v) {
            // Indicates communication with the service was successful.
        }
    }).addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            // There was an error communicating with the service.
        }
    });
}
```


### 调用UserDetect API

调用[UserDetect API](https://developer.huawei.com/consumer/cn/doc/Security-References/userdetectresponseapi-0000001050259900)分为两步：

1. 发起检测请求：调用UserDetect API的[userDetection](https://developer.huawei.com/consumer/cn/doc/Security-References/userdetectresponseapi-0000001050259900)方法以发起虚假用户检测请求，API会返回一个[responseToken](https://developer.huawei.com/consumer/cn/doc/Security-References/userdetectresponseapi-0000001050259900#ZH-CN_TOPIC_0000001629774553__p15531235173419)。

   您需要通过调用[userDetection](https://developer.huawei.com/consumer/cn/doc/Security-References/userdetectresponseapi-0000001050259900)发起检测。通常在用户点击UI组件（如一个按钮）后触发调用该方法。调用[userDetection](https://developer.huawei.com/consumer/cn/doc/Security-References/userdetectresponseapi-0000001050259900)方法时，您需要做以下事情：
   1. 传入您申请的appId作为该方法的参数。
   2. 分别添加OnSuccessListener和OnFailureListener实例作为监听器。
   3. 重写onSuccess、onFailure，处理对应的结果。

   调用该方法的示例代码如下所示：

   ```screen
   "Java"
   public void onClick(View v) {
       SafetyDetectClient client = SafetyDetect.getClient(getActivity());
       String appId = "your_app_id";
       client.userDetection(appId)
               .addOnSuccessListener(new OnSuccessListener<UserDetectResponse>() {
                   @Override
                   public void onSuccess(UserDetectResponse userDetectResponse) {
                       // Indicates communication with the service was successful.
                       String responseToken = userDetectResponse.getResponseToken();
                       if (!responseToken.isEmpty()) {
                           // Send the response token to your app server, and call the cloud API of HMS Core on your server to obtain the fake user detection result. 
                       }
                   }
               })
               .addOnFailureListener(new OnFailureListener() {
                   @Override
                   public void onFailure(Exception e) {
                       // There was an error communicating with the service.
                       String errorMsg;
                       if (e instanceof ApiException) {
                           // An error with the HMS API contains some additional details.
                           // You can use the apiException.getStatusCode() method to get the status code.
                           ApiException apiException = (ApiException) e;
                           errorMsg = SafetyDetectStatusCodes.getStatusCodeString(apiException.getStatusCode()) + ": "
                                   + apiException.getMessage();
                       } else {
                           // Unknown type of error has occurred.
                           errorMsg = e.getMessage();
                       }
                       Log.i(TAG, "User detection fail. Error info: " + errorMsg);
                   }
               });
   }
   ```

   ```screen
   "Kotlin"
   override fun onClick(v: View?) {
   	val client = SafetyDetect.getClient(activity)
           val appId = "your_app_id"
           client.userDetection(appId)
               .addOnSuccessListener { userDetectResponse ->
                   // Indicates communication with the service was successful.
                   val responseToken = userDetectResponse.responseToken
                   if (responseToken.isNotEmpty()) {
                       // Send the response token to your app server, and call the cloud API of HMS Core on your server to obtain the fake user detection result.
                   }
               }
               .addOnFailureListener {  // There was an error communicating with the service.
                   val errorMsg: String? = if (it is ApiException) {
                       // An error with the HMS API contains some additional details.
                       // You can use the apiException.getStatusCode() method to get the status code.
                       (SafetyDetectStatusCodes.getStatusCodeString(it.statusCode) + ": "
                               + it.message)
                   } else {
                       // Unknown type of error has occurred.
                       it.message
                   }
                   Log.i(TAG, "User detection fail. Error info: $errorMsg")
               }
   	}
   ```

   > 说明
   >
   > 若UserDetect API执行了onSuccess()方法，则说明用户已经完成了人机识别检测，但您还需到您应用服务器验证用户的responseToken。

2. 获取检测结果：使用[1](#ZH-CN_TOPIC_0000001579573912__li1393517262347)获取response token调用云端获取检测结果：中国大陆地区调用[nocaptcha云侧](https://developer.huawei.com/consumer/cn/doc/Security-References/result-0000001058290700)接口获取检测结果，海外地区通过[verify云侧接口](https://developer.huawei.com/consumer/cn/doc/Security-References/getresult-0000001051066312)获取检测结果。

   服务端主要分为两步：
   1. 获取accessToken。
   2. 调用云侧API获取检测结果。

   具体步骤如下：

   获取accessToken：详细请参见[开放平台鉴权相关内容描述](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/open-platform-oauth-0000001053629189)。

   调用云侧API获取检测结果：调用云侧获取结果。消息请求示例如下所示。详细请参见[云侧API](https://developer.huawei.com/consumer/cn/doc/development/Security-References/getresult-0000001051066312)。

### App端关闭虚假用户检测

您可以通过调用shutdownUserDetect接口关闭虚假用户检测功能，释放资源，示例代码如下：

```screen
"Java"
private void shutdownUserDetect() {
    // Replace with your activity or context as a parameter.
    SafetyDetectClient client = SafetyDetect.getClient(MainActivity.this);
    client.shutdownUserDetect().addOnSuccessListener(new OnSuccessListener<Void>() {
        @Override
        public void onSuccess(Void v) {
            // Indicates communication with the service was successful.
        }
    }).addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            // There was an error communicating with the service.
        }
    });
}
```

```screen
"Kotlin"
private fun shutdownUserDetect() {
        // Replace with your activity or context as a parameter.
        val client = SafetyDetect.getClient(this@MainActivity)
        client.shutdownUserDetect()
            .addOnSuccessListener {
                // Indicates communication with the service was successful.
            }.addOnFailureListener {
                // There was an error communicating with the service.
            }
    }
```

**常见错误码处理**

[DETECT_FAIL](https://developer.huawei.com/consumer/cn/doc/Security-References/safetydetectstatuscodesapi-0000001050259854#ZH-CN_TOPIC_0000001629574573__p14316183611154)：值19800

检测失败，建议重新调用User Detect API。

[NETWORK_ERROR](https://developer.huawei.com/consumer/cn/doc/Security-References/safetydetectstatuscodesapi-0000001050259854#ZH-CN_TOPIC_0000001629574573__p1314113619156)：值19002

未连接到互联网，建议在确保接入互联网后，再次调用User Detect API。
