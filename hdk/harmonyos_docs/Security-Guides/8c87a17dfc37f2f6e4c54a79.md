# 土耳其BlindID App集成华为HMS Core虚假用户检测能力，应用100%抵御撞库攻击

## 前言

BlindID App是一个创新的社交媒体平台，主打陌生人交友的功能，可以实现匿名实时互动，玩法新颖有趣。用户聊天过程中搭配各种各样的趣味主题，能够快速拉近两人的距离，让互动变得自然生动。长久以来，BlindID App一直不具备抵御撞库攻击的能力，通过集成虚假用户检测能力，应用的安全性与稳定性得到大幅提升，能够100%抵御撞库攻击。（数据来源：BlindID App-Kazim Oguz Cin）

## 业务挑战

识别可疑或风险用户对社交类App的系统安全、用户个人帐户至关重要。BlindID App 创始人Adil Zehir说道："此前App受到DDoS攻击，恶意流量试图登录用户的帐户。"

## 解决方案

安全检测服务是华为推出的多维度安全检测开放服务，提供虚假用户检测等功能，通过在合法范围内采集相关数据，上传到实时风险分析引擎，来识别当前用户是否为风险用户。

如果用户未能通过华为安全检测服务的虚假用户检测，则BlindID App可以基于检测结果评估是否限制用户行为，从而保证系统与用户帐户安全。"我们在用户注册和登录环节调用虚假用户检测"，创始人说道。

"华为安全检测对我们来说是最好的解决方案，因为容易集成，并且能够快速阻挡攻击"创始人说，"虚假用户检测功能帮助我们验证用户是机器还是自然人，攻击者发现有Safety Detect防护，就会放弃攻击，未授权的访问数量明显下降。"

虚假用户检测能力的接入，帮助BlindID APP过滤垃圾流量，降低了虚假用户盗用帐号、恶意刷帖、薅羊毛的风险，有助于防范外部攻击，助力App为用户提供更安全的服务。

## 结果

BlindID App集成华为HMS Core虚假用户检测能力，应用100%抵御撞库攻击。
