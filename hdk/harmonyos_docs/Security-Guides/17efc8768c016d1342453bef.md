# 恶意URL检测功能助力蚂蚁浏览器App，有效提升安全性与用户满意度

## 前言

蚂蚁浏览器App是一款小巧轻快、便捷安全的浏览器应用，为中国、新加坡会员用户提供无广告、无推送骚扰、快速安全的浏览服务，用户可通过App内扫码等方式访问目标URL。

## 业务挑战

恶意URL，如钓鱼链接、假冒仿冒的网站链接，可能会盗取用户隐私信息或诱导转账、造成财产损失。但由于用户在扫描未知二维码前，无法通过肉眼判别其指向的网页是否有钓鱼、欺诈等风险，如果App扫码后直接跳转访问，用户隐私和资金安全就可能面临来自恶意网站的威胁。

因此，在用户访问未知类型URL前及时识别是否存在风险，对于浏览器App安全运行至关重要。蚂蚁浏览器App以用户隐私安全和体验优化为核心，为了提供安全、稳定、可信赖的浏览服务，蚂蚁浏览器需要在会员用户扫码访问时，及时识别URL风险类型，并根据检测结果提示用户访问风险。

## 解决方案

蚂蚁浏览器App选择集成华为安全检测服务提供的恶意URL检测功能，在用户扫码后，自动调用恶意URL检测API，如果检测到用户将要访问的URL存在风险，App会出现浮框消息提示，4秒后自动消失，提醒用户这个页面存在风险，以便用户谨慎操作或关闭页面。

"这使得蚂蚁浏览器App安全方面能力提高了80%，" 蚂蚁浏览器（MyIE）CTO郭峰表示，"同时用户体验也更好了------通过App内风险提示浮框的方式，用户可以及时知晓扫码访问的URL是否安全，并且检测快速、结果准确，避免误报拦截过头、影响用户正常浏览，我们的用户满意度因此提升了30%！"

## 结论

App安全性提升80% 。
