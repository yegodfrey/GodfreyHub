# 集成BioAuthn SDK

#### 指纹认证

华为提供安全的指纹认证能力。如果系统安全存在问题，回调函数[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_bioauthncallback-0000001050178012).[onAuthError](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_bioauthncallback-0000001050178012#section150553110349)()，会提供错误码[FingerprintManager](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_fingerprintmanager-0000001050418971).[FINGERPRINT_ERROR_SYS_INTEGRITY_FAILED](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_fingerprintmanager-0000001050418971#section2194185218211)。如果设备运行环境安全，则执行指纹认证。指纹认证的错误码详情，请参见[接口文档](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnoverview-0000001050268268)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250428154810.02661268910269662515448933316114:50001231000000:2800:F756EB528D69D49D1CB4FF0ACC9A5112ACD5E0E9EF2B2A79B0A3CE32CD71A60F.png)  
EMUI 4.0及以上版本才支持指纹认证。

华为指纹认证能力使用方法，如以下代码片段所示：

1. 创建[FingerprintManager](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_fingerprintmanager-0000001050418971)，[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_bioauthncallback-0000001050178012)。

   <br />

   ```
   "Java"
   private FingerprintManager createFingerprintManager() {
       // call back
       BioAuthnCallback callback = new BioAuthnCallback() {
           @Override
           public void onAuthError(int errMsgId, CharSequence errString) {
               showResult("Authentication error. errorCode=" + errMsgId + ",errorMessage=" + errString);
           }
           @Override
           public void onAuthSucceeded(BioAuthnResult result) {
               showResult("Authentication succeeded. CryptoObject=" + result.getCryptoObject());
           }
           @Override
           public void onAuthFailed() {
               showResult("Authentication failed.");
           }
       };
       return new FingerprintManager(this, Executors.newSingleThreadExecutor(), callback);
   }
   ```

   ```
   "Kotlin"
       // call back
       val callback = object : BioAuthnCallback() {
           override fun onAuthError(errMsgId: Int, errString: CharSequence?) {
               showResult("Authentication error. errorCode=$errMsgId,errorMessage=$errString")
           }
           override fun onAuthSucceeded(result: BioAuthnResult) {
               showResult("Authentication succeeded. CryptoObject=" + result.cryptoObject)
           }
           override fun onAuthFailed() {
               showResult("Authentication failed.")
           }
       }
       return FingerprintManager(this, Executors.newSingleThreadExecutor(), callback)
   }
   ```

   <br />

2. 进行认证。

   <br />

   ```
   "Java"
   fingerprintManager.auth();
   ```

   ```
   "Kotlin"
   fingerprintManager!!.auth()
   ```

   <br />

#### 面容认证

华为提供安全的面容认证能力。如果系统安全存在问题，回调函数[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_bioauthncallback-0000001050178012).onAuthError，会提供错误码[FaceManager](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_facemanager-0000001050180181).[FACE_ERROR_SYS_INTEGRITY_FAILED](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_facemanager-0000001050180181)。如果设备运行环境安全，则执行面容认证。面容认证的错误码详情，请参见[接口文档](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnoverview-0000001050268268)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250428154810.27425167455590042170410400824185:50001231000000:2800:6DE17290D5E577477F4F08281A0F8FE259A7A68D420167461CC8104EEE696E70.png)  
1. EMUI 10.0以上版本才支持面容认证，另外请确保设备硬件支持面容认证。
2. EMUI 10.0及以上版本且调用FaceManager中的[getFaceModality](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_facemanager-0000001050180181#section966851911288)接口返回"返回值：2"或"返回值：3"的支持面容认证。（注意：返回"返回值：1"的不支持面容认证。）
3. 使用[CryptoObject](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_bioauthnresult-0000001050178040)对象认证时，使用KeyGenParameterSpec.Builder创建key时setUserAuthenticationRequired()必须为false。当前版本中，KeyStore没有与面容认证结果关联。

华为面容认证能力使用方法，如以下代码片段所示：

1. 构造[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_bioauthncallback-0000001050178012)。

   <br />

   ```
   "Java"
   // call back
   BioAuthnCallback callback = new BioAuthnCallback() {
       @Override
       public void onAuthError(int errMsgId, CharSequence errString) {
           showResult("Authentication error. errorCode=" + errMsgId + ",errorMessage=" + errString
                   + (errMsgId == 1012 ? " The camera permission may not be enabled." : ""));
       }
       @Override
       public void onAuthHelp(int helpMsgId, CharSequence helpString) {
           resultTextView
                   .append("Authentication help. helpMsgId=" + helpMsgId + ",helpString=" + helpString + "\n");
       }
       @Override
       public void onAuthSucceeded(BioAuthnResult result) {
           showResult("Authentication succeeded. CryptoObject=" + result.getCryptoObject());
       }
       @Override
       public void onAuthFailed() {
           showResult("Authentication failed.");
       }
   };
   ```

   ```
   "Kotlin"
   // call back
   val callback = object : BioAuthnCallback() {
       override fun onAuthError(errMsgId: Int, errString: CharSequence?) {
           showResult("Authentication error. errorCode=" + errMsgId + ",errorMessage=" + errString
                   + if (errMsgId == 1012) " The camera permission may not be enabled." else "")
       }
       override fun onAuthHelp(helpMsgId: Int, helpString: CharSequence?) {
           resultTextView!!
                   .append("Authentication help. helpMsgId=$helpMsgId,helpString=$helpString\n")
       }
       override fun onAuthSucceeded(result: BioAuthnResult) {
           showResult("Authentication succeeded. CryptoObject=" + result.cryptoObject)
       }
       override fun onAuthFailed() {
           showResult("Authentication failed.")
       }
   }
   ```

   <br />

2. 构造[FaceManager](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_facemanager-0000001050180181)，调用[auth](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthn_facemanager-0000001050180181#section1976213823115)方法。

   <br />

   ```
   "Java"
   // Cancellation Signal
   CancellationSignal cancellationSignal = new CancellationSignal();
   FaceManager faceManager = new FaceManager(this);
   // flags
   int flags = 0;
   // Authentication message handler.
   Handler handler = null;
   // Recommended CryptoObject to be set to null. KeyStore is not associated with face authentication in current
   // version. KeyGenParameterSpec.Builder.setUserAuthenticationRequired() must be set false in this scenario.
   CryptoObject crypto = null;
   faceManager.auth(crypto, cancellationSignal, flags, callback, handler);
   ```

   ```
   "Kotlin"
   // Cancellation Signal
   val cancellationSignal = CancellationSignal()
   val faceManager = FaceManager(this)
   // flags
   val flags = 0
   // Authentication message handler.
   val handler: Handler? = null
   // Recommended CryptoObject to be set to null. KeyStore is not associated with face authentication in current
   // version. KeyGenParameterSpec.Builder.setUserAuthenticationRequired() must be set false in this scenario.
   val crypto: CryptoObject? = null
   resultTextView!!.text = "Start face authentication.\nAuthenticating......\n"
   faceManager.auth(crypto, cancellationSignal, flags, callback, handler)
   ```
