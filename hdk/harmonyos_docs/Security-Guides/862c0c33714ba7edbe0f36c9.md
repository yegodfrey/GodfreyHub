# 集成Keyring客户端

## 用户登录场景

### 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230928103010.77653488930665717620385623127839:50001231000000:2800:5332F88E110512B9FC374AE23FB717C3239B33F96E57A79A23810F32331034B3.png?needInitFileName=true?needInitFileName=true "点击放大")

1. 用户打开应用后，应用在Keyring查找是否存在可用的凭据，如果存在，则跳转到[2](#ZH-CN_TOPIC_0000001135972364__li198889242424)，否则跳转到[3](#ZH-CN_TOPIC_0000001135972364__li108881524174210)。
2. 提示用户是否使用某个凭据登录，如果有多个凭据，建议您的应用展示一个列表让用户进行选择希望使用的凭据。如果只有一个凭据，您也可以忽略此步骤，直接跳转到[5](#ZH-CN_TOPIC_0000001135972364__li1288852410426)。
3. 您的应用引导用户输入用户名/密码，用户点击登录后，跳转到[4](#ZH-CN_TOPIC_0000001135972364__li088822415421)。
4. 您的应用记录一个状态，用户输入了新凭据，以便用户登录成功后把凭据保存起来，然后跳转到[5](#ZH-CN_TOPIC_0000001135972364__li1288852410426)。
5. 您的服务器验证用户认证凭据是否有效，如果验证通过，则跳转到[6](#ZH-CN_TOPIC_0000001135972364__li088812240429)，否则跳转到[3](#ZH-CN_TOPIC_0000001135972364__li108881524174210)，引导用户重新输入用户名/密码。
6. 判断用户是否输入了新凭据，如果是跳转到[7](#ZH-CN_TOPIC_0000001135972364__li13888102418420)，否则登录成功，流程结束。
7. 调用凭据存储接口，把新的凭据保存到Keyring中。

### 开发步骤

1. 使用一个Activity实例初始化[CredentialClient](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialclient-0000001133185186)，可以写在Activity的onCreate方法中。

   ```screen
   "Java"
   CredentialClient credentialClient = CredentialManager.getCredentialClient(this);
   ```

   ```screen
   "Kotlin"
   val credentialClient = CredentialManager.getCredentialClient(this)
   ```

2. 查询是否存在可用的凭据。

   ```screen
   "Java"
   List<AppIdentity> trustedAppList = new ArrayList<>();
   trustedAppList.add(new AndroidAppIdentity("yourAppName", "yourAppPackageName", "yourAppCodeSigningCertHash"));
   trustedAppList.add(new WebAppIdentity("youWebSiteName", "www.yourdomain.com"));
   trustedAppList.add(new WebAppIdentity("youWebSiteName", "login.yourdomain.com"));
   SharedCredentialFilter sharedCredentialFilter = SharedCredentialFilter.acceptTrustedApps(trustedAppList);
   credentialClient.findCredential(sharedCredentialFilter, new CredentialCallback<List<Credential>>() {
       @Override
       public void onSuccess(List<Credential> credentials) {
           if (credentials.isEmpty()) {
               Toast.makeText(MainActivity.this, R.string.no_available_credential, Toast.LENGTH_SHORT).show();
           } else {
               for (Credential credential : credentials) {
               }
           }
       }
       @Override
       public void onFailure(long errorCode, CharSequence description) {
           Toast.makeText(MainActivity.this, R.string.query_credential_failed, Toast.LENGTH_SHORT).show();
       }
   });
   ```

   ```screen
   "Kotlin"
   val credentialClient = CredentialManager.getCredentialClient(this)
   val trustedAppList: MutableList<AppIdentity> = ArrayList()
   trustedAppList.add(AndroidAppIdentity("yourAppName", "yourAppPackageName", "yourAppCodeSigningCertHash"))
   trustedAppList.add(WebAppIdentity("youWebSiteName", "www.yourdomain.com"))
   trustedAppList.add(WebAppIdentity("youWebSiteName", "login.yourdomain.com"))
   val sharedCredentialFilter = SharedCredentialFilter.acceptTrustedApps(trustedAppList);
   credentialClient.findCredential(sharedCredentialFilter, object : CredentialCallback<List<Credential>> {
       override fun onSuccess(credentials: List<Credential>) {
           if (credentials.isEmpty()) {
               Toast.makeText(this@MainActivity, R.string.no_available_credential, Toast.LENGTH_SHORT).show()
           } else {
               for (credential in credentials) {
               }
           }
       }
       override fun onFailure(errorCode: Long, description: CharSequence) {
           Toast.makeText(this@MainActivity, R.string.query_credential_failed, Toast.LENGTH_SHORT).show()
       }
   })
   ```

3. 调用[Credential.getContent](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188#section5681103510191)获取凭据内容，在[CredentialCallback<T>](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialcallback-0000001179304555)获取结果。

   ```screen
   "Java"
   private Credential mCredential; 
   //获取的凭据
   mCredential.getContent(new CredentialCallback<byte[]>() {
       @Override
       public void onSuccess(byte[] bytes) {
           String hint = String.format(getResources().getString(R.string.get_password_ok),
                   new String(bytes));
           Toast.makeText(MainActivity.this, hint, Toast.LENGTH_SHORT).show();
           mResult.setText(new String(bytes));
       }
    
       @Override
       public void onFailure(long l, CharSequence charSequence) {
           Toast.makeText(MainActivity.this, R.string.get_password_failed,
                   Toast.LENGTH_SHORT).show();
           mResult.setText(R.string.get_password_failed);
       }
   }); 
   ```

   ```screen
   "Kotlin"
   credential!!.getContent(object : CredentialCallback<ByteArray?> {
       override fun onSuccess(content: ByteArray?) {
           //成功获取到凭据 content，处理代码放这里
           val hint: String = kotlin.String.format(getResources().getString(R.string.get_password_ok),
           String(content!!))
           Toast.makeText(this@MainActivity, hint, Toast.LENGTH_SHORT).show()
           mResult.setText(String(content!!))
       }
    
       override fun onFailure(l: Long, charSequence: CharSequence?) {
           //获取凭据失败，处理代码放这里
           Toast.makeText(this@MainActivity, R.string.get_password_failed,
                   Toast.LENGTH_SHORT).show()
           mResult.setText(R.string.get_password_failed)
       }
   })
   ```

4. 用户输入了新凭据，调用凭据存储接口。

   ```screen
   "Java"
   AndroidAppIdentity app2 = new AndroidAppIdentity(sharedToAppName,
                   sharedToAppPackage, sharedToAppCertHash);
   List<AppIdentity> sharedAppList = new ArrayList<>();
   sharedAppList.add(app2);

   Credential credential = new Credential(username, CredentialType.PASSWORD, userAuth,
                   password.getBytes());
   credential.setDisplayName("user_niceday");
   credential.setSharedWith(sharedAppList);
   credential.setSyncable(true);

   credentialClient.saveCredential(credential, new CredentialCallback<Void>() {
       @Override
       public void onSuccess(Void unused) {
           Toast.makeText(MainActivity.this,
                   R.string.save_credential_ok,
                   Toast.LENGTH_SHORT).show();
       }
    
       @Override
       public void onFailure(long errorCode, CharSequence description) {
           Toast.makeText(MainActivity.this,
                   R.string.save_credential_failed + " " + errorCode + ":" + description,
                   Toast.LENGTH_SHORT).show();
       }
   });
   ```

   ```screen
   "Kotlin"
   val app2 = AndroidAppIdentity(sharedToAppName, sharedToAppPackage, sharedToAppCertHash)
   val sharedAppList: MutableList<AppIdentity> = ArrayList()
   sharedAppList.add(app2)

   val credential = Credential(username, CredentialType.PASSWORD, userAuth, password.toByteArray())
   credential.setDisplayName("user_niceday")
   credential.setSharedWith(sharedAppList)
   credential.syncable = true

   credentialClient.saveCredential(credential, object : CredentialCallback<Void?> {
       override fun onSuccess(unused: Void?) {
           Toast.makeText(this@MainActivity,
                   "save credential OK",
                   Toast.LENGTH_SHORT).show()
       }
    
       override fun onFailure(errorCode: Long, description: CharSequence) {
           Toast.makeText(this@MainActivity,
                   "save credential failed. $errorCode:$description",
                   Toast.LENGTH_SHORT).show()
       }
   })
   ```

## 用户登出场景

### 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230928103010.57803801166448726583312166385329:50001231000000:2800:118475CBB4AFF0C6C1A633A33E7C92C97347489DD39542D367D0169AA184636C.png?needInitFileName=true?needInitFileName=true)

1. 用户点击登出按钮。
2. 在服务器上执行登出用户的操作。
3. 为了防止用户进入登录界面后使用已经保存的凭据自动登录，需要您的应用停用自动登录的功能，用户手动登录成功后，可以再启用。
4. 如果应用在Keyring中保存了Token类型的凭据，用户登出后Token会失效，建议删除。

## 凭据共享机制

钥匙环服务提供两种凭据共享机制，帮助您在安卓应用、快应用、Web应用之间构建无缝登录体验。

### 通过API参数实现凭据共享

在调用[saveCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialclient-0000001133185186#section109797369169)保存凭据时，您可以通过[setSharedWith](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188#section1699664511331)设置[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)对象的属性实现凭据共享，最多支持共享给128个应用。

示例如下：

```screen
AndroidAppIdentity app1 = new AndroidAppIdentity("your android app name",
                "your android app package name", "3C:99:C3:....");
QuickAppIdentity app2 = new QuickAppIdentity("your quick app name",
                "your quick app package name", "DC:99:C4:....");
List<AppIdentity> sharedAppList = new ArrayList<>(); // 共享关系列表
sharedAppList.add(app1);
sharedAppList.add(app2);
Credential credential = new Credential("username", CredentialType.PASSWORD, true,
                "password".getBytes());
credential.setSharedWith(sharedAppList); // 设置共享关系
credentialClient.saveCredential(credential, new CredentialCallback<Void>() {
    @Override
    public void onSuccess(Void unused) {
        Toast.makeText(MainActivity.this,
                R.string.save_credential_ok,
                Toast.LENGTH_SHORT).show();
    }
    @Override
    public void onFailure(long errorCode, CharSequence description) {
        Toast.makeText(MainActivity.this,
                R.string.save_credential_failed + " " + errorCode + ":" + description,
                Toast.LENGTH_SHORT).show();
    }
});
```

### 通过Digital Asset Links资源实现凭据共享

您可以在Android应用的AndroidManifest.xml中添加凭据共享关系，方法如下：

1. 在AndroidManifest.xml的<application>节点中添加以下内容：

```screen
<application>
           <meta-data
            android:name="asset_statements"
            android:value="@string/asset_statements" />
</application>
```

2. 在res\values\strings.xml中添加以下内容：

```screen
<string name="asset_statements">your digital asset links statements</string> 
```

Digital asset links statements是一个遵循Digital Asset links规范的JSON字符串，示例如下：

```screen
[{
                   "relation": ["delegate_permission/common.get_login_creds"],
                   "target": {
                            "namespace": "web",
                            "site": "https://developer.huawei.com" // 您的网站域名
                   }
         },
         {
                   "relation": ["delegate_permission/common.get_login_creds"],
                   "target": {
                            "namespace": "android_app",
                            "package_name": "your android app package name",
                            "sha256_cert_fingerprints": [
                                     "F2:52:4D:..."
                            ]
                   }
         },
         {
                   "relation": ["delegate_permission/common.get_login_creds"],
                   "target": {
                            "namespace": "quick_app",
                            "package_name": "your quick app package name",
                            "sha256_cert_fingerprints": [
                                     "C3:68:9F:..."
                            ]
                   }
         }
]
```

relation属性的值固定为 ["delegate_permission/common.get_login_creds"]，表示把凭据共享给target属性所描述的应用。

target属性描述凭据共享的目标应用，根据应用的类型不同，分为以下三种情况：

1. web应用：

|属性名称|值|
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|namespace|web|
|site|网站的URL，格式为https://domain[:optional_port] domain为网站的域名，而且必须完全匹配，不支持通配符。 optional_port为网站端口号，使用http协议默认的443端口时，必须省略。例如https://developer.huawei.com site参数中不能包含路径，例如斜杠。 子域名不认为是匹配的：如果您指定的site为https://developer.huawei.com，域名login.developer.huawei.com不能使用您的凭据。|

2. Android应用：

|属性名称|值|
|:-----------------------|:----------------------------------------------------------------------------------------------|
|namespace|android_app|
|package_name|在应用清单中声明的包名称。例如com.huawei.android|
|sha256_cert_fingerprints|应用程序的签名证书的SHA256指纹。您可以使用以下命令来得到证书指纹： $ keytool -list -v -keystore your-android-app-fingerprints|

3. 快应用：

|属性名称|值|
|:-----------------------|:----------------------------------------------------------------------------------------------|
|namespace|quick_app|
|package_name|在应用清单中声明的包名称。例如com.huawei.quick|
|sha256_cert_fingerprints|应用程序的签名证书的SHA256指纹。您可以使用以下命令来得到证书指纹： $ keytool -list -v -keystore your-android-app-fingerprints|

除了把凭据共享关系（Digital Asset Links）直接嵌入到应用的资源内，还可以通过引用的方式嵌入Web资源。通过include属性引用一个https的网址，从该网址得到凭据共享关系，示例如下：

```screen
[
         {
                   "include": "https://developer.huawei.com/keyring"
         }
]
```

直接在App中嵌入Digital Asset Links的内容的和通过include方式引用Web资源的优缺点具体如下：

|方式|优点|缺点|
|:-------------------------|:--------------------------------|:----------------|
|直接嵌入Digital Asset Links的内容|不需要部署网络服务。|凭据共享关系变更时，需要发布版本。|
|通过include方式引用Web资源|凭据共享关系变更时，只需要变更网络服务器上的内容，不需要发布版本。|需要部署额外的服务器。|

## 优先级

通过API参数设置凭据共享关系的方式比Digital Asset Links方式的优先级高。只要Credential对象的sharedWith属性不为空就不会再尝试通过Digital Asset Links方式获取共享关系。

> 注意
>
> 当您在非华为设备上使用Keyring服务时，会关联启动HMS Core应用，对此您需要向用户明示并获取其同意。
