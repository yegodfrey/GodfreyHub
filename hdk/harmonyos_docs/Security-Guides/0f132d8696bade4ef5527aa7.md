# 业务介绍

## 业务简介

人脸识别（Face Recognition）是本地认证SDK的一部分，为您提供了认证使用者是否是机主的能力。人脸识别能力通过比对前置摄像头获取的人脸图像与预先录入的机主人脸图像，认证使用者是否为机主。

您可以基于人脸识别能力，在应用中认证使用者是否为机主，实现人脸登录、人脸支付等功能。

## 支持的设备

|设备类型|OS 版本|
|:-----------------|:---------------|
|支持3D人脸识别的华为手机、华为平板|EMUI 10.0及以上版本|
|支持2D人脸识别的华为手机、华为平板|EMUI 11.0.1及以上版本|

您可在人脸识别设置界面查看设备支持的人脸识别的类型。如界面显示的人脸识别声明为"关于人脸识别的声明"，则设备支持2D人脸识别。如界面显示的人脸识别声明为"关于3D人脸识别的声明"，则设备支持3D人脸识别。

## 场景介绍

人脸识别可以帮助您认证使用者是否为机主，适用于账号登录、支付等场景。
