# 业务简介

本地生物特征认证BioAuthn SDK和BioAuthn-AndroidX SDK区别如下：

* BioAuthn-AndroidX SDK基于androidx.biometric API开发。BioAuthn SDK基于android.hardware.fingerprint开发。

* BioAuthn-AndroidX SDK的指纹认证能力提供统一界面，不需要应用自己绘制指纹认证提示界面；BioAuthn SDK的指纹认证能力不提供统一界面，需要应用自己绘制指纹认证提示界面。

* 对于屏下指纹的手机，指纹提示界面由EMUI控制，而不是BioAuthn SDK、BioAuthn-Androidx SDK控制。

## 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230927165411.71506531048231013795194351231049:50001231000000:2800:A1714DE6828DE7073E2B55F1C82813252D0B123406070D2BE92A1A7E05F79EB1.png?needInitFileName=true?needInitFileName=true "点击放大")

1. 应用App集成FIDO BioAuthn SDK。
2. FIDO BioAuthn SDK调用Safety Detect SysIntegrity检测确认设备运行环境是否安全。
3. 当运行环境安全时，FIDO BioAuthn SDK进行本地生物特征认证；当运行环境不安全，直接返回未通过系统完整性检查。
