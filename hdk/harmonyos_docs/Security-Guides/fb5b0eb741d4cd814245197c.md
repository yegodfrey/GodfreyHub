# 版本更新说明

## 1.1.1（2021-12-09）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.security:localauthentication:1.1.1 **新增特性** 新增[FaceRecognitionCapability](https://developer.huawei.com/consumer/cn/doc/development/Security-References/facerecognitioncapability-0000001064416874)类、FaceManager类的[getFaceRecognitionCapability](https://developer.huawei.com/consumer/cn/doc/development/Security-References/facemanager-0000001051358144#section1840313536188)方法。支持获取人脸识别能力，包括设备是否支持人脸识别、是否已录入人脸、是否支持人脸识别类型是否为3D。|

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
