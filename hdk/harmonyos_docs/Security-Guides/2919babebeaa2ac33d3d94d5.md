# 系统完整性检测API

#### 系统特性

|-------------------------------------------------------------------------------------------------------------------------------------------------------------|------|
|1. 基于可信执行环境TEE提供系统完整性检测结果：在设备安全启动时，在TEE中评估检测系统完整性，可信度高，并动态评估系统完整性。 2. 系统完整性检测结果安全可信：系统完整性检测结果请求证书签名；服务端使用X.509数字证书对系统完整性检测结果签名，使用JWS格式回传给系统完整性检测API，签名结果不可篡改。|<br />|

#### 业务流程

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251017092005.26394796528419196147011318521616:50001231000000:2800:31FCBE67ACF41756157B38392D06A7634067AA91425505D32D635F78718D1781.png)

1. 您的App集成HMS Core SDK调用Safety Detect service。
2. 请求TSMS服务器签名检测结果。
3. 您的App请求自己服务检测结果。  

#### 典型场景

应用需要检测系统完整性时，调用系统完整性检测API，检测系统完整性是否被破坏，针对不安全设备采取相应的措施。  

#### 应用开发

调用SysIntegrity API主要分为三个步骤：

1. 获取nonce。

   <br />

   在调用Safety Detect SysIntegrity API时，您必须传入一个随机生成的nonce值。在检测结果中会包含这个nonce值，您可以通过校验这个nonce值来确定返回结果能够对应您的请求，并且没有被重放攻击。如果nonce值长度超出16-66字节范围，将导致调用失败，请参考下方注意说明内容。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251017092005.03823392512683555383808960153629:50001231000000:2800:7B87BF605922ED511E06024BCFA86C156CF19EC462E7BA6E91074DE48A51B0BA.png)  
   nonce值必须满足以下条件：
   * nonce值必须为16至66字节之间。

   <!-- -->

   * 推荐的做法是，每次请求都从服务器随机生成新的nonce值。

   <br />

2. 请求Safety Detect SysIntegrity。

   <br />

   Safety Detect SysIntegrity提供两个接口，调用只有参数上的不同，都需要传入的参数是nonce和APP ID。[sysIntegrity(SysIntegrityRequest sysIntegrityRequest)](https://developer.huawei.com/consumer/cn/doc/Security-References/safetydetectclientapi-0000001050175445#section19111747171418)接口还需要在[SysIntegrityRequest](https://developer.huawei.com/consumer/cn/doc/Security-References/sysintegrityrequest-0000001062917681)中传入签名的验证方式，这个将和您获取的JWS的Header中alg一致。
   * nonce：上一小节我们获取的nonce值。
   * APP ID：您可以通过如下方式获取APP ID。

   登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。

   在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。

   在"项目设置 \> 常规"页面的"应用"区域，可以查看应用的APP ID。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251017092005.07060228594764356154991889255646:50001231000000:2800:001EA93601D7D1A68A592326E9E6DE67EE830F5A5F799A2EA1CA14EDC7C87E02.png "点击放大")

   "Java"
   private void invokeSysIntegrity() {
      SafetyDetectClient mClient = SafetyDetect.getClient(getActivity());
      // TODO(developer): Change the value of nonce to a random value generated by the server.
      byte[] nonce = 从服务器生成的随机的nonce值;
      String alg = "PS256";
      SysIntegrityRequest  sysintegrityrequest = new SysIntegrityRequest();
      sysintegrityrequest.setAppId("3*******");
      sysintegrityrequest.setNonce(nonce);
      sysintegrityrequest.setAlg(alg);                                                              
      Task task = mClient.sysIntegrity(sysintegrityrequest);
      task.addOnSuccessListener(new OnSuccessListener<SysIntegrityResp>() {
          @Override
          public void onSuccess(SysIntegrityResp response) {
              // Indicates communication with the service was successful.
              // Use response.getResult() to get the result data.

          @Override

              // An error occurred while communicating with the service.

   <br />

3. 在您的服务器中验证检测结果。

   <br />

   HMS Core帮助您将验证结果发送到华为服务器校验证书的准确性并将完成校验的结果通过[SysIntegrityResp](https://developer.huawei.com/consumer/cn/doc/Security-References/safetydetectsysintegrityresp-0000001050173460)返回，使用此对象的[getResult](https://developer.huawei.com/consumer/cn/doc/Security-References/safetydetectsysintegrityresp-0000001050173460#section12859145861018)方法获取响应，格式为JSON WEB签名（JWS）。
   1. 解析JWS，获取header、payload、signature。
   2. 从header中获取证书链，使用[Huawei CBG Root CA](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyManage/011/111/111/0000000000011111111.20200113201542.07296797553983843176118547913293:50510425034500:2800:9402EC259426607F9DCF70F30C846E21C7AF76E26E46EE07C619536DD27E9CC7.zip?needInitFileName=true)证书对其进行验证。
   3. 校验证书链中的叶证书域名，域名：sysintegrity.platform.hicloud.com。
   4. 从signature中获取签名，校验其签名。
   5. 从payload中获取完整性验证结果，格式和样例摘录如下：

      ```
      {
               "advice": "RESTORE_TO_FACTORY_ROM",
               "apkCertificateDigestSha256": ["gwpz0q/WtjtJZZK5lTXl74fI/8QAKGLAhdhlznKkLhQ="],
               "apkDigestSha256": "nBrInk2DLVQrgcQ1DXYnIUIMnjJ+mVo0lwUicF7OzJM=",
               "apkPackageName": "com.huawei.hms.safetydetectsample",
               "appId": "1*******",
               "basicIntegrity": false,
               "detail": ["root", "unlocked"],
               "nonce": "UjJScmEyNGZWbTV4YTJNZw==",
               "timestampMs": 1612683290520
      }
      ```

      当检测结果中basicIntegrity为false，detail字段会列出检测结果为false的原因，具体描述请[参考](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/safetydetectsysintegrityresp-0000001050173460-V5#section12859145861018)，您可以根据自身功能对安全的要求决定是否提醒用户。

#### 注意事项

1. 当前方案已经通过服务端与客户端相结合等措施进行安全风险消减，但系统完整性检测API无法消减所有的安全风险。
2. 调用系统完整性检测API获取结果应该考虑检测结果误报带来的风险以及给用户带来的影响。系统完整性检测结果可以用作系统整体安全的一个环节，不建议将系统完整性检测结果作为判断当前设备是否安全的唯一依据，更好的做法是通过额外的步骤降低风险。
