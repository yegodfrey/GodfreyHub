# 添加权限

人脸识别SDK需要获取相机权限（仅EMUI 10.0版本）、人脸识别权限。需要在"AndroidManifest.xml"文件中添加权限：

```screen
/* 获取相机权限（仅EMUI10.0版本） */
<uses-permission android:name="android.permission.CAMERA" />
/* 获取人脸识别权限 */
<uses-permission android:name="android.permission.USE_FACERECOGNITION" /> 
```
