# 业务介绍

#### 服务简介

华为Asset存储是提供安全存储、删除、更新、查询短敏感数据的能力。  

#### 服务场景

Asset存储可用于保存、删除、更新、查询短敏感数据的场景，包括用户名密码、信用卡信息、App Token等长度在64字节以内的数据。  

#### 服务特点

* 方便：可覆盖多种存储及管理短敏感数据的场景。

* 安全：密钥存储在TEE安全世界（密钥安全），最优加解密算法（算法安全），数据加密存储（数据安全）等。

* 便捷：使用该SDK，可以大大节省安全性开发的时间，包括对加解密算法的选择及迭代、关键资产数据存储及管理的安全性等。
