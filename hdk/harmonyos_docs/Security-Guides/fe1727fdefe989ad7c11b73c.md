# 个人数据处理说明

此文档针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，华为作为数据处理者需要处理的个人数据清单。  

#### 华为处理的个人数据清单

|个人数据清单|使用目的|存留期|
|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------|
|生物数据：指纹|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 在应用读取凭据内容前，为确保当前设备使用者是机主本人，需要进行指纹验证。 指纹验证调用Android和HarmonyOS本地生物验证API完成。指纹数据仅在设备本地可信执行环境(TEE)中采集、保存和比对。|指纹数据仅在设备本地采集、保存和比对，没有在云侧处理。|
|帐号信息：用户登录ID|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 帐号信息在设备本地加密后，上传到云侧保存，用于同步到登录了同一个华为帐号并且经过用户安全验证的其他设备。|留存到用户注销华为帐号。用户注销华为帐号后即删除。|
|帐号信息：用户名|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 帐号信息在设备本地加密后，上传到云侧保存，用于同步到登录了同一个华为帐号并且经过用户安全验证的其他设备。|留存到用户注销华为帐号。用户注销华为帐号后即删除。|
|帐号信息：用户头像链接|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 帐号信息在设备本地加密后，上传到云侧保存，用于同步到登录了同一个华为帐号并且经过用户安全验证的其他设备。|留存到用户注销华为帐号。用户注销华为帐号后即删除。|
|帐号信息：登录密码|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 帐号信息在设备本地加密后，上传到云侧保存，用于同步到登录了同一个华为帐号并且经过用户安全验证的其他设备。|留存到用户注销华为帐号。用户注销华为帐号后即删除。|
|帐号信息：用户Token|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 帐号信息在设备本地加密后，上传到云侧保存，用于同步到登录了同一个华为帐号并且经过用户安全验证的其他设备。|留存到用户注销华为帐号。用户注销华为帐号后即删除。|
|帐号信息：华为帐号ID|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 帐号信息在设备本地加密后，上传到云侧保存，用于同步到登录了同一个华为帐号并且经过用户安全验证的其他设备。|留存到用户注销华为帐号。用户注销华为帐号后即删除。|
|设备信息：设备标识符、AndroidID|钥匙环服务作为数据处理者为最终用户提供跨应用和跨设备登录凭据共享功能。 帐号信息在设备本地加密后，上传到云侧保存，用于同步到登录了同一个华为帐号并且经过用户安全验证的其他设备。|留存到用户注销华为帐号。用户注销华为帐号后即删除。|

#### 帮助最终用户控制个人数据

如何清除最终用户的个人数据

可以通过调Keyring的[CredentialClient.deleteCredential](https://developer.huawei.com/consumer/cn/doc/Security-References/credentialclient-0000001133185186#section1766202311152)接口来删除保存的用户凭据信息。
