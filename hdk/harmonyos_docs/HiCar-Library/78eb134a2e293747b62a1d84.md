# 获取说明

目前HUAWEI HiCar仅向合作中的开发者开放应用接入SDK和设备接入SDK，SDK获取说明如下表所示。

|接入分类|类别|所需SDK|获取方式|
|:---|:----------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|应用接入|音频应用|CarBaseEngine|在申请接入HiCar获得同意后，参考[获取文档](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/get-docs-app-0000001150423322)发送邮件申请文档权限并获批后，重新登录本页面，切换到左侧CarBaseEngine菜单即可查看SDK下载链接。|
|应用接入|普通应用（即非音频、非地图类应用）|CarBaseEngine|在申请接入HiCar获得同意后，参考[获取文档](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/get-docs-app-0000001150423322)发送邮件申请文档权限并获批后，重新登录本页面，切换到左侧CarBaseEngine菜单即可查看SDK下载链接。|
|应用接入|地图应用|-|请参考[应用接入流程](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/app-process-0000001056059155)线下获取。|
|设备接入|Android设备|-|请参考[设备接入流程](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/device-process-0000001052717625)线下获取。|
|设备接入|Linux设备|-|请参考[设备接入流程](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/device-process-0000001052717625)线下获取。|
