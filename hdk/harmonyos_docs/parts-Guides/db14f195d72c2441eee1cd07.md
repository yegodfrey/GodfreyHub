# 1. DFH简介

DFH是华为智能手机、平板电脑、可穿戴设备等的配件合作伙伴计划，致力于与创新的合作伙伴一起，提供与华为终端产品相兼容的配件和配套设备，为消费者提供更丰富的配件选择和更好的用户体验。

华为将对于通过验收测试的产品授权其在该产品外包装上（非产品本体）使用DFH标识。

# 2. DFH合作伙伴的机会

* 产品上市：更早的获取华为终端产品的相关信息，与华为终端产品同步上市；

* 市场支持：更多品牌露出机会与华为产品联合推广；

* 销售渠道：进入华为线下体验店和线上Vmall商城销售。

# 3. DFH合作伙伴的要求

* 能够提供与华为智能手机、平板电脑、可穿戴设备等相兼容的配件或配套设备；

* 拥有自主研发能力、自主销售品牌和售后服务能力（若进入华为线下体验店销售，需具备线下服务的能力）；

* 具备一定的经营实力和销售规模。
