针对AndroidStudio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的AndroidStudio开发环境中。

1\. 在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件。

a. 登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

b. 在名称列表中找到应用所在的产品，点击应用名称。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191210104521.26959532476608477028413462538372:50510418081102:2800:4EF2B4748D5E67EB56428A9DD103A8761409CBF8BBB38AE39BDF5EF9915AC937.png?needInitFileName=true)

c. 选择“开发 > 概览”。

d. 单击“应用”栏下的“agconnect-services.json”下载配置文件。

e. 将agconnect-services.json文件拷贝到应用级根目录下。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191206151707.29547031515453412837521432306055:50510418081102:2800:3292957734F8EF3A263AE8937A6CCBE35E74801246D6145165420C748E2C2D6F.png?needInitFileName=true)

2\. 配置HMS SDK的maven仓地址。

a. 打开AndroidStudio项目级build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191206151707.62115646170394053882302549439995:50510418081102:2800:784343B9FBF3500B4A3A81A75425042620F56F716105BC86F286E702BB1ADD4D.png?needInitFileName=true)

b. 在allprojects ->repositories里面配置HMS SDK的maven仓地址。
      
      1. allprojects {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {url 'https://developer.huawei.com/repo/'}
        6.     }
        7. }
    
    

c. 在buildscript ->repositories里面配置HMS SDK的maven仓地址。
      
      1. buildscript {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {url 'https://developer.huawei.com/repo/'}
        6.     }
        7. }
    
    

d. 在buildscript -> dependencies里面增加配置。
      
      1. buildscript {
        2.     dependencies {
        3.         classpath 'com.huawei.agconnect:agcp:1.0.0.300'
        4.     }
        5. }
    
    

说明：

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

3\. 添加编译依赖。  


a. 打开应用级的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191206151708.29613703002263703756956979903484:50510418081102:2800:15B305D74FFAD04804CCC6D352D7A82B6C7E5A01C743719494812E40041FC329.png?needInitFileName=true)

b. 在“dependencies”中添加如下编译依赖。
      
      1. dependencies {
        2.      //其它已存在的依赖不要删除
        3.      implementation 'com.huawei.hms:push:{version}'
        4.  }
    
    

说明：

{version} 替换为实际的SDK版本号，如：implementation 'com.huawei.hms:push:3.0.3.301'。

  


c. 在应用级build.gradle文件头添加配置。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191206151708.36767727358566456250353564092136:50510418081102:2800:E27DBE7FCA142023A665C0712B00AB766259165797DDD7CEF9539AFCE1BE89B5.png?needInitFileName=true)

d. 在“android”中配置签名。

将生成签名证书指纹步骤中生成的签名文件拷贝到工程的app目录下，在build.gradle文件中配置签名。
      
      1. android {
        2.      signingConfigs {
        3.          config {
        4.              keyAlias 'pushdemo'
        5.              keyPassword '123456789'
        6.              storeFile file('pushdemo.jks')
        7.              storePassword '123456789'
        8.          }
        9.      }
        10.      buildTypes {
        11.          debug {
        12.              signingConfig signingConfigs.config
        13.          }
        14.          release {
        15.              signingConfig signingConfigs.config
        16.              minifyEnabled false
        17.              proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        18.          }
        19.      }
        20.  }
    
    

4\. 修改完的**build.gradle** 文件右上方出现**Sync Now** 链接。点击“Sync Now”等待同步完成。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191206151737.12408782128739988151358486814937:50510418081102:2800:3F00E936D4B3E0C282F4A18DCB0D378C6740724361817C4EB51D79F9FB73D17C.png?needInitFileName=true)

说明：

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

5\. 多语言设置。  


●  如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。

●  如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。

打开应用级根目录的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191206151737.43421019745206206857329128440067:50510418081102:2800:2A86A65F35081C7AB8689CE54C5E735BCC1BAF942359D382820D93503B8E8540.png?needInitFileName=true)

在**android- >defaultConfig**中新增**resConfigs** 配置，**en** （英语） 和 **zh-rCN** （简体中文）为必须配置的语种，配置格式如下：
      
      1. android {
        2.         defaultConfig {
        3.                 ...
        4.                 resConfigs "en", "zh-rCN", "需要支持的其他语言"
        5.         }
        6. }
    
    

HMS SDK支持的语言列表请参考[HMS SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/hmssdk_language)。
