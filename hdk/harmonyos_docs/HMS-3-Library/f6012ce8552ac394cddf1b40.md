# 1\. AppGallery Connect 配置

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 1.1 注册成为开发者

在开发应用前需要在华为开发者联盟网站上注册成为开发者并完成实名认证，具体方法可参考帐号[注册认证](https://developer.huawei.com/consumer/cn/doc/start/20300)。

## 1.2 创建应用

参见AppGallery Connect帮助中心的创建应用章节[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/AppGallery-Connect/agc-create_app)，特殊配置如下： 

  * “软件包类型”：选择“APK(Android应用)”。

  * “支持设备”：选择“手机”。 

  * “应用包名”：必须与最终发布的APK包名一致。

  * “应用分类”：选择“应用”或“游戏”。




## 1.3 生成签名证书指纹

签名证书指纹用于在通过华为HMS SDK访问华为移动服务（HMS）的能力时，校验应用的真实性。开发者在使用HMS SDK服务前必须将签名证书指纹配置到华为开发者联盟，在配置前需要根据签名证书在本地生成签名证书指纹。 在申请前需要满足以下2个条件：

  * 已创建应用程序的签名文件，签名证书创建属于通用技术，此处不详细描述。

  * 当前开发的PC已经安装JDK。




操作步骤如下：

1、打开命令行工具（使用CMD命令），执行cd命令进入keytool.exe所在的目录（图中样例为PC上java程序安装在C盘的Program Files (x86)目录）。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191108104648.67575027536385252195067651949482:50510721075425:2800:293F8A14B7271F22F0140D749C2DC50C7CCBF7B9C17DF19CCAE9B70963ABC656.png?needInitFileName=true)

2、执行命令keytool -list -v –keystore <keystore-file> ，按命令行提示进行操作。<keystore-file>为应用签名文件的完整路径。 例如：
      
      1. keytool -list -v –keystore SDK_2.5.1.300_2.5.1.300_AS.keystore
    
    

3、根据结果获取对应的SHA256指纹。

## 1.5 打开相关服务

需要使用华为安全检测功能的应用必须打开华为安全检测服务。具体操作步骤请参见[开通服务](https://developer.huawei.com/consumer/en/doc/distribution/AppGallery-Connect/agc-enable_service)。

# 2\. 集成 HMS SDK

针对AndroidStudio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的AndroidStudio开发环境中。

1、在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件。

a、登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。

b、在名称列表中找到应用所在的产品，点击对应手机设备的“Android应用”链接。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191108113508.54752050359969361130441985087477:50510721075425:2800:D390846637CEB9A5994076956A7797D7E80DEBA02648383D5316DB4B29111B50.png?needInitFileName=true)

c、选择“开发 > 概览”。

d、单击“应用”栏下的“agconnect-service.json”下载配置文件。

e、将“agconnect-service.json”文件拷贝到应用级根目录下。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191108113535.20541191141149330305104468724113:50510721075425:2800:32A7A0166D1967ADD5AF8CC14AEA2464B87124DD561949310FB8D94138F02604.png?needInitFileName=true)

2、配置HMS SDK的maven仓地址。

a、打开AndroidStudio项目级build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191108113546.43852280207072488076634379848915:50510721075425:2800:857B7A775CDB0A28D1EFF72314589AA5AF8CFFF5A3585CB5997EA9C4ED037651.png?needInitFileName=true)

b、在allprojects ->repositories 里面配置HMS SDK的maven仓地址。
      
      1. allprojects {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {
        6.             url 'https://developer.huawei.com/repo/'
        7.         }
        8.     }
        9. }
    
    

说明：

maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

c、在buildscript->repositories中配置HMS SDK的maven仓地址。  

      
      1. buildscript {
        2.     repositories {
        3.         google()
        4.         jcenter()
        5.         maven {
        6.             url 'https://developer.huawei.com/repo/'
        7.         }
        8.     }
        9. }
    
    

d、在buildscript->dependencies中配置AppGallery Connect插件地址。
      
      1. buildscript {
        2.     dependencies {
        3.         classpath 'com.android.tools.build:gradle:3.3.0'
        4.         classpath 'com.huawei.agconnect:agcp:1.0.0.300'
        5.     }
        6. }
    
    

3、添加编译依赖。和AppGallery Connect插件地址。

a、打开应用级的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191108113808.81954887975475262264556598086449:50510721075425:2800:D777FFE9CD340362C05B087CA79988E113C44D6424B24B600A6E4CC71C61AEE6.png?needInitFileName=true)

b、在文件头添加AppGallery Connect插件依赖。
      
      1. apply plugin: 'com.huawei.agconnect'
    
    

c、在“dependencies”中添加如下编译依赖。
      
      1. dependencies {
        2.     implementation 'com.huawei.hms:safetydetect:3.0.3.300'
        3. }
    
    

4、重新打开修改完的build.gradle文件，右上方出现“Sync Now”链接。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191108113913.93327452066159993362966841350164:50510721075425:2800:413BBFD8D1457B1CF6354C67916AA0B98B64EB81189401C5411FB8B9FD335FDA.png?needInitFileName=true)

点击“Sync Now”等待同步完成。

说明：

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

5、多语言设置。  


如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。 

如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。

打开项目工程下app目录的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191108114006.59782830075560672342941195154301:50510721075425:2800:F310D7A136996554518D82B554030667CDB356CD5C17C56DF19C9FFB1BB71AE2.png?needInitFileName=true)

在“android”->“defaultConfig”中新增resConfigs配置，“en”（英语） 和 “zh-rCN”（简体中文）为必须配置的语种，配置格式如下：
      
      1. android {
        2.    defaultConfig {
        3.        ...
        4.        resConfigs "en", "zh-rCN", "需要支持的其他语言"
        5.    }
        6. }
    
    

HMS SDK支持的语言列表请参考[HMS SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/hmssdk_language)。

6、配置manifest文件

（必选）用于HMS SDK引导升级HMS APK，提供给系统安装器读取升级文件。
      
      1. <provider
        2. android: name = "com.huawei.hms.update.provider.UpdateProvider"
        3. android: authorities = "xxx.xxx.xxx.hms.update.provider"
        4. android: exported = "false"
        5. android: grantUriPermissions = "true" >
        6. </provider>
    
    

# 3\. 配置混淆脚本

开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。

1、打开工程的混淆配置文件。 

2、加入排除HMS SDK的混淆配置。
      
      1. -ignorewarning 
        2. -keepattributes *Annotation* 
        3. -keepattributes Exceptions 
        4. -keepattributes InnerClasses 
        5. -keepattributes Signature 
        6. -keepattributes SourceFile,LineNumberTable 
        7. -keep class com.hianalytics.android.**{*;} 
        8. -keep class com.huawei.updatesdk.**{*;} 
        9. -keep class com.huawei.hms.**{*;}
    
    

3、如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard白名单。  

      
      1. "R.string.hms*",
        2. "R.string.agc*",
        3. "R.string.connect_server_fail_prompt_toast",
        4. "R.string.getting_message_fail_prompt_toast",
        5. "R.string.no_available_network_prompt_toast",
        6. "R.string.third_app_*",
        7. "R.string.upsdk_*",
        8. "R.layout.hms*",
        9. "R.layout.upsdk_*",
        10. "R.drawable.upsdk*",
        11. "R.color.upsdk*",
        12. "R.dimen.upsdk*",
        13. "R.style.upsdk*
