# 1\. AppGallery Connect配置

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 1.1 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn/)网站上注册成为开发者并完成实名认证，具体方法可参考[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/20300)。

## 1.2 创建应用

参见AppGallery Connect帮助中心的[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/50102)章节创建应用，联运应用的特殊配置如下：  
● “软件包类型”：选择“APK(Android应用)”。  
● “支持设备”：选择“手机”。  
● “应用分类”：选择“应用”或“游戏”。

## 1.3 生成签名证书指纹

签名证书指纹用于在通过华为HMS SDK调用HMS Core（APK）时，校验应用的真实性。开发者在使用HMS Core（APK）前必须将签名证书指纹配置到华为开发者联盟，在配置前需要根据签名证书在本地生成签名证书指纹。在申请前需要满足以下2个条件：  
● 已创建应用程序的签名文件，签名证书创建属于通用技术，此处不详细描述。  
● 当前开发的PC已经安装JDK。

操作步骤如下：

1、打开命令行工具（使用CMD命令），执行cd命令进入keytool.exe所在的目录（图中样例为PC上java程序安装在C盘的Program Files 目录）。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200106160355.16810516679156713397153822216734:50510722113522:2800:E9E0EB1FB82B25F6A949E8FB3E6A2192201C0C2960F8927C79CFCAD0254626F5.png?needInitFileName=true?needInitFileName=true)

2、执行命令**keytool -genkey -alias** _android_test_key_ **-keyalg** _RSA_ **-keystore** _< keystore-file>_，按命令提示进行生成签名文件。

-alias android_test_key，这里"android_test_key"为别名，可以是任意字符，只要不提示错误即可。

-keyalg RSA，这里"RSA"为密钥的算法。

-keystore <keystore-file>，这里<keystore-file>为应用签名文件的完整路径。

例如：
      
      1. C:\Program Files\Java\jdk1.8.0_181\bin>keytool -list -v -keystore E:\HMS_SDK_2.5.1.300\Sample\HMSSdkSample_2.5.1.300_AS\HmsSample\android.keystore
    
    

3、执行命令**keytool -list -v -keystore**  <keystore-file>，按命令行提示进行操作。

<keystore-file>为应用签名文件的完整路径。  
例如：  

      
      1. C:\Program Files\Java\jdk1.8.0_181\bin>keytool -list -v -keystore E:\HMS_SDK_2.5.1.300\Sample\HMSSdkSample_2.5.1.300_AS\HmsSample\android.keystore
    
    

4、根据结果获取对应的SHA256指纹。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114095703.70644291123561442954074678532481:50510722113522:2800:3589FEF40DA101F43CC056ADD1267D38AAC2707421677CC818D0D18834625EC0.png?needInitFileName=true?needInitFileName=true)

## 1.4 配置签名证书指纹

1、登录 [AppGallery Connect ](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的应用”。

2、找到对应应用产品，选择并点击“Android应用”链接，进入应用开发页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114095728.60249836624836898844181700313005:50510722113522:2800:B35CCB8AE121DF6285B6C604FE69F6AB7A83DFF156BA1C199E18CF0AE4E60885.png?needInitFileName=true?needInitFileName=true)

3、在“SHA256证书指纹”配置栏，输入生成签名证书指纹章节中生成的SHA256指纹。

4、配置完成后，点击![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20200119154515.18486167687470278116913127960814:50510722113522:2800:6DDE68AC24032C5CB023DFCC8E115032807DB971346456C724ABB587AD2A8A34.png?needInitFileName=true?needInitFileName=true)。

## 1.5 打开相关服务

● 如果您的应用需要接入华为帐号登录功能，需要开通帐号服务。  
具体操作步骤请参见[打开服务](https://developer.huawei.com/consumer/cn/doc/distribution/AppGallery-Connect/agc-enable_service)。

# 2\. 集成HMS SDK

针对AndroidStudio开发环境，华为提供了maven仓集成方式的HMS SDK包。在开始开发前，您需要将HMS SDK集成到您的AndroidStudio开发环境中。

1、在AndroidStudio开发环境中添加当前应用的AppGallery Connect配置文件。    

a.登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择“我的应用”。    

b.在名称列表中找到应用所在的产品，点击对应手机设备的“Android应用”链接。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114100959.70978040411110674691726712921756:50510722113522:2800:200E4DB01B409EC7267D81E20B09FA3F177D835341749F025D2BFCCA16B53945.png?needInitFileName=true?needInitFileName=true)

c.选择“开发 > 概览”。    

d.单击“应用”栏下的“agconnect-service.json”下载配置文件。    

e.将“agconnect-service.json”文件拷贝到应用级根目录下。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114101025.72016790062789208133569187752284:50510722113522:2800:37C7401E6BDA81972591E0DE98B446263D8BE9E8EBE7B1893E936E749118CD5F.png?needInitFileName=true?needInitFileName=true)

2、配置HMS SDK的maven仓地址。   

a.打开AndroidStudio项目级build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114101046.97066339880237437351465630214055:50510722113522:2800:5E74BC274891952DBB36672A24CD2E2DF7D61872E18E89070743A96387159F55.png?needInitFileName=true?needInitFileName=true)

 b.在allprojects ->repositories里面配置HMS SDK的maven仓地址。
      
      1. allprojects { 
        2.     repositories { 
        3.     google() 
        4.     jcenter()         
        5.     maven {url 'https://developer.huawei.com/repo/'} 
        6.   } 
        7. }
    
    

 c.在buildscript ->dependencies里面增加配置。
      
      1. buildscript {
        2.     repositories {
        3.         maven { url 'https://developer.huawei.com/repo/' }
        4.         google()
        5.         jcenter()
        6.     }
        7.     dependencies {
        8.         classpath 'com.android.tools.build:gradle:3.4.0'
        9.         classpath 'com.huawei.agconnect:agcp:1.1.1.300'
        10.     }
        11. }
    
    

**说明** ：    

仓地址直接在浏览器中打开无法访问，只能在IDE中配置。

3 添加编译依赖。

a. 打开应用级的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114101308.44237347860248417318768457883358:50510722113522:2800:A2850C9BA801D108FCB7186A51B85DA7F3AD6E83E39A661A43287440483508DF.png?needInitFileName=true?needInitFileName=true)

b.在“dependencies”中添加如下编译依赖。 
      
      1. dependencies {
        2.     implementation 'com.huawei.hms:hwid:{version}'
        3. }
    
    

**说明：**

hwid为华为帐号服务，{version} 替换为实际的SDK版本号，

如：implementation 'com.huawei.hms:hwid:3.0.3.301'。 

c.在文件头添加配置  

      
      1. apply plugin: 'com.huawei.agconnect'
    
    

4、保存修改，单击右上角同步按钮，等待同步完成。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114101533.49381690387203098423310708147946:50510722113522:2800:92D55AD58FB36A17600C94F7D9E5858F0EDC77F5DBA474C66D0F2F2FB2BD80CD.png?needInitFileName=true?needInitFileName=true)

**说明：**

如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

5、多语言设置。  
   ●  如果您的应用不需要设置只支持某些特定语言，则请忽略本步骤。应用将默认支持所有HMS SDK支持的语言。  
   ●  如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。  
打开项目工程下app目录的build.gradle文件。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20191114101743.73331215136343381563672723755581:50510722113522:2800:EAF4A46C276236D2B8C9BB36786906B8BAEEC0781B25FCD4203C504E0E10D831.png?needInitFileName=true?needInitFileName=true)

在“android”->“defaultConfig”中新增resConfigs配置，“en”（英语） 和 “zh-rCN”（简体中文）为必须配置的语种，配置格式如下：
      
      1. android{ 
        2.   defaultConfig{ 
        3.   ... 
        4.   resConfigs "en","zh-rCN","需要支持的其他语言"
        5.   } 
        6. }
    
    

HMS SDK支持的语言列表请参考[HMS SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/hmssdk_language)。

# 3\. 配置混淆脚本

开发者编译APK前需要配置不要混淆HMS SDK，避免功能异常。  
1、打开工程的混淆配置文件。

2、加入排除HMS SDK的混淆配置。
      
      1. -ignorewarning 
        2. -keepattributes *Annotation* 
        3. -keepattributes Exceptions 
        4. -keepattributes InnerClasses 
        5. -keepattributes Signature 
        6. -keepattributes SourceFile,LineNumberTable 
        7. -keep class com.hianalytics.android.**{*;} 
        8. -keep class com.huawei.updatesdk.**{*;} 
        9. -keep class com.huawei.hms.**{*;}
    
    

3、如果开发者使用了AndResGuard，需要在混淆配置文件中加入AndResGuard允许清单。
      
      1. "R.string.hms*", 
        2. "R.string.connect_server_fail_prompt_toast", 
        3. "R.string.getting_message_fail_prompt_toast", 
        4. "R.string.no_available_network_prompt_toast", 
        5. "R.string.third_app_*", 
        6. "R.string.upsdk_*", 
        7. "R.layout.hms*", 
        8. "R.layout.upsdk_*", 
        9. "R.drawable.upsdk*", 
        10. "R.color.upsdk*", 
        11. "R.dimen.upsdk*", 
        12. "R.style.upsdk*",
        13. "R.string.agc*"
