# 采购华为全屋设备

在启动云云对接前，需要先准备一套简单的华为全屋设备，建议找华为销售按需采购；建议采购如下设备：

* 1台华为智能主机SE +1个智能开关(3键开关)+1个窗帘电机+2个筒灯

**注：以上建议仅为最简单的设备组合，以满足云云对接最简单诉求，实际以项目需求为准。**
> 注意
>
> 不是所有的设备都能支持云云对接，建议在采购设备前找华为销售进行确认，确认好相关设备以及对应的型号，避免购买错误影响项目。
