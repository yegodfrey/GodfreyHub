# 安装插件

1. 插件包push到LCD面板特定位置

面板连接PC机成功后， 将编译签名好的插件包修改名称Smarthome-plugin.apk替换， 双击执行pushPlugin.cmd脚本。

[pushLocalPluginTool.zip](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091407.56665582933779746579296875320088:50001231000000:2800:47B1EBA70FE2D2A893101B811A09F86D6D40092EB095624F52853F6E8A26AD26.zip?needInitFileName=true)

2. 进入插件配置调测界面

面板连接PC机成功后， 将编译签名好的插件包修改名称Smarthome-plugin.apk替换， 双击执行pushPlugin.cmd脚本。

点击智慧生活全屋版图标，进入界面后，点击"启动插件配置页"；

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091407.30564870923836528080877712126072:50001231000000:2800:040FEE70B5F670B95A3877943FAF2DC964A4808E8C3EDF1BA4427DE4A94CCAE8.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 点击安装插件按钮，会提示插件安装成功， 重启面板。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091407.86488731746765984077582993613482:50001231000000:2800:039DFB640142723F7E6EC9E30AD19AF2498F6A5BE989981A95789C8F1A3A8FFC.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 再次进入调试界面，手动输入插件包名、插件绑定的服务名称全路径。输入完成后，点击绑定服务按钮可触发宿主绑定插件服务。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091407.78445652918693952618984323751908:50001231000000:2800:D199839BE155044B0D6A27082FA3223E194F68BFB523E04012F3393B13B22034.png?needInitFileName=true?needInitFileName=true "点击放大")

5、点击"绑定服务"若显示bind success return代表宿主跟插件绑定正常；

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091407.88946111866346386242381307969695:50001231000000:2800:540B59B81391527CE9E4EE9FB99683173F0E7082684C8F8B9CA9B680FCE938F4.png?needInitFileName=true?needInitFileName=true "点击放大")

6、同时可以通过"检查插件状态"按钮检测插件是否安装成功

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091407.34364633624953638691488080056232:50001231000000:2800:5786354A93FF657863E2309DE2AB23506422C8D2413FBCF91B8442CDB80A04E7.png?needInitFileName=true?needInitFileName=true "点击放大")
> 说明
>
> pluginName：插件的包名
>
> isbind：表示当前插件是否绑定成功
>
> isInstall：表示当前插件是否安装成功
