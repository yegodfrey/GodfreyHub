# 业务简介

HUAWEI空间智能是华为面向2B行业进行智慧化升级，如酒店、地产、办公、教育和医疗等，全面开放全屋智能系统的端云相关能力，联合行业伙伴构建创新化解决方案，满足行业客户需求。华为提供端到端的解决方案，从设备、云服务到交互界面，并通过多种开放方式，以被集成者角色向各行业解决方案提供接口调用能力，赋予其调用华为全屋智能原子能力的接口，包含设备管理、场景管理和控制类原子能力。

* 南向生态设备端，延用鸿蒙智联、华为智选生态，根据全屋智能场景需要，从生态设备中筛选合适设备，进入华为全屋设备清单列表，持续丰富华为全屋智能原子能力。


* 北向应用集成端，智慧生活云开放Rest接口，以被集成者身份灵活应对行业各种集成诉求。
