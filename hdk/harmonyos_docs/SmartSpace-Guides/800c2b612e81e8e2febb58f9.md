# 设备组网

以上述提供的设备套餐（1台华为智能主机SE +1个智能开关(3键开关)+1个窗帘电机+2个筒灯）为例，由于三个子设备都是PLC协议，故只需要将华为智能主机SE的家庭网口插上能够访问外网的路由器，同时设备上电即可，华为智能主机SE会自动识别下挂的子设备（该自动识别只适用于PLC子设备，若购买的子设备中，有wifi设备下个章节会介绍如何添加wifi子设备）。
