# 上传插件

1. 将本地调试好的插件发给华为负责人； 说明
   >
   > 1、若涉及图片等静态资源，由于图片的地址需要固定写在插件中，建议该图片地址放在一个外网插件可以访问的地址即可。
   >
   > 2、该处上传插件的地址为华为调试地址，仅用作调试使用；待完全验证完毕后，需要将插件上架到应用市场，请参考[上架应用市场](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/upload-to-app-market-0000001503473049)
2. **可选：** 编写配置文件：具体请参考以下示例，编写完成后命名为**pluginInfoV2.json** ，然后发给华为接口人

   示例如下：

   ```codeblock
   [
   	{
   		"accessMethods": [
   			"setUicontent",
   			"getBuildNetInfo",
   			"setBuildPort",
   			"wakeLockScreen",
   			"subscribeSecurityEvent",
   			"unsubscribeSecurityEvent",
   			"getHomeInfo"
   		],
   		"proId": "包名",
   		"allowDaemon": 1,
   		"binderAction": "service的完整路径",
   		"fileName": "包名.apk",
   		"packageName": "包名",
   		"pluginName": "包名",
   		"pluginPath": "华为提供",
   		"launcherClassName": "launcherActivity的完整路径",
   		"pluginData": [
   			{
   				"appExVersionMatch": "123-",
   				"versionCode": 版本号，建议为整型例如1000,
   				"pluginStatus": 0,
   				"signDigest": "SHA256签名"
   			}
   		]
   	}
   ]
   ```

   > 注意
   >
   > **pluginInfoV2.json**文件格式为json格式，且文本内容最外层有数组的中括号
