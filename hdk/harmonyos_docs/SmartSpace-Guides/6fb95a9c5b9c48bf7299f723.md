# 编写脚本

完成上述所有步骤后，即所有云端的准备工作已完成，该步骤将实现在中控屏上分配坑位并显示首页卡片UX；

伙伴将自行编写step1、step2和step3脚本：

1. 编写step1.cmd（直接将内容复制即可）

```codeblock
adb shell settings put secure launcher_custom_layout ''
adb shell settings put secure pluginCardConfig  ''
 
adb shell pm clear com.huawei.android.launcher
adb shell pm clear com.huawei.smarthome.extend
```

b) 运行step2.cmd

```codeblock
adb shell settings put secure launcher_custom_layout '[{\"layout\":[{\"x\":\"0\",\"y\":\"0\",\"spanX\":\"1\",\"spanY\":\"2\",\"pageIndex\":1,\"tag\":\"XXXXXXX\"}],\"priority\":1,\"condition\":\"none\",\"screensize\":\"10\",\"loginStatus\":\"logout\"}]'
```

> 注意
>
> 1. screensize字段，若使用的是10寸屏，则为10，若为6寸屏则需要改成6
> 2. tag建议采用驼峰格式，并与step3中的featureName保持一致。
> 3. 由于上述仅展示了一张卡片，若需要展示多张卡片，可联系华为负责人指导脚本的编写；

c) 运行step3.cmd

```codeblock
adb shell settings put secure pluginCardConfig  '[{\"buildPort\":0,\"featureName\":\"XXXXXX\",\"panelSize\":\"10\",\"pluginName\":\"com.xxx.xxx\",\"uiTemplateType\":\"TEMPLATE_TYPE_4\"}]'
pause
```

> 注意
>
> 1. panelSize字段，若使用的是10寸屏，则为10，若为6寸屏则需要改成6;两个都有填10|6
> 2. buildPort字段，若需要配套轻主机验证UX使用，则需要配置为1，若仅是在背夹上无轻主机验证UX，则需配置0；
> 3. featureName字段，需要跟step2的tag保持一致；
> 4. uiTemplateType字段，按照UX要求填写对应的字段即可，例如TEMPLATE_TYPE_4；
> 5. 由于上述仅展示了一张卡片，若需要展示多张卡片，可联系华为负责人指导脚本的编写；

最终将完成step1.cmd，step2.cmd, step3.cmd这三个脚本；
