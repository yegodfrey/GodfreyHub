# 提供相关的信息

华为云云对接是使用标准的RestFul接口，故需要申请AccessKey和Secret。申请方法如下：

1. ISV自行生成一套公钥私钥（建议使用openssl），加密长度为2048 ；生成后，需要将**公钥**提供给华为。
2. 提供项目相关信息，包含：**ISV名称、项目名称、项目地址信息**
3. 提供其他相关信息：**智慧生活账号、接受上报数据的URL，跟华为全屋家居云所对接的服务器的IP集合**
4. 将前三步的相关数据发送给华为全屋技术接口人，正常申请时间为**5** 个工作日；申请成功后，华为全屋技术接口人会以邮件的方式将：**使用公钥加密的AK/SK** ，**项目ID** 以及**请求的域名**返回给ISV
5. ISV收到后用私钥进行解密AK/SK

> 说明
>
> 按照指引，最终ISV需要提供给华为的信息如下：
>
> * 公钥信息
> * ISV名称
> * 智慧生活账号：建议使用项目真正的账号,可以为多个，避免后续变更
> * 接受设备数据的对端url：例如：[https://XXXXXX:123/data/../../](https://xxxxxx:123/)
> * 项目名称：xxxxxx项目
> * 项目具体地址：xx省xx市xx区xx号
> * 跟华为全屋家居云对接的服务器的IP集合：填写与华为全屋家居云通信的三方服务器的出口IP，可以为多个IP

提供完成后，华为会生成相关的信息返回给开发者；
> 注意
>
> * 使用公钥加密的AK/SK信息
> * 项目ID(project_id)
> * 对应的域名
