# 智慧生活交房

> 说明
>
> 该步骤需要使用到智慧生活App，如右图所示：![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.98909131909257286651678695448545:50001231000000:2800:2A1A402A243A9A337088CAA3F1F143F388DCAFE3146EC23D9476ACDFC541B42C.png?needInitFileName=true?needInitFileName=true "点击放大") 。该App可以在华为应用市场进行下载。

1. 手机安装智慧生活App，进入智慧生活App后，点击右上角 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.77512251640572192322896044856625:50001231000000:2800:4F5AD7BAF5B9E43E924FBEA0E0E58F72AB9797CE45566B15B1100F63C71B513A.png?needInitFileName=true?needInitFileName=true "点击放大") ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091405.54983797389414165157229092740670:50001231000000:2800:891624921EF3DA8B4F25AB61A4FF49A3087D106F1F5E3BFC408E015E1DD0C3AD.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 进入扫描页后，会出现如下界面，点击连接。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091405.60349012080985663375523611126212:50001231000000:2800:E906C6915BD3D206114C674F8B08AEC624A93C11DF2113276C62CB371559B24D.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 选择所属房间（说明：在[设备组网](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/network-topology-0000001499152225)已经完成房间创建，则能够在当前弹框中选择房间）：

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091405.28108203714858513971422532731186:50001231000000:2800:AB29D1DFA6B015E4A0E033E07FB438B8F14FBD43BCEA314A09E02011A96DFB9A.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 选择完房间后，将播放一段收房动画，当手机显示如下界面，则代表收房完成，点击立即体验，即完成交房操作 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091405.91395992510215010151618707483241:50001231000000:2800:470088EE293C8EFAFFBD0449A97CA37B125B65971693811F67DDAAC4A7020A30.png?needInitFileName=true?needInitFileName=true "点击放大")

   > 说明
   >
   > **若已经完成智慧生活交房操作，后续又新增了其他子设备或者新增场景，如何操作？**
   >
   > 需要先使用华为全屋易维App登陆华为智能主机SE，登陆后进行"恢复交房"操作，具体操作如下：
   > 1. 成功登陆华为全屋易维App，具体登陆方法请参考[提供相关的信息](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/relevant-reference-0000001449432488)的第三步
   > 2. 进入"我的"，点击"交房配置"；
   > 3. 先点击"保存当前配置"，再点击"恢复交房配置"，如下图所示：
   > 4. ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091405.95936642569119456375210822510441:50001231000000:2800:AEA38AB626A99246FEDDA2D727BD8418260508E7D0623AFCC318AF9E32940DD0.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 5. 【新增设备】完成操作后，即可把想要新买的设备上电，待轻主机下显示在线即完成配置（若为Wi-Fi子设备，则需要单独扫描添加，请参考[提供相关的信息](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/relevant-reference-0000001449432488)第5步）
   > 6. 【新增场景】进入规则界面，新增想要的场景即可
   > 7. 完成操作后，再直接参考[易维App配置](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/maintenance-app-0000001449752332)------智慧生活交房即可。
   >
   > 说明：每次新增设备或者场景都需重复上述操作
