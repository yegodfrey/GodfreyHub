# 场景介绍

目前可基于华为全屋智能系统的开放能力，结合行业业务，可创新出更多的智慧新场景，能够给企业方带来高收益，给用户带来高体验的价值。如：

* 地产行业场景应用示例

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091403.53634748127054242939866271551673:50001231000000:2800:3E44C6D38F319EEF10A5DED765385886FC5B441DCBDC6CFF0BF832FA3C97DD93.png?needInitFileName=true?needInitFileName=true "点击放大")

在地产行业普遍存在园区设备与用户家里互通的需求，利用华为中控屏开放的插件技术能力和接口，可在中控屏上集成园区可视对讲、智能梯控、社区监控、物业通知、维护维修、客服中心、邻里互助、活动通知、信息公示等社区服务应用插件。实现园区相关系统与全屋系统互通，给用户提供一屏统一呈现、集中操控的便捷体验，以及给地产建设项目减少部署可视对讲室内屏，降低建设成本，并提供了地产物业触达用户的通道，提升物业服务价值。

* 酒店行业场景应用示例

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091403.06535331928673922892570984311453:50001231000000:2800:572D4D04D88EA6BACE9C09391888B2FEB520FA1B1889B6E14C88D7F4D9D851C8.png?needInitFileName=true?needInitFileName=true "点击放大")

在酒店行业可利用全屋智能云的开放能力，通过云云对接RESTful API接口，实现酒店PMS管理系统与客控智能系统对接，可实现当前台办理入住时，远程开启空调，并按设定温度运行，使房间迅速升温或降温，保障用户进入房间后有一个舒适的入住体验。同时也可以利用华为中控屏开放的插件技术能力和接口，实现将呼叫前台、客房服务等客需相关功能一屏集成，给用户提供高交互体验的场景方案。

基于华为全屋智能系统开放能力，也可以应用于办公、教育、医疗等行业，给会议室、教室、病房等空间带来全新的智能化体验，在会议场景，利用全屋智能系统云开放能力，会议管理系统通过RESTful API控制会议室环境智能设备，如会前根据会议议程提前5分钟开启会议室相关设备和环境设备，提高会前准备效率，同时提前将空调温度调整到指定温度，给用户带来舒适体验。期待合作伙伴一起解锁更多行业智慧场景。
