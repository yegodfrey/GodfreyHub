# 易维App配置

> 说明
>
> 该步骤需要使用到华为全屋易维App，如右图所示： ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091403.16266254650645855132390685805394:50001231000000:2800:15C4F1E69E12948E0F6B44626705FC962586418F2939BF9DCD58DE2F237007FF.png?needInitFileName=true?needInitFileName=true "点击放大")，由于该App暂未对外，故优先找华为全屋技术服务的同事获取。若未能华为全屋技术服务同事，请联系华为全屋技术开放接口人。

整个全屋环境的大致组网图如下所示：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091403.86650523567041963413017758461005:50001231000000:2800:34C4B38B2520003A9D0386BC30A3A3ADE51F88D1EDFFA356E05BD13DFC6FE439.png?needInitFileName=true?needInitFileName=true)

1. 手机安装华为全屋易维App，并连接轻主机家庭网口的路由器WIFI
2. 先登录装维App（账号请单独和华为全屋技术开放接口人沟通申请）
3. 登录华为全屋易维App成功后，再登录轻主机，登录轻主机的方法：点击首页"登录"（如图一），进入自动"扫描登录设备"界面（如图二），App会自动扫描当前网络下的轻主机（查询成功，会自动填充主机IP（如图三），若查询失败，建议优先排查当前手机连接的wifi是否跟轻主机为同一个，若排查无问题，则可以手动添加登录设备，查询轻主机的IP，在装维App界面选择登录主机SE，并输入IP）然后按照手机指引，登录即可。若手机进入设备界面，如下界面（如图四）：则代表登录成功； ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.74091491832818179719933830402082:50001231000000:2800:89FE83FF5DD82DA9764FA71D447FF6989E4C1763F833BB7B3A7950B8D9E9B97A.png?needInitFileName=true?needInitFileName=true "点击放大") ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.34035197435360986909954469264467:50001231000000:2800:D09656F96D4814FDA90D649C453468E5D0CBEEA76CC69F712857EC4DE7F9158C.png?needInitFileName=true?needInitFileName=true "点击放大") ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.22176943702250632583137349281251:50001231000000:2800:18FB9792BFF8DCB56AA113D83FB66F19F8F6A72AC72E601D52342B37E973F748.jpg?needInitFileName=true?needInitFileName=true "点击放大") ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.52200155719168847239444960294170:50001231000000:2800:D941E18C702189A295FDE8311216AE1A495AC38D6BCACC77BFAAEA268530E9F0.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 登陆成功，点击华为全屋智能主机的卡片，查看子设备的卡片是否出现并显示**在线** 状态，如下图所示：

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.58777251409088181056908464860663:50001231000000:2800:F0E65DC400F28D825D092B28A3AA985D0B3BE069A7B16722A8C32AAA3748F1D3.png?needInitFileName=true?needInitFileName=true "点击放大")
5. 【若子设备没有WiFi设备可跳过该步骤】进入装维首页，WiFi设备上电，然后点击右上角的"+"进行设备扫描，如下图所示：按照指引进行添加即可 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.98641239560416688989106169156526:50001231000000:2800:29DCC5FAB3F3BFE263E814D764EB66F5800276EE511A683E1FFF59E3D55A1B85.png?needInitFileName=true?needInitFileName=true)

6. 创建相关场景，按需自行创建，如下图示例所示： ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091404.55495717894276044638755507293777:50001231000000:2800:2DBE3C4EBFE60EF7CDA9CEA9235D2DB4A450A883DC4DD8DCF7BEB61CE22E8081.png?needInitFileName=true?needInitFileName=true "点击放大")
