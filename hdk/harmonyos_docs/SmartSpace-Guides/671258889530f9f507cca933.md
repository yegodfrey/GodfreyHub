# 业务优势

支持多种开放方式，面向不同行业灵活定制竞争力特性，提供强大的支撑资源，实现合作共赢。

* **多种开放方式**：提供云侧开放、中控屏开放、BLE Mesh协议、干接点接入方式四类开放方式，提供更优的业务对接体验。


* **支持灵活定制**：根据不同行业支持相关定制，如地产行业可视对讲、物业通知等。


* **OpenLab专业实验室**：6个专业实验室+1个创新实验室+10个认证实验室，用于和合作伙伴联合孵化创新解决方案。


* **丰富的生态品类** ：HarmonyOS与2200家合作伙伴构建领先的全场景智能硬件生态。
