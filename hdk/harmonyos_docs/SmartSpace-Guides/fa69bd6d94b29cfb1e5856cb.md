# 可视对讲功能验证

若涉及可视对讲功能，可以参考此章节进行验证，若不涉及可以略过

* 【检查版本】
  1. 查看轻主机版本号
     * 查看方式：点击"华为全屋智能轻主机"的卡片，进入后，点击右上角的四个点，查看版本是否**大于等于** **2.1.41.305(H110SP1C00)** **，** 如下界面：

       ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091408.48556326244688876068538642660385:50001231000000:2800:7D3D28216832D33EBBEF98F5B1B9D75A8C8E1CB1A361A2DE43065E588D1FBDAC.png?needInitFileName=true?needInitFileName=true "点击放大")
  2. **（版本号正确可跳过此步骤）**若版本号不对，可以进行OTA升级，升级方式：在装维App---我的---固件升级---OTA升级---检查更新
  3. **（若没有进行** **主机升级动作，可跳过此步骤）** 升级成功后，**对轻主机进行一次恢复出厂设置** ；操作方式：点击轻主机的卡片---点击右上角4个点------恢复出厂设置

  4. **（若没有进行主机** **升级动作，可跳过此步骤）**当轻主机亮白灯后，重新登录轻主机，再次确认版本号是否正确，升级是否成功；若不成功返回第5步重新操作；
  5. **查看中控屏版本**
     * 点击中控屏---设置---关于设备---HarmonyOS 版本，然后点击HarmonyOS版本，会切换成，软件版本，查看软件版本是否**大于等于** **2.1.0.149** **，** 如下图所示：

  6. 版本确认无误进行中控屏跟轻主机的绑定，请按照[中控屏和轻主机绑定流程](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/install-screen-0000001504516317#ZH-CN_TOPIC_0000001504516317__li1083931412417)，进行绑定操作。
* 【可视对讲功能验证】
  1. 轻主机的楼宇网口和物业门口机均连到接社区交换机；保证家庭网口和楼宇网口的处于不同网段，用于模拟物业局域网和家庭网络，组网架构大致如下： ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230525091408.89139865293939646546439144234079:50001231000000:2800:180818A2EA220286A08F0863D78D687C14966BDDC485AC24A1C2393D2CA5C623.png?needInitFileName=true?needInitFileName=true "点击放大")

  2. 在中控屏上设置轻主机的IP，操作方式：中控屏的设置---关于设备------主机信息------获取楼宇网络信息；提示下发成功后，退出再进一次界面观察数据是否能够正确回读；
  3. 可视对讲的端口设置**（若业务不涉及端口可跳过）**

     当前轻主机有个限制，每个服务仅支持4个端口；如果有需要超过4个端口，可以用新的服务，进行设置端口；例如服务为5555，端口为123,456,789,100; 服务为6666，端口为321,654,987
  4. 门口机或中控屏发起呼叫即可；
