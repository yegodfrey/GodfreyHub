# 端到端验证

1. **首次呈现插件卡片**

   要能出现卡片，则保证有上行网络，若使用轻主机，则轻主机的家庭网口得接入路由器。

   将PC和中控屏连成功连接，运行脚本
   * 运行step1.cmd
   * 清理智慧生活数据并切换智慧生活的**家居云环境为沙箱认证云**；
   * 运行step2.cmd
   * 运行step3.cmd

2. **更新插件**
   1. **本地更新插件（推荐此方法）**

      将需要更新的插件使用[安装插件](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/install-plug-in-0000001503313373)的方式，将插件推送到中控屏中，并进入配置界面，点击**"更新插件"**
      > 注意
      >
      > 1、该更新方式仅适用于插件包名没有变化，跟云端包名一致；若更新后的插件包名发生变化，请使用云端更新插件的方式
      >
      > 2、使用的[安装中控屏](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/install-screen-0000001504516317)章节里面的脚本自行修改，将脚本中的Smarthome-plugin.apk修改成对应包名即可

      本地验证无问题后，再联系华为接口人部署到云端，按照"云端更新插件"的方式进行测试即可
   2. **云端更新插件**

   当需要云端更新插件，先找华为接口人部署插件，部署成功后，只需要在中控屏上做如下操作

   a) 清除智慧生活全屋版的数据：

   i. 设置---应用---应用管理---滑到最底下，找到智慧生活全屋版---存储------删除数据------确定。
