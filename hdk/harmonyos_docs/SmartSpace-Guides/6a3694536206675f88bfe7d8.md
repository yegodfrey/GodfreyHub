# 加入FAQ

* **中控屏扣在轻主机上，中控屏主机信息页显示设备状态异常，点击扫码登录提示数据获取失败**

  出现此现象是由于中控屏和轻主机未绑定，需通过装维扫描添加中控屏，请参见[中控屏和轻主机绑定流程](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-Guides/install-screen-0000001504516317#ZH-CN_TOPIC_0000001504516317__li1083931412417)
