# SDK下载

## 系统预置振动类型

针对Android Studio开发环境，华为提供了maven仓集成和本地集成HMS Core SDK包的两种方式。

(1) 针对本地集成方式，下载后请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/integrated_hms_core_sdk-0000001076772888)。

|SDK包|SDK工程名|提供的能力|需求场景|SHA256校验码|
|:-------------------------|:---------|:--------------|:------------|:---------------------------------------------------------------|
|hapticskit-maven-1.0.1.300|Hapticskit|提供Haptics SDK能力|使用Haptics SDK|84e52d65ab5a7a8dbcd06262f2a196750488b8c58f1e8dd67d52f727e8c085b8|

(2) 针对华为提供的Maven仓集成方式，请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/system-Guides/integrated_hms_core_sdk-0000001076772888)。
