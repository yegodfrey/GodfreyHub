# HwScrollbarHelper  
  
Class Info  
---  
public class HwScrollbarHelper HwScrollbarHelper是一个工具类，实现了HwScrollbarView和可滚动控件ListView、ScrollView、RecyclerView绑定，同步两者间的滚动交互。
