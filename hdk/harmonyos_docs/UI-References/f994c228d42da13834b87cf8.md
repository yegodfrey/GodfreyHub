# HwSubTabFragmentPagerAdapter  
  
Class Info  
---  
public class HwSubTabFragmentPagerAdapter 处理ViewPager和[HwSubTabWidget](https://developer.huawei.com/consumer/cn/doc/development/UI-References/hwsubtab-interface-hwsubtabwidget-0000001052543585)的辅助类，继承FragmentPagerAdapter，实现了[HwSubTabListener](https://developer.huawei.com/consumer/cn/doc/development/UI-References/hwsubtab-interface-hwsubtablistener-0000001052662305)以及ViewPager.OnPageChangeListener方法，如果用到ViewPager，Item的创建可以直接使用这个辅助类创建，帮助用户快捷方便使用。
