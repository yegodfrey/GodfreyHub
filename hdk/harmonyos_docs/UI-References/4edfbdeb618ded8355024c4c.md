# HwTextView  
  
Class Info  
---  
public class HwTextView extends TextView 该类是华为新型文字控件，继承了TextView，可以处理长字符串。  
  
#### XML Attributes

Qualifier and Type | Attributes Name and Description  
---|---  
dimension | hwAutoSizeMinTextSize 定义文字自动调整大小时的最小尺寸。  
dimension | hwAutoSizeStepGranularity 定义文字自动调整大小时的步长（间隔尺寸）。
