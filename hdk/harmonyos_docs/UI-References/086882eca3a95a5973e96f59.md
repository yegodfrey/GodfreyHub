# HwRecyclerView  
  
Class Info  
---  
public class HwRecyclerView extends RecyclerView implements ScrollCallback 该类在继承原生RecyclerView基础特性上，增加点击状态栏回滚到列表顶端、挖孔屏手机边距自动适配、自动滚动、OverScroll物理回弹效果、列表删除动效。
