# Overview  
  
包含华为悬浮按钮的功能类以及不同风格的资源。

#### Class Summary

Class | Description  
---|---  
[HwFloatingActionButton](https://developer.huawei.com/consumer/cn/doc/development/UI-References/hwfab-class-0000001052582250) | 华为[HwFloatingActionButton](https://developer.huawei.com/consumer/cn/doc/development/UI-References/hwfab-class-0000001052582250)控件（悬浮按钮）分为渐变彩色阴影和灰色阴影两种类型。 在API 24以下使用本控件，按钮图标将不支持渐变色。
