# DevEco Studio设置新建ets文件时自动添加头部注释和版权声明的方法

自动添加头部注释方法：

1.File \> Settings \> Editor \> File and Code Templates。

2.右侧选Files \> ArkTS File。

3.添加头部注释和版权声明。
