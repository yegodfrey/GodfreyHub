# PC系统是否支持USB外接无线网卡

## 问题现象

HarmonyOS PC系统是否支持USB外接无线网卡？如果有可用的USB无线网卡，如何判定连接Wi-Fi热点使用的是该网卡？

## 解决方案

HarmonyOS PC设备自带Wi-Fi功能，目前不支持外接USB无线网卡。因此无需针对USB外接无线网卡进行额外的禁用管控。
