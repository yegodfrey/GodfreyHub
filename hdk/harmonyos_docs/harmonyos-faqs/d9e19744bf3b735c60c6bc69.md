# Huks生成2048位RSA密钥，加密数据，报错401错误

生成RSA密钥长度与生成密钥时传入参数有关，例如生成2048位RSA密钥参数可以传'RSA2048\|PRIMES_2'或者'RSA2048\|PRIMES_3'。
