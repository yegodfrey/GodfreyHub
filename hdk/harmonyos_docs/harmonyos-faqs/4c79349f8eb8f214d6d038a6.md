# 如何通过hdc命令关闭整个应用

可以通过以下命令结束应用：

```
hdc shell aa force-stop <bundleName>
```

返回"force stop process successfully"，表示应用已成功结束。

示例如下：

```
hdc shell aa force-stop com.example.myapplication
```
