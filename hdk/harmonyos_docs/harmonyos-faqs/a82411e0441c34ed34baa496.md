# 如何对指定的页面进行压测

## 问题现象

如果希望对指定的页面进行稳定性测试或者压力测试，那么具体该如何操作呢？

## 背景知识

[DevEco Testing](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/deveco-testing)是一款专项集成测试工具，提供了多项测试能力，支持一键执行测试任务，同时提供了测试报告和分析，辅助开发者发现应用和产品问题，提升应用质量。

## 解决方案

1. 已完成[DevEco Testing的下载和安装](https://developer.huawei.com/consumer/cn/download/deveco-testing)。
2. 打开DevEco Testing工具，点击实用工具->应用图谱管理工具->创建图谱->空白图谱，填写图谱名、选择设备和应用包名，点击创建图谱。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/jb3-rk-hSO-Gt4qmo_Az-A/zh-cn_image_0000002628563138.png?HW-CC-KV=V1&HW-CC-Date=20260909T181827Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E0E9DA4CCD684A5FE3002B4289FF26D58CAF4D439BDE3ACFB6063C201FE380B "点击放大")

3. 点击新增特性按钮，输入特性名称和特性描述（非必填），点击提交按钮；选择已有特性，点击新建场景路径按钮，设置场景名称，选择投屏设备，点击窗口中的"+"号添加步骤，选择通过屏幕录制添加，通过在左侧投屏设备的区域内，执行点击、滑动或者右键弹窗输入文本动作，添加相应的场景步骤，点击保存按钮完成场景创建。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/5vRk0lCOR5euwxYrMZRxmw/zh-cn_image_0000002658922461.png?HW-CC-KV=V1&HW-CC-Date=20260909T181827Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E74500C025D583E502592C371ABFDA91060E43FAC6C191847447E553B6550B8 "点击放大")

4. 点击调试，查看实际执行页面与图谱指定路径是否一致。如果不一致，可以进行场景路径编辑。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/NUPHj86GQd2zp65zlvQT7Q/zh-cn_image_0000002628403248.png?HW-CC-KV=V1&HW-CC-Date=20260909T181827Z&HW-CC-Expire=31536000000&HW-CC-Sign=78A703B6D0D1C553AFA9C6083550342C437CF04C5C6EA2AC61D37A1264A639BE "点击放大")

5. 点击DevEco Testing工具的探索测试->应用探索测试->创建任务->选择测试设备、选择应用、定义测试时长->模式类型选择"场景压测"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/O8HjCPjTQNCrYBmI3s1_NQ/zh-cn_image_0000002658802513.png?HW-CC-KV=V1&HW-CC-Date=20260909T181827Z&HW-CC-Expire=31536000000&HW-CC-Sign=66D9D31C4163AF77D51E67BA13A40FFF9B26B076224851C00B6F543D318574BA "点击放大")
