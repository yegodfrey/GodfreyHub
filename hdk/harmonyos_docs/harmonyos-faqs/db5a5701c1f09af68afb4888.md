# 如何解决hdc server和client版本不一致的问题

**问题现象**

hdc.log 中的报错信息为"Daemon Session Handshake failed"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/aPmIJwiiRleVFXjnwXAEQA/zh-cn_image_0000002624476472.png?HW-CC-KV=V1&HW-CC-Date=20261008T191615Z&HW-CC-Expire=31536000000&HW-CC-Sign=641A00EE6485FEDA1F3D81D34C23BC966199B24697D7D7E05B38B547CE1D6AA5 "点击放大")

**解决措施**

1. 通过以下命令检查server和client的版本是否匹配。 hdc checkserver

2. 执行以下命令，终止其他版本的服务器。 hdc kill
