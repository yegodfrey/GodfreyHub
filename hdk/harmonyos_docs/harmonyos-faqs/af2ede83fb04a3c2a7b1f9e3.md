# DevEco Testing支持的设备类型

#### 问题现象

DevEco Testing是否支持HarmonyOS 4.x版本设备、OpenHarmony设备？  

#### 解决方案

DevEco Testing从5.0版本开始不支持除OpenHarmony和HarmonyOS Next外的其他设备，从5.1.5.200版本开始不支持OpenHarmony设备，只支持HarmonyOS Next设备，现在低于5.1.5.200版本打开后会弹框提示升级，否则无法使用。

[DevEco Testing](https://developer.huawei.com/consumer/cn/download/deveco-testing?ha_source=sousuo&ha_sourceId=89000251)下载中心可查看版本号。

![](https://media:101782454468046626 "点击放大")

已安装DevEco Testing，可以在设置-关于查看版本。
