# 已实名认证，登录时还是提示用户需要进行实名认证

**问题现象**

登录授权模拟器时，若提示华为账号需要实名制认证，请在账号中心检查账号状态。若状态显示"已实名"，请核对相关信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/TLjwJEelREm4pKvaoGpITQ/zh-cn_image_0000002624638638.png?HW-CC-KV=V1&HW-CC-Date=20260916T082506Z&HW-CC-Expire=31536000000&HW-CC-Sign=7914B83EA737B9CED1878CCC47BBA2B077AF0F1117AD4B6448DA5B320B49E58F "点击放大")

**解决措施**

华为账号实名分两种，一个是账号实名认证，即上图展示的状态，还有一个是开发者实名认证。这两种实名认证方式是不一样的，模拟器的登录授权是需要开发者实名认证，请根据[实名认证指导](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)进行处理。开发者实名认证后的结果如下图所示。
