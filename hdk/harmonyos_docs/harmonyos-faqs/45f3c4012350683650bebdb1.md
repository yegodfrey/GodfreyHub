# InsightIntent debugging什么时候会被调用

## 问题现象

通过小艺建议拉起应用时，提示"InsightIntent debugging"，这个提示是什么情况下会被调用呢？

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/ilM_lwMgTTKaxMhrgGAbDg/zh-cn_image_0000002628554736.png?HW-CC-KV=V1&HW-CC-Date=20260910T054834Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4A6879589B0DB038D7BF7DE864C090CF69C4EC8CB93567E03DCD7D81DA4374E "点击放大")

## 解决方案

当设备上启用了意图框架调试开关时，通过小艺建议拉起应用会提示"InsightIntent debugging"，该提示是开发测试阶段涉及的，可以在"设置--系统--开发者选项"中找到开关。
