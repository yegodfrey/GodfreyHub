# InsightIntent debugging什么时候会被调用

#### 问题现象

通过小艺建议拉起应用时，提示"InsightIntent debugging"，这个提示是什么情况下会被调用呢？

![](https://media:101782441978389122 "点击放大")  

#### 解决方案

当设备上启用了意图框架调试开关时，通过小艺建议拉起应用会提示"InsightIntent debugging"，该提示是开发测试阶段涉及的，可以在"设置--系统--开发者选项"中找到开关。
