# 如何正确地在CMakeLists.txt文件中配置头文件搜索路径

请按照以下示例进行配置：

**例1** **：**

目录结构：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/4968LehMTmWVFUT7E4Lz4g/zh-cn_image_0000002654835209.png?HW-CC-KV=V1&HW-CC-Date=20261008T191529Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E45B082604DE599505123D6243F377720CE921014302860811304DAB0FF5EF0)

cpp文件中引用头文件:

#include 'test.h'
