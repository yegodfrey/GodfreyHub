# 如何正确地在CMakeLists.txt文件中配置头文件搜索路径

请按照以下示例进行配置：

**例1** **：**

目录结构：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/4968LehMTmWVFUT7E4Lz4g/zh-cn_image_0000002654835209.png?HW-CC-KV=V1&HW-CC-Date=20260920T114737Z&HW-CC-Expire=31536000000&HW-CC-Sign=5EF1A2A1E891CBBD2B7EF7E9381CC39F95424C93B80F217B40B2F1C76B33231F)

include_directories(${NATIVERENDER_ROOT_PATH}/include)

cpp文件中引用头文件:

#include 'test.h'
