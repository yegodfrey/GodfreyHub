# 编译报错"Failed to obtain the module type."

**错误描述**

未找到指定的模块类型。

**可能原因**

在FA模型中，config.json文件中的module/distro/moduleType字段缺失或配置错误。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/xZrWUTH-QzOZCbSmXs_hww/zh-cn_image_0000002654798001.png?HW-CC-KV=V1&HW-CC-Date=20260916T082508Z&HW-CC-Expire=31536000000&HW-CC-Sign=9CADA2886BBF56FE9E90FED386441291BA5743F18671AE4271498D76CE00F7B4)

**解决措施**

确保在FA模型的config.json文件中，module/distro/moduleType字段存在且配置正确。
