# 编译报错"Failed to obtain the module type."

错误描述

未找到指定的模块类型。

可能原因

在FA模型中，config.json文件中的module/distro/moduleType字段缺失或配置错误。

![](https://media:101782454459654110)

解决措施

确保在FA模型的config.json文件中，module/distro/moduleType字段存在且配置正确。
