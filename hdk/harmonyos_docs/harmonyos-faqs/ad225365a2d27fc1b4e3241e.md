# 智能体如何在真机上显示markdown格式文档

#### 问题现象

工作流模式智能体在真机测试时，消息样式不兼容markdown格式文档。  

#### 解决方案

将工作流模式结束节点中的流式输出打开，即可显示markdown格式文档。
