# 关系型数据库文件如何清理

#### 问题现象

使用关系型数据库提供的API删除数据库，并没有完全删除建库时生成的文件夹和文件，如何彻底删除？

调用deleteRdbStore删除后的文件夹结构如下图：

![](https://media:301785308654630063)  

#### 背景知识

* [relationalStore.getRdbStore](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-data-relationalstore-f#relationalstoregetrdbstore)：创建或打开已有的关系型数据库，开发者可以根据自己的需求配置config参数，然后通过RdbStore调用相关接口执行数据操作。使用Promise异步回调。系统会根据配置创建关系型数据库文件目录，如下图：

  ![](https://media:301785308654709064)
* [relationalStore.deleteRdbStore](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-data-relationalstore-f#relationalstoredeleterdbstore10-1)：使用指定的数据库文件配置删除数据库，使用Promise异步回调。
* 关系型数据库目录："/data/app/el2/100/database/(bundleName)/entry/rdb/"，参考：[获取应用文件路径](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-context-stage#获取应用文件路径)。  

#### 解决方案

使用[@ohos.file.fs (文件管理)](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-fs)的功能进行文件夹/文件删除。步骤如下：

1. 使用[fs.listFileSync](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-fs#fileiolistfilesync)获取关系型数据库文件目录(context.databaseDir)下的文件夹/文件。
2. 使用[isDirectory](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-fs#isdirectory)判断获取到的是目录还是文件，使用[fs.rmdirSync](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-fs#fileiormdirsync)删除目录、使用[fs.unlinkSync](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-file-fs#fileiounlinksync)删除文件。
