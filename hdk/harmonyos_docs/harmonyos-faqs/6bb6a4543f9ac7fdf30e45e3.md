# 编译报错"The srcPath is not a relative path：xxx"

**错误描述**

srcPath字段配置值必须为相对路径。

**可能原因**

开发者在hvigorconfig.ts文件中使用includeNode方法时，srcPath必须是相对路径。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/t5bYQn-MTaGs8RZDESYPpA/zh-cn_image_0000002654837933.png?HW-CC-KV=V1&HW-CC-Date=20261008T190210Z&HW-CC-Expire=31536000000&HW-CC-Sign=B62413AE98DF1B1D193AC2FF51882D6EF410186523B7A609D72A1C93128854B1)

**解决措施**

确保项目的hvigorconfig.ts文件中使用includeNode时的传参srcPath为相对路径。
