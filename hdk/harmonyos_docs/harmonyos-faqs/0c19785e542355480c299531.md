# 编译报错"Invalid form name 'xxx'."

**错误描述**

卡片名称无效。

**可能原因**

在insight_intent.json中配置意图框架时，formName必须是form_config.json中已配置的forms之一。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/cGRubeCZToKxnW4XlbuWjA/zh-cn_image_0000002654837943.png?HW-CC-KV=V1&HW-CC-Date=20260916T082508Z&HW-CC-Expire=31536000000&HW-CC-Sign=176ADC8499ECDC033128BFC50B489F89ABD7F7B6D40D3EE35C40C6D80FEBD84B "点击放大")

**解决措施**

修改insight_intent.json中的 form 配置，确保formName已在form_config.json文件的 forms 中配置。
