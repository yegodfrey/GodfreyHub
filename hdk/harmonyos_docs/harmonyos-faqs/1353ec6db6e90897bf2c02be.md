# 编译报错"Duplicate 'Module-Abilities' object names detected."

**错误描述**

Module-Abilities对象名称重复。

**可能原因**

依赖的HAR模块中module.json5的abilities数组中存在重复的ability对象名称。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/KwC4uLCuTPiFZgNkf2C2EQ/zh-cn_image_0000002654837963.png?HW-CC-KV=V1&HW-CC-Date=20261008T161522Z&HW-CC-Expire=31536000000&HW-CC-Sign=6247DE9B6FF6908502B9B655747F22C78A73C050029F2908C730043E408C1B4A)

**解决措施**

检查依赖的HAR模块在module.json5文件中的abilities字段，确保每个ability的name唯一。
