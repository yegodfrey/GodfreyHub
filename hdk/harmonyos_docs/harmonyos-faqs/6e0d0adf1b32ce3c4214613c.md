# ArkTS如何定义callback函数

定义一个callback函数的样例，参考代码如下：

1. 定义回调函数

   <br />

   ```
   // Define 2 parameters on the page, return empty callback function
   myCallback: (a: number,b: string) => void = () => {}
   ```

   <br />

2. 在使用时进行初始化赋值

   <br />

   ```
   aboutToAppear() {
     // Initialization of callback function
     this.myCallback = (a,b) => {
       console.info(`handle myCallback a=${a},b=${b}`)
     }
   }
   ```

   <br />
