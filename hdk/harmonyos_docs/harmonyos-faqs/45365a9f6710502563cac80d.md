# 模拟器在后台放置一段时间后会卡在加载状态，CPU占用率高

**问题描述**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/-FNXf_mVRyakoYMYH6cfKA/zh-cn_image_0000002654798119.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=A89302767821B8ACCC4740C5A2778BB4EABE847F77C4F167E5E052AAFEE2D2D0)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/vBQmbFOwTZatTKmzvjXovw/zh-cn_image_0000002624638666.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=ABD9CCD7CE32E59BFE8C4BCD02C9F4131668F9098BF02655E7C367D602BCFD82)

打开活动检测器，发现模拟器的CPU占用率为80%。

**解决措施**

1.打开模拟器设备管理页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/5gmvG1NrTfaWbo3xvQB44Q/zh-cn_image_0000002654838069.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=E557032B124AD3FEA6C3351D3F273053D657E1EC2E8754268964E251321DEF8D)

2.选择"新建模拟器"弹窗。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0d/v3/19YR_tGsT9yPYMJt8fwdQg/zh-cn_image_0000002624478756.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=B1CB439E52BE50BAD6295B11B4C48C7CBA07B130134936A67CCB61601C11878D)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/O1Bvc7sMSeeTN2HxqNzo7w/zh-cn_image_0000002654798121.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=0F80FA9613520EEC6916A1FD50EBAE73FA5651D6F47D5116A99193C976004AD6)

3.复制路径并用文件夹打开system-image\HarmonyOS-NEXT-DB1\phone_x86。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d/v3/aAV4-5LbTWeClSf_TENGKQ/zh-cn_image_0000002624638668.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=7DF42847CADF945C6CA9A90D8F6512804CC1EB17D6EBF32FCFE187EBA8FDF336)

4.打开features.ini文件，将bootanimation.feature.key的值改为true，保存后重启模拟器。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/2jjNuPbPTN2eVX5UzimkKQ/zh-cn_image_0000002654838073.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE960D70A031F90A6A9A0878B6A2156C1A4BFE7BF90E7D21808842CA47980D7C)
