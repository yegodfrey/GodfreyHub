# 预览功能使用过程中，可能无法使用帮助菜单压缩日志按钮收集日志

**问题现象**

当同时预览多个工程时，点击帮助菜单中的"压缩日志"按钮，可能会因日志文件被占用而无法压缩。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/wrGRSkCiQ06ZQW5Hglgdtg/zh-cn_image_0000002654837765.png?HW-CC-KV=V1&HW-CC-Date=20260916T082506Z&HW-CC-Expire=31536000000&HW-CC-Sign=C00B511C423124EBF9F6D374B79655E91675551D1BD6FD6BA502CB933B25085F)

此时右下角会出现压缩失败的提示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/eGLz1aEJRNmwLDSutG3AAg/zh-cn_image_0000002624478454.png?HW-CC-KV=V1&HW-CC-Date=20260916T082506Z&HW-CC-Expire=31536000000&HW-CC-Sign=3317E3AB95781F285E7D5ABA86FB4BB29B94DC728BC95F5319ADE035B4A40D3A)

**解决措施**

请关闭预览过的工程，或者重启DevEco Studio后不要打开预览器，即可再次压缩收集日志。
