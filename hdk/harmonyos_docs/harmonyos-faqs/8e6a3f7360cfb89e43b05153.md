# 运行UITest用例，运行超时屏幕黑屏后报错

**问题现象**

运行UITest用例时，如果屏幕黑屏并超时，将报错提示"Tests failed"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/qpWO612lSMSPKe9L1XBVQw/zh-cn_image_0000002654838141.png?HW-CC-KV=V1&HW-CC-Date=20260916T082506Z&HW-CC-Expire=31536000000&HW-CC-Sign=28DE22768321862C96C778A8FB2FBB6356BE64029A88B53720C3E2B73C960002)

**解决措施**

运行UITest用例时，需确保设备屏幕常亮。屏幕常亮时，用例能够成功运行。
