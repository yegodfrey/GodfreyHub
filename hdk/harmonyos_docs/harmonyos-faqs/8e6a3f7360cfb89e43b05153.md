# 运行UITest用例，运行超时屏幕黑屏后报错

**问题现象**

运行UITest用例时，如果屏幕黑屏并超时，将报错提示"Tests failed"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/qpWO612lSMSPKe9L1XBVQw/zh-cn_image_0000002654838141.png?HW-CC-KV=V1&HW-CC-Date=20261008T163228Z&HW-CC-Expire=31536000000&HW-CC-Sign=E32E5CCB20EEBF954BBA7AF2C8C8A09A613978DC3A2155BC0284C647B50F4261)

**解决措施**

运行UITest用例时，需确保设备屏幕常亮。屏幕常亮时，用例能够成功运行。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/Oj7p-cNRR7GSpTgIg7kKFg/zh-cn_image_0000002624478822.png?HW-CC-KV=V1&HW-CC-Date=20261008T163228Z&HW-CC-Expire=31536000000&HW-CC-Sign=18238D095DAE74A6876D4D8A2F6E4C28DE12A9091050E89D76E8267BCF65E81C)
