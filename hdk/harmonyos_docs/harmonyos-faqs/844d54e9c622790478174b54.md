# 升级react-native-openharmony编译出错

**问题现象**

升级react-native-openharmony编译出错，类似如下报错：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/JuvodfiVTDOUtDbO5laJWw/zh-cn_image_0000002624638608.png?HW-CC-KV=V1&HW-CC-Date=20261008T174106Z&HW-CC-Expire=31536000000&HW-CC-Sign=61BBAD272BC2EEE67D6C5C029D620E344B649994FB3CE128712527EEFE2BC4CB)

**问题原因**

旧版本的react-native-openharmony缓存还在,导致某些链接找不到。

**解决措施**

删除要编译的模块根目录下的.cxx和build目录,然后重新触发编译。
