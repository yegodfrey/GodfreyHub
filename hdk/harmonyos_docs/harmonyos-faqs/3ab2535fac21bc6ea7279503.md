# 用户如何退出AppGallery邀请测试

## 问题现象

用户参与了某应用的邀请测试，系统会自动将用户账号加入到测试用户群组。后续应用有新的邀请测试版本时会给用户发测试通知。如果用户不希望参与该应用的邀请测试，应该如何退出呢？

## 解决方案

可通过以下方式取消邀请测试的推送通知：

1. 用户主动退出：点击邀请测试链接，进入应用详情页，或通过"应用市场-我的-应用尝鲜"路径访问应用测试详情页。在应用测试详情页中，找到关于-测试通知，点击"停止接收"即可退出该应用的测试群组，后续将不再收到测试推送，如下： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/ZwcSfznCRC6nEj-hnAjFXw/zh-cn_image_0000002658793917.png?HW-CC-KV=V1&HW-CC-Date=20261008T173827Z&HW-CC-Expire=31536000000&HW-CC-Sign=A98A413BE3DC07077D5A4FB09C3839B245B27F7ED4CD8EB068D8EFCC5C3E6614 "点击放大")

2. 联系开发者删除：直接联系该应用开发者，登录AGC，在测试用户群组中删除用户的测试账号，如下： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/xG_veIWgStq4k34bymPGTw/zh-cn_image_0000002628394648.png?HW-CC-KV=V1&HW-CC-Date=20261008T173827Z&HW-CC-Expire=31536000000&HW-CC-Sign=A4577036F3880F673A7687EA14B9CFA1938D2D9DE3936F23FBD77129F99A34D3 "点击放大")
