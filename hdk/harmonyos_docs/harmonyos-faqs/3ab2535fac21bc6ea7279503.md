# 用户如何退出AppGallery邀请测试

## 问题现象

用户参与了某应用的邀请测试，系统会自动将用户账号加入到测试用户群组。后续应用有新的邀请测试版本时会给用户发测试通知。如果用户不希望参与该应用的邀请测试，应该如何退出呢？

## 解决方案

可通过以下方式取消邀请测试的推送通知：

1. 用户主动退出：点击邀请测试链接，进入应用详情页，或通过"应用市场-我的-应用尝鲜"路径访问应用测试详情页。在应用测试详情页中，找到关于-测试通知，点击"停止接收"即可退出该应用的测试群组，后续将不再收到测试推送，如下： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/ZwcSfznCRC6nEj-hnAjFXw/zh-cn_image_0000002658793917.png?HW-CC-KV=V1&HW-CC-Date=20260920T112703Z&HW-CC-Expire=31536000000&HW-CC-Sign=E9C759C225E1DE0A29BCB6A7EDB2A78022CDE495A557515292F141C4B185DB9D "点击放大")

2. 联系开发者删除：直接联系该应用开发者，登录AGC，在测试用户群组中删除用户的测试账号，如下： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/xG_veIWgStq4k34bymPGTw/zh-cn_image_0000002628394648.png?HW-CC-KV=V1&HW-CC-Date=20260920T112703Z&HW-CC-Expire=31536000000&HW-CC-Sign=315F0DE9D72FCD9DF75F799B9313B657D026AC941388E3E80067126CE8F25C55 "点击放大")
