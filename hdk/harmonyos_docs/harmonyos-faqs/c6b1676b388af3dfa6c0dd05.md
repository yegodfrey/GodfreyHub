# 点击Device Manager，提示"找不到应用程序"

**问题现象**

点击Device Manager进行登录授权时，如果提示"找不到应用程序"，则无法打开浏览器登录。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/0yoNsTWaR8WD9iStPOkwIg/zh-cn_image_0000002624478754.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CA838C456DC2E92A9D97CC65DAB6B47FA8D619C52A53C449CFE76B44B7ECDD5)

**解决措施**

该问题由默认浏览器损坏或被卸载导致，无法打开默认浏览器。

请根据[输入华为账号后，未出现"允许"按钮，浏览器界面无跳转](https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-signature-service-3)处理指导，重新设置默认浏览器后进行登录。
