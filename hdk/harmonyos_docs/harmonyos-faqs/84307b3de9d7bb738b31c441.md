# 出现"container is not running"错误

**问题现象**

在HarmonyOS设备上运行命令"hdc -n shell param set persist.ace.testmode.enabled 1"时，出现错误提示"container is not running"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/KiGuE2AcSdGk-Q31sQkhww/zh-cn_image_0000002654798185.png?HW-CC-KV=V1&HW-CC-Date=20260916T082506Z&HW-CC-Expire=31536000000&HW-CC-Sign=B290356452C61D57E95762F269D2CD89A8389892BEF4F550B6E5AC591BB8E9E7)

**解决措施**

在DevEco Studio中运行一个测试用例，推包到设备上，然后运行命令hdc -n shell param set persist.ace.testmode.enabled 1。
