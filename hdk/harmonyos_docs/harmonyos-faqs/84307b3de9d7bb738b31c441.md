# 出现"container is not running"错误

**问题现象**

在HarmonyOS设备上运行命令"hdc -n shell param set persist.ace.testmode.enabled 1"时，出现错误提示"container is not running"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/KiGuE2AcSdGk-Q31sQkhww/zh-cn_image_0000002654798185.png?HW-CC-KV=V1&HW-CC-Date=20261008T144325Z&HW-CC-Expire=31536000000&HW-CC-Sign=26CE4090851D7F91D3C19E4C01F3B014C2B50EBD7994EFB92217A365EF836EE9)

**解决措施**

在DevEco Studio中运行一个测试用例，推包到设备上，然后运行命令hdc -n shell param set persist.ace.testmode.enabled 1。
