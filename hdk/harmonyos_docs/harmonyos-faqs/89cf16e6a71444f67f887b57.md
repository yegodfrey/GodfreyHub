# 如何解决编译报错"Error: the name 'XXX' can only contain [a-zA-Z0-9_]"的问题

**问题现象**

编译报错：文件名只能包含大小写字母、数字、下划线。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ae/v3/7CIYad7iTWeFoG-kVYNAZg/zh-cn_image_0000002624638508.png?HW-CC-KV=V1&HW-CC-Date=20260916T082508Z&HW-CC-Expire=31536000000&HW-CC-Sign=79BA36C8967867D8C306457B6C5EE1C11AA5EB9BF18ABAF81EE3052378432A07)

**解决方案**

检查文件名是否包含除了大小写字母、数字和下划线之外的其他字符。
