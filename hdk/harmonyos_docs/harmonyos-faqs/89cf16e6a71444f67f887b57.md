# 如何解决编译报错"Error: the name 'XXX' can only contain [a-zA-Z0-9_]"的问题

**问题现象**

编译报错：文件名只能包含大小写字母、数字、下划线。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ae/v3/7CIYad7iTWeFoG-kVYNAZg/zh-cn_image_0000002624638508.png?HW-CC-KV=V1&HW-CC-Date=20261008T141655Z&HW-CC-Expire=31536000000&HW-CC-Sign=81EB9471677A4DDF79EE87F26BD606B62A770D0FF4F2D28C28BF4701A95505ED)

**解决方案**

检查文件名是否包含除了大小写字母、数字和下划线之外的其他字符。
