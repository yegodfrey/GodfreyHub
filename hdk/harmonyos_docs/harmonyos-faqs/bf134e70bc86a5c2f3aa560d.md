# 对象中函数的this如何指向外层

通过箭头函数实现。参考代码如下：

```ts
interface T {
  start: () => number
}
@Component
struct PointingOuterLayer {
  @State num: number = 1
  obj: T = {
    start: () => {
      return this.num
    }
  }
```
