# 如何查看智能体AgentID

## 问题现象

如何在小艺开放平台上查找已创建智能体的AgentID？

## 解决方案

方法一：登录小艺开放平台后，点击已创建的智能体，在配置页面下可查找到智能体ID，即为该智能体的AgentID。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/07/v3/gmUWnLUASpuip52u6NMU5Q/zh-cn_image_0000002658914061.png?HW-CC-KV=V1&HW-CC-Date=20260910T054834Z&HW-CC-Expire=31536000000&HW-CC-Sign=82114592979186827F5D3EFB5DE3C6F876620FF0443F4EC74317F9F63B4553F5 "点击放大")

方法二：登录小艺开放平台后，点击已创建的智能体，在网页地址栏中存在"agentid=agentxxxx"样字段，即为该智能体AgentID，样例如下图所示：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/_09aTZACRPmEpJPsv69c6A/zh-cn_image_0000002658794109.png?HW-CC-KV=V1&HW-CC-Date=20260910T054834Z&HW-CC-Expire=31536000000&HW-CC-Sign=46471051F644BD8E8D0C3659324CE1D070C9B99CE4C14647D1E0A721BF9BC787 "点击放大")
