# 如何解决编译报错"Error: cJSON_Parse failed, please check the JSON file."的问题

**问题现象**

编译错误："Error: cJSON\_Parse failed"。请检查JSON文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/hlJrELBzQ0qi8UN2HffwBw/zh-cn_image_0000002654797961.png?HW-CC-KV=V1&HW-CC-Date=20261008T142717Z&HW-CC-Expire=31536000000&HW-CC-Sign=7204B4FE9515667636D3132FBC8682CCC15B1793C67665648EC189B19F5C4196 "点击放大")

**报错原因**

module.json 文件格式不正确。

**常见场景**

1. JSON文件末尾有多余的逗号。

2. 根标签不是大括号{}。

**解决方案**

检查报错指向的 JSON 文件格式，例如末尾是否有多余的逗号，根标签是否为大括号 {}。
