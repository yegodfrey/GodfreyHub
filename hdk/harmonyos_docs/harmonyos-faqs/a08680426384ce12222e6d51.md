# 应用/服务的启动界面信息缺失，提示"Schema validate failed"报错

问题现象

在工程同步或编译构建时，出现"Schema validate failed"的错误提示。

![](https://media:101782454418916442)

解决措施

在开发应用/服务时，创建工程后，默认设置了启动界面信息。如果开发者误删其中某个字段，将导致报错。下面以重新设置启动界面信息为例，为提高冷启动性能，可以通过以下方式设置启动界面的图标和背景颜色。

1. 在模块的resources \> base \> element目录下，右键点击并选择New \> Element Resource File来创建资源文件。

   <br />

   ![](https://media:101782454418942443)

   <br />

2. 在弹出的对话框中，开发者可以自定义"File name"，例如 color；"Root element"请选择 color。

   <br />

   ![](https://media:101782454418970444)

   创建完成后，color.json文件如下图所示：

   ![](https://media:101782454419000445)

   <br />

3. 将[2](#zh-cn_topic_0000001233028585_li124901748185712)创建的color.json文件拷贝至模块的ohosTest \> resources \> base \> element目录下。

   <br />

   ![](https://media:101782454419026446)

   <br />

4. 在模块的src \> main \> module.json5文件的abilities数组中，添加startWindowIcon和startWindowBackground字段。若缺少任一字段，将出现ERROR: Schema validate failed报错。startWindowIcon字段索引模块下resources \> base \> media中的图标资源，startWindowBackground字段索引resources \> base \> element \> color.json中的颜色。

   <br />

   ![](https://media:101782454419058447)

   <br />

5. 在src \> ohosTest \> module.json5文件的abilities数组中，添加startWindowIcon和startWindowBackground字段。其中，startWindowIcon字段引用模块ohosTest下 resources \> base \> media中的图标资源，startWindowBackground字段引用 resources \> base \> element \> color.json中的颜色。
