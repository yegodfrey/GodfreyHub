# 如何写har包的编译脚本

在har包目录下的hvigorfile.ts文件中编写代码如下：

```
import { harTasks } from '@ohos/hvigor-ohos-plugin';


function harTask(): HvigorPlugin {
    return {
        pluginId: 'harTask',
        apply(node: HvigorNode) {
            console.log('hello harTasks!');
        }
    }
}


export default {
    system: harTasks,
    plugins: [harTask()]
}
```
