# 如何快速生成class的setter和getter方法

1. 在类内部，右键点击，选择"生成"。 ![](https://media:101782454287931953 "点击放大")

2. 选择Getter and Setter。 ![](https://media:101782454287956954 "点击放大")

3. 选择要生成Getters和Setters的字段，点击OK，快速生成。 ![](https://media:101782454287984955 "点击放大")

![](https://media:101782454288018956 "点击放大")
