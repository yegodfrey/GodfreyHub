# 编译报错"Local dependency in parameterFile does not exist"

**错误描述**

parameterFile 中的本地依赖项不存在。

**可能原因**

parameterFile中定义的值不存在。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/-9KyFmwdQYitluQDjQ5IwA/zh-cn_image_0000002624638536.png?HW-CC-KV=V1&HW-CC-Date=20260916T082508Z&HW-CC-Expire=31536000000&HW-CC-Sign=23BC6135F91454A548D19BBF9E23D4D97B22E798A9FE7A0DEE316780C034747E)

**解决措施**

检查本地依赖路径是否存在，以及是否区分大小写。
