# 编译报错"Local dependency in parameterFile does not exist"

**错误描述**

parameterFile 中的本地依赖项不存在。

**可能原因**

parameterFile中定义的值不存在。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/-9KyFmwdQYitluQDjQ5IwA/zh-cn_image_0000002624638536.png?HW-CC-KV=V1&HW-CC-Date=20261008T140117Z&HW-CC-Expire=31536000000&HW-CC-Sign=52C6A9424DD5C499D0AD596251AF7EBE603AB831927DAE6D8DB5B519BC46D512)

**解决措施**

检查本地依赖路径是否存在，以及是否区分大小写。
