# 构建报错"proxy data is duplicated"

**问题现象**

打包APP时，出现"uri datashareproxy://bundleName/** in proxy data is duplicated"的提示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2/v3/LYs7NnDoQLWGVl50zESDSA/zh-cn_image_0000002624478596.png?HW-CC-KV=V1&HW-CC-Date=20260916T082508Z&HW-CC-Expire=31536000000&HW-CC-Sign=2715943583E4CC89717E1FC901B28BC436FC476C5EB76CD4A140BEEA0A225374)

**解决措施**

proxyData 标识模块提供的数据代理列表，仅允许 entry 和 feature 配置，不同 proxyData 中配置的 URI 不得重复。遇到此问题，检查模块间是否配置了相同的 URI。
