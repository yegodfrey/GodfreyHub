# 邀请测试中的版本如何继续添加测试人员

## 问题现象

对于当前已处于测试阶段的版本，是否支持新增测试人员？

## 解决方案

1. 在AGC平台上，已开启的测试版本支持新增测试人员。当测试邀请任务启动后，若向测试群组添加新的测试用户，该用户并不会自动接收测试邀请链接。需要手动选择"重新邀请"用户： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/UGp8FInVTIib2xStXpgW-g/zh-cn_image_0000002628554472.png?HW-CC-KV=V1&HW-CC-Date=20260920T112703Z&HW-CC-Expire=31536000000&HW-CC-Sign=B4BAEE8422856BD6FC1974A926752ACA17C55B31F3787735DB5EEE664632AA7D "点击放大")

   或者通过分享邀请测试链接给新添加的用户：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/9nYYfsufSFCYbHKEENG1ag/zh-cn_image_0000002658913797.png?HW-CC-KV=V1&HW-CC-Date=20260920T112703Z&HW-CC-Expire=31536000000&HW-CC-Sign=05434B3F31A496045252B78E0534CE1F19F4264694A888BD6526C43B3BDC5B8A "点击放大")
2. 推荐[通过"分享链接+邀请码"邀请用户](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appgallery-invite-testuser-0000002292624413#section8765163593316)，该方式不需要手动添加测试用户，拥有该链接的用户可以直接点击链接加入测试计划。
