# Target AOT编译，AP文件生成失败

问题现象

Target AOT编译，AP文件生成失败，并报错提示"errno: 13"表示权限不足，如下图所示。

![](https://media:101782454429182644)

解决措施

errno: 13表示权限不足，请通过下述措施解决：  
打开命令行工具，输入以下命令，关闭selinux权限管控。

```
hdc shell
setenforce 0
```

以上设置重启将会失效，若设备重启请重新进行以上设置
