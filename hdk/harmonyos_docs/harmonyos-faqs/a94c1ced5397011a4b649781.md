# DevEco Studio安装HAP时报错"FileTransfer Failed: Error while Deploy Hap"

**问题现象**

DevEco Studio安装HAP时报错"FileTransfer Failed: Error while Deploy Hap"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/E5XYmXBYSyKvGMLhHNiE4g/zh-cn_image_0000002654798167.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=9319BEE04A383D9993C6582AEB05B64076A4651E6E0AAF1AC0E28DB8CCE103CF)

**解决措施**

使用真机场景：请更换数据线或PC侧USB接口后尝试。

使用模拟器场景：

* 在Local Emulator的设备列表窗口，点击"Wipe User Data"清除数据，启动模拟器并重新运行工程。
* 打开命令行工具，并进入DevEco Studio安装目录下的sdk\default\openharmony\toolchains路径，执行 hdc kill -r 命令，启动模拟器，重新运行工程。
