# 构建报错"input module releaseType is different"

**问题现象**

在打包APP时，如果提示"input module releaseType is different"，请检查输入模块的发布类型是否一致。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/xS6Om8R_RPuBiUUGLQWVWw/zh-cn_image_0000002654837859.png?HW-CC-KV=V1&HW-CC-Date=20261008T161812Z&HW-CC-Expire=31536000000&HW-CC-Sign=A91B780DCFC07D744151A1977DF49DE811ACB9ABF4DD3C00CA41D8FC900C0465)

**解决措施**

根据报错日志中的Warning信息提示的模块名称，检查模块间的apiReleaseType字段是否一致。

apiReleaseType字段由编译构建工具自动生成并保存在HAP/HSP包的module.json文件中。请确认各模块间该字段是否一致。如果存在不一致，需使用相同版本的SDK重新打包应用的各个模块，然后重新打包APP。
