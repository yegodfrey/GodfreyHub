# CodeGenie偶现报错：The reasoning_content in the thinking mode must be passed back to the API.

**问题现象**

DevEco Studio 6.1.0 Release（6.1.0.850）及以上版本，在CodeGenie中通过URL方式配置deepseek-v4模型后，过程中界面提示"The reasoning_content in the thinking mode must be passed back to the API."。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/PiTLDhxPQf6peM-APggPVA/zh-cn_image_0000002624478830.png?HW-CC-KV=V1&HW-CC-Date=20260916T082506Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E3107B7FC05FD131E78ED14916746AC3E51682A96CD80DCC94BDC78DD56908C "点击放大")

**解决措施**

使用Service Provider（服务提供商）方式配置模型，并在使用过程中打开深度思考。
