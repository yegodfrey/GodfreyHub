# 编译报错"keystore password was incorrect"

**问题现象**

编译时出现错误，提示"ERROR - hap-sign-tool: error: ACCESS_ERROR, code: 109. Details: Init keystore failed: keystore password was incorrect"。请检查密钥库密码是否正确。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/ryubatshSp-bvPC98SrZsg/zh-cn_image_0000002624638392.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB00497DB18AEA20DE8BDCAF87A4F6EFD1F08F22496EA344711490ECDD8E8860)

**报错原因**

密钥库(p12)的密码错误。签名文件中的签名密码错误导致该问题出现。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/cW9PGwlUQXaXFe6SOTgiJQ/zh-cn_image_0000002654837801.png?HW-CC-KV=V1&HW-CC-Date=20260916T082507Z&HW-CC-Expire=31536000000&HW-CC-Sign=DCB2A2D9A6DD2566FAEEFB3D6AB25EAB2E08EDEEB0DF82063F65E2A665DDEDCA)
> 注意
>
> 密钥库密码和密钥密码在创建p12文件时由开发者输入，请牢记这些密码。build-profile.json5文件中记录了密码的密文，但签名工具需要输入密码明文，不能直接使用build-profile.json5中的值。

**常见场景**

1. 密码输入错误。
2. 在命令行中输入了密文。
3. 密钥（keyAlias）密码和密钥库（p12）密码混淆。

**解决措施**

重新自动签名可以解决该问题：

1. 点击**File > Project Structure > Project > Signing Configs**，打开签名配置页面。

2. 勾选"Automatically generate signing"（如果是HarmonyOS工程，还需勾选"Support HarmonyOS"），等待重新签名，点击**OK**。
