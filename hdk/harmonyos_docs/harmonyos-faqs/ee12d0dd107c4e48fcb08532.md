# 如何获取应用打印的hilog日志到本地查看

#### 问题现象

hilog日志如何导出到本地？  

#### 解决方案

hilog日志导出到本地有2种方案：

1. hdc shell hilog \> 导出的文件地址。 ![](https://media:101782454260080530 "点击放大")

2. 通过hdc file recv /data/log/hilog获取。 ![](https://media:101782454260236531 "点击放大")
