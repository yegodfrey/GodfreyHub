# 上传软件包时，提示"No app with the specified package name is found under the team."

**问题现象**

打开上传软件包界面后，提示"No app with the specified package name is found under the team."。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/o_hdj3qyQfKEtgd074NntQ/zh-cn_image_0000002654798193.png?HW-CC-KV=V1&HW-CC-Date=20260916T082506Z&HW-CC-Expire=31536000000&HW-CC-Sign=89AD9CF61007018ED2B19685A2CA011AF3F20E3403F316FA18D47FC5DBDAF30F)

**解决措施**

因为当前账号在AppGallery Connect没有对应包名的应用，请在AppGallery Connect登录当前账号后[创建应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-createapp-0000001146718717)，再重新打开上传软件包界面。
