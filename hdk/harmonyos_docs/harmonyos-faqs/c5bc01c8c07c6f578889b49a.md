# 编译报错"module.json5 file not found."

**错误描述**

未找到module.json5文件。

**可能原因**

模块下的module.json5文件缺失。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/iSlTH2clSiGE3XVVrKNbhg/zh-cn_image_0000002624638540.png?HW-CC-KV=V1&HW-CC-Date=20260916T082508Z&HW-CC-Expire=31536000000&HW-CC-Sign=48704D92C990FBD082F1AC06CFDBC917581D8363155CE370D268A0C4DC2F46A6)

**解决措施**

在Stage模型项目中，确保每个模块包含module.json5文件。
