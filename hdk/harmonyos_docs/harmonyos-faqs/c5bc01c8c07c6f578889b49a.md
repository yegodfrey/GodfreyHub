# 编译报错"module.json5 file not found."

**错误描述**

未找到module.json5文件。

**可能原因**

模块下的module.json5文件缺失。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/iSlTH2clSiGE3XVVrKNbhg/zh-cn_image_0000002624638540.png?HW-CC-KV=V1&HW-CC-Date=20261008T172127Z&HW-CC-Expire=31536000000&HW-CC-Sign=48B6E842CC7E2E6AB364B92DCCDB69EA55B081E40474DCBD7F4A57725C9E511F)

**解决措施**

在Stage模型项目中，确保每个模块包含module.json5文件。
