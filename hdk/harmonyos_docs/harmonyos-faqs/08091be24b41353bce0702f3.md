# 如何解决编译报错"Declaration merging is not supported(arkts-no-decl-merging)" 或 "Cannot redeclare block-scoped variable 'xxx'"的问题

**问题现象**

在不同的文件中声明相同变量、interface、enum等类型，DevEco Studio不报错，但编译时会报错。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/MiOj5QiZSq6ELhR5PL3vwQ/zh-cn_image_0000002624478606.png?HW-CC-KV=V1&HW-CC-Date=20260916T082508Z&HW-CC-Expire=31536000000&HW-CC-Sign=EABEF65FDA2B4630DEFC48C664D268477F533EB4D980CE1C8F0218C58A3BA005)

**解决方案**

如果文件中不包含export关键字，该文件将视为全局命名空间的一部分。
