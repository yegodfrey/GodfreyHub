# 华为运动健康服务

#### HTS.00120000

|错误码编号|HTS.00120000|
|所属模块|HtsHmsCertHealthKit|
|描述|非常规错误|
|解决方法|步骤1：检查设备系统版本。 1.1 若Android版本不大于6.0，请更换设备。 步骤2：检查网络是否已连接。 2.1 若未连接手机无线网络，请连接。 2.2 若已连接手机无线网，依然报错，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-----------------------------------------------------------------------------------------------------------------------|

#### HTS.00120001

|错误码编号|HTS.00120001|
|所属模块|HtsHmsCertHealthKit|
|描述|用户未授权|
|解决方法|步骤1：检查用户是否授权。 1.1 若用户未授权，请重新进行登录授权，勾选所有读写权限。 1.2 若已存在全部权限，依然报错，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|--------------------------------------------------------------------------------------|

#### HTS.00120002

|错误码编号|HTS.00120002|
|所属模块|HtsHmsCertHealthKit|
|描述|正在进行数据割接，数据点操作暂时禁止|
|解决方法|步骤1：等待数据割接结束重新执行用例（性能测试百万级数据5分钟内完成割接）。 1.1 等待5分钟，数据割接结束，再次执行用例。 1.2 若等待5分钟之后执行用例，依然报错，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-------------------------------------------------------------------------------------------------------------|

#### HTS.00120003

|错误码编号|HTS.00120003|
|所属模块|HtsHmsCertHealthKit|
|描述|API调用异常|
|解决方法|步骤1：检查HMSCore版本是否安装错误。 1.1 若HMSCore版本为mirror环境版本，请卸载后到应用市场下载最新的HMSCore。 1.2 若HMSCore 版本正确，但是执行用例时提示HealthKit应用需要升级，请根据提示升级HealthKit的apk。 1.3 若HMSCore版本安装正确且HealthKit 的apk升级成功，依然报错，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00120004

|错误码编号|HTS.00120004|
|所属模块|HtsHmsCertHealthKit|
|描述|查询输入的时间戳不正确|
|解决方法|步骤1：请检查设备时区，设置-系统和更新-日期和时间，时区更改为中国标准时间。 1.1 若非中国时区，请将时区更改为中国标准时间。 1.2 若已为中国时区，依然报错，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|----------------------------------------------------------------------------------------------------------|

#### HTS.00120005

|错误码编号|HTS.00120005|
|所属模块|HtsHmsCertHealthKit|
|描述|用户华为帐号未登录|
|解决方法|步骤1：检查是否登录华为帐号。 1.1 若未登录华为帐号，请先登录华为帐号。 1.2 若已登录华为帐号，依然报错，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|--------------------------------------------------------------------------------|

#### HTS.00120006

|错误码编号|HTS.00120006|
|所属模块|HtsHmsCertHealthKit|
|描述|锁屏下禁止数据读写|
|解决方法|步骤1：检查是否在锁屏时进行数据的读写。 1.1 若手机黑屏锁屏状态，请解锁并保持设备在执行用例期间为亮屏解锁状态。 1.2 若亮屏解锁状态，依然报错，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|---------------------------------------------------------------------------------------------------|
