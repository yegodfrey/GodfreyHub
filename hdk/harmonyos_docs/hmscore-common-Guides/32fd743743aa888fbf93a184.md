# 集成HMS Core SDK（JavaScript）

在开发前，您需要将HMS Core SDK集成到您的开发环境中。  

#### 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.json"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 \> 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141626.09725301984241564617689327313294:50530906070409:2800:330892AB70649B351E2AFC1FA0BDE004527EF1E1FC98F31B88DE85F12213CBEB.png?needInitFileName=true?needInitFileName=true)
4. 将"agconnect-services.json"文件拷贝到"entry"应用级根目录下。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141626.76049717946978930104601451140070:50530906070409:2800:B61982FCF051BDC8A04458CF2F000F8397B3AE798BB643E2B75A3B5FD221E559.png?needInitFileName=true?needInitFileName=true)

如果您在"项目设置"模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的"agconnect-services.json"，来替换HarmonyOS应用模块entry的根目录下已有的文件。  

#### 添加编译依赖

1. 打开项目级"build.gradle"文件，添加agconnect服务依赖。项目级"build.gradle"文件已自动添加Maven代码库地址，您无需额外配置。

   ```
   buildscript { 
       dependencies { 
           classpath 'com.huawei.ohos:hap:2.4.4.2' 
           // 添加agconnect服务依赖。
           classpath 'com.huawei.agconnect:agcp-harmony:1.3.0.300'
       } 
   } 
   ```

2. 打开"entry"应用级根目录的"build.gradle"文件。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141626.78717375935235687933833373789534:50530906070409:2800:4EF3418787051AE755865EE1D0766E0C66B60970A99C2DE98310EF84E80B6315.jpg?needInitFileName=true?needInitFileName=true)
3. 在"dependencies"中添加如下编译依赖。

   ```
   dependencies {
       implementation 'com.huawei.hms:jsb-ohos-adapter:5.3.0.303'
   }
   ```

4. 在"dependencies"中添加agconnect的编译依赖。

   ```
   dependencies { 
       // agconnect依赖组件
       implementation 'com.huawei.agconnect:agconnect-core-harmony:1.3.0.300'
   }
   ```

5. 添加agcp插件配置。请根据实际情况选择：
   * 方式一：在文件头部声明下一行添加如下配置。

     ```
     apply plugin: 'com.huawei.agconnect'
     ```

   * 方式二：在plugins中添加如下配置。

     ```
     plugins {
         // 添加如下配置
         id 'com.huawei.agconnect'
     }
     ```

6. 在config.json文件添加如下配置。

   ```
   "deviceConfig": {
       "default": {
           "allowComponentsProxy": true
       }
   }
   ```

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141627.39531908913328931346737849234860:50530906070409:2800:CC2D0B1EBA5F77409BA0C140A2A3A9420117A30878ADD856BBEC65E461E9961A.png?needInitFileName=true?needInitFileName=true)  
allowComponentsProxy配置只能配置在entry模块中，并且entry模块中config.json里bundleName和package名称必须相同。  

#### 下载HMS Core SDK

1. 执行CMD命令打开命令行工具，执行cd命令进入HarmonyOS应用"entry"目录。
2. 执行NPM命令下载Base SDK。

   ```
   npm install @hmscore/hms-js-base
   ```

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141627.40285284833595661933762962727058:50530906070409:2800:F38AB2A6D9E9204E9099C8E6A319E51590F49B817B28ACAA1AEA89AD90291650.png?needInitFileName=true?needInitFileName=true)  
   * npm install @hmscore/hms-js-base表示下载最新版本Base SDK。
   * 如需下载指定版本Base SDK，可使用npm install @hmscore/hms-js-base@1.0.300。
   * 详细版本信息请参见[版本列表](https://www.npmjs.com/package/@hmscore/hms-js-base?activeTab=versions)。  
   出现如下提示，说明下载成功：

   ```
   + @hmscore/hms-js-base@1.0.300
   added 1 package from 1 contributor in 1.192s
   ```

3. 执行NPM命令下载对应Kit的SDK。

   ```
   npm install @hmscore/hms-js-account@1.0.300
   ```

#### 初始化模块

1. 在应用的MyApplication的onInitialize方法初始化JSB，在onEnd方法结束JSB模块的使用。

   ```
   import com.huawei.hms.jsb.adapter.har.bridge.HmsBridge;
   import ohos.aafwk.ability.AbilityPackage;

   public class MyApplication extends AbilityPackage {
       private HmsBridge mHmsBridge;
       @Override
       public void onInitialize() {
           // 初始化JSB
           mHmsBridge = HmsBridge.getInstance();
           mHmsBridge.initBridge(this);
           super.onInitialize();
       }

       @Override
       public void onEnd() {
           // 结束JSB
           mHmsBridge.destoryBridge();
           super.onEnd();
       }
   }
   ```

2. 在HarmonyOS应用"entry/src/main/js/default/app.js"文件中添加如下代码。

   ```
   import {hmsjsb} from '@hw-hmscore/hms-js-base'
   export default {
       hmsData: {
           eventCallbackMap: {}
       },
       onCreate() {
           console.info('AceApplication onCreate');
           hmsjsb.init(this.hmsData.eventCallbackMap);
       },
       onDestroy() {
           console.info('AceApplication onDestroy');
       }
   }
   ```

#### 同步工程

在完成以上的配置后，点击右上角"Sync Now"，完成"build.gradle"文件的同步，将相关依赖下载到本地。
