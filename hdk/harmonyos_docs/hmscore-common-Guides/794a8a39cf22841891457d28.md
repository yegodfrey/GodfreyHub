# 机器学习服务

#### HTS.00160001

|错误码编号|HTS.00160001|
|所属模块|HtsHmsCertMLKit|
|描述|HMS Core预装项检查：HMS Core运行所需的关键apk文件不存在|
|解决方法|步骤1：请检查/system/app/HMS/HMS.apk或/system/priv-app/HMS/HMS.apk是否存在。 1.1 若步骤1对应目录及文件已存在，执行步骤2。 1.2 若步骤1对应目录或文件不存在，请重新预置HMS Core。 步骤2：请检查/system/app/modules/目录下的apk文件与下列apk数量和名称是否一致。 2.1 若数量或名称有误,请按预装规范重新预装。 2.2 若数量和名称无误，但脚本执行失败,将结果信息返回华为工程师，进行定位并修复错误。 /modules/ML-documentskew.apk /modules/ML-isr.apk /modules/ML-LangDetect.apk /modules/ML-object.apk /modules/ML.apk /modules/ML-skeleton.apk /modules/ML-tsr.apk|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
