# 地图服务

## HTS.00170000

|**错误码编号**|HTS.00170000|
|---------|-------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertMapKit|
|**描述**|网络信号不稳定，导致地图加载超时|
|**解决方法**|步骤1：请检查设备网络信号是否正常。 1.1若信号不稳定，请确认信号稳定后重试。 1.2若信号正常，将结果信息返回华为工程师，进行定位并修复错误。|

## HTS.00170001

|**错误码编号**|HTS.00170001|
|---------|-----------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertMapKit|
|**描述**|相机已经移动到地图边缘导致移动操作未完成|
|**解决方法**|步骤1：请单独运行脚本，并观察设备界面，查看相机是否移动到地图边缘位置。 1.1若相机已经移动到边缘，请手动调整到地图中心位置后，重新尝试。 1.2若未移动到边缘，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|

## HTS.00170002

|**错误码编号**|HTS.00170002|
|---------|-------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertMapKit|
|**描述**|点击事件未触发|
|**解决方法**|步骤1：请确认设备状态，是否存在弹窗、卡顿或死机。 1.1若手机出现弹窗，请关闭弹窗后，重新尝试。 1.2若手机出现死机或者卡顿现象，请将手动恢复正常状态后，重新尝试。 1.3若手机状态正常，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
