# 安装HMS测试套件

#### 安装前准备：安装adb

1. 从官网下载最新adb版本包，需要安装1.0.41及以上版本，点击[下载链接](https://developer.android.com/studio/releases/platform-tools#downloads)。
2. 将版本包解压至用户的工作目录下。
3. 配置环境变量：系统变量修改 Path 变量，变量值新增 adb 程序所在路径。

   例如：adb 程序所在路径为"D:\\adb\\1.0.41\\adb"。进入环境变量编辑界面，选中系统变量"Path"，点击编辑，在该系统变量的编辑界面新增一项"D:\\adb\\1.0.41\\adb"即可。
4. 检查 adb 是否安装成功。  
   使用快捷键 Windows+R 打开"运行"窗口，在该窗口中输入cmd 并按回车，打开命令提示符。输入 adb version 并回车。
   * 若 adb 安装成功，则回显中显示 adb 版本信息等，如下图所示。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.48937209569078456168675384498647:50531115012105:2800:A0466A8074E3F959E76E396C9315C6192CBECAAD98A04CDF24BEF4178DA503F5.png?needInitFileName=true?needInitFileName=true)

* 若 adb 安装失败，则界面显示"adb不是内部或外部命令，也不是可运行的程序或批处理文件"。请排查是否环境变量配置有误。  

#### 安装前准备：配置JDK环境

1. 下载JDK安装包：从官网下载JDK 1.8版本，下载地址如下：

   <https://www.oracle.com/java/technologies/javase-jdk8-downloads.html>
2. 安装JDK：双击JDK安装包开始安装，根据指引完成JDK安装。过程中请注意记录JDK安装路径，用于后续环境变量配置。
3. 配置环境变量：系统变量修改Path变量，变量值新增JDK安装路径。

   例如：步骤2中JDK安装路径为"D:\\env\\Java\\JDK\\jdk1.8.0_231"。进入环境变量编辑界面，选中系统变量"Path"，点击编辑，新增一项"D:\\env\\Java\\JDK\\jdk1.8.0_231\\bin"即可。
4. 检查JDK是否安装成功。  
   使用快捷键Windows+R打开"运行"窗口，在该窗口中输入cmd并按回车，打开命令提示符。输入java -version并回车。
   * 若JDK安装成功，则回显中显示java版本信息等，如下图所示。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.70470796486830975015595408987289:50531115012105:2800:7A25AEBEB62E3EA948DFC1158423C4569476DA10BB40B6F11A652A2F55A079B8.png?needInitFileName=true?needInitFileName=true "点击放大")

* 若JDK安装失败，则界面显示"java不是内部或外部命令，也不是可运行的程序或批处理文件"。请排查是否环境变量配置有误。
