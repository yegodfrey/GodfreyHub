# 位置服务

#### HTS.00250000

|错误码编号|HTS.00250000|
|所属模块|HHtsHmsCertSiteKit|
|描述|等待查询超时|
|解决方法|步骤1：请检查设备网络信号是否正常。 1.1若信号不稳定，请确认信号稳定后重试。 1.2若信号正常，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-------------------------------------------------------------------------|

#### HTS.00250001

|错误码编号|HTS.00250001|
|所属模块|HHtsHmsCertSiteKit|
|描述|断言错误，返回结果与实际预期不符|
|解决方法|步骤1：请查看设备日志，搜索关键字"TomGeoProvider"。 1.1若可以搜索到关键字，说明设备使用的是Tomtom的能力，未使用华为Site功能导致，非问题。 1.2若未搜索到关键字，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|------------------------------------------------------------------------------------------------------------------------|
