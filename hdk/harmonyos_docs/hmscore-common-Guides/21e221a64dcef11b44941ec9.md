# 预装规范

#### HTS.00010001

|错误码编号|HTS.00010001|
|所属模块|HtsHmsCertPreInstallHmsDevice|
|描述|HMS Core预装项检查：HMS Core运行时权限预授权白名单未生效|
|解决方法|步骤1：请检查hms-default-permissions.xml文件是否按照预装规范要求放置在system/etc/default-permission目录下。 1.1 若文件未放置，请按照预装规范将文件放置在指定目录下。 1.2 若文件已放置，但脚本执行失败，请厂商优先确定是否做了特殊修改导致白名单中预授权权限未生效。|
|-----|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|

|描述|HMS Core预装项检查：HMS Core特许权限白名单未生效|

#### HTS.00010008

|错误码编号|HTS.00010008|
|所属模块|HtsHmsCertPreInstallHmsDevice|
|描述|HMS Core预装项检查：HMS Core触发拉起失败|
|解决方法|步骤1：am force-stop com.huawei.hwid清理所有进程。 1.1 若进程可以被清理，执行步骤2。 1.2 若进程无法被清理，已允许HMS Core核心进程保活，该情况下脚本不会报错。 步骤2：以任意方式调用HMS Core。 2.1 如打开华为帐号登录界面等，安卓7以上用ps --ef安卓7及以下用ps查询com.huawei.hwid进程。 2.2 若HMS Core进程未被拉起，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00010009

|错误码编号|HTS.00010009|
|所属模块|HtsHmsCertPreInstallHmsDevice|
|描述|HMS Core预装项检查：com.huawei.hwid进程空闲时被清理|
|解决方法|步骤1：清空后台所有运行软件，开始抓取全量手机日志，以便PID不一致时又要重新抓取，安卓7以上用ps --ef安卓7及以下用ps查询com.huawei.hwid进程，记录com.huawei.hwid.core/persistent两个核心进程的PID。 步骤2：手机静置5分钟及以上（期间不要对手机有任何操作），重新查询两个核心进程PID，和步骤1记录PID对比是否一致，查询后可停止抓取日志。 2.1 若PID不一致，优先自检HMS Core和HSF是否加入了对应的白名单允许核心进程保活。 2.2 若已加入白名单，但PID还是不一致，将步骤1抓取的全量日志返回华为工程师，进行定位并修复错误。|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
