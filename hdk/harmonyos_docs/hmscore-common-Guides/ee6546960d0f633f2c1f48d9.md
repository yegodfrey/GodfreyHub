# 流程

#### 操作流程

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------|
|1|[准备开发环境](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/android-dev-environment-0000001167344220)|在开发应用前，需要先进行Android Studio安装及配置。|
|2|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/android-config-agc-0000001212784051)|在开发应用前，需要在AppGallery Connect中创建项目、创建应用、打开相关服务。|
|3|[配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/android-signature-info-0000001167504158)|创建应用程序的签名证书，使用命令行生成签名证书指纹，并在AppGallery Connect上配置签名证书指纹。|
|4|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/integrate-sdk-0000001167185652)|在应用级"build.gradle"文件中添加agcp插件和HMS Core SDK的编译依赖，并同步您的应用以确保所有依赖项都具有所需的版本。|
|5|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/android-obfuscation-script-0000001212585591)|您编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|6|[添加权限](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/android-add-permissions-0000001167025694)|在"AndroidManifest.xml"文件中配置应用所需权限，并根据需要在代码中动态申请权限。|

#### 后续操作

完成开发准备任务后，你可以参见各服务的文档，继续将HMS Core服务添加到您的应用，并上架应用市场。

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。
