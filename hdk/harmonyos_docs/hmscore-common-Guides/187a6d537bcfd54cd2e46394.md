# Nearby Service和Awareness Kit的信标业务增加相关限制通知

尊敬的开发者，您好！

为达到更好的蓝牙扫描效果和终端设备的功耗平衡，华为将于2023年1月15日在近距离通信服务（Nearby Service）的信标业务（Beacon）和情景感知服务Awareness Kit的围栏业务中的"信标感知能力"新版本中增加相关限制，请您于2023年1月15日0点前按照以下要求重新配置，避免因配置不当导致您的业务出现异常。  

#### 情况一

如您使用的是Nearby Service的信标业务（Beacon），我们将：

1. 仅允许beacon id以"6bff00f723fdf7471402"开始的设备注册到云端。
2. 在Nearby扫描信标时，仅识别Beacon广播中uuid以"6bff00f723fdf7471402"前缀开始的iBeacon和以"6bff00f723fdf7471402"作为Name Space ID的Eddystone设备。

为保证您能正常访问Nearby Service，请排查完毕后根据以上要求完成相关配置。  

#### 情况二

如您使用的是Awareness Kit的围栏业务中的"信标感知能力"，请注意：

1. 如使用的参数是BeaconId，您将不受上述前缀的影响，默认只能使用2个Filter。
2. 如使用的参数是Namespace+Type，您的Beacon需要按照情况一描述中的相关要求进行修改，否则围栏将无法识别该Beacon，进而无法通知您的应用。

在配置过程中，您有任何疑问，请联系[技术支持](https://developer.huawei.com/consumer/cn/consultation)。如您未使用HMS Core Nearby Service的信标业务（Beacon）和Awareness Kit的围栏业务中的"信标感知能力"，可忽略此信息。给您带来的不便敬请谅解，感谢您的理解与支持！
