# 华为消息分类调整通知

尊敬的华为开发者：

您好，华为推送服务将于2023年3月31日对消息分类进行优化，届时推送消息将统一通过[消息自分类](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1076611477914)进行分类。

若您的应用在上述日期前未接入消息自分类，消息通知类型将会默认归为[资讯营销类](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section171976503205)消息（资讯营销消息每日推送数量有一定限制）。

建议您参考[《消息分类标准》](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section153801515616)尽快规划消息分类，并申请接入消息自分类，以便享受更多消息权益。

1. 智能分类在2023年3月31日后，将不再参与消息分类环节。
2. 申请自分类权益后，应用发消息若category未传值或者传值不准确，消息将默认归类为内容资讯。

[自分类权益申请流程](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section893184112272)：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，通过"增长 > 推送服务 > 配置"，在"配置"页签下选择需要申请自分类权益的应用，点击自分类权益后的"申请"。
3. 分类申请审核通过后，请根据[应用适配开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)进行适配，发送消息时携带category传值。
4. 适配完成后，点击界面上方的"激活功能"进行激活。

## FAQ

1. 消息分类优化之后有什么影响？一定要申请自分类吗？ 消息分类优化后，若应用没有及时申请[自分类权益](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835)，应用的消息将会默认归为资讯营销类消息（资讯营销消息每日推送数量有一定限制，请参考[《推送数量管理细则》](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-restriction-description-0000001361648361)）。应用可以通过申请[自分类权益](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section893184112272)，自行对消息进行分类，让消息分类能更精准地符合业务需要。

2. 如何确认我现在已经适配好了自分类？ 主要确认自分类申请页面，已经激活功能；正式发送时，消息报文携带了审核通过的消息类型 [category](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)值。

3. 资讯营销消息也需要配置[category](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)值吗？

   资讯营销消息可以配置为MARKETING，也可以默认为空。
4. 测试应用是否需要申请自分类权益？ 为了方便开发者对消息进行测试，测试应用可通过设置target_user_type参数为1发送测试消息。具体字段请参见[AndroidConfig](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197#section13271045101216)的定义。

如您有任何疑问请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093?ha_source=hms5)，感谢您对的理解和支持。
