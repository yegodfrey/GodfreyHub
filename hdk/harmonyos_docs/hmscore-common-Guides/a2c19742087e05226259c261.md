# 近距离通信服务

#### HTS.00450000

|错误码编号|HTS.00450000|
|所属模块|HtsHmsNearbyService|
|描述|Nearby服务未启动|
|解决方法|步骤1：查看HMS Core设置页面是否有"新冠肺炎接触卫士"。 1.1 若没有，请确认安装的HMS Core是否有预置NearbyService服务。 1.2 若有，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-------------------------------------------------------------------------------------------------------------------|
