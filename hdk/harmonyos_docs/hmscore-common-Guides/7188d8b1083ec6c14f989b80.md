# 集成HMS Core SDK（Java）

针对HUAWEI DevEco Studio开发环境，华为提供了Maven仓集成方式的HMS Core SDK包。在开始开发前，您需要将HMS Core SDK集成到您的HUAWEI DevEco Studio开发环境中。

## 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.json"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141627.03072493914273428238658980966582:50530906070409:2800:97616A49673C4A571ECDA6E3F9C9554E262F0D38BCCEC9880BBA28D2A444D5DD.png?needInitFileName=true?needInitFileName=true)
4. 将"agconnect-services.json"文件拷贝到"entry"应用级根目录下。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141627.26792342218603954893685855029646:50530906070409:2800:3D2F87DA13F354F2A32A8534FF2D4A9B186B4A60733FE737CC71ACEB290428C9.png?needInitFileName=true?needInitFileName=true)
   > 说明
   >
   > 如果您在"项目设置"模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的"agconnect-services.json"，来替换HarmonyOS应用模块entry的根目录下已有的文件。

## 添加编译依赖

1. 打开项目级"build.gradle"文件，添加agconnect服务依赖。项目级"build.gradle"文件已自动添加Maven代码库地址，您无需额外配置。

   ```screen
   buildscript { 
       dependencies { 
           classpath 'com.huawei.ohos:hap:2.4.4.2' 
           // 添加agconnect服务依赖。
           classpath 'com.huawei.agconnect:agcp-harmony:1.3.0.300'
       } 
   } 
   ```

2. 打开"entry"应用级根目录的"build.gradle"文件。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220907141627.93481518192255142344965096172213:50530906070409:2800:6ABD175AA16DBFD9B49DBC3C39FB932E4EAD21B4BC4999EFFA05AD7978072191.jpg?needInitFileName=true?needInitFileName=true)
3. 在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:hwid-ohos:{version}'
   }
   ```

   > 说明
   >
   > *hwid-ohos:{version}*仅为举例，请替换为实际的Kit依赖版本。
   >
   > 如：com.huawei.hms:**hwid-ohos:6.5.0.300** 、com.huawei.hms:**hianalytics-harmony:6.3.2.301**。
4. 在"dependencies"中添加agconnect的编译依赖。

   ```screen
   dependencies { 
       // agconnect依赖组件
       implementation 'com.huawei.agconnect:agconnect-core-harmony:1.3.0.300'
   }
   ```

5. 添加agcp插件配置。请根据实际情况选择：
   * 方式一：在文件头部声明下一行添加如下配置。

     ```screen
     apply plugin: 'com.huawei.agconnect'
     ```

   * 方式二：在**plugins** 中添加如下配置。

     ```screen
     plugins {
         // 添加如下配置
         id 'com.huawei.agconnect'
     }
     ```

## 同步工程

在完成以上的配置后，点击右上角"Sync Now"，完成"build.gradle"文件的同步，将相关依赖下载到本地。 说明
>
> 如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
