# HMS Core智慧屏2.x版本SDK下架停服的通知

尊敬的华为开发者，您好！

我们已经于2021年6月30日下架并停止HMS Core智慧屏2.x的SDK服务，建议您集成HMS Core SDK最新版本。最新的版本可同时支持华为智慧屏和华为手机，功能更加丰富。

如您对此有疑惑或升级遇到问题，可发送邮件至[HMSCore@huawei.com](mailto:HMSCore@huawei.com)或通过[客服支持](https://developer.huawei.com/consumer/cn/support/feedback/#/)咨询，我们将竭诚为您服务。

感谢长期以来对HMS Core服务的信赖和支持！

* 点击查看[华为帐号升级指导](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/account_upgrade_guide)
