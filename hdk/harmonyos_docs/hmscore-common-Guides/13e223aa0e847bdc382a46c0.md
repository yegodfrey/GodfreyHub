# Panorama Kit \& Image Kit下架停服的通知

尊敬的华为开发者：

您好，由于我们的业务调整和变化，我们即将下架Panorama Kit 和 Image Kit，如果您的应用集成了Panorama Kit 或 Image Kit，请您尽快移除集成，以免影响您的应用的可用性。

给您带来不便请您谅解。若您有疑问及使用问题，可发送邮件至[HMSCore@huawei.com](mailto:HMSCore@huawei.com)或通过[客服支持](https://developer.huawei.com/consumer/cn/support/feedback/#/)咨询，我们将竭诚为您服务。

下架时间表：  

|日期|计划|
|:---------|:-----------------------------------------------------------------------------------------------|
|2022.12.30|发布Kit下架通知。已集成应用可以继续使用，但建议您尽快启动移除集成工作。|
|2023.12.30|下架Panorama Kit 和 Image Kit的SDK及资料，停止对该开放能力的下载及编译支持，您将无法使用该开放能力构建新的应用，包括上架华为应用市场。请您在此时间前完成移除集成工作。|
|2024.03.30|停止就Panorama Kit 和 Image Kit提供技术支持服务，如果您的应用届时还集成了该开放能力，可能将无法使用。|
