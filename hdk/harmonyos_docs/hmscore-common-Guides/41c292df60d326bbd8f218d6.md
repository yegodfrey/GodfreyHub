# 开发者文档

## 开发者文档体系

为帮助开发者了解HMS Core的版本特性、开放能力、接口等信息并顺利集成相关功能至最终上架，HMS Core开发者文档为您提供了六类文档。

|文档类型|文档介绍|
|:----------------------------------------------------------------------------------------------------------------------|:-----------------------------------|
|[开发指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050048870)|指导开发者集成一个或多个HMS Core服务并实现不同的能力。|
|[API参考](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/api-summary-desc-0000001063744095)|提供开发者集成服务时需要使用的API参考信息。|
|[示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Examples/client-sample-code-0000001050048970)|一个能体现服务开放能力的示例工程。|
|[SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/android-sdk-download-0000001050048974)|提供各服务SDK的下载方法。|
|[Codelabs](https://developer.huawei.com/consumer/cn/codelabsPortal/index)|基于一个实战的场景，step by step的指导开发者去完成一个实践。|
|[学习视频](https://developer.huawei.com/consumer/cn/training/result?type1=50&type2=58)|用视频的方式介绍业务能力和如何接入。|
