# 华为分析服务

## HTS.00070001

|**错误码编号**|HTS.00070001|
|---------|-----------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertAnalyticsKit|
|**描述**|应用数据库无缓存打点事件|
|**解决方法**|步骤1：请检查设备是否有存储空间让应用写入数据。 1.1 若存储空间空间不够，请清除设备存储空间无用数据。 1.2 若存储空间空间清除后，问题依旧无法解决，将结果信息返回华为工程师，进行定位并修复错误。|

## HTS.00070019

|**错误码编号**|HTS.00070019|
|---------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertAnalyticsKit|
|**描述**|多品类HMS版本与设备不对应|
|**解决方法**|步骤1：请检查设备的HMS版本是否与设备对应。 1.1 卸载不对应的HMS core，安装应用市场内上架的HMS core。 1.2 若HMS core为预置包或是从应用市场内安装的，请参考步骤2。 步骤2：请检查设备是否刷过ROM或者使用工具修改过设备信息。 2.1 请使用未刷过ROM或者修改过设备信息的设备。 2.2 若使用的设备正常未修改过底层代码，问题依旧无法解决，将结果信息返回华为工程师，进行定位并修复错误。|

## HTS.00070020

|**错误码编号**|HTS.00070020|
|---------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertAnalyticsKit|
|**描述**|Kit无法绑定服务|
|**解决方法**|步骤1：请检查是否是网络环境问题，HMS core无法在后台运行。 1.1 切换设备网络，使设备可以接入外部网络。 1.2 若设备网络正常，请参考步骤2。 步骤2：请检查HMS core是否可以在后台运行。 2.1 给予HMS自启动或开机启动的权限。 2.2 若HMS core权限正常，问题依旧无法解决，将结果信息返回华为工程师，进行定位并修复错误。|
