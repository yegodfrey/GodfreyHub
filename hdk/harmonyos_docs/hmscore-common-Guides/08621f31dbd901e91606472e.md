#### HTS.00060002

|错误码编号|HTS.00060002|
|所属模块|HtsHmsCertAdsKit|
|描述|广告请求返回204：广告请求到服务器了，匹配到了广告位，但是因各种过滤条件，而未返回广告内容|
|解决方法|步骤1：请确认验证的手机是否是华为设备。 1.1 若非华为设备，这是服务器过滤的逻辑，将执行结果和以下路径的日志返回华为工程师，进行定位并修复错误。 /sdcard/Android/data/com.huawei.hwid/files/Log/HiAdKitLog.log 1.2 若是华为设备，需要反馈机型和名称，以便确实是否为超高端手机或者是新设备未入库导致的不投放广告。|
|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00060004

|错误码编号|HTS.00060004|
|所属模块|HtsHmsCertAdsKit|
|描述|广告请求中广告位在服务器未匹配到对应的广告位，而无广告任务返回|
|解决方法|步骤1：请基于当前设备,点击HuaweiAdsSdk_Demo，进行手工触发开屏广告，如果10s无法展示广告，查看业务日志是否包含关键字样（包含引号）"content":\[{【业务日志路径】/sdcard/Android/data/com.huawei.hwid/files/Log/HiAdKitLog.log。 1.1 若包含关键字样，则表示目前网络过慢导致广告下载和展示过慢；请替换网络。 1.2 若不包含关键字样，请参考广告请求检查错误码进行排查。|
