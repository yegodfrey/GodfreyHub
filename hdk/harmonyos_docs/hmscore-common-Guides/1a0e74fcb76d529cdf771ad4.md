# 社交关系服务

#### HTS.00210001

|错误码编号|HTS.00210001|
|所属模块|HtsHmsCertSNSKit|
|描述|HMS Core预装项检查：HMS Core运行时未找到社交入口|
|解决方法|步骤1： 检查HMS Core是否按照预装规范进行安装成功，并授权。 1.1 若HMS Core未安装或者未授权，请按照预装规范进行检查安装。 1.2 若HMS Core已检查无误，请执行步骤2。 步骤2：检查华为帐号是否按照预装规范进行登录成人帐号。 2.1 若华为帐号未登录成人帐号，请按照预装规范进行登录帐号。 2.2 若华为帐号已登录，请执行步骤3。 步骤3：检查hts anchor版本是否按照预装规范安装对应测试版本。 3.1 若anchor未安装，请按照预装规范进行安装。 3.2 若检查没问题，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00210002

|错误码编号|HTS.00210002|
|所属模块|HtsHmsCertSNSKit|
|描述|HMS Core预装项检查：HMS Core未找到家人共享入口|
|解决方法|步骤1： 检查HMS Core是否按照预装规范进行安装成功，并授权。 1.1 若HMS Core未安装或者未授权，请按照预装规范进行检查安装。 1.2 若HMS Core已检查无误，请执行步骤2。 步骤2：检查华为帐号是否按照预装规范进行登录成人帐号。 2.1 若华为帐号未登录成人帐号，请按照预装规范进行登录帐号。 2.2 若华为帐号已登录，请执行步骤3。 步骤3：通过cmd命令adb shell getprop ro.build.version.emui检查手机是否能获取到EMUI版本。 3.1 若手机能获取到版本，请执行步骤4。 3.2 若手机不能获取到版本，请将结果信息返回华为工程师，进行定位并修复错误。 步骤4：检查帐号中心页面是否有家人共享入口。 4.1 若检查帐号中心没有家人共享入口，将结果信息返回华为工程师，进行定位并修复错误。 4.2若检查帐号中心有家人共享入口，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00210004

|所属模块|HtsHmsCertSNSKit|

#### HTS.00210005

|错误码编号|HTS.00210005|
|所属模块|HtsHmsCertSNSKit|
|描述|HMS Core老版本未进入好友界面|
|解决方法|步骤1： 检查HMS Core是否按照预装规范进行安装成功，并授权。 1.1 若HMS Core未安装或者未授权，请按照预装规范进行检查安装。 1.2 若HMS Core已检查无误，请执行步骤2。 步骤2：检查华为帐号是否按照预装规范进行登录成人帐号。 2.1 若华为帐号未登录成人帐号，请按照预装规范进行登录帐号。 2.2 若华为帐号已登录，请执行步骤3。 步骤3：点击帐号中心右上角小气泡，进入社交，若有更新等待更新完成 。 3.1进入社交界面以后，查看页面下方是否有消息和好友页面，若不存在，则将结果信息返回华为工程师，进行定位并修复错误。 3.2进入社交界面以后，查看页面下方是否有消息和好友页面，若存在，则返回帐号中心页面重新进入一次小气泡，若还存在消息好友页面，则自行判断是否需要升级HMS CORE版本，若不升级则将结果信息返回华为工程师，进行定位并修复错误 ，若升级后，该问题还没解决，将结果信息返回华为工程师，进行定位并修复错误。|

#### HTS.00210006

|错误码编号|HTS.00210006|
|所属模块|HtsHmsCertSNSKit|
|描述|HMS Core未进入消息设置页面|
|解决方法|步骤1： HMS Core进入帐号中心，点击右上角小气泡，进入社交界面，再点击右上角设置按钮，检查设置页面是否存在接收新消息通知按钮以及显示消息详情按钮。 1.1 若存在接收显示消息详情按钮，则进行步骤2。 1.2 若不存在显示消息详情按钮，则打开接收新消息通知按钮。 步骤2： 关闭接受新消息通知按钮，观察显示消息详情是否存在。 2.1 若存在显示消息详情，则结果信息返回华为工程师，进行定位并修复错误。 2.2 若不存在显示消息详情，但是脚本执行失败，则结果信息返回华为工程师，进行定位并修复错误。|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00210007

|错误码编号|HTS.00210007|
|所属模块|HtsHmsCertSNSKit|
|描述|HMS Core家人共享的部分功能未适配到手机|
|解决方法|步骤1： HMS Core进入帐号中心，点击右上角小气泡，进入社交界面，点击右上角的铃铛图标，进入通知号页面，检查是否有应用市场 。 1.1 若存在应用市场，则进行步骤2。 1.2 若不存在应用市场，则点击右上角搜索，进行关注应用市场，检查是否能关注成功，若关注成功，则进行步骤2，若关注失败，则结果信息返回华为工程师，进行定位并修复错误。 步骤2： 进入应用市场通知号界面，点击右上角的小人头像，进入设置页面，观察是否存在通知号头像、名称、简介、归属以及接收消息按钮、免打扰按钮、置顶按钮。 2.1 若该元素全部存在，但是脚本执行失败，则结果信息返回华为工程师，进行定位并修复错误。 2.2 若元素有缺失，则结果信息返回华为工程师，进行定位并修复错误。|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00210008

|错误码编号|HTS.00210008|
|所属模块|HtsHmsCertSNSKit|
|描述|HMS Core应用市场通知号置顶失败|
|解决方法|步骤1： HMS Core进入帐号中心，点击右上角小气泡，进入社交界面，点击右上角的铃铛图标，进入通知号页面，检查是否有应用市场 。 1.1 若存在应用市场，则进行步骤2。 1.2 若不存在应用市场，则点击右上角搜索，进行关注应用市场，检查是否能关注成功，若关注成功，则进行步骤2，若关注失败，则结果信息返回华为工程师，进行定位并修复错误。 步骤2： 进入应用市场通知号界面，点击右上角的小人头像，进入设置页面，观察是否存在置顶按钮。 2.1 若该按钮存在，则打开置顶按钮，返回通知号消息界面，观察应用市场通知号是否被置顶并置灰，若被置顶并置灰，但是脚本执行失败，则结果信息返回华为工程师，进行定位并修复错误，若未被置顶，则是产品问题，也结果信息返回华为工程师，进行定位并修复错误。 2.2 若元素有缺失，则结果信息返回华为工程师，进行定位并修复错误。|
