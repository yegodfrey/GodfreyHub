# 环境检查

#### HTS.00360000

|错误码编号|HTS.00360000|
|所属模块|HtsHmsCertPresetHost|
|描述|检查设备是否插入SIM卡：该设备未插入SIM卡，请检查并处理。|
|解决方法|步骤1：确保插入SIM卡后，选择"重试"。 1.1若已确定插入SIM卡且多次"重试"失败，可选择"跳过"。|
|-----|-----------------------------------------------------|

#### HTS.00360002

|错误码编号|HTS.00360002|
|所属模块|HtsHmsCertPresetHost|
|描述|设置系统语言为中文：系统语言库不存在"中文简体"（或系统地区不为中国区）。|
|解决方法|步骤1：请先添加在"中文简体"系统语言库，并且将地区设置为"中国区"，选择"重试"。 1.1若已手工设置正确且多次"重试"失败可选择"跳过"，然后手动将系统语言设置为"中文简体"即可。|
|-----|--------------------------------------------------------------------------------------------|

#### HTS.00360003

|错误码编号|HTS.00360003|
|所属模块|HtsHmsCertPresetHost|
|描述|关闭移动4G网络：关闭移动网络失败。|
|解决方法|步骤1.请检查设备是否插入SIM卡。 1.1若已经插入SIM卡，可手动关闭4G网络后，选择"重试"。 1.2若该设备无移动网络功能或已手工关闭移动网络且多次"重试"失败可选择"跳过"。|
|-----|--------------------------------------------------------------------------------------------|

#### HTS.00360004

|错误码编号|HTS.00360004|
|所属模块|HtsHmsCertPresetHost|
|描述|打开设备定位功能：打开定位功能失败。|
|解决方法|步骤1.查看设备是否支持GPS定位。 1.1若设备支持GPS定位，可手动打开定位功能后，选择"重试"。 1.2若设备无定位服务功能或已手工打开定位服务功能且多次"重试"失败可选择"跳过"。|
|-----|----------------------------------------------------------------------------------------------|

#### HTS.00360009

|错误码编号|HTS.00360009|
|所属模块|HtsHmsCertPresetHost|
|描述|检查系统推送服务是否符合要求：系推送服务版本不满足要求。|
|解决方法|步骤1：请检查系统是否安装了推送服务。 1.1若ROM不支持推送服务，请选择"跳过"。 1.2若已安装推送服务，请确保至少11.1.6版本（确认下是否设备都是这个版本），选择"重试"。若已确认版本满足要求但多次"重试"失败，可选择"跳过"。|
|-----|------------------------------------------------------------------------------------------------------------------------|

#### HTS.00360013

|错误码编号|HTS.|
|所属模块|HtsHmsCertPresetHost|
|描述|检查账号：拉起账号中心界面超时。|
|解决方法|步骤1.请清除该设备缓存或重启设备。 1.1查看是否能手动拉起账号中心界面，并估测该设备拉起账号中心的所需时间，操作命令：adb shell am start -a android.intent.action.MAIN -n com.huawei.hwid/com.huawei.hms.runtimekit.stubexplicit.HwIDCenterActivity，若能拉起，请把拉起所需时间反馈给华为工程师。 1.2若不能拉起，请联系华为工程师解决。|
|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
