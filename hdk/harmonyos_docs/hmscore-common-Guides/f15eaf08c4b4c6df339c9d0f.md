# 本地通知频次及分类管控通知

尊敬的华为开发者：

为了给用户提供更好的消息通知体验，营造清朗网络空间。从2023年9月15日开始，华为推送服务将基于[《华为消息分类标准》](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section153801515616)对本地通知进行灰度管控，主要包括对应用发送的本地通知进行分类管理，以及对资讯营销消息统一进行频次管控。

（注：本地通知指应用客户端直接调用系统接口发送的通知 。）

详细规则如下：

1. 应用在未申请自分类权益的情况下，发送的本地通知将全部按照资讯营销消息处理（限频2条或5条/天）。
2. 应用发送的本地资讯营销消息会计入总的资讯营销消息频次数量，每天应用的推送频次有总量限制，具体请参见[《推送数量管理细则》](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-restriction-description-0000001361648361)。建议应用合理规划本地通知和云端通知的发送策略。

   （例：如应用发送营销内容配额为5条/天，此时本地通知发送3条，则通过云端通知可发送的消息条数为5-3=2条。）
3. 应用可通过申请自分类权益，对本地消息进行分类管理；应用若已申请云端相关消息类型，将自动生效本地通知类型，本地通知无需重复申请，但应用仍需适配开发。
4. 本地通知与云端通知的自分类适配开发方式不一样，具体请参考[适配流程](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)。

本地通知[自分类权益申请流程](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section893184112272)：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，通过"增长 \> 推送服务 \> 配置"，在"配置"页签下选择需要申请自分类权益的应用，点击自分类权益后的"申请"。
3. 分类申请审核通过后，请根据[应用适配开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)进行适配，发送消息时携带category传值。
4. 适配完成后，点击界面上方的"激活功能"进行激活。

#### FAQ

1. 本地通知和云端通知申请自分类的流程有什么区别？ 本地通知和云端通知，申请自分类的流程一致，如果应用已申请过云端通知相同消息类型，无需重复申请。

   但应用适配开发流程不一样，需要对本地通知进行适配开发，具体请参考[应用适配开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)。

   （例：即时聊天的category取值，本地通知为CATEGORY_MESSAGE，云端通知为IM）
2. 同一个消息类型，应用的本地通知和云端通知category传值相同吗？ 不相同，具体请参考[《消息分类标准》](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1076611477914)。

3. 本地通知不接入自分类可以吗？ 若应用本地通知不涉及发送服务与通讯消息，无需申请自分类。本地通知不接入自分类，消息将全部按照资讯营销消息处理（限频2条或5条/天）。

4. 资讯营销消息需要申请自分类吗？ 资讯营销消息无需申请，可直接进行[应用适配开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)。
