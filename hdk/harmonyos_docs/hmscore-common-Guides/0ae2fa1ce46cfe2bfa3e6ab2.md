# 预装App

## HTS.00350000

|**错误码编号**|HTS.00350000|
|---------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertAppCommon|
|**描述**|打开华为教育APP：拉起华为教育APP失败|
|**解决方法**|步骤1：请检查该设备是否预装了华为教育App，并确保华为教育app未被隐藏。 1.1 若该设备安装了华为教育app，请尝试用命令查看是否能手动拉起（adb shell am start -a android.intent.action.MAIN -n com.huawei.educenter/.MainActivity ）。 1.2 若不能拉起app，将结果信息返回华为工程师，进行定位并修复错误。|
