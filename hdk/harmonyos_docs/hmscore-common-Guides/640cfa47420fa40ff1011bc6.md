# 配置应用签名信息

## 生成签名证书

开发者通过**Android Studio** 创建一个新的签名文件并使用其对APK进行签名。此签名文件后续会用于生成**SHA256**指纹。

1. 在新建的**Android Studio** 工程的菜单栏中选择"Build > Generate Signed Bundle/APK..."。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143029.27006892634952268725563052780719:50001231000000:2800:C3B775301726E5D7F5D07EDBCD89F29E24182ECA668026210CD21E435EB7454D.png?needInitFileName=true?needInitFileName=true "点击放大")
2. 在"Generate Signed Bundle or APK"页面，选择"APK"签名，并点击"Next"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143029.60358732093059902904592750412195:50001231000000:2800:BF0016CEE698EECCF7726CEA1A719DFC6F06D37CE1A5942D941C8F08CE49B9E2.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 在填写签名文件信息页面，如果已经存在签名文件，则点击"Choose existing..."选择签名文件，并填写对应签名文件的"Key store password"、"Key alias"、"Key password"，然后点击"Next"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.18013822114163744404763500644193:50001231000000:2800:14CEE64895663AA4FCA7F18672465BF44C40FBBD101732712819A2533E659914.png?needInitFileName=true?needInitFileName=true "点击放大")

   如果不存在签名文件，则选择"Create new..."，创建一个新的签名文件。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.14087041246266499002902060513967:50001231000000:2800:5CB0B1B00AA623688E1C743D771C2CD5978B917922C800D4C814BF45CD785C34.png?needInitFileName=true?needInitFileName=true "点击放大")

   在创建新的签名文件页面，填写签名文件的保存地址以及保存文件名称、签名文件的密码、**Alias**等信息。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.13302675873809551204982620948033:50001231000000:2800:566E436A511CA59D260A1224E811526EC769A57399157B7D7DF3339202DCD367.png?needInitFileName=true?needInitFileName=true "点击放大")

   完成新签名文件创建后，在"Generate Signed Bundle or APK"弹出框页面上会显示对应签名文件的信息，然后点击"Next"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.29421399016034752641230045987265:50001231000000:2800:B7B7629980F59F59B5133858EEAF01C3F2BEA1DD3B6697CCBD8C61388258E623.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 在填写完签名信息页面点击"Next"后，出现选择签名方式页面，在此页面勾选"V1"和"V2"签名选项，并点击"Finish"，生成一个签名**APK** （此APK可上传至**AppGallery Connect** 用于自动获取应用包名）。

## 生成签名证书指纹

签名证书指纹用于校验应用的真实性，您需要根据签名证书在本地生成签名证书指纹，并在应用上架前将签名证书指纹配置到AppGallery Connect。

在生成签名证书指纹前需要满足以下两个条件：

* 已创建应用程序的签名证书，签名证书创建请参见[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#2)。
* 当前PC已经安装[JDK](https://www.oracle.com/java/technologies/javase-downloads.html)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore C:\TestApp.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.34960572461137721917576074036054:50001231000000:2800:D9DCB5274AC49E4FE0A7BA52E9ACC54DFC466F9F56451B59613CBF86B1C21C43.png?needInitFileName=true?needInitFileName=true "点击放大")

* macOS
  1. 打开Terminal终端。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.57227035694251660561757588188628:50001231000000:2800:C8ADCC91422750077942349B899780092D2F6C289BEF9CE1C2D2E48302A5667B.png?needInitFileName=true?needInitFileName=true)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/admin/Downloads/HmsDemo.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.88394028495599216561997413611290:50001231000000:2800:A7AA1E7DAAA4E87C4F0C43FA1159C3F7C03B7ABCF00064CAFCE23F9FBC514BA8.png?needInitFileName=true?needInitFileName=true)

## 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.71983809252920379437655741172108:50001231000000:2800:C2693A21EB2B8604B10BE1DC29D5D4CB3163E2329EBC626989EDA9ABED0AF73E.png?needInitFileName=true?needInitFileName=true)
   > 说明
   >
   > 在"项目设置"页面的"应用"区域，点击"Client Secret"后面的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230712143030.64050940830282990762420417363844:50001231000000:2800:4E57E8603C963401B5F2A6B7CF5D45524080A4D031E90257E2F3FE14D690BEAC.png?needInitFileName=true?needInitFileName=true)即可复制Client Secret。
4. 配置完成后，点击"保存"。
