# 使用HMS测试套件进行认证测试

1. 点击"认证测试"，在页面上方搜索框找到所需要进行认证测试的申请单。 说明
   >
   > 此处只列出状态为"认证中"的认证记录。
2. 选择所需要认证的产品，点击展开后，点击操作下方的"认证测试"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191608.47734613346044200336244872833268:50531115012105:2800:C49441E7A8F9AE79CCE5434720A2A628A1C2C65D7A21ECC559115664182D40F5.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   > 1. 同一款机型支持创建多个配置，后续可进行认证测试。
   > 2. 可同时并行执行多个认证测试。
3. 在进行"认证准备"前，为保证测试用例顺利执行，必须对测试机进行对应品类场景预置操作，详情请参见[FAQ](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/wenti-0000001204131102#section1651234384117)。
4. PC连接所需被测设备，系统识别设备信息后，选择测试设备，开始点击"认证准备"，对被测设备进行校验，检验完成后，页面进行用例下载、安装APK和环境检查。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191608.41668388654426924698027192523838:50531115012105:2800:94E9C59031ECD4B317C3FF2AF30EB8AA97F5FE5D80A3E4B0F12BBB1FCAB68BF5.png?needInitFileName=true?needInitFileName=true "点击放大")
5. 请根据实际情况，确保环境检查无误后，点击"开始测试"，仔细阅读弹框内容，点击"确认"，进行测试执行。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191608.52025366100812451324249221725789:50531115012105:2800:10CFDC1C0A3AE45B450C69F4EE15721C3F84B98EE83F3D02A0F80A214483E760.png?needInitFileName=true?needInitFileName=true "点击放大")
6. 自动测试完成后，进入交互测试环节，测试相关业务服务，每条用例根据页面展示的操作步骤完成相关测试。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191608.23794428303553481854716467731536:50531115012105:2800:44197B0660297D1B2470375C4D83398714F3A1B30E07D00E722D38BDD61197AF.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   >
   > 每条用例都必须填写执行结果，如果通过则需选择设备截图上传测试凭证，不通过则请描述失败步骤和失败现象。
7. 认证测试执行完成后，生成测试结果，同时支持重新测试和失败重试。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191608.16992487689959215858952087126655:50531115012105:2800:AD679D4ED21EF641FDDCDB8359BA366DBD9CCD97C72A91F8996FB8113ED9641E.png?needInitFileName=true?needInitFileName=true "点击放大")
8. 确认结果无误后，点击"上传测试结果"，将上传最近的一次认证测试结果，上传后，当前认证测试流程关闭，相关数据会同步认证中心。
