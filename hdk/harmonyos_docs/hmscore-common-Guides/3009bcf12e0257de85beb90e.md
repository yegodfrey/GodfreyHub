# 视频编辑服务

## HTS.00310001

|**错误码编号**|HTS.00310001|
|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertVideoEditorKit|
|**描述**|用例执行异常检查：执行中"开始创作"按钮找不到|
|**解决方法**|步骤1：检查手机界面是否处在VideoEditor主界面。 1.1 若处在主界面，请执行步骤2。 1.2 若不处在主界面，将结果信息返回华为工程师，进行定位并修复错误。 步骤2：检查手机界面是否有弹出框等其他弹出按钮遮挡主界面。 2.1 若有弹出框遮挡，点击关闭弹出框后，重跑该用例。 2.2 若无弹出框遮挡，将结果信息返回华为工程师，进行定位并修复错误。|
