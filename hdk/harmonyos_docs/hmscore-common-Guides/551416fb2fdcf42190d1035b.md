# 配置应用签名信息

> 说明
>
> * 若您在模拟器上进行调试并查看运行效果，则无需完成本章节以下步骤，具体操作请参见[使用模拟器运行应用](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/run_simulator-0000001053303709)和[使用模拟器进行调试](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_emulator-0000001115721921)。
> * 若您在真机上进行调试并查看运行效果，请继续完成本章节以下步骤。

## 通过自动签名方式对应用签名

为确保HarmonyOS应用的完整性，HarmonyOS通过数字证书和Profile文件来对应用进行管控，只有签名过的HAP才允许安装到设备上运行。因此，为了保证应用能够安装到调试设备上，您需要提前申请相应的调试证书与调试Profile文件。

具体操作请参见[通过DevEco Studio自动化签名方式对应用签名](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section677893315228)。

## 通过手动签名方式对应用签名

1. 生成数字证书和调试Profile文件。

   为确保HarmonyOS应用的完整性，HarmonyOS通过数字证书和Profile文件来对应用进行管控，只有签名过的HAP才允许安装到设备上运行。因此，为了保证应用能够安装到调试设备上，您需要提前申请相应的调试证书与调试Profile文件。

   详细步骤如下：
   1. [生成密钥和证书请求文件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/publish_app-0000001053223745#section9752152162813)。
      * **密钥**：格式为.p12，包含非对称加密中使用的公钥和私钥，存储在密钥库文件中，公钥和私钥对用于数字签名和验证。
      * **证书请求文件**：格式为.csr，全称为Certificate Signing Request，包含密钥对中的公钥和公共名称、组织名称、组织单位等信息，用于向AppGallery Connect申请数字证书。
   2. [申请应用调试证书](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-manual-0000001177608893#section13331154632718)。

      **数字证书**：格式为.cer，由华为AppGallery Connect颁发，分为应用调试证书和应用发布证书。
   3. [注册调试设备](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-manual-0000001177608893#section7732152932911)。
   4. [申请调试Profile](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-manual-0000001177608893#section1774717395304)。

      **Profile文件**：格式为.p7b，包含HarmonyOS应用的包名、数字证书信息、描述应用允许申请的证书权限列表，以及允许应用调试的设备列表（如果应用类型为Release类型，则设备列表为空）等内容，每个应用包中均必须包含一个Profile文件，分为调试Profile和发布Profile。
2. 配置签名信息。

   编译构建APP需要使用到制作的密钥（.p12）文件、在AppGallery Connect中申请的证书（.cer）文件和Profile（.p7b）文件，然后在DevEco Studio中对工程进行配置。

   操作指导请参见[配置签名信息](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/publish_app-0000001053223745#section280162182818)。配置时，请选择在**File > Project Structure > Project > Signing Configs > Debug**窗口中，配置工程的签名信息。

## 手动生成签名证书指纹

签名证书指纹用于校验应用的真实性，您需要根据密钥文件（.p12文件）在本地生成签名证书指纹，并在应用上架前将签名证书指纹配置到AppGallery Connect。

在生成签名证书指纹前，已通过DevEco Studio或命令行工具[生成密钥文件（.p12文件）和证书请求文件（.csr文件）](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/publish_app-0000001053223745#section9752152162813)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore D:\harmony\key\myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420143827.69460612619417621949006800818848:50530419065356:2800:85D76DECD720326B1C28AC1398FADD820468A2F5B99D416FF24011DED7A2AFA8.png?needInitFileName=true?needInitFileName=true)

* macOS
  1. 打开Terminal终端。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420143827.99483434134445769243711821415421:50530419065356:2800:7F3EDF1B9FD3FC2A3CC94ACF09C1B75DD57E9A479C423CFDDDE3F1908EB40B18.png?needInitFileName=true?needInitFileName=true)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。<keystore-file>为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/xxxxxx/Downloads/myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420143827.84467239426089159146630570229069:50530419065356:2800:81F179DE96052EDCE31B158B547789193F4821893F6104CF838043B85ECB10B2.png?needInitFileName=true?needInitFileName=true "点击放大")

## 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420143828.65416762855424366629529099566879:50530419065356:2800:59FC427BA1AAC518C0701318EADF5B0076E1EEBEA773641F9FA0884BF288B766.png?needInitFileName=true?needInitFileName=true)
   > 说明
   >
   > 在"项目设置"页面的"应用"区域，点击"Client Secret"后面的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420143828.70893908226297103852484496138036:50530419065356:2800:F08A81CF29A1EDF0FF7500FF6E3D320422A14C066E8079E75AE6D0E5DBB545C9.png?needInitFileName=true?needInitFileName=true)即可复制Client Secret。
4. 配置完成后，点击"保存"。
