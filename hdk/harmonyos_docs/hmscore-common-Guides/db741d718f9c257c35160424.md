# 版本更新说明

#### 6.8.0.300（2022-10-31）

|----------------------|
|新增特性 支持修改执行结果和日志存放的路径。|

#### 6.7.0.300（2022-10-10）

|----------------------------------------------------|
|新增特性 支持英文页面展示。 安装支持选择英文模式。 开发测试/认证测试支持品牌、型号、渠道号信息校验。|

#### 6.6.1.300（2022-09-05）

|--------------------------------|
|新增特性 开发测试支持离线模式。 新增CPU架构、屏幕密度校验。|

#### 6.6.0.300（2022-08-05）

|---------------------------------------|
|新增特性 客户端支持失败用例截图。 出端用例提供错误码。 多任务并发下载用例。|

#### 6.5.1.300（2022-06-30）

|-------------------------------------------------------------------------------|
|新增特性 开发测试中的测试类型支持二级分类。 认证测试结果展示页面支持失败重试。 支持多产品并发测试。 客户端和认证中心支持查看开源声明，支持未登录即可查看。|

#### 6.5.0.300（2022-05-30）

|--------------|
|新增特性 新增开发测试功能。|

#### 6.4.0.302（2022-04-18）

|---------------------------------------------------|
|新增特性 修复特定设备上更新程序无法拉起的问题。 新增认证测试前环境检查。 交互用例新增自动截图功能。|

#### 6.3.1.300（2022-01-25）

|------------------------|
|新增特性 新增交互测试。 支持用例版本动态更新。|

#### 6.3.0.300（2021-12-29）

|-------------------------------------|
|新增特性 HMS测试套件首个发布版本，支持HMS技术认证场景下的测试能力。|
