# 求助

* 通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/)，联系客服以获取技术支持。我们将在1到2个工作日答复您。
* 进入[开发者论坛](https://developer.huawei.com/consumer/cn/forum/)，一个开放的技术问答社区，华为专家在线解答技术问题，分享经验知识。
* 访问[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services)，提问或回答集成HMS Core遇到的问题。
* 访问[GitHub](https://github.com/HMS-Core)或[Gitee](https://gitee.com/hms-core/)，参与开源项目，为HMS Core做出贡献。
