# 推送服务

## HTS.00190000

|**错误码编号**|HTS.00190000|
|---------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertPushKit|
|**描述**|Push测试Demo申请token检查：未成功申请到token|
|**解决方法**|步骤1：请检查HMSCore是否成功安装。 1.1 若未安装则请到华为应用市场安装后重试用例。 1.2 若已安装则执行检查步骤2。 步骤2：请检查手机设备连接wifi是否正常。 2.1 若设备连接wifi不能访问网络，请解决wifi问题后重试本用例。 2.2 若设备访问网络正常，则执行步骤3。 步骤3：将用例执行结果信息和日志返回华为工程师，进行定位并修复错误。|
