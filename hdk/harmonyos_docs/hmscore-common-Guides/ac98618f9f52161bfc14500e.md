# 统一扫码服务

## HTS.00230001

|**错误码编号**|HTS.00230001|
|---------|-------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertScanKit|
|**描述**|用例执行异常检查：ScanKit脚本图片不存在|
|**解决方法**|步骤1：查看/res/drawable目录下是否有图片文件。 1.1 若有图片文件，请重跑用例可以解决。 1.2 若无图片文件，请联系华为工程师，在脚本中预置该图片文件。|
