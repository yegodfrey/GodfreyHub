# Nearby Service Wi-Fi配置分享功能下线通知

尊敬的华为开发者：

您好，近距离通信服务（Nearby Service） Wi-Fi配置分享（Wi-Fi Sharing） 功能计划2023年8月15日下线，如您的应用有集成Wi-Fi Sharing功能，需要在8月15日前完成替换。

给您带来不便请您谅解。若您有疑问及使用问题，可发送邮件至[HMSCore@huawei.com](mailto:HMSCore@huawei.com)或通过[客服支持](https://developer.huawei.com/consumer/cn/support/feedback/#/?ha_source=hms5)咨询，我们将竭诚为您服务。

下线时间表：  

|日期|计划|
|:---------|:---------------------------------------------------------|
|2023.05.20|发布下线通知。已集成应用需要尽快替换其他方案。|
|2023.06.30|停止对该功能接口的调用及编译支持，您将无法使用该功能构建新的应用，包括上架华为应用市场。|
|2023.08.15|停止就Nearby Wi-Fi Sharing提供技术支持服务，如果您的应用届时还集成了该开放能力，可能将无法使用。|
