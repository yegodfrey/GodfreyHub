# 分析服务

#### 清除应用缓存广播

ACTION：com.huawei.intent.action.PACKAGE_CACHE_CLEARED

用户清除了应用的缓存数据后，发送此系统广播。需要注意的是，被清除缓存的应用不能收到此广播。被清除缓存的应用包名通过intent对象的接口getPackage()返回。

注：此广播必须是系统广播。
