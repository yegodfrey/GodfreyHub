# FAQ

## 认证中的产品，是否可以停止认证？

可以停止认证，点击"我的认证 > 操作 > 终止认证"。"终止认证"将会终止当前的认证申请，如需继续认证，请重新提交认证申请。

## "我的认证"的"操作"栏目下"复制"用于什么场景？

当产品审核失败、产品认证失败、产品部分认证成功和已认证后，需要重新认证时，可以使用"复制"功能可将之前填写的信息直接复制。
