# FAQ

#### 为什么HTS Agent APK会安装失败？

如果安装HTS Agent apk失败，使用adb shell pm list packages命令，查看测试机上是否有HTS Agent apk历史版本未卸载，如果存在历史版本，请进行卸载。

```
adb shell pm list packages | findstr com.huawei.htsanchor.plrdtest
```

#### 如何对测试机进行预置操作，要注意什么？

为保证测试用例顺利执行，需对测试机进行如下人工预置操作（注意区分五大品类场景）。HMS测试套件在执行测试任务时会通过自动化脚本对预置条件进行检查和预置。  

#### 手机/平板类场景

由于不能保证所有合作伙伴设备的各项设置入口完全一致，此处仅以一款华为设备的操作方法为例，供用户参考。

1. 测试机连接Wi-Fi 操作方法：进入手机设置， 找到设置无线网络开关的操作入口，将无线网络开关设置为开启，并连接至网关的可用网络。若可用网络为加密网络，请输入用户名与密码并保存，保证Wi-Fi重启后该网络能自动重连。

   例如：进入"设置 \> WLAN"，将WLAN开关设置为开启，并连接至网关的可用网络。
2. 申请华为帐号 测试机配置开始前需要先申请华为帐号用于后续华为帐号相关功能的测试。登录[华为官方网站](https://id1.cloud.huawei.com/CAS/portal/userRegister/regbyphone.html)，根据界面提示完成华为帐号注册。为满足后续测试诉求，注册过程中请注意如下事项：

   * 请完成实名认证。
   * 选择所在"国家/地区"。
   * 填写出生日期时，请保证当前帐号持有者年龄达到国家法定成年要求。
   * 帐号未设置昵称。
3. 测试机设置系统语言为当前国家语言 操作方法：进入手机设置， 找到设置系统语言的操作入口，选择系统语言为当前国家语言。

   例如：进入"设置 \> 系统和更新 \> 语言和输入法 \> 语言和地区"，选择语言为当前国家语言。
4. 测试机登录华为帐号 操作方法：进入测试机设置，找到华为帐号的登录入口，输入已申请的华为帐号，完成登录。测试期间请勿在其他设备同时登录该华为帐号。

   例如：进入"设置 \> 登录华为帐号"，输入已申请的华为帐号。若"设置"中没有华为帐号登录入口，可进入"设置 \> HMS Core \> 登录华为帐号"，完成登录。
5. 测试机插入SIM卡 操作方法：测试机插入SIM卡，找到SIM卡管理界面，检查SIM卡是否被正确插入。

   例如：测试机插入SIM卡，进入"设置 \> 移动网络 \> SIM卡管理"，查看SIM卡状态是否正常。
6. 测试机校准时间 操作方法：进入测试机设置，找到时间设置入口，打开自动设置日期与时间功能。若测试机无法实现自动时间校准，可关闭自动设置，手动校准测试机时间。

   例如：进入"设置 \> 系统和更新 \> 日期和时间"，打开"自动设置"。若测试机无法实现自动时间校准，则关闭自动设置，手动校准测试机时间。
7. 关闭华为帐号的家人共享功能 操作方法：若测试过程中使用的华为帐号并非新注册的帐号，需要检查该帐号的家人共享功能是否关闭。

   例如：进入"设置 \> 帐号中心 \> 个人信息 \> 更多 \> 姓名"，在弹窗中输出一个空格并点击"确认"，若界面提示"您已加入家人共享，此姓名供家人查看，不能删除"，则表示该华为帐号已开启家人共享功能，进入"设置 \> 帐号中心 \> 家人共享"，进入家庭成员中管理员的设置界面，点击"停止共享"即可。
8. 测试机未处于静音状态 操作方法：检查测试机媒体音量状态，保证其未处于静音状态。

9. 为应用HMS Core授予权限 操作方法：进入测试机设置，找到应用HMS Core的权限设置界面，为HMS Core授予所有权限，通常包括如下权限：存储、电话、位置信息、相机、通讯录、信息、日历、健身运动。

   例如：进入"设置 \> 应用 \> 权限管理"，点击"HMS Core"，点击"查看所有权限"，将界面显示的所有权限设置为"允许"。
10. 检查"推送服务"版本 操作方法：进入应用市场搜索"推送服务"，如果能够搜索到该应用并可更新，将其升级至11.1.6及其以上版本；如果搜索不到或者显示需要安装，则说明该设备默认不支持"推送服务"，无需处理。

11. 测试机连接蓝牙 操作方法：进入测试机设置， 找到设置蓝牙开关的操作入口，将蓝牙开关设置为开启。例如：进入"设置 \> 蓝牙"，将蓝牙开关设置为开启。如设备无蓝牙功能，请忽略。

12. 测试机关闭移动网络 操作方法：进入测试机设置，找到移动网络开关，将移动网络关闭。

13. 测试机设置不息屏 操作方法：进入测试机设置，找到自动休眠时间的设置入口，将自动休眠时间设置为"永不"。若休眠时间选项中无"永不"可选，则选中选项中的最大值。

14. 打开HMS Core更新开关 操作方法：进入测试机设置，找到应用HMS Core应用管理，打开HMS Core设置页面，点击"自动更新"，打开WLAN闲时自动更新开关。

15. 测试机打开GPS定位 操作方法：进入测试机设置，找到GPS定位，打开定位开关。
