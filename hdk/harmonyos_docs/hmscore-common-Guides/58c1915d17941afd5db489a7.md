# 使用Toolkit添加HMS Core

HMS Toolkit是一个IDE工具插件，可以帮助开发者以更低的开发成本、更高的开发效率集成HMS Core服务，打造出色的应用。

借助HMS Toolkit工具提升3倍以上集成开发效率，基于Android Studio增强HMS Core集成场景，提供全流程、一站式支持接入HMS Core工具链。提供了包括应用创建、编码和转换、功能调测和测试、版本发布等8个端到端开发工具。

支持的场景有如下两种：

* 场景一：开发者目前已经开发了一个Android应用，集成和使用了GMS（Google Mobile Services）服务，想要快速迁移使用HMS Core服务和上线华为应用市场。

* 场景二：开发者准备开发一个新应用，想快速集成华为HMS Core服务和上线华为应用市场。
