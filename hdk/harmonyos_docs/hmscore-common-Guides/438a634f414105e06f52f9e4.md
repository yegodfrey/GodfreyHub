# 游戏服务

## HTS.00110000

|**错误码编号**|HTS.00110000|
|---------|-----------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertGameService|
|**描述**|已登录帐号的检查：未使用已实名成年人的华为帐号|
|**解决方法**|步骤1：请打开GameTest的apk后，点击登录，会拉起实名认证界面，请使用真实的成人身份证进行实名。 1.1实名成功，可登录游戏。 1.2实名失败，请先根据错误提示解决实名问题，如果无法解决，请将结果返回给华为工程师定位。|

## HTS.00110001

|**错误码编号**|HTS.00110001|
|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertGameService|
|**描述**|未成功登录demo|
|**解决方法**|步骤1：请查看失败截图是否有特殊弹框，若有请处理下弹框再执行套件 1.1 若拉起登录页面，则请先登录华为实名账号，再执行套件。 1.2 有特殊弹框挡住了DEMO的主界面，手工处理掉特殊弹框，保障弹框不再展示，重新执行用例。 1.3无特殊弹框，检查DEMO是否安装成功，是否能够成功打开。 1.4若不是以上情况，但脚本执行失败，将结果信息返回华为工程师定位。|

## HTS.00110002

|**错误码编号**|HTS.00110002|
|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertGameService|
|**描述**|前台登录的检查：前台登录失败，未打印success|
|**解决方法**|步骤1：请查看页面是不是有弹框，若有请处理后再执行。 1.1 有弹框挡住了DEMO的主界面，手工处理掉特殊弹框，保障弹框不再展示，重新执行用例。 1.2 无弹框，DEMO的控制台上打印了2002、7002、2012、7400等错误码，检查当前登录账号是否是现网华为账号（不是的话，切换华为实名账号），检查手机网络连接是否正常（不正常，调试好网络再执行套件）。 1.3若不是以上情况，但脚本执行失败，将结果信息返回华为工程师定位。|

## HTS.00110003

|**错误码编号**|HTS.00110003|
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**所属模块**|HtsHmsCertGameService|
|**描述**|玩家信息的检查：获取当前玩家信息XX失败|
|**解决方法**|步骤1：请查看demo的控制台是不是打印了7002、若是则是服务器暂时不稳定，再次执行基本可解决。 1.1 DEMO控制台上打印了7002，检查手机网络连接，连接正常后，再次执行套件。 1.2 再次执行套件失败，且网络连接正常，返回码仍为7002，请将结果信息返回华为工程师定位。 步骤2：请查看demo的控制台是不是打印了7013，则是demo未登录成功，再次执行可解决。 2.1打印了7013，检查设备是否已成功登录华为账号，登录成功后，重新执行套件。 2.2再次执行套件失败，华为账号是登录状态，返回码仍为7013，请将结果信息返回华为工程师定位。 步骤3：请查看demo的控制台是不是打印了7018，则是初始化未成功，再次执行可解决 3.1打印了7018，重新执行套件。 3.2 再次执行套件失败，或控制台上不是7002，7013，7018，将结果信息返回华为工程师定位。|
