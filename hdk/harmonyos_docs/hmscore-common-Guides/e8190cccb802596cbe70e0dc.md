# Push服务

HMS Core提供了Push推送服务，App可以接入HMS Core Push服务，接受推送消息。当设备收到推送消息时，HMS Core Push会将推送消息传递个目标App，由目标App处理Push消息，通常目标App会创建通知栏消息向用户展示。因此，每次设备收到发给不同App的Push推送消息，目标App都需要被拉起，并对Push推送消息做处理，从而导致设备整体功耗的增加。因此，HMS Core Push服务提供了统一的通知中心服务（HMS Core Notification Center），代替目标App处理Push推送消息，创建通知栏消息向用户展示Push推送消息，避免各目标App被拉起，从而降低设备整体的功耗。为达到上述效果，合作伙伴需要对AOSP做一定的修改，不同AOSP版本修改点会有所不同，具体修改点和修改方式见如下描述。

HSF替应用创建通知栏的修改点  

|AOSP版本|10及以上|
|修改文件|frameworks/base/services/core/java/com/android/server/notification/NotificationManagerService.java|
|修改函数|int resolveNotificationUid(String callingPkg, String targetPkg, int callingUid, int userId)|
|新增函数|private boolean isCallerHsf(String callingPkg, int uid, int userId)|
|------|--------------------------------------------------------------------------------------------------|

修改函数（加粗语句为修改部分）：

```
 @VisibleForTesting
 int resolveNotificationUid(String callingPkg, String targetPkg, int callingUid, int userId) {
     if (userId == UserHandle.USER_ALL) {
            userId = USER_SYSTEM;
     }
     // posted from app A on behalf of app A
     if (isCallerSameApp(targetPkg, callingUid, userId)
            && (TextUtils.equals(callingPkg, targetPkg)
            || isCallerSameApp(callingPkg, callingUid, userId))) {
         return callingUid;
     }

     int targetUid = INVALID_UID;
     try {
          targetUid = mPackageManagerClient.getPackageUidAsUser(targetPkg, userId);
     } catch (NameNotFoundException e) {
         /* ignore, handled by caller */
     }
     // posted from app A on behalf of app B
     if (isCallerAndroid(callingPkg, callingUid)
            || mPreferencesHelper.isDelegateAllowed(
                  targetPkg, targetUid, callingPkg, callingUid)
            || isCallerHsf(callingPkg, callingUid, userId)) {
         return targetUid;
      }

      throw new SecurityException("Caller " + callingPkg + ":" + callingUid
             + " cannot post for pkg " + targetPkg + " in user " + userId);
  }
```

新增函数：

```
private boolean isCallerHsf(String callingPkg, int callingUid, int userId) {
    if(!isCallingUidSystem() || !isCallerSameApp(callingPkg, callingUid, userId)) {
         return false;
    }

    Intent hsfIntent = new Intent("com.oem.android.hsf.service.CoreService").setPackage(callingPkg);
    return mPackageManagerClient.queryIntentServices(hsfIntent, PackageManager.GET_META_DATA).size() != 0;
}
```
