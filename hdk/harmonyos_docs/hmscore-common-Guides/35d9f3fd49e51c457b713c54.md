# 华为接触卫士（HMS Core Contact Shield）中国区下线通知

尊敬的华为开发者：

您好，华为接触卫士（HMS Core Contact Shield）计划在2023年3月15日在中国区下线相关功能。

给您带来不便请您谅解。若您有疑问及使用问题，可发送邮件至[HMSCore@huawei.com](mailto:HMSCore@huawei.com)或通过[客服支持](https://developer.huawei.com/consumer/cn/support/feedback/#/?ha_source=hms5)咨询，我们将竭诚为您服务。

下架时间表：  

|日期|计划|
|:---------|:------------------------------------------------------------------------------|
|2023.03.06|发布下线通知。已集成应用可以继续使用。|
|2023.03.15|下架HMS Core Contact Shield的SDK及资料，停止对该开放能力的下载及编译支持，您将无法使用该开放能力构建新的应用，包括上架华为应用市场。|
|2023.04.15|停止就HMS Core Contact Shield提供技术支持服务，如果您的应用届时还集成了该开放能力，可能将无法使用。|
