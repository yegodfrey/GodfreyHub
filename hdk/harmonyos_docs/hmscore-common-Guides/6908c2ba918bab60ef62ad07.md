# 添加权限

开发者需要在config.json文件中的"reqPermissions"字段中声明所需要的权限。详情参见[权限开发指导](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/security-permissions-guidelines-0000000000029886)。

```
{
    "module": {
           "reqPermissions": [
            {
                "name": "ohos.permission.INTERNET",
                "reason": "access internet",
                "usedScene": {
                    "ability": [
                        "com.mycamera.MainAbility"
                    ],
                    "when": "always"
                }
            }
        ]
    }
}
```
