# 定位服务

#### HTS.00150000

|错误码编号|HTS.00150000|
|所属模块|HtsHmsCertLocationKit|
|描述|设备不支持网络定位，或由于网络信号不稳定，导致结果未返回|
|解决方法|步骤1：请确认该设备是否支持网络定位。 1.1若不支持网络定位，则LocationKit无法提供服务，为非问题。 1.2若确认支持网络定位，请参考步骤2。 步骤2：请检查设备网络信号是否正常。 2.1若信号不稳定，请确认信号稳定后重试。 2.2若信号正常，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00150001

|错误码编号|HTS.00150001|
|所属模块|HtsHmsCertLocationKit|
|描述|获取围栏信息失败|
|解决方法|步骤1：请检查设备的GPS信号。 1.1若信号不稳定，则LocationKit服务无法触发硬围栏，为非问题。请将设备移动到信号好的位置，或在网络闲时进行重试。 1.2若确认网络信号正常，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|----------------------------------------------------------------------------------------------------------------------------|
