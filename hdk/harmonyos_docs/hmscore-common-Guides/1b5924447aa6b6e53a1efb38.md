# 安全检测服务

#### HTS.00220000

|错误码编号|HTS.00220000|
|所属模块|HtsHmsCertSafetyDetectKitApiTest|
|描述|设备环境检测：设备未成功唤醒并解锁|
|解决方法|步骤1：检查设备是否处于唤醒状态。 1.1 若设备为未唤醒状态，进入系统设置-开发者选项，保持设备为唤醒状态。 1.2 若设备已为唤醒状态，执行步骤2。 步骤2：检查设备是否有锁屏码。 2.1 若存在锁屏码，手动移除设备锁屏码。 2.2 若不存在锁屏码，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
