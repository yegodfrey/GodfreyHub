# 卸载HMS测试套件

1. 在电脑端打开"开始"，找到"HTS"，右键点击"卸载"。
2. 弹出解除安装的弹框，点击"下一步"。

3. 点击"解除安装"，完成HMS测试套件卸载，如不需要保留用户数据，请勾选"用户数据"。
