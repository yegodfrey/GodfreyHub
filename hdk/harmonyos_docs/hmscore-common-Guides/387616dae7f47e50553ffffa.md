# 使用HMS测试套件进行开发测试

安装HMS测试套件后进行开发测试。

1. 打开HMS测试套件，用华为帐号登录。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.59055956521521529506926118603136:50531115012105:2800:0080F71DC593FD20ADAF34BA95A0470F278F9A9F2855F08BD953FEDADA6A8DDB.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   >
   > 企业帐号注册及实名认证：
   > * 注册企业帐号 ：注册华为帐号，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
   > * 实名认证：具体方法请参见[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)。
2. 帐号首次登录，需要签署HMS测试套件服务协议。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.92672390453075381482655964681154:50531115012105:2800:9D8E4EDE79969AA90A54BD86ABABB7E3816922CE08544A1F1921CEC3FCD13146.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 登录成功后，点击"开发测试"，在页面上方搜索框找到所需要进行开发测试的产品名称或型号。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.05779478075384995985379255938882:50531115012105:2800:BA1158E835E34611D94476354718FAB1E5911CCD920C6969D7FF25014A6831AA.png?needInitFileName=true?needInitFileName=true "点击放大")
4. PC连接所需被测设备，系统识别设备信息后，选择所需测试设备和测试类型，点击"创建测试任务"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.14011519504053839499847390060047:50531115012105:2800:AF5B7B5483CF9C8038AAAD3BA465ACE73902648B025F61CC6FE5103DB15C9294.png?needInitFileName=true?needInitFileName=true "点击放大")

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.11816558794503685831191404663675:50531115012105:2800:F33F290975F6C8F2CD72D3A7E6A6EA7FF3DC59EA0AE872C53C0177833E82C3A6.png?needInitFileName=true?needInitFileName=true "点击放大")
5. 页面进入环境检查阶段。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.96178954578217278973693336982522:50531115012105:2800:992C83455094FDF874BAF615D033200D751A7A23766D4E00FC688C97D086983B.png?needInitFileName=true?needInitFileName=true "点击放大")
6. 确保环境检查无误后，点击"开始测试"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.62874863100229465761125870143162:50531115012105:2800:8A9317D8E215D34D7FAC06FE72FAF3A86711029636C637635D72D66CC726EDD1.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   >
   > 失败环境检查项可以点击跳过。
7. 开发测试执行完成后，可以查看测试结果，支持失败重执行和导出测试结果。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.12228617465438817990995259969783:50531115012105:2800:DBC3C7AE0DA7482745ABA960A7BE23E3FDFE88920392CD1436431899D87C0CDB.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   >
   > 未通过重执行的设备不支持更换。
8. 可以点击产品查看对应开发测试的结果，可对其进行"查看"或"删除"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191607.39834188695320856092278541032278:50531115012105:2800:3993D3BA84BB0BB3844E03096E55551E47611EED2B87CEE7E9720BB5A4CEA951.png?needInitFileName=true?needInitFileName=true "点击放大")
