# Hquic服务

#### HTS.00130000

|错误码编号|HTS.00130000|
|所属模块|HtsHmsCertHquicKit|
|描述|请求Response响应项检查：等待UrlRequest.Callback回调结果超时|
|解决方法|步骤1：请检查网络是否连接，连接的网络信号是否稳定。 1.1 若网络未连接，请连接网络，若连接的网络信号不稳定，请维护网络环境或连接信号稳定的网络。 1.2 若网络已连接且网络信号稳定，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
