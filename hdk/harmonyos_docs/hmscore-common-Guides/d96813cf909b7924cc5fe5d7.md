# 动态标签管理

#### HTS.00090000

|错误码编号|HTS.00090000|
|所属模块|HtsHmsCertDRMKit|
|描述|设备ro.product.manufacturer 属性获取出现错误|
|解决方法|步骤1：可以使用adb shell getprop ro.product.manufacturer命令查询设备厂商信息是否能够获取正常。 1.1 若返回为空，属于设备自身问题，请厂商自行确认该属性是否存在。 1.2 若返回值在厂商白名单内，打印current system in trust list，脚本仍失败，将结果信息返回华为工程师，进行定位并修复错误。 1.3 若返回值不在厂商白名单内，打印current system not in trust list，脚本仍失败，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00100400

|错误码编号|HTS.00100400|
|所属模块|HtsHmsCertDTMKitDevice|
|描述|日志中未查找到预期结果|
|解决方法|步骤1：检查是否能正常获取到设备打印的日志。 1.1 若能正常获取到设备打印的日志，参考步骤2。 1.2 若未能正常获取到设备打印的日志，请厂商打开获取设备打印日志权限。 步骤2：检查设备是否获取到配置，日志中查找config version:3。 2.1 若未能查找到，检查设备网络连接是否正常，是否无法访问AGC现网。 2.2 若能查找到，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
