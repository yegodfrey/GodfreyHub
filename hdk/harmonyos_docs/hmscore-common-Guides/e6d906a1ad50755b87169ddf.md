#### HTS.00280005

|错误码编号|HTS.00280005|
|所属模块|HtsHmsCertAccountTv|
|描述|安装包错误|
|解决方法|步骤1：执行命令：adb shell pm dump com.huawei.hwid.tv \| findstr version，检查返回值是否为空。 1.1 如果返回值为空，则未安装正确的apk，请安装com.huawei.hwid.tv测试包测试。 1.2 如果返回值不为空，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
