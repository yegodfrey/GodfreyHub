# 准备开发环境

* 推荐安装最新版本的Android Studio。要求最低兼容版本：API 17、Android 4.2。 Android Studio的安装和环境配置的具体操作，请参见[iLearning教程](https://developer.huaweiuniversity.com/courses/course-v1:HuaweiX+CBGHWDCN095+Self-paced/courseware/30a2399f74d64485a4c14986eaf4be05/1f043e9b72a34e2aa153ed9aa09182c5/)。

* 访问AGC管理页面时推荐使用谷歌浏览器。如果使用win10系统的火狐浏览器，可能出现请求被浏览器拦截，导致点击下载无响应。处理方法：
  1. 在火狐浏览器地址栏输入"about:config"。
  2. 查找"security.csp.enable"，将其切换为"false"。
* 准备一台用于测试的Android设备或者模拟器。
