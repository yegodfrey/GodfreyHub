# 华为应用内支付服务

#### HTS.00140001

|错误码编号|HTS.00140001|
|所属模块|HtsHmsCertIAPKit|
|描述|HMS Core页面信息不正确|
|解决方法|步骤1：检查是否能正常获取到设备打印的日志。 1.1 若能正常获取到设备打印的日志，参考步骤2。 1.2 若未能正常获取到设备打印的日志，请厂商打开获取设备打印日志权限。 步骤2：请根据日志检查当前是否已经进入到预期页面。 2.1 如果未进入预期页面，请检查进入预期页面前的操作是否有效，比如控件点击，页面跳转等。 2.2 若已经进入到预期页面，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00140002

|错误码编号|HTS.00140002|
|所属模块|HtsHmsCertIAPKit|
|描述|HMS Core 华为支付协议内容不正确|
|解决方法|步骤1：检查是否能正常获取到设备打印的日志。 1.1 若能正常获取到设备打印的日志，参考步骤2。 1.2 若未能正常获取到设备打印的日志，请厂商打开获取设备打印日志权限。 步骤2：请根据日志检查华为支付协议内容是否一致。 2.1 若不一致，请确认协议内容是否发生变更，用例检查内容是否正确。 2.2 协议内容一致，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### HTS.00140003

|错误码编号|HTS.00140003|
|所属模块|HtsHmsCertIAPKit|
|描述|HMS Core华为帐号未登录|
|解决方法|步骤1：请确认设备是否已登录华为帐号。 1.1 若未登录，请先登录华为帐号。 1.2 若已经登录华为帐号，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|----------------------------------------------------------------------------|

#### HTS.00140004

|错误码编号|HTS.00140004|
|所属模块|HtsHmsCertIAPKit|
|描述|HMS Core新增我的地址保存失败|
|解决方法|步骤1：检查是否能正常获取到设备打印的日志。 1.1 若能正常获取到设备打印的日志，参考步骤2。 1.2 若未能正常获取到设备打印的日志，请厂商打开获取设备打印日志权限。 步骤2：请检查新增我的地址时，各项输入是否符合要求。 2.1 若我的地址各项信息输入若不符合，请输入正确的地址信息。 2.2 若各项输入皆符合要求，请检查是否点击保存正常。 2.3 若以上步骤皆正常，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
