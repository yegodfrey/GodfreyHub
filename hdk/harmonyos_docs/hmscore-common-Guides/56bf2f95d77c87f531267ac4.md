# 介绍

Android O版本开始，系统设置菜单支持动态菜单注入技术，允许系统应用在系统设置页面中动态注入菜单项。HMS Core是预置的系统应用，因此采用动态菜单注入技术实现在系统设置首页注入"HMS Core"和"华为帐号"菜单。

通常设备厂商会对系统设置首页显示的菜单项有比较严格的限制，通过代码或者白名单配置文件的方式控制系统设置首页显示哪些菜单，以及每个菜单的位置，因此导致Android的动态菜单注入技术失效。

本章节要求预置HMS Core的合作伙伴，在系统设置首页显示"HMS Core"和"华为帐号"的菜单项。
