# 设备品类定义

HMS Core对不同品类设备提供不同的解决方案，因此，设备需要确定归属哪个品类，并且正确声明设备的品类（Feature）。除手机/平板品类外，其他品类的设备，必须按照下表中的描述，声明Feature。  

|品类|特点说明|Feature|
|:----|:-----------------------------------------------------|:-------------------------------|
|手机/平板|手持使用、触屏操作，屏幕尺寸介于4到18英寸之间，近距离观看，支持安装各种丰富的三方应用。|NA|
|大屏|遥控器操作，屏幕尺寸大和特大（或包含视频输出端口），适合远距离观看，支持安装各种丰富的三方应用。|android.software.leanback|
|穿戴|穿戴在身上（主要是手腕，如手表），屏幕尺寸通常不超过2英寸，支持触屏；支持安装应用。|android.hardware.type.watch|
|车机|放置于汽车中控屏位置的设备，触屏操作，近距离观看，支持安装应用。鉴于行车安全原因，界面显示有比较严格的限制。|android.hardware.type.automotive|
