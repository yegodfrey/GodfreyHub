# 3D建模服务

#### HTS.00470001

|错误码编号|HTS.00470001|
|所属模块|HtsHmsCert3DModelingKit|
|描述|普通模式初始化失败|
|解决方法|步骤1：请检查手机本地这个路径下/data/data/com.android.customlistview/cache/3DMagic是否存放'test'测试集。 1.1若文件未放置，请按照预装规范将文件放置在指定目录下。 1.2若文件已放置，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。 步骤2：请检查安卓9及以上手机是否有网络。 2.1若手机无网络，请检查设备，保持网络畅通。 2.2若网络正常，但脚本执行失败，将结果信息返回华为工程师，进行定位并修复错误。|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
