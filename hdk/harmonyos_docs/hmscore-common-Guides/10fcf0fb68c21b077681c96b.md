# 华为帐号服务（车机）

#### HTS.00440000

|错误码编号|HTS.00440000|
|所属模块|HtsHmsCertAccountCar|
|描述|HMS Core华为帐号未登录|
|解决方法|步骤1：请确认设备是否已登录华为帐号。如果未登录，请先登录华为帐号。 步骤2：如果已经登录华为帐号，则转由华为工程师定位问题原因。|
|-----|-----------------------------------------------------------------|

#### HTS.00440001

|错误码编号|HTS.00440001|
|所属模块|HtsHmsCertAccountCar|
|描述|控件检查失败|
|解决方法|步骤1：请进入华为帐号-\>帐号中心，检查是否有异常提示框弹出，若有请手动点击同意或根据提示手动排查。 步骤2：如果进入帐号中心无异常提示框弹出，则转由华为工程师定位问题原因。|
|-----|----------------------------------------------------------------------------------------|

#### HTS.00440002

|错误码编号|HTS.00440002|
|所属模块|HtsHmsCertAccountCar|
|描述|测试demo未安装|
|解决方法|步骤1：请检查应用界面是否安装有hwidDemo，若无请安装demo后测试。 步骤2：如果安装有hwidDemo，则转由华为工程师定位问题原因。|
|-----|------------------------------------------------------------------------|

#### HTS.00440003

|错误码编号|HTS.00440003|
|所属模块|HtsHmsCertAccountCar|
|描述|测试设备语言未设置为简体中文|
|解决方法|步骤1：请检查系统语言设置，如未设置成简体中文，请设置成简体中文后测试。 步骤2：如果当前语言设置为简体中文，则转由华为工程师定位问题原因。|
|-----|----------------------------------------------------------------------|

#### HTS.00440004

|错误码编号|HTS.00440004|
|所属模块|HtsHmsCertAccountCar|
|描述|SDK返回值错误|
|解决方法|步骤1：请进入华为帐号-\>帐号中心，检查是否有异常提示框弹出（无法连接服务器或者网络连接异常），若有根据提示检查网络设置。 步骤2：如果进入帐号中心无异常提示框弹出，则转由华为工程师定位问题原因。|
|-----|---------------------------------------------------------------------------------------------------|

#### HTS.00440005

|错误码编号|HTS.00440005|
|所属模块|HtsHmsCertAccountCar|
|描述|安装包错误|
|解决方法|步骤1：执行命令：adb shell pm dump com.huawei.hwid.tv \| findstr version，检查返回值是否为空，若为空则未安装正确的apk。 步骤2：如果返回值不为空，则转由华为工程师定位问题原因。|
|-----|----------------------------------------------------------------------------------------------------------------------|

#### HTS.00440006

|错误码编号|HTS.00440006|
|所属模块|HtsHmsCertAccountCar|
|描述|网络不可用|
|解决方法|步骤1：请检查其他应用网络是否可用。 步骤2：如果其他应用网络可用，则转由华为工程师定位问题原因。|
|-----|-------------------------------------------------|
