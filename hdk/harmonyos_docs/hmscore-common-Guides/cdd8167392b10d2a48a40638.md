# 设置

#### 版本更新操作

自动更新：客户端打开时会对客户端版本进行检查，如非最新版本，软件会提示用户更新到最新版本。  

#### 查看开源代码许可、隐私声明和用户协议

打开HMS测试套件，点击"设置"，在"关于"页面下，可查看开源代码许可、隐私声明和用户协议。
