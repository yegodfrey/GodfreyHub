# 流程

您可以使用Java或者JavaScript语言开发HarmonyOS应用。Kit提供了一种或两种语言的SDK包，请根据Kit提供的SDK包选择开发应用的语言。  

#### 操作流程

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------|
|1|[准备开发环境](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/harmony-dev-environment-0000001212784053)|在开发应用前，需要先进行HUAWEI DevEco Studio安装及配置。|
|2|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/harmony-config-agc-0000001167504160)|在开发应用前，需要在AppGallery Connect中创建项目、创建应用、打开相关服务。|
|3|[配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/harmony-signature-info-0000001167185654)|创建应用程序的签名证书，使用命令行生成签名证书指纹，并在AppGallery Connect上配置签名证书指纹。|
|4|* [集成HMS Core SDK（JavaScript）](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/js-integrate-sdk-0000001212585593) * [集成HMS Core SDK（Java）](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/java-integrate-sdk-0000001167025696)|在应用级"build.gradle"文件中添加agcp插件和HMS Core SDK的编译依赖，并同步您的应用以确保所有依赖项都具有所需的版本。|
|5|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/harmony-obfuscation-script-0000001212265541)|您编译HAP前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|6|[添加权限](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/harmony-add-permissions-0000001212664113)|在"config.json"文件中配置应用所需权限，并根据需要在代码中动态申请权限。|

#### 后续操作

完成开发准备任务后，你可以参见各服务的文档，继续将HMS Core服务添加到您的应用，并上架应用市场。
