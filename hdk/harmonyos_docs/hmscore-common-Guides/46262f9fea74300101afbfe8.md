# 手机/平板品类

## HMS Core菜单项

"HMS Core"菜单项要求出现在系统设置的首页，位置要求在"用户和帐户"之后，如下图所示：

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191613.81288782269498407558942931949172:50531115012105:2800:6B3FF320FFF6C73A077C3AC0E31D06726B20F456C08E4C27914621C6883474AC.png?needInitFileName=true?needInitFileName=true)

以下AndroidManifest.xml清单中的组件配置，描述了"HMS Core"菜单项的注入信息。

```screen
<activity-alias
   android:name="com.huawei.hms.fwksdk.stub.HmsSettingActivity.Alias" 
   android:permission="com.huawei.permission.external_app_settings.USE_COMPONENT" 
   android:enabled="false"
   android:exported="true" 
   android:excludeFromRecents="true"
   android:launchMode="1"
   android:configChanges="0x40002fff" 
   android:targetActivity="com.huawei.hms.fwksdk.stub.HmsSettingActivity"> 
    <meta-data
        android:name="com.android.settings.Tile_Identifier" //HMS Core菜单标识
        android:value="com.huawei.hms.fwksdk.s tub.HmsSettingActivity.Alias" /> 
    <intent-filter android:priority="116">
<action android:name="com.android.settings.action.EXTRA_SETTINGS" />
<category android:name="android.intent.category.DEFAULT" />
</intent-filter>
<meta-data
android:name="com.android.settings.category"
android:value="com.android.settings.category.ia.homepage" />
<meta-data
android:name="com.android.settings.title" //静态标题
android:resource="@ref/0x7f0b05b1" />
<meta-data
android:name="com.android.settings.icon" //静态图标
android:resource="@ref/0x7f0807ed" />
<meta-data
android:name="com.android.settings.summary" //静态摘要
android:resource="@ref/0x7f0b0203" />
</activity-alias>
```

## 华为帐号菜单项

"华为帐号"菜单要求在系统设置菜单的第一个位置，华为帐号的菜单项图标、标题、摘要都是动态内容。当登录华为帐号后，此菜单项的图标显示帐号的头像，标题显示帐号的昵称，如下图所示：

**图1**未登录的菜单显示   
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191613.83262002423062789481002081471584:50531115012105:2800:581359D23DD45B158DB3388DF78B9D2654601ECADB2A6959F69F073B3401F313.png?needInitFileName=true?needInitFileName=true)

**图2**已登录的菜单显示   
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221115191613.91967763839856858395935918740914:50531115012105:2800:F73C8E80A8E48EA34AEDE0618BF35579C935EB00F8C892F5B09FD8D373FF19CB.png?needInitFileName=true?needInitFileName=true)

以下AndroidManifest.xml清单中的组件配置，描述了"华为帐号"菜单项的注入信息。

```screen
<activity
     android:theme="@ref/0x7f1302db"
     android:name=".cloudsettings.ui.HuaweiIDForSettingsActivity"
     android:exported="false"
     android:configChanges="0x2d87">
     <intent-filter>
         <action android:name="com.android.settings.action.IA_SETTINGS" />
         <category android:name="android.intent.category.DEFAULT" />
     </intent-filter>
     <meta-data
         android:name="hw_meta_tile_type" //华为帐号菜单标识
         android:value="hwid_tile" />
     <meta-data
         android:name="com.android.settings.category"
         android:value="com.android.settings.category.ia.homepage" />
     <meta-data
         android:name="com.android.settings.icon"  //静态图标
         android:resource="@ref/0x7f08049e" />
     <meta-data
         android:name="com.android.settings.title"  //静态标题
         android:resource="@ref/0x7f0b0013" />
     <meta-data
         android:name="com.android.settings.summary"  //静态摘要
         android:resource="@ref/0x7f0b0014" />
     <meta-data
         android:name="com.android.settings.icon_uri"  //动态图标
         android:value="content://com.huawei.hwid.settings.provider/icon" />
     <meta-data
         android:name="com.android.settings.title_uri"  //动态标题
         android:value="content://com.huawei.hwid.settings.provider/title" />
     <meta-data
         android:name="com.android.settings.summary_uri" //动态摘要
         android:value="content://com.huawei.hwid.settings.provider/summary" />
     <meta-data
         android:name="com.android.settings.badge_uri"  //动态红点
         android:value="content://com.huawei.hwid.settings.provider/badge" />
 </activity>
```
