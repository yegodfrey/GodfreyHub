# 设备唯一标识符

用于设备激活数统计以及帐号、IAP等敏感业务的风险控制，需要提供一个固定不变且唯一的设备标识符（包括恢复出厂设置也不会发生变化），仅允许华为预置应用读取。实现建议：

1. 对已有的唯一硬件标识进行SHA256计算得出，如SN、IMEI、CPU序列号等。
2. 出厂时生成一个唯一的字符串（64位的16进制字符串）并预置在设备中。

|类名|com.huawei.android.os.BuildEx|
|----|-------------------------------------|
|方法|String getUDID()|
|访问权限|com.huawei.permission.sec.ACCESS_UDID|
|保护级别|signature|privileged|

|参数||
|:-|--|
|无|无。|

|返回||
|:-----|----------------------------|
|String|返回64位长的16进制字符串，如发生异常则返回空字符串。|

为确保HMS App正常运行，com.huawei.android.os.BuildEx类中需要补充以下成员：

|类名|com.huawei.android.os.BuildEx|
|--|---------------------------------------------|
|成员|public static final String EMUI_VERSION = "";|

|类名|public com.huawei.android.os.BuildEx.VERSION|
|--|---------------------------------------------------------------------------------------|
|接口|BuildEx.VERSION()|
|成员|public static final int EMUI_SDK_INT = 0; public static final int EMUI_SUB_SDK_INT = 0;|
