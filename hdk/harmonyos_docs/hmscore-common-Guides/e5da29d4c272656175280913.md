# 认证介绍

[HMS认证中心](https://hts.huawei.com/)是面向生态伙伴（以下简称"伙伴"）的一站式认证测试服务平台。提供集成HMS相关能力后的兼容性验证服务，保障所认证的产品可以更好地为用户服务。  

#### 认证背景

HMS合作厂家下载预置产品包，将预置产品包集成到系统中，完成预装集成开发。  

#### 认证前提

认证前请进行产品包下载，联系商务拓展专家签署[商务合作协议](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/cert-guide-0000001221678147#section419035372811)，同时完成开发流程包括帐号申请、申请合作、下载产品包、预装集成开发、填写产品信息和[自测试](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/test-0000001306275885)，自测试问题全部解决后，满足认证条件提交认证申请，进行认证测试。

#### 认证流程

本节介绍如何开展产品认证，包含企业帐号注册及实名认证、签署协议、创建认证产品、创建认证申请、执行测试用例、提交认证申请、认证审核、认证通过，共八个环节。通过认证之后，即可获得对应产品的认证报告。
