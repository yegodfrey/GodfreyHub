# 搜索问题

此页面显示了如何**搜索问题** ，搜索结果仅限于您具有**“创建、查看和评论问题”** 的组件中的**问题** 。

如何使用搜索栏进行搜索？

     1. 在网络浏览器中打开[IR工单](https://developer.huawei.com/consumer/cn/support/issues/my-created)
     2. 在搜索栏中键入查询，运行搜索，搜索栏始终显示在问题跟踪器的顶部。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250819092602.58519793837596997694851428732192:50001231000000:2800:04C9D67455C611D0896F7D684D0DD4DF9622D065C9E9A2C826B54B21901188ED.png)

     3. 在搜索框右侧的下拉列表中为搜索添加条件，同时可以输入搜索历史名称并保存搜索历史。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250819092602.58105864697944034400106960540053:50001231000000:2800:2620160586308747B6B6A5BDAC4459AA1665D2EFA71DE20D0DF425896A2DF02E.png)

     4. 在菜单的搜索历史中可查看保存的所有搜索记录。
