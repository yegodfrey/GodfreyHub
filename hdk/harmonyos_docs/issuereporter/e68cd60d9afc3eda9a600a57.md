# 关于IR工单

IR工单是华为面向HarmonyOS、硬件等生态产品的开发者、合作伙伴提供的统一问题跟踪处理平台，可在产品开发过程中跟踪bug、漏洞和功能需求，实时跟踪反馈进展，提升华为生态服务体验。IR工单不是通用的问题跟踪平台，且不作为外部消费者的产品问题跟踪。一般情况下您不能使用此工具来提交有关华为终端产品的反馈。

**目标用户：**

该IR工单适用于两组用户：

公共用户：个人开发者，可使用IR工单对开发过程中遇到的问题进行提问跟踪，但仅可提交系统中可见的项目或组件的相关问题。

合作伙伴用户：与华为合作的企业开发者，可使用IR工单对项目中的问题进行跟踪。

以上两类用户均需注册华为账号进行登录。

IR工单具有访问控制权限，该权限控制哪些用户可以在项目中**创建** 、**查看和评论问题** 。这些权限由华为根据每个项目指定，仅华为员工可以在IR工单平台中添加项目或设置访问权限。
