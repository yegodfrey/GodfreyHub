# 创建问题

您必须对要在其中**创建问题** 的组件享有**“创建、查看和评论问题”** 的权限，您在创建问题时只能设置问题标题和描述，以及对该组件下的问题进行评论。

如何创建问题：

     1. 在网络浏览器中打开[IR工单](https://developer.huawei.com/consumer/cn/support/issues/my-created)。
     2. 首先进入IR工单页面，点击页面左侧的**新建问题** 。
     3. 在**问题分类** 中使用下拉列表查找要在其中创建问题的组件。您只能在拥有**“创建、查看和评论问题”** 权限的那些组件中查找。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250819092602.92399958344218459780137070150211:50001231000000:2800:9E343C0B56C497756EB92611FDFFE36FC1F73E0F41F487C73EE4B27331710C27.png)

     4. 在标题字段中输入**标题** 。
     5. 选择最适合您要报告的问题的**模板** ，不同组件的可选模板可能会不同。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250819092602.84258627943272899303173526207071:50001231000000:2800:BA28D3134F7DDBC05F956F2F33C4D4B671B5EC47EBCF96ACABB75618A235519B.png)

     6. 在**描述** 字段中输入问题的具体信息。
     7. （可选）为您提的问题**指定处理人** ，如不指定系统将为该问题自动指定处理人员。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250819092602.69635927398469113594821370770449:50001231000000:2800:190B95E60C2FB7E66B390C25CAA507380B316DE3EBD52B04816C9989F6B98F5D.png)

     8. 输入该问题的其他补充信息，不同组件的补充信息可能会有所不同，并且添加相关附件。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250819092602.35743705906564067838976678567788:50001231000000:2800:569BC04C43B5B4A604A6726167AD288CDCC354B8A6E0211C61CA3C0612186D4D.png)

     9. 单击“保存”按钮保存当前输入信息，“创建”或者“创建并启动另一个”按钮提交问题。
