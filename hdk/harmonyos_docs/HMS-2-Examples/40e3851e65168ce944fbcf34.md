尊敬的华为开发者：

从2020年9月16日起不推荐使用HMS Core 2.x版本SDK，华为将在2021年9月30日下架HMS Core 2.x版本的SDK，届时您的应用如果还集成2.x版本的SDK将无法上架华为应用市场。

给您带来不便请您谅解。若您有疑问及使用问题，可发送邮件至[HMSCore@huawei.com](mailto:HMSCore@huawei.com)或通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)咨询。

下架时间表：

日期 |  计划  
---|---  
2020.09.16 |  发布版本下架通知。已集成应用可以继续使用，但应立即启动迁移工作。新接入HMS Core的开发者请集成最新版本。  
2021.09.30 |  下架HMS Core 2.x版本的SDK，届时还集成2.x版本SDK的应用将无法上架应用市场，请您在此时间前升级到HMS Core最新版本SDK。  
2021.12.31 |  停止提供技术支持服务。
