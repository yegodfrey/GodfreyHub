# 关联认证申请操作指导  
  
**请注意，目前关联认证申请仅限于在您的企业有已实名认证过的普通企业开发者账号的基础上进行申请。**

如您想申请关联认证，请确保您已实名认证的普通企业开发者账号满足如下条件：

     * 确保您的企业名称、证件信息为最新；
     * 确保您的法人信息（法人姓名、证件照片、证件号码）的完整；
     * 法人需与企业证件信息中保持一致，且法人证件在有效期内；

**通过关联认证申请，企业开发者账号（In-house应用分发）无需重新提供企业相关证件，即可完成企业开发者账号（In-house应用分发）的实名认证。**

**请您按照如下步骤进行准备工作：**

     1. 注册一个新的归属地为中国大陆地区的华为账号，且不要进行实名认证；
     2. 使用新注册的账号，完成[In-house应用分发资格申请](https://developer.huawei.com/consumer/cn/verified/enterpriseDistribute)；
     3. 填写申请信息，提交并等待资格审核；
     4. 如您的资格申请审核通过，可登录您已实名认证、且主体名称与本次申请In-house应用分发资格相同的普通企业开发者账号，对您本次新注册的企业开发者账号（In-house应用分发）发起关联认证邀请。

     2. 点击“关联认证”按钮，进入开发者账号关联认证邀请页面（如您已实名的账号没有该入口，请确保您的已实名认证的普通企业开发者账号资质齐全且为最新。如您仍有疑问，可[提交工单](https://developer.huawei.com/consumer/cn/support/feedback/#/)联系客服处理）；
