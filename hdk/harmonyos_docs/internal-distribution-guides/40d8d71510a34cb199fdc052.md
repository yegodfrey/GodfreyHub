# 人工审核实名认证申请操作指导

企业开发者（In-house应用分发）人工审核认证需要提供企业相关证件、法人身份证证件或完成法人人脸识别验证。如您的法人验证选择“人脸识别”，则不需要提供法人身份证证件。

提交企业资料人工审核认证，选择不同的法人验证方式，需要的资料如下：

     * 上传法人手持身份证：企业最新的三证合一营业执照、法定代表人手持身份证正反面照片。
     * 法人人脸识别：企业最新的三证合一营业执照、通过法人人脸识别验证。
     1. 在[In-house应用分发资格申请](https://developer.huawei.com/consumer/cn/verified/enterpriseDistribute)审批通过后，通过[“企业开发者（In-house应用分发）实名认证”入口](https://developer.huawei.com/consumer/cn/verified/choose-corp-auth-method?distribution=2)进入实名认证页面；
     2. 选择企业资料人工审核认证，进入人工认证页面；

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916152002.43079556987303775050828764658237:50001231000000:2800:A5C981C1B542D12E646A27EC6BB0F37E4AD24CA0C2F01DAC7D4B27F40F5EA522.png)

     3. 根据实名认证页面的提示，填写企业、法人、公司的企业邮箱及其他信息。签署《华为In-house应用分发服务协议》和《华为开发者服务协议》，点击“下一步”，等待审核，审核结果会在1-2个工作日发送至联系人邮箱（标有红色星号（*）的项目是必填项）。
