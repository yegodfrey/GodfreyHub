# 开发准备

## 获取软件包

伙伴在获取华为书面准入许可时，将同时获得HiCar SDK软件包。

## 软件包说明

HiCar SDK软件包根据芯片类型分为arm，classic和x86三类，文件构成基本一致，不同点在于：

* arm平台的软件包提供DMSDP的32位和64位so库。
* classic平台软件包提供DMSDP的32位so库，主要用于Android4.2/4.4平台。
* x86平台软件包提供DMSDP的64位so库。

## 使用软件包

### 安装软件包

厂商获取到软件包后，请勿改动软件包的目录结构，按照如下步骤将软件包安装到车机系统中：

1. 使用厂商秘钥对软件包中的APK文件进行签名，确保APK文件能够以系统应用的方式运行在车机系统中。
2. 执行根目录下"Install_*.bat"（*为arm/X86/classic）脚本，完成HiCar SDK在车机侧的安装。

### 安装Demo

HiCar SDK软件包中包含用于调测及静态展示HiCar功能的Demo应用，但执行安装软件包的安装脚本时默认不会自动安装该Demo应用。如厂商需要，可按照如下步骤将Demo安装到车机系统中：

1. 进入Demo所在目录，打开"Demo/hicar.properties"文件，设置车机硬件参数。

   |参数名|是否必填|含义|单位|说明|
   |:-----------------|:---|:----------|:-|:----------------------------------------------------------------------|
   |ModelId|是|厂商设备ID|-|该参数由华为分配给车机厂商，调试及正式商用时该参数值需要厂商向华为申请获得。|
   |ScreenWidth|否|屏幕宽度|像素|屏幕分辨率宽度（例如1920），建议厂商设置该参数。该参数未设置时，SDK会通过OS系统函数尝试获取。|
   |ScreenHeight|否|屏幕高度|像素|屏幕分辨率高度（例如720），建议厂商设置该参数。该参数未设置时，SDK会通过OS系统函数尝试获取。|
   |ScreenSize|否|屏幕大小|英寸|屏幕对角线尺寸（例如10.4），建议厂商设置该参数。该参数未设置时，SDK会通过OS系统函数尝试获取。|
   |DefaultBitrate|否|默认投屏码率|-|设置该参数可以提升投屏画质，在同等网络质量前提下设置值越大画质越好，应介于500*1000 bit ~ 20*1000*1000 bit之间。|
   |MaxBitrate|否|最大投屏码率|-|投屏码率最大值，HiCar投屏画面码率会基于网络情况动态调整，最大值为20*1000*1000 bit。|
   |MinBitrate|否|最小投屏码率|-|投屏码率最小值，最小值为500*1000 bit。|
   |DefaultAudioFormat|否|默认车机侧音频输出格式|-|参数取值： * 0：AAC * 1：PCM，（缺省默认值）车机Wi-Fi传输速率较高（320Mbps及以上）时，建议优先选择PCM。|
   [**表2**车机硬件参数说明]

   更多关于参数设置的说明，请参考[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000030695)。

2. 执行Demo所在目录下"Install.bat"脚本，完成Demo应用在车机侧的安装。

### 使用调测日志开关

HiCar SDK支持通过系统参数"persist.vendor.hicarsdk.debug"或者"persist.sys.hicarsdk.debug"设置SDK的调试日志开关：

* 开启调测日志：厂商在集成调试阶段请开启调测日志，此时HiCar SDK会打印所有级别，包括DEBUG级别日志，便于厂商在集成调测阶段快速定位问题。
* 关闭调测日志：厂商在商用发布后请关闭调测日志，此时HiCar SDK仅会打印INFO，WARNING和ERROR级别日志，便于提升HiCar SDK的运行性能。

该系统参数设置后会写入系统/data/property目录下，重启车机依然生效。

命令如下所示：

```screen
adb shell
> setprop persist.vendor.hicarsdk.debug 1 //打开调试日志
> setprop persist.vendor.hicarsdk.debug 0 //关闭调试日志
//当"persist.vendor.hicarsdk.debug"参数无法读写时尝试设置"persist.sys.hicarsdk.debug"参数
adb shell
> setprop persist.sys.hicarsdk.debug 1 //打开调试日志
> setprop persist.sys.hicarsdk.debug 0 //关闭调试日志
```

## 调测时可使用的车型ID

华为会为每个车型提供唯一车型ID，即下文提到的ModelID与SubModelID。车型ID为4字节16进制字符串，其中前三个字节为车辆品牌标记（ModelID），第四个字节为车辆型号标记（SubModelID）。

调试及正式商用时该参数值需要厂商向华为申请获得。
