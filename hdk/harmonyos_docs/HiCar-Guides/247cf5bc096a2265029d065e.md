# 投屏说明

**图1**交互流程   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214106.11966022422245798067083041116557:50001231000000:2800:6BA8EBBBA62907550E843235A1819767DA7F6D30A2D0BBA1B5202021B8724AAB.png "点击放大")

假设厂商HMI应用是HMIHiCar，其中与HiCar SDK交互的模块为HiCarController。

1. HMIHiCar在初始化HiCar SDK的时候需要将支持的视频编码类型、屏幕尺寸、屏幕分辨率等信息通过"CarDisplayCapability"结构体传给HiCar SDK。
2. 车机和手机经过发现连接、鉴权认证、设备虚拟化等过程后，会将手机的投屏视频流数据通过CarListener中的"GetVideoData"回调函数发给HiCarController，HiCarController转给车机的解码模块解码后输出到屏幕显示。
3. 在投屏过程中，用户点击屏幕上的图标，或者操作方向盘上的方控按键，可以通过"HiCarPostEvent"接口将触屏事件或者按键事件通知到HiCar SDK，HiCar SDK会通知到手机侧做出相应的处理。
