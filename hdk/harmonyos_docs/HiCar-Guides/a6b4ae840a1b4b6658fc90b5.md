# 连接流程介绍

## 无线连接流程

首次连接手机：车机发起无线连接后，手机端确认连接，并输入授权码，车机端直接进入HUAWEI HiCar界面。

非首次连接手机：在满足自动连接条件时（自动连接选项开启，并且本次上电周期内未手动断开HiCar连接），手机靠近车机，车机自动进入HUAWEI HiCar界面。

## 有线连接流程

首次连接手机：通过USB先连接手机和车机后，手机端确认连接并授权，车机端直接进入HUAWEI HiCar界面。

非首次连接手机： 通过USB先连接手机和车机后，车机自动进入HUAWEI HiCar界面（自动连接开启）。
