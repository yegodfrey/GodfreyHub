# Camera

## 场景说明

HiCar支持发现车辆的Camera设备资源，包括车辆前装的Camera和用户后装的Camera。基于车辆Camera资源能力HiCar可以给用户提供更多的业务和服务。比如：

* **车内视频通话/视频会议：**用户在保障驾驶安全的情况下（如停车模式）可以采用车辆Camera和车机大屏与其它用户进行视频通话/视频会议。
* **驾驶安全关怀：**利用HiCar手机的AI算力，基于车辆驾驶位的Camera实时数据，可以对驾驶员进行实时的驾驶安全监控，异常时可智能提醒用户驾驶安全。
* **手势识别交互：**利用HiCar手机的AI算力，基于车辆驾驶位的Camera实时数据，可以识别驾驶员的手势交互来控制HiCar应用和服务。
* **行车安全辅助：**利用HiCar手机的AI算力，基于车辆行车记录Camera实时数据，可以对行车安全进行辅助检测并智能提醒用户。

如果厂商需要支持HiCar基于Camera的服务，车机需要实现Camera相关接口供HiCar调用。

厂商根据HiCar SDK提供的Camera接口头文件，实现Camera相关接口，并生成"libdmsdpcamerahandler.so"文件。HiCar SDK会在运行时，试图加载该so库文件，如果加载失败或未找到文件，则认为车机未实现Camera相关接口。如果找到该文件，则动态加载该so链接库，并通过so链接库中实现的接口从车机获取Camera数据。实现过程中可参考HiCar SDK包中的"dmsdp_camera_sdk_samples.c"。

1. HiCarSDK在初始化时，会试图打开"libdmsdpcamerahandler.so"，如果打开成功，则认为车机适配虚拟Camera功能，才会上报车机具备虚拟camera的能力。如果没有打开成功，不会上报支持虚拟Camera。
2. Camera回调函数集合中包括向车机系统注册业务状态侦听器，厂商在HiCarController中缓存侦听器指针，用于后续Camera状态（如Camera忙闲变化），数量等发生变化（如USB Camera插拔等）时，上报Camera状态变化信息。
3. Camera回调函数集合中会向车机系统查询Camera能力信息，包括Camera数量，各个Camera的id，支持的分辨率，帧率，数据格式等（对应接口：GetCameraCapability）。如果车机有多个摄像头，具体返回哪些摄像头用于分布式虚拟化需要厂商根据业务需求自行决定。摄像头可能有多种能力，选择HiCar SDK支持的一种能力上报即可，建议优先返回H264或H265数据类型，若摄像头不支持输出H264/H265视频流，可以选择返回NV21或RGB565格式。
4. 车机系统需要监控本地Camera状态变化。例如，车机Camera被打开，需要监控到Camera状态忙；车机新插入一个USB摄像头，如果该摄像头需要进行分布式虚拟化使用，需要查询该摄像头能力信息；如果车机之前上报了的一个USB摄像头被拔出，需要监控到摄像头丢失事件。
5. HiCarSDK接收到Camera设备状态变化后，更新本地缓存信息，同时上报变化信息到手机侧。
6. HiCarSDK在打开Camera之前，会先向车机注册Camera数据回传函数句柄，Camera视频流数据通过该句柄回传数据（对应接口：RegisterSendDataCallback）。
7. HiCarSDK调用打开Camera函数，携带Camera参数（对应接口：OpenCamera），Camera打开后回传Camera数据。
8. 业务运行中，HiCar SDK可能会更新Camera配置，例如运行中修改Camera帧率，调用更新接口下发新的配置（对应接口：UpdateConfig），如果摄像头不支持更新对应配置，厂商保持接口空实现即可。
9. HiCarSDK在不需要摄像头数据的时候调用关闭Camera接口（对应接口：CloseCamera），释放本地缓存的资源，如数据回传函数句柄等。

## 接口说明

HiCar SDK定义的Camera接口抽象了Camera操作，将对于Camera的操作封装为打开、关闭、更新配置、查询能力、注册事件侦听器等接口，厂商需要按照接口说明实现对Camera的基本操作。

```screen
dmsdp_business.h              -- 定义了错误码，状态码等信息
dmsdp_camera_data_type.h      -- 定义camera数据对象
dmsdp_camera_handler.h        -- 定义了camera接口
```

## 开发步骤

1. 梳理车机Camera硬件信息，判断哪些车机Camera需要进行分布式虚拟化，供手机使用，只有需要参与分布式虚拟化业务的Camera信息需要收集能力和上报。
2. 由于HiCar SDK需要通过设备接口操作车机Camera，同时，车机上其他业务也可能操作Camera，所以需要厂商妥善处理不同业务对于Camera使用的冲突。
3. 车机Camera上报能力给手机后，可能存在Camera状态变化的情况，例如Camera被车机其他业务使用、USB Camera拔出丢失Camera、USB Camera插入新增Camera的情况。如果发生状态变化的Camera是需要参与虚拟化业务的，则厂商需要监控对应Camera的状态变化。
4. 根据设备接口定义头文件实现Camera设备接口，提供Camera操作以及状态侦听的能力。
5. 编译构建so库，部署到车机系统中进行测试。
