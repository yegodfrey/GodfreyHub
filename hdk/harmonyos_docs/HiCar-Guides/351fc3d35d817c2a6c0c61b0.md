# 退出全屏

## 场景说明

用户点击退出全屏按钮后，由于此时用户手机可能处于竖屏、横屏或折叠展开状态，需先通知手机上报当前屏幕宽高。车机拿到手机上报的屏幕宽高后，等比缩放窗口宽高，再通知手机进行异源屏到同源屏的切换。（同源屏即手机镜像屏）

## 接口说明

当前接口需发送546消息，参数包含两个字段：

* stateCode：值为3，通知手机从异源投屏切换为同源投屏。
* stateData：值为窗口宽高，手机针对新的宽高进行同源屏宽高适配。

## 开发步骤

通知手机进行退出全屏切换。

```screen
// 通知手机上报当前手机宽高
public void onExitFullScreen() {
    JSONObject jsonData = new JSONObject();
    jsonData.put("stateCode", 3);
    jsonData.put("stateData", ""); 
    hiCarAdapter.sendCarData(546, jsonData.toJSONString());
}

// 监听546消息，接收到手机上报的宽高后，resize窗口宽高，并通知手机进行异源屏到同源屏的切换。
class HiCarListener implements Carlistener {
    @Override
    public void onDataReceive(String deviceId, int dataType, byte[] data) {
        switch (dataType) {
            case DeviceData.DATA_TYPE_SMALL_WINDOW_STATE: // 546
                JSONObject jsonData = CommonUtils.getJsonObject(data, datatype).orElse(null); // 将从手机接收的命令字符串转换为JSON数据
                int stateCode = jsonData.getInteger("stateCode");
                String stateData = jsonData.getString("stateData");
                if (stateCode == 3) {
                    JSONObject stateDataJson = JSON.parseObject(stateData);
                    int mPhoneWidth = stateDataJson.getInteger("width");
                    int mPhoneHeight = stateDataJson.getInteger("height");
                    // resize窗口宽高
                    resizePhoneWindow(mPhoneWidth, mPhoneHeight); // HMI实现此函数

                    // 上报当前窗口宽高，并通知手机进行同源屏到异源屏的切换，即退出全屏
                    JSONObject jsonData = new JSONObject();
                    jsonData.put("stateCode", 3);
                    JSONObject jsonStateData = new JSONObject();
                    jsonStateData.put("width", mPhoneDesktopWidth); // 手机桌面窗口宽度
                    jsonStateData.put("height", mPhoneDesktopHeight); // 手机桌面窗口高度
                    jsonData.put("stateData", jsonStateData.toJSONString());
                    hiCarAdapter.sendCarData(DeviceData.DATA_TYPE_SMALL_WINDOW_STATE, jsonData.toJSONString());
                }
                break;
        }
    }
}
```
