# 处理视频丢帧

## 场景说明

在投屏过程中，HiCar SDK在收到手机侧发送的视频帧数据时，会通过厂商HMI应用在初始化注册的GetVideoData函数将视频帧数据发给厂商HMI应用，其中注册的GetVideoData函数中不能存在耗时操作，以免阻塞后续的回调通知。

厂商HMI应用可以在本地维护一个视频帧的列表，用于解码和送显。如果出现视频帧的堆积，可以适当丢弃视频帧，从而保证投屏显示的实时性。在丢弃视频帧后，厂商HMI应用可以通过HiCar SDK的接口请求I帧，恢复后续视频帧的解码。

## 开发步骤

1. 在HiCar SDK初始化时注册视频数据回调函数GetVideoData，详见[注册事件侦听回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/register-event-listener-0000000000105633)。
2. 在回调函数中解码视频并送显，同时添加异常处理流程，当视频数据堆积时进行丢帧处理并通过HiCarPostEvent接口请求I帧。
