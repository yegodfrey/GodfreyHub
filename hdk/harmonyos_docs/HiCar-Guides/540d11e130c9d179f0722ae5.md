# 处理相关回调

## 处理PIN码回调

厂商通过"startAdv"开始广播后触发PIN码回调，厂商HMI应用可以通过回调方法"onPinCode()"获取PIN码，显示到连接界面中，供手机用户输入。当用户三次输入PIN码错误，PIN码将自动刷新。

|类|方法|说明|
|:----------|:--------|:------------------|
|CarListener|onPinCode|厂商HMI应用通过该接口获取PIN码。|
[**表1**处理PIN码回调相关接口]

1. 在[注册事件侦听回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/register-event-listener-0000000000030698)中已注册的"onPinCode()"回调方法中获取PIN码，并将其显示在连接界面中。

   请参考《HUAWEI HiCar 设备接入UX设计规范》设计连接界面。

   处理PIN码回调的示例代码如下所示：

   ```screen
   CarListener carListener = new CarListener() {
       ...
       @Override
       public void onPinCode(final String pinCode) {
           runOnUiThread(new Runnable() {
               @Override
               public void run() {
                   mPinText.setText(pinCode);
                   mPinText.setVisibility(View.VISIBLE);
               }
           });
       }
   };
   ```

2. 如果获取PIN码失败，请参考《HUAWEI HiCar 设备接入UX设计规范》显示对应的失败反馈界面。

## 处理认证回调

HiCar SDK会对成功连接过的手机和车机进行认证，认证过的设备无需输入PIN码即可再次连接。

厂商HMI应用需要将上述认证信息保存在车机系统中，并通过HiCar SDK提供的回调方法完成认证文件的读取、保存和删除操作。
> 说明
>
> HiCar SDK通过回调向厂商HMI应用提供的认证数据已经过白盒加密，厂商HMI应用仅需保证存储安全即可。
>
> 建议厂商规划专门的安全存储区域，存储认证文件。

|类|方法|说明|
|:----------|:----------------|:-------------------|
|CarListener|getSecureFileSize|获取认证文件大小。|
|CarListener|readSecureFile|读取认证文件信息。|
|CarListener|writeSecureFile|保存认证信息到车机本地文件或安全存储区。|
|CarListener|removeSecureFile|删除安全认证文件。|
[**表2**处理认证回调相关接口]

在[注册事件侦听回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/register-event-listener-0000000000030698)中已注册的认证相关回调方法中完成认证文件处理逻辑。

认证回调的示例代码如下：

```screen
CarListener carListener = new CarListener() {
    ...
    @Override
    public long getSecureFileSize(String fileName) {
        try(FileInputStream fis = getApplicationContext().openFileInput(fileName)) {
            return fis.available();
        } catch (IOException e) {
            Log.d(TAG, "read file IOException", e);
        }
        return FAILED;
    }
 
    @Override
    public byte[] readSecureFile(String fileName) {
        Log.i(TAG,"readSecureFile: fileName = " + fileName);
        byte[] readFileData = null;
        try(FileInputStream fis = getApplicationContext().openFileInput(fileName)) {
            byte[] temp = new byte[1024];
            int len = 0;
            // read file
            Log.d(TAG,"readSecureFile: openFileInput success");
            while ((len = fis.read(temp)) != FAILED) {
                if ((readFileData != null) && (readFileData.length != 0)) {
                    readFileData = byteMerger(readFileData, temp, len);
                } else {
                    readFileData = new byte[0];
                    readFileData = byteMerger(readFileData, temp, len);
                }
            }
            Log.d(TAG,"read secure file");
            return readFileData;
        } catch (IOException e) {
            Log.d(TAG,"read file IOException", e);
        }
        return null;
    }
 
    @Override
    public boolean writeSecureFile(String fileName, byte[] data) {
        Log.i(TAG,"write secure file:" + fileName);
 
        try(FileOutputStream fos = getApplicationContext().openFileOutput(fileName, Context.MODE_PRIVATE)) {
            fos.write(data);
            fos.flush();
            fos.close();
            return true;
        } catch (FileNotFoundException e) {
            Log.d(TAG,"write file FileNotFoundException", e);
        } catch (IOException e) {
            Log.d(TAG,"write file IOException", e);
        }
        return false;
    }
 
    @Override
    public boolean removeSecureFile(String s) {
        return false;
    }
};
```

## 处理连接事件回调

厂商HMI应用在手机和车机连接后，可以通过回调方法获取到具体的连接事件，并根据不同的连接事件完成相应的逻辑处理。例如在收到断开连接事件后，退出厂商HMI应用。

|类|方法|说明|
|:----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|onDeviceChange|HiCar SDK通过回调的方式向厂商HMI应用通知连接相应的事件： * EVENT_DEVICE_CONNECT（值为101）：设备已连接。收到连接成功事件后，厂商HMI应用需要停止广播、显示连接动画（在投屏成功或超时之前，连接动画需要一直显示）。 * EVENT_DEVICE_DISCONNECT（值为102）：设备已断开连接。收到连接断开事件后，厂商HMI应用应进行断开连接、释放资源等操作。 * EVENT_DEVICE_CONNECT_FAILD（值103）：设备连接失败。收到连接失败事件后，厂商HMI应用应进行退出操作。|
|CarListener|onDataReceive|* DATA_TYPE_USERACTIVEDISCONNECT（值518）：手机侧主动断开。收到连接断开事件后，厂商HMI应用应进行断开连接、释放资源等操作。|
[**表3**处理连接事件回调相关接口]

处理连接事件回调的示例代码如下所示：

```screen
CarListener carListener = new CarListener() {
    @Override
    public void onDeviceChange(String deviceId, int state, int errorCode) {
        switch(state) {
            ...
            case HiCarConst.EVENT_DEVICE_CONNECT:
                //TODO:厂商逻辑，如加载连接动画等
                break;
            case HiCarConst.EVENT_DEVICE_DISCONNECT:
                //TODO:厂商逻辑，如退出厂商HMI应用
                break;
            case HiCarDemoServiceListener.EVENT_DEVICE_CONNECT_FAILD:
                //TODO:厂商逻辑，如退出厂商HMI应用
                break;
            default:
                break;
        }
    }
};
```
