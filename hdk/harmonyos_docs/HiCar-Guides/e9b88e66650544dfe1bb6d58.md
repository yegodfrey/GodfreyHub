# 建立自动连接

## 交互流程

如果用户已经成功通过无线方式连接了HiCar，并在手机HiCar App中允许了"自动连接"，那么当用户再次进入驾驶环境时，手机将自动与车机建立HiCar无线连接。此功能即为HiCar的自动连接功能。

HiCar自动连接功能依赖车机的基础蓝牙回连能力（基础蓝牙回连能力指车机会自动与已配对的手机建立蓝牙连接），厂商HMI应用在收到蓝牙回连成功事件后，调用"HiCarReconnect"接口触发HiCar自动连接流程。

厂商HMI应用是否调用HiCar SDK的自动连接接口，需要满足如下条件：

* 车机自身具备基础蓝牙回连能力，即车机会自动连接已配对的手机。
* 当手机靠近车机时，车机与手机自动建立蓝牙连接。
* 在本次车机上电周期内，不存在用户主动在手机侧断开HiCar连接的行为。

当以上条件都满足时，厂商HMI应用调用HiCar SDK提供的"HiCarReconnect"接口，该接口传入远端设备的蓝牙地址，发起自动连接流程。接口内部会判断该手机是否之前通过了HiCar认证，如果没认证过，不会完成HiCar连接。

## 发起自动连接

### 自动连接场景

厂商HMI应用需要在用户再次用车时发起自动连接。由于自动连接依赖车机的基础蓝牙连接，一般情况下，厂商HMI应用可以通过侦听系统的基础蓝牙连接事件，在收到蓝牙连接完成的系统广播后，调用HiCar SDK的"HiCarReconnect"接口发起自动连接流程。

由于部分车辆在熄火后并不会立即断开蓝牙连接，所以在部分车辆熄火后重新启动的场景下，无法通过侦听蓝牙连接事件发起自动连接流程，此时需要厂商HMI应用判断蓝牙已连接后，即可发起自动连接流程。
> 说明
>
> 在自动连接过程中，厂商HMI应用无需再调用"HiCarStartAdv"接口发送连接广播，避免出现自动连接成功后手机仍在弹出发现连接窗口的情况。

### 无需自动连接场景

当用户手动断开HiCar连接时，厂商HMI应用需要确保在下次用户上车启动前，即使蓝牙重新连接，也不会触发自动连接。**如果用户在本次上电周期又主动触发了连接的情况除外，需清除用户主动断开的记录。**

该场景下，厂商HMI应用需要在通过"DataReceive"回调获取到这次HiCar断开连接事件是用户主动断开连接，则设置相应标志位，在用户下次用车之前都不触发自动连接流程。详情请参考[主动断开车机连接通知](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/disconnect-notification-0000001081869175)。
