# 方控模拟滑动按键（Beta）

## 场景说明

为优化用户体验，连接HiCar后，用户可以通过方控模拟滑动按键来控制滑动浏览在白名单上的视频应用。

车机在检测到车机物理按键被按下后，需要向HiCar App上报相应的数据。

方控模拟滑动按键能力上报相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"[方控模拟滑动按键](https://developer.huawei.com/consumer/cn/doc/HiCar-References/ctrl-simulation-0000002135813341)中部分。

## 应用示例

车机向HiCar发送查询消息获取支持该功能的白名单应用列表，可以通过前台应用检测功能（见[前台应用检测](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/foreground-application-0000002100214960)）来判断前台应用是否支持该功能。如果支持即可将上滑或下滑动作指令发送给HiCar，从而实现滑动浏览三方视频应用的功能。
> 说明
>
> 1. 此功能只支持前台应用处于视频上下滑动模式。
> 2. 如果实现滑动控制的按钮为切歌按钮，使用此功能可能出现视频与音乐应用抢占音频通道问题。 建议车机在相应按键事件前判断一下前台应用：
>
>    * 前台应用为白名单视频应用，则跳过[HiCarPostEvent](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/physical-key-knob-0000000000105717#ZH-CN_TOPIC_0000001050064330__p112143317612)，发送滑动功能事件。
>    * 前台应用为非白名单视频应用，执行[HiCarPostEvent](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/physical-key-knob-0000000000105717#ZH-CN_TOPIC_0000001050064330__p112143317612)事件。

## 开发步骤

1. 手机和车机成功连接并投屏后，车机需要通过**HiCarSendData**接口向HiCar App发送白名单应用列表的查询请求（dataType=543）。车机发送的数据内容示例如下：

   ```screen
   {
       "action"："querySupportApps"
   }
   ```

   车机通过**DataReceive** 方法，判断**dataType**后可以收到返回的应用信息。

   ```screen
   {
       "supportApps": "[com.ss.android.ugc.aweme]"
   }
   ```

2. 车机通过**HiCarSendData**接口向HiCar App发送滑动事件消息（dataType=543），示例如下：

   ```screen
   {
       "action":"moveNext"
   }
   ```
