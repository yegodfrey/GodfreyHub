# 当手机连接平板时通过WLAN连接手机实时查看调测日志

当您通过USB连接手机与平板中的HiCar模拟器后，无法再通过有线的方式连接手机与主机使用adb进行应用调试，此时您可以通过WLAN连接到手机使用adb查看日志。

1. 将主机和手机连接到同一局域网的Wi-Fi。请注意，并非所有接入点都适用；您可能需要使用防火墙已正确配置为支持adb的接入点。
2. 使用USB数据线将手机连接到主机，确保手机成功连接。可使用"adb devices"命令查看连接状态。
3. 设置目标设备以监听端口5555上的TCP/IP连接。

   ```screen
   adb tcpip 5555
   ```

4. 拔掉连接目标设备的USB数据线。
5. 找到Android设备的IP地址。例如，对于华为手机，您可以在"设置>关于手机>状态>IP地址"下找到IP地址。
6. 通过IP地址连接到设备。

   ```screen
   adb connect *device_ip_address*
   ```

7. 确认主机已连接到目标设备。

   ```screen
   $ adb devices     
   List of devices attached     
   **device_ip_address**:5555 device
   ```
