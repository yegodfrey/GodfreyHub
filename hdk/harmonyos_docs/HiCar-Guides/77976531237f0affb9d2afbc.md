# 开启HiCar Debug模式

应用接入HiCar需要鉴权成功后才可以正常显示在HiCar的车机屏幕上，您在调测阶段可以开启HiCar Debug模式，从而将应用直接显示到车机屏幕上进行调测。

1. 使用USB数据线将手机连接到主机，确保手机成功连接。可使用"adb devices"命令查看连接状态。
2. 开启HiCar Debug开关。

   ```screen
   adb shell setprop hicar.config.app.white_debug true
   ```

3. 重启手机上HiCar进程。

   ```screen
   adb shell am force-stop com.huawei.hicar
   ```

4. 重新连接手机和平板中的HiCar模拟器，可以看到正在调测的应用图标已经显示在HiCar的应用图标区。
