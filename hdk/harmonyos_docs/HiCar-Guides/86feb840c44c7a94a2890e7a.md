# 连接设备模拟器

## 有线连接

建立HUAWEI HiCar有线连接的步骤如下：

1. （有双头Type-C数据线时）通过双头Type-C数据线连接。
   1. 在华为平板上打开HiCar Simulator。
   2. 将双头Type-C数据线分别连接华为手机和华为平板。
2. （无双头Type-C数据线时）通过OTG转接器+Type-C连接线连接。
   1. 将Type-C数据线连接到OTG转换器。
   2. 将OTG转换器连接到华为平板上。
   3. 在华为平板上打开HiCar Simulator。
   4. 将Type-C数据线连接到华为手机上。
3. 华为手机与华为平板连接后，系统将自动识别并建立连接，在华为手机侧将弹出发现和建立连接的窗口。
4. 连接成功后，在华为手机通知页面会出现HUAWEI HiCar已连接消息。

   **图1**华为手机显示HUAWEI HiCar连接中以及连接成功图示

5. 如果超过20秒没有连接成功，请断开连接（拔下华为手机端连线），并再次重复步骤4和步骤5尝试重新连接。

## 无线连接

> 注意
>
> 仅HUAWEI MatePad Pro版本可以支持HiCar无线连接，其它华为平板无法通过无线方式建立HiCar连接。
>
> 请开发者检查收到的华为平板版本，如果不是HUAWEI MatePad Pro版本，请继续使用有线方式建立HiCar连接。

建立HUAWEI HiCar无线连接的步骤如下：

1. 打开华为平板的蓝牙开关，关闭华为平板的Wi-Fi开关。
2. 打开华为手机的蓝牙开关及Wi-Fi开关。
3. 在华为平板上打开HiCar Simulator，显示连接码如[图2](#ZH-CN_TOPIC_0000001181831469__fig1026615507320)所示。

   **图2**HiCar连接码

4. 在手机侧显示HiCar连接弹框后，单击"连接"。

   **图3**手机侧HiCar连接弹框   
   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220524101405.69977780896474987367568559334422:50530523030437:2800:731533DDD0836E4AA3C6ECF13C546877387C45A3B5E99C731A47D3630FDA0682.png?needInitFileName=true?needInitFileName=true "点击放大")
5. 在华为手机弹出的连接码输入框中输入HiCar连接码后，单击"确定"。

   连接码输入正确后，华为手机会弹出正在连接的弹框，当华为平板显示投屏界面后，连接成功。

   后续连接过程中，无需再次输入连接码即可成功连接。

## 异常处理

如果无法建立HUAWEI HiCar连接，请尝试如下方法：

1. 如果华为平板中HiCar Simulator正常运行，但无法连接，请重启HiCar Simulator。
2. 如果华为平板侧提醒无法配对，请重启华为平板和华为手机，再次连接。
3. 如果都无法解决，请联系华为支持人员。
