# 行驶状态

## 场景说明

HiCar针对不同的行驶状态，会提供不同的应用和服务，例如在停车时可以观看视频以及玩游戏。HiCar定义了两种行驶状态：

* 行车状态：汽车处于行车（D档）/倒车（R档）/空挡（N档）
* 停车状态：自动挡车处于驻车档（P档）；手动挡车处于空挡+手刹模式

车机和手机连接后需要主动向HiCar App上报当前所处的行驶状态，并在行驶状态发生变化后及时更新。HiCar App在接收到车机上报的行驶状态信息后会进行消息响应，以避免因为传输问题导致未获取到行驶状态信息。

如果车机发送行驶状态信息后没有收到HiCar App的响应消息，车机需要间隔重发，间隔重发次数为3次，每次间隔时间为1秒，重发期间只要收到一次HiCar App的响应消息，则表示此次上报成功。如果间隔重发3次依然没有收到响应消息，则表明传输链路可能出现故障，需要车机侧记录相应异常信息。

行驶状态相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[行驶状态](https://developer.huawei.com/consumer/cn/doc/HiCar-References/vehicle-running-status-0000001199289935)部分。

## 开发步骤

1. 手机和车机成功连接并投屏后，车机需要通过**HiCarAdapter::sendCarData**接口向HiCar App上报当前的行驶状态。车机发送的数据内容示例如下：

   ```screen
   {
       "drivingMode":1
   }
   ```

2. HiCar App在收到行驶状态数据后，会向车机发送响应数据（dataType=506）。响应数据示例如下所示：

   ```screen
   {
       "errorCode":100000
   }
   ```

3. 车机通过**onDataReceive** 方法，判断**dataType**后可以收到上述具体数据内容。

   1. 如果返回结果为成功（errorCode为100000），则此次行驶状态数据已成功上报。
   2. 如果返回结果为异常（errorCode为其它值），车机需要根据异常信息进行处理。
   3. 如果未收到响应消息，车机需要间隔重发。
