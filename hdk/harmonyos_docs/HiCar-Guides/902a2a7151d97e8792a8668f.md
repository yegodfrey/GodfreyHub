# 获取应用列表

## 场景说明

在HiCar连接完成后，厂商HMI应用可以通过HiCar SDK向HiCar App请求获取接入HiCar的应用信息，获取成功后，将应用信息与原车界面进行融合显示。

## 接口说明

在获取支持HiCar的应用信息的过程中，需要用到以下接口：

* HiCarAppDataListener：融合桌面应用数据及事件信息类，提供应用数据获取及应用事件（例如应用安装、应用卸载等）回调接口。

另外，融合桌面中与HiCar App交互的接口设计，沿用了已有车机与HiCar App交互接口的机制，所以在开发融合桌面特性之前，请参考[数据交互](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/interactions-0000001051779174)了解交互机制。

获取应用列表过程中与HiCar App交互的具体数据格式说明，请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[融合桌面应用列表](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-References/fusion-ui-app-list-0000002012192725)部分。

## 开发步骤

1. 注册接口监听。请确保该步骤中的注册接口监听的代码，在步骤2之前被执行。

   ```screen
   // 注册接口监听
   HiCarRegisterAppDataListener(HiCarAppDataListener *appListener);
   ```

2. 在建立HiCar连接后，车机可向HiCar App发送请求报文（dataType=528）请求获取接入HiCar的应用信息。报文内容示例如下所示：

   ```screen
   {
       "RequestData" : "all",
       "RequestCaller" : "00010001"
   }
   ```

   示例代码如下所示：

   ```screen
   const char *requestAppData = "{\"RequestData\":\"all\",\"RequestCaller\":\"00010001\"}";
   HiCarSendData((HICAR_HANDLE)g_handle, HICAR_DATA_TRANS_APP_INFO, (uint8_t *)requestAppData, (uint32_t)strlen(requestAppData));
   ```

3. 获取HiCar App返回的应用数据结果。

   当数据请求成功时，HiCar SDK会通过HiCarAppDataListener的OnAppDataLoad回调返回所有HiCar支持的应用信息列表，并在应用安装或卸载时触发其它回调，具体回调说明如下：
   * void **OnAppDataLoad** (const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize)：

     SDK将获取到的全量APP数据回调给车机，车机可将应用信息绘制到Launcher应用界面上。
   * void**OnAppDataAppend** (const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize)：

     SDK将新增部分APP数据回调给车机，车机可将新增部分应用添加到Launcher应用界面上。
   * void**OnAppDataDelete** (const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize)：

     SDK将已删除部分APP数据回调给车机，车机需从Launcher应用中删除该部分应用。
   * void**OnAppDataUpdate** (const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize)：

     SDK将有信息更新的APP数据回调给车机，车机需在Launcher应用中更新该部分应用信息。
   * int32_t (***GetLocalAppDataCount** )(const char *devId, uint32_t devIdLen):

     获取本地缓存的应用总数量，SDK通过此接口获取本地缓存的应用总数量。
   * int32_t (***LoadLocalAppData** )(const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize):

     加载本地缓存的应用数据，SDK通过此接口获取本地缓存的应用数据，需将应用数据查询，填充至array中（array的内存已经分配，长度为arraySize）。
   * int32_t (***** **InsertLocalAppData** )(const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize, bool isClear):

     将应用数据存储（插入）到本地缓存，isClear指定了是否需要清除此设备之前的数据。
   * int32_t (*RemoveLocalAppData)(const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize): 删除缓存中的应用数据，根据devId和应用包名(即(array + index)->pkgName)删除相应应用。

   * int32_t (*UpdateLocalAppData)(const char *devId, uint32_t devIdLen, AppInfo *array, uint32_t arraySize): 更新缓存中的应用数据，根据devId和应用包名更新应用数据。

   |参数名|类型|说明|
   |:---------|:-------|:-------------------|
   |appName|char*|应用名称|
   |appNameLen|uint32_t|应用图标字符串长度|
   |pkgName|char*|应用包名|
   |pkgNameLen|uint32_t|应用图标字符串长度|
   |appIcon|char*|应用图标（二进制数据，图标格式为PNG）|
   |appIconLen|uint32_t|应用图标二进制数据长度|
   |appType|int32_t|应用类型|

4. 在HiCar断开连接后，反注册接口监听及释放资源。

   ```screen
   // 去注册监听
   HiCarUnregisterAppDataListener();
   // SDK内部在释放资源时也会调用HiCarUnregisterAppDataListener();
   HiCarRelease ();
   ```
