# 实现基础语音操作

## 场景说明

用户在HiCar环境中使用音频应用时，会通过语音助手下发"上一首"、"下一首"、"播放"、"暂停"、"停止"等基础语音操作指令，此时需要音频应用正确进行响应。

## 接口说明

为了实现基础语音操作功能，音频应用需要实现MediaSession相应的回调方法，如[表1](#ZH-CN_TOPIC_0000001119898507__table437373043114)所示。

基于MediaSession框架的音频应用一般已经实现了对应的回调方法，音频应用根据表格中回调方法检查即可。

|操作|说明|需要实现的回调方法|
|:--|:----------|:-------------------------------------------------------------|
|上一首|用户选择播放上一首曲目|android.media.session.MediaSession.Callback.onSkipToPrevious()|
|播放|用户选择继续播放曲目|android.media.session.MediaSession.Callback.onPlay()|
|暂停|用户选择暂停播放曲目|android.media.session.MediaSession.Callback.onPause()|
|停止|用户选择停止播放曲目|android.media.session.MediaSession.Callback.onStop()|
|下一首|用户选择播放下一首曲目|android.media.session.MediaSession.Callback.onSkipToNext()|
[**表1**基础语音功能需要音频应用实现的MediaSession回调方法]

## 开发步骤

1. 音频应用请根据[表1](#ZH-CN_TOPIC_0000001119898507__table437373043114)检查是否已经实现表中列出的回调方法。

   如果存在部分回调方法未实现，请根据MediaSession框架要求实现相应的方法。

2. 在设置或更新播放状态时，音频应用需要通过PlaybackState设置相应的Action指令。

   示例代码如下所示：

   ```screen
   mPlaybackState = new PlaybackState.Builder()
               .setState(PlaybackState.STATE_PLAYING, currentPosition, 1.0f)
               .setActions(PlaybackState.ACTION_STOP
                       | PlaybackState.ACTION_PAUSE
                       | PlaybackState.ACTION_PLAY
                       | PlaybackState.ACTION_SKIP_TO_NEXT
                       | PlaybackState.ACTION_SKIP_TO_PREVIOUS).build();
   mMediaSession.setPlaybackState(mPlaybackState);
   ```
