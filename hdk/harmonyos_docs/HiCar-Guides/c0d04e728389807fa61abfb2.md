# 切换退出全屏按钮的禁用状态

## 场景说明

手机在切换全屏前不应保持退出全屏按钮为启用状态，否则在投屏未结束时点击退出全屏按钮会导致投屏失败。因此，车机侧需在全屏隐藏全屏按钮并显示退出全屏按钮的同时，并禁用退出全屏按钮。待手机侧投屏结束后，由手机侧通知车机去启用退出全屏按钮。

## 接口说明

当前接口需监听546消息，参数包含两个字段：

* stateCode：值为8，表示禁用退出全屏按钮。值为9，表示启用退出全屏按钮。
* stateData：值为空字符。

## 开发步骤

禁用或启用退出全屏按钮。

```screen
// 监听546消息，禁用或启用全屏按钮
class HiCarListener implements Carlistener {
    @Override
    public void onDataReceive(String deviceId, int dataType, byte[] data) {
        switch (dataType) {
            case DeviceData.DATA_TYPE_SMALL_WINDOW_STATE: // 546
                JSONObject jsonData = CommonUtils.getJsonObject(data, datatype).orElse(null); // 将从手机接收的命令字符串转换为JSON数据
                int stateCode = jsonData.getInteger("stateCode");
                String stateData = jsonData.getString("stateData");
                if (stateCode == 8) {
                    mExitFullScreenButton.setEnable(false);
                } else if (stateCode == 9) {
                    mExitFullScreenButton.setEnable(true);
                }
                break;
        }
    }
}
```
