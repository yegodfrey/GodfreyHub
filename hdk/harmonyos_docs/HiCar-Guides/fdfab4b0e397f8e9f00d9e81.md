# 界面布局

## 投屏控件

"HiSightSurfaceView"是HiCar SDK提供的投屏控件，当手机和车机建立连接后，手机上的HiCar应用会投射到该控件上，厂商HMI应用集成该控件后，即可在车机屏幕上显示HiCar应用和服务。同时，用户在车机屏幕上对该控件的触控操作也会通过反向控制通道传输到手机侧，从而完成用户对HiCar应用和服务的操控。

"HiSightSurfaceView"控件和其它Android控件类似，厂商HMI应用在投屏界面集成时，需要在布局文件中增加对该控件的描述。示例代码如下所示：

```screen
<RelativeLayout
        android:id="@+id/project_layout"
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        android:gravity="center"
        android:background="#000000">
        <com.huawei.hicarsdk.HiSightSurfaceView
android:id="@+id/surface"
android:focusableInTouchMode="true"
android:layout_width="match_parent"
android:layout_height="match_parent"
android:fillViewport="true"
android:scrollbars="vertical"/>
</RelativeLayout>
```

## 界面逻辑

厂商在设计开发HMI应用时，应遵循《HUAWEI HiCar 设备接入UX设计规范》。界面交互核心流程及典型界面如下所示。

### 无线连接流程

首次连接手机：车机发起无线连接后，手机端确认连接，并输入授权码，车机端直接进入HUAWEI HiCar界面。

非首次连接手机：在满足自动连接条件时（自动连接选项开启，并且本次上电周期内未手动断开HiCar连接），手机靠近车机，车机自动进入HUAWEI HiCar界面。
