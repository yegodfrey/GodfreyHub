# 提供导航功能

#### 导航卡片

HiCar为地图应用提供了导航空闲卡片和导航TBT（Turn By Turn）卡片，供用户在HiCar连接成功后，通过导航卡片快速进入应用或直接执行卡片上的快捷功能。

     * 导航空闲卡片：执行快捷操作，如回家、去公司。
     * 导航TBT卡片：展示导航中的引导信息。

#### 应用显示状态

地图应用在HiCar场景中有全屏、分屏、悬浮窗三种显示状态，地图应用需要根据当前的显示状态适配界面。

     * 全屏状态：点击应用后默认进入的状态。

#### 导航元数据

导航元数据是描述导航信息的基础数据，包括导航类型、导航目的地、下一步道路名等。HiCar通过导航元数据从地图应用获取信息用于导航TBT卡片内信息显示，同时通过开放导航元数据的方式，将导航相关信息传递给车机，车机在正确获取到相关元数据后，可以在仪表盘、HUD显示导航信息。详细字段描述请参考[Car Kit API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/car-navigationinfomgr#section12118327148)。

元数据示例如下所示：
    
    {

        naviSpeedLimitValid: false,

#### 开发步骤

#### [h2]地图应用配置

     1. 地图应用在HiCar场景中通过Car Kit接口与HiCar进行交互，需要申请Car Kit相关权限。在module.json5中配置相关权限。
            
            {
              "module": {
                ......
                "requestPermissions": [
                  {
                    "name": "ohos.permission.ACCESS_SERVICE_NAVIGATION_INFO"
                  },
                  {
                    "name": "ohos.permission.ACCESS_CAR_DISTRIBUTED_ENGINE"
                  },
                ]
              }
            }

     2. （仅当地图应用适配地图悬浮窗简易UI时需要配置）地图悬浮窗简易UI配置。
            
            {
              "module": {
                ......
                "metadata": [{
                  "name": "com.huawei.hicar.supportCardWindow",
                  "value": "1.0",
                }]
              }
            }

#### [h2]更新导航状态

当地图应用状态发生变化后需要主动通知HiCar，便于HiCar针对不同的状态处理不同的业务逻辑。更新导航状态数据包含地图状态、导航类型、导航目的地、导航途径点、路线等。

**表1** 更新导航状态相关接口接口 | 方法 | 说明  
---|---|---  
navigationInfoMgr.NavigationController | updateNavigationStatus(navigationStatus: NavigationStatus): void | navigationStatus：导航数据结构，详细字段描述请参考[Car Kit API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/car-navigationinfomgr#section153711644737)。  
  
更新当前导航状态示例代码如下所示：
    
    const navigationStatus: navigationInfoMgr.NavigationStatus = {} as navigationInfoMgr.NavigationStatus;
    navigationStatus.status = navigationInfoMgr.MapStatus.NAVIGATION;
    navigationStatus.naviType = navigationInfoMgr.NaviType.DRIVING;
    navigationStatus.destLocation = {
      name: '地点名称',
      coordType: navigationInfoMgr.LocationCoordType.GCJ02,
      longitude: 114.11,
      latitude: 30.591,
      altitude: 0
    }
    this.navInfoController?.updateNavigationStatus(navigationStatus);

#### [h2]监听系统导航指令

地图应用在启动后需要注册监听系统导航信息和指令，用于接收HiCar给地图应用发送的指令，地图应用根据对应的指令执行相应的功能。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126084407.09322263658886286708481280903067:50001231000000:2800:166E5740FE3452AA7323A4E874DBFA55C596AAAA5DD62D4C640868FCA0AC13BC.png)

在调用Car Kit接口时均需要try catch捕获异常。

**表2** 注册和取消注册Car Kit监听接口接口 | 方法 | 说明  
---|---|---  
navigationInfoMgr.NavigationController | registerSystemNavigationListener(listener: SystemNavigationListener): void | 注册监听系统导航信息和指令。  
navigationInfoMgr.NavigationController | unregisterSystemNavigationListener(listener: SystemNavigationListener): void | 取消监听系统导航信息和指令。  
  
     1. 导入Car Kit模块。
            
            import { navigationInfoMgr } from '@kit.CarKit';

     2. 获取NavigationController实例。
            
            try {
              let navInfoController: navigationInfoMgr.NavigationController = navigationInfoMgr.getNavigationController();
            } catch (err) {
              ......
            }

     3. 注册监听系统导航信息和指令。
            
            //实现SystemNavigationListener接口
            class Listener implements navigationInfoMgr.SystemNavigationListener {
              //实现onQueryNavigationInfo方法
              onQueryNavigationInfo(query: navigationInfoMgr.QueryType, args: Record<string, Object>): Promise<navigationInfoMgr.ResultData> {
                return new Promise(resolve => {
                  let ret: navigationInfoMgr.ResultData = {
                    code: 1001,
                    message: 'message test1',
                    data: args
                  }
                  resolve(ret);
                })
              }
            
              //实现onReceiveNavigationCmd方法
              onReceiveNavigationCmd(command: navigationInfoMgr.CommandType, args: Record<string, Object>): Promise<navigationInfoMgr.ResultData> {
                return new Promise(resolve => {
                  let ret: navigationInfoMgr.ResultData = {
                    code: 1002,
                    message: 'message test2',
                    data: args
                  }
                  resolve(ret);
                })
              }
            }
            try {
              navInfoController.registerSystemNavigationListener(new Listener());
            } catch (err) {
              ......
            }

     4. 当应用退出时取消注册监听。
            
            try {
              navInfoController.unregisterSystemNavigationListener();
            } catch (err) {
              ......
            }

#### [h2]监听显示状态变化

地图应用在全屏状态、分屏状态、地图悬浮窗状态三种状态之间切换时，HiCar会通过Car Kit向地图应用发送CommandType.CHANGE_THEME指令通知地图应用显示状态变化。

**表3** 监听显示状态变化相关接口接口 | 方法 | 说明  
---|---|---  
navigationInfoMgr.SystemNavigationListener | onReceiveNavigationCmd(command: CommandType, args: Record<string, Object>): Promise<ResultData> | **command：** CommandType.CHANGE_THEME **args：** 包含地图应用显示状态，currentDisplayStatus，取值如下： 0：全屏显示 1：分屏显示 2：地图悬浮窗显示 **返回值：** code返回成功0  
  
监听显示状态变化示例代码如下所示：
    
    onReceiveNavigationCmd: (command: navigationInfoMgr.CommandType, args: Record<string, Object>):
      Promise<navigationInfoMgr.ResultData> => {
      return new Promise(resolve => {
        let ret: navigationInfoMgr.ResultData = {
          code: 1001,
          message: 'not supported',
          data: {}
        };
        switch (command) {
          case navigationInfoMgr.CommandType.CHANGE_THEME:
            if (args.currentDisplayStatus !== undefined) {
              let displayStatus = args.currentDisplayStatus;
            }
            ret.code = 0;
            ret.message = 'success';
            break;
        }
        resolve(ret);
      });
    }

#### [h2]响应导航卡片“回家”/“去公司”指令

当用户点击导航空闲卡片的“回家”或“去公司”按钮时，HiCar会通知地图应用开始导航回家或导航去公司。

当用户之前已经在地图应用中设置了家和公司地址时，地图应用在收到指令后直接开始导航 ，发起导航成功返回错误码“0”，发起导航失败则返回错误码“1”。当地图应用中没有记录家和公司地址时，地图应用需要跳转到对应设置界面，提醒用户设置地址，同时返回错误码“2”。

**表4** 实现“回家”/“去公司”功能相关接口接口 | 方法 | 说明  
---|---|---  
navigationInfoMgr.SystemNavigationListener | onReceiveNavigationCmd(command: CommandType, args: Record<string, Object>): Promise<ResultData> | **command：** CommandType.GO_HOME、 CommandType.GO_TO_COMPANY **args：** 无参数 **返回值：** 发起导航成功返回错误码”0”，发起导航失败返回错误”1”，当没有家和公司地址时返回错误码”2”  
  
响应“回家”和“去公司”导航指令的示例代码如下所示：
    
    onReceiveNavigationCmd: (command: navigationInfoMgr.CommandType, args: Record<string, Object>):
        Promise<navigationInfoMgr.ResultData> => {
        return new Promise(resolve => {
          let ret: navigationInfoMgr.ResultData = {
            code: 1001,
            message: 'not supported',
            data: {}
          };
          switch (command) {
            case navigationInfoMgr.CommandType.GO_HOME:
              // 执行导航回家任务
              ......
              ret.code = 0;
              ret.message = 'success';
              break;
            case navigationInfoMgr.CommandType.GO_TO_COMPANY:
              // 执行导航去公司任务
              ......
              ret.code = 0;
              ret.message = 'success';
              break;
          }
          resolve(ret);
        });
      }
    };

#### [h2]响应结束导航指令

HiCar在部分场景需要通知地图应用结束导航，例如：

     * 用户通过语音发起导航时，需要先结束前一个导航任务，以及用户通过语音结束导航。
     * 用户使用多个地图应用开启导航时，后一个地图应用开启导航任务时，需要结束前一个地图应用的导航任务。

**表5** 实现结束导航指令相关接口接口 | 方法 | 说明

navigationInfoMgr.SystemNavigationListener | onReceiveNavigationCmd(command: CommandType, args: Record<string, Object>): Promise<ResultData> | **command：** CommandType.STOP_NAVIGATION **args：** 无参数 **返回值：** 返回错误码”0”  
  
响应结束导航任务指令的示例代码如下所示：
    
    onReceiveNavigationCmd: (command: navigationInfoMgr.CommandType, args: Record<string, Object>):

      return new Promise(resolve => {

          message: 'not supported',
          data: {}

        switch (command) {
          case navigationInfoMgr.CommandType.STOP_NAVIGATION:
            // 结束当前导航任务

            ret.code = 0;

        }
        resolve(ret);
      });

#### [h2]响应导航状态查询指令

HiCar在连接成功后会主动向地图应用查询当前的导航状态，地图应用在接收到指令QueryType.NAVIGATION_STATUS后，需要返回当前的状态信息。

**表6** 响应导航状态查询指令相关接口接口 | 方法 | 说明  
---|---|---  
navigationInfoMgr.SystemNavigationListener | onReceiveNavigationCmd(command: CommandType, args: Record<string, Object>): Promise<ResultData> | **query：** CommandType.NAVIGATION_STATUS **args：** 无参数 **返回值：** code返回0，data包含“mapStatus”、“naviType”、“destination”字段，字段详细描述见表7。  
  
**表7** 返回值数据描述字段名称 | 值 | 说明  
---|---|---  
mapStatus | 0：MapStatus.IDLE 空闲 1：MapStatus.NAVIGATION导航中 2：MapStatus.CRUISE巡航中 3：MapStatus.POI地图选点状态 4：MapStatus.ROUTE路径选择状态 5：MapStatus.UNAVAILABLE状态不可用 | 地图应用状态  
naviType | 0：NaviType.DRIVING 驾车导航 1：NaviType.MOTORCYCLE 摩托车导航 2：NaviType.CYCLING 骑行导航 3：NaviType.WALKING 步行导航 | 导航类型  
destination | navigationInfoMgr.Location | 目的地信息  
  
响应导航状态查询指令示例代码如下所示：
    
    onQueryNavigationInfo: (query: navigationInfoMgr.QueryType,
      args: Record<string, Object>): Promise<navigationInfoMgr.ResultData> => {
      return new Promise((resolve) => {
        let resultData: Record<string, Object> = {};
        let ret: navigationInfoMgr.ResultData = {
          code: 1001,
          message: 'not supported',
          data: resultData
        };
        switch (query) {
          case navigationInfoMgr.QueryType.NAVIGATION_STATUS:
            const destination: navigationInfoMgr.Location = {
              name: '地点名称',
              coordType: navigationInfoMgr.LocationCoordType.GCJ02,
              longitude: 114.1,
              latitude: 30.5,
              altitude: 0
            }
            const navigationStatus: Record<string, Object> = {
              'mapStatus': navigationInfoMgr.MapStatus.IDLE,
              'naviType': navigationInfoMgr.NaviType.DRIVING,
              'destination': destination,
            }
            // 返回数据
            ret.code = 0;
            ret.message = 'success';
            ret.data = navigationStatus;
            resolve(ret);
            break;
        }
        resolve(ret);
      });
    }

#### [h2]响应导航元数据查询指令

HiCar在监听到地图应用进入导航状态时，会主动向地图应用查询一次导航元数据，防止首次数据丢失。通过查询指令QueryType.NAVIGATION_METADATA向地图应用获取数据。

**表8** 响应导航元数据查询指令相关接口接口 | 方法 | 说明  
---|---|---  
navigationInfoMgr.SystemNavigationListener | onReceiveNavigationCmd(command: CommandType, args: Record<string, Object>): Promise<ResultData> | **query：** CommandType.NAVIGATION_METADATA **args：** 无参数 **返回值：** code返回0，data包含navigationInfoMgr.Location参数，字段详情请参考[Car Kit API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/car-navigationinfomgr#section546213416209)。  
  
响应导航元数据查询指令示例代码如下所示：
    
    onQueryNavigationInfo: (query: navigationInfoMgr.QueryType,
      args: Record<string, Object>): Promise<navigationInfoMgr.ResultData> => {
      return new Promise((resolve) => {
        let resultData: Record<string, Object> = {};
        let ret: navigationInfoMgr.ResultData = {
          code: 1001,
          message: 'not supported',
          data: resultData
        };
        switch (query) {
          case navigationInfoMgr.QueryType.NAVIGATION_METADATA:
            const naviMetaData: navigationInfoMgr.NavigationMetadata = {
              naviTurnMode: 0x03E7,
              segmentLeftDis: 0,
              currentRoadName: '当前道路名称',
              nextRoadName: '进入xxx导航',
              intersectionView: '',
              viewWidth: 0,
              viewHeight: 0,
              trafficLane: '',
              cameraSpeedLimitValid: false,
              cameraSpeedLimit: 0,
              naviSpeedLimitValid: false,
              naviSpeedLimit: 0,
              currentSpeed: 0,
              naviBearing: 0,
              totalLeftDis: 0,
              remainingTime: 0
            }
            ret.code = 0;
            ret.data = JSON.parse(JSON.stringify(naviMetaData));
            break;
        }
        resolve(ret);
      });
    }
