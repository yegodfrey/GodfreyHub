# GPS及车身数据

## 场景说明

HiCar手机与车机连接后，可以共享使用车载GPS的数据用于导航定位，以解决部分场景下手机GPS信号不好的问题，例如车辆内手机摆放位置不好，信号有衰减等都会导致手机GPS信号异常。HiCar手机会根据车机上报的汽车GPS数据与手机自身的GPS数据进行对比融合定位，从而为HiCar应用提供高精度的GPS定位能力。

当车机具备GPS传感器时，厂商需实现GPS数据上报相关的接口供HiCar调用。

厂商需要根据HiCar SDK提供的GPS设备接口头文件，实现GPS相关接口，编译成"libdmsdpgpshandler.so"文件。HiCar SDK会在运行时，试图加载该so库文件，如果加载失败或未找到文件，则认为车机未实现GPS相关接口。如果找到该文件，则动态加载该so链接库。

1. HiCar SDK初始化时，会试图加载libdmsdpgpshandler.so，如果存在，则认为厂商适配了GPS功能，会向其注册状态回调函数，接收来自厂商的状态事件上报。
2. 当手机APP使用位置服务时，HiCar SDK会向so注册数据回调函数。当车机的位置/车速/传感器等信息发送变化时，按照既定频率向HiCar SDK异步上报数据。HiCar SDK期望的位置信息（经纬度、高度、行进方向等）的上报频率是1Hz，车身数据（车速、方向盘转向角等）的上报频率是10Hz，车身传感器数据（加速度、陀螺仪等）的上报频率是40Hz。

## 接口说明

HiCar SDK定义的GPS接口主要包括注册/注销GPS数据回调接口，获取/设置GPS数据上报周期等。

```screen
dmsdp_gps_handler.h        --定义了gps接口
```

|接口|入参|说明|
|:------------------------|:--------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------|
|RegisterGPSDataCallback|callback|包含位置、车身数据、传感器数据的回调函数集合，当手机侧应用需要使用位置服务时（比如进入地图）HiCar SDK会向车机进行注册，注册后车机向HiCar SDK上报GPS数据。|
|UnRegisterGPSDataCallback|-|注销上述回调。当手机侧应用不再需要位置服务时（比如结束导航）会调用该接口，车机不再需要向HiCar SDK上报GPS数据。|
|GetGPSDataReportFreq|locationFreq：GPS数据上报频率（单位：Hz） drivingFreq：车身数据上报频率（单位：Hz） sensorFreq：车身传感器数据上报频率（单位：Hz）|获取各类数据上报频率。|
|SetGPSDataReportFreq|locationFreq：GPS数据上报频率（单位：Hz） drivingFreq：车身数据上报频率（单位：Hz） sensorFreq：车身传感器数据上报频率（单位：Hz）|动态设置GPS数据上报频率，如设置频率参数大于支持的最大值，返回错误。|
|RegisterListener|listener|用于HiCar SDK接收来自车机的状态通知。比如外设连接到设备上，外设和设备断开连接等事件。|
|BusinessControl|-|GPS业务控制，扩展接口。|

## 开发步骤

厂商需要实现的接口如下：

```screen
typedef struct {
    void (*GPSLocation)(char *location, int32_t len);
    void (*GPSDriving)(char *driving, int32_t len);
    void (*GPSSensor)(char *sensor, int32_t len);
    void (*CarBaseInfo)(char *info, int32_t len);
}DMSDPGPSCallback;

typedef struct {
    int32_t (*RegisterGPSDataCallback)(DMSDPGPSCallback* callback);
    int32_t (*UnRegisterGPSDataCallback)();
    int32_t (*GetGPSDataReportFreq)(int32_t* locationFreq, int32_t* drivingFreq, int32_t* sensorFreq);
    int32_t (*SetGPSDataReportFreq)(int32_t locationFreq, int32_t drivingFreq, int32_t sensorFreq);
    int32_t (*RegisterListener)(const DMSDPListener *listener);
    int32_t (*BusinessControl)(uint32_t cmd, char *inputPara, uint32_t inLen, char *outputPara, uint32_t outLen);
} DMSDPGpsHandler;
```
