# VoIP通话

## 场景说明

HiCar支持VoIP类（例如畅连等）应用进行语音通话，HiCar SDK会识别并向厂商HMI应用通知此类VoIP通话的状态。

厂商HMI应用通过onDeviceServiceChange回调方法接收到EVENT_DEVICE_SERVICE_VOIP_CALLING事件后，需要进行回声消除和降噪处理。

## 接口说明

|类|方法|说明|
|:----------|:--------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|onDeviceServiceChange|HiCar SDK通过回调的方式向厂商HMI应用通知VOIP通话相应的事件： * EVENT_DEVICE_SERVICE_VOIP_CALLING（值为214）：VOIP通话接听后发送该事件，厂商HMI应用收到该事件后进行回声消除和降噪处理。 * EVENT_DEVICE_SERVICE_VOIP_HANG_UP（值为215）：VOIP通话挂断后发送该事件，厂商HMI应用收到该事件后停止回声消除和降噪处理。|
[**表1**处理VoIP通话冲突相关接口]

## 开发步骤

1. 厂商HMI应用在HiCar SDK初始化时注册事件回调，详见[注册事件侦听回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/register-event-listener-0000000000030698)。
2. 当厂商HMI应用从onDeviceChange回调方法中收到EVENT_DEVICE_SERVICE_VOIP_CALLING事件后，进行回声消除和降噪处理。
3. 当厂商HMI应用从onDeviceChange回调方法中收到EVENT_DEVICE_SERVICE_VOIP_HANG_UP事件后，停止回声消除和降噪处理。

## 处理通话冲突

HiCar App默认提供通话服务，可能会与车机通话功能（车载蓝牙通话、车机本地SIM卡通话等）产生冲突，所以为了避免通话冲突，车机需要将本地通话服务状态通知到HiCar。同时在HiCar App提供通话服务时，当用户按下方控按键，车机也需要根据HiCar App通话状态进行通话/挂断事件的上报，所以车机需要从HiCar App获取通话状态。

关于通话冲突相关的内容请参考[通话状态与焦点](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/call-status-and-focus-0000001051530010)。
