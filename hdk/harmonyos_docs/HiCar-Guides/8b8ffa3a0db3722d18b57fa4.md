# 处理投屏事件回调

## 场景说明

厂商HMI应用可以通过事件回调的方式获取投屏结果，并根据投屏结果在事件回调中处理自己的业务逻辑，例如在投屏失败后销毁投屏界面并返回车机原始HMI界面。

## 接口说明

|接口|方法|说明|
|:----------|:------------------|:--------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|DeviceServiceChange|HiCar SDK通过回调的方式向厂商HMI应用通知投屏相应的事件。 HICAR_DEVICE_DISPLAY_SERVICE_PLAYING（值为207）：厂商HMI应用收到该事件后，表明投屏成功。厂商HMI应用在收到该事件后，可以开始接收视频流，并正常进行投屏显示。|
