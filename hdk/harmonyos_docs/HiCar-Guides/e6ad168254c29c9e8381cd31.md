# 上市质量管理要求

* 在验收测试完成之前，相关硬件产品不允许搭载HiCar功能上市销售。如未通过验收测试，相关硬件产品的HiCar功能无法实现身份鉴权，消费者将无法使用。

* 上市后质量管理要求：后续因车机升级（包括但不限于OTA版本升级）引入的质量问题，由贵司承担解决，华为可提供必要的技术支持，同时华为将根据质量处理情况，保留取消手机和车机连接的云端配置的权利。
