# 认证

**图1**认证流程

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194817.49252252011418284984695885700224:50001231000000:2800:D00576B2D0E8BD87675380720F2FADD9B4E2FE91058B2FD60D229D2F482BB787.png)

为保障集成HiCar的产品体验，只有通过华为认证的HiCar产品才可以上市销售，华为有权对未经认证但已上市的HiCar产品进行技术封禁。

|厂商|主要职责|
|:---|:------------------------------------------------------------------|
|车厂|车企需对集成HiCar的产品进行测试，并确保100%自测试用例高质量通过，提供相关自测试报告。|
|测试机构|负责HiCar自测试审核和验收测试，提供验收测试报告和留证材料|
|华为|审核测试机构提供的HiCar验收测试报告和留证材料，并针对相关测试项进行抽查，给出是否认证通过的结论，并对认证通过的项目发放电子证书。|

|物料|数量|说明|
|:---|:-|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|车机台架|1台|需采用台架封装，台架必须包含全套配件，保证车机可用。全套配件包括但不限于台架箱、主机、屏幕、电源、麦克风、扬声器、方控键、GPS天线、相关线束等。车机台架示例如下所示： ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194817.24382671135454615235140157827884:50001231000000:2800:C13FD5AED805A3816BF2083C0CF1565FA89AEBB0953307F2F6423C94FD86605C.png "点击放大")|
|整车|1台|* 整车整体软硬件配置需与商用保持一致。 * 整车车况允许上路，且务必保证上路安全可用。 * 寄送时需确保满足满电/满油状态 * 车辆临牌有效期90天（如需延期，请协助重新申请临牌），且临牌需可支撑路测（确保临牌行驶区域中包含送测城市）。 * 车辆保险：整车必须提供交强险和商业保险保单 * 车辆物联网卡：如车辆支持物联网卡，需提供带流量的物联网卡，卡流量至少500M/月。 * 整车车内车外请确保整洁有序，无裸露线束等。 * 对于整车车况（如刮痕、磨损、车辆异常告警等）提供必要说明和解释。 * 整车使用期间的注意事项请一并提供。|

> 说明
>
> 认证完成后归还1台整车，保留2台车机（开工会后1台+认证环节1台，合计2台）台架直到该车型发布2年后（车型发布2年内，车机的软件升级，将会基于保留的车机台架进行升级版本的抽检测试）。
