# 处理音频分流策略（Beta）

## 场景描述

**图1** HarmonyOS音频分流方案

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/XMoSiTe2QGeO1OrvIQuJDw/zh-cn_image_0000002685571753.png?HW-CC-KV=V1&HW-CC-Date=20261008T140319Z&HW-CC-Expire=31536000000&HW-CC-Sign=AA8564EEE45E98D233825165EE230527DEF84B95170BA354F302E9F0FB531E63 "点击放大")

HarmonyOS系统上音频框架最大支持三路分流，分流参数必需设置为3个。**推荐车厂设置为8：4096：1，媒体单独一股流，导航一股流，通话一股流，其他类型的流混音从媒体通道发送。**车机在接收到手机侧音频流后，需要根据音频流的属性streamusage和streamtype判断当前音频流所属音区，车机侧音量调节以音区为单位进行媒体、导航、通话三类音量分级调节。

车机可以在初始化SDK成功之后，调用接口使能音频分流策略。车机侧可以根据HiCar音频流开放接口读取音频流，并基于音频流类型送入不同音频通路。如果不需要音频分流，可以忽略本章节内容。需要注意的是：操作系统Harmony OS 3.0及以上版本的手机支持音频分流能力。

## 接口说明

|接口|结构体|说明|
|:----------------------------------------------------------------------------------|:-------------------------------|:----------------------------------------------------------------|
|int32_t (*GetAudioCapability)(DMSDPAudioCapabilities** capabilities, uint32_t *num)|DMSDPAudioCapabilities.reserveds|厂商通过该接口上报是否需要进行音频分流，后续通过WriteStreamBuffer获取数据并通过streamType区分各音频流。|
[**表1**上报音频分流能力的接口]

音频流分流策略支持3组音频流分流定义，音频流按StreamType类型进行分组。通过在上报音频能力时，利用DMSDPAudioCapabilities中保留字段reserveds进行上报。保留字段通过Key-Value格式上报，涉及到的Key定义如下，具体填充参见下方demo代码。

```screen
#define MULTI_AUDIO_BUS_CAP_KEY       "1000"  // HiCarSDK定义的key值，表示是否支持音频分流能力
#define MULTI_AUDIO_BUS_CAP_VALUE     "true"  // 车机传值"true"表示支持，"false"表示不支持
#define MULTI_AUDIO_BUS_POLICY_KEY    "1001"  // HiCarSDK定义的key值，表示音频分流策略
#define MULTI_AUDIO_BUS_POLICY_VALUE  "8:4096:1" // 车机根据上文描述，传递车机的分流能力，建议按照8：4096：1适配
#define MULTI_AUDIO_BUS_VERSION_KEY   "1002"  // HiCarSDK定义的key值，表示车机音频分流能力的版本号
#define MULTI_AUDIO_BUS_VERSION_VALUE "1.0"   // 车机传递给SDK，比如"1.0"或者"2.0"
```

HiCar支持的StreamType范围如下：

* 电话呼叫的音频流：AUDIO_STREAM_VOICE_CALL = 0
* 系统声音的音频流：AUDIO_STREAM_SYSTEM = 1
* 电话铃声的音频流：AUDIO_STREAM_RING = 2
* 音乐播放的音频流：AUDIO_STREAM_MUSIC = 3
* 警报的音频流：AUDIO_STREAM_ALARM = 4
* 通知的音频流：AUDIO_STREAM_NOTIFICATION = 5
* 电话过程中按键音频流：AUDIO_STREAM_DTMF = 8
* 语音播报音频流：AUDIO_STREAM_TTS = 9
* 辅助音频流：AUDIO_STREAM_ACCESSIBILITY = 10
* 语音助手流： AUDIO_STREAM_ASSISTANT = 11
* 导航播报流：AUDIO_STREAM_NAVIGATION_GUIDANCE = 12

## 开发步骤

上报音频分流能力的示例代码如下所示：

```screen
// 以下示例代码未考虑内存释放操作
#define MULTI_AUDIO_BUS_CAP_KEY       "1000"  // HiCarSDK定义的key值，表示是否支持音频分流能力
#define MULTI_AUDIO_BUS_CAP_VALUE     "true"  // 车机传值"true"表示支持，"false"表示不支持
#define MULTI_AUDIO_BUS_POLICY_KEY    "1001"  // HiCarSDK定义的key值，表示音频分流策略
#define MULTI_AUDIO_BUS_POLICY_VALUE  "8:4096:1" // 车机根据上文描述，传递车机的分流能力
#define MULTI_AUDIO_BUS_VERSION_KEY   "1002"  // HiCarSDK定义的key值，表示车机音频分流能力的版本号
#define MULTI_AUDIO_BUS_VERSION_VALUE "1.0"   // 车机传递给SDK，比如"1.0"或者"2.0"

DMSDPReserved *policyReserved = NULL;
policyReserved = (DMSDPReserved *)malloc((sizeof(DMSDPReserved)) * 3);

DMSDPAudioCapabilities *capabilities;  // 已分配好内存
capabilities->reserveds.num = 3;
capabilities->reserveds.reserveds = policyReserved;

// 填充是否支持音频分流能力
uint32_t len = strlen(MULTI_AUDIO_BUS_CAP_KEY);
char *capKey = (char *)malloc(len + 1);
strcpy_s(capKey, len + 1, MULTI_AUDIO_BUS_CAP_KEY);
policyReserved[0].key = capKey;
policyReserved[0].keyLen = len;

len = strlen(MULTI_AUDIO_BUS_CAP_VALUE);
char *capValue = (char *)malloc(len + 1);
strcpy_s(capValue, len + 1, MULTI_AUDIO_BUS_CAP_VALUE);
policyReserved[0].value = capValue;
policyReserved[0].valueLen = len;

// 填充音频分流策略
len = strlen(MULTI_AUDIO_BUS_POLICY_KEY);
char *policyKey = (char *)malloc(len + 1);
strcpy_s(policyKey, len + 1, MULTI_AUDIO_BUS_POLICY_KEY);
policyReserved[1].key = policyKey;
policyReserved[1].keyLen = len;

len = strlen(MULTI_AUDIO_BUS_POLICY_VALUE);
char *policyValue = (char *)malloc(len + 1);
strcpy_s(policyValue, len + 1, MULTI_AUDIO_BUS_POLICY_VALUE);
policyReserved[1].value = policyValue;
policyReserved[1].valueLen = len;

// 填充音频分流版本号
len = strlen(MULTI_AUDIO_BUS_VERSION_KEY);
char *versionKey = (char *)malloc(len + 1);
strcpy_s(versionKey, len + 1, MULTI_AUDIO_BUS_VERSION_KEY);
policyReserved[2].key = versionKey;
policyReserved[2].keyLen = len;

len = strlen(MULTI_AUDIO_BUS_VERSION_VALUE);
char *versionValue = (char *)malloc(len + 1);
strcpy_s(versionValue, len + 1, MULTI_AUDIO_BUS_VERSION_VALUE);
policyReserved[2].value = versionValue;
policyReserved[2].valueLen = len;

// 填充完保留字，通过GetAudioCapability接口上报给HiCarSDK
```
