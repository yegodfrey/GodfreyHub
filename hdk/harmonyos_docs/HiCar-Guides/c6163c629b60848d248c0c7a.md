# 注册事件侦听回调

## 场景说明

厂商HMI应用需要通过SDK接口注册事件侦听回调，并根据回调中的不同事件进行业务处理，例如在接收到连接成功事件后开始投屏操作。

## 接口说明

厂商HMI应用需要注册的事件侦听回调方法如[表1](#ZH-CN_TOPIC_0000001050744537__table101151034195012)所示。更多关于回调的参数及说明，请参考《HUAWEI HiCar SDK API参考》。如何根据回调事件进行业务处理的内容，请参考本文档后续章节。

|接口|回调方法|说明|
|:-----------|:-------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|onDeviceChange()|当手机与车机连接发生变化时回调该方法。对应的连接事件说明请参考[表2](#ZH-CN_TOPIC_0000001050744537__table42321929463)。|
|CarListener|onDeviceServiceChange()|当服务发生变化时回调该方法，服务包括投屏服务、Modem通话服务。对应的服务事件说明请参考[表2](#ZH-CN_TOPIC_0000001050744537__table42321929463)。|
|CarListener|onDataReceive()|当SDK接收到手机侧HiCar App发送数据时回调该方法。厂商HMI应用可通过该方法与HiCar App进行数据交互，接收来自HiCar App的车控指令、导航焦点变化通知等数据，更多内容请参考[数据交互](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/data-interaction-0000001192952815)。|
|CarListener|onPinCode()|当SDK产生PIN码时回调该方法。厂商HMI应用获取PIN码后展示到连接界面中。|
|CarListener|getSecureFileSize()|与认证文件相关的回调方法。|
|CarListener|readSecureFile()|与认证文件相关的回调方法。|
|CarListener|writeSecureFile()|与认证文件相关的回调方法。|
|CarListener|removeSecureFile()|与认证文件相关的回调方法。|
|CarListener|getReconnectType()|预埋能力接口，暂无实际含义。|
|CarListener|onAbilityGet(int ability)|预埋能力接口，暂无实际含义。|
|CarListener|bluetoothRecommendStartConnect()|预埋能力接口，暂无实际含义。|
|CarListener|getDisconnectRetryCount()|异常断开连接时，SDK默认会尝试回连3次，厂商HMI应用可使用该方法设置回连次数，范围是1-3。|
|HiCarAdapter|registerCarListener|厂商HMI应用应该在初始化SDK时注册HiCar事件侦听。|

## 开发步骤

1. 新建类实现CarListener接口。

   当前可以先保留各回调方法空实现，后续根据实际业务填充对应的业务逻辑。示例代码如下所示。

   ```screen
   public class HiCarListener implements CarListener{

   	@Override
   	public void onDeviceChange(String s, int i, int i1) {

   	}

   	@Override
   	public void onDeviceServiceChange(String s, int i) {

   	}

   	@Override
   	public void onDataReceive(String s, int i, byte[] bytes) {

   	}

   	@Override
   	public void onPinCode(String s) {

   	}

   	@Override
   	public long getSecureFileSize(String s) {
   		return 0;
   	}

   	@Override
   	public byte[] readSecureFile(String s) {
   		return new byte[0];
   	}

   	@Override
   	public boolean writeSecureFile(String s, byte[] bytes) {
   		return false;
   	}

   	@Override
   	public boolean removeSecureFile(String s) {
   		return false;
   	}

           @Override
   	public int getDisconnectRetryCount() {
   		return 3;
   	}
   }
   ```

2. 在初始化成功的回调方法中注册CarListener接口的实现类。

   示例代码如下所示。

   ```screen
   HiCarAdapter.init(getApplicationContext(), mCarConfig, new HiCarInitCallback() {
   	@Override
   	public void onInitSuccess(HiCarAdapter hiCarAdapter) {
   		Log.i(TAG, "HiCar onInitSuccess");
   		if (hiCarAdapter == null) {
   			Log.d(TAG, "onInitSuccess: hiCarAdapter is null");
   			return;
   		}
   		mHiCarAdapter = hiCarAdapter;
   		int retCode = mHiCarAdapter.registerCarListener(mHiCarListener);
   		if (retCode != HiCarConst.SUCCESS) {
   			Log.d(TAG, "HiCar reg listener failed");
   			return;
   		}
   		
   		Log.i(TAG, "HiCar reg listener success");
   	}

   	@Override
   	public void onInitFail(int i) {
   		Log.i(TAG, "HiCar init failed");
   	}

   	@Override
   	public void onBinderDied() {
   		Log.i(TAG, "HiCar service bind died");
   	}
   });
   ```
