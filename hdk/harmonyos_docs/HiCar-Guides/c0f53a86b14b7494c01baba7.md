# 共享上网

**车机使用手机流量场景：**支持车机应用使用华为手机流量，但需要在多处提示用户正在共享流量。

**规则9-1**当用户在车机侧开启"手机流量共享"开关，需要弹窗提示告知用户：开启"手机流量共享"开关，则车机应用默认优先使用手机流量，确定开启？

**建议**开关位置置于连接列表中，位置由车企根据情况自行定义。

**图1**流量共享开关与弹窗   
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/P91v4Jm4QZGHN8vM9XlxjA/zh-cn_image_0000002368194550.png?HW-CC-KV=V1&HW-CC-Date=20261008T181453Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8485A0F8F4333099B5F0722C9F235DA2A8AD3280F39A15996C6CA4D87BA4C7E "点击放大")

**规则9-2** 用户开启开关后，状态栏或信号栏需要常显流量消耗图标（样式参照下图），车企可根据自身UI规范进行图标样式调整，但需要表意相同。

**建议** 当用户打开车机应用，可通过toast告知用户：正在使用手机流量，请注意流量消耗。若车机应用不涉及到消耗手机流量，则可以不提醒。
