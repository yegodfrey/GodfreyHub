# 创建车型信息

1. 在"车机管理"中单击已创建的车机卡片。

   **图1**车机卡片   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.67067648952498788540574099038390:50001231000000:2800:9E67D36BFF9B81619AE66A24D25B06027C4323E1C6492ABEC2B1DB98FCE59873.png?needInitFileName=true?needInitFileName=true "点击放大")

2. 进入车机详情页面后，单击"+"创建车型信息。

   **图2**车型信息创建   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.07270501232334250554531805047653:50001231000000:2800:23A9382695A13A041BE87C775803640887917FCBA0A3DAB6B65A5BDB3772282D.png?needInitFileName=true?needInitFileName=true "点击放大")

3. 进入创建车型页面后，请填写车机对应的车型信息。

   **图3**车型信息

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.60139126377917573960253019639202:50001231000000:2800:A892995E6C3AEB29019B1D859418BBFD4A441C3C5706546DD8ECBF21660E52B9.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 继续填写"开发计划"与"量产计划"，并选择委托测试机构。

   如果是等效验收测试，请选择等效车型汽车型号（仅"车机平台"相同的车型可被关联点选），并上传《HUAWEI HiCar等效验收测试申请表》。

   **图4**等效验收测试   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.60062691116275997000281447458779:50001231000000:2800:B39CA470311D42652231D9AF8930BE73456143CBB551E29FEA477FDC8FB36785.png?needInitFileName=true?needInitFileName=true "点击放大")

   > 说明
   >
   > 等效验收测试需要在首次验收测试已经完成的前提下进行，且车机供应商和HiCar HMI应用开发团队不允许变更。

5. 填写完毕后，单击"提交"。

   提交验收测试申请之后，可以通过点击车型卡片进入"车型详情"页面。

   **图5**验收申请记录   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.45794754150518246496951230911444:50001231000000:2800:B8DB79A187AB73DB5665B71F593A25F4DB3057934D8A13604D1C324007C54E7F.png?needInitFileName=true?needInitFileName=true "点击放大")

6. 根据设计规范，提交全量功能页面布局和交互流程设计文件（图片格式、pdf；尺寸无限制），打成zip包提交。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.99842822839618574514905719185881:50001231000000:2800:665801F5DC2A6A41D40A8A727C9402B505F71B626DE34FD6F8868706EF79DCD7.png?needInitFileName=true?needInitFileName=true "点击放大")
