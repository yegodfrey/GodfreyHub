# mDNS广播IP和Port

## 场景说明

通过发送USB控制命令字的方式只能保证支持该种方式的手机正常与车机建立HiCar有线连接，部分运行10.X版本EMUI系统的华为手机不支持静态IP和端口，将无法正常与车机建立HiCar有线连接。

为了兼容这部分手机，车机端在向手机端发送USB控制命令字的同时，需要启动mDNS Server，广播车机端IP地址和HiCar SDK侦听的Server Socket端口（IP地址和端口在HiCar SDK初始化USB driver时，告知车机），在检测到手机断开USB连接时关闭mDNS Server。

不支持静态IP和端口的手机将通过mDNS广播获取IP地址和端口，从而进行Socket通道连接。

## 接口说明

通过USB连接时开启mDNS服务，mDNS相关配置说明如[表1](#ZH-CN_TOPIC_0000001059290770__table36344362228)所示。

|mDNS配置项|取值|含义|
|:--------|:---------------------------------------------------------------------|:-----|
|name|com.huawei.nearby.usb.nsd|服务名称|
|type|_nearby._tcp|服务类型|
|domain|local|服务域|
|txtRecord|以"ncm.ip"为标签将本机ip地址以txtRecord格式记录，由mDNS服务的txtRecord参数和txtLen带入mDNS配置信息|附带文本信息|
|port|由HiCar SDK传递的端口号|端口号|
[**表1**mDNS配置说明]

## 开发步骤

厂商需自行选择mDNS组件，启动mDNS服务，下文给出的示例代码仅供参考。

示例代码如下所示：

```screen
DNSServiceFlags flags = 0;
uint32_t ifindex = kDNSServiceInterfaceIndexAny;
const char* name = HICAR_MDNS_NAME;
const char* regtype = HICAR_MDNS_REG_TYPE;
const char* domain = HICAR_MDNS_DOMAIN;
const char* host = NULL;
uint16_t port = (nearby传递的port);

uint8_t txtBuf[256] = {0};
TXTRecordRef txtRec;
TXTRecordCreate( &txtRec, (uint16_t) sizeof( txtBuf ), txtBuf );
DNSServiceErrorType err = TXTRecordSetValue( &txtRec, HICAR_MDNS_NCMIP_TAG, (uint8_t) strlen( ip ), ip ); //ip为本机ip
if (err != kDNSServiceErr_NoError) {
	HWLog(LOG_LEVEL_ERROR, "TXTRecordSetValue failed: %d\n", err);
	return;
}
txtPtr = (const char*)TXTRecordGetBytesPtr( &txtRec );
txtLen = TXTRecordGetLength( &txtRec );

err = DNSServiceRegister((DNSServiceRef*)&handle, flags, ifindex, name, regtype, domain, host,htons(port), txtLen, txtPtr, _RegistrationHandler, this);
if (err != kDNSServiceErr_NoError) {
	HWLog(LOG_LEVEL_ERROR, "DNSServiceRegister failed: %d\n", err);
} else {
	HWLog(LOG_LEVEL_DEBUG, "DNSServiceRegister %s\n", regtype);
}
```
