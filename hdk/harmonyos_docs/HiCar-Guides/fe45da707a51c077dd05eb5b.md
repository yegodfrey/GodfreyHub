# Android 10.0适配须知

如果厂商车机ROM是Android 10.0版本，在进行无线连接之前，应进行蓝牙和Wi-Fi适配修改。其中蓝牙适配修改可参考[蓝牙](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/bluetooth-0000001193969601)，Wi-Fi适配可参考以下操作进行。
> 说明
>
> 以下修改方案参考及代码供厂商参考，具体修改内容还需厂商根据自身系统情况独立完成适配。
