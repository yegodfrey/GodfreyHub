# 设置全屏

## 场景说明

用户点击全屏按钮后，车机改变手机桌面窗口宽高为全屏后，通知手机进行全屏投屏切换，并将全屏宽高传递给手机。

## 接口说明

当前接口需发送546消息，参数包含两个字段：

* stateCode：值为2，通知手机从同源投屏切换为异源投屏。
* stateData：值为json字符串，包含width和height两个参数，分别表示全屏时窗口宽高。

## 开发步骤

通知手机进行全屏切换。

```screen
// 通知手机进行全屏切换
public void onFullScreen(int width, int height) {
    JSONObject jsonData = new JSONObject();
    jsonData.put("stateCode", 2);
    JSONObject jsonStateData = new JSONObject();
    jsonStateData.put("width", mFullScreenWidth);
    jsonStateData.put("height", mFullScreenHeight);
    jsonData.put("stateData", jsonStateData.toJSONString()); 
    hiCarAdapter.sendCarData(546, jsonData.toJSONString());
}
```
