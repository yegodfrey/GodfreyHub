# 连接手机蓝牙启动厂商HMI应用

## 场景说明

为了简化用户首次连接HiCar的步骤，车机可以在检测到连接手机蓝牙后，直接启动厂商HMI应用。
> 说明
>
> * 为实现该功能，需要车机蓝牙支持与UUID（FA87C0D0-AFAC-11DE-8A39-0800200C9A66）进行Secure RFcomm通信。
> * 需要车机蓝牙类型（BluetoothClass.Device）为指定蓝牙类型：1032（AUDIO_VIDEO_HANDSFREE）或1056（AUDIO_VIDEO_CAR_AUDIO）。

当支持HiCar的手机与支持HiCar的车机，建立蓝牙连接时，车机侧HiCar SDK和手机侧HiCar App会通过蓝牙RFcomm通道进行数据交互，在确认双方都支持HiCar后手机侧将直接推荐用户使用HiCar，用户在手机侧同意使用HiCar后，车机侧需要直接进入到连接界面（连接码或者扫码连接界面），从而简化用户的首次连接流程。

用户体验路径如下：

1. 手动修改车机蓝牙名称为HiCarTest，用户手机和车机连接蓝牙后，若满足推荐条件，则手机端会出现如下弹窗，询问用户是否体验HiCar（HiCarTest为测试使用车机蓝牙名称，正式使用需要厂商提供蓝牙默认名称，在经过验证后会添加到蓝牙推荐白名单的规则里，白名单生效后现网可正常使用）。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214052.96729500728756716694235960605350:50001231000000:2800:F695AF9535B36D3C264D5D918EDB0C986EB55D56FE6360F62D61DB41881EF075.png)

2. 若用户点击"同意"，则车机端应该拉起HiCar HMI应用界面（PIN码或二维码界面）；若用户点击"取消"，则车机端不会收到任何回调通知，即无需进行任何动作。

为实现该功能，厂商需根据本章节内容完成功能开发。

## 接口说明

|类|方法|说明|
|:-----------|:----------------------|:-------------------------------------------|
|HiCarAdapter|startBluetoothRecommend|启动Rfcomm监听，等待手机侧连接交互。|
|CarListener|onShowStartPage|接收到显示连接起始界面的回调，厂商HMI应用需实现此回调接口，跳转到HiCar连接界面。|
[**表1**相关接口]

> 说明
>
> Rfcomm建立成功后，手机会弹窗询问用户是否同意使用。用户点击确认之后才会给HMI发送显示连接起始界面的回调（onShowStartPage），不需要HMI提前自行拉起HiCar连接界面。

## 开发步骤

1. 厂商需配置CarConfig，初始化HiCar SDK，初始化成功后，获得HiCarAdapter实例。另需实现监听蓝牙连接的广播，并在检测到有蓝牙连接成功后调用startBluetoothRecommend方法。

   ```screen
   private BlueToothStateReceiver blueToothStateReceiver= new BlueToothStateReceiver();
   private int loadHiCarSdk() {
           ...
       HiCarAdapter.init(getApplicationContext(), mCarConfig, new HiCarInitCallback() {
           @Override
           public void onInitSuccess(HiCarAdapter hiCarAdapter) {
               ...
             mHiCarAdapter = hiCarAdapter
           }
       });
       //注册蓝牙连接广播监听
       IntentFilter filter = new IntentFilter(BluetoothDevice.ACTION_ACL_CONNECTION);
       registerReceiver(blueToothStateReceiver, filter);
   }
   /**
    * 广播监听蓝牙状态
    */
   public class BlueToothStateReceiver extends BroadcastReceiver {
       @Override
       public void onReceive(Context context, Intent intent) {
           String action = intent.getAction();
           if (BluetoothDevice.ACTION_ACL_CONNECTION.equals(action)) {
               mHiCarAdapter.startBluetoothRecommend();
           }
       }
   }
   ```

2. 实现CarListener中的onShowStartPage接口，在此回调方法中跳转到HiCar连接界面（连接码界面或者扫码连接界面）。

   ```screen
   public class HiCarListener implements CarListener {
       ...
       @Override
       public void onShowStartPage() {
           //拉起PIN码或二维码界面
           Context context = getApplicationContext();
           Intent activityIntent = new Intent(context, HiCarDemoActivity.class);
           activityIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_SINGLE_TOP);
           try {
               context.startActivity(activityIntent);
           } catch (ActivityNotFoundException anfe) {
               Log.e(TAG, "onDeviceChange:ActivityNotFoundException");
           }        
       }
   }
   ```
