# 融合桌面介绍

从HiCar Android SDK 4.0.0.300版本开始，HiCar新增了一种全新的融合桌面形态，即允许厂商调用接口获取来自HiCar的应用列表以及来自手机应用的各类元数据，与车机原生的应用进行融合展示，从而提升消费者的应用使用体验。
> 说明
>
> 融合桌面是在HiCar传统智慧桌面基础之上，开放的新扩展能力，所以厂商在集成融合桌面特性之前，需要按照前文章节完成HiCar的功能集成。集成完成后，再按照本章节"开发融合桌面"提供的指导进行融合桌面特性开发。

## 逻辑结构

**图4**融合桌面逻辑结构   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214059.89148682659473980661449749410532:50001231000000:2800:8F6B4A99F10D459C26B327D49C49B244A6AAFF49B26BBF967117ED1E5F50F3E3.png "点击放大")

厂商HMI应用通过集成HiCar SDK，可以获取支持HiCar的应用列表，参考[应用融合形式](#section1943315622213)中的融合形式在车机原生界面中进行展示。当用户点击这部分应用图标时，拉起HiCar到前台展示，退出这部分应用时，将HiCar隐藏到后台。另外，通过SDK相关接口，厂商HMI应用可以获取来自HiCar的各类元数据，包括导航元数据、音频元数据、通话元数据、消息元数据、情景类元数据（日历、天气、情景智能）等，并将这些元数据显示在原生车机界面，或其它可显示元数据的位置，例如仪表盘/HUD等。

## 连接流程

**图5**融合桌面交互流程示意   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214059.77093365028825584038263352528213:50001231000000:2800:DDEB8D5E204D47D1A064BA76EF6C48E85EECB5447390E1CE0F2510F007A68315.png "点击放大")

连接HiCar后实现融合桌面的核心是从HiCar获取支持HiCar的应用列表，并与车机原生的应用列表进行融合展示。这个过程中由于HiCar存在一些需要用户操作的界面，例如隐私声明界面、引导用户使用的OOBE界面等，需要车机在进行融合展示之前，将HiCar完整的界面显示到前台，待用户完成相应操作之后，才可以继续完成融合展示。
> 说明
>
> 如果厂商仅实现融合桌面，则需要在车机HiCar配置文件中投屏参数同一层级增加"enableIntegration": true配置。

当用户在融合桌面中点击了来自HiCar的应用，车机需要将具体点击的内容告知HiCar，并将HiCar界面切换至前台，具体的细节可参考后续章节。
