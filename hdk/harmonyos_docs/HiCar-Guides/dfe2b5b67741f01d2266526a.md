# 车辆品牌图标

## 场景说明

**图1**车辆品牌图标示例   
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194822.62464778638285146577406430169640:50001231000000:2800:FC97BCB07AD5F8F6B4C9C243340922E2447245C178C8E11F856FA5965A6B89F3.png "点击放大")

HiCar连接成功后，HiCar界面投屏到车机屏幕上进行显示，通过点击HiCar应用图标区的车辆品牌图标可返回到车机原始界面，此车辆品牌图标需要车机传递给手机HiCar App。

交互过程中详细数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[品牌图标](https://developer.huawei.com/consumer/cn/doc/HiCar-References/brand-icon-0000001153300358)部分。

## 开发步骤

1. HiCar连接成功后，手机HiCar App向车机发送请求报文（dataType=502），请求车辆品牌图标。车机将收到的数据内容如下：

   ```screen
   {
       "brandIconData":"PNG"
   }
   ```

2. 车机通过**DataReceive** 方法，判断**dataType** 后可收到上述具体数据内容，准备完成车辆品牌图标数据后，通过**HiCarSendData**接口上报数据。示例代码如下：

   ```screen
   int pngFileLen = 0;
   int maxBufLen = 1024*1024;
   uint8_t *buffer = (uint8_t*)malloc(sizeof(uint8_t)*maxBufLen);

   FILE *fp = fopen(pngFilePath, "rb");
   if (fp != NULL) {
       pngFileLen = fread(buffer, 1, maxBufLen, fp);
       fclose(fp);
   }
   HiCarSendData(handle, HICAR_DATA_BRAND_ICON_DATA, buffer, pngFileLen);
   free(buffer);
   ```

   > 说明
   >
   > 车辆品牌图标下方显示的车辆品牌文字信息，在SDK初始化时设置，详情请参考[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000105632)。
