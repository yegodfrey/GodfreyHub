# 通知手机当前投屏结束

## 场景说明

在投屏结束后，车机需要在收到207消息后通知手机当前投屏成功，手机需根据车机当前投屏状态来进行下一步显示。

## 接口说明

当前接口需发送546消息，参数包含两个字段：

* stateCode：值为10，代表当前投屏成功。
* stateData：值为空字串，不需要传递数据。

## 开发步骤

通知手机当前投屏已结束。

```screen
// 监听207消息，通知手机当前投屏已结束
class HiCarListener implements Carlistener {
    @Override
    public void onDeviceServiceChange(String serviced, int state) {
        switch(state) {
            case HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAYING: // 207
                JSONObject jsonData = new JSONObject();
                jsonData.put("stateCode", 10);
                jsonData.put("stateData", ""); 
                hiCarAdapter.sendCarData(546, jsonData.toJSONString());
                break;
        }
    }
}
```
