# 应用元数据（音频/通话/导航/消息/场景）

## 场景说明

HiCar通过开放应用元数据的方式，将音频、通话、导航等相关的数据传递到车机，车机在正确获取到相关元数据后，可以用于仪表盘/HUD辅助显示。

HiCar支持的元数据包括：

* 音频元数据：包括歌曲名、演唱者、时长、专辑、播放状态等信息。歌词在HarmonyOS 6.0及以上系统支持。
* 通话元数据：包括联系人名称、来电号码、号码类型等信息。
* 导航元数据：包括路名、转向箭头图片等信息。导航应用中，当前仅花瓣地图及百度地图在HarmonyOS 5.1及以上版本系统中支持导航元数据。
* 导航路线数据：包括应用包名、导航状态、导航路线信息。
* 消息元数据：包括手机电量不足、手机过热等信息。
* 场景元数据：包括日历、天气、情景智能等信息。

> 说明
>
> 消息元数据低电量提醒规则：
>
> 1. 连接状态下，手机电量会在小于等于 10% 和 5% 分别提醒一次。
> 2. 手机正在充电状态时不提示。
> 3. 投屏成功时手机已经低于10%电量，会在投屏成功后立即提示一次。

应用元数据交互过程可简要描述为：

1. 车机侧向手机HiCar App请求元数据。

2. HiCar App响应车机请求，返回可开放的元数据类型。

3. 满足条件后，HiCar App开始发送元数据（其中通话元数据需要用户授权）。

## 元数据授权说明

因通话、日历、导航元数据（呼入/呼出号码、联系人、位置信息等）涉及用户个人隐私，HiCar会通过界面弹框及设置项的方式获取用户授权及更改授权设置。

## 开发步骤

1. 请求HiCar App开放元数据的类型。

   车机可通过**HiCarSendData**接口发送请求报文（dataType=514）请求开放的元数据类型。报文内容示例如下所示：

   ```screen
   {
       "RequestAAData":7 //Bit位1为1，表示请求媒体元数据；Bit位2为1，表示请求呼叫元数据；Bit位3为1，表示请求导航元数据；全0表示关闭元数据请求，HiCar App停止向车机发送元数据
   }
   ```

   示例代码如下所示：

   ```screen
   char *metadataRequest = "{\"RequestAAData\":7}"; //请求媒体、呼叫、导航元数据
   HiCarSendData(g_hicarHandle, HICAR_DATA_AA_DATA, metadataRequest, strlen(metadataRequest ) + 1);
   ```

   HiCar App在接收到请求后，会立即发送响应数据（dataType=514），响应报文内容示例如下所示：

   ```screen
   {    
       "ResponseAAData":{
           "MEDIA":true, 
           "CALL":true, 
           "NAVIGATION":false    
      } 
   }
   ```

   > 说明
   >
   > 导航元数据中的转向箭头图标区分深浅模式。如果车机上报不支持深浅模式，则无法请求导航元数据。建议车机在初始化HiCar SDK时，正确处理深浅模式相关逻辑，具体内容可参见[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000105632)。

2. 车机通过**onDataReceive** 方法，判断**dataType**后可以收到上述及以下具体数据内容，请判断相应的元数据开放状态后再使用元数据。

   1. 使用音频元数据。 HiCar App在音频播放状态变化时，向车机发送音频元数据报文（dataType=515），车机将收到的数据内容示例如下：

      ```screen
      {
          "MediaData": {
      	"Name": "dream it possible",
      	"Artist": "somebody",
      	"TotalTime": 500,
      	"ElapsedTime": 300,
      	"AlbumName": "name",
      	"AlbumArtURL": "url",
      	"Status": 300,
      	"AppName": "kugou",
      	"AppIcon": [],
      	"AppPackageName": "package name",
      	"AlbumArtIcon": [],
      	"IsAudioFromCar": false
          }
      }
      ```

      音频播放过程中，每隔1s，手机会向车机发送播放进度（单位：秒）数据。

      ```screen
      {
          "ElapsedTime": 50
      }
      ```

      > 说明
      > 1. 音频元数据仅在音频播放状态发生变化时传输，即播放/暂停/缓存/停止等状态，播放状态可参见android.media.session.PlaybackState类定义或参见HiCar SDK API参考。
      > 2. 播放过程中，每隔1秒，HiCar App会向车机发送播放进度数据。
      > 3. HarmonyOS 5.x及以下版本不支持音频元数据歌词传输。
      > 4. HarmonyOS 6.0支持音频元数据歌词传输，当前HarmonyOS 6.0版本中仅支持华为音乐和QQ音乐。
   2. 使用通话元数据。 HiCar App在呼叫状态发生变化时，根据用户授权记录，向授权车机发送呼叫元数据报文（dataType=516），车机将收到的数据内容示例如下：

      ```screen
      {
          "CallData": {
      	"ContactName": "tom",
      	"RemoteNumber": "123456789",
      	"Direction": 1,
      	"Status": 1,
      	"CallStartTimestamp": 1999,
      	"CallID": "123456789",
      	"CallApp": 2,
      	"NumberMarktype": "insurance",
      	"ReleaseCause": 1
           }
      }
      ```

      > 说明
      > 1. 通话元数据仅在通话呼叫状态发生变化时传输，通话呼叫状态定义参见HiCar SDK API参考。
      > 2. 通话时长需由车机HMI应用自行定时刷新。
      > 3. 通话元数据需要手机运行HarmonyOS 3.0及以上系统才会支持。
   3. 使用导航元数据。

      HiCar App在导航状态变化时，向车机发送导航元数据报文（dataType=517），车机将收到的数据内容示例如下：

      ```screen
      {
          "type": "update", //create，update，remove
          "navData": {
              "AppName": "com.amap.hmapp",
              "NavTurnImage": [],
              "CurrentRoadName": "进入xxx路",
              "ToDistance": "888",
              "NaviTurnMode": "002E", // 导航转向模式
              "Distance": "888",// 下一次动作剩余距离
              "RoadName":"xxx路", // 下一次进入的道路名
              "IntersectionView": [],// 路口放大图
              "ViewWidth": "10",// 路口放大图宽
              "ViewHeight": "10",// 路口放大图高
              "TrafficLane": "000F", // 行车道
              "NaviBearing": "0",// 导航方向
              "RemainingTime": "0",// 剩余时间
              "DestLocation": "xxx" //终点名称
          }
      }
      ```

   4. 使用消息元数据。 HiCar App在有消息产生时，向车机发送消息元数据报文（dataType=531），车机将收到的数据内容示例如下（以弹框类型消息元数据为例）：

      ```screen
      {
          "MessageData" : {
              "Status" : 0,
              "Type" : 2,
              "Id" : 1020,
              "Title" : "消息",
              "AppIcon" : [],
              "AppPackage" : "com.huawei.hicar",
              "InfoImage" : [],
              "MainText" : "是否允许访问通话数据？",
              "SubText" : "允许后，连接中的设备可使用手机通话数据。",
              "OptText" : "",
              "Button1" : {
                  "BtnText" : "确认",
                  "BtnType" : "emphasize",
              }
              "Button2" : {
                  "BtnText" : "取消",
                  "BtnType" : "normal",
              }
              "Button3" : {
                  "BtnText" : "不再提示",
                  "BtnType" : "check",
              }
          }
      }
      ```

      车机在收到上述元数据并在车机界面进行提示后，向HiCar App发送响应消息，发送的内容示例如下所示：

      ```screen
      {
          "MessageDataResp" : {
              "RespCode" : 100000,
              "Id" : 1020,
              "Type" : 2,
              "Button1" : true,
              "Button2" : false,
              "Button3" : true,
          }
      }
      ```

   5. 使用场景元数据。日历、天气、情景智能元数据的使用基本一致，此处以天气元数据为例进行介绍说明，其他元数据内容，请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"的应用元数据部分。

      以天气元数据为例，HiCar App在有天气数据产生时，向车机发送天气元数据报文（dataType=530），车机将收到的数据内容示例如下：

      ```screen
      {
          "ScenceData" : {
              "Type" : 2,
              "Status" : 0,
              "Id" : 7867,
              "AppName" : "天气 HUAWEI HiCar",
              "AppIcon" : [],
              "AppPackage" : "com.huawei.hicar",
              "InfoImage" : [],
              "MainText" : "30℃",
              "SubText" : "空气优质\n33℃/26℃",
              "OptText" : "江夏区",
              "OptImage" : [],
       
          }
      }
      ```

      车机在收到上述元数据后，向HiCar App发送响应消息，发送的内容示例如下所示：

      ```screen
      {
          "ScenceDataResp": {
              "RespCode" : 100000,
              "Id" : 7867,
              "Type" : 1,
              "CardClick" : true
          }
      }
      ```

> 说明
>
> 上述通话元数据授权弹框为智慧桌面场景，在融合桌面下当车机发送请求报文（dataType=514）之后，HiCar会发送消息（授权）元数据报文（dataType=531）给车机，车机侧在拿到消息元数据报文（dataType=531）之后需要自己绘制通话元数据隐私授权弹框（dataType=531消息元数据详情见[消息元数据](https://developer.huawei.com/consumer/cn/doc/HiCar-References/app-metadata-message-0000002012277025)）。
