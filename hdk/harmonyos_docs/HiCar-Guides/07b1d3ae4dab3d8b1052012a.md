# 车辆传感器（Beta）

## 场景说明

当车机和手机建立HiCar连接后，HiCar App会向车机请求获取光线强度、车辆速度、加速度、陀螺仪数据，车机在收到请求数据后，应上报相应数据，并在对应数据后续发生变化后，主动上报变化后的数据。

车辆传感器相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[车辆传感器（车速/加速度等）](https://developer.huawei.com/consumer/cn/doc/HiCar-References/vehicle-sensors-0000001153300362)部分。

## 开发步骤

1. HiCar App启动后在需要获取车辆传感器数据时，会向车机发送报文（dataType=510），通知车机上报相应的数据。车机将收到的数据内容如下：

   ```screen
   {
       "service": "sensorData", 
       "subService": "transmission", 
       "command": 0, 
       "data": {
           "illumination": [1,1], 
           "speed": 1, 
           "acc": [1,1,1], 
           "gry": [1,1,1]
       }
   }
   ```

2. 车机需要通过**HiCarSendData**接口向HiCar App上报相应的车辆传感器数据。车机发送的数据内容示例如下：

   ```screen
   {
       "service": "sensorData", 
       "subService": "transmission", 
       "command": 1, 
       "data": {
           "illumination": [100,1000], 
           "speed": 80, 
           "acc": [1.15,0.01,0], 
           "gry": [1.10,3.15,0.45]
       }, 
       "timestamp": 1617087892722
   }
   ```

3. 后续车辆传感器数据发生变化时，同步向HiCar App上报最新的传感器数据。

   上报周期约定如下：
   * 车速：车速发生变化后更新。为避免消息拥塞，正常行车（车速80km/h以下）更新周期间隔1s以上，高速行车（车速80km/h以上）更新周期间隔500ms以上。
   * 光线强度、加速度、陀螺仪：每秒更新。
