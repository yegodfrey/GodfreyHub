## 投屏前

启动投屏流程前，厂商HMI应用需确保：

* 集成投屏控件。厂商HMI应用在投屏界面中集成投屏控件，具体内容可以参考[界面布局](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/ui-layout-0000001147321358)。
* 设置投屏参数。厂商HMI应用可以在SDK初始化或者运行时动态设置投屏参数。本文档在之前的章节已经介绍过相应的参数及设置方法，具体内容可以参考[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000030695)和[运行态更新车机信息](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/update-head-unit-information-0000000000030706)。 说明
  >
  > 投屏参数必须在投屏开始之前传递给HiCar SDK，投屏的Surface对象如果在投屏过程中发生了变化，需要重新设置给HiCar SDK。

在建立连接环节的回调处理过程中（前文[处理连接事件回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callbacks-0000001193322373#section134661359336)），厂商应在接收到EVENT_DEVICE_CONNECT事件后，显示连接动画，用作投屏前的过渡动画。

|类|方法|说明|
|:----------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|onDeviceChange|HiCar SDK通过回调的方式向厂商HMI应用通知连接相应的事件： * EVENT_DEVICE_CONNECT（值为101）：设备已连接。收到连接成功事件后，厂商HMI应用需要停止广播、显示连接动画（在投屏成功或超时之前，连接动画需要一直显示）。 * EVENT_DEVICE_DISCONNECT（值为102）：设备已断开连接。收到连接断开事件后，厂商HMI应用应进行断开连接、释放资源等操作。 * EVENT_DEVICE_CONNECT_FAILED（值103）：设备连接失败。收到连接失败事件后，厂商HMI应用应进行退出操作。|
|CarListener|onDataReceive|* DATA_TYPE_USERACTIVEDISCONNECT（值518）：手机侧主动断开。收到连接断开事件后，厂商HMI应用应进行断开连接、释放资源等操作。|
[**表1**处理连接事件回调相关接口]

厂商HMI应用需要在连接事件回调中判断当前连接状态：

* 如果连接成功，则在回调处理中启动连接动效界面，连接动效界面在收到投屏成功事件后结束。
* 如果连接断开，则在回调处理中停止投屏并销毁投屏界面。

## 开始投屏

HiCar SDK在连接成功后，会启动投屏服务，并将投屏服务的启动结果通过事件通知到厂商HMI应用。

|类|方法|说明|
|:----------|:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|onDeviceServiceChange|HiCar SDK通过回调的方式向厂商HMI应用通知服务相关的事件： * EVENT_DEVICE_SERVICE_START（值为204）：服务启动。投屏服务启动后，厂商HMI应用将收到该事件，此时厂商HMI应用需要进行投屏操作（融合桌面不适用此消息，需监听[融合桌面HiCar前后台显示消息](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/handle-app-backgroud-0000001606109141)进行开始投屏操作）。 * EVENT_DEVICE_SERVICE_STOP（值为205）：服务停止。投屏服务停止后，厂商HMI应用将收到该事件，此时厂商HMI应用需要停止投屏（融合桌面不适用此消息，需监听[融合桌面HiCar前后台显示消息](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/handle-app-backgroud-0000001606109141)进行暂停投屏操作）。 * EVENT_DEVICE_DISPLAY_SERVICE_PLAYING（值为207）：投屏成功。 * EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED（值为208）：投屏失败。|
[**表2**投屏相关接口]

1. 厂商HMI应用在收到EVENT_DEVICE_SERVICE_START（值为204）事件，并在投屏界面Surface绘制完成后启动投屏。

   示例代码如下所示：

   ```screen
   CarListener carListener = new CarListener() {
       ...
       @Override
       public void onDeviceServiceChange(String serviceId, int state) {
           if (state == HiCarConst.EVENT_DEVICE_SERVICE_START) {
               //投屏服务启动成功
               //增加厂商业务逻辑
           } 

       }
   };
   ```

   厂商HMI应用在投屏界面Surface绘制完成后，启动投屏。 说明
   > 1. HiCar SDK提供的开始投屏接口必须在投屏界面启动完成之后调用，厂商应用需要侦听surfaceChanged事件，在Surface完成绘制后再处理开始投屏的逻辑。
   > 2. 调用startProjection接口后，必须等待收到HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAYING或HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED任一回调事件，方可才能再次调用。

   ```screen
   //投屏界面Surface绘制完成后，启动投屏
   mSurfaceView = (SurfaceView) findViewById(R.id.surface);
   if (mSurfaceView != null) {
       mSurfaceView.getViewTreeObserver().addOnGlobalLayoutListener(new ViewTreeObserver.OnGlobalLayoutListener() {
           @Override
           public void onGlobalLayout() {
               mSurfaceView.getViewTreeObserver().removeOnGlobalLayoutListener(this);
    
               mSurfaceView.getHolder().addCallback(new SurfaceHolder.Callback() {
                   @Override
                   public void surfaceCreated(SurfaceHolder surfaceHolder) {
                       Log.i(TAG, "surface view created");
                   }
    
                   @Override
                   public void surfaceChanged(SurfaceHolder surfaceHolder, int format, int width, int height) {
                       Log.i(TAG, "surface view changed: width = " + width + ", height = " + height);
                       if (surfaceHolder != null
                               && surfaceHolder.getSurface() != null
                               && surfaceHolder.getSurface().isValid()) {
                           if (mDemoService.updateCarConfig(surfaceHolder.getSurface(), width, height)) {
                               startProjection();
                           }
                       } else {
                           Log.i(TAG, "surface holder or surface is null or invalid");
                           pauseProjection();
                       }
                   }
    
                   @Override
                   public void surfaceDestroyed(SurfaceHolder surfaceHolder) {
                       Log.i(TAG, "surface view destroyed");
                       pauseProjection();
                   }
               });
           }
       });
   }
   ```

2. 厂商HMI应用在启动投屏后，需要在服务事件回调中关注投屏事件，根据投屏事件结果完成业务处理，例如在投屏失败后销毁投屏界面并返回车机原始HMI界面；如果投屏控件和其它引导控件在同一界面布局中，可以在投屏成功后隐藏其它引导控件。

   投屏事件回调的示例代码如下所示：

   ```screen
   CarListener carListener = new CarListener() {
       ...
       @Override
       public void onDeviceServiceChange(String serviceId, int state) {
           if (state == HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAYING) {
               //投屏成功
               //增加厂商业务逻辑
           } else if (state == HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED) {
               //投屏失败
               //增加厂商业务逻辑
           }
       }
   };
   ```

   > 说明
   >
   > 投屏启动后，厂商HMI应用须等待并接收HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAYING或HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED回调事件，方可执行pauseProjection操作。

## 投屏后

厂商HMI应用可以自由布局投屏控件，可以全屏显示投屏控件，也可以将投屏控件与车机原生HMI界面进行融合。

* 投屏控件全屏显示的场景下，厂商HMI应用需要处理投屏界面与车机原生HMI界面的切换。
* 投屏控件非全屏显示的场景下，厂商HMI应用也需要处理用户焦点的切换。

|类|方法|说明|
|:----------|:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|onDeviceServiceChange|HiCar SDK通过回调的方式向厂商HMI应用通知服务相关的事件： * EVENT_DEVICE_SERVICE_PAUSE（值为202）：服务暂停。当用户从HiCar显示切换到车机原生系统界面显示时，厂商HMI应用会收到该事件时，此时厂商HMI应用需要在回调处理中暂停投屏并切换显示界面为车机原生HMI界面。 * EVENT_DEVICE_SERVICE_RESUME（值为203）：服务恢复。当厂商HMI应用收到该事件时， 表明手机侧HiCar App被启动，需要把HiCar投屏界面显示给车机用户，此时厂商HMI应用需要在回调处理中开始投屏并且切换显示界面为HiCar投屏界面。|
[**表3**处理视频焦点切换相关接口]

视频焦点事件处理示例代码如下所示：

```screen
CarListener carListener = new CarListener() {
    ...
    @Override
    public void onDeviceServiceChange(String serviceId, int state) {
        if (state == HiCarConst.EVENT_DEVICE_SERVICE_PAUSE) {
            //暂停投屏
            mHiCarAdapter.pauseProjection();
            ...
            //退出HiCar投屏界面
        } else if (state == HiCarConst.EVENT_DEVICE_SERVICE_START) {
            //拉起HiCar投屏界面
            mHiCarAdapter.startProjection();
            ...
        }else if (state == HiCarConst.EVENT_DEVICE_SERVICE_RESUME) {
            //拉起HiCar投屏界面
            mHiCarAdapter.startProjection();
            ...
        }
    }
};
```

> 说明
>
> 厂商HMI应用在处理视频焦点切换时，需要判断Surface是否发生变化，当Surface变化时，需要厂商HMI应用重新设置Surface对象并重新启动投屏。
