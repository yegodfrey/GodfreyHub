# 通话状态与焦点

## 场景说明

HiCar App默认提供通话服务，可能会与车机通话功能（车载蓝牙通话、车机本地SIM卡通话等）产生冲突，所以为了避免通话冲突，车机需要将本地通话服务状态通知到HiCar。同时在HiCar App提供通话服务时，当用户按下方控按键，车机也需要根据HiCar App通话状态进行通话/挂断事件的上报，所以车机需要从HiCar App获取通话状态。

通话状态说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[通话状态](https://developer.huawei.com/consumer/cn/doc/HiCar-References/call-focus-0000001153460174)部分，通话状态与通话焦点的申请释放两者没有必然联系，通话状态与通话焦点的申请释放相互独立，互不影响。同时，当车机通话与HiCar通话发生冲突时，对应的冲突解决方案如[表1](#ZH-CN_TOPIC_0000001052659461__table13904629184512)所示。

|冲突场景|冲突解决|
|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HiCar呼叫时车机来电|根据车机来电优先级进行处理： * 车机来电如果是高优先级呼叫，例如E-Call，此时直接释放HiCar呼叫。 * 车机来电如果是普通呼叫，例如B-Call/I-Call/蓝牙通话等，当用户接听车机来电时，直接释放HiCar呼叫，当用户拒绝车机来电时，继续保持HiCar呼叫。|
|HiCar呼叫时车机去电|直接释放HiCar呼叫。|
|车机呼叫时HiCar来电|根据车机呼叫优先级进行处理： * 车机呼叫如果是高优先级呼叫，例如E-Call，此时直接释放HiCar呼叫。 * 车机呼叫如果是普通呼叫，例如B-Call/I-Call/蓝牙通话等，车机拉起HiCar呼叫界面或显示HiCar来电悬浮窗，当用户接听HiCar来电时，直接释放车机呼叫，当用户拒绝HiCar来电时，继续保持车机呼叫。|
|车机呼叫时HiCar去电|保持或释放车机呼叫。|

|头文件|方法|说明|

|hicar.h|HiCarPostEvent|发送按键事件。处理通话冲突场景中，厂商HMI应用可以复用按键事件进行通话接通和释放： * KEYCODE_CALL（值为5）：接通HiCar通话。 * KEYCODE_ENDCALL（值为6）：释放HiCar呼叫。|

## HarmonyOS 4.x及以下系统版本微信通话无声解决方法

HiCar App会在通话状态发生变化时通知车机。车机可以通过onDataReceive方法，判断dataType后获取相应的通话状态，对于微信应用，HiCar会在通话接通时，通过504回调callstate 3来通知车机当前是微信通话，收到这个状态时需要车机申请微信通话焦点，当收到callstate 0的时候释放通话焦点。
> 说明
>
> 断开连接的场景，如果通话焦点还在，也需要手动释放，否则会影响原车媒体播放，请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[通话状态](https://developer.huawei.com/consumer/cn/doc/HiCar-References/call-focus-0000001153460174)部分。

## 通话场景下通话状态及接通挂断键处理

多路通话状态下（如同时存在一路运营商通话与一路微信语音），此时通话状态的发送与方控事件的响应遵循优先控制当前活跃/前台通路的原则，具体场景处理如下表所示。

|----------------|--------------------|---------------------|---------|---------|
|**通话场景**|**通话行为**|**通话状态发送**|**方控事件响应**||
|**通话场景**|**通话行为**|**通话状态发送**|**接通键**|**挂断键**|
|单路通话场景|通话来电正在响铃|响铃态（callstate = 1）|需要向手机发送事件|需要向手机发送事件|
|单路通话场景|通话接通状态|接通态（callstate = 2）|NA|需要向手机发送事件|
|运营商多路通话场景|一路通话中，第二路通话呼入|响铃态（callstate = 1）|需要向手机发送事件|需要向手机发送事件|
|运营商多路通话场景|一路响铃中，第二路通话呼入|不发送（因为第一路已经发送过响铃通话状态）|需要向手机发送事件|需要向手机发送事件|

|运营商通话和VoIP多路通话场景|一路运营商通话中，第二路VoIP通话呼入|NA（VoIP通话系统后台拦截）|NA|NA|

## 开发步骤

1. 车机在本地存在通话开始及结束时，通过**HiCarSendData**接口，通知HiCar App通话状态是否可用。

   * 启动本地通话时通知HiCar App通话状态不可用。
   * 结束本地通话时通知HiCar App通话状态可用。

   车机发送的数据内容示例如下所示：

   ```screen
   {
       "isCallAvailable":true
   }
   ```

2. HiCar App会在通话状态发生变化时，通知车机。车机可以通过**DataReceive** 方法，判断**dataType**后获取相应的通话状态。车机将收到的数据内容示例如下所示：

   ```screen
   {
       "callState":1
   }
   ```

3. 通过发送按键事件接通及释放HiCar通话的内容，请参考[管理车机按键/旋钮/触摸板](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/physical-key-knob-0000000000105717)。
