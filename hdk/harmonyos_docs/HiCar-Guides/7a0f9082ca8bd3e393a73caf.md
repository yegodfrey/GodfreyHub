# 有线连接

## 连接流程

HiCar支持USB有线连接，用户可以通过手机配套的USB线缆连接支持HiCar的手机和车机设备来使用HiCar。

手机和车机间支持多种USB模式，包括：仅充电、USB Storage、MTP、NCM和AOA。HiCar基于USB的有线连接支持通过NCM（暂不支持AOA）建立通道，进行数据传输。

**图1**USB连接流程   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214045.11043257853515774712715630749412:50001231000000:2800:8A92423A4E7EEAC38EA31F424419C1299E98DDF08B58253C520A2F516B88B0EC.png)

1. 车机启动后初始化HiCar SDK，厂商需要在初始化时将车辆信息通过接口提供给HiCar SDK，该步骤通过厂商HMI应用实现，详情请参考后续[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000030695)。
2. HiCar SDK侦听车机USB连接事件"android.hardware.usb.action.USB_DEVICE_ATTACHED"。
3. HiCar SDK在侦听到USB设备插入后，如果是手机，则向手机发送一条USB控制信息，包含当前的车辆信息、是否支持NCM等。
4. HiCar SDK在发送完USB控制信息后，等待手机USB切换为NCM模式。
5. HiCar SDK在侦听到手机切换为NCM模式后，会尝试建立连接通道。此时为了确保正常建立连接，车机需要将IP网口相关的信息配置到车机路由表中，详情请参考[配置车机路由](#section154359281312)。
6. 手机与车机建立完通道后，HiCar SDK会向上层厂商HMI应用发送EVENT_DEVICE_CONNECT事件。上层厂商HMI应用即可进行后续投屏操作，详情请参考开发厂商HMI应用章节的[建立有线连接](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/wired-connectivity-0000000000030734)。

## 配置车机路由

有线连接需要车机系统支持USB虚拟NCM网卡功能。当USB连接车机时，车机端会映射出一块名为"wwan0"的网卡，同时HiCar SDK会为此网卡在网段192.168.66.100~192.168.66.255内随机配置一个IP地址。**"wwan0"**的网卡初始地址需为空，否则会导致连接失败。

同时，HiCar SDK支持通过系统参数"ro.hicar.wwan0.network"指定该网卡的IP地址网段，避免随机分配的IP地址与车机已使用的IP地址产生冲突。

|参数名|类型|说明|
|:---------------------|:-----|:---------------------------------------------|
|ro.hicar.wwan0.network|string|厂商可根据实际需要设置相应的IP地址网段。如果未设置，默认为"192.168.66."网段。|
[**表1**参数说明]

命令如下所示：

```screen
adb shell
> setprop ro.hicar.wwan0.network XXX.XXX.XX. //设置网段
```

为了能够快速组网，厂商需要配置此网段的车机路由信息。
> 注意
>
> 示例代码仅供参考，请厂商根据实际车机系统进行修改。

1. 在Android源码文件中查找"system/netd/server/NetlinkHandler.cpp"。
2. 在onEvent方法中补充相关路由信息。示例代码如下所示。


3. 重新编译车机系统或编译netd相关组件替换到车机系统中，进行有线连接验证。

## 验证有线连接

在完成有线连接相关配置后，厂商可以通过HiCar SDK软件包中的HiCarDemo.apk验证车机设备的有线连通性。

1. 运行HiCarDemo.apk。

   **图2**HiCarDemo运行初始界面示意（以实际界面为准）   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214045.38756822457440264824813798237987:50001231000000:2800:E5470A126E370070341CAD3F605E93F551EFDA00664DCDCD0DB79BB11F31F125.png "点击放大")

2. 通过USB连接手机和车机设备。

   如果有线连通，会正常弹出连接确认框，点击连接后，连接成功时车机将正常显示HiCar界面。

   如果有线不连通，请根据日志信息进行问题排查及解决。
