# 切换分辨率

进入设置页面"选择屏幕"菜单，可以切换模拟器所模拟的屏幕尺寸和分辨率。

选择对应分辨率后，需要断开华为机和华为平板的连接线（拔下华为手机和华为平板连接线的任意一端），重新连接。
