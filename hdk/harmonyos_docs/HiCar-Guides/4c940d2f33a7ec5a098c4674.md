# 媒体控制

## 场景说明

车机通过向HiCar发送媒体控制指令，在车机端直接控制HiCar上的音频应用。

对于HiCar上应用支持的播控指令，可以通过查询支持的播控指令接口查询，从而实现在车机侧直接控制HiCar上的媒体应用。

媒体控制相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[媒体控制](https://developer.huawei.com/consumer/cn/doc/HiCar-References/media-control-command-0000002668508570)部分。

## 开发步骤

1. 手机与车机连接成功后，车机需要通过**HiCarSendData**接口（dataType=556）注册监听播控指令变化事件。HiCar App媒体元数据中支持的播控指令或者播放状态发生变化时，会向车机发送媒体支持指令及播放状态消息（dataType=556），告知车机当前媒体应用支持的播控指令以及播放状态（收藏和循环模式），比如不支持下一曲指令，车机可以以此来禁用下一曲播控按钮。示例如下所示：

   ```screen
   {
       "MediaDataResp" : {
           "RespCode" : 100000
       }
   }
   ```

   车机通过onDataReceive接收HiCar App发送的数据，HiCar App返回数据示例：

   ```screen
   {
       "validCommands": {
           "isCanPlayPrevious": true,
           "isCanPlayNext": false,
           "isCanPlay": true,
           "isCanLoopMode": true,
           "isCanFavor": true
       },
       "playbackState": {
           "loopMode": 0,
           "isFavorite": false
       }
   }
   ```

2. 点击车机HMI上的播控按钮，发送媒体控制指令消息（dataType=555），支持发送的指令有播放、暂停、下一首、上一首、设置循环模式、跳转某一节点和收藏。比如拖动进度条，发送seek指令，支持按进度百分比或者按指定播放位置跳转，两种方式选择一种即可，示例如下：

   ```screen
   // 方式一：按进度百分比位置跳转
   {
     "command": "seekTo",
     "parameter": {
       "mediaSeekToPosition": 30000, //进度占总时长播放比
     }
   }
   // 方式二：按指定播放位置跳转
   {
     "command": "seekTo",
     "parameter": {
       "progressPercentage": 30.5 //指定播放位置，单位：毫秒
     }
   }
   ```
