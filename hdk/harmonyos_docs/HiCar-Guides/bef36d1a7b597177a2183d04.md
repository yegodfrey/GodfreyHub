# 开始/停止车机广播

## 场景说明

厂商HMI应用可以在自身被启动或者用户按下车机物理按键（例如长按语音唤醒按键）时调用"HiCarStartAdv"接口发送BLE广播，在连接成功后调用"HiCarStopAdv"接口停止BLE广播。调用发送广播接口与停止广播接口时，厂商HMI应用需要根据返回值判断广播是否真正发送或停止。

## 接口说明

|接口|方法|说明|
|:----------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|-|HiCarStartAdv|厂商HMI应用通过该接口发送BLE广播。|
|-|HiCarStopAdv|厂商HMI应用通过该接口停止BLE广播。|
|CarListener|DeviceChange|HiCar SDK通过回调的方式向厂商HMI应用通知广播相应的事件。 * HICAR_DEVICE_ADV_TIMEOUT（值为111）：广播超时。厂商HMI应用收到该事件后，需要重新发起广播刷新PIN码。 * HICAR_DEVICE_DISPLAY_SERVICE_PLAYING（值为207）：投屏成功。厂商HMI应用收到该事件后，可以通过"GetVideoData"回调方法获取视频流数据。|
[**表1**广播相关接口]

## 开发步骤

1. 厂商HMI应用在自身被启动或者用户按下车机物理按键时，需要检测车机蓝牙状态。

   如果车机蓝牙未打开，厂商HMI应用需要开启车机蓝牙。

2. 通过HiCarStartAdv接口发送BLE广播。

   调用发送广播接口的代码示例如下所示：

   ```screen
   //发送广播 
   int retCode = HiCarStartAdv(); 
   if (retCode == 0) { 
       Log.i(TAG, "handleStartAdv: start adv success"); 
       return; 
   } 
   ```

3. 获取PIN码，详情请参见[处理PIN码回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callback-0000001195856541#section2561617101014)。

   厂商HMI应用在触发BLE广播后，HiCar SDK会生成对应的PIN码，厂商HMI应用需将该PIN码在车机屏幕上向用户显示。该PIN码为本次广播周期内的连接校验码，用户需要在连接时输入该PIN码才能成功连接车机。

4. 关注广播超时事件。

   厂商HMI应用在发送BLE广播后，需要关注DeviceChange中的广播超时事件。当接收到广播超时事件后，需要重新发起广播。

   示例代码如下所示：

   ```screen
   void DeviceChange(const char *deviceId, uint32_t idLen, int state, int errorCode)
   {
       printf("DeviceChange, deviceId:%s, state:%d\n", deviceId, state);
       switch (state) {
           case HICAR_DEVICE_ADV_TIMEOUT:
           // 重新发起广播

           break;
           default:
           break;
       }
   }
   ```

5. 处理认证回调，详情请参见[处理认证回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callback-0000001195856541#section16702192691018)。

   厂商HMI应用需要将HiCar SDK与车机的认证信息保存在车机系统中，并通过HiCar SDK提供的回调方法完成认证文件的读取、保存和删除操作。

6. 处理连接事件回调，详情请参见[处理连接事件回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callback-0000001195856541#section12985733201014)。

   厂商HMI应用需要侦听连接事件，并根据不同的连接事件完成相应的逻辑处理。

7. 收到连接成功事件后，通过HiCarStopAdv接口停止发送BLE广播。

   HiCar SDK内部在连接成功后，也会主动停止BLE广播。厂商HMI应用也可以自行调用停止广播接口，示例代码如下所示：

   ```screen
   //停止广播 
   int retCode = HiCarStopAdv(); 
   if (retCode != 0) { 
       Log.d(TAG, "handleStopAdv failed"); 
   }
   ```

8. 关注投屏成功事件，获取视频流。

   HiCar SDK内部会在连接成功后，自动启动投屏流程。厂商HMI应用只需关注投屏成功事件，在收到投屏成功事件（HICAR_DEVICE_DISPLAY_SERVICE_PLAYING）后，可以通过"GetVideoData"回调方法获取视频流数据，更多详细内容请参见[投屏说明](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/interaction-process-0000001050121798)。
