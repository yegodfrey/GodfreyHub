# 三键导航

## 场景说明

通过增加常驻的虚拟三键能力接口（返回、桌面、任务管理），为提供车机侧小窗场景的三键导航能力。

从HarmonyOS 6.1版本开始支持。

## 接口说明

复用类[HiCarAdapter的sendCarData接口](https://developer.huawei.com/consumer/cn/doc/HiCar-References/send-car-data-0000000000030601)，新增dataType=550的消息，表示发送虚拟按键事件。新增如下参数：

|dataType|value（int类型）|value值|类型含义|
|:--------------------------|:----------------------------|:-----|:-----|
|DATA_TYPE_VIRTUAL_KEY_EVENT|VIRTUAL_KEY_ACTION_BACK|0|返回上一级|
|DATA_TYPE_VIRTUAL_KEY_EVENT|VIRTUAL_KEY_ACTION_HOME|1|进入主页|
|DATA_TYPE_VIRTUAL_KEY_EVENT|VIRTUAL_KEY_ACTION_RECENT_APP|2|进入任务中心|

## 开发步骤

HMI应用自行绘制用于导航的三键，当用户点击三键后，同步参考如下示例代码向HiCar发送相关事件：

```screen
ByteBuffer buffer = ByteBuffer.allocate(4);
buffer.putInt(HiCarConst.VIRTUAL_KEY_ACTION_BACK); // 传入不同按键事件
mHiCarAdapter.sendCarData(HiCarConst.DATA_TYPE_VIRTUAL_KEY_EVENT, buffer.array());
```
