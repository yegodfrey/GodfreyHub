# 入口

**规则 2-1 遵循入口便捷，HUAWEI HiCar 入口首选在车机首界面露出，并展现HUAWEI HiCar品牌图标。**

**建议 2-2 车机连接入口分为未连接与已连接，未连接状态与已连接状态的样式需区分（1.允许相同图标，文本区分连接与未连接状态 2.允许无文本，图标区分连接与未连接状态）**

例如：进入方式可用图标模式，卡片等。
