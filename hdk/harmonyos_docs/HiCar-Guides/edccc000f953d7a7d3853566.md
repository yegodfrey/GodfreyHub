# 处理视频焦点切换

## 场景说明

厂商HMI应用可以自由控制HiCar投屏区域，可以全屏显示HiCar投屏界面，也可以在车机屏幕的某个区域显示HiCar投屏界面。

* 全屏显示的场景下，厂商HMI应用需要处理投屏界面与车机原生HMI界面的切换。
* 非全屏显示的场景下，厂商HMI应用也需要处理用户焦点的切换。

## 接口说明

|接口|方法|说明|
|:----------|:------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|DeviceServiceChange|HiCar SDK通过回调的方式向厂商HMI应用通知服务相关的事件： * HICAR_DEVICE_SERVICE_PAUSE（值为202）：当用户点击HiCar投屏界面中退出按钮时，厂商HMI应用会收到该事件。此时，厂商HMI应用应该退到后台，并调用"HiCarPauseProjection"暂停投屏。 * HICAR_DEVICE_SERVICE_RESUME（值为203）：当厂商HMI应用在后台，收到外部来电或者方控唤醒语音助手时，厂商HMI应用会收到该事件。此时，厂商HMI应用应该启动到前台，并调用"HiCarStartProjection"进行投屏。|
[**表1**处理视频焦点切换相关接口]

## 开发步骤

视频焦点事件处理示例代码如下所示：

```screen
void DeviceServiceChange(const char *serviceId, uint32_t idLen, int state) {
    LOGD("DeviceServiceChange, state:%d", state);
    switch (state) {
        case HICAR_DEVICE_SERVICE_PAUSE: {  
            // 切到车机主界面，调用HiCarPauseProjection暂停投屏

            break;
        }
        case HICAR_DEVICE_SERVICE_RESUME: {  
            // 切到HiCar界面，调用HiCarStartProjection进行投屏
			
            break;
        }

        default: break;
    }
}
```
