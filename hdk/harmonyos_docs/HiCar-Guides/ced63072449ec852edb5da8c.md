# 配置音频管理服务

## 场景说明

当用户在HiCar环境中点击应用图标启动音频应用时，HiCar会绑定AbstractCarOperationService实现类，通知音频应用完成音频服务的初始化。音频应用需要新建一个继承自AbstractCarOperationService的实现类用于与HiCar对接。

## 接口说明

|继承类|方法|实现功能|音频应用在对应方法中需返回的结果|
|:--------------------------|:-----------------|:------|:-------------------------------------------------------------------------------|
|AbstractCarOperationService|callMediaStart()|初始化音频服务|返回对象为Bundle，其中Key为**result**，对应的Value取值为： * 0：初始化音频服务成功 * 100：隐私声明未确认 * 999：其它错误|
|AbstractCarOperationService|callMediaDestroy()|销毁音频服务|返回对象为Bundle，其中Key为**result**，对应的Value取值为： * 0：销毁音频服务成功 * 999：其它错误|
|AbstractCarOperationService|callMediaRestart()|重启音频服务|返回对象为Bundle，其中Key为**result**，对应的Value取值为： * 0：初始化音频服务成功 * 100：隐私声明未确认 * 999：其它错误|
[**表1**音频管理服务相关接口]

> 说明
>
> AbstractCarOperationService中的其它方法，音频应用不涉及，留空即可。

## 开发步骤

1. 新建一个继承自AbstractCarOperationService的实现类，例如HiCarMediaOperateMgr。
2. 在AndroidManifest.xml清单文件中声明HiCarMediaOperateMgr，并配置HiCar相关内容。配置示例如下所示：

   ```screen
   <application>
   ...
       <service
           android:name=".service.HiCarMediaOperateMgr"
           android:directBootAware="true"
           android:enabled="true"
       android:exported="true"
   android:permission="com.huawei.hicar.HICAR_PERMISSION_SYSTEM">
   <intent-filter>
   <action android:name="com.huawei.hicar.CALLBACK_EVENT"/>
   </intent-filter>
       </service>
   ...
   </application>
   ```

3. 在HiCarMediaOperateMgr中分别实现callMediaStart()、callMediaDestroy()和callMediaRestart()方法来完成对音频服务的初始化、销毁和重启，并返回相应的结果，同时音频应用需要在callMediaStart()、callMediaRestart()方法中判断当前隐私声明确认和权限获取情况。示例代码如下所示：

   ```screen
   private static final String TAG="HiCarMediaOperateMgr";

   @Override
   public Bundle callMediaStart(Bundle bundle){
       Log.i(TAG,"mediaStart");
       Bundle result = new Bundle();

       boolean isFirstStart = true;
       SharedPreferences preferences = getSharedPreferences("user",Context.MODE_PRIVATE);
       isFirstStart = preferences.getBoolean("isFirstStart",true);

       if(isFirstStart){
           //判断是否需要启动隐私声明Activity，如果需要，返回结果100
           result.putInt("result",100);
       }else{
           //启动音频服务，其中PlayService为音频服务
           Intent intent = new Intent(getApplicationContext(),PlayService.class);
           getApplication().startService(intent);
           result.putInt("result",0);
       }
       return result;
   }

   @Override
   public Bundle callMediaDestroy(Bundle bundle){
       Log.i(TAG,"callMediaDestroy");
       return null;
   }

   @Override
   public Bundle callMediaRestart(Bundle bundle){
       Log.i(TAG,"mediaStart");
       Bundle result = new Bundle();

       boolean isFirstStart = true;
       SharedPreferences preferences = getSharedPreferences("user",Context.MODE_PRIVATE);
       isFirstStart = preferences.getBoolean("isFirstStart",true);

       if(isFirstStart){
           //判断是否需要启动隐私声明Activity，如果需要，返回结果100
           result.putInt("result",100);
       }else{
           //启动音频服务，其中PlayService为音频服务
           Intent intent = new Intent(getApplicationContext(),PlayService.class);
           getApplication().startService(intent);
           result.putInt("result",0);
       }
       return result;
   }
   ```

   当音频服务状态发生变化时，HiCar将调用上述实现方法通知音频应用完成对音频服务的相关操作。
