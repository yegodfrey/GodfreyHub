# 配置USB

## 场景说明

HiCar SDK通过USB通道建立有线连接，厂商需要为HiCar SDK提供相应的USB驱动。

## 接口说明

厂商需实现HiCar SDK包中设备接口（driver_adapt.h）的FcDriverAdaptOps类型变量以及其中的部分接口。

配置USB时，FcDriverAdaptOps变量中必须实现的接口如[表1](#ZH-CN_TOPIC_0000001063680113__table7112357182912)所示。

|结构体|结构体成员名称|说明|
|:---------------|:----------------------|:--------------------------------------------------|
|FcDriverAdaptOps|name|USB driver名称。|
|FcDriverAdaptOps|desc|USB设备接口描述，厂商可根据需要自行填写，例如"usb driver"。|
|FcDriverAdaptOps|Init|USB driver初始化接口，HiCar SDK在使用其他USB接口前，首先会调用该接口进行初始化。|
|FcDriverAdaptOps|Deinit|USB driver去初始化接口，厂商可按需进行相关操作。|
|FcDriverAdaptOps|GetParam|HiCar SDK会调用该接口获取厂商ModelID。ModelID由华为分配给厂商。|
|FcDriverAdaptOps|RegisterChannelCallback|HiCar SDK向驱动注册回调。驱动通过此回调向HiCar SDK上报事件。|
[**表1**FcDriverAdaptOps结构体]

FcDriverAdaptOps类型的变量实现方式请参考HiCar SDK包中USB demo代码（driver_usb.c），其中须注意，变量名称须为"g_fcDriverUsbOps"。

## 开发步骤

1. 实现USB初始化接口Init。

   示例代码如下所示：

   ```screen
   static int UsbDriverInit(const void *context, const char *ifName)
   {
       if (context == NULL) {
           return RESULT_RET_ERROR;
       }

       UsbParam *usbParam = (UsbParam *)context;
       char ip[STR_IP_LEN + 1] = {0};
       if (strcpy_s(ip, STR_IP_LEN + 1, usbParam->localIp) != EOK) {
           printf("UsbDriverInit copy ip fail.\n");
       }

       int port = usbParam->port;
       printf("UsbDriverInit port is:%d.\n", port);
       return RESULT_RET_OK;
   }
   ```

2. 实现USB去初始化接口Deinit。

   示例代码如下所示：

   ```screen
   static int UsbDriverDeinit(const void *context)
   {
       (void)context;
       return RESULT_RET_OK;
   }
   ```

3. 实现获取设备参数接口GetParam。

   示例代码如下所示：

   ```screen
   static int UsbGetParam(GetParamsType paramType, void *result)
   {
       if (paramType == GET_MODEL_ID) {
           DeviceModelId *devModeld = (DeviceModelId *)result;
           // 调试可用以下数据
           devModeld->subModelFlag = 0x01;
           devModeld->subModelId = 0x0;
           unsigned char modelId[] = {0x00, 0x04, 0x09};
           memcpy_s(devModeld->modelId, DEV_MODEL_ID_LEN, modelId, DEV_MODEL_ID_LEN);
       } else {
           printf("UsbGetParam unknown paramType:%d.\n", paramType);
           return RESULT_RET_ERROR;
       }
       return RESULT_RET_OK;
   }
   ```

4. 实现注册回调接口RegisterChannelCallback。

   示例代码如下所示：

   ```screen
   static ChannelCallback *g_usbChannelCallback;
   static int UsbRegisterChannelCallback(const ChannelCallback *callback)
   {
       g_usbChannelCallback = (ChannelCallback *)callback;
       return RESULT_RET_OK;
   }
   ```
