# 前台娱乐应用检测

## 场景说明

HiCar SDK会将在HiCar场景中正处于前台的应用，通知到车机侧。车机可以根据该结果，合理处理相关业务逻辑，例如当视频类应用处于前台时，车机侧可以通过调整音频缓存解决音画不同步问题。

前台应用检测相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[前台娱乐应用检测](https://developer.huawei.com/consumer/cn/doc/HiCar-References/foreground-application-0000002012273209)部分。

## 应用示例

HiCar SDK检测到当前处于HiCar前台的是视频类应用，将检测结果传递给车机，车机接收到有视频类应用处于前台的消息后，可以减小音频缓存；当车机接收到没有视频类应用处于前台的消息后，恢复正常的音频缓存，可以有效解决车机音画不同步的问题。

## 开发步骤

1. HiCar App会向车机发送前台应用消息（dataType=533），告知车机当前处于前台的应用，示例如下所示：

   ```screen
   {
      "status":1,
      "appType":"video",
      "appName":"com.huawei.himovie"
   }
   ```

2. 车机通过**DataReceive** 方法，判断**dataType**后可以收到上述具体数据内容，在处理完成自身业务逻辑后，反馈处理结果。

   如果自身逻辑正常完成，可以向HiCar发送处理完毕的消息（dataType=533），示例如下所示：

   ```screen
   {
       " RespCode":100000
   }
   ```

   如果自身逻辑处理失败，可以向HiCar发送处理失败的消息（dataType=533），示例如下所示：

   ```screen
   {
       " RespCode":-100000
   }
   ```
