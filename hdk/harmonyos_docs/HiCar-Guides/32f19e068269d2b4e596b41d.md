# 动态切换投屏尺寸

## 场景说明

车机侧改变投屏区域的宽高，手机侧接收车机侧发来的数据自适应调整显示的分辨率，达到较好的观感体验。

建议车机原始屏幕分辨率大于2k，分辨率按照全屏和2/3屏幕显示，应用显示效果最佳。

投屏窗口和原车应用窗口融合相关的数据格式说明请参考[《HUAWEI HiCar SDK API参考》](https://developer.huawei.com/consumer/cn/doc/HiCar-References/fusion-ui-windows-0000002625560304)。
> 说明
>
> 1. 该特性需手机侧HarmonyOS系统版本在6.1.0.120及以上。
> 2. 该特性当前仅在融合桌面中支持。

1. 手机车机连接时，车机上报真实的投屏区域宽高值，并监听手机上报的应用信息。
2. 连接成功后，车机将接收到的应用图标显示在指定区域。
3. 点击应用，投屏区域显示指定应用内容。
4. 车机侧改变投屏区域后，向手机发送投屏区域的宽高。手机根据宽高值调整投屏显示，并向车机发送隐藏蒙层消息。

## 开发步骤

1. 手机侧如果支持窗口大小动态调节，调用HiCarGetAdaptiveWindowAbility接口会返回1。

   ```screen
   void OnDeviceChange(DeviceChangeEvent event) {    
     if (event.type == HICAR_DEVICE_AUTH_SUCCESS) {      
        // 认证成功后，主动获取手机自适应窗口能力       
        int capability = HiCarGetAdaptiveWindowAbility();         
        if (capability == 1) {       // 支持自适应窗口能力的处理逻辑        
          LogPrint("自适应窗口能力: 支持"); 
          EnableAdaptiveWindow(true);
        } else {        // 不支持自适应窗口能力的处理逻辑         
          LogPrint("自适应窗口能力: 不支持"); 
          EnableAdaptiveWindow(false);
     }
   }}
   ```

2. 车机侧调整投屏显示区域时，显示车机侧的蒙层。

   ```screen
   std::unique_ptr<FrameLayout> container = std::make_unique<FrameLayout>(context); 
   // 创建蒙层视图 
   auto maskView = std::make_unique<MaskSurfaceView>(context);
   // 设置布局参数 
   FrameLayout::LayoutParams layoutParams(    
     FrameLayout::LayoutParams::MATCH_PARENT,    
     FrameLayout::LayoutParams::MATCH_PARENT 
   ); 
   // 添加蒙层到容器
   container->addView(maskView.get(), &layoutParams); 
   // 如果需要保持引用 
   maskView.release();
   ```

3. 车机侧调整完投屏区域宽高后，向手机侧发送新的宽高值。

   ```screen
   mHiCarAdapter->updateCarConfig(mCarConfig);
   // 如果Surface尺寸发生变化，发送尺寸信息
   if (mSurfaceSizeHasChanged) {
       // 创建JSON对象
       JSONObject jsonObject;
       jsonObject.put("code", 1);
       // 创建数据对象
       JSONObject dataObject;
       dataObject.put("width", mSurfaceWidth);
       dataObject.put("height", mSurfaceHeight);
       // 将数据对象添加到根对象
       jsonObject.put("data", dataObject);
       // 转换为JSON字符串并获取UTF-8字节
       std::string jsonString = jsonObject.toJSONString();
       std::vector<uint8_t> utf8Data(jsonString.begin(), jsonString.end());
       mHiCarAdapter->sendCarData(547, utf8Data.data(), utf8Data.size());
   }
   ```

4. 投屏区域绘制完成后，会给车机侧返回绘制完成的消息，车机侧需要做取消蒙层的操作。

   ```screen
   void onDataReceive(std::string deviceId, int dataType, std::vector<uint8_t> data) override {        
     switch (dataType) {            
       case 547: {               
         // 将从手机接收的命令字符转换成json数据                 
         JSONObject jsonData = CommonUtils::getJsonObject(data, dataType).orElse(nullptr);                
         if (jsonData != nullptr) {                   
            int code = jsonData.getInteger("code");                    
            if (code == 2) {                        
                hideMaskLayer(); // 隐藏加载蒙层                    
            }                
          }               
        break;            
        }           
        // 其他case分支...             
       default:                
        // 处理其他数据类型                
        break;        
     }    
   }
   ```
