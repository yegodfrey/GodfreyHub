# 设置无线连接参数

## 启用SDK无线连接功能

只有当HiCar SDK的无线连接功能被启用时，厂商HMI应用才可以正常调用接口发送BLE广播进行无线连接。

厂商HMI应用可以在SDK初始化或者运行时动态启用无线连接功能。

SDK初始化启用无线连接功能的示例代码如下所示：

```screen
CarConfig.Builder builder = new CarConfig.Builder();
......
//在SDK初始化时启用无线连接功能，值为true表示启用无线连接功能，值为false表示禁用无线连接功能
builder.withSupportWireless(true);
CarConfig carconfig = builder.build();
```

运行时动态启用无线连接功能的示例代码如下所示：

```screen
//在运行时动态更新是否启用无线连接功能
carconfig.updateSupportWireless(true);
```

## 设置支持的Wi-Fi 5G信道列表（Beta）

厂商车机对WiFi 5G信道的支持有差异，HiCar SDK支持厂商设置其车机支持的5G信道列表，SDK使用该列表中的信道创建热点，并保证手机连接热点时在该信道列表范围内进行协商，确保连接成功。如果厂商未设置该值，HiCar SDK默认使用以下列表中"[36,40,44,48,149]"的信道创建热点。

设置WiFi 5G信道列表的代码示例如下：

```screen
//设置车机信息
CarConfig.Builder builder = new CarConfig.Builder();

//设置WiFi 5G信道列表
int[] channels = new int[] { 36,40,44,48,149 };
builder.withSupport5gChannels(channels);

//更新WiFi 5G信道列表
carconfig.update5gChannels(channels);
```

## 设置蓝牙发射功率（Beta）

HiCar SDK通过BLE广播方式查找附近的手机，当手机靠近车机且收到BLE广播后，手机侧会弹框提示用户连接HiCar，广播的蓝牙发射功率决定了手机能收到广播的距离，功率强度越大，表明手机在较远的距离可以发现车机并进行连接，反之，手机必须靠近车机才能进行发现连接。
> 说明
>
> 蓝牙发射功率的取值范围为-128 ~ 127之间，厂商可以通过调整该值获取到手机靠近发现的最佳距离。
>
> 最佳距离约定：在实车环境下，手机距离中控0.7米以内100%弹出设备发现弹框，距离中控1.5米以外100%不弹出设备发现弹框。

设置蓝牙发射功率的代码示例如下：

```screen
//设置车机信息
CarConfig.Builder builder = new CarConfig.Builder();

//设置蓝牙发射功率
int advPower = -112; 
builder.withAdvPower(advPower);

//更新蓝牙发射功率
carconfig.updateAdvPower(advPower);
```
