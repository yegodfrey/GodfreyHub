# 本地语音车控（Beta）

## 场景说明

如果车机系统具备车辆空调、车窗、音量控制功能，车机在连接HiCar后为方便用户对车辆原生功能进行控制（例如通过HiCar语音控制），需要车机开放车控能力并实现与HiCar App数据交互。

车控相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[车辆控制（空调/车窗）](https://developer.huawei.com/consumer/cn/doc/HiCar-References/vehicle-control-0000001199339961)部分。

## HiCar App向车机查询车控能力

1. HiCar连接成功后，手机HiCar App会向车机发送请求报文（dataType=500），查询车机车控能力。车机将收到的数据内容如下：

   ```screen
   {
   	"VehicleControlCapability": {}
   }
   ```

2. 车机通过**DataReceive** 方法，判断**dataType** 后可以收到上述具体数据内容，准备完成车控相关数据后，可通过**HiCarSendData**接口上报数据。报文示例如下所示：

   ```screen
   {
   	"VehicleControlCapabilityResp": {
   		"volume": {
   			"support": "true",
   			"status": "unmute",
   			"maxVolume": "7",
   			"minVolume": "0",
   			"currentVolume": "6"
   		},
   		"airConditioner": {
   			"support": "true",
   			"maxTemperature": "30",
   			"minTemperature": "15",
   			"status": "on",
   			"currentTemperature": "25"
   		},
   		"skyLight": {
   			"support": "true",
   			"status": "close"
   		},
   		"vehicleWindow": {
   			"leftFrontSupport": "true",
   			"leftFrontStatus": "close",
   			"rightFrontSupport": "true",
   			"rightFrontStatus": "close",
   			"leftBackSupport": "true",
   			"leftBackStatus": "close",
   			"rightBackSupport": "true",
   			"rightBackStatus": "close",
   			"isPercentSupport": "false"
   		}
   	}
   }
   ```

## HiCar App向车机发送车控指令

1. 当HiCar App识别了用户的语音车控指令后，将向车机发送具体车控指令报文。报文示例如下所示：

   ```screen
   {
       "VehicleControl": {
             "airConditioner": {
                   "intent":"settemp",
                   "temperature":"25"
             }
       }
   }
   ```

2. 车机解析报文并执行车控指令。
3. 车机执行车控指令后需主动将最新的车控状态上报给HiCar App。报文示例如下所示：

   ```screen
   {
       "VehicleControlResp": {
            "respCode":"success",
            "airConditioner": {
                   "status":"on",
                   "currentTemperature":"25"
             }
        }
   }
   ```

## 车机主动向HiCar App上报车控状态

车机需要在车控状态发生变化后（例如用户手动调整了车窗、空调或天窗等），主动向HiCar App上报最新的车控状态。报文示例如下（与车机向HiCar App回应车控能力报文格式相同）：

```screen
{
	"VehicleControlCapabilityResp": {
		"volume": {
			"support": "true",
			"status": "unmute",
			"maxVolume": "7",
			"minVolume": "0",
			"currentVolume": "6"
		},
		"airConditioner": {
			"support": "true",
			"maxTemperature": "30",
			"minTemperature": "15",
			"status": "on",
			"currentTemperature": "25"
		},
		"skyLight": {
			"support": "true",
			"status": "close"
		},
		"vehicleWindow": {
			"leftFrontSupport": "true",
			"leftFrontStatus": "close",
			"rightFrontSupport": "true",
			"rightFrontStatus": "close",
			"leftBackSupport": "true",
			"leftBackStatus": "close",
			"rightBackSupport": "true",

		}
	}
}
```
