# 播放页中播放模式/播放速率显示与实际不一致

## 问题现象

通过"sendSessionEvent"方法设置播放模式/播放速率后，播放页中显示的播放模式/播放速率与实际设置的内容并不一致。

## 问题原因

当HiCar冷启动音频应用时，如果音频应用在200ms内初始化成功，并在此时调用"sendSessionEvent"方法通知HiCar播放模式/播放速率的初始值，HiCar内部的相关回调可能还未初始化完成，会导致设置无效，播放页显示与实际设置不一致。

## 解决措施

音频应用可以通过以下两种方式解决，任选其一即可。

方式一：在设置播放页界面参数的同时，提供播放模式/播放速率的初始值，这样HiCar冷启动音频应用时，在播放页中的播放模式/播放速率将会是正确的。示例代码如下所示：

```screen
private Bundle genExtras(){
...
    bundle.putInt("hicar.media.bundle.ALBUM_IMAGE_STYLE",0);        //设置播放页面的歌曲图片形状，0代表方形，后续将支持其他形状定制
    bundle.putInt("hicar.media.bundle.SUB_TITLE_STYLE",1);          //设置播放页面的第二行文字是歌手还是专辑，0代表歌手，1代表专辑
    bundle.putInt("hicar.media.bundle.THIRD_TITLE_STYLE",0);        //设置播放页面的第三行文字是专辑还是歌词，0代表专辑，1代表歌词
...
    // 设置HiCar首次冷启动打开音频应用时播放页默认的播放模式 0: LOOP_ALL, 1: LOOP_SINGLE, 2: SHUFFLE, 3: ORDER
    hicarUIStyle.putInt("hicar.media.bundle.PLAY_MODE", 0);
    // 设置HiCar首次冷启动打开音频应用时播放页默认的播放速率 0: 0.75倍速, 1: 1倍速, 2: 1.5倍速
   hicarUIStyle.putInt("hicar.media.bundle.PLAY_RATE", 1);
...
}
```

方式二：音频应用在"callMediaStart"回调方法完成音频服务初始化后，如果需要立即刷新播放模式/播放速率，此时可以延迟200~500ms再调用"sendSessionEvent"方法设置播放模式/播放速率。
