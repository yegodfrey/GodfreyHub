# 更新内容列表数据

## 场景说明

音频应用可以通过MediaSession.sendSessionEvent方法发送数据更新指令，主动刷新内容页/详情页展示数据。

## 接口说明

### 发送数据更新指令

|接口|参数|参数类型|说明|
|:---------------------------------------------------------|:-----|:-----|:------------------------------------------------------------------|
|MediaSession.sendSessionEvent(String action,Bundle extras)|action|String|数据更新指令，取值为"hicar.media.action.UPDATE_QUEUE"。|
|MediaSession.sendSessionEvent(String action,Bundle extras)|extras|Bundle|数据更新指令扩展参数，详见[表2](#ZH-CN_TOPIC_0000001119898505__table86132816374)。|
[**表1**数据更新相关接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:---------------------------|:-----|:---------------------------|
|hicar.media.bundle.RESULT|int|执行结果： * 0：成功 * -1：因其它或未知原因失败|
|hicar.media.bundle.PARENT_ID|String|需要更新的列表Media ID。|
[**表2**数据更新Bundle参数说明]

### 数据更新

音频应用在主动发送"hicar.media.action.UPDATE_QUEUE"指令后，HiCar会重新通过"hicar.media.action.LOAD_QUEUE"指令来获取列表信息，音频应用根据LOAD_QUEUE指令返回具体需要更新的数据即可。相关接口及数据结构参见前文[加载内容数据](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/load-content-data-0000001120118673)。

## 开发步骤

1. 音频应用在需要更新数据列表时，通过MediaSession.sendSessionEvent方法发送数据更新指令。

   示例代码如下所示：

   ```screen
   private void updateList(String updateParentId) {
       Bundle bundle = new Bundle();
       bundle.putInt("hicar.media.bundle.RESULT", 0);
       bundle.putString("hicara.media.bundle.PARENT_ID", updateParentId);
       mMediaSession.sendSessionEvent("hicar.media.action.UPDATE_QUEUE", bundle);
   }
   ```

2. 音频应用在onCustomAction方法中根据LOAD_QUEUE指令完成数据更新，详情参见前文[加载内容数据](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/load-content-data-0000001120118673)。
