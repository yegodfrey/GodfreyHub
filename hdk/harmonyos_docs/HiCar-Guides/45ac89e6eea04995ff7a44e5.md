# 验证无线连接

在完成无线连接相关配置后，厂商可以通过HiCar SDK软件包中的HiCarDemo.apk验证车机设备的有线连通性。

1. 运行HiCarDemo.apk。

   **图1**HiCarDemo运行初始界面示意（以实际界面为准）   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214047.21781321414400532491930359225656:50001231000000:2800:F83196D1B7F596EF19F754AF095496FBE80471EF8798E8604220FD90E1E7FF59.png "点击放大")

2. 通过无线方式连接手机和车机设备。

   如果无线连通，会正常弹出连接确认框，点击连接后，连接成功时车机将正常显示HiCar界面。

   如果无线不连通，请根据日志信息进行问题排查及解决。
