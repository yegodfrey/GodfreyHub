# 虚拟通话（Beta）

## 场景说明

HiCar默认通过Modem虚拟通话的方式处理运营商通话，这对厂商在通话回声抑制上提出了较高的要求。如厂商在处理运营商通话的回声抑制方面存在困难，可以采用蓝牙通话的方式处理HiCar运营商通话。该场景下，厂商需要在HiCar App询问车机是否支持Modem虚拟通话时，正确上报"不支持"的结果。

虚拟通话相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[虚拟通话](https://developer.huawei.com/consumer/cn/doc/HiCar-References/virtual-modem-0000001194799646)部分。

## 开发步骤

1. HiCar App会在完成连接和认证后向车机发送查询消息（dataType=523），查询车机是否支持Modem虚拟通话，示例如下所示：

   ```screen
   {
       "service":"virtualModem",
       "subService":"capability",
       "command":0
   }
   ```

2. 车机根据实际情况，返回支持结果。

   如果车机可以较好处理通话过程中回声抑制等问题，则响应支持。示例如下所示：

   ```screen
   {
       "service":"virtualModem",
       "subService":"capability",
       "command":1,
       "errorCode":100000
   }
   ```

   如果车机无法较好处理通话过程中回声抑制等问题，则响应不支持。示例如下所示：

   ```screen
   {
       "service":"virtualModem",
       "subService":"capability",
       "command":1,
       "errorCode":100003
   }
   ```

   若是车机不支持虚拟通话的情况下，车机本地蓝牙通话胶囊和HiCar通话胶囊同时存在，需要增加字段屏蔽HiCar通话胶囊。示例如下所示：

   ```screen
   {
       "service":"virtualModem",
       "subService":"capability",
       "command":1,
       "errorCode":100003,
       "data":{
           "showCallUI":0
       }
   }
   ```
