# 判断应用所在屏幕

#### 场景说明

应用如果需要在HiCar上展示差异化的内容（如屏蔽部分内容或额外显示部分内容），可以判断当前应用所在屏幕，根据判断结果如果是在车机屏幕上则进行差异化处理。

#### 判断方式

应用可以通过调用display.getDisplayByIdSync接口获取display对象，判断display对象中name属性值即可判断当前应用所在屏幕。相关属性值说明如下：

     * HiCar：当前应用在HiCar屏幕上显示
     * SuperLauncher：当前应用在超级桌面屏幕上显示
    
    //根据displayId获取display对象
    let curDisplay = display.getDisplayByIdSync(this.windowObj.getWindowProperties().displayId);
    
    if (curDisplay.name === 'HiCar' || curDisplay.name === 'SuperLauncher') {
      hilog.info(0x0000, 'testTag', '%{public}s', 'Application in HiCar or SuperLauncher');
    }

displayId也可以通过以下方式获取
    
    windowStage.getMainWindowSync().getWindowProperties().displayId
