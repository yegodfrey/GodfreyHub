# 管理车机连接

## 场景说明

手机和车机认证连接后，车机需要保存已认证的设备信息，并提供连接管理界面，用于协助用户在车机上断开、删除已认证的设备。

**图1**连接管理示意

厂商HMI应用可以通过HiCar SDK提供的接口管理已认证的设备，包括获取已认证设备列表、删除已认证设备、断开设备连接、连接设备等，以及支持通过断开设备和连接设备实现切换连接功能。

## 接口说明

|头文件|方法|说明|
|:------|:----------------------|:-------------------|
|hicar.h|HiCarGetTrustDeviceList|获取当前和车机完成鉴权认证后的设备列表。|
|hicar.h|HiCarDisconnectDevice|断开指定已认证设备。|
|hicar.h|HiCarDeleteTrustDevice|删除指定已认证设备。|
|hicar.h|HiCarReconnect|触发自动连接。|
[**表1**连接认证相关接口]

## 开发步骤

1. 厂商需要完成连接认证管理界面的设计和开发。该界面中需要包含已认证的设备列表，用户可以选择指定的已认证设备并对其进行删除操作。
2. 厂商HMI应用可以通过HiCar SDK接口获取认证设备信息展示在认证管理界面中，可获取的信息包括已认证手机标识、已认证手机名称、已认证手机蓝牙地址、上一次连接时间。

   示例代码如下：

   ```screen
   //获取已认证设备列表 
   TrustPhoneInfo info[10];
   TrustPhoneInfo *pinfo = &info;
   HiCarGetTrustDeviceList(&pinfo, 10); 

   //删除已认证设备，设备ID从获取认证设备列表中获取 
   HiCarDeleteTrustDevice(phoneId, idLen); 
   ```

3. 实现连接切换管理。当前HiCar并不支持多部手机同时与车机进行HiCar连接，但厂商可以在多部手机中切换到某一部与车机建立HiCar连接。

   > 说明
   >
   > 不支持在通过USB有线方式连接车机的多部手机中，切换HiCar连接。第一部手机成功建立HiCar有线连接后，后续手机仅能通过USB端口进行充电操作。

   针对无线连接场景，当驾驶环境中存在多部支持HiCar的手机时，厂商HMI应用可以在多部手机之间切换HiCar连接。

   假设手机A已经与车机建立HiCar连接，现在计划切换到手机B的示例代码如下所示：

   ```screen
   TrustPhoneInfo *phoneInfo = NULL;
   int32_t phoneNum = 8;
   int32_t realNum = 0;
   int32_t find = 0;

   phoneInfo = (TrustPhoneInfo *)malloc(sizeof(TrustPhoneInfo) * phoneNum);
   if (phoneInfo == NULL) {
   	return;
   }
   // 获取已认证过的设备列表
   realNum = HiCarGetTrustDeviceList(&phoneInfo, phoneNum);
   //查看需要连接的手机B是否在列表中
   for (int i = 0; i < realNum; i++) {
   	if (memcmp(phoneInfo[i].phoneBrMac, B_PhoneMac) == 0) {
   		// 找到手机B在列表中，可以触发对手机B的连接
   		find = 1;
   		break;
   	}
   }

   if (find == 1) {
   	//断开手机A
   	HiCarDisconnectDevice(A_PhoneId, Id_LENGTH);
   	//回连目标手机B，前提注意车机和手机蓝牙已配对。
   	HiCarReconnect(B_PhoneMac, MAC_LENGTH);
   }

   free(phoneInfo);
   phoneInfo = NULL;
   ```
