# 判断是否支持融合桌面

## 场景说明

融合桌面依赖手机侧的HiCar App及手机系统配合，厂商在实现融合桌面特性时，需判断当前的HiCar连接是否支持融合桌面能力。

* 当前HiCar连接支持融合桌面能力时，以融合桌面的形式进行显示。
* 当前HiCar连接不支持融合桌面能力时，则按照传统的形式进行显示。

## 接口说明

厂商可以通过如下接口判断当前HiCar连接是否支持融合桌面能力。

|方法|说明|
|:------------------------------------|:-------------------------------------------|
|int32_t HiCarIsSupportSuperLauncher()|返回当前HiCar连接是否支持融合桌面能力，返回结果为： * 0：支持 * 非0：不支持|
[**表1**判断融合桌面能力接口]

## 开发步骤

在HiCar连接成功后，例如通过DeviceChange接口接收到EVENT_DEVICE_CONNECT事件（值为101）后，通过HiCar SDK提供的HiCarIsSupportSuperLauncher()方法判断当前HiCar连接是否支持融合桌面能力。
