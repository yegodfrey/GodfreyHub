# 主动断开车机连接通知

## 场景说明

车机在支持自动连接的情况下，需要正确识别用户主动断开HiCar连接的场景，便于在该场景下不发起自动连接。

用户主动断开HiCar连接时，HiCar App会通知车机相关消息。主动断开车机连接通知相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[主动断开车机连接通知](https://developer.huawei.com/consumer/cn/doc/HiCar-References/disconnection-notification-0000001153460178)部分。

说明：收到该消息后，如果想立即返回原车机界面，也可以另起一个线程调用HiCarDisconnectDevice接口立即断开连接。

## 开发步骤

1. HiCar App在用户主动断开HiCar连接时，向车机发送通知消息（dataType=518），示例如下所示。

   ```screen
   {
       "isUserDisconnect":0
   }
   ```

2. 车机通过**DataReceive** 方法，判断**dataType** 后可以收到上述具体数据内容，通过**HiCarSendData**接口返回响应消息，示例如下所示。

   ```screen
   {
       "isUserDisconnect":1
   }
   ```
