# 方向盘按键

**规则2-2 未连接HUAWEI HiCar状态下，支持通过方向盘（短按或长按方向盘按键）进入连接界面。**

**在已连接HUAWEI HiCar状态下，通过方向盘按键唤醒HUAWEI HiCar语音助手，界面切换到前台。**
