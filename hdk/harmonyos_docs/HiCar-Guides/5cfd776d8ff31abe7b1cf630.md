# 说明

## 连接流程

为了支持HiCar无线连接，需要车机设备支持蓝牙（经典蓝牙及低功耗蓝牙）和Wi-Fi，并进行相应的适配。

**图1**HiCar无线连接步骤顺序   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214045.36889904995821541396245226145173:50001231000000:2800:DF9210F6AC664B82F2B678829CAA418E0FD34010578738BEAE0144D644A3B031.png "点击放大")

1. 手机和车机间建立RFCOMM连接。
2. 手机和车机间建立GC_AP连接。
3. 手机和车机间建立TCP Socket连接。
4. 手机和车机间启动HiCar投屏。

HiCar无线连接过程主要涉及：蓝牙服务发现、蓝牙RFCOMM连接、Wi-Fi连接。无线连接过程中消息交互过程如[图2](#ZH-CN_TOPIC_0000001194049481__fig1551342713350)所示。

**图2**无线连接消息交互   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214045.69361264225569982044098718754519:50001231000000:2800:900FC5EA9074F9087453A513D3FF056DB15818922152EB2592E3534E037975E4.png "点击放大")

手机和车机在无线连接时6类消息交互：

1. BLE（Bluetooth Low Energy）广播携带车机BR（Basic Rate）地址到手机，便于手机根据经典蓝牙BR地址建立BR链路。
2. 低速蓝牙控制通道（图中RFCOMM控制通道），用于孵化蓝牙数据通道和高速Wi-Fi控制通道。
3. 低速蓝牙数据通道（图中RFCOMM数据通道），用于进行HiCar鉴权。
4. 协商Wi-Fi高速通道，基于低速蓝牙控制通道协商高速Wi-Fi控制通道参数。
5. 高速Wi-Fi控制通道（图中Wi-Fi控制通道），用于孵化高速Wi-Fi数据通道。
6. 高速Wi-Fi数据通道（图中Wi-Fi数据通道），进行HiCar投屏。

## 涉及接口

为了保证车机可以正常完成上述信息交互，车机原生系统需要保留的Android原生接口如[表1](#ZH-CN_TOPIC_0000001194049481__table969111717130)所示。

|业务描述|业务流程|使用接口|
|:------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|BLE广播|车机发送BLE广播数据包时，携带车机BR地址|android.bluetooth.le.BluetoothLeAdvertiser.startAdvertisingSet android.bluetooth.le.AdvertisingSet.setAdvertisingData|
|开启/关闭热点|手机与车机建立GC_AP连接|android.net.wifi.WifiManager.setWifiApConfiguration android.net.wifi.WifiManager.saveConfiguration android.net.ConnectivityManager.startTethering android.net.ConnectivityManager.stopTethering|
|BR连接|手机向车机发起RFCOMM连接|android.bluetooth.BluetoothAdapter.listenUsingInsecureRfcommWithServiceRecord android.bluetooth.BluetoothDevice.createInsecureRfcommSocketToServiceRecord|
|关闭Wi-Fi|手机向车机建立GC_AP连接|android.net.wifi.WifiManager.setWifiEnabled|
[**表1**无线连接过程中依赖的车机原生接口]
