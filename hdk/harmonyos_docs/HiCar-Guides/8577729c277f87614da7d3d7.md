# 有线连接流程

HiCar支持USB有线连接，用户可以通过手机配套的USB线缆连接支持HiCar的手机和车机设备来使用HiCar。

手机和车机间支持多种USB模式，包括：仅充电、USB Storage、MTP、NCM和AOA。HiCar基于USB的有线连接支持通过NCM（暂不支持AOA）建立通道，进行数据传输。

1. 车机启动后初始化HiCar SDK，在初始化过程中SDK需要调用厂商实现的USB驱动，关于驱动部分的实现可参考HiCar SDK包中的"driver_usb.c"。另外，厂商需要在初始化时将车辆信息通过接口提供给HiCar SDK，该步骤通过厂商HMI应用实现，详情请参考后续[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000105632)。
2. 车机侦听USB设备插入事件，并根据vendorID判断是否华为手机或荣耀手机（包括新荣耀手机）。
3. 车机根据vendorID判断插入手机是华为手机或荣耀手机（包括新荣耀手机），则向手机发送一条USB控制信息，包含当前的车辆信息、是否支持NCM、IP和端口等，USB控制信息请参考[发送USB控制命令](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/send-usb-control-command-0000001050123765)。为了保证兼容更多的手机，车机需要同时启动mDNS Server，广播IP地址和端口，更多信息请参考[mDNS广播IP和Port](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/broadcast-ip-port-via-mdns-0000001059290770)。IP和端口在HiCar SDK中Nearby子模块在初始化USB驱动时，告知车机。
4. 车机在发送完USB控制信息后，等待手机USB切换为NCM模式。
5. 车机在侦听到手机切换为NCM模式后，会尝试建立连接通道。此时为了确保正常建立连接，车机需要将IP网口相关的信息配置到车机路由表中，详情请参考[配置车机路由](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/configure-route-table-0000001050002465)。
6. 手机与车机建立完通道后，HiCar SDK会向上层厂商HMI应用发送HICAR_DEVICE_CONNECTED事件。上层厂商HMI应用即可进行后续投屏操作，详情请参考开发厂商HMI应用章节的[建立有线连接](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/wired-connectivity-0000000000105665)。
