# 合作准入申请

## 成为HUAWEI HiCar合作伙伴

请参考[成为合作伙伴](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/join-us-0000001134281535)，完成华为帐号注册与企业实名认证，并加入合作伙伴计划，成为HUAWEI HiCar汽车硬件合作伙伴。

## 新建申请

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)，点击右上角"管理中心"，在左侧导航栏中，切换到"HUAWEI HiCar产品开发"。
2. 单击"+"，新建一款车机。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194817.68247106165659342330015278137760:50001231000000:2800:C9C754CC279009AFAEB6D882F5268CF98079743FECA3F243EBAB51E7AF04AF1C.png)

3. 在"车机详情"页面完善"车机信息"和"附件信息"。

   其中附件信息填写时，请注意：
   * 下载模板后填写上传。
   * 若车机操作系统为Linux，请在当前页面的"附件"区域上传《HUAWEI HiCar生态Linux版本HiCar SDK编译工具入库声明》。
   * 其它证书在合作准入阶段为非必填项，但需提前规划，确保认证阶段可以提供，以免影响认证进度。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194817.87181456620321738618857497136122:50001231000000:2800:26550E7014B2B3A506DEF920FC26E5913B5D6B877D80544C9608E3D0F6D35A5A.png)

4. 确保信息无误后，点击"提交申请"。
5. 在弹出的联系人信息窗口中，完善联系人信息。建议填写项目经理、产品经理、认证/测试经理等联系人。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194817.07725209483464393855718914266995:50001231000000:2800:340F7D76E0D795D427FE3B102A50E4E147FC3ED1E2EA2BEC90928F5269A62416.png)

6. 点击"确认"后，进入待审核页面。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194817.60792726760205923839744119630550:50001231000000:2800:338CFA3FDBFFF4A7A4493FDD3C2E541066CE0626A4996BD85B858ABACBDE5A40.png)

## 后续处理

### 审核未通过

如果车机审核未通过，请查看备注、附件、审核记录和详情，重新编辑并提交。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194818.64738309810592382670460683982735:50001231000000:2800:8703A3872AE7245494A548B89210B568C0AB1FDE0CE567C951181F4A9E2D7455.png)

### 审核通过

车机审核通过后，点击车机卡片，可以为该车机创建不同的车型，并进入集成认证阶段。详情请参见[集成认证](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/integration-and-certification-0000002021043025)。
