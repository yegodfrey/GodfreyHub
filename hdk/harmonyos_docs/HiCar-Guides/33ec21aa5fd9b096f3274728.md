# 使用元数据构建车机原生界面

## 场景说明

HiCar通过元数据的方式向车机提供音频、通话、消息、场景类数据的基础信息，车机获取到这些元数据后，可以通过车机原生界面展示，从而实现手机内容与车机界面无缝融合的原生体验。
