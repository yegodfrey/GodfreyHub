# 注册事件侦听回调

## 场景说明

厂商HMI应用需要调用SDK提供的接口"HiCarRegisterListener"注册事件侦听，并根据回调中的不同事件进行业务处理。

## 接口说明

厂商HMI应用需要注册的事件侦听回调方法如[表1](#ZH-CN_TOPIC_0000001050066223__table101151034195012)所示。
> 说明
>
> 厂商HMI应用通过DeviceChange，DeviceServiceChange，DataReceive回调会收到HiCarSDK发送的一些消息或事件，如果在这些回调中想进一步调用HiCarSDK提供的API，需要在另外一个线程中去调用。

|接口|回调方法|说明|
|:----------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|GetHiCarHandle|获取HiCar操作句柄。|
|CarListener|DeviceChange|当手机与车机连接发生变化时回调该方法。对应的连接事件说明请参考[表2](#ZH-CN_TOPIC_0000001050066223__table42321929463)。|
|CarListener|DeviceServiceChange|当服务发生变化时回调该方法。对应的服务事件说明请参考[表2](#ZH-CN_TOPIC_0000001050066223__table42321929463)。|
|CarListener|DataReceive|当SDK接收到手机侧HiCar App发送数据时回调该方法。厂商HMI应用可通过该方法与HiCar App进行数据交互，接收来自HiCar App的车控指令、导航焦点变化通知等数据，更多内容请参考[数据交互](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/interactions-0000001051779174)。|
|CarListener|GetVideoData|当投屏后回调该方法获取投屏视频流数据，更多内容请参考[投屏说明](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/interaction-process-0000001050121798)。|
|CarListener|GetSecureFileSize|与认证文件相关的回调方法。|
|CarListener|ReadSecureFile|与认证文件相关的回调方法。|
|CarListener|WriteSecureFile|与认证文件相关的回调方法。|
|CarListener|RemoveSecureFile|与认证文件相关的回调方法。|
[**表1**回调方法]

|回调方法|相关事件|事件说明|
|:------------------|:-----------------------------------------|:---------------------------------------------------------------------------------------------|
|DeviceChange|HICAR_DEVICE_CONNECTED = 101|设备已连接，HMI应用需要显示连接界面。|
|DeviceChange|HICAR_DEVICE_DETECT_DISCONNECT = 106|检测到车机和手机心跳断开，HMI应用需要退回到原生车机界面。|
|DeviceChange|HICAR_DEVICE_MANUAL_DISCONNECT = 110|当用户主动在手机侧断开连接，HMI应用需要记录下该事件标志，直到车机下次重启清除该标志。|
|DeviceChange|HICAR_DEVICE_ADV_TIMEOUT = 111|支持发BLE广播的车机，在发广播页面超时的时候，HMI应用会收到该事件，需要提示用户重新刷新连接码。|
|DeviceServiceChange|HICAR_DEVICE_SERVICE_PAUSE = 202|当用户返回原生车机系统界面时，HMI应用会收到该事件，HMI应用应该退到后台，并调用HiCarPauseProjection。|
|DeviceServiceChange|HICAR_DEVICE_SERVICE_RESUME = 203|当投屏界面在后台，收到外部来电或者方控唤醒语音助手时，HMI应用会收到该事件，HMI应用应该将投屏界面显示到前台，并调用HiCarStartProjection。|
|DeviceServiceChange|HICAR_DEVICE_DISPLAY_SERVICE_PLAYING = 207|投屏成功通知。厂商HMI应用接收到该事件后，即可通过"GetVideoData"回调方法获取视频流数据。|
|DeviceServiceChange|HICAR_DEVICE_VIRMODEM_CALLING = 307|运营商电话接通事件。HMI应用接收到此事件，需要通知车机Mic设置回声消除等参数，避免通话过程中出现回声。|
|DeviceServiceChange|HICAR_DEVICE_VIRMODEM_HANGUP = 308|运营商电话挂断事件。HMI应用接收到此事件，可以将车机Mic设置恢复到正常状态。|
|DeviceServiceChange|HICAR_DEVICE_VOIP_CALLING = 309|VoIP电话接通事件。HMI应用接收到此事件，需要通知车机Mic设置回声消除等参数，避免通话过程中出现回声。|
|DeviceServiceChange|HICAR_DEVICE_VOIP_HANG_UP = 310|VoIP电话挂断事件。HMI应用接收到此事件，可以将车机Mic设置恢复到正常状态。|
|DataReceive|HICAR_DATA_MANUAL_DISCONNECT=518|当用户主动在手机侧断开连接，HMI应用需要记录下该事件标志。该消息比110消息更可靠，以此消息为准。收到此消息后另起一个线程调用HiCarDisconnectDevice可以立即断开连接。|
[**表2**回调事件]

更多关于回调的参数及说明，请参考《HUAWEI HiCar SDK API参考》。如何根据回调事件进行业务处理的内容，请参考本文档后续章节。

2. 厂商HMI应用通过HiCarRegisterListener注册事件侦听回调。示例代码如下所示：

   ```screen
   CarListener carListener = {0};

   carListener.GetHiCarHandle = GetHiCarHandle;
   carListener.DeviceChange = DeviceChange;
   carListener.DeviceServiceChange = DeviceServiceChange;
   carListener.DataReceive = DataReceive;
   carListener.GetSecureFileSize = GetSecureFileSize;
   carListener.ReadSecureFile = ReadSecureFile;
   carListener.WriteSecureFile = WriteSecureFile;
   carListener.RemoveSecureFile = RemoveSecureFile;
   carListener.GetVideoData = GetVideoData;

   printf("Call HiCarRegisterListener.\n");
   int retCode = HiCarRegisterListener(&carListener);
   ```
