# 适配说明

HiCar可以共享使用车机的部分传感器设备数据，用于特定场景下的功能增强。此时需要厂商根据HiCar的接口定义实现这部分数据上报接口，供HiCar调用。其中，适配的必须性说明如下：

* Audio：厂商必须适配，否则HiCar将无法正常使用车机的MIC及Speaker。
* Camera：厂商选择性适配。
* GPS及车身数据：厂商选择性适配。
