# 合作说明

HUAWEI HiCar智慧出行生态合作关注产品体验与消费者感知，主要涵盖"产品开发"与"上市基础配套资料"两大内容，申请产品合作的伙伴需同时负责好这两项工作的开展，保证最终上市后的产品体验与消费者认知口碑。

2026年起，华为将基于《[HUAWEI HiCar生态产品合作伙伴标准及权益](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/standard-and-benefit-0000002517146826)》，根据市场表现、创新能力、产品体验、营销上市、合作投入等维度的合作与增长情况来评估，为伙伴匹配相应权益，给予伙伴更好的支持，加快产品上市以及提升产品消费者体验，保证双方的合作有序开展，推进HUAWEI HiCar生态健康发展。

> 说明
>
> 为了提升合作的效率和质量，请车企在合作之前，仔细阅读本建议，熟悉合作流程及要求，并按照本建议配置相关的团队和人员。
>
> 如果车企对本建议存在疑问或意见，可以在与HiCar团队建立联系后，展开讨论，后续以讨论达成的一致结论进行合作。

## 合作双方职责说明

|厂商|主要职责|
|:-|:------------------------------------------------------|
|车企|制定并监控项目总体计划，协调相关资源，完成车机侧HiCar合作准入/开发/自测试/认证/上市/运营维护等工作。|
|华为|审核HiCar合作项目，提供HiCar SDK、集成文档、技术支持、认证准出和商用许可结论。|

## 合作范围

车企在与华为针对HiCar进行合作时，可以合作的范围如下表所示。

|合作范围|合作内容|
|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**HiCar需求互锁和技术评估**|正式合作前，华为与车企完成生态合作目标互锁，产品需求范围锁定和相关技术评估。 HiCar车机端功能分为必选和可选两种，必选功能为车企集成开发时必须实现的，否则无法通过认证；可选功能可由车企和华为讨论后确定是否支持。如，必选功能包括：无线连接、自动回连、连接手机蓝牙启动厂商HMI应用（连接手机蓝牙推荐用户使用HiCar）等；可选功能包括：共享上网、音乐/电话/导航元数据展示、车机摄像头集成（通过车机摄像头拨打视频电话）等。 此外，一些共创的新特性也可与华为讨论。 确定本项目HiCar相关需求后，华为会对车机软硬件能力进行审核，评估车机是否满足HiCar准入标准。|
|**HiCar开发和自测** **试**|华为与车企合作完成HiCar在目标车型/平台的集成开发和预置，为消费者提供HiCar服务。|
|**HiCar认证**|车企在完成车机端HiCar集成开发后，按照华为提供的测试用例100%完成测试并提供测试报告，华为审查测试报告，并抽查相关测试项目，根据结果给出是否技术认证评审通过的结论，认证通过且车企完成HiCar上市准备工作后发送电子/实体证书。|
|**HiCar上市**|车企应在支持HiCar的车型/设备的宣传物料如在官方Social宣传，官网配置表，三方门户网站配置表，线下销售物料（产品折页，配置表，使用手册/说明书），培训材料，OTA更新说明等体现支持HiCar功能，确保消费者感知。华为在官网露出支持HiCar的车型和设备列表。|
|**HiCar运营维护**|华为与车企在目标车型/平台的生命周期范围内，共同保障车机系统/HiCar的升级迭代，并针对可能出现的HiCar相关问题/舆情进行联合解决。|
[**表2**合作范围]
