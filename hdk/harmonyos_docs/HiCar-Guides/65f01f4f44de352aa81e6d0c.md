# 开放能力简介

## 概述

HUAWEI HiCar（以下简称HiCar ）为手机应用提供了一系列软件开发工具包，为应用开发者接入HiCar提供API接口及应用模板，便于应用开发者能够快速将已有的应用接入HiCar，在出行场景中为用户提供服务。

## 接入说明

应用开发者只需要在原有应用的基础上集成HiCar开放能力即可支持 HiCar，而不需要单独为HiCar设计开发单独的应用。

应用开发者需要根据HiCar设计规范，单独设计开发专门用于在HiCar车机屏幕上显示的界面，避免直接复用已有的用于在手机屏幕上展示的界面。
