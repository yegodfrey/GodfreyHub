# 处理HiCar前后台显示

在融合桌面形态下，HiCar会通知车机跟随场景变化，将HiCar切换到前台或后台，典型场景如下：

* 车机与手机通过HiCar进行连接时，HiCar可能会先显示投屏前界面，供用户确认授权后，再进行业务的初始化。投屏前界面包括：安全驾驶声明、隐私协议变更确认、超级隐私模式、OOBE引导界面等。投屏前界面会在首次连接或部分投屏前界面有更新时显示，因此该情景下，需要在连接成功时先将HiCar拉至前台，待用户确认后，方可将HiCar切换至后台执行融合桌面相关业务逻辑。
* 应用启动失败时（如网络较差时，音乐模板界面加载失败，用户点击失败提示界面的确认按钮等），需要直接返回车机界面，此时车机需要将HiCar切换到后台。
* 从车机融合桌面点击图标进入部分应用时，该部分应用中存在返回按钮，点击后需要直接返回车机界面，此时车机需要将HiCar切换到后台。

## 接口说明

融合桌面中与HiCar App交互的接口设计，沿用了已有车机与HiCar App交互接口的机制，所以在开发融合桌面特性之前，请参考[数据交互](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/interactions-0000001051779174)了解交互机制。

处理HiCar前后台显示过程中与HiCar App交互的具体数据格式说明，请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[融合桌面HiCar前后台显示](https://developer.huawei.com/consumer/cn/doc/HiCar-References/fusion-ui-foreground-background-0000001975553062)部分。

## 开发步骤

1. HiCar App会在需要车机进行HiCar前后台操作时，向车机发送报文（dataType=532）。车机将收到的数据内容如下：

   ```screen
   {
       "ProjectAction" : {
           "Background" : false
       }
   }
   ```

2. 车机通过**DataReceive** 方法，判断**dataType** 后可以收到上述具体数据内容，根据Background字段将HiCar界面切换到前台或后台，切换完成后通过**sendData**接口返回响应消息，示例如下所示：

   ```screen
   {
       "ProjectActionResp" : {
           "RespCode" : 100000
       }
   }
   ```
