# 连接异常提示页面

**建议 3-1 连接异常页面符合规范布局，与功能完整**。

## P.4 自动开启车机蓝牙加载页面

场景：当车机侧蓝牙未打开，点击HUAWEI HiCar图标，自动开启蓝牙Loading的界面，提示语"蓝牙开启中"， 备注提示语"HUAWEI HiCar 无线连接过程需要使用蓝牙"，如状态栏有蓝牙图标显示连接状态可省略全屏蓝牙加载页面。
