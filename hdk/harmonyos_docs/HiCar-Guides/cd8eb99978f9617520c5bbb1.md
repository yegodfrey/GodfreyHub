# 管理语音交互

## 场景说明

HiCar支持用户在驾驶过程中通过语音交互的方式使用HiCar提供的功能，例如语音导航、语音控制空调、语音播放音乐等。在用户正常使用HiCar语音交互之前，厂商需要完成HiCar语音交互的唤醒。

HiCar支持图标点击唤醒、物理按键唤醒、语音唤醒三种方式唤醒语音交互。

### 1.图标点击唤醒

用户通过点击语音球图标唤醒HiCar语音交互，整个过程都由HiCar App完成，无需厂商关注。

### 2.物理按键唤醒

用户通过方向盘中的语音按键唤醒HiCar语音交互，此时需要厂商解析物理按键事件，并根据HiCar SDK提供的接口（**sendHotWord**）将唤醒数据发送到手机侧的HiCar App，由HiCar App完成后续的语音识别处理。

HiCar使用语音唤醒键的原则为：

* 如果车机具有本地原生语音功能，则采用长按唤醒HiCar语音交互。进入语音交互状态后，再次长按重新唤醒语音，短按退出语音交互。
* 如果车机没有本地原生语音功能，则采用短按唤醒HiCar语音交互。进入语音交互状态后，再次长按重新唤醒语音，短按退出语音交互。

当语音唤醒键被触发时，厂商可以根据HiCar当前的语音唤醒状态，决定分发开始语音识别或结束语音识别按键事件。HiCar语音状态相关内容请参考[语音空闲/唤醒状态](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/voice-status-0000001051370067)。

### 3.语音唤醒

用户直接通过唤醒词唤醒HiCar语音交互。该场景包含两种子场景：

* 用户通过手机语音助手唤醒HiCar语音交互，整个过程都由HiCar App完成，无需厂商关注。
* 用户通过车机原生的语音识别应用唤醒HiCar语音交互，此时需要厂商在车机原生语音识别应用中识别"小艺小艺"，并根据HiCar SDK提供的接口（**sendHotWord**）将唤醒数据发送到手机侧的HiCar App，由HiCar App完成后续的语音识别处理。

|frontEndInfo|car|-|必选|map|车辆信息。|

[**表2**车机侧语音交互接口]

HiCar语音处于唤醒播报状态时，如果车机原生语音助手被唤醒，厂商可以通过向HiCar发送"stopVoiceRecognize"意图，取消HiCar语音唤醒，从而避免出现原生语音和HiCar语音同时播报的情况。

更多唤醒数据内容请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[车机侧语音唤醒](https://developer.huawei.com/consumer/cn/doc/HiCar-References/voice-wakeup-0000001199330033)部分。

## 开发步骤

### 物理按键唤醒

1. 厂商需要根据自身车机系统自行完成物理按键事件的解析。
2. 唤醒按键事件触发后调用HiCar SDK提供的**sendHotWord**接口发送唤醒数据。

   组装唤醒数据并发送的示例代码如下所示：

   ```screen
   String hotWordStr =
   "{\n" +
   "	\"frontEndInfo\": {\n" +
   "		\"car\": {\n" +
   "			\"micNumber\": 2,\n" +
   "			\"speakerNumber\": 4\n" +
   "		},\n" +
   "		\"centralControl\": {\n" +
   "			\"vendorName\": \"XX\",\n" +
   "			\"version\": \"10.0.0.12\"\n" +
   "		},\n" +
   "		\"intent\": \"startVoiceRecognize\",\n" +
   "		\"voice\": {\n" +
   "			\"infoToVendorCloud\": \"HicarManager\",\n" +
   "			\"vendorName\": \"10.0.0.12\",\n" +
   "			\"version\": \"12\"\n" +
   "		},\n" +
   "		\"wakeType\": \"buttonPress\"\n" +
   "	}\n" +
   "}\n";
   mHiCarAdapter.sendHotWord(hotWordStr);
   ```

3. 厂商在发送完唤醒数据后，HiCar语音助手将进入唤醒状态，此时为了达到更好的收音效果，厂商需对车机MIC设置回声消除、降噪等参数。

   厂商可通过语音状态接口判断当前语音唤醒状态，在语音状态处于唤醒状态时进行回声消除、降噪等处理，语音状态相关内容请参见[语音空闲/唤醒状态](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/voice-status-0000001051370067)。

4. 停止语音按键事件（或者本地语音助手）触发后调用HiCar SDK提供的**sendHotWord**接口发送停止唤醒数据。

   物理按键结束语音交互的示例代码如下所示：

   ```screen
   String hotWordStr =
   "{\n" +
   "	\"frontEndInfo\": {\n" +
   "		\"car\": {\n" +
   "			\"micNumber\": 2,\n" +
   "			\"speakerNumber\": 4\n" +
   "		},\n" +
   "		\"centralControl\": {\n" +
   "			\"vendorName\": \"XX\",\n" +
   "			\"version\": \"10.0.0.12\"\n" +
   "		},\n" +
   "	        \"intent\": \"stopVoiceRecognize\",\n" +
   "		\"voice\": {\n" +
   "			\"infoToVendorCloud\": \"HicarManager\",\n" +
   "			\"vendorName\": \"10.0.0.12\",\n" +
   "			\"version\": \"12\"\n" +
   "		},\n" +
   "		\"wakeType\": \"buttonPress\"\n" +
   "	}\n" +
   "}\n";
   mHiCarAdapter.sendHotWord(hotWordStr);
   ```

### 语音唤醒

1. 厂商原生语音系统识别"小艺小艺"。
2. 组装唤醒数据并通过HiCar SDK提供的**sendHotWord**接口发送到HiCar App。

   组装唤醒数据并发送的示例代码如下所示：

   ```screen
   String hotWordStr ="{" +
   "    \"frontEndInfo\":" +
   "    {\"wakeType\":\"voice\"," +
   "    \"intent\":\"startVoiceRecognize\"" +
   "   ,\"voice\":{\"wakeWord\":\"小艺小艺\"}" +
   "    }" +
   "}"
   mHiCarAdapter.sendHotWord(hotWordStr);
   ```
