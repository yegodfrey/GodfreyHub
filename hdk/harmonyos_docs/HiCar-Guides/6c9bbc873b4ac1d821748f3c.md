# 无法在"我的"页签显示多层级内容

## 问题现象

用户可以在音频应用中播放/收藏专辑内容，而音频应用在HiCar环境的"我的"页签中，在类似"最近播放"/"我的收藏"中只能显示到专辑这一层级，无法显示专辑内的曲目。

## 问题原因

当前HiCar不支持专辑嵌套，即只支持在专辑内展示单首曲目，不支持在专辑内展示专辑。

在"我的"页签中，"最近播放"/"我的收藏"作为专辑存在，其中只能展示单首曲目，无法在嵌套专辑后再展示专辑内的曲目。

## 解决措施

音频应用可以将专辑看做成曲目展示在"最近播放"/"我的收藏"中，当用户点击时，直接播放整个专辑内容。同时，为了更好维护播放状态，在"我的"页签设置"最近播放"/"我的收藏"时，通过指定"hicar.media.metadata.SHOW_PLAY_BUTTON"参数为"false"控制宫格封面上不显示播放按钮。
