# 入口

**建议 5-1 在车机首页显示HUAWEI HiCar入口。**

入口可采用应用图标、信息卡片等形式。HUAWEI HiCar未连接状态下，点击入口用于触发连接；已连接状态下，点击入口可显示来自手机的应用列表。
