# 处理相关回调

## 处理PIN码回调

厂商HMI应用可以通过接口"HiCarGetPinCode"获取PIN码，显示到连接界面中，供手机用户输入。

|头文件|方法|说明|
|:------|:--------------|:------------------|
|hicar.h|HiCarGetPinCode|厂商HMI应用通过该接口获取PIN码。|
[**表1**获取PIN码相关接口]

1. 厂商HMI应用通过HiCarGetPinCode方法获取PIN码，并将其显示在连接界面中。

   请参考《HUAWEI HiCar 设备接入UX设计规范》设计连接界面。

   获取PIN码的示例代码如下所示：

   ```screen
   uint8_t pinCode[8] = {0};  
   HiCarGetPinCode(pinCode, 8);   
   ```

2. 如果获取PIN码失败，请参考《HUAWEI HiCar 设备接入UX设计规范》显示对应的失败反馈界面。

## 处理认证回调

HiCar SDK会对成功连接过的手机和车机进行认证，认证过的设备无需输入PIN码即可再次连接。

厂商HMI应用需要将上述认证信息保存在车机系统中，并通过HiCar SDK提供的回调方法完成认证文件的读取、保存和删除操作。
> 说明
>
> HiCar SDK通过回调向厂商HMI应用提供的认证数据已经过白盒加密，厂商HMI应用仅需保证存储安全即可。
>
> 建议厂商规划专门的安全存储区域，存储认证文件。

|接口|方法|说明|
|:----------|:----------------|:-------------------|
|CarListener|GetSecureFileSize|获取认证文件大小。|
|CarListener|ReadSecureFile|读取认证文件信息。|
|CarListener|WriteSecureFile|保存认证信息到车机本地文件或安全存储区。|
|CarListener|RemoveSecureFile|删除安全认证文件。|
[**表2**处理认证回调相关接口]

在[注册事件侦听回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/register-event-listener-0000000000105633)中已注册的认证相关回调方法中完成认证文件处理逻辑。

认证回调的示例代码如下：

```screen
int32_t GetSecureFileSize(const char *filename)
{    
    FILE* fp;
    int32_t size = 0;

    if (filename == NULL) {
        printf("GetSecureFileSize param null.\n");
        return -1;
    }

    char filenameInBox[256] = {0};
    sprintf(filenameInBox, "%s/%s", HICHAIN_FILE_PATH, filename);
    fp = fopen(filenameInBox, "rb");
    if (fp == NULL) {
        printf("fopen null.\n");
        return 0;
    }

    if (fseek(fp, 0L, SEEK_END) != 0) {
        printf("fseek error.\n");
        fclose(fp);
        return -1;
    }

    size = ftell(fp);
    fclose(fp);

    return size;
}

int32_t ReadSecureFile(const char *filename, uint32_t offset, uint8_t *buf, uint32_t len)
{
    FILE* fp;
    int32_t size = 0;

    (void)offset;

    if (filename == NULL || buf == NULL) {
        printf("ReadSecureFile param null.\n");
        return -1;
    }

    char filenameInBox[256] = {0};
    sprintf(filenameInBox, "%s/%s", HICHAIN_FILE_PATH, filename);
    fp = fopen(filenameInBox, "rb");
    if (fp == NULL) {
        printf("fopen null.\n");
        return 0;
    }

    size = fread(buf, sizeof(uint8_t), (size_t)len, fp);
    fclose(fp);

    return size;
}

int32_t WriteSecureFile(const char *filename, uint32_t offset, uint8_t *buf, uint32_t len)
{
    (void)offset;
    FILE* fp;
    size_t size;

    if (filename == NULL || buf == NULL) {
        printf("WriteSecureFile param null.\n");
        return -1;
    }

    char filenameInBox[256] = {0};
    sprintf(filenameInBox, "%s/%s", HICHAIN_FILE_PATH, filename);
    fp = fopen(filenameInBox, "wb");
    if (fp == NULL) {
        printf("fopen null.\n");
        return 0;
    }

    size = fwrite(buf, sizeof(uint8_t), (uint32_t)len, fp);
    fflush(fp);
    fclose(fp);

    if (size != len) {
        printf("WriteSecureFile error.\n");
        return -1;
    }

    return 0;
}

int32_t RemoveSecureFile(const char *filename)

}
```

## 处理连接事件回调

厂商HMI应用在手机和车机连接后，可以通过回调方法获取到具体的连接事件，并根据不同的连接事件完成相应的逻辑处理。例如在收到断开连接事件后，退出厂商HMI应用。

|类|方法|说明|
|:----------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|DeviceChange|HiCar SDK通过回调的方式向厂商HMI应用通知连接相应的事件： * HICAR_DEVICE_CONNECTED（值为101）：设备已连接。收到连接成功事件后，厂商HMI应用需要显示连接动画（在投屏成功或超时之前，连接动画需要一直显示）。在显示连接动画时，如果想显示正在连接的设备名称，可以通过"HiCarGetTrustDeviceList"方法获取已认证设备信息，详情请参见[管理车机连接](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/connection-management-0000000000105737)。 * HICAR_DEVICE_DETECT_DISCONNECT（值为106）：设备已断开连接。收到连接断开事件后，厂商HMI应用应进行断开连接、释放资源等操作。|
|CarListener|DataReceive|* HICAR_DATA_MANUAL_DISCONNECT（值为518）：手机侧主动断开。收到连接断开事件后，厂商HMI应用应进行断开连接、释放资源等操作。|
[**表3**处理连接事件回调相关接口]

处理连接事件回调的示例代码如下所示：

```screen
void DeviceChange(const char *deviceId, uint32_t idLen, int state, int errorCode)
{
    printf("DeviceChange, deviceId:%s, state:%d\n", deviceId, state);
    switch (state) {
        case HICAR_DEVICE_CONNECTED:
        // 显示连接动画
        break;
        case HICAR_DEVICE_DETECT_DISCONNECT:
        // 退出会车机界面
        break;
        default:
        break;
    }
}
```
