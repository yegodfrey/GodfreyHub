# 反初始化SDK

## 场景说明

HiCar SDK的初始化和注册、认证过程会保持一些资源，因此需要厂商HMI应用在退出或者HiCar SDK底层执行发生异常时，主动调用"HiCarRelease"接口释放资源。

## 接口说明

|头文件|方法|说明|
|:------|:-----------|:-----------------------------------------------------|
|hicar.h|HiCarRelease|厂商HMI应用应该在不使用HiCar业务时，调用HiCarRelease接口进行HiCar SDK反初始化。|
[**表1**反初始化接口]

## 开发步骤

通过HiCarRelease方法进行反初始化。示例代码如下所示：

```screen
// 释放  
int retCode = HiCarRelease();
```
