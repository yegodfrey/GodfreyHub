# 界面说明

成功连接HUAWEI HiCar后，HiCar Simulator的投屏区将显示HUAWEI HiCar界面，开发者可以操作投屏区的HUAWEI HiCar。

投屏区：位于中部，根据开发者选择的车机屏幕规格，自动调整投屏区的大小和分辨率。

操作模拟区：位于底部，这些按钮均是模拟车机按键，按键功能：

1. "设置"模拟键：点击进入"设置"页面，提供分辨率切换、语言切换和日志查看等功能。
2. "语音唤醒"模拟键：唤醒语音助手，如果语音助手已经被唤醒，则关闭语音助手。
3. "拨号"模拟键：拨打电话，投屏区应显示通话记录。
4. "挂断"模拟键：如果正在通话中，断开通话。
5. "上一曲"模拟键：如果有音乐正在播放，切换到上一节目。
6. "播放"/"暂停"模拟键：播放音乐/暂停正在播放的音乐。
7. "下一曲"模拟键：如果有音乐正在播放，切换到下一节目。
8. "演示模式"模拟键：切换到当前平板的实际分辨率尺寸。
9. "隐藏"模拟键：将底部模拟按键区域隐藏掉，只显示当前投屏区域。当从屏幕左右两侧触发"返回"操作或点按物理"返回"按键时，底部区域会再次恢复。
