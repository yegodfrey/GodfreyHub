# 车机蓝牙推荐使用HiCar

为了推荐用户使用手车互联功能，简化用户首次连接HiCar的步骤，车机可以在检测到连接手机蓝牙后，在车机界面中推荐用户使用HiCar。现增加**从车机侧发起推荐** 使用的交互流程，车机侧推荐优先级高于[手机侧推荐](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/bluetooth-hmi-app-0000001382050134)（建议厂商手机侧推荐、车机侧推荐中二选一进行实现）。

厂商可以按照如下步骤来实现车机蓝牙推荐功能：

1. 在连接上蓝牙设备之后，先根据指定的Rfcomm进行SDP查询判断是否华为设备，再通过设备类型判断是否手机设备，二者都满足则认为对端是支持HiCar的华为手机。示例代码如下所示：

   ```screen
   static int g_cur_fd = -1;
   #define HUAWEI_RFCOMM_UUID_STR  "0000FE35-0000-1000-8000-00805F9B34FB"
   #define PHONE_MAJOR_CLASS       0x0200

   static void close_current_socket(void)
   {
       if(g_cur_fd > 0)
       {
           close(g_cur_fd);
           g_cur_fd = -1;
       }
   }
   static int cancel_bluetooth_discovery(int hci_dev_id)
   {
       int sock = hci_open_dev(hci_dev_id);
       if(sock < 0)
       {
           return -1;
       }
       hci_cancel_inquiry(sock, 1000);
       close(sock);
       return 0;
   }

   int is_huawei_phone(int hci_dev_id, bdaddr_t *remote_bdaddr, uint16_t dev_major_class)
   {
       if(remote_bdaddr == NULL)
       {
           printf("dev error: null ptr\n");
           return 0;
       }
       // 校验设备大类必须是手机 0x0200
       if(dev_major_class != PHONE_MAJOR_CLASS)
       {
           printf("dev error:not phone, major:0x%04X\n", dev_major_class);
           return 0;
       }
       cancel_bluetooth_discovery(hci_dev_id);
       close_current_socket();

       // 1. 创建RFCOMM socket
       int fd = socket(AF_BLUETOOTH, SOCK_STREAM, BTPROTO_RFCOMM);
       if(fd < 0)
       {
           printf("create rfcomm socket fail errno:%d %s\n",errno,strerror(errno));
           close_current_socket();
           return 0;
       }
       g_cur_fd = fd;

       // 2. 通过SDP查询UUID拿到rfcomm通道号
       sdp_session_t *sdp_sess = sdp_connect(remote_bdaddr, 0, SDP_RETRY_IF_BUSY);
       if (!sdp_sess)
       {
           printf("sdp connect fail\n");
           close_current_socket();
           return 0;
       }
       uuid_t target_uuid;
       sdp_uuid16_create(&target_uuid, 0xFE35);
       sdp_list_t *attr_list = NULL, *search_list = NULL;
       sdp_list_append(&search_list, &target_uuid);

       uint8_t rfcomm_channel = 0;
       sdp_record_t *rec = sdp_service_search_attr_req(sdp_sess, search_list,SDP_ATTR_RFCOMM_CHANNEL, attr_list, NULL);
       if(rec && rec->attr)
       {
           rfcomm_channel = rec->attr->val.uint8;
           sdp_record_free(rec);
       }
       sdp_list_free(search_list,0);
       sdp_close(sdp_sess);

       if(rfcomm_channel == 0)
       {
           printf("sdp can not find FE35 channel\n");
           close_current_socket();
           return 0;
       }
       printf("查询rfcomm成功\n");
       close_current_socket();
       return 1;
   }
   ```

2. 查询本地HUAWEI HiCar连接设备记录和推荐记录，若车机无连接记录并且小于最大推荐次数，则弹出HiCar推荐弹框。
