# 业务介绍

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126084404.41123317283411642838024867135984:50001231000000:2800:386FF21BED2AD3A161CEBD70456B6A9CD24A78C0D4864E6D9959E64582203751.png)

HUAWEI HiCar（以下简称HiCar）是华为提供的人-车-家全场景智慧互联（HUAWEI HiCar Smart Connection）解决方案，具备如下特点：

     * 安全交互：以安全为前提的极简交互（Safety）
     * 无感互联：手机/IoT设备和汽车无感全互联（Smart Connection）

     * 硬件互助：手机和汽车资源共享（Resource Sharing）

     * 生态共享：用户体验在车内、车外无缝流转（Seamless Experience）

HiCar将移动设备和汽车连接起来，利用汽车和移动设备各自的特点以及多设备互联能力，为消费者提供便捷、智能、安全的出行体验。

#### 概述

消费者从手机应用市场下载支持HiCar的应用，日常在手机上正常使用，当手机连接到支持HiCar的车辆时，支持HiCar的应用会显示在车机屏幕的HiCar主界面中。

开发者无需为HiCar开发独立的应用，只需在现有应用的基础上针对HiCar进行部分适配。

#### 实现原理

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260126084404.74325019340823168470186137918134:50001231000000:2800:0E3076E278C3C1E8CCE1759A6065ADE6A9FFAED513979D0700260A57C09481E9.png)

HiCar通过分布式软总线技术、分布式虚拟化能力和应用服务共享虚拟化技术，构建了一个开放的平台解决方案。支持HiCar的应用，在手机上安装和运行，手机中的HiCar服务将应用启动到汽车硬件设备屏幕上（例如车机中控屏幕，后续皆以车机屏幕举例），从而实现手机应用在车机屏幕上显示的效果。

#### 约束与限制

当前支持的手机、车型请参考：[HUAWEI HiCar](https://consumer.huawei.com/cn/phones/hicar/)。

#### 与相关Kit的关系

[Car Kit（车服务）](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/car-api)：包含导航类和出行互联类，提供地图导航聚合能力集和监听分布式业务状态、事件能力。

[Ability Kit（程序框架服务）](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ability-api)：使用Ability Kit中的意图框架，通过意图框架拉起HiCar上支持的应用，比如通过语音指令拨打电话、发起导航、播放音乐等操作。

[AVSession Kit（音视频播控服务）](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/avsession-api)：提供音视频播控服务，在语音交互场景，通过AVSession Kit给车机发送语音指令，具体参考[提供语音交互功能](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/voice-interaction-0000002005036064)章节。
