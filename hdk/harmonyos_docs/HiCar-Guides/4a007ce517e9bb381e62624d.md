# 扫码连接

当厂商计划通过无线方式连接HiCar，但车机无法提供BLE广播进行发现连接时，可以通过扫码连接方案实现无线连接。

## 连接约束

扫码连接是无线连接的一种补充形式，当且仅当车机无法进行BLE广播时才可以使用。如果车机支持通过BLE广播进行发现连接时，请勿使用扫码连接方案。即不存在无线连接PIN码界面与扫码界面同时出现的场景。

## 连接流程

1. 厂商HMI应用启动后初始化HiCar SDK。用户进入到扫码界面，厂商HMI应用要将车机蓝牙状态更改成可扫码可连接状态。
2. 厂商HMI应用通过HiCar SDK接口获取二维码码值，为了防止二维码信息泄露，厂商HMI应用需要每隔两分钟重新获取码值重新生成二维码图片。
3. 用户通过手机扫码，识别后手机会有发现弹框提示用户发现汽车。
4. 用户点击连接后，开始建立蓝牙BR连接，进行认证鉴权。
5. 认证鉴权成功后，开始建立Wi-Fi连接，进行HiCar投屏，显示HiCar界面后连接成功。

## 适配说明

厂商选择通过扫码连接方案实现HiCar无线连接时，无需关注本文档的[蓝牙](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/bluetooth-0000001193969601)，但仍需要根据[Wi-Fi](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/wifi-0000001147929890)完成Wi-Fi相关配置。

厂商在HMI应用中实现扫码连接相关功能的说明，详见后续章节[建立扫码连接](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/scan-to-connect-0000001051090204)。
