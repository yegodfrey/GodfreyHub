# 进度条拖动

## 场景说明

播放页的进度条可配置支持进度条拖动的功能。

如果音频应用在[表2](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/set-ui-parameters-0000001078018960#ZH-CN_TOPIC_0000001078018960__table711014219226)配置了支持进度条拖动的功能，则需要实现onSeekTo接口的功能。

如果曲目为试听曲目，全部时长的进度条不能支持拖动，则同时需要实现[表2](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/update-song-0000001078467008#ZH-CN_TOPIC_0000001078467008__table134871534193614)中试听曲目的起始和结束时长。播放页进度条则会只显示试听时间。

## 接口说明

|需要实现的回调方法|参数|参数类型|说明|
|:-------------------------------------------------------------|:--|:---|:----------|
|android.media.session.MediaSession.Callback.onSeekTo(long pos)|pos|Long|进度跳转到pos位置。|
