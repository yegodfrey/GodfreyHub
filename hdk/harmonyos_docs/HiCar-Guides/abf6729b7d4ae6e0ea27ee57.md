# 车机摄像头拍照

## 场景说明

如果车机支持控制车载摄像头进行拍照操作，连接HiCar后，用户可以通过HiCar语音操控摄像头拍照。

操作车机摄像头拍照相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[车载摄像头拍照](https://developer.huawei.com/consumer/cn/doc/HiCar-References/vehicle-mounted-camera-0000001153450250)部分。

## 开发步骤

1. HiCar App查询车机是否支持操作摄像头拍照。

   1. HiCar App会在连接成功后向车机发送查询消息（dataType=522），查询车机是否支持操作摄像头进行拍照，示例如下所示：

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":0
      }
      ```

   2. 车机通过**onDataReceive** 方法，判断**dataType** 后可以收到上述具体数据内容，通过**HiCarAdapter::sendCarData** 接口返回支持情况。

      车机支持操作摄像头拍照，示例如下所示：

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":0,
          "errorCode":100000,
          "data":{
              "camera":{
                  "isControlSupported":3
              }
          }
      }
      ```

      车机不支持操作摄像头拍照，示例如下所示：

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":0,
          "errorCode":100004
      }
      ```

2. HiCar App语音操控车机拍照，车机完成拍照操作并返回响应消息。

   1. HiCar App向车机发送拍照指令消息，示例如下所示：

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":1,
          "data":{
              "camera":{
                  "position":3
              }
          }
      }
      ```

   2. 车机自行完成拍照操作，并根据操作结果返回响应消息。 成功后返回消息示例如下所示：

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":1,
          "errorCode":100000
      }
      ```

      失败后返回消息示例如下所示：

      ```screen
      {
          "service":"photo",
          "subService":"capability",
          "command":1,
          "errorCode":100004
      }
      ```

3. 车机在非HiCar触发拍照时，主动上报HiCar。

   车机在非HiCar触发的情况下，自行完成摄像头拍照后，为了避免与HiCar语音产生冲突，需要主动上报HiCar。示例如下所示：

   ```screen
   {
       "service":"photo",
       "subService":"capability",
       "command":2,
       "data":{
           "camera":{
               "position":3
           }
       }
   }
   ```
