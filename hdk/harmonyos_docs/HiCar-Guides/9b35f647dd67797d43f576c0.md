# 获取设备模拟器

## 获取设备

应用开发者在与华为明确应用接入合作计划后，将会收到华为寄送调测模拟器设备。如未收到，可联系华为侧项目接口人获取。

HUAWEI HiCar（以下简称HiCar）模拟器设备以及模拟环境包括如下软硬件：

1. 华为手机（例如，HUAWEI Mate30 Pro），预装可开启Debug模式的HiCar App，该版本不同于华为应用市场的HiCar App版本，开发者请勿自行将其升级至华为应用市场版本，届时将会导致无法进行应用调测。
2. 华为平板（例如，HUAWEI MatePad Pro），预装模拟器软件HiCar Simulator，用于模拟HUAWEI HiCar车机环境。HiCar Simulator适配特定的EMUI版本，开发者请勿自行升级EMUI版本，届时将会导致HiCar Simulator无法使用。
3. 连接线。两种连接方案，任选一种即可：
   1. OTG转接器+Type-C连接线，用来连接华为手机和华为平板。
   2. 双头Type-C连接线，用来连接华为手机和华为平板。

## 注意事项

**注意事项-1：不要升级华为手机和华为平板系统，并且关闭系统自动升级功能，方法如下** ：

1. 关闭华为平板自动升级功能：通过"设置>系统>软件更新"进入软件更新界面后，点击右上角"齿轮![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194819.20672825562356478519248125626669:50001231000000:2800:EB150098FBADA8512D1EA521C1F20E50B18DA9C2B791399B89E9882CCE467C41.jpg)"图标，进入软件更新设置界面，关闭"WLAN环境自动下载"和"夜间安装"两个选项。如收到系统更新的提示请选择忽略更新。
2. 关闭华为手机自动升级功能：通过"设置>系统和更新>软件更新"进入软件更新界面后，点击右上角"齿轮![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194820.30236705732958855053464361510552:50001231000000:2800:17C8835FB95076A461B8326198EE929B9ACF216331CDEC54871A54457D7827BD.jpg)"图标，进入软件更新设置界面，关闭"WLAN环境自动下载"和"夜间安装"两个选项。如收到系统更新的提示请选择忽略更新。

**注意事项-2：建立HUAWEI HiCar连接之前，需要注意以下事项：**

1. 在使用HUAWEI HiCar模拟器之前，**需要打开华为平板的蓝牙开关，关闭Wi-Fi开关**。
2. 请尽量使用华为原装Type-C数据线，不要使用多合一数据线。
