# 建立有线连接

## 交互流程

在进行有线连接之前，可能需要对车机设备的路由系统进行相应的配置，具体内容请参考[有线连接流程](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/wired-connection-process-0000001050002451)。

## 启用SDK有线连接功能

只有当HiCar SDK的有线连接功能被启用时，HiCar SDK才会处理USB插入事件，从而进行有线连接。

SDK初始化启用有线连接功能的示例代码如下所示：

```screen
// 在初始化时设置是否支持有线连接，具体设置请参考API接口说明
CarConfig config;
Config.connectInfo.connectAllowType = 0x02; // 仅支持有线时的设置
```

## 处理认证回调

有线连接过程中，不需要车机侧展示PIN码信息。PIN码信息由HiCar SDK内部通过USB通道直接发送给手机侧，用户在手机侧也不需要输入PIN码信息。

在有线连接过程中，尽管用户不需要输入PIN码信息，但仍然需要完成认证流程，因此认证回调接口仍然需要厂商应用实现。有线连接的认证回调实现和无线连接使用相同的逻辑与处理函数，实现示例代码请参考[处理认证回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callback-0000001195856541#section16702192691018)。

## 处理连接事件回调

厂商HMI应用在手机和车机连接后，可以通过回调方法获取到具体的连接事件，根据事件进行投屏、退出应用等操作，具体处理连接事件回调的方式可以参考无线连接章节的[处理连接事件回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callback-0000001195856541#section12985733201014)。
