# 处理页签点击

## 场景说明

当用户点击内容页页签时，音频应用会收到页签点击指令，音频应用可根据实际业务需要在收到页签点击指令后完成相应的业务处理，例如音频应用可以在收到页签点击指令后，主动向HiCar发送内容更新指令，从而更新用户点击的页签内容。

## 接口说明

|接口|参数|参数类型|说明|
|:----------------------------------------------------------------|:-----|:-----|:--------------------------------------------------------------------|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|action|String|页签点击指令，取值为"hicar.media.action.CLICK_TAB"。|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|extras|Bundle|页签点击指令扩展参数，详见[表2](#ZH-CN_TOPIC_0000001078018962__table1094034618172)。|
[**表1**页签点击指令相关接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:-----------------------------------|:------|:------------------------------------------------------------------------------------------------------------------------------------------------|
|hicar.media.action.CLICK_TAB_ID|String|点击的页签的Tab ID，即之前为页签设置的Media ID。|
|hicar.media.action.CLICK_IS_INIT|Boolean|点击时该页签是否已经初始化： * true：音频应用可以通过"hicar.media.action.UPDATE_QUEUE"指令完成数据更新。 * false：建议音频应用此时不进行操作，因为此时HiCar会通过"hicar.media.action.LOAD_QUEUE"指令获取数据。|
|hicar.media.action.CLICK_IS_RE_CLICK|Boolean|是否重复点击页签： * true：重复点击。当前展示页签A，点击页签A即为重复点击。 * false：非重复点击。当前展示页签A，点击页签B即为非重复点击。|
[**表2**页签点击指令扩展参数说明]

## 开发步骤

1. 音频应用在onCustomAction方法中针对action入参识别页签点击指令。

   示例代码如下所示：

   ```screen
   @Overrride
   public void onCustomAction(@NonNull String action, @Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       switch(action){
           case "hicar.media.action.CLICK_TAB":         

               break;
           default:
               break;
       }
   }
   ```

2. 从页签点击指令中获取扩展参数，并根据业务需要完成业务处理，如果是主动更新数据，可以参考前文[更新内容列表数据](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/update-content-all-0000001119898505)。

   示例代码如下所示：

   ```screen
   @Overrride
   public void onCustomAction(@NonNull String action, @Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       switch(action){
           case "hicar.media.action.CLICK_TAB":
               // 点击的tab的id
               String clickTabId = extras.getString("hicar.media.action.CLICK_TAB_ID");
               // 当点击该tab时，该tab是否已经初始化
               boolean isTabInit = extras.getBoolean("hicar.media.action.CLICK_IS_INIT");
               // 是否是重复点击该tab的情况
               boolean isTabReClick = extras.getBoolean("hicar.media.action.CLICK_IS_RE_CLICK");
               
               // 应用可以在此处理自己的业务

               break;
           default:
               break;
       }
   }
   ```
