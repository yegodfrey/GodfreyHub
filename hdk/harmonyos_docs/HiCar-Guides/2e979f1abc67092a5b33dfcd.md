# 配置Wi-Fi

## 场景说明

HiCar SDK业务能力建立在Wi-Fi P2P通道上，车机作为Group Owner（GO），手机作为Group Client（GC），建立P2P连接。
> 说明
>
> 1. 车机侧热点名称长度需小于48字节。
> 2. 车机侧Wi-Fi热点需要加密。
> 3. 车机侧Wi-Fi热点的IP地址请勿使用172.30.x.x网段，避免冲突，造成HiCar不可用。

## 接口说明

厂商需实现HiCar SDK包中设备接口（driver_adapt.h）的FcDriverAdaptOps类型变量及其中的部分接口，需要实现的接口如[表1](#ZH-CN_TOPIC_0000001057492388__table1412554713555)所示。

|结构体|结构体成员名称|说明|
|:---------------|:----------------------|:----------------------------------------------------|
|FcDriverAdaptOps|name|Wi-Fi driver名称，必须填写为WIFI_DRIVER_NAME。|
|FcDriverAdaptOps|desc|Wi-Fi设备接口描述，厂商可根据需要自行填写，如wifi driver。|
|FcDriverAdaptOps|Init|Wi-Fi driver初始化，HiCar SDK在使用其他Wi-Fi接口前，首先会调用该接口进行初始化。|
|FcDriverAdaptOps|Deinit|Wi-Fi driver去初始化，厂商可按需进行相关操作，如释放资源等。|
|FcDriverAdaptOps|SetParam|HiCar SDK会调用该接口设置Wi-Fi本地IP相关参数，厂商需要把该IP设置为本机IP地址。|
|FcDriverAdaptOps|GetParam|HiCar SDK在分配GC信息时会调用该接口向厂商获取空闲IP作为GC的IP地址。|
|FcDriverAdaptOps|RegisterChannelCallback|回调注册函数，HiCar SDK会调用该接口将HiCar相关回调函数传递给厂商。|
|FcDriverAdaptOps|CreateWifiChannel|HiCar SDK会调用厂商接口创建AP或GO，相关信息会从入参传入。|
[**表1**FcDriverAdaptOps结构体]

FcDriverAdaptOps类型的变量实现方式请参考HiCar SDK包中Wi-Fi demo代码（driver_wifi.c），其中须注意，变量名称必须为"g_fcDriverWifiOps"

HiCar SDK会按照以下顺序调用厂商实现的接口：

1. 调用Init初始化Wi-Fi。
2. 调用RegisterChannelCallback注册HiCar回调函数。
3. 调用CreateWifiChannel创建AP或GO。
4. 调用SetParam将Wi-Fi本地IP设置给厂商。
5. 调用GetParam获取GC的IP地址。
6. HiCarRelease接口被调用时，Deinit接口会被同步调用，完成资源清理工作。

## 开发步骤

1. 实现Wi-Fi初始化接口Init ，初始化和Wi-Fi相关的资源，启动Wi-Fi协议栈。
2. 实现Wi-Fi去初始化接口Deinit，在接口中释放Wi-Fi相关资源。
3. 实现RegisterChannelCallback接口，将HiCar传递的ChannelCallback类型指针保存记录。
4. 实现CreateWifiChannel接口，开启Wi-Fi AP。

   CreateWifiChannel接口入参wifiInfo需以int*类型解释，参数值为默认信道频率，厂商可选择使用默认信道频率或自定义信道频率。

   厂商在该接口中需开启Wi-Fi AP模式，并在开启AP模式成功后，调用[3](#ZH-CN_TOPIC_0000001057492388__li14852184682410)中回调函数ChannelCallback的ChannelStateChange接口通知HiCar车机的AP已建立，其中ChannelStateChange方法入参为WifiParams格式，需传入AP的SSID、key、网卡MAC地址、Wi-Fi信道频段。

   示例代码如下所示：

   ```screen
   /*
   * @function   : WifiCreateAP
   * @brief      : 创建热点, 这里需要注意WifiCreateAP
   如果传递下来的frequency,如果和已经创建的热点的频率不一致，应该关闭热点， 重新起指定频率的热点。
   * @param[IN]  : context，参数未启用，传参NULL
   * @param[IN]  : wifiInfo, 传参frequency(int*)
   * @return     : 0 成功，非0 失败
   */
   static int WifiCreateAP(const void *context, const void *wifiInfo)
   {
       (void)context;
       if (wifiInfo == NULL) {
           printf("WifiCreateAP[in], invalid input.");
           return RESULT_RET_ERROR;
       }

       int frequency = (int)(*(int *)wifiInfo);
       printf("WifiCreateAP[in] Wifi Channel frequency:%d.\r\n", frequency);

       // 需要设备侧生成ssid 和 key, 若不满足要求要和华为接口人说明.
       char ssid[WIFI_SSID_LEN + 1] = "HiCar-12345";
       char key[WIFI_KEY_LEN + 1] = "123456789";

       // 网卡 mac地址
       char mac[STR_MAC_ADDR_LEN + 1] = "xx:xx:xx:xx:xx:xx";

       WifiParams apParams;
       (void)memset(
           &apParams, 0, sizeof(WifiParams));  // (void)memset_s(&apParams, sizeof(WifiParams), 0, sizeof(WifiParams));

       apParams.frequency = frequency;  // 理论上车机要使用Nearby下发的频率，如果不使用下发频率，要和华为接口人说明.
       (void)strncpy(apParams.ssid, ssid, WIFI_SSID_LEN);   //(void)strcpy_s(apParams->ssid, WIFI_SSID_LEN + 1, ssid);
       (void)strncpy(apParams.key, key, WIFI_KEY_LEN);      // (void)strcpy_s(apParams->key, WIFI_KEY_LEN + 1, key);
       (void)strncpy(apParams.mac, mac, STR_MAC_ADDR_LEN);  // (void)strcpy_s(apParams->mac, WIFI_MAC_LEN + 1, mac);

       printf("WifiCreateAP[in] ssid:%s, key:%s, mac:%s, freq:%d.\r\n",
           apParams.ssid,
           apParams.key,
           apParams.mac,
           apParams.frequency);

       // 热点创建成功后, 上报EVENT_CREATE_WIFI_SUCCESS事件给Nearby
       if (g_wifiCallback != NULL) {
           g_wifiCallback->ChannelStateChange(CHANNEL_P2P, EVENT_CREATE_WIFI_SUCCESS, &apParams, sizeof(WifiParams));
       }

       return RESULT_RET_OK;
   }
   ```

5. 实现设置Wi-Fi参数接口SetParam。

   SetParam接口入参paramType为枚举值SET_WIFI_LOCAL_IP，此时厂商需以WifiSetIpParam格式解释入参，设置ip、mask、gateway到本机（厂商也可以使用自定义的ip地址）。

   设置本机ip信息后，厂商需调用ChannelStateChange通知HiCar设置已完成，调用方式为ChannelStateChange(CHANNEL_P2P, EVENT_CONFIG_IP_SUCCESS, apIp, 0)，其中参数apIp为车机侧ip地址的字符串格式，变量类型为char *。

   示例代码如下所示：

   ```screen
   /*
    * @function   : WifiSetParam
    * @brief      : 设置wifi driver的参数
    * @param[IN]  : paramType 参考SetParamsType
    * @param[IN]  : context 为paramType对应的参数值
    * @return     : 0 成功，非0 失败
    */
   static int WifiSetParam(SetParamsType paramType, const void *context)
   {
       if (context == NULL) {
           printf("WifiSetParam[in] invalid input, paramtype:%d.\r\n", paramType);
           return RESULT_RET_ERROR;
       }

       printf("WifiSetParam[in] paramtype:%d.\r\n", paramType);
       if (paramType == SET_WIFI_LOCAL_IP) {
           WifiSetIpParam *ipParam = (WifiSetIpParam *)context;
           printf("WifiSetParam[in] paramType:SET_WIFI_LOCAL_IP, local ip:%s.", ipParam->ipAddr);

           // 设置本端的IP成功后，上报EVENT_CONFIG_IP_SUCCESS事件给Nearby
           g_wifiCallback->ChannelStateChange(CHANNEL_P2P, EVENT_CONFIG_IP_SUCCESS, NULL, 0);
       } else {
           printf("WifiSetParam[in] unknown paramtype:%d.\r\n", paramType);
       }

       return RESULT_RET_OK;
   }
   ```

6. 实现获取Wi-Fi参数接口GetParam。

   GetParam接口适配使用到枚举值GET_DEV_MAC, GET_WIFI_ABILITY 和 GET_GC_IP：
   * GET_DEV_MAC时，以macParam类型传递参数。厂商需要给出本段网卡的MAC地址，示例代码见HiCar SDK包中的driver_wifi.c。
   * GET_WIFI_ABILITY时，以wifiAbilityParam类型传递参数。厂商需要将各项WIFI能力赋值给wifiAbilityParam, 示例代码见HiCar SDK包中的driver_wifi.c。
   * GET_GC_IP时，以GcIpParam类型传递参数。厂商需要查询本机GO网段中的空闲IP（厂商应从网段分配空闲IP供HiCar使用），传递给HiCar SDK，若该接口返回-1，HiCar将使用固定默认GC IP地址。

   以IP为10.42.0.2为例，示例代码如下所示：

   ```screen
   /*
    * @function   : WifiGetParam
    * @brief      : 设置GC_IP参数
    * @param[IN]  : paramType 参照GetParamsType
    * @param[IN]  : result,获取的参数值
    * @return     : 0 成功，非0 失败
    */
   static int WifiGetParam(GetParamsType paramType, void *result)
   {
          if (paramType == GET_GC_IP) {
                GcIpParam *gcIpParam = (GcIpParam*)result;
                strcpy(gcIpParam->gcIp, "10.42.0.2")；
                gcIpParam->len = strlen("10.42.0.2")；
                printf("get gc ip success");
          } 
   }
   ```
