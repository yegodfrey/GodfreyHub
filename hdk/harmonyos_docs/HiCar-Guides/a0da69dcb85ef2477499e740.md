# 发送手机桌面宽高到手机

## 场景说明

在手机连接成功并开始投屏前，若车机当前显示的桌面为手机桌面，则手机会向车机发送一个命令，要求车机将手机桌面等比放大的窗口宽高通过5xx消息发送给手机。手机重新计算后，显示投屏内容。

## 接口说明

在HiCarListener的onDataReceive中监听手机发给车机的546消息，当stateCode为6时需要将车机创建的手机桌面窗口宽高传递给手机，参数为resolutionWidth/resolutionHeight/width/height：

* resolutionWidth：必须，手机在113连接认证成功后报给车机的手机视频流宽度，单位为px。
* resolutionHeight：必须，手机在113连接认证成功后报给车机的手机视频流高度，单位为px。
* width：非必须，车机上手机桌面窗口的宽度，单位为px。
* height：非必须，车机上手机桌面窗口的高度，单位为px。

另外，width和height可不传给手机。如果传递，手机会根据width和height等比计算视频流宽高。如果不传递，则手机自动根据当前视频流分辨率宽高进行resize。此处是防止车机上手机桌面窗口的width和height未根据resolutionWidth和resolutionHeight等比计算而做的兜底。一般不用传width和height，但resolutionWidth和resolutionHeight必须传，用于手机侧同步当前上报的视频流宽高。若上报的宽高和当前手机视频流宽高不一致（比如连接前手机竖屏，上报的是竖屏宽高，连接后手机横屏），则手机会进一步做调整，将新调整的宽高通知车机进行等比适配，保证手机侧与车机侧显示一致。

## 开发步骤

收到手机通知消息后，将连接前手机上报给车机的视频流宽高传给手机对比计算。

```screen
// 监听546消息，当stateCode为6时，将手机连接时上报的宽高和车机上手机桌面宽高发送给手机。
class HiCarListener implements Carlistener {
    @Override
    public void onDataReceive(String deviceId, int dataType, byte[] data) {
        switch (dataType) {
            case DeviceData.DATA_TYPE_SMALL_WINDOW_STATE: // 546
                JSONObject jsonData = CommonUtils.getJsonObject(data, datatype).orElse(null); // 将从手机接收的命令字符串转换为JSON数据
                int stateCode = jsonData.getInteger("stateCode");
                String stateData = jsonData.getString("stateData");
                if (stateCode == 6) {
                    JSONObject jsonData = new JSONObject();
                    jsonData.put("stateCode", 6);
                    JSONObject jsonStateData = new JSONObject();
                    jsonStateData.put("resolutionWidth", mPhoneWidth); // 手机上报的视频流宽度
                    jsonStateData.put("resolutionHeight", mPhoneHeight); // 手机上报的视频高度
                    // 可选
                    jsonStateData.put("width", mPhoneDesktopWidth); // 手机桌面窗口宽度
                    jsonStateData.put("height", mPhoneDesktopHeight); // 手机桌面窗口高度
                    jsonData.put("stateData", jsonStateData.toJSONString());
                    hiCarAdapter.sendCarData(DeviceData.DATA_TYPE_SMALL_WINDOW_STATE, jsonData.toJSONString());
                }
                break;
        }
    }
}
```
