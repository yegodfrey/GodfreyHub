# 标准与权益

面向对象：前装车企/品牌、后装车载设备品牌。

评估周期：2026年按照半年度评估，例如2026年1月1日前完成评定，标准和权益在2026H1生效，以此类推。

评估标准：[表1 合作伙伴评估标准](#ZH-CN_TOPIC_0000002517146826__table11997124433313)。

权益设置：[表2 合作伙伴权益](#ZH-CN_TOPIC_0000002517146826__table155891929113412)。

权益项：根据后续资源情况逐步增加，例行刷新公布。

加入方式：[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)注册验证、认证级/优选级根据评估标准评定。
