# 配置车机路由

有线连接需要车机系统支持USB虚拟NCM网卡功能。当USB连接车机时，车机端会映射出一块名为"wwan0"的网卡（不同车机映射的网卡名称可能不同），同时HiCar SDK会为此网卡在网段192.168.66.100~192.168.66.255内随机配置一个IP地址。为了能够快速组网，厂商需要配置此网段的车机路由信息。

请厂商根据实际车机系统进行修改。
