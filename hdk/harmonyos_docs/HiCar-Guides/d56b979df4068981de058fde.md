# 车机视频流解码能力上报

## 场景说明

部分车机由于硬件性能原因，在播放视频时可能由于视频流解码阻塞出现视频卡顿现象。为缓解这一问题，HiCar支持车机上报当前视频流解码是否阻塞的信息，动态调整发送到车机侧的视频流帧数量。

车机视频流解码能力上报相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[车机视频流解码能力](https://developer.huawei.com/consumer/cn/doc/HiCar-References/video-stream-decode-0000001918457336)部分

## 应用示例

HiCar SDK检测到当前手机支持动态调整视频流帧数，将支持情况传递给车机。车机接收到消息后，当车机解码视频流阻塞时上报阻塞状态到手机侧，手机侧降低每秒发送到车机侧的视频流帧数；当车机解码视频流不阻塞时上报不阻塞状态，手机侧恢复正常的视频流帧数，从而有效解决车机侧视频播放卡顿的问题。

## 开发步骤

1. HiCar App会向车机发送当前手机是否支持动态调整视频流帧数的消息（dataType=535），示例如下所示：

   ```screen
   {
       "isSupport"：true
   }
   ```

2. 车机通过**onDataReceive** 方法，判断**dataType**后可以收到上述具体数据内容，当isSupport为true时，车机侧根据实际情况上报视频流解码阻塞状态。

   如果解码视频流出现阻塞，可以向HiCar发送阻塞状态（dataType=535），请求降低视频流帧数，示例如下所示：

   ```screen
   {
       "isBlocking":true
   }
   ```

   如果解码视频流不阻塞，可以向HiCar发送不阻塞状态（dataType=535），请求恢复视频流帧数，示例如下所示：

   ```screen
   {
       "isBlocking":false
   }
   ```
