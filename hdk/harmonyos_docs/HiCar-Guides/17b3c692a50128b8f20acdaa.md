# 连接手机蓝牙启动厂商HMI应用

## 场景说明

为了简化用户首次连接HiCar的步骤，车机可以在检测到连接手机蓝牙后，直接启动厂商HMI应用。
> 说明
>
> * 为实现该功能，需要车机蓝牙支持与UUID（FA87C0D0-AFAC-11DE-8A39-0800200C9A66）进行Secure RFcomm通信。
> * 需要车机蓝牙类型（BluetoothClass.Device）为指定蓝牙类型：1032（AUDIO_VIDEO_HANDSFREE）或1056（AUDIO_VIDEO_CAR_AUDIO）。

当支持HiCar的手机与支持HiCar的车机，建立蓝牙连接时，车机侧HiCar SDK和手机侧HiCar App会通过蓝牙RFcomm通道进行数据交互，在确认双方都支持HiCar后手机侧将直接推荐用户使用HiCar，用户在手机侧同意使用HiCar后，车机侧需要直接进入到连接界面（连接码或者扫码连接界面），从而简化用户的首次连接流程。

用户体验路径如下：

1. 手动修改车机蓝牙名称为HiCarTest，用户手机和车机连接蓝牙后，若满足推荐条件，则手机端会出现如下弹窗，询问用户是否体验HiCar（HiCarTest为测试使用车机蓝牙名称，正式使用需要厂商提供蓝牙默认名称，在经过验证后会添加到蓝牙推荐白名单的规则里，白名单生效后现网可正常使用）。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214105.53977906120917802843223769799051:50001231000000:2800:49C89F00BBA1B644C4F7B3AC36CBC996B5415D11725CF5EDCC137DF26D4A2D78.png)

2. 若用户点击"同意"，则车机端应该拉起HiCar HMI应用界面（PIN码或二维码界面）；若用户点击"取消"，则车机端不会收到任何回调通知，即无需进行任何动作。

为实现该功能，厂商需根据本章节内容完成功能开发。

## 接口说明

|文件|接口|说明|
|:------|:-----------------------------------------------------------------------------|:---------------------------------------|
|hicar.c|HiCarStartBluetoothRecommend(const char* modelId, int32_t allowConnectionType)|SDK初始化之后，调用此接口传入车机的modelID和支持的连接类型。|
|hicar.c|ShowStartPage()|接收到显示连接界面的回调，HMI应用需实现此回调接口，跳转到HiCar连接界面。|
[**表1**相关接口]

|结构体|结构体内函数|说明|
|:-------------------|:-------------------------------------------------------|:---------------------------------------------------|
|BtRecommendAdpterOps|registerBtSocketCallback(BtSocketDataCallback *callback)|从SDK中获得数据接收处理函数，用于处理从蓝牙socket中获取的数据。|
|BtRecommendAdpterOps|initBtSocket(RfcommServerInfo serverInfo)|根据SDK给出的RfcommServerInfo创建蓝牙socket，并处理从socket中接收的数据。|
|BtRecommendAdpterOps|sendData(char *data)|SDK会调用此函数，将数据回复给手机。|
|BtRecommendAdpterOps|unregisterBtSocketCallback()|反注册函数，释放从SDK中拿到的数据处理函数。|
|BtRecommendAdpterOps|deInitBtSocket()|反初始化函数，销毁蓝牙socket。|
[**表2**相关结构体（bt_socket_wrapper.h）]

> 说明
>
> Rfcomm建立成功后，手机会弹窗询问用户是否同意使用。用户点击确认之后才会给HMI发送显示连接起始界面的回调（ShowStartPage），不需要HMI提前自行拉起HiCar连接界面。

## 开发步骤

1. 厂商需实现监听蓝牙连接的接口，并在检测到有蓝牙连接时，在HiCar SDK初始化成功的回调中调用HiCarStartBluetoothRecommend方法，传入车机modelID和支持的连接类型 （此处的modelId为完整的8位modelId）。
2. 实现ShowStartPage接口，在此回调方法中跳转到HiCar连接界面（连接码界面或者扫码连接界面）。
3. 蓝牙连接及数据收发需要厂商实现bt_socket_wrapper.h中的接口，即根据此头文件实现bt_socket_wrapper.c 。
