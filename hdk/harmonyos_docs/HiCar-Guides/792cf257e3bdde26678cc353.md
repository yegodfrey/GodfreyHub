# 重置车机HiCar数据

## 场景说明

手机和车机认证连接后，车机会保存HiCar相关数据例如：已连接设备信息、鉴权数据和融合桌面数据等，厂商HMI应用可以通过HiCar SDK提供的接口重置这些信息。

## 接口说明

|类|方法|说明|
|:-----------|:---------------|:------------|
|HiCarAdapter|resetSdkCashData|重置车机侧SDK所有数据。|
[**表1**相关接口]

> 注意
>
> 非必要情况下不要随意调用此接口。
