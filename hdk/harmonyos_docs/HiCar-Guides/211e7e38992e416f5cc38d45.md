# 创建车机信息

1. 登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)，进入"账号管理"-"合作计划"页面，点击加入"HUAWEI HiCar 汽车硬件合作伙伴"计划。

   **图1**申请加入"HUAWEI HiCar 汽车硬件合作伙伴"计划   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.64910015426434613291093241093525:50001231000000:2800:E1BFD5FF8915898F657DF5CC8387CFBBBF044839C19E78646FC19732988ED23B.png?needInitFileName=true?needInitFileName=true)

2. 在左侧导航栏中，切换到"HUAWEI HiCar产品开发"。
3. 单击"+"，创建一款车机。

   **图2**车机管理

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.40525438513829315153009834565036:50001231000000:2800:D7F98EC8CA7E184B1DB66F6AFDC12ECFBC154581B838187CAF3FAD6FFB3A1B34.png?needInitFileName=true?needInitFileName=true "点击放大")

4. 在车机管理页面完善"车机信息"。

   **图3**创建车机

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.54172341451124458760075232229895:50001231000000:2800:85D3042C724C75336A44CA7ADC255DC445E033D6D2CD34A96DD909BE877B4485.png?needInitFileName=true?needInitFileName=true "点击放大")

5. 在当前页面的"附件"区域上传《HUAWEI HiCar软硬件资源约束》。

   **图4**附件区域

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.23718718038938931859450238022588:50001231000000:2800:9F8BDC57A2FF6CD49A288FF38B55B701A014A92A2CBB0C3143AC1671BDC8BC9D.png?needInitFileName=true?needInitFileName=true "点击放大")

6. 若车机操作系统为Linux，请在当前页面的"附件"区域上传《HUAWEI HiCar生态工具（Linux编译工具链）入库声明》。

   请确保上传的文件内容完整并且是盖有公司公章的电子版本，与前期申请合作准入时提交的文件保持一致。如准入时反馈有误，请重新更新并上传准入材料。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240827103033.18446505690710657659544026462242:50001231000000:2800:B599ECCDC27B3AC1B02CD70053DD43596A8EF7C69E2BFDF971108FCD0AFF4548.png?needInitFileName=true?needInitFileName=true "点击放大")

7. 在当前页面的"附件"区域上传USB、蓝牙、Wi-Fi证书。

   证书的认证机构如下：
   * 蓝牙技术联盟（英文名：Bluetooth SIG）。需上传BQB（Bluetooth Qualification Body）证书。
   * Wi-Fi联盟（英文名：Wi-Fi Alliance）。
   * USB协会（英文名：USB IF）。

   如已通过认证，请提交联盟颁发的认证证书， 并确保证书中的product list信息与此次申请验收测试的车机信息一致。

   如未通过认证，请尽快完成对应联盟认证，三个联盟机构发布的车机认证证书是HiCar验收测试报告发放的必要条件，如果车机不支持无线接入方式，HiCar验收测试不依赖于蓝牙和Wi-Fi认证证书，可以不提交。

8. 如果申请方为后装车机厂商，请在当前页面"附件"区域上传支持HUAWEI HiCar的车型清单附件（附件中给出车型列表即可，华为不提供表格模板）。
9. 完成所有信息填写后，点击"提交申请"。
10. 提交车机信息后，完善联系人信息，点击确认进入车机审核状态。
