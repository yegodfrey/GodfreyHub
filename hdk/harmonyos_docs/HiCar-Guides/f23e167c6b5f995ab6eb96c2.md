# 名称规范

**规则 2-7 HUAWEI HiCar品牌名字符规范：HUAWEI为大写字母，HiCar中H与C为大写**。

HUAWEI HiCar图标诠释文案描述只能使用规范化表达术语，不得使用与规范之外的任何其他描述话术。

注意事项：

* "HUAWEI HiCar" 不得单独拆解使用。
* "HiCar"不得在面向消费者的任何场景中单独使用。
* "HUAWEI HiCar"中的"HUAWEI"拼音大写不可转化成"华为"汉字使用（包括但不限于：华为HiCar）。Logo 描述时只能用HUAWEI HiCar一种标准写法。
