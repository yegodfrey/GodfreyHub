# 签署合作伙伴授权

华为会在车机设备完成HiCar验收测试后，在华为侧配置申请方授权信息，并将在华为官方渠道露出支持HiCar的车型车款/车机等相关信息，所以需要申请方完成相关授权。

在验收通过之后，HiCar验收测试运营工程师将通过邮件发送《HUAWEI HiCar合作伙伴授权书》、《伙伴OTA升级信息反馈》文档。若申请方是通过OTA升级方式支持HiCar功能，则请一并反馈《伙伴OTA升级信息反馈》文档，若申请方为新产品支持HiCar，不涉及OTA升级，则请反馈产品正式上市支持HiCar时间。
> 说明
>
> 若申请方未完成相关授权，后续将无法获得验收测试准出，并及时反馈OTA升级/新产品上市时间。
