# 开发准备

## 获取软件包

HiCar Linux SDK软件包根据厂商工具链进行编译。厂商在提供编译工具链后，华为将线下提供SDK软件包。
> 说明
>
> 向华为提供的编译工具链如果需要安装，或者需要执行环境变量配置脚本，其中涉及的路径需要支持可配置，不要固定。如果有其他使用注意事项的，也请提供使用说明文档。

## 软件包说明

厂商获取到的HiCar SDK包含以下部分：so动态链接库文件、头文件、参考代码、配置文件。

### so动态链接库文件

厂商需要给华为提供编译工具链用于生成so动态链接库文件，华为编译后放在HiCar SDK包的lib目录。这些文件建议拷贝到系统如下路径："/usr/lib/"。

### 头文件

头文件在HiCar SDK包的"include/north"和"include/south"文件夹。

|SDK文件夹|头文件|说明|
|:-------------------|:-----------------------|:-------------------------------|
|include/north|hicar.h|HiCar SDK的应用接口，提供给厂商HMI应用调用|
|include/north|dmsdp_errno.h|DMSDP模块的错误码定义|
|include/north|HwRemoteControlEvent.h|HiSight投屏模块对外头文件，主要定义了反向控制有关的结构体|
|include/south/dmsdp|dmsdp_camera_handler.h|定义了厂商需要适配的Camera设备接口|
|include/south/dmsdp|dmsdp_camera_data_type.h|定义了Camera设备相关枚举和结构|
|include/south/dmsdp|dmsdp_audio_handler.h|定义了厂商需要适配的Audio设备接口|
|include/south/dmsdp|dmsdp_audio_data_type.h|定义了Audio设备相关枚举和结构|
|include/south/dmsdp|dmsdp_gps_handler.h|定义了厂商需要适配的GPS设备接口|
|include/south/dmsdp|dmsdp_business.h|定义了在设备侧通知HiCar SDK的枚举和结构|
|include/south/nearby|driver_adapt.h|定义了厂商需要适配的发现连接的设备接口|
[**表2**头文件说明]

更多关于接口定义和说明的内容，请参见《HUAWEI HiCar SDK API参考》。

### 参考代码

参考代码放在HiCar SDK包的samples目录，包括HMI应用调用HiCar SDK的示例代码、设备侧适配Audio和Camera的示例代码、设备侧适配Nearby的示例代码。 说明
>
> 其中Nearby参考代码中定义的全局变量名不要修改，否则会导致编译失败。

### 配置文件

配置文件放在HiCar SDK包的ConfigDir目录，涉及DFX日志功能中事件、区域、版本配置等（HiCar SDK的日志在默认情况下占用空间约为15MB）。

厂商将上述配置文件放置到规划的存储日志路径即可。例如：日志文件路径为"/log/hicarlogs/"，则需要存在"/log/hicarlogs/ConfigDir/"目录，ConfigDir下为配置文件。配置的完整路径在HiCar SDK初始化时，告知HiCar SDK，详见[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000105632)。

## 开发环境要求

HiCar SDK对集成开发环境的要求与其他嵌入式开发相同，厂商在已有的嵌入式开发环境中，引入HiCar SDK包中的头文件，并把依赖的so库文件放到可搜索的路径即可。

## 调测时可使用的车型ID

华为会为每个车型提供唯一车型ID，即下文提到的ModelID与SubModelID。车型ID为4字节16进制字符串，其中前三个字节为车辆品牌标记（ModelID），第四个字节为车辆型号标记（SubModelID）。

调试及正式商用时该参数值需要厂商向华为申请获得。
