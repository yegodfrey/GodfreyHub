# 图标背景控制

**规则2-5 使用标准色图标，背景明度不得大于50% ，并确保背景图片与标志之间具有清晰的色彩对比度**。

请按规范使用标志，确保背景图片与标志之间具有清晰的色彩对比度，并避免将图标放置在复杂的图片背景上，从而保障标志在背景图片中的可识别性。
