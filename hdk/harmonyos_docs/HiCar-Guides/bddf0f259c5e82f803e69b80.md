# 获取文档

目前HUAWEI HiCar仅向合作中的开发者开放接入文档，处于合作中的开发者可参考[获取文档](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/get-docs-app-0000001150423322)申请相关权限。

待访问权限配置生效后重新登录本页面即可查看相关文档。
