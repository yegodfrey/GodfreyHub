# 发送USB控制命令

## 场景说明

当车机通过USB检测到新设备后，需要通过判断厂商ID是否为"0x12D1"、"0x339B"识别出华为手机和荣耀手机，然后将车辆信息（modelId、蓝牙Mac地址、IP、端口号等），按照Nearby互联协议规范封装，通过USB命令字发送接口发送到手机侧。

## 接口说明

互联协议头数据格式如[表1](#ZH-CN_TOPIC_0000001050123765__table20066927)所示。

|Field|Size (byte)|Value|
|:-----------|:----------|:------------------------------|
|magic_string|8|车机集成时固定值"hwnearby"，用于判断是否遵循该协议。|
|total_len|2|总长度，包括协议头及数据的长度（不超过256）。|
|type|2|互联设备类型，车机集成时固定值"0x01"。|
|version|2|协议版本。 1.0版本协议对应"0x0100"。|
|subtype|2|互联设备子业务，车机集成时固定值"0x01"。|
[**表1**Nearby互联协议头数据格式]

扩展数据是TLV格式，具体数据格式如[表2](#ZH-CN_TOPIC_0000001050123765__table66166979)所示。

|Tag|Length (byte)|Value|
|:--|:------------|:-------------------------------------------------------------|
|0|1|0x01: NCM 0x02: AOA 0x03: NCM+AOA 其他ID可扩展。目前只支持NCM，即0x01。|
|1|3|ModelID。|
|2|1|SubModelID。SubModelID即为车型ID第四个字节数据。|
|3|32|DeviceID: sha256(ModelID+SubModelID+蓝牙MAC地址)。其中，MAC地址中字母必须为大写。|
|4|6|蓝牙MAC地址。其中，MAC地址中字母必须为大写。|
|5|可变长度|设备名称。|
|6|14|IP地址：格式为192.168.66.xxx。其中xxx范围为：100~255。|
|7|4|Socket Server端口号。|
[**表2**扩展数据的数据格式]

车机发送的USB控制命令格式如[表3](#ZH-CN_TOPIC_0000001050123765__table51563966)所示。

|Field|Size (byte)|Value|
|:------------|:----------|:----------------------------------|
|bmRequestType|1|0x40: USB_DIR_OUT | USB_TYPE_VENDOR|
|bRequest|1|0x34|
|wValue|2|0x00|
|wIndex|2|0xA0|
|wLength|2|发送数据实际长度，最长不超过256字节。|
[**表3**USB控制命令格式]

## 开发步骤

车机发送USB控制命令的示例代码如下所示：

```screen
// For example:
if (libusb_device_descriptor.idVendor == VENDOR_ID_HUAWEI || libusb_device_descriptor.idVendor == VENDOR_ID_HONOR) {
    unsigned char data[256] = {0};
    FillUsbControlBuffer(data); //按照Nearby互联协议规范填充数据
    /**
      * 其中data字段为车辆信息编码数据，长度不超过256
      */
    libusb_control_transfer(0x40, 0x34, 0, 0xA0, data, data.length, 2000);
}

int FillUsbControlBuffer(uint8_t *buf) {
    int totalLen = 0;
    // fill nearby head
    HiCarNearbyHead *pHead = (HiCarNearbyHead*)(buf + totalLen);
    totalLen += sizeof(HiCarNearbyHead);
    memcpy(pHead->magic_string, HICAR_NEARBY_STRING, 8);
    pHead->type = Nearby_Type_Car;
    pHead->version = Nearby_Version;
    pHead->subtype = Nearby_Subtype_Car;

    // fill Extend Data, format of TLV
    // Trans Channel
    HiCarUSBExtendData *pTLV = (HiCarUSBExtendData*)(buf + totalLen);
    pTLV->tag = TAG_TransferType;
    pTLV->len = 1;
    pTLV->value[0] = VALUE_TransferType_NCM;
    totalLen += TLV_TOATL_LEN(pTLV);
    // ModelID、SubModelID、DeviceID、BluetoothMac等类似封装
    ....
    pHead->total_len = totalLen;
}
```
