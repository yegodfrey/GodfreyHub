# 语音提示音播报通知

## 场景说明

HiCar与车机间的语音交互方案，如果涉及到重新创建虚拟音频通道，可能会由于时延较大导致语音提示音播报"滴"声丢失或破音播放。为避免该种情况，车机可以选择在车机侧保存"滴"声语音文件，收到HiCar App发送的通知消息后，在本地播放"滴"声语音提示音。

语音提示音播报通知相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[语音提示音播报](https://developer.huawei.com/consumer/cn/doc/HiCar-References/voice-prompt-announcement-0000001199339969)部分。

## 开发步骤

1. HiCar App查询车机是否支持在本地播报"滴"声提示音。

   1. HiCar App会在连接成功后向车机发送查询消息（dataType=519），查询车机是否支持在本地播报"滴"声提示音，示例如下所示：

      ```screen
      {
          "isVoicePromptSupport":1
      }
      ```

   2. 车机通过**DataReceive** 方法，判断**dataType** 后可以收到上述具体数据内容，通过**HiCarSendData** 接口返回支持情况。

      车机支持本地播放语音提示音，示例如下所示：

      ```screen
      {
          "isVoicePromptSupport":2
      }
      ```

      车机不支持本地播放语音提示音，示例如下所示：

      ```screen
      {
          "isVoicePromptSupport":-1
      }
      ```

2. HiCar App语音向车机下发开始/停止播放语音提示音。示例如下所示：

   ```screen
   //开始播放语音提示音
   {
       "voicePrompt":1
   }

   //停止播放语音提示音
   {
       "voicePrompt":0
   }
   ```
