# 连接管理

**规则 4-1 车机系统需有HUAWEI HiCar连接管理功能模块**。

方便用户在车机侧对HUAWEI HiCar做连接管理，连接管理入口与界面风格可根据车机系统自行设计，例如入口从设置进入。

## 列表排序与名称

**规则 4-2 连接列表当前已连接的设备需在列表的首行**。

设备列表首行为已连接的设备项，当未有连接的设备，列表的次序根据连接先后顺序排序。

## 设备管理

**规则 4-3 已连接设备的列表需要有断开的入口**。

为方便用户能从车机侧断开当前已连的设备，在连接管理界面，需有用户可以快速断开当前已连接的设备的入口。
