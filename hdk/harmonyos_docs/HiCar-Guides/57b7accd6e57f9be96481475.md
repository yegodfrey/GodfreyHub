# 开始/停止车机广播

## 场景说明

厂商HMI应用可以在自身被启动或者用户按下车机物理按键（例如长按语音唤醒按键）时调用"startAdv()"接口发送BLE广播，在连接成功后调用"stopAdv()"接口停止BLE广播。调用发送广播接口与停止广播接口时，厂商HMI应用需要根据返回值判断广播是否真正发送或停止。
> 说明
>
> 当车机执行 HiCar 回连操作时，界面禁止弹出 PIN 码页面，需展示正在连接状态页。

## 接口说明

|类|方法|说明|
|:-----------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HiCarAdapter|startAdv|厂商HMI应用通过该接口发送BLE广播。|
|HiCarAdapter|stopAdv|厂商HMI应用通过该接口停止BLE广播。|
|CarListener|onDeviceChange|HiCar SDK通过回调的方式向厂商HMI应用通知广播相应的事件： * EVENT_DEVICE_ADV_START（值为106）：广播已开始。 * EVENT_DEVICE_START_ADV_TIMEOUT（值124）：广播发送超时。收到广播超时事件后，厂商HMI应用应重新连接。 * EVENT_DEVICE_ADV_STOP（值为107）：广播已停止。如果此时仍未连接成功，厂商HMI应用需要重新触发广播流程。|
[**表1**广播相关接口]

## 开发步骤

1. 厂商HMI应用在自身被启动或者用户按下车机物理按键时，需要检测车机蓝牙状态。

   如果车机蓝牙未打开，厂商HMI应用需要开启车机蓝牙。

2. 通过"startAdv()"接口发送BLE广播。

   厂商HMI应用调用接口发送广播后，每一次广播周期为2分钟，2分钟后广播自动停止。如果在广播发送过程中，再次触发广播会重置持续时间。

   调用发送广播接口的代码示例如下所示：

   ```screen
   //发送广播
   int retCode = mHiCarAdapter.startAdv();
   if (retCode == HiCarConst.SUCCESS) {
       Log.i(TAG, "handleStartAdv: start adv success");
       return;
   }
   ```

   > 说明
   >
   > 当手机接收到广播并弹出发现连接窗后，即使此时广播停止，手机侧依旧可以正常连接车机。

3. 响应广播事件。

   HiCar SDK通过回调的方式向厂商HMI应用通知广播相应的事件，厂商HMI应用可以根据需要在获取到相应广播事件后进行业务处理。

   广播事件回调的示例代码如下所示：

   ```screen
   CarListener carListener = new CarListener() {
       @Override
       public void onDeviceChange(String deviceId, int state, int errorCode) {
           switch(state) {
               ...
               case HiCarConst.EVENT_DEVICE_ADV_START:
                   //广播已开始
                   //TODO:厂商逻辑
                   break;
               case HiCarDemoServiceListener.EVENT_DEVICE_START_ADV_TIMEOUT:
                   //广播超时
                   //TODO:厂商逻辑，如重新发送广播
                   break;
               case HiCarConst.EVENT_DEVICE_ADV_STOP:
                   //广播已停止，收到该事件后，PIN码失效，车机界面停止显示PIN码
                   //TODO:厂商逻辑
                   break;
               default:
                   break;
           }
       }
   };
   ```

4. 处理PIN码回调，详情请参见[处理PIN码回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callbacks-0000001193322373#section71806403312)。

   每次厂商HMI应用触发广播后，HiCar SDK会通过回调的方式向厂商HMI应用返回一个PIN码，厂商HMI应用需将该PIN码在车机屏幕上向用户显示。该PIN码为本次广播周期内的连接校验码，用户需要在连接时输入该PIN码才能成功连接车机。

5. 处理认证回调，详情请参见[处理认证回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callbacks-0000001193322373#section317145010317)。

   厂商HMI应用需要将HiCar SDK与车机的认证信息保存在车机系统中，并通过HiCar SDK提供的回调方法完成认证文件的读取、保存和删除操作。

6. 处理连接事件回调，详情请参见[处理连接事件回调](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/process-callbacks-0000001193322373#section134661359336)。

   厂商HMI应用需要侦听连接事件，并根据不同的连接事件完成相应的逻辑处理。

7. 收到连接成功事件后，通过"stopAdv()"接口停止发送BLE广播。

   调用停止广播接口的示例代码如下所示：

   ```screen
   //停止广播
   int retCode = mHiCarAdapter.stopAdv();
   if (retCode != HiCarConst.SUCCESS) {
       Log.d(TAG, "handleStopAdv failed");
   }
   ```
