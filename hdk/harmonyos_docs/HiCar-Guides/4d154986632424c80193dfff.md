# 开发文件互传

从HiCar Android SDK 4.0.0.600版本开始，HiCar新增文件互传能力，支持手机和车机之间通过HiCar的通道互相传输文件。
> 说明
>
> 文件互传是在HiCar互联场景之上，开放的新扩展能力，所以厂商在集成文件互传特性之前，需要按照前文章节完成HiCar的功能集成。集成完成后，再按照本章节"开发文件互传"提供的指导进行文件互传特性开发。

## 功能介绍

1. 文件互传针对HiCar互联场景，只有连接了HiCar后才可以使用，支持从车机传输文件到手机，也支持从手机传输文件到车机。
2. 当前支持的文件格式是图片和视频。 支持的详细格式信息如下：

   * 图片：jpg、jpeg、gif、png、bmp、wbmp、webp
   * 视频：mp4、m4v、3gp、3gpp、3g2、3gpp2、wmv、ts
3. 当前支持同时传输的最大文件个数为**20** 个，总大小不超过**10GB**（1024M=1GB），支持图片+视频混合发送。
4. 无论是车机侧还是手机侧，在接收文件前需要弹框授权获取用户同意。
5. 不支持断点续传。
6. 如果在发送过程中传输中断（发送端取消发送/接收端取消接收/HiCar断连/网络异常等），已经发送过去完整文件保留，不完整的文件会在接收端删除。

## 开发步骤

### 权限说明

文件互传功能中，车机给手机传输文件需要访问车机存储空间，需要配置权限保证功能正常运行。

厂商HMI应用在开发过程中需要在应用的AndroidManifest.xml文件中声明需要系统权限，并且动态申请允许该权限，示例如下所示：

```screen
<!-- used for file share -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
<!-- 另需要在application标签中添加如下内容 -->
android:requestLegacyExternalStorage="true"
```

### 开发步骤

1. 车机HMI在HiCar连接成功后，需要调用**FileShareManager** 的**registerFileShareListener**方法注册FileShareListener接口用来处理和监听文件传输业务逻辑。

   ```screen
   // 注册接口监听
   FileShareManager.getInstance().registerFileShareListener(fileShareListener);
   // 反注册接口
   FileShareManager.getInstance().unregisterFileShareListener();
   ```

   > 说明
   >
   > 1.每次HiCar连接成功后都必须调用接口注册FileShareListener，以确保文件互传业务正常。
   >
   > 2.当无需使用文件互传业务时以及HiCar断开连接时需调用反注册接口。

2. 车机HMI需要实现**FileShareManager** 的**FileShareListener**接口，以供步骤1注册方法传参。

   FileShareListener接口各方法如下所示：

   ```screen
   public interface FileShareListener {
       void obtainFileShareNotificationInstance(FileShareStatusNotification notification);
       void onReceiveFileShareRequest(List<FileInfo> fileInfoList);
       void onTransmissionProgressUpdate(int progress);
       void onTransmissionSpeedUpdate(long speed);
       void onTransmissionStatusUpdate(int status);
       String onCustomSavePath(List<String> defaultSavePathList);
       void onTransmissionSingleProgressUpdate(int fileIndex, int progress);
       void onTransmissionCompletedUpdate(int succeedCount, int failedCount)
   }
   ```

   |方法|说明|
   |:---------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------|
   |void obtainFileShareNotificationInstance(FileShareStatusNotification notification)|提供FileShareStatusNotification实例给HMI应用，HMI应用需定义变量保存FileShareStatusNotification，后续通过此实例调用方法与手机端进行指令交互。 方法及参数详细说明参考SDK API参考。|
   |void onReceiveFileShareRequest(List<FileInfo> fileInfoList)|收到手机侧发送文件请求，车机可在此回调中弹框提示用户是否同意接收文件。 方法及参数详细说明参考SDK API参考。|
   |void onTransmissionProgressUpdate(int progress)|文件传输过程中，文件传输进度的回调，1s一次。 方法及参数详细说明参考SDK API参考。|
   |void onTransmissionSingleProgressUpdate(int fileIndex, int progress)|文件传输过程中，文件传输编号以及进度的回调，1s一次。 方法及参数详细说明参考SDK API参考。|
   |void onTransmissionSpeedUpdate(long speed)|文件传输过程中，文件传输速率的回调，1s一次。 方法及参数详细说明参考SDK API参考。|
   |void onTransmissionStatusUpdate(int status)|文件传输过程中，各种状态的回调。 方法、参数及返回值详细说明参考SDK API参考。|
   |String onCustomSavePath(List<String> defaultSavePathList)|车机可通过本接口设置自定义存储路径，文件存储动作由SDK内部完成。 方法、参数及返回值详细说明参考SDK API参考。|
   |void onTransmissionCompletedUpdate (int succeedCount, int failedCount)|文件传输过程中，当前文件传输数量的统计结果的回调（成功、失败数量），1s一次。 方法及参数详细说明参考SDK API参考。|
   [**表1**FileShareListener接口方法说明]

3. 车机端向手机端发送文件，车机需要调用**FileShareManager** 中**sendFileShareRequest**方法发送文件，文件传输状态和通知的更新在步骤2中onTransmissionStatusUpdate方法回调，状态码详见API参考说明。

   ```screen
   // 车机端向手机发起文件传输请求(路径入参)
   FileShareManager.getInstance().sendFileShareRequest(filePathList); 
   // 车机端向手机发起文件传输请求(URI入参)
   FileShareManager.getInstance().sendFileShareUriRequest(context, uriList); 
   ```

   |方法|说明|
   |:------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------|
   |public int sendFileShareRequest(List<String> filePathList)|向手机发起文件传输请求，传入文件路径列表。HMI应用处理该方法的返回值，用于提示用户或更新界面显示，若选中的文件满足发送标准，接下来手机端会弹框询问用户是否接收。 具体参数、返回值含义详见SDK API参考。|
   |public int sendFileShareRequestUris(Context context, List<String> filePathList)|向手机发起文件传输请求。传入文件URI列表。 具体参数、返回值含义详见SDK API参考。|
