# 测试物料准备

在自测试通过后请申请方及时准备验收测试物料。只有申请方确保可按要求提供相应验收测试物料后，才可提交后续验收测试预约。

## 首次验收测试物料

1. 车机台架2台（1台用于测试机构验收，1台用于华为研发同步分析问题、华为实验室复测以及兼容性测试），需采用台架封装，台架必须包含全套配件，保证车机可用。全套配件包括但不限于台架箱、主机、屏幕、电源、麦克风、扬声器、方控键、GPS天线、相关线束等。如车机未进行台架封装，验收测试组将拒收物料。

2. 整车1台（后装车机验收测试可以不提供整车，但车机台架要确保配备双声道喇叭），整车物料提交注意事项（如整车未按照以下要求提供，验收测试组将拒收物料）：
   * 整车整体软硬件配置需与商用保持一致。
   * 整车车况允许上路，且务必保证上路安全可用。
   * 寄送时需确保满足满电/满油状态
   * 车辆临牌有效期90天（如需延期，请协助重新申请临牌），且临牌需可支撑路测（确保临牌行驶区域中包含送测城市）。
   * 车辆保险：整车必须提供交强险和商业保险保单
   * 车辆物联网卡：如车辆支持物联网卡，需提供带流量的物联网卡，卡流量至少500M/月。
   * 整车车内车外请确保整洁有序，无裸露线束等。
   * 对于整车车况（如刮痕、磨损、车辆异常告警等）提供必要说明和解释。
   * 整车使用期间的注意事项请一并提供。

## 等效验收测试物料

等效验收测试物料准备需参考《HUAWEI HiCar等效验收测试申请表》（该表格在[创建车型信息](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/submit-application-0000001145036331)过程中在线下载），申请方在等效申请表的"等效验收测试申请表"页签，根据实际情况选择等效验收设备的软硬件差异情况，细化表页签会自动生成等效验收测试的物料参考要求和对应的评估结果。HiCar验收测试经理最终会根据《HUAWEI HiCar等效验收测试申请表》实际差异情况判断是否满足等效验收测试以及所需要的设备物料。
