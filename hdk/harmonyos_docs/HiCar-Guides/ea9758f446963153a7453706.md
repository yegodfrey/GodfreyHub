# 无线连接说明

厂商HMI应用在集成无线连接功能之前，车机需要已经完成对蓝牙和Wi-Fi的适配，具体内容请参考[无线连接流程](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/wireless-connection-process-0000001052464951)。

**图1**交互流程   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214105.80798979891839793417249302420746:50001231000000:2800:F5EEDBC52DB8D8CE3BE76A4F6ECC88ADDC0365EE388F0E910074B1029BD104D2.png "点击放大")

在无线连接过程中，厂商HMI应用需要通过调用HiCar SDK提供的广播发送接口"HiCarStartAdv"发送BLE广播，同时通过方法"HiCarGetPinCode"获取连接PIN码显示到应用界面中，等待HiCar手机接收到广播并输入PIN码后，可以在回调方法"DeviceServiceChange"获取到相应的连接事件。
