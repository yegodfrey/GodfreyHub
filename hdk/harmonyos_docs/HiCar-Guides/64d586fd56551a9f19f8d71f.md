# 手机桌面

**规则11-1** 手机桌面样式需包含：最大化、最小化、关闭、多任务、home、后退，需要支持横竖屏。

**建议11-2** 当手机开启应用锁时，建议使用如下样式：在应用上覆盖遮罩，并增加图标+文字提示，支持用户返回退出。
