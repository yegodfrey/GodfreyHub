# 获取验收测试物料清单

测试机构收到验收预约工单后，会对申请方提交的自测试情况进行审核。

审核通过后，测试机构会根据项目情况和验收测试实验室资源情况协调安排，明确负责项目测试验收的实验室，并向申请方提供验收物料清单，其中包括：验收测试物料具体条目。

申请方可在验收预约成功页面，下载上述相关附件。
