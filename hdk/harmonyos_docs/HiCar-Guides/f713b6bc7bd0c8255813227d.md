# 物理快捷按键（Beta）

## 场景说明

如果车辆中存在物理导航/联系人/音乐按键，连接HiCar后，用户可以通过这些物理按键，一键打开HiCar中对应的地图/联系人/音乐应用。打开应用时无法指定具体的应用，只能打开用户上一次使用的地图/联系人/音乐应用。

车机在检测到这些物理按键被按下后，需要向HiCar App上报相应的数据。

物理快捷键相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[物理按键快捷键](https://developer.huawei.com/consumer/cn/doc/HiCar-References/physical-shortcut-key-0000001199339967)部分。

## 开发步骤

手机和车机成功连接并投屏后，如果检测到物理快捷键被按下，需要通过**HiCarSendData** 接口向HiCar App上报对应的数据。车机发送的数据内容示例如下：

```screen
{
    "KEYCODE":"NAVIGATION"
}
```
