# 查看日志

进入设置页面"日志"菜单，可以查看模拟器的日志。
> 注意
>
> 此处展示的仅是设备模拟器的日志信息，并不包含手机侧应用的调测日志，所以开发者在测试验证时，仍需要通过IDE（例如Android Studio、HUAWEI DevEco Studio）获取手机应用日志信息。在手机连接平板时，开发者可以通过WLAN连接手机实时查看应用对应日志，详情可参考[当手机连接平板时通过WLAN连接手机实时查看调测日志](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/adb-wifi-0000001135474796)。

1. 系统提供查看实时日志的功能，按日志类型（V、I、D、W、E、F）以不同的颜色显示日志条目。目前暂不支持日志的实时滚动显示。
2. 开发者可以通过HiCar Simulator界面右上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220524101406.12245753274859869431766809161502:50530523030437:2800:8C47B3A94672A371B66443AA65A136AE961AD8FA66E869B220F3D006853BF821.png?needInitFileName=true?needInitFileName=true)按钮重新加载最新的日志。
3. 开发者可以通过HiCar Simulator界面右上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220524101406.61695756170609210960869729442479:50530523030437:2800:913FD4387FE614929C0DE7E0829C59B39C8DA3D9D5A2AAFC54771366903F107A.png?needInitFileName=true?needInitFileName=true)按钮将日志导出到文件，以便于进一步的分析和定位问题。日志存放路径会以Toast的形式提示开发者，在点击导出图标时可以查看日志存放路径。目前仅支持查看，暂不支持日志路径的自定义设置。当开发者与华为技术工程师协同解决技术问题时，可将此处导出的日志连同应用日志提供给华为技术工程师，进行进一步分析与定位。
