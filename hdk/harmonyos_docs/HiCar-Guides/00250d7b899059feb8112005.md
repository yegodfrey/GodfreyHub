# 多车机互联产品连接

## 产品连接

**规则 6-1 首次连接车机时，提供多车机互联产品的选择界面。**

用户首次通过USB连接发起连接车机支持多互联产品，车机提供多互联产品选择界面（不默认其中任何一款产品）。
