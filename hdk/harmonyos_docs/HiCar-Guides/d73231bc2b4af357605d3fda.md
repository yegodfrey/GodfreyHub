# 业务介绍

## 业务简介

HUAWEI HiCar（以下简称HiCar）是华为提供的人-车-家全场景智慧互联解决方案。HiCar将手机和汽车连接起来，利用汽车和手机各自的优势属性以及多设备互联能力，为消费者打造以手机为核心的全场景智慧出行体验。

* 以手机为中心，体验随着人走，在家、车等场所间无缝流转。
* 把手机和汽车的硬件资源、系统能力、服务生态快速融合在一起，让消费者感觉所有设备像一个虚拟超级设备，提升智慧出行整体体验。

## 开放能力

HiCar通过分布式软总线技术、分布式虚拟化能力和应用服务共享虚拟化技术，构建了一个开放的平台解决方案。针对汽车硬件设备厂商，HiCar提供了HiCar SDK开放能力，方便汽车硬件接入HiCar。汽车硬件设备厂商集成HiCar SDK的逻辑架构如[图1](#ZH-CN_TOPIC_0000001050064258__zh-cn_topic_0000001050704494_zh-cn_topic_0000001051645450_fig327511415713)所示。

华为提供的HiCar SDK主要包括三部分内容：

* **HiCar应用层集成调用接口（HiCar Client Interface）：**HiCar为车机应用层提供的HiCar相关功能接口，车机的HMI（Human Machine Interface）应用需要调用这些接口实现HiCar相关的人机交互界面。
* **HiCar分布式协议组件：**HiCar为厂商提供的用于实现车机与手机间的数据传递、交互控制等功能的组件，包括分布式设备发现连接组件（Nearby）、分布式设备管理组件（DMSDP）、投屏显示组件（HiSight）以及日志处理组件（HiViewLite）。
* **HiCar硬件和OS适配层接口（Adapter Interface）：** HiCar定义的硬件和OS相关适配层接口，需要厂商负责集成适配，HiCar分布式协议组件会调用这些接口。
