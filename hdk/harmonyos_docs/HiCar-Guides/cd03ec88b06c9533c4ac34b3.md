# 接入规范

为了保证一致的用户体验，音频应用在接入HiCar时需遵守如下规范。

## 技术规范

1. 音频应用需遵从MediaSession框架实现音频内容的播放控制。
2. 音频应用需严格按照Android焦点机制处理音频焦点变化。在接入HiCar后，音频应用不能在其他音频正常播放时，同时播放内容。

## 功能规范

1. 音频应用应妥善处理首次在HiCar环境中使用弹出隐私声明及权限获取弹框的逻辑。详见[配置隐私声明界面](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/configure-privacy-statementui-0000001120118671)。
   * 音频应用不需要为HiCar设计提供单独的隐私声明界面，在HiCar场景下复用音频应用原有的隐私声明界面即可。
   * 音频应用在手机侧已完成用户协议和隐私政策确认后，首次在HiCar环境使用时，无需再弹出隐私声明界面及获取用户权限授权。
   * 音频应用在手机侧未完成用户协议和隐私政策确认，首次在HiCar环境中使用时，应为HiCar授予相关权限便于被HiCar拉起隐私声明界面，并在用户完成确认后告知HiCar相关结果。
2. 音频应用需在MediaSession初始化时设置初始播放列表，列表中存在可播放内容，并将一首曲目信息填充到MediaSession中。详见[更新播放列表](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/update-playlist-0000001119742857)。
3. 音频应用需在以下场景中正确使用通知弹框进行提醒。详见[使用通知弹框](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/use-dialog-0000001120118675)。
   * 用户尝试使用流量播放音频内容时弹出提醒弹框。
   * 用户在无网状态尝试播放时弹出提醒弹框。
   * 用户在未登录状态尝试使用登录后才可使用的特性时弹出提醒弹框。
   * 用户尝试播放付费/会员内容但无法播放时弹出提醒弹框。

   另外，如果音频应用在手机侧和HiCar车机侧同时弹框，当用户在某一端完成弹框确认后，音频应用需保证另一端弹框同步被处理。例如，音频应用在车机和手机上同时弹出了流量提示弹框，如果用户在手机上操作使得手机侧弹框取消，那么音频应用需要调用HiCar取消弹框指令，通知HiCar取消车机上的弹框。
4. 音频应用在付费/会员内容无法播放时，应妥善进行弹框及语音播报提醒。详见[播放付费/会员内容](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/play-paid-content-0000001078467010)。
   * 有声读物场景
     1. 用户手动点击付费/会员内容时，进行弹框提醒，不进行语音播报。
     2. 播放器正常播放时遇到付费/会员内容时，进行TTS语音播报提醒，不进行弹框提醒。
   * 音乐场景
     1. 用户手动点击付费/会员内容时，进行弹框提醒，不进行语音播报。
     2. 播放器正常播放时遇到付费/会员内容时，直接跳过付费/会员内容，播放其它可播放的内容，不进行TTS语音播报提醒，也不进行弹框提醒。
5. 音频应用应实现语音交互，并合理返回搜索结果。详见[实现语音内容搜索](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/voice-search-0000001078018964)。
   * 音频应用接入HiCar后需支持语音搜索功能，并明确支持的语音内容搜索类型（音乐、有声读物、新闻资讯），可根据语音助手下发的搜索指令返回正确的搜索结果。
   * 对于搜索目的不明确的指令，例如"播放歌曲"、"播放相声"，建议根据用户喜好或其他规则进行推荐，并且请勿每次都重复推荐同一曲目。
6. 音频应用在播放页应妥善处理上下首按钮切换逻辑。详见[更新播放曲目](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/update-song-0000001078467008)。
   * 如果有播放列表，上下首按钮在播放列表中切换内容，内容列表应支持循环播放。
   * 如果无播放列表（例如电台），上下首按钮在不同电台或频道中切换。
   * 如果无可切换内容，上下首按钮置灰显示表示不可用。

## 界面规范

界面规范详见[界面显示说明](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/ui-style-specification-0000001119898503)。

1. 音频应用在内容页中通过宫格布局展示内容项时，需通过宫格形状区分专辑和单曲。
   * 专辑通过方形宫格展示。
   * 单曲通过圆形宫格展示。
2. 音频应用包含至少一个、至多四个页签进行内容展示，多余的页签将不再显示。
3. 音频应用接入HiCar后需妥善处理"我的"功能。
   * 如果音频应用存在"我的"相关菜单/功能，则需要在HiCar环境中同步提供"我的"页签（例外：新闻资讯类应用可根据实际情况不提供）。
   * 建议"我的"页签展示的内容与在手机端使用时"我的"菜单/功能保持一致，建议包括：播放历史、收藏/订阅、已下载、我的歌单、已购买内容。音频应用可根据实际情况自行决定其它内容是否在"我的"页签展示。
   * "我的"页签排序在最后位置，即最远离DOCK区域的位置。
   * "我的"页签采用方形宫格样式，通过宫格封面上一键播放时优先接续用户上次播放的内容。
   * "我的"页签中不显示无数据内容的宫格。例如，用户无购买内容时，则不显示已购买的内容宫格。
