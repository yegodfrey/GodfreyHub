# 动态切换投屏区域尺寸

## 场景说明

车机侧改变投屏区域的宽高，手机侧接收车机侧发来的数据自适应调整显示的分辨率，达到较好的观感体验。

建议车机原始屏幕分辨率大于2k，分辨率按照全屏和2/3屏幕显示，应用显示效果最佳。

投屏窗口和原车应用窗口融合相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[动态切换投屏区域尺寸](https://developer.huawei.com/consumer/cn/doc/HiCar-References/fusion-ui-windows-0000002624854137)部分。
> 说明
>
> 1. 该特性需手机侧HarmonyOS系统版本在6.1.0.120及以上。
> 2. 该特性当前仅在融合桌面中支持。

1. 手机车机连接时，车机上报真实的投屏区域宽高值，并监听手机上报的应用信息。
2. 连接成功后，车机将接收到的应用图标显示在指定区域。
3. 点击应用，投屏区域显示指定应用内容。
4. 车机侧改变投屏区域后，向手机发送投屏区域的宽高。手机根据宽高值调整投屏显示，并向车机发送隐藏蒙层消息。

## 开发步骤

1. 手机侧如果支持窗口大小动态调节，会在设备连接时发送'custom_ability':0x1字段。

   ```screen
   private static final int WINDOW_DISPLAY_DYNAMIC_ADJUSTMENT=0x1;
   @Override
   public void onAbilityGet(int ability) {
   	DeviceLogUtils.info("HICARSDK", "onAbilityGet:" + ability); // 这里会打印1
   	boolean support = (ability & WINDOW_DISPLAY_DYNAMIC_ADJUSTMENT) == WINDOW_DISPLAY_DYNAMIC_ADJUSTMENT;
   }
   ```

2. 车机侧调整投屏显示区域时，显示车机侧的蒙层。

   ```screen
   // 创建容器布局         
   FrameLayout container = new FrameLayout(this);
   // 添加蒙层        
   MaskSurfaceView maskView = new MaskSurfaceView(this);       
   container.addView(maskView, new FrameLayout.LayoutParams(FrameLayout.LayoutParams.MATCH_PARENT,FrameLayout.LayoutParams.MATCH_PARENT));
   ```

3. 车机侧调整完投屏区域宽高后，向手机侧发送新的宽高值。

   ```screen
   mHiCarAdapter.updateCarConfig(mCarConfig);
   If (mSurfaceSizeHasChanged) {
       JSONObject jsonObject = new JSONObject();
       jsonObject.put("code", 1);
       JSONObject dataObject = new JsonObject();
       dataObject.put("width", mSurfaceWidth);
       dataObject.put("height", mSurfaceHeight);
       jsonObject.put("data", dataObject);
       mHiCarAdapter.sendCarData(547, jsonObject.toJSONString().getBytes(StandardCharsets.UTF_8));
   }
   ```

4. 投屏区域绘制完成后，会给车机侧返回绘制完成的消息，车机侧需要做取消蒙层的操作。

   ```screen
   class HiCarListener implements Carlistener {
   @Override
   public void onDataReceive(String deviceId, int dataType, byte[] data) {
       Switch (dataType) {
           Case 547:
               JSONObject jsonData = CommonUtils.getJsonObject(data, datatype).orElse(null); // 将从手机接收的命令字符转换成json数据
               Int code = jsonData.getInterger("code");
               If (code == 2) {
                   hideMaskLayer(); // 隐藏加载蒙层
               }
               break;
    ...
   }
   ```
