# 连接流程页面

连接流程页面方便车机适配，界面的风格可依据车机整体风格适当修改（最终风格与华为确认）。

**规则 3-1 连接流程保证功能完整，符合规范文案描述，布局整体居中，视觉位于屏幕中心**。

## P.1 无线连接提示页（支持有线无线与仅支持无线）

**标题：**HUAWEI HiCar 连接码

**提示语：**

* 支持USB：手机开启蓝牙靠近中控，发现汽车后输入连接码，进行首次验证。您也可以通过 USB 线连接您的手机。
* 不支持USB：手机开启蓝牙靠近中控，发现汽车后输入连接码，进行首次验证。
* 若车机需登录账号：手机开启蓝牙靠近中控，发现汽车后输入连接码进行首次验证，也可通过 USB 线连接手机。若车机支持账号登录，请登录后重试。
