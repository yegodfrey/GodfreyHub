# 开发准备

#### 准备软件环境

请下载并安装[最新版DevEco Studio](https://developer.huawei.com/consumer/cn/download/)，具体可参照[下载与安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-software-install)，更多工具使用指导可见[工具概述](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-tools-overview)，DevEco Studio开发环境依赖于网络环境，需要连接上网络才能确保工具的正常使用。在部分企业网络受限的情况下，需要[配置代理](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-environment-config)信息。

     * HarmonyOS SDK已嵌入DevEco Studio中，无需额外下载配置。HarmonyOS SDK可以在DevEco Studio安装位置下DevEco Studio\sdk目录中查看。
     * 应用适配HiCar时需要的Car Kit已集成在HarmonyOS SDK中，无需额外下载配置。

#### 准备调试设备

     * 运行HarmonyOS 5及以上版本系统的手机：用于安装HarmonyOS应用
     * 安卓平板电脑及HiCar配件：平板电脑用于安装HiCar模拟器软件，模拟不同分辨率的车机屏幕。手机通过HiCar配件连接HiCar模拟器。更多关于模拟器软件及HiCar配件的说明，请发送邮件至huaweihicar@huawei.com获取。

#### 开通应用白名单

在本地打包时将应用包名修改为测试包名，将具体测试包名邮件发送至huaweihicar@huawei.com配置云端数据。

云端数据配置后，请再次修改应用包名为“测试包名”+ “.hicar.test”。此时应用将可以显示在HiCar应用尝鲜区，便于开展调试工作。

#### UX适配

     * 请针对不同分辨率设备进行UX界面适配，相关设计说明请参考：[HUAWEI HiCar 系统特性](https://developer.huawei.com/consumer/cn/doc/design-guides/smart-cockpit-0000002045925712#section355812571494)。
     * 提交对应UX设计原稿，发送至huaweihicar@huawei.com审核。审核通过后，继续按照后续步骤进行开发。
