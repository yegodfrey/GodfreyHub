# 深浅色模式

#### 场景说明

HiCar上存在深浅色两种显示模式，为了应用在车机上有良好的显示效果，应用需要适配深浅色模式。

用户可以通过“显示模式”设置HiCar的深浅色模式。在HiCar连接成功后，HiCar会根据当前用户选择的显示模式，结合车机侧传感器信息和日出日落时间信息，将界面渲染为深色/浅色样式。如果应用自身也存在深浅色模式，可以跟随HiCar进行动态切换。

#### 适配深浅色模式

应用的深浅色模式是通过[ApplicationContext.setColorMode](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-inner-application-applicationcontext#applicationcontextsetcolormode11)设置，如未设置则默认跟随系统设置。开发者可以使用预置枚举设置应用的深浅色模式。

**表1** ColorMode枚举说明名称 | 值 | 说明  
---|---|---  
COLOR_MODE_NOT_SET | -1 | 表示未设置颜色模式。 即跟随系统设置。  
COLOR_MODE_DARK | 0 | 表示深色模式。  
COLOR_MODE_LIGHT | 1 | 表示浅色模式。  
  
应用在未设置深浅色模式时，默认跟随HiCar深浅色模式变化。如果应用不希望跟随HiCar深浅色模式变化，可主动设置应用的深浅色模式。设置后，应用的深浅色模式固定，不会随HiCar改变。示例代码如下所示：
    
    import UIAbility from "@ohos.app.ability.UIAbility"
    import { ConfigurationConstant } from "@kit.AbilityKit";
    
    export default class EntryAbility extends UIAbility {
      onCreate(want: Want) {
         this.context.getApplicationContext().setColorMode(ConfigurationConstant.ColorMode.COLOR_MODE_LIGHT);
      }
    }

如果应用有设置自己的ColorMode，仍希望跟随HiCar深浅色模式变化，则应用需要在HiCar场景中将ColorMode设置为COLOR_MODE_NOT_SET。

     1. 应用可以从[UIAbilityContext](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-inner-application-uiabilitycontext)的context中的[Configuration](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-app-ability-configuration)获取到当前应用的所在的屏幕id，即displayId。
     2. 通过Car Kit提供的接口[getSmartMobilityStatus](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/car-smartmobilitycommon#section98392519331)查询HiCar连接状态，查询对应HiCar设备屏幕displayId，用于判断当前应用是否在HiCar场景中显示。 

**表2** SmartMobilityInfo中状态（status）取值说明**编号** | **状态** | **描述**  
---|---|---  
0 | IDLE | 空闲态。  
1 | RUNNING | 运行态。  
  
**表3** SmartMobilityInfo中业务类型（type）取值说明**编号** | 业务类型 | **描述**  
---|---|---  
0 | HICAR | HiCar。  
1 | SUPER_LAUNCHER | 超级桌面。  
2 | CAR_HOP | 流转。  
  
**表4** SmartMobilityInfo中业务数据（data）参数说明**编号** | 参数 | **描述**  
---|---|---  
0 | DEVICE_TYPE | 设备类型。  
1 | DISPLAY_ID | 业务所在的虚拟屏ID。  
2 | IS_PHONE_DESKTOP | 当前是否在HiCar上显示手机桌面（仅在HiCar业务中展示）。  
  
示例代码如下所示：
    
    import UIAbility from "@ohos.app.ability.UIAbility"
    import { smartMobility } from "@kit.CarKit";
    
    export default class EntryAbility extends UIAbility {
    onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
        // 判断 是否 在hicar 屏幕上面显示
        if (this.isAppOnHiCar()) {
          //  设置自己应用 在hicar上 特定的深色
          this.context.getApplicationContext().setColorMode(ConfigurationConstant.ColorMode.COLOR_MODE_DARK);
        }
      }
    
      /**
       * 是否在hicar屏幕上面显示
       * @returns true 为显示
       */
      private isAppOnHiCar(): boolean {
        try {
          // 应用所在的屏幕id
          const currentDisplayId = this.context.config.displayId;
          // 获取SmartMobilityAwareness实例
          let awareness: smartMobilityCommon.SmartMobilityAwareness = smartMobilityCommon.getSmartMobilityAwareness();
          // 获取当前智慧出行连接状态
          let info: smartMobilityCommon.SmartMobilityInfo =
            awareness.getSmartMobilityStatus(smartMobilityCommon.SmartMobilityType.HICAR);
          const deviceDisplayId = Number(info.data["DISPLAY_ID"]);
          if (currentDisplayId === deviceDisplayId) {
            // 表示应用在对应的设备屏幕上
            hilog.info(0x0000, 'testTag', 'app in on device screen');
            return true;
          }
        } catch (e) {
          // 捕获接口调用异常时的错误码并做相应处理
          hilog.error(0x0000, 'testTag', `get smart mobility status error, error code: ${e?.code}`);
        }
        return false;
    }
