# 无线连接说明

厂商HMI应用在集成无线连接功能之前，车机需要已经完成对蓝牙和Wi-Fi的适配，具体内容请参考[说明](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/note-0000001194049481)。

**图1**交互流程   
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250630214052.05171118568408459916073397552015:50001231000000:2800:9A14B29A3047F1FF238E0FEC6402849D37DDF490380089D65F3363188CF37D2A.png "点击放大")

在无线连接过程中，厂商HMI应用需要通过调用HiCar SDK提供的广播发送接口"startAdv()"发送BLE广播，同时通过回调方法"onPinCode()"获取连接PIN码显示到应用界面中，等待HiCar手机接收到广播并输入PIN码后，可以在回调方法"onDeviceChange()"获取到相应的连接事件。
