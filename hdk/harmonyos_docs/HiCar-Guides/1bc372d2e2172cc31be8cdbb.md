# 配置隐私声明界面

## 场景说明

音频应用需提供隐私声明界面用于对用户呈现用户协议与隐私政策，当用户同意之后退出该界面，并向用户请求赋予应用相关权限。

当用户未在手机中完成用户协议与隐私政策确认（例如全新安装音频应用），此时在HiCar环境下首次打开音频应用时，HiCar会在车机屏幕上显示提示信息，如[图1](#ZH-CN_TOPIC_0000001120118671__fig1442217354719)所示（该信息由HiCar生成并弹出，不需要音频应用进行操作），同时在手机端拉起音频应用的隐私声明界面。

**图1**提示信息

为了实现HiCar在手机侧拉起应用隐私声明界面的目的，音频应用需要为HiCar授予相关的权限，并在用户同意用户协议和隐私政策后，将结果告知HiCar，便于后续不再显示提示信息。

## 规范说明

音频应用在处理隐私声明界面及用户权限时，应遵循的规范如下：

* 音频应用不需要为HiCar设计提供单独的隐私声明界面，在HiCar场景下复用音频应用原有的隐私声明界面即可。
* 音频应用在手机侧已完成用户协议和隐私政策确认后，首次在HiCar环境使用时，无需再弹出隐私声明界面及获取用户权限授权。
* 音频应用在手机侧未完成用户协议和隐私政策确认，首次在HiCar环境中使用时，应为HiCar授予相关权限便于被HiCar拉起隐私声明界面，并在用户完成确认后告知HiCar相关结果。

## 接口说明

音频应用在用户完成用户协议和隐私政策确认后，通过如[表1](#ZH-CN_TOPIC_0000001120118671__table8955446471)所示的接口向HiCar告知相关结果。

|接口|参数|参数类型|说明|
|:------------------------------------------------------------------------------------------------|:-------|:------------|:------------------------------------------------------------------------------|
|EventMgr.sendEvent(Context context, final int event, final Bundle params, EventCallBack callBack)|context|Context|应用上下文。|
|EventMgr.sendEvent(Context context, final int event, final Bundle params, EventCallBack callBack)|event|int|事件ID。该场景下固定使用301000作为事件ID。|
|EventMgr.sendEvent(Context context, final int event, final Bundle params, EventCallBack callBack)|params|Bundle|音频应用需返回的结果Bundle。该场景下Key值为**errorCode**，对应的Value取值为： * 0：用户确认成功 * -1：因其它或未知原因失败|
|EventMgr.sendEvent(Context context, final int event, final Bundle params, EventCallBack callBack)|callBack|EventCallBack|结果回调。音频应用无需关注该回调内容。|
[**表1** CarBaseEngine事件上报接口]

## 开发步骤

1. 音频应用需要在AndroidManifest.xml清单文件的隐私声明Activity条目中，配置HiCar相关的权限。

   本示例中假设隐私声明界面对应的界面为PermissionActivity，配置示例如下所示：

   ```screen
   <application>
   ...       
           <!-- PermissionActivity为本示例对应的隐私声明界面 -->
   	<activity android:name=".activity.PermissionActivity">
               <intent-filter>
                   <action android:name="com.huawei.hicar.Media.Permission" />
   <category android:name="com.huawei.hicar.category.Media.Permission" />
               </intent-filter>
           </activity>
   ...
   </application>
   ```

   > 说明
   > * 隐私声明界面Activity的作用是进行用户协议和隐私政策确认以及请求获取权限授权，请勿进行其他无关的业务处理。
   > * 音频应用完成该配置后，在HiCar Debug模式下即可在HiCar主页的应用图标区中看到音频应用的图标。
2. 音频应用需要在用户完成用户协议和隐私政策确认后，将确认结果通过**EventMgr.sendEvent**接口返回HiCar。

   音频应用需先完成音频服务的初始化，再向HiCar返回确认结果。示例代码如下所示：

   ```screen
   private static final String TAG = "PermissionActivity";

   public void onClick(View v){
       SharedPreferences preferences = getSharedPreferences("user",Context.MODE_PRIVATE);
       SharedPreferences.Editor editor = preferences.edit();
       editor.putBoolean("isFirstStart",false);
       editor.commit();
       //当应用完成权限获取及隐私声明后，应用需要将确认结果返回给HiCar，301000这个事件ID作为返回事件ID
       int permissionRequestEventId = 301000;
       //如果应用返回操作码0，应用同时还需要完成MediaSession服务的初始化
       //Todo：完成MediaSession服务初始化，需要音频应用自行完成

      Bundle result = new Bundle();
   result.putInt("errorCode",0);
       Log.i(TAG,"send permission request");
       try{
          EventMgr.sendEvent(getApplicationContext(),permissionRequestEventId,result,callBackResult->{
               Log.i(TAG,"send permission request result:"+callBackResult);
           });
       }catch(RemoteServiceNotRunning remoteServiceNotRunning){
           remoteServiceNotRunning.printStackTrace();
       }
       finish();
   }
   ```
