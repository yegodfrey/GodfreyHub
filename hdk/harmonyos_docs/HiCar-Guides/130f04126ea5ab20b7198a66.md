厂商在集成HiCar SDK时，主要需要完成以下几件工作：

1. 适配连接驱动。为HiCar实现USB/蓝牙/Wi-Fi驱动，便于车机可以通过有线和无线方式连接HiCar。
2. 开发厂商HMI应用。为HiCar实现厂商HMI相关逻辑处理，实现投屏显示、数据传输以及连接管理等功能。厂商需要集成HiCar SDK包中头文件，开发一款预置于车机系统的厂商HMI应用，用于与HiCar手机建立连接显示支持HiCar的应用。实现过程中可参考HiCar SDK包中的"hicar_demo.c"。厂商在进行HMI应用开发时，界面设计需要遵循《HUAWEI HiCar 设备接入UX设计规范》。界面包括但不限于：
   * 有线连接提示界面
   * 无线连接的连接码界面
   * 连接异常提示界面
   * 正在连接界面
3. 管理车机连接。在车机系统设置界面中增加HiCar连接管理的功能。
4. 适配传感器设备。为HiCar实现Audio（必选）、Camera（可选）、GPS模块（可选），便于HiCar可以使用车机MIC、Speaker、Camera、GPS。
