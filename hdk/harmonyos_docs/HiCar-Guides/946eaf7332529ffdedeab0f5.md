# 初始化SDK

## 场景说明

厂商HMI应用在初始化SDK时，需要先设置车机的基本信息，例如车机屏幕大小、蓝牙地址、主驾位置、车机类型等信息，然后在合适的时机（一般为用户需要用车时，例如车机系统上电且车机中控屏幕亮屏后）进行SDK初始化。

## 接口说明

|类|方法|说明|
|:-----------|:---|:------------------------------------------------------------|
|HiCarAdapter|init|厂商HMI应用应该在用户用车时（例如：车机系统点火上电且车机中控屏幕亮屏后）调用"init"进行HiCar SDK初始化。|
[**表1**初始化接口]

初始化流程是一个异步的流程，初始化结果通过事件回调的方式返回给厂商HMI应用。初始化相关的回调如[表2](#ZH-CN_TOPIC_0000001051064476__table1292133713232)所示。

|接口|回调方法|说明|
|:----------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HiCarInitCallback|onInitSuccess()|初始化成功时回调。成功后，SDK会返回一个HiCarAdapter实例，厂商HMI应用需要保存该实例，SDK提供的其他接口都需要使用该实例进行访问调用。|
|HiCarInitCallback|onInitFail()|初始化失败时回调。失败后，SDK会返回相应的错误码信息，请参考《HUAWEI HiCar SDK API参考》检查错误原因。|
|HiCarInitCallback|onBinderDied()|HiCar内部子模块，例如DMSDP、Nearby或者HiSight模块发生异常退出时回调。厂商HMI应用收到该回调时需要调用unRegisterCarListener接口和deInit接口清理HiCar SDK的相关资源。同时，**为了提升连接的稳定性，避免出现连续连接失败以及进程被系统误杀的情况，建议厂商HMI应用在onBinderDied() 回调方法中进行SDK重新加载和厂商HMI应用重启的操作。**|
[**表2**初始化回调方法]

## 开发步骤

1. 厂商HMI应用在调用init接口初始化SDK前设置车机基本信息。

   ```screen
   //设置车机信息
   CarConfig.Builder builder = new CarConfig.Builder(); 
   //设置ModelID 
   builder.withModeId("00010001"); 
   //设置蓝牙Mac 
   builder.withBrMac("74:xx:xx:xx:xx:21"); 
   //设置屏幕物理尺寸，单位毫米 
   builder.withPhysicsWidth(220); 
   builder.withPhysicsHeight(176); 
   //设置屏幕分辨率，单位像素 
   builder.withScreenWidth(1920); 
   builder.withScreenHeight(720); 
   //设置屏幕物理尺寸，单位Inch
   builder.withScreenSize(10.4); 

   //设置默认投屏码率，设置默认值为5*1024*1024bit,用户设置的该值不能小于500*1000bit
   builder.withDefaultBitrate(5242880);
   //设置最大投屏码率，HiCar投屏过程中会动态调整码率，最大码率为调整的上限值
   builder.withMaxBitrate(20000000);
   //设置最小投屏码率，HiCar投屏过程中会动态调整码率，最小码率为调整的下限值
   builder.withMinBitrate(500000);
   //设置音频数据默认输出格式
   builder.withDefaultAudioFormat(0);
   //调整音频流缓存帧数
   builder.withAudioDelayBuffer(10);
   //支持MediaSession按键监听
   builder.withIsAllowMediaButton(true);

   //设置品牌、深浅模式等信息
   Map<String, String> config = newHashMap<String, String>();
   config.put("CAR_BRAND",  "XXX");  
   builder.withInitialConfig(config);

   //配置MIC的值为1
   Map<String, String> config = newHashMap<String, String>();
   config.put("MIC",  "1");
   builder. withAudioSourceConfig(config);

   //设置车机硬件信息
   HardwareInfo hardwareInfo = new HardwareInfo(
       "车机厂商名称", "车机ROM版本号", "蓝牙芯片型号", "Wi-Fi芯片型号");
   builder.withHardwareInfo(hardwareInfo);
   CarConfig carConfig = builder.build(); 
   ```

2. 厂商HMI应用调用init接口初始化SDK。

   初始化示例代码如下所示：

   ```screen
   //SDK初始化 
   HiCarAdapter.init(getApplicationContext(), carconfig, new HiCarInitCallback() { 
       @Override 
       public void onInitSuccess(HiCarAdapter hiCarAdapter) { 
           Log.i(TAG, "HiCar onInitSuccess"); 
           if (hiCarAdapter == null) { 
               Log.d(TAG, "onInitSuccess: hiCarAdapter is null"); 
               return; 
           } 
           
           Log.i(TAG, "HiCar reg listener success"); 
       } 

       @Override 
       public void onInitFail(int errorCode) { 
           Log.i(TAG, "HiCar init failed"); 
       } 

       @Override 
       public void onBinderDied() { 
           Log.i(TAG, "HiCar service bind died"); 
           unloadHiCarSdk(); 
           //TODO:增加重新加载SDK、重启厂商应用的操作，避免出现连续连接失败的情况。
           ......
       } 
   });
   ```
