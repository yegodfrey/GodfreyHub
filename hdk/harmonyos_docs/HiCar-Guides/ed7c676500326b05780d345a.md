# 开发准备

## 环境要求

软件环境：

* JDK版本需1.8及以上。
* Android Studio版本需3.0及以上。

硬件环境：

* 支持HiCar的华为手机。具体机型列表可参见[支持的手机](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/available-phones-0000001227954439)。
* 支持HiCar的车机或预装HiCar模拟器的华为平板。具体车型及设备列表可参见[支持的车型](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/available-models-0000001226230373)。

应用开发者在[向华为申请应用接入](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/app-process-0000001056059155)获得同意后，将会收到华为寄送的硬件调测设备。

## 获取软件包

应用开发者在向华为申请应用接入获得同意后，即可线下收到华为发送的最新版本开放能力软件包。

音频应用将获取CarBaseEngine。

## 集成软件包

1. 打开Android Studio，进入待集成HiCar开放能力的工程。
2. 将解压后的*.aar包复制至工程的app/libs目录中。
3. 在应用级的"build.gradle"文件中添加如下依赖。

   ```screen
   dependencies {
        implementation fileTree(dir: 'libs', include: ['*.aar'])
   }
   ```

## 添加APP ID

为了应用后续可以正常上架华为应用市场HUAWEI HiCar专区，应用需要增加华为开发者联盟网站中生成的APP ID信息。

在AndroidManifest.xml文件中，增加开发者联盟创建应用时生成的APP ID信息，示例如下所示：

```screen
<application
......
        <meta-data
android:name="com.huawei.hms.client.appid"
android:value="appid=********" />
        <!-- 将上述 * 号内容修改为实际 APP ID，其他内容无需修改  -->
......
</application>
```

## 配置应用签名信息

华为对接入HiCar的应用实行白名单管控，只有在白名单中的应用才可以正常显示在HiCar的环境中。白名单管控依赖HMS Core的云端鉴权能力，而云端鉴权需要应用在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站完成签名证书指纹配置，所以应用在接入HiCar时，需完成相应的签名证书指纹配置。具体配置方式请参见[配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/android-signature-info-0000001167504158)。
