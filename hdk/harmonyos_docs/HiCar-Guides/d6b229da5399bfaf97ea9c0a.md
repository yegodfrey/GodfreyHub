# 更新播放列表

## 场景说明

音频应用在播放音频内容时需要通过MediaSession.setQueue方法正确维护播放列表。

## 规范说明

用户在音频应用未播放的情况下，通过右上角音频应用图标直接进入播放页，点击播放按钮时，会出现无内容播放的情况。为了避免出现上述情况，音频应用应在MediaSession初始化时设置一个默认播放列表，并保证列表中有音频内容可以播放。

## 接口说明

|接口|参数|参数类型|说明|
|:-------------------------------------------|:----|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|MediaSession.setQueue(List<QueueItem> queue)|queue|List<QueueItem>|音频应用通过该方法更新播放列表，在构造QueueItem时，除了通过MediaDescription设置曲目Media ID、Title、SubTitle、Description等信息外，还需要通过MediaDescription.setExtras(Bundle bundle)设置HiCar需要的相关信息，其中Bundle参数相关说明如[表2](#ZH-CN_TOPIC_0000001119742857__table965893823917)所示。|
[**表1**更新播放列表相关接口]

|Bundle参数Key|参数类型|说明|
|:------------------------------------------|:----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|hicar.media.metadata.VIP|String|曲目VIP标识： * 0：非VIP * 1：VIP 设置后增加VIP标识。|
|hicar.media.metadata.EXTRA_MES|String|专辑额外信息，展示在方形宫格封面右下角。例如可设置播放量"45万"，最长支持完整展示5个中文汉字或10个英文字符。 仅用于宫格布局。|
|hicar.media.bundle.TAGS|ArrayList<String>|曲目的标签。每首曲目最多允许增加三个标签，如"HQ","独家"。 当曲目带有VIP标识时，将会显示一个VIP标签，此时音频应用只能额外增加两个标签。|
|hicar.media.metadata.CHECK_PAYMENT|Boolean|曲目点击触发播放时，是否需要查询该曲目是否为会员内容或付费内容，详细参见[播放付费/会员内容](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/play-paid-content-0000001078467010)。|

|hicar.media.metadata.ENABLE_EXTRA_PLAY_MODE|Boolean|是否显示自定义播放模式： * false：不显示（缺省值） * true：显示 如果设置为true，则需要在自定义播放模式列表中传入对应ID列表。 这样在模式切换过程中就可以支持传入的自定义播放模式（自定义播放模式和原有播放模式为扩展使用，在原来基础上累加）。|
|hicar.media.metadata.ENABLE_EXTRA_PLAY_RATE|Boolean|是否显示自定义播放模式： * false：不显示（缺省值） * true：显示 如果设置为true，并且自定义播放速率列表中传入希望所支持的播放速率就可以使用（自定义播放速率和原有功能二选一）。|
|音频应用自定义Key|按需设置|音频应用可根据需要在QueueItem入参的Bundle对象中增加自定义键值对。 说明如下： * 用户在点击对应曲目播放时，HiCar会调用playFromMediaId方法，并将该extras作为方法的入参传入。音频应用可以在该extras中添加自定义的字段信息进行相应的逻辑判断或操作。 * 音频应用在设置键值对时，请勿使用"playFromWhere"作为key，该key已被HiCar内部使用，用于区分是否从播放列表开始播放。（该key值为"MediaListPlayList"表示是否是点击播放页播放列表中歌曲进行播放。）|

## 开发步骤

1. 在初始化MediaSession时，音频应用设置一个默认播放列表，并保证列表中有音频内容可以播放。
2. 在后续播放其它曲目时，音频应用及时刷新播放列表。

   构建播放列表的示例代码如下所示：

   ```screen
   private ArrayList<MediaSession.QueueItem> genArrayListQueue(String parentId,int pageIndex,int pageSize){
       ArrayList<MediaSession.QueueItem> results = new ArrayList<>(pageSize);
       int startIndex = (pageIndex - 1)*pageSize;
       int size = pageSize * pageIndex;
       if(size>ITEM_SIZE){
           size = ITEM_SIZE;
       }
       for(int i = startIndex;i < size;++i){
           Bundle bundle = new Bundle();
           bundle.putString("hicar.media.metadata.VIP",vipState[i]+"");
           ArrayList<String> tags = new ArrayList<>(2);
           switch(i%3){
               case 0:
                   tags.add("SQ");
                   break;
               case 1:
                   tags.add("HQ");
                   break;
               default:
                   tags.add("SQ");
                   tags.add("HQ");
           }
           bundle.putStringArrayList("hicar.media.bundle.TAGS",tags);
           MediaDescription description = new MediaDescription.Builder().setMediaId(parentId+"_"+i)
               .setTitle(getTitle(i))
               .setSubtitle(getSubTitle(i))
               .setDescription(getAlbum(i))
               .setIconUri(parentId.contains("_")?Uri.parse(""):Uri.parse(URI_PREV_iconUrls))
               .setExtras(bundle)
               .build();
           MediaSession.QueueItem queueItem = new MediaSession.QueueItem(description,i);
           result.add(queueItem);
       }
       return results;
   }

   mMediaSession.setQueue(genArrayListQueue("",1,ITEM_SIZE));
   ```
