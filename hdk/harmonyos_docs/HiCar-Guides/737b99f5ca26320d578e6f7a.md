# 指定通信端口

为确保手机和车机之间正常通信，HiCar SDK会在业务运行期间（基于有线或无线连接）创建多个Socket作为数据交互通道。默认情况下，HiCar SDK绑定本地IP时采用随机端口，导致其对车机系统端口的占用不可预测且范围较广。若需关闭系统中非必要的通信端口，或缩小HiCar SDK的端口占用范围，请配置下表中的系统属性，为HiCar SDK相关业务通道指定固定的通信端口。

|使用进程|属性名|协议|SOCKET说明|
|:---------------------|:----------------------------------------|:--|:-------------------------------------------------------------------------------------------------------------|
|com.huawei.nearby|persist.sys.hicar.sessionControl.port|TCP|建立连接控制通道|
|com.huawei.nearby|persist.sys.hicar.authentication.port|TCP|认证通道（仅有线连接使用）|
|com.huawei.nearby|persist.sys.hicar.virtualization.port|TCP|虚拟化通道|
|com.huawei.dmsdpdevice|persist.sys.hicar.ctrlServer.port|TCP|分布式业务控制通道|
|com.huawei.dmsdpdevice|persist.sys.hicar.udpKa.port|UDP|分布式业务保活通道|
|com.huawei.dmsdpdevice|persist.sys.hicar.timeSyn.port|UDP|时间同步通道|
|com.huawei.dmsdpdevice|persist.sys.hicar.virSpeakerSocket.port|UDP|扬声器数据通道|
|com.huawei.dmsdpdevice|persist.sys.hicar.modemSpeakerSocket.port|UDP|通话扬声器（听筒）数据通道|
|com.huawei.dmsdpdevice|persist.sys.hicar.virMicSocket.port|UDP|麦克风数据通道|
|com.huawei.dmsdpdevice|persist.sys.hicar.modemMicSocket.port|UDP|通话麦克风（话筒）数据通道|
|com.huawei.hisight|persist.sys.hicar.rtsp.port|TCP|RTSP（实时流协议）通道|
|com.huawei.hisight|persist.sys.hicar.remoteControl.port|TCP|反控通道|
|com.huawei.hisight|persist.sys.hicar.media.port|UDP|视频流通道|
|com.huawei.hisight|persist.sys.hicar.audio.port|UDP|音频流通道（仅[高品质/空间音频](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/spatial-audio-0000002563616238)使用）|
|HMI|persist.sys.hicar.logSocket.port|TCP|日志传输通道|
|HMI|persist.sys.hicar.metaDataSocket.port|TCP|元数据通道|
|HMI|persist.sys.hicar.fileShareControl.port|TCP|文件互传控制通道|
|HMI|persist.sys.hicar.fileShareData.port|TCP|文件互传数据通道|
[**表1**HiCar SDK通信端口相关系统属性]

指定元数据通道socket使用50001端口，示例如下：

```screen
adb shell
> setprop persist.sys.hicar.metaDataSocket.port 50001  // 指定元数据通道socket端口为50001
```

查询元数据通道socket通信端口是否已指定，示例如下：

```screen
adb shell
> getprop persist.sys.hicar.metaDataSocket.port  // 查询元数据通道socket通信端口
```

查询所有已指定的通信端口，示例如下：

```screen
adb shell
> getprop | grep persist.sys.hicar.*.port  // 查询HiCar SDK所有已指定的通信端口
```

> 说明
>
> 1. 上述系统属性对有线连接、无线连接和扫码连接同时生效。
>
> 2. 上述系统属性不可复用相同端口；若未设置相应属性值，HiCar SDK默认使用随机端口。
>
> 3. 指定通信端口后，车机系统需要为HMI及HiCar SDK相关进程保留这些端口，保证端口可访问，避免其他进程占用。
