# 更新播放模式

## 场景说明

用户在播放页通过播放模式按钮进行模式切换时，音频应用会收到播放模式变化指令，音频应用应变更当前播放模式，并将结果告知HiCar。

## 接口说明

### 设置支持的播放模式集合

音频应用在首次设置MediaMetadata时，应通过MediaSession.setMetadata方法向HiCar明确音频应用支持的播放模式及默认的播放模式，便于HiCar在界面中展示相应的播放模式按钮。

|接口|参数|子参数类型|子参数|说明|
|:-----------------------------------------------|:-------|:-----|:----------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|MediaSession.setMetadata(MediaMetadata metadata)|metadata|String|hicar.media.metadata.PLAY_MODE_LIST|音频应用支持的播放模式集合，HiCar约定支持的播放模式为： * 0：列表循环 * 1：单曲循环 * 2：随机播放 * 3：顺序播放 * 4：自定义的播放模式 * ... 如果音频应用支持列表、单曲、随机、顺序播放，则设置集合为"0123"，其它情况返回对应的数字组合即可。 如果存在自定义播放模式，切换顺序在原有基础上累加。|
|MediaSession.setMetadata(MediaMetadata metadata)|metadata|String|hicar.media.metadata.PLAY_MODE|默认的播放模式。|

### 获取播放模式变化指令

|接口|参数|参数类型|说明|
|:----------------------------------------------------------------|:-----|:-----|:----------------------------------------------------------------------|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|action|String|播放模式变化指令，取值为"hicar.media.action.PLAY_MODE_CHANGE"。|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|extras|Bundle|播放模式变化指令中扩展参数，详见[表3](#ZH-CN_TOPIC_0000001078147430__table965893823917)。|
[**表2**获取播放模式变化指令接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:----------------------------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------|
|hicar.media.bundle.REQUEST_ID|String|本次操作的requestId，由HiCar生成并下发。|
|hicar.media.bundle.PLAY_MODE|int|用户切换后新的播放模式： * 0：列表循环 * 1：单曲循环 * 2：随机播放 * 3：顺序播放 * 4：自定义的播放模式 * ... 该参数只在指定切换播放模式时会带入。 如果是在播放页点击按钮切换播放模式，因HiCar不知道下一个模式是什么，这种情况下不会带有此参数。|
[**表3**播放模式变化指令中扩展参数说明]

### 响应播放模式变化指令

音频应用在收到播放模式变化指令后，需通过MediaSession.setMetadata方法更新MediaMetadata对象中的hicar.media.bundle.PLAY_MODE属性更新当前的播放模式。

同时，音频应用还需要通过MediaSession.sendSessionEvent方法返回变更后的收藏状态，便于HiCar进行语音播报。

|接口|参数|参数类型|说明|
|:---------------------------------------------------------|:-----|:-----|:---------------------------------------------------------------------|
|MediaSession.sendSessionEvent(String action,Bundle extras)|action|String|播放模式变化指令，取值为"hicar.media.action.PLAY_MODE_CHANGE"。|
|MediaSession.sendSessionEvent(String action,Bundle extras)|extras|Bundle|播放模式变化指令响应参数，详见[表5](#ZH-CN_TOPIC_0000001078147430__table573215409478)。|
[**表4**播放模式变化响应接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:----------------------------|:-----|:----------------------------------------------------------------|
|hicar.media.bundle.RESULT|int|执行结果： * 0：成功 * -1：因其它或未知原因失败|
|hicar.media.bundle.REQUEST_ID|String|本次下发的requestId需要在此处返回。|
|hicar.media.bundle.PLAY_MODE|int|切换后新的播放模式： * 0：列表循环 * 1：单曲循环 * 2：随机播放 * 3：顺序播放 * 4：自定义的播放模式 * ...|
[**表5**播放模式变化指令响应参数说明]

## 开发步骤

1. 音频应用在首次设置MediaMetadata时，应明确支持的播放模式集合及默认的播放模式。

   示例代码如下所示：

   ```screen
   MediaMetadata metadata = new MediaMetadata.Builder()
               .putString("hicar.media.metadata.PLAY_MODE_LIST", "0123")
               .putInt("hicar.media.metadata.PLAY_MODE", 0).build();	
   mMediaSession.setMetadata(metadata);
   ```

2. 音频应用在onCustomAction方法中针对action入参识别播放模式变化指令。

   示例代码如下所示：

   ```screen
   private int mPlaymode = 0;

   @Override
   public void onCustomAction(@NonNull String action,@Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       String requestId;
       switch(action){
           case "hicar.media.action.PLAY_MODE_CHANGE":
               //执行播放模式变化任务

               break;
           default;
               break;
       }
   }
   ```

3. 音频应用需自行处理播放模式的变化，在完成后告知HiCar执行结果。

   示例代码如下所示：

   ```screen
   private int mPlaymode = 0;

   @Override
   public void onCustomAction(@NonNull String action,@Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       String requestId;
       switch(action){
           case "hicar.media.action.PLAY_MODE_CHANGE":
               requestId = extras.getString("hicar.media.bundle.REQUEST_ID");
   			
   		//执行播放模式变化任务，改变mPlaymode
   		
   		bundle = new Bundle();
   		bundle.putInt("hicar.media.bundle.RESULT",0);
   		bundle.putString("hicar.media.bundle.REQUEST_ID", requestId);
   		bundle.putInt("hicar.media.bundle.PLAY_MODE", mPlaymode);
   		mMediaSession.sendSessionEvent(action, bundle);
   		
                   // 注意：这里仅为播放模式的示例，不能只设置这一个数据，其它的全量数据还是要正确设置，不然歌曲信息等数据就会被冲掉	
   		MediaMetadata metadata = new MediaMetadata.Builder()
   			.putString("hicar.media.metadata.PLAY_MODE", String.valueOf(mPlaymode)).putXXX....build();
   		mMediaSession.setMetadata(metadata);
   			
               break;
           default;
               break;
       }
   }
   ```
