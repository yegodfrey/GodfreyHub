# 应用分屏

#### 场景说明

为充分利用车机屏幕比较大的优势，HiCar支持应用分屏功能。应用分屏是指在同一设备屏幕上同时显示并运行两个或多个应用程序的功能。应用在适配HiCar时需要关注全屏和分屏状态下的UI布局。

**图1** 应用分屏

HiCar当前支持的分屏场景：

     * 当前支持音频、导航类应用分屏显示。
     * 导航应用处于导航状态，音频应用处于播放状态时会进入分屏状态。

在不同分辨率的屏幕上，应用分屏的比例并不一样，应用需要适配各种尺寸分辨率下的页面布局。应用分屏比例如下图所示。

#### 应用分屏设置

应用分屏中，音频应用显示存在两种界面形式：

     * 播放器界面（HarmonyOS 6.0及以上系统支持）
     * 音频应用原始界面

在HiCar连接成功后，用户可以在设置中通过开关控制显示播放器界面还是音频应用原始界面。

#### 监听应用分屏状态变化

应用可以通过系统提供的接口[window.on('windowSizeChange')](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-window-window#onwindowsizechange7)监听应用分屏状态的变化，如进入/退出分屏状态，并刷新UI界面。示例代码如下所示：
    
    import { uiExtensionHost } from '@kit.ArkUI';
    public init(windowProxy: uiExtensionHost.UIExtensionHostWindowProxy): void {
      try {
        if (windowProxy) {
          windowProxy?.on('windowSizeChange', this.sizeChangeCallback);
        }
      } catch (err) {
        log.error(`listenWindowChange, listen failed, code: ${{(err as BusinessError).code}`);
      }
    }
    private sizeChangeCallback = (): void => {
        // 在此处处理窗口变化
    }
