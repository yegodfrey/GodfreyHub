# 获取文档

## 权限说明

目前HUAWEI HiCar仅向合作中的开发伙伴开放接入文档。合作中的伙伴可按照如下步骤获取文档。

## 获取步骤

如果已经参照[应用接入流程](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/app-process-0000001056059155)反馈了全量的应用接入申请信息，无需重复按照本章节指导获取文档权限。

在需要新增个别账号的文档权限时，请按照如下步骤操作：

1. 确认您用于登录[华为开发者联盟网站](https://developer.huawei.com/consumer/cn/)的华为账号，一般为邮箱或手机号码。
2. 发送邮件【HUAWEI HiCar文档权限申请】到邮箱"huaweihicar@huawei.com"。

   发送邮件时请提供如下信息：
   * 您的公司
   * 您的姓名
   * 您的华为账号（如有多人，请收集后一并发送）
   * 您当前与HiCar的合作项目（需明确是音频应用接入、地图应用接入、普通应用接入）

   HiCar团队在收到邮件后，会根据项目进展情况，为您开通相关文档的访问权限。届时您再刷新本页面即可查看相关接入文档。
