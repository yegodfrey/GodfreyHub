# 更新列表单个数据

## 场景说明

音频应用可以通过MediaSession.sendSessionEvent方法发送单个数据更新指令，主动刷新列表中的单个数据，避免使用[更新内容列表数据](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/update-content-all-0000001119898505)指令更新整个列表数据时，引起界面闪烁。例如音频应用可以通过该指令，随时更新最近播放列表。

## 接口说明

|接口|参数|参数类型|说明|
|:---------------------------------------------------------|:-----|:-----|:-------------------------------------------------------------------|
|MediaSession.sendSessionEvent(String action,Bundle extras)|action|String|数据更新指令，取值为"hicar.media.action.UPDATE_ITEM"。|
|MediaSession.sendSessionEvent(String action,Bundle extras)|extras|Bundle|数据更新指令扩展参数，详见[表2](#ZH-CN_TOPIC_0000001158160569__table965893823917)。|
[**表1**单个数据更新指令相关接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:-----------------------------------|:---------------------|:----------------------------------------|
|hicar.media.bundle.PARENT_ID|String|当前更新数据所在的列表ID。|
|hicar.media.bundle.MEDIA_ID|String|当前更新数据的Media ID。|
|hicar.media.bundle.UPDATE_QUEUE_ITEM|MediaSession.QueueItem|MediaSession.QueueItem对象参数，对应曲目需要更新的内容信息。|
[**表2**数据更新指令扩展参数]

## 开发步骤

音频应用在需要更新数据列表时，通过MediaSession.sendSessionEvent方法发送数据更新指令。

示例代码如下所示：

```screen
public void updateQueueItem() {
  String parentId = parentId;   
  String mediaId = mediaId ;
  MediaDescription description = new MediaDescription.Builder().setMediaId(mediaId)
    .setTitle("title")
    .setSubtitle("subTitle")
    .setDescription("description")
    .setIconUri(Uri.parse(url))
    .setExtras(new Bundle())
     .build();
   Bundle bundle = new Bundle();
   bundle.putInt("hicar.media.bundle.RESULT", 0);
   bundle.putString("hicar.media.bundle.PARENT_ID", parentId);
   bundle.putString("hicar.media.bundle.MEDIA_ID", mediaId);
   MediaSession.QueueItem queueItem = new MediaSession.QueueItem(description, 0);
   bundle.putParcelable("hicar.media.bundle.UPDATE_QUEUE_ITEM", queueItem);
   mMediaSession.sendSessionEvent(MEDIA_ACTION_UPDATE_ITEM, bundle);
}
```
