# 判断手机是否支持HiCar

## 场景说明

厂商HMI应用可以通过HiCar SDK提供的接口，判断当前连接车载蓝牙的手机是否支持HiCar，进而在车机原生界面中进行提示或引导用户使用HiCar。例如，假设车机存在连接管理器原生界面，在该界面中可以展示当前连接的设备情况，如[图1](#ZH-CN_TOPIC_0000001541760816__fig61017428189)所示。

**图1**连接管理器示意图

对于支持HiCar的手机设备：

* 如果该手机设备此前已连接过车机，则在点击图标后，直接进行连接。具体说明可以参考[3](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/device-management-0000001606952849#ZH-CN_TOPIC_0000001606952849__li826017415532)。
* 如果该手机设备此前未连接过车机，但支持HiCar，则在点击图标后，可跳转到PIN码界面引导用户进行首次连接。

## 接口说明

|类|方法|说明|
|:-----------|:-------------|:----------------------------|
|HiCarAdapter|isSupportHiCar|根据蓝牙地址判断当前连接车载蓝牙的手机是否支持HiCar。|
[**表1**相关接口]

## 开发步骤

1. 厂商HMI应用关注系统蓝牙连接事件。蓝牙事件如下所示：

   ```screen
   android.bluetooth.headsetclient.profile.action.CONNECTION_STATE_CHANGED
   ```

2. 在收到蓝牙连接完成的系统广播后，调用HiCar SDK的"isSupportHiCar"接口可以获取手机是否支持HiCar。
