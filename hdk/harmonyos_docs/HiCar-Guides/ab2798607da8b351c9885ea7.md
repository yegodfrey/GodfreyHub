# 播放付费/会员内容

## 场景说明

音频应用可以为付费/会员内容设置标记，当需要播放付费/会员内容时，可以通过通知弹框和TTS语音播报的方式提醒用户。

约定：

1. 会员内容：登录后可以播放的内容。
2. 付费内容：购买后可以播放的内容。
3. 会员/付费内容不包括可试听的内容，可试听内容认为是免费内容。

## 规范说明

音频应用在处理付费/会员内容时，应遵循如下规范：

* 有声读物场景
  1. 用户手动点击付费/会员内容时，进行弹框提醒，不进行语音播报。
  2. 播放器正常播放时遇到付费/会员内容时，进行TTS语音播报提醒，不进行弹框提醒。
* 音乐场景
  1. 用户手动点击付费/会员内容时，进行弹框提醒，不进行语音播报。
  2. 播放器正常播放时遇到付费/会员内容时，直接跳过付费/会员内容，播放其它可播放的内容，不进行TTS语音播报提醒，也不进行弹框提醒。

## 接口说明

前文[加载内容数据](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/load-content-data-0000001120118673)提到，音频应用可以为付费/会员内容设置"hicar.media.metadata.CHECK_PAYMENT"标记，当需要播放付费/会员内容时，音频应用会收到查询该曲目是否能够播放的指令。

音频应用应根据用户的购买/登录状态判断当前曲目是否可以正常播放，并返回结果。如果无法播放，音频应用需要根据当前播放场景（用户主动点击或播放器自动播放），通过MediaSession.sendSessionEvent方法发起通知弹框及TTS语音播报。

## 开发步骤

1. 音频应用在加载内容数据时，为付费/会员内容设置"hicar.media.metadata.CHECK_PAYMENT"标记，具体内容可参见前文[加载内容数据](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/load-content-data-0000001120118673)。

   示例代码如下所示：

   ```screen
   ......
   Bundle bundle = new Bundle();
   bundle.putString("hicar.media.metadata.VIP", "1"); 
   bundle.putBoolean("hicar.media.metadata.CHECK_PAYMENT",true);
   ......
   ```

2. 当用户主动点击付费/会员内容进行播放时，如果不允许播放，进行弹框提醒。

   音频应用需要严格遵守如[表7](#ZH-CN_TOPIC_0000001078467010__table1620110123313)所示的弹框要求。

   |要求项|具体要求|
   |:--|:--------------------------------------------------------------------------------------------------------------|
   |标题|"提醒"|
   |内容|弹框内容分为两种场景： * 如果需要用户登录后使用，内容请设置为："当前为会员内容，请在安全的情况下在手机端登入后播放。" * 如果需要用户付费后使用，内容请设置为："当前为付费内容，请在安全的情况下载手机端购买后播放。"|
   |按钮|按钮形式：单按钮。 按钮文字："知道了"|
   [**表7**付费/会员内容弹框要求]

   示例代码如下所示：

   ```screen
   @Override
   public void onCustomAction(@NonNull String action,@Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       switch(action){
           case "hicar.media.action.CHECK_PAYMENT":
   	    String requestId =extras.getString("hicar.media.bundle.REQUEST_ID");
   	    String mediaId = extras.getString("hicar.media.bundle.MEDIA_ID");

   	    //音频应用完成是否可以播放的判断逻辑

   	    Bundle paymentBundle =new Bundle();
   	    paymentBundle.putInt("hicar.media.bundle.RESULT",0);
   	    paymentBundle.putBoolean("hicar.media.bundle.IS_CAN_PLAY",false);
   	    paymentBundle.putString("hicar.media.bundle.REQUEST_ID",requestId);
   	    mediaSession.sendSessionEvent(action,paymentBundle);
   	    mediaSession.sendSessionEvent("hicar.media.action.DIALOG",createBundle());
               break;
           default:
               break;
       }
   }

   // 创建dialog
   private Bundle createBundle() {
   	Bundle bundle = new Bundle();
   	bundle.putString("hicar.media.bundle.DIALOG_ID", "dialog_one");
   	bundle.putInt("hicar.media.bundle.RESULT", 0);
   	bundle.putString("hicar.media.bundle.DIALOG_TITLE", "提醒");
   	bundle.putString("hicar.media.bundle.DIALOG_CONTENT",
   			"当前为会员内容，请在安全的情况下在手机端登入后播放。");
   	bundle.putString("hicar.media.bundle.DIALOG_LEFT_BUTTON_TEXT", "知道了");

   	return bundle;
   }
   ```

3. 当播放器播放内容时遇到有声读物付费/会员内容时，如果不允许播放，进行TTS语音播报提醒。

   示例代码如下所示：

   ```screen
   Bundle ttsBundle = new Bundle();
   ttsBundle.putInt("hicar.media.bundle.RESULT",0);
   ttsBundle.putInt("hicar.media.bundle.TTS_TYPE",0);
   mediaSession.sendSessionEvent("hicar.media.action.TTS",ttsBundle);
   ```

4. 当播放器播放内容时遇到音乐付费/会员内容时，如果不允许播放，直接跳过付费/会员内容，播放可以播放的内容。

   该步骤需要音频应用根据业务逻辑自行完成。
