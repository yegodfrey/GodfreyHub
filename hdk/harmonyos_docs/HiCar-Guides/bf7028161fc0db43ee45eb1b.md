# 接入说明

音频应用可以通过CarBaseEngine提供的音频模板快速接入HiCar。音频模板基于Android MediaSession框架实现，HiCar通过MediaSession机制与音频应用进行数据交互，完成数据获取并展示、进行播放控制等，所以音频应用在接入HiCar之前必须完成MediaSession框架适配，更多关于MediaSession的内容，请参考Android官方说明[Android Developers中的媒体章节](https://developer.android.com/guide/topics/media-apps/media-apps-overview)。

音频应用与HiCar交互过程中，HiCar通过CarBaseEngine启动应用的MediaSession服务后，将通过MediaSession框架获取界面绘制所需要的数据，并完成界面展示。当用户点击界面热键时，HiCar会通过MediaSession框架向音频应用下发对应的指令，音频应用完成对应的操作，从而完成界面对用户动作的响应。

在通过音频模板方案接入HiCar过程中，音频应用只需专注于音频数据的准备和播放服务的实现即可，其它繁琐的工作，例如绘制车机界面并保证各分辨率兼容性、管理音频桌面卡片和实现音频任务接续等都由HiCar完成。
