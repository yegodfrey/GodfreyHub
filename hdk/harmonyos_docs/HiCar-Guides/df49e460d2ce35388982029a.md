# 无线连接流程

HiCar无线连接过程主要涉及：蓝牙服务发现、蓝牙配对、蓝牙RFCOMM连接、Wi-Fi连接。无线连接过程中消息交互过程如[图1](#ZH-CN_TOPIC_0000001052464951__fig9355214164716)所示。

**图1**无线连接消息交互

手机和车机在无线连接时6类消息交互：

1. BLE广播携带车机BR地址到手机，便于手机根据经典蓝牙BR地址建立BR链路。
2. 低速蓝牙控制通道（图中RFCOMM控制通道），用于孵化蓝牙数据通道和高速Wi-Fi控制通道。
3. 低速蓝牙数据通道（图中RFCOMM数据通道），用于进行HiCar鉴权。
4. 协商Wi-Fi高速通道，基于低速蓝牙控制通道协商高速Wi-Fi控制通道参数。
5. 高速Wi-Fi控制通道（图中Wi-Fi控制通道），用于孵化高速Wi-Fi数据通道。
6. 高速Wi-Fi数据通道（图中Wi-Fi数据通道），进行HiCar投屏、业务数据传输。
