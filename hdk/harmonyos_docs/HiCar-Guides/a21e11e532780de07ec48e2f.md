# 获取当前连接方式

## 场景说明

厂商HMI应用可以通过"HiCarGetConnectionType()"接口获取当前的连接方式，进行一些业务场景的处理。例如用户通过无线方式连接成功后，手机和车机之间通过新建的Wi-Fi AP进行数据交互，如果用户手工修改了Wi-Fi AP的信息，会导致连接中断。此时，厂商HMI应用在获取当前连接为无线方式时，可以禁用相应Wi-Fi AP信息的修改，保证HiCar连接正常。

## 接口说明

|头文件|方法|说明|
|:------|:---------------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
|hicar.h|HiCarGetConnectionType|返回当前的连接方式，返回结果为： * HICAR_CONNECTION_USB（值为：6）：当前通过有线方式连接。 * HICAR_CONNECTION_WIFI（值为：3）：当前通过无线方式连接。 * HICAR_CONNECTION_UNKNOWN（值为：0）：当前连接方式未知。|
[**表1**获取连接方式相关接口]

## 开发步骤

厂商HMI应用获取连接方式的示例代码如下所示：

```screen
//获取连接方式
int connectType = HiCarGetConnectionType(hicarHandle);
if (connectType == HICAR_CONNECTION_USB) {
     //TODO:厂商逻辑
} else if (connectType == HICAR_CONNECTION_WIFI) {
     //TODO:厂商逻辑
} else {
     //TODO:厂商逻辑
}
```
