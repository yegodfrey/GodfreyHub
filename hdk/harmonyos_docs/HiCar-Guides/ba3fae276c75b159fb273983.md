# 管理车机按键/旋钮/触摸板

## 场景说明

HiCar支持通过物理按键和旋钮控制相应的应用和服务，例如通过多媒体下一首按键切换音乐、通过挂机键挂断通话等。厂商在集成HiCar SDK时需要将物理按键和旋钮事件上报给HiCar SDK，便于控制对应的应用和服务。

厂商在处理车机物理按键、旋钮、触摸板时，应合理处理物理事件在车机本地与HiCar之间的分发逻辑。推荐按照以下规则进行实现：

1. 厂商无需上报不需要HiCar处理的按键事件，需要车机上报的物理按键如[表 HiCar SDK中支持的按键和旋钮事件](#ZH-CN_TOPIC_0000001050064330__table8342183114500)。
2. 接通/挂断键按照按照如下规则适配：
   1. 蓝牙通话时，HiCar不处理接听/挂断键，通话的接听挂断由蓝牙处理。
   2. HiCar虚拟通话时，接听/挂断键需要根据[通话状态](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/call-status-and-focus-0000001052659461)发送正确的事件给手机。
3. 媒体播控键按照如下规则适配：厂商判断当前焦点栈中有HiCar应用申请的媒体焦点，发送方控事件给手机，如焦点栈中没有找到HiCar申请的媒体焦点，厂商在收到HiCar音乐元数据的状态下，也需要发送方控事件给手机。

## 开发步骤

1. 当物理按键或旋钮被触发后，厂商需要自行解析对应的事件。
2. 通过HiCarPostEvent接口向HiCar SDK发送对应的事件。注意DOWN事件和UP事件必须成对发送。

   示例代码如下所示：

   ```screen
   void SendKeyEvent()
   {
       if (g_hicarHandle == NULL) {
           printf("hicar handle null\n");
           return;
       }
       printf("SendKeyEvent start\n");
       HwRemoteCtrlEvent *obj = (HwRemoteCtrlEvent*)HiCarNewObject(g_hicarHandle, HICAR_OBJECT_REMOTE_CTRL, sizeof(HwRemoteCtrlEvent));
       if (obj != NULL) {
           obj->header.version = 0;
           obj->header.dFlag = 1;
           obj->header.wFlag = 0;
           obj->header.wr1Flag = 0;
           obj->header.wr2Flag = 0;
           obj->header.rFlag = 0;
           obj->header.inputCategory = 0;
           obj->header.len = 10;
           obj->evtType = REMOTECTRL_KEY;
   	obj->timestamp = 0;
   	obj->evtDetail.keyEvt.type = REMOTECTRL_KEY_DOWN
   	obj->evtDetail.keyEvt.keyCode1 = 5; // 5 call, 6 end call
   	obj->evtDetail.keyEvt.keyCode2 = 0;
   	obj->evtDetail.keyEvt.metaState = 0;

           HiCarPostEvent(g_hicarHandle, HICAR_EVENT_REMOTE_CTRL, (char*)obj, sizeof(*obj));
           //HiCarDeleteObject(g_hicarHandle, HICAR_OBJECT_REMOTE_CTRL, (char*)obj);
       }
       printf("SendKeyEvent end\n");
       return;
   }
   ```
