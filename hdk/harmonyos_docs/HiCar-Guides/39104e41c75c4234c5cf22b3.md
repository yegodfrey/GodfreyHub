# 更新播放曲目

## 场景说明

音频应用在完成数据加载后，当用户点击某个曲目时，HiCar会将该曲目的Media ID告知音频应用。音频应用需在onPlayFromMediaId根据Media ID播放对应的曲目，同时通过MediaSession.setMetadata刷新曲目MediaMetadata数据、通过MediaSession.setPlaybackState维护正确的播放状态和播放进度。

## 规范说明

音频应用在播放页应妥善处理上下首按钮切换逻辑。

* 如果有播放列表，上下首按钮在播放列表中切换内容，内容列表应支持循环播放。
* 如果无播放列表（例如电台），上下首按钮在不同电台或频道中切换。
* 如果无可切换内容，上下首按钮置灰显示。

## 开发步骤

1. 音频应用在MediaSession的Callback实现类中Override onPlayFromMediaId方法，并在该方法中实现根据曲目Media ID进行播放的功能。
2. 通过MediaSession.setMetadata刷新曲目MediaMetadata数据。

   示例代码如下所示：

   ```screen
   //构造MediaMetadata，主要包括歌曲名称、歌曲作者、专辑名称、歌词信息、歌曲时长、歌曲封面、是否是VIP
   Bitmap bitmap = BitmapFactory.decodeResource(getResources(),R.drawable.album_art);//初始化专辑封面
   MediaMetadata metadata = new MediaMetadata.Builder().putString(MediaMetadata.METADATA_KEY_MEDIA_ID,mediaID)    //id
       .putString(MediaMetadata.METADATA_KEY_TITLE,"歌曲名称")    //歌曲名称
       .putString(MediaMetadata.METADATA_KEY_ARTIST,"作者")    //作者
       .putString(MediaMetadata.METADATA_KEY_ALBUM,"专辑")    //专辑
       .putLong(MediaMetadata.METADATA_KEY_DURATION,228000)    //媒体时长为3分48秒
       .putBitmap(MediaMetadata.METADATA_KEY_ALBUM_ART,bitmap)    //专辑或歌曲封面
       .putString("hicar.media.metadata.FAVORITE_STATE","0")    //这首曲目是否已经被收藏，"0"表示未收藏，"1"表示已收藏
       .putString("hicar.media.metadata.VIP","1")    //这首曲目是否是VIP曲目，"0"表示非VIP，"1"表示VIP
       .putString("hicar.media.metadata.PARENT_ID",mParentId)    //所在播放列表id，用于首页播放状态同步
       .putString("hicar.media.metadata.LIKE_BUTTON_ENABLE",true)    //喜欢按钮是否可用，true代表可用，false代表不可用
       .putString("hicar.media.metadata.PLAY_FUNCTION_BUTTON_ENABLE",true)    //播放功能按钮是否可用，true代表可用，false代表不可用
       .putString("hicar.media.metadata.PREV_BUTTON_ENABLE",true)    //上一首按钮是否可用，true代表可用，false代表不可用
       .putString("hicar.media.metadata.NEXT_BUTTON_ENABLE",true)    //下一首按钮是否可用，true代表可用，false代表不可用
       .putString("hicar.media.metadata.PROGRESS_ENABLE",true)    //进度条是否可用，true代表可用，false代表不可用
       .putString("hicar.media.metadata.PLAY_FUNCTION","playMode")    //播放功能按钮的功能，"playMode"代表播放模式功能，"playRate"代表播放速率功能
       .putString("hicar.media.metadata.ENABLE_EXTRA_PLAY_RATE", "true")     //自定义模式是否启用，true代表启用，false代表不启用         
       .putString("hicar.media.metadata.ENABLE_EXTRA_PLAY_MODE", "false")   //自定义模式是否启用，true代表启用，false代表不启用    
       .build();
   mMediaSession.setMetadata(metadata);
   ```

3. 正确维护PlaybackState，同步播放状态和播放进度。

   示例代码如下所示：

   ```screen
   //设置播放进度和状态信息，这里将播放状态设置为正在播放，播放进度设置为42秒
   PlaybackState playbackState = new PlaybackState.Builder().setState(PlaybackState.STATE_PLAYING,42000,1.0f).build();
   mMediaSession.setPlaybackState(playbackState);
   ```

4. 在首次初始化播放服务时，建议音频应用正确设置播放模式及播放速率。

   示例代码如下所示：

   ```screen
   //应用需要根据最右侧按钮的功能选择播放模式或播放速率
   //设置播放模式，使用MediaSession.sendSessionEvent()传送播放模式信息
   //当播放模式发生变化或者首次初始化播放服务时，音频应用需要将播放模式信息传递给HiCar
   String action = "hicar.media.action.PLAY_MODE_CHANGE";
   Bundle bundle = new Bundle();
   //播放模式参数定义（0：列表循环，1：单曲循环，2：随机播放，3：顺序播放）
   int playMode = extras.getInt("hicar.media.bundle.PLAY_MODE",0);
   bundle.putInt("hicar.media.bundle.RESULT",0);
   bundle.putInt("hicar.media.bundle.PLAY_MODE",playMode);
   mMediaSession.sendSessionEvent(action,bundle);

   //设置播放速率，使用MediaSession.sendSessionEvent()传送播放速率信息
   //当播放速率发生变化或者首次初始化播放服务时，音频应用需要将播放速率信息传递给HiCar
   String action = "hicar.media.action.PLAY_RATE_CHANGE";
   Bundle bundle = new Bundle();
   //播放速率参数定义（0：0.75倍速，1：1倍速，2：1.5倍速）
   int playRate = extras.getInt("hicar.media.bundle.PLAY_RATE",1);
   bundle.putInt("hicar.media.bundle.RESULT",0);
   bundle.putInt("hicar.media.bundle.PLAY_RATE",playRate);
   mMediaSession.sendSessionEvent(action,bundle);
   //自定义播放速率参数定义切换
   String playRate = extras.getString("hicar.media.bundle.PLAY_RATE",1.0X); 
   bundle.putInt("hicar.media.bundle.RESULT",0);
   bundle.putString("hicar.media.bundle.RATE_KEY", mPlayRate);
   mMediaSession.sendSessionEvent(action,bundle);
   ```
