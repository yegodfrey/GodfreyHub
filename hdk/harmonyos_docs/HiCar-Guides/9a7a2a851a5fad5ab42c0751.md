# 前台应用检测

## 场景说明

车机侧HMI应用对HiCar当前的打开应用缺乏实时感知，故通过在HiCar SDK中增加前台应用通知接口，使HMI应用能够实时获取HiCar当前打开应用的包名、类型。目前支持智慧桌面、融合桌面。典型场景如下：融合桌面可以在车机的原生Dock栏里面显示当前HiCar前台应用图标。
> 说明
>
> 推荐使用前台应用检测（dataType=537）接口，不再推荐使用前台娱乐应用检测（dataType=533）接口。

前台应用监听相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[前台应用检测](https://developer.huawei.com/consumer/cn/doc/HiCar-References/fore-app-0000002590160176)部分。

## 开发步骤

原车订阅前台应用变化，并通过向 HiCar 发送 537 消息来实现订阅与取消订阅，订阅前台应用变化：

```screen
{
    "action":"registerForegroundAppChange"
}
```

取消订阅：

```screen
{
    "action":"unregisterForegroundAppChange"
}
```

用户在HiCar上打开应用时，HiCar将应用类型、包名传给原车：

```screen
{
    "appPackageList": [
        {
            "appType": 1,
            "packageName": "com.huawei.hicar"
        }
    ]
}
```

字段参数说明：

|字段名|描述|
|:----------|:------------------------------------------------|
|packageName|应用包名|
|appType|应用类型： 0：未知类型 1：工具类型 2：地图类型 3、4：音乐类型 5：通话类型 6：娱乐类型|

当前台无应用打开时，更新如下消息给原车：

```screen
{
    "appPackageList": []
}
```
