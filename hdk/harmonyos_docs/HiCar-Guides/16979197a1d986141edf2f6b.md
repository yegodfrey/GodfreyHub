# 提交验收测试预约

1. 在完成验收测试准备后，请申请方再次登录[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)。
2. 在"自测试"节点、上传自测试报告及测试用例的日志、录屏和截图等文件。

   需上传的材料包括：
   * 《HUAWEI HiCar汽车接入验收自测试报告》，其中自测试用例必须100%通过。
   * 表格中"测试用例"页签对应测试用例的日志、录屏和截图等。如文件较大，可与测试机构沟通，采用云盘等方式提交材料。
