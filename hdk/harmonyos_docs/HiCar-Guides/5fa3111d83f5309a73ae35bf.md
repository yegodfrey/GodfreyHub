# 上市

华为会在车机设备完成HiCar验收测试后，在华为侧配置申请方授权信息，并将在华为官方渠道露出支持HiCar的车型车款/车机等相关信息，所以需要申请方完成相关授权。

车企应及时反馈OTA升级/新产品上市时间，并在产品手册/官网/汽车门户网站的车型配置清单中露出HUAWEI HiCar功能，车企门店销售人员加入HiCar功能话术。

若申请方未完成相关授权或未完成上市准备工作，无法获得华为的商用许可。
