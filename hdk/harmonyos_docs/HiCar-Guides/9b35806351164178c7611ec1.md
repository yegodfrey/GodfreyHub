# 图标介绍

**规则 2-3 HUAWEI HiCar图标只能从最终规范文件中直接拷贝使用**。

HUAWEI HiCar logo是一个平衡的整体，其元素间的相对大小和位置是固定的，使用中不得改变其形状、结构和比例。
