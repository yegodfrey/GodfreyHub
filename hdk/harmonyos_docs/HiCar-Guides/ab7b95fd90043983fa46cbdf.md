# 使用通知弹框

## 场景说明

音频应用可以主动通过MediaSession.sendSessionEvent向HiCar发送通知弹框指令，从而向用户发送Dialog消息弹框。例如当用户处于非Wi-Fi环境下使用音频应用时，音频应用通过弹框进行流量消耗提醒。应用可以自行决定何时在车机屏幕中弹出弹框。

## 规范说明

音频应用在接入HiCar后，应针对以下场景根据HiCar定义的弹框样式及文字描述，正确设置通知弹框：

* 用户尝试播放付费/会员内容时，如果付费/会员内容无法播放，音频应用应通过弹框进行提示。详见[播放付费/会员内容](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/play-paid-content-0000001078467010)。
* 用户尝试使用流量播放音频内容时，音频应用应通过弹框进行流量使用提醒。流量提醒弹框相关约束如[表1](#ZH-CN_TOPIC_0000001120118675__table1620110123313)所示。
* 用户在无网状态尝试播放时，音频应用应通过弹框进行提示。无网络提醒弹框相关约束如[表2](#ZH-CN_TOPIC_0000001120118675__table7168183411252)所示。
* 用户在未登录状态尝试使用登录后才可使用的特性时，音频应用应通过弹框进行提示。登录提醒弹框相关约束如[表3](#ZH-CN_TOPIC_0000001120118675__table14787185312278)所示。

另外，如果音频应用在手机侧和HiCar车机侧同时弹框，当用户在某一端完成弹框确认后，音频应用需保证另一端弹框同步被处理。例如，音频应用在车机和手机上同时弹出了流量提示弹框，如果用户在手机上操作使得手机侧弹框取消，那么音频应用需要调用HiCar取消弹框指令，通知HiCar取消车机上的弹框。

## 接口说明

### 发起弹框

|接口|参数|参数类型|说明|
|:---------------------------------------------------------|:-----|:-----|:-----------------------------------------------------------------|
|MediaSession.sendSessionEvent(String action,Bundle extras)|action|String|弹框指令，取值为"hicar.media.action.DIALOG"。|
|MediaSession.sendSessionEvent(String action,Bundle extras)|extras|Bundle|弹框指令扩展参数，详见[表5](#ZH-CN_TOPIC_0000001120118675__table147451653233)。|
[**表4**发起弹框相关接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:------------------------------------------|:-----|:-------------------------------------------------------------------------------------------|
|hicar.media.bundle.DIALOG_ID|String|音频应用自定义的Dialog ID，用于对多个Dialog进行区分。|
|hicar.media.bundle.RESULT|int|执行结果： * 0：成功 * -1：因其它或未知原因失败|
|hicar.media.bundle.DIALOG_TITLE|String|Dialog标题。|
|hicar.media.bundle.DIALOG_CONTENT|String|Dialog内容。|
|hicar.media.bundle.DIALOG_LEFT_BUTTON_TEXT|String|Dialog左按钮文字。|
|hicar.media.bundle.DIALOG_LEFT_BUTTON_TYPE|String|Dialog左按钮类型： * "emphasize"：强调类型，蓝色背景白色文字。 * "warning"：告警类型，红色背景白色文字。 * 若不设置，则为默认类型，灰色背景白色文字。|
|hicar.media.bundle.DIALOG_RIGHT_BUTTON_TEXT|String|Dialog右按钮文字。 如果不设置，则只会有一个按钮，按钮文字及类型来自左按钮设置。|

## 开发步骤

1. 音频应用在需要弹框时，通过MediaSession.sendSessionEvent方法发起弹框。

   示例代码如下所示：

   ```screen
   // 创建dialog
   private Bundle createBundle() {
       Bundle bundle = new Bundle();
       bundle.putString("hicar.media.bundle.DIALOG_ID", "dialog_one");
       bundle.putInt("hicar.media.bundle.RESULT", 0);
       bundle.putString("hicar.media.bundle.DIALOG_TITLE", "消耗流量提醒");
       bundle.putString("hicar.media.bundle.DIALOG_CONTENT",
               "当前非Wi-Fi环境，继续播放会被运营商收取流量费用");
       bundle.putString("hicar.media.bundle.DIALOG_LEFT_BUTTON_TEXT", "继续播放");
       // emphasize代表强调按钮(蓝色按钮)，warning代表为告警按钮(红色按钮)，不设置代表默认按钮(灰色按钮)
       bundle.putString("hicar.media.bundle.DIALOG_LEFT_BUTTON_TYPE", "emphasize");
       bundle.putString("hicar.media.bundle.DIALOG_RIGHT_BUTTON_TEXT", "取消");
       return bundle;
   }

   // 告知HiCar需要弹出dialog
   mMediaSession.sendSessionEvent("hicar.media.action.DIALOG", createBundle());
   ```

2. 在onCustomAction方法中针对action入参识别弹框操作指令，根据用户点击进行业务处理。

   示例代码如下所示：

   ```screen
   // 当用户点击dialog的按钮后，需要应用自行处理相关逻辑
   @Override
   public void onCustomAction(String action, Bundle extras) {
   	super.onCustomAction(action, extras);
   	Log.i(TAG, "onCustomAction,action:" + action + " extras:" + extras);
   	Bundle bundle = new Bundle();
   	switch (action) {
   		case "hicar.media.action.DIALOG":
   			String dialogId = extras.getString("hicar.media.bundle.DIALOG_ID", "");
   			// 可以用switch-case区分不同类型的dialog进行不同的处理
   			if (!"dialog_one".equals(dialogId)) {
   				break;
   			}
   			String clickWhat = extras.getString("hicar.media.bundle.CLICK_WHAT", "");
   			switch (clickWhat) {
   				case "left":
   					mIsNeedDialog = false;
   					onPlay();
   					break;
   				case "right":
   					break;
   				default:
   					break;
   			}
   			break;
   	}
   }
   ```

3. 在用户未点击弹框按钮时，如果音频应用不再需要弹框，可以主动取消弹框。用户主动点击弹框按钮后，音频应用无需显式取消弹框，HiCar会自动关掉弹框。

   示例代码如下所示：

   ```screen
   // 创建取消弹框的bundle
   private Bundle createCancelBundle() {
       Bundle bundle = new Bundle();
       bundle.putString("hicar.media.bundle.DIALOG_ID", "dialog_one");
       bundle.putInt("hicar.media.bundle.RESULT", 0);
       bundle.putBoolean("hicar.media.bundle.IS_CANCEL", true);
       return bundle;
   }

   // 告知HiCar需要取消dialog
   mMediaSession.sendSessionEvent("hicar.media.action.DIALOG_CANCEL", createCancelBundle());
   ```
