# 车辆品牌图标

## 场景说明

**图1**车辆品牌图标示例   
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251030194822.57945188302382834321125257964702:50001231000000:2800:F71FF82B9AA8DC5546FF5655719B217953456F2AB3B2850D8C38F11D9D64A925.png "点击放大")

HiCar连接成功后，HiCar界面投屏到车机屏幕上进行显示，通过点击HiCar应用图标区的车辆品牌图标可返回到车机原始界面，此车辆品牌图标需要车机传递给手机HiCar App。

交互过程中详细数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[品牌图标](https://developer.huawei.com/consumer/cn/doc/HiCar-References/brand-icon-0000001199289933)部分。

## 开发步骤

1. HiCar连接成功后，手机HiCar App向车机发送请求报文（dataType=502），请求车辆品牌图标。车机将收到的数据内容如下：

   ```screen
   {
       "brandIconData":"PNG"
   }
   ```

2. 车机通过**onDataReceive** 方法，判断**dataType** 后可收到上述具体数据内容，准备完成车牌品牌图标数据后，通过**HiCarAdapter::sendCarData**接口上报数据。示例代码如下：

   ```screen
   public void onDataReceive(String s, int dataType, byte[] bytes) {
        try {
            int DATA_TYPE_BRAND_ICON_DATA = 502;
            //TODO:这里需要对上面收到的报文进行校验
            if (dataType == DATA_TYPE_BRAND_ICON_DATA) {
                //图片路径自行规划           
                byte[] pictureBytes = getPngBytes("/data/test.png");
                mHicarAdapter.sendCarData(DATA_TYPE_BRAND_ICON_DATA, pictureBytes);
            }
        } catch (Exception e) {
            Log.i(TAG, " error");
        }
    }
   // 将图片文件转换成字节流 
   private byte[] getPngBytes(String pictureFilePath) {
        try {
            FileInputStream fis = new FileInputStream(pictureFilePath); 
            ByteArrayOutputStream baos = new ByteArrayOutputStream();
            Bitmap bitmap = BitmapFactory.decodeStream(fis);
            bitmap.compress(Bitmap.CompressFormat.PNG, 100, baos);
            return baos.toByteArray();
        } catch (Exception ex) {
            Log.i(TAG, "get picture error");
            return null;
        }
    }
   ```

   > 说明
   >
   > 车辆品牌图标下方显示的车辆品牌文字信息，在SDK初始化时设置，详情请参考[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000030695)。
