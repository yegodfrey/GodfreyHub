# 横竖屏切换

## 场景说明

用户全屏视频或展开折叠屏后，手机视频流变为横屏状态。反之变为竖屏状态，针对此种屏幕宽高改变的，车机需监听resize事件，进行等比缩放。

## 接口说明

当前接口需监听546消息，参数包含两个字段：

* stateCode：值为1，表示手机屏幕宽高已改变。
* stateData：值为包含width和height两个参数的字符串，表示手机视频流变化后的宽高。

## 开发步骤

手机视频流宽高改变。

```screen
// 监听546消息，接收到手机上报的宽高后，resize窗口宽高
class HiCarListener implements Carlistener {
    @Override
    public void onDataReceive(String deviceId, int dataType, byte[] data) {
        switch (dataType) {
            case DeviceData.DATA_TYPE_SMALL_WINDOW_STATE: // 546
                JSONObject jsonData = CommonUtils.getJsonObject(data, dataType).orElse(null); // 将从手机接收的命令字符串转换为JSON数据
                int stateCode = jsonData.getInteger("stateCode");
                String stateData = jsonData.getString("stateData");
                if (stateCode == 1) {
                    JSONObject stateDataJson = JSON.parseObject(stateData);
                    int mPhoneWidth = stateDataJson.getInteger("width");
                    int mPhoneHeight = stateDataJson.getInteger("height");
                    // resize窗口宽高
                    resizePhoneWindow(mPhoneWidth, mPhoneHeight); // HMI实现此函数
                }
                break;
        }
    }
}
```
