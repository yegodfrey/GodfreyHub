# 生命周期维护

明确产品上市后的舆情和问题处理机制、软件升级维护机制。产品上市发布后，维护的方案如下：

* 涉及手机软件的问题，通常情况遵循HarmonyOS版本的升级策略和升级周期，特殊重大的问题特殊处理。
* 涉及车机ROM、华为SDK软件的问题，华为按照双方沟通计划更新SDK给车企，车企自行输出对应的车机ROM升级软件及升级计划。
