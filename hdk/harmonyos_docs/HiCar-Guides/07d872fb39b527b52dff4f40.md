# 获取文档

## 文档地址

设备接入的文档可通过以下两种方式在线浏览：

* 在本网站左侧目录，切换到"设备接入"版块，即可在线浏览。
* 访问[华为智能硬件合作伙伴平台](https://devicepartner.huawei.com/cn/)的文档中心，在页面右上角导航菜单中切换为"HiCar接入"，即可在线浏览。

两种方式获取的文档内容一致。

在本网站左侧目录，切换到"设备接入"版块，即可在线浏览。
