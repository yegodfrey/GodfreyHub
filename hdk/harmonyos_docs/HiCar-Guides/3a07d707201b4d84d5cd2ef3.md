# 开发高品质/空间音频

从HiCar Android SDK 6.0.0.100版本开始，HiCar新增支持高品质/空间音频能力，支持将手机高品质/多声道音频投音到车机播放。
> 说明
>
> 高品质/空间音频是在HiCar互联场景之上，开放的新扩展能力，所以厂商在集成该特性之前，需要按照前文章节完成HiCar的功能集成。

## 功能介绍

高品质音频（High-Resolution Audio）是指超越 CD 标准（16-bit/44.1kHz）的音频采样率和位深度（采样率通常为 96kHz 或 192kHz、位深通常为24 bit）,能够还原录音室级别的细节与原音。

空间音频（Spatial Audio）是一种模拟真实声学环境的音频技术，能让用户感觉声音来自不同的方向、距离甚至高度，营造出"身临其境"的听觉体验。

HiCar支持将手机侧空间音频/多声道音频投音到车机播放，充分利用汽车的多扬声器资源，可让用户全身心地沉浸其中。

## 开发步骤

1. 车机需要在HiCar的配置文件中（hicar_config.json或hicar.properties）配置车机支持的音频能力。

   在配置文件中新增AudioCapability数组，数组的参数如下表，**车机需根据自身支持的音频能力进行选配**。

   |参数|说明|取值范围|备注|
   |:------------|:------------|:-----------------------------------------------------------------------------------------------------------|:-------------------------------------------|
   |sampleRate|音频采样率|* 48000：48K * 96000：96K * 192000：192K|NA|
   |sampleDepth|位宽（采样深度）， bit|* 16：16bit * 24：24bit|NA|
   |channelLayout|声道布局|* 2：双声道 * 51：5.1 side 声道 * 510：5.1 back声道 * 512：5.1.2声道 * 514：5.1.4声道 * 71：7.1声道 * 712：7.1.2声道 * 714：7.1.4声道|1. 只有48kHz采样率才支持多声道，其他采样率只支持双声道。 2. 暂不支持杜比音。|
   [**表1**参数说明]

   hicar_config.json配置文件配置参考如下, 在CarConfig中新增AudioCapability数组, 数组需根据车机的音频能力进行选配，请勿直接复制使用。

   ```screen
   {"CarConfig": {
       "ModelId": "00010001",   
       ... 
   "audioCapability": [
   { sampleRate: 48000, sampleDepth: 16, channelLayout: 2 },
   { sampleRate: 48000, sampleDepth: 16, channelLayout: 51 },
   { sampleRate: 48000, sampleDepth: 16, channelLayout: 512 },
   { sampleRate: 48000, sampleDepth: 16, channelLayout: 514 },
   { sampleRate: 48000, sampleDepth: 16, channelLayout: 714 },
   { sampleRate: 48000, sampleDepth: 24, channelLayout: 714 },
   { sampleRate: 96000, sampleDepth: 16, channelLayout: 2 },
   { sampleRate: 192000, sampleDepth: 16, channelLayout: 2 }
   ]
   }}
   ```

   hicar.properties配置文件配置参考如下所示。新增AudioCapability数组，数组需根据车机的音频能力进行选配，请勿直接复制使用。

   ```screen
   ModelId=00010001
   ScreenWidth=1920
   ScreenHeight=720
   ScreenSize=10.4
   DefaultBitrate=5000000
   MaxBitrate=10000000
   MinBitrate=500000
   DefaultAudioFormat=0
   AudioCapability=[{"sampleRate":48000,"sampleDepth":16,"channelLayout":2},{"sampleRate":48000,"sampleDepth":16,"channelLayout":512},{"sampleRate":48000,"sampleDepth":16,"channelLayout":714},{"sampleRate":48000,"sampleDepth":24,"channelLayout":714},
   {"sampleRate":96000,"sampleDepth":16,"channelLayout":2},{"sampleRate":192000,"sampleDepth":16,"channelLayout":2}]
   ```

2. HMI代码中设置CarConfig时读取配置文件里的AudioCapability 配置，并设置到CarConfig.Builder中，示例代码如下所示：

   ```screen
   private static final String KEY_AUDIO_CAPABILITY = "AudioCapability";
   ......
   try {
       JSONArray capabilities= carConfigObject.getJSONArray(KEY_AUDIO_CAPABILITY);
       if (capabilities == null) {
           return;
       }
       List<AudioCap> list = JSONArray.parseArray(capabilities.toJSONString(), AudioCap.class);
       if (list == null || list.isEmpty()) {
           return;
       }
       builder.withAudioCaps(list);
   } catch (JSONException e) {
       DeviceLogUtils.error(TAG, "parseAudioCapabilitySet JSONException： " + e.getMessage());
   }
   ```

3. 车机配置好声道路由后，连接HiCar，并在华为音乐播放界面点击封面上的空间音频按钮或超高清按钮，车机就可以播放高品质/空间音频了。
