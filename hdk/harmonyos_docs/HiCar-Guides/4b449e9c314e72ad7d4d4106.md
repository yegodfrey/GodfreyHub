# 通知日志区可写状态

## 场景说明

厂商HMI应用在初始化SDK后，在日志区可写状态Ready或者变化的时候，发送消息通知SDK，SDK才会将日志落盘到文件，否则一直维护在内存中，不会写到文件。

该接口主要针对车机日志存储区是在SD/TF卡的场景，防止在存储卡还未准备好前开始写日志。非SD/TF卡的场景，在SDK初始化完成后，直接发送该消息即可。

## 接口说明

|头文件|方法|说明|
|:------|:-------------|:--------------------------------------------------------------------------------------------------------|
|hicar.h|HiCarPostEvent|向HiCar SDK发送日志区是否可写状态。接口入参中的CarEventType为HICAR_EVENT_LOG_SECTION_CHANGE，content内容分为： * 1：日志区可写 * 0：日志区不可写|
[**表1**发送消息事件接口]

## 开发步骤

1. 当日志区可用时，厂商HMI应用通过HiCarPostEvent通知HiCar SDK日志可以落盘。

   ```screen
   uint32_t status = 1
   HiCarPostEvent(handle, HICAR_EVENT_LOG_SECTION_CHANGE, (char*)&status, sizeof(status));
   ```

2. 当日志区状态发生变化，变为不可用时，厂商HMI应用通过HiCarPostEvent通知HiCar SDK停止落盘。

   ```screen
   uint32_t status = 0
   HiCarPostEvent(handle, HICAR_EVENT_LOG_SECTION_CHANGE, (char*)&status, sizeof(status))
   ```
