# 配置BR

## 场景说明

HiCar无线连接需要使用BR通道。在手机扫描到BLE广播后弹窗提示用户，用户点击连接后触发连接流程（手机侧扫描到BLE广播后，会触发了BR连接，此时手机侧会主动发起BR连接，开启设备发现连接流程）。

## 接口说明

厂商需实现HiCar SDK包中设备接口（driver_adapt.h）的FcDriverAdaptOps类型变量以及其中的部分接口。

FcDriverAdaptOps变量中必须实现的接口如[表1](#ZH-CN_TOPIC_0000001056814267__table1412554713555)所示。

|结构体|结构体成员名称|说明|
|:---------------|:----------------------|:----------------------------------------------------------------------------|
|FcDriverAdaptOps|name|BR driver名称，必须填写为BR_DRIVER_NAME。|
|FcDriverAdaptOps|desc|BR设备接口描述，厂商可根据需要自行填写，例如"br driver"。|
|FcDriverAdaptOps|Init|BR driver初始化接口，HiCar SDK在使用其他BR接口前，首先会调用该接口进行初始化。该接口需保证协议栈正常启动，且为以下接口的调用做好准备。|
|FcDriverAdaptOps|Deinit|BR driver去初始化接口，释放相关资源。|
|FcDriverAdaptOps|SetParam|HiCar SDK调用该接口设置BR相关参数给厂商。设置的参数包括service uuid和sessionId的对应关系。|
|FcDriverAdaptOps|GetParam|HiCar SDK会调用该接口获取BR的mac地址和数据通道的channel Id。|
|FcDriverAdaptOps|Connect|车机自动连接手机时调用，根据sessionId连接对端手机。|
|FcDriverAdaptOps|Disconnect|关闭指定的BR通道，释放通道占用的相关资源。|
|FcDriverAdaptOps|SendData|HiCar SDK调用，通过BR通道发送数据到手机侧。|
|FcDriverAdaptOps|RegisterChannelCallback|BR driver调用此函数用来保存HiCar SDK注册的应用接口。|
[**表1**FcDriverAdaptOps结构体]

FcDriverAdaptOps类型的变量实现方式请参考HiCar SDK包中BR demo代码（driver_br.c），其中须注意，变量名称必须为"g_fcDriverBrOps"。

HiCar SDK会按照以下顺序调用厂商实现的接口：

1. 首次无线连接场景：
   1. 调用Init函数，实现BR driver初始化。
   2. 调用SetParam函数设置会话和serviceUuid的对应关系。
   3. 调用GetParam函数，获取车机BR的mac地址。
   4. 进行数据交互时，调用SendData函数将数据发送到对端手机的BR服务。
   5. 在退出Nearby服务时，调用Deinit函数实现BR driver资源的释放。
2. 自动连接场景：
   1. 调用Init函数，实现BR driver初始化。
   2. 调用SetParam设置会话和serviceUuid的对应关系。
   3. 调用Connect连接手机侧BR服务。
   4. 进行数据交互时，调用SendData函数将数据发送到对端手机的BR服务。
   5. 在退出Nearby服务时，调用Deinit函数实现BR driver资源的释放。

## 开发步骤

1. 实现BR初始化接口Init，保证BR协议栈正常启动。
2. 实现BR去初始化接口Deinit，保证释放BR driver相关资源。
3. 实现设置BR参数接口SetParam。

   当paramType为SET_BR_UUID值时，以类型为ServiceUuidRelatedSessionId指针来接收paramValue。实现需要保存ServiceUuidRelatedSessionId结构体成员serviceUuid和sessionId的对应关系，并且进行侦听serviceUuid，当serviceUuid对应的通道状态发生变化时，调用HiCar SDK提供的通道状态回调函数ChannelStateChange。当接收到手机发送的数据时，可以调用HiCar SDK提供的数据接收回调函数ReceiveData上报给HiCar SDK进一步处理。

   示例代码如下所示：

   ```screen
   /*
    * @function   : BrSetParam
    * @brief      : 设置BR参数，BR需要适配 SET_BR_UUID
    * @param[IN]  : paramType 参照SetParamsType
    * @param[IN]  : context,设置paramType对应的值
    * @return     : 0 成功，非0 失败
    */
   static int BrSetParam(SetParamsType paramType, const void *context)
   {
       printf("BrSetParam[in] paramType:%d.\r\n", paramType);
       if (context == NULL) {
           printf("BrSetParam[in] input param is invalid. paramType:%d\r\n.", paramType);
           return RESULT_RET_ERROR;
       }

       if (paramType == SET_BR_UUID) {
           // 注册 service uuid，记录这种映射关系，后面统一用session Id 来管理通道.
           ServiceUuidRelatedSessionId *serviceUuid2SessionId = (ServiceUuidRelatedSessionId *)context;
           char serviceUuid[BT_SERVICE_UUID_LEN + 1] = {0};
           (void)strncpy(serviceUuid,
               serviceUuid2SessionId->serviceUuid,
               BT_SERVICE_UUID_LEN);  // (void)strcpy_s(serviceUuid, BT_SERVICE_UUID_LEN + 1,
                                      // serviceUuid2SessionId->serviceUuid);

           int sessionId = serviceUuid2SessionId->sessionId;
           printf("BrSetParam[in] paramType:SET_BR_UUID, sessionId:%d, serviceuuid:%s.\r\n", sessionId, serviceUuid);

           // 监听BR service uuid.

       } else {
           printf("BrSetParam[in] unknown paramType:%d.\r\n", paramType);
           return RESULT_RET_ERROR;
       }

       return RESULT_RET_OK;
   }
   ```

4. 实现获取设备参数的接口GetParam。

   只需要适配当paramType为GET_DEV_MAC和GET_MAP_PORT的情况：
   * GET_DEV_MAC时，获取车机BR的mac地址，此时paramValue的类型为MacParam，厂商进行返回mac值。
   * GET_MAP_PORT时，需要按ServiceUuidMapPort类型解析入参result，在ServiceUuidMapPort类型数据中会带有char *类型的蓝牙服务UUID，厂商需要根据该UUID到蓝牙协议栈查询该服务对应的端口（也称为channelId），channelId为int类型，其值应大于0，直接赋值到ServiceUuidMapPort->port即可。

   示例代码如下所示：

   ```screen
   /*
    * @function   : BrGetParam
    * @brief      : 获取BR参数信息，BR需要适配 GET_DEV_MAC 和 GET_MAP_PORT
    * @param[IN]  : paramType 参考GetParamsType
    * @param[out] : result,获取的参数值
    * @return     : 0 成功，非0 失败
    */
   static int BrGetParam(GetParamsType paramType, void *result)
   {
       printf("BrGetParam[in], paramType:%d.\r\n", paramType);
       if (result == NULL) {
           printf("BrGetParam[in] paramType is invalid. paramType:%d.\r\n", paramType);
           return RESULT_RET_ERROR;
       }

       if (paramType == GET_DEV_MAC) {
           // get device mac
           MacParam *macParam = (MacParam *)result;
           // 注意：MAC地址需要大写
           char macSrc[STR_MAC_ADDR_LEN + 1] = "12:34:56:78:9A:1F";
           (void)strncpy(macParam->mac, macSrc, macParam->len);  // strcpy_s(macParam->mac, macParam->len, macSrc);
           printf("BrGetParam[in], paramType:GET_DEV_MAC, get br mac:%s.\r\n", macParam->mac);
       } else if (paramType == GET_MAP_PORT) {
           // get service uuid map port
           ServiceUuidMapPort *uuid2Port = (ServiceUuidMapPort *)result;
           char serviceUuid[BT_SERVICE_UUID_LEN + 1] = {0};
           (void)strncpy(serviceUuid,
               uuid2Port->serviceUuid,
               BT_SERVICE_UUID_LEN);  // (void)strcpy_s(serviceUuid, BT_SERVICE_UUID_LEN + 1, uuid2Port->serviceUuid);

           uuid2Port->port = 4;  // 需要从协议栈去好获取BR service uuid映射的端口(也称为channelId)
           printf("BrGetParam[in], paramType:GET_MAP_PORT, get map port:%d.\r\n", uuid2Port->port);
       } else {
           printf("BrGetParam[in], unknown paramType:%d.\r\n", paramType);
           return RESULT_RET_ERROR;
       }

       return RESULT_RET_OK;
   }
   ```

5. 实现注册回调接口RegisterChannelCallback。

   参数channelCallback的类型为ChannelCallback，是HiCar SDK传入参数，是BR连接过程中会调用到的接口，将BR的一些状态变化和接收到的数据通过这些接口上传到HiCar SDK。BR driver只会调用到channelCallback参数中的两个函数指针：
   1. ChannelStateChange（BR通道状态发生变化时调用）。调用此函数时，需要传入的参数：第一个参数类型为BrChannelData，需要提供sessionId（获取方式见步骤3）；第二个参数类型为EventType， 表示通道的状态，只有二种状态：EVENT_CONNECT（通道建立成功）和EVENT_DISCONNECT（断开通道连接）。
   2. ReceiveData（BR driver上传蓝牙数据到HiCar SDK时调用）。当蓝牙协议栈收到对端的数据时，调用此函数，需要传入四个参数，第一个参数必须为CHANNEL_BREDR，第二个参数类型是BrChannelData，需要提供sessionId；第三个参数为上传数据，第四个参数为上传数据长度。

6. 实现连接接口Connect。

   使用类型BrChannelData接收参数channelInfo。此接口只会在车机回连手机时调用，根据参数中的sessionId和MAC地址连接对端设备。

7. 实现关闭连接接口Disconnect。

   以类型BrChannelData接收参数channelInfo，关闭参数中sessionId指定的BR通道，释放其相关资源。

8. 实现发送数据接口SendData。

   参数data是需要发送到手机侧的数据，dataLen为发送数据的长度（单位：字节），数据在参数channelInfo（参数类型：BrChannelData）指定sessionId，厂商需根据sessionId找到对应的蓝牙UUID（映射关系见步骤3），将数据发送到对端。

   示例代码如下所示：

   ```screen
   /*
    * @function   : BrSendData
    * @brief      : 利用Br接口发送数据
    * @param[IN]  : data, 待发送数据
    * @param[IN]  : dataLen, 待发送数据的长度
    * @param[IN]  : context 通道数据结构参见BrChannelData
    * @return     : 0 成功，非0 失败
    */
   static int BrSendData(const unsigned char *data, int dataLen, const void *context)
   {
       if ((data == NULL) || (dataLen <= 0) || (context == NULL)) {
           printf("BrSendData[in] input is invalid.\r\n");
           return RESULT_RET_ERROR;
       }

       BrChannelData *channelInfo = (BrChannelData *)context;
       // 根据不同的session id,对应不同的通道发送数据。
       printf("BrSendData[in] sessionId:%d, remoteMac:%s.\r\n", channelInfo->sessionId, channelInfo->remoteMac);

       return RESULT_RET_OK;
   }
   ```
