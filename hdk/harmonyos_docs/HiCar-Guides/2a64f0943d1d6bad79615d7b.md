# 桌面类型设置

**规则10-1** **为了让用户非首次连接可以切换桌面类型，需要在原生车机界面增加桌面选择功能（单选），具体配置数量根据实际支持类型呈现，手机桌面形态下三种桌面类型只能三选一**。

为了便于用户理解，需要增加图文解释：

* 智慧桌面：手机应用与服务以全屏桌面呈现。
* 融合桌面：手机应用与车机应用融合呈现。
* 手机桌面：手机在车机界面以镜像呈现。

**建议：**功能放在原生车机系统设置或其他HUAWEI HiCar相关的页面，具体位置和形态以车企落地结果为准。
