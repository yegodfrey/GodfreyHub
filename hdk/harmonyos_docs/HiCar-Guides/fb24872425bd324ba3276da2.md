# 深浅模式

## 场景说明

当汽车传感器具备深浅模式探测能力时，HiCar App可以基于此能力进行深浅模式的切换。

车机上电启动后，需要调用HiCar SDK提供的接口上报是否支持深浅模式检测及当前所处的模式，后续在模式发生变化时主动向HiCar App上报最新的模式。

深浅模式相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[深浅模式](https://developer.huawei.com/consumer/cn/doc/HiCar-References/day-night-mode-0000001199289931)部分。

## SDK初始化时设置深浅模式

SDK初始化时，车机可以通过InitialConfig设置深浅模式，具体请参考[初始化SDK](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/initialize-sdk-0000000000030695)。

## 车机主动向HiCar App上报深浅模式

当车机检测到深浅模式发生变化时，需要通过**HiCarAdapter::sendCarData**接口主动向HiCar App上报当前所处的模式。上报浅色模式的报文示例如下所示：

```screen
{
    "dayNightMode":"day"
}
```
