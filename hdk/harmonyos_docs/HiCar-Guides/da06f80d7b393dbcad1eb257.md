# 启用SDK无线连接功能

只有当HiCar SDK的无线连接功能被启用时，厂商HMI应用才可以正常调用接口发送BLE广播进行无线连接。

SDK初始化启用无线连接功能的示例代码如下所示：

```screen
// 在初始化时设置是否支持无线连接，具体设置值请参见API参考文档
CarConfig config;
Config.connectInfo.connectAllowType = 0x1; // 仅支持无线连接时的设置
```
