# 更新播放速率

## 场景说明

用户在播放页通过播放速率按钮进行速率切换时，音频应用会收到播放速率变化指令，音频应用应变更当前播放速率，并将结果告知HiCar。

## 接口说明

### 获取播放速率变化指令

|接口|参数|参数类型|说明|
|:----------------------------------------------------------------|:-----|:-----|:-----------------------------------------------------------------------|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|action|String|播放速率变化指令，取值为"hicar.media.action.PLAY_RATE_CHANGE"。|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|extras|Bundle|播放速率变化指令中扩展参数，详见[表2](#ZH-CN_TOPIC_0000001078307034__table2171511174019)。|
[**表1**获取播放速率变化指令接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:---------------------------|:-----|:-------------------------------------------------------------------------------------------|
|hicar.media.bundle.PLAY_RATE|int|切换后新的播放速率： * 0：0.75倍速 * 1：1倍速 * 2：1.5倍速|
|hicar.media.bundle.RATE_KEY|String|自定义播放速率场景下，音频应用可以通过该参数获取本次计划切换的目的播放速率。 播放速率来自音频应用前期通过hicar.media.bundle.PLAY_RATE_LIST设置的内容。|
[**表2**播放速率变化指令中扩展参数说明]

### 响应播放速率变化指令

|接口|参数|参数类型|说明|
|:---------------------------------------------------------|:-----|:-----|:---------------------------------------------------------------------|
|MediaSession.sendSessionEvent(String action,Bundle extras)|action|String|播放速率变化指令，取值为"hicar.media.action.PLAY_RATE_CHANGE"。|
|MediaSession.sendSessionEvent(String action,Bundle extras)|extras|Bundle|播放速率变化指令响应参数，详见[表4](#ZH-CN_TOPIC_0000001078307034__table622171116408)。|
[**表3**播放速率变化响应接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:---------------------------|:-----|:------------------------------------------------------|
|hicar.media.bundle.RESULT|int|执行结果： * 0：成功 * -1：因其它或未知原因失败|
|hicar.media.bundle.PLAY_RATE|int|切换后新的播放速率： * 0：0.75倍速 * 1：1倍速 * 2：1.5倍速 自定义播放速率场景忽略该参数。|
|hicar.media.bundle.RATE_KEY|String|自定义播放速率场景下，切换后新的播放速率。|
[**表4**播放速率变化指令响应参数说明]

## 开发步骤

1. 音频应用在onCustomAction方法中针对action入参识别播放速率变化指令。

   示例代码如下所示：

   ```screen
   private int mPlayrate = 0;

   @Overrride
   public void onCustomAction(@NonNull String action,@Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       switch(action){
           case "hicar.media.action.PLAY_RATE_CHANGE":
               //执行播放速率变化任务

               break;
           default:
               break;
       }
   }
   ```

2. 音频应用需自行处理播放速率的变化，在完成后告知HiCar执行结果。

   示例代码如下所示：

   ```screen
   private int mPlayrate = 0;

   @Overrride
   public void onCustomAction(@NonNull String action,@Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       switch(action){
           case "hicar.media.action.PLAY_RATE_CHANGE":
               //执行播放速率变化任务
               bundle = new Bundle();
               //播放速率参数定义（0：0.75倍速，1：1倍速，2：1.5倍速）
               mPlayrate = (mPlayrate + 1)%3;
               //返回播放速率切换结果并把当前正在播放的速率信息传给HiCar
               bundle.putInt("hicar.media.bundle.RESULT",0);
   bundle.putInt("hicar.media.bundle.PLAY_RATE",mPlayrate);
   bundle.putString("hicar.media.bundle.PLAY_KEY","0.75X");//自定义模式和原有模式二选一来实现
   mMediaSession.sendSessionEvent(action,bundle);
   Log.i(TAG,"onCustomAction,"+action+"playRate:"+mPlayrate);
               break;
           default:
               break;
       }
   }
   ```
