# 蓝牙通话

## 场景说明

HiCar建议厂商HMI应用通过HiCar通道处理运营商通话和VoIP通话，但HiCar在处理运营商通话和VoIP通话时，会触发蓝牙SCO连接，可能导致通话无声、蓝牙通话界面异常覆盖等问题，同时对厂商在通话回声抑制方面提出了较高的要求。

如厂商在处理虚拟通话的回声抑制方面存在困难，或遇到通话无声等问题时，可以考虑采用蓝牙通话的方式处理HiCar虚拟通话。

## 开发步骤

当虚拟电话发起时，手机会将相关通话数据通过蓝牙HFP通道发送到车机，厂商按照蓝牙HFP通话流程处理即可。

如果厂商之前采用的是在HiCar连接成功后禁用HFP的方式，规避相关问题，此时可以按照如下思路进行调整：

1. 在HiCar连接成功后，不再断开HFP，仅断开A2DP即可。当HiCar连接时，车机蓝牙通话来电等界面请勿遮挡集成HiCar的厂商HMI应用界面。
2. 在HiCar断开后，恢复A2DP连接。

当HiCar App向车机查询是否支持Modem虚拟通话时，直接返回不支持，便于手机侧关闭虚拟通话功能。具体内容请参见[虚拟通话](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/virtual-call-0000001212227824)。
