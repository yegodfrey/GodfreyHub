# 更新收藏状态

## 场景说明

用户在播放页通过收藏按钮进行收藏或者取消收藏时，音频应用会收到收藏状态变化指令，音频应用应变更当前曲目的收藏状态，并将结果告知HiCar。

## 接口说明

### 获取收藏状态变化指令

|接口|参数|参数类型|说明|
|:----------------------------------------------------------------|:-----|:-----|:----------------------------------------------------------------------|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|action|String|收藏状态变化指令，取值为"hicar.media.action.FAVORITE_STATE_CHANGE"。|
|MediaSession.Callback.onCustomAction(String action,Bundle extras)|extras|Bundle|收藏状态变化指令中扩展参数，详见[表2](#ZH-CN_TOPIC_0000001119983203__table782710071818)。|
[**表1**收藏状态变化指令接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:----------------------------|:-----|:--------------------------|
|hicar.media.bundle.REQUEST_ID|String|本次操作的requestId，由HiCar生成并下发。|
|hicar.media.bundle.MEDIA_ID|String|收藏状态发生变化的曲目Media ID。|
[**表2**收藏状态变化指令中扩展参数说明]

### 响应收藏状态变化指令

音频应用在收到曲目收藏状态变化指令后，需通过MediaSession.setMetadata方法更新MediaMetadata对象中的hicar.media.metadata.FAVORITE_STATE属性更新曲目的收藏状态，详情可参见前文[更新播放曲目](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/update-song-0000001078467008)。

同时，音频应用还需要通过MediaSession.sendSessionEvent方法返回变更后的收藏状态，便于HiCar进行语音播报。

|接口|参数|参数类型|说明|
|:---------------------------------------------------------|:-----|:-----|:---------------------------------------------------------------------|
|MediaSession.sendSessionEvent(String action,Bundle extras)|action|String|收藏状态变化指令，取值为"hicar.media.action.FAVORITE_STATE_CHANGE"。|
|MediaSession.sendSessionEvent(String action,Bundle extras)|extras|Bundle|收藏状态变化指令响应参数，详见[表4](#ZH-CN_TOPIC_0000001119983203__table573215409478)。|
[**表3**收藏状态变化响应接口及参数说明]

|Bundle参数Key|参数类型|说明|
|:--------------------------------|:-----|:---------------------------------|
|hicar.media.bundle.RESULT|int|执行结果： * 0：成功 * -1：因其它或未知原因失败|
|hicar.media.bundle.REQUEST_ID|String|本次下发的requestId需要在此处返回。|
|hicar.media.bundle.MEDIA_ID|String|收藏状态发生变化的曲目Media ID。|
|hicar.media.bundle.FAVORITE_STATE|String|变更后的收藏状态。 曲目的收藏状态： * 0：未收藏 * 1：已收藏|
[**表4**收藏状态变化指令响应参数说明]

## 开发步骤

1. 音频应用在onCustomAction方法中针对action入参识别收藏状态变化指令。

   示例代码如下所示：

   ```screen
   @Overrride
   public void onCustomAction(@NonNull String action, @Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       switch(action){
           case "hicar.media.action.FAVORITE_STATE_CHANGE":
               //这里音频应用需要处理某一首曲目或列表的收藏信息变化
               
           default:
               break;
       }
   }
   ```

2. 音频应用需自行处理曲目收藏状态的变化，在完成后告知HiCar执行结果。

   示例代码如下所示：

   ```screen
   @Overrride
   public void onCustomAction(@NonNull String action, @Nullable Bundle extras){
       super.onCustomAction(action,extras);
       Bundle bundle;
       String requestId;
       switch(action){
           case "hicar.media.action.FAVORITE_STATE_CHANGE":
               requestId = extras.getString("hicar.media.bundle.REQUEST_ID");
               //这里音频应用需要处理某一首曲目或列表的收藏信息变化
               bundle = new Bundle();
   //首先需要先从Bundle中获取对应的曲目ID或列表ID
   String mediaId = extras.getString("hicar.media.bundle.MEDIA_ID");

   //处理曲目或列表收藏信息发生变化的业务
   ......

   //音频应用需要更新当前的音频信息即Metadata数据
   mMediaSession.setMetadata(genMetadata(mediaId));
   Log.i(TAG,"onCustomAction,"+action+"favoriteState:"+favoriteState+"mediaId:"+mediaId);

               bundle.putInt("hicar.media.bundle.RESULT",0);
               bundle.putString("hicar.media.bundle.REQUEST_ID", requestId);
               bundle.putString("hicar.media.bundle.MEDIA_ID", mediaId);
               bundle.putString("hicar.media.bundle.FAVORITE_STATE", "1");
               mMediaSession.sendSessionEvent(action, bundle);

               break;
           default:
               break;
       }
   }
   ```
