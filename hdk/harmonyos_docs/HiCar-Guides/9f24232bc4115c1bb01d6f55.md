# 自测试

## 自测试说明

申请方在预约验收测试之前必须按照《HUAWEI HiCar汽车接入验收自测试报告》进行自测试，只有在自测试用例100%通过后，才可以预约验收测试。

> 说明
>
> * HiCar验收测试组不提供验收测试手机，申请方可按照如下说明准备验收测试手机：自测试需使用华为当前年度或者前一年度发布的最新Mate/P系列商用手机，同时需要在手机的[设置]-[系统和更新]中把EMUI、HarmonyOS升级到最新版本。例如验收自测试的时间是2020年，可以选择P40系列（2020年3月发布）、Mate40系列（2020年10月发布）。
> * 华为提供手机兼容性保证，申请方无需进行全线品牌的华为手机测试，仅需参照上述原则选择1~2款手机进行自测试即可。
> * 针对测试无线非首次连接成功率场景，申请方需准备3部主流旗舰手机（覆盖2种主流芯片平台+3种主流ROM版本，如：HarmonyOS 4.2的海思/高通芯片手机各一款，HarmonyOS 5.0 的海思芯片手机一款）进行自测试。海思芯片手机推荐使用Mate60/Mate70/P70系列，高通芯片手机推荐使用P50/P60系列，后期如无高通芯片的华为新机发布，沿用推荐机型即可。
