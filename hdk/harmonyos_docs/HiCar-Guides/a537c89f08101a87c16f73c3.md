# 验收测试介绍

合作伙伴（以下简称申请方）在集成HUAWEI HiCar（以下简称HiCar）之后，在充分自测试的前提下，需向华为申请针对集成HiCar的车载设备进行验收测试。只有验收测试通过的产品才可以搭载HiCar功能上市销售。
> 说明
>
> 华为会根据实际情况不断优化验收测试流程及文档，如您在验收测试过程中有任何疑问，可向华为咨询，华为将负责解释。

## 总体原则

### 测试用例相关性

只执行所集成功能对应的验收测试用例，不涉及的功能无需执行相应的验收测试用例。

### 准入准出的绝对性

验收准入准出有明确的要求，不符合验收测试准入条件要求则不予以准入，详见"[提交验收测试预约](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/submit-appointment-0000001098476370)"，不符合验收测试准出条件则必然不允许准出。

### 给予验收测试申请方以信任

基于信任原则，由验收测试申请方先行进行自测试并提交自测试报告，测试机构再进行验收测试。

## 验收测试分类

HiCar将验收测试分为：首次验收测试和等效验收测试。

### 首次验收测试

新申请车型/车机首次申请HiCar验收测试。

### 等效验收测试

新申请车型和已通过HiCar验收测试的旧车型存在软硬件相关性，等效验收测试需要在首次验收测试已经完成的前提下进行。

等效验收测试典型场景：

* 新旧车型车机的软件相同，但硬件不同（若CPU不同则不允许申请等效验收测试）。如搭载同一平台车机的不同车型申请验收测试，首个车型申请首次验收测试并通过后，其他搭载同平台车机的车型可申请等效验收测试。
* 新旧车型车机的硬件相同，但软件不同（若车机操作系统不同则不允许申请等效验收测试）。如同一车型已经通过HiCar验收测试，升级车机侧软件后可重新申请HiCar等效验收测试。

### 验收测试分类界定参照

申请方在合作准入阶段填写《HUAWEI HiCar等效验收测试申请表》后提交到DevicePartner网站，由测试机构来评估是否满足等效验收 。

|车机平台|车型|车机软硬件变更情况|应申请的验收测试方式|
|:---|:--|:-------------------|:---------|
|新平台|新车型|全新软硬件。|**首次验收测试**|
|旧平台|新车型|软硬件部分变化/软硬件均不变。|**等效验收测试**|
|旧平台|旧车型|软件/功能升级，HiCar功能发生变化。|**等效验收测试**|
[**表1**首次验收测试与等效验收测试界定参照]

> 说明
>
> 申请方若申请等效验收测试，则需详细说明新旧车型、车机的具体差异，测试机构最终会根据《HUAWEI HiCar等效验收测试申请表》实际差异情况判断是否满足等效验收条件，并根据提交的差异信息调整验收测试内容。
