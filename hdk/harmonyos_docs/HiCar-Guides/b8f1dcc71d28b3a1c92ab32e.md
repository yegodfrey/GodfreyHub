# 车机蓝牙推荐使用HiCar

为了推荐用户使用手车互联功能，简化用户首次连接HiCar的步骤，车机可以在检测到连接手机蓝牙后，在车机界面中推荐用户使用HiCar。现增加**从车机侧发起推荐** 使用的交互流程，车机侧推荐优先级高于[手机侧推荐](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/bluetooth-hmi-app-0000001430747785)（建议厂商手机侧推荐、车机侧推荐中二选一进行实现）。

厂商可以按照如下步骤来实现车机蓝牙推荐功能：

1. 在HMI应用的AndroidManifest.xml文件中增加蓝牙权限。

   ```screen
   <uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />
   ```

2. 在连接上蓝牙设备之后，需要判断该设备是否华为手机。

   * 方案一（推荐）：先根据指定的Rfcomm连接判断是否为华为设备，再通过设备类型判断是否为手机设备，二者都满足则认为对端是支持HiCar的华为手机。示例代码如下所示：

     ```screen
     private static BluetoothSocket mCurSocket;
     public static void closeCurrentSocket() {
     	if (mCurSocket != null) {
     		try {
     			mCurSocket.close();
     		} catch (IOException e) {
     			e.printStackTrace();
     		}
     		mCurSocket = null;
     	}
     }
     // 入口：直接尝试通道连接，不做任何SDP查询
     public static boolean isHuaweiPhone(BluetoothDevice device) {
     	if (device == null || device.getBluetoothClass() == null) {
     		DeviceLogUtils.error(TAG, "not phone");
     		return false;
     	}
     	if (device.getBluetoothClass().getMajorDeviceClass() != 0X0200) {
     		DeviceLogUtils.error(TAG, "not phone");
     		return false;
     	}
     	BluetoothAdapter adapter = BluetoothAdapter.getDefaultAdapter();
     	if (adapter.isDiscovering()) {
     		adapter.cancelDiscovery();
     	}
     	try {
     		closeCurrentSocket();
     		// 核心：直接按通道创建RFCOMM socket，无SDP/UUID
     		mCurSocket = device.createRfcommSocketToServiceRecord(UUID.fromString("0000FE35-0000-1000-8000-00805F9B34FB"));
     		DeviceLogUtils.info(TAG, "尝试连接rfcomm:FE35");
     		// 阻塞连接，不支持RFCOMM会直接抛IOException
     		mCurSocket.connect();
     		// 连接成功，回调主线程
     		DeviceLogUtils.info(TAG, "尝试连接rfcomm成功");
     		closeCurrentSocket();
     	} catch (IOException e) {
     		DeviceLogUtils.info(TAG, "尝试连接rfcomm失败");
     		closeCurrentSocket();
     		return false;
     	}
     	return true;
     }
     ```

   * 方案**二** ：根据gatt连接发现设备信息服务列表FE35对比，然后再通过设备类型判断是否为手机，二者基本可判定对端是华为手机。示例代码如下所示：

     ```screen
     private static BluetoothGatt mBluetoothGatt;
     private static void releaseGatt() {
     	if (mBluetoothGatt != null) {
     		mBluetoothGatt.disconnect();
     		mBluetoothGatt.close();
     		mBluetoothGatt = null;
     	}
     }
     private static final BluetoothGattCallback gattCallback = new BluetoothGattCallback() {
     	@Override
     	public void onConnectionStateChange(BluetoothGatt gatt, int status, int newState) {
     		DeviceLogUtils.info(TAG, "onConnectionStateChange" + newState);
     		if (newState == BluetoothProfile.STATE_CONNECTED) {
     			gatt.discoverServices();
     		} else if (newState == BluetoothProfile.STATE_DISCONNECTED) {
     			releaseGatt();
     		}
     	}
     	@Override
     	public void onServicesDiscovered(BluetoothGatt gatt, int status) {
     		DeviceLogUtils.info(TAG, "onServicesDiscovered" + status);
     		if (status != BluetoothGatt.GATT_SUCCESS) return;
     		// 1. 遍历所有服务，判断是否存在FE35
     		for (BluetoothGattService service : gatt.getServices()) {
     			DeviceLogUtils.info(TAG, "uuid:" + service.getUuid().toString());
     			if (service.getUuid().toString().equalsIgnoreCase(FE35)) {
     				DeviceLogUtils.info(TAG, "find Fe35，isHuawei device");
     				return;
     			}
     		}
     		releaseGatt();
     	}
     };
     public static void detectHuaweiPhone(Context context, BluetoothDevice device) {
     	if (device == null || device.getBluetoothClass() == null) {
     		DeviceLogUtils.error(TAG, "device null");
     		return;
     	}
     	if (device.getBluetoothClass().getMajorDeviceClass() != 0X0200) {
     		DeviceLogUtils.error(TAG, "not phone");
     		return;
     	}
     	// 建立BLE GATT连接，纯系统原生链路，无自定义报文
     	closeGatt();
     	DeviceLogUtils.info(TAG, "detectBrand");
     	mBluetoothGatt = device.connectGatt(context, false, gattCallback);
     }
     ```
