# HiCar虚拟通话

## 场景说明

当HiCar连接上后，HiCar优先建议虚拟通话使用HiCar通道收发数据，为避免与原车HFP电话冲突，需要关闭车机蓝牙或者断开蓝牙HFP连接，在HiCar断开后再恢复。

HiCar SDK会在虚拟通话接通和挂断时，以事件通知的方式告知厂商HMI应用，HMI应用接收到对应的事件后，应对车机MIC设置回声消除、降噪等参数，避免通话过程中出现回声、杂音等问题。

## 接口说明

|接口|方法|说明|
|:----------|:------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|CarListener|DeviceServiceChange|HiCar SDK通过回调的方式向厂商HMI应用通知虚拟通话事件： * HICAR_DEVICE_VIRMODEM_CALLING（值为307）：运营商电话接通事件。HMI应用接收到此事件，需要通知车机MIC设置回声消除等参数，避免通话过程中出现回声。 * HICAR_DEVICE_VIRMODEM_HANGUP（值为308）：运营商电话挂断事件。HMI应用接收到此事件，可以将车机Mic设置恢复到正常状态。 * HICAR_DEVICE_VOIP_CALLING（值为309）：VoIP电话接通事件。HMI应用接收到此事件，需要通知车机Mic设置回声消除等参数，避免通话过程中出现回声。 * HICAR_DEVICE_VOIP_HANG_UP（值为310）：VoIP电话挂断事件。HMI应用接收到此事件，可以将车机Mic设置恢复到正常状态。|

## 开发步骤

运营商通话及VoIP通话事件示例代码如下所示：

```screen
void DeviceServiceChange(const char *serviceId, uint32_t idLen, int state) {
    LOGD("DeviceServiceChange, state:%d", state);
    switch (state) {
        case HICAR_DEVICE_VIRMODEM_CALLING: {  
            // 运营商通话接通，厂商HMI应用需做相应处理，比如开启回声抑制。
            break;
        }
        case HICAR_DEVICE_VIRMODEM_HANGUP: {  
            // 运营商通话挂断，厂商HMI应用需做相应处理。
            break;
        }
        case HICAR_DEVICE_VOIP_CALLING: {  
            // VoIP通话接通，厂商HMI应用需做相应处理，比如开启回声抑制。
            break;
        }
        case HICAR_DEVICE_VOIP_HANG_UP: {  
            // VoIP通话挂断，厂商HMI应用需做相应处理。
            break;
        }
        default: 
            break;
    }
}
```

## 处理通话冲突

HiCar App默认提供通话服务，可能会与车机通话功能（车载蓝牙通话、车机本地SIM卡通话等）产生冲突，所以为了避免通话冲突，车机需要将本地通话服务状态通知到HiCar。同时在HiCar App提供通话服务时，当用户按下方控按键，车机也需要根据HiCar App通话状态进行通话/挂断事件的上报，所以车机需要从HiCar App获取通话状态。

关于通话冲突相关的内容请参考[通话状态与焦点](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/call-status-and-focus-0000001052659461)。
