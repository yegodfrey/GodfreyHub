# 处理触屏事件

## 场景说明

在投屏过程中，厂商HMI应用需要识别用户的按键和触屏操作，并将对应的事件发送到HiCar SDK，便于控制投屏中的应用。

触屏事件支持单指触屏和多指触屏，当触屏事件发生后，厂商HMI应用需要将事件按照HiCar SDK的要求封装成对应的结构体，并通过HiCarPostEvent接口发送到HiCar SDK。

按键和旋钮相关的事件处理请参见[管理车机按键/旋钮/触摸板](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/physical-key-knob-0000000000105717)。

## 接口说明

|头文件|方法/结构体|说明|
|:---------------------|:-----------------------|:----------------------------------------------------------------------------|
|hicar.h|HiCarPostEvent|处理触屏事件时，接口入参中的CarEventType为HICAR_EVENT_REMOTE_CTRL，content为HwRemoteCtrlEvent。|
|HwRemoteControlEvent.h|HwRemoteCtrlEvent|事件相关结构体。在处理投屏事件时，涉及到的屏幕坐标为相对坐标，相对于投屏区域左上角的坐标。|
|HwRemoteControlEvent.h|HwRemoteCtrlHeader|事件相关结构体。在处理投屏事件时，涉及到的屏幕坐标为相对坐标，相对于投屏区域左上角的坐标。|
|HwRemoteControlEvent.h|HwRemoteCtrlEventType|事件相关结构体。在处理投屏事件时，涉及到的屏幕坐标为相对坐标，相对于投屏区域左上角的坐标。|
|HwRemoteControlEvent.h|HwRemoteCtrlEventDetails|事件相关结构体。在处理投屏事件时，涉及到的屏幕坐标为相对坐标，相对于投屏区域左上角的坐标。|

## 开发步骤

1. 当触屏事件发生后，厂商需要自行解析对应的事件。
2. 将事件转换，并填充到HwRemoteCtrlEvent结构体，调用HiCarPostEvent接口发送触摸事件。注意：一次完整的触屏事件需要包括DOWN事件和UP事件。

   示例代码如下所示：

   ```screen
   //  调用HiCarPostEvent接口，发送事件Event
   void SendTouchEvent()
   {
       if (g_hicarHandle == NULL) {
           printf("hicar handle null\n");
           return;
       }
       printf("SendTouchEvent start\n");
       HwRemoteCtrlEvent *obj = (HwRemoteCtrlEvent*)HiCarNewObject(g_hicarHandle, HICAR_OBJECT_REMOTE_CTRL, sizeof(HwRemoteCtrlEvent));
       if (obj != NULL) {
           printf("init HwRemoteCtrlEvent start\n");
           obj->header.version = 0;
           obj->header.dFlag = 1;
           obj->header.wFlag = 0;
           obj->header.wr1Flag = 0;
           obj->header.wr2Flag = 0;
           obj->header.rFlag = 0;
           obj->header.inputCategory = 0;
           obj->header.len = 10;
           obj->evtType = REMOTECTRL_TOUCH;
           obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_DOWN;
           obj->evtDetail.touchEvt.numPointers = 1;
           obj->evtDetail.touchEvt.pointerId[0] = 0;
           obj->evtDetail.touchEvt.coordinateX[0] = x;
           obj->evtDetail.touchEvt.coordinateY[0] = y;
           HiCarPostEvent(g_hicarHandle, HICAR_EVENT_REMOTE_CTRL, (char*)obj, sizeof(*obj));
       }
       printf("SendTouchEvent end\n");
       return;
   }
   ```

## 双指操作场景举例

这里对如何适配双指操作地图缩放进行说明。

1. 当第一个指头按下时，假设坐标是(x1,y1)，发送DOWN事件。

   ```screen
   // obj是HwRemoteCtrlEvent结构指针
   obj->evtType = REMOTECTRL_TOUCH;
   obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_DOWN;
   obj->evtDetail.touchEvt.numPointers = 1;
   obj->evtDetail.touchEvt.pointerId[0] = 0;
   obj->evtDetail.touchEvt.coordinateX[0] = x1;
   obj->evtDetail.touchEvt.coordinateY[0] = y1;
   ```

2. 第二个指头按下时，坐标是(x2,y2)，发送DOWN事件。

   ```screen
   // obj是HwRemoteCtrlEvent结构指针
   obj->evtType = REMOTECTRL_TOUCH;
   obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_DOWN;
   obj->evtDetail.touchEvt.numPointers = 2;
   obj->evtDetail.touchEvt.pointerId[0] = 0;
   obj->evtDetail.touchEvt.pointerId[1] = 1;
   obj->evtDetail.touchEvt.coordinateX[0] = x1;
   obj->evtDetail.touchEvt.coordinateY[0] = y1;
   obj->evtDetail.touchEvt.coordinateX[1] = x2;
   obj->evtDetail.touchEvt.coordinateY[1] = y2;
   ```

3. 两个指头同时移动，发送MOVE事件，两个点的坐标实时刷新。

   ```screen
   // obj是HwRemoteCtrlEvent结构指针
   obj->evtType = REMOTECTRL_TOUCH;
   obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_MOVE;
   obj->evtDetail.touchEvt.numPointers = 2;
   obj->evtDetail.touchEvt.pointerId[0] = 0;
   obj->evtDetail.touchEvt.pointerId[1] = 1;
   obj->evtDetail.touchEvt.coordinateX[0] = x1;
   obj->evtDetail.touchEvt.coordinateY[0] = y1;
   obj->evtDetail.touchEvt.coordinateX[1] = x2;
   obj->evtDetail.touchEvt.coordinateY[1] = y2;
   ```

4. 当第一个指头抬起时，假设坐标是(x2,y2)，发送UP事件。

   ```screen
   // obj是HwRemoteCtrlEvent结构指针
   obj->evtType = REMOTECTRL_TOUCH;
   obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_UP;
   obj->evtDetail.touchEvt.numPointers = 2;
   obj->evtDetail.touchEvt.pointerId[0] = 0;
   obj->evtDetail.touchEvt.pointerId[1] = 1;
   obj->evtDetail.touchEvt.coordinateX[0] = x1;
   obj->evtDetail.touchEvt.coordinateY[0] = y1;
   obj->evtDetail.touchEvt.coordinateX[1] = x2;
   obj->evtDetail.touchEvt.coordinateY[1] = y2;
   ```

5. 当第二个指头抬起时，坐标是(x1,y1)，发送UP事件。

   ```screen
   / obj是HwRemoteCtrlEvent结构指针
   obj->evtType = REMOTECTRL_TOUCH;
   obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_UP;
   obj->evtDetail.touchEvt.numPointers = 1;
   obj->evtDetail.touchEvt.pointerId[0] = 0;
   obj->evtDetail.touchEvt.coordinateX[0] = x1;
   obj->evtDetail.touchEvt.coordinateY[0] = y1;
   ```
