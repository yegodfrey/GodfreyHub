# 管理连接设备

## 场景说明

手机和车机认证连接后，车机需要保存已认证的设备信息，并提供连接认证管理界面，用于协助用户在车机上管理已认证的设备。

厂商HMI应用可以通过HiCar SDK提供的接口管理已认证的设备，包括获取已认证设备列表、删除已认证设备、断开设备连接、连接设备等，以及支持通过断开设备和连接设备实现切换连接功能。

## 接口说明

|类|方法|说明|
|:-----------|:-----------------|:-------------------------------------|
|HiCarAdapter|getTrustDeviceList|获取已认证设备列表，包含手机ID、手机名称、手机Mac地址、上一次连接时间。|
|HiCarAdapter|deleteTrustDevice|删除已认证的设备。|
|HiCarAdapter|disconnectDevice|断开指定设备连接。|
|HiCarAdapter|startReconnect|触发自动连接。|
[**表1**连接认证相关接口]

## 前提条件

使用startReconnect触发自动连接前，需开启HiCar SDK的自动连接功能，具体请参考[启用SDK自动连接功能](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/automatic-connection-0000000000030747#section20548163618129)。

## 开发步骤

1. 厂商需要完成连接认证管理界面的设计和开发。该界面中需要包含已认证的设备列表，用户可以选择指定的已认证设备并对其进行删除操作。
2. 厂商HMI应用可以通过HiCar SDK接口获取认证设备信息展示在认证管理界面中，并根据用户选择进行删除和断开操作。

   示例代码如下所示：

   ```screen
   //获取已认证设备列表
   List<TrustPhoneInfo> trustPhoneList = mHiCarAdapter.getTrustDeviceList();

   //删除已认证设备，设备ID从获取认证设备列表中获取
   mHiCarAdapter.deleteTrustDevice("xxxx");
    
   //断开设备连接，设备ID从获取认证设备列表中获取
   mHiCarAdapter.disconnectDevice("xxxx");
   ```

3. 当用户选择连接某个设备时，厂商HMI应用需调用HiCar SDK的"startReconnect(String macAddress, boolean isManualReconnect)"接口发起连接流程。

   发起回连的接口startReconnect存在不同参数个数的方法：
   * startReconnect(String macAddress)：自动连接方法，一般用于车辆启动上电后自动连接的场景。仅在手机侧HiCar App设置界面中"自动连接"开关处于打开状态时才可以连接。
   * startReconnect((String macAddress, boolean isManualReconnect)：自动连接方法，可以通过isManualReconnect设置是否是手动触发的连接。当isManualReconnect设置为true时，无论手机侧HiCar App设置界面中"自动连接"是否打开，都可以连接。

   在此处手动发起连接的场景下，请使用startReconnect(String macAddress, boolean isManualReconnect)接口发起连接流程，并设置isManualReconnect参数为true。

4. （Beta）实现连接切换管理。当前HiCar并不支持多部手机同时与车机进行HiCar连接，但厂商可以在多部手机中切换到某一部与车机建立HiCar连接。

   > 说明
   >
   > 不支持在通过USB有线方式连接车机的多部手机中，切换HiCar连接。第一部手机成功建立HiCar有线连接后，后续手机仅能通过USB端口进行充电操作。

   针对无线连接场景，当驾驶环境中存在多部支持HiCar的手机时，厂商HMI应用可以在多部手机之间切换HiCar连接。

   假设手机A已经与车机建立HiCar连接，现在计划切换到手机B的示例代码如下所示：

   ```screen
   //获取已连接设备列表
   List<TrustPhoneInfo> list = mHiCarAdapter.getTrustDeviceList();
   //查看需要连接的手机B是否在列表中
   for (TrustPhoneInfo info : list) {
       if (info.getPhoneBrMac() == targetMac) { 
         //TODO,保存mac地址
       }
   }
   //断开当前连接的手机A，处理断开流程
   mHiCarAdapter.disconnectDevice(deviceId);
   ...
   //初始化车机，蓝牙已和B手机配对（如未配对，请先配对连接）
   //回连目标手机B
   mHiCarAdapter.startReconnect(targetMac,true);
   ```
