# 管理车机按键/旋钮/触摸板

## 场景说明

HiCar支持通过物理按键和旋钮控制相应的应用和服务，例如通过多媒体下一首按键切换音乐、通过挂机键挂断通话等。厂商在集成HiCar SDK时需要将物理按键和旋钮事件上报给HiCar SDK，便于控制对应的应用和服务。

厂商在处理车机物理按键、旋钮、触摸板时，应合理处理物理事件在车机本地与HiCar之间的分发逻辑。推荐按照以下规则进行实现：

1. 厂商无需上报不需要HiCar处理的按键事件，需要车机上报的物理按键如[表 HiCar SDK中支持的按键和旋钮事件](#ZH-CN_TOPIC_0000001050984575__table8342183114500)。
2. 接通/挂断键按照按照如下规则适配：
   1. 蓝牙通话时，HiCar不处理接听/挂断键，通话的接听挂断由蓝牙处理。
   2. HiCar虚拟通话时，接听/挂断键需要根据[通话状态](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/call-status-and-focus-0000001051530010)发送正确的事件给手机。
3. 媒体播控键按照如下规则适配：厂商判断当前焦点栈中有HiCar应用申请的媒体焦点，发送方控事件给手机，如焦点栈中没有找到HiCar申请的媒体焦点，厂商在收到HiCar音乐元数据的状态下，也需要发送方控事件给手机。

## 接口说明

|类|方法|说明|
|:-----------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HiCarAdapter|sendKeyEvent|发送按键事件。入参包括按键值及按键操作： * 按键值：支持的按键值如[表2](#ZH-CN_TOPIC_0000001050984575__table8342183114500)所示。 * 按键操作： * 0：ACTION_DOWN。 * 1：ACTION_UP。 * 2：不区分ACTION_DOWN和ACTION_UP，例如旋转按钮操作。|

## 开发步骤

1. 当物理按键或旋钮被触发后，厂商需要自行解析对应的事件。
2. 通过sendKeyEvent接口向HiCar SDK发送对应的事件。

   示例代码如下所示：

   ```screen
   //发送广播按键事件
   mHiCarAdapter.sendKeyEvent(2000, 0);
   ```
