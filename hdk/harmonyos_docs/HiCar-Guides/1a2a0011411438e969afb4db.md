# 显示媒体信息

音视频类应用在适配HiCar时需要接入AVSession。应用接入AVSession后，HiCar可以通过AVSession将音视频信息在车机界面上向用户展示，同时用户可以通过音频卡片实现音视频的播放、暂停等操作。
