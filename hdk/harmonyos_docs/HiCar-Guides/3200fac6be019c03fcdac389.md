# 应用融合形式

**规则 5-1 车机已连接HUAWEI HiCar的状态下，来自手机HUAWEI HiCar的全量应用需要在车机露出，且需要与车机原生应用融合显示，融合应用图标右上角不允许添加P档或其它标识，以免挡住"尝鲜"字样。**

来自手机的应用可由车机系统自行排序。应用融合显示可选择采用以下方式。

## 方式一：来自手机的应用在HUAWEI HiCar Tab页签内显示

优先推荐在车机原生应用中心增加页签，页签标题为"HUAWEI HiCar"。

**规则 5-2 HUAWEI HiCar 智慧桌面应用需要在页签内排在首位。**

HUAWEI HiCar 智慧桌面操作交互具体参见[HUAWEI HiCar 智慧桌面](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/app-fusion#section124617421795)

## 方式二：与车机原生应用直接混排

**规则 5-3 HUAWEI HiCar 智慧桌面应用需要在车机原生应用中心的首屏内露出。**

**规则 5-4 来自手机的应用名称显示为"应用名称"+"HUAWEI HiCar"，便于用户区分应用来源。**
