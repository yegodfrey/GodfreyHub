# 声明支持多屏显示

音频应用需要在AndroidMainfest.xml清单文件中配置以下信息，声明音频应用支持多屏显示，以支持应用同时在手机和车机界面被打开并使用。

```screen
<application>
...        
<meta-dataandroid:name="com.huawei.multidisplay.support.multidisplay"
android:value="true" />
...
</application>
```
