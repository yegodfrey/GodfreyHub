# 开放能力简介

## 概述

HUAWEI HiCar（以下简称HiCar ）为手机应用提供了一系列软件开发工具包，为应用开发者接入HiCar提供API接口及应用模板，便于应用开发者能够快速将已有的应用接入HiCar，在出行场景中为用户提供服务。

HiCar为应用提供一系列开放能力，包含基础的CarBaseEngine和为不同类别应用提供专属能力的子Engine。目前已开放CarBaseEngine和CarMapEngine能力（CarMapEngine同时依赖CarUIEngine，相关能力同步开放）。

集成HiCar开放能力的应用，安装和运行都是在手机上，手机上的HiCar App会将应用对应的界面启动到汽车硬件设备屏幕上（例如车机屏幕，后续皆以车机屏幕举例），并通过应用中集成的HiCar开放能力与应用进行通讯。

## 能力说明

HiCar将逐步为手机应用提供如下开放能力：

* 应用模板化接入，目前音频/地图应用可以通过模板接入HiCar。
* （暂未开放）车辆属性信息获取，包括车控屏幕属性、油量/电量/胎压状态、行驶状态等。
* （暂未开放）车辆基本功能控制，包括控制车窗、车载空调、车载媒体设备等。

## 应用入口

用户使用手机与车机建立HiCar连接后，HiCar通过HiCar Launcher的方式，在车机屏幕上显示集成了HiCar开放能力的应用。

HiCar Launcher由以下几部分构成：

* 系统信息区：显示手机状态信息，包括信号、电量。


* DOCK区：常用功能入口，包括语音助手、导航、音乐、联系人、返回HiCar Launcher桌面、当前时间。当前只向音频应用和地图应用开放DOCK区入口。当用户点击DOCK区导航/音乐按钮时，HiCar会打开最近使用的地图/音频应用。
* 内容区：显示HiCar Launcher桌面和应用内容。内容区可以展示应用图标和应用卡片。
  * 应用图标区：显示集成了HiCar开放能力的应用的图标。用户可以点击图标直接在车机屏幕上打开应用。
  * 卡片区：显示应用对应的桌面卡片。用户可以通过桌面卡片快速进入应用或执行卡片上的快捷功能。

## 接入说明

应用开发者只需要在原有应用的基础上集成HiCar开放能力即可支持HiCar，而不需要单独为HiCar设计开发单独的应用。但应用开发者需要单独设计开发专门用于在HiCar车机屏幕上显示的界面，请勿直接复用已有的用于在手机屏幕上展示的界面。

如果应用开发者选择在车机屏幕上复用显示已有的界面，则该界面同一时刻只能显示在手机屏幕或者车机屏幕上，当用户在车机屏幕上通过点击图标启动应用时，HiCar会结束掉手机上正在显示的界面，重新在车机屏幕上启动该界面。此时用户无法在手机上打开该应用，影响用户体验。

如果应用开发者选择单独设计开发车机专用界面，通过声明支持多屏显示（接入指导中有详细介绍），用户可以在手机屏幕和车机屏幕上同时使用该应用。
