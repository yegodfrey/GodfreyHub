# 开发自测试

根据实现方案及计划，完成车机侧HiCar项目的开发与测试。

## UI/UE设计

华为针对集成HiCar的产品制定了明确的UX规范，并提供设计阶段所需的图标、连接界面等设计资源。相关UX规范及设计资源可在本站点左侧的"交互设计"章节在线浏览。

车企在UI/UE设计阶段请严格按照HiCar相关UX规范进行设计，如在应用规范时存在突破或无法遵守规范的场景，请及时与华为团队进行沟通。

## 集成开发

### HiCar系统架构

HiCar系统设计的核心思想是建立手机与汽车的连接，通过分布式技术构建手机和汽车共享互助资源池，从而将手机的能力以及手机生态引入到汽车环境，完成出行场景内外服务接续和数字化体验升级。

### 问题跟踪解决

在集成HiCar过程中，如遇到流程和技术类问题，可通过如下步骤进行解决：

1. 请优先查看HiCar配套的开发指南与API参考等指导文档。
2. 文档中未覆盖的问题可通过邮件集中咨询，或联系华为BD组织集中答疑，集中答疑前需提前邮件发送问题列表。
3. 对于需要分析日志的问题，例如Bug，请先进行初步分析和定界，定界在华为侧的问题可以通过CEPM系统提单，供华为侧分析解决。

   CEPM提单规范：
   * 测试环境：填写手机型号及ROM版本，车机硬件平台及系统版本，手机的HUAWEI HiCar APP版本，车机的HMI应用版本号。
   * 测试步骤：填写详细的复现问题的步骤。
   * 问题描述：填写问题发生的时间点，以及车企的初步分析结论。

   > 说明
   >
   > 没有初步分析结论或没有按照提单规范填写信息的问题会被打回。

### 自测试

华为针对HiCar集成项目提供了完备的自测试用例，车企在完成HiCar相关功能开发之后，在提交认证之前，需要按照自测试用例完成测试工作。

自测试用例100%测试通过，是华为认证准入的前提。华为启动认证时，将针对车企提供的自测试报告进行审核和抽查。
