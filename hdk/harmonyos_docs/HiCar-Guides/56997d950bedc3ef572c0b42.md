# 车机屏幕操作（Beta）

## 场景说明

如果车机支持控制车机屏幕息屏/亮屏操作，连接HiCar后，用户可以通过HiCar语音操控车机屏幕息屏或亮屏。

操作车机屏幕相关的数据格式说明请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[车机屏幕息亮屏](https://developer.huawei.com/consumer/cn/doc/HiCar-References/screen-on-off-0000001153300364)部分。

## 开发步骤

1. HiCar App查询车机是否支持操作车机屏幕息屏/亮屏。

   1. HiCar App会在连接成功后向车机发送查询消息（dataType=521），查询车机是否支持操作屏幕息屏/亮屏，示例如下所示：

      ```screen
      {
          "queryScreenState":"state"
      }
      ```

   2. 车机通过**DataReceive** 方法，判断**dataType** 后可以收到上述具体数据内容，通过**HiCarSendData** 接口返回支持情况。

      车机不支持操作车机屏幕息屏/亮屏，示例如下所示：

      ```screen
      {
          "isSupportAbility":-1
      }
      ```

      车机支持操作车机屏幕息屏/亮屏，且当前屏幕处于亮屏状态，示例如下所示：

      ```screen
      {
          "isSupportAbility":1,
          "screenState":1
      }
      ```

      车机支持操作车机屏幕息屏/亮屏，且当前屏幕处于息屏状态，示例如下所示：

      ```screen
      {
          "isSupportAbility":1,
          "screenState":2
      }
      ```

2. HiCar App语音操控车机息屏/亮屏，车机完成操作并返回响应消息。

   1. HiCar App向车机发送息屏/亮屏指令消息，示例如下所示：

      ```screen
      //亮屏
      {
          "deviceScreenOper":1
      }

      //息屏
      {
          "deviceScreenOper":2
      }
      ```

   2. 车机自行完成操作，并根据操作结果返回响应消息。 成功后返回消息示例如下所示：

      ```screen
      {
          "response":100000
      }
      ```

      失败后返回消息示例如下所示：

      ```screen
      {
          "response":100004
      }
      ```

3. 车机在非HiCar触发息屏/亮屏时（例如物理按键触发时），主动上报HiCar。

   车机在非HiCar触发的情况下，自行完成息屏/亮屏后，为了避免与HiCar语音产生冲突，需要主动上报HiCar。示例如下所示：

   ```screen
   {
       "screenStateChange":1
   }
   ```
