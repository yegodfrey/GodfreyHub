# 运行态更新车机信息

## 场景说明

厂商HMI应用可以在SDK初始化设置车机参数，也可以在SDK运行过程中，动态更新部分车机参数。

* 支持运行态更新的参数包括：投屏Surface对象、是否支持无线连接、是否支持有线连接、是否支持自动连接、屏幕分辨率宽度VideoWidth、屏幕分辨率高度VideoHeight、车机Camera配置信息等。
* 其它参数，例如ModelID，蓝牙Mac等只能在SDK初始化时设置。

## 接口说明

|类|方法|说明|生效方式|
|:--------|:-----------------------|:-------------------|:--------|
|CarConfig|updateSurface|更新投屏Surface对象。|实时生效|
|CarConfig|updateSupportWireless|更新是否支持无线连接。|修改后重新连接生效|
|CarConfig|updateSupportUsb|更新是否支持有线连接。|修改后重新连接生效|
|CarConfig|updateSupportReconnect|更新是否支持自动连接。|修改后重新连接生效|
|CarConfig|updateVideoWidth|更新投屏区域宽度。|修改后重新连接生效|
|CarConfig|updateVideoHeight|更新投屏区域高度。|修改后重新连接生效|
|CarConfig|updateCameraCustomDefine|更新车机Camera配置信息。|实时生效|
|CarConfig|updateDefaultBitrate|更新车机默认投屏码率。|修改后重新连接生效|
|CarConfig|updateAdvPower|更新车机广播信号强度。|实时生效|
|CarConfig|update5gChannels|更新车机支持的Wi-Fi 5G信道列表。|实时生效|
|CarConfig|updateDpi|更新投屏DPI。|修改后重新连接生效|
|CarConfig|updateFps|更新投屏每秒帧数。|实时生效|
|CarConfig|updateGop|更新投屏两个I帧之间的间隔帧数。|实时生效|
|CarConfig|updateCodecType|更新投屏视频流编码格式。|修改后重新连接生效|
|CarConfig|updateAudioDelayBuffer|更新音频流缓存帧数。|实时生效|
|CarConfig|updateCodecConfigureFlag|更新车机解码器的定制配置参数。|修改后重新连接生效|
[**表1**运行态更新车机信息相关接口]

更多关于上述接口的内容，详见本文档后续章节。

## 开发步骤

运行态更新车机参数的示例代码如下所示：

```screen
//更新投屏区域信息
carconfig.updateVideoWidth(1024);
carconfig.updateVideoHeight(768);
//更新是否支持自动连接功能
carconfig.updateSupportReconnect(true);
//更新音频流缓存帧数
HiCarAdapter.updateCarConfig(carconfig.updateAudioDelayBuffer(delaybuffer))
```

> 说明
>
> * HMI应用在调整delaybuffer字段时为避免出现短暂无声或者卡顿问题，需要少量逐步多次去更新delaybuffer字段。
> * updateAudioDelayBuffer接口调用完成之后还需要再调用HiCarAdapter的updateCarConfig接口，否则会出现更新不生效的情况。
