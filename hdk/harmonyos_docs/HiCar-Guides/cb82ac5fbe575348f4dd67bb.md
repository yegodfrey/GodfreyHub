# 获取应用列表

## 场景说明

在HiCar连接完成后，厂商HMI应用可以通过HiCar SDK向HiCar App请求获取接入HiCar的应用信息，获取成功后，将应用信息与原车界面进行融合显示。

## 接口说明

在获取支持HiCar的应用信息的过程中，以下两个类需要了解：

* AppTransManager：融合桌面应用管理类，提供注册、反注册等接口。它是一个单例，通过getInstance方法获取该单例，通过release方法销毁该单例。
* AppInfoChangeListener：融合桌面应用数据及事件信息类，提供应用数据获取及应用事件（例如应用安装、应用卸载等）回调接口。

另外，融合桌面中与HiCar App交互的接口设计，沿用了已有车机与HiCar App交互接口的机制，所以在开发融合桌面特性之前，请参考[数据交互](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/data-interaction-0000001192952815)了解交互机制。

获取应用列表过程中与HiCar App交互的具体数据格式说明，请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[融合桌面应用列表](https://developer.huawei.com/consumer/cn/doc/HiCar-References/fusion-ui-app-list-0000001607807413)部分。

## 开发步骤

1. 注册接口监听。请确保该步骤中的注册接口监听的代码，在步骤2之前被执行。

   ```screen
   // 注册接口监听
   AppTransManager.getInstance().registerAppInfoChangeListener(this);
   ```

2. 在建立HiCar连接后，车机可通过**HiCarAdapter::sendCarData**接口发送请求报文（dataType=528）请求获取接入HiCar的应用信息。报文内容示例如下所示：

   ```screen
   {
       "RequestData" : "all",
       "RequestCaller" : "00010001"
   }
   ```

   示例代码如下所示：

   ```screen
   JSONObject jsonObject = new JSONObject();
   jsonObject.put("RequestData", "all");
   jsonObject.put("RequestCaller", "00010001");
   String data = jsonObject.toJSONString();
   mHiCarAdapter.sendCarData(528, data.getBytes(StandardCharsets.UTF_8));
   ```

3. 获取HiCar App返回的应用数据结果。

   当数据请求成功时，HiCar SDK会通过AppInfoChangeListener的onLoadAllAppInfo回调返回所有HiCar支持的应用信息列表，并在应用安装或卸载时触发其它回调，具体回调说明如下：
   * **onLoadAllAppInfo**(String deviceId, List<AppInfoBean> list)：当请求成功后，通过该回调返回所有当前手机中已安装的支持HiCar的应用信息列表。
   * **onAppInfoAdd**(String deviceId, List<AppInfoBean> list)：当有支持HiCar的应用被安装时，通过该回调返回新安装的应用信息列表。
   * **onAppInfoRemove**(String deviceId, List<AppInfoBean> list)：当有支持HiCar的应用被卸载时，通过该回调返回被卸载的应用信息列表。
   * **onAppInfoUpdate**(String deviceId, List<AppInfoBean> list)：当有支持HiCar的应用信息发生变化时，例如应用图标发生变化，通过该回调返回信息发生变化的应用信息列表。

   |字段名|描述|
   |:------------------|:-----------------------------------------|
   |String mPackageName|应用包名|
   |String mName|应用名称|
   |byte[] mIcon|应用图标|
   |int mType|应用类型： 1：工具类型 2：地图类型 3、4：音乐类型 5：通话类型 6：娱乐类型|
   [**表1**AppInfoBean字段参数说明]

   > 说明
   > 1. 车机获取应用列表后，需等待接收手机端发送的首次[532 消息](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/handle-app-backgroud-0000001606109141)，以此决定是跳转车机桌面，还是启动投屏并展示"安全驾驶声明"页面。
   > 2. 当处于"安全驾驶声明"界面示状态时，如非用户主动操作不可强制结束投屏并跳转车机桌面。

4. 在HiCar断开连接后，反注册接口监听及释放资源。

   ```screen
   // 反注册接口监听
   AppTransManager.getInstance().unregisterAppInfoChangeListener(this);
   // 释放资源
   AppTransManager..release();
   ```
