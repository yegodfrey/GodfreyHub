# 处理应用操作

## 场景说明

车机将获取的来自HiCar的应用显示到车机原生界面后，当用户点击这部分应用图标后，车机需按照HiCar SDK设定的方式与HiCar进行交互。

## 接口说明

融合桌面中与HiCar App交互的接口设计，沿用了已有车机与HiCar App交互接口的机制，所以在开发融合桌面特性之前，请参考[数据交互](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/data-interaction-0000001192952815)了解交互机制。

处理应用操作过程中与HiCar App交互的具体数据格式说明，请参考《HUAWEI HiCar SDK API参考》"HiCar App与车机间接口"中[融合桌面应用操作](https://developer.huawei.com/consumer/cn/doc/HiCar-References/fusion-ui-app-operation-0000001607687489)部分。

## 开发步骤

1. 车机在根据[获取应用列表](https://developer.huawei.com/consumer/cn/doc/HiCar-Guides/get-app-list-0000001606309545)内容获取到应用列表并展示在车机原生界面后，当用户通过屏幕点击或其他方式（如语音）打开来自HiCar的应用时，车机可通过**HiCarAdapter::sendCarData**接口发送请求报文（dataType=529）告知HiCar App当前被打开的应用信息。报文内容示例如下所示：

   ```screen
   {
       "RequestApp" : {
           "Action" : "start",
           "AppPackage" : "com.android.mediacenter"
       }
   }
   ```

2. HiCar App将会根据打开应用的实际情况进行回复，车机通过**onDataReceive** 方法，判断**dataType**后可以收到具体数据内容。报文内容示例如下所示：

   ```screen
   {
       "RequestAppResp" : {
           "RespCode" : 100000,
           "AppPackage" : "com.android.mediacenter",
           "Description" : "success"
       }
   }
   ```

3. 车机收到打开应用的回复后，判断是否成功打开了应用，如果成功则拉起投屏。示例代码如下所示：

   ```screen
   @Override
   public void onDataReceive(String key, int dataType, byte[] data) {
       switch (dataType) {
           case 529:
               String stringOptional = bytesToString(data);
               JSONObject object = JSONObject.parseObject(stringOptional);
               int respCode = object.getIntValue("RespCode");
               if (respCode == 100000) {
                   startProjection();
               }
       }
   }
   ```
