# 获取手机设备信息

## 场景说明

在连接认证成功后，车机侧需要获取当前对端手机设备信息，用来判断手机是否支持手机桌面。同时若此时车机要显示手机桌面，则需从设备信息中获取到手机分辨率，同比例显示手机桌面窗口宽高（不能默认显示竖屏，有可能此时手机是横屏显示或折叠展开态）。

## 接口说明

在从接口获取的手机设备信息中包含两个接口getDeviceWidth()、getDeviceHeight()，接口意义如下：

* getDeviceWidth()：当前手机视频流的宽度。
* getDeviceHeight()：当前手机视频流的高度。
