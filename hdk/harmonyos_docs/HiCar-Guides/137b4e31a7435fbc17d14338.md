# 指定HiCar使用的MediaSession

## 场景说明

音频应用中可能存在多个MediaSession服务，为避免HiCar音频模板绑定错误的MediaSession服务产生异常，音频应用需要明确指定HiCar可以使用哪一个MediaSession服务。

## 接口说明

音频应用在设置界面显示参数时，可以同时指定HiCar使用的MediaSession，相应的接口及参数说明参见前文[界面显示说明](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/ui-style-specification-0000001119898503)。

## 开发步骤

音频应用在初始化HiCar使用的MediaSession服务时，通过setExtras()方法在入参对象中添加"hicar.media.bundle.FOR_HICAR"字段即可，详情可见前文[界面显示说明](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/ui-style-specification-0000001119898503)。
