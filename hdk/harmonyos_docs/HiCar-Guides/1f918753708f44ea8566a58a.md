# 配置界面显示参数

## 场景说明

HiCar环境中音频应用的界面由HiCar绘制完成，音频应用根据业务展示需要指定界面显示参数，控制界面元素的展示形态和展示样式即可。

## 接口说明

|接口|说明|
|:------------------------------------|:-----------------------------------------------------------------------------------------------|
|MediaSession.setExtras(Bundle extras)|音频应用在初始化MediaSession时，通过该方法设置界面参数，参数结构如[表2](#ZH-CN_TOPIC_0000001078018960__table711014219226)所示。|
[**表1**配置界面显示参数相关接口]

|Bundle参数Key|参数类型|说明|
|:---------------------------------------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|hicar.media.bundle.UI_STYLE|Bundle|音频应用需要将内容页、详情页、播放页相关的所有界面参数打包成一个Bundle对象，Bundle对象的结构如[表3](#ZH-CN_TOPIC_0000001078018960__table10339142910390)所示。|
|hicar.media.bundle.FOR_HICAR|Boolean|HiCar可以使用的MediaSession服务标记，具体说明请参见[指定HiCar使用的MediaSession](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/specify-mediasession-0000001119983201)。|
|hicar.media.bundle.PLAY_MODE|int|建议音频应用在MediaSession初始化时，设置初始播放模式： * 0：列表循环 * 1：单曲循环 * 2：随机播放 * 3：顺序播放 HiCar会根据音频应用提供的当前播放模式，来决定显示哪个播放模式的图标。|
|hicar.media.bundle.PLAY_RATE|int|建议音频应用在MediaSession初始化时，设置初始播放速率： * 0：0.75倍速 * 1：1倍速 * 2：1.5倍速 HiCar会根据音频应用提供的当前播放速率，来决定显示哪个播放速率的图标。|
|hicar.media.bundle.EXTRA_PLAY_MODE|Boolean|【在默认播放模式基础上累加】是否支持自定义模式： * false：不支持（默认值） * true：支持 配合hicar.media.bundle.PLAY_MODE_EXTRA_BITMAP_LIST使用。|
|hicar.media.bundle.PLAY_MODE_EXTRA_BITMAP_LIST|List<Integer>|自定义播放模式图标的ID集合，最多支持新增三个自定义模式。 自定义的播放模式在默认播放模式基础上累加，即自定义了一个播放模式后，加上已有的四个默认播放模式，一共存在五种播放模式。|
|hicar.media.bundle.EXTRA_PLAY_RATE|Boolean|【和默认播放速率二选一】是否支持自定义速率： * false：不支持（默认值） * true：支持 配合hicar.media.bundle.PLAY_RATE_LIST使用。|
|hicar.media.bundle.PLAY_RATE_LIST|List<String>|自定义速率具体的数值，如：0.5X、1X、1.25X。|
|hicar.media.bundle.SUPPORT_SCROLL_PROGRESS|Boolean|是否支持进度条拖动功能： * false：不支持（默认值） * true：支持|

## 开发步骤

1. 音频应用在MediaSession初始化时通过MediaSession.setExtras设置HiCar需要的所有参数。

   初始化MediaSession对象时设置界面参数的示例代码如下所示：

   ```screen
   @Override
   public void onCreate(){
       super.onCreate();
       mMediaSession = new MediaSession(this,"MediaService");
       //当播放服务初始化后通过setExtras()设置界面参数
       //建议setExtras()方法置于setActive()方法之前，否则HiCar不能及时得到Bundle数据
       //genExtras()为设置界面参数的函数，可见后续示例代码
       mMediaSession.setExtras(genExtras());
       mMediaSession.setActive(true);
   }
   ```

2. 音频应用设置内容页、详情页、播放页、品牌颜色等具体参数。

   示例代码如下所示：

   ```screen
   public class MediaService extends MediaBrowserService {
       private static final String TAG = "MediaService ";

       private MediaSession mMediaSession;

       @Override
       public void onCreate() {
           super.onCreate();
           mMediaSession = new MediaSession(this, "MediaService");
           // 当播放服务初始化时需要将UI风格信息设置下去
           // 建议setExtras置于setActive之前
           mMediaSession.setExtras(genExtras());      
           mMediaSession.setActive(true);
       }
       private Bundle genExtras() {
           Bundle bundle = new Bundle();

           int highLightColor = 0xFF41BA41;
           bundle.putParcelableArrayList("hicar.media.bundle.TABS_STYLE", genTabItems());  // 设置首页tab的样式，其中包括名称、图标、样式三部分
           bundle.putInt("hicar.media.bundle.LOGO_HIGH_LIGHT_COLOR", highLightColor);      // 设置三方品牌高亮色
           bundle.putInt("hicar.media.bundle.ALBUM_IMAGE_STYLE", 0);                   // 设置播放页面的歌曲图片是方形还是圆形，0代表方形，1代表圆形
           bundle.putInt("hicar.media.bundle.SUB_TITLE_STYLE", 1);                   // 设置播放页面的第二行文字是歌手还是专辑，0代表歌手，1代表专辑
           bundle.putInt("hicar.media.bundle.THIRD_TITLE_STYLE", 0);                 // 设置播放页面的第三行文字是专辑还是歌词，0代表专辑，1代表歌词
           bundle.putInt("hicar.media.bundle.TITLE_LINKABLE", 0);                // 设置播放页面的后两行文字是否支持点击跳转，0代表不支持，1代表支持
           bundle.putInt("hicar.media.bundle.PAGE_SIZE", 25);                // 设置分页机制中每一页的子项数目 
          // 设置详情页样式，0代表有专辑介绍，1代表没有专辑介绍，设置后全局生效，所有详情页均为此样式
           bundle.putString("hicar.media.bundle.DETAIL_PAGE_STYLE", "0");     
          // 设置默认图片，当传给hicar的url取不到图片时，使用此默认图片   
           bundle.putParcelable("hicar.media.bundle.DEFAULT_ICON_BITMAP",BitmapFactory.decodeResource(getResources(), R.drawable.ic_launcher));  
           //是否支持自定义模式
           bundle.putBoolean("hicar.media.bundle.EXTRA_PLAY_MODE", true);    
           //设置自定义模式数据
           bundle.putIntegerArrayList("hicar.media.bundle.PLAY_MODE_EXTRA_BITMAP_LIST",getExtraPlayMode());      
           //设置是否支持自定义速率
           bundle.putBoolean("hicar.media.bundle.EXTRA_PLAY_RATE", true);  
          //设置自定义速率数据  
           bundle.putStringArrayList("hicar.media.bundle.PLAY_RATE_LIST", getExtraPalyRate());
           Bundle hicarUIStyle = new Bundle();
           //指明当前HiCar可以使用该MediaSession服务
           hicarUIStyle.putBoolean("hicar.media.bundle.FOR_HICAR", true);  
           // 设置HiCar首次冷启动打开音频应用时播放页默认的播放模式 0: LOOP_ALL, 1: LOOP_SINGLE, 2: SHUFFLE, 3: ORDER
       hicarUIStyle.putInt("hicar.media.bundle.PLAY_MODE", 0);
           // 设置HiCar首次冷启动打开音频应用时播放页默认的播放速率 0: 0.75倍速, 1: 1倍速, 2: 1.5倍速
      hicarUIStyle.putInt("hicar.media.bundle.PLAY_RATE", 1);
           //设置UI风格信息
           hicarUIStyle.putBundle("hicar.media.bundle.UI_STYLE", bundle);  
           return hicarUIStyle;
       }

       private ArrayList<MediaSession.QueueItem> genTabItems() {
           ArrayList<MediaSession.QueueItem> results = new ArrayList<>(4);
           for (int i = 0; i < 4; ++i) {
               Bundle bundle = new Bundle();

               int isMusic = 1;                  
               int hasChild= i % 2 == 0 ? 0 : 1;             // 该tab内容是否支持下一级跳转，0代表不支持，1代表支持
               int gridListStyle= i == 0 ? 1 : 0;            // 该tab采用列表布局(仅有声有效)还是宫格布局，0代表列表，1代表宫格
               int indexStyle = i % 2 == 0 ? 0 : 1;           // 该tab为列表的情况下，0使用数字序号，1使用图片封面
               int lineStye= i % 2 == 0 ? 0 : 1;             // 该tab为列表的情况下，0代表两行文字，1代表一行文字
   	    // 注1：在tab是音乐的情况下，若支持下一级跳转则固定采用宫格布局，没有下一级跳转则固定采用列表布局。宫格和列表的自由选择仅有声支持。
              // 注2：音乐的列表中固定没有进度条，有声的列表固定有进度条
               Bundle uiStyle = new Bundle();
               uiStyle.putInt("hicar.media.bundle.IS_MUSIC",isMusic );
               uiStyle.putInt("hicar.media.bundle.HAS_CHILD",hasChild);
               uiStyle.putInt("hicar.media.bundle.GRIDLIST_STYLE",gridListStyle);
               uiStyle.putInt("hicar.media.bundle.INDEX_STYLE",indexStyle  );
               uiStyle.putInt("hicar.media.bundle.LINE_STYLE",lineStye);
               bundle.putParcelable("hicar.media.bundle.PATTERN_STYLE",uiStyle);
               Bitmap bitmap = BitmapFactory.decodeResource(getResources(), tabIcons[i]);

   	   // title为tab名称，bitmap为tab图标，mediaId为tab的Id
               MediaDescription description = new MediaDescription.Builder().setMediaId("title_" + i)
                   .setTitle(tabs[i])
                   .setIconBitmap(bitmap)
                   .setExtras(bundle)
                   .build();
               MediaSession.QueueItem queueItem = new MediaSession.QueueItem(description, i);
               results.add(queueItem);
           }
           return results;
       }

   }
   ```
