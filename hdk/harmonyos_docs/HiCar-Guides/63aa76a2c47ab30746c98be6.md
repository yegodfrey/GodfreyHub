# 手机桌面介绍

从HiCar Android SDK 4.0.0.600版本开始，HiCar新增一种全新的手机桌面形态，在手机将自身分辨率信息传递给车机之后，在车机桌面开辟一块等比区域来进行同源投屏，来为用户提供更多元化的HiCar使用体验。
> 说明
>
> 1. 手机桌面与融合桌面以及智慧桌面属于互斥关系，厂商需要根据前文章节完成HiCar的功能集成，集成完成之后再按照本章节进行手机桌面的特性开发。
> 2. 为保证用户体验，车机屏幕垂直分辨率必须大于等于1080 px。

## 交互理念

1. 手车连接时，车机将支持桌面信息通过SDK接口上报给手机，同时手机上报分辨率给车机。
2. 手机桌面宽高等发生变化，或手机投屏内容发生变化通过546消息进行数据传送。
3. 手机桌面设置放在车机侧，车机侧通过设置新桌面后断连，下次主动连接生效的方式进行桌面切换。
4. 支持桌面设置后会将智慧桌面和融合桌面拆分开，智慧桌面和融合桌面可独立显示，同时融合桌面将不会有智慧桌面入口图标。
5. 设置里选择手机桌面或融合桌面后会断开连接，再次连接HiCar后设置生效，且当前点击HiCar应用车机要保证不再显示投屏界面。
6. 第一次连接后当前手机mac会绑定协商后的桌面设置，此后直接读取车机存储的桌面设置不再协商。
7. 当车机支持的桌面设置有变更时，需要清除车机数据库里的桌面设置数据，防止已连接手机不再进行新的协商。

连接HiCar前需要注册桌面信息回调，因为车机不知道当前连接的手机是否支持手机桌面，所以需要在连接握手认证时进行桌面信息协商，并返回协商结果。如果协商结果里车机和手机都支持手机桌面，则在协商结束回调里去初始化手机桌面surfaceView，否则不显示手机桌面不需要初始化。连接HiCar后实现手机桌面的主要逻辑就是从HiCar获取到手机分辨率之后，在车机对应区域进行展示。因为手机使用的过程中分辨率和横竖屏状态可能是实时变化的，所以在接收到对应变化通知时，车机侧的投屏也需要实时动态更新。

具体开发步骤与其中操作交互可参考后续章节。
