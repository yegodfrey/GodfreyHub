# 注册桌面设置回调

## 场景说明

在HiCarSDK初始化完成后，拿到HiCarAdapter对象立即注册桌面设置回调，车机在与手机握手协商时，将从回调函数里获取车机桌面设置信息，并将最终协商结果更新到车机桌面信息类中。

## 接口说明

此回调类继承自DesktopInfoCallbackMethods接口，车机侧需要实现以下五个函数，各函数及参数意义如下：

* queryDesktopSettingByMac：通过mac地址查询桌面设置。参数为deviceMac，当前连接的手机mac地址。车机要在此函数里通过deviceMac在数据库里查询对应的桌面设置信息，并赋值。
* saveDesktopSetting：保存桌面设置。参数currentDesktop为协商后车机将要显示的桌面，参数desktopSettingList为协商后桌面设置选项清单。车机在此函数里实现桌面设置信息保存到数据库功能。
* getDesktopByPriority：获取桌面优先级列表。此函数将车机支持的所有桌面按优先级从高到低排序后返回对应的列表信息，如果协商结果与currentDesktop不一致，则按此列表规定的优先级展示优先级最高的桌面。
* onNegotiationFinished：协商结束回调函数，握手协商结束后执行，车机在此可根据协商结果初始化要投屏的surface（也可在此显示桌面设置选项，但需要在连接失败时隐藏）。
* updateDesktopSetting: 改变当前显示的桌面。用户在设置里切换当前显示的桌面后，提示用户此操作会断开当前连接，需下次主动连接后设置生效。等用户点击同意后，调用此接口将更改后的桌面枚举值传给此函数，此函数将变更后的值更新到数据库中，同时调用sdk断连接口断连。

另外，在queryDesktopSettingByMac拿到参数deviceMac后需自动保存，以便saveDesktopSetting和updateDesktopSetting函数里使用。同时车机需实时更新mCurrentDesktop和mDesktopSettingList的值，与数据库里的值同步显示。同时在显示融合桌面或手机桌面的时候，建议屏蔽掉HiCar应用。避免用户点击HiCar应用图标后，仍可进入投屏界面。

## 开发步骤

1. 初始化桌面设置回调类。

   ```screen
   public class DesktopInfoCallback extends AbstractDesktopInfoCallback {
       private String mDeviceMac = ""; // 保存手机mac地址
       @Override
       public int queryDesktopSettingByMac(String deviceMac) {
           // 先查询数据库里是否插入当前手机的设置信息
           if (!isDeviceMacInDB(deviceMac)) {
               setCurrentDesktop(HiCarAuthenticationConstant.PHONE_DESKTOP); // 这里赋值需要优先级最高的桌面
               return DesktopInfoCallback.UNSET_DESKTOP_INFO; // 返回unset_desktop_info后sdk会识别到当前手机是第一次进行连接，自动进入协商流程
           }
           
           // 查询失败返回对应的errorCode
           if (queryDataByMacFailed(deviceMac)) {
               return DesktopInfoCallback.QUERY_DESKTOP_INFO_FAILED; // sdk识别到此错误码后会终止协商流程，此次协商失败，同时会将mShowDesktopSetting置为false。
           }

           mDeviceMac = deviceMac; // 保存手机mac地址
           setShowDesktopSetting(true);
           setDesktopSettingList(db.queryDesktopList(deviceMac)); // 查询与手机mac绑定的桌面设置列表
           setCurrentDesktop(db.queryCurrentDesktop(deviceMac)); // 查询当前显示的桌面
           return DesktopInfoCallback.QUERY_DESKTOP_INFO_SUCCESS; // 返回查询成功结果码，sdk识别此结果后将此结果上报给手机
       }
       @Override
       public ArrayList<Integer> getDesktopByPriority() {
           // 按车机桌面优先级返回支持的桌面列表, 列表里的第一个值显示优先级最高，最后一个值显示优先级最低
           ArrayList<Integer> supportDesktopList = new ArrayList<>();
           supportDesktopList.add(HiCarAuthenticationConstant.PHONE_DESKTOP); // 手机桌面
           supportDesktopList.add(HiCarAuthenticationConstant.INTEGRATION_DESKTOP); // 融合桌面
           supportDesktopList.add(HiCarAuthenticationConstant.WISDOM_DESKTOP); // 智慧桌面
           return supportDesktopList;
       }
       @Override
       public void saveDesktopSetting(int currentDesktop, ArrayList<Integer> desktopSettingList) {
           setCurrentDesktop(currentDesktop);
           setDesktopSettingList(desktopSettingList);
           saveDesktopSettingInDB(mDeviceMac, currentDesktop, desktopSettingList); // sdk第一次协商完成后，会调此函数将结果保存到数据库
       }
       @Override
       public void onNegotiationFinished() {
           initCurrentSurfaceView(); // 初始化当前要显示的surfaceView
           if (getShowDesktopSetting()) {
               showDesktopSetting(); // 在设置里显示桌面设置项
           }
       }
       public void updateDesktopSetting(int currentDesktop) {
           if (currentDesktop == mCurrentDesktop) {
               DeviceLogUtils.warn(TAG, "the desktop not change");
               return;
           }
           mCurrentDesktop = currentDesktop;
           updateDesktopSettingInDB(mDeviceMac, currentDesktop); // 用户更改桌面设置后调此接口保存至数据库
           mHicarAdapter.disconnect(); // 保存后断连，可以给个弹框提示更改后会断连，需手动重连后生效，点击确认后再断连。
       }
   }

   public DesktopInfoCallback mDesktopInfoCallback = new DesktopInfoCallback();
   ```
