# 自动连接

如果用户已经成功通过无线方式连接了HUAWEI HiCar，并在手机允许了"自动连接"，当上次非手动断开HUAWEI HiCar，用户再次进入驾驶环境时，车机将自动与手机建立HUAWEI HiCar无线连接。

**规则 3-4 自动连接过程中，车机侧需首页有状态提示。**

提示语： "HUAWEI HiCar 图标 +XXXX 正在连接"（XXX连接的手机名称）。

提示语："HUAWEI HiCar 连接失败，重新进行连接"
