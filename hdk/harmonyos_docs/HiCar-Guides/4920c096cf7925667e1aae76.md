# 加载内容数据

## 场景说明

音频应用在收到数据加载指令时，应根据不同场景正确加载数据并返回。

### 初始化时加载内容页数据

用户首次打开音频应用展示首个页签或首次切换到其他页签时，音频应用会收到数据加载指令，指令中hicar.media.bundle.PARENT_ID为音频应用在设置界面参数时设置的内容页页签Media ID，此时音频应用应返回内容页的数据。

如果内容页中内容项为专辑时，音频应用在返回专辑数据时，还需根据之前设置的界面参数进行灵活处理：若设置详情页有专辑信息（即[表3](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/set-ui-parameters-0000001078018960#ZH-CN_TOPIC_0000001078018960__table10339142910390)中hicar.media.bundle.DETAIL_PAGE_STYLE设置为0），音频应用应在返回内容页数据时，除了设置专辑封面图片（icon）和专辑标题（title）以外，还需要设置专辑二级标题（subtitle）和专辑描述（description）。当用户点击专辑进入详情页时，HiCar会在专辑内容项列表顶部显示专辑二级标题和专辑描述。

### 点击专辑加载专辑曲目数据

用户在内容页点击某个专辑时，音频应用会收到数据加载指令，指令中hicar.media.bundle.PARENT_ID为专辑Media ID，此时音频应用应返回专辑内曲目数据。

音频应用在返回专辑内容曲目数据时，如果返回列表的第一个Item已设置图片的URI信息，则HiCar将使用图片作为列表的索引样式，否则使用数字作为索引样式。

### 列表滑动到底加载分页数据

为了降低内存占用和提升性能，HiCar采用分页查询的方式获取数据。当用户将列表滑动到底部触发分页查询时，音频应用将收到数据加载指令，指令中hicar.media.bundle.PARENT_ID为数据所在的内容页页签Media ID或专辑Media ID，同时包含分页的相关参数，音频应用应返回相应的分页数据。

### 音频应用触发数据更新后加载更新数据

音频应用可以主动更新某个专辑内容，相应的场景说明及更新说明参见下文[更新内容列表数据](https://developer.huawei.com/consumer/cn/doc/development/HiCar-Guides/update-content-all-0000001119898505)，HiCar在收到音频应用的数据更新指令后，会通过数据加载指令的方式通知音频应用，即音频应用在发送数据更新指令后会再收到数据加载指令，指令中hicar.media.bundle.PARENT_ID为音频应用在数据更新指令中指定的Media ID，此时音频应用返回需要更新的数据即可。

### 点击宫格封面一键播放加载数据

用户通过方形宫格封面上的一键播放按钮（或点击方形宫格进入带有专辑介绍的详情页时，再点击播放按钮）进行整个专辑内容播放时，音频应用会收到数据加载指令，指令中hicar.media.bundle.PARENT_ID为专辑Media ID，此时音频应用应返回专辑内曲目数据。同时，音频应用在刷新当前播放曲目MetaData信息时，需要将parent ID设置为当前宫格专辑的ID，将media ID设置为宫格专辑中正在播放曲目的media ID，HiCar会以此比对来同步页签item上的播放状态。

## 开发步骤

1. 音频应用在MediaSession的Callback实现类中Override onCustomAction方法。
2. 在onCustomAction方法中针对action入参识别数据加载指令，并返回相应的数据。

   数据加载的示例代码如下所示：

   ```screen
   MediaSession.Callback callback = new MediaSession.Callback() {
          @Override
           public void onCustomAction(@NonNull String action, @Nullable Bundle extras) {
               super.onCustomAction(action, extras);
               Bundle bundle;
               // 音频应用需要根据不同的action做不同的业务处理
               switch (action) {
                   case "hicar.media.action.LOAD_QUEUE":
                       bundle = new Bundle();
                       String parentId = extras.getString("hicar.media.bundle.PARENT_ID", "");
                       LogUtils.i(TAG, "load queue:" + parentId);
                       int pageIndex = extras.getInt("hicar.media.bundle.QUEUE_PAGE_INDEX",1);
                       int pageSize = extras.getInt("hicar.media.bundle.QUEUE_PAGE_SIZE",300);
                       Bundle extraBundle = extras.getBundleExtra("hicar.media.bundle.QUEUE_EXTRA");
                       //此extraBundle为应用构造列表数据description.setExtra的入参，在此处会返还回来

                       if (checkInternetConnect()) {
                           // 网络正常 
                           ArrayList<MediaSession.QueueItem> queue = genArrayListQueue(parentId,pageIndex,pageSize);
                           bundle.putInt("hicar.media.bundle.RESULT", 0);
                           bundle.putParcelableArrayList("hicar.media.bundle.QUEUE_RESULT", queue);
                       } else {
                           // 网络异常
                           bundle.putInt("hicar.media.bundle.RESULT", 200);
                       }
                       bundle.putString("hicar.media.bundle.PARENT_ID", parentId);
                       bundle.putInt("hicar.media.bundle.QUEUE_TOTAL_SIZE",1000);
                       bundle.putInt("hicar.media.bundle.QUEUE_PAGE_INDEX",pageIndex);
                       // 返回子节点信息结果
                       mMediaSession.sendSessionEvent(action, bundle);
                       break;
                   default:
                       break;
               }
           }
       };

       private ArrayList<MediaSession.QueueItem> genArrayListQueue(String parentId, int pageIndex, int pageSize) {
           ArrayList<MediaSession.QueueItem> results = new ArrayList<>(pageSize);
           int startIndex = (pageIndex - 1) * pageSize;
           int size = pageSize * pageIndex;
           if (size > ITEM_SIZE) {
               size = ITEM_SIZE;
           }
           for (int i = startIndex ; i < size; ++i) {
               Bundle bundle = new Bundle();
               bundle.putString("hicar.media.metadata.VIP", state[i] + "");
               bundle.putString("hicar.media.metadata.EXTRA_MES", "45万"); // 额外信息，例如可以为喜欢或收藏数量，用于宫格信息展示，如非宫格样式，可不添加
               ArrayList<String> tags = new ArrayList<>(3);
               tags.add("hq");
               tags.add("独家");
               tags.add("音效");
               bundle.putStringArrayList("hicar.media.bundle.TAGS", tags);
               bundle.putBoolean("hicar.media.metadata.CHECK_PAYMENT", true); // 设置该内容属于付费内容
               MediaDescription description = new MediaDescription.Builder().setMediaId(parentId + "_" + i)
                   .setTitle("title" + i)
                   .setSubtitle("artist" + i)
                   .setDescription("album" + i)
                   .setIconUri(Uri.parse(URI_PREV + iconUrls[i % 40]))
                   .setExtras(bundle)
                   .build();
               MediaSession.QueueItem queueItem = new MediaSession.QueueItem(description, i);
               results.add(queueItem);
           }
           return results;
       }
   ```
