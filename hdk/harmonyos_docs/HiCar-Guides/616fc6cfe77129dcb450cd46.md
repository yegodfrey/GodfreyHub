# 数据交互

## 交互说明

HiCar为车机与手机侧的HiCar App间的数据交互约定了一系列的接口，用于在车机与HiCar App之间进行车辆控制、车辆属性传输等。根据接口传递数据的不同，区分为：

* 非基于JSON格式的数据接口：主要用于在SDK初始化时，车机上报一些固定信息，例如驾驶位置、车机类型等。
* 基于JSON格式的数据接口：主要用于在车机和HiCar App间通过请求/响应的方式传输可变的信息，例如车辆速度、车辆行驶状态等。不同的数据交互接口，在接收和发送时通过Data Type字段进行区分。

Android车机可以通过HiCar SDK提供的接口与HiCar App进行数据交互：

* 车机接收HiCar App发送的数据（相关接口/方法："CarListener::onDataReceive(String deviceId, int dataType, byte[] data)"）
* 车机向HiCar App发送数据（相关接口/方法："HiCarAdapter::sendCarData(int dataType, byte[] data)"）

Linux车机可以通过HiCar SDK提供的接口与HiCar App进行数据交互：

* 车机接收HiCar App发送的数据（相关接口/方法："DataReceive(const char *deviceId, uint32_t idLen, int dataType, char *data, uint32_t dataLen)"）
* 车机向HiCar App发送数据（相关接口/方法："HiCarSendData(HICAR_HANDLE handle, CarDataType dataType, uint8_t* data, uint32_t size)"）

### 车机接收HiCar App发送的数据

车机侧要接收手机侧HiCar App的数据，厂商HMI应用需要注册相应的Listener，并实现其中的**DataReceive** 方法，根据**dataType**判断不同的业务，处理相应的数据。

示例代码如下：

```screen
void DataReceive(const char *deviceId, uint32_t idLen, int dataType, char *data, uint32_t dataLen)
{
   printf("DataReceive\n");
   //收到数据后根据不同的dataType处理业务逻辑
}
carListener.DataReceive = DataReceive;
HiCarRegisterListener(&carListener);
```

### 车机向手机HiCar App发送数据

车机可以通过"HiCarSendData(HICAR_HANDLE handle, CarDataType dataType, uint8_t* data, uint32_t size)"接口向手机侧HiCar App发送数据。

示例代码如下：

```screen
// 车机检测到停车模式后，向HiCar App发送消息
uint8_t *data = "{\"drivingMode\":1}";
uint32_t size = strlen(data);
HiCarSendData(handle, HICAR_DATA_DRIVING_MODE, data, size);
```
