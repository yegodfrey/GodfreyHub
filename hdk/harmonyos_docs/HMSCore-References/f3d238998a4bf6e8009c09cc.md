# 查询时间段内的健康记录

#### 功能介绍

查询指定时间段内的健康记录。  

#### 场景描述

指定开始时间和结束时间，返回指定采集器在该时间段内的健康记录。  

#### 使用约束

无  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors/{dataCollectorId}/healthRecords?startTime=\*\*\*\&endTime=\*\*\*\&limit=\*\*\*\&cursor=\*\*\*|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 路径参数

|参数|参数类型|是否必选|描述|
|:--------------|:-----|:---|:----------|
|dataCollectorId|String|是|数据采集器的唯一标识。|

#### 查询参数

|参数|参数类型|是否必选|描述|
|:--------|:------|:---|:----------------------------------------------------------------|
|startTime|Long|是|开始时间。单位：纳秒。 startTime时间早于endTime时间。 endTime与startTime时间间隔不能超过31天。|
|endTime|Long|是|结束时间。单位：纳秒。 startTime时间早于endTime时间。 endTime与startTime时间间隔不能超过31天。|
|limit|Integer|否|单次分页查询长度。取值范围：0\~2000。|
|cursor|String|否|分页标识。填入上一个请求的cursor值进行后续查询。 小写字母/数字（长度1\~1000）。|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/json; charset=UTF-8|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body

无  

#### 请求示例

```
GET
https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors/cmF3OmNvbnRpbnVvdXMuZWNnX3JlY29yZAEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg/healthRecords?startTime=1609293600000000000&endTime=1609380000000000000
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
```

#### 响应参数

状态码为200时：

Response Header  

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

Response Body  

|参数|参数类型|是否必选|描述|
|:------------|:--------------------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|healthRecords|List\<HealthRecords\>|是|健康记录HealthRecords列表。请参见[HealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section1362316521971)数据模型。|
|cursor|String|否|分页标识。填入上一个请求的cursor值进行后续查询。 小写字母/数字（长度1\~1000位）。|
