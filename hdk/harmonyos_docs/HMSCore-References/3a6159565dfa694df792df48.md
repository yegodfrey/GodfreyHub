# 天气类-天气实况-基础实况

#### 功能介绍

天气服务REST API提供HTTPS接口，通过HTTPS形式发起请求，开发者调取基础版本实时天气信息。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 开发者服务器 -> 华为天气服务器  
接口URL | {rootUrl}/v1/weather/live/basic 说明：  {_rootUrl_}：请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/description-0000001255747721#section14786518719)  
数据格式 | 请求消息：Content-Type: application/json 响应消息：Content-Type: application/json  
  
#### 请求参数

**Request Header**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
Content-Type | 是 | String | 取值为：application/json  
Authorization | 是 | String | 您动态获取的[Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section12493191334711) 说明：  Bearer后面拼接空格，再拼接获取的access_token  
  
**Request Body**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
citycode | 是 | String | [城市编码表](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/city-dictionary-0000001256958081)  
  
#### 请求示例
    
    GET {rootUrl}/v1/weather/live/basic
    Content-Type:application/json
    Authorization:Bearer {access_token}
    {
     "citycode": "106566"
    }

#### 响应参数

**状态码为200时****：**

**Response Header**

参数 | 参数类型 | 描述  
---|---|---  
Content-Type | String | 取值为：application/json  
  
**Response Body**

参数 | 参数类型 | 描述  
---|---|---  
ret | String | 返回码，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/error-code-0000001255557253)  
msg | String | 返回值描述  
data | Object | 返回数据  
requestid | String | 请求id，用于查询日志
