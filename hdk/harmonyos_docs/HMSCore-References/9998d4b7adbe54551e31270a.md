# 错误码

|错误码|描述|处理建议|
|:--|:----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|200|成功|-|
|400|参数错误|请参考返回信息，检查请求参数是否正确。如果检查正确，请联系[华为技术支持](https://developer.huawei.com/consumer/cn/support/contactUs)定位。|
|401|鉴权失败|请重新获取Authorization参数并填写在请求头中。|
|404|路径错误|请检查URL拼写是否正确。|
|405|权限错误|请检查是否在AGC网站上开启了钱包服务能力。并检查申请的Service ID（passTypeIdentifier）对应的卡券类型是否与调用的接口相对应。如果检查正确，请联系[华为技术支持](https://developer.huawei.com/consumer/cn/support/contactUs)定位。|
|429|服务不可用|请求接口次数超过调用量限额，详见[调用量限额](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/invoke-limit-0000001053382176)。可提交[例外申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/application-0000001056538228)。|
