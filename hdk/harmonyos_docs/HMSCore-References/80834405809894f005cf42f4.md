# BarrierStatus

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract class [BarrierStatus](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierstatus-0000001050164092) extends Object implements Parcelable 将围栏状态封装在[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)中。其中，围栏状态包括当前状态、上一次状态以及上一次围栏状态更新的时间。|
