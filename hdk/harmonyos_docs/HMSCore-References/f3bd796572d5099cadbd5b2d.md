# 错误码

#### 公共错误码说明

华为支付开放网关会对开发者接口的非业务调用错误码统一处理。  

|resultCode|resultDesc|subCode|subDesc|Solution|
|:---------|:---------|:------------------------|:-------------|:-------------------------------------|
|000000|Success|\\|\\|不涉及|
|100000|权限不足|INSUFFICIENT_PERMISSION|商户权限受限|在商户平台检查并配置该产品权限|
|200000|缺少必选参数|MISSING_AUTH_HEADER|缺少鉴权参数|在请求头中构建并传入对应的鉴权信息|
|200000|缺少必选参数|MISSING_TRACER_ID|缺少tracerId参数|检查请求参数，每次请求传入唯一的traceId|
|200000|缺少必选参数|MISSING_HEADER_SIGN|缺少headSign参数|检查请求参数，传入headerSign|
|200000|缺少必选参数|MISSING_CALLER_ID|缺少callerId参数|检查请求参数，传入callerId，对应于商户号|
|200000|缺少必选参数|MISSING_BODY_SIGN|缺少bodySign参数|检查请求参数，传入bodySign|
|200000|缺少必选参数|MISSING_AUTH_ID|缺少authId参数|检查请求参数，传入商户对应的authId|
|200000|缺少必选参数|MISSING_TIME|缺少时间戳参数|检查请求参数，传入当前时间戳信息|
|200001|非法的参数|INVALID_AUTH_HEADER|鉴权信息无效|检查请求头，传入正确的鉴权信息|
|200001|非法的参数|INVALID_TRACER_ID|tracerId参数无效|检查请求参数，传入正确的traceId|
|200001|非法的参数|INVALID_AUTH_ID|authId参数无效|检查请求参数，传入正确的authId|
|200001|非法的参数|INVALID_TIME|时间戳参数无效|检查请求参数，传入正确的时间戳|
|200001|非法的参数|INVALID_SESSION_KEY|sessionKey参数无效|检查请求参数，传入正确的sessionKey|
|200001|非法的参数|INVALID_PUB_KEY|商户公钥无效|检查请求参数，确认已生成并上传公钥|
|200001|非法的参数|INVALID_DUPLICATE_REQUEST|无效的重复请求|检查请求参数，每次请求需要生成新的traceId|
|200001|非法的参数|INVALID_PARAMETER|参数无效|检查请求参数，传入正确的参数|
|200001|非法的参数|INVALID_CALLER_ID|callerId参数无效|检查鉴权请求头callerId字段传递是否正确（如类型、特殊字符、长度等）。|
|200002|签名错误|INVALID_SIGNATURE|无效签名|检查请求参数，按说明完成签名并传入正确的签名参数|
|300000|调用频率受限|CALL_FREQUENCY_LIMITED|API调用次数超限|降低请求并发量|
|400000|业务处理失败|对应的错误码和说明见具体API说明|||
|500000|服务不可用|UNKNOW_ERROR|服务暂不可用, 请稍后重试|稍后重试|
