# 管理用户设置

#### getHealthAppAuthorization()

|Method|
|:-------------------------------------------------------------------------|
|getHealthAppAuthorization() 查询运动健康应用隐私管理是否关联Health Service Kit。该接口只在手机上支持。|

Returns  

|Type|Description|
|:--------------------------|:--------------------------------------------------------------------------------|
|Promise\<Result\<String\>\>|返回读取健康记录和详情数据到Health Service Kit的异步回调。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

查询运动健康应用隐私管理是否关联Health Service Kit的示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.getHealthAppAuthorization().then((result) => {
    // 调用成功
    console.info("getHealthAppAuthorization success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.info("getHealthAppAuthorization fail: " + JSON.stringify(error))
});
```

#### checkHealthAppAuthorization()

|Method|
|:-----------------------------------------------------------------------------------------------------------------|
|checkHealthAppAuthorization() 检查运动健康应用隐私管理是否关联Health Service Kit，若未关联会跳转到运动健康关联Health Service Kit的授权页面。该接口只在手机上支持。|

Returns  

|Type|Description|
|:--------------------------|:--------------------------------------------------------------------------------|
|Promise\<Result\<String\>\>|返回读取健康记录和详情数据到Health Service Kit的异步回调。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

检查运动健康应用隐私管理是否关联Health Service Kit的示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
// 调用checkHealthAppAuthorization接口查询用户是否开启华为运动健康服务
HMSHealthKit.checkHealthAppAuthorization().then((result) => {
   // 调用成功
    console.info("checkHealthAppAuthorization success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.error("checkHealthAppAuthorization Error: " + JSON.stringify(error));
});
```
