# NavigationResult

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250123172214.73388814868755913546818338728120:50001231000000:2800:BF9DD998C7F2EDD010BDB4B6F7C62BF0882A2FB8B0E33D057E1A5B59230B272E.png?needInitFileName=true?needInitFileName=true)  
1. 使用室外高精度能力的开发者需要遵守国家法律法规与华为公司共同向国家有关部门申请高精度偏转插件的使用许可。
2. 室外高精度能力当前仅支持中国大陆地区的部分城市：深圳市、广州市、苏州市、杭州市、重庆市、成都市、天津市、东莞市（持续增加中），海外暂不支持。
