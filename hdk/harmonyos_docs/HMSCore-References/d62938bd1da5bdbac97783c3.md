# 查询维度值

## 功能介绍

您的应用服务器可以通过调用此接口查询指定维度的维度值。

## 场景描述

当您将华为分析开放指标呈现在您的运营报表时，如果需要基于某个维度对指标进行细分，您可以通过此接口查询指定维度的维度值。

## 使用约束

调用频率不超过5次/秒。

## 接口原型

|承载协议|HTTP POST|
|-----|-----------------------------------------------------------------------|
|接口方向|开发者服务器->分析服务服务器|
|接口URL|{rootUrl}/analytics/report/dimension/list/v1|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

**Request Header**

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-product-id|是|String|用户在AppGallery Connect上的Product ID。|
|x-app-id|是|String|用户在AppGallery Connect上的App ID。|
|Authorization|是|String|鉴权信息。请参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 > 说明 > Bearer后面拼接空格，再拼接获取的access_token。|

**Request Body**

|参数|是否必选|参数类型|描述|
|:----------|:---|:------|:--------------------------------------------------------------------------------------------|
|lang|是|String|语种标识，取值范围： * cn：中文 * en：英文 * ru：俄文 默认值："en"。|
|metric_name|是|String|指标值。|
|dim_name|是|String|查询的维度名称。 > 说明 > 查询维度值接口不直接返回event_id维度取值。对于event_id维度取值，为上报事件ID，可在"华为分析 > 管理 > 事件管理"页面查看事件ID。|
|size|否|Integer|查询每页最大记录数。默认10。|
|from|否|Integer|查询数据偏移量。默认0。|

## 请求示例

```screen
POST /analytics/report/dimension/list/v1 HTTP/1.1
Content-Type: application/json; charset=UTF-8
Accept: application/json
Authorization: Bearer 78C2395236BBF4262CAE4F1172E327C2929AD63EAA0395961A49DEBC3B6F8339 
x-product-id: sample-productid
x-app-id: sample-appid
 
{
    "lang":"cn",
    "metric_name":"retain_day_user_cnt_2day",
    "dim_name":"app_ver",
    "size":"10",
    "from":"0"
}
```

## 响应参数

**Response Header**

|参数|是否必选|参数类型|描述|
|:-----------|:---|:---------------|:---------|
|Content-Type|是|application/json|响应消息的数据格式。|

**Response Body**

|参数|是否必选|参数类型|描述|
|:----------|:---|:---------|:----------------------------------|
|result_code|是|String|响应码，请参见[错误码](#section195846692412)。|
|result_msg|是|String|响应描述。|
|dimension|否|DimValue[]|维度值信息。|

**DimValue结构体定义**

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:-------|
|value|是|String|维度值。|
|display_value|否|String|维度值展示文字。|

## 错误码

|状态码|错误码|描述|解决方法|
|:--|:----|:------------|:-------------|
|200|0|处理成功。|-|
|400|10020|非法参数。|请修改填写错误的参数值。|
|400|10008|接口请求过于频繁。|降低调用接口频次，稍后再试。|
|500|19910|内部处理错误，请稍后重试。|请稍后重试。|
