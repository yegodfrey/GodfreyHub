# LatLngBounds

使用一对经纬度坐标定义一个矩形区域。

|名称|类型|描述|
|:--------|:---------------------------------------------------------------------------------------------------------------|:--------|
|southwest|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|边界西南角的坐标。|
|northeast|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|边界东北角的坐标。|

## Methods

### LatLngBounds.contains

检查LatLngBounds对象是否包含指定的位置。

|参数|类型|描述|
|:----|:---------------------------------------------------------------------------------------------------------------|:-----|
|point|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|指定的位置。|

|返回类型|描述|
|:---|:---------------------------|
|bool|如果包含指定的位置，则返回true；否则返回false。|

调用示例：

```screen
// 定义一个LatLngBounds对象和一个LatLng对象。
LatLngBounds latLngBounds; 
LatLng latLng; 
 
// 传入LatLng来调用contains方法。
bool status = latLngBounds.contains(latLng);
```
