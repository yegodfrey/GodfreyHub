# 错误码

|错误码|值|描述|解决方法|
|:-----------|:----|:----|:---------------------------|
|OK|0|成功。|-|
|PARAM_ERROR|10001|参数错误。|请检查报错参数并修正。|
|SYSTEM_ERROR|50000|系统错误。|服务内部报错，您无法单方面处理，请联系华为技术支持解决。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
