# GeofenceRequest

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class GeofenceRequest implements Parcelable, IMessageEntity 地理围栏请求类，在调用[GeofenceRequest.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/geofencingrequest-builder-0000001050706138)类中的[build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/geofencingrequest-builder-0000001050706138#section428465112311)()方法时会返回一个该类型的实例。|

构建GeofenceRequest对象的示例代码如下：

```java
"Java"
GeofenceRequest.Builder builder = new GeofenceRequest.Builder();
builder.createGeofenceList(geofenceList);
builder.setInitConversions(5);
GeofenceRequest geofenceRequest = builder.build();
```

```java
"Kotlin"
val builder = GeofenceRequest.Builder()
builder.createGeofenceList(geofenceList)
builder.setInitConversions(5)
```
