# 请求参数说明

#### Coordinate

|参数|是否必选|类型|说明|
|:--------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------|
|lat|是|double|纬度，取值范围：\[-90, 90\] 。|
|lng|是|double|经度，取值范围：\[-180, 180\] 。|
|matchType|否|int|起终点是否限制绑路。 取值包括0和1，默认值为0: * 0：限制绑路。起点避免绑定封闭、施工、限行、偏好设置所避免道路，终点避免绑定高速、轮渡、偏好设置所避免道路。 * 1：无限制绑路，不考虑道路本身限制。 说明： matchType参数暂只适用Directions API。|

#### Condition

|参数|是否必选|类型|说明|
|:-------|:---|:-----|:--------------------------------------|
|name|是|String|条件名。|
|field|是|String|矢量数据的attribute名称。|
|operator|是|String|操作符，支持=、!=、\<、\>、\<=、\>=、like、not like。|
|value|是|String|取值。|

#### DataCfg

|参数|是否必选|类型|说明|
|:---------|:---|:------------------------------------|:-----------------------------------------|
|minZoom|是|integer|最小层级。|
|maxZoom|是|integer|最大层级。|
|bbox|否|String\[\]|切片范围，包括东南角和西北角的经纬度。|
|filter|否|[DataFilter](#section148841428195713)|矢量数据的过滤规则。|
|resampling|否|String|设置栅格数据重采样算法，取值包括： * average（默认） * bilinear|

#### DataFilter

|参数|是否必选|类型|说明|
|:---------|:---|:----------------------------------|:----------------------------|
|conditions|是|[Condition](#section1998435733)\[\]|矢量数据过滤条件。|
|logics|是|String|条件的逻辑关系，支持"or"、"and"、"("、")"。|

#### Fill

|参数|是否必选|类型|说明|
|:-------------|:---|:-------------|:-------------------------|
|strokeColor|否|String|描边颜色。|
|strokeWidth|否|integer|描边宽度，默认1。|
|strokeLineDash|否|Integer\[\]|描边虚线。|
|fillColor|否|String|填充颜色。|
|fillOpacity|否|number($float)|填充颜色透明度，取值范围：\[0, 1\]，默认1。|

#### Icon

|参数|是否必选|类型|说明|
|:------------|:---|:-------------|:--------------------------------------------------------------------------------------------------------|
|url|否|String|图标URL，必须是公网可以访问的地址。|
|anchor|否|String|Icon相对锚点方位：\[center, left, right, top, bottom, top-left, top-right, bottom-left, bottom-right\]，默认center。|
|scale|否|number($float)|Icon大小，取值范围：大于等于0，默认1。|
|opacity|否|number($float)|透明度，取值范围：\[0, 1\]。|
|color|否|String|填充颜色，默认#000000，仅支持SDF格式图片。|
|collisionSize|否|number($float)|Icon碰撞范围大小，单位：px，默认1。|

#### Label

|参数|是否必选|类型|说明|
|:-----------------|:---|:------|:------------------------------------|
|textField|否|String|标签内容，从瓦片中获取相应值，例如：textField: 'title'。|
|textSize|否|integer|字体大小，单位：px，取值范围：大于0，默认16。|
|offsetX|否|integer|文字的偏移X位置，默认0。|
|offsetY|否|integer|文字的偏移Y位置，默认0。|
|color|否|String|文字的填充颜色，默认#000000。|
|textOuterLineSize|否|integer|文字描边宽度，默认0。|
|textOuterLineColor|否|String|文字的描边颜色，默认rgba(0, 0, 0, 0)。|

#### LayerFeature

|参数|是否必选|类型|说明|
|:--------|:---|:---------------------------------|:--------------------------------------------------|
|dataId|是|String|数据ID。|
|featureId|是|String|特征ID。|
|layerType|否|String|矢量图的图层类型，取值包括: * scatterChart：点图层 * zoningChart：面图层|
|data|是|[DataCfg](#section15867164019524)|瓦片数据的编译规则。|
|point|否|[PointLayer](#section284116123814)|点图层。|
|zoning|否|[ZoningLayer](#section12051278133)|面图层。|

#### PointLayer

|参数|是否必选|类型|说明|
|:------------------|:---|:-----------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|visible|否|boolean|是否显示点图层。 * true：显示（默认） * false：隐藏|
|collisionEnabled|否|boolean|文字和图标是否开启碰撞。 * true：开启（默认） * false：关闭|
|symbolSortKey|否|String|features优先级。从瓦片里获取相应值，symbolSortKey值小的覆盖symbolSortKey值大的feature，例如：symbolSortKey: 'rank'。|
|multilingualOptions|否|Map|自定义图层多语言设置。如果未设置，使用Lable中textField值显示。 ``` { localCode: 'zh', zh: 'zh_name', en: 'en_name', fr: 'fr_name', } ``` localCode为必传项，其他字段为多语言名称和该语言对应显示的属性字段名称。 显示规则：根据当前设置语言，显示对应属性的值，如果当前没有设置语言对应的属性，显示localCode值所对应的属性。|
|zIndex|否|integer|压盖关系，值大的压盖值小的，默认0。|
|icon|否|[Icon](#section121404149618)|点图层的图标配置。|
|label|否|[Label](#section8301154816614)|点图层的文本配置。|

#### Segment

|参数|是否必选|类型|说明|
|:-----|:---|:-----------------------------------------|:---------------------------------------------------------|
|field|否|String|分段字段，从瓦片中获取相应值。|
|type|否|String|分段类型，取值包括：single或interval。|
|styles|否|[SegmentStyle](#section83271251122720)\[\]|分段样式SegmentStyle的fill与Segment的fill一致，但不支持strokeLineDash属性。|

#### SegmentStyle

|参数|是否必选|类型|说明|
|:-----|:---|:----------------------------|:--------------------------------------------------------------|
|factor|否|String|分段值。 * type是interval，取值为两个数字，使用逗号分隔。 * type是single，取值为字符串。|
|fill|否|[Fill](#section2093813317172)|面图层的填充配置，SegmentStyle的fill与Segment的fill一致，但不支持strokeLineDash属性。|

#### ZoningLayer

|参数|是否必选|类型|说明|
|:-----------|:---|:-------------------------------|:------------------------------------------------------------------------|
|visible|否|boolean|是否显示面图层。 * true：显示（默认） * false：隐藏|
|fillSortKey|否|String|面优先级，从瓦片里获取相应值，fillSortKey值大的覆盖fillSortKey值小的fill，例如：fillSortKey: 'rank'。|
|zIndex|否|integer|压盖关系，值大的压盖值小的，默认0。|
|fill|否|[Fill](#section2093813317172)|面图层的填充配置。|
|segmentStyle|否|[Segment](#section5568134261710)|面图层的分段样式。|
