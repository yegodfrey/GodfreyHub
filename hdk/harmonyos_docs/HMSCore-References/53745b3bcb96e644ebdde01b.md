# AccountAuthService

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Interface Info|
|:-------------------------------------------|
|public interface AccountAuthService 帐号登录客户端。|

## Public Methods

### silentSignIn

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [Task](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-account-task-tresult-0000001163095881)<[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-account-result-authaccount-0000001163061337)> silentSignIn() 静默登录接口。 1. 如果华为帐号已经登录，之前没有授权过此应用，此次则为首次授权，将会拉起授权页面。如果用户同意授权，则登录成功，此接口将返回执行成功；如果用户取消授权，此接口将返回执行失败。首次授权过后，再次调用此接口无需拉起授权页面，将会直接静默登录成功，提升用户体验。 2. 如果帐号没有登录，此接口将执行失败。|

**Returns**

|Type|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[Task](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-account-task-tresult-0000001163095881)<[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-account-result-authaccount-0000001163061337)>|用来获取[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-account-result-authaccount-0000001163061337)或者[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-accountsdk-exception-apiexception-0000001117192584)的Task，通过在Task中设置回调来处理异步结果。 在接口返回的Task中需要设置两个回调监听： * 使用[OnSuccessListener](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-account-task-onsuccesslistener-0000001163095879)可以获取到成功场景返回的数据，如果静默登录成功，在结果中能够获取登录成功的华为帐号的信息，即AuthAccount对象。 * 使用[OnFailureListener](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-account-task-onfailurelistener-0000001116416004)可以获取到此次请求失败的相关信息。在OnFailureListener中需要判断该方式回调的异常对象是否是一个ApiException实例对象，然后根据ApiException实例对象中包含的[getStatusCode](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-accountsdk-exception-apiexception-0000001117192584#section1889231710519)()进行一些必要错误场景的处理。|
