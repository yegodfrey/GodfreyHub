# 错误码

|错误码|值|描述|解决方法|
|:---------|:--|:--------------------------------------------------|:----------------|
|NSP_STATUS|500|调用接口出错。|根据错误描述进行处理。|
|NSP_STATUS|6|Access Token正常过期。|重新获取Access Token。|
|NSP_STATUS|102|Access Token无效，如因用户修改密码而被加入禁用清单，或Access Token格式不对等。|重新获取Access Token。|
|NSP_STATUS|1|未知错误。|-|
