# 请求补差退款

#### 功能介绍

开发者可以调用该接口对已完成补差的订单请求补差退款。  
![](https://media:201774590625604571)  
1. 补差退款以原补差订单为依据，支持多次回退，申请回退总金额不能超过补差金额。
2. 该接口会直接返回处理结果并支持幂等，相同请求参数只会退款一次，重复请求可视为补差退款订单查询。
3. 系统异常（如返回UNKNOW_ERROR），请务必稍后再使用相同参数重新调用此接口，如更换金额可能会导致重复补差退款。  

#### 使用约束

换单重试，视为新的业务订单，需开发者自行将新的业务订单关联业务原订单。接口重入规则说明如下（供参考）：  

|重入判定字段|支持原单重入场景|建议换单重试场景|
|:-----------------------------------|:---------------------------------------------------------------------------|:--------------------------------------------------------------------|
|商户补差退款订单号 （mercSubsidyRefundOrderNo）|1. 请求补差接口失败，建议使用原补差退款订单号重入，避免可能出现重复补差退款等异常问题。 2. 请求补差接口成功，原补差退款订单号重入，接口幂等返回。|1. 多次补差退款场景下，每次需要换单后发起请求。 2. 补差退款状态为FAILED，则订单进入失败终态。如需重新补差回退，需要换单重试。|

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/partner/subsidies/refund|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------|

#### 请求参数

* Request Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|

* Request Body  

  |参数|是否必选|类型|说明|
  |:-----------------------|:---|:------|:-------------------|
  |subMercNo|是|String|收单商户号。|
  |sysSubsidyTransOrderNo|是|String|华为支付系统补差订单号。|
  |subsidyRefundAmount|是|Integer|补差退款金额，单位分。|
  |subsidyRefundRemark|否|String|补差退款附言（账单字段），最大长度64。|
  |mercSubsidyRefundOrderNo|是|String|商户补差退款订单号，最大长度64。|

#### 响应参数

* Response Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

* Response Body  

  |参数|是否必选|参数类型|描述|
  |:---------------------------|:---|:------|:--------------------------------------------|
  |resultCode|是|String|返回码，"000000"表示成功，其他表示见错误码。|
  |resultDesc|是|String|结果描述。|
  |subCode|否|String|业务错误码。|
  |subDesc|否|String|业务错误描述信息。|
  |sign|是|String|签名值。用于开发者对响应报文进行防篡改验证。|
  |subMercNo|否|String|收单商户号。|
  |sysSubsidyTransOrderNo|否|String|华为支付系统补差订单号。|
  |subsidyRefundAmount|否|Integer|补差退款金额，单位分。|
  |subsidyRefundRemark|否|String|补差附言（账单字段），最大长度64。|
  |mercSubsidyRefundOrderNo|否|String|商户补差退款订单号，最大长度64。|
  |subsidyRefundStatus|否|String|补差退款状态。 * SUCCESS：成功 * FAILED：失败 * APPLY：申请状态|
  |sysSubsidyRefundTransOrderNo|否|String|华为支付系统补差退款订单号，最大长度64。|
