# HwCheckBox

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HwCheckBox extends CheckBox 该类是华为风格的多选框，继承了原生的CheckBox（动画限定在API 23及以上版本，在layout-television布局和layout Normal风格中，当多选框不带文本时，需要配置paddingStart为0保证图标样式居中）。|
