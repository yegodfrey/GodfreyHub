# 退款成功后通知（应用外支付）

#### 功能描述

当教育中心客户端的课程类商品完成订单退款后，华为服务器调用此接口通知开发者服务器解除订购关系。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 开发者服务器|
|接口URL|URL为您在配置课程时配置的[退款通知地址](https://developer.huawei.com/consumer/cn/doc/distribution/content/educenter-basic-0000001050822889#section1586818217119)。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------|

#### 使用约束

退款功能当前仅支持教育中心客户端的课程类商品，且您在配置课程时需[配置退款通知地址](https://developer.huawei.com/consumer/cn/doc/distribution/content/educenter-basic-0000001050822889#section1586818217119)。  

#### 请求参数

|参数|是否必选|参数类型|描述|
|:---|:---|:----------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|data|是|[UnsubsribeNotifyRequest](#ZH-CN_TOPIC_0000001197220319__p175161730874)|通知解除订购关系的请求信息。 注意： data中的参数顺序为每一个参数ASCII码的升序排序，若遇到相同首字母，则比较第二个字母，以此类推。请将data中的参数顺序调整为以上顺序，否则可能会导致验签失败。|
|sign|是|String|华为服务器在发送通知时对data中的所有参数使用SHA256WithRSA/PSS算法进行了签名，并在sign参数中返回签名后的字符串。 您需要[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/get-public-key-0000001050164350)，并根据加密算法使用公钥对签名字符串进行验签。|

UnsubsribeNotifyRequest  

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------|
|developerId|是|String|开发者帐号的CP ID，用于唯一标识当前开发者。|
|orderId|是|String|华为的业务订单号，与[申请退款](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit-outiap-refund-0000001197299667)时传入的orderId一致。|
|payOrderId|是|String|支付订单号，与[申请退款](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit-outiap-refund-0000001197299667)时传入的payOrderId一致。|
|openId|是|String|用户的唯一标识。 如果您使用unionId作为用户唯一标识，在获取openId后可根据openId和unionId的对应关系自行映射。|
|appId|是|String|应用ID。|
|productNo|是|String|已退款的商品ID。|
|ts|是|Long|发送退款成功通知的时间戳。|

#### 请求示例

```
POST {第三方应用服务器url} HTTP/1.1
Content Type : application/json ; charset=UTF-8
{
  "data": {
      "developerId": "234234234",
      "orderId": "sdfsfff32324324234234",
      "payOrderId": "xxxxxxxxxxxxxxxx",
      "openId": "openId13123",
      "appId": "1231333",
      "productNo": "product344",
      "ts": "12312313123131123"
  },
  "sign": "xxxxxxxxxxxxxxxxxxxxxxxx"
}
```

#### 响应参数

|参数名称|是否必选|参数类型|描述|
|:----|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------|
|error|否|String|处理失败时包含操作结果的JSON字符串，格式为"{"errorCode": xxx, "errorMsg": xxxx}"。 * errorCode：[错误码](#section884534381211) * errorMsg：错误码对应的描述信息。|
|data|否|String|处理成功时包含操作结果的JSON字符串，格式为"{"result": 0}"。0表示处理成功。|

#### 响应示例

```
HTTP/1.1 200 OK
Content Type : application/json ; charset=UTF-8
{
   "error": {
       "errorCode": 0,
       "errorMsg": "string"
    }
}
or
{
   "data": {
       "result": 0
    }
}
```

#### 错误码

|错误码|说明|
|:--|:-----------------|
|1|验签失败。|
|2|超时。|
|3|业务信息错误，例如报文无法解析。|
|4|IP允许清单限制，开发者侧拒绝服务。|
|11|商品不存在。|
|12|用户不存在|
|13|订单不存在|
|94|系统错误。|
|95|IO错误。|
|96|错误的请求URL。|
|97|错误的响应。|
|98|参数错误。|
|99|其他错误。|
