# Polyline

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class Polyline 折线是一个点列表，其中线段在连续点之间绘制。在调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)类的[addPolyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582#section527091714515)方法时会返回该类型的实例。|

|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[remove](#section193591012413)() 从地图中删除此折线。|

#### Public Methods

#### remove

|Method|
|:-------------------------------------------------|
|public void remove() 从地图中删除此折线。删除折线后，其所有方法的行为都会消失。|

#### setPoints

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setPoints(List\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535)\> points) 您调用此API可以设置折线的顶点坐标，默认在折线终点到设置坐标点间生成一条直线。|

Parameters  

|Name|Description|
|:-----|:--------------------------------------|
|points|折线顶点的集合。默认情况下，折线不闭合；要形成闭合的折线，起点和终点必须相同。|

#### setColor

|Method|
|:------------------------------------------------|
|public void setColor(int color) 您调用此API可以设置折线的颜色。|

Parameters  

|Name|Description|
|:----|:----------------------------|
|color|ARGB格式颜色值，默认值为黑色（0xff000000）。|

#### setWidth

|Method|
|:--------------------------------------------------|
|public void setWidth(float width) 您调用此API可以设置折线的宽度。|

Parameters  

|Name|Description|
|:----|:---------------------------------------------------------------------|
|width|折线的宽度，单位：像素。取值范围：大于等于0，默认为10像素。 说明： 为兼容性考虑，此接口推荐设置的折线实际宽度为设置值width的三倍。|

Throws  

|Name|Description|
|:-----------------------|:---------------|
|IllegalArgumentException|当传入的宽度width是负数时。|

#### setGeodesic

|Method|
|:---------------------------------------------------------------------------------------|
|public void setGeodesic(boolean geodesic) 您调用此API可以设置是否将折线的每个线段绘制为大地线。如果未设置，则返回默认值false。|

Parameters  

|Name|Description|
|:-------|:------------------------------|
|geodesic|* true：每段绘制为大地线。 * false：不是大地线。|

#### setJointType

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setJointType(int jointType) 设置折线除起始和结束顶点之外的所有顶点的节点类型，有关允许的值，请参见[JointType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-jointtype-0000001121983512)。如果节点类型未定义或不是允许值之一，则将使用默认值[DEFAULT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-jointtype-0000001121983512#section103572813326)。|

Parameters  

|Name|Description|
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|jointType|节点类型，默认值为[DEFAULT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-jointtype-0000001121983512#section103572813326)。|

#### setVisible

|Method|
|:------------------------------------------------------------------------|
|public void setVisible(boolean visible) 设置折线的可见性。如果折线不可见，则不会绘制，其他所有状态均保留。|

Parameters  

|Name|Description|
|:------|:---------------|
|visible|折线的可见性，默认值为true。|

#### setClickable

|Method|
|:--------------------------------------------------------------|
|public void setClickable(boolean clickable) 您调用此API可以设置折线的可点击性。|

Parameters  

|Name|Description|
|:--------|:---------------------------------------|
|clickable|可点击性。 * true：可点击 * false：不可点击 默认值为false。|

#### setZIndex

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setZIndex(float zIndex) 用于设置折线的z指数。z指数指的是折线的叠加顺序，具有较大z指数的折线会绘制在具有较小z指数的折线上，具有相同z指数的叠加顺序为元素添加的先后顺序。 说明： 数量限制：添加Circle和Polygon的总数乘以2加上添加Polyline和GroundOverlay的总数不超过1450，否则会出现图形叠加错误。|

Parameters  

|Name|Description|
|:-----|:---------------------|
|zIndex|z指数，即折线的叠加顺序。默认的z指数是0。|
