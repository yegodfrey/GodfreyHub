# 导入自定义用户属性

## 功能介绍

应用服务端调用此接口后，能够同步应用服务端计算的自定义用户属性，用于基于用户自定义属性的分析及受众管理。

## 场景描述

* 当您的应用服务器自行计算了一些用户属性，而不是在App端侧直接获取用户属性，同时您又希望将这些用户属性应用到高级分析提供的各种分析报告中（如作为查看报告时的一个过滤条件），您可以在其应用服务器调用此接口，通过服务端上报其自行计算的用户属性。
* 通过App端侧上报了用户属性以后，当您发现用户属性有修改，可调用此接口修改用户属性。

## 使用约束

* 每次请求中，userDataSet可以最多携带100个用户的信息。
* 在App端侧上报事件时已通过[setUserId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section11961041191220)接口设置了用户ID，且在本接口中设置的id与[setUserId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section11961041191220)设置的id一致，上报的自定义用户属性才可以在分析服务中生效。
* 您可以通过移动端SDK上报的自定义用户属性、也可以通过服务端同步的自定义用户属性，累计可以上报不超过25个自定义用户属性。服务端同步自定义用户属性时，需要考虑端侧已经上报了多少个自定义用户属性，服务端同步自定义用户属性数时，不能超过可用配额上限。
* 如果有某个自定义用户属性既通过移动端上报、也通过服务端同步，则以服务端同步的自定义用户属性值为准。
* 需要确保未将用户的个人数据作为自定义用户属性进行同步。
* 每秒请求数不超过100。

## 接口原型

|承载协议|HTTPS POST|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者回调接口服务器->分析服务服务器|
|接口URL|{rootUrl}/analytics/datacollection/import/user > 说明 > {rootUrl}：请参见[接口访问路径获取](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-common-interface-description-0000001050707180#section777183816123)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

**Request Header**

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-product-id|是|String|用户在AppGallery Connect上的Product ID。|
|x-app-id|是|String|用户在AppGallery Connect上的App ID。|
|Authorization|是|String|鉴权信息。请参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 > 说明 > Bearer后面拼接空格，再拼接获取的access_token。|

**Request Body**

|参数|是否必选|参数类型|描述|
|:-----------|:---|:----------------|:--------------------|
|data_type|是|Integer|自定义用户属性的数据类型。 固定填写为1。|
|userdata_set|是|UserData[1...100]|待导入的用户及属性列表。|

**UserDataSet数据结构说明**

|参数|是否必选|参数类型|描述|
|:---------|:---|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|id|是|String|匿名化用户标识，在华为分析服务侧通过此标识关联用户数据。只有您可以使用该标识符追溯到具体用户，分析系统无法使用您设置的**id**追溯到具体用户。 非空，长度不超过256字符。 > 说明 > 设置**id** 时，需要遵守[分析服务协议](https://developer.huawei.com/consumer/cn/doc/distribution/app/20212)，避免使用能标识个人身份信息的原始**id** ，且此处配置的**id** 须与端侧SDK的[setUserId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section11961041191220)接口中配置的**id**一致。|
|properties|是|UserProperty[1...25]|用户属性列表。|

**UserProperty数据结构说明**

|参数|是否必选|参数类型|描述|
|:----|:---|:-----|:---------------------------------------------------------|
|id|是|String|用户属性的ID，由数字、字母、下划线组合成，且不能以数字开头，1-256个字符。例如：favorite_sport。|
|value|是|String|用户属性值，1-256个字符。例如：football。|

## 请求示例

```screen
POST /analytics/datacollection/import/user HTTP/1.1
Content-Type: application/json; charset=UTF-8
Content-Length: xxxx
Accept: application/json
Authorization: Bearer *** 
x-product-id: sample-productid
x-app-id: sample-appid
 
{
    "data_type": 1, 
    "userdata_set": [
        {
            "id": "123", 
            "properties": [
                {
                    "id": "favorite_sport", 
                    "value": "football"
                }, 
                {
                    "id": "vip_users", 
                    "value": "true"
                }
            ]
        }, 
       {
            "id": "456", 
            "properties": [
                {
                    "id": "favorite_sport", 
                    "value": "basketball"
                }, 
                {
                    "id": "vip_users", 
                    "value": "false"
                }
            ]
        }
    ]
}
```

**Response Header**

|参数|是否必选|参数类型|描述|

**Response Body**
