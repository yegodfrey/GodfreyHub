# DataController

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------|
|public class DataController 数据管理的接口定义，用户可通过该接口插入、删除、 修改和读取数据，同时支持对当天、历史天统计等特性化查询。 开发者可以通过HuaweiHiHealth类获取到DataController。|

获取DataController对象的示例代码如下：

```screen
"Java"
// 获取dataController对象
// 请注意此处的this为Activity对象
DataController dataController = HuaweiHiHealth.getDataController(this);
```

```screen
"Kotlin"
// 获取dataController对象
// 请注意此处的this为Activity对象
val dataController = HuaweiHiHealth.getDataController(this)
```

## Public Methods

### clearAll()

|Method|
|:---------------------------------------------------------------------------|
|public Task<Void> clearAll() 清除本应用插入的所有Health Service Kit Android侧和REST侧的数据。|

**Return** **s**

|Type|Description|
|:---------|:------------------------|
|Task<Void>|用来检查请求是否成功、失败、已完成的Task对象。|

示例代码如下：

```screen
"Java"
// 1. 调用clearAll接口， 清除本应用插入的所有Health Service Kit Android侧和REST侧的数据 
Task<Void> clearTask = dataController.clearAll(); 
 
// 2. 调用clearAll接口清空所有的用户数据是异步操作，需要设置成功或失败listener，返回清空成功或失败 
clearTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
    @Override 
    public void onSuccess(Void result) { 
        logger("clearAll success"); 
    } 
}).addOnFailureListener(new OnFailureListener() { 
    @Override 
    public void onFailure(Exception e) { 
        String errorCode = e.getMessage(); 
        Pattern pattern = Pattern.compile("[0-9]*"); 
        Matcher isNum = pattern.matcher(errorCode); 
        if (isNum.matches()) { 
            String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode)); 
            logger("clearAll failure " + errorCode + ":" + errorMsg); 
        } else { 
            logger("clearAll failure " + errorCode); 
        } 
    } 
});
```

### delete(DeleteOptions options)

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public Task<Void> delete([DeleteOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/do_class-0000001050091172) options) 删除插入的数据采样集，数据采样集包括指定时间范围的数据、全部数据和运动记录。|

**Parameters**

|Name|Description|
|:------|:---------------------------------------|
|options|DeleteOptions类型，指定要删除数据的数据采集器、数据类型和时间范围。|

**Return** **s**

|Type|Description|
|:---------|:------------------------|
|Task<Void>|用来检查请求是否成功、失败、已完成的Task对象。|

删除插入的数据采样集的示例代码如下：

```screen
"Java"
// 构造删除条件：一个数据采集器对象 
DataCollector dataCollector = new DataCollector.Builder().setPackageName(getApplicationContext()) 
    .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA) 
    .setDataStreamName("STEPS_DELTA") 
    .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
    .build(); 
 
// 构造删除条件时间区间：开始，结束时间 
SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss"); 
Date startDate = null;
Date endDate = null;
try {
    // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳。删除满足时间戳范围内的数据点，时间戳不涉及时区
    startDate = dateFormat.parse("2020-03-17 09:00:00");
    endDate = dateFormat.parse("2020-03-17 09:05:00");
} catch (ParseException exception) {
    logger("Time parsing error");
}
 
// 构造条件删除的参数对象 
DeleteOptions deleteOptions = new DeleteOptions.Builder().addDataCollector(dataCollector) 
    .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS) 
    .build(); 
 
// 使用指定的条件删除对象，调用delete接口删除数据样本集 
Task<Void> deleteTask = dataController.delete(deleteOptions); 
 
// 调用delete接口删除样本集合数据是异步操作，需要设置成功或失败listener标识，返回数据删除成功或失败 
deleteTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
    @Override 
    public void onSuccess(Void result) { 
        logger("Sample data is successfully deleted from the HMS core."); 
    } 
}).addOnFailureListener(new OnFailureListener() { 
    @Override 
    public void onFailure(Exception e) { 
        Log.i("DataController","Failed to delete sample data from HMS core" + e.getMessage());
    } 
});
```

|public Task<Void> insert([SampleSet](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/sampleset_class-0000001050164521) sampleSet) 将数据采样集插入到Health Service Kit。|

**Parameters**

插入数据采样集的示例代码如下：

```screen
"Java"
// 1. 构造一个数据采集器对象 
DataCollector dataCollector = new DataCollector.Builder().setPackageName(getApplicationContext()) 
    .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA) 
    .setDataStreamName("STEPS_DELTA") 
    .setDataGenerateType(DataCollector.DATA_TYPE_RAW) 
    .build(); 
 
// 2. 根据数据采集器，创建一个数据采样集 
final SampleSet sampleSet = SampleSet.create(dataCollector); 
 
// 3. 构造步数增量（DT_CONTINUOUS_STEPS_DELTA）一个采样点的开始，结束时间 
SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss"); 
Date startDate = null;
Date endDate = null;
try {
    // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳，时间戳不涉及时区
    // 请注意插入的运动健康数据的采样点数据的结束时间需大于2014年1月1号对应的UNIX时间戳
    startDate = dateFormat.parse("2020-03-17 09:00:00");
    endDate = dateFormat.parse("2020-03-17 09:05:00");
} catch (ParseException exception) {
    logger("Time parsing error");
}
int stepsDelta = 200; 
 
// 4. 构造一个步数增量（DT_CONTINUOUS_STEPS_DELTA）采样点 
SamplePoint samplePoint = sampleSet.createSamplePoint() 
    .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS); 
samplePoint.getFieldValue(Field.FIELD_STEPS_DELTA).setIntValue(stepsDelta); 
// 若写入的步数数据需要在运动健康App首页上展示，需要使用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/samplepoint_class-0000001050164515#section67423170142对采样点添加如下元数据
samplePoint.addMetadata("motion_type", "RUN");
 
// 5. 可以将一个步数增量采样点添加到数据采样集，也可以重复执行3 ~ 5添加多个样本点数据到样本集合 
sampleSet.addSample(samplePoint); 
 
// 6. 调用insert接口，将数据采样集插入到Health Service Kit
Task<Void> insertTask = dataController.insert(sampleSet); 
 
// 7. 调用insert接口写入样本集合数据是异步操作，需要设置成功或失败listener标识，返回数据写入成功或失败
insertTask.addOnSuccessListener(new OnSuccessListener<Void>() { 
    @Override 
    public void onSuccess(Void result) { 
        logger("Successfully insert a SampleSet into HMS core"); 
        showSampleSet(sampleSet); 
    } 
}).addOnFailureListener(new OnFailureListener() { 
    @Override 
    public void onFailure(Exception e) { 
        Log.i("DataController","Failed to insert a SampleSet into HMS core" + e.getMessage());
    } 
});
```

### read(ReadOptions readOptions)

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public Task<[ReadReply](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/readreply-0000001050093471)> read([ReadOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ro_class-0000001050091216) readOptions) 读取用户数据的接口，可通过设置ReadOptions的参数，读取不同时间、设备、数据采集源等维度的数据。|

**Parameters**

|Name|Description|
|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|readOptions|ReadOptions类型，读取数据的请求参数选项，用于指定数据采集器、数据类型以及查询数据的时间范围等条件，具体可参考[ReadOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ro_class-0000001050091216)的定义。|

**Return** **s**

|Type|Description|
|:------------------------------------------------------------------------------------------------------------|:----------------------------------|
|Task<[ReadReply](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/readreply-0000001050093471)>|返回读取数据，返回满足开始时间或者结束时间在指定查询时间段内的数据点。|

读取用户数据的示例代码如下：

```screen
"Java"
// 1. 构造查询条件时间区间：开始，结束时间 
SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss"); 
Date startDate = null;
Date endDate = null;
try {
    // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳。查询时间戳范围的数据点，时间戳不涉及时区
    startDate = dateFormat.parse("2020-03-17 09:00:00");
    endDate = dateFormat.parse("2020-03-17 09:05:00");
} catch (ParseException exception) {
    logger("Time parsing error");
}
 
// 2. 构造条件查询的查询对象 
// 以下示例为步数详情数据类型为例（DT_CONTINUOUS_STEPS_DELTA），读取指定时间范围内的步数数据
// 如果需要读取其他类型的最新数据点，请开发者自行添加对应的数据类型
ReadOptions readOptions = new ReadOptions.Builder().read(DataType.DT_CONTINUOUS_STEPS_DELTA) 
    .setTimeRange(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS) 
    .build(); 
 
// 3. 使用指定的条件查询对象，调用read接口查询数据样本集 
Task<ReadReply> readReplyTask = dataController.read(readOptions); 
 
// 4. 调用read接口查询样本集合数据是异步操作，需要设置成功或失败listener，返回数据查询成功或失败 
readReplyTask.addOnSuccessListener(new OnSuccessListener<ReadReply>() { 
    @Override 
    public void onSuccess(ReadReply readReply) { 
        logger("Successfully read a SampleSet from HMS core"); 
        for (SampleSet sampleSet : readReply.getSampleSets()) { 
            showSampleSet(sampleSet); 
        } 
    } 
}).addOnFailureListener(new OnFailureListener() { 
    @Override 
    public void onFailure(Exception e) { 
        Log.i("DataController","Failed to read a SampleSet from HMS core" + e.getMessage());
    } 
});
```

    // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳。查询时间戳范围的数据点，时间戳不涉及时区

    .setTimeRange(startDate!!.time, endDate!!.time, TimeUnit.MILLISECONDS)
    .build()

// 3. 使用指定的条件查询对象，调用read接口查询数据样本集

readReplyTask!!.addOnSuccessListener { readReply ->
    logger("Successfully read a SampleSet from HMS core")
    for (sampleSet in readReply.sampleSets) {
        showSampleSet(sampleSet)
    }
}!!.addOnFailureListener { e -> logger(e.toString()) }
