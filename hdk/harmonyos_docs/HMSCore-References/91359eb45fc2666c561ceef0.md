# AdsBanner

## 概述

Banner广告组件。

## 参数

|参数|是否必选|类型|描述|
|:----------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|slotId|是|String|广告位ID。|
|deviceType|否|number|设备类型。 * PHONE：手机 * TABLET：平板 默认值：PHONE，详细取值请参见[DeviceType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section545534453916)。|
|width|是|number|广告尺寸[宽度](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-createbannerad-0000001179593165#section455613917416)，单位：px。|
|height|是|number|广告尺寸[高度](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-createbannerad-0000001179593165#section455613917416)，单位：px。|
|refreshTime|否|number|Banner广告的自动刷新时间间隔，单位：s。 取值范围：[30, 120]。|

## 方法

|方法|描述|参数|返回值|
|:------------------|:--------|:-----------------------------------------------|:--|
|load()|加载广告。|-|-|
|onAdLoad(callback)|广告加载成功监听。|callback：广告加载成功的回调函数。|-|
|onAdError(callback)|广告加载失败监听。|callback：素材加载失败携带错误码的回调函数，callback的参数为errorcode。|-|
