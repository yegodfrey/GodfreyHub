# 合单支付结果回调通知

## 功能介绍

用户支付完成后，华为支付服务器调用此接口向商户服务器发送支付关键事件通知。

> 说明
>
> 1. 为保证回调请求的可靠性，系统具备重试机制，所以可能出现重发的通知。
> 2. 订单状态需根据orderStatus字段判断。

## 接口原型

|承载协议|HTTPS POST|
|-----|-----------------------------------------------------------------------|
|接口方向|华为支付服务器 -> 开发者服务器|
|接口URL|URL由开发者在请求预下单接口时传的主单callbackUrl|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

* **Request Body**

  |参数|是否必选|参数类型|描述|
  |:----------------------|:---|:------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------|
  |callbackId|是|String|回调通知的唯一ID。|
  |callbackTime|是|String|回调通知时间。|
  |dataType|是|String|数据加密类型标识。 * encrypt：加密 * plain：未加密|
  |sign|是|String|回调通知结果签名，除"sign"字段以外的其他字段参与签名。|
  |signType|是|String|签名类型。华为支付生成签名字符串使用的算法，当前为SM2算法。|
  |certNo|否|String|签名所使用的证书编号。|
  |combinedMercNo|否|String|商户号。|
  |combinedAppId|否|String|商户申请并关联的应用ID。|
  |combinedSysTransOrderNo|是|String|华为支付合单支付主订单号。|
  |combinedMercOrderNo|是|String|商户生成的合单支付主订单号。|
  |orderStatus|否|String|订单状态。 * TRX_SUCCESS：交易成功 * TRX_FAILED：交易失败|
  |payload|是|String|预留信息，如商户请求时传递该参数，此时会原样返回。|
  |subOrders|是|List<[SubOrderResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section883324283110)>|子单交易结果详情。|
  |payer|否|[PayerOut](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section14195124713166)|用户支付时客户端信息。|

## 响应参数

* **Response Header**

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|


* **Response Body**

  |参数|是否必选|参数类型|描述|
  |:---------|:---|:-----|:-----------------------------------------------------------------------|
  |resultCode|是|String|华为支付侧解析application/json类型响应，"000000"表示成功，其他值失败，如返回值格式不匹配或非"000000"将视为失败。|
  |resultDesc|是|String|结果描述。|


* **响应示例**

  ```screen
  HTTP/1.1 200 OK
  Content-Type: application/json; charset=UTF-8
  {
    "resultCode": "000000",
    "resultDesc": "Success."
  }
  ```
