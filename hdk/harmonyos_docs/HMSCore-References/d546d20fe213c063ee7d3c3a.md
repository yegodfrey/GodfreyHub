# HuaweiMap.OnMyLocationButtonClickListener

|Interface Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface HuaweiMap.OnMyLocationButtonClickListener 是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)类的一个内部接口，表示"我的位置"按钮点击事件的侦听器，包含一个抽象函数[onMyLocationButtonClick](#section2082520410519)()。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------|
|abstract boolean|[onMyLocationButtonClick](#section2082520410519)() 点击我的位置按钮时的回调方法。|

#### Public Methods

#### onMyLocationButtonClick

|Method|
|:--------------------------------------------------------------------------|
|public abstract boolean onMyLocationButtonClick() 点击我的位置按钮时的回调方法。必须在主线程中调用。|

Returns  

|Type|Description|
|:------|:-----------------------------------------------------------------------|
|boolean|如果侦听器已经消耗了该事件（即不发生默认行为），返回true，否则（即发生默认行为），返回false。默认行为是相机移动，使其以用户位置为中心。|
