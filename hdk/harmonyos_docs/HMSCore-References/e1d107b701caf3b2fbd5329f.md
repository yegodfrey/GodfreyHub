# 查询统计指标

#### 功能介绍

您的应用服务器可以通过调用此接口查询开放的指标和维度对应的统计报告信息。  

#### 场景描述

当您需要将华为分析计算的指标呈现于您的运营报表时，可以通过此接口指定查询的指标、过滤条件、细分维度，华为分析将根据您指定的条件提供对应的指标值。  

#### 使用约束

调用频率不超过5次/秒。  

#### 接口原型

|承载协议|HTTP POST|
|接口方向|开发者服务器-\>分析服务服务器|
|接口URL|{rootUrl}/analytics/report/metrics/v1|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-product-id|是|String|用户在AppGallery Connect上的Product ID。|
|x-app-id|是|String|用户在AppGallery Connect上的App ID。|
|Authorization|是|String|鉴权信息。请参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|

Query Parameter  

|参数|是否必选|参数类型|描述|
|:--------|:---|:------|:--------------|
|size|否|Integer|查询每页最大记录数。默认10。|
|curr_page|否|Integer|查询起始页。默认1。|

Request Body  

|参数|是否必选|参数类型|描述|
|:---------|:---|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|metric|是|String|查询的指标名称。|
|dimensions|是|String\[\]|查询的维度列表。 说明： * pt_d表示日期维度，一般dimensions传pt_d，表示在start_date和end_date期间返回每一天对应的指标值。例如："dimensions":\["pt_d"\] * metric传留存相关指标时，dimensions必须传pt_d，且pt_d必须填写在第一个值中。|
|start_date|否|String|起始日期，格式yyyy-MM-dd。默认为请求发生当日。|
|end_date|否|String|截止日期，格式yyyy-MM-dd。默认为请求发生当日。|
|filters|否|Filter|过滤条件。 说明： 接口默认查询的指标统计报告为项目级别，如果需要查询应用级别，需要在此参数中添加一个app_id的维度过滤器。|
|orderby|否|OrderBy|排序条件。|

Filter结构体定义  

|参数|是否必选|参数类型|描述|
|:---------|:---|:------------|:---------------------------------------|
|operator|否|String|操作符。取值如下： * OR（暂不支持） * AND 填写多个过滤条件时，必填。|
|conditions|是|Condition\[\]|过滤条件。|

Condition结构体定义  

|参数|是否必选|参数类型|描述|
|:-------------|:---|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|dimension_name|是|String|维度名称。|
|operator|是|String|操作符，支持列表如下： * EQUAL：等于 * GT：大于 * LT：小于 * LE：小于等于 * GE：大于等于 * NOTEQUAL：不等于 * IN：包含 * ISNULL：等于NULL * ISNOTNULL：不等于NULL * NOTIN：不包含 说明： dimension_name传app_id时，operator仅支持填写"EQUAL"或"IN"。|
|values|是|String\[\]|过滤条件值列表。|

OrderBy结构体定义  

|参数|是否必选|参数类型|描述|
|:--------|:---|:------|:--------------------------------|
|name|是|String|维度或指标名称。|
|type|是|Integer|排序类型，支持按维度或指标排序。 * 0：指标 * 1：维度|
|direction|是|String|排序方向： * ASC：升序 * DESC：降序 默认按升序排序。|

#### 请求示例

```
项目级别：
POST /analytics/report/metrics/v1?size=2&curr_page=1 
Content-Type: application/json; charset=UTF-8
Content-Length: xxxx
Accept: application/json
Authorization: Bearer 78C2395236BBF4262CAE4F1172E327C2929AD63EAA0395961A49DEBC3B6F8339 
x-product-id: sample-productid
x-app-id: sample-appid
 
{
    "metric":"active_distinct_user_cnt",
    "dimensions":["pt_d"],
    "start_date":"2021-03-01",
    "end_date":"2021-04-13",
    "orderby":{
        "name":"pt_d",
        "type":"1",
        "direction":"ASC"
    }
}

应用级别：
POST /analytics/report/metrics/v1?size=2&curr_page=1 
Content-Type: application/json; charset=UTF-8
Content-Length: xxxx
Accept: application/json
Authorization: Bearer 78C2395236BBF4262CAE4F1172E327C2929AD63EAA0395961A49DEBC3B6F8339 
x-product-id: sample-productid
x-app-id: sample-appid
 
{
    "metric": "active_distinct_user_cnt", 
    "dimensions": ["pt_d"], 
    "start_date": "2021-03-01", 
    "end_date": "2021-04-13", 
    "filters": {
        "operator": "AND", 
        "conditions": [
            {
                "dimension_name": "app_id", 
                "operator": "EQUAL", 
                "values": ["10****945"]
            }
        ]
    }, 
    "orderby": {
        "name": "pt_d", 
        "type": "1", 
        "direction": "ASC"
    }
}
```

#### 响应参数

Response Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:---------------|:---------|
|Content-Type|是|application/json|响应消息的数据格式。|

Response Body  

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:----------------------------------|
|result_code|是|String|响应码，请参见[错误码](#section195846692412)。|
|result_msg|是|String|响应描述。|
|report|否|Report|报告数据集合。|

Report结构体定义  

|参数|是否必选|参数类型|描述|
|:----------|:---|:----------|:----|
|header|是|Header|表头。|
|rows|是|RowInfo\[\]|查询结果。|
|total_pages|是|Integer|总页数。|
|curr_page|是|Integer|当前页。|

Header结构体定义  

|参数|是否必选|参数类型|描述|
|:---------|:---|:---------|:------|
|metric|是|String|指标名称。|
|dimensions|是|String\[\]|维度名称列表。|

RowInfo结构体定义  

|参数|是否必选|参数类型|描述|
|:----|:---|:--------|:----------|
|cells|是|Value\[\]|一行数据各个字段的值。|

Value结构体定义  

|参数|是否必选|参数类型|描述|
|:--------|:---|:------|:-------------------|
|col_type|是|Integer|结果值类型： * 0：指标 * 1：维度|
|col_name|是|String|指标名称或维度名称。|
|col_value|是|String|指标名称或维度名称对应的值。|
