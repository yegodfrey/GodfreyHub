# OnInfoWindowClickListener

|Interface Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface OnInfoWindowClickListener 表示标记窗口点击事件侦听器，包含一个抽象函数[onInfoWindowClick](#section42521813113917)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-marker-0000001101552572) marker)，您只需要注册此侦听器，并实现这个抽象函数，就能对信息窗口点击事件进行侦听。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|abstract void|[onInfoWindowClick](#section42521813113917)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-marker-0000001101552572) marker) 点击标记信息窗口时回调此方法。|

#### Public Methods

#### onInfoWindowClick

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void onInfoWindowClick([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-marker-0000001101552572) marker) 点击标记信息窗口时回调此方法。必须在主线程中执行。|

Parameters  

|Name|Description|
|:-----|:----------|
|marker|被点击的标记。|
