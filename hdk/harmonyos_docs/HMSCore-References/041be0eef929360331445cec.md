# 分账结果回调通知

#### 功能介绍

开发者完成分账申请成功后，华为支付服务器调用此接口向开发者服务器发送分账关键事件通知。  
![](https://media:201774590625112567)  
1. 为保证回调请求的可靠性，系统具备重试机制，所以可能出现重发的通知。
2. 订单状态需根据orderStatus字段判断。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为支付服务器 -\> 开发者服务器|
|接口URL|URL由开发者在请求申请分账接口时传的callbackUrl|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

* Request Body  

  |参数|是否必填|参数类型|描述|
  |:-------------------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
  |callbackId|是|String|回调通知的唯一ID。|
  |callbackTime|是|String|回调通知时间。|
  |dataType|是|String|数据加密类型标识。 * encrypt：加密 * plain：未加密|
  |sign|是|String|回调通知结果签名，除"sign"字段以外的其他字段参与签名。|
  |signType|是|String|签名类型。华为支付生成签名字符串使用的算法，当前为SM2算法。|
  |certNo|否|String|签名所使用的证书编号。|
  |sysAllocationOrderNo|是|String|华为支付分账订单号。|
  |mercAllocOrderNo|否|String|商户分账订单号。|
  |sysTransOrderNo|是|String|华为支付系统订单号。|
  |mercOrderNo|是|String|商户交易订单号。|
  |orderStatus|是|String|订单状态。 * ALLOC_SUCCESS：分账成功 * ALLOC_FAILED：分账失败|
  |finishTime|是|String|完成时间，UTC时间格式（yyyy-MM-dd'T'HH:mm:ss.SSSZ）。|
  |currency|是|String|交易币种单位，最大长度为3。 * CNY （默认）|
  |mercAllocRule|是|List\<[MercAllocRuleDetail](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section12263134923713)\>|分账规则。|
  |payload|是|String|创建交易订单时带过来（原样带回）。|
  |extInfo|否|String|附加信息。|

#### 响应参数

* Response Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

<!-- -->

* Response Body  

  |参数|是否必选|参数类型|描述|
  |:---------|:---|:-----|:-----------------------------------------------------------------------|
  |resultCode|是|String|华为支付侧解析application/json类型响应，"000000"表示成功，其他值失败，如返回值格式不匹配或非"000000"将视为失败。|
  |resultDesc|是|String|结果描述。|

<!-- -->

* 响应示例

  ```
  HTTP/1.1 200 OK
  Content-Type: application/json; charset=UTF-8
  {
    "resultCode": "000000",
    "resultDesc": "Success."
  }
  ```
