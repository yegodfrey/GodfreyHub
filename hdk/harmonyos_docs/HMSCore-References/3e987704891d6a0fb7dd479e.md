# 平台券

## RequestSceneInfo

|参数|是否必选|类型|说明|
|:--------------------------------|:---|:------------------|:-------------------------------------------------------------------------------------------------------------------|
|sceneId|是|String|场景id，要求为唯一字符串，用于匹配响应结果。|
|[sceneParams](#section0852525298)|是|Map<String, Object>|场景扩展参数，用于匹配使用条件。部分参数可参考[设备信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-device-info)|

## sceneParams

|参数|是否必选|类型|说明|
|:---------------|:---|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|tradeOrderAmount|是|Integer|订单金额，单位为分。|
|bundleType|是|String|包类型。 * APP (鸿蒙应用) * ATOMIC_SERVICE(元服务)|
|bundleName|否|String|包名。|
|productModel|否|String|**元服务API**：从API version 11开始，该接口支持在元服务中使用。 示例：ALN-AL00|
|deviceType|否|String|设备类型。详细请参考[deviceTypes标签](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/module-configuration-file#devicetypes标签)。 **元服务API**：从API version 11开始，该接口支持在元服务中使用。 示例：phone|
|osType|是|String|系统类型枚举，当前只支持HMOS。 示例：HMOS|

## ServCouponInfo

|参数|是否必选|类型|说明|
|:------------|:---|:-----------------------------------------|:------------------------------|
|couponCode|是|String|优惠券编号。|
|batchNo|是|String|优惠券批次。|
|couponType|是|String|券批次类型，可选取值： NORMAL：固定面额满减券批次类型。|
|effectiveTime|是|Long|券可使用开始时间的时间戳。|
|expireTime|是|Long|用户领取到这张券的过期时间的时间戳。|
|amount|否|Integer|优惠金额（优惠券面额），单位分。|
|displayInfo|否|[SimpleDisplayInfo](#section1164395514116)|优惠券简易展示信息。|

## SimpleDisplayInfo

|参数|是否必选|类型|说明|
|:---------|:---|:-----|:----------|
|couponDesc|否|String|券描述。|
|logoUrl|否|String|品牌Logo的URL。|

## SceneMatchedCouponNos

|参数|是否必选|类型|说明|
|:--------|:---|:-----------|:-------------------------------------------|
|sceneId|否|String|场景Id，由商户自动生成。如果请求体中的场景条件匹配上券，则把相应的sceneId返回。|
|couponNos|否|List<String>|场景条件匹配上的优惠券编码列表。|
