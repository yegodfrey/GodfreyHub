# syncCloud：将本地数据与云端同步

接口原型

public void syncCloud(String uniqueId, String function)

方法描述：将本地数据更新，与云端保持一致。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-----------------------------------|:---|
|uniqueId|String|设备标识ID|-|
|function|String|运动健康返回同步结果的回调函数，该回调函数有一个参数，详情参见响应参数。|M|
[表1 请求参数]

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:-----------------------------------------------------------------------------------------------------------------------------|:---|
|errCode|Number|0，表示同步成功。 0以外表示同步失败，具体错误信息参见[错误码清单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/errcode-0000001058135271)。|M|
[表2 响应参数]
