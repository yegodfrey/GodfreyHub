# Overview

包含华为图片框的功能类。  

#### Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|[HwImageView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwimageview-class-0000001051623504)|华为风格的ImageView控件，在原生ImageView基础上，增加点击阴影效果、基于页面滚动的垂直视差效果、图片详情界面下拉返回，以及图片按照任意圆角显示功能，并提供上述特性的开关接口。 在API 24以下使用本控件，将不会有点击阴影效果。在API 21以下使用本控件，将不会有圆角显示效果。|
