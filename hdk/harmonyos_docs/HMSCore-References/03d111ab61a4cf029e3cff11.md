# HwSubTabWidget

|Class Info|
|:--------------------------------------------------------------------------------------------|
|public class HwSubTabWidget extends LinearLayout 该类是华为的子页签，继承了LinearLayout，一组标签，用户点击选择特定的选项卡。|
