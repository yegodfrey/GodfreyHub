# DownloadState

|Enum Info|
|:----------------------------------------------|
|public enum DownloadState 用于指示与媒体HTTP下载关联的下载状态。|

#### Enum Value Summary

|Enum Value and Description|
|:--------------------------|
|NOT_STARTED 下载过程尚未开始。|
|MEDIA_IN_PROGRESS 媒体文件正在下载。|
|MEDIA_COMPLETE 媒体文件下载成功。|
