# 解冻剩余可分账金额

## 功能介绍

不需要再分账的订单，可调用此接口将订单剩余可分账金额全部解冻给收单商户。
> 说明
>
> 此接口为异步处理模式，即接收到平台类商户/服务商分账完结申请后，会先受理请求后再异步处理。
