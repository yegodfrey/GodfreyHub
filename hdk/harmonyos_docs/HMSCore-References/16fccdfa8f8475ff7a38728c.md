# Geofence

|Interface Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface Geofence 地理围栏实体接口。地理围栏可以由地理围栏服务监控，当用户进入、退出围栏或者驻留地理围栏一定时间时，将生成警报。调用[Geofence.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/geofence-builder-0000001050706136)类中的[build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/geofence-builder-0000001050706136#section44721944453)()方法时返回一个该类型的实例。|
