## Public Methods

### setAnalyticsEnabled

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void setAnalyticsEnabled(boolean enabled) 是否打开埋点采集能力。关闭后将不再记录任何数据，且不分析数据。 > 说明 > 如果您之前关闭了埋点采集能力，当再次打开埋点采集能力时，数据分析能力不会同步打开，需要您设置[setRestrictionEnabled](#section1448813311134)接口的参数值为**false**。|

**Parameters**

|Name|Description|
|:------|:-----------------------------------------------------|
|enabled|是否打开埋点采集开关。默认值为**true**，表示打开埋点采集。 * true：打开 * false：关闭|

**Sample code：**

SDK默认打开采集数据，您可参考以下示例代码，关闭埋点采集能力。

```screen
HiAnalyticsInstance instance = HiAnalytics.getInstance(ability);
instance.setAnalyticsEnabled(false);
```

### setUserId

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void setUserId(String id) 设置用户ID。 调用setUserId()接口时，如果旧**id** 不为空字符串且和新**id** 不同，会重新生成新的Session会话。若您不希望使用setUserId标识用户（如用户退出时），必须将**id** 设为**null**。 SDK不会保存您的用户ID，建议您在每次应用启动后设置用户ID。|

**Parameters**

|Name|Description|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|id|匿名化用户标识，在华为分析服务侧通过此标识关联用户数据。只有您可以使用该标识符追溯到具体用户，分析系统无法使用您设置的**id**追溯到具体用户。 非空，长度不超过256字符。 > 说明 > 设置**id** 时，需要遵守[分析服务协议](https://developer.huawei.com/consumer/cn/doc/distribution/app/20212)，避免使用能标识个人身份信息的原始**id** ，建议使用随机化的**id**。|

### setUserProfile

**Parameters**

|Name|Description|
|:----|:-------------------------------------------|

|value|属性值。长度不超过256字符。|

> 说明

> * 如果您删除或新增属性，需要在端侧和云侧同步修改，并通过设置的属性name进行关联。

### setReportPolicies

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void setReportPolicies(Set<[HAReportPolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-reportpolicy-0000001169640375)> policies) 设置自动上报的策略。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|policies|支持四种上报策略，可以设置多个策略同时存在。 * [ON_APP_LAUNCH_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：应用启动上报策略，选择该策略时会立即上报一次，此后每次应用启动时上报一次。 * [ON_MOVE_BACKGROUND_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：应用切后台（包括应用退出）上报策略。 * [ON_SCHEDULED_TIME_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：定时上报策略，根据指定的间隔时间轮循上报事件，取值范围为[60, 1800]秒（默认60秒），如果设置的值超过给定范围则取边界值。 * [ON_CACHE_THRESHOLD_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：阈值上报策略，缓存事件条数达到阈值时上报事件，取值范围为[30, 1000]条（默认30条），如果设置的值超过给定范围则取边界值。|

> 说明
>
> * 以上上报策略仅在非调试模式下生效。
> * 应用切后台上报策略和阈值上报策略为必选策略，无论设置什么策略，这两个策略都会生效，但是可以改变阈值上报策略的阈值。
> * 多次调用设置上报策略的接口，会刷新上报策略，仅最后一次设置的策略生效，请谨慎多次调用。
> * 当策略满足触发事件上报时，如果没有网络，则会将事件缓存在本地，等待下次条件满足继续上报。
> * 上报策略持久化保存。

**Sample code** **：**

您可以参考以下示例代码，设置应用切后台上报策略和定时上报策略。

```screen
HiAnalyticsInstance instance = HiAnalytics.getInstance(ability); 
// 创建应用启动上报策略
HAReportPolicy appLaunchPolicy = HAReportPolicy.ON_APP_LAUNCH_POLICY;
// 创建定时上报策略
HAReportPolicy scheduledTimePolicy = HAReportPolicy.ON_SCHEDULED_TIME_POLICY;
// 设置定时上报时间周期为600秒
scheduledTimePolicy.setThreshold(600);
Set<HAReportPolicy> reportPolicies = new HashSet<>();
// 添加定时上报策略和应用启动上报策略
reportPolicies.add(scheduledTimePolicy);
reportPolicies.add(appLaunchPolicy);
// 设置应用启动上报策略和定时上报策略
instance.setReportPolicies(reportPolicies);
```
