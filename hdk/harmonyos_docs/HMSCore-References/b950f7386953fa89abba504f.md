# 说明

|Name|Description|
|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，提供地图呈现、地图交互、地图绘制和个性化定制能力。|
|HarmonyOS|基于Java语言开发的独立HarmonyOS应用程序接口，支持地图呈现、地图交互、地图绘制。|
|iOS|基于Objective-C语言开发的独立iOS应用程序接口，支持地图呈现、地图交互、地图绘制和自定义地图样式能力。|
|JavaScript|基于JavaScript语言开发的独立浏览器应用编程接口，提供基础地图展示、地图交互、地图绘制、路径规划、位置搜索和地理编码能力满足您的大多数需求。使用接口需收费，收费标准请参见[服务定价](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/about-charging-0000001051637068)。|
|REST|提供支持HTTP和HTTPS的云服务接口，用于开发路径规划、静态图、栅格图等相关能力。使用接口需收费，收费标准请参见[服务定价](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/about-charging-0000001051637068)。|
|Flutter|Flutter插件实现HMS Core Map SDK与Flutter平台之间的通信，提供地图服务的创建地图、地图交互、在地图上绘制、精简模式相关能力。|
