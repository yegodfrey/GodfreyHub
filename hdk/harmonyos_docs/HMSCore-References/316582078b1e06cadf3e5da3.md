# 说明

|Application Scenario|Name|Description|
|:-------------------|:-------------------|:-------------------------------------------------------------------------------------------|
|订单、订阅服务|Android|基于Java语言开发的独立Android应用程序接口，包含查询商品信息、创建订单、查询已购商品的订单信息、订阅页面跳转等，用于完成各类型商品的购买和提供商品服务的流程。|
|订单、订阅服务|HarmonyOS-JavaScript|基于JavaScript语言开发的独立HarmonyOS应用程序接口，包含查询商品信息、创建订单、查询已购商品的订单信息、订阅页面跳转等，用于完成各类型商品的购买和提供商品服务的流程。|
|订单、订阅服务|Server|提供支持HTTPS的云服务接口，包括应用内支付服务端的订单/订阅服务验证购买Token、返还费用、取消订阅、撤销订阅等API能力，以及数据模型与错误码释义。|
|VR支付服务|Android|基于Java语言开发的独立Android应用程序接口，提供应用内支付、订单信息查询能力。|
|VR支付服务|Server|提供支持HTTPS的云服务接口，包括服务端回调说明。当支付成功时，应用内支付服务器向开发者配置的URL回调支付结果数据。|
