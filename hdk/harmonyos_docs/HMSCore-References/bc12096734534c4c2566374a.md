# Overview

数据捐赠的消息包，包含[Message](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/message-0000001297835688)、[Session](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/session-0000001297675736)、[Content](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/content-0000001351035337)和[ContentData](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/contentdata-0000001350955541)四个类。

## Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[Content](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/content-0000001351035337)|消息的Content部分。|
|[ContentData](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/contentdata-0000001350955541)|传入Content数据。|
|[Message](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/message-0000001297835688)|捐赠消息体，承载整个捐赠消息报文，包含[Session](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/session-0000001297675736)和[Content](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/content-0000001351035337)。|
|[Session](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/session-0000001297675736)|消息Session部分。|
|[InsightIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/insightintent-0000001556686061)|共享的意图数据，包括意图名称、版本号、标识、Action信息、Entity信息。|
