# ActivityFeature

|Function Info|
|:---------------------------------------------------------------------------------------------------------|
|function ActivityFeature 运动特征数据采样点，记录一次运动记录中的相关的特征值，比如跳绳运动记录需要关联的跳绳个数、绊绳次数、最多连跳、双摇个数、三摇个数等可以描述跳绳运动记录的特征字段。|
