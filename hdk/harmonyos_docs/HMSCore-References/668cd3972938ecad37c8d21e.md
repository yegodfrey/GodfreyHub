# Cap

定义[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695)对象的起始顶点和末端顶点的类型。  

#### Constants

|常量|类型|描述|
|:--------|:--|:--------------------------------|
|squareCap|Cap|将折线的起始顶点或末端顶点设置为正方形类型。|
|buttCap|Cap|定义起始于折线的起始顶点或末端顶点的方形帽。|
|roundCap|Cap|表示半径为线宽一办的半圆形。该半圆的圆心为折线的起始或者末端顶点。|

#### Constructor Summary

|构造函数|描述|
|:---------------------------------------------------------------------------------------------------------------------------------|:--------|
|[Cap.customCapFromBitmap(BitmapDescriptor bitmapDescriptor, {double refWidth})](#ZH-CN_TOPIC_0000001208344748__section74264376390)|自定义折线的帽型。|

#### Constructors

#### Cap.customCapFromBitmap

构建拥有Bitmap覆盖物的帽型，其以[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695)Polyline的起始或末端顶点为中心、朝向折线的第一条或最后一条边的方向、并且以折线线宽为比例进行缩放。  

|参数|类型|描述|
|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------|
|bitmapDescriptor|[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-bitmapdescriptor-0000001208024788)|[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-bitmapdescriptor-0000001208024788)对象。|
|refWidth|double|线宽，单位为像素。|
