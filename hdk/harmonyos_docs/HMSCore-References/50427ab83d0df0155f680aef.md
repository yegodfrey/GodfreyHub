# Polyline

在地图上定义一个折线。  

#### Properties

|名称|类型|描述|
|:---------|:---------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------|
|polylineId|[PolylineId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polylineid-0000001253024731)|折线唯一的ID。|
|clickable|bool|表示折线是否可点击。|
|color|Color|线条颜色。|
|geodesic|bool|表示是否将折线的每个线段绘制为测地线。取值为true（是）和false（否）。|
|jointType|[JointType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-jointtype-0000001253144697)|折线除起始顶点和末端顶点外所有顶点的连接类型。|
|patterns|List\<[PatternItem](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-patternitem-0000001253264693)\>|折线的线条样式。默认值为null，表示线条样式为实线。|
|points|List\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)\>|折线的顶点。连续的两点之间用线段连接。默认情况下，折线是不闭合的。要绘制闭合的折线，则起始顶点和末端顶点必须相同。|
|startCap|[Cap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cap-0000001208344748)|折线的起始顶点。|
|endCap|[Cap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cap-0000001208344748)|折线的末端顶点。|
|visible|bool|折线的可见性。|
|width|int|折线的线条宽度。|
|zIndex|int|折线的Z-index，表示该折线的重叠顺序。|
|onClick|VoidCallback?|点击折线时调用的函数。|

复制已有的Polyline对象并更新指定的属性。  

|参数|类型|描述|
|:--------|:----------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------|
|clickable|bool?|表示折线是否可点击。|
|color|Color?|线条颜色。|
|geodesic|bool?|表示是否将折线的每个线段绘制为测地线。取值为true（是）和false（否）。|
|jointType|[JointType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-jointtype-0000001253144697)?|折线除起始顶点和末端顶点外所有顶点的连接类型。|
|patterns|List\<[PatternItem](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-patternitem-0000001253264693)\>?|折线的线条样式。默认值为null，表示线条样式为实线。|
|points|List\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)\>?|折线的顶点。连续的两点之间用线段连接。默认情况下，折线是不闭合的。要绘制闭合的折线，则起始顶点和末端顶点必须相同。|
|startCap|[Cap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cap-0000001208344748)?|折线的起始顶点。|
|endCap|[Cap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cap-0000001208344748)?|折线的末端顶点。|
|visible|bool?|折线的可见性。|
|width|int?|折线的线条宽度。|
|zIndex|int?|折线的Z-index，表示该折线的重叠顺序。|
|onClick|VoidCallback?|点击折线时调用的函数。|

|返回类型|描述|
|:-------|:----------|
|Polyline|Polyline对象。|

调用示例：

```
// 定义Polyline对象。

// 调用updateCopy方法。
```
