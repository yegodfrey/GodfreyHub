# startScanCode：启动扫码功能

接口原型

public void startScanCode(String function)

方法描述：启动扫码界面，通过扫描设备的SN码获取SN码信息。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-----------------------------------|:---|
|function|String|运动健康返回扫码结果的回调函数，该回调函数有一个参数，详情参见响应参数。|M|
[表1 请求参数]

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:-----------------------------------------------------------------------------------------------------------------------------|:---|
|errCode|Number|0，表示扫码成功。 0以外表示扫码失败，具体错误信息参见[错误码清单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/errcode-0000001058135271)。|M|
|data|String|11位的sn码字符串|M|
[表2 响应参数]
