#### Circle.updateCopy

复制已有的Circle对象并更新指定的属性。  

|参数|类型|描述|

|clickable|bool?|表示圆形是否可点击。|

|center|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)?|圆心的经纬度坐标。|
|radius|double?|圆的半径。|
|strokeColor|Color?|线条颜色。|
|strokeWidth|int?|圆形的线宽。|
|visible|bool?|圆的可见性。|
|zIndex|int?|圆的Z-index，表示该圆形的重叠顺序。|
|onClick|VoidCallback?|点击圆形时调用的函数。|
|strokePattern|List\<[PatternItem](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-patternitem-0000001253264693)\>?|圆形的线宽。|

|返回类型|描述|
|:-----|:--------|
|Circle|Circle对象。|

调用示例：

```

// 调用updateCopy方法。
circle = circle!.updateCopy(radius: 4000);
```
