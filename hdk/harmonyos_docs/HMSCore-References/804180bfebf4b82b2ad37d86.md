# SupportMapFragment

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class SupportMapFragment 应用中的地图组件，是应用中放置地图的最简单的方式。通过[getMapAsync](#section1874811557456)，获取地图管理器。 [HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象必须使用[getMapAsync](#section1874811557456)([OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378) callback)获取，此类会自动初始化地图系统和视图。 从[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)获取的任何对象都与视图关联，不要在视图的生命周期之外保留对象（例如：标记），否则将导致内存泄漏，因为视图无法释放。|

### getMapAsync

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void getMapAsync([OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378) callback) 当地图对象准备就绪时，就会触发此接口回调，获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象。 > 说明 > * 必须在主线程调用此方法。 > * 回调将在主线程中执行。 > * 在极少数情况下，创建后立即销毁[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)时，不会触发回调。 > * [HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)回调提供的对象为非null。|

**Parameters**

|Name|Description|

|callback|当地图准备就绪时被触发的回调对象。|
