# onBluetoothDeviceFound：订阅发现新的蓝牙设备的事件

接口原型

public void onBluetoothDeviceFound(String function)

方法描述：订阅发现新的蓝牙设备的事件。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:------------------------------------------|:---|
|function|String|监听手机蓝牙模块状态回调函数名，该回调函数是一个devices数组，详情参见响应参数。|M|
[表1 请求参数]

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------------------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---|
|devices|Array|Device数组， Json字符串格式|M|
|deviceId|String|用于区分设备的 id，Android 上获取到的deviceId为设备 MAC 地址|M|
|RSSI|number|当前蓝牙设备的信号强度|M|
|manufacturerData|String|当前蓝牙设备的广播数据段中的ManufacturerData数据段|O|
|advertisServiceUUIDs|String|当前蓝牙设备的广播数据段中的ServiceUUIDs数据段（UUID字符串数组） 示例：\['0000ffe0-0000-1000-8000-00805f9b34fb', '0000ffe1-0000-1000-8000-00805f9b34fb', '0000ffe2-0000-1000-8000-00805f9b34fb'\]|M|
|localName|String|当前蓝牙设备的广播数据段中的LocalName数据段|M|
|serviceData|String|当前蓝牙设备的广播数据段中的ServiceData数据段|O|
[表2 响应参数]

![](https://media:801784947931404885)  
1. CallbackName可多次注册不同名称回调函数，已注册的全部回调函数，会在hilink.stopBluetoothDevicesDiscovery调用前生效。Hilink.stopBluetoothDevicesDiscovery后，会清除回调注册。
2. hilink.onBluetoothDeviceFound建议在hilink.startBluetoothDevicesDiscovery前调用，确保启动发现后每一次搜索到设备都能被准确回调。
