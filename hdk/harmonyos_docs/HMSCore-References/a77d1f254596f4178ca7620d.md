# HuaweiMapUtils

#### Methods

#### disableLogger

禁用HMSLogger能力，该能力用于发送地图服务SDK方法的使用分析，以提高服务质量。该方法是异步的。  

|返回类型|描述|
|:-------------|:------------------|
|Future\<void\>|无返回值的执行任务的Future结果。|

调用示例：

```
// 调用disableLogger接口。
await HuaweiMapUtils.disableLogger();
```

#### enableLogger

开启HMSLogger能力，该能力用于发送地图服务SDK方法的使用分析，以提高服务质量。该方法是异步的。  

|返回类型|描述|
|:-------------|:------------------|
|Future\<void\>|无返回值的执行任务的Future结果。|

调用示例：

```
// 调用enableLogger接口。
await HuaweiMapUtils.enableLogger();
```

#### distanceCalculator

计算两个坐标点之间的距离。该方法是异步的。  

|参数|类型|描述|
|:----|:---------------------------------------------------------------------------------------------------------------|:-----|
|start|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|起始坐标点。|
|end|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|结束坐标点。|

|返回类型|描述|
|:---------------|:------------------|
|Future\<double\>|指定的两个坐标点之间的距离，单位为米。|

调用示例：

```
// 调用distanceCalculator接口。
double? result = await HuaweiMapUtils.distanceCalculator( 
 start: LatLng(41.048641, 28.977033), 
        end: LatLng(41.063984, 29.033135), 
);
```
