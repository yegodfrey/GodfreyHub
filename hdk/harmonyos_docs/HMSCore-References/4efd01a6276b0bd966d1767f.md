# ppsads.requestConsentUpdate(object)

## 概述

请求用户意见更新状态。

## 参数

|参数|是否必选|类型|描述|
|:------|:---|:-------|:------------|
|success|是|function|请求用户意见更新状态成功。|
|fail|是|function|请求用户意见更新状态失败。|

## success回调参数

|参数|类型|描述|
|:-------------|:------|:----------------------------------------------------------------------------------------|
|consentStatus|number|用户意见状态。 * 0：用户已同意接收个性化广告与非个性化广告。 * 1：用户已同意仅接收非个性化广告。 * 2：用户既未同意接收也未拒绝接收个性化广告或非个性化广告。|
|isNeedConsent|boolean|是否需要用户确认意见。 * false，表明可以向鲸鸿动能JavaScript API请求个性化广告。 * true，表明用户在欧洲经济区内或其他敏感地区，需进一步确认用户意见。|
|AdProviderList|array|广告技术提供商信息列表。AdProvider对象结构详细请参见[AdProvider](#section16417191023816)。|

## AdProvider

|属性|类型|描述|
|:---------------|:-----|:-----------------|
|id|String|广告技术提供商的ID。|
|name|String|广告技术提供商的名称。|
|serviceArea|String|广告技术提供商的服务地。|
|privacyPolicyUrl|String|广告技术提供商的隐私政策链接URL。|
