# 请求补差

#### 功能介绍

商户预下单时添加最大补差金额"subsidyAmount"及延时分账"allocationType=DELAY_ORDER_ALLOCATION"入参，订单支付成功并结算完成后，在发起分账前，可调用该接口进行订单补差。  
![](https://media:201774590624258562)  
1. 如该笔订单需要补差，在补差完成前发起订单分账，分账接口会响应异常信息。
2. 一笔订单只能发起一笔补差，补差金额需要小于等于预下单时传递的最大补差金额。
3. 此接口会直接返回处理结果并支持幂等，相同请求参数只会扣款一次，重复入参请求可视为补差订单查询。
4. 系统异常（如返回UNKNOW_ERROR），请务必稍后再使用相同参数重新调用此接口，如更换金额可能会导致重复扣款。  

#### 使用约束

换单重试，视为新的业务订单，需开发者自行将新的业务订单关联业务原订单。接口重入规则说明如下（供参考）：  

|重入判定字段|支持原单重入场景|建议换单重试场景|
|:--------------------------|:------------------------------------------------------------------|:--------------------------------------|
|商户补差订单号（mercSubsidyOrderNo）|1. 请求补差接口失败，建议根据错误码排查后，支持原商户补差订单号重入。 2. 请求补差接口成功，原商户补差订单号重入，接口幂等返回。|补差状态为FAILED时，则订单进入失败终态。如需重新发起补差，需要换单重试。|

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/partner/subsidies/create|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------|

#### 请求参数

* Request Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|

* Request Body  

  |参数|是否必选|类型|说明|
  |:-----------------|:---|:------|:-----------------|
  |subMercNo|是|String|收单商户号。|
  |sysTransOrderNo|是|String|华为支付系统订单号。|
  |subsidyAmount|是|Integer|补差金额，单位分。|
  |subsidyRemark|否|String|补差附言（账单字段），最大长度64。|
  |mercSubsidyOrderNo|是|String|商户补差订单号，最大长度64。|

#### 响应参数

* Response Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

* Response Body  

  |参数|是否必选|参数类型|描述|
  |:---------------------|:---|:------|:------------------------------------------|
  |resultCode|是|String|返回码，"000000"表示成功，其他表示见错误码。|
  |resultDesc|是|String|结果描述。|
  |subCode|否|String|业务错误码。|
  |subDesc|否|String|业务错误描述信息。|
  |sign|是|String|签名值。用于开发者对响应报文进行防篡改验证。|
  |subMercNo|否|String|收单商户号。|
  |sysTransOrderNo|否|String|华为支付系统订单号。|
  |subsidyAmount|否|Integer|补差金额，单位分。|
  |subsidyRemark|否|String|补差附言（账单字段），最大长度64。|
  |mercSubsidyOrderNo|否|String|商户补差订单号，最大长度64。|
  |subsidyStatus|否|String|补差状态。 * SUCCESS：成功 * FAILED：失败 * APPLY：申请状态|
  |sysSubsidyTransOrderNo|否|String|华为支付系统补差订单号，最大长度64。|
