# 添加分账白名单

#### 功能介绍

仅提供给平台类商户，用于添加分账接收白名单。平台类商户管理的子商户默认是在白名单（分账接收方）内，白名单支持添加普通商户。 添加后，其管理的子商户的收单后，可以分账给分账白名单商户。  
![](https://media:201774590630210617)  
1、白名单添加审核成功后会回调结果给商户服务器。

2、入参文件下载失败会通过回调接口通知开发者。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/partner/allocation/receivers/add|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|--------------------------------------------------------------------------------------|

#### 请求参数

* Request Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|

<!-- -->

* Request Body  

  |参数|是否必填|参数类型|描述|
  |:---------------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------|
  |callbackUrl|是|String|结果回调地址，最大长度512。|
  |acceptMercNo|是|String|分账接收方商户号。|
  |acceptMercType|是|String|分账接收方商户身份。 * 01：平台 * 02：供应商 * 03：分销商 * 04：服务商 * 05：其他 * 06：入驻商家 * 07：门店 * 08：员工 * 09：店主 * 10：平台类商户/服务商 * 11：总部 * 12：品牌方|
  |description|否|String|说明。|
  |relationFileUrl|是|String|关系证明材料下载地址，此地址必须是公网地址且一次性地址。华为支付系统会通过异步去下载材料，下载失败会通过回调接口返回通知。|
  |relationFileType|是|String|文件类型 附件上传按钮，支持格式：zip、rar、jpg、png，最大支持20M。|

#### 响应参数

* Response Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

<!-- -->

* Response Body  

  |参数|是否必填|参数类型|描述|
  |:---------|:---|:-----|:---------------------------------------|
  |resultCode|是|String|结果码，"000000"表示成功，其他表示失败。|
  |resultDesc|是|String|结果描述。|
  |subCode|否|String|业务错误码。|
  |subDesc|否|String|业务错误描述信息。|
  |sign|是|String|签名值。用于开发者对响应报文进行防篡改验证。|
  |mercNo|否|String|商户号。|
  |subMercNo|否|String|特约商户号或平台子商户号。|
  |mercStatus|否|String|当前商户状态。 * 20：正常 * 30：冻结 * 40：销户 * 50：预销户|
  |flowId|否|String|审批流程id。|

#### 错误码

(resultCode非400000的错误码请看[公共错误码说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-error-code-description-0000001589053741#section1187515498410))  

|resultCode|resultDesc|subCode|subDesc|
|:---------|:---------|:---------------------------|:-------|
|400000|业务处理失败|INVALID_ARGUMENTS|参数不合法|
|400000|业务处理失败|MERC_NOT_SUPPORT_ALLOCATION|商户不支持分账|
|400000|业务处理失败|INVALID_MERC_NO|无效商户号|
|400000|业务处理失败|ALLOCATION_PERMISSIONS_LIMIT|商户暂无分账权限|
