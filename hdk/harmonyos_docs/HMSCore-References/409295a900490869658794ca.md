# 发货完成后通知（应用外支付）

## 功能描述

当开发者服务器完成发货后，需要调用此接口向华为服务器发送发货完成通知。

## 接口原型

|承载协议|HTTPS PUT|
|-----|-----------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/dps/v1/usage/delivery/callback|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 使用约束

调用本接口前必须要通过华为服务器的API客户端认证，详细方法参见[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit_gettoken-0000001050123505)。

## 请求参数

**header参数**

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|developerId|是|String|开发者帐号的ID，用于唯一标识当前开发者，查询方法请参见[查询开发者帐号ID](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-developerid-projectid-0000001166543063)。|
|appId|是|String|应用ID，获取方法请参见[查询应用信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/query-app-info-0000001050164344)。|
|client_id|是|String|[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)中生成的客户端ID。|
|Authorization|是|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit_gettoken-0000001050123505)中获取的access_token。access_token的有效期由[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit_gettoken-0000001050123505)返回的expires_in确定。|
|productId|是|String|应用所在项目的项目ID，查询方法参见[获取项目ID](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/query-project-id-0000001050166305)。|

**body参数**

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|orderId|是|String|华为生成的业务订单号，参见[通知发货](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit-notifysendproduct-0000001050121556)接口中的orderId参数。|
|productNo|是|String|已发货的商品ID。|
|openId|是|String|用户唯一标识，传入用户的openId。|
|status|是|int|发货状态，目前只支持0，表示发货成功。|
|ts|是|long|通知发送时间的时间戳，即距离1970年1月1日0点的毫秒数。|

## 请求示例

```screen
PUT {url}
Content-Type: application/json
developerId:******
appId:******
client_id: *******
productId：******
Authorization: Bearer ******
"body":
{
    "orderId":"xxxxxx",
    "productNo":"lishan1",
    "openId":"xxxxxxxxx",
    "status": 0
    "ts":1571053683587
}
}
```

## 响应参数

|参数|是否必选|参数类型|描述|
|:----|:---|:-----|:------------------------------------------------------------------------------------------------------------------------------------------|
|error|否|String|处理失败时包含操作结果的JSON字符串，格式为"{"errorCode": xxx, "errorMsg": xxxx}"。 * errorCode：错误码，具体取值请参见[错误码](#section17457111971515)。 * errorMsg：错误码对应的描述信息。|
|data|否|String|处理成功时包含操作结果的JSON字符串，格式为"{"result": 0}"。0表示成功。|

## 响应示例

```screen
HTTP/1.1 200 OK
Content Type : application/json ; charset=UTF-8
{
"error": {
"errorCode": 0,
"errorMsg": "string"
}
}
or
{
"data": {
"result": 0
}
}
```

## 错误码

|错误码|说明|
|:--|:----------------|
|1|鉴权失败。|
|2|超时。|
|3|业务信息错误，例如支付订单不存在。|
|11|商品不存在。|
|12|用户不存在。|
|94|系统错误。|
|95|IO错误。|
|96|错误的请求URL。|
|97|错误的响应。|
|98|参数错误。|
|99|其他错误。|
