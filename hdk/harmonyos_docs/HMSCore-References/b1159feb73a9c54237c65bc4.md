# 延迟付款型支付关键事件通知

#### 功能介绍

用户在使用延迟付款型支付购买一次性商品后，华为应用内支付服务器调用此接口向您的服务器发送关键事件通知。  

#### 场景描述

如果您在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)申请支付服务时提前[配置了订单/订阅通知地址](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section15820113193119)，用户使用延迟付款型支付购买一次性商品后，当订单从Pending状态变更为Purchased时，华为应用内支付服务器会调用此接口通知已配置的服务器。

若您的服务器返回结果为非成功响应（返回的http status code值为200之外的值），将对本次关键事件的通知进行周期性重发。建议在您的服务端收到通知后立即返回成功响应，避免通知消息堆积。

为保证可靠性，系统具备补偿机制，所以可能出现重发的通知比预期的多。  

#### 接口约束

不允许您的服务器设置IP允许清单用于限制华为侧的出口IP地址。IP允许清单本身并不能提高安全性且会给业务发展带来约束，在消息层面已有更安全的RSA签名机制条件下，没有存在价值。您不遵守该约定而导致的后果将由您自行承担。

必须在开发前在AppGallery Connect中配置您的服务器的回调地址，地址必须支持HTTPS协议且具有合法商用证书，出于安全考虑，cipher需要支持ECDHE-RSA-AES128-GCM-SHA256、ECDHE-ECDSA-AES128-GCM-SHA256、ECDHE-RSA-AES256-GCM-SHA384或ECDHE-ECDSA-AES256-GCM-SHA384中至少一种，否则无法正常接收通知消息。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为应用内支付服务器 -\> 开发者服务器|
|接口URL|URL由您在申请支付服务时配置。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

|notifyTime|是|Long|通知时间，UTC时间戳，即自1970年1月1日0时起到商户通知的毫秒数|
|applicationId|是|String|应用ID。|
|orderNotification|是|JSONObject|通知内容。|

#### 请求示例

```
POST /order/notify/address
Content-Type: application/json; charset=UTF-8
Accept: application/json
Content-Length: 2754
{
  "version": "v2",
  "notifyTime": 1638302788109,
  "eventType": "ORDER",
  "applicationId": "1638302781639",
  "orderNotification": {
      "version": "v2",
      "notificationType": 1,
      "purchaseToken": "***",
      "productId": "1638302781639"
  }
}
```

#### 响应参数

通过HTTP状态码来标识华为应用内支付服务器通知您的应用服务器是否发送成功：

* 如果通知发送成功，则发送HTTP 200，不需要返回响应体。
* 如果通知发送失败，则通过发送HTTP 40X或者HTTP 50X，告知华为应用内支付服务器进行重试，华为应用内支付服务器会在一段时间内重试多次。  

#### 响应示例

```
HTTP/1.1 200 OK
```
