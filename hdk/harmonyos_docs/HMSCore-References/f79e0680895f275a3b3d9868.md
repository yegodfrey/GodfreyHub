# HwRspListView

|Class Info|
|:----------------------------------------------------------------------------------------------------|
|public class HwRspListView extends ListView 该类是华为响应式ListView控件，继承了原生ListView，可以通过设置列数控制折叠屏手机展开态的显示列数。|

## XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:------------------------------|
|integer|rspColNum 响应式控件列数设置。|
|boolean|isRspEnable 使能响应式能力配置。|
|dimension|rspItemSpace 响应式控件每列元素之间间距设置。|
