# 关注服务号接口

#### 功能介绍

在商家自己的快应用中，通过集成服务号JavaScript SDK并调用agreeFollow接口，关注目标服务号。

#### 场景描述

在商家的自己的快应用中，通过用户授权，需要关注目标服务号，快应用开发者可通过调用此接口，执行关注商家服务号操作。

用户点击同意后，终端用户信息（OpenID和UnionID）会通过开发者传入的成功方法回调给商家。

#### 使用约束

无。

#### 请求参数

**Request Header**

参数 | 参数类型 | 是否必选 | 描述信息  
---|---|---|---  
appId | String | 是 | 开发者的appId（创建项目和凭证中的客户端ID）。  
pubId | String | 是 | 服务号ID，用于请求需要关注的商家服务号。  
pubName | String | 是 | 服务号名称（最大长度不超过30个字符）。  
succ | function | 是 | 成功回调函数。在成功回调时调用。  
fail | function | 是 | 失败回调函数。在失败回调时调用。  
  
#### 请求示例
    
    let doAgreeFollow = function(){
        let appId = 'string'
        let pubId = 'string'
        let pubName = 'string'
        let succ = function(res) {
            //成功回调
        }
        let fail = function(error) {
            //失败回调
        }
        HBT.agreeFollow(appId, pubId, pubName, succ, fail)
    },

#### 返回结果

**data**

code | 含义  
---|---  
0 | 关注服务号接口调用成功  
20000 | 服务号协议未授权  
20001 | Kit不支持  
20005 | 请求的appId在快应用禁用清单中，请求被拒绝  
1000 | 协议未同意  
1001 | Kit拉起登录华为帐号授权被拒绝  
1004 | 网络无法连接  
20008 | 接口请求超时  
  
**errorCode**

错误码 | 含义  
---|---  
-2 | appId或pubId或pubName缺失  
-3 | 服务号名称长度超限  
-4 | 回调方法缺失
