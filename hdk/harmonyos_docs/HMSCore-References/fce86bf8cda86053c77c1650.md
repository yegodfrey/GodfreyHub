# 跳绳数据格式

![](https://media:801784947930490880)  
以下数据格式只适用于saveHeathData和saveMultipleHealthData接口。

RopeSkipping(type: 30029, dataTypeName: com.huawei.instantaneous.rope_skipping)

备注：所有字段value都作了非负数校验，可选的可以不传，如果传了就必须是非负数。  

|字段Key|数据类型|描述|可选选项|
|:---------------|:-----|:----------------------------|:---|
|sportType|int|运动种类，跳绳为283|M|
|totalCalories|int|运动消耗总卡尔数|M|
|totalTime|long|运动的总时间(毫秒值）|M|
|skipNum|String|跳绳总个数|M|
|skipSpeed|String|跳绳平均速度|M|
|stumblingRope|String|绊绳次数，如果没有传入此字段或传入为空默认写入"-1"|O|
|maxSkippingTimes|String|最大连跳个数，如果没有传入此字段或传入为空默认写入"-1"|O|
