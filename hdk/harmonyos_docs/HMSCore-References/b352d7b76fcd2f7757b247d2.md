# 体重数据格式

> 说明
>
> * 以下数据格式只适用于saveHeathData和saveMultipleHealthData接口。
> * 存储体重数据时，至少需要存储以下一个体重字段值。

**Weight (type: 10006, dataTypeName: com.huawei.instantaneous.body_weight)**

|字段Key|数据类型|描述|可选选项|
|:-----------------|:-----|:------------------|:---|
|weight|double|体重 千克 [0.1, 500.0]|O|
|bmi|double|BMI千克/平方米 [1,200]|O|
|muscleMass|double|肌肉量 千克 [0.1, 150.0]|O|
|basalMetabolism|double|基础代谢 千卡/日 (0,∞）|O|
|moisture|double|水分 升/千克 (0,500.0]|O|
|visceralFatLevel|double|内脏脂肪等级 [1.0,59.0]|O|
|boneSalt|double|骨盐量 千克 [0.5,5.0]|O|
|proteinRate|double|蛋白质比例 (0.0,100.0]|O|
|bodyScore|double|身体得分 (0.0,100.0]|O|
|bodyAge|double|身体年龄 [5，99]|O|
|bodyFatRate|double|体脂率 (0.0,100.0]|O|
|impedance|double|体脂称阻抗 欧姆 [1,200]|O|
|moistureRate|double|水分率 (0.0,100.0]|O|
|skeletalMuscleMass|double|骨骼肌 千克 [1,150]|O|
