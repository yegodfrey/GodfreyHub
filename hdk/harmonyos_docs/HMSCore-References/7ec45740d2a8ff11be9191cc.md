## Public Methods

### setAnalyticsEnabled

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setAnalyticsEnabled(final boolean enabled) 是否打开埋点采集能力。关闭后将不再记录任何数据，且不分析数据。 > 说明 > * 如果您已经调用过[setRestrictionEnabled](#section1448813311134)接口，再次打开埋点采集能力时，数据分析能力不会同步打开，需要您设置[setRestrictionEnabled](#section1448813311134)接口的参数值为**false**。 > * 如果您未调用过[setRestrictionEnabled](#section1448813311134)接口，再次打开埋点采集能力时，数据分析能力会同步打开。 > * 如果您在分析服务侧禁止数据采集，可能会影响[A/B测试](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-introduction-0000001058210679) 、[App Linking](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215)、[应用内消息](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-appmessage-introduction-0000001071884501)、[性能管理](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-apm-introduction-0000001052247254)服务的数据分析功能，也会影响[崩溃服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-crash-introduction-0000001055732708)的崩溃率。|

**Parameters**

|Name|Description|
|:------|:-----------------------------------------------------|
|enabled|是否打开埋点采集开关。默认值为**true**，表示打开埋点采集。 * true：打开 * false：关闭|

**Sample code：**

SDK默认打开采集数据，您可参考以下示例代码，关闭埋点采集能力。

```screen
"Java"
HiAnalyticsInstance instance = HiAnalytics.getInstance(context);
instance.setAnalyticsEnabled(false);
```

```screen
"Kotlin"
val instance = HiAnalytics.getInstance(context)
instance.setAnalyticsEnabled(false)
```

### setReportPolicies

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setReportPolicies(Set<[ReportPolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)> policies) 设置自动上报的策略。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|policies|支持四种上报策略，可以设置多个策略同时存在。 * [ON_APP_LAUNCH_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：应用启动上报策略，选择该策略时会立即上报一次，此后每次应用启动时上报一次。 * [ON_MOVE_BACKGROUND_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：应用切后台（包括应用退出）上报策略。 * [ON_SCHEDULED_TIME_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：定时上报策略，根据指定的间隔时间轮循上报事件，取值范围为[60, 1800]秒（默认60秒），如果设置的值超过给定范围则取边界值。 * [ON_CACHE_THRESHOLD_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：阈值上报策略，缓存事件条数达到阈值时上报事件，取值范围为[30, 1000]条（默认30条），如果设置的值超过给定范围则取边界值。|

> 说明
>
> * 以上上报策略仅在非调试模式下生效。
> * 应用切后台上报策略和阈值上报策略为必选策略，无论设置什么策略，这两个策略都会生效，但是可以改变阈值上报策略的阈值。
> * 多次调用设置上报策略的接口，会刷新上报策略，仅最后一次设置的策略生效，请谨慎多次调用。
> * 当策略满足触发事件上报时，如果没有网络，则会将事件缓存在本地，等待下次条件满足继续上报。
> * 上报策略持久化保存。

**Sample code** **：**

您可以参考以下示例代码，设置应用切后台上报策略和定时上报策略。

```screen
"Java"
// 创建应用切后台上报策略
ReportPolicy moveBackgroundPolicy = ReportPolicy.ON_MOVE_BACKGROUND_POLICY;
// 创建定时上报策略
ReportPolicy scheduledTimePolicy = ReportPolicy.ON_SCHEDULED_TIME_POLICY;
// 设置定时上报时间周期为600秒
scheduledTimePolicy.setThreshold(600);
Set<ReportPolicy> reportPolicies = new HashSet<>();
// 添加定时上报策略和应用切后台上报策略
reportPolicies.add(scheduledTimePolicy);
reportPolicies.add(moveBackgroundPolicy);
// 设置应用切后台上报策略和定时上报策略
instance.setReportPolicies(reportPolicies);
```

```screen
"Kotlin"
// 创建应用切后台上报策略
val moveBackgroundPolicy = ReportPolicy.ON_MOVE_BACKGROUND_POLICY
// 创建定时上报策略
val scheduledTimePolicy = ReportPolicy.ON_SCHEDULED_TIME_POLICY
// 设置定时上报时间周期为600秒
scheduledTimePolicy.threshold = 600
val reportPolicies = HashSet<ReportPolicy>()
// 添加定时上报策略和应用切后台上报策略
reportPolicies.add(scheduledTimePolicy)
reportPolicies.add(moveBackgroundPolicy)
// 设置应用切后台上报策略和定时上报策略
instance.setReportPolicies(reportPolicies)
```

### setRestrictionEnabled

|Method|

|public void setRestrictionEnabled(boolean isEnabled) 设置是否限制数据分析能力。限制分析开关默认值为**false**，即默认开启数据分析能力。 > 说明 > * 此接口设置为**true** 时，[setRestrictionShared](#section11693910145613)中的值也会被设置为**true**，即自动限制数据共享。 > * 此接口设置为**false** 时，若开启数据共享，需要手动设置[setRestrictionShared](#section11693910145613)为**false**。|

**Parameters**

|Name|Description|
|:--------|:--------------------------------------------------------|
|isEnabled|打开或关闭数据分析能力。默认值为**false**，即打开数据分析能力。 * true：关闭 * false：打开|

**Sample code：**

```screen
"Java"
// 限制数据分析，同时也会自动限制数据共享
HiAnalyticsInstance instance = HiAnalytics.getInstance(context);
instance.setRestrictionEnabled(true);

// 开启数据分析
instance.setRestrictionEnabled(false);

// 开启数据共享
instance.setRestrictionShared (false);
```

```screen
"Kotlin"
// 限制数据分析，同时也会自动限制数据共享
val instance = HiAnalytics.getInstance(context)
instance.setRestrictionEnabled(true)

// 开启数据共享
instance.setRestrictionShared (false)
```

```screen
"Java"
// 在Activity的onNewIntent中调用
public class MainActivity extends Activity {
    private HiAnalyticsInstance instance;
    @Override
    protected void onCreate(Bundle savedInstanceState){
        instance = HiAnalytics.getInstance(this);
    }	
    @Override
    protected void onNewIntent(Intent intent) {
        super.onNewIntent(intent);
        if (instance != null) {
            instance.onNewIntent(intent);
        }
    }
}
```
