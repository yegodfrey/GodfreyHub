# 主题订阅

> 注意
>
> 为了更安全的网络访问，华为推送服务于2022年11月30日关闭Push相关域名的TLS1.0、TLS1.1协议及规定之外的加密套件，关闭后，应用使用TLS1.2以下协议或使用规定外的加密套件将无法正常推送消息。
>
> 若您的应用访问Push相关域名使用协议是TLS1.0或TLS1.1，后续可能无法正常发送消息，**请您务必升级到TLS1.2及以上版本。**
>
> 调整指导请查阅《[Push Kit相关域名的TLS1.0和TLS1.1协议关闭通知](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/tls-0000001368035257)》，如您有任何疑问，请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/technical-support-0000001058590093)，感谢您对华为推送的支持。

## 功能介绍

此接口实现给单个或多个用户完成主题订阅操作。

## 接口约束

每次接口调用最大不超过1000个Token，并行发送主题消息数量最大不超过100个，目前只支持Android应用。

## 接口原型

|承载协议|HTTPS POST|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为Push服务器|
|接口URL|https://push-api.cloud.huawei.com/v1/**[clientid]**/topic:subscribe > 说明 > **[clientid]** ：OAuth2.0客户端ID（凭据），登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"开发与服务"，在项目列表中选择对应的项目，左侧导航栏选择"项目设置"，在该页面获取。|
|数据格式|请求消息：Content-Type: application/json;charset=UTF-8 响应消息：Content-Type: application/json|

## 请求参数

**Request Header**

|参数|取值描述|样例|
|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------|
|Authorization|通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)获取的 Access Token 或者[基于服务账号生成的鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)。 > 说明 > Bearer后面拼接空格，再拼接获取的 Access Token 或 JSON Web Token。|Bearer CF3Xl2XV6jMK*******ccUIaDg== 或 Bearer eyJr*****OiIx****.eyJh*****iJodHR**.QRod*****4Gp****|

**Request Body**

|参数|是否必选|参数类型|描述|
|:---------|:---|:-------------|:-------------------------------------------------------------|
|topic|是|String|订阅的主题名称，最大不能超过900个字符，支持的字符包括数字、字母、下划线、百分号、中文、英文点号、英文波浪号、英文破折号。|
|tokenArray|是|Array [String]|订阅的Token列表，最大不能超过1000个。样例：["pushtoken1","pushtoken2"]。|

## 请求示例

```screen
{
    "topic": "weather",
    "tokenArray": [
        "pushtoken1",
        "pushtoken2"
    ]
}
```

## 响应参数

**Response Body**

|参数|参数类型|描述|
|:-----------|:-------------|:------------------------------------|
|code|String|错误码。|
|msg|String|错误码描述。|
|requestId|String|请求标识。|
|failureCount|Integer|失败数量。|
|successCount|Integer|成功数量。|
|errors|Array [Object]|错误列表。 * index：错误Token下标 * reason：错误描述|

## 响应示例

```screen
{
    "msg": "partial token processed fail",
    "code": "82000010",
    "requestId": "1574*******00701",
    "successCount": 1,
    "failureCount": 1,
    "errors": [
        {
            "index": 0,
            "reason": "wrong token format"
        }
    ]
}
```

## 错误码

|HTTP错误码|描述|解决方法|
|:------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|200|成功。|不涉及。|
|400|参数错误。|请根据错误码描述进一步排查问题。|
|401|鉴权失败。|请求HTTP头中Authorization参数鉴权令牌错误。|
|404|找不到服务。|请检查请求URI是否正确。|
|500|服务内部错误。|请选择"支持 > 技术支持 > 在线提单"提交问题，技术支持人员会及时处理。|
|502|请求连接异常，常见于网络状况不稳定。|建议稍后重试，或联系[技术支持](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/technical-support-0000001058590093)解决。|
|503|流量控制。|1. 平均分配发送速度，尽量控制在华为提供的QPS配额内。QPS配额请查看[FAQ](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050042183#ZH-CN_TOPIC_0000001652491960__p833162017110)。 2. 平均分布推送时间段，不要集中发送。|
