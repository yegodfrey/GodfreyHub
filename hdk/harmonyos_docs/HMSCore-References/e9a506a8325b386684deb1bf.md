# Overview

提供信标围栏、活动状态围栏、耳机状态围栏、位置围栏、时间围栏、环境光围栏、车载蓝牙围栏、Wi-Fi围栏和屏幕围栏。同时提供围栏管理：添加、查询、更新、删除，以及围栏的组合逻辑运算。  

#### Interface Summary

|Interface|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[BarrierStatusMap](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierstatusmap-0000001050166320)|通过在[BarrierQueryRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierqueryrequest-0000001050164090)中输入围栏参数得到的围栏状态集合。|

#### Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|围栏基础类，支持围栏的逻辑运算。|
|[BeaconBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-beaconbarrier-0000001050166077)|信标围栏，包括发现、接近和丢失围栏。|
|[BehaviorBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-behaviorbarrier-0000001050164122)|活动状态检测围栏，包括活动开始、活动结束和活动进行中围栏。|
|[HeadsetBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-headsetbarrier-0000001050164086)|耳机围栏，包括连接、未连接、状态驻留的围栏。|
|[LocationBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-locationbarrier-0000001050164124)|位置围栏，包括进入、离开和驻留的围栏。|
|[TimeBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-timebarrier-0000001050166041)|时间围栏，支持按照时间状态设置单次触发和周期触发的围栏。|
|[AmbientLightBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-ambientlightbarrier-0000001050164088)|光照度围栏，提供小于（below）设定值、大于（above）设定值、在设定的区间（range）三种围栏能力。|
|[BluetoothBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-bluetoothbarrier-0000001050166043)|车载蓝牙围栏，包括连接、未连接、状态驻留的围栏。|
|[BarrierQueryRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierqueryrequest-0000001050164090)|查询围栏的请求。|
|[BarrierQueryResponse](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierqueryresponse-0000001050166045)|查询围栏的响应。|
|[BarrierStatus](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierstatus-0000001050164092)|将围栏状态封装在[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)中。其中，围栏状态包括当前状态、上一次状态和上一次围栏状态更新的时间。|
|[BarrierUpdateRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierupdaterequest-0000001050164128)|添加或删除围栏的请求。|
|[BarrierUpdateRequest.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-barrierupdaterequest-builder-0000001050164094)|添加或删除围栏请求的构造器。|
|[WifiBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifibarrier-0000001055262759)|Wi-Fi围栏，包括Wi-Fi状态驻留、Wi-Fi已连接、Wi-Fi断连、打开WLAN、关闭WLAN的围栏。|
|[ScreenBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/screenbarrier-0000001054982744)|屏幕围栏，包括状态驻留、亮屏，灭屏和解锁的围栏。|
