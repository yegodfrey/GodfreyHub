# 公共说明

## REST接口说明

* 接口概述 本文描述的接口为Search Kit云侧对外开放接口。

* 接口规范 当您调用该接口和Search Kit的云侧服务（Search Kit Service）交互时，请求符合RESTful规范。

  > 说明
  >
  > 接口的认证凭据获取方式：[OAuth 2.0开放鉴权-客户端模式（Client Credentials）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。

## 站点信息

调用Search Kit的服务端API时，在不同站点有不同的rootUrl。您应选择最近的站点访问。使用站点地址和后续章节中的接口URL拼接成完整的URL。

|服务|站点信息（rootUrl）|
|:---------|:-------------------------------------------------------------|
|Web Search|亚非拉：search-dra.cloud.huawei.com 欧洲：search-dre.cloud.huawei.com|
