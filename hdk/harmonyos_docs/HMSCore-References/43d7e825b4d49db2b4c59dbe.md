# BitmapDescriptorFactory

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class BitmapDescriptorFactory 用于创建Bitmap图像的定义。 在使用此类中的任何方法之前，必须执行以下操作之一以确保初始化此类： * 等待[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)从[MapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapfragment-0000001050150294)或[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)中可用。您可以通过调用getMapAsync()并等待onMapReady(HuaweiMap huaweiMap)回调来获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)实例。 * 调用[MapsInitializer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366).[initialize](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366#section1516212511479)(Context context)接口，完成初始化。|
