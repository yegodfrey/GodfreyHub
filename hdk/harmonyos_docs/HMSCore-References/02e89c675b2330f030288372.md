# 获取实时心率数据

#### startReadingHeartRate(String callBack, Map map)

|Method|
|:-------------------------------------------------------------------|
|startReadingHeartRate(String callBack, Map map) 开始获取实时心率。该接口只在手机上支持。|

Parameters  

|Name|Description|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|callBack|实时心率回调|
|map|全局事件回调集合，定义方法请参照[初始化模块](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-integration-hms-core-sdk-0000001226760449#section159413421451)。|

Returns  

|Type|Description|
|:--------------------------|:-----------------------------------------------------|
|Promise\<Result\<String\>\>|返回实时心率回调数据。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

注册实时心率回调示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
var heartRateData;
HMSHealthKit.startReadingHeartRate((callback) => {
    if (heartRateData?.data === callback?.data) {
        return;
    } else {
        heartRateData = callback;
    }
    // 心率实时回调
    console.info("startHeartRate callback: " + JSON.stringify(heartRateData.data))
}, this.$app.$def.hmsData.eventCallbackMap);
```

上面的代码片段中用到this.$app.$def.hmsData.eventCallbackMap为全局事件回调集合，定义方法请参照[初始化模块](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-integration-hms-core-sdk-0000001226760449#section159413421451)。  

#### stopReadingHeartRate()

|Method|
|:------------------------------------------|
|stopReadingHeartRate() 结束获取实时心率。该接口只在手机上支持。|

Returns  

|Type|Description|
|:--------------------------|:----------------------------------------------------------|
|Promise\<Result\<String\>\>|返回取消实时心率回调的异步回调。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

取消实时心率回调的示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.stopReadingHeartRate().then((result) => {
    // 调用成功
    console.info("stopReadingHeartRate success: " + JSON.stringify(result.data))
}).catch((error) => {
    // 调用失败
    console.info("stopReadingHeartRate fail: " + JSON.stringify(error))
});
```
