# HuaweiMap.OnMarkerClickListener

|Interface Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface HuaweiMap.OnMarkerClickListener 是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)类的一个内部接口，表示标记点击事件的侦听器，包含一个抽象函数[onMarkerClick](#section165540817477)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|abstract boolean|[onMarkerClick](#section165540817477)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 点击标记时回调此方法。|

#### Public Methods

#### onMarkerClick

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract boolean onMarkerClick([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 点击标记时回调此方法。 说明： 点击标记时发生的第一件事是关闭当前显示的所有信息窗口并触发[HuaweiMap.OnInfoWindowCloseListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/oninfowindowcloselistener-0000001050151987)，然后再触发[HuaweiMap.OnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerclicklistener-0000001050152047)。因此，从任何标记的[OnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerclicklistener-0000001050152047)中调用[isInfoWindowShown](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section643110419342)()都将返回false。|

Parameters  

|Name|Description|
|:-----|:----------|
|marker|标记。|

Returns  

|Type|Description|
|:------|:-----------------------------|
|boolean|当侦听器没有执行默认行为则返回true，否则返回false。|
