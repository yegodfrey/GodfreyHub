# ReadOptions

|Class Info|
|:--------------------------------------------------------------------------------------|
|public class ReadOptions 数据读取请求类，使用此请求可以指定要读取的数据类型以及聚合参数，读取请求需要设置时间范围，并允许以详细或汇总的方式读取数据。|

构建ReadOptions查询详情数据，需要指定详情数据的时间区间（必填），一个或多个特定的DataType或DataCollector。

构建ReadOptions查询数据详情的示例代码如下：

1. 构建ReadOptions读一个指定DataType（增量步数）的详情。  
   示例代码如下：

   ```
   "Java"
   ReadOptions readOptions = new ReadOptions.Builder()
       .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
       .read(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .build();
   ```

   ```
   "Kotlin"
   val readOptions = ReadOptions.Builder()
       .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
       .read(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .build()
   ```

2. 构建ReadOptions读取多个指定DataType（增量步数和身高）的详情。  
   示例代码如下：

   ```
   "Java"
   ReadOptions readOptions = new ReadOptions.Builder()
       .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
       .read(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .read(DataType.DT_INSTANTANEOUS_HEIGHT)
       .build();
   ```

   ```
   "Kotlin"
   val readOptions = ReadOptions.Builder()
       .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
       .read(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .read(DataType.DT_INSTANTANEOUS_HEIGHT)
       .build()
   ```

3. 构建ReadOptions读取指定DataCollector的详情。  
   示例代码如下：

   ```
   "Java"
   ReadOptions readOptions = new ReadOptions.Builder()
       .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
       .read(dataCollectorDevices)
       .build();
   ```

   ```
   "Kotlin"
   val readOptions = ReadOptions.Builder()
       .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
       .read(dataCollectorDevices)
       .build()
   ```

构建ReadOptions查询汇总数据，需要指定汇总数据的时间区间（必填），汇总方式（必填），分组方式（必填）。  
构建ReadOptions查询数据汇总的示例代码如下：

```
"Java"
ReadOptions readOptions = new ReadOptions.Builder()
    .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
    .polymerize(DataType.DT_CONTINUOUS_STEPS_DELTA, DataType.DT_CONTINUOUS_STEPS_TOTAL)
    .groupByTime(1, TimeUnit.HOURS)
    .build();
```

```
"Kotlin"
val readOptions = ReadOptions.Builder()
    .setTimeRange(startTime, endTime, TimeUnit.MILLISECONDS)
    .polymerize(DataType.DT_CONTINUOUS_STEPS_DELTA, DataType.DT_CONTINUOUS_STEPS_TOTAL)
    .groupByTime(1, TimeUnit.HOURS)
    .build()
```
