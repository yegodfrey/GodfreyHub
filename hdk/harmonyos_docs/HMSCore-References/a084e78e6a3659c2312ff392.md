# 错误码

|状态码|错误码|描述|解决方法|
|:--|:----|:----------------------------------|:------------------------------------|
|400|10020|非法参数。|请修改填写错误的参数值。|
|400|10008|接口请求过于频繁。|请提示用户请求导出数据过于频繁，稍后再试。|
|400|10030|用户已申请删除个人数据，无法导出。|请提示用户数据已经删除。|
|400|10031|用户申请数据已导出，上次请求距离当前请求未超过两个月。|请提示用户需要距上次导出请求两个月后，才可以再次请求导出个人数据。|
|400|10032|数据导出中，无法删除。|请提示用户，正在导出该用户的个人数据，需要待导出完成后，重新申请删除数据。|
|400|10033|数据已删除。|请提示其用户数据已经删除。|
|400|10009|超过任务上限，同一个App下最多允许同时存在3个进行中的数据导出任务。|请等待其中的某些或者全部任务执行完成后重新调用创建导出任务。|
|400|19910|* 鉴权请求超时，请稍后重试。 * 鉴权服务器内部错误，请稍后重试。|请稍后重试。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
