### getInstance

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|getInstance(bundleName:string, routePolicy?:string): Promise<void> 获取Analytics Kit实例。 > 说明 > * 需通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/)申请多数据处理位置功能体验，该接口方可生效。在线提单操作详情请参见[在线提单指导](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/online-application-guide-0000001174952406)。 > * 如果已经调用过[getInstance](#section14289539163414)(bundleName:string, routePolicy?:string)设置了指定的数据处理位置，再次调用[getInstance](#section14289539163414)(bundleName: string)时将会切换成默认数据处理位置。 > * 使用多数据处理位置接口时，请务必下载应用对应的最新AGC配置文件，下载方法：在"项目设置"页面中，点击"应用"栏下的"agconnect-services.json"。 > * 如果您的应用发布到全球多个国家，建议您启用多数据处理位置，按照用户实际使用区域指定数据上报位置。|

**Parameters**

|Name|Description|
|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|bundleName|开发者应用的bundleName。 示例：com.huawei.harmonyos.demo|
|routePolicy|设置的数据处理位置。 数据处理位置包括：CN(中国)、DE(德国)、SG(新加坡)、RU(俄罗斯)。 > 说明 > * 设置的数据处理位置必须是开通过存储权限的数据处理位置，如果没有开通，数据将无法上报，请务必设置有效的数据处理位置。 > * 当不填写routePolicy时，数据上报到默认数据处理位置。|

### setAnalyticsEnabled

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|setAnalyticsEnabled(flag:boolean): Promise<void> 是否打开埋点采集能力。关闭后将不再记录任何数据。 > 说明 > * 如果您已经调用过[setRestrictionEnabled](#section1448813311134)接口，再次打开埋点采集能力时，数据分析能力不会同步打开，需要您设置[setRestrictionEnabled](#section1448813311134)接口的参数值为**false**。 > * 如果您未调用过[setRestrictionEnabled](#section1448813311134)接口，再次打开埋点采集能力时，数据分析能力会同步打开。|

**Parameters**

|Name|Description|
|:---|:-------------------------------------------|
|flag|是否打开埋点采集开关。默认为**true**。 * true：打开 * false：关闭|

**Sample code：**

SDK默认打开采集数据，您可参考以下示例代码，关闭埋点采集能力，请将*com.huawei.harmonyos.demo*替换为您的bundleName。

```screen
let bundleName = 'com.huawei.harmonyos.demo';
analytics.getInstance(bundleName); 
analytics.setAnalyticsEnabled(false);
```

### setReportPolicies

|Method|
|:--------------------------------------------------------------------------------------|
|setReportPolicies(policies: { [key:string]:number | string }): Promise<void> 设置自动上报的策略。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|policies|支持四种上报策略，可以设置多个策略同时存在。 * [ON_APP_LAUNCH_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：应用启动上报策略，选择该策略时会立即上报一次，此后每次应用启动时上报一次。 * [ON_MOVE_BACKGROUND_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：应用切后台（包括应用退出）上报策略。 * [ON_SCHEDULED_TIME_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：定时上报策略，根据指定的间隔时间轮循上报事件，取值范围为[60, 1800]秒（默认60秒），如果设置的值超过给定范围则取边界值。 * [ON_CACHE_THRESHOLD_POLICY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-reportpolicy-0000001058890134)：阈值上报策略，缓存事件条数达到阈值时上报事件，取值范围为[30, 1000]条（默认30条），如果设置的值超过给定范围则取边界值。|

> 说明
>
> * 以上上报策略仅在非调试模式下生效。
> * 应用切后台上报策略和阈值上报策略为必选策略，无论设置什么策略，这两个策略都会生效，但是可以改变阈值上报策略的阈值。
> * 多次调用设置上报策略的接口，会刷新上报策略，仅最后一次设置的策略生效，请谨慎多次调用。
> * 当策略满足触发事件上报时，如果没有网络，则会将事件缓存在本地，等待下次条件满足继续上报。
> * 上报策略持久化保存。

**Sample code** **：**

您可以参考以下示例代码，设置应用切后台上报策略和定时上报策略。

```screen
// 设置应用切后台上报策略和定时上报策略 
analytics.setReportPolicies({ ON_SCHEDULED_TIME_POLICY: 60, ON_MOVE_BACKGROUND_POLICY: '' });
```
