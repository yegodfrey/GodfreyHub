# Circle

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class Circle 地图上的圆形对象，包括实心圆和空心圆两种。在调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)类的[addCircle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582#section7603022114010)方法时会返回该类型的实例。|

## Public Methods

### remove

|Method|
|:--------------------------------------------------------|
|public void remove() 您调用此API可以从地图上移除该圆，移除后，该圆的所有方法行为都将无效。|

### setCenter

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setCenter([LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535) center) 您调用此API可以给圆心设置经纬度坐标，该圆心不能为空，因为圆没有默认的圆心。 > 说明 > 圆的中心点纬度在[-85.051119, 85.051119]范围内才能画出圆。若圆中心点纬度正好为-85.051119或85.051119时，能画出半径为1米的圆。|

**Parameters**

|Name|Description|
|:-----|:----------|
|center|圆心对象。|

**Throws**

|Name|Description|
|:-------------------|:------------------|
|NullPointerException|当传入的center为空时，抛出异常。|

### setFillColor

|Method|
|:---------------------------------------------------------------------------------------------|
|public void setFillColor(int color) 您调用此API可以设置圆的填充色，如果使用Color.TRANSPARENT.getValue()，则不会绘制填充。|

**Parameters**

|Name|Description|
|:----|:-------------------------------|
|color|ARGB格式颜色值，默认填充色为透明色（0x00000000）。|

### setRadius

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|public void setRadius(double radius) 您调用此API可以设置圆的半径。 > 说明 > 圆的中心点纬度在[-85.051119, 85.051119]范围内才能画出圆。若圆中心点纬度正好为-85.051119或85.051119时，能画出半径为1米的圆。|

**Parameters**

|Name|Description|
|:-----|:-------------------------|
|radius|圆的半径，单位：米。取值范围：大于等于0，默认为0。|

### setStrokeWidth

|Method|

**Parameters**

|Name|Description|
|:----|:----------------------------|
|width|边框的宽度，单位：像素。取值范围：大于等于0，默认为10。|

### setStrokeColor

|Method|
|:------------------------------------------------------------------------------------------------|
|public void setStrokeColor(int color) 您调用此API可以设置圆的边框颜色，如果使用Color.TRANSPARENT.getValue()，则不会绘制边框。|

**Parameters**

|Name|Description|
|:----|:----------------------------|
|color|ARGB格式的颜色值，默认为黑色（0xff000000）。|

### setZIndex

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setZIndex(float zIndex) 设置圆的z指数。z指数指的是圆的叠加顺序，具有较大z指数的圆会绘制在具有较小z指数的圆上，具有相同z指数的叠加顺序为元素添加的先后顺序。默认的z指数是0。 > 说明 > 数量限制：添加Circle和Polygon的总数乘以2加上添加Polyline和GroundOverlay的总数不超过1450，否则会出现图形叠加错误。|

**Parameters**

|Name|Description|
|:-----|:-----------------|
|zIndex|z指数，即圆的叠加顺序。默认值为0。|

### setVisible

|Method|
|:---------------------------------------------------------------------------------------|
|public void setVisible(boolean visible) 您调用此API可以设置圆的可见性，如果圆不可见，则不会绘制，其他所有状态均保留，圆默认是可见的。|

**Parameters**

|Name|Description|
|:------|:-------------------------------------|
|visible|圆的可见性。 * true：可见 * false：不可见 默认值为true。|
