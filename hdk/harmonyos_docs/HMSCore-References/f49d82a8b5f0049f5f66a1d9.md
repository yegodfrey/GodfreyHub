# DataCollector

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class DataCollector 定义唯一的数据采集器。数据采集器可以提供手机或者外接设备的原始数据，多个数据采集器通过转换或者合并可以生成派生数据。每个采集点必须有一个对应的数据采集器。 开发者可以主动查询数据，也可以通过注册listener在固定时间间隔获取数据。 数据采集器在创建时会产生唯一的标识符，该标识符由相关的数据采集器的类型、设备信息、应用程序包名等组成。|
