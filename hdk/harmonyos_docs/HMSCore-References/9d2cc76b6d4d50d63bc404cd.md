# City

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class [City](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/city-0000001050975621) implements Parcelable 天气状态WeatherSituation中的城市信息。包括城市码、省份名称、时区、和城市/区名称。|
