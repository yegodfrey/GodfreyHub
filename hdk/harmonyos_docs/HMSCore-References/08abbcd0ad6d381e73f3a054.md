### getToken:(NSString *) apnsToken

|Method|
|:----------------------------------------------------------------------------------------------------------------|
|- (NSString *)getToken:(NSString *) apnsToken 获取接入推送服务所需的Token。如果本地没有生成AAID，调用本方法会自动生成AAID，Push服务端生成Token时依赖AAID。|

**Parameters**

|Name|Description|
|:--------|:---------------------------------------------------------------|
|apnsToken|从APNs（苹果推送通知服务）获取的device token（设备Token），device token是iOS设备的唯一标识。|

**Returns**

|Type|Description|
|:--------|:--------------|
|NSString*|接入推送服务所需的Token。|

```screen
"Objective-C"
#import <HmsPushSdk/HmsInstanceId.h>
NSString *apnsToken = @"yourApnsToken";
NSString *huaweiToken = [[HmsInstanceId getInstance] getToken:apnsToken];
```

```screen
"Swift"
import HmsPushSdk
let apnsToken = "yourApnsToken";
let huaweiToken = HmsInstanceId.getInstance().getToken(apnsToken);
```

### getToken:(NSString* apnsToken, NSString* subjectId)

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (NSString *)getToken:(NSString *) apnsToken subjectId:(NSString*) subjectId; 在多发送者场景下，目标应用给发送者申请Token的方法，subjectId需要传入[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中发送者的项目ID。|

**Parameters**

|Name|Description|
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|apnsToken|从APNs（苹果推送通知服务）获取的device token（设备Token），device token是iOS设备的唯一标识。|
|subjectId|发送者的项目ID，登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"我的项目"，在项目列表中选择对应的项目，左侧导航栏选择"项目设置"，在该页面获取发送者的项目ID。|

**Returns**

|Type|Description|
|:--------|:--------------|
|NSString*|接入推送服务所需的Token。|

```screen
"Objective-C"
#import <HmsPushSdk/HmsInstanceId.h>
NSString *apnsToken = @"yourApnsToken";
NSString *projectId = @"yourProjectId";
NSString *huaweiToken = [[HmsInstanceId getInstance] getToken:apnsToken subjectId:projectId];
```

```screen
"Swift"
import HmsPushSdk
let projectID = "yourProjectId";
let apnsToken = "yourApnsToken";
let hwTokenSubProjectId = HmsInstanceId.getInstance().getToken(apnsToken,subjectId: projectID);
```
