# HwErrorTipTextLayout

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------|
|public class HwErrorTipTextLayout extends LinearLayout HwErrorTipTextLayout是一个包裹了EditText的布局，如果用户输入使得提示文本隐藏，这个布局可以显示一个浮动光标。|

#### XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:-------------------------------------|
|boolean|hwErrorEnabled 判断是否为错误态。|
|enum|hwShapeMode 定义输入框形状（胶囊型、线型）。|
|drawable|hwErrorLinearEditBg 定义华为线性错误编辑框背景。|
|drawable|hwErrorResBg 定义华为错误资源背景。|
|drawable|hwEditTextBg 定义华为编辑文本背景。|
|reference|hwErrorTipTextAppearance 定义华为错误提示文本皮肤。|
|drawable|hwLinearEditBg 定义线性编辑背景。|
