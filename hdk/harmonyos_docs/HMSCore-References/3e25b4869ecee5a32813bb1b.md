# HWAuthLoginApi

HWAuthLoginApi用于提供进行免登录授权业务处理的能力。  

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------------------------------------------------------------|
|instancetype|[sharedInstance](#section1177142134312) 生成一个单例对象。|
|void|[registerApp](#section593316567515) 注册三方应用。|
|void|[authLoginAction](#section20396113015526) 授权登录（授权结果自行从openurl方法获取授权结果。）|
|void|[authLoginActionWithSportHealthApp](#section16579173915020) 授权登录，授权完成后引导用户打开上云开关（授权结果自行从openurl方法获取授权结果。）|

#### registerApp

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (void)registerApp:(NSString \*)clientId scope:(NSArray \*)scope redirectUri:(NSString \*)redirectUri signature:(NSString \*)signature state:(NSString \*)state;|
|注册三方应用，用于跳转华为运动健康App登录授权或跳转H5页面登录授权。|

Parameters  

|Name|Description|
|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|clientId|注册应用时获得的App ID。|
|scope|申请授权的Scope权限数组。|
|redirectUri|授权后要回调的URI，即接收Authorization Code的URI。这个回调地址与[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud-free-auth-login-iso-prep-0000001985833184)中配置的"应用scheme地址"一致。|
|signature|deepLink签名，申请Scheme地址时云端分配的secret。在完成"应用scheme地址"配置后，点击应用查看应用详情，"Scheme 信息 \> Scheme Secret"中的值即为签名。|
|state|随机串，用于防CSRF，在返回授权码Code时原封不动返回。|
