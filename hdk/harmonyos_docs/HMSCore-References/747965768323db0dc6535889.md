## Public Methods

### getTile

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract [Tile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/tile-0000001050153285) getTile(int x, int y, int zoom) 此API可以返回指定坐标和缩放级别下的瓦片图层对象。|

**Parameters**

|Name|Description|
|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x|tile的横坐标，取值范围：[0, 2^zoom^ - 1]。|
|y|tile的纵坐标，取值范围：[0, 2^zoom^ - 1]。|
|zoom|瓦片的缩放级别，范围通过类[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)的[getMinZoomLevel](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section15491181135412)()和[getMaxZoomLevel](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section10176115075312)()获得。|

**Return** **s**

|Type|Description|
|:---|:----------------------------------------------------------------------------------------------------------|
|Tile|指定坐标和缩放级别下的[Tile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/tile-0000001050153285)对象。|
