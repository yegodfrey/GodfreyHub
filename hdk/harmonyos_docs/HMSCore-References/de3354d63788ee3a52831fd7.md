# 同步/异步更新规则

对卡券模板的修改可以使用"全量更新卡券模板"、"局部更新卡券模板"和"卡券模板增加message"三类接口。当开发者对某一个卡券模板进行修改之后，与之关联的已被用户领取的卡券都会被相应地更新。有以下两种更新场景：

场景一：与被更新模板关联的用户卡券数量小于等于10000个。模板被修改后，用户卡券会被同步更新，约在几分钟之后生效。

场景二：与被更新模板关联的用户卡券数量大于10000个。模板被修改后，用户卡券会在华为钱包服务器所处地区的第二天凌晨被更新。更新完成后，华为钱包服务器会调用[钱包卡券事件回调通知接口](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/callback-0000001050160427)通知开发者服务器，"eventType"参数的值为"TASK_RESULT_NOTIFY"，"sceneType"参数的值为"MODEL_ASYNC_UPDATE_SUCCESS"。
