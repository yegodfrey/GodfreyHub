# HWPolyUtils

#### 概述

经纬度编解码工具类。

|函数|描述|
|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
|HWMapJsSDK.HWPolyUtils|[overviewPolyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section2645183017570)编解码工具类。|
