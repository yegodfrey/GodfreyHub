# HmsMessageService

* 支持的场景：手机、平板。
* 支持的OS：EMUI 3.0及以上，Android 4.4及以上。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230913165242.92176818016536712818781117336057:50001231000000:2800:C23135A3DA49DDB9BD3727D67550B41CBAEDE2EACADBB6DBAA0B721ED1879D8F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
多发送者功能支持的OS为EMUI 9.1.0+。  

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HmsMessageService extends Service Push Kit中的基础类，用于接收下行消息或者刷新的Token。 为了接收下行消息或者刷新的Token，您需要在应用的"AndroidManifest.xml"文件中声明HmsMessageService的实现类。在实现类中需要重写基类中的所有方法来处理Push SDK的返回的数据。HmsMessageService类中所有的回调方法需要您保证能够在10s内处理完成，超过10s由您自己起新任务处理。 "AndroidManifest.xml"文件中需要包含： ``` <service android:name=".YourHmsMessageService" android:exported="false"> <intent-filter> <action android:name="com.huawei.push.action.MESSAGING_EVENT"/> </intent-filter> </service> ```|

#### onNewToken(String token)

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onNewToken(String token) 应用调用[HmsInstanceId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-instanceid-0000001050255634)中的[getToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)方法向服务端申请Token，如果服务端当次没有返回Token值，后续服务端返回Token通过此方法返回。主要包含如下场景： * 申请Token如果当次调用失败，Push会自动重试申请，成功后则以onNewToken方法返回。 * 华为设备上EMUI版本低于10.0申请Token时，以onNewToken方式返回。|

Parameters  

|Name|Description|
|:----|:----------------|
|token|Push SDK返回的Token。|

#### onNewToken(String token, Bundle bundle)

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onNewToken(String token, Bundle bundle) 应用调用[HmsInstanceId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-instanceid-0000001050255634)中的[getToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)(String appId, String scope)方法向服务端申请Token，如果服务端当次没有返回Token值，后续服务端返回Token通过此方法返回。主要包含如下场景： * 申请Token如果当次调用失败，Push会自动重试申请，成功后则以onNewToken方法返回。 * 华为设备上EMUI版本低于10.0申请Token时，以onNewToken方式返回。 在多发送者场景下，应用调用[HmsInstanceId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-instanceid-0000001050255634)中的[getToken](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-instanceid-0000001050255634#section197651125175917)(String subjectId)方法向Push服务端申请Token成功时，服务端返回Token时通过此方法返回。Bundle中包含一些额外的返回数据，可以通过HmsMessageService.[SUBJECT_ID](#section10846194219216)等key值获取。 说明： 如果您集成的Push SDK版本为5.0.4.302及以上，建议您使用此方法获取Token。|

Parameters  

|Name|Description|
|:-----|:-----------------------|
|token|Push SDK返回的Token。|
|bundle|Push SDK返回的除Token外的其他数据。|
