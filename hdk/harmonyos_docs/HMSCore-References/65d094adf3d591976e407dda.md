#### Sample Code

```
private void subscribeFile(Drive drive, String fileId){
    try{
        Channel channel = new Channel();
        channel.setId("id" + System.currentTimeMillis());
        channel.setType("web_hook");
        channel.setUrl("https://......");
        Channel result = drive.files().subscribe(fileId, channel).execute();
    } catch (Exception e){
        Log.e(TAG, "subscribeFile error: " + e.getMessage());
    }
}
```
