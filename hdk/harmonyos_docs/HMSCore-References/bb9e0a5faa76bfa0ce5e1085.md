# LocationList

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----|:---|
|longitude|是|String|经度信息|
|latitude|是|String|纬度信息|

示例：

```codeblock
{
    "locationList": [
        {
            "longitude": "114.0679603815",
            "latitude": "22.6592051284"
        }
    ]
}
```
