#### anchorMarker

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public MarkerOptions anchorMarker(float anchorU, float anchorV) 您调用此API可以设置标记的锚点位置。锚点是标记图标接触地图平面的点，图标的左顶点为（0, 0）点，右顶点为（1, 0）点，左底点为（0, 1）点，右底点为（1, 1）点。例如，在标记X（0.5, 0.3）处的锚点坐标如下： ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240929170023.92743752817544172543691636041382:50001231000000:2800:6E00C872E02F8164ED85AB7564888276DBB308244313019F9045C3EE46C92326.png?needInitFileName=true?needInitFileName=true "点击放大")|

Parameters  

|Name|Description|
|:---|:-------------------------------------|
|u|锚点的水平坐标，以图像宽度的比例，建议取值\[0, 1\]，默认值为0.5。|
|v|锚点的垂直坐标，以图像高度的比例，建议取值\[0, 1\]，默认值为1。|

Returns  

|Type|Description|
|:------------|:-------------------------|
|MarkerOptions|设置新的锚点位置后的MarkerOptions对象。|

#### flat

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------|
|public MarkerOptions flat(boolean flat) 您调用此API可以设置标记是否平贴地图。如果标记平贴地图，则在相机旋转和倾斜时，标记仍将停留在地图上，保持与照相机缩放时相同的大小。如果标记面对相机，它将始终面向相机绘制，并随相机旋转和倾斜。|

Parameters  

|Name|Description|
|:---|:----------------------------------|
|flat|* true：平贴地图 * false：面对相机 默认值为false。|

Returns  

|Type|Description|
|:------------|:---------------------------|
|MarkerOptions|设置新的flat属性后的MarkerOptions对象。|
