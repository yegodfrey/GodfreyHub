# AggrPayClient

* 支持的设备：华为手机。
* 支持的OS：EMUI 3.0+、Android 4.4+、HarmonyOS 2.0+。

|Interface Info|
|:-----------------------------------------------------|
|public interface AggrPayClient 包含了PaymentService的所有接口。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:--------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------|
|[PayResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/aggrpay-entity-pay-result-0000001588233533)|[pay](#section160418663212)(String orderStr) 手机拉起PaymentService收银台接口。|
|[PayResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/aggrpay-entity-pay-result-0000001588233533)|[combinedPay](#section149681049348)(String orderStr) 手机拉起PaymentService合单支付收银台接口。|
|[ContractResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-entity-contract-result-0000001638831782)|[signContract](#section12289185817129)(String orderStr) 手机拉起PaymentService签约界面接口。|

#### pay

|Method|
|:-------------------------------------------------------------|
|PayResult pay(String orderStr) 调起PaymentService服务收银台接口并返回支付结果。|

Parameters  

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|orderStr|商户[预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-android-pre-pay-order-0000001589121249)成功返回prepayId后，由商户服务器返回的orderStr。|

orderStr参数说明  

|参数|参数类型|是否必填|描述|
|:--------|:-----|:---|:---------------------------------------------------------------|
|app_id|String|M|应用ID。|
|merc_no|String|M|商户号。|
|prepay_id|String|M|prepayId，使用预下单请求生成，有效期2小时。|
|timestamp|String|M|时间戳，标准北京时间，时区为东八区，自1970年1月1日 0点0分0秒以来的毫秒数，13位。示例值：1666230721315。|
|noncestr|String|M|随机字符串，不长于32位。推荐随机数生成算法。|
|sign|String|M|签名，使用除了sign字段以外的其他字段计算签名值。用于开发者对响应报文进行防篡改验证。|
|auth_id|String|M|开放平台分配的鉴权id，一个商户可配置多套证书，请妥善保管。|

Returns  

|Type|Description|
|:--------|:----------------|
|PayResult|支付完成后端侧同步返回的支付结果。|

Sample code：

```
public void payApi(final Activity activity, Handler handler) {
     String orderStr = "{\"app_id\":\"***\",\"merc_no\":\"***\",\"prepay_id\":\"1230331185102089244382635044\",\"timestamp\":\"1680259863114\",\"noncestr\":\"1487b8a60ed9f9ecc0ba759fbec23f4f\",\"sign\":\"****\",\"auth_id\":\"***\"}"
    Runnable runnable = () -> {
        AggrPayClient client = Pay.getPayClient(activity);
        PayResult result = client.pay(orderStr);
        handler.post(() -> dealOminPayResult(result));
    };
    Thread payThread = new Thread(runnable);
    payThread.start();
}
/**
 * 支付结果处理
 *
 * @param payResult
 */
private void dealOminPayResult(PayResult payResult) {
    if (payResult == null) {
        Log.e("支付失败", false);
        return;
    }
    String returnCode = payResult.getReturnCode();
    String returnMsg = payResult.getReturnMsg();
    // 如果returnCode="0"，表示成功，注意：为了支付安全，请以服务器的通知或查询结果为准。
}
```

#### signContract

|Method|
|:-----------------------------------------------------------------------------|
|ContractResult signContract(String contractStr) 调起PaymentService服务签约接口并返回签约结果。|

Parameters  

|Name|Description|
|:----------|:----------------------------------------|
|contractStr|商户预下单成功返回preSignNo后，由商户服务器返回的contractStr。|

contractStr参数说明  

|参数|参数类型|是否必填|描述|
|:--------|:-----|:---|:---------------------|
|appId|String|M|应用ID。|
|preSignNo|String|是|预签约号，使用预签约请求生成，有效期2小时。|

Returns  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------|:----------------|
|[ContractResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-entity-contract-result-0000001638831782)|签约完成后端侧同步返回的签约结果。|

Sample code：

```
public void contract(Activity activity, Handler handler) {
        String contractStr = "{\"appId\":\"***\",\"preSignNo\":\"***\"}";
        Runnable runnable = () -> {
        AggrPayClient client = Pay.getPayClient(activity);
        ContractResult result = client.signContract(contractStr);
        handler.post(() -> dealContractResult(activity, result));
    };
    Thread payThread = new Thread(runnable);
    payThread.start();
}
/**
 * 签约结果处理
 * @param result 签约结果
 */
private void dealContractResult(Activity activity, ContractResult result) {
    if (result == null) {
        Log.e("支付失败", false);
        return;
    }
    String returnCode = result.getReturnCode();
    String returnMsg = result.getReturnMsg();
    // 如果returnCode="0"，表示成功，注意：为了支付安全，请以服务器的通知或查询结果为准。
    String contractTips = createCommonTips(returnCode, returnMsg);
    Toast.makeText(activity, contractTips, Toast.LENGTH_LONG).show();
}
```
