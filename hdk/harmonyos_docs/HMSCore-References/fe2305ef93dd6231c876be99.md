|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477) getInstance(Ability ability) 初始化Analytics Kit。Analytics Kit将根据配置完成初始化，且需要在主线程中初始化。 说明： * SDK初始化时会发送网络请求，请您务必在用户同意隐私协议后再初始化SDK。 * 必须在MainAbility的onStart中初始化Analytics SDK，否则会导致生命周期相关事件采集不准确。 * 如果已经调用过[getInstance(Ability ability, String routePolicy)](#section8500174514479)设置了指定的数据处理位置，再次调用[getInstance(Ability ability)](#section1239421717451)时[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477)将会切换成默认数据处理位置。 * 如果您的应用发布到全球多个国家，建议您启用多数据处理位置，使用[getInstance(Ability ability, String routePolicy)](#section8500174514479)初始化SDK，按照用户实际使用区域指定数据上报位置。|

#### getInstance(Ability ability, String routePolicy)

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477) getInstance(Ability ability, String routePolicy) 初始化Analytics Kit。Analytics Kit将根据设置的数据处理位置完成初始化，且需要在主线程中初始化。 说明： * 需通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/)申请多数据处理位置功能体验，该接口方可生效。在线提单操作详情请参见[在线提单指导](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/online-application-guide-0000001174952406)。 * SDK初始化时会发送网络请求，请您务必在用户同意隐私协议后再初始化SDK。 * 必须在MainAbility的onStart中初始化Analytics SDK，否则会导致生命周期相关事件采集不准确。 * 如果需要切换数据处理位置，重新调用该接口传入新的数据处理位置即可。 * 使用多数据处理位置接口时，请务必下载应用对应的最新AGC配置文件，下载方法：在"项目设置"页面中，点击"应用"栏下的"agconnect-services.json"。|

Parameters  

|Name|Description|
|:----------|:---------------------------------------------------------------------------------------------------------------|
|ability|Ability实例。|
|routePolicy|设置的数据处理位置。 数据处理位置包括：CN(中国)、DE(德国)、SG(新加坡)、RU(俄罗斯)。 注意： 设置的数据处理位置必须是开通过存储权限的数据处理位置，如果没有开通，数据将无法上报，请确保设置有效的数据处理位置。|
