# ActivityRecordDeleteOptions

|Class Info|
|:------------------------------------------------------------------------------------------------------------------|
|public class ActivityRecordDeleteOptions 删除运动记录的请求参数类，用于向平台中删除一个运动记录，该运动记录包含activityRecordIds、起止时间、subDataTypeList。|

构造ActivityRecordDeleteOptions的示例代码如下：

```
"Java"
// 请注意以下代码中的subDataTypeList、startTime、endTime、activityRecordIds请参考删除运动记录中的相关代码
ActivityRecordDeleteOptions deleteRequest = new ActivityRecordDeleteOptions.Builder()
    .setSubDataTypeList(subDataTypeList)
    .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
    .setActivityRecordIds(activityRecordIds)
    .build();
```

```
"Kotlin"
// 请注意以下代码中的subDataTypeList、startTime、endTime、activityRecordIds请参考删除运动记录中的相关代码
val deleteRequest = ActivityRecordDeleteOptions.Builder()
    .setSubDataTypeList(subDataTypeList)
    .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
    .setActivityRecordIds(activityRecordIds)
    .build()
```
