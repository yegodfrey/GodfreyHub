# HuaweiMap

有状态组件，用于展示包含从地图服务获取的数据的地图。

|REASON_DEVELOPER_ANIMATION|int|3|开发者启动的动画。|
|REASON_GESTURE|int|1|响应用户在地图上的手势的动画。|
|LOWER_LEFT|int|8388691|左下角徽标和版权位置。|
