# 错误码

|**错误码**|**值**|**描述**|**解决方案**|
|:------------------|:----|:------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|INTERNAL_ERROR|10000|内部错误。|请联系技术支撑。|
|PARAM_ERROR_EMPTY|10801|必填参数为空。|请检查必填参数。|
|PARAM_ERROR_INVALID|10802|参数校验错误。|请检查参数是否正确。|
|PERMISSION_DENIED|10803|权限不足。|请前往设置>隐私中检查定位权限是否打开。|
|AGC_CHECK_FAIL|10808|鉴权失败。|请在检查"agconnect-services.plist"配置文件与网络设置后，调用[startAuthorize](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanager-0000001160046484#section1290762831520)重新发起鉴权。|
|NETWORK_ERROR|10809|网络错误。|请检查网络设置并前往网络信号较强的场所。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。在线提单操作步骤可参见[在线提单指导](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/problems-submission-guide-0000001168773227)。
