# 批量查询openId

#### 功能介绍

为了采用更安全的OAuth 2.0协议实现游戏帐号登录，游戏服务中playerId需要逐步替换为openId。如果您正在参考[playerId替换为openId方案](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/openid-replace-solution-0000001343681705)进行playerId的替换，在完成第一阶段的[步骤3](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/openid-replace-solution-0000001343681705#ZH-CN_TOPIC_0000001343681705__li4553105773916)后，可以调用此接口批量查询playerId对应的openId，便于后续建立映射关系。  

#### 接口约束

* 此接口每秒钟最多处理500个请求，超出时会返回限流错误"provider request rejected by qps flowcontrol"，请稍后重试。
* 请勿频繁调用此接口，调用的时间间隔请控制在1秒以上。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|请根据您的服务器部署地就近选择对应站点的URL。 中国站点：https://connect-api.cloud.huawei.com/api/jas/user/player/convert/openid 欧洲站点：https://connect-api-dre.cloud.huawei.com/api/jas/user/player/convert/openid 亚太站点：https://connect-api-dra.cloud.huawei.com/api/jas/user/player/convert/openid 俄罗斯站点：https://connect-api-drru.cloud.huawei.com/api/jas/user/player/convert/openid 注意： 调用[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口时使用的域名必须与本接口域名保持一致，例如本接口使用"connect-api-dre.cloud.huawei.com"，则调用[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)接口必须使用"https://connect-api-dre.cloud.huawei.com/api/oauth2/v1/token"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

#### Header

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|用于鉴权的客户端ID，获取方法参考[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)。|
|Authorization|M|String|认证信息，格式为"Authorization: Bearer ${access_token}"。access_token为[获取Token](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-obtain_token-0000001158365043)中获取的access_token。|

#### Body

请求Body中使用JSON格式携带更相关信息，参数如下表所示。  

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------|
|playerIds|M|List\<String\>|需要查询的playerId列表。查询请求中有重复的playerId时，只会返回一次查询结果。 注意： playerId的字符串数组最大不能超过50，超出将返回3001错误码，为了获得更好的接口性能，建议一次最多传20个playerId。|
|appId|M|String|游戏的APP ID，获取方法参见[查询应用基本信息](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|

#### 调用示例

#### Java

```
/**
 * 批量获取openIds
 *
 * @param domain 请根据您的服务器部署地就近选择对应站点的URL，与获取token时使用的domain保持一致
 * @param client_id 用于鉴权的客户端ID
 * @param token post认证请求的token
 * @param playerIds 需要查询的playerId列表
 * @param appId 应用appId
 */
private static void batchGetOpenIds(String domain, String client_id, String token, List<String> playerIds,
	String appId) {
	try {
		// 接口URL，domain请根据您的服务器部署地就近选择对应站点的URL且与获取token时使用的domain保持一致
		HttpPost post = new HttpPost(domain + "/api/jas/user/player/convert/openid");
		// 构造消息头
		post.setHeader("Authorization", "Bearer " + token);
		post.setHeader("client_id", client_id);
		// 构造消息实体
		JSONObject keyString = new JSONObject();
		keyString.put("playerIds", playerIds);
		keyString.put("appId", appId);
		StringEntity entity = new StringEntity(keyString.toString(), Charset.forName("UTF-8"));
		entity.setContentEncoding("UTF-8");
		// 发送Json格式的数据请求
		entity.setContentType("application/json");
		post.setEntity(entity);
		CloseableHttpClient httpClient = HttpClients.createDefault();
		HttpResponse response = httpClient.execute(post);
		int statusCode = response.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_OK) {
			BufferedReader br = new BufferedReader(
				new InputStreamReader(response.getEntity().getContent(), Consts.UTF_8));
			String result = br.readLine();
			System.out.println(result);
			JSONObject object = JSON.parseObject(result);
		}
		post.releaseConnection();
		httpClient.close();
	} catch (Exception e) {
		System.out.println(e.getMessage());
	}
}
```

{
	try
	{
		// 接口URL，domain请根据您的服务器部署地就近选择对应站点的URL且与获取token时使用的domain保持一致
		var requestUrl = domain + "/api/jas/user/player/convert/openid";
		HttpWebRequest request = WebRequest.Create(requestUrl) as HttpWebRequest;
		request.Method = "post";
		request.ContentType = "application/json";
		request.Headers.Add("client_id", clientId);
		request.Headers.Add("Authorization", "Bearer " + token);
		Dictionary<string, object> dic = new Dictionary<string, object>
		{
			{"appId", appId},
			{"playerIds", playerIds}
		};
		string sendData = JsonConvert.SerializeObject(dic, Formatting.Indented);
		Console.WriteLine(sendData);
		byte[] byteData = Encoding.GetEncoding("utf-8").GetBytes(sendData);
		request.ContentLength = byteData.Length;
		Stream postStream = request.GetRequestStream();
		postStream.Write(byteData, 0, byteData.Length);
		postStream.Close();
		WebResponse response = request.GetResponse();
		StreamReader reader = new StreamReader(response.GetResponseStream(), Encoding.UTF8);
		string strJson = reader.ReadToEnd();
		Console.WriteLine(strJson);
		reader.Close();
		response.Close();
	} 
	catch (Exception e)
	{
		Console.WriteLine(e.ToString());
	}

	$curl = curl_init();
	$data = array("playerIds" => $playerIds, "appId" => $appId);
	curl_setopt_array($curl, array(

		CURLOPT_ENCODING => '',
		CURLOPT_MAXREDIRS => 10,
		CURLOPT_TIMEOUT => 0,

		CURLOPT_SSL_VERIFYHOST => false,
		CURLOPT_SSL_VERIFYPEER => false,
