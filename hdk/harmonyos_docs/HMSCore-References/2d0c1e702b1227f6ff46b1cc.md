# 成功回调

## 功能介绍

URL及接口名由您提供。您需要将此回调URL配置到开发者联盟。请参见[开通支付服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/vr-config-agc-0000001065075588#section7284026143012)。

用户使用华为支付进行付款成功后，华为支付服务器将通过此URL回调CP的服务器通知支付结果。

通知重发：若您的返回结果为非成功响应（返回的result值为0之外的值），将对同一笔订单的通知进行周期性重发。

重发机制：共2天，前3次每20s尝试一次，4-20次每200s尝试一次，之后每3小时尝试一次。
> 说明
>
> 为保证可靠性，系统具备补偿机制，所以可能出现通知比预期的多。

## 接口原型

|承载协议|HTTP POST|
|-----|-----------------------------------------------------------------------|
|接口方向|华为支付服务器->商户服务器|
|接口URL|application/x-www-form-urlencoded|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

> 说明
>
> 1. 请严格按接口定义返回相应的结果码，包括已经明确定义的错误情况。
> 2. 不允许商户设置IP允许清单用于限制华为侧的出口IP地址。IP允许清单本身并不能提高安全性且会给业务发展带来约束，在消息层面已有更安全的RSA签名机制条件下，没有存在价值。商户不遵守该约定而导致的后果由商户承担。

## 参数说明

本接口采用的是application/x-www-form-urlencoded格式，会在HTTP层进行编码，同时接收端会自动解码。建议通过如下方法获得的get参数串，也就是我们发送的原始信息。而原始信息是没有urlencode的，验签也是需要使用原始内容参与的。而使用request. getParameter()会隐含进行urldecode，在部分情况下可能无法正确获取原始参数信息，比如参数取值中如果包含"%"等特殊符号。

```screen
InputStream stream=request.getInputStream();
InputStreamReader isr=new InputStreamReader(stream);
BufferedReader br=new BufferedReader(isr);
String str=br.readLine();
```

采用如上方法获取参数时，对于sign、sysReserved和extReserved参数需要进行urldecode处理，其余参数不需要处理。

## 请求参数

**Request Header**

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:--------------------------------------------------------|
|HW-IAP-SIGN|否|String|如果商户存在多套密钥，则使用最新的密钥进行签名，在签名前增加索引的前缀，如：1-XXXX，建议优先使用该签名验签。|

**Request Body**

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|result|是|String (3)|支付结果： * "0"：表示支付成功。 * "1"：表示退款成功（暂未启用）。|
|userName|是|String|商户名称，您注册的公司名。|
|productName|是|String (100)|商品名称。|
|payType|是|int|支付类型，取值请参见[payType说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-data-model-0000001050986133#section135412662210)。|
|amount|是|String (10)|商品支付金额 ，保留两位小数， 例如：20.00。|
|currency|否|String|国标货币，值为空或者CNY时本参数不返回。|
|orderId|是|String (50)|华为支付平台订单号。|
|notifyTime|是|String (15)|通知时间，UTC时间戳，以毫秒为单位。|
|requestId|是|String (50)|商户订单号。 来源：您的应用在支付前生成，用来唯一标识一次支付请求。 该字段由字母和数字组成，必须在商户内唯一，用于唯一标识一个商户订单。|
|bankId|否|String(50)|银行编码，支付通道信息，可选参数。 > 说明 > 该字段仅在urlver为2时返回。|
|orderTime|否|String|下单时间：yyyy-MM-dd hh:mm:ss。 > 说明 > 该字段仅在urlver为2时返回。|
|tradeTime|否|String|交易/退款时间：yyyy-MM-dd hh:mm:ss。 > 说明 > 该字段仅在urlver为2时返回。|
|accessMode|否|String|接入方式： * -1：未知设备 * 0：手机 * 1：PC-Web * 2：Mobile-Web * 3：TV(包括机顶盒) * 4：pad * 5：watch * 6：kid watch * 7：PC simulator * 8：mobile tv * 9：glass * 10：ear phone * 11：car * 12：kid pad > 说明 > 该字段仅在urlver为2时返回。|
|spending|否|String|渠道开销，保留两位小数，单位：元。 > 说明 > * 该字段仅在urlver为2时返回。 > * 本参数依赖于上游支付平台的能力，进一步的信息请联系我们获取。|
|extReserved|否|String|商户侧保留信息，原样返回商户调用支付SDK输入的保留信息。参数长度为客户端传入参数的长度，未输入时，不返回。 > 说明 > * 考虑到自选参数格式多样化，本参数在"utf-8"urlencode后发送。 > * Java中request的getParameter()方法会隐含进行urldecode。|
|sysReserved|否|String|商户侧保留信息，原样返回商户调用支付SDK输入的保留信息。未输入时，不返回。 > 说明 > * 考虑到自选参数格式多样化，本参数在"utf-8"urlencode后发送。 > * Java中request的getParameter()方法会进行urldecode。|
|signType|否|String|签名类型，不参与签名。 * 没有传递signType或者signType值为RSA，表示使用SHA1WithRSA算法。 * signType值为RSA256，表示使用SHA256WithRSA算法。|
|sign|是|String|RSA签名。 > 说明 > * 考虑到自选参数格式多样化，本参数在"utf-8"urlencode后发送。 > * Java中request的getParameter()方法会隐含进行urldecode。|

> 说明
>
> 实际回调结果中除sign和signType之外都需要参与签名，实际回调结果指的是商户服务器收到的实际回调报文中的参数。

## 响应参数

**返回码：200**

**Response Body**

|参数|是否必选|参数类型|描述|
|:-----|:---|:---|:---------------------------------------------------------------------------------------------------------------|
|result|是|int|操作结果。 * 0：表示成功 * 1：验签失败 * 2：超时 * 3：业务信息错误，例如订单不存在 * 94：系统错误 * 95：IO错误 * 96：错误的URL * 97：错误的响应 * 98：参数错误 * 99：其他错误|

> 说明
>
> * 对于重复的订单，要求返回0。
> * 请严格按定义的结果码返回，包括各种已经明确定义的错误码。
> * 商户收到通知消息时，在完成最小必要处理后，要立即返回响应，避免超时。
