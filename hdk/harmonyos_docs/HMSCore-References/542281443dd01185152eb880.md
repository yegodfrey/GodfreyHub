# ActivityRecord

|Function Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|function ActivityRecord 运动记录，记录用户一次运动的基本信息。例如一次户外跑步运动，记录跑步的开始时间、结束时间，运动记录的名称、标识符、描述信息、对应的运动类型（参见[HiHealthActivities](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthactivities-0000001050089540)）、运动持续时间等。|
