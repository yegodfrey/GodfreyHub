# HwImageView

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HwImageView extends AppCompatImageView implements ViewTreeObserver.OnScrollChangedListener 该类是华为风格的ImageView，继承了原生ImageView，扩展了如下特性： * 点击阴影效果。 * 基于页面滚动的垂直视差效果。 * 图片详情界面下拉返回功能。 * 图片以任意圆角显示功能。|

#### XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:-------------------------------------------------------------------|
|boolean|hwClickEffect 标记点击阴影特性是否生效。其中ture表示生效，false表示不生效。|
|enum|hwParallaxStyle 标记垂直视差特性是否生效。其中none代表垂直视差不生效，verticalOffset代表垂直视差生效。|
|boolean|hwClipToOutline 标记图片圆角显示特性是否生效。其中ture表示生效，false表示不生效。|
