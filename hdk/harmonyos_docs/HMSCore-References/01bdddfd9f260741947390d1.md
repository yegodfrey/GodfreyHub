# Changes:getStartCursor

## 功能介绍

获取startCursor。

## 场景描述

获取Changes.subscribe需要使用的cursor值。

## 使用约束

Scope至少包含下面其中一个：

* https://www.huawei.com/auth/drive.appdata
* https://www.huawei.com/auth/drive.file
* https://www.huawei.com/auth/drive
* https://www.huawei.com/auth/drive.readonly
* https://www.huawei.com/auth/drive.metadata
* https://www.huawei.com/auth/drive.metadata.readonly

## 接口原型

|承载协议|HTTP GET|
|-----|-----------------------------------------------------------------------|
|接口方向|开发者服务器->华为云空间服务器|
|接口URL|https://driveapis.cloud.huawei.com.cn/drive/v1/changes/getStartCursor|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

    private static JSONObject changesGetStartCursor(String url, String access_token) throws IOException {
        StringBuilder stringBuilder = new StringBuilder("");
        stringBuilder.append("?").append("fields=*");
        HttpGet httpGet = new HttpGet(url + stringBuilder);
        httpGet.setHeader("Authorization","Bearer " + access_token);
        CloseableHttpResponse response = HttpClientUtil.getClient().execute(httpGet);

        try {
            HttpEntity responseEntity = response.getEntity();
            String ret = responseEntity != null ? EntityUtils.toString(responseEntity) : null;
            JSONObject jsonObject = (JSONObject) JSON.parse(ret);
            EntityUtils.consume(responseEntity);
            return jsonObject;
        }finally {
            response.close();
        }
    }
