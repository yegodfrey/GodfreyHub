# LiveInfo

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class [LiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/liveinfo-0000001051055552) implements Parcelable 某个生活指数当天和未来一到两天的指数等级。包括该指数的指数码、当天和未来一到两天的该指数的等级。仅支持国内数据。|

## Public Method Summary

|Qualifier and Type|Method Name|
|:--------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------|
|String|[getCode](#section913743195417)()|
|List<[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyliveinfo-0000001051055550)>|[getLevelList](#section6948780544)()|

## Public Methods

### getCode

|Method|
|:-------------------------------------------------------------------------------------|
|public String getCode()|
|获取生活指数码，生活指数码code有1~6六个值，"1"表示穿衣指数，"2"表示运动指数，"3"表示感冒指数，"4"表示洗车指数，"5"表示旅游指数，"6"表示紫外线指数。|

**Returns**

|Type|Description|
|:-----|:-------------------------------------------------------------------------------|
|String|生活指数码，生活指数码有1~6六个值，"1"表示穿衣指数，"2"表示运动指数，"3"表示感冒指数，"4"表示洗车指数，"5"表示旅游指数，"6"表示紫外线指数。|

### getLevelList

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public List<[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyliveinfo-0000001051055550)> getLevelList() 获取当天和未来一到两天的该指数的等级信息。例如，如果getCode获取到code为"1"，则List<[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyliveinfo-0000001051055550)>表示当天和未来一到两天的穿衣指数信息。|

**Returns**

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|List<[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyliveinfo-0000001051055550)>|当天和未来一到两天的该指数的等级信息。例如，如果getCode获取到code为"1"，则List<[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyliveinfo-0000001051055550)>表示当天和未来一到两天的穿衣指数信息。|
