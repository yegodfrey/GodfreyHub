# PassResponse

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class PassResponse extends Response ICCE车钥匙公共API接口，用于接收返回的车钥匙卡片信息。 这个类在Response类的基础上，增加了成员变量passDeviceId：用于描述设备唯一标识、passCardInfoList：用于描述卡片状态信息。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-------------------|:----------------------------------|
|String|getPassDeviceId() 返回设备+用户唯一标识（加密后的）|
|List\<PassCardInfo\>|getCardInfoList() 返回卡片状态信息|
|int|getDeviceType() 返回设备类型：0-手机；1-穿戴|
