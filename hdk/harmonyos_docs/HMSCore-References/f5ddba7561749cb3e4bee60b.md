# Overview

地图服务Flutter插件实现HMS Core Map SDK与Flutter平台之间的通信。本插件提供华为地图服务的所有功能。您可在"HuaweiMap"、"HuaweiMapUtils"、"HuaweiMapController"和"Data Types"章节查看该插件提供的数据类型和方法的详细信息。  

|名称|描述|
|:-----------------------------------------------------------------------------------------------------------------------------------------|:-------------------------|
|[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimap-0000001253024725)|有状态组件，用于展示包含从地图服务获取的数据的地图。|
|[HuaweiMapUtils](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimaputils-0000001208344746)|地图服务工具入口类。|
|[HuaweiMapController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimapcontroller-0000001208504720)|HuaweiMap组件的地图控制器。|
|[Data Types](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-data-types-overview-0000001252864731)|提供与地图服务API交互的数据类型的详细信息。|
