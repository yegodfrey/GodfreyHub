# HOverlayView

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|@interface HOverlayView : NSObject 地图覆盖物视图的基类，提供了绘制覆盖物的接口，希望不要直接实例化，可以使用该类的子类[HCircleView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hcircleview-0000001235650699)、[HPolylineView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hpolylineview-0000001237677117)、[HPolygonView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hpolygonview-0000001237317105)来实例化。|
