# 查询开放的指标及维度信息

#### 功能介绍

您的应用服务器可以通过调用此接口查询华为分析开放的指标和维度。  

#### 场景描述

当您需要将华为分析计算的指标呈现于您的运营报表时，可以通过此接口获取华为分析开放的指标与维度信息。  

#### 使用约束

调用频率不超过5次/秒。  

#### 接口原型

|承载协议|HTTP POST|
|接口方向|开发者服务器-\>分析服务服务器|
|接口URL|{rootUrl}/analytics/report/metrics/list/v1|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-product-id|是|String|用户在AppGallery Connect上的Product ID。|
|x-app-id|是|String|用户在AppGallery Connect上的App ID。|
|Authorization|是|String|鉴权信息。请参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|

Request Body  

|参数|是否必选|参数类型|描述|
|:--------|:---|:------|:-------------------------------------------|
|lang|是|String|语种标识，取值范围： * cn：中文 * en：英文 * ru：俄文 默认值："en"。|
|size|否|Integer|查询每页最大记录数。默认10。|
|curr_page|否|Integer|查询起始页。默认1。|

#### 请求示例

```
POST /analytics/report/metrics/list/v1 HTTP/1.1
Content-Type: application/json; charset=UTF-8
Accept: application/json
Authorization: Bearer 78C2395236BBF4262CAE4F1172E327C2929AD63EAA0395961A49DEBC3B6F8339 
x-product-id: sample-productid
x-app-id: sample-appid
 
{
    "lang" : "cn",
    "size" : 6,
    "curr_page" : 3
}
```

#### 响应参数

Response Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:---------------|:---------|
|Content-Type|是|application/json|响应消息的数据格式。|

Response Body  

|参数|是否必选|参数类型|描述|
|:----------|:---|:---------|:----------------------------------|
|result_code|是|String|响应码，请参见[错误码](#section195846692412)。|
|result_msg|是|String|响应描述。|
|metrics|否|Metric\[\]|指标详情。|
|total_pages|否|Integer|总页数。|
|curr_page|否|Integer|当前页。|

Metric结构体定义  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:------------|:---------|
|name|是|String|指标名称。|
|display_name|是|String|指标展示名。|
|description|是|String|指标说明。|
|dimensions|是|Dimension\[\]|指标支持细分的维度。|

Dimension结构体定义  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:-----|
|name|是|String|维度名称。|
|display_name|是|String|维度展示名。|
|description|是|String|维度说明。|
