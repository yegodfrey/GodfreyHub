# HwFloatingActionButton

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HwFloatingActionButton extends FloatingActionButton 该类是华为FloatingActionButton，继承了google material FloatingActionButton，分为渐变彩色阴影和灰色阴影两种类型。|

#### XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:---------------------------------------------------|
|string|hwFabTitleString 设置hwfab标题文本（只针对Menu组中的hwfab生效）。|
|color|hwFabShadowStartColor 设置hwfab正常状态阴影开始的颜色值。|
|color|hwFabShadowEndColor 设置hwfab正常状态阴影结束的颜色值。|
|color|hwFabDisabledShadowStartColor 设置hwfab不可点击状态阴影开始的颜色值。|
|color|hwFabDisabledShadowEndColor 设置hwfab不可点击状态阴影结束的颜色值。|
