# 申请分账

#### 功能介绍

华为支付支付成功后的订单，可由平台类商户/服务商调用此接口发起分账请求，将结算后的资金分账给接收方商户。分账规则说明如下：

1. 一笔订单申请一次或者多次分账请求，每次分账请求可以添加多个分账规则，但只会返回一个成功或者失败的请求标识。
2. 分账完成的订单不能再次发起分账。
3. 分账金额不能超过最大分账比例对应的金额。
4. 需要补差的订单（预下单入参传递了最大补差金额subsidyAmount及分账allocationType为延时分账），只有在完成补差（取消补差成功或者一次补差成功）后才能发起分账或完结分账。若用户支付完成后，发起分账前需要取消补差的，可以通过[取消补差](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-subsidies-cancel-0000001966012880)接口来取消补差，取消补差后才能发起分账。
5. 需要补差的订单180天没有发起补差或者取消补差，系统自动完成分账，将收单资金结算给收单商户。  

#### 使用约束

换单重试，视为新的业务订单，需开发者自行将新的业务订单关联业务原订单。接口重入规则说明如下（供参考）：  

|重入判定字段|支持原单重入场景|建议换单重试场景|
|:------------------------|:--------------------------------------------------------------------------------------------|:--------------------------------------------|
|商户分账订单号（mercAllocOrderNo）|1. 请求分账接口失败，建议根据错误码排查后，支持同一商户分账订单号重入。 2. 请求分账接口成功，原商户分账订单号重入，接口会幂等返回。该笔订单状态以异步结果通知或同步查询接口里为准。|分账订单状态返为ALLOC_FAILED，则订单进入失败终态。如需重新分账，需要换单重试。|

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/partner/allocation/orders|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-------------------------------------------------------------------------------|

#### 请求参数

* Request Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|

<!-- -->

* Request Body  

  |参数|是否必填|参数类型|描述|
  |:----------------|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |mercAllocOrderNo|是|String|商户分账订单号，由商户自己生成，商户需保证订单信息唯一性。最大长度46。|
  |sysTransOrderNo|是|String|华为支付系统订单号。|
  |allocationDetails|是|List\<[MercAllocRuleDetail](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section12263134923713)\>|分账详情。 说明： 金额总和，不能超过配置/默认最大分账比例|
  |allocFinish|否|boolean|分账完结标识。详见"[解冻剩余分账金额](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-finish-to-sys-0000001591340368#section1089114712582)"部分。 * true：完结分账 * false：不完结分账（默认） 说明： 超过180天分账未完结，系统自动发起分账指令，全部分给收单方|
  |callbackUrl|是|String|回调通知地址，最大长度512。|
  |payload|否|String|商户预留信息，最大长度64。|

  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

* Response Body  

  |参数|是否必选|参数类型|描述|
  |:-------------------|:---|:-----|:-------------------------|
  |resultCode|是|String|返回码，"000000"表示成功，其他表示见错误码。|
  |resultDesc|是|String|结果描述。|
  |subCode|否|String|业务错误码。|

  |sysAllocationOrderNo|是|String|华为支付分账订单号。|
