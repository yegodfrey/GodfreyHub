# ppsads.setGlobalRequestConfig(object)

#### 概述

设置通用广告请求配置。  

#### 参数

|参数|是否必选|类型|描述|
|:----------------------|:---|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|childProtectionTag|否|number|儿童保护标签。 参数取值请参见[TagForChild](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section14302415114716)。|
|underAgeOfPromiseTag|否|number|面向未达到法定承诺年龄用户。 * 1：不按面向未达到法定承诺年龄用户的方式来处理广告请求。 * 0：按面向未达到法定承诺年龄用户的方式来处理广告请求。 * -1：不确定是否按面向未达到法定承诺年龄用户的方式来处理广告请求。|
|adContentClassification|否|String|广告内容分级上限。 参数取值请参见[ContentClassification](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section5581237103111)。|
|nonPersonalizedAd|否|number|是否请求非个性化广告。 参数取值请参见[NonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section11976611184619)。|
|hwNonPersonalizedAd|否|number|是否请求华为DSP非个性化广告。 参数取值请参见[NonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section11976611184619)。|
|thirdNonPersonalizedAd|否|number|是否请求三方DSP非个性化广告。 参数取值请参见[NonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section11976611184619)。|
|appLang|否|String|媒体希望广告返回的语言。|
|appCountry|否|String|媒体希望广告返回的语言所在国家码。|
|appInstalledNotify|否|boolean|设置是否启用全屏激活提醒页。 * true：启用。 * false：禁用。|
|appActivateStyle|否|number|设置激活提醒弹框样式。 * 1: 底部横幅。 * 2: 确认弹框。|
|consent|否|String|[TCF v2.0](https://iabeurope.eu/tcf-2-0/)用户同意信息字符串，遵循IAB TCF v2.0标准中的[Consent String Format](https://github.com/InteractiveAdvertisingBureau/GDPR-Transparency-and-Consent-Framework/blob/master/TCFv2/IAB Tech Lab - Consent string and vendor list formats v2.md#the-global-vendor-list)格式。|
|belongCountry|否|String|设备归属地。例如：CN。|
|extras|否|object|广告请求的扩展信息。|
|isQueryUseEnabled|否|number|是否允许使用搜索词。 参数取值请参见[IsQueryUseEnabled](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section1186418240816)。|
