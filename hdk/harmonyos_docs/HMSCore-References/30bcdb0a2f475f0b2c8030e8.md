# Overview

## Interface Summary

|Interface|Description|
|:------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------|
|[GameCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamecallback-0000001050121692)|GameCallback接口是GameManager类内部定义的接口。设备通过该接口反馈设备信息，如温度、CPU负载和GPU负载信息。|

## Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------|
|[GameManager](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamemanager-0000001050123643)|GameManager是GameTurbo Engine对外提供的类，它是一个抽象类，具有一个公共的静态方法，用来获取一个继承并实现GameManager抽象方法的类的实例。|
