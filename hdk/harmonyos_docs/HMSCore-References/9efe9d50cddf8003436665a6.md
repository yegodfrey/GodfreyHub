# Overview

支持的场景：手机、平板、华为智慧屏、车机、智能手表。

Account SDK JS ForHarmony是适配HarmonyOS应用的SDK，集成后可使用相关接口进行授权登录、静默登录、退出、取消授权操作。

## Function Summary

|Function|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------|
|[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-authhuaweiid-0000001064638400)|登录后获取的华为帐号信息。|
|[HuaweiIdAuth](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185)|帐号授权登录、静默登录、退出、取消授权接口实现对象。|
|[HuaweiIdAuthManager](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthmanager-0000001063840255)|华为帐号登录服务入口。|
|[HuaweiIdAuthParams](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthparams-0000001064189912)|帐号登录参数对象。|
|[HuaweiIdAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthparamshelper-0000001064109899)|帐号登录参数构造对象。|
|[Scope](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-scope-0000001064957982)|帐号信息的授权范围。|
