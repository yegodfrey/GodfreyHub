# Overview

情景感知天气状态包，属于情景感知状态包，包含了感知天气状态的[Aqi](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aqi-0000001050695586)、[City](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/city-0000001050975621)、[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyliveinfo-0000001051055550)、[DailySituation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailysituation-0000001050735617)、[DailyWeather](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyweather-0000001050695588)、[HourlyWeather](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hourlyweather-0000001050975623)、[LiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/liveinfo-0000001051055552)、[Situation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/situation-0000001050735619)、[WeatherSituation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/weathersituation-0000001050695590)类。  

#### Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------|
|[Aqi](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aqi-0000001050695586)|天气状态WeatherStatus中的空气质量指数。包括一氧化碳指数、二氧化氮指数、臭氧指数、PM10指数、PM2.5指数、二氧化硫指数，和综合天气指数。|
|[City](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/city-0000001050975621)|天气状态WeatherStatus中的城市信息。包括城市码、省份名称、时区、和城市/区名称。|
|[DailyLiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyliveinfo-0000001051055550)|当天与未来一到两天的生活指数信息。每天的生活指数包括穿衣指数、运动指数、寒冷指数、洗车指数、旅游指数和紫外线指数。|
|[DailySituation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailysituation-0000001050735617)|白天或者晚上的简略天气情况。包括天气ID(CN)、风速、风级、风向。|
|[DailyWeather](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailyweather-0000001050695588)|当天和未来六到七天的天气信息。包括月出、月落、日出、日落、最低温最高温（摄氏度）、最低温最高温（华氏度）、综合空气指数（国外版不支持）、当地时间凌晨时间戳、月相、白天简略天气情况（DailySituation）、夜间简略天气情况（DailySituation）。|
|[HourlyWeather](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hourlyweather-0000001050975623)|当前小时和未来24个小时的天气信息。包括天气ID(CN)、对应时间信息、摄氏度、华氏度、降雨概率、是否是晚上。|
|[LiveInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/liveinfo-0000001051055552)|某个生活指数当天和未来一到两天的指数等级。包括该指数的指数码、当天和未来一到两天的该指数的等级。|
|[Situation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/situation-0000001050735619)|当前天气信息。包括天气ID(CN)、湿度、摄氏度、华氏度、体感温度（℃）、体感温度（℉）、风向、风力等级、风速、气压、紫外线强度、更新时间。|
|[WeatherSituation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/weathersituation-0000001050695590)|当前天气情况，由当前天气信息（Situation）及城市信息（City）组成。|
