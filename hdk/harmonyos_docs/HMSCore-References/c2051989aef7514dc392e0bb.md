### consumeOwnedPurchase

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[Task](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/task_tresult-0000001050121148)<[ConsumeOwnedPurchaseResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consumeownedpurchaseresult-0000001050137625)> consumeOwnedPurchase([ConsumeOwnedPurchaseReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consumeownedpurchasereq-0000001050137617) consumeOwnedPurchaseReq) 针对消耗型商品，在商品支付成功后，应用需要在发放商品成功之后调用此接口对消耗型商品执行消耗操作。 > 注意 > 1. 您需在发货成功后再执行消耗操作。如果您在消耗之后再进行发货，可能存在以下异常场景：调用消耗接口过程中，服务器消耗成功但因网络异常等原因没有成功将结果回调给端侧，从而造成服务器已经消耗但是端侧没有发货的场景。此场景后续很难处理，您需在发货之后再执行消耗操作。 > 2. 您需要把已发货的购买Token传至您的服务器，后续即使消耗失败也可以从您的服务器拉取数据进行对比，避免出现异常。建议您在发货前检查您的应用服务器，以确保每个购买Token都未使用过，即未发过货。|

### createPurchaseIntent

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[Task](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/task_tresult-0000001050121148)<[PurchaseIntentResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentresult-0000001050135852)> createPurchaseIntent([PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842) purchaseIntentReq) PMS商品创建订单接口，支持购买消耗型商品、非消耗型商品、订阅型商品。 您在AppGallery Connect[配置商品](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-product-0000001050033076)后，使用此接口调用华为应用内支付收银台，显示商品、价格和支付方式。华为会根据国际汇率变动进行商品价格档调整，为了保证应用内商品价格显示一致，请您同时使用[obtainProductInfo](#section339016011301)接口获取商品详情，避免从自有服务端获取价格，以免在汇率变动价格调整时，导致价格显示不一致。 本接口只返回包含IAP收银台页面的[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象，应用需要自行启动收银台页面，启动方法见[PurchaseIntentResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentresult-0000001050135852)中对[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)的说明。用户完成支付后应用可以在onActivityResult回调方法中通过[parsePurchaseResultInfoFromIntent](#section1317716106377)获取支付结果信息。 > 注意 > * 为避免资金损失，您在对支付结果验签成功后，必须校验[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的productId、price、currency等信息的一致性。 > * [Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)不支持序列化，请勿对IAP接口返回的[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象执行序列化操作。|

**Sample code：**

```screen
"Java"
// 构造一个PurchaseIntentReq对象
PurchaseIntentReq req = new PurchaseIntentReq();
// 通过createPurchaseIntent接口购买的商品必须是您在AppGallery Connect网站配置的商品
req.setProductId("CProduct1");
// priceType: 0：消耗型商品; 1：非消耗型商品; 2：订阅型商品
req.setPriceType(0);
req.setDeveloperPayload("test");
// 获取调用接口的Activity对象
final Activity activity = getActivity();
// 调用createPurchaseIntent接口创建PMS商品订单
Task<PurchaseIntentResult> task = Iap.getIapClient(activity).createPurchaseIntent(req);
task.addOnSuccessListener(new OnSuccessListener<PurchaseIntentResult>() {
    @Override
    public void onSuccess(PurchaseIntentResult result) {
        // 获取创建订单的结果
        // Status不支持序列化操作
        Status status = result.getStatus();
        if (status.hasResolution()) {
            try {
                // 6666是您自定义的常量
                // 启动IAP返回的收银台页面
                status.startResolutionForResult(activity, 6666);
            } catch (IntentSender.SendIntentException exp) {
            }
        }
    }
}).addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        if (e instanceof IapApiException) {
            IapApiException apiException = (IapApiException) e;
            // Status不支持序列化操作
            Status status = apiException.getStatus();
            int returnCode = apiException.getStatusCode();
        } else {
            // 其他外部错误
        }
    }
});

@Override
protected void onActivityResult(int requestCode, int resultCode, Intent data) {
    super.onActivityResult(requestCode, resultCode, data);
    if (requestCode == 6666) {
        if (data == null) {
            Log.e("onActivityResult", "data is null");
            return;
        }
        // 调用parsePurchaseResultInfoFromIntent方法解析支付结果数据
        PurchaseResultInfo purchaseResultInfo = Iap.getIapClient(this).parsePurchaseResultInfoFromIntent(data);
        switch(purchaseResultInfo.getReturnCode()) {
            case OrderStatusCode.ORDER_STATE_CANCEL:
                // 用户取消
                break;
            case OrderStatusCode.ORDER_STATE_FAILED:
            case OrderStatusCode.ORDER_PRODUCT_OWNED:
                // 检查是否存在未发货商品
                break;
            case OrderStatusCode.ORDER_STATE_SUCCESS:
                // 支付成功
                String inAppPurchaseData = purchaseResultInfo.getInAppPurchaseData();
                String inAppPurchaseDataSignature = purchaseResultInfo.getInAppDataSignature();
                // 使用您应用的IAP公钥验证签名
                // 若验签成功，必须校验InAppPurchaseData中的productId、price、currency等信息的一致性，验证一致后发货
                // 若用户购买商品为消耗型商品，您需要在发货成功后调用consumeOwnedPurchase接口进行消耗
                break;
            default:
                break;
        }
    }
}
```
