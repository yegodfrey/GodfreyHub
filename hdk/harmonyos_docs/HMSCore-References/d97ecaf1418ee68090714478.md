# Scope

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Class Info|
|:----------------------------------------------------------------|
|public class Scope 描述一个OAuth 2.0的请求授权，对用户安全有影响，当请求授权时，会产生一个授权对话框。|

## Public Constructor Summary

|Constructor Name|
|:-------------------------------------------------------------------|
|public [Scope](#section762834875012)(String uri) 使用指定URI创建一个新的Scope。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------|
|String|[getScopeUri](#section63617200397)() 获取当前Scope对应的授权URI。|

### Scope

|:-------------------------------------------|
