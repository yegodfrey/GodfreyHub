# 说明

|Name|Description|
|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，提供关键字搜索、周边搜索、地点详情、地点搜索建议、Widget搜索组件和自动补全接口。部分接口需收费，收费标准请参见[服务定价](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/about-charging-0000001052557393)。|
|REST|提供支持HTTP和HTTPS的云服务接口，用于开发关键字搜索、周边搜索、地点详情、地点搜索建议、自动补全、地理编码和获取时区等相关能力。使用接口需收费，收费标准请参见[服务定价](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/about-charging-0000001052557393)。|
