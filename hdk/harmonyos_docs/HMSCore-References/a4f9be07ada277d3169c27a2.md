# getDeviceId：获取绑定设备的UUID

**接口原型**

public String getDeviceId()

方法描述：获取绑定设备在开发者平台分配的UUID（资源包的UUID）。

**请求参数**

无

**响应参数**

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:----------------|:---|
|deviceId|String|该设备在开发者平台分配的UUID。|M|
