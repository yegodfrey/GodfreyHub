# HeadsetStatus

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Interface Info|
|:---------------------------------------------------------------------------------------------------------|
|public interfaceHeadsetStatus 耳机状态接口类，其中定义了3个耳机状态的常量，即表示耳机已连接CONNECTED、耳机未连接DISCONNECTED和无法识别到耳机状态UNKNOWN。|
