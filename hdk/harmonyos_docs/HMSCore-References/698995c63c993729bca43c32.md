## Sample Code

```screen
private void updateComments(Drive drive, File file, Comment comment){
    try{
        Comment newComment = new Comment();
        newComment.setDescription("update interface test");
        comment = drive.comments().update(file.getId(), comment.getId(), newComment).execute();
    } catch (Exception e){
        Log.e(TAG, "updateComments error: " + e.getMessage());
    }
}
```
