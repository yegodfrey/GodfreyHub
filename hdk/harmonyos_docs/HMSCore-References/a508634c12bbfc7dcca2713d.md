# HwRspViewPager

|Class Info|
|:--------------------------------------------------------------------------------------|
|public class HwRspViewPager extends ViewPager 该类是华为响应式HwRspViewPager控件类，继承了原生ViewPager。|

## XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boolean|rsp_need_adjust 大屏下是否需要执行响应式逻辑|
|enum|rsp_adjust_type 使用哪种范式来调整ViewPager，默认使用居中的方式|
|integer|rsp_indicator_view_id 导航点View ID。|
|integer|rsp_page_margin Item间距，如果用户未指定，则使用小屏下设置的值，如果还未设置，则使用默认值12dp|
|enum 取值： un_change scale aspect|rsp_width_adjust_mode 单个Item的宽调整策略： un_change：宽不变，IW_NEW=IW scale：按照配置rsp_scale_width缩放，IW_NEW=IW* rsp_scale_width aspect：按照配置rsp_aspect依据高等比缩放，IW_NEW=IH_NEW* rsp_aspect|
|float|rsp_scale_width 宽缩放大小，如果未配置则默认为0.5|
|enum 取值： un_change scale aspect|rsp_height_adjust_mode un_change：高不变 scale：按照配置rsp_scale_height缩放 aspect：按照配置rsp_aspect依据宽等比缩放|
|float|rsp_scale_height 高缩放大小，如果未配置则默认为0.5|
|float|rsp_aspect 单个Item的高宽比，如果未设置则使用ViewPager的高宽比：VPH/VPW|
|integer|rsp_off_page_limit Item的缓存数量，不设置则使用系统默认值|
|integer|rsp_one_page_item_cnt 一页完整显示多少个Item，不设置则使用默认值2|
