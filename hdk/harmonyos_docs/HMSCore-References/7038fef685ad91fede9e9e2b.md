# 错误码

|错误码|值|描述|解决方法|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:-|:-------------------------------|:--------------------------------------------------------------------------|
|[INNER](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section20785175174812)|0|内部错误。|1. 请检查HMS Core（APK）版本是否为4.0.0.300及以上版本。 2. 请检查当前网络是否可用。|
|[INVALID_REQUEST](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section7707427520)|1|无效的广告请求，如未设置广告位ID、Banner广告尺寸无效等。|1. 请检查申请的广告位是否已生效。 2. 请检查应用包名与申请广告位的使用的包名是否一致。 3. 请检查广告尺寸是否设置正确。|
|[NETWORK_ERROR](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section9815518537)|2|由于网络连接错误导致广告请求失败。|请检查当前网络是否可用。|
|[NO_AD](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section13199161614545)|3|广告请求成功，但是服务器没有返回可用的广告素材。|检查广告位ID是否生效、测试手机连接的网络是否正确，或联系客服支持。|
|[AD_LOADING](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section321643214553)|4|广告正在请求中，不能重复发起请求。|请检查是否重复下发广告请求。|
|[LOW_API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section627162718562)|5|API版本不在广告服务支持范围内。|1. 请检查HMS Core（APK）版本是否为4.0.0.300及以上版本。 2. 请检查App中设置的minSdkVersion是否为19及以上。|
|[BANNER_AD_EXPIRE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section11146180145717)|6|Banner广告过期。|请重新请求广告，不要缓存广告。|
|[BANNER_AD_CANCEL](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section7399145465713)|7|Banner广告任务下架。|请重新请求广告，不要缓存广告。|
|[HMS_NOT_SUPPORT_SET_APP](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-errorcode-0000001050064880#section14251642141410)|8|HMS Core（APK）版本过低，不支持设置AppInfo。|请将手机中的HMS Core更新至最新版本。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
