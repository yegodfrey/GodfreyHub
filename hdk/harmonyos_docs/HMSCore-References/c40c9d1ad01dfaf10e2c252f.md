# DeleteOptions

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------|
|public class DeleteOptions 删除数据的请求参数类，从华为Health Service Kit中删除指定时间间隔内的数据和运动记录。应用只能删除自己添加的数据和运动记录，而不能删除其他应用添加的数据和运动记录。|

构建DeleteOptions删除数据，需要指定删除数据的时间区间（必填），一个DataType或多个特定DataCollector，或者设置为删除所有数据。若都不指定，则不会删除应用的任何数据。

示例代码如下：

1. 构建DeleteOptions删除一个指定DataType（增量步数）的数据。

   示例代码如下：

   ```screen
   "Java"
   DeleteOptions deleteOptions = new DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .build();
   ```

   ```screen
   "Kotlin"
   val deleteOptions = DeleteOptions.Builder()
       .addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .build()
   ```

2. 构建DeleteOptions删除多个指定DataType（增量步数和身高）的数据。

   示例代码如下：

   ```screen
   "Java"
   DeleteOptions deleteOptions = new DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .addDataType(DataType.DT_INSTANTANEOUS_HEIGHT)
       .build();
   ```

   ```screen
   "Kotlin"
   val deleteOptions = DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .addDataType(DataType.DT_INSTANTANEOUS_HEIGHT)
       .build()
   ```

3. 构建DeleteOptions删除一个指定DataType（增量步数）和多个特定DataCollector（多个设备）的数据。

   示例代码如下：

   ```screen
   "Java"
   DeleteOptions deleteOptions = new DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .addDataCollector(dataCollector1)
       .addDataCollector(dataCollector2)
       .build();
   ```

   ```screen
   "Kotlin"
   val deleteOptions = DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .addDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .addDataCollector(dataCollector1)
       .addDataCollector(dataCollector2)
       .build()
   ```

4. 构建DeleteOptions删除所有的数据。

   示例代码如下：

   ```screen
   "Java"
   DeleteOptions deleteOptions = new DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .deleteAllData()
       .build();
   ```

   ```screen
   "Kotlin"
   val deleteOptions = DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .deleteAllData()
       .build()
   ```

构建DeleteOptions删除运动记录，需要指定删除运动记录的时间区间（必填），一个或多个指定的运动记录ActivityRecord，或删除所有的运动记录。若不指定运动记录，则不会删除任何运动记录数据。

构建DeleteOptions删除运动记录的示例代码如下：

1. 构建DeleteOptions删除多个指定运动记录（跑步和游泳）。

   示例代码如下：

   ```screen
   "Java"
   DeleteOptions deleteOptions = new DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .addActivityRecord(activityRecordRunning)
       .addActivityRecord(activityRecordSwimming)
       .build();
   ```

   ```screen
   "Kotlin"
   val deleteOptions = DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .addActivityRecord(activityRecordRunning)
       .addActivityRecord(activityRecordSwimming)
       .build()
   ```

2. 构建DeleteOptions删除所有运动记录。

   示例代码如下：

   ```screen
   "Java"
   DeleteOptions deleteOptions = new DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .deleteAllActivityRecords()
       .build();
   ```

   ```screen
   "Kotlin"
   val deleteOptions = DeleteOptions.Builder()
       .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
       .deleteAllActivityRecords()
       .build()
   ```
