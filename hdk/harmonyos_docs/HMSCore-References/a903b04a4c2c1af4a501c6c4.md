# TileOverlay

瓦片图层是显示在地图上的一组图像。这些瓦片可以是透明的，允许您增加一些新的功能到现有的地图上。

## Properties

|名称|类型|描述|
|:------------|:-----------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------|
|tileOverlayId|[TileOverlayId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlayid-0000001252864737)|瓦片图层唯一的ID。|
|fadeIn|bool?|表示瓦片图层是否是淡入。|
|transparency|double?|瓦片图层的透明度。|
|visible|bool?|表示瓦片图层是否可见。如果瓦片图层不可见，则不会绘制，其他所有状态均保留。瓦片图层默认可见。|
|zIndex|double?|瓦片图层的Z-index。z-index表示瓦片图层的叠加顺序。Z-index值较大的瓦片图从将压盖Z-index较小的瓦片图层。具有相同z-index的瓦片图层以随机顺序相互压盖。|
|tileProvider|dynamic|瓦片图层的提供者。|
