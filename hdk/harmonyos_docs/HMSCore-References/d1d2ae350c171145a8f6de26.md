# 已取消或者退费购买查询

#### 功能介绍

此接口用于查询全球最近一个月已取消或者有退费的购买信息。  

#### 场景描述

当您想查看近期非消耗型商品的退费情况、消耗型商品在已购买尚未消耗场景下的退费情况以及订阅型商品的取消和退费情况，您可以调用华为应用内支付服务器提供的已取消或者退费购买查询接口进行查询，查询的时间范围为最近一个月内。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241028180417.88978188230049476976490615554701:50001231000000:2800:48AD2DC8E3A7999C16EF0C72E0CD87D62EC0D75F0BDD3A572F39FF594C5659A6.png?needInitFileName=true?needInitFileName=true)  
为避免批量查询的性能问题，并且https服务本身安全性高，因此返回的购买信息不包含签名信息。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为应用内支付服务器|
|接口URL|{rootUrl}/applications/v2/purchases/cancelledList 说明： rootUrl在不同站点有不同的url：您应固定选择最近站点的Order服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1954123781815)和[站点选择](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1741234185817)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Content-Type|是|String|取值为：application/json; charset=UTF-8|
|Authorization|是|String|认证信息，使用Access Token进行鉴权，这里使用开放平台鉴权提供的服务接口获取Access Token，格式说明参见[公共说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127)，获取方式参见[获取应用级AT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/obtain-application-level-at-0000001051066052)。|

Request Body  

|参数|是否必选|参数类型|描述|
|:----------------|:---|:------|:----------------------------------------------------------------------------------------------|
|endAt|否|Long|希望查询的最近被取消或者退费的购买，UTC时间戳，以毫秒为单位。不能超过当前时间，默认值为当前时间；endAt必须大于等于startAt。在输入continuationToken情况下忽略。|
|startAt|否|Long|希望查询的最早被取消或者退费的购买，UTC时间戳，以毫秒为单位。不能早于当前时间的30天前，默认值为当前时间减去30天。在输入continuationToken情况下忽略。|
|maxRows|否|Integer|大于0，当前查询返回的最大条数，默认值为1000，最大值也为1000。|
|continuationToken|否|String|输入上次查询返回的continuationToken以查询下一页数据。|
|type|是|Integer|查询类别，在输入continuationToken情况下忽略： * 0：查询消耗型和非消耗型商品的购买信息，也是默认值。 * 1：查询消耗型、非消耗型，以及订阅型商品的购买信息。|

#### 响应参数

Response Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:----------------------------------|
|Content-Type|是|String|取值为：application/json; charset=UTF-8|

Response Body  

|参数|是否必选|参数类型|描述|
|:--------------------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------|
|responseCode|是|String|返回码。 * 0：成功。 * 其他：失败，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-error-code-0000001050166248)。|
|responseMessage|否|String|响应描述。|
|cancelledPurchaseList|否|String|被取消或者退费的购买信息列表，是一个JSON格式的String，此Json是一个购买信息的列表，购买信息格式参见下表CancelledPurchase。|
|continuationToken|否|String|表示下一页数据，如果返回，可以输入下一次查询请求，以此查询下一页数据|

CancelledPurchase  

|参数|是否必选|参数类型|描述|
|:--------------|:---|:------|:----------------------------------------------------------------------------------------------------|
|orderId|是|String|唯一标示一次购买或者订阅续期的订单号。|
|productId|是|String|商品ID。|
|purchaseToken|是|String|购买Token。|
|purchaseTime|是|Long|UTC购买时间戳。|
|cancelledTime|是|Long|UTC取消或者退费时间戳。|
|cancelledSource|是|Integer|取消或者退费来源。 * 0：顾客 * 1：您 * 2：华为|
|cancelledReason|是|Integer|取消或者退费原因。 * 0：其他 * 1：顾客反悔 * 2：商品未提供 * 3：App服务异常 * 4：意外购买 * 5：欺诈 * 6：chargeBack * 7：升级、降级等 * 8：用户服务地切换|
