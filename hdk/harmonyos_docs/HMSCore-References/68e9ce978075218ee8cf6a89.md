# 天气类-N天逐小时预报

#### 功能介绍

提供N天小时级预报天气信息。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 开发者服务器 -> 华为天气服务器  
接口URL | {rootUrl}/v1/weather/hourly/{hours} 说明：  {_rootUrl_}：请参见站点信息。 {hours}：查询的小时数，支持[24，36，72]  
数据格式 | 请求消息：Content-Type: application/json 响应消息：Content-Type: application/json  
  
#### 路径参数

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
hours | 是 | String | 支持取值为：24，36，72  
  
#### 请求参数

**Request Header**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
Content-Type | 是 | String | 取值为：application/json  
Authorization | 是 | String | 您动态获取的[Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section12493191334711) 说明：  Bearer后面拼接空格，再拼接获取的access_token。  
  
**Request Body**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
citycode | 是 | String | 城市编码，具体参见[城市编码表](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/city-dictionary-0000001256958081)  
  
#### 请求示例
    
    GET {rootUrl}/v1/weather/live/basic
    Content-Type:application/json
    Authorization:Bearer {access_token}
    {
     "citycode": "106566"
    }

#### 响应参数

**状态码为200时****：**

**Response Header**

参数 | 参数类型 | 描述  
---|---|---  
Content-Type | String | 取值为：application/json  
  
**Response Body**

参数 | 参数类型 | 描述  
---|---|---  
ret | String | 返回码，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/error-code-0000001255557253)  
msg | String | 返回值描述  
data | Object | 返回数据，具体请参见响应示例  
requestid | String | 请求id，用于查询日志  
  
#### 响应示例
    
    HTTP/1.1 200 OK
    Content-type: application/json
    {
      "ret": 0,
      "msg": "success",
      "data": {
        "hourlyweather": [
          {
            "date": 1576490400000,    //小时时间点
            "temp": 1,    //温度
            "cnweatherid": 2,    //天气状态
            "wp": 1,    //风力
            "wd": "E"    //风向
          },
          ......
        ]
      },
      "requestid": "xxxxxxxxxx"
    }
