# Scope

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Function Info|
|:------------------------|
|function Scope 帐号信息的授权范围。|

## Constant Summary

|Type|Name|Description|
|:----|:------|:--------------------------------|
|Scope|EMAIL|获取华为帐号的Email地址时传递的scope参数。|
|Scope|OPENID|获取华为帐号的OpenID和UnionID时传递的scope参数。|
|Scope|PROFILE|获取华为帐号信息，如昵称和头像时传递的scope参数。|
