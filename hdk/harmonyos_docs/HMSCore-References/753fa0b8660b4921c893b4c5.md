# MapsInitializer

|Class Info|
|:-------------------------------------------------------------------------------------|
|public final class MapsInitializer 继承自Object的final类，如果在获取地图之前需要使用某些功能，请使用此类初始化地图服务SDK。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
|static synchronized void|[initialize](#section1516212511479)(Context context) 初始化地图服务SDK，以便后续能够使用其中的相关的类。|
|static synchronized void|[initialize](#section13620131508)(Context context, String routePolicy) 初始化地图服务SDK，支持设置数据路由地。routePolicy： CN(中国)、DE(德国)、SG(新加坡)、RU(俄罗斯)|
|static void|[setAccessToken](#section187558358324)(String accessToken) 设置地图服务SDK的AT。|
|static void|[setApiKey](#section1389444514617)(String apiKey) 设置地图服务SDK的API密钥。|

## Public Methods

### initialize

|Method|
|:-----------------------------------------------------------------------------------------------|
|public static synchronized void initialize(Context context) 您调用此API进行初始化地图服务SDK，以便后续能够使用其中的相关的类。|

**Parameters**

|Name|Description|
|:------|:-----------------|
|context|用来获取必要的SDK资源，不能为空。|

### initialize

|Method|
|:-----------------------------------------------------------------------------------------------------------|
|public static synchronized void initialize(Context context, String routePolicy) 您调用此API初始化地图服务SDK，支持设置数据路由地。|

**Parameters**

|Name|Description|
|:----------|:-----------------------------------|
|context|用来获取必要的SDK资源，不能为空。|
|routePolicy|数据路由地： CN(中国)、DE(德国)、SG(新加坡)、RU(俄罗斯)|

### setAccessToken

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static void setAccessToken(String accessToken) 您调用此API设置地图服务SDK的AT。 > 说明 > * 该接口是针对增强版MapSDK使用，请不要在基础MapSDK场景下使用。 > * 如果同时设置了API KEY和AT，优先使用AT认证。|

**Parameters**

|Name|Description|
|:----------|:----------|
|accessToken|设置AT。|

### setApiKey

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static void setApiKey(String apiKey) 您调用此API设置地图服务SDK的API密钥。 > 说明 > * 如果在"agconnect-services.json"文件中api_key字段已有API密钥，则可以不用调用此方法。 > * 如果setApiKey方法和"agconnect-services.json"文件中同时设置了API密钥，优先使用setApiKey方法中设置的API密钥。|

**Parameters**

|Name|Description|
|:-----|:----------|
|apiKey|设置API密钥。|
