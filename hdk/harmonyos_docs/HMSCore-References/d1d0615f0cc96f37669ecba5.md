# OnDeeplinkAcquiredListener

|Interface Info|
|:----------------------------------------------------------------------------------------------------|
|public interface OnDeeplinkAcquiredListener 获取深度链接的监听器；当调用request()方法时，将调用此监听器的launchDeeplink(Uri)方法。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|abstract boolean|[launchDeeplink](#section291114533716)(Uri deeplink) 当调用[request](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/deeplinkclient-0000001361239353#section1141110531817)()方法时，该方法被调用将deeplink回传给监听者。|

#### Public Methods

#### launchDeeplink

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract boolean launchDeeplink(Uri deeplink) 当调用[request](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/deeplinkclient-0000001361239353#section1141110531817)()方法时，该方法被调用将deeplink回传给监听者。|

Parameters  

|Name|Description|
|:-------|:------------|
|deeplink|广告主应用推广的深度链接。|

return  

|Type|Description|
|:------|:--------------------------------------------------------------------|
|boolean|是否由广告主自己来拉起深度链接： * true：是。 * false：否，由ads-installreferrer SDK来拉起深度链接。|

Sample code：

```
DeeplinkClient deeplinkClient = new DeeplinkClient(this, new OnDeeplinkAcquiredListener() {
    @Override
    public boolean launchDeeplink(Uri deeplink) {
        Log.d(TAG, "deeplink is:" + deeplink);
        return false;
    }
});
```
