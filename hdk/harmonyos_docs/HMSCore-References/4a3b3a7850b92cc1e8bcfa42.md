# 通知发货（应用外支付）

#### 功能描述

当用户完成应用外PMS商品支付后，华为数字商品服务器调用此接口通知开发者服务器向用户发放对应的商品。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为服务器 -\> 开发者服务器|
|接口URL|URL为开发者在配置商品营销信息时配置的"接收发货通知地址"。|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------|

|参数|是否必选|参数类型|描述|
|:-------|:---|:--------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|data|是|[DeliveryRequest](#ZH-CN_TOPIC_0000001050121556__p175161730874)|通知发货的请求信息。 注意： 如果data中的参数顺序不为developerId、orderId、openId、appId、count、productNo、ts，请将data中的参数顺序调整为以上顺序，否则可能会导致验签失败。|
|sign|是|String|华为服务器在发送通知时对data中的所有参数使用SHA256WithRSA算法进行了签名，并在sign参数中返回签名后的字符串。 您需要[获取验签公钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/get-public-key-0000001050164350)，并使用公钥对签名字符串进行验签，验签方法参见[验签示例](#section6682105612547)。 说明： 华为服务器端对sign进行了urlencode处理，开发者需要对sign进行urldecode处理才能获取真实的签名字符串。|
|extInfos|否|Map\<String, String\>|通知发货请求中不参与验签的扩展信息。当前包含参数如下： payOrderId：实际的支付订单号，开发者发起退款时使用。 举例：{"payOrderId":"H202012241940\*\*\*\*\*\*\*\*\*"}|

DeliveryRequest  

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:--------------------------------------------------------------------|
|developerId|是|String|开发者帐号ID，用于唯一标识当前开发者。|
|orderId|是|String|华为生成的业务订单号，开发者可在发货完成后向华为服务器通知时携带。|
|openId|是|String|用户的唯一标识。 如果开发者使用unionId作为用户唯一标识，在获取openId后可根据openId和unionId的对应关系自行映射。|
|appId|是|String|需要发货的应用ID。|
|count|是|String|传入固定值1。|
|productNo|是|String|需要发货的商品ID。|
|ts|是|String|通知发送时间的时间戳，即距离1970年1月1日0点的毫秒数。|

#### 响应参数

|参数名称|是否必选|参数类型|描述|
|:----|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------------------|
|error|否|String|处理失败时包含操作结果的JSON字符串，格式为"{"errorCode": xxx, "errorMsg": xxxx}"。 * errorCode：错误码，具体取值请参见[错误码](#section974973513918)。 * errorMsg：错误码对应的描述信息。|
|data|否|String|处理成功时包含操作结果的JSON字符串，格式为"{"result": 0}"。0表示处理成功，可以发货。|

HTTP/1.1 200 OK

#### 验签示例

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240927134839.02619157077196567228513376348923:50001231000000:2800:2BD277DF5284E01DA8B80BB78DB29140AEAC50CCE2BDEDFEAD97E8018CB2AFAA.png?needInitFileName=true?needInitFileName=true)  
验签前请确保待校验字符串中的参数顺序为developerId、orderId、openId、appId、count、productNo、ts，否则会导致验签失败。

```
/** *校验签名信息  
* @param content 待校验字符串，传入请求参数data的json字符串。 
* @param sign 签名字符串  
* @param publicKey 验签公钥  
* @param 是否校验通过  
*/ 
public static boolean doCheck(String content, String sign, String publicKey) { 
   try { 
      KeyFactory keyFactory = KeyFactory.getInstance("RSA"); 
      byte[] encodedKey = decoder.decode(publicKey); 
      PublicKey pubKey = keyFactory.generatePublic(new X509EncodedKeySpec(encodedKey)); 
      java.security.Signature signature = null; 
      signature = java.security.Signature.getInstance("SHA256WithRSA"); 
      signature.initVerify(pubKey); 
      signature.update(content.getBytes("utf-8")); 
      boolean bverify = signature.verify(decoder.decode(sign)); 
      return bverify; 
   } catch (Exception e) { 
      e.printStackTrace(); 
   } 
   return false; 
}
```
