# 商户处置结果回调通知

#### 功能介绍

商户被处置后，华为支付服务器调用此接口向开发者服务器发送关键事件通知。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为支付服务器 -\> 开发者服务器|
|接口URL|URL由开发者在创建商户处置通知回调地址接口时传的notifyUrl|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

* Request Body  

  |参数|是否必填|参数类型|描述|
  |:-----------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |callbackId|是|String|回调通知的唯一ID。|
  |callbackTime|是|String|回调通知时间。|
  |dataType|是|String|数据加密类型标识。 * encrypt：加密 * plain：未加密|
  |sign|是|String|回调通知结果签名，除"sign"字段以外的其他字段参与签名。|
  |signType|是|String|签名类型。华为支付生成签名字符串使用的算法，当前为SM2算法。|
  |certNo|否|String|签名所使用的证书编号。|
  |subMercNo|否|String|子商户号。|
  |subMercName|否|String|子商户名称。|
  |limitPolicy|否|String|处置措施（简称）。 * 限制结算功能：限制结算功能，交易资金暂停结算。 * 限制出款功能：限制出款功能，无法使用结算、提现、退款等功能。 * 商户号冻结：商户号冻结，无法使用交易、结算、提现、退款等功能。 * 限制支付账户功能：限制支付账户功能，无法使用充值、转账、红包、代付、补差等功能。|
  |policyDesc|否|String|处置措施描述。|
  |limitTime|否|String|处置开始时间。|
  |limitReason|否|String|处置原因。 * RISK_CONTROL：存在风险异常 * UNLICENSED_BUSINESS：主体在工商系统登记状态已注销或吊销 * ABNORMAL_REGISTRATION_STATE：主体在工商系统登记状态异常 * SELF_FREEZING：商户自冻结 * INACTIVE_TRANSACTION：长时间无交易 * OUTDATED_DOCUMENT：信息未更新 * BUSINESS_LICENSE_EXPIRED：营业执照到期 * LEGAL_REPRESENTATIVE_ID_EXPIRED：法定代表人证件到期 * BENEFICIARY_ID_EXPIRED：受益人证件到期 * DOCUMENT_EXPIRED：证件到期|
  |limitDesc|否|String|处置原因描述。|

#### 响应参数

* Response Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

<!-- -->

* Response Body  

  |参数|是否必选|参数类型|描述|
  |:---------|:---|:-----|:-----------------------------------------------------------------------|
  |resultCode|是|String|华为支付侧解析application/json类型响应，"000000"表示成功，其他值失败，如返回值格式不匹配或非"000000"将视为失败。|
  |resultDesc|是|String|结果描述。|

<!-- -->

* 响应示例

  ```
  HTTP/1.1 200 OK
  Content-Type: application/json; charset=UTF-8
  {
    "resultCode": "000000",
    "resultDesc": "Success."
  }
  ```
