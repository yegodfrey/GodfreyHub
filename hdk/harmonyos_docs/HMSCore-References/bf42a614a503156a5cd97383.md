# 查询结算账单

> 说明
>
> 1. 获取结算账单API接口能力需要管理员到"[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/)>功能设置"，开启"结算单接口开启开关"，开启后**次日开始生成** 前一日的账单。
>
>    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/29/v3/7IgY9rtOQPSnDF7OnVFH4g/zh-cn_image_0000002480320070.png?HW-CC-KV=V1&HW-CC-Date=20260910T132632Z&HW-CC-Expire=31536000000&HW-CC-Sign=E8F54F5E238A5A62F24352D7B608FF34972FA03CEE736F5A17B2E0A2FEC149C7 "点击放大")
> 2. 无论是否产生交易，每日自动生成账单。如果查询日期超限或未生成，则不返回文件下载信息。其他情况会返回。
> 3. 账单下载后，建议遍历附件目录以获取csv后缀的文件进行解析。
> 4. 解析表单内容时，需考虑表单更新，如新增列等场景。

## 功能介绍

提供给商户下载结算账单。

## 接口原型

|承载协议|HTTPS GET|
|-----|------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器-> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/partner/bill/settle-bill/downloadInfo?billDate=xxxxxx[&subMercNo=xxxxxx]|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

* **Request Header**

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|

* **Request Query**

  |参数|是否必选|参数类型|描述|
  |:--------|:---|:-----|:----------------------------------------------------------------------------------------------------|
  |billDate|是|String|账单日期。只能查询九十日内的，需精确到某一天，格式：yyyyMMdd（如20210101）。 不支持下载当日账单，只能下载前一日24点前的账单数据，当日数据一般于次日 15 点后生成，特殊情况可能延迟。|
  |subMercNo|否|String|平台子商户/特约商户商户号。传入时返回的账单数据将只包含对应子商户的记录信息，不传默认查询商户下所有记录信息。|

  |参数|是否必选|参数类型|描述|
  |:----------------|:---|:---------------------------------------------------------------------------------------------------------------------------------------|:-----------------------|
  |resultCode|是|String|结果码，"000000"表示成功，其他表示失败。|
  |resultDesc|是|String|结果描述。|
  |subCode|否|String|业务错误码。|

## 错误码

(**result_code** 非400000的错误码请看[公共错误码说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-error-code-description-0000001589053741#section1187515498410))

错误码

|**result_code**|**result_desc**|**sub_code**|**sub_desc**|**solution**|
|:--------------|:--------------|:----------------------|:-----------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
|400000|业务处理失败|NOT_SETTLEMENT_DATE|非结算日，账单未生成|请选择结算日重试|
|400000|业务处理失败|BILL_SWITCH_NOT_TURN_ON|账单开关没有打开|请检查并[打开账单开关](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-base-payment-load-settle-bill-0000001644012081)|
|400000|业务处理失败|INVALID_SUB_MERCNO|权限异常，请求传递的子商户号不是验签商户的子商户|请检查子商户号是否和验签商户正确关联|
|400000|业务处理失败|INVALID_ARGUMENTS|参数不合法|请检查请求参数|
|400000|业务处理失败|UNKNOWN_ERROR|服务暂不可用, 请稍后重试|请稍后重试|

## 下载文件示例

```screen
RestTemplate restTemplate = new RestTemplate(new HttpComponentsClientHttpRequestFactory(HttpClients.createSystem()));
HttpHeaders headers = new HttpHeaders();
// billResponse为请求账单接口响应的对象
billResponse.getBillDownloadParam().getHeaders().forEach(headers::add);
HttpEntity<?> httpEntity = new HttpEntity<>(headers);
ResponseEntity<byte[]> responseEntity = restTemplate.exchange(billResponse.getBillDownloadParam().getDownloadUrl(), HttpMethod.GET, httpEntity, byte[].class, new Object[0]);
if (responseEntity.getStatusCode() == HttpStatus.OK) {
    // ./结算账单2022xxxxxx.zip 路径可自定义
    Files.write(Paths.get("./结算账单2022xxxxxx.zip"), responseEntity.getBody());
}
```
