# 路线导入接口

#### 功能介绍

将运动路线导入到运动健康App。  

#### 场景描述

用户将三方平台的路线导出为线路文件，在进行华为账号授权之后，通过本章节内容实现路线数据导入并展示在华为运动健康APP上。  

#### 使用约束

当前只支持GPX文件格式的路线导入。  

#### 接口原型

|承载协议|HTTPS PUT|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/routeInfos?format=\*\*\*|
|数据格式|请求消息：Content-Type: application/xml 响应消息：Content-Type: application/json|
|-----|-------------------------------------------------------------------------|

#### 查询参数

|参数|参数类型|是否必选|描述|
|:-----|:-----|:---|:--------------------|
|format|String|是|轨迹导入支持的格式。当前只支持GPX格式。|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/xml|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body

使用标准的GPX格式。扩展字段增加下面三个字段：  

|参数|参数类型|是否必选|描述|
|:------------|:-----|:---|:--------------|
|totalTime|Double|是|路线使用的总时间，单位为秒。|
|totalDistance|Double|是|路线的总距离，单位为米。|
|routeName|String|是|路线的名字，限制长度1000。|

文件元数据（metadata）包含以下字段：  

|参数|参数类型|是否必选|描述|
|:---|:-----|:---|:----------------------------------|
|time|String|否|文件的创建日期，为UTC时间，符合ISO 8601日期/时间表示规范。|

路径轨迹（trk，限制80000个轨迹点）包含以下字段：  

|参数|参数类型|是否必选|描述|
|:---|:-----|:---|:----------------------------------|
|lat|Double|是|纬度，-90°\~90°。|
|lon|Double|是|经度，-180°\~180°。|
|time|String|否|轨迹的创建日期，为UTC时间，符合ISO 8601日期/时间表示规范。|
|type|String|否|轨迹的类型，限制长度200。|
|ele|Double|否|海拔单位为米。|

路线（rte，限制80000个轨迹点）包含以下字段：  

|参数|参数类型|是否必选|描述|
|:---|:-----|:---|:----------------------------------|
|lat|Double|是|纬度，-90°\~90°。|
|lon|Double|是|经度，-180°\~180°。|
|time|String|否|路线的创建日期，为UTC时间，符合ISO 8601日期/时间表示规范。|
|ele|Double|否|海拔，单位为米。|

CP点（wpt）包含以下字段：  

|参数|参数类型|是否必选|描述|
|:---|:------|:---|:-----------------------|
|lat|Double|是|纬度，-90°\~90°。|
|lon|Double|是|经度，-180°\~180°。|
|name|String|否|CP点名称，限制长度128。|
|desc|String|否|CP点描述，限制长度128。|
|sym|Integer|否|CP点类型，0\~14，253，254，255。|

CP点的扩展字段中包含以下字段：  

|参数|参数类型|是否必选|描述|
|:----|:------|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|mode|Integer|否|CP点模式，0：自动点，1：手动点。|
|color|Integer|否|\[1,255\]，典型取值如下： 0：橙色（#FFFB6522） 1：红色（#FFFF0000） 2：蓝色（#FF5794CC） 3：黄色（#FFE6CB48） 4：灰色（#FF6B6F5F） 5：绿色（#FF9FE150） 255：自动标记点颜色（#FFFB6500） 说明： 典型颜色代码为"透明度+RGB颜色"的八位十六进制代码。|

<br />

#### 请求示例

```
PUT
https://health-api.cloud.huawei.com/healthkit/v2/routeInfos?format=GPX
Content-Type: application/xml
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
<?xml version='1.0' encoding='UTF-8' standalone='yes' ?>
<gpx version="1.1" creator="***" xmlns:xsi="***" xmlns="***" xsi:schemaLocation="***">
  <metadata>
    <time>1970-01-01T00:00:00Z</time>
  </metadata>
  <extensions>
    <totalTime>10000</totalTime>
    <totalDistance>10000</totalDistance>
    <routeName>testRouteName</routeName>
  </extensions>
  <rte>
    <rtept lat="24.27207756704355" lon="98.6666815648492">
      <ele>2186.0</ele>
    </rtept>
    <rtept lat="24.27218810046418" lon="98.66668171910422">
      <ele>2188.0</ele>
    </rtept>
    <rtept lat="24.27229019048912" lon="98.6667668786458">
      <ele>2188.0</ele>
    </rtept>
    <rtept lat="24.27242784195029" lon="98.6668908573738">
      <ele>2188.0</ele>
    </rtept>
  </rte>
  <wpt lat="40.730610" lon="-73.935242">
        <name>名称</name>
        <desc>描述</desc>
        <sym>1</sym>
        <extensions>
            <color>1</color>
            <mode>0</mode>
        </extensions>
  </wpt>
  <wpt lat="00.000000" lon="-00.000000">
        <name>名称</name>
        <desc>描述</desc>
        <sym>2</sym>
        <extensions>
            <color>2</color>
            <mode>0</mode>
        </extensions>
  </wpt>
</gpx>
```

#### 响应参数

状态码为200时：

Response Header  

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

Response Body  

|参数|参数类型|是否必选|描述|
|:------|:---|:---|:---|
|routeId|Long|是|路线ID|

#### 响应示例

```
HTTP/1.1 200 OK
Content-type: application/json;charset=utf-8
{
    "routeId": 167001079583340846
}
```
