# getPayResultInfoFromIntent

#### 接口定义

```
 PayResultInfo payResultInfo = HuaweiPay.HuaweiPayApi.getPayResultInfoFromIntent(Intent data);
```

#### 接口描述

调用pay接口拉起支付后会在Activity的onActivityResult方法中回调支付结果，可用此方法解析支付结果数据。  

#### 请求参数

|参数|是否必填|参数类型|描述|
|:---|:---|:-----|:-----------------|
|data|是|Intent|包含支付结果信息的Intent对象。|

#### 返回值

|参数|参数类型|描述|
|:---------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------|
|returnCode|int|返回码，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/vr-errorcode-0000001064289571)，当有业务返回码时，会将此值赋值给retCode。|
|errMsg|String|信息描述。|
|orderID|String|华为支付平台订单号。|
|amount|String|金额。|
|currency|String|币种。|
|country|String|国家/地区码。|
|time|String|时间戳。|
|requestId|String|商户订单号。|
|userName|String|商户名称，来源：开发者注册的公司名。|
|sign|String|以上数据的签名信息。|
[表1 payResultInfo]

#### 调用示例

以下代码片段来源于[客户端示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/vr-client-sample-code-0000001064616643)，您可直接下载代码工程。相关的类和常量定义等可参见代码工程。

```
@Override
protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
    super.onActivityResult(requestCode, resultCode, data);
    if (requestCode == REQUEST_PAY) {
        if (resultCode == Activity.RESULT_OK) {
            //获取支付完成信息
            PayResultInfo payResultInfo = HuaweiPay.HuaweiPayApi.getPayResultInfoFromIntent(data);
            if (payResultInfo == null) {
                return;
            }
            int retuenCode = payResultInfo.getReturnCode();
            if (retuenCode == PayStatusCodes.PAY_STATE_SUCCESS) {
                Toast.makeText(this, "支付成功", Toast.LENGTH_SHORT).show();
                boolean checkRst = PaySignUtil.checkSign(payResultInfo, Constant.getPublicKey());
                if(checkRst){
                    // 支付成功且验签成功，发放商品
                    Log.i("IAP", "pay success");
                } else {
                    // 签名失败，需要查询订单状态：对于没有服务器的单机应用，调用查询订单接口查询；
                    // 其他应用到开发者服务器查询订单状态
                    startQueryOrder();
                }
            } else {
                dealPayResultErrCode(retuenCode);
            }
        }
    }
}
```
