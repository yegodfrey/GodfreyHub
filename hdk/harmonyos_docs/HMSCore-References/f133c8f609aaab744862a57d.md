# 调用量限额

开发者调用钱包服务器接口有次数限制。

下表所示为每个"passTypeIdentifier"对应的接口调用量限额：  

|接口类别|每日调用限额（次）|总调用限额（次）|
|:------------|:----------------------|:-------|
|创建卡券模板|500|5000|
|单个查询卡券模板|1000|-|
|全量更新卡券模板|500 备注：此为两接口调用次数之和的限额|-|
|局部更新卡券模板|500 备注：此为两接口调用次数之和的限额|-|
|卡券模板添加message|2000|-|
|新增卡券实例|20000|1000000|
|单个查询卡券实例|20000|-|
|全量更新卡券实例|10000 备注：此为两接口调用次数之和的限额|-|
|局部更新卡券实例|10000 备注：此为两接口调用次数之和的限额|-|
|卡券实例添加message|20000|-|
|关联/去关联优惠券信息|20000|-|

下表所示为每个"App ID"对应的接口调用量限额：  

|接口类别|每日调用限额（次）|总调用限额（次）|
|:--------|:--------|:-------|
|批量查询卡券模板|1000|-|
|批量查询卡券实例|1000|-|
|NFC卡券数据托管|50000|-|

调用接口次数超过限额后，华为钱包服务器会返回[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-server-errorcode-0000001051072926)"429"。
