# Overview

包含华为编辑框的相关功能类以及模型类。

## Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------|

|[HwHelpTextLayout](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwedittext-class-hwhelptextlayout-0000001051782244)|帮助文本布局，包含编辑框和文本控件。|
|[HwIconTextLayout](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwedittext-class-hwicontextlayout-0000001052862246)|按钮文本布局，包含编辑框和图像控件。|
