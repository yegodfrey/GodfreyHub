#### getUnionId

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getUnionId() 如果授权时携带[setId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-support-hwid-request-hwidauthparamshelper-0000001050050425#section1679116121206)指定的授权参数，该方法返回用户的UnionID，否则返回null。 UnionID是开发者帐号ID，对于同一个用户，同一个开发者帐号下管理的不同应用，UnionID值相同。如果一个应用转移到另外一个帐号后，UnionID值也会变化。当前固定长度46，最大允许长度64，需进行三倍冗余考虑，不推荐进行长度限制。 UnionID和OpenID的区别请参见[说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/faq-0000001050048966#section1813811309575)。 使用UnionID作为用户标识需要满足以下所有条件： * 应用集成HMS Core SDK 3.0.0以及更高版本。 * HMS Core（APK）版本为3.0.0以及更高版本。 * 应用启用了UnionID。|

Returns  

|Type|Description|
|:-----|:------------|
|String|获取用户的UnionID。|

#### getOpenId

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getOpenId() 如果授权时携带[setId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-support-hwid-request-hwidauthparamshelper-0000001050050425#section1679116121206)指定的授权参数，该方法返回OpenID，否则返回null。 同一个用户，不同应用，OpenID值不同。使用OpenID标识用户，多个应用之间同一个华为帐号用户在开发者系统内会被标识为多个用户。当前非固定长度，最大允许长度256，需进行三倍冗余考虑，不推荐进行长度限制。|
