# HwSpinner

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HwSpinner extends Spinner HwSpinner继承与原生Spinner，扩展了如下特性： 1. 下拉弹框区域左右24dp及底部保证具有16dp的屏幕边距。 2. 下拉弹框的单个Item的行高规则同List规则，即单行text的List规则，上下边距8dp，左右边距16dp，总高度48dp。 3. 下拉弹框区域内边距左右边距16dp。 4. 下拉弹框超长处理，字体动态变化，从正常的16sp逐步缩小，最小字号为9sp。 5. 展开菜单如果继续超长允许换行，maxLines="2"，继续超出后需要截断+省略号。 6. 下拉弹框点击效果跟随List规范，背景5%的黑色。 7. 弹出框动画效果继承Holo主题下的效果。 8. 关闭窗口和文字大小变化90%-100%，使用阻尼曲线；透明度变化100-0，标准曲线。 9. 打开窗口和文字大小变化90%-100%，使用阻尼曲线；透明度变化0-100，标准曲线。 10. 栅格化特性。 该控件只支持在API 28及以下使用。|
