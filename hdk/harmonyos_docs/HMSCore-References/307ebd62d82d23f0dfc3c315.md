# 平台类商户/服务商

![](https://media:201774590622388546)  
服务商：华为支付商户与华为支付之间的连接者，为特约商户提供开户申请、支付接入、技术开发等综合解决方案的机构。

平台类商户：为入驻商家提供服务的网络交易平台，入驻商家为平台子商户。
