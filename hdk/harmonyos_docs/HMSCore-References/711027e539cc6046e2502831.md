# HwHelpTextLayout

|Class Info|
|:------------------------------------------------------------------------------------------------|
|public class HwHelpTextLayout extends LinearLayout 该类是华为的新型HelpText布局，继承了LinearLayout，包括编辑框和文本控件。|

#### XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:-------------------------------|
|String|hwHelp 帮助说明文本。|
|enum|hwShapeMode 输入框形状（胶囊型、线型）。|
|String|hwHint 输入框提示文本。|
|reference|hwHelpTextAppearance 定义华为帮助文本皮肤。|
|string|hwText 定义华为编辑框文本。|
