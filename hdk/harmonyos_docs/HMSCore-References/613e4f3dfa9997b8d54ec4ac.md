# ServiceOpenIdStatus

* 支持的场景：手机。
* 支持的OS：HarmonyOS 2.0及以上。

|Interface Info|
|:------------------------------------------------------------------------------------------------------------------------------------|
|public interface ServiceOpenIdStatus 获取Service Open Id接口类，可以从该类中调用getResult获取调用接口是否成功；调用getReason获取失败原因；成功时调用getSid获取Service Open Id。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:------------------------------------|
|abstract int|[getResult](#section14459057101312)()|
|abstract String|[getReason](#section95655716222)()|
|abstract String|[getSid](#section1258013102314)()|

#### Public Methods

#### getResult

|Method|
|:----------------------------------------|
|public abstract int getResult() 获取接口调用结果。|

Returns  

|Type|Description|
|:---|:----------------|
|int|0表示成功；其他为错误码，表示失败|

|Method|
|:----------------------------------------------|
