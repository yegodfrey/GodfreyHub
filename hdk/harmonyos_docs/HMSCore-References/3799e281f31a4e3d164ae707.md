# HmsInstanceId

* 支持的场景：手机、平板。
* 支持的OS：EMUI 4.0+、Android 4.0+。

### getId

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getId() 同步获取AAID。应用申请Token之前调用本接口获取AAID。Push服务端根据AAID生成应用的Token。如果应用的AAID发生变化，下次申请Token时也会生成新的Token。 应用如果要上报统计事件，也需要获取AAID作为应用唯一标识。|

**Returns**

|Type|Description|
|:-----|:----------|
|String|AAID。|

### getAAID

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)<[AAIDResult](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aaid-result-0000001050255642)> getAAID() 异步任务获取AAID。此接口为异步操作接口，需要添加对应的侦听器来侦听任务执行结果。|

**Returns**

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)<[AAIDResult](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aaid-result-0000001050255642)>|接口调用结果为[Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)<[AAIDResult](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aaid-result-0000001050255642)>类型，您需要添加对应的侦听器来侦听任务执行结果。任务执行成功后可以使用[AAIDResult](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aaid-result-0000001050255642)中的[getId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aaid-result-0000001050255642#section1788692510237)()方法获取AAID字符串。|

```java
"Java"
public void getAAID() {
    Task<AAIDResult> idResult = HmsInstanceId.getInstance(context).getAAID();
    idResult.addOnSuccessListener(new OnSuccessListener<AAIDResult>() {
        @Override
        public void onSuccess(AAIDResult aaidResult) {
            // 获取AAID方法成功
            String aaid = aaidResult.getId();
            Log.d(TAG, "getAAID success:" + aaid );
        }
    }).addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            // 获取AAID失败
            Log.d(TAG, "getAAID failure:" + e);
        }
    });
}
```

```java
"Kotlin"
fun getAAID() {
    val idResult = HmsInstanceId.getInstance(context).aaid
    idResult.addOnSuccessListener{ aaidResult ->        
        // 获取AAID成功
        Log.d(TAG, "getAAID success, the aaid is " + aaidResult.getId())        
    }.addOnFailureListener{ exception ->        
        // 获取AAID失败
        Log.d(TAG, "getAAID failed, catch exception: $exception")
    }
}
```

### deleteAAID

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void deleteAAID() throws [ApiException](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/apiexception-0000001050123087) 删除本地生成的AAID与时间戳并同步删除已生成的与本AAID相关的所有Token。 此接口为同步接口，在主线程中请勿调用此接口，以免阻塞主线程。|

**Throws**

|Name|Description|
|:-------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[ApiException](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/apiexception-0000001050123087)|调用此方法失败产生的一切异常都通过本异常类抛出。您可以通过[ApiException](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/apiexception-0000001050123087)类提供的方法获取错误信息。|

```screen
"Java"
public void deleteAAID() {
    // 创建新线程
    new Thread() {
        @Override
        public void run() {
            try {
                // 删除AAID
                HmsInstanceId.getInstance(context).deleteAAID();
                Log.i(TAG, "deleteAAID ok.");
            } catch (Exception e) {
                Log.i(TAG, "deleteAAID failed! Catch exception : " + e);
            }
        }
    }.start();
}
```

```screen
"Kotlin"
fun deleteAAID() {

        }
    }.start()
```
