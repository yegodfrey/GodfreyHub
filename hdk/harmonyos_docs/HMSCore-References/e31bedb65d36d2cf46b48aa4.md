## Public Methods

### getAdvertisingIdInfo

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AdvertisingIdClient.Info](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/advertisingidclient-info-0000001050064942) getAdvertisingIdInfo(Context context) throws IOException 获取OAID和"限制广告跟踪"的开关状态。 如果用户手机中，HMS Core（APK）版本在2.6.2以下，无法获取OAID，将抛出IOException。|

**Parameters**

|Name|Description|
|:------|:-----------------|
|context|Android的标准Context。|

**Returns**

|Type|Description|
|:------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|[AdvertisingIdClient.Info](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/advertisingidclient-info-0000001050064942)|接口调用成功返回[AdvertisingIdClient.Info](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/advertisingidclient-info-0000001050064942)对象。|

**Throws**

|Name|Description|
|:----------|:------------------------------------------|
|IOException|接口调用失败抛出IOException，通过getMessage可以获取异常信息描述。|

**Sample code：**

```screen
/**
 * 在非UI线程获取设备标识信息
 */
private Thread getIdentifierThread = new Thread() {
    @Override
    public void run() {
        try {
            AdvertisingIdClient.Info info = AdvertisingIdClient.getAdvertisingIdInfo(getApplicationContext());
            if (null != info) {
                Log.i("AdvertisingIdClient", "info id=" + info.getId() +
                        ", isLimitAdTrackingEnabled=" + info.isLimitAdTrackingEnabled());
            }
        } catch (IOException e) {
            Log.i("AdvertisingIdClient", "getAdvertisingIdInfo Exception: " + e.toString());
        }
    }
};
```

### verifyAdId

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static boolean verifyAdId(Context context, String adId, boolean isLimitAdTracking) throws AdIdVerifyException 校验OAID和"限制广告跟踪"开关是否是有效。 此方法存在耗时较长的情况，请不要在主线程调用此方法。|

**Parameters**

|Name|Description|
|:----------------|:-----------------|
|context|Android的标准Context。|
|adId|OAID。|
|isLimitAdTracking|"限制广告跟踪"开关状态。|

**Returns**

|Type|Description|
|:------|:-----------------------------------------------------------|
|boolean|* true表示有效的OAID和"限制广告跟踪"开关状态。 * false表示无效的OAID和"限制广告跟踪"开关状态。|

**Throws**

|Name|Description|
|:--------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------|
|[AdIdVerifyException](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adidverifyexception-0000001184085596)|接口调用失败抛出AdIdVerifyException，通过getMessage可以获取异常信息描述。|
