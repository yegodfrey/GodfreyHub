# BarCode

|参数|是否必选|参数类型|描述|
|:-------|:---|:-----|:-------------------------------------|
|text|否|String|条形码下面一段描述或者数字|
|type|是|String|类型，当前支持如下两种： * codabar：条形码 * qrCod：二维码|
|value|是|String|二维码的内容|
|encoding|是|String|编码方式，如UTF-8|

示例：

```
{
    "barCode": {
        "text": "1118466050",
        "type": "codabar",
        "value": "1118466050",
        "encoding": "UTF-8"
    }
}
```
