# onBLEServicesDiscovered：通知三方发现BLE服务

**接口原型**

public void onBLEServicesDiscovered(String function)

方法描述：蓝牙设备建立连接后，开始发现设备支持的服务，当服务被发现后，回调通知三方。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-------------------------------------------|:---|
|function|String|设备主动上报低功耗蓝牙服务发现状态的回调函数名，该回调函数有一个参数，详情参见响应参数。|M|
[**表1**请求参数]

请求示例：

```screen
function() {
     window.changeServiceDiscoverState = this.changeServiceDiscoverState;
     // 注册发现服务的回调方法
     window.hilink.onBLEServicesDiscovered("changeServiceDiscoverState");
}
```

**响应参数**

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:------------|:---|
|errCode|Number|0，表示发现了BLE服务。|M|
[**表2**响应参数]

> 说明
>
> closeBLEConnection调用前生效。closeBLEConnection后，会清除回调注册。
