# AdsNative

#### 概述

原生广告容器组件。  

#### 参数

|参数|是否必选|类型|描述|
|:--------------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|choicesPosition|否|number|广告选项的展示位置。 参数取值请参见[ChoicesPosition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section1395188192920)。|

#### 方法

|方法|描述|参数|返回值|
|:----------------------------------------------|:----------|:-------------------------------------------------------------------|:--|
|registerNativeAd(adData, clickViews, videoView)|注册广告素材。|* adData：广告素材对象。 * （可选）clickViews：广告子元素集合。 * （可选）videoView：广告视频播放组件。|-|
|registerAppButton(appButton)|注册广告应用下载组件。|appButton：广告下载组件。|-|
|onAdClose(keyWords)|广告关闭回调。|（可选）keyWords：广告关闭理由。|-|
|unregister()|广告组件注销。|-|-|

#### 事件

|事件|描述|用法|说明|
|:------|:---------------|:---------------------------------------------------------------|:--------------------------------|
|dislike|点击"不再显示该广告"按钮触发。|``` adsNativeVideoView.addEventListener('dislike', callback) ```|callback函数包含了以下参数： adId：广告素材标识ID。|
|adClick|用户点击广告位区域触发。|``` adsNativeVideoView.addEventListener('adClick', callback) ```|callback函数包含了以下参数： adId：广告素材标识ID。|
