#### Sample Code

```
private void updatePermissions(Drive drive, File file, Permission permission) {
    try {
        Permission newPermission = new Permission();
        newPermission.setRole("writer");
        permission = drive.permissions().update(file.getId(), permission.getId(), newPermission).execute();
    } catch (Exception e) {
        Log.e(TAG, "updatePermissions error:" + e.getMessage());
    }
}
```
