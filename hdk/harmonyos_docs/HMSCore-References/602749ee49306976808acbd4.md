|Class Info|
|:------------------------------------|
|public class DeeplinkClient 获取深度链接对象。|

|Constructor Name|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[DeeplinkClient](#section05238275714)(Context context, [OnDeeplinkAcquiredListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ondeeplinkacruiredlistener-0000001361522561) listener) 深度链接请求构造方法。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[request](#section1141110531817)() 从AG的转化归因参数中获取深度链接，回调[OnDeeplinkAcquiredListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ondeeplinkacruiredlistener-0000001361522561).launchDeeplink()方法， 如果launchDeeplink()返回false，则由ads-installreferrer SDK负责拉起该深度链接。 如果launchDeeplink()返回true，则表示由广告主自己来拉起深度链接。|

#### request

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void request() 从AG的转化归因参数中获取深度链接，回调[OnDeeplinkAcquiredListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ondeeplinkacruiredlistener-0000001361522561).launchDeeplink()方法。 如果launchDeeplink()返回false，则由ads-installreferrer SDK负责拉起该深度链接。 如果launchDeeplink()返回true，则表示由广告主自己来拉起深度链接。|

![](https://media:201785910058473989)  
request方法第一次请求后，会记录下此次请求，下一次调用将不会触发[OnDeeplinkAcquiredListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ondeeplinkacruiredlistener-0000001361522561).launchDeeplink()的回调。
