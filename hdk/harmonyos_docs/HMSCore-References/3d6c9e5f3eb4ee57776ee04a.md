# HwSeekBar

|Class Info|
|:-------------------------------------------------------------------|
|public class HwSeekBar extends SeekBar 华为样式滑动条，支持进度气泡展示，数字刻度和线段刻度样式。|

#### Nested Class Summary

|Qualifier and Type|Class Name and Description|
|:-----------------|:---------------------------------------------------------------------|
|interface|OnSeekBarChangeListener 当进度变化时的回调接口，包括用户通过触摸手势、箭头按键、轨迹球、以及代码方式引起的进度变化。|

#### XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:--------------------------------|
|boolean|hwShowText 定义是否显示提示，默认关闭。|
|reference|hwBubbleTipBg 定义水滴形状进度气泡可绘制资源。|
|reference|hwSingleTipBg 定义对话框形状进度气泡可绘制资源。|
|color|hwTipTextColor 定义进度气泡文字颜色。|
|dimension|hwTipTextSize 定义进度气泡文字大小。|
|reference|hwScaleLineDrawable 定义线段刻度点可绘制资源。|
|color|hwStepTextColor 定义刻度文字颜色。|
|dimension|hwStepTextSize 定义刻度文字大小。|
