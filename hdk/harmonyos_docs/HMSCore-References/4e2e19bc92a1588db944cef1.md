# HMSHealthKitActivityRealTimeType

以下HMSHealthKitActivityRealTimeType里的常量为Health Service Kit已定义的开始和结束运动支持的的运动类型常量。  

|Type|Name|Description|
|:-----|:-------------------|:----------|
|String|SPORT_TYPE_WALK|室外走。|
|String|SPORT_TYPE_RUN|室外跑。|
|String|SPORT_TYPE_BIKE|室外骑行。|
|String|SPORT_TYPE_TREADMILL|室内跑。|
