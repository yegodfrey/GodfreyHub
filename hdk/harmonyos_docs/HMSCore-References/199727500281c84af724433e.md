# HAUserProfileType

|Interface Info|
|:--------------------------------------|
|HAUserProfileType 此接口提供了所有预定义用户属性名称的常量。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-----------------------------------------------|
|string|USERLEVEL 用户等级。对于构建了用户等级体系的应用，可使用此属性标识用户在应用内的级别。|
|string|ISFULLLEVEL 用于标识用户是否是满级用户。|
|string|ISMEMBER 用于标识用户的会员类型。|
