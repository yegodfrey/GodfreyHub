# ActivityRecordReadOptions

|Class Info|
|:---------------------------------------------------------------------------|
|public class ActivityRecordReadOptions 从华为Health Service Kit中读取运动记录数据的请求参数类。|

读取运动记录数据请求参数类的示例代码如下：

```screen
"Java"
// 请注意这里的startTime、endTime为读取运动记录的开始时间和结束时间，开发者可以自己定义
ActivityRecordReadOptions readOption = new ActivityRecordReadOptions.Builder()
    .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
    .readActivityRecordsFromAllApps()
    .read(DataType.DT_CONTINUOUS_STEPS_DELTA)
    .build();
```

```screen
"Kotlin"
// 请注意这里的startTime、endTime为读取运动记录的开始时间和结束时间，开发者可以自己定义
val readRequest = ActivityRecordReadOptions.Builder()
    .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
    .readActivityRecordsFromAllApps()
    .read(DataType.DT_CONTINUOUS_STEPS_DELTA)
    .build()
```

> 说明
>
> 1. 调用查询运动健康数据的锻炼记录接口，接口参数中的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳；
> 2. 调用查询运动健康数据的锻炼记录接口，接口参数中的开始时间和结束时间之间的时间跨度不允许超过31天。
