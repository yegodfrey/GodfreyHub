# LatLng

定义经纬度坐标，单位为度。  

#### Properties

|名称|类型|描述|
|:--|:-----|:------------------------|
|lat|double|经度。取值范围为-180\~180（不含180）。|
|lng|double|纬度。取值范围为-90\~90。|

|构造函数|描述|
