# Overview

包含华为列表的相关功能类和接口。  

#### Interface Summary

|Interface|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[HwLinkedViewCallBack](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwrecyclerview-interface-hwlinkedviewcallback-0000001052222252)|用于[HwRecyclerView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwrecyclerview-class-hwrecyclerview-0000001052662283)与AppBar的状态变化的回调。|
|[HwOnOverScrollListener](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwrecyclerview-interface-hwonoverscrolllistener-0000001052543561)|[HwRecyclerView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwrecyclerview-class-hwrecyclerview-0000001052662283) OverScroll状态回调。|

#### Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[HwDefaultItemAnimator](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwrecyclerview-class-hwdefaultitemanimator-0000001052463581)|实现了包括增加、删除、修改、移动在内的[HwRecyclerView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwrecyclerview-class-hwrecyclerview-0000001052662283)动效接口。|
|[HwRecyclerView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwrecyclerview-class-hwrecyclerview-0000001052662283)|在继承原生RecyclerView基础特性上，增加点击状态栏回滚到列表顶端、挖孔屏手机边距自动适配、自动滚动、OverScroll物理回弹效果、列表删除动效新特性。|
