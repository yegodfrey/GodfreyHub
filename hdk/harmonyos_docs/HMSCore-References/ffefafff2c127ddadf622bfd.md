# Overview

支持的设备：HarmonyOS系统的手机及部分智能表款型。

Health Service Kit JS SDK是适配HarmonyOS应用的SDK，集成后可使用相关接口进行管理运动健康数据、运动记录数据、健康记录数据、实时数据、个人资料。  

#### Public Method Summary

HMSHealthKit是Health Service Kit提供接口的入口类，其提供的接口能力包括[管理运动健康采样数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-sampling-data-0000001232012585)、[管理运动记录数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-activity-records-0000001186732884)、[管理健康记录数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027)、[管理实时数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-heart-data-0000001250273423)、[管理用户设置](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-authorisation-0000001206472504)、[管理个人资料](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-userinfo-0000001208702446)，包含以下方法。
