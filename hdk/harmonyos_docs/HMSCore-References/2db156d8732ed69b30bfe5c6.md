# BluetoothStatus

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Interface Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface BluetoothStatus 蓝牙状态接口类，其中定义了4个蓝牙状态的常量，即表示车载类型的蓝牙[DEVICE_CAR](#section71881338223)、蓝牙已连接[CONNECTED](#section525911458386)、表示蓝牙未连接[DISCONNECTED](#section10851114814388)和未识别到蓝牙状态[UNKNOWN](#section109391959123819)。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:----------------------------------------------|
|static int|[DEVICE_CAR](#section71881338223) 表示车载类型的蓝牙。|
|static int|[CONNECTED](#section525911458386) 表示蓝牙已连接。|
|static int|[DISCONNECTED](#section10851114814388) 表示蓝牙未连接。|
|static int|[UNKNOWN](#section109391959123819) 表示未识别到蓝牙状态。|
