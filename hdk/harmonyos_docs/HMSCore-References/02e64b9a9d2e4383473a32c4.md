# onBLECharacteristicValueChange：设备主动上报低功耗蓝牙设备的特征值变化

**接口原型**

public void onBLECharacteristicValueChange(String function)

方法描述：设备主动上报低功耗蓝牙设备的特征值变化。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:---------------------------------------|:---|
|function|String|获取低功耗蓝牙设备特征值变化回调函数名，该回调函数有四个参数，详情参见响应参数。|M|
[**表1**请求参数]

请求示例：

```screen
function() {
    window.changeCharacteristicsState = this.changeCharacteristicsState;
    window.hilink.onBLECharacteristicValueChange("changeCharacteristicsState");        
}
```

**响应参数**

|参数名称|参数类型|参数描述|可选选项|
|:---------------|:-----|:---------------------------------|:---|
|deviceId|String|蓝牙设备ID，通过接口getDeviceId()获取。|M|
|characteristicId|String|蓝牙设备特征值的UUID（不使用4位的简写，用完整写法的UUID）。|M|
|data|String|最新的特征值，以16进制字符串方式构造。|M|
[**表2**响应参数]

> 说明
>
> closeBLEConnection调用前生效。closeBLEConnection后，会清除回调注册。
