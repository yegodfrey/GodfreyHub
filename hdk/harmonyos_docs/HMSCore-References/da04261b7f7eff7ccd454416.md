# HuaweiMap.OnMapLoadedCallback

|Interface Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface HuaweiMap.OnMapLoadedListener 是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)类的一个内部接口，地图加载完成时的回调接口，包含一个抽象函数[onMapLoaded](#section25781857124418)()。当地图上所有的图层元素都渲染完成时会回调该接口。如果地图处于不可用状态，或者因为用户不停地与地图交互而导致地图不断变化且未完成加载，则此接口将不会触发回调。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------|
|abstract void|[onMapLoaded](#section25781857124418)() 地图加载完成时回调此方法。|

#### Public Methods

#### onMapLoaded

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract void onMapLoaded() 地图加载完成时回调此方法。此方法只会被回调一次，如果要再次收到回调，则必须重新调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757).[setOnMapLoadedCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section61080560616)([HuaweiMap.OnMapLoadedCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmaploadedcallback-0000001050150074))接口再次触发方法回调。 回调方法将在主线程中执行。|
