#### dataSet(int resourceId)

|Method|
|:-----------------------------------------------------------|
|public void dataSet(int resourceId) 您调用此API可以传入资源ID设置热力图数据集。|

Parameters  

|Name|Description|
|:---------|:------------------------------------------------------------------------------------------------------|
|resourceId|热力图数据集文件资源ID，文件格式：GeoJSON。 说明： * 热力图每个点的权重只支持通过GeoJSON中的mag属性设置，如果不设置，默认为1。 * 热力图权重为5的一个点与5个权重为1的点效果相同。|

#### opacity(float opacity)

|Method|
|:--------------------------------------------------------------|
|public void opacity(float opacity) 您调用此API可以设置热力图透明度，控制所有层级透明度。|

Parameters  

|Name|Description|
|:------|:-------------------------------------------------------------------------------------------------------------------|
|opacity|热力图透明度。取值范围：\[0, 1\]。 * 0：完全不透明。 * 1：完全透明。 值越大透明度越高，默认为完全不透明。 说明： 若透明度取值超过\[0, 1\]，会进行纠偏，即大于1纠偏为1的取值效果，小于0纠偏为0的取值效果。|
