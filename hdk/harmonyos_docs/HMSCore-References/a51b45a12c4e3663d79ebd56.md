# 存储测量结果

经过一定的时序交互和特征值结果的解析，可以获取本次测量的结果。三方厂商应该通过JS接口将测量结果存储到运动健康App。存储测量成功后，需通过scheme协议跳转到健康数据二级页面呈现测量结果。
