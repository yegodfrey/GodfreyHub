# HMSLocationManager

|Class info|
|:-----------------------------------------------------------|
|@interface HMSLocationManager : NSObject 定位管理类，提供了定位相关的实现方法。|

#### Public Property Summary

|Qualifier and Type|Property name and Description|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|@property (nonatomic, assign) BOOL|allowsBackgroundLocationUpdates 是否允许后台定位，默认值为NO。|
|@property (nonatomic, assign) NSString \*|apiKey api密钥。|
|@property (nonatomic, weak) id\<[HMSLocationManagerDelegate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445)\>|delegate 代理对象，遵循[HMSLocationManagerDelegate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445)协议。|
|@property (nonatomic, assign) CLLocationAccuracy|desiredAccuracy 期望定位精度，单位：米。 默认值为kCLLocationAccuracyBest，表示最高精确度。|
|@property (nonatomic, assign) CLLocationDistance|distanceFilter 定位的最小更新距离，单位：米。 默认值为kCLDistanceFilterNone，表示只要检测到设备位置发生变化就会更新位置信息。|
|@property (nonatomic, assign) CLLocationDegrees|headingFilter 方向获取的最小更新角度，单位：度。 默认为0，表示只要检测到设备朝向发生变化就会更新朝向信息。|
|@property (nonatomic, assign) CLDeviceOrientation|headingOrientation 设备当前的校准朝向。|
|@property (nonatomic, assign) NSInteger|locationTimeout 指定的单次定位超时时间，单位：秒。 默认值为10，最小值为2。|
|@property (nonatomic, assign) BOOL|pausesLocationUpdatesAutomatically 指定的定位是否会被系统自动暂停。 默认值为YES。|
|@property (nonatomic, assign) [HMSAuthorizationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmsauthorizationtype-0000001160524962)|preferredAuthorizationType 偏好授权类型。 默认值为[HMSAuthorizationTypeAuto](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmsauthorizationtype-0000001160524962#section633916215525)，表示权限未知。|

#### Public Methods

#### dismissHeadingCalibrationDisplay

|Method|
|:-----------------------------------------------------|
|- (void) dismissHeadingCalibrationDisplay; 移除设备朝向校准显示。|

#### locationServicesEnabled

|Method|
|:-------------------------------------------|
|+ (BOOL)locationServicesEnabled; 返回位置服务是否可用。|

Returns  

|Type|Description|
|:---|:--------------------------------------------------|
|BOOL|返回用户是否位置服务可用。 * YES：当前位置服务是可用状态。 * NO：当前位置服务是不可用状态。|

#### requestAlwaysAuthorization

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (void) requestAlwaysAuthorization; 位置权限"始终授权"请求方法。调用此方法前，必须在您应用程序的"info.plist"中添加相应的权限声明，具体操作请参见[添加权限声明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-add-permissionstatement-0000001205871011)。当用户选择授权后，Location SDK将会通过[HMSLocationManager:didChangeAuthorizationStatus:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445#section056214595157)回调方法传递用户的授权类型。|

#### requestLocationWithCompletionBlock:

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (BOOL) requestLocationWithCompletionBlock:([HMSLocatingCompletionBlock](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocatingcompletionblock-0000001205886475))completionBlock; 请求单次定位。|

Parameters  

|Name|Description|
|:--------------|:-------------------------------------------------------------------------------------------------------------------------------|
|completionBlock|请求成功回调block。包含[HMSLoc](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmsloc-0000001160206474)对象和NSError对象。|

Return  

|Type|Description|
|:---|:-------------------------------------------------------------|
|BOOL|返回单次定位请求是否成功。 * YES：请求成功。 * NO：请求失败。如果当前正在连续定位，调用此方法将会失败，返回NO。|

#### requestWhenInUseAuthorization

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (void) requestWhenInUseAuthorization; 位置权限"使用期间"授权请求方法。调用此方法前，必须在您应用程序的"info.plist"中添加相应的权限声明，具体操作请参见[添加权限声明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-add-permissionstatement-0000001205871011)。当用户选择授权后，Location SDK将会通过[HMSLocationManager:didChangeAuthorizationStatus:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445#section056214595157)回调方法传递用户的授权类型。|

#### startAuthorize

|Method|
|:---------------------------------------------------------|

#### startUpdatingHeading

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (void) startUpdatingHeading; 开启获取设备朝向。 如果设备支持方向识别，则会进入[HMSLocationManager:didUpdateHeading:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445#section210289181617)代理回调。需要根据应用场景设置合适的headingFilter来使用。每次捕获到错误都会触发代理中的[HMSLocationManager:didFailWithError:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445#section1642419471611) 回调方法。|

#### startUpdatingLocation

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|- (void) startUpdatingLocation; 开启连续定位。调用此方法会取消所有的单次定位请求。 每次捕获到新的位置信息都会触发代理中的[HMSLocationManager:didUpdateLocation:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445#section163769197165) 回调方法。每次捕获到错误都会触发代理中的[HMSLocationManager:didFailWithError:](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanagerdelegate-0000001205566445#section1642419471611)回调方法。|

#### stopUpdatingHeading

|Method|
|:----------------------------------------------------------------------------------|
|- (void) stopUpdatingHeading; 停止更新朝向。 此类事件会发送消息给接收器，使其在客户端不需要位置信息时，禁用适当的硬件（从而节省电源）。|

#### stopUpdatingLocation

|Method|
|:-------------------------------------------------------------------------------------------------------------------|
|- (void) stopUpdatingLocation; 停止连续定位。调用此方法同时会取消掉所有的单次定位请求，可以用来取消单次定位。 此类事件会发送消息给接收器，使其在客户端不需要位置信息时，禁用适当的硬件（从而节省电源）。|
