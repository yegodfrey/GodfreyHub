# Aqi

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class [Aqi](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/aqi-0000001050695586) implements Parcelable 天气状态WeatherStatus中的空气质量指数。包括一氧化碳浓度指数、二氧化氮浓度指数、臭氧浓度指数、PM10浓度指数、PM2.5浓度指数、二氧化硫浓度指数，和综合天气指数。仅支持国内数据。|
