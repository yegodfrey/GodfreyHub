# 签约结果通知回调

#### 功能介绍

用户签约完成后，华为支付服务器调用此接口向开发者服务器发送签约关键事件通知。  
![](https://media:201774590626966584)  
为保证回调请求的可靠性，系统具备重试机制，所以可能出现重发的通知。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|华为支付服务器 -\> 开发者服务器|
|接口URL|URL由开发者在请求预签约接口时传入的callbackUrl|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

* Request Body  

  |参数|是否必选|参数类型|描述|
  |:---------------|:---|:--------------------------------------------------------------------------------------------------------------------------------|:---------------------------------|
  |callbackId|是|String|回调通知的唯一ID。|
  |callbackTime|是|String|回调通知时间。|
  |dataType|是|String|数据加密类型标识。 * encrypt：加密 * plain：未加密|
  |sign|是|String|回调通知结果签名，除"sign"字段以外的其他字段参与签名。|
  |signType|是|String|签名类型。华为支付生成签名字符串使用的算法，当前为SM2算法。|
  |certNo|否|String|签名所使用的证书编号。|
  |planId|否|String|模板号。|
  |mercContractCode|否|String|商户侧生成，签约协议号。|
  |contractId|是|String|委托代扣协议ID。|
  |mercNo|否|String|商户号。|
  |appId|否|String|应用ID。|
  |operateTime|是|String|操作时间，如：2021-12-10 10:28:13。|
  |changeMode|否|String|签约方式。 * USER_SIGN：用户签约|
  |expireDate|否|String|签约过期时间，格式：yyyy-MM-dd。|
  |payer|否|[PayerOut](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section14195124713166)|用户客户端信息。|

#### 响应参数

* Response Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

<!-- -->

* Response Body  

  |参数|是否必选|参数类型|描述|
  |:---------|:---|:-----|:-----------------------------------------------------------------------|
  |resultCode|是|String|华为支付侧解析application/json类型响应，"000000"表示成功，其他值失败，如返回值格式不匹配或非"000000"将视为失败。|
  |resultDesc|是|String|结果描述。|

<!-- -->

* 响应示例

  ```
  HTTP/1.1 200 OK
  Content-Type: application/json; charset=UTF-8
  {
    "resultCode": "000000",
    "resultDesc": "Success."
  }
  ```
