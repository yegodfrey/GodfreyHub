# 消息订阅  
  
#### 功能介绍

您调用本API完成向订阅消息的用户推送通知。

#### 使用约束

消息体最大不能超过4096Bytes（不包括Token）。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 开发者服务器 -> 华为Push服务器  
接口URL | https://push-api.cloud.huawei.com/v3/**[projectid]** /messages:send 说明：  **[projectid]** ：项目ID，登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的项目”，在项目列表中选择对应的项目，左侧导航栏选择“项目设置”，在该页面获取。  
数据格式 | 请求消息：Content-Type: application/json 响应消息：Content-Type: application/json  
  
#### 请求参数

**Request Header**

参数 | 取值描述 | 样例  
---|---|---  
Authorization | 请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)或 [OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/oauth2-0000001212610981#section128682386159)。 说明：  Bearer后面拼接空格，再拼接获取的鉴权信息。 | Bearer eyJr****OiIx---*****OiJodHR---****eXSt4Gp---*** 或 Bearer CF3Xl2XV6jMK*******ccUIaDg==  
push-type | 消息类型，取值如下： 0：通知栏消息 | 0  
  
**Request Body**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
payload | 是 | AlertPayload Object | 推送消息结构体，详情请参见AlertPayload结构体，可参考请求示例。  
pushOptions | 否 | PushOptions Object | 发送控制参数，详情请参见PushOptions结构体。  
target | 是 | Target Object | 发送目标，详情请参见Target结构体。  
  
**AlertPayload**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
notificationMode | 是 | Integer | 是否为订阅消息。 1：订阅消息  
subscribeNotification | 否 | SubscribeNotification Object | 订阅消息内容，详情请参见SubscribeNotification结构体。  
  
**SubscribeNotification**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
entityId | 是 | String | 订阅消息对应的模板实例ID。  
data | 否 | Object | 若[订阅消息模板](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmony-java-noti-sub-0000001626768130#section3252638301)里有占位符，则本字段填写模板中的占位符需要被替换的变量值，否则不需要填写；格式为：key-value，其中value长度不超过50个字符。 **示例：{"keyword1":"aaaaaa", "keyword2": "bbbbbb"}**  
importance | 否 | String | 消息的提醒级别，取值如下：
                * LOW：表示通知栏消息预期的提醒方式为静默提醒，消息到达手机后，无铃声震动。 
                * NORMAL：表示通知栏消息预期的提醒方式为强提醒，消息到达手机后，以铃声、震动提醒用户（**默认值** ），实际提醒效果会根据订阅模板的[消息类型](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/message-classification-0000001149358835#ZH-CN_TOPIC_0000001652651372__p18153445171315)决定消息提醒方式。   
clickAction | 是 | ClickAction Object | 消息点击行为，详情请参见ClickAction结构体。  
profileId | 否 | String | 关联终端设备登录用户标识，最大长度为64。  
  
**ClickAction**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
actionType | 是 | Integer | 消息点击行为类型：
                * 1：打开应用自定义页面 
                * 3：打开应用首页   
legacy | 是 | LegacyClickAction Object | 设备点击行为具体动作，详情请参见LegacyClickAction结构体。
                * **当actionType为3时，必须携带本字段，内容可为空**示例：
                      
                      "clickAction": {
                        "actionType": 3,
                        "legacy": {}
                      }

                * **当actionType为1时，必须携带本字段，legacy结构体中的action和uri字段至少携带一个**示例：
                      
                      "clickAction": {
                        "actionType": 1,
                        "legacy": {
                          "action": "test"
                        }
                      }  
  
**LegacyClickAction**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
action | 否 | String | 填写要打开的页面activity对应的action，当actionType为1时，字段uri和action至少填写一个。  
uri | 否 | String | 当actionType为1时，设置待跳转页面的uri。  
data | 否 | Object | 自定义消息负载，点击时传递给应用，key-value格式。 **示例："data": {"key1": "value1", "key2": "value2"}**  
  
**PushOptions**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
testMessage | 否 | Boolean | 测试消息标识，每个应用每日可推送1000条消息订阅测试消息，取值如下：
                * false：正常消息**（默认值）**
                * true：测试消息   
ttl | 否 | Integer | 消息缓存时间，单位是秒。在用户设备离线时，消息在Push服务器进行缓存，在消息缓存时间内用户设备上线，消息会下发，超过缓存时间后消息会丢弃，**默认值为86400秒（1天）** ，最大值为15天。  
biTag | 否 | String | 批量任务消息标识，消息回执时会返回给应用服务器，应用服务器可以识别biTag对消息的下发情况进行统计分析。 **格式允许大小写字母、数字、空格、下划线、+、/、=、-。**  
receiptId | 否 | String | 输入一个唯一的回执ID指定本次消息的回执地址及配置，该回执ID可以在[回执参数配置](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/msg-receipt-guide-0000001050040176#section1883224614497)中查看。  
  
**Target**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
token | 是 | Array [String] | 按照 **单个Token** 向目标用户推送消息订阅通知**。** **示例："token": ["pushtoken"]**  
  
#### 请求示例
    
    {
        "pushOptions": {
            "testMessage": true
        },
        "payload": {
            "notificationMode": 1,
            "subscribeNotification": {
                "entityId": "TM*****FA9",
                "data": {
                    "keyword1": "接单了",
                    "keyword2": "苏A1****5",
                    "keyword3": "司机路径"
                },
                "clickAction": {
                    "actionType": 3,
                    "legacy": {}
                }
            }
        },
        "target": {
            "token": ["iqaaa*****aaaa"]
        }
    }

#### 响应参数

**Response Body**

参数 | 参数类型 | 描述  
---|---|---  
code | String | 错误码。  
msg | String | 错误码描述。  
requestId | String | 请求标识。  
  
#### 响应示例
    
    {
        "code": "80000000",
        "msg": "Success",
        "requestId": "157*******006"
    }
    

#### 错误码

HTTP错误码 | 描述 | 解决方法  
---|---|---  
200 | 成功。 | -  
400 | 参数错误。 | 请检查响应内容错误码并根据错误码进一步排查问题。  
401 | 鉴权失败。 | 请检查HTTP头中Authorization参数。  
404 | 找不到服务。 | 请检查请求URI是否正确。  
500 | 服务内部错误。 | 请联系华为技术支持解决。  
502 | 请求连接异常，常见于网络状况不稳定。 | 建议稍后重试，或联系华为技术支持解决。  
503 | 流量控制。 | 
                1. 平均分配发送速度，尽量控制在华为提供的QPS配额内。QPS配额请查看[FAQ](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/faq-0000001050042183#ZH-CN_TOPIC_0000001652491960__p833162017110)。 
                2. 平均分布推送时间段，不要集中发送。   
  
业务错误码 | 描述 | 解决方法  
---|---|---  
80000000 | 成功。 | 不涉及。  
80100000 | 部分Token发送成功。 | 请检查返回值中发送失败的Token。  
80100001 | 请求参数部分错误。 | 请按照响应消息中的提示，检查请求参数内容。  
80100003 | 消息结构体错误。 | 请按照响应消息中的提示，检查消息结构体内容。  
80100004 | 消息设置的过期时间小于当前时间导致。 | 请检查消息字段ttl。  
80100016 | 消息内容校验未通过 | 按照响应消息中的提示，检查对应字段是否含敏感词。  
80100022 | 消息携带图片未验签 | 请检查图片是否正常经过风控验证。  
80200001 | Oauth认证错误。 | 请求HTTP头中Authorization参数里面的Access Token鉴权失败，请检查Access Token。  
80200003 | Oauth Token过期。 | 请求HTTP头中Authorization参数里面的Access Token已过期，请重新申请后重试。  
80300002 | 当前应用无权限下发推送消息。 | 
                1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，查看Push服务状态是否已开通。 
                2. 如果您集成的是SDK 2.0版本，请把获取到的AT（Access Token）里的转义字符（\）去掉后再进行URL Encode编码（编码常用网址为https://tool.chinaz.com/Tools/urlencode.aspx）。 
                3. 用户的Token与应用的Token不匹配。 
                4. 如果您的应用在国内推送正常，而在海外服务器返回80300002错误码，则您需要开通海外的Push权益。具体操作：请找到“我的应用”后禁用Push服务，重新开启Push服务。  说明：  如果只开通Push服务，请您先去应用市场上传一个APK，保存草稿状态即可，否则重新添加的时候您可能无法找到原来的应用。
                5. 请检查发送消息体中内容是否有输入错误。 
                6. 您可先在推送运营平台先推送消息测试下，如果成功，则表明您在调用接口时出错。 
                7. 在多发送者场景下，请检查[接口原型](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197#section134322259125)。   
80200005 | JWT Token过期。 | 请重新生成JWT Token后再推送消息。  
80300007 | 所有Token都是无效的。 | 
                1. 同一个设备，不同应用的Token原则上是不一样，但实际操作时可能误传递同样的值。 
                2. 客户端应用配置的应用包名、应用ID与[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站上申请的不一致。 
                3. 检查获取access_token的URL是否正确。 
                4. 检查消息发送的URL是否正确。   
80300008 | 消息体大小（不含Token）超过系统设置的默认值（4096Bytes）。 | 请求消息体大小超过默认值，请减小消息体后重新发送消息。  
80300010 | 消息体中的Token数量超过系统设置的默认值。 | 请减少Token数量后分批发送消息。  
81000001 | 系统内部错误。 | 请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093)解决。
