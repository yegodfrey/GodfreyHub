# HuaweiMap

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HuaweiMap HuaweiMap是适用于地图服务SDK的主要功能入口类，与地图有关的所有方法从此处接入。您不能直接对象化HuaweiMap类，需要通过[MapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapfragment-0000001050150294)或者[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)中的getMapAsync()方法来获取它的对象。 > 说明 > HuaweiMap与View对象类似，只能从Android UI线程中读取和修改。从其他线程调用HuaweiMap方法可能会导致异常。 您可以通过更改相机的位置来调整地图的视图。您可以使用地图的相机设置位置、缩放级别、倾斜角度和方位等参数。有关更多信息，请参见[地图相机](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-map-camera-0000001061885327)。|
