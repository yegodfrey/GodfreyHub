# HWOverlay

#### 概述

在地图上添加自定义覆盖物。  

#### 构造函数

|函数|描述|
|:-----------------------------------|:-----------------------------------------------------------------------|
|HWMapJsSDK.HWOverlay(overlayOptions)|overlayOptions：设置Overlay的属性，详情见[OverlayOptions](#section11213936143011)。|

#### 方法

|方法|描述|参数类型|返回值|
|:--------------------|:---------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------|
|getContent()|获取[HWOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwoverlay-0000001050750149)的内容。|-|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|
|getMap()|获取绑定的地图实例。|-|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|
|getPosition()|获取[HWOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwoverlay-0000001050750149)的位置。|-|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)|
|getStopEvent()|获取是否支持穿透。|-|Boolean|
|setContent(content)|设置[HWOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwoverlay-0000001050750149)的内容。|String \| Element|-|
|setMap(map)|绑定到地图。|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|-|
|setPosition(latlng)|设置[HWOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwoverlay-0000001050750149)的位置。|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)|-|
|setStopEvent(boolean)|设置是否支持穿透。|Boolean|-|

#### OverlayOptions

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|content|否|String \| Element|弹出框中的显示内容，可以是纯文本或者是HTML元素。窗口会根据内容自动调整大小。调用该接口需要注意跨站脚本攻击，SDK中没有过滤有可能导致xss的html代码，因为作为SDK无法区分是否为您主动使用。|
|map|是|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|地图实例。|
|offset|否|\[Number, Number\]|可选，配置x，y偏移量。默认位置是指向position的位置。|
|position|是|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)|用于设置[HWOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwoverlay-0000001050750149)的位置。|
|stopEvent|否|Boolean|用于设置[HWOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwoverlay-0000001050750149)是否支持穿透，穿透表示不阻止事件，即鼠标事件在[HWOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwoverlay-0000001050750149)上可以穿透到地图上。 * true：不支持穿透 * false：支持穿透 默认值为true。|
