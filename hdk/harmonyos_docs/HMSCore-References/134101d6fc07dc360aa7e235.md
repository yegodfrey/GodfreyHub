#### Sample Code

```
private void updateHistoryVersions(Drive drive, HistoryVersion historyVersion, File file){
    try{
        historyVersion.setKeepPermanent(!historyVersion.getKeepPermanent());
        drive.historyVersions().update(file.getId(), historyVersion.getId(), historyVersion).execute();
    } catch (Exception e){
        Log.e(TAG, "updateHistoryVersions error: " + e.toString());
    }
}
```
