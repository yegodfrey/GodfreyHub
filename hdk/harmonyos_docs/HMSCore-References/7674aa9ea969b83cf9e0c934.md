# 错误码

推送服务的错误码由[HMS Core SDK框架错误码](#section13768513403)与[HMS Core Push SDK错误码](#section15969337175715)两部分组成，如果您在本页面找不到您遇到的错误码，请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093)描述问题，相关技术支持人员会及时处理您的问题。

## HMS Core SDK框架错误码

|错误码|值|描述|解决方法|
|:----------------------------------------|:--------|:------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ErrorCode.ARGUMENTS_INVALID|907135000|传入的参数错误。|请检查相关的配置信息是否正确。例如："agconnect-services.json"文件中的app_id是否配置准确，"build.gradle"文件是否配置证书签名。|
|ErrorCode.INTERNAL_ERROR|907135001|内部错误，表示内部出现异常且无法恢复。|内部错误，一般情况下重试或进程重新启动可以恢复正确。|
|ErrorCode.NAMING_INVALID|907135002|服务接口查询错误，指定服务接口不存在或创建服务接口实例失败。|请检查服务接口是否不存在，以及创建服务接口是否失败。|
|ErrorCode.CLIENT_API_INVALID|907135003|ApiClient对象无效。|一般不会出现此问题。若返回该错误码，请重试，如果多次重试失败，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题。|
|ErrorCode.NOT_IN_SERVICE|907135005|当前区域不支持此业务。|请检查用户所在区域是否支持此接口。|
|ErrorCode.SESSION_INVALID|907135006|HMS Core SDK内部错误，AIDL连接session无效。|一般不会出现此问题。若返回该错误码，请重试，如果多次重试失败，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题。|
|ErrorCode.DENY_NETWORK|907135007|OOBE（Out-of-box experience，开箱体验）阶段未同意隐私声明，不能访问网络。|OOBE阶段同意隐私声明之后即可正常访问网络。|
|ErrorCode.CERT_FINGERPRINT_EMPTY|907135702|OpenGW没有配置指纹证书。|1. 请检查手机网络是否可以正常访问互联网。 2. 检查申请相关服务时是否配置了正确的证书指纹。登录AppGallery Connect，单击"我的项目"，选择需要操作的项目，进入项目页面后选择应用，然后在"项目设置 > 常规"中检查"SHA256证书指纹"配置的信息是否和根据签名文件生成指纹证书一致，如果不一致请修改。|
|ErrorCode.PERMISSION_LIST_EMPTY|907135703|OpenGW没有配置Permission。|请检查创建应用时是否启用相关功能，例如使用unionId作为用户表示，需要在创建应用时启用UnionId功能。|
|StatusCode.AUTH_INFO_NOT_EXIST|6002|应用的鉴权信息不存在。|请检查当前应用是否已创建并已申请相关服务。|
|StatusCode.PERMISSION_NOT_AUTHORIZED|6005|接口鉴权：未授权。|请检查当前应用是否已创建并已申请相关服务。|
|StatusCode.PERMISSION_EXPIRED|6006|接口鉴权：授权过期。|请检查当前应用是否已创建并已申请相关服务。|
|ErrorCode.FRAMEWORK_UPDATING|1200|框架正在升级中，AMS和PMS服务未准备好。|1. 检查框架升级是否完成，AMS和PMS服务是否准备就绪。 2. 再次发送请求。|
|ErrorCode.FRAMEWORK_NOT_READY|1201|AMS和PMS服务未准备好。|1. 检查AMS和PMS服务是否准备就绪。 2. 再次发送请求。|
|ErrorCode.PARAMETER_INVALID|1210|无效参数。|检查传入参数是否正确。|
|ErrorCode.SESSION_INVALID|1211|无效session。|检查调用方应用身份标识是否正确。|
|ErrorCode.KIT_NEED_UPDATE|1212|Kit需要升级。|1. 检查Kit升级是否完成。 2. 检查应用市场或者本地安装目录是否有高版本Kit。 3. 再次发送请求。|
|ERRORCODE.KIT_BREAKER|1213|Kit需要熔断。|熔断状态下，Kit调用失效，不可使用。|
|ERRORCODE.FRAMEWORK_BREAKER|1214|Framework需要熔断。|熔断状态下，framework调用失效，不可使用。|
|ERRORCODE.MEMORY_OVER_LIMIT|1215|内存超限。|1. 检查内存状态是否超限。 2. 释放内存后重试。|
|ERRORCODE.RUNTIME_AMS|1230|AMS运行时错误。|1. 请等待几秒重试。 2. 重启HMS Core。 3. 应用市场重装HMS Core。|
|ERRORCODE.RUNTIME_PMS|1240|PMS运行时错误。|1. 请等待几秒重试。 2. 重启HMS Core。 3. 应用市场重装HMS Core。|
|ERRORCODE.RUNTIME_KAC|1250|KAC运行时错误。|1. 请等待几秒重试。 2. 重启HMS Core。 3. 应用市场重装HMS Core。|
|ERRORCODE.RUNTIME_OTHER|1260|其他类型错误。|获取相关异常日志，通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题。|
|BaseCode.KPMS_UPDATE_FAILED|-10|KPMS升级Kit失败。|1. 检查网络是否正常。 2. 相关kit是否上架。 3.以上排查都正常时，仍然存在异常，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题。|
|ResolutionResult.INTERNAL_ERROR|8|内部错误。|尝试重试。|
|AvailableCode.CANCELED|13|用户取消下载、取消安装或者应用使用错误证书。|1. 下载HMS Core APK过程中请勿点击取消，等待下载完成。 2. 点击立即安装按钮。 3. 使用正确的hmsrootcas.bks证书，里面包含052root。|
|AvailableCode.APP_IS_BACKGROUND_OR_LOCKED|28|当前应用在后台或者处于锁屏状态，无法弹出升级页面。|使当前应用处于前台显示状态。|
|AvailableCode.HMS_IS_SPOOF|29|HMS Core被仿冒。|尝试卸载当前HMS Core应用，应用市场重新下载安装。|

## HMS Core Push SDK错误码

|错误码|现象描述|解决方法|
|:--------|:-----------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|6003|指纹证书配置不一致。|1. 确认证书指纹端云配置一致。客户端应用打包的证书和在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站上给应用配置的"SHA256证书指纹"一致，具体可参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmony-java-development-environment-0000001227370647)。 2. HMS Core（APK）会缓存签名文件，需在"应用管理"中找到HMS Core（APK）清理缓存数据，然后重新打开您的应用尝试之前的操作。|
|6004|接口鉴权时，权限不存在。|详情请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmony-java-development-environment-0000001227370647)，检查当前应用是否已经正常打开相关服务。 * 如果您还未申请，请完成开启。 * 如果您已经申请，建议将需要申请的服务行所在开关关闭并重新开启。 该配置项操作后需等待30分钟左右，同时手机客户端清除HMS Core的缓存后，重启手机测试。 清除HMS Core缓存的方法：依次点击"手机设置 > 应用 > 应用管理 > HMS Core"，进入后，点击存储，将数据和缓存均清除。|
|907122030|没有Token。|请检查调用[申请Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-push-ohos-hmsinstanceid-0000001199553039#section1427213359368)方法的入参是否正确。|
|907122031|当前网络不可用。|请检查网络连接情况。|
|907122032|Token失效。|请尝试[删除Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-push-ohos-hmsinstanceid-0000001199553039#section17745356143619)后重新[申请Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-push-ohos-hmsinstanceid-0000001199553039#section1427213359368)。|
|907122036|没有开通推送服务权益。|详情请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmony-java-development-environment-0000001227370647)，检查当前应用是否已经正常打开相关服务。|
|907122037|申请Token失败。|建议稍后重试，或联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093)解决。|
|907122038|应用未选择存储位置或者存储位置非法。|请为您的应用设置正确的数据处理位置，详情请参见[设置默认数据处理位置](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-datalocation-0000001160439813)。|
|907122041|消息体大小超过了允许的最大值（1KBytes）。|请检查您发送的消息体大小。|
|907122042|发送的消息中携带了无效参数。|请检查消息体的参数是否合法。|
|907122045|未知错误。|系统内部异常，您无法单独处理，请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093)。|
|907122047|Push通用错误码。|错误场景较多，请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093)具体定位。|
|907122048|HMS Core（APK）无法连接Push Kit。|请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093)。|

|907122051|设备证书认证失败。|请联系[技术支持](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/technical-support-0000001058590093)。|
