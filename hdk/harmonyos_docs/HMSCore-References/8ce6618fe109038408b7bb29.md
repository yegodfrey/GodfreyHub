# PurchaseResultInfo

* 支持的场景：手机、平板、智慧屏。
* 支持的OS：EMUI 3.0+、Android 4.4+。

|Class Info|
|:---------------------------------|
|class PurchaseResultInfo 包含支付结果信息。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------|
|String|[getErrMsg](#section1284382012116)() 获取返回码描述信息。|
|String|[getInAppDataSignature](#section21711535101118)() 返回使用IAP私钥签署购买数据生成的签名字符串。|
|String|[getInAppPurchaseData](#section17671828101114)() 返回购买商品的购买数据。|
|int|[getReturnCode](#section245101514116)() 获取返回码。|
|String|[getSignatureAlgorithm](#section1721042803811)() 返回签名算法。|

## Public Methods

### getErrMsg

|Method|
|:-----------------------------------|
|public String getErrMsg() 获取返回码描述信息。|

**Returns**

|Type|Description|
|:-----|:----------|
|String|返回码描述信息。|

### getInAppDataSignature

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getInAppDataSignature() 该方法返回使用IAP私钥签署购买数据（[getInAppPurchaseData](#section17671828101114)方法返回的字符串）生成的签名字符串。签名算法可以通过[getSignatureAlgorithm](#section1721042803811)方法获取。|

**Returns**

|Type|Description|
|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|使用IAP私钥签署购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)生成的签名字符串。 支付成功后应用请参见[对返回结果验签](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-signature-returned-result-0000001050033088)使用IAP公钥对[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)的JSON字符串进行验签。 公钥获取请参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/query-payment-info-0000001050166299)。|

### getInAppPurchaseData

|Method|

|public String getInAppPurchaseData() 获取购买数据的JSON字符串。|

**Returns**

|Type|Description|
|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------|

### getReturnCode

|Method|
|:-----------------------------------|
|public int getReturnCode() 获取结果的返回码。|

**Returns**

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------|
|int|返回码。 * 0：执行成功。 * 其他：支付失败，请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-error-code-0000001050746111)。|

### getSignatureAlgorithm

|Method|
|:--------------------------------------------|
|public String getSignatureAlgorithm() 返回签名算法。|

**Returns**

|Type|Description|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|签名算法。 调用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)接口时，若在[setSignatureAlgorithm](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842#section674512136510)方法中传入IAP支持的签名算法，该方法将返回您传入的签名算法。若未传入签名算法，该方法返回"SHA256WithRSA"或空值。 > 说明 > 传入签名算法的场景需要通过此方法返回的签名算法进行数据验签。未传入签名算法的场景可使用默认的SHA256WithRSA算法或该方法返回的算法进行数据验签。 > 可能存在该方法返回为空的情况，该情况默认使用SHA256WithRSA算法进行验签。|
