# 说明

|Name|Description|
|:--------|:----------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口。|
|HarmonyOS|基于JavaScript语言开发的独立HarmonyOS应用程序接口。|
|REST|提供支持HTTPS的云服务接口。|

#### Android API全场景支持一览表

Android API在手机、部分平板上可使用。  

#### HarmonyOS API全场景支持说明

HarmonyOS（JavaScript） API支持在手机、智能表WATCH 3/4系列上使用。
