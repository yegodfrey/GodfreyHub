# HmsOptions

|Interface Info|
|:------------------------------|
|HmsOptions 此接口提供了应用初始化的变量名称和类型。|

## Public Field Summary

|Type|Name and Description|
|:-----|:-------------------|
|string|apiKey Web应用签名。|
|string|projectId 项目ID。|
|string|clientId 应用ID。|
|string|countryCode 国家码。|

> 注意
>
> **apiKey** 、**projectId** 、**clientId** 和**countryCode** 均在[工程配置](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-dev-guides-0000001080547778#ZH-CN_TOPIC_0000001652651288__p134802018974)中自动生成，您可以直接拷贝至您的项目中。
