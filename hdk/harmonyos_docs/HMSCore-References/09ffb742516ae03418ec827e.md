# LatLng

|Class Info|
|:--------------------------------|
|public class LatLng 表示经纬度的类，单位：度。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-------------------------------|
|double|mLongitude 经度，取值范围：\[-180, 180)。|
|double|mLatitude 纬度，取值范围：\[-90, 90\]。|

#### Public Constructor Summary

|Constructor Name|
|:--------------------------------------------------------------------------------------------------------------------------------|
|[LatLng](#section114762417137)(double mLatitude, double mLongitude) 使用纬度和经度创建LatLng对象。如果传入的经纬度值不在范围之内，会打印错误日志进行提示，然后转换为接近的合理的经纬度。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------|
|boolean|equals(Object other) 判断两个LatLng对象是否相等。|
|double|[getLongitude](#section365865121019)() 获取经度。|
|double|[getLatitude](#section10758193075418)() 获取纬度。|
|int|hashCode() 返回该对象的哈希值。|
|String|toString() 返回该对象的字符串表示。|
