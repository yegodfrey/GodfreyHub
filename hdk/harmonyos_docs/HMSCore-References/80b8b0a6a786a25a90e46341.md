# CapabilityStatus

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Interface Info|
|:------------------------------------------------------------------------------------------------------------------|
|public interface CapabilityStatus 各能力支持状态接口类，可以从该接口调用getCapabilities方法获取Awareness在当前设备所支持的能力，其中定义了10个能力状态码，分别代表各能力。|
