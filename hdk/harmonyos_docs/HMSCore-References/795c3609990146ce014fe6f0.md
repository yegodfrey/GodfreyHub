# 申请分账回收

## 功能介绍

订单已经分账，可以调用此接口，将已分账的资金从分账接收方账户回退给收单方，再发起退款。
> 说明
>
> * 回收金额不能超过分账金额。
> * 目前该接口一次请求只能支持回收一笔分账，一笔分账单支持多次分账回收。
> * 此接口为异步处理模式，即接收到商户分账回收申请后，会先受理再异步处理，最终结果会异步给商户。
> * 分账订单退款和分账回收并无强耦合关系。是否需要分账回收，由商户决定。商户余额充足的情况下，可以不发起分账回收，直接发起退款。

## 使用约束

换单重试，视为新的业务订单，需开发者自行将新的业务订单关联业务原订单。接口重入规则说明如下（供参考）：

|重入判定字段|支持原单重入场景|建议换单重试场景|
|:----------------------------|:--------------------------------------------------------------------------------------------------|:------------------------------------------------|
|商户分账回收订单号（mercReclaimOrderNo）|1. 请求分账回收接口失败，建议根据错误码排查后，支持原商户分账回收订单号重入。 2. 请求分账回收接口成功，原商户分账回收订单号重入，接口幂等返回。该笔订单状态以异步结果通知或同步查询接口里为准。|分账回收订单状态RECLAIM_FAILED，则订单进入失败终态。如需重新分账回收，需要换单重试。|

## 接口原型

|承载协议|HTTPS POST|
|-----|-------------------------------------------------------------------------------|
|接口方向|开发者服务器-> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/allocation/reclaim/orders|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

* **Request Header**

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|


* **Request Body**

  |参数|是否必填|参数类型|描述|
  |:--------------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------|
  |mercReclaimOrderNo|是|String|商户分账回收订单号，**由商户自己生成，商户需保证订单信息唯一性**。建议采用。|
  |sysTransOrderNo|是|String|华为支付系统订单号。|
  |mercAllocationOrderNo|否|String|商户分账订单号。|
  |sysAllocationOrderNo|否|String|华为支付分账订单号， 和mercAllocOrderNo二选一。|
  |reclaimAllocDetails|是|List<[MercAllocRuleDetail](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section12263134923713)>|分账回收详情列表。 > 说明 > * 分账回收接口， 目前只支持一次只能回收一笔。reclaimAllocDetails的长度最大为1。 > * 回收金额不能大于分账金额。|
  |callbackUrl|是|String|回调通知地址。|
  |payload|否|String|商户预留信息。|

## 响应参数

* **Response Header**

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|


* **Response Body**

  |参数|是否必填|参数类型|描述|
  |:---------------------|:---|:-----|:----------------------|
  |resultCode|是|String|结果码，"000000"表示成功，其他表示失败|
  |resultDesc|是|String|结果描述|
  |subCode|否|String|业务错误码|
  |subDesc|否|String|业务错误描述信息|
  |sign|是|String|签名值|
  |sysReclaimAllocOrderNo|否|String|华为支付分账回收订单号|
