# BuoyClient

|Interface Info|
|:-------------------------------------------------|
|public interface BuoyClient BuoyClient类定义了浮标的相关接口。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------|
|void|[showFloatWindow](#section17952328272)() 展示浮标。|
|void|[hideFloatWindow](#section91343409278)() 隐藏浮标。|

#### Public Methods

#### showFloatWindow

|Method|
|:----------------------------------------------------------------|
|public void showFloatWindow() 在游戏界面中展示浮标。一般建议在游戏界面的onResume方法中调用。|

#### hideFloatWindow

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------|
|public void hideFloatWindow() 将游戏界面中浮标隐藏。一般建议在onPause中调用本接口隐藏游戏浮标。 同一个游戏界面必须已经调用[showFloatWindow](#section17952328272)接口显示浮标以后，才能调用本方法隐藏浮标。|
