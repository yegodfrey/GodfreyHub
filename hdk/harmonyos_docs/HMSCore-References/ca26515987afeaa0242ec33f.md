# LoginFreeAuthController

|Class Info|
|:----------------------------------------------|
|public class LoginFreeAuthController 提供免登录授权功能。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Intent|[requestLoginFreeAuthorizationIntent](#section14218260118) (String\[\] scopes, String state, String clientId, String deepLinkUrl, String signature) 获取集成华为账号授权，华为运动健康App应用授权和H5授权的Intent，可以通过startActivityForResult拉起授权流程页面。|
|Intent|[requestAuthorizationWithPrivacyIntent](#section46669234509) (String\[\] scopes, String state, String clientId, String deepLinkUrl, String signature) 获取集成华为运动健康APP授权的Intent，授权完成后引导用户打开上云开关，可以通过startActivityForResult拉起授权流程页面。|

#### Public Methods

#### requestLoginFreeAuthorizationIntent(String\[\] scopes, String state, String clientId, String deepLinkUrl, String signature)

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public Intent requestLoginFreeAuthorizationIntent(String\[\] scopes, String state, String clientId, String deepLinkUrl, String signature) 获取集成华为账号授权，华为运动健康APP授权，H5授权的Intent，可以通过startActivityForResult拉起授权流程页面。|

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|scopes|申请授权的Scope权限数组。|
|state|随机串，用于防CSRF，在返回授权码Code时原封不动返回。|
|clientId|注册应用时获得的App ID。|
|deepLinkUrl|授权后要回调的URI，即接收Authorization Code的URI。这个回调地址与[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud-free-auth-login-android-prep-0000002021742552)中配置的"应用scheme地址"一致。|
|signature|deepLink签名，申请Scheme地址时云端分配的secret，在完成"应用scheme地址"配置后，点击应用查看应用详情，"Scheme 信息 \> Scheme Secret"中的值即为签名。|

Returns  

|Type|Description|
|:-----|:----------------------------------------------------|
|Intent|启动免登录授权流程Activity的Intent，可通过startActivityForResult启动。|

免登录授权的示例代码如下：

```
"Java"
	
private static final String TAG = "HealthKitLoginFreeAuthActivity";
private static final int REQUEST_AUTH_LOGIN_FREE = 2000;

private void requestAuth(){
    // 添加需要申请的权限，这里只是举例说明，开发者需要根据实际情况添加所需的权限
    String[] scopes = new String[] {
        "https://www.huawei.com/healthkit/step.read",
        "https://www.huawei.com/healthkit/distance.read",
        "https://www.huawei.com/healthkit/heartrate.read"
    };
    // 获取注册应用时获得的App ID
    String appid = "xxx";
    // 开发者注册应用时应用的产品服务>账号>回调地址
    String deepLinkUrl = "xxx";
    // 根据 appid和应用注册回调链接的scheme secret
    String signature = "您应用的Scheme信息中的Scheme Secret";
    // 随机串，和授权码一起返回
    String state = "xxx";
    // 获取授权流程Intent
    Intent intent = HuaweiHiHealthLite.getSettingController(this).requestLoginFreeAuthorizationIntent(scopes, state, appid, deepLinkUrl, signature);
    // 打开授权流程页面
    Log.i(TAG, "start authorization activity");
    startActivityForResult(intent, REQUEST_AUTH_LOGIN_FREE);
}
```

```
        "https://www.huawei.com/healthkit/step.read",

    // 打开授权流程页面
    Log.i(TAG, "start authorization activity");

companion object {
    // 日志Tag
    private val TAG = "HealthKitLoginFreeAuthActivity";

    // 通过startActivityForResult方式拉起授权流程界面的请求码，具体数值开发者可以自行定义
    private val REQUEST_AUTH_LOGIN_FREE= 2000;
}
```
