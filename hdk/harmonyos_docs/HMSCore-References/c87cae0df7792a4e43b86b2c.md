# InstallReferrerStateListener

|Interface Info|
|:-----------------------------------------------------------------------------------------------------------------|
|public interface InstallReferrerStateListener 建立服务链接的回调接口；当与服务完成建立时，将调用此侦听器的onInstallReferrerSetupFinished(int)方法。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------|
|abstract void|[onInstallReferrerServiceDisconnected](#section519213505233)() 当服务断开连接时该方法被调用以通知监听者。|
|abstract void|[onInstallReferrerSetupFinished](#section2096212872413)(int responseCode) 当服务完成连接时该方法被调用以通知监听者。|

#### Public Methods

#### onInstallReferrerServiceDisconnected

|Method|
|:--------------------------------------------------------------------------------|
|public abstract void onInstallReferrerServiceDisconnected() 当服务断开连接时该方法被调用以通知监听者。|

#### onInstallReferrerSetupFinished

|Method|
|:------------------------------------------------------------------------------------------|
|public abstract void onInstallReferrerSetupFinished(int responseCode) 当服务完成连接时该方法被调用以通知监听者。|

Parameters  

|Name|Description|
|:-----------|:---------------------------------------------------------------|
|responseCode|连接响应状态： * -1：连接服务失败。 * 0：连接服务成功。 * 1：服务不存在。 * 2：服务不支持。 * 3：调用错误。|

Sample code：

```
InstallReferrerClient referrerClient;
...
referrerClient = InstallReferrerClient.newBuilder(this).setTest(true).build();
    /**
     * 创建一个监听器
     */
    private InstallReferrerStateListener installReferrerStateListener = new
            InstallReferrerStateListener() {
                @Override
                public void onInstallReferrerSetupFinished(int responseCode) {
                    switch (responseCode) {
                        case InstallReferrerClient.InstallReferrerResponse.OK:
                            // 连接服务
                            break;
                        case InstallReferrerClient.InstallReferrerResponse.FEATURE_NOT_SUPPORTED:
                            // 当前应用不支持API
                            break;
                        case InstallReferrerClient.InstallReferrerResponse.SERVICE_UNAVAILABLE:
                            // 无法建立连接
                            break;
                    }
                }
                @Override
                public void onInstallReferrerServiceDisconnected() {
                    // 尝试重新启动调用startConnection()方法
                }
            };
```
