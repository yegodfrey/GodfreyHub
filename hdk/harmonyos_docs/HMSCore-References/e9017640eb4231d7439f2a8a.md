# 公共说明

## 接口鉴权方式

* 变现报表服务采用共享API密钥的方式为您开放服务端接口。
* 请求参数和返回数据统一采用UTF-8编码。
* 请求URL中的参数值进行URL编码。
* 您的服务器端在调用接口时，统一的消息头格式请参见[Request Header](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/query-publisher-service-reports-0000001050933546#ZH-CN_TOPIC_0000001057125200__p1090711452376)。
