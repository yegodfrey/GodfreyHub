# LinkDevicePass

|参数|是否必选|参数类型|描述|
|:-------------|:---|:-----|:--------------------------------------------------|
|​webServiceURL|是|String|开发者提供的NFC接口地址。|
|token|是|String|从开发者服务器获取DevicePass卡券包时使用的token。|
|serialNumber|是|String|开发者定义的NFC卡券唯一标识。|
|passVersion|否|String|DevicePass卡券包版本|
|spPublickey|是|String|开发者在AGC网站提供的公钥。NFC卡片信息不会上传到钱包服务器，所以终端设备需要这个参数来进行验签。|
|nfcType|是|String|固定值"1"，表示开启NFC能力。如果这个值不是"1"，当前个人化实例的NFC能力会被关闭。|

> 说明
>
> 这里的NFC serialNumber建议与卡券实例的serialNumber使用不同的值，开发者服务器需将这两个serialNumber绑定。这里的passVersion与卡券实例的passVersion没有关联。更详细的说明请查看[商户服务器实现NFC刷卡能力](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-overa-nfc-0000001050042374)。
