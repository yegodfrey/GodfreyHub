# 血压数据格式

![](https://media:801784947930232878)  
以下数据格式只适用于saveHeathData和saveMultipleHealthData接口。

BloodPressure (type: 10002, dataTypeName: com.huawei.instantaneous.blood_pressure)  

|字段Key|数据类型|描述|可选字段|
|:--------|:-----|:-----------------|:---|
|diastolic|double|舒张压 毫米汞柱\[10,500\]|M|
|systolic|double|收缩压 毫米汞柱\[10,500\]|M|
|pulse|double|脉搏 次/每分钟\[1,200\]|O|
