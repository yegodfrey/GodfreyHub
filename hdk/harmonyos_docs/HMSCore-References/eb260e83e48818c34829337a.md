# BatchCallback

## 功能介绍

批处理接口。

## 场景描述

BatchCallback接口实现批处理调用接口。

## 使用约束

* 严格按照http协议的multipart格式进行接口调用。
* 不能使用批量接口调用文件上传和文件下载等接口。

## 接口原型

|承载协议|HTTP POST|
|-----|----------------------------------------------------|
|接口方向|开发者服务器->华为云空间服务器|
|接口URL|https://driveapis.cloud.huawei.com.cn/batch/drive/v3|
|数据格式|请求消息：Content-Type: multipart/mixed;boundry=XXX|

## 请求参数

固定格式为

```screen
--XXX
请求1总Headers

请求1
headers1

body1（非必填）
--XXX
请求2总Headers

请求2
headers2

body2（非必填）
--XXX--
```

## 常见错误码

**错误码后4位为业务错误码，用于区分错误场景，其他业务错误码见[状态码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/status-code-0000001050992633)章节**。

|状态码|错误码|响应代码|描述|
|:--|:--|:----------------------|:-------------|
|200|NA|-|成功。|
|400|NA|PARAM_VALUE_NOT_SUPPORT|参数不支持，请检查参数列表。|
|404|NA|SERVICE_NOT_FOUND|服务器无法响应。|
|500|NA|SERVER_TEMP_ERROR|服务器内部错误。|
|503|NA|SERVICE_UNAVAILABLE|服务不可达。|
|504|NA|REQUEST_TIMEOUT|请求超时。|
