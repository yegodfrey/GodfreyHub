#### Public Constructors

#### ScaleAnimation

|Constructor|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public ScaleAnimation(float fromX, float toX, float fromY, float toY) 使用起始坐标缩放比例与目的坐标缩放比例创建ScaleAnimation对象。0表示收缩到没有，1表示正常无伸缩，值小于1表示收缩，值大于1表示放大。图标放大的最大尺寸为（width:1080，height:1080），单位：像素。|

Parameters  

|Name|Description|
|:----|:---------------|
|fromX|指动画开始时应用的水平缩放倍数。|
|toX|指动画结束时应用的水平缩放倍数。|
|fromY|指动画开始时应用的垂直缩放倍数。|
|toY|指动画结束时应用的垂直缩放倍数。|
