# HWDistanceCalculator

## 概述

根据经纬度计算两点之间的直线距离。

## 构造函数

|函数|描述|
|:--------------------------------|:-|
|HWMapJsSDK.HWDistanceCalculator()|-|

## 方法

|**方法**|**描述**|**参数类型**|**返回值**|
|:----------------------------------------------------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------|
|computeDistanceBetween(fromPostion, toPosition, opt_radius)|计算两点之间的直线距离。|* fromPostion：[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)，一个点的经纬度。 * toPosition：[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)，另一个点的经纬度。 * opt_radius：Number，球体半径，可选参数，默认为6378137.0米。|两点之间的直线距离，单位：米。|
