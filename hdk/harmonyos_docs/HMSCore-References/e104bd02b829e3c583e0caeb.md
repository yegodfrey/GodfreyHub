# 审核结果回调

## 功能介绍

商户完成[添加分账白名单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-receivers-add-0000001639876341)、[子商户入网](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-register-submerc-0000001642382965)、[冻结子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-freeze-submerc-0000001593101828)、[解冻子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-ufreeze-submerc-0000001592624240)、[注销子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-delete-submerc-0000001592782432)等申请成功后，华为支付服务器调用此接口向开发者服务器发送申请审核的关键事件通知。

> 说明
>
> 为保证回调请求的可靠性，系统具备重试机制，所以可能出现重发的通知。

## 接口原型

|承载协议|HTTPS POST|
|-----|-----------------------------------------------------------------------|
|接口方向|华为支付服务器 -> 开发者服务器|
|接口URL|URL由开发者在请求接口时传的callbackUrl|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

* **Request Body**

  |参数|是否必填|参数类型|描述|
  |:-----------|:---|:-----|:--------------------------------------------------------------|
  |callbackId|是|String|回调通知的唯一ID。|
  |callbackTime|是|String|回调通知时间|
  |dataType|是|String|数据加密类型标识。 * encrypt：加密 * plain：未加密|
  |sign|是|String|回调通知结果签名，除"sign"字段以外的其他字段参与签名|
  |signType|是|String|签名类型。华为支付生成签名字符串使用的算法，当前为SM2算法。|
  |certNo|否|String|签名所使用的证书编号。|
  |subMercNo|是|String|特约商户号或平台子商户号。|
  |flowId|是|String|审批流程Id。|
  |auditStatus|是|String|审批状态。 * AUDIT_CANCEL：审核撤销 * AUDIT_PASS：审核通过 * AUDIT_REFUSE：审核拒绝|
  |auditDesc|否|String|审批结果信息。|
  |auditTime|否|String|审批时间（yyyy-MM-dd HH:mm:ss）。|


* **请求示例**

  ```screen
  POST /opengw/merc/v1/transactions/result HTTP/1.1
  Content-Type: application/json;charset=UTF-8
  {
    "callbackId": "548eee94b1ac43028eaed234d29f215s",
    "callbackTime": "2023-06-23 09:29:14"
    "dataType": "plain",
    "auditStatus": "AUDIT_PASS",
    "finishTime": "2023-06-23T09:28:44.000+0800",
    "certNo": "10132120***",
    "subMercNo": "101320000***",
    "flowId": "20230726104038800xxx",
    "signType": "SM2",
    "sign": "MEUCIQDoLjokddqBkcfJSmANgxo7Fi0M********************XJ31ABMx85CxH7I65M45YE6G0oTKcftPn1YsiYcmU=",
    "auditDesc": "审核通过",
    "auditTime": "2023-06-23 09:22:30"
  }
  ```

## 响应参数

* **Response Header**

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|


* **Response Body**

  |参数|是否必选|参数类型|描述|
  |:---------|:---|:-----|:-----------------------------------------------------------------------|
  |resultCode|是|String|华为支付侧解析application/json类型响应，"000000"表示成功，其他值失败，如返回值格式不匹配或非"000000"将视为失败。|
  |resultDesc|是|String|结果描述。|


* **响应示例**

  ```screen
  HTTP/1.1 200 OK
  Content-Type: application/json; charset=UTF-8
  {
    "resultCode": "000000",
    "resultDesc": "Success."
  }
  ```
