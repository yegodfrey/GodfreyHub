# getUserInfo：获取当前用户的个人信息

**接口原型**

public void getUserInfo(String function)

方法描述：获取当前用户的个人信息。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-----------------------------------|:---|
|function|String|运动健康返回查询结果的回调函数，该回调函数有一个参数，详情参见响应参数。|M|
[**表1**请求参数]

请求示例：

```screen
getUserInfo: function (){
    this.log.info("getUserInfo!");
    window.getUserInfoCallback = this.getUserInfoCallback;
    window.hilink.getUserInfo("getUserInfoCallback");
}
```

**响应参数**

回调返回resultCode和JSON对象说明：

|参数名称|参数类型|参数描述|可选选项|
|:---------|:-----|:--------------------------------------------------------------------------------------------------------------------|:---|
|resultCode|String|处理结果码： 0：成功，其他失败，参见[错误码清单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/errcode-0000001058135271)。|M|
|data|String|运动健康用户信息数据集。主要包含用户ID，单位种类（英制单位或公制单位，默认为公制单位，0表示公制单位），身高，体重，性别，年龄。详情可参考下方响应示例。|M|
[**表2**响应参数]

响应示例：

```screen
{
    "resultCode": 0,
    "data": {
        "id": xxx,
        "unitType": 0,
        "height": 170,
        "weight": 65,
        "gender": 1,
        "age": 25,
        "modifyTime": 1487726051000
    }
}
```
