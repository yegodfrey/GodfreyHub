# HealthRecordDeleteOptions

|Class Info|
|:------------------------------------------------------------------------------|
|public class HealthRecordDeleteOptions 删除健康记录的参数类，用于删除Health Service Kit中的健康记录。|

构造HealthRecordDeleteOptions的示例代码如下：

```
"Java"
// 请注意以下代码中的subDataTypeList、startTime、endTime、mHealthRecordIds、mDataType请参考删除健康记录中的相关代码
HealthRecordDeleteOptions deleteRequest = new HealthRecordDeleteOptions.Builder()
    .setHealthRecordIds(mHealthRecordIds)
    .isDeleteSubData(true)
    .setDataType(mDataType)
    .setSubDataTypeList(subDataTypeList)
    .setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
    .build();
```

