# 上报用户行为

#### 功能介绍

应用服务端调用此接口后，能够上报用户行为事件，用于创建受众群组。  

#### 场景描述

当您的应用服务器自行收集了一些用户行为，而不是在App端侧直接上报的用户行为，同时您又希望将这些用户行为应用到高级分析提供的各种分析报告中，您可以在其应用服务器调用此接口，通过服务端上报其自行收集的用户行为。通过此接口上报的用户行为不能脱离分析服务SDK上报而独立存在，只是分析服务SDK上报的补充。  

#### 使用约束

* 每次请求中，event_set可以最多携带100个用户行为。
* 每秒请求数不超过100。
* 需集成分析服务SDK。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者回调接口服务器-\>分析服务服务器|
|接口URL|{rootUrl}/analytics/datacollection/import/event 说明： {rootUrl}：请参见[接口访问路径获取](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-common-interface-description-0000001050707180#section777183816123)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-product-id|是|String|用户在AppGallery Connect上的Product ID。|
|x-app-id|是|String|用户在AppGallery Connect上的App ID。|
|Authorization|是|String|鉴权信息。请参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|

Request Body  

|参数|是否必选|参数类型|描述|
|:---------------|:---|:------|:---------------------------------|
|data_type|是|Integer|数据类型，标记是否为用户行为。 固定填写为3。|
|protocol_version|是|String|协议版本号。 固定填写为1。|
|productid|是|String|用户在AppGallery Connect上的Product ID。|
|appid|是|String|用户在AppGallery Connect上的App ID。|
|package_name|是|String|开发者的应用包名。 如果为Web应用则填写为appid。|
|requestid|是|String|上报数据时随机生成的一段32个字符的16进制随机码，每次请求生成。|
|timestamp|是|Long|事件上报的时间，1970年到现在的毫秒数。|
|event_set|是|json|事件信息。|

event_set数据结构说明  

|参数|是否必选|参数类型|描述|
|:------------------|:---|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|aaid|是|String|匿名用户标识，通过HMS Core端侧getAAID接口获取。 * Android：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section124931637174316) * HarmonyOS（Java）：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477#section124931637174316) * HarmonyOS（JavaScript）：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section124931637174316) * iOS：[AAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-analytics-0000001050164675#section10770121143112) * macOS：[AAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/macos-api-analytics-0000001241100765#section10770121143112) * Web：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-analytics-0000001050825689#section993793015410) * 快应用：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-analytics-0000001077322170#section993793015410) * 快游戏：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickgame-api-analytics-0000001238739841#section993793015410) * 微信小程序：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/miniprogram-api-wxanalytics-0000001198293007#section993793015410)|
|userid|否|String|用户ID。|
|oaid|否|String|开放广告标识符（Open Advertising ID），若是iOS终端，则取IDFA的值；若是Android终端，则优先取OAID的值，如果获取不到则取GAID的值。|
|oaid_source|否|String|OAID的来源，枚举值： * oaid * gaid * idfa|
|_oaid_tracking_flag|否|boolean|是否允许广告跟踪。如果允许跟踪（即没有打开"限制广告跟踪"开关），则为true；如果不允许跟踪（即打开了"限制广告跟踪"开关），则为false。|
|eventid|是|String|事件ID。|
|eventtime|是|Long|事件发生时间，1970年到现在的毫秒数。|
|event_session_name|是|String|事件session标识。|
|first_session_event|否|String|事件session是否刷新。|
|properties|否|Json|事件参数。|

#### 响应参数

状态码为200时：

Response Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:---------------|:---------|
|Content-Type|是|application/json|响应消息的数据格式。|

Response Body  

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:----------------------------------|
|result_code|是|String|响应码，请参见[错误码](#section477443017812)。|
|result_msg|是|String|响应描述。|

#### 响应示例

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=UTF-8
Connection:  Close
Content-Length: xxxx
 
{          
  "result_code":"0",
  "result_msg":"success"
}
```

#### 错误码

|状态码|错误码|描述|解决方法|
|:--|:----|:---------------------------------|:-----------|
|200|0|请求成功。|-|
|400|10020|非法参数。|请修改填写错误的参数值。|
|400|19910|* 鉴权请求超时，请稍后重试。 * 鉴权服务器内部错误，请稍后重试。|请稍后重试。|
