# 错误码

如果本页面中您没有查找到对应的错误码值，请到[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)页面中搜索。

## 业务错误码

|错误码|值|描述|解决方法|
|:-----------------------------------------------|:----|:------------------------|:--------------------------------------------------------------------------------|
|PayStatusCodes.PAY_STATE_SUCCESS|0|支付成功。|-|
|PayStatusCodes.PAY_STATE_CANCEL|30000|用户取消支付。|-|
|PayStatusCodes.PAY_STATE_NET_ERROR|30005|网络连接异常。|请检查设备网络连接。|
|PayStatusCodes.PAY_STATE_TIME_OUT|30002|支付结果查询超时。|请稍后在设备的"设置 > 华为帐号 > 付款与账单 > 账单"中查询支付结果。若仍未获取支付结果，请联系华为支持人员。|
|PayStatusCodes.PAY_STATE_PARAM_ERROR|30001|参数错误（包含无参）。|请检查参数是否正确。|
|PayStatusCodes.PAY_STATE_ERROR|30099|返回给客户端时放入JSON数据错误，支付结果未知。|请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，联系华为支持人员。|
|PayStatusCodes.PAY_OTHER_ERROR|30006|其他异常错误。|请重试或华为技术支持解决。|
|PayStatusCodes.PAY_STATE_FAILED|-1|通用支付失败错误码。|若购买请求返回该错误码，请确认用户是否购买了商品。|
|PayStatusCodes.HWPAY_COUNTRY_CODE_ERROR|30011|支付服务不可用，请切换华为帐号服务地。|帐号服务地与商户传递的国家/地区码不一致导致无法使用支付服务，需要切换帐号服务地。|
|PayStatusCodes.ORDER_STATUS_HANDLING|30012|查询订单结果状态：订单处理中。|请稍后再查询订单。|
|PayStatusCodes.ORDER_STATUS_UNTREATED|30013|查询订单结果状态：订单还未处理。|请稍后再查询订单。|
|PayStatusCodes.PAY_GAME_ACCOUNT_ERROR|30101|华为帐号不一致。|请检查进入应用后是否切换过华为帐号。 若使用华为帐号登录应用，请退出应用重新登录；若使用非华为帐号登录应用，建议清除HMS Core（APK）缓存后重试。|
|PayStatusCodes.PAY_GAME_ACCOUNT_ERROR|30102|游戏实名认证失败。|请完成帐号实名认证。|
|PayStatusCodes.PRODUCT_NOT_EXIST|40001|商品ID在对应商户查询的应用中不存在。|请输入正确的商品ID。|
|PayStatusCodes.PRODUCT_AUTHENTICATION_FAILED|40002|商品授权失败。|请重新进行商品授权。|
|PayStatusCodes.PRODUCT_SERVER_INTERNAL_EXCEPTION|40003|商品服务器内部异常。|请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，联系华为支持人员。|
|PayStatusCodes.PRODUCT_SOME_NOT_EXIST|40004|商品ID在对应商户查询的应用中部分不存在。|请输入正确的商品ID。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
