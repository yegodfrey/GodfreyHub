#### Public Methods

#### getCurrency

|Method|
|:-----------------------------------|
|public String getCurrency() 获取商品的币种。|

Returns  

|Type|Description|
|:-----|:-------------------------------------------------------------------------------------------|
|String|用于支付该商品的币种，必须符合[ISO 4217](https://www.iso.org/iso-4217-currency-codes.html)标准，例如USD、CNY、MYR。|

#### getMicrosPrice

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public long getMicrosPrice() 获取商品微单位价格。 说明： 当查询为非订阅型商品时，若[设置促销价格](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-modify-product-0000001146814541#section1658714562570)，该方法将返回商品微单位促销价格，未设置促销价格时则返回商品微单位原价。 当查询为订阅型商品，该方法将返回商品微单位原价。|

Returns  

|Type|Description|
|:---|:------------------------------------------------------------------------------|
|long|商品实际价格乘以1,000,000后的微单位价格。例如某个商品实际价格是1.99美元，则该商品对应的微单位价格为：1.99\*1000000=1990000。|

#### getOfferUsedStatus

|Method|
|:------------------------------------------------------------------------------------|
|public int getOfferUsedStatus() 可获取用户是否享受过订阅型商品所在订阅组促销的信息。 说明： 当查询为非订阅型商品时，该方法固定返回-1。|

Returns  

|Type|Description|
|:---|:------------------------------------------------------|
|int|用户是否享受过订阅型商品所在订阅组的促销，取值如下： * 0：未享受过 * 1：已享受 * -1：未获取到状态|

#### getOriginalLocalPrice

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getOriginalLocalPrice() 获取商品的原价。 说明： 当查询为非订阅型商品时，若[设置促销价格](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-modify-product-0000001146814541#section1658714562570)，促销价需通过[getPrice](#section332511271309)方法获取，若未设置促销价格，则该方法返回与[getPrice](#section332511271309)方法一致。 当查询为订阅型商品时，该方法返回为null，您无需关注此方法。|

Returns  

|Type|Description|
|:-----|:-----------------------------------------------------------------------------------|
|String|商品的原价，包含商品币种和价格，格式为"币种+商品价格"，例如 EUR0.15。部分国家/地区会返回"货币符号+商品价格"，例如中国大陆返回"￥0.15"。此价格含税。|

#### getOriginalMicroPrice

|Method|

Returns  

|Type|Description|
|:---|:--------------------------------------------------------------------------|
|long|商品原价乘以1,000,000后的微单位价格。例如某个商品原价是1.99美元，则该商品对应的微单位价格为：1.99\*1000000=1990000。|
