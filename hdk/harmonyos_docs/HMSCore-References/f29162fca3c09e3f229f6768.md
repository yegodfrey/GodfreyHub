# 获取用户标识

## 功能介绍

* 调用该接口，对已经获得的Access Token进行鉴权。
* 传入Access Token到华为服务器上获取用户的unionId、openId、playerId、expire等信息。

## 使用限制

当前接口仅支持Android游戏调用，不支持HarmonyOS游戏调用。

## 场景描述

应用已经获取到Access Token，要对其进行解析鉴权，通过Access Token到华为服务器上获取用户的unionId、openId、expire等信息。

## 接口原型

|承载协议|HTTPS POST|
|-----|----------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为游戏服务器|
|接口URL|https://jos-open-api.cloud.huawei.com/gameservice/api/gbClientApi > 注意 > * 此接口当前不支持SSL双向认证，在发送HTTPS请求时需要先关闭SSL认证。 > * 请使用TLS 1.2协议或以上版本。|
|数据格式|请求：Content-Type: application/x-www-form-urlencoded（表单方式） 响应：Content-Type: application/json|

## 请求参数

|参数|是否必选|参数类型|描述|
|:----------|:---|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|method|是|String|固定传入"external.hms.gs.getTokenInfo"。|
|accessToken|是|String|取自[通过AuthorizationCode获取Access Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526#section163812617171)中获取到的Access Token。 > 说明 > 该参数需经过UrlEncode处理后，再添加进请求消息中。|
|reqPlayerId|否|Integer|是否需要获取playerId。 * 0：不获取，不传值时默认为0 * 1：获取 > 注意 > 仅当进行playerId替换为openId时需要获取playerId，新游戏接入时不需要获取。|

## 请求示例

```screen
POST /gameservice/api/gbClientApi HTTP/1.1
Content-Type: application/x-www-form-urlencoded
User-Agent: PostmanRuntime/7.24.0
Accept: */*
Host: jos-open-api.cloud.huawei.com
Accept-Encoding: gzip, deflate, br
Connection: keep-alive
Content-Length: 717
method=external.hms.gs.getTokenInfo&accessToken=******&reqPlayerId=1
```

## 响应参数

|参数|是否必选|参数类型|描述|
|:-------|:---|:-----|:-------------------------------------------------------------------------|
|rtnCode|是|int|服务端结果说明： * 0：成功 * -1：accessToken获取失败 * -2：playerId获取失败 * 2：accessToken鉴权失败|
|unionId|否|String|玩家的unionId。|
|openId|否|String|玩家的openId。|
|expire|否|int|accessToken的剩余过期时间，单位：秒。|
|clientId|否|String|应用的AppID。|
|playerId|否|String|玩家的playerId。|

## 调用示例

### Java

```screen
package okhttp.com.post;
import com.alibaba.fastjson.JSONObject;
import okhttp3.*;
import java.io.IOException;
public class GetTokenInfoTest {
    private static Integer RETURN_CODE_SUCCEED = 0;
    /**
     * 接口本地调测使用
     */
    public static void main(String[] args) {
        String method = "external.hms.gs.getTokenInfo"; // 固定传入
        String accessToken= "xxxx"; // 通过AuthorizationCode获取的AccessToken 
        Integer reqPlayerId = new Integer(0); // 是否需要获取playerId,0表示不获取，1表示获取
        getTokenInfoService(method, accessToken, reqPlayerId);
    }
    /**
     * 根据AccessToken获取玩家信息
     *
     * @param method 固定传入"external.hms.gs.getTokenInfo"
     * @param accessToken 客户端Player对象中的AccessToken
     * @param reqPlayerId 是否需要获取playerId，0表示不获取，1表示获取
     */
    private static void getTokenInfoService(String method, String accessToken, Integer reqPlayerId) {
        OkHttpClient client = new OkHttpClient().newBuilder().build();
        RequestBody mFormBody = new FormBody.Builder().add("method", method)
            .add("accessToken", accessToken)
            .add("reqPlayerId", String.valueOf(reqPlayerId))
            .build();
        Request request = new Request.Builder().url("https://jos-open-api.cloud.huawei.com/gameservice/api/gbClientApi")
            .post(mFormBody)
            .build();
        try {
            Response response = client.newCall(request).execute();
            if (response.isSuccessful()) {
                JSONObject object = JSONObject.parseObject(response.body().string());
                if (RETURN_CODE_SUCCEED.equals(object.get("rtnCode"))) {
                    System.out.println("openId: " + object.get("openId"));
                    System.out.println("unionId: " + object.get("unionId"));
                    System.out.println("clientId: " + object.get("clientId"));
                } else {
                    System.out.println("rtnCode: " + object.get("rtnCode"));
                    System.out.println("rtnMsg: " + object.get("errMsg"));
                }
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

            postStream.Close();
