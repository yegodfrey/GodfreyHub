# registerRequestMtu：订阅设置手机与蓝牙设备传输mtu值的方法

**接口原型**

public void registerRequestMtu(String function)

方法描述：订阅设置手机与蓝牙设备传输mtu值的方法，当订阅成功时，调用本接口通知上层。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:----------------------------------|:---|
|function|String|获取手机蓝牙模块状态回调函数名，该回调函数有两个参数，详情参看响应参数|M|
[**表1**请求参数]

**响应参数**

|参数名称|参数类型|参数描述|可选选项|
|:-----|:-----|:-------------------------|:---|
|status|Number|0,成功；非0，失败|M|
|mtu|Number|默认为设置值，超过手机与设备传输的最大值则返回最大值|M|
[**表2**响应参数]
