# SettingsClient

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class SettingsClient 位置相关设置检查类，在调用[LocationServices](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationservice-0000001050746175)类的[getSettingsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationservice-0000001050746175#section395012913594)(Context context)或[getSettingsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationservice-0000001050746175#section96644536583)(Activity activity)方法时会返回一个该类型的实例。|

检查位置设置各开关的状态，示例代码如下：

```
"Java"
SettingsClient settingsClient = LocationServices.getSettingsClient(this);
LocationRequest locationRequest = new LocationRequest();
LocationSettingsRequest.Builder builder =
    new LocationSettingsRequest.Builder().addLocationRequest(locationRequest)
        .setAlwaysShow(false)
        .setNeedBle(false);
settingsClient.checkLocationSettings(builder.build())
    .addOnCompleteListener(new OnCompleteListener<LocationSettingsResponse>() {
        @Override
        public void onComplete(Task<LocationSettingsResponse> task) {
            if (task != null && task.isSuccessful()) {
                LocationSettingsResponse response = task.getResult();
                if (response == null) {
                    return;
                }
                LocationSettingsStates locationSettingsStates = response.getLocationSettingsStates();
                // TODO：接口调用成功的结果处理
            }
        }
    })
    .addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            Log.i(TAG, "checkLocationSettings onFailure:" + e.getMessage());
        }
    });
```
