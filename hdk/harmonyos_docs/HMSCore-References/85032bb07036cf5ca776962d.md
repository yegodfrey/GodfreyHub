# HMSPAYMENT

华为支付服务 JS SDK 为快应用提供便捷的支付体验和简便的接入流程。开发者的快应用通过集成华为支付服务 JS SDK，再调用华为支付服务 JS SDK接口启动华为支付收银台，即可实现应用支付能力。

## 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:---|:--------------------|:--------------|
|华为手机|HarmonyOS 2.0及以上|6.11.0.300及以上|
|华为手机|EMUI3.0或Android4.4及以上|6.11.0.300及以上|

## 导入模块

```screen
import HMSPAYMENT from '@hw-hmscore/hms-payment';
```

## HMSPAYMENT.pay

pay(orderStr: any, appId: any): Promise<any>

调起收银台接口，开发者的服务器在[预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-quick-app-pre-pay-order-0000001538696096)接口返回成功后组**orderStr**返回给端侧入参pay接口调起收银台。

* 参数：

  |参数名|类型|必填|说明|
  |:-------|:--|:-|:---------------|
  |orderStr|any|是|订单信息，接口入参。详情见下表。|
  |appId|any|是|应用ID，接口入参。|

* orderStr参数说明

  |**参数**|**参数类型**|**是否必填**|**描述**|
  |:--------|:-------|:-------|:---------------------------------------------------------------|
  |app_id|String|是|应用ID。|
  |merc_no|String|是|商户号。|
  |prepay_id|String|是|预下单id，使用预下单请求生成，有效期2小时。|
  |timestamp|String|是|时间戳，标准北京时间，时区为东八区，自1970年1月1日 0点0分0秒以来的毫秒数，13位。示例值：1666230721315。|
  |noncestr|String|是|随机字符串，不长于32位。推荐随机数生成算法。|
  |sign|String|是|签名，使用除了sign字段以外的其他字段计算签名值。用于开发者对响应报文进行防篡改验证。|
  |auth_id|String|是|开放平台分配的鉴权id，一个商户可配置多套证书，请妥善保管。|

* 返回值：

  |类型|说明|
  |:-----------|:------------|
  |Promise<any>|接口请求后返回的详细信息。|

  > 注意
  > 1. hms core最低版本要求，低于6.7.0.300，将无法拉起。
  > 2. hms core低于6.11.0.332版本，拉起时将引导更新，再拉起收银台。
  > 3. appId必填。
  > 4. orderStr注意是json格式的String的字符串，不要传json对象，也不要stringfy。
  > 5. 应用调用接口需做防重放处理，防止重复下单。
* 示例：

  ```screen
  const orderStr = "{\"app_id\":\"***\",\"merc_no\":\"***\",\"prepay_id\":\"1230331185102089244382635044\",\"timestamp\":\"1680259863114\",\"noncestr\":\"1487b8a60ed9f9ecc0ba759fbec23f4f\",\"sign\":\"****\",\"auth_id\":\"***\"}"
  HMSPAYMENT.pay(orderStr, appId).then(res => {
       // 此处处理支付结果，页面刷新或跳转等操作，res请参考下面Response
  }).catch(err => {
      console.error("paymentService err: "+ JSON.stringify(err));
  })
  ```

  **Response:**

  ```screen
  {
    "errCode": 0,
    "errMsg": "{\"PayResult\":\"{\\\"returnCode\\\":\\\"0\\\",\\\"returnMsg\\\":\\\"pay success\\\"}\"}"
  }
  ```

## HMSPAYMENT.signContract

signContract(contractStr: any, appId: any): Promise<any>

调起签约界面接口，开发者的服务器在[预签约](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-quickapp-presign-0000001631578996)接口返回成功后组**contractStr**返回给端侧入参signContract接口调起签约界面。

* 参数：

  |参数名|类型|必填|说明|
  |:----------|:--|:-|:-----------------|
  |contractStr|any|是|预签约号信息，接口入参。详情见下表。|
  |appId|any|是|应用ID，接口入参。|

* contractStr参数说明

  |**参数**|**参数类型**|**是否必填**|**描述**|
  |:--------|:-------|:-------|:---------------------|
  |appId|String|是|应用ID。|
  |preSignNo|String|是|预签约号，使用预签约请求生成，有效期2小时。|

* 返回值：

  |类型|说明|
  |:-----------|:------------|
  |Promise<any>|接口请求后返回的详细信息。|

  > 注意
  >
  > 1. hms core最低版本要求，低于6.7.0.300，将无法拉起。
  >
  > 2. hms core低于6.11.0.332版本，拉起时将引导更新，再拉起收银台。
  >
  > 3. appId必填。
  >
  > 4. contractStr注意是json格式的String的字符串，不要传json对象，也不要stringfy。
* 示例：

  ```screen
  const contractStr = "{\"preSignNo\":\"***\",\"preSignNo\":\"1230331185102089244382635044\"}";
  const appId = "***";
  HMSPAYMENT.signContract(contractStr, appId).then(res => {
      // 此处处理签约结果，页面刷新或跳转等操作，res请参考下面Response
  }).catch(err => {
      console.error("paymentService err: "+ JSON.stringify(err));
  })
  ```

  **Response:**

  ```screen
  {
    "errCode": 0,
    "errMsg": "{\"ContractResult\":\"{\\\"openId\\\":\\\"****\\\",\\\"returnCode\\\":\\\"0\\\",\\\"returnMsg\\\":\\\"success\\\",\\\"signNo\\\":\\\"****\\\"}\"}"
  }
  ```
