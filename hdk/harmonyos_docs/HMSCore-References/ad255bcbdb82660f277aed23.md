# HWBezierCurve

#### 概述

在图层上添加贝塞尔曲线 。  

#### 构造函数

|函数|描述|
|:-------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HWMapJsSDK.HWBezierCurve(bezierCurveOptions)|bezierCurveOptions：设置[HWBezierCurve](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwbeziercurve-0000002007429292)的属性，详情见[BezierCurveOptions](#section673933118442)。|

#### 方法

|方法|描述|参数类型|返回值|
|:--------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
|getMap()|获取绑定的地图实例。|-|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|
|getStrokeColor()|获取边框颜色。|-|String|
|getStrokeLineDash()|获取贝塞尔曲线的虚线类型。|-|Array\<Number\>|
|getStrokeWeight()|获取边框宽度。|-|Number|
|getVisible()|获取可见性。|-|Boolean|
|getZIndex()|获取[HWBezierCurve](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwbeziercurve-0000002007429292)的z-index属性。|-|Number|
|setMap(map)|绑定到地图。|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|-|
|setStrokeColor(strokeColor)|设置边框颜色。 支持以下几种颜色设置： * 颜色名称：green * 十六进制：#ff0000 * RGB：rgb(0,0,0) * RGBA：rgba(0,0,0,0.5) * HSL：hsl(120,65%,75%)|String|-|
|setStrokeLineDash(strokeLineDash)|设置贝塞尔曲线的虚线类型。|Array\<Number\>|-|
|setStrokeWeight(strokeWeight)|设置边框宽度。|Number|-|
|setVisible(visible)|设置可见性。|Boolean * true：可见 * false：不可见 默认值为true。|-|
|setZIndex(zIndex)|设置[HWBezierCurve](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwbeziercurve-0000002007429292)的z-index属性，即z轴方向的叠加关系。|Number|-|
|addListener(type, callback)|添加事件侦听。|* type：String，见[事件](#section5657218144413)。 * callback：事件触发的回调函数。|-|
|removeListener(type, callback)|删除事件侦听。|* type：String，见[事件](#section5657218144413)。 * callback：事件触发的回调函数。|-|

|mouseOut|鼠标离开。|bezierCurve.addListener('mouseOut', callback)，参数callback为自定义回调函数。|

#### BezierCurveOptions

|参数|是否必选|参数类型|描述|
|:-------------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|map|是|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|地图实例。|
|paths|是|Array\<Array\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)\>\>|第一个是起点，后面是控制点和途径点，每条路径点之间可以有1或2个控制点。 比如： ``` [ // 起点 [ {lng, lat}], // 控制点 控制点 途经点1 [ {lng, lat}, {lng, lat}, {lng, lat}], // 控制点 途经点2 [ {lng, lat}, {lng, lat}] ] ```|
|strokeColor|否|String|用于设置颜色和透明度，表示边框颜色，默认为黑色。 支持以下几种颜色设置： * 颜色名称：green * 十六进制：#ff0000 * RGB：rgb(0,0,0) * RGBA：rgba(0,0,0,0.5) * HSL：hsl(120,65%,75%)|
|strokeLineDash|否|Array\<Number\>|用于设置虚线类型，参数是一组描述交替绘制线段和间距长度的数字。 如果数组元素的数量是奇数， 数组的元素会被复制并重复。例如， \[5, 10, 15\] 会变成 \[5, 10, 15, 5, 10, 15\]。|
|strokeWeight|否|Number|线宽，单位：像素，默认为1像素。|
|visible|否|Boolean|表示可见性。 * true：可见 * false：不可见 默认值为true。|
|zIndex|否|Number|[HWBezierCurve](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwbeziercurve-0000002007429292)的z-index属性，即z轴方向的叠加关系（相对于[HWCircle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwcircle-0000001051070086)、[HWMarker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmarker-0000001051070088)、[HWPolygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwpolygon-0000001050710118)、[HWPolyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwpolyline-0000001050990169)、[HWBezierCurve](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwbeziercurve-0000002007429292)）。|
