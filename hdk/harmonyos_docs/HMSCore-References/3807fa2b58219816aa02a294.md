# ppsads.createBannerAd(object)

#### 概述

创建Banner广告对象，返回类型：[BannerAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263)。  

#### 参数

|参数|是否必选|类型|描述|
|:----------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|slotId|是|String|广告位ID。|
|deviceType|否|number|设备类型。 * PHONE：手机 * TABLET：平板 默认值：PHONE，详细取值请参见[DeviceType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section545534453916)。|
|width|是|number|广告尺寸[宽度](#section455613917416)，单位：px。|
|height|是|number|广告尺寸[高度](#section455613917416)，单位：px。|
|refreshTime|否|number|Banner广告的自动刷新时间间隔，单位：s。 取值范围：\[30, 120\]。|
|container|是|DOM|广告容器元素。|

#### width与height取值说明

|width|height|描述|
|:----|:-----|:-------------------------------|
|360|57|全球支持。|
|360|144|全球支持。|
|160|600|中国大陆地区不支持。|
|300|250|中国大陆地区不支持。|
|320|100|中国大陆地区不支持。|
|320|50|中国大陆地区不支持。|
|468|60|中国大陆地区不支持。|
|728|90|中国大陆地区不支持。|
|-1|-2|动态横幅尺寸，屏幕宽度和自动高度。|
|-3|-4|动态横幅尺寸，宽度匹配DOM父节点宽度，高度匹配广告内容的高度。|
