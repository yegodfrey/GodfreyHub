# HwDotsPageIndicator

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------|
|public class HwDotsPageIndicator extends View 该类是华为的导航点指示器，继承了View，和ViewPager一起使用，用来指示ViewPager的页面显示情况。支持自动滚动以及2种导航点显示样式，圆点显示以及数字显示。|

#### XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:--------------------------------------------|
|boolean|hwIsAutoPlay 定义关联的页面是否自动滚动，为true时以5秒时间间隔自动滚动。|
|color|hwUnselectedDotColor 当导航点为圆点显示时，设置其他页导航点颜色值。|
|color|hwSelectedDotColor 当导航点为圆点显示时，设置当前页导航点颜色值。|
|boolean|hwIsShowAsDot 设置导航点为圆点或数字显示，true时采用圆点显示。|
