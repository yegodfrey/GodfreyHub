# NFC卡券数据托管

## 功能介绍

开发者把NFC卡券数据推送到华为钱包服务器进行托管。

## 场景描述

若开发者服务器不具备个人化数据的查询能力，可使用此接口将NFC卡券个人化数据推送到华为钱包服务器进行托管。

下面以酒店开发者集成酒店会员卡和房门NFC能力为例，描述此接口的使用流程。首先，酒店服务器将酒店会员卡模板推送到华为钱包服务器，顾客使用酒店提供的接口生成会员卡实例并添加到华为钱包App。顾客在酒店办理开房手续后，酒店服务器向房门供应商服务器获取房门NFC数据，并使用此接口将房门NFC数据推送华为钱包服务器，此接口会返回一个"token"。然后，酒店服务器使用更新会员卡实例接口将"token"信息添加到顾客会员卡的[LinkDevicePass](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/linkdevicepass-0000001050160329)字段里。顾客使用华为钱包NFC能力刷卡时，由华为钱包App向钱包服务器发送请求进行NFC相关操作。

## 使用约束

实现了[商户服务器实现NFC刷卡能力接口](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-overa-nfc-0000001050042374#section7295173313517)中所描述的接口的开发者不需要使用此接口。使用此接口需联系[华为技术支持](https://developer.huawei.com/consumer/cn/support/contactUs)进行开发联调。

## 接口原型

|承载协议|HTTPS POST|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器 ->华为钱包服务器|
|接口URL|{url}/hmspass/v1/nfccard/personalizeddata {url}变量需要开发者根据服务器所属区域自行选择，请参见[钱包服务器地址](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-address-0000001050158382)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

**Request Header** **：**

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Authorization|是|String|鉴权码。获取方式详见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides-V5/open-platform-oauth-0000001053629189-V5)，请使用"客户端模式"。"client_id"和"client_secret"即为开发者在华为AGC网站上创建应用后获取的"App ID"和"App key"。将获取到的"access_token"的值拼接在字符串"Bearer"之后，以空格符相隔，组成"Authorization"参数的值。|
|Content-Type|是|String|固定值："application/json;charset=utf-8"。|
|Accept|是|String|固定值："application/json;charset=utf-8"。|

**Request Body** **：**

|参数|是否必选|参数类型|描述|
|:--------------|:---|:------------|:------------------------------------------------------|
|serviceType|是|String(32)|业务名称，由华为技术提供。|
|transId|是|String(32)|业务序列号，由开发者自定义。在同一个serviceType下唯一。|
|personlizedData|是|String(10240)|NFC卡券数据|
|expireTime|否|String(32)|NFC数据过期时间（UTC时间）："yyyy-mm-dd HH:MM:SS"。如果不设置，则默认为3个月过期。|
|appendInfo|否|String(2048)|附加信息|

## 请求示例

```codeblock
POST /hmspass/v1/nfccard/personalizeddata HTTP/1.1
Content-Type: application/json;charset=utf-8
Authorization: Bearer ***
Accept: application/json;charset=utf-8
Host: wallet-passentrust-drcn.cloud.huawei.com.cn
{
  "serviceType": "amber_house",
  "transId": "amberHouse10001",
  "personalizedData": "{\"key1\":\"value1\",\"key2\":\"value2\"}",
  "expireTime": "2021-07-22T09:12:43.083Z"
}
```

## 响应参数

**错误码为200时：**

|参数|参数类型|描述|
|:---------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------|
|returnCode|String|响应码，"0"表示成功。|
|returnDesc|String|响应描述，成为是为"success"。|
|token|String|token值，应更新到对应卡券实例的[LinkDevicePass](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/linkdevicepass-0000001050160329)参数里。|

## 响应示例

```codeblock
HTTP/1.1 200 OK
Content-Type: application/json
{
  "returnCode": "0",
  "returnDesc": "success",
  "token": "5jyilu6km72yfiv8b54trcr90fj5val8"
}
```

## 错误码

详见接口公共定义中的[公共响应码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/public-0000001050158472#section104092484415)。

## 调用示例

```codeblock
public JSONObject postToWalletServer(String urlSegment, String body) {
  // Construct the http header.    
  HttpHeaders header = constructHttpHeaders();    
  // Construct the http URL.    
  String baseUrl = ConfigUtil.instants().getValue("walletServerBaseUrl");    
  String walletServerUrl = baseUrl + urlSegment;    
  // Send the http request and get response.    
  HttpEntity<JSONObject> entity = new HttpEntity<>(JSONObject.parseObject(body), header);    
  ResponseEntity<JSONObject> exchange =REST_TEMPLATE.exchange(walletServerUrl, HttpMethod.POST, entity, JSONObject.class);    
  // Return the posted model or instance or NFC card personalized data.    
  return exchange.getBody();
}
```
