# Projection

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class Projection 用于在屏幕坐标和经纬度之间进行转换，在调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)类的[getProjection](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582#section10118629175416)方法时会返回该类型的实例。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535)|[fromScreenLocation](#section10287164110496)(Point point) 实现屏幕像素点坐标转换成经纬度。|
|[VisibleRegion](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-visibleregion-0000001206767440)|[getVisibleRegion](#section124911628145020)() 获取在屏幕坐标和地理经纬度坐标之间转换之后的可见区域。|
|[Point](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-point-0000001149809211)|[toScreenLocation](#section998261112518)([LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535) latLng) 获取与经纬度对应的屏幕上的点的位置。|

#### Public Methods

#### fromScreenLocation

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535) fromScreenLocation([Point](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-point-0000001149809211) point) 您调用此API实现屏幕像素点坐标转换成经纬度。屏幕位置是以相对于地图左上角（而不是整个屏幕的左上角）的屏幕像素（而非显示像素）指定的。|

Parameters  

|Name|Description|
|:----|:-----------------------------------------------------------------------------------|
|point|屏幕上的坐标点，单位：像素。取值范围：\[INT_MIN, INT_MAX\]。 说明： 选点（屏幕上的坐标点）与相机的连线与地面近似平行时，返回固定值(90, 0)。|

Returns  

|Type|Description|
|:-----|:-------------------------------------------------------------------------------------------------------------------|
|LatLng|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535)对象，表示经纬度。|

#### toScreenLocation

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [Point](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-point-0000001149809211) toScreenLocation([LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535) latLng) 您调用此API可获取与经纬度对应的屏幕上的点的位置。屏幕位置是以相对于地图左上角（而不是整个屏幕的左上角）的屏幕像素（而非显示像素）指定的。|

Parameters  

|Name|Description|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|latLng|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-latlng-0000001148112535)对象，表示经纬度。取值范围：经度\[-180, 180\]，纬度\[-85.05, 85.05\]。 说明： 经纬度超出相机视椎体时，返回固定值(INT_MAX, INT_MAX)。|

Returns  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------|:-------------|
|[Point](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-point-0000001149809211)|屏幕上的坐标点，单位：像素。|
