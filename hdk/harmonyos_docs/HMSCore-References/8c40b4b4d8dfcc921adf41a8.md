# onBluetoothAdapterStateChange: 监听手机蓝牙状态的变化

接口原型

public void onBluetoothAdapterStateChange(String function)

方法描述：监听手机蓝牙状态的变化。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-----------------------------------|:---|
|function|String|监听手机蓝牙模块状态回调函数名，该回调函数有两个参数，详情参见响应参数。|M|
[表1 请求参数]

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:----------|:------|:----------------------------------------------------|:---|
|discovering|Boolean|是否正在搜索设备，true代表正在搜索设备，false表示本地蓝牙适配器状态不是准备使用状态，不能被搜索。|M|
|available|Boolean|蓝牙适配器是否可用，true表示可用，false表示不可用。|M|
[表2 响应参数]
