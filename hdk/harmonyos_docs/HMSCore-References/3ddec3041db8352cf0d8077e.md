# 设备主动上报低功耗蓝牙的特征值变化

当设置低功耗蓝牙的特征值的主动上报开关为打开状态，且低功耗蓝牙设备的指定服务的特征值发生变化时，蓝牙适配器会主动上报特征值。三方可获取上报后的特征值，根据自己蓝牙协议定义的数据格式进行解析，获取关注的数据。
