# Overview

情景感知服务的入口包，包括[BarrierClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrierclient-0000001050162440)、[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-captureclient-0000001050164395)、[DonateClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-donateclient-0000001298155168)接口和[Awareness](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awarenes-awareness-0000001050162582)、[AwarenessStatusCodes](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-awarenessstatuscodes-0000001050164539)类，主要的API都定义在其中。

## Interface Summary

|Interface|Description|
|:------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------|
|[CaptureClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-captureclient-0000001050164395)|情景感知快照API的主要入口，能够通过该接口获取耳机状态、活动状态、时间状态、地理位置、信标状态、光照度、天气状态、车载蓝牙状态、手机状态和各能力支持状态的响应。|
|[BarrierClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrierclient-0000001050162440)|客户端向服务端注册以及查询情景感知围栏的入口。|
|[Client](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-client-0000001363534229)|情景感知服务基本入口。|
|[DonateClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-donateclient-0000001298155168)|数据捐赠API入口。|
