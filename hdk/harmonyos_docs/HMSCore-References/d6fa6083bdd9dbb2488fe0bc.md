# Overview

包含华为按钮的功能类以及不同风格按钮的资源。

## Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------|
|[HwButton](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwbutton-class-0000001051623476)|华为Button控件（按钮）分为强调按钮、普通按钮、及文字按钮三种类型，使用对应的style可实现不同的样式。 在API 28以下使用本控件，按钮内文本将不会被默认设置为全部大写。|
