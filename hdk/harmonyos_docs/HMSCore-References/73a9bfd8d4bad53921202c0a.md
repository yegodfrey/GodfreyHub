# 采样数据多日统计查询

#### 功能介绍

将特定数据类型数据以天为单位按一定规则进行聚合查询。  

#### 场景描述

指定采样数据以天为单位进行聚合查询。  

#### 使用约束

无  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:dailyPolymerize|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|--------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/json; charset=UTF-8|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body  

|参数|参数类型|是否必选|说明|约束条件|
|:--------|:-------------|:---|:-----------------|:----------------------------------------------------------|
|startDay|String|是|期望被聚合的数据开始日期。 单位：天|格式为yyyyMMdd，不早于20140101。|
|endDay|String|是|期望被聚合的数据结束日期。 单位：天|格式为yyyyMMdd。 endDay不小于startDay。 endDay与startDay时间间隔不能超过31天。|
|dataTypes|List\<String\>|是|原子采样明细数据类型的集合。|List最大容量：20。|
|timeZone|String|是|指定时区。|格式：+0800。|

#### 请求示例

```
POST
https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:dailyPolymerize
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
{
 "dataTypes": [
   "com.huawei.continuous.steps.delta"
 ],
 "startDay": "20200811",
 "endDay": "20200812",
 "timeZone": "+0800"
}
```

#### 响应参数

状态码为200时：

Response Header  

|参数|参数类型|是否必选|描述|
|:-------------------|:-----|:---|:--------------------------------------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|
|x-health-app-privacy|int|是|用户隐私标记取值为： 1：用户在运动健康App已授权 2：用户在运动健康App未授权 3：非华为运动健康App用户（无需授权）|

Response Body  

|参数|参数类型|是否必选|描述|
|:----|:------------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|group|List\<Group\>|是|汇总数据的组列表。请参见[Group](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section1943715915337)数据模型。|
