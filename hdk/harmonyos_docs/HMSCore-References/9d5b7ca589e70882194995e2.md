# ActivityConversionData

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ActivityConversionData implements Parcelable 活动转换事件。您可以通过[ActivityConversionResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityconversionresponse-0000001051066106)类的[getActivityConversionDatas](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityconversionresponse-0000001051066106#section11207204211222)()获取此类列表。|

获取ActivityConversionData实例对象的示例代码如下：

```java
"Java"
ActivityIdentificationResponse activityRecognitionResult =
    ActivityIdentificationResponse.getDataFromIntent(intent);
if (activityRecognitionResult != null) {
    List<ActivityIdentificationData> list = activityRecognitionResult.getActivityIdentificationDatas();
}
```

```java
"Kotlin"
val activityRecognitionResult =
    ActivityIdentificationResponse.getDataFromIntent(intent)
if (activityRecognitionResult != null) {
    val list =
        activityRecognitionResult.activityIdentificationDatas
}
```

### ActivityConversionData(int activityType, int conversionType , long elapsedTimeFromReboot)

|Constructor|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public ActivityConversionData(int activityType, int conversionType , long elapsedTimeFromReboot) 构建一个ActivityConversionData实例。通过传参进行构建实例，传入的activityType需要为[ActivityIdentificationData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityidentificationdata-0000001050706134)定义的活动类型之一并且传入的conversionType需要为[ActivityConversionInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityconversioninfo-0000001050746165)定义的转换类型之一 ，否则会抛出参数不正确异常。|

**Parameters**

|Name|Description|

|conversionType|转换类型，请参阅[Constant-values](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-values-0000001050746179#section1176918644717)。|

**Throws**

|Name|Description|
|:-----------------------|:--------------------------------------------------|
