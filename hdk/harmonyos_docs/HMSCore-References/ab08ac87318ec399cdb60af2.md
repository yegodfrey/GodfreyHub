# 说明

|Name|Description|
|:------|:---------------------------------------------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，提供Android接入华为云空间服务能力。包括文件的上传、下载和搜索，对文件的评论、回复、查询历史版本，云端文件变化的查询、推送通知功能。|
|REST|提供REST API接入华为云空间服务能力，包括文件的上传、下载和搜索，对文件的评论、回复、查询历史版本，云端文件变化的查询、推送通知功能，助您实现可靠文件管理、多端协同、安全存储。每个接口支持独立开发，不需要端云协同开发。|
