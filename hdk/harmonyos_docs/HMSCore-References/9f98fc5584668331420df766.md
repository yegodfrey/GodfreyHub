# 错误码

|错误码|值|描述|解决方法|
|:-----------------------|:------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|STATUS_SUCCESS|"0"|支付/签约成功|-|
|STATUS_FAIL|"-1"|支付/签约失败|应用向用户提示支付失败|
|STATUS_CANCEL|"30000"|取消支付/签约|应用向用户提示取消了支付|
|STATUS_PARAM_ERROR|"30001"|参数错误|请检查请求参数是否遗漏，参数值格式是否正确。|
|STATUS_UNKNOWN|"30004"|支付/签约未知状态|建议[查询交易](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-query-order-status-0000001589215985)或者[签约订单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-query-sign-info-0000001680058661)接口，确认是否支付成功|
|STATUS_DUPLICATE_REQUEST|"30010"|重复请求|应用向用户提示重复支付请求|
|STATUS_NETWORK_ERROR|"30011"|网络错误|应用向用户给出提示，请用户检查网络。|

其他错误码请参见[HMS Core SDK框架错误码](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/error-code-0000001050045846)。

若开发者的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
