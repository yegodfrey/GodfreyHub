#### LogConfig(String logPath, int fileSize, int fileNum, int fileExpiredTime)

|Constructor|
|:------------------------------------------------------------------------------------------------|
|public LogConfig(String logPath, int fileSize, int fileNum, int fileExpiredTime) 构建一个LogConfig实例。|

Parameters  

|Name|Description|
|:--------------|:----------------------------------------------------|
|logPath|日志保存路径。|
|fileSize|单个日志文件大小，单位：MB。取值范围：(0，2\]，默认为2。如果输入的值不在该范围内，则会使用默认值。|
|fileNum|文件最大数量。取值范围：(0，20\]，默认为20。如果输入的值不在该范围内，则会使用默认值。|
|fileExpiredTime|文件有效期，单位：天。取值范围：(0，5\]，默认为5。如果输入的值不在该范围内，则会使用默认值。|
