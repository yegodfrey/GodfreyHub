# Overview

该包主要提供扫码格式选项类、扫码结果数据类和多码识别类。

* 扫码格式选项类主要设置扫码支持的码制式。
* 扫码结果数据类为扫码结果的数据信息，包括码值信息、码制式信息等。
* 多码识别类提供通过MultiProcessor Mode的同步和异步扫码方式。
