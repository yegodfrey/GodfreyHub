# 标准蓝牙BLE交互操作

三方可通过封装后的JS接口，与蓝牙设备创建连接，获取蓝牙设备的特征值变化等相关操作。三方根据自己定义的蓝牙协议时序，使用封装后的JS接口，进行数据通信，解析数据，获取测量结果。

|接口|说明|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------|
|[createBLEConnection](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/createbleconnection-0000001056726830)|通过指定的设备UUID与手机蓝牙适配器创建连接。|
|[closeBLEConnection](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/closebleconnection-0000001057695280)|通过指定的设备UUID断开与手机蓝牙适配器的连接。|
|[onBluetoothAdapterStateChange](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onbluetoothadapterstatechange-0000001064337078)|监听手机蓝牙状态的变化。|
|[startBluetoothDevicesDiscovery](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/startbluetoothdevicesdiscovery-0000001064271118)|开始搜寻附近的蓝牙设备。|
|[stopBluetoothDevicesDiscovery](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/stopbluetoothdevicesdiscovery-0000001065039542)|停止搜寻附近的蓝牙设备。|
|[onBluetoothDeviceFound](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onbluetoothdevicefound-0000001064879694)|订阅发现新的蓝牙设备的事件。|
|[requestConnectionPriority](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestconnectionpriority-0000001064042279)|设置蓝牙设备请求连接的优先级。|
|[readBLECharacteristicValue](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/readblecharacteristicvalue-0000001057789163)|读取低功耗蓝牙设备的特征值，以十六进制字符串返回。|
|[writeBLECharacteristicValue](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/writeblecharacteristicvalue-0000001057974880)|通过指定服务的ID写入指定数据。|
|[registerRequestMtu](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/registerrequestmtu-0000001064192901)|订阅设置手机与蓝牙设备传输Mtu值的方法。|
|[requestMtu](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestmtu-0000001063924689)|设置手机与设备传输的mtu值。|
|[notifyBLECharacteristicValueChange](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/notifyblecharacteristicvaluechange-0000001058254872)|设置低功耗蓝牙设备是否开启指定服务的特征值的模式，通过onBLECharacteristicValueChange返回设置结果。|
|[onBLEConnectionStateChange](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onbleconnectionstatechange-0000001057217138)|设备主动上报低功耗蓝牙连接状态的变化。|
|[onBLECharacteristicValueChange](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onblecharacteristicvaluechange-0000001057377116)|设备主动上报低功耗蓝牙设备的特征值变化。|
|[onBLEServicesDiscovered](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onbleservicesdiscovered-0000001057417205)|蓝牙设备建立连接后，开始发现设备支持的服务，当服务被成功发现后，回调通知三方。|
|[setEnableIndication](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/setenableindication-0000001058017149)|设置低功耗蓝牙工作模式为启用指示模式或启用通知模式。|
