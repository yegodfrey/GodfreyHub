# 控制运动并获取实时运动数据

## startSport(String activityType)

|Method|
|:---------------------------------------------------------|
|startSport(String activityType) 根据输入的运动类型，开始运动。该接口只在手机上支持。|

**Parameters**

|Name|Description|
|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|activityType|运动类型。取值请参见[HMSHealthKitActivityRealTimeType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-hmshealthkitactivityrealtimetype-0000001204692698)。|

**Returns**

|Type|Description|
|:----------------------|:------------------------------------------------------|
|Promise<Result<String>>|返回开始运动的异步回调。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

开始运动的示例代码如下：

```screen
import {HMSHealthKit, HMSHealthKitActivityRealTimeType} from '@hw-hmscore/hms-js-health'
HMSHealthKit.startSport(HMSHealthKitActivityRealTimeType.SPORT_TYPE_WALK).then((result) => {
    // 调用成功
    console.info("startSport callback: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.info("startSport callback error: " + JSON.stringify(error))
});
```

## stopSport()

|Method|
|:--------------------------------|
|stopSport() 结束已经开始的运动。该接口只在手机上支持。|

**Returns**

|Type|Description|
|:----------------------|:-----------------------------------------------------------|
|Promise<Result<String>>|返回结束已经开始的运动的异步回调。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

结束已经开始的运动的示例代码如下：

```screen
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.stopSport().then((result) => {
    // 调用成功
    console.info("stopSport success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.info("stopSport fail: " + JSON.stringify(error))
});
```

## registerSportData(String callBack, Map map)

|Method|
|:---------------------------------------------------------------|
|registerSportData(String callBack, Map map) 注册实时运动回调。该接口只在手机上支持。|

**Parameters**

|Name|Description|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|callBack|实时运动回调|
|map|全局事件回调集合，定义方法请参照[初始化模块](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-integration-hms-core-sdk-0000001226760449#section159413421451)。|

**Returns**

|Type|Description|
|:----------------------|:----------------------------------------------------------|
|Promise<Result<String>>|返回注册实时运动回调的异步回调。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

注册实时运动回调的示例代码如下：

```screen
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
var sportData;
HMSHealthKit.registerSportData((result) => {
    if (sportData?.data === result?.data) {
        return;
    } else {
        sportData = result;
    }
    // 实时运动回调
    console.info("startSportData callback: " + JSON.stringify(sportData))
}, this.$app.$def.hmsData.eventCallbackMap);
```

> 说明
>
> 上面的代码片段中用到this.$app.$def.hmsData.eventCallbackMap为全局事件回调集合，定义方法请参照[初始化模块](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-integration-hms-core-sdk-0000001226760449#section159413421451)。

## unregisterSportData()

|Method|
|:-----------------------------------------|
|unregisterSportData() 取消实时运动回调。该接口只在手机上支持。|

**Returns**

|Type|Description|
|:----------------------|:----------------------------------------------------------|
|Promise<Result<String>>|返回取消实时运动回调的异步回调。 * 若回调成功，则表示接口调用成功。 * 若回调失败，可通过异步回调结果获取错误码。|

取消实时运动回调的示例代码如下：

```screen
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.unregisterSportData().then((result) => {
    // 调用成功
    console.info("stopSportData success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.info("stopSportData fail: " + JSON.stringify(error))
});
```
