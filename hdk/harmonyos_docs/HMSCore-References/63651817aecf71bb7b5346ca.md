# ExitCallback

|Interface Info|
|:--------------------------------------|
|public interface ExitCallback 退出游戏回调接口。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------|
|void|[onExit](#section73140185015)(int rtnCode) 退出游戏方法。当智慧屏会员权益校验不通过需要退出游戏时触发该方法。您需要在此方法中实现退出游戏的功能，例如保存玩家进度、调用华为帐号退出接口等。|

#### Public Methods

#### onExit

|Method|
|:------------------------------------------------------------------------------------------------|
|void onExit(int rtnCode) 退出游戏方法。当智慧屏会员权益校验不通过需要退出游戏时触发该方法。您需要在此方法中实现退出游戏的功能，例如保存玩家进度、调用华为帐号退出接口等。|

Parameters  

|Name|Description|
|:------|:-----------------------------------------------------------------------------|
|rtnCode|退出游戏时的返回码。 * 7002: 网络异常或服务器异常。 * 7404：已开通会员，触发登录限制，用户点击退出游戏。 * 7403：非会员或会员已过期。|
