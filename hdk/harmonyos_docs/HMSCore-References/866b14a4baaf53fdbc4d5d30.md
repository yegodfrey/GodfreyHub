# 子商户进件状态查询

#### 功能介绍

平台类商户/服务商通过子商户号、流程ID查询该商户下子商户进件流程进度的状态信息。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者服务器-\> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/partner/mgmt/submerc/query|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|--------------------------------------------------------------------------------|

#### 请求参数

* Request Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|

<!-- -->

* Request Path  

  |参数|是否必填|参数类型|描述|
  |:---------|:---|:-----|:---------------------------------------------------------------------|
  |externalNo|否|String|外部平台关联编号（externalNo）由商户生成，最大长度为64。subMercNo与该参数必选其一，同时传递则以subMercNo为准。|
  |subMercNo|否|String|特约商户号或平台子商户号。externalNo与该参数必选其一，同时传递则以subMercNo为准。|
  |flowId|否|String|子商户入网流程ID。如果不传递该参数，则以最新请求的入网flowId为准。|

#### 响应参数

* Response Header  

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|

* Response Body  

  |参数|是否必填|参数类型|描述|
  |:-----------------------|:---|:----------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |resultCode|是|String|结果码，"000000"表示成功，其他表示失败。|
  |resultDesc|是|String|结果描述。|
  |subCode|否|String|业务错误码。|
  |subDesc|否|String|业务错误描述信息。|
  |sign|是|String|签名值。用于开发者对响应报文进行防篡改验证。|
  |merchantInfo|否|[MerchantInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section29315216227)|商户基本信息。|
  |activeUrl|否|String|激活链接。操作员激活或者小额打款。|
  |flowId|是|String|子商户入网流程ID。|
  |applyStatus|是|String|进件状态。 * APPLY_STATUS_TO_BE_SUBMIT：待提交入网材料 <!-- --> * APPLY_STATUS_AUDITING：审核中 * APPLY_STATUS_OPERATOR_TO_BE_ACTIVIED：待激活 * APPLY_STATUS_BANK_ACCOUNT_TO_BE_CERTIED：待认证 * APPLY_STATUS_AGREEMENT_TO_BE_SIGNED：待签署 * APPLY_STATUS_TO_BE_SIGNED：开户中 * APPLY_STATUS_FINISHED：入网完成 * APPLY_STATUS_REJECTED：入网驳回 * APPLY_STATUS_CANCELED：流程撤回|
  |auditDetail|否|String|驳回原因详情（当申请状态为APPLY_STATUS_REJECTED时才返回）。 说明： 入网驳回的可能原因（非固定，供参考）： 1. 审核节点系统规则校验不通过、人工驳回相关原因说明。 2. 打款节点打款超限。 3. 协议签署节点拒绝签署协议。 4. 开户节点银网联入网失败相关原因说明。|
  |operActiveFlag|否|String|超管是否激活的标志。 0：未激活 1：已激活|
  |operActiveTime|否|String|超管激活时间。已激活的情况下返回。 格式：yyyy-MM-dd HH:mm:ss。|
  |finishRecords|否|List\<[FlowNodeInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section8520852182610)\>|已完成的流程节点相关信息。|
  |accountVerifyInfo|否|List\<[BankAccountVerifyInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section2066619515278)\>|打款验证的相关信息。|
  |appAuthorizationInfoList|否|List\<[AppAuthorizationInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section44373167547)\>|应用授权信息。|
