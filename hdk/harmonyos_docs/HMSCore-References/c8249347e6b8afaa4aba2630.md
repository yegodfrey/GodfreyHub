# RelatedPassIds

|参数|是否必选|参数类型|描述|
|:-----|:---|:-----|:----------------------------|
|typeId|是|String|关联卡券的服务号，即passTypeIdentifier。|
|id|是|String|关联对象的个人化实例ID，即serialNumber。|

示例：

```
{
    "relatedPassIds": [
        {
            "typeId": "hwpass.com.huawei.wallet.offer",
            "id": "50001"
        }
    ]
}
```
