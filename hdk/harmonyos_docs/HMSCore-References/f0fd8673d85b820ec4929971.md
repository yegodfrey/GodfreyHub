# WeatherStatus

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Interface Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface[WeatherStatus](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-weatherstatus-4-0000001050167025) 天气状态接口，携带了完整的天气信息，在该类中提供了5个方法，可分别获取AQI天气指数、当前天气信息、未来7天天气、未来24小时天气和未来1~2天的生活指数，其中，AQI和生活指数仅提供国内数据。|
