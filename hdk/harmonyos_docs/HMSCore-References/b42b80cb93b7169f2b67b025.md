# getOrderDetail

## 接口定义

```screen
PendingResult<OrderResult> orderDetail = HuaweiPay.HuaweiPayApi.getOrderDetail(HuaweiApiClient mClient, OrderRequest orderReq);
```

## 接口描述

查询订单详情，所有调用pay接口的订单均可查询，用于在丢单的情况下复核订单。

* 支付过程异常中断（关机、程序崩溃等）。
* 支付结果码为-1005、30005、30002。
* 结果码为0但是验签失败。

对于有应用服务器的非单机应用，开发者需要在自己的服务器上实现支付成功回调处理的能力，然后访问自己的服务器确认订单是否支付成功，不需要使用此接口。

## 请求参数

|参数|参数类型|是否必填|描述|
|:-------|:--------------|:---|:-------------|
|orderReq|OrderRequest|是|支付请求参数。|
|mClient|HuaweiApiClient|是|用于调用IAP SDK接口。|

|参数|参数类型|是否必填|是否参与签名|描述|
|:---------|:-----|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|merchantId|String|是|是|商户ID。在华为开发者联盟上获取的"支付ID"。|
|requestId|String|是|是|商户订单号。开发者应用在支付前生成，用来唯一标识一次支付请求。注意：该字段中不能包含特殊字符，包括# " & / ? $ ^ *:) \ < > , | .等，不支持中文。|
|keyType|String|是|是|固定值，请填写：1 商户秘钥|
|time|String|是|是|UTC时间戳，以毫秒为单位。|
|sign|String|是|否|1. 取上述参数字段，按参数名的ASCII码的增序排序，若遇到相同首字母，则看第二个字母，以此类推。 注意 > * sign参数不参与签名。 > * 没有值的参数，包括null和""两种情况都不需要参与签名。 2. 排序完成之后，再把所有参数名和参数值的键值对以"&"字符连接起来，得到的字符串即为待签名串。 3. 将待签名字符串使用RSA私钥进行签名，得到的字符串即为sign参数的值。|
[**表1**OrderRequest]

## 返回值

通过setResultCallback回调订单查询结果orderResult。

|参数|参数类型|是否必填|是否参与签名|描述|
|:---------|:-----|:---|:-----|:-------------------------------------------------------------------------------------------------------------------------------------|
|returnCode|int|是|是|返回码，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/vr-errorcode-0000001064289571)。当有业务返回码时，会将此值赋值给retCode。|
|returnDesc|String|是|是|错误描述信息。|
|requestId|String|否|是|商户订单号。|
|orderID|String|否|是|华为支付平台订单号。|
|orderTime|String|否|是|下单时间，yyyy-MM-dd HH:mm:ss|
|tradeTime|String|否|是|支付时间，yyyy-MM-dd HH:mm:ss|
|status|String|否|是|状态。 * 0：失败（订单失败） * 1：成功（完成支付） * 2：未处理（订单可能在等待支付或者等待支付应答，1天之内可以再次查询，1天后算作失败） * 3：处理中（订单在处理中，1天之内可以再次查询，1天后算作失败）|
|sign|String|否|否|响应的签名字符串。|
[**表2**OrderResult]

## 调用示例

以下代码片段来源于[客户端示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/vr-client-sample-code-0000001064616643)，您可直接下载代码工程。相关的类和常量定义等可参见代码工程。

```screen
PendingResult<OrderResult> orderDetail = HuaweiPay.HuaweiPayApi.getOrderDetail(mClient, orderReq);
orderDetail.setResultCallback(new ResultCallback<OrderResult>() {
    @Override
    public void onResult(OrderResult orderResult) {
        Log.i("IAP", "startQueryOrder success");
        if (orderResult.getReturnCode() == OrderStatusCode.ORDER_STATE_SUCCESS) {
            // 订单查询成功
            boolean orderSignCheck = PaySignUtil.checkSign(orderResult, Constant.getPublicKey());
            if (orderSignCheck) {
                // 订单验签成功，发放商品
            } else {
                // 订单验签失败
                Log.i("IAP", "orderResult checkSign  failed");
            }
        } else {
            // 订单查询失败
            Log.i("IAP", "getOrderDetail failed");
        }
    }
});
```
