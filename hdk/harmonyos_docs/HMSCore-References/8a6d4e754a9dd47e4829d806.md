# Marker

定义展示在地图特定位置的图标。  

#### Properties

|名称|类型|描述|
|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------|
|markerId|[MarkerId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-markerid-0000001252864735)|标记的唯一ID。|
|position|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|标记的位置。|
|infoWindow|[InfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-infowindow-0000001208504722)|标记的信息窗。|
|anchor|Offset|标记的锚点。|
|draggable|bool|表示标记是否可以拖拽。取值为true（可拖拽）和false（不可拖拽）。|
|flat|bool|表示标记是否平贴到地图上。如果标记平贴地图，则在相机旋转和倾斜时，标记仍将停留在地图上。当相机放大或缩小时，标记将保持与相机缩放时相同的大小。如果标记面对相机，它将始终面向相机绘制，并随相机旋转和倾斜。|
|icon|[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-bitmapdescriptor-0000001208024788)|待渲染的标记图标。|
|rotation|double|标记的旋转角度，单位为度。|
|alpha|double|不透明度。取值范围为0（完全透明）到1（完全不透明）。|
|visible|bool|表示标记是否可见。取值为true（可见）和false（不可见）。|
|zIndex|double|标记的Z-index。z-index表示标记的叠加顺序。Z-index值较大的标记将压盖Z-index较小的标记。具有相同z-index的标记以随机顺序相互压盖。Z-index默认值为0。|
|clickable|bool|表示标记是否可以点击。取值为true（可点击）和false（不可点击）。|
|clusterable|bool|表示标记是否可聚合。|
|onClick|VoidCallback?|点击标记时执行的回调函数。|
|onDragEnd|ValueChanged\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)\>?|标记拖动完成时执行的回调函数。|
|onDragStart|ValueChanged\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)\>?|标记拖动开始时执行的回调函数。|
|onDrag|ValueChanged\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)\>?|拖动标记时执行的回调函数。|
|animationSet|List\<dynamic\>|动画。|
