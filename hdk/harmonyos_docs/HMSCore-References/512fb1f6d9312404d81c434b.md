# 蓝牙适配器开关操作

三方可通过封装后的JS接口，获取蓝牙适配器的开关状态和设置蓝牙适配器的开关状态。  

|接口|说明|
|:------------------------------------------------------------------------------------------------------------------------------------|:-----------|
|[openBluetoothAdapter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/openbluetoothadapter-0000001058135267)|打开手机蓝牙适配器。|
|[closeBluetoothAdapter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/closebluetoothadapter-0000001057566847)|关闭手机蓝牙适配器。|
|[getBluetoothAdapterState](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/getbluetoothadapterstate-0000001057686851)|获取手机蓝牙适配器状态。|
