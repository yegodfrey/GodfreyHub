# HwBottomNavigationView

|Class Info|
|:--------------------------------------------------------------------------------------------------------|
|public class HwBottomNavigationView extends LinearLayout 该类是华为底部页签导航栏控件，内部包含2~5子项，用户可通过点击子项，快捷地访问应用的不同模块。|

## Nested Class Summary

|Qualifier and Type|Class Name and Description|
|:-----------------|:----------------------------------------------------------------|
|public interface|BottomNavListener 切换不同子项的回调接口，提供三种回调方法，被选中、去选中或重新选中；可在其中切换不同模块页面。|

## XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:-----------------------------------------------------------|
|reference|color|hwIconDefaultColor 定义未选中子项，图标（可着色类图标）颜色。|
|reference|color|hwIconActiveColor 定义选中子项，图标（可着色类图标）和文本颜色。|
|reference|color|hwMessageBgColor 定义子项新消息圆点颜色。|
|reference|hwBottomNavMenu 通过菜单方式配置各子项图标和文本。|
|reference|hwBottomNavDivider 引用底部页签顶部分割线资源，当底部页签和内容区域相同背景时，可以配置分割线以区分。|
|boolean|hwColumnEnabled 是否开启栅格化布局。|
|reference|color|hwTitleDefaultColor 定义未选中子项，文本颜色。|
|reference|color|hwTitleActiveColor 定义选中子项，文本颜色。|
