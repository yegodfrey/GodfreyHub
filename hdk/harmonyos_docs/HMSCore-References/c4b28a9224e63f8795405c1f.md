# Overview

Health Service Kit的功能类集合，入口类为[HuaweiHiHealth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweihihealth-0000001050091513)。

|[HealthRecordController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/healthrecordcontroller-0000001165268361)|提供创建、删除、管理健康记录的功能。|
|[HiHealthActivities](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthactivities-0000001050089540)|运动类型定义。|

|[HiHealthStatusCodes](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560)|状态码定义。|
|[HuaweiHiHealth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweihihealth-0000001050091513)|API入口类。|
|[SettingController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/settingcontroller-0000001050089660)|提供设置功能。|
