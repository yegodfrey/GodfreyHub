# HWDirectionsRenderer

#### 概述

根据路径规划接口的返回结果，在地图使用polyline呈现出规划的路径。  

#### 构造函数

|函数|描述|
|:--------------------------------|:-|
|HWMapJsSDK.HWDirectionsRenderer()|-|

#### 方法

|方法|描述|参数类型|返回值|
|:---------------------------------------|:-------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------|
|setMap(map)|绑定到地图。|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|-|
|getMap()|获取绑定的地图实例。|-|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|
|setOptions(options)|设置路径的样式。|[RendererOptions](#section9347115555210)|-|
|getOptions()|获取路径的样式。|-|[RendererOptions](#section9347115555210)|
|setDirections(directionsResult, options)|根据路径规划接口返回数据显示路径，其中options为可选参数。|* directionsResult：[DirectionsResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwdirectionsservice-0000001050710120#section171015555618)，路径规划结果。 * options：[RendererOptions](#section9347115555210)，路线的渲染样式。|Array\<[HWPolyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwpolyline-0000001050990169)\>|

#### RendererOptions

|参数|是否必选|参数类型|描述|
|:-----------|:---|:------|:------------------------------------------------------------------------------------------------------------------------------|
|strokeColor|否|String|用于设置颜色和透明度，表示路径颜色，默认为黑色。 支持以下几种颜色设置： * 颜色名称：green * 十六进制：#ff0000 * RGB：rgb(0,0,0) * RGBA：rgba(0,0,0,0.5) * HSL：hsl(120,65%,75%)|
|strokeWeight|否|Number|路径宽度，单位：像素，默认为1像素。|
|visible|否|Boolean|表示可见性。 * true：可见 * false：不可见 默认值为true。|
|zIndex|否|Number|同[HWPolyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwpolyline-0000001050990169)的zIndex。|
