# IBleThirdService

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------|
|interface IBleThhirdService extends Object ICCE车钥匙service接口（商户App实现），钱包可绑定该service后，调用其中的接口，完成配对码的获取，广播名称的获取，触发配对。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------|
|String|getPairCode(String macAddress, byte\[\] bytes) 华为钱包向商户app获取ICCE车钥匙配对码|
|String|getBroadcastName(String serialNumber) 华为钱包向商户app获取ICCE车钥匙对应的车端广播名称|
|String|applyToPair(String macAddress, byte\[\] bytes) 运动健康钱包向商户app请求蓝牙配对（仅限穿戴）|
