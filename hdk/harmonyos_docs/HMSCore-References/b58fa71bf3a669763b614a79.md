# Polygon

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class Polygon 地球表面的多边形。多边形可以是凸面或凹面，它可以跨越180子午线并且可以具有未填充的孔。在调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)类的[addPolygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582#section342720397412)方法时会返回该类型的实例。|

#### setZIndex

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setZIndex(float zIndex) 设置多边形的z指数。z指数指的是多边形的叠加顺序，具有较大z指数的多边形会绘制在具有较小z指数的多边形上，具有相同z指数的叠加顺序为元素添加的先后顺序。 说明： 数量限制：添加Circle和Polygon的总数乘以2加上添加Polyline和GroundOverlay的总数不超过1450，否则会出现图形叠加错误。|

Parameters  

|Name|Description|
|:-----|:----------------------|
|zIndex|z指数，即多边形的叠加顺序。默认的z指数是0。|
