# Overview

集成ads-installreferrer SDK后，可使用相应API，获取转化跟踪参数。

## Interface Summary

|Interface|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------|
|[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerstatelistener-0000001050064948)|建立服务链接的回调接口；当与服务完成建立时，将调用此侦听器的onInstallReferrerSetupFinished(int)方法。|
|[OnDeeplinkAcquiredListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ondeeplinkacruiredlistener-0000001361522561)|获取深度链接的监听器；当调用request()方法时，将调用此监听器的launchDeeplink(Uri)方法。|

## Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------|
|[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-0000001050064946)|获取转化跟踪参数的抽象类。|
|[InstallReferrerClient.InstallReferrerResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerresponse-0000001382833793)|转化跟踪参数的响应。|
|[InstallReferrerClient.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-builder-0000001050066895)|用于创建InstallReferrerClient实例的Builder类。|
|[ReferrerDetails](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/referrerdetails-0000001050066897)|描述转化跟踪参数。|
|[DeeplinkClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/deeplinkclient-0000001361239353)|获取深度链接对象。|
