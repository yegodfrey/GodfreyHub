# HuaweiIdAuth

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Const Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|const HuaweiIdAuth 帐号授权登录、静默登录、退出、取消授权接口实现对象。应用通过[HuaweiIdAuthManager.getAuthApi](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthmanager-0000001063840255#section169782218282)获取接口对象调用相关接口。|

#### getSignInIntent

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|getSignIntent([HuaweiIdAuthParams](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthparams-0000001064189912) signInOption) 帐号授权登录。|

Parameters  

|Name|Description|
|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|signInOption|帐号登录参数对象，通过[HuaweiIdAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthparamshelper-0000001064109899)创建。|

Returns  

|Type|Description|
|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Promise\<string\>|返回登录成功帐号信息的异步回调。 * 若回调成功，可通过[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-authhuaweiid-0000001064638400)中的方法获取帐号信息。 * 若回调失败，可通过异步回调结果获取错误码。|
