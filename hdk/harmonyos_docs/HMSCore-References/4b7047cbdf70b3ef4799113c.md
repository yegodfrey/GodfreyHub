# HWMapUtils

#### 概述

3857投影经纬度与WGS84经纬度转换工具类。  

#### 构造函数

|函数|描述|
|:--------------------|:--------|
|HWMapJsSDK.HWMapUtils|经纬度转换工具类。|

#### 方法

|方法|描述|参数类型|返回值|
|:-----------------------|:------------------|:-------------------------|:-------------------------|
|epsgFromLatLng(latLng)|WGS84经纬度转3857投影经纬度。|{lng: Number, lat: Number}|\[lng, lat\]|
|epsgToLatLng(coordinate)|3857投影经纬度转WGS84经纬度。|\[lng, lat\]|{lng: Number, lat: Number}|
