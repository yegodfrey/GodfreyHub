# DarkModeStatus

* 支持的场景：手机。
* 支持的OS：EMUI 10.0及以上，Android 10.0及以上。

|Interface Info|
|:------------------------------------------------------------------------------------------------------|
|public interface DarkModeStatus 设备的深色模式状态，可以从该类中调用[isDarkModeOn](#section125251461688)方法判断当前深色模式开关是否打开。|

## Public Method Summary

|Qualifier and Type|Method Name|
|:-----------------|:-------------------------------------|
|boolean|[isDarkModeOn](#section125251461688)()|

## Public Methods

### isDarkModeOn

|Method|
|:-----------------------------------------------------|
|public abstract boolean isDarkModeOn() 判断当前深色模式开关是否打开。|

**Returns**

|Type|Description|
|:------|:------------------------------------------|
|boolean|返回true，代表设备打开了深色模式开关；返回false，代表设备关闭了深色模式开关。|
