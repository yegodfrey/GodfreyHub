# 参数描述

|参数|是否必选|参数类型|描述|
|:------------------|:---------|:----------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------|
|passVersion|创建模板时必填|String|钱包对象版本，开发者可以依据此确定钱包对象的版本信息，最长64个字符，只能是字母、数字和（.）、（-）、（_）。|
|organizationName|创建模板时必填|String|商户名称，最长64个字节。|
|passTypeIdentifier|创建模板和实例时必填|String|服务号，需要开发者到华为AGC网站申请。|
|passStyleIdentifier|创建模板和实例时必填|String|模板ID，即modelId。在同一个appId下唯一。长度不超过64个字符，只能是字母、数字和（.）、（-）、（_）。|
|organizationPassId|创建实例时必填|String|卡券在开发者服务器中的卡号。在同一个appId下唯一。长度不超过64个字符，只能是字母、数字和（.）、（-）、（_）。|
|serialNumber|创建实例时必填|String|卡券在华为钱包服务器中的卡号，即instanceId。在同一个appId下唯一。长度不超过64个字符，只能是字母、数字和（.）、（-）、（_）。可以使用与organizationPassId相同的值。|
|fields|否|[Fields](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fields-0000001050158368)|卡券展示信息。|
|linkDevicePass|否|[LinkDevicePass](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/linkdevicepass-0000001050160329)|此参数用于使能卡券的NFC能力。如果一个卡券对象的linkDevicePass参数非空，则此卡券具有NFC能力。否则，此卡券不能使用NFC功能。|

示例

```codeblock
{
    "passVersion": "2.0",
    "organizationName": "Huawei",
    "passTypeIdentifier": "hwpass.com.huawei.wallet.loyalty",
    "passStyleIdentifier": "loyaltyModel",
    "organizationPassId": "356688116",
    "serialNumber": "23234314194",
    "fields": {},
    "linkDevicePass": {}
}
```
