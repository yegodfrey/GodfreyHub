# 错误码

|错误码|值|描述|解决方法|
|:-----------------------------------------------------|:---|:------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
|GamesStatusCodes.GAME_STATE_SUCCESS|0|成功。|-|
|GamesStatusCodes.GAME_STATE_FAILED|-1|通用游戏接口失败返回码。|-|
|GamesStatusCodes.GAME_STATE_ERROR|7001|一般错误。|-|
|GamesStatusCodes.GAME_STATE_NETWORK_ERROR|7002|网络错误、应用市场服务地设置错误。|检查网络、应用市场客户端服务地设置是否正确。|
|GamesStatusCodes.GAME_STATE_USER_CANCEL|7003|用户取消操作。|请根据场景适时地重新触发接口调用。|
|GamesStatusCodes.GAME_STATE_USER_CANCEL_LOGIN|7004|用户取消登录。|用户取消登录，提醒用户重新登录。|
|GamesStatusCodes.GAME_STATE_PARAM_ERROR|7005|请求参数错误。|请检查接口入参，如果检查正确，请联系华为技术支持定位。|
|GamesStatusCodes.GAME_STATE_NO_SUPPORT|7006|当前区域不提供游戏服务。|请检查玩家所在的国家和地区是否支持游戏服务。|
|GamesStatusCodes.GAME_STATE_NOT_SUPPORT|7010|当前设备不支持。|当前设备不支持硬件注册能力，可以忽略。|
|GamesStatusCodes.GAME_STATE_PARAM_NULL|7011|入参为空。|请检查接口入参是否为空，如果检查正确，请联系华为技术支持定位。|
|GamesStatusCodes.GAME_STATE_CALL_REPEAT|7012|重复调用接口。|10秒钟内不要重复调用相同的接口。|
|GamesStatusCodes.GAME_STATE_NOT_LOGIN|7013|未登录华为帐号。|请先调用华为帐号授权接口，引导用户完成帐号授权。|
|GamesStatusCodes.GAME_STATE_DISAGREE_PROTOCOL|7014|用户不同意联运隐私协议。|不允许用户进入游戏。|
|GamesStatusCodes.GAME_STATE_REALNAME_REGISTER|7016|已经实名。|用户已经完成实名认证，不需要重复调用。|
|GamesStatusCodes.GAME_STATE_REGISTER_FAIL|7017|系统设置错误（游戏注册失败）。|请检查参数后，重新调用，如果检查正确，请联系华为技术支持定位。|
|GamesStatusCodes.GAME_STATE_NOT_INIT|7018|未调用初始化接口。|未调用init接口，请在调用游戏服务接口之前，先调用初始化接口。|
|GamesStatusCodes.GAME_STATE_ACCOUNT_NOT_MATCH|7019|应用内登录帐号与系统当前帐号不一致。|华为帐号发生切换，请重新调用华为帐号授权接口完成用户授权，重新登录游戏。|
|GamesStatusCodes.GAME_STATE_REALNAME_CANCEL|7021|用户取消实名认证服务。|用户取消实名认证，无法继续当前接口调用，请给出友好提示，引导用户重新触发接口调用，完成实名认证。|
|GamesStatusCodes.GAME_STATE_REALNAME_NOT_SUPPORT|7022|该用户为成年用户或未实名，不支持实名时长统计功能。|请检查用户是否已实名，未实名则引导用户完成实名认证。已成年建议直接放通。|
|GamesStatusCodes.GAME_STATE_CALL_FREQUENTLY|7023|接口调用过于频繁。|获取游戏玩家基本信息接口调用过于频繁，请适时适量调用接口，在非必要场景可以使用缓存数据。|
|GamesStatusCodes.GAME_STATE_APPGALLERY_NOT_SUPPORT|7024|无安装应用市场APK或当前应用市场版本不支持。|引导用户安装或者升级华为应用市场客户端到最新版本。|
|GamesStatusCodes.GAME_STATE_ACHIEVEMENT_NONEXIST|7201|成就或事件未找到。|请检查成就ID或事件ID是否和AppGallery Connect中创建的成就ID或事件ID一致。如果检查正常，请联系华为技术支持定位。|
|GamesStatusCodes.GAME_STATE_RINGINGS_NOT_FOUND|7215|未找到排行榜数据。|请检查排行榜ID是否和AppGallery Connect上配置的ID一致。如果一致，请联系华为技术支持定位。|
|GamesStatusCodes.GAME_STATE_GAMESERVICE_AUTHOR_FAILURE|7218|游戏服务授权失败，用户未同意应用市场协议。|忽略，SDK会自行拉起应用市场协议。|
|JosStatusCodes.JOS_PRIVACY_PROTOCOL_NO_AGREE|7400|用户当前还未同意联运隐私协议。|调用[init](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)接口引导用户同意协议。|
|JosStatusCodes.JOS_PRIVACY_PROTOCOL_REJECTED|7401|用户在联运隐私协议界面拒绝同意联运隐私协议。|不允许用户进入游戏。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
