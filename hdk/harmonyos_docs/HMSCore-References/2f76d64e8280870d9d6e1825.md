# ppsads.createNativeAd(object)

## 概述

创建原生广告对象，返回类型：[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814)。

## 参数

|参数|是否必选|类型|描述|
|:-------------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|slotId|是|String|广告位ID。广告位ID为null或不填时通过ppsads.createNativeAd方法创建广告对象为null。|
|type|否|number|广告类型。 * NATIVE：普通的信息流广告 * ICON：应用图标类广告 默认值：NATIVE，详细取值请参见[AdType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section143191838283)。|
|deviceType|否|number|设备类型。 * PHONE：手机 * TABLET：平板 默认值：PHONE，详细取值请参见[DeviceType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section545534453916)。|
|creativeTypes|否|array|广告素材的详细创意类型。当广告类型type为NATIVE时使用。 参数取值请参见[DetailedCreativeType与CreativeType对应关系](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section20290135814019)。|
|mediaAspect|否|number|素材的图片比例。参数取值请参见[MediaAspect](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section5198202074217)。|
|mediaDirection|否|number|素材的图片方向。参数取值请参见[MediaDirection](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section103913114511)。|
|width|否|number|广告宽度，单位：px，配合mediaAspect参数使用。 当mediaAspect=ASPECT_CUSTOM_SIZE时有效，取值：广告的宽度或者常量-1。|
|height|否|number|广告高度，单位：px，配合mediaAspect参数使用。 当mediaAspect=ASPECT_CUSTOM_SIZE时有效，取值：广告的高度或者常量-2。|

### width与height取值限制

|width|height|描述|
|:-----|:-----|:------------------------------------------------------------------------------------------------------------------|
|-1|-2|智能广告尺寸。 宽度为页面的宽度，高度根据页面的高度得到合适的广告高度。 * 页面高度> 720px，广告高度取值为90px。 * 页面高度> 400px 且 ≤ 720px，广告高度取值为50px。 * 其他情况取值为32px。|
|number|number|正常的广告尺寸。|
