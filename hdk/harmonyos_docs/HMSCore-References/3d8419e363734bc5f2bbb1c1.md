# Files:create.content

#### 功能介绍

创建并上传文件（content方式）。  

#### 场景描述

Files.create.content接口实现一次性上传不超过20M的文件，并返回文件元数据。  

#### 使用约束

* Body为上传文件的二进制内容，大小不超过20M。
* fields填\*时，drive#file 结构中sharer、sharedWithMeTime、hasShared、capabilities、permissions、permissionIds不返回。
* Scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.appdata
* https://www.huawei.com/auth/drive.appfile  

#### 接口原型

|承载协议|HTTP POST|
|接口方向|开发者服务器-\>华为云空间服务器|
|接口URL|https://driveapis.cloud.huawei.com.cn/upload/drive/v1/files?uploadType=content|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------|

    public static void main(String[] args) throws IOException {

        // 创建并上传文件
        JSONObject fileInfo = filesCreateContent(url, access_token);
        System.out.println(fileInfo.toJSONString());
    }

    private static JSONObject filesCreateContent(String url, String access_token) throws IOException {
        StringBuilder stringBuilder = new StringBuilder("");
        stringBuilder.append("?").append("fields=*").append("&").append("uploadType=content");
        HttpPost httpPost = new HttpPost(url + stringBuilder);
        httpPost.setHeader("Authorization","Bearer " + access_token);
        httpPost.setHeader("Content-Type", "image/jpeg");
        httpPost.setHeader("Accept", "application/json");
        // 创建文件
        File file = new File("C:\\Users\\z00502234\\Pictures\\Saved Pictures\\8.jpg"); // 该路径修改为您本地的路径
        if(!file.exists()){
            System.out.print("File not exist");
            return null;
        }
        HttpEntity entity = new FileEntity(file);
        httpPost.setEntity(entity);


        CloseableHttpResponse response = HttpClientUtil.getClient().execute(httpPost);

        try {
            HttpEntity responseEntity = response.getEntity();
            String ret = responseEntity != null ? EntityUtils.toString(responseEntity) : null;
            JSONObject jsonObject = (JSONObject) JSON.parse(ret);
            EntityUtils.consume(responseEntity);
            return jsonObject;
        }finally {
            response.close();
        }
    }
