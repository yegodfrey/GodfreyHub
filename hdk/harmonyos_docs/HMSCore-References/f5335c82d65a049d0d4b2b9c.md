# saveHealthData：将设备测量数据存储到运动健康平台

接口原型

public void saveHealthData(String data, String function)

方法描述：将设备测量数据存储到运动健康平台。当前支持JS将体温、血氧、体重、血糖、血压、跳绳数据存储到运动健康。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-----------------------------------|:---|
|data|String|测量数据，参考下方举例。|M|
|function|String|运动健康返回存储结果的回调函数，该回调函数有一个参数，详情参见响应参数。|M|
[表1 请求参数]

data参数是一个json字符串，是设备测量的结果

请求示例：

```
parseData: function (data) {
    // 解析第a1位为b1
    let b1 = data.substr(a1, 1);
    if (解析成功) {
        this.tempData = b1;
        //保存测量接口到数据平台
        var dataParams = {
            "type": this.globalData.TEMPERATURE_TYPE,
            "value": {
                "temp": this.tempData
            }
        };
        window.saveFunctionCallback = this.saveFunctionCallback;
        window.hilink.saveHealthData(JSON.stringify(dataParams), "saveFunctionCallback");
    }
}
```

数据举例：

比如体温测量结果为36.5，则构造以下json字符串传递给参数data

```
{
    "type"：2104,
    "dataTypeName": "com.huawei.instantaneous.body.temperature",
    "startTime":1488297600000,
    "endTime":1488297600000,

        "temp":36.5
```
