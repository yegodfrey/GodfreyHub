# DailySituation

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class [DailySituation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/dailysituation-0000001050735617) implements Parcelable 白天或者晚上的天气情况。包括天气ID(CN)、风速、风级、风向。|

## Public Methods

### getCnWeatherId

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public int getCnWeatherId() 获取CN天气ID(cnWeatherId)。CN天气ID表示的是当前的天气，每个值都对应不同的天气，例如0表示晴，1表示多云，7表示小雨。更多天气ID对应的天气信息请参见[CNWeatherId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/cn-weatherid-4-0000001050165072)。|

**Returns**

|Type|Description|
|:---|:----------|
|int|CN天气ID。|

### getWindDir

|Method|
|:------------------------------------------------------------------------------------------------------------------------|
|public String getWindDir() 获取风向，风向值是"NE"（东北风向）、"E"（东风向）、"SE"（东南风向）、"S"（南风向）、"SW"（西南风向）、"W"（西风向）、"N"（北风向）和"NW"（西北风向）八个值之一。|

**Returns**

|Type|Description|
|:-----|:-------------------------------------------------------------------------------------------|
|String|风向，风向值是"NE"（东北风向）、"E"（东风向）、"SE"（东南风向）、"S"（南风向）、"SW"（西南风向）、"W"（西风向）、"N"（北风向）和"NW"（西北风向）八个值之一。|

### getWindLevel

|Method|
|:----------------------------------------------------------------------|
|public int getWindLevel() 获取风级。风级，实时天气的风级，值区间为0~17，0国内版本表示微风，国外版本0表示无风。|

**Returns**

|Type|Description|
|:---|:---------------------------------------|
|int|风级，实时天气的风级，值区间为0~17，0国内版本表示微风，国外版本0表示无风。|

### getWindSpeed

|Method|
|:--------------------------------------|
|public int getWindSpeed() 获取风速，单位：km/h。|

**Returns**

|Type|Description|
|:---|:----------|
|int|风速，单位：km/h。|
