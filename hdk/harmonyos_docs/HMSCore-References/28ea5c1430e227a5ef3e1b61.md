# 错误码

|错误码|描述|解决方法|
|:---|:------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|2002|应用尚未授权，需要授权。该错误码一般在silentSignIn接口中出现。|使用[HuaweiIdAuth.getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185#section169782218282)进行授权登录。|
|2003|调用方法的参数不合法，一般是方法使用不当。|请检查传入的参数。|
|2005|授权过程中发生网络错误。|请检查当前设备所处的网络环境是否通畅，请网络连通后重试。|
|2008|独立授权时AccessToken失效。|业务需要重新获取有效AccessToken。|
|2009|请求华为帐号服务器失败。|-|
|2012|用户点击返回键，取消登录。|-|
|2013|正在登录中，请不要再次登录。|等待授权登录结果或取消授权登录。|
|2026|儿童帐号不支持独立授权。|-|
|2032|HMS Core没有安装。|请确保安装HMS Core。|
|2033|当前HarmonyOS为单框架，不支持加载SDK。|请切换成双框架版本HarmonyOS系统。|
|2034|SDK初始化失败。|出现此错误码时，请重试2至3次。如果还是无法成功，表示当前ROM无法适配，请更换ROM后进行调测。|
|2035|获取AccountAuthService服务失败。|出现此错误码时，请重试2至3次。如果还是无法成功，表示当前ROM无法适配，请更换ROM后进行调测。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
