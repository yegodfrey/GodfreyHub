# Overview

包含Analytics SDK预置事件接口、事件参数接口、用户属性接口以及上报策略枚举类。  

#### Interface Summary

|Interface|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------|
|[HAEventType](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-haeventtype-0000001204636027)|此接口提供了所有预定义事件的事件ID常量。|
|[HAParamType](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-haparamtype-0000001204476053)|此接口提供了所有预定义参数的参数ID常量。|
|[HAUserProfileType](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hauserprofiletype-0000001159634578)|此接口提供了所有预定义用户属性名称的常量。|
|[HAReportPolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-reportpolicy-0000001204754589)|此接口提供数据自动上报的策略。|
|[HALog](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-halog-0000001159444446)|此接口提供了日志级别的常量。|
