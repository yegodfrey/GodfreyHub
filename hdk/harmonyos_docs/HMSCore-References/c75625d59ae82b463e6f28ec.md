# WifiBarrier

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class [WifiBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifibarrier-0000001055262759) extends Object Wi-Fi围栏，包括keeping（Wi-Fi状态驻留围栏）、connecting（Wi-Fi连接围栏）、disconnecting（Wi-Fi断连围栏）、enabling（WLAN开启围栏）、disabling（WLAN关闭围栏）五类围栏。当围栏被指定了BSSID和SSID，且HMS Core未打开位置权限（android.permission.ACCESS_FINE_LOCATION）或设备未打开GPS时，无法正确判断围栏状态。 开发者应当提醒用户手机WiFi状态可能被App监控。|

## Public Methods

### keeping(int wifiStatus)

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) keeping(int wifiStatus) Wi-Fi状态驻留围栏，开发者添加打开WLAN、关闭WLAN、连接Wi-Fi、断连Wi-Fi四种状态的Wi-Fi状态驻留围栏后，当手机WLAN保持为某状态时，此围栏状态为TRUE并触发围栏事件上报。|

**Parameters**

|Name|Description|
|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|wifiStatus|Wi-Fi状态。 * [ENABLED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section144731117208)：已开启WLAN。 * [DISABLED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section5841122206)：未开启WLAN。 * [CONNECTED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section828413582511)：已连接Wi-Fi。 * [DISCONNECTED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section845115991915)：未连接Wi-Fi。|

**Returns**

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|情景感知围栏。|

**Throws**

|Name|Description|
|:-----------------------|:--------------------------------------------------------------|
|IllegalArgumentException|参数不合法（此时wifiStatus不为ENABLED、DISABLED、CONNECTED或DISCONNECTED）异常。|

### keeping(int wifiStatus, String bssid, String ssid)

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) keeping(int wifiStatus, String bssid, String ssid) Wi-Fi状态驻留围栏，开发者添加打开WLAN、关闭WLAN、连接Wi-Fi、断连Wi-Fi四种状态的Wi-Fi状态驻留围栏后，当手机WLAN保持为某状态时，此围栏状态为TRUE并触发围栏事件上报。|

**Parameters**

|Name|Description|
|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|wifiStatus|Wi-Fi状态。 * [ENABLED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section144731117208)：已打开WLAN。 * [DISABLED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section5841122206)：已关闭WLAN。 * [CONNECTED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section828413582511)：已连接Wi-Fi。 * [DISCONNECTED](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/wifistatus-0000001055461316#section845115991915)：未连接Wi-Fi。|
|bssid|如果wifiStatus为CONNECTED或DISCONNECTED，可以指定Wi-Fi围栏的BSSID（Wi-Fi来源的物理地址）；当该值为null时，表示任意BSSID；如果wifiStatus为ENABLED或者DISABLED，该BSSID无效。|
|ssid|如果wifiStatus为CONNECTED或DISCONNECTED，可以指定Wi-Fi围栏的SSID（Wi-Fi来源的名称标识）；当该值为null时，表示任意SSID；如果wifiStatus为ENABLED或者DISABLED，该SSID无效。|

**Returns**

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|情景感知围栏。|
