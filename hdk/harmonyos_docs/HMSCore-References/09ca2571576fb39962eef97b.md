# deleteMultipleHealthData: 从运动健康平台删除多条测量数据

接口原型

public void deleteMultipleHealthData(String data, String function)

方法描述：将多条设备测量数据从运动健康平台删除。当前支持JS删除血糖和跳绳数据。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-----------------------------------|:---|
|data|String|要删除的数据，参考下方举例。|M|
|function|String|运动健康返回存储结果的回调函数，该回调函数有一个参数，详情参见响应参数。|M|
[表1 请求参数]

data参数是一个json字符串，是需要删除数据的结构
