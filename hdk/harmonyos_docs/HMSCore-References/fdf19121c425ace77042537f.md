# HMSScanFormatTypeCode

二维码与一维码的类型，整型数据。支持13种码类型：EAN-8、EAN-13、UPC-A、UPC-E、Codabar、Code 39、Code 93、Code 128、ITF14、QR、DataMatrix、PDF417、Aztec。
