# Overview

此目录下的所有类均为调用Health Service Kit接口的返回类，开发者可以在调用API接口的回调中使用。

## Class Summary

|Name|Description|
|:--------------------------------------------------------------------------------------------------------------------------|:----------------------|
|[ActivityRecordReply](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordreply-0000001050093245)|读取ActivityRecord结果的响应类。|
|[HealthKitAuthResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/auth-result-0000001098318552)|登录授权流程返回结果类。|
|[HealthRecordReply](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/healthrecordreply-0000001118588564)|读取HealthRecord结果的响应类。|
|[ReadReply](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/readreply-0000001050093471)|数据读取响应类。|
