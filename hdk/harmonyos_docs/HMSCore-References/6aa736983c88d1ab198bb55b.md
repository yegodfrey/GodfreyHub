#### getPaymentSignature

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getPaymentSignature() 该方法返回使用IAP私钥签署订单数据（[getPaymentData](#section17492205324115)方法返回的字符串）生成的签名字符串，签名算法为SHA256WithRSA。 说明： 仅在使用[createPurchaseIntentWithPrice](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16712634155213)接口时返回，使用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)接口时不返回。 应用在收到该签名字符串后，请参见[对返回结果验签](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-signature-returned-result-0000001050033088)对订单数据的JSON字符串校验签名，成功后再继续拉起IAP收银台。|

Returns  

|Type|Description|
|:-----|:------------------------------------------------------------------------------------------|
|String|使用IAP私钥签署订单数据（[getPaymentData](#section17492205324115)方法返回的字符串）生成的签名字符串。签名算法为SHA256WithRSA。|
