# 接口使用说明

HTTP REST接口定义如下：

**协议**：HTTPS

**HTTPS请求头**：

请求参数请参见[公共参数说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/public-parameter-0000001050202130)。

Content-type：application/json

Authorization：Bearer ${access_token}，access_token获取请参见[开放平台鉴权-授权码模式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/open-platform-oauth-0000001053629189#section1022911426469)。

x-client-id：开放联盟分配的应用标识，服务端可以基于其进行灰度路由，建议携带。

x-version：接口调用方的软件版本号，即当前客户端版本号，建议携带。

x-caller-trace-id：请求跟踪id，用于串联服务调用方与服务端整体请求链条，建议携带。

**URL格式**：

https://health-api.cloud.huawei.com/healthkit/v2/{resourcesSet}/{resourceId}?{param=xxx}

URL中各部分的说明如下：

|字段|描述|格式|
|:-----------|:-----|:-----------------------------|
|Method|HTTP方法|POST、PUT、PATCH、GET、DELETE|
|resourcesSet|资源集合|例如：dataCollectors（数据采集器集合）|
|resourceId|资源ID|例如：dataCollectorId（指定的数据采集器标识）|
|param|查询参数|例如：limit（单次分页查询长度）|
