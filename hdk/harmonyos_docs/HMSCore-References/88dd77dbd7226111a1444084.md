# HMSHealthKitDeviceType

以下HMSHealthKitDeviceType里的常量为Health Service Kit已定义的常用的设备类型常量。  

|Type|Name|Description|
|:-----|:--------------------------|:------------------|
|String|TYPE_UNKNOWN|取值为"0"，表示未知设备类型|
|String|TYPE_PHONE|取值为"1"，表示手机设备类型|
|String|TYPE_SCALES|取值为"2"，表示智能体脂秤设备类型|
|String|TYPE_SMART_WATCH|取值为"3"，表示智能穿戴设备类型|
|String|TYPE_SMART_BAND|取值为"4"，表示智能手环设备类型|
|String|TYPE_SMART_EARPHONE|取值为"5"，表示智能耳机设备类型|
|String|TYPE_BLOOD_GLUCOSE_MONITOR|取值为"6"，表示血糖仪设备类型|
|String|TYPE_BLOOD_PRESSURE_MONITOR|取值为"7"，表示血压仪设备类型|
|String|TYPE_HEART_RATE_MONITOR|取值为"8"，表示心率计设备类型|
|String|TYPE_ECG_EQUIPMENT|取值为"9"，表示心电设备类型|
|String|TYPE_THERMOMETERS|取值为"10"，表示体温计设备类型|
|String|TYPE_OXIMETER|取值为"11"，表示血氧仪设备类型|
|String|TYPE_TREADMILL|取值为"12"，表示跑步机设备类型|
|String|TYPE_ELLIPTICAL_MACHINE|取值为"13"，表示椭圆机设备类型|
|String|TYPE_EXERCISE_BIKE|取值为"14"，表示动感单车设备类型|
|String|TYPE_ROWING_MACHINE|取值为"15"，表示划船机设备类型|
|String|TYPE_WALKING_MACHINE|取值为"16"，表示步行机设备类型|
|String|TYPE_ROPE_SKIPPING|取值为"17"，表示跳绳设备类型|
|String|TYPE_THIRD_WATCH|取值为"18"，表示非华为手表设备类型|
