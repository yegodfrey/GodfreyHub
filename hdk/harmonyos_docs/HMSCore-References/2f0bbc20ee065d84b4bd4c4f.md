# Overview

集成Push SDK后，可使用相关API，获取接入推送服务所需Token和打点上报等。

## Class Summary

|Class|Description|
|:----------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------|
|[HmsInstanceId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-hmsinstanceid-0000001063681650)|本类提供了获取AAID（匿名应用ID）的方法以及接入推送服务所需Token的获取方法。|
|[EventReport](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-eventreport-0000001063403418)|本类提供了上报通知消息事件的功能。|
