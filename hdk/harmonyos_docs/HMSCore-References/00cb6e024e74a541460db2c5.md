# DrawingManager

#### 概述

DrawingManager提供绘制多边形、矩形、圆形和折线等形状的能力。  

#### 构造函数

|函数|描述|
|:------------------------------|:-----------------------------------------------------------------------------|
|drawing.DrawingManager(options)|options：设置DrawingManager属性，详情见[DrawingManagerOptions](#section20368181194214)。|

#### 方法

|方法|描述|参数类型|返回值|
|:--------------------------|:--------------------|:-------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
|getDrawingMode()|获取DrawingManager绘图模式。|-|[OverlayType](#section20641155922617)|
|getMap()|获取绑定的地图实例。|-|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|
|setDrawingMode(drawingMode)|设置DrawingManager绘图模式。|[OverlayType](#section20641155922617)|-|
|setMap(map,HWMapJsSDK)|绑定到地图。|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|-|
|setOptions(options)|设置DrawingManager选项。|[DrawingManagerOptions](#section20368181194214)|-|

#### DrawingManagerOptions

|参数|是否必选|参数类型|描述|
|:---------------------|:---|:-------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|boxOptions|否|[BoxOptions](#section278885317411)|设置矩形的自定义样式。|
|circleOptions|否|[CircleOptions](#section106498151455)|设置圆形的自定义样式。|
|drawingControl|是|Boolean|绘图控件是否启用。 * true：启用 * false：关闭 默认值为true。|
|drawingControlOptions|否|[DrawingControlOptions](#section10644114145012)|绘图控件显示选项。|
|drawingMode|否|[OverlayType](#section20641155922617)|绘图模式，指定地图覆盖物类型，默认None。|
|polygonOptions|否|[PolygonOptions](#section17210359194520)|设置多边形的自定义样式。|
|polylineOptions|否|[PolylineOptions](#section11826121619467)|设置折线的自定义样式。|
|map|否|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|地图实例。|
|markerOptions|否|[MarkerOptions](#section518782913460)|设置点的自定义样式。|
|onComplete|否|Function|绘制完成事件回调函数。 说明： 回调函数包含两个参数： * result：当前操作的图形对象。type为2，可以通过result.getInstance()获取HW Object实例，通过result.getObjectType()获取当前HW Object实例的类型（Marker、Circle、Polygon、Polyline）。 * type：绘制图形所使用的工具类型，1：OLOBJECT；2：HWOBJECT。|
|onChange|否|Function|形状改变事件回调函数。 说明： 回调函数包含两个参数： * result：当前操作的图形对象。type为2，可以通过result.getInstance()获取HW Object实例，通过result.getObjectType()获取当前HW Object实例的类型（Marker、Circle、Polygon、Polyline）。 * type：绘制图形所使用的工具类型，1：OLOBJECT；2：HWOBJECT。|
|selectedObjectType|否|[SelectedObjectType](#section95591011012)|指定使用HW Object还是OL Object绘制图形，默认HW Object。|
|showSelectedObjectType|否|Boolean|HW Object和OL Object选择框是否显示。 * true：显示 * false：隐藏 默认值为false。|

#### BoxOptions

|参数|是否必选|参数类型|描述|
|:-----------|:---|:------|:-------------------------------------------------|
|fillColor|否|String|用于设置颜色，表示填充颜色。默认为"#D8D8D8"。 支持以下颜色设置：十六进制：#ff0000|
|fillOpacity|否|Number|填充颜色的不透明度，取值范围：\[0, 1\]。 0：完全透明。 1：完全不透明。 默认值为0.6。|
|strokeColor|否|String|用于设置颜色，表示边框颜色，默认为"#969696"。 支持以下颜色设置：十六进制：#ff0000|
|strokeWeight|否|Number|线宽，单位：像素，默认为4像素。|
|clickable|否|Boolean|是否允许点击。 true：允许 false：不允许 默认值为true。|
|editable|否|Boolean|是否允许编辑。 true：允许 false：不允许 默认值为false。|

#### DrawingControlOptions

|参数|是否必选|参数类型|描述|
|:-----------|:---|:---------------------------------------------|:----------------------------------------------------------|
|drawingModes|否|Array\<[OverlayType](#section20641155922617)\>|绘图模式，指定绘图控件的排列顺序。小手图标（对应值为null）排列顺序无需设置。默认排序：点、圆、多边形、折线、矩形。|
|position|否|[ControlPosition](#section1456133112710)|位置ID，指定控件在地图上的位置，默认TOP_CENTER。|

#### OverlayType

|常量字段|描述|
|:----------|:---------------------|
|NONE|不设置绘图模式。|
|POINT|指定DrawingManager创建点。|
|CIRCLE|指定DrawingManager创建圆。|
|POLYGON|指定DrawingManager创建多边形。|
|LINE_STRING|指定DrawingManager创建折线。|
|BOX|指定DrawingManager创建矩形。|

#### ControlPosition

|常量字段|描述|
|:------------|:--------------------|
|BOTTOM_CENTER|绘图控件位于底部居中。|
|BOTTOM_LEFT|绘图控件位于左下角。|
|BOTTOM_RIGHT|绘图控件位于右下角。|
|LEFT_CENTER|绘图控件位于左侧居中。|
|RIGHT_CENTER|绘图控件位于右侧居中。|
|TOP_CENTER|绘图控件位于顶部居中。|
|TOP_LEFT|绘图控件位于左上角，且依次向中间方向展示。|
|TOP_RIGHT|绘图控件位于右上角，且依次向中间方向展示。|

#### SelectedObjectType

|常量字段|描述|
|:-------|:---------------|
|HWOBJECT|指定使用HW Object绘制。|
|OLOBJECT|指定使用OL Object绘制。|
