# BehaviorBarrier

* 支持的场景：手机。
* 支持的OS：EMUI 9.1及以上。

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class [BehaviorBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-behaviorbarrier-0000001050164122) extends Object 活动状态检测围栏，包括活动开始、活动结束和活动进行中的围栏。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-------------------------------------------------------------------------|
|static int|[BEHAVIOR_IN_VEHICLE](#section184431125125914) 表示用户在开车状态。|

|static int|[BEHAVIOR_ON_FOOT](#section8388152165911) 表示用户在行走或跑步状态。|

|static int|[BEHAVIOR_STILL](#section153552181404) 表示用户在静止状态。|

## Public Methods

### keeping

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)keeping(int... behaviorTypes) 活动状态进行中围栏，添加指定活动状态（[BEHAVIOR_UNKNOWN](#section9381524803)除外）的围栏后，当用户正在进行以上该类活动时，此围栏状态为TRUE并触发围栏事件上报。 * 对于Android 10（API级别29）及以后的版本需要添加android.permission.ACTIVITY_RECOGNITION权限。 * 对于Android 9（API级别28）的版本需要添加com.huawei.hms.permission.ACTIVITY_RECOGNITION权限。|

**Parameters**

|Name|Description|
|:------------|:-----------|
|behaviorTypes|一个或多个活动类型常量。|

**Returns**

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|情景感知围栏。|

**Throws**

|Name|Description|
|:-----------------------|:-------------------------------------------------------------------------|
|IllegalArgumentException|参数不合法（当behaviorTypes为空或为无效的数值，或为[BEHAVIOR_UNKNOWN](#section9381524803)）异常。|
