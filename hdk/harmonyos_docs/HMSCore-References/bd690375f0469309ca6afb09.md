# 错误码

|错误码|值|描述|解决方法|
|:-------------------------------------------|:----|:-------------------|:------------------------|
|SERVICE_NOT_EXIST|101|请求服务不存在|请检查请求服务是否存在|
|SERVICE_RESPONSE_ERROR|102|请求服务响应错误|请联系服务侧进行定位|
|ERROR_CONNECTION|105|请求访问超时|请检查网络是否正常|
|INSUFFICIENT_PRIVILEGES|106|无权限访问此服务|请检查权限|
|OVER_QUOTA|108|请求超出配额|请按照服务配额控制每条的调用次数|
|INVALID_USER_KEY|109|用户key非法或过期|请保证秘钥有效性|
|UNKNOWN_ERROR|150|未知错误|-|
|INVALID_REQUEST|10007|起终点无归属国家，或服务错误|请确认传入点是否有归属国家，如有归属国家请稍后重试|
|INVALID_REQUEST|10008|路径数据不存在|查询的路径不存在|
|INVALID_REQUEST|10009|不支持跨区进行路径规划|起点和终点不支持跨区|
|INVALID_REQUEST|10010|参数非法|请设置合理参数|

|INVALID_PARAMS|20200|参数不合法或缺失|请检查参数是否正确|
|START_MATCH_FAILED|20201|起点匹配失败|请检查参数是否正确|
|END_MATCH_FAILED|20202|终点匹配失败|请检查参数是否正确|
|ROUTE_PLAN_FAILED|20203|规划路线失败|请检查参数是否正确|
|DATA_ERROR|20204|缺少道路，可能是数据错误|请检查参数是否正确|
|START_END_TOO_CLOSE|20205|起终点距离太近|请检查参数是否正确|
|WAYPOINT_MATCH_FAILED|20206|途经点匹配失败|请检查参数是否正确|
|START_END_TOO_FAR|20207|距离过长，无法规划|请检查参数是否正确|
|INVALID_TASKID|20208|taskId不合法|请检查参数是否正确|
|DRIVING_HMM_MATCH_FAILED|20210|行中偏航HMM绑路失败|请检查参数是否正确|
|START_HEAP_EMPTY|20301|起点最小堆为空|请检查参数是否正确|
|END_HEAP_EMPTY|20302|终点最小堆为空|请检查参数是否正确|
|OVER_MAX_CALC_TIMES|20303|达到最大计算的次数|请联系服务侧进行定位|
|INVALID_RESULT|20304|无效结果|请联系服务侧进行定位|
|LOADING_FAILED|20305|加载失败|请联系服务侧进行定位|
|LOADING_FAILED|20306|内存问题|请联系服务侧进行定位|
|GEN_JSON_REAULT_FAILED|20307|生成json协议错误|请联系服务侧进行定位|
|OVER_MAX_INDEX_RESOURCE|20308|达到最大引用资源上线|请联系服务侧进行定位|
|NULL_POINTER|20309|指针为空|请联系服务侧进行定位|
|PROTOCAL_FAILED|20310|协议失败|请检查协议内容是否正确|
|RC_OUT_RANGE|20316|超出限制|请检查参数是否正确|
|PATH_PLANNING_TIMEOUT|20399|路径规划超时（驾车3秒，步/骑行20秒）|请联系服务侧进行定位|
|OTHER_ERROR|20400|其他错误导致|请联系服务侧进行定位|

|SUB_SERVER_ERROR_CODE_CYCLING_ROUTE_TOO_LONG|50001|距离过长，不规划（骑行）。|距离较远，建议您更换其他出行方式。|
