#### Sample Code

```
private void createFiles(Drive drive, String type, String filePath){
    try{
        // 创建文件夹
        File dir = new File().setFileName("testDir")
            .setMimeType("application/vnd.huawei-apps.folder");
        File directory = drive.files().create(dir).execute();
        // 创建(上传)文件
        FileContent fileContent = new FileContent(type, new java.io.File(filePath));
        File fileInfo = new File().setFileName("testFile");
        File mFile = drive.files().create(fileInfo, fileContent).execute();
    } catch (Exception e){
        Log.e(TAG, "createFiles error:" + e.getMessage());
    }
}
```
