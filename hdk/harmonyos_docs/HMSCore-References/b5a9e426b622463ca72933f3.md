# 上传采样数据

#### 功能介绍

上传数据采集器采集的采样数据。  

#### 场景描述

向指定的dataCollector下某个SampleSet中添加SamplePoint，在添加时SampleSet无需提前创建。  

#### 使用约束

* 先创建对应数据类型的数据采集器。
* 只允许创建该数据采集器的应用上传该数据采集器的采样数据，其他应用只支持读取该数据采集器的数据。  

#### 接口原型

|承载协议|HTTPS PATCH|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors/{dataCollectorId}/sampleSets/{sampleSetId}|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|----------------------------------------------------------------------------------------------------------|

#### 路径参数

|参数|参数类型|是否必选|描述|
|:--------------|:-----|:---|:--------------------------------------------------------------------------------------------------------------------------|
|dataCollectorId|String|是|数据采集器的唯一标识。|
|sampleSetId|String|是|采样数据集标识符。单位：纳秒。 格式："startTime-endTime"，其中：startTime/endTime必须是19位整数的时间戳。 对应时间范围是2000-01-01 00:00:00 \~ 2099-12-31 23:59:59。|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/json; charset=UTF-8|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body  

|参数|参数类型|是否必选|描述|
|:--------------|:------------------|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|dataCollectorId|String|是|数据采集器的唯一标识。 满足如下规则： 请求参数和请求体里dataCollectorId必须一致。|
|startTime|Long|是|所有采样点的最小开始时间。单位：纳秒|
|endTime|Long|是|所有采样点的最大结束时间。单位：纳秒|
|samplePoints|List\<SamplePoint\>|是|采样点SamplePoint列表。每次PATCH最多上传1000个SamplePoint。 请参见[SamplePoint](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section1420111125182)数据模型。|
|timeZone|String|是|时区信息。 格式：+0800。|

```
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***

{
  "dataCollectorId": "cmF3OmNvbnRpbnVvdXMuY2Fsb3JpZXMuYnVybnQEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg",
  "startTime": 1567267200000000000,
  "endTime": 1567440000000000000,
  "timeZone": "+0800",
  "samplePoints": [
    {

      "endTime": 1567310400000000000,

```

#### 响应参数

状态码为200时：

Response Header  

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

Response Body  

|参数|参数类型|是否必选|描述|
|:--------------|:------------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|startTime|Long|是|所有采样点的最小开始时间。单位：纳秒|
|endTime|Long|是|所有采样点的最大结束时间。单位：纳秒|
|dataCollectorId|String|是|数据采集器的唯一标识。 满足如下规则： 请求参数和请求体里dataCollectorId必须一致。|
|samplePoints|List\<SamplePoint\>|是|采样点SamplePoint列表。请参见[SamplePoint](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section1420111125182)数据模型。|
