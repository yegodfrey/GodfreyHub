# readBLECharacteristicValue：读取低功耗蓝牙设备的特征值

**接口原型**

public void readBLECharacteristicValue(String deviceId, String serviceId, String characteristicId, String function)

方法描述：读取低功耗蓝牙设备的特征值，以十六进制字符串返回。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:---------------|:-----|:--------------------------------------|:---|
|deviceId|String|蓝牙设备ID，通过接口getDeviceId()获取。|M|
|serviceId|String|蓝牙设备特征值对应服务的 UUID（不使用4位的简写，用完整写法的UUID）。|M|
|characteristicId|String|蓝牙设备特征值的 UUID（不使用4位的简写，用完整写法的UUID）。|M|
|function|String|读取低功耗蓝牙设备的特征值的回调函数，该回调函数有两个参数，详情参见响应参数。|M|
[**表1**请求参数]

**响应参数**

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:------------------|:---|
|data|String|返回特征值的值，以16进制字符串返回。|M|
|errCode|Number|错误码：0, 90001。|M|
[**表2**响应参数]
