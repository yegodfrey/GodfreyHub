# requestConnectionPriority：设置蓝牙设备请求连接的优先级

**接口原型**

public String requestConnectionPriority (int connectionPriority)

方法描述：设置蓝牙设备请求连接的优先级。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:-----------------|:---|:--------------------------------------------------------------------------------------------------|:---|
|connectionPriority|int|只能传0,1,2； 0表示 Bluetooth传输的默认值； 1表示请求高优先级，低延迟连接，以便快速传输BLE上的大量数据，传输完成请再次设置为0，降低功耗。 2表示请求低功耗，降低数据传输速率。|M|
[**表1**请求参数]

**响应参数**

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:-----------|:---|
|errCode|Number|错误码：0, 90001|M|
[**表2**响应参数]
