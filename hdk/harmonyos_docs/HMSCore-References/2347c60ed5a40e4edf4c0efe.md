#### getUnionId

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getUnionId() 如果授权时携带[setId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthparamshelper-0000001050438849#section8381635151315)指定的授权参数，该方法返回用户的UnionID，否则返回null。 UnionID是用户在开发者多个应用中的唯一标志，对于同一个用户，同一个开发者帐号下管理的不同应用，UnionID值相同。如果一个应用转移到另外一个开发者帐号后，UnionID值也会变化。当前固定长度46，最大允许长度64，需进行三倍冗余考虑，不推荐进行长度限制。 UnionID和OpenID的区别在于，如果开发者帐号下管理了多个应用，针对同一个帐号，不同的应用返回的OpenID值不同，但返回的UnionID相同。如果您需要在不同应用中共享同一个帐号的用户信息，可以使用UnionID作为用户标识。 使用UnionID作为用户标识需要满足以下所有条件，如果任一不满足则不会返回： * 应用集成Account SDK 4.0.4以及更高版本。 * HMS Core APK版本为4.0.4以及更高版本。 * 应用启用了UnionID。|

Returns  

|Type|Description|
|:-----|:-------------|
|String|获取用户的union ID。|
