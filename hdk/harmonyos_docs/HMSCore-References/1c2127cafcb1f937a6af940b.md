# Files:emptyRecycle

## 功能介绍

清空回收站。

## 场景描述

您的应用可以通过Files.emptyRecycle接口清空网盘或者应用数据的回收站。

## 使用约束

Scope至少包含下面其中一个：

* https://www.huawei.com/auth/drive.appdata
* https://www.huawei.com/auth/drive

## 接口原型

|承载协议|HTTP DELETE|
|-----|-----------------------------------------------------------------------|
|接口方向|开发者服务器->华为云空间服务器|
|接口URL|https://driveapis.cloud.huawei.com.cn/drive/v1/files/recycle|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 路径参数

|参数|是否必选|参数类型|描述|

|containers|否|string|drive或applicationData，如果同时清理网盘和应用数据回收站，则传入drive，application。传空，则默认为drive。|

## 调用示例

```screen
    public static void main(String[] args) throws IOException {
        // 设置请求地址和用户认证令牌
        String url = "https://driveapis.cloud.huawei.com.cn/drive/v1/files/recycle";
        String access_token = "CF3mIRW1G2Ljt8qvDpZuNW0d6lNHXNT4V61o3/XLHIbcI54AQSc8wx2XAuMvOFEFFIwIvWjGitFRV3UCXWiUnuzCx0b5x/4Pq31BJpo4HK46G8l+k2DuEQ==";
        // 清空回收站
        Boolean isTrash = false;
        isTrash = filesEmptyTrash(url, access_token);

        System.out.println(isTrash);
    }

    private static Boolean filesEmptyTrash(String url, String access_token) throws IOException {
        HttpDelete httpDelete = new HttpDelete(url);
        httpDelete.setHeader("Authorization","Bearer " + access_token);

        CloseableHttpResponse response = HttpClientUtil.getClient().execute(httpDelete);

        try {
            if(response.getStatusLine().getStatusCode() == 204){ // 清理状态成功返回204
                return true;
            }
            return false;
        }finally {
            response.close();
        }
    }
```
