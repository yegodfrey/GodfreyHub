# InfoWindow

定义[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699)对象点击时展示的信息窗口。  

#### Constants

|常量|类型|描述|
|:-----|:---------|:----|
|noText|InfoWindow|空信息窗。|

#### Properties

|名称|类型|描述|
|:----------|:------------|:------------------------------------------------------------------------------------------------------------------------|
|title|String?|[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699)的标题。默认为空。|
|snippet|String?|[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699)的snippet。|
|anchor|Offset|信息窗的偏移量。|
|onClick|VoidCallback?|点击信息窗时执行的函数。|
|onLongClick|VoidCallback?|长按信息窗时执行的函数。|
|onClose|VoidCallback?|关闭信息窗时执行的函数。|
