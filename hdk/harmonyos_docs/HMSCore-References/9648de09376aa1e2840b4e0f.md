# Localized

|参数|是否必选|参数类型|描述|
|:-------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|key|否|String|字段标识，在同一语言类型下key值唯一。与[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)中的localizedValue或localizedLabel对应。|
|language|否|String|语言类型|
|value|否|String|语言类型对应的值|

> 说明
>
> 多语言的字段在localized中统一提供，按照语言类型组织。具体字段展示时如果需要国际化。根据key值引用即可。语言类型遵循BCP 47语言标记。

示例

```codeblock
{
    "localized": [
        {
            "key": "localizedValue_merchantName",
            "language": "zh-cn",
            "value": "华为"
        },
        {
            "key": "localizedLabel_merchantName",
            "language": "zh-cn",
            "value": "公司名称"
        },
        {
            "key": "localizedValue_merchantName",
            "language": "en",
            "value": "Huawei"
        },
        {
            "key": "localizedLabel_merchantName",
            "language": "en",
            "value": "Company Name"
        }
    ]
}
```
