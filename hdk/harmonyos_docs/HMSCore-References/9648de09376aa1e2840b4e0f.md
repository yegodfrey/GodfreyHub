# Localized

|参数|是否必选|参数类型|描述|
|:-------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|key|否|String|字段标识，在同一语言类型下key值唯一。与[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)中的localizedValue或localizedLabel对应。|
|language|否|String|语言类型|
|value|否|String|语言类型对应的值|

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231120160812.85702977937085486802850362165243:50001231000000:2800:F7C14BD6328438947B6D665D3DB44DCFB59CE26DD6C6BF203F9E3239226C9ACB.png?needInitFileName=true?needInitFileName=true)  
多语言的字段在localized中统一提供，按照语言类型组织。具体字段展示时如果需要国际化。根据key值引用即可。语言类型遵循BCP 47语言标记。

示例

```
{
    "localized": [
        {
            "key": "localizedValue_merchantName",
            "language": "zh-cn",
            "value": "华为"
        },
        {
            "key": "localizedLabel_merchantName",
            "language": "zh-cn",
            "value": "公司名称"
        },
        {
            "key": "localizedValue_merchantName",
            "language": "en",
            "value": "Huawei"
        },
        {
            "key": "localizedLabel_merchantName",
            "language": "en",
            "value": "Company Name"
        }
    ]
}
```
