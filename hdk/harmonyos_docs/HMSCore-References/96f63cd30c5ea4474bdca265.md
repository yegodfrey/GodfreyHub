# 商户文件上传

## 功能介绍

文件统一管理接口，通过该接口可上传相关文件到华为服务器获取文件Id（objectId）。
> 说明
>
> 文件上传接口配置了流控规则，需要避免频繁调用接口及上传超大文件。

## 接口原型

|承载协议|HTTPS POST|
|-----|------------------------------------------------------------------------|
|接口方向|开发者服务器-> 华为支付服务器|
|接口URL|https://petalpay-developer.cloud.huawei.com.cn/api/v1/common/file/upload|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 请求参数

* **Request Header**

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|
  |PayMercAuth|是|String|取值为：[PayMercAuth](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-data-model-0000001538219104#section11744172016145)的JSON串|


* **Request Body**

  |参数|是否必填|参数类型|描述|
  |:----------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |fileExt|是|String|文件类型。图片格式支持JPG、PNG格式，最大2M。视频支持MP4、MOV、MKV，最大20M。文件支持PDF、ZIP，最大20M，ZIP压缩包内仅支持JPG，PNG，PDF，JPEG。|
  |fileName|是|String|文件名。|
  |fileContent|是|String|会话秘钥加密后的文件内容。 > 注意 > 敏感字段使用sessionKey加密，具体参见[敏感信息处理](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-sensitive-information-handle-0000001588934001)（需要使用base64编码），参考以下示例代码： > ```screen > public static String encryptSm4Gcm(byte[] plainData, String key) { >     try { >         SM4Cryptor cryptor = new SM4Cryptor.Builder().withAlg(Sm4Alg.SM4_GCM) >             .withKey(EncodeUtil.hex2Byte(key)).build(); >         return cryptor.encrypt().from(plainData).toBase64(); >     } catch (Exception e) { >         log.error("Sm4 GCM encrypt failed", e); >         return null; >     } > } > ```|

## 响应参数

* **Response Header**

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:----------------------------------|
  |Content-Type|是|String|取值为：application/json; charset=UTF-8|


* **Response Body**

  |参数|是否必填|参数类型|描述|
  |:---------|:---|:-----|:-----------------------|
  |resultCode|是|String|结果码，"000000"表示成功，其他表示失败。|
  |resultDesc|是|String|结果描述。|
  |subCode|否|String|业务错误码。|
  |subDesc|否|String|业务错误描述信息。|
  |sign|是|String|签名值。用于开发者对响应报文进行防篡改验证。|
  |objectId|是|String|文件Id。|


* **响应示例**


## 错误码

(**resultCode** 非400000的错误码请看[公共错误码说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-error-code-description-0000001589053741#section1187515498410))

|**resultCode**|**resultDesc**|**subCode**|**subDesc**|
|:-------------|:-------------|:----------------|:----------|
|400000|业务处理失败|INVALID_ARGUMENTS|参数不合法|
|400000|业务处理失败|INVALID_MERC_NO|无效商户号|
|400000|业务处理失败|CHECK_MERC_STATUS|商户状态异常|
