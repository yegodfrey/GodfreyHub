# MapView

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class MapView 继承自FrameLayout，显示地图的视图（包含从地图服务获取的数据）。 当使用MapView加载地图时，必须将包含此视图的Activity或Fragment中的生命周期方法应用到MapView对应的方法当中，包括： * [onCreate](#section5701320154117)(Bundle savedInstanceState) * [onStart](#section1929311316455)() * [onResume](#section127594720434)() * [onPause](#section119871413124319)() * [onStop](#section1185125812451)() * [onDestroy](#section1991150164217)() * [onSaveInstanceState](#section17492429104415)(Bundle outState) * [onLowMemory](#section1298412345428)() [HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象必须使用[getMapAsync](#section18155143712405)([OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378) callback)获取，此类会自动初始化地图系统和视图。 > 说明 > 建议不要向MapView添加子View。|
