# ApkUpgradeInfo

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|com.huawei.updatesdk.service.appmgr.bean.ApkUpgradeInfo ApkUpgradeInfo类用于在调用[AppUpdateClient.checkAppUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641#section15712187193218)方法时在回调结果中返回，在调用[AppUpdateClient.showUpdateDialog](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641#section1113567144514)方法时需传入。|

#### 参数说明

本对象中的参数应用可以不关注，在应用升级时调用showUpdateDialog方法直接传入从checkAppUpdate回调结果中获取的ApkUpgradeInfo对象即可。  

|参数名|参数类型|参数说明|
|:-----------------|:---------|:---------------------------------|
|name|String|应用名称。|
|id|String|应用ID。|
|releaseDate|String|应用发布时间，精确到天，格式为"yyyy-MM-dd"。|
|versionCode|Integer|APK中解析出来的内部版本号。|
|package|String|APK中解析出来的包名。|
|icon|String|应用图标链接地址。|
|downurl|String|应用整包或者差分包下载地址。|
|size|int|新版本应用大小。|
|diffSize|int|差分包大小。|
|diffHash|String|差分包的MD5。|
|hash|String|新版本APK包MD5。|
|version|String|新版本的版本名。|
|sameS|int|签名是否相同。 * 0：相同 * 1：不相同|
|newFeatures|String|新版本特性。|
|releaseDateDesc|String|应用更新时间描述，如"X天发布"，由服务器计算生成，客户端原样显示。|
|detailId|String|应用市场请求详情接口的ID。|
|isCompulsoryUpdate|int|是否是强制更新。 * 0：非强制更新 * 1：强制更新应用|
|devType|int|是否是华为自有应用。 * 0：非华为应用 * 1：华为自有应用|
|oldVersionName|String|老版本名。|
|oldVersionCode|int/span\>|老版本号。|
|notRcmReason|String|不推荐更新理由。|
|sha256|String|包的sha256值。|
