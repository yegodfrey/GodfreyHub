# BeaconStatus.Filter

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Interface Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract static class [BeaconStatus.Filter](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/status-filter-4-0000001050167033) extends Object implements Parcelable 信标过滤器，可以通过以下任一方式构造过滤器： * 按照在信标下注册的附件信息的命名空间和类型进行过滤。 * 按照在信标下注册的附件信息的命名空间、类型和内容进行过滤。 * 按照信标的广播ID进行过滤。|
