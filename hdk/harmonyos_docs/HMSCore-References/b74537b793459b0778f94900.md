# RemoteMessage

* 支持的场景：手机、平板。
* 支持的OS：EMUI 9.1.0+、Android 9.0+。

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class RemoteMessage implements Parcelable RemoteMessage类是一个消息实体类，应用通过[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hmsmessageservice-0000001050173839)中的[onMessageReceived](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hmsmessageservice-0000001050173839#section2394629102116)(RemoteMessage)方法接收服务端推送的消息，通过[HmsMessaging](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hmsmessaging-0000001050255650)中的[send](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hmsmessaging-0000001050255650#section17106147135813)(RemoteMessage)方法发送上行消息。 [RemoteMessage.Notification](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/remotemessage-notification-0000001050255662)类是一个内部类，代表通知栏消息。您在服务端推送通知栏消息时，如果通过服务端提供的开放接口设置了当应用进程在前台则不通过华为的统一消息中心（Notification Center，简称NC）展示消息，那么应用在前台时这个通知栏消息是直接透传给应用，由应用自己处理展示，此时RemoteMessage消息实体中包含[RemoteMessage.Notification](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/remotemessage-notification-0000001050255662)数据实例。Notification类中成员字段定义与[下行消息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197)中的[AndroidNotification](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p14253121131620)结构体字段定义相映射。如果应用进程在后台或者不存在，通知栏消息都是通过NC展示。 [RemoteMessage.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/remotemessage-builder-0000001050413831)类用于构建RemoteMessage消息实例。该类下所有方法从EMUI9.1版本开始生效。|
