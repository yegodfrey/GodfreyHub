#### HMSLocationManagerShouldDisplayHeadingCalibration:

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|@optional - (BOOL) HMSLocationManagerShouldDisplayHeadingCalibration:([HMSLocationManager](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanager-0000001160046484) \*)manager; 是否显示朝向校准警告。 此方法可以用来校准获取朝向的硬件设备。通常位置服务会在以下情形调用此方法： * 首次请求朝向信息更新。 * 当位置服务检测到所观测磁场的大小或者倾角发生重大变化时。 如果此方法返回YES，位置服务会立即在当前窗口顶部显示航向校准警告。校准警告提示用户以特定模式移动设备，以便位置服务能够区分地球磁场和任何局部磁场。该警告会一直保持可见状态，直到校准完成或通过显示调用[dismissHeadingCalibrationDisplay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmslocationmanager-0000001160046484#section2021613432913)方法来移除警告。校准过程只能过滤掉随设备移动的磁场。要校准靠近其他磁干扰源的设备，用户必须在校准过程中将设备从源移开或与设备一起移动源。 此方法返回NO或者未在代理中实现该方法，则不会显示朝向校准警告。当设备上的干扰磁场移除或产生较大变化时，校准仍会自动发生。|

Parameters  

|Name|Description|
|:------|:----------|
|manager|管理类对象。|

Return  

|Type|Description|
|:---|:--------------------------------------------|
|BOOL|返回是否显示朝向校准警告。 * YES：显示朝向校准警告。 * NO：不显示朝向校准警告。|
