# Task<TResult>

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Interface Info|
|:----------------------------------------------------------|
|public interface Task<TResult> 任务接口，任务执行完成后，会调用此接口中注册的回调方法。|
