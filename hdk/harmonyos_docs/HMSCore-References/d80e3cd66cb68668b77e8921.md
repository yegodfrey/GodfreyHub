# DeviceInfo

|Function Info|
|:---------------------------------------------------------------------------------------------------------------|
|function DeviceInfo 设备类，包含设备信息的类。 > 说明 > 设备信息是可选项。Health Service Kit不收集设备信息，设备信息是由开发者传入，开发者不传入设备信息时也不影响SDK的正常使用。|
