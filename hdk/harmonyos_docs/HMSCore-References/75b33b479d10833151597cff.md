# CoordinateConverter

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------|
|public class CoordinateConverter 坐标系转换工具类，传入1个或1组WGS84坐标，转换为GCJ02坐标。适用于中国区范围坐标转换，在中国地图范围内转换为GCJ02坐标，中国地图范围外保持WGS84坐标。|
