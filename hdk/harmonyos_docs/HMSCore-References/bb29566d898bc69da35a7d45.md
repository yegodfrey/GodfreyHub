# VastPlayerListener

|Interface Info|
|:----------------------------------------------|
|public interface VastPlayerListener 广告播放器状态的监听。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------|
|void|[onPlayStateChanged](#section1736916283124)(int playState) 切换播放器播放状态。|
|void|[onProgressChanged](#section17281743132814)(long duration, long currentPosition, long skipDuration) 调整广告播放进度。|
|void|[onScreenViewChanged](#section1421144142719)(int screenState) 切换屏幕状态。|
|void|[onVolumeChanged](#section14720545122614)(float volume) 调整系统媒体音量。|

## Public Methods

### onPlayStateChanged

|Method|
|:--------------------------------------------------------|
|default void onPlayStateChanged(int playState) 切换播放器播放状态。|

**Parameters**

|Name|Description|
|:--------|:-----------------------------------------------------------------------------|
|playState|播放器的播放状态码： * 2001：播放器正在播放。 * 2002：播放器暂停播放。 * 2006：播放器播放视频资源。 * 2007：播放器播放图片资源。|

### onProgressChanged

|Method|
|:-----------------------------------------------------------------------------------------------|
|default void onProgressChanged(long duration, long currentPosition, long skipDuration) 调整广告播放进度。|

**Parameters**

|Name|Description|
|:--------------|:-------------|
|duration|全部素材总时长，单位：毫秒。|
|currentPosition|当前已播放时长，单位：毫秒。|
|skipDuration|跳过时长，单位：毫秒。|

### onScreenViewChanged

|Method|
|:--------------------------------------------------------|
|default void onScreenViewChanged(int screenState) 切换屏幕状态。|

**Parameters**

|Name|Description|
|:----------|:-----------------------------|
|screenState|屏幕状态码： * 1001：普通模式 * 1002：全屏模式|

### onVolumeChanged

|Method|
|:---------------------------------------------------|
|default void onVolumeChanged(float volume) 调整系统媒体音量。|

**Parameters**

|Name|Description|
|:-----|:----------|
|volume|系统媒体音量。|
