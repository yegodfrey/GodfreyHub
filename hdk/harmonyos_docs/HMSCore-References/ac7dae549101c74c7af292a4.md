### getInstance(Activity activity)

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219) getInstance(Activity activity) 初始化Analytics Kit。Analytics Kit将根据配置完成初始化，且需要在主线程中初始化。 > 说明 > * SDK初始化时会发送网络请求，请您务必在用户同意隐私协议后再初始化SDK。设置能否发送网络请求实现方法详情请参见[为满足监管要求，集成SDK后要求用户在未同意访问网络前不能发送任何网络请求，如何处理？](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876#section3638114945120) > * 必须在第一个Activity的onCreate中初始化Analytics SDK，否则会导致生命周期相关事件采集不准确。 > * 如果已经调用过[getInstance(Context context, String routePolicy)](#section123561840111517)设置了指定的数据处理位置，再次调用[getInstance(Activity activity)](#section1239421717451)时[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219)将会切换成默认数据处理位置。 > * 如果您的应用发布到全球多个国家，建议您启用多数据处理位置，使用[getInstance(Context context, String routePolicy)](#section123561840111517)初始化SDK，按照用户实际使用区域指定数据上报位置。|

### getInstance(Context context, String routePolicy)

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219) getInstance(Context context, String routePolicy) 初始化Analytics Kit。Analytics Kit将根据配置完成初始化，Analytics Kit要求必须在主线程中初始化。 如果是Context方式初始化，将影响LAUNCHAPP事件的自动采集，某些场景取不到App的启动方式，这时需要传入Activity进行初始化。 > 说明 > * 需通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/)申请多数据处理位置功能体验，该接口方可生效。在线提单操作详情请参见[在线提单指导](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/online-application-guide-0000001174952406)。 > * SDK初始化时会发送网络请求，请您务必在用户同意隐私协议后再初始化SDK。设置能否发送网络请求实现方法详情请参见[为满足监管要求，集成SDK后要求用户在未同意访问网络前不能发送任何网络请求，如何处理？](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876#section3638114945120) > * 必须在第一个Activity或者Application的onCreate中初始化Analytics SDK，否则会导致生命周期相关事件采集不准确。 > * 使用多数据处理位置接口时，请务必下载应用对应的最新AGC配置文件，下载方法：在"项目设置"页面中，点击"应用"栏下的"agconnect-services.json"。|

**Parameters**

|Name|Description|
|:----------|:------------------------------------------------------------------------------------------------------------------|
|context|Context实例。|
|routePolicy|设置的数据处理位置。 数据处理位置包括：CN(中国)、DE(德国)、SG(新加坡)、RU(俄罗斯)。 > 说明 > 设置的数据处理位置必须是开通过存储权限的数据处理位置，如果没有开通，数据将无法上报，请务必设置有效的数据处理位置。|

**Returns**

|Type|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------|
|[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219)|获取Analytics Kit实例。|
