# AppPlayerInfo

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class AppPlayerInfo extends Object AppPlayerInfo类主要用于保存玩家在游戏内的信息，例如游戏内等级、角色、区服等，供开发者在调用[PlayersClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668)的savePlayerInfo方法时使用。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------------|
|String|[getRank](#section1946916196810)() 获取玩家在游戏内的等级。|
|String|[getRole](#section1897716281495)() 获取玩家在游戏内的角色。|
|String|[getArea](#section1789519341016)() 获取玩家在游戏内的区服信息。|
|String|[getSociaty](#section4748230101010)() 获取玩家在游戏内的公会信息。|
|String|[getPlayerId](#section1660563512114)() 获取玩家在游戏中的playerId。|
|String|[getOpenId](#section83579225113)() 获取玩家在游戏中的openId。openId是华为帐号在应用中的唯一标识。|
