# RewardAd

## 概述

激励视频广告对象。

## 方法

|方法名|描述|参数|返回值|
|:-----------------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------|
|load()|加载广告。|-|-|
|setRequestConfig(object)|设置广告请求配置参数。|[RequestConfig](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#section15312204811345)|-|
|onLoad(callback)|广告加载成功监听。|callback：广告加载成功的回调函数。|-|
|isLoading()|广告是否正在加载。|-|* true：广告正在加载。 * false：广告不在加载中。|
|isLoaded()|广告是否加载完成。|-|* true：广告加载完成。 * false：广告未加载完成。|
|offLoad()|移除广告加载成功监听。|-|-|
|show(object)|展示广告，广告加载成功后调用。|[RewardAdConfig](#section668573322513)|-|
|onClose(callback)|广告关闭监听。|callback：广告关闭成功的回调函数。|-|
|offClose()|移除广告关闭监听。|-|-|
|onError(callback)|广告加载失败监听。|callback：素材加载失败携带错误码的回调函数，callback的参数为errorcode。|-|
|offError()|移除广告加载失败监听。|-|-|
|onShow(callback)|广告展示监听。|callback：广告成功展示的回调函数。|-|
|offShow()|移除广告打开监听。|-|-|
|onComplete(callback)|广告播放完成监听。|callback：广告播放完成的回调函数。|-|
|offComplete()|移除广告播放完成监听。|-|-|
|onReward(callback)|广告获取奖励监听。|callback：广告获取奖励的回调函数。|-|
|offReward()|移除广告获取奖励监听。|-|-|
|destroy()|销毁广告组件。|-|-|

### RewardAdConfig

|参数|是否必选|类型|描述|
|:---------------|:---|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|customData|否|String|用户自定义数据。|
|userId|否|String|用户ID。|
|audioFocusType|否|number|视频播放时获取音频焦点类型。详情请参见[AudioFocusType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-api-0000001133473816#section9857084307)。|
|muted|否|Boolean|是否静音播放。|
|rewardDataAlerts|否|Boolean|是否流量提醒。|
