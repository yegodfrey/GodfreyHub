# 说明

> 注意
>
> 1. **使用室外高精度能力的开发者需要遵守国家法律法规与华为公司共同向国家有关部门申请高精度偏转插件的使用许可。**
> 2. **室外高精度能力当前仅支持中国大陆地区的部分城市：深圳市、广州市、苏州市、杭州市、重庆市、成都市、天津市、东莞市（持续增加中），海外暂不支持。**

|Name|Description|
|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，提供客户端侧定位服务能力。主要包含五个部分能力：融合定位、活动识别、地理围栏、室外高精度、室内定位，您可以根据自己的需求，调用相应的能力。使用室外高精度和室内定位能力需收费，收费标准请参见[服务定价](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pricing-0000001061986005)。|
|HarmonyOS（Java）|基于Java语言开发的独立HarmonyOS（Java）应用程序接口，目前支持融合定位。|
|iOS（Objective-C）|基于Objective-C语言开发的独立iOS应用程序接口，目前支持融合定位。|
|REST|提供支持HTTPS的云服务接口，用于网络定位（API）和IP定位（API）能力。使用网络定位（API）和IP定位（API）接口需收费，收费标准请参见[服务定价](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pricing-0000001061986005)。|

## Android功能支持说明

当您集成HMS Core（APK）时，Location Kit所有功能均支持；当您未集成HMS Core（APK）时，Location Kit仅支持融合定位能力。详情请参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-0000001050706106#section207491610112917)。
