# 说明

|Name|Description|
|:---------|:----------------------------------------------------|
|Android|基于Java、Kotlin语言开发的独立Android应用程序接口，提供向用户终端设备推送消息的能力。|
|HarmonyOS|基于Java语言开发的独立HarmonyOS应用程序接口，提供向用户终端设备推送消息的能力。|
|iOS|基于Objective-C和Swift语言开发的独立iOS应用程序接口，提供向用户终端设备推送消息的能力。|
|JavaScript|基于JS语言开发的独立Web应用程序接口，提供向用户浏览器推送消息的能力。|
|REST|提供支持HTTPS的云服务接口，用于向Push服务器发送请求。|
