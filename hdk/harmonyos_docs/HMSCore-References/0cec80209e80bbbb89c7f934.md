#### setDataSummary(List\<SamplePoint\> dataSummary)

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setDataSummary(List\<[SamplePoint](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/samplepoint_class-0000001050164515)\> dataSummary) 设置统计数据点集合。|

![](https://media:801784947938573897)  
设置统计数据点集合时，请注意运动记录类型和统计数据点集合的关联关系，否则可能开发者创建的运动记录数据不能正常上传到HealthKit服务器，具体详见[运动记录数据类型](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/activity-type-constants-0000001135051290)。例如可以通过以下代码，创建一个[跑步运动记录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/running-0000001181010707)。  

```
"Java"
// 1.构造请求对象的时间区间：开始和结束时间 
Context context = getApplicationContext();
Calendar cal = Calendar.getInstance(); 
Date now = new Date(); 
cal.setTime(now); 
long endTime = cal.getTimeInMillis(); 
cal.add(Calendar.HOUR_OF_DAY, -1); 
long startTime = cal.getTimeInMillis(); 

// 2.构造运动记录配速对象PaceSummary
// ActivitySummary中的PaceSummary用来承载配速统计数据 
ActivitySummary activitySummary = new ActivitySummary();
PaceSummary paceSummary = new PaceSummary();
paceSummary.setAvgPace(247.27626);
paceSummary.setBestPace(212.0);
paceSummary.setPartTimeMap((Map<String, Double>) new HashMap<>().put(1.0, 456));
paceSummary.setPaceMap((Map<String, Double>) new HashMap<>().put(1.0, 263));
paceSummary.setPartTimeMap((Map<String, Double>) new HashMap<>().put(1.0, 263));
paceSummary.setSportHealthPaceMap((Map<String, Double>) new HashMap<>().put(102802480, 535));
activitySummary.setPaceSummary(paceSummary);

// 3.创建一个步数统计数据采集器
DataCollector dataCollector2 = new com.huawei.hms.hihealth.data.DataCollector.Builder()
    .setDataType(DataType.DT_CONTINUOUS_STEPS_TOTAL)
    .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
    .setPackageName(context)
    .setDataCollectorName("test1")
    .build();
// 构造一个速度统计数据采集器
DataCollector dataCollector20 = new com.huawei.hms.hihealth.data.DataCollector.Builder()
    .setDataType(DataType.POLYMERIZE_CONTINUOUS_SPEED_STATISTICS)
    .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
    .setPackageName(context)
    .setDataCollectorName("test1")
    .build();
// 4.根据统计数据采集器，构造统计数据样本点，并添加至DataSummary对象
// 创建步数统计数据采样点
SamplePoint samplePoint = new SamplePoint.Builder(dataCollector2).build();
samplePoint.setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
samplePoint.getFieldValue(Field.FIELD_STEPS).setIntValue(352);
// 创建速度统计数据采样点
SamplePoint samplePoint20 = new SamplePoint.Builder(dataCollector20).build();
samplePoint20.setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
samplePoint20.getFieldValue(Field.FIELD_AVG).setDoubleValue(6.0d);
samplePoint20.getFieldValue(Field.FIELD_MIN).setDoubleValue(4.0d);
samplePoint20.getFieldValue(Field.FIELD_MAX).setDoubleValue(8.0d);
// ActivitySummary中的DataSummary用来承载统计数据
List<SamplePoint> dataSummary = new ArrayList<>();
dataSummary.add(samplePoint);
dataSummary.add(samplePoint20);
activitySummary.setDataSummary(dataSummary);

// 5.构造运动记录，设置统计数据ActivitySummary对象
ActivityRecord activityRecord = new ActivityRecord.Builder() 
    .setName("AddActivityRecord") 
    .setDesc("This is ActivityRecord add test!") 
    .setId("MyAddActivityRecordId") 
    .setActivityTypeId(HiHealthActivities.RUNNING) 
    .setStartTime(startTime, TimeUnit.MILLISECONDS) 
    .setEndTime(endTime, TimeUnit.MILLISECONDS) 
    .setActivitySummary(activitySummary)
    .setTimeZone("+0800")
    .build(); 
```
