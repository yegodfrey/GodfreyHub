# ResolveTaskHelper

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ResolveTaskHelper 处理Task任务的辅助类。该类的excuteTask方法处理了回调结果，将该回调结果返回到当前的activity的onActivityResult(int,int,Intent)；在onActivityResult中，根据返回的错误码,提示相应的添卡状态给用户。成功为Activity.RESULT_OK，目前提供的错误标记在[WalletPassConstants](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hms-wallet-pass-constant-walletpasscontant-0000001050986377)中有以下几种： * ERROR_CODE_SERVICE_UNAVAILABLE * ERROR_CODE_UNSUPPORTED_API_REQUEST * ERROR_CODE_INTERNAL_ERROR * ERROR_CODE_OTHERS * ERROR_CODE_INVALID_PARAMETERS * ERROR_CODE_USER_ACCOUNT_ERROR * ERROR_CODE_DEVELOPER_ERROR * ERROR_CODE_MERCHANT_ACCOUNT_ERROR|
