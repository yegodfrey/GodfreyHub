# 获取已绑定设备的标识

运动健康将测量过程的能力通过JS接口提供给三方，三方只能操作和运动健康App绑定过的设备。

|接口|说明|
|:----------------------------------------------------------------------------------------------------------|:-----------------------------|
|[getDeviceId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/getdeviceid-0000001058135269)|获取绑定设备在开发者平台分配的UUID（资源包的UUID）。|
