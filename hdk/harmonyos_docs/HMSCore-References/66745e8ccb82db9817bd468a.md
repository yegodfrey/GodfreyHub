# HWMap

#### 概述

API中的核心类，用来加载一张地图。  

#### 构造函数

|函数|描述|
|:--------------------------------|:-------------------------------------------------------------------------|
|HWMapJsSDK.HWMap(div, mapOptions)|* div：填充地图容器。 * mapOptions：设置地图属性，详情见[MapOptions](#section12313153115171)。|

|zoomSlider|否|Boolean|设置地图是否显示缩放条，默认false。|
|zoomControl|否|Boolean|设置地图是否显示缩放按钮，默认true。|
