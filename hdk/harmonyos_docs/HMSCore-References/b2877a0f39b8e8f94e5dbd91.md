# 搜索图片网页

## 功能介绍

提供通用网页图片搜索功能，根据输入的关键词，返回通用网页图片搜索结果。

## 场景描述

您需要从互联网上搜索相关图片时，调用该API，输入关键词，可以得到万维网中与此相关的图片所在网页列表数据。

## 使用约束

无。

## 接口原型

|承载协议|HTTPS GET|
|-----|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|接口方向|开发者服务器->华为搜索服务器|
|接口URL|https://{*rootUrl*}/apis/search/v1.0.0/image/search > 说明 > {*rootUrl* }：请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/overview-0000001057087079#section899715361751)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

## 查询参数

|**参数**|**是否必选**|**参数类型**|**描述**|
|:------|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
|q|是|string|搜索词。|
|lang|否|string|支持的搜索语言，参见[语言码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/language-code-0000001057569148)。默认值是en。|
|sregion|否|string|支持的搜索区域，参见[搜索区域码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/search-region-code-0000001057330966)。默认值是ww。|
|pn|否|integer|搜索结果分页页号，取值范围[1, 100]。默认值是1。|
|ps|否|integer|搜索结果单页条目数量，取值范围[1, 100]。默认值是10。|

## 请求参数

**Request Header**

|参数|是否必选|参数类型|描述|
|:--------------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Accept|是|string|取值为application/json。|
|Content-Type|是|string|取值为application/json。|
|Authorization|是|string|您动态获取的[Access token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 > 说明 > Bearer后面拼接空格，再拼接获取的access_token。|
|X-Kit-AppID|是|string|联盟申请的凭证后得到的对应[应用级ID及Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/app-gallery-connect-0000001057712438#section27092029144315)。|
|X-Kit-ClientIP|否|string|终端用户IP，云侧服务器对接时建议您传入，支持本地化。|
|X-Kit-RequestID|否|string|标识请求的唯一ID(用户可自己指定ID，如无指定则配置默认值)。|

**Request Body**

无。

## 请求示例

```screen
GET https://{rootUrl}/apis/search/v1.0.0/image/search?q=<query>
Content-Type:application/json
Accept:application/json
Authorization:Bearer {access_token}
X-Kit-AppID:{appid}
```

如果实际搜索的query为test，按这里的示例appid、域名、Access Token，实际请求为：

```screen
GET https://search-forexample.cloud.huawei.com/apis/search/v1.0.0/image/search?q=test
Content-Type:application/json
Accept:application/json
Authorization:Bearer Access1Token/For2Example
X-Kit-AppID:appidforexample
```

## 响应参数

**状态码为200时：**

**Response Header**

无。

**Response Body**

|**参数**|**是否必选**|**参数类型**|描述|
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------|
|request_id|是|string|请求ID，和请求Header中的X-Kit-RequestID一致，若请求中没有X-Kit-RequestID，会在服务端生成。|
|data|是|Array[[ImageItem](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/data-model-0000001056519097#section12590182754813)]|图片搜索结果。|
|query_lang|否|string|从query推断出的语言。|

**状态码为非200时：**

**Response Header**

无。

**Response Body**

|参数|是否必选|参数类型|描述|
|:---------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------|
|code|是|string|详细错误码，参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/error-code-0000001055689455)。|
|msg|是|string|错误信息。|
|request_id|是|string|请求ID，和请求Header中的X-Kit-RequestID一致，若请求中没有X-Kit-RequestID，会在服务端生成。|

## 响应示例

```screen
HTTP/1.1 200 OK
Content-type: application/json
{
"data": {search result},
"request_id": {X-Kit-RequestID}
}
```
