# HAReportPolicy

|Class Info|
|:-----------|
|支持您设定数据上报策略。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------|
|HAReportPolicy|[onScheduledTimePolicy](#section490110481519):(NSInteger)seconds 定时触发上报，并支持参数配置。定时周期范围：[60, 1800]秒。|
|HAReportPolicy|[onAppLaunchPolicy](#section155171835195515) 应用打开触发上报。|
|HAReportPolicy|[onMoveBackgroundPolicy](#section13346181218561) 应用切后台触发上报，默认开启。|
|HAReportPolicy|[onCacheThresholdPolicy](#section1136841218578):(NSInteger)threshold 阈值触发上报，默认开启，并支持参数配置。阈值范围：[30, 1000]条（默认200条）。|
