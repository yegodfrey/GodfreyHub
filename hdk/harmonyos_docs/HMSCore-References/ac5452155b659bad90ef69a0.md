# 上传健康记录

#### 功能介绍

上传数据采集器采集的健康记录。  

#### 场景描述

向指定的DataCollector下添加HealthRecord。  

#### 使用约束

* 先创建对应数据类型的数据采集器。
* 只允许创建该数据采集器的应用上传该数据采集器的采样数据，其他应用只支持读取该数据采集器的数据。  

#### 接口原型

|承载协议|HTTPS PATCH|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors/{dataCollectorId}/healthRecords|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------|

#### 路径参数

|参数|参数类型|是否必选|描述|
|:--------------|:-----|:---|:----------|
|dataCollectorId|String|是|数据采集器的唯一标识。|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/json; charset=UTF-8|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body  

|参数|参数类型|是否必选|描述|
|:------------|:----------------------------------------------------------------------------------------------------------------------------------------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|healthRecords|List\<[HealthRecords](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section1979415545136)\>|是|健康记录HealthRecord列表。每次PATCH最多上传1000个HealthRecord。 请参见[HealthRecords](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section1979415545136)数据模型。|
