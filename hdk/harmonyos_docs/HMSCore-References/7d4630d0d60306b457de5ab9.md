# Main

|Class Info|
|:---------------------|
|功能入口，可获取APK版本号、触发重排功能。|

## 方法

|方法|描述|参数类型|返回值|
|:----------|:-------|:----------|:--|
|start(para)|运行本产品功能。|HwParameter|无|

## 常量

|常量|描述|
|:-----------|:-----------------|
|version_code|获取number类型的版本号，只读|
|version_name|获取string类型的版本号，只读。|

## 示例代码

```screen
<script lang="javascript">
    if (Ditto) {
        let para = new Ditto.HwParameter();
        Ditto.Main.start(para);

        const version_number = Ditto.Main.version_code;
        const version_string = Ditto.Main.version_name;
    }
</script>
```
