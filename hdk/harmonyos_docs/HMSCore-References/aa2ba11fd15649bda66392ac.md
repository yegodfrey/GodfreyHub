# ActivityIdentificationService

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ActivityIdentificationService 活动识别交互接入类，在调用[ActivityIdentification](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityidentification-0000001050746167)类的[getService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityidentification-0000001050746167#section1120013264461)(Activity activity)或[getService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityidentification-0000001050746167#section146052044204717)(Context context)方法时会返回一个该类型的实例。|

获取ActivityIdentificationService实例对象的示例代码如下：

```
"Java"
private ActivityIdentificationService activityIdentificationService;
activityIdentificationService = ActivityIdentification.getService(this);
```

```
"Kotlin"
private lateinit var activityIdentificationService: ActivityIdentificationService
activityIdentificationService = ActivityIdentification.getService(this)
```

#### createActivityConversionUpdates(ActivityConversionRequest activityConversionRequest, PendingIntent pendingIntent)

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
