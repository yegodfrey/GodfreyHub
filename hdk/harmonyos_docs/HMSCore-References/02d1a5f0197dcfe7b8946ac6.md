#### Public Methods

#### getToken()

|Method|
|:-------------------------------------------------|
|getToken(): Promise\<string \| null\> 获取推送服务Token。|

Returns  

|Type|Description|
|:------------------------|:-----------------------------|
|Promise\<string \| null\>|推送服务Token字符串。如果返回空表示获取Token失败。|

#### deleteToken(token: string)

|Method|
|:----------------------------------------------------------|
|deleteToken(token: string): Promise\<boolean\> 删除推送服务Token。|

Parameters  

|Name|Description|
|:----|:--------------|
|token|需要删除的推送服务Token。|

Returns  

|Type|Description|
|:-----------------|:---------------------------------------|
|Promise\<boolean\>|删除推送服务Token的结果。 * true：删除成功 * false：删除失败|

#### onMessage()

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|onMessage(callback: AsyncCallback\<payload\>): （）=\> void 获取推送消息的内容。 示例： ``` // 获取HmsMessaging对象 messaging = hms.messaging(); // 调用onMessage方法获取消息内容 messaging.onMessage((payload) => { console.log('Message received. ', payload); }); ```|

Parameters
