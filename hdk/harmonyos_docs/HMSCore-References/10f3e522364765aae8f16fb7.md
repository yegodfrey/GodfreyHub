# BitmapDescriptor

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class BitmapDescriptor 用于定义Bitmap图像，可以通过[BitmapDescriptorFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptorfactory-0000001050152411)类获得。Bitmap图像可用于标记的图标或覆盖物的图像。 例如，使用BitmapDescriptor设置[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858)图标的示例代码如下： ``` MarkerOptions options = new MarkerOptions() .position(new LatLng(48.893478, 2.334595)) .title("Hello Huawei Map") .snippet("This is a snippet!") .icon(BitmapDescriptorFactory.defaultMarker()); Marker mMarker = hMap.addMarker(options); ```|
