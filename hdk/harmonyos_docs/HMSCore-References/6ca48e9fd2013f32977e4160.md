# HmsMarkerTranslateAnimation

控制动画移动。

## Properties

|名称|类型|描述|
|:---------------|:---------------------------------------------------------------------------------------------------------------|:--------------------|
|animationId|String|动画唯一的ID。|
|target|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|移动的目标位置。|
|duration|int|动画时长。|
|fillMode|int|动画结束后的状态。|
|repeatCount|int|动画重播的次数。|
|repeatMode|int|动画重播模式。默认情况下，动画从开始重播。|
|interpolator|int|动画插值器。|
|onAnimationStart|Function?|动画开始播放时执行的函数。|
|onAnimationEnd|Function?|动画结束播放时执行的函数。|
