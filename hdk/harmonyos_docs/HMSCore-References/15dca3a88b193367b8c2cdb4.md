# HourlyWeather

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class [HourlyWeather](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hourlyweather-0000001050975623) implements Parcelable 当前小时和未来24个小时的天气信息。包括天气ID(CN)、对应时间信息、摄氏度、华氏度、降雨概率、是白天还是晚上。|

#### getCnWeatherId

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public int getCnWeatherId() 获取CN天气ID(cnWeatherId)。CN天气ID表示的是当前的天气，每个值都对应不同的天气，例如0表示晴，1表示多云，7表示小雨。更多天气ID对应的天气信息请参见[CNWeatherId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/cn-weatherid-4-0000001050165072)。|

Returns  

|Type|Description|
|:---|:----------|
|int|CN天气ID。|
