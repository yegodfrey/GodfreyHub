# 删除个人数据

#### 功能介绍

终端用户在应用客户端发起个人数据删除请求，应用服务端调用此接口能够协助用户删除在分析服务平台的数据。  

#### 场景描述

当您需要支持终端用户删除个人数据，以满足GDPR要求时，您可以在其开发的应用中提供删除个人数据按钮，当终端用户点击此按钮时，您的应用服务器可以调用此接口删除其采集上报到Analytics Kit服务端的该用户的数据。  

#### 使用约束

* 用户已请求导出数据，导出未完成前，不支持删除。
* 数据已经被删除的用户，不支持再次删除。
* 调用频率不超过1次/秒。  

#### 接口原型

|承载协议|HTTP POST|
|接口方向|开发者回调接口服务器-\>分析服务服务器|
|接口URL|{rootUrl}/analytics/gdpr/user_deletion_requests/v2 说明： {rootUrl}：请参见[接口访问路径获取](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-common-interface-description-0000001050707180#section777183816123)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-product-id|是|String|用户在AppGallery Connect上的Product ID。|
|x-app-id|是|String|用户在AppGallery Connect上的App ID。|
|Authorization|是|String|鉴权信息。请参见[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|

Request Body  

|参数|是否必选|参数类型|描述|
|:---|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|aaid|否|String|通过HMS Core端侧接口获取。 * Android：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section124931637174316) * HarmonyOS（Java）：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477#section124931637174316) * HarmonyOS（JavaScript）：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section124931637174316) * iOS：[AAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-analytics-0000001050164675#section10770121143112) * macOS：[AAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/macos-api-analytics-0000001241100765#section10770121143112) * Web：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-analytics-0000001050825689#section993793015410) * 快应用：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-analytics-0000001077322170#section993793015410) * 快游戏：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickgame-api-analytics-0000001238739841#section993793015410) * 微信小程序：[getAAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/miniprogram-api-wxanalytics-0000001198293007#section993793015410)|

#### 请求示例

```
POST /analytics/gdpr/user_deletion_requests/v2 HTTP/1.1
Content-Type: application/json; charset=UTF-8
Content-Length: xxxx
Accept: application/json
Authorization: Bearer *** 
x-product-id: sample-productid
x-app-id: sample-appid
 
{
     "aaid":"sample-aaid"
}
```

#### 响应参数

状态码为200时：

Response Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:---------------|:---------|
|Content-Type|是|application/json|响应消息的数据格式。|

Response Body  

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----|:-----------------------------------|
|result_code|是|String|响应码，请参见[错误码](#section1237194119178)。|
|result_msg|是|String|响应描述。|

#### 响应示例

状态码为200时：

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=UTF-8
Connection:  Close
Content-Length: xxxx                       
 
{
  "result_code":"0",
  "result_msg":"success"
}
```

#### 错误码

|状态码|错误码|描述|解决方法|
|:--|:----|:----------|:------------------------------------|
|200|0|请求成功。|-|
|400|10020|非法参数。|请修改填写错误的参数值。|
|400|10032|数据导出中，无法删除。|请提示用户，正在导出该用户的个人数据，需要待导出完成后，重新申请删除数据。|
|400|10033|数据已删除。|请提示用户数据已经删除。|
|400|10008|接口请求过于频繁。|请提示用户请求删除数据过于频繁，稍后再试。|
