#### setAnalyticsEnabled

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|+ (void)setAnalyticsEnabled:(BOOL)enabled 是否打开埋点采集能力。关闭后将上报所有缓存，并不再记录任何数据。 说明： * 如果您已经调用过[setRestrictionEnabled](#section86371153192510)接口，再次打开埋点采集能力时，数据分析能力不会同步打开，需要您设置[setRestrictionEnabled](#section86371153192510)接口的参数值为NO。 * 如果您未调用过[setRestrictionEnabled](#section86371153192510)接口，再次打开埋点采集能力时，数据分析能力会同步打开。 * 如果您在分析服务侧禁止数据采集，可能会影响[A/B测试](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-introduction-0000001058210679) 、[App Linking](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-applinking-introduction-0000001054143215)、[应用内消息](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-appmessage-introduction-0000001071884501)、[性能管理](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-apm-introduction-0000001052247254)服务的数据分析功能，也会影响[崩溃服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-crash-introduction-0000001055732708)的崩溃率。|

Parameters  

|Name|Description|
|:------|:---------------------------------|
|enabled|是否打开埋点采集开关，默认YES。 * YES：打开 * NO：关闭|

Sample code：

SDK默认打开采集数据，您可参考以下示例代码，关闭埋点采集能力。

```
-(BOOL)application:(UIApplication *)applicationdidFinishLaunchingWithOptions:(NSDictionary*)launchOptions {
  // Override point for customization after application launch.
  [HiAnalytics config];
  [HiAnalytics setAnalyticsEnabled:NO];
  return YES;
}
```
