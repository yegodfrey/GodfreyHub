# SamplePoint

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class SamplePoint implements Parcelable 采样点类，是特定数据采集器在某时刻（或一段时间）采集到的特定数据类型的样本。保存了该时刻（或时间范围内）数据类型各维度的值，以及采样的起止时间。 采样点的采样方式根据数据类型的定义，分为瞬时采样和区间采样两种， 在设置采样点时间时，建议瞬时数据使用setSamplingTime()接口，区间数据使用setTimeInterval()接口（必须是一个有效时间段）。 区间数据在初次创建时不支持使用setSamplingTime()，否则无法创建成功；但该接口可以用来修改已创建的区间采样点的结束时间，调用后仅会修改结束时间。|

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final void checkIntervalValidity() 时间间隔合理性校验： 1. 开始时间和结束时间均不可为0。 2. 开始时间不应大于结束时间。 3. 时间跨度不超过3天。 4. 区间数据类型开始时间应小于结束时间。 5. 统计类型（总量、聚合）时间跨度不超过1年（366天）。 6. 无法识别的数据类型（自定义数据类型）符合1、2、3即可。|

![](https://media:801784947941231912)  
请注意若创建的SamplePoint的数据类型为[步数](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562)或者[血糖](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/healthdatatypes-0000001050092315#section12947326103010)类型，且开发者希望将写入Health Service Kit的数据在运动健康App首页展示，需要按以下列举的键值对设置SamplePoint中的元数据。

* 若为[步数](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562)数据类型，key值需设置为"motion_type"（表示运动状态），value值可以设置为：
  * "RUN"（表示跑步）；
  * "WALK"（表示走路）；
  * "STAIRS"（表示爬楼）；
  * "UNKNOWN"（表示未知）。
* 若为[血糖](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/healthdatatypes-0000001050092315#section12947326103010)数据类型，key值需设置为"mIsConfirmed"（表示用户确认状态），value值可以设置为：
  * "true"（表示用户已确认）；
  * "false"（表示用户未确认）。

以下示例为步数数据类型创建SampleSet，用于调用[插入用户的运动健康数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section10704529103014)接口。

```
// 步骤1：构造一个数据采集器对象。
DataCollector dataCollector = new DataCollector.Builder().setPackageName(getApplicationContext())
    .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
    .setDataStreamName("STEPS_DELTA")
    .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
    .build();

// 步骤2：根据数据采集器，创建一个采样集。
final SampleSet sampleSet = SampleSet.create(dataCollector);

// 步骤3：构造一个步数增量（DT_CONTINUOUS_STEPS_DELTA）采样点的开始时间、结束时间、增量步数。
SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
Date startDate = null;
Date endDate = null;
try {
    // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳，时间戳不涉及时区
    // 请注意此处设置的插入运动健康数据的采样点数据的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳
    startDate = dateFormat.parse("2020-03-17 09:00:00");
    endDate = dateFormat.parse("2020-03-17 09:05:00");
} catch (ParseException e) {
    logger("Time parsing error");
}
int stepsDelta = 200;

// 步骤4：构造一个步数增量采样点。
SamplePoint samplePoint = sampleSet.createSamplePoint()
    .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS);
samplePoint.getFieldValue(Field.FIELD_STEPS_DELTA).setIntValue(stepsDelta);
// 若写入的步数数据需要在运动健康App上展示，需要对采样点添加如下元数据
samplePoint.addMetadata("motion_type", "RUN");

// 步骤5：将一个步数增量采样点存储到采样集，也可以重复执行步骤3 ~ 步骤5添加多个样本点数据到采样集。
sampleSet.addSample(samplePoint);
```
