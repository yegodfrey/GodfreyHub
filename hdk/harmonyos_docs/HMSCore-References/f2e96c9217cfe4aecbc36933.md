# HwParameter

|Class Info|
|:------------------------------------------|
|参数配置，可配置是否修改viewport、设置根节点字体大小、设置瀑布流样式重排列数。|

#### smallScreenRootFontSize

|Name|Description|
|:------------------------------|:---------------------|
|smallScreenRootFontSize: number|写入窄屏时此页面的根节点字体大小，默认不设置|

#### viewPortSwitch

|Name|Description|
|:---------------------|:-----------------------------------------------------------------------------|
|viewPortSwitch: number|设置是否启用放大方案及字体、通栏处理，默认模式1 0：关闭放大模式 1：开启放大模式，处理字体 2：开启放大模式，处理通栏 3：开启放大模式，处理字体和通栏|

#### columnCount

|Name|Description|
|:------------------|:------------|
|columnCount: number|瀑布流列数配置，默认不设置|

#### 示例代码

```
<script lang="javascript">
    if (Ditto) {
        let para = new Ditto.HwParameter();
        para.smallScreenRootFontSize = 40;
        para.viewPortSwitch = 1;
        para.columnCount = 3;
        Ditto.Main.start(para);
    }
</script>
```
