# Order服务确认购买

#### 功能介绍

对于消耗型商品，发货成功后，您可以调用此接口，以此通知华为应用内支付服务器更新商品的发货状态。如果不通知，将导致无法再次购买这个商品。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241028180416.13704657398877503045087154014361:50001231000000:2800:E072642F49F67E4B3A5E3660DF5477B1A28ACDE4734FF5270EE93A9E2CB91100.png?needInitFileName=true?needInitFileName=true)  
该接口的作用等同于IAP客户端的[IapClient.consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口或[HMSIAP.consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-js-hmsiap-0000001333923881#section6274833121119)接口。

使用本接口时，需要注意以下情况：

以IAP Android客户端为例，若使用IAP客户端[IapClient.consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口进行确认，确认后再次请求[IapClient.obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section15126153542812)接口时，IAP客户端将会刷新缓存数据。而使用当前服务端接口进行确认时，确认后IAP客户端将不会刷新缓存，从而导致[IapClient.obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section15126153542812)接口返回已确认的购买数据。

因此，使用当前接口向IAP服务器发起确认时，建议您将确认的结果记录到您的服务器。对IAP客户端[IapClient.obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section15126153542812)接口或[HMSIAP.obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-js-hmsiap-0000001333923881#section12785229123913)返回的订单进行确认前，可先通过您的服务器检查该笔订单的确认状态。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为应用内支付服务器|
|接口URL|{rootUrl}/applications/v2/purchases/confirm 说明： rootUrl在不同站点有不同的url：您应固定选择最近站点的Order服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1954123781815)和[站点选择](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1741234185817)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Content-Type|是|String|取值为：application/json; charset=UTF-8|
|Authorization|是|String|认证信息，使用Access Token进行鉴权，这里使用开放平台鉴权提供的服务接口获取Access Token，格式说明参见[公共说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127)，获取方式参见[获取应用级AT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/obtain-application-level-at-0000001051066052)。|

Request Body  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:--------------------------|
|purchaseToken|是|String|商品的购买Token，发起购买和查询订阅信息均会返回。|
|productId|是|String|商品ID。|

|参数|是否必选|参数类型|描述|
