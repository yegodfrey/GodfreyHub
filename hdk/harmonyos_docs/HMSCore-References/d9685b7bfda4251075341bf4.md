# HeadsetBarrier

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class [HeadsetBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-headsetbarrier-0000001050164086) extends Object 耳机围栏，包括连接、未连接、状态驻留的围栏。|

#### Public Methods

#### keeping

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) keeping(int headsetStatus) 耳机状态驻留围栏，开发者添加连接或非连接两种状态的耳机状态驻留围栏后，当耳机状态保持为指定状态时，此围栏状态为TRUE并触发围栏事件上报。 使用此围栏需添加android.permission.BLUETOOTH权限。|

Parameters  

|Name|Description|
|:-----------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
|[headsetStatus](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/headset-status-4-0000001050165080)|耳机状态。 * CONNECTED：耳机已连接。 * DISCONNECTED：耳机未连接。|

Returns  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|情景感知围栏。|

Throws  

|Name|Description|
|:-----------------------|:----------------------------------------------|
|IllegalArgumentException|参数不合法（headsetStatus不为CONNECTED或DISCONNECTED）异常。|

#### connecting

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) connecting() 耳机连接围栏，添加此围栏后，当耳机连接设备时，此围栏状态为TRUE并触发围栏事件上报，5s后状态切换为FALSE。 使用此围栏需添加android.permission.BLUETOOTH权限。|

|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
