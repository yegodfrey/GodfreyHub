## Sample Code

```screen
private void subscribeChange(Drive drive, String cursor){
    try{
        Channel channel = new Channel();
        channel.setId(HmsProxyImpl.getInstance().getDeveiceId());
        channel.setType("web_hook");
        channel.setUrl("https://...... ");
        Drive.Changes.Subscribe subscribe= drive.changes().subscribe(cursor, channel);
        Channel result = subscribe.execute();
    } catch (Exception e){
        Log.e(TAG, "subscribeChange error: " + e.getMessage());
    }
}
```
