# 查询分账结果

#### 功能介绍

华为支付系统已发起分账的订单，可由分账方商户调用此接口发起查询分账结果请求，获取分账结果。  
![](https://media:201774590626140576)  
1、一笔订单申请一次或者多次分账请求，每次分账请求可以添加多个分账规则，但只会返回一个成功或者失败的请求标识。

2、分账完成的订单不能再次发起分账。

3、分账金额不能超过最大分账比例对应的金额。
