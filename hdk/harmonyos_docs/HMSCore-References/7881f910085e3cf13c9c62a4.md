# 管理个人资料

## getGender()

|Method|
|:---------------------------|
|getGender() 获取性别。该接口只在手机上支持。|

**Returns**

|Type|Description|
|:----------------------|:------------------------------------------------------------------------------------------|
|Promise<Result<String>>|返回获取性别的异步回调。 * 若回调成功，则表示接口调用成功。调用成功返回以下值：0(女), 1(男),2(保密), -1(未设置)。 * 若回调失败，可通过异步回调结果获取错误码。|

获取性别的示例代码如下：

```screen
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.getGender().then((result) => {
    console.info("getGender success: " + JSON.stringify(result))
}).catch((error) => {
    console.error("getGender Error: " + JSON.stringify(error));
});
```

## getBirthday()

|Method|
|:-------------------------------|

**Returns**

|Type|Description|

|Promise<Result<String>>|返回获取出生日期的异步回调。 * 若回调成功，则表示接口调用成功。调用成功返回出生年月日，举例：19900801代表1990年8月1日。 * 若回调失败，可通过异步回调结果获取错误码。|
