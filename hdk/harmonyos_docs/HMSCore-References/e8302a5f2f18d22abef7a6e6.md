# ContentData

* 支持的场景：手机。
* 支持的OS：HarmonyOS 2.0及以上。

|Class Info|
|:-----------------------------------------------------------------------------------|
|public class ContentData 捐赠内容数据，一个消息可以发送多个内容数据，一般对应一个事件； Header和Payload Key总数需小于100。|
