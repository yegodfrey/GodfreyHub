# GameManager

|Class Info|
|:---------------------------------------------------------------------------------------------------------------|
|public class GameManager GameManager是GameTurbo Engine对外提供的类，它是一个抽象类，具有一个公共的静态方法，用来获取一个继承并实现GameManager抽象方法的类的实例。|

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------------------------------------------------|
|GameManager|[getGameManager()](#section1527485551610) 返回一个继承并实现了GameManager抽象类的实例。|
|boolean|[registerGame(String packageName, GameCallBack gameCallback)](#section1374617317199) 向设备注册应用。|
|void|[updateGameAppInfo(String gameInfoJson)](#section322262018287) 向设备传递消息。|
|String|[getPhoneInfo()](#section81111243202916) 主动获取设备信息。|

#### Public Methods

#### getGameManager

|Method|
|:-------------------------------------------------------------------------------------------------|
|public static GameManager getGameManager() 返回一个继承并实现了GameManager抽象类的实例。 设计为单例模式，每次调用该接口返回的都是同一个实例。|

Returns  

|Type|Description|
|:----------|:------------------------------------------------------|
|GameManager|返回一个继承并实现了GameManager抽象类的实例。 设计为单例模式，每次调用该接口返回的都是同一个实例。|

#### registerGame

|Method|
|:--------------------------------------------------------------------------------------------------------------|
|public boolean registerGame(String packageName, GameCallBack gameCallback) 向设备注册应用，注册成功后可以正常调用GameManager提供的接口。|

Parameters  

|Name|Description|
|:------------------------|:-----------------------------------------------------------------------------|
|String packageName|应用的包名。|
|GameCallBack gameCallback|GameCallBack接口的实现。设备通过该回调接口反馈设备信息，如温度信息等。 该参数可以传入null。表示应用不需要通过回调的方式获得设备上报的信息。|

Returns  

|Type|Description|
|:------|:-----------------------------|
|boolean|注册结果。 * true：注册成功 * false：注册失败|

#### updateGameAppInfo

|Method|
|:---------------------------------------------------------------------------------------------------------|
|public void updateGameAppInfo(String gameInfoJson) 向设备传递消息。通过registerGame方法注册成功后，再通过该方法向设备传递消息，否则设备不会收到消息。|

Parameters  

|Name|Description|
|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String gameInfoJson|向设备传递的消息。|
|String gameInfoJson|游戏全局消息： 在游戏初始化时发送的游戏全局参数，这些参数在整个游戏过程中是保持不变的。 JSON格式样例： ``` { "MessageType":0, "PackageName":"xxx.xxx.xxxx.xxx", "AppVersion":"1.0", "ResourceVersion":"1.0", "EngineType":2, "EngineVersion":"1.0", "GameType":2, "VulkanSupport":true } ``` 字段：MessageType(int) 说明：必填。取值为0，标识是一个游戏全局消息。 字段：PackageName(String) 说明：必填。标识游戏的包名。最大长度128个字符。 字段：AppVersion(String) 说明：必填。游戏App版本号。最大长度64个字符。 字段：ResourceVersion(String) 说明：选填。游戏资源版本号。最大长度64个字符。 字段：EngineType(byte) 说明：选填。标识游戏引擎类型。 * 1：UNITY * 2：UNREAL4 * 3：MESSIAH * 4：COCOS * 200：OTHERS 字段：EngineVersion(String) 说明：选填。如果EngineType没有填，该字段也不需要填。标识游戏引擎版本号。最大长度64个字符。 字段：GameType(byte) 说明：选填。标识游戏类型。 * 1：MOBA多人在线战术竞技 * 2：RPG 角色扮演 * 3：FPS 第一人称射击类 * 4：FTG 格斗游戏 * 5：RAC 竞速游戏 * 200：OTHERS 其他 字段：VulkanSupport(boolean) 说明：选填。标识是否支持Vulkan。|
|String gameInfoJson|游戏设置消息： 在游戏初始化时发送的游戏默认设置，或者在游戏设置发生改变时（如用户通过设置改变参数时）发送的更新后设置。 JSON格式样例： ``` { "MessageType":1, "PictureQualityMaxLevel":3, "PictureQualityCurLevel":3, "FrameRateMaxValue":60, "FrameRateCurValue":50, "ResolutionMaxValue":"1920x1080", "ResolutionCurValue":"1280x720", "AntiAliasing":true, "Shadow":true, "MultiThread":true, "Particle":true, "HDMode":true, "TempTrendThresholdLevel":4 } ``` 字段：MessageType(int) 说明：必填。取值为1，标识是一个游戏设置消息。 字段：PictureQualityMaxLevel(byte) 说明： 必填。标识画质支持的最高等级，如最高支持高清，则该项的值为3。 等级分为1-5分别标识流畅，均衡，高清，HDR高清，超高。 字段：PictureQualityCurLevel(byte) 说明： 必填。标识画质的当前等级，如当前设置为高清，则该项的值为3。 字段：FrameRateMaxValue(float) 说明：必填。标识支持的最高帧率。如最高支持60帧，则该项的值为60。 字段：FrameRateCurValue(float) 说明：必填。标识设置的帧率，如当前设置为50帧，则该项的值为50。 字段：ResolutionMaxValue(String) 说明：必填。标识支持的最高分辨率。例如: "1920x1080"。 字段：ResolutionCurValue(String) 说明：必填。标识当前设置的分辨率。例如: "1280x720"。 字段：AntiAliasing(boolean) 说明：必填。标识当前是否开启抗锯齿。 字段：Shadow(boolean) 说明：必填。标识当前是否开启阴影。 字段：MultiThread(boolean) 说明：必填。标识当前是否开启多线程。 字段：Particle(boolean) 说明：必填。标识当前是否开始粒子效果。 字段：HDMode(boolean) 说明：必填。标识当前是否开启高清模式。 字段：TempTrendThresholdLevel(int) 说明：选填。标识温度趋势目标阈值。 不同档位及其建议如下： * 1：无需处理。 * 2：建议降低无感知业务规格，例如后台更新降速或延迟运行。 * 3：建议暂停无感知业务，降低游戏非核心业务的规格，例如前台更新降速。 * 4：建议降低游戏全场景规格，例如分辨率、画质。 * 5：建议游戏进一步降低规格。 * 6：建议游戏降至最低规格。|
|String gameInfoJson|游戏开局消息：在游戏一局开始和结束时发送。 JSON格式样例： ``` { "MessageType":2, "Status":1 } ``` 字段：MessageType(int) 说明： 必填。取值是2，标识是一个游戏开局消息。 字段：Status(byte) 说明：必填。标识一局游戏的开始和结束。 * 1：开局 * 0：结束|
|String gameInfoJson|游戏场景消息： 在游戏进入某个场景、场景进行中和场景结束时发送给手机，消息主要包含的是场景重要性及性能功耗调优用到的相关参数。 ``` { "MessageType":3, "SceneID":1, "Description":"driving", "ImportantLevel":5, "SceneFreq":3, "SceneTime":1000, "RecommendCpuLevel":5, "RecommendGpuLevel":5, "RecommendDdrLevel":5, "RecommendFps":60, "MaxFps":60, "CurrentFps":56.6, "KeyThread":"render|5006|render|5007|logic|6008|logic|6009|logic|6010|net|7009", "DrawCallNum":5000, "VertexNum":60000, "TriangleNum":30000, "ShaderNum":500, "TextureNum":1000, "MeshNum":100, "PassNum":5, "PeopleNum":6 } ``` 字段：MessageType(int) 说明：必填。取值为3，标识是一个游戏场景消息。 字段：SceneID(int) 说明：必填。标识游戏场景ID。游戏常见场景ID编码： * 0：回切场景标识结束 * 1：游戏启动 * 2：游戏内更新 * 3：登录过程 * 4：主界面 * 5：加载一局游戏（自己加载） * 6：加载一局游戏（自己加载完毕，等待其他玩家） * 7：游戏中 * 8：观战模式 （游戏特殊场景编码：从100开始自定义） 字段：Description(String) 说明：选填。标识游戏场景描述，如 "driving"等。 字段：ImportantLevel(byte) 说明：必填。标识场景重要程度。分1 - 5，共5个等级，重要程度从1到5依次递增。 字段：SceneFreq(int) 说明：选填。标识该场景在一局游戏中出现的次数。依据游戏大数据给出该场景在一局游戏中出现的次数。 字段：SceneTime(int) 说明：选填。标识该场景持续的时间，单位ms。依据游戏大数据给出该场景持续的时间。 字段：RecommendCpuLevel(byte) 说明：选填。标识游戏推荐的该场景下的cpu等级。 字段：RecommendGpuLevel(byte) 说明：选填。标识游戏推荐的该场景下的gpu等级。 字段：RecommendDdrLevel(byte) 说明：选填。标识游戏推荐的该场景下的ddr等级。 字段：RecommendFps(float) 说明：选填。标识游戏推荐的该场景的帧率。 字段：MaxFps(float) 说明：选填。标识游戏指定的该场景的最大帧率。 字段：CurrentFps(float) 说明：选填。标识游戏指定的该场景的当前帧率。 字段：KeyThread(String) 说明：选填。标识游戏在该场景下的关键线程。 * render：渲染线程 * logic：逻辑线程 * net：网络线程 字段：DrawCallNum(int) 说明：选填。标识游戏在该场景下每帧的平均Drawcall数。 字段：VertexNum(int) 说明：选填。标识游戏在该场景下每帧的平均模型顶点数。 字段：TriangleNum(int) 说明：选填。标识游戏在该场景下每帧的平均模型三角形数。 字段：ShaderNum(int) 说明：选填。标识游戏在该场景下每帧的平均shader数量。 字段：TextureNum(int) 说明：选填。标识游戏在该场景下每帧的平均纹理数量。 字段：MeshNum(String) 说明：选填。标识游戏在该场景下每帧的平均mesh数量。 字段：PassNum(int) 说明：选填。标识游戏在该场景下每帧渲染的通道数。 字段：PeopleNum(int) 说明：选填。标识游戏在该场景下的同屏人数。|
|String gameInfoJson|游戏触控区域消息： 在游戏进入到游戏场景时发送给手机系统有效触控区域， 若在游戏场景中有效触控区域发生改变也要发送手机系统。 JSON格式样例： ``` { "MessageType":4, "ValidRegin":"direct:3:(10,10,30,30)|op:2:(200,200,210,210)|set:1:(500,500,510,510)", "HandleTime":10 } ``` 字段：MessageType(int) 说明：必填。取值是4，标识是一个游戏触控区域消息。 字段：ValidRegin(String) 说明：必填。标识游戏场景中有效的触控区域，包括属性，使用频率和区域属性定义： * 方向：diret * 操作：op * 设置：set 使用频率定义：1-3，分别为低，中，高三个等级区域定义： rect表示法，左上角和右下角坐标格式样例： direct:3:(10,10,30,30)\|op:2:(200,200，210,210)\|set:1:(500,500,510,510) 字段：HandleTime(int) 说明：选填。标识游戏应用收到input事件到应用做出响应的时间，单位ms。|
|String gameInfoJson|游戏网络状态消息： 在游戏进入到游戏场景时把网络状态发送给手机， 当在游戏场景中网络延时或负载跳变时要发送给手机系统。 JSON格式样例： ``` { "MessageType":5, "NetLatency":"total:50|up:20|server:10|down:20", "NetServerIP":"10.111.65.22", "NetLoad":2 } ``` 字段：MessageType(int) 说明：必填。取值是5，标识是一个游戏网络状态消息。 字段：NetLatency(String) 说明：必填。标识游戏场景中网络时延，单位ms 。 0-50-100-150-200... 当总时延出现跳变时，发送一次时延，在发送时延时要包含上行，下行和服务器处理时间。 格式：total:50\|up:20\|server:10\|down:20 字段：NetServerIP(String) 说明：必填。标识游戏场景中游戏服务器地址。 字段：NetLoad(byte) 说明：选填。标识游戏网络负载等级，分1-3共三个等级： * 1：轻度负载 * 2：中度负载 * 3：重度负载|

#### getPhoneInfo

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getPhoneInfo() 主动获取设备信息。比如温度、CPU负载和GPU负载信息。 该方法取得的设备信息与通过GameCallback接口的[onPhoneInfoUpdated](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamecallback-0000001050121692#section1461104041212)方法得到的设备信息格式一致。 说明： * 须通过registerGame方法注册成功后，再通过该方法获取设备信息，否则获取不到信息。 * 返回设备信息为GameCallback接口的[onPhoneInfoUpdated](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamecallback-0000001050121692#section1461104041212)方法最近一次回调反馈的内容。|

Returns  

|Type|Description|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|设备的信息。比如温度、CPU负载和GPU负载信息。该值可能为null或empty。 返回内容与GameCallback接口的[onPhoneInfoUpdated](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamecallback-0000001050121692#section1461104041212)方法回调反馈的内容相同。|
