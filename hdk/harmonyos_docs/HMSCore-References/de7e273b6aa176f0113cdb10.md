# 查询合单订单

## 功能介绍

商户用此接口查询已经存在的交易订单状态。
> 说明
>
> 建议优先通过通知回调来更新订单状态，请勿高频轮询调用此接口查询订单状态，否则可能触发"调用频率受限"的报错。

* **[商户订单号查询合单订单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-combined-query-merc-order-0000001755135342)**
