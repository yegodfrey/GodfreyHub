# Subscription服务验证购买Token

#### 功能介绍

此接口用于校验购买的商品，判断商品是否已经成功购买，是否在有效期内。  

#### 场景描述

在完成一笔支付后，IAP客户端会返回商品购买单详情JSON字符串[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)和签名字符串dataSignature。[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中有用于唯一标识商品和用户对应关系的purchaseToken。

通过签名验证，可确保[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)有效性。您还可以解析出[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的purchaseToken数据，调用华为应用内支付服务器提供的Subscription服务验证购买Token接口。为避免资金损失，您在验签成功后，必须校验InAppPurchaseData中的productId、price、currency等信息的一致性。验证方法和公钥获取方式可参见[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。一般应该判断商品是否已经成功购买，对于订阅型商品返回最近的收费情况，包括何时收费以及是否在有效期内。

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为应用内支付服务器|
|接口URL|{rootUrl}/sub/applications/v2/purchases/get 说明： rootUrl在不同站点有不同的url：您应固定选择最近站点的Subscription服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1954123781815)和[站点选择](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1741234185817)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Content-Type|是|String|取值为：application/json; charset=UTF-8|
|Authorization|是|String|认证信息，使用Access Token进行鉴权，这里使用开放平台鉴权提供的服务接口获取Access Token，格式说明参考[公共说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127)，获取方式参考[获取应用级AT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/obtain-application-level-at-0000001051066052)。|

Request Body  

|参数|是否必选|参数类型|描述|
|:-------------|:---|:-----|:--------------------------|
|subscriptionId|是|String|订阅ID。|
|purchaseToken|是|String|商品的购买Token，发起购买和查询订阅信息均会返回。|

#### 响应参数

Response Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:----------------------------------|
|Content-Type|是|String|取值为：application/json; charset=UTF-8|

Response Body  

|参数|是否必选|参数类型|描述|
|:-----------------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|responseCode|是|String|返回码。 * 0：成功。 * 其他：失败，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-error-code-0000001050166248)。|
|responseMessage|否|String|响应描述。|
|inappPurchaseData|否|String|包含购买详情的字符串（JSONString格式），格式请参见[InappPurchaseDetails](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-data-model-0000001050986133#section264617465219)。|
|dataSignature|否|String|inappPurchaseData基于应用RSA IAP私钥的签名信息，签名算法为signatureAlgorithm。应用请参见[对返回结果验签](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-signature-returned-result-0000001050033088)使用IAP公钥对inappPurchaseData的JSON字符串进行验签。|
|signatureAlgorithm|是|String|签名算法。默认为：SHA256WithRSA/PSS。|
