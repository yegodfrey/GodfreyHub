# ScreenBarrier

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class [ScreenBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/screenbarrier-0000001054982744) extends Object 屏幕围栏，包括状态驻留、亮屏，灭屏和解锁的围栏。 开发者应当提醒用户手机屏幕状态可能被App监控。|

#### Public Methods

#### keeping

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) keeping(int screenStatus) 状态驻留围栏，开发者添加亮屏、灭屏、解锁三种屏幕状态驻留围栏后，当屏幕状态保持为指定状态时，此围栏状态为TRUE并触发围栏事件上报。|

Parameters  

|Name|Description|
|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|screenStatus|屏幕状态。 * [SCREEN_ON](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/screenstatus-0000001055301330#section22611495317)：亮屏 * [SCREEN_OFF](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/screenstatus-0000001055301330#section828413582511)：灭屏 * [UNLOCK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/screenstatus-0000001055301330#section8227162310510)：解锁状态|

Returns  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|情景感知围栏。|

Throws  

|Name|Description|
|:-----------------------|:-----------------------------------------------------|
|IllegalArgumentException|参数不合法（screenStatus不为SCREEN_ON，SCREEN_OFF、UNLOCKED时）异常。|
