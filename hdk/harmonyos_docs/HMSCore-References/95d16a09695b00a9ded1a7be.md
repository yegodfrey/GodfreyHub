#### Public Methods

#### getBeaconStatus(BeaconStatus.Filter... filters)

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)\<[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-beaconstatusresponse-0000001050166011)\> getBeaconStatus([BeaconStatus.Filter](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/status-filter-4-0000001050167033)... filters) 使用可变数量的filters参数，获取相关信标的信息。 信标快照仅在API级别24或更高版本上可用。要使用此方法，您的应用必须在AndroidManifest.xml中声明android.permission.BLUETOOTH和android.permission.ACCESS_FINE_LOCATION权限，并且用户必须在运行时选择同意。|

Parameters  

|Name|Description|
|:------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
|filters|信标过滤器，可以通过以下任一方式构造过滤器： * 按照在信标下注册的附件信息的命名空间和类型进行过滤。 * 按照在信标下注册的附件信息的命名空间、类型和内容进行过滤。 * 按照信标的广播ID进行过滤（目前支持Eddystone协议中的UID和iBeacon协议中的UUID+Major+Minor）。|

Returns  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)\<[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-beaconstatusresponse-0000001050166011)\>|返回[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-beaconstatusresponse-0000001050166011)的Task泛型。可以使用Task中的isSuccessful()判断是否成功。如果成功，可继续通过[BeaconStatusResponse](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-capture-beaconstatusresponse-0000001050166011)获取信标数据；否则表示获取信标信息失败。|
