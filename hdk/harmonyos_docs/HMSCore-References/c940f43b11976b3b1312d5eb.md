# setEnableIndication：设置启用指示还是启用通知

**接口原型**

public void setEnableIndication (boolean isEnableIndication)

方法描述：设置低功耗蓝牙工作模式为启用指示模式或启用通知模式。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:-----------------|:------|:-----------------------------------------|:---|
|isEnableIndication|Boolean|true：启用指示。 false：不启用指示，启用通知。 不设置默认是 false。|M|
[**表1**请求参数]

**响应参数**

无
> 说明
>
> 该方法需要和notifyBLECharacteristicValueChange配合使用，在notifyBLECharacteristicValueChange前调用；不设置默认是false。
