# AdjustConfig

|Class Info|
|:------------------------------------------------------------------------|
|public class AdjustConfig 该类是华为响应式HwRspViewPager控件的配置类，xml里指定的参数都可以在这里配置。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------|
|void|setNeedAdjust(boolean isNeedAdjustView) 设置大屏下是否需要执行响应式逻辑|
|void|setAdjustType(AdjustType adjustType) 使用哪种范式来调整ViewPager，默认使用居中的方式|
|void|setIndicatorViewId(Integer indicatorViewId) 导航点View ID|
|void|setPageMargin(Integer pageMargin) Item间距，如果用户未指定，则使用小屏下设置的值，如果还未设置，则使用默认值12dp|
|void|setWidthResizeType(ResizeType widthResizeType) 单个Item的宽调整策略|
|void|setScaleWidth(Float scaleWidth) 宽缩放大小，如果未配置则默认为0.5|
|void|setHeightResizeType(ResizeType heightResizeType) 单个Item的高度调整策略|
|void|setScaleHeight(Float scaleHeight) 高度缩放大小，如果未配置则默认为0.5|
|void|setAspect(Float aspect) 单个Item的高宽比，如果未设置则使用ViewPager的高宽比：VPH/VPW|
|void|setOnePageItemCnt(Integer onePageItemCnt) 一页完整显示多少个Item，不设置则使用默认值2|
|void|setItemCnt(Integer itemCnt) 设置ViewPager包含的Item总数|
|void|setOffPageLimit(Integer offPageLimit) Item的缓存数量，不设置则使用系统默认值|
