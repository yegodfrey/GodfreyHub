# HWNaviLine

#### 概述

在地图上绘制彩虹蚯蚓线。  

#### 构造函数

|函数|描述|
|:------------------------------------|:------------------------------------------------------------------|
|HWMapJsSDK.HWNaviLine(naviLineOption)|naviLineOption：设置蚯蚓线的属性，详情见[NaviLineOptions](#section366163604219)。|

#### 事件

|事件|描述|用法|
|:----|:----|:----------------------------------------------------------|
|click|鼠标单击。|naviLine.addListener('click', callback)，参数callback为自定义回调函数。|

#### AnimateOption

|参数|是否必选|类型|说明|
|:------|:---|:------|:-------------------------------------------------------------|
|animate|否|boolean|蚯蚓线是否展示动画。 * true：显示 * false：不显示 默认为false。|
|timeout|否|int|蚯蚓线生长动画时长，单位：ms。取值范围：大于等于1000，默认1000ms，表示蚯蚓线在1s内完成从起点到终点的生长动画。|

#### NaviLineOptions

|参数|是否必选|参数类型|描述|
|:-----------------|:---|:------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------|
|animateOption|否|[AnimateOption](#section1698865754215)|初始动画定义。|
|collisionEnable|否|Boolean|是否开启碰撞。 * true：开启 * false：关闭 默认为true。|
|fillColor|否|String|填充颜色，默认#000000。对于naviLineFillColors中indexes内未包含的部分使用此颜色渲染。|
|fillWidth|否|Number|填充宽度，默认1。|
|map|否|[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)|添加的地图图层，如果不设置，则不在地图上显示蚯蚓线。|
|NaviLineFillColors|否|[NaviLineFillColors](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section1922663710261)|每段路线的填充颜色。|
|NaviLineTexts|否|[NaviLineTexts](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section17656164119261)|每段路线的路名。|
|NaviLineCodes|否|[NaviLineCodes](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section12579114452512)|每段路线的路牌。|
|points|否|Array\<[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)\>|路线的点集，如果不设置，则不在地图上显示蚯蚓线。|
|strokeColor|否|String|描边颜色，默认#000000。|
|strokeWeight|否|Number|描边宽度，默认0。|
|textColor|否|String|文字颜色，默认#000000。|
|textSize|否|Number|文字大小，默认16。|
|textStrokeColor|否|String|文字描边颜色，默认#ffffff。|
|textStrokeWeight|否|Number|文字描边宽度，单位：px。取值范围：\[0, 10\]，默认0。|
|zIndex|否|Number|压盖顺序，即多个蚯蚓线的压盖关系，默认0。|
