# 获取用户信息

## 功能介绍

应用服务器向华为帐号服务器调用该接口获取华为帐号用户昵称、头像、手机号码信息。

## 场景描述

应用已经获取到Access Token并已申请帐号开放信息对应权限后，应用需要获取帐号用户昵称、头像、手机号码等信息。

## 使用约束

不涉及。

## 接口原型

|**承载协议**|HTTPS POST|
|---------|------------------------------------------------------------------------------------------------------|
|**接口方向**|开发者服务器->华为帐号服务器|
|**接口URL**|https://account.cloud.huawei.com/rest.php?nsp_svc=GOpen.User.getInfo|
|**数据格式**|请求消息：Content-Type: application/x-www-form-urlencoded 响应消息：Content-Type: application/json;charset=UTF-8|

## 请求参数

**Request Header**

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:-------------------------------------|
|Content-type|否|String|取值为：application/x-www-form-urlencoded。|

**Request Body**

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|access_token|是|String|通过[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)或者授权接口获取到的Access Token。 > 说明 > 该参数需经过UrlEncode处理后，再添加进请求消息中。|
|getNickName|否|int|控制昵称、匿名化帐号的返回顺序。 * 0：返回匿名化帐号，没有匿名化帐号时返回昵称（默认）。 * 1：返回昵称，没有昵称时返回匿名化帐号。|

## 请求示例

请通过POST方式调用，示例如下：

```screen
POST /rest.php?nsp_svc=GOpen.User.getInfo HTTP/1.1
Host: account.cloud.huawei.com
Content-Type: application/x-www-form-urlencoded

access_token=*****&getNickName=0
```

## 响应参数

调用成功时，返回如下：

**Response H** **eader**

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:----------------------------------|
|Content-type|否|String|取值为：application/json;charset=UTF-8。|

**Response Body**

|**参数**|是否必选|参数类型|描述|
|:----------------|:---|:-----|:----------------------------------------------------------------------------|
|openID|否|String|用户OpenID。|
|unionID|否|String|用户UnionID。|
|displayName|否|String|* getNickName为0或不传时，返回匿名化帐号，没有匿名化帐号时返回昵称。 * getNickName为1时，返回昵称，没有昵称时返回匿名化帐号。|
|headPictureURL|否|String|头像。|
|mobileNumber|否|String|用户手机号。|
|email|否|String|用户邮箱。|
|loginMobileNumber|否|String|一键登录功能提供的华为帐号绑定号码。|

> 说明
>
> 当应用有获取头像、手机号、邮箱权限后才返回对应信息。
