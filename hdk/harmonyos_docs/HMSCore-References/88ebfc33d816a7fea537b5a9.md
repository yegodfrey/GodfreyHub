# HWCoordinateConverter

## 概述

地球坐标转火星坐标类，传入1个或1组WGS84坐标，转换为GCJ02坐标。适用于中国区范围坐标转换，在中国地图范围内转换为GCJ02坐标，中国地图范围外保持WGS84坐标。

## 构造函数

|函数|**描述**|
|:-------------------------------|:---------------|
|HWMapJsSDK.HWCoordinateConverter|WGS84坐标转GCJ02坐标。|

## 方法

|**方法**|**描述**|**参数类型**|**返回值**|
|:-----------------|:-------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------|
|convert(locations)|WGS84坐标转GCJ02坐标。最多可以传入512个坐标系，超过512个，返回null。|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)[] 地球坐标。|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-params-0000001051070092#section188758113562)[] 火星坐标。|
