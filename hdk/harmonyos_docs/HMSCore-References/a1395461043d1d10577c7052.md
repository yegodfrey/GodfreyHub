#### Public Methods

#### onStatusChanged

|Method|
|:-------------------------------------------------------------------------------|
|public void onStatusChanged(String status, String uniqueId) 当广告应用下载状态发生变化后调用的方法。|

Parameters  

|Name|Description|
|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|status|状态描述： 1. DOWNLOAD：下载未开始，应用初始状态。 2. DOWNLOADING：应用下载中。 3. DOWNLOADFAILED：下载失败。 4. WAITING：下载等待中。 5. PAUSE：应用下载暂停中。 6. INSTALL：等待安装。 7. INSTALLING：安装中。 8. INSTALLED：安装完毕，此时应用可打开。|
|uniqueId|应用唯一标识，即appInfo的uniqueId。|
