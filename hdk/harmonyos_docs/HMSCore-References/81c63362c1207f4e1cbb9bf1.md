# 血糖数据格式

![](https://media:801784947929357874)  
* 以下数据格式只适用于saveHeathData和saveMultipleHealthData接口。
* 每次存储血糖数据仅可存入一个时间段的血糖数据。

BloodSugar (type: 10001, dataTypeName: com.huawei.instantaneous.blood_glucose)  

|字段Key|数据类型|描述|可选选项|
|:--------------|:------|:-----------------------------------------|:---|
|beforeBreakfast|double|早餐前（空腹）血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|afterBreakfast|double|早餐后血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|beforeLunch|double|午餐前血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|afterLunch|double|午餐后血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|beforeDinner|double|晚餐前血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|afterDinner|double|晚餐后血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|beforeBedtime|double|睡前血糖 ，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|earlyMorning|double|凌晨血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|randomness|double|随机时间段血糖，取值范围1.0\~33.0，建议保留一位小数，单位mmol/L。|O|
|isConfirmed|boolean|判断当前存入的血糖字段的值的状态，true表示确认存储，false表示待确认存储。|O|
