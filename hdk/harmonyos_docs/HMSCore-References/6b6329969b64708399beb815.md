# writeBLECharacteristicValue：通过指定服务的ID写入指定数据

接口原型

public void writeBLECharacteristicValue(String deviceId, String serviceId, String characteristicId, String data, String function)

方法描述：通过指定服务的ID写入指定数据。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:---------------|:-----|:----------------------------------------|:---|
|deviceId|String|蓝牙设备ID，通过接口getDeviceId()获取。|M|
|serviceId|String|蓝牙设备特征值对应服务的 UUID（不使用4位的简写，用完整写法的UUID）。|M|
|characteristicId|String|蓝牙设备特征值的 UUID（不使用4位的简写，用完整写法的UUID）。|M|
|data|String|写入的二进制数据，以16进制字符串方式构造。|M|
|function|String|通过指定服务的ID写入指定数据的回调函数，该回调函数有一个参数，详情参见响应参数。|M|
[表1 请求参数]

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:------------|:---|
|errCode|Number|错误码：0, 90001。|M|
[表2 响应参数]
