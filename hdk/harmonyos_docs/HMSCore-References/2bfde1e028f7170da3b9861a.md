# Maps Static API

#### 功能介绍

静态图服务通过发送Http请求返回一张地图图片，您可以指定请求的地图位置、图片大小、以及在地图上添加覆盖物，如标签、折线、多边形。

#### 场景描述

通过HTTP请求发送的URL参数创建地图图片并直接嵌入到网页中，而无需通过JavaScript或动态页面加载。  

#### 使用约束

服务调用量的限制请查看[服务定价](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/about-charging-0000001051637068)。

|markerStyles|否|String|marker样式描述信息，可指定的属性包括： * size * label * color * icon 参考样例： size:mid\|color:black\|label:C\|icon:https%253A%252F%252Fwww-file.huawei.com%252F-%252Fmedia%252Fcorporate%252Fimages%252Fhome%252Flogo%252Fhuawei_logo.png。 说明： 1. icon属性将自定义marker显示的图标，此时size、color属性将不再生效。 2. icon对应的URL地址必须为可以从互联网下载到的PNG格式图片，图片可以是长方形，大小不能大于16KB，像素不超过128\*128。 3. 由于该接口为GET类型，发送请求后会被自动进行一次URL解码，因此icon对应的属性值必须进行两次URL编码。|
|path|否|String|Path描述信息，支持Path样式、经纬度或地址，支持输入多组位置信息，通过\|分开。 path=Path样式\|{纬度1,经度1}\|{纬度2,经度2}\|地址，如果不指定Path样式，使用pathStyles作为默认样式。 说明： markers/path和location/zoom至少需要输入一组。如果都存在，以location/zoom为主。|
|pathStyles|否|String|path样式描述信息，可指定的属性包括： * color * weight * fillcolor 如果有fillcolor，表示path是多边形，否则是折线。 参考样例：color:0x0000ff80\|weight:1\|fillcolor:0x0000ff80。|
|logo|否|String|logo样式描述信息，可指定属性包括logoAnchor、visible。 * logoAnchor取值包括： * bottomleft：左下（默认） * bottomright：右下 * topleft：左上 * topright：右上 * visible取值包括： * true：logo可见（默认） * false：logo不可见 静态图logo默认显示在左下角。 参考样例：logoAnchor:bottomleft\|visible:true。|
|signature|否|String|签名，通过签名密钥加密生成的消息签名。推荐使用该签名功能，与API密钥联合控制保证接口安全性。 说明： 获取签名密钥的方式请参见[获取签名密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-static-map-introduction-0000001059170753#section91071644142315)。|
|presetStyleId|否|String|支持设置地图预置样式，可指定的属性包括： * standard：标准样式（默认） * night：深色样式 * simple：简单样式|

    private String sign(String urlToSign, String secret)
        throws MalformedURLException, NoSuchAlgorithmException, InvalidKeyException {
        URL url = new URL(urlToSign);
        String canonicalUrl = url.getPath() + "?" + new CanonicalQueryString(url.getQuery()).toString();

        SecretKey secretKey = new SecretKeySpec(secret.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        Mac mac = Mac.getInstance("HmacSHA256");
        mac.init(secretKey);
        byte[] sigBytes = mac.doFinal(canonicalUrl.getBytes());
        String signature = Base64.getEncoder().encodeToString(sigBytes);
        signature = signature.replace('+', '-');
        signature = signature.replace('/', '_');
        return signature;
    }

    static class CanonicalQueryString {
        private static final int INIT_BUFFER_SIZE = 128;

        /**
         * The constant PARAMETER_EQ.
         */
        public static final String PARAMETER_EQ = "=";

        /**
         * The constant PARAMETER_SEP.
         */
        public static final String PARAMETER_SEP = "&";

        private SortedMap<String, List<String>> params = new TreeMap<>();

        /**
         * Instantiates a new Canonical query string.
         *
         * @param queryString the query string
         */
        public CanonicalQueryString(String queryString) {
            if (queryString == null || queryString.length() == 0) {
                return;
            }

            for (String pair : queryString.split(PARAMETER_SEP)) {
                int idx = pair.indexOf(PARAMETER_EQ);
                if (idx != -1) {
                    String value = pair.substring(idx + 1);
                    if (value == null || value.length() == 0) {
                        continue;
                    }
                    String paramKey = pair.substring(0, idx);
                    List<String> values = params.computeIfAbsent(paramKey, key -> new ArrayList<>());
                    try {
                        values.add(URLDecoder.decode(value, "UTF-8"));
                    } catch (UnsupportedEncodingException e) {
                        // ignore
                    }
                }
            }
        }

        @Override
        public String toString() {
            StringBuilder sb = new StringBuilder(INIT_BUFFER_SIZE);
            for (SortedMap.Entry<String, List<String>> item : params.entrySet()) {
                String key = item.getKey();
                for (String value : item.getValue()) {
                    if (sb.length() > 0) {
                        sb.append(PARAMETER_SEP);
                    }
                    sb.append(key).append(PARAMETER_EQ).append(value);
                }
            }

            return sb.toString();
        }
    }
}

    private String sign(String urlToSign, String secret)
        throws MalformedURLException, NoSuchAlgorithmException, InvalidKeyException {
        URL url = new URL(urlToSign);
        String canonicalUrl = url.getPath() + "?" + new CanonicalQueryString(url.getQuery()).toString();

        SecretKey secretKey = new SecretKeySpec(secret.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        Mac mac = Mac.getInstance("HmacSHA256");
        mac.init(secretKey);
        byte[] sigBytes = mac.doFinal(canonicalUrl.getBytes());
        String signature = Base64.getEncoder().encodeToString(sigBytes);
        signature = signature.replace('+', '-');
        signature = signature.replace('/', '_');
        return signature;
    }

    static class CanonicalQueryString {
        private static final int INIT_BUFFER_SIZE = 128;

        /**
         * The constant PARAMETER_EQ.
         */
        public static final String PARAMETER_EQ = "=";

        /**
         * The constant PARAMETER_SEP.
         */
        public static final String PARAMETER_SEP = "&";

        private SortedMap<String, List<String>> params = new TreeMap<>();

        /**
         * Instantiates a new Canonical query string.
         *
         * @param queryString the query string
         */
        public CanonicalQueryString(String queryString) {
            if (queryString == null || queryString.length() == 0) {
                return;
            }

            for (String pair : queryString.split(PARAMETER_SEP)) {
                int idx = pair.indexOf(PARAMETER_EQ);
                if (idx != -1) {
                    String value = pair.substring(idx + 1);
                    if (value == null || value.length() == 0) {
                        continue;
                    }
                    String paramKey = pair.substring(0, idx);
                    List<String> values = params.computeIfAbsent(paramKey, key -> new ArrayList<>());
                    try {
                        values.add(URLDecoder.decode(value, "UTF-8"));
                    } catch (UnsupportedEncodingException e) {
                        // ignore
                    }
                }
            }
        }

        @Override
        public String toString() {
            StringBuilder sb = new StringBuilder(INIT_BUFFER_SIZE);
            for (SortedMap.Entry<String, List<String>> item : params.entrySet()) {
                String key = item.getKey();
                for (String value : item.getValue()) {
                    if (sb.length() > 0) {
                        sb.append(PARAMETER_SEP);
                    }
                    sb.append(key).append(PARAMETER_EQ).append(value);
                }
            }

            return sb.toString();
        }
    }
