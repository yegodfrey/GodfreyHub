# HwCounterTextLayout

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------|
|public class HwCounterTextLayout extends LinearLayout HwCounterTextLayout包含了一个编辑框和一个文本控件，当输入文本的长度超过布局最大长度的90%以后会显示提示。|

#### XML Attributes

|Qualifier and Type|Attributes Name and Description|
|:-----------------|:----------------------------------|
|enum|hwShapeMode 定义输入框形状。|
|int|hwMaxLength 定义最大字符限制。|
|reference|hwCounterTextAppearance 定义华为计数文本皮肤。|
|drawable|hwErrorLinearEditBg 定义华为线性错误编辑框背景。|
|drawable|hwErrorResBg 定义华为错误资源背景。|
|drawable|hwEditTextBg 定义华为编辑文本背景。|
|drawable|hwLinearEditBg 定义线性编辑背景。|
