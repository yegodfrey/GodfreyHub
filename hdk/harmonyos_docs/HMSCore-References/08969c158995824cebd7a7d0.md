# OnSuccessListener

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Interface Info|
|:------------------------------------------------------------------------------------------------|
|public interface OnSuccessListener<TResult> 任务成功监听接口，任务执行成功后，会回调此接口中的onSuccess(TResult result)方法。|
