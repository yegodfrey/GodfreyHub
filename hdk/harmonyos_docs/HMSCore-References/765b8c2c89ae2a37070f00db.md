#### setTtl(int ttl)

|Method|
|:------------------------------------------------------------------------------------------------------------|
|public RemoteMessage.Builder setTtl(int ttl) 当设备离线时，设置离线消息的最大缓存时间，单位：秒。如果不设置，消息将尝试立即发送而不会缓存，如果设备不可连接，那么消息将丢弃。|

Parameters  

|Name|Description|
|:---|:----------------------------------------|
|ttl|推送服务缓存离线消息的最大时间，单位：秒。支持设置最大1296000秒（15天）。|

Returns  

|Type|Description|
|:--------------------|:----------|
|RemoteMessage.Builder|实例对象。|

Throws  

|Name|Description|
|:-----------------------|:------------------------------------------------------------------|
|IllegalArgumentException|ttl的值必须满足闭区间\[1, 1296000\]，否则会抛出不合法参数（IllegalArgumentException）的异常。|

#### setCollapseKey(String collapseKey)

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public RemoteMessage.Builder setCollapseKey(String collapseKey) 设置消息分类标识，用于控制离线消息的覆盖功能。对于缓存的离线消息，具有相同分类标识的最新消息会覆盖老的消息。当推送服务检测到目标设备离线时，下发给离线用户的多条消息，推送服务会按照设置的ttl将消息进行缓存，待用户上线后会将缓存的消息下发给用户。|

Parameters  

|Name|Description|
|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|collapseKey|* -1：表示对于本应用的离线消息待用户上线后全部发送给用户。 * 0：表示对于本应用的离线消息待用户上线后按照华为推送系统默认策略发送给用户（一般是最新的一条）。 * 1\~100：表示对消息进行分组，例如如果您发送了10条消息，其中前5条的[collapse_key](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5318198112317)为1，后5条的[collapse_key](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5318198112317)为2，那么待用户上线后[collapse_key](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5318198112317)为1和2的分别下发最新的一条消息给最终用户。|

Returns  

|Type|Description|
|:--------------------|:----------|
|RemoteMessage.Builder|实例对象。|
