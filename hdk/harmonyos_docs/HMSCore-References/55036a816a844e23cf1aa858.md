# Overview

包含华为滚动条的相关功能类。

## Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[HwScrollbarHelper](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwscrollbarview-class-hwscrollbarhelper-0000001052942279)|实现了[HwScrollbarView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwscrollbarview-class-hwscrollbarview-0000001052463589)和可滚动控件ListView、ScrollView、RecyclerView绑定，同步两者间的滚动交互。|
|[HwScrollbarView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwscrollbarview-class-hwscrollbarview-0000001052463589)|在实现系统垂直滚动条基础特性上，增加可拖拽快速滚动，并可通过布局调整滚动条的宽，高和位置，使其相比系统滚动条在布局上更加灵活多变。|
