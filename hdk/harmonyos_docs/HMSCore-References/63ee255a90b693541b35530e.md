# 查询代扣订单

## 功能介绍

商户用此接口查询已经存在的交易订单状态。
> 说明
>
> 建议优先通过通知回调来更新订单状态，请勿高频轮询调用此接口查询订单状态，否则可能触发"调用频率受限"的报错。

* **[华为支付系统订单号查询代扣订单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-withhold-query-sys-order-0000001943080966)**   
* **[商户订单号查询代扣订单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-withhold-query-merc-order-0000001970359185)**
