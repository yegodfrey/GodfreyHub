# ProductOrderInfo

|Class Info|
|:--------------------------------------------------------------------------------|
|public class ProductOrderInfo extends Object ProductOrderInfo类主要用于返回某个未发货订单的具体信息。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|[getTradeId](#section16629154810404)() 获取业务订单ID，业务订单号由华为服务器维护，开发者可无需关注。|
|String|[getProductNo](#section796511511409)() 获取未发货的商品ID。|
|String|[getOrderId](#section125495014414)() 获取未发货订单的支付订单ID。|
|String|[getSign](#section1646175174112)() 获取订单的签名字符串，应用服务端可以参见[对掉单数据验签](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/missoder-signature-0000001050164352)向华为服务器验证订单信息的有效性。|
