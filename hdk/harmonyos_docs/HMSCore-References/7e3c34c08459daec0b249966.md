# 例外申请

如果开发者对上述使用规则有特殊需求，可使用[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)功能进行申请。请在申请中包含下列内容：开发者的公司资质，开发者使用接口的场景描述，开发者对接口使用的诉求（比如期望的阈值）。如有其它疑问，可联系[华为技术支持](https://developer.huawei.com/consumer/cn/support/contactUs)咨询。
