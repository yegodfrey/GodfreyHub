# Status

|参数|是否必选|参数类型|描述|
|:---------|:---|:-----|:-----------------------------------------------------------------|
|state|否|String|状态值，取值如下: * active：生效 * inactive：未激活 * completed：已使用 * expired：已过期|
|effectTime|否|String|UTC格式，生效时间|
|expireTime|否|String|UTC格式，失效时间，如果超过此事件，卡券自动按照expired状态处理|

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231120160811.68301479695423493595534007375479:50001231000000:2800:AD8D06294B02DFDCEEAA168B25D272F3AE8213AD5ABA1DDBF0CB28900DCAB2D5.png?needInitFileName=true?needInitFileName=true)  
如果没有填写state参数，卡券状态默认为active。effectTime和expireTime需同时填写或同时不填写。expireTime必须大于当前时间，expireTime必须大于effectTime。调用新增个人化实例接口时，卡券状态不能为expired。

示例：

```
{
    "status": {
        "state": "active",
        "effectTime": "2019-11-13T00:00:00.111Z",
        "expireTime": "2019-11-20T00:00:00.111Z"
    }
}
```
