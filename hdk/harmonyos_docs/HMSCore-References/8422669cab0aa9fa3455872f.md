# TextureMapFragment

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class TextureMapFragment extends Fragment 是一个地图组件，继承安卓原生Fragment，是应用中放置地图的最简单的方式。它提供了一个地图界面，管理地图生命周期，能够加载到Activity的布局文件中使用。通过[getMapAsync](#section1352948173510)，获取地图管理器。 注意： TextureMapFragment不能与[MapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapfragment-0000001050150294)、[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)、[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)混用。|
