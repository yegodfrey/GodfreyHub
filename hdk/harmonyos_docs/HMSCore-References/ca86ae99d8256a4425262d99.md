# 血氧数据格式

![](https://media:801784947929041872)  
以下数据格式只适用于saveHeathData和saveMultipleHealthData接口。

BloodOxygen (type: 2103, dataTypeName: com.huawei.instantaneous.spo2)  

|字段Key|数据类型|描述|可选选项|
|:----|:-----|:---------------------------------|:---|
|SpO2|double|血氧饱和度 百分比 取值范围(0,100\]，即0\<x\<=100|M|
