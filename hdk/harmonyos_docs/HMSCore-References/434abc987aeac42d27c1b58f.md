# setTitleRightBlank：三方设备H5页面TitleBar右侧是否显示为空白

**接口原型**

public void setTitleRightBlank(boolean isShowBlank)

方法描述：三方设备H5页面TitleBar右侧是否显示为空白。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:----------|:------|:------------------------------------------|:---|
|isShowBlank|boolean|true:TitleBar右侧显示空白；false:TitleBar右侧显示三个点按钮|M|
[**表1**请求参数]

> 说明
>
> 目前只支持在三方设备详情页为H5页面时调用该接口。
