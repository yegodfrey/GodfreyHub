# Client

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Interface Info|
|:------------------------------------------------------|
|public interface Client 情景感知服务基本入口。快照、围栏、捐赠能力入口继承该接口实现。|

#### Public Method Summary

|Qualifier and Type|Method Name|
|:-----------------|:------------------------------------------------------------|
|void|[enableUpdateWindow](#section1343372819711)(boolean isEnable)|

#### Public Methods

#### enableUpdateWindow

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void enableUpdateWindow(boolean isEnable) 当Awareness Kit和HMS Core升级时，是否出现弹窗。 注意： 慎用该功能。如果设置成false将无法触发升级，没有升级弹窗提示，相当于在升级弹窗点击了取消升级。在没有完成升级前，Awareness Kit所有功能将不可用。只能等待完成静默升级后，功能恢复。静默升级触发时间一般为7-14天。|

Parameters  

|Name|Description|
|:-------|:----------|
|isEnable|是否允许弹窗。|
