# HAReportPolicy

|Enum Info|
|:-----------------------------------------|
|public enum HAReportPolicy 此接口提供数据自动上报的策略。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:---------------------------------------------------------------|
|public enum|ON_APP_LAUNCH_POLICY 应用启动上报策略。无须设置参数。|
|public enum|ON_MOVE_BACKGROUND_POLICY 应用切后台（包括应用退出）上报策略。无须设置参数。|
|public enum|ON_SCHEDULED_TIME_POLICY 定时上报策略。定时周期范围：[60, 1800]秒，默认60秒。|
|public enum|ON_CACHE_THRESHOLD_POLICY 数据缓存达到阈值自动上报策略。阈值范围：[30, 1000]条，默认30条。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------|
|final void|[setThreshold](#section1695153652215)(long threshold) 设置上报策略需要的参数。|
|final long|[getThreshold](#section10623359304)() 获取上报策略参数。|

## Public Methods

### setThreshold

|Method|
|:------------------------------------------------------------|
|public final void setThreshold(long threshold) 设置上报策略需要的阈值参数。|

**Parameters**

|Name|Description|
|:--------|:----------|
|threshold|上报策略的阈值参数。|

### getThreshold

|Method|
|:-----------------------------------------|
|public final long getThreshold() 获取上报策略参数。|

**Returns**

|Type|Description|
|:---|:---------------------------------------------------------------------------------------------------------------------------|
|long|上报策略的阈值参数。如果设置了策略参数，返回最终生效的参数值；如果没有设置，则取默认值。 ON_MOVE_BACKGROUND_POLICY和ON_APP_LAUNCH_POLICY这两个策略无需设置参数，getThreshold()返回值为-1。|
