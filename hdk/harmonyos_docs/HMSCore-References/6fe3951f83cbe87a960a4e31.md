# 查询有效优惠券信息

## 功能介绍

开发者调用此接口，查询用户在游戏内持有的有效优惠券信息，以便在游戏内进行营销活动展示和优惠提示。

## 申请权限

当前接口受限开放，请通过邮件联系华为运营申请权限。邮件格式如下：

|发送邮箱|gamebeta@huawei.com|
|----|---------------------|
|邮件标题|申请queryCouponInfo接口权限|
|邮件正文|* 游戏名称 * 游戏APP ID|

## 接口约束

* 当前接口仅支持Android游戏调用，不支持HarmonyOS游戏调用。
* 当前接口支持的调用频率：单游戏日上限默认10万次，单游戏单用户日上限默认3次。
* 优惠券信息实时有效，不支持缓存。请在查询后立即展示，以免造成使用优惠券时信息不一致，引发舆情。

## 接口原型

|承载协议|HTTPS POST|
|------|---------------------------------------------------------------------------------|
|接口方向|开发者服务器 -> 华为游戏服务器|
|性能指标|TPS>200|
|最大响应时间|<3000ms|
|接口URL|https://gi-api.cloud.huawei.com.cn/game-data-edge-service/v1/game-data-client-api|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

|参数|是否必选|类型|描述|
|:------------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|是|String|游戏APP ID。 获取游戏APP ID请参见[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/app/agc-help-appinfo-0000001100014694)。|
|clientId|是|String|客户端ID。 [创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)后，在客户端信息列表中获取"ID"值。|
|cpAccessToken|是|String|认证信息，[获取Token（团队级）](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/obtaintoken-team-restapi-0000001721192648)中获取的access_token。|
|accessToken|是|String|用户Access Token。 [通过AuthorizationCode获取Access Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526#section163812617171)中获取的Access Token。|

### Body

|参数|是否必选|类型|描述|
|:--------|:---|:-----|:-----------------------------------------|
|method|是|String|请求方法名。 固定传入"external.gds.queryCouponInfo"。|
|requestId|是|String|请求唯一标识UUID。|

## 响应参数

|参数|是否必选|类型|描述|
|:----------|:---|:-----------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|rtnCode|是|int|服务端结果返回码： * 0：请求成功。 * -1：请求失败。可能因为调用超时或网络波动等异常情况，导致查询失败。建议开发者尝试重新调用接口2次。 * 1：开发者Access Token鉴权失败。 * 2：用户Access Token鉴权失败。请检查Access Token是否过期，若已失效请重新获取。 * 3001：参数错误。请检查请求参数的格式是否正确，或是否缺失请求参数。 * 601100：查询优惠券信息失败。请联系华为运营。 * 603101：无权限查询优惠券信息。请参见[申请权限](#section823712116819)申请接口权限。 * 603102：超出应用级单日限频。 * 603103：超出用户级单日限频。|
|msg|否|String|失败返回码的信息描述。|
|couponInfos|是|List<[CouponInfo](#ZH-CN_TOPIC_0000002596553731__li1976934593514)>|用户在游戏内持有的有效优惠券信息列表。|

* CouponInfo

  |参数|是否必选|类型|描述|
  |:------------|:---|:-----|:-----------------------------------|
  |currentFee|是|Long|优惠券的可用余额。 单位：分。|
  |minFee|是|Long|优惠券的使用门槛金额。 单位：分。|
  |effectiveDate|是|String|有效优惠券的生效时间。 格式为：yyyy-mm-dd HH:mm:ss。|
  |expireDate|是|String|有效优惠券的失效时间。 格式为：yyyy-mm-dd HH:mm:ss。|

## 响应示例

* 响应成功示例

  ```screen
  {

    ]
  }
  ```

  ```screen
  {
    "rtnCode": 3001,

  }
  ```
