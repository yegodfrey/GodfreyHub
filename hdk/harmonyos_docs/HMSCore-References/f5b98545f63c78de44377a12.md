# 返还订阅费用

#### 功能介绍

此接口用于退款给用户，不会取消订阅，在订阅到期之前一直有效。  

#### 场景描述

本接口仅进行最近一次收据的退费操作，不会对订阅产生额外影响，订阅可以继续正常使用，到期后也会进行自动续费。当用户意外购买订阅型商品申诉退款时，可以调用返还订阅费用接口退还用户费用，让用户在本周期免费试用后考虑是否留存订阅关系。若用户下周期不想继续使用该订阅，您可主动调用取消订阅接口进行取消处理，也可让用户自行在HMS Core（APK）的订阅管理页中取消订阅。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241028180417.57801457866104241352886938259919:50001231000000:2800:CA14A6854BB21D8867B86ED924DE0539D44BD93AE6854141585563353BC1BD4A.png?needInitFileName=true?needInitFileName=true)  
* 本接口仅对指定订阅的最近一次收费完成退款处理，不会取消订阅，订阅的有效性和后续的续期仍然会正常发生。
* 在订阅最新收据上已经有退款信息情况下，不会再进行退款。在此情况下，如果您希望处理其他往期收据的费用返还，或者最新收据的剩余费用返还，建议联系本地运营或[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)进行退款。
* 沙盒购买和购买金额为0的商品，退费直接成功。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为应用内支付服务器|
|接口URL|{rootUrl}/sub/applications/v2/purchases/returnFee 说明： rootUrl在不同站点有不同的url：您应固定选择最近站点的Subscription服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1954123781815)和[站点选择](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1741234185817)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Content-Type|是|String|取值为：application/json; charset=UTF-8|
|Authorization|是|String|认证信息，使用Access Token进行鉴权，这里使用开放平台鉴权提供的服务接口获取Access Token，格式说明参见[公共说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127)，获取方式参见[获取应用级AT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/obtain-application-level-at-0000001051066052)。|

Request Body  

|参数|是否必选|参数类型|描述|
|:-------------|:---|:-----|:--------------------------|
|subscriptionId|是|String|订阅ID。|
|purchaseToken|是|String|商品的购买Token，发起购买和查询订阅信息均会返回。|

|参数|是否必选|参数类型|描述|
