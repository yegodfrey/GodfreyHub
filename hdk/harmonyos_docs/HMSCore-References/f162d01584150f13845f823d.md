# UploadState

|Enum Info|
|:--------------------------------------------|
|public enum UploadState 用于指示与媒体HTTP上传关联的上传状态。|

## Enum Value Summary

|Enum Value and Description|
|:---------------------------|
|NOT_STARTED 上传过程尚未开始。|
|INITIATION_STARTED 初始化请求开始。|
|INITIATION_COMPLETE 初始化请求完成。|
|MEDIA_IN_PROGRESS 媒体文件正在上传。|
|MEDIA_COMPLETE 媒体文件上传成功。|
