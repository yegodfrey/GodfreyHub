# Overview

包含华为字母索引相关功能类。  

#### Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[HwAlphaIndexerListView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwalphaindexer-class-hwalphaindexer-0000001052581880)|一般与ListView结合使用，扩展了如下特性： 1. 按首字母或数字大小排序显示列表。 2. 点击对应字母出现高亮，出现字母提示框，并将左侧列表跳转到对应位置。 3. 滑动字母排序列表，字母随手指移动依次高亮，出现字母提示框，左侧列表跟随变化。 4. 滑动左侧列表，根据列表首字母的不同，切换字母排序列表的高亮位置，并出现相应提示框。 在API 24以下的版本上运行本控件，将不会根据列表的内容切换索引的内容，而且繁体中文是按照拼音排序索引的。|
|[HwQuickIndexController](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwalphaindexer-class-hwquickindexcontroller-0000001052861888)|ListView和[HwAlphaIndexerListView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwalphaindexer-class-hwalphaindexer-0000001052581880)滚动回调控制器。|
|[HwSortedTextListAdapter](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwalphaindexer-class-hwsortedtextlistadapter-0000001051781886)|ListView适配器，用于根据list文本排序。|
