## Sample Code

```screen
private void listHistoryVersions(Drive drive, File file, HistoryVersion historyVersion){
    try{
        HistoryVersionList historyVersionList = drive.historyVersions().list(file.getId()).setFields("*").execute();
        if (historyVersionList.getHistoryVersions().size() > 0) {
            historyVersion = historyVersionList.getHistoryVersions().get(0);
        }
    } catch (Exception e){
        Log.e(TAG, "listHistoryVersions error: " + e.getMessage());
    }
}
```
