# 获取Token

#### 功能介绍

应用在与华为服务器端交互前，需要对API客户端接入请求进行授权，鉴权成功后客户端可以获取一个认证Token，应用可以在该Token在有效期内访问已授权的资源。  

#### 使用约束

请参见[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)提前获取用于生成Token的客户端ID和密钥。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/oauth2/v1/token|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------|

#### 请求参数

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|grant_type|是|String|固定传入"client_credentials"。|
|client_id|是|String|客户端ID，即[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)中生成的"客户端ID"。|
|client_secret|是|String|客户端密钥，即[创建API客户端](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agcapi-getstarted-0000001111845114#section103mcpsimp)中生成的"密钥"。|

#### 请求示例

```
POST /api/oauth2/v1/token HTTP/1.1
Host: connect-api.cloud.huawei.com
Content-Type: application/json
{
   "grant_type":"client_credentials",
   "client_id":"26********20",
   "client_secret":"************************"
}
```

#### 响应参数

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:-------------------------------------------------------|
|access_token|是|String|认证Token，在客户端向华为服务端发送请求的Authorization Bearer头中携带。|
|expires_in|是|long|access_token的有效期，单位秒。您需要在过期时间到达时重新调用本接口获取新的access_token。|

#### 响应示例

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
    "access_token": "eyJhbGciOiJIUzU****************",    
    "expires_in": 172800
}
```
