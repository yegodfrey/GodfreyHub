# HmsInstanceId

|Class Info|
|:--------------------------------------------------------|
|public class HmsInstanceId 本类提供了获取AAID以及接入推送服务所需Token的方法。|

### getId

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getId() 同步获取AAID。应用申请Token之前调用本接口获取AAID。Push服务端根据AAID生成应用的Token。如果应用的AAID发生变化，下次申请Token时会生成新的Token。 如果需要应用上报统计事件，则需要获取AAID，作为应用的唯一标识。|

**Returns**

|Type|Description|
|:-----|:----------|
|String|AAID。|

### getCreationTime

|Method|
|:------------------------------------------|
|public long getCreationTime() 获取AAID的生成时间戳。|

**Returns**

|Type|Description|
|:---|:-----------------------------------------|
|long|时间戳，自1970年1月1日0时0分0秒起至AAID生成时间点的时间差，单位：毫秒。|

### deleteId

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void deleteId() throws [ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-common-apiexception-0000001199553037) 删除本地生成的AAID与时间戳，并同步删除已经生成的与本AAID相关的所有Token。此接口为同步接口，在主线程中请勿调用此接口，以免阻塞主线程。|

**Throws**

|Name|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

### getToken(String appId, String scope)

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getToken(String appId, String scope) throws [ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-common-apiexception-0000001199553037) 获取接入推送服务所需的Token。如果本地没有生成AAID，调用本方法会自动生成AAID，Push服务端生成Token时依赖AAID。此接口为同步接口，在主线程中请勿调用此接口，以免阻塞主线程。|

**Parameters**

|Name|Description|
|:----|:-----------------------------------------------------------------------------------------------------------|
|appId|在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)平台创建应用时分配的APP ID。|
|scope|授权范围，您目前可传入常量字符串"HCM"。|

**Returns**

|Type|Description|
|:-----|:--------------|
|String|接入推送服务所需的Token。|

**Throws**

|Name|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-common-apiexception-0000001199553037)|调用此方法失败产生的一切异常通过本异常类抛出，比如在主线程中调用该方法则抛出907122050错误码。您可以通过[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-common-apiexception-0000001199553037)类提供的方法获取错误信息。|
