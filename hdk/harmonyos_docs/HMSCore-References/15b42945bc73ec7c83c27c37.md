# WifiStatus

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Interface Info|
|:--------------------------------------------------------------------------------------------------------------|
|public interface WifiStatus 设备的Wi-Fi连接状态，可以从该类中调用getStatus获得当前状态，如果状态为已连接，可以进一步通过getBssid、getSsid方法获取Wi-Fi相关信息。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-----------------------------------------------|
|static int|[CONNECTED](#section828413582511) 表示已连接Wi-Fi。|
|static int|[DISCONNECTED](#section845115991915) 表示未连接Wi-Fi。|
|static int|[ENABLED](#section144731117208) 表示已开启WLAN。|
|static int|[DISABLED](#section5841122206) 表示未开启WLAN。|
|static int|[UNKNOWN](#section2553542207) 表示未知状态。|

#### Public Methods

#### getStatus

|Method|
|:---------------------------------------------|
|public abstract int getStatus() 获取设备当前Wi-Fi状态。|

Returns  

|Type|Description|
|:---|:--------------------------------------------------------------------------------------------------|
|int|设备当前Wi-Fi状态值。 * 4：表示设备未打开WLAN。 * 3：表示设备已打开WLAN但未连接Wi-Fi。 * 1：表示设备已打开WLAN且已连接Wi-Fi。 * -1：表示其他未知异常情况。|

#### getBssid

|Method|
|:-------------------------------------------------|
|public abstract String getBssid() 获取Wi-Fi的BSSID信息。|

Returns  

|Type|Description|
|:-----|:----------------------------------------------------------------------------------------------------------------------------------|
|String|Wi-Fi的BSSID信息。 当getStatus的值为1（表示已连接Wi-Fi）且HMS Core拥有位置权限（android.permission.ACCESS_FINE_LOCATION）并已打开GPS开关，返回Wi-Fi的BSSID信息；否则返回无效值。|

#### getSsid

|Method|
|:-----------------------------------------------|
|public abstract String getSsid() 获取Wi-Fi的SSID信息。|

Returns  

|Type|Description|
|:-----|:---------------------------------------------------------------------------------------------------------------------------------|
|String|Wi-Fi的SSID信息。 当getStatus的值为1（表示已连接Wi-Fi）且HMS Core拥有位置权限（android.permission.ACCESS_FINE_LOCATION）并已打开GPS开关，返回Wi-Fi的SSID信息；否则返回null。|
