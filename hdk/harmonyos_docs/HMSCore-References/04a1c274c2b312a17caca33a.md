# HuaweiMap.OnMarkerDragListener

|Interface Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface HuaweiMap.OnMarkerDragListener 是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)类的一个内部接口，表示标记拖拽事件进行侦听器，包含三个抽象函数[onMarkerDrag](#section41919381488)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))、[onMarkerDragEnd](#section17191517124913)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))、[onMarkerDragStart](#section15750115717498)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))。用户实现此接口可以对标记拖拽事件进行侦听。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|abstract void|[onMarkerDrag](#section41919381488)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 标记拖动过程中反复回调此方法，标记的位置可通过[getPosition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section49343761418)()获取。|
|abstract void|[onMarkerDragEnd](#section17191517124913)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 标记拖动完成时回调此方法，标记的位置可通过[getPosition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section49343761418)()获取。|
|abstract void|[onMarkerDragStart](#section15750115717498)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 标记拖动开始时回调此方法，标记的位置可通过[getPosition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section49343761418)()获取。|
