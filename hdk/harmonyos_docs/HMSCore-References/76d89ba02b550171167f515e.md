# OnFailureListener

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Interface Info|
|:--------------------------------------------------------------------------------------------|
|public interface OnFailureListener 任务失败监听接口，任务执行失败后，会回调此接口中的onFailure(Exception exception)方法。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------|
|void|[onFailure](#section63617200397)(Exception exception) 任务执行失败后的回调方法。|

## Public Methods

### onFailure

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onFailure(Exception exception) 任务失败后的回调方法。Exception exception为任务执行失败后返回的异常对象。 您可以根据此回调方法，获取到任务执行时抛出的异常对象e。 判断此异常对象如果是一个[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-accountsdk-exception-apiexception-0000001117192584)实例对象，可以根据[ApiException](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-accountsdk-exception-apiexception-0000001117192584)实例对象中包含的[getStatusCode](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-java-accountsdk-exception-apiexception-0000001117192584#section1889231710519)()进行一些必要错误场景的处理。|

**Parameters**

|Name|Description|
|:--------|:--------------|
|exception|任务执行失败后返回的异常对象。|
