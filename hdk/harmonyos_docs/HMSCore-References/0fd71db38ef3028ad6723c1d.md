# 申请退款（应用外支付）

#### 功能描述

此接口用于发起教育中心课程类商品的退款申请。  

#### 接口原型

|承载协议|HTTPS PUT|
|接口方向|开发者服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/dps/v1/usage/order/refund|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|-------------------------------------------------------------------|

#### 使用约束

* 调用本接口前必须要通过华为服务器的API客户端认证，详细方法参见[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appgallerykit_gettoken-0000001050123505)。
* 申请退款功能当前仅支持教育中心客户端的课程类商品，有关课程的配置请参见[课程管理](https://developer.huawei.com/consumer/cn/doc/distribution/content/educenter-cource-0000001050782860)。
* 退款申请可能会根据退款金额触发人工审批流程，请耐心等待。

#### 签名机制

为了确保HTTPS传输的安全性，防止请求参数被篡改，应用需要在调用接口时携带请求参数的签名字符串，用于华为服务器对请求参数进行校验。签名字符串的生成规则如下所示：

1. 将请求参数中需要参与签名的参数，按参数名首字母的ASCII码将参数升序排序，若遇到相同首字母，则比较第二个字母，以此类推。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240927134840.72364285362947067644851114539658:50001231000000:2800:B5DC0649E85DDAB91E06C77E70801A755EFC1A32C09BA886B7CF24185809A3BF.png?needInitFileName=true?needInitFileName=true)  
   * sign、keyIndex参数不参与签名。
   * 只有body中传入的参数需要参与签名，没有出现的不参与。
   * 没有值（包括null和""）的参数如果出现在body中也需要参与签名，格式为"parametername="。
2. 将所有排序后的参数的参数值进行urlencode。
3. 将所有参与签名的参数名和参数值（urlencode后）的键值对以"\&"字符连接成待签名字符串，例如"a=xxxxxx\&b=xxxxxxx\&c=xxxxxxxxxxx..."。生成待签名字符串的Java示例代码如下：

   ```
   private static String format(Map<String, String> params)
   {
       StringBuffer base = new StringBuffer();
       Map<String, String> tempMap = new TreeMap<String, String>(params);
       //获取计算nsp_key的基础串       
       try
       {
           for (Map.Entry<String, String> entry : tempMap.entrySet())
           {
               String k = entry.getKey();
               String v = entry.getValue();
               base.append(k).append("=").append(URLEncoder.encode(v, "UTF-8")).append("&");
           }
       }
       catch (UnsupportedEncodingException e)
       {
           System.out.println("Encode parameters failed.");
           e.printStackTrace();
       }
       String body = base.toString().substring(0, base.toString().length() - 1);
       return body;
   }
   ```

4. 将待签名字符串使用支付私钥按照RSA算法（SHA256WithRSA/PSS）进行签名，将签名后的字符串经过Base64编码，得到的字符串即为签名字符串。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240927134840.74030570166017364536387209876810:50001231000000:2800:C2D183BF5282F155C939D805AF223AE179C65F0ECD1EBB88BEB7C3A3C8BA2D76.png?needInitFileName=true?needInitFileName=true)  
   支付私钥获取请参见[获取支付服务信息](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-Guides/hmssdk_jointOper_querypayinfo)。

   Java示例代码如下：

   ```
   /** *  
   * @param content 待签名字符串   
   * @param publicKey 支付私钥  
   */ 
   public static String signWithSHA256UseRsaWithPss(String content, String privateKey) {
           try {
               return RsaCryptUtil.signRSAWithPSS(content, privateKey);
           } catch (GeneralSecurityException | AegisDecoderException | IOException e) {
              
           }
           return "";
    }
   ```
