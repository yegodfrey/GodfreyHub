# LocationEnhanceService

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250508151212.22869560173164539050315732524512:50001231000000:2800:C5737C75D5742BE1B7958558F353695B87C56D21BD2BD46A63FFEFC9C197F372.png)  
1. 使用室外高精度能力的开发者需要遵守国家法律法规与华为公司共同向国家有关部门申请高精度偏转插件的使用许可。
2. 室外高精度能力当前仅支持中国大陆地区的部分城市：深圳市、广州市、苏州市、杭州市、重庆市、成都市、天津市、东莞市（持续增加中），海外暂不支持。  

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class LocationEnhanceService 获取导航状态，判断设备是否支持室外高精度，定位能力扩展类。在调用[LocationServices](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationservice-0000001050746175)类的[getLocationEnhanceService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationservice-0000001050746175#section10184034204513)(Context context)或[getLocationEnhanceService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationservice-0000001050746175#section8724152316583)(Activity activity)方法时会返回一个该类型的实例。|

获取导航状态的示例代码如下：

```
"Java"
LocationEnhanceService locationEnhanceService = LocationServices.getLocationEnhanceService(this);
NavigationRequest request = new NavigationRequest(type);
locationEnhanceService.getNavigationState(request)
    .addOnSuccessListener(new OnSuccessListener<NavigationResult>() {
        @Override
        public void onSuccess(NavigationResult result) {
            Log.i(TAG, "get NavigationResult success, State is :" + result.getState()
                + " , Possibility is : " + result.getPossibility());
        }
    })
    .addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            Log.i(TAG, "get NavigationResult fail " + e.getMessage());
        }
    });
Log.i(TAG, "getNavigationContextStateCall finish");
```

```
"Kotlin"
val locationEnhanceService =
    LocationServices.getLocationEnhanceService(this)
val request = NavigationRequest(type)
locationEnhanceService.getNavigationState(request)
    .addOnSuccessListener { result ->
        Log.i(
            TAG, "get NavigationResult success, State is :" + result.state
                    + " , Possibility is : " + result.possibility
        )
    }
    .addOnFailureListener { e -> Log.i(TAG, "get NavigationResult fail " + e.message) }
Log.i(TAG, "getNavigationContextStateCall finish")
```
