#### Sample Code

```
private void updateFile(Drive drive, File file){
    try{
        File updateFile = new File().setFileName(file.getFileName() + "_update");
        File mFile = drive.files().update(file.getId(), updateFile).execute();
    } catch (Exception e){
        Log.e(TAG, "updateFile error: " + e.getMessage());
    }
}
```
