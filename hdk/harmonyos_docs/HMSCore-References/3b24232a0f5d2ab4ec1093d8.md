# Overview

集成Analytics SDK后，可使用相关API，进行代码埋点与上报、用户属性设置、自动事件采集与Session计算等。  

#### Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------|
|[HiAnalytics](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-0000001123080524)|此类提供了获取Analytics Kit实例的方法。|
|[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477)|Analytics单例类，提供上报用户行为数据的公共方法。|
|[HiAnalyticsTools](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-tools-0000001169640371)|此类提供了打开调试日志的方法，以支持开发阶段的调试需求。|
