# GameCallback

|Interface Info|
|:---------------------------------------------------------------------------------|
|public interface GameCallBack GameManager类内部定义的接口。设备通过该接口反馈设备信息，如温度、CPU负载和GPU负载信息。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------|
|void|[onPhoneInfoUpdated](#section1461104041212) 设备通过该回调接口获取设备信息。|

## Public Methods

### onPhoneInfoUpdated

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void onPhoneInfoUpdated(String info) 设备通过该回调接口获取设备信息，如温度、CPU负载和GPU负载信息。该方法取得的设备信息与通过GameManager的[getPhoneInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gamemanager-0000001050123643#section81111243202916)方法得到的设备信息格式一致。|

**Parameters**

|Name|Description|
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String info|手机系统返回系统关键资源信息，包含当前温度等级、CPU负载和GPU负载相关信息。 JSON格式样例： ```screen { "MessageType": "20001", "TempCurLevel": "1", "TempTrendValue": "50", "TempTrendMargin": "10", "CpuPerfInfos": [{ "CpuLoad": "9" } ], "GpuPerfInfos": [{ "GpuLoadLevel": "1", "VertexLoadLevel": "1", "FragmentLoadLevel": "10", "TextureLoadLevel": "10", "BandwidthLoadLevel": "1", "GpuFreqCurr": "1" } ] } ``` * MessageType(int)：必填。取值是20001，标识了是一个系统返回的关键资源信息。 * TempCurLevel(byte)：必填。标识温度当前等级。 * 1：设备常温。 * 2：设备温热。建议降低无感知业务规格，例如后台更新降速或延迟运行。 * 3：设备发热。建议暂停无感知业务，降低游戏非核心业务的规格，例如前台更新降速。 * 4：设备发烫。系统资源供给下降，建议降低游戏全场景规格，例如分辨率、画质、帧率。 * 5：设备过热。系统资源供给大幅降低，建议进一步降低游戏规格。 * TempTrendValue(int)：选填。温升趋势归一化值，取值范围-100~100，符号代表降温/升温，数值代表速度。 * 小于零，表示下降。 * 等于零，表示无变化。 * 大于零，表示上升。 * TempTrendMargin(int)：选填。温升趋势时间裕量，温控到达指定档位的时间，单位：秒（s），取值范围自然数。 * CpuPerfInfos(list)：必填。CPU负载当前信息，单元素集合。 * CpuLoad(int)：CPU负载信息，取值范围0~100，值越大负载越重。 * GpuPerfInfos(list)：选填。GPU负载当前信息，单元素集合。 * GpuLoadLevel(int)：GPU整体负载等级，取值范围1~10，值越大负载越重。 * VertexLoadLevel(int)：顶点处理负载等级，取值范围1~10，值越大负载越重。 * FragmentLoadLevel(int)：片元处理负载等级，取值范围1~10，值越大负载越重。 * TextureLoadLevel(int)：纹理处理负载等级，取值范围1~10，值越大负载越重。 * BandwidthLoadLevel(int)：带宽负载等级，取值范围1~10，值越大负载越重。 * GpuFreqCurr(int)：GPU当前工作频率，单位：KHz。 该值可以为null或empty。 常见的原因是： * 游戏未调用注册接口或注册接口调用失败。 * 系统未上报设备信息。此情况可尝试重启设备解决。|
