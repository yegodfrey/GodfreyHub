# 错误码

|**http状态码**|错误码|**描述**|解决方法|
|:----------|:-----------------------|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|400|SK-ParameterMissing|参数缺失|请参见接口参数说明，补充缺失的必选参数。|
|400|SK-ParameterInvalid|参数不合法|请参见接口参数说明，填写正确的参数值。|
|401|SK-AuthenticationMissing|认证凭据缺失|请参见[公共说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/overview-0000001057087079)，补充认证凭据。|
|401|SK-AuthenticationInvalid|认证凭据不合法|请参见[公共说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/overview-0000001057087079)，提供正确的认证凭据。|
|401|SK-AuthenticationExpired|认证凭据过期|请参见[公共说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/overview-0000001057087079)，提供有效期内的认证凭据。|
|403|SK-AuthorizationDenied|鉴权失败|确认凭据具有正确的API调用权限，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/app-gallery-connect-0000001057712438)获取正确的调用凭证。|
|429|SK-LimitExceeded|调用超限|调用的API次数超过限制，请等候下个周期再进行尝试，或者[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)联系华为支持人员提升API调用阈值。|
|500|SK-InternalError|内部错误|请收集返回的response信息，提交至[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)页面。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
