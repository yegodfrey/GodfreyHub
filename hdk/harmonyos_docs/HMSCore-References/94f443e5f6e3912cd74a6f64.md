# HCoordinateConverter

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------|
|@interface HCoordinateConverter : NSObject 坐标系转换工具类，传入1个或1组WGS84坐标，转换为GCJ02坐标。适用于中国区范围坐标转换，在中国地图范围内转换为GCJ02坐标，中国地图范围外保持WGS84坐标。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:------------------------|:------------------------------------------------------------|
|CLLocationCoordinate2D|[converter:gpsLon:](#section490110481519) 单个WGS84坐标转GCJ02坐标。|
|CLLocationCoordinate2D \*|[converter:count:](#section19787541142313) 多个WGS84坐标转GCJ02坐标。|

#### Public Methods

#### converter:gpsLon:

|Method|
|:------------------------------------------------------------------------------------------------------|
|+ (CLLocationCoordinate2D)converter:(double)wgsLat gpsLon:(double)wgsLon 您调用此API可以将单个WGS84坐标转换为GCJ02坐标。|

Parameters  

|Name|Description|
|:-----|:----------|
|wgsLat|WGS84坐标，纬度。|
|wgsLon|WGS84坐标，经度。|

Returns  

|Type|Description|
|:---------------------|:--------------------------------------|
|CLLocationCoordinate2D|GCJ02坐标。若传入的WGS84坐标在中国范围外，返回值保持WGS84坐标。|

#### converter:count:

|Method|
|:------------------------------------------------------------------------------------------------------------------------------|
|+ (CLLocationCoordinate2D \*)converter:(CLLocationCoordinate2D \*)coords count:(NSUInteger)count 您调用此API可以将多个WGS84坐标转换为GCJ02坐标。|

Parameters  

|Name|Description|
|:-----|:----------------------------------|
|coords|WGS84坐标，最多可以传入512个坐标系，超过512个，返回原数据。|
|count|传入的坐标数量。|

Returns  

|Type|Description|
|:------------------------|:--------------------------------------|
|CLLocationCoordinate2D \*|GCJ02坐标。若传入的WGS84坐标在中国范围外，返回值保持WGS84坐标。|
