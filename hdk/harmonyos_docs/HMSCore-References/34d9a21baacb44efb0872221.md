# HWTrafficLayer

## 概述

在地图上添加路况图层。

## 构造函数

|函数|**描述**|
|:-----------------------------------|:-----------------------------------------------------------------------------|
|HWMapJsSDK.HWTrafficLayer(map, opts)|* map：添加的地图图层。 * opts：设置路况图层的属性，详情见[TrafficLayerOption](#section226182213617)。|

## 方法

|**方法**|**描述**|**参数类型**|**返回值**|
|:----------------------|:--------------|:---------------------------|:------|
|forceRefresh()|强制刷新路况数据，仅刷新一次。|-|-|
|getInterval()|获取路况刷新时间间隔。|-|Number|
|getMap()|获取地图图层。|-|Map对象。|
|getRefresh()|获取路况是否自动刷新。|-|Boolean|
|setInterval(interval)|设置路况刷新时间间隔。|Number|-|
|setMap(map)|设置地图图层。|Map对象 | null 设置为null则隐藏路况图层。|-|
|setRefresh(autoRefresh)|设置路况是否自动刷新。|Boolean|-|

## TrafficLayerOption

|**参数**|**是否必选**|**参数类型**|**描述**|
|:----------|:-------|:-------|:----------------------------------------|
|autoRefresh|否|Boolean|路况是否启用自动刷新。 * true：开启 * false：关闭 默认false。|
|interval|否|Number|路况刷新时间间隔，单位：秒。取值范围：大于等于30，默认120s。|
