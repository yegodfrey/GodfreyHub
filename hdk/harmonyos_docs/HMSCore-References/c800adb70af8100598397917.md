# Overview

商户APP通过钱包sdk，进行ICCE车钥匙蓝牙连接状态的查询，以及车控指令的交互等相关操作。

## Interface Summarys

|Interface|Description|
|:-----------------|:-----------------------------------------------------------------------|
|IBleWalletService|ICCE车钥匙service接口（华为钱包APP实现），商户开发者可通过绑定钱包服务后，调用车钥匙相关接口。|
|IBleWalletListener|ICCE车钥匙监听接口，商户开发者可通过service接口注册该监听后，实现蓝牙状态、指令交互过程和车辆数据的监听。|
|IBleThirdService|ICCE车钥匙service接口（商户App实现），钱包可绑定该service后，调用其中的接口，完成配对码的获取，广播名称的获取，触发配对等。|

## Class Summary

|Class|Description|
|:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
|Response|ICCE车钥匙公共API接口，用于接收AIDL接口的返回值； 该类提供了AIDL接口返回值的基类描述，定义了基本的返回码。|
|CommandResponse|ICCE车钥匙公共API接口，用于接收返回的指令消息； 这个类在Response类的基础上，增加了成员变量commandValue，用于描述返回的指令消息。|
|BleStateResponse|ICCE车钥匙公共API接口，用于接收返回的蓝牙状态消息。 这个类在Response类的基础上，增加了成员变量state，用于描述返回的蓝牙状态。|
|DeviceVersionResponse|ICCE车钥匙公共API接口，用于接收返回的设备钱包版本、rom版本和机型。 这个类在Response类的基础上，增加了成员变量deviceType、walletVersion、romVersion、model、appId和appVersion，用于描述返回的设备和版本信息|
|PassResponse|ICCE车钥匙公共API接口，用于接收返回的车钥匙卡片信息。 这个类在Response类的基础上，增加了成员变量passDeviceId：用于描述设备唯一标识、passCardInfoList：用于描述卡片状态信息。|
|BleProcedureStatus|ICCE车钥匙公共API接口，用于接收返回的车钥匙状态。 这个类在Response类的基础上，增加了成员变量，用于描述返回的车钥匙状态。|
|PassCardInfo|ICCE车钥匙公共API接口，用于描述车钥匙卡片的状态信息。|
|CommandInfo|ICCE车钥匙公共API接口，用于描述车钥匙指令数据信息。|
|BleCalibrationData|ICCE车钥匙公共API接口（穿戴专用），用于接收标定数据的参数对象。 这个类含有成员变量factoryData、passID，用于描述传入的标定数据。|
|BleWearModelResponse|ICCE车钥匙公共API接口（穿戴专用），用于接收返回的穿戴型号消息。 这个类在Response类的基础上，增加了成员变量model，用于描述返回的穿戴设备型号。|
|BleProcedureConstants|ICCE车钥匙公共API接口，常量定义。|
|BleStateConstants|ICCE车钥匙公共API接，蓝牙状态常量定义。|
|GenericResultCode|ICCE车钥匙公共API接口，通用错误码定义。|
