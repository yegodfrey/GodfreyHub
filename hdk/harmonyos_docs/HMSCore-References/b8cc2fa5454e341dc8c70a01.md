#### Public Methods

#### inSunriseOrSunsetPeriod

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) inSunriseOrSunsetPeriod(int timeInstant, long startTimeOffset, long stopTimeOffset) 日出日落时间围栏，添加此围栏后，在以日出或者日落时间为基准的一段指定时间范围内时围栏状态为TRUE；否则，围栏状态为FALSE。 使用此围栏需添加android.permission.ACCESS_FINE_LOCATION权限。|

Parameters  

|Name|Description|
|:--------------|:----------------------------------------------------------------------------------------|
|timeInstant|日出或日落的标识常量，可选值为：[SUNRISE_CODE](#section54829319913) [SUNSET_CODE](#section15466134312914)|
|startTimeOffset|时间围栏的开始时间偏移量。单位为ms，取值范围是-24小时到24小时范围内的毫秒数，且必须小于stopTimeOffset。|
|stopTimeOffset|时间围栏的结束时间偏移量。单位为ms，取值范围是-24到24小时范围内的毫秒数，且必须大于startTimeOffset。|

Throws  

|Name|Description|
|:-----------------------|:----------------------------------------------------------------------------------------------------------|
|IllegalArgumentException|参数异常（传入了未知或无效的timeInstant，startTimeOffset大于或等于stopTimeOffset，startTimeOffset或stopTimeOffset的绝对值大于24小时的毫秒数）。|

Returns  

|Name|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|情景感知围栏。|

#### duringPeriodOfDay

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) duringPeriodOfDay(TimeZone timeZone, long startTimeOfDay, long stopTimeOfDay) 指定时间围栏，添加此围栏后，在指定时区的指定时间段内，围栏状态为TRUE；否则，围栏状态为FALSE。 使用此围栏需添加android.permission.ACCESS_FINE_LOCATION权限。|

Parameters  

|Name|Description|
|:-------------|:-----------------------------------------------|
|timeZone|时区。如果不存在，则使用用户所在地时区。|
|startTimeOfDay|围栏的开始时间。单位为ms，0点为0，最大值为24小时的毫秒数。|
|stopTimeOfDay|围栏的结束时间。单位为ms，须保证stopTimeOfDay\>=startTimeOfDay。|

Returns  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------|
|[AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120)|情景感知围栏。|

Throws  

|Name|Description|
|:-----------------------|:-----------------------------------------------------------------------------|
|IllegalArgumentException|参数异常（startTimeOfDay大于stopTimeOfDay，startTimeOfDay、stopTimeOfDay为负或大于24小时的毫秒数）。|
