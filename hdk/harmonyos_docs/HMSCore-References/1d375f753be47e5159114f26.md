# HuaweiMap.InfoWindowAdapter

|Interface Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface HuaweiMap.InfoWindowAdapter 是[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)类的一个内部接口，提供自定义标记信息窗口视图的适配器，包含两个抽象函数[getInfoContents](#section1665805611258)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))和[getInfoWindow](#section1927115112273)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))。当需要显示标记信息窗口时，无论是出于何种原因（不管是因为用户手势还是调用了[showInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section13223817123711)()方法），都会调用适配器提供的方法。由于任何时候都只显示一个标记信息窗口，因此适配器可以选择重用视图，也可以选择在每次调用方法时创建新视图。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|abstract View|[getInfoContents](#section1665805611258)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 为标记的默认信息窗口提供自定义内容，仅当[getInfoWindow](#section1927115112273)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))首次返回null时才会被调用。|
|abstract View|[getInfoWindow](#section1927115112273)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 为标记提供自定义信息窗口。|

## Public Methods

### getInfoContents

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract View getInfoContents([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 此方法为标记的默认信息窗口提供自定义内容，仅当[getInfoWindow](#section1927115112273)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))首次返回null时才会被调用。如果此方法返回一个视图，它将被放置在默认信息窗口里。如果您在此方法被调用之后更改视图，则这些更改不一定会反映在展示的信息窗口中。如果此方法返回null，则将展示默认信息窗口。|

**Parameters**

|Name|Description|
|:-----|:----------|
|marker|待填充的标记。|

**Return** **s**

|Type|Description|
|:---|:---------------------------------------------|
|View|View对象，返回一个内容自定义的标记信息窗口，如果返回为null，将使用默认标记信息窗口。|

### getInfoWindow

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract View getInfoWindow([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858) marker) 为标记提供自定义信息窗口。如果此方法返回一个视图，则它将用于整个信息窗口。如果您在此方法被调用之后更改此视图，则这些更改不一定会反映在展示的信息窗口中。如果此方法返回null，则将展示默认信息窗口，其内容由[getInfoContents](#section1665805611258)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))提供。|

**Parameters**

|Name|Description|
|:-----|:----------|
|marker|待填充的标记。|

**Return** **s**

|Type|Description|
|:---|:--------------------------------------------|
|View|View对象，返回一个自定义的标记信息窗口，如果返回为null，将使用默认的标记信息窗口。|
