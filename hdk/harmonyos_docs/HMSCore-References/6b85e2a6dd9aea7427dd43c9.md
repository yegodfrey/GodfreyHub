# Overview

## Interface Summary

|Interface|Description|
|:------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|[TileProvider](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/tileprovider-0000001050151412)|为[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/tileoverlay-0000001050153293)提供瓦片图像。 调用这个接口的方法可能会存在多线程，所以实现时注意线程安全。|
