# HealthRecordReadOptions

|Class Info|
|:-------------------------------------------------------------------------|
|public class HealthRecordReadOptions 从华为Health Service Kit中读取健康记录数据的请求参数类。|

读取记录数据请求参数类的示例代码如下：

```screen
"Java"
// 设置请求体的开始时间和结束时间 
Calendar cal = Calendar.getInstance();
Date now = new Date();
cal.setTime(now);
long endTime = cal.getTimeInMillis();
cal.add(Calendar.DAY_OF_YEAR, -1);
long startTime = cal.getTimeInMillis();

// 构造待读取的心率过缓健康记录数据类型关联的心率明细数据类型
List<DataType> subDataTypeList = new ArrayList<>();
subDataTypeList.add(DataType.DT_INSTANTANEOUS_HEART_RATE);
// 构建读取健康记录的参数HealthRecordReadOptions，以心率过缓健康数据类型为例
HealthRecordReadOptions healthRecordReadOptions =
    new HealthRecordReadOptions.Builder().setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
        .readHealthRecordsFromAllApps()
        .readByDataType(HealthDataTypes.DT_HEALTH_RECORD_BRADYCARDIA)
        .setSubDataTypeList(subDataTypeList)
        .build();
```

```screen
"Kotlin"
// 设置请求体的开始时间和结束时间
val cal = Calendar.getInstance()
val now = Date()
cal.time = now
val endTime = cal.timeInMillis
cal.add(Calendar.DAY_OF_YEAR, -1)
val startTime = cal.timeInMillis

// 构造待读取的心率过缓健康记录数据类型关联的心率明细数据类型
val subDataTypeList = ArrayList<DataType>()
subDataTypeList.add(DataType.DT_INSTANTANEOUS_HEART_RATE)
// 构建读取健康记录的参数HealthRecordReadOptions，以心率过缓健康数据类型为例
val healthRecordReadOptions =
    HealthRecordReadOptions.Builder().setTimeInterval(startTime, endTime, TimeUnit.MILLISECONDS)
        .readHealthRecordsFromAllApps()
        .readByDataType(HealthDataTypes.DT_HEALTH_RECORD_BRADYCARDIA)
        .setSubDataTypeList(subDataTypeList)
        .build()
```

> 说明
>
> 1. 调用查询运动健康数据的健康记录接口，接口参数中的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。
> 2. 调用查询运动健康数据的健康记录接口，接口参数中的开始时间和结束时间之间的时间跨度不允许超过31天。
