# Overview

提供与地图服务API交互的数据类型的详细信息。  

|数据类型|描述|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-bitmapdescriptor-0000001208024788)|定义Bitmap图片。Bitmap图片可用作[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699)图标或用于[GroundOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-groundoverlay-0000001208344754)。|
|[CameraPosition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cameraposition-0000001208184786)|封装所有相机属性。|
|[CameraTargetBounds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cameratargetbounds-0000001253264691)|封装边界属性。|
|[CameraUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cameraupdate-0000001253024727)|提供各种创建[CameraUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cameraupdate-0000001253024727)对象的方法，该对象用于修改地图相机。|
|[Cap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-cap-0000001208344748)|定义[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695)对象的起始顶点和末端顶点的类型。|
|[InfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-infowindow-0000001208504722)|定义[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699)对象点击时展示的信息窗口。|
|[JointType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-jointtype-0000001253144697)|定义[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695)的连接类型。|
|[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)|表示经度和纬度，单位为度。|
|[LatLngBounds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlngbounds-0000001208024790)|表示经纬度对应的矩形。|
|[MinMaxZoomPreference](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-minmaxzoompreference-0000001208184788)|封装最小和最大缩放级别属性。|
|[PatternItem](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-patternitem-0000001253264693)|描述[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695)的线条类型。|
|[ScreenCoordinate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-screencoordinate-0000001253024729)|封装x和y属性。|
|[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-circle-0000001208344752)|在地图上定义一个圆形。|
|[CircleId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-circleid-0000001208504726)|表示不可变的圆形ID。|
|[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699)|定义展示在地图特定位置的图标。|
|[MarkerId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-markerid-0000001252864735)|表示不可变的标记ID。|
|[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polygon-0000001208024792)|在地图上定义一个多边形。|
|[PolygonId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polygonid-0000001208184790)|表示不可变的多边形ID。|
|[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695)|在地图上定义一个折线。|
|[PolylineId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polylineid-0000001253024731)|表示不可变的折线ID。|
|[GroundOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-groundoverlay-0000001208344754)|在地图上定义一个图片。|
|[GroundOverlayId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-groundoverlayid-0000001208504728)|表示不可变的覆盖物ID。|
|[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlay-0000001253144701)|表示瓦片图层。|
|[TileOverlayId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlayid-0000001252864737)|表示不可变的瓦片图层ID。|
|[Tile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/tile-0000001208024794)|为[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlay-0000001253144701)提供瓦片图片。|
|[UrlTile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-urltile-0000001208184792)|基于URL为[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlay-0000001253144701)提供瓦片图片。|
|[RepetitiveTile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-repetitivetile-0000001253264697)|为[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlay-0000001253144701)提供重复的瓦片图片。|
|[HmsMarkerAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkeranimation-0000001253024733)|支持标记动画。|
|[HmsMarkerAlphaAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkeralphaanimation-0000001208344756)|控制透明度。|
|[HmsMarkerRotateAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkerrotateanimation-0000001208504730)|控制动画旋转。|
|[HmsMarkerScaleAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkerscaleanimation-0000001253144703)|控制动画缩放。|
|[HmsMarkerTranslateAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkertranslateanimation-0000001252864739)|控制动画移动。|
|[MapType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-maptype-0000001208024796)|定义地图类型。|
|[Location](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-location-0000001208184794)|包含位置相关属性的对象。|
|[PointOfInterest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-pointofinterest-0000001253264699)|包含点击的POI相关属性的对象。|
