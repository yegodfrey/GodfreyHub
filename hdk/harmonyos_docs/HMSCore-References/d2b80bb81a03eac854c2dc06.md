# ResultStatus

* 支持的设备：华为手机。
* 支持的OS：EMUI 3.0+、Android 4.4+、HarmonyOS 2.0+。

|Interface Info|
|:-----------------------------------------------------|
|public interface ResultStatus 包含了PaymentService接口的返回码。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:----------------------------|
|static String|STATUS_SUCCESS 支付/签约成功|
|static String|STATUS_FAIL 支付/签约失败|
|static String|STATUS_CANCEL 取消支付/签约|
|static String|STATUS_PARAM_ERROR 参数错误|
|static String|STATUS_UNKNOWN 支付/签约未知状态|
|static String|STATUS_DUPLICATE_REQUEST 重复请求|
|static String|STATUS_NETWORK_ERROR 网络错误|
