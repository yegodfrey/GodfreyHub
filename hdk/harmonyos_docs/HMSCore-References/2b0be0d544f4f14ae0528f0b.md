# 位置类API  
  
#### 功能介绍

根据经纬度信息，获取基础citycode信息。

#### 接口原型

承载协议 | HTTPS POST  
---|---  
接口方向 | 开发者服务器 -> 华为天气服务器  
接口URL | {rootUrl}/v1/location/code 说明：  {_rootUrl_}：请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/description-0000001255747721#section14786518719)  
数据格式 | 请求消息：Content-Type: application/json 响应消息：Content-Type: application/json  
  
#### 请求参数

**Request Header**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
Content-Type | 是 | String | 取值为：application/json  
Authorization | 是 | String | 您动态获取的[Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section12493191334711) 说明：  Bearer后面拼接空格，再拼接获取的access_token  
  
**Request Body**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
location | 是 | Struct | 经纬度信息，请参见location参数。  
  
**l****ocation**

参数 | 是否必选 | 参数类型 | 描述  
---|---|---|---  
longitude | 是 | String | 经度。  
latitude | 是 | String | 纬度。  
locationsystem | 否 | String | 定位坐标系。
                * GCJ02：火星坐标系
                * WGS84：标准坐标系（默认）  
  
#### 请求示例
    
    GET {rootUrl}/v1/location/code
    Content-Type:application/json
    Authorization:Bearer {access_token}
    {
      "location": {
        "longitude": "116.405285",    //经度
        "latitude": "39.904989",      //纬度
        "locationsystem": "WGS84"     //定位坐标系，火星坐标系：GCJ02;标准坐标系：WGS84（默认）
      }
    }

响应参数

**状态码为200时****：**

**Response Header**

参数 | 参数类型 | 描述  
---|---|---

参数 | 参数类型 | 描述  
---|---|---

msg | String | 返回值描述  
data | Object | 返回数据，具体请参见响应示例  
requestid | String | 请求id，用于查询日志
