# bindDevice：将设备与数据中心和云端绑定

接口原型

public void bindDevice(String data, String function)

方法描述：用data中的设备信息，将设备与APP和云端建立绑定关系。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:-----------------------------------|:---|
|data|String|设备信息Json数据，参考下方举例。|M|
|function|String|运动健康返回绑定结果的回调函数，该回调函数有一个参数，详情参见响应参数。|M|
[表1 请求参数]

```
data数据：
{"uuid": "afc4c113-3c16-42e6-aa3e-f590b0840bda",
 "measureKitId": "20170721",
 "deviceName": "三诺亲智血糖仪"
 "uniqueId": "20130001"
 "sn": "2AJC2R00917"}
```

<br />

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:-----------------------------------------------------------------------------------------------------------------------------|:---|
|errCode|Number|0，表示绑定成功。 0以外表示绑定失败，具体错误信息参见[错误码清单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/errcode-0000001058135271)。|M|
