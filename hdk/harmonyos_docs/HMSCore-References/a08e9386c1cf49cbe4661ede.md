# HwAlphaIndexerListView

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HwAlphaIndexerListView extends View 该类一般与ListView配合使用，扩展了如下特性： 1. 按首字母或数字大小排序显示列表。 2. 点击对应字母出现高亮，出现字母提示框，并将左侧列表跳转到对应位置。 3. 滑动字母排序列表，字母随手指移动依次高亮，出现字母提示框，左侧列表跟随变化。 4. 滑动左侧列表，根据列表首字母的不同，切换字母排序列表的高亮位置，并出现相应提示框。|
