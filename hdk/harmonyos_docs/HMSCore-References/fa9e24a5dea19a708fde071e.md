# ZRemoteMessage

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class ZRemoteMessage ZRemoteMessage类是一个消息实体类，应用通过[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-push-ohos-hmsmessageservice-0000001153713354)中的[onMessageReceived](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-push-ohos-hmsmessageservice-0000001153713354#section520014264371)(ZRemoteMessage)方法接收服务端推送的消息。 [ZRemoteMessage.Notification](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-push-ohos-notification-0000001153553546)类是一个内部类，代表通知消息。您在服务端推送通知消息时，如果通过服务端提供的开放接口设置了当应用进程在前台则不通过NC展示消息，那么应用在前台时这个通知消息是直接透传给应用，由应用自己处理展示，此时ZRemoteMessage消息实体中包含[ZRemoteMessage.Notification](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-push-ohos-notification-0000001153553546)数据实例。Notification类中成员字段定义与[下行消息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197)中的[AndroidNotification](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p516983952612)结构体字段定义相映射。|
