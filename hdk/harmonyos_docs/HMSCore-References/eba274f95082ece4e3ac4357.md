#### getSignatureAlgorithm

|Method|
|:----------------------------------------------------------------------|
|public String getSignatureAlgorithm() 返回签名算法。您可使用该方法返回的签名算法对消耗结果数据进行验签。|

Returns  

|Type|Description|
|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|签名算法。 调用[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section16784102213346)接口时，若在[setSignatureAlgorithm](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consumeownedpurchasereq-0000001050137617#section674512136510)方法中传入IAP支持的签名算法，该方法将返回您传入的签名算法。若未传入签名算法，该方法返回"SHA256WithRSA"或空值。 说明： 传入签名算法的场景需要使用此方法返回的签名算法进行数据验签。未传入签名算法的场景可使用默认的SHA256WithRSA算法或该方法返回的算法进行数据验签。 可能存在该方法返回为空的情况，该情况默认使用SHA256WithRSA算法进行验签。|
