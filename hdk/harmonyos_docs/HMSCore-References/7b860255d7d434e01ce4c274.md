# Player

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class Player extends Object Player类主要用于返回游戏玩家的具体信息，在调用[PlayersClient.getCurrentPlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section1442582231216)方法时会返回Player类型的实例。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|[getDisplayName](#section97851713752)() 获取玩家昵称。|
|Uri|[getHiResImageUri](#section1482030152)() 获取玩家高清头像的URI地址。|
|Uri|[getIconImageUri](#section162011544452)() 获取玩家普通图标头像的URI地址。|
|int|[getLevel](#section14336195511520)() 获取玩家等级信息，当前只支持中国大陆玩家，中国大陆以外的玩家将默认返回1。|
|String|[getPlayerId](#section1887311271266)() 获取华为为玩家分配的游戏帐户ID，该ID可在应用内唯一标识该用户。|
|boolean|[hasHiResImage](#section1442564019617)() 检查玩家是否存在高清头像。|
|boolean|[hasIconImage](#section5745834718)() 检查玩家是否存在普通头像。|
|String|[getPlayerSign](#section893716271979)() 获取玩家的登录签名，应用服务端可以根据登录签名调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/verify-login-signature-0000001050123503)接口向华为游戏服务器验证玩家信息的有效性。|
|String|[getSignTs](#section15657194216714)() 获取校验登录签名时需要提交的时间戳信息。|
|String|[getOpenId](#section8861615201313)() 获取用户在应用中的openId。同一个用户在不同应用中的openId值不同。使用openId标识用户，多个应用之间同一个华为帐号用户在开发者系统内会被标识为多个用户。|
|String|[getUnionId](#section7615821121417)() 获取用户的unionId。unionId是开发者帐号ID，对于同一个用户，同一个开发者帐号下管理的不同应用，unionId值相同。如果一个应用转移到另外一个帐号后，unionId值也会变化。|
|String|[getOpenIdSign](#section1033912811361)() 获取openId的登录签名，应用服务端可以根据登录签名调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/verify-login-signature-0000001050123503)接口向华为游戏服务器验证playerId和openId对应关系的准确性。|

#### getOpenId

|Method|
|:-------------------------------------------------------------------------------------------------------|
|public String getOpenId() 获取用户的openId。同一个用户，不同应用，openId值不同。使用openId标识用户，多个应用之间同一个华为帐号用户在开发者系统内会被标识为多个用户。|

Returns  

|Type|Description|
|:-----|:----------|
|String|用户的OpenId。|

#### getUnionId

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getUnionId() 获取用户的unionId。unionId是开发者帐号ID，对于同一个用户，同一个开发者帐号下管理的不同应用，unionId值相同。如果一个应用转移到另外一个帐号后，unionId值也会变化。 unionId和openId的区别在于，如果开发者帐号下管理了多个应用，针对同一个华为帐号，不同的应用返回的openId值不同，但返回的unionId相同。如果开发者需要在不同应用中共享同一个华为帐号的用户信息，可以使用unionId作为用户标识。|

Returns  

|Type|Description|
|:-----|:----------|
|String|用户的UnionId。|
