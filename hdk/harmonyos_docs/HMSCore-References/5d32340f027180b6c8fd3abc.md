# DataType

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class DataType 由华为Health Service Kit定义的数据类型，每个数据类型字段都有唯一的名称来标识。 不同的数据类型表示不同的含义，例如：DT_CONTINUOUS_STEPS_DELTA数据类型表示增量步数。数据类型的名称、属性组成和取值范围等信息请参见[数据类型](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-0000001147638696)。|
