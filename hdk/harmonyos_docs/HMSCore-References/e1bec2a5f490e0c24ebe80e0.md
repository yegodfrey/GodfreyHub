# HiHealthOptions

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class HiHealthOptions implements HuaweiIdAuthExtendedParams 用于通过华为账号的接口HuaweiIdAuthManager.addAuthScopes(Activity, int, HuaweiIdAuthExtendedParams)申请权限。 权限通过DataType定义，决定了应用登录的账号所拥有的HealthKit的scope权限。 > 注意 > 已废弃，请勿使用。|
