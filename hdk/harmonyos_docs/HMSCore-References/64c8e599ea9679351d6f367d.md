# DeviceInfo

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class DeviceInfo implements Parcelable 设备信息类，指在构造数据采集器时使用的设备信息。包含设备厂家、型号、设备类型、序列号以及平台类型。 在读取数据采集器的时候，可以通过DataCollector.getDeviceInfo()方法获取数据采集器的具体设备信息。 > 说明 > 设备信息是可选项。Health Service Kit不收集设备信息，设备信息是由开发者传入，开发者不传入设备信息时也不影响SDK的正常使用。|
