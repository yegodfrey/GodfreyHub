# startBluetoothDevicesDiscovery：开始搜寻附近的蓝牙设备

**接口原型**

public String startBluetoothDevicesDiscovery(UUID[] services， boolean allowDuplicatesKey，int interval)

方法描述：开始搜寻附近的蓝牙设备。

**请求参数**

|参数名称|参数类型|参数描述|可选选项|
|:-----------------|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---|
|services|array|当前搜索的蓝牙设备的广播数据段中的ServiceUUIDs数据段（UUID字符串数组） 示例：['0000ffe0-0000-1000-8000-00805f9b34fb', '0000ffe1-0000-1000-8000-00805f9b34fb', '0000ffe2-0000-1000-8000-00805f9b34fb']|M|
|allowDuplicatesKey|Boolean|是否允许重复上报同一设备， 如果允许重复上报，则onBluetoothDeviceFound 方法会多次上报同一设备，但是 RSSI 值会有不同（android：true表示不允许，false表示允许）|M|
|interval|Number|上报设备的间隔，默认为0，意思是找到新设备立即上报，否则根据传入的间隔上报|M|
[**表1**请求参数]

**响应参数**

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:-----------|:---|
|retCode|Number|错误码：0, 90001|M|
[**表2**响应参数]
