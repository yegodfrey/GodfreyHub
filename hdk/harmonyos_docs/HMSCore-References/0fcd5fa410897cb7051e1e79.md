# Overview

Analytics SDK预置事件ID列表及事件参数列表，代码埋点时，可直接调用预置事件及事件参数。  

#### Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------|
|[EventName](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-haeventtype-0000001050961482)|此接口提供了所有预定义事件的事件ID常量。|
|[InitSettings](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-initsettings-0000001113291296)|此接口用来在SDK初始化之前，做一些全局设置。|
|[ParamName](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-haparamtype-0000001051201529)|此接口提供了所有预定义参数的参数ID常量。|
|[RoutePolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/web-api-routepolicy-0000001160054484)|此接口提供了所有数据处理位置ID常量。|
|[UrlClusteringOptions](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-urlclusteringoptions-0000001124540912)|此接口用来在SDK初始化之前，做url聚类相关配置。|
|[UserProfileType](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-userprofiletype-0000001064482208)|此接口提供了所有预定义用户属性名称的常量。|
|[ReportPolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/web-api-reportpolicy-0000001494427025)|此接口提供数据自动上报的策略。|
