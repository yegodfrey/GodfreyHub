# MapFragment

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class MapFragment 是一个地图组件，继承安卓原生Fragment，是应用中放置地图的最简单的方式。它提供了一个地图界面，自动处理生命周期函数，能够加载到Activity的布局文件中使用。通过[getMapAsync](#section11704105017376)，自动初始化地图系统和视图。 [HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象必须使用[getMapAsync](#section11704105017376)([OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378) callback)获取，此类会自动初始化地图系统和视图。 从[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)获取的任何对象都与视图关联，不要在视图的生命周期之外保留对象（例如：标记），否则将导致内存泄漏，因为视图无法释放。|

#### Public Methods

#### getMapAsync

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void getMapAsync([OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378) callback) 当地图对象准备就绪时，就会触发此接口回调，获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象。 说明： * 必须在主线程调用此方法。 * 回调将在主线程中执行。 * 在极少数情况下，创建后立即销毁[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)时，不会触发回调。 * [HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)回调提供的对象为非null。|

|:-------|:---------------------------------------------------------------------------------------------------------------|
