# HMSHealthKitFormatType

以下HMSHealthKitFormatType里的常量为Health Service Kit已定义的常用的字段类型常量。  

|Type|Name|Description|
|:-----|:------------|:---------------|
|String|FORMAT_INT32|取值为"1"，表示整型类型|
|String|FORMAT_FLOAT|取值为"2"，表示浮点类型|
|String|FORMAT_DOUBLE|取值为"2"，表示双精度浮点类型|
|String|FORMAT_STRING|取值为"3"，表示字符串类型|
|String|FORMAT_MAP|取值为"4"，表示Map类型|
|String|FORMAT_LONG|取值为"5"，表示长整型类型|
