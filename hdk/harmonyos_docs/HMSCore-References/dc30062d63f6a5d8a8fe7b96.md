# Overview

Analytics SDK预置事件ID列表及事件参数列表，代码埋点时，可直接调用预置事件及事件参数。

## Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------|:----------------------|
|[EventName](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-haeventtype-0000001153022493)|此接口提供了所有预定义事件的事件ID常量。|
|[InitSettings](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-initsettings-0000001159651551)|此接口用来在SDK初始化之前，做一些全局设置。|
|[ParamName](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-haparamtype-0000001106542570)|此接口提供了所有预定义参数的参数ID常量。|
|[RoutePolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-routepolicy-0000001205813419)|此接口提供了所有数据处理位置ID常量。|
|[UserProfileType](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-userprofiletype-0000001106382612)|此接口提供了所有预定义用户属性名称的常量。|
|[ReportPolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-reportpolicy-0000001515040801)|此接口提供数据自动上报的策略。|
