# VisibleRegion

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class VisibleRegion VisibleRegion实现了Parcelable。它包含四个点，这四个点定义了地图相机的四边形可视区域。因为相机可能会倾斜，所以这个多边形可以是梯形而不是矩形。如果相机正好位于可视区域中心上方，则形状为矩形，但如果相机倾斜，则形状将显示为最短边最接近视点的梯形。|
