# Fields

|参数|是否必选|参数类型|描述|
|:-------------|:---|:------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|​countryCode|否|String|国家码。|
|currencyCode|否|String|货币单位。|
|allowMultiUser|否|String|是否允许多个用户领取同一张卡券，取值为"true"或"false"。若allowMultiUser的值为"true"，则允许多个用户领取此卡券。若无allowMultiUser字段或allowMultiUser的值为"false"，则只允许一个用户领取此卡券。|
|status|否|[Status](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/status-0000001050160323)|开发者自定义状态信息，包括状态和有效时间，会根据此状态值展示卡券是否失效。|
|relatedPassIds|否|List\<[RelatedPassIds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/relatedpassids-0000001050158370)\>|卡券如果存在关联卡券，开发者可以在此填写关联卡券的ID。仅会员卡实例有此属性，用于关联同一个用户账号下的优惠券实例。不应在会员卡模板中设置此属性。|
|locationList|否|List\<[LocationList](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationlist-0000001050160325)\>|地理位置，如果卡券类别支持根据地理围栏通知，可以填写此信息。|
|barCode|否|[BarCode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/barcode-0000001050158372)|条码/二维码，在使用卡券时展示，当不涉及条码/二维码展示时，可以不需要填写此字段。|
|commonFields|否|List\<[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)\>|通用展示字段列表，即一种卡券中通常需要使用到的属性。各类卡券的具体字段详见各卡券的[UI设计](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access_membership-0000001050044329#section1811873155314)。|
|appendFields|否|List\<[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)\>|附加展示字段列表，即同种卡券类型，不同商家根据场景差异化的展示信息。各类卡券的具体字段详见各卡券的[UI设计](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access_membership-0000001050044329#section1811873155314)。|
|messageList|否|List\<[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)\>|卡券中的通知信息，与卡券的通用展示无关，商家通过此字段可以通知用户特定时间段的使用等等。|
|timeList|否|List\<[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)\>|时间列表。|
|imageList|否|List\<[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)\>|卡券详情页面展示中的轮播图列表，如酒店会员卡可以通过轮播图更直观的将酒店服务图景展示给用户。|
|ticketInfoList|否|List\<[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/barcode-0000001050158372)\>|开发者自定义的票根信息。仅交通卡使用。|
|urlList|否|List\<[ValueObject](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/valueobject-0000001050160327)\>|展示在卡片上的链接。|
|localized|否|List\<[Localized](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/localized-0000001050158374)\>|多语言字段，当展示字段涉及多语言时，其他语言类型的字段在此节点中定义，由具体的节点通过key引用。|
