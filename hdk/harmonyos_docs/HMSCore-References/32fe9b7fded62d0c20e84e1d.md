# CameraUpdate

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class CameraUpdate CameraUpdate定义了相机移动参数。通过调用[animateCamera](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section13382161444614)(CameraUpdate)或者[moveCamera](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section168451531308)(CameraUpdate)等可以移动地图相机，您可以通过工厂类[CameraUpdateFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/cameraupdatefactory-0000001050151725)获取CameraUpdate对象，具体使用方法参见[CameraUpdateFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/cameraupdatefactory-0000001050151725)。|
