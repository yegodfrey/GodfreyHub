# 采样数据统计查询

#### 功能介绍

将特定数据类型或数据采集器的数据按一定规则进行聚合分组。  

#### 场景描述

指定采样数据由时间间隔进行聚合分组，返回指定数据类型的统计结果。

* 以精确时间段duration对采样数据进行聚合分组。
* 以天为单位对采样数据进行聚合分组。
* 以周为单位对采样数据进行聚合分组。
* 以月为单位对采样数据进行聚合分组。  

#### 使用约束

无  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:polymerize|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/json; charset=UTF-8|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body  

|参数|参数类型|是否必选|说明|约束条件|
|:-------------|:---------------------|:---|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
|startTime|Long|否|期望被聚合的数据开始时间。 单位：毫秒|13位整数的时间戳，不早于1388505600000（20140101）。|
|endTime|Long|是|期望被聚合的数据结束时间。 单位：毫秒|13位整数的时间戳。 endTime需大于startTime。 endTime与startTime时间间隔不能超过31天。|
|polymerizeWith|List\<PolymerizeWith\>|是|聚合数据的标准。 至少提供一个聚合标准。 每个聚合标准产生一个汇总采样数据集。|List最大容量：20。 请参见[PolymerizeWith](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section221511853211)数据模型。|
|groupByTime|GroupByTime|否|指定数据由时间间隔聚合数据。|请参见[GroupByTime](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section156913161345)数据模型。|

#### 请求示例

```
POST
https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:polymerize
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
{
 "polymerizeWith": [
   {
     "dataTypeName": "com.huawei.continuous.steps.delta"
   }
 ],
 "endTime": 1563330660000,
 "startTime": 1563157860000,
 "groupByTime": {
   "duration": 86400000
 }
}
```

#### 响应参数

状态码为200时：

Response Header  

|参数|参数类型|是否必选|描述|
|:-------------------|:-----|:---|:--------------------------------------------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|
|x-health-app-privacy|int|是|用户隐私标记取值为： * 1：用户在运动健康App已授权 * 2：用户在运动健康App未授权 * 3：非华为运动健康App用户（无需授权）|

Response Body  

|参数|参数类型|是否必选|描述|
|:----|:------------|:---|:-------------------------------------------------------------------------------------------------------------------------------------------|
|group|List\<Group\>|是|包含汇总数据的组列表。请参见[Group](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section1943715915337)数据模型。|
