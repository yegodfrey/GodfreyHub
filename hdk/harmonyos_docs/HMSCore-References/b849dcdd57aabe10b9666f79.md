|Field|

|public static final int AWARENESS_REGISTER_FAILED_CODE 注册围栏失败。 * 当注册围栏失败，可能原因有：围栏参数转换存在异常、Android SDK版本不匹配、Awareness服务未获取到CP信息、Awareness服务未初始化完成。 * 当注册beacon围栏失败，可能原因有：Awareness订阅nearby服务失败。 * 当注册bluetooth围栏失败，可能原因有：该设备不支持蓝牙、传入的deviceType有误、deviceType当前只支持车载蓝牙类型（deviceType为0）。 * 当注册behavior围栏失败，可能原因有：Awareness订阅msdp活动服务失败。 建议：当排除上述可能原因后还存在问题，请检查调用方法是否正确，传入参数是否合法。若是依旧存在问题，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。 另请参阅：[Constant-values](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-values-0000001051057325#ZH-CN_TOPIC_0000002290683721__p8921440153116)|

#### AWARENESS_RESULT_INVALID_ERROR

|Field|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static final int AWARENESS_RESULT_INVALID_ERROR 从Awareness Kit返回的结果无效（例如，获取耳机状态未知）。 可能因为是调用快照接口超时，导致返回的结果无效。 在headset快照中出现该问题可能原因：服务未找到设备的音频管理器，无法获取耳机状态。 在ambient快照中出现该问题可能原因：设备缺少光传感器或者服务无法获取设备的光传感器；设备光传感器不灵敏或是周围环境光无变化，从而导致服务获取光照度值超时。 建议：请确认设备的相关功能是否正常。若是依旧存在问题，可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。 另请参阅：[Constant-values](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/constant-values-0000001051057325#ZH-CN_TOPIC_0000002290683721__p15951184093111)|
