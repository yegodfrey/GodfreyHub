# 新增/更新订阅记录

#### 功能介绍

新增/更新订阅记录。  

#### 场景描述

记录订阅者、用户、事件之间的关联关系，表示订阅者关注了用户的某个事件。订阅记录由订阅记录ID唯一标识。  

#### 使用约束

对于不同事件场景需要单独校验权限。例如：

ACTIVITY_RECORD_EVENT需要校验activityRecord或者兼容的activity读权限。

SAMPLESET_EVENT$UPDATE${dataType}需要校验对应的dataType数据读权限。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/subscriptions|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/json; charset=UTF-8|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body  

|参数|参数类型|是否必选|描述|
|:-----------|:------------------------------------------------------------------------------------------------------------------------------------|:---|:--------------------------------------------------------------------------------------------------------------------------------------------|
|eventTypes|List\<[EventType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section5150212112016)\>|是|关注/订阅的事件列表。支持的事件类型请参见[订阅事件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/subscription-0000001078496860#section13879857154018)。|
|subscriberId|String|是|订阅者ID，订阅者ID可从联盟网站上查询。|

#### 请求示例

```
POST
https://health-api.cloud.huawei.com/healthkit/v2/subscriptions
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
{
  "subscriberId": "08666998-78f6-46b9-8620-faa06cdbac2b",
  "eventTypes": [
      {
          "type": "ACTIVITY_RECORD_EVENT",
          "subType": "UPDATE",
          "eventType": "ACTIVITY_RECORD_EVENT$UPDATE"
      }
  ]
}
```

#### 响应参数

状态码为200时：

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

Response Body  

|参数|参数类型|是否必选|描述|
