# SubscribedItem

* 支持的场景：手机、平板。
* 支持的OS：HarmonyOS 4.0及以上。

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class SubscribedItem 您调用[getSubscribedItems](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ohos-java-support-subres-0000001680700117#section193261440453)方法返回的订阅信息。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:--------------------------------------------------|
|String|[getEntityId](#section1092415181551)() 获取订阅模板ID。|
|int|[getResultCode](#section19267455155817)() 获取消息订阅结果。|

#### Public Methods

#### getEntityId()

|Method|
|:--------------------------------------|
|public String getEntityId() 获取消息订阅模板ID。|

Returns  

|Type|Description|
|:-----|:----------|
|String|消息订阅模板ID。|

#### getResultCode()

|Method|
|:-----------------------------------|
|public int getResultCode() 获取消息订阅结果。|

Returns  

|Type|Description|
|:---|:---------------------------------------------------------------------|
|int|消息订阅结果： * -1：模板状态未知，无法订阅 * 0：用户同意订阅 * 1：用户拒绝订阅 * 2：模板名称相同被过滤 * 3：模板被禁用|
