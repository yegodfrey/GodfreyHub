# 错误码

错误码参见[HiHealthStatusCodes](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560)。

实时接口调用场景下，错误码如下。  

|数值|数据定义|典型场景|
|:----|:---------------------------------------------------------------------------------------------------------------------------|:------------------------------|
|0|调用成功|执行正常。|
|1|调用失败|没有安装华为运动健康App。|
|2|参数异常|存储血压数据时数据列表为空。|
|4|API调用异常|与运动健康App通信中断。|
|5|设备异常|设备数据读取失败或设备不支持功能。|
|30|运动健康App版本较低|查询体温新类型值时运动健康App版本较低。|
|31|与运动健康App的连接断开|订阅日常数据后，与运动健康App的连接断开，提示需要重新订阅。|
|32|HMS版本低|HMS华为移动服务版本号小于5.1.0.300。|
|101|重复调用|使用相同模型重复订阅日常数据。|
|102|超出调用阈值|订阅日常数据使用模型数超过10个。|
|150|设备未连接|未连接设备。|
|1001|隐私权限校验异常|用户未授权，需要提醒用户打开相关权限。|
|1003|APP隐私协议未同意异常|用户未在华为运动健康App上同意隐私协议。|
|1004|网络请求失败|测试权限鉴权时网络出现异常。|
|50048|未[申请验证](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-verification-0000001239730723)的应用Beta用户超出了预置数值|使用某测试权限的用户超过100人。|
