# onBLEConnectionStateChange：设备主动上报低功耗蓝牙连接状态的变化

接口原型

public void onBLEConnectionStateChange(String function)

方法描述：设备主动上报低功耗蓝牙连接状态的变化。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:-------|:-----|:------------------------------------|:---|
|function|String|获取低功耗蓝牙连接状态回调函数名，该回调函数有两个参数，详情参见响应参数。|M|
[表1 请求参数]

请求示例：

```
function() {
     window.changeBLEConnectionState = this.changeBLEConnectionState;
     // 注册蓝牙连接的回调方法
     window.hilink.onBLEConnectionStateChange("changeBLEConnectionState");
}
```

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:--------|:------|:----------------------------|:---|
|deviceId|String|蓝牙设备ID，通过接口getDeviceId()获取。|M|
|connected|Boolean|连接目前的状态： true表示连接。 false表示断开。|M|
[表2 响应参数]

![](https://media:801784947932057886)  
1. 已注册的全部回调函数，会在closeBLEConnection调用前生效。closeBLEConnection后，会清除回调注册。
2. onBLEConnectionStateChange建议在createBLEConnection前调用，确保每一次连接状态都可以被准确接收。
