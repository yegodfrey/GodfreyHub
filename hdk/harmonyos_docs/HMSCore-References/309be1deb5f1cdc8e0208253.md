# NetworkTool

* 支持的场景：手机、平板、华为智慧屏、车机。
* 支持的OS：EMUI 3.0及以上、Android 4.4及以上。

|Class Info|
|:-------------------------------------------------|
|public final class NetworkTool 使用指定参数构建Cookie的帮助类。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|static String|[buildNetworkUrl](#section1831127143712)(String domain, Boolean isUseHttps) 根据域名以及isUseHttps返回Cookie URL。|
|static String|[buildNetworkCookie](#section15276134193710)(String cookieName, String cookieValue, String domain, String path, Boolean isHttpOnly, Boolean isSecure, Long maxAge) 根据输入的值来拼接构造Cookie。|

#### Public Methods

#### buildNetworkUrl

|Method|
|:----------------------------------------------------------------------------------------------------|
|public static String buildNetworkUrl(String domain, Boolean isUseHttps) 根据域名以及isUseHttps返回Cookie URL。|

Parameters  

|Name|Description|
|:---------|:----------------------------|
|domain|域名。|
|isUseHttps|布尔类型，true表示HTTPS，false表示HTTP。|

Returns  

|Type|Description|
|:-----|:----------|
|String|Cookie URL。|

#### buildNetworkCookie

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static String buildNetworkCookie(String cookieName, String cookieValue, String domain, String path, Boolean isHttpOnly, Boolean isSecure, Long maxAge) 根据输入的值来拼接构造Cookie。|

Parameters  

|Name|Description|
|:----------|:-------------------------------------------------------------|
|cookieName|Cookie名称。|
|cookieValue|Cookie值。|
|domain|Cookie的域名。|
|path|可以访问此Cookie的页面路径。|
|isHttpOnly|true表示只有在HTTP请求头中会带有此Cookie的信息，而不能通过document.cookie来访问此Cookie。|
|isSecure|* true表示只能通过HTTPS传输此Cookie。 * false表示可以通过HTTP传输此Cookie。|
|maxAge|Cookie的生存期，单位：秒。|

Returns  

|Type|Description|
|:-----|:------------|
|String|拼接后的Cookie数据。|
