# OnCompleteListener

* 支持的场景：手机、平板、华为智慧屏、车机、智能手表。
* 支持的OS：HarmonyOS 2.0及以上。

|Interface Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public interface OnCompleteListener<TResult> 任务完成监听接口，任务执行完成后，会回调此接口中的onComplete([Task<TResult>](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-java-account-task-tresult-0000001163095881) task)方法。|
