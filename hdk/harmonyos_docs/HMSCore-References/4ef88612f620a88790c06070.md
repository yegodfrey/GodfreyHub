# HMSPAYMENT

华为支付服务 JS SDK是适配HarmonyOS应用的SDK，为HarmonyOS 应用提供便捷的支付体验和简便的接入流程。开发者的HarmonyOS 应用通过集成华为支付服务 JS SDK，再调用华为支付服务 JS SDK接口启动华为支付收银台，即可实现应用支付能力。

## 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:---|:---------------|:--------------|
|华为手机|HarmonyOS 2.0及以上|6.11.0.300及以上|

## 导入模块

```screen
import HMSPAYMENT from '@hw-hmscore/hms-payment';
```

## HMSPAYMENT.pay

pay(orderStr: any, appId: any): Promise<any>

调起收银台接口，开发者的服务器在[预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-harmony-pre-pay-order-0000001538536140)接口返回成功后组**orderStr**返回给端侧入参pay接口调起收银台。

* 参数：

  |参数名|类型|必填|说明|
  |:-------|:--|:-|:---------------|
  |orderStr|any|是|订单信息，接口入参。详情见下表。|
  |appId|any|否|应用ID，接口入参。|

* orderStr参数说明

  |**参数**|**参数类型**|**是否必填**|**描述**|
  |:--------|:-------|:-------|:---------------------------------------------------------------|
  |app_id|String|是|应用ID。|
  |merc_no|String|是|商户号。|
  |prepay_id|String|是|预下单id，使用预下单请求生成，有效期2小时。|
  |timestamp|String|是|时间戳，标准北京时间，时区为东八区，自1970年1月1日 0点0分0秒以来的毫秒数，13位。示例值：1666230721315。|
  |noncestr|String|是|随机字符串，不长于32位。推荐随机数生成算法。|
  |sign|String|是|签名，使用除了sign字段以外的其他字段计算签名值。用于开发者对响应报文进行防篡改验证。|
  |auth_id|String|是|开放平台分配的鉴权id，一个商户可配置多套证书，请妥善保管。|

* 返回值：

  |类型|说明|
  |:-----------|:------------|
  |Promise<any>|接口请求后返回的详细信息。|

* 示例：

  ```screen
  const orderStr = "{\"app_id\":\"***\",\"merc_no\":\"***\",\"prepay_id\":\"1230331185102089244382635044\",\"timestamp\":\"1680259863114\",\"noncestr\":\"1487b8a60ed9f9ecc0ba759fbec23f4f\",\"sign\":\"****\",\"auth_id\":\"***\"}"
  HMSPAYMENT.pay(orderStr).then(res => {
      // 此处处理支付结果，页面刷新或跳转等操作，res请参考下面Response
  }).catch(err => {
      console.error("paymentService err: "+ JSON.stringify(err));
  })
  ```

  **Response:**

  ```screen
  {
    "errCode": 0,
    "errMsg": "success",
    "data": {
      "PayResult": "{\"returnCode\":\"0\",\"returnMsg\":\"pay success\"}"
    }
  }
  ```

## HMSPAYMENT.signContract

* 参数：

  |参数名|类型|必填|说明|
  |:----------|:--|:-|:---------------|
  |contractStr|any|是|预签约号，接口入参。详情见下表。|
  |appId|any|否|应用ID，接口入参。|

* contractStr参数说明

  |**参数**|**参数类型**|**是否必填**|**描述**|
  |:--------|:-------|:-------|:---------------------|
  |appId|String|是|应用ID。|
  |preSignNo|String|是|预签约号，使用预签约请求生成，有效期2小时。|

* 返回值：

  |类型|说明|
  |:-----------|:------------|
  |Promise<any>|接口请求后返回的详细信息。|

* 示例：

  ```screen
  const contractStr = "{\"appId\":\"***\",\"preSignNo\":\"1230331185102089244382635044\"}"
  HMSPAYMENT.signContract(contractStr).then(res => {
      // 此处处理签约结果，页面刷新或跳转等操作，res请参考下面Response
  }).catch(err => {
      console.error("paymentService err: "+ JSON.stringify(err));
  })
  ```

  **Response:**

  ```screen
  {
    "errCode": 0,
    "errMsg": "success",
    "data": {
      "ContractResult": "{\"openId\":\"****\",\"returnCode\":\"0\",\"returnMsg\":\"success\",\"signNo\":\"*****\"}"
  ```
