# 错误码

> 说明
>
> indoorMode=1时会返回7016xxxxx错误码。

|错误码|描述|解决方法|
|:--------|:-------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|0|请求成功。|-|
|100000|参数异常。|请根据报错信息检查您的输入参数，输入参数格式请参见[Request Body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table15450132517415)。|
|100001|API Key过期或解析失败。|请在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站检查API Key。|
|100002|鉴权失败。|请在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站检查签名方法或者API Key是否配置正确。|
|100003|内部服务异常。|系统内部报错，您无法单独处理，请联系华为技术支持解决。|
|500000|套餐订阅状态异常。|请在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站检查是否已订阅套餐。|
|500001|当前您禁止使用服务。|若您是个人开发者，需[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，申请projectID允许清单后使用。|
|500032|参数个数异常|请检查Wi-Fi输入参数或Cell输入参数个数是否小于10000。|
|701200001|必选参数丢失。|请根据错误信息检查必填参数完整性，必填参数请参见[Request Body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table15450132517415)。|
|701200002|参数格式错误。|请根据错误信息检查您的输入参数格式，参数格式请参见[Request Body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table15450132517415)。|
|701200003|无有效指纹信息。|1. 请根据错误信息检查Wi-Fi输入参数是否正确，Wi-Fi输入参数请参见[WifiInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table1745142515410)。 2. 若检查Wi-Fi信息参数无误，则说明该指纹信息在指纹库中未录入，需要添加Cell参考位置。|
|701200004|无效的基站信息。|请根据错误信息检查Cell输入参数是否正确，Cell输入参数请参见[CellInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table1645242512410)。|
|701200005|Wi-Fi数据条数超过最大值。|请根据错误信息检查Wi-Fi输入参数是否正确，Wi-Fi输入参数请参见[Request Body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table15450132517415)中的wifiInfos参数。|
|701200006|Cell数据条数超过最大值。|请根据错误信息检查Cell输入参数是否正确，Cell输入参数请参见[Request Body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table15450132517415)中的cellInfos参数。|
|701200007|临区Cell数据条数超过最大值。|请根据错误信息检查Cell输入参数是否正确，Cell输入参数请参见[CellInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table1645242512410)中的neighborCells参数。|
|701600001|室内Mac数量未达触发室内定位最低数量。|请根据错误信息检查Wi-Fi参数，Wi-Fi输入参数请参见[WifiInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table1745142515410)。|
|701600002|Mac数量超出限制。|请根据错误信息检查Wi-Fi参数，Wi-Fi输入参数请参见[WifiInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table1745142515410)。|
|701xxxxxx|内部服务器错误。|1. 错误情况较复杂，您无法单独处理，请联系华为技术支持解决。 2. 建议您预先将错误码打印出来，有助于华为技术支持定位问题。|
|702100001|IP定位必选参数丢失。|请根据错误信息检查必填参数完整性，必填参数请参见[Request Body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table15450132517415)。|
|702100002|IP定位参数格式错误。|请根据错误信息检查您的输入参数格式，参数格式请参见[Request Body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/web-network-location-0000001051602603#ZH-CN_TOPIC_0000001051602603__table15450132517415)。|
|702200001|IP定位查询结果为空。|请检查IP地址是否为公网IP（内网IP无法定位）。|
|702xxxxxx|Wi-Fi、Cell均定位失败。|1. 错误情况较复杂，您无法单独处理，请联系华为技术支持解决。 2. 建议您预先将错误码打印出来，有助于华为技术支持定位问题。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。在线提单操作步骤可参见[在线提单指导](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/problems-submission-guide-0000001168773227)。
