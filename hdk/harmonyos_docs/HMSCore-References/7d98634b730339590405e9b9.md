# 取消订阅

#### 功能介绍

此接口用于主动取消用户订阅的商品，不影响已经收取费用的收据，只是在订阅到期日不会继续续订。  

#### 场景描述

在收到用户申诉不希望对订阅的商品续期后，您的服务器可以调用华为应用内支付服务器提供的取消订阅接口停止续期，商品在有效期内仍然有效，但后续的续期会终止。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\> 华为应用内支付服务器|
|接口URL|{rootUrl}/sub/applications/v2/purchases/stop 说明： rootUrl在不同站点有不同的url：您应固定选择最近站点的Subscription服务地址访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1954123781815)和[站点选择](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127#section1741234185817)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Content-Type|是|String|取值为：application/json; charset=UTF-8|
|Authorization|是|String|认证信息，使用Access Token进行鉴权，这里使用开放平台鉴权提供的服务接口获取Access Token，格式说明参见[公共说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-common-statement-0000001050986127)，获取方式参见[获取应用级AT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/obtain-application-level-at-0000001051066052)。|

Request Body  

|参数|是否必选|参数类型|描述|
|:-------------|:---|:-----|:--------------------------|
|subscriptionId|是|String|订阅ID。|
|purchaseToken|是|String|商品的购买Token，发起购买和查询订阅信息均会返回。|
