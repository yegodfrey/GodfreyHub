# VastErrorType

|Enum Info|
|:----------------------------------------|
|public enum VastErrorType VAST协议中定义的错误类型。|

## Enum Value Summary

|Enum Value and Description|Enum Value|
|:----------------------------------------------------------------|:---------|
|TRAFFICKING_ERROR 下发错误，收到的广告不是所期待的。|200|
|EXPECTING_LINEARITY_ERROR 期望的是不同的线性广告。|201|
|EXPECTING_DURATION_ERROR 期望的是不同的广告时长。|202|
|EXPECTING_SIZE_ERROR 期望的是不同的广告大小。|203|
|DISPLAY_LINEAR_ERROR 一般的线性错误，无法展示线性广告。|400|
|LINEAR_NOT_FOUND 从资源链接中无法访问有效线性广告。|401|
|MEDIAFILE_TIMEOUT 请求资源超时。|402|
|MEDIAFILE_NOT_SUPPORT 无法找到支持播放的广告资源。|403|
|MEDIAFILE_DISPLAY_ERROR 播放器找到了可播放的广告资源，但是无法播放。（比如不支持的编码、MIME类型等）。|405|
|UNDEFINED_ERROR 未定义的错误。|900|
