#### 实况窗通知涉及的原生通知接口

接口 | 必选 | 参数类型 | 描述  
---|---|---|---  
setContentTitle | 是 | CharSequence | 原生通知标题接口，传递的字符串在通知标题显示。在实况窗通知中，若不设置notification.live.titleOverlay参数，则实况窗通知的标题也显示为ContentTitle。  
setContentText | 是 | CharSequence | 原生通知内容接口，传递的字符串在通知内容显示。在实况窗通知中，若不设置notification.live.contentOverlay参数，则实况窗通知的内容也显示为ContentText。  
setUsesChronometer | 否 | boolean | 设置是否使用计时器。在基础类型的实况窗通知中，支持将主标题或副文本使用计时器来替代，需要将该接口设置为true来使计时器生效。  
setWhen | 否 | long | 设置计时器的初始时间。若已在基础类型的实况窗通知中显示计时器，可使用该接口来设置计时器显示的初始时间，单位为ms，默认为0。  
setChronometerCountDown | 否 | boolean | 设置计时器是否为倒计时。若已在基础类型的实况窗通知中显示计时器，可使用该接口来设置计时器为倒计时，默认为正计时。  
setProgress | 否 | int max int progress boolean indeterminate | 设置通知的进度。该接口有3个参数，分别设置进度的最大值、进度的当前值和进度的显示形式。在基础类型的实况窗通知中，通过该接口设置进度可在右侧显示圆形的进度条。在多操作类型的实况窗通知中，通过该接口设置进度可在中间显示直条进度条。在进度类型的实况窗胶囊中，通过该接口设置进度可控制胶囊内显示的进度值，且通过indeterminate可控制进度是以百分比形式还是数值比形式显示。  
addExtras | 是 | Bundle | 应用可使用该接口来增加扩展参数，将参数添加到Bundle中，然后将bundle添加到通知的extras中，发送时即可携带实况窗通知的扩展参数。  
setActions | 否 | Action | 设置按钮的接口。在基础类型的实况窗通知中，通过该接口可设置右侧的操作按钮。  
setLargeIcon | 否 | Icon | 设置大图标的接口。在实况窗通知中若设置了LargeIcon和IconOverlay属性，则会叠加显示LargeIcon和应用图标，否则只显示应用图标。该参数仅适用于基础操作类型模板，建议用于通话等场景。  
setSmallIcon | 是 | Icon | 设置小图标的接口，该小图标将用于在状态栏和内容视图中表示通知。  
  
#### 实况窗通知扩展参数

参数 | 必选 | 参数类型 | 描述  
---|---|---|---  
notification.live.operation | 是 | int | 实况窗通知生命周期。
                * 0：创建实况窗通知
                * 1：更新实况窗通知
                * 2：结束实况窗通知  
notification.live.event | 是 | String | 实况窗通知的应用场景。
                * TAXI：出行打车
                * DELIVERY：即时配送（外卖、生鲜）
                * FLIGHT：航班
                * TRAIN：高铁/火车
                * QUEUE：排队
                * PICK_UP：取餐
                * TIMER：计时
                * SCORE：赛事比分
                * RENT：共享租赁  
notification.live.type | 是 | int | 实况窗通知的类型
                * 0：默认类型，普通通知
                * 1：基础类型，可选区操作按钮，无扩展区
                * 3：进度可视化类型，扩展区显示通知进度
                * 4：强调文本类型，扩展区显示文本+图标
                * 5：左右文本类型，扩展区显示多条文本
                * 7：赛事类型，扩展区显示赛事信息  
notification.live.titleOverlay | 否 | CharSequence | 若携带该参数，则实况窗通知主标题显示该参数内容，若不携带，则主标题显示原生通知ContentTitle。参数限制最大128个字符。  
notification.live.contentOverlay | 否 | CharSequence | 若携带该参数，则实况窗通知副文本显示该参数内容，若不携带，则副文本显示原生通知ContentText。参数限制最大128个字符。支持传递SpannableString来设置文本颜色，最多支持设置一种强调色。  
notification.live.iconOverlay | 否 | boolean | 实况窗通知图标是否叠加显示。
                * true：若存在LargeIcon，则叠加显示LargeIcon和应用图标**（默认值）**
                * false：只显示应用图标。
叠加显示功能仅支持[基础类型](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rest-live-0000001562939968#ZH-CN_TOPIC_0000001700850537__p2074116181852)。  
notification.live.keepTime | 否 | long | 实况窗通知存档期，在结束实况窗通知后，通知保留在通知中心中显示的时长，默认0不保留，最多设置1小时，单位为s。系统会将应用设置的时间规整到标准的时间段。  
notification.live.feature | 否 | Bundle | 实况窗通知各个类型的独立扩展参数，需设置到bundle中。  
notification.live.capsule | 否 | Bundle | 实况窗胶囊的扩展参数，需设置到bundle中。  
notification.live.version | 否 | int | 实况窗通知消息序号，用于消息展示保序，当高序号通知已显示，后来的低序号通知会被拦截丢弃。
                * 若不指定序号，则实况窗通知统一放行，不做拦截处理
                * 若指定了序号，则之后的整个生命周期内均需指定序号，否则无序号的通知会被拦截丢弃  
  
#### 外屏适配的扩展参数

参数 | 必选 | 参数类型 | 描述  
---|---|---|---  
notification.live.externalEnable | 否 | boolean | 实况窗通知是否支持外屏显示，默认为true。  
notification.live.externalTitle | 否 | CharSequence | 自定义外屏显示的实况窗通知标题，若无则选择实况窗通知原本的标题。参数限制最大为128字符。支持传递SpannableString来设置文本颜色，最多支持设置一种强调色。  
notification.live.externalBody | 否 | CharSequence | 自定义外屏显示的实况窗通知内容，若无则选择实况窗通知原本的内容。参数限制最大为128字符。支持传递SpannableString来设置文本颜色，最多支持设置一种强调色。  
notification.live.externalType | 否 | int | 外屏模板类型：
                * 0：默认类型
                * 1：背景图片类型  
notification.live.externalBgImage | 否 | Icon | 外屏背景图。当externalType=1时，首次创建实况窗通知时需携带，后续若不更新可只第一次携带。  
notification.live.externalBgColor | 否 | int | 外屏背景色。默认为灰色（#F1F3F5）。  
  
#### 基础类型的扩展参数

参数 | 必选 | 参数类型 | 描述  
---|---|---|---  
notification.live.feature.chronometerPosition | 否 | int | 基础类型的实况窗通知支持将主标题或通知内容替换为计时器，使用本字段决定计时器的位置。
                * 0：计时器显示在主标题位置**（默认值）**
                * 1：计时器显示在通知内容位置  
notification.live.feature.progressHide | 否 | boolean | 基础类型的实况窗通知是否隐藏右侧的进度显示。
                * true：隐藏进度显示
                * false：不隐藏进度显示**（默认值）**

notification.live.capsuleBgColor | 是 | int | 实况窗胶囊的背景颜色。在创建胶囊时必填，更新时可不携带。  
notification.live.capsuleTitle | 否 | String | 实况窗胶囊的标题文本，在图标+文本类型的胶囊中会显示该文本。在创建图标+文本类型的胶囊时必填，更新时可不携带。参数限制不能为空，最大128个字符。  
notification.live.capsuleContent | 否 | String | 实况窗胶囊的扩展文本，当设备为宽屏设备，或设备横屏时，图标+文本类型和计时器类型的胶囊中会显示该文本。在创建图标+文本类型或计时器类型的胶囊时必填，更新时可不携带。参数限制不能为空，最大128个字符。  
notification.live.capsuleTime | 否 | long | 计时器类型的胶囊的初始时间，单位为ms，默认为0。  
notification.live.capsuleCountdown | 否 | boolean | 表示计时器类型的胶囊是否为倒计时，默认为false。  
notification.live.capsulePause | 否 | boolean | 表示计时器类型的胶囊是否暂停计时，默认为false。  
notification.live.capsuleRemind | 否 | boolean | 表示实况窗胶囊更新时是否提醒用户，需要提醒时则在更新胶囊时设置此字段为true，默认为false。胶囊存在时间内最多提醒5次。
