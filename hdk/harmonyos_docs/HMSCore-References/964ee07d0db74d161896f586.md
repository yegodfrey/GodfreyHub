# Channels:stop

## 功能介绍

删除订阅变更。

## 场景描述

调用channels.stop接口实现关闭监听某个Channel。

## 使用约束

Scope至少包含下面其中一个：

* https://www.huawei.com/auth/drive.appdata
* https://www.huawei.com/auth/drive.file
* https://www.huawei.com/auth/drive
* https://www.huawei.com/auth/drive.readonly
* https://www.huawei.com/auth/drive.metadata
* https://www.huawei.com/auth/drive.metadata.readonly

## 接口原型

|承载协议|HTTP POST|
|-----|-----------------------------------------------------------------------|
|接口方向|开发者服务器->华为云空间服务器|
|接口URL|https://driveapis.cloud.huawei.com.cn/drive/v1/channels/stop|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|

无

    public static void main(String[] args) throws IOException {
        // 设置请求地址和用户认证令牌
        String url = "https://driveapis.cloud.huawei.com.cn/drive/v1/channels/stop";
        String access_token = "CV5OUVN/e79TSba9Kaxlgx+TONKyYovWvre8BZM05oh6J51jBIbeYp0FRSuLcFBZoDaft0V/B+m+mPFf7MG3n8JmO8w3n6/K6zUI8I5/auSzdxv8GOdAPw==";
        // 删除订阅变更
        Boolean isStop = false;
        isStop = channelsStop(url, access_token);

    private static Boolean channelsStop(String url, String access_token) throws IOException {
        HttpPost httpPost = new HttpPost(url);
        httpPost.setHeader("Authorization","Bearer " + access_token);
        httpPost.setHeader("Content-Type", "application/json");
        httpPost.setHeader("Accept", "application/json");

        JSONObject jsonParam = new JSONObject();//You can get every value of jsonParam from ChangesSubscribe
        jsonParam.put("resourceId", "MTIzOTA0Njg3ODM3MTUxMjcwNA");
        jsonParam.put("category", "api#channel");
        jsonParam.put("expirationTime", "1582191947000");
        jsonParam.put("id", "46TMU");
        jsonParam.put("pushToken", "Qeqqn");
        jsonParam.put("type", "web_hook");
        jsonParam.put("url", "https://www.huawei.com");
        jsonParam.put("resourceUri", "https://drive.hicloud.com/drive/v3/changes?pageSize=100&cursor=299830100109593600&form=json&containers=drive");

        StringEntity entity = new StringEntity(jsonParam.toString());
        entity.setContentType("application/json");
        httpPost.setEntity(entity);

        CloseableHttpResponse response = HttpClientUtil.getClient().execute(httpPost);

        try {
            if(response.getStatusLine().getStatusCode() == 204){
                return true;
            }
            return false;
        }finally {
            response.close();
        }
    }
