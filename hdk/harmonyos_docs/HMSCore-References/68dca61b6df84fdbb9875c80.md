# Files:create.multipart

#### 功能介绍

创建并上传文件（multipart方式）。  

#### 场景描述

Files.create.multipart接口实现同时上传不超过20M的文件和元数据。  

#### 使用约束

* Scope至少包含下面其中一个： https://www.huawei.com/auth/drive

  https://www.huawei.com/auth/drive.appdata

  https://www.huawei.com/auth/drive.appfile

<!-- -->

* Request body为multipart格式，包括metadata和文件二进制内容。
* 文件大小不能超过20M。
* 0bit文件（空文件），不允许带缩略图上传。
* fields填\*时，drive#file 结构中sharer、sharedWithMeTime、hasShared、capabilities、permissions、permissionIds不返回。  

#### 接口原型

|承载协议|HTTP POST|
|接口方向|开发者服务器-\>华为云空间服务器|
|接口URL|https://driveapis.cloud.huawei.com.cn/upload/drive/v1/files?uploadType=multipart|
|数据格式|请求消息：Content-Type: multipart/related 响应消息：Content-Type: application/json|

#### 调用示例

```
  
public static void main(String[] args) throws Exception {
        // 设置请求地址和用户认证令牌
        String url = "https://driveapis.cloud.huawei.com.cn/upload/drive/v1/files";
        String access_token = "DAEAANApuUTBWbVKLu7HkNytlhHg+naBsKszPZ6V/uY7wIaHReDtI3sgUNmcJ1D/wcgkW6yGl5ht6fxcW3+olmgMgkS/ypJxkw89icLwzxXBbX2h3ochRK8=";
        // 创建并上传文件
        JSONObject fileInfo = filesCreateMultipart(url, access_token);
        System.out.println(fileInfo.toJSONString());
    }

    private static JSONObject filesCreateMultipart(String url, String access_token) throws Exception {
        StringBuilder stringBuilder = new StringBuilder("");
        stringBuilder.append("?").append("fields=*").append("&").append("uploadType=multipart");
        HttpPost httpPost = new HttpPost(url + stringBuilder);
        httpPost.setHeader("Authorization", "Bearer " + access_token);
        httpPost.setHeader("Content-Type", "multipart/related;boundary=OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO");
        httpPost.setHeader("Accept", "application/json");

        FileInputStream fis = new FileInputStream("D:\\123456781234.jpg");// The path of your local file
        ByteArrayOutputStream fos = new ByteArrayOutputStream();
        byte[] tempData = new byte[1024];
        int count = 0;

        // 第一部分 元数据
        byte[] multipartContentPart1 = ("--OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO" + System.lineSeparator()
            + "Content-Type: application/json" + System.lineSeparator() + System.lineSeparator() + "{"
            + System.lineSeparator() + "\"fileName\":\"hwe013.jpg\"," + System.lineSeparator() + "\"contentExtras\": {"
            + System.lineSeparator() + "\"thumbnail\":{\"content\":\"dGVzdDAwMw==\",\"mimeType\":\"image/png\"}},"
            + System.lineSeparator() + "\"parents\":[\"applicationData\"]" + System.lineSeparator() + "}"
            + System.lineSeparator() + "--OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO" + System.lineSeparator()
            + "Content-Type: application/octet-stream" + System.lineSeparator() + System.lineSeparator()).getBytes();
        fos.write(multipartContentPart1);

        // 第二部分文件内容
        while ((count = fis.read(tempData)) != -1) {
            fos.write(tempData, 0, count);
        }

        // 第三部分文件尾分隔符
        byte[] multipartContentPart3 = (System.lineSeparator() + "--OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO--").getBytes();
        fos.write(multipartContentPart3);

        ByteArrayEntity entity = new ByteArrayEntity(fos.toByteArray());
        entity.setContentType("multipart/related;boundary=OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO");
        httpPost.setEntity(entity);
        CloseableHttpClient client = HttpClients.createDefault();
        CloseableHttpResponse response = client.execute(httpPost);
        try {
            HttpEntity responseEntity = response.getEntity();
            String ret = responseEntity != null ? EntityUtils.toString(responseEntity) : null;
            JSONObject jsonObject = (JSONObject) JSON.parse(ret);
            EntityUtils.consume(responseEntity);
            return jsonObject;
        } finally {
            response.close();
        }
    }
```
