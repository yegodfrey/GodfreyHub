|Class Info|
|:-------------------------------------------------------------------------------|

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### startScan

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static int startScan(Activity activity, int requestCode, [HmsScanAnalyzerOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options4-0000001050167925) option) Default View Mode方式扫码接口，检测扫码需要的相机权限和存储权限，若有权限则跳转到由Scan Kit定义的扫码界面，若没有权限直接返回。|

Parameters  

|Name|Description|
|:----------|:---------------------------------|
|activity|请求扫码的activity。|
|requestCode|扫码请求的请求码，用于鉴定activity返回时是否从扫码界面返回。|
|option|扫码格式选项。|

Returns  

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------|
|int|扫码请求结果状态。 * 0：[SUCCESS](#section171631634203411) * 1：[ERROR_NO_CAMERA_PERMISSION](#section0154728103411)|
