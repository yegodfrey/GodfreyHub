## Public Methods

### getOpenId

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|AuthHuaweiId.prototype.getOpenId = function(){} 获取授权帐号的OpenID。如果授权时携带[setId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthparamshelper-0000001064109899#section1679116121206)指定的授权参数，该方法返回OpenID，否则返回null。 同一个用户，不同应用，OpenID值不同。使用OpenID标识用户，多个应用之间同一个华为帐号用户在开发者系统内会被标识为多个用户。当前非固定长度，最大允许长度256，需进行三倍冗余考虑，不推荐进行长度限制。|

**Returns**

|Type|Description|
|:-----|:---------------------------------------|
|string|帐号的open ID，同一个帐号，不同应用，OpenID值不同，单个应用内唯一。|

### getUnionId

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|AuthHuaweiId.prototype.getUnionId= function(){} 获取授权帐号的UnionID。如果授权时携带[setId](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthparamshelper-0000001064109899#section1679116121206)指定的授权参数，该方法返回用户的UnionID，否则返回null。 UnionID和OpenID的区别在于，如果开发者帐号下管理了多个应用，针对同一个华为帐号，不同的应用返回的OpenID值不同，但返回的UnionID相同。如果您需要在不同应用中共享同一个华为帐号的用户信息，可以使用UnionID作为用户标识。 使用UnionID作为用户标识需要满足以下所有条件： * 应用集成HMS Core SDK 3.0.0以及更高版本。 * HMS Core（APK）版本为3.0.0以及更高版本。 * 应用启用了UnionID。|

**Returns**

|Type|Description|
|:-----|:------------------------------------------------------|
|string|授权帐号的UnionID，即开发者帐号ID，同一个用户，同一个开发者帐号下管理的不同应用，UnionID相同。|

### getAuthorizedScopes

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|AuthHuaweiId.prototype.getAuthorizedScopes= function(){} 获取用户授权给当前应用的所有[Scope](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-scope-0000001064957982)或当前业务请求中传入的[Scope](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-scope-0000001064957982)。 用户授权的[Scope](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-scope-0000001064957982)数量可能会比应用通过[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185#section169782218282)或[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185#section322611432359)请求获取的[Scope](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-scope-0000001064957982)数量多，建议业务按需授权。 * 如果存在授权缓存信息，则获取用户授权给当前应用的所有[Scope](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-scope-0000001064957982)。 * 如果不存在授权缓存信息（调用[signOut](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185#section1535113443355)或者在应用管理中清除应用缓存），则获取当前业务请求中传入的[Scope](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-scope-0000001064957982)。|

**Returns**
