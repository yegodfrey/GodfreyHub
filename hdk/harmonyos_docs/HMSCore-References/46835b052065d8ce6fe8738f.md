# CameraPosition

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class CameraPosition 一个封装了相机所有属性的类。包括所有相机位置参数，如位置、缩放级别、倾斜角度和方位。使用[CameraPosition.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/cameraposition-builder-0000001050150514)构造一个CameraPosition实例，然后可以与CameraUpdateFactory结合使用。有关详细信息，请参见[移动相机](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-map-camera-0000001061885327#section149815252431)。|
