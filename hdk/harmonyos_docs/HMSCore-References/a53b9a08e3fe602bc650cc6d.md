# Message

* 支持的场景：手机。
* 支持的OS：HarmonyOS 2.0及以上。

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class Message 捐赠消息体，承载整个捐赠消息报文，包含[Session](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/session-0000001297675736)和[Content](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/content-0000001351035337)。|

## Public Method Summary

|Qualifier and Type|Method Name|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[setSession](#section23751943194815)([Session](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/session-0000001297675736) session)|
|void|[setContent](#section134382414535)([Content](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/content-0000001351035337) content)|

## Public Methods

### setSession

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setSession([Session](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/session-0000001297675736) session) 设置捐赠消息session。|

**Parameters**

|Name|Description|
|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|session|指示消息的名称、消息的版本、消息ID。 示例： ```screen "session": { "messageId": "1", "messageName": "featurePrediction", // 消息名 "messageVersion": "1.1", "deviceModel": " MHA-AL00", "deviceCategory": "", "deviceName": "", "packageName": "com.huawei.packagename" }, ```|

### setContent

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Public void setContent([Content](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/content-0000001351035337) content) 设置捐赠消息content。|

**Parameters**

|Name|Description|
|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|content|数据类型，数据内容（key、value、单位），数据产生的时间，一个content最多10个contentData。 示例： ```screen "content": { "contentVersion": "2.1", "contentData": [ { "header": { "namespace": "event", "name": "featurePrediction"  // ===== 功能推荐 }, "payload": { "eventCommonInfo": { "creationTime": 1637393112, // 事件创建时间 "effectiveTime": 1637393112, // 事件生效时间，对应predictInfo中的最早开始时间 "expirationTime": 1637394112, // 事件结束时间，对应predictInfo中的最晚结束时间 "timeZone": "+8" // 时区 }, "predictInfo":{ "featureName":"", "timelineInfo":[  // 功能预测（预约）时间线 { "startTime":1637393112, "endTime":1637393112 }, { "startTime":1637393112, "endTime":1637393112 }, { "startTime":1637393112, "endTime":1637393112 } ] }, "faFormInfo": { "bundleName": "aaa", "moudleName": "bbb", "abilityName": "ccc", "formName": "ddd", "formDimension": "fff", "formParams": { "hwChannelId": "xxx", "key1": "value1", "key2": "value2" } } } } ] } ```|
