# 说明

|Application Scenario|Name|Description|
|:-------------------|:--------|:---------------------------------------------------------------|
|支付服务|Android|基于Java语言开发的独立Android应用程序接口，包含支付接口。|
|支付服务|HarmonyOS|基于JavaScript语言开发的独立HarmonyOS应用程序接口，包含支付接口。|
|支付服务|快应用|基于JavaScript语言开发的独立快应用程序接口，包含支付接口。|
|支付服务|Server|提供支持HTTPS的云服务接口，包括支付、签约代扣、合单支付、分账、子商户管理等一系列API接口能力，以及数据模型与错误码释义。|
