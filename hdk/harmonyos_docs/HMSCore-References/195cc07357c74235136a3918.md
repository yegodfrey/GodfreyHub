# HWHeatmapLayer

## 概述

在地图上添加热力图。

## 构造函数

|函数|**描述**|
|:-------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HWMapJsSDK.HWHeatmapLayer(map, points, opts)|* map：添加的地图图层。 * points：被显示的点集合。 数据类型：Array<{location: {lng: Number, lat: Number}, weight: Number}>。 * points.weight：被显示的点权重（可选）。 数据类型：Number。取值范围：大于等于0，默认1。 * opts：设置热力图的属性，详情见[HeatmapLayerOption](#section154851722182515)。|

## 方法

|**方法**|**描述**|**参数类型**|**返回值**|
|:-------------------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------|
|getData()|获取points数据。|-|points数组： Array<{location: {lng: Number, lat: Number}, weight: Number}>|
|getMap()|获取地图图层。|-|Map对象。|
|getProperty(option)|获取可选option属性。|String 取值包括： * heatmap-radius：热力图半径 * heatmap-intensity：热力图强度 * heatmap-opacity：热力图透明度 * heatmap-color：热力图颜色|返回option对应的value，请参见[HeatmapLayerOption](#section154851722182515)参数。|
|setData(points)|设置points数据。|Array<{location: {lng: Number, lat: Number}, weight: Number}>|-|
|setMap(map)|设置地图图层。|Map对象 | null 设置为null则隐藏热力图。|-|
|setProperty(option, value)|设置可选option属性。|* option：String 取值包括： * heatmap-radius：热力图半径 * heatmap-intensity：热力图强度 * heatmap-opacity：热力图透明度 * heatmap-color：热力图颜色 * value：[HeatmapLayerOption](#section154851722182515)参数|-|

## HeatmapLayerOption

|**参数**|**是否必选**|**参数类型**|**描述**|
|:--------|:-------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|colors|否|Array<String>|热力图颜色。支持以下几种颜色设置： * 颜色名称：green * 十六进制：#ff0000 * RGB：rgb(0, 0, 0) * RGBA：rgba(0, 0, 0, 0.5) * HSL：hsl(120, 65%, 75%) 默认颜色： ```screen [ // 数组第一个颜色格式必须为rgba，且透明度为0 'rgba(45, 29, 238, 0)', 'rgba(29, 125, 238, 1)', 'rgba(25, 247, 187, 1)', 'rgba(249, 201, 23, 1)', 'rgba(249, 122, 23, 1)', 'rgba(242, 16, 16, 1)', ] ```|
|intensity|否|Number|热力图强度。取值范围：大于等于0，默认1。|
|opacity|否|Number|热力图透明度。取值范围：[0, 1]，默认1。|
|radius|否|Number|热力图半径，单位：px。取值范围：大于等于1，默认30。|
