# AmbientLightBarrier

* 支持的场景：手机。
* 支持的OS：EMUI 7.0及以上，Android 7.0及以上。

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public final class [AmbientLightBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-ambientlightbarrier-0000001050164088) extends Object 光照度围栏，提供小于（below）设定值、大于（above）设定值、在设定的区间（range）三种围栏能力。|

### range

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static [AwarenessBarrier](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-barrier-awarenessbarrier-0000001050164120) range(float minLightIntensity, float maxLightIntensity) 设置光照度range围栏，当光照度值在[minLightIntensity, maxLightIntensity)之内时，此围栏状态为true，并触发围栏事件上报；当光照度值不在区间时，围栏状态为false，并触发围栏事件上报。|
