# HmsProfile

* 支持的场景：手机、平板。
* 支持的OS：EMUI 9.1.0+、Android 9.0+。

|Class Info|
|:--------------------------------------------|
|public class HmsProfile 根据帐号校验是否显示当前用户消息功能的类。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:----------------------|:---------------------------------------------------------------|
|public static final int|[HUAWEI_PROFILE](#section14671716193815) 帐号校验功能的类型，表示关联华为帐号。|
|public static final int|[CUSTOM_PROFILE](#section7406202415401) 帐号校验功能的类型，关联其他帐号（非华为帐号）。|

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
