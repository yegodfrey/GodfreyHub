# HiAnalyticsTools

|Class Info|
|:---------------------------------------------------------------------|
|com.huawei.hms.analytics.HiAnalyticsTools 此类提供了打开调试日志的方法，以支持开发阶段的调试需求。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------|
|static void|[enableLog](#section28021816194219)() 打开调试日志，默认DEBUG级别。|
|static void|[enableLog](#section15775410448)(int level) 打开调试日志，可自定义打印的最小日志级别。|

#### Public Methods

#### enableLog

|Method|
|:-----------------------------------------------|
|public static void enableLog() 打开调试日志，默认DEBUG级别。|

#### enableLog(int level)

|Method|
|:----------------------------------------------------------------------------------------------------------------------------|
|public static void enableLog(int level) 打开调试日志，可自定义打印的最小日志级别。 调试日志： * Log.DEBUG(3) * Log.INFO(4) * Log.WARN(5) * Log.ERROR(6)|

Parameters  

|Name|Description|
|:----|:-------------------------------------------------------|
|level|开启指定级别的调试日志。 日志级别：Log.DEBUG、Log.INFO、Log.WARN、Log.ERROR。|
