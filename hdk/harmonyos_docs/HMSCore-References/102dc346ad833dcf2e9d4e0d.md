# 查询用户授予某个应用的权限信息

#### 功能介绍

查询用户授予某个应用的权限信息。  

#### 场景描述

查询用户授权给指定应用的权限信息。  

#### 使用约束

无  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|开发者应用-\>Health Service Kit云|
|接口URL|https://health-api.cloud.huawei.com/healthkit/v2/consents/{appId}?lang=xxx|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|--------------------------------------------------------------------------|

#### 路径参数

|参数|参数类型|是否必选|描述|
|:----|:-----|:---|:------------------|
|appId|String|是|待查询应用Id（三方自身的应用标识）。|

#### 查询参数

|参数|参数类型|是否必选|描述|
|:---|:-----|:---|:------------|
|lang|String|是|语言描述，比如zh-cn。|

#### 请求参数

Request Header  

|参数|参数类型|是否必选|描述|
|:----------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------|
|Content-type|String|是|取值为：application/json; charset=UTF-8|
|Authorization|String|是|请参见[认证鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058)。 说明： Bearer后面拼接空格，再拼接获取的access_token。|
|x-client-id|String|否|开放联盟分配的应用标识。服务端可以基于其进行灰度路由，建议携带。|
|x-version|String|否|接口调用方的软件版本号。即当前客户端版本号，服务端可以基于其进行灰度，建议携带。|
|x-caller-trace-id|String|否|请求跟踪ID。用于串联服务调用方与服务端整体请求链条，建议携带。|

Request Body

无  

#### 请求示例

```
GET
https://health-api.cloud.huawei.com/healthkit/v2/consents/123456789?lang=zh-cn
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
```

#### 响应参数

状态码为200时：

Response Header  

|参数|参数类型|是否必选|描述|
|:-----------|:-----|:---|:----------------------------------|
|Content-Type|String|是|取值为：application/json; charset=UTF-8|

Response Body  

|参数|参数类型|是否必选|描述|
|:----|:------------|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|items|ScopeLangItem|是|已授权应用的权限列表，请参见[ScopeLangItem](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/data-model-0000001054556973#section186758010312)数据模型。|
