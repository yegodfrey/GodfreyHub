# notifyBLECharacteristicValueChange：设置低功耗蓝牙设备是否开启指定服务的特征值的模式

接口原型

public String notifyBLECharacteristicValueChange(String deviceId, String serviceId, String characteristicId, String state)

方法描述：设置低功耗蓝牙设备是否开启指定服务的特征值的模式通过onBLECharacteristicValueChange返回设置结果。

请求参数  

|参数名称|参数类型|参数描述|可选选项|
|:---------------|:------|:--------------------------------------|:---|
|deviceId|String|蓝牙设备ID，通过接口getDeviceId()获取。|M|
|serviceId|String|蓝牙设备特征值对应服务的 UUID（不使用4位的简写，用完整写法的UUID）。|M|
|characteristicId|String|蓝牙设备特征值的UUID（不使用4位的简写，用完整写法的UUID）。|M|
|state|Boolean|true：启用 notify； false：停用 notify。|M|
[表1 请求参数]

请求示例：

```
function() {
        this.connectStatus = "0";
        let changeStatus = window.hilink.notifyBLECharacteristicValueChange(this.deviceId,
            this.globalData.SERVICE_ID, this.globalData.CHARACTERISTIC_ID, true);
        this.log.info('changeServiceDiscoverState changeStatus = ' + changeStatus);
}
```

响应参数  

|参数名称|参数类型|参数描述|可选选项|
|:------|:-----|:------------|:---|
|retCode|Number|错误码：0, 90001。|M|
