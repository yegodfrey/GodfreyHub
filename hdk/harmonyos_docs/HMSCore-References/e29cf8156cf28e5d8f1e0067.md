# Overview

该包提供Default View Mode、Customized View Mode、Bitmap Mode和Multiprocessor Mode四种扫码方式的接口和码生成接口。

## Interface Summary

|Interface|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------|
|[OnLightVisibleCallBack](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/onlightvisiblecallback-0000001059056737)|Customized View Mode扫码方式中，场景昏暗产生的回调。|
|[OnResultCallback](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/scan-onresultcallback4-0000001050165738)|Customized View Mode扫码方式中，扫码结果的回调接口。|

## Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
|[RemoteView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/scan-remoteview4-0000001050167711)|控制相机预览和扫码的视图，用于Customized View Mode扫码方式。|
|[RemoteView.Builder](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/scan-remoteviewbuilder4-0000001050165770)|用于创建视图类[RemoteView](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/scan-remoteview4-0000001050167711)的Builder类。|
|[ScanUtil](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/scan-scanutil4-0000001050167699)|扫码工具类，用于检测权限并启动扫码界面，提供Default View Mode和Bitmap Mode两种扫码方式，同时提供码生成接口。|
