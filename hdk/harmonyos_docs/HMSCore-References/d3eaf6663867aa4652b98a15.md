# IBleWalletListener

|Class Info|
|:----------------------------------------------------------------------------------------------------|
|interface IBleWalletListener extends Object ICCE车钥匙监听接口，商户开发者可通过service接口注册该监听后，实现蓝牙状态、指令交互过程和车辆数据的监听|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------|
|String|notifyCommand(String macAddress, String command) 开发者通过此接口接收钱包透传的车辆数据|
|void|notifyProcedureStatus(String macAddress, in BleProcedureStatus status) 开发者通过此接口接收钱包透传的指令交互过程|
|void|notifyBluetoothStatus(String macAddress, int status) 开发者通过此接口接收钱包透传的ICCE车钥匙蓝牙连接状态|

|Method|
|:---------------------------------------------------------------------------------|
|public String notifyCommand(String macAddress, String command) 开发者通过此接口接收钱包透传的车辆数据|
