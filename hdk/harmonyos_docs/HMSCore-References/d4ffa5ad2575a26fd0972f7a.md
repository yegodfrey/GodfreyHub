# 校验登录签名

#### 功能介绍

应用服务端在获取登录签名后调用此接口请求华为游戏服务器进行登录验签。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240927134839.88800759673428340071122358561164:50001231000000:2800:D3BAE355B5077163069166323C79F608B4C8225E60BC37814207E1C54AAF5B1B.png?needInitFileName=true?needInitFileName=true)  
此接口仅适用于使用playerId的游戏接入，新游戏请直接采用openId方式接入，具体流程请参见[新游戏接入登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526)。  

#### 场景描述

当应用客户端在获取玩家的登录签名后，将玩家信息和登录签名传递给应用服务端。为了确保玩家信息的准确性，应用的服务端需要调用本接口向华为游戏服务器验证登录签名，验证成功后才能确定登录成功。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器-\>华为游戏服务器|
|接口URL|https://jos-open-api.cloud.huawei.com/gameservice/api/gbClientApi 注意： * 此接口当前不支持SSL双向认证，在发送HTTPS请求时需要先关闭SSL认证。 * 请使用TLS 1.2协议或以上版本。|
|数据格式|请求：Content-Type: application/x-www-form-urlencoded（表单方式） 响应：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

|参数|是否必选|参数类型|是否参与签名|描述|
|:----------|:---|:-----|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|method|是|String|是|固定传入"external.hms.gs.checkPlayerSign"。|
|appId|是|String|是|游戏的应用ID，查询方法请参见[查询应用信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/query-app-info-0000001050164344)。|
|cpId|是|String|是|商户ID，即华为开发者联盟给开发者分配的开发者帐号ID。 开发者帐号ID的查询方法请参见[查询支付服务信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/query-payment-info-0000001050166299)。|
|ts|是|String|是|时间戳，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象。|
|playerId|是|String|是|玩家的playerId，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象。|
|playerLevel|是|String|是|玩家等级，取自当前玩家[Player.getLevel](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section14336195511520)方法，必须转化为string类型。|
|playerSSign|是|String|是|登录签名，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象。 此字符串主要验证登录后获取的玩家信息是否准确。|
|openId|否|String|是|玩家的openId，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象。 如果开发者需要验证playerId与openId的对应关系，需要传入openId。|
|openIdSign|否|String|是|验证openId的签名字符串，取自当前玩家的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象。 此字符串主要用于华为服务器验证playerId与openId的对应关系是否准确。|
|cpSign|是|String|否|用于华为游戏服务器对请求参数验签的签名字符串。 为防止请求被篡改，应用需要根据[登录验签接口签名字符串的生成方法](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/generation-method-0000001050166301)中的方法生成签名字符串，华为服务器在收到请求后会对签名字符串进行验签，验签成功后才会进行后续处理，否则将返回失败错误码。|

#### 请求示例

```
POST /gameservice/api/gbClientApi HTTP/1.1
Content-Type: application/x-www-form-urlencoded
User-Agent: PostmanRuntime/7.24.0
Accept: */*
Host: jos-api.cloud.huawei.com
Accept-Encoding: gzip, deflate, br
Connection: keep-alive
Content-Length: 717
playerLevel=2&playerSSign=*****&method=external.hms.gs.checkPlayerSign&openIdSign=******&cpId=89****0000013&openId=******&appId=******&cpSign=******&playerId=****&ts=*****
```

#### 响应参数

|参数|是否必选|参数类型|是否参与签名|描述|
|:------|:---|:-----|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|rtnCode|是|int|是|登录验签的返回码。 * 0：验签成功。 * -1：验签失败，请检查签名字符串是否按要求生成、时间戳是否失效、签名是否进行urlencode等。详细定位方法请参见[登录验签专题](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-check-login-0000001050746133)。 * 3001：参数错误，请检查传参是否满足格式要求、是否遗漏。 * 3：校验openId失败。|
|ts|否|String|是|接口返回的当前时间的时间戳，即当前时间距1970年的毫秒数。 此参数仅在rtnCode等于0时返回。|
|rtnSign|否|String|否|返回参数的签名字符串。 应用可以参考[对登录验签响应消息验签的方法](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verification-method-0000001050164348)对签名字符串进行验签，确认响应消息是否被篡改。|
