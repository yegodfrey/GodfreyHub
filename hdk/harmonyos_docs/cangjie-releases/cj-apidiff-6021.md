# 6.0.2(22) Beta1-仓颉Beta1引入的API

DevEco Studio-Cangjie Plugin 6.0.2 Beta1是仓颉配套HarmonyOS 6.0.2(22)发布的首个版本。该版本提供了仓颉语言标准库、仓颉与ArkTS互操作、以及仓颉版HarmonyOS系统能力Kit、ArkUI等能力。该版本提供的详细仓颉版API请参见[API参考](https://developer.huawei.com/consumer/cn/doc/cangjie-references/cj-development-intro)。
