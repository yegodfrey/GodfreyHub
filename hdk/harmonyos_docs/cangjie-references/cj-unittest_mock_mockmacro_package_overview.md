# std.unittest.mock.mockmacro

#### 功能介绍

unittest.mock.mockmacro 为 mock 框架提供了用户所需的宏。

#### API 列表

#### [h2]宏

宏名 | 功能  
---|---  
[Called](https://developer.huawei.com/consumer/cn/doc/cangjie-references/cj-unittest_mock_mockmacro_package_macros#called-宏) | 创建一个[验证语句](https://developer.huawei.com/consumer/cn/doc/cangjie-references/cj-mock_framework_verification#验证语句和-called-宏)。  
[On](https://developer.huawei.com/consumer/cn/doc/cangjie-references/cj-unittest_mock_mockmacro_package_macros#on-宏) | 使用[配置 API](https://developer.huawei.com/consumer/cn/doc/cangjie-references/cj-mock_framework_basics#配置-api) 定义 mock/spy 对象成员的行为（或重新定义 spy 对象）。
