* 若您从Java层集成，华为提供了Maven仓集成方式的HMS Core SDK包。集成方式请参见[集成HMS Core SDK-从Java层接入](https://developer.huawei.com/consumer/cn/doc/Media-Guides/integrating-sdk-0000001156025441#section5461134384418)。
