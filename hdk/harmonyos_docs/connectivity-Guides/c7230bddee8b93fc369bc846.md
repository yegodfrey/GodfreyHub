# 集成Wear Engine SDK

华为DevEco Studio开发环境，请参见[DevEco Studio使用指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/tools_overview-0000001053582387-V3)。  

#### 配置Maven仓地址

1. 打开DevEco Studio项目根路径下的build.gradle文件。

   <br />

   图1 打开根路径下的build.gradle文件

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.92442674209288761811029132490054:50001231000000:2800:6ABA7B87FAAB7B1E0B3CE42555802B10B85944775254804108690CE5E7A4C28A.png)

   <br />

2. 在"buildscript \> repositories"里面增加Maven仓配置。

   <br />

   ```
   maven {url 'https://developer.huawei.com/repo/'}
   ```

   图2 Maven仓配置

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.05164844804051314604481159128421:50001231000000:2800:738ABF6D535D977B61E691CA6C958F931E1701812546480F4DD8DCAF1B8618F6.png)

   <br />

3. 在"allprojects \> repositories"里面增加Maven仓地址。

   <br />

   ```
   maven {url 'https://developer.huawei.com/repo/'} 
   ```

   图3 Maven仓配置   
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.25315308719072321041196406378549:50001231000000:2800:D917189DB0E6F2A82AE1E11036C5D31D98FBE2543B70F66CC949E654CB070EBD.png)  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.33023698689002718734261065210552:50001231000000:2800:D09A61323905F4D257CEE0AA5A3B063FE748CCB7F3BA80134CEBB2EF99CA162F.png)  
   Maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。

   <br />

#### 添加编译依赖

1. 打开应用级的build.gradle文件。

   <br />

   图4 打开应用级的build.gradle文件

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.42969919601539026382711039814282:50001231000000:2800:58BE814E039A54776FF6EFBFF614835C1F0ADC71F0640CB7B6DA693F7A20E58F.png)

   <br />

2. 在"dependencies"中添加如下编译依赖。

   <br />

   ```
   implementation 'com.huawei.hms:wearengine-wearable-harmonyos:{version}'
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.56935939357369732610546121808869:50001231000000:2800:1B9961C8A6539184D2CA18BE47A5067AB09200F95C532C2E9C73EBD27654C1D4.png)  
   {version}替换为实际的SDK版本号：com.huawei.hms:wearengine-wearable-harmonyos:5.0.2.306。建议集成最新的SDK版本，版本号详见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/version-change-history-0000001119036892)。  
   图5 编译依赖

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.12310893171700100377954301781919:50001231000000:2800:EF58428F07747A4C910C166F5C47C54CBF45541E46403599EA6E417B45693BCE.png "点击放大")

   <br />

3. 重新打开修改完的build.gradle文件，右上方出现Sync Now链接。点击"Sync Now"等待同步完成。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250923115002.26261136872922866012650442395612:50001231000000:2800:C6908FCEDC6C4431349FCD137D16D9F4104F8C0C0E3B59F4C53641C476DFF1EA.png)  
   如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。

   <br />
