# 集成Wear Engine SDK

华为DevEco Studio开发环境，请参见[DevEco Studio使用指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/tools_overview-0000001053582387-V3)。

## 配置Maven仓地址

1. 打开**DevEco Studio** 项目根路径下的**build.gradle**文件。

   **图1** 打开根路径下的**build.gradle**文件

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/AF5rSp7cRGeQRrMyKPmGSw/zh-cn_image_0000001919950621.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=ABC1633990EA944F2BC57FA797D119A836B2AE3B0F11583A92D09EF7423D2C99)

2. 在"buildscript > repositories"里面增加Maven仓配置。

   ```screen
   maven {url 'https://developer.huawei.com/repo/'}
   ```

   **图2**Maven仓配置

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/15/v3/bVTPwdDeRvK9oqgZgJ3uLw/zh-cn_image_0000001920110281.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=FF46209065691A93C0D1C3531BE9A96471C5C0834FCFB8C4B8D0942F81883079)

3. 在"allprojects > repositories"里面增加Maven仓地址。

   ```screen
   maven {url 'https://developer.huawei.com/repo/'} 
   ```

   **图3**Maven仓配置   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/h1ojMB9HRVK1GWb7sUCOmw/zh-cn_image_0000001919950625.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=5BDD74A831041D19B168FBE512DAA75797747E6F7567C4C58CF882DC09EB1195)

   > 说明
   >
   > Maven仓地址直接在浏览器中打开无法访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。

## 添加编译依赖

1. 打开应用级的**build.gradle**文件。

   **图4**打开应用级的build.gradle文件

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/zSQYmI_BTHCTj45axybeBA/zh-cn_image_0000001920110293.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D6395E4554E591DC1EB232F904FB28129E9893795B9192FA63F28F8D7E16633)

2. 在"dependencies"中添加如下编译依赖。

   ```screen
   implementation 'com.huawei.hms:wearengine-wearable-harmonyos:{version}'
   ```

   > 说明
   >
   > *{version}* 替换为实际的SDK版本号：com.huawei.hms:wearengine-wearable-harmonyos:5.0.2.306。建议集成最新的SDK版本，版本号详见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/version-change-history-wear-java-0000001119036892)。

   **图5**编译依赖

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/2EO5_vlDQw-NwKO-SGKljg/zh-cn_image_0000001919950633.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=920E1B03A77626C1AB2329F3A03063DF36A88ADAD606AF03B18164006D073BC9 "点击放大")

3. 重新打开修改完的**build.gradle** 文件，右上方出现**Sync Now**链接。点击"Sync Now"等待同步完成。

   > 说明
   >
   > 如果出现错误，请检查网络连接是否正常，以及检查gradle文件是否正确。
