# 业务介绍

#### 业务简介

畅连能力（CaaS Engine）是华为依托畅连业务通信能力，面向应用开发者和硬件开发者提供的开放接口，可以帮助开发者快速实现应用内视频通话服务。开发者通过华为设备虚拟化服务，可以使用任意视频数据作为视频通话的视频源。  

#### 场景介绍

CaaS Engine服务于视频通话场景，与普通视频通话区别在于可以实现应用内自定义视频源的视频通话。

典型场景如下：

1. 创新智能设备制造者：集成CaaS Engine快速实现与华为设备间通信互联。
2. 互联网App开发者：集成CaaS Engine基于华为设备通信能力快速进行业务及服务的创新开发。  

#### 功能介绍

|功能|描述|
|:----------|:-------------------------------|
|给应用嵌入视频通话能力|应用通过集成CaaS Engine的SDK可以具备视频通话能力。|
|视频通话视频源自定义|开发者可将自身应用视频数据作为与对方通话的视频源。|
