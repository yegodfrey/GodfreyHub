# 申请Wear Engine服务

申请Wear Engine服务前，请先按照[注册账号及申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)的操作，申请账号服务。

1. 点击"应用服务"\>"开发服务"下的"Wear Engine"卡片。

   <br />

   图1 "Wear Engine"卡片

   ![](https://media:301772615884985645 "点击放大")

   <br />

   ![](https://media:301772615885012646)  
   如果无"Wear Engine"卡片。请点击"开发服务"标签右边图标![](https://media:301772615885044647)添加卡片。

   ![](https://media:301772615885090648 "点击放大")

   <br />

   <br />

<!-- -->

2. 点击"申请Wear Engine服务"，同意协议后，进入权限申请页面。

   <br />

   图2 申请Wear Engine服务

   ![](https://media:301772615885128649 "点击放大")

   <br />

   <br />

3. 点击"Android应用"并选择产品后，勾选必需申请的权限（个人开发者只可申请[设备基础信息](#ZH-CN_TOPIC_0000001873951218__p144135716461)、[消息通知](#ZH-CN_TOPIC_0000001873951218__p9640134154416)两个基本的权限）。

   <br />

   ![](https://media:301772615885155650)  
   * 请选择手机侧应用，穿戴设备侧应用默认不需要申请权限。
   * 若未能正确选择产品，请按照[注册账号及申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)的操作，申请账号服务。

4. 上传申请数据权限及使用说明、用户授权路径说明，选择授权入口是否展示华为品牌LOGO后提交。

   <br />

   * 申请数据权限及使用说明填写要求：
     * 权限说明：提供申请的数据权限，每个权限一行。
     * 数据使用说明：提供使用数据权限的需求、场景、目的和方式等。
     * 数据展示路径：提供所申请权限的使用场景的界面截图。可选。
   * 用户授权路径说明填写要求：
     * 提供获取用户授权的界面截图及界面操作路径的文字描述。
     * 如果应用内提供了修改授权的功能，请提供修改授权的界面截图及界面操作路径的文字描述。可选。

   ![](https://media:301772615885279653)

   * 用户授权路径说明：[用户授权路径说明（范例）](https://hihealthbase-drcn.things.hicloud.com/healthkit/fileServer/getFile/plain/authDisplayDesc/000/001/062/1000000000000001062.20260228015622.62864815611324569060780795144875:20760216015648:100005355:4D88BD3183D7B4DE07ACDD94FFFD8BD10BD271850BFB585F1215324979201B64.xlsx)。

   <br />

5. 等待申请通过。

   <br />

   权限审批一般需要1到2周。取决于申请的权限类型和应用发布地区，我们将视应用发布地区的相关要求进行权限开放的评估。

   如果提交的材料不满足要求，审批将不能通过。如果审批通过，即可进入开发测试阶段，完成开发测试后即可发布。

   若您的业务范围发生变动，需要修改相应的数据权限，您可以点击"修改"重新提交申请。
