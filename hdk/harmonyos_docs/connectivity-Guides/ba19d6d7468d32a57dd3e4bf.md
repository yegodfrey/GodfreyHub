# 手写套件功能

#### 开发流程

|序号|步骤名称|目的|
|:-|:-----------------------------------------------------------------------|:--------------------------------------------------|
|1|[判断Pencil Engine是否可用](#ZH-CN_TOPIC_0000001059327099__li7668185920159)|判断当前机器是否支持Pencil Engine，以免功能失效。|
|2|[初始化手写套件](#ZH-CN_TOPIC_0000001059327099__li6668175913155)|获取HwHandWritingView实例。|
|3|[（可选）设置手写套件参数](#ZH-CN_TOPIC_0000001059327099__li152637220407)|* 设置当前笔形工具，不设置默认使用圆珠笔，二档笔宽，黑色。 * 设置最大页数参数，不设置默认10页。|
|4|[（可选）设置手写套件监听回调事件](#ZH-CN_TOPIC_0000001059327099__li6668459151514)|三方应用可以在不同的回调操作中定制应用想要实现的功能。|
|5|[（可选）实现保存、撤销、重做、清空画布等功能](#ZH-CN_TOPIC_0000001059327099__li86681598158)|Pencil Engine提供了这些功能的接口，三方应用可以实现自己的UI然后调用接口。|
|6|[（可选）获取缩略图功能样例](#ZH-CN_TOPIC_0000001059327099__li1647818238182)|获取手写笔迹缩略图。|
|7|[（可选）配置ConfigChanges信息](#ZH-CN_TOPIC_0000001059327099__li13599171916339)|配置configChanges信息，横竖屏转换、屏幕大小变化、暗黑模式切换等场景，以免笔记丢失。|

#### 约束与限制

禁止将Pencil Engine手写套件集成在PopupWindow中。  

#### 开发步骤

1. 判断Pencil Engine是否可用。

   <br />

   ```
   if (!HwPenEngineManager.isEngineRuntimeAvailable(this)) { 
       Log.w(TAG, "isEngineRuntimeAvailable false"); 
       return; 
   }
   ```

   <br />

2. 初始化手写套件。

   <br />

   ```
    /** 在布局文件中新增手写套件*/ 
   <com.huawei.stylus.penengine.view.HwHandWritingView 
       android:id="@+id/hw_handwriting_view" 
       android:layout_width="match_parent" 
       android:layout_height="match_parent" /> 
     
   /** 在代码中初始化*/ 
   private HwHandWritingView mHandWritingView; 
   mHandWritingView = findViewById(R.id.hw_handwriting_view);
   ```

   也可以在代码中通过addview的方式将手写套件加载到指定ViewGroup中。

   <br />

3. （可选）设置手写套件参数。

   <br />

   ![](https://media:201775014443280267)  
   当您需要定制手写套件虚拟页数和笔型工具时，需要调用下面两个接口。

   ```
   /** 设置最大虚拟页数为15*/
   mHandWritingView.setMaxPages(15);
   /** 设置笔型为铅笔，笔宽为二档，颜色为黑色*/
   mHandWritingView.setToolType(3, 1, 6);
   ```

   <br />

4. （可选）设置手写套件监听回调事件。

   <br />

   ```
   mHandWritingView.setPaintViewListener( 
        new IPaintViewListener() { 
            /** 手写套件每一笔手写数据变化的回调*/
            @Override             
            public void onStepChanged(int step) { 
                /** 设置撤销、恢复、保存按钮是否可用*/
                mUndo.setEnabled(mHandWritingView.canUndo()); 
                mRedo.setEnabled(mHandWritingView.canRedo()); 
                mSave.setEnabled(mHandWritingView.isChanged());
            } 
     
            /** 手写套件初始化回调，需要调用load方法读取手写数据文件，该方法和onLoaded共同完成手写数据文件读取的流程*/
            @Override             
            public void onEngineInit() { 
                if (mSaveInfo.exists()) { 
                    try { 
                        mHandWritingView.load(mSaveInfo.getCanonicalPath());                     
                    } catch (IOException e) {                         
                        Log.e(TAG, "mOpen: mHandWritingView.load :IOException");                     
                    }                 
                 } else { 
                     mHandWritingView.load();                
                 }             
            } 
     
            /** 手写数据文件渲染完成的回调*/
            @Override             
            public void onLoaded() {             
            }         
        });
   ```

   <br />

5. （可选）实现保存、撤销、重做、清空画布等功能。

   <br />

   ![](https://media:201775014443306268)  
   当您需要调用手写套件的保存、撤销、重做、清空等功能时，请实现监听事件去调用这些接口。
   1. 添加您想要实现的按钮到布局文件中，如撤销、重做、保存按钮。
   2. 初始化按钮对象，设置按钮监听事件。

      ```
      mUndo.setOnClickListener( 
           new View.OnClickListener() { 
           @Override 
           public void onClick(View view) { 
               if (mHandWritingView.canUndo()) { 
                   mHandWritingView.undo(); 
               } 
           } 
       }); 
      mRedo.setOnClickListener( 
           new View.OnClickListener() { 
           @Override 
           public void onClick(View view) { 
               if (mHandWritingView.canRedo()) { 
                   mHandWritingView.redo(); 
               } 
           } 
       });
      mSave.setOnClickListener( 
           new View.OnClickListener() { 
           @Override 
           public void onClick(View view) { 
               try { 
                   File saveDirectory = new File(getExternalFilesDir(null), "saveFileName.txt"); 
                   boolean isSaveSuccess = mHandWritingView.save(saveDirectory.getCanonicalPath()); 
                   if (!isSaveSuccess) { 
                       Log.e(TAG, "save file failed."); 
                   } 
               } catch (IOException e) { 
                   Log.e(TAG, "invalid file"); 
               } 
           } 
       });
      ```

   <br />

6. （可选）获取缩略图功能样例。

   <br />

   ![](https://media:201775014443435269)  
   当您需要将手写内容分享或做部分展示时，可以调用获取缩略图功能实现。

   ```
   int MAX_BITMAP_HEIGHT = 4000;
   Rect rect = mHandWritingView.getContentRange(); 
   if (rect.width() <= 0 || rect.height() <= 0) { 
       return; 
   } 
   int extraHeight = getResources().getDimensionPixelSize(R.dimen.dimen_40dp); 
   int currentHeight = rect.bottom + extraHeight; 
   int bitmapHeight = currentHeight > MAX_BITMAP_HEIGHT ? MAX_BITMAP_HEIGHT : currentHeight; 
   Bitmap bm = Bitmap.createBitmap(rect.width(), bitmapHeight, Bitmap.Config.ARGB_8888); 
   RectF rectf = new RectF(rect.left, 0, rect.right, bitmapHeight); 
   mHandWritingView.getThumbnail(bm, rectf);
   ```

   <br />

7. （可选）在mainifest文件中配置configChanges信息。当您需要手写套件在设备做了某种操作（如转换横竖屏）后不重建Activity（在重建Activity之前如果没有保存可能会导致之前的数据丢失），请参照如下说明进行配置。

   <br />

   |配置项|说明|
   |:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |keyboard|键盘类型发生了改变，比如用户使用了外插键盘。|
   |keyboardHidden|键盘状态发生了改变，比如用户调出了键盘。|
   |orientation|屏幕方向发生了改变，这个最常用，比如旋转手机屏幕。|
   |screenSize|屏幕的尺寸信息发生改变。当旋转设备屏幕时，屏幕尺寸发生改变，这个选项比较特殊，它和编译选项有关，当编译选项中的minSdkVersion和targetSdkVersion均低于13时，此选项不会导致Activity重启，否则会导致Activity重启（API 13新添加）。|
   |smallestScreenSize|设备的物理尺寸发生改变，这个项目和屏幕的方向没关系，仅仅表示在实际的物理屏幕的尺寸改变的时候发生，比如用户切换到了外部的显示设备，这个选项和screenSize一样，当编译选项中的minSdkVersion和targetSdkVersion均低于13时,此选项不会导致Activity重启，否则会导致Activity重启（API 13新添加）。|
   |screenLayout|屏幕的显示发生了变化，比如不同的显示器被激活。|
   |uiMode|用户界面模式发生改变，比如开启了深色模式。 说明： 在华为设备上，Pencil Engine手写套件默认会随主题颜色切换而切换，要禁止自动适配切换，可以采取以下两种方式： * 在configChanges里配置uiMode，在重写的onConfigurationChanged方法中不对uiMode做处理。 * 设置全套自定义颜色主题，不使用华为EMUI主题。|

   <br />
