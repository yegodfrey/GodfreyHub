# 发送端开发场景设计

作为文件分享发起端，通过调用接口实现Huawei Share能力。

**正常场景：**

* 指定文本或选中文件（单个或多个文件）。
* 发起分享，启动对端设备发现，显示对端设备列表及标识。
* 选中设备，启动分享，对端设备接收文件。
* 完成文件传输。

**异常场景：**

* 未发现设备；
* 对端拒绝接收文件；
* 文件传输过程中异常中止。
