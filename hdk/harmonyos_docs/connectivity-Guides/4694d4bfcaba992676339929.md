# Huawei DevEco Studio接入流程

#### 注册认证

开发者需要注册华为开发者联盟帐号，并且实名认证才能享受联盟开放的各类能力和服务，详见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/20300)。填写完善相关信息后，提交给华为进行审核。提交申请后，华为将在3个工作日内对您的申请进行处理并及时通知您审批结果，请耐心等待。  

#### 获取Beta权限

您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。

1. 登录[华为开发者联盟](http://developer.huawei.com/consumer/cn/)官网或者网页搜索"华为开发者联盟官网"点击进入。
2. 注册华为开发者联盟帐号，并点击右上角头像旁边的下拉图标，点击"立即前往实名认证"上传信息进行实名认证。
3. 实名认证后，在开发者联盟网站中选择"开发 \> 开发工具 \> HUAWEI DevEco Studio"。
4. 点击"试用申请"。

#### 获取技术支持

您在使用Huawei DevEco Studio时，如果您有任何的问题或建议，都可以通过如下两种方式与我们取得联系。

1. 在线工单：登录[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站，在菜单栏选择"支持 \> 技术支持 \> 在线提单"，进入在线提单页面提交工单。
2. 邮件反馈：发送邮件至devConnect@huawei.com，反馈问题。  

#### 安装和配置DevEco Studio

获取Beta权限后，您就可以下载HUAWEI DevEco Studio软件进行开发了。

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn)官网。
2. 点击右上角"管理中心 \> 应用服务"页面，点击开发服务旁边的图标![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513191802.98922358027431134547125678561533:50001231000000:2800:2A8859944FB64E4D8BDA4E917D051ED9BC31C7B4F4C7E404BF6A066B5051C9B0.png)并打开"配置"菜单，勾选HUAWEI DevEco Studio卡片。

   <br />

   配置完成后，即可在"开发服务"中看到HUAWEI DevEco Studio卡片。

   <br />

3. 在开发服务中，点击HUAWEI DevEco Studio卡片，阅读和签署Beta保密协议。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513191802.30060843912350804804479497224393:50001231000000:2800:98F36DB327E4DE718721068BF405A9C8A8439148FE8742E40D1ACBF083CC2BC9.png "点击放大")

   <br />

4. 点击对应版的"IDE下载"按钮（当前包括Windows版和Mac版）获取DevEco Studio软件包。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513191802.86284408217691006790850073351644:50001231000000:2800:D779A7CB86A85AC529EB05997879A426D27B0023FD384EAA262EA4874E8C2748.png "点击放大")

   <br />

5. 软件包下载完成后，请根据DevEco Studio使用指南中的[安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/install-0000001050028630)和[配置DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/config-guide-0000000000034467)章节完成环境的安装和配置。
