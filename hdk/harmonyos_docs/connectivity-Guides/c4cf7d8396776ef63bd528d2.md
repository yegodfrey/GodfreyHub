# 注册账号及申请账号服务

1. 注册成为开发者并完成实名认证，注册链接详细操作请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/Blaj2j24RuikeD_ggxvVCQ/zh-cn_image_0000002503619657.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=83133431AD4DBC4C109EAFE91213A730BEE1FE9CFD0CCAC44F3342321B2FD66D "点击放大")

   > 说明
   >
   > 个人开发者只可申请两个基本的服务权限（[设备基础信息](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-0000001050777982#ZH-CN_TOPIC_0000001873951218__p144135716461)、[消息通知](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-0000001050777982#ZH-CN_TOPIC_0000001873951218__p9640134154416)），企业开发者可申请完整的服务权限，建议优先申请企业开发者账号。

2. 登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/)，点击进入"管理中心"。

   **图1**进入"管理中心"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/-UYSFwaRRGSMVjPxSu3AMg/zh-cn_image_0000002470700024.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=47A3D987E9A2853D49FE995FCA11FE993B1EC62DE6D13313F2F7D603368B7BF5)


3. 点击"应用服务">"开发服务">"账号"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/6WmOTZpSR8yFb7mtPntDAA/zh-cn_image_0000002503601041.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1A33B81BB29FC82141999B1C0FF68FCEEB0B6ECD8666BC0AA2FB6A56C880BCB "点击放大")


4. 点击"申请账号服务"，同意协议后，进入产品信息填写页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/lJEsVD59TyapdbHUm9nh4w/zh-cn_image_0000002470686604.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=3F7631C0588CE9E01E79E5F5B95953BCBDC9F08E55F4B131B1FC6CE76504B24B "点击放大")

   * **产品类型**：选择"Android移动应用"。
   * **账号接入方式**：默认"SDK接入"。
   * **选择产品** ：选择Android移动产品，包括已创建和未创建两种情况。
     * 情况一：已创建产品，则从已创建的产品列表里选择。
     * 情况二：未创建产品。
       1. 点击"创建产品"，并填写应用名称、选择应用类型和语言。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/OWQ5_brIQXWEK3wx1q7P6A/zh-cn_image_0000002465567434.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=6F0F4654C30BB965D030B748841595DF6DDEAA0976C5F86D0A29D453DDE60D41)

       2. 创建成功后，生成APP ID以及Secret信息。用来标识应用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/kg52NPl9SSCn75x0S52T-w/zh-cn_image_0000002465407798.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=425D79DA82DD7303C5AF84187E0B31B2D4D717EE1EE28E3C7F85858D36A15447 "点击放大")

   * **应用包名** ：填写[应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)。如"com.huawei.healthdemoanna"，请与APK包名一致，提交后不允许修改。
   * **SHA256证书指纹** ：填写证书指纹，签名证书指纹用于校验应用的真实性。参见[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#2)创建应用程序的签名证书，然后参见[生成签名证书指纹](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#3)获取签名文件的SHA256证书指纹。 说明
     >
     > 建议开发者优先配置应用的多个应用市场的证书指纹，方便开发者的穿戴设备侧应用与手机侧不同应用市场下载的应用进行消息通信。
   * **回调地址**：可选，最多添加50个回调地址。每个地址：不超过255个字符；（可选）支持IP地址和端口；url中不能包含问号。


5. 点击"提交"，即可完成账号服务的开通，AGC中应用的"华为账号"开关会自动开启。开通完成后，继续[申请Wear Engine服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-0000001050777982)。

   > 说明
   >
   > 在[AGC](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)可查看"华为账号"开关开启情况。查看前，应用需添加至项目，添加方式请参考[创建项目和应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-0000001100014692)。
