# 集成Wear Engine SDK

DevEco Studio开发环境，请参见[DevEco Studio使用指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/tools_overview-0000001053582387-V3)。

1. 将SDK文件下载到本地，然后解压出wearengine.js文件。

   * 轻量级智能穿戴设备侧SDK： [WearEngine-LiteWearable](https://developer.huawei.com/consumer/cn/doc/connectivity-Library/litewearable-sdk-0000001051627695)
   * 智能穿戴设备侧SDK：[WearEngine-Wearable](https://developer.huawei.com/consumer/cn/doc/connectivity-Library/wearable-sdk-0000001052267687)

2. 将wearengine.js文件拷贝到代码工程目录**\entry\src\main\js\default** **\pages**，并在代码中导入使用。

   ```screen
   import { P2pClient, Message, Builder } from '../wearengine.js'
   ```

> 说明
>
> 集成轻量级智能穿戴设备侧SDK：[WearEngine-LiteWearable](https://developer.huawei.com/consumer/cn/doc/connectivity-Library/litewearable-sdk-0000001051627695)时，DevEco Studio 支持的Compile SDK版本为6或10。
