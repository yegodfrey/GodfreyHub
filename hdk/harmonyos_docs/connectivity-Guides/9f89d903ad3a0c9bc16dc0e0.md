# 概述

#### 业务流程

首先使用DV Engine服务，需要AndroidManifest.xml中声明使用android:sharedUserId="android.uid.system"系统权限。

DV Engine开发的基本方法是，首先创建VirtualizationAdapter对象并且连接后端服务进行初始化，通过该对象获得虚拟化服务；通过服务可以启动停止设备发现监听及虚拟化事件处理。
