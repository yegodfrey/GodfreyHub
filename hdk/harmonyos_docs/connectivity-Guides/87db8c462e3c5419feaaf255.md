# 集成SDK

1. 启动 IDE（如 Xcode），把 iOS 包中的压缩文件中WearEngineSDK.framework文件拷贝到项目文件夹下，并导入到项目工程中。
2. 在Build Phases选项卡的Link Binary With Libraries中，增加以下依赖：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/8_fgYST_Q0KO9vSZnzZjow/zh-cn_image_0000002658542843.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=2F6391B87FE5232F9198CC1C8DD33F524F4277D2B88F6AA75F337701BEF6304E "点击放大")

3. 导入SDK后，在代码中添加import依赖，重新编译项目工程。编译通过，说明依赖引入成功。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/iHGkQ_GAT7mWrgQb8Pl4Cw/zh-cn_image_0000002096465304.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=D0C770BB2B11DB0E0591FA1F799775F81BDE7647F6C9EDFC6534794D7D53268F "点击放大")

4. 在项目的info.plist文件中添加下面2个URL Scheme：

   * huaweischeme
   * huaweihealthwearengine

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/EYoUc5STQbyHvm06L921Vw/zh-cn_image_0000002090407420.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=A75FB601BA034029009F2DDA9A58954A3D9543AFDE020FEFAF2EB82221FDC387 "点击放大")
   > 说明
   >
   > URL Scheme配置的目的是：在授权过程中，通过Scheme跳转到运动健康app。
   >
   > 当前，应用/app的Queries URL Schemes数量不超过50个。若应用的Queries URL Schemes数量超过50时，可调用[authWithClientId](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesauthclient-class-0000001897943254#section15405203834110)接口进行授权。
