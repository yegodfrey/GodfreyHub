# 集成SDK

1. 启动 IDE（如 Xcode），把 iOS 包中的压缩文件中WearEngineSDK.framework文件拷贝到项目文件夹下，并导入到项目工程中。
2. 在Build Phases选项卡的Link Binary With Libraries中，增加以下依赖：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/OpFBw8xmQZWrecU5lhfQiQ/zh-cn_image_0000002658542843.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=227916530DD039EEF463D4E03DF49BEF5C1E3772E932C0FBE20844E895B563AD "点击放大")

3. 导入SDK后，在代码中添加import依赖，重新编译项目工程。编译通过，说明依赖引入成功。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/JvroAfCjSWOFGGFRJJ8tDg/zh-cn_image_0000002096465304.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=26EC8E7F65AAFB42EEBA727147412BA33FECE3999EF6BDC4C867544EAB8B4BA7 "点击放大")

4. 在项目的info.plist文件中添加下面2个URL Scheme：

   * huaweischeme
   * huaweihealthwearengine

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/bynobgvHT2O2-hjdXorfJQ/zh-cn_image_0000002090407420.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=A6047438CB609E9BA6DCE76FEAF6520F8D3F9C18132B30A22E0C683ED5604C7B "点击放大")
   > 说明
   >
   > URL Scheme配置的目的是：在授权过程中，通过Scheme跳转到运动健康app。
   >
   > 当前，应用/app的Queries URL Schemes数量不超过50个。若应用的Queries URL Schemes数量超过50时，可调用[authWithClientId](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesauthclient-class-0000001897943254#ZH-CN_TOPIC_0000001897943254__section15405203834110)接口进行授权。
