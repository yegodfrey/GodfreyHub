# 添加APP ID、修改包名、配置签名证书

为确保接入的第三方应用是合法的，华为会对应用的包名、APP ID及证书指纹进行校验。以确保和申请账号服务时提供的一致。

在您调测验证前，请对应用完成如下修改。

## 添加APP ID

1. 打开**AndroidManifest.xml**文件。

   **图1**打开AndroidManifest.xml文件   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/5fcfd73vTfqmrFFO9MfkTw/zh-cn_image_0000001873951270.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=7C7D87F3C9ACC35757F687C1CFADAF0DDF17A01AB1C3CA91F20040D4B2FB30D4)

2. 在"application"中添加开发者联盟创建应用时生成的**APP ID**信息。

   value请使用[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)过程中创建产品生成的**APP ID** 。

   ```screen
   <meta-data
       android:name="com.huawei.hms.client.appid"
       android:value="******"/>
   <!-- 将上述 * 号内容修改为实际 APP ID，其他内容无需修改  -->
   ```

   **图2**添加APP ID

## 修改包名

如果您的包名与[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)中填写的包名不一致，请[修改应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)为一致。

## 配置签名证书

1. 生成签名证书。开发者通过Android Studio创建一个新的签名文件并使用其对APK进行签名。此签名文件后续会用于生成SHA256指纹。

   1. 在新建的Android Studio工程的菜单栏中选择"Build > Generate Signed Bundle/APK..."。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/PvOJiiFcQ06_-uhy4v7LNQ/zh-cn_image_0000002752537741.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=2FB0B56F1C4ED708E25C3A9AF7CB1B759B66F6D40504701D7689A90C79AFED1F)

   2. 在"Generate Signed Bundle or APK"页面，选择"APK"签名，并点击"Next"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fb/v3/kevb_qxCTjS2s85jPGvKtQ/zh-cn_image_0000002752458815.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A48C94F81791448198925CD007A5B2A9F5159F2A3E932770ED7C425A32FAD06)

   3. 在填写签名文件信息页面，如果已经存在签名文件，则点击"Choose existing..."选择签名文件，并填写对应签名文件的"Key store password"、"Key alias"、"Key password"，然后点击"Next"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/77/v3/Qe5hi2UTRoWgpimrrYgTHQ/zh-cn_image_0000002752459099.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=2AAA0B19760AB3E74A495BD3DF74B5D6189FF2DEEA58E4B2B4E1A050C5F9F3B5)

      如果不存在签名文件，则选择"Create new..."，创建一个新的签名文件。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/yh83hIG4TdWlqDaktVIcqw/zh-cn_image_0000002752540381.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=B410031FD53221D3A4F5449A207A3C13C4680939B396EA2B49643A2466CE6839)

      在创建新的签名文件页面，填写签名文件的保存地址以及保存文件名称、签名文件的密码、Alias等信息。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/TqNA-OHqTcumi5rx1KeUlg/zh-cn_image_0000002752540547.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=76B3EE5B479BAD9C1E8BAB071AAE634BC8B6920113E69A0D7E671C58D95F0C02)

      完成新签名文件创建后，在"Generate Signed Bundle or APK"弹出框页面上会显示对应签名文件的信息，然后点击"Next"。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3d/v3/8R3r1iliQmKkMI_jcCAGQw/zh-cn_image_0000002722940780.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=3FF87F71DD1795C7841031F6B5B99AD1BF9BCDF9933B5E8388DCF8044E3AF460)
   4. 在填写完签名信息页面点击"Next"后，出现选择签名方式页面，在此页面勾选"V1"和"V2"签名选项，并点击"Finish"，生成一个签名APK（此APK可上传至AppGallery Connect用于自动获取应用包名）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b3/v3/F4ybzLmsSZa1_DKKP_Uv_w/zh-cn_image_0000002722780868.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=F908D7E09CE18B01D6292FE5AC8AD4F731FE7A8CEEC10EE87C35E8A873361EB9)

2. 生成签名证书指纹。开发者通过JDK的Keytool工具以及签名文件，导出SHA256指纹。

   1. 使用JDK携带的Keytool工具导出签名证书中的SHA256信息。
      * Windows系统
        1. 执行CMD命令打开命令行工具，执行cd命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。
        2. 执行keytool -list -v -keystore <keystore-file>命令，其中<keystore-file>为应用签名证书的完整路径。
        3. 根据结果获取对应的SHA256指纹。 示例：

           ```screen
           cd C:\Program Files\Java\jdk\bin
           keytool -list -v -keystore C:\TestApp.jks
           ```

           ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/uA4wcl35TYWvxv0otqweyQ/zh-cn_image_0000002757568784.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=836891FA72A34240623F27BB51A4B43142FBA020EBB00620A319002126BFBCC9)
      * macOS系统
        1. 打开Terminal终端。
        2. 执行命令keytool -list -v -keystore <keystore-file>，其中<keystore-file>为应用签名证书的完整路径，
        3. 根据结果获取对应的SHA256指纹。

        示例：

        ```screen
        keytool -list -v -keystore /Users/admin/Downloads/Demo.jks
        ```

3. AppGallery Connect上添加指纹证书。开发者将生成的SHA256指纹配置到AppGallery Connect上。

   1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)网站，点击"开发与服务"。
   2. 在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。
   3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/0xoptsM_QJKO8ZRkH6E1oA/zh-cn_image_0000002752471471.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=B54A758A7E8CC2BC377C574CC8016FBE0D60379F398F627CC97E940E326BCFDC)

   4. 配置完成后，点击"保存"。

4. AppGallery Connect上开通API服务。

   1. 在项目的"应用"信息页面，选择"API管理"页签。
   2. 在"API管理"页签中，找到想要开通的服务，打开该服务所在行的开关。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/DmsePUBRTeyg5cYG1PqwwQ/zh-cn_image_0000002752551931.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=F43175E03E7160675DC02A08B71775AF2CDC1CED62AA1621775FBBDAB5D3ECEE)

5. 添加应用的AppGallery Connect配置文件。

   登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/05/v3/ZbXv_mIBSgidBtzjTPEA2A/zh-cn_image_0000002757730642.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=0ACEBDB2CE43C720261F8DBEC411751C863A174C23FF7287E8981DF38F8B968F)

   将"agconnect-services.json"文件拷贝到应用级根目录下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/rTJMbzITSyirV7RyNwlhiA/zh-cn_image_0000002787129431.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D95DD1E55B5D4038B89B299E9178936BCDDC939900DF04B01CE15550219BB32)

6. 配置HMS Core SDK的Maven仓地址。

   具体请参考[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/integrating-sdk-0000001050069724)。

7. 添加agcp插件配置。

   打开应用级的"build.gradle"文件（通常是 app/build.gradle），添加agcp插件配置，有如下两种方式，请根据实际情况选择：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/PXRAR9SUTHWmYzayQf-nKA/zh-cn_image_0000002723144934.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=84097D01219853A0C1684C9421D707BD7DF30A1DC36C71E3C72AD4152B7FCC49)
   * 方式一：在文件头部声明下一行添加如下配置。

     ```screen
     apply plugin: 'com.huawei.agconnect'
     ```

   * 方式二：在plugins中添加如下配置。

     ```screen
     plugins { 
         id 'com.android.application' 
         // 添加如下配置 
         id 'com.huawei.agconnect' 
     }
     ```

8. 配置项目签名。

   1. 将已经生成的签名文件HmsDemo.jks拷贝到app文件夹下，并打开应用级build.gradle文件（通常是 app/build.gradle）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/8mIwqNH8QrKoPYFYHQcQhQ/zh-cn_image_0000002722985606.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=D294ED063A7A7F91B88B6E665425603A71CBBD146D6E47BC4F22BF237A5348D6)

   2. 在build.gradle文件的android闭包中添加签名配置信息。

      ```screen
      signingConfigs { 
           release { 
               storeFile file('HmsDemo.jks') 
               keyAlias 'hmsdemo' 
               keyPassword '123456' 
               storePassword '123456' 
               v1SigningEnabled true 
               v2SigningEnabled true 
           } 
      } 

      buildTypes { 
           release { 
               signingConfig signingConfigs.release 
               minifyEnabled false 
               proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro' 
           } 
           debug { 
               signingConfig signingConfigs.release 
               debuggable true 
           } 
      }
      ```

9. 点击"Sync Now"同步工程。completed successfully即代表同步成功，至此完成了集成准备工作。
