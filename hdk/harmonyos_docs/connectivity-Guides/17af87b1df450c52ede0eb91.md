# 添加APP ID、修改包名、配置签名证书

为确保接入的第三方应用是合法的，华为会对应用的包名、APP ID及证书指纹进行校验。以确保和申请账号服务时提供的一致。

在您调测验证前，请对应用完成如下修改。  

#### 添加APP ID

1. 打开AndroidManifest.xml文件。

   <br />

   图1 打开AndroidManifest.xml文件   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250709163007.00980319345859466308881556185640:50001231000000:2800:C35919685FE74F3A0973DEFDB3624300829650194D094085F01EFCE198BC3172.png)

   <br />

2. 在"application"中添加开发者联盟创建应用时生成的APP ID信息。

   <br />

   value请使用[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)过程中创建产品生成的APP ID。

   ```
   <meta-data
       android:name="com.huawei.hms.client.appid"
       android:value="******"/>
   <!-- 将上述 * 号内容修改为实际 APP ID，其他内容无需修改  -->
   ```

   <br />

#### 修改包名

如果您的包名与[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)中填写的包名不一致，请[修改应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)为一致。  

#### 配置签名证书

[配置签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#7)，注意签名文件需与[申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)中填写的证书指纹匹配。
