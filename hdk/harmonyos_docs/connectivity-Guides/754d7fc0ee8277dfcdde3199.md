# 使用入门

## 开发环境

* 安装Android Studio 3.4及以上。

* 您的应用应满足以下条件：

  * minSdkVersion 23
  * targetSdkVersion 29
  * compileSdkVersion 29
  * Gradle 4.6及以上

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：参见[支持的设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/introduction-0000001059179897#section199351939122310)。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/config-agc-0000001058750349)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/config-agc-0000001058750349#section1464519554325)、[创建应用](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/config-agc-0000001058750349#section15850522183317)。|
|2|[在Android Studio项目中集成Pencil Engine SDK](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/android-studio-integrating-sdk-0000001059060025)|在开发应用前，您需要将Pencil Engine SDK集成到您的开发环境中：|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/config-obfuscation-scripts-0000001059470317)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|应用开发|您根据业务需求完成[手写套件功能](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/handwriting-suite-function-0000001059327099)、[报点预测功能](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/stroke-estimate-function-0000001060192798)、[一笔成形功能](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/instant-shape-function-0000001119998328)、[手写笔双击功能](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/double-click-function-0000001166918053)实现。|
|5|[开发后自检](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/pre-release-check-0000001059322357)|华为提供对应用自动检查的能力。|
|6|[上架申请](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/app-release-0000001059665589)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|
