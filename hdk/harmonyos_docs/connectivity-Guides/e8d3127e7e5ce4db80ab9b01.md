# 穿戴设备传感器获取

> 注意
>
> 人体传感器功能仅限专业研究机构使用。

手机侧应用可以通过Wear Engine获取穿戴设备上的传感器信息，并通过打开、关闭命令控制获取传感器数据。

使用传感器相关接口前，需要向手机侧用户申请获取对应权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/requesting-user-authorization-0000001050819181)），否则接口将调用失败。

|传感器类型|申请权限|
|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|ECG、PPG、HR|[SENSOR](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__SENSOR) 人体传感器|
|ACC、GYRO、MAG|[MOTION_SENSOR](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#section1410013154017) 运动传感器|

> 说明
>
> * 穿戴设备侧无对应的第三方应用，手机侧应用也可以使用该能力获取穿戴设备传感器。
> * 请确保穿戴设备和华为运动健康App处于连接状态。用户可进入App"设备"界面查看设备是否在线。开发者可调用[isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)方法了解设备是否在线，如果返回false（true：已连接；false：未连接）提醒用户重新连接设备。

## 获取穿戴设备的传感器列表

手机侧应用可以获取穿戴设备上传感器列表，并获得这些传感器的名称、ID、上报周期等参数。

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getSensorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getSensorClient-android_content_Context-)方法，获取[SensorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130)对象。
3. 调用[getSensorList](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__getSensorList-com_huawei_wearengine_device_Device-)方法，获取指定连接设备的传感器列表。

   ```screen
   // 步骤2：获取传感器客户端对象
   SensorClient sensorClient = HiWear.getSensorClient(this);

   // 步骤3：调用getSensorList方法，获取指定连接设备的传感器列表
   Sensor ecg = null;
   Sensor ppg = null;
   Sensor acc = null;
   if (connectedDevice != null && connectedDevice.isConnected()) {
       sensorClient.getSensorList(connectedDevice).addOnSuccessListener(new OnSuccessListener<List<Sensor>>() {
           @Override
           public void onSuccess(List<Sensor> sensors) {
               for (Sensor item : sensors) {
                   Log.d(TAG, "getSensorList sensor name is: " + item.getName());
                   Log.d(TAG, "getSensorList sensor id is: " + item.getId());
                   if (Sensor.NAME_PPG.equals(item.getName())) {
                       ppg = item;
                   }
                   if (Sensor.NAME_ECG.equals(item.getName())) {
                       ecg = item;
                   }
                   if (Sensor.NAME_ACC.equals(item.getName())) {
                       acc = item;
                   }
               }
           }
       }).addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               Log.e(TAG, "getSensorList task submission error " + e.getMessage());
           }
       });
   }
   ```

   > 说明
   > * [getSensorList](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__getSensorList-com_huawei_wearengine_device_Device-)方法的调用使用的是Task模式，通过OnSuccessListener和OnFailureListener回调来获取调用结果。如果回调到OnSuccessListener表示getSensorList方法调用成功，如果回调到OnFailureListener表示[getSensorList](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__getSensorList-com_huawei_wearengine_device_Device-)方法调用失败。
   > * [Sensor](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensor-0000001059980981)对象不允许自己构造，必须通过[getSensorList](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__getSensorList-com_huawei_wearengine_device_Device-)接口获取。

## 打开指定传感器并获取传感器数据

手机侧通过[getSensorList](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__getSensorList-com_huawei_wearengine_device_Device-)方法获取传感器列表后可以通过[asyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__asyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorReadCallback-)方法打开指定传感器，并通过传入的回调方法获取传感器数据。

1. 参见上一小节[获取穿戴设备的传感器列表](#section77891421131617)，获取设备的传感器列表信息。
2. 初始化和实现[SensorReadCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorreadcallback-0000001060099095)接口，用于获取传感器上报的数据。
3. 调用[asyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__asyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorReadCallback-)方法，打开指定传感器。

   ```screen
   // 步骤2：初始化和实现 SensorReadCallback 接口，用于获取传感器上报的数据
   SensorReadCallback sensorReadCallback = new SensorReadCallback() {
       @Override
       public void onReadResult(int errorCode, DataResult dataResult) {
           // 耗时操作建议在子线程去处理，否则可能会导致数据处理阻塞
           switch (dataResult.getSensor().getType()) {
               case Sensor.TYPE_PPG:
               case Sensor.TYPE_ECG:
                   Log.d(TAG, "asyncRead " + dataResult.getSensor().getName() + " errorCode is: " + errorCode);
                   List<DataResult> dataResults = dataResult.asList();
                   for (DataResult item : dataResults) {
                       Log.d(TAG, "channel is: " + item.getChannel() + " data is: " + Arrays.toString(
                           item.asFloats()));
                    }
                   break;
               case Sensor.TYPE_ACC:
                   Log.d(TAG, "asyncRead " + dataResult.getSensor().getName() + " errorCode is: " + errorCode
                       + " data is: " + Arrays.toString(dataResult.asFloats()));
                   break;
               default:
                   break;
           }
       }
   };

   // 步骤3：调用 asyncRead 方法，打开指定传感器。
   sensorClient.asyncRead(connectedDevice, sensor, sensorReadCallback)
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               Log.d(TAG, "asyncRead task submission success" + " sensor name is:" + sensor.getName());
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               Log.e(TAG, "asyncRead task submission error " + e);
           }
       });
   ```

   > 说明
   > * [asyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__asyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorReadCallback-)方法的调用使用的是Task模式，通过OnSuccessListener和OnFailureListener回调来获取调用结果。如果回调到OnSuccessListener表示[asyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__asyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorReadCallback-)方法调用成功，如果回调到OnFailureListener表示asyncRead方法调用失败。
   > * 传感器成功打开后，会根据每个传感器的上报周期，连续不断的通过[SensorReadCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorreadcallback-0000001060099095)接口的[onReadResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorreadcallback-0000001060099095#ZH-CN_TOPIC_0000001920110405__onReadResult-int-com_huawei_wearengine_sensor_DataResult-)方法上报数据，数据上报时长可由开发者通过关闭传感器接口自行控制。每组数据都有时间戳属性，建议开发者根据时间戳进行数据对齐。不同的传感器上报的数据格式是不同的，具体可参见：[穿戴设备传感器数据格式及样例](#section18811142832216)。
   > * 传感器上报的数据最终都是以float[]的形式呈现，其中又分为多通道传感器，如PPG、ECG，和非多通道传感器，如ACC。
   >   * 对于非多通道传感器，可以直接通过调用[DataResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670)对象的[asFloats](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670#ZH-CN_TOPIC_0000001920110365__asFloats--)方法获取数据。
   >   * 对于支持多通道的传感器，数据在dataResult类中嵌套了一层。以PPG为例，在一种设备上，PPG的数据包含GREEN、RED、IR三路通道，可以通过[DataResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670)对象的[asList](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670#ZH-CN_TOPIC_0000001920110365__asList--)方法获得一个List<DataResult>，该List的长度即为通道数（比如：PPG为3）。通过[getChannel](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670#ZH-CN_TOPIC_0000001920110365__getChannel--)方法来区分不同的通道，具体可参考[DataResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670)定义和[Sensor](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensor-0000001059980981)定义，每个通道的数据，可以再调用[asFloats](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670#ZH-CN_TOPIC_0000001920110365__asFloats--)方法获取。
   > * 如果希望一次打开多个传感器，可以将[asyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__asyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorReadCallback-)方法中传入的[Sensor](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensor-0000001059980981)参数改为使用链表List<Sensor>，一次会打开设备上的多个传感器。这时多个传感器使用同一个回调方法上报数据，需要根据[DataResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670)中的[getSensor](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670#ZH-CN_TOPIC_0000001920110365__getSensor--)方法来判断当前数据属于哪个传感器。
   > * 设备连接状态断开，设备会停止传感器数据的上报，需要开发者主动订阅设备的连接状态，设备重新连接上后主动调用[asyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__asyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorReadCallback-)方法打开指定传感器开始数据上报。

## 关闭指定传感器

当开发者希望关闭传感器时，可以调用[stopAsyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__stopAsyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorStopCallback-)方法。

1. 参见前面两小节[获取设备的传感器信息列表](#section77891421131617)与[打开指定传感器并获取传感器数据](#section1217814464225)，获取设备的传感器列表信息并打开指定传感器。
2. 初始化和实现[SensorStopCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorstopcallback-0000001059781035)接口，用于获取关闭传感器的结果。
3. 调用[stopAsyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__stopAsyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorStopCallback-)方法，关闭指定传感器。

   ```screen
   // 步骤2：初始化和实现 SensorStopCallback 接口，用于获取关闭传感器的结果。
   SensorStopCallback sensorStopCallback = new SensorStopCallback() {
       @Override
       public void onStopResult(int errorCode) {
           Log.d(TAG, "stopAsyncRead " + sensor.getName() + " errorCode is: " + errorCode);
       }
   };

   // 步骤3：调用 stopAsyncRead 方法，关闭指定传感器。
   sensorClient.stopAsyncRead(connectedDevice, sensor, sensorStopCallback)
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               Log.d(TAG, "stopAsyncRead task submission success" + " sensor name is:" + sensor.getName());
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               Log.e(TAG, "stopAsyncRead task submission error " + e.getMessage() + " sensor name is:"
                   + sensor.getName());
           }
       });
   ```

   > 说明
   > * [stopAsyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__stopAsyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorStopCallback-)方法的调用使用的是Task模式，通过OnSuccessListener和OnFailureListener回调来获取调用结果。如果回调到OnSuccessListener表示[stopAsyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__stopAsyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorStopCallback-)方法调用成功，如果回调到OnFailureListener表示[stopAsyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__stopAsyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorStopCallback-)方法调用失败。
   > * 传感器关闭成功后，会通过[SensorStopCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorstopcallback-0000001059781035)接口的[onStopResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorstopcallback-0000001059781035#ZH-CN_TOPIC_0000001920110401__onStopResult-int-)方法获得传感器关闭结果，0表示关闭成功，非0返回值可在错误码表中查看失败原因。
   > * 如果希望一次关闭多个传感器，可以将[stopAsyncRead](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__stopAsyncRead-com_huawei_wearengine_device_Device-java_util_List-com_huawei_wearengine_sensor_SensorStopCallback-)方法中传入的[Sensor](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensor-0000001059980981)参数改为使用链表List<Sensor>，一次可以关闭多个传感器。
