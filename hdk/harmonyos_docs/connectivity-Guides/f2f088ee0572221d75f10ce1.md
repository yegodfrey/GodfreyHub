# 约束与限制

|检查项|规格要求|建议配置|最小配置|
|:------|:-----------|:---------------------------------------------------------------------------------------|:-----------------------------------------|
|资源|ROM|1M 注：不包含安全认证和蓝牙/WLAN的ROM占用|512K 注：不包含安全认证和蓝牙/WLAN的ROM占用|
|资源|RAM|5M|4M|
|Speaker|音频编解码器|支持AAC-LC、PCM、G.711A其中之一|支持PCM|
|Speaker|声道数|支持1-2声道|支持1声道|
|Speaker|采样率|支持采样率8K-48KHz|支持采样率8KHz|
|Speaker|位宽|支持16bit|支持16bit|
|Mic|音频编解码器|支持AAC-LC、PCM、G.711A其中之一|支持PCM|
|Mic|声道数|支持1-2声道|支持1声道|
|Mic|采样率|支持采样率8K-48KHz|支持采样率8KHz|
|Mic|位宽|支持16bit|支持16bit|
|Mic|Mic前置处理能力|包含降噪和回声消除能力|包含降噪和回声消除能力|
|Camera|编码格式|支持H264编码|支持H264编码|
|Camera|分辨率规格|1080P以上|720P以上|
|Camera|帧率|支持典型帧率：15fps、20 fps、25 fps、30fps；运行时可修改帧率|支持典型帧率：15fps、30fps|
|Camera|是否支持B帧|不支持B帧|不支持B帧|
|网络|WLAN|支持802.11ac，2*2天线，WLAN（2.4G） 40Mbps，WLAN（5G）100Mbps （linux wpa_supplicant version >= 2.9）|支持802.11b/g/n，1*1天线，WLAN（2.4G） 30Mbps|
|网络|蓝牙|支持BLE，支持GATT profile bluez version >= 5.52|支持BLE，支持GATT profile bluez version >= 5.52|
|操作系统|Linux/LiteOS|Linux/LiteOS|Linux/LiteOS|
|屏幕（可选）|可显示的屏幕|可显示的屏幕|可显示的屏幕|
