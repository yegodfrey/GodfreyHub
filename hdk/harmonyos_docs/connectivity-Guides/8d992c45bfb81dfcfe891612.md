# 注册账号及申请账号服务

1. 注册成为开发者并完成实名认证，注册链接详细操作请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

   **图1**注册成为开发者

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/tP8hdQquQGymD0RMtl3dXA/zh-cn_image_0000002547516181.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=48843A2C3208BEA3F13949CA679B8F672DB0269325406BA21B579365CBEC3552 "点击放大")

2. 登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/)，点击进入"管理中心"。

   **图2**进入"管理中心"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/kzbLF08FQVeNZYSsjpYSzw/zh-cn_image_0000002515956940.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=713FE140435FE90B85628AF0548F9604C79DB006EE79DBAF733E19E0E6C2D3A2 "点击放大")

3. 点击"AppGallery Connect"。

   **图3**点击"AppGallery Connect"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/iaAxt1wIS0mdI1D3D4t_DA/zh-cn_image_0000002516000572.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=661A710FB2B51792DC063ADE6902DE3E51E1E474D0FF9E57AA3E5321E93E061D "点击放大")

4. 点击"开发与服务"，进入项目页面。点击"添加项目"。

   **图4**点击"开发与服务"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/5dO5QWZtSemRWso7HquXyQ/zh-cn_image_0000002516956910.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A5D66CFA783587873D975F5A66198A1622ADA63E7AE79590E6473A7A6426396 "点击放大")

   **图5**点击"添加项目"   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/s71Uw7dzSce2r-UG9YdSMA/zh-cn_image_0000001958009585.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=5594107A50DA1062E6A63D120D6D0C66843BB01F88F11920F0F162F4BF5506FC "点击放大")

5. 输入项目名称，选择是否开通分析服务（可不开通），创建项目。

   **图6**输入项目名称创建项目

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/lmJabivYSYq3zXIzP6_kgQ/zh-cn_image_0000002547640389.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=07342CF82D4A781D66597408AA8C4399BBE9E02E5DC3D857ADD2DA8066D5D13C "点击放大")

6. 在项目中添加应用。选择"iOS"，填写软件包ID和应用名称。

   **图7**在项目中添加应用

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/6jQQoRKTT6KrQ6PHiEWT3w/zh-cn_image_0000002601639405.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=1FEEBA699009D3E2F9C23FC66F8D544878D6AB5DAA048774CB13F0BA5C69D707 "点击放大")

   **图8**选择"iOS"，填写软件包ID和应用名称   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/xOv8EXX-SHSma8b0_P_2UQ/zh-cn_image_0000001957924577.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=5AC043A2B5A3794D2E5821EEDAB1B6845BF0451199CB44B5A12440ED2A16F500 "点击放大")

7. 在完成"iOS应用"的创建后，还需要在应用中添加回调地址。

   在项目的应用配置中，填写WearEngine接入专属的回调地址：https://h5hosting.dbankcdn.com/cch5/healthkit/oauth-h5/oauth-callback.html ，修改位置如下图。在[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/request-user-authorization-ios-0000001920933293)时需要填写Client Secret。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/3FoQpcNvSD-t-yze_sOCyA/zh-cn_image_0000002548476867.png?HW-CC-KV=V1&HW-CC-Date=20260914T093830Z&HW-CC-Expire=31536000000&HW-CC-Sign=970E391B33964ECD925FDE0CC8C419CCF2EFEF7B3FAB7A5D4077D248D325453E)

8. 点击"确认"，即可完成"iOS应用"的创建，接下来请[申请Wear Engine服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-ios-0000001935664117)。
