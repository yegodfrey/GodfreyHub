# 注册账号及申请账号服务

1. 注册成为开发者并完成实名认证，注册链接详细操作请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

   **图1**注册成为开发者

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2c/v3/RVI0kM9SQ1O1mfQlcYIo4g/zh-cn_image_0000002547516181.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=ECD01847848193FFBEDFC0C4320EAD8A9814F3706AE5024250B0A26EBF597394 "点击放大")

2. 登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/)，点击进入"管理中心"。

   **图2**进入"管理中心"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/41DRlrTBR82QJ3ziylndtw/zh-cn_image_0000002515956940.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E006CEE971D205E5DEEA9A08BED5F65A19FF1C09BAF088202398D7DC96E7F54 "点击放大")

3. 点击"AppGallery Connect"。

   **图3**点击"AppGallery Connect"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/LKKYHcaZRnOThstPve210Q/zh-cn_image_0000002516000572.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=A7AB689AF3DFEACAA0B2DBB3183AC46AEF86D364172CD6F3EA1BCDD0D86AC678 "点击放大")

4. 点击"开发与服务"，进入项目页面。点击"添加项目"。

   **图4**点击"开发与服务"

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/ugT4Vn0gTQucGfLoEHqqOA/zh-cn_image_0000002516956910.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=43E931EF9EDBB9987C7E21B6807F9AE52AD3D7083FCF0BA6989D0E41535BDB2C "点击放大")

   **图5**点击"添加项目"   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/dzuUuCb8T1uY2nGcxdHvFg/zh-cn_image_0000001958009585.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=94071290570F4C8AE4A41A0CBB71C9FDD9D31236ACBCEC616BB699A2E8BB0691 "点击放大")

5. 输入项目名称，选择是否开通分析服务（可不开通），创建项目。

   **图6**输入项目名称创建项目

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c7/v3/zPuE3pakQoCP41iONo5X9A/zh-cn_image_0000002547640389.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=6FE4EE36FAA69A58789D3E27E55573B38C34B94FFC4A39E9A3907023B4333397 "点击放大")

6. 在项目中添加应用。选择"iOS"，填写软件包ID和应用名称。

   **图7**在项目中添加应用

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/db/v3/YScz7X_ZRuaX4IGadopULA/zh-cn_image_0000002601639405.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=ACCDEE414C68E879A9FF147757746E162FD3BAE8FCFEF91D13417A7DD88F44C5 "点击放大")

   **图8**选择"iOS"，填写软件包ID和应用名称   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/0XSPeHdUSHa7PYil5lcFow/zh-cn_image_0000001957924577.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=B727B9F43642154EFFBB62F51140885FA512B6EDD2EF1E305A2E71270D00BCA1 "点击放大")

7. 在完成"iOS应用"的创建后，还需要在应用中添加回调地址。

   在项目的应用配置中，填写WearEngine接入专属的回调地址：https://h5hosting.dbankcdn.com/cch5/healthkit/oauth-h5/oauth-callback.html ，修改位置如下图。在[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/request-user-authorization-ios-0000001920933293)时需要填写Client Secret。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/9N776IKHQfmuwIyWdHzz0w/zh-cn_image_0000002548476867.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=CDD8E0E12D8AF2598F1C503D23382FAF0CD0F73A148CB9289070B0234ADB7C92)

8. 点击"确认"，即可完成"iOS应用"的创建，接下来请[申请Wear Engine服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-ios-0000001935664117)。
