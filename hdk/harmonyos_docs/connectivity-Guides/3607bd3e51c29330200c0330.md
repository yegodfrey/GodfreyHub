# 穿戴设备信息查询

在获取设备列表之前，需要向手机侧用户申请获取[DEVICE_MANAGER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__DEVICE_MANAGER)权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/requesting-user-authorization-0000001050819181)），否则设备列表将获取失败。  

#### 获取支持应用间消息通信能力的穿戴设备

手机侧应用获取已配对的华为穿戴设备列表（仅包含支持[应用间消息通信](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-0000001051059209)的设备），并从设备列表中选定需要操作的设备。

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getDeviceClient-android_content_Context-)方法，获取[DeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120)对象。
2. 调用[getBondedDevices](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#ZH-CN_TOPIC_0000001919950697__getBondedDevices--)方法，获取已配对的设备列表。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506152011.04447017857730181236516095224630:50001231000000:2800:934F1CA2DC8DE4216E70A1E9AC2B87BA972C645847742178C6E6BE6B5A7FE8D2.png)  
   * 若用户的运动健康App版本为11.0.3.512及以上，用户对同一个设备进行了解绑并重新绑定操作后，设备详细信息中的UUID会发生变化，如果使用之前缓存的设备调用业务接口，有可能会出现UUID非法异常（[ERROR_CODE_DEVICE_UUID_IS_INVALID](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineerrorcode-0000001059980969#ZH-CN_TOPIC_0000001873951390__ERROR_CODE_DEVICE_UUID_IS_INVALID)），建议此时通过getBondedDevices方法重新获取设备。
   * 设备的详细信息参见[Device](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971)对象。

   <br />

3. 从设备列表中选定需要操作的设备（可选，若需要实现其他功能，如：[应用间消息通信](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-0000001051059209)，则需要实现该步骤），必须是已连接的设备，不然后续操作会失败。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506152011.35695065748324707623903143657977:50001231000000:2800:E482695E21F658BBDD1DDFFB269F564211335037C447D6D2006AC26E1B9B055C.png)  
   * 华为运动健康App可以与多款穿戴设备配对，但同一时间只能连接一款穿戴设备。
   * [isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)接口返回的设备连接状态不是实时的，该连接状态为调用[getBondedDevices](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#ZH-CN_TOPIC_0000001919950697__getBondedDevices--)方法时返回的状态。如果需要订阅设备的实时连接状态，参见[状态查询与订阅](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/monitoring-device-status-0000001050785756)章节。

   ```
   // 存储已配对的设备列表List
   final List<Device> deviceList = new ArrayList<>();

   // 步骤1：获取DeviceClient对象
   DeviceClient deviceClient = HiWear.getDeviceClient(this);

   // 步骤2：获取已配对的设备列表
   deviceClient.getBondedDevices()
       .addOnSuccessListener(new OnSuccessListener<List<Device>>() {
           @Override
           public void onSuccess(List<Device> devices) {
               // 获取到的设备列表
               deviceList.addAll(devices);
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 获取设备列表异常时，处理相关的逻辑
           }
       });

   // 步骤3：从设备列表选定需要操作的设备，必须是已连接的设备，不然后续操作会失败
   Device connectedDevice = null;
   if (deviceList != null && !deviceList.isEmpty()){
       // 说明：该部分为获取已连接的设备的代码逻辑，开发者需要根据实际情况修改，获取需要通信的设备
       for(Device device : deviceList){
           if(device.isConnected()){
               connectedDevice = device;
           }
       }
   }
   ```

   在获取到的Device列表中取出[Device](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971)对象，调用Device对象中的[isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)接口可查询该设备的连接状态（true：已连接；false：未连接）。

   ```
   device.isConnected();
   ```

#### 获取支持Wear Engine能力的穿戴设备

通过[getBondedDevices](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#ZH-CN_TOPIC_0000001919950697__getBondedDevices--)方法获取的为支持应用间通信能力的穿戴设备，某些穿戴设备不支持应用间通信，但是支持Wear Engine的其他能力，可以通过[getCommonDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#section35971727163219)方法获取。

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getDeviceClient-android_content_Context-)方法，获取[DeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120)对象。
2. 调用[getCommonDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#section35971727163219)方法，获取已配对的设备列表。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506152011.78259089772063353456879989036606:50001231000000:2800:3E9145C268A54D81B47D822A3940CA98C92311F9B03F8EA184B181960A9C45E6.png)  
   * [具有Wear Engine能力的穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/service-introduction-0000000000018585#section14370945135215)才能通过[getCommonDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#section35971727163219)方法获取到。
   * 若用户的运动健康App版本为11.0.3.512及以上，用户对同一个设备进行了解绑并重新绑定操作后，设备详细信息中的UUID会发生变化，如果使用之前缓存的设备调用业务接口，有可能会出现UUID非法异常（[ERROR_CODE_DEVICE_UUID_IS_INVALID](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineerrorcode-0000001059980969#ZH-CN_TOPIC_0000001873951390__ERROR_CODE_DEVICE_UUID_IS_INVALID)），建议此时通过[getCommonDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#section35971727163219)方法重新获取设备。
   * 设备的详细信息参见[Device](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971)对象。

   <br />

3. 从设备列表中选定需要操作的设备（可选，若需要实现其他功能，如：[应用间消息通信](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-0000001051059209)，则需要实现该步骤），必须是已连接的设备，不然后续操作会失败。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506152011.46326534970192967405118649375001:50001231000000:2800:0B03D70973B77453BA2E63B4E58C7611578E53238C32A3A3E91221D04104A8E8.png)  
   华为运动健康App可以与多款穿戴设备配对，但同一时间只能连接一款穿戴设备。

   ```
   // 存储已配对的设备列表List
   final List<Device> deviceList = new ArrayList<>();

   // 步骤1：获取DeviceClient对象
   DeviceClient deviceClient = HiWear.getDeviceClient(this);

   // 步骤2：获取已配对的设备列表
   deviceClient.getCommonDevice()
       .addOnSuccessListener(new OnSuccessListener<List<Device>>() {
           @Override
           public void onSuccess(List<Device> devices) {
               // 获取到的设备列表
               deviceList.addAll(devices);
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 获取设备列表异常时，处理相关的逻辑
           }
       });

   // 步骤3：从设备列表选定需要操作的设备，必须是已连接的设备，不然后续操作会失败
   Device connectedDevice = null;
   if (deviceList != null && !deviceList.isEmpty()){
       // 说明：该部分为获取已连接的设备的代码逻辑，开发者需要根据实际情况修改，获取需要通信的设备

           if(device.isConnected()){
               connectedDevice = device;
           }
       }
   }
   ```

   <br />

4. 在获取到的Device列表中取出[Device](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971)对象，调用Device对象中的[isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)接口可查询该设备的连接状态（true：已连接；false：未连接）。

   <br />

   ```
   device.isConnected();
   ```

   <br />

5. 调用Device对象中的[getP2pCapability](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#section10259112594716)、[getMonitorCapability](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#section599145914319)、[getNotifyCapability](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#section165631894415)、[getSensorCapability](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#section95716166416)接口可以分别判断设备是否支持应用间消息通信、状态查询与订阅、穿戴模板化通知、穿戴设备传感器获取，返回值为0代表支持，1代表不支持，2代表未知。

   <br />

   ```
   // 判断设备是否支持应用间消息通信能力
   device.getP2pCapability();
   // 判断设备是否支持状态查询与订阅能力
   device.getMonitorCapability();
   // 判断设备是否支持穿戴模板化通知能力
   device.getNotifyCapability();
   // 判断设备是否支持穿戴设备传感器获取能力
   device.getSensorCapability();
   ```

   <br />

#### 查询穿戴设备是否支持某种能力集

通过queryDeviceCapability方法查询穿戴设备是否支持某种能力集，目前仅支持查询设备是否支持CBTI数字疗法能力集，ID为128。

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getDeviceClient-android_content_Context-)方法，获取[DeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120)对象。
2. 调用[getBondedDevices](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#ZH-CN_TOPIC_0000001919950697__getBondedDevices--)或者[getCommonDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#section35971727163219)方法，获取已配对的设备列表。
3. 从设备列表中选定需要操作的设备，必须是已连接的设备，不然后续操作会失败。

   <br />

   ```
   // 存储已配对的设备列表List
   final List<Device> deviceList = new ArrayList<>();

   // 步骤1：获取DeviceClient对象
   DeviceClient deviceClient = HiWear.getDeviceClient(this);

   // 步骤2：获取已配对的设备列表
   deviceClient.getCommonDevice()
       .addOnSuccessListener(new OnSuccessListener<List<Device>>() {
           @Override
           public void onSuccess(List<Device> devices) {
               // 获取到的设备列表
               deviceList.addAll(devices);
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 获取设备列表异常时，处理相关的逻辑
           }
       });

   // 步骤3：从设备列表选定需要操作的设备，必须是已连接的设备，不然后续操作会失败
   Device connectedDevice = null;
   if (deviceList != null && !deviceList.isEmpty()){
       // 说明：该部分为获取已连接的设备的代码逻辑，开发者需要根据实际情况修改，获取需要通信的设备
       for(Device device : deviceList){
           if(device.isConnected()){
               connectedDevice = device;
           }
       }
   }
   ```

   <br />

4. 在获取到的Device列表中取出[Device](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971)对象，调用Device对象中的[isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)接口可查询该设备的连接状态（true：已连接；false：未连接）。

   <br />

   ```
   device.isConnected();
   ```

   <br />

5. 调用Device对象中的queryDeviceCapability方法查询设备是否支持某种能力集，返回值为0代表支持，1代表不支持。

   <br />

   ```
   // 查询设备是否支持CBTI数字疗法能力集, device:已连接的设备对象, 128:表示设备是否支持CBTI数字疗法能力集。

       .addOnSuccessListener(new OnSuccessListener<Integer>() {
           @Override

               // DEVICE_CAPABILITY_NOT_SUPPORT: 不支持            
               if(integer == Device.DEVICE_CAPABILITY_SUPPORT){
                   // 处理设备支持CBTI数字疗法能力集相关的逻辑            
               }        
           }    
       })    
       .addOnFailureListener(new OnFailureListener() {
           @Override        
           public void onFailure(Exception e) {
               // 查询设备能力集出现异常，处理相关的逻辑        
           }    
       });
   ```

#### 查询穿戴设备的序列号

通过getDeviceSn方法查询穿戴设备的SN号。在调用getDeviceSn获取设备SN之前，需要向手机侧用户申请获取DEVICE_SN权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/requesting-user-authorization-0000001050819181)），否则会导致获取设备SN失败。

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getDeviceClient-android_content_Context-)方法，获取[DeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120)对象。
2. 调用[getCommonDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#section35971727163219)方法，获取已配对的设备列表。
3. 调用[DeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120)对象中的getDeviceSn方法查询穿戴设备的SN号。

   <br />

   ```
   // 查询穿戴设备的SN号，需要有DEVICE_SN权限。
   deviceClient.getDeviceSn(device)    
       .addOnSuccessListener(new OnSuccessListener<String>() {
           @Override        
           public void onSuccess(String deviceSn) {
               // 查询设备SN号成功，处理相关逻辑          
               Log.i(TAG, "getDeviceSn: " + devicesSn);
           }    
       })    
       .addOnFailureListener(new OnFailureListener() {
           @Override        
           public void onFailure(Exception e) {
               // 查询设备SN号异常，处理相关的逻辑        
           }    
       });
   ```

   <br />
