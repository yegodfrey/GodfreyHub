# 华为畅连服务协议

最后更新日期：2020年9月8日

以下条款（以下简称"本协议"）是您与华为订立的关于"畅连服务"的具有法律约束效力的协议。本协议是[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)的补充协议，而[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)则是[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)的补充协议。本协议约定了您在使用"畅连服务"时所享有的法律权利和应尽的法律义务。您通过点击对应本协议的同意按钮，或使用本协议项下的"畅连服务"，即视为自您接受、使用之日（"生效日期"）起对本协议条款、[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)和[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)的充分理解和完全接受。本协议未尽事宜，按照[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)和[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)执行。如果您不同意本协议、[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)或[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)，您应当停止使用各个协议项下的服务。

1 定义

除非本协议另有规定，本协议中的术语与[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)和[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)中的术语含义相同。如无特别说明，下列术语在本协议中的含义为：

1.1 华为"畅连服务"：指华为通过 CaaS Engine 向开发者提供的外置虚拟设备通话等能力。

1.2 华为"CaaS Engine"：华为向开发者提供的通信开放能力和服务相关的API和SDK，包括但不限于虚拟音视频通话、屏幕共享、应用内呼叫和应用内自定义呼叫，具体产品以[CaaS Engine 在网站](https://developer.huawei.com/consumer/cn/caas-kit)上的介绍为准。

2 权利和义务

2.1 您的权利和义务

（1）您同意，为了进行通信华为会通过服务器对开发者产品的音视频流进行传输，但华为不会保存该音视频流。

（2）您承诺您不会攻击或以任何未经授权方式访问"畅连服务"网络及服务器，或以任何方式干扰"畅连服务"网络及服务器，或干扰其他开发者使用"畅连服务"。

（3）"畅连服务"并未在所有国家/地区提供，且华为并不保证您一定可以在某一特定地点使用该服务。开发者产品的分发地域由您自行决定，您应遵守一切适用的法律法规，包括但不限于本地法律，尤其是与数据保护及最终用户的合法权利保障相关的法律。

2.2 华为的权利和义务

（1）您对"畅连服务"的使用应符合华为通过本网站发布的相关使用规范和政策；华为可随时对开发者产品使用本服务的情况予以审查；华为亦有权根据实际运营情况、市场及用户的反馈要求您对开发者产品进行修改、升级。

（2）华为有权自行决定更新"畅连服务"的API 和 SDK。华为不保证未来CaaS Engine 的版本与在以前 CaaS Engine 版本上开发的应用完全兼容。在某些情况下，您可能需要修改或升级您的应用才可正常使用更新以后的API 和 SDK。

（3）如果"畅连服务"需要暂停以进行系统维护或 API、SDK、网站更新，华为将通过邮件提前通知您。

（4）华为保留根据情况随时变更、更新、修改、转让、暂停和终止"畅连服务"的权利，并保留在本服务中开发新模块、新功能或不同语言版本的权利。除非另有说明，否则本协议将同样适用于本服务的任何和所有此类新模块、新功能和不同语言版本。

3 隐私

您承诺，您将根据适用的法律法规以及您和华为签订的协议使用"畅连服务"和处理与"畅连服务"相关的数据。

3.1 用户同意

（1）为了使用"畅连服务"，您必须明确指出可能由于您使用"畅连服务"而收集、接收和/或使用最终用户个人数据的各方。您必须向最终用户披露此类当事方，并将当事方收集的个人数据及其使用目的告知最终用户。您必须获得并记录最终用户的有效同意，例如最终用户签署具有法律约束效力的协议。您必须记录此类同意，并保证最终用户有能力撤销其同意。

（2）如果您不同意前述约定，华为可能会限制或暂停您对"畅连服务"的使用。

3.2 限制

您不得向畅连服务器上传任何可用于识别用户的信息（例如姓名、email 地址、设备识别符或发票等）。

3.3 用户体验提升项目

对您使用"畅连服务"开发的您的开发者产品，华为有权收集开发者产品使用"畅连服务"的相关信息（包括开发者产品的名称、"畅连服务"的名称、版本、接口以及返回结果），用于本服务的持续优化，华为收集的上述信息将在华为的服务器留存两（2）年。未经您的同意，华为不会与任何第三方分享此类信息，除非第三方按照合约代表华为行事。

4 协议终止

4.1 任何一方终止[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)或[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)后，本协议将在同一终止日期自行终止。

4.2 您可通过关闭您所有应用的"畅连服务"使用权限来终止本协议。

4.3 若华为决定不再提供"畅连服务"或者对服务做重大变更，则华为有权提前向您发出通知后终止本协议。

4.4 协议双方签订的[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)和[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)不会随着本协议终止而自动终止。

5 分发区域和签约主体

您承认并同意，本协议项下分发区域和签约主体按照[《华为 APIs 使用协议》](https://developer.huawei.com/consumer/cn/doc/distribution/app/20209)"签约主体"条款执行。

6 法律适用和争议解决

您承认并同意，本协议项下法律适用和争议解决按照[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/20201)"法律适用和争议解决"条款执行。
