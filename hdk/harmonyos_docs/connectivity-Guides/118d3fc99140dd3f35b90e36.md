# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## 什么是NFC？

NFC（Near Field Communication）近场通信由非接触式射频识别（RFID）和互联互通技术整合演变而来。NFC是一种短距高频的无线电技术，在13.56MHz频率运行于20厘米距离内。其传输速度有106 Kbit/秒、212 Kbit/秒或者424 Kbit/秒三种。当前近场通信已通过成为ISO/IEC IS 18092国际标准、EMCA-340标准与ETSI TS 102 190标准。

## OneHop 应用接续的关键能力是什么？

OneHop的实现主要依赖于短距通信技术，OneHop通过NFC实现触发功能，连接，传输和拉起功能则主要依赖于蓝牙和Wi-Fi技术。

## App调用注册接口失败的原因有哪些？

EMUI版本过低，Engine支持的版本为EMUI11.0+

App使用需要添加相应的权限。否则通不过权限校验

```screen
<uses-permission android:name="com.huawei.permission.ONEHOP"/>
```

App未在华为开发者网站申请使用OneHop Engine应用接续能力的权限。

App申请使用OneHop Engine应用接续能力权限未配置完成，未生效

App使用该功能时，未联网。云端鉴权需要应用联网，或者连接过网络，有HMS的缓存。

## App编写代码时，HwOneHopSdk提示错误的原因是什么？

未正确加载OneHop Engine，请按照demo，正确加载jar包。

## 调用其他接口前是不是要先调注册？

是，如果注册不成功，调其他接口会返回失败。

## 测试NFC触碰时，手机启动了多屏协同功能，没有出现业务接续功能是什么情况？

当前App需要在前台播放，而且对于小视频的播放，如果应用未给OneHop传递播放的视频连接及进度，也是无法传递到PAD上续播的。
