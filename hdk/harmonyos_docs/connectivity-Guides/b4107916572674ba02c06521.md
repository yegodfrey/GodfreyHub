# 约束与限制

首先使用DV Engine服务根据使用的DV Engine的不同能力，需要声明虚拟化外设的使用权限以及声明该应用调用DV Engine对应接口需要的权限，例如：相机权限、音频权限以及身体传感器权限等。

应用在使用DV Engine能力的使用，也需要根据使用DV Engine能力的不同，申请不同的Android权限，这些权限需要在应用代码中声明，不同的DV Engine能力对应的Android权限如下：

1. DV Engine虚拟Camera权限，如果使用Camera能力，则必须要申请该权限。

   ```
   android.permission.CAMERA
   ```

2. DV Engine虚拟Mic权限，如果使用Mic的能力，则必须要申请该权限。

   ```
   android.permission.RECORD_AUDIO
   ```

3. DV Engine虚拟Sensor权限，如果使用Sensor的能力，则必须要申请该权限，虚拟Sensor包括body_sensor中心率计以及加速度计、气压计、陀螺仪。

   ```
   android.permission.BODY_SENSORS
   ```

4. DV Engine虚拟Vibrator权限，如果使用Vibrator的能力，则必须要申请该权限。

   ```
   android.permission.VIBRATE
   ```

5. DV Engine虚拟化设备的权限，如果使用分布式虚化设备的权限，需要申请该权限。

   ```
   com.huawei.permission.DISTRIBUTED_VIRTUALDEVICE 
   ```

   该权限需要在DV Engine连接之前获得授权，否则将不能正常使用分布式虚拟化能力，可以通过Android的requestPermissions方法动态申请权限，根据业务放在合适的流程中。

   例如：

   ```
   <uses-permission android:name="android.permission.CAMERA"/>
   <uses-permission android:name="android.permission.RECORD_AUDIO"/>
   <uses-permission android:name="com.huawei.permission.DISTRIBUTED_VIRTUALDEVICE"/>
   ```

   如果需要使用Vibrator和Sensor需要增加的如下的权限：

   ```
   <uses-permission android:name="android.permission.VIBRATE" />
   <uses-permission android:name="android.permission.BODY_SENSORS" />
   ```

   DV Engine开发的基本方法是，首先创建基础DV Engine对象并且连接后端服务进行初始化，通过该对象获取VirtualDeviceManager服务。

   通过VirtualDeviceManager服务可以发现当前手机可以控制的虚拟化设备，并且每个虚拟化设备都带有各自支持的能力，可以根据业务需要进行开发。

   例如当VirtualDeviceManager服务发现大屏设备并返回当前大屏支持Display、Mic、Speaker、Camera能力，应用可以根据需要使能相应的能力。
