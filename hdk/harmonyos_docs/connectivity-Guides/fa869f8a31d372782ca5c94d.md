# 配置混淆脚本

您编译APK前需要配置混淆配置文件，避免混淆Pencil Engine SDK导致功能异常。

1. 打开工程的混淆配置文件"proguard-rules.pro"。
2. 加入排除Pencil Engine SDK的混淆配置。

   <br />

   ```
   -dontwarn  com.huawei.stylus.penengine.**
   -keep class com.huawei.stylus.penengine.** {*;}
   ```

   <br />
