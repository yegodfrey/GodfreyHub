# 业务介绍

#### 业务简介

畅连能力（CaaS Engine）是华为依托畅连业务通信能力，面向应用开发者提供的开放接口，CaaS Engine基于开发者应用自身的联系人（好友）等社交体系，可以帮助开发者快速实现应用内音视频通话服务。  

#### 场景介绍

CaaS Engine服务于音视频通话场景。

典型的场景如下：

互联网App开发者：集成CaaS Engine基于华为设备通信能力快速进行业务及服务的创新开发。  

#### 功能介绍

|功能|描述|
|:-----------|:------------------------------------|
|提供应用内音视频通话能力|应用通过集成CaaS Engine的SDK可以具备视频通话或音频通话能力。|
