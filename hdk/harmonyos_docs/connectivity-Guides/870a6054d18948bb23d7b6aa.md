# 版本更新说明

JAVA语言的SDK仅适用于智能穿戴（Wearable）的应用开发；对于轻量级智能穿戴（Lite Wearable），请[使用JS语言](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/version-change-history-wear-js-0000001133580285)进行应用开发。

#### 5.0.2.306（2022-02-09）

**新增特性** 查询手机系统型号：新增[getPeerDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/peerdeviceclient-0000001192908020#ZH-CN_TOPIC_0000001873951294__getPeerDevice-com_huawei_watch_kit_hiwear_peerdevice_PeerDeviceCallback-)用于查询穿戴设备连接的手机系统类型。

#### 历史版本

#### [h2]5.0.2.302（2021-08-24）

华为运动健康推出了全新的Wear Engine-Wearable-5.0.2.302版本，支持手机侧第三方应用和智能穿戴设备侧第三方应用互发点对点消息和文件。支持手机侧应用通过ping方法拉起智能穿戴设备侧应用。 欢迎广大开发者接入。
