## 添加依赖库

1. 向项目级"build.gradle"文件中配置Maven代码仓。

   ```screen
   buildscript { 
        repositories { 
            google() 
            jcenter() 
            maven {url 'https://developer.huawei.com/repo/'} 
        } 
    } 
    allprojects { 
        repositories { 
            maven {url 'https://developer.huawei.com/repo/'} 
            google() 
            jcenter() 
        } 
    }
   ```

   Gradle 7.0版本后，"allprojects > repositories"配置已迁移到项目级"settings.gradle"文件中。

   "settings.gradle"文件配置示例如下：

   ```screen
   dependencyResolutionManagement {
       ...
       repositories {
           google()
           jcenter() 
           maven {url 'https://developer.huawei.com/repo/'} 
       }
   }
   ```

2. 在工程App目录中的"build.gradle"文件中添加如下依赖。

   ```screen
   dependencies {
       implementation group: 'com.huawei.caaskit: caaskitlite:{caasengine_version}'
   }
   ```

   > 说明
   >
   > {caasengine_version}替换为实际的CaaSEngine版本号，具体版本号请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-version-history-0000001051143052)。例如：
   >
   > implementation group: 'com.huawei.caaskit: caaskitlite:1.0.1.500'

> 说明
>
> 已知项目工程采用gradle 6.0 及以上版本会导致依赖添加失败，可先降低gradle版本，将jar包下载到本地后，将jar放在libs文件夹下依赖，后恢复高版本gradle编译运行。

## 添加appid信息

在您的应用AndroidManifest.xml中添加开发者联盟创建应用时生成的appid信息，name为""com.huawei.hms.client.appid""，value为""appid=******""，******用已注册的appid。

```screen
<meta-data
android:name="com.huawei.hms.client.appid"
android:value="appid=******"/>
```

## 在Android中配置签名

将[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-config-agc-0000001051143066#ZH-CN_TOPIC_0000001050784692__section1022161511414)生成的签名文件复制到您工程的App目录下，并将签名文件的路径配置到storeFile file属性中，"build.gradle"文件配置签名的模板如下：

```screen
android {
    signingConfigs {
        release {
            keyAlias 'xxxxxx'
            keyPassword 'xxxxxx'
            storeFile file('xxx.xxx')
            storePassword 'xxxxxx'
        }
    }
 
    buildTypes {
        release {
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
            signingConfig signingConfigs.release
        }
    }
}
```
