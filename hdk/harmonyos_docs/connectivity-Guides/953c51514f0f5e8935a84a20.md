# 获取Wear Engine的API level

Wear Engine的每个接口都有对应的API level，比如：0、2。其中SDK客户端各个接口的API level可以查看[API参考文档](https://developer.huawei.com/consumer/cn/doc/connectivity-References/overview-0000001051473926)。

Wear Engine服务端和客户端作为两个独立的整体也有对应的API level，是其支持的所有接口的最高API level，比如：客户端有40个接口，这些接口的API level有0、2两个值，则客户端作为一个整体其API level为2。

若服务端的API level比客户端低，则表示客户端的部分接口，服务端不支持，此时开发者可以建议用户升级运动健康App版本。若客户端的API level比服务端低或两者相同，则表示客户端的功能，服务端均支持。

## 获取Wear Engine SDK客户端的API level

当开发者需要获取客户端的API level时，可以调用[getClientApiLevel](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904#ZH-CN_TOPIC_0000001874111230__getClientApiLevel--)获取。

1. 参见上一节[监测应用与Wear Engine服务的连接状态](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/monitoring-wearengine-service-0000001052828059#section10962817102613)章节，获取[WearEngineClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904)对象。
2. 调用[getClientApiLevel](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904#ZH-CN_TOPIC_0000001874111230__getClientApiLevel--)方法，获取客户端的API level。

   示例代码

   ```screen
   // 步骤2：调用getClientApiLevel方法，获取客户端API level
   wearEngineClient.getClientApiLevel()
       .addOnSuccessListener(new OnSuccessListener<Integer>() {
           @Override
           public void onSuccess(Integer integer) {
               // 接口调用成功，integer返回客户端API level
               Log.i(TAG,"sdk apiLevel: " + integer.intValue());
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 接口调用失败 
               Log.e(TAG,"sdk apiLevel e: " + e.getMessage());
           }
       });
   ```

## 获取Wear Engine服务端的API level

当开发者需要获取服务端的API level时，可以调用[getServiceApiLevel](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904#ZH-CN_TOPIC_0000001874111230__getServiceApiLevel--)获取。

1. 参见上一节[监测应用与Wear Engine服务的连接状态](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/monitoring-wearengine-service-0000001052828059#section10962817102613)章节，获取[WearEngineClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904)对象。
2. 调用[getServiceApiLevel](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904#ZH-CN_TOPIC_0000001874111230__getServiceApiLevel--)方法，获取服务端的API level。

   示例代码

   ```screen
   // 步骤2：调用getServiceApiLevel方法，获取服务端API level
   wearEngineClient.getServiceApiLevel()
       .addOnSuccessListener(new OnSuccessListener<Integer>() {
           @Override
           public void onSuccess(Integer integer) {
               // 接口调用成功，integer返回服务端API level
               Log.i(TAG,"service apiLevel: " + integer.intValue());
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 调用接口失败
               Log.e(TAG,"service apiLevel e: " + e.getMessage());
           }
       });
   ```
