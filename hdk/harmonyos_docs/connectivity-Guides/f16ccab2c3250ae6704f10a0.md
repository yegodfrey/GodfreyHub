# 获取手机系统信息

穿戴侧应用可以通过[getPeerDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/phone-system-0000001237277153#section9463195104019)方法获取手机系统信息。

1. 创建PeerDeviceClient对象。
2. 调用[getPeerDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/phone-system-0000001237277153#section9463195104019)方法，获取手机系统信息。当前仅支持获取手机系统类型，其中1为Andriod系统或HarmonyOS 5.0之前版本（如HarmonyOS 2.x/3.x/4.x）系统，2为IOS系统，3为HarmonyOS 5.0及以上版本系统。

   ```screen
   // 步骤1：创建peerDeviceClient对象
   var peerDeviceClient = new PeerDeviceClient();

   // 步骤2：获取手机系统信息
   var flash = this;
   peerDeviceClient.getPeerDevice({
       onSuccess:function(data){
           // 获取手机系统类型
           console.log("phone os type " + data.peerDevice.mOsType);
           flash.receiveMessageOK = "getPeerDevice success:" + JSON.stringify(data);
       },
       onFailure: function (data) {
           flash.receiveMessageOK = "getPeerDevice fail：" + JSON.stringify(data);
       },
   });
   ```
