# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[Codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/CaaSKitLite-VirtualCamera)快速体验CaaS Engine 的开发过程。

## 开发环境

* 安装Android Studio 3.X及以上

* JDK 1.8.211及以上
* 您的应用应满足以下条件：

  * minSdkVersion 26
  * targetSdkVersion 28
  * compileSdkVersion 28
  * Gradle 4.6及以上

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：EMUI10.0及以上且支持畅连通话的系统版本，目前支持的芯片平台有Kirin980、Kirin990。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-config-agc-0000001051143066)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-config-agc-0000001051143066#ZH-CN_TOPIC_0000001050784692__sa913a899ca504de89b02419e1eec5673)。|
|2|[申请权限](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-preparations-pre-0000001052367034)|以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)方式申请虚拟音视频通话能力权限。|
|3|[添加权限](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-as-integration-0000001051145284#ZH-CN_TOPIC_0000001051145284__section189605451214)|虚拟音视频通话能力需在"AndroidManifest.xml"文件中添加权限。|
|4|[客户端开发](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-instructions-0000001087036468)|您可根据业务需求，完成虚拟音视频通话功能的开发。|
|5|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/pre-release-check-0000001050825997)|华为提供对应用自动检查的能力。|
|6|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/app-release-0000001050785970)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|
