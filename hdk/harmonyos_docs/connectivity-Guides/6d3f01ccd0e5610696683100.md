# 申请权限

## 申请接口使用权

基于安全考虑，服务侧对DeviceVirtualization Engine开放的接口做了权限保护处理，使用相关接口需要向华为方申请对应权限。权限申请需提供开发者联盟网站创建应用时生成的appid，且指纹信息已配置。权限申请请联系[devConnect@huawei.com](mailto:devConnect@huawei.com)，主题标明DeviceVirtualization Engine权限申请。

DV Engine对外提供接口做了权限保护，权限有两类，分别是向华为方申请的权限以及向应用申请的本地权限。

应用向华为申请的权限，这些权限不需要在代码中声明，不过在使用DV Engine的时候需要根据不同的能力（Capability类中定义了DV Engine给应用的能力）进行对应权限申请，不同的能力对应的权限如下：

* DV Engine基础权限，该权限是接入DV Engine的基础权限，使用DV Engine必须要申请。

  ```screen
  com.huawei.dv.permission.BASE
  ```

* DV Engine虚拟Camera权限，如果使用Camera能力，则必须要申请该权限。

  ```screen
  com.huawei.dv.permission.VIRTUALCAMERA
  ```

* DV Engine虚拟Mic权限，如果使用Mic的能力，则必须要申请该权限。

  ```screen
  com.huawei.dv.permission.VIRTUALMIC
  ```

* DV Engine虚拟Speaker权限，如果使用Speaker的能力，则必须要申请该权限。

  ```screen
  com.huawei.dv.permission.VIRTUALSPEAKER
  ```

* DV Engine虚拟Display权限，如果使用Display的能力，则必须要申请该权限。

  ```screen
  com.huawei.dv.permission.VIRTUALDISPLAY
  ```

* DV Engine虚拟Sensor权限，如果使用Sensor的能力，则必须要申请该权限，虚拟Sensor包括body_sensor中心率曲线以及加速度、陀螺仪等，当前只支持心率曲线。

  ```screen
  com.huawei.dv.permission.VIRTUALSENSOR
  ```

* DV Engine虚拟Vibrator权限组，如果使用Vibrator的能力，则必须要申请该权限。

  ```screen
  com.huawei.dv.permission.VIRTUALVIBRATOR
  ```

* DV Engine虚拟Notification权限组，如果使用Notification的能力，则必须要申请该权限。

  ```screen
  com.huawei.dv.permission.NOTIFICATION
  ```

> 说明
>
> com.huawei.dv.permission.BASE权限组是应用必须申请的权限组，定义了DV Engine的基础接口功能。如果应用需要使用虚拟Camera、虚拟Sensor以及虚拟Vibrator还需要申请对应的特定权限。
