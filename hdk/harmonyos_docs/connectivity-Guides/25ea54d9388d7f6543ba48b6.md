# 在Android Studio项目中集成Cast Engine SDK

## 创建Android Studio工程

1. 新建或者打开已有的Android Studio项目。
2. 选择"Phone and Tablet" ，选择Empty Activity，点击"Next "。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/B7JNybTjQ9-SIN_vaebwRA/zh-cn_image_0000001052244704.png?HW-CC-KV=V1&HW-CC-Date=20260909T142001Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC6D078112C3D572BE44D5BFD3BCDCAF2FC5FABF86CA208332F17DBA9E322DB7 "点击放大")

3. 填写项目名称（Name）、包名（Package name），选择"Minimum SDK"为"API 23：Android 6.0"，点击"Finish"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/6QwLcvuLSx-c1jhV9YYy7Q/zh-cn_image_0000001052884718.png?HW-CC-KV=V1&HW-CC-Date=20260909T142001Z&HW-CC-Expire=31536000000&HW-CC-Sign=DBDD4D99994C1F616593118E301E49990171BBEE02E68EC0142A945D80C4065A "点击放大")

## 添加编译依赖

1. 将下载好的SDK包（aar后缀名文件）放到三方App自身工程的libs文件夹下。
2. 打开应用级的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/O3JdPytlTgyReIII1IYAaw/zh-cn_image_0000001071372127.png?HW-CC-KV=V1&HW-CC-Date=20260909T142001Z&HW-CC-Expire=31536000000&HW-CC-Sign=530E703DE380FC9698885492F90767128DA15D1247FE4A3CDAE6625A59AAF97A)

3. 在"dependencies"中添加如下编译依赖。

   ```screen
     implementation fileTree(dir: 'libs', include: '*.aar') 
   ```

   > 说明
   >
   > 请将**.aar*替换为Cast Engine SDK包名称。如：implementation fileTree(dir: 'libs', include: 'hisightkit-release.aar') 。

## 同步工程

在完成以上的配置后，点击工具栏中的gradle同步图标，完成"build.gradle"文件的同步，将相关依赖下载到本地。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/uJz9kU_6Tom897UoJjRvNQ/zh-cn_image_0000001050057091.png?HW-CC-KV=V1&HW-CC-Date=20260909T142001Z&HW-CC-Expire=31536000000&HW-CC-Sign=2CC4AF5823CE8C9EC800B6FE3B40C1CB7CAE47CD1DF1D6D52564D7BD5C9A0750) 说明
>
> 如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
