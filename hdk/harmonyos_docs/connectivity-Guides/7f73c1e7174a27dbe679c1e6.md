# 业务介绍

## 业务简介

畅连能力（CaaS Engine）是华为依托畅连业务通信能力，面向应用开发者和硬件开发者提供的开放接口，帮助开发者实现应用内实时共享的能力，助力用户即刻分享应用内允许共享的内容。

## 场景介绍

CaaS Engine服务于界面共享场景，助力用户即刻分享应用内允许共享的内容。

典型的场景如下：

互联网App开发者：集成CaaS Engine基于华为设备通信能力快速进行业务及服务的创新开发。

## 功能介绍

|功能|描述|
|:-----|:--------------------|
|实现屏幕共享|用户可将当前应用界面向联系人好友实时共享。|
