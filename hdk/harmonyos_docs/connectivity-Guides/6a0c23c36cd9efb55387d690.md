#### 配置HMS Core SDK的Maven仓地址

1. 打开Android Studio项目级"build.gradle"文件。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221017155810.53316827184522800054884231632072:50531024064228:2800:DE0C681B8D35258943383EB6E5212EC4C83B1A95C41F1CDD5B2B5B55E7657BD9.png?needInitFileName=true?needInitFileName=true)
2. 添加Maven代码库。
   * 在"allprojects \> repositories"中配置HMS Core SDK的Maven仓地址。

     ```
     buildscript { 
          repositories { 
              google() 
              jcenter() 
              maven {url 'https://developer.huawei.com/repo/'} 
          } 
      } 
      allprojects { 
          repositories { 
              maven {url 'https://developer.huawei.com/repo/'} 
              google() 
              jcenter() 
          } 
      }
     ```

     Gradle 7.0版本后，"allprojects \> repositories"配置已迁移到项目级"settings.gradle"文件中。

     "settings.gradle"文件配置示例如下：

     ```
     dependencyResolutionManagement {
         ...
         repositories {
             google()
             jcenter() 
             maven {url 'https://developer.huawei.com/repo/'} 
         }
     }
     ```

     ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221017155810.99278712893857445053699840464741:50531024064228:2800:E78F4B57602E49779F2B1EF3A004C34E0F3BF444A071E1B86E8CB45A453A65A7.png?needInitFileName=true?needInitFileName=true)  
Maven仓地址无法直接在浏览器中打开访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后  

#### 添加编译依赖

1. 打开应用级的"build.gradle"文件。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221017155810.70389185927589775828724348916990:50531024064228:2800:AB2A610631A91A390371AE62FA8D0CAB97BA203AB4191A975A2D08FA81D6C588.png?needInitFileName=true?needInitFileName=true)
2. 在"dependencies"中添加如下编译依赖。

   ```
   dependencies {
       implementation 'com.huawei.caasengine:caasengine-message:{caasengine-message_version}'
   }
   ```

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221017155811.90264508758895112847495206530412:50531024064228:2800:39226E0C3FFAFCC61629822637789EEF8012A024998545FE044270CE72A22568.png?needInitFileName=true?needInitFileName=true)  
   {caasengine-message_version}替换为实际的CaaSEngine-Message版本号，具体版本号请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/meetime-share-version-change-history-0000001059671347)。例如：

implementation 'com.huawei.caasengine:caasengine-message:1.0.0.300'

#### 添加appid信息

在您的应用AndroidManifest.xml中添加开发者联盟创建应用时生成的appid信息，name为""com.huawei.hms.client.appid""，value为""appid=\*\*\*\*\*\*""，\*\*\*\*\*\*用已注册的appid。

```
<meta-data
android:name="com.huawei.hms.client.appid"
android:value="appid=******"/>
```

#### 添加服务权限

添加服务权限信息。

```
<uses-permission android:name="com.huawei.meetime.CAAS_SHARE_SERVICE"/>
```

#### 在Android中配置签名

将[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/connectivity-Guides/virtualized-devices-calling-config-agc-0000001051143066#ZH-CN_TOPIC_0000001050784692__section1022161511414)生成的签名文件复制到您工程的App目录下，并将签名文件的路径配置到storeFile file属性中，"build.gradle"文件配置签名的模板如下：

```
android {
    signingConfigs {
        release {
            keyAlias 'xxxxxx'
            keyPassword 'xxxxxx'
            storeFile file('xxx.xxx')
            storePassword 'xxxxxx'
        }
    }
 
    buildTypes {
        release {
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
            signingConfig signingConfigs.release
        }
    }
}
```
