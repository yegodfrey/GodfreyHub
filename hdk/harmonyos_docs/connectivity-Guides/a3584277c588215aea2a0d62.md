# 业务介绍

#### 业务简介

CaaS Engine-Message是CaaS Engine的子能力，依托畅连业务通信能力，面向应用开发者提供的开放接口，可以帮助开发者更加简单的集成畅连分享服务，提升用户应用分享体验。  

#### 场景介绍

CaaS Engine-Message服务于消息分享场景，助力用户即刻分享应用内的页面内容与信息。

典型的场景如下：

互联网App开发者：集成CaaS Engine-Message基于华为设备通信能力快速进行业务及服务的创新开发。

畅连分享提供5种卡片形式，购物类、音乐类、新闻类、短视频和长视频卡片。

#### 功能介绍

|功能|描述|
|:-------|:-------------------------------------------|
|提供内容分享能力|应用通过集成CaaS Engine-Message的SDK可以具备应用内容信息分享能力。|
|实现应用快捷操作|用户可以通过分享内容，将应用卡片化、浮窗化、直接拉起。|
