# 开发后自检

## 网络环境准备

大屏端与手机端连接同一Wi-Fi，大屏端可有线或无线。

## 大屏端环境准备

大屏端已安装集成该投屏功能的APK，并已对投屏服务进行后台保活，避免由于服务被停止导致Cast Engine投屏功能无法正常使用。

## 移动端环境准备

EMUI 10.1及以上版本手机，联系接口邮箱获取：[castpluskit@huawei.com](mailto:castpluskit@huawei.com)。

## 操作方法

1. 大屏端打开应用，打开"无线投屏"开关。
2. 手机端通过下拉栏，点击"无线投屏"，开始扫描周边可投屏设备。
3. 手机端点击有Huawei Cast+图标标识的目标设备，尝试连接。
4. PIN码模式下，手机端正确输入大屏端展示的PIN码；密码模式下，手机端正确输入大屏端设置的密码。
5. 鉴权成功，投屏开始，手机端画面投屏到大屏界面。

## 结果验证

大屏端界面实时展示手机端画面，音画同步，投屏界面低时延、高清晰。
