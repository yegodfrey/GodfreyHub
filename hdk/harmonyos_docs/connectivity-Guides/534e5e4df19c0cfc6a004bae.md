# 场景介绍

## 手机-穿戴设备分布式协同

* 重要通知实现腕上提醒，零距离触达，如：在手机侧App中设置日程提醒、用药提醒、任务提醒等数据，可以同步到穿戴设备侧App中，不用打开手机，也可以随时在穿戴设备上查看重要信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0e/v3/Hw6QTwjiT3iBkHOrJhJlWA/zh-cn_image_0000001920110317.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=3123E968C4CAFF28E0C42AEBE5A6E6EBC5A9E1FE43A434AC51482459773E8990 "点击放大")

* 为手机应用带来全新的"腕上交互"，如：用手机侧App看视频、听音频时，可以通过穿戴设备侧App操控手机侧App，比如暂停，下一首，停止等。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/tHpVHLLbTYazakD5I547xw/zh-cn_image_0000001919950653.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=31507A6F1AD1BA93EF79089E4C14A552BD9F54A75CF397CCA8572E80526483F3 "点击放大")

* 手机侧和穿戴侧的实时协同体验。如：在手机侧App开启导航，可以通过穿戴设备侧App提示用户左转、直行、右转等。在走路或骑行时，不用每次拿出手机查看路线。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/NJQ_rqqWQfuvGy1aOOvTMA/zh-cn_image_0000001920110325.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=A89B451E84E3334625C261DEF419CE4BBB62032C8378EBD84F28C839CFA70AF2 "点击放大")

## 手机-穿戴设备虚拟化

开发者在手机侧App集成Wear Engine SDK，而不需要在穿戴设备侧开发App。

* 穿戴设备状态实时掌握，如：手机侧App实时获取穿戴设备侧连接状态、佩戴状态、电量状态等，给用户提供更多增值服务。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/47/v3/BrMFMj7GScauPgViLReDIg/zh-cn_image_0000001919950649.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=D9F4C6083CFB03653BE108BFB30AE451F5E389FC0AE73BEBA1BD7934BCACC03D "点击放大")

* 穿戴设备传感器和I/O虚拟化：手机侧App读取穿戴设备的传感器数据（如ECG、PPG、ACC数据等），调用穿戴设备的I/O能力（比如振动手表的马达，点亮手表屏幕）来将手机侧App的能力延伸到穿戴设备，提升用户体验。 说明
  > * 传感器受限发布，仅限专业研究机构使用。
  > * 穿戴设备的I/O能力在后续版本中支持。
