# 场景介绍

#### 手机-穿戴设备分布式协同

* 重要通知实现腕上提醒，零距离触达，如：在手机侧App中设置日程提醒、用药提醒、任务提醒等数据，可以同步到穿戴设备侧App中，不用打开手机，也可以随时在穿戴设备上查看重要信息。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241210153031.36248062942835372440873968363934:50001231000000:2800:372CE3970A6361C59F31E9C586A6C05F36B705CE80C9C53A0316C6C4AC68C4CD.png?needInitFileName=true?needInitFileName=true "点击放大")

* 为手机应用带来全新的"腕上交互"，如：用手机侧App看视频、听音频时，可以通过穿戴设备侧App操控手机侧App，比如暂停，下一首，停止等。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241210153031.89057367599137072048950774672520:50001231000000:2800:97D62CB8E5BCF8EF288C883414F4A3D914C34B47A6285B38CDFF2F102B328B3A.png?needInitFileName=true?needInitFileName=true "点击放大")

* 手机侧和穿戴侧的实时协同体验。如：在手机侧App开启导航，可以通过穿戴设备侧App提示用户左转、直行、右转等。在走路或骑行时，不用每次拿出手机查看路线。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241210153031.72648024090372650534016008062789:50001231000000:2800:D3AB7A513ACC4FD44EEEBD5A5F092E74009B12D5BD05A2F39282AF2B8B0BFD80.png?needInitFileName=true?needInitFileName=true "点击放大")

#### 手机-穿戴设备虚拟化

开发者在手机侧App集成Wear Engine SDK，而不需要在穿戴设备侧开发App。

* 穿戴设备状态实时掌握，如：手机侧App实时获取穿戴设备侧连接状态、佩戴状态、电量状态等，给用户提供更多增值服务。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241210153031.78671324079293051065006153628575:50001231000000:2800:B594EA646D1AF2C603AEB9C1A2FC9C2F781682B07158F8DF134CB494F3A38384.png?needInitFileName=true?needInitFileName=true "点击放大")

* 穿戴设备传感器和I/O虚拟化：手机侧App读取穿戴设备的传感器数据（如ECG、PPG、ACC数据等），调用穿戴设备的I/O能力（比如振动手表的马达，点亮手表屏幕）来将手机侧App的能力延伸到穿戴设备，提升用户体验。  
  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241210153032.24317496547864506569684421918962:50001231000000:2800:89F0AD4FF94D14121BCF12BD50B44CF794303D0849CF91E1295CC561F5DF39BD.png?needInitFileName=true?needInitFileName=true)  
  * 传感器受限发布，仅限专业研究机构使用。
* 穿戴设备的I/O能力在后续版本中支持。
