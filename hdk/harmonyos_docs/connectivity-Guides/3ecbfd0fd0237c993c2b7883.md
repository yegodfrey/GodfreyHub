# SDK安全数据说明

#### SDK工作方式

CaaS Engine的SDK需要在应用打包时，被加载在您的应用当中。SDK会由开发者调用相应接口，开启或者关闭服务，不会在后台做任何额外动作。  

#### SDK权限说明

SDK运行时会调用CaaS服务权限。

```
<uses-permission android:name="com.huawei.hwcaasservice.THIRDPARTY_BIND_HWCAAS_SERVICE" />
```

#### SDK收集数据

不涉及。  

#### SDK数据安全保护

不涉及
