# 管理应用与Wear Engine服务的连接状态

## 监测应用与Wear Engine服务的连接状态

华为运动健康App在后台停止服务（如功耗过高），从而导致应用与Wear Engine服务的连接状态发生变化。对于类似这种不确定的断开情况，开发者可以通过本功能特性了解当前应用和Wear Engine的连接状态。前提是在设备断开前，开发者已经使用该功能进行过监测。

1. 定义连接状态监测接口对象。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getWearEngineClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getWearEngineClient-android_app_Activity-com_huawei_wearengine_client_ServiceConnectionListener-)方法，获取[WearEngineClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904)对象。
3. 调用[registerServiceConnectionListener](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904#ZH-CN_TOPIC_0000001874111230__registerServiceConnectionListener--)方法，监测应用与Wear Engine服务的连接状态。

   ```screen
   // 步骤1：定义连接状态监测接口对象
   ServiceConnectionListener serviceConnectionListener = new ServiceConnectionListener() {
       @Override
       public void onServiceConnect() {
           // 处理与Wear Engine服务连接成功事件
       }

       @Override
       public void onServiceDisconnect() {
           // 处理与Wear Engine服务断开连接事件
       }
   };

   // 步骤2：获取WearEngineClient对象
   wearEngineClient = HiWear.getWearEngineClient(this, serviceConnectionListener);

   // 步骤3：调用registerServiceConnectionListener方法，监测与Wear Engine服务的连接状态
   wearEngineClient.registerServiceConnectionListener()
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               // 接口调用成功
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 接口调用失败
           }
       });
   ```


4. 调用[unregisterServiceConnectionListener](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904#ZH-CN_TOPIC_0000001874111230__unregisterServiceConnectionListener--)方法，取消监测应用与Wear Engine服务的连接状态。

   ```screen
   // 步骤4：调用unregisterServiceConnectionListener方法，取消监测与Wear Engine服务的连接状态
   wearEngineClient.unregisterServiceConnectionListener()
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               // 接口调用成功
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 接口调用失败
           }
       });
   ```

## 断开应用与Wear Engine服务的连接

断开后，将释放Wear Engine资源，监测设备状态、收消息、收文件等功能不可用。如需重新连接，主动调用任意接口即可。

1. 参见上一节[监测应用与Wear Engine服务的连接状态](#section10962817102613)章节，获取[WearEngineClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904)对象。
2. 调用[releaseConnection](https://developer.huawei.com/consumer/cn/doc/connectivity-References/wearengineclient-0000001060620904#ZH-CN_TOPIC_0000001874111230__releaseConnection--)方法，断开应用与Wear Engine服务的连接。

   ```screen
   // 步骤2：调用releaseConnection方法，断开应用与Wear Engine服务的连接
   wearEngineClient.releaseConnection()
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               // 接口调用成功
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 接口调用失败
           }
       });
   ```
