## 开发步骤

1. 查询当前运行环境是否支持一笔成形。

   使用一笔成形能力所属的起始SDK API LEVEL作为判断依据，查询时需传入API_LEVEL_2作为判断依据。

   ```screen
   if (!HwPenEngineManager.isSupportFeature(context, https://developer.huawei.com/consumer/cn/doc/connectivity-References/constant-values-0000001120799864#section5245355815.API_LEVEL_2))) {
       Log.w(TAG, "feature not supported");
       return;
   }
   ```

2. 实例化一笔成形功能类。

   在初始化阶段进行实例化，后续功能均依赖该实例化对象

   ```screen
   InstantShapeGenerator mInstantShapeGenerator= new InstantShapeGenerator (context);
   ```

3. （可选）设置触发一笔成形功能图形识别的停顿时间。

   初始化阶段进行设置，单位：ms。若不设置则默认为300ms；若设置的值小于0或大于5000，则使用默认值。

   ```screen
   /** 设置停顿时间为400ms **/
   mInstantShapeGenerator.setStopTime(400);
   ```

4. 传入当前绘制控件的宽高。

   在onSizeChanged（控件大小发生变化时）中，将新的控件的宽度和高度传入引擎，用于点位的归一化处理。

   ```screen
   @Override  
   public void onSizeChanged(int width, int height, int oldwidth, int oldheight) {
       super.onSizeChanged(width, height, oldwidth, oldheight);
       if (mInstantShapeGenerator != null) {
           mInstantShapeGenerator.notifyViewSizeChange(width, height);
       }
   } 
   ```

5. 传入触摸事件。

   ```screen
   @Override  
   public boolean onTouchEvent(MotionEvent event) {
       if (mInstantShapeGenerator != null) {
           mInstantShapeGenerator.processTouchEvent(event);
       }
    
       /** 其他应用自定义行为 **/
       ...
       return true;
   }
   ```

6. 获取Path形式的图形识别结果。

   在触发了一笔成形的识别能力后，可以自行选择在ACTION_MOVE的事件处理中直接获取，或者在onDraw的时候获取。

   ```screen
   private Path mFormedShapePath = new Path();
   ...
   @Override  
   public void onDraw(Canvas canvas) {
       /** 绘制原始笔迹 **/
       mPaint.setColor(Color.BLACK);
       canvas.drawPath(mOriginalPath, mPaint);
       /** 绘制规整图形 **/
       mPaint.setColor(Color.RED);
       if (mInstantShapeGenerator != null) {
           mFormedShapePath = mInstantShapeGenerator.getPath();
       }
       canvas.drawPath(mFormedShapePath, mPaint);
   }
   ```

7. （可选）获取String形式的图形识别结果。

   在需要将图形识别结果进行保存的场景，在触发了一笔成形的识别能力后，可以通过获取图形识别结果的String信息，将String信息进行保存。可以在一笔结束ACTION_UP的时候进行获取。

   ```screen
   private List<String> mFormedShapeResults = new ArrayList<>();
   ...
   @Override  
   public boolean onTouchEvent(MotionEvent event) {
       if (mInstantShapeGenerator != null) {
           mInstantShapeGenerator.processTouchEvent(event);
       }
    
       switch (event.getAction()) {
           case MotionEvent.ACTION_DOWN:
             /** 其他应用自定义行为 **/
           case MotionEvent.ACTION_MOVE:
             /** 其他应用自定义行为 **/
           case MotionEvent.ACTION_UP:
               if (mInstantShapeGenerator == null) {
                   break;
               }
               String strResult = mInstantShapeGenerator.getStringResult();
               if (strResult != null && strResult.length() > 0) {
                   /** 将结果保存至String List **/
                   mFormedShapeResults.add(strResult);
               }
               break;
       }
    
       /** 其他应用自定义行为 **/
       ...
       return true;
   }
   ```

8. （可选）通过图形识别结果的String信息还原图形Path信息。

   在图形识别结果的String信息被保存后，可以在需要加载的时候将保存的String信息恢复为Path信息以便绘制。

   ```screen
   private Path mOrigninalPath = new Path();
   private Path mFormedShapePath = new Path();
   ...
   @Override  
   public void onDraw(Canvas canvas) {
       /** 绘制原始笔迹 **/
       mPaint.setColor(Color.BLACK);
       canvas.drawPath(mOriginalPath, mPaint);
       /** 绘制规整图形 **/
       mPaint.setColor(Color.RED);
       if (mInstantShapeGenerator != null) {
           mFormedShapePath = mInstantShapeGenerator.getPath();
       }
       canvas.drawPath(mFormedShapePath, mPaint);
    
       if (mInstantShapeGenerator == null) {
           return;
       }
       /** 将保存的关键信息恢复成可绘制的path **/
       mPaint.setColor(Color.GREEN);
       for (String shape : mFormedShapeResults) {
           canvas.drawPath(mInstantShapeGenerator.getPathFromString(shape, mPaint.getStrokeWidth()), mPaint);
       }
   }
   ```

9. 销毁一笔成形功能类对象。

   在不需再进行一笔成形功能时（退出应用、onDetachedFromWindow等），需进行资源释放。

   ```screen
   @Override  
   public void onDetachedFromWindow() {
           if (mInstantShapeGenerator != null) {
               mInstantShapeGenerator.destroy();
               mInstantShapeGenerator = null;
           }
           super.onDetachedFromWindow();
   }
   ```

## 调测验证

在实现的一笔成形能力的应用中，在绘制一笔结束时，手写笔/手指不离开屏幕并保持不动停顿一定时间（具体时间由自行设置，默认为300ms）后，可以获取到图形识别结果，并按需绘制出来。
