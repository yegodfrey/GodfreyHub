# 申请Wear Engine服务

申请Wear Engine服务前，请先完成[注册账号及申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-ios-0000001893544118)。

1. 点击"应用服务"页签下的"Wear Engine"卡片。

   <br />

   图1 "Wear Engine"卡片

   ![](https://media:301772615885388655 "点击放大")

   <br />

   <br />

2. 点击"申请Wear Engine服务"，同意协议后，进入权限申请页面。

   <br />

   图2 申请Wear Engine服务

   ![](https://media:301772615885429656 "点击放大")

   <br />

   <br />

3. 点击"iOS应用"并选择产品后，勾选必需申请的权限（个人开发者只可申请设备基础信息、消息通知两个基本的权限）。填写应用回调scheme地址，该地址必须定义在第三方app中。第三方app进行用户授权时，页面从第三方app跳转到华为运动健康app。授权完成后，页面从华为运动健康app跳转回第三方app。这里定义的应用回调scheme地址，用于华为运动健康app跳转回第三方app。

   <br />

   ![](https://media:301772615885452657)  
   请选择手机侧应用，穿戴设备侧应用默认不需要申请权限。  
   图3 填写应用信息

   ![](https://media:301772615885495658)  

   |权限|开放能力||用途|
   |:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------|-----------|:------------------------------------|
   |设备基础信息 [DEVICE_MANAGER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__DEVICE_MANAGER)|穿戴设备状态管理|穿戴设备基础信息查询|获取已配对穿戴设备列表并选定设备；支持查询穿戴设备可用空间。|
   |设备基础信息 [DEVICE_MANAGER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__DEVICE_MANAGER)|穿戴设备状态管理|查询或订阅穿戴设备状态|支持查询或订阅穿戴设备连接状态、可用空间、充电状态、电量状态、低电量告警。|
   |设备基础信息 [DEVICE_MANAGER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__DEVICE_MANAGER)|通信能力管理|发送点对点消息|手机侧"xxx(应用名)"向穿戴设备侧"xxx(应用名)"发送消息。|
   |设备基础信息 [DEVICE_MANAGER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__DEVICE_MANAGER)|通信能力管理|接收点对点消息|手机侧"xxx(应用名)"接收穿戴设备侧"xxx(应用名)"消息。|
   [表1 权限说明]

   <br />

4. 上传申请数据权限及使用说明、用户授权路径说明，选择授权入口是否展示华为品牌LOGO后提交。

   <br />

   * 申请数据权限及使用说明填写要求：
     * 权限说明：提供申请的数据权限，每个权限一行。
     * 数据使用说明：提供使用数据权限的需求、场景、目的和方式等。
     * 数据展示路径：提供所申请权限的使用场景的界面截图。可选。
   * 用户授权路径说明填写要求：
     * 提供获取用户授权的界面截图及界面操作路径的文字描述。
     * 如果应用内提供了修改授权的功能，请提供修改授权的界面截图及界面操作路径的文字描述。可选。

   ![](https://media:301772615885520659)  
   * 数据使用说明：[申请数据权限及使用说明（范例）个人开发者.xlsx](https://hihealthbase-drcn.things.hicloud.com/healthkit/fileServer/getFile/plain/usageDescForIndividual/000/001/044/1000000000000001044.20251209032349.74589818940681309738674024154756:20751127032356:100005355:24B697F375223CCF34910C9D8DA18079134D1018EC6FEE201016FFC73DCE3CFA.xlsx)、[申请数据权限及使用说明（范例）企业开发者.xlsx](https://hihealthbase-drcn.things.hicloud.com/healthkit/fileServer/getFile/plain/usageDescForEnterprise/000/001/044/1000000000000001044.20251209032231.78198893037413673087257560319146:20751127032255:100005355:C2F902BA7C9CF53088CDFDA5B72F4CCE2B34C11FB8BC48637D97244075BF17B9.xlsx)。
   * 用户授权路径说明：[用户授权路径说明（范例）](https://hihealthbase-drcn.things.hicloud.com/healthkit/fileServer/getFile/plain/authDisplayDesc/000/001/062/1000000000000001062.20260228015622.62864815611324569060780795144875:20760216015648:100005355:4D88BD3183D7B4DE07ACDD94FFFD8BD10BD271850BFB585F1215324979201B64.xlsx)。

   <br />

5. 等待申请通过。

   <br />

   权限审批一般需要1到2周。取决于申请的权限类型和应用发布地区，我们将视应用发布地区的相关要求进行权限开放的评估。

   如果提交的材料不满足要求，审批将不能通过。如果审批通过，即可进入开发测试阶段，完成开发测试后即可发布。

   若您的业务范围发生变动，需要修改相应的数据权限，您可以点击"修改"重新提交申请。  
   图4 权限审批通过

   ![](https://media:301772615885557660)

   <br />

   <br />

6. 审批通过后，系统会为应用生成Scheme Secret。"APP ID"、"应用scheme地址"和"Scheme Secret"将在[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)时被使用。

   <br />

   图5 应用审批通过

   ![](https://media:301772615885601661)

   <br />
