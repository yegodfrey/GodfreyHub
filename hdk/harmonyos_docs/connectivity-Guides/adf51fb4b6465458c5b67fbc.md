# 请求用户授权

为保护用户隐私，Wear Engine的API需要用户授权才可以正常访问。建议开发者在用户首次调用Wear Engine开放能力的时候执行本章节操作。  

#### 校验用户授权结果

调用[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)或[应用间消息通信](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-ios-0000001875158886)的任一API，如果当前状态为未获取授权，则返回错误码WESErrorCodeUserUnauthorizedWearEngine(9)。如果已取得授权，则正常返回接口的结果。  

#### 申请用户穿戴设备权限

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getAuthClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section612419344112)方法，获取[WESAuthClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesauthclient-0000001897479350)对象。
2. 调用[authWithClientId](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesauthclient-class-0000001897943254#section12194195011300)方法，跳转到运动健康APP并拉起授权页进行授权。
3. 执行成功后，会弹出授权界面，让用户选择授予权限。

   <br />

   * 方式一：通过scheme跳转运动健康app授权。

     ```
     HiWear.getAuthClient().auth(withClientId:"xxx",  // 华为开发者联盟client id
                                 scheme:"test://healthkitdemo/comeback",  // 用于授权后从华为运动健康app跳回第三方app
                                 schemeSecret:"xxx", // 华为开发者联盟应用schemeSecret
                                 clientSecret:"xxx",  // 华为开发者联盟的clientSecret
                                 srcPkgName:"xx.xx.xx",  // iOS手机侧第三方app的包名
                                 destPkgName:"xx.xx.xx"  // 穿戴设备侧第三方app的包名 
                                 ) { (isSuccess, errorCode) in
         // 拉起运动健康返回状态码为 errorCode
     }
     ```

     * client id：华为开发者联盟APP ID。请根据申请Wear Engine服务中[步骤6](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-ios-0000001935664117#ZH-CN_TOPIC_0000001935664117__li16957258104517)查看并填写正确的APP ID。
     * scheme： 用于授权后从华为运动健康App跳回第三方App。根据申请Wear Engine服务中[步骤3](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-ios-0000001935664117#ZH-CN_TOPIC_0000001935664117__li88131112548)，查看并填写正确的应用回调scheme地址，并在项目中配置URL Scheme。
     * schemeSecret：华为开发者联盟应用schemeSecret。根据申请Wear Engine服务中[步骤6](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/applying-wearengine-ios-0000001935664117#ZH-CN_TOPIC_0000001935664117__li16957258104517)，查看并填写正确的Scheme Secret。
     * clientSecret：华为开发者联盟的clientSecret。根据注册账号及申请账号服务中[步骤7](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-ios-0000001893544118#ZH-CN_TOPIC_0000001893544118__li1582134618509)，查看并填写正确的Client Secret。
   * 方式二：通过Universal Link跳转运动健康app授权，用于4.3.1中scheme数量受限的场景。

     ```
     HiWear.getAuthClient().auth(withClientId:"xxx",  // 华为开发者联盟client id
                                 scheme:"test://healthkitdemo/comeback",  // 用于授权后从华为运动健康app跳回第三方app
                                 schemeSecret:"xxx", // 华为开发者联盟应用schemeSecret
                                 clientSecret:"xxx",  // 华为开发者联盟的clientSecret
                                 srcPkgName:"xx.xx.xx",  // iOS手机侧第三方app的包名
                                 destPkgName:"xx.xx.xx"  // 穿戴设备侧第三方app的包名 
                                 ulinkType: .global) { (isSuccess, errorCode) in
         // 拉起运动健康返回状态码为 errorCode
     }
     ```

     * 相比方式一，新增函数参数ulinkType。ulinkType类型为WESULinkType，开发者可以根据自身的app运营地区，决定使用类型。WESULinkType类型说明：
       * WESULinkGlobal: 使用Universal Link授权流程，适用全球地区。
       * WESULinkNone: 使用常规授权流程。
       * WESULinkCn: 使用Universal Link授权流程，适用中国地区。
       * WESULinkEu: 使用Universal Link授权流程，适用欧洲地区。
       * WESULinkRu: 使用Universal Link授权流程，适用俄罗斯地区。

     ![](https://media:201778661483548128)  
     Universal Link授权接口，仅匹配运动健康App 16.1.4.305以上版本。

   <br />

4. 授权完成后，界面由运动健康app跳转至第三方应用。第三方应用需要添加回调处理。回调处理因工程设置的不同，会在AppDelegate.swift或者SceneDelegate.swift文件中。在回调函数中，调用[processAuthResultWith](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesauthclient-class-0000001897943254#section6464173116407)方法解析授权结果。

   <br />

   AppDelegate.swift文件：

   ```
   // AppDelegate.swift文件
   func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey: Any] = [:]) -> Bool {
       if url.absoluteString.contains("wearenginesdk://") {
           HiWear.getAuthClient().processAuthResult(with: url)
       }
       return true
   }
   ```

   SceneDelegate.swift文件：

   ```
   // SceneDelegate.swift文件
   func scene(_ scene: UIScene, openURLContexts URLContexts: Set<UIOpenURLContext>) {
       guard let url = URLContexts.first?.url else {
           return
       }
       if url.absoluteString.contains("wearenginesdk://") {
           HiWear.getAuthClient().processAuthResult(with: url)
       }
   }
   ```

   <br />

5. 授权结果解析完成后，步骤3中授权接口的回调函数将会被调用。开发者需要对授权结果进行处理。

   <br />

   ```
   HiWear.getAuthClient().auth(...){ (isSuccess, errorCode) in
       // 对授权结果进行响应和处理
   }
   ```

   * isSuccess为true时，表示授权成功，可以正常处理业务。
   * isSuccess为false时，表示授权失败，开发者需要检查errorCode。  
     ![](https://media:201778661483577129)  
     授权失败时，如果errorCode为"WESErrorCodeUserNotSelectDeviceManager(223)"，则表示用户在授权页面上点击了"允许"，但漏勾选"设备权限"的选项。在这个场景下，建议用文字提示用户，和再次调用授权接口。
