# 接入前准备

## 合作协议签署及SDK包获取

Cast Engine设备侧SDK接入前，厂商需提交接入申请（[https://developer.huawei.com/consumer/cn/support/feedback/#/](https://developer.huawei.com/consumer/cn/support/feedback/#/)），问题分类选择 HarmonyOS 3.1/4.0及以下 > HMS Core >投屏能力，按照页面模板填写相关信息。提交后需要关注工单状态，评估通过后，将发放软件包供厂商集成。

## 华为Cast Engine设备硬件规格约束自检

|检查项|规格要求|建议配置|最小配置|
|:---|:-------------|:----------------------------------|:-------------------------|
|资源|SOC|单核不低于2500 DMIPS，整个CPU不低于10000 DMIPS|整个CPU不低于7K DMIPS|
|资源|ROM|>5MB可用|>5MB可用|
|资源|RAM可用内存|>250MB可用|>150MB可用|
|资源|屏幕分辨率规格|1080P及以上|1080P及以上|
|解码|视频解码器|H265/H264硬解码|H264硬解码|
|解码|视频解码能力|支持1080P/60fps/20Mbps以上解码能力|支持1080P/30fps/10Mbps以上解码能力|
|解码|视频解码器-单帧解码耗时|不高于10ms|不高于50ms|
|网络|以太网口|1000M及以上|100M及以上|
|网络|Wi-Fi|支持802.11ac及以上|支持802.11n及以上|
|网络|Wi-Fi吞吐量|屏蔽室场景吞吐量>100Mbps|屏蔽室场景吞吐量>40Mbps|
|网络|Wi-Fi P2P模式|支持|可选|

> * 该规格要求用于华为Cast Engine接入可行性的入口评估，属于必要但非充分条件。最终用户体验依赖于跨系统的软硬件的协同优化。

## 开发约束

### 支持的Android版本

当前Cast Engine支持最低Android 4.4，仅SDK 205以后版本，请持续对软件版本进行关注。

### 服务后台保活

Cast Engine服务集成于厂商自行开发的服务中，因此若需要保证正常投屏功能，厂商需要对自行开发的服务进行后台保活，避免由于服务被停止导致投屏功能无法正常使用。

### 防抢占机制

当前业界有很多投屏协议，如MiraCast、DLNA等。因此，当用户使用Cast Engine投屏时，厂商需要自行增加防抢占机制，保证投屏不被其他协议抢占。协议内部防抢占机制由Cast Engine实现，厂商无需对协议内设备进行防抢占设计。

### 信息采集

Cast Engine会采集集成了能力的App包名，传回到手机，做打点和使用率统计。请在应用包名中体现出厂家/品牌信息，便于Cast Engine统计合作伙伴使用情况。
