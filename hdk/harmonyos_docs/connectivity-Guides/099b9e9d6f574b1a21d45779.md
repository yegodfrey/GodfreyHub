# 穿戴设备模板化通知

手机侧应用向穿戴设备发送通知，并在穿戴设备上按模板显示，支持穿戴设备收到通知后同步振动或响铃（跟随穿戴设备系统设置）。执行成功后，穿戴设备上会显示下图所示通知界面。

使用该接口前，需要向手机侧用户申请获取[NOTIFY](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__NOTIFY)权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/requesting-user-authorization-0000001050819181)），否则接口将调用失败。

* 穿戴设备侧无对应的第三方应用也可以显示模板化通知。
* 请确保穿戴设备和华为运动健康App处于连接状态。用户可进入App"设备"界面查看设备是否在线。开发者可调用[isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)方法了解设备是否在线，如果返回false（true：已连接；false：未连接）提醒用户重新连接设备。
* 穿戴设备振动或响铃的条件：
  1. 穿戴设备侧已开启振动或响铃；
  2. 穿戴设备处于佩戴状态；
  3. 穿戴设备未开启勿扰模式。
* 通知在穿戴设备上自动弹出通知的条件：
  1. 穿戴设备处于佩戴状态；
2. 穿戴设备未开启勿扰模式。

#### 向穿戴设备侧发送通知

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getNotifyClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getNotifyClient-android_content_Context-)方法，获取[NotifyClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/notifyclient-0000001060330666)对象。
3. 定义[Notification](https://developer.huawei.com/consumer/cn/doc/connectivity-References/notification-0000001060620912)通知对象。
4. 调用[notify](https://developer.huawei.com/consumer/cn/doc/connectivity-References/notifyclient-0000001060330666#ZH-CN_TOPIC_0000001874111246__notify-com_huawei_wearengine_device_Device-com_huawei_wearengine_notify_Notification-)方法，从手机上的第三方应用发送通知到穿戴设备侧。

   <br />

   * 通过[Notification](https://developer.huawei.com/consumer/cn/doc/connectivity-References/notification-0000001060620912)对象，定义需要发送的通知对象。
   * 通过[onResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/action-0000001060460918#ZH-CN_TOPIC_0000001920110421__onResult-com_huawei_wearengine_notify_Notification-int-)(Notification notification, int feedback)方法，返回发送成功的结果。
   * 通过[onError](https://developer.huawei.com/consumer/cn/doc/connectivity-References/action-0000001060460918#ZH-CN_TOPIC_0000001920110421__onError-com_huawei_wearengine_notify_Notification-int-java_lang_String-)(Notification notification, int errorCode, String errorMsg)方法，返回发送失败或其他异常的结果。

   ```
   // 步骤2：获取NotifyClient对象
   NotifyClient notifyClient = HiWear.getNotifyClient(this);

   // 步骤3：定义Notification通知对象
   Notification.Builder builder = new Notification.Builder();
   // notificationTemplate 为必填字段，代表发送通知的样式，当前是4种样式，分别是50-没有按钮，51-一个按钮，52-两个按钮，53-三个按钮。
   builder.setTemplateId(NotificationTemplate.NOTIFICATION_TEMPLATE_THREE_BUTTONS);
   // packageName 为必填字段，最多28个字符，为穿戴设备侧应用包名。若穿戴设备侧无应用，则输入任意包名，此时通知使用默认图标显示。
   String packageName = "com.*.*";
   builder.setPackageName(packageName);
   // title 为必填字段，最多28个字符
   String title = "Wear Engine Notification";
   builder.setTitle(title);
   // text 为必填字段，最多400个字符
   String text = "Hello, Wear Engine!";
   builder.setText(text);
   // 如果notificationTemplate 样式设置为没有按钮，则buttonContents不需要填写，否则根据设置了几个按钮，添加几个按钮,每个按钮最多12个字节
   HashMap<Integer, String> buttonContents = new HashMap<>();
   buttonContents.put(NotificationConstants.BUTTON_ONE_CONTENT_KEY, "按钮1");
   buttonContents.put(NotificationConstants.BUTTON_TWO_CONTENT_KEY, "按钮2");
   buttonContents.put(NotificationConstants.BUTTON_THREE_CONTENT_KEY, "按钮3");
   builder.setButtonContents(buttonContents);
   // 创建发送通知的回调对象。当穿戴设备侧收到通知后，用户点击通知上的按钮，开发者可以收到回调信息。
   Action action = new Action() {
       @Override
       public void onResult(Notification notification, int feedback) {
           // 处理notify返回发送成功的结果 
           // feedback == 0: 物理HOME键退出或者灭屏
           // feedback == 1: 删除消息
           // feedback == 2: 用户点击第一个按钮
           // feedback == 3: 用户点击第二个按钮
           // feedback == 4：用户点击第三个按钮
       }

       @Override
       public void onError(Notification notification, int errorCode, String errorMsg) {
           // 处理notify返回发送失败或其他异常的结果
       }
   };
   builder.setAction(action);
   Notification notification = builder.build();

   // 步骤4：调用 notify 方法，从手机上的第三方应用发送消息通知到穿戴设备侧
   if (connectedDevice != null && connectedDevice.isConnected()) {
       notifyClient.notify(connectedDevice, notification).addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               // 处理消息通知接口调用成功的事件
           }
       }).addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 处理消息通知接口调用失败的事件
           }
       });
   }
   ```
