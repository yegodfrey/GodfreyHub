# 版本更新说明

轻量级智能穿戴（Lite Wearable），现阶段只使用JS语言进行应用开发。

智能穿戴（Wearable）既支持使用JS语言开发，也支持[使用JAVA语言开发](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/version-change-history-0000001119036892)。

## 轻量级智能穿戴设备侧

### 5.0.2.306（2022-02-09）

|------------------------------------|
|**新增特性** 查询手机系统型号：支持查询穿戴设备连接的手机系统类型。|

> 说明
>
> 匹配轻量级智能穿戴设备系统HarmonyOS 2.1.0.201及以上版本。

### 历史版本

**5.0.2.300（2021-04-27）**

|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**修改特性** [应用间消息通信](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052460491)：支持使用相对路径"internal://app/"发送文件。 **新增特性** [应用间消息通信](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052460491)：支持在应用运行过程中通过setPeerPkgName()和setPeerFingerPrint()接口指定需要通信的手机侧第三方应用的包名和指纹信息。|

> 说明
>
> 匹配轻量级智能穿戴设备系统 11.0.5 及以上版本。

**5.0.1.300（2020-12-25）**

|------------------------------------------------------------------------------------------------------------------------------------------------------|
|**新增特性** [应用间消息通信](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052460491)：支持接收手机侧第三方应用发过来的文件，支持发送文件至手机侧第三方应用。|

> 说明
>
> 匹配轻量级智能穿戴设备系统 10.1及以上版本。

**5.0.0.300（2020-08-31）**

|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|华为运动健康推出了全新的Wear Engine-LiteWearable-5.0.0.300版本，支持手机侧第三方应用获取轻量级智能穿戴设备列表、订阅轻量级智能穿戴设备连接状态；手机侧第三方应用和轻量级智能穿戴设备侧对应第三方应用互发点对点消息，及手机侧向轻量级智能穿戴设备侧发送点对点文件。 欢迎广大开发者接入。|

> 说明
>
> 匹配轻量级智能穿戴设备系统 10.1及以上版本。

## 智能穿戴设备侧

### 5.0.2.306（2022-02-09）

|------------------------------------|
|**新增特性** 查询手机系统型号：支持查询穿戴设备连接的手机系统类型。|

> 说明
>
> 匹配智能穿戴设备系统 2.0.0.216 及以上版本。

### 历史版本

**5.0.2.302（2021-08-24）**

|---------------------------------------------------------------------------------------------------------------------|
|华为运动健康推出了全新的Wear Engine-Wearable-5.0.2.302版本，支持手机侧第三方应用和智能穿戴设备侧第三方应用互发点对点消息和文件。支持手机侧应用通过ping方法拉起智能穿戴设备侧应用。 欢迎广大开发者接入。|

> 说明
>
> 匹配智能穿戴设备系统 2.0.0.170 及以上版本。
