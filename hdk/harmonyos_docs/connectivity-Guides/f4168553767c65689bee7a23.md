# 开发步骤

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250513191803.88773014451684816001211507851944:50001231000000:2800:FE2921E0F6E12819E9B2031947EF5BC1D32D37A157F843C616C3122243A7B70E.png)  
本接口以jar包的形式提供，jar包内部实现接口类HwOneHopSdk，该类定义相应接口的成员函数供应用调用。  

#### 工程导入OneHop Kit

```
import com.huawei.onehop.appsdk.HwOneHopSdk;
import android.emcom.IOneHopSdkCallback;
```

#### 获取OneHop操作句柄

HwOneHopSdk类以单例的形式实现，使用时通过getInstance()来获取实例，例如HwOneHopSdk.getInstance().registerOneHop();  

#### 接口鉴权

1. 实现鉴权回调接口IOneHopAuthReqCallback

   <br />

   ```
   public class authReqCallBack implements IOneHopAuthReqCallback.Stub {
       public void onAuthResult(boolean result) {
           if (result) {
               //If the authentication succeeds, then...
           } else {
               //else...
           }
       }
   }
   ```

   <br />

2. 调用鉴权接口，获取返回值

   <br />

   ```
   int retcode;
   String packageName = "com.android.example";
   retcode = HwOneHopSdk.getInstance().onehopAuthReq(packageName, authReqCallBack);
   if (HwOneHopSdk.AUTH_RESULT_SUCCESS == retcode) {
       Log.d("OneHop", "authentication succeeds.");
   } else if (HwOneHopSdk.AUTH_RESULT_ERROR == retcode  || HwOneHopSdk.AUTH_RESULT_FAIL == retcode) {
       Log.d("OneHop", "authentication fail.");
   } else {
       // means HwOneHopSdk.AUTH_RESULT_WAIT == retcode
       Log.d("OneHop", "wait for the authentication result.");
   }
   ```

   <br />

#### 注册监听函数

1. 实现监听接口ServiceCallBack

   <br />

   ```
   public class ServiceCallBack implements IOneHopSdkCallback.Stub {
       public void onOneHopReceived (String para) {
           //Call the OneHop API OneHopData to notify the current tapping event.
           JSONObject jsonObject = new JSONObject(para);
           //Parse the JSON data and process it...
       }
   }
   ```

   <br />

2. 将ServiceCallBack注册到OneHopSDK中

   <br />

   ```
   int retcode;
   String packageName = "com.android.example";
   ServiceCallBack  servicecallback = new ServiceCallBack();
   retcode = HwOneHopSdk.getInstance().registerOneHop(packageName, HwOneHopSdk.ONEHOP_DATA_TYPE_BUSINESS_CONTINUITY, servicecallback);
   if (HwOneHopSdk.ONEHOP_ERR == retcode) {
         Log.e("OneHop", "register OneHop error.");
   }
   ```

   <br />

#### 同步应用数据

调用时机：OneHop SDK通过APP注册的回调接口onOneHopReceived()通知应用同步数据时，应用调用该接口进行数据同步。

```
//oneHopSend
int retcode;
String packageName = "com.android.example";
String param={"para1":"xxxxxx", "para2":xxx};
JSONObject obj = new JSONObject(param);
retcode  = HwOneHopSdk.getInstance().oneHopSend (packageName , obj);
```

<br />

JSON格式说明：

预设KEY值说明  

|名称|值|描述|
|:------------------|:--------------------|:--------------------|
|ONEHOP_DATA_TYPE|"onehop_data_type"|ONEHOP的数据类型|
|ONEHOP_RECEIVE_TYPE|"onehop_receive_type"|onOneHopReceived的数据类型|

ONEHOP_DATA_TYPE值说明  

|名称|子类型|值|描述|
|:---------------|:-----------------------------------|:-|:---|
|ONEHOP_DATA_TYPE|ONEHOP_DATA_TYPE_BUSINESS_CONTINUITY|7|业务接续|

ONEHOP_DATA_TYPE值说明  

|名称|子类型|值|描述|
|:------------------|:----|:-|:---|
|ONEHOP_RECEIVE_TYPE|event|1|触发事件|
|ONEHOP_RECEIVE_TYPE|data|2|业务数据|

JSON参数示例：

1. onOneHopReceived()：NFC触发通知到第三方应用，参数json格式定义。

   ```
   {"OneHop_data_type":7, "onehop_receive_type":1}
   ```

2. onOneHopReceived()：业务接续数据发送到第三方应用，参数json格式定义。

   ```
   {"OneHop_data_type":7, "onehop_receive_type":2, "xxx":"xxx", ...}
   ```

   后面跟业务数据。
3. oneHopSend()：第三方应用将业务接续数据发送到OneHop，参数json格式定义。

   ```
   {"OneHop_data_type":7, "xxx":"xxx", ...}
   ```

   后面跟业务数据。

<br />

权限说明

1. 在使用OneHop Engine的接口时，需要在apk的manifest.xml文件里添加下面所列权限，以通过权限校验

   ```
   <uses-permission android:name="com.huawei.permission.ONEHOP"/>
   ```

2. 鉴权接口采用云端鉴权方式，需要开发者去华为开发者网站注册申请使用Onehop Engine相关权限，成功之后，方可通过该接口鉴权。
