# 查询可用穿戴设备

Wear Engine提供查询用户是否有可用穿戴设备（即支持Wear Engine能力的穿戴设备）的接口。在获取设备列表之前，需要向手机侧用户申请获取[DEVICE_MANAGER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__DEVICE_MANAGER)权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/request-user-authorization-ios-0000001920933293)），否则设备列表将获取失败。

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section81891233142218)方法，获取[WESDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesdeviceclient-0000001897479342)对象。
2. 调用[getCommonDevices](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesdeviceclient-class-0000001937982749#section16552950197)方法，查询用户的可用穿戴设备列表。

   ```screen
   HiWear.getDeviceClient().getCommonDevices { status, deviceArr in
       if status != .WESErrorCodeSuccess {
           // 获取设备列表失败，错误码：status.rawValue
           return
       }
       guard let deviceArr else {
           // 获取到的设备列表为空
           return
       }
       guard deviceArr.first != nil else {
           // 获取到的设备列表的第一个设备为空
           return
       }
       var deviceString = ""
       var tag = 0
       for device in deviceArr {
           let deviceDescription :String = device.description
           deviceString.append("device<\(tag)>:\(deviceDescription),\n")
           tag += 1
       }
       // 获取到的设备列表信息为deviceString
   }
   ```

> 说明
>
> * 穿戴设备列表的信息会在[申请用户穿戴设备权限](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/request-user-authorization-ios-0000001920933293#section738754382)时缓存。如果穿戴设备信息发生变化，需再次调用[申请用户穿戴设备权限](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/request-user-authorization-ios-0000001920933293#section738754382)接口，刷新缓存。
> * 接口返回的穿戴设备列表信息为运动健康App中已连接和未连接的手表设备。不支持iOS版WearEngineSDK的手表设备则不包含在列表中。
> * 接口返回的穿戴设备列表信息为空时，可能是用户的手表不支持iOS WearEngine。

## 连接指定设备

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section81891233142218)方法，获取[WESDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesdeviceclient-0000001897479342)对象。
2. 调用[connect](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesdeviceclient-class-0000001937982749#section161612521497)方法，连接指定的设备。

   ```screen
   let deviceClient: WESDeviceClient = HiWear.getDeviceClient()
   // currentDevice上方接口查询到的穿戴设备
   deviceClient.connect(currentDevice) { status, connectStatus in
       if status != .WESErrorCodeSuccess {
           // 连接穿戴设备失败
       }
       if status == .WESErrorCodeSuccess {
           // 连接穿戴设备成功
       }
   }
   ```

## 查询当前设备连接状态

在连接设备成功后，调用getCurrentDevices方法，获取当前连接的设备。后续调用其他接口，建议以这里获取到的device作为参数。

1. 第三方应用调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section81891233142218)方法，获取[WESDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesdeviceclient-0000001897479342)对象。
2. 调用[getCurrentDevices](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesdeviceclient-class-0000001937982749#section6464173116407)方法，获取已配对的设备。

   ```screen
   let currentDevice = HiWear.getDeviceClient().getCurrentDevices()
   let deviceConnected = currentDevice?.connectState == .stateConnected ? "已连接" : "未连接"
   ```

## 连接状态订阅

1. 获取已配对的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getMonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section7710184710415)方法，获取[WESMonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesmonitorclient-0000001897319434)对象。
3. 调用[subscribeStatus](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesmonitorclient-class-0000001898103114#section16552950197)方法，订阅设备连接状态的变化。

   ```screen
   let device = HiWear.getDeviceClient().getCurrentDevices() 
   HiWear.getMonitorClient().subscribeStatus(of: device) { status, connectStatus in 
       if status.rawValue == 0 && connectStatus.rawValue == 0 {
           // 订阅成功
       } else {
           // 订阅-连接状态为connectStatus.rawValue
       } 
   }
   ```

## 连接状态取消订阅

1. 获取已配对的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getMonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section7710184710415)方法，获取[WESMonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesmonitorclient-0000001897319434)对象。
3. 调用[unsubscribeStatus](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesmonitorclient-class-0000001898103114#section161612521497)方法，取消订阅设备连接状态的变化。

   ```screen
   let device = HiWear.getDeviceClient().getCurrentDevices()
   HiWear.getMonitorClient().unsubscribeStatus(of: device) { 
       status, connectStatus in
       // 解除订阅成功
   }
   ```
