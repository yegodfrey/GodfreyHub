# 开发准备及注意事项

## 环境准备

* Android Studio开发环境，建议版本V3.0.1及以上。

* 手机开发环境：华为手机EMUI 9.0及以上版本，系统支持Huawei Share能力。

## 添加权限

应用通过Huawei Share分享文件时，需要授权指定文件的读取权限。
