# 术语缩略表

|**缩略语**|**英文全称**|**中文**全称|**描述**|
|:------|:-------------------|:-------|:---------------------------|
|ACC|Accelerometer|加速度计|通过振动测量直接加速度。|
|ECG|Electrocardiography|心电图|利用在人体皮肤表面贴上的电极，侦测到心脏的电位传动。|
|GYRO|Gyroscopes|陀螺仪|陀螺仪又叫角速度传感器，用于对转动、偏转的动作进行测量。|
|HR|Heart Rate|心率|人体每分钟心跳数，利用PPG数据计算得出。|
|MAG|Magnetometer|磁力计|用于测量三轴的磁场强度。|
|PPG|Photoplethysmography|光电容积图|利用光电手段检测血管中血液容积变化的一种检测方法。|
