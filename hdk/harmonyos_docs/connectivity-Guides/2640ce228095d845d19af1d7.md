# 接收端开发场景设计

作为文件分享接收端， 需实现如下场景：

正常场景：

* 收到文件接收请求（用户交互界面、设置默认接收模式）
* 正常接收文件（存储空间预判、文件重命名）
* 传输文件过程中显示进度条及传输状态（传输成功、传输失败等）
* 传输文件过程异常中断的处理（等待恢复周期、恢复文件传输、清除残留文件等）

异常场景：

* 存储空间不足等导致文件传输中止
* 对端设备拒绝接收文件
* 文件传输中途取消文件接收
