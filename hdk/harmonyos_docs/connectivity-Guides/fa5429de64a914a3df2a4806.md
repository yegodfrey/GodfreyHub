# 开发准备

## 获取软件包

参见[DV Engine SDK下载](https://developer.huawei.com/consumer/cn/doc/connectivity-Library/harmonyos-sdk-download-0000001051392749)。

## 获取开发工具

### 安装和配置开发环境

1. 安装Android Studio开发工具。
2. 新建或者打开已有的Android Studio项目。
3. 将下载好的DV Engine的aar包复制至工程中的"app/libs"下。
4. 在工程app目录中的"build.gradle"中添加如下代码，将对应的aar添加至工程中。

   ```screen
   dependencies { 
       implementation files('libs/devicevirtualization-device-android-1.0.0.300.aar') 
   }
   ```

5. 在"AndroidManifest.xml"中配置应用为系统权限。

   ```screen
   <manifest xmlns:android="http://schemas.android.com/apk/res/android" 
       package="com.huawei.dmsdptest" 
       android:sharedUserId="android.uid.system">
   ```

### 检验环境是否搭建成功

使用aar文件中的API接口，并且工程能够构建成功。
