# 应用间消息通信

在穿戴设备侧和手机侧构建应用到应用的通信隧道，用于收发第三方应用自定义的报文消息以及文件。

## 穿戴设备侧的第三方应用检测手机侧对应的第三方应用是否安装

在发送点对点消息前，可以用ping方法检测穿戴设备上的第三方应用是否能跟手机侧对应的第三方应用正常通信。

1. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060#ZH-CN_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062)对象。
2. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-)方法，指定需要ping通信的手机侧对应的第三方应用包名。
3. 调用[ping](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__ping-com_huawei_watch_kit_hiwear_p2p_PingCallback-)方法，检测手机侧对应的第三方应用是否已安装指定应用，若手机侧应用未安装，则返回错误码204，若已安装返回205。

   ```screen
   // 步骤1：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);
   String peerPkgName = "com.*.*";

   // 步骤2：设置需要通信的手机侧对应的第三方应用包名
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤3：检测手机侧对应的第三方应用是否在线
   p2pClient.ping(new PingCallback() {
       @Override
       public void onResult(int i) {
           // 回调结果
       }
   });
   ```

## 穿戴设备侧的第三方应用发送点对点消息或文件到手机侧第三方应用

消息长度大小的限制为1KB。针对消息长度超过限制的情况可以采用发送文件（文件大小不超过4MB）的方式或进行消息的分包控制。

穿戴设备侧实现发送消息和文件功能后，手机侧第三方应用需要对应实现接收消息和文件的功能。参见手机侧[接收穿戴设备侧应用发过来的点对点消息或文件](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-0000001051059209#section11891149183312)。

### 发送点对点消息

1. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060#ZH-CN_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062)对象。
2. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-)方法，指定需要通信的手机侧对应的第三方应用包名。
3. 调用[setPeerFingerPrint](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__setPeerFingerPrint-java_lang_String-)方法，指定需要通信的手机侧应用指纹SHA256信息（请参见[生成签名证书指纹](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#3)获取签名证书的SHA256证书指纹，指纹设置为手机侧应用在开发者联盟申请账号服务时注册的指纹之一，即[注册账号及申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)步骤4中的SHA256证书指纹之一）。
4. 调用[send](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__send-com_huawei_watch_kit_hiwear_p2p_HiWearMessage-com_huawei_watch_kit_hiwear_p2p_SendCallback-)方法，从穿戴设备上的第三方应用发送简短消息到手机侧对应的第三方应用。

   * 调用[HiWearMessage](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwearmessage-0000001059835462)对象，定义第三方应用需要发送的消息。
   * 调用[onSendProgress](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059147015#ZH-CN_TOPIC_0000001873951310__onSendProgress-long-)(long progress)方法，查看消息发送进度。
   * 调用[onSendResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059147015#ZH-CN_TOPIC_0000001873951310__onSendResult-int-)(int resultCode)方法，返回消息发送结果：成功或失败。

   ```screen
   // 步骤1：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);
   String peerPkgName = "com.*.*";
   String peerFinger = "67DFB7FD********";

   // 步骤2：设置需要通信的手机侧对应的第三方应用包名
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤3：设置手机侧应用指纹信息
   p2pClient.setPeerFingerPrint(peerFinger);

   //步骤4：发送简短消息到手机侧对应的第三方应用
   // 构造Message对象
   String messageStr = "Hello, Wear Engine!";
   HiWearMessage.Builder builder = new HiWearMessage.Builder();
   builder.setPayload(messageStr.getBytes("UTF-8"));
   HiWearMessage sendMessage = builder.build();
   // 创建回调方法
   SendCallback sendCallback = new SendCallback() {
       @Override
       public void onSendResult(int resultCode) {
       }
       @Override
       public void onSendProgress(long progress) {
       }
   };
   if (sendMessage != null && sendCallback != null) {
       p2pClient.send(sendMessage, sendCallback);
   }
   ```

### 发送文件

1. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060#ZH-CN_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062)对象。
2. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-)方法，指定需要通信的手机侧应用包名。
3. 调用[setPeerFingerPrint](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__setPeerFingerPrint-java_lang_String-)方法，指定需要通信的手机侧应用指纹SHA256信息（请参见[生成签名证书指纹](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#3)获取签名证书的SHA256证书指纹，指纹设置为手机侧应用在开发者联盟申请账号服务时注册的指纹之一，即[注册账号及申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)步骤4中的SHA256证书指纹之一）。
4. 调用[send](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__send-com_huawei_watch_kit_hiwear_p2p_HiWearMessage-com_huawei_watch_kit_hiwear_p2p_SendCallback-)方法，从穿戴设备上的第三方应用发送文件到手机侧对应的第三方应用。

   * 调用[HiWearMessage](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwearmessage-0000001059835462)对象，构造第三方应用需要发送的文件。
   * 调用[onSendProgress](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059147015#ZH-CN_TOPIC_0000001873951310__onSendProgress-long-)(long progress)方法，查看文件发送进度。
   * 调用[onSendResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059147015#ZH-CN_TOPIC_0000001873951310__onSendResult-int-)(int resultCode)方法，返回文件发送结果：成功或失败。

   ```screen
   // 步骤1：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);
   String peerPkgName = "com.*.*";
   String peerFinger = "67DFB7FD********";

   // 步骤2：设置需要通信的手机侧应用包名
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤3：设置手机侧应用指纹信息
   p2pClient.setPeerFingerPrint(peerFinger);

   // 步骤4：发送文件到手机侧对应的第三方应用
   // 构造需要发送的文件
   String filePath = ".....";
   File sendFile = new File(filePath);
   HiWearMessage.Builder builder = new HiWearMessage.Builder();
   builder.setPayload(sendFile);
   HiWearMessage sendMessage = builder.build();
   // 创建回调方法
   SendCallback sendCallback = new SendCallback() {
       @Override
       public void onSendResult(int resultCode) {
       }
       @Override
       public void onSendProgress(long progress) {
       }
   };
   if (sendMessage != null && sendCallback != null) {
       p2pClient.send(sendMessage, sendCallback);
   }
   ```

### 接收手机侧第三方应用发过来的点对点消息或文件

1. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060#ZH-CN_TOPIC_0000001920110329__getP2pClient-ohos_app_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062)对象。
2. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__setPeerPkgName-java_lang_String-)方法，指定需要通信的手机侧应用包名。
3. 调用[setPeerFingerPrint](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__setPeerFingerPrint-java_lang_String-)方法，指定需要通信的手机侧应用指纹SHA256信息（请参见[生成签名证书指纹](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#3)获取签名证书的SHA256证书指纹，指纹设置为手机侧应用在开发者联盟申请账号服务时注册的指纹之一，即[注册账号及申请账号服务](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/registering-applying-account-0000001050818011)步骤4中的SHA256证书指纹之一）。
4. 调用[registerReceiver](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__registerReceiver-com_huawei_watch_kit_hiwear_p2p_Receiver-)方法，穿戴设备侧第三方应用接收手机侧第三方应用发过来的简短消息或文件，其实现原理即是向Wear Engine注册一个监测器。

   调用[onReceiveMessage](https://developer.huawei.com/consumer/cn/doc/connectivity-References/receiver-0000001059027011#ZH-CN_TOPIC_0000001919950665__onReceiveMessage-com_huawei_watch_kit_hiwear_p2p_HiWearMessage-)方法，处理手机侧发过来的消息或文件，默认接收文件路径为**data/data/包名/cache/hiwear**目录下。

   ```screen
   // 步骤1：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);
   String peerPkgName = "com.*.*";
   String peerFinger = "67DFB7FD********";

   // 步骤2：设置需要通信的手机侧应用包名
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤3：设置手机侧应用指纹信息
   p2pClient.setPeerFingerPrint(peerFinger);

   // 步骤4：接收手机侧第三方应用发过来的简短消息或文件
   Receiver receiver = new Receiver() {
        @Override
        public void onReceiveMessage(HiWearMessage message) {
             // 处理手机侧第三方App发过来的简短消息以及文件
        }
   };
   p2pClient.registerReceiver(receiver);
   ```

5. 调用[unregisterReceiver](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001059995062#ZH-CN_TOPIC_0000001874111170__unregisterReceiver-com_huawei_watch_kit_hiwear_p2p_Receiver-)方法，穿戴设备侧第三方应用取消接收手机侧第三方应用发过来的消息或文件，其实现原理即是向Wear Engine取消已经注册的监测器。

   ```screen
   // 步骤5：取消接收手机侧第三方应用发过来的消息或文件
   p2pClient.unregisterReceiver(receiver);
   ```

## 手机侧App通过ping方法拉起穿戴设备侧App

当手机侧App启动，穿戴设备侧App没有启动时，手机App可以通过ping方法拉起穿戴设备App。使用该功能时，穿戴设备侧应用需要创建指定名称的Page Ability。

1. 在穿戴设备侧创建Page Ability，命名为HiWearMainAbility.java，在onStart方法中通过setMainRoute方法指定对应的界面。

   ```screen
   public class HiWearMainAbility extends Ability {
       @Override    
       public void onStart(Intent intent) {
           super.onStart(intent);
           super.setMainRoute(MainAbilitySlice.class.getName());
       }
   }
   ```

   > 说明
   >
   > Ability的名称为HiWearMainAbility.java，不支持自定义。

2. 在config.json文件中声明该Ability。type设置为page，visible设置为true。

   ```screen
   "abilities": [ 
     ...... 
     {
       ......
       "visible": true,
       "name": ".HiWearMainAbility",
       "type": "page",
       ......
     }, 
     ...... 
   ],
   ```

3. 完成以上配置后，在手机侧调用[ping](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__ping-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_PingCallback-)方法，即可拉起穿戴设备侧应用。具体操作请参见[手机侧应用检测穿戴设备侧对应的应用是否在线](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-0000001051059209#section25081840087)。
