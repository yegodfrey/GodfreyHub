# 调测验证

1. 打开手机WLAN和BT功能。
2. 打开DV EngineDemo App，参见[DV Engine北向应用开放](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/version-change-history-0000001052667185)，获取此测试应用。
3. 点击"DVKITDEMO"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/NuQTUTpVSSy0zOAkWynAlQ/zh-cn_image_0000001052885426.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T133428Z&HW-CC-Expire=31536000000&HW-CC-Sign=F378B348A121EF6F7ACD50285913F5A9580086515BA3EE0C7138F409594802CC "点击放大")

4. 点击"START DISCOVERY"按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/bOFMjpCyQNyNjs9gjYcCaQ/zh-cn_image_0000001052486761.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T133428Z&HW-CC-Expire=31536000000&HW-CC-Sign=2276D2F169B1F520C1868CB77C77D9701C0BD036F7DC8B83CD154C4DFA1A5771 "点击放大")

5. 会展示出发现的列表，找到对应的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/x0-07W37TGCl1h24yxITBQ/zh-cn_image_0000001052486771.jpg?HW-CC-KV=V1&HW-CC-Date=20260909T133428Z&HW-CC-Expire=31536000000&HW-CC-Sign=D0B8B08B767A4A82E7FC5109B90F86EC3B74D53F8EB6596837EA94ED6D61167A "点击放大")

6. 测试Camera功能，点击Camera按钮使能服务，点击ID，选择FRONT后，点击OK确认，跳转到摄像头图像界面。
7. 测试Speaker功能，点击Speaker按钮，打开华为音乐，播放歌曲，智能设备喇叭出声。
8. 测试Mic功能，点击Mic按钮，打开录音机，在智能设备的Mic处说话。
