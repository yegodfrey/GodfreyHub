# 调测验证

1. 打开手机WLAN和BT功能。
2. 打开DV EngineDemo App，参见[DV Engine北向应用开放](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/version-change-history-0000001052667185)，获取此测试应用。
3. 点击"DVKITDEMO"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/NuQTUTpVSSy0zOAkWynAlQ/zh-cn_image_0000001052885426.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T143425Z&HW-CC-Expire=31536000000&HW-CC-Sign=655A16456ACA83BE24022FD610184EE6FB0A76B1B3FD76C996C545D097F7FB3D "点击放大")

4. 点击"START DISCOVERY"按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/bOFMjpCyQNyNjs9gjYcCaQ/zh-cn_image_0000001052486761.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T143425Z&HW-CC-Expire=31536000000&HW-CC-Sign=F2F343448335E1405260491C69BFC2FA5FDD35064AECE17E1A637EA8A6251304 "点击放大")

5. 会展示出发现的列表，找到对应的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/x0-07W37TGCl1h24yxITBQ/zh-cn_image_0000001052486771.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T143425Z&HW-CC-Expire=31536000000&HW-CC-Sign=2CB3192DCD84BE4BA46827AFAC29507B40E929F1EBB5A18E4A05AEB17319EC9C "点击放大")

6. 测试Camera功能，点击Camera按钮使能服务，点击ID，选择FRONT后，点击OK确认，跳转到摄像头图像界面。
7. 测试Speaker功能，点击Speaker按钮，打开华为音乐，播放歌曲，智能设备喇叭出声。
8. 测试Mic功能，点击Mic按钮，打开录音机，在智能设备的Mic处说话。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/lxfH7l2CQe-XMkoFafpzDQ/zh-cn_image_0000001051628902.jpg?HW-CC-KV=V1&HW-CC-Date=20261008T143425Z&HW-CC-Expire=31536000000&HW-CC-Sign=00C1E1E290EE167EE4EFC4B33122CEF90B324C4E8F3171AF77CFD38E74607BB4 "点击放大")
