# 开发前准备

1. 基于安全考虑，服务侧对CaaS Engine开放的接口做了权限保护处理，使用相关接口需要向华为方申请对应权限。权限申请需提供开发者联盟网站创建应用时生成的appid，且指纹信息已配置。权限申请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)的方式提供信息，信息内容包括appid、包名、所属公司、产品简单介绍、面向哪类用户、用户使用场景和方法以及上线时间。
2. Android Studio开发环境，建议版本V3.0.1及以上。 手机开发环境：华为手机EMUI 9.1及以上版本且支持畅连通话。
