# 业务介绍

## 业务简介

HUAWEI Cast Engine是华为提供以手机为中心的大小屏协同能力。通过集成华为Cast Engine，可以实现手机与大屏类设备屏幕的快速、稳定、低时延协同，带来多屏场景下的优质体验。

## 场景介绍

* 大屏类设备厂商（如电视）通过集成Cast Engine，可快速与华为手机打通大小屏协同能力。
* （即将开放）手机侧三方App可根据自身业务特点，利用Cast Engine打造差异化操控体验。

## 能力优势

* 手机与大屏类设备快速发现及稳定连接
* 高清晰、低时延投屏能力
* 领先的多屏协同硬实力，抗花屏卡顿，提供流畅协同体验

|**终端设备**|**系统版本**|
|:-------|:-----------|
|华为手机|EMUI 10.1及以上|

### 支持的国家/地区

请参见[支持的国家/地区](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/regions-0000001052420729)。

### 注意事项

* 三方设备集成华为Cast Engine SDK需要遵从《HUAWEI Cast Engine 三方集成UX设计规范》，此规范在签约后，由华为提供。
* 三方设备集成华为Cast Engine升级方式：Cast Engine以二进制软件包形式提供给三方设备厂商，具体升级策略由厂商与华为协商确定。
* 当前Cast Engine在三方设备中与Miracast、AirPlay、Google Cast不兼容 。
