# 手写笔双击功能

## 开发流程

|序号|步骤名称|目的|
|:-|:----------------------------------------------------------------------|:--------------|
|1|[（可选）使用手写套件内的双击功能](#ZH-CN_TOPIC_0000001166918053__li96101924472)|使用手写套件的双击功能。|
|2|[（可选）注册手写笔双击广播使用手写笔双击功能](#ZH-CN_TOPIC_0000001166918053__li189781541116)|用于手写笔双击功能自定义开发。|

## 约束与限制

* 仅支持HarmonyOS 2.0及以上系统且手写笔支持双击(HUAWEI M-Pen 2 及 HUAWEI M-Pencil 第二代)。
* Pencil Engine手写套件界面内已支持手写笔双击功能，建议不要在手写套件界面内再自定义手写笔双击功能。

## 开发步骤

1. （可选）使用手写套件内的双击功能

   在"设置 > 辅助功能 > 手写笔" 中设置手写笔双击菜单选项，菜单选项如下：

   |菜单索引|菜单选项|
   |:---|:--------------|
   |0|当前工具与橡皮擦切换，默认值。|
   |1|当前工具与上次使用工具切换|
   |2|显示调色盘|
   |3|关闭|

   设置完毕之后，在Pencil Engine手写套件内使用手写笔双击功能时，将触发所选取的手写笔双击响应事件。

2. （可选）三方注册双击广播，获取双击菜单选项进行自定义开发。

   注册手写笔双击广播，在Activity获取焦点时注册广播，失去焦点时注销广播注册。

   ```screen
   private static final String DOUBLE_CLICK_BROADCAST = "com.huawei.stylus.action.BUTTON_DOUBLE_PRESSED";
   ...
   public voidonWindowFocusChanged(booleanhasFocus){
       super.onWindowFocusChanged(hasFocus);
   if(hasFocus) {
           myBroadcastReceiver= newMyBroadCastReceiver();
           IntentFilter filter = newIntentFilter();
           filter.addAction(*DOUBLE_CLICK_BROADCAST*);
           registerReceiver(myBroadcastReceiver, filter);
           changeDoubleClickMode();
       } else{
           unregisterReceiver(myBroadcastReceiver);
       }
   }
   ```

   读取手写笔双击菜单选项进行自定义功能开发

   ```screen
   private static final String DOUBLE_CLICK_SWITCH_MODE = "double_click_switch_mode";
   private static final int CURRENT_AND_ERASER = 0;
   int doubleClickMode = 0;
   ...
   ContentResolver contentResolver = getApplicationContext().getContentResolver();
   doubleClickMode= Settings.Global.getInt(contentResolver,*DOUBLE_CLICK_SWITCH_MODE*, *CURRENT_AND_ERASER*);
   switch (doubleClickMode) {
       case 0:
           // 自定义双击功能
           break;
       case 1:
           // 自定义双击功能
           break;
   ...
   }
   ```

## 调测验证

* 在Pencil Engine手写套件界面内双击手写笔，观察在手写笔双击菜单中设置的功能选项是否触发。
* 在自定义双击功能界面，双击手写笔后，观察自定义的手写笔双击功能是否触发。
