# 业务简介

#### 业务简介

对于办公、社交等需要文件互传的手机应用，Share Engine可无缝嵌入其分享操作逻辑，确保其流畅的自有业务逻辑和统一的UI界面。EMUI 10.1版本开始，华为将Huawei Share功能以API的方式开放给Android App，应用通过Intent方式启动Huawei Share分享页，实现各App内调用Huawei Share接口的同时满足自定义设置文件发送逻辑和UI界面。

App集成Share Engine后，当前仅支持华为手机之间互传文件。  

#### 场景介绍

华为Share Engine为手机App提供以下3种文件分享的方式：

* 文本分享
* 单个文件分享
* 多个文件分享
