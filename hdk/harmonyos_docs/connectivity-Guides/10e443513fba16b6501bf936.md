# 开发流程

#### 文本发送开发

在合适的位置添加以下代码，如按钮的OnClick监听事件中。

```
// 判断当前设备是否支持Intent方式发起分享 仅在支持时显示相关UI
Intent intent = new Intent(Intent.ACTION_SEND); 
intent.setType("*"); 
intent.setPackage("com.huawei.android.instantshare"); 
intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK); 
PackageManager manager = getApplicationContext().getPackageManager(); 
List<ResolveInfo> infos = manager.queryIntentActivities(intent, 0); 
if (infos.size() == 0) { 
    // 说明当前设备不支持Intent方式通过Share分享,此时界面不应显示相关内容
    Log.d("Share", "share via intent not supported");
} else {
    // 分享文本,对端将收到包含指定内容的文件 
    intent.putExtra(Intent.EXTRA_TEXT, "test text"); 
    getApplicationContext().startActivity(intent); 
}
```

#### 多个文件分享开发

在合适的位置添加以下代码，如按钮的OnClick监听事件中。

```
// 判断当前设备是否支持Intent方式发起分享 仅在支持时显示相关UI
Intent intent = new Intent(Intent.ACTION_SEND); 
intent.setType("*"); 
intent.setPackage("com.huawei.android.instantshare"); 
intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK); 
PackageManager manager = getApplicationContext().getPackageManager(); 
List<ResolveInfo> infos = manager.queryIntentActivities(intent, 0); 
if (infos.size() == 0) { 
    // 说明当前设备不支持Intent方式通过Share分享,此时界面不应显示相关内容
    Log.d("Share", "share via intent not supported");
} else {
    // 分享多个文件
File storageDirectory = Environment.getExternalStorageDirectory();
File file1 = new File(storageDirectory, "Download/testfile1");
File file2 = new File(storageDirectory, "Download/testfile2");
ArrayList<Uri> files = new ArrayList<>(); 
files.add(FileProvider.getUriForFile(this, App_PROVIDER, file1));
files.add(FileProvider.getUriForFile(this, App_PROVIDER, file2));
    intent.putParcelableArrayListExtra(Intent.EXTRA_STREAM, files);
intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION);
    getApplicationContext().startActivity(intent); 
}
```
