# 调测验证

## 环境准备

* EMUI 10.1以上版本的手机。
* 手机和电视设备接入同一局域网络，电视可为有线或无线连接。

## Engine服务安装

1. 将设备置成可读写模式。

   ```screen
   adb remount
   ```

2. 安装HwDMSDPDevice。

   1. 创建HwDMSDPDevice安装路径。

      ```screen
      adb shell mkdir -p /system/app/HwDMSDPDevice/lib/arm
      adb shell mkdir -p /system/app/HwDMSDPDevice/lib/arm64
      ```

   2. 将HwDMSDPDevice.apk进行系统签名并放在对应路径下。

      ```screen
      adb push HwDMSDPDevice.apk /system/app/HwDMSDPDevice
      ```

   3. 将64位和32位的so文件分别放到对应的路径下。

      ```screen
      adb push lib/arm/xxx.so /system/app/HwDMSDPDevice/lib/arm/
      adb push lib/arm64/xxx.so /system/app/HwDMSDPDevice/lib/arm64/
      ```

3. 安装HiSight。

   1. 创建HiSight安装路径。

      ```screen
      adb shell mkdir -p /system/priv-app/HiSight/lib/arm
      ```

   2. 将HiSight.apk进行系统签名并放在对应路径下。

      ```screen
      adb push HiSight.apk /system/priv-app/HiSight/
      ```

   3. 将so文件放在对应的路径下。

      ```screen
      adb push libjniFtSocketSink.so /system/priv-app/HiSight/lib/arm/libjniFtSocketSink.so
      ```

4. 安装厂商适配应用（以华为提供的Demo应用为例）。

   1. 创建Demo应用的安装路径。

      ```screen
      adb shell mkdir -p /system/app/HwDMSDPDeviceTest
      ```

   2. 将Demo应用进行系统签名并放在对应路径下。

      ```screen
      adb push dvkitdemo_android.apk /system/app/HwDMSDPDeviceTest/
      ```

5. 重启设备。

   ```screen
   adb reboot
   ```

## 验证步骤

1. 设备侧打开Demo应用，点击"启动虚拟化"按钮。
2. 手机侧打开测试工具，点击"开始发现"按钮。
3. 如果发现成功，会在手机测试工具界面显示被发现的设备名称以及CAMERA、DISPLAY、SPEAKER、MIC四个按钮。
4. 点击按钮就可以实现对应能力的虚拟化。

## 预期结果

1. Camera虚拟化，手机可以使用设备侧的相机。
2. Display虚拟化，可以将手机屏幕投射到设备侧屏幕上。
3. Speaker虚拟化，手机播放的音频通过设备侧的扬声器播出。
4. Mic虚拟化，手使用录音机时，收集到的声音来自于设备侧的麦克风。
