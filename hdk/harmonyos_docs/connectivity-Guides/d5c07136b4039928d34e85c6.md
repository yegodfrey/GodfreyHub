# 获取手机系统信息

当前Wear Engine不支持iOS系统的手机，穿戴侧应用可以通过[getPeerDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/peerdeviceclient-0000001192908020#ZH-CN_TOPIC_0000001873951294__getPeerDevice-com_huawei_watch_kit_hiwear_peerdevice_PeerDeviceCallback-)方法获取手机系统信息，若手机系统为iOS，开发者可在穿戴侧应用上做相应的提示。

1. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060)中的[getPeerDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001059995060#section4609548162615)方法，获取PeerDeviceClient对象。
2. 调用[getPeerDevice](https://developer.huawei.com/consumer/cn/doc/connectivity-References/peerdeviceclient-0000001192908020#ZH-CN_TOPIC_0000001873951294__getPeerDevice-com_huawei_watch_kit_hiwear_peerdevice_PeerDeviceCallback-)方法，获取手机侧系统信息。当前仅支持获取手机系统类型，其中1为Andriod系统或HarmonyOS 5.0之前版本（如HarmonyOS 2.x/3.x/4.x）系统，2为IOS系统，3为HarmonyOS 5.0及以上版本系统。

   ```screen
   // 步骤1：获取手机侧信息对象
   PeerDeviceClient peerDeviceClient = HiWear.getPeerDeviceClient(this);

   // 步骤2：获取手机侧系统信息
   peerDeviceClient.getPeerDevice(new PeerDeviceCallback() {
       @Override
       public void onResult(int i, PeerDevice peerDevice) {
           // 回调结果，处理包含手机侧系统信息的对象
       }
   });
   ```
