# 配置混淆脚本

开发者编译APK前配置混淆配置文件，为避免混淆SDK导致功能异常，需要在工程中的"proguard-rules.pro"文件中进行如下配置：

```
-keep class com.huawei.dmsdpsdk.**{*;}
-keep interface com.huawei.dmsdpsdk.**{*;}
```
