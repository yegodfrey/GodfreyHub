# 概述

DeviceVirtualization（设备虚拟化） Engine提供三方应用使用虚拟外设的能力，三方应用App通过集成该Engine，可以方便使用外部的虚拟设备，包括但不限于摄像头、扬声器、显示器、麦克风、传感器、马达等外部设备能力以及相关器件的能力。

#### 兼容性说明

DV Engine目前只支持华为手机，当调用DV Engine接口的应用运行在不支持DV Engine的运行环境上时，系统会抛出NoClassDefFoundError。若调用Dv Engine接口运行在不支持此接口版本的华为手机上时，系统也会抛出NoClassDefFoundError。

因此，使用DV Engine的应用应进行兼容性判断。首先应该应判断当前运行环境是否支持DV Engine，然后判断当前Dv Engine服务的版本是否满足要求。

如下示例：CURRENT_KIT_VERSION是应用适配的华为DV Engine版本，需要应用自己记录，在应用内部需要判断当前手机上的DV Engine版本跟应用自己适配的DV Engine版本是否一致，如果不一致需要进行兼容性处理。

```
boolean isSupport = true;
try {
    //获取当前DV Engine服务的运行版本
    String version = DvKit.getVersion();
    if (version.compareTo(CURRENT_KIT_VERSION) < 0) {
        //当前DV Engine服务版本不满足应用的运行要求
        isSupport = false;
    }
} catch (NoClassDefFoundError e) {
    //当前运行环境不支持DV Engine
    isSupport = false;
    Log.e(TAG, "DvKit not exist", e);
}
if (isSupport) {
    //当前DV Engine服务版本满足应用的运行要求
    Intent intent = new Intent(MainActivity.this, DvKitDemoActivity.class);
    startActivity(intent);
}
```
