# 状态查询与订阅

* 实时查询穿戴设备可用空间、电量状态。
* 订阅穿戴设备连接状态、低电量告警、用户心率告警。
* 查询和订阅穿戴设备充电状态、佩戴状态、设备模式。

使用该接口前，需要向手机侧用户申请获取对应权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/requesting-user-authorization-0000001050819181)），否则接口将调用失败。

#### 查询穿戴设备可用存储空间

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getDeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getDeviceClient-android_content_Context-)方法，获取[DeviceClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120)对象。
3. 调用[getAvailableKbytes](https://developer.huawei.com/consumer/cn/doc/connectivity-References/deviceclient-0000001060779120#ZH-CN_TOPIC_0000001919950697__getAvailableKbytes-com_huawei_wearengine_device_Device-)方法，获取指定设备的可用存储空间。

   <br />

   ```
   // 步骤2：获取DeviceClient对象
   DeviceClient deviceClient = HiWear.getDeviceClient(this);

   // 步骤3：获取指定设备的存储空间
   if (connectedDevice != null && connectedDevice.isConnected()) {
       deviceClient.getAvailableKbytes(connectedDevice).addOnSuccessListener(new OnSuccessListener<Integer>() {
           @Override
           public void onSuccess(Integer integer) {
               // 返回指定设备可用存储空间千字节数（KB）
           }
       }).addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 处理查询指定设备可用存储空间失败相关的逻辑
           }
       });
   }
   ```

   <br />

#### 查询其他状态

除可用空间外，穿戴设备与运动健康的其他状态，可以调用[MonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorclient-0000001059980975)对象中的[query](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorclient-0000001059980975#ZH-CN_TOPIC_0000001874111238__query-com_huawei_wearengine_device_Device-com_huawei_wearengine_monitor_MonitorItem-)方法获取到。一次只能查询一个状态。

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getMonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getMonitorClient-android_content_Context-)方法，获取[MonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorclient-0000001059980975)对象。
3. 调用[query](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorclient-0000001059980975#ZH-CN_TOPIC_0000001874111238__query-com_huawei_wearengine_device_Device-com_huawei_wearengine_monitor_MonitorItem-)方法，查询指定指标状态。

   <br />

   * 通过[MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013)对象，查询指定指标状态。目前支持查询的状态如下：
     * "电量状态"字段：[MONITOR_POWER_STATUS](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_POWER_STATUS)。
     * "充电状态"字段：[MONITOR_CHARGE_STATUS](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_CHARGE_STATUS)。
     * "佩戴状态"字段：[MONITOR_ITEM_WEAR](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_ITEM_WEAR)。
     * "设备模式"字段：[MONITOR_ITEM_POWER_MODE](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#section1932264143916)。
   * 通过[MonitorData](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitordata-0000001060779124)对象，返回指定指标状态的查询结果。  
     示例代码：以查询"佩戴状态"为例

     ```
     // 步骤2：获取MonitorClient对象
     MonitorClient monitorClient = HiWear.getMonitorClient(this);

     // 步骤3：查询指定指标状态
     if (connectedDevice != null && connectedDevice.isConnected()) {
         monitorClient.query(connectedDevice, MonitorItem.MONITOR_ITEM_WEAR)
             .addOnSuccessListener(new OnSuccessListener<MonitorData>() {
                 @Override
                 public void onSuccess(MonitorData monitorData) {
                     // 处理查询成功相关的事情
                     int wearStatus = monitorData.asInt();
                     // 1：佩戴
                     // 2：未佩戴
                     if(wearStatus == 1){
                         // 处理佩戴状态相关的逻辑
                     }
                 }
             })
             .addOnFailureListener(new OnFailureListener() {
                 @Override
                 public void onFailure(Exception e) {
                     // 处理查询失败相关的事情
                 }
             });
     }
     ```

   <br />

#### 订阅单个状态

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getMonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getMonitorClient-android_content_Context-)方法，获取[MonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorclient-0000001059980975)对象。
3. 定义订阅任务的回调对象monitorListener。
4. 调用[register](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorclient-0000001059980975#ZH-CN_TOPIC_0000001874111238__register-com_huawei_wearengine_device_Device-com_huawei_wearengine_monitor_MonitorItem-com_huawei_wearengine_monitor_MonitorListener-)方法，订阅指定指标状态变化的订阅。

   <br />

   * 通过[MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013)对象，订阅穿戴设备与运动健康状态。目前支持的订阅状态如下：
     * "设备连接状态"字段： [MONITOR_ITEM_CONNECTION](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_ITEM_CONNECTION)。
     * "电量降低状态"字段：[MONITOR_ITEM_LOW_POWER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_ITEM_LOW_POWER)。
     * "充电状态"字段： [MONITOR_CHARGE_STATUS](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_CHARGE_STATUS)。
     * "佩戴状态"字段：[MONITOR_ITEM_WEAR](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_ITEM_WEAR)。
     * "心率告警"字段：[MONITOR_ITEM_HEART_RATE_ALARM](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#ZH-CN_TOPIC_0000001919950717__MONITOR_ITEM_HEART_RATE_ALARM)。
     * "设备模式"字段：[MONITOR_ITEM_POWER_MODE](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013#section1932264143916)。
   * 通过[MonitorListener](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorlistener-0000001059850655)对象，返回设备状态的订阅结果。

   示例代码：以订阅"佩戴状态"为例

   ```
   // 步骤2：获取MonitorClient对象
   MonitorClient monitorClient = HiWear.getMonitorClient(this);

   // 步骤3：定义订阅任务的回调对象
   MonitorListener monitorListener = new MonitorListener() {
       @Override
       public void onChanged(int errorCode, MonitorItem monitorItem, MonitorData monitorData) {
           // 处理穿戴设备的指定指标的状态变化
           // 判断设备的佩戴状态
           if(MonitorItem.MONITOR_ITEM_WEAR.getName().equals(monitorItem.getName())){
               int wearStatus = monitorData.asInt();
               // 1：佩戴
               // 2：未佩戴
               if(wearStatus == 1){
                   // 处理佩戴状态相关的逻辑
               }
           }       
       }
   };

   // 步骤4：订阅佩戴状态变化
   if (connectedDevice != null && connectedDevice.isConnected()) {
       monitorClient.register(connectedDevice, MonitorItem.MONITOR_ITEM_WEAR, monitorListener)
           .addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void successVoid) {
   	        // 处理监测任务订阅成功相关的事情
               }
           })
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
   		// 处理监测任务订阅失败相关的事情
               }
           });
   }
   ```
