# 应用间消息通信

在手机侧与穿戴设备侧构建应用到应用的通信隧道，用于收发第三方应用自定义的报文消息以及文件。实现手机应用和穿戴设备应用间的交互，为用户提供分布式场景和体验。比如手机应用发送音频文件到穿戴设备侧应用，实现在穿戴设备侧应用上播放音乐；手机应用发送暂停指令，实现穿戴设备音乐播放暂停等。

收发点对点消息前，需要向手机侧用户申请获取[DEVICE_MANAGER](https://developer.huawei.com/consumer/cn/doc/connectivity-References/permission-0000001059433005#ZH-CN_TOPIC_0000001874111234__DEVICE_MANAGER)权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/requesting-user-authorization-0000001050819181)），否则接口将调用失败。
> 说明
>
> 使用该功能前，请确保穿戴设备侧已有对应的第三方应用（参见[轻量级智能穿戴开发](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/lite-wearable-overview-0000001197577411-V3)、[智能穿戴设备开发](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/wearable-overview-0000001052065839-V3)）。
>
> * 手机App和穿戴设备App必须同时处于启动状态。
> * 当手机App启动，穿戴设备App没有启动时，手机App可以通过ping方法拉起穿戴设备App。手机App在调用ping接口拉起穿戴设备App后，如果需要立即向穿戴设备App发送消息，建议穿戴设备App在初始化完成后先给手机App发消息，手机App收到消息后再进行下一步操作。

## 手机侧应用检测穿戴设备侧应用是否安装

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。


2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getP2pClient-android_content_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712)对象。
3. 调用[isAppInstalled](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#section12211338104010)方法，查看是否安装指定的设备应用。

   ```screen
   // 步骤2：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);
   // 指定穿戴设备侧应用包名(bundleName)
   String devicePkgName = "com.*.*";

   // 步骤3：检测穿戴设备侧对应的第三方应用是否安装
   if (connectedDevice != null && connectedDevice.isConnected()) {
       p2pClient.isAppInstalled(connectedDevice, devicePkgName)
           .addOnSuccessListener(new OnSuccessListener<Boolean>() {
               @Override
               public void onSuccess(Boolean isAppInstalled) {
                   // 检测指定的设备侧应用是否安装任务执行成功相关逻辑
                   // true：已安装 false：未安装
               }
           })
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   // 检测指定的设备侧应用是否安装任务执行失败时三方应用处理相关的逻辑
               }
           });
   }
   ```

## 手机侧应用获取穿戴设备侧应用的版本号

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。


2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getP2pClient-android_content_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712)对象。
3. 调用[getAppVersion](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#section1545919591033)方法，获取指定设备对应的应用版本号。

   ```screen
   // 步骤2：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);
   // 指定穿戴设备侧应用包名(bundleName)
   String devicePkgName = "com.*.*";

   // 步骤3：获取穿戴设备侧对应的第三方应用的版本号
   if (connectedDevice != null && connectedDevice.isConnected()) {
       p2pClient.getAppVersion(connectedDevice, devicePkgName)
           .addOnSuccessListener(new OnSuccessListener<Integer>() {
               @Override
               public void onSuccess(Integer versionCode) {
                   // 获取设备应用版本号任务执行成功相关逻辑
                   // -1：该应用未安装
               }
           })
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   // 获取设备应用版本号任务执行失败时三方应用处理相关的逻辑
               }
           });
   }
   ```

## 手机侧应用检测穿戴设备侧对应的应用是否在线

在发送点对点消息前，可以用ping方法检测手机上的第三方应用是否能跟穿戴设备侧对应的第三方应用正常通信。

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getP2pClient-android_content_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712)对象。
3. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerPkgName-java_lang_String-)方法，指定需要ping通信的穿戴设备侧应用包名(bundleName)（可选，当没有指定包名时，默认需要ping通信的穿戴设备侧包名与手机侧第三方应用的包名一致）。
4. 调用[ping](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__ping-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_PingCallback-)方法，检测穿戴设备侧对应的第三方应用是否在线。

   > 说明
   >
   > 请确保穿戴设备和华为运动健康App处于连接状态。用户可进入App"设备"界面查看设备是否在线。开发者可调用[isConnected](https://developer.huawei.com/consumer/cn/doc/connectivity-References/device-0000001059980971#ZH-CN_TOPIC_0000001873951338__isConnected--)方法了解设备是否在线，如果返回false（true：已连接；false：未连接）提醒用户重新连接设备。

   ```screen
   // 步骤2：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);

   // 步骤3：先设置需要通信的穿戴设备侧应用包名(bundleName)
   String peerPkgName = "com.*.*";
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤4：检测穿戴设备侧对应的第三方应用是否在线
   if (connectedDevice != null && connectedDevice.isConnected()) {
       p2pClient.ping(connectedDevice, new PingCallback() {
           @Override
           public void onPingResult(int errCode) {
               // 与设备端ping通信的结果
               // errCode为200表示穿戴设备侧应用未安装，201表示穿戴设备侧应用已安装未启动，202表示穿戴设备侧应用已启动
           }
       }).addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               // ping任务执行成功时三方应用处理相关的逻辑
           }
       }).addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // ping任务执行失败时三方应用处理相关的逻辑
           }
       });
   }
   ```

   > 说明
   > * [ping](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__ping-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_PingCallback-)方法的调用有两个过程，一个是手机给设备发指令的过程，一个是设备给手机回响应的过程。
   > * [ping](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__ping-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_PingCallback-)方法的调用使用的是Task模式，通过OnSuccessListener和OnFailureListener回调来获取调用结果，属于手机给设备发指令的过程。如果回调到OnSuccessListener表示ping方法调用成功，如果回调到OnFailureListener表示ping方法调用失败。
   > * [ping](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__ping-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_PingCallback-)方法的[PingCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/pingcallback-0000001060938728)是收到设备返回信息接口，属于设备给手机回响应的过程。

## 穿戴设备侧应用拉起手机侧应用的前台服务

当穿戴设备侧应用要拉起Android手机侧应用的前台服务时（请参见[穿戴侧应用拉起对端设备侧应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/watch_p2p_communication#穿戴侧应用拉起对端设备侧应用)），需在手机侧应用的AndroidManifest.xml文件中添加如下配置。

**配置说明：**

通过此配置，手机侧应用可以控制允许拉起其前台服务的穿戴端应用列表。

* 配置项名称（name）：WearEngineRemoteAppInfoList，固定名称。
* 配置项值（value）：穿戴设备侧应用的信息，格式：穿戴侧应用包名#穿戴侧应用指纹。多个应用信息需要英文逗号隔开。 说明
  >
  > Android手机厂商对拉起前台服务可能存在限制，导致拉起前台服务失败。需引导用户对手机进行设置，包括允许后台运行、取消电池优化，允许关联启动等。

```screen
// AndroidManifest.xml文件配置示例
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
...
<application>
    <meta-data
        android:name="WearEngineRemoteAppInfoList"   
        android:value="PkgName1#Fingerprint1,PkgName2#Fingerprint2..." />
</application>
</manifest>
```

## 手机侧应用发送点对点消息或文件到穿戴设备侧应用

消息长度大小的限制为1KB。针对消息长度超过限制的情况可以采用发送文件（文件大小不超过100MB）的方式或进行消息分包控制。

手机侧实现发送消息和文件功能后，穿戴设备侧第三方应用需要对应实现接收消息和文件的功能，请参见：

* JS：[接收手机侧第三方应用发过来的点对点消息或文件](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052460491#section1361217411408)
* Java：[接收手机侧第三方应用发过来的点对点消息或文件](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052540469#section1361217411408)

### 发送点对点消息

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[Message.Builder](https://developer.huawei.com/consumer/cn/doc/connectivity-References/message_builder-0000001059850659)构造需要发送的消息[Message](https://developer.huawei.com/consumer/cn/doc/connectivity-References/message-0000001059781033)。


3. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getP2pClient-android_content_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712)对象。
4. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerPkgName-java_lang_String-)方法，指定需要通信的穿戴设备侧应用包名(bundleName)（当没有指定包名时，默认需要通信的穿戴设备侧包名与手机侧第三方应用的包名一致）。
5. 调用[setPeerFingerPrint](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerFingerPrint-java_lang_String-)方法，指定需要通信的穿戴设备侧应用签名证书指纹。具体请参见[如何获取应用指纹](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/wearengine_faq-9)。
6. 调用[send](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__send-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_Message-com_huawei_wearengine_p2p_SendCallback-)方法，从手机上的第三方应用发送简短消息到穿戴设备侧对应的第三方应用。

   * 通过[Message](https://developer.huawei.com/consumer/cn/doc/connectivity-References/message-0000001059781033)对象，定义第三方应用需要发送的消息。
   * 通过[onSendResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059290639#ZH-CN_TOPIC_0000001874111262__onSendResult-int-)(int resultCode)方法，[返回发送结果](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/errocode-0000001054450278#section394183995410)：成功、失败或其他异常。
   * 通过[onSendProgress](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059290639#ZH-CN_TOPIC_0000001874111262__onSendProgress-long-)(long progress)方法，查看发送进度。

     ```screen
     // 步骤2：需要发送的消息Message
     String messageStr = "Hello, Wear Engine!";
     Message.Builder builder = new Message.Builder();
     builder.setPayload(messageStr.getBytes(StandardCharsets.UTF_8));
     Message sendMessage = builder.build();

     // 步骤3：获取点对点通信对象
     P2pClient p2pClient = HiWear.getP2pClient(this);

     // 步骤4：指定需要通信的穿戴设备侧应用包名(bundleName)
     String peerPkgName = "com.*.*";
     p2pClient.setPeerPkgName(peerPkgName);

     // 步骤5：指定需要通信的穿戴设备侧应用签名证书指纹，轻量级智能穿戴设备侧应用指纹最大长度为127位
     String peerFingerPrint = "*******";
     p2pClient.setPeerFingerPrint(peerFingerPrint);

     // 步骤6：从手机上的第三方应用发送简短消息到穿戴设备侧对应的第三方应用
     // 创建回调方法
     SendCallback sendCallback = new SendCallback() {
         @Override
         public void onSendResult(int resultCode) {
             // resultCode为207表示消息发送成功，其他表示消息发送失败
         }
         @Override
         public void onSendProgress(long progress) {
         }
     };
     if(connectedDevice != null && connectedDevice.isConnected() && sendMessage != null && sendCallback != null){
         p2pClient.send(connectedDevice, sendMessage, sendCallback)
             .addOnSuccessListener(new OnSuccessListener<Void>() {
                 @Override
                 public void onSuccess(Void successVoid) {
                     // send任务执行成功时三方应用处理相关的逻辑
                 }
          })
            .addOnFailureListener(new OnFailureListener() {
                @Override
                public void onFailure(Exception e) {
                    // send任务执行失败时三方应用处理相关的逻辑
                }
            });
     }
     ```

### 发送文件

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。


2. 根据文件路径filePath，调用[Message.Builder](https://developer.huawei.com/consumer/cn/doc/connectivity-References/message_builder-0000001059850659)构造需要发送的文件[Message](https://developer.huawei.com/consumer/cn/doc/connectivity-References/message-0000001059781033)。
3. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getP2pClient-android_content_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712)对象。
4. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerPkgName-java_lang_String-)方法，指定需要通信的穿戴设备侧应用包名(bundleName)（当没有指定包名时，默认需要通信的穿戴设备侧包名与手机侧第三方应用的包名一致）。
5. 调用[setPeerFingerPrint](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerFingerPrint-java_lang_String-)方法，指定需要通信的穿戴设备侧应用签名证书指纹。具体请参见[如何获取应用指纹](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/wearengine_faq-9)。
6. 调用[send](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__send-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_Message-com_huawei_wearengine_p2p_SendCallback-)方法，从手机上的第三方应用发送文件到穿戴设备侧对应的第三方应用。

   * 通过[Message](https://developer.huawei.com/consumer/cn/doc/connectivity-References/message-0000001059781033)对象，定义第三方应用需要发送的文件。
   * 通过[onSendResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059290639#ZH-CN_TOPIC_0000001874111262__onSendResult-int-)(int resultCode)方法，返回发送结果：成功、失败或其他异常。
   * 通过[onSendProgress](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sendcallback-0000001059290639#ZH-CN_TOPIC_0000001874111262__onSendProgress-long-)(long progress)方法，查看发送进度。

   ```screen
   // 步骤2：构造需要发送的文件 Message
   String filePath = ".....";
   File sendFile = new File(filePath);
   Message.Builder builder = new Message.Builder();
   builder.setPayload(sendFile);
   Message fileMessage = builder.build();

   // 步骤3：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);

   // 步骤4：指定需要通信的穿戴设备侧应用包名(bundleName)
   String peerPkgName = "com.*.*";
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤5：指定需要通信的穿戴设备侧应用签名证书指纹
   String peerFingerPrint = "*******";
   p2pClient.setPeerFingerPrint(peerFingerPrint);

   // 步骤6：从手机上的第三方应用发送文件到穿戴设备侧对应的第三方应用
   // 创建发送文件的回调对象
   SendCallback sendCallback = new SendCallback() {
       @Override
       public void onSendResult(int resultCode) {
           // resultCode为207表示消息发送成功，其他表示消息发送失败
       }
       @Override
       public void onSendProgress(long progress) {
       }
   };
   // 发送文件到设备侧
   if(connectedDevice != null && connectedDevice.isConnected() && fileMessage != null && sendCallback != null){
       p2pClient.send(connectedDevice, fileMessage, sendCallback)
           .addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void successVoid) {
                   // send任务执行成功时三方应用处理相关的逻辑
               }
           })
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   // send任务执行失败时三方应用处理相关的逻辑
               }
           });
   }
   ```

   > 说明
   >
   > 手机应用发送文件给穿戴设备应用时收到错误码10（ERROR_CODE_INVALID_FILE），请检查手机侧应用是否有相关文件的访问权限。

### 取消发送文件

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。


2. 根据文件路径filePath，调用[FileIdentification.Builder](https://developer.huawei.com/consumer/cn/doc/connectivity-References/fileidentification_builder-0000001093318165)构造需要取消发送的文件标识信息[FileIdentification](https://developer.huawei.com/consumer/cn/doc/connectivity-References/fileidentification-0000001077679542)。
3. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getP2pClient-android_content_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712)对象。
4. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerPkgName-java_lang_String-)方法，指定需要通信的穿戴设备侧应用包名(bundleName)（当没有指定包名时，默认需要通信的穿戴设备侧包名与手机侧第三方应用的包名一致）。
5. 调用[cancelFileTransfer](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#section219165413392)方法，取消从手机上的第三方应用到穿戴设备侧对应的第三方应用的文件发送。

   * 通过[FileIdentification](https://developer.huawei.com/consumer/cn/doc/connectivity-References/fileidentification-0000001077679542)对象，定义第三方应用需要取消发送的文件标识信息。
   * 通过[onCancelFileTransferResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/cancelfiletransfercallback-0000001093458245#section19719193003813)(int errorCode)方法，返回取消发送结果：成功、失败或其他异常。

   ```screen
   // 步骤2：构造需要取消发送的文件标识信息FileIdentification
   String filePath = ".....";
   File cancelFile = new File(filePath);
   FileIdentification.Builder builder = new FileIdentification.Builder();
   builder.setFile(cancelFile);
   FileIdentification fileIdentification = builder.build();

   // 步骤3：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);

   // 步骤4：指定需要通信的穿戴设备侧应用包名(bundleName)
   String peerPkgName = "com.*.*";
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤5：从手机上的第三方应用发送文件到穿戴设备侧对应的第三方应用
   // 创建取消发送文件的回调对象
   CancelFileTransferCallBack cancelFileTransferCallBack = new CancelFileTransferCallBack() {
       @Override
       public void onCancelFileTransferResult(int errCode) {
           /*
            * 常见几个错误码解释如下：
            * errCode:207 取消文件发送成功
            * errCode:1990020004 取消发送文件失败
            * errCode:5
            * （1）调用取消发送文件接口，传的参数为空。
            * （2）取消发送的文件不存在、文件不在发送过程中或者对端包名填写错误
            */
           Log.d(TAG, "cancel send file callBack, errCode: " + errCode);
       }
   };

   // 取消发送文件到设备侧
   if (connectedDevice != null && connectedDevice.isConnected() && fileIdentification != null
       && cancelFileTransferCallBack != null) {
       p2pClient.cancelFileTransfer(connectedDevice, fileIdentification, cancelFileTransferCallBack)
           .addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void successVoid) {
                   Log.d(TAG, "cancel send file submission success");
                   // 取消文件发送任务执行成功时三方应用处理相关的逻辑
               }
           })
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   Log.d(TAG, "cancel send file onFailure e: " + e.getMessage());
                   // 取消文件发送任务执行失败时三方应用处理相关的逻辑
               }
           });
   }
   ```

   > 说明
   > * [cancelFileTransfer](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#section219165413392) 仅支持取消正在发送的文件。
   > * 如果取消发送的文件不存在、文件不在发送过程中或者对端包名填写错误都会报非法参数错误（Invalid argument），错误码5。

## 接收穿戴设备侧应用发过来的点对点消息或文件

1. 参见[穿戴设备信息查询](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/device-connection-management-0000001050779152)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716)中的[getP2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/hiwear-0000001060938716#ZH-CN_TOPIC_0000001873951394__getP2pClient-android_content_Context-)方法，获取[P2pClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712)对象。
3. 调用[setPeerPkgName](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerPkgName-java_lang_String-)方法，指定需要通信的穿戴设备侧应用包名(bundleName)（当没有指定包名时，默认需要通信的穿戴设备侧包名与手机侧第三方应用的包名一致）。
4. 调用[setPeerFingerPrint](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__setPeerFingerPrint-java_lang_String-)方法，指定需要通信的穿戴设备侧应用签名证书指纹。具体请参见[如何获取应用指纹](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/wearengine_faq-9)。


5. 调用[registerReceiver](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__registerReceiver-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_Receiver-)方法，手机第三方应用接收穿戴设备侧第三方应用发过来的消息或者文件，其实现原理即是向Wear Engine注册一个监测器。

   调用[onReceiveMessage](https://developer.huawei.com/consumer/cn/doc/connectivity-References/receiver-0000001060460920#ZH-CN_TOPIC_0000001874111202__onReceiveMessage-com_huawei_wearengine_p2p_Message-)方法，处理穿戴设备侧发过来的消息或者文件。文件会保存在"/data/data/{三方应用包名}/files/WearEngine" 路径下。
   > 说明
   >
   > 若开发者集成的SDK版本为5.0.0.301及以下，调用[registerReceiver](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__registerReceiver-com_huawei_wearengine_device_Device-com_huawei_wearengine_p2p_Receiver-)和[onReceiveMessage](https://developer.huawei.com/consumer/cn/doc/connectivity-References/receiver-0000001060460920#ZH-CN_TOPIC_0000001874111202__onReceiveMessage-com_huawei_wearengine_p2p_Message-)2个方法，只能接收点对点消息。若集成的SDK版本是5.0.1.300及以上，则还可以接收文件。

   ```screen
   // 步骤2：获取点对点通信对象
   P2pClient p2pClient = HiWear.getP2pClient(this);

   // 步骤3：指定需要通信的穿戴设备侧应用包名(bundleName)
   String peerPkgName = "com.*.*";
   p2pClient.setPeerPkgName(peerPkgName);

   // 步骤4：指定需要通信的穿戴设备侧应用签名证书指纹
   String peerFingerPrint = "*******";
   p2pClient.setPeerFingerPrint(peerFingerPrint);

   // 步骤5：手机第三方应用接收穿戴设备侧第三方应用发过来的消息或文件
   Receiver receiver = new Receiver() {
       @Override
       public void onReceiveMessage(Message message) {
           if (message.getType() == Message.MESSAGE_TYPE_DATA) {
               // 处理穿戴设备侧第三方App发过来的消息
           } else if (message.getType() == Message.MESSAGE_TYPE_FILE) {
               // 处理穿戴设备侧第三方App发过来的文件
           }
       }
   };
   if(connectedDevice != null && connectedDevice.isConnected()){
       HiWear.getP2pClient(this).registerReceiver(connectedDevice, receiver)
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   // 手机侧第三方应用接收消息或文件失败
               }
           })
           .addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void successVoid) {
                   // 手机侧第三方应用接收消息或文件成功
               }
           });
   }
   ```


6. 调用[unregisterReceiver](https://developer.huawei.com/consumer/cn/doc/connectivity-References/p2pclient-0000001061098712#ZH-CN_TOPIC_0000001920110385__unregisterReceiver-com_huawei_wearengine_p2p_Receiver-)方法，手机第三方应用取消接收穿戴设备侧第三方应用发过来的消息或者文件，其实现原理即是向Wear Engine取消已经注册的监测器。

   ```screen
   // 步骤6：手机第三方应用取消接收穿戴设备侧第三方应用发过来的消息或文件
   HiWear.getP2pClient(this).unregisterReceiver(receiver)
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void successVoid) {
               // 手机侧第三方应用取消接收消息或文件成功
           }
       })
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 手机侧第三方应用取消接收消息或文件失败
           }
       });
   ```
