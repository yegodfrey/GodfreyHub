# 应用间消息通信

在手机侧与穿戴设备侧构建应用到应用的通信隧道，用于收发第三方应用自定义的报文消息以及文件。实现手机应用和穿戴设备应用间的交互，为用户提供分布式场景和体验。比如手机应用发送音频文件到穿戴设备侧应用，实现在穿戴设备侧应用上播放音乐；手机应用发送暂停指令，实现穿戴设备音乐播放暂停等。

收发点对点消息前，需要向手机侧用户申请获取[DEVICE_MANAGER](#ZH-CN_TOPIC_0000001875158886__ZH-CN_TOPIC_0000001059433005__DEVICE_MANAGER)权限的授权（参见[请求用户授权](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/request-user-authorization-ios-0000001920933293)），否则接口将调用失败。

## 手机侧应用检测穿戴设备侧应用是否安装

1. 参见[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getP2PClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section124399485412)方法，获取[P2PClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)对象。
3. 调用[isAppInstalled](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesp2pclient-class-0000001897319430#section459201316365)方法，查看是否安装指定的设备应用。

   ```screen
   HiWear.getP2PClient().isAppInstalled(currentDevice, targetPkgName: "com.xxx" , srcPkgName: "com.yyy") { status, data in
       if (status == .WESErrorCodeSuccess) {
           let dataString :String = data ?? ""
           // 应用安装状态查询成功，信息为 dataString
       } else {
           // 应用安装状态查询失败，错误码为 status.rawValue
       }
   }
   ```

## 手机侧应用获取穿戴设备侧应用的版本号

1. 参见[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getP2PClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section124399485412)方法，获取[P2PClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)对象。
3. 调用[getAppVersion](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesp2pclient-class-0000001897319430#section156970158362)方法，获取指定设备对应的应用版本号。

   ```screen
   HiWear.getP2PClient().getAppVersion(currentDevice, targetPkgName: "com.xxx" , srcPkgName: "com.yyy") { status, data in
       if (status == .WESErrorCodeSuccess) {
           var dataString :String = data ?? ""
           if data == "-1" {
               dataString = "未安装"
           }
           // 应用版本号查询成功，信息为dataString
       } else {
           // 应用版本号查询失败，错误码为 status.rawValue
       }
   }
   ```

## 手机侧应用检测穿戴设备侧对应的应用是否在线

在发送点对点消息前，可以用ping方法检测手机上的第三方应用是否能跟穿戴设备侧对应的第三方应用进行正常通信。

1. 参见[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)章节，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 调用[HiWear](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-0000001897479338)中的[getP2PClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-hiwear-class-0000001898103106#section124399485412)方法，获取[P2PClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesp2pclient-0000001897479334)对象。
3. 调用[ping](https://developer.huawei.com/consumer/cn/doc/connectivity-References/we-ios-wesp2pclient-class-0000001897319430#section229118515360)方法，指定需要ping通信的穿戴设备侧应用包名（可选，当没有指定包名时，默认需要ping通信的穿戴设备侧包名与手机侧第三方应用的包名一致）。
4. 调用ping方法，检测穿戴设备侧对应的第三方应用是否在线。

   ```screen
   HiWear.getP2PClient().ping(currentDevice, srcPkgName: "com.xxx", destPkgName:
       "com.yyy") { status in
       if status == .WESErrorCodeP2PWatchAPPRunning {
           // ping成功
       } else {
           // ping失败，错误码为status.rawValue
       }
   }
   ```

> 说明
>
> 1. 对于Ping接口，iOS WearEngine SDK只支持手机侧应用Ping手表侧应用，不支持手表调用Ping接口唤起iOS手机侧三方应用。
> 2. Ping接口拉起手表侧应用后，手表侧应用需要注册消息监听，才能接收手机侧的消息。如果需要立刻从手机侧发送消息到手表侧应用，建议手表侧应用在启动完成后，发送一条消息到手机侧应用。确保手表侧能正常接收消息后，手机侧再发送消息。

## 手机侧应用发送点对点消息

消息长度大小的限制为1KB。针对消息长度超过限制的情况可以采用消息分包控制。

手机侧实现发送消息功能后，穿戴设备侧第三方应用需要对应实现接收消息的功能，请参见：

* JS：[接收手机侧第三方应用发过来的点对点消息](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052460491#section1361217411408)
* Java：[接收手机侧第三方应用发过来的点对点消息](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052540469#section1361217411408)

1. 参见[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 创建发送方的WESIdentityInfo对象，填写手机侧第三方app的包名和指纹。指纹信息是用于手表侧校验app信息是否正确。iOS应用没有指纹信息，开发者可以填写任意文本作为指纹信息。
3. 创建接收方的WESIdentityInfo对象，填写穿戴设备侧第三方app的包名和指纹。具体请参见[如何获取应用指纹](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/wearengine_faq-9)。


4. 创建WESP2PMessage对象，构造发送的消息message。
5. 创建WESP2PData对象，配置是否为TLV格式。
6. 调用TLVDataCmm的init方法，构造数据。创建TLVDataCmm对象，构造TLV格式数据。
7. 将TLV格式的数据赋值到message消息中。
8. 调用HiWear中的getP2pClient方法，获取P2pClient对象。调用send方法，从手机上的第三方应用发送简短消息到穿戴设备侧对应的第三方应用。

   * 通过callback参数，返回发送结果。
   * 通过WearEngineServerErrorCode status参数，[返回发送结果](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/errocode-0000001054450278#section394183995410)：WESErrorCodeCommSuccess表示成功，其他错误码为失败。

   ```screen
   @objc func sendDataBtnAction() {
       sendDataBtn.isSelected = !sendDataBtn.isSelected
       // 模型转换
       let srcInfo = WESIdentityInfo()
       srcInfo.mPackageName = "XXXX" // 源App的包名
       srcInfo.mFingerPrint = "YYYY" // 源App的指纹
    
       let destInfo = WESIdentityInfo();
       destInfo.mPackageName = "XXXX" // 目标App的包名
       destInfo.mFingerPrint = "YYYY" // 目标App的指纹
    
       let message = WESP2PMessage();
       message.type = WESP2PMessageType.data;
    
       let wesP2PData = WESP2PData()
       wesP2PData.isTLVFormat = false
    
       let unitIsOpen = "XXXX" // 传输的数据
       let tlv = TLVDataCmm.init(0, value: unitIsOpen.data(using: .utf8))
       let tlvData = tlv?.value ?? NSMutableData()
    
       let rootCmm = TLVDataCmm(type: 0x07, withLen: Int32(tlvData.count))
       let rootCmmData = rootCmm?.tlvToData() ?? Data()
    
       let tmpPayloadData = NSMutableData.init(data: rootCmmData)
       tmpPayloadData.append(tlvData as Data)
       wesP2PData.payloadData = tmpPayloadData.copy() as? Data
       message.p2pData = wesP2PData.copy() as? WESP2PData
       HiWear.getP2PClient().send(self.currentDevice, message: message, srcInfo: srcInfo, 
           destInfo: destInfo) { status, progress in
           if status == .WESErrorCodeCommSuccess {
               // p2p传输成功
           } else {
               // p2p传输失败，错误码：status.rawValue
           }
       }
   }
   ```

## 接收穿戴设备侧应用发过来的点对点消息

创建穿戴设备侧发送过来的点对点消息的监听。

1. 参见[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 创建发送方的WESIdentityInfo对象，填写穿戴设备侧第三方App的包名和指纹。具体请参见[如何获取应用指纹](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/wearengine_faq-9)。
3. 创建接收方的WESIdentityInfo对象，填写手机侧第三方App的包名和指纹。指纹信息是用于手表侧校验app信息是否正确。iOS应用没有指纹信息，开发者可以填写任意文本作为指纹信息。
4. 调用HiWear中的getP2pClient方法，获取P2pClient对象，调用registerReceiver方法注册一个监听器。

   ```screen
   let srcInfo = WESIdentityInfo()
   srcInfo.mPackageName = "XXXX" // 源App的包名
   srcInfo.mFingerPrint = "YYYY" // 源App的指纹
   let destInfo = WESIdentityInfo()
   destInfo.mPackageName = "XXXX" // 目标App的包名
   destInfo.mFingerPrint = "YYYY" // 目标App的指纹
   receiverCallback = {status, message in
       if status != .WESErrorCodeSuccess {
           // 注册监听失败，错误码 status.rawValue
           return
       }
       if (status == .WESErrorCodeSuccess && message == nil) {
           // 注册监听成功 包名: destInfo.mPackageName 指纹: destInfo.mFingerPrint
       }
       if (message != nil) {
           let response = message?.data
           let responseString :String = String.init(data: response ?? Data() , encoding: .utf8) ?? ""
           if (responseString.count > 0) {
               // p2p 接收信息：responseString
           } else {
               let string = message?.data.toHexString() ?? ""
               // p2p 接收的数据为string
           }
       }}
   HiWear.getP2PClient().registerReceiver(currentDevice, srcInfo: srcInfo, destInfo: destInfo, receiverCallback: receiverCallback)
   ```

## 取消对穿戴设备侧点对点消息的监听

取消点对点消息的监听。

1. 参见[查询可用穿戴设备](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/check-availabla-dev-ios-0000001921237861)，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 创建发送方的WESIdentityInfo对象，填写穿戴设备侧第三方app的包名和指纹。
3. 创建接收方的WESIdentityInfo对象，填写手机侧第三方app的包名和指纹。
4. 调用HiWear中的getP2pClient方法，获取P2pClient对象，调用unRegisterReceiver方法取消监听。

   ```screen
   let srcInfo = WESIdentityInfo()
   srcInfo.mPackageName = "XXXX" // 源App的包名
   srcInfo.mFingerPrint = "YYYY" // 源App的指纹
   let destInfo = WESIdentityInfo()
   destInfo.mPackageName = "XXXX" // 目标App的包名
   destInfo.mFingerPrint = "YYYY" // 目标App的指纹
   HiWear.getP2PClient().unRegisterReceiver(currentDevice, srcInfo: srcInfo, destInfo: destInfo) { status, message in
       if status != .WESErrorCodeSuccess {
           // 取消注册监听失败，错误码status.rawValue
           return
       }
       if (status == .WESErrorCodeSuccess) {
           // 取消监听成功 包名:destInfo.mPackageName 指纹: destInfo.mFingerPrint
       }
   }
   ```

## 手机侧应用发送文件

文件大小限制为100M。

手机侧实现发送文件后，穿戴设备侧第三方应用需要对应实现接收文件的功能，请参见：

* JS：[接收手机侧第三方应用发过来的点对点消息或文件](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052460491#section1361217411408)。
* JAVA：[h2接收手机侧第三方应用发过来的点对点消息或文件](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/send-message-0000001052540469#section1361217411408)。

1. 参见查询可用穿戴设备，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 创建发送方的WESIdentityInfo对象，填写手机侧第三方app的包名和指纹。指纹信息是用于手表侧校验app信息是否正确。iOS应用没有指纹信息，开发者可以填写任意文本作为指纹信息。
3. 创建接收方的WESIdentityInfo对象，填写穿戴设备侧第三方app的包名和指纹。具体请参见[如何获取应用指纹](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/wearengine_faq-9)。
4. 创建WESP2PMessage对象，根据文件路径和文件名构造发送的消息message。
5. 调用HiWear中的getP2pClient方法，获取P2pClient对象。调用send方法，从手机上的第三方应用发送文件到穿戴设备侧对应的第三方应用。
6. 通过callback参数，返回发送结果。
7. 通过WearEngineServerErrorCode status参数，返回发送结果：WESErrorCodeSuccess表示正常传输回调，WESErrorCodeCommSuccess表示传输成功，其他错误码为失败。

   ```screen
   @objc func sendFile() {
       // 模型转换
       let srcInfo = WESIdentityInfo()
       srcInfo.mPackageName = "XXXX" // 源App的包名
       srcInfo.mFingerPrint = "YYYY" // 源App的指纹

       let destInfo = WESIdentityInfo();
       destInfo.mPackageName = "XXXX" // 目标App的包名
       destInfo.mFingerPrint = "YYYY" // 目标App的指纹

       let fileName = (filePath as NSString).lastPathComponent
       let message = WESP2PMessage.initWithFilePath(filePath, withFileName: fileName)
   	
       var lastProgress: Int32 = -1
       HiWear.getP2PClient().send(self.currentDevice, message: message, srcInfo: srcInfo, destInfo: destInfo) { status, progress in
           if status == .WESErrorCodeSuccess {
               // 正常传输回调
               if progress != lastProgress { // 进度滤重，大文件的时候会存在持续回调
                   // 正常处理文件进度
                   lastProgress = progress
               }
           } else {
               // p2p文件发送结果，错误码：status.rawValue
           }
       }
   }
   ```

## 手机侧应用取消发送文件

1. 参见查询可用穿戴设备，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 创建发送方的WESIdentityInfo对象，填写手机侧第三方app的包名和指纹。
3. 创建接收方的WESIdentityInfo对象，填写穿戴设备侧第三方app的包名和指纹。
4. 创建WESFileIdentification对象，填写文件路径和文件名。
5. 调用HiWear中的getP2pClient方法，获取P2pClient对象。调用cancelFileTransfer方法，从手机上的第三方应用取消发送文件到穿戴设备侧对应的第三方应用。
6. 通过callback参数，返回发送结果。
7. 通过WearEngineServerErrorCode status参数，返回取消发送结果，WESErrorCodeCommSuccess表示传输成功，其他错误码为失败。

   ```screen
   @objc func cancelSendFile() {
       // 模型转换
       let srcInfo = WESIdentityInfo()
       srcInfo.mPackageName = "XXXX" // 源App的包名
       srcInfo.mFingerPrint = "YYYY" // 源App的指纹

       let destInfo = WESIdentityInfo();
       destInfo.mPackageName = "XXXX" // 目标App的包名
       destInfo.mFingerPrint = "YYYY" // 目标App的指纹
       let fileName = (filePath as NSString).lastPathComponent
       let fileIdentification = WESFileIdentification()
       fileIdentification.fileName = fileName
       fileIdentification.filePath = filePath

       HiWear.getP2PClient().cancelFileTransfer(self.currentDevice, fileIdentification: fileIdentification, srcInfo: srcInfo,
           destInfo: destInfo) { status in
           if status == WearEngineServerErrorCode.WESErrorCodeCommSuccess.rawValue { // 错误码207，业务成功
               // 取消文件发送成功
           } else {
               // 取消文件发送失败
           }
       }
   }
   ```

## 监听穿戴侧应用发送文件

创建穿戴设备侧发送文件消息的监听。

1. 参见查询可用穿戴设备，获取已配对的设备列表，并从设备列表中选定需要通信的设备。
2. 创建发送方的WESIdentityInfo对象，填写穿戴设备侧第三方App的包名和指纹。
3. 创建接收方的WESIdentityInfo对象，填写手机侧第三方App的包名和指纹。
4. 调用HiWear中的getP2pClient方法，获取P2pClient对象，调用registerReceiver方法注册一个监听器。

   ```screen
   let srcInfo = WESIdentityInfo()

       if status != .WESErrorCodeSuccess {
           // 注册监听失败，错误码 status.rawValue
           return
       }
       if (status == .WESErrorCodeSuccess && message == nil) {
           // 注册监听成功 包名: destInfo.mPackageName 指纹: destInfo.mFingerPrint
       }
       if (message != nil) {
           if message?.type == WESP2PMessageType.file { // 2是文件消息类型
               if let path = message?.filePath {
                   // 文件路径正确，处理文件接收结果
               } else {
                   // 文件路径不存在
               }
           } else {
               let response = message?.data
               let responseString :String = String.init(data: response ?? Data() , encoding: .utf8) ?? ""
               if (responseString.count > 0) {
                   // p2p 接收信息：responseString
               } else {
                   let string = message?.data.toHexString() ?? ""
                   // p2p 接收的数据为string
               }
           }
       }

   HiWear.getP2PClient().registerReceiver(currentDevice, srcInfo: srcInfo, destInfo: destInfo, receiverCallback: receiverCallback)
   ```

## 取消监听穿戴设备侧应用发送文件

取消文件发送的监听，代码实现与"取消点对点消息的监听"一致，具体请参见[取消对穿戴设备侧点对点消息的监听](#section23191541108)。
