# 添加权限（可选）

在实现[应用间消息通信-发送文件](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-0000001051059209#section17422551112517)功能时，如您的应用targetSdkVersion符合19 ≤ targetSdkVersion ≤ 29，且需要发送的文件位于外部存储应用专属目录之外，则需要获取READ_EXTERNAL_STORAGE权限。

1. 打开**AndroidManifest.xml**文件。

   **图1**打开AndroidManifest.xml文件   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241210153036.84966536634918671614103318835246:50001231000000:2800:670C057E63CB31F629E392EAE1B2390567F5023B0E2A17D48983636857EC4D2E.png?needInitFileName=true?needInitFileName=true)

2. 在"application"中添加读取外部存储权限。

   ```screen
   <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
   ```

   **图2**添加读取外部存储权限   
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20241210153036.50001035574783191431345362391615:50001231000000:2800:69B6F9FF0734CEFDCAEEF08812CF06693BEF0F737AFDC66044741703335204D1.png?needInitFileName=true?needInitFileName=true)

3. 打开代码java文件，在代码中动态申请外部存储权限，可参考如下示例。

   ```screen
   String[] permissionsStorage = {Manifest.permission.READ_EXTERNAL_STORAGE};
   int requestExternalStorage = 1;
   int permission = ActivityCompat.checkSelfPermission(this, Manifest.permission.READ_EXTERNAL_STORAGE);
   if (permission != PackageManager.PERMISSION_GRANTED) {
       ActivityCompat.requestPermissions(this, permissionsStorage, requestExternalStorage);
   }
   ```
