# 添加权限（可选）

在实现[应用间消息通信-发送文件](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/phone-send-message-0000001051059209#ZH-CN_TOPIC_0000001874111046__section17422551112517)功能时，如您的应用targetSdkVersion符合19 ≤ targetSdkVersion ≤ 29，且需要发送的文件位于外部存储应用专属目录之外，则需要获取READ_EXTERNAL_STORAGE权限。

1. 打开**AndroidManifest.xml**文件。

   **图1**打开AndroidManifest.xml文件   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/ZvSOmh5sSYWV5Kq5oVpq-w/zh-cn_image_0000001873951250.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=9DA09A70A4A41E2BC50FFEA54ADEAF049AF4188BC9B4117AFA1648D69377A0D1)

2. 在"application"中添加读取外部存储权限。

   ```screen
   <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
   ```

   **图2**添加读取外部存储权限   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/0HUkjfQcTpuKtliLqhMFoQ/zh-cn_image_0000001873951246.png?HW-CC-KV=V1&HW-CC-Date=20261010T040630Z&HW-CC-Expire=31536000000&HW-CC-Sign=985879A2D396481D4E648013A2291B97DF175F8177943C961B6B320DF64DD887)

   注意：Android 13以上版本READ_EXTERNAL_STORAGE权限已经失效，读取外部存储媒体文件需要增加以下三个细分媒体权限，并且动态申请对应权限：

   ```screen
   <uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
   <uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
   <uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
   ```

3. 打开代码java文件，在代码中动态申请外部存储权限，可参考如下示例。

   ```screen
   String[] permissionsStorage = {Manifest.permission.READ_EXTERNAL_STORAGE};
   int requestExternalStorage = 1;
   int permission = ActivityCompat.checkSelfPermission(this, Manifest.permission.READ_EXTERNAL_STORAGE);
   if (permission != PackageManager.PERMISSION_GRANTED) {
       ActivityCompat.requestPermissions(this, permissionsStorage, requestExternalStorage);
   }
   ```
