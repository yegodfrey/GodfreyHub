# 5.0.0(12)

#### 版本概述

欢迎开发者进入HarmonyOS NEXT。暌违一年，HarmonyOS NEXT终于在万千开发者的期待下从幕后走向台前。

HarmonyOS NEXT采用全新升级的系统架构，贯穿HarmonyOS全场景体验的底层优化，系统更流畅，隐私安全能力更强大，将给您带来更高效、更流畅、更便捷、更安全的智能化操作体验。

对于开发者，尤其是从HarmonyOS 3.1/4.0进入HarmonyOS NEXT的开发者而言，将体验到更加丰富和完善的应用开发能力、更加流畅美观的UX效果，更加智能易用的开发工具等。

在HarmonyOS NEXT经过概念阶段、开发者体验阶段、消费者体验阶段的打磨后，正式以HarmonyOS 5.0面向消费者发布。

HarmonyOS 5.0.0(12)版本是以5.0.0(12) Release为核心的HarmonyOS全套开发套件（含SDK及开发工具DevEco Studio）。开发者可基于Release状态的开发套件进行应用开发并正式上架华为应用市场。

#### 新增和增强特性

#### 元服务框架

* 程序框架服务（Ability Kit）：元服务API的开放能力范围增强，新增元服务专有启动API。
* 对于元服务，服务卡片变更为可选项。不创建元服务卡片，可通过负一屏的元服务图标作为元服务入口。
* 服务卡片：面对需要实时更新信息的应用卡片，Push Kit向开发者提供了卡片刷新服务。应用可以将重要信息或操作前置到卡片，以达到服务直达、减少体验层级的目的。  

#### UI

方舟UI框架（ArkUI）：

* 开放XComponent组件，满足开发者较为复杂的自定义绘制需求，可与AVPlayer配合使用，完成视频播放。
* 开放MeasureText文本计算能力，可实现折叠展开功能的计算。
* 新增提供元服务导航根视图容器组件（AtomicServiceNavigation），可作为Page页面的根容器使用。
* 新增提供元服务页签容器组件（AtomicServiceTabs），对Tabs组件一些不需提供给用户自定义设计的属性进行简化。
* 新增提供元服务弹框组件（InterstitialDialogAction），用于在保持当前的上下文环境时，临时展示用户需关注的信息或待处理的操作，用户点击弹框的不同区域可以触发相应的动作。

除此之外，新增支持Observer、窗口等大量API，具体可查看[元服务API集](https://developer.huawei.com/consumer/cn/doc/atomic-references/atomic-apis-intro)。  

#### Web

* 新增提供元服务Web（AtomicServiceWeb）组件，用于在元服务内显示Web页面内容，为开发者提供Web页面加载、页面交互等能力。  

#### 后台任务

后台任务开发服务（Background Tasks Kit）：首次开放元服务API能力，支持元服务申请长时任务。  

#### 媒体

* 相机（Camera Kit）：首次开放元服务API能力，提供Camera Picker能力。
* 媒体会话（AVSession Kit）：首次开放元服务API能力，提供投播组件、切换音频设备能力。
* 媒体服务（Media Kit）：
  * 元服务API的开放能力范围增强，提供音频录制的相关能力。
  * 进一步开放AVPlayer能力，可使用AVPlayer开发视频播放功能，支持清晰度切换、倍速播放等能力。

* 音视频播控服务（AVSession Kit）：进一步开放AVSession能力，元服务可完成音视频跨设备投播。
* 媒体文件管理服务（Media Library Kit）：
  * 开放媒体库能力，支持Photo Picker组件、Album Picker组件等能力。
* 支持"使用安全控件创建媒体资源"的方式。无需在元服务中申请相册管理模块权限，即可创建媒体资源。

* 设备证书服务（Device Certificate Kit）：首次开放元服务API能力，支持证书算法库能力。

#### 文件

文件基础服务（Core File Kit）：

* 元服务API的开放能力范围增强，提供文件选择、保存Picker能力。
* 支持选择音频文件相关接口AudioViewPicker，适用于音频类型文件的选择。  

#### 网络

域名管控框架：新增开放能力，支持服务器域名管控。  

#### 基础通信

短距通信服务（Connectivity Kit）：元服务API的开放能力范围增强，提供蓝牙、NFC、WIFI基础能力。  

#### 联系人

联系人服务（Contacts Kit）：元服务API的开放能力范围增强，提供添加联系人能力。  

#### 本地化开发服务

本地化开发服务（Localization Kit）：元服务API的开放能力范围增强，提供国际化、本地化等能力。

* 国际化（Internationalization）是系统提供的一套能力集，支持设置区域特性、时区和夏令时等，满足多语言多文化的设计需求。
* 本地化（Localization）在元服务定制阶段，是开发者为满足不同地区用户在语言和文化方面的需求，针对具体的目标语言对元服务进行翻译和定制，过程包括配置多语言等资源翻译、敏感禁忌检查和测试。支持拼音转换能力。  

#### AI能力

场景化视觉服务（Vision Kit）：首次开放元服务API能力，集成了视觉类AI能力，包括人脸活体验证（interactiveLiveness）能力、卡证识别（CardRecognition）能力、文档扫描（DocumentScanner）能力。  

#### ArkTS语言基础类库

方舟编程语言（ArkTS）：新增支持并发、ArkTS容器库、ArkTS基础库等大量API，满足元服务对于工具类库的诉求。  

#### 天气

天气服务（Weather Service Kit）：首次开放元服务API能力。Weather Service Kit融合了多家气象行业TOPs供应商，提供专业、精准、稳定的超本地化天气预报服务，帮助开发者为用户提供更贴心的本地生活服务，支撑行业客户防灾减灾、降本增效。开发者可以轻松地在HarmonyOS应用/元服务中获取天气数据。  

#### 云开发

云开发服务（Cloud Foundation Kit）：首次开放元服务API能力，提供云函数、云数据库、云存储等云端服务。  

#### 设备管理

基础服务（Basic Services Kit）：元服务API的开放能力范围增强，提供获取设备电量能力。  

#### 帐号

华为帐号服务（Account Kit）：元服务API的开放能力范围增强，提供全局收货地址、全局发票抬头管理能力。  

#### 推送

应用内支付服务（IAP Kit）：首次开放元服务API能力，提供便捷的应用内支付体验和简便的接入流程。

广告服务（Ads Kit）：首次开放元服务API能力，依托华为终端平台与数据能力为开发者提供流量变现服务，  

#### 运动健康

华为运动健康服务（Health Service Kit）：首次开放元服务API能力，开发者可获取运动健康数据，基于多种类型数据构建运动健康领域应用与服务，为用户打造丰富、便捷、专业的运动健康场景体验。  

#### 场景化组件

#### 变更说明

#### ArkUI

变更原因

RichText当前功能不适用于元服务，接口下线不再支持用于元服务，编译和上架均会报错。

变更影响

此变更涉及应用适配。

变更后，不再支持元服务调用RichText组件。

变更发生版本

从HarmonyOS SDK 5.0.0 beta5（API12）开始。

变更的接口/组件

变更前：支持元服务使用RichText组件。

变更后：不支持使用RichText组件，可使用AtomicServiceWeb/Web/ArkUI原生替代。

适配指导

可参考如下方式代替 RichText(content:string) 的用法。

* （推荐）富文本内容放到H5页面中，使用AtomicServiceWeb({ src: $rawfile("index.html") })。参考指导：[AtomicServiceWeb](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ohos-atomicservice-atomicserviceweb)
* 针对在HarmonyOS NEXT Developer Preview时，申请并获得Web权限的开发者，可以使用Web组件代替。但仍建议此类开发者尽快切换到AtomicServiceWeb组件。  
  示例可参考：

  ```
  import webview from '@ohos.web.webview';

  @Component
  export default struct AsRichText {
    @Prop html?: string;
    @State pageHeight: string | number = '10';
    controllerWeb: webview.WebviewController = new webview.WebviewController();

    build() {
      Web({ controller: this.controllerWeb, src: `data:text/html;utf-8,${this.html}` })
        .width("100%")
        .height(this.pageHeight)
        .onPageEnd(() => this.handlePageEnd());
    }

    async handlePageEnd() {
      const height = await this.controllerWeb.runJavaScript('document.body.scrollHeight');
      this.pageHeight = height != null ? (height + 'px') : 30;
    }
  }
  ```

  参考指导：[Webview.loadData](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arkts-apis-webview-webviewcontroller#loaddata)
* 使用原生ArkUI的方法代替，将富文本内容解析为原生的Text/Image等组件渲染。  

#### Web

变更原因

根据元服务的产品特点，独立提供元服务Web组件。

变更影响

变更前：

可使用ArkWeb的能力，在元服务中显示Web页面的内容，提供页面加载等能力。

该能力仅在HarmonyOS NEXT Developer Preview时，面向部分合作伙伴及开发者的Beta开放。申请并获得Web权限的开发者，仍可使用ArkWeb能力，但建议尽快切换为AtomicServiceWeb。

变更后：

ArkWeb不再支持元服务，需使用AtomicServiceWeb组件替代。

变更发生版本

从HarmonyOS SDK 5.0.0 beta3（API12）开始。

变更的接口/组件

[@ohos.web.webview](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-webview)和[Web组件](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-web)不再支持元服务。

适配指导

请使用元服务Web组件（AtomicServiceWeb）替代，开发指导请参考：[元服务Web开发指导](https://developer.huawei.com/consumer/cn/doc/atomic-guides/web-upgraded-to-atomicserviceweb)。  

#### 账号

变更原因

按元服务账号使用规范，元服务只能调用登录API实现静默登录，不再提供账号登录组件。

变更影响

此变更涉及应用适配。

变更后，不再支持元服务调用华为账号的登录组件（含登录面板和登录button）。

变更发生版本

从HarmonyOS NEXT Beta1（API12）开始。

变更的接口/组件

变更前：支持元服务使用华为账号登录组件（含登录按钮/面板）。

变更后：不支持元服务使用华为账号登录组件（含登录按钮/面板），仅支持元服务调用登录API。

适配指导
