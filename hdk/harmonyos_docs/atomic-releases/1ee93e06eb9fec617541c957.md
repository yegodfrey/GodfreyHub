# 26.0.0

#### 版本概述

HarmonyOS开发套件26.0.0 Beta1版本在HDC.2026正式面向开发者发布。本次发布对HarmonyOS开发套件的版本号格式进行了调整，详情见[版本号格式调整说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/version-number-26)。

26.0.0 Beta1在6.1.1(24)的基础上，进一步增强了组件的材质效果，实现更好的沉浸光感效果；Device Security Kit增强了星盾引擎能力，等等。

更多详情可参见[OS平台新增和增强特性](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/os-new-feature-2600)。
