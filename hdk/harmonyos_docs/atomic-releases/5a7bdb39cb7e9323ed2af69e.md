# 5.0.1(13)

#### 版本概述

HarmonyOS 5.0.1(13)在HarmonyOS 5.0.0(12)的基础上进一步完善了API的接口能力，并重点增强了API接口的稳定性。

详细说明请参见[OS平台能力](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/os-new-feature)和[DevEco Studio](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/deveco-studio-new-features-501-release)的新增和增强特性。  

#### 版本信息

![](https://media:301781250843931078)  
使用正确的配套关系进行应用开发可以获得更流畅的开发体验。

请在阅读版本更新和变更内容前，务必确认版本的配套关系是否与当前您所使用的开发套件是一致的。
