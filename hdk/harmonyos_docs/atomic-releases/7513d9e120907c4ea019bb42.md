# 6.1.1(24)

#### 版本概述

6.1.1(24) 在6.1.0(23)的基础上，开发能力得到进一步增强：Ability Kit增强了AbilityStage上下文能力以支持动态加载资源；ArkUI增强了平行视界状态获取、自定义组件跨Ability迁移、动态布局容器等能力；ArkTS支持taskpool任务超时设置；Camera Kit新增延迟预览输出和影随人动能力；Performance Analysis Kit增强了资源采集能力，等等。

更多详情可参见[OS新增和增强特性](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/os-new-feature-611)。
