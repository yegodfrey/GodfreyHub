# 扩展接口

## Overview

iTrustee在Global Platform标准API基础上，提供了一些扩展接口用于增强系统的安全性。

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------------------------------------------------|
|TEE_Result|[AddCaller_CA_exec](#section134901732104914)(const char *ca_name, uint32_t ca_uid) 为指定可执行文件形式CA添加调用本TA的权限。|
|TEE_Result|[AddCaller_CA_apk](#section963725195319)(const char *ca_name, char *modulus, char *pub_exponent) 为指定APK形式CA添加调用本TA的权限。|
|TEE_Result|[AddCaller_TA_all](#section127442613536)(void) 添加其他TA调用本TA的权限。|
|TEE_Result|[TEE_EXT_GetDeviceUniqueId](#section6591177125312)(uint8_t *device_unique_id, uint32_t *length) 获取设备的唯一标识。|

|Name|Description|
