# Overview

集成FIDO SDK之后，您就可以调用FIDO BioAuthn API来完成生物特征认证，包括指纹认证和面容认证。  

#### Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
|[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887)|提供给BioAuthn指纹认证或人脸认证的结果回调。需要由开发者完成具体实现。|
|[BioAuthnManager](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnmanager_x-0000001050418713)|FIDO BioAuthn指纹认证是否可用API入口。|
|[BioAuthnPrompt](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnprompt_x-0000001050267874)|FIDO BioAuthn指纹认证API的主入口。|
|[BioAuthnPrompt.PromptInfo](https://developer.huawei.com/consumer/cn/doc/Security-References/promptaromptinfo_x-0000001050268124)|展示给用户的指纹认证提示框中的信息。|
|[BioAuthnPrompt.PromptInfo.Builder](https://developer.huawei.com/consumer/cn/doc/Security-References/promptinfobuilder_x-0000001050418939)|用于生成[BioAuthnPrompt.PromptInfo](https://developer.huawei.com/consumer/cn/doc/Security-References/promptaromptinfo_x-0000001050268124)对象的构造器。|
|[BioAuthnResult](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthnresult_x-0000001050268116)|[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/Security-References/bioauthncallback_x-0000001050418887)回调的输入参数。|
|[CryptoObject](https://developer.huawei.com/consumer/cn/doc/Security-References/cryptoobject_x-0000001050178973)|与指纹认证或人脸认证关联的加密对象的包装类。|
|[FaceManager](https://developer.huawei.com/consumer/cn/doc/Security-References/facemanager_x-0000001050418949)|FIDO BioAuthn面容认证API的主入口。|
