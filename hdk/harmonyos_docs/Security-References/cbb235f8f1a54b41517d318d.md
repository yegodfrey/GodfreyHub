# Overview

包含华为人脸识别的服务类。例如：获取人脸识别能力，执行人脸识别等。

## Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------|
|[AuthenticationCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/authenticationcallback-0000001051676866)|人脸识别回调类，用于返回人脸识别的结果。|
|[AuthenticationResult](https://developer.huawei.com/consumer/cn/doc/development/Security-References/authenticationresult-0000001187125826)|认证结果类，用于传输密码操作对象。|
|[CryptoObject](https://developer.huawei.com/consumer/cn/doc/development/Security-References/cryptoobject-0000001187273542)|密码操作类，用于传输密码相关信息。|
|[FaceManager](https://developer.huawei.com/consumer/cn/doc/development/Security-References/facemanager-0000001051358144)|人脸识别类，用于执行人脸识别。|
|[FaceRecognitionCapability](https://developer.huawei.com/consumer/cn/doc/development/Security-References/facerecognitioncapability-0000001064416874)|人脸识别能力类，用于返回人脸识别能力。|
|[HwFaceManagerFactory](https://developer.huawei.com/consumer/cn/doc/development/Security-References/hwfacemanagerfactory-0000001051988085)|人脸识别实例工厂类，用于人脸识别实例初始化。|
