# FaceManager

|Class Info|
|:------------------------------------------------|
|public abstract class FaceManager 人脸识别类，用于执行人脸识别。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
|void|[authenticate](#section5130125021016)() 发起一次人脸识别认证，认证结果通过callback返回。|
|FaceRecognitionCapability|[getFaceRecognitionCapability](#section1840313536188)() 获取当前设备的人脸识别能力。 EMUI 11.0.1及以上版本支持。|
|boolean|[hasEnrolledTemplates](#section178633661513)() 获取当前设备是否已录入人脸。 EMUI 11.0.1及以上版本建议使用[getFaceRecognitionCapability](#section1840313536188)。|
|boolean|[isHardwareDetected](#section167010476105)() 获取当前设备是否支持人脸识别。 EMUI 11.0.1及以上版本建议使用[getFaceRecognitionCapability](#section1840313536188)。|

## Public Methods

### authenticate

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void authenticate([CryptoObject](https://developer.huawei.com/consumer/cn/doc/development/Security-References/cryptoobject-0000001187273542) crypto, CancellationSignal cancel, int flags, [AuthenticationCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/authenticationcallback-0000001051676866) callback, Handler handler) 发起一次人脸识别认证，认证结果通过callback返回。|

**Parameters**

|Name|Description|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|

|flags|认证标记。|
|callback|认证结果回调, 参见[AuthenticationCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/authenticationcallback-0000001051676866)。|
|handler|认证相关回调处理的Handler，参数可以为null。|

|Method|
|:-------------------------------------------------------------------------------------------------|

### hasEnrolledTemplates

|Method|
|:------------------------------------------------------------------------------------------------------------------------------|
|public boolean hasEnrolledTemplates() 获取当前设备是否已录入人脸。 EMUI 11.0.1及以上版本建议使用[getFaceRecognitionCapability](#section1840313536188)。|

**Return** **s**

|Type|Description|
|:------|:----------------------------------------|
|boolean|表明当前设备是否已录入人脸，如果已录入人脸为true，如果未录入人脸为false。|

### isHardwareDetected

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------|
|public boolean isHardwareDetected() 获取当前设备是否支持人脸识别。 EMUI 11.0.1及以上版本建议使用[getFaceRecognitionCapability](#section1840313536188)。|

**Return** **s**

|Type|Description|
|:------|:--------------------------------------------|
|boolean|表明当前设备是否支持人脸识别，如果支持人脸识别为true，如果不支持人脸识别为false。|
