# WebAppIdentity  
  
#### 概述

[AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165)的子类，标识一个Web应用的身份。

#### 构造函数

函数 | 描述  
---|---  
WebAppIdentity(jsonObject) | 从一个JSON对象构造WebAppIdentity对象，JSON对象的属性名称和WebAppIdentity的属性相同。  
  
#### 属性

名称 | 类型 | 描述  
---|---|---  
domain | String | 网站域名。如果端口号不是默认值(443)，则需携带端口号，形式为domain:port。只读属性。
