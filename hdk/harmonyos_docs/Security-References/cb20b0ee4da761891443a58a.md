# 安全时间

## Overview

TEE中提供了安全时钟机制，防止时钟计时被非法篡改，保障TEE中时钟计时的可靠性。

## Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------|
|void|[TEE_GetSystemTime](#section134901732104914)(TEE_Time *time) 获取TEE当前系统时间。|
|TEE_Result|[TEE_Wait](#section1325411101916)(uint32_t timeout) 设置当前线程等待时长。|
|TEE_Result|[TEE_GetTAPersistentTime](#section209089244201)(TEE_Time *time) 获取TA持续时间，计时起点通过TEE_SetTAPersistentTime接口设置。|
|TEE_Result|[TEE_SetTAPersistentTime](#section530916352215)(TEE_Time *time) 设置TA基准时间。|
|void|[TEE_GetREETime](#section102861056234)(TEE_Time *time) 获取非安全侧时间。|
|void|[TEE_GetREETimeStr](#section14344175811233)(char *time_str, uint32_t time_str_len); 获取非安全侧时间字符串。|
