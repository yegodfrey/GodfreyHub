|Class Info|
|:---------------------------------------------------------------------------------|

### onAuthenticationHelp

|Method|
|:---------------------------------------------------------------------------------------------------|
|public void onAuthenticationHelp(int helpCode, CharSequence helpString) 人脸识别过程中提示信息回调函数，返回识别过程中提示信息。|

**Parameters**

|Name|Description|
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|errorCode|提示信息ID。 * FACE_ACQUIRED_GOOD = 0：获得的图像质量符合要求。 * FACE_ACQUIRED_INSUFFICIENT = 1：当前获得面部图像不足。 * FACE_ACQUIRED_TOO_BRIGHT = 2：光线太强，获取的图像太亮。 * FACE_ACQUIRED_TOO_DARK = 3：光线太暗，获取的图像太暗。 * FACE_ACQUIRED_TOO_CLOSE = 4：设备和面部距离太近。 * FACE_ACQUIRED_TOO_FAR = 5：设备和面部距离太远。 * FACE_ACQUIRED_TOO_HIGH = 6：设备太高，仅获取到人脸上部。 * FACE_ACQUIRED_TOO_LOW = 7：设备太低，仅获取到人脸下部。 * FACE_ACQUIRED_TOO_RIGHT = 8：设备太靠右，仅获取到人脸右部。 * FACE_ACQUIRED_TOO_LEFT = 9：设备太靠左，仅获取到人脸左部。 * FACE_ACQUIRED_TOO_MUCH_MOTION = 10：在图像采集过程中，用户脸部移动过多。 * FACE_ACQUIRED_POOR_GAZE = 11：用户的注视偏离传感器太远，导致用户脸部的重要部分被隐藏。 * FACE_ACQUIRED_NOT_DETECTED = 12：传感器未检测到面部。 * FACE_ACQUIRED_VENDOR = 13：扩展信息。|
|errString|提示字符串，可以在UI中显示。|
