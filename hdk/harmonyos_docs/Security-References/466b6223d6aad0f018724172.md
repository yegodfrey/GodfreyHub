# 说明

|Name|Description|
|:------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，提供Android端侧安全检测服务能力的API，支持系统完整性检测（SysIntegrity）、恶意URL检测（URLCheck）、应用安全检测（AppsCheck）、虚假用户检测（UserDetect）、恶意Wi-Fi检测, 帮助您快速构建应用安全。|
|REST|提供服务端接口，用于获取虚假用户检测结果。|
