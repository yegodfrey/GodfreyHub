# 系统接口

## Overview

iTrustee系统层接口函数，包括TA运行框架、通信框架、内存管理等基础接口函数。

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|TEE_Result|[TA_CreateEntryPoint](#section250145282518)(void) TA实例的构造函数，每个TA实例的生命周期中只被调用一次。如果函数执行失败，则表示创建TA实例失败。|
|TEE_Result|[TA_OpenSessionEntryPoint](#section52108163274)(uint32_t paramTypes, TEE_Param params[4], void** sessionContext) 在CA请求创建一个与TA的会话时，TEE系统会调用此函数来创建一个会话。|
|TEE_Result|[TA_InvokeCommandEntryPoint](#section14555195692818)(void* session_context, uint32_t cmd_id, uint32_t paramTypes, TEE_Param params[4]) 在CA发送指令给TA时，需要指定之前创建成功的会话，TEE系统收到请求后会调用此函数。|
|void|[TA_CloseSessionEntryPoint](#section314775863416)(void* session_context) 在CA发起关闭与TA的会话连接时，TEE系统会调用此函数。TA需要释放用于此会话的资源。|

|TEE_Result|[TEE_InvokeTACommand](#section1845313010337)(TEE_TASessionHandle session, uint32_t cancellationRequestTimeout, uint32_t commandID, uint32_t paramTypes, TEE_Param params[4], uint32_t *returnOrigin) 向目标TA发送消息。|
|TEE_Result|[TEE_CloseTASession](#section9367141813514)(TEE_TASessionHandle session) 关闭与目标TA的通信链接。|

## Methods

### TA_CreateEntryPoint

|Method|
|:--------------------------------------------------------------------------------------|
|TEE_Result TA_CreateEntryPoint(void) TA实例的构造函数，每个TA实例的生命周期中只被调用一次。如果函数执行失败，则表示创建TA实例失败。|

**Return**

|Type|Description|
|:---------|:-------------------------------------------------------------------------------------------------------------------|
|TEE_Result|参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/Security-References/error-code-0000001053477090)定义。|

### TA_OpenSessionEntryPoint

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------|
|TEE_Result TA_OpenSessionEntryPoint(uint32_t paramTypes, TEE_Param params[4], void** sessionContext) 在CA请求创建一个与TA的会话时，TEE系统会调用此函数来创建一个会话。|

**Parameters**

|Name|Description|
|:-------------|:-------------|
|paramTypes|TEE_Param参数类型。|
|params|TEE_Param实际参数。|
|sessionContext|指向会话的二级指针。|

**Return**

|Type|Description|
|:---------|:-------------------------------------------------------------------------------------------------------------------|

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|

**Return**
