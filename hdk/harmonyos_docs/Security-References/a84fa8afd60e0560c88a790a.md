# SharedCredential  
  
#### 概述

一个可以在应用间共享的凭据。

#### 构造函数

函数 | 描述  
---|---  
SharedCredential(jsonObject) | 从一个JSON对象构造SharedCredential对象，JSON对象的属性名称和SharedCredential的属性相同。  
  
#### 属性

名称 | 类型 | 描述  
---|---|---  
owner | AppIdentity的子类 | 凭证属主，只读属性。  
type | int | 凭据的类型，只读属性，支持以下三种类型：
                * SharedCredential.PASSWORD 0
                * SharedCredential.TOKEN 1
                * SharedCredential.FEDERATION 2  
username | String | 用户名，最大长度128。 只读属性  
content | ArrayBuffer | 密码/Token/联邦认证信息，需要调用getContent()方法获取。最大长度16384。  
displayName | String | 显示名称，最大长度128。  
avatarUrl | String | 头像URL，最大长度16384。  
tag | String | 凭据的标签，由开发者定义含义，最大长度1024。  
syncAble | Bool | 设置是否支持在设备间进行同步。数据同步过程中，使用密码技术对凭据的敏感信息进行加密，华为不掌握凭据的内容。本功能为预留能力，当前版本仅提供参数设置功能，未来版本提供同步能力。  
userAuth | Bool | 是否启用用户认证，获取凭据内容时验证锁屏口令或者指纹， 只读属性。  
sharedWith | AppIdentity[] | 共享给哪些App/网站。如果不共享，可以不设置此参数。  
timeCreated | long | 凭据最初创建时间，返回UNIX时间戳。 只读属性。  
timeUpdated | long | 凭据最后更新时间，返回UNIX时间戳。 只读属性。  
timeLastUsed | long | 凭据最后使用时间，返回UNIX时间戳。 只读属性。  
  
#### 常量

常量 | 描述  
---|---  
PASSWORD | 密码类型的凭据，值为0。  
TOKEN | 令牌类型的凭据，值为1。  
FEDERATION | 联邦认证类型凭据，值为2。  
  
#### 方法概述

方法 | 描述 | 参数类型 | 返回值  
---|---|---|---  
getContent() | 获得凭据中保存的内容 | - | ArrayBuffer类型的Promise。  
  
#### getContent()

获得凭据中保存的内容。

#### [h2]语法
    
    SharedCredential.getContent().then(function(contentBuffer) { ... } )

#### [h2]参数

None

#### [h2]返回值

解析为ArrayBuffer的Promise。

#### [h2]示例
    
    navigator.sharedCredentials.find([]).then((credentials)=>{
    for (var credential of credentials) {
    credential.getContent().then((content)=>{
    // handle content buffer
    //ConvertToString(content)
    })
    }
    })
