# SharedCredentialsContainer  
  
#### 概述

SharedCredentialsContainer提供了在浏览器中管理钥匙环服务（Keyring）中凭据的方法。您可通过navigator.sharedCredentials获得该SharedCredentialsContainer类的实例。

#### 方法概述

方法 | 描述 | 参数类型 | 返回值  
---|---|---|---  
delete(credential) | 删除凭据。 | [SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862) | undefined类型的Promise。  
find(trustedApps) | 查找可用的凭据，包括应用自己保存和其它应用共享的。 | [AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165)子类的数组 | [SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862)数组的Promise。  
isSupported() | 判断当前设备是否支持Keyring服务。 | - | bool类型的Promise。  
save(credential) | 保存凭据。如果凭据已经存在，则更新凭据。 | [SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862) | undefined类型的Promise。  
  
#### delete(credential)

#### [h2]语法
    
    SharedCredentialsContainer.delete(credential).then(function() { ... } )

#### [h2]参数

参数 | 是否必选 | 类型 | 描述  
---|---|---|---  
credential | 是 | [SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862) | 待删除的凭据，传入[findCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialclient-0000001133185186#section1514021810425)返回的[SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862)对象。
                * 如果凭据是当前的Web应用创建的，完整的删除凭据。
                * 如果凭据是其它的应用创建的，授权当前Web应用使用，则只删除凭据的共享关系，调用者以后不能再使用该凭据，但不影响凭据的所有者和其它被授权的应用继续使用。  
  
#### [h2]返回值

解析为undefined的Promise。

#### [h2]示例

参考[findCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialclient-0000001133185186#section1514021810425)的例子。

#### find(trustedApps)

查找可以使用的凭据，返回应用本应用创建的凭据和其它应用共享给它的凭据。

#### [h2]语法
    
    SharedCredentialsContainer.find(trustedApps[]).then(function(credentials[]) { ... } )

#### [h2]参数

参数 | 是否必选 | 类型 | 描述  
---|---|---|---  
trustedApps | 是 | [AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165)类型数组 | 开发者可以设置可信应用列表，限制只返回列表中的应用共享给调用者的凭据，以防止使用不可信的凭据。此参数只用于过滤其它应用共享给当前应用的凭据，不需要把当前应用放入列表中。 如果传入的参数为空数组，则返回所有应用共享给调用者的凭据，开发者可以根据凭据的owner属性判断是否信任并使用这个凭据。  
  
#### [h2]返回值

解析为[SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862)数组的Promise。

返回应用自己保存的凭据和其它应用共享给它的凭据。

#### [h2]示例
    
    var android = new AndroidAppIdentity({name:"androidDemo",packageName:"android.huawei.com",certHash:"00:01:02:03….1F"});
    var quick = new QuickAppIdentity({name:"quickDemo",packageName:"quick.huawei.com",certHash:"00:01:02:03….1F"});
    var web = new WebAppIdentity({name:"webDemo",domain:"www.huawei.com"});
    var trustedApps = [android,web,quick];
    navigator.sharedCredentials.find(trustedApps).then((credentials)=>{
      for (var credential of credentials) {
        navigator.sharedCredentials.delete(credential).then(() => { //删除查找到的所有凭证
          console.info("SharedCredential deleted.");
        }, (err) => {
          console.error("Error while deleting the SharedCredential: ", err);
        });
      }
    })

#### isSupported()

判断当前设备是否支持钥匙环服务。

#### [h2]语法
    
    SharedCredentialsContainer.isSupported().then(function(supported) { ... } )

#### [h2]参数

None

#### [h2]返回值

解析为bool的Promise。

#### [h2]示例
    
    navigator.sharedCredentials.isSupported().then((supported)=>{
        console.info("SharedCredentials isSupported : " + supported);
    })

#### save(credential)

把凭据保存到钥匙环服务中。

Web应用可以通过本方法保存新的凭据，也可以更新已有的凭据。

**1.****保存新凭据**

对于每个Web应用（根据域名和端口进行区分），[SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862)的username和type属性的组合是唯一的，如果username和type组合相同的凭据已经存在，则会更新已有的凭据。

对于每个应用，每种类型凭据的最大数量均为10个。超过数量限制后，您可以使用[deleteCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialclient-0000001133185186#section1766202311152)删除最不常用的凭据，然后再尝试保存。

保存新凭据时，不需要设置凭据的owner属性，系统自动把当前的Web应用设置为凭据的owner。

**2.****更新凭据**

应用修改find返回的[SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862)对象的属性，然后调用save方法。如果[SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862)对象的owner属性和当前应用不同，只能修改displayName、avatarUrl、tag、content属性。

#### [h2]语法
    
    SharedCredentialsContainer.save(credential).then(function() { ... } )

#### [h2]参数

参数 | 是否必选 | 类型 | 描述  
---|---|---|---  
credential | 是 | [SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862) | 待保存的凭据。  
  
#### [h2]返回值

解析为undefined的Promise。

#### [h2]示例
    
    var cre = new SharedCredential({
        username: 'John',
        type: SharedCredential.TOKEN,
        content: new ArrayBuffer(16),
        userAuth: true,
        displayName: "John's nickname",
        avatarUrl: 'xxxx.html',
        tag: 'John password',
        syncAble: false,
      });
     
    var android = new AndroidAppIdentity({name:"androidDemo",packageName:"android.huawei.com",certHash:"00:01:02:03….1F"});
    var quick = new QuickAppIdentity({name:"quickDemo",packageName:"quick.huawei.com",certHash:"00:01:02:03….1F"});
    var web = new WebAppIdentity({name:"webDemo",domain:"www.huawei.com"});
    var trustedApps = [android,web,quick];
    cre.sharedWith = trustedApps;
     
    navigator.sharedCredentials.save(cre).then(() => {
           console.info("SharedCredential saved successfully.");
    }, (err) => {
           console.error("Error while saving the SharedCredential: ", err);
    });
