# AppIdentity  
  
#### 概述

标识一个应用的身份，是[AndroidAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/androidappidentity-0000001169090316)、[QuickAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/quick-appidentity-0000001214250207)、[WebAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/webappidentity-0000001214408733)的基类。

#### 属性

名称 | 类型 | 描述  
---|---|---  
name | String | 应用的名称，只读属性。  
type | String | 应用的类型，只读属性。 "quickApp"：快应用 "webApp"：Web应用 "androidApp"：Android应用
