# CredentialType  
  
Enum Info  
---  
public enum CredentialType 用于标识一个[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)对象中保存的是什么类型的凭据。  
  
#### Enum Value Summary

Enum Value and Description  
---  
PASSWORD 口令类型的凭据。  
TOKEN Token类型的凭据。  
FEDERATION 联邦认证类型的凭据
