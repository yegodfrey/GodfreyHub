# Credential  
  
Class Info  
---

#### Public Constructors

#### [h2]Credential

Constructor  
---  
public Credential(String username, [CredentialType](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialtype-0000001179304561) type, Boolean userAuth, byte[] newContent) 构造Credential对象。  
  
**Parameters**

Name | Description  
---|---  
username | 用户名，最大长度128个字符。 注意：  username会在凭据管理界面向用户展示，因此需要让用户可理解。凭据管理界面请参考[凭据管理界面](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/interface-0000001256429155)。  
type | 凭据类型。  
userAuth | 使用凭据时，是否需要验证用户的生物特征或锁屏口令。  
newContent | 凭据内容，如密码、会话令牌、联邦认证URL的值，数据将被加密保存。最大长度为16384。
