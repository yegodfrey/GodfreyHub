|Qualifier and Type|Method Name and Description|

|public void|[auth](#section39750555252)(final [CryptoObject](https://developer.huawei.com/consumer/cn/doc/development/Security-References/cryptoobject_x-0000001050178973) crypto, final android.os.CancellationSignal cancel, final int flags, final [BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthncallback_x-0000001050418887) callback, final android.os.Handler handler) 发起一次对当前设备的面容认证请求。|
|public boolean|[isHardwareDetected](#section2064569195819)() 获取当前手机是否支持人脸识别，如果当前手机支持人脸识别返回true，如果当前手机不支持人脸识别返回false。|
|public boolean|[hasEnrolledTemplates](#section75771721132610)() 用于获取当前手机中是否有人脸录入，如果有人脸录入返回true，如果没有人脸录入返回false。|
