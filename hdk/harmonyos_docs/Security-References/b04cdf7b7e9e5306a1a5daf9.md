### getResult

|Method|
|:----------------------------------------------------------------|
|public String getResult() 获取系统完整性检测结果，检测结果的格式为JSON Web Signature。|

**Returns**

|Type|Description|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|一个JSON Web Signature格式的字符串，使用Base64URL编码，如果发生异常或错误，则返回null。 JWS的Header字段如下： ```screen { "alg": "RS256", "x5c": ["",""] } ``` > 说明 > "alg"：签名算法名称，RS256表示为SHA256withRSA使用PKCS1填充。PS256表示为SHA256withRSA使用PSS填充。 > "x5c"：华为签名服务器对JWS签名的证书链，x5c[0]为给JWS签名的证书，x5c[1]为华为设备CA。 JWS的Payload字段如下： ```screen { "apkCertificateDigestSha256": [ "osaUtTsdAvezjQBaW3IhN3/fsc6NQ5KwKuAQXcfrxb4=" ], "apkDigestSha256": "vFcmE0uw5s+4tFjXF9rVycxk2xR1rXiZFHuuBFzTVy8=", "apkPackageName": "com.huawei.hms.safetydetectsample", "appId": "1*******" "basicIntegrity": false, "detail": [ "root", "unlocked" ], "nonce": "UjJScmEyNGZWbTV4YTJNZw==", "timestampMs": 1604048377137, "advice": "RESTORE_TO_FACTORY_ROM" } ``` > 说明 > nonce：调用sysIntegrity接口时传入的nonce值的Base64编码。 > timestampMs：华为签名服务器生成的时间戳。 > apkPackageName：您应用的包名。 > apkDigestSha256：您应用的APK SHA256摘要。 > apkCertificateDigestSha256：您应用的签名证书SHA256摘要。 > basicIntegrity：系统完整性检测的结果，true表示检测结果完整。 > appId：您应用的appid。 > advice：根据系统完整性检测结果提出的建议，"RESTORE_TO_FACTORY_ROM"表示恢复出厂设置。 > detail：可选字段，当系统完整性检测返回结果为"false"时，该字段将描述具体因为什么原因导致结果为false，该字段提供给需要针对明细结果作出不同决策的App使用。 > * unlocked：设备系统被解锁，可能造成刷机的风险。 > * root：设备被root，超级用户权限被泄漏。 > * emulator：模拟器。 > * attack：设备被攻击。|
