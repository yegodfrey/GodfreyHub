#### setLabel

|Method|
|:---------------------------------------------------------------------------------------------------------------------------|
|public int setLabel(Context context, String filePath, String labelName, String labelValue, int flag) 该接口用于为文件设置风险等级和相应的保护策略。|

Parameters  

|Name|Description|
|:---------|:------------------------------------------------------------------------------------------------------------------------------------------|
|context|应用的上下文信息，用于获取文件的存储路径，判断是否为CE/DE类路径。|
|filePath|需要设置风险等级的文件。格式为：绝对路径+文件名称。filePath格式举例：/data/user/0/com.tips.test/test1.txt。|
|labelName|分类分级标签名，现仅支持HwSfpPolicyManager.LABEL_NAME_SECURITY_LEVEL。|
|labelValue|标签值：S0、S1、S2、S3、S4。 标签值的含义参见[业务介绍](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/introduction-0000001163501961)。|
|flag|标签值的辅助信息，仅当labelValue=S3时有意义，flag取值含义如下： * 0x0000：锁屏不可打开、不可读写文件。 * 0x0001：锁屏下可以新增文件，对于已经打开的文件，可以继续读写该等级文件。|

Return  

|Type|Description|
|:---|:--------------------------------------------------------------------------------------------------------------|
|int|* 返回值为0，代表设置标签成功。 * 返回错误码为1，代表存在非法入参。 * 返回错误码为2，代表文件已经被设置过标签。 * 返回错误码为3，代表该context和设置目标路径不匹配。 * 返回错误码为4，代表调用失败。|

Throws  

|Name|Description|
|:----------------|:-----------------------------|
|NoExtAPIException|当前版本不支持则抛出NoExtAPIException异常。|

#### getLabel

|Method|
|:-----------------------------------------------------------------------------------------|
|public String getLabel(Context context, String filePath, String labelName) 该接口用于获取文件的风险等级。|

Parameters  

|Name|Description|
|:--------|:---------------------------------------------------------------------------|
|context|应用的上下文信息，用于获取文件的存储路径，判断是否为CE/DE类路径。|
|filePath|需要查询风险等级的文件。格式为：绝对路径+文件名称。filePath格式举例：/data/user/0/com.tips.test/test1.txt。|
|labelName|分类分级标签名，现仅支持HwSfpPolicyManager.LABEL_NAME_SECURITY_LEVEL。|

Return  

|Type|Description|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|* 返回的 String为空字符串""，代表未能正确获得标签信息。 <!-- --> * 返回的字符串为"S0"，代表成功获取文件的标签值S0。 * 返回的字符串为"S1"，代表成功获取文件的标签值S1。 * 返回的字符串为"S2"，代表成功获取文件的标签值S2。 * 返回的字符串为"S3"，代表成功获取文件的标签值S3。 * 返回的字符串为"S4"，代表成功获取文件的标签值S4。 "S0"-"S4"标签值的含义参见[业务简介](https://developer.huawei.com/consumer/cn/doc/development/Security-Guides/introduction-0000001163501961#section1595182765015)。|

Throws  

|Name|Description|
|:----------------|:-----------------------------|
|NoExtAPIException|当前版本不支持则抛出NoExtAPIException异常。|
