# AndroidAppIdentity  
  
#### 概述

[AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165)的子类，标识一个Android应用的身份。

#### 构造函数

函数 | 描述  
---|---  
AndroidAppIdentity(jsonObject) | 从一个JSON对象构造AndroidAppIdentity对象，JSON对象的属性名称和AndroidAppIdentity的属性相同。  
  
#### 属性

名称 | 类型 | 描述  
---|---|---  
packageName | String | Android应用的包名，只读属性。  
certHash | String | APK代码签名证书的SHA256指纹，只读属性。 可以使用以下命令得到：
    
    keytool -list -v -keystore app.keystore

或
    
    openssl x509 -fingerprint -sha256 -noout -in app.pem
