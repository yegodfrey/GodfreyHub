# FaceRecognitionCapability

|Class Info|
|:---------------------------------------------------------|
|public class FaceRecognitionCapability 人脸识别能力类，用于返回人脸识别能力。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:------------------------------------------------|
|boolean|[isEnrolled](#section397740153913) 表明当前设备是否已录入人脸。|
|boolean|[isSupport](#section266414464015) 表明当前设备是否支持人脸识别。|
|boolean|[is3D](#section7651830124015) 表明当前设备人脸识别模式是否为3D。|

## Public Fields

### isEnrolled

|Fields|
|:------------------------------------------------------------------|
|public boolean isEnrolled 表明当前设备是否已录入人脸，如果已录入人脸为true，如果未录入人脸为false。|

### isSupport

|Fields|
|:---------------------------------------------------------------------|
|public boolean isSupport 表明当前设备是否支持人脸识别，如果支持人脸识别为true，如果不支持人脸识别为false。|

### is3D

|Fields|
|:------------------------------------------------------------------------|
|public boolean is3D 表明当前设备人脸识别模式是否为3D，如果人脸识别模式是3D为true，如果人脸识别模式是2D为false。|
