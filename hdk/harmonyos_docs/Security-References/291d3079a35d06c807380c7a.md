# UserVerificationRequirement

|Enum Info|
|:----------------------------------------------------------------------------------------------------------|
|public enum UserVerificationRequirement 依赖方可能对其某些操作要求进行用户验证（校验当前使用者是否用户本人），而对其他操作不要求，通过定义枚举类型，来区分不同的要求级别*。*|

## Enum Value Summary

|Enum Value and Description|
|:-----------------------------------------------------|
|REQUIRED 需要用户校验。|
|PREFERRED 依赖方在可能的情况下优先对操作进行用户验证，但如果响应没有设置用户校验标志，则不会失败。|
|DISCOURAGED 依赖方不希望在操作期间使用用户验证（例如，为了尽量减少对用户交互流的干扰）。|
