### assetSelect

|Method|
|:----------------------------------------------------------------------------------|
|public AssetResult assetSelect(Context context, Bundle bundle) 该接口用于精确或批量查询Asset数据。|

**Parameters**

|Name|Description|
|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|context|类型：Context。 应用上下文信息。|
|bundle|类型：Bundle。 * 精确查询（包含但不限于以下参数）： * BUNDLE_SELECT_MODE （= SELECT_ONCE） * BUNDLE_ASSETHANDLE（目标数据索引值） * BUNDLE_APPTAG（如包名） * BUNDLE_ASSETTYPE（数据类型） * 批量查询（包含但不限于以下参数）： * BUNDLE_SELECT_MODE （= SELECT_FROM_BEGIN 或 SELECT_CONTINUE） SELECT_FROM_BEGIN表示从头开始查询，SELECT_CONTINUE表示继续查询，一次最多查询10条数据。 * BUNDLE_APPTAG（不配置则查询所有应用） * BUNDLE_ASSETTYPE（数据类型）|

**Throws**

|Name|Description|
|:----------------|:----------------------------|
|NoExtAPIException|版本不支持，则抛出NoExtAPIException异常。|

**Return**

|Name|Description|
|:---------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|AssetResult.resultCode|* SUCCESS = 0：成功 * ERROR_CODE_INVALID_ARGUMENT = -1：非法入参 * ERROR_CODE_PERMISSION_DENIED = -2：权限校验失败 * ERROR_CODE_UNINITIALIZED = -3：未初始化 * ERROR_CODE_DATABASE_ERROR = -4：数据库操作异常 * ERROR_CODE_UNSECURED_ENVIRONMENT = -5：非安全环境 * ERROR_CODE_SYSTEM_ERROR = -10：系统错误|
|AssetResult.resultInfo|* resultInfo为一组包含Asset数据详细信息的Json字符串：成功 * resultInfo为null：失败|
