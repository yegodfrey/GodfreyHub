# Overview

集成SafetyDetect SDK之后，您就可以调用HUAWEI Safety Detect API来检测系统安全性。  

#### Interface Summary

|Interface|Description|
|:----------------------------------------------------------------------------------------------------------------------------------------|:---------------------|
|[SafetyDetectClient](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445)|Safety Detect API的主入口。|

#### Class Summary

|Class|Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
|[AppsCheckConstants](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appscheckconstantsapi-0000001050175475)|应用安全检测的恶意应用类型。|
|[SafetyDetect](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectapi-0000001050415383)|获取[SafetyDetectClient](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445)实例的入口。|
|[SafetyDetectStatusCodes](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectstatuscodesapi-0000001050259854)|Safety Detect SDK状态码。|
