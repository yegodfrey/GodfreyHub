#### Public Methods

#### setNonce

|Method|
|:---------------------------------------------|
|public void setNonce(byte\[\] nonce) 设置nonce值。|

Parameters  

|Name|Description|
|:----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|nonce|一个密码学的nonce值，用于防重放攻击。您必须确保每次调用[sysIntegrity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/safetydetectclientapi-0000001050175445#section1590913375578)接口时传入的nonce值都是不同的。nonce的长度有限制，为16-66字节。 说明： nonce为必填项。|

#### setAppId

|Method|
|:------------------------------------------|
|public void setAppId(String appId) 设置appId。|

Parameters  

|Name|Description|
|:----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|您在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上申请的APP ID。HMS Core会对appId进行鉴权，您需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站的"API管理"上打开这个appId访问Safety Detect服务的开关。 说明： appId为必填项。|

#### setAlg

|Method|
|:-------------------------------------|
|public void setAlg(String alg) 设置签名算法。|

Parameters  

|Name|Description|
|:---|:---------------------------------------------------------------------------------------------------------------|
|alg|签名算法填充方式，支持RS256和PS256。 * RS256表示为SHA256withRSA使用PKCS1填充。 * PS256表示为SHA256withRSA使用PSS填充。 说明： alg为必填项。推荐使用PS256。|
