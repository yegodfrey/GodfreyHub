# Overview  
  
类名 | 描述  
---|---  
[AndroidAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/androidappidentity-0000001169090316) | [AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165)的子类，标识一个Android应用的身份。  
[AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165) | 标识一个应用的身份，是[AndroidAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/androidappidentity-0000001169090316)、[QuickAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/quick-appidentity-0000001214250207)、[WebAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/webappidentity-0000001214408733)的基类。  
[QuickAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/quick-appidentity-0000001214250207) | [AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165)的子类，标识一个快应用的身份。  
[SharedCredential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001169248862) | 一个可以在应用间共享的凭据。  
[SharedCredentialsContainer](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredentialscontainer-0000001169408814) | [SharedCredentialsContainer](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredentialscontainer-0000001169408814)提供了在浏览器中管理钥匙环服务（Keyring）中凭据的方法。您可通过navigator.sharedCredentials获得该[SharedCredentialsContainer](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredentialscontainer-0000001169408814)类的实例。  
[WebAppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/webappidentity-0000001214408733) | [AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001214370165)的子类，标识一个Web应用的身份。
