# 加解密

## Overview

iTrustee提供丰富的加解密接口，用于TA业务中数据的加解密及秘钥处理等操作。加解密接口的使用限制请参见[接口使用限制与约束](https://developer.huawei.com/consumer/cn/doc/development/Security-References/public-introduction-0000001053797070)。
