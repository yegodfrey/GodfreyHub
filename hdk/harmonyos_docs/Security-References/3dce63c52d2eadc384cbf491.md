# CredentialClient  
  
Interface Info  
---  
public interface CredentialClient 凭据管理客户端接口。

#### Public Methods

#### [h2]deleteCredential

Method  
---  
deleteCredential([Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188) credential, [CredentialCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialcallback-0000001179304555)<Void> callback) 删除凭据。  
  
**Parameters**

Name | Description  
---|---  
credential | 待删除的凭据，传入findCredential返回的[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)对象。
                * 如果凭据的[owner](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188#section279515115233)和调用者相同，完整的删除凭据。
                * 如果凭据的[owner](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188#section279515115233)和调用者不相同，则只删除凭据的共享关系，调用者以后不能再使用该凭据，但不影响凭据的[owner](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188#section279515115233)和其它应用继续使用。  
callback | 回调对象。  
  
#### [h2]findCredential

Method  
---  
public void findCredential(List<[AppIdentity](https://developer.huawei.com/consumer/cn/doc/development/Security-References/appidentity-0000001179304557)> trustedApps, [CredentialCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialcallback-0000001179304555)<List<[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)>> callback) 注意：  已废弃，推荐使用findCredential([SharedCredentialFilter](https://developer.huawei.com/consumer/cn/doc/development/Security-References/sharedcredential-0000001211539620) filter, [CredentialCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialcallback-0000001179304555)<List<[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)>> callback) 查找可以使用的凭据，返回应用自己保存的凭据和其它应用共享给它的凭据。  
  
**Parameters**

Name | Description  
---|---  
trustedApps | 开发者可以设置可信应用列表，限制只返回列表中的应用共享给调用者的凭据，以限制只使用可信的凭据。 如果本参数为null，则返回所有应用共享给调用者的凭据，开发者可以根据凭据的[owner](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188#section279515115233)属性判断是否信任并使用这个凭据。 如果传入的信任App列表为空，可能存在潜在安全隐患，所以不建议传值null或者空列表。  
callback | 回调对象，可以在[onSuccess](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialcallback-0000001179304555#section144051625164318)方法得到凭据列表。  
  
#### [h2]saveCredential

Method  
---  
public void saveCredential([Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188) credential, [CredentialCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credentialcallback-0000001179304555)<Void> callback) 把凭据保存到钥匙环服务中。 应用可以通过本方法保存新的凭据，也可以更新已有的凭据。
                1. **保存新凭据** 应用创建一个新的[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)对象并设置各个属性，然后调用saveCredential方法。 对于每个应用，[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)的username和type属性的组合是唯一的，如果username和type组合相同的凭据已经存在，则会更新已有的凭据。 对于每个应用，每种类型凭据的最大数量均为10个。超过数量限制后，您可以使用deleteCredential删除最不常用的凭据，然后再尝试保存。
                2. **更新凭据** 应用修改findCredential返回的[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)对象的属性，然后调用saveCredential方法。如果[Credential](https://developer.huawei.com/consumer/cn/doc/development/Security-References/credential-0000001133185188)对象的owner属性和当前应用不同，只能修改displayName、avatarUrl、tag、newContent属性。  
  
**Parameters**

Name | Description  
---|---  
credential | 待保存的凭据。  
callback | 回调对象。
