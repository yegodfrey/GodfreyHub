# Overview

集成FIDO SDK之后，您就可以调用HUAWEI FIDO BioAuthn API来完成生物特征认证，包括指纹认证和面容认证。  

#### Class Summary

|Class Name|Class Description|
|:----------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_bioauthncallback-0000001050178012)|提供给BioAuthn指纹认证或面容认证的结果回调。需要由开发者完成具体实现。|
|[BioAuthnResult](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_result-0000001050180151)|[BioAuthnCallback](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_bioauthncallback-0000001050178012)回调的输入参数。|
|[CryptoObject](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_bioauthnresult-0000001050178040)|与指纹认证或面容认证关联的加密对象的包装类。|
|[FaceManager](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_facemanager-0000001050180181)|FIDO BioAuthn面容认证API的主入口。|
|[FingerprintManager](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_fingerprintmanager-0000001050418971)|FIDO BioAuthn指纹认证是否可用API入口。|
