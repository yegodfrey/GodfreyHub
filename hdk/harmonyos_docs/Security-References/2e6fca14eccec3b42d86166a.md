# 公共说明

iTrustee提供了Global Platform标准中定义的基础API，以及一些扩展API接口。

此处只提供部分通用接口及扩展接口使用说明，了解全部GP接口内容请参见Global Platform[官网文档](https://globalplatform.org/specs-library/tee-internal-core-api-specification-v1-2/)。

**特殊说明：**

由于某些算法已经被证明可以被短时间内攻破，因此不建议TA在业务中使用，不推荐使用算法如下：

* 对称算法： DES算法、keysize小于256的AES算法、3DES算法（K1≠K2≠K3的情况除外）。


* 摘要算法： SHA256以下算法。


* 非对称算法： DSA算法，keysize小于2048的RSA算法、keysize小于256的ECC算法。
