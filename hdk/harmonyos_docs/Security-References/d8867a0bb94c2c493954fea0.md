# BioAuthnCallback

|Class Info|
|:-----------------------------------------------------------------------------|
|public abstract class BioAuthnCallback 提供给BioAuthn指纹认证或面容认证的结果回调。需要由开发者完成具体实现。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|publicvoid|[onAuthError](#section201341832462)(int errorCode, java.lang.CharSequence errString) 在BioAuthn指纹认证或面容认证过程中遇到不可恢复的错误且操作完成时回调函数，可以表明本次认证失败。不会执行进一步操作。|
|publicvoid|[onAuthHelp](#section48065182473)(int helpCode, java.lang.CharSequence helpString) 面容认证过程中提示信息回调函数，返回识别过程中提示信息。|
|publicvoid|[onAuthSucceeded](#section62012281496)([BioAuthnResult](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthnresult_x-0000001050268116) result) 指纹认证或面容认证成功时的回调函数，表明本次认证成功。|
|publicvoid|[onAuthFailed](#section18777859164917)() 指纹认证或面容认证失败时的回调函数，可以表明本次认证失败。|

## Public Methods

### onAuthError

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------|
|public void onAuthError(int errorCode, java.lang.CharSequence errString) 在BioAuthn指纹认证或面容认证过程中遇到不可恢复的错误且操作完成时回调函数，可以表明本次认证失败，不会执行进一步操作。|

**Parameters**

|Name|Description|
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|errorCode|错误码，参见[BioAuthnPrompt](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthnprompt_x-0000001050267874)和[FaceManager](https://developer.huawei.com/consumer/cn/doc/development/Security-References/facemanager_x-0000001050418949)中错误码。|
|errString|可在用户界面上显示的可读错误字符串。|

### onAuthHelp

|Method|
|:---------------------------------------------------------------------------------------------------|
|public void onAuthHelp(int helpCode, java.lang.CharSequence helpString) 面容认证过程中提示信息回调函数，返回识别过程中提示信息。|

**Parameters**

|Name|Description|
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|helpCode|帮助码，参见[FaceManager](https://developer.huawei.com/consumer/cn/doc/development/Security-References/facemanager_x-0000001050418949)中常量定义。 > 说明 > 参见FACE_ACQUIRED开头的错误码。|
|helpString|可在用户界面上显示的可读帮助字符串。|
