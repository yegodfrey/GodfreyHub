# BioAuthnCallback

|Class Info|
|:-----------------------------------------------------------------------------|
|public abstract class BioAuthnCallback 提供给BioAuthn指纹认证或面容认证的结果回调。需要由开发者完成具体实现。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void|[onAuthError](#section150553110349)(int errorCode, java.lang.CharSequence errString) 在BioAuthn指纹认证或面容认证过程中遇到不可恢复的错误且操作完成时回调方法，可以表明本次认证失败，不会执行进一步操作。|
|public void|[onAuthHelp](#section22284520351)(int helpCode, java.lang.CharSequence helpString) 在BioAuthn指纹认证或面容认证过程中提示信息回调方法，返回识别过程中提示信息。|
|public void|[onAuthSucceeded](#section9288746133517)([BioAuthnResult](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_result-0000001050180151) result) 指纹认证或面容认证成功时的回调方法，可以表明本次认证成功。|
|public void|[onAuthFailed](#section12917241362)() 指纹认证或面容认证失败时的回调方法，可以表明本次认证失败。|

#### Public Methods

#### onAuthError

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------|
|public void onAuthError(int errorCode, java.lang.CharSequence errString) 在BioAuthn指纹认证或面容认证过程中遇到不可恢复的错误且操作完成时回调方法，可以表明本次认证失败，不会执行进一步操作。|

Parameters  

|Parameter Name|Description|
|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|errorCode|错误码，参见[FingerprintManager](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_fingerprintmanager-0000001050418971)和[FaceManager](https://developer.huawei.com/consumer/cn/doc/development/Security-References/bioauthn_facemanager-0000001050180181)中错误码。|
|errString|可在用户界面上显示的可读错误字符串。|

Parameters
