#### Public Constructors

#### [h2]WebAppIdentity

Constructor  
---  
public WebAppIdentity(String name, String domain) 构造WebAppIdentity对象。  
  
**Parameters**

Name | Description  
---|---  
name | 应用名称。  
domain | Web应用的域名。 说明： 
                * 网站的URL，格式为https://domain[:optional_port]
                * domain为网站的域名，而且必须完全匹配，不支持通配符。
                * optional_port为网站端口号，使用http协议默认的443端口时，必须省略。例如<https://developer.huawei.com>。
                * domain参数中不能包含路径，例如斜杠。
                * 子域名不认为是匹配的：如果您指定的domain为<https://developer.huawei.com>，域名login.developer.huawei.com不能使用您的凭据。
