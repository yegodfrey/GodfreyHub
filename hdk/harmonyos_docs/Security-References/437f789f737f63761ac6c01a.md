# Overview  
  
钥匙环服务（Keyring）提供了用户认证凭据在本地设备安全存储、读取和跨应用安全共享的能力。Keyring能够让应用：

                * 在设备本地安全的保存凭据，在Android Keystore内使用随机生成的密钥对凭据进行加密。
                * 应用读取凭据时对用户的身份进行认证，用户验证生物特征或锁屏口令后才能获取凭据的内容。
                * 在多种形态的应用之间安全的共享凭据，包括Android应用、快应用、Web应用等应用形态。
