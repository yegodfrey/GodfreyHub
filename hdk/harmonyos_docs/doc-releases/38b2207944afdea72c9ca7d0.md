# V3.1 版本已知问题  
  
#### V3.1 Beta1已知问题

在使用DevEco Studio V3.1 Beta1版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。 **环境配置：**
     * 通过安装目录的Uninstall.exe卸载DevEco Studio时，提示此应用无法在电脑上运行。规避措施：通过软件安装包重新安装时，选择卸载，可以完成DevEco Studio卸载。
     * 在Windows 10和Windows 11中，修改字符编码后，安装在中文目录下的DevEco Studio无法打开，报错“Error launching...”。规避措施：在英文目录重新安装DevEco Studio。
**工程管理：**
     * 导入部分Sample工程并同步完成后，Build按钮置灰不可用。规避措施：查看Sample工程的README文件，使用匹配的DevEco Studio版本或者根据EventLog的提示进行处理。
     * SDK安装向导界面偶现文件夹图标消失，但功能正常。
     * 新建HarmonyOS API 9工程，module.json5中默认配置的actions值，无法准确联想出来。例如默认配置的action为action.system.home，实际联想出来的是ohos.want.action.home，可直接使用联想出的action，不影响实际功能，无须规避。
     * 新建Lite类型工程，通过全局搜索文件，偶现一直处于搜索中的状态。规避措施：关闭工程重新打开后再进行搜索。
     * API 4-8的工程在M1上无法正常使用。ARM架构芯片系列处理器的Mac仅支持创建API 9及以上版本的工程，如果使用DevEco Studio打开API 4-8的历史工程，在使用预览功能以及开发Native应用时将产生未知问题。规避措施：创建API 9及以上版本的工程。
**编辑器：** 当字符串模板语法内出现“/”后，若当前行在字符串模板外仍出现“/”，则出现词法解析异常。 **预览器：**
     * HarmonyOS API 8工程，预览checkBox、checkBoxGroup组件时预览器白屏或崩溃。
     * API 9 JS工程中开启GIF动图预览后，放置较长时间（例如40分钟），预览器崩溃。
     * API 9 Stage模型工程中，开启极速预览后，修改百分比类型数值时，PreviewerLog报错，且极速预览功能失效。
**编译构建：** 如果makefile中的业务逻辑存在并发操作，由于CMake机制上通过多线程执行，在多CPU架构并发操作场景，会偶现编译失败。规避措施：建议排查并修改makefile中的业务逻辑，去除并发操作。 **调试：**
     * API 7及以下JS工程时光调试功能无法正常使用。
     * 使用3.1Beta1之前版本的DevEco Studio配合最新版本的HarmonyOS SDK，API7及以下JS工程调试过程中堆栈变量可能无法查看。规避措施：建议升级DevEco Studio到3.1Beta1版本。
     * 使用HarmonyOS 3.1 Beta1手机x86模拟器进行C++代码调试，在FunctionA中调用FunctionB场景中，在调用FunctionB处使用Step Over/Step Into功能时，调试会异常跳转到汇编代码中执行。规避措施：在调试窗口点击Resume Program跳出汇编。
     * HarmonyOS 3.1 Beta1手机x86模拟器暂不支持输入中文，未安装默认视频播放器，不支持调用华为帐号，不支持Sensor、蓝牙等硬件功能，首次启动可能会有桌面无响应等问题。

#### V3.1 Canary1已知问题

在使用DevEco Studio V3.1 Canary1版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。 **工程管理** ：在从深色主题切换到浅色主题时，部分界面或窗口（如Settings界面）未适配的情况。 **编辑器：** 在编辑器中，调用JS/ArkTS接口时，会出现少量接口的参数无法自动联想和检验的问题，但不影响该接口的使用。 **预览器：**
     * 在预览过程中，如果新增加了图片资源或者删除图片资源，请点击刷新按钮刷新预览或重启预览器进行预览。
     * 在HarmonyOS 3.0.0（API 8）ArkTS工程中，DatePicker组件和Rating组件未设置Options参数时，会导致预览引擎崩溃。规避措施：请设置DatePicker组件和Rating组件的Options再进行预览。
     * 在OpenHarmony API 9 ArkTS工程中，DatePicker组件未设置Options参数时，会导致预览引擎崩溃。规避措施：请设置DatePicker组件的Options再进行预览。
     * 在HarmonyOS 3.0.0（API 8）ArkTS工程中，修改组件的百分比类型的属性值时进行预览时，PreviewLog窗口中可能出现报错，影响预览功能使用。规避措施：请点击刷新按钮刷新预览或重启预览器。
     * 在低代码开发中，设置divider组件的color属性后预览结果不生效。规避措施：使用低代码开发完成后，需要将JS Visual文件转换为css文件重新设置color属性，然后重新预览。
     * 在预览过程中，存在部分组件或属性不生效，无法查看其预览效果。
     * 在ArkTS代码中，打开双向预览开关，新增组件属性后，会出现组件树异常，无法双向定位。规避措施：请使用**Ctrl+S** 保存后恢复。
     * 在ArkTS工程中，修改组件的属性可能导致极速预览功能不生效。规避措施：请使用**Ctrl+S** 保存后生效。
**调试运行：**
     * HarmonyOS 3.1.0(API 9)应用在远程模拟器中运行时，通过“show only selected application”方式可能出现无法过滤日志的问题。规避措施：请尝试退出应用（需结束进程）后，再重启应用进行重试
     * 在Native C++工程调试过程中，部分stl类型不支持变量修改，例如map类型，请在源码文件中进行修改。
     * 在Native C++工程中，当bundleName长度超过57个字符时，C++调试启动失败。规避措施：减小bundleName长度，建议不超过57个字符。
     * 用户在进行JS/ArkTS调试时，修改代码后重新运行调试，可能会出现断点不生效的情况。规避措施：请执行Clean Project后重启调试。
     * Phone和Tablet调试过程中，点击rotate按钮，会导致调试终止。
     * 在进行LiteWearable JS工程的调试时，如果点击stepOver执行完某方法后，再次触发该方法时，会停留在该方法的第一行代码处，需点击Resume才能进入断点。
     * 使用开发板连接DevEco Studio，可能会出现设备无法识别的问题，处理方式请参见[设备连接后，无法识别设备的处理指导](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/faq-debugging-and-running-0000001122066466#section1017120616410)。
**测试框架：** 在OpenHarmony Stage模型的工程中，ohosTest下的测试用例引用了pages目录下含有ArkUI语法糖的文件时，会导致测试框架运行失败。
