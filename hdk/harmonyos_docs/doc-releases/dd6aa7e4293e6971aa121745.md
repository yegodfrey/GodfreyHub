# V3.0 版本已知问题  
  
#### V3.0 Release已知问题

在使用DevEco Studio V3.0 Release版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。 **工程管理** ：
     * 在从深色主题切换到浅色主题时，部分界面或窗口（如Settings界面）未适配的情况。
     * OpenHarmony SDK API 9 Beta3（3.2.7.5）的安装路径不支持空格。
**编辑器：** 在编辑器中，调用JS/ArkTS接口时，会出现少量接口的参数无法自动联想和检验的问题，但不影响该接口的使用。 **预览器：**
     * 在低代码开发中，设置divider组件的color属性后预览结果不生效。规避措施：使用低代码开发完成后，需要将JS Visual文件转换为css文件重新设置color属性，然后重新预览。
     * 在预览过程中，存在部分组件或属性不生效，无法查看其预览效果。
     * 在ArkTS代码中，打开双向预览开关，新增组件属性后，会出现组件树异常，无法双向定位。规避措施：请使用**Ctrl+S** 保存后恢复。
     * 在ArkTS工程中，修改组件的属性可能导致极速预览功能不生效。规避措施：请使用**Ctrl+S** 保存后生效。
     * 在ArkTS工程中，使用Inspector双向预览功能时，部分组件的属性在Attributes属性列表中不显示，修改属性请在源代码文件中进行修改。
     * 在OpenHarmony的ArkTS工程中，连续修改DataPanel组件的values属性值可能导致预览器崩溃。规避措施：请点击刷新按钮重启预览器。
**编译构建：** 编译过程小概率出现内存使用过高导致编译失败。规避措施：请关闭当前非必要的进程，然后重新进行编译。 **调试运行：**
     * 在macOS系统升级到12.3及以上版本时，使用DevEco Studio启动C++调试失败，原因是系统默认不带Python 2.7版本，LLDB无法运行。规避措施：请自行安装Python 2.7版本后重新启动调试。
     * 用户在进行JS/ArkTS调试时，修改代码后重新运行调试，可能会出现断点不生效的情况。规避措施：请执行Clean Project后重启调试。
     * Phone和Tablet调试过程中，点击rotate按钮，会导致调试终止。
     * 在进行LiteWearable JS工程的调试时，如果点击stepOver执行完某方法后，再次触发该方法时，会停留在该方法的第一行代码处，需点击Resume才能进入断点。
     * 使用开发板连接DevEco Studio，可能会出现设备无法识别的问题，处理方式请参见[设备连接后，无法识别设备的处理指导](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/faq-debugging-and-running-0000001122066466#section1017120616410)。

#### V3.0 Beta4已知问题

在使用DevEco Studio V3.0 Beta4版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。 **工程管理** ：
     * 使用深色主题下，在创建工程、新增模块、新增Ability、新增Page等操作时，配置向导界面会出现闪动的现象，但不影响功能使用。
     * 在从深色主题切换到浅色主题时，部分界面或窗口（如Settings界面）未适配的情况。
**低代码开发****：** 创建低代码工程，添加button组件，绑定事件后进行代码调试，在进入断点时，会出现断点执行顺序错乱的问题。 **预览器：**
     * 修改部分组件的属性或接口参数，可能导致预览器引擎崩溃。
     * 在低代码开发中，设置divider组件的color属性后预览结果不生效。规避措施：使用低代码开发完成后，需要将JS Visual文件转换为css文件重新设置color属性，然后重新预览。
     * 在预览过程中，存在部分组件或属性不生效，无法查看其预览效果。
     * 在ArkTS代码中，打开双向预览开关，新增组件属性后，会出现组件树异常，无法双向定位，需要**Ctrl+S** 保存后才能恢复。
     * 在模块的hml代码中引用npm包中的自定义组件，新增或删除组件并使用**Ctrl+S** 保存后，预览界面会显示白屏，需要点击刷新按钮才能恢复。
**远程模拟器：**
     * P50模拟器连接WLAN网络后，会出现反复断开和自动重连。
     * P50模拟器显示宽度有压缩，存在字体和图标显示效果有压缩的现象。
**调试运行：**
     * OpenHarmony的C++工程，存在概率性无法进入断点，请重新启动调试。
     * 调试时，小概率出现Hilog日志打印丢失的情况。
     * DeviceConfigureAbility(JS)模板创建的工程不支持Js调试。
     * Phone和Tablet调试过程中，点击rotate按钮，会导致调试终止。
     * 在进行LiteWearable JS工程的调试时，如果点击stepOver执行完某方法后，再次触发该方法时，会停留在该方法的第一行代码处，需点击Resume才能进入断点。
     * 使用开发板连接DevEco Studio，可能会出现设备无法识别的问题，处理方式请参见[设备连接后，无法识别设备的处理指导](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/faq-debugging-and-running-0000001122066466#section1017120616410)。

#### V3.0 Beta3已知问题

在使用DevEco Studio V3.0 Beta3版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。 **环境配置** ：
     * 在配置OpenHarmony开发环境时，macOS会出现设置HTTP proxy的弹框，如果您不需要设置代理，请直接点击**Netx:Configure npm** 进行下一步配置。
     * 在macOS中，如果选择了macOS Light主题，可能会导致功能异常，如导入PCID失败，请更换为其它主题。
**工程管理** ：
     * 在工程中删除模块后，右下角会出现“Build Sync Failed！”的错误提示，该提示信息请忽略，工程可以正常进行编译。
     * 使用深色主题下，在创建工程、新增模块、新增Ability、新增Page等操作时，配置向导界面会出现闪动的现象，但不影响功能使用。
     * 在从深色主题切换到浅色主题时，部分界面或窗口（如Settings界面）未适配的情况。
**编辑器****：** 当工程文件所在的目录中含有中文字符时，编辑器的自动联想、跳转等编辑功能存在异常。 **低代码开发****：** 创建低代码工程，添加button组件，绑定事件后进行代码调试，在进入断点时，会出现断点执行顺序错乱的问题。 **预览器：**
     * 在macOS中预览Button、Checkbox、Toggle、TextInput、Blank、Rating组件，修改相应组件的属性时，预览器界面不会立即刷新，需要**Ctrl+S** 保存后才会更新。
     * 在macOS版本上修改DatePicker、Progress、Radio、Slider组件属性会导致预览引擎崩溃。
     * Panel组件预览异常。
     * 在ArkTS代码中，打开双向预览开关，新增组件属性后，会出现组件树异常，无法双向定位，需要**Ctrl+S** 保存后才能恢复。
     * 在模块的hml代码中引用npm包中的自定义组件，新增或删除组件并使用**Ctrl+S** 保存后，预览界面会显示白屏，需要点击刷新按钮才能恢复。
     * 在ArkTS模块中引用npm三方共享包中的JS函数，如果修改了引用的JS函数，预览界面不会刷新，需要点击刷新按钮才能恢复。
**调试运行：**
     * 使用开发板连接DevEco Studio，可能会出现设备无法识别的问题，处理方式请参见[设备连接后，无法识别设备的处理指导](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/faq-debugging-and-running-0000001122066466#section1017120616410)。
     * 在Hilog中调用hilog.isLoggable接口会出现程序卡死，影响后续程序运行，例如Hilog日志打印失败。建议暂时不要使用该接口。
**Profile性能分析：** 在进行Profile录制时，点击Stop停止录制时，会概率性出现录制失败的情况，提示“Failed to get the recorded file of sample perf record type”，请尝试重新录制。

#### V3.0 Beta2已知问题

在使用DevEco Studio V3.0 Beta2版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。 **工程管理** ： 打开已有工程，打开文件选择器选择文件，部分用户存在文件列表加载缓慢的问题。 **代码****编辑器：** 在卡片的hml文件中，在如下内联示例中{{ param1 || param2 }}，如果 param1 、param2和前后的{{、||、}}如果没有空格，存在点击param1 、param2跳转失败的问题。 **预览器：**
     * 在低代码开发中，设置divider组件的color属性后预览结果不生效。规避措施：使用低代码开发完成后，需要将JS Visual文件转换为css文件重新设置color属性，然后重新预览。
     * 在JS工程中，开启双向预览功能，在组件树中选择panel或dialog组件时，在预览界面不能正常选中该组件。
     * 使用组件预览功能时，在组件预览和页面预览切换过程中，可能会导致预览器引擎Crash。
     * 在预览过程中，存在部分组件或属性不生效，无法查看其预览效果。
     * 在预览器过程中，存在点击触发onDragEnter、onDragMove、onDragLeave、onDrop事件不生效的问题。
     * 在ArkTS工程中，JS类型的卡片，clock组件预览显示异常。
     * Video Player Ability(Java)、Device Control Ability(JS)、Image Editor Ability(Java)、Picture Browser Ability(Java)工程模板创建的工程不支持预览。
**调试运行：**
     * DeviceConfigureAbility(JS)模板创建的工程不支持Js调试。
     * Splash Screen Ability(JS)模板创建的工程，不支持app.terminate的写法，会存在调试问题。
     * 如果工程中存在多个模块，且“package”相同的情况下，不支持多hap安装和调试，您可以选择单个hap包进行调试。
     * About Ability(JS) 模板创建的工程，不支持this写法，会存在调试问题。
     * Phone和Tablet调试过程中，点击rotate按钮，会导致调试终止。
     * 在进行TV、LiteWearable、Wearable JS工程的调试时，如果点击stepOver执行完某方法后，再次触发该方法时，会停留在该方法的第一行代码处，需点击Resume才能进入断点。
**Profile性能分析：** 在打开多个工程时，如果一个工程导入了录制的离线Profile分析文件，再对其他工程进行调试，会出现“AssertionError”错误。

#### V3.0 Beta1已知问题

在使用DevEco Studio V3.0 Beta1版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。

     * 使用C++变量可视化功能调试时，会出现单步调试操作卡顿，且变量连续变化值会显示异常。
     * Video Player Ability(Java)、Device Control Ability(JS)、Image Editor Ability(Java)、Picture Browser Ability(Java)工程模板创建的工程不支持预览。
     * DeviceConfigureAbility(JS)模板创建的工程不支持Js调试。
     * Splash Screen Ability(JS)模板创建的工程，不支持app.terminate的写法，会存在调试问题。
     * 如果工程中存在多个模块，且“package”相同的情况下，不支持多hap安装和调试，您可以选择单个hap包进行调试。
