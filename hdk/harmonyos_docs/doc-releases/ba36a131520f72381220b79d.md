# 文件服务

#### 变更1 securityLabel模块变更

文件管理子系统d.ts整改，现统一整改到file目录下。securityLabel模块支持错误码处理。

**变更影响**

基于此前版本开发的应用，需注意d.ts位置的变更及import模块名的变更。现securityLabel模块支持错误码处理，需同步注意错误码处理的使用。

**关键的接口/组件变更**

无

**适配指导**

需import新模块并进行适配开发。

原securityLabel使用的是@ohos.securityLabel，之前的import：
    
    import securityLabel from '@ohos.securityLabel'

现securityLabel使用的是@ohos.file.securityLabel，可以通过修改import，来适配进行开发：
    
    import securityLabel from '@ohos.file.securityLabel';

#### 变更2 fs模块Stat.ino属性类型变更

fs模块中Stat接口的ino属性类型发生变更，由number变更为bigint。

**变更影响**

fs模块下Stat接口ino属性类型变更，由number变更为bigint，以适配文件系统下所有类型文件的inode范围。

**关键的接口/组件变更**

@ohos.file.fs.Stat.ino

**适配指导**

需适配@ohos.file.fs.Stat.ino属性类型的变更，现ino属性类型为bigint。
