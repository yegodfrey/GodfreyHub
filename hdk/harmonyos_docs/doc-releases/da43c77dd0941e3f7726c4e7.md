# 2021年3月

#### 版本信息

**软件包** | **发布类型** | **版本号** | **发布时间**  
---|---|---|---  
HarmonyOS SDK | Beta | **Build Version****：** HarmonyOS SDK 2.1.1.18（API Version 5 Beta 1） 说明： HarmonyOS SDK 2.1.0.13版本新增接口，统一由API Version 4变更为API Version 5。 | 2021/3/31  
DevEco Studio | Beta | **Version** ：DevEco Studio 2.1 Beta 3 **Build Version****：** DevEco Studio 2.1.0.301 | 2021/3/31  
  
#### 版本介绍

本次版本的重点变更如下：

     * 分布式能力增强：
       * 新增应用程序获取DVID（Distributed Virtual device ID，分布式虚拟设备ID）的能力，并对开发者提供相应接口。
       * 新增“按需同步”能力，结合DVID，实现在同帐号登录的分布式设备上设置数据的按需同步，并对开发者提供相应接口。
       * 新增基础服务状态识别能力，并对开发者提供相应接口。能力支持识别HarmonyOS基础服务启动状态，发送服务启动完成通知。
       * 新增多个分布式硬件能力接口，包括：本地设备信息查询接口、可信设备信息查询接口、设备状态变化订阅接口、设备列表选择接口。
     * 基础通信能力增强：
       * 新增支持三方应用连接WiFi热点功能，并对开发者提供相应接口。
       * 新增支持HCE（Host Card Emulation，主机卡模拟）能力，并对开发者提供相应接口。
     * 图形图像及UI框架能力增强：
       * 增强了多种渲染能力，优化了UI框架性能和SIMD（single-instruction, multiple-data stream processing，单指令流多数据流）性能。
       * 新增支持多种显示效果（列表滑动回弹等控件动效、多种动画曲线、组件级旋转缩放、组件级透明度），并对开发者提供相应接口。
       * 新增事件冒泡机制，并对开发者提供相应接口。
       * 新增GIF图片解析显示的能力。
       * 新增百分比宽高布局，并对开发者提供相应接口。
       * 新增Video和二维码控件，并对开发者提供相应接口。
       * 新增支持Java UI多种能力（基础控件40+、图形无障碍、自定义控件、可变字体、WebView）。
     * 数据服务能力增强：
       * 新增数据搜索（融合搜索）索引模板，提供了几种索引属性和格式规范，并对开发者提供相应接口。
       * 新增数据标签化能力。通过数据标签，可将本地及分布式数据库分类分级，并对开发者提供相应接口。
     * 媒体新增和优化了若干能力，以下能力可直接通过接口调用：
       * MediaLibrary：增加图库分类搜索数据开放功能。
       * Media：
         * 增加Native API，支持mediaformat的读取和设置。
         * 支持使用Player接口设置和读取播放音频的pitch参数。
       * Image：
         * 增加RAW、WBMP格式图片的解码能力。
         * 增加图片DecodeHeader回调。
         * 增加H.264、H.265图像格式通过ImageReceiver获取的能力。
         * 修复图片解码加载问题，优化JNI接口的加载速度。
       * Audio:
         * 新增支持智慧屏低时延播放能力AudioSwift框架。
         * 新增支持媒体管道功能AVTube。
       * Camera
         * 新增相机厂商私有Tag配置的key。
         * 新增相机白平衡控制及查询能力。
         * 新增部分API工具类接口，如equal等。
     * 全球化能力增强，以下能力可通过接口或资源文件进行配置：
       * 新增支持MCC_MNC、深色模式限定词。
       * 新增支持xliff标记，用于标记无需翻译的资源文本。
       * 新增支持度量衡的国际化能力。
     * 安全新增对证书进行操作的相关能力，并对开发者提供相应接口。
     * LiteOS内核能力新增及优化：
       * LiteOS-M支持作为内核组件纳入解决方案编译。
       * LiteOS-M支持Cortex-M7、Cortex-M33和RISC-V芯片架构。
       * LiteOS-M支持MPU功能。
       * LiteOS-M支持部分POSIX接口。
       * LiteOS-M支持FatFS文件系统。
       * LiteOS-M支持异常回调函数注册机制。
       * LiteOS-M三方芯片易适配性架构调整。
       * LiteOS-M、LiteOS-A支持堆内存调测功能，包括内存泄漏、踩内存、内存统计。
       * LiteOS-M、LiteOS-A支持TLSF堆内存算法，提高内存申请和释放效率，降低碎片率。
       * LiteOS-A调度优化。
