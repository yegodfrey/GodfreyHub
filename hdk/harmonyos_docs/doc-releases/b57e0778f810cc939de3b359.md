# API 6相对API 5变更详细说明  
  
#### JS API变更说明

#### [h2]div组件功能变更

变更前：根节点div默认宽高为占满全屏，非根节点div在非嵌套场景下横向布局时会布满横轴，在非嵌套场景下纵向布局会布满纵轴。

变更后：div不再区分节点是否为根节点，默认大小均按照子节点的大小进行设置。

**变更影响**

根节点div的布局不再占满全屏，会根据子节点的大小进行设置。

**关键的接口/组件变更**

无

**适配指导**

     * 如果需要兼容API 5及更早版本的布局行为，需修改build.gradle中的compatibleSdkVersion的值为5或5以下即可。
     * 如果需要使用API 6实现原效果，需要将根节点的宽高设置为100%。

示例：
           
           <div style="width:100%;height:100%;">
             <text>Hello</text>
           </div>

#### [h2]通用样式margin功能变更

变更前：API 5版本中当组件的宽和高设置为百分比时，margin设置的尺寸会计算在组件本身的宽和高中，组件的宽高非百分比场景下，margin设置的尺寸不会计算在组件本身的宽和高中。

变更后：API 6版本中不论组件的宽和高是否为百分比，margin设置的尺寸都不会计算在组件本身的宽和高中。

**变更影响**

当组件同时设置了百分比的宽高和margin时，在API 5和API 6会有不同的布局。

**关键的接口/组件变更**

无

**适配指导**

     * 如果需要兼容API 5及更早版本的布局行为，需修改build.gradle中的compatibleSdkVersion的值为5或5以下即可。
     * 如果需要使用API 6实现原效果，需将margin修改为padding。

示例：
           
           <div style="width:500px;height:500px;">
             <div style="width:100%;height:100%;padding:80px;">
               <text>Hello</text>
             </div>
           </div>

#### [h2]list组件功能变更

变更前：list组件未设置默认宽高时占用屏幕剩余空间。

变更后：list组件未设置默认宽高时根据子节点占用空间进行布局。

**变更影响**

不设置高度的List组件在API 6场景下布局高度会发生变化

**关键的接口/组件变更**

无

**适配指导**

     * 如果需要兼容老版本的布局行为，修改build.gradle中的compatibleSdkVersion为5及5以下即可。
     * 如果需要使用API 6又想使用API 5的效果，需要在样式中主动设置List高度值。

示例：
           
           <list style="height:100%;">
             <list-item>
               <text>Hello</text>
             </list-item>
           </list>

#### [h2]text组件功能变更

变更前：text组件的text-overflow属性设置ellipsis时，max-lines会自动设为1，文本内容会变为一行。

变更后：text组件的text-overflow属性设置ellipsis时，需要结合max-lines属性使用，否则不生效。

**变更影响**

text组件在API 6场景下，不设置maxlines，设置text-overflow属性为ellipsis将不生效。

**关键的接口/组件变更**

无

**适配指导**

     * 如果需要使用API 6又想使用API5的效果，设置maxlines为1即可。
           
           <text style="text-overflow: ellipsis;max-lines: 1;">
             Hello,如果需要使用API 6又想使用API 5的效果，设置maxlines为1即可。
           </text>
