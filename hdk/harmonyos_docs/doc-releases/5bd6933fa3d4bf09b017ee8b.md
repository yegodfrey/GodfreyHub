#### 版本介绍

本次发布HarmonyOS 3.0 Beta，可用于开发基于API Version 8的应用。从本次发布起，变更了SDK的配套关系：

     * 需同时获取HarmonyOS SDK与OpenHarmony SDK配套使用。
     * 配套JS/eTS SDK、Native SDK，推荐使用JS/eTS进行应用开发。

OpenHarmony SDK新增API Version 8 Release接口。更新说明请参见[JS API差异报告（API 7 -> API 8）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-js-api-8-arkui-0000001276484188)。

本次在API Version 8新增2300+ JS/eTS API接口，覆盖多个能力模块。主要包括：

     * 在原有触摸屏输入方式的基础上，支持更多交互方式：键盘、鼠标。
     * 新增分栏、侧边栏、富文本组件和动画效果（如共享元素过场动画），更好地支持宽屏设备上应用开发和动效开发。
     * 新增一系列画布接口，支持游戏、媒体复杂应用开发。
     * 新增一系列应用程序框架的接口以及相应工具链。支持使用纯JS实现卡片的UI布局和业务逻辑。
     * 新增一系列事件通知接口，支持大部分常用类型通知。
     * 新增一系列分布式软总线接口，支持使用JS/eTS语言实现应用（同设备、跨设备）间通信。
     * 新增一系列媒体数据管理接口，优化了本地公共目录、物理相册的媒体文件处理（增、删、改）能力，支持通过面向对象方式（相对于URL方式）处理媒体文件数据。
     * 新增一系列网络连接管理接口，支持对本地Wi-Fi和蜂窝数据网络的统一管理。
     * 新增一系列安全接口，支持统一秘钥管理服务，用户身份认证以及指纹认证。
     * 使用ArkCompiler替换V8、QuickJS引擎。
     * 新增一系列任务管理接口，支持实现长时任务，如后台播放音乐、导航类任务。
     * 新增一系列DFX能力接口，支持分布式调优调用链，可以支持多设备间分布式业务流程打点，支持获取崩溃、卡死的故障日志。

#### 遗留问题

#### [h2]getbundleInfo方法无法指定用户ID查询应用

【问题描述】getbundleInfo方法无法指定用户ID查询应用信息。

【发生版本】HarmonyOS SDK 3.1.1.1 Beta1

【问题影响】对于指定用户ID查询的应用信息，无法获取目标用户在该应用的信息，只能获取当前用户下的应用信息。

#### [h2]全屏或设置背景色时无法获取窗口属性

【问题描述】设置窗口属性成功后，查询结果不正确。

【发生版本】HarmonyOS SDK 3.1.1.1 Beta1

【问题影响】在对窗口设置全屏或背景色时，无法正确获取到窗口的相关属性。

#### [h2]startActivityForResult部分场景失效

【问题描述】startActivityForResult调用入参带FLAG导致失效，且回调后不置空回调。

【发生版本】HarmonyOS SDK 3.1.1.1 Beta1

【问题影响】startActivityForResult失效，在当前版本不建议使用。

#### [h2]accessibility.getCaptionsManager()调用style和enabled属性失败

【问题描述】无法通过accessibility.getCaptionsManager()方法调用style和enabled属性。

【发生版本】HarmonyOS SDK 3.1.1.1 Beta1

【问题影响】accessibility.getCaptionsManager()调用style和enabled属性时，无法读取该属性值。style、enabled属性值只能从日志中查看。

#### [h2]featureAbility.getWant()调用报错。

【问题描述】featureAbility.getWant()调用报错。

【发生版本】HarmonyOS SDK 3.1.1.1 Beta1

【问题影响】当前版本featureAbility.getWant()不建议使用。

#### [h2]getAddressesFromLocation调用后返回值异常

【问题描述】通过经纬度查询当前位置信息的返回信息异常，存在字段缺失。

【发生版本】HarmonyOS SDK 3.1.1.1 Beta1

【问题影响】设备刷机后首次获取位置信息会失败。后续可查询成功。

#### [h2]音频录制连续多次调用同一个接口会触发状态错误的信息

【问题描述】在使用音频录制audiorecorder的能力时，重复去调用同一个接口会触发接口无法正常返回。

【发生版本】HarmonyOS SDK 3.1.1.1 Beta1

【问题影响】重复调用音频录制audiorecorder的同一个接口时，会在订阅中接收到Error信息，但不影响接口功能的使用。
