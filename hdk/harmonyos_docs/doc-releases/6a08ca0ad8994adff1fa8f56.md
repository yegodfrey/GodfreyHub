#### 版本介绍

本次发布HarmonyOS 3.1 Beta1，相比上一版本，API变更请参见“[JS API差异报告（API 9 Canary1 -> API 9 Beta1）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-api-9-beta1-ability-0000001508287441)”。此次版本的部分变更可能影响到使用上一版本SDK开发的应用，具体影响说明及其适配方式请参见“[API 9 Beta1变更详细说明](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/changelog-api-9-beta1-arkui-0000001458813974)”。

     * HarmonyOS 3.1 Developer Preview版本中，存在部分历史版本的接口暂未提供或暂不兼容，这些接口大部分已在HarmonyOS 3.1 Beta1实现，剩余少量接口将在后续版本实现。

     * 如需浏览HarmonyOS 3.0 Release版本的文档，请在“指南”或“API参考”板块左上角切换版本到“HarmonyOS 3.0 Release”。

特性更新说明如下：

     * 部分接口新增或变更，以支持接口错误码。当前系统可能出现的错误码统一收录在[错误码参考](https://developer.harmonyos.com/cn/docs/documentation/doc-references-V3/errorcode-universal-0000001427902780-V3?catalogVersion=V3)中，供开发者参考。
     * [ArkTS声明式UI更新机制优化](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/changelog-api-9-beta1-arkui-0000001458813974#section559110358173)，当某个状态变量发生变化导致自定义组件重新渲染时，仅执行该自定义组件build函数中的部分UI描述（使用了该状态变量的内置UI组件的UI描述）来实现更高性能的UI更新。
     * ArkTS声明式UI组件变更：promptAction替代prompt接口，增加animator接口，Canvas组件支持绘制PixelMap，支持自定义布局组件。
     * 媒体能力新增支持音视频录制能力、支持音频toneplayer、支持音频焦点管理机制。
     * Web能力新增支持前进后退与历史记录管理、缩放管理、与H5互通、地理位置访问管理、Cookie管理、网页存储、网页内搜索等功能。
     * 包管理新增支持应用查询自身包信息的能力、以及查询应用自身metadata信息的能力。
     * 窗口新增支持窗口沉浸式显示、焦点设置、背景设置、亮度设置、隐私设置、屏幕常亮等功能。
     * 公共基础类库新增支持UUID 生成和解析功能、支持统一的异常处理。
     * 输入法新增支持显示可选输入法列表、支持显示/隐藏软键盘、支持切换输入法、获取当前输入法、监听输入法变化，支持停止当前输入法会话。
     * 图形能力新增支持色域配置与管理、支持图片Exif信息获取；允许应用生产图片数据，并通过surface传递给其他组件。
     * 元能力将Stage模型下前台Ability重命名为UIAbility，并补齐其生命周期；补齐AbilityContext、ApplicationContext、UIAbilityContext的启动ability、停止进程、获取进程信息等API；补齐wantAgent获取包名、uid、operation类型等API。
     * DFX新增应用完成预埋、预定义、自定义事件埋点、存储、分发、订阅框架等能力。
     * 分布式数据管理提供preferences数据库的基础功能，包括数据库的创建、删除能力，以及数据写入、数据删除能力等。
     * 安全基础能力新增常用加解密算法库的API，以及部分密钥管理（增删改查）的API。
     * 用户IAM新增用户身份认证的API。
     * MSDP新增设备静止状态检测的API。
     * 电源服务新增查询电池状态信息、充放电状态信息、温升状态信息的API。
     * 程序访问控制新增Stage模型下应用申请权限的API。
     * 泛Sensor服务新增支持获取sensor的相关信息和数据，控制sensor的开启和关闭；支持传感器类型包括加速度、陀螺仪、环境光、地磁、气压等。
     * 系统帐号服务新增应用标识查询、主用户判断和约束来源管理的相关API；应用帐号服务新增凭据删除、授权查询、帐号选择、认证器属性编辑和帐号可删除性判断的相关API。
