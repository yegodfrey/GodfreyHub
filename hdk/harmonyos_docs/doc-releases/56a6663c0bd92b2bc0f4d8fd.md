# 2021年9月15日

#### 版本信息

**软件包** | **发布类型** | **版本号** | **发布时间**  
---|---|---|---  
HarmonyOS SDK | Release | **Build Version****：** HarmonyOS SDK 2.2.0.3（API Version 6） | 2021/9/15  
DevEco Studio | Beta | **Version** ：DevEco Studio 2.2 Beta 2 **Build Version****：** DevEco Studio 2.2.0.400 | 2021/9/15  
  
#### 版本介绍

本次发布HarmonyOS SDK 2.2 Release，较前一版本在接口内容上无新增和变更。但对于JS API，部分在API Version 6 Beta版本不稳定的接口，在本次API Version 6 Release版本已经可以正常使用。

相较于API Version 5 Release，全部的接口变更请参见[Java API差异报告（API 5 -> API 6）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-java-api-6-0000001123842928)、[JS API 差异报告（API 5 -> API 6）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-js-api-6-phone-component-0000001170697425)。

另外，本次版本还有如下变更：

     * 在使用DevEco Studio进行JS工程开发时，支持JS FA调用PA代码的辅助开发。相关指导请参见[使用工具自动生成JS FA调用PA代码](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ui-js2java-codegen-0000001171039385)。
     * 配置文件config.json新增配置项“module > distroFilter”，用于定义HAP包对应的细分设备规格的分发策略，以便在应用市场进行云端分发应用包时做精准匹配。详细说明请参见[配置文件的元素](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/basic-config-file-elements-0000000000034463)。
