# （2022年11月）HarmonyOS 3.1 Developer Preview

#### 版本信息

**软件包** | **发布类型** | **版本号** | **发布时间**  
---|---|---|---

#### 版本介绍

本次发布HarmonyOS 3.1 Developer Preview，为开发者尝鲜版本，全新推出应用开发Stage模型，并在ArkTS语言、应用程序框架、web、ArkUI等子系统能力方面有所更新或增强。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230515172019.46223321418519752833749479683386:50001231000000:2800:F05F4EF741F0D8C46973C259F24FD7CABC56AB1B5664AD6519F113E36587478D.png?needInitFileName=true?needInitFileName=true)

     * 本次开发者尝鲜版本推荐开发者重点体验Stage模型下的HarmonyOS生态应用。但同时会存在部分历史接口暂未提供或暂不兼容等已知问题，这些接口将在HarmonyOS 3.1后续发布Beta及Release版本陆续补齐。详细的能力支持情况请参考[JS API差异报告（API 8 -> API 9 Canary1）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-js-api-9-arkui-0000001276484188)。
     * 如需浏览HarmonyOS 3.0 Release版本的文档，请在“指南”或“API参考”板块左上角切换版本到“HarmonyOS 3.0 Release”。

本次开放体验的功能包括：

     * Ability框架新增Stage开发模型，包含Stage模型生命周期管理、调度、回调、上下文获取、鉴权等。同时增强了应用的运行管理能力。
     * ArkUI开发框架增强了声明式Canvas/XComponent组件能力，增强了组件布局能力及状态管理能力，优化了部分组件的易用性。
     * 应用包管理新增查询应用、Ability和ExtensionAbility相关属性的接口。
     * 公共基础类库新增支持Buffer二进制读写。
     * Web服务新增支持文档类Web应用的文档预览和基础编辑功能，以及cookie的管理和存储管理。
     * 图形图像新增支持YUV、webp图片编解码等能力；新增native vsync能力，支持自绘制引擎自主控制渲染节奏。
     * 媒体服务新增相机配置与预览功能。
     * 窗口服务新增Stage模型下窗口相关接口，增强窗口旋转能力，增强避让区域查询能力。
     * 全球化服务新增支持时区列表、音译、电话号码归属地等国际化增强能力。
     * 公共事件基础能力增强，commonEvent模块变更为commonEventManager。
     * 资源管理服务新增资源获取的同步接口，新增基于名称查询资源值的接口，新增number、float资源类型查询接口，新增Stage模型资源查询方式。
     * 输入法服务新增输入法光标方向常量。

#### 遗留问题

#### [h2]Canary版本不兼容ErrorObserver类，影响registerErrorObserver与unregisterErrorObserver方法的使用

【问题描述】registerErrorObserver与unregisterErrorObserver方法依赖ErrorObserver作为入参或返回值，但ErrorObserver当前版本暂不兼容，导致上述方法无法使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】registerErrorObserver与unregisterErrorObserver方法暂不支持使用，但不影响体验Stage模型下的HarmonyOS生态应用。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容Configuration属性，影响部分接口的使用

【问题描述】Ability.onConfigurationUpdated、AbilityStage.onConfigurationUpdated、Options.onConfigurationUpdated、ExtensionAbility.onConfigurationUpdated等接口依赖Configuration属性值作为参数，Configuration属性暂不兼容导致上述接口无法使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】不支持对Configuration进行自定义的修改，但不影响体验Stage模型下的HarmonyOS生态应用。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容inputmethodengine.KeyEvent属性，影响部分键盘回调接口的使用

【问题描述】KeyboardDelegate.on_keyDown、KeyboardDelegate.on_keyUp、KeyboardDelegate.off_keyDown、KeyboardDelegate.off_keyUp等接口依赖KeyEvent属性值作为参数，inputmethodengine.KeyEvent属性暂不兼容会导致上述接口无法使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】涉及的接口非公共接口或基础能力接口，无法正常使用不影响体验Stage模型下的HarmonyOS生态应用。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容pasteboard.PasteDataProperty类，影响PasteData.getProperty()和PasteData.getMimeTypes()方法的使用

【问题描述】PasteData.getProperty(): PasteDataProperty方法依赖PasteDataProperty类作为参数；PasteData.getMimeTypes(): Array<string>用于获取PasteDataProperty类中的mimeTypes列表。pasteboard.PasteDataProperty类暂不兼容导致上述方法无法使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】涉及的接口非公共接口或基础能力接口，无法正常使用不影响体验Stage模型下的HarmonyOS生态应用。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容media.SeekMode枚举，影响media.seek方法的使用

【问题描述】media.seek方法依赖media.SeekMode枚举作为参数，media.SeekMode枚举暂不兼容导致media.seek方法无法使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】涉及的接口非公共接口或基础能力接口，无法正常使用不影响体验Stage模型下的HarmonyOS生态应用。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容media.BufferingInfoType枚举，影响相关回调接口的使用

【问题描述】media.BufferingInfoType的回调on(type: 'bufferingUpdate', callback: (infoType: BufferingInfoType, value: number) => void): void依赖BufferingInfoType枚举，该枚举暂不兼容会导致其事件回调仅可得到数值，无法对应具体的BufferingInfoType。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】涉及的接口非公共接口或基础能力接口，无法正常使用不影响体验Stage模型下的HarmonyOS生态应用。回调中的数值指代关系如下，可作为参考：

     * BUFFERING_START = 1
     * BUFFERING_END = 2
     * BUFFERING_PERCENT = 3
     * CACHED_DURATION = 4

不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容notification.SlotType枚举，影响reminderAgent相关接口的使用

【问题描述】reminderAgent.addNotificationSlot、reminderAgent.removeNotificationSlot方法依赖notification.SlotType枚举值作为入参，该枚举值暂不兼容，导致使用使用上述接口时不能通过枚举值作为入参。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】涉及的接口非公共接口或基础能力接口，无法正常使用不影响体验Stage模型下的HarmonyOS生态应用。在使用受影响的接口时，可使用具体数值替代枚举值，映射关系如下：

     * UNKNOWN_TYPE = 0，表示未知类型。
     * SOCIAL_COMMUNICATION = 1，表示社交类型。
     * SERVICE_INFORMATION = 2，表示服务类型。
     * CONTENT_INFORMATION = 3，表示内容类型。

不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容XComponentController.getXComponentSurfaceId，影响media.VideoPlayer相关接口的使用

【问题描述】VideoPlayer.setDisplaySurface方法依赖XComponentController.getXComponentSurfaceId获取SurfaceID显示视频播放画面，SDK中暂不支持接口getXComponentSurfaceId，影响VideoPlayer视频播放的正常使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】涉及的接口非公共接口或基础能力接口，无法正常使用不影响体验Stage模型下的HarmonyOS生态应用。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容Character类、Util类，影响部分接口的使用

【问题描述】i18n.Character.isDigit、i18n.Character.isSpaceChar、i18n.Util.unitConvert等接口暂不兼容静态调用，影响字符属性获取及度量衡转换功能的正常使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】涉及的接口非公共接口或基础能力接口，无法正常使用不影响体验Stage模型下的HarmonyOS生态应用。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不兼容sendRequest(code: number, data: MessageParcel, reply: MessageParcel, options: MessageOption): Promise<SendRequestResult>接口，影响调用该接口实现IPC通信的使用

【问题描述】调用sendRequest(code: number, data: MessageParcel, reply: MessageParcel, options: MessageOption): Promise<SendRequestResult>接口时编译报错。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】无法调用接口sendRequest(code: number, data: MessageParcel, reply: MessageParcel, options: MessageOption): Promise<SendRequestResult>进行IPC通信，可以使用sendRequest(code: number, data: MessageParcel, reply: MessageParcel, options: MessageOption, callback: AsyncCallback): void接口替代实现，不影响功能开发。不兼容接口会在后续Beta及Release版本中陆续补齐。

#### [h2]Canary版本不支持Stage模型下Context.getApplicationContext方法，影响应用上下文ApplicationContext的使用

【问题描述】Stage模型下应用上下文ApplicationContext通过Context.getApplicationContext方法获取，当前版本Context.getApplicationContext方法暂不兼容，导致ApplicationContext无法使用。

【发生版本】OpenHarmony SDK 3.2.1.4 Canary1

【问题影响】Context.getApplicationContext方法以及ApplicationContext的方法暂不支持使用，主要影响：

     1. 应用无法直接通过ApplicationContext获取应用数据根目录的Dir路径。

替代方案：可以通过AbilityContext获取Ability的Dir路径，拼接应用数据根目录

     2. 应用无法通过ApplicationContext注册监听所有Ability生命周期。

替代方案：应用需要自己维护监听功能，在各个Ability生命周期中添加状态监听，监听所有Ability的生命周期。

相关接口会在后续Beta及Release版本中陆续补齐。
