# （2022年2月）HarmonyOS 3.0 Preview 2

#### 版本信息

**软件包** | **发布类型** | **版本号** | **发布时间**  
---|---|---|---  
HarmonyOS SDK | Beta | **Build Version****：** HarmonyOS SDK 3.0.0.1（API Version 7 Beta2） | 2022/02/26  
DevEco Studio | Beta | **Version** ：DevEco Studio 3.0 Beta2 **Build Version****：** DevEco Studio 3.0.0.800 | 2021/12/31  
  
#### 版本介绍

本次发布HarmonyOS 3.0 Preview 2。相较上一版本，Java API无变更；JS API变更说明请参见[JS API 差异报告（API 6 -> API 7）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-js-api-7-ability-0000001341003238)。

主要变更说明如下：

     * 新增两个TS的文本输入组件：
       * 单行文本输入组件[TextInput](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-basic-components-textinput-0000001333321201)。

支持四种格式的单行文本输入（普通文本、密码、E-mail地址、纯数字）。

       * 多行文本输入组件[TextArea](https://developer.harmonyos.com/cn/docs/documentation/doc-references/ts-basic-components-textarea-0000001333800557)。
     * 窗口模块新增设置窗口类型的能力的JS接口setWindowType。

#### 遗留问题

#### [h2]富文本组件RichText内容显示异常

【问题描述】富文本组件RichText的内容显示异常，会导致终端用户无法查看使用RichText组件展示的内容。

【发生版本】该问题在API Version 7 Beta1出现。

【问题影响】RichText组件在API Version 7 Beta1及Beta2无法正常使用。该问题计划在API Version 7的后续版本修复。

#### [h2]手势事件无法传递到被遮挡的控件

【问题描述】多个图层存在覆盖遮挡时（尤其在上层控件透明时），被遮挡的控件可能无法接收到来自父布局分发的事件，导致用户主观体验为点击、滑动等手势动作无响应。

【发生版本】该问题在API Version 7 Beta1出现。

【优化方案】多控件覆盖场景，在API Version7不会将手势指令透传。开发者可以通过新增自定义热区功能，自定义事件热区来解决兄弟节点之间的遮挡问题。该问题计划在API Version 7的后续版本修复。

#### [h2]调试工程时，UX布局出现蓝色框线

【问题描述】调试应用工程时，应用的UX布局可能出现蓝色框线。如下图所示：
