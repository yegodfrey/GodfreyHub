# 2021年4月

#### 版本信息

**软件包** | **发布类型** | **版本号** | **发布时间**  
---|---|---|---  
HarmonyOS SDK | Release | **Build Version****：** HarmonyOS SDK 2.1.1.20（API Version 5） | 2021/4/30  
DevEco Studio | Beta | **Version** ：DevEco Studio 2.1 Beta 4 **Build Version****：** DevEco Studio 2.1.0.303 | 2021/4/30  
  
#### 版本介绍

     * 本次发布HarmonyOS SDK 2.1 Release，较前一版本在接口内容上无新增和变更。
     * 在配置文件“config.json”中，“reqPermissions > reason”字段的设置信息，支持在设备界面的权限申请弹窗中进行显示。
     * 新增提供服务卡片的开发指导。详见[服务卡片开发指南](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ability-service-widget-overview-0000001062607955)。
