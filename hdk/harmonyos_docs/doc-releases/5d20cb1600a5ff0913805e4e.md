# （2022年9月）HarmonyOS 3.0 Release

#### 版本信息

**软件包** | **发布类型** | **版本号** | **发布时间**  
---|---|---|---  
SDK | Release | 需同时获取如下SDK文件：
     * HarmonyOS SDK 3.1.1.2 （API Version 8 Release）
     * OpenHarmony SDK 3.1.7.6（API Version 8 Release）
| 2022/09/06  
SDK | Release | HarmonyOS SDK 3.0.0.5（API Version 7 Release） | 2022/09/06  
DevEco Studio | Release | **Version** ：DevEco Studio 3.0 Release **Build Version****：** DevEco Studio 3.0.0.993 | 2022/09/06  
  
#### 版本介绍

本次发布[HarmonyOS 3.0 Release](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/document-outline-js-ets-0000001282486428)。SDK更新说明如下：

     * API Version 8的HarmonyOS SDK更新为Release状态。API Version 8 Release相比API Version 7 Release的接口更新清单请参见：[JS API差异报告（API 7 -> API 8）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-js-api-8-arkui-0000001276484188)。
     * API Version 7的HarmonyOS SDK更新为Release状态。API Version 7 Release相比API Version 6 Release的接口更新清单请参见：[JS API差异报告（API 6 -> API 7）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-js-api-7-arkui-0000001341003226)。

同时，在前一版本（HarmonyOS 3.0 Beta）的基础上，更新支持如下特性：

     * 新增HUKS特性，向应用提供密钥库能力，包括密钥管理及密钥的密码学操作等功能。
     * 新增Webview特性，使ArkUI框架支持H5页面的加载和渲染能力。
