# （2023年5月）HarmonyOS 3.1 Release

#### 版本信息

**软件包** | **发布类型** | **版本号** | **发布时间**  
---|---|---|---

     * OpenHarmony SDK 3.2.12.2 (API Version 9 Release)
     * Previewer 3.2.3.6 (API Version 9 Release)
     * Toolchains 3.2.3.6 (API Version 9 Release)
| 2023/05/15  
DevEco Studio | Release | **Version** ：DevEco Studio 3.1 Release **Build Version****：** DevEco Studio 3.1.0.500 | 2023/05/15  
  
#### 版本介绍

本次发布HarmonyOS 3.1 Release，至此，与版本配套的SDK及SDK所包含的所有API Version 9的接口更新为Release状态。

相比上一版本（3.1 Beta2），API变更请参见“[JS API差异报告（API 9 Beta2 -> API 9 Release）](https://developer.harmonyos.com/cn/docs/documentation/doc-releases/apidiff-api-9-release-web-0000001582507077)”。

特性更新说明如下：

     * 元能力新增提供流转/协同入口管理服务能力，包括连接/取消流转管理服务，注册/解注册设备连接变化监听，拉起设备选择模块，更新连接状态。
     * 媒体新增接口支持使用AVPlayer开发音频播放的功能。
     * 分布式数据管理新增KVStore自动同步的能力。
     * 资源调度进一步补齐长短时任务触发的条件，包括网络条件（蓝牙、WiFi、以太网）以及充电条件（USB接口充电、无线充电）。
