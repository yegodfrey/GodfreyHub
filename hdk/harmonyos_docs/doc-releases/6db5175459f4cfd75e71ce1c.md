# 变更说明信息定义

从API 5 Release版本发布后，将在后续版本发布时例行提供相较上一个版本的SDK变更说明。

变更说明重点记录因API的变更对开发者调用API行为所产生的影响，并针对变更影响提供适配指导。

变更说明不对新增API进行说明。
