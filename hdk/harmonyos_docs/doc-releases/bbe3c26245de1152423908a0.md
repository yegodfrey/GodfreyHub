# V2.2 版本已知问题

#### V2.2 Beta2已知问题

在使用DevEco Studio V2.2 Beta2版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。
     * Video Player Ability(Java)、Device Control Ability(JS)、Image Editor Ability(Java)、Picture Browser Ability(Java)工程模板创建的工程不支持预览。
     * DeviceConfigureAbility(JS)模板创建的工程不支持Js调试。
     * Splash Screen Ability(JS)模板创建的工程，不支持app.terminate的写法，会存在调试问题。
     * 如果工程中存在多个模块，且“package”相同的情况下，不支持多hap安装和调试，您可以选择单个hap包进行调试。
     * About Ability(JS) 模板创建的工程，不支持this写法，会存在调试问题。
     * Phone和Tablet调试过程中，点击rotate按钮，会导致调试终止。

#### V2.1 Beta1已知问题

在使用DevEco Studio V2.2 Beta1版本过程中，您可能会遇到以下问题，我们将在后续版本中针对这些问题进行改进和优化。
     * 在hml文件中，当属性值为数值属性时，输入数值后的自动补全功能异常。
     * 在路由器真机设备上推包安装未签名的应用，Run窗口会显示推包成功，但实际未安装成功。
     * 使用Wearable真机和模拟器运行JS测试框架进行单步调试时，需要点两次Resume Program才能进入下一个断点。
     * 在Clock组件的预览时，预览界面中显示的时间和代码中设置的时间不一致。
     * Video Player Ability(Java)、Device Control Ability(JS)、Image Editor Ability(Java)、Picture Browser Ability(Java)工程模板创建的工程不支持预览。
     * DeviceConfigureAbility(JS)模板创建的工程不支持Js调试。
     * Splash Screen Ability(JS)模板创建的工程，不支持app.terminate的写法，会存在调试问题。
     * 如果工程中存在多个模块，且“package”相同的情况下，不支持多hap安装和调试，您可以选择单个hap包进行调试。
     * About Ability(JS) 模板创建的工程，不支持this写法，会存在调试问题。
     * 在macOS版本中，如果未在app.js中设置断点，则无法进入index.js中的断点。
     * Wearable和TV的调试不支持ES6 Symbol类型。
     * Phone和Tablet调试过程中，点击rotate按钮，会导致调试终止。
