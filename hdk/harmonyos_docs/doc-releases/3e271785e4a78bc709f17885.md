# 事件通知

#### 变更1 API异常处理方式变更

事件通知部分接口使用业务逻辑返回值表示错误信息，不符合HarmonyOS接口错误码规范。

**变更影响**

基于此前版本开发的应用，需适配变更接口的错误信息返回方式，否则会影响原有业务逻辑。

**关键的接口/组件变更**

下表中的“原接口”列废弃，“新接口”列为对应的新增替代接口。

新增接口支持统一的错误码异常处理规范，功能上与原接口保持一致。

原接口 | 新接口  
---|---  
@ohos.commonEvent.d.ts | @ohos.commonEventManager.d.ts  
@ohos.notification.d.ts | @ohos.notificationManager.d.ts  
@ohos.notification.d.ts | @ohos.notificationSubscribe.d.ts  
  
**适配指导**

如上所述，可以通过修改import来解决适配问题，以@ohos.commonEvent为例：

如原先接口使用了@ohos.commonEvent，之前的import为：
    
    import commonEvent from '@ohos.commonEvent'; 

现在则可以通过修改import，来适配进行开发：
    
    import commonEvent from '@ohos.commonEventManager'; 

另外，对于@ohos.notification来说，则拆分成了两个模块，需要根据接口情况选择对应的导入模块进行适配开发。

此外还需要适配异常处理，具体参考对应的新接口文档。
