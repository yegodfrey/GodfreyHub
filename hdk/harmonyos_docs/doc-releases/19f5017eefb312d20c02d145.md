# webview

#### 变更1 WebMessagePort类迁移

WebMessagePort类迁移至@ohos.web.webview.d.ts，并新增错误码抛出的功能。

**变更影响**

基于此前版本开发的应用，需注意d.ts的变更并import对应的模块。该类接口支持错误码处理，需同步注意错误码处理的使用。

**关键的接口/组件变更**

postMessageEvent(message: WebMessageEvent): void

onMessageEvent(callback: (result: string) => void): void

**适配指导**

原WebMessagePort类不需要import，现WebMessagePort类对应的import模块为@ohos.web.webview，参照如下方式：
    
    import web_webview from '@ohos.web.webview';

**适配指导**

原HitTestValue类不需要import，现HitTestValue类对应的import模块为@ohos.web.webview，参照如下方式：
    
    import web_webview from '@ohos.web.webview';

#### 变更5 WebAsyncController类迁移

WebAsyncController类的接口迁移至web.webview.WebviewController，并新增接口错误码抛出功能。

**变更影响**

该类接口支持错误码处理，需同步注意错误码处理的使用。

**关键的接口/组件变更**

storeWebArchive(baseName: string, autoName: boolean): Promise<string>

storeWebArchive(baseName: string, autoName: boolean, callback : AsyncCallback<string>): void

**适配指导**

     1. 原WebController类不需要import，现WebviewController类对应的import模块为@ohos.web.webview，参照如下方式：
            
            import web_webview from '@ohos.web.webview';

     2. 使用WebviewController类调用该方法。
            
            // xxx.ets
              import web_webview from '@ohos.web.webview'
            
              @Entry
              @Component
              struct WebComponent {
                controller: web_webview.WebviewController = new web_webview.WebviewController();
            
                build() {
                  Column() {
                    Button('saveWebArchive')
                      .onClick(() => {
                        try {
                          this.controller.storeWebArchive("/data/storage/el2/base/", true, (error, filename) => {
                            if (error) {
                              console.info(`save web archive error: ` + JSON.stringify(error))
                              return;
                            }
                            if (filename != null) {
                              console.info(`save web archive success: ${filename}`)
                            }
                          });
                        } catch (error) {
                          console.error(`ErrorCode: ${error.code},  Message: ${error.message}`);
                        }
                      })
                    Web({ src: 'www.example.com', controller: this.controller })
                  }
                }
              }
