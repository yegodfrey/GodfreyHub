# 1. 概述

HUAWEI LiteOS 是华为面向IoT领域，构建的轻量级物联网操作系统，以轻量级低功耗、快速启动、互联互通、安全等关键能力，为开发者提供 "一站式" 完整软件平台，有效降低开发门槛、缩短开发周期。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20190910001105.26053528687202857384798842158702:50510313080453:2800:F3297A1E570826D5C24853E87ADB1EEC2EC234A3EA8C97598AF9C5B64A47DD9D.png)

HUAWEI LiteOS 自开源社区发布以来，围绕NB-IoT物联网市场从技术、生态、解决方案、商用支持等多维度使能合作伙伴，构建开源的物联网生态，目前已经聚合了50+MCU和解决方案合作伙伴，共同推出一批开源开发套件和行业解决方案，帮助众多行业客户快速的推出物联网终端和服务，客户涵盖智能家居、抄表、停车、路灯、环保、物流等众多行业，加速物联网产业发展和行业数字化转型。

# 2. 关键特性

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20190910001105.02346996203464195488474015973405:50510313080453:2800:3F2E81A3177456DC888340CF1309C9428B06EF2A3F7D100CFE9C09875D6E97D5.png)

## 2.1 轻量级内核

特点：更小体积、更低功耗、更快响应。

合作伙伴和第三方开发者基于 HUAWEI LiteOS Kernel 能够快速开发智能硬件，产品具备快速启动、低功耗等竞争力。

## 2.2 传感框架

特点：更低时延、更高精度，传感智能化。

降低50%时延，2X +精确度，采集算法 > 智能算法。

## 2.3 互联引擎

特点：更多协议、更广互通，联接智能化。

互联互通中间件，支持短距、LTE、NB-IoT 等多种互联技术，解决IoT不同协议的设备互联互通，覆盖家庭互联、穿戴互联、工业互联等多种场景，在业务层面提供开放API和业务Profile，方便开发者开发应用，实现不同设备间互操。

## 2.4 运行引擎

特点：更轻框架、更好性能，应用智能化。

面向物联网的应用开发框架：使能轻量级物联网设备JavaScript开发； JS框架、JS虚拟机和OS协同优化性能和功耗。


高性能、轻量级 JavaScript 虚拟机：极小的ROM和内存占用空间； 提供独立用户空间和应用隔离，保护应用安全。
