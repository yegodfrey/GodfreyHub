# IAR编译器

#### IAR RWPI&ROPI动态库文件头格式

动态库文件头遵循如下格式：
    
    typedef struct {
    uint32_t magicWords;    // 动态库文件头魔术字，每个不同的动态库可以配置不同的魔术字
    uint32_t romBase;       // 动态库ROM基地址
    uint32_t romLength;     // 动态库bin文件大小，或理解为ROM大小，包含.text代码段，.rodata const数据段，.data_init data数据的初始化信息段等数据信息
    uint32_t dataLength;    // 动态库数据段大小
    void* init;             // 动态库初始化函数
    void* deinit;           // 动态库去初始化函数
    uint32_t methodsLen;    // 动态库对外提供的接口个数
    void* methods[];        // 动态库对外接口列表
    } LosBinInfo;

**表1** 动态库文件头格式字段说明字段 | 大小（字节）  
---|---  
动态库头魔术字 | 4  
ROM起始地址 | 4  
ROM空间大小 | 4  
RAM空间大小 | 4  
动态库init函数地址 | 4  
动态库deinit函数地址 | 4  
动态库对外提供接口个数 | 4  
  
IAR编译器提供los_fu_header.s文件内定义了动态库bin文件的头格式，如下：
    
    __los_fu_header
    DCD     (0x484d2e62)                     ; magic words，不同动态库，可以定义不同魔术字
    DCD     ROM$$Base                        ; ROM begin，对应icf 脚本里面 __ICFEDIT_region_ROM_start__的值
    DCD     ROM$$Length                      ; ROM 段size，对应icf脚本里面 movable block ROM空间的大小
    DCD     RWPI$$Length                     ; RAM 段size，对应icf脚本里面 movable block RWPI空间的大小
    DCD     __init - __los_fu_header         ; init 入口函数在bin文件内的偏移位置，__los_fu_header为bin文件起始位置，init-__los_fu_header则为init 函数在bin文件内的偏移位置
    DCD     __deinit - __los_fu_header       ; __deinit 函数在bin文件内的偏移位置
    DCD     2                                ; 动态库对外提供2个接口函数
    DCD     __testParam1 - __los_fu_header   ; 接口函数__testParam1在bin文件内的偏移位置
    DCD     __testParam2 - __los_fu_header   ; 接口函数__testParam2在bin文件内的偏移位置
    DCD     0                                ; reserved
    DCD     0                                ; reserved
    DCD     0                                ; reserved
    DCD     0                                ; reserved
    DCD     0                                ; reserved
    DCD     0                                ; reserved
    DCD     0                                ; reserved
    DCD     0                                ; reserved
    END

#### 编译环境准备

本文描述使用IAR软件在demo工程中编译第三方SDK库的方法，供三方SDK团队开发lib库使用。

#### [h2]IAR工具下载

     1. 建议使用与华为相同的版本IAR版本：9.30.1。

下载地址<https://www.iar.com/products/architectures/arm/iar-build-tools-for-arm/>，选择安装IAR Embedded Workbench for Arm。

     2. 激活License后在License Manager中查看License信息。

#### [h2]编译环境配置

配置项 | 描述  
---|---  
芯片类型 | 选择适用的ARM芯片类型。  
双精度 | 配置浮点数运算精度设置。  
编译选项 | 配置编译优化选项和相关参数。  
配置生成.bin | 确保编译输出为.bin格式文件。

ICF文件配置 | 新建ICF配置文件，IAR配置ICF文件路径指向新建的ICF文件。  
  
#### 数据初始化

IAR 数据初始化，在__init 函数内调用__losInitFunc，__losInitFunc调用__iar_data_init3完成data 数据初始化，__iar_data_init3内实现在IAR库文件内不可见。
    
    void __losInitFunc(void* val)
    {
        //1. set R9
        asm volatile (
            "mov  r9, r0       \n"
        );
        //2. init data
        __iar_data_init3();
    }
    int __init(void ** symbols, int symbolLen, void *dataAddr, unsigned int *appVer)
    {
       __losInitFunc(dataAddr);
       return 0;
    }

#### icf链接脚本实现

     1. 定义ROPI ROM block。
            
            define movable block ROM with alignment = 4, fixed order
            {
            readonly section .intvec,
            readonly,
            readonly section .checksum
            };

     2. 定义RWPI RAM block。
            
            define movable block RWPI with alignment = 8, fixed order, static base
            {
            rw,
            block HEAP
            };

     3. 指定ROPI ROM block到ROM Region。
            
            "ROM":
            place in ROM_region   { block ROM };

     4. 指定RWPI RAM block到RAM Region。
            
            "RAM":
            place in RAM_region   { block RWPI };
