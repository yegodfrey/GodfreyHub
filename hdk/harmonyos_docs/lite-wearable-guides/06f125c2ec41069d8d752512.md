# 开发指导书  
  
#### 功能概述

为了方便音乐应用的开发者，本文档提供基于轻量级智能穿戴设备开发指导。

#### 接口说明

**音频操作接口**

函数名 | 功能描述  
---|---  
play():void | 开始播放音频。  
pause():void | 暂停播放音频。  
stop():void | 停止音频播放，可以通过play重新播放音频  
getPlayState(Object): void | 获取当前播放状态数据。  
  
**音频属性说明**

名称 | 参数类型 | 可读 | 可写 | 必填 | 描述  
---|---|---|---|---|---  
src | string | 是 | 是 | 是 | 播放的音频媒体uri。  
currentTime | number | 是 | 否 | 否 | 音频的当前进度，单位秒。  
duration | number | 是 | 否 | 否 | 音频的播放时长，单位秒，未知返回NaN。  
autoplay | boolean | 是 | 是 | 否 | 音频是否自动播放，默认false。 true表示音频自动播放。 false表示音频不自动播放。  
loop | boolean | 是 | 是 | 否 | 音频是否循环播放，默认false。 true表示音频循环播放。 false表示音频不循环播放。  
volume | number | 是 | 是 | 否 | 音频的音量，音量变化范围[0.0,1.0]，默认为当前系统媒体音量。  
muted | boolean | 是 | 是 | 否 | 音频是否静音，默认false。 true表示静音。 false表示不静音。  
  
播放回调事件

名称 | 描述  
---|---  
onplay | 在调用play方法后的回调事件。  
onpause | 在调用pause方法后的回调事件。  
onstop | 在调用stop方法后的回调事件。  
onloadeddata | 第一次获取到音频数据的回调事件。  
onended | 播放结束时的回调事件。  
onerror | 播放发生错误时的回调事件。  
ontimeupdate | 播放进度变化时的回调事件。  
  
#### 约束与限制

     * 音乐文件名称长度限定为256字节（含结束符）。
     * 手表侧音乐应用包名长度限制为32字节（含结束符）。
     * 同一时刻只支持播放一个音乐应用。
     * 受硬件能力限制，不支持指定进度进行播放。
     * 只支持MP3格式音乐文件。

MP3音频文件

歌单文件

音乐信息文件

#### 音乐目录划分

音乐应用的私有数据根目录是internal://app/，音乐文件放在music目录下，歌单文件放在internal://app/folder目录下，音乐信息文件放在internal://app/music_info目录下。

**表1** 各目录作用目录名 | 作用  
---|---  
music | 音乐文件目录。  
folder | 歌单文件目录。  
music_info | 音乐信息文件目录。
