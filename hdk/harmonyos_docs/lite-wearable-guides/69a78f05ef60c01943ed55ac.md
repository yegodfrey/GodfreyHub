# 通用二维码支付场景开发指导书

该指导书用于指导二维码开发者完成支付SDK的开发。

**基本概念**

     * BLE（低功耗蓝牙）：用于手机App与手表设备之间的无线通信。
     * GATT（通用属性配置文件）：BLE通信的服务和特征值定义。
     * Service UUID：蓝牙服务的唯一标识符。
     * Characteristic UUID：蓝牙特征值的唯一标识符。
     * Binding Status（绑定状态）：设备与支付账号的绑定关系状态。

#### [h2]绑定流程

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/54/v3/xnHO2MsWTRivmwvgBN265w/zh-cn_image_0000002645027048.png?HW-CC-KV=V1&HW-CC-Date=20261005T092456Z&HW-CC-Expire=86400&HW-CC-Sign=1284502D7976072CA7EF981F0F0382DED393F4DD8D7BCE98BEA449FCDC859FED)

预置App（Huawei_App）调用支付SDK（PaymentSDK）的接口获取绑定状态，当属于未绑定时，启动绑定流程：

     1. 获取绑定二维码流程。 
        1. Step1：启动绑定流程。
        2. Step2：华为预置App调用支付SDK获取绑定二维码。
        3. Step3：支付SDK根据内部算法生成绑定二维码。
        4. Step4：华为预置App显示绑定二维码。
     2. 手机手表建立BLE蓝牙通道流程。 
        1. Step1：启动绑定流程。
        2. Step2：华为预置App调用支付SDK接口获取蓝牙信息。
        3. Step3：华为预置App调用系统蓝牙(watchBluetooth)发送蓝牙广播。
        4. Step4-5：华为预置App调用支付SDK接口订阅绑定状态，更新绑定状态。
        5. Step6-7：手机侧支付App扫描绑定二维码，和手表建立BLE蓝牙通道。
     3. 绑定流程。 
        1. Step1：手机侧支付App通过蓝牙通道发送数据给手表侧华为预置App。
        2. Step2：华为预置App调用支付SDK接口将手机侧支付App的数据写入。
        3. Step3：支付SDK解析并且存储从手机侧App传输的数据。
        4. Step4-5：支付SDK调用接口通知华为预置App更新绑定状态。
        5. Step6：支付SDK调用接口通知华为预置App，发送数据给手机侧支付App。
        6. Step7-9：华为预置App调用通过蓝牙接口将数据发送给手机侧支付App，手机侧支付App完成数据存储。
        7. Step10-14：支付SDK调用接口通知华为预置App更新绑定状态，直到绑定完成。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/1iWH5mB2QSSYAaOS2jvwSg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T092456Z&HW-CC-Expire=86400&HW-CC-Sign=5944736A97D57B1DD0A19B3F1C354137227BE9D254D61E44BE64B58ADE01EF5B)

BLE广播接口定义：

     * 支付厂商的蓝牙Service UUID，用于区分其他蓝牙广播，例如：00004576-0000-3000-80455-00806f9b3。
     * 对应的CHARACTERISTIC UUID，例如：02337890-0123-3258-80455-00806f9b3。
     * CHARACTERISTIC权限：PROPERTY_WRITE + PROPERTY_READ + PROPERTY_NOTIFY。
     * 在广播包的Service UUID服务数据中填入系统设备ID，以便手机找到对应设备。
     * 广播原始数据长度不超过31字节。
     * 蓝牙广播频率和周期：每100ms广播一次，绑定完成或支付应用退出后停止蓝牙广播。

#### [h2]支付流程

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/lfKB0bkUTgiyG2jetxPJjg/zh-cn_image_0000002675346743.png?HW-CC-KV=V1&HW-CC-Date=20261005T092456Z&HW-CC-Expire=86400&HW-CC-Sign=43FE7DF4E0495AA999E3B35E300035E0441B93FCBA4E705E0D3AA207F9083EB6)

Step1-2：当启动应用，华为预置App获取支付SDK的绑定状态为已经绑定。

Step3-5：华为预置App调用支付SDK接口获取支付二维码，并且在手表侧显示支付二维码。

Step6-7：POS机扫码支付二维码，并且将支付二维码发送给支付服务器。

Step8-9：支付服务器根据支付二维码和前期绑定信息进行校验，根据校验结果返回支付结果。

#### [h2]解绑流程

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/8nYNTqz4R02JO5z6UPmUHA/zh-cn_image_0000002645186948.png?HW-CC-KV=V1&HW-CC-Date=20261005T092456Z&HW-CC-Expire=86400&HW-CC-Sign=0F459D39A8892807628233168CA6FA0EA2587E022FB6C619AA56F4DA014289EB)

Step1：用户从手表侧点击“解绑”。

Step2：预置App调用支付SDK解绑接口。

Step3-4：支付SDK删除本地绑定相关的数据，返回解绑结果。

Step5：手表侧显示解绑结果。

#### 接口说明

接口具体使用方法和说明请参考[thirdpay.h](https://developer.huawei.com/consumer/cn/doc/lite-wearable-guides/bin-compilation-tool-demo#section19194519455)，该文件定义了三方支付SDK中需要实现的接口，以及穿戴设备/手表侧提供给三方支付SDK调用的回调函数。

其中，void* val是非功能性参数，用于恢复特定寄存器R9的初始值，SDK需要在每个接口入口调用THIRDPAY_SDK_SetR9接口。示例：
    
    ThirdPay_RetCode ThirdPay_EnvInit(void* val) {
        THIRDPAY_SDK_SetR9(val);
        return RETCODE_OK;
    }
    
    void THIRDPAY_SDK_SetR9(void* val)
    {
        asm volatile ("mov r9, r0 \n");
    }
