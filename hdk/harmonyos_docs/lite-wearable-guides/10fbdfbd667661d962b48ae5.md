# 解决方案

#### 方案简介

轻量级穿戴设备不支持在线播放音频，只支持从手机侧影音App通过Wear Engine Kit传输音频文件到手表App，支持手表影音App本地播放音频，也支持通过手表影音App控制手机侧音视频的播放控制（启动/停止/下一首/暂停等）。

手表侧本地音频播放如果涉及加解密，则需要手表侧生态应用提供对应的解密库。

该解决方案仅适用于轻量级智能穿戴设备。

#### 方案架构

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/TCfnDJSiSlqYMtz1NfHWow/zh-cn_image_0000002645428990.png?HW-CC-KV=V1&HW-CC-Date=20261005T092456Z&HW-CC-Expire=86400&HW-CC-Sign=031975DD074F344ACD8F93C4760C86A191FE307C9C69F4C6549C911E9D655801)

音频服务：提供场景化的音频播放接口，助力开发者迅速构建音频播放能力。

生态应用：应用开发者通过调用JS API接口，利用音频系统提供的软/硬件能力，实现应用所需的播放功能。

解密库和音频文件：对于加密音乐文件，开发者需要提供配套的解密库，由音频服务加载和调用。

Wear Engine Kit：主要用于手机侧生态应用和手表应用之间的分布式通信。

华为运动健康应用：和穿戴设备通过蓝牙连接，主要支持手机侧生态应用的Wear Engine Kit的鉴权，部分手机型号支持手机和穿戴设备生态应用之间的数据传输。

#### 方案约束

手表侧只能播放音频，不支持视频，支持的音频格式仅mp3格式。
