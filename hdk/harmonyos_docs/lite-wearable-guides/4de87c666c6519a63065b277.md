# 解决方案

#### 方案简介

轻量级智能穿戴支持Wear Engine Kit，通过手机侧App和手表侧App分布式互通的方式，支持出行生态场景。

轻量级智能穿戴支持通过手机华为运动健康App联网，支持在线出行生态场景。

该解决方案同时适用于轻量级智能穿戴设备和智能穿戴设备。

#### 方案架构

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/OrS_IK13TGOhRhaS-NZS8Q/zh-cn_image_0000002645429698.png?HW-CC-KV=V1&HW-CC-Date=20261005T092457Z&HW-CC-Expire=86400&HW-CC-Sign=957014890DBB02CFE2112F8593F2DB9A5EE7191B2B7C95B21AEA58249A85F870)

Wear Engine Kit：主要用于手机侧生态应用和手表应用之间的分布式通信。

华为运动健康应用（华为运动健康App）：和手表通过蓝牙连接，主要支持手机侧生态应用的Wear Engine Kit的鉴权，部分手机型号支持手机和手表生态应用之间的数据传输。

#### 方案约束

轻量级智能穿戴仅支持HTTP协议栈，当支持在线出行场景时，需要和开发者提前沟通对HTTP协议栈的依赖（仅部分国家和地区不支持，可以咨询本地技术支持）。
