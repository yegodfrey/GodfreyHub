# 功能介绍

穿戴历史产品使用IAR编译器，IAR编译器提供了RWPI&ROPI 动态加载技术。穿戴生态音频类、海外二维码支付等生态使用了RWPI&ROPI 技术进行开发。因此毕昇编译器也支持了RWPI&ROPI 动态加载技术，用于支撑音频类、海外支付等三方生态开发。

RWPI&ROPI动态加载技术，可以实现多个动态库根据业务场景加载到同一个地址空间运行，节省加载三方库的运行空间。

**基本概念**

     * RWPI&ROPI：ROPI全称为Read-Only Position Independence，表示只读位置无关，RWPI全称为Read-Write Position Independence，表示读写位置无关。
