# CommonEvent_SubscribeInfo

> phone 12+ | 2in1 13+ | tablet 12+ | tv 19+ | wearable 18+

```c
typedef struct CommonEvent_SubscribeInfo CommonEvent_SubscribeInfo
```

## 概述

提供公共事件订阅者信息结构体声明。该结构体用于描述订阅者的配置信息，在调用创建订阅者接口时作为参数传入。

**起始版本：** 12

**相关模块：** [OH_CommonEvent](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-oh-commonevent)

**所在头文件：** [oh_commonevent.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-oh-commonevent-h)
