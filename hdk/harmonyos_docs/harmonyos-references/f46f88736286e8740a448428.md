# FAST_Rect

#### 概述

定义矩形的数据结构（坐标系说明：X轴从左到右递增，Y轴从上到下递增）。

系统能力： SystemCapability.FAST.Core

起始版本： 6.0.2(22)

相关模块： [FAST](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/fast-kit-fast)

所在头文件： [fast_solver_rect_partition.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/fast-kit-fast-solver-rect-partition-8h)
