# ArkUI_TextLayoutManager

> phone 22+ | 2in1 22+ | tablet 22+ | tv 22+ | wearable 22+

```c
typedef struct ArkUI_TextLayoutManager ArkUI_TextLayoutManager
```

## 概述

定义文本布局管理器对象，用于对文本进行布局处理，适用于需要精细控制文本显示和排版效果的场景，可帮助开发者实现自定义的文本布局需求。

**起始版本：** 22

**相关模块：** [ArkUI_NativeModule](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-arkui-nativemodule)

**所在头文件：** [styled_string.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-styled-string-h)
