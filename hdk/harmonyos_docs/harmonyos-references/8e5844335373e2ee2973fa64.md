# ArkUI_RoundRectShape

```
typedef struct ArkUI_RoundRectShape ArkUI_RoundRectShapeOption
```

#### 概述

定义圆角矩形形状配置项，用于配置圆角矩形形状，并可用于创建渲染节点遮罩或裁剪。

起始版本： 20
