# ContentEmbed_ExtensionProxy

> phone 24+ | 2in1 24+ | tablet 24+

```c
typedef struct ContentEmbed_ExtensionProxy ContentEmbed_ExtensionProxy
```

声明ContentEmbed_ExtensionProxy结构体类型。用于指向OE文档在客户端封装的文档嵌入和编辑的程序对象（简称客户端OE对象）。
