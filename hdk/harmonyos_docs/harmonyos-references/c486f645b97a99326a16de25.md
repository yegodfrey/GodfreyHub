# hiai_helper.h

## 概述

查询CANN Kit版本以及检查模型支持情况的接口。

**引用文件：** <CANNKit/hiai_helper.h>

**库：** libhiai_foundation.so

**系统能力：** SystemCapability.AI.HiAIFoundation

**起始版本：** 4.1.0(11)

**相关模块：** [CANN](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/cannkit)
