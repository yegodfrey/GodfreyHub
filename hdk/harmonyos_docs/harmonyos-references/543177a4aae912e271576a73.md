# ArkUI_EmbeddedComponentOption

> phone 20+ | 2in1 20+ | tablet 20+ | tv 20+ | wearable 20+

```c
typedef struct ArkUI_EmbeddedComponentOption ArkUI_EmbeddedComponentOption
```

## 概述

为EmbeddedComponent定义配置参数ArkUI_EmbeddedComponentOption，用于在创建或配置EmbeddedComponent时设置该组件的配置选项，适用于需要在页面中嵌入并管理其他组件的嵌入式UI开发场景。

**起始版本：** 20

**相关模块：** [ArkUI_NativeModule](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-arkui-nativemodule)

**所在头文件：** [embedded_component.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-embedded-component-h)
