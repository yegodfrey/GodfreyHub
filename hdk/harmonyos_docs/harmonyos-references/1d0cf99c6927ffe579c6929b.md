# OH_NativeBundle_AbilityResourceInfo

> phone 21+ | 2in1 21+ | tablet 21+ | tv 21+ | wearable 21+

```c
struct OH_NativeBundle_AbilityResourceInfo
```

## 概述

表示Ability资源信息，用于存储和传递Ability的基本配置信息，包括名称、类型等属性，适用于Native层查询和管理Ability资源的场景。

**起始版本：** 21

**相关模块：** [Native_Bundle](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-bundle)

**所在头文件：** [ability_resource_info.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-ability-resource-info-h)
