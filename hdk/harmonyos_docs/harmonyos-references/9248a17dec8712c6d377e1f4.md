# OHAudioSuite

> phone 22+ | 2in1 22+ | tablet 22+

## 概述

提供音频编创相关C接口定义。

**系统能力：** SystemCapability.Multimedia.Audio.SuiteEngine

**起始版本：** 22

## 文件汇总

|名称|描述|
|:--------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
|[native_audio_suite_base.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-audio-suite-base-h)|声明音频编创相关底层数据结构。|
|[native_audio_suite_engine.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-audio-suite-engine-h)|声明与音频编创相关接口（包括引擎、管线、节点）。|
|[native_audio_converter.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-audio-converter-h)|声明输入音频格式、输出音频格式底层数据结构和格式转换接口。 **起始版本：** 26.0.0|
