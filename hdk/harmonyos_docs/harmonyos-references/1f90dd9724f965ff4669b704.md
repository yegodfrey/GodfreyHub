# ArkUI_RenderNode\*

```
typedef struct ArkUI_RenderNode* ArkUI_RenderNodeHandle
```

#### 概述

定义渲染节点指针，用于在ArkUI_RenderNodeUtils相关接口中表示和传递渲染节点对象。

起始版本： 20

相关模块： [ArkUI_RenderNodeUtils](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-arkui-rendernodeutils)
