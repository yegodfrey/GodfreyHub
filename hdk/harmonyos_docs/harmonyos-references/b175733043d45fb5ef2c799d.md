# ArkUI_RenderContentModifier\*

```
typedef struct ArkUI_RenderContentModifier* ArkUI_RenderContentModifierHandle
```

#### 概述

定义渲染内容修改器指针，用于引用内容修改器。内容修改器可挂载到渲染节点，并附加渲染属性或设置onDraw回调。

起始版本： 20

相关模块： [ArkUI_RenderNodeUtils](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-arkui-rendernodeutils)

所在头文件： [native_render.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-native-render-h)
