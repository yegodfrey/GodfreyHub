# AbilityRuntime_StartOptions

> phone 17+ | 2in1 17+ | tablet 17+ | tv 19+ | wearable 18+

```c
typedef struct AbilityRuntime_StartOptions AbilityRuntime_StartOptions
```

## 概述

表示启动Ability时的配置选项结构体。开发者可以通过此结构体设置启动Ability时的窗口模式、显示ID、动画效果、窗口位置和大小、显示模式、启动图标、背景颜色、支持的窗口模式等配置参数。

**起始版本：** 17

**相关模块：** [AbilityRuntime](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-abilityruntime)

**所在头文件：** [start_options.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-start-options-h)
