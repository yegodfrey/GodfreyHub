# AREngine_ClipPlaneDistance

#### 概述

裁剪平面距离数据。

作为[HMS_AREngine_ARCamera_GetProjectionMatrix](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arengine-capi-arengine#hms_arengine_arcamera_getprojectionmatrix)接口输入。

起始版本： 5.0.0(12)

相关模块： [AR Engine](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arengine-capi-arengine)

所在头文件： [ar_engine_core.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/arengine-header-file)  

#### 汇总

#### 成员变量

|名称|描述|
|:------------------|:-------------------|
|float [near](#near)|OpenGL近裁剪平面距离，以m为单位。|
|float [far](#far)|OpenGL远裁剪平面距离，以m为单位。|
