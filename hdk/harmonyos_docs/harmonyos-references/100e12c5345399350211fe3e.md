# FG_Dimension2D

> phone 5.0.0(12)+ | tablet 5.0.0(12)+ | tv 6.1.0(23)+

## 概述

此结构体描述2D图像分辨率，以px为单位。

**起始版本：** 5.0.0(12)

**相关模块：** [GraphicsAccelerate](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/_graphics_accelerate)

**所在头文件：** [frame_generation_base.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/frame__generation__base_8h)

## 汇总

### 成员变量

|名称|描述|
|:-------------------------|:-----------|
|uint32_t [width](#width)|图像宽度，以px为单位。|
|uint32_t [height](#height)|图像高度，以px为单位。|

## 结构体成员变量说明

### height

```c
uint32_t FG_Dimension2D::height
```

**描述**

图像高度，以px为单位。

### width

```c
uint32_t FG_Dimension2D::width
```

**描述**

图像宽度，以px为单位。
