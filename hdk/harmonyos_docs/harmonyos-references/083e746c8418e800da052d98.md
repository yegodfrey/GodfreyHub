# HuksExternalCryptoApi

> phone 26.0.0+ | 2in1 22+ | tablet 24+

## 概述

通用密钥库（HUKS）针对外部密钥管理扩展的能力，包括提供者管理、Ukey PIN码管理及其它对应用提供的操作接口。

**起始版本：** 22
