# HiAppEvent_Processor

> phone 18+ | 2in1 18+ | tablet 18+ | tv 19+ | wearable 18+

```c
typedef struct HiAppEvent_Processor HiAppEvent_Processor
```

## 概述

应用事件上报的处理者。用于事件的上报和管理，开发者可自定义数据处理配置，满足不同的数据处理需求。

**起始版本：** 18
