功能：根据输入参数创建并运行一个子进程，等待该子进程运行完毕并返回子进程退出状态。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240621215209.03737372659083674513860012349487:50001231000000:2800:211BF131696AAE17CAB9300D563BE6E257B138207708AB4F9640B32E6937D77D.png?needInitFileName=true?needInitFileName=true)
    * 在 Windows 平台上，在子进程执行完成后立即删除子进程的可执行文件可能删除失败并抛出异常，异常信息为 Access is denied，如果遇到该问题，可以在一小段延迟后重新尝试删除该文件，详细实现可参考示例。
参数：
    * command: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 指定子进程命令，command 不允许包含空字符。

    * environment!: ?[Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek)<[String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string), [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string)> \- 命名可选参数，指定子进程环境变量，默认继承当前进程环境变量，key 不允许字符串中包含空字符或 '='，value 不允许字符串中包含空字符。
    * stdIn!: [ProcessRedirect](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_process_package_enums#enum-processredirect) \- 命名可选参数，指定子进程重定向标准输入，默认继承当前进程标准输入。

    * stdErr!: [ProcessRedirect](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_process_package_enums#enum-processredirect) \- 命名可选参数，指定子进程重定向标准错误，默认继承当前进程标准错误。
    * timeout!: ?[Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) \- 命名可选参数，指定等待子进程超时时间，默认为不超时, timeout 指定为 0 或负值时表示不超时。
返回值：
    * [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64) \- 返回子进程退出状态，若子进程正常退出，返回子进程退出码，若子进程被信号杀死，返回导致子进程终止的信号编号。

    * [ProcessException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_process_package_exceptions#class-processexception) \- 当内存分配失败或 command 对应的命令不存在或等待超时，抛出异常。
