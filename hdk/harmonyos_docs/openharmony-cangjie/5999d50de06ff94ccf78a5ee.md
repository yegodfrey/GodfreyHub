功能：获取输入流的下一个 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 的类型，不保证下一个 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 的格式一定正确。 例：如果输入流中的下一个字符为 't'，获取的 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 将为 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken).[Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool)，但调用 readValue<[Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool)>() 不一定成功。 返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken)> \- 获取到的下一个 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 的类型，如果到了输入流的结尾返回 None。
异常：
    * [IllegalStateException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-illegalstateexception) \- 如果输入流的下一个字符不在以下范围内：(n, t, f, ", 0~9, -, {, }, [, ])。

功能：从输入流的当前位置读取一个 value。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240621215232.23037557111981130462553864574917:50001231000000:2800:8C0626A94A58E912FA8D8DA281461F9D35C9639FA32A6B866005F4AEEEB1D366.png?needInitFileName=true?needInitFileName=true) 当泛型 T 是 [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) 类型时，根据下一个 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 的不同，该函数的返回值将会不同：
    * 当下一个 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 是 [JsonString](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonstring) 时， 反序列化过程会按照标准 [ECMA-404 The JSON Data Interchange Standard](https://www.ecma-international.org/publications-and-standards/standards/ecma-404/) 对读到的 [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) 进行转义。
    * 当下一个 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 是 [JsonInt](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonint) [JsonFloat](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonfloat) [JsonBool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonbool) [JsonNull](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonnull) 其中一个时，将会读取下一个 value 字段的原始字符串并返回。
    * 当下一个 [JsonToken](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_enums#enum-jsontoken) 是其它类型时，调用此接口会抛异常。
返回值：
    * T - 读取出的 value 值。
异常：
    * [IllegalStateException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-illegalstateexception) \- 如果输入流的 JSON 数据不符合格式，抛出异常。
[h2]func skip()
    
    public func skip(): Unit

功能：从输入流的当前位置跳过一组数据。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240621215232.50926484667254593456941873202562:50001231000000:2800:3A096B8852BF1AD6E5A9F3BE1F0DC98BAC90436E5296F2900103406A8A26BA49.png?needInitFileName=true?needInitFileName=true) Skip 的规则如下：
    * 如果 next token 是 value，跳过这个 value, 跳过 value 时不检查该 value 格式是否正确。
    * 如果 next token 是 Name，跳过 (name + value) 这一个组合。
    * 如果 next token 是 BeginArray，跳过这个 array。
    * 如果 next token 是 BeginObject，跳过这个 object。
    * 如果 next token 是 EndArray 或者 EndObject 或者 None，不做任何操作，peek 仍返回 EndArray 或者 EndObject 或者 None。
异常：
    * [IllegalStateException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-illegalstateexception) \- 如果输入流的 JSON 数据不符合格式，抛出异常。

功能：将实现了 [JsonSerializable](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_interfaces#interface-jsonserializable) 接口的类型写入到 Stream 中。该接口会调用泛型 T 的 toJson 方法向输出流中写入数据。 json.stream 包已经为基础类型 [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64)、[UInt64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#uint64)、[Float64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#float64)、[Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool)、[String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string)类型扩展实现了 [JsonSerializable](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_interfaces#interface-jsonserializable)， 并且为 [Collection](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_interfaces#interface-collectiont) 类型 [Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)、[ArrayList](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-arraylistt)和 [HashMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-hashmapk-v-where-k--hashable--equatablek) 扩展实现了 [JsonSerializable](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_interfaces#interface-jsonserializable)。 返回值：
    * [JsonWriter](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonwriter) \- 返回当前 [JsonWriter](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonwriter) 的引用。
异常：
    * [IllegalStateException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-illegalstateexception) \- 当前 writer 的状态不应该写入 value 时。
