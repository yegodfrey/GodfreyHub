class XmlParser
    
    public class XmlParser {
        public init()
        public init(handler: SaxHandler)
    }

功能：此类提供 XML 解析功能。 目前支持两种模式：文档对象模型（DOM）模式和 XML 简单 API（SAX）模式，暂不支持外部实体功能，以及 <? ?> 形式的指令声明。 支持 5 个内置符号的解析，如下表所示： 符号 | 字符  
---|---  
< | &lt;, &#60;, &#x3c;  
> | &gt;, &#62;, &#x3e;  
& | &amp;, &#38;, &#x26;  
' | &apos;, &#39;, &#x27;  
" | &quot;, &#34;, &#x22;

[h2]func parse(String)
    
    public func parse(str: String): Option<XmlElement>

功能：解析字符串类型的 XML 文本。 参数：
    * str: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- XML 文本，最大解析长度 2^32 - 1, 即 [UInt32](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#uint32) 的最大值。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[XmlElement](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/xml_package_classes#class-xmlelement)> \- DOM 模式下如果解析成功则返回 [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[XmlElement](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/xml_package_classes#class-xmlelement)>.Some(element)，失败则返回 [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[XmlElement](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/xml_package_classes#class-xmlelement)>.None；SAX 模式下返回 [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[XmlElement](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/xml_package_classes#class-xmlelement)>.None。
异常：
    * [XmlException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/xml_package_exceptions#class-xmlexception) \- 当内存分配失败，或解析文本出错，或存在空指针时，抛出异常。
    * [IllegalArgumentException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-illegalargumentexception) \- 当 XML 文本中包含字符串结束符时，抛出异常。
