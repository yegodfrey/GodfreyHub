接口 interface ConcurrentMap<K, V> where K <: Equatable<K>
    
    public interface ConcurrentMap<K, V> where K <: Equatable<K> {
        func get(key: K): Option<V>
        func contains(key: K): Bool
        mut func put(key: K, value: V): Option<V>
        mut func putIfAbsent(key: K, value: V): Option<V>
        mut func remove(key: K): Option<V>
        mut func remove(key: K, predicate: (V) -> Bool): Option<V>
        mut func replace(key: K, value: V): Option<V>
        mut func replace(key: K, eval: (V) -> V): Option<V>
        mut func replace(key: K, predicate: (V) -> Bool, eval: (V) -> V): Option<V>
    }

功能：保证线程安全和操作原子性的 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 接口定义。 [ConcurrentMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_concurrent_interface#interface-concurrentmapk-v-where-k--equatablek) 接口中声明了并发场景下线程安全的 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 必须保证**原子性** 的方法，我们希望定义的线程安全 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 类都能实现 [ConcurrentMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_concurrent_interface#interface-concurrentmapk-v-where-k--equatablek) 接口。例如我们在该包中定义的 [ConcurrentHashMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_concurrent_class#class-concurrenthashmapk-v-where-k--hashable--equatablek) 就实现了 [ConcurrentMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_concurrent_interface#interface-concurrentmapk-v-where-k--equatablek) 接口，并提供了 [ConcurrentMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_concurrent_interface#interface-concurrentmapk-v-where-k--equatablek) 中所声明方法的保证原子性的实现。 [ConcurrentMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_concurrent_interface#interface-concurrentmapk-v-where-k--equatablek) 接口中声明了并发 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 在并发场景下需要保证原子性的方法。 并发 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 为“键”到“值”的映射，其中 K 为键的类型，V 为值的类型。 [h2]func contains(K)
    
    func contains(key: K): Bool

功能：判断 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中是否包含指定键 key 的关联。 参数：
    * key: K - 传递要判断的 key。
返回值：
    * [Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool) \- 当 key 存在时返回 true；当 key 不存在时返回 false。
[h2]func get(K)
    
    func get(key: K): Option<V>

功能：返回 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中键 key 所关联的值。 参数：
    * key: K - 传递 key，获取 value。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 当 key 存在时，返回其关联的值 Some(v)；当 key 不存在时，返回 None。
[h2]func put(K, V)
    
    mut func put(key: K, value: V): Option<V>

功能：将指定的值 value 与此 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中指定的键 key 关联。如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中已经包含键 key 的关联，则旧值将被替换；如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中不包含键 key 的关联，则添加键 key 与值 value 的关联。 参数：
    * key: K - 要放置的键。
    * value: V - 要关联的值。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 如果赋值之前 key 存在，则返回旧的值 Some(v)；当赋值前 key 不存在时，返回 None。
[h2]func putIfAbsent(K, V)
    
    mut func putIfAbsent(key: K, value: V): Option<V>

功能：当此 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中不存在键 key 时，在 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中添加指定的值 value 与指定的键 key 的关联。如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 已经包含键 key，则不执行赋值操作。 参数：
    * key: K - 要放置的键。
    * value: V - 要分配的值。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 如果赋值之前 key 存在，则返回当前 key 对应的值 Some(v)，且不执行赋值操作；当赋值前 key 不存在时，返回 None。
[h2]func remove(K)
    
    mut func remove(key: K): Option<V>

功能：从此映射中删除指定键 key 的映射（如果存在）。 参数：
    * key: K - 传入要删除的 key。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 如果移除之前 key 存在，则返回 key 对应的值 Some(v)；当移除时 key 不存在时，返回 None。
[h2]func remove(K, (V) -> Bool)
    
    mut func remove(key: K, predicate: (V) -> Bool): Option<V>

功能：如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中存在键 key 且 key 所关联的值 v 满足条件 predicate，则从 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中删除 key 的关联。 参数：
    * key: K - 传入要删除的 key。
    * predicate: (V) ->[Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool) \- 传递一个 lambda 表达式进行判断。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中存在 key，则返回 key 对应的旧值 Some(v)；当 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中不存在 key 时，或者 key 关联的值不满足 predicate 时，返回 None。
[h2]func replace(K, (V) -> Bool, (V) -> V)
    
    mut func replace(key: K, predicate: (V) -> Bool, eval: (V) -> V): Option<V>

功能：如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中存在键 key（假设其关联的值为 v），且 v 满足条件 predicate，则将 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中键 key 关联的值替换为 eval(v) 的计算结果；如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中不存在键 key，或者存在键 key 但关联的值不满足 predicate，则不对 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 做任何修改。 参数：
    * key: K - 传入要替换所关联值的键。
    * predicate: (V) ->[Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool) \- 传递一个 lambda 表达式进行判断。
    * eval: (V) ->V - 传入计算用于替换的新值的函数。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 如果 key 存在，则返回 key 对应的旧值 Some(v)；当 key 不存在时，或者 key 关联的值不满足 predicate 时，返回 None。
[h2]func replace(K, (V) -> V)
    
    mut func replace(key: K, eval: (V) -> V): Option<V>

功能：如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中存在键 key（假设其关联的值为 v），则将 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中键 key 关联的值替换为 eval(v) 的计算结果；如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中不存在键 key，则不对 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 做任何修改。 参数：
    * key: K - 传入要替换所关联值的键。
    * eval: (V) ->V - 传入计算用于替换的新值的函数。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 如果 key 存在，则返回 key 对应的旧值 Some(v)；当 key 不存在时，返回 None。
[h2]func replace(K, V)
    
    mut func replace(key: K, value: V): Option<V>

功能：如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中存在 key，则将 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中键 key 关联的值替换为 value；如果 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 中不存在 key，则不对 [Map](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_interface#interface-mapk-v-where-k--equatablek) 做任何修改。 参数：
    * key: K - 传入要替换所关联值的键。
    * value: V - 传入要替换成的新值。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<V> \- 如果 key 存在，则返回 key 对应的旧值 Some(v)；当 key 不存在时，返回 None。
