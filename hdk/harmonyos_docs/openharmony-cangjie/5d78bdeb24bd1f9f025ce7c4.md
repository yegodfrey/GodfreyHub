func diagReport(DiagReportLevel, Tokens, String, String)
    
    public func diagReport(level: DiagReportLevel, tokens: Tokens, message: String, hint: String): Unit

功能：报错接口，在编译过程的宏展开阶段输出错误提示信息，支持 WARNING 和 ERROR 两个等级的报错。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240621215145.25897962241217310168108258631315:50001231000000:2800:0C0E1988E3251C994C33AC59212A28FB346A71D5EC8092FCC9B9544BAB68E42A.png?needInitFileName=true?needInitFileName=true)
    * 该接口在 错误等级为 ERROR 时会终止编译过程，但不会终止宏展开过程，建议用户调用接口后直接 return 或者抛出异常来终止宏展开过程。
    * 该接口会按照 cjc 标准报错的接口，将传入的 tokens 所在行的代码列出，并对 tokens 的内容用波浪线进行标注， message 信息将展示在首行， hint 信息将紧跟波浪线进行展示。
    * 报错引用的源码内容目前仅依据第一个 [Token](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_structs#struct-token) 的开始位置和最后一个 [Token](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_structs#struct-token) 的结束位置确定，不校验中间 [Token](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_structs#struct-token) 位置信息的一致性。
    * 该接口在非宏展开过程中调用无效，参见[示例代码](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/report#非宏展开过程中调用示例)。
参数：
    * level: [DiagReportLevel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_enums#enum-diagreportlevel) \- 报错信息等级。
    * tokens: [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) \- 报错信息中所引用源码内容对应的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens)。
    * message: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 报错的主信息。
    * hint: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 辅助提示信息。
异常：
    * [ASTException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_exceptions#class-astexception) \- 当输入的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 存在以下错误时，抛出异常。
      * 输入的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 为空；
      * 输入的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 中的 [Token](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_structs#struct-token) 来自于不同的源文件；
      * 输入的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 中首位 [Token](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_structs#struct-token) 位置早于末位 [Token](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_structs#struct-token) 位置；
      * 输入的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 中的 [Token](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_structs#struct-token) 位置范围超出了宏调用的位置范围。

func parseDecl(Tokens, String)
    
    public func parseDecl(input: Tokens, astKind!: String = ""): Decl

功能：用于解析一组词法单元，获取一个 [Decl](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-decl) 类型的节点。 参数：
    * input: [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) \- 待解析源码的词法单元。
    * astKind!: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 用于指定解析特定的节点类型，有效支持的值为：PrimaryCtorDecl 和 PropMemberDecl。
      * PrimaryCtorDecl: 解析主构造函数。
      * PropMemberDecl: 解析prop声明的getter和setter函数。
返回值：
    * [Decl](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-decl) \- 一个 [Decl](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-decl) 类型的节点。
异常：
    * [ParseASTException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_exceptions#class-parseastexception) \- 当输入的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 类型无法构造为 [Decl](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-decl) 节点时，抛出异常。
示例：
    1. 以下代码展示 astKind 设为 PropMemberDecl 的案例。在这个参数下，可以使用 parseDecl 解析 prop 的getter和setter函数，解析结果为 FuncDecl 类型（如果不设置astKind，则会因为没有 func 关键字而无法解析）。
           
           import std.ast.*
           
           main() {
               let getter = quote( get() { _val } )
               let setter = quote( set(v) { _val = v })
               let getterDecl = parseDecl(getter, astKind: "PropMemberDecl")
               let setterDecl = parseDecl(setter, astKind: "PropMemberDecl")
               println((getterDecl as FuncDecl).getOrThrow().block.toTokens())
               println((setterDecl as FuncDecl).getOrThrow().block.toTokens())
           }

运行结果：
           
           {
               _val
           }
           
           {
               _val = v
           }

    2. 以下代码展示 astKind 设为 PrimaryCtorDecl 的案例。在这个参数下，可以使用 parseDecl 解析主构造函数节点，解析结果为 PrimaryCtorDecl 类型（如果不设置 astKind，则会因为没有 func 关键字而无法解析）。
           
           import std.ast.*
           
           main() {
               let ctor = quote(
                   Point(var x: Int32, var y: Int32) {}
               )
               let ctorDecl = parseDecl(ctor, astKind: "PrimaryCtorDecl")
               println(ctorDecl is PrimaryCtorDecl)
               println(ctorDecl.toTokens())
           }

运行结果：
           
           true
           Point(var x: Int32, var y: Int32) {
           }
