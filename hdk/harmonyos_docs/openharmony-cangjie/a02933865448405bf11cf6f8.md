compress.zlib 包 功能介绍zlib 压缩解压库。 本包使用自研 deflate 算法，支持 deflate-raw 和 gzip 数据格式，支持快速、默认、高压缩率三种压缩等级，压缩速度依次下降，压缩率依次提升。 本包提供流式压缩和解压功能，即支持从输入流读取数据，将其压缩或解压，并写入字节数组，或从字节数组中读取数据，将其压缩或解压，并写入输出流。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240621215225.41557437555389295399582737959927:50001231000000:2800:9332234C20C3E0BDDF7EBBF33E8180A9B345E67617824B2EE02D628A5B6EF115.png?needInitFileName=true?needInitFileName=true) 本包暂不支持文件打包功能。 API 列表 [h2]类 类名 | 功能
