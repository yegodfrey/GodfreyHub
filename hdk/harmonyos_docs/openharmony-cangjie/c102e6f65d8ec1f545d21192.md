枚举 enum OverflowStrategy
    
    public enum OverflowStrategy {
        | saturating
        | throwing
        | wrapping
    }

溢出策略枚举类，共包含 3 种溢出策略。[BigInt](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_structs#struct-bigint) 类型转换为整数类型时，允许指定不同的溢出处理策略。 [h2]saturating
    
    saturating

功能：出现溢出，当前值大于目标类型的 MAX 值，返回目标类型 MAX 值，当前值小于目标类型的 MIN 值，返回目标类型 MIN 值。 [h2]throwing
    
    throwing

功能：出现溢出，抛出异常。 [h2]wrapping
    
    wrapping

功能：出现溢出，高位截断。
