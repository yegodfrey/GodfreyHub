interface ToTokens
    
    public interface ToTokens {
        func toTokens(): Tokens
    }

功能：实现对应类型的实例到 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 类型转换的接口，作为支持 quote 插值操作必须实现的接口。 [h2]func toTokens()
    
    func toTokens(): Tokens

功能：实现对应类型的实例到 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 类型的转换。 返回值：
    * [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) \- 转换后的 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens)。

    func toTokens(): Tokens

功能：实现 [Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt) 类型到 [Tokens](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/ast_package_classes#class-tokens) 类型的转换，仅支持数值类型、[Rune](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#rune) 类型、[Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool) 类型、[String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) 类型。 返回值：
