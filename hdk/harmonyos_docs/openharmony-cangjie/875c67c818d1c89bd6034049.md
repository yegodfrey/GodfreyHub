函数 func fromHexString(String)
    
    public func fromHexString(data: String): Option<Array<Byte>>

功能：此函数用于 Hex 编码的字符串的解码。 参数：
    * data: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 要解码的 Hex 编码的字符串。
返回值：
    * [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)<[Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte)>> \- 输入空字符串会返回 [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)<[Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte)>>.Some([Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)<[Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte)>())，解码失败会返回 [Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)<[Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)<[Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte)>>.None。
func toHexString(Array<Byte>)
    
    public func toHexString(data: Array<Byte>): String

功能：此函数用于将 [Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte) 数组转换成 Hex 编码的字符串。 参数：
    * data: [Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)<[Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte)> \- 要编码的 [Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte) 数组。
返回值：
    * [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 返回编码后的字符串。
