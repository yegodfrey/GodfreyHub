类 class SimpleLogger
    
    public class SimpleLogger <: Logger {
        public init()
        public init(name: String, level: LogLevel, output: OutputStream)
    }

功能：此类实现 [Logger](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_interfaces#interface-logger) 接口，提供基础的日志打印和管理功能。 包括自定义日志名称，控制日志打印级别，自定义输出流，默认情况下，日志名称为 “[Logger](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_interfaces#interface-logger)”，打印级别为 INFO，输出流为 stdOut。 [h2]prop level
    
    public mut prop level: LogLevel

功能：获取和修改日志打印级别。 类型：[LogLevel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_enums#enum-loglevel) [h2]init()
    
    public init()

功能：创建一个默认的 [SimpleLogger](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_classes#class-simplelogger) 实例。 [h2]init(String, LogLevel, OutputStream)
    
    public init(name: String, level: LogLevel, output: OutputStream)

功能：创建一个 [SimpleLogger](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_classes#class-simplelogger) 实例，指定日志名称，日志打印级别和输出流。 参数：
    * name: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 日志名称。
    * level: [LogLevel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_enums#enum-loglevel) \- 日志级别。
    * output: [OutputStream](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/io_package_interfaces#interface-outputstream) \- 输出流。
