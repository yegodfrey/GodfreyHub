std.collection 包 功能介绍collection 包提供了常见数据结构的高效实现、相关抽象的接口的定义以及在集合类型中常用的函数功能。 本包实现了以下常用的数据结构：
    * [ArrayList](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-arraylistt)：变长的连续数组，在需要存储不确定数量的数据，或者需要根据运行时的条件动态调整数组大小时使用 ArrayList，使用 ArrayList 可能会导致内存分配和释放的开销增加，因此需要谨慎使用。
    * [LinkedList](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-linkedlistt)：链表结构， LinkedList 的优点是它可以动态地添加或删除元素，而不需要移动其他元素。这使得它在需要频繁添加或删除元素的情况下非常有用。它还可以轻松地进行修改或删除操作，并且可以在列表中存储多个元素。 LinkedList 的缺点是它需要额外的内存来存储每个元素的引用，这可能会导致内存浪费。
    * [HashMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-hashmap)：哈希表，它存储键值对，并且可以根据键快速访问值。在需要使用映射关系并且需要快速查找时使用。
    * [HashSet](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-hashsett-where-t--hashable--equatablet)：基于哈希表实现的集合数据结构，它可以用于快速检索和删除元素，具有高效的插入、删除和查找操作。
    * [TreeMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-treemapk-v-where-k--comparablek)：基于红黑树实现的有序映射表。通常情况下，当需要将元素按照自然顺序或者自定义顺序进行排序时，可以使用TreeMap。
collection 包提供的集合类型都不支持并发安全，并发安全的集合请见 [collection.concurrent 包](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_concurrent_package_overview)。 API 列表 [h2]函数 函数名 | 功能
