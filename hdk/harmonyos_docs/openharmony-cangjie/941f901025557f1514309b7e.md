异常类 class SecureRandomException
    
    public class SecureRandomException <: Exception {
        public init()
        public init(message: String)
    }

功能：crypto 包安全随机数的异常类。 [h2]init()
    
    public init()

功能：创建默认的 [SecureRandomException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/crypto_package_exceptions#class-securerandomexception) 实例，异常提示消息为空。 [h2]init(String)
    
    public init(message: String)

功能：根据异常信息创建 [SecureRandomException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/crypto_package_exceptions#class-securerandomexception) 实例。 参数：
    * message: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 异常提示信息。
