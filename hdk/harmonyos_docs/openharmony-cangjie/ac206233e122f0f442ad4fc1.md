接口 interface DurationExtension
    
    public interface DurationExtension {
        operator func *(r: Duration): Duration
    }

功能：[DurationExtension](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_interfaces#interface-durationextension) 用于拓展 [Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) 实例作为右操作数时，返回乘积为新 [Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) 实例的乘法运算。 [h2]operator func *(Duration)
    
    operator func *(r: Duration): Duration

功能：实现 T 类型（T 是实现 [DurationExtension](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_interfaces#interface-durationextension) 接口的类型）和 [Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) 类型的乘法，即 T * [Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) 运算。 参数：
    * r: [Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) \- 乘法的右操作数。
返回值：
    * [Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) \- T 类型实例和 r 的乘积。
异常：
    * [ArithmeticException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-arithmeticexception) \- 当相乘后的结果超出 [Duration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/time_package_structs#struct-duration) 的表示范围时，抛出异常。
