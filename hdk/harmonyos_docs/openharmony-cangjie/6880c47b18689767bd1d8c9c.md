枚举 enum OpenOption
    
    public enum OpenOption {
        | Append
        | Create(Bool)
        | CreateOrAppend
        | CreateOrTruncate(Bool)
        | Open(Bool, Bool)
        | Truncate(Bool)
    }

功能：表示不同的文件打开选项。 [h2]Append
    
    Append

功能：构造一个 [OpenOption](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_enums#enum-openoption) 实例，指定文件系统应打开现有文件并查找到文件尾，用这个选项创建的 [File](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_classes#class-file) 默认只具有 Write 权限，试图查找文件尾之前的位置时会引发 [FSException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_exceptions#class-fsexception) 异常，并且任何试图读取的操作都会失败并引发 [FSException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_exceptions#class-fsexception) 异常。如果文件不存在，则将引发 [FSException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_exceptions#class-fsexception) 异常。 [h2]Create(Bool)
    
    Create(Bool)

功能：构造一个 [OpenOption](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_enums#enum-openoption) 实例，指定文件系统应创建新文件，用这个选项创建的 [File](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_classes#class-file) 默认具有 Write 权限，可以通过参数指定是否具有 Read 权限。如果文件已存在，则将引发 [FSException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_exceptions#class-fsexception) 异常。 [h2]CreateOrAppend
    
    CreateOrAppend

功能：构造一个 [OpenOption](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_enums#enum-openoption) 实例，指定文件系统应打开文件（如果文件存在），否则，应创建新文件。用这个选项创建的 [File](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_classes#class-file) 默认只具有 Write 权限，并且试图查找文件尾之前的位置时会引发 [FSException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_exceptions#class-fsexception) 异常。分为两种情况：如果文件不存在，则使用 Create；否则使用 Append。 [h2]CreateOrTruncate(Bool)
    
    CreateOrTruncate(Bool)

功能：构造一个 [OpenOption](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_enums#enum-openoption) 实例，指定文件系统应创建新文件，如果此文件已存在，则会将其覆盖。用这个选项创建的 [File](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_classes#class-file) 默认具有 Write 权限，可以通过参数指定是否具有 Read 权限。分为两种情况：如果文件不存在，则使用 Create；否则使用 Truncate。 [h2]Open(Bool, Bool)
    
    Open(Bool, Bool)

功能：构造一个 [OpenOption](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_enums#enum-openoption) 实例，指定文件系统应打开现有文件，第一个参数指定文件是否具有 Read 权限，第二个参数指定文件是否具有 Write 权限。如果文件不存在，则将引发 [FSException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_exceptions#class-fsexception) 异常。 [h2]Truncate(Bool)
    
    Truncate(Bool)

功能：构造一个 [OpenOption](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_enums#enum-openoption) 实例，指定文件系统应打开现有文件，该文件被打开时，将被截断为零字节大小。用这个选项创建的 [File](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_classes#class-file) 默认具有 Write 权限，可以通过参数指定是否具有 Read 权限。如果文件不存在，则将引发 [FSException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/fs_package_exceptions#class-fsexception) 异常。
