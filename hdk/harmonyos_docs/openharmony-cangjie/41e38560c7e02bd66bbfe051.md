函数 func field<T>(String, T)
    
    public func field<T>(name: String, data: T) : Field where T <: Serializable<T>

功能：此函数用于将一组数据 name 和 data 封装到 [Field](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-field) 对象中。处理一组数据 name 和 data，将 data 序列化为 [DataModel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-datamodel) 类型，并将二者封装到 [Field](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-field) 对象中。 参数：
    * name: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) 类型，name 字段为 "" 时行为与为其它字符串时一致。
    * data: T - T 类型，T 类型必须实现 [Serializable](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_interfaces#interface-serializable)<T> 接口。
返回值：
    * [Field](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-field) \- 封装了 name 和 data 的 [Field](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-field) 对象。
