异常 class ConcurrentModificationException  
      
    public class ConcurrentModificationException <: Exception {
        public init()
        public init(message: String)
    }

功能：并发修改异常类。当函数检测到不同步的并发修改，抛出异常。 由于 collection 包提供的容器类都不支持并发修改，因此在执行某些操作时，会抛出 [ConcurrentModificationException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_exception#class-concurrentmodificationexception)。 典型的抛异常场景有：
    * 使用 for-in 遍历一个容器过程中对容器进行修改时([HashMapIterator](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-hashmapiteratork-v-where-k--hashable--equatablek)的[remove](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_posix_package_funcs#func-removestring)() 方法除外)。
    * 在使用声明周期较短的类型，如 [EntryView](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/colleciton_package_struct#struct-entryviewk-v-where-k--hashable--equatablek)、[TreeMapNode](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/colleciton_package_struct#struct-treemapnodek-v-where-k--comparablek) 时，如果其所在的容器内容被修改，也会抛出异常。
