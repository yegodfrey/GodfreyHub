std.math.numeric 包 功能介绍math.numeric 包对基础类型可表达范围之外提供扩展能力。 例如：
    1. 支持大整数(BigInt)；
    2. 提供常见的数学运算能力。
API 列表 [h2]函数 函数名 | 功能  
---|---  
[abs(BigInt)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_funcs#func-absbigint) | 求一个 BigInt 的绝对值。  
[sqrt(BigInt)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_funcs#func-sqrtbigint) | 求 BigInt 的算数平方根，向下取整。  
[gcd(BigInt, BigInt)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_funcs#func-gcdbigint-bigint) | 求两个 BigInt 的最大公约数。总是返回非负数（相当于绝对值的最大公约数）。  
[lcm(BigInt, BigInt)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_funcs#func-lcmbigint-bigint) | 求两个 BigInt 的的最小公倍数。除了入参有 0 时返回 0 外，总是返回正数（相当于绝对值的最小公倍数）。  
[max(BigInt, BigInt)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_funcs#func-maxbigint-bigint) | 计算并返回两个 BigInt 中较大的那个。  
[min(BigInt, BigInt)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_funcs#func-minbigint-bigint) | 计算并返回两个 BigInt 中较小的那个。  
[countOne(BigInt)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_funcs#func-countonebigint) | 计算并返回入参 BigInt 的二进制补码中 1 的个数。  
[h2]枚举 枚举 | 功能  
---|---  
[OverflowStrategy](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_enums#enum-overflowstrategy) | 溢出策略枚举类，共包含 3 种溢出策略。BigInt 类型转换为整数类型时，允许指定不同的溢出处理策略。  
[h2]结构体 结构体 | 功能
