class RSAPrivateKey
    
    public class RSAPrivateKey <: PrivateKey{
        public init(bits: Int32)
        public init(bits: Int32, e: BigInt)
    }

功能：RSA 私钥类，提供生成 RSA 私钥能力，RSA 私钥支持签名和解密操作，支持 PEM 和 DER 格式的编码解码，符合 PKCS1 标准。 [h2]init(Int32)
    
    public init(bits: Int32)

功能：init 初始化生成私钥, 公钥指数默认值为 65537，业界推荐。公钥指数e的大小直接影响了RSA算法的安全性和加密效率。通常情况下，e的值越小，加密速度越快，但安全性越低。 参数：
    * bits: [Int32](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int32) \- 密钥长度，需要大于等于 512 位，并且小于等于 16384 位。
异常：
    * [CryptoException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/digest_package_exceptions#class-cryptoexception) \- 密钥长度不符合要求或初始化失败，抛出异常。
[h2]init(Int32, BigInt)
    
    public init(bits: Int32, e: BigInt)

功能：init 初始化生成私钥，允许用户指定公共指数。 参数：
    * bits: [Int32](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int32) \- 密钥长度，需要大于等于 512 位，并且小于等于 16384 位，推荐使用的密钥长度不小于 3072 位。
    * e: [BigInt](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_structs#struct-bigint) \- 公钥公共指数，范围是 [3, 2^256-1] 的奇数。
异常：
    * [CryptoException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/digest_package_exceptions#class-cryptoexception) \- 密钥长度不符合要求、公钥公共指数值不符合要求或初始化失败，抛出异常。
