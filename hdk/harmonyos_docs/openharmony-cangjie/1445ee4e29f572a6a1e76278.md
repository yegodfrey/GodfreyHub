encoding 模块 encoding 功能介绍encoding 模块提供字符编解码功能。 支持 Base64、Hex、JSON、URL、XML 格式数据的编解码。 encoding 模块的包列表encoding 模块提供了如下包： 包名 | 功能  
---|---  
[base64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/base64_package_overview) | base 包提供字符串的 Base64 编码及解码。  
[hex](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/hex_package_overview) | hex 包提供字符串的 Hex 编码及解码。  
[json](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/json_package_overview) | json 包用于对 json 数据的处理，实现 String, JsonValue, DataModel 之间的相互转换。  
[json.stream](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/json_stream_package_overview) | json.stream 包主要用于仓颉对象和 JSON 数据流之间的互相转换。  
[url](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/url_package_overview) | url 包提供了 URL 相关的能力，包括解析 URL 的各个组件，对 URL 进行编解码，合并 URL 或路径等。  
[xml](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/xml_package_overview) | xml 包提供 XML 文本处理能力。
