encoding.json 包 功能介绍json 包用于对 JSON 数据的处理，实现 String, JsonValue, DataModel 之间的相互转换。 JsonValue 是对 JSON 数据格式的封装，包括 object, array, string, number, true, false 和 null。 DataModel 详细信息可参考：[serialization 包文档](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-datamodel)。 JSON 语法规则可参考：[介绍 JSON](https://www.json.org/json-zh.html)。 JSON 数据转换标准可参考：[ECMA-404 The JSON Data Interchange Standard](https://www.ecma-international.org/publications-and-standards/standards/ecma-404/)。 API 列表 [h2]接口 接口名 | 功能  
---|---  
[ToJson](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_interfaces#interface-tojson) | 用于实现 JsonValue 和 DataModel 的相互转换。  
[h2]类 类名 | 功能  
---|---  
[JsonArray](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonarray) | 创建空 JsonArray。  
[JsonBool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonbool) | 将指定的 Bool 类型实例封装成 JsonBool 实例。  
[JsonFloat](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonfloat) | 将指定的 Float64 类型实例封装成 JsonFloat 实例。  
[JsonInt](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonint) | 将指定的 Int64 类型实例封装成 JsonInt 实例。  
[JsonNull](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonnull) | 将 JsonNull 转换为字符串。  
[JsonObject](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonobject) | 创建空 JsonObject。  
[JsonString](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonstring) | 将指定的 String 类型实例封装成 JsonString 实例。  
[JsonValue](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonvalue) | 此类为 JSON 数据层, 主要用于 JsonValue 和 String 数据之间的互相转换。  
[h2]枚举 枚举名 | 功能  
---|---  
[JsonKind](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_enums#enum-jsonkind) | 表示 JsonValue 的具体类型。
