类 class CompressInputStream
    
    public class CompressInputStream <: InputStream {

    }

功能：压缩输入流。 可将 [CompressInputStream](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_classes#class-compressinputstream) 实例绑定到任意 [InputStream](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/io_package_interfaces#interface-inputstream) 输入流，将该输入流中的数据压缩，并输出到字节数组。 [h2]init(InputStream, WrapType, CompressLevel, Int64)
    
    public init(inputStream: InputStream, wrap!: WrapType = DeflateFormat, compressLevel!: CompressLevel = DefaultCompression, bufLen!: Int64 = 512)

功能：构造一个压缩输入流。 需绑定一个输入流，可设置压缩数据格式、压缩等级、内部缓冲区大小（每次从输入流中读取多少数据进行压缩）。 参数：
    * inputStream: [InputStream](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/io_package_interfaces#interface-inputstream) \- 待压缩的输入流。
    * wrap!: [WrapType](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_enums#enum-wraptype) \- 压缩数据格式，默认值为 [DeflateFormat](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_enums#deflateformat)。
    * compressLevel!: [CompressLevel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_enums#enum-compresslevel) \- 压缩等级，默认值为 [DefaultCompression](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_enums#defaultcompression)。
    * bufLen!: [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64) \- 输入流缓冲区的大小，取值范围为 (0, [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64).Max]，默认 512 字节。
异常：
    * [ZlibException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_exceptions#class-zlibexception) \- 当 bufLen 小于等于 0，输入流分配内存失败，或压缩资源初始化失败，抛出异常。

功能：关闭压缩输入流。 当前 [CompressInputStream](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_classes#class-compressinputstream) 实例使用完毕后必须调用此函数来释放其所占内存资源，以免造成内存泄漏。调用该函数前需确保 [read](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_classes#func-readarraybyte) 函数已返回 0，否则可能导致绑定的 [InputStream](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/io_package_interfaces#interface-inputstream) 并未被全部压缩。 异常：
    * [ZlibException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_exceptions#class-zlibexception) \- 如果释放压缩资源失败，抛出异常。

    * [ZlibException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_exceptions#class-zlibexception) \- 当 outBuf 为空，或压缩数据失败，抛出异常。

[h2]func close()
    
    public func close(): Unit

功能：关闭当前压缩输出流实例。 关闭时，将写入剩余压缩数据（包括缓冲区中数据，以及压缩尾部信息），并释放其所占内存资源。当前压缩输出流使用完毕后必须调用此函数来释放其所占内存资源，以免造成内存泄漏。在调用 [close](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_classes#func-close-1) 函数前，绑定的输出流里已写入的数据并不是一段完整的压缩数据，调用 [close](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_classes#func-close-1) 函数后，才会把剩余压缩数据写入绑定的输出流，使其完整。 异常：
    * [ZlibException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_exceptions#class-zlibexception) \- 如果当前压缩输出流已经被关闭，或释放压缩资源失败，抛出异常。

    * [ZlibException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/zlib_package_exceptions#class-zlibexception) \- 如果当前压缩输出流已经被关闭，抛出异常。
