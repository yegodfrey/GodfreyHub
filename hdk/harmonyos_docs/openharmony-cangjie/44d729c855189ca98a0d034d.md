接口 interface JsonDeserializable<T>
    
    public interface JsonDeserializable<T> {
        static func fromJson(r: JsonReader): T
    }

功能：此接口用于实现从 [JsonReader](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonreader) 中读取一个仓颉对象。 支持的对象类型包括： 基本数据类型：整数类型、浮点类型、布尔类型、字符串类型。 [Collection](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_interfaces#interface-collectiont) 类型：[Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)、[ArrayList](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-arraylistt)、[HashMap](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/collection_package_class#class-hashmapk-v-where-k--hashable--equatablek)、[Option](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_enums#enum-optiont)。 [BigInt](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/math_numeric_package_structs#struct-bigint) 类型。 [h2]static func fromJson(JsonReader)
    
    static func fromJson(r: JsonReader): T

功能：从参数 r 指定的 [JsonReader](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonreader) 实例中读取一个 T 类型对象。 参数：
    * r: [JsonReader](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonreader) \- 读取反序列化结果的 [JsonReader](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonreader) 实例。
返回值：
    * T - T 类型的实例。
interface JsonSerializable
    
    public interface JsonSerializable {
        func toJson(w: JsonWriter): Unit
    }

功能：为类型提供序列化到 JSON 数据流的接口。 与 [JsonWriter](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonwriter) 搭配使用，[JsonWriter](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonwriter) 可以将实现了 [JsonSerializable](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_interfaces#interface-jsonserializable) 接口的类型写入到 Stream 中。 [h2]func toJson(JsonWriter)
    
    func toJson(w: JsonWriter): Unit

功能：将实现了 [JsonSerializable](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_interfaces#interface-jsonserializable) 接口的类型写入参数 w 指定的 [JsonWriter](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonwriter) 实例中。 参数：
    * w: [JsonWriter](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonwriter) \- 写入序列化结果的 [JsonWriter](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_stream_package_classes#class-jsonwriter) 实例。
