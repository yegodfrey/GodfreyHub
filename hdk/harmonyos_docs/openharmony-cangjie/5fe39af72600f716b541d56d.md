类型别名 type Byte
    
    public type Byte = UInt8

功能：[Byte](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-byte) 类型是内置类型 [UInt8](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#uint8) 的别名。 type Int
    
    public type Int = Int64

功能：[Int](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-int) 类型是内置类型 [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64) 的别名。 type UInt
    
    public type UInt = UInt64

功能：[UInt](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_types#type-uint) 类型是内置类型 [UInt64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#uint64) 的别名。
