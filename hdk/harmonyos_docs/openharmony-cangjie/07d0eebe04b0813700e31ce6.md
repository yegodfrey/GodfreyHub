类 class SecureRandom
    
    public class SecureRandom {
        public init(priv!: Bool = false)
    }

功能：用于生成加密安全的伪随机数。 和 [Random](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/random_package_classes#class-random) 相比，主要有三个方面不同：
    * 随机数种子： [Random](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/random_package_classes#class-random) 使用系统时钟作为默认的种子，时间戳一样，结果就相同；[SecureRandom](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/crypto_package_classes#class-securerandom) 使用操作系统或者硬件提供的随机数种子，生成的是真随机数。
    * 随机数生成： [Random](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/random_package_classes#class-random) 使用了梅森旋转伪随机生成器；[SecureRandom](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/crypto_package_classes#class-securerandom) 则使用了 openssl 库提供的 [MD5](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/digest_package_classes#class-md5) 等随机算法，使用熵源生成真随机数；如果硬件支持，还可以使用硬件随机数生成器来生成安全性更强的随机数。
    * 安全性： [Random](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/random_package_classes#class-random) 不能用于加密安全的应用或者隐私数据的保护，可以使用 [SecureRandom](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/crypto_package_classes#class-securerandom)。
[h2]init(Bool)
    
    public init(priv!: Bool = false)

功能：创建 [SecureRandom](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/crypto_package_classes#class-securerandom) 实例，可指定是否使用更加安全的加密安全伪随机生成器，加密安全伪随机生成器可用于会话密钥和证书私钥等加密场景。 参数：
    * priv!: [Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool) \- 设置为 true 表示使用加密安全伪随机生成器。
