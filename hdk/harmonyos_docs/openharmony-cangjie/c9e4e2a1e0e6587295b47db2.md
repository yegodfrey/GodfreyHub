    public func canExecute(): Bool

功能：判断当前用户是否有权限执行该实例对应的文件。
    * 对文件而言，判断用户是否有执行文件的权限。
    * 对目录而言，判断用户是否有进入目录的权限。

    * [Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool) \- true 表示有权限；false 表示无权限。
