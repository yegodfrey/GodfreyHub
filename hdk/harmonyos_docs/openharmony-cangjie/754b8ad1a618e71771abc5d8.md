异常类 class UrlSyntaxException
    
    public class UrlSyntaxException <: Exception {
        public init(reason: String)
        public init(input: String, reason: String)
    }

功能：url 解析异常类。 [h2]init(String)
    
    public init(reason: String)

功能：根据错误原因构造 [UrlSyntaxException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/url_package_exceptions#class-urlsyntaxexception) 实例。 参数：
    * reason: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 解析错误的原因。
[h2]init(String, String)
    
    public init(input: String, reason: String)

功能：根据 url 及错误原因构造 [UrlSyntaxException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/url_package_exceptions#class-urlsyntaxexception) 实例。 参数：
    * input: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 原生 url 或其片段。
    * reason: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 解析错误的原因。
