[h2]func copyTo(Array<T>, Int64, Int64, Int64)
    
    public func copyTo(dst: Array<T>, srcStart: Int64, dstStart: Int64, copyLen: Int64): Unit

功能：将当前数组中的一段数据拷贝到目标数组中。 参数：
    * dst: [Array](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-arrayt)<T> \- 目标数组。
    * srcStart: [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64) \- 从 this 数组的 srcStart 下标开始拷贝，取值范围为 [0, this.size)。
    * dstStart: [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64) \- 从目标数组的 dstStart 下标开始写入，取值范围为 [0, dst.size)。
    * copyLen: [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64) \- 拷贝数组的长度，取值要求为 copyLen + srcStart < this.size，copyLen + dstStart < dst.size。
异常：
    * [IllegalArgumentException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-illegalargumentexception) \- copyLen 小于 0 则抛出此异常。
    * [IndexOutOfBoundsException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_exceptions#class-indexoutofboundsexception) \- 如果参数不满足上述取值范围，抛出此异常。
示例：
    
    main() {
        let arr = [0, 1, 2, 3, 4, 5]
        let new = [0, 0, 0, 0, 0, 0]
        arr.copyTo(new, 2, 2, 4)
        println(new)
    }

运行结果：
    
    [0, 0, 2, 3, 4, 5]
