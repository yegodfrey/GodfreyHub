枚举 enum LogLevel
    
    public enum LogLevel <: ToString {
        | OFF
        | ERROR
        | WARN
        | INFO
        | DEBUG
        | TRACE
        | ALL
    }

功能：该枚举类表示打印级别。 定义了日志打印的七个级别，级别从低到高分别为 OFF、ERROR、WARN、INFO、DEBUG、TRACE、ALL。 [SimpleLogger](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_classes#class-simplelogger) 类的实现中，指定了日志打印级别，以及每一条日志的级别，只有级别小于等于指定打印级别的日志条目会被打印到输出流中。 [h2]ALL
    
    ALL

功能：构造一个日志打印级别的枚举实例，等级为所有。 [h2]DEBUG
    
    DEBUG

功能：构造一个日志打印级别的枚举实例，等级为调试。 [h2]ERROR
    
    ERROR

功能：构造一个日志打印级别的枚举实例，等级为错误。 [h2]INFO
    
    INFO

功能：构造一个日志打印级别的枚举实例，等级为通知。 [h2]OFF
    
    OFF

功能：构造一个日志打印级别的枚举实例，等级为禁用。 [h2]TRACE
    
    TRACE

功能：构造一个日志打印级别的枚举实例，等级为跟踪。 [h2]WARN
    
    WARN

功能：构造一个日志打印级别的枚举实例，等级为警告。 [h2]func level()
    
    public func level(): Int64

功能：获取日志级别对应的数字，OFF 为 1，ERROR 为 2，此后依次加一。 返回值：
    * [Int64](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#int64) \- 当前的日志级别对应的数字。
[h2]func toString()
    
    public func toString(): String

功能：获取日志级别对应的名称。 返回值：
    * [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 当前的日志级别的名称。
[h2]operator func >=(LogLevel)
    
    public operator func >=(target: LogLevel): Bool

功能：比较日志级别高低。 参数：
    * target: [LogLevel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/log_package_enums#enum-loglevel) \- 将当前日志级别和 target 进行比较。
返回值：
    * [Bool](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#bool) \- 如果当前日志级别大于等于 target，返回 true，否则返回 false。
