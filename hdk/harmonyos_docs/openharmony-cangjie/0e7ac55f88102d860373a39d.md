std.unittest 包 功能介绍Unittest 库用于编写仓颉项目单元测试代码，提供包括代码编写、运行和调测在内的基本功能，并为有经验的用户提供的一些高级功能。 仓颉单元测试支持 cjc 编译器（单包编译模式）和 cjpm 包管理器（ 多包模式）。 用户可通过[快速入门](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_getting_started#unittest-快速入门)写出第一个单元测试程序。同时文档对于一些[基础概念及用法](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_basics#unittest-基础概念及用法)做了说明并附有示例代码，另外，对于一些高阶特性例如[参数化测试](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_parameterized_tests#参数化测试入门)等做了进一步说明。 API 列表 [h2]函数 函数名 | 功能  
---|---  
[csv<T>(String, Rune, Rune, Rune, Option<Rune>, Option<Array<String>>, Array<UInt64>, Array<UInt64>, Bool)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_functions#func-csvtstring-rune-rune-rune-optionrune-optionarraystring-arrayuint64-arrayuint64-bool-where-t--serializablet) | 该函数可从 csv 文件中读取类型 T 的数据值，其中 T 必须可被序列化。该函数的返回值是参数化测试的一种参数源。  
[json<T>(String)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_functions#func-jsontstring-where-t--serializablet) | 该函数可从 JSON 文件中读取类型 T 的数据值，其中 T 必须可被序列化。该函数的返回值是参数化测试的一种参数源。  
[random<T>()](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_functions#func-randomt-where-t--arbitraryt) | 该函数生成 T 类型的随机数据，其中 T 必须实现接口 Arbitrary<T> 。该函数的返回值是参数化测试的一种参数源。  
[tsv<T>(String, Rune, Rune, Option<Rune>, Option<Array<String>>, Array<UInt64>, Array<UInt64>, Bool)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_functions#func-tsvtstring-rune-rune-optionrune-optionarraystring-arrayuint64-arrayuint64-bool-where-t--serializablet) | 该函数可从 tsv 文件中读取类型 T 的数据值，其中 T 必须可被序列化。该函数的返回值是参数化测试的一种参数源。  
[h2]接口 接口名 | 功能  
---|---  
[Arbitrary](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-arbitrary) | 生成 T 类型随机值的接口。  
[DataFinisher](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-datafinisher) | DataStrategy 的组件，用于在测试完成后对数据进行后处理。  
[DataProvider](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-dataprovider) | DataStrategy 的组件，用于提供测试数据, T 指定提供者提供的数据类型。  
[DataShrinker](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-datashrinkert) | DataStrategy 的组件，用于在测试期间缩减数据，T 指定该收缩器处理的数据类型。  
[DataStrategy](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-datastrategy) | 为参数化测试提供数据的策略，T 指定该策略操作的数据类型。  
[Generator](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-generatort) | 生成器生成 T 类型的值。  
[Measurement](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-measurement) | 在性能测试过程中可以收集和分析各种数据的接口。性能测试框架使用的特定实例由 @Configure 宏的 measurement 参数指定。  
[Shrink](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_interfaces#interface-shrinkt) | 将 T 类型的值缩减到多个“更小”的值。  
[h2]类 类名 | 功能  
---|---  
[Configuration](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-configuration) | 存储 @Configure 宏生成的 unittest 配置数据的对象。Configuration 是一个类似 HashMap 的类，但它的键不是键和值类型，而是 String 类型，和任何给定类型的值。  
[CsvStrategy](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-csvstrategy) | DataStrategy 对 CSV 数据格式的序列化实现。  
[JsonStrategy](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-jsonstrategy) | DataStrategy 对 JSON 数据格式的序列化实现。  
[RandomDataProvider](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-randomdataprovider) | 使用随机数据生成的 DataProvider 接口的实现。  
[RandomDataShrinker](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-randomdatashrinker) | 使用随机数据生成的 DataShrinker 接口的实现。  
[RandomDataStrategy](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-randomdatastrategy) | 使用随机数据生成的 DataStrategy 接口的实现。  
[RawBench](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-rawbench) | 提供较低级别的性能测试 API ，以便对性能测试过程进行更细粒度的控制。使用时应小心，因为如果使用不当，可能会产生误导性结果。  
[TimeNow](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_classes#class-timenow) | Measurement 的实现，用于测量执行一个函数所花费的时间。  
[h2]枚举 枚举名 | 功能  
---|---  
[ExplicitGcType](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_enums#enum-explicitgctype) | 用于指定 @Configure 宏的 explicitGC 配置参数。表示 GC 执行的三种不同方式。  
[TimeoutInfo](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_enums#enum-timeoutinfo) | 指定测试超时的信息。目前，可以通过 @Timeout[expr] 宏或者运行时选项 --timeout-each 提供此超时信息。  
[TimeUnit](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_enums#enum-timeunit) | 可以在 TimeNow 类构造函数中使用的时间单位。  
[h2]宏 宏名 | 功能  
---|---  
[Assert](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#assert-宏) | 声明 Assert 断言，测试函数内部使用，断言失败停止用例。  
[Bench](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#bench-宏) | 宏用于标记要执行多次的函数并计算该函数的预期执行时间。  
[Configure](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#configure-宏) | 为测试类或测试函数提供配置参数。它可以放置在测试类或测试函数上。  
[Expect](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#expect-宏) | 声明 Expect 断言，测试函数内部使用，断言失败继续执行用例。  
[Parallel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#parallel-宏) | 可以修饰测试类。被 @Parallel 修饰的测试类中的测试用例可并行执行。  
[PowerAssert](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#powerassert-宏) | 检查传递的表达式是否为真，并显示包含传递表达式的中间值和异常的详细图表。  
[RawBench](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#rawbench-宏) | 与 @Bench 相同，但可以访问更高级的 API 。被 @RawBench 修饰的函数主体将被执行一次，并且应使用 RawBencher 类进行相关配置。 @RawBench 宏不能与 @TestCase 和 @Bench 一起应用在同一个测试用例上。  
[Skip](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#skip-宏) | 修饰已经被 @TestCase / @bench 修饰的函数，使该测试用例被跳过。  
[Test](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#test-宏) | 宏应用于顶级函数或顶级类，使该函数或类转换为单元测试类。  
[TestCase](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#testcase-宏) | 宏用于标记单元测试类内的函数，使这些函数成为单元测试的测试用例。  
[Timeout](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#timeout-宏) | 指示测试应在指定时间后终止。它有助于测试可能运行很长时间或陷入无限循环的复杂算法。  
[Types](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/unittest_package_macros#types-宏) | 宏为测试类或测试函数提供类型参数。它可以放置在测试类或测试函数上。
