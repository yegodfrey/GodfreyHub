接口 interface ToJson
    
    public interface ToJson {
        static func fromJson(jv: JsonValue): DataModel
        func toJson(): JsonValue
    }

功能：用于实现 [JsonValue](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonvalue) 和 [DataModel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-datamodel) 的相互转换。 [h2]static func fromJson(JsonValue)
    
    static func fromJson(jv: JsonValue): DataModel

功能：将 [JsonValue](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonvalue) 转化为对象 [DataModel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-datamodel)。 参数：
    * jv: [JsonValue](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonvalue) \- 待转换的 [JsonValue](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonvalue)。
返回值：
    * [DataModel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-datamodel) \- 转换后的 [DataModel](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/serialization_package_classes#class-datamodel)。

    func toJson(): JsonValue

功能：将自身转化为 [JsonValue](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_classes#class-jsonvalue)。 返回值：

异常：
    * [JsonException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/encoding_json_package_exceptions#class-jsonexception) \- 如果转换失败，抛出异常。
