异常类 class CryptoException
    
    public class CryptoException <: Exception {
        public init()
        public init(message: String)
    }

功能：此类为摘要和加解密出现错误时抛出的异常。 [h2]init()
    
    public init()

功能：无参构造函数，构造[CryptoException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/digest_package_exceptions#class-cryptoexception)异常。 [h2]init(String)
    
    public init(message: String)

功能：根据异常信息构造 [CryptoException](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/digest_package_exceptions#class-cryptoexception) 异常类对象。 参数：
    * message: [String](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_structs#struct-string) \- 异常信息。
