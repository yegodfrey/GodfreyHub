接口 interface SaxHandler
    
    public interface SaxHandler {
        func characters(content: String): Unit
        func endDocument(): Unit
        func endElement(name: String): Unit
        func startDocument(): Unit
        func startElement(name: String, attrs: ArrayList<XmlAttr>): Unit
    }

功能：提供 XML 简单 API（SAX）模式的回调函数接口。 SAX（Simple API for XML）是一种基于流的解析方式，边读取 XML 边解析，并以事件回调的方式让调用者获取数据。DOM 模型就是把 XML 结构作为一个树形结构处理，从根节点开始，每个节点都可以包含任意个子节点。相比 DOM 模式，SAX 模式占用的内存更小。 [h2]func characters(String)
    
    func characters(content: String): Unit
