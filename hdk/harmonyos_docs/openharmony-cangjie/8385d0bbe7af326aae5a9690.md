Form 的构造使用 Form 的构造与其函数get的使用创建 Form 类，并通过 get 获取 key 对应映射的 value。 代码如下：
    
    import encoding.url.*
    
    main(): Int64 {
        var s = Form("1=2&2=3&1=2&&")
        print(s.get("1").getOrThrow())
        return 0
    }

运行结果如下：
    
    2

Form 的构造与重复key情况下函数get的使用创建 Form 正则类，并通过 get 获取 key 对应映射的 value。 代码如下：
    
    import encoding.url.*
    
    main(): Int64 {
       var s = Form("2=3&1=%6AD&1=2")
       // 对于 %6A 解码成 j，重复的 key 调用 get 获取第一个 value 值 jD
       print(s.get("1").getOrThrow())
       return 0
    }

运行结果如下：
    
    jD

Form 的构造与其他函数使用分别调用 add，set，clone，打印输出前后变化。 代码如下：
    
    import encoding.url.*
    
    main(): Int64 {
        var f = Form()
        f.add("k", "v1")
        f.add("k", "v2")
        println(f.get("k").getOrThrow())
        f.set("k", "v")
        println(f.get("k").getOrThrow())
        let clone_f = f.clone()
        clone_f.add("k1", "v1")
        println(clone_f.get("k1").getOrThrow())
        println(f.get("k1") ?? "kkk")
        0
    }

运行结果如下：
    
    v1
    v
    v1
    kkk
