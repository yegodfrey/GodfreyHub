函数 func abs(Float16)
    
    public func abs(x: Float16): Float16

功能：求一个半精度浮点数的绝对值。 参数：
    * x: [Float16](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#float16) \- 传入的半精度浮点数。
返回值：
    * [Float16](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/core_package_intrinsics#float16) \- 返回传入参数的绝对值。
示例：
    
    import std.math.abs
    
    main() {
        let n: Float16 = -23.0
        let abs = abs(n)
        println(abs)
    }

运行结果:
    
    23.000000
