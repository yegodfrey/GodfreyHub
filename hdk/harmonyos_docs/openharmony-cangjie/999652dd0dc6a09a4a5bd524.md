std.os 包 功能介绍os 包提供了包括获取或操作当前进程相关信息(如进程参数、环境变量、目录信息等)，注册回调函数及退出当前进程等能力。 目前支持 Linux 平台，macOS 平台，Windows 平台与 OHOS 平台。 API 列表 [h2]函数 函数名 | 功能 | 支持平台  
---|---|---  
[currentDir()](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-currentdir) | 获取当前工作目录。 | Linux Windows macOS OHOS  
[envVars()](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-envvars) | 获取所有环境变量。 | Linux Windows macOS OHOS  
[getArgs()](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-getargs) | 返回命令行参数列表，例如在命令行中执行 a.out ab cd ef，其中 a.out 是程序名，返回的列表包含三个元素 ab cd ef。 | Linux Windows macOS OHOS  
[getEnv(String)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-getenvstring) | 获取指定名称的环境变量值。 | Linux Windows macOS OHOS  
[homeDir()](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-homedir) | 获取 home 目录。 | Linux Windows macOS OHOS  
[processorCount()](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-processorcount) | 获取处理器数量。 | Linux Windows macOS OHOS  
[removeEnv(String)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-removeenvstring) | 通过指定环境变量名称移除环境变量。 | Linux Windows macOS OHOS  
[setEnv(String, String)](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-setenvstring-string) | 用于设置一对环境变量。 | Linux Windows macOS OHOS  
[tempDir()](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs#func-tempdir) | 获取临时目录。 | Linux Windows macOS OHOS  
    * **[函数](https://developer.huawei.com/consumer/cn/doc/openharmony-cangjie/os_package_funcs)**
