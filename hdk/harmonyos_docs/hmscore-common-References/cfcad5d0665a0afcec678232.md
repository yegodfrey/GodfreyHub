AvailableAdapter Class Info  
---  
public class [AvailableAdapter](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/integrate-installer-sdk-class-adapter-0000001327152537) 提供检测HMS Core APK以及下载安装HMS Core APK的能力。

---  
AvailableAdapter(int version) 创建一个AvailableAdapter实例，version为要求的最低HMS Core APK版本号（例如HMS Core APK版本号要求为6.4.0.312，则version = 60400312）。

void | startResolution(Activity activity, [AvailableCallBack](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/integrate-installer-sdk-interface-callback-0000001326952585) in) 如果需要下载HMS Core APK最新版本，则进行升级处理。

Public Methods [h2]isHuaweiMobileServicesAvailable Method  
---  
public int isHuaweiMobileServicesAvailable(Context context) HMS Core APK是否可用。该接口检测HMS Core APK是否已安装、被仿冒、被禁用。如果HMSCore的版本大于等于5.0，或者低于2.0，则返回HMS Core APK可用。（指定的版本在构造[AvailableAdapter](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/integrate-installer-sdk-class-adapter-0000001327152537)对象时设定，建议设置该版本号的值大于0）。  
**Parameters** Name | Type | Constraint | Description  
---|---|---|---  
context | Context | Y | 上下文对象。  
**Returns** Type | Description  
---|---  
int | 
    * 0：可用
    * 1：在设备上没有发现HMS Core APK
    * 2：已经安装的HMS Core APK过时（当前设备上安装的HMS Core APK版本需要根据Kit SDK设置的MinApkVersion进行升级检测，并且HMS Core APK版本低于指定的版本。如果HMSCore的版本大于等于5.0，或者低于2.0，则不会被判断为过时）。
    * 3：设备上的HMS Core APK不可用
    * 21：设备因太老而不能被支持（安卓版本在4.1以下）
    * 29：设备上安装的HMS Core APK是仿冒的  
[h2]checkHuaweiMobileServicesForUpdate Method  
---  
public int checkHuaweiMobileServicesForUpdate(Context context) HMS Core APK是否可用。该接口检测HMS Core APK是否已安装、被仿冒、被禁用。指定的版本在构造[AvailableAdapter](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/integrate-installer-sdk-class-adapter-0000001327152537)对象时设定，建议设置该版本号的值大于0。  
**Parameters** Name | Type | Constraint | Description  
---|---|---|---  
context | Context | Y | 上下文对象。  
**Returns** Type | Description  
---|---  
int | 
    * 0： 可用
    * 1： 在设备上没有发现HMS Core APK
    * 2： 设备上安装的HMS Core APK版本低于指定的版本
    * 3： 设备上的HMS Core APK不可用
    * 21：设备因太老而不能被支持（安卓版本在4.1以下）
    * 29：设备上安装的HMS Core APK是仿冒的
