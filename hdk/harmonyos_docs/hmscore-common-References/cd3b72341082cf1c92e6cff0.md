# Overview

用于接收HMS Core的返回结果。

## Interface Summary

|Interface|Description|
|:--------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------|
|[IMessageEntity](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/imessage-0000001589035789)|消息实体，请求/响应消息实体必须实现此接口（此抽象类的子类，必须实现默认（0个参数）的构造函数）。|
|[ResponseErrorCode](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/response-0000001474875021)|HMS Core (APK) 返回给业务的响应信息。|

## Class Summary

|Class|Description|
|:---------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
|[ApiException](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/apiexception-0000001050123087)|SDK抛出的异常。|
|[HuaweiApiAvailability](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/huaweiapiavailability-0000001050121134)|获取当前设备的HMS Core（APK）可用性。|
|[ResolvableApiException](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/resolvableapiexception-0000001050123089)|需要开发者解决的异常。|
|[Result](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/result-0000001050123085)|表示调用HMS Core（APK）API的处理结果。|
|[ResultCallback<R>](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/resultcallback_r-0000001050121136)|结果回调，当异步调用HMS Core SDK方法时，结果是通过此回调返回。|
|[Scope](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/scope-0000001050123083)|描述一个OAuth 2.0的请求授权，对用户安全有影响，当请求授权时，会产生一个授权对话框。|
|[Status](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/status-0000001050121132)|表示任务处理的结果。|
