void onComplete(int result) 接收安装或者升级的处理结果，result为升级处理结果。  
**Parameters** Name | Type | Constraint | Description  
---|---|---|---  
result | int | Y | 
    * 0：成功。
    * 8：发生了内部错误，请尝试重试是否解决问题。
    * 13：用户取消。
