|ErrorCode.ARGUMENTS_INVALID|907135000|传入的参数错误。|请检查相关的配置信息是否正确。比如："Manifest"文件中的appid是否配置准确。|
|ErrorCode.INTERNAL_ERROR|907135001|内部错误，表示内部出现异常且无法恢复。|内部错误，一般情况下重试或进程重新启动可以恢复正确。|

|ErrorCode.CLIENT_API_INVALID|907135003|ApiClient对象无效。|检查ApiClient不为null，以及isConnected为true。|
|ErrorCode.EXECUTE_TIMEOUT|907135004|调用AIDL超时。|检查service是否终止、是否需要重新获取binder等。|
|ErrorCode.NOT_IN_SERVICE|907135005|当前区域不支持此业务。|请检查用户所在区域是否支持此接口。|
|ErrorCode.SESSION_INVALID|907135006|HMS Core SDK内部错误，AIDL连接session无效。|一般不会出现此问题。若返回该错误码，请重试，如果多次重试失败，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题。|
|ErrorCode.DENY_NETWORK|907135007|OOBE（Out-of-box experience，开箱体验）阶段未同意隐私声明，不能访问网络。|OOBE阶段同意隐私声明之后即可正常访问网络。|
