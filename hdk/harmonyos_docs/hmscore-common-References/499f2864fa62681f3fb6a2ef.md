# 说明

OpenRS：开放路由服务，OpenRS用于开发者进行Kit服务端域名地址发现。OpenRS帮助开发者服务器根据上下文（例如运营商ID，即carrierId）查找其依赖的Kit服务端各个站点域名URL。

接口协议：HTTPS

响应协议接口数据格式：JSON

协议接口数据字符编码：UTF-8

* 接口支持post
* 编码：utf-8
* Post Content Type：application/json
* 无认证信息
* 不涉及语言信息

## 站点信息

|站点信息（rootUrl）|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|全球（优先）：https://openrs-api.cloud.huawei.com 中国站点：https://openrs-api.cloud.huawei.com.cn 亚洲站点：https://openrs-api.cloud.huawei.asia 欧洲站点：https://openrs-api.cloud.huawei.eu（待开放）|

## 站点选择

优先选择全球域名，根据请求所在地就近接入OpenRS服务器。当此域名访问不通时，请根据请求地访问对应站点的域名。

OpenRS中的配置数据全球各站点统一，请求任何站点理论上都不会影响功能。
