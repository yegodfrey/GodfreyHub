# 错误码

|值|描述|解决方法|
|:-|:------------------------------------|:------------------------------------------------------------------|
|0|成功。|-|
|1|向API提供的参数无效。此错误也可能说明Kit未在OpenRS中正确配置。|1. 请检查请求参数是否符合要求。 2. 请检查请求的ServiceName是否合法（即该Kit服务是否已在OpenRS上正确注册）。|

若您的问题仍无法解决，请选择[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
