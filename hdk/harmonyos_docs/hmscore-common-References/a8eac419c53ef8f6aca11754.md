# 获取服务器域名

#### 功能介绍

您可以调用本接口获取Kit服务端各个站点的域名URL。  

#### 场景描述

OpenRS API帮助开发者服务器根据运营商ID（即carrierId）查找其依赖的Kit服务端各个站点域名URL。  

#### 使用约束

由于Kit服务端地址变更频率低，请在本地缓存请求结果，缓存时间请参考请求头中Cache-Control参数。  

#### 接口原型

|承载协议|HTTPS POST|
|接口方向|开发者服务器 -\> OpenRS服务器|
|接口URL|{rootUrl}/openrs/1.0/router 说明： rootUrl在不同站点有不同的URL：优先选择全球域名，如果域名访问不通，您应固定选择最近的站点访问。具体请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/description-0000001101904800#section1954123781815)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/description-0000001101904800#section1741234185817)。|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

#### 请求参数

Request Header  

|参数|是否必选|参数类型|描述|
|:-----------|:---|:-----|:----------------------------------|
|Content-Type|是|String|取值为：application/json; charset=utf-8|

Request Parameter  

|参数|是否必选|参数类型|描述|
|:--------|:---|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|carrierId|否|String|运营商ID，可选，如果不传或者传空则返回服务端所有站点的域名URL，由Kit SDK传入。|
|clientId|是|String|App ID/Client ID，开发者在创建应用后由华为开发者联盟为应用分配的唯一标识。App ID的查询方法请参见[查看应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|

Request Body  

|参数|是否必选|参数类型|描述|
|:-------|:---|:---------|:-----------------------------------------------------------------|
|services|是|String\[\]|需要查询的ServiceName，该服务名称由各Kit约定，支持在同一个请求中同时携带多个服务名称。 数组长度：\[1, 128\]|

#### 请求示例

```
POST /openrs/1.0/router?carrierId=600&clientId=xxx
Content-Type: application/json; charset=utf-8
Accept: application/json

{
  "services": [
        "oauth.apptouch",
        "account.apptouch"
    ]
}
```

#### 响应参数

Response Header  

|参数|是否必选|参数类型|描述|
|:------------|:---|:-----|:--------------------------------------------------------------------------------------------------------------------------|
|Content-Type|是|String|取值为：application/json; charset=utf-8|
|Cache-Control|是|String|取值参考：private, max-age=86500 建议按照max-age时间（单位：秒）缓存接口返回的URL地址。该时间为86400（24小时）+\[1,600\]秒随机离散值。 该设置适用于HTTP 1.1版本，优先级大于Expires。|
|Expires|否|String|接口响应过期时间。 取值参考：Fri, 30 Apr 2021 04:30:46 GMT|

Response Body  

|参数|是否必选|参数类型|描述|
|:---------|:---|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|resultCode|是|String|返回码。 * 0：成功或部分成功。 * 其他：失败，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/rest-error-code-0000001102224786)。|
|services|否|Map|当resultCode=0时，返回查询成功的域名URL，请参见[services](#ZH-CN_TOPIC_0000001148464767__table477mcpsimp)。|
|errorList|否|Map|当resultCode=0时，返回查询失败的错误信息，请参见[errorList](#ZH-CN_TOPIC_0000001148464767__table972418718301)。|
|errorDesc|否|String|当resultCode≠0时，返回错误详情。|

services  

|参数|是否必选|参数类型|描述|
|:----------|:---|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|serviceInfo|否|\<String,Map\[\]\>|格式为：serviceName : serviceArray * 当请求中携带carrierId且不为空，返回本次查询的carrierId所在站点的域名URL集合，请参见[serviceArray](#ZH-CN_TOPIC_0000001148464767__table1792234122418)。 * 当请求未携带carrierId或为空，返回本次查询的服务所有站点的域名URL集合，请参见[serviceArray](#ZH-CN_TOPIC_0000001148464767__table1792234122418)。|

serviceArray  

|参数|是否必选|参数类型|描述|
|:----------|:---|:---------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|serviceName|否|\<String,String\> 或\<String,String\[\]\>|Key值分为两种：apiName和固定值"carrierIds"。 * Key为apiName，格式为：apiName : "URL"。apiName为Kit约定的URL功能名称，"URL"为服务端域名地址。 * Key为"carrierIds"，格式为："carrierIds":\[\]。carrierIds为本次查询的carrierId或者该站点的所有carrierId集合。|

errorList  

|参数|是否必选|参数类型|描述|
|:----------|:---|:----------------|:--------------------------------------------------------------------------------------------------------------|
|serviceName|否|\<String,String\>|格式为：serviceName : errorInfo errorInfo为查询失败返回错误信息，请参见[错误信息列表](#ZH-CN_TOPIC_0000001148464767__table570513584141)。|

错误信息列表  

|参数取值|描述|
|:-----------------|:----------------------------------------|
|NOT_FIND_SERVICE|查询的服务名称不存在。|
|NOT_FIND_ADDRESS|查询的carrierId所在站点未配置服务端域名URL（carrierId合法）。|
|NOT_FIND_CARRIERID|查询的carrierId未配置服务端域名URL（carrierId不合法）。|

#### 调用示例

openRSUrl请参见[站点信息](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/description-0000001101904800#section1954123781815)和[站点选择](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/description-0000001101904800#section1741234185817)。carrierId字段可以从Kit SDK中获取。

```
"Java"
    /**
     * 获取kit服务端域名URL信息
     *
     * @throws IOException 异常
     */
    private static void getRouter() throws IOException {
	// 优先从本地缓存中获取，如果缓存过期或者为空，则从服务器获取最新数据
        getRouterFromCache();
		
        // carrierId为kit sdk传入的运营商Id，clientId为开发者应用在华为开发者联盟上注册的唯一标识APPID/CLIENTID
        String queryParam = "carrierId=" + carrierId + "&clientId=" + clientId;
	String openRSUrl = "https://openrs-api.cloud.huawei.com";
        String postUrl = openRSUrl + "?" + queryParam;

	// 设置报文头 Content-Type
        PostMethod postMethod = new PostMethod(postUrl);
        postMethod.setRequestHeader("Content-Type", "application/json; charset=utf-8");

        // 设置报文body，示例：String body="{\"services\": [\"oauth.apptouch\"]}";
        List<String> serviceList = new ArrayList<>();
        param.add("services", serviceList);
        postMethod.setRequestBody(param);

        HttpClient httpClient = new HttpClient();
        int resCode = httpClient.executeMethod(postMethod);
        String responseBody = postMethod.getResponseBodyAsString();
        if (resCode == 200) {
            JSONObject routerJson = JSONObject.parseObject(responseBody);

            // resultCode=0为成功或者部分成功
            if ("0".equals(routerJson.getResultCode())) {
                // 获取查询的所有服务配置
		Map<String, Object> services = routerJson.getServices();
		// 根据serviceName查询域名列表
		List<Map<String, Object>> serviceUrls = services.get("oauth.apptouch");
		if(serviceUrls.size() > 0){
	            // 场景1：请求携带carrierId不为空且合法，根据kit提供的apiName(key)获取服务端域名
	            String tokenUrl = serviceUrls.get(0).get("token");
				
	            // 场景2：请求不携带carrierId或为空，根据serviceName查询域名列表
	            List<String> tokenUrls = serviceUrls.stream().map(s -> s.get("token");

	            // 由于Kit服务端地址变更频率低，请在本地缓存请求结果，缓存时间请参考请求头中Cache-Control参数。
                    String cacheControl = postMethod.getResponseHeader("Cache-Control").getValue();
	            // 缓存查询结果
	            saveRouterToCache(cacheControl);
		} else { // 查询失败场景：1、服务名称不存在；2、carrierId不合法；3、carrierId合法但是所在站点无域名配置
	            Map<String, String> errorList = routerJson.getErrorList();
	            // 根据serviceName查询错误信息描述
	            String errorMsg = errorList.get("oauth.apptouch");
	        }
            } else if ("1".equals(routerJson.getResultCode())) { // resultCode=1为失败
                // 异常响应，分析失败异常类型，打印日志，是否重试，看CP自己决策
                log.error("get router failed " + routerJson.getErrorDesc());
            }
        } else {
            log.error("request router failed " + routerResponse);
        }
    }
```
