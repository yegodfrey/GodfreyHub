# Overview

开发者与HMS Core进行交互，tasks异步函数为开发者提供了同步和异步的接口调用方法。  

#### Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------|
|[Continuation](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/continuation-0000001050123097)|包含一个函数，调用该函数还在一个任务执行完后，继续执行。|
|[ExecuteResult](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/executeresult-0000001050123099)|任务执行结果。|
|[OnCanceledListener](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/oncanceledlistener-0000001050123095)|任务被取消时调用。|
|[OnCompleteListener](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/oncompletelistener-0000001050121142)|任务完成时调用。|
|[OnFailureListener](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/onfailurelistener-0000001050123093)|任务执行失败时调用。|
|[OnSuccessListener](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/onsuccesslistener-0000001050121140)|当任务成功完成时进行监听调用。|
|[SuccessContinuation\<TResult, TContinuationResult\>](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/successcontinuation-0000001050121146)|一个任务执行成功后，调用该函数继续执行。|

#### Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[CancellationToken](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/cancellationtoken-0000001050123105)|传播被取消操作的通知。|
|[CancellationTokenSource](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/cancellationtokensource-0000001050121152)|创建一个[CancellationToken](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/cancellationtoken-0000001050123105)或者取消一个已创建的[CancellationToken](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/cancellationtoken-0000001050123105)。|
|[TaskCompletionSource](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/taskcompletionsource-0000001050123103)|提供创建[Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)的能力。|
|[TaskExecutors](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/taskexecutors-0000001050121150)|线程管理类，包含一个Executor实例，用于[Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)执行。|
|[Tasks](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/tasks-0000001050123101)|[Task](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)的工具类。|
|[Task\<TResult\>](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/task_tresult-0000001050121148)|任务的抽象类，表示一个异步的操作。|
