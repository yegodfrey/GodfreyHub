# HarmonyOS认证FAQ

［问题一］HarmonyOS认证与Work With HUAWEI HiLink认证是什么关系？

HarmonyOS认证与Work With HUAWEI HiLink认证有且仅有模组硬件测试部分重叠，通过Work With HUAWEI HiLink认证的设备可以豁免HarmonyOS硬件测试。
