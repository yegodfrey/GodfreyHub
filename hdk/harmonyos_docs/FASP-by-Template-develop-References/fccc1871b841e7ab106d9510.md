# WebsiteAppPlatformInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------|
|platformType|O|Integer(32)|应用运行平台类型。 取值范围： * 0：安卓 * 1：IOS * 2：黑莓 * 3：鸿蒙 * 4：LINUX * 5：其他|
|appPlatformId|O|Integer(64)|APP平台记录ID。|
|platforms|O|List\<[PlatformInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-platforminfo-0000002489083884)\>|所属平台的信息。|
|domains|O|List\<String\>|域名信息。|
|platformName|O|String|其他平台名称。|
