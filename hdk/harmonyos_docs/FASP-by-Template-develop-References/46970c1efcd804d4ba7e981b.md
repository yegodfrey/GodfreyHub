# 查询Scope权限列表

#### 功能介绍

代商家查询应用Scope权限列表和申请状态。  
![](https://media:201775202742433687)  
* 需要商家完成元服务[权限集的授权](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-authorization-link-0000002523075602)。
* 此章节应用即包含HarmonyOS应用或元服务。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|服务商服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/tpp/v1/client-scope/list|
|数据格式|请求消息：Content-Type: application/json 响应消息：Content-Type: application/json|
|-----|-----------------------------------------------------------------------|

#### 请求参数

<br />

#### Header

|参数|必选(M)/可选(O)|类型|说明|
|:------------|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台"开发配置 \> 开发资料设置"页面中获取，详情请参见[获取平台访问凭据](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section3986829135420)。|
|Authorization|M|String|认证信息。 格式为"Authorization: Bearer ${access_token}"。 其中，${access_token}为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-0000001569170877)中获取的access_token。|
|appId|M|String(32)|应用ID。 元服务则为元服务的应用ID。 应用ID可以调用[获取指定授权账号详情](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-authorization-info-0000001501417588)接口从authorizerAppId字段获取。|

#### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------|:----------|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|publicServiceId|O|String|服务ID。 当前仅支持"publicServiceId"为"account"。|
|sensitiveFlag|O|Integer|是否敏感权限。 取值范围： * 0：公开 * 1：敏感|
|status|O|String|权限审批状态。 取值范围： * SUCCESS：已获取 * PENDING：待审批 * REJECTED：不通过 * NO_APPLY：未申请 说明： 当"scopeUrl"为"huaweiAccountAddress"时，权限审批状态不会取值为"REJECTED"。因为申请Scope权限被驳回后，此时权限审批状态即回到"NO_APPLY"状态。所以"scopeUrl"为"huaweiAccountAddress"的申请Scope权限被驳回，调用查询Scope权限列表接口入参"status"请设置为"NO_APPLY"。|

#### 请求示例

```
GET /api/tpp/v1/client-scope/list?publicServiceId=account HTTP/1.1
Host: connect-api.cloud.huawei.com
client_id: 414*******68
Content-Type: application/json
Authorization: Bearer ******
appId: 1********57
```

#### 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------|:----------|:---------------------------------------------------------------------------------------------------------------------------------|:---------------|
|ret|M|[ConnectRet](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-connectret-0000002130805573)|包含返回码及描述信息的结果。|
|scopeList|O|List\<[ScopeItem](#ZH-CN_TOPIC_0000002330285706__zh-cn_topic_0000002319924577_p163491240764)\>|申请Scope权限提交状态列表。|

ScopeItem  

|参数|必选(M)/可选(O)|类型|说明|
|:--------------|:----------|:------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|publicServiceId|O|String|服务ID。 当前仅支持"publicServiceId"为"account"。|
|scopeUrl|O|String|Scope权限URL。 当前仅支持"scopeUrl"为"phone"、"huaweiAccountAddress"。|
|scopePrompt|O|String|Scope权限描述。|
|sensitiveFlag|O|Integer|是否敏感权限。 取值范围： * 0：公开 * 1：敏感|
|status|O|String|权限审批状态。 取值范围： * SUCCESS：已获取 * PENDING：待审批 * REJECTED：不通过 * NO_APPLY：未申请 说明： 当"scopeUrl"为"huaweiAccountAddress"时，权限审批状态不会取值为"REJECTED"。因为申请Scope权限被驳回后，此时权限审批状态即回到"NO_APPLY"状态。所以"scopeUrl"为"huaweiAccountAddress"的申请Scope权限被驳回，调用查询Scope权限列表接口"status"会为"NO_APPLY"。|
|comment|O|String|审核驳回意见。|
