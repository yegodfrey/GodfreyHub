# 获取草稿模板列表

## 功能介绍

此接口用于获取第三方管理平台草稿箱中所有的草稿模板列表信息。

## 接口原型

|**承载协议**|HTTPS GET|
|---------|-------------------------------------------------------------------------|
|**接口方向**|服务商服务器 -> 华为服务器|
|**接口URL**|https://connect-api.cloud.huawei.com/api/template/v1/gettemplatedraftlist|
|**数据格式**|响应消息：Content-Type: application/json|

## 请求参数

### Header

|**参数**|必选(M)/可选(O)|**类型**|**说明**|
|:------------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台"开发配置 > 开发资料设置"页面中获取，详情请参见[获取平台访问凭据](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section3986829135420)。|
|Authorization|M|String|认证信息。 格式为"Authorization: Bearer *${access_token}*"。 其中，*${access_token}* 为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-0000001569170877)中获取的access_token。|

## 响应参数

|**参数**|**类型**|**说明**|
|:--------|:----------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|ret|[CodeAndMsg](#ZH-CN_TOPIC_0000002095034852__p4532204018325)|包含返回码及描述信息。 返回码详情请参见[错误码](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/error-code-information-0000001556590441)。|
|draftList|List<[DraftPojo](#ZH-CN_TOPIC_0000002095034852__p17970161617564)>|草稿箱列表信息。|

**CodeAndMsg**

|**参数**|**类型**|**说明**|
|:-----|:------|:-------|
|code|Integer|返回码。|
|msg|String|返回码描述信息。|

**DraftPojo**

|**参数**|**类型**|**说明**|
|:-------------|:----------|:-----------------------------------------------------|
|draftId|Long|草稿ID，服务商在第三方管理平台上传模板代码到草稿箱时自动生成。|
|createTime|Long|草稿创建时间。|
|lastUpdateTime|Long|草稿更新时间。|
|userDesc|String|草稿描述信息。|
|userVersion|String|草稿版本号。|
|mode|Integer|模板开发模式。 取值范围： * 0：解析中 * 1：ArkUI开发 * 2：类Web开发 * -1：解析失败|
|packageType|String|模板包类型。 取值范围： * APP：元服务模板|
|categoryId|Integer(64)|模板的二级分类ID。 例如：10000001（应用/商务）|
