# WebsiteAppletInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:----------|:------------------------------|
|appletId|O|Integer(64)|元服务的小程序信息的记录ID。|
|appletFeature|O|String|元服务包名。|
|appletType|O|String|小程序类型。 取值范围： * ATOM_SERVICE：元服务|
|remark|O|String|备注。|
