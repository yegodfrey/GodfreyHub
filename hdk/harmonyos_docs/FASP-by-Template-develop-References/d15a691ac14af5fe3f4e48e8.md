# SubjectDetailInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------|
|investor|O|String|投资人或者主办单位。|
|status|O|Integer(32)|主体状态。 取值范围： * 0：待审核 * 1：审核驳回 * 2：待提交管局 * 3：已备案 * 4：已注销 * 5：已注销接入 * 6：管局驳回 * 7：已转移 * 8：待完善资料 * 9：待管局审核|
|remarks|O|String|备注。|
|ztid|O|Integer(64)|管局保存的主体ID。|
|subjectId|O|Integer(64)|主体ID。|
|subjectRecordNo|O|String|主体备案号。 对于已经备案成功的主体才有备案号。|
|provinceId|O|Integer(32)|备案省份ID。|
|provinceName|O|String|备案省份名称。|
|cityId|O|Integer(32)|市ID。|
|cityName|O|String|市名称。|
|countryId|O|Integer(32)|县ID。|
|countryName|O|String|县名称。|
|recordRegion|O|String|主办者地域。 此字段值由省市县组成。|
|unitPropertyId|O|Integer(32)|主办者性质ID。|
|unitPropertyName|O|String|主办者性质名称。|
|certificateTypeId|O|Integer(32)|证件类型ID。|
|certificateTypeName|O|String|证件类型名称。|
|certificateNo|O|String|证件号码。|
|certificateAddr|O|String|证件住址。|
|subjectName|O|String|主体名称。|
|regionAddr|O|String|区域地址(省+市+县)。|
|detailAddr|O|String|详细地址(省市县之外的地址)。|
|contactAddr|O|String|通讯地址(区域地址+详细地址)。|
|leadingOfficial|O|[LeadingOfficialInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-leadingofficialinfo-0000002489243866)|主办单位的责任人信息。|
|accessories|O|List<[AttachmentRelation](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-attachmentrelation-0000002489083870)>|关联附件信息。|
|auditStatus|O|Integer(32)|主体审核状态。 取值范围： * 0：等待审核 * 1：审核通过 * -1：审核拒绝 * 2：未请求审核 * 3：审核未完成|
|websiteList|O|List<[WebsiteDisplay](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-websitedisplay-0000002489243884)>|主体关联的元服务简要信息。|
|isLegalPerson|O|Integer(32)|主体是否为法人。 取值范围： * 0：否 * 1：是|
|firstRecordTime|O|Integer(64)|首次报备时间。|
|lastRecordTime|O|Integer(64)|最近修改时间。|
|cerValidPeriod|O|Integer(64)|证书有效期。|
|auditName|O|String|审核人姓名。|
|auditTime|O|Integer(64)|审核时间。|
|checkStatus|O|Integer(32)|法人核验状态。 取值范围： * 0：未核验 * 1：已通过 * 2：未通过 * 3：待确认|
