# 版本更新说明

|版本|发布时间|更新说明|
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|16.8.1.300|2026-09-10|[申请Scope权限](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/apply-permission2-0000002330125850)接口优化：当**scopeUrl** 字段取值为"phone"时，**tagId** 、**purposeId**字段必填。|
|16.3.1.300|2026-07-21|新增[获取时效性授权链接](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/temporary-authorization-link-0000002680150323)接口，增加24小时的时效性限制。|
|16.2.1.300|2026-03-10|1. [查询应用信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-query-0000002130941805)和[更新应用软件包信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-file-info-update-app-0000002130782149)接口，支持解析软件包中的构建版本号（buildVersion），用于区分同一主版本下的不同测试子版本。 2. 新增[删除资质审核任务](https://developer.huawei.com/consumer/cn/doc/app/agc-help-publish-api-app-package-info-update-0000002236201250)接口。如果元服务资质审核已通过，但在提交上架时因资质问题被驳回，可调用该接口移除旧的资质材料，之后重新提交资质审核任务。|
|15.4.2.300|2026-01-04|1. [新建测试版本](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/add-test-version-0000002057706045)接口新增支持邀请测试上架自检（onshelfSelfDetect）。自检后，可以调用[查询上架自检报告信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-detect-task-0000002536833565)接口确认自检是否通过，未通过时可以查看自检报告。 2. [更新测试版本](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/modify-test-version-0000002021706726)接口新增支持向用户发送测试通知（needNotify）、更新应用版本已解决问题（versionVocReq）、选择是否涉及AI生成合成服务（isAiGenerate/aiTypes）和更新应用负责人信息（appReviewPhoneInfo/appReviewEmailInfo/appReviewName）。 3. [更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-update-0000002021703170)、[查询应用信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-query-0000002130941805)接口新增支持更新或查询应用版本已解决问题（versionVocs）。 4. 调用Publishing API[更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-file-info-update-0000002021703174)接口上传授权书及其他材料文件压缩包（otherCertificatesURL）时支持包含PDF格式文件；上传截图素材（screenShotList）和视频素材（introVideoList）时增加了方向一致性校验。 5. 新增代商家[备案元服务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-fa-0000002521363629)相关接口。|
|15.4.1.300|2025-12-02|1. 新增备案元服务的[查询备案订单列表](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-order-infos-0000002521243661)接口。 2. [查询应用信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-query-0000002130941805)接口中新增**customInfo** 、**appReviewPhoneInfo** 、**appReviewEmailInfo** 字段集和**privacyAgreementId** 、**downloadCount** 、**isAiGenerate** 、**aiTypes** 、**testUserName** 、**testUserPassword** 、**appRemark** 、**selfTestVideos** 、**appReviewName**字段。 3. [更新应用基本信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-info-update-0000002021703170)接口中新增**customInfo** 、**appReviewPhoneInfo** 、**appReviewEmailInfo** 字段集和**isAiGenerate** 、**aiTypes** 、**testUserName** 、**testUserPassword** 、**appRemark** 、**selfTestVideos** 、**appReviewName**字段。 4. [更新应用文件信息](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/app-file-info-update-0000002021703174)接口中新增**updateScreenShotList** 、**updateVideoList**字段。 5. **deviceType** 字段枚举值19修改为PC/2in1，**appAdapters**字段枚举值19修改为PC/2in1。 6. 更新[应用文件要求](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/api-file-requirement-0000002130782157)。|
|15.3.3.300|2025-11-04|[申请Scope权限](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/apply-permission2-0000002330125850)接口中新增**tagId** 、**purposeId**字段，支持申请Scope权限接口支持携带使用目的。|
|15.3.2.300|2025-10-11|1. 代调用华为账号服务支持代开通收货地址。 [申请Scope权限](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/apply-permission2-0000002330125850)、[查询Scope权限列表](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/query-permission2-0000002330285706)接口中**scopeList** 、**publicServiceId** 、**scopeUrl** 字段补充相关功能约束。 2. 第三方管理平台支持模板类目管理，增加"模板分类"字段。 [获取草稿模板列表](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-draft-template-list-0000001552257477)、[获取模板列表](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-template-list-0000001552137521)接口中同步新增**categoryId**字段。 3. 资质审核任务接口优化。 新增[修改资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/modify-qualification-review-task-0000002483476657)接口，修改[提交资质审核任务](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/post-tag-qual-dependent-0000002152513894)接口新增**taskId**字段。|
