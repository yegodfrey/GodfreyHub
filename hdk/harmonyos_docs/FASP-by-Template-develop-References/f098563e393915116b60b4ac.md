# AttachmentRequire

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------|
|id|O|String|附件关联记录ID。|
|side|O|Integer(32)|附件正反面。 取值范围： * 0：正面 * 1：反面|
|remark|O|String|备注。|
|url|O|String|域名证书域名。|
|relationId|O|String|关联对象ID。 包含主体ID、网站ID、负责人ID、域名ID。|
|relationName|O|String|关联对象名称。|
|relationType|O|Integer(32)|附件关联对象的类型ID。|
|relationTypeName|O|String|附件关联对象的类型名称。|
|mustUpload|O|Boolean|是否必传。 取值范围： * true：是 * false：否|
|valid|O|Boolean|附件是否失效。 取值范围： * true：是 * false：否|
|attachmentFormat|O|String|附件支持文件格式。 多个格式用英文逗号分隔。 说明： 需要前台忽略大小写进行判断。|
|attachmentTemplate|O|String|附件模板。 返回的是附件ID，有值返回的话前端需要可以下载对应模板。|
|attachmentCase|O|String|附件用例。 返回的是附件ID，有值返回的话前端使用图片查看接口下载用例图片。|
|attachBelong|O|List\<[AttachBelong](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-attachbelong-0000002489243856)\>|附件所属对象。|
|accessoryId|O|String|附件ID。|
|codeAccessoryId|O|String|采集码关联附件ID。|
|collectionCode|O|String|采集码。|
|accessoryLength|O|Integer(64)|附件大小。|
|codeAccessoryLength|O|Integer(64)|采集码关联附件大小。|
|allowModify|O|Boolean|附件是否允许修改。 取值范围： * true：是 * false：否|
|needCheck|O|Integer(32)|附件是否需要审核。 取值范围： * 1：是 * 0：否|
|checked|O|Integer(32)|附件是否已经审核过。 取值范围： * 1：是 * 0：否|
|checkRemark|O|String|附件的审核信息。|
|subRelationId|O|String|附件关联的子项（前置审批等）ID。|
|subRelationName|O|String|附件关联的子项（前置审批等）名称。|
|updateTime|O|String|附件更新时间。 UTC时间格式：YYYY-MM-DDTHH:MM:SS.sssZ 示例：2025-10-25T01:11:29.903Z|
