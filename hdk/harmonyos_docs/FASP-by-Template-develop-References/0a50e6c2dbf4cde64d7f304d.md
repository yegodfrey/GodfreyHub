# HmLinkDetailInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------|
|id|O|Integer(64)|元服务链接ID。|
|prefixId|O|Integer(64)|网址链接前缀ID。|
|name|O|String|元服务链接名称。|
|state|O|String|元服务链接状态。 取值范围： * ACTIVATING：已生效 * ENABLED：待生效 * DISACTIVATING：已失效 * DRAFT：草稿态|
|shortUrl|O|String|元服务链接URL。|
|isQRCodeLinked|O|Boolean|是否关联二维码。 取值范围： * true：关联。 * false：不关联。|
|qrCodeRule|O|String|二维码链接的匹配规则。|
|testQrCodeUrl|O|String|测试二维码链接。|
|isPrefixOccupied|O|Boolean|是否占用符合二维码匹配规则的所有子规则。 取值范围： * true：占用，表示其他元服务不可配置该元服务设置的前缀匹配规则的子规则。 * false：不占用。|
|startTime|O|Integer(64)|元服务链接生效开始时间。 此时间是与1970年1月1日午夜之间的差值。 单位：毫秒 示例：1704211200000|
|endTime|O|Integer(64)|元服务链接生效结束时间。 此时间是与1970年1月1日午夜之间的差值。 单位：毫秒 示例：1704211200000|
|atomicService|O|[AtomicService](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/applinking-data-atomicservice-0000002513999020)|元服务的相关信息。|
|createTime|O|Integer(64)|元服务链接创建时间。 此时间是与1970年1月1日午夜之间的差值。 单位：毫秒 示例：1704211200000|
|updateTime|O|Integer(64)|元服务链接更新时间。 此时间是与1970年1月1日午夜之间的差值。 单位：毫秒 示例：1704211200000|
