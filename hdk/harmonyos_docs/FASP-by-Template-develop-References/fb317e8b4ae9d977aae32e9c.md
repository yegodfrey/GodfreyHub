# LeadingOfficialInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------|
|name|O|String|责任人姓名。|
|email|O|String|邮箱。|
|watermark|O|Integer(32)|是否加水印标识。 取值范围： * 0：是 * 1：否|
|reuse|O|Boolean|是否复用。 取值范围： * true：是 * false：否|
|orderId|O|Integer(64)|订单ID。|
|officialId|O|Integer(64)|责任人ID。|
|officialCertificateTypeId|O|Integer(32)|证件类型ID。|
|officialCertificateTypeName|O|String|证件类型名称。|
|officialCertificateNo|O|String|证件类号码。|
|phoneNum|O|String|手机号。|
|phoneCity|O|String|手机号归属地。|
|emergencyTel|O|String|紧急联系人号码。|
|emergencyTelCity|O|String|紧急联系人号码归属地。|
|checkStatus|O|Integer(32)|责任人核验状态。 取值范围： * 0：未核验 * 1：已通过 * 2：未通过 * 3：待确认|
|checkResultDesc|O|String|责任人核验结果描述。|
|idCardFaceVerifyResult|O|Integer(32)|身份证人脸核验结果。 取值范围： * 0：未核验 * 1：已通过 * 2：未通过 * 3：待确认|
|failedReason|O|String|身份证人脸核验结果状态为未通过或待确认时的原因详情。|
|accessories|O|List<[AttachmentRelation](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-attachmentrelation-0000002489083870)>|责任人附件。|
|certificatePeriod|O|String|证件有效期。 示例：2024.10.27-2034.10.27|
