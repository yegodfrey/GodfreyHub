# DeviceTypeInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:----------|:-------------------------------------------------------------------------------------|
|deviceType|M|Integer(32)|设备类型。 取值范围： * 4：手机 * 5：平板 * 12：智能手表 * 14：运动手表 * 19：2in1|
|appAdapters|O|String(32)|适配设备类型。 取值范围： * 5：平板 说明： 当deviceType为4（手机）时，系统会默认兼容分发到平板设备，即给appAdapters赋值5。 * 19：2in1|
