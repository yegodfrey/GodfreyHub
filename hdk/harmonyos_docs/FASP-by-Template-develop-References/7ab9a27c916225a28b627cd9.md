# 备案订单修改元服务

## 功能介绍

此接口用于给备案的订单修改元服务信息。

## 接口原型

|承载协议|HTTPS PUT|
|-----|--------------------------------------------------------------------|
|接口方向|服务商服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/icp-manage/v1/order/website|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

|**参数**|必选(M)/可选(O)|**类型**|**说明**|
|:------------|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台"开发配置 > 开发资料设置"页面中获取，详情请参见[获取平台访问凭据](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section3986829135420)。|
|Authorization|M|String|认证信息。 格式为"Authorization: Bearer *${access_token}*"。 其中，*${access_token}* 为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-0000001569170877)中获取的access_token。|
|appId|M|String(32)|应用ID。 元服务则为元服务的应用ID。 应用ID可以调用[获取指定授权账号详情](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-authorization-info-0000001501417588)接口从**authorizerAppId**字段获取。|

### Body

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|remarks|O|String(1024)|备注。|
|orderId|O|Integer(64)|订单ID。 备案订单修改元服务时，需要传**orderId**。 此入参值可以在调用[备案订单创建](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-subject-website-0000002489243844)、或[查询备案订单列表](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-order-infos-0000002521243661)接口时，从**orderId**字段中获取。|
|websiteId|O|Integer(64)|元服务信息的记录ID。 备案订单修改元服务时，需要传**websiteId**。 此入参值可以在调用[备案订单增加网站](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-add-websites-0000002489083860)接口时，从**websiteId**字段中获取。|
|websiteName|M|String(512)|元服务名称。|
|websiteServiceContents|M|List<String>|元服务的服务内容。 数组最大长度为5。|
|websiteServiceType|O|Integer(32)|应用服务类型。 取值范围： * 8：元服务服务类型|
|websiteLanguages|O|List<Integer(32)>|元服务的语言类别。 数组最大长度为3。 取值范围： * 1：中文简体 * 2：中文繁体 * 3：维吾尔语 * 4：哈萨克语 * 5：柯尔克孜语 * 6：蒙古语 * 7：藏语 * 8：壮语 * 9：朝鲜语 * 10：彝文 * 11：苗语 * 12：英语 * 13：日语 * 14：法语 * 15：俄罗斯语 * 16：西班牙语 * 17：阿拉伯语|
|preApproveInfos|O|List<[PreApproveInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-preapproveinfo-0000002521363683)>|前置审批信息。|
|leadingOfficial|M|[CreateLeadingOfficial](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-createleadingofficial-0000002521243677)|主办单位责任人信息。|
|recordId|O|String|备案号。|
|websiteApplet|O|[WebsiteAppletReq](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-websiteappletreq-0000002489083894)|元服务的小程序信息。|
