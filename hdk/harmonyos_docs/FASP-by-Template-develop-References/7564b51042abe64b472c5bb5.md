# WebsiteAppInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------|
|appId|O|Integer(64)|APP记录ID。|
|supportSdk|O|Integer(32)|是否提供SDK。 取值范围： * 0：未提供 * 1：提供|
|useSdk|O|Integer(32)|是否使用SDK。 取值范围： * 0：未使用 * 1：使用|
|appIcon|O|String|APP的图标附件ID。|
|sdkServiceList|O|List\<[WebsiteSdkServiceInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-websitesdkserviceinfo-0000002521243701)\>|应用SDK服务信息。|
|appPlatformList|O|List\<[WebsiteAppPlatformInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/recordal-websiteappplatforminfo-0000002521243697)\>|APP平台发布信息。|
|remark|O|String|备注。|
