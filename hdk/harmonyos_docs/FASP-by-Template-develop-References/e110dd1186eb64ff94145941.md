# AppServiceType

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:----------|:-------------------------------------------------------|
|typeId|O|Integer(64)|类型ID。|
|fatherId|O|String|标识ID。 0为一级ID，非0为二级ID。一级ID为二级ID的父标识ID。 示例：500，则500即为二级ID。|
|typeName|O|String|类型名称。|
|isValid|O|Integer(32)|类型是否有效。 取值范围： * 0：无效 * 1：有效|
