# WebsiteSimpleInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:--------------|:----------|:----------|:---------------------------------------------------------------|
|websiteId|O|Integer(64)|元服务信息的记录ID。|
|websiteRecordNo|O|String|对于已经备案成功的元服务，返回元服务的备案号。|
|websiteName|O|String|元服务名称。|
|serviceType|O|Integer(32)|应用服务类型。 取值范围： * 8：元服务服务类型|
|recordStatus|O|Integer(32)|备案状态。 取值范围： * 0：备案中 * 1：已备案|
|auditStatus|O|Integer(32)|订单元服务审核状态。 取值范围： * 0：等待审核 * 1：审核通过 * -1：审核拒绝 * 2：未请求审核 * 3：审核未完成|
|createTime|O|Integer(64)|创建时间。 此时间是与1970年1月1日午夜之间的差值。 单位：毫秒 示例：1764062872000|
|updateTime|O|Integer(64)|修改时间。 此时间是与1970年1月1日午夜之间的差值。 单位：毫秒 示例：1764062872000|
|appletFeature|O|String|元服务包名。|
|appletType|O|Integer(32)|应用类型。 取值范围： * 83：元服务|
