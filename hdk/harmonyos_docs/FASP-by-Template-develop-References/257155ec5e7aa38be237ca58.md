# 备案历史记录

#### 功能介绍

此接口用于查询备案的历史记录，以支持查看审核历史。  

#### 接口原型

|承载协议|HTTPS GET|
|接口方向|服务商服务器 -\> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/icp-manage/v1/record-history|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|
|-----|---------------------------------------------------------------------|
