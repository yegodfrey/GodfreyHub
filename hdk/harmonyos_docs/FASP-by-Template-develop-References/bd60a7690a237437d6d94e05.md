# CreateLeadingOfficial

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------------|:----------|:----------|:----------------------------------------------------------------------------------------------------------------|
|name|M|String(128)|责任人姓名。|
|email|M|String(128)|邮箱。 最小字符长度为6，最大字符长度为128。|
|officialId|O|Integer(64)|责任人ID。 如果使用已存在负责人，则需传**officialId**。|
|certificateType|M|Integer(32)|证件类型。|
|certificateNo|M|String(255)|证件号码。|
|phoneNum|M|String(11)|手机号码。|
|isPhoneNumVerify|M|Boolean|手机号码是否验证。 取值范围： * true：不需要验证手机号 * false：需要验证手机号 默认值：true > 说明 > 当前接口不支持手机号验证，如果设置为false，请服务商自行在SaaS平台完成手机号的有效性验证。|
|verifyCode|O|String(6)|验证码。 用于验证手机号码是否正确。 > 说明 > isPhoneNumVerify选择false（需要验证手机号）时，此参数必填。|
|emergencyTel|O|String(11)|紧急联系人号码。|
|certificatePeriod|O|String(21)|证件有效期。 最小字符长度为11，最大字符长度为21。 示例：2021.01.01-2031.01.01|
