# WebsiteDisplay

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------------|:----------|:-----------|:-----------------------------------------------------------------------------------------------------|
|domains|O|List<String>|元服务域名。|
|status|O|Integer(32)|元服务状态。 取值范围： * 0：待审核 * 1：审核驳回 * 2：待提交管局 * 3：已备案 * 4：已注销 * 5：已注销接入 * 6：管局驳回 * 7：已转移 * 8：待完善资料 * 9：待管局审核|
|websiteId|O|Integer(64)|元服务信息的记录ID。|
|websiteName|O|String|元服务名称。|
|officialId|O|Integer(64)|元服务的负责人ID。|
|leadingOfficialName|O|String|元服务的负责人名称。|
|websiteRecordId|O|String|元服务的备案号。|
|serviceType|O|Integer(32)|应用服务类型。 取值范围： * 8：元服务服务类型|
|appletType|O|Integer(32)|应用类型。 取值范围： * 83：元服务|
