# TicketStatus

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:---------|:----------|:----------|:-------------------------------------------------------|
|ticket|O|String|核验二维码URL对应的票证。|
|isExpire|O|Integer(32)|是否过期。 取值范围： * 0：未过期 * 1：已过期|
|expireTime|O|Integer(32)|距离过期时间。 单位：秒 说明： 当isExpire=0时，返回此字段；当isExpire=1时，不返回此信息。|
