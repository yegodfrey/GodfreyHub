# WebsiteAppletReq

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:----------|:------------------------------|
|websiteId|O|Integer(64)|元服务信息的记录ID。|
|appletId|O|Integer(64)|元服务的小程序信息的记录ID。|
|appletFeature|M|String(64)|元服务包名。|
|appletType|O|String|元服务类型。 取值范围： * ATOM_SERVICE：元服务|
|remark|O|String(256)|备注。|
