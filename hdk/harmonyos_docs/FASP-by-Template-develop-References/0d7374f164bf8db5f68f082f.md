# ACLPermission

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:----------|:------------------------------|
|id|O|String(100)|ACL权限ID。|
|aclType|O|integer|ACL权限类型。 取值范围 * 0：普通应用 * 1：自研应用|
|reason|O|String(500)|使用ACL权限的原因。|
|videoObjectId|O|String(256)|ACL权限使用场景说明的视频。|
