# OrderChangeLog

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-----------|:----------|:----------|:-------------------------------|
|orderId|O|Integer(64)|备案订单ID。|
|relativeType|O|Integer(32)|备案订单下变更实体类型。 取值范围： * 1：主体 * 2：网站|
|relativeId|O|Integer(64)|备案订单下变更实体ID。|
|fieldName|O|String|变更属性名称。|
|oldValue|O|String|变更属性原值。|
|updateTime|O|Integer(64)|更新时间。|
|operatorId|O|String|更新操作人。|
