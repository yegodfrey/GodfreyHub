# 查询应用信息

## 功能介绍

此接口用于根据指定语言和应用ID查询HarmonyOS应用/元服务的详细信息。

## 接口原型

|承载协议|HTTPS GET|
|-----|-------------------------------------------------------------------|
|接口方向|服务商服务器 -> 华为服务器|
|接口URL|https://connect-api.cloud.huawei.com/api/publish/v3/app-info|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

|**参数**|必选(M)/可选(O)|**类型**|**说明**|
|:------------|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|M|String|API客户端ID。 创建第三方平台成功后系统自动分配的客户端ID，可在第三方管理平台"开发配置 > 开发资料设置"页面中获取，详情请参见[获取平台访问凭据](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section3986829135420)。|
|Authorization|M|String|认证信息。 格式为"Authorization: Bearer *${access_token}*"。 其中，*${access_token}* 为[获取平台级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-0000001569170877)中获取的access_token。|

### Query

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|appId|M|String(32)|需要查询的应用ID。|
|lang|O|String(16)|需要查询的语言。 取值参考[语言类型](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/api-reference-langtype-0000002130782153)。不传该参数则查询全部语言的应用信息。|
|releaseType|O|Integer|应用发布方式。 取值范围： * 1：全网 * 6：HarmonyOS测试发布方式（API>=10） 默认值：1|
|versionId|O|String|需要查询的版本ID。 > 注意 > releaseType为6，该字段必填。|

## 请求样例

```screen
GET /api/publish/v3/app-info?appId=10*****57 HTTP/1.1
Host: connect-api.cloud.huawei.com
client_id: 41*****7168
Authorization: Bearer ******
```

## 响应参数

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:----------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------|
|ret|M|[ConnectRet](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-connectret-0000002130805573)|包含返回码及描述信息的结果。|
|appInfo|O|[AppInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-appinfo-0000002130965209)|应用基本信息。|
|auditInfo|O|[AuditInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-auditinfo-0000002130805577)|审核意见信息。|
|languages|M|List<[LanguageInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-languageinfo-0000002130965213)>|包含多种语言的应用信息。 * 如果查询时传递了语言类型，则返回当前语言的应用信息。 * 如果查询时未传递语言类型，则返回所有语言的应用信息。 * 如果查询时设置了异常的语言数据（例如不存在的语言类型），则返回空数组。|
|phasedReleaseInfo|O|[PhasedReleaseInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-phasedreleaseinfo-0000002095246218)|分阶段发布信息。|
|openTestInfo|O|[OpenTestInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-opentestinfo-0000002657935600)|测试版本信息，包含测试版本开始时间和结束时间。|
