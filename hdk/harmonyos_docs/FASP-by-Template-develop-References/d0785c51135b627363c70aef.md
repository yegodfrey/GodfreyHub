# 刷新用户级Token

## 功能介绍

当Access Token快要失效或已经失效时，使用Refresh Token来获取新的Access Token。

## 使用注意事项

建议在Access Token即将过期的时候调用。

## 接口原型

|承载协议|HTTPS POST|
|-----|-------------------------------------------------------------------------|
|接口方向|服务商服务器 -> 华为服务器|
|接口URL|https://oauth-login.cloud.huawei.com/oauth2/agent/v1/access-token/refresh|
|数据格式|请求：Content-Type: application/json 响应：Content-Type: application/json|

## 请求参数

### Header

|**参数**|必选(M)/可选(O)|**类型**|**说明**|
|:----------------|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|x-client-id|M|String|商家的client_id。 前往授权信息页面点击"更多"获取的"授权应用ClientID"，详情请参见[查看授权信息](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/query-authorization-infor-0000002523075604)。|
|x-agent-client-id|M|String|服务商的client_id。 创建第三方平台时由服务商主动创建的服务账号ID，可在第三方管理平台"开发配置 > 开发资料设置"页面中创建/查询，详情请参见[获取应用访问凭据](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section46998614287)。|

### Body

|**参数**|必选(M)/可选(O)|类型|**说明**|
|:--------------------|:----------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------|
|grant_type|M|String|固定为refresh_token。|
|refresh_token|M|String|填写[获取用户级Token](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-token-user-0000001622722589)返回的refresh_token。|
|client_assertion_type|M|String|固定为"urn:ietf:params:oauth:client-assertion-type:jwt-bearer"。|
|client_assertion|M|String|服务商生成的JWT。|

其中，**client_assertion**是一个JSON Web Token（JWT）。
> 说明
>
> JWT是一个开放标准（RFC 7519），定义了一种安全传输信息的方法，具体请参见[jwt.io](https://jwt.io/)。

JWT由Header、Payload和Signature三部分拼接组成，三部分中间以"."号分隔，例如：xxxx.yyyy.zzzz。

服务商可以依据Header中指定算法以及使用创建凭据下载的json文件内密钥ID关联的私钥（即json凭据文件中[private_key](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/create-platform-0000002523075512#ZH-CN_TOPIC_0000002523075512__p8324442152714)）进行签名生成JWT。

**JWT Header**

|**参数**|必选(M)/可选(O)|**类型**|**说明**|
|:-----|:----------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|alg|M|String|算法类型，固定为PS256。|
|typ|M|String|Token类型，固定为JWT。|
|kid|M|String|密钥ID。即json凭据文件中[key_id](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/create-platform-0000002523075512#ZH-CN_TOPIC_0000002523075512__p73739394272)。|

**JWT** **Payload**

|**参数**|必选(M)/可选(O)|类型|**说明**|
|:-----|:----------|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|iss|M|String|服务商的client_id。 创建第三方平台时由服务商主动创建的服务账号ID，可在第三方管理平台"开发配置 > 开发资料设置"页面中创建/查询，详情请参见[获取应用访问凭据](https://developer.huawei.com/consumer/cn/doc/SPPartnerCenter-develop-Guides/obtain-development-infor-0000002523235520#section46998614287)。|
|sub|M|String|商家的client_id。|
|aud|M|String|固定为"https://oauth-login.cloud.huawei.com/oauth2/agent/token"。|
|iat|M|Integer|生成时间，linux时间戳。|
|exp|M|Integer|过期时间，linux时间戳。|

## 请求示例

```screen
POST /oauth2/agent/v1/access-token/refresh HTTP/1.1
Host: oauth-login.cloud.huawei.com
x-client-id: 12345000
x-agent-client-id: 12345666
Content-Type: application/json
 
{
    "grant_type": "refresh_token",
    "refresh_token": "DAECABdcJTSlxxxxxHi81JkkE6zGT",
    "client_assertion_type": "urn:ietf:params:oauth:client-assertion-type:jwt-bearer",
    "client_assertion": "xxxx.yyyy.zzzz"
}
```

## 响应参数

返回值为JSON格式的字符串，包含参数如下。

|字段名|类型|说明|
|:-----------|:------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|id_token|String|如果scope中包含openid，则返回id_token，JWT格式。 如果要解析出用户的ID Token，需要先对ID Token的有效性进行验证，详情请参见[ID Token验证签名](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section1991115414569)。|
|access_token|String|ACCESS_TOKEN，后续用它来调用业务API接口。|
|token_type|String|固定值Bearer。|
|expires_in|Integer|access_token的过期时间，以秒为单位。过期时间默认60分钟。|
|scope|String|该access_token对应的scope列表，以空格分隔。|

## 响应示例

**成功**：

```screen
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
Cache-Control: no-store
Pragma: no-cache
 
{
"access_token": "CFyJ4Jxxxxxxxxx7vs=",
"id_token": "eyJhbGciOiJSUzxxxxxxxxxx1GDLQ",
"expires_in": 3600,
"scope": "openid profile email",
"token_type": "Bearer"
}
```

**失败**：

失败返回的httpstatus=400，在body中返回错误码和描述，json格式。

例如：

```screen
HTTP/1.1 400 Bad Request
Content-Type: text/html;charset=UTF-8
 
{
"error":31204,
"error_description":"token revoked"
}
```
