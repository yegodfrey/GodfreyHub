# OpenApplyPermissionStatusInfo  
  
参数名称 | 必选(M)/可选(O) | 类型 | 参数说明  
---|---|---|---  
name | O | String(256) | 受限ACL权限名称。  
status | O | Integer | 受限ACL权限的申请状态。 取值范围：

  * 0：申请中
  * 1：审核通过
