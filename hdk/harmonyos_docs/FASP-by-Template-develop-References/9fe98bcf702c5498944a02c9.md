# QualificationFileInfo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------|:----------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|objectId|M|String(128)|资质上传的objectId。 先调用[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-upload-url-0000002057702505)接口，然后调用[上传文件](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/upload-file-0000002095222766)接口上传文件，最后得到[获取上传文件地址](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/get-upload-url-0000002057702505)接口返回的objectId。|
|fileName|M|String(128)|资质文件名称。|
|fileSize|M|Integer(64)|资质文件大小，单位：字节。|
|sha256|M|String(128)|资质文件SHA256值。|
