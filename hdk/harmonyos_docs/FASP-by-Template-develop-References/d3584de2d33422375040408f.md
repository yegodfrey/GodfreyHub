# AttachBelong

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:------------|:----------|:-------------|:------------------------------------------------------------------------------------------------------------------|
|belongName|O|String|附件所属的对象名称。|
|belongType|O|Integer(32)|责任人所属的类型。 取值范围： * 0：主体责任人 * 1：元服务责任人|
|belongId|O|Integer(64)|附件所属的对象ID。|
|domainNames|O|List\<String\>|元服务的域名列表。|
|curtainStatus|O|Integer(32)|备案幕布状态。 说明： 备案幕布是一种在备案时使用的图片或模板，主要用于遮挡敏感信息（如身份证号、联系方式等），防止个人信息泄露。 取值范围： * 0：待提交 * 1：待审核 * 2：审核通过 * 3：审核驳回 * 4：待提交审核|
