# Agreement（用户协议）

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------|
|id|O|String|用户协议ID。|
|type|O|Integer(32)|协议类型。 取值范围： * 2：用户协议|
|agreementInfos|O|List\<[AgreementInfo](https://developer.huawei.com/consumer/cn/doc/FASP-by-Template-develop-References/publish-agreementinfo-0000002226856433)\>|用户协议列表。 数组长度不超过100。|
|versionCode|O|Integer(64)|用户协议版本号。|
|status|O|Integer|用户协议状态。 取值范围： * 2：已完成 * 3：已删除|
|defaultLang|O|String(20)|用户协议默认语言。 取值范围： * zh：简体中文 * en：英语 * ug：维吾尔语 * bo：藏语 * zh-Hant-HK：繁体中文（中国香港特别行政区） * zh-Hant-TW：繁体中文（中国台湾）|
|createTime|O|Integer(64)|用户协议创建时间与1970年1月1日午夜之间的差值，以毫秒为单位。例如：1733555215000|
|updateTime|O|Integer(64)|用户协议最近更新时间与1970年1月1日午夜之间的差值，以毫秒为单位。例如：1733555215000|
