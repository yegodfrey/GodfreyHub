# PackagePermissionIntroVideo

|参数名称|必选(M)/可选(O)|类型|参数说明|
|:-------------|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|lang|M|String(8)|语言种类，取值参见[语言类型](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-References/agcapi-reference-langtype-0000001158245079)。|
