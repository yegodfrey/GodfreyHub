# 手动升级-升级检测

1. 描述：指定某一台设备做新版本检测，检测是否有待升级新版本。
   1. 本接口是异步接口，检测结果会通过上报接口（参考[统一事件通知接口](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-References/event-notification-interface-0000001455235346)）上报检测结果；也可以主动查询设备数据信息（参考[查询指定设备信息](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-References/query-specific-device-information-0000001455555178)）
   2. 根据检测结果判断是否需要升级规则：设备查询信息中当前版本字段：fwv；检测结果返回新版本version；当这两个版本值不一致时表示需要升级。
2. 复用[控制设备](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-References/control-device-0000001455395278)接口发送检测命令
3. 请求示例：

   ```screen
   POST https://{Endpoint}/openapi/asset/v1/device/8f7e3fbd-8804-4a48-b3d1-df29f05d823c/command
    
   {
    "deviceId": "8f7e3fbd-8804-4a48-b3d1-df29f05d823c",
    "serviceId": "update",
    "data": {
        "action": 0
    }
   }
   ```

4. 响应示例： Status Code: 200 OK
