# 场景执行日志通知- scenarioLog

1. 描述：场景执行后， 将执行结果通知给ISV。 注：支持场景范围：主机手动规则、中枢手动规则、中枢自动规则。

2. 请求示例：

   ```screen
   [
    {
        "dataType": "scenarioLog",
     "payload":"[{\"projectId\":\"878052642478100096\",\"spaceId\":\"878052642478100096\",\"scenarioId\":\"b9a34261-df91-461a-bd18-0c102ca317cf\",\"result\":\"success\",\"dataTimeStamp\":\"1655293118529\"},{\"projectId\":\"878052642478100096\",\"spaceId\":\"878032460108009088\",\"scenarioId\":\"e68d5ab1-959f-4374-8a4d-3e594d81e237\",\"result\":\"failed\",\"dataTimeStamp\":\"1655293118529\"}]"
    }
   ]
    
   Payload部分报文格式：
   [
    {
        "projectId": "878052642478100096",
        "spaceId": "878052642478100096",
        "scenarioId": "b9a34261-df91-461a-bd18-0c102ca317cf",
        "result": "success",
        "dataTimeStamp": "1655293118529"
    },
    {
        "projectId": "878052642478100096",
        "spaceId": "878032460108009088",
        "scenarioId": "e68d5ab1-959f-4374-8a4d-3e594d81e237",
        "result": "fail",
        "failedReason": "",
        "dataTimeStamp": "1655293118529"
    }
   ]
    
   ```

3. 参数说明：

|--|-------------|----|------|------|--------------------|
|序号|参数|是否必须|类型|长度|描述|
|1|projectId|必选|String|1-24|项目ID|
|2|spaceId|必选|String|1-24|空间ID|
|3|scenarioId|必选|String|24-256|场景ID|
|4|result|必选|枚举|1-36|场景执行结果： success/fail|
|5|failedReason|可选|String|0-256|失败原因|
|6|dataTimeStamp|必选|Long|  |产生时间|
