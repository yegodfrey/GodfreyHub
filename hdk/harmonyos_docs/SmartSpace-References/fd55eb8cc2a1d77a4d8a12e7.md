# 使用限制及规约

|--|----------------------------------------------------------------------------------------|
|序号|说明|
|1|单个项目调用API的每秒最大次数（最大下行的请求数）为20次/s； 单个API每秒最大次数为10次/s；每天API调用总次数限制为1w次/天。|
|2|单个项目的空间数量最多支持1000个|
|3|因为设备数据、状态变更频繁导致通知变更频繁，三方云定义上报接口时，应优先考虑处理效率，建议异步处理；华为全屋智能平台的Http超时等待时间为1s。|
|4|仅支持Https ，Https TLS版本不得低于1.2|
|5|Https支持的body体最大长度为1M|
|6|华为全屋智能平台会对接口调用方采取IP白名单管理|
|7|x-request-id 格式说明，由 0-9a-z和-组成， 长度为36位，每个请求不能相同。|
|8|PUT修改接口默认为全量修改；例如修改空间接口， 支持修改spaceName和desc两个字段， 假如接口报文中只带了spaceName的值，会默认为desc字段会修改为空值。|
|9|ISV <-> 华为全屋智能平台，双向接口采用一套鉴权机制，共用一套共享秘钥。|
|10|通知接口无法保证100%可达，所以高可靠的特性不能依赖通知接口， 比如SOS通知。|
