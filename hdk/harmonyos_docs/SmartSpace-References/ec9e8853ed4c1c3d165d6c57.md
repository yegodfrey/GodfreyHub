# 设备注册状态变更通知- deviceRegisterStatus

1. 描述：交房后，设备注册到全屋智能平台；或者恢复交房，设备从全屋智能平台删除，触发此通知消息
2. 请求示例：

   ```screen
   [
    {
        "dataType": "deviceRegisterStatus",
        "payload":"[{\"projectId\":\"878052642478100096\",\"deviceId\":\"8f7e3fbd-8804-4a48-b3d1-df29f05d823c\",\"registerStatus\":\"active\",\"spaceId\":\"878052642478100096\",\"gatewayDeviceId\":\"2908d7b5-ab58-4531-8764-15eadeebd3b6\",\"timestamp\":\"20151212T121212001Z\"},{\"projectId\":\"878052642478100096\",\"deviceId\":\"13d3bb29-01fd-4b11-af7a-70ba87f9ddf2\",\"registerStatus\":\"deActive\",\"spaceId\":\"878052642478100096\",\"gatewayDeviceId\":\"2908d7b5-ab58-4531-8764-15eadeebd3b6\",\"timestamp\":\"20151212T121212001Z\"}]"
    }
   ]
    
   Payload部分报文格式：
   [
    {
        "projectId": "878052642478100096",
        "deviceId": "8f7e3fbd-8804-4a48-b3d1-df29f05d823c",
        "registerStatus": "active",
        "spaceId": "878052642478100096",
        "gatewayDeviceId": "2908d7b5-ab58-4531-8764-15eadeebd3b6",
        "timestamp": "20151212T121212001Z"
    },
    {
        "projectId": "878052642478100096",
        "deviceId": "13d3bb29-01fd-4b11-af7a-70ba87f9ddf2",
        "registerStatus": "deActive",
        "spaceId": "878052642478100096",
        "gatewayDeviceId": "2908d7b5-ab58-4531-8764-15eadeebd3b6",
        "timestamp": "20151212T121212001Z"
    }
   ]
   ```

3. 参数说明：

|--|---------------|----|------|----|---------------------------------------|
|序号|参数|是否必须|类型|长度|描述|
|1|projectId|必选|String|1-24|项目ID|
|2|deviceId|必选|String|1-36|设备ID，设备唯一标识|
|3|registerStatus|必选|枚举|16|注册状态: active deActive|
|4|spaceId|必选|String|1-24|空间ID|
|5|gatewayDeviceId|必选|String|1-36|中枢/主机的设备ID，针对下挂设备；假如就是中枢/主机值等于deviceId。|
|6|dataTimeStamp|必选|Long|  |产生时间|
