# 统一事件通知接口

1. 描述：该接口由三方云定义提供，当华为全屋智能平台管理的指定数据、状态发生变更时，华为全屋智能平台调用此接口将变更通知给三方云。 建议： 为了提高通知消息发收的可靠性， ISV在实现此接口，建议定义主备两套URL入口，且物理隔离开； 全屋智能平台优先往主接口发送通知， 当主接口出现错误时， 会自动再尝试通过备接口发送。

2. 接口类型：REST
3. URI：

   |----|-------------------|
   |请求方法|POST|
   |URI|https://xxxx(ISV提供)|
   |传输协议|HTTPS|

4. 请求参数：

   |--|--------|----|------|------|-------------------------------------------------------------------------------------------------------------------------------|
   |序号|参数|是否必须|类型|长度|描述|
   |1|dataType|必选|枚举|1-16|通知类型 枚举值： 1. deviceEvent：设备数据变更通知 2. deviceStatus：设备状态变更通知（online/offline） 3. scenarioLog：场景执行日志 4. deviceRegisterStatus:设备注册状态|
   |2|payload|必选|String|1-2048|通知消息体|

5. 响应参数： NA

6. 请求示例：

   ```screen
   POST https://xxxx
    
   [
    {
        "dataType": "deviceEvent",
        "payload":"..."
    },
    {
        "dataType": "deviceStatus",
        "payload":"..."
    },
    {
        "dataType": "scenarioLog",
        "payload":"..."
    },
    {
        "dataType": "deviceRegisterStatus",
        "payload":"..."
    }
   ]
   ```

7. 响应示例： Status Code: 200 OK

8. 错误码

   |-------|----------|----------------------|------|---------------|
   |HTTP状态码|错误码|英文错误描述|中文错误描述|处理建议|
   |401|isv.000001|Unauthorized.|非法请求|请检查AK/SK算法是否正确。|
   |403|isv.000002|Forbidden.|没有权限|请检查是否被授权|
   |404|isv.000003|Not Found.|资源不存在|请排查请求参数是否有误|
   |500|isv.000004|Internal server error.|内部错误|请稍等重试|
