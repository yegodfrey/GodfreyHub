# 通知宿主亮屏

## 接口描述

wakeLockScreen

唤醒点亮屏幕，如果屏幕已锁定则先解锁然后亮屏

## 适用平台

Android

## 请求参数

通用参数

|参数|类型|描述|
|:-----------|:-----|:----|
|functionName|String|接口名称|
|accessId|String|接口鉴权码|
|packageName|String|插件包名|

## 请求参数样例

```codeblock
{
	" functionName ": " wakeLockScreen ",
	" accesssId ": "xxxx-xxx-xx-xxx-xxxx-xxx",
	" packageName ": "com.huawei.xxx"
}
```

## 响应参数

NULL

## 错误码

code为0：成功

code为-1：成功
