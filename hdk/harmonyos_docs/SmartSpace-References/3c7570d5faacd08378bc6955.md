# 请求消息头

附加请求头字段，如指定的URI和HTTP方法所要求的字段。例如定义消息体类型的请求头"Content-Type"，请求鉴权信息等。

如下公共消息头需要添加到请求中，下文请求示例中不再体现。

· **Content-Type** ：消息体的类型（格式），必选，默认取值为"application/json;charset=UTF-8"，有其他取值时会在具体接口中专门说明。

· **Accept** **：** 消息头的类型（格式），必选，默认取值为"application/json"。

· **x-request-id** ：请求标识，建议采取UUID（36）格式，每个请求生成不同的ID。

· **x-access-key** ：AK（Access Key ID）信息。

· **x-project-id**：项目ID信息。

·**x-timestamp**：时间戳，距离1970年1月1日0时0分0秒的毫秒值，防止重放攻击使用。该字段主要用来防止重放攻击，针对超过5s的重复请求直接拒绝。

· **x-sign** ：对消息头+消息体的签名信息，签名计算规则请参照[签名认证操作指导](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-References/signature-authentication-guide-0000001455235350)。

例：POST https:// domain:port/openapi/asset/v1/space

Content-Type: application/json

Accept: application/json

x-access-key: 101867757

x-project-id: 123456112355442

x-request-id: 4871cc67-a2ec-41f7-b4e7-a5c1b236ee1b

x-timestamp：1640759898914

x-sign: x-access-key,x-project-id,x-request-id,x-timestamp;MTIzMTIzMTLpmLAOIYTkjYTTHpPIWNUTGFEEE
