# 请求获取AccessId

## 接口描述

requestAccessId

请求宿主更新AccessId，基于安全策略宿主不会直接通过callback返回accessId

```screen
宿主会通过调用插件的setAccessId接口将最新的accessId传递给插件, 参见https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-References/notification-brighten-screen-0000001455235298。
主要用于插件侧和宿主侧两侧存储的AccessId不一致时调用。
注：由于此接口不会校验accessId, 出于安全考虑，设置有防攻击机制，10s 内仅允许调用一次，如果连续调用多次可能会失败，如果接口失败，可以等待10s后调用。
```

## 适用平台

Android

## 请求参数

通用参数

|参数|类型|描述|
|:-----------|:-----|:-------------------------|
|functionName|String|接口名称|
|accessId|String|接口鉴权码（此参数建议带上已失效的accessId）|
|packageName|String|插件包名|

## 请求参数样例

```codeblock
{
	" functionName ": " updateAccessId",
	" accessId ": "xxxxx-xxxxx-xxxxxx",
	" packageName ": "com.huawei.xxx"
}
```

## 响应参数

NA

## 错误码

code为0：成功

code为-1：失败
