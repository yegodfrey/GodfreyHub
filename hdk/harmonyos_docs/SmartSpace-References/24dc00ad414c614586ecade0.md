# 解除订阅安防事件

## 接口描述

unsubscribeSecurityEvent

解除订阅的告警事件

## 适用平台

Android

## 请求参数

通用参数

|参数|类型|描述|
|:-----------|:-----|:----|
|functionName|String|接口名称|
|accessId|String|接口鉴权码|
|packageName|String|插件包名|

## 请求参数样例

```codeblock
{
	" functionName ": " unsubscribeSecurityEvent ",
	" accesssId ": "xxxx-xxx-xx-xxx-xxxx-xxx",
	" packageName ": "com.huawei.xxx"
}
```

## 响应参数

NULL

## 错误码

code为 0：成功

code为-1：失败
