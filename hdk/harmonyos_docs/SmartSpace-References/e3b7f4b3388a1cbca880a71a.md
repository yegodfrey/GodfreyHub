# 查询指定设备信息

1. 描述：调用此接口查询指定设备信息。一次查询最多支持查询20个设备信息。
2. 接口类型：REST
3. URI：

   |----|-------------------------------------------------|
   |请求方法|GET|
   |URI|/openapi/asset/v1/devices?deviceId=xx&deviceId=xx|
   |传输协议|HTTPS|

4. 请求参数：

   |--|--------|----|------|----|----|
   |序号|参数|是否必须|类型|长度|描述|
   |1|deviceId|必选|String|1-24|设备ID|

5. 响应参数：

   |--|-------------------|----|-------|-----|-----------------------------------------------------------------------------------|
   |序号|参数|是否必须|类型|长度|描述|
   |1|devices|可选|Object|0-500|设备集合|
   |2|deviceId|必选|String|  |设备ID|
   |3|status|必选|String|8|设备状态 枚举： online/offline|
   |4|spaceId|必选|String|1-24|空间ID|
   |5|gatewayDeviceId|必选|String|1-36|中枢/主机的设备ID，针对下挂设备；假如就是中枢/主机值等于deviceId。|
   |6|devInfo|必选|Object|  |设备基本信息|
   |7|model|必选|String|  |设备型号|
   |8|devType|必选|String|  |设备类型ID|
   |9|deviceName|可选|String|  |设备名称|
   |10|manu|必选|String|  |制造商ID|
   |11|prodId|必选|String|  |产品ID|
   |12|hiv|必选|String|  |sdk版本|
   |13|swv|可选|String|  |software version.软件版本|
   |14|fwv|可选|String|  |固件版本|
   |15|hwv|可选|String|  |硬件版本|
   |16|protType|可选|Integer|  |协议类型: 1: WiFi 2: Z-Wave 3: ZigBee 4: BLE|
   |17|services|必选|Object|0-100|服务集|
   |18|serviceType|必选|String|  |服务类型|
   |19|serviceId|必选|String|  |服务ID|
   |20|characteristics|必选|Object|0-100|特性集|
   |21|timestamp|可选|String|  |时间戳 UTC时间。Device可选，Gateway上报时必选添加此字段。时间格式：yyyymmddThhmmssSSSZ，如：20151212T121212001Z|
   |22|characteristicName|必选|String|  |特性名|
   |23|characteristicValue|必选|Object|  |特性值|

6. 请求示例：

   ```screen
   GET https://{Endpoint}/openapi/asset/v1/devices?deviceId=xxx
   ```

7. 响应示例： Status Code: 200 OK

