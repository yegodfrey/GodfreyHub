# 设备数据变更通知- deviceEvent

1. 描述：当华为全屋智能平台管理的设备数据发生变更时，触发此通知消息。
2. 请求示例：

   ```screen
   [
    {
        "dataType": "deviceEvent",
        "payload":"[{\"deviceId\":\"8f7e3fbd-8804-4a48-b3d1-df29f05d823c\",\"prodId\":\"2CQ5\",\"gatewayDeviceId\":\"\",\"dataTimeStamp\":1647353239,\"statusTimeStamp\":1647353239,\"gatewayStatusTime\":1647353239,\"services\":[{\"serviceType\":\"temperature\",\"serviceId\":\"acTemperature\",\"characteristics\":[{\"timestamp\":\"20151212T121212001Z \",\"characteristicName\":\"current\",\"characteristicValue\":25}]}]}]"
    }
   ]

   Payload部分报文格式：
   [
     {
         "deviceId": "8f7e3fbd-8804-4a48-b3d1-df29f05d823c",
         "projectId": "885462738984242816",
         "prodId": "2CQ5",
         "gatewayDeviceId": "",
         "dataTimeStamp": 1647353239,
         "statusTimeStamp": 1647353239,
         "gatewayStatusTime": 1647353239,
         "services": [
             {
                 "serviceType": "temperature",
                 "serviceId": "acTemperature",
                 "characteristics": [
                     {
                         "timestamp": "20151212T121212001Z",
                         "characteristicName": "current",
                         "characteristicValue": 25
                     }
                 ]
             }
         ]
     }
   ]
   ```

3. 参数说明：

|--|-------------------|----|----------|-----|-------------------------------------------------------------------------------|
|序号|参数|是否必须|类型|长度|描述|
|1|deviceId|必选|String|1-36|设备ID，设备唯一标识|
|2|projectId|必选|String|1-24|项目ID|
|2|prodId|必选|String|4|产品ID|
|3|gatewayDeviceId|必选|String|1-36|中枢/主机的设备ID，针对下挂设备；假如就是中枢/主机值等于deviceId。|
|4|dataTimeStamp|必选|Long|  |产生时间|
|5|statusTimeStamp|必选|Long|  |设备在线离线状态最近一次变化时间|
|6|gatewayStatusTime|必选|Long|  |设备网关在线离线状态最近一次变化时间。|
|7|services|必选|Object|  |  |
|8|servicetype|必选|  |  |服务类型|
|9|serviceId|必选|String(64)|  |服务标识，设备中唯一标识该服务|
|10|characteristics|必选|Object|0-100|特性集|
|11|timestamp|可选|String|  |UTC时间。Device可选，Gateway上报时必选添加此字段。时间格式：yyyymmddThhmmssSSSZ，如：20151212T121212001Z|
|12|characteristicName|必选|String|  |特性名|
|13|characteristicValue|必选|Object|  |特性值|
