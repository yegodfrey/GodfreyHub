# 订阅安防事件

## 接口描述

subscribeSecurityEvent

订阅事件

## 适用平台

Android

## 请求参数

通用参数

|参数|类型|描述|
|:-----------|:-----|:----|
|functionName|String|接口名称|
|accessId|String|接口鉴权码|
|packageName|String|插件包名|

接口定制参数

|参数|类型|描述|
|:--------|:------------|:------------------------------------------------------------|
|eventType|List<Integer>|订阅的事件类型: 1-烟雾告警 2-燃气告警 3-水浸告警 4-紧急按钮告警 5-入侵告警 当前仅支持传紧急按钮告警事件4|

## 请求参数样例

```codeblock
{
	" functionName ": " subscribeSecurityEvent",
	" accesssId ": "xxxx-xxx-xx-xxx-xxxx-xxx",
	" packageName ": "com.huawei.xxx",
	" eventType ": [
		4
	]
}
```

## 响应参数

NULL

## 错误码

code为 0：成功

code为-1：失败
