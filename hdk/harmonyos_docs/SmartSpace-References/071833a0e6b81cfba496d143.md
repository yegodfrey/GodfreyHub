# 状态码

请求发送以后，您会收到响应，包含状态码、响应消息头和消息体。

状态码是一个整型数字代码，状态码表示了请求响应的状态。对于[创建空间](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-References/create-space-0000001455395258)接口，如果调用后返回状态码为0，则表示请求成功。
