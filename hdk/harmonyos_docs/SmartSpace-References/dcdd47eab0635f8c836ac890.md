# 自动升级-查询自动升级状态

1. 描述：以空间维度查询自动升级能力是否激活。
2. 接口类型：REST
3. URI：

   |----|---------------------------------------------|
   |请求方法|GET|
   |URI|/openapi/asset/v1/space/{spaceId}/autoupgrade|
   |传输协议|HTTPS|

4. 请求参数：

   |--|-------|----|------|----|----|
   |序号|参数|是否必须|类型|长度|描述|
   |1|spaceId|必选|String|1-24|空间ID|

5. 响应参数：

   |--|---------------|----|------|---------------|--------------|
   |序号|参数|是否必须|类型|长度|描述|
   |1|spaceId|必选|String|1-24|空间ID|
   |2|gatewayDeviceId|必选|String|1-32|主机deviceId|
   |3|operationTag|必选|枚举|enable/disnable|使能自动升级/去使能自动升级|

6. 请求示例：

   ```screen
   GET https://{Endpoint}/openapi/asset/v1/space/879492664414703232/autoupgrade
   ```

7. 响应示例： Status Code: 200 OK

   ```screen
   {
     "spaceId": "879492664414703232",
     "gatewayDeviceId": "xxxx",
     "operationTag": "enable"
   }
   ```
