# 插件错误码

|-------|--------|-------------------------------------------|
|**错误码**|**说明**|**排查点**|
|0|执行成功|  |
|-1|执行失败|需要宿主侧定位|
|-2|参数错误|插件传入参数有误， 1排查json格式 2 排查字段是否完全 3 排查字段是否拼写正确|
|-3|无scope权限|1 排查调用的functionName是否在云侧已配置|
|-4|鉴权不成功|1 插件侧是否存储AccessId 2 可以重新请求AccessId|
