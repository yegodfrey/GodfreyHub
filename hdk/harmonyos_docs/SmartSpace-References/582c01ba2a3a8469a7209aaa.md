# 开启常驻任务

## 接口描述

startDaemonTask

开启插件常驻任务，该接口要求插件配置pluginInfoV2.json（联系华为接口人修改）中的allowDaemon字段；

## 适用平台

Android

## 请求参数

|参数|类型|描述|
|:-----------|:-----|:------------------|
|functionName|String|接口名称startDaemonTask|

## 响应参数

NULL

## 错误码

code为0：成功

code为-1：失败

## 方法实现说明

该方法在插件中实现，实现内容建议为拉起插件的某个服务或者业务；也可不实现具体业务，为空方法，直接放回0；
