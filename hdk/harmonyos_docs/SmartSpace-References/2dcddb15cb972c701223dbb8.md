# 自动升级-设置自动升级能力

1. 描述：以空间维度设置主机及下挂设备的自动升级能力，支持激活及去激活自动升级。
2. 接口类型：REST
3. URI：

   |----|---------------------------------------------|
   |请求方法|PUT|
   |URI|/openapi/asset/v1/space/{spaceId}/autoupgrade|
   |传输协议|HTTPS|

4. 请求参数：

   |--|-----------|----|------|----|--------------|
   |序号|参数|是否必须|类型|长度|描述|
   |1|spaceId|必选|String|1-24|空间ID|
   |2|autoUpgrade|必选|枚举|1/0|使能自动升级/去使能自动升级|

5. 响应参数： NA

6. 请求示例：

   ```screen
   PUT https://{Endpoint}/openapi/asset/v1/space/879492664414703232/autoupgrade
   {
    "autoUpgrade": 1
   }
   ```

7. 响应示例： Status Code: 200 OK
