# 控制设备

1. 描述：调用此接口实现异步控制设备。
2. 接口类型：REST
3. URI：

   |----|-------------------------------------------|
   |请求方法|POST|
   |URI|/openapi/asset/v1/device/{deviceId}/command|
   |传输协议|HTTPS|

4. 请求参数：

   |--|--------|----|------|----|----|
   |序号|参数|是否必须|类型|长度|描述|
   |1|deviceId|必选|String|1-24|设备ID|

5. 响应参数： NA

6. 请求示例：

   ```screen
   POST https://{Endpoint}/openapi/asset/v1/device/8f7e3fbd-8804-4a48-b3d1-df29f05d823c/command
    
   {
    "deviceId": "8f7e3fbd-8804-4a48-b3d1-df29f05d823c",
    "serviceId": "acSwitch",
    "data": {
        "on": 0
    }
   }
   ```

   > 说明
   >
   > 请求参数里的属性值（例如："on"具体的值的类型请参考给款设备的profile信息，具体信息请联系华为工程师）
7. 响应示例： Status Code: 200 OK

8. 错误码
