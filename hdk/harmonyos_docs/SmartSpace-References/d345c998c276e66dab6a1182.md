# 概述

智慧生活和插件之间是主进程和子进程的关系，之间涉及进程间通信，本方案中通过 AIDL 实现进程间通信。为了增加后续接口的拓展性，本方案中在插件侧和宿主侧进行的 AIDL 接口设计上，做了通用化的设计，使用通用控制接口，而相关的接口命令统一封装为 JSON ，作为参数传递。

**调用接口**：

* 插件调用智慧生活 void **callV2** (String **paramJsonString**, in IRemoteControlCallback callback);
* 智慧生活调用插件 void **call** (String **paramJsonString**, in IRemoteControlCallback callback);

**调用形式（paramJsonString）**：

```codeblock
{ 
    "functionName":"setPluginViewData", 
    "packageName":"xxxx",
    "param1":"xxx", 
    "param2":"xxx", 
    ... 
}
```

下面两个参数是所有插件调用宿主接口必备参数：

|参数|类型|描述|
|:-----------|:-----|:---|
|functionName|String|接口名称|
|packageName|String|插件包名|

后续接口介绍中，将省略以上两个通用必备参数的描述。

**回调接口**：

```codeblock
interface IRemoteControlCallback { 
    //成功的回调接口 
    void onSuccess(int code,String msg,String response); 
    //失败回调接口 
    void onFailure(int code,String msg,String response); 
}
```
