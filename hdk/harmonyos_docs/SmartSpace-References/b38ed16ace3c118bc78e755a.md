# 获取楼宇网络信息

## 接口描述

getBuildNetInfo

用户获取LCD屏连接主机楼宇网口IP相关信息

## 适用平台

Android

## 请求参数

通用参数

|参数|类型|描述|
|:-----------|:-----|:----|
|functionName|String|接口名称|
|accessId|String|接口鉴权码|
|packageName|String|插件包名|

## 请求参数样例

```codeblock
{
              "functionName": "getBuildNetInfo"
              "accesssId": "xxxx-xxx-xx-xxx-xxxx-xxx",
              "packageName": "com.huawei.xxx"
}
```

## 响应参数

```codeblock
{
	"address": "192.168.128.4",
	"gateway": "192.168.128.1",
	"mask": "255.255.255.0"
}
```

## 错误码

code为0：成功

code为-1：失败
