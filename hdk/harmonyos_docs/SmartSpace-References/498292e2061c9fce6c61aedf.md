# 通知插件告警

## 接口描述

notifySecurityEvent

通知告警信息

## 适用平台

Android

## 请求参数

|参数|类型|描述|
|:---------|:-----|:-----------------------------------|
|level|int|1-紧急 2-警告 3-提示|
|alarmType|int|1-烟雾告警 2-燃气告警 3-水浸告警 4-紧急按钮告警 5-入侵告警|
|status|int|0-正常 1-告警中 2-告警超时 3-用户确认|
|deviceId|String|事件发生的设备id|
|deviceName|String|事件发生的设备名字|
|productId|String|设备产品id|
|roomName|String|设备房间名称|
|roomId|String|设备房间id|

## 响应参数

NULL

## 错误码

code为0：成功

code为-1：失败
