# 设置卡片显示数据

## 接口描述

setUiContent

此接口用于LCD定制卡片动态刷新显示内容

## 适用平台

Android

## 请求参数

通用参数

|参数|类型|描述|
|:-----------|:-----|:----|
|functionName|String|接口名称|
|accessId|String|接口鉴权码|
|packageName|String|插件包名|

接口定制参数

|参数|类型|描述|
|:-------------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|featureName|String|智慧生活拉起插件时通过intent传递给插件的设备唯一标识,功能名称|
|pluginName|String|所对应的插件包名|
|uiTemplateType|enum|卡片类型，需要在已支持的卡片范围内，卡片类型选定就确定了卡片的尺寸和显示样式，内容必须与此一致；目前支持5中类型： 1. TEMPLATE_TYPE_1：运营展示类卡片4*4 2. TEMPLATE_TYPE_2：功能类4*4 3. TEMPLATE_TYPE_3：功能图标类2*4 4. TEMPLATE_TYPE_4：功能双按钮类2*4 5. TEMPLATE_TYPE_5：运营服务类2*4|
|uiContent|String|界面显示内容，具体内容请参考[华为全屋智能中控屏卡片规范及开放接口指导](https://developer.huawei.com/consumer/cn/doc/development/smartspace-Library/introduction-0000001504672469)|

## 请求参数样例

```codeblock
{
              "functionName": "setUiContent",
              "accesssId": "xxxx-xxx-xx-xxx-xxxx-xxx",
              "packageName": "com.huawei.xxx"，
              "featureName": "meetTime",
              "pluginName": "com.huawei.xxx",
              "uiTemplateType": "TEMPLATE_TYPE_1",
              "uiContent": {... ...}
}
```

## 响应参数

NULL

## 错误码

code为 0：成功

code为 -1：失败
