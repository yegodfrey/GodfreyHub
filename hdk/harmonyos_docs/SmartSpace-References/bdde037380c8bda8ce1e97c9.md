# 认证鉴权

调用接口通过AK/SK认证：通过AK（Access Key ID）/SK（Secret Access Key）加密调用请求。

· AK/SK认证就是使用AK/SK对请求进行签名，在请求时将签名信息添加到消息头，从而通过身份认证。

· AK(Access Key ID)：访问密钥ID。与私有访问密钥关联的唯一标识符；访问密钥ID和私有访问密钥一起使用，对请求进行加密签名。

· SK(Secret Access Key)：与访问密钥ID结合使用的密钥，对请求进行加密签名，可标识发送方，并防止请求被修改。

·使用AK/SK认证时，您可以基于签名算法使用AK/SK对请求进行签名，详细的签名方法请参见：[AK/SK签名认证操作指导](https://developer.huawei.com/consumer/cn/doc/development/SmartSpace-References/signature-authentication-guide-0000001455235350)。

注意：

1. AK/SK签名认证方式仅支持消息体大小以内。
2. AK/SK请联系华为工程师或对接接口人获取。
3. 请妥善保管AK/SK，属于绝密信息，不要泄漏。
4. AK/SK支持定期更新，确保安全。
