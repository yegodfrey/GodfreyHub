# 获取家庭信息

## 接口描述

getHomeInfo

查询当前家庭信息

## 适用平台

Android

## 请求参数

通用参数

|参数|类型|描述|
|:-----------|:-----|:----|
|functionName|String|接口名称|
|accessId|String|接口鉴权码|
|packageName|String|插件包名|

## 请求参数样例

```codeblock
{
	" functionName ": " getHomeInfo ",
	" accesssId ": "xxxx-xxx-xx-xxx-xxxx-xxx",
	" packageName ": "com.huawei.xxx"
}
```

## 响应参数

```codeblock
{
	"homeId": "xxx",
	"homeName": "xxx"
}
```

## 错误码

code为0：成功

code为-1：失败

## 接口限制

此接口需要在中控屏登录个人账号，方可使用
