# 修改场景

1. 描述：调用此接口修改指定场景，支持启用、禁用；修改特定场景的部分参数，比如执行时间、周期等。
2. 接口类型：REST
3. URI：

   |----|------------------------------------------|
   |请求方法|PUT|
   |URI|/openapi/asset/v1/space/{spaceId}/scenario|
   |传输协议|HTTPS|

4. 请求参数：

   |--|----------|----|-------|------|-----------------------------------------------------------------------|
   |序号|参数|是否必须|类型|长度|描述|
   |1|spaceId|必选|String|1-24|空间ID|
   |2|scenarioId|必选|String|24-256|场景ID|
   |3|status|可选|Integer|  |枚举： * inactive * active （只有自动场景支持设置激活去激活。即：场景查询结果中的type值为2/3的场景支持激活去激活）|
   |4|datas|可选|Map|  |Key-value键值对|

5. 响应参数： NA

6. 请求示例：

   ```screen
   PUT https://{Endpoint}/openapi/asset/v1/space/123134534576745/scenario
    
   {
    "scenarioId": "11223364756345345",
    "status": 0,
    "datas": {
        "repeatTimes": 10,
        "repeatInterval": 5
    }
   ```

   }
7. 响应示例： Status Code: 200 OK

8. 错误码

|-------|-------------|-------------------------------|-------------------------------|----------------|
|HTTP状态码|错误码|英文错误描述|中文错误描述|处理建议|
|400|space.001000|Bad Request.|请求的格式不正确，如json非法，mediaType不正确等。|请排查该请求的请求格式是否正确。|
|400|space.001001|Space name invalid.|空间命名不合法|请修改空间命名|
|400|space.001002|Space name repeat in a project.|同一个项目下，不允许重复命名|请修改空间命名|
|400|space.001003|Space count exceeds.|空间数量超过限额|不允许超过1000个|
|401|common.000001|Unauthorized.|非法请求|请检查AK/SK算法是否正确。|
|403|common.000002|Forbidden.|没有权限|请检查是否被授权|
|404|common.000003|Not Found.|资源不存在|请排查请求参数是否有误|
|500|common.000004|Internal server error.|内部错误|请稍等重试|
|503|Common.000005|Limit access.|限制访问|请联系华为工程师分析解决。|
|590|Common.000005|Limit access.|限制访问|请联系华为工程师分析解决。|
