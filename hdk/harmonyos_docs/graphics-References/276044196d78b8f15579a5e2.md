# glTexStorage2D

## 接口定义

```screen
void GL_APIENTRY glTexStorage2D(GLenum target, GLsizei levels, GLenum internalformat, GLsizei width, GLsizei height)
```

## 功能介绍

功能与glTexImage2D一致，为纹理对象设置存储和数据。与glTexImage2D不同的是，glTexStorage2D创建的是固定存储，使用该函数分配内存之后，不能再重新定义存储。

## 参数

|名称|类型|描述|
|:-------------|:----|:----------------------------------------------------------------------------------|
|target|无符号整型|指定目标纹理，这个值必须是GL_TEXTURE_2D。|
|levels|整型|执行细节级别。0是最基本的图像级别，n表示第N级贴图细化级别。|
|internalformat|无符号整型|指定纹理中的颜色组件。可选的值有： * GL_ALPHA * GL_RGB * GL_RGBA * GL_LUMINANCE * GL_LUMINANCE_ALPHA|
|width|整型|指定纹理图像的宽度，必须是2的n次方。纹理图片至少要支持64个材质元素的宽度。|
|height|整型|指定纹理图像的高度，必须是2的m次方。纹理图片至少要支持64个材质元素的高度。|

## 调用示例

```screen
glTexStorage2D(GL_TEXTURE_2D, 1, intFormat, w, h );
```
