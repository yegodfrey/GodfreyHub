# Overview

该包为图形引擎服务场景化接口SDK。

该包对应依赖sdk或full-sdk。  

#### Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------|:-------------|
|[ARView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-arview-0000001051923459)|提供一般AR场景的渲染能力。|
|[FaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-faceview-0000001052804698)|提供面部AR场景的渲染能力。|
|[SceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-sceneview-0000001050304388)|提供自适应场景的渲染能力。|
