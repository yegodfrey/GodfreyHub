# GetApiVersion

|**Method**|
|:--------------------------------------------------------------------------|
|int GetApiVersion(std::string &outStr) 获取当前API版本号，版本号为X.Y.Z格式的字符串，例如：0.9.1。|

**Parameters**

|**Name**|**Description**|
|:-------|:--------------|
|outStr|存储版本号的字符串引用。|

**Returns**

|**Type**|**Description**|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
|int|0表示获取成功；否则获取失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
