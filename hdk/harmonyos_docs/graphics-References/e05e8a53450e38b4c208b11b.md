# MouseInputEvent

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|class MouseInputEvent : public [InputEvent](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/inputevent-0000001050259190) 鼠标输入事件类，可以监听单击、右击和滑轮等事件，可以获取鼠标位置和滚轮变化值。 举例： * 按下鼠标左键：收到[MOUSE_ACTION_LEFT_BUTTON_DOWN](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/mouseaction-0000001178927412#ZH-CN_TOPIC_0000001178927412__p663619912419)事件。 * 按下鼠标右键：收到[MOUSE_ACTION_RIGHT_BUTTON_DOWN](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/mouseaction-0000001178927412#ZH-CN_TOPIC_0000001178927412__p151923316229)事件。 * 滑动鼠标滚轮：收到[MOUSE_ACTION_MOUSE_WHEEL](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/mouseaction-0000001178927412#ZH-CN_TOPIC_0000001178927412__p18606432122218)事件。|
