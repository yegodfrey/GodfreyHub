# glTexImage2D

## 接口定义

```screen
void GL_APIENTRY glTexImage2D(GLenum target, GLint level, GLint internalformat, GLsizei width, GLsizei height, GLint border, GLenum format, GLenum type, GLvoid const *pixels)
```

## 功能介绍

将指定纹理图像的一部分映射到纹理化为活动的每个图形基元上。当前片段着色器或顶点着色器使用内置纹理查找函数时，纹理处于活动状态。定义纹理图像时，调用glTexImage2D。在调用该接口之前，需要调用glBindTexture来指定要操作的纹理ID。该接口允许重新定义纹理对象。

## 参数

|名称|类型|描述|
|:-------------|:----|:------------------------------------------------------------------------------------------------------------------------|
|target|无符号整型|指定目标纹理，这个值必须是GL_TEXTURE_2D。|
|level|整型|执行细节级别。0是最基本的图像级别，n表示第N级贴图细化级别。|
|internalformat|整型|指定纹理中的颜色组件。可选的值有： * GL_ALPHA * GL_RGB * GL_RGBA * GL_LUMINANCE * GL_LUMINANCE_ALPHA|
|width|整型|指定纹理图像的宽度，必须是2的n次方。纹理图片至少要支持64个材质元素的宽度。|
|height|整型|指定纹理图像的高度，必须是2的m次方。纹理图片至少要支持64个材质元素的高度。|
|border|整型|指定边框的宽度。必须为0。|
|format|无符号整型|像素数据的颜色格式，不需要和internalformat取值必须相同。可选的值参考[internalformat](#ZH-CN_TOPIC_0000001050170287__p1645713417191)。|
|type|无符号整型|指定像素数据的数据类型。可以使用的值有： * GL_UNSIGNED_BYTE * GL_UNSIGNED_SHORT_5_6_5 * GL_UNSIGNED_SHORT_4_4_4_4 * GL_UNSIGNED_SHORT_5_5_5_1|
|pixels|指针|指定内存中指向图像数据的指针。|

## 调用示例

```screen
glTexImage2D(GL_TEXTURE_2D, 1, GL_RGBA, fbo_width, fbo_height, 0, GL_RGBA, GL_UNSIGNED_BYTE, NULL);
```
