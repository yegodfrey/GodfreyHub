# dispatch_autostat_disable

## 功能描述

当使能multithread-lib自动统计功能后，调用此接口可以关闭自动统计。

如无特殊需求，不必关闭自动统计。

## 函数原型

void dispatch_autostat_disable(void);

## 返回

|类型|描述|
|:---|:-|
|void|-|
