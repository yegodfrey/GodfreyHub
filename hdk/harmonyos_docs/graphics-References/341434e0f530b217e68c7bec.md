# GetThumbstickPos [For 6DoF]

获取当前控制器摇杆的触摸位置向量。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|pos|Vector2|将当前控制器的位置向量(x,y)写入pos。 摇杆在正中间时 (x, y) 为 (0.5, 0.5)，摇杆扳到最左为 (0, 0.5)，最右为 (1, 0.5)，最上为 (0.5, 0)，最下为 (0.5, 1)。可参考 [2.1.5.1.9 GetTouchpadTouchPos](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/controller_get_touchpad_touch_pos-0000001205684087) 。|

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
if (null == controller) {
    Debug.LogError("Controller is null");
} else {
    Vector2 thumbstickPos = new Vector2();
    int ret = controller.GetThumbstickPos(ref thumbstickPos);
    if (ret == 0) {
        Debug.Log("Get controller thumbstickPos success!");
    } else {
        Debug.Log("Get controller thumbstickPos failed!");
    }
}
```
