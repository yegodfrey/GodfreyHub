# HwArPlaneFindingMode

|Enum Info|
|:--------|
|平面搜索模式。|

#### Enum Value Summary

|Enum Name|
|:---------------------------------------------------------------------|
|HWAR_PLANE_FINDING_MODE_DISABLED 禁用平面检测，取值为0。|
|HWAR_PLANE_FINDING_MODE_HORIZONTAL 仅检测水平面，取值为1。|
|HWAR_PLANE_FINDING_MODE_VERTICAL 仅检测垂直平面，取值为2。|
|HWAR_PLANE_FINDING_MODE_HORIZONTAL_AND_VERTICAL 启用平面检测，包括水平和垂直平面，取值为3。|
