# FluidShakeInit

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[FluidShakeContext](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/fluidshakecontext-0000001118521584) *FluidShakeInit([Result](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/result-0000001165481331) *outRes, [ResultType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/resulttype-0000001118681480) flag, [Float3](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/float3-0000001118681478) startCoordinate, int particleNum, [Box](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/box-0000001165481329) boxType) 用于创建并返回[FluidShakeContext](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/fluidshakecontext-0000001118521584)的对象指针。|

**Parameters**

|Name|Description|
|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|outRes|返回数据结构体，包括GPU buffer ID 、CPU data array、粒子数量。|
|flag|输入返回结果类型。 * resultType：true时返回GPU bufferID，false时返回CPU data array。 * surfaceFlag：true时返回表面粒子，false时返回全部粒子。|
|startCoordinate|容器起始坐标。|
|particleNum|粒子数量，取值范围为[300, 512]。|
|boxType|* boxType：0表示长方体，1表示圆柱体。 * boxSize：3维数组。如果是长方体，表示长方体的长、宽、高；如果是圆柱体，boxSize[0]，表示圆柱体的直径，boxSize[1]，表示圆柱体的高，boxSize[2]，保留，暂未使用。取值范围为[0.1, 1.0]。 * filename：保留接口参数，暂未使用。|

**Returns**

|Type|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------|:-------------------|
|[FluidShakeContext](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/fluidshakecontext-0000001118521584) *|流体对象的指针。 nullptr：失败。|
