# TouchInputEvent

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|class TouchInputEvent : public [InputEvent](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/inputevent-0000001050259190) 触摸输入事件类，具有监控单指，多指操作的能力。 举例： * 按下手指1：收到[TOUCH_ACTION_DOWN](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/touchaction-0000001050268360#ZH-CN_TOPIC_0000001050268360__p12802030185414)事件。 * 保存手指1按下状态，再按下手指2：收到[TOUCH_ACTION_POINTER_DOWN](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/touchaction-0000001050268360#ZH-CN_TOPIC_0000001050268360__p12754185624910)事件。 * 抬起手指1，保持手指2按下：收到[TOUCH_ACTION_POINTER_UP](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/touchaction-0000001050268360#ZH-CN_TOPIC_0000001050268360__p1514118513509)事件。 * 两个手指全部抬起：收到[TOUCH_ACTION_UP](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/touchaction-0000001050268360#ZH-CN_TOPIC_0000001050268360__p2080012306547)事件。|
