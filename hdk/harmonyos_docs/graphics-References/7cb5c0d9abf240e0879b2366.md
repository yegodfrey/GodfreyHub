# StartVibration [For 6DoF]

使控制器开始震动。

## Parameter

|------------------|---------------------------------|
|**Parameter Name**|**Description**|
|amplitude|设置震动强度，0-1|
|durationTimeMs|设置震动总时长，波形1-8总时长固定|
|frequency|设置震动频率，0-1|
|waveform|设置震动波形，波形包括0-8，默认为0，仅默认波形可调节强度和频率|

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
if (null == controller) {
    Debug.LogError("Controller is null");
} else {
    int ret = controller.StartVibration(1.0f, 20, 1.0f, 0);
    if (ret == 0) {
        Debug.Log("Controller start vibration!");
    }
}
```
