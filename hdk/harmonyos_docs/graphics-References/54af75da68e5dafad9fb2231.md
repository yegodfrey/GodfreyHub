# ARPose

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARPose 位姿数据类，包含平移向量和旋转向量（四元组）。 1. 在AR Engine中，其用于描述物体从局部坐标系向世界坐标系的转换，局部坐标通过该类的对象转化成世界坐标系下的坐标。 2. AR Engine中的世界坐标系是右手坐标系（与OpenGL一致），上 -> y轴正方向，x和z轴在水平面上。该类的对象等价于OpenGL中的变换矩阵。|
