# SetScene

|**Method**|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int SetScene(const std::string &sceneDescription) 设置应用场景，当前支持的场景参见[表1](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/setscene-0000001055107774)，5.0.5版本中该接口只针对非游戏类应用生效。|

**Parameters**

|**Name**|**Description**|
|:---------------|:--------------------------------------------------------------------------------------------------------------------------------|
|sceneDescription|场景参数值，用户支持输入的场景参数值参见[表1](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/setscene-0000001055107774)。|

|场景分类|场景参数值（sceneDescription）|场景描述|场景帧率上限|
|:---|:--------------------------------|:---------|:----------|
|默认场景|"default"|默认|默认华为限帧策略|
|视频场景|"video_scene"|视频场景|5.0.5版本没有限制|
|视频场景|"video_full_scene"|全屏视频场景|5.0.5版本没有限制|
|视频场景|"video_full_scene_with_bullet"|全屏视频带弹幕场景|5.0.5版本没有限制|
|视频场景|"video_full_scene_without_bullet"|全屏视频不带弹幕场景|5.0.5版本没有限制|
|视频场景|"video_not_full_scene"|非全屏视频场景|5.0.5版本没有限制|
|视频场景|"video_freeform_window"|悬浮窗场景|5.0.5版本没有限制|
|游戏场景|"game"|游戏场景|5.0.5版本没有限制|
|游戏场景|"game_fight"|战斗场景|5.0.5版本没有限制|
|游戏场景|"game_setting"|设置场景|5.0.5版本没有限制|
[**表1**场景定义表]

**Returns**

|**Type**|**Description**|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
|int|0表示设置成功；否则设置失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
