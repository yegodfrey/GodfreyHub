# ARHand.ARHandSkeletonType

|Enum Info|
|:--------------------------------------|
|public enum ARHandSkeletonType 手部关节点定义。|

## Enum Value Summary

|Enum Value and Description|
|:---------------------------------------|
|HANDSKELETON_ROOT(0) 手骨根节点，即手腕。|
|HANDSKELETON_PINKY_1(1) 小手指关节1。|
|HANDSKELETON_PINKY_2(2) 小手指关节2。|
|HANDSKELETON_PINKY_3(3) 小手指关节3。|
|HANDSKELETON_PINKY_4(4) 小手指指尖。|
|HANDSKELETON_RING_1(5) 无名指关节1。|
|HANDSKELETON_RING_2(6) 无名指关节2。|
|HANDSKELETON_RING_3(7) 无名指关节3。|
|HANDSKELETON_RING_4(8) 无名指指尖。|
|HANDSKELETON_MIDDLE_1(9) 中指关节1。|
|HANDSKELETON_MIDDLE_2(10) 中指关节2。|
|HANDSKELETON_MIDDLE_3(11) 中指关节3。|
|HANDSKELETON_MIDDLE_4(12) 中指指尖。|
|HANDSKELETON_INDEX_1(13) 食指关节1。|
|HANDSKELETON_INDEX_2(14) 食指关节2。|
|HANDSKELETON_INDEX_3(15) 食指关节3。|
|HANDSKELETON_INDEX_4(16) 食指指尖。|
|HANDSKELETON_THUMB_1(17) 大拇指关节1。|
|HANDSKELETON_THUMB_2(18) 大拇指关节2。|
|HANDSKELETON_THUMB_3(19) 大拇指关节3。|
|HANDSKELETON_THUMB_4(20) 大拇指指尖。|
|HANDSKELETON_LENGTH(21) 非关节点，表示定义的关节点个数。|
