# GetHelmetHeight [For 6DoF] (Not Supported)

获取地面检测算法得到当前头盔与地面之间的相对高度。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-----------------|:----------------------|
|height|float|将当前头盔与地面之间的相对高度写入height|
