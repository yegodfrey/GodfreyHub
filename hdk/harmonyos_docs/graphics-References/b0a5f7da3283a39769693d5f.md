# SamplerAddress

|Enum Info|
|:--------|
|纹理寻址模式枚举。|

#### Enum Value Summary

|Enum Value and Description|
|:---------------------------------------------------------------|
|SAMPLER_ADDRESS_WRAP 重复寻址模式，在每个整数连接点处重复上一个整数的纹理。|
|SAMPLER_ADDRESS_MIRROR 镜像纹理寻址模式，每个整数纹理坐标连接处自动复制并翻转纹理，且为两两成对翻转。|
|SAMPLER_ADDRESS_CLAMP 夹取纹理模式，超过1.0的纹理都被裁剪到1.0，小于0.0的纹理被裁剪到0.0。|
|SAMPLER_ADDRESS_BORDER 边框颜色寻址模式，在纹理边界\[0.0, 1.0\]之外采样将返回边框颜色的纹素。|
|SAMPLER_ADDRESS_MIRROR_ONCE 纹理坐标镜像一次模式，取纹理坐标的绝对值，然后夹取到最大值1.0。|
