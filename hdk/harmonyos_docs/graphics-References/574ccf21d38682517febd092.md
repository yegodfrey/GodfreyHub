# SensorData

## SensorData

头盔传感器参数，指示头盔的陀螺仪数据、加速度计数据、磁力计数据、预测时间的结构体。

|**Attribute**|||
|**Member**|**Type**|**Description**|
|:----------|:-------|:--------------|
|gypo|Vector3|指示头盔的陀螺仪数据|
|accel|Vector3|指示头盔的加速度计数据|
|mag|Vector3|指示头盔的磁力计数据|
|predictTime|ulong|指示头盔的预测时间（单位us）|
