# Init

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int Init(JNIEnv \*env) 初始化Socket通道。返回0，则初始化成功；否则初始化失败，调用其他API都会失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|

Parameters  

|Name|Description|
|:---|:---------------|
|env|当前运行的Java环境对象指针。|

Returns  

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------|
|int|0表示初始化成功；否则初始化失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
