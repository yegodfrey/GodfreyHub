# RegisterSystemEventCallback

|**Method**|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|using SystemEventCb = std::function<void (int)> int RegisterSystemEventCallback(SystemEventCb cb) 注册系统事件回调函数，回调参数类型为int，即SystemEvent定义的枚举值。当性能水平、帧率变化时，调用注册的回调函数。一个进程中只能注册一个回调。|

**Parameters**

|**Name**|**Description**|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|cb|回调函数。回调函数传入参数是一个int值，即[SystemEvent](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)定义的枚举值。|

**Returns**

|Type|**Description**|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------|
|int|0表示注册成功；否则注册失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
