原子化接口资源加载接口统一使用URI类来代表资源路径，目前支持的资源路径协议为Assets及Android文件系统：

* 从Assets读取资源：

  ```
  Uri.parse("xxx/xxx");
  ```

* 从Android文件系统读取资源：

  ```
  Uri.parse("file:///xx/xx/xx");
  ```

若资源URI中包含中文字符及特殊字符，请使用URI编码功能提前进行编码。

例如：如加载资源"/sdcard/你好世界.gltf"，需要写成：

```
Uri.parse(Uri.encode("file:///sdcard/你好世界.gltf", ":/"));
```
