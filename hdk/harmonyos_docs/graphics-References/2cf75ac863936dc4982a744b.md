#### getCloudImageId

|Method|
|:-----------------------------------------------------------------------------------------------------------------|
|public String getCloudImageId() 获取云图像ID，此ID为图像在云图像库中的标识。该ID为开发者在云端创建的图像库中添加图像的时候自动生成。AR Engine Server 3.13及以后版本可用。|

Returns  

|Type|Description|
|:-----|:---------------|
|String|当前识别的图像对应的云图像ID。|

#### getCloudImageMetadata

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public String getCloudImageMetadata() 获取云图像的Metadata信息。图像的Metadata数据是在2D云端设置的图像元数据，可以是一个附件（返回附件的URL地址），也可以是图像对应的名称，亦或是图像对应的介绍信息。AR Engine Server 3.13及以后版本可用。|

Returns  

|Type|Description|
|:-----|:-----------------------|
|String|当前识别的图像对应的云图像Metadata信息。|
