# CharacterData

|Struct Info|
|:---------------------------------------------|
|struct CharacterData 存储用于PC端角色模型适配的游戏角色捏脸模型数据。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:--------------------------------------------------------------------------------------------------------------------------|
|std::string|posPath 游戏角色捏脸模型保持其他捏脸参数不变、每次仅将一个捏脸参数正向调整到最大值后，网格模型导出为obj文件，所有参数都导出obj文件后存放的路径。 说明： 每个参数的正负向.obj文件保持文件名一致。|
|std::string|negPath 游戏角色捏脸模型保持其他捏脸参数不变、每次仅将一个捏脸参数负向调整到最小值后，网格模型导出为obj文件，所有参数都导出obj文件后存放的路径。如无负向调整功能，该文件夹为空。 说明： 每个参数的正负向.obj文件保持文件名一致。|
|std::string|neutralPath 所有捏脸参数为默认值的情况下，导出中性人脸三维模型obj文件的路径。 中性模型与正负向网格模型拓扑一致，即具有同样的顶点数、三角面片连接关系；坐标原点、朝向、尺度完全一致，脸正面为Z轴正向，头顶为Y轴正向，左耳为X轴正向。|
|std::string|texturePath 角色模型UV纹理展开图路径。|
|std::string|markIdPath 与Android端捏脸参数计算输入的人脸特征点位置对应的中性人脸三维模型顶点索引文件路径，文件类型为txt文本文件，索引文件中第一行为特征点个数，其后每行为一个顶点索引值。|
|std::string|contourIdPath 脸部圆形轮廓点对应的中性人脸三维模型顶点索引文件路径，文件类型为txt文本文件，索引文件中第一行为轮廓点个数，其后每行为一个顶点索引值。轮廓点个数不少于20。|
