#### Public Methods

#### HwArCamera_getDisplayOrientedPose

|Function|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HwArCamera_getDisplayOrientedPose(const [HwArSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_session-0000001060385725) \*session, const [HwArCamera](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_camera-0000001060131795) \*camera, [HwArPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_pose-0000001060013677) \*outPose) 设置outPose为虚拟相机（面向显示）在世界空间中的位姿，用以将AR内容渲染到最新帧中。该位姿是OpenGL相机的位姿，其中x轴正方向为右，y轴正方向为上，z轴负方向为相机的观察方向。相机位置即物理相机位置，而相机x轴与y轴指向受屏幕方向（考虑显示旋转）的影响。 注意： 该位姿信息应该在[HwArCamera_getTrackingState](#section29011236183718)返回Tracking状态的时候才能使用。|

Parameters  

|Name|Description|
|:------|:------------------------|
|session|与AR Engine服务交互的Session对象。|
|camera|Session对应的相机。|
|outPose|虚拟相机在世界空间中的位姿。|

|Function|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
