# GetGripData [For 6DoF]

获取当前控制器的侧握键数据。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-----------------|:--------------------------------------|
|data|float|将当前控制器的侧握键数据(取值为[0.0f, 1.0f]的浮点数)写入data|

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
if (null == controller) {
    Debug.LogError("Controller is null");
} else {
    float gripData = 0.0f;
    int ret = controller.GetGripData(ref gripData);
    if (ret == 0) {
        Debug.Log("Get controller grip data success!");
    } else {
        Debug.Log("Get controller grip data failed!");
    }
}
```
