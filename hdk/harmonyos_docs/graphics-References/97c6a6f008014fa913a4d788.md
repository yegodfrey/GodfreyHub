# HwArBody

|Module Info|
|:-----------------------------------------------------------------------------------------------------------------|
|提供AR Engine人体骨骼追踪能力。包括单人和多人的身体关节点和骨骼识别能力，可以输出四肢端点、身体姿态、人体骨骼等人体高级特征。支持2D骨骼（屏幕坐标系）和3D骨骼（与SLAM结合的空间坐标系）的输出，目前仅支持后置相机。|
