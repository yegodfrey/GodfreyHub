# HwArStatus

|Enum Info|
|:---------------------|
|状态返回值类型，用于表示一个方法的调用状态。|

#### Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------------------|
|HWAR_SUCCESS 成功状态，取值为0。|
|HWAR_ERROR_INVALID_ARGUMENT 错误：无效参数状态，取值为-1。|
|HWAR_ERROR_FATAL 错误：失败状态，取值为-2。|
|HWAR_ERROR_SESSION_PAUSED 错误：会话已暂停状态，取值为-3。|
|HWAR_ERROR_SESSION_NOT_PAUSED 错误：会话未暂停状态，取值为-4。|
|HWAR_ERROR_NOT_TRACKING 错误：未跟踪状态，取值为-5。|
|HWAR_ERROR_TEXTURE_NOT_SET 错误：未设置错误纹理状态，取值为-6。|
|HWAR_ERROR_MISSING_GL_CONTEXT 错误：缺少GL上下文状态，取值为-7。|
|HWAR_ERROR_UNSUPPORTED_CONFIGURATION 错误：不支持的配置状态，取值为-8。|
|HWAR_ERROR_CAMERA_PERMISSION_NOT_GRANTED 错误：相机权限未授予状态，取值为-9。|
|HWAR_ERROR_DEADLINE_EXCEEDED 错误：超过截止时间状态，取值为-10。|
|HWAR_ERROR_RESOURCE_EXHAUSTED 错误：资源耗尽状态，取值为-11。|
|HWAR_ERROR_NOT_YET_AVAILABLE 错误：尚不可用状态，取值为-12。|
|HWAR_ERROR_CAMERA_NOT_AVAILABLE 错误：相机不可用状态，取值为-13。|
|HWAR_UNAVAILABLE_ARSERVICE_NOT_INSTALLED 不可用：AR服务未安装，取值为-100。|
|HWAR_UNAVAILABLE_DEVICE_NOT_COMPATIBLE 不可用：不兼容状态，取值为-101。|
|HWAR_UNAVAILABLE_APK_TOO_OLD 不可用：APK过旧，取值为-102。|
|HWAR_UNAVAILABLE_SDK_TOO_OLD 不可用：SDK过旧，取值为-103。|
|HWAR_UNAVAILABLE_USER_DECLINED_INSTALLATION 不可用：用户拒绝安装，取值为-104。|
|HWAR_UNAVAILABLE_EMUI_NOT_COMPATIBLE 不可用：EMUI不兼容，取值为-105。|
|HWAR_UNAVAILABLE_CONNECT_SERVER_TIME_OUT 不可用：连接服务器超时，取值为-106。|
