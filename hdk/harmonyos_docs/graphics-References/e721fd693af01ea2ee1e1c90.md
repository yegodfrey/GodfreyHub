# RegisterPerformanceTracer

|**Method**|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|using PerformanceTracerCb = std::function<void (*std::vector<uint32_t>&)*> int RegisterPerformanceTracer(int sampleRate, PerformanceTracerCb cb) 注册系统性能追踪回调函数，参数为vector数据，按照指定周期返回CPU、GPU负载情况。|

**Parameters**

|**Name**|**Description**|
|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
|sampleRate|采样间隔，单位ms。 在游戏场景下，每帧采样，以sampleRate为间隔上报，上报的多帧数据会被连成一个vector数据。其中，时间戳的获取方式是：chrono::system_clock::now().time_since_epoch().count()。|
|cb|回调函数。回调传入参数是一个int类型vector数据，每4个元素是一组数据，代表一帧的信息。每组数据的4个元素分别：CpuLoad、GpuLoad、TimeStamp低32bit、TimeStamp高32bit。|

**Returns**

|Type|**Description**|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------|
|int|0表示注册成功；否则注册失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
