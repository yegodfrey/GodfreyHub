# IArFaceView.SurfaceType

|Enum Info|
|:-----------------------------------------------------------------|
|public enum SurfaceType surface的类型，用于人脸组件场景客户端打开相机的情况下，获取指定类型的图片流。|

## Enum Value Summary

|Enum Value and Description|
|:-----------------------------------------------|
|PREVIEW 1440*1080预览数据。|
|VGA 图片规格为640*480，用于算法使用。|
|DEPTH 深度流，图片规格为40*30，用于算法使用。|
|METADATA 摄像机参数，此通道暂不可用。待元数据接入后，AR所有场景都支持外置摄像头打开。|
