# PluginManager

|Class Info|
|:---------------------------------------------------------------------------------------------------------------|
|class PluginManager : public Singleton\<PluginManager\> 插件管理器，负责执行各种插件的管理，可以对多种插件进行注册注销、信息管理、路径存放管理等操作，以单例的方式使用。|
