# ControllerEvent

## ControllerEvent

控制器连接事件，通过注册控制器事件句柄来监听控制器状态变化事件。

|**Attribute**||
|:--------------------------|---------|
|ControllerEventConnected|控制器已连接事件|
|ControllerEventDisconnected|控制器断开连接事件|
|ControllerEventLowPower|低电量告警事件|
|ControllerEventReset|手柄位姿重置事件|
