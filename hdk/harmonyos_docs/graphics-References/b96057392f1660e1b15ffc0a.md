# ARFaceGeometry

|Class Info|
|:----------------------------------------------|
|public class ARFaceGeometry 用于描述人脸拓扑结构，即人脸Mesh。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|FloatBuffer|[getTextureCoordinates](#section147322563577)() 获取人脸Mesh纹理坐标点数组，在渲染时，与[getVertices](#section167571834185819)()返回的顶点数据配合使用。|
|int|[getTriangleCount](#section89331821175819)() 获取人脸Mesh三角面个数。|
|IntBuffer|[getTriangleIndices](#section20957194545819)() 获取人脸Mesh三角面下标数组，可在渲染时使用。|
|IntBuffer|[getTriangleLabels](#section11389756115816)() 获取人脸Mesh三角面标签，取值：人脸Mesh的所有三角形对应的label值，用于区分三角形是属于哪个关键部位，对应枚举：[ARFaceGeometry.TriangleLabel](https://developer.huawei.com/consumer/cn/doc/graphics-References/triangle_label-0000001050164141)， -1---不是脸部部位、0---脸部非关键部位、1---下嘴唇、2---上嘴唇、3---左眼睛、4---右眼睛、5---左眉毛、6---右眉毛、7---眉心、8---鼻子。|
|FloatBuffer|[getVertices](#section167571834185819)() 获取人脸Mesh顶点，数据格式为\[x0,y0,z0,x1,y1,z1,...\]，返回的顶点在人脸中心的局部坐标系下，需经过人脸pose转换到其他坐标系。|
|void|[release](#section33736195917)() 在使用[ARFaceGeometry](https://developer.huawei.com/consumer/cn/doc/graphics-References/face_geometry-0000001050121445)结束后调用，否则会导致内存泄露。|
