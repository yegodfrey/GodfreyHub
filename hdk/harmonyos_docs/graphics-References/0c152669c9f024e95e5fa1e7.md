# CullMode

|Enum Info|
|:--------|
|渲染剔除类型枚举。|

#### Enum Value Summary

|Enum Value and Description|
|:-----------------------------------------|
|CULL_MODE_NONE 不剔除。|
|CULL_MODE_FRONT 剔除朝向相机的多边形。|
|CULL_MODE_BACK 剔除背向相机的多边形。|
|CULL_MODE_FRONT_AND_BACK 剔除朝向相机的和背向相机的多边形。|
