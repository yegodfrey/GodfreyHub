# Mesh

|Struct Info|
|:--------------------------------------------------------------|
|Mesh 模型的网格，包含顶点信息缓存、法线信息缓存、顶点索引信息缓存和所有节点数组信息。暂时只支持GPU buffer类型。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:--------------------------------------------------------------------------------------------------------------------|:--------------------|
|[Buffer](https://developer.huawei.com/consumer/cn/doc/graphics-References/rt-core-buffer-0000001133940651)|vertex 保存顶点信息的缓存。|
|[Buffer](https://developer.huawei.com/consumer/cn/doc/graphics-References/rt-core-buffer-0000001133940651)|normal 保存法线信息的缓存。|
|[Buffer](https://developer.huawei.com/consumer/cn/doc/graphics-References/rt-core-buffer-0000001133940651)|index 保存顶点索引信息的缓存。|
|std::vector\<[Node](https://developer.huawei.com/consumer/cn/doc/graphics-References/rt-core-node-0000001133823481)\>|nodes 网格所包含的节点信息数组。|
