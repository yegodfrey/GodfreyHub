# IFeatureEventListener

|Interface Info|
|:------------------------------------------------------------------------------------------|
|public interface IFeatureEventListener 特性事件监听，用于XRKit服务端上报运行时事件，包括模型加载成功、模型加载失败、模型与实景贴合等事件。|

|Qualifier and Type|Method Name and Description|

|Method|
