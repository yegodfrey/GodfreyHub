# HcCreate

|Method|
|:--------------------------------------------------------------------------------------------|
|struct HiCulling \*HcCreate(bool enableMutiThread) 创建一个用于执行软件遮挡剔除的对象，同时把depth buffer初始化为默认大小。|

Parameters  

|Name|Description|
|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|enableMutiThread|是否启用多线程。如果启用，[HcRasterizeOccluder](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcrasterizeoccluder-0000001055295358)和[HcTestOccludeesAABB](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hctestoccludeesaabb-0000001055455338)将会在多个线程并行执行。|

Returns  

|Type|Description|
|:--------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------|
|struct [HiCulling](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hiculling-0000001055695365)|返回[HiCulling](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hiculling-0000001055695365)类型对象，用于执行遮挡剔除的对象。|
