# HwArHand

|Module Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|用于人体手部跟踪时返回跟踪结果，包含手部骨骼数据和手势识别结果。 手势特性对硬件设备的依赖情况请参见[AR Engine特性软硬件依赖表](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/features-0000001060501339) 。|
