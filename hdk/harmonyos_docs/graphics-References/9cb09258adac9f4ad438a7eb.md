# ARPlane

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARPlane extends ARTrackableBase 保存AR Engine识别的真实世界中的平面信息，派生自[ARTrackableBase](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable_base-0000001050119508)。两个或者多个平面法向量朝向一致，位置靠近时会自动合并到一个父平面中，合并之后每个子平面的[getSubsumedBy](#section620417127213)()将返回父平面。被合并的子平面将继续被跟踪和返回。|
