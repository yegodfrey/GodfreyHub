# Overview

## Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------|
|[CharacterAdapter](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/characteradapter-0000001180225147)|PC端角色模型适配，将用户提供的游戏角色模型转换为可进行智能捏脸计算的模型资源文件。|
|[GenerateFaceParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/generatefaceparas-0000001180345085)|生成照片捏脸参数。|
|[ModifyFaceParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/modifyfaceparas-0000001141570528)|根据设置的美观度，生成调整后的捏脸参数。|
