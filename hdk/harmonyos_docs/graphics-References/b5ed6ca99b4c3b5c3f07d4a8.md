# StopVibration [For 6DoF]

使控制器停止震动。

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
if (null == controller) {
    Debug.LogError("Controller is null");
} else {
    int ret = controller.StopVibration();
    if (ret == 0) {
        Debug.Log("Controller stop vibration!");
    }
}
```
