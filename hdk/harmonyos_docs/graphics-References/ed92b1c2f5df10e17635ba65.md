# AddKeyThreads

|**Method**|
|:----------------------------------------------------------------------------------------------------------|
|int AddKeyThreads(std::vector<int32_t> &tids) 添加关键线程，系统会更及时地调度关键线程。最多可以支持三个关键线程，但只能给前台进程添加关键线程，且线程必须都在本进程内。|

**Parameters**

|**Name**|**Description**|
|:-------|:--------------|
|tids|待添加的线程号。|

**Returns**

|**Type**|**Description**|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
|int|0表示设置成功；否则设置失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
