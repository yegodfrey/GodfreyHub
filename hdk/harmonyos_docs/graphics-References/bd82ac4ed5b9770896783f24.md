# 概述

multithread-lib提供了一套C语言多线程并行编程的API，用于在多核系统上支持程序的并发执行。

multithread-lib以队列的方式来管理任务的并行逻辑，队列在multithread-lib框架内部维护。开发者需要创建或声明一个队列，并提交任务到队列上。通过任务提交方式和目标队列属性的组合，可以全面地实现各种多任务并发的逻辑。

multithread-lib基于[swift-corelibs-libdispatch](https://github.com/apple/swift-corelibs-libdispatch)（又称GCD，Grand Central Dispatch）开发，并针对Android平台进行了适配和调整。
> 说明
>
> 如果下文无明确说明，各接口的意义和使用约束都与[GCD](https://apple.github.io/swift-corelibs-libdispatch/tutorial/)相同。

接口引用：#include <dispatch/dispatch.h>。

关于如何配置环境，快速开始使用，请参见[开发指南](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/introduction-0000001077053686)。
