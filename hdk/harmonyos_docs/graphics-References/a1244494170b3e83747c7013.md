# HwArLightShadowType

|Enum Info|
|:----------------------------------------------|
|阴影边缘形状类型(边缘锯齿或柔和)，底层有天气判别的算法，会根据不同天气给出不同阴影强度类型。|

## Enum Value Summary

|Enum Name|
|:---------------------------------------------------------------------|
|HWAR_LIGHT_SHADOW_TYPE_NONE 阴影类型为None，无阴影，取值为0。|
|HWAR_LIGHT_SHADOW_TYPE_HARD 在阴影强度比较高情况下使用，像晴天场景下，阴影是很明显的，取值为1。|
|HWAR_LIGHT_SHADOW_TYPE_SOFT 在阴影强度比较低的情况下使用，像在阴天/室内/夜晚场景中，比较柔和的阴影，取值为2。|
