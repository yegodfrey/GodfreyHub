# Box

|Struct Info|
|:--------------------------------|
|struct Box 流体的容器参数，包括容器的类型和容器的尺寸。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-------------------------------------------|
|int|boxType 流体容器类型。 * 0：长方体。 * 1：圆柱体。|
|float[3]|boxSize 流体容器尺寸。 长方体包括长、宽、高。取值范围为[0.14, 0.2]。|
|string|filename 流体容器尺寸详细参数。接口保留，目前暂未使用。|
