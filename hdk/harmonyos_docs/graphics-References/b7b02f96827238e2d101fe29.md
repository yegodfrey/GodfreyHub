# ARTarget.TargetShapeType

|Enum Info|
|:--------------------------------------------------------------------|
|public enum TargetShapeType 识别到的物体形状。 该枚举在AR Engine Server 3.13及以后可用。|

#### Enum Value Summary

|Enum Value and Description|
|:-------------------------------------|
|TARGET_SHAPE_INVALID(-1) 当前识别目标形状无效。|
|TARGET_SHAPE_OTHER(0) 当前识别目标形状有效为其他形状。|
|TARGET_SHAPE_CUBE(1) 当前识别目标形状为立方体。|
|TARGET_SHAPE_CIRCLE(2) 当前识别目标形状为圆形。|
|TARGET_SHAPE_RECT(3) 当前识别目标形状为矩形。|
