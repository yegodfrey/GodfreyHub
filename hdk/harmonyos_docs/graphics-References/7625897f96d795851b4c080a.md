# GetControllerByIndex

获取序列号为index的控制器对象。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-----------------|:------------------|
|index|int|控制器的序列号：左手柄为2，右手柄为1|

## Return Values

调用函数成功返回序列号为index的控制器对象，失败返回null。

## Examples

```screen
private IController controller; //This variable related to the controller is used in the following codes.

void Start() {
    if (null == controllerHandle) {
        Debug.LogError("controllerHandle is null");
    } else {
        int[] indices = controllerHandle.GetValidIndices();
        //Obtain the controller object of the controller input event.
        controller = controllerHandle.GetControllerByIndex(1);
    }
    if (null == controller) {
        Debug.LogError("Controller is null");
    }
}
```
