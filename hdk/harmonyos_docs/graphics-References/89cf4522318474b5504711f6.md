# ARImage

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARImage extends ImageAdapter 实现Android里面的Image类，用于描述[ARFrame](https://developer.huawei.com/consumer/cn/doc/graphics-References/frame-0000001050121447)获取到的预览图等Image信息，通过此类可以获取图片格式、宽高等信息。|

## Public Constructor Summary

|Constructor Name|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[ARImage](#section166520151573)(long nativeHandle) 通过传入的[ARFrame](https://developer.huawei.com/consumer/cn/doc/graphics-References/frame-0000001050121447)数据流创建[ARImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/image-0000001050126047)对象，在使用时应直接使用ARFrame.acquireXXXImage()获取对应帧的[ARImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/image-0000001050126047)对象。|
