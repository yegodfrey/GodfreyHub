# RayTracingShaderModuleCreateInfo

|Struct Info|
|:----------------------------------------------------|
|RayTracingShaderModuleCreateInfo 开发者创建的用于生成光追着色模块的信息。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
|const char \*|pName 着色器名称，默认值nullptr。|
|const char \*|pSource 着色器代码，默认值nullptr。|
|[ShaderStage](https://developer.huawei.com/consumer/cn/doc/graphics-References/rt-core-shaderstage-0000001151206230)|stage 指定要编译的着色器代码位于哪个阶段，默认值ShaderStage::SHADER_STAGE_ALL 通常指定为SHADER_STAGE_FRAGMENT_BIT或SHADER_STAGE_COMPUTE_BIT（即片段着色阶段/计算阶段）|
|[TraceRayHitFormat](https://developer.huawei.com/consumer/cn/doc/graphics-References/rt-core-tracerayhitformat-0000001133823485)|hitFormat 指定交点格式|
|const char \*\*|ppShaderIncludes 着色器头文件名称，默认值nullptr。|
|uint32_t|shaderIncludeCnt 着色器头文件个数，默认值0。|
|const char \*\*|ppShaderIncludeSources 着色器头文件代码，默认值nullptr。|
