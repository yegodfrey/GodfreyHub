## Public Methods

### HwArAugmentedImageDatabase_addImage

|Function|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HwArAugmentedImageDatabase_addImage(const [HwArSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_session-0000001060385725) *session, [HwArAugmentedImageDatabase](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_augmentedimagedatabase-0000001060493638) *augmentedImageDatabase, const char *imageName, const uint8_t *imageGrayscalePixels, int32_t imageWidthInPixels, int32_t imageHeightInPixels, int32_t imageStrideInPixels, int32_t *outIndex) 添加命名为imageName（非空）的单个未知物理尺寸的Bitmap图像到图像数据库中，返回图像在图像数据库中的索引值（大于等于0）。如果图像的物理尺寸已知，可以使用[HwArAugmentedImageDatabase_addImageWithPhysicalSize](#section179951350331)来添加图像，以减少图像检测的时间。 通过该接口增加的图像（物理尺寸未知），AREngine会在该图像可见并处于Tracking状态时，动态估算图像的尺寸和位姿。这个动态估算过程要求用户移动设备来从不同的视角观察物理图像，以更好的估算图像的尺寸和位姿。 该函数执行的操作属于耗时操作，建议运行在后台线程中来执行。 > 说明 > 目前只支持Bitmap图的跨度值与Bitmap图的宽度值相同的情况。|

**Parameters**

|Name|Description|
|:---------------------|:------------------------|
|augmentedImageDatabase|需要添加图像的图像库。|
|imageGrayscalePixels|Bitmap图对应的灰度像素数组。|
|imageHeightInPixels|Bitmap图对应的高度值。|
|imageName|图像名称。|
|imageStrideInPixels|Bitmap图对应的跨度值，可能大于图像宽度。|
|imageWidthInPixels|Bitmap图对应的宽度值。|
|outIndex|图像在图像数据库中以0为起始的索引值。|
|session|与AR Engine服务交互的Session对象。|

**Returns**

|Type|Description|
|:----------------------------------------------------------------------------------------------------------------|:-----------------|
|[HwArStatus](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_enum_arstatus-0000001060493644)|状态返回值类型，表示方法的调用状态。|

### HwArAugmentedImageDatabase_addImageWithPhysicalSize

|Function|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HwArAugmentedImageDatabase_addImageWithPhysicalSize(const [HwArSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_session-0000001060385725) *session, [HwArAugmentedImageDatabase](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_augmentedimagedatabase-0000001060493638) *augmentedImageDatabase, const char *imageName, const uint8_t *imageGrayscalePixels, int32_t imageWidthInPixels, int32_t imageHeightInPixels, int32_t imageStrideInPixels, float imageWidthInMeters, int32_t *outIndex) 添加命名为imageName的单个Bitmap图像到图像数据库中，并指定了图像的物理宽度（以米为单位）。返回图像在图像数据库中以0为起始的索引值。如果图像的物理尺寸未知，请使用[HwArAugmentedImageDatabase_addImage](#section1435415812424)接口，但会增加识别图像的时间。 只要检测到通过该接口添加的物理图像，AR Engine便能立即估算物理图像的位姿，而不需要用户移动设备来从不同的视角观察物理图像。当从不同角度观察物理图像时，AR Engine会优化估算的尺寸和位姿。 该函数执行的操作属于耗时操作，建议运行在后台线程中来执行。 > 注意 > 目前只支持Bitmap图的跨度值与Bitmap图的宽度值相同的情况。|

|imageName|图像名称。|
|imageStrideInPixels|Bitmap图对应的跨度值，可能大于图像宽度。|
|imageWidthInMeters|指定Bitmap图像的物理宽度（单位：米）。|
|imageWidthInPixels|Bitmap图对应的宽度值。|
|outIndex|图像在图像数据库中以0为起始的索引值。|
