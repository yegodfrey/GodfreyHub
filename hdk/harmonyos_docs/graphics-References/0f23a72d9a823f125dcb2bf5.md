# StencilFaceFlag

|Enum Info|
|:--------|
|定义模板状态枚举。|

## Enum Value Summary

|Enum Value and Description|
|:------------------------------------------------|
|STENCIL_FACE_FRONT = 0x00000001 只更新前面模板状态。|
|STENCIL_FACE_BACK = 0x00000002 只更新后面模板状态。|
|STENCIL_FRONT_AND_BACK = 0x00000003 更新前面和后面的模板状态。|
