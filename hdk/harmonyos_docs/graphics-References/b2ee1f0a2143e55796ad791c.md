# JoystickInfo

|Struct Info|
|:-----------------------------|
|struct JoystickInfo 存储摇杆相关的数据。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|float|horizontalAxis 摇杆水平方向位移量。|
|float|verticalAxis 摇杆垂直方向位移量。|
|bool[4]|buttons bool数组类型，该数组存储游戏手柄XYAB四个按键触发的状态，具体类型请参见[JoystickButton](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/joystickbutton-0000001156813831)。 * true：按键按下。 * false：按键未按。|
