# DirLightParas

|Struct Info|
|:-------------------------------|
|struct DirLightParas 平行光及阴影相关参数。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:--------------------------------------------------------|
|float[3]|dir 平行光方向。|
|float[3]|color 平行光颜色RGB值。|
|float|intensity 平行光强度。|
|int|shadowFlag 控制是否开启体积阴影。取值：0（关闭）或1（开启）。|
|float[16]|shadowMatrix 相机坐标下的投影矩阵，按照行优先存储。|
|void*|shadowMap 指向阴影纹理的指针。|
|int|shadowMapResolution 阴影纹理尺寸，值越大阴影效果越好，耗时也相应增加。建议使用256或512。|
