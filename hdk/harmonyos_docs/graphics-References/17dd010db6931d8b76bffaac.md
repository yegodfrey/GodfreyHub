# dispatch_get_global_queue

## 功能描述

根据参数指定的QoS class返回系统默认创建的全局队列。

## 函数原型

```screen
dispatch_queue_global_t dispatch_get_global_queue(long identifier, unsigned long flags);
```

## 参数

|名称|类型|描述|
|:---------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|identifier|long|指定queue的QoS class即优先级。 可以使用的数值为：QOS_CLASS_USER_INTERACTIVE， QOS_CLASS_USER_INITIATED，QOS_CLASS_DEFAULT， QOS_CLASS_UTILITY，QOS_CLASS_BACKGROUND。 由于当前版本中还没有实现QoS class的区分，因此以上数值暂不需要考虑其意义，一般情况下建议使用QOS_CLASS_DEFAULT传入。|
|flags|unsigned long|总是传入0。这个参数是为未来预留的字段，目前没有使用。|

## 返回

|类型|描述|
|:----------------------|:-------|
|dispatch_queue_global_t|指定的全局队列。|
