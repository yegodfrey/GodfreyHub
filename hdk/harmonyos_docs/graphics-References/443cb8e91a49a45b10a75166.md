# m_CamCtrObj

## Transform m_CamCtrObj

相机变换组件(Camera Transform Component)，用于获取HUAWEI VR相机位置、旋转、缩放等信息。

## Examples

```screen
HVRLayoutCore.m_CamCtrObj.transform.position; //This parameter is used to obtain camera position information. 
HVRLayoutCore.m_CamCtrObj.transform.rotation; //This parameter is used to obtain camera rotation information. 
```
