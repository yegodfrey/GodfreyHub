# HVREventListener

提供委托变量，用来传递开发者想要监听的射线指向的UI输入事件（包含：点击、按下、抬起、进入、退出事件）。

## Public Static Delegation Variables

|**Delegate Name**|**Delegate Type**|**Description**|
|:----------------|:----------------|:--------------|
|onEnter|VoidDelegate|响应进入事件|
|onExit|VoidDelegate|响应退出事件|
|onDown|VoidDelegate|响应按下事件|
|onUp|VoidDelegate|响应抬起事件|
|onClick|VoidDelegate|响应点击事件|
|onBeginDrag|VoidDelegate|响应开始进入拖拽事件|
|onDrag|EventDelegate|响应拖拽事件|
|onDrop|EventDelegate|响应拖拽分离事件|
|onEndDrag|VoidDelegate|响应结束拖拽事件|
|onUpdateSelectObj|VoidDelegate|响应更新获取Obj事件|
|onHover|VoidDelegate|响应悬停事件|
|onMove|AxisEventDelegate|响应翻页事件|

变量类型包括 **VoidDelegate** , **EventDelegate** , **AxisEventDelegate。**

public delegate void VoidDelegate (GameObject go)

该委托类型用于传入发生事件的GameObject

public delegate void EventDelegate (GameObject go,PointerEventData eventData)

该委托类型用于传入发生事件的GameObject和PointerEventData

public delegate void AxisEventDelegate (GameObject go,AxisEventData eventData)

该委托类型用于传入发生事件的GameObject和AxisEventData

## Examples

```screen
// When the controller's ray points at the exit button, the user clicks the touch panel to exits from the app. This script is bound to the Back button.
void Start() {
    HVREventListener.Get(transform.gameObject).onClick = onPointClick;
}

private void onPointClick(GameObject go) {
    if (go == transform.gameObject) {
        Application.Quit();
    }
}
```
