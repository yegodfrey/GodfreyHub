# ARHand

|Class Info|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARHand extends ARTrackableBase 用于人体手部跟踪时返回跟踪结果，包含手部骨骼数据和手势识别结果，派生自[ARTrackableBase](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable_base-0000001050119508)。 1. 应用需要根据该对象上的TrackingState对数据进行处理。当且仅当[TrackingState](https://developer.huawei.com/consumer/cn/doc/graphics-References/tracking_state-0000001050164125)为TRACKING时，对象上的数据才有效。 2. 对于3D类型的Hand跟踪（如支持3D结构光，[getSkeletonCoordinateSystem](#section145531524171016)()返回的结果是COORDINATE_SYSTEM_TYPE_3D_CAMERA），使用setPowerMode设置功耗模式以后，会影响相机输出帧率，普通模式：25fps，超级省电模式：15fps。 3. 手势特性对硬件设备的依赖情况请参见[特性依赖表](https://developer.huawei.com/consumer/cn/doc/graphics-Guides/features-0000001060501339)，AR Engine Server 3.17版本以后，手部骨骼点及左右手识别功能支持更多机型。|

手势识别与深度流有关联，对应的关系如下表所示：

|手势类型|数值|不开启深度流，是否支持|开启深度流，是否支持|

|手势0（握拳的手势）|0|支持|支持|
|手势1（竖食指）|1|支持|不支持|
|手势2（食指中指张开）|2|不支持|支持|
|手势5（五指张开）|5|支持|支持|
|手势6（打电话手势）|6|支持|支持|
|手势7（love手势）|7|支持|支持|
|手势8（拇指食指张开）|8|不支持|支持|
|手势10（比心）|10|支持|不支持|
|其他手势|-1|--|--|
