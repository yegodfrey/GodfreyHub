# HwArEnvironmentTextureUpdateMode

|Enum Info|
|:--------|
|环境纹理更新模式。|

#### Enum Value Summary

|Enum Name|
|:-------------------------------------------------------------------------------|
|HWAR_LIGHT_ENVIRONMENT_TEXTURE_UPDATE_UNKNOWN 未设置更新模式，取值为-1。|
|HWAR_LIGHT_ENVIRONMENT_TEXTURE_UPDATE_AUTO 自动更新模式，取值为0。|
|HWAR_LIGHT_ENVIRONMENT_TEXTURE_UPDATE_ONE_TIME 手动更新模式，更新模式只针对上半部分预测出来的环境纹理，取值为1。|
