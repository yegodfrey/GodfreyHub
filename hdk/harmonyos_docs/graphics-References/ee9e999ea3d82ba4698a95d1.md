# dispatch_after_f

## 功能描述

[dispatch_after](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/after-0000001050168876)的_f版本。

## 函数原型

```screen
void dispatch_after_f(dispatch_time_t when, dispatch_queue_t queue, void *context, dispatch_function_t work);
```

## 参数

|名称|类型|描述|
|:------|:------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|when|dispatch_time_t|时间点，由[dispatch_time](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/time-0000001050168878)或[dispatch_walltime](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/walltime-0000001050170835)所返回。也可以用DISPATCH_TIME_NOW，但是这种情况通常用[dispatch_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-0000001050168872)代替。|
|queue|dispatch_queue_t|提交任务的目标queue。|
|context|void *|任务函数参数。|
|work|dispatch_function_t|使用者定义的任务函数。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
