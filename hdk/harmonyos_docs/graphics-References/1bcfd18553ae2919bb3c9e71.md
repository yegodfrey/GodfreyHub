# ShaderStage

|Enum Info|
|:----------------------------------------------------------|
|enum class ShaderStage ShaderModuleCreateInfo中可以指定着色器运行的阶段。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------|
|SHADER_STAGE_VERTEX_BIT 顶点着色阶段。|
|SHADER_STAGE_TESSELLATION_CONTROL_BIT 细分控制阶段。|
|SHADER_STAGE_TESSELLATION_EVALUATION_BIT 镶嵌评估阶段。|
|SHADER_STAGE_GEOMETRY_BIT 指定几何阶段。|
|SHADER_STAGE_FRAGMENT_BIT 片段着色阶段。|
|SHADER_STAGE_COMPUTE_BIT 计算阶段。|
|SHADER_STAGE_ALL_GRAPHICS_BIT 组合，包含上面所有的图形阶段（计算除外）。|
|SHADER_STAGE_ALL 组合，包含上面所有着色器阶段。|
