# Posture

## Posture

姿态、位置参数及跟踪状态，指示头盔或手柄的旋转四元数、位置向量及跟踪状态的结构体。

|**Attribute**|||
|**Member**|**Type**|**Description**|
|:----------|:----------|:--------------|
|rotation|Quaternion|旋转四元数（x,y,z,w）|
|position|Vector3|位置向量（x,y,z）|
|trackStatus|TrackStatus|头部跟踪状态|
