# DDGIMesh

|Struct Info|
|:--------------------------------------------------------|
|DDGIMesh 网格数据，渲染模型中每个物体的顶点、材质、顶点索引、变换矩阵等信息，DDGI支持Submesh。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------|
|std::string|meshName 渲染模型中每个网格的名称。|
|std::vector<[DDGIVertex](https://developer.huawei.com/consumer/cn/doc/graphics-References/ddgi-api-ddgivertex-0000001259437072)>|meshVertex 网格的顶点数据数组，包括subMesh的顶点数据。|
|std::vector<uint32_t>|meshIndice 网格的顶点索引数组，包括subMesh的顶点索引。|
|std::vector<[DDGIMaterial](https://developer.huawei.com/consumer/cn/doc/graphics-References/ddgi-api-ddgimaterial-0000001259277204)>|materials 网格的材质数组，数组中成员的数量表示subMesh的数量，每个成员依次为每个subMesh的材质。|
|std::vector<uint32_t>|subMeshStartIndexes 数组中成员的数量表示subMesh的数量，每个成员表示每个subMesh的顶点索引在meshIndice数组中的起始位置。|
|std::vector<uint32_t>|subMeshIndexCnts 数组中成员的数量表示subMesh的数量，每个成员表示每个subMesh的顶点索引数量。|
|DDGI::Mat4f|localToWorld 用于将网格中顶点从局部坐标系变换到世界坐标系。 默认为单位矩阵。|
|bool|isSkinMesh 表示网格是否有骨骼蒙皮动画，true表示有骨骼蒙皮动画，false表示没有。 默认为false。|
|std::vector<DDGI::Mat4f>|boneTransforms 当前帧骨骼的变换矩阵数组。|
|bool|isDDGIMesh 表示网格是否用于DDGI渲染，true表示用于DDGI渲染，false表示不用于DDGI渲染。 默认为true。|
|bool|hasIndices 表示网格是否有顶点索引，true表示有顶点索引，false表示没有。当前DDGI仅支持有顶点索引的网格。|
|bool|hasAnimation 表示网格在软件运行的渲染过程中是否会运动，true表示是运动网格，false表示为固定网格，整个运行阶段都不会运动。如果有骨骼蒙皮动画该值应该设为true。 默认值为false。|

> 注意
>
> * 网格（Mesh）的子网格（subMesh）数量必然大于等于1个。
> * 在网格可能会运动和网格存在骨骼蒙皮动画的两种情况下，hasAnimation都设置为true。
> * DDGI中骨骼蒙皮动画的每个顶点仅同时支持4个关节的影响；每个网格最多支持128个boneTransforms矩阵。
