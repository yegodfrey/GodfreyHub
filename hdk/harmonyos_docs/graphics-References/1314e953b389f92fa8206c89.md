# CGKitInterface

> 注意
>
> * 该类已融合到[BaseApplication](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736)类，原有的参数设置可直接调用[BaseApplication](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736)中相关接口设置即可。
> * [SetApplication](#section63014151419)，[GetApplication](#section156269151091)因为直接使用[BaseApplication](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseapplication-0000001050197736)对象的原因，完全废弃。
> * [SetMSAA](#section19381703011)、[SetSampleCount](#section935812558718)、[SetSampleShading](#section8819191416715)、[SetMinSampleShading](#section171471111988)接口已废弃，使用[SetMultiSampleInfo](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/camera-0000001050179056#section4239186554)替代。

|Class Info|
|:--------------------------------------------------------|
|class CGKitInterface CG Kit接口类，可设置、获取应用程序，获取屏幕宽高比及宽度、高度等。|
