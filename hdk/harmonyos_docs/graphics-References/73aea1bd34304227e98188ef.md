# LogicOp

|Enum Info|
|:-----------------|
|帧缓冲与输入像素的逻辑操作方式枚举。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------|
|LOGIC_OP_CLEAR 清除类型，所有值置为0。|
|LOGIC_OP_AND 帧缓冲与输入像素进行逻辑与操作类型。|
|LOGIC_OP_AND_REVERSE 帧缓冲逻辑取反后，与输入像素进行逻辑与操作类型。|
|LOGIC_OP_COPY 拷贝类型，将输入像素拷贝到帧缓冲中。|
