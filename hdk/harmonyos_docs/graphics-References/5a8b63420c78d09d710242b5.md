# TraceRayFlag

|Enum Info|
|:-------------------------------------------------------------------|
|enum TraceRayFlag 计算交点时所使用的标志位，可以选择计算任意一个交点或者计算最近的交点，和三角形正面相交或者背面相交。|

## Enum Value Summary

|Enum Value and Description|
|:---------------------------------------------------------------|
|TRACERAY_FLAG_ANY_HIT 计算得到任意一个交点就返回。|
|TRACERAY_FLAG_CLOSEST_HIT 计算最近的交点。|
|TRACERAY_FLAG_CULL_BACK_FACING_TRIANGLES 和三角形背面相交不会判断为相交。|
|TRACERAY_FLAG_CULL_FRONT_FACING_TRIANGLES 和三角形正面相交不会判断为相交。|
|TRACERAY_FLAG_INTERSECT_DEFAULT 默认标志位，计算最近的交点，和三角形正面和背面相交都判断为相交。|

> 说明
>
> TRACERAY_FLAG_ANY_HIT、TRACERAY_FLAG_CLOSEST_HIT标志位可以和TRACERAY_FLAG_CULL_BACK_FACING_TRIANGLES、TRACERAY_FLAG_CULL_FRONT_FACING_TRIANGLES标志位进行位或（|）操作。
