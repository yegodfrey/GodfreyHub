# EnableHiAnalytics

**EnableHiAnalytics(bool isEnable)**函数用于开启数据统计分析的接口。

启用统计后，SDK将进行应用信息、网络信息、接口信息的收集，用于统计分析及服务改进。

## Return Values

**固定返回0。**

## Examples

```screen
HvrApi.EnableHiAnalytics(true);
```
