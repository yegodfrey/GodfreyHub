# GetCurrentFrameRate

|**Method**|
|:---------------------------------------|
|int GetCurrentFrameRate() 获取当前场景下的帧率上限值。|

**Returns**

|Type|**Description**|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------------|
|int|正数值即帧率上限，表示获取成功；否则获取失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
