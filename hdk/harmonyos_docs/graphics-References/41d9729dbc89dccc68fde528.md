# vkAllocateMemory

## 接口定义

```screen
VkResult vkAllocateMemory(VkDevice device, const VkMemoryAllocateInfo *pAllocateInfo, const VkAllocationCallbacks *pAllocator, VkDeviceMemory *pMemory)
```

## 功能介绍

Vulkan的缓冲是可以存储任意数据的可以被显卡读取的内存。缓冲区除了用来存储定点数据，还有很多其他的用途，但是缓冲对象并不自动的为它们自己分配内存。因此，需要根据确定好的内存类型，调用vkAllocateMemory为帧缓冲区分配内存。

## 参数

|名称|类型|描述|
|:------------|:-|:---------------------------------------|
|device|句柄|拥有内存的逻辑设备。|
|pAllocateInfo|指针|指向VkMemoryAllocateInfo结构的指针，该结构描述分配参数。|
|pAllocator|指针|控制主机内存分配。|
|pMemory|指针|指向VkDeviceMemory句柄的指针，在该句柄中返回有关已分配内存的信息。|

## 返回

|值|描述|
|:-------------------------------|:---------------|
|VK_SUCCESS|命令成功完成。|
|VK_ERROR_OUT_OF_HOST_MEMORY|主机内存分配失败。|
|VK_ERROR_OUT_OF_DEVICE_MEMORY|设备内存分配失败。|
|VK_ERROR_TOO_MANY_OBJECTS|创建了太多类型的对象。|
|VK_ERROR_INVALID_EXTERNAL_HANDLE|外部句柄不是指定类型的有效句柄。|

## 调用示例

```screen
VkResult result = vkAllocateMemory( logical_device, &image_memory_allocate_info, nullptr, &memory_object );
```
