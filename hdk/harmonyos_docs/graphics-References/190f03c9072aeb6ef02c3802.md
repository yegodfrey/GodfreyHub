# FaceHealthCheckState

|Enum Info|
|:---------------------------------------|
|public enum FaceHealthCheckState 健康检测状态。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------|
|DETECT_FAILED(-1) 健康检测失败，当前条件不满足算法处理。|
|DETECT_SUCCESS(0) 健康检测状态OK，当前状态满足算法处理。|
|NO_AVAILABLE_HEALTH_DATA(1) 健康检测提示，无法获取有效的健康值。|
|FACE_WITH_EXPRESSION(10) 健康检测提示，检测中人脸有表情。|
|IMAGE_SIZE_WRONG(20) 健康检测失败，算法获取的图像尺寸错误。|
|FACE_NOT_IN_ELLIPSE(21) 健康检测失败，人脸没有在椭圆框内，即没有在合适的位置。|
|FACE_MOTION_TOO_MUCH(22) 健康检测失败，人脸移动较快。|
|EFFECTIVE_PIXEEL_TOO_LOW(23) 健康检测失败，人脸图像有效像素太少。|
|LIGHT_TOO_DARK(24) 健康检测失败，光线太暗。|
|LIGHT_NOT_UNIFORM(25) 健康检测失败，图像上人脸的光线不均匀。|
|POSE_TOO_LARGE(26) 健康检测失败，图像中人脸位姿太大，超过限制。|
|SIGNAL_CAPTURE_FAILED(27) 健康检测失败，从图像中提取信号失败。|
|SIGNAL_NAN(28) 健康检测失败，提取的信号为NAN。|
|FINGER_OUTSIDE_CAMERA(29) 健康检测失败，手指未按压后置摄像头。|
