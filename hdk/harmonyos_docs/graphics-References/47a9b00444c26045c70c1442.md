# vkCreateDevice

## 接口定义

```screen
VkResult vkCreateDevice(VkPhysicalDevice physicalDevice, const VkDeviceCreateInfo *pCreateInfo, const VkAllocationCallbacks *pAllocator, VkDevice *pDevice)
```

## 功能介绍

根据指定物理设备创建逻辑设备。

## 参数

|名称|类型|描述|
|:-------------|:-|:-----------------------------------|
|physicalDevice|句柄|给定硬件平台上可用的物理设备的句柄。|
|pCreateInfo|指针|指向VkDeviceCreateInfo结构的指针，该结构描述创建参数。|
|pAllocator|指针|控制主机内存分配。|
|pDevice|指针|指向VkDevice句柄的指针。|

## 返回

|值|描述|
|:-----------------------------|:--------------------|
|VK_SUCCESS|命令成功完成。|
|VK_ERROR_OUT_OF_HOST_MEMORY|主机内存分配失败。|
|VK_ERROR_OUT_OF_DEVICE_MEMORY|设备内存分配失败。|
|VK_ERROR_INITIALIZATION_FAILED|由于实现特定的原因，无法完成对象的初始化。|
|VK_ERROR_EXTENSION_NOT_PRESENT|不支持请求的扩展名。|
|VK_ERROR_FEATURE_NOT_PRESENT|不支持请求的功能。|
|VK_ERROR_TOO_MANY_OBJECTS|创建了太多类型的对象。|
|VK_ERROR_DEVICE_LOST|逻辑或物理设备已丢失。|

## 调用示例

```screen
VkResult err = vkCreateDevice(physicalDevice, &deviceCreateInfo, nullptr, &m_Device);
```
