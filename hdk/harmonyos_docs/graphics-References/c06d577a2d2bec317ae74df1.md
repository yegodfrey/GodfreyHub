# Log

|Class Info|
|:-----------------------------------------------------------------------------------------------------------------------------------|
|class Log 日志类。包含日志记录器的注册、注销，及char数组类型数据作为log信息输出。 需定义宏： #define CGKIT_LOG 以启用日志，并设置日志等级以打印对应级别日志，如设置为： Log::SetLogLevel(LOG_VERBOSE)|
