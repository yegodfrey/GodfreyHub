# HcOccludeeBoxType

|Struct Info|
|:------------------------------------|
|struct HcOccludeeBoxType Occludee的结构。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------|
|int|numBox Occludee中AABB（轴对齐包围盒）的数量。|
|float*|boxMinMax Occludee的AABB（轴对齐包围盒），定义在world space下。 AABB的数据按照(xmin, ymin, zmin, xmax, ymax, zmax)的顺序排布，每6个数值表示一个AABB。|
|float[4][4]|worldToClip 顶点从world space变换到clip space的变换矩阵，以列主序的方式存储。 worldToClip= ProjectionMatrix * ViewMatrix|
