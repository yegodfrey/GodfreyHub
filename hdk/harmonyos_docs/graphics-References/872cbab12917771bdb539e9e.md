# 说明

|Name|Description|
|:------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android|基于Java语言开发的独立Android应用程序接口，分别提供如下能力： * 原子化接口：提供场景、节点、组件管理能力，助您实现场景渲染与手势交互。您也可以基于原子化接口二次开发，打造出绚丽的应用。 * 场景化接口：提供面向模型展示、面向虚拟现实放置场景、面向面部AR场景，助您实现模型加载、天空盒纹理加载、平面识别与绘制、虚拟现实放置和虚拟头像替换等功能。 * 2D流体模拟接口：提供一套较为完备、高扩展性的流体模拟接口，使用原子接口您可以完成创建流体粒子，模拟流体晃动的物理效果。|
|C++|基于C++语言开发的跨平台（例如：Android、Windows、Linux、Mac等）应用程序接口，提供DDGI插件、GoodCulling插件、SlimLOD插件与Ray shop插件，具体功能详见各插件章节。|
