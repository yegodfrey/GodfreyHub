# RenderingSortType

|Enum Info|
|:--------|
|渲染排序枚举。|

## Enum Value Summary

|Enum Value and Description|
|:-----------------------------------------|
|RENDERING_SORT_TYPE_DISTANCE 依据物体到相机的距离排序。|
|RENDERING_SORT_TYPE_ID 依据物体的排序ID。|
|RENDERING_SORT_TYPE_MAX 枚举最大值，有效的枚举值小于该值。|
