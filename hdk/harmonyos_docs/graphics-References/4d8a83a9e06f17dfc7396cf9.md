# IFeatureEventListener.FeatureEventType

|Enum Info|
|:----------------------------------------------------------------------------------------------------------|
|public enum FeatureEventType XRKit特性事件类型，包含模型加载成功、模型选定、模型错误、模型与目标场景绑定、ARSceneView场景初始化失败、ARFaceView场景初始化失败。|

#### Enum Value Summary

|Enum Value and Description|
|:---------------------------------------------------------------------------|
|MODEL_LOADED 特性事件上报，标识模型加载成功事件类型。|
|MODEL_SELECTED 特性事件上报，标识模型选定的事件类型。|
|MODEL_ERROR 特性事件上报，标识模型错误事件类型。|
|MODEL_PLACED 特性事件上报，标识虚拟模型与现实世界指定特征结合，即实现虚实结合的时候上报的事件类型。|
|ARSCEBEVIEW_INIT_FAILED 特性事件上报，标识ARSceneView场景初始化失败事件上报。|
|ARFACEVIEW_INIT_FAILED 特性事件上报，标识ARFaceView场景初始化失败事件上报。|
|MEDIA_ERROR_UNSUPPORTED 特性事件上报，标识空间音频加载的音频格式不支持。|
|AR_ENGINE_SERVICE_APK_TOO_OLD 特性事件上报，标识使用的特性需要配套高版本的AR Engine Service才能正常运行。|
