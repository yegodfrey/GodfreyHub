# DDGICamera

|Struct Info|
|:----------------------------------|
|DDGICamera 相机设置参数，包括相机位置、欧拉转角、变换矩阵。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:------------------------------------------|
|DDGI::Vec4f|pos 相机在世界空间的位置，前3维依次为X、Y、Z坐标值，第4维保留不使用。|
|DDGI::Vec4f|rotation 相机的欧拉转角，前3维依次为绕X、Y、Z轴的转角，第4维保留不使用。|
|DDGI::Mat4f|viewMat 视角变换矩阵。|
|DDGI::Mat4f|perspectiveMat 投影变换矩阵。|
