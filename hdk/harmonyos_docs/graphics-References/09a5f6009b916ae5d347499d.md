# ARTrackableBase

|Class Info|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARTrackableBase implements ARTrackable 所有可跟踪对象类的基类，实现了[ARTrackable](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable-0000001050121431)接口，不可直接引用此类创建对象，请使用此类的子类（具体的可跟踪对象）进行操作。|

|Qualifier and Type|Method Name and Description|
|:----------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

|Collection<[ARAnchor](https://developer.huawei.com/consumer/cn/doc/graphics-References/anchor-0000001050119480)>|[getAnchors](#section12165724143817)() 获取当前可跟踪对象上绑定的所有锚点数据。|
|[ARTrackable.TrackingState](https://developer.huawei.com/consumer/cn/doc/graphics-References/tracking_state-0000001050164125)|[getTrackingState](#section06202034143812)() 获取当前可跟踪对象的跟踪状态。 1. 应用初始化，在调用ARSession.[resume](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section134371320365)()前，状态为PAUSED。 2. 调用ARSession.[resume](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section134371320365)()以后，系统正常运行并识别到可跟踪对象，状态为TRACKING。 3. 在应用调用ARSession.[pause](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section1913415217363)()以后，状态从TRACKING变成PAUSED。 4. 调用ARSession.[stop](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section254018514378)()以后，状态变成STOPPED。|
