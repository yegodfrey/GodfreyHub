# ShowCircle

**void ShowCircle (bool isTrue)**

手柄射线指向可交互物体时光标显示圆圈，指向不可交互的物体时光标显示圆点，isTrue为true：显示圆圈，isTrue为false：显示圆点。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-----------------|:----------------------------------|
|isTrue|bool|光标显示形状输入参数（true： 显示圆圈， false： 显示圆点）|

## Examples

```screen
// When the controller's ray points to the selected UI element (the script is bound to the UI string).
void Start() {
    HVREventListener.Get(transform.gameObject).onEnter = onPointEnter;
}

private void onPointEnter(GameObject go) {
    if (go == transform.gameObject) {
        HVRLinePointer.Instance.ShowCircle(true);
    }
}
```
