|public void setMaxMapSize(long maxMapSize) 设置地图数据最大使用内存大小。在AR Engine Service 4.0.1.100及以上版本生效。若配置的地图数据最大使用内存范围不合法，则配置最接近用户配置的有效值，默认最大使用内存大小800MB。|

|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void setPreviewSize(int width, int height) 设置输入预览流分辨率，默认分辨率为（1440x1080），此外还支持宽高比为4:3的物理相机预览分辨率。 说明： 获取预览列表的方法： 1. 使用CameraCharacteristics.getCameraCharacteristics(id)获取指定id的相机特性对象。 2. 调用getOutputSizes(SurfaceTexture.class)获取预览列表。 代码示例： ``` Size[] supportedPreviewSizes = characteristics.get(CameraCharacteristics.SCALER_STREAM_CONFIGURATION_MAP).getOutputSizes(SurfaceTexture.class); ```|

Parameters  

|Name|Description|
|:-----|:----------|
|width|预览流宽度。|
|height|预览流高度。|
