# Overview

图形引擎服务光线追踪插件，提供光线追踪的加速结构构建与求交接口，该接口需要带vulkan驱动的主流安卓/HarmonyOS环境，支持华为Kirin990、Kirin9000、高通888、三星Exynos 1080、MTK1000+芯片。
