# AREnginesApk

|Class Info|
|:------------------------------------------|
|public class AREnginesApk 用于管理AR Engine服务端。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[ARAvailability](https://developer.huawei.com/consumer/cn/doc/graphics-References/availability-0000001050162180)|[checkAvailability](#section15109235155311)(Context applicationContext) 检查设备是否支持当前设置的引擎（通过AREnginesSelector.[setAREngine](https://developer.huawei.com/consumer/cn/doc/graphics-References/engines_selector-0000001050119490#section17316132125517)()方法设置AR Engine类型）。 注意： 该方法已废弃，请使用[isAREngineApkReady](#section375674515317)()。|
|boolean|[isAREngineApkReady](#section375674515317)(Context applicationContext) 检查设备是否已安装AR Engine Service，并且版本与AR Engine SDK兼容，若返回值为false，请执行跳转应用市场安装AR Engine Service的操作。|
|[ARInstallStatus](https://developer.huawei.com/consumer/cn/doc/graphics-References/install_status-0000001050164137)|[requestInstall](#section65801355195316)(Activity applicationActivity, boolean isUserRequestedInstall) 在需要安装的情况下，初始化安装功能。userRequestedInstall为true时，该方法会调用。 注意： 该方法已废弃，请使用[isAREngineApkReady](#section375674515317)()。|
