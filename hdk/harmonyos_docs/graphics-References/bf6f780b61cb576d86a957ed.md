# ARSessionPausedException

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARSessionPausedException extends IllegalStateException 继承IllegalStateException，当一个操作需要AR Engine运行（而实际不处于该状态）时抛出。例如： 1. 在启动后未调用ARSession.[resume](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section134371320365)()，而是直接调用ARSession.[update](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section1826912043817)()。 2. 在调用ARSession.[pause](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section1913415217363)()后，未调用ARSession.[resume](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section134371320365)()前，调用了ARSession.[update](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section1826912043817)()，会抛出该异常。|
