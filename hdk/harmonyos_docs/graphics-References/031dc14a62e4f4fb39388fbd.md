# HVRHelpMessage

提供静态变量，用于自定义手柄帮助信息文字、字体颜色、字体大小、背景板颜色等。

## Public Static Variables

|**Variable Name**|**Variable Type**|**Description**|
|:----------------|:----------------|:--------------|
|m_trigger_msg|string|扳机键提示信息|
|m_confirm_msg|string|触摸板按键提示信息|
|m_back_short_msg|string|返回键短按提示信息|
|m_back_long_msg|string|返回键长按提示信息|
|m_home_short_msg|string|Home键短按提示信息|
|m_home_long_msg|string|Home键长按提示信息|
|m_volume_msg|string|音量键提示信息|
|m_FontSize|int|提示信息字号|
|m_ImageColor|Color|背景板颜色|
|m_ArrowColor|Color|指示线颜色|
|m_TextColor|Color|字体颜色|

## Examples

```screen
// The following is an example for customizing the tooltip for the trigger button.
void Start() {
    HVRHelpMessage.m_trigger_msg = "trigger msg";
}
```
