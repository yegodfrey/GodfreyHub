# dispatch_group_create

## 功能描述

创建一个空的group。

## 函数原型

```screen
dispatch_group_t dispatch_group_create(void);
```

## 返回

|类型|描述|
|:---------------|:---------------------|
|dispatch_group_t|新创建的group。如果失败则返回NULL。|
