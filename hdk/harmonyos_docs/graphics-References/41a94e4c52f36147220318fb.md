# HwArEnableItem

|Enum Info|
|:--------|
|配置的启用项。|

## Enum Value Summary

|Enum Name|
|:-----------------------------------------------------------|
|HWAR_ENABLE_NULL 不启用特殊能力，取值为0。|
|HWAR_ENABLE_DEPTH 启用深度能力，默认启用，取值为1。|
|HWAR_ENABLE_MASK 启用遮罩能力，取值为1 << 1。|
|HWAR_ENABLE_SCENE_MESH 启用环境Mesh能力，取值为1 << 2。|
|HWAR_ENABLE_CLOUD_AUGMENTED_IMAGE 启用2D云图像识别能力，取值为1 << 5。|
|HWAR_ENABLE_HEALTH_DEVICE 启用健康检查能力，取值为1 << 6。|
|HWAR_ENABLE_CLOUD_OBJECT_RECOGNITION 启用3D云物体识别能力，取值为1 << 10。|
