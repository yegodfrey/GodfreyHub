# ARSession

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARSession 用于管理AR Engine的整个运行状态，是AR Engine运行的基础，启动[ARSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459)前，使用ARSession.[configure](#section22281312163311)()设置相关配置，通过[ARSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459)可以实现： * 控制AR Engine的启动、暂停、结束等行为。 * 更新并获取AR Engine内部数据，如：锚点、平面、可跟踪对象等。|
