# HwArEnginesSelector

> 注意
>
> 该模块已废弃，目前只支持AR Engine，不支持切换。

|Module Info|
|:-------------------------------------------------------------|
|用于查询设备支持的AR引擎，并设置应用使用的引擎。如果应用不需要切换引擎，可以直接略过该类，默认的引擎为AR Engine。|
