# LoadState

|Enum Info|
|:--------|
|资源读取状态枚举。|

## Enum Value Summary

|Enum Value and Description|
|:-----------------------------------------------------|
|LOAD_STATE_IDLE 默认状态。|
|LOAD_STATE_STARTED 开始读取状态。|
|LOAD_STATE_COMPLETED 读取完毕状态。|
|LOAD_STATE_FAILED 读取失败状态。|
|LOAD_STATE_MAX = LOAD_STATE_FAILED 枚举最大值，有效的枚举值小于等于该值。|
