### singleStep(float timeStep, int particleIterations)

|Method|
|:---------------------------------------------------------------------|
|public void singleStep(float timeStep, int particleIterations) 单步仿真模拟。|

**Parameters**

|Name|Description|
|:-----------------|:--------------------------------------------------------------------------------------------|
|timeStep|单步仿真模拟时间。参考值 1/60秒。|
|particleIterations|粒子运动状态求解迭代次数。参考值 5。迭代次数越小，求解精度越低，粒子发生挤压穿透；迭代次数越大，求解精度越高，但求解效率越低，功耗越高，需要在粒子求解效率与粒子模拟效果之间做平衡考虑。|
