# HcSetResolution

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[HcErrorCode](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcerrorcode-0000001055612806) HcSetResolution(struct [HiCulling](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hiculling-0000001055695365) *obj, unsigned int width, unsigned int height) 设置depth buffer的分辨率。此函数被调用后，会立即执行一次[HcClearBuffer](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcclearbuffer-0000001055256783)，并且之前的分辨率将不再适用。|

**Parameters**

|Name|Description|
|:-----|:---------------------------------------------------------------------------------------------------------------------------------|
|obj|用于执行软件遮挡剔除的[HiCulling](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hiculling-0000001055695365)对象。|
|width|以像素为单位描述的depth buffer的宽度，必须是2的倍数。|
|height|以像素为单位描述的depth buffer的高度，必须是2的倍数。|

**Returns**

|Type|Description|
|:-----------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------|
|[HcErrorCode](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/hcerrorcode-0000001055612806)|[错误码](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/error-code-0000001061725148)，用于描述错误原因。|
