# Overview

|[HwArAugmentedImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_augmentedimage-0000001060013669)|AR Engine增强图像功能，[HwArAugmentedImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_augmentedimage-0000001060013669)是由AR Engine检测与追踪的图像。|

|[HwArFace](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_face-0000001060811832)|用于人脸跟踪时返回人脸跟踪的结果，包含人脸位置、姿态、拓扑和微表情。|
|[HwArFaceBlendShapes](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_faceblendshapes-0000001060653620)|用于描述人脸微表情，包含若干个表情参数。|
|[HwArFaceGeometry](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_facegeometry-0000001060493632)|用于描述人脸拓扑结构，即人脸Mesh。|
|[HwArFrame](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_frame-0000001060013671)|每一帧的状态，由[HwArSession_pause](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_session-0000001060493634#section28611048131015)创建。|
|[HwArHand](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_hand-0000001061131408)|用于人体手部跟踪时返回跟踪结果，包含手部骨骼数据和手势识别结果。|
|[HwArHitResult](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_hitresult-0000001060971426)|定义了射线（如以屏幕的点为起点的射线）与真实世界（平面等）的碰撞交点。|
|[HwArImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_image-0000001060363372)|用于描述[HwArFrame](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_frame-0000001060013671)获取到的预览图等Image信息，通过此类可以获取图片格式、宽高等信息。|
|[HwArImageMetadata](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_imagemetadata-0000001060385719)|提供对相机图像捕获结果metadata的访问。|
|[HwArLightEstimate](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_lightestimate-0000001060243329)|真实场景中光照估计信息。|
|[HwArPlane](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_plane-0000001060131793)|保存AR Engine识别到的真实世界中的平面信息。两个接近的平面会被自动合并成一个平面。|
|[HwArPoint](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_point-0000001059883365)|描述AR Engine跟踪范围内的一个点。|
|[HwArPointCloud](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_pointcloud-0000001060493733)|包含场景中观察到的三维点及其对应置信度的集合。|
|[HwArPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_pose-0000001060811834)|位姿数据类，描述从一个坐标系到另一个坐标系的不可变的刚体变换。包含平移向量和旋转向量（四元组）。在AR Engine中，其用于描述物体从局部坐标系向世界坐标系的转换，局部坐标通过该类的对象转化成世界坐标系。|
|[HwArSceneMesh](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_scenemesh-0000001060653622)|用于环境Mesh跟踪时返回跟踪结果的类，结果包括Mesh顶点坐标，三角形下标等。|
|[HwArSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_session-0000001060493634)|该模块管理AR Engine的系统状态，是AR Engine NDK的重要API。通过该模块，开发者可以创建会话，配置会话，启动，暂停和停止会话，还可以获取每一帧的数据。|
|[HwArTarget](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_target-0000001134008952)|用于扫描目标物体返回跟踪结果，包含环境平面的标签和物体的形状。|
|[HwArTrackable](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_trackable-0000001060013673)|任何可以被追踪，可以依附锚点的对象。|
