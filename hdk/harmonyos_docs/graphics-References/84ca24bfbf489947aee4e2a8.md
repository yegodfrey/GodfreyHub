# dispatch_queue_get_label

## 功能描述

返回某个queue创建时候所声明的label。

## 函数原型

```screen
const char * dispatch_queue_get_label(dispatch_queue_t queue);
```

## 参数

|名称|类型|描述|
|:----|:---------------|:--------------------------------------------------------------|
|queue|dispatch_queue_t|要查询的某个queue。使用DISPATCH_CURRENT_QUEUE_LABEL则表示当前queue（注：只适用此接口）。|

## 返回

|类型|描述|
|:-----------|:---------------------------------------------------------|
|const char *|指定queue的label。 如果queue创建时候label参数是NULL，那么对应的label就是一个空字符串。|
