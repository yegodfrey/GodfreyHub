# GetHelmetHandle

获取头盔句柄IHelmetHandle，用于调用头盔相关功能的接口函数. 请参考 [2.1.5.3](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/helmet_handle_is_available-0000001160524074) 节 "[IHelmetHandle](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/helmet_handle_is_available-0000001160524074)"。

## Return Values

调用函数成功返回头盔句柄IHelmetHandle，调用函数失败返回null。
> 说明
>
> 该接口需要在Unity生命周期的Start()或其之后调用。

## Examples

```screen
IHelmetHandle helmetHandle; //This variable related to the helmet handle is used in the //following codes.
helmetHandle = HvrApi.GetHelmetHandle();
if (helmetHandle != null) {
    Debug.Log("GetHelmetHandle Success!");
} else {
    Debug.Log("GetHelmetHandle Failed!");
}
```
