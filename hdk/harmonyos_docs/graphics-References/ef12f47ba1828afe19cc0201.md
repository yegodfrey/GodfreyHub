# HwArAvailability

> 注意
>
> 该枚举已废弃，无替代。

|Enum Info|
|:----------------|
|AR Engine服务端是否可用。|

## Enum Value Summary

|Enum Value and Description|
|:------------------------------------------------------------------|
|HWAR_AVAILABILITY_UNKNOWN_ERROR 未知错误，取值为0。|
|HWAR_AVAILABILITY_UNKNOWN_CHECKING 检查中，取值为1。|
|HWAR_AVAILABILITY_UNKNOWN_TIMED_OUT 检查超时，取值为2。|
|HWAR_AVAILABILITY_UNSUPPORTED_DEVICE_NOT_CAPABLE 设备不支持，取值为100。|
|HWAR_AVAILABILITY_SUPPORTED_NOT_INSTALLED AR Engine服务端未安装，取值为201。|
|HWAR_AVAILABILITY_SUPPORTED_APK_TOO_OLD AR Engine服务端版本太老，取值为202。|
|HWAR_AVAILABILITY_SUPPORTED_INSTALLED 设备支持并且AR Engine服务端已安装，取值为203。|
|HWAR_AVAILABILITY_UNSUPPORTED_EMUI_NOT_CAPABLE EMUI版本不支持，取值为5000。|
