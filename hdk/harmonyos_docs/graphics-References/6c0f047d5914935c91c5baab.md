# HwArAnchor

|Module Info|
|:------------------------------------------------------------------------------------------|
|锚点是实际环境中一个固定的位置和指定的方向。当环境发生变化时，比如摄像头移动，为了维持这个物理空间的固定位置和方向，AR Engine会根据自己对于环境的检测结果，不断更新它的数值。|
