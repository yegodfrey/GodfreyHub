# IsAvailable

查询已连接的控制器是否可用。

## Return Values

返回true：可用，false：不可用。

## Examples

```screen
if (null == controller) {
    Debug.LogError("Controller is null");
} else {
    if (controller.IsAvailable()) {
        Debug.Log("Controller is available");
    }
}
```
