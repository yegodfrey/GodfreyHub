# dispatch_retain

## 功能描述

对象的引用计数加1。

## 函数原型

```screen
void dispatch_retain(dispatch_object_t object);
```

## 参数

|名称|类型|描述|
|:-----|:----------------|:----------------------------------------------------------------------------------|
|object|dispatch_object_t|对象。multithread-lib中的任何对象都可以强转为dispatch_object_t使用，因为各对象结构体的起始统一是dispatch_object结构体。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
