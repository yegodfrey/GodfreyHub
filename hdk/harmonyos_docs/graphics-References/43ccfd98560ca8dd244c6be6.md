# ARBody

|Class Info|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARBody extends ARTrackableBase 用于人体骨骼跟踪时返回跟踪结果，包含人体骨骼数据，派生自[ARTrackableBase](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable_base-0000001050119508)。 1. 如果ARSession.[configure](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section22281312163311)()中传入[ARBodyTrackingConfig](https://developer.huawei.com/consumer/cn/doc/graphics-References/body_tracking_config-0000001050119484)或者[ARWorldBodyTrackingConfig](https://developer.huawei.com/consumer/cn/doc/graphics-References/world_body_tracking_config-0000001050121461)的对象时，AR Engine将实时检测相机预览中的人体。 2. AR Engine默认配置可同时识别两个人体，将始终返回两个body对象，应用需要根据对象上的[getTrackingState](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable-0000001050121431#section06202034143812)()的返回值判断该对象是否有效。当且仅当[getTrackingState](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable-0000001050121431#section06202034143812)()返回值为[ARTrackable.TrackingState.TRACKING](https://developer.huawei.com/consumer/cn/doc/graphics-References/tracking_state-0000001050164125#section15256152217277)时，识别到的人体才有效。 3. 以器件为基础的3D类型Body跟踪（如支持TOF（深度相机），[getCoordinateSystemType](#section117912594379)()返回的结果是COORDINATE_SYSTEM_TYPE_3D_CAMERA），使用[setPowerMode](https://developer.huawei.com/consumer/cn/doc/graphics-References/config_base-0000001050119488#section8395310135012)设置功耗模式以后，会影响相机输出帧率，普通模式：30fps，省电模式：20fps，超级省电模式：15fps。|
