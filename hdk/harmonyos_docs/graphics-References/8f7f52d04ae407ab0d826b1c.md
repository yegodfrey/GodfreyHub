# HwArHandSkeletonType

|Enum Info|
|:--------|
|手部关节点类型。|

## Enum Value Summary

|Enum Name|
|:----------------------------------------------|
|HwAr_HandSkeleton_Root 手骨根节点，即手腕，取值为0。|
|HwAr_HandSkeleton_Pinky_1 小手指关节1，取值为1。|
|HwAr_HandSkeleton_Pinky_2 小手指关节2，取值为2。|
|HwAr_HandSkeleton_Pinky_3 小手指关节3，取值为3。|
|HwAr_HandSkeleton_Pinky_4 小手指尖，取值为4。|
|HwAr_HandSkeleton_Ring_1 无名指关节1，取值为5。|
|HwAr_HandSkeleton_Ring_2 无名指关节2，取值为6。|
|HwAr_HandSkeleton_Ring_3 无名指关节3，取值为7。|
|HwAr_HandSkeleton_Ring_4 无名指尖，取值为8。|
|HwAr_HandSkeleton_Middle_1 中指关节1，取值为9。|
|HwAr_HandSkeleton_Middle_2 中指关节2，取值为10。|
|HwAr_HandSkeleton_Middle_3 中指关节3，取值为11。|
|HwAr_HandSkeleton_Middle_4 中指尖，取值为12。|
|HwAr_HandSkeleton_Index_1 食指关节1，取值为13。|
|HwAr_HandSkeleton_Index_2 食指关节2，取值为14。|
|HwAr_HandSkeleton_Index_3 食指关节3，取值为15。|
|HwAr_HandSkeleton_Index_4 食指指尖，取值为16。|
|HwAr_HandSkeleton_Thumb_1 大拇指关节1，取值为17。|
|HwAr_HandSkeleton_Thumb_2 大拇指关节2，取值为18。|
|HwAr_HandSkeleton_Thumb_3 大拇指关节3，取值为19。|
|HwAr_HandSkeleton_Thumb_4 大拇指尖，取值为20。|
|HwAr_HandSkeleton_Length 非关节点，表示定义的关节点个数，取值为21。|
