# PixelFormat

|Enum Info|
|:-------------------|
|像素通道排布格式，用于描绘数据输入输出。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------------|
|PIXEL_FORMAT_R8G8B8_UNORM 像素通道按照RGB交错排列，且每个通道为8位无符号整型。|
|PIXEL_FORMAT_R8G8B8A8_UNORM 像素通道按照RGBA交错排列，且每个通道为8位无符号整型。|
|PIXEL_FORMAT_MAX 支持的像素通道排布格式数量。|
