# SetFrameRate

|**Method**|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int SetFrameRate(int fps) 设置显示帧率，根据设置的帧率值进行系统帧率和刷新率的调控，且帧率值需要小于当前场景的帧率上限，不同场景的帧率上限值不同，具体参见[SetScene](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/setscene-0000001055107774)。|

**Parameters**

|**Name**|**Description**|
|:-------|:--------------|
|fps|帧率值。|

**Returns**

|**Type**|**Description**|
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
|int|0表示帧率值设置成功；否则设置失败，具体错误码参见[常量](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/constants-0000001055426371)。|
