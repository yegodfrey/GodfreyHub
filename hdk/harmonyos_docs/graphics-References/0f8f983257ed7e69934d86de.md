# HelmetModel

## HelmetModel

头盔类型，指示HUAWEI VR头盔类型。

|**Attribute**||
|:--------------------|---------------|
|HVR_HELMET_FIRST_GEN|HUAWEI VR 1.0头盔|
|HVR_HELMET_SECOND_GEN|HUAWEI VR 2|
|HVR_HELMET_THIRD_GEN|HUAWEI VR Glass|
|HVR_HELMET_NOT_FOUND|未找到头盔|
|HVR_HELMET_UNKNOWN|未知类型|
