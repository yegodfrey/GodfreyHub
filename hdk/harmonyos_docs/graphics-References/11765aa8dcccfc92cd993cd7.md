# BlendOperation

|Enum Info|
|:--------|
|混合操作类型枚举。|

#### Enum Value Summary

|Enum Value and Description|
|:-------------------------------------------------------------------------------------------------------------------------------|
|BLEND_OPERATION_ADD RGB = 源RGB颜色因子 \* 源RGB值 + 目标RGB颜色因子 \* 目标RGB值，Alpha = 源Alpha因子 \* 源Alpha值 + 目标Alpha因子 \* 目标Alpha值。|
|BLEND_OPERATION_SUBTRACT RGB = 源RGB颜色因子 \* 源RGB值 - 目标RGB颜色因子 \* 目标RGB值，Alpha = 源Alpha因子 \* 源Alpha值 - 目标Alpha因子 \* 目标Alpha值。|
|BLEND_OPERATION_REV_SUBTRACT RGB = 目标RGB颜色因子 \* 目标RGB值 -- 源RGB颜色因子 \* 源RGB值，Alpha = 目标Alpha因子 \* 目标Alpha值 - 源Alpha因子 \* 源Alpha值。|
|BLEND_OPERATION_MIN RGB = min(源RGB值, 目标RGB值)，Alpha = min(源Alpha值, 目标Alpha值)。|
|BLEND_OPERATION_MAX RGB = max(源RGB值, 目标RGB值)，Alpha = max(源Alpha值, 目标Alpha值)。|
