# HwArPlane

|Module Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------|
|保存AR Engine识别的真实世界中的平面信息。两个或者多个平面法向量朝向一致，位置靠近时会自动合并到一个父平面中，[HwArPlane_acquireSubsumedBy](#section11547163453310)将返回对应平面的父平面。被合并的子平面将继续被跟踪和返回。|
