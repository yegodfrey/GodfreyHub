# PipelineStageFlagBits

|Enum Info|
|:----------|
|渲染管线阶段标志枚举。|

|Enum Value and Description|
|:-------------------------------------------------------------------------------------------------------------------------------------|
|PIPELINE_STAGE_TOP_OF_PIPE_BIT = 0x00000001 渲染管线阶段的顶端。|
|PIPELINE_STAGE_DRAW_INDIRECT_BIT = 0x00000002 渲染管线阶段的间接绘制。|

|PIPELINE_STAGE_VERTEX_SHADER_BIT = 0x00000008 渲染管线阶段的顶点着色器。|

|PIPELINE_STAGE_GEOMETRY_SHADER_BIT = 0x00000040 渲染管线阶段的几何着色器。|
|PIPELINE_STAGE_FRAGMENT_SHADER_BIT = 0x00000080 渲染管线阶段的片段着色器。|

|PIPELINE_STAGE_TRANSFER_BIT = 0x00001000 渲染管线阶段的传输。|
|PIPELINE_STAGE_BOTTOM_OF_PIPE_BIT = 0x00002000 渲染管线阶段的底端。|
|PIPELINE_STAGE_HOST_BIT = 0x00004000 渲染管线阶段的主位。|
|PIPELINE_STAGE_ALL_GRAPHICS_BIT = 0x00008000 渲染管线阶段的所有图形执行管道。|

|PIPELINE_STAGE_SHADING_RATE_IMAGE_BIT_NV = 0x00400000 渲染管线阶段的着色速率影像扩展。|

|PIPELINE_STAGE_ACCELERATION_STRUCTURE_BUILD_BIT_NV = PIPELINE_STAGE_ACCELERATION_STRUCTURE_BUILD_BIT_KHR 渲染管线阶段的加速结构构建NV扩展，以KHR扩展为默认值。|
