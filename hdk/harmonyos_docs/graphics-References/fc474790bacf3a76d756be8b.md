# IsTouchpadSwipeDown

判定触摸板是否触发下滑动作，兼容HUAWEI VR 1.0的触摸板向下滑动功能。

## Return Values

判定触摸板是否触发左滑动作，兼容HUAWEI VR 1.0的触摸板向左滑动功能。
