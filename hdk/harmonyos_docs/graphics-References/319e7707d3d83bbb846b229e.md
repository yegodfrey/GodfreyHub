# 概述

为了方便地且线程安全地管理一组任务的运行，multithread-lib提供了group相关的接口。需要创建一个group对象，通过在任务的提交和任务的结束调用[dispatch_group_enter](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/enter-0000001050425193)(group)和dispatch_group_release(group)，这样就能让外部知道某一组任务执行结束。

外部有同步和异步两种方式获得group中全部任务执行结束的方式，[dispatch_group_wait](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/wait-0000001050170847)和[dispatch_group_notify](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/notify-0000001050170845)。

一个典型的示例如下：

```screen
#创建组任务
dispatch_group_t grp = dispatch_group_create();
dispatch_queue_t q = dispatch_get_global_queue(QOS_CLASS_DEFAULT, 0);

#异步执行第一个组任务
dispatch_group_enter(grp);
dispatch_async(q, ^{
	data_processing();
	dispatch_group_leave(grp);
});

#异步执行第二个组任务
dispatch_group_enter(grp);
dispatch_async(q, ^{
	another_data_processing();
	dispatch_group_leave(grp);
});

#组任务已全部完成
dispatch_group_notify(grp, dispatch_get_main_queue(), ^{
	data_processing_done();
});
```

为了简化这类代码的书写（异步地提交一个任务并把任务与一个group关联），提供了[dispatch_group_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-0000001050170843)来代替上述写法。此时形式如下：

```screen
#异步执行第一个组任务
dispatch_group_async(grp, q, ^{ data_processing(); } );
#异步执行第二个组任务
dispatch_group_async(grp, q, ^{ another_data_processing(); } );
dispatch_group_notify(grp, dispatch_get_main_queue(), ^{ data_processing_done(); });
```

## API列表

|API|描述|
|:--------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------|
|[dispatch_group_create](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/create-0000001050168886)|创建一个空的group。|
|[dispatch_group_enter](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/enter-0000001050425193)|手动增加group中的任务计数。|
|[dispatch_group_leave](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/leave-0000001050283414)|手动减少group中的任务计数。|
|[dispatch_group_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-0000001050170843)|异步提交一个任务到目标队列上，并且把任务与指定的group关联。|
|[dispatch_group_async_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-f-0000001050168888)|[dispatch_group_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-0000001050170843)的_f版本。|
|[dispatch_group_notify](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/notify-0000001050170845)|当这个group的所有任务都执行完的时候（即group变空），此时再提交指定的任务到目标队列上执行。此函数立即返回。|
|[dispatch_group_notify_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/notify-f-0000001050168890)|[dispatch_group_notify](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/notify-0000001050170845)的_f版本。|
|[dispatch_group_wait](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/wait-0000001050170847)|同步地等待这个group上所有任务执行完成（即group为空），并指定超时时间。|
