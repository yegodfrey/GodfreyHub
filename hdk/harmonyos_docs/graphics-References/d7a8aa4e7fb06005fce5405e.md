# HcIndexBufferType

|Enum Info|
|:----------------------|
|用于指定index buffer中的数据类型。|

## Enum Value Summary

|Enum Value and Description|
|:---------------------------------------------------|
|HC_UNSIGNED_BYTE index buffer中的数据类型为unsigned byte。|
|HC_UNSIGNED_SHORT index buffer中的数据类型为unsigned short。|
|HC_UNSIGNED_INT index buffer中的数据类型为unsigned int。|
