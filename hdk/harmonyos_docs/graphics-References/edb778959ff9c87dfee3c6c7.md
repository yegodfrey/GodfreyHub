# ControllerStatus

## ControllerStatus

控制器连接状态，主动查询控制器当前状态。

|**Attribute**||
|:---------------------------|--------|
|ControllerStatusDisconnected|控制器已断开连接|
|ControllerStatusScanning|控制器正在扫描|
|ControllerStatusConnecting|控制器正在连接|
|ControllerStatusConnected|控制器已连接|
|ControllerStatusError|控制器状态错误|
