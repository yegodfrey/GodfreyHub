# HcBackfaceWinding

|Enum Info|
|:------------------|
|定义三角形的背面和顶点环绕方向的关系。|

## Enum Value Summary

|Enum Value and Description|
|:-------------------------|
|HC_CW 表示顺时针方向为三角形背面。|
|HC_CCW 表示逆时针方向为三角形背面。|
|HC_NONE 表示不做面剔除。|
