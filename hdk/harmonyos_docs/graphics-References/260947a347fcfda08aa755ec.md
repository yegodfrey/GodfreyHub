# traceRay

|Method|
|:---------------------------------------------------------------------------------|
|void traceRay(in Ray ray, in uint rayFlags, inout HitInfo hit) shader中使用，返回光线求交结果。|

**Parameters**

|Name|Description|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
|ray|光线信息，包括起点、方向。|
|rayFlags|求交的标志位，对应取值详见[TraceRayFlag](https://developer.huawei.com/consumer/cn/doc/graphics-References/rt-core-tracerayflag-0000001086915948)。|
|hit|求交结果。|
