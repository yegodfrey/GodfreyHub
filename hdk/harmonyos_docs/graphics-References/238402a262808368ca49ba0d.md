# ARLightEstimate

|Class Info|
|:----------------------------------------------------|
|public class ARLightEstimate 用于表示AR Engine对当前环境光照的估计。|

|float[]|[getPrimaryLightDirection](#section299911551309)() 获取主光源方向。AR Engine Server 3.15及以后版本可用。|

|Method|
|:-------------------------------------------------------------|

**Returns**

|Type|Description|
