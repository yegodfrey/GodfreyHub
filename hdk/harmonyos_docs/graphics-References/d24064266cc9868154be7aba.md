# dispatch_sync

## 功能描述

提交一个任务，同步执行（此函数当提交的任务执行完毕后才返回）。

## 函数原型

```screen
void dispatch_sync(dispatch_queue_t queue, dispatch_block_t block);
```

## 参数

|名称|类型|描述|
|:----|:---------------|:---------|
|queue|dispatch_queue_t|目标队列。|
|block|dispatch_block_t|要提交的block。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
