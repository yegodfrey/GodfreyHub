# TakeScreenshotListener

|Interface Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------|
|public interface TakeScreenshotListener ARFaceView场景中获取组件位图的监听接口，有[onSuccess](#section0838193818508)()和[onFailure](#section266511520815)()两个方法。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------------|
|void|[onFailure](#section266511520815)() 无法获取位图。|
|void|[onSuccess](#section0838193818508)(Bitmap bitmap) XRKit服务单场景组件位图获取成功后会调用此接口。|

## Public Methods

### onFailure

|Method|
|:-----------------------|
|void onFailure() 位图获取失败。|

### onSuccess

|Method|
|:-------------------------------------------------------|
|void onSuccess(Bitmap bitmap) XRKit服务单场景组件位图获取成功后会调用此接口。|

**Parameters**

|Name|Description|
|:-----|:------------|
|bitmap|场景组件所提供的位图实例。|
