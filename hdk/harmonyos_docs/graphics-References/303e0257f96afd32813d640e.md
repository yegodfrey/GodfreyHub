# AttachmentFlages

|Enum Info|
|:---------|
|确定附件的加载方式。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------------------------------------------------|
|NONE_ATTACHMENT = 0x0u 不清除附件。|
|COLOR0 = 0x00000001u 清除COLOR0附件。|
|COLOR1 = 0x00000002u 清除COLOR1附件。|
|COLOR2 = 0x00000004u 清除COLOR2附件。|
|COLOR3 = 0x00000008u 清除COLOR3附件。|
|COLOR4 = 0x00000010u 清除COLOR4附件。|
|COLOR5 = 0x00000020u 清除COLOR5附件。|
|COLOR6 = 0x00000040u 清除COLOR6附件。|
|COLOR7 = 0x00000080u 清除COLOR7附件。|
|COLOR_ALL= COLOR0 | COLOR1 | COLOR2 | COLOR3 | COLOR4 | COLOR5 | COLOR6 | COLOR7 清除所有COLOR附件。|
|DEPTH_STENCIL = 0x00000100u 清除深度模板附件。|
|ALL = COLOR_ALL | DEPTH_STENCIL 清除所有附件。|
