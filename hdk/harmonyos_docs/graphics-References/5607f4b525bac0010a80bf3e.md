# ModifyFaceParas

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int ModifyFaceParas(const float modifyDegree, [GeneratedParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/generatedparas-0000001134825080)& genParas) 根据设置的美观度，生成调整后的捏脸参数。|

**Parameters**

|Name|Description|
|:-----------|:--------------------------------------------------|
|modifyDegree|捏脸美观度参数，取值范围为[0, 1]。|
|genParas|美观度调整后的捏脸参数数据结构体，包含捏脸连续值参数、捏脸离散值参数、融合真实感照片纹理的游戏纹理图。|

**Returns**

|Type|Description|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|返回接口调用结果标志位。 * 0：成功。 * 非0：失败，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/error-code-0000001061725148#section965820932815)。|
