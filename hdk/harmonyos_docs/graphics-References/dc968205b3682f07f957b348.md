# StencilOperation

|Enum Info|
|:--------|
|模板操作测试枚举。|

## Enum Value Summary

|Enum Value and Description|
|:----------------------------------------------------------|
|STENCIL_OPERATION_KEEP 保持当前值。|
|STENCIL_OPERATION_ZERO 将值设置为0。|
|STENCIL_OPERATION_REPLACE 将值设置为模板参考值。|
|STENCIL_OPERATION_INCREMENT_AND_CLAMP 将当前值递增并增到最大，可表示无符号值。|
|STENCIL_OPERATION_DECREMENT_AND_CLAMP 递减当前值并减少到0。|
|STENCIL_OPERATION_INVERT 按位反转当前值。|
|STENCIL_OPERATION_INCREMENT_AND_WRAP 递增当前值，并在超过最大值时换为0。|
|STENCIL_OPERATION_DECREMENT_AND_WRAP 递减当前值，并在低于0时转换到可能的最大值。|
