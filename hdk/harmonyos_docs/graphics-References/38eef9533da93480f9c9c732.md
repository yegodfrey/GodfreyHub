# TextureUsage

|Enum Info|
|:--------|
|指定图像用途枚举。|

## Enum Value Summary

|Enum Value and Description|
|:------------------------------------|
|TEXTURE_USAGE_NONE 未操作。|
|TEXTURE_USAGE_SAMPLED 可用于采样器命令。|
|TEXTURE_USAGE_RENDERTARGET 可用于渲染目标命令。|
|TEXTURE_USAGE_DEPTHSTENCIL 可用于深度模板命令。|
|TEXTURE_USAGE_DEPTH 可用于深度命令。|
|TEXTURE_USAGE_TRANSFER_DST 可用于转移命令。|
