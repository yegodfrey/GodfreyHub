# ARSession.EnvironmentTextureUpdateMode

|Enum Info|
|:------------------------------------------------------------------------------|
|public enum EnvironmentTextureUpdateMode 环境纹理更新模式。AR Engine Server 3.15及以后版本可用。|

## Enum Value Summary

|Enum Value and Description|
|:----------------------------------------------|
|UNKNOWN(-1) 异常环境纹理更新模式。|
|AUTO(0) 自动更新模式。|
|UPDATE_ONE_TIME(1) 手动更新模式。更新模式只针对上半部分预测出来的环境纹理。|
