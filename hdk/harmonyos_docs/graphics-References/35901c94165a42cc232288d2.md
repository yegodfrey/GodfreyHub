# AREnginesSelector

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250409111411.75008886574801889896577072027055:50001231000000:2800:75388C6D5BAA89D9F2A8E22FF8CF396CAED83CC7612C2DF7B242DBD285978E23.png)  
该类已废弃，目前只支持AR Engine，不支持切换。  

|Class Info|
|:--------------------------------------------------------------------------------------------|
|public class AREnginesSelector 用于查询设备支持的AR引擎，并设置应用使用的引擎。如果应用不需要切换引擎，可以直接略过该类，默认的引擎为AR Engine。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[AREnginesAvaliblity](https://developer.huawei.com/consumer/cn/doc/graphics-References/ar_engines_avaliblity-0000001050162182)|[checkAllAvailableEngines](#section18116174210540)(Context context) 注意： 该方法已废弃，获取本终端所支持的引擎的类型。|
|AREnginesType|[setAREngine](#section17316132125517)(AREnginesType enginesType) 注意： 该方法已废弃，设置要使用的引擎，返回值为设置的引擎类型。注意： 1. 由于设备的能力差异，如果设置的引擎在设备上不支持，返回的实际使用的引擎会与指定值不相同。 2. [setAREngine](#section17316132125517)()前必须调用[checkAllAvailableEngines](#section18116174210540)()检查当前支持的AR Engine类型。|
|AREnginesType|[getCreatedEngine](#section362015133553)() 注意： 该方法已废弃，获取目前使用的引擎类型。|
