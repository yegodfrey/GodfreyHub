# AttachmentTextureType

|Enum Info|
|:--------------------------------------------------|
|enum class AttachmentTextureType 指定保存DDGI渲染结果的图像类型。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------------|
|DDGI_IRRADIANCE DDGI渲染的图像保存相机视角的Irradiance结果。|
|DDGI_RELOCATION DDGI渲染的图像保存调整探针摆放位置的偏移值。|
|DDGI_NORMAL_DEPTH DDGI渲染的图像保存法线、深度值，前3维是法线值，第4维为深度值。|
|DDGI_PROBE_IRRADIANCE DDGI渲染的图像保存探针的Irradiance结果。保留，暂不使用。|
|DDGI_PROBE_DISTANCE DDGI渲染的图像保存探针的distance值。保留，暂不使用。|

> 注意
>
> 当前版本DDGI不支持输出探针的结果，因此DDGI_PROBE_IRRADIANCE、DDGI_PROBE_DISTANCE暂时不使用。
