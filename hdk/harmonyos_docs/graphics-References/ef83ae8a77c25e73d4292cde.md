# Overview

AR Engine SDK提供对外接口，用于指导开发者使用AR Engine相关服务构建AR应用。

## Interface Summary

|Interface|Description|
|:-------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------|
|[ARTrackable](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable-0000001050121431)|被AR Engine识别的真实物体信息描述接口类。|
|[FaceHealthServiceListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/health-service-listener-0000001059997121)|健康检测事件监听接口，用于向应用传递健康检测状态和进度等信息。|
|[ServiceListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/service-listener-0000001060810054)|事件监听接口，应用实现相应的接口以后，SDK通过回调的方式向应用通知AR Engine相关事件。|
