# CharacterStateInfo

|Struct Info|
|:--------------------------------------|
|struct CharacterStateInfo 当前帧角色状态相关的数据。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|bool|isJump 是否跳跃。 * true：跳跃。 * false：不跳跃。|
|float|jumpTime 跳跃的时长，单位：秒。|
|int|state 当前游戏角色的状态，如站立、走、跑、跳跃，具体类型请参见[CharacterState](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/characterstate-0000001110653856)。|
