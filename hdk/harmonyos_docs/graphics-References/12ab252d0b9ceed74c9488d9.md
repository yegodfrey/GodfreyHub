# VkContext

|Struct Info|
|:---------------------------------|

|Qualifier and Type|Field and Description|
|:-----------------|:---------------------------------------|
|VkCommandBuffer|cmdBuffer 开发者创建的命令缓存，默认值VK_NULL_HANDLE。|
|VkRenderPass|renderpass 开发者创建的渲染通路，默认值VK_NULL_HANDLE。|
