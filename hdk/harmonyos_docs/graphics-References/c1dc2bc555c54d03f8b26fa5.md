# dispatch_queue_get_qos_class

## 功能描述

返回某个queue的QoS class和relative_priority。对于global queue，relative_priority为0；对于使用者创建的但是创建时候未使用[dispatch_queue_attr_make_with_qos_class](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/attr-make-with-qos-class-0000001050168788)声明的，则返回QOS_CLASS_UNSPECIFIED且relative priority 0。

## 函数原型

```screen
dispatch_qos_class_t dispatch_queue_get_qos_class(dispatch_queue_t queue, int *relative_priority_ptr);
```

## 参数

|名称|类型|描述|
|:--------------------|:---------------|:------------------------------------------------------------------|
|queue|dispatch_queue_t|要查询的某个queue。|
|relative_priority_ptr|int *|一个int变量的地址，或NULL，用于获得这个QoS class的relative_priority值。传入NULL则不去获取这个值。|

## 返回

|类型|描述|
|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|dispatch_qos_class_t|返回QoS class value。可能的值为：QOS_CLASS_USER_INTERACTIVE，QOS_CLASS_USER_INITIATED，QOS_CLASS_DEFAULT，QOS_CLASS_UTILITY，QOS_CLASS_BACKGROUND，QOS_CLASS_UNSPECIFIED。|
