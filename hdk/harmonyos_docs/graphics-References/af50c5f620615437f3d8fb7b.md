# GetAccelerometer (Not Supported)

获取当前控制器的加速度计数据。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-----------------|:------------------------------------|
|accelerometer|Vector3|将当前控制器加速度计的位置向量(x,y,z)写入accelerometer|

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
if (null == controller) {
    Debug.LogError("Controller is null");
} else {
    Vector3 accelerometer = new Vector3();
    int ret = controller.GetAccelerometer(ref accelerometer);
    if (ret == 0) {
        Debug.Log("Get controller accelerometer success!");
    } else {
        Debug.Log("Get controller accelerometer failed!");
    }
}
```
