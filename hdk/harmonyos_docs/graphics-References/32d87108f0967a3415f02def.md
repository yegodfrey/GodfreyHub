# dispatch_async_f

## 功能描述

[dispatch_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-0000001050168872)的_f版本。

在multithread-lib所有包含任务参数的接口中，都会同时有一个block版本和function版本表征对两种不同任务形式一并支持。在函数名上即同一个功能会有不带_f后缀和带_f后缀的两个版本，除了任务的声明形式不同外其它没有任何区别。

block版本接受一个block变量表示任务，function版本则接受两个变量，第一个变量是函数参数，第二个变量是函数指针。

## 函数原型

```screen
void dispatch_async_f(dispatch_queue_t queue, void *context, dispatch_function_t work);
```

## 参数

|名称|类型|描述|
|:------|:------------------|:-----------------------------|
|queue|dispatch_queue_t|目标队列。|
|context|void *|使用者定义的将要传给work的参数。|
|work|dispatch_function_t|使用者定义的函数，在执行的时候会接收context作为参数。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
