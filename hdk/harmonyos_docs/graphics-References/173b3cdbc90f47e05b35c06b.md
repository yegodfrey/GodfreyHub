# HwArLightEstimationMode

|Enum Info|
|:--------|
|光照估计模式。|

## Enum Value Summary

|Enum Name|
|:-------------------------------------------------------------------------------------------|
|HWAR_LIGHT_ESTIMATION_MODE_DISABLED 关闭光照估计，取值为0。|
|HWAR_LIGHT_ESTIMATION_MODE_AMBIENT_INTENSITY 开启光照估计，HwArFrame_getLightEstimate()返回环境光强，取值为1。|
|HwAr_LIGHT_ESTIMATION_MODE_ENVIRONMENT_LIGHTING 开启环境光照估计，取值为2。|
|HwAr_LIGHT_ESTIMATION_MODE_ENVIRONMENT_TEXTURE 开启环境纹理光照估计，取值为4。|
