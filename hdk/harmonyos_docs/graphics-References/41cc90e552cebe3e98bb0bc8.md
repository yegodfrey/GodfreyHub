# ARTarget

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARTarget extends ARTrackableBase 用于扫描目标物体返回跟踪结果，包含目标物体的标签和形状，派生自[ARTrackableBase](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable_base-0000001050119508)。 目标语义识别标签类型可见[ARTarget.TargetLabel](https://developer.huawei.com/consumer/cn/doc/graphics-References/target_label-0000001179958731)，形状类型可见[ARTarget.TargetShapeType](https://developer.huawei.com/consumer/cn/doc/graphics-References/target_shape_type-0000001133839366)。 该类AR Engine Server 3.13及以后可用。|
