# ResourceType

|Enum Info|
|:---------------|
|根据资源内容定义的资源类型枚举。|

## Enum Value Summary

|Enum Value and Description|
|:----------------------------------|
|RESOURCE_TYPE_MODEL 模型资源。|
|RESOURCE_TYPE_TEXTURE 纹理资源。|
|RESOURCE_TYPE_MATERIAL_BASE 基础材质资源。|
|RESOURCE_TYPE_MATERIAL 材质资源。|
|RESOURCE_TYPE_GLTF GLTF资源。|
|RESOURCE_TYPE_GLB GLB资源。|
|RESOURCE_TYPE_SHADER 着色器资源。|
|RESOURCE_TYPE_MAX 枚举最大值，有效的枚举值小于该值。|
