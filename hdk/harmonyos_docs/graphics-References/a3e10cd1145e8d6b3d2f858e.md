# KeyAction

|Enum Info|
|:--------|
|按键事件类型枚举。|

## Enum Value Summary

|Enum Value and Description|
|:----------------------------------------------------|
|KEY_ACTION_DOWN 按下。|
|KEY_ACTION_UP 抬起。|
|KEY_ACTION_REPEAT 重复（长按）。|
|KEY_ACTION_UNKNOWN 未知的按键值。|
|KEY_ACTION_MAX = KEY_ACTION_UNKNOWN 枚举最大值，有效的枚举值小于该值。|
