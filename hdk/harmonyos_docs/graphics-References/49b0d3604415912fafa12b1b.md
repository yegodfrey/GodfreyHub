# CImageEnhancingSyncExecute

|Method|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|bool CImageEnhancingSyncExecute(const CGKit::BufferDescriptor *inBuffer, const CGKit::BufferDescriptor *outBuffer, float sharpenStrength, bool toneMapping, int timeOut) 通过同步方式调用离线超分插件的图像处理能力。|

**Parameters**

|Name|Description|
|:--------------|:-----------------|
|inBuffer|输入图像数据。|
|outBuffer|输出图像数据，内存由调用者预先分配。|
|sharpenStrength|锐化程度，取值范围为[0, 1]。|
|toneMapping|使能亮度调整，使能后画面亮度增强。|
|timeOut|运行时间上限。|

**Returns**

|Type|Description|
|:---|:-----------------------------------------|
|bool|* true：同步调用图像处理能力成功。 * false：同步调用图像处理能力失败。|
