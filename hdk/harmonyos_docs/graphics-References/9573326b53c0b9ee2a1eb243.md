# ARLightEstimate.LightShadowType

|Enum Info|
|:-------------------------------------------------------------------------------------------------------|
|public enum LightShadowType 阴影边缘形状类型(边缘锯齿或柔和)，底层有天气判别的算法，会根据不同天气给出不同阴影强度类型。AR Engine Server 3.15及以后版本可用。|

#### Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------------|
|SHDOW_TYPE_UNKNOW(-1) 异常阴影类型。|
|SHADOW_TYPE_NONE(0) 阴影类型为None，无阴影。|
|SHADOW_TYPE_HARD(1) 在阴影强度比较高情况下使用，像晴天场景下，阴影是很明显的。|
|SHADOW_TYPE_SOFT(2) 在阴影强度比较低的情况下使用，像在阴天/室内/夜晚场景中，比较柔和的阴影。|
|SHADOW_TYPE_END(3) 注意： 该枚举暂未使用。|
