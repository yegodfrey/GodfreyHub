# GetBatteryLevel

获取控制器电量值。

## Return Values

调用函数成功返回控制器电量值，失败返回-1。

## Examples

```screen
if (null == controller) {
    Debug.LogError("Controller is null");
} else {
    int batteryLevel = controller.GetBatteryLevel();
}
```
