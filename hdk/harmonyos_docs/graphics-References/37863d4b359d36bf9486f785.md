# ResetYaw

姿态重置偏航角。通常用于如下情况：当远离VR头盔，手机屏幕熄灭，再次佩戴头盔，点亮屏幕时，画面可能会发生视角偏离。

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
//Reset the yaw angle.
if(helmetHandle.ResetYaw() == 0){
    Debug.Log("Reset Yaw Success!");
} else {
    Debug.Log("Reset Yaw Failed!");
}
```
