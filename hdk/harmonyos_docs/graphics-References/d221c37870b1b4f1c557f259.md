# ImageUsageFlagBits

|Enum Info|
|:-----------|
|指定图像的使用标志枚举。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------------------------------|
|IMAGE_USAGE_TRANSFER_SRC_BIT = 0x00000001 指定图像可以用作传输源图像命令。|
|IMAGE_USAGE_TRANSFER_DST_BIT = 0x00000002 指定图像可以用作传输目的图像命令。|
|IMAGE_USAGE_SAMPLED_BIT = 0x00000004 可用于combined类和采样类的描述符。|
|IMAGE_USAGE_STORAGE_BIT = 0x00000008 可用于storage类的描述符。|
|IMAGE_USAGE_COLOR_ATTACHMENT_BIT = 0x00000010 创建视图时使用的帧缓存中的颜色附件。|
|IMAGE_USAGE_DEPTH_STENCIL_ATTACHMENT_BIT = 0x00000020 创建视图时使用的帧缓存中的深度/模板附件。|
|IMAGE_USAGE_TRANSIENT_ATTACHMENT_BIT = 0x00000040 创建视图时使用的颜色、深度/模板、输入附件。|
|IMAGE_USAGE_INPUT_ATTACHMENT_BIT = 0x00000080 从shader中读取，并用于帧缓存的输入附件。|
|IMAGE_USAGE_SHADING_RATE_IMAGE_BIT_NV = 0x00000100 创建适用于片段密度图的视图图像。|
|IMAGE_USAGE_FLAG_BITS_MAX_ENUM = 0x7FFFFFFF 创建用于着色率附件或着色率图像的视图。|
