# HwArSession

|Module Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|用于管理AR Engine的整个运行状态，是AR Engine运行的基础，启动HwArSession前，使用[HwArSession_configure](#section191031942143319)设置相关配置，通过HwArSession可以实现： * 控制AR Engine的启动、暂停、结束等行为。 * 更新并获取AR Engine内部数据，如：锚点、平面、可跟踪对象等。|
