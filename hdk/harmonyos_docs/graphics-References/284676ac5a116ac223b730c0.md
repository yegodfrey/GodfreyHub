# dispatch_sync_f

## 功能描述

[dispatch_sync](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sync-0000001050168874)的_f版本。

## 函数原型

```screen
void dispatch_sync_f(dispatch_queue_t queue, void *context, dispatch_function_t work);
```

## 参数

|名称|类型|描述|
|:------|:------------------|:-----------------------------|
|queue|dispatch_queue_t|目标队列。|
|context|void *|使用者定义的将要传给work的参数。|
|work|dispatch_function_t|使用者定义的函数，在执行的时候会接收context作为参数。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
