# HwArConfig

|Module Info|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|该模块提供配置session的功能，支持配置使用的能力类型，包括Body、Hand、World、Face、Image；支持设置前后置摄像头（CameraLensFacing）切换；支持设置光照模式、平面查找模式、Session的Update模式、省电模式、聚焦模式、手部查找模式、平面语义模式；支持设置使能项，如深度、人体虚实遮挡等；支持配置图像流输入模式（Server内部打开相机或应用打开相机）。 > 注意 > 在调用[HwArSession_configure](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_session-0000001060493634#section191031942143319)之前，任何HwArConfig_set*都不会实际影响Session。|
