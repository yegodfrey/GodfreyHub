# FenceFlag

|Enum Info|
|:---------------|
|指定Fence创建时的信号状态。|

## Enum Value Summary

|Enum Value and Description|
|:-----------------------------|
|FENCE_FLAG_INVALID 无信号状态。|
|FENCE_FLAG_SIGNALED 有信号状态。|
|FENCE_FLAG_MAX 最大值为0x7FFFFFFF。|
