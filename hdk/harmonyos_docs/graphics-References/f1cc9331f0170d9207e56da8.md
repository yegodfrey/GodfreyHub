# IsButtonNearTouch [For 6DoF]

判定控制器按键当前状态是否即将被触摸。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------|
|button|ButtonType 细节详见 [2.1.4.1](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/button-type-0000001160044960) "[ButtonType](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/button-type-0000001160044960)"|控制器按键的类型，ButtonType|

## Return Values

对应按键类型的按键当前状态，即将被触摸则返回true，否则返回false。
