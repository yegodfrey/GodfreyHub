# ARPointCloud

|Class Info|
|:--------------------------------------------------------|
|public class ARPointCloud 点云类，存储场景中的所有地图点，包含点的位置及其对应的置信度。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------|
|FloatBuffer|[getPoints](#section598133752213)() 获取点云中所有点的坐标x，y，z，以及置信度。数据格式为[x0,y0,z0,c0,x1,y1,z1,c1]。其坐标值都在世界坐标系下，使用右手坐标系表示。|
|long|[getTimestampNs](#section16226144672215)() 获取当前帧的时间戳，以纳秒为单位，从开机时间开始计算。|
|void|[release](#section867518542228)() 释放点云，使用完点云以后调用。|

## Public Methods

### getPoints

|Method|
|:-----------------------------------------------------------------------------------------------------------|
|public FloatBuffer getPoints() 获取点云中所有点的坐标x，y，z，以及置信度。数据格式为[x0,y0,z0,c0,x1,y1,z1,c1]。其坐标值都在世界坐标系下，使用右手坐标系表示。|

**Returns**

|Type|Description|
|:----------|:------------------------------------------|
|FloatBuffer|点云数据，数据格式[x0,y0,z0,c0, x1,y1,z1,c1]，c0为置信度。|

### getTimestampNs

|Method|
|:-------------------------------------------------------|
|public long getTimestampNs() 获取当前帧的时间戳，以纳秒为单位，从开机时间开始计算。|

**Returns**

|Type|Description|
|:---|:----------|
|long|当前特征点云的时间戳。|

### release

|Method|
|:------------------------------------|
|public void release() 释放点云，使用完点云以后调用。|
