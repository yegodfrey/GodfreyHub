# vkEnumerateDeviceExtensionProperties

## 接口定义

```screen
VkResult vkEnumerateDeviceExtensionProperties(VkPhysicalDevice physicalDevice, const char *pLayerName, uint32_t *pPropertyCount, VkExtensionProperties *pProperties)
```

## 功能介绍

查询设备支持的vulkan的扩展。

## 参数

|名称|类型|描述|
|:-------------|:-|:------------------------|
|physicalDevice|句柄|给定硬件平台上可用的物理设备的句柄。|
|pLayerName|指针|为NULL或指向以空终止的UTF-8字符串的指针。|
|pPropertyCount|指针|指向与可用或查询的扩展属性数量有关的整数的指针。|
|pProperties|指针|为NULL或指向扩展属性结构数组的指针。|

## 返回

|值|描述|
|:----------------------------|:-------------|
|VK_SUCCESS|命令成功完成。|
|VK_INCOMPLETE|返回数组对于结果而言太小。|
|VK_ERROR_OUT_OF_HOST_MEMORY|主机内存分配失败。|
|VK_ERROR_OUT_OF_DEVICE_MEMORY|设备内存分配失败。|
|VK_ERROR_LAYER_NOT_PRESENT|请求的图层不存在或无法加载。|

## 调用示例

```screen
vkEnumerateDeviceExtensionProperties(pDevice, nullptr, &extensionCount, nullptr); 
```
