### RenderFogFrameTexture

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------|
|void RenderFogFrameTexture(void* FogTexHandle, int textureWidth, int textureHeight, int textureDepth) 进行体积雾的绘制渲染，将体积雾绘制在纹理FogTexHandle上。|

**Parameters**

|Name|Description|
|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|FogTexHandle|用于绘制的纹理内存。|
|textureWidth|纹理内存的宽度，最大宽度为300。（该值与[tileSize](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseparas-0000001156929855#ZH-CN_TOPIC_0000001156929855__p10165145335017)的乘积为屏幕像素宽）|
|textureHeight|纹理内存的高度，最大高度为300。（该值与[tileSize](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/baseparas-0000001156929855#ZH-CN_TOPIC_0000001156929855__p10165145335017)的乘积为屏幕像素高）|
|textureDepth|纹理内存的深度，最大深度为64。|
