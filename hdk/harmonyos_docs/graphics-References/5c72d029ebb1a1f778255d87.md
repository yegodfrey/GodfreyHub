# HwArFaceDetectMode

|Enum Info|
|:--------|
|人脸检测模式。|

## Enum Value Summary

|Enum Name|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|HwAr_HEALTH_ENABLE_HEART_RATE 健康检查心率，取值为0x01。|
|HwAr_HEALTH_ENABLE_BREATH_RATE 健康检查呼吸率，取值为0x02。|
|HwAr_HEALTH_ENABLE_LIVE_DETECTION 健康实时检测，取值为0x04。|
|HwAr_HEALTH_ENABLE_DEFAULT 默认健康检查模式，同时启用心率、呼吸率和实时监测模式，取值为HwAr_HEALTH_ENABLE_HEART_RATE | HwAr_HEALTH_ENABLE_BREATH_RATE | HwAr_HEALTH_ENABLE_LIVE_DETECTION。|
|HwAr_HEALTH_ENABLE_SP02 健康检查血氧饱和度，取值为0x08。|
|HwAr_HEALTH_ENABLE_STRESS 健康检查压力，取值为0x10。|
|HwAr_FACE_ENABLE_MESH 脸部标记为网格形状，取值为0x100。|
|HwAr_FACE_ENABLE_BLEND_SHAPE 脸部标记为混合形状，取值为0x200。|
|HwAr_FACE_ENABLE_DEFAULT 脸部标记为默认形状，取值为HwAr_FACE_ENABLE_MESH | HwAr_FACE_ENABLE_BLEND_SHAPE。|
|HwAr_FACE_ENABLE_MULTIFACE 多人脸检测，取值为0x800。|
