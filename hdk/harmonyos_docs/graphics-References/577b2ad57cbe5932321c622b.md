# ResetCenter

将当前位置和姿态复位到初始位置和姿态。通常用于画面姿态、位置都偏离的情况（重置位置暂不支持）。

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
//Reset the position and posture.
if(helmetHandle.ResetCenter() == 0){
    Debug.Log("Reset Center Success!");
} else {
    Debug.Log("Reset Center Failed!");
}
```
