# EnableSvsEffect (Not Supported)

**EnableSvsEffect (bool enable)** 函数用于开启EMUI系统的SVS音频效果。这个函数需要获取**android.permission.MODIFY_AUDIO_SETTINGS** 权限。

启用SVS音频效果后，应用程序中所有声音的位置会随着头部方向的变化而变化。该功能适用于虚拟现实中的视频观看。请注意开启时间，并及时关闭。

## Return Values

**固定返回0。**

## Examples

```screen
HvrApi.EnableSvsEffect(true);
```
