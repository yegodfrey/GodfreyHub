# DDGIDirectionalLight

|Struct Info|
|:-----------------------------------------------|
|DDGIDirectionalLight 方向光设置参数，包括ID、变换矩阵、颜色、方向和强度。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:--------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------|
|[CoordSystem](https://developer.huawei.com/consumer/cn/doc/graphics-References/ddgi-api-coordsystem-0000001309340053)|coordSystem 坐标系，目前仅支持右手坐标系。|
|int|lightId 光源索引的ID，目前仅支持1个方向光。|
|DDGI::Mat4f|localToWorld 从光源空间变换到世界空间的转换矩阵。|
|DDGI::Vec4f|color 光源的颜色，依次为RGB。第4维保留不使用。|
|DDGI::Vec4f|dirAndIntensity 光源的方向和强度，前3维表示光源照射向场景的方向，第4维表示光源强度。|
