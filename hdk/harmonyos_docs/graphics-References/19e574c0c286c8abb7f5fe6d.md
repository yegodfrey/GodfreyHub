# DynamicFlag

|Enum Info|
|:-----------------|
|管线渲染期间可以修改的动态状态枚举。|

## Enum Value Summary

|Enum Value and Description|
|:----------------------------------------------------------------|
|DYNAMIC_STATE_VIEWPORT = 1 指定视口可以在渲染过程中改变。|
|DYNAMIC_STATE_SCISSOR = 2 指定裁切可以在渲染过程中改变。|
|DYNAMIC_STATE_LINE_WIDTH = 4 指定线宽可以在渲染过程中改变。|
|DYNAMIC_STATE_BLEND_CONSTANTS = 8 指定混合常量可以在渲染过程中改变。|
|DYNAMIC_STATE_STENCIL_COMPARE_MASK = 16 指定模板测试的位掩码可以在渲染过程中改变。|
|DYNAMIC_STATE_STENCIL_REFERENCE = 32 指定模板测试的参考值可以在渲染过程中改变。|
|DYNAMIC_STATE_STENCIL_WRITE_MASK = 64 指定写入模板缓冲的位掩码可以在渲染过程中改变。|
|DYNAMIC_STATE_STENCIL_TEST_ENABLE_EXT = 128 指定是否启用模板缓冲可以在渲染过程中改变。|
|DYNAMIC_STATE_FLAG_MAX = 256 动态状态的最大值，表示枚举到此结束。|
