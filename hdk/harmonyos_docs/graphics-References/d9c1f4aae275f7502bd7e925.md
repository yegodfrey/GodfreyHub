# Overview

图形引擎服务离线简模插件，提供针对模型Mesh数据信息，对三角面片进行简模处理的功能。

## Interface Summary

|Interface|Description|
|:---------------------------------------------------------------------------------------------------------|:-----------------------------------|
|[SlimMesh](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-slimmesh-0000001071109885)|针对模型Mesh相关的数据信息，依据其拓扑结构，进行三角面片的简模处理。|

## Struct Summary

|Struct|Description|
|:---------------------------------------------------------------------------------------------------------|:-------------|
|[MeshInfo](https://developer.huawei.com/consumer/cn/doc/graphics-References/api-meshinfo-0000001071969954)|模型Mesh结构相关的信息。|
