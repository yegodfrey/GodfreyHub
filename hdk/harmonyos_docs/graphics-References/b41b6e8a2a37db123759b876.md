# DDGIMaterial

|Struct Info|
|:--------------------------------------|
|DDGIMaterial PBR材质数据，用于DDGI SDK内部PBR计算。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:----------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------|
|float|alphaCutoff 透明度因子，取值范围[0.0, 1.0]，0.0代表透明，1.0代表不透明，默认值1.0。|
|float|metallicFactor 金属度因子，取值范围[0.0, 1.0]，0.0代表非金属，1.0代表金属，默认值0.0。|
|float|roughnessFactor 粗糙度因子，取值范围[0.0, 1.0]，0.0代表光滑，1.0代表粗糙，默认值0.5。|
|DDGI::Vec4f|baseColorFactor 基础颜色因子，每维取值范围[0.0, 1.0]，Vec4f的前3维分别代表RGB，第4维保留，默认值Vec4f(1.0)。|
|DDGI::Vec4f|emissiveFactor 自发光颜色因子，每维取值范围[0.0, 1.0]，Vec4f的前3维分别代表RGB，第4维保留，默认值Vec4f(1.0)。该成员暂时无效。|
|[DDGIVulkanImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/ddgi-api-ddgivulkanimage-0000001259756944)|baseColorTexture 基础颜色贴图，贴图为空时表示该材质没有颜色贴图。贴图中每个像素为4通道，每通道取值范围[0.0, 1.0]，贴图每个像素的前3通道分别代表RGB，第4通道为透明度。|
|[DDGIVulkanImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/ddgi-api-ddgivulkanimage-0000001259756944)|metallicRoughnessTexture 金属度粗糙度贴图，贴图为空时表示该材质没有金属度粗糙度贴图。贴图中每个像素为4通道，每通道取值范围[0.0, 1.0]，第1个通道表示粗糙度，第2个通道表示金属度，3和4通道暂时无效。|

> 注意
>
> 材质中各个因子和贴图关系如下：
>
> 1、当材质没有贴图，仅使用各个因子时，这些因子的值就是对应材质系数。
>
> 2、当材质使用贴图时，各个因子作为缩放系数。例如metallicRoughnessTexture贴图中R通道roughness是0.5，而roughnessFactor是0.6，最终的roughness 为 0.5 * 0.6 = 0.3。其他同理。
