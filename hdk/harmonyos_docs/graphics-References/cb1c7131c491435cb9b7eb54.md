# 常量

|常量名|值|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|系统性能事件枚举常量： * CONNECTION_FAILURE kit失去连接。需要重启并依次调用DeletePerfGeniusHandle GetPerfGeniusApiHandle和Init。 * PERFORMANCE_UNLIMITED 频率不受限。 * PERFORMANCE_WARNING GPU/DDR/CPU等器件其中一个或几个已被限频。 * PERFORMANCE_LIMITED GPU、DDR、CPU等器件其中一个或几个频率已不能满足当前性能要求。 * PERFORMANCE_DEEP_LIMITED GPU/DDR/CPU等器件其中一个或几个已被严重限频。 * FRAME_RATE_INCONSISTENCE 帧率不匹配。游戏设置帧率与系统检测到的实际帧率不匹配，或系统帧率不支持。 * FRAME_RATE_LIMIT 帧率比用户设置值低。原因是温度过高或省电模式或场景变化等。 * FRAME_RATE_RESUME_TO_NORMAL 帧率恢复用户设置值。 * ENTER_POWER_SAVING_MODE 进入省电模式。 * EXIT_POWER_SAVING_MODE 退出省电模式。|enum SystemEvent : int { CONNECTION_FAILURE = -1, PERFORMANCE_UNLIMITED = 0, PERFORMANCE_WARNING = 1, PERFORMANCE_LIMITED = 2, PERFORMANCE_DEEP_LIMITED = 3, FRAME_RATE_INCONSISTENCE = 0x100, FRAME_RATE_LIMIT = 0x101, FRAME_RATE_RESUME_TO_NORMAL = 0x102, ENTER_POWER_SAVING_MODE = 0x200, EXIT_POWER_SAVING_MODE = 0x201, };|
|接口函数返回错误码枚举常量： * ERR_NO_ERROR 无异常。 * ERR_COMMON 一般异常。 * ERR_INVALID_PARAM 参数异常。 * ERR_INNER_MODULE_FAIL 内部模块异常。 * ERR_SOCKET_FAIL socket异常。 * ERR_TOO_MANY_COMMANDS 命令过多异常。 * ERRCODE_MAX 错误码枚举最大值。|enum ErrorCode : int { ERR_NO_ERROR = 0, ERR_COMMON = 1, ERR_INVALID_PARAM = 2, ERR_INNER_MODULE_FAIL = 3, ERR_SOCKET_FAIL = 4, ERR_TOO_MANY_COMMANDS = 5, ERRCODE_MAX, };|
|其他常量： * MAX_BOOST_TIME 最大boost持续时间。 * MAX_PERFORMANCE_TRACER_SAMPLE_RATE 最大帧率值。|const uint32_t MAX_BOOST_TIME = 3000; static const int MAX_PERFORMANCE_TRACER_SAMPLE_RATE = 50;|
