# ARSceneMesh

|Class Info|
|:-----------------------------------------------------------------------------------------------------------|
|public class ARSceneMesh 用于环境Mesh跟踪时返回跟踪结果的环境识别信息，结果包括Mesh顶点坐标，三角形下标等。当前支持2.5米以内生成Mesh，在相机移动的情况下，支持Mesh动态刷新。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ShortBuffer|[getSceneDepth](#section1422712234318)() 获取环境Mesh当前帧对应优化后的深度图。 1. 和[acquireDepthImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/frame-0000001050121447#section2102300118)()获取传感器输出的原始深度图不同，[getSceneDepth](#section1422712234318)()深度图是不含空洞的且对边缘做了优化的深度图，支持使用该深度图进行2.5米以内的虚实遮挡，深度图的单位为毫米。 2. 在渲染引擎中，可以通过调用[acquireDepthImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/frame-0000001050121447#section2102300118)()接口得到场景的深度图（注意：根据需要把深度图缩放到彩色图相同分辨率），通过和虚拟物体的深度值做对比，从而判断每个像素是显示虚拟物体还是真实场景的彩色像素值。|
|int|[getSceneDepthHeight](#section1996413273113)() 获取深度图的高。|
|int|[getSceneDepthWidth](#section13845458312)() 获取深度图的宽。|
|IntBuffer|[getTriangleIndices](#section17899981327)() 返回当前视角下环境Mesh三角面片顶点索引的数组，和getVertices()的顶点对应，返回的数据格式为face_0_index0，face_0_index1，face_0_index2，face_1_index0，face_1_index1，face_1_index2...，可在渲染引擎中使用。|
|FloatBuffer|[getVertexNormals](#section126891913326)() 获取当前视角下环境Mesh顶点法向量顶点信息，和[getVertices](#section387615773117)()的顶点对应，返回数组的形式为nx0,ny0,nz0,nx1,ny1,nz1,...。|
|FloatBuffer|[getVertices](#section387615773117)() 返回当前视角下环境Mesh顶点坐标数组，这些顶点是在世界坐标系下，在开发应用时可以将多帧的顶点直接融合得到更多更大视野下的Mesh顶点。每个顶点由float型的x，y，z构成，返回数据中数据的构成形式为x0，y0，z0，x1，y1，z1...，可在渲染引擎中使用。|
|void|[release](#section1455642818326)() 释放[ARSceneMesh](https://developer.huawei.com/consumer/cn/doc/graphics-References/scene_mesh-0000001050119506)占用的资源，在不需要使用[ARSceneMesh](https://developer.huawei.com/consumer/cn/doc/graphics-References/scene_mesh-0000001050119506)对象后调用，否则会导致内存泄露。|

## Public Methods

### getSceneDepth

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public ShortBuffer getSceneDepth() 获取环境Mesh当前帧对应优化后的深度图。 1. 和[acquireDepthImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/frame-0000001050121447#section2102300118)()获取传感器输出的原始深度图不同，[getSceneDepth](#section1422712234318)()深度图是不含空洞的且对边缘做了优化的深度图，支持使用该深度图进行2.5米以内的虚实遮挡，深度图的单位为毫米。 2. 在渲染引擎中，可以通过调用[acquireDepthImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/frame-0000001050121447#section2102300118)()接口得到场景的深度图（注意：根据需要把深度图缩放到彩色图相同分辨率），通过和虚拟物体的深度值做对比，从而判断每个像素是显示虚拟物体还是真实场景的彩色像素值。|

**Throws**

|Name|Description|
|:--------------------------------------------------------------------------------------------------------------------|:--------------------|
|[ARFatalException](https://developer.huawei.com/consumer/cn/doc/graphics-References/fatal_exception-0000001050162194)|致命错误，session没创建或已经释放。|

**Returns**

|Type|Description|
|:----------|:----------|
|ShortBuffer|深度图信息。|

### getTriangleIndices

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public IntBuffer getTriangleIndices() 返回当前视角下环境Mesh三角面片顶点索引的数组，和getVertices()的顶点对应，返回的数据格式为face_0_index0，face_0_index1，face_0_index2，face_1_index0，face_1_index1，face_1_index2...，可在渲染引擎中使用。|

### getVertexNormals

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------|
|public FloatBuffer getVertexNormals() 获取当前视角下环境Mesh顶点法向量顶点信息，和[getVertices](#section387615773117)()的顶点对应，返回数组的形式为nx0,ny0,nz0,nx1,ny1,nz1,...。|

**Returns**

|Type|Description|
|:----------|:----------|
|FloatBuffer|顶点法向量信息。|

### getVertices

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public FloatBuffer getVertices() 返回当前视角下环境Mesh顶点坐标数组，这些顶点是在世界坐标系下，在开发应用时可以将多帧的顶点直接融合得到更多更大视野下的Mesh顶点。每个顶点由float型的x，y，z构成，返回数据中数据的构成形式为x0，y0，z0，x1，y1，z1...，可在渲染引擎中使用。|

**Returns**

|Type|Description|
|:----------|:------------|
|FloatBuffer|环境Mesh顶点坐标数组。|
