# AABB

|Class Info|
|:---------------------------------------------------------------------|
|class AABB 描述网格包围盒的类，包围盒为一个立方体。包括包围盒对象间的赋值、比较，获取包围盒最小、最大坐标、中心点坐标、角坐标等。|
