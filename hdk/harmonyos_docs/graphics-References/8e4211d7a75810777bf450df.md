# CloudServiceState

|Enum Info|
|:---------------------------------------------------------------------------------------------------------------|
|public enum CloudServiceState 云服务状态码，服务器识别客户端上传的图片信息或物体模型后对客户端返回状态码，用于表明本次3D云识别结果。该枚举AR Engine Server 3.11及以后可用。|

#### Enum Value Summary

|Enum Value and Description|
|:------------------------------------------------------------------------|
|CLOUD_SERVICE_NORMAL(10000) 云服务状态正常。|
|CLOUD_SERVICE_ERROR_NETWORK_UNAVAILABLE(10001) 云服务错误，网络不可用。|
|CLOUD_SERVICE_ERROR_CLOUD_SERVICE_UNAVAILABLE(10002) 云服务错误，云端服务不可用。|
|CLOUD_SERVICE_ERROR_NOT_AUTHORIZED(10003) 云服务错误，未授权。|
|CLOUD_SERVICE_ERROR_SERVER_VERSION_TOO_OLD(10004) 云服务错误，云服务版本太旧，或云服务响应错误。|
|CLOUD_SERVICE_ERROR_TIME_EXHAUSTED(10005) 云服务错误，会话超时。|
|CLOUD_SERVICE_ERROR_INTERNAL(10006) 云服务错误，云服务库无效。|
|CLOUD_IMAGE_ERROR_IMAGE_GALLERY_INVALID(20001) 云图片错误，图片库无效。|
|CLOUD_IMAGE_ERROR_IMAGE_RECOGNIZE_FAILE(20002) 云图片错误，图片识别失败。|
|CLOUD_OBJECT_ERROR_OBJECT_MODEL_INVALID(30001) 物体错误，对象无效。|
|CLOUD_OBJECT_ERROR_OBJECT_RECOGNIZE_FAILE(30002) 物体错误，识别失败。|
