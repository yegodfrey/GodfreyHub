# ResetOrientation

陀螺仪传感器姿态复位到初始姿态。通常用于画面姿态发生偏离的情况。

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
//Reset the posture.
if(helmetHandle.ResetOrientation() == 0){
    Debug.Log("Reset orientation Success!");
} else {
    Debug.Log("Reset orientation Failed!");
}
```
