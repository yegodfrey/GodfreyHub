# HitDistancePrimitiveCoordinates

|Struct Info|
|:--------------------------------------------------------------------------|
|HitDistancePrimitiveCoordinates 交点信息，包含光线原点与交点的距离、相交的三角形编号、光线和三角形交点的u, v参数。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-----------------------------|
|float|t 光线原点和交点的距离，t\>0表示相交，否则表示不相交。|
|uint32_t|primId 相交的三角形编号。|
|float|u 交点坐标参数u。|
|float|v 交点坐标参数v。|

交点坐标通过u，v计算：

交点坐标 = (1 - u - v) \* v0 + u \* v1 + v \* v2

v0、v1、v2为相交三角形的顶点坐标。
