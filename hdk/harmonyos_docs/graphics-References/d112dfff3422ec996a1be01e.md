# MemoryPropertyFlagBits

|Enum Info|
|:--------|
|内存的类型。|

## Enum Value Summary

|Enum Value and Description|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|MEMORY_PROPERTY_DEVICE_LOCAL_BIT = 0x00000001 设备访问最有效内存类型。|
|MEMORY_PROPERTY_HOST_VISIBLE_BIT = 0x00000002 可以用MapMemory映射的内存类型。|
|MEMORY_PROPERTY_HOST_COHERENT_BIT = 0x00000004 可以统一刷新的主机内存类型。|
|MEMORY_PROPERTY_HOST_CACHED_BIT = 0x00000008 可以被缓存在主机上的内存类型，比未缓存在主机的内存访问要快。但未缓存的内存是连续的。|
|MEMORY_PROPERTY_LAZILY_ALLOCATED_BIT = 0x00000010 允许设备访问的内存类型，但不能和MEMORY_PROPERTY_HOST_VISIBLE_BIT 同时使用。|
|MEMORY_PROPERTY_PROTECTED_BIT = 0x00000020 只允许设备访问和受保护的队列操作访问内存，内存类型不得和MEMORY_PROPERTY_HOST_VISIBLE_BIT 、MEMORY_PROPERTY_HOST_COHERENT_BIT 或MEMORY_PROPERTY_HOST_CACHED_BIT 一起设置。|
|MEMORY_PROPERTY_FLAG_BITS_MAX_ENUM = 0x7FFFFFFF 最大值。|
