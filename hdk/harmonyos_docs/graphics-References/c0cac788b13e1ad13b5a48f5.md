# 概述

|API|描述|
|:----------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|[dispatch_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-0000001050168872)|提交一个任务，异步执行（调用者立即返回不等待任务执行完成）。|
|[dispatch_async_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-f-0000001050170829)|[dispatch_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/async-0000001050168872)的_f版本。|
|[dispatch_sync](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sync-0000001050168874)|提交一个任务，同步执行（此函数当提交的任务执行完毕后才返回）。|
|[dispatch_sync_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sync-f-0000001050170831)|[dispatch_sync](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sync-0000001050168874)的_f版本。|
|[dispatch_after](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/after-0000001050168876)|（异步地）提交一个任务到某个队列，在指定的时间执行。|
|[dispatch_after_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/after-f-0000001050170833)|[dispatch_after](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/after-0000001050168876)的_f版本。|

|[dispatch_walltime](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/walltime-0000001050170835)|类似[dispatch_time](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/time-0000001050168878)，但是时间系统使用墙上时间（walltime）。|
|[dispatch_once](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/once-0000001050168880)|（同步地）执行一个任务只一次。|
|[dispatch_once_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/once-f-0000001050168924)|[dispatch_once](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/once-0000001050168880)的_f版本。|
|[dispatch_apply](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/apply-0000001050170837)|（同步地）在指定队列重复执行多次某个任务。|
|[dispatch_apply_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/apply-f-0000001050168882)|[dispatch_apply](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/apply-0000001050170837)的_f版本。|
|[dispatch_barrier_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/barrier-async-0000001050170839)|异步地提交一个barrier任务到目标队列上。|
|[dispatch_barrier_async_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/barrier-async-f-0000001050168884)|[dispatch_barrier_async](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/barrier-async-0000001050170839)的_f版本。|
|[dispatch_barrier_sync](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/barrier-sync-0000001050168930)|同步地提交一个barrier任务到目标队列上。|
|[dispatch_barrier_sync_f](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/barrier-sync-f-0000001050170841)|[dispatch_barrier_sync](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/barrier-sync-0000001050168930)的_f版本。|
