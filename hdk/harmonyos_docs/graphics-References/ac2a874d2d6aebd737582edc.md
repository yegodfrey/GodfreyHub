# OnSurfaceReadyListener

|Interface Info|
|:--------------------------------------------------------------------------------------------------|
|public interface OnSurfaceReadyListener 若在ARFaceView场景中设置客户端打开相机，则需要使用此监听从服务端获取并向surface对象写入对应的图像流。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[onSurfaceReady](#section0838193818508)(List\<[IArFaceView.SurfaceType](https://developer.huawei.com/consumer/cn/doc/graphics-References/xrkit-enum-faceview-surfacetype-0000001064620627)\> typeList, List\<Surface\> surfaceList) XRKit服务端成功创建所需Surface（包括[PREVIEW](https://developer.huawei.com/consumer/cn/doc/graphics-References/xrkit-enum-faceview-surfacetype-0000001064620627#section18447152312816)、[VGA](https://developer.huawei.com/consumer/cn/doc/graphics-References/xrkit-enum-faceview-surfacetype-0000001064620627#section18447152312816)、[DEPTH](https://developer.huawei.com/consumer/cn/doc/graphics-References/xrkit-enum-faceview-surfacetype-0000001064620627#section18447152312816)、[METADATA](https://developer.huawei.com/consumer/cn/doc/graphics-References/xrkit-enum-faceview-surfacetype-0000001064620627#section18447152312816)）后会调用此方法，将Surface传入客户端用于打开相机。|
