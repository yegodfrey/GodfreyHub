# GetSensorInfo

获取当前头盔传感器数据、预测时间。

## Parameters

|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------|
|**Parameter Name**|**Parameter Type**|**Description**|
|sensor|SensorData 细节详见 [2.1.3.2](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099) "[SensorData](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099)."|将头盔的陀螺仪数据(x,y,z)写入sensor.gypo|
|sensor|SensorData 细节详见 [2.1.3.2](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099) "[SensorData](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099)."|将头盔的加速度计数据(x,y,z)写入 sensor.accel|
|sensor|SensorData 细节详见 [2.1.3.2](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099) "[SensorData](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099)."|将头盔的磁力计数据(x,y,z)写入 sensor.mag|
|sensor|SensorData 细节详见 [2.1.3.2](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099) "[SensorData](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/sensor-data-0000001205684099)."|将头盔的预测时间(单位：us)写入 sensor.predictTime|

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
SensorData sensor = new SensorData();
int ret = helmetHandle.GetSensorInfo(ref sensor); 
if (ret == 0) {
    Vector3 gypoDat;
    gypoDat = sensor.gypo; //This parameter is used to obtain the gyro data of the helmet.
} else {
    Debug.Log("Get VR glass SensorData failed!");
}
```
