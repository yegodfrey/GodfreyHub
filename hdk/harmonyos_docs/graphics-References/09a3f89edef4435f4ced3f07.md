# VolumeRenderParas

|Struct Info|
|:-------------------------------------------------|
|struct VolumeRenderParas 体积云渲染所需要的参数，包含相机位置、光照风速等。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:------------------------------------------------------------------------------------|
|int[2]|rayMarchSteps 长度为2的一维int型数组，表示rayMarch最小和最大步数，最小步数的范围为[20, 40]，最大步数的范围为[40, 80]。|
|int|downSample 渲染过程中downSample次数，只能取1或2。|
|float[3]|cloudBoxMinCoordinate 长度为3的一维float型数组，表示体积云box的最小世界坐标。|
|float[3]|cloudSize 长度为3的一维float型数组，表示体积云box的尺寸大小，最小值为[100, 100, 100]，最大值为[5000, 512, 5000]。|
|float[3]|shapeTiling 长度为3的一维float型数组，表示体积云形态的tiling值，最小值为[0.0, 0.0, 0.0]，最大值为[2.0, 10.0, 2.0]。|
|float|noiseTiling 体积云细节噪声的tiling值，范围为[0.0, 5.0]。|
|float|noiseIntensity 体积云细节噪声的强度值，范围为[0.0, 100.0]。|
|float|density 体积云的密度值，范围为[0.0, 10.0]。|
|float|sigmaExtinction 体积云直射光的吸收系数，范围为[0.0, 0.5]。|
|float|sigmaScattering 体积云直射光的散射系数，范围为[0.0, 0.5]。|
|float[3]|mainLightColor 长度为3的一维float型数组，表示体积云全局光照颜色RGB值，每个分量取值范围为[0.0, 1.0]。|
|float[3]|ambientLightColor 长度为3的一维float型数组，表示体积云环境光颜色RGB值，每个分量取值范围为[0.0, 1.0]。|
|float|mainLightIntensity 全局光照强度，范围为[0.0, 5.0]。|
|float|ambientLightIntensity 环境光照强度，范围为[0.0, 5.0]。|
|float|silverSpread 炫光强度，影响云的"金边"效果，范围为[0.0, 1.0]。|
|float|shadowStepSize 体积云阴影步长，范围为[0, 20]。|
|float[3]|detailWindStrength 长度为3的一维float型数组，细节移动的方向和强度，三个分量分别对应世界坐标系中的XYZ坐标轴，值越大表示在该方向上风速越大。|
|float[3]|shapeWindStrength 长度为3的一维float型数组，形态移动的方向和强度，三个分量分别对应世界坐标系中的XYZ坐标轴，值越大表示在该方向上风速越大。|
|float|timeSinceLevelLoad 从体积云渲染开始到当前帧的时间，单位：秒，用来根据风速确定当前帧云的形态。|
|float[3]|worldSpaceLightDirection 长度为3的一维float型数组，世界坐标系下平行光的方向向量。|
|float[3]|worldSpaceCameraPosition 长度为3的一维float型数组，世界坐标系下的相机坐标。|
|float|cameraClippingPlanesNear 裁剪空间的近平面到相机距离。|
|float|cameraClippingPlanesFar 裁剪空间的远平面到相机距离。|
|float[16]|camera2World 长度为16的一维float型数组，表示从相机坐标系到世界坐标系的转换矩阵，按行优先排列存储。|
|float[16]|world2Camera 长度为16的一维float型数组，表示从世界坐标系到相机坐标系的转换矩阵，按行优先排列存储。|
|float[16]|cameraProjection 长度为16的一维float型数组，相机投影矩阵，按行优先排列存储。|
|float[16]|cameraInvProjection 长度为16的一维float型数组，相机反投影矩阵，按行优先排列存储。|
|char[128]|noisePath 长度为128的一维char型数组，体积云细节噪声bin文件的路径。|
|char[128]|shapePath 长度为128的一维char型数组，表示体积云形状纹理的bin文件（烘焙的结果）的路径。|
