# TrackStatus

## TrackStatus

头盔跟踪状态，指示头部跟踪数据是否有效。

|**Attribute**||
|:---------|----------|
|Tracking|表示头盔跟踪数据有效|
|Untracking|表示头盔跟踪数据无效|
