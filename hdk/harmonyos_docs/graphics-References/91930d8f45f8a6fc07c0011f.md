# BufferType

|Enum Info|
|:----------------------------------------------|
|enum class BufferType 可以选择传递CPU类型的缓存或者GPU类型的缓存。|

#### Enum Value Summary

|Enum Value and Description|
|:---------------------------------------|
|CPU 缓存类型是CPU类型，需要传递内存地址。|
|GPU 缓存类型是GPU类型，需要传递vulkan中定义的VkBuffer句柄。|
