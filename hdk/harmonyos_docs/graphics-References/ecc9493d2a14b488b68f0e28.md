# ARHitResult

|Class Info|
|:---------------------------------------------------------------|
|public class ARHitResult 定义了射线（如以屏幕的点为起点的射线）与真实世界（如点云、平面等）的碰撞交点。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:---------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[ARAnchor](https://developer.huawei.com/consumer/cn/doc/graphics-References/anchor-0000001050119480)|[createAnchor](#section6321731121312)() 在碰撞命中位置创建一个新的锚点。|
|float|[getDistance](#section1916642101310)() 返回相机与碰撞点的距离，单位为米。|
|[ARPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/pose-0000001050121457)|[getHitPose](#section825615815142)() 获取交点的位姿，其平移向量是交点在世界坐标系的坐标，其旋转分量根据碰撞点的不同类型（与平面的交点、与点云的交点）而有不同的定义。 1. 当射线与平面碰撞时，局部坐标系为：X+垂直于射线，平行于跟踪平面；Y+是跟踪平面的法向量；Z+平行于平面，大致指向摄像头。 2. 当射线与点云中的点碰撞时，系统会尝试用点击区域的点云估计一个平面，如果[getOrientationMode](https://developer.huawei.com/consumer/cn/doc/graphics-References/point-0000001050121455#section1510151820223)()接口返回ESTIMATED_SURFACE_NORMAL，则X+垂直于射线，平行于跟踪平面，Y+是跟踪平面的法向量，Z+平行于平面，大致指向摄像头，如果返回INITIALIZED_TO_IDENTITY，则坐标的方向不会随平面的角度发生变化，X+垂直于射线且指向右侧（从设备的角度观察），Y+向上，Z+大致指向摄像头，具体参见[朝向模式定义](https://developer.huawei.com/consumer/cn/doc/graphics-References/orientation_mode-0000001050162190)。|
|[ARTrackable](https://developer.huawei.com/consumer/cn/doc/graphics-References/trackable-0000001050121431)|[getTrackable](#section6298221101519)() 返回被命中的可跟踪对象。|
