# dispatch_once

## 功能描述

（同步地）执行一个任务只一次。由predicate参数标识。通常用于在程序中做初始化。

示例：

```screen
void foo_init_once(void)
{
	static dispatch_once_t foo_init_pred;
	dispatch_once(&foo_init_pred, ^{
		// Initialize foo here.
	});
}
```

> 注意
>
> predicate变量维护了任务的执行状态，因此它必须定义在全局/静态的作用域，且初始值应为0。上面示例代码中在第一次调用foo_init_once之后，foo_init_pred变量会被自动置为已经执行完成的状态，从而以后dispatch_once(&foo_init_pred, ^{ ... })将跳过不再执行^{}中语句。

## 函数原型

```screen
void dispatch_once(dispatch_once_t *predicate, dispatch_block_t block);
```

## 参数

|名称|类型|描述|
|:--------|:----------------|:-------------------------------------------------------------------------------|
|predicate|dispatch_once_t *|指向一个dispatch_once_t的指针。这个dispatch_once_t用来标识任务是否完成过以及是否正在执行。需要定义在全局或静态区域且不应手动赋值。|
|block|dispatch_block_t|任务。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
