# dispatch_time

## 功能描述

创建一个dispatch_time_t变量在multithread-lib中使用，表征一个绝对时间。基于给定的另一个绝对时间加上一个相对时间偏移得到。

## 函数原型

```screen
dispatch_time_t dispatch_time(dispatch_time_t when, int64_t delta);
```

## 参数

|名称|类型|描述|
|:----|:--------------|:------------------------------|
|when|dispatch_time_t|基数时间。使用DISPATCH_TIME_NOW作为当前时间。|
|delta|int64_t|以纳秒为单位的相对时间，会被加在when上作为新的时间值。|

## 返回

|类型|描述|
|:--------------|:-------------------|
|dispatch_time_t|一个新的dispatch_time_t。|
