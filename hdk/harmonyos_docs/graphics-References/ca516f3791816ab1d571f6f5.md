# AIFaceModParas

|Struct Info|
|:--------------------------------------------------------|
|struct AIFaceModParas 照片捏脸所需要的参数，包含人脸照片信息、模型资源文件、捏脸效果参数等。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:---------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|landmarkMode 人脸特征点个数，目前只支持[68点](https://ibug.doc.ic.ac.uk/resources/facial-point-annotations/)或[276点](https://developer.huawei.com/consumer/cn/doc/development/hiai-Guides/facial-feature-detection-introduction-0000001054022505)。|
|std::vector\<float\>|landmarkData 人脸特征点坐标值，按照每个点X坐标和Y坐标的顺序存储的一维float型数组。|
|int|segmentImgW 背景分割后的人脸图像宽度，取值范围为\[200, 2048\]。|
|int|segmentImgH 背景分割后的人脸图像高度，取值范围为\[200, 2048\]。|
|std::vector\<unsigned char\>|segmentImg 人像分割图像，按照图像上每个像素RGB值的顺序存储的一维unsigned char型数组。|
|std::string|modAPath ModA.om的路径。|
|std::string|modBPath ModB.om的路径。|
|std::string|modCPath ModC.om的路径。|
|std::string|shapePath 人脸三维重建基库的文件路径。|
|std::string|characterPath 用户调用PC端角色模型适配功能自行生成的游戏角色模型资源文件路径。|
|int|characterGender 游戏角色模型性别。 * 1：男性 * 2：女性|
|int|enableRealTex 是否生成融合照片真实感纹理的游戏纹理图。 * 1：生成 * 2：不生成|
