# CornerType

|:-----------|

|CORNER_TYPE_FRONT_LEFT_TOP 包围盒的左前上方的角。|3|
|CORNER_TYPE_BACK_RIGHT_BOTTOM 包围盒的右后下方的角。|4|

|CORNER_TYPE_FRONT_RIGHT_BOTTOM 包围盒的右前下方的角。|6|
|CORNER_TYPE_FRONT_RIGHT_TOP 包围盒的右前上方的角。|7|
|CORNER_TYPE_MAX 枚举最大值。|-|
