# HwArSceneMesh

|Module Info|
|:----------------------------------------------------------------------------------|
|用于环境Mesh跟踪时返回跟踪结果的环境识别信息，结果包括Mesh顶点坐标，三角形下标等。当前支持2.5米以内生成Mesh，在相机移动的情况下，支持Mesh动态刷新。|

#### HwArSceneMesh_getSceneDepth

|Function|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HwArSceneMesh_getSceneDepth(const [HwArSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_session-0000001060385725) \*session, const [HwArSceneMesh](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_struct_scenemesh-0000001060363378) \*sceneMesh, const uint16_t \*\*data, uint32_t \*width, uint32_t \*heigth) 获取环境Mesh当前帧对应优化后的深度图。 * 与[HwArFrame_acquireDepthImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_frame-0000001060013671#section4662196143014)获取传感器输出的原始深度图不同，[HwArSceneMesh_getSceneDepth](#section48320251116)获取的深度图是不含空洞的且对边缘做了优化的深度图，支持使用该深度图进行2.5米以内的虚实遮挡，深度图的单位为毫米。 * 在渲染引擎中，可以通过调用[HwArFrame_acquireDepthImage](https://developer.huawei.com/consumer/cn/doc/graphics-References/ndk_frame-0000001060013671#section4662196143014)接口得到场景的深度图， 通过和虚拟物体的深度值做对比，从而判断每个像素是显示虚拟物体还是真实场景的彩色像素值。 注意： 根据需要把深度图缩放到彩色图相同分辨率。|

Parameters  

|Name|Description|
|:--------|:------------------------|
|session|与AR Engine服务交互的Session对象。|
|sceneMesh|SceneMesh对象。|
|data|深度图数据。|
|width|深度图的宽度，可以与高度相乘得到data的大小。|
|heigth|深度图的高度，可以与宽度相乘得到data的大小。|
