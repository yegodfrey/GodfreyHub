# BakeData

|Struct Info|
|:----------------------------------|
|struct BakeData 存储用于PC端离线烘焙的三维模型数据。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-----------------------------------------------------------------------|
|float*|vDatas 指针数组类型，该数组存储多个顶点的三维世界坐标，按照顶点顺序依次排序，例如[x1, y1, z1, x2, y2, z2...]。|
|int|vDatasLength 该值存储InputData.vDatas数组的长度，最大值为5000000。|
|float*|fDatas 指针数组类型，该数组存储多个组成三角面片的顶点列表，例如[1, 2, 3, 2, 3, 4...]。|
|int|fDatasLength 该值存储InputData.fDatas数组的长度，最大值为8000000。|
|float*|minBox 指针数组类型，该数组长度为3，存储烘焙的box空间XYZ轴世界坐标最小值。|
|float*|maxBox 指针数组类型，该数组长度为3，存储烘焙的box空间XYZ轴世界坐标最大值。|
|int*|volumeSize 指针数组类型，该数组长度为3，存储烘焙后的3D纹理尺寸，最大值为[256, 64, 256]，每个均需大于16。|
