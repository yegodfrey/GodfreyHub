# dispatch_main

## 功能描述

调用dispatch_main以使当前线程成为multithread-lib中特殊的主线程，并进入一个永不停止的循环去处理提交到主队列上的任务。

注意，此函数是永不返回的，在它之后的语句不会被执行到。

如果使用场景是用multithread-lib编译运行一个独立的可执行二进制程序，那么有的时候需要通过某种方式让程序暂时不要退出，从而异步提交到某个队列上的任务能够有时间被处理。此时可以在main()函数流程中调用dispatch_main()进入等待主队列上任务的循环。当所有任务处理结束，程序想要退出的时候，调用exit(0)即可。
> 说明
>
> 调用dispatch_main是使用主队列的必要条件。如果程序中不需要提交任务到主队列，那么dispatch_main可以调用，也可以不调用，这种情况如果需要让程序暂时不退出可以使用别的方法。这方面的详细信息请参见[GCD Tutorial](https://apple.github.io/swift-corelibs-libdispatch/tutorial/)中对Queues介绍的章节。

但是，如果是在Android环境的一个应用的JNI函数中使用multithread-lib，这种情况下进程本身是长久存在的，通常不需要特意让进程进入永不退出的循环。虽然在某个线程中调用dispatch_main()来充当主线程仍然是允许的，但是不推荐这种做法，更好的做法就是避免使用主队列。可以创建一个普通的串行队列代替主队列。

## 函数原型

```screen
void dispatch_main(void);
```

|类型|描述|
|:-|:--------|
