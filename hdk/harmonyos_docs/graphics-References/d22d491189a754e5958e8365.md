# CSuperSamplingSyncExecute

|Method|
|:--------------------------------------------------------------------------------------------------------------------------------------------------|
|bool CSuperSamplingSyncExecute(const CGKit::BufferDescriptor *inBuffer, const CGKit::BufferDescriptor *outBuffer, int timeOut) 通过同步方式调用离线超分插件的AI能力。|

**Parameters**

|Name|Description|
|:--------|:----------------------------|
|inBuffer|输入图像数据。|
|outBuffer|输出图像数据，内存由调用者预先分配。|
|timeOut|运行时间上限，设置范围[1, 10000]（单位：ms）。|

**Returns**

|Type|Description|
|:---|:-------------------------------------|
|bool|* true：同步调用AI能力成功。 * false：同步调用AI能力失败。|
