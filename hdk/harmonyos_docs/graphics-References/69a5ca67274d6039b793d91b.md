# IArSceneView

|Interface Info|
|:--------------------------------------------------------------------------|
|public interface IArSceneView AR展示场景组件，提供3D场景的模型呈现、AR场景真实环境识别与虚拟模型在真实环境的渲染。|

#### Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String|[URL_SCHEMA_ASSET](#section1254213477129) 传入应用内部文件路径所需添加的文件头，加载模型文件或背景文件时使用。 注意： 该常量已废弃，请使用[IXrKitFeature.URL_SCHEMA_ASSET](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-xrkit-feature-0000001065058380#section1254213477129)。|
|String|[URL_SCHEMA_STORAGE](#section175491019104815) 传入设备存储文件路径所需添加的文件头，加载模型或背景文件时使用。 注意： 该常量已废弃，请使用[IXrKitFeature.URL_SCHEMA_STORAGE](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-xrkit-feature-0000001065058380#section175491019104815)。|
