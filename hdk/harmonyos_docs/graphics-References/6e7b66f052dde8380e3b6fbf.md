# ASBuildMethod

|Enum Info|
|:------------------------------------------------|
|enum class ASBuildMethod 可以选择使用CPU或者GPU进行加速结构的构建。|

## Enum Value Summary

|Enum Value and Description|
|:-------------------------|
|SAH_CPU 使用CPU进行加速结构构建。|
|SAH_GPU 使用GPU进行加速结构构建。|

> 说明
>
> 当前版本不支持SAH_GPU标志。
