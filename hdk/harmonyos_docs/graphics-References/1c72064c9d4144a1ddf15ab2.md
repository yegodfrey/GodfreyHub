# GetRenderStatics

获取渲染相关统计信息（提交帧率、渲染帧率、渲染超时帧数等信息）。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------|
|renderStatics|RenderStatistics 细节详见 [2.1.3.1](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/render-statistics-0000001205804115) "[RenderStatistics](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/render-statistics-0000001205804115)"|渲染统计信息，RenderStatistics|

## Return Values

调用函数成功返回0，失败返回-1。

## Examples

```screen
RenderStatistics renderStatics;

void Update() {
    renderHandle.GetRenderStatics(ref renderStatics);
    int submiteFrameRate = (int) renderStatics.SubmitFrameRate; //Frame submit rate
    int renderFrameRate = (int) renderStatics.RenderFrameRate; //Frame rendering rate
}
```
