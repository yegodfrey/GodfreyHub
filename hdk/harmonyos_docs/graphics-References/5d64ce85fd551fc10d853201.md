# CompareOperation

|Enum Info|
|:----------|
|深度测试操作类型枚举。|

#### Enum Value Summary

|Enum Value and Description|
|:---------------------------------------------------------------|
|COMPARISON_OPERATION_NEVER 深度测试始终不通过。|
|COMPARISON_OPERATION_LESS 新片段深度值小于旧片段深度值，则深度测试通过。|
|COMPARISON_OPERATION_EQUAL 新片段深度值等于旧片段深度值，则深度测试通过。|
|COMPARISON_OPERATION_LESS_OR_EQUAL 新片段深度值小于或等于旧片段深度值，则深度测试通过。|
|COMPARISON_OPERATION_GREATER 新片段深度值大于旧片段深度值，则深度测试通过。|
|COMPARISON_OPERATION_NOT_EQUAL 新片段深度值不等于旧片段深度值，则深度测试通过。|
|COMPARISON_OPERATION_GREATER_OR_EQUAL 新片段深度值大于或等于旧片段深度值，则深度测试通过。|
|COMPARISON_OPERATION_ALWAYS 深度测试始终通过。|
