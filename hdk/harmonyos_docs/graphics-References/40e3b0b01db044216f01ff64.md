# ARFaceBlendShapes

|Class Info|
|:------------------------------------------------|
|public class ARFaceBlendShapes 用于描述微表情，包含若干个表情参数。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|[getBlendShapeCount](#section3732632195612)() 获取表情参数个数。|
|FloatBuffer|[getBlendShapeData](#section144847419562)() 获取所有表情参数，数值范围[0-1]，表示每种表情的表现程度，每个参数的代表的含义可根据相同数组下标去[getBlendShapeType](#section16525135215618)()接口返回的数组中查询获得。如：floatBuffer是[getBlendShapeData](#section144847419562)()返回值，shapeStr是[getBlendShapeType](#section16525135215618)返回值，shapeStr[0] = Animoji_Eye_Blink_Left，floatBuffer[0]=1表示左眼完全闭合。|
|HashMap<[ARBlendShapeType](https://developer.huawei.com/consumer/cn/doc/graphics-References/blend_shape_type-0000001050162184), Float>|[getBlendShapeDataMapKeyEnum](#section55339164574)() 获取所有表情参数Map，key为表情参数类型对应的枚举值，value为表情参数系数，取值范围[0,1]。value的值越大，则key对应的表情越接近规定的最大值。例如，Animoji_Eye_Blink_Left对应的值为1，表明左眼完全闭合；Animoji_Eye_Blink_Left对应的值为0，则表明左眼完全张开。 > 注意 > 该方法已废弃，请使用[getBlendShapeDataMapKeyString](#section67962355719)()。|
|HashMap<String, Float>|[getBlendShapeDataMapKeyString](#section67962355719)() 获取所有表情参数Map，key为表情枚举类型对应的string，value为表情表现程度，取值范围[0,1]。value的值越大，则key对应的表情越接近规定的最大值。例如，Animoji_Eye_Blink_Left对应的值为1，表明左眼完全闭合；Animoji_Eye_Blink_Left对应的值为0，则表明左眼完全睁开。|
|String[]|[getBlendShapeType](#section16525135215618)() 获取所有表情参数类型数组，该数组成员与[getBlendShapeData](#section144847419562)()接口返回的数组成员一一对应，值为[ARBlendShapeType](https://developer.huawei.com/consumer/cn/doc/graphics-References/blend_shape_type-0000001050162184)对应的枚举名称。|
|void|[release](#section17877130175711)() 确保在获取[ARFaceBlendShapes](https://developer.huawei.com/consumer/cn/doc/graphics-References/face_blend_shapes-0000001050119492)对象使用结束后调用，否则将导致内存泄露。|
