# ARAnchor

|Class Info|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public class ARAnchor 锚点是实际环境中一个固定的位置和指定的方向。当环境发生变化时，比如摄像头移动，为了维持这个物理空间的固定位置和方向，AR Engine会根据自己对于环境的检测结果，不断更新它的数值，以做到在该锚点上放置的物体固定不动的效果。在使用前，应使用[getTrackingState](#section870144851810)()接口检查锚点的状态，锚点的状态为[ARTrackable.TrackingState](https://developer.huawei.com/consumer/cn/doc/graphics-References/tracking_state-0000001050164125#section15256152217277).TRACKING时，通过[getPose](#section1022012307181)()接口获取的数据才是可用的。|

#### getPose

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public [ARPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/pose-0000001050121457) getPose() 获取锚点在世界坐标系的位置和姿态信息，该Pose包含坐标信息供程序调整物体位置，随着实际环境变化，[ARPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/pose-0000001050121457)的数据也会有所更新。因此，在需要获取最新的[ARPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/pose-0000001050121457)数据前，需要先调用[ARSession](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459)里面的[update](https://developer.huawei.com/consumer/cn/doc/graphics-References/session-0000001050121459#section1826912043817)()方法。当锚点的状态为TRACKING时，获取的[ARPose](https://developer.huawei.com/consumer/cn/doc/graphics-References/pose-0000001050121457)数据才是有效的。|
