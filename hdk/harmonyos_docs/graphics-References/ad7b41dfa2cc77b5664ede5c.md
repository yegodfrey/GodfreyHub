# LoadOp

|Enum Info|
|:---------------------|
|子通道在渲染之前对附件中数据的操作方式枚举。|

## Enum Value Summary

|Enum Value and Description|
|:-------------------------------------|
|ATTACHMENT_LOAD_OP_LOAD 保持附件的现有内容。|
|ATTACHMENT_LOAD_OP_CLEAR 清除附件中的内容。|
|ATTACHMENT_LOAD_OP_DONT_CARE 不关心附件的内容。|
