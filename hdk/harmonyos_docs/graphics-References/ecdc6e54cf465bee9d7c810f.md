# VertexLayout

|Enum Info|
|:---------|
|顶点属性的组织枚举。|

## Enum Value Summary

|Enum Value and Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|VERTEX_LAYLAYOUT_POSITION_XY 顶点属性中只包含位置坐标，且只有XY两个分量。|
|VERTEX_LAYLAYOUT_POSITION_XY_COLOR 顶点属性中包含位置坐标和颜色数据，且位置坐标为XY两个分量，颜色数据为RGBA四个分量。|
|VERTEX_LAYLAYOUT_POSITION_XY_TEXTURE 顶点属性中包含位置坐标和纹理坐标，且位置坐标为XY两个分量，纹理坐标为st两个分量。|
|VERTEX_LAYLAYOUT_POSITION 顶点属性中只包含位置坐标，且坐标为XYZ三个分量。|
|VERTEX_LAYLAYOUT_POSITION_COLOR 顶点属性中包含位置坐标和颜色数据，且坐标为XYZ三个分量，颜色数据为RGBA四个分量。|
|VERTEX_LAYLAYOUT_POSITION_TEXTURE 顶点属性中包含位置坐标和纹理坐标，且坐标为XYZ三个分量，纹理坐标为st两个分量。|
|VERTEX_LAYLAYOUT_POSITION_NORMAL 项点属性中包含位置坐标和法线数据，且位置坐标和法线数据都为XYZ三个分量。|
|VERTEX_LAYLAYOUT_POSITION_TEXTURE_COLOR 顶点属性中包含位置坐标、纹理坐标和颜色数据，且位置坐标为XYZ三个分量，纹理坐标为st两个分量，颜色数据为RGBA四个分量。|
|VERTEX_LAYLAYOUT_POSITION_TEXTURE_NORMAL 顶点属性中包含位置坐标、纹理坐标和法线数据，且位置坐标和法线数据为XYZ三个分量，纹理坐标为st两个分量。|
|VERTEX_LAYLAYOUT_POSITION_TEXTURE_NORMAL_TANGENT 顶点属性中包含位置坐标、纹理坐标、法线数据和颜色空间数据，且位置坐标和法线数据为XYZ三个分量，纹理坐标为st两个分量，颜色空间数据为四个分量。|
|VERTEX_LAYLAYOUT_POSITION_TEXTURE_NORMAL_TANGENT_SKINNING 顶点属性中包含位置坐标、纹理坐标、法线数据、颜色空间数据和关节数据，且位置坐标和法线数据为XYZ三个分量，纹理坐标为st两个分量，颜色空间数据和关节数据（joint1、joint2、joint3、joint4）包含四个分量。|
|VERTEX_LAYLAYOUT_MAX 顶点属性组织枚举最大值，表示枚举到此结束。|
