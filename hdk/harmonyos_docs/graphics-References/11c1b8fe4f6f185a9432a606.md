# dispatch_get_main_queue

## 功能描述

获取主队列。主队列是一个特殊的全局串行队列，它与主线程绑定（除此之外的其它队列都是不与线程绑定的）。

主线程是调用[dispatch_main](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/dispatch-main-0000001050170741)的线程。提交到主队列上的任务会被主线程处理，如果没有线程调用[dispatch_main](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/dispatch-main-0000001050170741)变为主线程，那么主队列就是不存在的。
> 说明
>
> 不同于[GCD](https://developer.apple.com/documentation/dispatch/1452921-dispatch_get_main_queue?language=objc)，Android平台并没有为了multithread-lib而自动绑定一个主线程。
>
> 因此要使用主队列必须有一个线程主动调用[dispatch_main](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/dispatch-main-0000001050170741)。如果是在Android应用的JNI函数使用multithread-lib，这种做法是不推荐的，请避免使用主队列。

## 函数原型

```screen
dispatch_queue_main_t dispatch_get_main_queue(void);
```

## 返回

|类型|描述|
|:--------------------|:-----|
|dispatch_queue_main_t|返回主队列。|
