# dispatch_group_wait

## 功能描述

同步地等待这个group上所有任务执行完成（即group为空），并指定超时时间。

## 函数原型

```screen
long dispatch_group_wait(dispatch_group_t group, dispatch_time_t timeout);
```

## 参数

|名称|类型|描述|
|:------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|group|dispatch_group_t|group。|
|timeout|dispatch_time_t|超时的绝对时间。参见[dispatch_time](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/time-0000001050168878)或[dispatch_walltime](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/walltime-0000001050170835)。|

## 返回

|类型|描述|
|:---|:-----------------------------------------------------|
|long|如果timeout前group上的所有任务执行完成，此函数返回0；如果timeout发生，此函数返回非0值。|
