# GenerateFaceParas

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int GenerateFaceParas(const [AIFaceModParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/aifacemodparas-0000001133008108)& modParas, [GeneratedParas](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/generatedparas-0000001134825080)& genParas) 生成照片捏脸参数。|

**Parameters**

|Name|Description|
|:-------|:---------------------------------------------|
|modParas|捏脸资源文件、捏脸效果参数。|
|genParas|生成捏脸参数数据结构体，包含捏脸连续值参数、捏脸离散值参数、融合真实感照片纹理的游戏纹理图。|

**Returns**

|Type|Description|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|返回接口调用结果标志位。 * 0：成功。 * 非0：失败，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/error-code-0000001061725148#section965820932815)。|
