# SetPositionLock (Not Supported)

开启关闭位置锁定。通常用于观看电影的情况，观看者在调整观看位置前后，均调用该接口，分别开启、关闭位置锁定，以保证观看的画面位置不会发生。

## Parameter

|**Parameter Name**|**Parameter Type**|**Description**|
|:-----------------|:-----------------|:---------------------------------------|
|enable|bool|输入enable为true：开启位置锁定；enable为false：解除位置锁定|

## Return Values

调用函数成功返回0，失败返回-1。
