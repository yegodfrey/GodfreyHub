# ImageCreateFlagBits

|Enum Info|
|:--------|
|图像创建标志枚举。|

## Enum Value Summary

|Enum Value and Description|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|IMAGE_CREATE_SPARSE_BINDING_BIT = 0x00000001 支持稀疏图像绑定内存。|
|IMAGE_CREATE_SPARSE_RESIDENCY_BIT = 0x00000002 支持部分稀疏图像绑定内存，使用这个标志创建的图像也必须同时使用IMAGE_CREATE_SPARSE_BINDING_BIT。|
|IMAGE_CREATE_SPARSE_ALIASED_BIT = 0x00000004 支持稀疏图像与支持另一个图像（或图像的一部分）的内存范围进行绑定，使用此标志也必须同时使用IMAGE_CREATE_SPARSE_BINDING_BIT。|
|IMAGE_CREATE_MUTABLE_FORMAT_BIT = 0x00000008 对于多平面格式，可以创建与视图格式不同的图像。|
|IMAGE_CREATE_CUBE_COMPATIBLE_BIT = 0x00000010 指定图像可用于创建由立体贴图与立体贴图数组创建的视图。|
|IMAGE_CREATE_ALIAS_BIT = 0x00000400 指定使用相同参数创建的两个图像和别名到同一内存，可以一致的解释彼此的内存内容。这个标志进一步指定不相交的图像的每个面可以在非线性的内存中共享单平面图像。|
|IMAGE_CREATE_SPLIT_INSTANCE_BIND_REGIONS_BIT = 0x00000040 这个标志具有使图像使用标准稀疏图像块的效果。|
|IMAGE_CREATE_2D_ARRAY_COMPATIBLE_BIT = 0x00000020 指定图像可以创建二维或二维数组的视图。|
|IMAGE_CREATE_BLOCK_TEXEL_VIEW_COMPATIBLE_BIT = 0x00000080 具有压缩的图像格式，用于创建 一个具有未压缩的视图，其中每个纹素在视图中对应于图像的压缩纹素。|
|IMAGE_CREATE_EXTENDED_USAGE_BIT = 0x00000100 可以使用不支持的格式去创建图像，但从视图创建的图像至少要支持一种格式。|
|IMAGE_CREATE_PROTECTED_BIT = 0x00000800 指定图像是受保护的图像。|
|IMAGE_CREATE_DISJOINT_BIT = 0x00000200 指定具有多平面格式的图像，必须具有每个平面单独绑定的内存而不是整个图像的。此标志位将不相交的图像与没有此标志位的图像区分开。|
|IMAGE_CREATE_CORNER_SAMPLED_BIT_NV = 0x00002000 指定图像为角采样图像。|
|IMAGE_CREATE_SAMPLE_LOCATIONS_COMPATIBLE_DEPTH_BIT_EXT = 0x00001000 指定图像可以做为深度/模板附件，被深度或深度/模板格式以及自定义采样使用。|
|IMAGE_CREATE_SPLIT_INSTANCE_BIND_REGIONS_BIT_KHR = IMAGE_CREATE_SPLIT_INSTANCE_BIND_REGIONS_BIT 同[IMAGE_CREATE_SPLIT_INSTANCE_BIND_REGIONS_BIT](#ZH-CN_TOPIC_0000001253055702__p3752193510545)的定义。|
|IMAGE_CREATE_2D_ARRAY_COMPATIBLE_BIT_KHR = IMAGE_CREATE_2D_ARRAY_COMPATIBLE_BIT 同[IMAGE_CREATE_2D_ARRAY_COMPATIBLE_BIT](#ZH-CN_TOPIC_0000001253055702__p9159439205413)的定义。|
|IMAGE_CREATE_BLOCK_TEXEL_VIEW_COMPATIBLE_BIT_KHR = IMAGE_CREATE_BLOCK_TEXEL_VIEW_COMPATIBLE_BIT 同[IMAGE_CREATE_BLOCK_TEXEL_VIEW_COMPATIBLE_BIT](#ZH-CN_TOPIC_0000001253055702__p886014411541)的定义。|
|IMAGE_CREATE_EXTENDED_USAGE_BIT_KHR = IMAGE_CREATE_EXTENDED_USAGE_BIT 同[IMAGE_CREATE_EXTENDED_USAGE_BIT](#ZH-CN_TOPIC_0000001253055702__p194582515543)的定义。|
|IMAGE_CREATE_DISJOINT_BIT_KHR = IMAGE_CREATE_DISJOINT_BIT 同[IMAGE_CREATE_DISJOINT_BIT](#ZH-CN_TOPIC_0000001253055702__p9366124418548)的定义。|
|IMAGE_CREATE_ALIAS_BIT_KHR = IMAGE_CREATE_ALIAS_BIT 同[IMAGE_CREATE_ALIAS_BIT](#ZH-CN_TOPIC_0000001253055702__p139911814413)的定义。|
|IMAGE_CREATE_FLAG_BITS_MAX_ENUM = 0x7FFFFFFF 最大值。|
