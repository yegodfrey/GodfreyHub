# GetRenderHandle

获取显示句柄，调用显示相关的功能函数. 请参考 [2.1.5.4](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/render_handle_capture_eye_image-0000001160205594) 节 "[IRenderHandle](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/render_handle_capture_eye_image-0000001160205594)"。

## Return Values

调用函数成功返回头盔句柄IRenderHandle，调用函数失败返回null。
> 说明
>
> 该接口需要在Unity生命周期的Start()或其之后调用。

## Examples

```screen
IRenderHandle renderHandle; //This variable related to the rendering handle is used in the following codes.
renderHandle = HvrApi.GetRenderHandle();
if (renderHandle != null) {
    Debug.Log("GetRenderHandle Success!");
} else {
    Debug.Log("GetRenderHandle Failed!");
}
```
