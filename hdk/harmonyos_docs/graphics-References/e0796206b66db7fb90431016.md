# dispatch_queue_create_with_target

## 功能描述

创建一个新队列并指定它的target_queue。

target_queue指定了此queue上的任务会重定向到哪个queue上被执行，属于底层的一个实现细节。不影响queue自身的逻辑和约束，例如serial or concurrent还是由queue自己决定的，和target_queue无关。

使用[dispatch_queue_create](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/queue-create-0000001050170743)接口创建的queue的target_queue是对应优先级的global queue。

使用[dispatch_queue_create_with_target](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/create-with-target-0000001050170747)接口创建queue，如果没有指定QoS那么它的QoS就继承指定的target_queue。较少使用，通常更建议使用[dispatch_queue_create](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/queue-create-0000001050170743)接口。

## 函数原型

```screen
dispatch_queue_t dispatch_queue_create_with_target(const char *label,dispatch_queue_attr_t attr, dispatch_queue_t target_queue);
```

## 参数

|名称|类型|描述|
|:-----------|:--------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|label|const char *|一个字符串，作为这个队列的名字。label为方便调试的目的而设，可以以你觉得方便的任何名字命名。允许传入NULL。|
|attr|dispatch_queue_attr_t|允许三类参数： * DISPATCH_QUEUE_SERIAL或NULL或0。表示创建DEFAULT优先级的串行队列。 * DISPATCH_QUEUE_CONCURRENT。表示创建DEFAULT优先级的并发队列。 * 使用[dispatch_queue_attr_make_with_qos_class](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/attr-make-with-qos-class-0000001050168788)接口的返回值。此返回值定义了一个更丰富的queue属性。|
|target_queue|dispatch_queue_t|指定的target_queue。如果传入DISPATCH_TARGET_QUEUE_DEFAULT（即NULL），那么则是设为默认的target_queue，等价于[dispatch_queue_create](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/queue-create-0000001050170743)。|

## 返回

|类型|描述|
|:---------------|:------|
|dispatch_queue_t|新创建的队列。|
