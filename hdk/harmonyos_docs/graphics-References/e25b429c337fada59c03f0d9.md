# MouseAction

|Enum Info|
|:--------|
|鼠标事件枚举。|

## Enum Value Summary

|Enum Value and Description|
|:-------------------------------------------------|
|MOUSE_ACTION_UNKNOWN 未知鼠标事件。|
|MOUSE_ACTION_LEFT_BUTTON_DOWN 鼠标左键按下事件。|
|MOUSE_ACTION_LEFT_BUTTON_UP 鼠标左键抬起事件。|
|MOUSE_ACTION_LEFT_BUTTON_DOUBLE_CLICK 鼠标左键双击事件。|
|MOUSE_ACTION_MIDDLE_BUTTON_DOWN 鼠标中间键按下事件。|
|MOUSE_ACTION_MIDDLE_BUTTON_UP 鼠标中间键抬起事件。|
|MOUSE_ACTION_MIDDLE_BUTTON_DOUBLE_CLICK 鼠标中间键双击事件。|
|MOUSE_ACTION_RIGHT_BUTTON_DOWN 鼠标右键按下事件。|
|MOUSE_ACTION_RIGHT_BUTTON_UP 鼠标右键抬起事件。|
|MOUSE_ACTION_RIGHT_BUTTON_DOUBLE_CLICK 鼠标右键双击事件。|
|MOUSE_ACTION_MOUSE_WHEEL 鼠标滚轮事件。|
|MOUSE_ACTION_MOVE 鼠标移动事件。|
|MOUSE_ACTION_MAX 枚举最大值，有效的枚举值小于该值。|
