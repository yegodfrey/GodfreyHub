# CharacterAdapter

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int CharacterAdapter(const [CharacterData](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/characterdata-0000001178927805) data, std::string savePath) PC端角色模型适配，将用户提供的游戏角色模型转换为可进行智能捏脸计算的模型资源文件。|

Parameters  

|Name|Description|
|:-------|:----------------------------|
|data|存储角色模型信息的结构体。|
|savePath|角色模型资源文件（character.bin）的存储路径。|

Returns  

|Type|Description|
|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|返回接口调用结果标志位。 * 0：成功。 * 非0：失败，具体请参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/graphics-Guides/error-code-0000001061725148#section965820932815)。|
