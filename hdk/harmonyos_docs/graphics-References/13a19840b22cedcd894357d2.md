# Overview

XRKit SDK提供对外接口，用于指导开发者使用场景化、组件化的AR解决方案构建AR应用。

## Interface Summary

|Interface|Description|
|:------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[IArFaceView](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-faceview-0000001064620625)|AR人脸场景组件，提供实时的人脸相关模型呈现，包括表情驱动与人脸贴纸呈现。|
|[IArSceneView](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-sceneview-0000001064738794)|AR展示场景组件，提供3D场景的模型呈现、AR场景真实环境识别与虚拟模型在真实环境的渲染。|
|[IFeatureEventListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-feature-event-listener-0000001064580554)|特性事件监听，用于XRKit服务端上报运行时事件，包括模型加载成功、模型加载失败、模型与实景贴合等事件。|
|[IModel](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-model-0000001064420560)|模型接口，包含获取模型标签方法。|
|[IModelListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-modelistener-0000001064060563)|模型监听接口，包含模型加载、选择、放置等回调函数。 > 注意 > 该接口已废弃，请使用[IFeatureEventListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-feature-event-listener-0000001064580554)。|
|[IXrKitFeature](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-xrkit-feature-0000001065058380)|XRKit特性组件管理接口，负责创建XRKit特性组件与注册特性事件监听。|
|[OnSurfaceReadyListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-ready-listener-0000001064898370)|surface实例化监听接口。 > 说明 > 若在AR人脸场景中设置客户端打开相机，则需要使用此监听从服务端获取并向surface对象写入对应的图像流。|
|[TakeScreenshotListener](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-screenshot-listener-0000001064290308)|IARFaceView场景中获取组件位图的监听接口，有[onSuccess](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-screenshot-listener-0000001064290308#section0838193818508)()和[onFailure](https://developer.huawei.com/consumer/cn/doc/graphics-References/interface-screenshot-listener-0000001064290308#section266511520815)()两个方法。|
