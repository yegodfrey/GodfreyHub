# runUpdate

升级应用VR库，初始化应用VR环境。  

#### Return Values

初始化VR环境成功返回true，失败返回false。  

#### Examples

```
public void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    new LibUpdateClient(this).runUpdate();
}
```
