# HrdelayAutostatEnable

|**Method**|
|:--------------------------------------------------------------------------------------------------|
|void HrdelayAutostatEnable(JNIEnv *env) 打开Hrdelay自动统计的功能。此功能通过接受JNI环境指针，反射获得Java运行环境统计Hrdelay的使用情况。|

**Parameters**

|**Name**|**Description**|
|:-------|:---------------------------------------------------------------------------|
|env|Android Native代码中获得的JNIEnv *参数，用于HrdelayAutostatEnable内部获得Java虚拟机并调用Java中的类。|

**Returns**

|**Type**|**Description**|
|:-------|:--------------|
|void|-|
