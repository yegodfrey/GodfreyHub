# dispatch_once_f

## 功能描述

[dispatch_once](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/once-0000001050168880)的_f版本。

## 函数原型

```screen
void dispatch_once_f(dispatch_once_t *predicate, void *context, dispatch_function_t work);
```

## 参数

|名称|类型|描述|
|:--------|:------------------|:-------------------------------------------------------------------------------|
|predicate|dispatch_once_t *|指向一个dispatch_once_t的指针。这个dispatch_once_t用来标识任务是否完成过以及是否正在执行。需要定义在全局或静态区域且不应手动赋值。|
|context|void *|任务函数参数。|
|work|dispatch_function_t|使用者定义的任务函数。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
