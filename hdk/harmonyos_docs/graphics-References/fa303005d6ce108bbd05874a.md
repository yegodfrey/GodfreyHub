# dispatch_queue_attr_make_with_qos_class

## 功能描述

根据参数创建一个queue属性，提供给[dispatch_queue_create](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/queue-create-0000001050170743)函数作为参数。

示例：

```screen
dispatch_queue_t queue;
dispatch_queue_attr_t attr;
attr = dispatch_queue_attr_make_with_qos_class(DISPATCH_QUEUE_SERIAL,
		QOS_CLASS_UTILITY, 0);
queue = dispatch_queue_create("example", attr);
```

## 函数原型

```screen
dispatch_queue_attr_t dispatch_queue_attr_make_with_qos_class(dispatch_queue_attr_t attr, dispatch_qos_class_t qos_class, int relative_priority);
```

## 参数

|名称|类型|描述|
|:----------------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|attr|dispatch_queue_attr_t|DISPATCH_QUEUE_SERIAL或NULL或0：表示串行队列。 DISPATCH_QUEUE_CONCURRENT：表示并发队列。|
|qos_class|dispatch_qos_class_t|指定QoS class。可以使用的数值为： QOS_CLASS_USER_INTERACTIVE，QOS_CLASS_USER_INITIATED，QOS_CLASS_DEFAULT，QOS_CLASS_UTILITY，QOS_CLASS_BACKGROUND。 请参见[dispatch_get_global_queue](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/get-global-queue-0000001050168786)。 在内部实现上，如果创建某个QoS class的queue（无论是串行队列还是并发队列），此queue会链接到对应的global_queue上，由对应的global_queue从线程池中分配特定优先级的线程来处理提交到queue上的任务。 由于当前版本中没有实现线程池中线程优先级的区分，因此当前声明一个QoS class没有什么实际意义。|
|relative_priority|int|指定相对于这个QoS class优先级的偏移。 是0或一个负值，范围：[QOS_MIN_RELATIVE_PRIORITY， 0]。越小越优先，用于更精细的优先级控制。 通常传入0，不建议使用。|

## 返回

|类型|描述|
|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|dispatch_queue_attr_t|一个attr属性值，用于传入[dispatch_queue_create](https://developer.huawei.com/consumer/cn/doc/development/graphics-References/queue-create-0000001050170743)。如果参数不在范围则返回NULL。|
