# ImageLayout

|Enum Info|
|:--------|
|图像布局方式枚举。|

## Enum Value Summary

|Enum Value and Description|
|:---------------------------------------------------------------------------------|
|IMAGE_LAYOUT_UNDEFINED 未知布局。|
|IMAGE_LAYOUT_GENERAL 常规布局。|
|IMAGE_LAYOUT_COLOR_ATTACHMENT_OPTIMAL 用作颜色附件的布局。|
|IMAGE_LAYOUT_DEPTH_STENCIL_ATTACHMENT_OPTIMAL 用作深度/模板附件的布局。|
|IMAGE_LAYOUT_DEPTH_STENCIL_READ_ONLY_OPTIMAL 用作只读访问的深度/模板附件的布局。|
|IMAGE_LAYOUT_SHADER_READ_ONLY_OPTIMAL 用作着色器内只读访问图像的布局。|
|IMAGE_LAYOUT_TRANSFER_SRC_OPTIMAL 用作传输命令的源图像的布局。|
|IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL 用作传输命令的目标图像的布局。|
|IMAGE_LAYOUT_PREINITIALIZED 预初始化布局。|
|IMAGE_LAYOUT_DEPTH_READ_ONLY_STENCIL_ATTACHMENT_OPTIMAL 用作深度/模板附件的布局，只读访问深度附件。|
|IMAGE_LAYOUT_DEPTH_ATTACHMENT_STENCIL_READ_ONLY_OPTIMAL 用作深度/模板附件的布局，只读访问模板附件。|
|IMAGE_LAYOUT_DEPTH_ATTACHMENT_OPTIMAL 用作深度附件的布局。|
|IMAGE_LAYOUT_DEPTH_READ_ONLY_OPTIMAL 用作深度附件只读访问的布局。|
|IMAGE_LAYOUT_STENCIL_ATTACHMENT_OPTIMAL 用作模板附件的布局。|
|IMAGE_LAYOUT_STENCIL_READ_ONLY_OPTIMAL 用作模板附件只读访问的布局。|
|IMAGE_LAYOUT_PRESENT_SRC_KHR 用作交换链中进行呈现的布局。|
|IMAGE_LAYOUT_SHARED_PRESENT_KHR 共享的可呈现的图像布局。|
|IMAGE_LAYOUT_SHADING_RATE_OPTIMAL_NV 用作片段着色率附件或着色率图像的布局。|
|IMAGE_LAYOUT_FRAGMENT_DENSITY_MAP_OPTIMAL_EXT 用于片元密度图附件的布局。|
|IMAGE_LAYOUT_DEPTH_READ_ONLY_STENCIL_ATTACHMENT_OPTIMAL_KHR 用作深度/模板附件的布局，只读访问深度附件。|
|IMAGE_LAYOUT_DEPTH_ATTACHMENT_STENCIL_READ_ONLY_OPTIMAL_KHR 用作深度/模板附件的布局，只读访问模板附件。|
|IMAGE_LAYOUT_DEPTH_ATTACHMENT_OPTIMAL_KHR 用作深度附件的布局。|
|IMAGE_LAYOUT_DEPTH_READ_ONLY_OPTIMAL_KHR 用作深度附件只读访问的布局。|
|IMAGE_LAYOUT_STENCIL_ATTACHMENT_OPTIMAL_KHR 用作模板附件的布局。|
|IMAGE_LAYOUT_STENCIL_READ_ONLY_OPTIMAL_KHR 用作模板附件只读访问的布局。|
