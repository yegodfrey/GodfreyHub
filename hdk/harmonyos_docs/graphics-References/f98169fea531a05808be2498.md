# CSuperSamplingAsyncExecute

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|bool CSuperSamplingAsyncExecute(const CGKit::BufferDescriptor *inBuffer, const CGKit::BufferDescriptor *outBuffer, PluginCallback callback) 通过异步方式调用离线超分插件的AI能力。|

**Parameters**

|Name|Description|
|:--------|:-----------------|
|inBuffer|输入图像数据。|
|outBuffer|输出图像数据，内存由调用者预先分配。|
|callback|异步执行的回调函数。|

**Returns**

|Type|Description|
|:---|:-------------------------------------|
|bool|* true：异步调用AI能力成功。 * false：异步调用AI能力失败。|
