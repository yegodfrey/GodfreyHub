# dispatch_async

## 功能描述

提交一个任务，异步执行（调用者立即返回不等待任务执行完成）。

关于什么是block，请参见[GCD Tutorial](https://apple.github.io/swift-corelibs-libdispatch/tutorial/)或[Clang Doc](http://clang.llvm.org/docs/BlockLanguageSpec.html)。

## 函数原型

```screen
void dispatch_async(dispatch_queue_t queue, dispatch_block_t block);
```

## 参数

|名称|类型|描述|
|:----|:---------------|:--------|
|queue|dispatch_queue_t|目标队列。|
|block|dispatch_block_t|提交的block。|

## 返回

|类型|描述|
|:---|:-|
|void|-|
