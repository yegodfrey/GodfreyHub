# Ray

|Struct Info|
|:-----------------|
|Ray 光线，包含光线的原点和方向。|

## Public Field Summary

|Qualifier and Type|Field and Description|
|:-----------------|:------------------------|
|float|origin[3] 光线的原点坐标。|
|float|tmin 光线原点和最近交点的距离，不需要初始化。|
|float|dir[3] 光线的方向向量。|
|float|tmax 光线原点和最远交点的距离，不需要初始化。|
