# Starting the HMI App After Connecting to the Phone via Bluetooth

#### Scenario

To simplify the procedure of connecting to HiCar for the first time, the head unit can directly start the HMI app after being connected to the phone via Bluetooth.

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210254.98678605788563176013097701861787:50001231000000:2800:B093CF176D21E32429EC05C2819A68597CDBFFFFF85CEF0B16AD5ED5815428E4.png?needInitFileName=true?needInitFileName=true)

To implement this feature, the head unit Bluetooth must support Secure RFCOMM communications with the UUID (FA87C0D0-AFAC-11DE-8A39-0800200C9A66).

When a Bluetooth connection is established between a phone and a head unit that both support HiCar, the HiCar SDK on the head unit and the HiCar app on the phone will interact via the Bluetooth RFCOMM channel, to determine that HiCar is supported on both sides. The phone will then recommend HiCar to the user. After the user agrees to the use of HiCar, the head unit directly displays the connection screen (where users can enter a PIN or scan the QR code to connect). In this way, the initial connection procedure is made easy and simple for the user.

User path:

     1. After the head unit supporting HiCar is connected to the phone via Bluetooth, the following prompts will display, asking whether the user would like to try HiCar out.

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210254.11472542989440258886568779550035:50001231000000:2800:88710B901E44CF3467C81A1B26C03687D49A84F3B46B8661B94F7FA063431971.png?needInitFileName=true?needInitFileName=true)

     2. If the user touches **Try Now** , the head unit displays the HiCar HMI app (where users can enter a PIN or scan the QR code to connect); if the user touches **No Thanks** , the head unit will not receive any callback and no action will be triggered.

#### API Description

**Table 1** Related APIsClass | Method | Description  
---|---|---  
HiCarAdapter | startBluetoothRecommend | Starts RFCOMM listening on the connection and interaction between the phone and the head unit.  
CarListener | onShowStartPage | Redirects to the HiCar connection screen after receiving the callback (implemented by the HMI app) for displaying the connection screen.  
  
#### Development Procedure

     1. Set **CarConfig** to initialize the HiCar SDK, then obtain the **HiCarAdapter** instance. In addition, implement the API to listen for Bluetooth connections, and call the **startBluetoothRecommend** method when a successful Bluetooth connection is detected.
            
            HiCarAdapter.init(getApplicationContext(), mCarConfig, new HiCarInitCallback() {
                @Override
                public void onInitSuccess(HiCarAdapter hiCarAdapter) {
                    ...
                  mHiCarAdapter = hiCarAdapter
                }
            });
                    ...
            mHiCarAdapter.startBlueToothRecommend();

     2. Implement **onShowStartPage** in **CarListener**. In this callback, redirect to the HiCar connection screen (where users can enter a PIN or scan the QR code to connect).
            
            public class HiCarListener implements CarListener {
                ...
                @Override
                public void onShowStartPage() {
                    // Display the screen where users can enter a PIN or scan the QR code to connect.
                }
            }
