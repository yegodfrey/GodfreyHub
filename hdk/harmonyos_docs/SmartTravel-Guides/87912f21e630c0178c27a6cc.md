# Handling Projection Event Callback

#### Scenario

The HMI app can obtain the projection result through event callback, and process its service logic in the event callback based on the projection result. For example, if the projection fails, the HMI app destroys the projection screen and returns to the native HMI screen.

#### APIs

**Table 1** APIs for handling projection event callbackAPI | Method | Description  
---|---|---  
CarListener | DeviceServiceChange | The HiCar SDK notifies the HMI app of the projection events through callback. **HICAR_DEVICE_DISPLAY_SERVICE_PLAYING** (value being **207**): If the HMI app receives this event, the projection is successful. After receiving this event, the HMI app can start to receive video streams and start the projection.  
  
#### Development Procedure

The following is the sample code for projection event callback:
    
    void DeviceServiceChange(const char *serviceId, uint32_t idLen, int state)
    {
        switch (state) {
            case HICAR_DEVICE_DISPLAY_SERVICE_PLAYING:
            // TODO: The manufacturer's logic for, for example, establishing a vehicle service channel.
            ...
            break;
            default:
            break;
        }
    }
