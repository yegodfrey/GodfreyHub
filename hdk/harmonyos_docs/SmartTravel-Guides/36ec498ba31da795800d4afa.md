# Development Overview

**Figure 1** HiCar SDK integrated development overview

To integrate the HiCar SDK, complete the following tasks:

     1. Adapting the connection driver: Provide the USB, Bluetooth, or Wi-Fi drivers for HiCar so that the head unit can connect to HiCar in wired or wireless mode.
     2. Developing an HMI app: Implement HMI-related logic processing for HiCar to implement functions such as projection display, data transmission, and connection management. Integrate the header files in the HiCar SDK package to develop an HMI app, which will be pre-installed in the head unit and used to connect to HiCar phones and display HiCar-supported apps. For details about the implementation process, please refer to **hicar_demo.c** in the HiCar SDK package. When developing HMI apps, follow the HUAWEI HiCar App UX Design Specification, which contains design specifications for UIs including but are not limited to the following:
        * Wired connection prompt UI
        * Wireless connection PIN display UI
        * Connection exception prompt UI
        * Ongoing connection UI
     3. Managing head unit connections: Add the HiCar connection management function to the vehicle system settings page.
     4. Adapting sensors: Implement audio (mandatory), camera (optional), and GPS modules (optional) for HiCar so that HiCar can use the in-vehicle microphone, speaker, camera, and GPS devices.
