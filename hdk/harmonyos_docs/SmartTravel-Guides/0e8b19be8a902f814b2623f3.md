# VoIP Call

#### Scenario

HiCar supports voice calls in VoIP apps (such as MeeTime). The HiCar SDK identifies VoIP apps and notifies the HMI app of the VoIP call status.

After receiving **EVENT_DEVICE_SERVICE_VOIP_CALLING** in the **onDeviceServiceChange** callback, the HMI app needs to perform echo cancellation and noise reduction.

#### API Description

**Table 1** API for handling VoIP conflictsClass | Method | Description  
---|---|---  
CarListener | onDeviceServiceChange | The HiCar SDK notifies the HMI app of the VoIP call events through callback.
     * **EVENT_DEVICE_SERVICE_VOIP_CALLING** (value being **214**): This event is sent after a VoIP call is answered. After receiving this event, the HMI app should perform echo cancellation and noise reduction.
     * **EVENT_DEVICE_SERVICE_VOIP_HANG_UP** (value being **215**): This event is sent after a VoIP call is ended. After receiving this event, the HMI app should stop echo cancellation and noise reduction.  
  
#### Development Procedure

     1. The HMI app should register the event callback when the HiCar SDK is initialized. For details, please refer to [Registering Event Listeners](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/register-event-listener-0000000000030698).
     2. After receiving **EVENT_DEVICE_SERVICE_VOIP_CALLING** in the **onDeviceChange** callback, the HMI app should perform echo cancellation and noise reduction.
     3. After receiving **EVENT_DEVICE_SERVICE_VOIP_HANG_UP** in the **onDeviceChange** callback, the HMI app should stop echo cancellation and noise reduction.

#### Handling Conflicts During Calls

By default, HiCar provides the call service. If the head unit also provides the call service, conflicts may occur when they run at the same time. Therefore, the head unit should notify HiCar of the native call service state. When HiCar provides the call service, the head unit needs to report the call/hang-up event based on the call state of HiCar when the user presses the control button. Therefore, the head unit needs to obtain the call status from HiCar.

For details about call conflicts, please refer to [Call Status and Focus](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/call-status-and-focus-0000001051530010).
