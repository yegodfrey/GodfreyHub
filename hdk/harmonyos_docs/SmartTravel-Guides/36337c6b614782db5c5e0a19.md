# Wireless Connection Description

Before integrating the wireless connection function into the HMI app, the Bluetooth and Wi-Fi functions must have already been integrated to the head unit. For details, please refer to [Description](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/note-0000001194049481).

**Figure 1** Interaction process  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210255.03403301928595118872649263665850:50001231000000:2800:5F74539459C2373DA7777805E32729EB18FFDAD73AA70C2166E025C6827005F1.png?needInitFileName=true?needInitFileName=true)

To integrate the wireless connection function, the HMI app needs to call **startAdv()** , the advertisement sending API provided by the HiCar SDK, to send the BLE advertisement, and call **onPinCode()** to obtain the connection PIN and display it on the app screen. After the phone supporting HiCar receives the advertisement and the PIN is entered, obtain the corresponding connection event from the callback method **onDeviceChange()**.
