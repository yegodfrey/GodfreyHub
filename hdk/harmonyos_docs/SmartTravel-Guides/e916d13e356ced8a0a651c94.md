# Introduction to Open Capabilities

#### Overview

#### Integration Description

You only need to integrate the HiCar open capabilities to your app to make the app HiCar-compatible, but do not need to develop a whole new app for HiCar.

However, you need to re-design the UI dedicated for head unit display based on the HiCar design specifications, instead of directly using the UI for phone screen.
