# Keys on the Steering Wheel

**Rule 2-2: When HUAWEI HiCar is not connected, the user should be able to press or press and hold a key on the steering wheel to access the connection screen.**

**When HUAWEI HiCar is connected, the user should be able to press a key on the steering wheel to wake up the HUAWEI HiCar voice assistant and bring the HUAWEI HiCar screen to the foreground.**
