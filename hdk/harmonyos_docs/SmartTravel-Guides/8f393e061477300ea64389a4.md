# Managing Buttons, Knobs, and Touchpads

#### Scenario

HiCar allows users to control apps and services by using physical buttons and knobs. For example, the user can press the corresponding button to play the next music track or end a call. When integrating the HiCar SDK, report physical button and knob events to the HiCar SDK to control the corresponding apps and services.

#### APIs

**Table 1** APIs related to buttons and knobsHeader File | Method | Description  
---|---|---  
hicar.h | HiCarPostEvent | Sends a button event. For information about button and knob events supported by the HiCar SDK, see Table 2.  
  
You do not need to report the button events that do not require the handling of HiCar, such as those of the volume control buttons and mute button. For the physical button events that need to be reported, see Table 2.

#### Development Procedure

     1. When a physical button or knob is triggered, you need to parse the corresponding event.
     2. Send the corresponding event to the HiCar SDK via the **HiCarPostEvent** API. Note that the down event and up event must be sent in pairs.

The following is the sample code:
            
            void SendKeyEvent()
            {
                if (g_hicarHandle == NULL) {
                    printf("hicar handle null\n");
                    return;
                }
                printf("SendKeyEvent start\n");
                HwRemoteCtrlEvent *obj = (HwRemoteCtrlEvent*)HiCarNewObject(g_hicarHandle, HICAR_OBJECT_REMOTE_CTRL, sizeof(HwRemoteCtrlEvent));
                if (obj != NULL) {
                    obj->header.version = 0;
                    obj->header.dFlag = 1;
                    obj->header.wFlag = 0;
                    obj->header.wr1Flag = 0;
                    obj->header.wr2Flag = 0;
                    obj->header.rFlag = 0;
                    obj->header.inputCategory = 0;
                    obj->header.len = 10;
                    obj->evtType = REMOTECTRL_KEY;
            	obj->timestamp = 0;
            	obj->evtDetail.keyEvt.type = REMOTECTRL_KEY_DOWN
            	obj->evtDetail.keyEvt.keyCode1 = 5; // 5 call, 6 end call
            	obj->evtDetail.keyEvt.keyCode2 = 0;
            	obj->evtDetail.keyEvt.metaState = 0;
            
                    HiCarPostEvent(g_hicarHandle, HICAR_EVENT_REMOTE_CTRL, (char*)obj, sizeof(*obj));
                    //HiCarDeleteObject(g_hicarHandle, HICAR_OBJECT_REMOTE_CTRL, (char*)obj);
                }
                printf("SendKeyEvent end\n");
                return;
            }
