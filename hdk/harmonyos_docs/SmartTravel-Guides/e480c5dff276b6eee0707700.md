# Low-fuel, Low-battery, and Low-tire-pressure States (Beta)

#### Scenario

HiCar provides low fuel, low battery, and low tire pressure data for vehicle service apps to support service recommendation.

The head unit needs to proactively report the vehicle state data after HiCar is successfully connected, and update changes of state data.

For details about the related data format, please refer to [Low-fuel, Low-battery, and Low-tire-pressure States](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/low-fuel-battery-voltage-status-0000001199459869) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Development Procedure

     1. After the phone and head unit are successfully connected and the projection is successful, the head unit needs to report the current vehicle data the HiCar app through **HiCarSendData**. For a fuel vehicle, report the low fuel and low tire pressure states at the same time. For an electric vehicle, report the low battery and low tire pressure states at the same time. The head unit sends the following data:
            
            {
                "isOilEmpty":false,
                "isTpLow":false
            }

     2. After the state data of the head unit changes, the head unit needs to proactively update the state data. Only changed data needs to be reported. The head unit sends the following data:
            
            {
                "isOilEmpty":true
            }
