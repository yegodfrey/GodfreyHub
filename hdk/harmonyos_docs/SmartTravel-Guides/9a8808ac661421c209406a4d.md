# Driving State

#### Scenario

HiCar provides different apps and services for different driving status. For example, video playing and gameplay will be available when the vehicle is parked. As defined by HiCar, the driving status of a vehicle can either be on the move or parked:

     * On the move: The vehicle is put into the D (Drive), R (Reverse), or N (Neutral) gear. 
     * Parked: An automatic transmission vehicle is put into the P (Park) gear, or a manual transmission vehicle is put into the N gear and the handbrake is pulled up. 

After the head unit is connected to the phone, the head unit needs to proactively report the current driving status to the HiCar app and update any status changes in a timely manner. After receiving the driving status information reported by the head unit, HiCar responds to the message to prevent failure in obtaining driving status information caused by transmission issues.

If the head unit does not receive a response message from HiCar after sending the driving status information, the head unit needs to resend the driving status information for three times at an interval of 1s. If the head unit receives one response message from HiCar during the resending, the reporting is successful. If the response message is not received after three resends, the transmission link may be faulty. In this case, the head unit needs to record the exception information.

For details about the related data format, please refer to [Driving State](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/vehicle-running-status-0000001199289935) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Development Procedure

     1. After the phone and head unit are successfully connected and the projection is successful, the head unit needs to report the current driving status to the HiCar app through **HiCarAdapter::sendCarData**. The head unit sends the following data:
            
            {
                "drivingMode":1
            }

     2. After receiving the driving status data, the HiCar app sends response data (**dataType=506**) to the head unit. The following is an example of the response data:
            
            {
                "errorCode":100000
            }

     3. The head unit uses the **onDataReceive** method to determine the **dataType** , and can then receive the preceding data.
        1. If the returned result is success (with **errorCode** being **100000**), the driving status data has been successfully reported. 
        2. If an exception (with **errorCode** being a value other than **100000**) is returned, the head unit needs to handle the exception. 
        3. If the response message is not received, the head unit needs to resend the message.
