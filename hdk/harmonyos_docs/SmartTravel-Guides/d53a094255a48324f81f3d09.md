# Configuring Camera Information

#### Scenario

When initializing the HiCar SDK, the HMI app should report the camera information of the vehicle. After a HiCar connection is set up between the phone and head unit, the phone uses the cameras as virtual cameras of the phone through the HiCar SDK.

There are two types of cameras in the head unit:

     * Android camera: Cameras that can be used through standard Android APIs. If the HiCar SDK needs to use Android cameras, call **setAndroidCamInfos** by referring to this section to report the corresponding camera information during the initialization of the HiCar SDK.
     * Native camera: Cameras that cannot be used through the standard Android APIs. If the HiCar SDK needs to use such cameras, perform adaptation based on the camera-related APIs provided by HiCar. For details about the adaptations, see [Camera (Beta)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/camera-0000000000030830). After the adaptation is complete, call **setNativeCamInfos** to report the corresponding camera information during the initialization of the HiCar SDK.

The HiCar SDK uses only the camera information reported by the HMI app. You can selectively report the cameras that can be used by the HiCar SDK based on the actual situation. For example, you can report the information of the front-facing camera, but not report the information of the backup camera.

The HiCar SDK calls the standard Android camera service to read the attributes of Android cameras in the system. To tailor the Android camera service, call the **ignoreAndroidCamera** attribute provided by the SDK to explicitly instruct the SDK to ignore the Android camera check, preventing exceptions resulted from the SDK calling the APIs related to the camera service.

#### API Description

**Table 1** APIs for configuring customized camera informationClass | Method | Description  
---|---|---  
CarConfig | Builder.withCameraCustomDefine | Sets the camera information of the head unit during HiCar SDK initialization.  
Builder.withIgnoreAndroidCamera | Specifies whether to ignore the Android cameras during HiCar SDK initialization.  
updateCameraCustomDefine | Updates the camera information of the head unit.  
CameraCustomDefine | setAndroidCamInfos | Configures the Android cameras, which are discovered and controlled through Android APIs.  
setNativeCamInfos | Configures the native cameras, which are discovered and controlled through non-Android APIs, that is, cameras that are adapted by using the APIs provided by the HiCar SDK. For details, please refer to [Camera (Beta)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/camera-0000000000030830).  
  
#### Development Procedure

     1. When the HiCar SDK is initialized, select the camera type. If your system has been adapted to support the Android cameras, you do not need to ignore the Android cameras. During the SDK initialization, call the standard Android camera service API to query the camera attributes and report the attributes to the phone. If the Android camera service has been tailored in your system, ignore the Android cameras to avoid SDK initialization exceptions.
            
            // Set head unit information.
            CarConfig.Builder builder = new CarConfig.Builder(); 
            // Specify whether to ignore the Android cameras.
            builder.withIgnoreAndroidCamera(true);
            CarConfig carConfig = builder.build(); 

     2. During HiCar SDK initialization, if the head unit has Android cameras that can be used by the HiCar SDK, construct the **CameraCustomDefine** object.

The following is the sample code:
            
            // Customized extension information of the camera
            CameraCustomDefine customDefine = **new** CameraCustomDefine();

     3. Fill in the information of the camera that can be used by the HiCar SDK.

For example, if the head unit has a camera on the driving position, the sample code reported to the HiCar SDK is as follows:
            
            Map<Integer, CameraExtInfo> androidCamInfos = new HashMap<>();
            CameraExtInfo extCam1 = new CameraExtInfo();
            extCam1.setDesc("Camera At Driver Position");
            extCam1.setLocation(CameraLocation.CAR_DRIVER);
            // Set only the Android camera whose ID is 1.
            androidCamInfos.put(1, extCam1);
            customDefine.setAndroidCamInfos(androidCamInfos);
            carConfig.updateCameraCustomDefine(customDefine);
