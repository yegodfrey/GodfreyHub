# Text Specifications

**Rule 2-7: The brand name "HUAWEI" and letters "H" and "C" in "HiCar" must be in upper case.**

Only standard expressions in this section can be used as additional explanations to the HUAWEI HiCar logo. In principle, no other text can be added.

Note:

     * "HUAWEI HiCar" must be used as a whole.
     * The word "HiCar" cannot appear independently in any consumer-oriented scenarios.
     * Do not modify the capitalization of each letter in "HUAWEI HiCar" or use the Chinese characters of the brand "HUAWEI". Only "HUAWEI HiCar" can be used.
