# Photographing with the Vehicle-mounted Camera (Beta)

#### Scenario Overview

If the head unit supports taking photos with the vehicle-mounted camera, the user can do so using HiCar voice control after the head unit is connected to HiCar.

For details about the related data format, please refer to [Photographing with the Vehicle-mounted Camera](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/vehicle-mounted-camera-0000001199459873) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Development Procedure

     1. The HiCar app queries whether the head unit supports taking photos with vehicle-mounted cameras.
        1. After the connection is successful, the HiCar app sends a query message (dataType=522) to the head unit to query whether taking photos with vehicle-mounted cameras is supported. The following is an example: 
               
               {
                   "service":"photo",
                   "subService":"capability",
                   "command":0
               }

        2. The head unit uses the **DataReceive** method to determine the data type and then receives the preceding data. Then, the head unit returns a response message through the **HiCarSendData** API.

Example: The head unit supports taking photos with the vehicle-mounted camera.
               
               {
                   "service":"photo",
                   "subService":"capability",
                   "command":0,
                   "errorCode":100000,
                   "data":{
                       "camera":{
                           "isControlSupported":3
                       }
                   }
               }

Example: The head unit does not support taking photos with the vehicle-mounted camera.
               
               {
                   "service":"photo",
                   "subService":"capability",
                   "command":0,
                   "errorCode":100004
               }

     2. The HiCar app controls the head unit to take photos using the vehicle-mounted camera. The head unit completes the operation and returns a response message.
        1. The HiCar app sends an instruction for taking photos to the head unit. The following is an example:
               
               {
                   "service":"photo",
                   "subService":"capability",
                   "command":1,
                   "data":{
                       "camera":{
                           "position":3
                       }
                   }
               }

        2. The head unit completes the operation and returns a response message based on the operation result.

Example of the response upon success:
               
               {
                   "service":"photo",
                   "subService":"capability",
                   "command":1,
                   "errorCode":100000
               }

Example of the response upon failure:
               
               {
                   "service":"photo",
                   "subService":"capability",
                   "command":1,
                   "errorCode":100004
               }

     3. The head unit reports photographing not triggered by HiCar to HiCar.

In this case, the head unit should complete the operation of taking photos using the vehicle-mounted camera, and report this incident to HiCar to avoid conflicts with the HiCar voice service. The following is an example:
            
            {
                "service":"photo",
                "subService":"capability",
                "command":2,
                "data":{
                    "camera":{
                        "position":3
                    }
                }
            }
