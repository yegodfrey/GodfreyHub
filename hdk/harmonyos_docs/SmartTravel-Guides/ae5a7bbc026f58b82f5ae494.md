# Notification for User-initiated Disconnection from the Head Unit

#### Scenario Overview

When automatic connection is supported, the head unit needs to correctly identify the scenario where the user proactively ends the HiCar connection so that the automatic connection is not initiated in this scenario.

When a user proactively terminates the HiCar connection, the HiCar app notifies the head unit of the disconnection. For details about the related data format, please refer to [Notification for User-initiated Disconnection from the Head Unit](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/disconnection-notification-0000001153460178) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

Note: After this message is received, if you want to return to the original head unit screen immediately, you can start another thread to call **HiCarDisconnectDevice** to disconnect the connection immediately.

#### Development Procedure

     1. The HiCar app sends a notification message (dataType=518) to the head unit when the user proactively terminates the HiCar connection. The following is an example:
            
            {
                "isUserDisconnect":0
            }

     2. The head unit uses the **DataReceive** method to determine the data type and then receives the preceding data. Then, the head unit returns a response message through the **HiCarSendData** API. The following is an example:
            
            {
                "isUserDisconnect":1
            }
