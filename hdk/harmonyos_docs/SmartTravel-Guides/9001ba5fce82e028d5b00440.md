# UI Specifications

**Recommendation 3-1: The connection exception prompt screen must comply with the standard layout and provide complete functions.**

#### P.4 Enabling Bluetooth automatically

Scenario: When Bluetooth is not enabled on the head unit, the user touches the HUAWEI HiCar icon, and the head unit automatically enables Bluetooth. A message is displayed, indicating that Bluetooth is being enabled. The prompt text is "HUAWEI HiCar needs to use Bluetooth."
