# Wireless Connection Process

The wireless HiCar connection process involves Bluetooth service discovery, Bluetooth pairing, Bluetooth RFCOMM connection, and Wi-Fi connection. Figure 1 shows the message exchange process during the wireless connection.

**Figure 1** Message exchange during the wireless connection

During the wireless connection, the phone interacts with the head unit to fulfill the following purposes:

     1. Carrying the Classic Bluetooth (BR) address of the head unit in a BLE advertising packet to the phone, so that the phone can establish a BR link according to the address.
     2. Establishing a low-speed Bluetooth control channel (RFCOMM control channel in the figure), based on which a Bluetooth data channel and high-speed Wi-Fi control channel can be established.
     3. Establishing a low-speed Bluetooth data channel (RFCOMM data channel in the figure) used for HiCar authentication.
     4. Negotiating a high-speed Wi-Fi channel based on the low-speed Bluetooth control channel.
     5. Establishing a high-speed Wi-Fi control channel (Wi-Fi control channel in the figure) to incubate high-speed Wi-Fi data channels.
     6. Establishing a high-speed Wi-Fi data channel (Wi-Fi data channel in the figure) for HiCar projection and service data transmission.
