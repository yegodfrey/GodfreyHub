# Initializing the SDK

#### Scenario

When initializing the SDK, the HMI app needs to set the basic information about the head unit, such as the screen size, Bluetooth address, driver position, and head unit type. Then the SDK is initialized at a proper time (generally when the user needs to use the vehicle, for example, when the head unit screen turns on after the vehicle is started).

#### API Description

**Table 1** Initialization API  Header File | Method | Description  
---|---|---  
hicar.h | HiCarInit | The HMI app should call the **HiCarInit** API to initialize the HiCar SDK when the user uses the vehicle (for example, the head unit screen turns on after the vehicle is started).  
  
#### Development Procedure

     1. Before calling the **HiCarInit** API to initialize the SDK, the HMI app constructs the **CarConfig** structure and prepares to set the basic information about the head unit.

The HMI app should provide the head unit parameters, as shown in Table 2, during the initialization of the HiCar SDK.

**Table 2** SDK initialization parameters  Parameter | Description  
---|---  
CarConfig | [CarConnectInfo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-connect-info-0000001050123078) | Head unit connection information, including the vendor ID obtained from Huawei, head unit Bluetooth MAC address, and connection modes supported by the head unit.  
[CarDeviceInfo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-device-info-0000001050166038) | Vehicle information, including the vehicle brand, current mode (dark/light), and driver's seat.  
[CarDisplayCapability](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-display-capability-0000001050167993) | Display information of the head unit, including the video encoding format, frame rate, and physical size of the screen.  
[CarFeatureInfo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/car-feature-info-0000001050166040) | Head unit characteristics information, including the model, OS version, CPU model, storage size, Bluetooth chipset model, and Wi-Fi chipset model.  
  
For details about initialization parameters, please refer to the HUAWEI HiCar SDK API Reference.
            
            CarConfig config;

            /* Vehicle brand information. */

            memcpy_s((void*)&(config.deviceInfo.dayNightInfo[0]), CAR_DAY_NIGHT_MAX_LEN, "pending", strlen("pending"));

            config.deviceInfo.steeringWheelPos = 0; // left
            /* Device type. For details, please refer to CarDeviceType. */

            /* Restrict entertainment apps in certain scenarios. */
            config.deviceInfo.entertainmentAllowType = HICAR_ONLY_PARK_ALLOW;  // Support entertainment apps only when the vehicle is parked, that is, entertainment apps are disabled during driving.

     4. Set the head unit display information.

     5. Set the head unit feature information. The following is the sample code:
            
            /* Set the head unit feature. */
            InitCarFeatureInfo(&config);
            
            /* Set InitCarFeatureInfo*/
            int32_t InitCarFeatureInfo(CarConfig *config)
            {
                if (config == NULL) {
                    return -1;
                }
                CarFeatureInfo *feature = &config->featureInfo;
                FillDataInfo(&feature->carModel, "XXXX");
                FillDataInfo(&feature->manufacturer, "qcom");
                FillDataInfo(&feature->model, "msm8937_32go");
                FillDataInfo(&feature->os, "8.1.0");
                FillDataInfo(&feature->cpu, "armeabi-v7a");
                FillDataInfo(&feature->ram, "1.81GB");
                FillDataInfo(&feature->rom, "9.68GB");
                FillDataInfo(&feature->screenSize, "12.82");
                FillDataInfo(&feature->screenMetrics, "1920 X 720");
                FillDataInfo(&feature->linuxKernel, "3.18.71");
                FillDataInfo(&feature->btChip, "QCC5120");
                FillDataInfo(&feature->wifiChip, "BCM6338");
                FillDataInfo(&feature->romVersion, "7.0.7.9");
                return 0;
            }
            void FillDataInfo(DataInfo *info, char *content)
            {
                if (info == NULL || content == NULL) {
                    return;
                }
            
                int len = strlen(content);
                if (len == 0) {
                    return;
                }
            
                info->value = (uint8_t *)malloc(sizeof(uint8_t) * (len + 1));
                if (info->value == NULL) {
                    return;
                }
                int ret = memset_s(info->value, sizeof(uint8_t) * (len + 1), 0, sizeof(uint8_t) * (len + 1));
                if (ret != EOK) {
                    return;
                }
                ret = memcpy_s(info->value, sizeof(uint8_t) * (len + 1), (uint8_t*)content, len);
                if (ret != EOK) {
                    return;
                }
                info->length = len;
                return;
            }

            CarLogFuncGroup logGroup;
            logGroup.logD = LogDebug;
            logGroup.logI = LogInfo;
            logGroup.logW = LogWarning;
            logGroup.logE = LogError;
            
            HiCarInit(&config, &logGroup);
