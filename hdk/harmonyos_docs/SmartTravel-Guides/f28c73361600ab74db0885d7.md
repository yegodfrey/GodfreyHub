# UI Specifications

You can modify the connection screens following the head unit UI style. The final style requires the confirmation from Huawei.

**Rule 3-1 Ensure that the connection process is complete and complies with the text specifications, and the layout is aligned to the center of the screen.**

#### P.1 Wireless connection prompt screen (wired & wireless/wireless only)

**Title** : HUAWEI HiCar connection code

**Prompt text:**

     * USB connectivity is supported: Place your phone near the console and make sure Bluetooth is on. When the phone detects the car, enter this code. You can also connect using a USB cable.
     * USB connectivity is not supported: Place your phone near the console and make sure Bluetooth is on. When the phone detects the car, enter this code.
