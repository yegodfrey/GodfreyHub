# Vehicle Sensor (Beta)

#### Scenario

After a HiCar connection is set up between the head unit and the phone, the HiCar app sends a request to the head unit to obtain the light intensity, vehicle speed, acceleration, and gyroscope data. After receiving the requested data, the head unit reports the corresponding data. After the corresponding data changes, report the changed data.

For details about the related data format, please refer to [Vehicle Sensor (Speed/Acceleration)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/vehicle-sensors-0000001153300362) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Development Procedure

     1. After the HiCar app is started and requires the vehicle sensor data, it sends a packet (**dataType=510**) to the head unit, instructing the head unit to report the required data. The head unit receives the following data:
            
            {
                "service": "sensorData", 
                "subService": "transmission", 
                "command": 0, 
                "data": {
                    "illumination": [1,1], 
                    "speed": 1, 
                    "acc": [1,1,1], 
                    "gry": [1,1,1]
                }
            }

     2. The head unit needs to report vehicle sensor data to the HiCar app through the **HiCarSendData** API. The head unit sends the following data:
            
            {
                "service": "sensorData", 
                "subService": "transmission", 
                "command": 1, 
                "data": {
                    "illumination": [100,1000], 
                    "speed": 80, 
                    "acc": [1.15,0.01,0], 
                    "gry": [1.10,3.15,0.45]
                }, 
                "timestamp": 1617087892722
            }

     3. When the vehicle sensor data changes, the latest sensor data is reported to the HiCar app.

The reporting interval is as follows:

        * Vehicle speed: Updated when the vehicle speed changes. To avoid message congestion, the update interval is 1s or longer for normal driving (less than 80 km/h) and 500 ms or longer for high-speed driving (greater than 80 km/h). 
        * Light intensity, acceleration, and gyroscope: Updated per second.
