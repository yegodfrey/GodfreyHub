# Wired Connection Process

HiCar allows users to connect HiCar-capable phones and head units with a USB cable.

Multiple USB modes are supported between the phone and the head unit, including charging only, USB storage, MTP, NCM, and AOA. A USB wired HiCar connection can be set up through NCM (AOA is not supported for the moment) to transmit data.

**Figure 1** USB wired HiCar connection process

     1. After the head unit is started, the HiCar SDK is initialized, during which the SDK needs to call the implemented USB driver. For details about the implementation of the driver, please refer to **driver_usb.c** in the HiCar SDK. During initialization, the vehicle information must be provided to the HiCar SDK through the specified API. This step is implemented by the HMI app. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000105632).
     2. The head unit listens for the USB device insertion event and determines whether the phone is a Huawei phone or Honor phone (including new Honor phones) based on **vendorID**.
     3. If the phone is identified as a Huawei phone or Honor phone (including new Honor phones), the head unit sends a USB control message to the phone, including the vehicle information, whether NCM is supported, IP address, and port number. For details about the USB control message, please refer to [Sending a USB Control Command](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/send-usb-control-command-0000001050123765). To be compatible with more phones, the head unit needs to start the mDNS server to broadcast the IP address and port number. For details, please refer to [mDNS Broadcast IP Address and Port Number](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/broadcast-ip-port-via-mdns-0000001059290770). The IP address and port number are notified to the head unit when the Nearby module in the HiCar SDK initializes the USB driver.
     4. The head unit waits for the phone to switch the USB mode to NCM.
     5. After detecting that the phone has switched the USB mode to NCM, the head unit attempts to establish a connection channel. To ensure that the connection can be set up, the head unit needs to configure the network information, including the IP address and network port, to its routing table. For details, please refer to [Configuring the Head Unit Routing Table](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/configure-route-table-0000001050002465).
     6. After a channel is set up between the phone and the head unit, the HiCar SDK sends the HICAR_DEVICE_CONNECTED event to the HMI app. The app will then start the projection. For details, please refer to [Establishing a Wired Connection](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wired-connectivity-0000000000105665).
