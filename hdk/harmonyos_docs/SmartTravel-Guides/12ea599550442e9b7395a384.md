# Checking Support for the Converged Desktop

#### Scenario

The converged desktop depends on the HiCar app on the mobile phone and the mobile phone system. When implementing the converged desktop feature, you need to check whether the converged desktop capability is supported in the current HiCar connection.

     * If the converged desktop capability is supported in the current HiCar connection, use the converged desktop display form.
     * If the converged desktop capability is not supported in the current HiCar connection, use the traditional display form.

#### API Description

You can use the following APIs to check whether the converged desktop capability is supported in the current HiCar connection.

**Table 1** APIs for checking the support for the converged desktop capabilityMethod | Description  
---|---  
AppTransManager.getInstance().isRemoteSupport() | Checks whether the converged desktop capability is supported in the current HiCar connection. The returned result is as follows:
     * **true** : yes
     * **false** : no  
  
#### Development Procedure

Call the **AppTransManager.getInstance().isRemoteSupport()** method provided by the HiCar SDK to check whether the converged desktop capability is supported in the current HiCar connection, after receiving the **EVENT_DEVICE_CONNECT** (whose value is **101**) event through the **onDeviceChange** API. This event indicates that the HiCar connection is established.
