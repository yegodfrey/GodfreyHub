# Vehicle Manufacturer Customization Information

#### Customization Information Description

As extensions of HUAWEI HiCar's capabilities, the brand and model features of the head unit can be added on the UI.

#### Vehicle Brand Logo

**Rule 7-1: The vehicle brand logo size must be 512 x 512 (square) in PNG format.**

Example: The vehicle brand logo is used on the icon for the user to touch to switch to the native head unit system when the head unit enters the HUAWEI HiCar screen.

**Figure 2** Vehicle brand logo  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210222.54803683755869522395233877413144:50001231000000:2800:382DF68C05D8365D8D4AFB082043C2FA66D24984CF6E05401F5F3610A0819231.png?needInitFileName=true?needInitFileName=true)

**Icon grid** : Icon elements should be aligned to the center of the shape, and fill the dark gray area of the shape to ensure pleasant visual effects. Icon elements should not appear in the light gray area.

#### Vehicle Marketing Name

**Rule 7-2: The vehicle marketing name can contain up to 11 English characters.**

Example: The vehicle marketing name is used for the vehicle brand icon on the head unit side, or the HUAWEI HiCar discovery and connection window and details screens on the phone side, or on the vehicle list or index screen in the AI Life app (currently unavailable).

#### Vehicle 45-degree Side View

**Size** : Length and width ≥ 1440 px

**Resolution** : ≥ 72 dpi

**Format** : PNG

**Color** : Consistent with the vehicle color (Contact Huawei if you have any difficulty providing the image)

**Content** : 45-degree side view of the vehicle body without background Besides the vehicle body, the image content should be transparent (confirm with Huawei for the shadow effect)

#### Vehicle Front View

**Size** : Length and width ≥ 1440 px

**Resolution** : ≥ 72 dpi

**Format** : PNG

**Color** : Consistent with the vehicle color (Contact Huawei if you have any difficulty providing the image)

**Content** : Standard side view of the vehicle body without background

Besides the vehicle body, the image content should be transparent (confirm with Huawei for the shadow effect)
