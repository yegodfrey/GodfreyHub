# Establishing a Wired Connection

#### Interaction Process

Before setting up a wired connection, you may need to configure the routing system of the head unit. For details, please refer to [Wired Connection Process](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wired-connection-process-0000001050002451).

#### Enabling Wired Connection of the SDK

The HiCar SDK processes USB insertion events and performs wired connections only when the wired connection function of the HiCar SDK is enabled.

The following is the sample code for enabling wired connection during SDK initialization:
    
    // Set whether to support wired connection during initialization. For details, please refer to the API Reference.
    CarConfig config;
    Config.connectInfo.connectAllowType = 0x02; // Indicate that only wired connection is supported.

#### Handling Authentication Event Callback

Wired connections do not require any PIN from the head unit. The HiCar SDK directly sends the PIN to the phone through the USB channel, and the user does not need to enter the PIN.

Though PIN-free, the wired connection still requires authentication. Therefore, the HMI app must implement the authentication callback API. The authentication callback implementation for wired connections uses the same logic and processing functions as that for wireless connections. For details about the implementation sample code, please refer to [Handling Authentication Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callback-0000001195856541#section16702192691018).

#### Handling Connection Event Callback

After the phone is connected to the head unit, the HMI app can obtain the connection event through callback, and perform operations such as projection and exiting the app based on the event. For details about the connection event callback method, see [Handling Connection Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callback-0000001195856541#section12985733201014) in the wireless connection section.
