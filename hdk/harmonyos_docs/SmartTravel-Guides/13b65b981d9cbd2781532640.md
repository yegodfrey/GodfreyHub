# Managing Connected Devices

#### Scenario

After the phone and the head unit are connected after authentication, the head unit needs to save the information about the authenticated devices and provide a connection authentication management UI to help the user manage authenticated devices on the head unit.

**Figure 1** Connection management

The HMI app can manage authenticated devices through the APIs provided by the HiCar SDK, including obtaining the authenticated device list, deleting authenticated devices, disconnecting devices, connecting devices, and switching connections by disconnecting and connecting devices.

#### API Description

**Table 1** APIs for connection authenticationClass | Method | Description  
---|---|---  
HiCarAdapter | getTrustDeviceList | Obtains the list of authenticated devices, including the phone ID, phone name, phone MAC address, and last connection time.  
deleteTrustDevice | Deletes an authenticated device.  
disconnectDevice | Disconnects from a specified device.  
startReconnect | Triggers automatic connection.  
  
#### Prerequisite

Before using **startReconnect** to trigger automatic connection, enable the automatic connection feature of the HiCar SDK. For details, please refer to [Enabling Automatic Connection on the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/automatic-connection-0000000000030747#section20548163618129).

#### Development Procedure

     1. You will need to complete the design and development of the authentication management UI. This UI must contain a list of authenticated devices, where users can select one authenticated device and delete it.
     2. The HMI app can obtain the information about the authenticated device through an API of the HiCar SDK, display the information on the authentication management UI, and delete or disconnect the device based on the user's selection.

The following is the sample code:
            
            // Obtain the list of authenticated devices.
            List<TrustPhoneInfo> trustPhoneList = mHiCarAdapter.getTrustDeviceList();
            
            // Delete an authenticated device, whose ID is obtained from the list of authenticated devices.
            mHiCarAdapter.deleteTrustDevice("xxxx");
             
            // Disconnect from the device, whose ID is obtained from the list of authenticated devices.
            mHiCarAdapter.disconnectDevice("xxxx");

     3. When a user selects to connect to a device, the HMI app needs to call the **startReconnect(String macAddress, boolean isManualReconnect)** API of the HiCar SDK to initiate a connection.

In the **startReconnect** API that initiates a reconnection, the number of parameters vary:

        * **startReconnect**(String macAddress): an automatic connection method, which is generally used when the vehicle is powered on. Automatic connection is supported only when the auto-connect switch is toggled on in the HiCar app's settings screen on the phone.
        * **startReconnect**((String macAddress, boolean isManualReconnect): an automatic connection method, which uses **isManualReconnect** to set whether to manually trigger a connection. When **isManualReconnect** is set to **true** , automatic connection is supported regardless of whether the auto-connect switch is toggled on in the HiCar app's settings screen on the phone.

In the scenario where the connection is manually initiated, use the **startReconnect(String macAddress, boolean isManualReconnect)** API to initiate the connection and set **isManualReconnect** to **true**.

     4. (Beta) Manage connection switchover. Currently, HiCar does not support connections of multiple phones to the head unit at the same time. However, you can enable the switchover to one of the phones for the HiCar connection.

HiCar connection switchover is not applicable when phones are connected to the head unit via USB. After a HiCar connection has been set up for a phone via USB, any other USB-connected phones can only be charged.

For the wireless connection case, when there are multiple phones that support HiCar, the HMI app can switch the HiCar connection among the phones.

The following is the sample code for switching the HiCar connection to phone B when phone A has established a HiCar connection with the head unit:
            
            // Obtain the list of connected devices.
            List<TrustPhoneInfo> list = mHiCarAdapter.getTrustDeviceList();
            // Check whether phone B is in the device list.
            for (TrustPhoneInfo info : list) {
                if (info.getPhoneBrMac() == targetMac) { 
                  // TODO: Save the MAC address.
                }
            }
            // Disconnect from the currently connected phone A and process the disconnection process.
            mHiCarAdapter.disconnectDevice(deviceId);
            ...
            // Make sure the head unit is initialized and phone B has been paired via Bluetooth.
            // Connect to the target phone B.
            mHiCarAdapter.startReconnect(targetMac,true);
