# HUAWEI HiCar Connection Management

**Rule 4-1: The head unit system must be equipped with the HUAWEI HiCar connection management module.**

You can manage HUAWEI HiCar connections on the head unit. The connection management entry and UI style can be customized following the system style. For example, you can configure the entry to connection management in the settings menu.

#### List Sorting and Naming

**Rule 4-2: The currently connected device should appear at the top of the connection list.**

The currently connected device should appear in the top line of the device list. If no device is connected, the devices are displayed according to the connection sequence.

#### Device Management

**Rule 4-3: Provide an entry for disconnecting from a device in the connected device list.**

To allow the user to quickly disconnect a device from the head unit, an option for disconnection should be provided on the connection management screen.
