# Vehicle Service Channel

#### Scenario

HiCar provides an access channel for vehicle manufacturers' third-party services, so that third-party service apps can use this channel to connect to the head unit and send custom vehicle control commands, based on the phone-side CarKit capabilities.

The vehicle service channel involves the phone-side vehicle service apps, CarKit, HiCar, manufacturer's HMI app on the head unit, and HiCar SDK. To implement a complete vehicle service channel, vehicle service apps and HMI apps need to be collaboratively developed.

Based on the complexity of data exchanged between the vehicle service app and the head unit, the following two modes are provided:

     * For simple data of the character string type, the data is transmitted through the command packets provided by the HiCar SDK. 
     * For other complex data, such as images and videos, the data is transmitted through self-built transmission channels. 

For details about the related data format, see [Vehicle Service Channel](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/vehicle-service-access-0000001199330039) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Reporting Vehicle Service App Permissions to HiCar

After the phone and head unit are successfully connected and the projection is successful, the head unit needs to report the vehicle service app permissions to HiCar through **HiCarAdapter::sendCarData**. Only apps with required permissions can exchange data with the head unit. The following is an example of the packet:
    
    {
        "serviceInfo": { 
            "permission":"**com.android.demo** ", 
            "carBrand":"brand", 
            "carModel":"mode", 
            "version":"1.0" 
         }
    }

The following is an example of the packet sent by the head unit to HiCar: 
    
    **// Register an event listener for the data sent by HiCar.**
    **mHiCarAdapter.registerCarListener(new****carListener****());**
    ...
    CarListener carListener = new CarListener() {
        @Override
        public void onDeviceServiceChange(String serviceId, int state) {
            **// Projection is successful.**
    **if (state == HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAYING) {**
                **// Report the vehicle service app's permissions.**
    **** sendPermission();
    **}**
        }
    
        @Override
        public void onDataReceive(String deviceId, int dataType, byte[] bytes) {
    **if  (dataType == DATA_TYPE_SERVICE_CHANNEL)  {**
    ******// TODO: Process the custom vehicle service command and vehicle service channel sent by the mobile phone.**
    **}**
        }
     }
    
    public void sendPermission() {
        JSONObject command = new JSONObject();
        try {
            JSONObject serviceCommand  = new JSONObject();
            serviceCommand.put("permission", "com.android.demo");
            serviceCommand.put("carBrand", "brand");
            serviceCommand.put("carModel", "mode");
            serviceCommand.put("version", "1.0");
            command.put("serviceInfo", serviceCommand);
        } catch (JSONException e) {
            LogUtils.e(TAG, "sendPermission json exception");
            return;
        }
        **// Send a packet containing the vehicle service app permission information.**
    ******mHiCarAdapter.sendCarData(DATA_TYPE_SERVICE_CHANNEL,**
    **command.toString().getBytes(CommonUtil.UTF_8));**
    }

#### Registering a Listener for Vehicle Service Events through CarKit

After the vehicle service app is started, it detects that HiCar projection is successful. The app needs to proactively connect to the head unit and register to listen to vehicle service events.
    
    **// Connect to the head unit.**
    CarCommandMgr.getInstance().connectCar(mContext, new RequestCallBack<ConnectResponse>() {
        @Override
        public void onResult(ConnectResponse response) {
            if (response.getErrorCode() == ErrorCode.SUCCESS) {
    **// The connection is successful. Register a listener for the custom vehicle service commands.**
                CarCommandMgr.getInstance().listenCarReportData(mContext, new RequestCallBack<Response>() {
                    @Override
                    public void onResult(Response response) {
                        if (response.getErrorCode() == ErrorCode.SUCCESS) {
    **// The listener is successfully registered.**
                        }
                    }
                }, new CarEventListener<CarDataReport>() {
                        @Override
                        public void onListener(CarDataReport ataReport) {
    **// Receive a custom vehicle service command.**
                        }
                        @Override
                        public void onDisconnect() {
    **// The listener is invalid. Release resources or register the event listener again.**
                        }
                });
            }
        }
    });

#### Simple Data Transmission between Vehicle Service Apps and the Head Unit

Simple data transmission may be performed between the vehicle service app and the head unit by using a custom vehicle service command packet.

The following is an example of the packet data that is sent by the vehicle service app to the head unit (that is, the data received by the head unit through the **onDataReceive** method):
    
    {
        "dataToCar":"123"
    }

The following is an example of the packet data that is sent by the head unit to the vehicle service app through HiCar (that is, the data received by the vehicle service app through the **onListener** method in the preceding section):
    
    {
        "dataToApp":"123"
    }

The integration process is as follows:

     1. The vehicle service app sends a custom vehicle service command packet to HiCar through CarKit. The following is the sample code:
            
            ...
            **// Send a custom vehicle service command to the head unit.**
            **CarCommandMgr.getInstance().sendCommand**(mContext, "123", new RequestCallBack<Response>() {
                @Override
                public void onResult(Response response) {
                    if (response.getErrorCode() == ErrorCode.SUCCESS) {
                        **// Sent successfully.**
                    }
                }
            });
            ...

     2. The head unit uses the**onDataReceive** method to obtain the vehicle service command packet. For details, see the sample code in Reporting Vehicle Service App Permissions to HiCar.
     3. The head unit sends a custom vehicle service command packet to HiCar through **HiCarAdapter::sendCarData**. The following is the sample code:
            
            ...
            JSONObject command = new JSONObject();
            try {
                JSONObject command = new JSONObject();
                command.put("dataToApp", "123");
            } catch (JSONException e) {
                LogUtils.e(TAG, "send command json exception");
                return;
            }
            **// Send a custom vehicle service command to the phone.**
            **mHicarAdapter.sendCarData(DATA_TYPE_SERVICE_CHANNEL,** **command.toString().getBytes(CommonUtil.UTF_8));**
            ...

     4. After the vehicle service app registers a listener for the vehicle service event through CarKit, the vehicle service app uses the **onListener** method to obtain the vehicle service command packet. For details, see the sample code in Registering a Listener for Vehicle Service Events through CarKit.

#### Complex Data Transmitted through a Custom Channel

Complex data transmission may be performed between the vehicle service app and the head unit by using a custom vehicle service channel.

The integration process is as follows:

     1. The vehicle service app requests for a custom vehicle service channel to the head unit through CarKit. The following is the sample code:
            
            ...
            **// Requst for custom service.**
            **CarCommandMgr.getInstance().openChannel**(mContext, "request car service", new RequestCallBack<OpenChannelResponse>() {
                @Override
                public void onResult(OpenChannelResponse response) {
                    if (response.getErrorCode() == ErrorCode.SUCCESS) {
                        **// The request is successful. The vehicle service app can use the channelInfo and responseInfo returned by the head unit to implement custom services.**
            **String channelInfo = response.getChannelInfo();**
            **String responseInfo = response.getResponseInfo();**
                    }
                }
            });
            ...

     2. The head unit obtains the custom channel request of the vehicle service app from the phone by using the **onDataReceive** method. A packet example is as follows (**requestInfo** is provided by the vehicle service app, and other content is filled by HiCar):
            
            {    
                "requestService": {
                      **"requestInfo":"request car service",**
                      "serviceIp":"192.168.1.200",
                      "clientIp":"192.168.1.100",
                      "sessionId":"123"
                }
            }

     3. After receiving the request, the head unit determines whether to accept the request based on **requestInfo**. If the request is accepted, the head unit prepares a custom channel based on **serviceIp** and **clientIp** , and sends a response packet to the phone-side vehicle service app through the **sendCarData** API.

The following is an example of the response packet:
            
            {
                "responseService": {
                      "responseInfo":"response car service",
                      "channelInfo":"192.168.1.100:100",
                      "result":"accept",
                      "sessionId":"123"
               }
            }

The following is the sample code: 
            
            ...
            JSONObject command = new JSONObject();
            try {
                JSONObject serviceCommand  = new JSONObject();
                serviceCommand.put("responseInfo", "response car service");
                serviceCommand.put("channelInfo", "192.168.1.100:100");
                serviceCommand.put("result", "accept");
                serviceCommand.put("sessionId", "123");
                command.put("responseService", serviceCommand);
            } catch (JSONException e) {
                LogUtils.e(TAG, "response exception");
                return;
            }
            
            **// Send a response packet for the custom channel of the vehicle service.**
            **mHicarAdapter.sendCarData(DATA_TYPE_SERVICE_CHANNEL,** **command.toString().getBytes(CommonUtil.UTF_8));**
            ...

     4. The vehicle service app uses the **onResult** method in step 1 to obtain the response returned by the head unit.
     5. The vehicle service app and head unit establish a custom channel by using the channel connection information obtained through negotiation in the preceding process, and perform data exchange. This part needs to be implemented by the vehicle service app and the head unit.
