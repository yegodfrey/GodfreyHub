# Handling Touchscreen Events

#### Scenario

During screen projection, the HMI app needs to identify the button and touchscreen events, and send the corresponding events to the HiCar SDK to control the app being projected.

A touchscreen event can be triggered by a single-finger touch or multi-finger touch. In case of a touchscreen event, the HMI app needs to encapsulate the event into the corresponding structure based on the requirements of the HiCar SDK and send the event to the HiCar SDK via the **HiCarPostEvent** API.

For details about how to handle button and knob events, see [Managing Buttons, Knobs, and Touchpads](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/physical-key-knob-0000000000105717).

#### Development Procedure

     1. After a touchscreen event occurs, you need to parse the corresponding event.
     2. Convert the event, fill the converted event into the **HwRemoteCtrlEvent structure** , and call **HiCarPostEvent** to send the touchscreen event. Note: A complete touchscreen event must include a down event and an up event.

The following is the sample code:
            
            //  Call **HiCarPostEvent** to send an event.
            void SendTouchEvent()
            {
                if (g_hicarHandle == NULL) {
                    printf("hicar handle null\n");
                    return;
                }
                printf("SendTouchEvent start\n");
                HwRemoteCtrlEvent *obj = (HwRemoteCtrlEvent*)HiCarNewObject(g_hicarHandle, HICAR_OBJECT_REMOTE_CTRL, sizeof(HwRemoteCtrlEvent));
                if (obj != NULL) {
                    printf("init HwRemoteCtrlEvent start\n");
                    obj->header.version = 0;
                    obj->header.dFlag = 1;
                    obj->header.wFlag = 0;
                    obj->header.wr1Flag = 0;
                    obj->header.wr2Flag = 0;
                    obj->header.rFlag = 0;
                    obj->header.inputCategory = 0;
                    obj->header.len = 10;
                    obj->evtType = REMOTECTRL_TOUCH;
                    obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_DOWN;
                    obj->evtDetail.touchEvt.numPointers = 1;
                    obj->evtDetail.touchEvt.pointerId[0] = 0;
                    obj->evtDetail.touchEvt.coordinateX[0] = x;
                    obj->evtDetail.touchEvt.coordinateY[0] = y;
                    HiCarPostEvent(g_hicarHandle, HICAR_EVENT_REMOTE_CTRL, (char*)obj, sizeof(*obj));
                }
                printf("SendTouchEvent end\n");
                return;
            }

#### Two-Finger Operation Scenario Examples

The following describes the adaptation to zooming in or out a map with two fingers.

     1. When the first finger is pressed, assuming that the coordinates are (x1, y1), a down event is sent.
            
            // obj is the HwRemoteCtrlEvent structure pointer.
            obj->evtType = REMOTECTRL_TOUCH;
            obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_DOWN;
            obj->evtDetail.touchEvt.numPointers = 1;
            obj->evtDetail.touchEvt.pointerId[0] = 0;
            obj->evtDetail.touchEvt.coordinateX[0] = x1;
            obj->evtDetail.touchEvt.coordinateY[0] = y1;

     2. When the second finger is pressed, the coordinates are (x2, y2), and a down event is sent.
            
            // obj is the HwRemoteCtrlEvent structure pointer.
            obj->evtType = REMOTECTRL_TOUCH;
            obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_DOWN;
            obj->evtDetail.touchEvt.numPointers = 2;
            obj->evtDetail.touchEvt.pointerId[0] = 0;
            obj->evtDetail.touchEvt.pointerId[1] = 1;
            obj->evtDetail.touchEvt.coordinateX[0] = x1;
            obj->evtDetail.touchEvt.coordinateY[0] = y1;
            obj->evtDetail.touchEvt.coordinateX[1] = x2;
            obj->evtDetail.touchEvt.coordinateY[1] = y2;

     3. When two fingers move at the same time, a move event is sent. The coordinates of the two points are updated in real time.
            
            // obj is the HwRemoteCtrlEvent structure pointer.
            obj->evtType = REMOTECTRL_TOUCH;
            obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_MOVE;
            obj->evtDetail.touchEvt.numPointers = 2;
            obj->evtDetail.touchEvt.pointerId[0] = 0;
            obj->evtDetail.touchEvt.pointerId[1] = 1;
            obj->evtDetail.touchEvt.coordinateX[0] = x1;
            obj->evtDetail.touchEvt.coordinateY[0] = y1;
            obj->evtDetail.touchEvt.coordinateX[1] = x2;
            obj->evtDetail.touchEvt.coordinateY[1] = y2;

     4. When the first finger is raised, assuming that the coordinates are (x2, y2), an up event is sent.
            
            // obj is the HwRemoteCtrlEvent structure pointer.
            obj->evtType = REMOTECTRL_TOUCH;
            obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_UP;
            obj->evtDetail.touchEvt.numPointers = 2;
            obj->evtDetail.touchEvt.pointerId[0] = 0;
            obj->evtDetail.touchEvt.pointerId[1] = 1;
            obj->evtDetail.touchEvt.coordinateX[0] = x1;
            obj->evtDetail.touchEvt.coordinateY[0] = y1;
            obj->evtDetail.touchEvt.coordinateX[1] = x2;
            obj->evtDetail.touchEvt.coordinateY[1] = y2;

     5. When the second finger is raised, the coordinates are (x1, y1), and an up event is sent.
            
            // obj is the HwRemoteCtrlEvent structure pointer.
            obj->evtType = REMOTECTRL_TOUCH;
            obj->evtDetail.touchEvt.type = REMOTECTRL_TOUCH_UP;
            obj->evtDetail.touchEvt.numPointers = 1;
            obj->evtDetail.touchEvt.pointerId[0] = 0;
            obj->evtDetail.touchEvt.coordinateX[0] = x1;
            obj->evtDetail.touchEvt.coordinateY[0] = y1;
