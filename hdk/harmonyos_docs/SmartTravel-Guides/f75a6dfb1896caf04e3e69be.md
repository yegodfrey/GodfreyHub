# Automatic Connection

Assume that the user has successfully connected to HUAWEI HiCar in wireless mode, and automatic connection is enabled on the phone. When the user enters the driving environment again after HUAWEI HiCar is disconnected manually, the head unit will automatically establish a wireless HUAWEI HiCar connection with the phone.

**Rule 3-3: During automatic connection, the home screen of the head unit must display a prompt for the connection status.**

Prompt text: "HUAWEI HiCar logo + Connecting to XXX" (replace XXX with the phone name)

**Rule 3-4: If the automatic connection fails, a connection failure message should be displayed on the head unit.**

Prompt text: "Unable to connect to HUAWEI HiCar. Please try again."

**Rule 3-5: During automatic connection, when the user touches the HUAWEI HiCar entry, the automatic connection will not be interrupted. The head unit should display a message indicating HUAWEI HiCar connection is being established.**

Prompt text: "Connecting to HUAWEI HiCar... Please wait."
