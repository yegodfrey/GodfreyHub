# Vehicle Brand Logo

#### Scenario

**Figure 1** Vehicle brand logo example  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210313.42931973196176181508721159707801:50001231000000:2800:AEFC7A1880BF2629F345EDA79288A463F9235244BB4025B2800E64B0DDA9AB21.png?needInitFileName=true?needInitFileName=true)

After HiCar is successfully connected, the HiCar UI is projected to the head unit screen. The user can touch the vehicle brand logo in the HiCar icon area to return to the native HMI screen of the head unit. This vehicle brand logo needs to be passed from the head unit to the HiCar app on the phone.

For details about the related data format, please refer to [Brand Logo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/brand-icon-0000001153300358) in the **APIs Between the HiCar App and Head Unit** section of the API Reference.

#### Development Procedure

     1. After HiCar is successfully connected, the HiCar app on the phone sends a request packet (**dataType=502**) to the head unit to request the vehicle brand logo. The head unit receives the following data:
            
            {
                "brandIconData":"PNG"
            }

     2. The head unit determines **dataType** via the **DataReceive** method and can then receive the preceding data. After the brand logo is prepared, the head unit reports the data through **HiCarSendData**. Sample code:
            
            int pngFileLen = 0;
            int maxBufLen = 1024*1024;
            uint8_t *buffer = (uint8_t*)malloc(sizeof(uint8_t)*maxBufLen);
            
            FILE *fp = fopen(pngFilePath, "rb");
            if (fp != NULL) {
                pngFileLen = fread(buffer, 1, maxBufLen, fp);
                fclose(fp);
            }
            HiCarSendData(handle, HICAR_DATA_BRAND_ICON_DATA, buffer, pngFileLen);
            free(buffer);
