# App Icon

To adapt to different UI styles of the head unit system, three app icon styles are provided. Use the standard color version in general scenarios. Use the single-color version when the head unit system uses a single-color scheme. Use the monochrome black-and-white version when the head unit system uses a black-and-white color scheme.
