# App Metadata (Audio/Call/Message/Scenario)

#### Scenario

HiCar sends audio, call, and navigation data to the head unit through open app metadata. After obtaining the metadata, the head unit uses the metadata for dashboard/HUD auxiliary display.

HiCar supports the following metadata:

     * Audio metadata: includes the song name, artist, duration, album, and playback status, but does not include lyrics. 
     * Call metadata: includes the contact name, incoming call number, and phone number type, and requires mobile phones running HarmonyOS 3.0 or later. 
     * Navigation metadata (not supported currently): includes the road name and directional arrow images. 
     * Message metadata: includes information such as insufficient battery power and device getting overheated. 
     * Scenario metadata: includes metadata for weather, calendar, AI Tips, and IoT. 

For details about the related data formats, please refer to [Metadata Capabilities](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/app-metadata-capability-0000001383252450) in the **APIs Between the HiCar App and Head Unit** section of the HUAWEI HiCar SDK API Reference.

The following describes the process of app metadata interaction:

1\. The head unit requests metadata from the HiCar app on the mobile phone.

2\. The HiCar app responds to the head unit's request and returns the open metadata types.

3\. The HiCar app starts sending metadata (user authorization is required for call metadata).

#### Call Metadata Authorization

As call metadata (such as incoming/outgoing call numbers and contacts) involves user privacy, HiCar will display a prompt requesting user authorization, and allow users to change the authorization settings.

#### Development Procedure

     1. Query the metadata types that can be opened by the HiCar app.

The head unit can send a request packet (**dataType** =**514**) through the **HiCarAdapter::sendCarData** API to query the open metadata types. The following is an example of the packet:
            
            {
                "RequestAAData":7 // If the first bit is set to 1, media metadata is being requested; if the second bit is set to 1, call metadata is being requested; if the third bit is set to 1, navigation metadata is being requested.
            }

The following is the sample code:
            
            JSONObject jsonObject = new JSONObject();
            jsonObject.put("RequestAAData",  7); // Requests media, call, and navigation metadata.
            mHiCarAdapter.sendCarData(514, jsonObject.toString().getBytes(StandardCharsets.UTF_8));

After receiving the request, the HiCar app immediately sends response data (**dataType** =**514**). The following is an example of the response packet:
            
            {    
                "ResponseAAData":{
                    "MEDIA":true, 
                    "CALL":true, 
                    "NAVIGATION":false    
               } 
            }

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210300.56753892715669866125950877826440:50001231000000:2800:945B5B7ED09730596C5937ED8F9EFDFA4C7982CA006E72DE3E5B2458BCE00827.png?needInitFileName=true?needInitFileName=true)

Among the navigation metadata, the directional arrow icons are displayed in Dark/Light mode. If the head unit does not support reporting Dark/Light mode, it will not be able to request navigation metadata. It is recommended that the head unit correctly process the logic related to Dark/Light mode when the HiCar SDK is initialized. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000030695).

     2. The head unit can receive the preceding and following data after determining the **dataType** by using the **onDataReceive** method. Check whether the metadata is opened before using the metadata.
        1. Use the audio metadata.

When the audio playback status changes, the HiCar app sends an audio metadata packet (**dataType** =**515**) to the head unit. The following is an example of the data received by the head unit:
               
               {
                   "MediaData": {
               	"Name": "dream it possible",
               	"Artist": "somebody",
               	"TotalTime": 500,
               	"ElapsedTime": 300,
               	"AlbumName": "name",
               	"AlbumArtURL": "url",
               	"Status": 300,
               	"AppName": "kugou",
               	"AppIcon": [],
               	"AppPackageName": "package name",
               	"AlbumArtIcon": [],
               	"IsAudioFromCar": false
                   }
               }

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210300.08532215565134542876235237837339:50001231000000:2800:AE0A761F0A73C614D0429995E8163590FB5A381671D6D8FF5C451D33E8D20D90.png?needInitFileName=true?needInitFileName=true)

           1. The audio metadata is transmitted only when the audio playback status changes, for example, when the audio is played/paused/cached/stopped. For details about the playback states, see the definition of **android.media.session.PlaybackState** or refer to the HiCar SDK API Reference. 
           2. The HMI app on the head unit will periodically update the audio playback progress. 
           3. The transmitted audio metadata does not include lyrics. 

The head unit can process audio metadata by referring to the following sample code:
    
    private void handleMediaData(String data) throws JSONException {
        org.json.JSONObject dataObj = new org.json.JSONObject(data);
        org.json.JSONObject metaDataObj = dataObj.getJSONObject("MediaData");
     
        String name = metaDataObj.optString("Name");
        String artist = metaDataObj.optString("Artist");
        int totalTime = metaDataObj.optInt("TotalTime");
        int elapsedTime = metaDataObj.optInt("ElapsedTime");
        String albumName = metaDataObj.optString("AlbumName");
        String albumArtUrl = metaDataObj.optString("AlbumArtURL");
        int status = metaDataObj.optInt("Status");
        String appName = metaDataObj.optString("AppName");
        org.json.JSONArray appIcon = metaDataObj.optJSONArray("AppIcon");
        String appPackageName = metaDataObj.optString("AppPackageName");
        org.json.JSONArray albumArtIcon = metaDataObj.optJSONArray("AlbumArtIcon");
        boolean isAudioFromCar = metaDataObj.optBoolean("IsAudioFromCar");
        Bitmap iconBmp = jsonArrayToBitmap(appIcon);
        Bitmap albumBmp = jsonArrayToBitmap(albumArtIcon);;
        ivMediaAppIcon.setImageBitmap(iconBmp);
        ivMediaAlbumIcon.setImageBitmap(albumBmp);
    }
    
    private Bitmap jsonArrayToBitmap(org.json.JSONArray src) {
        byte[] tmp = new byte[src.length()];
        for (int i = 0; i < src.length(); i++) {
            tmp[i] = (byte) (((int) src.get(i)) & 0xFF);
        }
        return BitmapFactory.decodeByteArray(tmp, 0, tmp.length);
    }

        2. Use the call metadata.

When the call status changes, the HiCar app sends a call metadata packet (**dataType** =**516**) to the authorized head unit based on the user authorization record. The following is an example of the data received by the head unit:
               
               {
                   "CallData": {
               	"ContactName": "tom",
               	"RemoteNumber": "123456789",
               	"Direction": 1,
               	"Status": 1,
               	"CallStartTimestamp": 1999,
               	"CallID": "123456789",
               	"CallApp": 2,
               	"NumberMarktype": "insurance",
               	"ReleaseCause": 1
                    }
               }

           1. The call metadata is transmitted only when the call status changes. For details about the call status definition, see the HiCar API Reference. 
           2. The HMI app on the head unit will periodically update the call duration. 
           3. Call metadata requires mobile phones running HarmonyOS 3.0 or later. 

The head unit can process the call metadata by referring to the following sample code:
    
    private void handleInCallData(String data) {
        org.json.JSONObject dataObj = new org.json.JSONObject(data);
        org.json.JSONObject metaDataObj = dataObj.getJSONObject("CallData");
        String contactName = metaDataObj.optString("ContactName");
        String remoteNumber = metaDataObj.optString("RemoteNumber");
        int direction = metaDataObj.optInt("Direction", 0);
        int status = metaDataObj.optInt("Status", 0);
        long callStartTimestamp = metaDataObj.optLong("CallStartTimestamp", -1);
        String callId = metaDataObj.optString("CallID");
        int callApp = metaDataObj.optInt("CallApp", 0);
        String numberMarkType = metaDataObj.optString("NumberMarktype");
        int releaseCause = metaDataObj.optInt("ReleaseCause", -1);
    }

        3. Use the navigation metadata (not supported currently).

When the navigation status changes, the HiCar app sends a navigation metadata packet (**dataType** =**517**) to the head unit. The following is an example of the data received by the head unit:
               
               {
                   "type": "update", // Create, update, or remove
                   "navData": {
                       "PackageName": "com.xxx.xxx",
               	"NavTurnImage": [],
               	"RoadName": "Drive to xxx road",
               	"Distance": "888 meters"
                   }
               }

The head unit can process the navigation metadata by referring to the following sample code: 
               
               private void handleNavData(String data) {
                   JSONObject jsonObject = JSONObject.parseObject(data);
                   String type = jsonObject.getString("type");
                   if ("update".equals(type)) {
               	org.json.JSONObject dataObj = new org.json.JSONObject(data);
                       org.json.JSONObject metaDataObj = dataObj.getJSONObject("navData");
               	String roadName = metaDataObj.optString("RoadName");
               	String distance = metaDataObj.optString("Distance");
               	org.json.JSONArray turnImage = metaDataObj.optJSONArray("NavTurnImage");
               	Bitmap turnBmp = jsonArrayToBitmap(turnImage);
               	ivTurnImg.setImageBitmap(turnBmp);
                  }
               }

        4. Use the message metadata.

When a message is generated, the HiCar app sends a message metadata packet (**dataType** =**531**) to the head unit. The following is an example of the data received by the head unit (pop-up message metadata is used as an example):
               
               {
                   "MessageData" : {
                       "Status" : 0,
                       "Type" : 2,
                       "Id" : 1020,
                       "Title" : "Message",
                       "AppIcon" : [],
                       "AppPackage" : "com.huawei.hicar",
                       "InfoImage" : [],
                       "MainText" : "Allow access to call data?",
                       "SubText" : "When allowed, devices connected will be able to use phone call data.",
                       "OptText" : "",
                       "Button1" : {
                           "BtnText" : "Confirm",
                           "BtnType" : "emphasize",
                       }
                       "Button2" : {
                           "BtnText" : "Cancel",
                           "BtnType" : "normal",
                       }
                       "Button3" : {
                           "BtnText" : "Do not show again",
                           "BtnType" : "check",
                       }
                   }
               }

After receiving the metadata, the head unit displays the data and sends a response message to the HiCar app. The following is an example of the response message:
               
               {
                   "MessageDataResp" : {
                       "RespCode" : 100000,
                       "Id" : 1020,
                       "Type" : 2,
                       "Button1" : true,
                       "Button2" : false,
                       "Button3" : true,
                   }
               }

        5. Use the scenario metadata. The ways to use calendar, weather, AI Tips, and IoT metadata are basically the same. The following takes weather metadata as an example. For details about other metadata, please refer to "App Metadata" in the **APIs Between the HiCar App and Head Unit** section of the HUAWEI HiCar SDK API Reference.
