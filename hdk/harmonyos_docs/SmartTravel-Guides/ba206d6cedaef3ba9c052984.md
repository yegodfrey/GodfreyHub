# Using Metadata to Build Head Unit's Native Screen

#### Scenario

HiCar provides basic information about audio, calls, messages, and scenario data for the head unit in the form of metadata. After obtaining the metadata, the head unit can display the metadata on its native screen, to create seamless connections between the phone and the head unit.

In the converged desktop form, the head unit can use the following metadata:

     * Audio metadata: includes the song name, artist, duration, album, and playback status, but does not include lyrics.
     * Call metadata: includes the contact name, incoming call number, and phone number type, and requires mobile phones running HarmonyOS 3.0 or later.
     * Navigation metadata (not supported currently): includes the road name and directional arrow images.
     * Message metadata: includes information such as insufficient battery power and device getting overheated.
     * Scenario metadata: includes metadata for weather, calendar, AI Tips, and IoT.
