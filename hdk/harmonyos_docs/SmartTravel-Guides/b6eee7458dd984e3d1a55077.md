# Writable Status of the Notification Log Area

#### Scenario

After initializing the SDK, the HMI app sends a message to notify the SDK when the writable status of the log area is Ready or changes. Then, the SDK writes the logs to the disk. In any other cases, the logs are maintained in the memory and are not written to the file.

This API applies to the scenario where the log storage area of the head unit is in the SD/TF card. This API prevents logs from being written before the SD/TF card is ready. In the non-SD/TF card scenario, this message is directly sent after the SDK is initialized.

#### API Description

**Table 1** API for sending message eventsHeader File | Method | Description  
---|---|---  
hicar.h | HiCarPostEvent | Notifies the HiCar SDK of whether the log area is writable. The value of **CarEventType** as an input parameter is **HICAR_EVENT_LOG_SECTION_CHANGE** , and **content** can be:
     * **1** : The log area is writable.
     * **0** : The log area is not writable.  
  
#### Development Procedure

     1. When the log area is writable, the HMI app notifies the HiCar SDK via **HiCarPostEvent** that logs can be written to the disk.
            
            uint32_t status = 1
            HiCarPostEvent(handle, HICAR_EVENT_LOG_SECTION_CHANGE, (char*)&status, sizeof(status));

     2. When the log area status changes or the log area becomes unavailable, the HMI app notifies the HiCar SDK via **HiCarPostEvent** so that logs will no longer be written to the disk.
            
            uint32_t status = 0
            HiCarPostEvent(handle, HICAR_EVENT_LOG_SECTION_CHANGE, (char*)&status, sizeof(status))
