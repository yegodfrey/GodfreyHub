# App Metadata (Audio/Call/Navigation)

#### Scenario

HiCar sends audio, call, and navigation data to the head unit through open app metadata. After obtaining the metadata, the head unit uses the metadata for dashboard/HUD auxiliary display.

HiCar supports the following metadata:

     * Audio metadata: includes the song name, artist, duration, album, and playback status, but does not include lyrics. 
     * Call metadata: includes the contact name, incoming call number, and phone number type, and requires mobile phones running HarmonyOS 3.0 or later. 
     * Navigation metadata (not supported currently): includes the road name and directional arrow images. 

For details about the related data formats, please refer to [en-us_topic_0000001383093924.html](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/app-metadata-capability-0000001383093924) in the **APIs Between the HiCar App and Head Unit** section of the HUAWEI HiCar SDK API Reference.

The following describes the process of app metadata interaction:

1\. The head unit requests metadata from the HiCar app on the mobile phone.

2\. The HiCar app responds to the head unit's request and returns the open metadata types.

3\. The HiCar app starts sending metadata (user authorization is required for call metadata).

#### Call Metadata Authorization

As call metadata (such as incoming/outgoing call numbers and contacts) involves user privacy, HiCar will display a prompt requesting user authorization, and allow users to change the authorization settings.

#### Development Procedure

     1. Request the open metadata types from the HiCar app.

The head unit can send a request packet (**dataType** =**514**) through the **HiCarSendData** API to request the open metadata types. The following is an example of the packet:
            
            {
                "RequestAAData":7 // If the first bit is set to **1** , media metadata is being requested; if the second bit is set to **1** , call metadata is being requested; if the third bit is set to **1** , navigation metadata is being requested; if all bits are set to **0** , the request stops and the HiCar app stops sending metadata to the head unit.
            }

The following is the sample code:
            
            char *metadataRequest = "{\"RequestAAData\":7}"; // Requests media, call, and navigation metadata.
            HiCarSendData(g_hicarHandle, HICAR_DATA_AA_DATA, metadataRequest, strlen(metadataRequest ) + 1);

After receiving the request, the HiCar app immediately sends response data (**dataType** =**514**). The following is an example of the response packet:
            
            {    
                "ResponseAAData":{
                    "MEDIA":true, 
                    "CALL":true, 
                    "NAVIGATION":false    
               } 
            }

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210315.19217531106532624296226671156637:50001231000000:2800:1718E24FB53A79BD991E36E2297F240333CEA30E9DEC0E950B560C8CF18CB5F4.png?needInitFileName=true?needInitFileName=true)

Among the navigation metadata, the directional arrow icons are displayed in Dark/Light mode. If the head unit does not support reporting Dark/Light mode, it will not be able to request navigation metadata. It is recommended that the head unit correctly process the logic related to Dark/Light mode when the HiCar SDK is initialized. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000105632).

     2. The head unit can receive the preceding and following data after determining the **dataType** by using the **onDataReceive** method. Check whether the metadata is opened before using the metadata.
        1. Use the audio metadata.

When the audio playback status changes, the HiCar app sends an audio metadata packet (**dataType** =**515**) to the head unit. The following is an example of the data received by the head unit:
               
               {
                   "MediaData": {
               	"Name": "dream it possible",
               	"Artist": "somebody",
               	"TotalTime": 500,
               	"ElapsedTime": 300,
               	"AlbumName": "name",
               	"AlbumArtURL": "url",
               	"Status": 300,
               	"AppName": "kugou",
               	"AppIcon": [],
               	"AppPackageName": "package name",
               	"AlbumArtIcon": [],
               	"IsAudioFromCar": false
                   }
               }

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210315.04797562760924836783214815002350:50001231000000:2800:CF85459899F38B1C90F028FA4EDE319AE4EF84DED0268F8DC1923D55396440A1.png?needInitFileName=true?needInitFileName=true)

           1. The audio metadata is transmitted only when the audio playback status changes, for example, when the audio is played/paused/cached/stopped. For details about the playback states, see the definition of **android.media.session.PlaybackState** or refer to the HiCar SDK API Reference. 
           2. The HMI app on the head unit will periodically update the audio playback progress. 
           3. The transmitted audio metadata does not include lyrics. 

        2. Use the call metadata.

When the call status changes, the HiCar app sends a call metadata packet (**dataType** =**516**) to the authorized head unit based on the user authorization record. The following is an example of the data received by the head unit:
               
               {
                   "CallData": {
               	"ContactName": "tom",
               	"RemoteNumber": "123456789",
               	"Direction": 1,
               	"Status": 1,
               	"CallStartTimestamp": 1999,
               	"CallID": "123456789",
               	"CallApp": 2,
               	"NumberMarktype": "insurance",
               	"ReleaseCause": 1
                    }
               }

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210315.37337392025834571478597576438519:50001231000000:2800:35953496A221C63F71A072F89B5F1D6671C356A19B86935DF17928742A29FAC5.png?needInitFileName=true?needInitFileName=true)

           1. The call metadata is transmitted only when the call status changes. For details about the call status definition, see the HiCar SDK API Reference. 
           2. The HMI app on the head unit will periodically update the call duration. 
           3. Call metadata requires mobile phones running HarmonyOS 3.0 or later. 

        3. Use the navigation metadata.

When the navigation status changes, the HiCar app sends a navigation metadata packet (**dataType** =**517**) to the head unit. The following is an example of the data received by the head unit:
               
               {
                   "type": "update", // Create, update, or remove
                   "navData": {
                       "PackageName": "com.xxx.xxx",
               	"NavTurnImage": [],
               	"RoadName": "Drive to xxx road",
               	"Distance": "888 meters"
                   }
               }
