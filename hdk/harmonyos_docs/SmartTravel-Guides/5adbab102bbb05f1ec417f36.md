# Introduction to Open Capabilities

HUAWEI HiCar SDK is a software development kit provided by HUAWEI HiCar (HiCar for short) for vehicle hardware devices. It provides app APIs for vehicle hardware vendors to access HiCar to implement HMI apps and provides device APIs to connect to hardware devices.
