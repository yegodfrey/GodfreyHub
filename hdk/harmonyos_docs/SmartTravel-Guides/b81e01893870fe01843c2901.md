# Starting/Stopping Head Unit Advertisement

#### Scenario

When the HMI app is started, or the user presses a physical button on the head unit (such as long pressing the voice wakeup button), the HMI app can call **HiCarStartAdv** to send the BLE advertising packets. After the connection is successful, the HMI app can call **HiCarStopAdv** to stop the BLE advertisement. When calling these APIs, the HMI app should determine whether the advertisement is really started or stopped based on the return value.

#### API Description

**Table 1** APIs related to advertisingAPI | Method | Description  
---|---|---  
- | HiCarStartAdv | The HMI app starts BLE advertising via this API.  
HiCarStopAdv | The HMI app stops BLE advertising via this API.  
CarListener | DeviceChange | The HiCar SDK notifies the HMI app of the advertising events through callback.
     * **HICAR_DEVICE_ADV_TIMEOUT** (value being **111**): Advertising times out. After receiving the event, the HMI app needs to re-initiate advertising and update the PIN.
     * **HICAR_DEVICE_DISPLAY_SERVICE_PLAYING** (value being **207**): The projection is successful. After receiving the event, the HMI app can obtain the video stream data via **GetVideoData**.  
  
#### Development Procedure

     1. When the HMI app is started or the user presses the physical button on the head unit, the Bluetooth status of the head unit needs to be checked.

If Bluetooth is not enabled on the head unit, the HMI app needs to enable Bluetooth on the head unit.

     2. Send the BLE advertising via **HiCarStartAdv**.

The following is the sample code for calling the API to send advertising packets:
            
            //Start advertising.
            int retCode = HiCarStartAdv(); 
            if (retCode == 0) { 
                Log.i(TAG, "handleStartAdv: start adv success"); 
                return; 
            } 

     3. Obtain the PIN. For details, see [Handling PIN Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callback-0000001195856541#section2561617101014).

After the HMI app initiates BLE advertising, the HiCar SDK generates the corresponding PIN. The HMI app needs to display the PIN on the head unit screen. The PIN is used as the connection verification code in the current advertising period. The user needs to enter the correct PIN to connect to the head unit.

     4. Listen for advertising timeout events.

After initiating BLE advertising, the HMI app needs to listen for advertising timeout events in **DeviceChange**. Upon receiving a timeout event, the HMI app needs to re-initiate advertising.

The following is the sample code:
            
            void DeviceChange(const char *deviceId, uint32_t idLen, int state, int errorCode)
            {
                printf("DeviceChange, deviceId:%s, state:%d\n", deviceId, state);
                switch (state) {
                    case HICAR_DEVICE_ADV_TIMEOUT:
                    // Re-initiate advertising.
            
                    break;
                    default:
                    break;
                }
            }

     5. Process the authentication callback. For details, see [Handling Authentication Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callback-0000001195856541#section16702192691018).

The HMI app needs to store the HiCar SDK and head unit authentication information in the head unit system, and read, save, and delete the authentication file by using the callback methods provided by the HiCar SDK.

     6. Process the connection event callback. For details, see [Handling Connection Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callback-0000001195856541#section12985733201014).

The HMI app needs to listen for connection events and complete corresponding logic processing based on the connection events.

     7. Upon receiving the connection success event, the HMI app stops sending BLE advertising by calling **HiCarStopAdv**.

After the connection is successful, the HiCar SDK automatically stops the BLE advertising. The HMI app can also call the API to stop the advertising. The sample code is as follows:
            
            //Stop advertising.
            int retCode = HiCarStopAdv(); 
            if (retCode != 0) { 
                Log.d(TAG, "handleStopAdv failed"); 
            }

     8. Listen for projection success events and obtain video streams.

After the connection is successful, the HiCar SDK automatically starts the projection process. The HMI app needs only to pay attention to projection success events. After receiving the **HICAR_DEVICE_DISPLAY_SERVICE_PLAYING** event (indicating a projection success event), the HMI app can call **GetVideoData** to obtain video streams. For details, see [Projection Description](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/interaction-process-0000001050121798).
