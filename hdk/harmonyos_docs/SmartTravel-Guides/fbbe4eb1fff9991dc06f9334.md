# Operations on Screen (Beta)

#### Scenario Overview

If the head unit can be turned on/off, the user can do so using HiCar voice control after the head unit is connected to HiCar,

For details about the screen control data format, please refer to [Turning the Screen On/Off](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/screen-on-off-0000001153300364) in the **APIs Between the HiCar App and Head Unit** section in the _HUAWEI HiCar SDK API Reference_.

#### Development Procedure

     1. The HiCar app queries whether the head unit supports turning on/off the screen.
        1. After the connection is successful, the HiCar app sends a query message (dataType=521) to the head unit to query whether the screen can be turned on/off. The following is an example: 
               
               {
                   "queryScreenState":"state"
               }

        2. The head unit uses the **DataReceive** method to determine the data type and then receives the preceding data. Then, the head unit returns a response message through the **HiCarSendData** API.

Example: The head unit does not support turning the screen on/off.
               
               {
                   "isSupportAbility":-1
               }

Example: The head unit supports turning the screen on/off, and the screen is currently on.
               
               {
                   "isSupportAbility":1,
                   "screenState":1
               }

Example: The head unit supports turning the screen on/off, and the screen is currently off.
               
               {
                   "isSupportAbility":1,
                   "screenState":2
               }

     2. The HiCar app controls the head unit to turn on/off the screen via voice commands. The head unit completes the operation and returns a response message.
        1. The HiCar app sends an instruction for turning on/off the screen to the head unit. The following is an example:
               
               //Turn on the screen
               {
                   "deviceScreenOper":1
               }
               
               //Turn off the screen.
               {
                   "deviceScreenOper":2
               }

        2. The head unit completes the operation and returns a response message based on the operation result.

Example of the response upon success:
               
               {
                   "response":100000
               }

Example of the response upon failure:
               
               {
                   "response":100004
               }

     3. The head unit reports screen on/off not triggered by HiCar (such as by a physical button) to HiCar.

In this case, the head unit should complete the operation of turning on/off the screen, and report this incident to HiCar to avoid conflicts with the HiCar voice service. Example:
            
            {
                "screenStateChange":1
            }
