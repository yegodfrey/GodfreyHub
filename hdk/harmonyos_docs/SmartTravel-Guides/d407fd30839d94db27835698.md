# Establishing Scan to Connect (Beta)

#### Interaction Process

Scan to connect is a supplement to wireless connection. When the head unit cannot be connected through BLE advertising, use QR code scanning instead.

The only difference between scan to connect and the wireless connection implemented through BLE advertising is whether a QR code or PIN is used for identification.

This connection method requires you to adapt the Wi-Fi function. For details, please refer to [Description](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/note-0000001194049481). Note that only non-BLE-related items need to be completed.

#### Enabling Wireless Connection of the SDK

The connection channel for scan to connect is the same as that for wireless connection. Therefore, you need to enable wireless connection during initialization. For details about the sample code, please refer to [Enabling Wireless Connection of the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/setting-wireless-connection-parameters-0000001147240376#section1592814466522).

#### Obtaining the QR Code Value

During scan to connect, the HMI app can obtain the QR code value through the API provided by the HiCar SDK, convert the value into a QR code image, and display the image on the connection screen for the user to scan.

**Table 1** API for obtaining QR code valueClass | Method | Description  
---|---|---  
HiCarAdapter | generateQrCode | Generates a QR code for scan to connect.  
  
     1. The HMI app should draw the QR code connection screen.
     2. The HMI app obtains the QR code value by calling **generateQrCode**.

The validity period of the QR code value is 2 minutes, after which you will need to call the API again.

The sample code is as follows:
            
            String qrCode = mHiCarAdapter.generateQrCode();

     3. The HMI app should convert the code value into a QR code image and display the image on the QR code connection screen for the user to scan.

#### Handling Authentication Event Callback

In scan to connect mode, the head unit does not need to display the PIN separately, as the PIN is included in the QR code. However, the HMI app still needs to process the authentication callback to complete the authentication process.

The HMI app uses the same logic and processing functions for authentication event callback as in wireless connection mode. For details, please refer to [Handling Authentication Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callbacks-0000001193322373#section317145010317).

#### Handling Connection Event Callback

After the phone is connected to the head unit, the HMI app can obtain the connection event through callback, and perform operations such as projection and exiting the app based on the event. For details about the connection event callback method, refer to [Handling Connection Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callbacks-0000001193322373#section134661359336) in the wireless connection section.
