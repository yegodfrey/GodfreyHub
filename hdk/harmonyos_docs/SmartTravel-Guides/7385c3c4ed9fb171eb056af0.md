# Registering Event Listeners

#### Scenario

The HMI app needs to register event listeners through the APIs in the SDK, and perform service operations according to different events in the callback, such as starting projection after receiving a successful connection event.

#### API Description

For details about the callback methods of event listeners, refer to Table 1. For details about the callback parameters, see HUAWEI HiCar SDK API Reference. For details about how to process services based on callback events, see the subsequent sections in this document.

**Table 1** Callback methodsAPI | Callback Method | Description  
---|---|---  
CarListener | onDeviceChange() | Called back when the connection between the phone and the head unit changes. For details about the connection events, see Table 2.  
onDeviceServiceChange() | Called back when the service changes, including the projection service and modem call service. For details about the service events, see Table 2.  
onDataReceive() | Called back when the SDK receives data sent by HiCar on the phone. The HMI app can use this method to exchange data with HiCar and receive data such as vehicle control commands and navigation focus change notifications from HiCar. For details, please refer to [Data Interactions](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/data-interaction-0000001192952815).  
onPinCode() | Called back when the SDK generates a PIN. The HMI app obtains the PIN and displays it on the connection UI.  
getSecureFileSize() | Callback method related to the authentication file.  
readSecureFile()  
writeSecureFile()  
removeSecureFile()  
HiCarAdapter | registerCarListener | The HMI app should register the listener for HiCar events when initializing the SDK.  
  
**Table 2** Callback EventsCallback Method | Event | Description  
---|---|---  
onDeviceChange() | EVENT_DEVICE_CONNECT = 101 | Connected.  
EVENT_DEVICE_DISCONNECT = 102 | Disconnected.  
EVENT_DEVICE_CONNECT_FAILD= 103 | The device failed to be connected.  
EVENT_DEVICE_PROJECT_CONNECT = 104 | The projection channel is set up.  
EVENT_DEVICE_PROJECT_DISCONNECT = 105 | The projection channel is disconnected.  
EVENT_DEVICE_ADV_START = 106 | Advertisement discovery starts.  
EVENT_DEVICE_ADV_STOP = 107 | Advertisement discovery stopped.  
EVENT_DEVICE_MIC_REQUEST = 109 | Requesting to use the microphone of the head unit  
EVENT_DEVICE_MIC_RELEASE = 110 | The microphone of the head unit is released.  
EVENT_DEVICE_START_ADV_TIMEOUT = 124 | Advertisement discovery sending timed out.  
onDeviceServiceChange() | EVENT_DEVICE_SERVICE_PAUSE = 202 | The service is paused.  
EVENT_DEVICE_SERVICE_RESUME = 203 | The service is resumed.  
EVENT_DEVICE_SERVICE_START = 204 | The service starts.  
EVENT_DEVICE_SERVICE_STOP = 205 | The service stopped.  
EVENT_DEVICE_DISPLAY_SERVICE_PLAYING = 207 | Projection starts.  
EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED = 208 | Projection failed.  
EVENT_DEVICE_SERVICE_VIRMODEM_CALLING = 209 | Answering a modem call.  
EVENT_DEVICE_SERVICE_VIRMODEM_HANG_UP = 210 | A modem call is ended.  
EVENT_DEVICE_SERVICE_VOIP_CALLING = 214 | A VoIP call is answered.  
EVENT_DEVICE_SERVICE_VOIP_HANG_UP = 215 | A VoIP call is ended.  
  
#### Development Procedure

     1. Create a class to implement **CarListener**.

Currently, you can reserve the empty implementation of each callback method and fill in the corresponding service logic based on the actual service. The following is the sample code:
            
            public class HiCarListener implements **CarListener**{
            
            	@Override
            	public void onDeviceChange(String s, int i, int i1) {
            
            	}
            
            	@Override
            	public void onDeviceServiceChange(String s, int i) {
            
            	}
            
            	@Override
            	public void onDataReceive(String s, int i, byte[] bytes) {
            
            	}
            
            	@Override
            	public void onPinCode(String s) {
            
            	}
            
            	@Override
            	public long getSecureFileSize(String s) {
            		return 0;
            	}
            
            	@Override
            	public byte[] readSecureFile(String s) {
            		return new byte[0];
            	}
            
            	@Override
            	public boolean writeSecureFile(String s, byte[] bytes) {
            		return false;
            	}
            
            	@Override
            	public boolean removeSecureFile(String s) {
            		return false;
            	}
            }

     2. Register the implementation class of **CarListener** in the callback method that is successfully initialized.

The following is the sample code:
            
            HiCarAdapter.init(getApplicationContext(), mCarConfig, new HiCarInitCallback() {
            	@Override
            	public void onInitSuccess(HiCarAdapter hiCarAdapter) {
            		Log.i(TAG, "HiCar onInitSuccess");
            		if (hiCarAdapter == null) {
            			Log.d(TAG, "onInitSuccess: hiCarAdapter is null");
            			return;
            		}
            		mHiCarAdapter = hiCarAdapter;
            		int retCode = **mHiCarAdapter.registerCarListener(mHiCarListener)** ;
            		if (retCode != HiCarConst.SUCCESS) {
            			Log.d(TAG, "HiCar reg listener failed");
            			return;
            		}
            		
            		Log.i(TAG, "HiCar reg listener success");
            	}
            
            	@Override
            	public void onInitFail(int i) {
            		Log.i(TAG, "HiCar init failed");
            	}
            
            	@Override
            	public void onBinderDied() {
            		Log.i(TAG, "HiCar service bind died");
            	}
            });
