# Precautions for Android 11.0 Adaptation

This section describes the modifications involved in the Android 11 head unit adaptation. The adaptation mainly involves the Bluetooth and Wi-Fi modules. The adaptation of the Bluetooth module is mainly used for HiCar connection and device discovery. For details about the modification and adaptation of the Bluetooth module, see [3.1.2.2 Bluetooth](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/bluetooth-0000001193969601). The adaptation of the Wi-Fi module is mainly used for HiCar connection and video stream transmission. The following lists the modifications.

        private void notifyStationChanged(String action, String macAddress) {
            if (action != null && mContext != null) {
                Intent apStaChangedIt = new Intent(action);
                apStaChangedIt.putExtra("macInfo", macAddress);
                Log.i(TAG, "notifyStationChanged macAddress=" + macAddress);
                mContext.sendBroadcastAsUser(apStaChangedIt, UserHandle.ALL, android.Manifest.permission.ACCESS_WIFI_STATE);
            }
        }
    
        private class SoftApStateMachine extends StateMachine {
            // The original code is omitted.
            public static final int CMD_NOTIFY_STATION_ASSOCIATED = 12;
            public static final int CMD_NOTIFY_STATION_DISASSOCIATED = 13;
    
            // The original code is omitted.
            @Override
            public boolean processMessage(Message message) {
                switch (message.what) {
                    // The original code is omitted.
                    case CMD_NOTIFY_STATION_ASSOCIATED:
                        notifyStationChanged(ACTION_WIFI_AP_STA_JOIN, (String) message.obj);
                        break;
                    case CMD_NOTIFY_STATION_DISASSOCIATED:
                        notifyStationChanged(ACTION_WIFI_AP_STA_LEAVE, (String) message.obj);
                        break;
                    default:
                        return NOT_HANDLED;
                }
            }
        }
