# Wireless Connection Description

Before integrating the wireless connection function into the HMI app, the Bluetooth and Wi-Fi functions must have already been integrated to the head unit. For details, please refer to [Wireless Connection Process](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wireless-connection-process-0000001052464951).

To integrate the wireless connection function, the HMI app needs to call **HiCarStartAdv** , the advertisement sending API provided by the HiCar SDK, to send the BLE advertising packets, and call **HiCarGetPinCode** to obtain the connection PIN and display it on the app screen. After the HiCar phone receives the advertising packets and the PIN is entered, the HMI app obtains the corresponding connection event from the callback method **DeviceServiceChange**.
