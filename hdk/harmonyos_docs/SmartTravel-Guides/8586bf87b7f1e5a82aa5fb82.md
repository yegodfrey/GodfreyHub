# Preparations

#### Obtaining Software Packages

Use your own toolchain to compile the HiCar Linux SDK software package. After you provide the compilation toolchain, Huawei will provide the SDK software package offline.

Make sure to use a configurable path (instead of a fixed one), if the build toolchain provided for Huawei needs to be installed or the environment variable configuration script needs to be executed. If there are other notes that require our attention, provide the corresponding documentation.

#### Understanding Software Package

The HiCar SDK obtained by the vendor contains the .so dynamic link library (DLL) file, header file, sample code, and configuration file.

#### [h2]Sample Code

The sample code is stored in the **samples** folder of the HiCar SDK package, including the sample code for the HMI app to call the HiCar SDK, the sample code for audio and camera adaptation on the device, and the sample code for Nearby adaptation on the device.

#### [h2]Configuration Files

The configuration files are stored in the **ConfigDir** directory of the HiCar SDK package, involving the event, region, and version configurations of the DFX log function. (By default, the HiCar SDK logs occupy about 15 MB of space.)

You only need to save the preceding configuration files under the specified log file path. For example, if the log file path is **/log/hicarlogs/** , the configuration files need to be stored in **/log/hicarlogs/ConfigDir/**. When the HiCar SDK is initialized, the configured complete path is notified to the HiCar SDK. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000105632).

#### Development Environment Requirements

The requirements of the HiCar SDK on the integrated development environment are the same as those of other embedded SDKs. In brief, introduce the header files in the HiCar SDK to the existing embedded development environment and place the dependent .so files in the searchable folders.

#### Vehicle Model ID that Can Be Used During Commissioning

Huawei assigns a unique ID to each vehicle model, which consists of the **ModelID** and **SubModelID**. The vehicle model ID is a hexadecimal string of four bytes. The first three bytes indicate the **ModelID** , and the fourth byte indicates the **SubModelID**.

You can use the test ID **00040900** for debugging, and apply for a formal vehicle model ID from Huawei for commercial use.
