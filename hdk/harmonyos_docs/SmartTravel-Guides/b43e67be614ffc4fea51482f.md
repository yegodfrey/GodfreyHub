# Physical Shortcut Keys (Beta)

#### Scenario

If the vehicle features physical keys for navigation, contacts, and music, after HiCar connection is established, the user can press these physical keys to open the map, contacts list, and music app of HiCar. However, the opened app cannot be specified. The map, contacts, or music app that is most recently used will be opened.

After detecting that a physical key on the head unit is pressed, the head unit reports corresponding data to HiCar.

For details about the related data format, refer to [Physical Shortcut Buttons](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/physical-shortcut-key-0000001153290432) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Development Procedure

After the phone and head unit are connected and projection starts, if the head unit detects that the physical shortcut key is pressed, the head unit should report the corresponding data to HiCar through **HiCarAdapter::sendCarData**. The head unit sends the following data: 
    
    {
        " KEYCODE":"NAVIGATION"
    }
