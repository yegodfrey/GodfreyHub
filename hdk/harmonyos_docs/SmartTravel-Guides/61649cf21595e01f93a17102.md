# Preparations

#### Scenario

Integrate the **hicarsdk.aar** file in the HiCar SDK package to develop an HMI app, which handles HiCar-related interactions and HMI display. You can refer to the HMI app in the **DemoApp Source Code/demoapp.zip** in the HiCar SDK.

#### Permission

The HiCar SDK requires the system permission to run. The HMI app also requires the system permission to calling the APIs of the HiCar SDK.

During the development of the HMI app, declare that the app requires the system permission in the **AndroidManifest.xml** file as follows:
    
    <manifest xmlns:android="http://schemas.android.com/apk/res/android"
        package="com.huawei.hicar.demoapp"
        **android:sharedUserId="android.uid.system"** >
        ......
    </manifest>

#### Development Procedure

     1. Create a project in Android Studio.
     2. Copy the **hicarsdk.aar** package in the software package to the **app/libs** directory of the project and add dependencies to the module-level **build.gradle**.

     3. Complete HMI app development by referring to the following sections in this document and the demo app source code in the SDK.

When developing HMI apps, follow the HUAWEI HiCar App UX Design Specification, which contains design specifications for UIs including but are not limited to the following:

        * Wired connection prompt UI
        * Wireless connection PIN UI
        * Ongoing connection UI
        * Connection exception prompt UI
     4. After developing your HMI app, sign it using the key of your vendor platform to ensure that the app runs as a system app.
