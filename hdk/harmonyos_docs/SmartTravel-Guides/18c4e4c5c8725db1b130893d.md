After the head unit is successfully connected to the phone, the HMI app starts the projection process.

#### Before Projection

Before starting the projection, the HMI app must ensure that:

     * Integrate projection views. The HMI app integrates the projection views on the projection UI. For details, please refer to [GUI Layout](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/ui-layout-0000001147321358).
     * Set projection parameters. The HMI app can set projection parameters during SDK initialization, or dynamically set the parameters when the SDK is running. For details about parameters and setting methods, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000030695) and [Updating Head Unit Information When the SDK Is Running](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/update-head-unit-information-0000000000030706) in this document.

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210256.18039932910481503096732898163233:50001231000000:2800:A8D21A21E2DFF55C631FCBA704FF43F16211B28D4B7EABC2367D20FEA8BD150C.png?needInitFileName=true?needInitFileName=true)

The projection parameters must be passed to the HiCar SDK before the projection starts. If the projection surface object changes during the projection, you need to reset the projection parameters for the HiCar SDK.

During the callback processing in the connection setup phase (as described in [Handling Connection Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callbacks-0000001193322373#section134661359336)), the HMI app should display the connection animation as the transition animation before projection after receiving the **EVENT_DEVICE_CONNECT** event.

**Table 1** API for processing connection event callbacksClass | Method | Description  
---|---|---  
CarListener | onDeviceChange | The HiCar SDK notifies the HMI app of the connection events through callback.
     * **EVENT_DEVICE_CONNECT** (value being **101**): The device is connected. After receiving a connection success event, the HMI app needs to stop the advertising and display the connection animation. The animation will last until the projection is successful or times out.
     * **EVENT_DEVICE_DISCONNECT** (value being **102**): The device is disconnected. After a disconnection event is received, the HMI app should exit.
     * **EVENT_DEVICE_CONNECT_FAILD** (value being **103**): The device fails to be connected. After a connection failure event is received, the HMI app should exit.  
  
The HMI app needs to determine the current connection state in the connection event callback.

     * If the connection is successful, start the connection animation screen via the callback. The connection animation screen will end after the projection success event is received.
     * If the connection is dropped, the projection stops and the projection screen is destroyed during callback processing.

#### Starting Projection

After the connection is successful, the HiCar SDK starts the projection service and notifies the HMI app of the service startup result through an event.

**Table 2** APIs for projectionClass | Method | Description  
---|---|---  
CarListener | onDeviceServiceChange | The HiCar SDK notifies the HMI app of the notification events through callback.
     * **EVENT_DEVICE_SERVICE_START** (value being **204**): The service starts. After the projection service is started, the HMI app receives this event. In this case, the HMI app needs to perform projection.
     * **EVENT_DEVICE_SERVICE_STOP** (value being **205**): The service stops. After the projection service is stopped, the HMI app receives this event. In this case, the HMI app needs to stop projection.
     * **EVENT_DEVICE_DISPLAY_SERVICE_PLAYING** (value being **207**): The projection is successful.
     * **EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED** (value being **208**): The projection failed.  
  
     1. After the **EVENT_DEVICE_SERVICE_START** event (the value is **204**) is received and surface drawing on the projection screen is complete, the HMI app starts projection.

The following is the sample code:
            
            CarListener carListener = new CarListener() {
                ...
                @Override
                public void onDeviceServiceChange(String serviceId, int state) {
                    if (state == **HiCarConst.EVENT_DEVICE_SERVICE_START**) {
                        // The projection service is started successfully.
                        // Add manufacturer service logics.
                    } 
            
                }
            };

The HMI app should start projection after the surface is drawn on the projection screen.

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210256.81988264369469804040201099038526:50001231000000:2800:1DCE53D0554C74C4E310AD3A682E66BE4003E7AE6E4AF25DF2C52DD298762C33.png?needInitFileName=true?needInitFileName=true)

The projection start API provided by the HiCar SDK can be called only after the projection screen is launched. The HMI app needs to listen to the **surfaceChanged** event, and process the projection logic after the surface is drawn.
            
            // After the surface is drawn on the projection screen, start the projection.
            mSurfaceView = (SurfaceView) findViewById(R.id.surface);
            if (mSurfaceView != null) {
                mSurfaceView.getViewTreeObserver().addOnGlobalLayoutListener(new ViewTreeObserver.OnGlobalLayoutListener() {
                    @Override
                    public void onGlobalLayout() {
                        mSurfaceView.getViewTreeObserver().removeOnGlobalLayoutListener(this);
             
                        mSurfaceView.getHolder().addCallback(new SurfaceHolder.Callback() {
                            @Override
                            public void surfaceCreated(SurfaceHolder surfaceHolder) {
                                Log.i(TAG, "surface view created");
                            }
             
                            @Override
                            public void **surfaceChanged**(SurfaceHolder surfaceHolder, int format, int width, int height) {
                                Log.i(TAG, "surface view changed: width = " + width + ", height = " + height);
                                if (surfaceHolder != null
                                        && surfaceHolder.getSurface() != null
                                        && surfaceHolder.getSurface().isValid()) {
                                    if (mDemoService.updateCarConfig(surfaceHolder.getSurface(), width, height)) {
                                        startProjection();
                                    }
                                } else {
                                    Log.i(TAG, "surface holder or surface is null or invalid");
                                    pauseProjection();
                                }
                            }
             
                            @Override
                            public void surfaceDestroyed(SurfaceHolder surfaceHolder) {
                                Log.i(TAG, "surface view destroyed");
                                pauseProjection();
                            }
                        });
                    }
                });
            }

     2. After the HMI app starts projection, listen for the projection event in the service event callbacks and handle the service based on the event result. For example, if the projection fails, the HMI app destroys the projection screen and returns to the native HMI screen. If the projection control and other guidance controls are in the same layout, you can hide other guidance controls after the projection is successful.

The following is the sample code for projection event callback:
            
            CarListener carListener = new CarListener() {
                ...
                @Override
                public void onDeviceServiceChange(String serviceId, int state) {
                    if (state == **HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAYING**) {
                        // Projection is successful.
                        // Add manufacturer service logics.
                    } else if (state == **HiCarConst.EVENT_DEVICE_DISPLAY_SERVICE_PLAY_FAILED**) {
                        // Projection failed.
                        // Add manufacturer service logics.
                    }
                }
            };

#### After Projection

The HMI app can arrange the projection view according to its needs: It can display the projection view in full screen mode, or integrate the view with the original HMI UI of the head unit.

     * When the projection view is displayed in full screen, the HMI app needs to process the switchover between the projection UI and the native HMI UI of the head unit.
     * When the projection view is not displayed in full-screen mode, the HMI app also needs to process the focus switching.

**Table 3** APIs related to video focus switchingClass | Method | Description  
---|---|---  
CarListener | onDeviceServiceChange | The HiCar SDK notifies the HMI app of the notification events through callback.
     * **EVENT_DEVICE_SERVICE_PAUSE** (value being **202**): Service is paused. When the user switches from the HiCar display mode to the native HMI mode, the HMI app receives this event. In this case, the HMI app needs to pause projection in the callback and switch the display mode to the native HMI mode.
     * **EVENT_DEVICE_SERVICE_RESUME** (value being **203**): The service is resumed. When the HMI app receives this event, it indicates that HiCar on the phone is started, and the HiCar projection UI needs to be displayed. In this case, the HMI app needs to start projection during callback processing, and switch the display screen to the HiCar projection UI.  
  
The following is the sample code for processing the video focus event:
    
    CarListener carListener = new CarListener() {
        ...
        @Override
        public void onDeviceServiceChange(String serviceId, int state) {
            if (state == **HiCarConst.EVENT_DEVICE_SERVICE_PAUSE**) {
               // Pause projection.
                mHiCarAdapter.pauseProjection();
                ...
               // Exit the HiCar projection UI.
            } else if (state == **HiCarConst.EVENT_DEVICE_SERVICE_START**) {
               // Bring the HiCar projection UI up.
                mHiCarAdapter.startProjection();
                ...
            }else if (state == **HiCarConst.EVENT_DEVICE_SERVICE_RESUME**) {
               // Bring the HiCar projection UI up.
                mHiCarAdapter.startProjection();
                ...
            }
        }
    };
