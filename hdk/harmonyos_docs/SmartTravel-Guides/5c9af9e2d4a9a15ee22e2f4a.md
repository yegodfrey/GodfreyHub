# Notification for User-initiated Disconnection from the Head Unit

#### Scenario

When automatic connection is supported, the head unit needs to correctly identify the scenario where the user proactively ends the HiCar connection so that the automatic connection is not initiated in this scenario.

When a user proactively terminates the HiCar connection, the HiCar app notifies the head unit of the disconnection. For details about the related data format, refer to [Notification for User-initiated Disconnection from the Head Unit](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/disconnection-notification-0000001199330041) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Development Procedure

     1. The HiCar app sends a notification message (**dataType=518**) to the head unit when the user proactively terminates the HiCar connection. The following is an example:
            
            {
                "isUserDisconnect":0
            }

     2. The head unit uses the **onDataReceive** method to determine the data type and then receives the preceding data. Then, the head unit returns a response message through the **HiCarAdapter::sendCarData** API. The following is an example:
            
            {
                "isUserDisconnect":1
            }
