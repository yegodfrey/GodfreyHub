# Obtaining the Connection Mode

#### Scenario

The HMI app can use the **HiCarGetConnectionType()** method to obtain the current connection mode and handle some service scenarios. For example, after a user successfully establishes a wireless connection, the phone and the head unit exchange data by using the newly established Wi-Fi AP. If the user manually modifies information about the Wi-Fi AP, the connection will be disconnected. To ensure that the HiCar connection functions properly, the HMI app can disable the function to modify the Wi-Fi AP information.

#### API Description

**Table 1** API for obtaining the connection modeHeader File | Method | Description  
---|---|---  
hicar.h | HiCarGetConnectionType | Returns the current connection mode, which can be:
     * **HICAR_CONNECTION_USB** (value being **6**): Wired connection.
     * **HICAR_CONNECTION_WIFI** (value being **3**): Wireless connection.
     * **HICAR_CONNECTION_UNKNOWN** (value being **0**): Unknown connection mode.  
  
#### Development Procedure

The following is the sample code for how an HMI app obtains the connection mode:
    
    //Obtain the connection mode.
    int connectType = **HiCarGetConnectionType(hicarHandle)** ;
    if (connectType == HICAR_CONNECTION_USB) {
         //TODO: Manufacturer's own logics
    } else if (connectType == HICAR_CONNECTION_WIFI) {
         //TODO: Manufacturer's own logics
    } else {
         //TODO: Manufacturer's own logics
    }
