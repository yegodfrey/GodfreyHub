# Displaying HiCar in the Foreground/Background

#### Scenario

In the integrated desktop form, HiCar notifies the head unit of switching the HiCar app to the foreground or background based on the real-time scenarios. The typical scenarios are as follows:

     * When the phone is connected to the head unit via HiCar, HiCar may display pre-projection screens for user authorization before initializing services. Such screens include the Safe Driving Statement, Privacy Statement update confirmation, Super Privacy mode, and the Out of Box Experience (OOBE) screen. Pre-projection screens will display during the initial connection or when any update is available on any pre-projection screens. In this case, the head unit needs to display HiCar for users to confirm upon successful connection, and switch HiCar back to the background to process relevant service logic of the converged desktop. 
     * When an app fails to be started (for example, when the network is poor, the music template screen fails to be loaded, or the user touches the confirm button on a failure prompt), the head unit needs to go back to its native screen and switch HiCar to the background. 
     * Some apps provide a button for users to directly go back to the head unit screen. When a user touches an app icon on the converged desktop, and then touches such a button in the app, the head unit needs to switch HiCar to the background. 

#### API Description

The API design for interactions between the converged desktop and the HiCar app inherits that for interactions between the head unit and the HiCar app. See [Data Interactions](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/data-interaction-0000001192952815) for reference before developing the converged desktop feature.

For details about the data format during interactions with the HiCar app when displaying HiCar in the foreground/background, see [HiCar in the Foreground/Background on the Converged Desktop](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/fusion-ui-foreground-background-0000001556888280) in the **APIs Between the HiCar App and Head Unit** section in the HUAWEI HiCar SDK API Reference.

#### Development Procedure

     1. The HiCar app sends a packet (**dataType** =**532**) to the head unit to switch HiCar to the foreground/background. The head unit receives the following data:
            
            {
                "ProjectAction" : {
                    "Background" : false
                }
            }

     2. The head unit uses the **onDataReceive** method to determine the **dataType** and receives the preceding data. Then, the head unit switches HiCar to the foreground/background based on the **Background** field, and returns the response message through **HiCarAdapter::sendCarData**. The sample code is as follows:
            
            {
                "ProjectActionResp" : {
                    "RespCode" : 100000
                }
            }
