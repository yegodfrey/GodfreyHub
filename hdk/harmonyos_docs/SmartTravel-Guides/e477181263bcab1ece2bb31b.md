# Navigation Focus

#### Scenario

By default, HiCar provides the navigation service. If the head unit also provides the native navigation service, conflicts may occur when they run at the same time. Therefore, HiCar and head unit need to negotiate about the navigation focus. The navigation focus types are as follows:

     * **HICAR** : Navigation service provided by HiCar. 
     * **HICAR_STOP** : Navigation service provided by the HiCar app has stopped. 
     * **NATIVE** : Native navigation service provided by the head unit. 
     * **NATIVE_STOP** : Native navigation service provided by the head unit has stopped. 

For details about the related data format, please refer to [Navigation Focus](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/navigation-focus-0000001153450244) in the **APIs Between the HiCar App and Head Unit** section of the API Reference.

#### Navigation Focus Negotiation Process

     * When HiCar starts navigation, it notifies the head unit that the navigation focus is **HICAR** , and the head unit needs to stop the native navigation service. If the head unit stops the native navigation, for better user experience, the head unit may notify the user that the native navigation has stopped. 
     * When the HiCar app stops navigation, it notifies the head unit that the navigation focus is **HICAR_STOP**. 
     * When the head unit starts navigation, it notifies HiCar that the navigation focus is **NATIVE** , and HiCar needs to stop the native navigation service. 
     * When the head unit stops navigation, it notifies the HiCar app that the navigation focus is **NATIVE_STOP**. 

#### Development Procedure

     1. After the HiCar app starts the navigation service, it sends a packet (**dataType=503**) to the head unit to notify the head unit that the navigation focus is **HICAR**. The head unit receives the following data:
            
            {
                "navFocus":"HICAR"
            }

     2. The head unit uses the **onDataReceive** method to determine the **dataType** , and can then receive the preceding data and stop the native navigation service.
     3. After the HiCar app stops navigation, it notifies the head unit that the navigation focus is **HICAR_STOP**. The head unit receives the following data:
            
            {
                "navFocus":"HICAR_STOP"
            }

     4. After starting the native navigation service, the head unit needs to notify the HiCar app that the navigation focus has been switched to **NATIVE** through **HiCarAdapter::sendCarData**. The head unit sends the following data:
            
            {
                "navFocus":"NATIVE"
            }

After receiving the navigation focus notification, HiCar stops the navigation service.

     5. After stopping the native navigation service, the head unit needs to notify the HiCar app that the navigation focus has been switched to **NATIVE_STOP** through **HiCarAdapter::sendCarData**. The head unit sends the following data:
            
            {
                "navFocus":"NATIVE_STOP"
            }
