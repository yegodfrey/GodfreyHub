# Entry

**Rule 2-1: For ease of use, the HiCar entry should be displayed on the home screen of the head unit, and the HUAWEI HiCar icon should be displayed.**

**In card entry mode, text should be used to distinguish between the disconnected and connected states.**

**After a connection is set up, the HUAWEI HiCar icon should be displayed in the status bar.**

The entry can be in the form of a card or an icon.
