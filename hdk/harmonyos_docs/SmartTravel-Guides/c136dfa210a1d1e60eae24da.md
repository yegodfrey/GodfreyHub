# Voice State

#### Scenario

The voice wakeup physical button of the head unit is generally a reused button, offering functions including launching/exiting the voice assistant and answering/ending calls. To enable the head unit to define and reuse the functions of the voice wakeup physical button based on the voice state, the HiCar app sends the current voice state to the head unit when the voice state changes.

For details about the related data format, please refer to [Voice State](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/voice-status-0000001199339965) in the **APIs Between the HiCar App and Head Unit** section in the API Reference.

#### Development Procedure

     1. When the voice state changes, the HiCar app sends a packet (**dataType=505**) to the head unit to notify the head unit that the HiCar voice is idle or woken up. The head unit receives the following data:
            
            {
                "voiceState":1
            }

     2. The head unit uses the **DataReceive** method to determine the **dataType** , and can then receive the preceding data.
