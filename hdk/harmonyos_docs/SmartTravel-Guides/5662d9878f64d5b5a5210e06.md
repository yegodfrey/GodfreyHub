# Obtaining the App List

#### Scenario

After the HiCar connection is established, the HMI app can request the list of apps integrated with HiCar from the HiCar app through the HiCar SDK. After the app list is obtained, the head unit displays the app information together with its native content in a converged manner.

#### API Description

Pay attention to the following classes when obtaining the apps supporting HiCar:

     * **AppTransManager** : converged desktop app manager class, which provides registration and deregistration APIs. It is a singleton that can be obtained using the **getInstance** method and destroyed using the **release** method. 
     * **AppInfoChangeListener** : converged desktop app data and event information class, which provides callback APIs for obtaining app data and app events (such as app installation and uninstallation). 

In addition, the API design for interactions between the converged desktop and the HiCar app inherits that for interactions between the head unit and the HiCar app. See [Data Interactions](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/data-interaction-0000001192952815) for reference before developing the converged desktop feature.

For details about the data format during interactions with the HiCar app when obtaining the app list, see [Converged Desktop App List](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/fusion-ui-app-list-0000001607807413) in the **APIs Between the HiCar App and Head Unit** section in the HUAWEI HiCar SDK API Reference.

#### Development Procedure

     1. Register a listener. Make sure that the code for listener registration is executed before Step 2.
            
            // Register a listener.
            AppTransManager.getInstance().registerAppInfoChangeListener(this);

     2. After the HiCar connection is established, the head unit can send a request packet (**dataType** =**528**) through the **HiCarAdapter::sendCarData** API, to obtain information about apps integrated with HiCar. The following is an example of the packet:
            
            {
                "RequestData" : "all",
                "RequestCaller" : "00040900"
            }

The following is the sample code:
            
            JSONObject jsonObject = new JSONObject();
            jsonObject.put("RequestData", "all");
            jsonObject.put("RequestCaller", "00040900");
            String data = jsonObject.toJSONString();
            mHiCarAdapter.sendCarData(528, data.getBytes(StandardCharsets.UTF_8));

     3. Obtain the app data returned by the HiCar app.

When the data request is successful, the HiCar SDK returns the list of apps supporting HiCar through the **onLoadAllAppInfo** callback function of **AppInfoChangeListener** , and triggers other callback functions during app installation or uninstallation. The callback functions are described as follows:

        * **onLoadAllAppInfo**(String deviceId, List<AppInfoBean> list): When the request is successful, this callback function is used to return the list of all apps that support HiCar and are installed on the current mobile phone. 
        * **onAppInfoAdd**(String deviceId, List<AppInfoBean> list): When an app that supports HiCar is installed, this callback function is used to return the list of newly installed apps. 
        * **onAppInfoRemove**(String deviceId, List<AppInfoBean> list): When an app that supports HiCar is uninstalled, this callback function is used to return the list of uninstalled apps. 
        * **onAppInfoUpdate**(String deviceId, List<AppInfoBean> list): When the information about apps supporting HiCar changes, for example, if an app icon changes, this callback function is used to return a list of apps whose information changes. 
     4. Unregister the listener and release resources after the HiCar connection is disconnected.
            
            // Unregister a listener.
            AppTransManager.getInstance().unregisterAppInfoChangeListener(this);
            // Release resources.
            AppTransManager..release();
