# About the Converged Desktop

In HiCar SDK 4.0.0.300 and later versions (for Android), HiCar has introduced a brand-new converged desktop form, which allows you to call APIs to obtain HiCar's app list and metadata from phone apps, and then display the apps together with the head unit's native apps.

The converged desktop is a new open capability developed based on the traditional HiCar Smart Desktop. Therefore, you will need to integrate the HiCar features following the previous sections, before integrating the converged desktop feature in this section.

By integrating the HiCar SDK, the HMI app can obtain a list of apps that support HiCar. You can display the apps on the head unit's native screen by referring to Converged Display of Apps. When a user touches an app icon, HiCar will display in the foreground, and when the user exits from the app, HiCar will switch to the background. In addition, the HMI app can obtain various metadata from HiCar by calling APIs provided by the SDK, including metadata of navigation, audio, calls, messages, and scenarios (calendar, weather, AI Tips, and IoT devices). Then, the head unit displays the metadata on its native screen, dashboard, HUD, or other locations that can display the metadata.

#### Connection Process

**Figure 5** Converged desktop interaction process  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210301.85634417598268131478177728206248:50001231000000:2800:C7CC8460D477BB5C3B413569F512B7B895AB96A596BDB4F74B129C01CE3E3F74.png?needInitFileName=true?needInitFileName=true)

After a HiCar connection is established, the core process is to obtain the list of apps supporting HiCar from HiCar, and to display the apps together with the head unit's native apps. In this process, you will need to display the complete HiCar screen in the foreground, for users to agree to the privacy statement, complete the OOBE, or perform other operations, before displaying the converged desktop.

When a user touches an app from HiCar on the converged desktop, the head unit needs to notify HiCar of the touched content and switch HiCar to the foreground. For details, see the following sections.
