# Handling Video Focus Switching

#### Scenario

The HMI app can arrange the projection view according to its needs: It can display the projection view in full screen mode, or integrate the view as part of the native HMI screen.

     * When the projection view is displayed in full screen, the HMI app needs to process the switchover between the projection UI and the native HMI UI of the head unit.
     * When the projection view is not displayed in full-screen mode, the HMI app needs to process the focus switching.

#### APIs

**Table 1** APIs forinterfaces related to video focus switching.API | Method | Description  
---|---|---  
CarListener | DeviceServiceChange | The HiCar SDK notifies the HMI app of the notification events through callback.
     * **HICAR_DEVICE_SERVICE_PAUSE** (value being **202**): When the user touches the exit button on the HiCar projection view, the HMI app receives this event. In this case, the HMI app should move to the background and call **HiCarPauseProjection** to pause projection.
     * **HICAR_DEVICE_SERVICE_RESUME** (value being **203**): The HMI app moves to the foreground when a call comes in or the voice assistant is wakened up, and calls **HiCarStartProjection** to start projection.  
  
#### Development Procedure

The following is the sample code for processing the video focus event:
    
    void DeviceServiceChange(const char *serviceId, uint32_t idLen, int state) {
        LOGD("DeviceServiceChange, state:%d", state);
        switch (state) {
            case HICAR_DEVICE_SERVICE_PAUSE: {  
                // Switch to the home screen of the head unit and call **HiCarPauseProjection** to pause the projection. 
    
                break;
            }
            case HICAR_DEVICE_SERVICE_RESUME: {  
                // Switch to the HiCar screen and call **HiCarStartProjection** to start projection.
    			
                break;
            }
    
            default: break;
        }
    }
