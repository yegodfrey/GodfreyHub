# Adaptations  
  
To allow HiCar to share certain sensor data of the head unit to enhance the related functions, implement the data reporting APIs based on the HiCar interface definitions. The adaptation requirements are as follows:

     * Audio: The adaptation is mandatory for HiCar to use the microphone and speaker of the head unit.
     * Camera: The adaptation is optional.
     * GPS and vehicle body data: The adaptation is optional.
