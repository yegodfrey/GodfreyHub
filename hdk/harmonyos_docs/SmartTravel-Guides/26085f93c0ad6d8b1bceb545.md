The HMI app can communicate with the components in the HiCar SDK after header files in the SDK package are integrated to the app.

     * SDK initialization: Set necessary head unit parameters in the HMI app for the SDK to use.
     * SDK deinitialization: After the HMI app is closed, clear the cached configuration data through the deinitialization API.

#### SDK Lifecycle

The HiCar SDK provides the **HiCarInit** and **HiCarRelease** APIs to control the SDK lifecycle.

     * When **HiCarInit** is called, the HiCar SDK is initialized.
     * When **HiCarRelease** is called, the HiCar SDK is deinitialized and clears the cached configuration information.

To ensure that users can use HiCar when they get on the vehicle and disconnect from HiCar when they get off, it is recommended that the HMI app control the lifecycle of the HiCar SDK in the following scenarios:
     * Initialization: The HMI app should call the **init** API to initialize the HiCar SDK when the user starts to use the vehicle (for example, the vehicle is started and the in-vehicle screen turns on).
     * Deinitialization: The HMI app should call the **HiCarRelease** API to deinitialize the HiCar SDK after the user stops using the vehicle (for example, after the user turns off the engine and the screen).
