# Change History  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210249.48360191637319934966217229393369:50001231000000:2800:ACC174E12BEAFFE096881FE3DC23CBB1ACA510DFCC5566FC3C5F1ACF08A67AA7.png?needInitFileName=true?needInitFileName=true)

Automotive hardware developers must pay attention to the following notes in the change history:

     * **Modified** : Modification or deletion of existing open capabilities, which requires special attention of developers. If the change is not adapted, the existing features will be affected. 
     * **Added** : New open capabilities. Developers can adapt to the new capabilities as required. If the adaptation is not performed, the existing features are not affected. 

Date | Version | Description  
---|---|---  
2022-05-30 | 2.4 | 
     1. [Modified] Since version 2.0.0.300, the HiCar SDK no longer requires that the mobile phone must be a HUAWEI or HONOR mobile phone during wired connection so that other mobile phones that support HiCar can connect properly. The manufacturer only needs to update the HiCar SDK to the latest version, without making other modifications. For details, please refer to [Wired Connectivity](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wired-mode-connection-0000001051064574). 
     2. [Added] The **AudioSourceConfig** parameter is added for SDK initialization. The values of **MIC** and **VOICE_COMMUNICATION** in **AudioSource** can be changed. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000030695). 
     3. [Added] Added descriptions about Android 11 adaptation. For details, please refer to [Precautions for Android 11.0 Adaptation](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/android-11-adaptation-0000001313355693).   
2022-03-11 | 2.3 | Added:
     1. Added description of virtual call capability reporting. For details, please refer to [Virtual Call (Beta)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/virtual-call-0000001212227824). 
     2. Added description of how the vendor processes carrier calls through the Bluetooth channel. For details, please refer to [Carrier Call (via Bluetooth)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/tele-call-bluetooth-0000001257144161). 
     3. Allowed the head unit to specify the IP address segment for wired connection. For details, please refer to [Configuring the Head Unit Routing Table](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wired-mode-connection-0000001051064574#section154359281312). 
     4. Added the following wireless connection parameters: 
        * **persist.sys.hicar.apsta.coexist** : Indicates whether the AP hotspot and Wi-Fi can coexist. 
        * **persist.sys.hicar.reuse.ap** : Indicates whether the existing AP hotspot of the head unit can be reused. 
        * **persist.sys.hicar.ap.interface** : Specifies the name of the network adapter used for wireless connection. 
For more details about the parameters, please refer to [Wireless Connectivity Parameters](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wifi-parm-0000001261116881).

     2. Added bit rate configuration recommendations for different resolutions based on the H.264 encoding format. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000030695).

For details, please refer to [Handling Bluetooth Conflicts](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/bluetooth-0000001193969601#section13182125133919).
