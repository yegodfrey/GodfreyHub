# Managing Voice Interactions

#### Scenario

HiCar allows users to use its functions through voice interactions, such as voice navigation, voice control of air conditioners, and voice control of music playback. You will need to wake up HiCar voice interaction so that your users can be able to interact with HiCar through voice commands.

HiCar voice interaction wakeup can be triggered by touching an icon, using the physical button, or via voice commands.

#### [h2]Touching an Icon for Wakeup

The user wakes up HiCar voice interaction by touching the voice ball icon. In this case, the entire process is implemented by the HiCar app and you do not need to perform any operations.

#### [h2]Using the Physical Button for Wakeup

The user can press the voice wakeup button on the steering wheel to wake up HiCar voice interaction. In this case, you need to parse the physical button event and send the wakeup data to the HiCar app on the phone side using the **HiCarPostEvent** API provided by the HiCar SDK. The HiCar app then completes the subsequent voice recognition processing.

Physical button wakeup for HiCar works as follows:

     * If the head unit features native voice functions, the user can press and hold the physical button to wake up HiCar voice interaction. During a voice interaction session, each time the user presses and holds the physical button, voice interaction will be woken up again. Pressing the physical button without holding it will exit the voice interaction. 
     * If the head unit does not have native voice function, the user can press the physical button once to wake up HiCar voice interaction. During a voice interaction session, each time the user presses and holds the physical button, voice interaction will be woken up again. Pressing the physical button without holding it will cause voice interaction to exit. 

When the voice wakeup button is triggered, determine whether to distribute the button event of voice recognition start or end based on the current voice wakeup status of HiCar. For details about the HiCar voice status, see [Voice State](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/voice-status-0000001053059443).

#### [h2]Voice Wakeup

The user can wake up HiCar voice interaction with voice commands. This includes two scenarios: 
     * The user wakes up HiCar voice interaction through the phone's voice assistant. In this case, the entire process is implemented by the HiCar app and you do not need to perform any operations. 
     * The user wakes up the HiCar voice interaction through the native voice recognition app of the head unit. In this case, you need to identify "Xiaoyi Xiaoyi" and "Nihao YoYo" in the native voice recognition app of the head unit, and send the wakeup data to HiCar on the phone side using the **HiCarPostEvent** API provided by the HiCar SDK. HiCar then completes the subsequent voice recognition processing. 

#### API Description

**Table 1** APIs for voice wakeup  Header File | Method | Description  
---|---|---  
hicar.h | HiCarPostEvent | Sends a popular keyword to wake up HiCar voice interaction. For details about the wakeup data format, please refer to Table 2.  
  
**Table 2** Head Unit Side Voice Interaction APIs  **Parameter** | **Mandatory** | **Type** | **Description**  
---|---|---|---  
frontEndInfo | - | - | Yes | map | Head unit information.  
wakeType | - | Yes | string | Wakeup mode:
     * **voice** : Voice wakeup, for which **wakeWord** must be specified. 
     * **buttonPress** : Wakeup by operations on the physical button.   
intent | - | Yes | string | User intent:
     * **startVoiceRecognize** : Start voice recognition after saying the voice wakeup phrase or pressing the physical key. 
     * **stopVoiceRecognize** : Stop voice recognition by pressing the physical key.   
voice | - | Yes | map | Voice information.  
wakeWord | No | string | Voice wakeup phrases: "Xiaoyi Xiaoyi" or "Nihao YOYO".  
vendorName | Yes | string | Provider of front-end voice processing, such as "xunfei" and "baidu".  
version | Yes | string | Version of the app that implements front-end voice processing, such as "10.0.0.1".  
infoToVendorCloud | No | string | Information sent to the cloud: The front-end voice processing must follow the same specifications as that used by the voice service provider.  
centralControl | - | Yes | map | Head unit central control information.  
vendorName | Yes | string | Provider of the head unit central control system, such as "PATEO".  
version | Yes | string | Version of the head unit central control system, such as "10.0.0.1".  
car | - | Yes | map | Vehicle info.  
micNumber | Yes | int | Number of microphones.  
speakerNumber | Yes | int | Number of speakers.  
  
When the HiCar voice is in the wakeup broadcast state, if the native voice assistant of the head unit is woken up, you can send the **stopVoiceRecognize** intent to HiCar to cancel the HiCar voice wakeup, avoiding simultaneous voice broadcasts.

For details about the wakeup data, please refer to [Voice Vehicle Wakeup](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/voice-wakeup-0000001153460170) in the **APIs Between the HiCar App and Head Unit** section in the _HUAWEI HiCar SDK API Reference_.

#### Development Procedure

#### [h2]Using the Physical Button for Wakeup

     1. You need to parse physical button events based on your own head unit system.
     2. After a physical button event for wakeup is triggered, the **HiCarPostEvent** API provided by the HiCar SDK needs to be called to send wakeup data.

The following is the sample code for assembling and sending wakeup data:
            
            char* hotWord = "{\"frontEndInfo\":{\"wakeType\":\"buttonPress\",\"intent\":\"startVoiceRecognize\",\"voice\":{\"wakeWord\":\"\",\"hotWord\":\"\",\"vendorName\":\"\",\"version\":\"\",\"infoToVendorCloud\":\"\"},\"centralControl\":{\"vendorName\":\"XXX\",\"version\":\"1.0\"},\"car\":{\"manufacturer\":\"XXX\",\"date\":\"2019-08-26\",\"brand\":\"XXX\",\"micNumber\":\"1\",\"speakerNumber\":\"1\"}}}"; 
            
            int hotWordSize = strlen(hotWord);
            HiCarPostEvent(hicarHandle, HICAR_EVENT_VOICE_WAKEUP, hotWord, hotWordSize);

     3. After the wakeup data is sent, the HiCar voice assistant enters the wakeup state. In this case, set parameters such as echo cancellation and noise reduction for the microphone of the head unit to achieve better sound pickup effect.

You can call the voice status API to determine the current voice state, and perform operations like echo cancellation and noise reduction when in the wakeup state. For details about the voice states, see [Voice State](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/voice-status-0000001053059443).

     4. After a physical button event for exiting voice interaction is triggered, the **HiCarPostEvent** API provided by the HiCar SDK needs to be called to stop sending wakeup data.

The following is the sample code for stopping voice interaction when a physical button event is triggered.
            
            char* hotWord = "{\"frontEndInfo\":{\"wakeType\":\"buttonPress\",\"intent\":\"stopVoiceRecognize\",\"voice\":{\"wakeWord\":\"\",\"hotWord\":\"\",\"vendorName\":\"\",\"version\":\"\",\"infoToVendorCloud\":\"\"},\"centralControl\":{\"vendorName\":\"XXX\",\"version\":\"1.0\"},\"car\":{\"manufacturer\":\"XXX\",\"date\":\"2019-08-26\",\"brand\":\"XXX\",\"micNumber\":\"1\",\"speakerNumber\":\"1\"}}}"; 
            
            int hotWordSize = strlen(hotWord);
            HiCarPostEvent(hicarHandle, HICAR_EVENT_VOICE_WAKEUP, hotWord, hotWordSize);

#### [h2]Voice Wakeup

     1. Make sure that your native voice system recognizes "Xiaoyi Xiaoyi" and "Nihao YoYo".
     2. Assemble wakeup data and send it to the HiCar app via the **HiCarPostEvent** API provided by the HiCar SDK.

The following is the sample code for assembling and sending wakeup data:
            
            char* hotWord = "{\"frontEndInfo\":{\"wakeType\":\"voice\",\"intent\":\"startVoiceRecognize\",\"voice\":{\"wakeWord\":\" Xiaoyi Xiaoyi \",\"hotWord\":\"\",\"vendorName\":\"xunfei\",\"version\":\"\",\"infoToVendorCloud\":\"\"},\"centralControl\":{\"vendorName\":\"XXX\",\"version\":\"1.0\"},\"car\":{\"manufacturer\":\"XXX\",\"date\":\"2019-08-26\",\"brand\":\"XXX\",\"micNumber\":\"1\",\"speakerNumber\":\"1\"}}}";
            
            int hotWordSize = strlen(hotWord);
            HiCarPostEvent(hicarHandle, HICAR_EVENT_VOICE_WAKEUP, hotWord, hotWordSize);
