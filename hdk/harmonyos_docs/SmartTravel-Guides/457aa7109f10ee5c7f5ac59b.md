# Local Voice-based Vehicle Control (Beta)

#### Scenario

If the head unit provides controls for the vehicle air conditioner, window, and volume, the head unit should open these control capabilities and implement data interaction with the HiCar app to facilitate more convenient control of native vehicle functions (for example, through HiCar voice control) after the head unit is connected to HiCar.

For details about the related data format, please refer to [Vehicle Control (AC/Window)](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/vehicle-control-0000001199339961) in the **APIs Between the HiCar App and Head Unit** section of the API Reference.

#### Querying Vehicle Control Capabilities from the Head Unit

     1. After HiCar is successfully connected, the HiCar app on the phone sends a request packet (**dataType=500**) to the head unit to request the vehicle control capabilities. The head unit receives the following data:
            
            {
            	"VehicleControlCapability": {}
            }

     2. The head unit uses the **DataReceive** method to determine **dataType** , and can then receive the preceding data. After the vehicle control data is prepared, the head unit reports the data through **HiCarSendData**. The following is an example of the packet:
            
            {
            	"VehicleControlCapabilityResp": {
            		"volume": {
            			"support": "true",
            			"status": "unmute",
            			"maxVolume": "7",
            			"minVolume": "0",
            			"currentVolume": "6"
            		},
            		"airConditioner": {
            			"support": "true",
            			"maxTemperature": "30",
            			"minTemperature": "15",
            			"status": "on",
            			"currentTemperature": "25"
            		},
            		"skyLight": {
            			"support": "true",
            			"status": "close"
            		},
            		"vehicleWindow": {
            			"leftFrontSupport": "true",
            			"leftFrontStatus": "close",
            			"rightFrontSupport": "true",
            			"rightFrontStatus": "close",
            			"leftBackSupport": "true",
            			"leftBackStatus": "close",
            			"rightBackSupport": "true",
            			"rightBackStatus": "close",
            			"isPercentSupport": "false"
            		}
            	}
            }

#### Sending Vehicle Control Commands to the Head Unit

     1. After identifying a voice vehicle control command, the HiCar app sends a specific vehicle control command packet to the head unit. The following is an example of the packet:
            
            {
                "VehicleControl": {
                      "airConditioner": {
                            "intent":"settemp",
                            "temperature":"25"
                      }
                }
            }

     2. The head unit parses the packet and executes the vehicle control command.
     3. After executing the vehicle control command, the head unit needs to proactively report the latest vehicle control state to the HiCar app. The following is an example of the packet:
            
            {
                "VehicleControlResp": {
                     "respCode":"success",
                     "airConditioner": {
                            "status":"on",
                            "currentTemperature":"25"
                      }
                 }
            }

#### Reporting Vehicle Control State to the HiCar App

The head unit needs to proactively report the latest vehicle control state to the HiCar app after the vehicle control state changes (for example, the user manually adjusts the window, air conditioner, or sunroof). The following is an example of the packet (the format is the same as that of the packet sent by the head unit to the HiCar app to respond to the vehicle control capability):
    
    {
    	"VehicleControlCapabilityResp": {
    		"volume": {
    			"support": "true",
    			"status": "unmute",
    			"maxVolume": "7",
    			"minVolume": "0",
