# Project Initiation and Planning

Both parties need to set up a project team based on project requirements, specify the responsibilities, and formulate a project plan.

To ensure efficient operations of the HiCar integration project, vehicle manufacturers and Huawei need to hold a **kick-off meeting** to specify the communication matrix, key project roles, and product plan during project initiation and planning.

#### Project Kick-off Meeting

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210214.58979903576042037092690175070941:50001231000000:2800:2EA82F8E09170924D46C54309A063F093E7A7A08835C7FFE587F718B6F6424CB.png?needInitFileName=true?needInitFileName=true)

     * Huawei will convene a project kick-off meeting only after the vehicle manufacturer passes the admission standards.
     * The project kick-off meeting serves as the basis for ensuring the smooth implementation of the HiCar project, and is also the prerequisite for vehicle manufacturers to obtain technical support from Huawei (including the SDK and technical Q&A).

#### [h2]Before the Meeting

     1. The Huawei HiCar cooperation manager (BD) sends this cooperation proposal to relevant personnel of the vehicle manufacturer by email.
     2. Relevant personnel of the vehicle manufacturer organize an internal review of this cooperation proposal and reply to the email with questions to be clarified attached.
     3. Both parties specify the roles that will participate in the project kick-off meeting. For the vehicle manufacturer, the following roles are involved:
        * Head unit HiCar project manager
        * Head unit HiCar project R&D owner
        * Head unit HiCar project testing owner
        * Head unit HiCar project design owner

#### [h2]During the Meeting

Relevant personnel in charge from both Huawei and vehicle manufacturers, including HiCar cooperation manager and HiCar technical support, have a discussion on the cooperation proposal, to specify the following:

     * Objectives
     * Plan
     * Responsibility matrix and operation mode
     * Communication matrix

#### [h2]After the Meeting

Output the meeting minutes (including the project objectives, plan, responsibility matrix, operation mode, and communication matrix), and carry out the HiCar integration project based on the conclusions in the meeting.

After the project kick-off meeting, vehicle manufacturers need to send a head unit workbench to Huawei for fault locating in the R&D phase as well as subsequent experience tests.

#### Communication Matrix

In the project initiation and planning phases, vehicle manufacturers and Huawei need to specify their key roles according to the communication matrix to ensure smooth communication.

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210214.28024659270857005412115540389584:50001231000000:2800:98514890A1BF71B12D5E16BDADAB4E44E30D3C82AE5CF415B18E4E6885C59E5E.png?needInitFileName=true?needInitFileName=true)

Vehicle manufacturers can add personnel from downstream vendors to the communication matrix as required.

**Table 2** Communication MatrixParticipant | Key Role | Responsibility | Remarks  
---|---|---|---  
Vehicle manufacturer | Head unit HiCar project manager | Develops the project plan and promotes the implementation of the HiCar head unit project. | Project emails are always copied to this role, to whom the permission to submit CEPM tickets should be granted.  
Head unit HiCar project R&D owner | Develops the HiCar project on the head unit. | Project emails are always copied to this role, to whom the permission to submit CEPM tickets should be granted.  
Head unit HiCar project testing owner | Performs self-test and applies for certification for the HiCar project on the head unit. | The permission to submit CEPM tickets should be granted to this role.  
Head unit HiCar project design owner | Designs the UI of HiCar HMI apps on the head unit. | The permission to submit CEPM tickets should be granted to this role.  
Huawei | HiCar cooperation manager | Be responsible for project implementation. | Project emails are always copied to this role.  
HiCar technical support | Answers technical questions and processes CEPM trouble tickets. | Project emails are always copied to this role.

The CEPM system is a trouble ticket system that allows participants to provide feedback online during HiCar integration, and track the subsequent modification. After the project is initiated, Huawei will grant the CEPM permission to related personnel according to the table above.

In addition, vehicle manufacturers should specify the product plan for integrating HiCar products in the project initiation and planning phases. The product plan template is provided in the Appendix section.
