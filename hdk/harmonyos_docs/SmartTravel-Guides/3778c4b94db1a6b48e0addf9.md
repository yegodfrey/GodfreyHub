# Configuring the Head Unit Routing Table

When the head unit supports USB virtual NCM network adapters, and a USB cable is plugged in, a network adapter named **wwan0** (the name may vary depending on the head unit) is mapped on the head unit. Then the HiCar SDK assigns a random IP address in the 192.168.66.100 to 192.168.66.255 segment to the network adapter. To implement fast networking, add a route to this network segment on the head unit.

Modify the configuration based on the actual condition.
