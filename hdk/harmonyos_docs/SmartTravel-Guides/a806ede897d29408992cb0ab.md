# Deinitializing the SDK

#### Scenario

The initialization, registration, and authentication processes of the HiCar SDK will occupy some resources. These resources must be released using the **HiCarRelease** API, when the HMI app exits or an exception occurs during the underlying execution of the SDK.

#### API Description

**Table 1** Deinitialization APIHeader File | Method | Description  
---|---|---  
hicar.h | HiCarRelease | The HMI app needs to call **HiCarRelease** to deinitialize the HiCar SDK when the HiCar service is not in use.  
  
#### Development Procedure

The sample code used for deinitialization via **HiCarRelease** is as follows:
    
    // Release resources.
    int retCode = HiCarRelease();
