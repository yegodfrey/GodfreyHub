# Precautions for Android 10.0 Adaptation  
  
If the ROM version of the head unit is Android 10.0, modify the Bluetooth and Wi-Fi settings before setting up a wireless HiCar connection. For details about how to modify Bluetooth settings, please refer to [Bluetooth](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/bluetooth-0000001193969601). For details about how to modify Wi-Fi settings, refer to the following:
