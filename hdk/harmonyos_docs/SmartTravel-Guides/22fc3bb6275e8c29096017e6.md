# Configuring Wi-Fi

#### Scenario

The HiCar SDK service capability is built on the Wi-Fi P2P channel. The head unit functions as the group owner (GO), and the phone functions as the group client (GC) to establish a P2P connection.

#### API Description

You need to implement the**FcDriverAdaptOps** variable of the device API (**driver_adapt.h**) in the HiCar SDK package and some of its APIs, as described in Table 1.

**Table 1****FcDriverAdaptOps** structureStructure | Structure Member | Description  
---|---|---  
FcDriverAdaptOps | name | Wi-Fi driver name, which must be **WIFI_DRIVER_NAME**.  
desc | Description of the Wi-Fi device API, which can be customized, for example, **wifi driver**.  
Init | Wi-Fi driver Initialization API. The HiCar SDK calls this API to initialize the driver before using other Wi-Fi APIs.  
Deinit | Wi-Fi driver deinitialization API. You can deinitialize the Wi-Fi driver as required, for example, to release resources.  
SetParam | The HiCar SDK calls this API to set the parameters related to the local Wi-Fi IP address. You need to set this IP address as the local IP address.  
GetParam | When allocating GC information, the HiCar SDK calls this API to obtain an idle IP address from your app as the GC IP address.  
RegisterChannelCallback | The HiCar SDK calls this API to pass HiCar-related callback functions to your app.  
CreateWifiChannel | The HiCar SDK calls your API to create an AP or GO, and related information is passed via input parameters.  
  
For details about the implementation of the **FcDriverAdaptOps** variable, see the Wi-Fi demo code (**driver_wifi.c**) in the HiCar SDK. Note that the variable name must be **g_fcDriverWifiOps**.

The HiCar SDK calls the APIs you have implemented in the following sequence:

     1. Call **Init** to initialize Wi-Fi.
     2. Call **RegisterChannelCallback** to register the HiCar callback function.
     3. Call **CreateWifiChannel** to create an AP or GO.
     4. Call **SetParam** to set the local Wi-Fi IP address.
     5. Call **GetParam** to obtain the IP address of the GC.
     6. When **HiCarRelease** is called, **Deinit** is also called to clear resources.

#### Development Procedure

     1. Implement the Wi-Fi initialization API **Init** to initialize Wi-Fi-related resources and start the Wi-Fi protocol stack.
     2. Implement the Wi-Fi deinitialization API **Deinit** and release Wi-Fi resources in the API.
     3. Implement **RegisterChannelCallback** to save the **ChannelCallback** type pointer transferred by HiCar.
     4. Implement **CreateWifiChannel** and enable Wi-Fi AP.

The input parameter **wifiInfo** of the **CreateWifiChannel** API must be of the int* type. The parameter value indicates the default channel frequency. You can use the default channel frequency or a customize one.

You need to enable the Wi-Fi AP mode in this API. Then call the **ChannelStateChange** API of the **ChannelCallback** function in 3 to notify the HiCar that the AP is established. The input parameter of **ChannelStateChange** is in the **WifiParams** format, and the AP SSID, key, network adapter MAC address, and Wi-Fi channel frequency band need to be passed.

The following is the sample code:
            
            /*
            * @function   : WifiCreateAP
            * @brief      : Creates a hotspot. Pay attention to **WifiCreateAP**.
            If the passed frequency is inconsistent with the frequency of the created hotspot, disable the hotspot and create a new one with the correct frequency.
            * @param[IN]  : context. The parameter is not yet in use, and **NULL** shall be passed.
            * @param[IN]  : wifiInfo. The **frequency(int*)** parameter is passed.
            * @return     : Returns **0** if successful; returns a non-zero value if otherwise.
            */
            static int WifiCreateAP(const void *context, const void *wifiInfo)
            {
                (void)context;
                if (wifiInfo == NULL) {
                    printf("WifiCreateAP[in], invalid input.");
                    return RESULT_RET_ERROR;
                }
            
                int frequency = (int)(*(int *)wifiInfo);
                printf("WifiCreateAP[in] Wifi Channel frequency:%d.\r\n", frequency);
            
                // The **ssid** and **key** need to be generated on the device side. If the values do not meet the requirement, explain it to the Huawei contact person.
                char ssid[WIFI_SSID_LEN + 1] = "HiCar-12345";
                char key[WIFI_KEY_LEN + 1] = "123456789";
            
                // Network adapter MAC address.
                char mac[STR_MAC_ADDR_LEN + 1] = "xx:xx:xx:xx:xx:xx";
            
                WifiParams apParams;
                (void)memset(
                    &apParams, 0, sizeof(WifiParams));  // (void)memset_s(&apParams, sizeof(WifiParams), 0, sizeof(WifiParams));
            
                apParams.frequency = frequency;  // It is generally required that the head unit should use the frequency delivered by Nearby. If the delivered frequency is not used, explain it to the Huawei contact person.
                (void)strncpy(apParams.ssid, ssid, WIFI_SSID_LEN);   //(void)strcpy_s(apParams->ssid, WIFI_SSID_LEN + 1, ssid);
                (void)strncpy(apParams.key, key, WIFI_KEY_LEN);      // (void)strcpy_s(apParams->key, WIFI_KEY_LEN + 1, key);
                (void)strncpy(apParams.mac, mac, STR_MAC_ADDR_LEN);  // (void)strcpy_s(apParams->mac, WIFI_MAC_LEN + 1, mac);
            
                printf("WifiCreateAP[in] ssid:%s, key:%s, mac:%s, freq:%d.\r\n",
                    apParams.ssid,
                    apParams.key,
                    apParams.mac,
                    apParams.frequency);
            
                // After the hotspot is successfully created, report the **EVENT_CREATE_WIFI_SUCCESS** event to Nearby.
                if (g_wifiCallback != NULL) {
                    g_wifiCallback->ChannelStateChange(CHANNEL_P2P, EVENT_CREATE_WIFI_SUCCESS, &apParams, sizeof(WifiParams));
                }
            
                return RESULT_RET_OK;
            }

     5. Implement **SetParam** for setting Wi-Fi parameters.

The input parameter **paramType** of the **SetParam** API is set to the enum **SET_WIFI_LOCAL_IP**. In this case, you need to explain the input parameter in **WifiSetIpParam** format and set **ip** , mask, and **gateway** for the local host. (You can choose to use the customized IP address).

After the local IP address is set, you need to call **ChannelStateChange(CHANNEL_P2P, EVENT_CONFIG_IP_SUCCESS, apIp, 0)** to notify the HiCar that the setting is complete. The parameter **apIp** is the character string presentation of the IP address on the head unit side, and the variable type is char*.

The following is the sample code:
            
            /*
             * @function   : WifiSetParam
             * @brief      : Sets the parameters of the Wi-Fi driver.
             * @param[IN]  : paramType. For details, see **SetParamsType**.
             * @param[IN]  : context, used to set the value of **paramType**.
             * @return     : Returns **0** if successful; returns a non-zero value if otherwise.
             */
            static int WifiSetParam(SetParamsType paramType, const void *context)
            {
                if (context == NULL) {
                    printf("WifiSetParam[in] invalid input, paramtype:%d.\r\n", paramType);
                    return RESULT_RET_ERROR;
                }
            
                printf("WifiSetParam[in] paramtype:%d.\r\n", paramType);
                if (paramType == SET_WIFI_LOCAL_IP) {
                    WifiSetIpParam *ipParam = (WifiSetIpParam *)context;
                    printf("WifiSetParam[in] paramType:SET_WIFI_LOCAL_IP, local ip:%s.", ipParam->ipAddr);
            
                    // After the local IP address is successfully set, report the **EVENT_CONFIG_IP_SUCCESS** event to Nearby.
                    g_wifiCallback->ChannelStateChange(CHANNEL_P2P, EVENT_CONFIG_IP_SUCCESS, NULL, 0);
                } else {
                    printf("WifiSetParam[in] unknown paramtype:%d.\r\n", paramType);
                }
            
                return RESULT_RET_OK;
            }

     6. Implement **GetParam** , which is an API to obtain Wi-Fi parameters.

The enums **GET_DEV_MAC** , **GET_WIFI_ABILITY** , and **GET_GC_IP** are used for **GetParam** adaptation.

        * When **GET_DEV_MAC** is used, parameters are passed in the **macParam** type. You'll need to provide the MAC address of the NIC. You can find the sample code in **driver_wifi.c** in the HiCar SDK.
        * When **GET_WIFI_ABILITY** is used, parameters are passed in the **wifiAbilityParam** type. You'll need to assign Wi-Fi capability values to **wifiAbilityParam**. You can find the sample code in **driver_wifi.c** in the HiCar SDK.
        * When **GET_GC_IP** is used, parameters are passed in the **GcIpParam** type. You need to query idle IP addresses in the local GO network segment (you are supposed to allocate idle IP addresses from the network segment to HiCar) and pass the IP addresses to the HiCar SDK. If the API returns **–1** , HiCar uses the default fixed GC IP address.

The sample code takes the IP address 10.42.0.2 as an example:
    
    /*
     * @function   : WifiGetParam
     * @brief      : Set the **GC_IP** parameter.
     * @param[IN]  : **paramType**. For details, see **GetParamsType**.
     * @param[IN]  : result, which indicates the obtained parameter value.
     * @return     : Returns **0** if successful; returns a non-zero value if otherwise.
     */
    static int WifiGetParam(GetParamsType paramType, void *result)
    {
           if (paramType == GET_GC_IP) {
                 GcIpParam *gcIpParam = (GcIpParam*)result;
                 strcpy(gcIpParam->gcIp, "10.42.0.2");
                 gcIpParam->len = strlen("10.42.0.2");
                 printf("get gc ip success");
           } 
    }
