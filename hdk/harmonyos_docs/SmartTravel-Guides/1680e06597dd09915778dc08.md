# Management of Device Connection Solutions

#### Device Connection

**Rule 6-1: When the user connects their device to the head unit for the first time, provide a screen for selecting the connection solution.**

When the user initiates a connection to the head unit through a USB connection for the first time, the head unit should provide a screen for selecting the connection solution (no solution is selected by default).

#### Switching Between Connection Solutions

**Rule 6-3: If solution A is currently connected, and the user wishes to switch to solution B, a confirmation dialog box should be displayed.**
