# Establishing a Wired Connection

#### Interaction Process

Before setting up a wired connection, you may need to configure the routing system of the head unit. For details, please refer to [Wired Connectivity](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wired-mode-connection-0000001051064574).

#### Enabling Wired Connection of the SDK

The HiCar SDK processes the USB insertion event and performs wired connection only when the wired connection function of the HiCar SDK is enabled.

The HMI app can enable the wired connection function during SDK initialization, or dynamically enable the function when the SDK is running.

The following is the sample code for enabling wired connection during SDK initialization:
    
    CarConfig.Builder builder = new CarConfig.Builder();
    ......
    //Enable the wired connection function during SDK initialization. The value **true** indicates that the wired connection function is enabled, and the value **false** indicates that wired connection is disabled.
    **builder.withSupportUsb(true);**
    CarConfig carconfig = builder.build();

The following is the sample code for dynamically enabling automatic connection when the SDK is running:
    
    //Dynamically update whether to enable the wired connection function when the SDK is running.
    **carconfig.updateSupportUsb(true)** ;

#### Handling Authentication Event Callback

During wired connection, the HiCar SDK directly sends the PIN to the phone through the USB wired connection channel. The HMI app does not need to obtain or display the PIN. However, the HMI app still needs to process the authentication callback to complete the authentication process.

The HMI app uses the same logic and process method for authentication event callback of wired connection and wireless connection. For details, see [Handling Authentication Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callbacks-0000001193322373#section317145010317).

#### Handling Connection Event Callback

After the phone is connected to the head unit, the HMI app can obtain the connection event through callback, and perform operations such as projection and exiting the app based on the event. For details about the connection event callback method, refer to [Handling Connection Event Callback](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/process-callbacks-0000001193322373#section134661359336) in the wireless connection section.

Although wired connection does not depend on the Bluetooth function of the head unit, to ensure that wireless connection can be implemented through Bluetooth later, the HMI app needs to actively enable Bluetooth when receiving a successful connection event after wired connection is established.

If the head unit supports only wired connections, this operation is not required.

#### Handling Connectivity Conflicts

If the head unit supports multiple interconnected solutions wired mode at the same time, the manufacturer needs to handle the connectivity conflicts when integrating HiCar. If the head unit supports only HiCar, skip this section.

If the head unit supports HiCar and another interconnected solution A, the process is as follows:

     1. The user connects the phone to the head unit through the USB port.
     2. The head unit displays a message, asking the user whether to connect to HiCar or A. For details about the design of the selection dialog box, see related sections in HUAWEI HiCar App UX Design Specification.
     3. The head unit starts the connection process of the corresponding solution according to the user's selection.

**Table 1** APIs for processing conflicts of multiple interconnection modesClass | Method | Description  
---|---|---  
Carconfig | updateSupportUsb | Updates whether the wired connection is supported dynamically.  
  
     1. During SDK initialization, the HMI app should disable the wired connection function of the SDK, that is, set **CarConfig.Builder::****withSupportUsb(false)** to prevent the phone from directly starting the HiCar connection process when connecting to the head unit in wired mode.
     2. If the user selects HiCar, the HMI app should dynamically enable the wired connection function of the SDK, that is, set **Carconfig::updateSupportUsb(true)**.
     3. When the user disconnects from HiCar, the HMI app should dynamically disable the wired connection function of the SDK, that is, set **Carconfig::updateSupportUsb(false)**. This prevents the phone from directly starting the HiCar connection process when the phone is connected to the head unit in wired mode again.
