# Processing App Operations

#### Scenario

The head unit can obtain apps from HiCar and display the apps on its native screen. When a user touches one of these app icons, the head unit needs to interact with HiCar in the way preset by the HiCar SDK.

#### API Description

The API design for interactions between the converged desktop and the HiCar app inherits that for interactions between the head unit and the HiCar app. See [Data Interactions](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/data-interaction-0000001192952815) for reference before developing the converged desktop feature.

For details about the data format during interactions with the HiCar app when processing app operations, see [Converged Desktop App Operations](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/fusion-ui-app-operation-0000001607687489) in the **APIs Between the HiCar App and Head Unit** section in the HUAWEI HiCar SDK API Reference.

#### Development Procedure

     1. The head unit can obtain the app list according to [Obtaining the App List](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/get-app-list-0000001606309545) and display the apps on its native screen. When a user opens an app from HiCar by touching the app icon or using a voice command, the head unit sends a request packet (**dataType** =**529**) through the **HiCarAdapter::sendCarData** API, to notify HiCar of the app being opened. The following is an example of the packet:
            
            {
                "RequestApp" : {
                    "Action" : "start",
                    "AppPackage" : "com.android.mediacenter"
                }
            }

     2. The HiCar app will reply based on the actual situation. The head unit can receive the data after determining the **dataType** using the **onDataReceive** method. The following is an example of the packet:
            
            {
                "RequestAppResp" : {
                    "RespCode" : 100000,
                    "AppPackage" : "com.android.mediacenter",
                    "Description" : "success"
                }
            }
