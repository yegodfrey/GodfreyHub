# Registering Event Callbacks

#### Scenario

The HMI app needs to register event listener callback through the **HiCarRegisterListener** API in the SDK, and perform service operations according to the events in the callback.

#### API Description

For details about the event listener callback methods, please refer to Table 1.

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210309.06733678282560682465862382886217:50001231000000:2800:F297C15E1DE4AA47400A080A66AB1A70DD30F37CE55D53EE5EF8BE280C87DDAF.png?needInitFileName=true?needInitFileName=true)

The HMI app receives some messages or events sent by the HiCar SDK via **DeviceChange** , **DeviceServiceChange** , and **DataReceive** callbacks. If you want to call the APIs provided by the HiCar SDK during the callbacks, you will have to do so in a different thread.

**Table 1** Callback methodsAPI | Callback Method | Description  
---|---|---  
CarListener | GetHiCarHandle | Obtains the HiCar handle.  
DeviceChange | Called when the connection between the phone and the head unit changes. For details about the connection events, please refer to Table 2.  
DeviceServiceChange | Called when the service changes. For details about the service events, please refer to Table 2.  
DataReceive | Called when the SDK receives data sent by the HiCar app on the phone. The HMI app can use this method to exchange data with HiCar and receive data such as vehicle control commands and navigation focus change notifications from HiCar. For details, please refer to [Data Interactions](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/interactions-0000001051779174).  
GetVideoData | Call back this method to obtain video stream data after screen projection. For details, please refer to [Projection Description](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/interaction-process-0000001050121798).  
GetSecureFileSize | Callback method related to the authentication file.  
ReadSecureFile  
WriteSecureFile  
RemoveSecureFile  
  
**Table 2** Callback eventsCallback Method | Event | Description  
---|---|---  
DeviceChange | HICAR_DEVICE_CONNECTED = 101 | The HMI app needs to display the connection screen when the device is connected.  
HICAR_DEVICE_DETECT_DISCONNECT = 106 | When detecting that the heartbeat between the head unit and phone is disconnected, the HMI app returns to the native HMI screen.  
HICAR_DEVICE_MANUAL_DISCONNECT = 110 | When the phone user disconnects the phone from the head unit, the HMI app records and keeps the event flag until the head unit restarts.  
HICAR_DEVICE_ADV_TIMEOUT = 111 | When BLE advertising by the head unit has timed out, the HMI app prompts the user to refresh the connection PIN.  
DeviceServiceChange | HICAR_DEVICE_SERVICE_PAUSE = 202 | When the user returns to the native head unit system screen, the HMI app will be notified of this event. The HMI app should return to the background and call **HiCarPauseProjection**.  
HICAR_DEVICE_SERVICE_RESUME = 203 | While the projection is running in the background, when a call comes in or the voice assistant is woken up, the HMI app will be notified of this event and should move the projection screen to the foreground and call **HiCarStartProjection**.  
HICAR_DEVICE_DISPLAY_SERVICE_PLAYING = 207 | Projection is successful. After receiving the event, the HMI app can obtain the video stream data via **GetVideoData**.  
HICAR_DEVICE_VIRMODEM_CALLING = 307 | Event for a connected carrier call. Upon receiving this event, the HMI app needs to notify the microphone of the head unit to set echo cancellation and other related parameters to prevent echoes during calls.  
HICAR_DEVICE_VIRMODEM_HANGUP = 308 | Event for an ended carrier call. Upon receiving this event, the HMI app needs to restore the microphone settings of the head unit to the normal state.  
HICAR_DEVICE_VOIP_CALLING = 309 | Event for a connected VoIP call. Upon receiving this event, the HMI app needs to notify the microphone of the head unit to set echo cancellation and other related parameters to prevent echoes during calls.  
HICAR_DEVICE_VOIP_HANG_UP = 310 | Event for an ended VoIP call. Upon receiving this event, the HMI app needs to restore the microphone settings of the head unit to the normal state.  
DataReceive | HICAR_DATA_MANUAL_DISCONNECT=518 | When the phone user disconnects the phone from the head unit, the HMI app records the event flag. This message is more reliable than message 110. After this message is received, another thread is started to call **HiCarDisconnectDevice** to disconnect the connection immediately.  
  
For details about the callback parameters, please refer to HUAWEI HiCar SDK API Reference. For details about how to process services based on callback events, please refer to the subsequent sections in this document.

     2. The HMI app registers the event listener callback via **HiCarRegisterListener**. The following is the sample code:
            
            CarListener carListener = {0};
            
            carListener.GetHiCarHandle = GetHiCarHandle;
            carListener.DeviceChange = DeviceChange;
            carListener.DeviceServiceChange = DeviceServiceChange;
            carListener.DataReceive = DataReceive;
            carListener.GetSecureFileSize = GetSecureFileSize;
            carListener.ReadSecureFile = ReadSecureFile;
            carListener.WriteSecureFile = WriteSecureFile;
            carListener.RemoveSecureFile = RemoveSecureFile;
            carListener.GetVideoData = GetVideoData;
            
            printf("Call HiCarRegisterListener.\n");
            int retCode = HiCarRegisterListener(&carListener);
