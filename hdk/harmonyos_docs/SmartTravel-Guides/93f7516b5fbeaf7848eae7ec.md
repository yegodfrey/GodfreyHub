# Preparations

#### Obtaining Software Packages

When obtaining Huawei's written permission, partners will also obtain the HiCar SDK package.

#### Package Description

The HiCar SDK package comes in three versions: Arm, classic, and x86. The differences between these versions are as follows:

     * The SDK package of the Arm version provides the 32-bit and 64-bit .so files for DMSDP.
     * The Classic platform software package provides the 32-bit so library of the DMSDP, which is mainly used on the Android4.2/4.4 platform.
     * The SDK package of the x86 version provides the 64-bit .so file for DMSDP.

#### Using the Software Package

#### [h2]Installing the Software Package

After obtaining the HiCar SDK package, do not change its directory structure. Perform the following steps to install the SDK in the head unit system:

     1. Sign the APKs in the package with keys to ensure that they can run as system apps in the head unit system.
     2. Run **Install_*.bat** (***** indicates Arm, x86, or classic) in the root directory to install the HiCar SDK on the head unit.

#### [h2]Installing the Demo

The HiCar SDK contains the demo app for debugging and presenting HiCar functions. However, when running the installation script of the software package, the demo app is not automatically installed by default. If required, you can install the demo app to the head unit system by performing the following steps:

     1. Go to the directory where the demo app is located, open the **Demo/hicar.properties** file, and set the head unit hardware parameters.

#### [h2]Using the Debug Log Switch

You can enable or disable the SDK debug log function of the HiCar SDK by setting the system parameter **persist.vendor.hicarsdk.debug**.

     * Enable the debug log during the integration and debugging phases. In this case, the HiCar SDK prints logs at all levels, including the DEBUG level to help you quickly locate faults.
     * Disable the debug log after the commercial release. In this case, the HiCar SDK prints only logs at the INFO, WARNING, and ERROR levels to improve its running performance.

The system parameter settings are written into the **/data/property** directory of the system. The settings still take effect after the head unit is restarted.

The command is as follows:
    
    adb shell
    > setprop persist.vendor.hicarsdk.debug 1 // Enable the debug log.
    > setprop persist.vendor.hicarsdk.debug 0 // Disable the debug log.

#### Vehicle Model ID that Can Be Used During Commissioning

Huawei assigns a unique ID to each vehicle model, which consists of the **ModelID** and **SubModelID**. The vehicle model ID is a hexadecimal string of four bytes. The first three bytes indicate the vehicle brand (**ModelID**), and the fourth byte indicates the vehicle model (**SubModelID**).

You can use the test ID **00040900** for commissioning, and apply for a formal vehicle model ID from Huawei for commercial use.
