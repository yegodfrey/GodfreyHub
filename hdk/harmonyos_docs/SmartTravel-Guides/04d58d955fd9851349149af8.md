# Projection Description

**Figure 1** Interaction process  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210311.69634647332289154095225082208447:50001231000000:2800:5BAE1F36B1C5D739B2C1001D4B344493AF501E8FF2B8223DB6ACA2A198E3433F.png?needInitFileName=true?needInitFileName=true)

Assume that the module that interacts with the HiCar SDK is HiCarController.

     1. When the HMI app initializes the HiCar SDK, it needs to transfer information such as the supported video encoding types, screen size, and screen resolution to the HiCar SDK through the **CarDisplayCapability** structure.
     2. When screen projection is ready, the head unit sends the video stream data to project from the phone to HiCarController through the **GetVideoData** callback function in CarListener. HiCarController forwards the data to the head unit's decoding module for decoding and output to the screen.
     3. During screen projection, when a user touches an icon on the screen or presses a control button on the steering wheel, the **HiCarPostEvent** API can be used to notify the HiCar SDK of the touchscreen event or physical button event. Then the HiCar SDK instructs the phone to perform corresponding processing.
