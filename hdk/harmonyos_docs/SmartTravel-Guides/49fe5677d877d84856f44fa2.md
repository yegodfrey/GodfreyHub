# Wi-Fi

#### Scenario

In a HiCar wireless connection, the head unit needs to serve as an access point (AP). While serving this purpose, the head unit must send broadcasts to notify the upper-layer app of connections and disconnections of devices over Wi-Fi.

To configure the Wi-Fi broadcast settings for the head unit, you can modify the code in Android Framework.

#### Development Procedure

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210252.87920630496692058062579743809042:50001231000000:2800:E13929A89E93A7FF0D7D68AD0F348C99E95CDE930B5322E3CB375673FD36B9F8.png?needInitFileName=true?needInitFileName=true)

The following uses the Android 8 system as an example. Make adaptation to the actual conditions. For details about the adaptation to other system versions, please refer to the appendix.

#### [h2]Modifying AndroidManifest.xml

     1. Search for **frameworks/base/core/res/AndroidManifest.xml** in the Android source code.
     2. Add a broadcast event as follows.
            
            **< protected-broadcast android:name="android.net.wifi.WIFI_AP_STA_JOIN" />**
            **< protected-broadcast android:name="android.net.wifi.WIFI_AP_STA_LEAVE" />**

#### [h2]Adding the IApInterfaceEventCallback.aidl File

     1. Search for the **system/connectivity/wificond/aidl/android/net/wifi/** path in the Android source code.
     2. Add the **IApInterfaceEventCallback.aidl** file to the **wifi** folder. The file content is as follows:
            
            package android.net.wifi;
             
            interface IApInterfaceEventCallback { 
               oneway void onNumAssociatedStationsChanged(int numStations);
               oneway void OnApLinkedStaJoin(String macStr);
               oneway void OnApLinkedStaLeave(String macStr);
            }
