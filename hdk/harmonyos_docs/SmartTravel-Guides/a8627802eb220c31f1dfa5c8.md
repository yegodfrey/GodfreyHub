# App Usage

#### HUAWEI HiCar Smart Desktop

Touch the HUAWEI HiCar Smart Desktop app icon to open the HUAWEI HiCar card screen, where important information about driving converges.

#### Apps and Information from Phones

When a user touches a phone app icon on the head unit, or a native head unit control that displays information from the phone, the phone app is opened the same way as how native apps are opened.
