# Wired Connectivity

#### Process

HiCar allows users to connect HiCar-capable phones and head units with a USB cable.

Multiple USB modes are supported between the phone and the head unit, including charging only, USB storage, MTP, NCM, and AOA. A USB wired HiCar connection can be set up through NCM (AOA is not supported for the moment) to transmit data.

**Figure 1** USB wired HiCar connection process

     1. When the HiCar SDK is initialized after the head unit starts up, the HMI app provides the vehicle information to the SDK using the provided API. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000030695).
     2. The HiCar SDK listens to the USB connection event **android.hardware.usb.action.USB_DEVICE_ATTACHED** on the head unit.
     3. The HiCar SDK identifies whether the device at the other end of the USB cable is a mobile phone. If it is, the HMI app sends a USB control message to the phone, including the vehicle information and whether the NCM is supported.
     4. The HiCar SDK waits for the phone to switch the USB mode to NCM.
     5. After detecting that the phone has switched the USB mode to NCM, the HiCar SDK attempts to establish a connection channel. To ensure that the connection can be set up, the head unit needs to configure the network information, including the IP address and network port, to its routing table. For details, please refer to Configuring the Head Unit Routing Table.
     6. After a channel is set up between the phone and the head unit, the HiCar SDK sends the EVENT_DEVICE_CONNECT event to the HMI app. The app will then start the projection. For details, please refer to [Establishing a Wired Connection](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/wired-connectivity-0000000000030734).

#### Configuring the Head Unit Routing Table

When the head unit supports USB virtual NCM network adapters, and a USB cable is plugged in, a network adapter named **wwan0** is mapped on the head unit. Then the HiCar SDK assigns a random IP address in the 192.168.66.100 to 192.168.66.255 segment to the network adapter. The initial IP address of the **wwan0** network adapter must be empty. Otherwise, the connection will fail.

In addition, the HiCar SDK specifies the IP address segment of the network adapter by using the system parameter **ro.hicar.wwan0.network** to avoid the conflict between the randomly allocated IP address and the IP address used by the head unit.

**Table 1** Parameter descriptionParameter | Type | Description  
---|---|---  
ro.hicar.wwan0.network | string | The vendor can set the IP address segment as required. If it is not set, the network segment **192.168.66.** is used by default.  
  
The command is as follows:
    
    adb shell
    > setprop ro.hicar.wwan0.network XXX.XXX.XX. // Set the network segment.

To implement fast networking, add a route to this network segment on the head unit.

#### Verifying the Wired Connectivity

After the wired connection configuration is complete, verify the wired connectivity of the head unit by using **HiCarDemo.apk** in the HiCar SDK.

     1. Run **HiCarDemo.apk**.

**Figure 2** Initial GUI of the HiCar Demo (for reference)  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210250.65683579565846489054730485806506:50001231000000:2800:193B64AFC90A0BBB96D233C807DB4C02D1BB56DB7D8224C7F31B3FA5579C6D46.png?needInitFileName=true?needInitFileName=true)

     2. Connect the phone to the head unit using a USB cable.

If the wired connection is set up, a confirmation dialog box is displayed. After the connection is successful, the HiCar screen is displayed.

If the wired connection fails, locate and rectify the fault based on the logs.
