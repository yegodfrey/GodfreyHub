# GPS and Vehicle Body Data

#### Scenario

After connecting to the head unit, the HiCar phone can use the in-vehicle GPS sensor's data for navigation and positioning. This allows the phone to maintain a strong GPS signal even in cases where the phone is placed near sources of interference or there is signal attenuation. The HiCar phone compares and merges the vehicle's GPS data with its own GPS data to provide high-precision GPS positioning for HiCar apps.

If the head unit has a GPS sensor, implement the interfaces related to GPS data reporting for the HiCar SDK to call.

Implement the GPS-related APIs based on the GPS device API header files provided by the HiCar SDK, and build the **libdmsdpgpshandler.so** file. When running, the HiCar SDK searches for the .so file. If the file is not found, it is considered that the GPS-related APIs have not been implemented. If the file is found, the SDK dynamically loads the .so library.

     1. During initialization, the HiCar SDK searches for the **libdmsdpgpshandler.so** file. If the file is found, it is considered that the GPS functions have been implemented. The HiCar SDK then registers the status callback, and receives status events from the HMI app.
     2. When a mobile app uses the location service, the HiCar SDK registers the data callback function with the **libdmsdpgpshandler.so** file. When the position, speed, or sensor of the head unit changes, the head unit reports the changes to the HiCar SDK asynchronously based on the specified frequency. The HiCar SDK expects the location information (such as the longitude, latitude, height, and moving direction) to be reported at a frequency of 1 Hz, the vehicle body data (such as the vehicle speed and steering angle) to be reported at a frequency of 10 Hz, and the vehicle sensor data (such as the acceleration and gyroscope) to be reported at a frequency of 40 Hz.

#### APIs

The GPS APIs defined in the HiCar SDK are mainly used for registering and deregistering the GPS data callback function, and obtaining and setting the GPS data reporting period.
    
    **dmsdp_gps_handler.h** : defines the GPS APIs.

**Table 1** APIsAPI | Input Parameter | Description  
---|---|---  
RegisterGPSDataCallback | callback | Registers the callback function for a set of data, including the GPS, vehicle body data, and sensor data. When a mobile app needs to use the location service (for example, to access a map), the HiCar SDK registers this callback function with the head unit. After the registration, the head unit will report GPS data to the HiCar SDK.  
UnRegisterGPSDataCallback | - | Deregisters the preceding callback function. This API is called when the mobile app does not need the location service (for example, when navigation is ended). After the deregistration, the head unit does not need to report GPS data to the HiCar SDK.  
GetGPSDataReportFreq | **locationFreq** : GPS data reporting frequency, in Hz. **drivingFreq** : Vehicle body data reporting frequency, in Hz. **sensorFreq** : Vehicle sensor data reporting frequency, in Hz. | Obtains the reporting frequencies for various types of data.  
SetGPSDataReportFreq | **locationFreq** : GPS data reporting frequency, in Hz. **drivingFreq** : Vehicle body data reporting frequency, in Hz. **sensorFreq** : Vehicle sensor data reporting frequency, in Hz. | Dynamically sets the GPS data reporting frequency. If the set frequency exceeds the limit, an error is returned.  
RegisterListener | listener | Used by the HiCar SDK to receive status notifications from the head unit, such as the notification that a peripheral is connected to or disconnected from the head unit.  
BusinessControl | - | Controls GPS services. This API is an extension API.  
  
#### Development Procedure

Implement the APIs as follows:
    
    typedef struct {
        void (*GPSLocation)(char *location, int32_t len);
        void (*GPSDriving)(char *driving, int32_t len);
        void (*GPSSensor)(char *sensor, int32_t len);
        void (*CarBaseInfo)(char *info, int32_t len);
    }DMSDPGPSCallback;
    
    typedef struct {
        int32_t (*RegisterGPSDataCallback)(DMSDPGPSCallback* callback);
        int32_t (*UnRegisterGPSDataCallback)();
        int32_t (*GetGPSDataReportFreq)(int32_t* locationFreq, int32_t* drivingFreq, int32_t* sensorFreq);
        int32_t (*SetGPSDataReportFreq)(int32_t locationFreq, int32_t drivingFreq, int32_t sensorFreq);
        int32_t (*RegisterListener)(const DMSDPListener *listener);
        int32_t (*BusinessControl)(uint32_t cmd, char *inputPara, uint32_t inLen, char *outputPara, uint32_t outLen);
    } DMSDPGpsHandler;
