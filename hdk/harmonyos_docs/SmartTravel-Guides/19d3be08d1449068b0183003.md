# Vehicle Brand Logo

#### Scenario

**Figure 1** Vehicle brand logo example  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210258.15994904610635477371545771003357:50001231000000:2800:3A3986BEA2CB1BD397C9D7098DF33F9B34CD703B392962CA33A57053A7C6E4C2.png?needInitFileName=true?needInitFileName=true)

After HiCar is successfully connected, the HiCar UI is projected to the head unit screen. The user can touch the vehicle brand logo in the HiCar icon area to return to the native HMI screen of the head unit. This vehicle brand logo needs to be passed from the head unit to the HiCar app on the phone.

For details about the related data formats, refer to [Brand Logo](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/brand-icon-0000001199289933) in the **APIs Between the HiCar App and Head Unit** section of the HUAWEI HiCar SDK API Reference.

#### Development Procedure

     1. After HiCar is successfully connected, the HiCar app on the phone sends a request packet (**dataType=502**) to the head unit to request the vehicle brand logo. The head unit receives the following data:
            
            {
                "brandIconData":"PNG"
            }

     2. The head unit determines **dataType** via the **onDataReceive** method and can then receive the preceding data. After the brand logo is prepared, the head unit reports the data through **HiCarAdapter::sendCarData**. The following is the sample code:
            
            public void onDataReceive(String s, int dataType, byte[] bytes) {
                 try {
                     int DATA_TYPE_BRAND_ICON_DATA = 502;
                     // TODO: Verify received reports.
                     if (dataType == DATA_TYPE_BRAND_ICON_DATA) {
                         // Plan the image path.
                         byte[] pictureBytes = getPngBytes("/data/test.png");
                         **mHicarAdapter.sendCarData(DATA_TYPE_BRAND_ICON_DATA, pictureBytes);**
                     }
                 } catch (Exception e) {
                     Log.i(TAG, " error");
                 }
             }
            // Convert the image file into a byte stream.
            private byte[] getPngBytes(String pictureFilePath) {
                 try {
                     FileInputStream fis = new FileInputStream(pictureFilePath); 
                     ByteArrayOutputStream baos = new ByteArrayOutputStream();
                     Bitmap bitmap = BitmapFactory._decodeStream_(fis);
                     bitmap.compress(Bitmap.CompressFormat._PNG_ , 100, baos);
                     return baos.toByteArray();
                 } catch (Exception ex) {
                     Log._i_(_TAG_ , "get picture error");
                     return null;
                 }
             }
