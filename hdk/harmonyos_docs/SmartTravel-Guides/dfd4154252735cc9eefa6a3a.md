# Dark/Light Mode

#### Scenario

If the vehicle sensor has the capability of detecting Dark/Light mode, the HiCar app can switch between the modes based on this capability.

After the head unit is powered on and started, it needs to call the corresponding API provided by the HiCar SDK to report whether Dark/Light mode detection is supported, as well as the current mode. Then, the head unit reports the latest mode to the HiCar app once the mode is changed.

For details about the related data formats, please refer to [Day/Night Mode](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/day-night-mode-0000001153300356) in the **APIs Between the HiCar App and Head Unit** section of the HUAWEI HiCar SDK API Reference.

#### Setting Dark/Light Mode During SDK Initialization

During SDK initialization, Dark/Light mode can be set for the head unit. The sample code is as follows: For details about SDK initialization, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000105632).
    
    CarConfig config;
    ......
    memcpy_s((void*)&(config.deviceInfo.dayNightInfo[0]), CAR_DAY_NIGHT_MAX_LEN, 0, CAR_DAY_NIGHT_MAX_LEN);
    memcpy_s((void*)&(config.deviceInfo.dayNightInfo[0]), CAR_DAY_NIGHT_MAX_LEN, "night", strlen("night"));
    config.deviceInfo.carDayNightLen = strlen("night");
    ......
    int retCode = HiCarInit(&config);

#### Reporting Dark/Light Mode to the HiCar App

When the head unit detects that Dark/Light mode changes, it needs to report the current mode to the HiCar app through the **HiCarSendData** API. The following is an example of the packet for reporting Light mode:
    
    {
        "dayNightMode":"day"
    }
