# Dark/Light Mode  
  
#### Scenario

If the vehicle sensor has the capability of detecting Dark/Light mode, the HiCar app can switch between the modes based on this capability.

After the head unit is powered on and started, it needs to call the corresponding API provided by the HiCar SDK to report whether Dark/Light mode detection is supported, as well as the current mode. Then, the head unit reports the latest mode to the HiCar app once the mode is changed.

For details about the related data formats, please refer to [Dark/Light Mode](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-References/day-night-mode-0000001199289931) in the **APIs Between the HiCar App and Head Unit** section of the HUAWEI HiCar SDK API Reference.

#### Setting Dark/Light Mode During SDK Initialization

During SDK initialization, the head unit can set the Dark/Bright mode through **InitialConfig**. For details, please refer to [Initializing the SDK](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/initialize-sdk-0000000000030695).

#### Reporting Dark/Light Mode to the HiCar App

When the head unit detects that Dark/Light mode changes, it needs to report the current mode to the HiCar app through the **HiCarAdapter::sendCarData** API. The following is an example of the packet for reporting Light mode:
    
    {
        "dayNightMode":"day"
    }
