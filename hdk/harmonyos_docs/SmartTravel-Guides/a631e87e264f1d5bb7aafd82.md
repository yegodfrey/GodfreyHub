# Deinitializing the SDK

#### Scenario

The initialization of the HiCar SDK records the state values. Therefore, call **deInit** to reset the state when the HMI app exits or an exception occurs during the bottom-layer execution of the HiCar SDK.

#### API Description

**Table 1** Deinitialization APIsClass | Method | Description  
---|---|---  
HiCarAdapter | unRegisterCarListener | The HMI app should deregister the listener for HiCar events before deinitializing the SDK.  
deInit | The HMI app should call the **deInit** API to deinitialize the HiCar SDK after the user stops using the vehicle (for example, after the user turns off the engine and the screen).  
  
#### Development Procedure

     1. Deregister event listeners by calling the **unRegisterCarListener** method of **HiCarAdapter**.

The following is the sample code:
            
            // Deregister the event listener
            int retCode = mHiCarAdapter.unRegisterCarListener(mHiCarListener); 
            if (retCode != HiCarConst.SUCCESS) { 
                Log.d(TAG, "HiCar unreg listener failed"); 
            } 

     2. Perform deinitialization by using the **deInit** method of **HiCarAdapter**.

The following is the sample code:
            
            **// Reset the initialization state of the HiCar SDK.**
            **mHiCarAdapter.deInit();** 
            
            // Set the **hicarAdapter** instance that is saved after successful initialization to null.
            mHiCarAdapter = null;
