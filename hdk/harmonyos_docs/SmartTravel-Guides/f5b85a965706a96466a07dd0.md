# Overview

**Rule 2-3: The HUAWEI HiCar logo can only be copied from the standard resource file.**

The HUAWEI HiCar logo is a balanced whole composed of elements of fixed relative size and position. The shape, structure, and proportion of the HUAWEI HiCar logo must not be changed.
