# Checking Whether HiCar Is Supported on the Phone  
  
#### Scenario

The HMI app can use the APIs provided by the HiCar SDK to determine whether the mobile phone connected to the head unit via Bluetooth supports HiCar, and then display a message or guide the user to use HiCar on the native head unit screen. For example, if the head unit has a native connection manager screen, devices connected to the head unit will display on this screen, as shown in Figure 1.

**Figure 1** Connection manager

For a phone that supports HiCar:

     * If the phone has been connected to the head unit, touching its device icon will directly initiate a connection. For details, please refer to [3](https://developer.huawei.com/consumer/cn/doc/development/SmartTravel-Guides/device-management-0000001606952849#EN-US_TOPIC_0000001606952849__li826017415532).
     * If the phone has not been connected to the head unit but supports HiCar, touching its device icon will redirect the user to the screen for initial connection. The user can enter a PIN on the screen to connect.

#### API Description

**Table 1** Related APIsClass | Method | Description  
---|---|---  
HiCarAdapter | isSupportHiCar | Checks whether the phone connected to the head unit via Bluetooth supports HiCar based on the Bluetooth address.  
  
#### Development Procedure

     1. The HMI app listens for system Bluetooth connection events. The following is a Bluetooth event example:
            
            **android.bluetooth.headsetclient.profile.action.CONNECTION_STATE_CHANGED**

     2. After receiving the system advertisement indicating that the Bluetooth connection is established, call the **isSupportHiCar** API of the HiCar SDK to check whether the mobile phone supports HiCar.
