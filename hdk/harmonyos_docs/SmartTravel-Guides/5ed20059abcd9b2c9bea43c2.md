# Managing Head Unit Connections

#### Scenario

After the phone and the head unit are connected after authentication, the head unit needs to save the information about the authenticated devices and provide a connection management UI to help the user disconnect or delete authenticated devices on the head unit.

**Figure 1** Connection management

The HMI app can manage authenticated devices through the APIs provided by the HiCar SDK, including obtaining the authenticated device list, deleting authenticated devices, disconnecting devices, connecting devices, and switching connections by disconnecting and connecting devices.

#### API Description

**Table 1** APIs for connection authenticationHeader File | Method | Description  
---|---|---  
hicar.h | HiCarGetTrustDeviceList | Obtains the list of devices that have been authenticated by the head unit.  
HiCarDisconnectDevice | Disconnects an authenticated device.  
HiCarDeleteTrustDevice | Deletes an authenticated device.  
HiCarReconnect | Triggers automatic connection.  
  
#### Development Procedure

     1. You will need to complete the design and development of the authentication management UI. This UI must contain a list of authenticated devices, where users can select one authenticated device and delete it.
     2. The HMI app can obtain the information about the authenticated devices through the APIs in the HiCar SDK, and display the information on the authentication management UI. The information includes the ID, name, and Bluetooth address of the authenticated phone, and its last connection time.

The following is the sample code:
            
            //Obtain the list of authenticated devices.
            TrustPhoneInfo info[10];
            TrustPhoneInfo *pinfo = &info;
            HiCarGetTrustDeviceList(&pinfo, 10); 
            
            //Delete an authenticated device. The device ID is obtained from the list of authenticated devices.
            HiCarDeleteTrustDevice(phoneId, idLen); 

     3. Manages connection switchover. Currently, HiCar does not support multiple phones to connect to the head unit at the same time. However, you can enable the switchover to one of the phones for the HiCar connection.

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210315.21407785286088498008311795975504:50001231000000:2800:C8E7357E14A3D4953F556279C9369CD004017422FAC870DE2A63915D3022C692.png?needInitFileName=true?needInitFileName=true)

HiCar connection switchover is not applicable when phones are connected to the head unit via USB. After a HiCar connection has been set up for a phone via USB, any other USB-connected phones can only be charged.

For the wireless connection case, when there are multiple phones that support HiCar, the HMI app can switch the HiCar connection among the phones.

The following is the sample code for switching the HiCar connection to phone B when phone A has established a HiCar connection with the head unit:
            
            TrustPhoneInfo *phoneInfo = NULL;
            int32_t phoneNum = 8;
            int32_t realNum = 0;
            int32_t find = 0;
            
            phoneInfo = (TrustPhoneInfo *)malloc(sizeof(TrustPhoneInfo) * phoneNum);
            if (phoneInfo == NULL) {
            	return;
            }
            // Obtain the list of authenticated devices.
            realNum = HiCarGetTrustDeviceList(&phoneInfo, phoneNum);
            //Check whether phone B is in the trust list.
            for (int i = 0; i < realNum; i++) {
            	if (memcmp(phoneInfo[i].phoneBrMac, B_PhoneMac) == 0) {
            		// If phone B is listed, the connection switchover can be triggered.
            		find = 1;
            		break;
            	}
            }
            
            if (find == 1) {
            	//Disconnect from phone A.
            	HiCarDisconnectDevice(A_PhoneId, Id_LENGTH);
            	//Switch the connection to phone B. The switchover is possible only when the phone has been paired with the head unit via Bluetooth.
            	HiCarReconnect(B_PhoneMac, MAC_LENGTH);
            }
            
            free(phoneInfo);
            phoneInfo = NULL;
