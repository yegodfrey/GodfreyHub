# Setting Wireless Connectivity Parameters

#### Enabling Wireless Connection of the SDK

The HMI app can call the relevant API to send the BLE advertising packets and set up a wireless connection only when the wireless connection function of the HiCar SDK is enabled.

The HMI app can enable the wireless connection function during SDK initialization, or dynamically enable the function when the SDK is running.

The following is the sample code for enabling wireless connection during SDK initialization:
    
    CarConfig.Builder builder = new CarConfig.Builder();
    ......
    //Enable the wireless connection function during SDK initialization. The value **true** indicates that the wireless connection function is enabled, and the value **false** indicates that wireless connection is disabled.
    **builder.withSupportWireless(true);**
    CarConfig carconfig = builder.build();

The following is the sample code for dynamically enabling wireless connection when the SDK is running:
    
    //Dynamically update whether to enable the wireless connection function when the SDK is running.
    **carconfig.updateSupportWireless(true)** ;

#### Setting the List of Supported 5 GHz Wi-Fi Channels (Beta)

The 5 GHz Wi-Fi channels supported by the head unit vary by manufacturers. With the HiCar SDK, you can set the list of 5 GHz channels supported by the head unit, which will be used by the SDK to establish a hotspot, ensuring that the phone performs negotiation within the channel list when connecting to the hotspot. This ensures successful connection. If you do not set this parameter, the HiCar SDK uses channels **[36,40,44,48,149]** to create a hotspot by default.

The sample code for setting the 5 GHz Wi-Fi channel list is as follows:
    
    // Set head unit information.
    CarConfig.Builder builder = new CarConfig.Builder();
    
    // Set the 5 GHz Wi-Fi channel list.
    int[] channels = new int[] { 36,40,44,48,149 };
    **builder.withSupport5gChannels(channels);**
    
    // Update the 5 GHz Wi-Fi channel list.
    **carconfig.update5gChannels(channels);**

#### Setting the Bluetooth Transmit Power (Beta)

The HiCar SDK searches for nearby phones in BLE advertising mode. When a phone is close to the head unit and receives the BLE advertisement, a dialog box is displayed on the phone, prompting the user to connect to HiCar. The Bluetooth transmit power of the advertisement determines the distance within which the phone can receive the advertisement. The higher the power strength, the longer the distance. If the transmit power is low, it means that the phone must be closed to the head unit enough in order to discover and connect to the head unit.

The Bluetooth transmit power ranges from –128 to 127. You can adjust the value to obtain the optimal discovery distance of the phone away from the head unit.

In a real vehicle environment, a device discovery prompt should be displayed every time the phone is within 0.7 m away from the head unit. The device discovery prompt should not be displayed anyway when the phone is over 1.5 m away from the head unit.

The sample code for setting the Bluetooth transmit power is as follows:
    
    // Set head unit information.
    CarConfig.Builder builder = new CarConfig.Builder();
    
    // Set the Bluetooth transmit power.
    int advPower = -112; 
    builder.withAdvPower(advPower);
    
    // Update the Bluetooth transmit power.
    carconfig.updateAdvPower(advPower);
