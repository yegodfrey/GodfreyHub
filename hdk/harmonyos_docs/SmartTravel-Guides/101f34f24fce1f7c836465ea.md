# Verifying the Wireless Connectivity

After the wireless connection configuration is complete, verify the wired connectivity of the head unit by using **HiCarDemo.apk** in the HiCar SDK.

     1. Run **HiCarDemo.apk**.

**Figure 1** Initial GUI of the HiCar Demo (for reference)  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230817210252.03554488670699922212230741737478:50001231000000:2800:6A36C400D5F6900F7BEF8A642D0F3598AD9CBCA88FCFB60446D110B55DC06BC9.png?needInitFileName=true?needInitFileName=true)

     2. Connect the mobile phone to the head unit device in wireless mode.

If the wireless connection is set up, a confirmation dialog box is displayed. After the connection is successful, the HiCar screen is displayed.

If the wireless connection fails, locate and rectify the fault based on the logs.
