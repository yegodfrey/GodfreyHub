# Obtaining the Connection Mode

#### Scenario

The HMI app can use the **HiCarAdapter::getConnectionType()** method to obtain the current connection mode and handle some service scenarios. For example, after a user successfully establishes a wireless connection, the phone and the head unit exchange data by using the newly established Wi-Fi AP. If the user manually modifies information about the Wi-Fi AP, the connection will be disconnected. To ensure that the HiCar connection functions properly, the HMI app can disable the function to modify the Wi-Fi AP information.

#### API Description

**Table 1** APIs for obtaining the connection modeClass | Method | Description  
---|---|---  
HiCarAdapter | getConnectionType | Returns the current connection mode, which can be:
     * **CONNECTION_TYPE_USB** (value being **5**): Wired connection.
     * **CONNECTION_TYPE_WIFI** (value being **4**): Wireless connection.
     * **CONNECTION_TYPE_UNKNOWN** (value being **–1**): Unknown connection mode.  
  
#### Development Procedure

The following is the sample code for obtaining the connection mode:
    
    // Obtain the connection mode.
    int connectType = **mHiCarAdapter.getConnectionType()** ;
    if (connectType == HiCarConst.CONNECTION_TYPE_USB) {
         // TODO: Your own logics
    } else if (connectType == HiCarConst.CONNECTION_TYPE_WIFI) {
         // TODO: Your own logics
    } else {
         // TODO: Your own logics
    }
