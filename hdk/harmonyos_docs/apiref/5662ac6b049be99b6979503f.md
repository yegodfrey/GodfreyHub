# Broadcast  
  
#### Overview

**Description:**

Provides data subscription and data push for services. 

With this module, the [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055675026), [Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055075077), or other modules can broadcast events or data. All services that listen to these events or data can receive these broadcasts. 

**Since:**

1.0

**Version:**

1.0
