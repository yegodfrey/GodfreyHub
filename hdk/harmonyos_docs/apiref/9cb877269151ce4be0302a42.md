# OHOS::UIPicker  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Defines a picker. Multiple texts or numbers can be put into a sliding list for selection. The selected text or numbers are highlighted. 

**Since:**

1.0

**Version:**

1.0
