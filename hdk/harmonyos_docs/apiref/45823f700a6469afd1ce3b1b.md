# wifi_module.h  
  
#### Overview

**Related Modules:**

[WLAN](https://device.harmonyos.com/cn/docs/develop/apiref/wlan-0000001055198080)

**Description:**

Provides features of the WLAN module and functions to create and delete modules. 

The [WifiModule](https://device.harmonyos.com/cn/docs/develop/apiref/wifimodule-0000001054718169) object is a core abstraction of the WLAN driver. It contains a module that communicates with user-level processes and also contains features.
