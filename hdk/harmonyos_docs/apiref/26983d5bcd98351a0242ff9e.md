# osal_firmware.h  
  
#### Overview

**Related Modules:**

[OSAL](https://device.harmonyos.com/cn/docs/develop/apiref/osal-0000001054799547)

**Description:**

Declares firmware structures and interfaces. 

This file provides operations such as requesting and reading a firmware file, setting the offset for reading a firmware file, and releasing a firmware file. The firmware file can be read in split mode. The size of the firmware block to read each time is defined by the macro **HDF_FW_BLOCK_SIZE**. The firmware file is requested by calling [OsalRequestFirmware](https://device.harmonyos.com/cn/docs/develop/apiref/osal-0000001054799547#ZH-CN_TOPIC_0000001054799547__ga428b9de7fb95a20ab9e25b47a7d4272c), the firmware block is read from the firmware file by calling [OsalReadFirmware](https://device.harmonyos.com/cn/docs/develop/apiref/osal-0000001054799547#ZH-CN_TOPIC_0000001054799547__ga2b721d36c177786841cd05cecdb01034), and the firmware block can also be randomly read at a specified position by calling [OsalSeekFirmware](https://device.harmonyos.com/cn/docs/develop/apiref/osal-0000001054799547#ZH-CN_TOPIC_0000001054799547__ga41ae4dade9246f3b30efd276cbd43474).
