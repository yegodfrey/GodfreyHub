# OHOS::Window  
  
#### Overview

**Related Modules:**

[Window](https://device.harmonyos.com/cn/docs/develop/apiref/window-0000001055039468)

**Description:**

Provides a drawing canvas for the **[RootView](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1rootview-0000001054598173)** , which represents the root node of a view tree. 

Each window is bound to a **[RootView](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1rootview-0000001054598173)**. For details, see [RootView](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1rootview-0000001054598173). This class also provides window management capabilities, including creating, destroying, showing, hiding, moving, resizing a window, raising a window to the top, and lowering a window to the bottom.

**Since:**

1.0

**Version:**

1.0
