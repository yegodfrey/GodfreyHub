# flow_control.h  
  
#### Overview

**Related Modules:**

[WLAN](https://device.harmonyos.com/cn/docs/develop/apiref/wlan-0000001055198080)

**Description:**

Declares flow control modules and provides functions such as initializing and deinitializing a flow control module, and transmitting and receiving data packets based on the flow control priority.

1.0
