# IWiFiSta

#### Overview

**Related Modules:**

[WLAN](https://device.harmonyos.com/cn/docs/develop/apiref/wlan-0000001055198080)

**Description:**

Inherits the basic features of [IWiFiBaseFeature](https://device.harmonyos.com/cn/docs/develop/apiref/iwifibasefeature-0000001106437920) and additionally provides the feature of setting scanning for a single MAC address. 

**Since:**

1.0

**Version:**

1.0

#### [h2]setScanningMacAddress
    
    int32_t(* IWiFiSta::setScanningMacAddress) (const struct [IWiFiSta](https://device.harmonyos.com/cn/docs/develop/apiref/iwifista-0000001152877837) *staFeature, unsigned char *scanMac, uint8_t len)

**Description:**

Sets scanning for a single MAC address. 

**Parameters:**

Name | Description  
---|---  
staFeature | Indicates the pointer to the STA feature, as described in [IWiFiSta](https://device.harmonyos.com/cn/docs/develop/apiref/iwifista-0000001152877837).   
scanMac | Indicates the pointer to the MAC address to scan for.   
len | Indicates the length of the MAC address.  
  
**Returns:**

Returns **0** if scanning for the MAC address is successfully set; returns a negative value otherwise.
