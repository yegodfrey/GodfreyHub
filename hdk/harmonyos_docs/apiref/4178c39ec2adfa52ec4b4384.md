# IAbilityConnection

#### Overview

**Related Modules:**

[AbilityKit](https://device.harmonyos.com/cn/docs/develop/apiref/abilitykit-0000001054598111)

**Description:**

Provides callbacks to be invoked when a remote [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) ability is connected or disconnected.
