# element_name.h  
  
#### Overview

**Related Modules:**

[BundleManager](https://device.harmonyos.com/cn/docs/develop/apiref/bundlemanager-0000001054918105)

**Description:**

Declares the structure that defines the required information for querying [AbilityInfo](https://device.harmonyos.com/cn/docs/develop/apiref/abilityinfo-0000001054918143), including the device ID, bundle name, and class name, and functions for setting such information. 

You can use functions provided in this file to specify the information for querying [AbilityInfo](https://device.harmonyos.com/cn/docs/develop/apiref/abilityinfo-0000001054918143).

**Since:**

1.0

**Version:**

1.0
