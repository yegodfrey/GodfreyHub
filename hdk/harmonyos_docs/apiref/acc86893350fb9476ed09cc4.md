# SensorInterface

#### Overview

**Related Modules:**

[Sensor](https://device.harmonyos.com/cn/docs/develop/apiref/sensor-0000001082140320)

**Description:**

Defines the functions for performing basic operations on sensors. 

The operations include obtaining sensor information, subscribing to or unsubscribing from sensor data, enabling or disabling a sensor, setting the sensor data reporting mode, and setting sensor options such as the accuracy and measurement range.

#### [h2]GetAllSensors

**Description:**

Obtains information about all sensors in the system. 

**Parameters:**

Name | Description  
---|---  
sensorInfo | Indicates the double pointer to the information about all sensors in the system. The information about a sensor generally includes the sensor name, sensor vendor, firmware version, hardware version, sensor type ID, sensor ID, maximum measurement range, accuracy, and power. For details, see [SensorInformation](https://device.harmonyos.com/cn/docs/develop/apiref/sensorinformation-0000001129018079).   
count | Indicates the pointer to the total number of sensors in the system.   
  
**Returns:**

Returns **0** if the information is obtained; returns a negative value otherwise.
