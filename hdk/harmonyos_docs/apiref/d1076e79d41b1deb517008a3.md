# OHOS::UISlider::UISliderEventListener  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Represents the listener for a slider change. 

This is an inner class of **[UISlider](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1uislider-0000001054918181)** used to listen for slider events and invoke the callback function.

See also
