# OHOS::AnimatorManager  
  
#### Overview

**Related Modules:**

[UI_Animator](https://device.harmonyos.com/cn/docs/develop/apiref/ui__animator-0000001081852204)

**Description:**

Represents the animator manager. 

This is a singleton class used to manage **[Animator](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1animator-0000001055518106)** instances.
