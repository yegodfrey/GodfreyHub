# Request

#### Overview

**Related Modules:**

[Samgr](https://device.harmonyos.com/cn/docs/develop/apiref/samgr-0000001055078091)

**Description:**

Defines a request. 

You can use this structure to define the request that will be sent to a feature through the asynchronous function of [IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055078143). [Request](https://device.harmonyos.com/cn/docs/develop/apiref/request-0000001055358144), which is data that is packed to send to a feature. If the data is not empty and the length is not 0, the system automatically releases the data.
