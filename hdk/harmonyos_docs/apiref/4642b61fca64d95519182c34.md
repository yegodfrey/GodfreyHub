# OHOS::UIImageAnimatorView  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Represents an image animator. 

Images are switched at a specified interval to form an animator.

See also 
    [UIImageView](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1uiimageview-0000001054718151)
