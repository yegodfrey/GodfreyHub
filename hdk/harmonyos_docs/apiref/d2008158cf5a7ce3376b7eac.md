# OHOS::UICircleProgress  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Represents a circular progress bar. 

This class is used to set the start and end angles, range, and current value to display the circular progress bar.

See also 
    [UIAbstractProgress](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1uiabstractprogress-0000001055078159)

**Since:**

1.0

**Version:**

1.0
