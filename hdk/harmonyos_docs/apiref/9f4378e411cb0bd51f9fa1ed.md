# OHOS::AbilityContext  
  
#### Overview

**Related Modules:**

[AbilityKit](https://device.harmonyos.com/cn/docs/develop/apiref/abilitykit-0000001054598111)

**Description:**

Provides functions for starting and stopping an ability. 

The [Ability](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1ability-0000001054479575) and [AbilitySlice](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abilityslice-0000001055078151) classes are inherited from the **[AbilityContext](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abilitycontext-0000001054879544)** class for you to call functions in this class for application development.

**Since:**

1.0

**Version:**

1.0
