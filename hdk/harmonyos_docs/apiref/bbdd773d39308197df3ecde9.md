# hdf_sbuf.h  
  
#### Overview

**Related Modules:**

[Core](https://device.harmonyos.com/cn/docs/develop/apiref/core-0000001054718073)

**Description:**

Defines functions related to a **[HdfSBuf](https://device.harmonyos.com/cn/docs/develop/apiref/hdfsbuf-0000001055039516)**. The HDF provides data serialization and deserialization capabilities for data transmission between user-mode applications and kernel-mode drivers.

1.0
