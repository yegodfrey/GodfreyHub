# NetcfgService  
  
#### Overview

**Description:**

Provides the network configuration service. Two network configuration modes are available: Neighbor Awareness Networking (NAN) and software enabled access point (SoftAP). 

**Since:**

1.0

**Version:**

1.0

**Description:**
