#### [h2]Play()
    
    int32_t OHOS::Media::Player::Play ()

**Description:**

Starts or resumes playback. 

This function must be called after [Prepare](https://device.harmonyos.com/cn/docs/develop/apiref/multimedia__player-0000001055518042#ZH-CN_TOPIC_0000001055518042__gade9bff3268e1c409273749a90700e056). If the player state is **Prepared** , this function is called to start playback. If the player state is **Playback paused** , this function is called to resume playback. If the media is playing in an abnormal speed, this function is called to restore the playback speed to normal.

**Returns:**

Returns **0** if the playback starts or resumes; returns **-1** otherwise.
