#### [h2]InputBufferAvailable
    
    int(* CodecCallback::InputBufferAvailable) ([UINTPTR](https://device.harmonyos.com/cn/docs/develop/apiref/codec-0000001055078087#ZH-CN_TOPIC_0000001055078087__ga58d2f4a8d12daa1dcf4eb297f3ebaabc) comp, [UINTPTR](https://device.harmonyos.com/cn/docs/develop/apiref/codec-0000001055078087#ZH-CN_TOPIC_0000001055078087__ga58d2f4a8d12daa1dcf4eb297f3ebaabc) appData, [InputInfo](https://device.harmonyos.com/cn/docs/develop/apiref/inputinfo-0000001054879536) *inBuf)

**Description:**

Reports that the input data has been used. 

This callback is invoked in asynchronous mode.

**Parameters:**

Name | Description  
---|---  
hComponent | Indicates the handle of the codec component.   
pAppData | Indicates upper-layer data, which is generally an upper-layer instance passed when this callback is set.   
pBuffer | Indicates the pointer to the input data that has been used.   
  
**Returns:**

Returns **0** if the operation is successful; returns a non-zero value otherwise. 

#### [h2]OnEvent
    
    int(* CodecCallback::OnEvent) ([UINTPTR](https://device.harmonyos.com/cn/docs/develop/apiref/codec-0000001055078087#ZH-CN_TOPIC_0000001055078087__ga58d2f4a8d12daa1dcf4eb297f3ebaabc) comp, [UINTPTR](https://device.harmonyos.com/cn/docs/develop/apiref/codec-0000001055078087#ZH-CN_TOPIC_0000001055078087__ga58d2f4a8d12daa1dcf4eb297f3ebaabc) appData, [EventType](https://device.harmonyos.com/cn/docs/develop/apiref/codec-0000001055078087#ZH-CN_TOPIC_0000001055078087__ga2628ea8d12e8b2563c32f05dc7fff6fa) event, uint32_t data1, uint32_t data2, [UINTPTR](https://device.harmonyos.com/cn/docs/develop/apiref/codec-0000001055078087#ZH-CN_TOPIC_0000001055078087__ga58d2f4a8d12daa1dcf4eb297f3ebaabc) eventData)

**Description:**

Reports an event. 

Reports event errors and output format changes.

**Parameters:**

Name | Description  
---|---  
hComponent | Indicates the handle of the codec component.   
pAppData | Indicates upper-layer data, which is generally an upper-layer instance passed when this callback is set.   
EVENTTYPE | Indicates the event type.   
nData1 | Indicates the first value contained in the reported event. This parameter is optional.   
nData2 | Indicates the second value contained in the reported event. This parameter is optional.   
pEventData | Indicates the pointer to data contained in the reported event. This parameter is optional.   
  
**Returns:**

Returns **0** if the operation is successful; returns a non-zero value otherwise.
