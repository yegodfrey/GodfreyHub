# LayerInfo

#### Overview

**Related Modules:**

[Display](https://device.harmonyos.com/cn/docs/develop/apiref/display-0000001055198078)

**Description:**

Defines layer information. 

**[LayerInfo](https://device.harmonyos.com/cn/docs/develop/apiref/layerinfo-0000001055518096)** must be passed to the **OpenLayer** function, which creates a layer based on the layer information.
