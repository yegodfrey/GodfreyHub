# OHOS::Media::StreamCallback  
  
#### Overview

**Related Modules:**

[MultiMedia_MediaCommon](https://device.harmonyos.com/cn/docs/develop/apiref/multimedia__mediacommon-0000001055678046)

**Description:**

Provides functions to obtain the address of a buffer memory and write the filled buffers into the playback queue. You need to implement the **[StreamCallback](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1media_1_1streamcallback-0000001054479577)** functions in a player object. 

**Since:**

1.0

**Version:**

1.0
