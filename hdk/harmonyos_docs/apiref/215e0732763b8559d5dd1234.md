# sensor_if.h  
  
#### Overview

**Related Modules:**

[Sensor](https://device.harmonyos.com/cn/docs/develop/apiref/sensor-0000001082140320)

**Description:**

Declares the APIs provided by the sensor module for obtaining sensor information, subscribing to or unsubscribing from sensor data, enabling or disabling a sensor, setting the sensor data reporting mode, and setting sensor options such as the accuracy and measurement range.

2.2
