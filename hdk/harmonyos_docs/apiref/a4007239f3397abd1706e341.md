# PWM  
  
#### Overview

**Description:**

Provides standard pulse width modulation (PWM) interfaces for driver development. 

The PWM module abstracts the PWM capabilities of different system platforms to provide stable APIs for driver development. You can use this module to create/release PWM device handles, set the PWM period, polarity, and duty cycle, enable/disable PWM devices, and set/obtain the PWM configuration.

**Since:**

1.0
