# IPowerEventListener

#### Overview

**Related Modules:**

[Core](https://device.harmonyos.com/cn/docs/develop/apiref/core-0000001054718073)

**Description:**

Defines the power management functions provided by the HDF for the driver. 

To use the power management mechanism provided by the HDF, implement operations of **[IPowerEventListener](https://device.harmonyos.com/cn/docs/develop/apiref/ipowereventlistener-0000001055358112)** and invoke {@linkHdfDeviceRegisterPowerListener} to register the operations with the HDF.

**Since:**

1.0
