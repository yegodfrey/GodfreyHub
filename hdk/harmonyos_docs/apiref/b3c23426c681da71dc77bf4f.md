# OHOS::AbilityLoader  
  
#### Overview

**Related Modules:**

[AbilityKit](https://device.harmonyos.com/cn/docs/develop/apiref/abilitykit-0000001054598111)

**Description:**

Declares functions for registering the class names of [Ability](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1ability-0000001054479575) and [AbilitySlice](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abilityslice-0000001055078151) with the ability management framework. 

After creating your own [Ability](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1ability-0000001054479575) and [AbilitySlice](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abilityslice-0000001055078151) child classes, you should register their class names with the ability management framework so that the application can start **[Ability](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1ability-0000001054479575)** instances created in the background.
