#### [h2]GetName
    
    const char*(* Feature::GetName) ([Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) *feature)

**Description:**

Obtains a feature name. 

This function is implemented by developers and called by Samgr during feature registration and startup. 

**Parameters:**

Name | Description  
---|---  
feature | Indicates the pointer to the feature.   
  
**Returns:**

Returns a constant character string less than 16 bytes if the operation is successful; returns **NULL** if the operation fails.

#### [h2]OnInitialize
    
    void(* Feature::OnInitialize) ([Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) *feature, [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) *parent, [Identity](https://device.harmonyos.com/cn/docs/develop/apiref/identity-0000001054918159) identity)

**Description:**

Initializes a feature. 

This function is implemented by developers. After Samgr dispatches tasks to a service, the service calls this function in its own tasks. 

**Parameters:**

Name | Description  
---|---  
feature | Indicates the pointer to the feature.   
parent | Indicates the pointer to the [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) to which the feature belongs.   
identity | Indicates the identity of a feature dispatched by the system.  
  
#### [h2]OnMessage
    
    BOOL(* Feature::OnMessage) ([Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) *feature, [Request](https://device.harmonyos.com/cn/docs/develop/apiref/request-0000001055358144) *request)

**Description:**

Processes a feature message. 

This function is implemented by developers to process requests sent by callers through [IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055078143). 

**Parameters:**

Name | Description  
---|---  
feature | Indicates the pointer to the feature.   
request | Indicates the request message.   
  
**Returns:**

Returns **TRUE** if the processing is successful; returns **FALSE** if the processing fails.

#### [h2]OnStop
    
    void(* Feature::OnStop) ([Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) *feature, [Identity](https://device.harmonyos.com/cn/docs/develop/apiref/identity-0000001054918159) identity)

**Description:**

Stops a feature. 

This function is implemented by developers and is called by Samgr when a feature is deregistered to stop running services. 

**Parameters:**

Name | Description  
---|---  
feature | Indicates the pointer to the feature.   
identity | Indicates the [Identity](https://device.harmonyos.com/cn/docs/develop/apiref/identity-0000001054918159) of the feature to be stopped.
