# pwm_if.h

#### Overview

**Related Modules:**

[PWM](https://device.harmonyos.com/cn/docs/develop/apiref/pwm-0000001128602593)

**Description:**

Declares standard PWM interfaces for driver development. 

A driver needs to use the PWM interfaces to perform operations on a PWM device.

1.0
