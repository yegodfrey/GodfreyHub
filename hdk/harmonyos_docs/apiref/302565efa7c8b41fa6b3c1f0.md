# SpiDevInfo

#### Overview

**Related Modules:**

[SPI](https://device.harmonyos.com/cn/docs/develop/apiref/spi-0000001055518038)

**Description:**

Defines the general SPI device descriptor, which can be used as the unique identifier of an SPI device. When operating an SPI device, you need to specify a descriptor of the [SpiDevInfo](https://device.harmonyos.com/cn/docs/develop/apiref/spidevinfo-0000001055039554) type, and obtain the handle of the SPI device by calling [SpiOpen](https://device.harmonyos.com/cn/docs/develop/apiref/spi-0000001055518038#ZH-CN_TOPIC_0000001055518038__ga193e808f7e68a5b4c6b71ca2db47a11f). 

**Since:**

1.0
