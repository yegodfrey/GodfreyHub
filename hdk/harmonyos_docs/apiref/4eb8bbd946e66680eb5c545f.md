# OHOS::UIView  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Defines the base class of a view, providing basic view attributes and operations. All views are derived from this class. 

**Since:**

1.0

**Version:**

1.0
