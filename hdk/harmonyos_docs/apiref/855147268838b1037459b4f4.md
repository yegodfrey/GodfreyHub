#### [h2]asctime()
    
    char* asctime (const struct [tm](https://device.harmonyos.com/cn/docs/develop/apiref/tm-0000001055358158) * tm)

**Description:**

Converts the broken-down time in the [tm](https://device.harmonyos.com/cn/docs/develop/apiref/tm-0000001055358158) structure into a string. 

**Parameters:**

Name | Description  
---|---  
tm | Indicates the pointer to the broken-down time in the [tm](https://device.harmonyos.com/cn/docs/develop/apiref/tm-0000001055358158) structure.   
  
**Returns:**

Returns the string in the format of **week month day hour:minute:second year** , for example, **Thu Jan 1 08:00:00 1970**. If the conversion fails, the program ends.
