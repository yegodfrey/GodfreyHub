# root_view.h

#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Manages a root view. 

A root view is the view containing its child views. It represents the root node in a tree structure and is the parent to all the children.
