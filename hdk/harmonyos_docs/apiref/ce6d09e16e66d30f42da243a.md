# WifiLinkedInfo

#### Overview

**Related Modules:**

[Wifiservice](https://device.harmonyos.com/cn/docs/develop/apiref/wifiservice-0000001055195054)

**Description:**

Represents the Wi-Fi connection information. 

This refers to the information about the hotspot connected to this station. The information is obtained using [GetLinkedInfo](https://device.harmonyos.com/cn/docs/develop/apiref/wifiservice-0000001055195054#ZH-CN_TOPIC_0000001055195054__gaa8f07a31b01761da44f0fe90d461c168).

1.0

1.0
