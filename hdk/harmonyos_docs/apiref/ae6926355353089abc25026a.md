# SdioFuncInfo  
  
#### Overview

**Related Modules:**

[SDIO](https://device.harmonyos.com/cn/docs/develop/apiref/sdio-0000001055678042)

**Description:**

Defines the SDIO capabilities. 

You can obtain and set the SDIO capabilities by calling [SdioGetCommonInfo](https://device.harmonyos.com/cn/docs/develop/apiref/sdio-0000001055678042#ZH-CN_TOPIC_0000001055678042__ga1289cc512ba56e3e904204c15d8ae23d) and [SdioSetCommonInfo](https://device.harmonyos.com/cn/docs/develop/apiref/sdio-0000001055678042#ZH-CN_TOPIC_0000001055678042__ga6a8eb2f6413c4685f92236dd1c8083dc) with [SdioCommonInfo](https://device.harmonyos.com/cn/docs/develop/apiref/unionsdiocommoninfo-0000001054799637) and [SdioCommonInfoType](https://device.harmonyos.com/cn/docs/develop/apiref/sdio-0000001055678042#ZH-CN_TOPIC_0000001055678042__ga4037437ac001a9848dd242e8aa632678) passed.
