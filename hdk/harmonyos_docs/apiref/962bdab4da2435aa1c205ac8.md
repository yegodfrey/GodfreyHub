# AbilityKit

#### Overview

**Description:**

Provides ability-related functions, including ability lifecycle callbacks and functions for connecting to or disconnecting from Particle Abilities. 

Abilities are classified into [Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) Abilities and Particle Abilities. [Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) Abilities support the Page template, and Particle Abilities support the [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) template. An ability using the Page template is called a Page ability for short and that using the [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) template is called a [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) ability.

**Since:**

1.0

**Version:**

1.0
