# StationInfo

#### Overview

**Related Modules:**

[Wifiservice](https://device.harmonyos.com/cn/docs/develop/apiref/wifiservice-0000001055195054)

**Description:**

Represents the station information. 

The station information is returned when **OnHotspotStaJoin** or **OnHotspotStaLeave** is called.
