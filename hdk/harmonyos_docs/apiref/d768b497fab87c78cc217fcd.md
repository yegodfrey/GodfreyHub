# OHOS::UICheckBox::OnChangeListener  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Represents a listener for changes of a check box. 

This is an inner class of **[UICheckBox](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1uicheckbox-0000001054479587)**. It contains a callback function to be invoked when the check box state changes.
