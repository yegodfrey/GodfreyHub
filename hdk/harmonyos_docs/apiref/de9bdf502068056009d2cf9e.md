# OSAL  
  
#### Overview

**Description:**

Defines the structures and interfaces for the Operating System Abstraction Layer (OSAL) module. 

The OSAL module OpenHarmony OS interface differences and provides unified OS interfaces externally, including the memory management, thread, mutex, spinlock, semaphore, timer, file, interrupt, time, atomic, firmware, and I/O operation modules.

**Since:**

1.0

**Version:**

1.0
