# OHOS::AbilitySlice  
  
#### Overview

**Related Modules:**

[AbilityKit](https://device.harmonyos.com/cn/docs/develop/apiref/abilitykit-0000001054598111)

**Description:**

Provides ability slice-related functions, including ability slice lifecycle callbacks and functions for connecting to or disconnecting from ability slices. 

**[AbilitySlice](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abilityslice-0000001055078151)** instances, which are specific to [Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) Abilities (abilities using the Page template), are used to present different screens on an application's user interface. A [Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) [Ability](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1ability-0000001054479575) can have multiple ability slices.

**Since:**

1.0

**Version:**

1.0
