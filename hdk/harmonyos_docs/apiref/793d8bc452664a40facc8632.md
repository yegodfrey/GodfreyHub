# iot_i2c.h  
  
#### Overview

**Related Modules:**

[IotHardware](https://device.harmonyos.com/cn/docs/develop/apiref/iothardware-0000001128233903)

**Description:**

Declares functions for operating I2C devices. 

These functions are used to initialize or deinitialize an I2C device, and read data from or write data to an I2C device. 

**Since:**

2.2
