# FormatBufferSetting  
  
#### Overview

**Related Modules:**

[Format](https://device.harmonyos.com/cn/docs/develop/apiref/format-0000001055358056)

**Description:**

Defines the buffer configuration. 

If **maxSize** and **maxDurationMs** are valid at the same time, the smaller value is used as the upper limit for the buffer.

**Since:**

1.0

**Version:**

1.0
