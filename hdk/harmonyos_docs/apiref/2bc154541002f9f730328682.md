# OHOS::Media::Player  
  
#### Overview

**Related Modules:**

[MultiMedia_Player](https://device.harmonyos.com/cn/docs/develop/apiref/multimedia__player-0000001055518042)

**Description:**

Provides functions for playing online movies, offline movies, and streams, for example, playing local movies and advanced audio coding (AAC) streams.
