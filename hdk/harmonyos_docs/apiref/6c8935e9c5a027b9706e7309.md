# OHOS::Animator  
  
#### Overview

**Related Modules:**

[UI_Animator](https://device.harmonyos.com/cn/docs/develop/apiref/ui__animator-0000001081852204)

**Description:**

Represents an animator. 

This class is used to set the animator attributes, such as the duration, whether an animator is repeated, start and stop of an animator.

See also 
    [Animator](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1animator-0000001055518106)

**Since:**

1.0

**Version:**

1.0
