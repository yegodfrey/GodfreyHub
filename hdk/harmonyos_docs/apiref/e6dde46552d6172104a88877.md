# FTW  
  
#### Overview

**Related Modules:**

[FS](https://device.harmonyos.com/cn/docs/develop/apiref/fs-0000001055069400)

**Description:**

Defines the file tree walker ([FTW](https://device.harmonyos.com/cn/docs/develop/apiref/ftw-0000001055078137)). 

**[ftw.h](https://device.harmonyos.com/cn/docs/develop/apiref/ftw_8h-0000001055228014)** describes the **[FTW](https://device.harmonyos.com/cn/docs/develop/apiref/ftw-0000001055078137)** structure. The file location can be determined based on the offset and the depth relative to the root node.
