# iot_flash.h  
  
#### Overview

**Related Modules:**

[IotHardware](https://device.harmonyos.com/cn/docs/develop/apiref/iothardware-0000001128233903)

**Description:**

Declares flash functions. 

These functions are used to initialize or deinitialize a flash device, and read data from or write data to a flash memory.
