# IWiFi  
  
#### Overview

**Related Modules:**

[WLAN](https://device.harmonyos.com/cn/docs/develop/apiref/wlan-0000001055198080)

**Description:**

Defines the basic WLAN features provided by the hardware abstraction layer (HAL). 

The basic features include creating and stopping a channel between the HAL and the WLAN driver, and creating, obtaining, and destroying WLAN features.

**Since:**

1.0

**Version:**

1.0
