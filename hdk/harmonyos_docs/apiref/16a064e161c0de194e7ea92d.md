# SensorInformation

#### Overview

**Related Modules:**

[Sensor](https://device.harmonyos.com/cn/docs/develop/apiref/sensor-0000001082140320)

**Description:**

Defines basic sensor information. 

Information about a sensor includes the sensor name, vendor, firmware version, hardware version, sensor type ID, sensor ID, maximum measurement range, accuracy, and power.

**Since:**

2.2
