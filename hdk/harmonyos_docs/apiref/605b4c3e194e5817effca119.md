#### [h2]Dispatch
    
    int(* HdfIoDispatcher::Dispatch) (struct [HdfObject](https://device.harmonyos.com/cn/docs/develop/apiref/hdfobject-0000001054918155) *service, int cmdId, struct [HdfSBuf](https://device.harmonyos.com/cn/docs/develop/apiref/hdfsbuf-0000001055039516) *data, struct [HdfSBuf](https://device.harmonyos.com/cn/docs/develop/apiref/hdfsbuf-0000001055039516) *reply)

**Description:**

Dispatches a driver service call. **service** indicates the pointer to the driver service object, **id** indicates the command word of the function, **data** indicates the pointer to the data you want to pass to the driver, and **reply** indicates the pointer to the data returned by the driver.
