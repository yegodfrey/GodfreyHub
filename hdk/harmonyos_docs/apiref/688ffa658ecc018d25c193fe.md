# bundle_manager.h  
  
#### Overview

**Related Modules:**

[BundleManager](https://device.harmonyos.com/cn/docs/develop/apiref/bundlemanager-0000001054918105)

**Description:**

Declares functions used for managing application bundles and obtaining bundle information. 

You can use functions provided in this file to install, update, or uninstall an application, obtain [AbilityInfo](https://device.harmonyos.com/cn/docs/develop/apiref/abilityinfo-0000001054918143) and [BundleInfo](https://device.harmonyos.com/cn/docs/develop/apiref/bundleinfo-0000001055678086) about an application, obtain the bundle name of an application based on the application's user ID (UID), and obtain [BundleInfo](https://device.harmonyos.com/cn/docs/develop/apiref/bundleinfo-0000001055678086) objects of all applications or keep-alive applications in the system.

**Since:**

1.0

**Version:**

1.0
