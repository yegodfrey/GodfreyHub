# osal_thread.h  
  
#### Overview

**Related Modules:**

[OSAL](https://device.harmonyos.com/cn/docs/develop/apiref/osal-0000001054799547)

**Description:**

Declares thread types and interfaces. 

Threads created by the OSAL module are in the detached state. When releasing threads, the service module must first terminate its own threads and then [OsalThreadDestroy](https://device.harmonyos.com/cn/docs/develop/apiref/osal-0000001054799547#ZH-CN_TOPIC_0000001054799547__ga223ce6b94770348a93168525c536e6f9) can be called to release applied resources.

**Since:**

1.0

**Version:**

1.0
