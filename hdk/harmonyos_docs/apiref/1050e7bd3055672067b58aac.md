# InputManager

#### Overview

**Related Modules:**

[Input](https://device.harmonyos.com/cn/docs/develop/apiref/input-0000001054879480)

**Description:**

Provides interfaces for managing input devices. 

The interfaces can be used to perform basic operations on the input devices, such as opening and closing the device files, querying information about a specified input device, and obtaining information about all input devices in the device list.

#### [h2]CloseInputDevice
    
    int32_t(* InputManager::CloseInputDevice) (uint32_t devIndex)

**Description:**

Closes a specified input device file. 

**Parameters:**

Name | Description  
---|---  
devIndex | Indicates the index of an input device. A maximum of 32 input devices are supported. The value ranges from 0 to 31, and value **0** represents the first input device.   
  
**Returns:**

Returns **0** if the operation is successful; returns an error code defined in [RetStatus](https://device.harmonyos.com/cn/docs/develop/apiref/input-0000001054879480#ZH-CN_TOPIC_0000001054879480__ga85d58a5185669daa4995e332b63eba7a) otherwise.
