# IpHeader  
  
#### Overview

**Related Modules:**

[WLAN](https://device.harmonyos.com/cn/docs/develop/apiref/wlan-0000001055198080)

**Description:**

Defines the IP header information of a data frame, including the version number, service type, and total length.
