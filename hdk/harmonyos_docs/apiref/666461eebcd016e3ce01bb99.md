# SensorEvents  
  
#### Overview

**Related Modules:**

[Sensor](https://device.harmonyos.com/cn/docs/develop/apiref/sensor-0000001082140320)

**Description:**

Defines the data reported by the sensor. 

The reported sensor data includes the sensor ID, sensor algorithm version, data generation time, data options (such as the measurement range and accuracy), data reporting mode, data address, and data length.

**Since:**

2.2
