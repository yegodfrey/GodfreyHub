# HdfChipDriverFactory

#### Overview

**Related Modules:**

[WLAN](https://device.harmonyos.com/cn/docs/develop/apiref/wlan-0000001055198080)

**Description:**

Describes the **[HdfChipDriverFactory](https://device.harmonyos.com/cn/docs/develop/apiref/hdfchipdriverfactory-0000001081980706)** instance and provides functions such as initializing and deinitializing a chip, and obtaining the maximum number of interfaces. 

**Since:**

1.0

**Version:**

1.0
