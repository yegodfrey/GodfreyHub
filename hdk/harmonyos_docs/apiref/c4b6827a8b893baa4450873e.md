# BundleManager

#### Overview

**Description:**

Provides structures and functions for managing application bundles and obtaining application information. 

You can use functions provided by this module to install, update, or uninstall an application, obtain [AbilityInfo](https://device.harmonyos.com/cn/docs/develop/apiref/abilityinfo-0000001054918143) and [BundleInfo](https://device.harmonyos.com/cn/docs/develop/apiref/bundleinfo-0000001055678086) about an application, and obtain the bundle name of an application based on the application's user ID (UID).

**Since:**

1.0

**Version:**

1.0
