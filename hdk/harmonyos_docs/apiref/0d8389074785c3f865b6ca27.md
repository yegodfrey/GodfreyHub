# Identity  
  
#### Overview

**Related Modules:**

[Samgr](https://device.harmonyos.com/cn/docs/develop/apiref/samgr-0000001054715047)

**Description:**

Identifies a service and feature. 

You can use this structure to identity a [IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055675024) feature to which messages will be sent through the asynchronous function of [IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055675024).
