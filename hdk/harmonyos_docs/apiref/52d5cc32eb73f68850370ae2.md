# OHOS::UIList  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Represents a scrollable list which is used with the adapter [AbstractAdapter](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abstractadapter-0000001055518108) to implement scrolling, inertial scrolling, automatic alignment, and invoking of a callback when a child view is selected at the preset position as this list scrolls. 

You need to override [AbstractAdapter](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abstractadapter-0000001055518108) to implement functions for setting and saving data, obtaining data quantity, and creating child views. **[UIList](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1uilist-0000001054799625)** is used when there is a large number of child views with a fixed format. This list automatically reclaims the child views removed out of the current view as it scrolls so that as many as child views can be displayed with a lower memory consumption.

**Since:**

1.0

**Version:**

1.0
