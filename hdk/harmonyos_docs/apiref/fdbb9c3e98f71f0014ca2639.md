# IWiFiAp

#### Overview

**Related Modules:**

[WLAN](https://device.harmonyos.com/cn/docs/develop/apiref/wlan-0000001055198080)

**Description:**

Inherits the basic features of [IWiFiBaseFeature](https://device.harmonyos.com/cn/docs/develop/apiref/iwifibasefeature-0000001106437920) and additionally provides the features of obtaining information about all the STAs connected to an AP and setting the country/region code. 

**Since:**

1.0

**Version:**

1.0

#### [h2]getAsscociatedStas
    
    int32_t(* IWiFiAp::getAsscociatedStas) (const struct [IWiFiAp](https://device.harmonyos.com/cn/docs/develop/apiref/iwifiap-0000001153077799) *apFeature, struct [StaInfo](https://device.harmonyos.com/cn/docs/develop/apiref/stainfo-0000001106757720) *staInfo, uint32_t count, uint32_t *num)

**Description:**

Obtains information (MAC addresses only in the current version) about all the connected STAs. 

**Parameters:**

Name | Description  
---|---  
apFeature | Indicates the pointer to the AP feature, as described in [IWiFiAp](https://device.harmonyos.com/cn/docs/develop/apiref/iwifiap-0000001153077799).   
staInfo | Indicates the pointer to the information about the STAs connected to the AP.   
count | Indicates the number of elements in the staInfo structure array.   
num | Indicates the pointer to the number of connected STAs.  
  
**Returns:**

Returns **0** if the information is obtained; returns a negative value otherwise.
