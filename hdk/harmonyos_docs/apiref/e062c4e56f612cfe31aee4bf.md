#### [h2]GetName
    
    const char*(* Service::GetName) ([Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055675026) *service)

**Description:**

Obtains the name of a service. 

This function is called by Samgr during service registration and startup. You need to implement this function. 

**Parameters:**

Name | Description  
---|---  
service | Indicates the pointer to the service.   
  
**Returns:**

Returns a constant string no more than 16 bytes if the service name is obtained successfully; returns **NULL** if the service name fails to be obtained.

#### [h2]Initialize
    
    BOOL(* Service::Initialize) ([Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055675026) *service, [Identity](https://device.harmonyos.com/cn/docs/develop/apiref/identity-0000001054796537) identity)

**Description:**

Initializes the service. 

After Samgr assigns tasks to a service, the service calls the function in its own tasks. You need to implement this function. 

**Parameters:**

Name | Description  
---|---  
service | Indicates the pointer to the service.   
identity | Indicates the ID allocated by the system to the service. For details, see [Identity](https://device.harmonyos.com/cn/docs/develop/apiref/identity-0000001054796537).   
  
**Returns:**

Returns **TRUE** if the initialization is successful; returns **FALSE** otherwise. 

#### [h2]MessageHandle
    
    BOOL(* Service::MessageHandle) ([Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055675026) *service, [Request](https://device.harmonyos.com/cn/docs/develop/apiref/request-0000001055195068) *request)

**Description:**

Processes service messages. 

This function is used to process requests sent by the caller through [IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055675024). You need to implement this function. 

**Parameters:**

Name | Description  
---|---  
service | Indicates the pointer to the service.   
request | Indicates the pointer to the request data.   
  
**Returns:**

Returns **TRUE** if the message processing is successful; returns **FALSE** if the processing fails.
