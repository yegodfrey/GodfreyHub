# OHOS::AbstractAdapter

#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Defines the base class for adapters. You can derive **[AbstractAdapter](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1abstractadapter-0000001055518108)** based on actual requirements and use the **[GetView()](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985#ZH-CN_TOPIC_0000001128996985__gab155b2f4a6d8fd97755dcd1e6d3d8361)** and **[GetCount()](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985#ZH-CN_TOPIC_0000001128996985__ga67021b360d4097c475d5e24519b5276d)** functions to implement adapters of different data types. For details, see [TextAdapter](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1textadapter-0000001054799619). 

**Since:**

1.0

**Version:**

1.0
