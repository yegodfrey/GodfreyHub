# HotspotConfig

#### Overview

**Related Modules:**

[Wifiservice](https://device.harmonyos.com/cn/docs/develop/apiref/wifiservice-0000001055195054)

**Description:**

Represents the hotspot configuration. 

A hotspot configuration must contain the SSID (or BSSID), security type, and key (if the security type is open). 

**Since:**

1.0

**Version:**

1.0
