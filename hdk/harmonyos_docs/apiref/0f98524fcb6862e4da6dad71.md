# ability_connection.h  
  
#### Overview

**Related Modules:**

[AbilityKit](https://device.harmonyos.com/cn/docs/develop/apiref/abilitykit-0000001054598111)

**Description:**

Declares callbacks to be invoked when a remote [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) ability is connected or disconnected. 

You must override the callbacks provided in [IAbilityConnection](https://device.harmonyos.com/cn/docs/develop/apiref/iabilityconnection-0000001054479567) to implement your processing logic for [Service](https://device.harmonyos.com/cn/docs/develop/apiref/service-0000001055198168) connection and disconnection.

**Since:**

1.0

**Version:**

1.0
