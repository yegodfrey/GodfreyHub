# OHOS::TextAdapter  
  
#### Overview

**Related Modules:**

[UI_Components](https://device.harmonyos.com/cn/docs/develop/apiref/ui__components-0000001128996985)

**Description:**

Defines a text adapter, which implements [UILabel](https://device.harmonyos.com/cn/docs/develop/apiref/ohos_1_1uilabel-0000001055198150) instance construction and supports text data and continuous integer data. 

**Since:**

1.0

**Version:**

1.0
