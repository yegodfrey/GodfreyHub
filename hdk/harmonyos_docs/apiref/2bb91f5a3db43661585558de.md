# MipiCfg

#### Overview

**Related Modules:**

[DSI](https://device.harmonyos.com/cn/docs/develop/apiref/mipi-0000001081980698)

**Description:**

Defines MIPI DSI configuration parameters. 

Before image data transmission, you must set MIPI DSI configuration parameters to ensure that images can be correctly displayed on the screen.

1.0
