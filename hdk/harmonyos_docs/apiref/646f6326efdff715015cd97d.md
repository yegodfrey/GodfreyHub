#### [h2]flag
    
    int* option::flag

**Description:**

Determines the returned value of the **[getopt()](https://device.harmonyos.com/cn/docs/develop/apiref/utils-0000001055308029#ZH-CN_TOPIC_0000001055308029__ga5ffa4c677fc71cecd94f140ef9db624c)** function. If **flag** is **NULL** , the **[getopt()](https://device.harmonyos.com/cn/docs/develop/apiref/utils-0000001055308029#ZH-CN_TOPIC_0000001055308029__ga5ffa4c677fc71cecd94f140ef9db624c)** function returns the **val** value that matches the option. If **flag** is not **NULL** , assign the **val** value to the memory to which **flag** points, and set the returned value to **0**. 

#### [h2]has_arg
    
    int option::has_arg

**Description:**

**has_arg** has three values. **0** indicates that the argument is not followed by an argument value, **1** indicates that the argument must be followed by an argument value, and **2** indicates that the argument can be followed or not followed by an argument value.
