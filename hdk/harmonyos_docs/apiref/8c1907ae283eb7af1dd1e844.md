# ability_slice.h  
  
#### Overview

**Related Modules:**

[AbilityKit](https://device.harmonyos.com/cn/docs/develop/apiref/abilitykit-0000001054598111)

**Description:**

Declares ability slice-related functions, including ability slice lifecycle callbacks and functions for connecting to or disconnecting from ability slices. 

**AbilitySlice** instances, which are specific to [Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) Abilities (abilities using the Page template), are used to present different screens on an application's user interface. A [Feature](https://device.harmonyos.com/cn/docs/develop/apiref/feature-0000001055518086) Ability can have multiple ability slices.
