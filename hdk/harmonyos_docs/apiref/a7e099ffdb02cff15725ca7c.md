# IUnknownEntry

#### Overview

**Related Modules:**

[Samgr](https://device.harmonyos.com/cn/docs/develop/apiref/samgr-0000001054715047)

**Description:**

Defines the **[IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055675024)** implementation class. 

You need to inherit this structure when developing a subclass of the **[IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055675024)** implementation class. Each **[IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055675024)** interface must correspond to one or more **[IUnknown](https://device.harmonyos.com/cn/docs/develop/apiref/iunknown-0000001055675024)** implementation classes.
