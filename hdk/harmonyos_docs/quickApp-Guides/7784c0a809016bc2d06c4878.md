# 详情

点击详情可查看当前正在编译的Web快应用详细信息，其中分别包括了当前Web快应用的基本信息，本地设置，编译设置：

基本信息：Web快应用的基本信息，项目名称，本地目录，编译后代码大小；

本地设置：本地快应用基础库版本；

编译设置：配置保存文件时是否需要编译；

编译设置共支持如下7个功能的调整：  

#### 修改编译库版本

点击修改可修改当前编译库版本。  

#### 保存文件时跳过编译

Web快应用开发工具默认会在保存文件时自动编译并重新加载Web快应用，勾选此项会跳过这个步骤，每次需要手动点击工具栏的编译按钮才会进行编译操作。  

#### ES6 转 ES5

勾选此项，在编译时会自动把 ES6 语法使用 babel 转换为 ES5 语法，以获得更好的使用兼容性。取消勾选此项可能会导致真机快应用加载失败的问题。  

#### 样式自动补全

在预览、真机调试、上传时使用 autoprefixer (opens new window)对 样式类自动补全前缀，以对不同的浏览器内核的真机做样式兼容性适配 autoprefixer 的 browsers 参数为 \[ 'iOS \>= 8', 'Chrome \>= 37', \]，勾选此项会增大代码包体积。  

#### 压缩样式

在预览、真机调试、上传时使用 cssnano (opens new window)对 wxss 文件进行压缩。  

#### 压缩代码

在预览、真机调试、上传时使用 UglifyJS 或者 Terser 对 js 文件进行代码压缩。  

#### 混淆代码

在预览、真机调试、上传时使用 UglifyJS 或者 Terser 对 js 文件进行代码混淆。
