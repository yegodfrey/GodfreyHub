# menubar

#### 概述

Menubar放在快应用界面顶部，由框架统一提供，开发者不可以对其位置和样式进行自定义。但可选择深浅两种配色以适应页面设计风格。

#### 滚动操作

在内容区滚动时，Menubar固定在界面顶部。

#### 视觉规则

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250624094005.07580427693775605355006744343847:50001231000000:2800:09B146C6CC564B9E50ED4BADF67F29FADDB1B3EAF25C8BA61491E775D5CC952D.png)  
视觉规则是不能控制menubar样式的，如果要设置menubar的样式，需要设置[menuBarData](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621#section182971920817)的menuBarStyle属性（dark：图标深色样式，light：图标浅色样式）。  

#### Light模式

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250624094005.16652025540964275181214817413418:50001231000000:2800:91F84C6CEC8175E4CC216248A555C653C09E261D45ED8E9F7C6792FB836C2ED4.png "点击放大")

竖线：20×1vp

竖线颜色：20%不透明黑（#33000000）
