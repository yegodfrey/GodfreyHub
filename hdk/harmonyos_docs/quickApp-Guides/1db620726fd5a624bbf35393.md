# 新增互联网信息

在华为云核准（备案）系统中已核准（备案）的主体下新增快游戏信息。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面点击"新增互联网信息"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/rhyOX1A9SBel5BkRLrj3mw/zh-cn_image_0000001935643762.png?HW-CC-KV=V1&HW-CC-Date=20260909T171650Z&HW-CC-Expire=31536000000&HW-CC-Sign=9B431B9097544DBDE24D6688172B1861DF1B2F1C62C74CDE7F9A40BBB1FCBCF2)
2. 在"产品验证"页面填写快游戏信息，完成后点击"验证"。在弹出的窗口中点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/OWUNfOQcRTShoV0p2ZjhsQ/zh-cn_image_0000001962842365.png?HW-CC-KV=V1&HW-CC-Date=20260909T171650Z&HW-CC-Expire=31536000000&HW-CC-Sign=0260666ED7E62452D5599BE7E852D931A43186A4FB2D013DD294E69A0D2A7B17)

3. 在"主体信息"页面校对主办单位信息、负责人信息，若有误请及时修改，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/yacxVN7OQnahyOG_T_Yo-g/zh-cn_image_0000001962722673.png?HW-CC-KV=V1&HW-CC-Date=20260909T171650Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC69C691FF14F93ED0E69187327F75FFB919E2EAC5069C51CBC74E3638E6342E)

4. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e2/v3/B0oVr3lAQVa5tjm2z65R-w/zh-cn_image_0000001935803490.png?HW-CC-KV=V1&HW-CC-Date=20260909T171650Z&HW-CC-Expire=31536000000&HW-CC-Sign=376A5E5C7EBB62FF13FA392B697BFB3A1781A76C21B1C7F51F2B2A6AA9AB3581)

5. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/Yl8YFs1RSPurq7xpbQudaQ/zh-cn_image_0000001935644118.png?HW-CC-KV=V1&HW-CC-Date=20260909T171650Z&HW-CC-Expire=31536000000&HW-CC-Sign=396A1AA06E74BB6F30AE24545B160D0E4A8E2FC07041476A8EEFEC4984449D4B)

6. 在"真实性核验"页面由互联网信息负责人进行人脸视频认证，完成后点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/NVGLpSCkQ9uoxOzN-q7Avg/zh-cn_image_0000001962842641.png?HW-CC-KV=V1&HW-CC-Date=20260909T171650Z&HW-CC-Expire=31536000000&HW-CC-Sign=BE808309816E2FC3C970CA235DE35E05BC6B430727CCC54BD9DCD1607B9A7395)

7. 在"预览资料"页面核对填写的信息，完成后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ca/v3/4w5V0ANBT1m8CkFVWYYWVw/zh-cn_image_0000002012046385.png?HW-CC-KV=V1&HW-CC-Date=20260909T171650Z&HW-CC-Expire=31536000000&HW-CC-Sign=0BF7C470236558CA023F5AF7C135BC797C2D3C12F9F4BFEFCEC4124050ECAFBE)

8. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。
9. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
