# 标签组件

#### 简介

标签（tag）组件通常用于商品分类、重点内容显示等场景。标签一般具有如下特点：

* 可以配置标签内容
* 可以配置标签颜色、实心/空心、尺寸、圆角/标记等样式
* 可以配置禁用状态
* 可以自定义触发标签点击事件

#### 开发指引

#### 自定义子组件

1. 定义布局样式。 标签组件由一个text组件构成。

   ```
   <template>
     <text class="tag {{basicStyle}} {{invertedColor}} {{tagSize}} {{markStyle}} {{radiuSize}} {{opacityStyle}}" style="{{customstyle}}" @click="onClick">{{ text }}</text>
   </template>
   ```

2. 规划属性和支持的事件。 支持的属性：

   |属性|类型|默认值|描述|
   |:----------|:------|:------|:--------------------------------------------------------------------------------|
   |text|String|-|标签内容。|
   |type|String|default|标签颜色类型。 * default：灰色 * primary：蓝色 * success：绿色 * warning：黄色 * error：红色 * royal：紫色|
   |inverted|Boolean|false|是否为空心。 * true：空心 * false：实心|
   |size|String|normal|标签尺寸。 * normal：正常 * small：偏小|
   |circle|Boolean|false|是否为圆角样式。|
   |mark|Boolean|false|是否为标记样式。|
   |disabled|Boolean|false|是否为禁用状态。|
   |customstyle|String|-|自定义标签样式。|

   支持的事件：  

   |事件名称|参数|描述|
   |:-----|:-|:----------|
   |change|-|点击标签时触发的事件。|

#### 父子组件通信

1. 子组件的props中定义相关属性值，父组件引用时传入属性值，子组件通过 this.xxx 获取值并进行处理。

   ```
   props: {      
     text: {
       // 标签内容
       type: String,
       default: ""
     },
     type: {
       // 标签颜色类型default、primary、success、warning、error、royal
       type: String,
       default: "default"
     },
     inverted: {
       // 是否为空心
       type: [Boolean, String],
       default: false
     },      
     size: {
       // 标签尺寸normal、small
       type: String,
       default: "normal"
     },
     circle: {
       // 是否为圆角样式
       type: [Boolean, String],
       default: false
     },
     mark: {
       // 是否为标记样式
       type: [Boolean, String],
       default: false
     },
     disabled: {
       // 是否为禁用状态
       type: [Boolean, String],
       default: false
     },
     customstyle: {
       type: String,
       default: ''
     }
   },
   ```

2. 父组件定义标签点击事件并绑定。

   ```
   <div class="tag-view">
     <tag text="标签" type="{{type}}" inverted="true" size="normal" circle="true" disabled="false" @change="setType"></tag>
   </div>
   <div class="tag-view">
     <tag text="标签"  type="primary" inverted="{{inverted}}" size="small" mark="true" disabled="false" @change="setInverted"></tag>
   </div>
   ```

   ```
   setType() {
     let types = ['default', 'primary', 'success', 'warning', 'error'];
     let index = types.indexOf(this.type);
     types.splice(index, 1);
     let randomIndex = Math.floor(Math.random() * 4);
     this.type = types[randomIndex];
     console.log("message", this.type);
   },
   setInverted() {
     this.inverted = !this.inverted;
   },
   ```

3. 在点击标签时，子组件通过this.$emit方法触发父组件的change事件。

   ```
   onClick() {
     if (this.isTrue(this.disabled)) {
       return
     }
     this.$emit("change");
   },
   ```

#### 计算数据和样式

使用计算属性computed方法，通过props属性动态计算数据和样式，返回给组件使用。

```
computed: {
  basicStyle() {
    const {
      type
    } = this
    return type
  },
  invertedColor() {
    const {
      isTrue,
      type,
      inverted
    } = this
    return isTrue(inverted) ? type + '-inverted' : '';
  },
  tagSize() {
    const {
      size
    } = this
    return size === 'small' ? 'tag-small' : ''
  },
  radiuSize() {
    const {
      isTrue,
      circle
    } = this
    return isTrue(circle) ? 'radiuSize' : '';
  },
  markStyle() {
    const {
      isTrue,
      mark
    } = this
    return isTrue(mark) ? 'markStyle' : '';
  },
  opacityStyle() {
    const {
      isTrue,
      disabled
    } = this
    return isTrue(disabled) ? 'opacityStyle' : '';
  }
},
```
