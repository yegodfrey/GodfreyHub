# 下架快应用

如果您当前在架的应用版本存在问题需要下架，或是不想再上架当前应用，您可以申请从华为应用市场下架该应用。应用下架后，用户将无法从华为应用市场搜索到该应用，此时应用会进入草稿状态。如果您想重新上架应用，可以直接在此草稿状态的应用版本基础上编辑、修改，然后重新发布。

* 只有在架应用版本支持下架操作，其他状态下的应用版本不支持。
* 下架应用仍会占据包名，只有删除应用才会释放包名。  

#### 提交下架申请

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的应用"。
2. 点击待下架的版本。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181439.68558387785107162749693279393471:50001231000000:2800:A0583FA5FCA68F1C72D1A500F3701A21E9D4FCCA70679B2B627F3D6E7A3BD009.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3. 点击右上角的"申请下架"。
4. 在弹出对话框中填写下架原因、备注（可选）后，点击"确认"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181439.39138304646903874689923894732228:50001231000000:2800:AA4BCF84D6D9B435CC0DB0C0A35A550D82627C2B4E334497968423170EA60055.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

6. 在下架申请审核通过前，还可以[撤销下架申请](#section1444214208415)。  

#### 撤销下架申请

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的应用"。
2. 点击待撤销下架的版本。
3. 点击右上角的"撤销下架申请"。
4. 在弹出对话框中，点击"确认"。
