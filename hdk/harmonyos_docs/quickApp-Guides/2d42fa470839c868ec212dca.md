# 第三方组件库

## 使用npm的场景

引入第三方组件库，需要使用 npm，npm 是包管理工具，能解决代码部署上的很多问题，常见的使用场景有以下几种：

* 允许用户从 npm 服务器下载别人编写的第三方包到本地使用
* 允许用户从 npm 服务器下载并安装别人编写的命令行程序到本地使用
* 允许用户将自己编写的包或命令行程序上传到 npm 服务器供别人使用

## 引入npm包

开发者可引入 npm 包中提供的文件，引入后即可正常使用包中的代码。

### 准备工作

引入 npm 包前，需要先在本地安装 npm 包。安装命令如下：

```screen
npm install <package>
```

其中<package>为 npm 包名。以 npm 包 quick-app-kit-demo 为例，命令如下：

```screen
npm install quick-app-kit-demo
```

### 引入文件

本地安装 npm 包后，就可以引入 npm 包提供的文件了。根据引入文件类型的不同，引入的方法存在差异。常见文件的类型及引入方法如下：

* 组件文件 使用 引入npm包中的自定义组件，注意设置为组件文件的相对路径。以 npm 包为 quick-app-kit-demo 为例：

  ```screen
  <import name="comp" src="<relative path to node_modules>/node_modules/quick-app-kit-demo/src/component/index.ux"></import>
  ```

* 样式文件 使用合并外部文件的方式，引入 npm 包中的样式文件，注意设置为样式文件的相对路径。以 npm 包 quick-app-kit-demo 为例：

  ```screen
  <style>
    @import '<relative path to node_modules>/node_modules/quick-app-kit-demo/src/common/common.css';
  </style>
  ```

* js文件 使用 import 引入 npm 包中的 js 文件，注意设置为 js 文件的相对路径。以 npm 包 quick-app-kit-demo 为例：

  ```screen
  import getStr from '<relative path to node_modules>/node_modules/quick-app-kit-demo/src/common/util'
  ```
