# 设计总则

为构建华为快应用生态体系内，清晰一致、简单易用的用户体验，我们拟定了快应用设计建议与指南，帮助快应用合作伙伴快速了解设计核心关注点，这将帮助应用减少用户舆情且提升用户体验的一致性，实现用户与快应用服务方的共赢。请在设计过程中重点关注以下影响体验的3个核心要素：

* 清晰一致 统一的页面体验和有延续性的界面元素，有利于降低用户学习成本，达成使用目标。设计者应注意多场景一致性，如同一控件在对应的使用场景下，其交互、视觉、动效要保持一致。及时提供必要的操作反馈，确保使用体验的可知可控。

* 简洁流畅 避免复杂的界面导航和切换，通过清晰简单、逐层深入的页面架构设计，帮助用户快速使用目标功能。向用户提供服务时，首先展示当前场景重要的内容，避免加载过量或不相关的内容（如：全量功能、广告等），让用户不用过多思考理解就可以立即进行操作。

* 高效易用 尽可能简化账号的注册流程，降低功能的使用门槛；建议使用华为账号服务，可有效减少用户需要输入的信息量。

另外需特别注意，手机与平板端侧快应用的所有页面，官方会在其右上角放置Menubar，开发者在设计界面时请预留出该区域空间，若需要在此区域附近放置可交互元素，如搜索栏，要特别注意交互事件是否会冲突，操作是否容易被使用。
