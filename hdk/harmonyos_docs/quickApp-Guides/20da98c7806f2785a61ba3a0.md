# 接入推送服务

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111519.02171581773437175665092360264710:50001231000000:2800:27298DFAEE37E7A996AA911481A282E6B1DBC3969420AFE176223D9FD0E781AC.png)

服务升级期间，快应用推送能力整体下线，即快应用的推送/通知（即通知栏消息）均无法触达用户，请您暂停使用，给您造成的不便敬请谅解。

#### 简介

华为推送（PUSH）是为开发者提供的消息推送平台，建立了从云端到手机端的消息推送通道，让应用可以将最新信息及时通知到用户，从而构筑良好的用户关系，提升用户的感知和活跃度。

PUSH功能在EMUI8.0及以上版本的手机上支持。

#### 准入条件

接入华为推送服务前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 在AppGallery Connect上已[开通推送服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-push-kit-0000001079643916)。
* 华为推送服务是华为扩展接口，而非厂商联盟规范，请[安装华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)进行接入。  

#### 接入指引

1. 调用 [push.getProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-push-0000001074632507#section108186664310) 接口判断当前设备是否支持华为PUSH服务。

   调用接口返回 huawei 表示支持，否则表示不支持。后续功能开发和接口调用必须在设备支持PUSH服务的前提进行。
2. 调用 [push.subscribe](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-push-0000001074632507#section24356519478) 接口获取regId。

   regId也被称为token或push token，是用于发送PUSH消息的标识。其长度不定，格式有类似如下样例两种：
   * 0862767037246841300005665000CN01
   * ANDmbp0JwPTftSc4tY90C2aW6xTGyKtTIY4idTf5GekYFfOKYmKTeqYlyKYUS0CQbf2xmUdkKWaYU6AoO1Ju6bL5lQgU7pmzQD_6cdIEABhHTLPYhMcsoF64B0tNAE_eBg

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111519.37441663035471862478495302363525:50001231000000:2800:3D376C9556F560495EEABCE921462163DEC372386AFB1D1124F8C955FC3C8FF8.png)  
   regId和快应用运行环境相关，在快应用加载器中获取的regId只能用于在加载器中运行的快应用推送消息，不能用于上架应用市场的快应用，因为上架后的快应用的运行环境是快应用中心。
3. 将上一步获取的regId可通过 [数据请求](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-fetch-0000001074421449) 接口上报到快应用自己的业务服务器，用于后续服务器向快应用发送PUSH消息。

   regId一般情况下不会发生变化，不需要每次获取后都上报到服务器。

   【推荐做法】使用快应用 [数据存储](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-storage-0000001075389688) 接口本地存储regId，每次获取regId后先与本地存储的进行对比，相同则不上报业务服务器，不同则需要上报。

   处理流程如下图所示。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111519.13383389851184230555190737857066:50001231000000:2800:0EA9511AB1DB5F62820523B97E465A63607493DB9275038866C406EC7FA116C6.png)

   获取regId与本地存储内容比对的代码逻辑如下：

   ```
   checkToken() {
       var subscribeToken=this.$app.$def.dataApp.pushtoken;
       console.log("checkToken subscribeToken= "+subscribeToken);
       var storage = require("@system.storage");
       var that=this;
       storage.get({
           key: 'token',
           success: function (data) {
               console.log("checkToken handling success data= "+data);
               if (subscribeToken != data) {
                  //上报到自己的业务服务器
                    that.uploadToken(subscribeToken);
                   that.saveToken(subscribeToken);
               }
           },
           fail: function (data, code) {
               console.log("handling fail, code = " + code);
           }
       })
   },
   ```

   将regId保存到本地的代码逻辑如下：

   ```
   saveToken(subscribeToken){
     console.log("saveToken");
     var storage = require("@system.storage");
     storage.set({
       key: 'token',
       value: subscribeToken,
          success: function (data) {
           console.log("saveToken handling success");
       },
       fail: function (data, code) {
           console.log("saveToken handling fail, code = " + code);
       }
     })
   },
   ```

4. 发送PUSH消息，具体操作请参见"[发送PUSH消息](#section151011188494)"。
5. 处理PUSH消息。 推送消息为通知栏消息，当用户点击通知栏消息时，会启动快应用相应界面，将携带的参数赋值给页面对应的参数。

#### 发送PUSH消息

开发者可以通过两种方式发送PUSH消息：

* 在AppGallery Connect发送：适用选取部分目标用户发送，支持推送到现网的快应用和加载器上运行的快应用。
* 通过服务端接口发送：适用面向大批量用户发送，支持推送到现网的快应用和加载器上运行的快应用。

满足如下前提条件的快应用才可以接收到PUSH消息：  

|消息类型|前提条件|
|:----|:----------------------------------------------------------------------------------------------------------------------------------------------------|
|通知栏消息|【快应用中心低于3.2.1版本】 快应用必须有使用记录，并满足如下条件之一： * 在桌面有快捷方式的快应用 * 加入"我的快应用"的快应用 * 快应用处于运行状态 【快应用中心从3.2.1版本开始】 快应用必须有使用记录，并满足如下条件之一： * 在桌面有快捷方式的快应用 * 加入"收藏"的快应用|

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111519.28056975322956569062670244219931:50001231000000:2800:D083810F4EE4075A9131ADA847AEDC56C8C88DCDD6BBFCEA9CCC709594B2670B.png)  
* 如果使用华为快应用加载器进行调试，必须确保加载器进程处于运行状态。发送条件和上述快应用中心要求相同，添加到桌面，加入收藏可以通过加载器的统一菜单实现。
* 如果手机安装了手机管家，请务必在"自启动"选项中，将快应用中心的开关打开。

#### 通过服务端接口发送

通过服务端接口发送PUSH消息涉及两个接口：获取accessToken接口和发送PUSH消息接口。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111519.88269145316244817229062027058024:50001231000000:2800:9E50184F0A209AFF8715C60066555D97EAFB4E6F45165A819D4C560D7DB6B39A.png)  
* 通过服务端接口发送消息，每天发送的次数没有限制，每次最多同时向1000个设备发送消息。

* PUSH消息不得推送与快应用自身业务无关内容以及诱导性广告、低俗/诈骗/涉黄/涉暴/涉政等信息，违者将关停处罚，详细请参见"[快应用PUSH消息违规处罚规定](#section04020287254)"。

data结构体说明  

|参数|类型|父节点|是否必填|描述|

|pushtype|Integer|data|是|* 0：通知栏消息 * 1：透传消息|
|pushbody|JSON Object|data|是|-|
|title|String|pushbody|否|通知栏消息标题，pushtype为0时有效。|
|description|String|pushbody|否|通知栏消息内容，pushtype为0时有效。|

|data|String|pushbody|否|透传消息的内容，pushtype为1时有效。|

|参数|取值类型|可选/必选|描述|

PUSH消息体示例代码如下：

```
var mData = {
    "pushtype": 0, //0表示通知栏消息
    "pushbody": {
        "title": "PUSH消息的标题",
        "description": "PUSH消息的详细内容",
        "page": "/", //点击通知栏消息需要跳转的快应用界面的path，pushtype为0时有效。”/”表示跳转到应用首页
        "params": {
            "key1": "test1",
            "key2": "test2"
        },
    }
};
var formatJsonString = JSON.stringify(mData);
var messbody = {
    "validate_only": false,
    "message": {
        "data": formatJsonString, //需要注意data类型是JsonString类型，非json对象
        "android": {
            "fast_app_target": 1, // 1表示向运行在加载器上的快应用发送PUSH消息，给上架应用市场的快应用发送PUSH消息时，此值要设置为2。
            "collapse_key": -1,
            "delivery_priority": "HIGH",
            "ttl": "1448s",
            "bi_tag": "Trump",
         },
         "token": ['pushtoken1','pushtoken2'], //消息推送的目标用户
    }
};
```

#### 快应用PUSH消息违规处罚规定

#### 目的与范围

为保证快应用开发者合理利用快应用PUSH能力，保证推送内容健康合规，提高用户满意度，特制定本违规处罚规定。  

#### 内容违规定义与处罚方式

（1）违规级别定义  

|违规级别|内容违规定义|
|:---|:--------------------------------------------------|
|一级|1. 涉黄、涉暴等违法信息或政治有害信息。 2. 病毒链接等侵犯用户权益的内容。|
|二级|1. 与快应用自身服务无关的下载链接、营销内容、诱导性信息。 2. 反复发送高度相似文案过度打扰用户。|

（2）违规处罚规则  

|违规级别|违规次数|处罚方式|
|:---|:----|:----------------|
|一级|1次及以上|永久关停违规快应用PUSH业务。|
|二级|1次|关停违规快应用PUSH业务30天。|
|二级|2次|关停违规快应用PUSH业务90天。|
|二级|3次及以上|永久关停违规快应用PUSH业务。|

#### 违规处罚执行

1. 华为平台通过运营监控及用户舆情反馈进行持续监督，若发现快应用PUSH内容存在违规情况，将按相应规则执行处罚，并以邮件方式通知开发者（通知发送邮箱为developer@huawei.com，接收邮箱为开发者在华为开发者联盟平台注册时填写的邮箱）。
2. 在开发者承诺完成整改并不再违规的前提下，处罚期满，将为快应用恢复PUSH能力。  

#### 生效及解释

本规定自2020年7月30日起生效，最终解释权归华为快应用平台所有，相关规则若有调整，将同步在华为开发者联盟官网更新，请开发者持续关注华为开发者联盟官网。

<script>

            let provider = push.getProvider();
            console.log("checkPush provider= " + provider);
            if (provider === 'huawei') {
                this.pushsubscribe();
            }

        pushsubscribe() {
            console.log("pushsubscribe start");
            var that = this;
            push.subscribe({
                success: function (data) {
                    console.log("push.subscribe succeeded, result data=" + JSON.stringify(data));
                    that.dataApp.pushtoken = data.regId;
                    console.log("app oncreate this.dataApp.pushtoken=" + that.dataApp.pushtoken);
                    that.checkToken();

                },
                fail: function (data, code) {
                    console.log("push.subscribe failed, result data=" + JSON.stringify(data) + ", code=" + code);
                },
                complete: function () {
                    console.log("push.subscribe completed");
                }
            })
        },

        checkToken() {
            var subscribeToken = this.dataApp.pushtoken;
            console.log("checkToken subscribeToken= " + subscribeToken);
            var storage = require("@system.storage");
            var that = this;
            storage.get({
                key: 'token',
                success: function (data) {
                    console.log("checkToken storage data= " + data);
                    if (subscribeToken !== data) {
                        //upload it to your own service server
                        that.uploadToken(subscribeToken);
                        that.saveToken(subscribeToken);
                    } else {
                        console.log("checkToken regid is  the same as local storage");
                    }
                },
                fail: function (data, code) {
                    console.log("checkToken handling fail, code = " + code);
                }
            })
        },

        saveToken(subscribeToken) {
            console.log("saveToken");
            var storage = require("@system.storage");
            storage.set({
                key: 'token',
                value: subscribeToken,
                success: function (data) {
                    console.log("saveToken handling success");
                },
                fail: function (data, code) {
                    console.log("saveToken handling fail, code = " + code);
                }
            })
        },

                xx: subscribeToken
            };

                data: body,
                success: function (data) {
                    console.log("uploadToken code: " + data.code);
                    console.log("uploadToken data: " + data.data);
                },
                fail: function (data, code) {
                    console.log("handling fail, code = " + code);
                }
            })
        },

        }

    }
