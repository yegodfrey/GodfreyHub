# 收藏按钮组件

## 简介

收藏按钮（fav）组件主要实现收藏功能，一般具有如下特点：

* 可点击切换选中或不选中的状态
* 可自定义按钮的图标、文本内容、文本颜色、背景色、是否带圆角等样式

基本布局代码如下：

```screen
<text class="section">基本用法</text>
<div class="basic-content">
    <fav  checked="{{checkList[0]}}" @handleclick="handleClick"></fav>
    <fav  checked="{{checkList[1]}}" star="false"  @handleclick="handleClick"></fav>

</div>
```

## 开发指引

### 自定义子组件

1. 定义布局样式。 收藏按钮组件可以分为两大类：一类显示图标+文本，一类只显示文本。

   * div组件横向布局嵌套"五角星"图标+文本。
   * 通过star和checked属性来控制是否显示"五角星"图标。 注意
     >
     > "已收藏"状态时，只会显示文本。
   * 收藏按钮组件宽度固定为150px。

   ```screen
   <template>
     <div style="width:150px; margin-right:20px;align-items:center; border-color: #ffffff;
         justify-content: center; padding-bottom:10px; padding-top:10px; background-color: {{checked ? bgColorChecked : bgColor}};
          border-radius:{{showcircle ? 20 : 3}}px;"  onclick="handle()">
       <image class="star" if="{{!checked && (star === true || star ==='true')}}" src="{{this.imgsrc}}"></image>
       <text class="text-context" style="color:{{ checked ? fgColorChecked : fgColor}};text-align:center;">
           {{checked ? contentText.contentFav : contentText.contentDefault}}
       </text>
     </div>
   </template>
   ```

2. 规划属性和支持的事件。

   支持的属性：

   |**属性**|**类型**|**默认值**|**描述**|
   |:-------------|:------|:------------------------------------------|:---------|
   |bgColor|String|#eeeeee|未收藏时的背景色。|
   |bgColorChecked|String|#007aff|已收藏时的背景色。|
   |fgColor|String|#666666|未收藏时的文本颜色。|
   |fgColorChecked|String|#FFFFFF|已收藏时的文本颜色。|
   |imgsrc|String|../Common/xxx.png|图标的路径。|
   |contentText|Object|{ contentDefault: "收藏", contentFav: "已收藏" }|按钮文本。|
   |star|Boolean|true|按钮是否带图标。|
   |showcircle|Boolean|false|按钮是否带圆角。|
   |checked|Boolean|false|按钮是否为已收藏。|

   支持的事件：

   |**事件名称**|参数|描述|
   |:----------|:-------------------|:---------|
   |handleclick|{checked:true|false}|点击收藏按钮的事件。|

### 父子组件通信

1. 子组件的props中定义相关属性值，父组件引用时传入属性值，子组件通过 this.xxx 获取值并进行处理。
2. 父组件中定义收藏按钮点击事件handleclick，实现并绑定事件。

   ```screen
   <fav  checked="{{checkList[0]}}" @handleclick="handleClick"></fav>
   ```

   ```screen
   handleClick(e) {
       console.log(JSON.stringify(e));
       let checked=e.detail.checked;
       let msg;
           if(checked){
           msg = "收藏成功"
           }else{
           msg = "取消收藏"  
           }
       prompt.showToast({
           message:  msg,
           duration: 2000,
           gravity: 'center'
       })
   },
   ```

3. 点击收藏按钮时，更新checked值，子组件通过this.$emit方法携带事件及参数通知父组件处理收藏或者取消收藏的逻辑。

   ```screen
   handle() {
       console.log("handleclick,success");
       this.checked = !this.checked;
       this.$emit('handleclick', { checked: this.checked });
   },
   ```

## 示例代码

收藏按钮fav.ux代码：

```screen
<template>
  <div style="width:150px; margin-right:20px;align-items:center; border-color: #ffffff;
      justify-content: center; padding-bottom:10px; padding-top:10px; background-color: {{checked ? bgColorChecked : bgColor}};
       border-radius:{{showcircle ? 20 : 3}}px;"  onclick="handle()">
    <image class="star" if="{{!checked && (star === true || star ==='true')}}" src="{{this.imgsrc}}"></image>
    <text class="text-context" style="color:{{ checked ? fgColorChecked : fgColor}};text-align:center;">
        {{checked ? contentText.contentFav : contentText.contentDefault}}
    </text>
  </div>
</template>
<script>
	/**
	 * fav 收藏按钮
	 * @description 收藏组件
	 * @tutorial https://ext.dcloud.net.cn/plugin?id=864
     * @property {String} imgsrc  图标的路径
     * @property {String} bgColor 未收藏时的背景色
	 * @property {String} bgColorChecked 已收藏时的背景色
	 * @property {String} fgColor 未收藏时的文本颜色
	 * @property {String} fgColorChecked 已收藏时的文本颜色
     * @property {Boolean} star = [true|false] 按钮是否带图标
     * @property {Boolean} showcircle = [true|false] 按钮是否为圆角
	 * @property {Object} contentText = [true|false] 收藏按钮文本
     * @property {Boolean} checked = [true|false] 是否为已收藏
	 * @event {Function} onClick 触发事件
	 * @example <fav ></fav>
	 */

    module.exports = {
        props: {
            showcircle: {
                type: [Boolean, String],
                default: false
            },

            bgColor: {
                type: String,
                default: "#eeeeee"
            },

            bgColorChecked: {
                type: String,
                default: "#007aff"
            },

            star: {
                type: [Boolean, String],
                default: true
            },

            imgsrc: {
                type: String,
                default: '../Common/star_fill.png'
            },

            fgColor: {
                type: String,
                default: "#666666"
            },

            fgColorChecked: {
                type: String,
                default: "#FFFFFF"
            },

            checked: {
                type: [Boolean, String],
                default: false
            },

            contentText: {
                type: Object,
                default() {
                    return {
                        contentDefault: "收藏",
                        contentFav: "已收藏"
                    };
                }
            }
        },
        data: {
            direction: ''
        },
        onInit() {
            this.$page.setTitleBar({ text: '收藏按钮' })
        },
        handle() {
            console.log("handleclick,success");
            this.checked = !this.checked;
            this.$emit('handleclick', { checked: this.checked });
        },
    }
</script>
```
