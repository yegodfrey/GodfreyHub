# 认领核准（备案）

在华为云核准（备案）系统中认领华为原核准（备案）系统核准（备案）的主体信息和快应用信息。操作步骤如下：

1. 进入[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，登录华为云核准（备案）系统，填写主办单位信息、互联网信息，完成后点击"验证核准（备案）类型"。在弹出的窗口中点击"下一步"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175841.49330679033328742667736761413377:50001231000000:2800:AD2CC4570A41E229B0DD31C04C4DE84D945CB7A81694114A7237F4D1302B5B3B.png "点击放大")
2. 在"认领核准（备案）"页面核对信息，完成后点击"上传资料并认领核准（备案）"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175841.36594927588954762831201461443341:50001231000000:2800:C2DD9C8C6F9C885D95E8DF642C3F5E6136EF461D118B54F6F8E286AB93D772A4.png "点击放大")

3. 根据提示上传附件信息，完成后点击"提交认领"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175841.79727785853556220333983386470896:50001231000000:2800:C5C4A7FF95572D0BD812B09BD97CF162C51A273ED5C6E2D1C219581E60C663F5.png "点击放大")

4. 华为工作员将在1\~2个工作日内完成审核，审核结果将以短信或邮件形式通知，在此期间请耐心等待。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175841.25943298721074129892445137078661:50001231000000:2800:5FE9D2DC4121A7988147CFFD026E342EEAB75FD08CAC9D2EC70884E525828081.png "点击放大")
