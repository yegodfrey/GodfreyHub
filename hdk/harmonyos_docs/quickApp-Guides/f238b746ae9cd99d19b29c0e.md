# 数字输入框组件

#### 简介

数字输入框组件是带加减按钮的输入框，主要用于设置限购商品、加购商品数量等场景。数字输入框一般具有如下特点：

* 数字输入框组件默认数值最大值为100，最小值为0，每次点击增加或减少1
* 可根据需要定制最小值和最大值，设置每次减少或增加的数值，是否禁用，获取输入值等

数字输入框（number_box）组件结构可按照布局分为三个部分。左边是减号按钮，中间是数字输入框，右边是加号按钮。布局结构如下图：

布局代码如下：

```
<text>设置最小值2，最大值10，步长为0.1</text>
<number_box  value="{{value}}" min="2" max="10"  step="0.1" @change="handlechange" @focus="handlefocus" @blur="handleblur"></number_box> 
```

#### 开发指引

#### 自定义子组件

1. 定义布局样式。 数字输入框整体外观都是通用的，但是内部具体的样式有区别，在设计的时候，不能把内部样式固定，否则一旦数字输入框的UI有变化，会导致子组件也要修改，违背了对外开源的初衷。

   所以，在子组件number_box中，开放多种样式属性，方便开发者自定义样式。

   ```
   <template>
     <div class="uni-numbox ">
       <div class="{{this.extremum1 ? 'uni-numbox__minus1' : 'uni-numbox__minus'}}" onclick="_calcValue('minus')">
         <text class="{{this.extremum1?'uni-numbox--text1':'uni-numbox--text'}}" disabled="{{disabled}}">-</text>
       </div>

       <input value="{{value}}" type="number" class="uni-numbox__value" onchange="updateValue" enterkeytype="done"  
         onenterkeyclick="enterkeyclick" disabled="{{disabled}}" onfocus="handlefocus" onblur="handleblur"></input>

       <div class="{{this.extremum ? 'uni-numbox__plus1' : 'uni-numbox__plus'}}" onclick="_calcValue('plus')">
         <text class="{{this.extremum ?'uni-numbox--text1':'uni-numbox--text'}}" disabled="{{disabled}}">+</text>
       </div>
     </div>
   </template>
   ```

2. 规划属性和支持的事件。 支持的属性：

   |属性|类型|默认值|描述|
   |:-------|:------|:----|:----------------|
   |value|Number|0|输入框当前值。|
   |min|Number|0|最小值。|
   |max|Number|100|最大值。|
   |step|Number|1|每次点击减号或者加号后改变的数值。|
   |disabled|Boolean|false|是否为禁用状态。|

   支持的事件：  

   |事件名称|参数|描述|
   |:-----|:----|:------------|
   |change|value|输入框值改变时触发的事件。|
   |focus|e|输入框聚焦时触发的事件。|
   |blur|e|输入框失焦时触发的事件。|

#### 父子组件通信

1. 父组件给子组件传递数据。
   1. 子组件的props中定义参数。

      ```
      props: {
        value: {
          type: [Number, String],
          default: 1
        },
        min: {
          type: Number,
          default: 0
        },
        max: {
          type: Number,
          default: 100
        },
        step: {
          type: Number,
          default: 1
        },
        disabled: {
          type: Boolean,
          default: false
        }
      },
      ```

   2. 父组件给子组件传值，如果是布尔值，需要在data中定义，而不能直接在组件中定义。

      ```
      <text>禁用状态</text>
      <number_box disabled="{{disabled}}"></number_box>
      ```

      ```
      data: {
        componentData: {},
        value: 8,
        disabled:true    
      },
      ```

2. 父组件给子组件传递方法。
   1. 点击父组件的任意区域时，都会触发如下onclick方法，使用this.$broadcast向子组件传递消息。

      ```
      <div class="container"  onclick="onclick">
      </div>
      ```

      ```
      onclick(e){
        this.$broadcast('checkValue')  
      }
      ```

   2. 子组件使用this.$on()方法监听输入的数字并校验。

      ```
      this.$on('checkValue', this.checkValue)
      ```

      ```
      checkValue(e) {
        console.log("checkValue")
        console.log(JSON.stringify(e))
        if (this.disabled) {
          return
        }
        if (Number(this.value) >= Number(this.max)) {
          this.value = this.max;
        } else if (Number(this.value) <= Number(this.min)) {
          this.value = this.min;
        } else {
          this.value = this.value
        }
      }
      ```

3. 子组件给父组件传递数据和方法。
   1. 父组件中注册特定方法的监听，等待子组件通知触发。

      ```
      <number_box id="number1" value="{{value}}" @change="handlechange" @focus="handlefocus" @blur="handleblur" ></number_box>
      ```

      ```
      handlechange(e) {
        this.value=e.detail
      },
      handlefocus() {
      },
      handleblur() {
      },
      ```

   2. 子组件通过this.$emit方法携带事件及参数通知父组件。

      ```
      updateValue(e) {
        if (Number(e.value) >= Number(this.max)) {
          prompt.showToast({
            message: '请不要超过最大数' + this.max,
          })
          this.value = e.value
          this.extremum = true;
          this.extremum1 = false;
        } else if (Number(e.value) <= Number(this.min)) {
          prompt.showToast({
            message: '请不要小于最小数' + this.min,
          })
          this.value = e.value
          this.extremum1 = true;
          this.extremum = false;
        } else {
          this.value = e.value
          this.extremum = false;
          this.extremum1 = false;
        }
        this.$emit('change', this.value)
      },
      handlefocus(e) {
        this.$emit('focus', e)
      },
      handleblur(e) {
        this.$emit('blur', e)
      }, 
      ```

        this.extremum = false;

        this.extremum = false;
        this.extremum1 = false;

    _calcValue(type) {
      console.log(this.disabled);
      if (this.disabled) {
        return
      }
      const scale = this.getDecimalScale();
      let calcvalue = this.value * scale;
      let calcstep = this.step * scale;
      if (type === "minus") {
        console.log("minus");
        console.log(this.value);
        this.value = (calcvalue - calcstep) / scale.toFixed(String(scale).length - 1);
        if (Number(this.value) <= Number(this.min)) {
          this.value = this.min
        }
        if (Number(this.value) >= Number(this.max)) {
          this.value = this.max
        }

          this.value = this.max
        }
        if (Number(this.value) < Number(this.min)) {
          this.value = this.min
        }

      this.$emit('change', this.value)

    getDecimalScale() {

      }
      return scale;
