# 认领核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/IIdFQLvWRg--J08viAmjXQ/zh-cn_image_0000001939010557.png?HW-CC-KV=V1&HW-CC-Date=20261008T183248Z&HW-CC-Expire=31536000000&HW-CC-Sign=0AC5441824EC1183DC911EE7692B42BB9DCA0DD4304CA48F9108581B7DEA8A29)

2. 填写待认领的主办单位和快游戏信息后，提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/cX6R8bYLSeGfVF6S_LCGtg/zh-cn_image_0000001939041085.png?HW-CC-KV=V1&HW-CC-Date=20261008T183248Z&HW-CC-Expire=31536000000&HW-CC-Sign=37162A153AE24F0492C0E4BD1DEC006D980ABD048F7CB85D0CB9A1F13958EBA7)

3. 华为工作人员将在1~2个工作日内完成审核，审核结果将以短信或邮件形式通知，在此期间请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/nEw5tveSTSSfNiv2w1KwKA/zh-cn_image_0000001900091012.png?HW-CC-KV=V1&HW-CC-Date=20261008T183248Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CB1DE6B0555DA4B37EAA56F9829F9BF59489B6916A97AA161EF08A6DD4ABE56)
