# 认领核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/IIdFQLvWRg--J08viAmjXQ/zh-cn_image_0000001939010557.png?HW-CC-KV=V1&HW-CC-Date=20260909T173246Z&HW-CC-Expire=31536000000&HW-CC-Sign=08D4AAC578017F6232B143A26FB0708EBB2346479217903F01649508D1C72E95)

2. 填写待认领的主办单位和快游戏信息后，提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/cX6R8bYLSeGfVF6S_LCGtg/zh-cn_image_0000001939041085.png?HW-CC-KV=V1&HW-CC-Date=20260909T173246Z&HW-CC-Expire=31536000000&HW-CC-Sign=261D64B229D9939035C25050F1EF6680032197980BF2399255B353E27C3428AB)

3. 华为工作人员将在1~2个工作日内完成审核，审核结果将以短信或邮件形式通知，在此期间请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/nEw5tveSTSSfNiv2w1KwKA/zh-cn_image_0000001900091012.png?HW-CC-KV=V1&HW-CC-Date=20260909T173246Z&HW-CC-Expire=31536000000&HW-CC-Sign=2A5040E454DF950222396D6F98A343832B2349E705511566B92FE0F5B202E5C6)
