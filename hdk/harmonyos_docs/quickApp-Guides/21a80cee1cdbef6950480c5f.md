# 新增接入

在华为云核准（备案）系统中接入已在其它接入商核准（备案）成功的快游戏。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面点击"新增互联网信息"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/-n7LZPdyTZKlM9BXsmUPjw/zh-cn_image_0000001962842717.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=129CAF997E6A23CDCFD5CA0D493EE0DB815D7877BC3B321BE13027BBC7535A35)
2. 在"产品验证"页面填写快游戏信息，完成后点击"验证"。在弹出的窗口中点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/Uu28hjKFTMOcYK85NMvywg/zh-cn_image_0000001962722953.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=D3F3213BC31D07DCE5BB00136C135AA282ADBAE8006A7E787F99312484AA28C4)

3. 在"主体信息"页面校对主办单位、负责人信息，若有误请及时修改，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/G_H1Fd3hQWKWp87CzUPM5A/zh-cn_image_0000001962847341.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=B13B52CA8668F99C6C116A2CB3FEE525D5EA389243DADB4EDAA5732F517665F8)

4. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/olg9Fix7RnWxx-V4P0xPfA/zh-cn_image_0000001935803746.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=216B69F6711E247D6720871159DB63C553701EEB9EEA04A1BD1B96AEFB11BA89)

5. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/wfKkQXV6RZOqtzH8NCOpDg/zh-cn_image_0000001935803810.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=68D2611F42B8544D6CD2F1579863C15EC568A78D74FED49924897890E021039B)

6. 在"真实性核验"页面由互联网信息负责人进行人脸视频认证，完成后点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/EGqwS2YPSVmd-ArcKUdKgQ/zh-cn_image_0000001935644598.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=19E2C239CED7AF5418A3450D95307DBCBDA4C15F105FE8CE71EE20A3A2D3AEC8)

7. 在"预览资料"页面核对填写的信息，完成后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/Dh219rZkSoy2b1GL3TiUJA/zh-cn_image_0000001975487350.png?HW-CC-KV=V1&HW-CC-Date=20261008T173711Z&HW-CC-Expire=31536000000&HW-CC-Sign=903AF525352AEE076B58350F361676DCBACD53B761014E57B34FB098EA5DBDE3)

8. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。
9. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
