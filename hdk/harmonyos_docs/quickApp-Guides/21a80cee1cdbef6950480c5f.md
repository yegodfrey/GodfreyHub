# 新增接入

在华为云核准（备案）系统中接入已在其它接入商核准（备案）成功的快游戏。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面点击"新增互联网信息"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/-n7LZPdyTZKlM9BXsmUPjw/zh-cn_image_0000001962842717.png?HW-CC-KV=V1&HW-CC-Date=20260909T163840Z&HW-CC-Expire=31536000000&HW-CC-Sign=F5BAC6F495C1DD717DB89F85BBD1DE76A09691D1A39C6501641E53019F6C58CC)
2. 在"产品验证"页面填写快游戏信息，完成后点击"验证"。在弹出的窗口中点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/Uu28hjKFTMOcYK85NMvywg/zh-cn_image_0000001962722953.png?HW-CC-KV=V1&HW-CC-Date=20260909T163840Z&HW-CC-Expire=31536000000&HW-CC-Sign=992DCCCF320766ECEC0324E69D1F3FC108A42F5A7AFB9C29BD65C4CE41967192)

3. 在"主体信息"页面校对主办单位、负责人信息，若有误请及时修改，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/G_H1Fd3hQWKWp87CzUPM5A/zh-cn_image_0000001962847341.png?HW-CC-KV=V1&HW-CC-Date=20260909T163840Z&HW-CC-Expire=31536000000&HW-CC-Sign=A88E51BB02A62790F2FABAFFC8145AFDBF430FBEBEA4890FEFFA048C34A595D2)

4. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/olg9Fix7RnWxx-V4P0xPfA/zh-cn_image_0000001935803746.png?HW-CC-KV=V1&HW-CC-Date=20260909T163840Z&HW-CC-Expire=31536000000&HW-CC-Sign=05293C0A396AD56FEFF6B435C22D092ABECBA277811CF888C04D68F8F7832A68)

5. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/wfKkQXV6RZOqtzH8NCOpDg/zh-cn_image_0000001935803810.png?HW-CC-KV=V1&HW-CC-Date=20260909T163840Z&HW-CC-Expire=31536000000&HW-CC-Sign=6911279550C6C9840217482D7F63B2BFEB3A2B457349C44A1DB6AD9E98DCAC67)

6. 在"真实性核验"页面由互联网信息负责人进行人脸视频认证，完成后点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/EGqwS2YPSVmd-ArcKUdKgQ/zh-cn_image_0000001935644598.png?HW-CC-KV=V1&HW-CC-Date=20260909T163840Z&HW-CC-Expire=31536000000&HW-CC-Sign=DBC88D5FF9B17F74D3FA6EC018F8375FC1AAEC0D349849F531027365CC384309)

7. 在"预览资料"页面核对填写的信息，完成后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9a/v3/Dh219rZkSoy2b1GL3TiUJA/zh-cn_image_0000001975487350.png?HW-CC-KV=V1&HW-CC-Date=20260909T163840Z&HW-CC-Expire=31536000000&HW-CC-Sign=9D26EC8EF341299D4D2987BADE986ADFC4F939B4A4295F55BF1B272FD0B7ECAB)

8. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。
9. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
