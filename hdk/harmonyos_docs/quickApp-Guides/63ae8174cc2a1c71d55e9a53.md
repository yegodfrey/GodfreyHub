# 取消接入

取消接入将在工信部删除快游戏在华为接入商的核准（备案）信息，若快游戏服务还需使用，建议在新的接入商完成核准（备案）后再取消接入，否则快游戏可能会被通管局清理。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面选择"更多 > 取消接入"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/Z6UggJVXR3yB7KFPjaB-mg/zh-cn_image_0000001962846645.png?HW-CC-KV=V1&HW-CC-Date=20261008T183931Z&HW-CC-Expire=31536000000&HW-CC-Sign=E2DBDB2AB83F95311254BE933FF8C5CDAFAEA9A678DCCD1096790F5E64CD6C01)
2. 在"取消接入"页面填写负责人的手机/邮箱，选择注销原因后点击"下一步，提交审核"，在弹出的"确认要取消接入互联网信息"窗口点击"确认"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/bUi7IxpfT3CC6tS2F-Vhcg/zh-cn_image_0000001962726877.png?HW-CC-KV=V1&HW-CC-Date=20261008T183931Z&HW-CC-Expire=31536000000&HW-CC-Sign=F6826CF84245932C4FC4A541292D2A55408117FCB4C7D3367293A5B75A687FC2)
