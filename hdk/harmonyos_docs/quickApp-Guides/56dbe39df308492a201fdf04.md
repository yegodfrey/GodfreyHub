# 接入应用内支付服务

## 简介

华为应用内支付服务（In-App Purchases，IAP）为应用提供便捷的应用内支付体验，接入流程简便。通过应用内支付，用户可以在您的应用内购买各种类型的虚拟商品，包括消耗型商品、非消耗型商品和订阅型商品。

使用华为应用内支付的场景如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111515.05606820241747135959375838080920:50001231000000:2800:82B65888F86DEAF5A551DAE6F7221F9113891B6861A70CA98984CF8135945806.png) ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111515.11566422998129843396266211023710:50001231000000:2800:7C22ACFF1FC24A98BA7F9D4AD7662F647031C88368F7E451BC7FFA2CD9B6980E.png)

应用内支付支持的商品主要分如下3类：

|**商品类型**|**描述**|**示例**|
|:-----------------------------|:----------------------------------------|:----------------------|
|[消耗型商品](#section998762993310)|仅能使用一次，消耗使用后即刻失效，需再次购买。|游戏中额外生命、钻石等。|
|[非消耗型商品](#section493211339414)|一次性购买，永久拥有，无需消耗。|游戏中额外的游戏关卡或应用中无时限的高级会员。|
|[订阅类商品](#section126404232425)|用户购买后在一段时间内允许访问增值功能或内容，周期结束后自动续期购买下一期的服务。|应用中有时限的高级会员，如视频月度会员等。|

## 准入条件

接入应用内支付服务前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 在AppGallery Connect上已[开通应用内支付服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-iap-kit-0000001079803876)。
* 在AppGallery Connect上已配置商品信息，具体操作请参见：[新增商品](https://developer.huawei.com/consumer/cn/doc/app/agc-help-create-product-0000001099854866)、[修改商品](https://developer.huawei.com/consumer/cn/doc/app/agc-help-modify-product-0000001146814541)。
* 支付内支付服务是华为扩展接口，而非厂商联盟规范，请[安装华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)进行接入。

## 购买商品流程

### 购买消耗型商品

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111516.79323789557661706265178365459971:50001231000000:2800:05FF3D4142978B4F92FB54AA16FC90566AD70F3516DFF792F1CB3D8E8058150C.png)

1. 发起购买。
2. 请求发货。需要对购买商品详情数据进行验签处理。如果应用对安全性要求比较高，可通过服务端[Order服务购买Token校验](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References-V5/api-order-verify-purchase-token-0000001050746113-V5)接口，向华为支付服务器发起校验请求，进一步确认订单的准确性。
3. 发放商品。需要把已发货的token传至应用的服务器，后续即使消耗失败也可以从应用的服务器获取商品的发货状态，从而避免重复发货的情况。
4. 发货成功后应用需要使用[consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-4-0000001075552476#section2946161093810)接口消耗该商品，以此通知华为服务器更新商品的发货状态。发送consumeOwnedPurchase请求时，请在请求参数中携带购买数据中的purchaseToken。应用成功执行消耗之后，华为服务器会将相应商品重新设置为可购买状态，即用户可再次购买该商品。

> 说明
>
> * 建议应用在发货成功后再执行消耗操作。如果应用在商品消耗后再进行发货，可能存在如下异常场景：华为服务器消耗成功后因为网络异常等原因未能成功将结果回调至应用，从而导致服务器已消耗商品但是应用没有发货。
> * 对于没有服务端的应用，以上流程同样适用，只需将服务端的处理放在客户端即可。

### 购买非消耗型商品

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111516.98007200869907428610074926126981:50001231000000:2800:C51106A4CAEB917D5C03DB9FE2699EFEFBA8A5A407B797858815BFFBCA7C86D8.png)

1. 发起购买。
2. 请求发货。需要对购买商品详情数据进行验签处理。如果应用对安全性要求比较高，可通过服务端[Order服务购买Token校验](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/api-order-verify-purchase-token-0000001050746113-V5)接口，向华为支付服务器发起校验请求，进一步确认订单的准确性。
3. 发放商品。验证成功后通过购买商品详情数据中的purchaseState字段判断商品的购买状态，当商品为已购买（purchaseState=0）时，发放相应的商品。

### 购买订阅类商品

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111516.24096699162222461126281713266980:50001231000000:2800:4B22EBC83A6BD16A8FF720B02BBC948E15F2FADABF9223DFFC130AF818B83CE0.png)

1. 发起购买。
2. 请求提供服务。
3. 提供商品服务，详细参见[订阅专有功能说明](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-subscription-functions-0000001146460329)。

## 判断是否支持应用内支付

在使用应用内支付之前，您的应用需要向快应用发送isEnvReady请求，以此判断用户当前登录的华为账号所在的服务地是否在IAP支持结算的国家或地区中。

调用 [pay.isEnvReady](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-4-0000001075552476#section1623962461015) 接口，并设置success和fail回调来获取返回结果。

* 当接口请求成功时，您的应用将获取到一个success返回值，表示用户当前登录的华为账号所在的服务地支持IAP。
* 当接口请求失败时，会返回一个fail返回值，可使用code获取此次请求的返回码。

```screen
pay.isEnvReady({
  isEnvReadyReq: {
    "applicationID": "101315751"
  },
  success: function (data) {
    console.debug("isEnvReady data =", JSON.stringify(data));
    prompt.showToast({
      message: "Env ready!"
    })
  },
  fail: function (data, code) {
    console.log("isEnvReady fail data =" + data, "code =" + code);
    prompt.showToast({
      message: "isEnvReady fail!"
    })
  }
})
```

## 展示商品信息

若在AppGallery Connect上配置了商品，在应用中可以使用obtainProductInfo接口来获取商品的详细信息。

1. 调用 [pay.obtainProductInfo](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-4-0000001075552476#section125017344614)接口并设置success和fail回调以接收接口请求的结果。 说明
   >
   > obtainProductInfo每次只能查询一种类型的商品。
2. 接口调用成功后返回一个productInfoList对象，可以使用productInfoList[i]查看单个商品信息，包含商品价格、名称、描述等信息，向用户展示可供购买的商品列表。

   ```screen
   pay.obtainProductInfo({
     productInfoReq: {
       "priceType": 1,
       "productIds": ["dy1","dmy00","lcole"],
       "applicationID": "101315751",
     },
     success: function (data) {
       console.debug("obtainProductInfo =" + JSON.stringify(data.productInfoList[0]));
       prompt.showToast({
         message: "obtainProductInfo success!"
       })
     },
     fail: function (data, code) {
       console.log("obtainProductInfo fail data =" + JSON.stringify(data), "code =" + code);
       prompt.showToast({
         message: "obtainProductInfo fail!"
       })
     }
   })
   ```

## 确认交易

用户完成一次支付之后，需要根据购买数据 [inAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-4-0000001075552476#ZH-CN_TOPIC_0000001075552476__p5724946202917) 的purchaseState字段来判断订单是否已成功支付。成功支付发放相应的商品或提供相应的服务，之后向IAP发送发货确认请求。

* 对于消耗型商品，需要从inAppPurchaseData的JSON字符串中解析出purchaseToken信息，用于确认商品的发货状态。 在成功发货并记录已发货商品的purchaseToken之后，需要使用[pay.consumeOwnedPurchase](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-4-0000001075552476#section2946161093810)接口消耗该商品，以此通知华为服务器更新商品的发货状态。调用consumeOwnedPurchase接口时，请在请求参数中携带purchaseToken。应用成功执行消耗之后，华为服务器会将相应商品重新设置为可购买状态，即用户可再次购买该商品。

  ```screen
  pay.consumeOwnedPurchase({
    consumeOwnedPurchaseReq: {
      "applicationID": "101315751",
      "developerPayload": "testPurchase",
      "purchaseToken": "0000017297d6a4faa22aaa2fa705e96247231b89ec228b3fd05e378b70e4c7d023a9c972c540e3d0x434e.1.101315751",
      "publicKey": "MIIBojANBgkqhkiG9w0BAQEFAAOCAY8AMIIBigKCAYEAnLLFO6c8d1x6jdbZ8PkNtrLtRMiFaRqWZgEjC4Vj9QXnPCmDZoPO5A5TSwzlWjYL5ktbbDnZC6Vfp8VI8nTMm8DvbGsJ+1ihru31vG1gqvUgOaXESqBhdpMrKFEgNBV8zlalLpcCU6Gayd8QJCxXRPcUisHLTQFJHjTMOWmvOcKiSxt1VmG3dvfWVkoMeKyerZy4qHEWM/asJihPZATBQ7puMC/kOh6i8V2gv4w/74KWifpBr3J5RN+PK6E7yWUqIALFTnN5vOIif2HELvgt+S6uaGpRydhSwu1xtV7bPtXQY20ollYo4BUi+AvM16iBCa1+1Mdw0y6Y9gZAtpHRK1Pf+yea4aoY4y/bZ6EX21wucvbzxexDcBkGn0DVvNHKr3usmUmq/yfMMmDPqPujv3iDWKFENfL4Agugo7I8etCF8vVYDOT5J8gXupgGLiritkfALZD8HgNZADyM+NnvQBJrdeVoHxCYoQMCS2hySPf2AaZWT7PzVAeGidLcEeKlAgMBAAE="
    },
    success: function (data) {
      console.debug("consumeOwnedPurchase data =", JSON.stringify(data));
      prompt.showToast({
        message: "consumeOwnedPurchase success!"
      })
    },
    fail: function (data, code) {
      console.log("consumeOwnedPurchase fail data =" + JSON.stringify(data), "code =" + code);
      prompt.showToast({
        message: "consumeOwnedPurchase fail!"
      })
    }
  })
  ```

* 对于非消耗型商品，华为服务器默认返回已确认的订单数据，应用需要在用户购买成功之后持续向用户提供相应的商品服务，具体参见[提供非消耗型商品对应的服务](#section957183653415)。
* 订阅类商品的处理参见[订阅专有功能说明](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-subscription-functions-0000001146460329)。

## 消耗型商品补单机制

在用户支付之后可能由于出现异常（网络错误、进程被终止等等）导致应用无法知道用户实际是否支付成功，即出现掉单情况。应用内支付针对此场景，提供了消耗型商品的补单机制。应用可参考以下流程图进行处理：

1. 在应用启动、购买请求返回错误码-1或60051时，使用[pay.obtainOwnedPurchases](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-4-0000001075552476#section3284913305)获取用户已购买未发货的消耗型商品的购买信息。应用需要在请求参数[ownedPurchasesReq](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-4-0000001075552476#ZH-CN_TOPIC_0000001075552476__p7697257103313)中指定查询的priceType为0。

## 对结果验签

> 说明
>
> 进行验签前，请务必将manifest文件中minPlatformVersion配置为1078或者以上版本。

在接口调用过程中，请求方在获取接收方的响应结果后，如果返回结果中包含了查询结果的签名字符串，请求方可以对签名字符串使用支付公钥进行验签，确认返回结果没有被篡改。支付公钥获取方式参见开通应用内支付服务中"[查询应用内支付服务信息](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-iap-kit-0000001079803876#section1318913307128)"章节。

建议把公钥存放在服务端并在服务端完成签名校验，保证接口调用的安全性。

1. 获取需要验签的返回结果字符串，例如pay.obtainOwnedPurchases返回的inAppPurchaseDataList中商品信息需要验签，先取第1条商品信息的JSON字符串参与验签。
2. 获取对应的签名字符串，例如pay.obtainOwnedPurchases返回的inAppSignature对应inAppPurchaseDataList的签名字符串，取第1条商品信息的签名字符串参与验签。
3. 使用支付公钥对结果字符串和对应的签名字符串通过SHA256WithRSA算法进行验证。

JAVA示例代码如下：

```screen
/** *校验签名信息  
* @param content 结果字符串  
* @param sign 签名字符串  
* @param publicKey 支付公钥  
* @param是否校验通过  
*/ 
public static boolean doCheck(String content, String sign, String publicKey) { 
    if ( sign == null) { 
        return false; 
    } 
    if (publicKey == null) { 
        return false; 
    } 
    try { 
        KeyFactory keyFactory = KeyFactory.getInstance("RSA"); 
        byte[] encodedKey = Base64.decode(publicKey); 
        PublicKey pubKey = keyFactory.generatePublic(new X509EncodedKeySpec(encodedKey)); 
        java.security.Signature signature = null; 
        signature = java.security.Signature.getInstance("SHA256WithRSA"); 
        signature.initVerify(pubKey); 
        signature.update(content.getBytes(StandardCharsets.UTF_8)); 
        byte[] bsign = Base64.decode(sign); 
        return signature.verify(bsign); 
    } catch (RuntimeException e) { 
        throw e; 
    } catch (Exception e) { 
        e.printStackTrace(); 
    } 
    return false; 
}
```
