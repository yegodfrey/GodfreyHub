# 转移核准（备案）

> 说明
>
> 若主账号[开启"账号管理功能"开关](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-account-0000001885962814#ZH-CN_TOPIC_0000001885962814__li1536716016483)，该核准（备案）方式仅限在主账号下操作。

在华为云核准（备案）系统中将主体及主体下的互联网信息全部转移到目标账号下。操作步骤如下：

1. 登录[华为云核准（备案）系统](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，左侧菜单栏点击"我的备案"，右侧页面点击"转移备案"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1a/v3/fE8X0H8nSpKEXthfPX2LgA/zh-cn_image_0000001935645274.png?HW-CC-KV=V1&HW-CC-Date=20261008T141412Z&HW-CC-Expire=31536000000&HW-CC-Sign=9691FB31A47CCF801E0748704ACBC4206C2D5A0081F7E93921DEF35D93D3CCE4)
2. 在"转移备案"填写目标账号后，点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/d6UhsA8SS_OUnoiT2KSpOA/zh-cn_image_0000001962844129.png?HW-CC-KV=V1&HW-CC-Date=20261008T141412Z&HW-CC-Expire=31536000000&HW-CC-Sign=85AEE9B9041DBBF07F44D60CD727081E2784D9D94570A0CBF22BD8CAEF79DB3E)

3. 提交转移申请后需要几分钟才能转移成功，请耐心等待。
