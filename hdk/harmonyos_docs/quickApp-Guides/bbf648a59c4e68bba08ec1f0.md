# 接入AGD Pro服务

#### 简介

AGD Pro应用变现服务（简称AGD Pro服务）是华为应用市场为在架应用提供的媒体增值服务，AGD Pro服务可以为您的应用提供推荐卡片的展示能力以及相应的应用下载安装能力。这些推荐卡片可以帮助您吸引用户，帮助用户快速了解应用信息，有效提高应用下载率，达到流量变现的目的。  

#### 准入条件

#### 注册账号、开通商户服务和签署协议

1. 注册华为账号。 在[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)进行华为账号注册，详细参见"[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。如果您已经拥有华为账号，可跳过本步骤。

2. 实名认证。 账号注册完后，需要完成实名认证才能享受华为开放的各类能力和服务，您可以选择认证成为企业开发者或个人开发者，企业开发者比个人开发者享受的服务更多，详细参见"[实名认证介绍](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)"。

3. 开通商户服务。 如果您的应用与华为应用市场进行收益分成（付费应用或接入华为应用内支付），您需要提前开通商户服务并签署华为商户服务协议，详细参见"[开通商户服务](https://developer.huawei.com/consumer/cn/doc/start/merchant-service-0000001053025967)"。

4. 签署协议。 账号注册完后，首次登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站时，请先签署首页弹出的华为AppGallery Connect服务协议。详细参见"[AppGallery Connect 协议签署指南](https://developer.huawei.com/consumer/cn/doc/app/signing-guide)"。

#### AGC控制台配置

在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。  

#### 为应用创建媒体和展示位

为需要接入AGD Pro服务的应用创建媒体和展示位，详细操作参见"[创建媒体和展示位](https://developer.huawei.com/consumer/cn/doc/monetize/agd_pro_sdk_quickapp_media-position-0000001368066693)"。  

#### 集成AGD Pro服务

#### 集成征求用户意见能力

为了征求用户意见，AGD Pro SDK提供了相关接口征求用户意见，以及在征得用户意见后如何根据用户意见获取广告。

1. 根据广告类型调用[ad.setNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section193934035615)设置请求广告类型（个性化或者非个性化）。
2. 请求广告。 通过调用开发的接口，接入应用榜单、信息流、互推盒子、互推盒子横划榜单广告。如果获取用户意见时，用户未给出选择，则只能请求非个性化广告。

#### 集成原生广告能力

1. 调用[ad.getProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section165521938191811)判断是否支持广告服务，如果返回空字符串，则无法使用广告服务。
2. 通过 const nativeAd=[ad.createNativeAd](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section443419211957)创建广告。
3. 调用[nativeAd.load](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section15261346684)拉取广告数据。

   成功执行[nativeAd.onLoad](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section1528411518185)回调。

   ```
   nativeAd.onLoad((adlist) => {
   })
   ```

   失败执行[nativeAd.onError](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section19331824172513)回调。

   ```
   nativeAd.onError((errorObj) => {
   })
   ```

4. 使用组件[ad-button](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-component-ad-button-0000001354638941)实现下载原生广告中的广告主App。
5. 调用[nativeAd.reportAdShow](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section64121517151117)上报广告曝光。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111523.01465365442492219704327215707482:50001231000000:2800:84A38E2FCE156FEB5766647301931D04387F2A5987740E761A93ADF889399D5A.png)  
   页面从后台切回到前台时（如切到桌面再返回、进入落地页后返回等），如果广告依然展示，都需要调用该接口进行上报。
6. 每次用户点击广告后调用[nativeAd.reportAdClick](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section18941134151715)进行上报。
7. 当应用页面销毁时，调用[nativeAd.destroy](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section176531949854)销毁原生广告。  

#### 集成应用榜单能力

1. 通过[ad.createTemplateAd](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section755192152412)创建广告，type设置为appList。

   ```
   const templateAd = ad.createTemplateAd({ adUnitId: 'xxx',type:'appList',darkMode:0,width:1200,height:800,personalizedAd:0})
   ```

2. 调用[templateAd.load](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section212762282412)拉取广告数据。
3. 使用组件[ad-view](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-component-ad-view-0000001330871396)呈现广告的内容。一个adUnitId只应绑定一个ad-view组件，宽高必须与[步骤1](#ZH-CN_TOPIC_0000001413917689__li914710184100)创建广告时设置的宽高保持一致。
4. 当应用页面销毁时，调用[templateAd.destroy](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section1568012252413)销毁应用榜单广告。  

#### 集成信息流能力

1. 通过[ad.createTemplateAd](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section755192152412)创建广告，type设置为infoCard。

   ```
   const templateAd = ad.createTemplateAd({ adUnitId: 'xxx',type:'infoCard',darkMode:0,width:1200,height:800,personalizedAd:0})
   ```

2. 调用[templateAd.load](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section212762282412)拉取广告数据。
3. 使用组件[ad-view](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-component-ad-view-0000001330871396)呈现广告的内容。一个adUnitId只应绑定一个ad-view组件，宽高必须与[步骤1](#ZH-CN_TOPIC_0000001413917689__li19572194517361)创建广告时设置的宽高保持一致。
4. 当应用页面销毁时，调用[templateAd.destroy](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section1568012252413)销毁信息流广告。  

#### 集成互推盒子能力

1. 通过const appBoxAd=[ad.createAppBoxAd](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section18436935741)创建广告。
2. 调用[appBoxAd.load](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section26918351541)拉取广告数据。

   成功执行[appBoxAd.onLoad](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section1313511361048)回调。

   ```
   appBoxAd.onLoad(()=> {
     console.log('onLoad success');
   });
   ```

   失败执行[appBoxAd.onError](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section2014120179168)回调。

   ```
   appBoxAd.onError((err)=>{
       console.log(err)
   })
   ```

3. 广告数据成功加载后，调用[appBoxAd.show](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section9927235848)展示广告页。
4. 调用[appBoxAd.onClick](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section1397561741616)监听广告点击事件。
5. 当应用页面销毁时，调用[appBoxAd.destroy](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section13743103461817)销毁互推盒子广告。  

#### 集成互推盒子横划榜单能力

1. 通过const bannerBoxAd=[ad.createAppBoxBannerAd](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section3217113215254)创建广告。
2. 调用[bannerBoxAd.show](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section5229133212257)拉取广告数据并展示广告页。

   成功执行[bannerBoxAd.onLoad](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section72311632112514)回调。

   ```
   bannerBoxAd.onLoad(()=> {
     console.log('onLoad success');
   });
   ```

   加载失败执行[bannerBoxAd.onError](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section1823343215258)回调。

   ```
   bannerBoxAd.onError((err)=>{
       console.log(err)
   })
   ```

3. 调用[bannerBoxAd.onClick](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section14240143212519)监听广告点击事件。
4. 当应用页面销毁时，调用[bannerBoxAd.destroy](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ad-0000001074754667#section20243133217252)销毁互推盒子横划榜单广告。  

#### 自测试验证及上线

在正式以SDK方式接入AGD Pro服务前，您需要对集成后业务进行自测，自测完成后再提交给华为验收，详细操作参见"[自测试验证及上线](https://developer.huawei.com/consumer/cn/doc/monetize/agd_pro_sdk_quickapp_test-online-0000001382333277)"。
