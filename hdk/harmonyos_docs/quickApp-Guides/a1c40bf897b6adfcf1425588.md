# 接入钥匙环服务

#### 简介

钥匙环服务（Keyring）为您提供在快应用、HarmonyOS应用、Android应用和浏览器之间共享登录信息的能力。

当前快应用中支持了钥匙环服务的用户凭据能力，调用这些能力，您可以基于用户凭证信息，让用户快速获取登录信息，简化登录成本。  

#### 准入条件

接入华为钥匙环服务前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。  

#### 接入指引

#### 判断是否支持钥匙环服务

调用[keyring.getProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-keyring-0000001206738947#section7247725135314)接口，判断手机是否支持钥匙环服务，如果返回空字符串，表示不支持此服务，此时请勿调用其他接口，否则将抛出异常；如果返回服务商代号，则可使用其他接口。  

#### 保存用户的凭证信息

调用[keyring.saveCredential](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-keyring-0000001206738947#section199437254539)接口，保存用户的凭证信息。

保存新增数据：

```
keyring.saveCredential({
  type: 0,
  syncable: "false",
  userAuth: "true",
  username: "Zhang San",
  newContent: "123456",
  success: function (msg) {
    prompt.showToast({
      message: msg,
      duration: 2000,
      gravity: 'bottom'
    })
  },
  fail: function (code,msg) {
    prompt.showToast({
      message: code + msg,
      duration: 2000,
      gravity: 'bottom'
    })
  }
})
```

保存更新数据：

```
keyring.saveCredential({
  type: 0,
  syncable: false,
  userAuth: true,
  username: "Zhang San",
  newContent: "12345678",
  sharedWith: [{
    certHash: "${签名指纹}",
    name: "${应用名称}",
    packageName: "${应用包名}",
    type: "android_app"
  },
  {
    name: "${网址名称}",
    domain: "${网址域名}",
    type: "web"
  }],
  owner: {
    certHash: "3a:25:d7:19:53:9b:39:b9:67:48:c4:85:86:bb:d7:f1:dd:53:e5:e9:29:12:77:0e:f2:5f:4e:7e:9a:b3:7f:cc",
    name: "Keyring_Test",
    packageName: "com.huawei.keyring",
    type: "quick_app"
  },
  success: function (msg) {
    prompt.showToast({
      message: msg,
      duration: 2000,
      gravity: 'bottom'
    })
  },
  fail: function (msg) {
    prompt.showToast({
      message: msg,
      duration: 2000,
      gravity: 'bottom'
    })
  }
})
```

#### 删除用户凭证信息

调用[keyring.deleteCredential](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-keyring-0000001206738947#section349516262537)接口，删除本应用之前保存的用户凭证信息。

```
keyring.deleteCredential({
  owner: {
    certHash: "3a:25:d7:19:53:9b:39:b9:67:48:c4:85:86:bb:d7:f1:dd:53:e5:e9:29:12:77:0e:f2:5f:4e:7e:9a:b3:7f:cc",
    name: "Keyring_Test",
    packageName: "com.huawei.keyring",
    type: "quick_app"
  },
  "type": 0,
  "username": "Zhang San",
  success: function (msg) {
    prompt.showToast({
      message: msg,
      duration: 2000,
      gravity: 'bottom'
    })
  },
  fail: function (code, msg) {
    prompt.showToast({
      message: code + msg,
      duration: 2000,
      gravity: 'bottom'
    })
  }
})
```

#### 查询用户凭证信息

调用[keyring.findCredential](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-keyring-0000001206738947#section8975142615313)接口，查询目标应用中用户已登录的凭证信息。

```
keyring.findCredential({
  trustedApps: [{
      type: 'quick_app',
      name: 'AndroidAppIdentity',
      packageName: 'com.huawei.hms.keyring.test',
      certHash: "3C:99:C3:69:27:75:46:FD:E4:14:82:C0:C1:FB:75:54:94:A7:A8:63:CA:9C:A7:BB:4B:9D:48:C4:04:86:9A:93"
    }],
  success: function (data) {
    credential = data // 返回的数据列表
    prompt.showToast({
      message: data,
      duration: 2000,
      gravity: 'bottom'
    })
  },
  fail: function (code, msg) {
    prompt.showToast({
      message: code + msg,
      duration: 2000,
      gravity: 'bottom'
    })
  }
})
```

#### 获取目标凭证的敏感信息

先调用[keyring.findCredential](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-keyring-0000001206738947#section8975142615313)接口查询目标应用的凭证列表，再调用[keyring.getCredentialContent](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-keyring-0000001206738947#section9655102716531)接口，获取目标凭证的敏感信息。

```
keyring.getCredentialContent({
  owner: {
    certHash: "3C:99:C3:69:27:75:46:FD:E4:14:82:C0:C1:FB:75:54:94:A7:A8:63:CA:9C:A7:BB:4B:9D:48:C4:04:86:9A:93",
    name: "AndroidAppIdentity",
    packageName: "com.huawei.hms.keyring.test",
    type: "quick_app"
  },
  type: 0,
  username: "Zhang San",
  success: function (data) {
    prompt.showToast({
      message: data, // 返回的敏感信息内容
      duration: 2000,
      gravity: 'bottom'
    })
  },
  fail: function (msg, code) {
    prompt.showToast({
      message: code + msg,
      duration: 2000,
      gravity: 'bottom'
    })
  }
})
```

#### 应用间共享凭据

#### AB快应用之间共享

1. 在A快应用中调用 keyring.getProvider() 接口判断当前设备是否支持华为钥匙环服务。调用接口返回 huawei 表示支持，否则表示不支持。
2. 在A快应用中调用 keyring.saveCredential() 接口新增并保存用户凭据同时通过sharedwith共享给B应用。
3. B应用通过 keyring.findCredential获取A应用共享的用户凭据。
4. B快应用调用keyring.getCredentialContent获取目标凭证的敏感信息。
5. A快应用调用keyring.saveCredential()更新用户凭据 。
6. B快应用通过 keyring.findCredential重新获取A应用共享的用户凭据。  

#### 快应用与HarmonyOS应用或Android应用共享

1. 在快应用中调用 keyring.saveCredential() 接口新增并保存用户凭据同时通过sharedwith共享给HarmonyOS应用或Android应用。
2. 在快应用中调用 keyring.findCredential()获取HarmonyOS应用或Android应用共享的用户凭据。  

#### 快应用与web应用共享

1. 在快应用中调用 keyring.saveCredential() 接口新增并保存用户凭据同时通过sharedwith共享给web应用。
2. 在快应用中调用 keyring.findCredential()获取web应用共享的用户凭据。
