# Deeplink

## 简介

快应用提供标准的Deeplink入口，可以实现点击web页面的链接启动快应用。
> 说明
>
> * Deeplink链接前后不能有空格。
> * Deeplink链接不能在短信中直接点击唤起快应用。
> * Deeplink跳转不支持失败回调，如果您是在网页中使用，请自己维护fallback，确保在未跳转的情况下，仍然有合适的H5页面为用户提供服务。

安装快应用中心后，就可以使用Deeplink。

## 支持的格式

Deeplink支持如下三种格式：

* hap://app/<package>/[path][?key=value]
* https://hapjs.org/app/<package>/[path][?key=value]
* hwfastapp://<package>/[path][?key=value]

> 注意
>
> * 快应用内推荐使用hap格式打开快应用，https格式将被当成web页面打开。
> * 以hwfastapp开头的格式仅适用于华为手机。

|参数|说明|
|:--------|:----------------------------------------------------|
|package|应用包名，必选。|
|path|应用内页面的路径，可选，默认为首页。|
|key-value|需要传给页面的参数，可选，可以有多个。传递的参数值有可能被其他应用获取，建议不要传递安全敏感度较高的数据。|

从1107版本开始，新增**__WINDOW_STYLE__**参数，可控制从原生应用或者快应用中打开的快应用是否半屏显示。

* **__WINDOW_STYLE__** 设置为**fullScreen**，快应用以全屏形式打开（默认打开方式）。
* **__WINDOW_STYLE__** 设置为**halfScreen**，快应用以半屏形式打开。

> 说明
>
> 当**__WINDOW_STYLE__** 设置为**halfScreen**时，但打开的快应用并没有使用记录，将仍然以全屏形式打开快应用，并将其加入到使用记录中。

## 使用示例

* 快应用中调用Deeplink打开另一个快应用。

  ```screen
  import router from '@system.router'
  router.push({
          uri: 'hap://app/com.example.quickapp/page?key=value'
  })
  router.push({
          uri: 'hap://app/com.example.quickapp/page?__WINDOW_STYLE__=halfScreen'
          //Jump to an half screen quick app
  })
  ```


* 在网页中点击链接跳转快应用。

  ```screen
  <html>
      <head>
          <meta charset="UTF-8">
          <title></title>
      </head>
      <body>
          <a href="hap://app/com.example.quickapp">跳转到新的快应用</a>
          <a href="hap://app/com.example.quickapp?__WINDOW_STYLE__=halfScreen">跳转到半屏的快应用</a>
      </body>
  </html>
  ```

通过Deeplink打开页面会触发不同的周期函数：

* 页面启动模式（launchMode）设置为singleTask：Deeplink的目标页面如果已经存在了只是切换到后台，这时候Deeplink跳转后会触发onRefresh，如果目标页面不在后台运行，则触发onShow。
* 页面启动模式（launchMode）设置为standard：Deeplink跳转后会始终触发onShow。

跳转后的页面可以通过onRefresh或者onShow获取传递的参数。
