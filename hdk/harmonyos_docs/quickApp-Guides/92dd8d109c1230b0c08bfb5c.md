# 角标组件

#### 简介

角标组件，主要用于在元素周围展示消息提醒，一般用于列表、九宫格、按钮。

角标（badge）一般具有如下特点：

* 可以定义角标为数字或点
* 可以配置角标的颜色、背景色
* 可以配置角标的位置

基本布局代码如下：

```
<template>
  <div class="container">
    <text class="section">数字角标通用来标记重点信息，如接收到新消息、有未读消息等</text>
    <div class="*">
      <badge display-value="1"></badge>
      <badge display-value="2" type="primary"></badge>
      <badge display-value="34" type="success"></badge>
      <badge display-value="45" type="warning"></badge>
      <badge display-value="123" type="info"></badge>
    </div>
<template>
```

#### 开发指引

#### 自定义子组件

1. 定义布局样式。 角标组件布局用stack组件堆叠实现，内容部分由text+slot组件实现。

   ```
   <template>
     <div class="container">
       <stack class="stack">
         <slot name="top"></slot>
         <text
           class="txt"
           style="background-color:{{customstyle.backgroundcolor?customstyle.backgroundcolor:type}};
                           color:{{customstyle.color?customstyle.color:color}};                  
                           width:{{bagdestylewidth}}px;height:{{bagdestyleheight}}px;
                           top: {{bagdestyletop}}px;left:{{bagdestyleleft}}px;"
         >
           {{displayValue}}
         </text>
       </stack>
     </div>
   </template>
   ```

2. 规划属性。 支持的属性：

   |属性|类型|默认值|描述|
   |:-----------|:------|:-----------------------------|:----------|
   |type|String|error|颜色类型。|
   |displayValue|String|0|角标内容。|
   |inverted|Boolean|false|是否无需背景色背景色。|
   |isdot|Boolean|false|是否显示为一个小点。|
   |countflag|Boolean|false|是否计数。|
   |maxNum|String|99|展示封底数值。|
   |absolute|String|-|绝对定位。|
   |offset|Object|offsetx: 0,offsety: 0|偏移量。|
   |customstyle|Object|backgroundcolor: '', color: ''|自定义样式。|

#### 父子组件通信

父组件给子组件传递数据：

1. 子组件通过在props定义参数，接收来自父组件的传值数据，如type、displayValue等。

   ```
   props: {
       type: {
           type: String,
           default: 'error'
       },
       displayValue: {
           type: String,
           default: '0'
       },
       inverted: {
           type: Boolean,
           default: false
       },
       isdot: {
           type: Boolean,
           default: false
       },
       countflag: {
           type: Boolean,
           default: false
       },
       maxNum: {
           type: Number,
           default: 99
       },
       absolute: {
           type: String,
           default: ''
       },
       offset: {
           type: Object,
           default() {
               return {
                   offsetx: 0,
                   offsety: 0
               }
           }
       },
       customstyle: {
           type: Object,
           default() {
               return {
                   backgroundcolor: '',
                   color: ''
               }
           }
       },
   },
   ```

2. 父组件给子组件传值，如果是布尔值，需要在data中定义，而不能直接在组件中定义。

   ```
   data: {
         customstyle: {
           backgroundcolor: '#62ed0d',
           color: '#fff',
         },
         isdot: true,
         countflag: true,
         value: '20',
         offset: {
           offsetx: 15,
           offsety: -15
         },
   },
   ```

3. 父组件通过parentVm.$broadcast()向子组件传递角标文本的宽和高。

   ```
   queryBounds: function () {
         var that = this;
         this.$element('box').getBoundingClientRect({
           success: function (data) {
             // console.log('getBoundingClientRect succeeded, result data =' + JSON.stringify(data.width));
             that.boxwidth = JSON.stringify(data.width)
             that.boxheight = JSON.stringify(data.height)
             that.$broadcast('boxsize', {
               boxwidth: that.boxwidth,
               boxheight: that.boxheight
             })
           },
           fail() {
             console.log('getBoundingClientRect failed');
           },
           complete: function () {
             console.log('getBoundingClientRect completed');
           }
         });
   }
   ```

4. 子组件通过$on()方法监听角标文本的width和height属性的变化，从而修改css样式，让其在对应的位置显示角标。

   ```
   onInit() {
       this.$watch('displayValue', this.changeValue())
       this.$watch('type', this.changeColor())
       this.$watch('inverted', this.changeInverted())
       this.$watch('isdot', this.isDot())
       this.$watch('countflag', this.countFlag())
       this.$on('boxsize', this.boxSizeEvt)
       this.startData();
   },
   //获取box的宽和高
   boxSizeEvt(evt) {
       console.log("evt:" + evt.detail.boxwidth + "|"  + evt.detail.boxheight);
       this.boxwidth = Number(evt.detail.boxwidth)
       this.boxheight = Number(evt.detail.boxheight)
       console.log("message:" + typeof (this.boxwidth) + "|"  + typeof (this.boxheight));
       this.positionStyle()
   },
   //位置样式
   positionStyle() {
       console.log("this.boxwidth :" + this.boxwidth + " " + "this.boxheight:" + this.boxheight);
       console.log("this.absolute:" + this.absolute);
       if (this.absolute === "rightTop") {
           this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.boxwidth + this.offset.offsetx
           this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.offset.offsety
       } else if (this.absolute === "rightBottom") {
           this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.boxwidth + this.offset.offsetx
           this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.boxheight + this.offset.offsety
       } else if (this.absolute === "leftTop") {
           this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.offset.offsetx
           this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.offset.offsety
       } else if (this.absolute === "leftBottom") {
           this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.offset.offsetx
           this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.boxheight + this.offset.offsety
       }
   },
   ```

#### 示例代码

```

  <!-- Only one root node is allowed in template. -->
  <div class="container">

      <slot name="top"></slot>
      <text

                        top: {{bagdestyletop}}px;left:{{bagdestyleleft}}px;"
      >
        {{displayValue}}
      </text>
    </stack>
  </div>
</template>
<script>
    module.exports = {
        props: {
            type: {
                type: String,
                default: 'error'
            },
            displayValue: {
                type: String,
                default: '0'

                type: Object,

                    return {
                        offsetx: 0,

                    }
                }
            },

                type: Object,
                default() {
                    return {
                        backgroundcolor: '',
                        color: ''
                    }
                }
            },
        },
        data: {
            syncFlag: true,
            bagdestylewidth: 60,
            bagdestyleheight: 40,
            bagdestyletop: 30,
            bagdestyleleft: 30,

        },

        onInit() {
            this.$watch('displayValue', this.changeValue())
            this.$watch('type', this.changeColor())
            this.$watch('inverted', this.changeInverted())
            this.$watch('isdot', this.isDot())
            this.$watch('countflag', this.countFlag())
            this.$on('boxsize', this.boxSizeEvt)

            console.log("message:" + typeof (this.boxwidth) + "|"  + typeof (this.boxheight));
            this.positionStyle()
        },
        //判断起始数据
        startData() {
            // console.log("startData countflag:" + this.countflag)
            if (this.countflag === true) {
                // console.log("displayValue:" + this.displayValue)
                setInterval(() => {
                    if (this.displayValue < 100) {
                        this.displayValue++
                        if (this.displayValue > 99) {
                            this.displayValue = "99+"
                            return
                        }
                    }
                }, 100)
            }
            if (this.displayValue >= 100) {
                this.displayValue = "99+"
            }
        },

        isDot() {
            console.log("isdot:" + this.isdot);
        },
        countFlag() {
            console.log("countFlag:" + this.countflag);
        },
        //位置样式
        positionStyle() {
            console.log("this.boxwidth :" + this.boxwidth + " " + "this.boxheight:" + this.boxheight);
            console.log("this.absolute:" + this.absolute);
            if (this.absolute === "rightTop") {
                this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.boxwidth + this.offset.offsetx
                this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.offset.offsety
            } else if (this.absolute === "rightBottom") {
                this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.boxwidth + this.offset.offsetx
                this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.boxheight + this.offset.offsety
            } else if (this.absolute === "leftTop") {
                this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.offset.offsetx
                this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.offset.offsety
            } else if (this.absolute === "leftBottom") {
                this.bagdestyleleft = this.bagdestyleleft - this.bagdestylewidth / 2 + this.offset.offsetx
                this.bagdestyletop = this.bagdestyletop - this.bagdestyleheight / 2 + this.boxheight + this.offset.offsety
            }
        },

        changeValue() {
            console.log("this.absolute_changeValue:" + this.absolute);
            if (this.absolute === "") {
                this.bagdestylewidth = this.bagdestylewidth;
                this.bagdestyleheight = this.bagdestyleheight;
            } else {
                this.bagdestylewidth = 40;
                this.bagdestyleheight = 30;
                if (this.isdot === true) {
                    this.displayValue = "";
                    this.bagdestylewidth = 20;
                    this.bagdestyleheight = 20;
                } else {
                    if (this.displayValue > this.maxNum) {
                        this.displayValue = "99+"
                    }
                }
            }
        },
        changeInverted() {
            console.log("this.inverted:" + this.inverted);
        },
        //改变文字和内容颜色
        changeColor() {
            if (this.inverted === false) {
                this.color = "white";
                if (this.type === "info") {
                    this.type = "#909399"
                } else if (this.type === "primary") {
                    this.type = "#2979ff"
                } else if (this.type === "error") {
                    this.type = "#dd524d"
                } else if (this.type === "success") {
                    this.type = "#4cd964"
                } else if (this.type === "warning") {
                    this.type = "#f0ad4e"
                }
            } else {
                if (this.type === "info") {
                    this.color = "#909399"
                } else if (this.type === "primary") {
                    this.color = "#2979ff"
                } else if (this.type === "error") {
                    this.color = "#dd524d"
                } else if (this.type === "success") {
                    this.color = "#4cd964"
                } else if (this.type === "warning") {
                    this.color = "#f0ad4e"
                }
                this.type = "#ffffff"
            }

        }

    }

</script>
```
