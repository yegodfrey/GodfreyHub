# 准备游戏信息

## 获取APP ID

APP ID是快游戏的唯一标识，在AGC控制台创建快游戏后生成。APP ID将在多个服务中使用，您需提前记录下APP ID。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"，在项目列表选择要获取APP ID的项目及项目下的快游戏。
2. 在"项目设置"页面右侧的"应用"区域下即可获取快游戏的APP ID。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/e29Usgo7RcysdjdRePQmmA/zh-cn_image_0000001752052610.png?HW-CC-KV=V1&HW-CC-Date=20261008T192446Z&HW-CC-Expire=31536000000&HW-CC-Sign=419B6ACF8292E03A5B55FAD259813E44C3F1392590A3D0CD201A2CCF291C561D)

## 获取游戏公钥和私钥

若在服务端对账号登录数据进行加签、验签，您需提前记录下游戏公钥和游戏私钥。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"，在项目列表选择要查询信息的项目及项目下的快游戏。
2. 选择"构建 > 游戏服务"，记录下游戏公钥与游戏私钥。
   * 游戏公钥：RSA公钥，可验证华为游戏服务器的验签结果。
   * 游戏私钥：RSA私钥，可对登录数据进行加签，并传递给华为游戏服务器。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/VVocAXKBSZeSO16_qGPmFQ/zh-cn_image_0000001799012269.png?HW-CC-KV=V1&HW-CC-Date=20261008T192446Z&HW-CC-Expire=31536000000&HW-CC-Sign=281F2DBC16C1FCB71AD974C068B0D73ABBA65E931E6416367333E5923DA5C848)

## 获取支付公钥

若快游戏需在服务端对购买返回数据进行验签，以保证数据未被篡改，您需提前记录下支付公钥。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"，在项目卡片列表选择要查询信息的项目及项目下的快游戏。
2. 选择"项目设置 > API管理 > 应用内支付服务 > 配置"，若首次设置应用内支付服务的配置项，请点击"设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/H97EUIGeTR69NHwgEJYhSw/zh-cn_image_0000001752211514.png?HW-CC-KV=V1&HW-CC-Date=20261008T192446Z&HW-CC-Expire=31536000000&HW-CC-Sign=B133A80B0897038EFC346F038F196CB96218FC6D89FE679522B2445DEB26DB37)

3. 在"应用内支付服务 > 应用配置"页面记录快游戏的支付公钥。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/5BP3UT2WTtmeKv72uFbxmw/zh-cn_image_0000001799131301.png?HW-CC-KV=V1&HW-CC-Date=20261008T192446Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E729604DA9B4C55FE0A7367D1DBA2699C576C23C9E1579DABF44863906F81CD)

## 获取支付ID

支付ID是由华为开发者联盟给开发者分配，即商户ID。支付ID、商户ID和开发者ID三者相同。用于开发中对merchantId参数的设置。

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站，点击"管理中心"。
2. 在"应用服务"页面，选择"支付"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/83/v3/qFpg6lS0RBu7vDWPw054Dw/zh-cn_image_0000001942518034.png?HW-CC-KV=V1&HW-CC-Date=20261008T192446Z&HW-CC-Expire=31536000000&HW-CC-Sign=DADBC554B092488CEEE6ACE5EFE4F754EDD10804719F36984B0E652978B1C646)

3. 单击需要查询支付服务信息的应用。 说明
   >
   > 如果没有需要查询的应用，表示应用尚未申请支付服务，请检查是否已为应用申请支付服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/gvTRp186SOWK_z7ccK9xTA/zh-cn_image_0000001942358710.png?HW-CC-KV=V1&HW-CC-Date=20261008T192446Z&HW-CC-Expire=31536000000&HW-CC-Sign=A3DEF4D5DD3AB16CCF5BD8F81E7C1353CFB8E31FA02982BF1C921660A4EC9FB1)
4. 在"服务信息"区域获取支付ID，即商户ID。支付ID、商户ID和开发者ID三者相同。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0c/v3/Ne18d4YGS2-kOt_LmGfGKQ/zh-cn_image_0000001969476141.png?HW-CC-KV=V1&HW-CC-Date=20261008T192446Z&HW-CC-Expire=31536000000&HW-CC-Sign=D3BC78271C26CE4392C1969C382D73F1D13CE20646E1DC6C6053F63B64288333)
