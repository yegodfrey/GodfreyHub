# 打包快应用

#### 打包体验版本

在打包正式版本前，可以打包体验版本提供给团队内部或者部分目标用户提前体验，详细操作指导参见"[发布体验版本](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-release-quickapp-trial-version-0000001368867756)"。  

#### 打包正式版本

1. 华为快应用IDE菜单选择"构建 \> 打包正式版本"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240229104037.31960508091902991727971152076936:50001231000000:2800:754CC4F491F381335DF1C2C2C22EDFD01ED86A5896E8DDCD86F91EBE844ED97D.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

2. 弹出正式签名文件信息，确认打包的版本信息后，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240229104037.55875590294559427233522411049172:50001231000000:2800:6C78338FD856482146B8B7DDB62077329D09504D96497A4B7F64FCCEDC318974.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3. 打包完成将自动打开项目工程的dist文件夹，其中的.rpk文件即最后生成的正式版本包。
