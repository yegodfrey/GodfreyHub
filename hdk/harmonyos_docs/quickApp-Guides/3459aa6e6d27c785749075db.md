# 生成、配置证书指纹

## 生成证书指纹

华为快应用签名文件存放目录如下所示：

|------ sign

|------ |------ debug 调试签名文件目录（老版本的项目会存在debug目录，与新版本签名目录结构不冲突，不需要额外调整）

|------ ------ |------ certificate.pem 证书文件

|------ ------ |------ private.pem 私钥文件

|------ |------ release 正式签名文件目录

|------ ------ |------ certificate.pem 证书文件

|------ ------ |------ private.pem 私钥文件
> 注意
>
> * 如果将已有快应用项目迁移至华为快应用IDE，请务必将原项目的证书、私钥文件同步复制到对应的release目录。
> * 证书文件请务必保管好，一旦丢失，将无法找回。更换证书文件将导致无法升级快应用。

1. 打开华为快应用IDE，打开已有项目或者新建项目（不使用快应用Serverless参见"[创建项目](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-develop-phone-quickapp-0000001079484296#section12506516131218)"，使用快应用Serverless参见"[新建Serverless项目](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-serverless-development-0000001126545719#section57015506197)"）。
2. 菜单选择"工具 > 生成证书"，即可管理证书指纹。
   * 当对rpk包签名的正式签名文件不存在时，引导用户创建签名文件。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/F9Z5yuwGQqCNE6SmHlYHZQ/zh-cn_image_0000001154748489.png?HW-CC-KV=V1&HW-CC-Date=20260909T132629Z&HW-CC-Expire=31536000000&HW-CC-Sign=865452BCC11FF5544B2B7A390CA4F60FB96FB863D1EA25A95840488ACD5F933F)

## 配置证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"我的项目"。
2. 点击待查询的项目卡片。
3. 选择需要配置证书指纹的快应用。
4. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c7/v3/5eYnpd2HTp68hV-kNHX1FA/zh-cn_image_0000001187979822.png?HW-CC-KV=V1&HW-CC-Date=20260909T132629Z&HW-CC-Expire=31536000000&HW-CC-Sign=333D32AC79253EF0AC97E2B87F7889F53F829677F5CF2BABCE4403558362DDA0)
