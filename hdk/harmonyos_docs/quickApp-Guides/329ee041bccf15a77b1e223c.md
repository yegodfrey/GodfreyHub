# 提交审核

#### 上架申请

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111536.41233754488027765936091700391876:50001231000000:2800:EF3B15164CA28CEEFFECE4D2053956BD850A1133CCBC4751AA0B00621DEE786B.png)  
* 在提交快应用上架审核前，请务必先"[了解审核规则](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-release-rules-0000001129822631)"，进行自检，避免过多的驳回。
* 首次申请上架"华为应用市场"的快应用请务必提前"[准备资质文件](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-prepare-doc-0000001129385459)"。

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的应用"。
2. 搜索待提交上架审核的应用，点击应用名称。
3. 进入"应用信息"页面，填写应用基本信息，填写完成后，点击右上角的"保存"。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111536.20115434519439591692003823464886:50001231000000:2800:964AD8ABFCDCBB3ACCA65A6D2122DEF96F0C245031BB7EB34BA8DAB3B851EAD2.png)  
   * 素材请勿包含非华为手机信息的截图。
   * 应用分类：如果之前有对应的App上架"华为应用市场"，务必与App的类别保持一致。
4. 左侧导航选择"版本信息 \> 准备提交"。
5. 在"发布国家或地区"区域，选择快应用上架后需要分发的地区。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111536.09205820366839490288904760587268:50001231000000:2800:5E256D5D71F577615F5C919DD2B3C05235EC8BE529BE4D0DFC9B97E4D22DA9DB.png)

6. 如果在全网发布前，需要邀请部分用户进行版本测试，选择"是"可将版本发布为开放式测试版本，详细内容参见"[开放式测试](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-betatest-introduction-0000001071477284)"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111536.06206675092426491670349236020583:50001231000000:2800:A35F228C512793D65470E60B8B03D71CDF8073E7255AD6E19A77E13BB899CAAC.png)
7. 在"软件版本"区域，点击"软件包管理"，选择待提交审核的rpk包。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111536.46971527204599194097117371220567:50001231000000:2800:4EE318D5320CD7A0670AEF5512F4E95D5D850F26897E9D0093762C5E2E0527B8.png)

8. 在"版权信息"区域，上传相关资质文件。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111536.55478295868100822571195130886662:50001231000000:2800:6BC80F6E91D1480C9205D81187450CB5A9D21247FF1F32095401EBF5E3A98250.png)  
   * 《APP电子版权证书》在"电子版权证书"处上传。
   * 《免责函》、《计算机软件著作权证书》和其他资质文件在"应用版权证书或代理证书"处上传，此处最多上传5张照片，如果超过5张照片，请将多张照片拼接到一起，图片需确保清晰。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111536.35204774710853490410684184614381:50001231000000:2800:B4E097606E0DB99CFF8A49D0FC7C37BAF6AA96F537D46F844D7BDCD43A0A94C9.png)
9. 完善应用的其他申请信息，例如"应用内资费"、"隐私声明"、"上架时间"等，完成后点击右上角的"保存"。
10. 所有信息确认无误后，点击右上角的"提交审核"。 待审核通过，版本全网发布后，可以采用分阶段发布，实现先向一定比例用户发布更新版本，详细操作请参见"[分阶段发布应用](https://developer.huawei.com/consumer/cn/doc/app/agc-help-phased-release-0000001099836872)"。
