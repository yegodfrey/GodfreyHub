# 隐私组件

#### 简介

隐私（privacy）组件，用于提供统一格式的隐私弹窗模板。隐私组件支持如下特点：

* 支持文本内容的更新
* 支持重点文字样式的修改
* 支持文件链接的替换

效果图如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111559.15489313475343269795849970562540:50001231000000:2800:7DBC496CB8B6FB0C00573AFC2FC466CEC60A33FD8F05DB4E894EFF0A5361D3BE.png)

基本布局代码如下：

```

        <text class="test-text">{{text}}</text>

#### 开发指引

1. 定义布局样式。 隐私组件整体外观都是通用的，但是内部具体的样式有区别，在设计的时候，不能把内部样式固定，否则一旦隐私的UI有变化，会导致子组件也要修改，违背了对外开源的初衷。

   该弹窗样式采用的单位为dp适配，与px的转换公式为：（样式dp值/设备dp值）\*designWidth。

   假设参考样式是180dp，当前设备是360dp，比率为0.5；默认的designWidth是750px， 则换算结果为0.5 \* 750px = 375px。

2. 规划属性和支持的事件。  
   支持的属性：  

   |名称|类型|默认值|是否必填|描述|
   |:------|:------|:----|:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |showPop|Boolean|false|是|控制隐私组件的显示与隐藏。 * false：隐藏 * true：显示|
   |title|String|隐私声明|否|隐私组件的标题内容。|
   |backImg|Url|-|否|可设置隐私组件幕布背景为图片（支持jpg和png格式），支持网络和本地相对路径的图片。 如果图片路径有误则为系统默认#CCC的背景色，不填则为黑色透明背景色。 注意： 背景图片请谨慎使用，示例如下： backImg="https://developer.huawei.com/consumer/cn/activity/bg.c2777d924ed162523fa9.jpg"|

   支持的事件：  

   |事件名称|参数|描述|
   |:-----|:-|:----------------|
   |agree|无|隐私组件中点击"同意"按钮的事件。|
   |cancel|无|隐私组件中点击"取消"按钮的事件。|

#### 父子组件通信

1. 子组件的props中定义相关属性值，父组件引用时传入属性值，子组件通过 this.xxx 获取值并进行处理。

   ```
   props: {
     backImg: {
       type: String,
       default: "",
     },
     zIndex: {
       default: 10000
     },
     title: {
       type: String,
       default: "隐私声明",
     },
     showPop: {
       type: Boolean,
       default: false,
       required: true,
     }
   },
   ```

2. 父组件定义"同意"或"取消"的点击事件并绑定。

   ```
   <privacy @agree="agree" @cancel="cancel" show-pop="{{isShow}}">
      …
   </privacy>
   ```

   ```
   agree() {
       //点击同意后关闭隐私组件
       this.isShow = false;
   },
   cancel(){
       this.isShow = false;
   },
   ```

3. 在点击"同意"或"取消"时，子组件通过this.$emit方法触发父组件的click事件。

   ```
   async cancel() {
     this.btndisabled = true;
     await setStorage("_PRIVAC", false);
     this.$emit("cancel");
   },
   async sure() {
     await setStorage("_PRIVAC", true);
     this.$emit("agree");
   }
   ```

#### 本地存储的方法processData.js代码

```
import storage from '@system.storage'

// 优化本地存储get方法
export function localStorage(key) {
    return new Promise((resolve, reject) => {
        storage.get({
            key,
            success: function (data) {
                resolve(data)
            },
            fail: function (data, code) {
                reject(data)
            }
        })
    })
}

export function setStorage(key, value = "") {
    return new Promise((resolve, reject) => {
        storage.set({
            key,
            value: JSON.stringify(value),
            success: function (data) {
                resolve(`setStorage success`);
            },
            fail: function (data, code) {
                reject(`setStorage fail, code = ${code}`);
            }
        });
    });
}

export function getStorage(key) {
    return new Promise((resolve, reject) => {
        storage.get({
            key,
            success: function (data) {
                if (data) {
                    const res = JSON.parse(data);
                    return resolve(res);
                }
                resolve(data);
            },
            fail: function (data, code) {
                reject(`getStorage fail, code = ${code}`);
            }
        });
    });
}

export function deleteStorage(key) {
    return new Promise((resolve, reject) => {
        storage.delete({
            key,
            success: function (data) {
                resolve(`deleteStorage success`);
            },
            fail: function (data, code) {
                reject(`deleteStorage fail, code = ${code}`);
            }
        });
    });
}

export function clearStorage() {
    return new Promise((resolve, reject) => {
        storage.clear({
            success: function (data) {
                resolve(`clearStorage success`);
            },
            fail: function (data, code) {
                reject(`clearStorage fail, code = ${code}`);
            }
        });
    });
}
