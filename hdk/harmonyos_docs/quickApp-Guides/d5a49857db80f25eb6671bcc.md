# 步骤条组件

## 简介

步骤条（steps）组件常用于描述一件事情从起始到结束的过程，电商购物物流场景使用居多。步骤条一般具有如下特点：

* 可设置横向排列或纵向排列
* 可突出显示当前步骤
* 可显示事件轴

基本布局代码如下：

```screen
<template>
  <div class="container">
    <text class="section">横向排列</text>
    <steps class="stepcss" options="{{list2}}" active-color="#007AFF" active="{{active}}" direction="row"></steps>
    <text class="section">纵向排列</text>
    <steps if="{{isShow}}}" class="stepcss" options="{{list2}}" active-color="#007AFF" active="{{active}}" direction="column"></steps>
  </div>
</template>
```

## 开发指引

### 自定义子组件

1. 定义布局样式。 步骤条整体外观都是通用的，但是内部具体的样式有区别，在设计的时候，不能把内部样式固定，否则一旦步骤条的UI有变化，会导致子组件也要修改，违背了对外开源的初衷。

   所以，在子组件steps.ux中，开放多种样式属性，方便开发者自定义样式。

   ```screen

             <div if="{{computed}}" class="steps_column-line-item" for="{{listoptions}}">
               <image if="$idx==active" class="steps_column-imgcheck"></image>
               <image else class="steps_column-imgcircle"></image>
               <div if="$idx!=options.length-1 && computed" class="steps_column-line" style="height: {{$item.lineHeight}}px;"></div>
                <!-- <div if="$idx!=options.length-1 && computed" class="steps_column-line" style="height:100%;"></div> -->
   ```

2. 规划属性和支持的事件。

   支持的属性：

   |**属性**|**类型**|**默认值**|**描述**|
   |:------------|:-----|:------|:--------|
   |direction|String|column|步骤排列方向。|
   |options|Array|-|事件源。|
   |active|Number|0|当前步骤。|
   |activeColor|Color|#1aad19|激活状态的颜色。|
   |deactiveColor|Color|#999999|未激活状态的颜色。|

   支持的事件：

   无

### 实现横向排列

1. 整体布局是"事件源布局"+"事件轴布局"组合起来的竖向布局。
2. "事件轴布局"是横向布局，"事件源布局"是横向布局。
3. 使用for循环形成列表布局。
4. 事件轴的起点（灰色小圆点）设置于起始事件的中心位置，然后计算事件轴左右距离根节点的宽度。
5. 两个小圆点之间的宽度和每个事件的宽度相同，需要计算所有事件布局的宽度之和，然后计算每个事件轴的宽度，代码如下：

   ```screen
   calRowItemWidth(len) {
     var that = this;
     this.$element('rowroot').getBoundingClientRect({
       success: function (data) {
         console.log('calRowItemWidth  getBoundingClientRect succeeded, result data =' 
         + JSON.stringify(data));
         that.row_list_item_width = data.width / len ;
         that.lineleft = that.row_list_item_width / 2 ;
         console.info("calRowItemWidth= " + that.row_list_item_width);
         that.computed = true;
       },
       fail() {
         console.log('getBoundingClientRect failed');
       },
       complete: function () {
         console.log('getBoundingClientRect completed');
       }
     });
   }
   ```

### 实现纵向排列

1. 整体布局是"事件轴布局"+"事件源布局"组合起来的横向布局。
2. "事件轴布局"是竖向布局，"事件源布局"是竖向布局。
3. 使用for循环形成列表布局。
4. 左侧事件轴的高度取决于右侧内容所占用的空间，若要保证事件轴上每个小圆点都与事件源水平对齐，可通过组件的[getBoundingClientRect](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-methods-0000001123690168#section20440806481)方法获取右侧每个事件源的高度，然后赋值给相应变量，代码如下：

   ```screen
   calLineHeight(optionItem) {
     var that = this;
     this.$element(optionItem.itemId).getBoundingClientRect({
       success: function (data) {
         console.log('getBoundingClientRect succeeded, result data =' 
         + JSON.stringify(data));
         let lineHeight = data.height - 10;
         optionItem.lineHeight = lineHeight;
         that.computed = true;
       },
       fail() {
         console.log('getBoundingClientRect failed');
       },
       complete: function () {
         console.log('getBoundingClientRect completed');
       }
     });
   },
   ```

   > 注意
   >
   > getBoundingClientRect( )方法只能在页面渲染后才可以计算出组件的宽高值，在页面生命周期调用时，一般要延时200ms左右。

> 说明
>
> 步骤条每个事件源高度和事件轴高度是根据自身内容来动态适配的，没有将高度固定。由于轴线高度、宽度值计算受限于渲染后，当计算出结果时，界面刷新，可能会出现界面闪一下的效果。
>
> 如果您的每个事件源内容少，建议固定高度，省去一些计算步骤。
