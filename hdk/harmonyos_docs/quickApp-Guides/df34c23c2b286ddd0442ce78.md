# 新增互联网信息

在华为云核准（备案）系统中已核准（备案）的主体下新增快应用信息。操作步骤如下：

1. 进入[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，登录华为云核准（备案）系统，左侧菜单栏点击"我的核准（备案）"，右侧页面点击"新增互联网信息"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/madAr0dNQaCu8ObAPn2gBQ/zh-cn_image_0000001997092973.png?HW-CC-KV=V1&HW-CC-Date=20260909T150756Z&HW-CC-Expire=31536000000&HW-CC-Sign=F51496399EB9E7EFFE5EEA651B54BAB210AE8BDB5B23668F1A60F99E6CF08298 "点击放大")
2. 在"产品验证"页面填写快应用信息，完成后点击"验证"。在弹出的窗口中点击"下一步"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/-nQvy-crQfqOQyw7k9Y1SA/zh-cn_image_0000001960493882.png?HW-CC-KV=V1&HW-CC-Date=20260909T150756Z&HW-CC-Expire=31536000000&HW-CC-Sign=0D12D729F4133BD073599A9DA5617E7B3BBF4BC30BB425819997317AFE425D7C "点击放大")

3. 在"主体信息"页面校对主办单位信息、负责人信息，若有误请及时修改，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/PrsyoEGBRj2T0-DNzjZsCQ/zh-cn_image_0000001960656302.png?HW-CC-KV=V1&HW-CC-Date=20260909T150756Z&HW-CC-Expire=31536000000&HW-CC-Sign=6777497F20281A5A428F5B027BCA7BF0182B040D22DF65E1BE2921B4FED055FB "点击放大")

4. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/BaJ87IZJSnSZwS7vH_bL2A/zh-cn_image_0000001997218153.png?HW-CC-KV=V1&HW-CC-Date=20260909T150756Z&HW-CC-Expire=31536000000&HW-CC-Sign=A0EE358DC6DB35DC5A8EE25F8B6926F848B3C70E42B63D8CE576E8EE8E8B4E53 "点击放大")

5. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/_OcWoN5sQkaGKjA2vCd0aQ/zh-cn_image_0000001997219481.png?HW-CC-KV=V1&HW-CC-Date=20260909T150756Z&HW-CC-Expire=31536000000&HW-CC-Sign=25E1A316EA4D904FF5247633C6155714E0C6DEAC8374EC3ED7488FC7608443CF "点击放大")

6. 在"真实性核验"页面由互联网信息负责人进行人脸视频认证，完成后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/788IQOZYRwa2p5w7_rqkIA/zh-cn_image_0000001960501070.png?HW-CC-KV=V1&HW-CC-Date=20260909T150756Z&HW-CC-Expire=31536000000&HW-CC-Sign=F0E9258CDC6C593C188267A98C373A9254D850C2F21962795A1A24332DA25096 "点击放大")

7. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。
8. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-icp-checkmessage-0000001820059249)。
