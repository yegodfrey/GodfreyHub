# 自动补全

相比于旧版 FIDE 开发者工具， Huawei Studio 提供了较为完善的自动补全功能，

js 文件编辑会帮助开发者补全所有的 API 及相关的注释解释，并提供代码模板支持，

wxml 文件编辑会帮助开发者直接写出相关的标签和标签中的属性，

json 文件编辑会帮助开发者补全相关的配置，并给出实时的提示。
