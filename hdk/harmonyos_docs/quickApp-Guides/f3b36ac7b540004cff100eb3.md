# 快应用分享

## 简介

开发者都希望自己的快应用能够借助用户的分享行为获得更多的曝光和流量。快应用在1030版本规范（华为快应用中心1.0.8）中提供了 [system.share](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-api-share-0000001074751847) 和 [service.share](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-api-thirdshare-0000001074424277) 两个分享接口。开发者可以使用它们向用户提供分享功能，将开发者自定义的图文内容分享到微信、微博等社交平台；用户点击分享链接、或识别分享图片中的二维码后，即可跳转到指定的网页或快应用。

## 分享文字

如果初期您需要向用户推广的信息比较简单，比如仅包含产品介绍，或者再加上一个访问应用的链接，您可以使用单纯的文字分享。

## 分享本地图片

如果觉得纯文字太过于单调，您可以将产品推广内容制作为一张图片，存放在项目的某个目录下，以图片的形式分享给用户。

### 运用场景

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230306172244.19753671170448466040066980252925:50001231000000:2800:9CDF828D6C91D53F093B4E3261930835B87E38EDB305575F3E05844AA8B3FDED.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

### 示例代码

```screen
shareWithImg(){
    share.share({
        type: "image/jpeg",
        data: "/Common/img/demo.jpg",
        fail: function (data, code) {
            console.log("handling fail, code = " + code);
        }
    })
}
```

* Type："image/jpeg"，表示分享内容为图片。
* Data：图片存放的本地目录。

> 说明
>
> 分享图片不能添加链接，建议将需要跳转的URL生成二维码嵌入在图片中，方便用户通过识别二维码访问对应的链接。

## 分享在线图片

如果产品网站上有现成的图片可以推广给用户，您也可以直接分享在线图片。

### 运用场景

当前分享能力不支持直接分享在线图片，要实现此效果，可以先将图片下载至本地，分享下载到本地的图片，最后删除下载的图片。

### 示例代码

```screen
shareLiveImg(){
    // 下载图片
    fetch.fetch({
        url: 'http://rallyox.iok.la/zhishixunlian/logo.png',
        success: function (data1) {
            console.log("code: " + data1.code);
            console.log("data: " + data1.data);
            // 分享下载了的文件
            share.share({
                type: "image/jpeg",
                data: data1.data,
                fail: function (data, code) {
                    console.log("handling fail, code = " + code);
                }
            });
        },
        fail: function (data, code) {
            console.log("handling fail, code = " + code);
        }
    })
}
```

> 说明
>
> 分享图片不能添加链接，建议将需要跳转的URL生成二维码嵌入在图片中，方便用户通过识别二维码访问对应的链接。

## 分享图文信息

在前面的分享场景中，或分享内容样式过于单一，或无法添加链接引导用户访问快应用，有没有两者兼顾的方法呢？当然有，分享图文信息可以满足您的需求。

在图文信息中，您可以设置分享内容的主题、分享的详细内容、配上您满意的图片，并加上访问您应用的链接。

### 运用场景

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230306172245.99197119746957976773348714238675:50001231000000:2800:02C5FFFD1639FD45F6DFE1513B4C03D750E19144F9346CFA59F62EDC17A49101.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

### 示例代码

```screen
shareWithImgText(){
    service_share.share({
        shareType: 0,
        title: '知识训练',
        summary: "助您对需要掌握的知识进行针对性训练，让你在学习工作中不断进步，节节高升~ ",
        imagePath: '/Common/logo.png',
        targetUrl: 'http://rallyox.iok.la/wangyetiaozhuan.html',
        fail: function (data, code) {
            console.log('handling fail, code = ' + code);
        }
    })
}
```

* Title：分享内容的主题（标题）。
* Summary：分享的详细内容。
* imagePath：分享图片的本地路径。
* targetUrl：点击分享内容跳转的URL。

## 分享快应用

除了可以使用自定义的方式推广快应用，您还可以使用快应用默认的分享功能。

### 运用场景

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230306172245.80972613210458719496349772408770:50001231000000:2800:02A870468D81B8418B78E9BC1E0997DC3AF940BF9F0B36534AC6BFF43FD32A6C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

### 配置方法

使用默认的分享功能，您只要进行如下简单配置即可：

1. 将快应用manifest文件中需要分享页面的menu设置为true。
2. 在需要分享页面对应的ux文件中请勿处理onMenuPress回调，否则该页面将无法显示默认菜单。

> 说明
>
> 1. 使用默认分享功能，分享的内容和形式由系统决定，包含快应用名称、快应用简介、快应用图标和快应用的链接。
> 2. 新版加载器打开不再集成分享功能，只有现网的快应用打开才能分享。
