## 准入条件

接入华为推送服务前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 在AppGallery Connect上已[开通推送服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-push-kit-0000001079643916)。
* 华为推送服务是华为扩展接口，而非厂商联盟规范，请[安装华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)进行接入。

## 接入指引

调用[push.requestSubscribeMessage](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-push-0000001074632507#section1083716481285)接口，获取用户的订阅结果。

● 订阅结果为acceptOnce：同意一次，同意次数可累加。接收到一次该模板的消息后同意次数减1，减至0后恢复未订阅状态。

● 订阅结果为acceptAlways：同意且不再询问。后续该模板的消息均为服务消息。

● 订阅结果为rejectOnce：拒绝一次。接收到一次该模板的消息后不会推送给用户，并恢复未订阅状态。

● 订阅结果为rejectAlways：拒绝且不再询问。接收到该模板的消息均不会推送给用户。

● 未订阅状态：消息以普通PUSH消息形式推送给用户。

## 发送服务消息

### 前提条件

满足如下条件的快应用才可以接收到服务消息：

* 快应用中心必须有快应用使用记录。
* 如果使用华为快应用加载器进行调试，必须确保加载器进程处于运行状态，且必须有快应用使用记录。
* 如果手机安装了手机管家，请务必在"自启动"选项中，将快应用中心的开关打开。

### 发送服务消息

发送服务消息涉及两个接口：获取accessToken接口和发送服务消息接口。
> 说明
>
> * 每天发送的次数没有限制，每次最多同时向1000个设备发送消息。
> * 为了提升用户体验，减少对用户的打扰，同一款快应用每天只能向同一用户推送5条服务消息。

**获取accessToken接口**

详细接口介绍，请参见"[基于OAuth 2.0开放鉴权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981)"。

**发送服务消息接口**

该接口用于发送服务消息。

承载协议：HTTPS POST

接口访问地址：https://push-api.cloud.huawei.com/v1/*[clientid]*/messages:send
> 说明
>
> **[clientid]** ：Oauth2.0客户端ID（凭据），登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"我的项目"，在项目列表中选择对应的项目，左侧导航栏选择"项目设置"，在该页面获取。

接口请求参数（HTTP header）

|**参数**|**样例**|**说明**|
|:------------|:----------------------------------------------------------------------------------------------|:-------------------------------------------------------------|
|Content-Type|application/json|--|
|Authorization|Bearer CF3Xl2XV6jMKZgqYSZFws9IPlgDvxqOfFSmrlmtkTRupbU2VklvhX9kC9JCnKVSDX2VrDgAPuzvNm3WccUIaDg==|Bearer后面拼接空格，再拼接对获取的access_token（如果access_token中包含\，必须去除所有的\）。|

请求参数说明

|**参数**|**取值类型**|**可选/** **必选**|**描述**|
|:------------|:-------|:-------------|:------------------------------------------------------------------------------------------------------------|
|validate_only|boolean|可选|控制当前是否为测试消息，测试消息只做格式合法性校验，不会推送给用户设备，取值如下： * true：测试消息 * false：正式消息 默认值是false。|
|message|Object|必选|推送消息结构体，message结构体中必须要有有效消息负载以及有效发送目标，具体字段请参考"[message结构体说明](#ZH-CN_TOPIC_0000001376397788__p1184301171516)"。|

message结构体说明

|**参数**|**取值类型**|**可选/** **必选**|**描述**|
|:------|:-------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|data|string|必选|描述服务消息JSON结构体，包括服务消息的类型、内容、点击动作、报表统计和扩展信息，详细内容请参见"[data样例](#ZH-CN_TOPIC_0000001376397788__p1984413121515)"和"[data结构体说明](#ZH-CN_TOPIC_0000001376397788__p1944383211816)"。|
|android|object|必选|Android消息推送控制参数，具体字段请参考"[AndroidConfig结构体说明](#ZH-CN_TOPIC_0000001376397788__p4447153211183)"。|
|token|array|必选|推送消息目标用户的pushtoken，每个pushtoken都为快应用通过subscribe接口获取到的regId： ["pushtoken1","pushtoken2"]|

|:----------------|:----------|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
|pushtype|integer|data|是|* 0：通知栏消息 * 1：透传消息|
|pushbody|json object|data|是|-|
|title|string|pushbody|否|服务消息标题，pushtype为0时有效。 > 注意 > 当一条消息被视为服务消息后，会使用[消息模板](#section8779124215231)中的标题代替title字段内容作为消息标题。 > 建议title字段内容与消息模板中的标题保持一致，避免未识别成服务消息时，该条消息以普通PUSH消息形式发送。|
|description|string|pushbody|否|服务消息内容，pushtype为0时有效。|
|page|string|pushbody|否|点击通知栏消息需要跳转到的快应用界面的path，pushtype为0时有效。 只支持配置在manifest文件中定义的路由页面，不支持配置H5页面的url。|

AndroidConfig结构体说明

|**参数**|**取值类型**|**可选/必选**|**描述**|
|:--------------|:-------|:--------|:---------------------------------------------------------------------------------------|
|fast_app_target|integer|必选|快应用的加载模式类型，取值如下： * 1：加载器方式 * 2：引擎方式 开发调试阶段，需要给华为快应用加载器发送服务消息时，请将此值设置为1。在提交正式上架前请将此值设置为2。|

服务消息体示例代码如下：

```screen
var mData = {
    "pushtype": 0, //0表示通知栏消息
    "pushbody": {
        "title": "服务消息的标题",
        "description": "服务消息的详细内容",
        "page": "/", //点击通知栏消息需要跳转的快应用界面的path，pushtype为0时有效。"/"表示跳转到应用首页
        "params": {
            "key1": "test1",
            "key2": "test2"
        },
        "templateId": "100001",
    }
};
var formatJsonString = JSON.stringify(mData);
var messbody = {
    "validate_only": false,
    "message": {
        "data": formatJsonString, //需要注意data类型是JsonString类型，非json对象
        "android": {
            "fast_app_target": 1, // 1表示向运行在加载器上的快应用发送服务消息，给上架应用市场的快应用发送服务消息时，此值要设置为2。
            "collapse_key": -1,
            "delivery_priority": "HIGH",
            "ttl": "1448s",
            "bi_tag": "Trump",
         },
         "token": ['pushtoken1','pushtoken2'], //消息推送的目标用户
    }
};
```

## 错误码说明

### HTTP协议错误码

|**错误码**|**描述**|**解决措施**|
|:------|:-------|:---------------------------------------|
|200|成功。|不涉及。|

|401|鉴权失败。|请检查HTTP头中Authorization参数里面的Access Token。|
|404|找不到服务。|请检查请求url是否正确。|
|500|服务器系统错误。|请联系华为技术支持人员。|
