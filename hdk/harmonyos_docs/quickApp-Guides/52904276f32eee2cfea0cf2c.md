# 文本翻译

#### 简介

文本翻译能力是由华为机器学习服务（ML Kit）提供的一项能力，支持将源语言文字翻译为目标语言文字。

目前支持中文简体、中文繁体、英语、法语、阿拉伯语、泰语、西班牙语、土耳其语、葡萄牙语、日语，德语、意大利语、俄语、波兰语、马来语、瑞典语、芬兰语、挪威语、丹麦语、韩语20种语言文字在线互译。

在使用文本翻译能力时，您需要参考：[华为机器学习服务隐私申明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/android-sdk-ys-0000001222765290)和[个人数据处理说明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/android-sdk-hg-0000001720566121)，处理用户数据。  

#### 准入条件

接入文本翻译前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 在AppGallery Connect上已[开通机器学习服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-ml-kit-0000001126700645)。

<script>
    import translate from "@service.ml.translate";
    import prompt from "@system.prompt";
    module.exports = {
        data: {
            title: "Text translation services",
            failed: "",
            text: "",
            sourceLanguageCode: "",
            targetLanguageCode: "en",
            sourceText: ""
        },
        update_sourceLanguageCode: function (e) {
            let value = e.newValue ? e.newValue : e.text;
            this.sourceLanguageCode = value;
        },

        update_sourceLanguage: function (e) {
            let value = e.newValue ? e.newValue : e.text;
            this.sourceText = value;
        },

        update_targetLanguageCode: function (e) {
            let value = e.newValue ? e.newValue : e.text;
            this.targetLanguageCode = value;
        },
        translate: function () {
            translate.translate({
                appId: '103913469',
                apiKey: "CgB6e3x9805WIU1KE8lnMBc+ka/A5sJ5DBKsSzGGkYuV7E/GxY18tAdAM5Zc5hg48CKW4kzmfarv75bRdiDe4RhK",
                sourceLanguageCode: this.sourceLanguageCode,
                targetLanguageCode: this.targetLanguageCode, 
                sourceText: this.sourceText, 
                success: text => {
                    this.text = text;
                    this.failed = "";
                },
                fail: (errMsg, errcode) => {
                    prompt.showToast({ message: "translate failed:" + errMsg });
                    this.failed = errMsg;
                }
            });
        },
        clear: function() {
            this.text = "";
            this.sourceText= "";
            this.failed = "";
        }
    };
</script>
