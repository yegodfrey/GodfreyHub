# 商品导航组件

## 简介

商品导航组件主要用于电商类应用底部导航，可自定义进入店铺、查看购物车、加入购物车、购买等操作。商品导航一般具有如下特点：

* 有店铺、购物车、加入购物车、立即购买等按钮
* 可根据需要定制显示的内容、样式等

商品导航（goods_nav）组件结构可分为左侧信息显示区和右侧点击加购区两部分。一般来说，左侧布局可以循环渲染传入的数据，右侧提供可点击的按钮触发相应事件。布局结构如下图：

```screen
<div class="container">
  <div style="flex-direction: column">
    <text style="height: 80px;width: 100%;font-weight: bold;">基础用法</text>
```

## 开发指引

### 自定义子组件

1. 定义布局样式。 商品导航整体外观都是通用的，但是内部具体的样式有区别，在设计的时候，不能把内部样式固定，否则一旦商品导航的UI有变化，会导致子组件也要修改，违背了对外开源引用的初衷。

   所以，在子组件goods_nav.ux中，开放多种样式属性，方便开发者自定义样式。

   ```screen
   <template>
       <div class="goods-body">
         <div style="width: {{value}}px">
           <!-- 循环渲染options -->
           <stack for="options" class="div1" onclick="handle($idx,$item)">
             <text class="{{ $item.info ? txt1 : txt2 }}">{{ $item.info }}</text>
             <image src="{{ $item.icon }}" class="photo"></image>
             <text id="text2">{{ $item.text }}</text>
           </stack>
         </div>
         <div style="width: {{value1}}px; " class="list1">
           <div style="justify-content: center;">
             <!-- 循环渲染buttongroup -->
             <block for="buttongroup">
               <text onclick="button($idx,$item)" style="color:{{$item.color}};text-align: center;background-color: {{$item.backgroundColor}};" 
               class="{{this.fill ==='true'? 'buttongroup'+($idx+1) : buttongroup0}}">{{ $item.text }}</text>
             </block>
           </div>
         </div>
       </div>
   </template>
   ```

2. 规划属性和支持的事件。 支持的属性：

   |**属性**|**类型**|**默认值**|**描述**|
   |:----------|:------|:------|:--------|
   |options|Array|-|可选内容的配置项。|
   |buttongroup|Array|-|按钮组的配置项。|
   |fill|Boolean|false|按钮是否有圆角。|

   options配置项：

   |参数|**类型**|**默认值**|**描述**|
   |:---|:-----|:------|:-------|
   |text|String|-|文字。|
   |icon|String|-|图标。|
   |info|Number|-|右上角数字角标。|

   buttongroup配置项：

   |参数|类型|**默认值**|**描述**|
   |:--------------|:-----|:------|:------|
   |text|String|-|按钮文字。|
   |backgroundColor|String|-|按钮背景色。|
   |color|String|-|按钮文字颜色。|

   支持的事件：

   |**事件名称**|参数|**描述**|
   |:----------|:-|:---------|
   |handleclick|无|左侧内容的点击事件。|
   |buttonclick|无|右侧按钮的点击事件。|

### 父子组件通信

1. 父组件中定义点击事件并绑定。

   ```screen
   <goods_nav options="{{options1}}" buttongroup="{{buttongroup}}" @handleclick="onClick" @buttonclick="buttonClick1"></goods_nav>
   ```

   ```screen
   onClick(e) {
     console.log(JSON.stringify(e));
     prompt.showToast({
       message: "点击了" + e.detail.item.text,
       duration: 2000,
       gravity: 'center'
     })
   },
   buttonClick1(e) {
     console.log(JSON.stringify(e));
     this.options1[this.options1.length - 1].info++
   },
   ```

2. 子组件通过this.$emit方法携带事件及参数通知父组件。

   ```screen
   handle(index, item) {
     console.log("handleclick", index, item);
     this.$emit('handleclick', {
       item, index
     })
   },
   button(index, item) {
     console.log("buttonclick", index, item);
     this.$emit('buttonclick', {
       item, index
     })
   },
   ```
