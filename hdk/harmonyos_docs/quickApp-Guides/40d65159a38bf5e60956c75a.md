# manifest配置文件

## manifest文件

manifest.json配置文件包含了快游戏描述、接口声明、页面路由等信息。

|属性|类型|必填(M)/选填(O)|描述|
|:-----------------|:------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|package|string|M|快游戏包名。|
|name|string|M|快游戏名称。|
|appType|string|M|快游戏类型： 快游戏**填写** **fastgame**。|
|icon|string|M|快游戏图标。必须与AGC控制台上架审核的图标保持一致。|
|versionName|string|O|应用版本名称。例如"1.0"。|
|versionCode|integer|M|应用版本号。从1自增，每次重新上传包后必须versionCode加1，否则将影响上架版本的更新，例如原版本为11，更新版本的versionCode必须为12。|
|minPlatformVersion|integer|M|支持的最小平台版本号，默认值是1000。属于兼容性检查，避免上线后在低版本平台运行出现不兼容的问题。 > 说明 > 若快游戏引擎低于该值时，打开**快应用中心** 或**花瓣轻游** 的快游戏将有弹框提示用户更新到最新版本。若用户选择不更新，将直接退出**快应用中心** 或**花瓣轻游**。|
|config|object|M|系统配置信息，详情请参见[config参数](#section829569145720)。|
|display|object|O|UI显示配置，详情请参见[display参数](#section6321102611211)。|
|subpackages|object|O|定义并启用分包加载，详情请参见[subpackages参数](#section49093457219)。|

### config参数

用于定义系统配置和全局数据。

|属性|类型|必填(M)/选填(O)|默认值|描述|
|:-------|:-----|:----------|:--|:------------------------------------------------|
|logLevel|string|M|log|日志打印等级： * off * error * warn * info * log * debug|

### display参数

用于定义与UI显示相关的配置。
> 说明
>
> 大屏设备仅支持fullScreen设置为true、orientation设置为landscape。

|属性|类型|默认值|描述|
|:-------------------------|:-----------------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|backgroundColor|string|#ffffff|窗口背景颜色。|
|fullScreen|boolean|false|是否全屏模式。全屏模式下将覆盖状态栏。|
|menu(1076+)|boolean|false|是否显示右上角菜单按钮。从1076平台版本开始将固定显示菜单，不支持自定义菜单内容。|
|windowSoftInputMode(1030+)|adjustPan | adjustResize|adjustPan|软键盘弹出时，为了保证页面的输入框可见，当前页面的调整方式： * adjustPan：上移页面。 * adjustResize：压缩页面的显示区域。若页面全屏，此设置项不生效。|
|pages|object|-|页面的显示样式。|
|orientation|string|portrait|页面显示方向： * portrait：竖屏。 * landscape：横屏。 * auto(1070+)：受手机系统自动旋转开关的控制。若设置auto，建议使用[响应式布局](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-responsive-layout-0000001082763996)开发。|

### subpackages参数

用于定义分包的相关配置。分包的使用指导请参见[分包加载](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-subpackage-0000001159658271)。

|属性|类型|描述|
|:-------|:-----|:----------------------------------------------------------------------------------------------------|
|name|string|分包名称。名称只能是字母数字和下划线，不允许包含其它符号。"base"是基础包的保留名称，您无需为基础包定义分包配置。|
|resource|string|分包资源根目录，相对于源码目录"src"的相对路径。根目录只能是字母数字以及"_"、"-"、"/"组成，第一个字符不允许为"-"和"/"，不允许包含其它符号。编译时会把该目录下的所有资源都打包到分包中。|

## 示例代码

```screen
{
  "package": "com.company.unit",
  "name": "appName",
  "icon": "/Common/icon.png",
  "versionName": "1.0",
  "versionCode": 1,
  "minPlatformVersion": 1000,
  "config": {
    "logLevel": "off"
  },
  "display": {
    "backgroundColor": "#ffffff",
    "fullScreen": false,
    "pages": {
      "Hello": {
        "backgroundColor": "#eeeeee",
        "fullScreen": true,
      }
    }
  },
  "subpackages": [
      {
          "name": "pkgA",
          "resource": "PackageA"
      },
      {
          "name": "pkgB",
          "resource": "PackageB"
      }
  ],
}
```
