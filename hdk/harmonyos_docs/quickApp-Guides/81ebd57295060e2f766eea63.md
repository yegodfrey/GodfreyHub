# 技术支持

若在开发快游戏时遇到问题，您可以按照以下顺序寻求帮助：

1. 请先仔细阅读文档，部分功能可能有限制。
2. 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-faq-0000001112830270)、[案例](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-case-0000001112670384)，寻找类似问题的解决方案。
3. 通过[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
4. 登录[华为开发者论坛](https://developer.huawei.com/consumer/cn/forum/block/ag-connect)参与问题讨论。
5. 若以上方法仍未解决问题，您可以通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/202200004?level2=91&level3=2022000030)与我们进行联系。提交工单后，您可以登录[华为开发者联盟官网](https://developer.huawei.com/consumer/cn/)，鼠标置于右上角头像处，在下拉框内点击"我的客服"查看工单处理进展。
