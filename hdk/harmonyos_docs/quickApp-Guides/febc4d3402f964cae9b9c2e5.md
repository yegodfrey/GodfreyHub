# 快应用快速出海

#### 出海限制

#### 功能限制

目前快应用发布中国大陆以外地区时，如下组件、接口暂不支持，请发布前屏蔽以下内容。

* 地图组件：map
* 华为AI接口：system.ai
* 微信支付接口：service.wxpay
* 支付宝支付接口：service.alipay
* 第三方分享接口：service.share  

#### 工具限制

建议访问"[安装开发工具](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-installtool-0000001126543467)"，安装最新版本的华为快应用IDE和调试运行在手机/平板的快应用的加载器。

#### 语言适配

快应用发布多个国家地区时，需要适配对应国家/地区的不同语言，适配方式参见"[多语言支持](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-multi-language-0000001126443983)"；如果发布的国家/地方使用了镜像语言（例如阿拉伯语），则需要进一步进行"[镜像语言适配](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-lang-direction-adapt-0000001126445945)"。
