# 接入情景感知服务

## 简介

情景感知服务（Awareness Kit）为您提供获取用户当前时空、位置、活动状态等情景感知组合能力。调用这些能力，您的App可以通过更高效的方式，洞悉用户当前所处的情景，为用户提供更加智慧和贴心的体验。

当前快应用中支持了情景感知服务的位置感知能力，通过使用该能力，您可以基于用户位置，设定位置围栏，当用户进入、离开围栏，或在围栏中停留指定时长时，向用户推送围栏通知。例如：当用户进入某个商家，向其推送该商家的优惠信息。

## 准入条件

接入华为情景感知服务前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 在AppGallery Connect上已[开通情景感知服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-awareness-kit-0000001126441733)。

## 接入指引

### 判断是否支持情景感知服务

调用[awareness.getProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-awareness-0000001074914563#section1257919243710)接口，判断手机是否支持情景感知服务，如果返回空字符串，表示不支持此服务，此时请勿调用其他接口，否则将抛出异常；如果返回服务商代号，则可使用其他接口。

### 创建围栏

根据业务场景，创建对应的围栏。以下以创建进入的围栏（即用户从围栏外进入围栏内）为例，描述调用[awareness.enterLocationBarrier](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-awareness-0000001074914563#section18423199103515)创建进入围栏的样例。

```screen
awareness.enterLocationBarrier({
  notification: {
    contentTitle: 'title',
    contentText: 'content',
    clickAction: {
      uri: 'Hello/AutoAwareness'
    }
  },
  key: 'enterLocationBarrier',
  latitude: '31.976427',
  longitude: '118.75277',
  radius: '200',
  success: function () {
    console.log('enterLocationBarrier---success');
  },
  fail: function (data, code) {
    console.log(JSON.stringify(data + ', code = ' + code));
  }
})
```

也可以分别调用[awareness.exitLocationBarrier](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-awareness-0000001074914563#section1928445754816)，[awareness.stayLocationBarrier](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-awareness-0000001074914563#section82131574617)创建离开的围栏和停留的围栏。

### 添加围栏

调用[awareness.addBarrier](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-awareness-0000001074914563#section3942145813101)将前面创建的围栏注册到情景感知服务里。此时，围栏才真正注册成功。

```screen
awareness.addBarrier({
  appId: '101449471',
  key: 'enterLocationBarrier',
  autoRemove: true,
  success: function () {
    console.log('addBarrier---success');
  },
  fail: function (data, code) {
    console.log(JSON.stringify(data + ', code = ' + code));
  }
})
```

### 触发围栏通知

围栏添加成功后，以进入围栏为例，当用户进入创建围栏的区域内，则触发一个通知，通知的内容和点击动作在创建围栏时的notification中定义。例如发送用户一条优惠通知消息，用户点击通知消息则打开快应用内优惠详细信息的页面。

### 查询围栏状态

调用[awareness.getBarrierLastStatus](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-awareness-0000001074914563#section17514144441916)查询围栏的状态。以查询进入围栏状态为例，当进入围栏瞬间查询状态为1（true），进入后状态为0（false），若查询过程中出现未获取经纬度或者没有信号的情况，则查询状态为2（unknown）。

```screen
awareness.getBarrierLastStatus({
  appId: '101449471',
  key: 'enterLocationBarrier',
  success: function (data) {
    console.log(data.status);
  },
  fail: function (data, code) {
    console.log(JSON.stringify(data + ', code = ' + code));
  }
})
```

### 删除围栏

当不再需要使用创建的围栏时，可以调用[awareness.deleteBarrier](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-awareness-0000001074914563#section944322651611)删除此围栏，避免对用户造成干扰。

```screen
awareness.deleteBarrier({
  appId: '101449471',
  key: 'enterLocationBarrier',
  success: function () {
    console.log('deleteBarrier---success');
  },
  fail: function (data, code) {
    console.log(JSON.stringify(data + ', code = ' + code));
  }
})
```
