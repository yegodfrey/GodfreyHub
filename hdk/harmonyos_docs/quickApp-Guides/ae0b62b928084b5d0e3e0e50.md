# 新增接入

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面接入快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/XHrXv3pJQnWiNw0Vj_PeBw/zh-cn_image_0000001885068697.png?HW-CC-KV=V1&HW-CC-Date=20261008T191227Z&HW-CC-Expire=31536000000&HW-CC-Sign=076697FB39F956CF88CD1E3A3A313B64D5784F5DAE99936894B70711B1DFC53A)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/07/v3/FYLQa_IDSLalV2viK_vi5Q/zh-cn_image_0000001838749110.png?HW-CC-KV=V1&HW-CC-Date=20261008T191227Z&HW-CC-Expire=31536000000&HW-CC-Sign=C09ABF04FEE6684830F22DB2DA9556AF67DFFA017BF3B092FA17C2DFA64EEC33)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e/v3/UYMT3w_6Sjmzp96Z-nzvwQ/zh-cn_image_0000001838749298.png?HW-CC-KV=V1&HW-CC-Date=20261008T191227Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CA33D7B4E5AA6F2F0388803DF72BD336923087F0E49127D7CBF41FC7C46710C)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/niH-LXlHS2-1vdGZXx6IbQ/zh-cn_image_0000001803737948.png?HW-CC-KV=V1&HW-CC-Date=20261008T191227Z&HW-CC-Expire=31536000000&HW-CC-Sign=251542C5A7EB9E9B71D8E2F980C162FBD71B62F3D36CC95004C476175C82ADE6)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/eqLWSUB5T0i59K8xfdV2fA/zh-cn_image_0000001838908218.png?HW-CC-KV=V1&HW-CC-Date=20261008T191227Z&HW-CC-Expire=31536000000&HW-CC-Sign=60C2056ADCE8797F5A2DF1200FD392028C668423C7E54538EEE608E307403E63)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
