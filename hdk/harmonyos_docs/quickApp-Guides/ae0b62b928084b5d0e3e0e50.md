# 新增接入

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面接入快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/XHrXv3pJQnWiNw0Vj_PeBw/zh-cn_image_0000001885068697.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=72B4FA4E5EB69F12708482CAF3641FC7ACED9D9BB9EE189B570879AA2AF2A3EA)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/07/v3/FYLQa_IDSLalV2viK_vi5Q/zh-cn_image_0000001838749110.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=373724E061DD61C80C9D5AA54C659AFC1246746B0FA3E98A9D9FD594BD9E3A56)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e/v3/UYMT3w_6Sjmzp96Z-nzvwQ/zh-cn_image_0000001838749298.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=499328DE9CB0009A77C882C735CADBD83E69C22C83D5D2E69519D852DF7A9C2B)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ee/v3/niH-LXlHS2-1vdGZXx6IbQ/zh-cn_image_0000001803737948.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=49D5E1442E1E864D9DE351C6EB211F6D959B060FE1F64745B1C1D9A5BB3B5AEB)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/eqLWSUB5T0i59K8xfdV2fA/zh-cn_image_0000001838908218.png?HW-CC-KV=V1&HW-CC-Date=20260909T181014Z&HW-CC-Expire=31536000000&HW-CC-Sign=982A856735CD11B7AF8A370C720F7161AC2C1790E5B7C96651D009F4C5934629)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
