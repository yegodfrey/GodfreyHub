# 开通推送服务（可选）

> 说明
>
> 如果需要接入华为推送服务，在开发前请先开通服务并获取服务相关参数，否则请忽略以下内容。

## 打开推送服务开关

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的项目"。

2. 点击待开通服务项目的卡片。
3. 选择"API管理"页签，打开 "推送服务"的开关。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181415.23488690760373476956791309422924:50001231000000:2800:06C7B880A5292EAC98B2B05BE6FCF08AF56C65D1568E092BDABCB8930DC351CD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

## 配置推送服务信息

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的项目"。
2. 点击待配置服务项目的卡片。
3. 左侧导航选择"增长 > 推送服务"，点击"立即开通"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181415.63703606087619335426382770234216:50001231000000:2800:49D71071CCCC2D1AA84CB4EC98695BC6F44DD484577BEB707CAAE8D07FAACD04.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

4. （如果不需要获取推送消息的发送状态，则无需进行以下步骤）点击"配置"页签，开通或关闭项目级和应用级的推送服务权益。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181415.10645247860359407311181413542388:50001231000000:2800:7DBAF9D1F12C55578F6DE5A9BE04E9B374418B8089358CC3BA46547520F90B7B.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)
