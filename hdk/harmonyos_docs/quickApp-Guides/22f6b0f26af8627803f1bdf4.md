小程序转换快应用
    1. 将测试手机与电脑成功连接，并打开“开发者调试”模式，打开“开发者模式”的方法请参见“[华为手机如何打开开发者选项](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-open-developer-option-0000001137005543)”。
    2. 打开华为快应用IDE，在欢迎页选择“导入项目 > 小程序”。![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111528.62917783609419526675281199480392:50001231000000:2800:34E9B7801E28FB59C0BECA88E6F626174AC308CD140D62AE1F3897429166BD26.png)
    3. 填写项目信息后，点击“确定”。
       * 小程序项目路径 ：选择需要转换小程序的存放路径。
       * 应用名称：桌面图标、弹窗等处显示的应用名称，可以和小程序相同。
       * 应用包名：发布的快应用为以.rpk为后缀的文件，此处即定义转换完成后，发布成快应用的包名。请勿与之前在华为应用市场上架过的应用包名重复。推荐采用com.company.module的格式，如：com.xyz.quickapp。包名由数字、小写字母、"."组成，必须以字母开头，以数字或字母结尾，同时必须包含"."，长度不能超过255字节。
       * 应用图标：应用市场或者桌面显示的应用图标，必须与提交上架审核的应用图标一致。
       * 导出路径：设置转换后项目存放路径。
    4. 转换完成后，将在设置的导出目录下生成一个对应的快应用项目。在项目的根目录下有一个transform.log文件，即本次转换的报告，里面包含了转换过程后，所有js文件中目前还不支持的接口记录，以及接口对应的文件路径信息和接口所在行、列信息，开发者可以根据此信息进行处理。![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111528.66513116744547599719225442351323:50001231000000:2800:AC2D9FCF53B9A48FC2F294435CF867736D64BF7B258454FC2816BE7BE1257BA5.png)
    5. 处理完 transform.log 文件中的提示信息后，还需要作如下调整。
       1. 按照IDE的错误提示对部分语法差异进行调整。例如：let 语法作用域、变量未定义使用、function、package关键字、：和v开头的变量。
       2. 对小程序私有变量进行调整。例如，__wxParseNodeId__在转换后的快应用不能使用，需要删除。
       3. 对项目进行编译，按照IDE底部“问题”页签输出的错误信息，修改错误内容。
       4. 修改非整型的px单位值为整型，例如0.5px修改为1px，否则渲染效果会有差异。
       5. 使用<toast></toast>组件的地方，使用qa.showToast代替实现。![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111528.65991052772009643777178790186982:50001231000000:2800:0BB749852AC56771EC4F2D09C363E36B66FA771807435020C19EB2D2E9B163CC.png) 编译过程中如需定位页面问题，可以使用[Webview调试工具](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-applet-to-quickapp-conver-guide-0000001126547703)进行调试。
       6. 如果接入小程序特有特性，需要修改为华为提供的能力。
          * 原来接入账号服务，需修改为[接入华为账号](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-applet-access-account-kit-0000001126445971)。
          * 原来接入支付服务，需修改为[接入应用内支付服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-applet-access-iap-kit-0000001161821217)。
          * 原来接入推送服务，需修改为[接入推送服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-applet-access-push-kit-0000001126790485)。
          * 原来接入小程序特有插件或者云开发，将无法继续使用，需使用自定义组件的方式代替。
       7. 如果是对百度小程序进行转换，需要做如下适配。
          * 快应用暂不支持 AOP机制，代码中使用 Page.after 等特性的地方请修改为在相应的生命周期函数中调用或者使用behaviors等其他方式替换。
          * 快应用暂不支持qa.nextTick()函数，您可以将nextTick中的逻辑放到下一个生命周期函数中执行。例如：在组件的created生命周期函数里存在qa.nextTick(() => this.fmtedMonth()); 这样的逻辑，请将此逻辑放到attached生命周期。
          * 快应用暂不支持自定义组件间使用dispatch方法通讯，可以使用triggerEvent方式替换。
          * 如果您在自定义组件中使用了slot，请注意slot节点内部的元素在快应用中是不会生效的。例如如下代码中text节点的内容在快应用中将不会展示。
                
                <slot name="text">
                    <text class="text text-class" bind:transitionend="aniEndHdl">{{text}}</text>
                </slot>

          * 如果您使用了switch组件，触发bindchange事件时，快应用返回的事件对象为event.detail={value} ，百度是 event.detail={checked}，请注意取值的差异。
       8. 如果是对支付宝小程序进行转换，需要做如下适配。
          * 默认情况下支付宝小程序中自定义组件可以直接使用页面的样式，但快应用中不可以，这可能会带来样式上的差异。如需使用，请在自定义组件中声明：
                
                options: {
                    styleIsolation: 'isolated'
                }

          * 自定义组件中如果使用了slot，请注意slot定义处声明的class在支付宝里是可以生效的，但快应用中不会生效，这与微信一致，请对这类样式做单独处理。
          * 自定义组件中快应用暂不支持$page、$slots属性，如有使用可能会因为无法取到有效值而导致业务问题，请自行去除并修改相关逻辑。
快应用国际化（可选） [h2]定义国际化应用资源采用 JSON 文件格式对 i18n 文本进行定义，在项目源文件下新建 i18n 目录。 目录结构如下： |—— dist // 快应用建目录 |—— package.json |—— src // 快应用源文件目录 |—— |—— app.js |—— |—— app.json |—— |—— app.qcss |—— |—— i18n // 国际化文本目录 |—— —— |—— defaults.json |—— —— |—— en-US.json |—— —— |—— zh-CN.json i18n目录下存放各种语言的国际化资源，文件命名参照[RFC3066标准](http://www.ietf.org/rfc/rfc3066.txt)和[ISO-639语言标准表](http://www.loc.gov/standards/iso639-2/)。命名可以包含一个基本语言和一个区域变种，语言和变种之间用下划线分隔，如“zh_CN”，“en_US”，区域变种非必选。快应用对于多个资源文件会按一定顺序进行匹配，例如：对于zh-CN，则按zh-CN -> zh -> zh-* -> defaults的顺序匹配，其中zh-*匹配到多个，则按字母升序区分大小写排序。defaults是默认语言（fallbackLocale），比如locale设置为zh-CN，但在zh相关的json中翻译不完整，而在defaults.json对应的语言文件中有翻译，那么就会显示defaults.json中的文本。 i18n 目录可以放置在源文件目录下的任意位置，例如可以跟 Page 或 Component 放在一起。但是需要注意的是，多个 i18n 目录下的文件在构建时会被合并打包，因此如果翻译文本有重复的 key 可能会发生覆盖。如果分开多个 i18n 目录定义请确保 key 是全局唯一的。 定义的文本如下：
    
    // i18n/en-US.json
    {
      "i18nText": "This is a i18nText text",
      "i18nTextWithParams": "{value} is what you pass in"
    }
    // i18n/zh-CN.json
    {
      "i18nText ": "这是一段纯文本",
      "i18nTextWithParams ": "你传入的值是{value}"
    }

[h2]在QXML中使用i18n对象在 QXML 中使用 $t 函数来获取文本。
    
    <!-- pages/index/index.qxml -->
    <view>{{ $t(i18nText) }}</view>
    <input placeholder="{{ $t('i18nTextWithParams', {value}) }}"></input>

$t函数签名如下：
    
    $t(key: string, params: object)

它可以接受两个参数，第一个参数是 i18n 文本的 key，第二个参数是需要传入的对象（可以是service层发送给view层的变量值）。 [h2]在Javascript中使用i18n对象在 JavaScript 里可以直接调用 Page 或者 Component 实例下的 t 函数获取翻译文本。
    
    Component({
      attached() {
        const text = this.t('withParams', { value: 'Test' })
        console.log(text)    // Test is what you pass in
      }
    })

在 Page 或者 Component 实例里还开放了一些其他接口，例如获取当前语言getI18nLocale、动态设置当前语言setI18nLocale、监听语言切换onI18nLocaleChange等，可用于实现国际化时进行调用。 调试快应用使用IDE的“WebView调试工具”可以帮助开发者定位页面元素信息，对页面元素进行审查，以便快速定位问题。具体调试步骤如下。

打包快应用
    1. 菜单选择“构建 > 打包正式版本”。
       * 如果没有签名文件，会提示创建签名或者导入已有的签名文件
       * 已有签名文件展示签名信息。
    2. 点击“确定”，打包正式版本的rpk包，打包完成将自动打开项目的dist目录，rpk包即存放在此处。
