# 功能简介

Web快应用是快应用提供的一种全新的快应用产品形态： 与小程序（微信、支付宝、字节）高度兼容适配。通过一键转化能力，可以将已有的小程序（微信、支付宝、字节）快速转化为Web快应用，方便在华为平台上线分发，同时支持微信支付、微信登录、华为账号（开发中）以及华为支付（开发中）等能力，助力开发者高效研发。
