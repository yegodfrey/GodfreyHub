# 准备资质文件

#### 资质要求

首次申请上架"华为应用市场"的快应用，需要准备相关的资质文件。

1. 参考"[华为应用市场应用分类](https://developer.huawei.com/consumer/cn/doc/50103)"， 确定快应用所属分类。
2. 根据上步确定的类别，参考"[应用版权资质要求](https://developer.huawei.com/consumer/cn/doc/80301)"提供对应类别所需的资质材料。
