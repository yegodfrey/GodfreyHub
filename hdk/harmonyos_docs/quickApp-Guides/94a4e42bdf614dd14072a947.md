# 测试快游戏

#### 运行快游戏

#### 方式一：快游戏开发者工具

支持连接手机后在快游戏开发者工具中运行快游戏。

#### 方式二：adb命令

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135235.32391930936179753059537803841127:50001231000000:2800:93A7972030DE2765DDB0DA829BC38C447CFCC0C686C1F3FDD8541F5BC5C6D1EC.png)  
HarmonyOS 5.0及以上系统不支持使用adb命令的方式测试快游戏。

支持adb命令将RPK包体PUSH到手机上，步骤如下：

1. 使用数据线连接手机和PC机。
2. 在命令行窗口输入如下命令，将RPK文件PUSH到手机。

   ```
   // RPK文件在手机的保存路径，例如sdcard/a，若没有指定路径将自动新建路径文件夹
   adb push [直接拖拽RPK文件至命令行窗口将自动生成RK文件的路径] [RPK文件在手机的保存路径]
   ```

3. 在手机中打开快应用加载器，点击右上角"+"，从文件路径中选择RPK文件，即可在手机上打开并运行快游戏。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135235.28563547969786177529545152515777:50001231000000:2800:FBF69AFB8BD08EEB55438010F016D4200091A0DBE14976FD7E648FF2315A42F8.png)
