# 折叠面板组件

## 简介

折叠面板（collapse）组件用来折叠过长的内容或者列表，点击可以展开折叠部分。主要用于多内容分类项场景，折叠不重要的内容，显示重要内容。

折叠面板一般具有如下特点：

* 可配置面板默认状态、是否展开、是否禁用
* 可开启动画效果，并选择是否有手风琴效果（展开一个会收起其他）
* 可配置图标

## 开发指引

### 自定义子组件

1. 定义布局样式。 折叠面板组件布局包括两个部分：简介内容部分、详细内容部分。

   * 简介内容通过image+text+image组件实现。
   * 详细内容通过text组件实现。

   ```screen
   <template>
     <!-- Only one root node is allowed in template. -->
     <div class="container">
       <block for="{{accordionarray}}">
         <div class="titlebar" style="background-color: {{$item.display?'#c0c0c0':'white'}}; " onclick="click($idx)">
           <image if="{{imgdisplay}}" src="{{$item.thumb}}" class="img"></image>
           <text class="title">{{ $item.title }}</text>
           <image id="img{{$idx}}" src="{{$item.display?'/Common/xialagrey.jpg':'/Common/xiala.jpg'}}" class="image {{animationimage}}"></image>
         </div>
         <div id="{{$idx}}" class="collapse {{$item.animationslot}}">
           <text class="txt">{{ $item.content }}</text>
         </div>
       </block>
     </div>
   </template>
   ```

2. 规划属性和支持的事件。

   支持的属性：

   |**属性**|**类型**|**默认值**|**描述**|
   |:------------|:------|:------|:-----------|
   |title|String|-|标题文字。|
   |thumb|String|-|标题左侧图标路径。|
   |disabled|Boolean|false|是否禁用。|
   |open|Boolean|false|是否展开折叠面板。|
   |showanimation|Boolean|false|是否开启动画效果。|
   |content|String|-|折叠面板展开内容。|
   |accordion|Boolean|false|是否开启手风琴动画效果。|

   支持的事件：

   |**事件名称**|参数|描述|
   |:-------|:-|:-----------|
   |change|e|返回折叠面板状态的事件。|

### 实现折叠面板展开和收起的动画效果

1. 实现简介内容部分的图标旋转。
   * 折叠面板展开时，图标从0度旋转至180度，代码如下：

     ```screen
     //图标旋转动画
     imageanimation(id) {
       var options = {
         easing: 'linear',
         fill: 'forwards',
       }
       var frames = [
         {
           transform: {
             rotate: 180
           }
         },
         {
           transform: {
             rotate: 0
           }
         }];
       var animation = this.$element('img' + id).animate(frames, options);
       animation.play();
       animation.finish();
       animation.pause();
       animation.cancel();
       animation.reverse();
       animation.onfinish = function () {
       }
       animation.oncancel = function () {
       }
     },
     ```

   * 折叠面板收起时，图标从180度旋转至0度，代码如下：

     ```screen
     //图标恢复动画
     imageanimationrecovery(id) {
       var options = {
         easing: 'linear',
         fill: 'forwards',
       }
       var frames = [
         {
           transform: {
             rotate: 0
           }
         },
         {
           transform: {
             rotate: 180
           }
         }];
       var animation = this.$element('img' + id).animate(frames, options);
       animation.play();
       animation.finish();
       animation.pause();
       animation.cancel();
       animation.reverse();
       animation.onfinish = function () {
       }
       animation.oncancel = function () {
       }
     },
     ```

2. 通过修改详细内容部分的高度，实现折叠面板展开和收起的状态。

   ```screen
   /* 内容动画 */
   .noanimationslotstart {
     animation-name: noanimationslotstart;
     animation-duration: 0ms;
     animation-fill-mode: forwards;
   }
   @keyframes noanimationslotstart {
     from {
       height: 0;
     }
     to {
       height: 200px;
     }
   }
   .noanimationslotend {
     animation-name: noanimationslotend;
     animation-duration: 0ms;
     animation-fill-mode: forwards;
   }
   @keyframes noanimationslotend {
     from {
       height: 200px;
     }
     to {
       height: 0;
     }
   }
   ```

3. 根据showanimation的值来决定折叠面板的展开和收起是否具有动画效果。
   * showanimation为false时，不开启动画效果。

     ```screen
     //showanimation为false时触发，此时没有动画效果
     if (this.accordionarray[index].open === false) {
       this.imageanimation(index)
       this.accordionarray[index].animationslot = "noanimationslotstart"
       this.accordionarray[index].open = true
       this.accordionarray[index].display = true
       this.changevalue = "折叠面板展开了"
       this.status = true
     } else {
       this.imageanimationrecovery(index)
       this.accordionarray[index].animationslot = "noanimationslotend"
       this.accordionarray[index].open = false
       this.accordionarray[index].display = false
       this.changevalue = "折叠面板收起了"
       this.status = false
     }
     ```

   * showanimation为true且accordion为false时，开启普通动画效果。

     ```screen
     if (this.accordionarray[index].showanimation === true) {
       this.accordionarray[index].open = true
       if (this.accordionarray[index].display === false) {
         this.imageanimation(index)
         this.accordionarray[index].animationslot = "animationslotstart"
         this.accordionarray[index].display = true
         this.changevalue = "折叠面板展开了"
         this.status = true
       } else {
         this.imageanimationrecovery(index)
         this.accordionarray[index].animationslot = "animationslotend"
         this.accordionarray[index].display = false
         this.changevalue = "折叠面板收起了"
         this.status = false
       }
     }
     ```

   * showanimation为true且accordion为true时，开启手风琴动画效果（即展开一个的同时将其他的收起）。

     ```screen
     //手风琴动画效果
     accordionanimation(index) {
       this.accordionarray[index].open = true
       if (this.accordionarray[index].display === false) {
         this.accordionarray[index].display = true
         this.accordionarray[index].animationslot = "animationslotstart"
         this.imageanimation(index)
         this.changevalue = "折叠面板展开了"
         this.status = true
         if (this.value !== index && this.value !== null) {
           this.accordionarray[this.value].display = false
           this.accordionarray[this.value].animationslot = "animationslotend"
           this.imageanimationrecovery(this.value)
           this.changevalue = "折叠面板收起了"
           this.status = false
         }
       } else {
         this.imageanimationrecovery(index)
         this.accordionarray[index].animationslot = "animationslotend"
         this.accordionarray[index].display = false
         this.changevalue = "折叠面板收起了"
         this.status = false
       }
       this.value = index
     },
     ```

### 父子组件通信

1. 父组件中定义change事件并绑定。

   ```screen
   <collapse accordionarray="{{animation}}" @change="change"></collapse>
   ```

   ```screen
   change(e) {
     console.log(e.detail.changevalue + e.detail.status);
     prompt.showToast({
       message: e.detail.changevalue + e.detail.status,
       duration: 500
     })
   }
   ```

2. 子组件通过this.$emit方法携带事件及参数通知父组件。

   ```screen
   click(num) {
     if (this.accordion === true) {
       this.accordionanimation(num)
     } else {
       this.easyanimation(num)
     }
     this.$emit('change', { changevalue: this.changevalue, status: this.status })
   },
   ```
