# 订阅消息

#### 功能介绍

为了向玩家提供更好的服务和更优的体验，快游戏提供了基于账号的消息订阅能力。

快游戏可以根据您选择的订阅模板向登录华为账号的玩家发起订阅请求，当玩家同意订阅后，快游戏会向登录华为账号的玩家推送订阅模板对应的消息。

服务通知支持在锁屏、通知中心等位置展示，效果图如下，真实样式请以实际效果为准：

#### 服务通知订阅消息分类

#### 一次性订阅消息

一次性订阅消息用于解决玩家游玩快游戏，后续游戏动态的通知问题。玩家订阅后，您可不限时间地下发一条对应的服务通知消息；每条消息可单独订阅或退订。当玩家勾选 "总是保持以上选择" 之后，订阅消息会被添加到玩家的快游戏设置页，下次发起订阅请求时将不会再向玩家弹窗，保持之前的选择，修改选择需要打开快游戏通知管理设置页进行修改 。

#### 前提条件

![](https://media:101784517136283137)  
当前使用订阅消息能力，您不需要自行配置订阅模板，只需提供[APP ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section1148753814717)、应用名称、[项目ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section67511056134110)和[应用的Client ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section33514260433)给相关运营人员。

* 已在AGC控制台开通[推送服务](https://developer.huawei.com/consumer/cn/doc/atomic-guides/push-as-prepare#section73941874447)。
* 已联系相关运营人员获取订阅模板ID。  

#### 开发指导

![](https://media:101784517136323138)

1. 快游戏启动时调用[qg.gameLoginWithReal](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-account-0000001083874630#section73325514166)发起防沉迷登录，玩家登录后返回playerId。
2. 调用[qg.canIUse('MiniGame.SubscribePushMsg')](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-sysinfo-0000001083874626#section165771434195617)判断当前客户端是否支持订阅消息能力。
3. 调用[qg.requestSubscribeMessage](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-subscribe-message-0000002524560898#section917310297396)拉起快游戏订阅消息界面，玩家选择是否订阅消息及订阅的消息类型。
4. 玩家选择订阅消息后，返回[订阅模板ID](#section1867813082216)和订阅结果等信息。
5. 调用[批量查询openId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/query-openid-0000001452874029)接口，通过playerId查询得到openId。
6. 调用[服务通知](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/push-api-service-noti)接口，通过msgId、openId、[appId](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-enable-account-kit-0000001159772367#section1148753814717)和[订阅模板ID](#section1867813082216)发送通知给玩家。
