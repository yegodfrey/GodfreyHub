# 接入华为支付服务

## 简介

华为支付服务为开发者的应用提供华为支付方式收款能力，适用于在移动端应用（APP、快应用、元服务等）收款的场景。使用产品之前，开发者需要在移动端应用内集成华为支付服务SDK，再调用SDK接口调起华为支付服务提供的收银台，即可帮助用户完成支付，并展示支付结果。

## 开发前导

在接入华为支付服务前，需要先完成商户入网和获取商户号、开通支付服务等步骤，具体请参考华为支付服务的"[开发前导](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/payment-development-config-0000001882266062)"章节内容。

## 华为支付服务 JS SDK

华为支付服务 JS SDK 为快应用提供便捷的支付体验和简便的接入流程。开发者的快应用通过集成华为支付服务 JS SDK，再调用华为支付服务 JS SDK接口启动华为支付收银台，即可实现应用支付能力。JS SDK的详细信息，请参考华为支付服务的"[API参考](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/quick-app-client-0000001588489305)"章节内容。
