# 开发车机快应用

> 说明
>
> 感谢您对车机快应用生态的支持，车机快应用开发前请先联系您的商务经理，确认分发的车型后再启动开发。

## 准入条件

在进行快应用开发前，请先完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 完成开发环境的搭建，包括在PC上安装华为快应用IDE、在测试手机安装调试运行在车机上快应用的加载器，详细参见"[安装开发工具](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)"。
* 在AppGallery Connect（以下简称AGC）上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。

## 开发车机快应用

### 创建项目

2. 根据待开发快应用的内容，选择合适的模板，点击"下一步"。
   * Hello World：生成车机快应用项目最基础的项目结构。
   * 横屏示例：生成适用于横屏的车机快应用项目最基础的项目结构。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111456.40588869034520177539934691321197:50001231000000:2800:F59E08511B7AE751956B647A2E7118B8C86AB563031D3C4E20072BD0A7742C7F.png)
3. 填写项目信息后，点击"确定"。
   * 应用名称：应用名称，用于在桌面图标、应用市场等处显示。例如：QuickAppDemo。

### 编辑代码

1. 配置manifest.json文件中 minPlatformVersion 为1040，config的 designWidth 设置为车机的屏幕宽度。
2. 在左侧工程目录选择相应的工程文件，参考快应用规范进行快应用基础功能的开发。 快应用规范包括：

   * [框架](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-filestructure-0000001074564510)
   * [组件索引](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-component-index-0000001073326871)中车机支持的组件
   * [API索引](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-index-0000001073124891)中车机支持的API
3. 除了基础功能的开发，您还可以根据需要实现更多功能。
   * 以卡片的形式在车机上展示应用信息，请参见"[开发车机卡片](#section2294135141113)"。
   * 使快应用在不同厂商不同尺寸的车机上都有良好的展示效果，请参见"[响应式布局](#section125761318171113)"。

## 响应式布局（可选）

为了使同一个快应用在不同厂商不同尺寸的车机上都有良好的展示效果，完成功能开发后，可以对快应用进行响应式布局处理。

### 尺寸转换

1. 配置manifest.json文件。
   1. minPlatformVersion配置为1045。

      ```screen
      "minPlatformVersion": 1045,
      ```

   2. 修改config节点下的designWidth属性为device-width。

      ```screen
      "config": {
          "designWidth": "device-width"
      },
      ```

2. 对项目文件中ux、css文件设置尺寸的地方进行换算，转换公式为：新尺寸 = 旧尺寸*真实宽度/designWidth。 以某11寸车机为例，分辨率1152*1184，屏幕密度为1.125，则真实宽度为 1152/1.125=1024。

   当原designWidth为1152时，原来 font-size:60 px 转换后变成 font-size:53.3 px。

   当原designWidth为750时，原来 font-size:60 px 转换后变成 font-size:81.9 px。

   也可以下载 [convert工具](https://appfile1.hicloud.com/FileServer/getFile/app/011/111/111/0000000000011111111.20200429152807.74458047516044528262595816735914:20471231000000:0001:F25A8DAF085AAB7426FC681073EBD22563E032836EAED8803D8D1857324ADB6B.zip?needInitFileName=true) 对项目文件进行批量转换，运行命令如下：

   java -jar convert.jar -root "d:\quickapp\proj" -formats "ux;css" -oldDesignWidth 750 -destScreenDps 360

   750替换为原始配置的宽度，360替换为屏幕的真实宽度。

### 动态布局

由于不同厂商车机横屏竖屏宽度差别较大，配置device-width且尺寸转换之后，可能仍然无法兼顾多种屏幕显示效果，此时可以使用MediaQuery进行动态布局，详细请参见"[MediaQuery响应式布局能力](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-mediaquery-0000001170210011)"。 例如需要区分1024宽度和1280宽度屏幕，可用以下代码实现：

```screen
@media screen and (min-width: 0) and (max-width: 1079) {
    .list {
        columns: 2;
    }
    .subtitle {
        font-size: 30px;
        width: 60px;
    }
    /*此处可以根据需要修改组件样式*/
    }
    @media screen and (min-width: 1080) and (max-width: 2159) {
    .list {
        columns: 4;
    }
    .subtitle {
        font-size: 20px;
        width: 40px;
    }
    /*此处可以根据需要修改组件样式*/}
}
```

### 实现建议

响应式布局实现的重要一步在于分割点的划分，即不同宽度范围，我们建议根据常见屏幕宽度按照以下区间划分屏幕范围。

开发者也可以在此基础上根据实际需求修改或者增加新的划分条件，以达到目标效果。

|序号|宽（dp）|高（dp）|DP区间（宽度）|
|:-|:----|:----|:--------|
|1|860|645|800-960|
|2|878|1024|800-960|
|3|912|540|800-960|
|4|960|500|800-960|
|5|994|559|960-1120|
|6|1024|1053|960-1120|
|7|1078|405|960-1120|
|8|1280|480|1120-1280|
|9|1280|720|1120-1280|
|10|1345|624|1280以上|
