# 创建快应用

#### 创建快应用

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的应用"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175835.02521940074151570795551020260046:50001231000000:2800:BF5CDD6D97EB1A989F45E50338B15CF78F7B04064454F07D2BF7A3311A22C8C7.png)
2. 点击"新建"，在"创建应用"界面填写应用信息后，点击"确认"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175835.12170010514447033213872071894591:50001231000000:2800:54AF4EE4436EACDF4EFCD0ED53F0548CD8ADE1B31A0C3C8EFA508D60E4541C8F.png)

   |参数|说明|
   |:----|:--------------------------------------------------------------------------------------------------------------------------------------------|
   |软件包类型|选择RPK(快应用)。|
   |支持设备|应用发布后运行的设备。 * 运行在手机和平板上的快应用：选择"手机" * 运行在智慧屏上的快应用：选择"大屏" * 运行在车机上的快应用：选择"车机" * 运行在PC上的快应用：选择"PC"|
   |应用名称|要求1-64个字符，创建后将获取一个新的APP ID，应用名称支持在应用信息中修改。|
   |应用分类|* 应用：普通应用。 * 游戏：游戏类应用。|
   |默认语言|应用的默认语言，根据实际情况选择。|
   |添加到项目|勾选。关于项目和应用的关系，请参见"[AppGallery Connect项目介绍](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-project-introduction)"。|
   |项目名称|* 应用加入已有项目，则从下拉框中选择对应的项目。 * 应用加入新项目，则直接填写项目的名称。|

#### 获取APP ID

APP ID是华为开发者联盟为应用分配的唯一标识，在后续开发过程中需要使用，获取方法如下。

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的项目"。
2. 点击待查询的项目卡片。
3. 选择需要查询的快应用。
4. 在"项目设置 \> 常规"页面的"应用"区域获取应用的APP ID。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175835.10923561106340115899420217940246:50001231000000:2800:1B2795C2B58C8EBB3052D867AFC01734ACED8F0CCCC162AE90945A3377E5CFE3.png)

#### 获取API密钥（凭据）

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的项目"。
2. 点击待查询的项目卡片。
3. 在"项目设置 \> 常规"页面的"项目"区域，点击![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.85228930794402507221215770734384:50001231000000:2800:4EF09C11C398E5ACE325203184A1D0B364532D3121289F7CC7AA53449DAE6078.png)，复制获取API密钥（凭据）。
