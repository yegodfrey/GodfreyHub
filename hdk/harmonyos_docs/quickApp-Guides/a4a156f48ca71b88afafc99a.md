# 转移核准（备案）

在华为云核准（备案）系统中将主体及主体下的互联网信息全部转移到目标账号下。操作步骤如下：

1. 进入[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，登录华为云核准（备案）系统，左侧菜单栏点击"我的核准（备案）"，右侧页面点击"转移核准（备案）"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175842.24277942409550209396850502116338:50001231000000:2800:433754470DAE10200B8AC15C546038D06871C3D11E75C954C2E7D5977088D7DE.png "点击放大")
2. 在"转移核准（备案）"填写目标账号后，点击"提交"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175842.20085610058538066690949647805315:50001231000000:2800:1B43E66929545CD46B0BD3A04C77F8BEDD139D73DB76477146BEA7CB686FB6B5.png "点击放大")

3. 提交转移申请后需要几分钟才能转移成功，请耐心等待。
