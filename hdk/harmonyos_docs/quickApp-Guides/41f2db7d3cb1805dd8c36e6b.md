# Web快应用开发工具使用指引

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162409.74583711470750927075547719340048:50001231000000:2800:24565D454064C2D20B995FF68A54A3F7AF5A99B903EBAD83E5A9F2A3554F6C82.png)  
后续示例图片中"小程序"如无特殊说明是指"Web快应用"。

Web快应用开发工具是面向开发者推出的「Web快应用桌面端集成开发环境」。开发者可以通过Web快应用开发工具完成小程序一键转化Web快应用，并实现开发、调试、预览等功能。Web快应用开发者工具原生支持 vscode 插件集成，默认集成了代码提示、代码补全、js link 、代码方法提醒、git 扩展、系统终端交互等现代编辑器具备的功能。
