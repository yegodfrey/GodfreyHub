# 悬浮按钮组件

#### 简介

悬浮按钮（fab）组件是一种特殊的按钮，点击可展开一个菜单。悬浮按钮一般具有如下特点：

* 可显示在页面的四个角落
* 可展开和收起菜单
* 展开的菜单可水平显示，也可竖直显示

效果图如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111559.14078245798842283341701414390433:50001231000000:2800:03FF5EF8435559B953FEB083F0D0C861C35E11A09D66C8B94832BDEEB55B3E9B.png)

基本布局代码如下：

```
<template>
  <!-- Only one root node is allowed in template. -->
  <div class="container">
    <stack style="width: 100%;height:100%;">
      <div class="content">
        <input type="button" value="切换菜单({{displayDirection}})" class="input" onclick="switch" />
        <input type="button" value="{{$item.value}}" class="input" onclick="choosePostion($item.horizontal , $item.vertical)" for="{{btnValue}}" />
      </div>
      <!-- fabdirection属性：设置悬浮按钮显示的位置；displaydirection属性：设置悬浮按钮展开菜单显示方式；fabClick事件：展示悬浮按钮点击后的状态。-->
      <fab popmenu="{{popMenu}}" pattern="{{pattern}}" content="{{content}}" fabvertical="{{fabvertical}}" fabhorizontal="{{fabhorizontal}}" displaydirection="{{displayDirection}}" @trigger="contentrigger" @fabClick="fabclick"></fab>
    </stack>
  </div>
</template>
```

#### 开发指引

#### 自定义子组件

1. 定义布局样式。 悬浮按钮组件布局包括两个部分：悬浮按钮部分、点击悬浮按钮展开菜单的内容部分。

   * 悬浮按钮通过stack组件堆叠的方式实现。
   * 菜单内容通过image+text组件实现。

   ```
   <template>
     <div style="flex-direction: {{flexdirection}};width: 100%;height: 100%;">
       <div class="{{container}}">
         <div class="{{animationcss}} fabcontentlayout" style="background-color: {{pattern.backgroundColor}};">
           <!-- 悬浮按钮展开后菜单的内容，fabcontentClick事件表示菜单的内容被点击的状态-->
           <div class="{{fabcontent}}" style="opacity: {{opactity}}">
             <div style="flex-direction: column;justify-content: center;align-items: center;margin-left: 10px;" for="content" onclick="fabcontentClick($idx)">
               <image class="img" src="{{$item.active?$item.selectedIconPath:$item.iconPath}}"></image>
               <text class="txt" style="color: {{$item.active?pattern.selectedColor:pattern.color}};">{{ $item.text }}</text>
             </div>
           </div>
         </div>
         <!-- 悬浮按钮 -->
         <div id="fabball" class="{{fab}} fabbtn" style="background-color: {{pattern.buttonColor}}" onclick="animation">
           <stack style="width: 100%;height:100%; justify-content: center;align-items: center;">
             <text class="icon-item"></text>
             <text class="icon-item1"></text>
           </stack>
         </div>
       </div>
     </div>
   </template>
   ```

2. 规划属性和支持的事件。 支持的属性：

   |属性|类型|默认值|描述|
   |:---------------|:------|:----|:---------------------------|
   |pattern|Object|-|可选样式配置项。|
   |fabhorizontal|String|left|水平对齐方式。left：左对齐，right：右对齐。|
   |fabvertical|String|top|竖直对齐方式。bottom：下对齐，top：上对齐。|
   |displaydirection|String|hor|展开菜单的显示方式。hor：水平显示，ver：竖直显示。|
   |popmenu|Boolean|false|是否展开菜单。|
   |content|Array|-|展开菜单的内容配置项。|

   pattern配置项：  

   |参数|类型|默认值|描述|
   |:--------------|:-----|:------|:----------|
   |color|String|#3c3e49|菜单文字的颜色。|
   |selectedColor|String|#007AFF|点击菜单文字时的颜色。|
   |backgroundColor|String|#bebcbc|菜单的背景色。|
   |buttonColor|String|blue|悬浮按钮的背景色。|

   content配置项：  

   |参数|类型|默认值|描述|
   |:---------------|:------|:--|:-----------|
   |iconPath|String|-|原始图标的路径。|
   |selectedIconPath|String|-|内容被选中后图标的路径。|
   |text|String|-|文字。|
   |active|Boolean|-|是否选中当前内容。|

   支持的事件：  

   |事件名称|参数|描述|
   |:-------|:-|:---------|
   |fabClick|无|点击悬浮按钮的事件。|
   |trigger|无|点击菜单内容的事件。|

#### 实现悬浮按钮的显示位置

通过动态改变class的container和fab以及根div的flex-direction属性实现。

* 左上角显示：悬浮按钮默认是关闭且显示在左上角的，container和fab的初始class就是container1和fab1，根div的flexdirection值设为column。
* 右上角显示：将container的flex-direction属性设为row-reverse，fab的position属性设为absolute，根div的flexdirection值设为column 。
* 左下角显示：将container的flex-direction属性设为column-reverse，fab的position属性设为absolute，根div的flexdirection值设为column-reverse 。
* 右下角显示：将container的flex-direction属性设为row-reverse，fab的position属性设为absolute，根div的flexdirection值设为column-reverse。

css样式代码如下：

```
/* 左上角显示 */
  .container1 {
    display: flex;
  }
  .fab1 {
    position: fixed;
  }

  /* 右上角显示 */
  .container2 {
    flex-direction: row-reverse;
    margin-left: 270px;
  }
  .fab2 {
    position: absolute;
  }

  /* 左下角显示 */
  .container3 {
    flex-direction: column-reverse;
  }
  .fab3 {
    position: absolute;
  }

  /* 右下角显示 */
  .container4 {
    flex-direction: row-reverse;
    display: flex;
  }
  .fab4 {
    position: absolute;
    right: 0px;
    bottom: 0px;
  }
```

#### 实现悬浮按钮的动画效果

1. 通过控制悬浮按钮图标的旋转实现菜单内容的展开和收起。  
   菜单展开时，图标从0度旋转至45度，代码如下：

   ```
   //fabball 旋转
   fabballrotate() {
     var that = this
     var options = {
       duration: 200,
       easing: 'ease-out',
       fill: 'forwards',
     }
     var frames = [
       {
         transform: {
           rotate: "45"
         }
       },
       {
         transform: {
           rotate: "0"
         }
       }];
     var animation = this.$element('fabball').animate(frames, options);
     animation.play();
     animation.finish();
     animation.pause();
     animation.cancel();
     animation.reverse();
     animation.onfinish = function () {
       console.log("animation  onfinish");
       that.popmenu = true
     }
   },
   ```

   菜单收起时，图标从45度旋转至0度，代码如下：

   ```
   //fabball 恢复
   fabballrotaterecovery() {
     var that = this
     var options = {
       duration: 200,
       easing: 'linear',
       delay: 0,
       fill: 'forwards',
       iterations: 1
     }
     var frames = [
       {
         transform: {
           rotate: "0"
         }
       },
       {
         transform: {
           rotate: "45"
         }
       }];
     var animation = this.$element('fabball').animate(frames, options);
     animation.play();
     animation.finish();
     animation.pause();
     animation.cancel();
     animation.reverse();
     animation.onfinish = function () {
       console.log("animation  onfinish");
       that.popmenu = false
     }
   },
   ```

#### 父子组件通信

1. 父组件通过parentVm.$broadcast()向子组件传递选择悬浮按钮显示位置的事件。

   ```
   //将悬浮按钮的显示位置传给子组件
   choosePostion(hor, ver) {
     prompt.showToast({
       message: `点击后显示在${hor}-${ver}`,

     })
     this.$broadcast('boradchoosePostion', {
       fabhorizontal: hor,
       fabvertical: ver
     })
   },
   ```

2. 子组件通过$on()方法监听悬浮按钮显示方向fabhorizontal、fabvertical属性的变化，从而修改css样式，让其在对应的位置显示悬浮按钮。

   ```
   onInit() {
     this.$on('boradchoosePostion', this.choosePostionEvt);
   },
   choosePostionEvt(evt) {
     this.fabhorizontal = evt.detail.fabhorizontal
     this.fabvertical = evt.detail.fabvertical
     this.displaypostion()
   },
   //悬浮按钮位置设置
   displaypostion() {
     if (this.fabhorizontal === "left" && this.fabvertical === "top") {
       if (this.display === false) {
         if (this.displaydirection === "hor") {
           this.closeHorToVer()
         } else {
           this.closeVerToHor()
         }
       }
       this.flexdirection = "column"
       this.container = "container1"
       this.fab = 'fab1'
       if (this.displaydirection === "hor") {
         this.fabcontent = 'fabcontent1'
       } else {
         this.fabcontent = 'fabcontent3'
       }
     } else if (this.fabhorizontal === "left" && this.fabvertical === "bottom") {
       if (this.display === false) {
         if (this.displaydirection === "hor") {
           this.closeHorToVer()
         } else {
           this.closeVerToHor()
         }
       }
       this.flexdirection = "column-reverse"
       this.container = "container3"
       this.fab = 'fab3'
       if (this.displaydirection === "hor") {
         this.fabcontent = 'fabcontent1'
       } else {
         this.fabcontent = 'fabcontent4'
       }
     } else if (this.fabhorizontal === "right" && this.fabvertical === "top") {
       if (this.display === false) {
         if (this.displaydirection === "hor") {
           this.closeHorToVer()
         } else {
           this.closeVerToHor()
         }
       }
       this.flexdirection = "column"
       this.container = "container2"
       this.fab = 'fab2'
       if (this.displaydirection === "hor") {
         this.fabcontent = 'fabcontent2'
       } else {
         this.fabcontent = 'fabcontent3'
       }
     } else if (this.fabhorizontal === "right" && this.fabvertical === "bottom") {
       if (this.display === false) {
         if (this.displaydirection === "hor") {
           this.closeHorToVer()
         } else {
           this.closeVerToHor()
         }
       }
       this.flexdirection = "column-reverse"
       this.container = "container4"
       this.fab = 'fab4'
       if (this.displaydirection === "hor") {
         this.fabcontent = 'fabcontent2'
       } else {
         this.fabcontent = 'fabcontent4'
       }
     }
   },
   ```

3. 子组件通过$watch()方法监听悬浮按钮displaydirection属性的变化，从而修改css样式，让其正确显示菜单内容的展示方向。

   ```
   onInit() {
       this.$watch('displaydirection', 'fabdirectionEvt');
   },
   fabdirectionEvt() {
       this.HorandVer()
   },
   HorandVer() {
       if (this.display === true) {
       if (this.displaydirection === "hor") {
           this.openVerToHor()
       } else {
           this.openHorToVer()
       }
       } else {
       if (this.displaydirection === "hor") {
           this.closeHorToVer()
       } else {
           this.closeVerToHor()
       }
     }
   },
   // 展开状态下水平/竖直切换
   openHorToVer() {
       this.animationcss = 'animationcssopenHH'
       this.display = true
       if (this.fabvertical === 'top') {
       this.fabcontent = 'fabcontent3'
       } else {
       this.fabcontent = 'fabcontent4'
       }
   },
   openVerToHor() {
       this.animationcss = 'animationcsscloseHH'
       this.display = true
       if (this.fabhorizontal === 'left') {
       this.fabcontent = 'fabcontent1'
       } else {
       this.fabcontent = 'fabcontent2'
       }
   },
   // 收起状态下水平/竖直切换
   closeHorToVer() {
       this.animationcss = 'animationcsscloseHorToVer'
       this.display = false
   },
   closeVerToHor() {
       this.animationcss = 'animationcsscloseVerToHor'
       this.display = false
   },
   ```

4. 子组件通过fabClick事件及参数通知父组件。

   ```
   setTimeout(() => {
   console.log(this.popmenu);
   this.$emit('fabclick', this.popmenu)
   }, 300);
   ```

   ```
   <fab  @fabClick="fabclick"></fab>
   ```

   ```
   //fabClick事件
   fabclick(e) {
     console.log("fabclick e = ", JSON.stringify(e));
     prompt.showToast({
       message: e.detail,
     })
   },
   ```

5. 子组件通过trigger事件及参数通知父组件。

   ```
   //菜单内容点击后高亮
   fabcontentClick(index) {
       this.content[index].active = !this.content[index].active
       this.$emit('trigger', this.content[index].text)
   },
   ```

   ```
   <fab  @trigger="contentrigger"></fab>
   ```

   ```
   //trigger事件
   contentrigger(e) {
     console.log("contentrigger e = ", JSON.stringify(e));
     prompt.showToast({
       message: e.detail + "被点击",
     })
   },
   ```
