# 华为手机如何打开开发者选项

> 注意
>
> 如果手机存在多账号模式，请切换至主账号再进行操作。

1. 打开手机，进入"设置"页面，搜索"关于手机"选项。
2. 快速点击"HarmonyOS版本"的项目多次，直到提示"您正处于开发者模式！"或者"您已处于开发者模式，无需进行此操作"，即表示您已经打开开发者选项，然后退出该页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111600.06512017037889016549630723591008:50001231000000:2800:D5481B06263CF33DDBACAE1F595BDBC5E5110C5671FB2F175976C72F1855A7C6.png)

3. 在"设置"页面搜索"开发人员选项"项目。
4. 打开"开发人员选项"，下拉屏幕，可以找到"连接USB时总是弹出提示"，打开选项。 注意
   >
   > 请勿打开"'仅充电'模式下允许ADB调试"，如果打开了，后续"USB连接方式"只能选择"仅充电"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111600.36372914359642624370554268583281:50001231000000:2800:89A6B4A76D69BDA3D43361C9815807AC29A2304D5F2061B9558B4F35B43E6AFC.png)
5. 将连接线插入手机，弹出连接方式，选择"传输文件"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111600.55305945220750870841062564346084:50001231000000:2800:FD91FD6A32A56BF895496EF965219BCFFA03A0B4BDACD991E4B1F7358651C481.png)

6. 在"开发人员选项"页面，打开"USB调试"选项。
   * 首次打开：弹出授权提示，勾选"始终允许使用这台计算机进行调试"，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111600.07470131783825004252782967169561:50001231000000:2800:19DDC94C4F72E56A8915DCCC45DD772E03F6DA3372F610253592FD5FDBA342AA.png)

   * 非首次打开：弹出授权提示，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111600.43340552140199051823465468276823:50001231000000:2800:7CC85C3245B0F202CE39AAC7DD6E00AC39D07FEA5729B31FD613D85F1D791078.png)
