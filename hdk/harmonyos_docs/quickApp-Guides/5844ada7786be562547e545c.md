# 国产游戏小程序核准（备案）准备

国产游戏小程序是指纯广告变现快游戏（IAA），若这类快游戏未注册在江苏省，且在履行核准（备案）手续前没有拿到国家/省份相关主管部门审核同意的前置审批文件，例如游戏版号、国家/省级新闻出版广电总局关于\*\*\*\*游戏的批复文件、省级新闻出版部门出具的游戏核准（备案）批复文件，需要前往AGC控制台申请前置审批文件。在AGC控制台为国产游戏小程序申请前置审批文件的操作步骤如下。

1. 下载模板文件，并根据实际情况进行填写。  

   |模板文件下载|
   |:--------------------------------------------------------------------|
   |[游戏小程序著作权人（开发者）授权运营、核准（备案）委托书.docx](https://media:801773035294243508)|
   |[游戏小程序开发者著作权自我声明.docx](https://media:801773035294298509)|
   |[广东省国产游戏小程序核准（备案）表.docx](https://media:801773035294351510)|

2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，为快游戏新建核准（备案）。

   ![](https://media:801773035294010504)
3. 在"国产小程序备案"页面填写信息，完成后点击"提交"。 ![](https://media:801773035294130505)

4. 您提交的申请需华为工作人员与管局共同审批，完成审批大概需要20\~30个工作日，请耐心等待。 ![](https://media:801773035294165506)

   ![](https://media:801773035294190507)  
   仅能有一条正在审批中的申请。
5. 完成审批后，请前往AGC控制台，在快游戏核准（备案）详情页最底部下载管局签署的准予核准（备案）通知书。
