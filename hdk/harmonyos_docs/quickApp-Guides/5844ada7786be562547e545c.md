# 国产游戏小程序核准（备案）准备

国产游戏小程序是指纯广告变现快游戏（IAA），若这类快游戏未注册在江苏省，且在履行核准（备案）手续前没有拿到国家/省份相关主管部门审核同意的前置审批文件，例如游戏版号、国家/省级新闻出版广电总局关于****游戏的批复文件、省级新闻出版部门出具的游戏核准（备案）批复文件，需要前往AGC控制台申请前置审批文件。在AGC控制台为国产游戏小程序申请前置审批文件的操作步骤如下。

1. 下载模板文件，并根据实际情况进行填写。

2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，为快游戏新建核准（备案）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/FeFvU8GcSPuq40teJw4J9w/zh-cn_image_0000002016468717.png?HW-CC-KV=V1&HW-CC-Date=20260909T132403Z&HW-CC-Expire=31536000000&HW-CC-Sign=24D1468B0FB87D7A22CFE686FD04AC30B9624EA7A02ACD19E6FF512F8B138B1D)
3. 在"国产小程序备案"页面填写信息，完成后点击"提交"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/C9p_rGhNTP67QEBPpsWkXQ/zh-cn_image_0000002016588245.png?HW-CC-KV=V1&HW-CC-Date=20260909T132403Z&HW-CC-Expire=31536000000&HW-CC-Sign=6E9083A5F64765B40BE9E9B67E1704B2126E4E0B695028EE3C1CB7039ADFF3D8)

4. 您提交的申请需华为工作人员与管局共同审批，完成审批大概需要20~30个工作日，请耐心等待。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/PoJYiPBITAqdwXG8OC9aPQ/zh-cn_image_0000001980108514.png?HW-CC-KV=V1&HW-CC-Date=20260909T132403Z&HW-CC-Expire=31536000000&HW-CC-Sign=A85F57D88E594190A43D3A141D49250C8047A2E2D5F996849F1CD5121B106A34)

   > 说明
   >
   > 仅能有一条正在审批中的申请。
5. 完成审批后，请前往AGC控制台，在快游戏核准（备案）详情页最底部下载管局签署的准予核准（备案）通知书。
