# 首次核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/dl8Scq_pQEagbOI_PyBjRQ/zh-cn_image_0000001803578168.png?HW-CC-KV=V1&HW-CC-Date=20261008T161714Z&HW-CC-Expire=31536000000&HW-CC-Sign=403CD23F3B4F1038E0030672F1C4B7A4EA04A6D2662863C0BDF1310124A7DFFE)

2. 填写主办单位和快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/6t9JaKpeTuuHIWzGdX4skg/zh-cn_image_0000001838739578.png?HW-CC-KV=V1&HW-CC-Date=20261008T161714Z&HW-CC-Expire=31536000000&HW-CC-Sign=1B69C95AA26D189EBA64877CBE5CFB1B88A78760A63350EF0774DFEDB80F7B4D)

3. 填写主办单位和快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/a8zblQf9QQahpaC4NO7sZA/zh-cn_image_0000001884979137.png?HW-CC-KV=V1&HW-CC-Date=20261008T161714Z&HW-CC-Expire=31536000000&HW-CC-Sign=874DFA7B13344E2F9E8F49C6E5345149F193AEAA92B058BEA32ECA0D374DE123)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/CVzI_AbJTMmkdNcyFvbTUQ/zh-cn_image_0000001850416933.png?HW-CC-KV=V1&HW-CC-Date=20261008T161714Z&HW-CC-Expire=31536000000&HW-CC-Sign=8D1BE68E2BDAEC84C6E36D44E62C1B49EC44EE258112005B5FF4501A1017A013)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/G2OPbGfAQZmAepdxSJfGjw/zh-cn_image_0000001838898818.png?HW-CC-KV=V1&HW-CC-Date=20261008T161714Z&HW-CC-Expire=31536000000&HW-CC-Sign=759ECA76C26833E44C7A5C30018845E7E74100844AEF6C6E508D36AB3115A779)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
