# 首次核准（备案）

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 打开华为云App，搜索并点击"ICP备案"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/dl8Scq_pQEagbOI_PyBjRQ/zh-cn_image_0000001803578168.png?HW-CC-KV=V1&HW-CC-Date=20260909T151816Z&HW-CC-Expire=31536000000&HW-CC-Sign=068E8D693A50FC116303859A4BBE196349F7139B79D5F8E9D174ADED640341CC)

2. 填写主办单位和快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/6t9JaKpeTuuHIWzGdX4skg/zh-cn_image_0000001838739578.png?HW-CC-KV=V1&HW-CC-Date=20260909T151816Z&HW-CC-Expire=31536000000&HW-CC-Sign=D320FECDCD0E574D970D49342B4E13ACF95B0FE753889E38E00CA32AA30EEBED)

3. 填写主办单位和快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/a8zblQf9QQahpaC4NO7sZA/zh-cn_image_0000001884979137.png?HW-CC-KV=V1&HW-CC-Date=20260909T151816Z&HW-CC-Expire=31536000000&HW-CC-Sign=973227B5DD82CCDADF09CE54966A2E72E822A0AED0B6CCC388E729EE273AD615)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/CVzI_AbJTMmkdNcyFvbTUQ/zh-cn_image_0000001850416933.png?HW-CC-KV=V1&HW-CC-Date=20260909T151816Z&HW-CC-Expire=31536000000&HW-CC-Sign=654153067241635379BBB3115CB6B1FF38B10F9CBC5D4B489D0C29B344FD28FC)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/G2OPbGfAQZmAepdxSJfGjw/zh-cn_image_0000001838898818.png?HW-CC-KV=V1&HW-CC-Date=20260909T151816Z&HW-CC-Expire=31536000000&HW-CC-Sign=5C40184AEBB406E18C664FB42E3C6840FC37DF1131D89C7B42A5F83210F6EDED)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
