# 发布上架

打包测试通过后，前往AGC控制台发布上架，为用户提供创新互动卡片服务。  

#### 了解上架规则

认真阅读[华为应用市场审核指南](https://developer.huawei.com/consumer/cn/doc/app/50104)和[游戏审核FAQ](https://developer.huawei.com/consumer/cn/doc/app/50118)，了解华为应用市场的上架规则。  

#### 提交上架申请

![](https://media:101784273674145476)  
请在提交上架申请前先联系相关责任人：QQ：2851508897，对创新互动卡片进行审核体验。

前往AGC控制台填写信息并提交上架申请，具体操作请参见[发布应用（APP）](https://developer.huawei.com/consumer/cn/doc/app/agc-help-releaseharmony-0000001933963166)和[审核与发布](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-playable-subpackage-0000002090384493#section229320301422)。
