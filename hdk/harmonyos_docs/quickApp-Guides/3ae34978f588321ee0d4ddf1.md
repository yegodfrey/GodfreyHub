# 快速开始

## 前期准备

### 注册认证账号

在开发快应用前，您需要拥有华为开发者联盟已经实名认证的开发者账号。

1. 注册详细操作请参见"[账号注册](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
2. 个人开发者和企业开发者的实名认证方式有所不同。
   * 个人开发者：通过 个人银行卡认证 或者 身份证人工审核认证。
   * 企业开发者：通过 对公银行打款认证 或者 企业资料人工审核认证。

### 创建快应用

在实际开发前，您需要登录 AppGallery Connect 创建快应用，详细操作参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。

### 安装开发工具

开发快应用需要使用华为快应用IDE、快应用加载器，参见"[安装开发工具](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)"下载并安装最新版本工具。

2. 选择"通用模板"页签，选择"快应用官方示例"模板，点击"下一步"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111453.35048718843099535702784694603887:50001231000000:2800:32A4C14F1D6619FC4BCEA92C92CC2A847D394D7F71187EE0E28E323A6F3FD9C3.png)

3. 填写项目信息后，点击"确定"。

* 应用名称：应用名称，用于在桌面图标、弹窗等处显示。例如：QuickAppDemo。
* 应用包名：发布的快应用为以.rpk为后缀的文件，此处即定义发布后的包名。推荐采用com.company.module的格式，例如：com.huawei.quickappdemo。
* 工作空间：项目工程存储路径。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111453.65452269811507267279279257653617:50001231000000:2800:E9EE8E15FF7222D58D2D05A7007351E0C725123AAA4478A175454DD121DDBE8E.png)

### 编写代码

在左侧工程目录选择相应的工程文件，参考快应用规范进行项目代码的编辑。

快应用规范包括：

* [框架](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-filestructure-0000001074564510)
* [组件索引](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-component-index-0000001073326871)中支持的组件
* [API索引](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-index-0000001073124891)中支持的API

### 预览调试

1. 将测试手机（最好为华为手机）使用USB数据线成功连接装有华为快应用IDE的电脑。打开测试手机的"开发者模式"，详细打开方式参见"[华为手机如何打开开发者选项](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-open-developer-option-0000001137005543)"。
2. 菜单选择"工具 > 生成证书"。
   * 没有签名文件：右下角弹出创建签名文件提示，点击"创建签名"，输入相关信息后，点击"创建"，或者点击"导入签名"，导入已有的签名文件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111453.78833527649288004574344122936205:50001231000000:2800:4F42ABD12C8B3D60DAE7663586F7581A53ADF4D7FC78C99A6EEA4235A47C075A.gif)


   * 已存在签名文件：弹出签名信息，点击"OK"。
3. 选择需要编译调试的文件，点击"运行"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111453.91419332152341550131854099499156:50001231000000:2800:D5D204442896ACEB4967D5B46A748793BA50723FE6658C7E1409026626BF41FD.png)

4. 在弹出页面选择运行的设备，点击"确认"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111453.03649205696910261964906655194605:50001231000000:2800:550BD390FB11A20EE7003B97E50BF68EF9B36C93DCF7DF6A59E9238A8116B09F.png)

5. 如果手机上没有安装快应用引擎，将在右下角弹出提示框，点击"安装"进行安装。已安装则跳过此步骤。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111453.35397814580956199608429309611319:50001231000000:2800:FA13FE50EC8894B073C11FA3CB30C0E44636AC542E19311A15C9D7C7B841F76D.png)

### 打包版本

1. 菜单选择"构建 > 打包正式版本"。
2. 确认版本和签名信息后，点击"确定"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111453.70954623533393562376280177249782:50001231000000:2800:2EB8D2FC3DD64309D952A19B2D5760D02C8BE6A1522E1C46F78CF1401004861E.png)

3. 查看打包过程日志，打包成功后，将自动打开项目的dist文件夹，里面的rpk文件即为生成的快应用包。

## 审核上架

开发完成，需准备好[快应用所需资质文件](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-prepare-doc-0000001129385459)，登录 AppGallery Connect [提交审核](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-app-release-0000001129563721)，审核通过后，您的快应用将成功上架华为应用市场。
