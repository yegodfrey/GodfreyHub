# 打开已有项目

打开已有工程只需在项目目录选择已经存在的快应用工程，一般来说，该目录是存在 project.config.json 或者 fide.project.config.json 的目录，注意有一些代码框架的根目录并非快应用的根目录，请注意甄别。
