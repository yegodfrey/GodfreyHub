# 取消接入

取消接入将在工信部删除快应用在华为接入商的核准（备案）信息，若快应用服务还需使用，建议在新的接入商完成核准（备案）后再取消接入，否则快应用可能会被通管局清理。操作步骤如下：

1. 进入[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，登录华为云核准（备案）系统，左侧菜单栏点击"我的核准（备案）"，右侧页面选择"更多 > 取消接入"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175843.06966738118512377888862660603501:50001231000000:2800:81C8DC374BF64A62DAECD33C22E1534DE8122D398454E4B633AB19886DD81933.png "点击放大")
2. 在"取消接入"页面验证负责人的手机/邮箱，选择注销原因后点击"下一步，提交审核"，在弹出的"确认要取消接入互联网信息"窗口点击"确认"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175843.64743642736332862589563009997490:50001231000000:2800:A276719BAF39E00CFC3205CC192DA22CAD0A3B89B8ED62D7FF5F953B66814A3F.png "点击放大")
