# 升级快应用

#### 提交升级申请

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的应用"。
2. 点击待升级的版本。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211203170226.32523667190580764351336032091155:50001231000000:2800:490D4222185AB43C8C3EA81C6F583DC188D209247BFDB7175B49D9E9BFCC563C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

3. 点击右上角的"升级"，生成新的版本。
4. 更新升级版本需要修改的内容，点击右上角的"提交审核"。 待审核通过，新版本的内容将更新到华为应用市场。
