# 生成睫毛图

快游戏开发者工具支持睫毛图工具，帮助您生成统一的小游戏图标样式。

1. 在快游戏开发者工具中打开需要生成小游戏图标的项目，点击"工具 > 睫毛图工具"，进入生成睫毛图页面。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/tRfGZXrPTqK3KoVcsdyXCQ/zh-cn_image_0000002524271824.png?HW-CC-KV=V1&HW-CC-Date=20260909T135813Z&HW-CC-Expire=31536000000&HW-CC-Sign=762F78C08816CBB423E0E308739D7978601980CF89AB09844EF207346F5284EE)

2. 点击"选择图片"，选择用于制作睫毛图的本地图片。图片尺寸及要求如下：

   |参数|要求|
   |:---|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |图片格式|格式为PNG、JPEG或JPG的静态图片资源。|
   |图片尺寸|大小为1024px*1024px的正方形图片。|
   |图片背景|不透明。|
   |质量要求|图标内容需清晰可辨，避免存在模糊、锯齿、拉伸等问题。详情请参见[元服务图标设计规范](https://developer.huawei.com/consumer/cn/doc/design-guides/ux-guidelines-overview-0000001900384976#section158386422413)。|

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/zIetwmXZRe2SnIYzHSoaAw/zh-cn_image_0000002555271915.png?HW-CC-KV=V1&HW-CC-Date=20260909T135813Z&HW-CC-Expire=31536000000&HW-CC-Sign=A6CA890C79C3316A4B694DBE00D7B82BC072720F22484E14AF4BDCCAFE88205D)
3. 图片导入后可以选择图片外圈颜色。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/Gn5me62yRFGcFWU58LTtDA/zh-cn_image_0000002524272134.png?HW-CC-KV=V1&HW-CC-Date=20260909T135813Z&HW-CC-Expire=31536000000&HW-CC-Sign=0CD5F785B2B02889DF9342849FA5A7B949FC6FCC918F0B0FCEB5F8F275FC5746)

4. 下载生成的睫毛图，并保存至您选择的位置。
   * 点击"下载元服务图标(512 * 512 px)"，此时保存的图标尺寸为512px*512px。可在小游戏module.json5文件的icon字段中配置该图标作为小游戏图标。
   * 点击"下载元服务AppGallery Connect上架图片（216 * 216 px）"，此时保存的图标尺寸为216px*216px。后续在AppGallery Connect上架小游戏时，需使用该图标作为应用图标上传。
