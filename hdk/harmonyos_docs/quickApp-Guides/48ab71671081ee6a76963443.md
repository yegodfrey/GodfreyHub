# 报表分析

#### 快应用用户报表

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"应用分析"。
2. 选择需要查询的快应用。
3. 点击"分发分析"页签，点击左侧导航"快应用用户报表"。
4. 选择起始时间和结束时间，但时间跨度不能超过31天，也可点击"上月"，"本周"，"本月"快速切换时间。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181438.24458372622159185697751731696041:50001231000000:2800:F219634A8302181126AF7BDEC1AF34201207B7467A64322863CBA17895C8AF32.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   点击"下载表格"，可将统计数据以Excel形式下载。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181438.95029471730742024657233220685576:50001231000000:2800:6C49367EA90FE1DCAE6663FE81ED58E2A72BCECFF77D11E39827778BBBB3CA35.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   统计项说明如下表所示。  

   |统计项|说明|
   |:------|:------------------------------|
   |用户总数|至少使用过一次快应用的用户总数（用户数已去重）。|
   |今日新增用户数|今天首次使用的用户（按设备标识统计）。|
   |日活用户数|今日使用快应用的用户数（用户数已去重）。|
   |日活率|日活用户数/用户总数。|
   |次日留存用户数|昨日首次使用的用户中今日再次使用的用户数。|
   |次日留存率|次日留存用户数/昨日新增用户数。|
   |7日留存用户数|第T-6日首次使用的用户中今日再次使用的用户数。|
   |7日留存率|7日留存用户数/昨日新增用户数。|
   |月活用户数|最近31日（含当天）中至少使用过一次的用户数（按设备标识统计）|

#### 快应用运行报表

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"应用分析"。
2. 选择需要查询的快应用。
3. 点击"分发分析"页签，点击左侧导航"快应用运行报表"。
4. 选择起始时间和结束时间，但时间跨度不能超过31天，也可点击"上月"，"本周"，"本月"快速切换时间。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181438.26655264510187775672876142202754:50001231000000:2800:A0B9CA1754BD6BE1682DA0E107531228C339F8B40E7563360633377EBE7177D2.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   点击"下载表格"，可将统计数据以Excel形式下载。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20211126181438.40779043152108328276732723106755:50001231000000:2800:9081F3FFF6CB4338ED6A8A1FD9446FD440762A0610B33DBACFBF0F1403753399.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   统计项说明如下表所示。  

   |统计项|说明|
   |:-------------|:---------------------------|
   |打开总次数|从此应用上线来用户打开的累计次数。|
   |今日打开次数|今天所有用户打开此应用的次数。|
   |今日使用时长（小时）|今天所有用户在前台使用此应用的时长。|
   |今日人均使用时长（秒/用户）|今日使用时长/日活用户数。|
   |桌面图标总数|从此应用上线来用户添加桌面图标 - 删除桌面图标的累计值|
   |今日净增桌面图标数|今日成功新添加到桌面的图标数量 - 删除数量|
   |我的快应用总数|从此应用上线后加入我的快应用累计值。|
   |今日净增我的快应用数|今日成功加到我的快应用-移出我的快应用的数量|
