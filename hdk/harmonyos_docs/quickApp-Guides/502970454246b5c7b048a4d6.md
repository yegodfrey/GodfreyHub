# RPK包私钥及证书生成

> 注意
>
> * 私钥证书只需生成一次，后续导出时可以复用。
> * 请妥善保留私钥证书文件，上架后签名文件不可变更，否则无法升级。

将Web快应用打包成RPK，需要对RPK进行签名，请参考以下方式生成私钥及证书：

```screen
#!/bin/bash
# 生成私钥
openssl genrsa -out private.pem 4096

# 生成证书签名请求(CSR)
openssl req -new -key private.pem -out cert.csr -sha256

# 生成自签名证书(有效期365天)
openssl x509 -req -days 365 -in cert.csr -signkey private.pem -out certificate.pem -sha256

# 可选：查看证书信息
openssl x509 -in certificate.pem -text -noout
```
