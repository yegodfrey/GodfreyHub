# 新增互联网信息

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面新增快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0d/v3/C4asRNtNS-qOvsOEZchb1w/zh-cn_image_0000001885060045.png?HW-CC-KV=V1&HW-CC-Date=20260909T172739Z&HW-CC-Expire=31536000000&HW-CC-Sign=7E41A9BE591328725C70DC3A78EC63CA60A8F337B031005A7B5A87E1DCFC697F)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/XBo9lJQATomYnfQOAsDOIg/zh-cn_image_0000001884985613.png?HW-CC-KV=V1&HW-CC-Date=20260909T172739Z&HW-CC-Expire=31536000000&HW-CC-Sign=90BB7D47243C5C46DE1EDA219C48BD2DBD07D012DCE6F08EF70C9255897F7C8D)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/UtjyIXsVTXKrlBlcBbZrWw/zh-cn_image_0000001885067009.png?HW-CC-KV=V1&HW-CC-Date=20260909T172739Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFF301A2AA925BB7C5E2F4C2B15A71B85C2D56B0C9A6B4A6CBADAE514254FAE6)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/w5KP9hR3TU6qHta5X3zrZQ/zh-cn_image_0000001850456961.png?HW-CC-KV=V1&HW-CC-Date=20260909T172739Z&HW-CC-Expire=31536000000&HW-CC-Sign=BCB0AD2C9D3034D4E409FDBB7F8D0B3BA48731CE8BFAD8611826A074224106A9)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/TRlHJQvCQzO1MfDYUbW1_g/zh-cn_image_0000001884992033.png?HW-CC-KV=V1&HW-CC-Date=20260909T172739Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFCD7CEBBD246AAC8B50930DD6F0CD8C2AC16165B524D66E205B5F40EB13A874)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
