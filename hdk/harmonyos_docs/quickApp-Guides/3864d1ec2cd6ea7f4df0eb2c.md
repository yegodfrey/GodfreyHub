# 新增互联网信息

## 前提条件

已前往应用市场下载最新版本的华为云App。

## 操作步骤

1. 在华为云App的"ICP备案"界面新增快游戏。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0d/v3/C4asRNtNS-qOvsOEZchb1w/zh-cn_image_0000001885060045.png?HW-CC-KV=V1&HW-CC-Date=20261008T182723Z&HW-CC-Expire=31536000000&HW-CC-Sign=9773D39FEE0C8AD6FCAD10C47619CCB90A3763D2BD88871F0F068A0705D3EF27)

2. 填写快游戏的基本信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/XBo9lJQATomYnfQOAsDOIg/zh-cn_image_0000001884985613.png?HW-CC-KV=V1&HW-CC-Date=20261008T182723Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD2BE20F721F4150A1570D81555FA8A2DBC2E2786BFD0030126298408A43A76F)

3. 填写快游戏的详细信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/UtjyIXsVTXKrlBlcBbZrWw/zh-cn_image_0000001885067009.png?HW-CC-KV=V1&HW-CC-Date=20261008T182723Z&HW-CC-Expire=31536000000&HW-CC-Sign=1DF3A32205E3F3D653043DED0A35DD4ABF3C096E8E37CCC3C04DA7F52D848289)

4. 根据提示上传提前准备好的附件材料。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/w5KP9hR3TU6qHta5X3zrZQ/zh-cn_image_0000001850456961.png?HW-CC-KV=V1&HW-CC-Date=20261008T182723Z&HW-CC-Expire=31536000000&HW-CC-Sign=8319E50B714CA77132A00F0ABD9A13D32D536D878CBB0E12F645C2138091FB43)

5. 互联网信息负责人人脸核验通过后提交初审。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/TRlHJQvCQzO1MfDYUbW1_g/zh-cn_image_0000001884992033.png?HW-CC-KV=V1&HW-CC-Date=20261008T182723Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4D7D3BF4EF601F761DE2ABB5F8380C33FA5B6E46B0F25F3FE354B49F6398266)

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机通畅。若需要修改核准（备案）信息，将以邮件形式通知。
7. 在华为平台通过人工初审后，需前往工信部网站核验短信验证码，详情请参见[工信部核验核验（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-filing-sms-verify-0000001818117885)。
