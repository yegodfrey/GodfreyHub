# IDE线下转换

## 转换流程

## 准入条件

使用华为快应用IDE将H5应用转换为快应用时，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 已[安装华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)。

## H5应用转换快应用

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.73588791629327552060685854036803:50001231000000:2800:3F29B1EF15B1E83FB45C8028EE5682B266AB57026399F878AB26B24B1BD7D99B.png) [查看视频教程](https://developer.huawei.com/consumer/cn/training/detail/101620467404043142)

使用华为快应用IDE进行转换时，有两种模式可供选择：

* System WebView Mode（推荐） 使用快应用web组件加载H5页面，本质上是使用WebView打开H5应用。

* Browser Custom Tabs Mode 使用快应用webview接口加载H5页面，在华为浏览器自定义tab页打开H5应用。

### System WebView Mode

1. 打开华为快应用IDE，在欢迎页选择"导入项目 > HTML5应用"。
2. 填写项目信息后，点击"确定"。
   * App URL：填写HTML5 APP链接。


   * 应用名称：桌面图标、弹窗等处显示的应用名称，可以和H5应用相同。
   * 应用包名：发布的快应用为以.rpk为后缀的文件，此处即定义转换完成后，发布成快应用的包名。

     请勿与之前在华为应用市场上架过的应用包名重复。推荐采用com.company.module的格式，如：com.xyz.quickapp。包名由数字、小写字母、"."组成，必须以字母开头，以数字或字母结尾，同时必须包含"."，长度不能超过255字节。
   * 应用图标：应用市场或者桌面显示的应用图标，必须与提交上架审核的应用图标一致。
   * 应用模式：选择"System WebView Mode"。
   * 导出路径：设置转换后项目存放路径。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.51301932863296778670525926114580:50001231000000:2800:1A59640D56DBDF49509AB6DD6FE2DEB5C7100BA5E2BB006D91B0461FFE6E0A66.png)
3. 配置manifest.json文件，文件详细说明请参见"[manifest文件](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621)"。
   1. 将icon修改为应用图标存放的路径。

      ```screen
      "icon": "/Common/logo.png",
      ```

   2. 设置display的orientation属性，用于控制应用显示的横竖屏。设置portrait为竖屏；设置landscape为横屏。如果没有设置，默认为竖屏。

      ```screen
      "display": {
          "pages": {
              "Hello": {
                  "titleBar": false,
                  "menu": false,
                  "orientation":"landscape"
              }
          }
      }
      ```

   3. 如果是针对应用市场上架版本的升级版本，versionCode的值必须在上架的版本号上加1，例如应用市场上架的版本为11，那么升级版本需设置为12。
4. 修改hello.ux文件。 allowthirdpartycookies：标识是否支持跨域cookies传递。如果网页需要跨域访问cookie，比如使用第三方账号登录，则必须设置该字段为true。

### Browser Custom Tabs Mode

> 说明
>
> * 当使用System WebView Mode转换的快应用有问题时，再考虑使用Browser Custom Tabs Mode转换。
> * 使用Browser Custom Tabs Mode转换依赖华为浏览器App，所以需要针对华为浏览器未安装的情况做容错处理。

1. 打开华为快应用IDE，在欢迎页选择"导入项目 > HTML5应用"。
2. 填写项目信息后，点击"确定"。
   * App URL：填写HTML5 APP链接。


   * 应用名称：桌面图标、弹窗等处显示的应用名称，可以和H5应用相同。
   * 应用包名：发布的快应用为以.rpk为后缀的文件，此处即定义转换完成后，发布成快应用的包名。

     请勿与之前在华为应用市场上架过的应用包名重复。推荐采用com.company.module的格式，如：com.xyz.quickapp。包名由数字、小写字母、"."组成，必须以字母开头，以数字或字母结尾，同时必须包含"."，长度不能超过255字节。
   * 应用图标：应用市场或者桌面显示的应用图标，必须与提交上架审核的应用图标一致。
   * 应用模式：选择"Browser Custom Tabs Mode"。
   * 导出路径：设置转换后项目存放路径。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.30221042697485046180573059055146:50001231000000:2800:F4504F87CFE49B151EB9124E4BC8FB4BB5D99C521682E102B872C90911BFD091.png)
3. 配置manifest.json文件，文件详细说明请参见"[manifest文件](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621)"。
   1. 将icon修改为应用图标存放的路径。

      ```screen
      "icon": "/Common/logo.png",
      ```

   2. minPlatformVersion最小需配置为1078。

      ```screen
      "minPlatformVersion": 1078,
      ```

   3. 设置display的orientation属性，用于控制应用显示的横竖屏。设置portrait为竖屏；设置landscape为横屏。如果没有设置，默认为竖屏。

      ```screen
      "display": {
          "pages": {
              "Hello": {
                  "titleBar": false,
                  "menu": false,
                  "orientation":"landscape"
              }
          }
      }
      ```

   4. 如果是针对应用市场上架版本的升级版本，versionCode的值必须在上架的版本号上加1，例如应用市场上架的版本为11，那么升级版本需设置为12。
4. 修改hello.ux文件。 由于此转换模式依赖华为浏览器App，所以需要在webview.loadCustomTabsUrl的fail回调中，使用webview.loadUrl()针对华为浏览器未安装的情况做容错处理。

## 运行预览快应用

1. 菜单选择"工具 > 生成证书"。
2. 在右下角弹出如下提示框。新建签名文件点击"创建签名"，已有签名文件点击"导入签名"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.49163534462835481612736264074382:50001231000000:2800:DF53A40BB47EBEB3C84B09AD2F59CB98A1EFEC850F4788E8C92AD76DAA4C0A4A.png)

3. 将手机与电脑成功连接，并打开"开发者调试"模式，打开"开发者模式"的方法请参见"[华为手机如何打开开发者选项](https://developer.huawei.com/consumer/cn/doc/quickapp-open-developer-option)"。
4. 连接成功后，选择需要编译的文件，点击"运行"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.64941921972179707832935023658723:50001231000000:2800:F814DD0756454F439D1BDE9FA5140CFFD046B74B462A3A9B5135113BD12FF346.png)

5. 选择已连接的设备，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.37008705733501828614961851358698:50001231000000:2800:D0C067D44748C8701662FF7283ECF574FA71C2367FBA0E6E8629081B02640C88.png)

6. 如果手机上没有安装华为快应用加载器，将在右下角弹出如下提示框，点击"安装"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.40383959967839525304239843696045:50001231000000:2800:46F44170F4C95554C33C1B2C503DA92C110852F543C54BAF7EAF3BF69B5752F9.png)

7. 安装成功后，在弹出授权页面给予授权，即可预览转换后快应用的效果。

## 打包快应用

1. 菜单选择"构建 > 打包正式版本"。 已有签名文件展示签名信息，没有则创建签名文件。

2. 点击"确定"，打包正式版本的rpk包，打包完成将自动打开项目的dist目录，rpk包即存放在此处。

生成的rpk包即可提交华为应用市场进行审核，详细操作参见"[提交审核](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-app-release-0000001129563721)"。
