# 自动保存

编辑代码后，工具会自动帮助用户保存当前的代码编辑状态，直接关闭工具或者切换到别的项目，并不会丢失已经编辑的文件状态，但需要注意的是，只有用户主动保存文件，修改内容才会真实的写到硬盘上。 如果设置中开启了 "自动保存"（文件 -> 自动保存），工具在修改文件时会自动保存到硬盘中，无需手动保存的效果。
