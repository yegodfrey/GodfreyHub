    * 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见“[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)”。
    * 在AppGallery Connect上完成快应用的创建，详细参见“[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)”。
    * 在AppGallery Connect上已[开通应用内支付服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-iap-kit-0000001079803876)。
    * 应用内支付服务是华为扩展接口，而非厂商联盟规范，请[安装华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)进行接入。
快应用中调用支付接口 华为提供了非托管商品支付和托管商品支付两种支付方式：
    * 非托管商品支付：应用中的虚拟商品信息不在华为AppGallery Connect中录入，由开发者自行管理，在使用应用内支付服务时开发者需自行传入商品价格。非托管商品支付无法支持商品信息自动全球化能力，如果涉及多国家、多币种的支付形式，需要开发者自行区分。
    * 托管商品支付：应用中的虚拟商品信息提前在华为AppGallery Connect中配置，应用在使用应用内支付服务时无需传入商品价格、国家码等，华为支付系统会根据商品ID自动判断所需要支付的商品名称，货币种类以及价格等信息。
[h2]非托管商品支付
    1. 调用 [pay.getProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-0000001074424275#section613101611151) 接口判断当前设备是否支持华为应用内支付服务。 调用接口返回 huawei 表示支持，否则表示不支持。后续功能开发和接口调用必须在设备支持应用内支付服务的前提进行。
    2. 组装支付参数，进行参数签名。支付接口的orderInfo参数订单信息是一个JSON对象，包括多个华为支付需要的参数。orderInfo详细说明请参见 [pay.pay](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-0000001074424275#section8402524171613)。
    3. 调用 [pay.pay](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-pay-0000001074424275#section8402524171613) 接口进行支付。前一步已经对支付参数进行签名，这一步需要将支付参数按照接口要求传入，进行支付。  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111515.14286591044499385160464380559223:50001231000000:2800:54D6BBCD05389A0FDF9411768C8A5D9B15BE0A89B8F4FFA42D3C11AA9E033E77.png) 步骤3传入的参数值需要与步骤2 sign签名时的参数值保持一致，否则会导致签名失败，无法调用接口。 调用的示例代码如下：

服务端处理支付结果 [h2]处理机制 当用户使用华为应用内支付进行付款成功后，华为支付服务器将回调开发者的服务器返回支付结果。
    * 回调的URL：开发者在华为开发者联盟上开通应用内支付服务时填入的“回调地址”，或者在pay.pay接口中传入的URL。当两个地方都传入时，优先采用华为开发者联盟上配置的“回调地址”。
    * 通知重发：若开发者返回结果为非成功响应（返回的result值为0之外的值），将对同一笔订单的通知进行周期性重发。
    * 重发机制：共2天，前3次每20s尝试一次，4-20次每200s尝试一次，之后每3小时尝试一次。

[h2]签名机制
    1. 开发者服务器接收到回调报文中除去sign和signType的参数需要参与签名。参数可能会变化，所以请不要写死。 在提供的Demo中，使用如下代码获取所有的参数：
           
           /**
            * @param request
            * @return 本接口Content-Type是：application/x-www-form-urlencoded，对所有参数，会自动进行编码，
            * 接收端收到消息也会自动根据Content-Type进行解码。 同时，接口中参数在发送端并没有进行单独的URLEncode
            * (sign和extReserved、sysReserved参数除外)，所以，在接收端根据Content-Type解码后，即为原始的参数信息。
            * 但是HttpServletRequest的getParameter
            * ()方法会对指定参数执行隐含的URLDecoder.decode(),所以，相应参数中如果包含比如"%"，就会发生错误。
            * 因此，我们建议通过如下方法获取原始参数信息。*  
            */
           public Map<String, Object> getValue(HttpServletRequest request)
           {
               String line = null;
               StringBuffer sb = new StringBuffer();
               try
               {
                   request.setCharacterEncoding("UTF-8");
                   InputStream stream = request.getInputStream();
                   InputStreamReader isr = new InputStreamReader(stream);
                   BufferedReader br = new BufferedReader(isr);
                   while ((line = br.readLine()) != null)
                   {
                       sb.append(line).append("\r\n");
                   }
                   System.out.println("The original data is : " + sb.toString());
                   br.close();
               }
               catch (Exception e)
               {
                   e.printStackTrace();
               }
               catch (Throwable e)
               {
                   e.printStackTrace();
               }
               String str = sb.toString();
               Map<String, Object> valueMap = new HashMap<String, Object>();
               if (null == str || "".equals(str))
               {
                   return valueMap;
               }
               String[] valueKey = str.split("&");
               for (String temp : valueKey)
               {
                   String[] single = temp.split("=");
                   valueMap.put(single[0], single[1]);
               }
               // 接口中，如下参数sign和extReserved、sysReserved是URLEncode的，所以需要decode，其他参数直接是原始信息发送，不需要decode 
               try
               {
                   String sign = (String) valueMap.get("sign");
                   String extReserved = (String) valueMap.get("extReserved");
                   String sysReserved = (String) valueMap.get("sysReserved");
                   if (null != sign)
                   {
                       sign = URLDecoder.decode(sign, "utf-8");
                       valueMap.put("sign", sign);
                   }
                   if (null != extReserved)
                   {
                       extReserved = URLDecoder.decode(extReserved, "utf-8");
                       valueMap.put("extReserved", extReserved);
                   }
                   if (null != sysReserved)
                   {
                       sysReserved = URLDecoder.decode(sysReserved, "utf-8");
                       valueMap.put("sysReserved", sysReserved);
                   }
               }
               catch (Exception e)
               {
                   e.printStackTrace();
               }
               return valueMap;
           }

    2. 参数排序连接。 对所有参数的key进行ASCII码的增序排序，若遇到相同首字母，则看第二个字母，以此类推。 排序完成之后，再把所有数组值以"&"连接起来，如： BankId=JUNNETNET&amount=2.00&notifyTime=1353317037173&orderId=918370122485714G&payType=2&productName=珍珠项链&requestId=1352286825177&result=0&userName=lilan 这串字符串便是待签名字符串。 示例代码如下：
           
           /**
            * 将除了sign的所有请求参数按照key的ASCII码进行升序排列，然后拼接成
            * key1=value1&key2=value2&key3=value3.....  
            * @param params 上面获取的所有请求参数
            * @return 用于签名校验的字符串
            */
           public static String getSignData(Map<String, Object> params)
           {
               StringBuffer content = new StringBuffer();
               // 按照key做排序 
               List<String> keys = new ArrayList<String>(params.keySet());
               Collections.sort(keys);
               for (int i = 0; i < keys.size(); i++)
               {
                   String key = (String) keys.get(i);
                   if ("sign".equals(key)) // 如果是sign字段，不作为签名校验参数 
                   {
                       continue;
                   }
                   String value = (String) params.get(key);
                   if (value != null)
                   {
                       content.append((i == 0 ? "" : "&") + key + "=" + value);
                   }
                   else
                   // 如果value为null，则写成：key=&key1=value1 
                   {
                       content.append((i == 0 ? "" : "&") + key + "=");
                   }
               }
               return content.toString();
           }
