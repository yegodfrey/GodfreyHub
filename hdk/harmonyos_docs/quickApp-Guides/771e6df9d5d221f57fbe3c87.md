# 通告栏组件

#### 简介

通告栏（noticebar）组件常用于展示公告信息、系统通知、广告通知等场景，通告栏一般具有如下特点：

* 可显示完整内容，也可省略显示
* 可设置公告文字颜色、背景颜色
* 可设置喇叭等图标
* 可关闭
* 可滚动展示文字

基本布局代码如下：

```
<template>
<div class="container">
<text class="section">基本布局</text>
<noticebar class="notice" show-icon="true" show-close="true" scrollable="true"

</noticebar>
</div>
</template>
```

#### 开发指引

#### 自定义子组件

1. 定义布局样式。 通告栏组件布局包括几个部分：展示公告文字、关闭按钮、喇叭图标、滚动文字、显示更多内容。

   1. 采用横向布局。
   2. block配套if、else命令控制不同组合布局，减少布局嵌套。

   ```
   <template>
     <!-- Only one root node is allowed in template. -->
     <div class="container" style="background-color: {{backgroundColor}};display:{{displaynotice}}">
       <image class="img" if="{{showClose}}" src="./Images/close.png" onclick="close"></image>
       <image class="img" if="{{showIcon}}" src="./Images/sound.png"></image>
       <block if="{{scrollable}}">
         <div id="box" class="box">
           <text id="txt1" class="scrolltxt" style="width: {{textWidth}};color: {{color}}">{{ text }}</text>
         </div>
       </block>
       <block elif="{{showGetMore}}">
         <text class="elliptxt" style="color: {{color}}">{{ text }}</text>
         <div class="moreBox" onclick="getMore">
           <text class="moretxt" style="color: {{moreColor}}">{{ moreText }}</text>
           <image class="img" src="./Images/more.png"></image>
         </div>
       </block>
       <block else>
         <text class="plaintxt" style="color: {{color}}">{{ text }}</text>
       </block>
     </div>
   </template>
   ```

2. 规划属性和支持的事件。 支持的属性：

   |属性|类型|默认值|描述|
   |:--------------|:------|:------|:-------------------------------|
   |text|String|-|通告栏的文字内容。|
   |moreText|String|-|更多文字，当通告栏的内容省略显示时使用。|
   |backgroundColor|Boolean|true|通告栏的背景色。|
   |color|Color|#de8c17|通告栏的文字颜色。|
   |speed|Number|160|通告栏的文字滚动速度，默认1s滚动160px。|
   |moreColor|Color|#999999|更多文字颜色。|
   |scrollable|Boolean|false|是否滚动。 说明： 设置为true时，只能单行显示通告栏的文字。|
   |showIcon|Boolean|false|左侧是否显示图标。|
   |showClose|Boolean|false|是否显示关闭按钮。点击关闭按钮后，通告栏消失。|
   |showGetMore|Boolean|false|是否显示更多文字。|

   支持的事件：  

   |事件名称|参数|描述|
   |:------|:-|:---------|
   |getmore|{}|查看更多内容的事件。|

#### 实现滚动通告栏

1. 滚动通告栏在组件渲染出来片刻后才开始滚动。 初始滚动是从当前位置向左滚动，当所有通告内容完全滚动消失后，再从右向左滚动。

2. 当通告栏文字滚动时，与"更多"相关的属性moreText、showGetMore、moreColor是不生效的，并且单行滚动显示所有的通告。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221207150422.33637899521936919998937733367813:50001231000000:2800:7A5A6B28CC5DF391FBE1D092D76A1FD237EB989FCF2AAB065E8E36FC2F21B8BD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   需要提前计算好单行滚动文字所占用的实际长度，否则会滚动不全。

   当文字总长度小于设备长度时，将通告栏文字长度设置为设备长度。由于快应用暂未提供"计算文字长度"的接口，实现滚动时必须要依赖这个长度，否则文字默认是被截断的。因此本文做了简单设置：文字完整显示长度=单文字长度\*字符数量。
3. 通过快应用translateX动画实现滚动，涉及到两个动画：从当前位置滚动的动画和从右边缘位置向左边缘位置滚动的重复动画。 动画时间取决于文字长度，文字越长，动画时间越久。

```
onInit() {
  console.log("oninit showGetMore=" + this.showGetMore);
  console.log("oninit scrollable=" + this.scrollable);
  if (this.scrollable) {
    this.initScrollNoticeSize();
  }
},

initScrollNoticeSize() {
  this.deviceWidth = device.getInfoSync().screenWidth;
  console.info("initScrollNotice deviceWidth=" + this.deviceWidth);
  let len = this.text.length;
  console.log("onInit txt len=" + len);
  let w = this.singleTxtWidth * len;
  if (w < this.deviceWidth) {
    this.textWidth = this.deviceWidth;
  } else {
    this.textWidth = w;
  }
  console.log("textWidth= " + this.textWidth);
  setTimeout(() => {
    //this.calTextWidth();
    this.calBoxWidth();
  }, 1000);
},
```

#### 实现关闭通告栏

1. 点击关闭按钮，通告栏消失。由于IDE限制了根节点不能使用if、show命令，此处设置css的display属性为none，实现布局不可见。
2. 如果父组件需要监听关闭事件，close()方法中还需要调用$emit('close')通知父组件。

```
close: function () {
  console.log("close=");
  this.stopAnimation = true;
  this.displaynotice = "none";
  this.$emit('close');
},
```

#### 实现"更多"功能

当通告栏内容过多，设备的空间有限而显示不完时，需要用到"更多"功能。一般来说，点击"更多"跳转到一个更详细的通告页面。

1. 父组件中处理"更多"的跳转逻辑。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221207150422.38851046614494927591875967415089:50001231000000:2800:0ABBBB742AA1C2B862FEAC0BDF5131FA145C34CBB1BFEC6E58B25CD4383537A6.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   不要在子组件中处理跳转逻辑，每个通告栏跳转的详情页面是不一样的。

   ```
   getMoreDetail:function (evt){
     console.info("getMoreDetail evt:"+JSON.stringify(evt));
     prompt.showToast({
       message: JSON.stringify(evt.detail),
       duration: 2000,
       gravity: 'center'
     })
   }
   ```

2. 父组件中监听"更多"事件。

   ```
   <noticebar  class="notice"  show-get-more="true"  more-text="查看更多"  @getmore="getMoreDetail"  text="[单行不能显示完整内容，省略显示] 快应用是一种基于行业标准开发的新型免安装应用。" ></noticebar>  
   ```

3. 子组件中触发通知。

   ```
   getMore: function () {
     console.info("getMore"+this.text);
     this.$emit('getmore', this.text);
   },
   ```

#### 遇到的问题

#### 图标压缩、"查看更多"显示不全

效果图如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221207150422.21828658756255882218258631960419:50001231000000:2800:27D178A942B2F6D6AD96B41B0A1F30BB1CCD0A8BCE09A871058033D890936769.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

【问题分析】组件的css属性flex-shrink默认值是1，当引擎计算出空间不够时，会进行压缩显示。

【解决方法】把flex-shrink设置为0，表示不对组件进行压缩。  

#### "查看更多"未显示在屏幕右侧

效果图如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221207150422.58196084672584400623575953676023:50001231000000:2800:D3F65C1510B98F6F2830AF990DDF0FFABA01B464A7D35D5CA477874196570C6D.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

【解决方法】设置elliptxt的宽度为100%，这样"查看更多"就固定显示在屏幕右侧。

```
<script>
  import device from '@system.device';
  module.exports = {
    props: {
      text: {
        type: String,
        default: ''
      },
      moreText: {
        type: String,
        default: ''
      },
      backgroundColor: {
        type: String,
        default: '#fffbe8'
      },
      speed: {
        // 默认1s滚动100px
        type: Number,
        default: 160
      },
      color: {
        type: String,
        default: '#de8c17'
      },
      moreColor: {
        type: String,
        default: '#999999'
      },

      scrollable: {
        // 是否滚动，默认不滚动
        type: Boolean,
        default: false
      },
      showIcon: {
        // 是否显示左侧icon
        type: [Boolean, String],
        default: false
      },
      showGetMore: {
        // 是否显示右侧查看更多
        type: [Boolean, String],
        default: false
      },
      showClose: {
        // 是否显示左侧关闭按钮
        type: Boolean,
        default: false
      }

    data() {
      return {
        singleTxtWidth: 80,
        textWidth: 750,
        deviceWidth: 0,
        boxWidth: 0,
        speed: 100,
        stopAnimation: false,
        displaynotice: "flex",
        animationDuration: 'none',
        animationPlayState: 'paused',
        animationDelay: '0s'
      }
    },
    onInit() {
      console.log("oninit showGetMore=" + this.showGetMore);
      console.log("oninit scrollable=" + this.scrollable);
      if (this.scrollable) {
        this.initScrollNoticeSize();
      }
    },
    initScrollNoticeSize() {
      this.deviceWidth = device.getInfoSync().screenWidth;
      console.info("initScrollNotice deviceWidth=" + this.deviceWidth);
      let len = this.text.length;
      console.log("onInit txt len=" + len);
      let w = this.singleTxtWidth * len;
      if (w < this.deviceWidth) {
        this.textWidth = this.deviceWidth;
      } else {
        this.textWidth = w;
      }
      console.log("textWidth= " + this.textWidth);
      setTimeout(() => {
        //this.calTextWidth();
        this.calBoxWidth();
      }, 1000);
    },
    calTextWidth() {
      var that = this;
      this.$element('txt1').getBoundingClientRect({
        success(res) {
          let msg = JSON.stringify(res);
          console.log('calTextWidth 当前坐标：' + msg);
          that.textleft = res.left;
          console.log("calTextWidth this.textleft=" + that.textleft);
        },
        fail() {
          console.log('calTextWidth 获取失败');
        },
        complete() {
          console.log('calTextWidth complete')
        }
      })
    },
    calBoxWidth() {
      var that = this;
      this.$element('box').getBoundingClientRect({
        success(res) {
          let msg = JSON.stringify(res);
          console.log('calBoxWidth 当前坐标：' + msg);
          that.boxWidth = res.width;
          that.startAnimateScroll();
        },
        fail() {
          console.log('calBoxWidth 获取失败');
        },
        complete() {
          console.log('calBoxWidth complete')
        }
      })
    },
    startAnimateScroll() {
      var that = this;
      this.duration = this.textWidth / this.speed * 1000;
      console.log("startAnimateScroll   this.duration=" + this.duration)
      this.animationDelay = this.boxWidth / this.speed;
      let dis = -1 * this.textWidth;
      var options = {
        duration: this.duration,
        easing: 'linear',
        delay: this.animationDelay,
        fill: 'forwards'
      }
      var frames = [
        {
          transform: {
            translateX: 0,
          }
        },
        {
          transform: {
            translateX: dis,
          }
        }];
      var animation = this.$element('txt1').animate(frames, options);
      animation.play();
      animation.onfinish = function () {
        console.log("animation  onfinish");
        that.animationLoop();
      }
      animation.oncancel = function () {
        console.log("animation  oncancel");
      }
    },
    animationLoop() {
      if (this.stopAnimation) {
        return;
      }
      var that = this;
      this.duration = this.textWidth / this.speed * 1000;
      var options = {
        duration: this.duration, easing: 'linear',
        delay: 0,
        fill: 'forwards'
      }
      let value1 = this.boxWidth + 200;
      console.log("animationLoop value1=" + value1);
      let value2 = -1 * this.textWidth;
      var frames = [
        {
          transform: {
            translateX: value1,
          }
        },
        {
          transform: {
            translateX: value2,
          }
        }];
      var animation = this.$element('txt1').animate(frames, options);
      animation.play();
      animation.onfinish = function () {
        console.log("animation  onfinish");
        that.animationLoop();
      }
      animation.oncancel = function () {
        console.log("animation  oncancel");
      }
    },

    onDestroy: function () {
      console.log("ondestroy");
      this.stopAnimation = true;
    },
    click: function () {

    },
 close: function () {
  console.log("close=");
  this.stopAnimation = true;
  this.displaynotice = "none";
  this.$emit('close');
 },
 getMore: function () {
  console.info("getMore"+this.text);
  this.$emit('getmore', this.text);
 },
}
</script>
```
