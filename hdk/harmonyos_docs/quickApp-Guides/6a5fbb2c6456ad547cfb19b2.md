    * 当前暂不提供接口查询手机是否支持H5点击组件跳转快应用的能力，请务必做好fallback，确保在无法正常跳转时，仍然有合适的H5页面为用户提供服务。 
    * 满足如下条件的华为手机支持H5点击组件跳转快应用：麒麟芯片、系统为HarmonyOS2.0及以上或Android 8.1或Android 9.0及以上。如果需要在第三方媒体投放快应用，请确保访问投放渠道的手机系统版本为HarmonyOS2.0及以上或Android 8.1及以上。 
H5点击组件跳转快应用是指通过在H5页面中使用快应用官方推荐的点击组件，在用户主动点击时，可以发起跳转到指定快应用的请求。 点击组件的样式可以自定义，也可以在页面中使用多个点击组件，具体使用方式如下：
    1. 在网页嵌入以下js脚本地址。
           
           <script
             type="text/javascript"
             src="//statres.quickapp.cn/quickapp/js/qa_router.min.js"
           />

    2. 在页面合适位置插入<qa-router-button>标签。
           
           <qa-router-button
             data-package-name="com.hybrid.demo.sample"
             data-page="/"
             data-params='{"id": 1}'
             data-design-params='{"fontSize": 16,"designWidth": 1080}'
             data-click-event='{"eventName": "handleClickEvent", "eventParams": "anyString"}'
             style="height: 2rem"
           >
             <templates>
               <!-- <templates> 中插入布局元素，以下仅为示例，开发者可根据业务需要定制 DOM 及 样式 -->
               <div id="container">
                 <img src="icon.png" ></img>
                 <button>秒开</button>
               </div>
             </templates>
             <styles>
               <!-- <styles> 中插入样式 -->
               #container { ... }
               img { ... }
               button { ... }
             </styles>
           </qa-router-button>
           <script>
             function handleClickEvent() { /* 点击回调执行的方法 */ }
           </script>

参数 | 类型 | 是否必填 | 说明  
---|---|---|---  
data-package-name | String | 是 | 配置跳转快应用的包名，包名和manifest.json文件中的“[package](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-manifest-0000001073698621#ZH-CN_TOPIC_0000001073698621__p1779975704120)”属性保持一致。  
data-page | String | 否 | 配置跳转的页面路径，对应manifest.json文件中router.pages的[path](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-manifest-0000001073698621#ZH-CN_TOPIC_0000001073698621__p9659115116540)字段。 说明：  如果不传path值或者path值为空字符串，跳转时会打开快应用首页。  
data-params | String | 否 | 配置透传给快应用页面的参数。 通过params传入的参数值，会赋值到当前快应用页面的 public 同名字段。  
data-design-params | String | 否 | 用于指定设计稿宽度及默认font-size大小，以适配不同宽度的屏幕。 您可以根据设计稿所标尺寸与默认font-size计算出元素rem单位值。点击组件会根据实际屏幕宽度、 designWidth值以及开发者指定的元素rem值重新计算元素实际大小。 说明：  不设置则默认fontSize为16、designWidth为1080。  
data-click-event | String | 否 | 配置用户点击后回调执行的方法，可用于数据上报。
       * eventName：click事件回调执行的方法名称 
       * eventParams：回调方法传入的参数   
在通用框架中使用点击组件 [h2]Vue Vue中使用点击组件时，可以控制传入的参数、动态传值、定制 DOM 结构。
    
    // Vue 2.x
    Vue.config.ignoredElements = [/^qa-router-button|templates|styles/]
    
    // xxx.vue
    <div v-for="(item, index) in items">
      <qa-router-button
        :data-package-name="item.name"
        :data-page="item.page"
        :data-params="item.params"
        data-design-params='{"fontSize": 16,"designWidth": 1080}'
        data-click-event='{"eventName": "handleClickEvent", "eventParams": "anyString"}'
        style="height: 2rem"
      >
        <templates>
          <!-- <templates> 中插入布局元素，以下仅为示例，开发者可根据业务需要定制 DOM 及 样式 -->
          <div id="container">
            <img src="item.icon" :class="item.classType" ></img>
            <button>秒开</button>
          </div>
        </templates>
        <styles>
          <!-- <styles> 中插入样式 -->
          #container { ... }
          img { ... }
          button { ... }
        </styles>
      </qa-router-button>
    </div>
    // index.html
    <script>
      function handleClickEvent() { /* 点击回调执行的方法 */ }
    </script>

[h2]React React中使用点击组件时，需要在<templates>中使用内联样式定制样式。
    
    // xxx.js
    function App() {
      return (
        <div className="App">
          <qa-router-button
            data-package-name="com.hybrid.demo.sample"
            data-page="/"
            data-params="{&quot;id&quot;: 1}"
            data-design-params="{&quot;fontSize&quot;: 161,&quot;designWidth&quot;: 10380}"
            data-click-event="{&quot;eventName&quot;: &quot;handleClickEvent&quot;, &quot;eventParams&quot;: &quot;anyString&quot;}"
            style={{ height: '2rem' }}
          >
            <templates is="x3d">
              <div id="container">
                <button style={{ backgroundColor: 'red' }}>秒开</button>
              </div>
            </templates>
          </qa-router-button>
        </div>
      )
    }
    
    // index.html
    <script>
      function handleClickEvent() { /* 点击回调执行的方法 */ }
    </script>
