# 首次核准（备案）

在华为云核准（备案）系统中首次核准（备案）主体信息和快应用信息。操作步骤如下：

1. 进入[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，登录华为云核准（备案）系统，填写主办单位信息、互联网信息，完成后点击"验证核准（备案）类型"。在弹出的窗口中点击"下一步"。

2. 在"主体信息"页面填写主办单位信息、负责人信息，完成后点击"下一步，填写互联网信息"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/tFleUZt6RK-nctbohRuOZQ/zh-cn_image_0000001997012693.png?HW-CC-KV=V1&HW-CC-Date=20260909T161025Z&HW-CC-Expire=31536000000&HW-CC-Sign=6DB5A86DB5E34D113B37EC75C2625134BC389C5B24262391965A0DEE0CB9240F "点击放大")

3. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/04/v3/2DdJdSvdTUq-S66O3FJauA/zh-cn_image_0000001960485476.png?HW-CC-KV=V1&HW-CC-Date=20260909T161025Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD40ADB8ADCDD13DDE695A986B6A433977EC4865A1F6C60BBE018F66E42DF752 "点击放大")

4. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/nuM1AZXES2iwy2smSNDPqw/zh-cn_image_0000001997207413.png?HW-CC-KV=V1&HW-CC-Date=20260909T161025Z&HW-CC-Expire=31536000000&HW-CC-Sign=053A9C738B7F35811426E880FE01CB587315F1C875F27A45CCA10160F61CD82E "点击放大")

6. 华为工作人员将在3~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/42/v3/vijw-YhnSHOMcmRBuUMufA/zh-cn_image_0000001889181377.png?HW-CC-KV=V1&HW-CC-Date=20260909T161025Z&HW-CC-Expire=31536000000&HW-CC-Sign=E07D89AB19117D655348CCF8138BD4951BA443A31D733D8A32DD1CF231F91F28)
7. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-icp-checkmessage-0000001820059249)。若初审被驳回，请点击"继续核准（备案）"修改信息后重新提交审核。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/EgF1GNIvR9qdob7A6oQH4A/zh-cn_image_0000001844809588.png?HW-CC-KV=V1&HW-CC-Date=20260909T161025Z&HW-CC-Expire=31536000000&HW-CC-Sign=E42FA3F23937D72D01676E8222D2E008A946F57DF23BAA041B1A75CB40C75B88)
