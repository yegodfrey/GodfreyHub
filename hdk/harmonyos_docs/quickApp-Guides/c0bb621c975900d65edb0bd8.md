# 首次核准（备案）

在华为云核准（备案）系统中首次核准（备案）主体信息和快应用信息。操作步骤如下：

1. 进入[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，登录华为云核准（备案）系统，填写主办单位信息、互联网信息，完成后点击"验证核准（备案）类型"。在弹出的窗口中点击"下一步"。

   ![](https://media:301781249740828933 "点击放大")
2. 在"主体信息"页面填写主办单位信息、负责人信息，完成后点击"下一步，填写互联网信息"。 ![](https://media:301781249740870934 "点击放大")

   ![](https://media:301781249741339941 "点击放大")
3. 在"互联网信息"页面填写互联网信息、负责人信息，完成后点击"下一步，上传资料"。 ![](https://media:301781249741432943 "点击放大")

   ![](https://media:301781249741518944 "点击放大")
4. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://media:301781249741672947 "点击放大")

   ![](https://media:301781249741726950 "点击放大")
5. 在"真实性核验"页面由互联网信息负责人进行人脸视频核验，完成后提交初审。 ![](https://media:301781249741774951 "点击放大")

6. 华为工作人员将在3\~5个工作日内进行审核，将以短信或邮件形式通知审核结果，请耐心等待，且保持手机畅通。若需要修改核准（备案）信息，将以邮件形式通知。![](https://media:301781249741878955)
7. 华为平台人工初审通过后，请前往工信部网站核验短信验证码，详情请参见[工信部核验核准（备案）短信](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-icp-checkmessage-0000001820059249)。若初审被驳回，请点击"继续核准（备案）"修改信息后重新提交审核。![](https://media:301781249741915957)
