# 首次核准（备案）

在华为云核准（备案）系统中首次核准（备案）主体信息和快应用信息。操作步骤如下：

1. 进入[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)，登录华为云核准（备案）系统，填写主办单位信息、互联网信息，完成后点击"验证核准（备案）类型"。在弹出的窗口中点击"下一步"。

4. 在"上传资料"页面根据提示上传提前准备的附件材料，完成后点击"下一步，真实性核验"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/nuM1AZXES2iwy2smSNDPqw/zh-cn_image_0000001997207413.png?HW-CC-KV=V1&HW-CC-Date=20261008T170854Z&HW-CC-Expire=31536000000&HW-CC-Sign=706B1DB9A1E3668B933C19FA3A667818606C8D34AB58AEF72E68B1759D5D0419 "点击放大")
