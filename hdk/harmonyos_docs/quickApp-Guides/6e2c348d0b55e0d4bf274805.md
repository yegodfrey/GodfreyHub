# 打开APK游戏预约页

预约阶段的APK游戏可通过同公司、或同款的快游戏版本进行引流，允许玩家直接在快游戏内打开预约详情页进行预约。APK游戏首发后，将在WIFI网络下为已预约的玩家自动下载并安装。  

#### 前提条件

APK游戏已处于[预约阶段](https://developer.huawei.com/consumer/cn/doc/distribution/app/game-center-pre-order-0000001239342333)。  

#### 用户体验

玩家预约APK游戏的步骤如下：

1. 玩家点击快游戏界面的预约按钮。
2. 若未签署华为应用市场相关协议，需同意相关协议。若已签署过相关协议，将不会弹出协议签署窗口。
3. 若华为应用市场客户端较低，需更新至最新版本。客户端更新完成后，不会自动打开APK游戏的预约详情页，玩家需重新进入快游戏界面点击预约按钮。若客户端版本满足要求，将不会弹出更新窗口。
4. 在打开的预约详情页完成预约后，点击顶部的返回按钮返回到快游戏界面。

#### 开发指导

快游戏调用[qg.reserveApp()](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-runtime-api-pre-orders-0000001583092993#section1584911596204)实现预约APK游戏能力。

```
// 替换成处于预约阶段的APK游戏包名
qg.reserveApp({
         packageName: "待预约应用的包名",
         success : function (data) {
                 console.log("reserveApp success data = " + JSON.stringify(data));
         },
         fail:function (data) {
                 console.log("reserveApp fail return data = " + JSON.stringify(data));
        },
});
```
