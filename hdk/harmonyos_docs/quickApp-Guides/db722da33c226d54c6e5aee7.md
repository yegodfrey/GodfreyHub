# 弹出APK游戏安装页

在快游戏中关联APK游戏即可方便、安全、快速地推广APK游戏，为用户提供基于华为应用市场的下载和安装能力。

## 用户体验

用户点击快游戏界面的APK游戏图标后，弹出mini详情页：

* 若手机未安装此APK游戏，用户可在mini详情页手动点击"安装"确认下载、安装APK游戏。安装完成后可在mini详情页点击"打开"进入APK游戏，或点击"关闭"留在当前快游戏。
* 若手机已安装此APK游戏，用户可在mini详情页点击"打开"直接进入APK游戏，或点击"关闭"留在当前快游戏。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135237.44787729695135553795891122118829:50001231000000:2800:66A10CD95B6CB1A5B0512D63A61C3B422F53B6679D519429D5632AFBCA36B3BE.png)

## 前提条件

* 已[注册开发者账号](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-registration-account-0000001794901061)。
* 已[创建项目和快游戏](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-create-quickgame-0000001159652387)。
* 相关联的APK游戏已上架至华为应用市场。
* 请提前准备放置在快游戏界面上的APK游戏图标，要求不遮挡游戏主要画面，不阻碍游戏进程，且与游戏整体风格保持一致。

## 开发指导

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135237.03436391351552200994698995329573:50001231000000:2800:A68000F05B213C03903BBA9C823F85FDBA6E90E74A4C385ECA7997D8D9B60F36.png)

1. 在快游戏点击相关联的APK游戏图标，调用[qg.downloadApp](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-runtime-api-collection-0000001504792169#section18269112115377)弹出华为应用市场的游戏mini详情页。 说明
   >
   > 未安装华为应用市场的用户，将提醒先安装华为应用市场。

   ```screen
   qg.downloadApp({
       // 替换成真实有效的APK游戏包名
       packageName:"com.huawei.***",
       success: function () {
         console.log("downloadApp successfully invoked");
       },
       fail: function (data, code) {
         console.log("downloadApp fail data =" + JSON.stringify(data), "code =" + code);
       },
       callback: function (data) {
         console.log("downloadApp callback data =", JSON.stringify(data));
       },
   });
   ```

2. 若手机未安装此APK游戏，用户需要手动确认是否同意安装APK游戏。
3. 若用户同意，华为应用市场将下载、安装APK游戏至手机。 说明
   >
   > 若用户的快游戏客户端版本低于3.0.1，将无法下载和安装相关联的APK游戏。
