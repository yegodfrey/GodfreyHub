# 快游戏直玩

快游戏直玩是一种激励广告的新形式，用户可以在激励广告中直接游玩您的游戏，并积累激励广告时长获取奖励。您可以直接使用您的游戏作为广告素材，减少素材制作成本。

## 形态优势

* 直玩广告无需制作/上传广告素材，直接使用游戏作为投放的广告内容，帮助您降低广告投放的成本；支持用户进入配置的特定关卡，可以灵活适配不同的运营策略。
* 直玩广告的互动性相较其他广告类型更强，转化效果优于其他广告类型。
* 直玩广告是以游戏本身作为广告内容，因此当用户进入广告时就可以获得真实的游戏体验，转化的用户质量更高、粘性更强。
* 直玩广告兼容多种盈利模式和游戏品类。

## 用户体验

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/b3R5RDdOTEaUFYQwl2KPzQ/zh-cn_image_0000002583508738.png?HW-CC-KV=V1&HW-CC-Date=20260909T152409Z&HW-CC-Expire=31536000000&HW-CC-Sign=409067280B04F33419BE151BA3CEEFD814F96F4505733DDDFE2EC72E01C35DB7)

1. 打开激励广告，进入蒙层状态，倒计时开始，时长为30s。此时游戏已经启动完成，但用户尚未开始游戏，不会进行注册上报和计算用户活跃。
2. 蒙层戳破后进入游玩状态，此时快游戏会将用户计为注册或活跃用户，退出时会进行注册上报，并会将戳破蒙层的行为视为广告可转化点击。
3. 倒计时结束，强制结束游戏，奖励已获得，展示结束页面。用户可以选择返回原快游戏继续游玩，或前往直玩体验的快游戏继续游玩。

## 注意事项

* 建议截取游戏内第一关或开发者认为游戏内最具吸引力、上手难度小、性能要求相对较低的玩法作为直玩内容。
* 建议选取用户进入时不会触发隐私弹框的关卡。
* 直玩内容的首帧需要从加载页开始，并含有[健康游戏忠告](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-runtime-environment-preparation-0000001752115494#ZH-CN_TOPIC_0000001752115494__zh-cn_topic_0000001435916312_p75551154171018)的内容，加载结束后直接接入对应关卡。
* 直玩模式下只允许游玩游戏，会屏蔽游戏内的广告内容。

## 开发指导

1. 选取您希望作为直玩内容的游戏关卡，在游戏内通过[qg.getLaunchOptionsSync](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickgame-api-lifecycle-0000001083746128#section4844135503910)返回的query参数内gameRunMode的值判断游戏的启动方式。
   * 若返回的gameRunMode值为normal或undefined，表示游戏为正常启动或未进行设置，请按照正常的游戏流程运行游戏。
   * 若返回的gameRunMode值为revisit或userAcquire，表示游戏通过直玩的方式启动。值为revisit时需要为老用户提供个性化体验，值为userAcquire时需要为新用户提供引导和激励。

   ```screen
   function onGameLaunch() {
       // 获取启动参数
       const launchOptions = qg.getLaunchOptionsSync();
       // query字段是JSON字符串，需要解析
       const query = launchOptions.query;
       let gameRunMode = 'normal';
       if (typeof query === 'string' && query) {
           try {
               const queryObj = JSON.parse(query);
               gameRunMode = queryObj.gameRunMode || 'normal';
           } catch (e) {
               console.warn('parse query failed:', e);
           }
       }
       // 根据gameRunMode定制游戏逻辑
       switch (gameRunMode) {
           case 'revisit':
               // 复访场景：为老用户提供个性化体验
               break;
           case 'userAcquire':
               // 获客场景：为新用户提供引导和激励
               break;
           case 'normal':
           default:
               // 普通场景：正常游戏流程
               break;
       }
   }
   ```

2. 将新的快游戏版本提交上架审核。
3. 前往[鲸鸿动能广告平台](https://ads.huawei.com)创建直玩投放任务，并按照要求填写对应的信息。

## 运行测试

1. 您可以通过设置gameRunMode为固定值，测试当前设置的直玩内容是否符合[注意事项](#section1049166183020)内的要求。

   ```screen
   function onGameLaunch() {
       // 获取启动参数
       const launchOptions = qg.getLaunchOptionsSync();
       // query字段是JSON字符串，需要解析
       const query = launchOptions.query;
       let gameRunMode = 'normal';
       if (typeof query === 'string' && query) {
           try {
               const queryObj = JSON.parse(query);
               gameRunMode = queryObj.gameRunMode || 'normal';
           } catch (e) {
               console.warn('parse query failed:', e);
           }
       }

       // 设置gameRunMode为固定值用于测试，正式上架时请删除
       gameRunMode = 'revisit';

       // 根据gameRunMode定制游戏逻辑
       switch (gameRunMode) {
           case 'revisit':
               // 复访场景：为老用户提供个性化体验
               break;
           case 'userAcquire':
               // 获客场景：为新用户提供引导和激励
               break;
           case 'normal':
           default:
               // 普通场景：正常游戏流程
               break;
       }
   }
   ```

2. 如需继续测试广告的展示效果，请先上架快游戏，然后在[鲸鸿动能广告平台](https://ads.huawei.com)内创建广告的测试任务，测试直玩广告的实际效果。
