# 布局变化规则

#### 概述

当显示环境发生变化时，如横竖屏切换、调节字体大小、应用分屏时，需要及时调整内容的布局方式以适应变化。了解布局的基础概念后，通过自适应布局和响应式布局就可以让你的内容更好地适配显示环境的变化。

#### 布局基础

#### 8vp网格系统

基于 8vp 为网格的基本单位可以对界面上元素的大小、位置、对齐方式进行更好的规划，构建更有层次感、秩序感，以及多设备上一致的布局效果。一些更小的控件（例如图标）大小也可以对齐 4vp 的网格大小。  

#### 栅格系统

栅格系统是一个多设备下通用的辅助定位系统，有 Margin，Gutter，Column 三个属性构成。其中 Column 是根据设备的水平宽度自动匹配的（规则见[栅格断点系统](#section47541637165118)）。通过栅格系统进行布局，可以达到多设备下布局的一致性。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162408.14645474281202523591530680133050:50001231000000:2800:10C1B36AFAE49DA5A5EC7F13E6CF4D2D1A02E744D2D5CC6E82AED0E9C6A0FF09.png)  

#### 自适应布局

#### 概述

自适应布局是通过设定元素与外部容器的相对关系达到的。当外部容器大小、位置等发生变化时，元素即可以根据相对关系自动变化以适应外部环境的变化。  

#### 栅格断点系统

根据设备的水平宽度，栅格系统定义了对应 Column 的数量关系。不同的设备根据自身屏幕水平宽度，在不同的断点范围，系统将自动匹配不同数量的栅格。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162408.61396076753721124785942375840363:50001231000000:2800:F4DA17F78FA229A9410E3CD8C69873EC7D3334A5CC54E640817875A6457251B8.png)  

#### 基础栅格

常规的应用都可以使用基础栅格为你的内容进行大小和位置的布局。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162408.25428236236419330895472977886913:50001231000000:2800:B671B19C98B8AC8495FE6B994BCC0534D21047DFA544281758445E5E7AE47839.png)

基础栅格参数：margin=24vp，gutter=24vp  

#### 卡片栅格

应用内使用卡片化设计（例如通知卡片、卡片信息流等）时需要使用卡片栅格进行布局。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162408.15506591027010163180376822955949:50001231000000:2800:CBE987B5FF54BAA6E10303561E3E63BEB65F1208F360BF2D71F5FCA9D3FC0A18.png)

卡片栅格参数：margin=12vp，gutter=12vp  

#### 自适应缩放

组件的显示大小是固定比例，通过相对参照物的方式来确定其宽或高。当参照物的大小发生变化时，元素的大小随之发生自适应缩放。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162408.08894166856297625013349562279396:50001231000000:2800:332705018B0E272461FED5A59E85344E1C5B2CBE140EC3416EEFCF34191071A1.png)  

#### 自适应拉伸

文本的显示宽度不是固定值，而是通过相对参照物的方式来确定其显示宽度。当参照物的宽度发生变化时，文本的显示宽度随之发生自适应拉伸。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162408.85188017883779764008569453195157:50001231000000:2800:5ACDA3342E5E9AAD6A4570C5DDE30CDE5D32E5764FDCC16C8C498A81965AE106.png)  

#### 自适应延伸

组件的数量不是固定的，而是通过相对参照物的方式来确定其显示数量。当参照物的宽度发生变化时，组件随之发生自适应延伸显示更多数量。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162409.09948772246265479750023774597274:50001231000000:2800:4C460FD9E347BB639BB61ADBE24E30B9205E4822FD64812513EBA6D88338C088.png)  

#### 响应式布局

#### 概述

当基本的自适应布局无法满足多终端上屏幕的体验要求时，我们需要针对不同终端的屏幕特点进行响应式的布局。常见的响应式布局样式有：分栏布局、重复布局、挪移布局和缩进布局。  

#### 分栏布局

利用屏幕的宽度优势，将有上下级层级的界面同时左右显示。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162409.25461201849125731280207348396393:50001231000000:2800:39D68CA28EFEC255DF64486882861DD8551A227E2F4D30A4CCC2BE2D57A0DFAA.png)

<br />

当栅格为8column或12column时可以响应分栏布局。  

#### 重复布局

利用屏幕的宽度优势，将相同属性的组件横向并列排布。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162409.45779991031504839468871247194927:50001231000000:2800:3B0FAABB61A56EFAA3DFC8B907022F168CD3CD25F1E5EFD923C154C0CEA9D5A5.png)

当栅格为8column或12column时可以响应重复布局。  

#### 挪移布局

利用屏幕的宽度优势，将原先的上下布局切换成左右布局。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162409.46907393985552000961330311861121:50001231000000:2800:AEFFE8E558A4E0E1D748EEB81887278F21DD527516B07DBD11E5B90587E446E5.png)  

#### 缩进布局

为了在宽屏上内容显示有更好的效果，在不同宽度的设备上进行不同缩进效果。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162409.64603835395526678049058157590581:50001231000000:2800:7B9806EF4BE4F5E2253FA2EAA308D0A1AAAADA79BE6CD464C0EADD78A6E2F503.png)当栅格为8column或12column时可以响应缩进布局。
