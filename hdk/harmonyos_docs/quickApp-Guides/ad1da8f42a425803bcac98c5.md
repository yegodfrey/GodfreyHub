# 注册开发者账号

若还没有实名认证的华为开发者账号，请前往华为开发者联盟网站注册账号并完成实名认证，具体操作请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
