# 自定义API

如果Web快应用里需要调用一些宿主 App 提供的能力，而快应用 SDK 未实现或无法实现时，就可以通过注册自定义 API 来实现，使得Web快应用里也能够调用 App 中注册的 API 了。

Web快应用开发工具会自动扫描 HuaweiConf.js 中的自定义 API 配置，添加到 自定义 API 面板中 在 自定义 API 面板中，可以指定自定义 API Mock 的返回值与返回类型 勾选启动，调用对应的自定义 API 就会返回指定的 Mock 值，从而快应用开发工具可以调通相关逻辑。
