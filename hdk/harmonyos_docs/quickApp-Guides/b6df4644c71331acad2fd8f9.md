# 轮播图指示点组件

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420151408.55524438352311505793373426864327:50001231000000:2800:C44E2D57B8AD3B167FDA908974F6D14C434A31A8D09E93B13DC5C2C7CB1E1645.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
轮播图指示点组件依赖快应用swiper组件，必须与swiper组件配合使用。  

#### 简介

快应用[swiper组件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-component-swiper-0000001074057289)可以实现轮播图，并且swiper组件自带指示点，如下图所示。但是指示点风格固定，不能修改，无法满足定制化的需求。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420151408.96125539481467686328681745791921:50001231000000:2800:1484A1D0DBDFBB572692D74FD22A00C734A2F327682BE967E19A816B348FC878.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

本文中轮播图指示点（swiperdot）组件可以配合快应用swiper组件使用，自定义实现指示点。轮播图指示点一般具有如下特点：

* 可以设置多种显示模式
* 可以设置指示点的个数
* 可以设置指示点的样式

效果图如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220420151408.36240167293166441575217712471355:50001231000000:2800:AFF2F2770EBC8F810505CB89C5711867826C70DC3A6980932B6462F396263D92.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

                <block for="(index, item) in info">

#### 开发指引

#### 自定义子组件

1. 定义布局样式。 轮播图指示点组件包括两个部分：轮播部分、指示点部分。

   * 轮播部分使用swiper组件展示图片或者其他内容，由于每个页面的swiper内容都不一样，所以使用slot组件来承载父组件中的swiper内容，由使用swiperdot组件的页面来完成轮播布局。
   * 指示点部分采用absolute布局，通过bottom属性将指示点显示在距离swiper底部。
     * 指示点布局是横向div布局，指示点用text实现。
     * 指示点有default、dot、round、nav、indexes五种模式，每种模式都是一个div布局，通过mode属性值来控制当前显示哪个。 如果当前的几种模式不满足您的要求，您可以自行修改或者添加另外一种模式。

   布局实现代码如下：

   ```
   <template>
     <!-- Only one root node is allowed in template. -->
     <div class="swiper_container">
       <slot></slot>
       <div if="mode === 'default'" style="bottom:{{dots.bottom}}px;" class="swiper_dots-box">
         <text for="(index,item) in info" class="swiper_dots-item swiper_dots-bar" @click="clickItem(index)" style="width: {{index === current? dots.width*2:dots.width }}px;height:{{dots.width/3}} px; background-color:{{index !== current?dots.backgroundColor:dots.selectedBackgroundColor}};}">
         </text>
       </div>

       <div if="mode === 'dot'" style="bottom:{{dots.bottom}}px;" class="swiper_dots-box">
         <text for="(index,item) in info" class="swiper_dots-item" @click="clickItem(index)" style="width: {{dots.width}}px;height:{{dots.height}}px; background-color:{{index !== current?dots.backgroundColor:dots.selectedBackgroundColor}};border:{{index !==current ? dots.border:dots.selectedBorder}};">
         </text>
       </div>

       <div if="mode === 'round'" style="bottom:{{dots.bottom}}px;" class="swiper_dots-box">
         <text for="(index,item) in info" class="swiper_dots-item" @click="clickItem(index)" style="width:{{index === current? dots.width*3:dots.width }}px;height:{{dots.height}}px;background-color:{{index !== current?dots.backgroundColor:dots.selectedBackgroundColor}};border:{{index !==current ? dots.border:dots.selectedBorder}};">
         </text>
       </div>

       <div if="mode === 'nav'" style="background-color:{{dotsStyles.backgroundColor}};bottom:0;}" class="swiper_dots-box swiper_dots-nav">
         <text style="color:{{dotsStyles.color}};" class="swiper_dots-nav-item">{{ (current+1)+"/"+info.length +' ' +info[current][field] }}
         </text>
       </div>

       <div if="mode === 'indexes'" style="bottom:{{dots.bottom}}px;" class="swiper_dots-box">
         <text for="(index,item) in info" class="swiper_dots-item swiper_dots-indexes-text" @click="clickItem(index)" style="width:{{dots.width}} px;height:{{dots.height}}px;color:{{index === current?dots.selectedColor:dots.color}};background-color:{{index !== current?dots.backgroundColor:dots.selectedBackgroundColor}};border:{{index !==current ? dots.border:dots.selectedBorder}};">{{ index+1 }}
         </text>
       </div>
     </div>
   </template>
   ```

2. 规划属性。 支持的属性：

   |属性|类型|默认值|描述|
   |:---------|:---------------|:-------|:----------------------------------------------|
   |current|Number \| String|0 \| '0'|当前指示点索引，必须是通过swiper的change事件获取的e.index。|
   |mode|String|default|指示点的类型。 * default * dot * round * nav * indexes|
   |field|String|-|mode为nav时显示的内容字段。 说明： 当mode为nav时，此参数必填。|
   |info|Array|-|轮播图的数据，通过数组长度决定指示点个数。|
   |dotsStyles|Object|-|指示点样式。|

   dotsStyles对象参数：  

   |属性|类型|默认值|描述|
   |:----------------------|:-----|:---------------------------|:------------------------------------------------------|
   |width|Number|18|每个指示点宽度。 说明： 当mode为nav或者indexes时，此参数不生效。|
   |bottom|Number|10|指示点距swiper底部的高度。 说明： 当mode为nav时，此参数不生效。|
   |color|Color|#fff|* 当mode为nav时，表示指示点文字颜色。 * 当mode为indexes时，表示未选择的指示点文字颜色。|
   |selectedColor|Color|#fff|当mode为indexes时，表示已选择的指示点文字颜色。|
   |backgroundColor|Color|rgba(0, 0, 0, 0.3)|未选择的指示点背景色。|
   |border|Border|1px rgba(0, 0, 0, 0.3) solid|未选择的指示点边框样式。|
   |selectedBackgroundColor|Color|#333|已选择的指示点背景色。 说明： 当mode为nav时，此参数不生效。|
   |selectedBorder|Border|1px rgba(0, 0, 0, 0.9) solid|已选择的指示点边框样式。 说明： 当mode为nav时，此参数不生效。|

#### 实现指示点模式及样式切换

当您希望用户按照自己的喜好去切换想要的模式及样式时，swiperdot组件需要及时更新响应。

1. 通过快应用$watch('xx', 'xxx')方法监听指示点类型mode和指示点样式dotsStyles两个属性的变化，从而更新样式绑定变量dots，触发界面刷新。
2. 当切换到indexes模式时，指示点的宽度和高度值单独设置为30。

```
onInit() {
  console.info("swiper dot sub oninit:this.dots="+JSON.stringify(this.dots));
  this.$watch('mode', 'modeChange');
  this.$watch('dotsStyles', 'dotsStyleChange');
},
modeChange: function (newValue, oldValue) {
  console.info("modeChange newValue= " + newValue
    + ", oldValue=" + oldValue);
  if (newValue === 'indexes') {
    this.dots.width = 30
    this.dots.height = 30
  } else {
    this.dots.width = 18
    this.dots.height = 18
  }
},
dotsStyleChange: function (newValue, oldValue) {
  console.info("dotsStyleChange newValue= " + newValue
    + ", oldValue=" + oldValue);
  this.dots = Object.assign(this.dots, this.dotsStyles);
  console.info("dotsStyleChange  this.dots="+JSON.stringify(this.dots));
},
```

* 由于swiper自身有指示点，在使用本组件时，请将swiper的indicator属性设置为false。
* swiper-item（滑块个数）尽量控制在一定数量之内，否则指示点可能会超出屏幕。
* 暂不支持垂直方向的指示点。
