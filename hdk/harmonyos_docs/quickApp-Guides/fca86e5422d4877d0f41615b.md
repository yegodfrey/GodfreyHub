# 开发指引

#### 概述

快应用是一种基于行业标准开发的新型免安装应用，可以运行在手机、平板、车机、智慧屏等各种终端，用户无需下载安装，就能流畅的体验应用的服务。快应用还可通过桌面图标、负一屏、快应用中心、应用市场等众多入口进入，大大提高了用户使用应用的便捷性。
