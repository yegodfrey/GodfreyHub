# 语音合成

#### 简介

语音合成服务支持将文字信息转换为语音输出，提供丰富的音色以及可通过调整音量、语速从而使发音达到更加真实自然的效果。该服务采用深度神经网络合成方式，可通过端侧SDK快速集成，能够实时输出音频数据。当前版本有2种标准男声发音人，以及6种标准女声发音人可供选择（详细发音人信息请参见[音色试听](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-tts-0000001050068169#section159151291041)）。该服务已在全球部署。  

#### 准入条件

接入语音合成前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 在AppGallery Connect上已[开通机器学习服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-ml-kit-0000001126700645)。  

#### 接入指引

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111526.74857604671354038776411348212423:50001231000000:2800:275A917BC46235C4BDC2B21CA3242A17AE264F86EFEE8F823F4015A6E2C0BF32.png)  
* 目前法语、西班牙语、德语、意大利语音合成服务仅支持华为手机和荣耀手机使用，中英文合成服务支持所有品牌手机。
* 单次请求文本不超过500个字符且使用UTF-8编码。
* 法语、西班牙语、德语、意大利语语音合成服务目前仅在亚非拉、欧洲地区部署。
* 语音合成属于云侧服务，调测和使用服务时需保证设备可正常访问互联网。
* 实时输出音频数据默认规格为PCM单声道，位深为16Bit，音频采样率为16kHZ。  

#### 开始语音合成并播放

调用[mltts.speak](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ml-tts-0000001139945591#section98051927539)接口，实现语音合成并播放，然后通过设置callback和fail回调获取返回结果。语音合成过程中，callback会实时监听回调，通过返回的eventName判断事件类型，从而进行相关业务操作。  

#### 暂停播放

播放过程中，调用[mltts.pausePlay](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ml-tts-0000001139945591#section753014449102)接口，暂停播放。  

#### 恢复播放

暂停播放状态下，调用[mltts.resumePlay](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ml-tts-0000001139945591#section9716173511115)接口，恢复播放。  

#### 停止语音合成

调用[mltts.stop](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ml-tts-0000001139945591#section235812431699)接口，停止语音合成。
