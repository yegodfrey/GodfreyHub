# 生成并配置证书指纹

证书指纹可以保证快游戏的完整性和安全性。快游戏在游戏引擎中生成证书指纹，详情请参见[生成并配置证书指纹](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-runtime-environment-preparation-0000001752115494#section6561155114119)，生成后在AGC控制台进行配置。
