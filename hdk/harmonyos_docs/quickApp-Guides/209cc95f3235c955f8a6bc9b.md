# FAQ

## 框架

### 页面空白并且logcat日志中显示$app._def找不到方法，如何处理？

app.ux中的公共对象只能通过this.$app.$def访问，日志中报的this.$app._def或者其他调用方式都是不支持的。

### 执行for指令不生效，如何处理？

for循环支持的写法（其中{{}}可以省略）：

* "fn"：for="list"：list为数组对象，默认元素变量为$item。
* "for="value in list"：value为自定义的元素变量，默认元素索引为$idx。
* "for="(index,value) in list"：index为元素索引，value为元素变量。

容易出错的是第三种用法，需要特别注意与Vue不同，"for="(index,value) in list"的写法中，index需要放在第一位。

### 快应用页面文件如何获取app.ux文件中自定义的全局数据和方法？

快应用页面可以通过this.$app.$def获取，卡片场景不支持。

### 快应用界面在输入法键盘弹出后，界面高度全部压缩在手机一个屏幕之内，如何处理？

这是由于manifest.json文件的display字段设置了windowSoftInputMode属性为adjustResize，导致输入法键盘弹出后，界面的压缩变形。将windowSoftInputMode属性设置为adjustPan即可。

### 内部函数如何通过this访问data中定义的数据？

例如：UX文件script中定义的data数据如下：

```screen
data: {
    listData:[]
}
```

可通过如下两种方法实现访问：

**【方法一】**将this传递给局部that变量，解决访问data中数据的问题。

```screen
testAddData() {
    var that = this;
    var renderData = that.listData.concat(that.listAdd);
    setTimeout(function () {
        that.listData = renderData;
    }, 1000)
}
```

**【方法二】**使用箭头函数，从自己的作用域链的上一层继承this。

```screen
testAddData() {
    var renderData = this.listData.concat(this.listAdd);
    setTimeout(() => {
        this.listData = renderData;
    }, 1000)
}
```

### 端+云的项目，云端服务如何快速部署？一般采用什么协议通信？

对于规模不大的项目，建议直接使用云服务商提供的能力，比如使用华为云的对象存储服务代替自行搭建数据库。

一般端云使用https通信，业务数据使用JSON格式封装。

### 输入框获取焦点弹出键盘后，键盘上面出现大片空白，挡住了输入框，如何处理？

检查manifest.json文件中display的windowSoftInputMode是否设置为adjustResize，如果设置了，请删除该属性或者增加设置fullScreen属性为true。

### 如何在快应用中设置titlebar？

目前设置titlebar有两种方式：

1. 在manifest文件中的display进行配置：

   ```screen
   "display": {
       "pages": {
           "main": {
               "titleBarText": "快应用功能展示"
           },
       }
   }
   ```

2. 当前页面中的oninit函数里或者自定义实现的函数里，在页面中实现的优先级高于在配置文件中设置。

   ```screen
   onInit() {
           this.$page.setTitleBar({ text: 'Divdemo' })
   }
   ```

### 从一个页面跳转到另一个页面时，onInit、onReady里的方法为什么不触发？

页面切换时，触发的是onShow，不会触发onInit和onReady，onInit和onReady只会在第一次打开页面时触发。所以从一个页面跳转到另一个页面或者返回上个页面时，需要将实现的函数或携带的数据在onShow里实现。

### 如何取消按退出按钮时自动提示应用添加到桌面的弹窗？

在onbackpress中将systemPromptEnabled设为false即可。

### 调用接口，提示"ilmess=null featureparmas of serviceshare code=200"，如何处理？

这是因为没有在manifest.json文件中配置参数params导致，params即使为空也需要配置。在manifest.json添加如下配置：

```screen
{
   "name": "service.share"
   "params":{
   }
}
```

### 在app.ux中定义的全局变量在js文件中能读取吗？

可以。

例如在app.ux中定义变量AppData：

```screen
data: {
    AppData: '123456',
}
```

JS文件中读取代码如下：

```screen
export default {
  getAppData() {
    return getApp().$def.data.AppData
  }

```

更多指导内容，请参见"[script脚本](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-script-0000001073643163)"中的"公共方法"章节。

### 页面data中定义变量时，初始化赋值是否支持多语言写法？

不支持，需要在方法中使用。建议在页面初始化时给定义的变量赋值，可以达到相同的效果。

错误写法：

```screen
data: {
  AppData: "{{ $t('message.takePhotoAndPick') }}",
},
```

正确写法：

```screen
data: {
  AppData: ""
},
onInit: function () {
    this.AppData = this.$t('message.takePhotoAndPick')
}
```

### 子组件如何向父组件传值？

**【方法一】**子组件通过$emit()触发在节点上绑定的自定义事件来执行父组件的方法。

如下例子中实现了如何将子组件中的count值传递到父组件：子组件定义了emitEvt事件（父组件中引用时，需要添加on前缀），子组件在调用$emit()时，携带count参数，父组件在响应事件时，便可获取参数值。

**<!-- 父组件 -->**

```screen
<import name="comp1" src="./comp1.ux"></import>
<template>
  <div style="flex-direction: column;">
    <text>我是父组件count:{{fcount}}</text>
    <comp1 count="{{fcount}}" onemit-evt="emitEvt"></comp1>
  </div>
</template>
<script>
  export default {
    private:{
        fcount:20
    },
    emitEvt(evt){
        this.fcount = evt.detail.count
    }
  }
</script>
```

**<!-- 子组件 -->**

```screen
<template>
  <div class="child-demo">
    <text>我是子组件一count:{{compCount}}</text>
    <input type="button" onclick='addHandler' value='add'></input>
  </div>
</template>
<script>
  export default {
    props: ['count'],
    data(){
        return{
            compCount:this.count
        }
    },
    addHandler(){
        this.compCount ++
        this.$emit('emitEvt',{
            count:this.compCount
        })
    }
  }
</script>
```

**【方法二】**子组件调用childVm.$dispatch()完成向上传递。

子组件通过$dispatch()触发自定义事件，父组件通过$on()监控自定义事件的触发，自定义事件中控制num的变化，父组件中通过evt.detail获取子组件中的num的值赋值给父组件。

**<!--** **父组件 -->**

```screen
<import name="comp1" src="./comp1.ux"></import>
<template>
  <div style="flex-direction: column;">
    <text>我是父组件fnum:{{fnum}}</text>
    <comp2 num="{{fnum}}"></comp2>
  </div>
</template>
<script>
  export default {
    private:{
        fnum:20
    },
    onInit(){
      this.$on('dispathEvt',this.dispathEvt)
    },
    dispathEvt(evt){
        this.fnum = evt.detail.num
    }
  }
</script>
```

**<!--** **子组件comp2 -->**

```screen
<template>
  <div class="child-demo">
    <text>我是子组件二num:{{compNum}}</text>
    <input type="button" onclick='delHandler' value='del'></input>
  </div>
</template>
<script>
  export default {
    props: ['num'],
    data(){
        return{
            compNum:this.num
        }
    },
    delHandler(){
        this.compNum --
        this.$dispatch('dispathEvt',{
            num:this.compNum
        })
    }
  }
</script>
```

### 为什么position设置为absolute不生效？

position可以设置为absolute是从1060版本开始的，所以需要将manifest文件中的minPlatformVersion属性设置为大于等于1060才能生效，小于1060是不会生效的。

### 如何触发自定义组件页面的生命周期函数？

例如页面a的自定义组件页面b，跳转到页面c，从页面c返回页面a，只能触发页面b的oninit和onready两个生命周期，其余的生命周期是无法触发的。

### 使用Deeplink时，页面接收了数据，却没有显示出来，如何处理？

这需要根据跳转页面的启动模式分开来看。

* 启动模式是singleTask：
  * 目标页面不存在（应用处于关闭状态），通过Deeplink打开时，可以在页面生命周期onshow中获取参数。
  * 目标页面已经存在（应用在后台运行），通过Deeplink打开时，此时不会新建页面，打开后页面也不会刷新，取到值也不会在页面上展示，需要重写onrefresh取值 。


* 启动模式是standard：
  * 目标页面不存在（应用处于关闭状态），通过Deeplink打开时，可以在页面生命周期onshow中获取参数。
  * 目标页面已经存在（应用在后台运行），通过Deeplink打开时，此时会新建页面，导致页面重复创建，影响用户体验，所以不建议进行这样的设置。

### 如何通过计算属性控制组件样式？

当某个组件的样式需要根据传入的变量进行动态变化，如果给组件设置不同的class样式进行切换，会比较繁琐，此时建议采用计算属性的方式。

通过计算属性进行样式的计算得到返回值之后，将返回值赋值给对应的组件style，就能够做到样式的动态变化。

完整实现代码如下：

```screen
<template>
  <div style="width: 100%">
  <!--组件样式的设置-->  
    <text style="{{textStyle}}">我是显示的文字</text>
  </div>
</template>

<script>
  export default {
    data: {
      width: 300,
      height: 100,
      size: 40,
      backgroundColor: '#dc143c'
    },
    //计算属性返回样式结果
    computed: {
      textStyle() {
        var style = '';
        style += 'width:' + this.width + 'px;'
        style += 'height:' + this.height + 'px;'
        style += 'font-size:' + this.size + 'px;'
        style += 'backgroundColor:' + this.backgroundColor + ';'
        return style;
      }
    }
  };
</script>

<style>
</style>
```

### 如何在父组件中控制自定义子组件的if属性？

当父组件引用自定义子组件时，有时需要控制子组件的显示和隐藏，可以通过控制子组件的if属性来实现。

1. 在自定义子组件的props属性中定义变量isShow。
2. 在父组件中给子组件的isShow变量赋值，子组件通过if="{{isShow}}" 控制显示或隐藏。

完整实现代码如下。

父组件hello.ux代码：

```screen
<import name="t-item" src="../Test/t-item"></import>

  <div style="width: 100%">
    <input type="button" value="改变if值" onclick="change" />
    <t-item is-show="{{isShow}}"></t-item>
  </div>
</template>

<script>
  export default {
    data: {
      isShow: true
    },
    onInit() {
    },
    change: function () {
      this.isShow = !this.isShow
    }
  };
</script>

<style lang="less">
</style>
```

子组件t-item.ux代码：

```screen
<template>
  <div class="col">
    <text if="{{isShow}}">我是子组件</text>
  </div>
</template>

<script>
  export default {
    data: {
    },

      isShow: {

    }

  .col {
    flex-direction: column;
  }

```

## 组件

### logcat日志中有"xxx cannot be cast to xxx at ...list"的错误提示，如何处理？

出现此错误提示，请对list-item组件进行如下检查：

1. 是否设置type属性 list-item的type属性为必填属性，如果没有设置，请补充属性信息。

2. 内部是否使用了if指令 list-item内部需谨慎使用if指令或for指令，因为相同type属性的list-item的DOM结构必须完全相同，而使用if指令或for指令会造成DOM结构差异。请使用show指令代替if指令，或设置不同的type属性。

3. 是否设置了相同的type属性，但是DOM结构不一致 如果DOM结构不一致，请设置不同的type属性。

4. list-item内是否有嵌套list list-item内不允许再嵌套list。

### map地图如何实现最佳视图窗口？

在地图组件的可视范围内显示给定的系列坐标点，当地图组件上有控件或者其他快应用组件遮挡的时候，使用includePoints()方法并在参数对象上加一个 padding 属性，可以对显示区域进一步进行约束。

实现代码如下：

```screen
<template>
  <div>
    <!-- includepoints 属性设置-->
    <map style="width:{{width}}; height:{{height}}" id="map" includepoints="{{includepoints}}" markers="{{markers}}" @loaded="loaded"></map>
  </div>
</template>
<script>
  const COMMON_MARKER = { iconPath: "/Common/logo.png", width: "30px" }
  const POINT1 = { latitude: 39.9090371069, longitude: 116.3953853161 }
  const POINT2 = { latitude: 39.9089550115, longitude: 116.3992842749 }
  const POINT3 = { latitude: 39.9061293143, longitude: 116.3995796987 }
  const POINT4 = { latitude: 39.9061694220, longitude: 116.3953937341 }
  const POINTS_LIST = [POINT1, POINT2, POINT3, POINT4]
  export default {
    private: {
      width: "100%",
      height: "50%",
      markers: null,
      includepoints: null
    },
    onInit() {
      this.markers = POINTS_LIST.map(item => Object.assign({}, COMMON_MARKER, item))
    },
    loaded() {
      // 方法和属性实现，二者取其一
      // includepoints 属性设置最佳视口
      this.includepoints = POINTS_LIST
      // includepoints 方法设置最佳视口
      // this.$element("map").includePoints({ points: POINTS_LIST })
    }
  }
</script>
```

### 如何实现长按图标随意拖动？

```screen

  }

    flex-direction: column;

    border-radius: 100px;
  }

<script>
  export default {
    data: {
      pageX: "",
      pageY: "",
    },
    onInit: function () {
      this.$page.setTitleBar({ text: "长按拖动图标" });
      console.info("Application onInit");
    },
    onShow(options) {
      console.info("Application onShow");
    },
    onHide(options) {
      console.info("Application onHide");

      console.log(JSON.stringify(TouchEvent.changedTouches));

      this.pageY = (TouchEvent.changedTouches[0].pageY - 80) + "px"
```

### H5快应用web组件打开的网页出现跨域问题，如何处理？

可以通过以下四种方式来规避：

* 原生jsonp：通过动态创建script标签，通过script标签的src，向一个不同源的接口发送一个get请求。

* nginx转发：利用nginx反向代理，将请求分发到部署相应项目的tomcat服务器。

### 如何全局监听步数变化?

在app.ux中调用传感器接口，每个页面使用watch监听获取当前步数变化即可。

1. 在app.ux中定义全局对象，见如下代码中的localeData对象，该对象中定义了属性currentStep，用来保存sensor接口返回的结果。
2. 在app.ux生命周期onCreate()中调用sensor计步传感器接口。
3. 具体页面调用$watch()函数监听步骤1中的currentStep，实时获取步数。

具体示例代码如下。

```screen
<script>
  import sensor from '@system.sensor'
  module.exports = {
    onCreate() {
      console.info('Application onCreate');
      this.listenStep();
    },
    onDestroy() {
      console.info('Application onDestroy');
      sensor.unsubscribeStepCounter();
    },
    listenStep: function () {
      console.info("currentStep START ");
      var that = this
      sensor.subscribeStepCounter({
        callback: function (ret) {
          that.data.localeData.currentStep = ret.steps;
          console.info("currentStep CALLBACK :" + that.data.localeData.currentStep);
        },
        fail: function (erromsg, errocode) {
          console.log('currentStep.subscribe----------' + errocode + ': ' + erromsg)
        }
      })
    },
    data: {
      localeData: {
        currentStep: '',
      }
    }
  }
</script>
```

### 调用geolocation.getLocation接口使用gcj02坐标系，经纬度返回的都是5e-324，为什么？

5e-324是无网络/网络不佳返回的固定值，快应用引擎针对无网络/网络不佳做了两种处理。

* 第一次调用定位接口时，如果无网络/网络不佳，就直接触发fail回调，返回200错误码，提示超时。
* 第一次调用定位接口时，定位成功并返回正确的经纬度，之后再次定位时如果无网络/网络不佳，也会返回经纬度，但是为固定值5e-324。

### 如何实现车辆停止时显示二维码，车辆启动后二维码蒙层或者不显示二维码？

1. 调用restrictions.registerUxRestrictionsListener注册车辆UX限制监听，restrictionsType值传对应的二维码限制项值。
2. 调用restrictions.getUxRestrictions查询是否限制二维码扫描功能，根据查询的结果，执行步骤3。
3. 实现二维码蒙层的功能，更换不可扫描的二维码或者弹出模糊图片覆盖原二维码等，需要使用if/show指令来控制是否显示/隐藏，详细参见示例代码中的isDriving变量。

页面template结构代码：

```screen
<!-- 原界面展示的二维码-->
<div class="item-content" show="{{!isDriving}}">
    <image class="mongolia" src="/common/img/qrcode.png"></image>                
</div>
<!-- 车辆行驶后展示的二维码-->
<div class="item-content" show="{{isDriving}}">
    <image class="mongolia" src="/common/img/mongolia.png"></image>
</div>
```

具体实现逻辑的代码：

```screen
regist() {
    var that = this;
    //注册车辆UX限制监听
    restrictions.registerUxRestrictionsListener({
        restrictionsType: 64,
        success: function (res) {
            console.log('车辆状态变化，监听回调：  success', res);
            let restricted = res.isRestricted;
            console.log('车辆状态变化，监听回调：  restricted ', restricted);

            prompt.showToast({ message: that.componentData.toastMessage1 + restricted })
        },
        fail: function (erromsg) {
            console.log('车辆状态变化，监听回调：  fail ', erromsg);
            that.isDriving = false;
        }
    })
},
//查询当前车辆UX监听结果
getUxRestrictions() {
    var that = this;
    restrictions.getUxRestrictions({
        restrictionsType: 64,
        success: function (res) {
            console.log('getUxRestrictions：  success', res)
            let restricted = res.isRestricted;
            //得到监听结果后处理具体蒙层效果,可使用页面if/show方法覆盖原二维码：
            that.isDriving = restricted;
        },

            console.log('获取二维码限制状态：  fail ', erromsg);
        },
    })
},
```

### 在真实车机上调用restrictions.registerUxRestrictionsListener成功了，但是为什么没有立即执行success的回调内容？

> 说明
>
> 行驶状态由每个车厂自己定义的，一般车速为0是停车状态，车速大于5或者15才会触发该回调，车辆状态也会立即改为行驶状态。

```screen
regist() {
    var that = this;

        success: function (res) {
```

## H5转换快应用

### 快应用是否支持通过URL打开？H5快应用的URL和普通的网页URL有什么区别？

支持。快应用支持通过网页打开，可以在网页中嵌入[Deeplink](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-develop-deeplink-0000001079808096)跳转实现。

H5快应用的URL和普通网页的URL没有区别，理论上普通网页URL都可以使用快应用的web组件打开。

### 如何在H5页面识别来自快应用的请求，不引导下载APP？

快应用的web组件，与一般浏览器Chrome、Safari一样都是标准的HTML执行环境，加载H5网页时会上报useragent字段到服务器，H5网页可以通过JS函数获取当前执行环境的UA。因此识别快应用的请求可以通过设置web组件的useragent属性来实现。

具体实现方法如下：

1. 在快应用中配置web组件的useragent属性值为default。

   ```screen
   <web id='web' allowthirdpartycookies="true" useragent="default"></web>
   ```

2. 在H5页面中检查window.navigator.userAgent对象中是否包含hap关键字，如果包含表示请求来自快应用。

   ```screen
   if (window.navigator.userAgent.indexOf("hap") >= 0) {
       // 当前请求来自快应用
   }
   ```

### 如果网站支持多语言，是否可以根据系统语言自动打开对应语言的网页？

可以。

在快应用生命周期onInit()方法中通过快应用API device接口获取系统地区语言，判断语言后加载对应的H5网址。比如手机系统语言为日语时，打开日语网页；系统语言为简体中文时，打开简体中文网页。示例代码如下：

```screen
onInit: function () {
    const device=require("@system.device")
    const res=device.getInfoSync();
    let local=res.language;  //system language  
    let region=res.region;  //system region
    console.info('onInit :locale= ' + local+", region="+region);
    if(local==='zh'){  
         if(region==="CN"){
            this.loadUrl="https://transit.navitime.com/zh-cn/";
         }else if(region==="TW"){
             this.loadUrl="https://transit.navitime.com/zh-tw/"; 
         }
    }else if(local==='ja'){ 
        this.loadUrl="https://transit.navitime.com/ja/?from=huawei.quickapp";
    }else{
       //Other languages can use the default language H5
       this.loadUrl="https://transit.navitime.com/en"; 
   }
},
```

## 小程序转换快应用

### 之前开发上架的快应用，是否可以和小程序转换的快应用共存？

之前开发上架的快应用如果需要和转换的快应用使用相同的包名和应用名称，则不能同时存在。

### 如果之前上架的快应用存在一些推广链接等，切换到新的快应用后是否能够正常跳转？

原来快应用的页面路径是到目录级别的，小程序转快应用后的页面路径是到文件级别的，所以不能够直接跳转，请在转换后的项目根目录下增加route-mapping.json文件进行转换配置。

```screen
{
    "page/index": "page/index/index",
    "page/index2": "page/index2/index",
}
```

或者在app.json中增加转换配置。

```screen
"routeMapping": {
    "page/index": "page/index/index",
    "page/index2": "page/index2/index"
}
```

### 已有快应用的账号、应用内支付、推送服务是否可以使用，如何迁移？

如果之前快应用已经按照华为要求接入相关服务，使用转换后的快应用替换原有快应用相关服务无需重复接入，调用小程序转快应用相关接口即可。

### 卡片是否可以和转换的快应用工程一起打包？

可以。目前IDE已支持卡片融合打包。

### 小程序支持与快应用代码混编吗？在js中可以引入快应用的模块吗？

不支持混编，暂不支持js中导入快应用模块。

### 如何在小程序转换的快应用中添加卡片？

在小程序转换的快应用中添加卡片和原生快应用类似，不同点在于：原生快应用在manifest.json中配置卡片，小程序转换的快应用是在app.json中配置卡片，卡片的开发依然遵循华为快应用的规范。华为快应用IDE支持将小程序转换的快应用工程和卡片融合打包。

### 调用qa.accountAuthorize返回报错1002，如何处理？

出现此错误码，一般为证书签名问题。请使用华为快应用IDE生成release签名，同时将生成的指纹配置到AppGallery Connect，最后打包release版本的rpk包，在华为快应用加载器中运行调试。

### IDE新建快应用项目，可以使用@system.device，@system.storage等内置包，但是小程序转快应用后却不行，是有什么限制吗？

在快应用中新建的项目才可以使用内置包，而小程序转的快应用，是通过webview加载的，所以不能使用这些内置包，直接调用qa.xxx接口即可。

### 小程序转换快应用后，使用image组件加载云服务器上的图片时，可以正确获取图片的链接地址，但是图片无法显示，如何处理？

请检查云服务器是否有设置防盗链，当前快应用不支持对防盗链的访问。

### 小程序转换快应用，无法调用快应用的$app.exit，如何在页面关闭快应用？

使用小程序转换快应用的navigator组件，设置open-type:exit可以实现。

示例代码如下：

```screen
<view class="btn-area">
      <navigator target="quickApp" open-type="exit">退出快应用</navigator>
 </view>
```

### 小程序转换快应用，打包时提示"页面路径pages/order-enter/order-enter非法"，如何处理?

华为快应用页面路径只支持数字、大小写字母及下划线组合，请勿使用"-"符号。

### 自定义组件的对外属性命名为dataXxx（即按驼峰命名法则，将data作为前缀）时，使用组件无法从外部设置属性，如何处理？

在模板中，对于以驼峰法则命名的属性，会进行data-xxx的转译，从而和dataset的使用写法冲突。请将对外属性重命名，避免命名采用dataXxx的格式。

## 接入华为服务

### 接入账号服务时出现异常，如何处理？

华为账号接口为厂商定制接口，为了方便定位问题，调试时，请[安装华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)进行调试。

出现异常请参见如下操作进行定位：

1. 检查是否已在"华为开发者联盟"申请华为账号服务。详细内容请参见官方文档"[开通账号服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-account-kit-0000001126786239)"。
2. 调用account.getProvider，请确保获取返回值为huawei后，再调用其他接口。华为账号相关接口请参见官方文档"[API> 华为服务 > 账号](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-account-0000001075392510)"。
3. 如果出现1002的错误码，请检查使用IDE生成的签名信息和"华为开发者联盟"上配置的证书指纹是否保持一致。
4. 出现其他错误码，请参见华为账号"[通用错误码](https://developer.huawei.com/consumer/cn/doc/development/HMS-2-References/hmssdk_jointOper_api_reference_errorcode)"中"HMSSDK框架错误码"部分的错误码进行处理。

### 调用account.authorize方法，出现signInByBaseScope Authorize base profile fail, code=1的报错信息，如何处理？

出现此错误是由于调试设备上没有安装HMS Core，请到华为应用市场下载并安装最新版本的HMS Core。

### 如何在手机上取消对快应用的用户授权？

进入手机设置页面，点击登录的账号，菜单选择"隐私中心 > 控制对您账号的访问"，点击需要取消授权的应用，点击"取消授权"。

### 如何清除HMS账号服务的缓存数据？

* 清理HMS的缓存数据：手机上点击"设置 > 应用 > 应用管理 > HMS Core > 存储"进入"存储"页面，点击"清空缓存"。
* 清理HMS的管理空间数据：手机上点击"设置 > 应用 > 应用管理 > HMS Core > 存储"进入"存储"页面，点击"管理空间 > 清理数据"。

### PUSH推送可以不填regid，进行所有用户推送吗？

不可以。推送是根据regid进行的，一个regid代表一个用户。

### 在AppGallery Connect发送PUSH消息时，填入token后又会消失，如何处理？

填入token后，加上逗号结束即可。

### 点击PUSH的通知栏消息，跳转到快应用界面显示"该应用已下架或者不在应用服务区"，如何处理？

请检查PUSH消息体中传入的page参数是否正确，该参数填写页面路径即可，如果填写/，则默认打开主页。

### 推送PUSH消息成功多次，但是手机只收到5次，回执地址接收的状态码为102，如何处理？

回执状态码为102表示消息被频控丢弃了，从而导致手机无法收到。

快应用的频控策略为：同一款快应用每天只能向同一个用户推送最多5条PUSH消息。

### 不同快应用的regId是全局唯一吗?

不同快应用，同一个手机的regId不一样。

相同的快应用，不同手机的regId不一样，同一个手机的线上线下regId也不一样。（regId和快应用运行环境相关，在快应用加载器中获取的regId只能用于在加载器中运行的快应用推送消息。）

每个快应用在每个手机上获取到的regId都是唯一的，一般情况下不会发生变化。

### 使用服务端接口发送PUSH消息时，提示Success，但是手机未收到消息，如何处理？

1. 检查消息体validate_only设置的值，为true表示测试消息只做格式合法性校验，不会推送给用户设备，正确应该是设为false。
2. 检查消息体params参数值，当Pushtype=0时，即使不需要携带参数，params参数也必须写入pushbody体中，例如：

   ```screen
   "params":{
   }
   ```

3. 检查是否使用了设备老的token，而非设备最新的token发送，快应用引擎会检测token是否是最新的，如果不是最新的，手机端也不会显示消息。token上报的时候，业务服务器务必要做更新。

### push.getProvider接口返回为空，如何处理？

接入华为PUSH服务时，需要使用华为的快应用加载器，请检查以下几点：

* 是否使用华为快应用加载器进行测试。
* 是否使用华为手机，如果是华为手机，检查华为手机的emui 版本号是否大于8.0。

如果以上条件都满足，push.getProvider会返回非空字符串。

### PUSH消息如何设置跳转到加载器？

1. 发送消息接口中的fast_app_target设置为1。
2. 加载器已有该快应用的使用记录。

### push.subscribe接口获取regid，提示"200 request apptoken error"错误 ，如何处理？

* 检查PUSH服务是否开通。
* 检查在AGC上申请开通PUSH服务的包名是否和rpk中的包名一致。
* 检查手机上是否预装了推送服务app。手机上点击"设置 > 应用 > 应用管理"，搜索是否存在"推送服务"。
* 如果以上3点都满足，请确认本地网络是否使用了代理。

### 在服务端发送推送消息时，返回"503 Service temporarily unavailable", 如何处理？

503错误码是指推送速率过快，受到服务器端流量控制，解决方案如下：

1. 平均分配发送速度，尽量控制在华为提供的QPS（一秒可以发送推送的条数）配额内。 建议每次发送条数不要设置太多，例如QPS为6000，即每秒发送100次，每次发送60条。具体的QPS计算方法可参见"[FAQ](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides-V5/faq-0000001050042183-V5)"中的"推送服务有什么使用限制？"

2. 平均分布推送时间段，不要集中发送。

### 快应用发送PUSH通知，配置了回执地址后，回执地址收到的status code各表示什么意思？

华为消息状态（status）介绍：

* 0：成功
* 1：设备不在线
* 2：成功发送到设备，对应的客户端应用不存在，通常表示已经卸载
* 5：终端安装了该应用，但从未打开过，未申请token，所以不能展示
* 6：用户设置不接收该App的PUSH消息
* 7：下发通知栏消息给sdk由PUSH弹通知栏，PushAPK不允许弹通知栏（华为手机管家设置）
* 8：PushAPK不允许弹通知栏（华为手机管家设置）
* 9：SDK不允许弹通知栏（华为手机管家设置）
* 10：非活跃设备，消息丢弃
* 12：无设备路由信息
* 13：设备在其他大区（中国大陆一般不用考虑，通常是全球化CP）
* 102：消息被频控
* 201：无效token管控

具体请参见[消息回执](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/msg-receipt-guide-0000001050040176)的状态码。

### 为何快应用项目推送到设备会白屏？

* 在使用数组循环设置图片时，使用了两个image通过获取评分的值与数组的值做判断来显示两种不同的图片，设置两个image标签通过if和else方式显示不同图片的写法。 **解决方案**：设置一个image标签，通过三元运算符为image的src属性设置不同的图片url。

* 在onInit()方法中错误使用setInterval周期性的刷新快应用数据，例如设置的周期10ms，导致快应用过于频繁刷新数据，从而导致快应用白屏。 **解决方案**：将setInterval的周期时间设置长一点，例如设置为：10*1000ms，也就是10秒，就可以避免此问题。

* 快应用中使用了媒体查询，但是现在快应用在手机端还不支持媒体查询。 **解决方案**：暂时手机上的快应用中不使用媒体查询。

* 使用了list组件，但是没有为list组件设置高度。 **解决方案**：为list组件设置高度。

### 如何获取快应用标题栏的高度？

可以通过[device.getInfo(OBJECT)](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-device-0000001075389690#section1030619161341)接口获取设备信息，然后根据公式计算：标题栏高度=屏幕的高度-可使用窗口高度-状态栏高度，即titleBarHeight= screenHeight-windowHeight-statusBarHeight。screenHeight和windowHeight的计算方式参见"[screenHeight和windowHeight的高度分别指什么](#section1621213361175)"。
> 注意
>
> 使用上述公式计算时，不能开启沉浸式状态栏，否则计算数据有误。即statusBarImmersive字段不能设置为true。

示例代码如下：

```screen
<template>
  <div class="container">
    <text>标题栏高度：</text>
    <text style="background-color: #7cfc00;">{{ this.titieBarHeight }}</text>
  </div>
</template>
<style>
  .container {
    width: 350px;
    height: 250px;
  }
</style>
<script>
  import device from "@system.device";
  export default {
    data: {
      titieBarHeight: ""
    },
    onInit() {
      this.$page.setTitleBar({ text: "获取标题栏高度", backgroundColor: "#7cfc00" });
      this.$page.setStatusBar({ backgroundColor: "#8b0000" });
    },
    onShow: function () {
      var that = this;
      device.getInfo({
        success: function (ret) {
          console.log("屏幕的高度=" + ret.screenHeight);
          console.log("状态栏高度=" + ret.statusBarHeight);
          console.log("可使用窗口高度=" + ret.windowHeight);
          console.log("屏幕密度=" + ret.screenDensity);
          console.log("标题栏高度=" + (ret.screenHeight - ret.statusBarHeight - ret.windowHeight));
          that.titieBarHeight = ret.screenHeight - ret.statusBarHeight - ret.windowHeight;
        }
      });
    }
  };
</script>
```

## 功能、机制、规则

### 应用使用加载器测试正常，上架后某些页面白屏，但是没有报错，如何处理？

出现此类现象大多是由安全沙箱导致的，请参见谷歌的"[内容安全策略](https://developer.chrome.com/extensions/contentSecurityPolicy)"，排查代码中违反安全性的地方。

### 为什么快应用PUSH消息发送失败（消息频控丢弃）？

为了提升用户体验，减少对用户的打扰，平台对PUSH消息发送频次做了限制，同一款快应用每天只能向同一用户推送5条PUSH消息。另外，PUSH消息不得推送与快应用自身业务无关内容以及诱导性广告、低俗/诈骗/涉黄/涉暴/涉政等信息，违者将关停处罚。

### 跳转快应用（包括：Deeplink、approuter、router.push）携带的参数有限制吗？

有限制。从非华为浏览器跳转快应用链接携带的参数大小总长度不能超过932B，华为浏览器跳转快应用链接携带的参数大小总长度不能超128K。

### 快应用名称设置了国际化，系统语言和地区改变后，为什么使用记录中应用名没有生效，打开快应用后退出才生效？

### 使用系统标题栏的时候，跳转至二级页面后的左上角返回按钮有方法去掉或者隐藏吗？

系统标题栏返回箭头是快应用引擎统一行为，方便用户返回操作，没有提供接口去掉或者隐藏。

### 如何升级快应用？

* 开发者：如果快应用内代码有改动，需要将manifest.json文件中的应用版本号versionCode+1，然后和app一样，提交新版本上架。 注意
  >
  > 升级时证书文件不能发生变化，否则会因为签名不一致，导致升级失败。
* 用户：从未打开过该快应用的用户第一次打开时，获取的就是应用市场上发布的最新版本。有使用记录的老用户更新版本后首次打开不是新版本，需再次打开才是最新版本。

### 签名变化对快应用版本更新有影响吗？

签名变化会导致打开过该快应用的老用户无法升级到最新版本，老用户始终打开的是引擎中缓存的老版本。第一次打开该快应用的新用户不受影响，打开的是最新版本。

### 快应用配置了菜单，但是为什么在快应用加载器调试菜单项中没有分享入口，上线后的快应用有分享入口？

快应用加载器仅用于开发调试使用，分享功能是分享快应用rpk文件的下载链接，本地加载时无法获取上架后的链接，而线上快应用打开时，是可以获取到下载地址，所以线上快应用菜单有分享功能。

### 快应用版本更新后，为什么打开之后还是老版本的内容？

新版本审核上架后，所有用户将在24小时内更新至最新版本。如果应用市场打开仍是老版本，请确认应用审核通过的时间，更新时间比较短，请再耐心等待一下。

### 使用IDE开发时，触发推送手机运行时无法连接手机，如何处理？

1. 请确保手机已经通过USB连接电脑，并打开"开发者模式"。具体操作请参见"[华为手机如何打开开发者选项](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-open-developer-option-0000001137005543)"
2. 请确认adb与手机连接成功。
   1. 打开终端Terminal，将目录切换至IDE目录 {installDir}/resource/app/extensions/deveco-debug/lib/toolkit。
   2. 执行 adb devices 命令。
      * 若 List of devices attached 下出现手机信息并且以device结尾，则说明adb已监控到手机。
      * 若List of devices attached 无信息输出，手机编号后结尾为offline，则表示adb没有与手机连接成功，此时进行调试、预览、inspect均会提示无法找到手机的错误。建议重启手机或者撤销USB的授权后重新插入手机。
3. 请确认手机上已经安装了正确的快应用引擎。
4. 请确保PC ADB端口可用，若默认端口被占用，请修改ADB端口。
5. 若需使用调试功能，请确保8088端口可用。
6. 若出现找不到设备或者adb daemon启动时ACK及smartsocket等问题，请执行 netstat --ano | findstr {*adbPort* }(mac下请执行lsof --i:{*adbPort*})，确认adb的端口未被占用或者有已启动的adb服务。

### 快应用IDE升级到11.4.1后，使用Node.js的核心模块时编译报错，如何处理？

快应用IDE的编译器从11.4.1版本开始，升级webpack到webpack 5，该版本移除了部分模块，详细内容参见"[webpack 5版本更新说明](https://webpack.js.org/blog/2020-10-10-webpack-5-release/#automatic-nodejs-polyfills-removed)"和"[移除模块列表](https://webpack.js.org/configuration/resolve/#resolvefallback)"。

所以当开发的项目中使用了移除的模块，编译时会报错，错误信息中会包含如下关键信息：BREAKING CHANGE，webpack 5，polyfills for node.js。

```screen
ERROR: Module not found: Error: Can't resolve 'crypto' in

`BREAKING CHANGE`, webpack < 5 used to include polyfills for node.js core modules by default.
This is no longer the case. Verify if you need this module and configure a polyfill for it.

If you want to include a polyfill, you need to:
	- add a fallback 'resolve.fallback: { "crypto": require.resolve("crypto-browserify") }'
	- install 'crypto-browserify'
If you don't want to include a polyfill, you can use an empty module like this:	resolve.fallback: { "crypto": false }
```

出现此错误，请参考如下步骤进行处理：

1. 在项目的根目录新增quickapp.config.js文件。 说明
   >
   > quickapp.config.js的配置生效需要确保package.json中配置的编译器fa-toolkit版本大于等于3.1.2版本。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/kSxI_VIGRdSYAZSC_jKK1w/zh-cn_image_0000001160320426.png?HW-CC-KV=V1&HW-CC-Date=20260909T152916Z&HW-CC-Expire=31536000000&HW-CC-Sign=425472B842E111B4A5313D20B61501A9F38AE37073098AE8F394E515AA4E3186)
2. 根据错误信息，添加对应node.js的核心模块，以crypto为例。

   ```screen
   module.exports = {
       resolve: {
           fallback: {
               // 添加对应的 Node.js 的核心模块, 此处以crypto为例，请按实际情况安装对应依赖
               "zlib": require.resolve("crypto")
           }
       }
   }
   ```

3. 执行 **npm i** *crypto* 安装对应的依赖。

## 核准（备案）

### 仅需在华为接入商核准（备案）快应用，还是所有接入商都要核准（备案）？

每个接入商都要单独核准（备案），例如在华为接入商核准（备案）快应用成功后，还可以在其它接入商接入快应用。

### 快应用核准（备案）审核需要多久？

* 华为平台初审需要3~5个工作日。
* 各省/市的通信管理局终审需要2~20个工作日，具体以实际审核时间为准。审核结果以邮件/短信形式通知。

## 上架审核

### 快应用在提交审核前需要准备哪些资质文件？

请根据提交快应用的类别，参见"版权、版号、核准（备案）资质审核"的"[1. 应用版权提供](https://developer.huawei.com/consumer/cn/doc/app/80301)"章节内容准备相应的资质文件。

填写免责函时，个人开发者在盖章处加按手印，并同时提供手持身份证正、反两面的照片。免责函中的AppID，为创建快应用时在华为开发者联盟为快应用分配的唯一标识，查看方式请参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。

### 快应用所需要的资质文件在哪里提交？

如果需要提供应用相关版权资质，请直接在华为开发者联盟后台提交，在"应用版权证书或代理证书"处上传，最多上传5张照片，如果超过5张照片，请将多张照片拼接到一起，图片需要清晰。同时请直接上传RPK包，完善产品信息后提交审核。详细操作请参见"[提交审核](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-app-release-0000001129563721)"。

一般为3-5个工作日，如果提交的应用审核不合格，会邮件通知您修改后，再次提交审核。

### 应用更新版本时，如果要变更签名证书，如何处理？

需重新创建新的快应用，待上架后将旧版本申请下架。

### 上传审核包提示rpk包解析失败，如何处理？

请检查rpk包中是否存在多个manifest文件，如果是，请删除子目录中的manifest文件，仅保留根目录的即可。

### 上传审核包提示文件类型错误，如何处理？

请到AppGallery Connect上查看应用信息，确认软件包类型是否和软件包匹配。 出现此问题，一般是不匹配导致的。请重新创建匹配的快应用，新创建的应用appid会发生变化，所以请检查业务代码中使用appid的地方，重新修改后再提交审核。

### 签名弄丢了如何更新版本？

签名证书文件丢失了是无法找回的，需重重新创建新的快应用，待上架后将旧版本的快应用申请下架。

### 提交审核时提示签名不一致，如何处理？

新版本使用的签名必须和原上架应用的签名保持一致，否则是无法更新到新版本。签名证书文件一旦创建好后务必保管好，丢失了就无法找回。

### 上传包时提示"当前操作遇到异常无法正常完成"，如何处理？

出现此问题一般与快应用manifest.json文件中的versionCode字段有关，请检查是否填写了异常的值，正常需填写long类型的数字。

### 应用驳回原因为：很抱歉，XXX出现错误，如何处理？

出现此错误信息，一般是因为快应用代码中有些小问题（比较常见的错误是组件绑定了事件回调函数，但实际该函数没有定义），请[安装华为快应用IDE和华为快应用加载器](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)进行调试定位，一般可以复现和定位出错误。

### 应用驳回原因为：应用名称不得广义归纳类、普遍且不具有识别性的词汇来命名，如何处理？

快应用不允许直接以诸如：电话、邮件、日历、汽车、证券、期货等广义归纳类词汇作为应用名称。例如，"查快递"因应用名称过于广义被驳回，改名为"快递直通车"审核通过。另外，应用名称建议使用中文。

### 在快应用项目创建了卡片，然后将配置文件中卡片的配置删除，提交审核时，为什么华为审核无法查看到卡片的包？

删除卡片配置信息后再打包快应用项目时，卡片不会被打包，从而导致审核无法获取卡片的包。

### 应用因部分图片不显示被驳回，但是本地测试是正常的，为什么？

应用提交审核需经过网站检测，图片命名中存在的特殊字符会被过滤掉，所以应用项目所有文件需按照规范进行命名：只能包含字母、数字、点、下划线、中划线、小括号，不能包含".."、"./"，文件名长度不能超过300个字符。

### 提交快应用被驳回，提示华为开发者联盟已经创建相同应用，但是未添加应用市场服务，请添加应用服务后重试，如何处理？

出现此驳回原因一般有两种情况：

* 首次提交快应用时，在华为AppGallery Connect上没有对应的快应用。先登录华为AppGallery Connect[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)。
* 在AppGallery Connect上对版本进行了升级，但是没有提交。

更新版本时，要么在快应用联盟提交，要么在AppGallery Connect上提交，切勿在AppGallery Connect上操作未提交的情况下，再去快应用联盟升级版本。

### 在华为平台提交快应用审核时，提交了资质文件，审核通过。之后从快应用联盟官网提交，华为提示缺少资质文件或文件过期而驳回，为什么？

开发者在快应用联盟官网提交的应用信息可以同步至各厂商的平台，但是不会从厂商的平台同步至快应用联盟官网，所以在华为平台提交的内容虽然通过审核，但是没有同步到快应用联盟官网，所以那边的资质文件还是老的。当开发者再次通过快应用联盟提交内容时，会将老信息覆盖华为平台的新信息。

因此，在厂商平台单独提交更新的内容，务必在快应用联盟官网也提交更新。

### 在快应用联盟提交审核，被驳回提示：ErrorCode=XXXXX，如何处理？

此错误一般出现在通过快应用联盟提交软件包的场景，是由于快应用联盟系统和厂商系统之间同步出错导致，请单独到华为开发者官网上提交即可。

### 应用驳回原因为：软著名称与上传的应用名称不一致，如何处理？

rpk包中的快应用名称、开发者网站上创建的快应用名称、软著上的应用名称必须保持一致。

### 应用驳回的问题无法复现，如何处理？

华为平台审核使用的是华为快应用加载器，请下载安装华为快应用加载器以及华为快应用IDE，打开项目，调试定位问题原因。获取安装工具的地址：

https://developer.huawei.com/consumer/cn/doc/Tools-Library/quickapp-ide-download-0000001101172926

### 应用驳回原因为：应用内未提供隐私协议，但应用中有提供，且第一次打开快应用需同意协议后才可进入，为什么？

不仅仅在打开应用的时候需要有隐私协议，在应用内也需要有地方可以查看。具体审核要求请参见"[审核指南](https://developer.huawei.com/consumer/cn/doc/50104)"。

### 应用驳回原因为：快应用名称与添加至桌面显示的名称不一致，如何处理？

快应用项目manifest.json文件中配置的应用名称必须和开发者网站上创建快应用使用的名称保持一致。

### 应用驳回原因为：快应用同步失败，如何处理？

如果是从快应用联盟官网提交审核的，请重新到华为开发者网站提交审核。

### 应用驳回原因为：未绑定华为开发者账号，但快应用联盟后台显示已绑定了，为什么？

审核时间如果早于绑定账号审核通过时间就会被驳回，比如审核驳回是1月20日，绑定华为账号是1月29日才通过的，那就会驳回，使用绑定华为账号的账号重新走下提交审核流程即可。

### 应用驳回原因为：已有版本在审核，不允许当前操作，errorcode=1，如何处理？

已有版本在审核中，是不允许再次提交的，系统会自动驳回，需要等审核中的版本有结果后，才可以提交新版本。

### 应用驳回原因为：addAianceApp, getRpkListByParame failed.，[ErrorCode]=90200006，如何处理？

请检查快应用包名中是否包含特殊字符，比如com.app.todo-mv中带有特殊字符-。包名建议全部是小写字母，格式为com.xx.xxx。

### 应用驳回原因为：账号下存在相似的应用，如何处理？

请检查是否上架过相似应用，如果申请下架是否已走完上架流程，没有下架就提交审核就会有此问题。

### 应用驳回原因为：资质文件不完整、应用分类不对等，如何处理？

请参见"[准备资质文件](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-prepare-doc-0000001129385459)"了解资质文件和分类要求，如果还存在疑问，可以参见"[如何与快应用审核沟通](#section68834101595)"在互动中心留言互动。

### 应用驳回原因为：应用打开后，部分页面空白、部分图标未显示，但是本地加载测试都是正常的，如何处理？

rpk包大于1M，会有拆包操作，审核收到的rpk包是分包后的，rpk包中引用的图片等资源命名如果不符合规范，拆包时会将包含特殊字符的路径过滤掉，导致审核时看到的页面是空白。项目中所有文件名只能包含字母、数字、点、下划线、中划线、小括号，不能包含".."、"./"， 文件名长度不能超过300个字符。

### 应用驳回原因为：应用内存在分发内容，分发内容是指什么？

是指快应用内包含下载三方App的操作。

### 应用驳回原因为：包名冲突，如何处理？

每个应用的包名是唯一的，出现此问题一般是华为开发者网站上该账号下已经创建过同包名的应用，如果有同包名、同类型的应用，请单独在华为开发者网站找到此应用提交rpk包审核。

### 应用驳回原因为：应用内的用户协议/隐私政策的公司与应用开发者的名称不一致，如何处理？

此处的名称并不是快应用名称，而是申请开发者联盟账号时使用的公司主体名称，请确认是否与应用内的用户协议/隐私政策的公司名称一致。

### 应用驳回原因为：需要有隐私政策提示框，告知用户快应用可能涉及到的隐私和使用的权限说明，如何处理？

针对此驳回意见，需要在快应用中补充实现弹出隐私协议提示框，提示框中包含详细协议的链接，并且用户可以点击确认。类似下图效果：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/CvYn82zvQ6Cf2aeD06jwcQ/zh-cn_image_0000001213977264.png?HW-CC-KV=V1&HW-CC-Date=20260909T152916Z&HW-CC-Expire=31536000000&HW-CC-Sign=663DEF792B87CD2BD81AFA5756168D4BE68F06F26D12AB2DF958A584EEB9D1FF)

而快应用的prompt.showDialog接口提供的弹框只能显示文字、按钮简单的元素，无法实现复杂的页面效果，所以需要通过自定义组件的形式来实现。

提示框涉及text、span、a组件，a组件实现在用户协议和隐私政策上加超链接，用户点击后可以跳转到具体说明的页面。提示框按钮点击处理逻辑为：点击同意将提示框隐藏起来，同时判断在退出快应用后重新进入时是否需要再次弹出；点击取消则调用this.$app.exit();退出快应用。

**【实现方案】**

在主页面通过stack组件堆叠和通过if属性来控制自定义组件的显示与隐藏。

自定义组件中处理点击同意的实现如下：

1. 将if的属性设为false。
2. 改变flag（即isagree）的值。flag用于在主页面中判断在退出快应用后重新进入时，是否需要再次弹出隐私政策提示框。

由于同意按钮是写在自定义组件中，所以需要使用父子组件的通信来实现，子组件通过$dispatch()触发自定义事件，主页面（父组件）通过$on()监控自定义事件的触发。实现代码如下：

**主页面：**

```screen
this.$on("dispatchEvent", this.dispatchEvent);
dispatchEvent(evt) {
  this.display = evt.detail.display;//if属性的变量
  this.isagree = evt.detail.isagree;//判断下次进入是否需要再次弹出的变量
  this.save(this.isagree);
},
```

**子组件：**

```screen
this.$dispatch("dispatchEvent", {
    display: false,
    isagree: "agree"
});
```

改变flag的值后，在主页面中调用storage.set和storage.get接口来存储和读取flag的值。代码如下：

```screen
save(params) {
  storage.set({
    key: "agreeFlag",
    value: params,
    success: function (data) {
      console.log("handling success");
    },
    fail: function (data, code) {
      console.log("handling fail, code = " + code);
    }
  });
},
get() {
  var that = this;
  storage.get({
    key: "agreeFlag",
    success: function (data) {
      that.isagree = data;
      console.log("handling success", data);
    },
    fail: function (data, code) {
      console.log("handling fail, code = " + code);
    }
  });
},
onShow(options) {
  var that = this;
  that.get();//获取存储的flag值，
  setTimeout(() => {
    if (that.isagree === "agree") {//判断是否需要弹出提示框
      that.display = false;//用户点击同意后，就不再弹出
    } else {
      setTimeout(() => {
        that.display = true;//否则继续显示
      }, 100);
    }
  }, 500);
  console.log("message", that.isagree);
  this.$on("dispatchEvent", this.dispatchEvent);
},
```

### 配置广告正式id提审应用市场，驳回原因为：点击广告是空白，如何处理？

可能广告逻辑做错了，当没有广告数据时不要弹出广告，避免出现空白广告。

### 应用驳回原因为：Auto verify not pass.，[ErrorCode]=80210108，如何处理？

该原因一般为用户实名认证或者小额打款认证没有通过，需要在华为开发者联盟开通实名认证和小额打款认证。

### 应用驳回原因为：参数错误，[ErrorCode]= 90200001，如何处理？

在快应用联盟后台提交审核时，辅助发布信息的文字描述太多，建议优化到300字以内再提交。

### 应用驳回原因为：账号未实名认证，如何处理？

开发者使用的账号有两种，一个是个人开发者注册的账号，一个是企业提供的账号。因此实名认证分为两种：个人开发者实名认证和企业开发者实名认证。

* 个人开发者实名认证有三种方式：
  * [个人银行卡认证](https://developer.huawei.com/consumer/cn/doc/start/ibca-0000001062388135)（推荐使用，简单易操作，可立刻通过认证）
  * 身份证人工审核认证
  * 华为云授权认证
* 企业开发者实名认证有三种方式：
  * [企业对公账户打款认证](https://developer.huawei.com/consumer/cn/doc/start/atpopb-0000001062836624)（推荐使用，简单易操作，认证时间相对较短）
  * 企业资料人工审核认证
  * 华为云授权认证

### 应用驳回原因为：应用不存在，[ErrorCode]=3，如何处理？

是因为绑定的华为账号下没有对应的快应用，请登录华为开发者联盟网站创建对应的应用，再去提交审核。

### 应用驳回原因为：未绑定华为账号，需要绑定，如何处理？

是因为快应用联盟里是否没有绑定华为账号或者绑定的华为账号还在审核中，请等待账号绑定成功后再重新提交rpk包审核。

## 报表

### 快应用上架后，相关运营数据在哪里查看？

华为开发者联盟有提供相关数据的报表统计，详细查看方式请参见"[报表分析](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-view-report-0000001082020378)"。

### 快应用报表的新增打开次数是如何定义的？

是指快应用某一天被打开的次数。

### 快应用进行应用转移后，快应用的用户报表历史数据是空白无法查看，为什么？

应用转移会导致快应用所属的开发者账号发生改变，在新账号下所属的团队账号（agcTeamId）也发生了改变，而查询快应用用户报表的历史数据需要保证appId和agcTeamId和转移之前是一致的，所以转移之后无法查看历史数据。并且应用转移之后是无法恢复查看历史数据，报表数据只能重新记录，因此建议开发者慎重选择应用转移。

### 快应用登录时如何获取多个scope授权？

快应用支持登录时获取多个scope授权，调用[account.authorize](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-account-0000001075392510#section1110582163011)接口时多个scope之间请用空格隔开。
