# 安装开发工具

#### 华为快应用IDE

华为快应用IDE是基于VSCode框架深度定制的快应用IDE，集工程管理、编程、实时预览、Inspect、调测、云测试、发布上架于一体的一站式快应用开发工具，提供完善的快应用极速编程、云端全机型覆盖测试等必备工具能力的同时，继承开发者习惯，让快应用开发更快。

1. [下载华为快应用IDE安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/quickapp-ide-download-0000001101172926#ZH-CN_TOPIC_0000001101172926__section8185184915)。

<!-- -->

2. 安装华为快应用IDE。
   * Windows 64位：双击下载的安装包进行安装（安装过程中将自动删除旧版本的内容）。
3. 华为快应用IDE的使用方法参见"[华为快应用IDE使用指导](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ide-overview-0000001147936547)"。  

#### 华为快应用加载器

华为快应用加载器用于启动和调试快应用，调试运行不同平台的快应用需要使用不同的加载器。

1. [下载华为快应用加载器安装包](https://developer.huawei.com/consumer/cn/doc/Tools-Library/quickapp-ide-download-0000001101172926#section9347192715112)。

   华为快应用加载器可以在使用华为快应用IDE调试时进行安装，也可以下载后手动在调试手机中安装。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175836.86468768438275164945120465321090:50001231000000:2800:A353F6357529099A77BB509E82B353B9E61B403BFEA77E5D4A2D8A9058B2A86C.png)  
   一个手机中只能安装一种快应用加载器。
2. 使用华为快应用加载器调试快应用的方法参见"[华为快应用加载器使用指导](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-loader-user-guide-0000001115925960)"。
3. "快应用官方示例"、"快应用研发助手"打开入口集成到加载器中，详情见"[华为快应用加载器使用指导](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-loader-user-guide-0000001115925960)"。
