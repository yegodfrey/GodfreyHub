# 导航栏组件

## 简介

导航栏（nav_bar）组件通常用于头部导航，结构大致分为两部分，一部分是图标，另一部分是文本。导航栏一般具有如下特点：

* 可以配置标题内容
* 可以配置导航栏左右两侧图标和文本
* 可以配置导航栏的高度、背景色等样式
* 可以自定义触发导航栏点击事件

基本布局代码如下：

```screen
<import name="nav_bar" src="./Nav_bar/nav_bar.ux"></import>
<template>
  <div class="container">
    <text>本导航栏为自定义组件，并非原生导航栏。除非原生导航栏无法满足需求，否则不推荐使用自定义导航栏组件。</text>
    <text class="section">基本用法</text>
    <div class="example-body">
      <nav_bar height="50px" backgroundcolor="#ffffff" left-icon="{{leftIcon}}" title="标题" @clickleft="back" title-style="font-size: 40px; color:red"></nav_bar>
    </div>
  </div>
</template>
```

## 开发指引

### 自定义子组件

1. 定义布局样式。 导航栏组件布局包括三个部分：左侧图标+文本部分、中间标题部分、右侧图标+文本部分。

   * 左侧图标+文本部分、右侧图标+文本部分通过image+text+slot组件实现。
   * 中间标题部分由text+slot组件实现。

   ```screen
   <template>
     <div>
       <div class="navbar_content" style="height:{{height}};background-color:{{backgroundcolor}}">
         <div class="navbar_btns_left" onclick="clickLeft">
           <div if="leftIcon.length">
             <image style="height: 50px" src="{{leftIcon}}"></image>
           </div>
           <div if="leftText.length">
             <text style="{{leftTextStyle}}">{{ leftText }}</text>
           </div>
           <slot name="left"></slot>
         </div>
         <div class="navbar_container" onclick="clickTitle">
           <text class="text_context" style="{{titleStyle}}" 
               if="title.length">{{ title }}</text>
           <slot name="mid"></slot>
         </div>
         <div class="navbar_btns_right" onclick="clickRight">
           <div if="rightIcon.length">
             <image style="height: 50px" src="{{rightIcon}}"></image>
           </div>
           <div class="*" if="rightText.length && !rightIcon.length">
             <text style="{{rightTextStyle}}">{{ rightText }}</text>
           </div>
           <slot name="right"></slot>
         </div>
       </div>
     </div>
   </template>
   ```

2. 规划属性和支持的事件。 支持的属性：

   |属性|类型|默认值|描述|
   |:--------------|:-----|:--|:------|
   |title|String|-|标题文字。|
   |height|String|-|导航栏高度。|
   |backgroundcolor|String|-|导航栏背景色。|
   |leftText|String|-|左侧文本。|
   |rightText|String|-|右侧文本。|
   |leftIcon|String|-|左侧图标。|
   |rightIcon|String|-|右侧图标。|

   支持的事件：

   |事件名称|参数|描述|
   |:---------|:-|:---------------|
   |clickLeft|-|点击左侧图标+文本时触发的事件。|
   |clickRight|-|点击右侧图标+文本时触发的事件。|
   |clickTitle|-|点击中间标题时触发的事件。|

### 父子组件通信

1. 父组件给子组件传递数据。
   1. 子组件的props中定义参数。

      ```screen
      props: {
        height: {
          type: String,
          default: ""
        },
        backgroundcolor: {
          type: String,
          default: ""
        },
        title: {
          type: String,
          default: ""
        },
        leftText: {
          type: String,
          default: ""
        },
        rightText: {
          type: String,
          default: ""
        },
        leftIcon: {
          type: String,
          default: ""
        },
        rightIcon: {
          type: String,
          default: ""
        },
        leftTextStyle: {
          type: String,
          default: ''
        },
        titleStyle: {
          type: String,
          default: ''
        },
        rightTextStyle: {
          type: String,
          default: ''
        },
      },
      ```

   2. 父组件给子组件传值，如果是布尔值，需要在data中定义，而不能直接在组件中定义。

      ```screen
      data() {
        return {
          city: "BeiJing",
          leftIcon: "../Common/leftIcon.png",
          rightIcon: "../Common/rightIcon.png"
        }
      },
      ```

2. 子组件给父组件传递数据和方法。
   1. 父组件定义点击事件并绑定。

      ```screen
      <nav_bar right-icon="{{rightIcon}}" @clickleft="showCity" @clickright="scan" @clickTitle="showTitle" ></nav_bar>
      ```

      ```screen
      showCity() {
        prompt.showToast({
          message: '选择城市',
          duration: "100000",
          gravity: 'center'
        })
      },
      scan() {
        prompt.showToast({
          message: '扫码',
          duration: "100000",
          gravity: 'center'
        })
      },
      showTitle() {
        prompt.showToast({
          message: '标题',
          duration: "100000",
          gravity: 'center'
        })
      },
      ```

   2. 子组件通过this.$emit方法触发父组件的点击事件。

      ```screen
      clickLeft() {
        this.$emit("clickleft");
      },
      clickRight() {
        this.$emit("clickright");
      },
      clickTitle() {
        this.$emit("clicktitle");
      }
      ```
