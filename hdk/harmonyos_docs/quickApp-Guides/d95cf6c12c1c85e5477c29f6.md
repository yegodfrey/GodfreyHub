# 华为快应用适配深色和浅色模式

## 简介

大部分手机会有深色模式和浅色模式之分，浅色模式一般都是"白底黑字"，深色模式则是"黑底白字"。下图是华为手机深色模式和浅色模式的界面效果：

如何在快应用中实现不同主题模式的适配呢？目前有以下方案：

使用MediaQuery响应式布局能力，自动检测用户设备的系统主题模式，配置不同模式下的css样式。

## MediaQuery响应式布局

华为快应用响应式布局中[媒体特征（Media Feature）](https://developer.huawei.com/consumer/cn/doc/development/quickApp-References/quickapp-mediaquery-0000001170210011#section1366510476381)类型提供了prefers-color-scheme字段，可以检测用户的系统主题，支持的属性值有light和dark，分别对应手机的浅色主题和深色主题。开发者只需要在代码中配置两种模式下的css样式即可，快应用引擎会根据系统主题模式自动调用不同的css。具体实现代码如下：

```screen
<template>
    <!-- Only one root node is allowed in template. -->
    <div class="container">
        <text class="title">
            Hello {{title}}
        </text>
    </div>
</template>
<style>
    .container {
        flex-direction: column;
        justify-content: center;
        align-content: center;
        align-items: center;
    }
    .title {
        font-size: 100px;
    }
    /**浅色主题css */
    @media (prefers-color-scheme: light) {
        .container {
            flex-direction: column;
            justify-content: center;
            align-content: center;
            align-items: center;  
        }
        .title {
            font-size: 100px;
            color: #000000;
        }
    }
    /**深色主题css*/
    @media (prefers-color-scheme: dark) {
        .container {
            flex-direction: column;
            justify-content: center;
            align-content: center;
            align-items: center;
            background-color: #000000;
        }
        .title {
            font-size: 100px;
            color: #ffffff;
        }
    }
</style>
<script>
    module.exports = {
        data: {
            title: 'World',
            titleBar: ''
        },
        onInit: function () {
            this.titleBar = this.titleBarText;
            console.log("onInit titleBar= " + this.titleBar);
            this.$page.setTitleBar({ text: this.titleBar });
        },
    }
</script>
```

此方案的优点在于实现简单，开发代码量小，开发者只需要配置响应式布局中浅色和深色主题对应的css，无需手动去调用不同模式下的css。
