# Git 状态展示

如果所在的Web快应用工程目录（project.config.json 所在目录）存在 Git 仓库，编辑器可以展示目前的 Git 状态。 关于 Git 相关的概念不清楚的同学，可以使用搜索引擎查找相关的概念进行了解。 Huawei Studio Git 扩展本质上是将 git 的命令封装成了一些可以点击操作的功能，了解 Git 基本概念的话，这些交互是非常好理解和上手的。
