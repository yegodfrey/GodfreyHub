# 增强输入框组件

## 简介

增强输入框组件是原生input组件的增强 ，主要用于填写信息、搜索商品等场景。增强输入框具有如下特点：

* 可根据需要定制图标
* 可提供默认值
* 可实现查询、清空、禁用功能

增强输入框（easyinput）组件结构可按照布局分为两个部分。一部分是图标，另一部分是输入框。

```screen
<text >左右图标</text>
<div class="example-body">
    <easyinput preimgsrc = "{{searchimgsrc}}" deletesrc = "{{deleteimgsrc}}"  @handleclick="handleClick"  @clearclick="clearClick"></easyinput>
```

## 开发指引

### 自定义子组件

1. 定义布局样式。 增强输入框整体外观都是通用的，但是内部具体的样式有区别，在设计的时候，不能把内部样式固定，否则一旦数字输入框的UI有变化，会导致子组件也要修改，违背了对外开源的初衷。

   所以，在子组件easyinput.ux中，开放多种样式属性，方便开发者自定义样式。

   ```screen
   <template>
     <div class="container">
           <image  src="{{this.preimgsrc}}"  class="photo" onclick="handle()" ></image>       
           <input  disabled="{{this.disabled}}"   class="selectionInput"  placeholder="{{this.placeholderinput}}" maxlength="100"  
                   value="{{this.inputValue}}"  onchange="updateValue" onselectionchange="*"  >
           </input>   
           <image  src="{{this.sufimgsrc}}"  class="photo" onclick="handle()" ></image>     
           <image  src="{{this.deletesrc}}"  class="photo" onclick="resetValue()"></image>    
     </div>
   </template>
   ```

2. 规划属性和支持的事件。

   支持的属性：

   |**属性**|**类型**|**默认值**|**描述**|
   |:---------------|:------|:------|:--------------------------|
   |preimgsrc|String|-|左"搜索"图标路径。|
   |sufimgsrc|String|-|右"搜索"图标路径（左、右"搜索"图标只能存在一个）。|
   |deletesrc|String|-|"删除"图标路径。|
   |placeholderinput|String|请输入内容|提示输入内容。|
   |disabled|Boolean|false|是否禁用。|

   支持的事件：

   |**事件名称**|参数|描述|
   |:----------|:---------|:--------------|
   |handleclick|left|right|点击左、右"搜索"图标的事件。|
   |clearclick|{}|清空当前输入框内容的事件。|

### 父子组件通信

1. 父组件给子组件传递数据。
   1. 子组件通过在props定义参数，接收来自父组件的传值数据，如preimgsrc、sufimgsrc、disabled等。

      ```screen
      props: { 
          preimgsrc: {
              type: String,
              default: ''  
          },
          sufimgsrc: {
              type: String,
              default: ''  
          },
          deletesrc: {
              type: String,
              default: ''  
          },
          placeholderinput: {
              type: String,
              default: '请输入内容：'  
          },
          disabled: {
              type: Boolean,
              default: false
          },
      },
      ```

   2. 父组件给子组件传值，如果是布尔值，需要在data中定义，而不能直接在组件中定义。

      ```screen
      <easyinput disabled="{{this.disabled}}" placeholderinput="{{this.placeholderinput}}"></easyinput>
      ```

      ```screen
      data() {
          return {
              placeholderinput:'禁用',
              inputValue: '',
              sufimgsrc:'',
              preimgsrc:'',
              deleteimgsrc:'',
              disabled:'true'
          }
      },
      ```

2. 子组件给父组件传递数据和方法。
   1. 父组件中注册特定方法的监听，等待子组件通知触发。

      ```screen
      <easyinput preimgsrc = "{{searchimgsrc}}" deletesrc = "{{deleteimgsrc}}"  @handleclick="handleClick"  @clearclick="clearClick"></easyinput>
      ```

      ```screen
      handleClick(e) {
          console.log(JSON.stringify(e));
          prompt.showToast({
              message: "点击了"+ e.detail+"侧的图标",
              duration: 2000,
              gravity: 'center'
          })
      },
      clearClick(e){
          console.log(JSON.stringify(e));  
          this.inputValue = '' 
      }
      ```

   2. 子组件通过this.$emit方法携带事件及参数通知父组件。

      ```screen
      handle() {
          console.log("handleclick", this.sufimgsrc,this.preimgsrc);
          let direction;
          if (this.preimgsrc !== '') {
              direction ="left"
          }else if(this.sufimgsrc !== ''){
              direction ="right"
          }
          this.$emit('handleclick',direction)
      },        
      resetValue() {
          this.inputValue = ''
          if(this.disabled){
              this.placeholderinput = '请输入内容：' 
          }
          this.$emit('clearclick', {});
      },
      ```

## 示例代码

增强输入框easyinput.ux代码：

```screen
<template>
  <div class="container">
        <image  src="{{this.preimgsrc}}"  class="photo" onclick="handle()" ></image>       
        <input  disabled="{{this.disabled}}"   class="selectionInput"  placeholder="{{this.placeholderinput}}" maxlength="100"  
                value="{{this.inputValue}}"  onchange="updateValue" onselectionchange="*"  >
        </input>   
        <image  src="{{this.sufimgsrc}}"  class="photo" onclick="handle()" ></image>     
        <image  src="{{this.deletesrc}}"  class="photo" onclick="resetValue()"></image>    
  </div>
</template>
<script>
    module.exports = {
        props: { 
            preimgsrc: {
                type: String,
                default: ''  
            },
            sufimgsrc: {
                type: String,
                default: ''  
            },
            deletesrc: {
                type: String,
                default: ''  
            },
            placeholderinput: {
                type: String,
                default: '请输入内容：'  
            },
            disabled: {
                type: Boolean,
                default: false
            },
        },
        data: {
            inputValue: '',
            direction:'',
        },

        onInit() {
            this.$page.setTitleBar({ text: '输入框' })
        },

        updateValue(e) {
            this.inputValue = e.value;
            console.log(e.value)
        },

        handle() {
            console.log("handleclick", this.sufimgsrc,this.preimgsrc);
            let direction;
            if (this.preimgsrc !== '') {
                direction ="left"
            }else if(this.sufimgsrc !== ''){
                direction ="right"
            }
            this.$emit('handleclick',direction)
        },

        resetValue() {
            this.inputValue = ''
            if(this.disabled){
              this.placeholderinput = '请输入内容：' 
            }
            this.$emit('clearclick', {});
        },
    }
</script>
<style>
    .container{
        width: 100%; 
        border-top-width: 1px;
        border-bottom-width: 1px;   
        border-left-width: 1px;
        border-right-width: 1px;
        border-color: #999999;
    }

    .selectionInput{
        width: 100%;
        placeholder-color:rgb(161, 152, 152);
        caret-color:#7b68ee;
    }
</style>
```
