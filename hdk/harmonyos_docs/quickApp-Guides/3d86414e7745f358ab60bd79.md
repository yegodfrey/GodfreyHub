# 求助

当您开发快应用遇到问题时，可以通过如下途径寻求帮助。

* 查看[FAQ](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-faq-0000001129279483)、[案例](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-case-0000001082020374)，寻求类似问题的解决方案。
* 通过[智能客服](https://developer.huawei.com/consumer/cn/customerService/#/bot-dev-top/faq-top/faq-talk-top)查找问题解决方案。
* 登录快应用联盟论坛的["华为"板块](https://bbs.quickapp.cn/forum.php?mod=forumdisplay&fid=40)参与问题讨论。
* 通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=111)将您的问题反馈给我们。
