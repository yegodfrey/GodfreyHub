# 打包测试

## 准备工作

* [下载](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickgame-tool-download-0000001166035569)并安装最新的快游戏开发者工具。
* 准备HarmonyOS 6.0.0 Release及以上版本的手机设备，且要求手机设备登录已实名认证的华为账号。
* 提前将带有互动卡片入口的HarmonyOS 5.0及以上游戏安装在手机设备上。

## 操作步骤

快游戏开发者工具支持运行创新互动卡片，具体步骤如下：

1. 请使用登录手机设备相同的华为账号登录快游戏开发者工具。
2. 在工具界面左侧点击"打开项目"，选择工程项目后，点击"确定"。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135225.11582675106160977982253380061576:50001231000000:2800:082D3565AD899235174B89C60D1A6D864F9CD7406176AE988FF2EB82F03F49B1.png)

3. 快游戏开发者工具连接手机后，点击"开始运行"，工具将编译快游戏，并向手机推送快游戏rpk包。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260121135225.90077709344118778076816893493905:50001231000000:2800:9A31681E5FAA8CEF7044C7752037C7F2E1C0075C6553E4812C9658DAFFB86879.png)

4. 完成推送后，手机弹出文件管理界面，选择rpk包后点击"完成"。
