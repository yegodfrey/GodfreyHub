# 快应用Serverless开发

#### 简介

#### 主要功能

云函数

云函数提供FaaS（Function as a Service）能力，开发者无需自建服务器，只需聚焦业务逻辑、开发并上传函数代码，即可构建高可用、可伸缩的Serverless应用。使用云函数可以帮助开发者大幅简化应用开发与传统运维相关的事务，降低应用功能的实现门槛，快速构建业务能力。

云数据库

云数据库提供托管在云端的数据存储服务，采用基于对象模型的数据存储结构，支持单个或批量操作对象，如新增、修改、删除和查询等丰富的API接口。

云存储

云存储是专为开发者打造的可伸缩、免维护的云端存储服务，开发者可以用于存储图片、音频、视频或其他由用户生成的内容。

认证服务

大部分的应用都需要对用户的业务访问进行身份认证，以便为用户提供个性化体验。但是端到端完整构建一套用户认证系统会面临很多挑战。认证服务可以为您的应用快速构建安全可靠的用户认证系统，您只需在应用中访问认证服务的相关能力，而不需要关心云侧的设施和实现。

认证服务为云函数、云数据库、云存储等服务提供了全面且自适应的安全支撑，可令您对用户数据的保护事半功倍。  

#### 优势

* 无需搭建服务器即可快速构建应用。
* 无运维：开发者只需聚焦业务逻辑，无需关注运维中的复杂事务。
* 高可用：后端由华为提供强大技术支撑，保障服务高可用性。
* 低成本：按需使用，避免资源浪费，有效降低研发成本。  

#### 准入条件

在进行快应用Serverless开发前，请先完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 完成开发环境的搭建，包括在PC上安装快应用IDE、在测试手机安装快应用加载器，详细参见"[安装开发工具](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)"。
* 在AppGallery Connect（以下简称AGC）上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 如果需接入云函数，请先"[开通云函数服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/preparations-android-0000001663966414)"。
* 如果需接入认证服务，请先"[开通认证服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-auth-enable-service-0000001274125746)"。
* 如果需接入云存储服务，请先"[开通云存储服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-cloudstorage-enable-service-0000001275330014)"。
* 如果需接入云数据库服务，请先"[开通云数据库服务](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-Guides/agc-clouddb-createfirstclouddb-0000001569588629)"。

#### 管理云函数

创建云函数

1. 选择云函数主目录cloudfunctions，右击鼠标选择"新建nodejs云函数"。
2. 选中新建的云函数，右击鼠标选择"上传云函数"，点击"确定"。

   * CPU：函数容器所占有的CPU大小，CPU单位为千分。
   * 内存：函数容器所占有的内存大小，大小为M。

#### 管理版本

$latest版本

首次创建函数，版本默认为$latest。

开发者只能基于$latest版本修改并发布版本，发布的版本不支持修改，只支持查看和删除。发布后展示的版本号从1开始递增。

例如，首次创建后版本为$latest，将$latest版本发布为版本1。一段时间后需要为函数增加新的功能，可以在$latest版本中修改，并将修改后的版本发布为版本2。开发者可以调用版本1和版本2的函数实现不同的功能。

发布版本

将测试通过的云函数发布为正式版本，每个云函数可以发布多个版本。

1. 选中待发布的云函数目录，右击鼠标选择"发布新版本"。

   |以"@every ValueUnit"格式|Value为一个正整数，Unit可以为"s"、"m"、"h"，表示每隔ValueUnit的时间触发一次函数。例如，"@every 6m" 表示每隔6分钟触发一次函数。|

   * 调用方式：支持同步调用和异步调用。

#### 调用云函数

调用云函数分触发器调用和应用客户端调用两种方式。

* 定时触发调用：在函数中创建触发器，当触发器触发时自动调用函数，详细方法参见"[创建CRON触发器](#ZH-CN_TOPIC_0000001126545719__p29194718195)"。
* 应用客户端调用：在应用内使用云函数SDK的API调用云函数，具体步骤如下：

1. 在调用云函数的ux文件中导入agc组件。

   ```
   import agconnect from '@agconnect/api';
   import '@agconnect/function';
   import "@agconnect/instance";
   ```

2. 初始化AGC SDK。

   ```
   let agConnectConfig = require('./agconnect-services.json');
   agconnect.instance().configInstance(agConnectConfig);
   ```

3. 在函数或函数别名中创建一个HTTP类型的触发器，详细参见"[创建HTTP触发器](#ZH-CN_TOPIC_0000001126545719__p14333111214619)"。
4. 调用[wrap](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/agconnectfunction-web-0000001059810183)方法设置函数，在方法中传入调用云函数的别名对应的[HTTP触发器标识](#section765320393612)，返回得到可执行云函数的对象。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250806162412.00907872533005013451378295269011:50001231000000:2800:6AD5EC39D1F52041F95CD4B0A546ABB33B371BDCC1CC04286E7B70A1586D8891.png)  
   调用云函数时，强烈建议通过云函数别名进行调用。这样当云函数变动升级后，只需修改别名中指定的版本即可。

   let functionCallable = agconnect.function().wrap("functionname-functionalias");//functionname-functionalias为云函数别名对应的HTTP触发器标识
5. （可选）可修改全局网络连接超时时长，详见[config.network说明](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-manifest-0000001073698621#ZH-CN_TOPIC_0000001073698621__p37588589429)说明，但不支持通过设置timeout属性设置超时时长。
6. 调用[call](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functioncallable-web-0000001060808272)方法运行云函数。如果函数有入参，可以将参数转化为JSON对象或JSON字符串传入，如果没有参数则不传。

   let reqBody = {"data":"value"};

   let functionResult = await functionCallable.call(reqBody);
7. 如果您需要关注函数的返回值，可调用[getValue](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/functionresult-web-0000001060650068)方法获取。

   let returnValue = functionResult.getValue();

更多接口请参见"[云函数API](https://developer.huawei.com/consumer/cn/doc/AppGallery-connect-References/overview-web-0000001059879805)"。
