# 开通账号服务（可选）

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111452.69794837494202924572405026229868:50001231000000:2800:3349E160877AE6B986A9F1755A2810B3B31EE90E2A138FCE0FE320181E638C87.png)  
如果需要接入华为账号服务，在开发前请先开通服务并获取服务相关参数，否则请忽略以下内容。  

#### 打开账号服务开关

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的项目"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111452.94017309347092577384926965437071:50001231000000:2800:87D26E1434EB39FF98B133FC03BB2606A2E6599714685B247240956DA927E14D.png)
2. 点击待开通服务项目的卡片。
3. 选择"API管理"页签，打开 "华为账号"的开关。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111452.04723060002568770597384993319773:50001231000000:2800:5216160FFD48D7B4C9692530CACFD53C348AA04EC7AA8D13DD18246DC1ADB58D.png)

#### 配置账号服务信息

1. 登录 [华为开发者联盟](https://developer.huawei.com/consumer/cn) ，点击"管理中心"。
2. 在"应用服务"页面，选择"账号"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111452.30743635637574808302698351971216:50001231000000:2800:CE7610C7BF46739C5BBF51630BC2CFC8D36D941930A3C4F56B2D3B7577AEC100.png)

3. 在产品列表中找到需要配置服务的快应用，点击所在行的"修改"。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111452.95087434077314243051849254729467:50001231000000:2800:C562FF4B5C5E0AE974700AF234007231E179E29C9180F8019052C84B00EAC72C.png)

4. 配置账号服务相关信息。
   * SHA256证书指纹：[生成证书指纹](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-generate-fingerprint-0000001079484294#section167817236307) 获取的指纹信息。
   * 启用UnionId：同一个开发者账号下不同应用中，同一个用户的UnionId相同。如果有在多个应用间拉通用户信息的需求，可以使用UnionId来标识用户的唯一性。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111452.02568666088536754270946697020114:50001231000000:2800:E4483DDD41004457F25099AD334917D079F128AF66AFD73E63880B1C557F8452.png)
5. 配置完成点击"提交"。  

#### 查询账号服务信息

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"我的项目"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111452.97297745335052669690929964322448:50001231000000:2800:8489014764978A94FC6693D6B93357A31D40A4DC8F0523EF217A3513B38A0A55.png)
2. 点击待查询的项目卡片。
3. 选择需要查询的快应用。
4. 在"项目设置 \> 常规"页面的"应用"区域获取账号服务参数。
   * APP ID：华为开发者联盟为APP分配的唯一标识，请保存，后续开发过程中需要使用。
   * Client Secret：应用密钥，请保存，后续开发过程中需要使用。
