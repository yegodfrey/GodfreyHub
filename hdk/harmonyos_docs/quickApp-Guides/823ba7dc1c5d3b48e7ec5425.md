接入推送服务 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111532.96082319851179217396720986027480:50001231000000:2800:A7EF5A53B741FFAFB592A59DF2B57BF43E75BAA7ABBC0178E8AB8CDB864D87DC.png) 为了规范通知栏消息，提升用户体验，2023年5月19日起，快应用推送服务将全面升级。 服务升级期间，快应用推送能力整体下线，即快应用的推送/通知（即通知栏消息）均无法触达用户，请您暂停使用，给您造成的不便敬请谅解。 本次服务升级预计于2023年四季度完成，完成后我们将会邮件通知您。如您遇到任何问题，请发邮件至developer@huawei.com与我们联系，感谢您的支持。 简介 华为推送（PUSH）是为开发者提供的消息推送平台，建立了从云端到手机端的消息推送通道，让应用可以将最新信息及时通知到用户，从而构筑良好的用户关系，提升用户的感知和活跃度。 PUSH功能在EMUI8.0及以上版本的手机上支持。 准入条件 接入华为推送服务前，需要完成如下准备工作：
    * 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见“[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)”。
    * 在AppGallery Connect上完成快应用的创建，详细参见“[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)”。
    * 在AppGallery Connect上已[开通推送服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-push-kit-0000001079643916)。
    * 华为推送服务是华为扩展接口，而非厂商联盟规范，请[安装华为快应用IDE](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-installtool-0000001126543467)进行接入。
接入指引
    1. 调用 [qa.getPushProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/webview-api-hwpush-0000001126147535#section4719144914456) 接口判断当前设备是否支持华为PUSH服务。 调用接口返回 huawei 表示支持，否则表示不支持。后续功能开发和接口调用必须在设备支持PUSH服务的前提进行。
    2. 调用 [qa.subscribePush](https://developer.huawei.com/consumer/cn/doc/quickApp-References/webview-api-hwpush-0000001126147535#section799117271461) 接口获取regId。 regId也被称为token或push token，是用于发送PUSH消息的标识。其长度不定，格式有类似如下样例两种：
       * 0862767037246841300005665000CN01
       * ANDmbp0JwPTftSc4tY90C2aW6xTGyKtTIY4idTf5GekYFfOKYmKTeqYlyKYUS0CQbf2xmUdkKWaYU6AoO1Ju6bL5lQgU7pmzQD_6cdIEABhHTLPYhMcsoF64B0tNAE_eBg
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250507111532.83799408212783620775968683543852:50001231000000:2800:A721BF9CCE4CCBC29BC541A4E0463DC5CF865A27F84678F9A43D5B38520F6498.png) regId和快应用运行环境相关，在快应用加载器中获取的regId只能用于在加载器中运行的快应用推送消息，不能用于上架应用市场的快应用，因为上架后的快应用的运行环境是快应用中心。
    3. 将regId上报到快应用自己的业务服务器，用于后续服务器向快应用发送PUSH消息。
    4. 发送PUSH消息，具体操作请参见“发送PUSH消息”。
    5. 处理PUSH消息。
发送PUSH消息 开发者可以通过两种方式发送PUSH消息：
    * 在AppGallery Connect发送：适用选取部分目标用户发送，支持推送到现网的快应用和加载器上运行的快应用。
    * 通过服务端接口发送：适用面向大批量用户发送，支持推送到现网的快应用和加载器上运行的快应用。

       * 为了提升用户体验，减少对用户的打扰，同一款快应用每天只能向同一用户推送5条PUSH消息。
       * PUSH消息不得推送与快应用自身业务无关内容以及诱导性广告、低俗/诈骗/涉黄/涉暴/涉政等信息，违者将关停处罚，详细请参见“快应用PUSH消息违规处罚规定”。

请求参数说明 **参数** |  **取值类型** |  **可选/****必选** |  **描述**  
---|---|---|---  
validate_only |  boolean |  可选 |  控制当前是否为测试消息，测试消息只做格式合法性校验，不会推送给用户设备，取值如下：
    * true：测试消息
    * false：正式消息
默认值是false。  
message |  Object |  必选 |  推送消息结构体，message结构体中必须要有有效消息负载以及有效发送目标，具体字段请参考“message结构体说明”。  
message结构体说明 **参数** |  **取值类型** |  **可选/****必选** |  **描述**  
---|---|---|---  
data |  string |  必选 |  描述PUSH消息JSON结构体，包括PUSH消息的类型、内容、点击动作、报表统计和扩展信息，详细内容请参见“data样例”和“data结构体说明”。  
android |  object |  必选 |  Android消息推送控制参数，具体字段请参考“AndroidConfig结构体说明”。  
token |  array |  必选 |  推送消息目标用户的pushtoken，每个pushtoken都为快应用通过subscribe接口获取到的regId： ["pushtoken1","pushtoken2"]

        "pushbody": {
            "title": "PUSH消息的标题",
            "description": "PUSH消息详细内容",
            "page": "/",
            "params": {
                "key1": "test1",
                "key2": "test2"
            }
        }
    }

pushtype |  Integer |  data |  是 |

pushbody |  JSON Object |  data |  是 |  -

        "pushtype": 0, //0表示通知栏消息

                "key1": "test1",
                "key2": "test2"
            },
        }
    };
    var formatJsonString = JSON.stringify(mData);
    var messbody = {

        "message": {

            "android": {

快应用PUSH消息违规处罚规定 [h2]目的与范围 为保证快应用开发者合理利用快应用PUSH能力，保证推送内容健康合规，提高用户满意度，特制定本违规处罚规定。 [h2]内容违规定义与处罚方式 （1）违规级别定义 **违规级别** |  **内容违规定义**  
---|---  
一级 | 
    1. 涉黄、涉暴等违法信息或政治有害信息。
    2. 病毒链接等侵犯用户权益的内容。  
二级 | 
    1. 与快应用自身服务无关的下载链接、营销内容、诱导性信息。
    2. 反复发送高度相似文案过度打扰用户。  
（2）违规处罚规则 **违规级别** |  **违规次数** |  **处罚方式**  
---|---|---  
一级 |  1次及以上 |  永久关停违规快应用PUSH业务。  
二级 |  1次 |  关停违规快应用PUSH业务30天。  
2次 |  关停违规快应用PUSH业务90天。  
3次及以上 |  永久关停违规快应用PUSH业务。  
[h2]违规处罚执行

    // app.js
    App({ 
      onLaunch() {
        // 展示本地存储能力
        const logs = qa.getStorageSync('logs') || []
        logs.unshift(Date.now())
        qa.setStorageSync('logs', logs)
      },
      globalData: {
         pushtoken: ''
      },
      onShow() {
          console.info('Application onCreate');
          setTimeout(() => {
              this.checkPushIsSupported(); 
          }, 1000);
      },
      checkPushIsSupported() {
          let provider = qa.getPushProvider()
          console.log("checkPush provider= " + provider);
          if (provider === 'huawei') {
              this.pushsubscribe();
          }
      },
      pushsubscribe() {
        console.log("pushsubscribe start");
        var that = this;
        qa.subscribePush({
            success: function (data) {
                console.log("push.subscribe succeeded, result data=" + JSON.stringify(data));
                that.globalData.pushtoken = data.regId;
                console.log("app oncreate that.dataApp.pushtoken " +   that.globalData.pushtoken );
                that.checkToken();
            },
            fail: function (data, code) {
                console.log("push.subscribe failed, result data=" + JSON.stringify(data) + ", code=" + code);
            },
            complete: function () {
                console.log("push.subscribe completed");
            }
        })
    },
    checkToken() {
        var subscribeToken = this.globalData.pushtoken;
        console.log("subscribeToken 1= " + subscribeToken);
        var that =this;
        qa.getStorage({key:'token',
            success: function (data) {
                console.log("checkToken storage data= " + data);
                if (subscribeToken !== data) {
                    //upload it to your own service server
                    that.uploadToken(subscribeToken);
                    that.saveToken(subscribeToken);
                }else{
                     console.log("checkToken regid is  the same as local storage");
                }
            },

                console.log("checkToken handling fail, code = " + code);
