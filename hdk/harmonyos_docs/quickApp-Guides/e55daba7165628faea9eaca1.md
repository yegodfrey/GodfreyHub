# 功能简介

快应用和H5 Web应用并不相同，快应用拥有独立的开发标准，依赖快应用中心进行运行。但是快应用支持通过 [web](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-component-web-0000001074615196) 组件加载H5网页，从而可以快速将H5应用打包成快应用。上架应用市场后，用户可以直接打开应用，所有体验和原H5应用相同。

* 搜索应用 在华为应用市场首页输入关键字，点击"搜索"，获取符合条件的应用。

* 打开应用 点击应用查看应用详情后打开应用或者点击"打开"按钮直接打开应用。

将H5应用转换为快应用有两种方式：

* 使用华为快应用IDE线下转换（推荐） 开发者将H5应用导入IDE进行转换，转换完成打包生成快应用提交审核。详细指导参见"[IDE线下转换](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-h5-to-quickapp-offline-0000001079648146)"。

* 在AppGallery Connect在线转换 开发者访问AppGallery Connect，进行相关配置后，由网站自动转换生成快应用后提交审核。详细指导参见"[AppGallery Connect在线转换](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-h5-to-quickapp-online-0000001079840068)"。
