# 实时语音识别

#### 简介

实时语音识别能力是由华为机器学习服务（ML Kit）提供的一项能力，支持将实时输入的语音转换为文本，可实时识别60秒内的语音。该能力使用行业领先的深度学习技术 ，识别准确率可达95%以上。

* 支持实时出字。
* 支持静音检测，语音中未说话部分不发送语音包。
* 支持数字格式的智能转换，例如语音输入"二零二零年"时，能够智能识别为"2020年"。

目前支持中文普通话（包括中英文混说）、英语、法语、德语、西班牙语、意大利语多种语言的识别。

在使用实时语音识别能力时，您需要参考：[华为机器学习服务隐私申明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/android-sdk-ys-0000001222765290)和[个人数据处理说明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/android-sdk-hg-0000001720566121)，处理用户数据。  

#### 准入条件

接入实时语音识别前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"[创建快应用](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824)"。
* 在AppGallery Connect上已[开通机器学习服务](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-enable-ml-kit-0000001126700645)。

* 目前实时语音识别能力仅支持华为手机使用。
* 实时语音识别能力通过访问云测接口完成识别，所以调试和使用该能力时，需保证设备可正常访问互联网。  

#### 开始语音识别

调用[mlasr.start](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ml-asr-0000001074914680#section690064651214)接口，通过设置callback和fail回调获取返回结果。语音识别过程中，callback会实时监听回调，通过返回的eventName判断事件类型，从而进行相关业务操作。  

#### 停止语言识别

停止说话时，语音识别会自动停止。也可以在说话过程中调用[mlasr.stop](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickapp-api-ml-asr-0000001074914680#section10339162913233)主动停止语音识别。

<script>
    import prompt from '@system.prompt'
    import mlasr from '@service.ml.asr';
    module.exports = {
        data: {
            title: 'Asr Test',
            appId: '103913469',
            apiKey: 'CgB6e3x9805WIU1KE8lnMBc+ka/A5sJ5DBKsSzGGkYuV7E/GxY18tAdAM5Zc5hg48CKW4kzmfarv75bRdiDe4RhK',
            language: 'zh-CN',
            feature: 11,
            onRecognizingResults: '',
            onResults: '',
            onStartListening: '',
            onStartingOfSpeech: '',
            onVoiceDataReceived: '',
            onState: '',
            onError: '',
            time0: '',
            time1: '',
            time2: '',
            time3: '',
            time4: ''
        },
        update_appId(e) {
            let value = e.newValue ? e.newValue : e.text;
            this.appId = value;
            // console.log(this.appId);
        },
        update_apiKey(e) {
            let value = e.newValue ? e.newValue : e.text;
            this.apiKey = value;
            // console.log(this.apiKey);
        },
        update_language(e) {
            let value = e.newValue ? e.newValue : e.text;
            this.language = value;
            // console.log(this.language);
        },
        update_feature(e) {
            let value = e.newValue ? e.newValue : e.text;
            this.feature = value;
            // console.log(this.feature);
        },
        onInit() {
            this.resetOutInfo();
        },
        asrStart() {
            this.resetOutInfo();
            prompt.showToast({ message: 'start' });
            this.time0 = new Date().getTime();
            mlasr.start({ 
                appId: this.appId, 
                apiKey: this.apiKey, 
                language: this.language, 
                feature: this.feature, 
                callback: (eventName, ...data) => { 
                    console.log(eventName, ...data);
                    prompt.showToast({ message: eventName });
                    switch (eventName) {
                        case 'onStartListening': 
                            this.time1 = new Date().getTime();
                            this.onStartListening = "success";
                            break;
                        case 'onStartingOfSpeech':
                            this.time2 = new Date().getTime();
                            this.onStartingOfSpeech = "success";
                            break;
                        case 'onVoiceDataReceived':
                            let voice = data[0], energy = data[1];
                            this.onVoiceDataReceived = '【' + voice + '】' + '；【' + energy + '】';
                            break;
                        case 'onRecognizingResults':
                            if (!this.time3) { this.time3 = new Date().getTime(); }
                            let partialResults = data[0];
                            this.onRecognizingResults = partialResults;
                            break;
                        case 'onResults':
                            this.time4 = new Date().getTime();
                            let results = data[0];
                            this.onResults = results;
                            break;
                        case 'onState':
                            let state = data[0];
                            this.onState = this.onState + '→' + state;
                            break;
                    }
                },
                fail: (err, errCode) => { 
                    prompt.showToast({ message: 'fail:' + err });
                    this.onError = err;
                    console.log("startRecognizing error:", err);
                },
            });
        },
        asrStop() {
            prompt.showToast({ message: 'stop' });
            mlasr.stop(); 
            this.resetOutInfo();
            },
        resetOutInfo() {
            this.onRecognizingResults = 'The result of identification process is output here';
            this.onResults = 'The final result is output here';
            this.onStartListening = 'Here the output recorder starts to receive sound';
            this.onStartingOfSpeech = 'The output here detects that the user has started to speak';
            this.onVoiceDataReceived = 'The users original PCM audio stream and audio energy are output here';
            this.onState = 'Application status';
            this.onError = 'Failure, output error message here';
            this.time0 = '';
            this.time1 = '';
            this.time2 = '';
            this.time3 = '';
            this.time4 = '';
        }
    }
</script>
