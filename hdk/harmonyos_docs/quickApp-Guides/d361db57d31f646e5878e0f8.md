# 接入账号服务

#### 简介

华为账号是用户访问华为云业务的凭证，拥有华为账号的用户，可以使用华为云业务，如华为云服务、华为游戏中心、华为应用市场等。

华为账号的开放基于OAuth2.0协议标准，在获得用户授权后，应用可以获取用户在华为账号系统的基本信息，如OpenID、AccessToken、用户昵称、头像等。

OpenID：应用使用华为账号登录后，会获得当前登录的华为账号对这个应用开放的唯一标识，这个唯一标识就是OpenID。不同的应用使用相同的华为账号登录获得的OpenID是不同且唯一的。即同一个华为账号，不同应用，OpenID不同。

UnionID与OpenId的区别：使用同一个华为账号登录不同的应用，返回的OpenID值不同，但是UnionID是相同的。所以如果开发者需要在多个应用之间标识用户的唯一性，可以使用UnionID。

接入华为账号后即可获取OpenID，但是获取UnionID需要在申请账号服务时，勾选"启用UnionId"。  

#### 准入条件

接入华为账号服务前，需要完成如下准备工作：

* 在华为开发者联盟上注册成为开发者，并完成实名认证，详细参见"[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)"。
* 在AppGallery Connect上完成快应用的创建，详细参见"创建快应用"。
* 在AppGallery Connect上已开通账号服务。
* 华为账号服务是华为扩展接口，而非厂商联盟规范，请安装华为快应用IDE进行接入。
* 完成申请账号MCP权限。  

#### 接入指引

#### 申请账号MCP权限

请通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=84)提交申请信息：

* 是否包含终端用户数据：选择"不存在"。
* 概述：填写"申请华为账号服务MCP权限"。
* 问题描述：提供父应用的包名和快应用的APP ID。
  * 父应用的包名：固定填写"com.huawei.fastapp.dev和com.huawei.fastapp"
  * 快应用APP ID：按实际情况反馈。

提交工单后，华为方将进行处理，请关注工单的处理进度。  

#### 简化模式

1. 在快应用中调用 [ft.hwGetProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section14951026165015)接口判断当前设备是否支持华为账号服务。

   调用接口返回 huawei 表示支持，否则表示不支持。后续功能开发和接口调用必须在设备支持账号服务的前提进行。
2. 在快应用中调用 [ft.hwAuthorize](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section68221371135)接口直接获取accessToken。
   * type：设置为token。
   * scope：设置为scope.baseProfile。
3. 通过 [ft.hwGetProfile](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section17781229201115)获取用户基本信息，主要包括OpenID 和用户昵称、头像等。  

#### 授权码模式

1. 在快应用中调用 [ft.hwGetProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section14951026165015)接口判断当前设备是否支持华为账号服务。

   调用接口返回 huawei 表示支持，否则表示不支持。后续功能开发和接口调用必须在设备支持账号服务的前提进行。
2. 判断是否需要重新获取Authorization Code。
   1. 未获取过Authorization Code，则执行 [步骤3](#ZH-CN_TOPIC_0000002414052162__li14893130321)。
   2. 获取过Authorization Code，由于Authorization Code存在有效期，所以使用Authorization Code前，调用 [ft.hwCheckUserSession](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section204734715218)校验有效性，有效则执行 [步骤4](#ZH-CN_TOPIC_0000002414052162__li143148110195)，无效则执行 [步骤3](#ZH-CN_TOPIC_0000002414052162__li14893130321)。
3. 在快应用中调用 [ft.hwAuthorize](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section68221371135)接口直接获取accessToken。
   * type：设置为code。
   * scope：如果获取用户基本信息，设置为"scope.baseProfile"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830103611.11403914349444065742391956078714:50001231000000:2800:D06BF33C3E95C9C7AE90F902E7D7641D40650C7528A6D74EB49BFE230BFE19CF.png)  
   每一个Authorization Code的有效期为5分钟，并且只能使用一次，再次使用将无效。
4. 快应用客户端将获取的Code存储到开发者的服务端，然后在服务端调用Code获取Access Token接口去获取Access Token，最后服务端将获取的Access Token返回给快应用客户端。

   获取Access Token方式：应用在其服务端发送请求（必须使用POST方式）到华为OAuth2.0授权服务的"https://oauth-login.cloud.huawei.com/oauth2/v3/token"地址上，并在请求的body体中带上以下5个必选参数：  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830103611.55328426871610445696548298218842:50001231000000:2800:B77BD61C107A88034FA5E0E32853C1DE98AB3EA006014916B820936889A23DDB.png)  
   传入参数值需要先进行URLEncode编码处理。
   * grant_type：必选参数，此值固定为"authorization_code"。
   * code：必选参数，获取的Authorization Code。
   * client_id：必须参数，在华为开发者联盟创建应用后获取的APP ID。
   * client_secret：必选参数，在华为开发者联盟创建应用后获取的APP SECRET。
   * redirect_uri：必选参数，此值固定为"hms://redirect_url"。

     ```
     POST /oauth2/v3/token HTTP/1.1
     Host: login.cloud.huawei.com
     Content-Type: application/x-www-form-urlencoded
     grant_type=authorization_code&code=Etersdfasgh74ddga%3d&client_id=12345&client_secret=0rDdfgyhytRtznPQSzr5pVw2&redirect_uri=hms%3A%2F%2Fredirect_url
     ```

     若参数无误，服务器将返回一段JSON文本，主要包含以下参数：
   * access_token：需要获取的Access Token（如果包含\\，必须去除所有的\\）。
   * expires_in：Access Token的有效期，以秒为单位。
   * refresh_token：用于刷新Access Token的Refresh Token，所有应用都会返回该参数。
   * scope：Access Token最终的访问范围，即用户实际授予的权限列表。
   * token_type：此值固定为"Bearer"。 示例代码如下：

     ```
     HTTP/1.1 200 OK
     Content-Type: application/json
     Cache-Control: no-store
     {
         "access_token": "CgB6e3x9vWbH14lMF16ofo80roi4YDHytsOl17fgjoI/67eOQgre7UfkniaWMPuK3j0Uvx369OhtdPR57HHE28dplowhhweNYg6p2V+9SWYv",
         "expires_in": 3600,
         "refresh_token": "CgB6e3x9wUMdDbx9a8Q7p6ZqaqmaN5ouXqn3mb1Txa5twbmi7NBS4hwiXYNaYeJ5DktHCrxNVx7kiRsJ51sOhDtywbVowbjEjaskmPc39FS2",
         "scope": "openid profile",
         "token_type": "Bearer"
     }
     ```

     若请求错误，服务器将返回一段JSON文本，包含以下参数：
   * error：错误码。
   * error_description：错误描述信息。 示例代码如下：

     ```
     HTTP/1.1 400 Bad Request
     Content-Type: application/json
     Cache-Control: no-store
     {
       "error": "1102",
       "error_description": "A required parameter is missing in the request."
     }
     ```

     Access Token有效期默认为3600秒，当Access Token过期后，需要使用Refresh Token去获取新的AccessToken。Refresh Token获取AccessToken请参见 [步骤5](#ZH-CN_TOPIC_0000002414052162__li9745223182512)。
5. 若[步骤4](#ZH-CN_TOPIC_0000002414052162__li143148110195)获取的Access Token过期失效，则可以调用服务端接口通过Refresh Token重新获取Access Token，然后服务端再将重新获取的Access Token返回给快应用客户端。

   RefreshToken的有效期为半年。如果Refresh Token失效，则执行[步骤3](#ZH-CN_TOPIC_0000002414052162__li14893130321)重新进行授权登录流程。

   使用Refresh Token刷新获得新的Access Token，需要应用在其服务端发送请求（使用POST方式）到华为OAuth2.0授权服务的"https://oauth-login.cloud.huawei.com/oauth2/v3/token"地址上，并带上以下参数：
   * grant_type：必选参数，固定为"refresh_token"。
   * refresh_token：必选参数，用于刷新Access Token用的Refresh Token。
   * client_id：必选参数，在华为开发者联盟创建应用后获取的APP ID。
   * client_secret：必选参数，在华为开发者联盟创建应用后获取的APP SECRET。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830103611.71328581779948329343407629905954:50001231000000:2800:32211C6F254A70D6FB04755B3F23C3679AFBF594C078E6DF0EC8490E2E90F8EE.png)  
   传入参数值需要先进行URLEncode编码处理。

   示例代码如下：

   ```
   POST /oauth2/v3/token HTTP/1.1
   Host: login.cloud.huawei.com
   Content-Type: application/x-www-form-urlencoded
   grant_type=refresh_token&client_id=12345&client_secret=bKaZ0VE3EYrXaXCdCe3d2k9few&refresh_token=2O9BSX675FGAJYK92KKGG
   ```

   若参数无误，服务器将返回一段JSON文本，主要包含以下参数：
   * access_token：要获取的Access Token（如果包含\\，必须去除所有的\\）。
   * expires_in：Access Token的有效期，以秒为单位。
   * refresh_token：用于刷新Access Token的Refresh Token，并不是所有应用都会返回该参数（有效期为6个月）。
   * scope：用户实际授予的权限列表。
   * token_type：此值固定为"Bearer"。 示例代码如下：

     ```
     HTTP/1.1 200 OK
     Content-Type: application/json
     Cache-Control: no-store
     {
         "access_token": "CgB6e3x996fDubcAuHR09aL9AIpjHwogVLyQZmjjW+Qk77yf0sbwbowovPmusqd51u3ythe99sPIruol+L7V4pKK9T+3cqMJutpGt2PLwpnO",
         "expires_in": 3600,
         "refresh_token": "CgB6e3x9wUMdDbx9a8Q7p6ZqaqmaN5ouXqn3mb1Txa5twbmi7NBS4hwiXYNaYeJ5DktHCrxNVx7kiRsJ51sOhDtywbVowbjEjaskmPc39FS2",
         "scope": "openid profile",
         "token_type": "Bearer"
     }
     ```

     若请求错误，服务器将返回一段JSON文本，包含以下参数：
   * error：错误码。
   * error_description：错误描述信息。

     ```
     HTTP/1.1 400 Bad Request
     Content-Type: application/json
     Cache-Control: no-store 
     {
     "error": "1102",
     "error_description": "A required parameter is missing in the request."
     }
     ```

6. 通过Access Token调用 [ft.hwGetProfile](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section17781229201115) 接口获取华为账号用户信息。包括OpenId 和用户昵称、头像。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830103612.89029800021026941277738254478983:50001231000000:2800:B66C820968A9CA5D7FA6996C4CE3F9D85FFF2FAC3C99149CD38ED30BB66EA51C.png)  
通过此接口获取的手机号码在端侧使用的场景中存在被破解的可能，服务端不可直接信任该手机号用于鉴权、获取用户信息等场景，只能用于自动填入手机号后发送验证码等场景。建议通过在服务端调用华为服务器的[获取用户信息](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/get-user-info-0000001060261938)接口获取用户手机号。  

#### 调试账号服务

华为快应用IDE的菜单选择"构建 \> 构建快应用"进行调试。如果调试过程中出现异常，请参考如下操作进行定位。

1. 检查是否已在"华为开发者联盟"申请华为账号服务。
2. 调用[ft.hwGetProvider](https://developer.huawei.com/consumer/cn/doc/quickApp-References/quickweb-api-account-0000002447593333#section14951026165015)，请确保获取返回值为huawei后，再调用其他接口。
3. 参考如下常见错误码处理建议修改问题。  

   |错误码|描述|处理建议|
   |:---|:--------------------------------------|:----------------------------------------------------------------------------------------------------------------|
   |200|通用错误，一般是网关请求网络异常导致，具体错误描述可以在message中查看。|出现403网络异常错误码时，建议尝试切换网络，或者检查是否有传入scope。|
   |201|用户拒绝授权。|-|
   |202|接口传入参数错误。|请对传入参数进行检查。|
   |1002|签名校验失败。|* 检查在AppGallery Connect上配置的证书指纹是否与华为快应用IDE生成的签名信息一致。 * 检查调试的rpk包是否为正式构建的版本，使用的签名是否与在AppGallery Connect上配置的证书指纹一致。|
   |2009|请求华为账号服务器失败。|联系快应用技术支持进行权限配置。|
   |其他|请参考华为账号"[通用错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/account-apk-cn-common-error-codes-0000001050048616)"中的错误码进行处理。||
