# 核准（备案）准备

#### 注册账号与实名认证

若在[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)中核准（备案）过网站、APP、快应用，您无需注册新的华为云账号，请继续使用以前的华为云账号核准（备案）快应用。

若在[华为云核准（备案）中心](https://beian.huaweicloud.com/?utm_source=HUAWEI%2BDeveloper&utm_adplace=AdPlace099034)中进行首次核准（备案），或同时核准（备案）多个主体信息，或转移主体及主体下的互联网信息，您需要注册新的华为云账号并完成实名认证。步骤如下：

1. 注册账号。个人或企业注册华为云账号的操作指导请参见[注册华为云账号并开通华为云服务](https://support.huaweicloud.com/usermanual-account/account_id_001.html)。![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175837.08696911073334654692890818967619:50001231000000:2800:7C60BFFC46FA904D2168A6ACB242999877A0A8F8B315656E66020D89CEEF809E.png)
2. 实名认证。个人或企业实名认证华为云账号的操作指导请参见[实名认证](https://support.huaweicloud.com/usermanual-account/account_auth_00001.html)。  

#### 获取APP ID

APP ID是快应用的唯一标识，在AGC控制台创建快应用后生成。APP ID将在填写快应用信息中使用，您需提前记录下APP ID。获取快应用APP ID的操作指导请参见[获取APP ID](https://developer.huawei.com/consumer/cn/doc/quickApp-Guides/quickapp-create-quickapp-0000001079835824#section975713401464)。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260211175837.24216078669244612994013648568611:50001231000000:2800:3E2C382895E15502EDA57543975CC438831C86B2A9440245293C61F9C18E9C58.png)

#### 办理前置审批文件

若快应用从事新闻、出版、药品和医疗器械、网约车等须经有关主管部门审核同意的互联网信息服务，在履行核准（备案）手续时，应提供业务对应前置审批文件。

通用前置审批类目参考如下：  

|前置审批类目|对应材料|办理部门（参考）|
|:-------|:----------------|:------------------|
|新闻|《互联网新闻服务许可证》|省级及以上互联网信息办公室|
|出版（非游戏）|《网络出版服务许可证》|国家新闻出版署、省级新闻出版部门|
|教育（校外培训）|教育部门允许开展校外培训的审批文件|所在地教育行政管理部门|
|药品和医疗器械|《互联网药品信息服务资格证书》|省级食品药品监督管理局|
|文化|《网络文化经营许可证》|省级文化和旅游厅|
|广播电影电视节目|《信息网络传播视听节目许可证》|省级省委宣传部、新闻出版广电局|
|网络预约车|《网络预约出租汽车经营许可证》|所在地交通管理委员会|
|互联网金融类|金融监管部门审批许可文件|所在地金融监督管理局、人民银行、证监会|
|宗教类|《互联网宗教信息服务许可证》|省级以上人民政府宗教事务部门|
