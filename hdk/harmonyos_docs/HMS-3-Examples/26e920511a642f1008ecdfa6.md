# 1\. 项目介绍

在这个Demo中，您将使用已经创建好的Demo工程实现对华为推送服务开放能力的API调用，通过Demo你可以体验到：

  1. 申请AAID，删除AAID；

  2. 申请Token，删除Token；

  3. 主题订阅与退订；

  4. 设置是否显示通知栏消息；

  5. 接收Push Kit服务端推送的通知消息或者透传消息；

  6. 点击通知消息打开App首页与App自定义页面；




有关更多信息，请参见[开发指南](https://developer.huawei.com/consumer/cn/doc/development/HMS-3-Guides/push-basic-overview "开发指南")。
