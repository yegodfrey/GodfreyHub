# 申请发布证书  
  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110810.77227221743395100281767079161260:50530920060115:2800:C5CFAD35BCAFD59E430790AD5A460EA0AE0CE0C12466C0A576C621D16895C124.png?needInitFileName=true?needInitFileName=true)

您最多可申请1个发布证书，2个调试证书。

     1. 登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)，单击“通用管理”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110810.28835143834891073536288413267502:50530920060115:2800:47D402612A41FEAD5F92393FFDA2EE8620EF104FED313F3FFA130EF424FD12C8.png?needInitFileName=true?needInitFileName=true)

     2. 在左侧导航栏单击“证书管理”，进入“证书管理”页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.83492628883526021552568456303348:50530920060115:2800:F17BBC2A949FBBDBB31D70C3F0EEA417EEA3468677036C02B3FC859B26D5007B.png?needInitFileName=true?needInitFileName=true)

     3. 单击右上角“新增证书”，弹出“新增证书”窗口。在新增证书的窗口中填写要申请的证书信息，单击“确定”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.13660643975544103239043597699753:50530920060115:2800:D7CE9CD6F47BE37B3C63A828146E051DAEA95BDA2E1D73A3116152BD8873562E.png?needInitFileName=true?needInitFileName=true)

参数 | 说明  
---|---  
证书名称 | 最多100个字符。  
证书类型 | 选择“发布证书”。  
证书有效期 | 根据需要选择有效期，单位：年。  
上传证书请求文件（CSR） | 上传已生成的证书请求文件，具体请参见[通过IDE生成证书请求文件（CSR）](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/publish_app-0000001053223745#section9752152162813)。  
  
     4. 证书申请成功后，“证书管理”页面展示“证书名称”、“证书类型”、“证书状态”、“失效日期”和“操作”列信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.02032226882828727313278062157076:50530920060115:2800:2D2CF2C74C64B3ADD4875AC86809DBF83B60828FD3BFE42B969CF60C8FD96DB1.png?needInitFileName=true?needInitFileName=true)

        * 在“操作”列单击“下载”，可下载证书。
        * 在“操作”列单击“删除”，在弹出的“提示”窗口中单击“确认”，可废除证书。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.26635007118984109193868382913835:50530920060115:2800:792CC362E404F14EA8A3DBA8E4106FF73ADD46BAF7F4B4B642D4700D0ABAFCF3.png?needInitFileName=true?needInitFileName=true)

如证书已过期，“失效日期”列展示“已于YYYY-MM-DD过期”。您可以下载或废除过期证书。
