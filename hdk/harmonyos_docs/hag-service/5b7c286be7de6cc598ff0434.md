# 数据最小化原则

服务收集和使用个人信息的行为应保证合法合规，仅可请求访问与服务核心功能相关的数据，仅可收集和使用完成相关任务所需的数据，不得超出服务所必需或无合理应用场景收集和使用个人信息。即使数据在收集当时或收集后即刻被匿名化处理，也应确保合法合规，获取必要的用户同意。
