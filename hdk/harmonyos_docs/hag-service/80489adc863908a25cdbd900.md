# 添加调试设备

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110809.88318213486454445128818366150493:50530920060115:2800:4733C988A19C0FF53DC0A9A732F268C3C4B08E7E4BBAF2659057E865BE91204E.png?needInitFileName=true?needInitFileName=true)

最多可添加100个调试设备。

添加调试设备用于生成调试Profile，使用包含了指定调试设备的Profile打包出来的调测包，只能在指定的设备上安装并运行。

     1. 登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)，单击“通用管理”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110810.21884975018844265933138521027741:50530920060115:2800:493D7555AACEB66041FBB9226C2B0F1B53E1EFDED7BF7CE67806B4333AD1DC77.png?needInitFileName=true?needInitFileName=true)

     2. 在左侧导航栏单击“设备管理”，进入“设备管理”页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110810.00897692416001763631661705936912:50530920060115:2800:447CF11F08345960C62E30BCE97C4946339F739FAE7729E4DD02D0F84574869B.png?needInitFileName=true?needInitFileName=true)

     3. 单击“添加设备”按钮，添加调试设备。在新增设备的窗口填写设备信息，单击“提交”完成设备添加。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110810.98620045219514249085005850042502:50530920060115:2800:DB203F4F46F70C2E6459A830C95166C110BA1D1545BE36D0C5ABF24BEAAB7BD2.png?needInitFileName=true?needInitFileName=true)

参数 | 说明  
---|---  
名称 | 输入设备名称。  
类型 | 选择设备类型。可选择手机、大屏（电视）、手表、车机。  
UDID | 输入设备的UDID，可以通过HarmonyOS调测助手获取。 设备唯一标识符，是由字母和数字组成的64位字符串。您可在对应的调试设备上获取其UDID，调试设备要求运行HarmonyOS系统。
        * 手机的UDID获取方法如下：
打开“设置 > 关于手机”，多次点击版本号，打开开发者模式。 打开“设置 > 系统和更新”，在最下方找到“开发人员选项”，打开“USB调试”开关。 使用PC连接手机后，打开命令行工具，在显示“hdc shell”后，输入bm get --udid命令，获取设备的UDID。
        * 智慧屏：
当前不支持获取智慧屏的UDID。
        * 智能手表的UDID获取方法如下：
打开智能手表的“设置 > 关于手表”，多次点击版本号，打开开发者模式。 打开“设置”，在最下方找到“开发人员选项”，打开“HDC调试”开关。 使用PC连接智能手表后，打开命令行工具，在显示“hdc shell”后，输入bm get --udid命令，获取设备的UDID。
        * 车机：
打开“设置 > 关于车机”，多次点击版本号，打开开发者模式。 打开“设置 > 系统和更新”，在最下方找到“开发人员选项”，打开“USB调试”开关。 使用PC连接车机后，打开命令行工具，在显示“hdc shell”后，输入bm get --udid命令，获取设备的UDID。  
  
     4. 设备添加成功后，展示在设备管理页面。
