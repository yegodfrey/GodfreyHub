# 账户登录、访问权限

     1. 如果服务不包含基于帐户的重要功能，应允许用户在不登录的情况下使用，除非个人信息与服务的核心功能直接相关或是法律要求。
     2. 如果核心服务功能与特定的社交网络不相关，开发方必须提供无需登录或其他类似机制的访问权限。
     3. 服务必须尊重用户的权限设置，不得操纵、欺骗或强迫用户同意不必要的数据访问。若有可能，请为不同意访问权限的用户提供在无需授予权限情况下、也可使用此功能的替代方案。
     4. 必须征得用户明确同意后，才能跟踪用户相关活动。如果服务在未经用户同意或未能符合数据隐私保护法律的情况下共享用户个人信息，原子化服务平台有权拒绝上架。
     5. 服务不得试图暗中基于收集的数据构建用户资料，也不得以不可识别的方式收集的数据来识别匿名用户的身份或重建用户资料。
     6. 服务不得仅出于广告投放或数据分析的目的而请求位置权限；服务若使用个人信息用于个性化广告和精准营销，需提供独立的关闭选项。
     7. 服务须使用加密技术，以安全的方式处理用户的所有个人信息。
