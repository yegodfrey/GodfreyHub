# 概览

HarmonyOS正在联动世界、构筑全场景智能生活体验，为原子化服务所有者、开发者和运营者(以下统称“原子化服务商”）提供崭新机遇。以“持续为用户提供简洁、流畅、连续、安全可靠的全场景交互体验”为宗旨，特制定《原子化服务管理及下架规范》（下称“本规范”），进一步警示和规范原子化服务（下称“服务”）上架后的操作及运营行为，不断推动HarmonyOS生态体系高效可持续发展。

《原子化服务管理及下架规范》将基于服务违规的严重程度、影响程度等因素，对服务的不同违规现象进行**警告降级** 以及相应级别的**下架 &扣分处理**，**当同一服务的累计扣分达到10分、该服务将被永久下架** 。

**注释：**

     1. 任何原子化服务商的操作及运营行为，必须严格遵守本规范的规定。如果服务未遵守本规范的任何条款或条件、未在平台规定的有效期内完成自身整改工作，平台有权采取下架服务、终止合作等措施。若服务的违规行为对HarmonyOS生态体系造成损失，平台有权要求其赔偿所有损失。
     2. **申诉时间：** 若原子化服务商对原子化服务平台的处理方式存在疑问，可以在接收到下架及整改通知的3个工作日内进行申诉。
     3. **使用异常：** 由于原子化服务商原因导致用户无法正常使用服务时，原子化服务平台将根据其使用异常的严重情况对其进行处罚；由于原子化服务商原因导致服务功能完全不可用时，原子化服务平台将对其进行下架处理，原子化服务商应在规定时间内解决问题、以保障已添加到桌面的服务使用；对于应急事件、相关机构要求的下架场景或影响严重的服务使用异常、不可用问题现象，原子化服务平台将对服务进行直接下架处理。
     4. **下架退款：** 当服务因违规而下架、且服务内涉及未完成或未启动的用户付费项目时，原子化服务商应执行相应退款操作：若存在用户所购买的未完成项目，原子化服务商应按照未完成项目的实际价值退还给用户；若存在用户所购买的未启动项目，原子化服务商应执行全额退款操作。
