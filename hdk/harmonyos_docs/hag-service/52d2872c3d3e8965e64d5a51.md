# 基本要求

服务展示广告应仅限于当前服务界面内，应保证用户在不离开当前服务即可查看广告的所有信息。未经用户同意，不得利用敏感用户数据（例如：健康/医疗数据、学校和课堂数据或儿童数据等）进行广告推送或展示；广告中不得包含违法、违规或误导性内容，不得从事恶意广告或干扰性广告的行为。

（注：更多服务广告审核要点详见本规范“服务上架合规审核要点”条例）
