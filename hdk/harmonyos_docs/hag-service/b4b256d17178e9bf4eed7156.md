# 重级违规类型  
  
**重级违规类型：** 违反相关规范条例且情节严重的违规行为。针对此类违规行为，平台将对其进行下架处理，并扣除5分、实施30天处罚期，原子化服务商完成服务问题整改且在服务下架的30天处罚期后可以重新申请上架。服务在运营过程中可能出现的此类型问题如下：

#### **1\. 侵犯隐私行为**

     1. 服务违反最小必要原则，套取他人身份证、邮箱、手机号、银行帐号、支付帐号等个人或者企业隐私信息的行为。
     2. 原子化服务商进行反射查找、跟踪、关联、挖掘、获取或利用用户机号、电子邮箱地址和出生日期等信息从事与服务主体无关的行为。
     3. 原子化服务商擅自出售、转让、向任何第三方泄露，或以其他方式违规使用运营数据或用户的个人信息和相关数据。
     4. 原子化服务商在被第三方收购或合并等情况下，违法或违规收集和处理用户数据的行为（从服务中接收的用户数据仅能在原有服务内继续使用）。
     5. 收到用户要求删除自身数据诉求后，未删除接收到的该用户数据（除非依据法律、法规，服务方有权保留数据）；用户终止使用该服务，原子化服务商没有立即删除在此服务中接收到的用户数据。

#### **2\. 安全漏洞**

     1. 服务在运营过程中出现钓鱼、病毒木马等侵害服务功能&有损网络安全的行为。（如果钓鱼、病毒木马等现象的出现和处理过程中，原子化服务商无任何过错，则不纳入“重级违规类型”）
     2. 服务中出现帐号提权、安装后门程序等危害系统安全的行为。
     3. 服务在运营过程中隐瞒其所发现的系统缺陷且恶意利用，并未立即告知平台。

#### **3\. 恶意内容违规**

服务在运营过程中涉及黄赌毒、政治敏感信息、不当言论宣传，或任何其他违法、违规、侵权、违反公序良俗或社会公德等信息。

#### **4\. 未成年人保护措施不健全**

未依法采取各项措施切实保护未成年人合法权益，包括但不限于：未在游戏界面增加适龄提示、未依法采取并实施未成年人防沉迷机制等。

#### **5\. 恶意竞争**

     1. 原子化服务商伪造或篡改用户评论/留言。
     2. 原子化服务商以用户身份或委托他人购买自已的服务或进行评价；以用户身份购买同行服务后作出恶意评价。
     3. 原子化服务商以恶意投诉、评价、诋毁、虚假订购等方式进行不正当竞争，恶意举报其他合作伙伴，例如：提供伪证的举报行为等破坏市场公平竞争秩序。
     4. 原子化服务商诱导用户通过其他平台进行交易或增加其他平台访问量的行为、通过虚假或不正当的方式提高合作伙伴服务销量或信用。

#### **6\. 滥用平台资源**

     1. 原子化服务商非正当使用HarmonyOS生态提供的资源&服务，自行或与其他第三方共同对HarmonyOS生态体系提供的资源&服务进行干扰或不正当使用。
     2. 原子化服务商将在平台上收集的信息用于服务之外的任何目的，将信息出售、转让或向任何第三方披露。

#### **7\. 规避或对抗平台审核监管**

原子化服务商通过技术或其他方式，绕开、规避或对抗平台的审核及监管规则，包括但不限于：对不同用户群体展示不同服务类目下的内容、采用虚假仿冒投诉入口拦截用户投诉等行为。
