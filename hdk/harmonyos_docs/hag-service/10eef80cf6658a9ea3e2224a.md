# 服务功能  
  
     1. 服务应确保自身拥有正常、可闭环的功能，不得从事纯跳转导流行为（详见注释A）、不得含有任何影响用户体验的不合理功能。若服务需跳转外部链接（跳转对象包括但不限于原子化服务、应用、快应用、网页等相关内容）应事先向原子化服务平台申请，对于符合原子化服务平台相关管理要求者，在加入外部链接跳转白名单后可设置跳转（详见注释C）；否则，原子化服务平台有权禁止前述违反本规范的跳转外部链接行为。

注释：

A.纯跳转导流行为：原子化服务平台为保证用户体验禁止原子化服务商从事纯跳转导流行为，即禁止原子化服务商在并不实际向用户提供特定服务的情况下，仅通过领红包、做任务领权益等形式，诱导用户点击跳转到第三方服务、应用、快应用、网页等相关内容或由其他方提供的页面。

B.服务不允许在未实现基础功能、上架功能的情况下，跳转APP或应用下载界面，且服务在跳转APP时需要一步直达相关服务页面，APP启动时不能再有开屏广告。

C.外部链接跳转白名单：未经原子化服务平台同意并列入白名单的服务，不得相互推荐、推广、排行或集中设立跳转。

     2. 服务应确保功能已完善且用户可正常使用，否则原子化服务平台有权拒绝。
     3. 服务应保证功能透明，充分尊重用户的知情权和选择权，不得有隐藏或用户不易感知、发现的违法或违规情形。
