# 知识产权

     1. 未经授权或超出授权范围或期限，不得在服务中使用受保护的第三方材料(例如商标、版权作品、专利设计)；不得以误导用户的方式使用与其他服务相同或相似的内容，如外观、名称、主题等；不得在服务套装或原子化服务商名称中包含虚假、抄袭或误导性的演示、名称或数据。
     2. 服务应提供符合适用的法律、法规和原子化服务平台要求的资质文件（如软著证书、电子版权认证等），原子化服务平台将对其进行审核。服务及其内容不得侵犯他人权利，包括不得以帮助、诱导等方式间接侵犯他人在先权利；服务不得是第三方版权软件的破解版、汉化版；服务不得销售或促销仿冒商品。
     3. 如果服务会使用和访问第三方服务，通过访问第三方服务盈利或是显示第三方服务的内容，应确保获得在该服务的使用条款下进行此类操作的特别许可。如有相应要求，则应提供相关授权。
     4. 音频/视频下载：服务不得从事或协助非法文件共享，或在没有获得权利人明确授权的情况下，提供从第三方保存、转换或下载媒体资源的功能或帮助；如有相应音频/视频下载要求，则应提供相关音频/视频所有者的授权文件。
     5. 原子化服务商使用华为商标须获得华为终端的事先书面授权，否则任何使用华为商标的行为都可能构成商标侵权或不正当竞争并应承担法律责任。
