# 中级违规类型

**中级违规类型：** 违反相关条款且情节较重的违规行为。针对此类违规行为，原子化平台将对其进行下架处理，并扣除3分、实施7天处罚期，原子化服务商完成服务问题整改且在服务下架的7天处罚期后可以重新申请上架。服务在运营过程中可能出现的此类型问题如下：

#### **1\. 诱导行为**

     1. 违反本规范的相关规定，在服务详情描述页面、案例等页面中嵌入外部链接地址，自行或协助他人通过明示或暗示的方式来诱导用户转发内容后获取收益。
     2. 通过操纵安装、评论、提供奖励、伪造反馈等手段来提高服务的排名；诱导用户下载或使用服务、跳转体验其他服务获取收益。
     3. 服务内涉及强行中断服务内功能的流程、要求用户跳转其他服务后才能继续下一步操作。

诱导方式包括但不限于：现金奖励、实物奖品、虚拟奖品（红包、优惠券、代金券、积分、话费、流量、信息等）。

     4. 服务中出现纯跳转导流行为且未在外部链接跳转白名单内。

A.纯跳转导流行为：原子化服务平台为保证用户体验禁止原子化服务商从事纯跳转导流行为，即禁止原子化服务商在并不实际向用户提供特定服务的情况下，仅通过领红包、做任务领权益等形式，诱导用户点击跳转到第三方服务、应用、快应用、网页等相关内容或由其他方提供的页面。

B.外部链接跳转白名单：未经原子化服务平台同意并列入白名单的服务，不得相互推荐、推广、排行或集中设立跳转。

#### **2\. 侵犯知识产权**

服务运营过程中出现侵犯第三方知识产权或其他合法权益的行为，包括但不限于抄袭其他已入驻平台的合作伙伴及服务信息。

#### **3\. 违规交付**

服务交付过程成熟度和规范性低，一年内出现1起以上重大运营故障，影响用户使用、造成用户投诉并造成严重后果。

#### **4\. 游戏类服务违规**

     1. 强制捆绑下载，包括但不限于：未经用户同意下载其他服务，通过退出服务的方式强迫用户下载其他服务，例如用户不同意下载、则退出或无法登录/注册；引导用户下载其他服务时，获取同意的页面中没有明确的拒绝或关闭选项。
     2. 恶意刷榜：通过刷下载量、评论、搜索等冒充用户行为以提高相关数据的行为。
     3. 游戏首屏场景中，用户无法正常“开始游戏”，直接弹出与本游戏无关的第三方跳转。

#### **5\. 多级分销**

     1. 以电商平台为载体，通过培养用户粉丝、分级佣金的形式进行多级分销。
     2. 以虚拟社区运营方式，形成上下级代理、诱导组建团队。
     3. 通过实物销售，发展下级代理，多层级抽取销售利润。

#### **6\. 欺诈行为**

对用户实施欺诈行为（服务内含有虚假红包、虚假活动、虚假宣传等，包括但不限于：虚假拼团、高额返利吸引用户消费、以免费领取商品为噱头，引导用户支付高于实际商品价值的邮费或其他费用等）引起用户投诉、对用户造成损失的行为。

#### **7\. 藐视投诉行为**

当接到投诉时，虚构事实、隐瞒实情，假冒用户向平台表示撤销投诉、阻碍正常调查。

#### **8\. 诱导非官方渠道下载/登录**

原子化服务商诱导非官方渠道下载/登录，包括但不限于：自升级至非华为渠道包；外链跳转到非华为或合同约定以外的分发平台或网站；依华为单方判断，存在任何形式诱导用户下载/登录非华为渠道游戏/服务的行为。
