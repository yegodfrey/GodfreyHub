# 点击确定完成服务创建

在发布HarmonyOS服务前，建议您在本地进行服务调试，以查看和验证服务运行效果，减少发布过程中可能遇到的问题。为了确保HarmonyOS服务包的完整性，HarmonyOS通过数字证书和Profile文件来对服务包进行管控，只有签名过的HAP才允许安装到真机设备上运行。

**自动化签名方式：** 如果您的服务调试时可以联网，建议您使用HUAWEI DevEco Studio自动化签名的方式对服务包进行签名并调试，具体步骤请参见使用真机进行调试。

**手动签名方式：** 如果您的服务调试时无法联网，您可以在HarmonyOS服务开放平台中申请调试证书和Profile后，再通过手动签名的方式进行调试，具体步骤请参见手动方式调试HarmonyOS服务。
