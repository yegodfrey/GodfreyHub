# 相关要求

     1. 服务内广告不得影响用户的正常操作体验，不得干扰服务或设备功能。
     2. 服务内广告应依法保证可识别性。任何服务内广告，无论是否属插播广告，是否可能中断或影响用户体验的广告，均应显著标明“广告”，使用户能够辨明其为广告；付费搜索广告应当与自然搜索结果明显区分。不得操纵或欺骗用户点击此类广告，并且必须提供可以轻松访问和清晰可见的关闭/跳过按钮，按钮大小要足以让用户轻松解除广告。服务内广告需带有关闭功能，且服务关闭后，服务内广告也应同时关闭。
     3. 禁止提供非基于用户正常使用、人为增加广告展示次数或者广告点进次数的服务。对于主要设计目的在于显示广告的服务，原子化服务平台有权拒绝上架。
     4. 服务内广告应与服务潜在用户群体相适，例如：对于未成年人用户群体可能使用的服务，服务内广告应符合相关法规和行业标准的要求，广告内容必须适合未成年人观看，不得包含可能对未成年人身心健康造成负面影响的内容，不得包含欺骗性内容或可能导致未成年用户在无意间点击的不恰当内容。
     5. 服务不得在通知栏推送与自身产品无关的内容，服务在通知栏的广告应保证用户可清除；不得含有其他移动服务平台的相关推广、不得含有欺诈内容与恶意网址、不得强制安装软件或捆绑下载、不得出现匿名推送的行为。
