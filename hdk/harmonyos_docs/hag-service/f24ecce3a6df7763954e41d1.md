# 未成年人保护

     1. 服务在收集和使用未成年人的个人信息前，需获得父母或其他监护人的明示同意。针对未成年人，服务不得使用位置权限。服务仅可出于遵守适用未成年人隐私法规的目的要求用户提供出生日期或家长联系信息，并应提供一些适用于各年龄层用户的实用功能或娱乐价值。
     2. 未成年人类别的服务以及向未成年人收集个人信息 (例如姓名、地址、电子邮件、位置、照片、视频等)、传输此类信息或能够共享此类信息的服务，应遵守适用的未成年人保护法律、法规和规范（包括但不限于中国《未成年人保护法》、欧盟《一般数据保护条例》(GDPR)、美国《儿童在线隐私保护法》(COPPA)等在提供该项原子化服务的地区适用的法律、法规），并应依法提供完整的隐私政策并严格遵从。
     3. 只有未成年人类别的服务才能在服务中使用“适合未成年人”等相关描述，否则不得在名称、副标题、图标、截屏或描述中包含任何暗示服务主要受众为未成年人的词汇。
     4. “未成年人类别”的服务内容应适合未成年人，不得含有可能对未成年人造成干扰的内容，“未成年人类别”的服务不得含有任何外部链接、购买机会，除非服务自身拥有完善的“家长管控机制”（家长可对未成年人使用服务的情况进行全程监控）。
     5. 原子化服务商应及时将已停止运营的服务信息告知未成年用户及其监护人，并按照应适用的法律要求停止收集和处理未成年用户的个人信息。
