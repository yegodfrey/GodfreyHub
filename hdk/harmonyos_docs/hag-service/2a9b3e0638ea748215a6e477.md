# ​专门领域服务上架合规审核要点

     1. 对于金融交易、投资、保险或资金管理等金融相关服务，原子化服务商应为依法经批准从事此类服务的金融机构，并应严格遵守所有适用的法律、法规和规范；提供个人贷款的原子化服务应以醒目的方式，清晰地披露所有贷款条款——其中包括但不限于等效最高年利率和到期还款日。
     2. 经批准的非营利组织在服务内进行筹款活动，应遵守所有适用的法律、法规和规范，如实披露资金的计划用途并应确保向捐款人提供相应的报税收据。
     3. 对于游戏类服务，游戏名称不得出现任何恶意歪曲著名人物、地名及重大历史事件的情况，不得混淆、侵权其他游戏；游戏背景若涉及历史题材，不得恶意篡改历史事件、颠覆历史人物形象；游戏音乐及音效应当符合国家版权管理的法律法规，不得侵犯他人著作权，不得提供非法下载服务；不得表现出恐怖、血腥、变态、色情等不利于用户身心健康的环境或场景；不得提供赌博或者宣扬赌博的功能；不得以随机抽取等偶然方式，诱导用户采取投入法定货币或者网络游戏虚拟货币方式获取小游戏产品和服务；游戏内若带有现金红包奖励或类似现金奖励提现玩法，打开红包或提现环节不得设置任何附加条件。
