# 信息内容

服务信息内容直接影响用户对原子化服务的使用体验，属原子化服务平台重点审核范围，本规范（包括但不限于“服务上架合规审核要点-信息内容”条例）适用于各原子化服务的全生命周期。

     1. 禁止危害国家安全、泄露国家秘密、颠覆国家政权、破坏国家统一、损害国家荣誉和利益的内容；禁止反政府、反社会或存在煽动性的涉政言论、散布谣言，以及扰乱社会秩序、破坏社会稳定的内容；禁止含有宣扬邪教和封建迷信的内容，禁止含有关于宗教、种族、性取向、性别或其他目标群体的诽谤或恶意内容；禁止存在煽动民族仇恨、民族歧视，破坏民族团结的内容；禁止存在国家法律法规禁止的其他内容。
     2. 禁止含有人类或动物遭到杀害、残害、酷刑、虐待的写实描绘，或者鼓励暴力的内容；禁止传播暴露、情色、低俗内容；禁止存在非法金钱交易、赌博及其他法律所禁止的内容；禁止含有虚假、欺诈或冒充类内容，包括但不限于虚假红包、虚假活动、虚假宣传。
     3. 禁止公然侮辱或者诽谤他人、揭露他人隐私、侵害他人合法权益的内容；禁止任何召集、鼓动犯罪或有明显违背社会善良风俗行为的内容；禁止含有具有攻击性、不顾及他人感受、令人不安、惹人厌恶或低俗不堪的内容。
     4. 禁止含有鼓励非法使用武器、危险物品或促进军火购买的内容；禁止含有非法使用毒品、过量摄入酒精、酒驾、违反交通规则、鼓励消费烟草及电子烟产品等人身伤害内容。
     5. 原子化服务商对用户生成的内容应进行有效管控，包括但不限于：核验用户帐号身份信息；制定内容过滤机制、对违法有害信息进行防范及处置；制定用户举报机制、完善反馈渠道；对严重违规用户帐号停止提供服务等。
     6. 禁止提供违反原子化服务平台的各项管理规范或原子化服务商与华为终端签订的任何形式的服务协议、平台协议、功能协议的内容。
