# 真机测试配置

确认手机中已安装服务中心，且版本号在13.0.3.200及以上。检查方法如下： 
     1. 在手机上选择“设置 > 应用和服务 > 应用管理”。
     2. 点击右上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.49671718548643467322811467503306:50531106021631:2800:66A8C30759451F65C1B641851F1C81528FB3B80BAA62EAE0CC10236D93C39935.png?needInitFileName=true?needInitFileName=true)，选择“显示系统程序”。
     3. 在搜索框中输入**应用名称** ，在搜索结果中单击应用，即可查看版本号。

#### 服务中心测试HarmonyOS原子化服务

提交到测试态的服务中心展示的服务，可以使用真实设备体验该服务。

**前提条件**

确保调测手机上登录的华为帐号为真机测试用户组中的用户成员，且该用户组已经在该服务中被选中。参见真机测试配置-步骤3。

**操作步骤**

     1. 打开HarmonyOS系统手机，在屏幕的左下角或右下角按住，往上滑动进入服务中心App。
     2. 点击右上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.29755722269725212286382070058155:50531106021631:2800:B37B695A9A047CE1889C955D2D3181CBF2C15E40A1A242A52F8B0B7D9EDEBDF0.png?needInitFileName=true?needInitFileName=true)，进入设置页面。
     3. 点击“辅助功能”，打开“开发者测试”开关。
     4. 在服务中心App中，点击“发现”。将页面滑动至底部，在“服务测试”栏目，可以看到您提交的测试态的服务。
     5. 点击该服务，即可查看服务运行效果。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.20967611157299925809399413990412:50531106021631:2800:809AE7C1569D75F7516529698F4807A2D04AD00D089D4B59165C41053A598B46.png?needInitFileName=true?needInitFileName=true)

#### HarmonyOS标签测试HarmonyOS原子化服务

提交到测试态的碰一碰/扫一扫触发的服务，可以使用真实设备体验该服务。

**前提条件**

     1. 确保**分发配置** 已经配置“碰一碰/扫一扫触发的服务”。
     2. 确保调测手机上登录的华为帐号为真机测试用户组中的用户成员，且该用户组已经在该服务中被选中。参见真机测试配置-步骤3。

**操作步骤**

     1. 打开HarmonyOS系统手机，在屏幕的左下角或右下角按住，往上滑动进入服务中心App。
     2. 点击右上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.53508188903547947490239139820197:50531106021631:2800:B5175F93FC1CD2FDF234F425EC72ADB3EEEB1C63398E21F939F1F60CFB039550.png?needInitFileName=true?needInitFileName=true)，进入设置页面。
     3. 点击“辅助功能”，打开“开发者测试”开关。
     4. 碰一碰/扫一扫场景运行效果查看。
        * 碰一碰场景运行效果查看。 
          1. 准备好一个实体NFC标签。并将申请好的HarmonyOS标签码流写入实体NFC标签中。
          2. 将调测手机靠近写好内容的NFC标签即可。
        * 扫一扫场景运行效果查看。 
          1. 准备好申请的HarmonyOS码图片。
          2. 在服务中心App中点击搜索栏右方的扫一扫图标后，扫描HarmonyOS码图片即可。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.37526310427855849378101250447513:50531106021631:2800:BDD5AE4C3778D70A121D8B003BFB3293FC4603E6F8B50EE6C55B23FBE16E630A.png?needInitFileName=true?needInitFileName=true)

如您之前已安装过该服务，请先进入“系统设置 > 应用与服务 > 服务管理”，移除该服务，确保碰一碰/扫一扫时能够拉起最新上传到平台的服务。
