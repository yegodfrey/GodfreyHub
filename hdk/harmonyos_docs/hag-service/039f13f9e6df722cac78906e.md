# 申请调试证书

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110809.26354414883683015811701767028249:50530920060115:2800:0D1C5CAB775B71B6C50D1588F4355FF4D1FC80F735ED0D4863927E24DA816BDD.png?needInitFileName=true?needInitFileName=true)

您最多可申请1个发布证书，2个调试证书。

     1. 登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)，单击“通用管理”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110809.19982234462873957624646599125978:50530920060115:2800:5A4F415663E7695BD14DEF5F1FAC86BFEE82877A81CB00262676E4AC1124B767.png?needInitFileName=true?needInitFileName=true)

     2. 在左侧导航栏单击“证书管理”，进入“证书管理”页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110809.99418484298474581000954603452030:50530920060115:2800:E6D207B55062F528A94B707966657DC11030A9F0351F5DD68927819DCB548184.png?needInitFileName=true?needInitFileName=true)

     3. 单击“新增证书”，弹出“新增证书”窗口，在新增证书的窗口中填写要申请的证书信息，单击“确定”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110809.81198540808599726128890427471512:50530920060115:2800:5E8D2B3B5F9DCF9AB9907B89700B22E47F54CFDFA5CA83F0DE2C4917B6ECBB36.png?needInitFileName=true?needInitFileName=true)

参数 | 说明  
---|---  
证书名称 | 最多100个字符。  
证书类型 | 选择“调试证书”。  
证书有效期 | 根据需要选择有效期，单位：年。  
上传证书请求文件（CSR） | 上传已生成的证书请求文件，具体请参见[使用DevEco Studio生成证书请求文件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ohos-manual-configuring-signature-information-0000001227179436#section17693112515615)章节，通过IDE生成密钥库文件（.p12）和证书请求文件（.csr）文件即可。  
  
     4. 证书申请成功后，“证书管理”页面展示“证书名称”、“证书类型”、“证书状态”、“失效日期”和“操作”列信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110809.44446124806897167828799042886328:50530920060115:2800:15857102ECBCD8E6AC64553E97D7D0625A1F885720FB1BDB81BF1DF31F368F48.png?needInitFileName=true?needInitFileName=true)

        * 在“操作”列单击“下载”，可下载证书。
        * 在“操作”列单击“删除”，在弹出的“提示”窗口中单击“确认”，可废除证书。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110809.92127521905689024374839948529571:50530920060115:2800:A0BDEAA5626360289E58193DB69C72496CB17C0AC8AAE7BEF5DDB60687AE80D3.png?needInitFileName=true?needInitFileName=true)

如证书已过期，“失效日期”列展示“已于YYYY-MM-DD过期”。您可以下载或删除过期证书。
