# 申请发布Profile

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.94618957287107376894006833674399:50530920060115:2800:029BCE596AB71387DB9E386303B325D2DC82440A130C6C3414A41DF5B2BE15F7.png?needInitFileName=true?needInitFileName=true)

您最多可申请 100 个 Profile 文件。

     1. 登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)，单击“我的项目”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.24552482236805883075131518480907:50530920060115:2800:156D40C6877E7828D939A68CF4F8A4E5B64F0FD963FD9F48600708B600023E24.png?needInitFileName=true?needInitFileName=true)

     2. 找到您的项目，单击项目名称进入项目详情。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.65797409696756368825692230558123:50530920060115:2800:903E5294C811304BAD908394F6FB864294320B3F3386237D8B6BEF89D04845D8.png?needInitFileName=true?needInitFileName=true)

     3. 在左侧导航栏选择“HAP Provision Profile管理”，进入“管理HAP Provision Profile”页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.83769080902763755925704153621081:50530920060115:2800:BE3F856305376A9841937B292FE38CC1467C411831B0D84FB2E1276EB8D3FD8A.png?needInitFileName=true?needInitFileName=true)

     4. 单击右上角“添加”，添加HAP Provision Profile。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.41214002696605340720718351603086:50530920060115:2800:F57D1F42C314EA079668A0E4D9907856D065F5A8A858CB4D4E971EA1DBAF4D76.png?needInitFileName=true?needInitFileName=true)

参数 | 说明  
---|---  
名称 | 最大100字符。  
类型 | 选择“发布”。  
选择证书 | 单击“选择证书”，选择申请服务发布证书中生成的证书。 须知：  升级服务时，您可以选择当前在架服务的发布证书，以继承已上架服务的数据与权限。  
受限权限 | 可选项。如软件包要求使用受限权限，请您务必在此处进行申请，否则您的服务将无法在调试设备上安装调试。 单击“修改”，勾选需要申请的权限，单击“确定”即可。 说明：  受限权限开放场景请参见[受限开放的权限](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/security-permissions-available-0000001051089272#ZH-CN_TOPIC_0000001073014298__section22412017171119)。  
  
     5. 发布Profile申请成功后，“管理HAP Provision Profile”页面展示“名称”、“类型”、“证书”、“失效日期”和“操作”列信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.41533723623892522746066667355179:50530920060115:2800:99AE46BDF924FEDBD7FE3D0E71A1B356C00AEC0705C1B5BFE79043DB9E677AC6.png?needInitFileName=true?needInitFileName=true)

        * 在“操作”列单击“下载”，可下载Profile文件。
        * 在“操作”列单击“删除”，在弹出的“提示”窗口中单击“确认”，可删除Profile文件。
