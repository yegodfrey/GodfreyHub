# 基本要求

     1. 服务的基础信息应能够准确反映服务提供方的特征及服务的核心体验，并与其他关联的服务保持同步更新。
     2. 服务的名称、介绍、图标、截图及预览视频应适合所有受众，应符合用户对其实际提供的功能或服务的预期，应避免引导、误导、混淆用户对其实际提供的功能或服务范围的理解，不得带有其他终端品牌或移动服务平台的内容，且不得含有政治敏感、色情、暴力血腥、恐怖内容，不得违反适用的法律法规，不得从事违法行为、非法活动或为从事违法行为、非法活动提供便利或协助；未经授权不得使用第三方享有合法权益的商标、品牌标识等内容或与之相似的内容、信息、特殊角标、侵犯他人合法知识产权和其他合法权益（包括但不限于肖像权、名誉权、隐私权、姓名权等）。服务的图标、名称、版本、功能和内容应与提交时填写信息相符。原子化服务商不得频繁更改（一年内最多2次修改机会）服务的名称、图标。
     3. 服务名称不得以广义归纳类、普遍且不具有识别性的词汇来命名、不得和其他服务名称相同，且不得含有特殊符号 (如“*”、“&”)。服务范围应与原子化服务商填写的类目和标签一致，与实际所提供的服务一致，不得超出原子化服务平台的类目库范围。
     4. 原子化服务商应当严格遵守法律、法规等规范性文件的规定。对于有合理理由认为存在违反法律、法规或监管要求的情况，原子化服务平台有权拒绝并采取必要的管理措施。
     5. 原子化服务商应当按照平台要求提供相应的审批、备案等资质文件材料，并应保证前述资质文件材料真实、合法、有效，否则原子化服务平台有权拒绝并追究相应的法律责任。拟从事发布、传播或其他相关经营活动，但未依法取得必要的审批、许可或授权者，原子化服务平台有权拒绝。
