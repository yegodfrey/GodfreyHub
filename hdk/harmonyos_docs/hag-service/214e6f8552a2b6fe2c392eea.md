# 本地开发和自测试

     1. 搭建DevEco Studio开发环境。参见[搭建DevEco Studio开发环境](https://device.harmonyos.com/cn/docs/devicepartner/DevicePartner-Guides/atomic-service-ide-preparations-0000001136537738#section922418946211103)。
     2. 配置签名信息。
        1. 在DevEco Studio中打开菜单“File > Project Structure”。
        2. 单击“Project > Signing Configs > debug”窗口。
        3. 去除勾选“Automatically generate signing”。
        4. 配置调试签名信息。 
           * Store File：选择密钥库文件，文件后缀为.p12，该文件为[使用DevEco Studio生成证书请求文件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ohos-manual-configuring-signature-information-0000001227179436#section17693112515615)中生成的.p12文件。
           * Store Password：输入密钥库密码，该密码为[使用DevEco Studio生成证书请求文件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ohos-manual-configuring-signature-information-0000001227179436#section17693112515615)中填写的密钥库密码保持一致。
           * Key Alias：输入密钥的别名信息，与[使用DevEco Studio生成证书请求文件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ohos-manual-configuring-signature-information-0000001227179436#section17693112515615)中填写的别名保持一致。
           * Key Password：输入密钥的密码，与Store Password保持一致。
           * Sign Alg：签名算法，固定为SHA256withECDSA。
           * Profile File：选择[申请调试Profile-步骤5](https://developer.harmonyos.com/cn/docs/distribute/hag-service/debugging-profile-0000001238267105#ZH-CN_TOPIC_0000001275712937__li668157143219)中生成的Profile文件，文件后缀为.p7b。
           * Certpath File：选择[申请调试Profile-步骤4](https://developer.harmonyos.com/cn/docs/distribute/hag-service/debugging-profile-0000001238267105#ZH-CN_TOPIC_0000001275712937__li173905474333)中生成的数字证书文件，文件后缀为.cer。

     3. 在调试Profile绑定的调试设备上安装调试包，进行服务调试，参见[使用真机进行调试](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/ide_debug_device-0000001053822404#section10491183521520)。
