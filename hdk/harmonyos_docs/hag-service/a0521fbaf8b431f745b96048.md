# 原子化服务卡片设计示例

根据原子化服务卡片所属类别、所需展示信息的丰富程度、用户常规使用习惯等因素，对卡片设计建议如下：

     1. **智能家居类原子化服务卡片：** 推荐使用小卡片（2*2宫格）和中卡片（2*4宫格）两类卡片，具体文字要素、页面布局请参考华为系统应用“智慧生活”卡片
     2. **智慧教育类原子化服务卡片：** 推荐使用小卡片（2*2宫格）和中卡片（2*4宫格）两类卡片
     3. **运动健康类原子化服务卡片：** 推荐使用微卡片（1*2宫格）和小卡片（2*2宫格）两类卡片，具体文字要素、页面布局请参考华为系统应用“运动健康”卡片
