# 隐私政策

     1. 原子化服务商应充分尊重用户隐私，严格遵守适用的法律、法规和本规范的要求，不得从事与[《华为消费者业务隐私声明》](https://consumer.huawei.com/minisite/legal/privacy/statement.htm?code=CN&language=zh-CN)、[《HarmonyOS开发者隐私设计指南》](https://developer.harmonyos.com/cn/docs/design/des-guides/introduction-0000001077467612)的相关要求存在冲突的行为。
     2. 原子化服务商必须在服务分发平台及服务内部提供自身可便捷查看的隐私政策链接、必须确保该链接始终能正常打开，且应和服务在运行中对用户个人信息的处理保持一致。服务的隐私政策应写明服务所收集的数据范围、收集数据的方式和目的以及数据的所有用途；清晰指出用户如何撤销同意或删除数据的方式，明确用户隐私问题反馈渠道。
     3. 服务的隐私政策链接指向的隐私政策应当包含服务（包括委托的第三方或嵌入的第三方代码、插件）收集和使用个人信息的目的、方式和范围。
     4. 服务披露任何个人信息须在隐私政策中说明披露内容、目的和披露对象，禁止违法出售、泄露、复制、分享或传播用户的个人信息。原子化服务商有义务确保：与服务共享用户个人信息的任何第三方要求提供不低于服务的隐私政策所述要求的用户个人信息保护措施。

注：更多隐私政策相关要求详见[《华为消费者业务隐私声明》](https://consumer.huawei.com/minisite/legal/privacy/statement.htm?code=CN&language=zh-CN)及[《HarmonyOS开发者隐私设计指南》](https://developer.harmonyos.com/cn/docs/design/des-guides/introduction-0000001077467612)。
