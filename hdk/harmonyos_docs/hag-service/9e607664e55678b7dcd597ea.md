# 服务内付费

     1. 若服务中涉及解锁特性或功能（例如：订阅内容、游戏关卡、优质内容，解锁完整版本等)，必须使用服务内购买项目，原子化服务商提交服务时需勾选“服务内付费”，不得包含按钮、外部链接或其他行为诱导用语来指引用户使用非服务内的购买方式。
     2. 服务内若具有随机虚拟物品购买机制的服务，需要在用户购买前指出每种类型物品的获取几率。
     3. 可用来兑换数字商品或服务的充值卡、礼品券、兑换券和优惠券仅可通过原子化服务内购买项目销售。
     4. 对于免费试用的服务，在用户试用之前，原子化服务商应清楚指明试用时长、试用结束后无法再访问的服务内容，以及用户为获得完整功能而需要支付的后续费用。
     5. 钱包凭证仅可用于付款或接收付款、传输交易或提供身份验证 (例如电影票、优惠券和 VIP 凭据) 。
     6. 退费：服务内应设置便捷的用户反馈渠道，当服务无法提供用户已付费的服务项目时，若按照适用的法律、法规和规范，原子化服务商有退费义务，则原子化服务商应依法将相应的付费金额及时退还至用户原有支付渠道；原有支付渠道无法使用时，原子化服务商应依法将相应的付费金额及时退还至原子化服务商和用户共同确认的收款渠道。
