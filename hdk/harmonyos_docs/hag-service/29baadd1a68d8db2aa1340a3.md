# 不同设备卡片规格要求

原子化服务平台致力于协同各原子化服务商，为用户提供更加优质的多设备使用体验。原子化服务商应根据以下设备卡片适配规范相应地进行开发部署。若服务不符合相关规范要求，将不允许上架：

[折叠屏、平板设备服务卡片适配](https://developer.harmonyos.com/cn/docs/design/des-guides/service-widget-adaptation-0000001144776279)

[智慧屏卡片规范](https://developer.harmonyos.com/cn/docs/design/des-guides/service-widget-devices-tv-0000001144699417)

[穿戴卡片规范](https://developer.harmonyos.com/cn/docs/design/des-guides/service-widget-devices-watch-0000001098059484)
