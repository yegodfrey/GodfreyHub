# 订阅

     1. 若服务提供自动续订订阅，应充分提示用户以获得用户自动续订授权。服务应保证为用户提供持续价值且应适用于订阅该服务的所有用户设备。
     2. 订阅可与单项服务共同提供，例如：用户既可以进行整个影片库的订阅，也可以进行单部影片的购买或租赁。
     3. 不得强制要求用户在为服务评级或点评、下载其他服务或执行其他类似操作之后方可访问该服务的功能和内容。
     4. 如果想要现有服务更改为基于订阅的业务模式，不得删减现有用户已付费购买的功能。例如，针对新用户引入订阅模式后，已购买完成服务的用户应能够继续访问或使用完整服务。
     5. 不得诓骗用户、通过虚假信息诱骗用户购买订阅的服务，否则原子化服务平台有权拒绝上架。
     6. 原子化服务商应在用户订阅服务之前，清晰描述付费后的具体权益，并应写明订阅有效期限、取消订阅的渠道、方式及相关注意事项。
