# HarmonyOS与HarmonyOS服务开放平台

HarmonyOS是一款面向万物互联时代的、全新的分布式操作系统。

HarmonyOS提供了[HUAWEI DevEco Studio](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/tools_overview-0000001053582387)供您完成HarmonyOS服务的开发。有关HarmonyOS的具体介绍，请参见[HarmonyOS开发文档](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/harmonyos-overview-0000000000011903)。

当完成HarmonyOS[原子化服务](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/atomic-service-definition-0000001090840664)的开发后，您可以登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)进行调试、分发配置和发布，以及上架后的统计分析、升级、回退、下架。服务上架后可以支持分发到运行HarmonyOS系统的设备。
