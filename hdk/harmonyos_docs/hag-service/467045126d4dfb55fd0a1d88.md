# 原子化服务卡片

     1. 原子化服务卡片介绍：

原子化服务卡片将服务的重要信息以卡片的形式展示在桌面，用户可通过快捷手势使用卡片，通过轻量交互行为实现服务直达、减少层级跳转的目的。原子化服务卡片的核心理念在于提供用户容易使用且一目了然的信息内容，将智慧化能力融入到原子化服务卡片的体验中供用户选择使用，同时满足在不同终端设备上的展示和自适应。

     2. 原子化服务卡片构成：

原子化服务卡片的显示主要由内容主体、归属的App名称构成，原子化服务卡片来自App的，建议使用其归属App名称；原子化服务卡片无归属App的，建议其名称需明确体现此服务的主要功能或特征。原子化服务商应借助卡片内容和卡片名称清晰地向用户传递所要提供的服务信息。

     3. 原子化服务卡片尺寸：

原子化服务卡片支持多种卡片尺寸：微、小、中、大。卡片展示的尺寸大小分别对应桌面不同的宫格数量，微卡片对应 1*2 宫格，小卡片对应 2*2 宫格，中卡片对应 2*4 宫格，大卡片对应 4*4 宫格。

        1. 必须支持免安装的 HarmonyOS 服务设计小尺寸（2*2）的原子化服务卡片。
        2. 请根据卡片尺寸的不同、提供对应的功能，避免将小尺寸的卡片内容在不做任何处理的情况下适配成较大尺寸。卡片尺寸越大，呈现的信息、内容成分应越丰富，可交互的范围也越大。

更多原子化服务卡片尺寸规范请参见“[关于卡片](https://developer.harmonyos.com/cn/docs/design/des-guides/service-widget-about-0000001144696239)”。
