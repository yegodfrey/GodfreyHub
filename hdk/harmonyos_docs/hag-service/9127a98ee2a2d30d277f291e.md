# 本地打包并上传

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.97816502058703979535894811718398:50530920060115:2800:38B87AA521C25EA8EAAA8FAE379781436D8BA35E8B21ECDAE73AEAAA2A6F31F1.png?needInitFileName=true?needInitFileName=true)

您最多可申请100个Profile文件。

     1. 下载发布证书和发布Profile，方法可分别参考[申请发布证书](https://developer.harmonyos.com/cn/docs/distribute/hag-service/apply-certificate-0000001238387073)和[申请发布Profile](https://developer.harmonyos.com/cn/docs/distribute/hag-service/apply-profile-0000001238587089)。
     2. 打包服务。打包时需要在HarmonyOS服务发布包中集成发布Profile，并使用发布证书对应的私钥对HarmonyOS服务发布包进行签名。参见[应用/服务发布](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/publish_app-0000001053223745#section280162182818)的“配置签名信息”和“编译构建App”章节。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.14227447390822980331914873342393:50530920060115:2800:FFF4CDA612C50A84178AECF8E79130654BBA26C5D4ED173E8F595F1544D23945.png?needInitFileName=true?needInitFileName=true)

免安装的HAP包不能超过10MB，以提供秒开体验。

     3. 登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)，单击“我的服务”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.51170414326900531958061563385190:50530920060115:2800:A140ADB275963DC94605E409479F44FBD5CBD8F034F1EB1C8DB3416F6B46DA98.png?needInitFileName=true?needInitFileName=true)

     4. 在我的服务列表中找到待上架，单击“编辑”进入服务详情页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.96899894391856442610263141753459:50530920060115:2800:ED37EFAD5B6D36990BBD53D9CE10EEB971A36BDCF8BD0DF80777FC08C562A226.png?needInitFileName=true?needInitFileName=true)

     5. 单击“上传”按钮，在服务包管理页面上传App包。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.67729701768720317872581187045338:50530920060115:2800:98F7F0A57A69EE0B6D48DD2C08F89D10D842FCE7392EAB3151D7EC36321014D2.png?needInitFileName=true?needInitFileName=true)

App包中的证书和Profile，需要为HarmonyOS服务开放平台及项目中申请的发布态的证书和发布态的Profile。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110811.27672566484746546003072774971183:50530920060115:2800:BD371F92440E82DFC262D8F7F6BE6A6E4604989C0514E880A439AB5E2566166B.png?needInitFileName=true?needInitFileName=true)

     6. （可选）HarmonyOS Connect产品如需要**申请免2*2服务卡片权限** 。按照如下要求发送邮件申请即可。

收件人：dtsedev@huawei.com

抄送人：相关产品的华为技术支持接口人

主题：【申请免2*2服务卡片权限】企业名称+产品名称

邮件内容：

        * 企业名称：XXX
        * 待上架的原子化服务名称（服务列表中的服务名称）：XXX
        * 登录联盟网站的主帐号（手机号或者邮箱地址）：XXX

对应于登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)之后，“帐号设置”中的“手机号”或者“邮箱地址”。

     7. （可选）服务升级，谨慎修改FA信息。升级服务时修改FA信息，可能导致用户侧的桌面卡片消失，具体规范如下：
        * 升级服务时，若该服务上一个版本下存在卡片，**服务组件名和服务接入名** ，均不允许修改；
        * 升级服务时，同一个ability下，**卡片名称** 不允许修改；
        * 升级服务时，同一个ability下，同一个卡片名称的**卡片尺寸** 不允许修改。
     8. 上传完成后得到服务包解析信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110812.23934301289118335146899660609289:50530920060115:2800:F5DA02BEA8489973336C77D398C604ACD82A43ACE680E59A858E5EFC1918EBF4.png?needInitFileName=true?needInitFileName=true)

        * 修改服务简介

如果需变更服务简介，除了在IDE进行修改（服务简介=IDE包内 description描述字段）重新上传；也可以点击详情在页面上进行修改，完成修改点击保存；对于已上架的服务，保存后需在发布页点击升级，运营审核通过后刷新到用户端。（注：如果页面上编辑过服务简介，再次上传HarmonyOS服务包时会保留修改的值不变，需要变更请在页面上修改）

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110812.97758745695533438884625918035854:50530920060115:2800:45C71C11C00A274F9600F22532B9D3599C5DD4630E3D6FC6DB2B28B163421821.png?needInitFileName=true?needInitFileName=true)

如果是多语言的服务简介，点击语言类型下拉选择语言，再修改服务简介并保存。
