# 发布原子化服务

#### 发布原子化服务

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.60871366602139023864844673259571:50530920060115:2800:A492086B2E81BDF0C872BCFE052924D425511402B8FAFD3D591A7DDFE6EFE208.png?needInitFileName=true?needInitFileName=true)

已上架的原子化服务，如需要升级，调测时直接将原子化服务推送和安装到本地。调测的时候会优先拉起本地的原子化服务。

     1. 完成真机测试后，选择上面菜单的“发布”选项，选择“发布类型”和“上架设置”之后，单击“上架”服务。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.66673946890815901364834680196125:50530920060115:2800:3CC1EB2B3E623FE4F800E8513AF3E8DD91DBE542AB45A5BC65C98597097CE1BA.png?needInitFileName=true?needInitFileName=true)

     2. 单击上面菜单的“版本”选项，查看版本的审核状态。审核人员会在2~3个工作日内进行审核并反馈意见。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.91703231242795033948588899264101:50530920060115:2800:4FBF123BB290FF47FC1ED4FC0AEC60BEE269F9351B1A619241F26B3AE2FAA42E.png?needInitFileName=true?needInitFileName=true)

     3. 单击上面菜单的“服务信息”选项，选择“审核意见”，可以查看审核意见。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.44534663196110653578966247579171:50530920060115:2800:510F9C461AD3727079665239732F9E2E33CD8C4ABBCF8CBD709073138990716A.png?needInitFileName=true?needInitFileName=true)

     4. 审核通过后，单击上面菜单的“版本”选项，版本的审核状态为“已上架”。上架审核完成后，审核人员预计会在1个工作日内完成服务订阅操作。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.10425210121906599475181988879345:50530920060115:2800:696FF197964135D8E7107D57F343F2E8EF08E2F890C2C9E2052E48B4AD1705C9.png?needInitFileName=true?needInitFileName=true)

#### 撤回提交审核中的服务

     * 撤回“上架审核中”的服务。 
       1. 在服务列表中找到需要撤回提交审核的服务，单击“撤回”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.69316958201269348068023589528450:50530920060115:2800:B02708307DD71706630E76B2A5C6219557EBF764F2D074FC234950E5148E9F47.png?needInitFileName=true?needInitFileName=true)

       2. 弹出确认撤回提示框，单击“确认”，即可撤回升级审核中的服务。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.25614189393379279606411036495086:50530920060115:2800:D5A967C7000882C4558DC8700AC689BDF08243CA6495ACE300A46B90F435EE55.png?needInitFileName=true?needInitFileName=true)

     * 撤回“升级审核中”的服务。 
       1. 在服务列表中找到需要撤回提交审核的服务，单击“撤回”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.40729782902349697942290460838665:50530920060115:2800:41DDDBE55E6117FFAF9821EB530E45E1CF7DE688EC5DBF6988E1E63A7ED17457.png?needInitFileName=true?needInitFileName=true)

       2. 弹出确认撤回提示框，单击“确认”，即可撤回升级审核中的服务。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.47755692546248815367587825773617:50530920060115:2800:48B232BFC77585E76F8B4AEA0F2A70F7FF005C1844B91BB0CFC4D2EF869B45BD.png?needInitFileName=true?needInitFileName=true)

#### 下架已完成上架的服务

     1. 在服务列表中找到需要下架的服务，单击“下架”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110815.90974113138608806470301023305044:50530920060115:2800:A48DCEAC2BFC6E97D42AD8A227E585D28C34CFF374CF0A8BADA4994239380C58.png?needInitFileName=true?needInitFileName=true)

     2. 弹出提示框中，输入下架原因，单击“确认”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.75982513776806394519769658766316:50530920060115:2800:7CDDB5E0EC25127C6F725763FB8E66F3F33853BA51A6ADAE113FA0E989938945.png?needInitFileName=true?needInitFileName=true)

     3. 当前服务处于“下架审核中”状态，审核人员会在1~2个工作日完成下架审核操作。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.46882955134403458219764654009837:50530920060115:2800:A183C47C0A5CDFF4C229B56A3D9E0FA8828EAB42F89D9285BB3C64A692E49652.png?needInitFileName=true?needInitFileName=true)

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.20891912359766788250192127528673:50530920060115:2800:63B3619FA09D6804E4D6B931605FCCAB7AA74D211A1EA7D7577FA1F15FE7CDB4.png?needInitFileName=true?needInitFileName=true)

如需撤回“下架审核中”状态的服务，在服务列表中找到该服务，单击“撤回”即可。

#### 回滚到上一个版本状态

     1. 进入服务详情中，单击上面菜单的“版本”选项，单击需要回滚到XX版本对应的“回滚”操作。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.30193713126762417413052824429949:50530920060115:2800:5A5DC4E6F51ECC6339CD7F199268F2DCF587D4BAE303EF0F1E06E291354978B6.png?needInitFileName=true?needInitFileName=true)

     2. 弹出确认撤回提示框，单击“确认”。
     3. 单击上面菜单的“服务信息”选项，可以看到平台上的版本信息和服务包内容已经回滚到指定版本。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.88626978117352431469050209565419:50530920060115:2800:15DAAD338B2FB39B60276DB5682C336A6C1F7EEDD2C5CF2828DF9DE7BBBE3B31.png?needInitFileName=true?needInitFileName=true)

     4. 单击上面菜单的“发布”选项，单击右上角“升级”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.68002722400215851227511388245182:50530920060115:2800:6D7286215C2078C06DEB391A6606EABF67E6E6D16CF129792DC1A2ACDCB6BD68.png?needInitFileName=true?needInitFileName=true)

     5. 等待服务升级审核通过，表示服务已经成功回滚到指定版本。参见发布原子化服务。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.10640827069185884226410144811333:50530920060115:2800:68A3B0428089EA749BA108FA2BA7FE183CD7E3087104B2D674CAF430076081E4.png?needInitFileName=true?needInitFileName=true)

#### 删除非最新版本的其他分支版本

     1. 进入服务详情中，单击上面菜单的“版本”选项，单击需要删除的XX分支版本对应的“删除”操作。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.97697136401576454330190082746857:50530920060115:2800:3B67F782C13AEA46C6324CB34550686B8AEFC0136BE8E1CAD1F5A560B415C86B.png?needInitFileName=true?needInitFileName=true)

     2. 弹出确认提示框，单击“确认”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.31269717875200405593155944677654:50530920060115:2800:B53C98417C6FA8DC9E555B0B1D3A3D066C42B8202F40692924C6AB89864ED919.png?needInitFileName=true?needInitFileName=true)

     3. 删除成功后，界面会提示删除成功，版本管理中即不再展示已删除的分支版本。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110816.31179803709238901620391543418391:50530920060115:2800:3670D669641CE535A23491296F377280B6A192A4571ECA07CEC50E5BD756B3DF.png?needInitFileName=true?needInitFileName=true)
