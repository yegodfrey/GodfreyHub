# 真机测试管理

在做现网真机测试之前，可以添加测试用户进行真机测试。如果您已经添加过测试用户，请跳过本章节。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155205.79396395697061911406586071505916:50531106021631:2800:712EF9BE09BBCEB1C98E133A48E24BF4C941167E0F804150B995F3F747EEE739.png?needInitFileName=true?needInitFileName=true)

当指定了测试用户执行真机测试后，在服务中心打开开发者测试开关，可以在服务中心体验到当前服务在现网的效果。

     1. 登录[HarmonyOS服务开放平台](https://developer.huawei.com/consumer/cn/console#/openCard/FastService/63)，单击“通用管理”。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155205.52727820530318322874871871505257:50531106021631:2800:16D86797357A1F133D5B57B4AEB1CE34233414B0D5E03531F517F6C08990ACA0.png?needInitFileName=true?needInitFileName=true)

     2. 在左侧导航栏单击“真机测试管理”，进入真机测试管理页面。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.02514038324489315530635204729242:50531106021631:2800:CE1DB9C2CA4CC78C91581BBC34EF9C2662052AE8D2BF77C53205BD6AFC3D853C.png?needInitFileName=true?needInitFileName=true)

     3. 单击“新增组”，填写组名后确认保存。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.45022883149052255399861109597575:50531106021631:2800:46F3B833323E7B5606937A9E6789335C4096A8B128D5A30C0D743C4960C2EB4D.png?needInitFileName=true?needInitFileName=true)

     4. 单击用户组列表中的“查看”操作，用户组下的用户列表。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.52060439557253934501098380414213:50531106021631:2800:5D0A87E12B0B766F7A28C17272A5B2A2B34B0B7FC970DD0C8D64C3A48755C99D.png?needInitFileName=true?needInitFileName=true)

     5. 单击“添加用户”，填写用户信息后确定。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20221026155206.56031621288596191512482400474962:50531106021631:2800:D9155CD28DE7FDB7FF5C228B7161466F95A5ED9F5C1FCE023753A7D631BA5225.png?needInitFileName=true?needInitFileName=true)

参数 | 说明  
---|---  
帐号类型 | 帐号类型可选手机号码和邮箱两种。  
手机号码 | 当帐号类型选择为手机号码时，填写手机号码。您在此填写的手机号码仅用户调用华为帐号系统获取该帐号的UID，不会被服务器存储。  
邮箱 | 当帐号类型选择为邮箱时，填写邮箱地址。您在此填写的邮箱地址仅用户调用华为帐号系统获取该帐号的UID，不会被服务器存储。  
帐号描述 | 填写帐号描述信息。
