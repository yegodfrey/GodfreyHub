# 原子化服务分发的终端

服务接入HarmonyOS服务开放平台后可以分发到“1+8+N”泛终端、全场景中，为用户提供自然交互的贴心服务。

“1”代表手机

“8”代表平板、智慧屏、音箱、眼镜、手表、车机、耳机、PC

“N”代表移动办公、智能家居、运动健康、影音娱乐及智能出行各大板块的延伸业务

举例：天气服务接入HarmonyOS服务开放平台后，通过智慧语音的流量入口可以分发到手机、平板、智慧屏、车机以及手表等设备上。
