# 订阅健康和健康研究

     1. 服务在健康、健身和医疗研究背景下收集的数据，不得因广告投放、市场营销等原因进行使用或向第三方披露。除非通过相关政府管理机构的审核及批准，并出于改进健康管理或健康研究的目的而使用；服务可以使用用户的健康或健身数据直接向该用户提供权益(如保费减免)，前提是服务须由提供相应权益的实体提交，且前述数据不得与第三方共享。同时，服务必须向用户清楚说明将从设备收集的具体健康数据并获得用户明示同意。
     2. 不得将虚假或错误数据写入任何具有医疗研究/健康管理属性的服务。
     3. 开展健康领域人体研究的服务应获得参与人员提供的知情同意书，如果涉及未成年人，则必须获得由其家长或监护人提供的知情同意书。知情同意书必须涵盖：(a)研究的性质、目的和时长；(b)具体规定与流程，给参与人员带来的风险和益处；(c)关于保密和数据处理(包括与第三方共享信息的情况)的信息；(d)用于回答参与人员问题的联系人；以及(e)退出流程。
     4. 用于开展健康领域人体研究的服务，应获得相关政府管理机构的审核及批准并向原子化服务平台提供前述批准相关的证明文件。
