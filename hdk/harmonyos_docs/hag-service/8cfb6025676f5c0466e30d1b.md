# 智慧视觉

**功能介绍**

通过手机扫图或扫码的方式触发原子化服务。

**服务示例**

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220921110806.54874964919008111729400440903734:50530920060115:2800:DBB6976A741BC9A5EB324B8ECE290B634B234F949F190ACA4C44FE716BB71C7D.jpg?needInitFileName=true?needInitFileName=true)

     1. 【01页面】点击智慧视觉图标进入【02页面】
     2. 【02页面】点击功能图标开始自动识别，进入【03页面】
     3. 【03页面】点击服务卡片进入【04页面】服务详情页

**上线终端：** 手机、平板

**触发方式：** 扫图触发、扫码触发
