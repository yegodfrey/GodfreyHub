# 敏感个人信息

     1. 收集和处理用户敏感个人信息（如银行金融数据、医疗健康数据、个体生物特征等），应严格遵守相关法律法规及“本规范”，未经用户同意不得将其用于服务改进、投放广告或营销等非业务核心功能。
     2. 服务若涉及到处理用户的财产信息、付款信息或身份信息，除非提供相应服务所必需，否则不得向任何第三方披露。
     3. 服务使用第三方支付交易过程中，如非适用法律要求或为提供第三方支付服务所必需，不得记录用户交易类鉴权信息，或向第三方批露与用户特定交易无关的用户个人信息。
