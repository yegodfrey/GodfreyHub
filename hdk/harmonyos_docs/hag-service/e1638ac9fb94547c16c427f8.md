# 概览

HarmonyOS作为新一代的智能终端操作系统，为不同设备的智能化、互联与协同提供了统一的语言，带来简洁、流畅、连续、安全可靠的全场景交互体验。HarmonyOS正在联动世界、构筑全场景智能生活体验，同时为原子化服务所有者、开发者和运营者(以下统称“原子化服务商”）提供崭新机遇。原子化服务商提供的原子化服务（下称“服务”），经过审核后即可接入原子化服务平台，并参与到HarmonyOS生态体系中，实现一次接入、多端分发。为帮助原子化服务商明确知晓各项审核要求、快速流畅完成审核流程，特围绕以下方面制定《原子化服务上架规范》（下称“本规范”）。

**为帮助您尽可能顺利地通过审核，请在提交审核前确认以下常见问题：**

     1. 确保所有服务信息完整且正确，不得关联至原子化服务商不具有完整合法权益或不具备完整授权的网站、应用程序、产品或服务等。
     2. 确保服务运行不会发生崩溃或错误。
     3. 原子化服务商需保证提供给原子化服务平台所有信息的真实性、准确性、完整性，包括但不限于公司名称、法定代表人姓名、公司地址、联系电话、电子邮箱等。信息如有变更需及时更新、确保您的联系信息真实有效，以便审核团队在需要时与您取得联系。
     4. 确保提供有效的演示帐户和登录信息，以及审核时所需的任何其他硬件或资源 (例如，特殊配置或特殊测试环境所需的相关资源或信息需备注清楚)。
     5. 确保服务审核期间可用，以使其在审核期间处于活动及可访问状态。
     6. 确保服务遵循相关规范。原子化服务平台鼓励原子化服务商进行创新，不允许重复注册、提交2个及以上页面、内容、功能相同或同质化严重的服务。同时，原子化服务商应避免注册或提交与已有的服务相同或类似的服务，保障服务之间相互具有区别性和不可替代性，避免造成混淆、影响用户体验，使服务的帐号资源得以合理、高效、高质使用。
     7. 服务应选择正确的语言和正确的终端设备适配类型。
     8. 原子化服务商不得针对特定教育阶段、景点、地区等场景的不同适用版本而提交多个服务，应优化合并提交同一个服务。

**注释：**

     1. 服务的上架操作和服务上架后的运营行为，必须严格遵守本规范及《原子化服务管理及下架规范》。
     2. **原子化服务所有者：** 提供此服务的组织或个人，对该服务负主要责任；**原子化服务开发者：** 在服务整体开发环节，原子化服务平台审核通过的实名注册开发者；**原子化服务运营者：** 负责服务上架后整体运营行为的运营者。原子化服务所有者、开发者和运营者三方对其提供的服务承担连带责任。
     3. 不同类别的服务卡片设计尺寸、样式，可参考本规范**服务信息和卡片-原子化服务卡片设计示例** 的有关规定，原子化服务商可根据自身服务所属类别进行对应参考设计、以保持同一类别服务卡片的一致性；也可根据自身服务卡片的特质进行个性化设计。
