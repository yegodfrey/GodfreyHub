# 碰一碰/扫一扫  
  
**功能介绍**

设备具有NFC标签，手机通过“碰一碰”或“扫一扫” 识别设备上的NFC标签，即可运行相应的原子化服务。

**服务示例**

用户拿出华为手机“碰一碰”蒸烤料理机，手机将自动跳转到相应的原子化服务页面，显示蒸烤料理机的配网界面或者控制界面。用户在手机侧即可操作设备，比如在控制界面选择系统推荐菜谱，体验自动烹饪等功能。
