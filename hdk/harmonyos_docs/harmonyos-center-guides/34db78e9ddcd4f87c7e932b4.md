流水线场景使用命令行工具sdkmgr下载Linux SDK失败  **问题现象** 在Linux上使用命令行工具sdkmgr时，如果提示“Failed to request URL https://devecostudio-dre.op.hicloud.com/sdkmanager/v5/hos/getSdkList”。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/BOb9J0zvT7Ca5zvDSunN1A/zh-cn_image_0000002623377623.png?HW-CC-KV=V1&HW-CC-Date=20261005T053117Z&HW-CC-Expire=86400&HW-CC-Sign=A2B657567CE2F6FF1F8854AA0A400B81D9D493A54EE6E2C992B9D85484C22E86) **解决措施** 该问题通常是因为Linux的国家码未设置为中国区。
    1. 进入sdkmgr所在的目录。
           
           cd ${命令行工具根目录}/sdkmanager/bin

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/oLxH-c7ESViLAQ1KjE6iMw/zh-cn_image_0000002592938132.png?HW-CC-KV=V1&HW-CC-Date=20261005T053117Z&HW-CC-Expire=86400&HW-CC-Sign=95BAE5BB18BC2AD1C4284072CB9386A1AF07FD71F2EE2F09B4A46D88783319C7)
    2. 打开sdkmgr文件。
           
           vim sdkmgr

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9f/v3/WURjQAP6QCe5APJUvmJv3g/zh-cn_image_0000002592778204.png?HW-CC-KV=V1&HW-CC-Date=20261005T053117Z&HW-CC-Expire=86400&HW-CC-Sign=729907047F3248E74C05B597257887D59E15F19548CCA5ADDF9478C466EA7EA6)
    3. 在sdkmgr文件的最后一行“-Dfile.encoding=UTF-8”后添加国家码“-Duser.country=CN”。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/7YqbfZicQaK0HZ00QPZ04g/zh-cn_image_0000002623217761.png?HW-CC-KV=V1&HW-CC-Date=20261005T053117Z&HW-CC-Expire=86400&HW-CC-Sign=BB3B108F743384297657D41D548086477328DEE67DB93931FB02297FC938DD58)
    4. ​保存修改后，再次执行sdkmgr相关命令即可正常下载Linux SDK。
