编译报错“CMake task execution failed” **错误描述** CMake任务执行时提示“CMake task execution failed”错误信息。 **可能原因** 需要手动删除 .cxx 目录，并在 build-profile.json5 文件的 arguments 字段中添加 “--version” 参数。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/MuKfFHk_ScS5JwbVv2ol7A/zh-cn_image_0000002592938050.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=C772013050AF57F7CAD41489EE8EB87CE47E4E52389F0813C1BDACFB4724DE9C) **解决措施** 移除arguments字段中的“--version”参数。
