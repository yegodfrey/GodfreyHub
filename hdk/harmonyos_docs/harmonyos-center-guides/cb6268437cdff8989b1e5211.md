如何解决DevEco Studio左侧加断点的区域消失，无法加断点的问题  点击Main Menu > File > Settings，进入Editor > General > Gutter Icons，勾选Show gutter icons以启用该功能。具体如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/MldAW3zCTbyjGZwB2D6LQA/zh-cn_image_0000002623217655.png?HW-CC-KV=V1&HW-CC-Date=20261005T053055Z&HW-CC-Expire=86400&HW-CC-Sign=C803672EF1860AFC8E02D38323863A7DD63417E5CA1DCF7836FD532010EE8D45)
