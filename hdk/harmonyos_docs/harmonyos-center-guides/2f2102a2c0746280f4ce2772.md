元服务API 9和API 11有什么区别，如何升级到API 11？ ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/86/v3/Pzi3OSGIT2qga2hAuwosIQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T053135Z&HW-CC-Expire=86400&HW-CC-Sign=EEB769907AF333CF52FBB0340E4CB1AD76920B35B46797B7262139C76673824B) 请避免基于API 9进行元服务开发。
    1. 元服务API 9和 API 11的区别：
       * 兼容性：API 9仅支持 HarmonyOS 4.0及以下版本，而无法在 HarmonyOS NEXT及以上版本上运行。API 11包含了HarmonyOS NEXT元服务所需的全部 API集。
       * 功能性：API 11引入了更多功能和改进，确保元服务在最新的HarmonyOS环境中高效运行和兼容新特性。
    2. 如何升级到API 11：请参考官方开发者网站，下载最新的[开发工具套件](https://developer.huawei.com/consumer/cn/download/)。
