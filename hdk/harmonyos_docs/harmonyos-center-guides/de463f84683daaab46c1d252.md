编译报错“Duplicate 'Module-Abilities' object names detected.” **错误描述** Module-Abilities对象名称重复。 **可能原因** 依赖的HAR模块中module.json5的abilities数组中存在重复的ability对象名称。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/ig_0RvEkQuiE9VTCEZi1_A/zh-cn_image_0000002592777932.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=12A724138D116C94067B0ECCB9AE1BDF2A6D5503EB1AB70E44E73C701435DBB4) **解决措施** 检查依赖的HAR模块在module.json5文件中的abilities字段，确保每个ability的name唯一。
