编译报错“Cannot resolved import statement” **错误描述** 在编译过程中，提示“Cannot resolved import statement”错误信息。 **可能原因** 导入文件时，大小写不一致会导致问题（导入到单个文件夹时，默认寻址小写 “index.ets”文件，但该文件夹下仅存在大写“index.ets”文件）。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/UaqNN_16R5CB5ydMjPbuzQ/zh-cn_image_0000002623377491.png?HW-CC-KV=V1&HW-CC-Date=20261005T053103Z&HW-CC-Expire=86400&HW-CC-Sign=2F57D4B288FA31E07CC70F909F10640F5C1D754AFE68A399B39AD5DA480F87B9) **解决措施** 检查import文件的大小写。
