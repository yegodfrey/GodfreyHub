应用/服务的启动界面信息缺失，提示“Schema validate failed”报错 **问题现象** 在工程同步或编译构建时，出现“Schema validate failed”的错误提示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/E3iv_Jz7SbulxEr_aZNkQQ/zh-cn_image_0000002592938004.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=0A1682EB81C72C3140C862625A4F9590178165F06CAC93AE07B24334BC0013A0) **解决措施** 在开发应用/服务时，创建工程后，默认设置了启动界面信息。如果开发者误删其中某个字段，将导致报错。下面以重新设置启动界面信息为例，为提高冷启动性能，可以通过以下方式设置启动界面的图标和背景颜色。
    1. 在模块的**resources > base > element**目录下，右键点击并选择**New > Element Resource File**来创建资源文件。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/YlEh940gTIqhL5D43A9DvA/zh-cn_image_0000002592778080.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=DCD30CAE3A1E54B0C8E328CD02B8FF90DA6B27BBE56AE604888B6FFA5C057BB5)
    2. 在弹出的对话框中，开发者可以自定义“File name”，例如 color；“Root element”请选择 **color** 。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/hciHP89zTfas2MCQUS3YjA/zh-cn_image_0000002592938002.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=D26888916FC4309D36D20565E4DD77834CB5C174FD2D9B1160B5DC0FC04A4425) 创建完成后，color.json文件如下图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/UjHKOibETqKiCyjVeKQkHw/zh-cn_image_0000002623217635.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=E2941C64F76A49F21953A28A21A58EBDC87B5C45741182FE732E3BAC2A196A86)
    3. 将2创建的color.json文件拷贝至模块的**ohosTest > resources > base > element**目录下。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/41ZlewLeQUe6Lw-lhwJ40Q/zh-cn_image_0000002623377501.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=2C562A745CD3DB1FF80383F983BFC0051B65A7E8D74A29EACCAB630BB3C465D6)
    4. 在模块的**src > main > module.json5**文件的abilities数组中，添加startWindowIcon和startWindowBackground字段。若缺少任一字段，将出现ERROR: Schema validate failed报错。startWindowIcon字段索引模块下**resources > base > media**中的图标资源，startWindowBackground字段索引**resources > base > element > color.json**中的颜色。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b6/v3/0KSsMjBUSRON4n1JcFrfnQ/zh-cn_image_0000002623377499.png?HW-CC-KV=V1&HW-CC-Date=20261005T053105Z&HW-CC-Expire=86400&HW-CC-Sign=593E0A9083124072188FAB39C89A4DDF74C23F43DA7684A2B20B3EF972FC4FF4)
    5. 在**src > ohosTest > module.json5**文件的abilities数组中，添加startWindowIcon和startWindowBackground字段。其中，startWindowIcon字段引用模块ohosTest下 **resources > base > media**中的图标资源，startWindowBackground字段引用 **resources > base > element > color.json**中的颜色。
