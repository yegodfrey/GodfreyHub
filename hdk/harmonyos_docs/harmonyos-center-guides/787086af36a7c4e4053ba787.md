Target AOT编译，AP文件生成失败 **问题现象** Target AOT编译，AP文件生成失败，并报错提示“errno: 13”表示权限不足，如下图所示。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/jItFBTsNRj2UvSARQi74HQ/zh-cn_image_0000002623217709.png?HW-CC-KV=V1&HW-CC-Date=20261005T053108Z&HW-CC-Expire=86400&HW-CC-Sign=054CA07493F391DDDA52FD963DE87C86A7D5B097C83D96467E92981A8DF358F2) **解决措施** errno: 13表示权限不足，请通过下述措施解决： 打开命令行工具，输入以下命令，关闭selinux权限管控。
    
    hdc shell
    setenforce 0

以上设置重启将会失效，若设备重启请重新进行以上设置
