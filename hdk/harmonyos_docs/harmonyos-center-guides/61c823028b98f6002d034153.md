无法调试，DevEco Studio提示“ The target can not be empty. Check the build-profile.json5 file of the project root directory and make sure the targets of the modules in configuration is set to specified product: default in applyToProducts.” **问题现象** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/zgUkjHeOQIaNxKkoRzcwaA/zh-cn_image_0000002623377467.png?HW-CC-KV=V1&HW-CC-Date=20261005T053109Z&HW-CC-Expire=86400&HW-CC-Sign=143DC286807AB0627B38FBB2CB19034F02161CDB5E5B87E843C035E1915D8067) **问题分析** 报该错误，可能是build-profile.json5文件中未添加“targets”配置，Module Target下为空，工程同步失败。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/vRUZjGXyRpmbuOvftV_dCA/zh-cn_image_0000002592937968.png?HW-CC-KV=V1&HW-CC-Date=20261005T053109Z&HW-CC-Expire=86400&HW-CC-Sign=781B68E5008B03153CA9A4964E0DA5CF896DCA680BF6C258A7BD814921B8EB25) **解决措施** 需要在模块级build-profile.json5文件中添加“targets”配置，点击“Sync Now”，待完成同步后，即可解决该问题（确保工程同步成功）。具体配置如图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/RvpkpN7yRmuSJCMo0tE8aw/zh-cn_image_0000002623217601.png?HW-CC-KV=V1&HW-CC-Date=20261005T053109Z&HW-CC-Expire=86400&HW-CC-Sign=CAB9C717411E955C6DA19E52A6AAA49CB455F7A06E13DBABFC3CA0F9662CE329)
