编译时DevEco Studio报错App Launch: To run and debug the Harmony device, configure the HarmonyOS runtime  **问题现象** ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/cKRSh6RKRgq7PbIO4ptr4g/zh-cn_image_0000002623377455.png?HW-CC-KV=V1&HW-CC-Date=20261005T053109Z&HW-CC-Expire=86400&HW-CC-Sign=858722E652ECD1907A46D4C51048D06F61547E25B7FD7C1DDF0199411C1D428B) **解决措施** 修改build-profile.json5文件，登录个人华为账号，然后重新签名。
    1. 将根目录下的build-profile.json5文件里的 "runtimeOS": "OpenHarmony" 改成 "runtimeOS": "HarmonyOS"；
    2. 点击 File > Project Structure > Signing Configs 进行签名配置；
    3. 勾选“Support HarmonyOS（支持HarmonyOS）”和“Automatically generate signature（自动签名）”；
    4. 点击“Sign In”按钮；
    5. 登录华为账号，按提示在弹出的登录页面输入手机号并使用验证码登录。
