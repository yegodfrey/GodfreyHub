Mac安装Python不修改环境变量 1\. 下载官方Python Mac系统安装包，推荐使用 [3.11.7](https://mirrors.huaweicloud.com/python/3.11.7/python-3.11.7-macos11.pkg)。 2\. Mac版本自定义安装可以不修改环境变量，请查看文档：[在 macOS 上使用 Python](https://docs.python.org/zh-cn/3/using/mac.html)不勾选UNIX command-line tools和shell profile updater。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/PKd-2qYARN298FHXzgfOQg/zh-cn_image_0000002592778154.png?HW-CC-KV=V1&HW-CC-Date=20261005T053047Z&HW-CC-Expire=86400&HW-CC-Sign=D12E651432701D7EB0A810445F9D97D645E86FFE24B422BE80ED4D96CFB434DF) 3\. 关闭DevEco Studio修改other.xml配置 。  
      
    cd ~/Library/Application\ Support/Huawei/DevEcoStudio6.0/options
    
    vi other.xml

输入： /python，定位到location.python.path这一行, 修改后面的python路径为/Library/Frameworks/Python.framework/Versions/3.11/bin ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/7gDwbaH8SI65gQJ8VsJoOA/zh-cn_image_0000002623377573.png?HW-CC-KV=V1&HW-CC-Date=20261005T053047Z&HW-CC-Expire=86400&HW-CC-Sign=08993555E5A3D9236FCFF448079E672C2F4DB40C1415CB540A25DCA9E0CBE65A)
