应用运行报错：hap path error **问题现象** 启动调试或运行应用/服务时，应用运行崩溃，提示错误信息“errorMsg: hap path error”。 **解决措施** 如果依赖的应用包未安装，建议进入**Run/Debug Configurations > Deploy Multi Hap****/Hsp** 页签，勾选**Deploy Multi Hap/Hsp Packages** ，选择所需依赖的应用包，然后重新运行应用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/nJHsT05zSxqYPn7tQkS6VA/zh-cn_image_0000002592937850.png?HW-CC-KV=V1&HW-CC-Date=20261005T053042Z&HW-CC-Expire=86400&HW-CC-Sign=2D4369460AEDC00083E65130C0AB06740DB7EF83B66E1643C129FF4A26CA5A27)
