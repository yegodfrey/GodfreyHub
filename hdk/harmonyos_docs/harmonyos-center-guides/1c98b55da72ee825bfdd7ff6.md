安装HAP时提示“error: failed to start ability” **问题现象** 启动调试或运行应用/服务时，如果安装HAP出错，提示“error: failed to start ability. error: ability visible false deny request”，请检查应用的可见性设置。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/BfCDDflwRlWSJKTxTm3mtQ/zh-cn_image_0000002623217535.png?HW-CC-KV=V1&HW-CC-Date=20261005T053041Z&HW-CC-Expire=86400&HW-CC-Sign=1CFB8C0D97694DF09FEECA9F532E40C94C9A4D728F796AC50AA9707695A02B4C) **解决措施**
    * 在Stage模型工程的module.json5文件中，将abilities字段内的exported设置为true。
    * FA模型工程：在config.json文件的abilities字段中，将visible设置为true。
