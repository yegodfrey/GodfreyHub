DevEco Studio中是否有一键检查未引用资源的功能  DevEco Studio中有一键检查未引用资源的功能，在DevEco Studio中点击菜单：Code > Analyze Code > Run Inspection by Name或使用快捷键Ctrl+Alt+Shift+I，在选项框输入Unused resources，即可进行资源检查。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/pLg7Taz3S8K6CKSQ5Ptdbw/zh-cn_image_0000002623217471.png?HW-CC-KV=V1&HW-CC-Date=20261005T053055Z&HW-CC-Expire=86400&HW-CC-Sign=B45312A407C186F757A8A93E596F671D697D27353ED569B6045BB3B61915E1DC)
