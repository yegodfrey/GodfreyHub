如何通过hdc命令唤醒设备和查看屏幕状态  唤醒设备：hdc shell power-shell wakeup。 查看屏幕状态：hdc shell hidumper -s 3301 -a 查询手机IMEI：首先，进入fastboot模式（hdc target boot bootloader），然后使用fastboot命令查询（fastboot oem get-psid）。
