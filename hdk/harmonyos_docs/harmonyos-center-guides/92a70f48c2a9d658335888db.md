编译报错“keystore password was incorrect” **问题现象** 编译时出现错误，提示“ERROR - hap-sign-tool: error: ACCESS_ERROR, code: 109. Details: Init keystore failed: keystore password was incorrect”。请检查密钥库密码是否正确。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1a/v3/u0QnEP99T9eQtMMWDaeQGA/zh-cn_image_0000002592778214.png?HW-CC-KV=V1&HW-CC-Date=20261005T053107Z&HW-CC-Expire=86400&HW-CC-Sign=9823C04F27B4AAEC6090F4FDAC67ACFB47B4ED050ADA2C6F85A236A1462D4925) **报错原因** 密钥库(p12)的密码错误。签名文件中的签名密码错误导致该问题出现。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e6/v3/9FfKCqtvTvmYlDXs-xKdRQ/zh-cn_image_0000002623377635.png?HW-CC-KV=V1&HW-CC-Date=20261005T053107Z&HW-CC-Expire=86400&HW-CC-Sign=97FFAF1684512CB002A8788F4FC3599AB7F037D9D17EFB9E1E5F7923654AB65D) ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/U011NFZtSQieykf5O1GoXw/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T053107Z&HW-CC-Expire=86400&HW-CC-Sign=5560958B638927B11D7A7E9E22232752672326D73807EE3BC07D8AC5A8EFAF8C) 密钥库密码和密钥密码在创建p12文件时由开发者输入，请牢记这些密码。build-profile.json5文件中记录了密码的密文，但签名工具需要输入密码明文，不能直接使用build-profile.json5中的值。 **常见场景**
    1. 密码输入错误。
    2. 在命令行中输入了密文。
    3. 密钥（keyAlias）密码和密钥库（p12）密码混淆。
**解决措施** 重新自动签名可以解决该问题： 1\. 点击**File > Project Structure > Project > Signing Configs**，打开签名配置页面。 2\. 勾选“Automatically generate signing”（如果是HarmonyOS工程，还需勾选“Support HarmonyOS”），等待重新签名，点击**OK** 。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/6q1GnNqKQMqqKtp_YxNDXA/zh-cn_image_0000002592938142.png?HW-CC-KV=V1&HW-CC-Date=20261005T053107Z&HW-CC-Expire=86400&HW-CC-Sign=F676521C9CE186572828673C7B0C79275D1454DBB942E375407B184D8DEF89AE)
