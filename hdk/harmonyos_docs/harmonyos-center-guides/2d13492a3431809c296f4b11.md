录制Allocation模板时，Memory泳道和Native Allocation泳道内存不一致 **问题现象** 录制Allocation模板时，Memory泳道和Native Allocation泳道内存不一致。 **可能原因** Memory泳道内是所选择应用的实际物理内存占用（Proportional Set Size, PSS），Native Allocation泳道展示的是应用在运行过程中动态向操作系统申请的虚拟内存，并不代表实际物理内存占用。 **解决措施** 开始录制前，单击工具控制栏中的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9/v3/KelCEeeNTGuIeeyyingLyw/zh-cn_image_0000002592778178.png?HW-CC-KV=V1&HW-CC-Date=20261005T053137Z&HW-CC-Expire=86400&HW-CC-Sign=6298A22CB7819115EC29D4FEE8F21AFA1E731B675C8535C02D6119F02F3B18B5)按钮，设置最小跟踪内存（Native Allocation Filter Size）为0或极小值，以采集更多甚至全量的虚拟内存分配事件，让Native Allocation泳道与Memory泳道的数据变化量接近。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/2ieV1QzCQTCbuBNg6zUYUw/zh-cn_image_0000002623217735.png?HW-CC-KV=V1&HW-CC-Date=20261005T053137Z&HW-CC-Expire=86400&HW-CC-Sign=6B4D1991DFB629582DCA310278BEA8FDB72D2C0968702AA516F6FE04B7AE3DA3)
