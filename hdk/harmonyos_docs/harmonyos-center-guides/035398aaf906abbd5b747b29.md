如何给新增的module在线签名 操作步骤：
    1. 连接真机设备，确保[DevEco Studio与真机设备已连接](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-run-device)，真机连接成功后如下图所示：![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/O9Q8AMKxRzGX0onYvDxX6w/zh-cn_image_0000002623377489.png?HW-CC-KV=V1&HW-CC-Date=20261005T053110Z&HW-CC-Expire=86400&HW-CC-Sign=25BCBF3AF707DE07D108947275939F9A12D4C7BB39DD32A040F413BA43EAD00D)
    2. 进入 File > Project Structure... > Project > Signing Configs 界面，勾选“Automatically generate signature”。如果是 HarmonyOS 工程，还需勾选“Support HarmonyOS”。若未登录，请先单击 Sign In 进行登录，然后完成签名。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/FOr16pCWSJypWf3_iHtrww/zh-cn_image_0000002592778070.png?HW-CC-KV=V1&HW-CC-Date=20261005T053110Z&HW-CC-Expire=86400&HW-CC-Sign=675937871FD057B9A13B8D0D3D4348572DD6D58E7BF01BE0951F3BF2C020C92F) 签名完成后，如下图所示： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/RYirOr2-SVSOeF92c_Sd_w/zh-cn_image_0000002592937992.png?HW-CC-KV=V1&HW-CC-Date=20261005T053110Z&HW-CC-Expire=86400&HW-CC-Sign=F57DC14C1657C6A73F547DD3DCA4FCCAFC5439D673D00C895C9B4FB5BA324732)
