如何解决搭建流水线时commandline-tools-linux中sdkmgr下载开发包报错  **问** 使用 commandline-tools 工具在 Linux 上时，如果提示“Failed to request URL https://devecostudio-dre.op.hicloud.com/sdkmanager/v5/hos/getSdkList”，请检查网络连接是否正常，确保可以访问该 URL。如果网络无问题，尝试更新 commandline-tools到最新版本。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/31/v3/Uc2JpbvYTk6uJra6qG4UKw/zh-cn_image_0000002623377391.png?HW-CC-KV=V1&HW-CC-Date=20261005T053112Z&HW-CC-Expire=86400&HW-CC-Sign=DD3681C16C00B2FD29FD5C0B36FDDB661C64FDD31F15C6FF0870AE024BE9E6A8) **解决措施** 该问题通常是因为Linux的国家码未设置为中国区所致。 请参考以下方法解决：
    1. 进入sdkmgr脚本所在的文件夹：${命令行工具根目录}/sdkmanager/bin。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/V9H97znuQHa0C7vwtvRijA/zh-cn_image_0000002592937890.png?HW-CC-KV=V1&HW-CC-Date=20261005T053112Z&HW-CC-Expire=86400&HW-CC-Sign=6243ED2BAE4B02D5EFFAD91CF78872B059B729E8DB983C78A851A2025D5E6E9F)
    2. 打开sdkmgr文件。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/MGwKCyhVQN-jGfy8Dq7D3w/zh-cn_image_0000002592777972.png?HW-CC-KV=V1&HW-CC-Date=20261005T053112Z&HW-CC-Expire=86400&HW-CC-Sign=1ED044CF188BCC94931ED35F8816D7F06E467F6C6C890C60CF3F21CD726075A9)
    3. 在文件的最后一行，-Dfile.encoding=UTF-8 后面添加 -Duser.country=CN。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/nc6UfA76SVKjANeNJUcAcw/zh-cn_image_0000002623217523.png?HW-CC-KV=V1&HW-CC-Date=20261005T053112Z&HW-CC-Expire=86400&HW-CC-Sign=45C2BA2F4DC247B55039204D31ADFDA41BE8A123B24373B8D5E2016FEA214E57)
    4. 保存修改，再次执行sdkmgr相关命令即可。
