# SearchKeySubTask

|参数|必选(M)/可选(O)|类型|描述|
|:------------------|:----------|:-----|:----------------------------------------------------------|
|subTaskId|O|Long|子任务ID，修改字词溢价子任务时，此字段必填。|
|subTaskPrice|O|Double|子任务出价，新增字词溢价子任务时，此字段必填。|
|subTaskKey|O|String|子任务搜索词,新增字词溢价子任务时，此字段必填。|
|subTaskKeyMatchType|O|String|字词匹配方式，新增字词溢价子任务时，此字段必填。 取值范围： * ACCURATE：精确匹配 * FUZZY：广泛匹配|
