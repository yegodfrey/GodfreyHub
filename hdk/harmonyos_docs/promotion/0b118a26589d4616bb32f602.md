# 术语介绍

|术语|详细描述|
|:-----------|:----------------------------------------------------------------------------------------------------------------|
|客户端 ID|鲸鸿动能广告平台Marketing API 客户端ID。|
|密钥|每一个客户端对应的密钥（用于后面获取access_token）。|
|scope|广告主授予的权限列表。|
|redirect_uri|授权后回调的URI，用于接收Authorization Code。|
|access_token|使用/oauth2/v2/token接口会同时获得access_token。access_token是调用API接口的调用凭证,用于服务端对API请求鉴权，默认有效期为1小时，一旦access_token失效，则需要重新获取。|
