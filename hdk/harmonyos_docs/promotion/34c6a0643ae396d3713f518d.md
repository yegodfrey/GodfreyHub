# 投放管理平台介绍

## 应用市场应用推广"单权限客户"

指只具备应用市场应用推广权限的开发者，登录投放管理平台的所有页面仅可查看、使用应用市场应用推广的相关数据和投放能力。

您可以在"工具------广告账户管理------账户辅助------认证中心"拓展推广范围。

## 应用市场应用推广和鲸鸿动能广告"双权限客户"

开发者应用同时具备应用市场应用推广和鲸鸿动能广告推广权限（均有开通广告账户并具备推广权限的开发者）。

管理平台所有页面可以通过"投放网络"，分别查询应用市场应用推广和鲸鸿动能广告展示广告网络的投放任务数据。
