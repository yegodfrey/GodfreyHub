# 新建人群定向任务

1. 登录[华为应用市场应用推广平台](https://ads.huawei.com/cn/)，点击"推广"页签。
2. 点击"创建任务"，进入创建任务页面。 说明
   >
   > 任务信息按需填写，详细步骤可参照：[推荐任务操作步骤](https://developer.huawei.com/consumer/cn/doc/promotion/bp-delivery-task-recommend-0000001337110797#section931210367197)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/6_7rpRCJSO6iWU9IY1yx6w/zh-cn_image_0000002524897788.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3E7B7F45D304B90159A6B9FA3F007C665DB52CC375C521D216B01DCCE59D1BF8)
3. 在"场景投放"设置模块，点击子任务的操作按钮"编辑"，进入页面：新建用户定向任务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/760lsbpQQzeqg_DhRvxo8w/zh-cn_image_0000002556097707.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=DD673B4DCEE3DD91643407A18F4BCD000EDE109CCDE75B1460692E6DDBE4C6D0 "点击放大")

   根据需要，新建标签定向包、文件定向包，或选择已有定向。新建的标签定向包、文件定向包，可同时保存到工具定向列表。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/08rX19_SRs6bCz2RMRaL1g/zh-cn_image_0000002525057790.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=6C6B1FDED5E3AE2758906BA0C604F71C51CFE3F3CE2E9BDDBEF8900D613EDCD8 "点击放大")
4. 以上设置模块均填写完毕后，点击"提交"，任务即可生效。
