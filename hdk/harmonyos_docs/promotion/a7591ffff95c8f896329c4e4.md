# 新建人群定向任务

1. 登录[华为应用市场应用推广平台](https://ads.huawei.com/cn/)，点击"推广"页签。
2. 点击"创建任务"，进入创建任务页面。 说明
   >
   > 任务信息按需填写，详细步骤可参照：[推荐任务操作步骤](https://developer.huawei.com/consumer/cn/doc/promotion/bp-delivery-task-recommend-0000001337110797#section931210367197)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/6_7rpRCJSO6iWU9IY1yx6w/zh-cn_image_0000002524897788.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=A8B068DB6BEE27642E03551CBB010B9EFB113078641F75D4C4643F67EEB3D7BC)
3. 在"场景投放"设置模块，点击子任务的操作按钮"编辑"，进入页面：新建用户定向任务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/760lsbpQQzeqg_DhRvxo8w/zh-cn_image_0000002556097707.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=18B08DCEEE8C34DA9113C9CF5BB4C23B1F1D66E14E5A78D5B27320E78EC16673 "点击放大")

   根据需要，新建标签定向包、文件定向包，或选择已有定向。新建的标签定向包、文件定向包，可同时保存到工具定向列表。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/08rX19_SRs6bCz2RMRaL1g/zh-cn_image_0000002525057790.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=CD82A1E27AB010C9C8AEADAA2D0C39F5ECE59D07F16710C442119670512EAB5B "点击放大")
4. 以上设置模块均填写完毕后，点击"提交"，任务即可生效。
