# 查询账户余额

【简介】查询广告主或者服务商账户的余额，包括现金、赠送、返利账户分别有多少钱和当日的支出数据。

新版查询账户余额接口差异点：

* 此接口替代openapi/v2/promotion/advertiser/account_balance/query接口

**请求地址**

https://ads.cloud.huawei.com/openapi/v2_1/promotion/advertiser/account_balance/query?user_service_type=ADS

**请求方法**

**GET**

**请求参数**

|-----------------|------|--------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|advertiser_id|long|否|广告主ID，使用经理账户登录或授权账号关联了多个子客账户时，此字段必填： 服务商登录时，可选填该字段 1、若一级一代服务商登录： i.传一级服务商一代直挂子客，则查询一级服务商一代直挂子客的余额 ii.传子客服务商直挂二代子客，则查询子客服务商直挂二代子客的余额 2、若子客二代服务商登录： i.传子客服务商二代直挂子客，则查询子客服务商二代直挂子客的余额|
|agency_id|long|否|服务商ID，服务商登录时，可选填写该字段 1、若一级服务商登录： i.传自身或不传，则查询一级服务商的余额 ii.传子客服务商，则查询子客服务商的余额 2、若子客服务商登录： i.传自身或不传，则查询子客服务商的余额|
|user_service_type|string|否|账户推广业务类型，不填默认查询ADS侧数据，详见[【账户推广业务类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section12306205591715)|

**响应字段**

|--------|---------|------|
|**参数名称**|**类型**|**描述**|
|code|string|返回码|
|message|string|返回描述|
|data|Struct1[]|返回数据|

Struct1定义

|--------------|----------|----------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**描述**|
|valid_balance|bigdecimal|可用余额|
|balance|bigdecimal|余额|
|consume|bigdecimal|当日支出金额|
|account_type|string|账户类型标识 详见[【资金账户类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section16745513560)|
|currency|string|币种|
|balance_detail|Struct2[]|余额详情|
|consume_detail|Struct3[]|当日支出金额详情|

Struct2定义

|-------------|------|-----------------------------------------------------------------------------------------------------------------------------|
|balance|string|余额|
|media_type|string|适用媒体范围 详见[【虚拟账户类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section416715287016)|
|valid_balance|string|可用余额|
|service_item|string|服务类型，详见[【服务类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section847382618013)|

Struct3定义

|----------|------|-----------------------------------------------------------------------------------------------------------------------------|
|media_type|string|适用媒体范围 详见[【虚拟账户类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section416715287016)|
|consume|string|支出金额|
