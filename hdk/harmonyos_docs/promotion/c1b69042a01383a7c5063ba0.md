# 修改定向包

【简介】通过此接口可以修改定向包。

请求地址

https://ads.cloud.huawei.com/ads/v1/tools/targeting_package/update

请求方法

POST

请求参数  

|--------------------------------|-------|----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|targeting_id|long|是|定向包ID 次留定向包不能编辑|
|targeting_name|string|否|定向包名称，最大长度不超过100|
|gender_struct|Struct2|否|性别定向，值为gender定向中的value 单选值，不支持复选 填充不限时value为UNLIMITED|
|age_struct|Struct2|否|年龄定向，值为age定向中的value 可同时选择不同年龄段的 填充不限时value为UNLIMITED|
|series_type_struct|Struct2|否|手机系列定向，值为series_type定向中的value， series_type_struct和device_price_struct不能同时选择 填充不限时value为UNLIMITED|
|device_price_struct|Struct2|否|设备价格定向，值为device_price定向中的value， series_type_struct和device_price_struct不能同时选择 填充不限时value为UNLIMITED|
|network_type_struct|Struct2|否|网络类型定向，值为network_type定向中的value，可以复选 填充不限时value为UNLIMITED|
|audience_struct|Struct2|否|自定义人群定向，值为pre_define_audience定向中的id; pre_defined_audience_struct和not_pre_defined_audience_struct选择的值不能相同 填充不限时value为UNLIMITED|
|not_audience_struct|Struct2|否|排除自定义人群定向，值为not_pre_define_audience定向中的id pre_defined_audience_struct和not_pre_defined_audience_struct选择的值不能相同 填充不限时value为UNLIMITED|
|current_geo_location_struct|Struct2|否|当前在这里的人（地理划分） 值为current_dmp_geo中的value 与自定义地理位置定向 current_custom_location_struct 不能同时选择 填充不限时value为UNLIMITED|
|current_level_location_struct|Struct2|否|当前在这里的人（发展划分） 值为current_level_geo中的value 与自定义地理位置定向 current_custom_location_struct 不能同时选择 填充不限时value为UNLIMITED|
|residence_geo_location_struct|Struct2|否|常驻在这里的人（地理划分）的值为current_dmp_geo中的value 与自定义地理位置定向 current_custom_location_struct 不能同时选择 填充不限时value为UNLIMITED|
|residence_level_location_struct|Struct2|否|常驻在这里的人（发展划分）的值为current_level_geo中的value 与自定义地理位置定向 current_custom_location_struct 不能同时选择 填充不限时value为UNLIMITED|
|current_custom_location_struct|Struct2|否|自定义地理位置定向 与地理划分，发展划分中的current_geo_location_struct current_level_location_struct residence_geo_location_struct residence_level_location_struct不能同时选择 填充不限时value为UNLIMITED|
|ai_target|Struct2|否|智能扩量 如果填值不为空，智能扩量开关ai_target_flag必须打开 取值详见[【智能扩量】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section3184194510)|
|ai_target_flag|string|否|智能扩量开关：开关打开ai_target字段如果不填就是默认突破 取值详见[【智能扩量开关】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section3590746181218)|
|feature_audience_struct|Struct2|否|细分受众 值为feature_audience的value 填充不限时value为UNLIMITED|
|app_category_of_media_struct|Struct2|否|投放媒体类型定向 value值如果需要选择所有的子节点的话，可以只传入父节点|
|not_app_category_of_media_struct|Struct2|否|投放媒体类型排除定向|
|content_id_struct|Struct2|否|内容ID定向，与内容标签不能同时出现，格式不能为中文，不能包含分号 填充不限时value为UNLIMITED|
|content_label_struct|Struct2|否|内容标签定向，与内容ID不能同时出现，content_label中的value 填充不限时value为UNLIMITED|
|brand_id_struct|Struct2|否|品牌门店定向 填充不限时value为UNLIMITED|

<br />

Struct2定义  

|----------|----------|----|------|
|参数名称|类型|是否必选|描述|
|value|string\[\]|是|定向选中的值|
|additional|string|否| |
