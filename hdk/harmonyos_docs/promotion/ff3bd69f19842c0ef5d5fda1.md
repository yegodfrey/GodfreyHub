# 查询维纳斯线索列表

【简介】广告主获取维纳斯平台的线索列表，线索来源于维纳斯落地页。

请求地址

https://ads.cloud.huawei.com/ads/v1/tools/landingpage/lead/query

请求方法

GET

请求参数  

|-------------|-------|----|------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|page|integer|是|搜索页码，大于等于1，默认值：1|
|page_size|integer|是|一页展示数量，取值范围 10\~50，默认值: 10|
|filtering|Struct|是|过滤条件|

<br />

filtering (Struct)定义  

|------------------|------|--|--------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|必选|描述|
|campaign_id|string|否|计划ID， 最大长度不得超50； 只能填写数字； 不能使用"\^"和换行；|
|adgroup_id|long|否|任务ID|
|creative_id|long|否|创意ID|
|lead_status|string|否|线索状态，详见[【线索状态】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1079462524412)|
|lead_type|string|是|线索类型，详见[【线索类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section148761437443)|
|created_begin_time|string|否|线索创建的开始时间， 格式如下: "yyyy-MM-dd HH:mm:ss"；|
|created_end_time|string|否|线索创建的结束时间， 格式如下: "yyyy-MM-dd HH:mm:ss"；|

<br />

响应字段  

|-------|-------|----|
|参数名称|类型|描述|
|code|string|返回码|
|message|string|返回描述|
|data|Struct1|线索列表|

<br />

Struct1定义  

|-----|-----------|----|
|类型|参数名称|描述|
|total|integer|总条数|
|data|Struct2\[\]|线索列表|

<br />

data (Struct2)定义  

|-----------------|------|--------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|描述|
|campaign_id|string|计划ID|
|adgroup_id|long|任务ID|
|creative_id|long|创意ID|
|landing_page_id|string|落地页ID|
|landing_page_name|string|落地页名称|
|landing_page_url|string|落地页地址|
|marketing_com_id|string|营销组件ID|
|lead_id|string|线索ID|
|lead_type|string|线索类型，详见[【线索类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section148761437443)|
|lead_status|string|线索状态，详见[【线索状态】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1079462524412)|
|created_time|string|线索提交时间|
