# 离线资产管理

## 功能简介

离线资产管理为有一方数据回传分析的客户，提供统一上传接口，并且一次上传即可实现多种业务场景。离线资产涵盖营销度量（转化跟踪）、联合建模、人群拓展，落地页事件上报等分析场景，可从根本上提升数据上传效率，更好地利用后向链路数据优化广告投放。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d4/v3/2awED8yjQ2uw8qC3QimxTw/zh-cn_image_0000001639974248.png?HW-CC-KV=V1&HW-CC-Date=20260928T100502Z&HW-CC-Expire=31536000000&HW-CC-Sign=184EDAA6E19F46F4C339EE8D096F1A78FA3148494AFC7300DBB5529522E9DA0A)

1. 营销度量（转化跟踪）：通过鲸鸿动能广告平台，利用科学的转化归因方法，将离线上传的事件归因至具体广告任务。
2. 联合建模：使用数据训练专属您的私有模型，帮您优化广告效果，提升广告跑量效果。
3. 人群拓展：使用数据作为种子人群进行人群拓展，生成可用于投放的人群包，需要在鲸鸿功能DMP中进行拓展操作。
4. 落地页事件上报：将不同状态的维纳斯落地页的线索ID离线上传。

## 操作步骤

**功能入口：**"投放平台"->"工具"->"投放辅助"->"离线资产管理"

2. 上传线索ID文件/设备ID文件。

   * 营销度量（转化跟踪）、联合建模、人群拓展，最多支持添加1个CSV文件，文件大小最大支持400M，内容行数不超过1000W。


   * 落地页事件上报最多支持添加1个CSV文件，文件大小最大支持10M,内容行数不超过5000。
   * 文件字段说明与场景说明：

   |----------|--------------|------|-------------------------------------|------------|----------|-------------|---------------|
   |**应用场景**|||设备ID/userId|时间/eventTime|价值分/Source|点击归因/callback|付费金额/paymentFee|
   |**设备ID文件**|**营销度量（转化跟踪）**|鲸鸿动能归因|OAID原值（idtype=1）|是|否|否|选填|
   |**设备ID文件**|**营销度量（转化跟踪）**|广告主归因|否|是|否|是|选填|
   |**设备ID文件**|**联合建模**||OAID原值（idtype=1）、SHA256OAID（idType=2）|否|是|否|否|
   |**设备ID文件**|**人群拓展**||OAID原值（idtype=1）|否|是|否|否|

   |-|-|-|-------------|
   |**应用场景**|||线索ID/（ClueID）|
   |**落地页事件上报**|||维纳斯线索ID|

   > 注意
   >

   > 2. 时间统一为时间戳上传格式
   > 3. 针对营销度量（转化跟踪）广告主归因场景，涉及到设备ID、设备ID类型，channel字段，该字段若无，可以传任意值，但不能传空值；鲸鸿动能归因场景，channel字段若无，可以传任意值，但不能传空值，callback字段可传空。
