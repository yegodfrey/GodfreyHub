# 选择创意优选

1. 创建或修改推广任务时，若该任务支持推广创意功能，勾选"编辑辅助创意"。 ![](https://media:801772778753712215 "点击放大")

2. 进入"推广创意"页面，在"创意展示模式"区域勾选"优选模式"或"轮播模式"，完成后点击"提交创意"。 ![](https://media:801772778753780216 "点击放大")
