# 快通知L档

快通知的轻量版，高性价比通道，平衡时效与成本，支持对时效要求宽松的大规模推送。

**开通快通知** **L** **档**

1、登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，登录后点击"开发与服务"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/y-Y8MKuDQ1OpyiJU7YeoWw/zh-cn_image_0000002557883945.png?HW-CC-KV=V1&HW-CC-Date=20261008T174743Z&HW-CC-Expire=31536000000&HW-CC-Sign=B92E484118EEE52E80159E574FD4577AB4F104C353E67D7E2487C449EF9C67A0 "点击放大")

2、选择你的项目，点击你的应用所在项目的卡片进入项目设置。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/6BrBwLyRRTm1uMgaYIKk7w/zh-cn_image_0000002527004058.png?HW-CC-KV=V1&HW-CC-Date=20261008T174743Z&HW-CC-Expire=31536000000&HW-CC-Sign=C5BECBAA0FD75BBBFD1C73208271B38F8B8C0CF8EE1595C7218B14CF5A9D9C85 "点击放大")

3、点击"项目套餐"页签，升级到付费档。

若之前未签署过开通协议，则弹出《华为AppGallery Connect付费服务协议》的界面，这是一个通用的服务协议，未包含快通知L档的具体内容。具体协议内容见另一附件"华为AppGallery Connect付费服务协议.pdf"。签署后进入"项目套餐"界面，点击"快通知L档-免费档"的右上方的"升级到付费档" 。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/azONxettTlGJZ3MJDitQNw/zh-cn_image_0000002526844098.png?HW-CC-KV=V1&HW-CC-Date=20261008T174743Z&HW-CC-Expire=31536000000&HW-CC-Sign=52D801C070FA071058D1B0A3D3B55AF9C331254C23D4929509BA2E9F78ABE24A "点击放大")

4、确认开通"快通知L档"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/i7mBaGZtRq-diTAdcT0mxg/zh-cn_image_0000002557883947.png?HW-CC-KV=V1&HW-CC-Date=20261008T174743Z&HW-CC-Expire=31536000000&HW-CC-Sign=D0EBD702297F7F9A1F278F761BEF78D817CCFB01EF2A4FC1F0C2A4A67F6F3997 "点击放大")

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/-dDXUSVtRpy6evbzeuXyhA/zh-cn_image_0000002526844100.png?HW-CC-KV=V1&HW-CC-Date=20261008T174743Z&HW-CC-Expire=31536000000&HW-CC-Sign=E1BB30AB2566C03743AF2E7477193AA742AE872875988141E9A66E4A6FC22CA8 "点击放大")

**发送快通知** **L** **档消息**

请使用下面的V5接口URL以及消息格式发送消息：

[https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References-V5/https-send-api-0000001050986197-V5](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References-V5/https-send-api-0000001050986197-V5)

快通知L档消息中需要携带business_type字段，值设置为4，示例如下：

```screen
{ 
    "validate_only": false, 
    "business_type": 4, 
    "message": { 
        "notification": { 
                "title": "11", 
                "body": "11" 
        }, 
        "token": [ 
                "token1" 
        ] 
    } 
}
```

说明：上述示例仅为了说明字段所处位置，非实际消息样例。

**计费与账单**

1、计费标准

Push快通知L档按调用次数计费，计费标准可在"项目套餐"-快通知L档的超额价格列查看：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e9/v3/es27YoSAThGeYJ87D_3QZQ/zh-cn_image_0000002558003909.png?HW-CC-KV=V1&HW-CC-Date=20261008T174743Z&HW-CC-Expire=31536000000&HW-CC-Sign=D144698CFB97947846396D6D948DA32253A6D9FA9F658378599B0D9FBDF9F479 "点击放大")

2、查看账单

进入项目设置->项目费用界面，商品选择"快通知L档"，或服务选择"Push快通知L档"，可查看消耗账单，账户存在可用的Push快通知L档优惠券时，系统将优先使用优惠券来抵扣相应的费用。优惠券不足以覆盖费用时，剩余部分将通过现金支付方式进行结算。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/eJ6MJgPkRjOrbSOTQNRh5A/zh-cn_image_0000002558003911.png?HW-CC-KV=V1&HW-CC-Date=20261008T174743Z&HW-CC-Expire=31536000000&HW-CC-Sign=DB58947DEEBA713C4063C6CEBDFCC00B22D5ABDEC079DB59379868978D9116D2 "点击放大")

3、优惠券查询

已领取但未使用的代金券，可以在优惠券页面[查看对应的优惠信息。](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-query-coupon-0000001154273152#section28841110669)
