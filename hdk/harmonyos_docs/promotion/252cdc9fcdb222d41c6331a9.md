# 使用指南

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/3B4XA7YvRSmdlSfHGig4Sw/zh-cn_image_0000001920245820.png?HW-CC-KV=V1&HW-CC-Date=20260928T100502Z&HW-CC-Expire=31536000000&HW-CC-Sign=239C04BF5C76D50373FFC22B5B864F185073BD9BB0EFDFA1B2ED019D66F76264 "点击放大")

1. 您向鲸鸿动能运营申请第三方监测链接白名单。

   > 说明
   >
   > 第三方监测服务器域名信息应在白名单内。
   >
   > 第三方监测平台监测地址需要符合鲸鸿动能平台要求。

2. 您在第三方监测平台获取监测链接。监测链接支持字段与格式请参考[第三方监测实现方式](https://developer.huawei.com/consumer/cn/doc/promotion/ads_jiance01-0000001057721993)。
3. 新建广告任务，上传广告创意时填写监测地址。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/ws-DfiZ5T1uO9V_agqGKrg/zh-cn_image_0000002492488410.png?HW-CC-KV=V1&HW-CC-Date=20260928T100502Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C989D7779F52EC49F3A8D25068C1E5C326CF86B7AB4AA0B197C141324D04109)![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f/v3/peyK5GOgTt-EzS_wXuJqpA/zh-cn_image_0000002524608173.png?HW-CC-KV=V1&HW-CC-Date=20260928T100502Z&HW-CC-Expire=31536000000&HW-CC-Sign=00EC16853B38C76F2D5BC86596A49F6BF5A5DD4B8743ADAFC2D8D71580CCA47B)

4. 投放广告。
5. 广告投放后您可在三方监测平台查看数据。

**三方域名加白名单详情：[三方域名加白名单](https://developer.huawei.com/consumer/cn/doc/promotion/ads-sfjbmd-0000002541143520)**
