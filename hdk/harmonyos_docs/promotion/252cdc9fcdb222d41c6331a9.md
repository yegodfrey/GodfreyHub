# 使用指南

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/3B4XA7YvRSmdlSfHGig4Sw/zh-cn_image_0000001920245820.png?HW-CC-KV=V1&HW-CC-Date=20260918T093101Z&HW-CC-Expire=31536000000&HW-CC-Sign=A5A7CB88CB32E60B61944A623A8D331E8298CCBFBCBCF7EA53BFFDDD31D180B6 "点击放大")

1. 您向鲸鸿动能运营申请第三方监测链接白名单。

   > 说明
   >
   > 第三方监测服务器域名信息应在白名单内。
   >
   > 第三方监测平台监测地址需要符合鲸鸿动能平台要求。

2. 您在第三方监测平台获取监测链接。监测链接支持字段与格式请参考[第三方监测实现方式](https://developer.huawei.com/consumer/cn/doc/promotion/ads_jiance01-0000001057721993)。
3. 新建广告任务，上传广告创意时填写监测地址。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/ws-DfiZ5T1uO9V_agqGKrg/zh-cn_image_0000002492488410.png?HW-CC-KV=V1&HW-CC-Date=20260918T093101Z&HW-CC-Expire=31536000000&HW-CC-Sign=CFA35002A43FEA3EC27F192BAC4C6722A7913FE3DD5C805381F69FE26A12F9CF)![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f/v3/peyK5GOgTt-EzS_wXuJqpA/zh-cn_image_0000002524608173.png?HW-CC-KV=V1&HW-CC-Date=20260918T093101Z&HW-CC-Expire=31536000000&HW-CC-Sign=68E749E4AF677AF33E799E5949F3ED6FD6F1DAFDBD52D0672EBFD75ECA961FAA)

4. 投放广告。
5. 广告投放后您可在三方监测平台查看数据。

**三方域名加白名单详情：[三方域名加白名单](https://developer.huawei.com/consumer/cn/doc/promotion/ads-sfjbmd-0000002541143520)**
