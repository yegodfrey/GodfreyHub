# 2026年7月高频问题Q\&A

Q1：如何查看计划/任务/创意的用户画像？

A：可以通过鲸鸿动能后台-工具-人群管理来创建广告行为人群，可以选取计划/任务/创意，然后在人群洞察查看，预计四五个小时左右就绪后查看。

<br />

Q2：鲸鸿动能后台充值金额有数目要求吗？

A：单笔最大充值金额为20亿元，最小充值金额为1元。建议按照一周的预算范围进行充值，在消息中心设置余额不足提醒（当账户余额少于200元时，账户会有余额不足提示）。

<br />

Q3：在调试回传事件时，显示已经回传成功，但是转化事件量为什么没有转化数量？

A：如果是手动联调下发的，并不是通过试投放真实点击下发，回传手动联调下发的callback仅仅会启用对应回传的指标，并不会记录在后台报表数据中。

<br />

Q4：自动盯盘的"过去3天（不包含今天）"会覆盖到投放时间不到3天的计划吗？

A：过去3天（不包含当天），不包含当天指的是不包含当天的过去3天。举例：比如7月9日创建的规则，那7月6日、7月7日、7月8日创建的任务都不会包含在内，但在7月6日-7月8日在投的老任务包含在内。

<br />

Q5：推广华为主题类产品，不涉及软著资质，需要提交什么补充资质？

A：软著资质处支持上传产品主体与广告主关系的证明文件。参考"华为主题APP里某个设计室/师的手机壁纸"推广案例，需提供"华为主题设计室/师后台个人信息界面"截图，且截图需清晰体现设计室的企业全称或设计师的真实姓名，以证明该主题权属归广告主所有。若推广产品权属主体非广告主，需补充推广协议或合作协议等。

<br />

Q6：搭建广告时，在定向的自定义人群中选择了两个人群包A和B，那么是会定向到A+B的人群吗？

A：是的，同时选两个的话是取并集。

<br />

Q7：报表里面用户唤醒是有转化数的，但是为什么在事件页面没有？

A：事件页面的数据可以不用关注，主要看事件有没有启用；看数据的话以报表为准。

<br />

Q8：开户被拒审了企业全称怎么修改？

A：首次开户且选择人工审核或对公银行打款认证审核未通过时，企业全称支持修改；若选择对公银行打款认证通过或已开户成功时，则企业全称不支持修改。

<br />

Q9：当前新开账户创建事件资产时没有【智能跟踪】的选择功能，那自动开启投放后，事件资产会自动转化启用吗？

A：目前新账户上是默认开启的，开启智能跟踪后进行广告投放，广告主也是要完成归因后回传动作的，然后自动建立事件。

<br />

Q10：开户时推广内容是HarmonyOS 4.X之前版本的应用产品，投放时可以推广HarmonyOS 5.0之后版本的鸿蒙版应用产品吗？

A：开户时若提供的是该应用HarmonyOS 4.X之前版本的相关资质，之后想投该应用HarmonyOS 5.0之后版本的鸿蒙版，可以直接在这个账户投放，但鸿蒙版应用推广需符合相关审核要求。您也可在开户时同时填写两个版本的应用推广，并附上两个版本应用的链接。
