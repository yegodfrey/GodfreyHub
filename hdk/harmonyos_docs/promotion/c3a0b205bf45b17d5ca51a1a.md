# ocpx赔付天报表查询

您通过本接口通过广告主ID、任务ID查询Ocpx赔付天报表数据。

* 请求地址：请根据您的就近区域进行选择 亚非拉：https://ads-dra.cloud.huawei.com/openapi/v2/reports/ocpx/queryDailyCompensation

  俄罗斯：https://ads-drru.cloud.huawei.com/openapi/v2/reports/ocpx/queryDailyCompensation

  欧洲：https://ads-dre.cloud.huawei.com/openapi/v2/reports/ocpx/queryDailyCompensation
* 请求方法：POST
* 请求参数：  

  |参数名称|类型|是否必选|描述|
  |:-------------------|:--------------------|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |is_abroad|Boolean|否|是否为海外广告主.|
  |advertiser_id|String|否|广告主ID，经理账户或者服务商账户登录时，则此字段必填；当前操作的华为账号支持多个广告主账户时，此字段必填。|
  |adgroup_id_list|list\<string\>|否|任务ID List|
  |page|integer|否|页数，默认值1，从1开始|
  |page_size|integer|否|期望返回页大小。默认20，取值范围1-10000|
  |ocpx_event_types|list\<OcpxEventType\>|否|OCPX任务转化目标类型|
  |compensation_status|list\<string\>|否|保障状态: COMPENSATING-保障中， NOT_MEET_COMPENSATING-不满足保障， NO_NEED_COMPENSATION-保障结束无需赔付， NEED_COMPENSATION-保障金额统计完成， COMPENSATION_CHECKING-保障核实中， FREE_OF_COMPENSATION-不涉及|
  |compensation_periods|list\<integer\>|否|保障周期，1-周期一，2-周期二|
  |start_time|string|是|数据周期时间起始时间，北京时间 YYYY-MM-DD hh:mm:ss|
  |end_time|string|是|数据周期时间结束时间，北京时间 YYYY-MM-DD hh:mm:ss|

  ocpx_event_types (OcpxEventType)参数：

|参数名称|类型|是否必选|描述|
|:-----------------|:------|:---|:-----------------------------------------------------------------------------------------------------------------------------|
|shallow_event_type|string|否|[浅层转化目标](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-appendix1-0000001174597591#section125615641916)|
|deep_event_type|string|否|[深层转化目标](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-appendix1-0000001174597591#section1042612114174)|
|deep_optimize_type|integer|否|深度优化类型 1-双出价； 2-双阶段； 3-单目标加强点|
