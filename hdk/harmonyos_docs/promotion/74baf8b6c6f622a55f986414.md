# 编辑计划

【简介】通过此接口可以编辑计划状态、计划名称、计划日预算

**请求地址**

https://ads.cloud.huawei.com/ads/v1/promotion/campaign/update

**请求方法**

**POST**

**请求参数**

|---------------|-------|--------|-----------------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|campaign_id|string|是|计划ID， 长度为1到50； 只能输入A到Z，a到z，0到9之间字母和数字|
|campaign_name|string|否|编辑后的名称， 最大长度不得超100位； 不能使用"^","|"特殊字符； 不能等于原来计划值且不能重复|
|daily_budget|Struct1|否|日预算， 修改后的值不能与原值重复； 详见[【修改限额约束】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_api721-0000001641010849#section16441194613613)|
|campaign_status|string|否|计划需要设置的状态 详见[【操作类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section349886194716)|

daily_budget (Struct1)定义

|--------------------|-------|--------|--------------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|daily_budget|integer|是|日预算， 修改后的值不能与原值重复；|
|daily_budget_op_type|string|是|计划修改日预算操作类型 详见[【计划修改日限额操作类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section89210523508)|
