# 私有人群上传

#### 功能介绍

在使用Marketing API创建投放任务前，您可以使用Marketing API上传自有的人群包文件数据、创建文件人群、修改文件人群，提升精细化投放效率。

私有人群API操作流程：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251117124649.01999567972278676048477617585049:50001231000000:2800:30AE0CE1B6C6AEAE28DD78691453BD8F39F799DA362C1675356CFA3338C8E1C3.png)  

#### 使用约束

1. 接口调用者的角色：仅支持直客调用。
2. 若文件人群已授权给代理，直客需先取消授权，再调用接口修改文件人群；修改完，重新授权给代理使用。
