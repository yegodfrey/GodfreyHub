# 2026年7月

本文旨在梳理常见驳回情形，以帮助广告主规范宣传。本文仅供参考，请广告主基于所宣传商品或服务（以下合称"商品"）的实际情况依法合规进行宣传。

<br />

典型驳回行业：电商、软件应用、小说阅读

典型驳回问题场景主要涵盖：

一、诱导点击

二、表述误导/不清晰

三、素材质量要求

四、虚假宣传

五、一致性要求
