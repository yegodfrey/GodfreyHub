# 创建素材

【简介】通过此接口可以创建素材，您也可以通过本接口对您的图片尺寸和大小进行预处理，target_width、target_height、target_file_size_kb_limit同时传才会触发图片裁剪压缩，PNG格式图片不能压缩。建议图片大小不超过1MB。

**请求地址**

https://ads.cloud.huawei.com/ads/v1/tools/creative_asset/create

**请求方法**

**POST**

**请求参数**

|-------------------------|-------|--------|------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|file_token|string|是|文件上传凭证 详见[【获取文件上传凭证】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_new_api34-0000001405360444)|
|file|File|是|文件内容 注：文件上限为50M 文件格式为：jpg，jpeg，png，mp4，webp 注：webp格式只允许上传尺寸低于512*512并且宽高比例为1:1的图片|
|asset_name|string|是|素材名称，不为空且长度不超过128 不能包含"'","\","{","}","%","*","^","#","<",">","|"特殊字符|
|target_width|integer|否|图片处理后的目标宽，范围在1-1080|
|target_height|integer|否|图片处理后的目标高，范围在1-1920|
|target_file_size_kb_limit|integer|否|图片处理后目标文件大小最大值KB，小于1024|
