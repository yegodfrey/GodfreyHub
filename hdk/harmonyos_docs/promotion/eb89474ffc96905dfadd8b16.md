# 新功能速递

#### 8月新功能速递

一、【投放平台新功能】

* 自动盯盘新增ROI系数及批量修改功能升级
* 经理账户平台支持批量关联子账户
* 投放端新增落地页类型校验功能

<br />

二、【投放工具新功能】

* 维纳斯落地页支持按钮复制口令并跳转
* 维纳斯落地页新增表单提交后跳转应用下载能力

<br />

三、【服务商管理平台新功能】

* 鲸鸿动能平台协议变更生效机制升级
* 服务商管理平台支持按角色维度盘点虚拟金订单
* 子客清单页面新增自定义列入口
* 支持服务商查看新客消耗及新客资质统计

<br />

#### 一、投放平台新功能

自动盯盘新增ROI系数及批量修改功能升级

【功能说明】

本次更新高频操作场景，优化批量修改逻辑，新增ROI系数调整能力，并强化系统校验机制，全面提升投放效率与准确性。

* 批量修改体验优化：

1)新增"更多修改"选项：当您依次进入"推广"-\>"任务"页面，批量选中任务后，上方列表新增"更多修改"入口，聚合可批量调整的参数项。

![](https://media:201785920806226858)

（"推广"-\>"任务"页面）

2)逻辑优化：批量修改出价、深度转化出价、ROI 系数时，若修改前后数值一致，系统自动跳过对应任务，不记录操作、不影响oCPC赔付规则。

![](https://media:201785920806265859)

（修改出价前后一致情况）

![](https://media:201785920806582860)

（修改ROI系数前后一致情况）

* 支持批量修改ROI系数：批量选中任务后，通过"更多修改"入口选择"修改 ROI 系数"（范围：0-100，支持4位小数）即可操作；支持"设置为xx"、"提升xx"、"降低xx"三种调整模式。

![](https://media:201785920806625861)

（"推广"-\>"任务"-\>"更多修改"页面）

![](https://media:201785920806664862)

（修改ROI系数页面）

* 自动盯盘新增ROI系数规则维度：在自动盯盘的任务级执行范围中，新增 ROI 系数规则条件，支持基于 ROI 系数设置自动化盯盘策略。

![](https://media:201785920806726863)

（自动盯盘-新建规则页面）

* 操作日志能力升级：

1)精准记录实际操作者：跨账户操作场景下（如管理员账户登录子客账户操作），操作日志将记录实际执行操作的账户 ID，比如B是A的管理员，B进入到A的账户操作，则记录是B的账户ID。

![](https://media:201785920806778864)（操作日志页面）

2)新增操作来源标识：日志新增操作来源字段，区分"投放平台"与"Marketing API"两类操作渠道。

![](https://media:201785920806861865)（操作日志页面）

【功能入口】

"工具"-\>"账户辅助"-\>"操作日志"

"推广"-\>"任务"-\>"详情"

"推广"-\>"任务"-\>"更多修改"-\>"修改ROI系数"

经理账户平台支持批量关联子账户

【功能说明】

为提升账户管理效率，鲸鸿动能经理账户平台新增批量关联子账户功能，单次最多支持关联50个子账户。

* 输入升级：登录经理账户平台后，在首页点击"关联账户"后弹出账户ID输入框；输入框升级为多行模式，不同账户 ID 以换行分隔，支持拖拽上下拉动调整文本框高度。
* 校验逻辑：输入校验规则与原有保持一致，仅允许输入数字与换行符。

![](https://media:201785920806925866)

（经理账户首页-关联账户页面）

* 批量校验与结果展示：用户输入账户ID并点击添加后，对输入的多个子账户ID做校验，并显示校验结果提示语以及校验成功和失败的表格：

1)无校验失败场景提示语："已匹配XX个，未匹配0个"，仅展示校验成功的表格，不展示校验失败表格

2)有校验失败场景提示语："已匹配XX个，未匹配YY个，以下为未匹配项"

3)校验成功表格：与原有特性保持一致，展示【序号、账户ID、企业名称、昵称、操作】列

4)校验失败表格：展示【序号、账户ID、未匹配原因】列，行数过多时支持滚动

5) 未匹配原因：依据系统原有提示逻辑展示每个未匹配账户的未匹配原因，包括但不限于"该账户不存在"、"该账户已关联经理账户"

![](https://media:201785920807102867)

（经理账户首页-关联账户校验弹框）

<br />

【功能入口】

"首页"-\>"关联账户"

<br />

【适用范围】

经理账户

投放端新增落地页类型校验功能

【功能说明】

为规范落地页投放流程，保障广告主完整使用维纳斯落地页功能，投放平台新增落地页类型校验机制，相关规则说明如下：

* 校验规则：若您拟推广的落地页链接是使用维纳斯工具制作的（落地页链接URL包含"dbankcdn.cn/cch5/PPS"字串），则将无法继续通过"自定义落地页"页签提交。
* 操作指引：请直接于"维纳斯落地页"列表中选择对应页面进行投放，以保障功能体验完整。
* 生效范围：任务创编页面（推广产品为网页场景）、创意创编页面（推广产品为应用场景），以及 Marketing API 的任务、创意创编接口同步执行该校验。

![](https://media:201785920807150868)

<br />

【功能入口】

推广产品是应用："创建计划"-\>"创建任务"-\>"上传创意"-\>"落地页链接"

推广产品是网页："创建计划"-\>"创建任务"-\>"落地页链接"

#### 二、投放工具新功能

维纳斯落地页支持按钮复制口令并跳转

【功能说明】

本次上线口令营销能力，网页落地页按钮组件新增"复制并跳转"功能选项。用户点击按钮后，可自动复制预设口令码、弹出复制成功提示，并跳转至指定第三方平台，满足口令引流的转化需求。

![](https://media:201785920807338872 "点击放大")

#### 三、服务商管理平台新功能

鲸鸿动能平台协议变更生效机制升级

【功能说明】

为保障广告投放与Marketing API调用连续性，鲸鸿动能广告平台正式上线协议变更默认同意规则：在平台相关协议变更通知发布后，若继续使用服务即视为同意修订条款，协议即时生效，无需手动签署即可正常开展投放操作与接口调用。

* 子客/子客服务商账户协议《鲸鸿动能服务商声明》增加默认签署条款说明："华为有权根据适用的法律法规或基于自身经营考虑更新本声明内容，并将在变更时提前30天通过邮件、站内通知、短信或公告等方式中的一种或多种方式通知您。如您继续使用鲸鸿动能服务（例如继续使用平台 API服务、继续调用接口）即视为您已阅读、理解并同意更新后的声明内容，如您不同意变更后的声明内容您可停止使用鲸鸿动能服务。"（新版协议及历史变更记录，请查阅：[鲸鸿动能平台协议](https://developer.huawei.com/consumer/cn/doc/promotion/ads-guanggaoxieyishuoming-0000001727130625)）。
* 生效逻辑：协议变更生效后，通过Marketing API调用、跳转登录等方式使用平台服务时，系统将自动确认协议同意状态，开放全部业务调用与使用权限。

![](https://media:201785920807755880 "点击放大")

* 协议变更通知机制：协议生效后，系统将通过短信及邮件自动向所有有效账户发送变更通知。

1)覆盖范围：所有生效状态（在用、静默）的非注销、非未注册账户，按账户状态分批次推送；

2)默认配置：自定义消息通知设置中，短信、邮件通知开关默认开启。

3)通知频次：单轮协议更新仅向账户发送 1 次通知。

服务商管理平台支持按角色维度盘点虚拟金订单

【功能说明】

本次升级服务商管理平台对"订单盘点（按账户）"导出页面进行重构升级，新增角色维度的订单分布数据导出能力，帮助服务商提升虚拟金运营效率。

* 新增角色维度：登录服务商管理平台后，依次进入财务管理 \> 虚拟金盘点 \> 订单盘点（按账户）\> 导出；导出页面现支持导出"订单及角色分布数据"，可一键查看各角色虚拟金余额及有效期分布，无需逐一点击。

1)导出内容-单选：可选"订单数据"或"订单及角色分布数据"，默认选中"订单数据"；

2)导出筛选-单选：可选"包含0金额数据"或"不包含0金额数据"，默认选中"包含0金额数据"；

3)导出方式-单选：可选"直接导出"或"异步导出"，默认选中"直接导出"。

![](https://media:201785920808319883 "点击放大")

（服务商管理平台-虚拟金盘点）

支持服务商查看新客消耗及新客资质统计

【功能说明】

为提升服务商新客运营效率，平台对星火竞价新客查询功能进行优化，并新增推介会新客资质查询能力，两项功能均面向服务商开放，具体说明如下：

* 星火竞价新客查询功能优化： 1)功能入口："政策活动"-\>"新客查询"-\>"星火(竞价)新客查询"

  2)查询调整：①取消"子客账户ID"；②新增"推广标的"检索；③"开始日期-结束日期"筛选规则调整为匹配 "新客起始日期"，即新客起始日期落在所选日期区间内的结果均会被检索。

  3)列表能力升级："新客期起始日期""新客期结束日期"支持升降序排序，默认按新客起始日期降序排列；列表新增 "推广标的"、"新客期 90 天内现金竞价消耗" 展示字段。

  4)场景说明：该新客查询的数据只适用于星火计划竞价政策。

  ![](https://media:201785920808972889 "点击放大")

  （星火(竞价)新客查询页面）

  <br />

* 推介会新客资质查询功能： 1)功能入口："政策活动"-\>"新客查询"-\>"推介会新客资质查询"

  2)查询操作：支持输入"推广标的"进行检索，提供查询、重置操作按钮。

  3)结果展示：点击查询后下方输出查询结果"推广标的"、"是否具备推介会新客资质" 两列内容；资质状态分为 "是/否"，若推广标的符合推介会新客资质定义，或从未在鲸鸿动能平台出现，均判定为"是"。

  4)场景说明：该新客资质查询的数据只适用于推介会新客资质查询，最终资质判定结果以平台运营审核结论为准。

  <br />

  ![](https://media:201785920809190890 "点击放大")

  （推介会新客资质查询页面）
