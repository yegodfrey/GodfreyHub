# 新功能速递

## 8月新功能速递

**一、【投放平台新功能】**

* 自动盯盘新增ROI系数及批量修改功能升级
* 经理账户平台支持批量关联子账户
* 投放端新增落地页类型校验功能

二、**【投放工具新功能】**

* 维纳斯落地页支持按钮复制口令并跳转
* 维纳斯落地页新增表单提交后跳转应用下载能力

**三、【服务商管理平台新功能】**

* 鲸鸿动能平台协议变更生效机制升级
* 服务商管理平台支持按角色维度盘点虚拟金订单
* 子客清单页面新增自定义列入口
* 支持服务商查看新客消耗及新客资质统计

**经理账户平台支持批量关联子账户**

**【功能说明】**

* 输入升级：登录经理账户平台后，在首页点击"关联账户"后弹出账户ID输入框；输入框升级为多行模式，不同账户 ID 以换行分隔，支持拖拽上下拉动调整文本框高度。

1)无校验失败场景提示语："已匹配XX个，未匹配0个"，仅展示校验成功的表格，不展示校验失败表格

5) 未匹配原因：依据系统原有提示逻辑展示每个未匹配账户的未匹配原因，包括但不限于"该账户不存在"、"该账户已关联经理账户"
