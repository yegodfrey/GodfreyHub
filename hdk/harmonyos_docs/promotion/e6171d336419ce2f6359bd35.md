# 绑定定向包

【简介】通过此接口可以绑定定向包

**约束**

* 满足下面条件的定向包才能支持绑定定向包
  1. 采买模式：竞价
  2. 计划类型：展示广告
  3. 资源类型：展示广告网络
  4. 推广产品：网页、应用、快应用、促销活动
* 推广目的是应用促活 定向包的App安装定向app_install_struct必须为true
* 推广目的是应用下载 定向包的App安装定向not_app_install_struct必须为true
* 次留任务和次留定向包支持绑定

**请求地址**

https://ads.cloud.huawei.com/ads/v1/tools/targeting_package/bind

**请求方法**

**POST**

**请求参数**

|-------------|------|--------|------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|targeting_id|long|是|定向包ID|
|adgroup_id|long|是|任务ID|
