# 创建展示网页广告

#### 概述

展示网页广告是指在[展示广告位](https://developer.huawei.com/consumer/cn/doc/promotion/display-0000001057113500)上对您的网页进行推广，用户看见图片/视频后，单击进入您想要推广的网页，增加网页的浏览量和转化量。  

#### 操作流程

![](https://media:101784103151284421)  

#### 操作步骤

1. 创建广告计划。

   <br />

   单击"创建"-\>"创建计划"，进入计划设置。

   ![](https://media:101784103151359422 "点击放大")
   * 营销目标：选择"销售转化"或者"无明确目的导向"，详情参考[营销目标](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_zh-cn_topic_0000001105216776_li07111843183611)。
   * 计划类型：选择"展示广告"，详情参考[计划类型](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_zh-cn_topic_0000001105216776_li234211653411)。
   * 投放网络：选择"自定义投放网络"-\>"展示广告网络"，详情参考[投放网络](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_zh-cn_topic_0000001105216776_li93421166342)。
   * 推广产品：选择"网页"，详情参考[推广产品](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_zh-cn_topic_0000001105216776_li8342416193416)。
   * 计划日预算：详情参考[计划日预算](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_zh-cn_topic_0000001105216776_li14342141615342)。
   * 推广计划名称：详情参考[推广计划名称](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_zh-cn_topic_0000001105216776_li1434211615342)。

   <br />

2. 创建广告任务。

   <br />

   如果您希望在已有的计划下增加新的任务，请参考[已有计划下创建任务](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_li5851143183912)。
   * 广告投放类型：选择"正式投放"。如果您希望在正式投放之前对投放进行测试，您可以创建[试投放](https://developer.huawei.com/consumer/cn/doc/promotion/ads-adtest-0000001190031279)任务。
   * 落地页类型：落地页链接是您想要推广内容的信息承载页面。输入您需要推广的落地页，用户单击广告后，即可进入落地页，落地页默认使用webview打开。在使用落地页正式投放之前，建议先用落地页创建一个试投放任务，测试落地页跳转、数据跟踪都正常之后再创建正式投放的广告任务，避免落地页异常导致广告投放费用的损失。 落地页的内容要保证合规，审核人员会进行落地页审核并在投放过程中进行抽检。

     * 自定义落地页：填写自定义的HTTPS访问地址。例如：https://ads.huawei.com/usermgtportal/home/index.html#/。您可以在自定义落地页中添加宏参数，用来监测广告流量信息，区分用户来自哪个广告计划任务等，详情请参考[鲸鸿动能广告支持的宏参数](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__li1791495401511)。
     * 维纳斯落地页：您也可以选择维纳斯落地页，用户点击您的广告后，进入您在维纳斯创建的落地页，进行填写表单等操作，具体请查看[落地页工具](https://developer.huawei.com/consumer/cn/doc/promotion/venus-0000001063299665)。您也可以对维纳斯落地页进行数据跟踪，详情请参考[维纳斯网页跟踪](https://developer.huawei.com/consumer/cn/doc/promotion/tracking-venus-0000001202117526)。
   * 定向：详情参考[定向](https://developer.huawei.com/consumer/cn/doc/promotion/targeting-0000001180547094)。
   * 流量验证：选择使用流量验证服务(流量验证)，可防止您的广告出现在不利于您品牌推广的APP或URL中，有利于节省您的预算，但需注意，使用流量验证服务，需收取额外的费用。（备注：流量验证条件仅可在 "流量验证条件管理" 页面创建；在"广告任务创建"页面只能选择已有条件，点击 "编辑" 按钮将自动跳转至管理页面进行修改。）
   * 版位：在版位选择中，您可以决定广告出现在什么位置。在选中某个版位后，右侧会出现对应的版位预览。
   * 投放日期：详情参考[投放日期](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_li73789433254)。
   * 投放时间：详情参考[投放时间](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_li1237874310252)。
   * 投放频次设置：支持广告主设置广告任务对用户的展示频率。例如：时长设置5， 展示频次上限为10，则在5天的周期内此任务向一个用户展示不超过10次。
   * 出价：版位不同，出价方式可能不同。目前展示网页广告支持的出价方式包括CPM、CPC。
   * 任务名称：详情参考[任务名称](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_li237864312259)。

   <br />

3. 上传创意。

   <br />

   根据您选择版位的不同，可以选择不同的创意样式及尺寸，并上传对应的创意素材、设置品牌名称和描述信息等。详情参见 [素材指导](https://developer.huawei.com/consumer/cn/doc/promotion/overview_ggsczd-0000001182713584)。

   单个版位支持多规格多创意样式同时投放，为获取更优的投放效果，建议您选择多种创意样式及创意推广产品。

   ![](https://media:101784103151393423)

   ![](https://media:101784103151432424)
   * 直达链接：指定网页内容的链接。

   <!-- -->

   * 创意名称：详情参考[创意名称](https://developer.huawei.com/consumer/cn/doc/promotion/overview-cjjjgg-0000001182873508#ZH-CN_TOPIC_0000001182873508__zh-cn_topic_0000001205953939_zh-cn_topic_0000001105216776_li1471941495513)。

   <br />

4. 任务审核。

   <br />

   单击"提交"，审核通过后即可推广，审核时间、审核结果通知、审核结果查看请参考[广告审核](https://developer.huawei.com/consumer/cn/doc/promotion/review-0000001052064324)。

   <br />
