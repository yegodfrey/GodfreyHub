# 创建解决方案数据源

贷款行业解决方案的数据源与外部通用数据源隔离，需在【解决方案】-【贷款行业解决方案】完成数据源创建。

1. 直客账户登录[华为应用市场应用推广平台](https://ads.huawei.com/cn/)， 点击页面顶部"解决方案"页签，选择"贷款行业解决方案"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/31/v3/mW3pxjASTPeN04N-mYKeOg/zh-cn_image_0000002552567948.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=2DF0DB17CA384303B76CBD36D82607FCD83901D30729564087DF5A1C685209A6)
2. 点击"数据资产"页签，选择"新建数据源"进行设置。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/nFnYyXJDTvqGwyTVMbILAg/zh-cn_image_0000002583367641.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=78A73C9C79E2EB5FCDC9247905844D78C682EA4DC6BEC08E1B5CA934866BD71A "点击放大")

3. "创建数据源"区域填写说明

   |**任务设置项**|**说明**|
   |:---------|:-------------------------------------------|
   |选择APP|选择您需要投放的APP。|
   |数据源名称|默认为APP名称，创建后支持修改。|
   |授权投放操作账户查看|若需要代理投放，请选择"是"，授权后客户投放伙伴也可以查看数据回传情况。创建后支持修改。|
   |归因方式|可根据您已对接的归因方案自行选择。|
