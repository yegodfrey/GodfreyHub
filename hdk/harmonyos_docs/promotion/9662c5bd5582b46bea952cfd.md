# 配置延迟Deeplink

## 操作步骤

在[华为应用市场应用推广平台](https://ads.huawei.com/cn/)，创建推广任务并在"推广创意"中填写"应用打开"后的APP Deeplink。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/JlbKqjqIS6SpSfKz8K2SMA/zh-cn_image_0000002555978983.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=F58DAB6B77852F9F78874FD6423BA1DDAB2F3475D2F8CD13E95F705DE162FB21 "点击放大")

Deeplink填写完成后，您可以通过扫描二维码或使用[测试工具](https://a.vmall.com/uowap/apkPage/deepLink.html#/)预览Deeplink的效果。
> 说明
>
> 建议使用华为浏览器，否则会因屏蔽站外链接情况导致扫描二维码后无法跳转。
