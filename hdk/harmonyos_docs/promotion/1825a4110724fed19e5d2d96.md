# 客户投放伙伴

尊敬的开发者，感谢您长期以来对华为应用市场应用推广的支持与信赖！为提供更高效、智能的一站式服务，我们将迎来投放端的重要升级------应用市场应用推广和鲸鸿动能的投放端将正式整合升级。投放端整合升级后，应用推广登录投放入口迁移到鲸鸿动能平台，历史数据和投放工具能力将自动迁移到鲸鸿动能平台下。

为避免影响您后续的应用投放，请您前往[鲸鸿动能广告平台](https://ads.huawei.com/cn/)进行广告投放。整合升级后如有任何疑问，请您联系行业运营或通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)、客服邮箱（developer@huawei.com）等方式反馈。感谢！
