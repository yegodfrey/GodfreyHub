# 更新人群包内容

【简介】合作伙伴更新人群包

人群包内容变化时可通过该接口更新。

特殊说明：增量更新可能存在失败情况，建议根据实际情况固定周期全量同步一次。

请求地址

https://svc-drcn.ads.huawei.com/opendmp/v2/audience_package/update

请求方法

POST

请求参数  

|----------|---------------|---|--|--------------------------------------------------------------------------|
|参数名称|类型|长度|必填|说明|
|dmpID|String|255|Y|三方DMP标识。|
|audienceID|String|128|Y|人群ID|
|addUrl|AudiencePackage|-|N|新增人群信息包下载URL。 注意1：当updateType为1时，addUrl是必须的。 注意2：addUrl和deleteUrl不可同时使用|
|deleteUrl|AudiencePackage|-|N|删除人群信息包的下载地址。 注意1：当updateType为1时，不能填写deleteUrl。 注意2：addUrl和deleteUrl不可同时使用|
|updateType|int|1|N|更新类型。 0：增量更新（默认） 1：完全更新。 建议：定期进行全量同步（updateType=1），避免增量同步导致数据不一致。|

AudiencePackage  

|--------------|--------------|------|---------|-----------------------------------------------------|
|Parameter name|Type|Length|Mandatory|Description|
|locationType|int|1|N|固定传1 1-华为OBS|
|downloadUrls|List\<String\>|-|Yes|人群包地址， 每个人群不超过100个文件路径。 国内传：objectID（即DMPID/文件名称.zip）|
|deviceIDType|int|-|No|人群包中的设备ID类型|

请求示例

POST http://${base_address}/opendmp/v2/audience_package/update

HTTP/1.1

Headers:

Content-Type: application/json

Authorization：Bearer DAEAAIX7IS\*\*\*\*\*Pd81PDmWiM1KS2

Body:

```
{
    "dmpID": "829411234539267456", // Ads运营提供的dmpID
    "audienceID": "联调测试test001", //人群特殊标志符，
    "addUrl": {
                "locationType": "1", //固定传1
                "downloadUrls": ["829411234539267456/A.zip"], //上传至OBS文件路径
                "deviceIDType": "3" //人群包中的设备ID类型
            },
    "deleteUrl": {
                "locationType": "1",//固定传1
                "downloadUrls": ["829411234539267456/B.zip"], //上传至OBS文件路径
                "deviceIDType": "3" //人群包中的设备ID类型
            },
    "updateType": "0" //更新方式：0-增量更新；1-全量更新
}
```

<br />

响应字段  

|-------|------|----|----|---|
|参数名|类型|长度|是否必填|说明|
|code|int|-|Y|错误码|
|message|String|2048|N|描述|
|value|object|-|N|NA|
