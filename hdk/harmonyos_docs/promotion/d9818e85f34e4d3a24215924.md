# 查看账户信息

投放端右上角，点击账户名称旁的下拉框，可以查看账户基本信息：账户ID和登录账户的UPID信息。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260303164838.91241693450949649032726157707752:50001231000000:2800:C851D4B74D27A305E86A378E1E4A25F5389F3D5AFE3A4C163790C0CA3708F1B2.png)

<br />

具体说明如下：

* 公司名称 企业实名认证的公司名称，直客协作者账户名称为直客管理者填写的昵称。

* 账户ID 开户时系统生成的账户唯一标识ID。

* UPID 推广账户绑定的华为账号标识，是开发者联盟通用的开发者ID。

* 团队管理 可邀请其他华为账号共同管理本账户，详见[文档介绍](https://developer.huawei.com/consumer/cn/doc/promotion/mix-tool-0000002466178422)。

* 切换账号 当前华为账号绑定登录多个账户，通过此入口切换。
