# OAuth2.0认证

Marketing API 采用OAuth2.0授权码模式（authorization code）模式进行授权认证，所有接口均通过请求头中传递的access_token（授权令牌）来进行身份认证和鉴权。

1. 使用实名认证账号登录[联盟](https://developer.huawei.com/consumer/cn/console)
2. 选择"管理中心"->"API服务"->"凭证"->"OAuth2.0 客户端ID" ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/N23dc6G0QuG9bLIRb1E0Zw/zh-cn_image_0000002473311286.png?HW-CC-KV=V1&HW-CC-Date=20260918T093101Z&HW-CC-Expire=31536000000&HW-CC-Sign=458B4C9B538078718F1079BFD83F7D4CD519DB41E6ED3E8AE18F9DE4FBFEE40D)

3. 各字段填写方式如下：
   * 凭证类型：服务器应用（只能选这个，其他MAPI不可用，默认值）
   * 凭证名称：客户端名称
   * 应用类型：应用
   * 默认语言： 简体中文
   * 回调地址："回调地址"请您的技术人员提供，以https//或http://开头，不能包含字符"?，且长度不能超过255字符。后续可修改。
   * 应用访问地址：客户端原地址，格式https://{ServerRoot}

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/mllv7TmsSLKTQUPW-uB5uw/zh-cn_image_0000002239875954.png?HW-CC-KV=V1&HW-CC-Date=20260918T093101Z&HW-CC-Expire=31536000000&HW-CC-Sign=13F5216896036AE4E051FF981D40CE7A94441D5440F531AD34E656550B17A3A0 "点击放大")

注：**回调地址必填**且与应用访问地址完全一样，且必须是https协议类型网址。

4. 单击"创建"，创建凭证成功，复制"客户端ID"和"密钥"即可
