# 鲸鸿动能平台协议

* 如果鲸鸿动能协议有更新，您在进入鲸鸿动能平台后，系统会弹出协议更新页面，您可以查看协议的更新内容以及完整的协议，您可以选择"立即签署"或"延期签署"。
  * 立即签署：如果您选择立即签署，协议将于xxxx年xx月x生效，签署后进入鲸鸿动能平台。
  * 延期签署：如果您选择延期签署，您必须在协议生效前完成签署，否则您将无法使用鲸鸿动能平台。鲸鸿动能平台会在协议生效前30天提醒您协议更新时间，您可以在鲸鸿动能平台的页面的上端查看协议生效时间，单击"查看详情"，可查看协议具体的更新点并签署协议，签署后协议将于xxxx年xx月x生效，您也可以单击协议名称，下载整个协议。
* 如果您开通了华为联盟提供的团队账号功能，您需要使用主账号登录鲸鸿动能平台并重新签署协议。
* 如果您开通了鲸鸿动能提供的团队账号功能，您可以使用主账号登录鲸鸿动能平台并签署协议，也可以授权您的管理员进行签署协议，详情可查看[授权签署协议权限](https://developer.huawei.com/consumer/cn/doc/promotion/addtuandui-0000001079312694#ZH-CN_TOPIC_0000001079312694__li16934182711012)。
* 如果您想了解华为开发者侧的协议，请参考[服务协议](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/agreement-0000001062394234)。
