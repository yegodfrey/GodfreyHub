# 申请应用权限

#### 申请方式

1. 使用通过[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)的持有者账号登录[华为开发者联盟](https://developer.huawei.com/consumer/en/console#/serviceCards/)，请不要使用团队成员账号。
2. 选择"API服务"-\>"授权管理"，选择需要申请的权限内容，单击"申请"，状态变更为"待审核"状态，完成提交申请。如果存在多个凭证，选择自己需要的授权的对应项目下的凭证名称、公开权限非鲸鸿动能业务，无需关注。![](https://media:101784100577284393 "点击放大")
3. 申请需要调用的scope权限

   应用/服务名称：创建凭证的名称

   服务类型：(固定填写)鲸鸿动能

   使用场景：(固定填写) 进行广告推广的创编查，包括广告计划、任务、创意的创建、编辑查询，广告工具的使用，广告账户信息查询，广告财务信息查询，以及详细的推广数据报表等。

   上传附件：[能力图.png](https://media:101784100577433396)

   ![](https://media:101784100577341394)
4. 请通过邮箱申请权限，主送对应行业运营邮箱。
