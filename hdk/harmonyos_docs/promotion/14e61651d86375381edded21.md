# 2026年6月高频问题Q&A

**Q1：创意层级显示部分元素通过，但是点击查看却是全部通过，是什么原因？**

**A：**当前元素列表不是所有元素都展示的，如果创意状态显示部分元素通过，原因可能是还有部分元素没有审核完成，还在审核中，可以反馈平台进行核实确认，如果查看任务状态是投放中的情况下就是正常投放中了。

**Q2：创建任务时，定向中的年龄选择是华为账号设置的年龄还是平台推断出来的年龄？**

**A：**年龄来源于多个数据源，大部分是通过行为预测模型评估得出的。

**Q3：搭建试投放任务时，可以使用同一个OAID同时录入到多个试投放任务中吗？**

**A：**建议一个oaid同一时间段最好只加到一个试投放任务的定向中。

**Q4：经理账户如果无法登录了，还有什么办法可以把里面关联的账户进行取消关联？**

**A：**可以到子客账户后台-工具-广告账户管理-经理账户信息页面操作取消关联。

**Q5：鲸鸿动能平台预充值后的开票金额是按充值金额还是消耗金额？**

**A：**预充值是按订单金额进行开票，不按消耗。

**Q6：子客账户需要签署协议时，只能通过该子客账户的账号密码登录进入签署协议吗？**

**A：**有另外的办法：子客账户绑定团队账号，具体操作方式：

①登录该子客对应的服务商账户或经理账户（已关联了需要签署协议的子客账户A）；

②进入到子客账户A后台，此时不会弹窗让其签署协议；

③点击工具-账户辅助-团队管理添加团队成员（某个能正常登录的子客账户B）；

④登录团队成员子客账号B的账号密码进入后台，切换账号至需要签署协议的账户进行签署。

**Q7：创建任务时，（自定义监测链接参数）需要点选吗？点选打开填写后会有什么影响？**

**A：**可以根据当前的实际需要选择打开或关闭，打开可以配置曝光、点击监测链接，配置完成会按照这里配置的监测链接下发，不会按照事件资产管理配置的监测链接下发。如果事件资产管理有配置，那么这里打开默认显示的链接就是事件资产管理配置的；也可以不用打开，如果是和事件资产配置的是一样的话，那打不打开都没有什么关系。

**Q8：开户过程中，选择对公银行打款认证时，打款账户主体是哪个？**

**A：**打款账户主体名称为银联商务支付股份有限公司，以实际打款情况为准，打款账号随机。

**Q9：广告素材涉及具体剧名，需要补充什么资质？**

**A：**涉及具体剧名，需要补充相应剧作按相关要求应当取得的许可或备案证明，例如微短剧《网络剧片发行许可证》或节目登记备案证明。

**Q10：投放应用促活，DP链接如果使用非官方RTA可以吗？**

**A：**非官方RTA地址，有外网权限且可以正常请求即可。

**Q11：鲸鸿动能后台人群包，客户用marketing api自己上传 ，经常更新的话可以每次不建新包直接在固定人群包id更新吗？**

**A：** 可以，具体可以查看文档：[人群管理](https://developer.huawei.com/consumer/cn/doc/promotion/ads-dmprqgl-0000001811407845#section1030111386356)-OpenDmpAPI接入指导-更新人群包接口。。

**Q12：推广产品选择"通投Android&鸿蒙应用"时，如何进行事件资产联调？没有通投选项？**

**A：**资产都是单独的，可以独立新建，然后通过单独新建Android、鸿蒙的试投放去操作，等事件启用了再创建正式广告。

**Q13：涉及游戏行业交易账号的产品是否可以准入投放？**

**A：** 属于禁投，具体可查看文档说明：[平台禁投内容](https://developer.huawei.com/consumer/cn/doc/promotion/ads_shenhe03-0000001057185555)。

**Q14：上传素材时会有普通图片和开屏两个选项，分别代表了什么意思？**

**A：**新建创意素材上传位置选择开屏图片，表示的是您要上传更高像素的素材。如果您选择的版位包含有开屏样式，不管是上传普通图片还是开屏图片都有可能投到开屏，只是选了开屏图片需要上更高像素的素材。

**Q15：使用管理式华为账号登录授权Marketing API时提示"暂不支持此业务"该怎么办？**

**A：**请先确认该账号对应的客户端id是否已申请Marketing API权限，已申请权限审批后就自然支持。

**Q16：在投放后台创意雷达工具里，素材详情页展示的投放行业具体是指开户时选择的客户行业还是审核行业？**

**A：**是搭建创意时所选的创意行业。

**Q17：关于投放后台的投放频次设置，时长和展示频次均设置为1表示什么？**

**A：**设置一天一次，表示这个任务的广告一天在同一个用户面前只会展示一次。这里是按照单任务维度设置的。
