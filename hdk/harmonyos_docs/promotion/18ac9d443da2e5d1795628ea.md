# 消息设置

#### 功能简介

鲸鸿动能投放平台提供消息通知功能，通知方式包括站内信、手机短信和邮箱三种，消息类别包含系统消息、审核消息、账户消息和财务消息。  

#### 操作步骤

1. "消息设置"页面支持添加联系人，单击右侧"编辑"，可自定义发送通知的消息类别与通知方式。![](https://media:101784100609923828 "点击放大")
2. 通知方式如选择"站内信"，则可单击账户右上方"![](https://media:101784100609949829 "点击放大")"查看消息内容，在该页面也可进入"消息设置"界面。
