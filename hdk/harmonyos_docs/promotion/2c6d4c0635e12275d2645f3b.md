# 2026年AppGallery应用推广激励（HarmonyOS 5.0及以上版本应用/游戏）

## 活动介绍

AppGallery应用推广激励，是华为应用市场面向开发者推出的用户增长激励政策，激励对象为HarmonyOS 5.0及以上版本应用/游戏，助力伙伴在HarmonyOS应用生态价值增长。

## 激励方案

|-----------------------|----|----------------|---------------------|--------|
|激励对象|激励场景|激励方案|激励考核期|最高激励金额|
|HarmonyOS 5.0及以上版本应用/游戏|新投激励|首次消耗1万现金后，返5万激励金|2026年1月1日-2026年12月31日|5万元（单应用）|
|HarmonyOS 5.0及以上版本应用/游戏|消耗返利|考核期内总现金消耗*25%|2026年1月1日-2026年12月31日|不封顶|

## **具体事项说明**

1. 激励对象：HarmonyOS 5.0及以上版本应用/游戏（不含元服务）。
2. 新投激励：HarmonyOS 5.0及以上版本应用/游戏（不含元服务），在2026年首次消耗满1万元现金即可享受5万元激励。2026年1月和2月达标的激励金将在3月10日前发放完毕；3月11日起，激励金将在达标后7个工作日发放（如遇节假日顺延）。该激励金须在生效后30天内消耗完毕，逾期失效，激励金额度上限为5万。
3. 消耗返利：2026年1月的返利金将在3月10日前发放，2月1日起产生的返利金将在次月15号之前（如遇节假日将顺延）发放，该返利金须在生效后365天内消耗完毕，逾期失效。
4. 使用场景：仅包含单独创建的HarmonyOS 5.0及以上版本应用/游戏的任务的应用推广。
5. 以上激励金的到账情况，可在鲸鸿动能投放端"我的账户"中"新投激励"和"消耗返利"中查询，因自身问题导致账号异常/注销无法发放的不支持补发。
6. 除另有约定外，账单和金额以华为应用市场数据为准。如发现不符合报名条件的情况，华为应用市场将对数据进行复核，并仅在符合激励条件的范围内发放激励，账单和金额以复核调整后的为准。
7. 政策期间，推广产品及相关推广投放应保持合法合规运营，不得出现违反法律法规或侵犯第三方合法权益的情形，否则华为应用市场有权取消推广产品的政策适用资格并采取相关处罚措施。

## FAQ

**开发者在哪里可以查看"2026年AppGallery应用推广激励"发放结果？**

客户在"开发者联盟"、"鲸鸿动能广告平台"的财务信息、鸿蒙应用新投激励页面及"鲸鸿动能-服务商管理平台"的返利金账户详情和鸿蒙应用市场激励金页面，均可查看激励发放情况，详见文档"[鸿蒙应用推广激励查询](https://developer.huawei.com/consumer/cn/doc/promotion/bp-query-0000002558498301)"。

**哪些应用不能参与"2026年AppGallery应用推广激励** **"** **？**

HarmonyOS 4.X 及以下版本应用/游戏不参与AppGallery应用推广激励， 但可参与"星火计划2026"激励。

**同一开发者的多个应用** **均可享受激励** **吗？**

可以。一个开发者下涉及多个符合条件的应用/游戏，消耗达标后获得相应达标激励，但单应用/游戏2026年最多享受1次新投激励的权益。

**全球的开发者都可以参与吗？**

仅适用于中国大陆注册并推广的开发者参加，应用满足鸿蒙激励发放条件后按承诺日期进行发放，无需报名。

**获得的激励金是否支持中国大陆以外地区使用？**

不支持，当前仅支持中国大陆地区推广使用。

**开发者账户既有激励金也有现金时，消耗的顺序是怎么样的？**

鸿蒙应用推广任务的消耗优先级为：鸿蒙应用新投激励＞鸿蒙应用消耗返利＞其他返利＞现金。

**专项激励金是否可以用在** **HarmonyOS 4.X** **以下的应用** **/** **游戏市场进行推广？**

不可以。

**赠送激励金是否只能给获得赠送的单款应用使用？**

首先，鸿蒙"新投激励"和"消耗返利"都只能给HarmonyOS 5.0及以上版本应用/游戏（不含元服务）使用。

其次，"新投激励"只能给账户内在"鸿蒙应用新投激励"页面，激励金显示"已激活"状态的应用使用，且单应用最多消耗5w新投激励；"消耗返利"可以给账户下所有鸿蒙应用使用，且没有单应用的消耗上限，因此账户内如果有多个在投鸿蒙应用的话，可能会出现"消耗返利"早于"新投激励"使用完的情况。

**2026年AppGallery应用推广激励活动激励金/返利金发放到哪个账户？如果投放中途更换服务商，怎么更换返利发放的账户呢？**

"消耗返利"默认发放至直客/一级服务商账户，若遇到中途更换服务商的场景，可联系对应销售进行返利账户切换申请，生效后激励金将会发放至指定的新一代账户当中；

"新投激励"默认发放至鸿蒙应用投放授权的直客/投放操作账户（单应用只授权给一个投放操作账户投放的情况下），若单应用授权给同个一级服务商下的多个投放操作账户投放，则发放至一级服务商账户；

另外，"新投激励"支持客户登录直客账户，将"新投激励"授权发放至指定投放操作账户，详细操作指引见"[鸿蒙新投激励授权指引](https://developer.huawei.com/consumer/cn/doc/promotion/bp-query-0000002558498301#section141031047228)"。

**鸿蒙应用推广现金消耗满1** **万元了，但该应用的新投激励显示"未达标"是什么原因呢？**

鸿蒙应用新投激励在发放前，该应用的新投激励状态都会显示"未达标"，在新投激励发放后，会显示为"已激活"；另外，新投激励金将在达标后7个工作日发放（如遇节假日顺延）。

**赠送激励金可以申请退款吗？**

赠送激励金不支持退款申请，请尽快使用，以免过期。

**本次应用推广激励活动持续时间有多久？**

本次应用推广激励活动有效时间以华为应用市场对外发布为准，如有变更我们将另行通知。
