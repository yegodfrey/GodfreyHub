# 低俗性暗示专题解读

**《广告法》第三条**

广告应当真实、合法，以健康的表现形式表达广告内容，符合社会主义精神文明建设和弘扬中华民族优秀传统文化的要求。

**《广告法》第九条**

第九条、广告不得有下列情形：（八）含有淫秽、色情、赌博、迷信、恐怖、暴力的内容；

根据官方指南，互联网低俗性、暗示内容是指以撩起性兴奋为目的，而展示或描述人类身体或人类性行为的一种表现，表现方式包括不限于：

**直接/隐晦表现性行为：**包括直接暴露描写、表现性行为、使用带有性暗示或性挑逗的语言描述性相关内容。

**以身体特征为噱头的低俗宣传：**如未着衣物仅用肢体掩盖隐私部位，或发布走光、偷拍等内容。

**以低俗方式吸引流量：**使用庸俗挑逗的标题，或传播一夜情、换妻等有害信息。

**相关案例仅用于展示审核规则，并不代表鲸鸿动能广告对此持认可态度**。
