# 广告账号管理

支持查看、修改鲸鸿动能广告账户联系人信息，提交后鲸鸿动能广告平台会进行审核，审核通过，则信息更新成功。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/cs8g585dTUCYgisJRZpoNA/zh-cn_image_0000001182712204.png?HW-CC-KV=V1&HW-CC-Date=20260920T074030Z&HW-CC-Expire=31536000000&HW-CC-Sign=3A8679F5CF7DCAB33C7E5A0D552B372FBABA465CF04F8D8DF4A21F888241E3FD)

支持查看并下载已签署协议，使用主账号登录鲸鸿动能广告平台，单击"**工具** "->"**广告账号管理** "，单击"**下载**"，保存跳出的密码，下载完成后使用该密码查看协议。
