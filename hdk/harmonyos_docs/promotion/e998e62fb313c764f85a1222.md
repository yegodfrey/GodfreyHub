# 广告账号管理

支持查看、修改鲸鸿动能广告账户联系人信息，提交后鲸鸿动能广告平台会进行审核，审核通过，则信息更新成功。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/cs8g585dTUCYgisJRZpoNA/zh-cn_image_0000001182712204.png?HW-CC-KV=V1&HW-CC-Date=20261008T192048Z&HW-CC-Expire=31536000000&HW-CC-Sign=A5AE234BF8833B3D599DD56E59307A5A3639E15B34D2DD23DC6710BF3FE845E8)

支持查看并下载已签署协议，使用主账号登录鲸鸿动能广告平台，单击"**工具** "->"**广告账号管理** "，单击"**下载**"，保存跳出的密码，下载完成后使用该密码查看协议。
