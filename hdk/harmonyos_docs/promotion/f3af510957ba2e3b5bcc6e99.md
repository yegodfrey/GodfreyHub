# 查看财务信息

## 概述

广告主在鲸鸿动能平台充值、投放广告后，可在投放端查看财务信息。

## 操作步骤

1. **登录鲸鸿动能广告平台** **：** 单击"![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/Iiqfpq2AR12by-DidrF3TQ/zh-cn_image_0000001815173014.png?HW-CC-KV=V1&HW-CC-Date=20260918T093100Z&HW-CC-Expire=31536000000&HW-CC-Sign=BA40AFF1F2172F96AF7C855A15D3A4BBB656FF19465590476129318D7AAED3FE)"->"查看财务信息"
2. **查看财务信息：**财务信息主界面包括账户日预算、现金账户、虚拟账户、财务记录和转账记录。

   * 财务记录：显示总支出、现金支出、 和虚拟账户（赠送金、返利金）支出数据，支持下载财务记录报表。
   * 转账记录：支持查看转入和转出记录、对方账户名称以及转账类型（现金、赠送金或返利金）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/30/v3/yEDLYf-ETAiBnVzC-OwBTg/zh-cn_image_0000001861732853.png?HW-CC-KV=V1&HW-CC-Date=20260918T093100Z&HW-CC-Expire=31536000000&HW-CC-Sign=D1B6CA09D609D9A4319C9E88061EA320884B0503496565BA73DE411878F8CFF5 "点击放大")

## 名词解释

**现金账户** **：**现金是广告主实际充值金额。

**虚拟账户：**虚拟账户余额 = 赠送金余额 + 返利金余额。

**赠送金：**鲸鸿动能赠送给广告主的可消耗金额，一般由活动或其他特殊场景产生。

**返利金：**鲸鸿动能根据线下合同约定的消耗返利政策，给与服务商的消耗返利金额。
