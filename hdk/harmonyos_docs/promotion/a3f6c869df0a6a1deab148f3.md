# 申请客户端ID

Marketing API 采用OAuth2.0授权码模式（authorization code）进行授权认证，所有接口均通过请求头中传递的授权令牌（access_token）来进行身份认证和鉴权。

## 操作步骤

1. 使用**通过[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)** 的华为团队主账号登录[华为开发者联盟](https://developer.huawei.com/consumer/en/console#/serviceCards/)，请不要使用团队账号。
2. 选择"管理中心"->"HMS API服务" -> "凭证"，单击"创建凭证"->"OAuth2.0 客户端ID"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/QDb8jZX2SIi-TMdNc9qzJg/zh-cn_image_0000001192901908.png?HW-CC-KV=V1&HW-CC-Date=20260920T074031Z&HW-CC-Expire=31536000000&HW-CC-Sign=BB92FC66C3595157C70D0D26212D38E896CCDFEC4464BED75D3FF09F29BD0319)

3. 各字段填写方式如下：

   * 产品类型：服务器应用（只能选这个，其他MAPI不可用，默认值）
   * 产品名称：客户端名称
   * 应用类型：应用
   * 默认语言： 英文
   * 回调地址：必填，且必须是https协议类型网址。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/h0Y83titSkmgfUWmDp7T5w/zh-cn_image_0000001193061906.png?HW-CC-KV=V1&HW-CC-Date=20260920T074031Z&HW-CC-Expire=31536000000&HW-CC-Sign=0E00F24E3CA8BDB0491FC6C31EA5666832F62CAB057EF1BE594B712F451A049B "点击放大")

4. 单击"创建"，创建凭证成功，复制"客户端ID"和"秘钥"即可。
