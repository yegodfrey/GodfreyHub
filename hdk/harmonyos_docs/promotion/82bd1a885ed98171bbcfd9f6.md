# 添加创意标签

1. 创建或修改推广任务时，若该任务支持推广创意功能，勾选"编辑辅助创意"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/X29qAAKWTsu4LNhcfezsgA/zh-cn_image_0000002525059902.png?HW-CC-KV=V1&HW-CC-Date=20261008T145021Z&HW-CC-Expire=31536000000&HW-CC-Sign=E1F7D346B2D7ED3BD7B7D006956D2B0F3572F0E204A0A457117237F28D558330 "点击放大")

2. 进入"推广创意"页面，在"创意展示"区域，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/6ewaW2XLRfKmbrGHmvCuHg/zh-cn_image_0000002555989527.png?HW-CC-KV=V1&HW-CC-Date=20261008T145021Z&HW-CC-Expire=31536000000&HW-CC-Sign=6A1B792B2D586F9021E5F0A917958D8AC0DDD7A2EFF5364AF0EBFB647A28EA60)。 说明
   > * 因创意标签较多，建议您根据创意内容按照关键词模糊搜索，高效勾选对应创意标签。
   > * 当前最多可添加5个三级标签。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/mqLqjqH5St2QRBvnB-PmkQ/zh-cn_image_0000002525069570.png?HW-CC-KV=V1&HW-CC-Date=20261008T145021Z&HW-CC-Expire=31536000000&HW-CC-Sign=2FEA33EA44F8A5540A57EDCB4323882BF7DDECB22E12AA31CDAFB096D362220A "点击放大")
3. 在弹出的"创意标签选择"窗口输入创意相关的关键词或下拉选项，勾选三级创意标签，完成后点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/_JB1o7iPRk2p_wevTYh0Sg/zh-cn_image_0000002556109493.png?HW-CC-KV=V1&HW-CC-Date=20261008T145021Z&HW-CC-Expire=31536000000&HW-CC-Sign=6BC7A318B8540FD55C343071B4057982A1495D8C0A3ECCB538F7DAD211CD3061 "点击放大")
