# 添加创意标签

1. 创建或修改推广任务时，若该任务支持推广创意功能，勾选"编辑辅助创意"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/X29qAAKWTsu4LNhcfezsgA/zh-cn_image_0000002525059902.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=E1C7122FEE9F1829163953A2D044310C8A69D39AA44357062021D6BD29274C83 "点击放大")

2. 进入"推广创意"页面，在"创意展示"区域，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/6ewaW2XLRfKmbrGHmvCuHg/zh-cn_image_0000002555989527.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CDB0674A598DE7C5713D42F02B951DA3AB8AF696B83F3EB7A4C18F79DCAF04A)。 说明
   > * 因创意标签较多，建议您根据创意内容按照关键词模糊搜索，高效勾选对应创意标签。
   > * 当前最多可添加5个三级标签。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/mqLqjqH5St2QRBvnB-PmkQ/zh-cn_image_0000002525069570.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=8BDC543111C5901AF8AC0C04E5D2120E3E2C296704DC22138D3F6BCE9CC4B401 "点击放大")
3. 在弹出的"创意标签选择"窗口输入创意相关的关键词或下拉选项，勾选三级创意标签，完成后点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/_JB1o7iPRk2p_wevTYh0Sg/zh-cn_image_0000002556109493.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=7AB12BC25B5F204D993D307C2DA1FB25E87A7333F34F9FF0DB08FE34113F5074 "点击放大")
