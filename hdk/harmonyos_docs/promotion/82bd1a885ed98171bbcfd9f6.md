# 添加创意标签

1. 创建或修改推广任务时，若该任务支持推广创意功能，勾选"编辑辅助创意"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/X29qAAKWTsu4LNhcfezsgA/zh-cn_image_0000002525059902.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=2A7D43D066E5A8E3A9278B8E254185AAB9E1C3730CB8AB7690BFA8F642C71259 "点击放大")

2. 进入"推广创意"页面，在"创意展示"区域，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/6ewaW2XLRfKmbrGHmvCuHg/zh-cn_image_0000002555989527.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=D26B8F0F18ACA7FE8778C1FAE248656CD1645FB9B75657FA79A525A1458B9429)。 说明
   > * 因创意标签较多，建议您根据创意内容按照关键词模糊搜索，高效勾选对应创意标签。
   > * 当前最多可添加5个三级标签。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d3/v3/mqLqjqH5St2QRBvnB-PmkQ/zh-cn_image_0000002525069570.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=7C4530A65984DE39A455FD0BA4C3ED95884F7DBDFA6B265B6B69ADC9CD19E980 "点击放大")
3. 在弹出的"创意标签选择"窗口输入创意相关的关键词或下拉选项，勾选三级创意标签，完成后点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/_JB1o7iPRk2p_wevTYh0Sg/zh-cn_image_0000002556109493.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=A231759E801DB22EB05015A4EC46AF5CCEE358500EA1FF452CE7BFFF3E735928 "点击放大")
