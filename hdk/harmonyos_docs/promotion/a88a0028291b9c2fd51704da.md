# 简介

在广告推广过程中，通过第三方监测，广告主可获得由客观公正的第三方监测公司提供认证的广告数据，监测目标广告的曝光、点击等关键指标。目前，鲸鸿动能已与秒针、国双等多家第三方监测公司实现技术对接。  

#### 实现方式

在广告创建过程中，平台可通过广告主填写的监测地址将创意的曝光/点击数据发送到第三方平台服务器。

通过约定监测地址 URL 中指定格式和名称的字符串，确定每次曝光/点击发生时需要上报给第三方平台服务器的信息。

当前支持的监测字段和地址格式要求如下：

* 支持字段  

  |宏名称|字段描述|
  |:--------------|:-------------------------------------------------------------------------------------|
  |__OS__|操作系统名称，仅支持安卓|
  |__IP__|IP地址|
  |__APP__|媒体名称 utf-8编码|
  |__REQUESTID__|广告请求ID 替换为 __REQUESTID__ 或 __HWPPSREQUESTID__|
  |__OAID__|OAID，原值，如果用户关闭了个性化广告，OAID会被设置为全0，例如: 00000000-0000-0000-0000-000000000000，附加\&optout=1|
  |__TERM__|机型|
  |__CREATIVE_ID__|素材ID|
  |__UA__|设备的UA|

* 监测地址格式 监测地址链接是由第三方监测平台提供的、用于鲸鸿动能将曝光/点击数据传输给第三方监测的链接。

  监测地址格式由"前缀+服务器域名+参数"三部分构成，其中：

  ① 前缀只能是 https 开头。

  ② 服务器域名必须是能够正常访问的正式域名，不接受 IP 或下载链接。

  ③ 参数必须是全大写字母，两边为双下划线（参数左右两边均为两个连续的英文字符"_"），可根据实际选择需要的参数，并使用与号 (\&) 分隔参数。

  示例：

  https://www.huawei.com/track_click.ashx?k=2129556\&p=7QJNf\&ns=__IP__\&tr=__REQUESTID__\&m0=__OS__\&m1=__OAID__

  <br />

* 多组监测链接

  鲸鸿动能支持在创意层级进行多组监测链接，用以将曝光/点击数据同时发送给不同的三方监测公司。您可以选择以下两种填写形式：

  ①秒针监测特有，不同的三方监测链接通过参数的形式进行串联，合并为一个链接，并发送曝光/点击数据。注意监测链接需以[https://e.cn.miaozhen.com](https://e.cn.miaozhen.com/)开头。

  示例：https://e.cn.miaozhen.com/r/k=000\&dx=__IPDX__\&rt=2\&tr=__REQUESTID__\&gc=__GCID__\& o=https%3A%2F%2Ftrace.rtbasia.com%3D__MAC1__%26idfa%3D__IDFA__

  ②通用形式，不同的三方监测链接并联，以英文分号作为分割。鲸鸿动能将会同时对所有并联的三方监测链接进行曝光/点击数据的发送。

  示例：

https://b.lnk0.com/osversion=__OS__\&requestid=__REQUESTID__\&oaid=__OAID__;https://g.cn.miaozhen.com/ osversion=__OS__\&requestid=__REQUESTID__\&oaid=__OAID__;https://trace.rtbasia.com/ osversion=__OS__\&requestid=__REQUESTID__\&oaid=__OAID__
