# 分享商品库

【简介】经理账户分享某一个商品库给广告主

请求地址

https://ads.cloud.huawei.com/openapi/v2/tools/dpa/product/share_store/create

请求方法

POST

请求参数  

|--------------|----------|----|--------------------------|
|参数名称|类型|是否必选|描述|
|manager_id|string|是|经理账户|
|store_id|string|是|商品库ID|
|advertiser_ids|String\[\]|是|该商品库共享的广告主id集合，不包括该商品库的所有者|

<br />

请求示例

POST openapi/v2/tools/dpa/product/share_store/create HTTP/1.1

Accept:application/json

Content-Type:application/json
