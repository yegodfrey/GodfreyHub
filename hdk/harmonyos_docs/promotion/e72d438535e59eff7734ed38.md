# 2026年5月

**【规则注意】2026"美加墨世界杯"广告创意投放事项**

**1、** **未经授权不得使用FIFA品牌资产或强相关元素**

|------|-----------------------------------------------------------------------------------|
|**序号**|**审核规范**|
|a|不得使用世界杯官方标志进行推广宣传|
|b|不得在文案中使用世界杯相关文字进行推广宣传（世界杯相关文字：FIFA、FIFA World Cup、World Cup、World Cup2026、世界杯、美加墨等）|
|c|不得使用世界杯元素（官方奖杯、官方吉祥物、官方足球、官方口号等）进行推广宣传|
|d|不得使用世界杯主题曲旋律及歌词（包括历届主题曲）进行推广宣传|
|e|不得使用本届世界杯参赛国家队国旗进行推广宣传|
|f|除非由FIFA 授权或与FIFA 权利持有者合作安排，否则不允许将世界杯门票用于推广、抽奖、奖励、在线拍卖及任何其他类型的消费者推广活动|
|g|未经授权不得借用世界杯相关的加油助威文案，进行商品营销宣传|
|h|在商品上使用官方知识产权或其任何元素是FIFA权利持有者的专属权利，未经授权，任何商家与平台严禁违规倒卖或自制售卖世界杯周边产品|
|i|不得涉及历届世界杯元素进行推广宣传|

**2、** **世界杯期间在广告中使用与本届世界杯参与者相关的注意事项**：在世界杯期间，非FIFA商业合作伙伴如果需要继续开展与本届参赛的球员/国家队等参与者相关的广告活动，需同时满足以下条件

|------|------------------------------------------|
|**序号**|**审核规范**|
|a|广告获得相关球员/国家队的许可授权|
|b|广告中没有使用世界杯属性|
|c|广告遵守FIFA、美加墨政府以及运动员所在国家政府的政策（如禁止参与违反法律的活动）|

**3、** **世界杯期间发布祝贺广告的注意事项**：非FIFA商业合作伙伴不得在世界杯期间发布祝贺广告（congratulatory advertising）

|------|------------------------------------------------------|
|**序号**|**审核规范**|
|a|非FIFA商业合作伙伴不能在世界杯期间发布祝贺广告（包含对参加世界杯球员/国家队的支持或同情等信息）|
|b|非FIFA商业合作伙伴的祝贺广告可在世界杯结束之后（或者开幕之前）发布，并且不使用任何世界杯元素或世界杯属性|
