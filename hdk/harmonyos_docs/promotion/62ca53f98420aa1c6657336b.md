# 2026年8月高频问题Q&A

**Q1：账户中搭建鸿蒙应用事件时，联调数据来源只有HMS跟踪，没有专属监测工具跟踪的选择，是什么原因？**

**A：**这种情况一般是新建资产时没有选择专属监测工具导致的。您可以将对应资产删除重建，新建时关联分析工具选择专属监测工具即可。

**Q2：推广医疗器械销售，推广链路可以跳转添加企业微信吗？**

**A：**涉及医疗器械推广需要上架知名第三方电商平台（如淘宝/京东等），不支持导流到企业微信，也不支持用维纳斯落地页承接添加企业微信。商品广告不支持这种链路。

**Q3：离线资产管理具体是一个什么工具？**

**A：**离线资产管理是一个回传广告主用户资产的工具，广告主可以通过离线文件（zip/txt/csv格式）的方式把用户id回传给平台，平台把这些用户id用于模型训练、人群拓展等后续广告环节的应用；离线资产管理的好处是免去广告主联调接口的人力和时间。

**Q4：为什么浏览器搜索直达版位的品牌名称显示限制7个字，其他版位可以10个字？**

**A：**浏览器搜索直达版位当前品牌名称是7个字的限制，不同版位的品牌名称在后台设置的长度限制会有不同，具体请以后台显示的为准。

**Q5：推广短剧时，每一部短剧都需要单独上传对应的资质吗？**

**A：**广告素材如果有推广具体的短剧，那么涉及到的就需要提供对应短剧的《微短剧发行许可证》、省级广电批准文件或节目登记备案资质。

**Q6：账户里某个推广素材比较优质，打算通过链接的形式进行分享，是否支持？**

**A：**当前两个方案可以实现到您要的素材链接地址：

1.如果您有对接Marketing API，可以通过Marketing API-查询创意接口，获取素材地址，详见接口文档：[查询创意](https://developer.huawei.com/consumer/cn/doc/promotion/ads_new_api14-0000001455880049)

2.可以让贵司内部研发人员在投放端后台中把图片转变成链接地址的形式即可，具体操作方式一般研发人员都会，平台侧没有相关文档说明或教程。

**Q7：创建APP行为人群时，对应APP的任务必须要有消耗产出吗？**

**A：**有提交对应APP任务就可以。需注意：当天创建的任务，预计创建后第三日同步数据，之后才可以在创建APP行为人群中搜索到。

**Q8：RTA功能开通后，假设账户阶段性的暂不需要，是否可以在账户端操作关闭？**

**A：**如果不需要RTA功能，可以联系对应行业运营申请关闭RTA权限即可，不过RTA权限是账户维度的，如后续需要再次开启请再次联系行业运营申请。自行操作的话，只能将整个账户所有任务暂停，但新建任务开启时还是默认打开的，所以还是建议联系行业运营申请启停。

**Q9：在人群管理后台三方人群中，人群包没有显示原始上报人数是什么原因？**

**A：**该指标是对应字段的创建人群接口上传的，最终投放请以实际覆盖人数为准。

**Q10：推广小程序产品时需要提供软著资质吗？**

**A：**正常上架且可以自然搜到的小程序产品可以不用提供软著资质。

**Q11：如果子客账户中同时存在华为自有媒体返利金和通用返利金，但是通用返利金有效期即将到期，这时账户会优先消耗哪种资金?**

**A：**先类型后时间，按类型优先，当前平台消耗顺序下整体规则如下：纯赠送金-华为自有媒体>纯赠送金-通用>充值赠送金-华为自有媒体>充值赠送金-通用>返利金-华为自有媒体>返利金-通用>现金。所以您的疑问中先消耗的是华为自有媒体返利金。

**Q12：目前广告投放有用弹窗形式展现的吗？**

**A：**当前在华为自有媒体中是没有的；版位涉及三方媒体，且有激励视频的就会有可能投放到弹窗广告。
