# 创建网页落地页

**网页落地页：**为用于获取潜在客户信息（如姓名，电话号码等）或直接引导客户线上购买商品，主要通过表单、电话、抽奖、在线咨询等营销方式获取客户信息，通过商品订购组件完成商品售卖闭环。

## 操作步骤

1. **进入创建落地页界面**

   在落地页工具"首页"单击"创建落地页"或在"我的落地页"界面单击"新建落地页"或直接点击导航栏"模板选择"，进入创建落地页界面，单击"网页落地页"，跳转至网页落地页创建界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/b-aqoCziSdOv3weE6rn5Ag/zh-cn_image_0000001673919369.png?HW-CC-KV=V1&HW-CC-Date=20260918T093102Z&HW-CC-Expire=31536000000&HW-CC-Sign=AE0CB13C5A90DC04CD2C93EF0CE341502E138DEDD228605A460103DEA3472A4E "点击放大")

2. **进入落地页编辑页面**

   方式一：单击"自由布局"空白模板，进入网页落地页编辑页面。

   方式二：选择合适的落地页模板，鼠标悬停模板上，单击"预览"可查看模板内容详情，单击"使用"则进入模板编辑页面。

3. **编辑落地页**

   落地页编辑页面分为3个区域，左侧为组件展示区，中部为页面编辑区，右侧为组件编辑区，广告主根据自身需求点击或拖拽左侧的组件进入页面编辑区，在页面右侧进行组件内容、排版等设置，如为模板建站，可直接在页面右侧组件编辑区替换相应组件内容素材。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/MesG1m0qRbOutjXjjgFVIw/zh-cn_image_0000002663575293.png?HW-CC-KV=V1&HW-CC-Date=20260918T093102Z&HW-CC-Expire=31536000000&HW-CC-Sign=CC793537F3BA9DD3F1447CF080637FC5065AE34B2D12D55A401C57A42B88F7BA "点击放大")

4. **配置营销组件**

   网页落地页营销组件支持表单、电话、在线咨询、抽奖、企业微信、多线沟通和跑马灯。
   * 表单组件： 可使用表单组件收集潜在用户信息，支持多种表单类型，留资后意向收集能力，同时支持提交跳转链接页面。

     * 基础信息：您可以填写表单的名称，并且可以选择表单类型：常规表单、置底表单、一键留资表单、一键留资置底表单、对话加微和对话留资。
     * 表单内容：您可以根据自己的需求，选择表单收集的内容，自定义输入提示，是否必填等相关设置。
     * 线索设置：数据转发，您需要填写数据转发接口，具体可参考单击右侧操作指引，您还可以设置是否开启手机号码短信验证和手机号码去重。
     * 隐私声明：由于您收集的是用户信息，基于隐私合规化，请设置您的隐私声明，让用户知悉并同意您按照隐私声明使用信息，我们将在表单下方展示声明链接以便查看。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/GFwFkdwoTzW4luNrLirleQ/zh-cn_image_0000002663577535.png?HW-CC-KV=V1&HW-CC-Date=20260918T093102Z&HW-CC-Expire=31536000000&HW-CC-Sign=457C185AE086D63FCC4E1AE2D153B601058F6631318D8895567BF658F189B911 "点击放大")
   * 电话组件：通过电话组件可直接调起手机拨号盘，智能电话支持手机号码、固定电话和400电话。
   * 咨询组件：通过咨询组件可直接跳转至在线咨询页面，支持对接多家第三方在线咨询平台。
   * 抽奖组件：可通过抽奖活动收集用户姓名、手机号信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/g40oc7HzSSapSnFigchcMw/zh-cn_image_0000001674119501.png?HW-CC-KV=V1&HW-CC-Date=20260918T093102Z&HW-CC-Expire=31536000000&HW-CC-Sign=D4C7C27D351A4E5FB5D1C9DB12B4DD63D0D3E902D770CA0A3069C85D377A61C5 "点击放大")

   * 商品订购组件：可通过商品订购组件让用户下单购买商品；该组件白名单开放，如需使用请联系运营经理开通。
   * 多线沟通组件：咨询、电话、表单、订购四种组件随意组合，不同方式触发不同类型用户转化。
   * 跑马灯为辅助营销组件，需关联落地页内的表单或抽奖、订购组件使用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/5qmGaN-rRVGQHSKdPbkZAg/zh-cn_image_0000001625279812.png?HW-CC-KV=V1&HW-CC-Date=20260918T093102Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A9DF0D80D0FB46E56028981D3A11BD31D4A6319074D52965455FAA77565E46D "点击放大")

     表单、智能电话和抽奖组件需关联已创建的营销活动，以表单为例，如无营销活动，单击右侧编辑区的"新建表单"或"表单管理"前往营销组件界面创建表单。

5. **调整落地页页面**

   如对之前的操作不满意可以点击落地页编辑区上方的撤销、重做按钮，如对某个组件不满意可单击组件编辑区右上角的"删除当前组件"直接删除，还支持添加空白模板、模块下移、模块设置、组件图层（支持拖动改变组件图层顺序）、删除模块、调整模块长度等操作。

6. **编辑完成**

   页面基础信息与组件内容编辑完毕，可单击页面右上角的"预览"，实时预览新建落地页；单击"保存"，新建落地页以草稿的形式保存至"我的落地页"，单击"提交"，落地页提交审核。

7. **线索转发设置**

   通过营销组件收集的用户线索，若广告主有CRM系统，可通过线上对接维纳斯线索转发接口，实现线索直接入库，提升线索处理时效性。

   广告主可在顶部导航单击"营销组件"-"线索转发设置"进入线索转发接口配置界面，详细对接流程请参考[《维纳斯线索推送接口说明》](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260715153056.15921070983183683172826743950900:50001231000000:2800:D3CE7BE037CAB9B7C2E60D27C84FC74E2AB8F54DF4C02D132645767109BED88E.pdf?needInitFileName=true)和[《维纳斯营销线索推送操作指引》](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260715153056.98507391403499393009557163217923:50001231000000:2800:F69E5491B1A589571D7CB3D05505655408671085A407DA7281B662896A62916A.pdf?needInitFileName=true)。或在配置界面查看"操作指引"。
