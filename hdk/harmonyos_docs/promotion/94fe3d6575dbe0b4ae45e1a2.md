# 查询深度转化目标

【简介】通过此接口可以查询深度转化目标，需要向运营申请转化指标权限。使用深度转化目标需要先创建相应的[转化跟踪指标](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-appendix1-0000001174597591#section125615641916)。例如，使用激活应用为浅层指标同时使用[浏览商品](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-appendix1-0000001174597591#section125615641916)作为深度转化目标。则需要创建[激活应用](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-appendix1-0000001174597591#section125615641916)和[浏览商品](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-appendix1-0000001174597591#section125615641916)的转化跟踪指标。此时即可使用浏览商品作为激活应用目标的深度转化目标。

请求地址

亚非拉：https://ads-dra.cloud.huawei.com/ads/v1/tools/effect_tracking/deep_effect_target/query

俄罗斯：https://ads-drru.cloud.huawei.ru/ads/v1/tools/effect_tracking/deep_effect_target/query

欧洲：https://ads-dre.cloud.huawei.com/ads/v1/tools/effect_tracking/deep_effect_target/query

请求方法

GET

请求参数  

|-------------|-------|----|-------------------------------------|
|参数名称|类型|是否必选|描述|
|advertiser_id|long|否|广告主ID，对于经理账户或您的多个广告主账户共用一个华为账号，此字段必填。|
|page|integer|是|搜索页码， 取值范围1\~10000；|
|page_size|integer|是|一页展示数量， 取值范围 10\~50；|
|filtering|Struct1|是|过滤条件，此字段必传|

<br />

filtering (Struct1)定义  

|--------------------|----|----|------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|tracking_id|long|是|转化跟踪指标ID|
|creative_size_id|long|否|版位ID|
|targeting_package_id|long|否|定向包ID 详见[【创建定向包】](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-tool-targeting1-0000001338502481)|

<br />

请求示例

GET /ads/v1/tools/effect_tracking/deep_effect_target/query

HTTP/1.1

Accept:application/json

Content-Type:application/json

Authorization:Bearer CgB\*\*\*\*\*\*

<br />

{

"page":1,

"page_size":10,

"filtering":{

"tracking_id":"xxxxxx",

"creative_size_id":"xxxxxx",

"targeting_package_id":"xxxx"

}

}

<br />

响应字段  

|-------|----------|---------------------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|描述|
|code|string|返回码|
|message|string|返回描述|
|data|string\[\]|深度转化目标 详见[深度转化目标](https://developer.huawei.com/consumer/cn/doc/promotion/marketing-api-appendix1-0000001174597591#section1042612114174)|
