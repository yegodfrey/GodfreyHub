# 使用创意洞察功能

1. 登录[华为应用市场应用推广平台](https://ads.huawei.com/cn/)。
2. 点击"工具"页签，在"创意工具"中选择"创意洞察"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fd/v3/jArFLufhQty_VIn1bsN2Dw/zh-cn_image_0000002525059898.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=B6ACC1D52B8448B31A5CC39A2636460A758A62ABD80C1F4C37569CF6067D3EB0 "点击放大")

   您也可以在"推广"页面的"创意"页签下，点击"创意洞察"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/DqZs4irpQti7ZODUgsX3nA/zh-cn_image_0000002556099827.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=DD7A8C6521BA5852BFEC4019AAFB3F071B5D3D6B5FC8E2B960E84A1EDDBB8F28 "点击放大")


3. 进入"创意洞察列表"页面，您可以在当前页面搜索、查看其它开发者的创意。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/AUsbFfxERqCT3F0csG3ZTQ/zh-cn_image_0000002524899958.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=F95AA9D159FA3DB34434B80651ECA240D54DD2D3F6158B5C293613D2F1BCE40B "点击放大")

   您也可以点击您感兴趣的创意，查看该创意的详细评价。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/iVt2Wm44RnyJvV3vtfT_EA/zh-cn_image_0000002525071964.jpg?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=471ADADEA542A601F008D6E980D8C7218519CAB1B0511B7110A2D5174A43AF4C "点击放大")

   |参数|说明|
   |:-------|:------------------------------------------------------------------------------------------------------|
   |基本信息|您可以查看该创意的展示类型、应用一句话简介等内容。|
   |数据概览|您可以查看该创意昨日或七日内的点击率、下载率及展示量。 * S级：表现优秀，超过75%的同行 * A级：表现良好，超过50%的同行 * B级：表现一般，超过25%的同行 * C级：表现较差，低于75%的同行|
   |二级品类受众分析|您可以选择在"观看广告人群"或"点击广告人群"页签下，查看性别分布、年龄分布、地区分布的受众分析结果。|
