# 2025年11月

**典型驳回行业：教育、游戏、电商、小说阅读。**

**典型驳回问题场景主要涵盖：**

一、广告内容禁止投放伪科学资讯内容。

二、广告中禁止出现 "原价"等描述。

三、广告内容不得使用带有不良诱导、沉迷游戏的描述。

四、广告素材禁止展示丑陋、恶心不适的画面，影响用户体验。

五、广告不得涉及带有明显性暗示的场景。
