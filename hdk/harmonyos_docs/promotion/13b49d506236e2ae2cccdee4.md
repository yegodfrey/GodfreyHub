# 获取设备意向分

【简介】合作伙伴查询联合建模后的设备意向分。

**请求地址**

https://svc-drcn.ads.huawei.com/opendmp/v3/label/intent-scoure

**请求方法**

**POST**

**请求参数**

|----------------|------|------|------|------|
|**参数名称**|**类型**|**长度**|**必填**|**说明**|
|**advertiserId**|String|100|Y|广告主Id|

**请求示例**

POST http://${base_address}/opendmp/v3/label/intent-scoure

HTTP/1.1

Headers:

Content-Type: application/json

Authorization：Bearer DAEAAIX7IS*****Pd81PDmWiM1KS2

Body:

```codeblock
{
" advertiserId ": "829411234539267456"，// corpId 企业ID
}
```

**响应字段**

|-----------|----------------------|------|--------|---------|
|**参数名**|**类型**|**长度**|**是否必填**|**说明**|
|**code**|int|-|Y|错误码|
|**message**|String|2048|N|描述|
|**value**|List<IntentScoreFile >|-|Y|意向分文件下载地址|

IntentScoreFile

|------------------------|------|------|--------|------------|
|**参数名**|**类型**|**长度**|**是否必填**|**说明**|
|**intentScoreLabelName**|String|-|Y|意向分标签名|
|**intentScoreFileName**|String|2048|Y|意向分文件名|
|**method**|String|-|Y|HTTP请求方法：GET|
|**url**|String|-|Y|请求的URL|
