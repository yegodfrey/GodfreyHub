# 刷新access_token

用Refresh Token来获取新的Access Token。建议在Access Token即将过期的时候调用，Access Token存在有效期，建议定期刷新。

* 调用业务API接口后，如果返回的code为如下内容： =========================================================================================================

  {

  "code": "1000009992",

  "message": "token已过期"

  }

  =========================================================================================================

  请调用刷新access_token接口，重新获取一次access_token，如果仍然失败，将用户登出，重新登录。

<br />

* 请求消息 客户端：广告主服务器

  服务端： 鲸鸿动能广告服务器

  请求协议：HTTPS

  请求方式：POST

  接口URL：https://oauth-login.cloud.huawei.com/oauth2/v2/token

<br />

* 请求参数  

  |参数名称|类型|是否必选|描述|
  |:------------|:-----|:---|:------------------------------------------|
  |grant_type|string|是|RT换AT场景，固定填：refresh_token。|
  |refresh_token|string|是|在授权码模式下获取到refresh_token值。|
  |client_id|int|是|必须和调用/oauth2/v2/authorize接口时传递的client_id一样。|
  |client_secret|string|是|Appid的密钥，在开发者联盟上查看。|

* 请求示例 =========================================================================================================

  POST /oauth2/v2/token HTTP/1.1

  Host: login.cloud.huawei.com

  Content-Type: application/x-www-form-urlencoded

  <br />

  grant_type=refresh_token\&client_id=12345\&client_secret=bKaZ\*\*\*\*\*\*\*\*\*\*\*\*\*d2k9few\&refresh_token=CF2Mm03n0aos9iZZ8nIhfyDtoXy74CXeBi50gVVhMpB0IUzlv9ZwizEvTBhVoF820ZPim0JwNR9j2p1qgEQWnIVYZRlp\*\*\*\*\*\*gekUnsHBkvNev5rd2MdfQMLP

  =========================================================================================================
* 响应参数  

  |参数名称|类型|是否必选|描述|
  |:-----------|:------|:---|:-------------------------------------------------------|
  |access_token|string|是|Access Token。注意在使用的时候要去掉\\这个转义字符。|
  |expires_in|integer|是|Access Token的有效期，以秒为单位。|
  |scope|string|是|Access Token最终的访问范围，即您实际授予的权限列表（您在授权页面时，有可能会取消掉某些请求的权限）。|

* 成功响应消息样例： =========================================================================================================

  HTTP/1.1 200 OK

  Content-Type: text/html;charset=UTF-8

  Cache-Control: no-store

  <br />

  {"access_token": "CFyJ4J\\/l6wuwcFqYOJG4maq2ca8RAV+g0i+mel6qCV5lvqH0PYtW0+BNwfHWg0AqMnW6ZdBvUgs7ijkxMFh1xVP\\/B+vQXz3PWsivkKCuL78XtbLt7vs=", "expires_in": 3600, "scope": "https:\\/\\/www.huawei.com\\/auth\\/account\\/base.profile", "token_type": "Bearer"}

  =========================================================================================================

![](https://media:201786699575450814)  
* json字符串中存在转义符。如果用curl命令或者postman工具手工获取access_token，把"\\/"还原为"/"才是正确的access_token，否则在使用access_token的过程中会报access_token非法。如果是写代码，采用任意的第三方库，都能正确解析json串，获取到正确的值
* access_token和refresh_token参数的长度和其中编码的内容多少有关系，按目前的编码格式，其长度不会超过1000个字符。

* 失败响应消息样例 =======================================================================================================

  HTTP/1.1 400 Bad Request

  Content-Type: text/html;charset=UTF-8
