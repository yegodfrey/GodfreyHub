# 概述

为确保您在鲸鸿动能广告平台（以下简称 "平台"）推广的内容严格遵守国家法律法规及相关政策要求，保障广大用户的合法权益，维护平台合规有序的运营环境，平台基于法律法规要求和平台体验要求制定了广告审核规范，具体要求如下：

1. 合法性：推广内容需符合符合《广告法》等国家相关[法律法规规范](https://developer.huawei.com/consumer/cn/doc/promotion/ads_shenhe32-0000001055095868)，不得存在任何违法违规情形。

2. 资质合规：推广的产品或服务不属于[禁投内容](https://developer.huawei.com/consumer/cn/doc/promotion/ads-jtnr-0000001057745564)，且广告主在开户环节已按平台要求提供完整、真实、有效的资质文件，满足平台[资质审核规则](https://developer.huawei.com/consumer/cn/doc/promotion/ads-zzgz-0000002473340168)。

3. 内容合规：广告创意（含标题、文案、视觉素材、音频内容等）需遵循[平台审核规范](https://developer.huawei.com/consumer/cn/doc/promotion/ads-pttyshgz-0000002505500131)，不得出现违规表述或违规元素。

4. 行业适配：广告主在投放广告时广告创意需满足其所属行业的[特定行业审核规范](https://developer.huawei.com/consumer/cn/doc/promotion/ads-hygz-0000002473340172)。

5. 版位适配：广告主在投放广告时广告创意需符合[版位规则](https://developer.huawei.com/consumer/cn/doc/promotion/ads-bwgz-0000002505500133)（如开屏、智慧屏开机的设计规范与内容要求）。

以上审核规范适用于广告创意中的所有元素，包括标题、文案、素材及落地页等，均需满足相应要求。

<br />

特别提示：您在平台投放时，应当遵守以上规范，经发现存在违反法律法规或以上规范时，依照[平台投放违规管理规范](https://developer.huawei.com/consumer/cn/doc/promotion/ads-toufanguangliguifang-0000001793450445)的相关规定，对投放方处理或处罚。  

#### 禁投内容

广告主在鲸鸿动能广告平台投放之前，需要先确定所推广的产品或服务不涉及禁投内容，如您无法确定内容归属，可选择咨询[在线客服](https://smartrobot-drcn.platform.dbankcloud.cn/?appId=31000)或者通过官方邮箱petalads@huawei.com进行准入咨询。  
禁投内容包括以下两部分：

* [法律法规禁投内容](https://developer.huawei.com/consumer/cn/doc/promotion/ads_shenhe02-0000001058065564)：根据国家法律法规制定的禁投规范。
* [鲸鸿动能平台禁投内容](https://developer.huawei.com/consumer/cn/doc/promotion/ads_shenhe03-0000001057185555)：为了规范平台广告行为，制定的鲸鸿动能广告禁投规范。  

#### 开户审核

广告主在注册鲸鸿动能广告账户后，需要进行企业信息认证（可选择对公银行打款或人工审核认证方式），平台会根据广告主选择的认证方式审核开户资质，具体包含以下内容：

[主体资质](https://developer.huawei.com/consumer/cn/doc/promotion/ads_shenhe04-0000001055414467)：

1. 企业社会信用代码。
2. 企业营业执照（仅当选择人工审核认证时需要提供）。
3. 法定代表人身份证正、反面（仅当选择人工审核认证时需要提供）。

<br />

[行业资质](https://developer.huawei.com/consumer/cn/doc/promotion/ads-hyzzsh-0000001055734442)：

广告主推广某一产品/服务，首先必须获取其经营权限、取得合法的经营许可证。资质文件需经过合法渠道获得，并且真实有效，文件内容清晰可辨认。

<br />

产品资质：

广告主推广的产品或服务，质量或服务程序必须符合国家标准，从而获取的合格证/质检证/特殊认证证明。资质文件需经过合法渠道获得，并且真实有效，文件内容清晰可辨认。

授权及证明资质：

1.知识产权权属及授权证明

* 知识产权权属证明：如涉及专利权、商标权、著作权等知识产权，需提供《商标注册证》《专利证书》《著作权登记证书》或其他权属证明文件。
* 第三方品牌授权：如推广内容涉及第三方商标、联合营销或推广第三方著作作品，需提供《商标注册证书》或其他权属证明文件＋授权书。
* 人物或IP形象授权：如使用知名人物或IP形象进行推广，需提供肖像权授权书、代言合同，或IP权利人（公司/个人）出具的合作协议等合法授权材料。

[《软著著作权授权书示例》.pdf](https://media:101784100489609602) [《形象授权书示例》.pdf](https://media:101784100489655603) 注：仅为参考模板，请结合自身权属、官方登记信息及真实合作场景，如实提交合规资质与授权协议；本平台仅提供参考模板，客户可修改或自拟正式文件。

2.关系说明及授权书

资质材料的主体需和账户主体一致，如账户主体与资质主体不一致，请根据实际关系提交以下对应材料：

* 关联企业关系证明：如账户主体与资质主体为关联企业（存在直接或间接控制关系、或同受一方控制等），需提供有效关联关系证明材料及授权投放协议。
* 业务合作关系证明：如为业务合作（如广告主与广告代理商、品牌与经销商、进口商与物流商、内容创作者及技术服务方等），需提供合法合作协议、采购协议、结算协议等文件。

[《关系说明及授权书示例》.pdf](https://media:101784100489711604) 注：请根据实际运营情况填写关系说明。协议文件具有法律效力，请核实运营信息确保真实准确。本平台仅提供参考模板，客户可修改或自拟相关证明文件。

3.承诺函参考模板

[《承诺函示例》.pdf](https://media:101784100489756605) 注：请结合实际经营和资质如实填写；严禁隐瞒资质、伪造授权、篡改落地页等违规行为。承诺函具有法律效力，请确保内容真实。本平台仅提供授权参考模板，客户可修改或自拟相关证明文件。

#### 素材审核规范

广告主开通鲸鸿动能广告账户后，即可启动广告投放素材准备阶段，素材需符合如下规范：

1. 法律法规规范：基于广告法的基本合规要求制定的规范。
2. 平台规范：基于鲸鸿动能广告平台用户体验制定的规范要求。
3. 特殊行业规范：针对特殊行业制定的特殊规范。

![](https://media:101784100489556601)  
* 所有广告必须满足"法律法规规范"和"平台规范"，特殊行业广告还需满足所属的"特定行业补充规范"。
* 如广告素材涉及明星授权、专利权等需要广告主提供证明资料的情况，须在广告投放前，在平台的广告资质补充相关证明，具体请参见：[《鲸鸿动能平台规范》](https://developer.huawei.com/consumer/cn/doc/promotion/ads_shenhe33-0000001055215903)中的授权及证明资质规范。
* 当广告主在平台提交广告素材，即触发素材审核，如素材不符合规范，将会被驳回，广告主根据驳回意见修改素材。
* 鲸鸿动能广告实行巡检制，不定期对通过审核的广告素材进行二次巡检，如广告素材不符合要求，将做下线处理。

#### 名词解释

广告主资质：指广告主开户时应具有的法律规定的必备资质，分为主体资质、行业资质。

广告素材：指广告主自行设计制作或依法委托他人设计制作的，用于展示广告主的品牌、自己生产或经授权销售的产品、服务的信息内容，广告素材包括广告入口图、广告语、下载链接以及广告落地页的页面内容。

落地页：指用户点击广告后跳转到的页面或重定向的页面，也称目标网址或landing page。
