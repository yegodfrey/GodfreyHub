# 财务管理

服务商平台财务管理包含：充值开票、充值记录、转账记录。

## 充值开票

原应用市场应用推广首页点击"充值和发票"后![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/AN3JUgjtRGCbE_GgDjqdbQ/zh-cn_image_0000002466019110.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=FF3A89C12509BF5DDC0B5CD6305B2A5BC07A5D25140223F0975C52AEE49DED21 "点击放大") ，跳转联盟充值。投放端整合升级后，您可在服务商管理平台------财务管理------充值开票进行充值，支持线上充值和线下充值。
