# 查询创意行业元数据

【简介】通过此接口可以[查询创意行业元数据](https://media:101784100679555837)

请求地址

https://ads.cloud.huawei.com/openapi/v2/promotion/creative_industry_metadata/query

请求方法

GET

请求示例

GET openapi/v2/promotion/creative_industry_metadata/query HTTP/1.1

Accept:application/json

Content-Type:application/json

Authorization:Bearer CgB6e3x9ERGComr9dENxZX22iBk+mLuf1yGtQVPUjPJUMrstfKlqpdXk+kfHU9J8ZJ/soYIZHZzT446GeSYumluQuhsK7jvz4kz1Bkms4CLI/rE=

<br />

响应字段  

|----|-----------|----|------|
|参数名称|类型|是否必选|描述|
|data|Struct1\[\]|否|行业信息列表|
|code|string|否|返回码|

<br />

data (Struct1)定义  

|--------------------|------|----|------------|
|参数名称|类型|是否必选|描述|
|industry_id|string|是|分类（行业）id|
|industry_name|string|是|行业名称|
|industry_desc|string|否|行业描述|
|industry_labels|string|否|行业标签，多个以逗号分隔|
|parent_industry_id|string|否|父行业id|
|parent_industry_name|string|否|父行业名称|

<br />

应答示例

HTTPS/1.1 200 OK

```
{
"code": 200,
"data": [
{
"industry_id": "1001",
"industry_name": "3C及电器"
}
]
}
```
