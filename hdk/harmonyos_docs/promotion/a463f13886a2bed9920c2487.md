# HarmonyOS应用推广任务

> 注意
>
> **文中HarmonyOS应用指HarmonyOS 5.0及以上版本应用。**
>
> 需先完成申请或授权步骤，否则无法进行HarmonyOS应用（HMOS）推广，请参考：
>
> 直客：确认HarmonyOS应用（HMOS）已开通推广评测权限；若未申请，请参考[推广评测申请指南](https://developer.huawei.com/consumer/cn/doc/promotion/bp-start-guest-apply-evaluation-0000001346654709)。
>
> 客户投放伙伴：确认直客已开通推广评测权限，并完成应用授权给客户投放伙伴投放操作账户，请参考[应用授权指南](https://developer.huawei.com/consumer/cn/doc/promotion/bp-start-guest-authorize-0000001346774281)。

## **您可能会遇到其他问题：**

**1."计划已关联任务"弹窗提醒，无法提交任务。**

因为一个计划，只能关联一个任务，故只需重新创建计划，即可提交任务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/BUsKTxRmSpiDyqbxL80hqQ/zh-cn_image_0000002546185781.png?HW-CC-KV=V1&HW-CC-Date=20260918T084030Z&HW-CC-Expire=31536000000&HW-CC-Sign=F44E708270F05C252086A3102201390218362F92437671D9C91E49FA262C5739 "点击放大")

**2."子任务必须大于等于¥2，小于等于¥1,000。保留两位小数。"弹窗提醒，无法提交任务。**

请检查是否每个"场景任务"均有出价信息，若无，则补齐后提交。
