# 查询商品库动态模板

【简介】通过此接口可以查询商品库动态模板

请求地址

https://ads.cloud.huawei.com/ads/v1/tools/dpa/product/templates/query

请求方法

POST

请求参数  

|-------------|-------|----|------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|filtering|Struct1|否|过滤条件，若此字段不传，或传空则视为无限制条件|
|page|integer|是|搜索页码，大于等于1，默认值：1|
|page_size|integer|是|一页展示数量，取值范围 10\~50，默认值: 10|

<br />

filtering（Struct1）定义  

|---------------------|----------|----|-------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|template_ids|string\[\]|否|模板Id，最多10个|
|creative_type|string|否|模板类型详见[【动态模板类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section18914273427)|
|creative_size_width|string|否|模板宽度|
|creative_size_height|string|否|模板高度|
|creative_size_subtype|string|否|创意版位大小子样式|

<br />

<br />

响应字段  

|-------|-------|-------------------|
|参数名称|类型|描述|
|code|string|返回码200：成功，其他错误码标识失败|
|message|string|返回描述|
|data|Struct1|商品库动态模板数据|

<br />

data （Struct1）定义  

|-------------|-----------|----|
|参数名称|类型|描述|
|total|integer|总条数|
|template_list|Struct2\[\]|数据列表|

<br />

template_list（Struct2）定义  

|---------------------|------|--------------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|描述|
|template_id|string|模板Id|
|template_name|string|模板名称|
|template_width|string|模板宽度|
|template_height|string|模板高度|
|template_type|string|商品库动态模板类型 详见[【模板类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section77981429124219)|
|solution|string|模板方案|
|preview_content_url|string|内容url|
|creative_type|string|创意类型|
|creative_size_width|string|创意宽度大小|
|creative_size_height|string|创意高度大小|
|creative_size_subtype|string|创意大小子样式，详见[【版位子样式】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section459185654519)|
|creative_size_type|string|创意大小样式，详见[【版位样式】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section540672213449)|
