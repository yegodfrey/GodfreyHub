# 查询商品库筛选条件取值

【简介】通过此接口可以查询商品库筛选条件

请求地址

https://ads.cloud.huawei.com/ads/v1/tools/dpa/store/dimensions/query

请求方法

POST

请求参数  

|-------------|-------|----|------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|filtering|Struct1|是|过滤条件|

<br />

filtering（Struct1）定义  

|------------------|----------|----|----------------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|country|string|是|商品库投放任务的销售国家|
|dimension_category|string|是|筛选条件类别 取值见[【筛选条件类别】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1848805894013)枚举值|
|flow_resources|string\[\]|是|资源类型 详见[【投放网络】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section11983101283716)|
|dimension_type|String\[\]|否|商品过滤维度 详见[【商品过滤维度】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section18334232399)|

<br />

请求示例  

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|POST /ads/v1/tools/dpa/store/dimensions/query HTTP/1.1 Accept:application/json Content-Type:application/json Authorization:Bearer DAEAALpy3envCfdLiOZRerq2oopxMPmzJmgZOVXs1o27CRO8kHr5z2nyH6bXPxvZIadBeVYgOo1qg3rkXNVd13f9kqn%252F65sm%252Bev7G8h1VT9l3rDMl00q <br /> ``` { "filtering": { "flow_resources": ["FLOW_RESOURCE_SHOWAD"], "country": "CN", "dimension_category": "DPA_DIMENSION", "dimension_type": "CATEGORY" } } ```|

<br />

响应字段  

|-------|-------|--------|
|参数名称|类型|描述|
|code|string|返回码|
|message|string|返回描述|
|data|Struct1|指定对象统计数据|

<br />

Struct1定义  

|----------------|-------|----------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|描述|
|dimension_type|string|商品过滤维度 详见[【商品过滤维度】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section18334232399)|
|dimension_values|Struct2|商品库中的筛选条件列表|

<br />

Struct2定义  

|-----------|-----------|--------------------------------|
|参数名称|类型|描述|
|list_values|string\[\]|筛选条件的取值 对于下拉取值的场景，返回取值列表（同样支持单值）|
|tree_values|Struct3\[\]|筛选条件的取值 对于树形结构取值的场景，返回树形结构的数据|

<br />

Struct3定义  

|---------|------|---------------------|
|参数名称|类型|描述|
|id|long|类目Id|
|parent_id|long|父级类目Id|
|level|int|类目级别|
|value|string|从父节点到叶节点蛇形结构|
|name|string|类目名称，根据请求中的language匹配|

<br />
