# 2026年鲸鸿动能服务商沙龙客户新客试投激励政策

政策周期：2026年6月1日\~2026年12月31日

面向对象：FSD-N1、 FSD-N2、FSD-N3模式下（不含游戏行业、不含快应用）参加服务商沙龙活动，且在活动现场通过二维码留资登记的客户主体，其名下的新产品/品牌

参与条件：

1、新产品/品牌自2026年报名参与政策之日起，前90天在鲸鸿动能无消耗。

2、"新推广产品/品牌"以实际推广内容为准，相同标的视为同一推广内容，不重复激励。最终以鲸鸿动能数据为准。

3、对于旅行社、教育、直投电商等特殊行业，是否属于"新推广产品/品牌"由鲸鸿动能最终判定为准。

4、单一主体限制参与激励的产品/品牌数量不超过20个。

5、单一产品/推广内容单一自然年内仅可参与一次。

报名方式：

1. 沙龙现场成功报名激励的客户主体通过邮件申请激励，报名邮箱：petaladsinc@huawei.com；报名模板联系服务商或对接BD获取。经鲸鸿动能审核确认具备激励资格后发放。
2. 同一客户主体仅可在一家服务商申请激励，客户主体在服务商A的账户申请试投激励政策，不可以在服务商B的账户下重复申请政策。开户子客账户所属服务商需与沙龙主办服务商一致。

激励内容：  

|-------------|----|----|----|-------------------------------------|
|激励名称|计算类型|计算基数|采买模式|返点细则|
|服务商沙龙新客竞价试投激励|\\|\\|竞价|符合参与条件的新客，给予赠送金1万元，直接下发至广告主投放账户，不可转出。|

注：仅限鲸鸿动能DSP；综合DSP和直客DSP不适用本激励。

激励发放形式和使用：  

|-----|----|----|
|竞价投放|发放周期|有效期|
|赠送金充值|月度|180天|

结算方式：

1. 账单和激励金额数据以鲸鸿动能数据为准。
2. 如发现不符合激励条件的情况，鲸鸿动能将对数据进行复核，并仅在符合激励条件的范围内发放激励，金额以复核调整后的为准。激励发放后，如果客户有异议，可以通过服务商发邮件向鲸鸿动能反馈问题，鲸鸿动能进行数据复核。
3. 如涉及数据差异，数据差异在鲸鸿动能数据的10%以内时，以鲸鸿动能数据为准；如差异超过10%，请于五个工作日内发正式邮件反馈数据差异排查，双方友好协商一致确认最终数据；如未及时反馈，视为确认以鲸鸿动能数据为准。

补充说明：

1. 适用政策期间，推广产品及相关推广投放应保持合法合规运营，不得出现违反法律法规或侵犯第三方合法权益的情形，否则鲸鸿动能有权取消推广产品的政策适用资格并采取相关处罚措施。
2. 服务商、客户享受鲸鸿动能提供的返利金等权益，需以其账户处于有效且可操作状态为前提。因广告主或服务商相关账户注销等账户状态异常情形，致使鲸鸿动能客观上无法向其账户成功充值返利金或发放其他权益的，由此产生的返利金等无法发放的后果，由服务商或客户自行承担，并视为其默认放弃该等权益，鲸鸿动能将不再进行发放操作。
3. 异常作弊、违规操作、恶意修改预算/出价、利用系统漏洞、滥用系统机制、可疑或非法交易等不当行为不可享受激励。经鲸鸿动能合理判定服务商或客户存在前述行为的，鲸鸿动能有权拒绝发放激励并追回已发放的激励，并采取相应处罚措施，由此造成的损失或赔偿责任由服务商或客户承担。
4. 如因产品功能、计算错误、系统错误等任何原因导致激励超额发放、重复发放或错误发放，一经发现，鲸鸿动能有权追回多发部分或按核实后的应发激励调整发放。
5. 对于应追回的激励金额，鲸鸿动能可按以下方式扣除或追缴：（1）从下期激励中扣除；（2）从服务商或客户激励账户中直接扣除；（3）从服务商或客户的充值账户等其他支付、结算账户中扣除；（4）从鲸鸿动能尚未向服务商或客户支付的各种激励、费用、分成、代收款等款项中直接扣除；（5）从服务商或客户在华为平台的其他激励、账户或待结算款项中扣除；（6）采取其他可行的方式要求服务商或客户在30个工作日内退回、支付或赔偿。
6. 如对本政策有任何疑问，请联系鲸鸿动能。
