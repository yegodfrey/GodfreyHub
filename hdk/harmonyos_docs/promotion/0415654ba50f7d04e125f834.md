# 查询推广产品

【简介】通过此接口可以查询推广产品

请求地址

https://ads.cloud.huawei.com/ads/v1/promotion/product/query

请求方法

GET

请求参数  

|-------------|-------|----|------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|filtering|Struct1|是|过滤条件 必传，需要指定product_type|
|page|integer|是|搜索页码 取值范围1\~10000|
|page_size|integer|是|一页展示数量 取值范围 10\~50|

<br />

filtering (Struct1)定义  

|------------|------|----|-------------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|是否必选|描述|
|product_type|string|是|推广产品 枚举限制 详见[【推广产品】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1526319223472)|
|product_id|long|否|推广产品id|

<br />

HTTP/1.1

Accept:application/json

Content-Type:application/json

响应字段  

|-------|-------|------|
|参数名称|类型|描述|
|code|string|返回码|
|message|string|返回描述|
|data|Struct1|推广产品详情|

<br />

data (Struct1)定义  

|------------|-------|--------------------------------------------------------------------------------------------------------------------------|
|参数名称|类型|描述|
|product_id|long|推广产品ID|
|product_type|string|推广产品 详见[【推广产品】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1526319223472)|
|product_info|Struct2|产品信息|

<br />

product_info (Struct2)定义  

|---------|-------|-------|
|参数名称|类型|描述|
|app|Struct3|应用信息|
|quick_app|Struct4|快应用信息|
|web_page|Struct5|网页信息|
|mini_app|Struct6|微信小程序信息|

<br />

app (Struct3)定义  

|------------------------------|----------|------------------|
|参数名称|类型|描述|
|app_id|string|华为应用市场App ID|
|product_name|string|产品名称|
|package_name|string|应用包名|
|icon_url|string|APP图标地址|
|description|string|App描述/介绍|
|app_store_download_url|string|App下载地址|
|app_store_second_ download_url|string|App备用下载地址|
|default_editor_desc|string|App的一句话简介|
|countries|string\[\]|应用上架国家|
|reserveCountries|string\[\]|应用是预上架状态，支持预约下载的国家|

<br />

quick_app (Struct4)定义  

|------------------|------|----------------------------------------------------------------------------|
|参数名称|类型|描述|
|deeplink_url|string|快应用直达地址|
|playable_link|string|游戏试玩\\直玩链接 最长2048|
|playable_link_type|string|快游戏链接类型： PLAYABLE_LINK_TYPE_TRIAL_PLAY-试玩， PLAYABLE_LINK_TYPE_DIRECT_PLAY-直玩|

<br />

web_page (Struct5)定义  

|--------|------|-----|
|参数名称|类型|描述|
|dest_url|string|落地页地址|

mini_app (Struct6)定义  

|-------------|------|--------------|
|参数名称|类型|描述|
|mini_app_id|string|微信小程序ID，最长2048|
|mini_app_link|string|微信小程序链接，最长2048|
|mini_app_name|string|微信小程序名称，最长2048|
