# 编辑推广产品

【简介】通过此接口可以编辑推广产品。仅可以编辑快应用和网页类型的推广产品。

**请求地址**

https://ads.cloud.huawei.com/ads/v1/promotion/product/update

**请求方法**

**POST**

**请求参数**

|-------------|-------|--------|-------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|product_id|long|是|创建的推广产品id|
|product_type|string|是|推广产品 枚举限制 详见[【推广产品】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1526319223472)|
|product_info|Struct1|是|推广产品信息|

product_info (Struct1)定义

|---------|-------|--------|--------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|quick_app|Struct2|否|快应用信息，productType为QUICK_APP时填写|
|web_page|Struct3|否|网页信息，productType为WEB时填写|
|mini_app|Struct5|否|微信小程序信息，product_type为MINI_APP时填写|

quick_app (Struct2)定义

|------------------|------|--------|----------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|deeplink_url|string|是|快应用直达地址 最长2048 格式如下： 以hap://app/包名/ 开头|
|playable_link|string|否|游戏试玩\直玩链接 最长2048|
|playable_link_type|string|否|快游戏链接类型： PLAYABLE_LINK_TYPE_TRIAL_PLAY-试玩， PLAYABLE_LINK_TYPE_DIRECT_PLAY-直玩|

web_page (Struct3)定义

|--------|------|--------|-----------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|dest_url|string|是|落地页地址 (国内) 最长2048 以https://开头|

mini_app (Struct4)定义

|-------------|------|--------|--------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|mini_app_id|string|是|微信小程序ID，最长2048|
|mini_app_link|string|是|微信小程序链接，最长2048|
|mini_app_name|string|是|微信小程序名称，最长2048|
