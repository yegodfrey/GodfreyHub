# 升级直客团队账户

* 如您需要升级直客团队账户，请参考[直客团队账户申请模板](https://developer.huawei.com/consumer/cn/doc/promotion/bp-start-guestteam-admin-0000001526225136)申请。运营开通后，您在直客账户可见"应用推广直客团队账户"入口，点击确认开通即升级为直客管理者账户。
