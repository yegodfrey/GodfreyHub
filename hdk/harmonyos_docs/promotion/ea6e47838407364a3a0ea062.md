# 创建素材

通过此接口可以创建素材

**请求地址**

https://ads.cloud.huawei.com/openapi/v2/tools/creative_asset/create

**请求方法**

**POST**

**请求参数**

|----------|------|--------|-----------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|file_token|string|是|5.4.5获取到的token|
|file|File|是|文件内容 注：文件上限为50M|
|asset_name|string|是|素材名称，不为空且长度不超过128|

|--------|-------|------|
|**参数名称**|**类型**|**描述**|
|code|string|返回码|
|message|string|返回描述|
|data|Struct1|素材信息|

Struct1：

|--------|------|------|
|**参数名称**|**类型**|**描述**|

|asset_id|long|素材ID|
