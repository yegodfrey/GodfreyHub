# 快通知

快通知，提供专属高优先级通道，保障消息快速触达用户，满足较高时效推送需求，保障低时延。

**开通快通知**

1、登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，登录后点击"开发与服务"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/JMl7gVKKQLuUnRaLjpiPTw/zh-cn_image_0000002527001686.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=057DA2B400578D12B95889BA5F8EB21E3A735EEF6F9D251CD8D8C2C333132F41 "点击放大")

2、选择你的项目，点击你的应用所在项目的卡片进入项目设置。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/05/v3/ztng6V29T0qxYjArqttYig/zh-cn_image_0000002526841736.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=09653103ECBDA6640887E64869399E98C424985ED9144370F0A4C4BE9EEFC5F2 "点击放大")

3、点击"项目套餐"页签，升级到付费档。

若之前未签署过开通协议，则弹出《华为AppGallery Connect付费服务协议》的界面，这是一个通用的服务协议，未包含快通知的具体内容。具体协议内容见另一附件"华为AppGallery Connect付费服务协议.pdf"。签署后进入"项目套餐"界面，点击"快通知-免费档"右上方的"升级到付费档" 。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/UqiRBGDIS9in7kn0oapc3g/zh-cn_image_0000002558001549.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=CE902316ABB0E72CAA58F80E2984C06795971742AA9313DA2CCF34BC9ABAF19B "点击放大")

4、确认开通"快通知"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5c/v3/Arrligz3RHmSvDZju-LqTw/zh-cn_image_0000002557881591.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=6510C4A74E18B0A051B889C885D2AEA878244A9027304068F34F27626AFF25EB "点击放大")

5、"快通知"开通成功。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/-lVHQTixSiycqrMRYOHTjg/zh-cn_image_0000002526841738.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=58FD7733591C37EB9994373E78916E047A691079047BDEC193895A86CC9AE437 "点击放大")

6、如需关闭快通知，进入"我的套餐"界面，点击"快通知-按量付费档"右上方的"降级到免费档"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/ysTIck_yQj-aXuTgii0DPA/zh-cn_image_0000002526841740.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=7776793DEC8C60E52905AA8D18BD0688AAB8D207FABE46E7E60D14911119BE61 "点击放大")

**发送快通知消息**

请使用下面的V5接口URL以及消息格式发送消息：

[https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References-V5/https-send-api-0000001050986197-V5](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References-V5/https-send-api-0000001050986197-V5)

快通知消息中需要携带business_type字段，值设置为1，示例如下：

```screen
{ 
    "validate_only": false, 
    "business_type": 1, 
    "message": { 
        "notification": { 
                "title": "11", 
                "body": "11" 
        }, 
        "token": [ 
                "token1" 
        ] 
    } 
}
```

说明：上述示例仅为了说明字段所处位置，非实际消息样例。

**计费与账单**

1、计费标准

Push快通知按调用次数（条数）计费，计费标准可在"项目套餐"-快通知的超额价格列查看：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/CaK-EJsWREecGqDRI50xWw/zh-cn_image_0000002558001547.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=C771B03E0F9E8A52EB2544A483AF415E3A639034F7933E3E1D314B16FFB0F9A9 "点击放大")

2、查看账单

进入项目设置->项目费用界面，商品选择"快通知"，或服务选择"推送服务"，可查看消耗账单，账户存在可用的Push快通知优惠券时，系统将优先使用优惠券来抵扣相应的费用。优惠券不足以覆盖费用时，剩余部分将通过现金支付方式进行结算。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/b71nTvH5Tq6CXSI4758gkA/zh-cn_image_0000002558001551.png?HW-CC-KV=V1&HW-CC-Date=20260909T171908Z&HW-CC-Expire=31536000000&HW-CC-Sign=30FB650BAAC7E58EE476C022451DCA03A52CAB9BA671F3BD7EBA23AC316B7F2F "点击放大")

3、优惠券查询

已领取但未使用的代金券，可以在优惠券页面[查看对应的优惠信息。](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-query-coupon-0000001154273152#section28841110669)
