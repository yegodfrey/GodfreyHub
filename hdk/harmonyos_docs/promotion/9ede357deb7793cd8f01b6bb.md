# 查询账户充值记录

【简介】查询广告主的账户充值记录信息，一级服务商账户和直客广告主可以通过此接口查询充值记录。

请求地址

https://ads.cloud.huawei.com/openapi/v2/finance/recharge/query

**请求方法**

**GET**

**请求参数**

|-----------------|-------|--------|------------------------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|start_date|string|否|付款起始时间 yyyy-MM-dd|
|end_date|string|否|付款结束时间yyyy-MM-dd 时间跨度最大一年|
|page_num|integer|是|搜索页码 取值范围1~200|
|page_size|integer|是|一页展示数据数量 取值范围10~50|
|recharge_type|string|是|充值类型 详见[【充值类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1092441935612)|
|recharge_status|string|是|充值状态 详见[【充值状态】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section2585103825611)|
|receipt_status|string|是|发票状态 详见[【发票状态】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section030985220568)|
|recharge_usage|string|否|充值用途。不填默认查全部充值用途 详见[【充值用途】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section8687552165920)|
|user_service_type|string|否|账户推广业务类型，不填默认查询ADS侧数据，详见[【账户推广业务类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section12306205591715)|

**请求示例**

GET openapi/v2/finance/recharge/query?start_date=2020-03-08&

end_date=2021-03-08&page_num=1&page_size=2

&recharge_type=ALL_RECHARGE&recharge_status=ALL_RECHARGE

&receipt_status=ALL_RECHARGE&recharge_usage=ALL&user_service_type=ADS

**响应字段**

|--------|---------|------|
|**参数名称**|**类型**|**描述**|
|code|string|返回码|
|message|string|返回描述|
|total|integer|信息总数|
|data|Struct1[]|充值信息列表|

Struct1定义

|---------------|----------|-----------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**描述**|
|recharge_id|string|充值订单ID|
|recharge_amount|bigdecimal|充值金额|
|currency|string|币种|
|created_time|string|订单创建时间 yyyy-MM-dd HH:mm:ss|
|pay_time|string|订单支付时间 yyyy-MM-dd HH:mm:ss|
|recharge_status|string|充值类型 详见[【充值类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1092441935612)|
|recharge_type|string|充值状态 详见[【充值状态】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section2585103825611)|
|receipt_status|string|发票状态 详见[【发票状态】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section030985220568)|
|remark|string|描述信息|
|sign_party|string|签约主体 详见[【签约主体】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section769391320017)|
|account_type|string|账户类型标识 详见[【资金账户类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section16745513560)|
|media_type|string|适用媒体范围 详见[【虚拟账户类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section416715287016)|
