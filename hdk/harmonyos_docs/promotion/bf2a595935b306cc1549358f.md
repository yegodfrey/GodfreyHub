# 概述

延迟Deeplink的推广任务投放成功后，您可以通过[客户端(方式一)](https://developer.huawei.com/consumer/cn/doc/promotion/bp-functions-deeplink-inquire-client-0000001348653289)和[API接口(方式二)](https://developer.huawei.com/consumer/cn/doc/promotion/bp-functions-deeplink-inquire-api-0000001296132894)两种方式查询。

两种方式对比如下：  

|查询方式|是否需要发布新版本|开发工作量|
|:-----------------------------------------------------------------------------------------------------------------------|:--------|:----|
|[客户端(方式一)](https://developer.huawei.com/consumer/cn/doc/promotion/bp-functions-deeplink-inquire-client-0000001348653289)|是|稍大|
|[API接口(方式二)](https://developer.huawei.com/consumer/cn/doc/promotion/bp-functions-deeplink-inquire-api-0000001296132894)|否|稍小|

请根据实际需要选择对应的方式查询。
