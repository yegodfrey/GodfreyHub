# 通过RTA实验ID查询

您通过本接口通过RTA实验ID查询报表。

* 请求地址：请根据您的就近区域进行选择 亚非拉：https://ads-dra.cloud.huawei.com/openapi/v2/reports/rta/experiment/query

  俄罗斯：https://ads-drru.cloud.huawei.com/openapi/v2/reports/rta/experiment/query

  欧洲：https://ads-dre.cloud.huawei.com/openapi/v2/reports/rta/experiment/query
* 请求方法：POST
* 请求参数：  

  |参数名称|类型|是否必选|描述|
  |:------------|:------|:---|:-----------------------------------------------------|
  |advertiser_id|long|否|广告主ID，经理账户或者服务商账户登录时，则此字段必填；当前操作的华为账号支持多个广告主账户时，此字段必填。|
  |filtering|Struct1|是|筛选条件|
  |page|integer|否|搜索页码 默认值1|
  |page_size|integer|否|每页展示的数据条数 默认值20 取值范围 1\~10000|
  |start_date|string|是|起始时间|
  |end_date|string|是|结束时间。|
  |is_abroad|boolean|是|是否为非中国大陆账户，取值为： true为海外账户：非中国大陆账户 false：为中国大陆账户。|

<br />

|参数名称|类型|是否必选|描述|
|:-------------|:---------|:---|:------------|
|campaign_ids|string\[\]|否|推广计划ID|
|campaign_name|string|否|计划名称|
|adgroup_ids|string\[\]|否|任务ID|
|adgroup_name|string|否|任务名称|
|creative_ids|string\[\]|否|创意ID|
|placement_name|string|否|版位名称|
|pricings|string\[\]|否|出价方式 详见【付费方式】|
|rta_exp_id|string\[\]|是|RTA实验组ID|
