# 更新商品库

【简介】通过此接口可以更新商品库

**请求地址**

https://ads.cloud.huawei.com/ads/v1/tools/dpa/store/update

**请求方法**

**POST**

**请求参数**

|-------------------|-------|--------|------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|store_id|long|是|商品库id|
|store_name|string|否|商品库名称|
|store_group|string|否|商品库分组 创建DPA任务时，可以通过商品库分组实现用于投放任务的商品库|
|store_data_source|Struct1|否|商品库商品更新数据源配置|
|store_update_policy|Struct2|否|商品库商品更新策略 当upload_method = REGULAR时必填[w(1]|

store_data_source（Struct1）定义

|-------------|------|--------|-----------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|upload_method|string|是|商品库数据上传方式 详见[【商品库数据上传方式】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section715644615399)|
|update_type|string|是|商品库数据更新方式 详见[【商品库数据更新方式】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section4978265409)|

store_update_policy（Struct2）定义

|-------------------|-------|--------|----------------------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|xml_update_url_type|string|是|定时拉取方式获取xml数据的url地址类型，详见[【URL地址类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1643914354402)|
|xml_update_url|string|是|定时拉取方式获取xml数据的url地址|
|auth_name|string|否|用户名|
|auth_password|string|否|密码|
|update_frequency|integer|是|定时拉取更新频次，单位小时|
|update_begin_time|integer|是|定时拉取开始时间，只能是整点，0-23|

**响应字段**

|--------|-------|-------------------|
|**参数名称**|**类型**|**描述**|
|code|string|返回码200：成功，其他错误码标识失败|
|message|string|返回描述|
|data|Struct1|更新商品库响应数据|

data（Struct1）定义

|--------|------|------|
|**参数名称**|**类型**|**描述**|
|store_id|long|商品库Id|
