# 活动数据查询

* **查询奖品流水**

奖品流水数据可以在【AppGallery Connect >我的应用>应用类型>运营>活动管理>奖品流水】中查看

* **查询活动效果**

活动效果可在【AppGallery Connect >常用服务>分发分析】中查看

运营分析支持活动ID或名称搜索查看结果
