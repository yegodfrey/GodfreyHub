# 查询操作日志列表

【简介】通过此接口可以查询操作日志信息。默认查询时间范围为30天，如果超过30天请分段查询。定向部分日志变更需要通过【操作日志中定向包信息转换接口】进行解析。（预计于2023年6月下架，请尽快切换至新接口【[查询操作日志列表](https://developer.huawei.com/consumer/cn/doc/promotion/ads_new_api61-0000001456986373)】）

**请求地址**

https://ads.cloud.huawei.com/openapi/v2/tools/operation_log/query

**请求方法**

**GET**

**请求参数**

|---------------------|--------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**是否必选**|**描述**|
|advertiser_id|long|否|广告主ID，当登录授权的华为账号为如下场景时此字段必填： 1）授权账号关联的是经理账户； 2）授权账号关联的是服务商账户； 3）授权账号关联了多个子客账户。|
|page_num|int|是|页数 取值范围1-10000|
|page_size|int|是|每页数量 取值范围1-50|
|start_date|string|是|开始时间(yyyy-MM-dd)|
|end_date|string|是|结束时间(yyyy-MM-dd) 时间范围最大30天|
|operation_type|string|否|[【操作类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section478931125811)|
|operator_type|string|否|[【操作者类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section1692524785813)|
|operation_target_type|string|否|[【操作对象类型】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_meijuzhi-0000001510863205#section62876581580) 用于选择类型，根据此字段可以选填下方参数，campaign_ids、adgroup_ids、creative_ids、targeting_ids仅可传入一个。|
|campaign_ids|string[]|否|计划ID列表【operation_target_type为CAMPAIGN时，可使用该字段进行筛选】|
|adgroup_ids|string[]|否|任务ID列表【operation_target_type 为ADGROUP时，可使用该字段进行筛选】|
|creative_ids|string[]|否|创意ID列表【operation_target_type 为CREATIVE时，可使用该字段进行筛选】|
|targeting_ids|string[]|否|定向包ID列表【operation_target_type 为TARGETING_TEMPLATE时，可使用该字段进行筛选】|

**请求示例**

GET openapi/v2/tools/operation_log/query?page_size=100&page_num=1&start_date=2021-03-04&end_date=2021-04-02&adgroup_ids=["45084699","45084700"]

**响应字段**

|--------|-------|--------|
|**参数名称**|**类型**|**描述**|
|code|string|返回码|
|message|string|返回描述|
|data|Struct1|操作日志响应结果|

Struct1定义

|--------|---------|------|
|**参数名称**|**类型**|**描述**|
|total|int|总数|
|data|Struct2[]|操作日志列表|

Struct2定义

|---------------------|---------|-------------------------|
|**参数名称**|**类型**|**描述**|
|operation_id|string|操作Id|
|operation_time|string|操作时间(yyyy-MM-dd HH:mm:ss)|
|operation_type|string|操作类型|
|operator_type|string|操作人员的类型|
|campaign_id|string|计划id|
|adgroup_id|string|任务id|
|creative_id|string|创意id|
|targeting_id|string|定向包id|
|operation_target|string|操作对象|
|operation_target_type|string|操作对象类型|
|details|Struct3[]|变更详细信息列表，包含定向包的变更详情|

Struct3定义

|-----------|------|-------------------------------------------------------------------------------------------------------------------------------|
|**参数名称**|**类型**|**描述**|
|change_item|string|日志记录修改 类型详见[【操作日志修改项说明】](https://developer.huawei.com/consumer/cn/doc/promotion/ads_api72-0000001058086561#section101874509542)|
|before|string|修改之前|
|after|string|修改之后|
