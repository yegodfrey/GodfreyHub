# 新功能速递

## 8月新功能速递

**一、【投放平台新功能】**

* 经理账户平台支持批量关联子账户

二、**【投放工具新功能】**

* 维纳斯落地页支持按钮复制口令并跳转
* 维纳斯落地页新增表单提交后跳转应用下载能力

**三、【服务商管理平台新功能】**

* 鲸鸿动能平台协议变更生效机制升级
* 服务商管理平台支持按角色维度盘点虚拟金订单
* 子客清单页面新增自定义列入口

## 一、投放平台新功能

**经理账户平台支持批量关联子账户**

**【功能说明】**

为提升账户管理效率，鲸鸿动能经理账户平台新增批量关联子账户功能，单次最多支持关联50个子账户。

* 输入升级：登录经理账户平台后，在首页点击"关联账户"后弹出账户ID输入框；输入框升级为多行模式，不同账户ID 以换行分隔，支持拖拽上下拉动调整文本框高度。
* 校验逻辑：输入校验规则与原有保持一致，仅允许输入数字与换行符。


* 批量校验与结果展示：用户输入账户ID并点击添加后，对输入的多个子账户ID做校验，并显示校验结果提示语以及校验成功和失败的表格：

1)无校验失败场景提示语："已匹配XX个，未匹配0个"，仅展示校验成功的表格，不展示校验失败表格

2)有校验失败场景提示语："已匹配XX个，未匹配YY个，以下为未匹配项"

3) 校验成功表格：与原有特性保持一致，展示【序号、账户ID、企业名称、昵称、操作】列

4)校验失败表格：展示【序号、账户ID、未匹配原因】列，行数过多时支持滚动

5)未匹配原因：依据系统原有提示逻辑展示每个未匹配账户的未匹配原因，包括但不限于"该账户不存在"、"该账户已关联经理账户"

**【功能入口】**

"首页"->"关联账户"

**【适用范围】**

经理账户

## 二、投放工具新功能

**维纳斯落地页支持按钮复制口令并跳转**

**【功能说明】**

本次上线口令营销能力，网页落地页按钮组件新增"复制并跳转"功能选项。用户点击按钮后，可自动复制预设口令码、弹出复制成功提示，并跳转至指定第三方平台，满足口令引流的转化需求。

* 配置路径：

1) 登录鲸鸿动能平台，依次进入"工具">"落地页工具">"新建落地页">"网页落地页"

2) 在按钮模块中，选择"复制并跳转"选项

3) 依次填写：复制内容、复制成功提示、Android应用 ID/包名、Android应用链接

4) 开启"复制后跳转"开关，保存配置后即可生成对应落地页

**【功能入口】**

"工具"-> "落地页工具"->"新建落地页"->"网页落地页"->"按钮：复制并跳转"

**【适用范围】**

广告账户

**维纳斯落地页新增表单提交后跳转应用下载能力**

**【功能说明】**

为解决表单提交与应用下载割裂问题，现支持落地页"先验证后下载"链路，助力金融等行业客户提升线索质量并完善归因：

* 表单优化：新建或编辑网页落地页、添加表单类型时，"提交提醒"模块新增"注册后下载样板"选项；选择该选项后，"表单提交后"字段将固定为"下载应用"。
* 注册归因对接要求：有注册后下载应用需求的广告主，需在表单编辑界面的线索设置中，提供注册事件接口，用于平台完成注册事件的归因统计。
* 广告投放适用范围：仅Android 应用下载广告任务，支持选用配置了"注册后下载样板"表单的网页落地页；其他类型广告任务不可选用该类落地页。

**【功能入口】**

"工具"-> "落地页工具"->"新建落地页"->"网页落地页"->"表单"->"选表单类型"->"注册后下载样板"

**【适用范围】**

广告账户

## 三、服务商管理平台新功能

**鲸鸿动能平台协议变更生效机制升级**

**【功能说明】**

为保障广告投放与Marketing API调用连续性，鲸鸿动能广告平台正式上线协议变更默认同意规则：在平台相关协议变更通知发布后，若继续使用服务即视为同意修订条款，协议即时生效，无需手动签署即可正常开展投放操作与接口调用。

* 子客/子客服务商账户协议《鲸鸿动能服务商声明》增加默认签署条款说明："华为有权根据适用的法律法规或基于自身经营考虑更新本声明内容，并将在变更时提前30天通过邮件、站内通知、短信或公告等方式中的一种或多种方式通知您。如您继续使用鲸鸿动能服务（例如继续使用平台 API服务、继续调用接口）即视为您已阅读、理解并同意更新后的声明内容，如您不同意变更后的声明内容您可停止使用鲸鸿动能服务。"（新版协议及历史变更记录，请查阅：[鲸鸿动能平台协议](https://developer.huawei.com/consumer/cn/doc/promotion/ad-agreements-0000001169499170)）。
* 生效逻辑：协议变更生效后，通过Marketing API调用、跳转登录等方式使用平台服务时，系统将自动确认协议同意状态，开放全部业务调用与使用权限。


* 协议变更通知机制：协议生效后，系统将通过短信及邮件自动向所有有效账户发送变更通知。

1)覆盖范围：所有生效状态（在用、静默）的非注销、非未注册账户，按账户状态分批次推送；

2)默认配置：自定义消息通知设置中，短信、邮件通知开关默认开启。

3)通知频次：单轮协议更新仅向账户发送 1 次通知。

**【适用范围】**

子客服务商、子客

**服务商管理平台支持按角色维度盘点虚拟金订单**

**【功能说明】**

本次升级服务商管理平台对"订单盘点（按账户）"导出页面进行重构升级，新增角色维度的订单分布数据导出能力，帮助服务商提升虚拟金运营效率。

* 新增角色维度：登录服务商管理平台后，依次进入财务管理 > 虚拟金盘点 > 订单盘点（按账户）> 导出；导出页面现支持导出"订单及角色分布数据"，可一键查看各角色虚拟金余额及有效期分布，无需逐一点击。

1)导出内容-单选：可选"订单数据"或"订单及角色分布数据"，默认选中"订单数据"；

2)导出筛选-单选：可选"包含0金额数据"或"不包含0金额数据"，默认选中"包含0金额数据"；

3)导出方式-单选：可选"直接导出"或"异步导出"，默认选中"直接导出"。

* 当导出内容选择"订单数据"时："导出筛选"自动选中"包含0金额数据"，不可选择"不包含0金额数据"（置灰不可选中）；导出方式支持直接导出、异步导出两种模式。
* 当导出内容选择"订单及角色分布数据"时： 1)导出方式固定为"异步导出"，"直接导出"选项置灰不可选择，导出文件可在下载中心查看；

  2)导出筛选支持自由切换；选择"不包含 0 金额数据"时，系统将剔除余额为 0 的数据，结果按充值订单ID升序排列。

**【功能入口】**

"财务管理"->"虚拟金盘点"->"按账户"->"订单数据"/"订单及角色分布数据"

**【适用范围】**

仅适用于一级服务商

**子客清单页面新增自定义列入口**

**【功能说明】**

服务商管理平台子客清单页新增自定义列功能，支持服务商按需勾选展示字段（默认全选），操作列固定靠右展示。

**【功能入口】**

"首页"->"子客清单"->"自定义列"

**【适用范围】**

服务商（包含一级服务商和子客服务商）
