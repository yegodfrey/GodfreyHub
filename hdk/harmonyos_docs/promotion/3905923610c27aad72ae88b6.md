# Push用户增长

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"开发与服务"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/wki0NPXCRfa4VwNyjtUsWw/zh-cn_image_0000002526933474.png?HW-CC-KV=V1&HW-CC-Date=20260909T141447Z&HW-CC-Expire=31536000000&HW-CC-Sign=1C04D1022D3E6BD2ADFBF431CAD427F137B131504DA90C3BC59D6E9D713EB9A6 "点击放大")

在项目列表中找到您的项目，通过"增长 > Push用户增长" 导航到"任务管理"页签。

若您无法在上述路径中找到"Push用户增长服务"，请您联系华为方销售/运营并且提供您的"Developer ID"信息。

了解更多投放指导，可点击页面右侧的文档图标，查看《Push用户增长投放指南》。
