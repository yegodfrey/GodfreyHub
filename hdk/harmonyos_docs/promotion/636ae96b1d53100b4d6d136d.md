# 管理素材库

素材库内素材支持删除、修改名称、预览等操作，请参考如下操作进行管理。

* 点击"缩略图"中的图片，可进行素材预览，查看已创建素材库中的图片。
* 点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/dFh7FxFJSg2V0oR7mxsnZA/zh-cn_image_0000001399646153.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=1B1CF3B815B4BFC30914A0AE9C184275206BC7711CCD7B5859721BEB048AEF96)可重新编辑素材名称。
* 点击"操作"列的"删除"，删除您已创建的素材。
* 在"批量操作"下拉框中，点击"批量删除"，可批量删除已创建的素材。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/KJg_xhDHSRK9-ws6z2q7Jg/zh-cn_image_0000002552896684.png?HW-CC-KV=V1&HW-CC-Date=20260918T084031Z&HW-CC-Expire=31536000000&HW-CC-Sign=FE545BACB10C9924FAA7150CA2748D6C93E378CC21C08C46EABC8057CBAF1FF5)
