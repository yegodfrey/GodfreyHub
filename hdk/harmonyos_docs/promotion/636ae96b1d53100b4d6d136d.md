# 管理素材库

素材库内素材支持删除、修改名称、预览等操作，请参考如下操作进行管理。

* 点击"缩略图"中的图片，可进行素材预览，查看已创建素材库中的图片。
* 点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/dFh7FxFJSg2V0oR7mxsnZA/zh-cn_image_0000001399646153.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=AF247D03041BA0429FF02BC45A8DF292E092DB73A1011EDD4C159ED8FEFBA0D8)可重新编辑素材名称。
* 点击"操作"列的"删除"，删除您已创建的素材。
* 在"批量操作"下拉框中，点击"批量删除"，可批量删除已创建的素材。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/KJg_xhDHSRK9-ws6z2q7Jg/zh-cn_image_0000002552896684.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=EED70C003A878C6545861B5A6B978D74D049602CB18631BEE0CEEC55FF43F8F8)
