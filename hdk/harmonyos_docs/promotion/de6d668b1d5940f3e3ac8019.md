# 新建素材库内容

1. 登录[华为应用市场应用推广平台](https://ads.huawei.com/cn/)， 在顶部菜单栏点击【工具】页签，确认推广范围为"应用市场应用推广"。选择"资产管理"------"素材库"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/TZ4vEnprSMyWtIXPrwzBgQ/zh-cn_image_0000002583371071.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C3F45758930B36911288FA12AC96B0ADC5AF72B07FA4DD3F4995F35AE9118A3 "点击放大")

2. 在当前页面点击"上传素材"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/mM4QfVnWSoqOtg4_B4aOFA/zh-cn_image_0000002583291079.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3EDECFE64724030FADC999D3222CADEAF6E32BB7F26AF0C8514D36A912A3BD1D "点击放大")

   >
   > 一次最多可上传20张图片。
