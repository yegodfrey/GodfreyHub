# 排除IP管理

对投放到搜索广告网络的任务，如果您希望不向特定的IP地址投放，可以添加"排除IP"。

单击"工具"-\>"排除IP管理"-\>"添加IP"，支持批量添加/删除，每行一条，最多300行。
