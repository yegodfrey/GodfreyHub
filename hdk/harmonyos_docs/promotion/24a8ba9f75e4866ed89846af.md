# 创建oCPC任务

## 前提条件

连续[回传转化数据](https://developer.huawei.com/consumer/cn/doc/promotion/bp-hm-callback-0000002513681587)等于或大于4天，且每天回传量超过5个。
> 说明
>
> 下载、平台激活目标不涉及回传。

## 操作步骤

1. 登录[华为应用市场应用推广平台](https://ads.huawei.com/cn/)，进入"概览"主页面，点击左上角"创建"按钮，下拉框中选择"创建任务"。
2. 在"计划设置"模块，为新建任务设置日预算。填写计划名称，点击"继续，创建任务"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/oA7XSCBoSKiAvWKge0-xyQ/zh-cn_image_0000002563510415.png?HW-CC-KV=V1&HW-CC-Date=20261008T165341Z&HW-CC-Expire=31536000000&HW-CC-Sign=2A8BA273DE7CB0AFD86C7E47F7C83E9134081B333643C8F3AF11D40584FBBF09 "点击放大")

3. 在"计划设置"模块，选择"计费类型"为"oCPC"。填写新任务名称，点击"继续，进行任务详细设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/lZSH3c1gSqi4DoGFPe-pvg/zh-cn_image_0000002532590538.png?HW-CC-KV=V1&HW-CC-Date=20261008T165341Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C225224C96E69BF85E39DC1A4829CCFDA239289F00F85B1797F3FCAF88A89A7 "点击放大")

4. 在"场景投放"栏目新建oCPC任务，设置任务名称、选择转化目标并出价。 注意
   >
   > 以投放"激活"为例，出价按照应用考核的激活成本填写，出价过低会导致oCPC量级较少。前期为更好起量，建议激活出价≥当前CPC任务的激活成本*120%，每日预算建议设置为5000以上。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/ktnx1dP8SJ2VhDYy1s_MKw/zh-cn_image_0000002532590592.png?HW-CC-KV=V1&HW-CC-Date=20261008T165341Z&HW-CC-Expire=31536000000&HW-CC-Sign=627CBCD577F87C7B396259D4AFF3B9A979383D97D999FFEB02FE882FBB32C3DD "点击放大")
5. 在"归因监测"栏目选择"自定义监测"，并按监测链接要求填写，请至少填写一个链接。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c/v3/fPzFNNyVRdma-gM7EIloIQ/zh-cn_image_0000002532750544.png?HW-CC-KV=V1&HW-CC-Date=20261008T165341Z&HW-CC-Expire=31536000000&HW-CC-Sign=35611B1D2456A68E2FB7AD284ECF17FD2221A9A295DD529D00861D4E1ACDA8BE "点击放大")
