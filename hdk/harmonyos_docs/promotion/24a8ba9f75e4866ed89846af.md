# 创建oCPC任务

## 前提条件

连续[回传转化数据](https://developer.huawei.com/consumer/cn/doc/promotion/bp-hm-callback-0000002513681587)等于或大于4天，且每天回传量超过5个。
> 说明
>
> 下载、平台激活目标不涉及回传。

## 操作步骤

1. 登录[华为应用市场应用推广平台](https://ads.huawei.com/cn/)，进入"概览"主页面，点击左上角"创建"按钮，下拉框中选择"创建任务"。
2. 在"计划设置"模块，为新建任务设置日预算。填写计划名称，点击"继续，创建任务"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/oA7XSCBoSKiAvWKge0-xyQ/zh-cn_image_0000002563510415.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=C4CAFCED9F022B7BA551CF6E5F8B11DD4FBD09E79E9E974F94B54EF9F3E61842 "点击放大")

3. 在"计划设置"模块，选择"计费类型"为"oCPC"。填写新任务名称，点击"继续，进行任务详细设置"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/lZSH3c1gSqi4DoGFPe-pvg/zh-cn_image_0000002532590538.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=4A11EFEE164D912C90DB22561833E8AC16A2A7DCEA1EA533B3A2FDCE835B898D "点击放大")

4. 在"场景投放"栏目新建oCPC任务，设置任务名称、选择转化目标并出价。 注意
   >
   > 以投放"激活"为例，出价按照应用考核的激活成本填写，出价过低会导致oCPC量级较少。前期为更好起量，建议激活出价≥当前CPC任务的激活成本*120%，每日预算建议设置为5000以上。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/01/v3/ktnx1dP8SJ2VhDYy1s_MKw/zh-cn_image_0000002532590592.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=F55798D0DEFBEB3B767155287E149A0E87767B3F674C35581C962F69B9505BA5 "点击放大")
5. 在"归因监测"栏目选择"自定义监测"，并按监测链接要求填写，请至少填写一个链接。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c/v3/fPzFNNyVRdma-gM7EIloIQ/zh-cn_image_0000002532750544.png?HW-CC-KV=V1&HW-CC-Date=20260929T074631Z&HW-CC-Expire=31536000000&HW-CC-Sign=C30C85298C9C6460C263A055FBCA46D303438B0EAFBF02F0F00483AE4D0CBF02 "点击放大")
