# 2026年8月

**【规则新增】-开户"企业全称"填写规范**

自2026年8月10日起，注册广告账户填写企业信息时，"企业全称"字段须严格与《营业执照》法定全称完全一致，不可填写任何备注。如有推广内容、激励金等备注需求，请使用"账户名称"字段。如填写不规范，审核将驳回并引导修改。

**背景：**为提升开户体验及账户通过率，区分"企业名称"和"账户名称"：

1.企业名称：指营业执照上的法定全称，由行政区划、字号、行业和组织形式四部分组成，具有法律效力，开户后通常不可修改。

2.账户名称：指广告主在平台内部自定义的展示名称，仅用于团队识别和管理，不影响资质审核，可随时修改。

**【规则** **更新** **】** **0元活动**

广告支持推广0元先用后付活动，推广需注意以下要求：

（1）对于实际需要收费的产品或服务，不得使用"不要钱"、"下单不付款"、"不用花钱"、"货到不用给钱"的描述。

（2）单独使用"0 元购"、"免费试用"、"免费拿"、"免费试吃"、"免费吃喝"等描述的，需真实准确并显著注明提示语，避免对用户造成误导，如："前往APP查看详细规则"、"具体规则可前往APP查看"、"产品退回不得影响二次销售"等。（大图字体≥16px，小图≥12px）

**【规则** **更新** **】规范使用地图**

广告中不得使用不符合国家有关标准和规定的地图，例如未完整表示中华人民共和国疆域（如遗漏台湾、南海诸岛等）的地图，允许按标准地图说明使用自然资源主管部门发布的标准地图，或使用经自然资源主管部门审核的地图。

（1）官方免费下载网站：（http://bzdt.ch.mnr.gov.cn/）。

（2）标准地图需显著标注原图自带的审图号，例如：审图号：GS (202X) XXXX 号。

（3）如地图经过修改、定制的，发布前需经过自然资源主管部门审核。
