# 创建动态商品落地页（可选）

## 概述

动态商品广告落地页通过使用图片、轮播图、视频组件的动态商品功能，和使用动态商品、动态视频、动态图文组件实现。一个落地页仅支持关联一个商品库，支持同时使用多个动态组件。

落地页第一个动态商品与创意商品保持一致，剩余动态替换商品由RTA接口返回的其他商品按productList补充，或由华为商品推荐推荐的商品补充，展示的商品取决于最终的商品推荐模式。

## 操作步骤

1. 使用已开通动态商品广告权限的账户登录鲸鸿动能投放端，选择"工具"->"创意中心"->**"** 落地页工具**"。**

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/pVQhOI1_STy7CJTtuO9MtA/zh-cn_image_0000002591546852.png?HW-CC-KV=V1&HW-CC-Date=20260928T100505Z&HW-CC-Expire=31536000000&HW-CC-Sign=5074750E620E049291C9D830EDEB34C5FB41467271196E523160D1F3E6B1A1BF "点击放大")

2. 在"模板选择"页面，选择创建**"应用下载落地页"**。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/I_EMMBzyRLiBjwXmswCXYA/zh-cn_image_0000001887970830.png?HW-CC-KV=V1&HW-CC-Date=20260928T100505Z&HW-CC-Expire=31536000000&HW-CC-Sign=ED654CA1BB2B1C3A786FBF0929481978B81DF212B7412FD841BCC2FFB3DB6AD2 "点击放大")

3. 在落地页基础设置中开启**"动态落地页"** ，并选择关联的"**商品库**"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/hGum_1LhSBGa1kfhcOR79w/zh-cn_image_0000001888130778.png?HW-CC-KV=V1&HW-CC-Date=20260928T100505Z&HW-CC-Expire=31536000000&HW-CC-Sign=5D4DBD7AB35A5A525FE224349DECDE1EFF441C6F6B61733E7007800EF839B969 "点击放大")

4. 选用图片、视频、商品等基础组件，设置素材展示形式。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/b3gD2RkcTPa7ddgiH31WgQ/zh-cn_image_0000001932970681.png?HW-CC-KV=V1&HW-CC-Date=20260928T100505Z&HW-CC-Expire=31536000000&HW-CC-Sign=B377A8FA54CACCFFCB89F47B1480D5A7ED68D3751EDA2A97980E82268E7C2323 "点击放大")
   * 选择**"图片"**，上传图片后打开"动态商品"开关，实际投放时将动态展示商品主图，若在异常场景下获取不到商品库的商品主图，则展示编辑落地页时上传的图片。

   * 选择**"视频"**，打开"动态商品" 开关实现动态视频展示，如未上传视频封面，落地页将展示视频首帧画面。
   * 选择**"轮播图"** ，上传图片后打开"动态商品"开关，实际投放时将动态展示商品主图，展示图片数量与上传图片数量一致；如需使用动态商品功能，建议上传的轮播图与商品库中的图片尺寸保持一致。轮播图支持单商品展示和多商品展示两种动态模式：

     单商品展示：从商品库获取同一个商品的图片进行轮播。

     多商品展示：从商品库获取不同商品的主图进行轮播，该模式下轮播图首个商品图与创意商品保持一致，其他商品图基于RTA反馈结果获取。
   * 选择**"动态商品"**，可设置动态商品样式（单列、双列、三列）和展示商品数量（4-20），实际投放时将动态展示商品信息；商品模板直接拉取商品库中的商品主图、描述、现价、原价、应用直达链接等商品信息；您还可以修改标签、按钮下载提示语。
   * 选择**"动态视频"**，默认为商品视频，关联调用Video字段，实际投放时将动态展示商品视频；可设置商品布局（单列、双列）和展示商品数量（4-20），可开启商品描述功能；商品描述可选商品名称、品牌名称和广告文案，您可自定义设置描述位置。
   * 选择**"动态图文"**，默认为商品主图，实际投放时将动态展示商品信息；可设置商品布局（单列、双列）和展示商品数量（4-20），可开启商品描述功能；商品描述可选商品名称、品牌名称和广告文案，您可自定义设置描述位置。
