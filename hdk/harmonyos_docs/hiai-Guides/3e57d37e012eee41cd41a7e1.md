# 合作案例：苏宁易购

**改善图片阅览体验，HUAWEI HiAI携手苏宁易购让手机购物更得心**

## 苏宁易购简介

苏宁易购作为B2C综合网上购物平台，为用户提供涵盖家电、数码、母婴、服装、百货等在内的各大品类商品，旨在为用户带来便捷丰富的网上购物服务。

## 核心痛点

**商品图片浏览存在不清晰、耗费流量、加载缓慢等问题：**越来越多用户习惯在移动端进行网络购物，然而由于需浏览大量商品图片，图片过小会造成画质模糊，影响用户阅览体验，而图片过大会消耗大量数据流量，同时引起图片加载时长过长的问题。提升图片清晰度，同时规避耗费流量、加载缓慢的问题，成为用户一大需求。

## 解决方案

**智能放大，提升图片清晰度：** 通过接入HUAWEI HiAI Engine图像超分辨率能力，将商品图片分辨率智能放大9倍（高宽各放大3倍），得到更加清晰优质的画面，显著改善用户图片阅览体验。

**压缩传送，有效节省流量、规避卡慢问题** **：** HUAWEI HiAI Engine图像超分辨率能力，还可运用于节省存储和流量；通过在图片存储、传输时加大图片压缩率，缩小分辨率，用户浏览时再用3x超分智能放大，实现同等清晰度下，大幅节省存储空间和数据流量，解决加载缓慢问题。

HUAWEI HiAI处理后，100*100分辨率的图像呈现效果，与常态下300*300分辨率图像呈现效果相同。

## 合作受益

**苏宁易购：**

显著提升商品图片画质；为用户节省70%流量成本，有效改善图片加载卡顿问题。

**用户：**

同等清晰度，数据流量消耗大大降低，图片加载速度更快。
