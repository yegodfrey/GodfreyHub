# IR在线模型构建

> 说明
>
> * IR在线模型构建仅支持Kirin 810及以后平台的华为手机，具体参见[DDK与CANN Version匹配关系](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/supported-platforms-0000001052830507#section94427279718)。

1. 下载[图像分类-Android Studio示例代码](https://developer.huawei.com/consumer/cn/doc/hiai-Examples/sample-code-0000001052989807#section1597885319308)。
2. 使用Android Studio打开源码工程：Demo_Source_Code。
3. 根据原生模型，修改样例文件"Demo_Source_Code\hiaiv1_irmodelbuild\src\main\jni\CreateModel.cpp"的参数和配置，如下操作。

   1. 从原生模型中找到所有的单算子模型。
   2. 构建网络单算子：调用[Graph类](https://developer.huawei.com/consumer/cn/doc/hiai-References/getimpl-0000001052808173)接口，构建单算子，并根据原生模型中算子之间的关系，进行算子级联。
   3. 构建graph，设置[SetInputs](https://developer.huawei.com/consumer/cn/doc/hiai-References/setinputs-0000001092030030)、[SetOutputs](https://developer.huawei.com/consumer/cn/doc/hiai-References/setoutputs-0000001052688183)。

4. 根据graph构建模型，样例文件："Demo_Source_Code\hiaiv1_irmodelbuild\src\main\jni\ClassifyJni.cpp"。

   1. 构建model，将graph对象添加到模型中。

   2. （可选）生成构建好的model，调用[SaveToFile](https://developer.huawei.com/consumer/cn/doc/hiai-References/savetofile-0000001180047737)接口。

   3. 构建网络，调用[模型构建类](https://developer.huawei.com/consumer/cn/doc/hiai-References/createmodelbuff1-0000001051489426)接口，构建模型生成文件。如果用户需要使用和原始模型输入输出一致的format，可以使用带有useOriginFormat能力的[BuildIRModel](https://developer.huawei.com/consumer/cn/doc/hiai-References/buildirmodel-options-0000001091362164)接口。

5. 使用Android Studio工具编译生成APK。
6. 将APK安装到手机上，运行App。

## 使用约束

* 在IR模型构建过程中，不支持"Node_Output"作为算子的名称。例如以下代码中"Test"不能自定义为"Node_Output"。

  ```screen
  auto activation = hiai::op::Activation("Test")         
       .set_input_x(data)         
       .set_attr_mode(13);
  ```

* 当前IR在线模型构建只支持运行在Kirin芯片平台的手机。

## 原生模型

以squeezenet网络为例，具体代码详见jni目录下的C++样例文件"Demo_Source_Code\hiaiv1_irmodelbuild\src\main\jni\CreateModel.cpp"。

此模型中包含以下几种算子：

* Data
* Const
* Convolution
* Activation
* PoolingD
* ConcatD
* Softmax

## 单算子构建

调用[Graph类接口](https://developer.huawei.com/consumer/cn/doc/hiai-References/getimpl-0000001052808173)（DDK包路径："ddk\ai_ddk_lib\include\graph\"），构建网络单算子，并根据原生模型中算子之间的关系，进行算子级联。
> 说明
>
> * 自DDK 100.320.030.010版本起，算子定义更改为hiai::op::命名空间，原有的ge::op命名空间下的算子定义，移到"./graph/compatible/"。推荐用户使用新的hiai::op::命名空间下的IR API。
> * 如果用户继续使用老的ge::op命名空间下的算子，需要将"#include <op/all_ops.h>"修改为："#include <compatible/all_ops.h>"。
> * 由于ge::op命名空间下的算子不再支持更多的扩展，如果用户使用两种命名空间下的算子，则需要同时包含"op/all_ops.h"、"compatible/all_ops.h"。

### Data&Const

用户可以自行构造Data算子作为整个网络的输入，如下示例：

```screen
TensorDesc desc(Shape({in_channels, out_channels, h, w}), format,  datatype);
string data_name = op_name;
data = hiai::op::Data(data_name);
data.update_input_desc_x(desc);
```

> 说明
>
> TensorDesc第二个参数format为预留参数，设置不生效，使用默认值即可。

权值等信息可以用Const算子作为算子的输入，如下示例：

```screen
hiai::op::Const conv10_const_1= hiai::op::Const("conv10_filter").set_attr_value(weightList0[0]);
```

### AIPP

> 说明
>
> CANN DDK V320增加功能。

AIPP算子包含AIPP输入算子和AIPP功能算子。

AIPP输入算子：ImageData、DynamicImageData。

AIPP功能算子：ImageCrop、ImageChannelSwap、ImageColorSpaceConversion、ImageResize、ImageDataTypeConversion、ImageRotation、ImagePadding。

* **静态/动态AIPP** **输入算子使用注意**

  |算子名称|使用场景|是否能级联AIPP功能算子|
  |:---------------|:-------------------------------------------------------------------|:------------|
  |ImageData|用于静态AIPP，输入图片类型、长宽由input_format，src_image_size_w和src_image_size_h定义。|能。|
  |DynamicImageData|用于动态AIPP，输入图片类型、长宽不确定。|不能。|

  AIPP的IR模型支持多输入场景，支持网络中定义多个ImageData算子，也支持一个ImageData算子之后，连接多组不同的AIPP功能算子。


* **静态AIPP算子级联顺序**

  对于所有的AIPP功能，硬件仅支持固定的处理顺序，IR构建时必须按AIPP算子级联顺序图进行级联。
  > 说明
  >
  > 一组AIPP功能算子之间，可以省略不必要的算子，但是不能插入其他类型的算子，也不能重复添加相同的AIPP功能算子。

* **使用范例**

  假定需要对模型输入进行Crop处理，其IR代码实现如下。

1. 构建ImageData节点。

   ```screen
   TensorDesc desc(Shape({n, channels, h, w}), format,  datatype);
   ge::op::ImageData data = op::ImageData(data_name).set_attr_input_format("XRGB8888_U8")
     .set_attr_src_image_size_w(32)
     .set_attr_src_image_size_h(32);
   data.update_input_desc_x(desc);
   ```

2. 构建AIPP功能算子cropOp和resizeOp。

   ```screen
   auto cropOp = op::ImageCrop("crop").set_input_x(data)
        .set_attr_load_start_pos_w(0)
        .set_attr_load_start_pos_h(0)
        .set_attr_crop_size_w(16)
        .set_attr_crop_size_h(16);
   auto resizeOp = op::ImageResize("resize").set_input_x(cropOp)
        .set_attr_resize_output_h(32)
        .set_attr_resize_output_w(32);
   ```

3. 衔接其他功能算子，如PoolingD。

   ```screen
   auto poolOp = op::PoolingD("pool").set_input_x(resizeOp)
        .set_attr_data_mode(0)
        .set_attr_pad_mode(4)
        .set_attr_ceil_mode(1)
        .set_attr_mode(0)
        .set_attr_pad(AttrValue::LIST_INT({0, 0, 0, 0}))
        .set_attr_window(AttrValue::LIST_INT({3, 3}))
        .set_attr_stride(AttrValue::LIST_INT({2, 2}))
        .set_attr_global_pooling(0);
   ```

>
> AIPP的完整示例代码请参见[使用示例](https://developer.huawei.com/consumer/cn/doc/hiai-References/usage-example-0000001052249426)。

### Convolution

根据算子定义，Convolution算子有以下输入和属性。

```screen
REG_OP(Convolution) 
.INPUT(x, TensorType({ DT_FLOAT })) 
.INPUT(filter, TensorType({ DT_FLOAT })) 
.OPTIONAL_INPUT(bias, TensorType({ DT_FLOAT })) 
.OPTIONAL_INPUT(offset_w, TensorType({ DT_INT8})) 
.OUTPUT(y, TensorType({ DT_FLOAT })) 
.REQUIRED_ATTR(strides, AttrValue::LIST_INT) 
.ATTR(dilations, AttrValue::LIST_INT ({ 1, 1 })) 
.ATTR(pads, AttrValue::LIST_INT ({ 0, 0, 0, 0 })) 
.ATTR(pad_mode, AttrValue::STR { "SPECIFIC" }) 
.ATTR(groups, AttrValue::INT { 1 }) 
.ATTR(data_format, AttrValue::STR { "NCHW" }) 
.ATTR(offset_x, AttrValue::INT { 0 }) 
.OP_END()
```

对于每个节点，根据网络模型中该节点的详细信息，调用单算子模型[Graph类接口](https://developer.huawei.com/consumer/cn/doc/hiai-References/getimpl-0000001052808173)设置其输入和属性值。

网络中的第一个Convolution节点，输入包括一个tensor输入和两个const输入，分别通过*set_input_x* 、*set_input_filter* 、*set_input_bias*接口配置，同时输入bias为可选输入，用户可根据需要选择是否设置。

模型中指定了属性"strides"、"dilations"等的取值，其他未指定属性值的属性则给予默认值，通过*set_attr_属性名*接口设置。

```screen
auto conv1 = hiai::op::Convolution("conv1")
     .set_input_x(data)
     .set_input_filter(conv1_const_0)
     .set_input_bias(conv1_const_1)
     .set_attr_strides(AttrValue::LIST_INT({ 2, 2 }))
     .set_attr_dilations(AttrValue::LIST_INT({ 1, 1 }))
     .set_attr_groups(1)
     .set_attr_pads(AttrValue::LIST_INT({ 0, 0, 0, 0 }))
     .set_attr_pad_mode("SPECIFIC");
```

### Activation

根据算子定义，Activation算子有以下输入和属性。

```screen
REG_OP(Activation)
.INPUT(x, TensorType({  DT_FLOAT }))
.OUTPUT(y, TensorType({ DT_FLOAT }))
.ATTR(mode, AttrValue::INT { 1 })
.ATTR(coef, AttrValue::FLOAT { 0.0 })
.ATTR(negative_slope, AttrValue::FLOAT { 0.0 })
.OP_END()
```

对于每个节点，根据网络模型中该节点的详细信息，调用单算子模型[Graph类接口](https://developer.huawei.com/consumer/cn/doc/hiai-References/getimpl-0000001052808173)设置其输入和属性值。

网络中的第一个Activation节点，输入包括一个input，通过*set_input_x*接口配置。

模型中没有指定属性的取值，为非必选属性，可不设置；如果设置也可通过*set_attr_属性名*接口给予默认值。

```screen
auto relu_conv1 = hiai::op::Activation("relu_conv1")
     .set_input_x(conv1)
     .set_attr_coef(0.000000)
     .set_attr_mode(1);
```

REG_OP(ConcatD)
.DYNAMIC_INPUT(x, TensorType({ DT_FLOAT, DT_INT32, DT_UINT8, DT_INT8, DT_BOOL }))

### IF

根据算子定义，If算子有以下输入和属性。

```screen
REG_OP(If)
.INPUT(cond, TensorType({DT_BOOL}))
.DYNAMIC_INPUT(x, TensorType({DT_FLOAT, DT_INT8, DT_INT32, DT_BOOL}))
.DYNAMIC_OUTPUT(y, TensorType({DT_FLOAT, DT_INT8, DT_INT32, DT_BOOL}))
.REQUIRED_GRAPH(then_branch)
.REQUIRED_GRAPH(else_branch)
.ATTR(output_shapes, AttrValue::LIST_TENSOR_DESC{})
.OP_END()
```

对于每个节点，根据网络模型中该节点的详细信息，调用单算子模型[Graph类接口](https://developer.huawei.com/consumer/cn/doc/hiai-References/getimpl-0000001052808173)设置其输入和属性值。

网络中的If节点，输入包括cond和动态输入x，cond通过"set_input_cond"接口配置，cond可通过构建一个单算子配置，如下所示。

```screen
auto less = hiai::op::Less("less").
set_input_x1(leftData).
set_input_x2(rightData);
auto y = hiai::op::If("if").set_input_cond(less)
```

属性包括REQUIRED_GRAPH子图属性，通过.set_graph_builder_接口去设定，示例如下。

```screen
.set_graph_builder_else_branch(GenerateThenGraph)
```

其中GenerateThenGraph为构造控制流算子子图的可调用函数（函数类型：std::function<void(ge::Graph&)>），通过可调用函数生成子模型，示例如下。

```screen
void GenerateThenGraph(ge::Graph& graph)
{
    auto data = hiai::op::Data("then_input").set_attr_index(0);
    ge::TensorDesc desc(ge::Shape({1, 1, 2, 2}), ge::Format::FORMAT_NCHW, ge::DataType::DT_FLOAT);
    data.set_attr_index(0);
    data.update_input_desc_x(desc);
    auto thenActivate = hiai::op::Activation("then_activation").set_input_x(data);
    std::vector<ge::Operator> inputs{data};
    std::vector<ge::Operator> outputs{thenActivate};
    graph.SetInputs(inputs).SetOutputs(outputs);
}
```

```screen
void GenerateCondGraph(ge::Graph&graph)
{
auto data = hiai::op::Data("data_input").set_attr_index(0);
auto leftData = hiai::op::Data("left_input").set_attr_index(1);
auto rightData = hiai::op::Data("right_input").set_attr_index(2);

auto less = hiai::op::Less("less").
set_input_x1(leftData).
set_input_x2(rightData);
std::vector<ge::Operator> inputs{data, leftData, rightData};
std::vector<ge::Operator> outputs{less};

graph.SetInputs(inputs).SetOutputs(outputs);
}
```

## 网络构建

Demo示例中Java通过JNI调用Native代码，Native代码调用libhiai_ir.so和libhiai_ir_build.so库的函数实现IR模型的构建，网络构建步骤如下。

1. 获取离线模型存储路径。
2. 获取各算子权重和偏置路径。
3. 创建Graph对象。
4. 调用"buildSqueezenetGraph"函数，详细步骤如下，构建上面创建好的图对象。

   1. 调用"getConvdata"函数构建网络输入data。
   2. 按照网络层次进行遍历，每次遍历时执行"getConvRealBias"和"getConvRealWeight"函数，即获得对应层dat文件中的权重和偏置。
   3. 创建op::Const，将对应层dat文件中的权重和偏置构建成Const算子，以作对应bias、filter的输入属性。
   4. 按照网络层次遍历，构建相应层的对象，设置输入以及参数，获得输出，并将输出作为下一层的输入。
   5. 构建softmax算子返回prob对象作为网络输出分类结果。
   6. 以data和prob创建输入输出vector。
   7. 将输入输出vector设置到graph中。

5. 创建Model对象，调用"SetGraph"函数将构建好的"graph"赋给"model"。
6. 创建HiaiIrBuild对象、ModelBufferData对象。
7. 调用HiaiIrBuild的"CreateModelBuff"函数，给上面的ModelBufferData对象分配空间。
8. 调用HiaiIrBuild的"BuildIRModel"函数进行模型构建，参数为上面的ModelBufferData对象。

   如果返回成功，请继续操作；如果返回失败，直接跳至[步骤9](#ZH-CN_TOPIC_0000001053169830__li18405134333511)。

9. 调用HiaiIrBuild对象的[ReleaseModelBuff](https://developer.huawei.com/consumer/cn/doc/hiai-References/releasemodelbuff-0000001052968175)函数释放ModelBufferData对象。

代码实现在DDK包Demo_Source_Code工程的"Demo_Source_Code\hiaiv1_irmodelbuild\src\main\jni\CreateModel.cpp"和"Demo_Source_Code\hiaiv1_irmodelbuild\src\main\jni\ClassifyJni.cpp"中。
