# 框架集成

MNN、TNN、Paddle-Lite、MindSpore等三方应用框架已对接CANN DDK，将对应的三方框架和CANN DDK联合编译，运行时这些三方框架对应模型算子映射成标准IR算子，就可以直接运行在KirinNPU芯片平台上。

具体框架集成方式可以参见[MNN集成华为NPU使用说明](https://www.yuque.com/mnn/cn/xfs77m)、[TNN集成华为NPU使用说明](https://github.com/Tencent/TNN/blob/master/doc/cn/faq.md#四npu相关问题)、[Paddle-Lite集成华为麒麟NPU使用说明](https://www.paddlepaddle.org.cn/lite/develop/demo_guides/huawei_kirin_npu.html)、[MindSpore集成NPU使用说明](https://www.mindspore.cn/lite/docs/zh-CN/master/use/npu_info.html)。
