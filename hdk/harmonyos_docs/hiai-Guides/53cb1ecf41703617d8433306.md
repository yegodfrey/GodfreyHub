# 开发指南

#### 应用开发

#### 必须导入类

1. 在使用文字图像超分API时，将实现文字图像超分的相关的类添加至工程。

   ```
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数 
   import com.huawei.hiai.vision.common.VisionBase; // 加载连接服务的静态类
   import com.huawei.hiai.vision.image.sr.TxtImageSuperResolution;  // 加载文字超分方法类
   import com.huawei.hiai.vision.visionkit.common.Frame; // 加载Frame类
   import com.huawei.hiai.vision.visionkit.image.ImageResult; // 加载文字超分结果类
   ```

#### 开发

1. 应用VisionBase静态类进行初始化，异步获取服务的连接。

   ```
   VisionBase.init(MainActivity.this, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. API使用示例。

   ```
   BitmapFactory.Options options = new BitmapFactory.Options();
   options.inPreferredConfig = Bitmap.Config.ARGB_8888;
   Bitmap bitmap = BitmapFactory.decodeFile(imgPath, options); // 获取Bitmap图像( 注意此处的bitmap类型必须为ARGB8888，请注意做必要的转换) 
   Frame frame = new Frame();// 构造Frame对象 
   frame.setBitmap(bitmap);  
   TxtImageSuperResolution tsr = new TxtImageSuperResolution (context);
   // 进行文字超分
   ImageResult srResult = tsr.doSuperResolution(frame, null);
   Bitmap bmp = srResult.getBitmap(); // 将结果中获得到处理后的bitmap
   ```
