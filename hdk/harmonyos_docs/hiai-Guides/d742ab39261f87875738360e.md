# 集成在线文本翻译服务SDK

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172359.64960535998259051463939386975966:50001231000000:2800:98B8FA059B4AAFFFEAB4D6CB890E1AB9E588029F02B962A19D141FA8D5F1B283.png)  
若您的应用同时集成了ML Kit提供的多个服务（[ML Kit服务列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-sdk-harmonyos-0000001252277009#ZH-CN_TOPIC_0000001252277009__li1842231414318)），可能会出现编译问题，您需要将您集成的其他服务升级到最新版本。

集成在线文本翻译服务示例代码如下：

```
dependencies{
    implementation 'com.huawei.hms:ml-computer-harmony-language-translate-bolt:3.7.0.302'
}
```

#### 添加AGCP插件配置

用上述方式集成SDK后，添加AGCP插件配置：  
在文件头部声明下一行添加如下配置。

```
apply plugin: 'com.huawei.agconnect'
```
