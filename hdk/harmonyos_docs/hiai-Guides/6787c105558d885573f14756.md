# 个人数据处理说明

此文档针对华为作为最终用户数据处理者，开发者作为最终用户数据控制者的数据处理进行说明，包括：

* 华为处理的个人数据清单。
* 提供指导使客户实现对最终用户数据主体权利的支持。

#### 华为处理的个人数据清单

|个人数据清单|使用目的|存留期|
|:--------------------------|:-------------------------------------|:-----------------------------------------------|
|用户上传的文本图片|识别文本图片中文字及文档结构信息，返回图片中的文字内容。|云侧不存储任何数据与信息，识别的图片和文字内容不进行保存，随着处理过程的结束，自动释放图片信息。|
|用户上传的中国二代身份证图片 \*该服务仅在中国区提供|识别用户上传的中华人民共和国二代身份证图片，返回中国二代身份证图片文字内容。|云侧不存储任何数据与信息，识别的图片和文字内容不进行保存，随着处理过程的结束，自动释放图片信息。|
|用户上传的需要翻译的文本|将输入的文字翻译为目标语种文字，如中、英、法、西、土、阿、泰等语言的互译。|云侧不存储任何数据与信息，识别的图片和文字内容不进行保存，随着处理过程的结束，自动释放图片信息。|
|用户输入的需要语种识别的文本|识别输入文本的语种，如法语、西班牙语、俄语等。|云侧不存储任何数据与信息，识别的图片和文字内容不进行保存，随着处理过程的结束，自动释放图片信息。|
|用户上传的需要进行分类的图片|识别图片中物体的分类信息。|云侧不存储任何数据与信息，识别的图片和文字内容不进行保存，随着处理过程的结束，自动释放图片信息。|
|用户上传的地标图片|识别图片中地标名称并根据地标名称提供地理坐标经纬度。|云侧不存储任何数据与信息，识别的图片和文字内容不进行保存，随着处理过程的结束，自动释放图片信息。|
|用户上传的需要识别拍照购物识别的图片|识别上传图片中的商品，返回商品对应的商品ID和图片ID。|云侧不存储任何数据与信息，识别的图片和文字内容不进行保存，随着处理过程的结束，自动释放图片信息。|
|用户通过实时语音插件录入的语音|将输入的实时语音转换为文字显示。|云侧不存储语音，云侧处理完成后删除。|
|用户上传需要语言合成的文本|对输入的文字转换为语音。|云侧不存储文本信息，云侧处理完成后删除。|
|用户上传的音频文件|将上传音频文件转换为文本输出。|云侧不存储音频文件，云侧处理完成后删除。|

#### 指导开发者如何帮助最终用户实现对数据的控制

云侧不存储个人数据，由数据控制者面向最终用户提供相应的数据主体权利及其相关解释。
