# 开发指南

#### 应用开发

#### 必须导入类

1. 在使用文档检测校正API时，将实现文档检测校正的相关的类添加至工程。

   ```
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
   import com.huawei.hiai.vision.common.VisionBase; // 加载连接服务的静态类
   import com.huawei.hiai.vision.common.VisionImage; // 加载VisionImage类
   import com.huawei.hiai.vision.image.docrefine.DocRefine; // 加载文档矫正类
   import com.huawei.hiai.vision.visionkit.image.detector.DocCoordinates; // 加载文档检测结果类
   ```

#### 开发

1. 应用VisionBase静态类进行初始化，异步获取服务的连接。

   ```
   VisionBase.init(MainActivity.this, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. 定义DocRefine实例，将此应用的Context当做入参。

   ```
   DocRefine docResolution = new DocRefine(context);
   ```

3. 新建VisionImage实例，传入待检测图像Bitmap。

   ```
   // 获取Bitmap图像
   Bitmap bitmap = BitmapFactory.decodeFile(filePath);
   // 构造VisionImage对象
   VisionImage img = VisionImage.fromBitmap(bitmap);
   // 构造文档检测结果类
   DocCoordinates docCoordinates = new DocCoordinates();
   // 进行文档检测，获取Java类形式的文档检测结果；sc中包含识别出来的文档四个角相对原图中左上角的坐标信息（单位：像素）
   int result = docResolution.docDetect(img, docCoordinates, null);
   //以docCoordinates中四个角坐标定义出来的矩形区域做为待校验区域，输出包含校验后的bitmap信息的ImageResult对象。此处传入的docCoordinates可使用文档检测接口检测出的结果，亦可自定义坐标信息。
   ImageResult imgResult = new ImageResult();
   int resultCode = docResolution.docRefine(img, docCoordinates, imgResult, null)
   //获取bitmap结果
   Bitmap bmp = imgResult.getBitmap();
   ```
