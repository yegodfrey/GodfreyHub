# 人体骨骼检测

## 服务介绍

人体骨骼检测服务支持检测人体多部位关键点，如：头顶、脖子、肩、肘、手腕、髋、膝盖、脚踝等，同时能够返回骨骼关键点的位置数据。目前支持全身和半身的静态图片识别，以及实时视频流识别。

* 静态图片识别：支持识别单人和多人图片，支持全身和半身图片。
* 实时视频流识别：支持单人和多人、全身和半身姿态相似度检测。
* 瑜伽模式下静态图片识别、实时视频流识别均只能识别单人模型。

## 应用场景

人体骨骼检测服务广泛应用于日常生活中的众多领域。例如，在进行拍摄时，可根据设定的动作模板摆出相似的造型，手机会进行骨骼点检测和相似度自动抓拍，完成趣味抓拍创作。另外，在进行瑜伽练习时，个人练习可能存在动作不规范等情况，可通过检测练习人的姿势，并与教学中的瑜伽姿势规范动作要点图片进行比对，符合要求后继续下一个动作，避免盲目练习。

## 注意事项

人体骨骼检测服务当前支持检测站立体位，对于倒立等高难度体位动作的检测将在后续版本支持。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/skeleton-sdk-0000001050728362)。

### 静态图片检测

1. 创建人体骨骼分析器。

   ```java
   "Java"
   // 方式一：使用自定义参数配置。
   MLSkeletonAnalyzerSetting setting = new MLSkeletonAnalyzerSetting.Factory()
       // 设置检测模式。
       // MLSkeletonAnalyzerSetting.TYPE_NORMAL:检测常规人体姿态对应的骨骼点。
       // MLSkeletonAnalyzerSetting.TYPE_YOGA：检测瑜伽人体姿态对应的骨骼点。
       .setAnalyzerType(MLSkeletonAnalyzerSetting.TYPE_NORMAL)
       .create();
   MLSkeletonAnalyzer analyzer = MLSkeletonAnalyzerFactory.getInstance().getSkeletonAnalyzer(setting);
   // 方式二：使用默认参数配置，默认参数为:检测常规人体姿态对应的骨骼点。
   MLSkeletonAnalyzer analyzer = MLSkeletonAnalyzerFactory.getInstance().getSkeletonAnalyzer();
   ```

   ```javascript
   "Kotlin"
   // 方式一：使用自定义参数配置。
   var setting = MLSkeletonAnalyzerSetting.Factory() // 设置检测模式。
            // MLSkeletonAnalyzerSetting.TYPE_NORMAL:检测常规人体姿态对应的骨骼点。
            // MLSkeletonAnalyzerSetting.TYPE_YOGA：检测瑜伽人体姿态对应的骨骼点。
            .setAnalyzerType(MLSkeletonAnalyzerSetting.TYPE_NORMAL)
            .create()
   var analyzer = MLSkeletonAnalyzerFactory.getInstance().getSkeletonAnalyzer(setting)

   // 方式二：使用默认参数配置，默认参数为:检测常规人体姿态对应的骨骼点。
   var analyzer = MLSkeletonAnalyzerFactory.getInstance().skeletonAnalyzer
   ```

2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象用于分析器检测图片，支持的图片格式包括：jpg/jpeg/png，建议图片尺寸不小于320*320像素，不大于1920*1920像素。

   ```java
   "Java"
   //通过bitmap创建MLFrame。
   MLFrame frame = MLFrame.fromBitmap(bitmap);
   ```

   ```javascript
   "Kotlin"
   //通过bitmap创建MLFrame。
   var frame = MLFrame.fromBitmap(bitmap)
   ```

3. 调用同步或异步方法进行人体骨骼检测。检测结果除了包含每个骨骼点的坐标信息外，还包含每个点的置信度值，可以基于置信度值过滤误识别的无效骨骼点，实际应用中可根据对误识别的容忍程度，设置阙值灵活应用。
   * [asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlskeletonanalyzer-0000001051056245#section13542111420252)异步方法示例代码：

     ```java
     "Java"
     Task<List<MLSkeleton>> task = analyzer.asyncAnalyseFrame(frame);
     task.addOnSuccessListener(new OnSuccessListener<List<MLSkeleton>>() {
         @Override
         public void onSuccess(List<MLSkeleton> results) {
             // 检测成功。
         }
     }).addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
             // 检测失败。
         }
     });
     ```

     ```javascript
     "Kotlin"
     val task = analyzer!!.asyncAnalyseFrame(frame)
      task.addOnSuccessListener {
     // 检测成功。
     }.addOnFailureListener {
     // 检测失败。
      }
     ```


   * [analyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlskeletonanalyzer-0000001051056245#section24809226580)同步方法示例代码：

     ```java
     "Java"
     SparseArray<MLSkeleton> sparseArray = analyzer.analyseFrame(frame); 
     for (int i = 0; i < sparseArray.size(); i++) {
         // 检测结果处理。
     };
     ```

     ```javascript
     "Kotlin"
     val sparseArray = analyzer!!.analyseFrame(frame)
     for (i in 0 until sparseArray.size()) {
          // 检测结果处理。
      }
     ```

4. 检测完成，停止分析器，释放检测资源。

   ```java
   "Java"
   try {
       if (analyzer != null) {
           analyzer.stop();
       }
   } catch (IOException e) {
       // 异常处理。
   }
   ```

   ```javascript
   "Kotlin"
   try {
        if (analyzer != null) {
            analyzer!!.stop()
        }
    } catch (e: IOException) {
        // 异常处理。
   }
   ```

### 视频流检测

开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按照上文中静态图像本地检测的方法进行骨骼检测。如果开发者调用的是同步检测接口，也可以使用SDK内置的[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)类实现视频流本地骨骼检测，示例代码如下：

1. 创建人体骨骼分析器。

   ```java
   "Java"
   // 方式一：使用自定义参数配置。
   MLSkeletonAnalyzerSetting setting = new MLSkeletonAnalyzerSetting.Factory()
       // 设置检测模式。
       // MLSkeletonAnalyzerSetting.TYPE_NORMAL:检测常规人体姿态对应的骨骼点。
       // MLSkeletonAnalyzerSetting.TYPE_YOGA：检测瑜伽人体姿态对应的骨骼点。
       .setAnalyzerType(MLSkeletonAnalyzerSetting.TYPE_NORMAL)
       .create();
   MLSkeletonAnalyzer analyzer = MLSkeletonAnalyzerFactory.getInstance().getSkeletonAnalyzer(setting);
   // 方式二：使用默认参数配置，默认参数为：检测常规人体姿态对应的骨骼点。
   MLSkeletonAnalyzer analyzer = MLSkeletonAnalyzerFactory.getInstance().getSkeletonAnalyzer();
   ```

   ```javascript
   "Kotlin"
   // 方式一：使用自定义参数配置。
   var setting = MLSkeletonAnalyzerSetting.Factory() // 设置检测模式。
            // MLSkeletonAnalyzerSetting.TYPE_NORMAL:检测常规人体姿态对应的骨骼点。
            // MLSkeletonAnalyzerSetting.TYPE_YOGA：检测瑜伽人体姿态对应的骨骼点。
            .setAnalyzerType(MLSkeletonAnalyzerSetting.TYPE_NORMAL)
            .create()
   var analyzer = MLSkeletonAnalyzerFactory.getInstance().getSkeletonAnalyzer(setting)

   // 方式二：使用默认参数配置，默认参数为:检测常规人体姿态对应的骨骼点。
   var analyzer = MLSkeletonAnalyzerFactory.getInstance().skeletonAnalyzer
   ```

2. 开发者创建识别结果处理类"SkeletonAnalyzerTransactor"，该类实现[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)<T>接口，使用此类中的[transactResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216#section7411382071)方法获取检测结果并实现具体业务。检测结果除了包含每个骨骼点的坐标信息外，还包含每个点的置信度值，可以基于置信度值过滤误识别的无效骨骼点，实际应用中可根据对误识别的容忍程度，设置阙值灵活应用。

   ```java
   "Java"
   public class SkeletonAnalyzerTransactor implements MLAnalyzer.MLTransactor<MLSkeleton> {
       @Override
       public void transactResult(MLAnalyzer.Result<MLSkeleton> results) {
           SparseArray<MLSkeleton> items = results.getAnalyseList();
           // 开发者根据需要处理识别结果，例如，在此方法中进行相似度计算，从而在检测到特定姿势后进行拍照等操作。
           // 需要注意，这里只对检测结果进行处理，不可调用ML Kit提供的其他检测相关接口。
           // 将SparseArray封装的结果转换为List数组，以便进行相似度比较。
           List<MLSkeleton> resultsList = new ArrayList<>();
           for (int i = 0; i < items.size(); i++) {
               resultsList.add(items.valueAt(i));
           }
           // 在检测结果和模板之间进行相似度比较。
           // templateList表示人体骨骼模板，可以通过静态图片检测的方式生成模板，支持单人或多人模板匹配。
           float result = analyzer.caluteSimilarity(resultsList, templateList);
       }
       @Override
       public void destroy() {
           // 检测结束回调方法，用于释放资源等。
       }
   }
   ```

   ```javascript
   "Kotlin"
   class SkeletonAnalyzerTransactor : MLTransactor<MLSkeleton?> {
        override fun transactResult(results: MLAnalyzer.Result<MLSkeleton?>) {
            val items = results.analyseList
            // 开发者根据需要处理识别结果，例如，在此方法中进行相似度计算，从而在检测到特定姿势后进行拍照等操作。
            // 需要注意，这里只对检测结果进行处理，不可调用ML Kit提供的其他检测相关接口。
            // 将SparseArray封装的结果转换为List数组，以便进行相似度比较。
            val resultsList: MutableList<MLSkeleton?> = ArrayList()
            for (i in 0 until items.size()) {
                resultsList.add(items.valueAt(i))
            }
            // 在检测结果和模板之间进行相似度比较。
            // templateList表示人体骨骼模板，可以通过静态图片检测的方式生成模板，支持单人或多人模板匹配。
            val result = analyzer!!.caluteSimilarity(resultsList, templateList)
        }

        override fun destroy() {
            // 检测结束回调方法，用于释放资源等。
        }
    }
   ```

   > 说明
   >
   > 当前人体骨骼服务提供的[caluteSimilarity](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlskeletonanalyzer-0000001051056245#section189864912717)接口实现的人体骨骼点匹配只支持二维点，因此在使用时可能出现人体在躺着状态生成的模板也可以匹配站立状态图像的现象，建议在您的应用中对此类场景作出说明。
3. 设置识别结果处理器，实现分析器与结果处理器的绑定。

   ```screen
   "Java"
   analyzer.setTransactor(new SkeletonAnalyzerTransactor());
   ```

   ```screen
   "Kotlin"
   analyzer!!.setTransactor(SkeletonAnalyzerTransactor())
   ```

4. 创建[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)，该类由ML Kit SDK提供，用于捕捉相机动态视频流并传入分析器。建议设置的相机显示尺寸不小于320*320像素，不大于1920*1920像素。

   ```screen
   "Java"
   LensEngine lensEngine = new LensEngine.Creator(getApplicationContext(), analyzer)
       .setLensType(LensEngine.BACK_LENS)
       .applyDisplayDimension(1280, 720)
       .applyFps(20.0f)
       .enableAutomaticFocus(true)
       .create();
   ```

   ```screen
   "Kotlin"
   val lensEngine = LensEngine.Creator(applicationContext, analyzer)
            .setLensType(LensEngine.BACK_LENS)
            .applyDisplayDimension(1280, 720)
            .applyFps(20.0f)
            .enableAutomaticFocus(true)
            .create()
   ```

5. 调用run方法，启动相机，读取视频流，进行识别。

   ```java
   "Java"
   // 请自行实现SurfaceView控件的其他逻辑。
   SurfaceView mSurfaceView = findViewById(R.id.surface_view);
   try {
       lensEngine.run(mSurfaceView.getHolder());
   } catch (IOException e) {
       // 异常处理逻辑。
   }
   ```

   ```javascript
   "Kotlin"
   // 请自行实现SurfaceView控件的其他逻辑。
   val mSurfaceView: SurfaceView? = findViewById(R.id.surface_view)
   try {
        lensEngine!!.run(mSurfaceView!!.holder)
    } catch (e: IOException) {
        // 异常处理逻辑。
   }
   ```

6. 检测完成，停止分析器,释放检测资源。

   ```java
   "Java"
   if (analyzer != null) {
       try {
           analyzer.stop();
       } catch (IOException e) {
            // 异常处理。
       }
   }
   if (lensEngine != null) {
       lensEngine.release();
   }
   ```

   ```javascript
   "Kotlin"
   if (analyzer != null) {
        try {
            analyzer.stop()
        } catch (e: IOException) {
            // 异常处理。
        }
    }
   lensEngine?.release()
   ```

使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)<T>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见[视频流检测模式多次识别场景开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-video-0000001050040139)。
