# 集成语音合成服务SDK

语音合成服务支持基础SDK方式集成，示例代码如下：

```
dependencies{
    // 引入语音合成服务SDK
    implementation ('com.huawei.hms:ml-computer-voice-tts:3.15.1.300') {
         exclude group : "com.huawei.hms", module: "network-embedded"
    }
    implementation 'com.huawei.hms:network-embedded:7.0.3.300'
}
```

#### 添加AGCP插件配置

用上述方式集成SDK后，请根据实际情况选择添加AGCP插件配置：

* 方式一：在文件头部声明下一行添加如下配置。

  ```
  apply plugin: 'com.huawei.agconnect'
  ```

* 方式二：在plugins中添加如下配置。

  ```
  plugins {
      id 'com.android.application'
      //添加如下配置
      id 'com.huawei.agconnect'
  }
  ```
