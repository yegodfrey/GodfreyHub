# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## 识别的图片大小、分辨率、格式有限制吗?

支持PNG、JPG、JPEG、BMP，不支持GIF图片。

## 基于ML Kit进行开发，开发者是否需要自行搭建ML框架？

不需要，只需集成ML Kit SDK即可。

## 在欧洲，ML Kit对数据的处理是否涉及GDPR？

ML Kit对数据处理遵循GDPR要求。

## 如果不上传ML的样本，后台训练模型的数据从哪里来的？

通过合法供应商及合作伙伴采购获取图片进行训练。

## 人脸识别是否依赖特定的硬件设备？

人脸识别需要基于ARM架构的Android手机。

## 文本识别目前支持哪些语言？

端侧提供中文（简体）、日文、韩文、拉丁语（包括英文、西班牙文、葡萄牙文、意大利文、德文、法文、俄文、特殊字符，支持的特殊字符请参见[文字识别客户端支持的拉丁字符](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)）。

云侧提供中文（简体）、英文、西班牙文、葡萄牙文、意大利文、德文、法文、俄文、日文、韩文、波兰文、芬兰文、挪威文、瑞典文、丹麦文、土耳其文、泰文、阿拉伯文、印地文、印尼文等文字。

## 目标跟踪是否支持目标的识别目标的远近、目标的颜色？

目前不支持物体远近、颜色的识别。

## 预置在手机中的模型更新周期是多长？

通过应用市场发布版本更新，ML Kit按月迭代发布，按规划持续提升准确率。

## 集成人脸检测功能后，为什么识别结果不准确？

如果您在集成了人脸检测模型的较高版本之后，将模型回退到旧版本，例如，您先集成了1.0.3.300版本的人脸检测模型之后，回退到1.0.2.300版本，有可能导致人脸检测结果不准确，使用ML Kit的最新人脸检测版本即可解决此问题。

## 集成拍照购iOS时，是否需要导入agconnect-services.plist文件？

需要。如果不导入agconnect-services.plist文件，调用SDK的检测接口会出现App闪退情况。

## 集成机器学习服务的新版本后，为什么会出现编译冲突？

ML Kit提供的部分服务新版本会和其他服务老版本有冲突，建议您根据[升级指南](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/upgrade-guide-0000001050038074)，将您集成的所有ML Kit服务升级到最新版本。

## 集成iOS动态库发布到AppStore时，需要移除模拟器架构吗？

需要。具体移除步骤如下（请在终端执行，下面的示例以本地电脑上的MLKitProductVisualSearch动态库所在路径为基础，具体操作，请改成本地电脑上动态库所在的路径）：

1. 进入到动态库所在的路径。 **cd /Users/user/Desktop/TempFile/MLKitProductVisualSearch-2.0.2**

2. 移除x86__64架构。 **lipo MLProductVisionSearch.framework/MLProductVisionSearch -remove x86_64 -output MLProductVisionSearch**

3. 将生成的新的二进制文件替换。 **mv MLProductVisionSearch MLProductVisionSearch.framework/MLProductVisionSearch**

此时，已经完成移除x86_64架构，可以通过lipo -info指令查看移除结果。

**lipo -info MLProductVisionSearch.framework/MLProductVisionSearch**

**Architectures in the fat file: MLProductVisionSearch.framework/MLProductVisionSearch are: armv7 arm64**

## TTS下载模型时报错multiThreadDownload failed，模型无法下载，这种情况该怎么处理？

ML的模型下载是通过非加密http连接的，在Android API 27+上会下载失败，需要在AndroidManifest.xml内配置android:usesCleartextTraffic="true"，详见 [3.4.3.6 配置AndroidManifest.xml文件](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-androidmanifestxml-0000001072072844)。

## TTS在线语言合成在部分Android6.0.1的手机上会出现Crash的情况是什么？

Android系统MediaCodec的缺陷导致。

## 集成多个SDK时出现"More than one file was found with OS independent path"错误的原因？

gradle配置项packagingOptions中添加pickFirst配置项。

## MLKit在Anroid 6.0以下的设备上不支持Lite SDK集成原因？

MLKit Lite SDK方式集成依赖[动态加载](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-dynamicability-faq-0000001086721834)SDK实现，而较低版本的Android系统对部分文件的路径长度做了限制，动态加载的so文件绝对路径总长度超过50个字符时，会报错"UnsatisfiedLinkError: dlopen failed: library name xxxxxx too long"错误，加载so文件失败而不支持。
