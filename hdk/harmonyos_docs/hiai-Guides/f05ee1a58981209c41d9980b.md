# 模型转换前准备

1. 准备训练好的Caffe、TensorFlow、ONNX等模型。例如：[Caffe SqueezeNet V1.0](https://github.com/forresti/SqueezeNet)模型。
2. 下载[Tools工具](https://developer.huawei.com/consumer/cn/doc/hiai-Library/tools-download-0000001060044334)，解压使用Tools下的OMG工具，将TensorFlow或Caffe模型转换为IR模型，使用方式请参见[模型转换示例](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-conversion-example-0000001053125647)。

若TensorFlow或Caffe模型过大，可以在OMG转换之前使用DDK中的轻量化工具，使用方式请参见[模型轻量化](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-0000001053005655)。
