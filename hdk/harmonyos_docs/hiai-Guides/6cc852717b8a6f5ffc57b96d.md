# 同声传译

## 服务介绍

同声传译实现将实时输入的长语音（时长不超过5小时）实时翻译为不同语种的文本以及语音，并实时输出原语音文本、翻译后的文本以及翻译文本的语音播报。支持中英文互译，支持多种音色语音播报。

## 应用场景

同声传译适用于国际论坛、智能会议、商务洽谈、智慧教育、跨国交流等场景使用。比如会议直播字幕场景，正在进行中的会议可以将音频内容实时输出为目标语言文字，便于不同语言的人实时理解会议内容，提高会议效率。另外，支持对目标语言文本进行实时播报，提升会议体验。

## 注意事项

* 此版本为众测体验版本，目前不支持息屏场景使用。
* 同声传译服务通过访问云侧接口完成识别服务，调测和使用时需保证设备可正常访问互联网。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/si-sdk-0000001307307593)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建同传识别器，并设置配置。

   ```java
   "Java"
   MLSimultaneousInterpretationConfig config = new MLSimultaneousInterpretationConfig.Factory()
                   // 设置源语种，目前支持中文和英文
                   .setSourceLanguage(MLSimultaneousInterpretationConstants.LAN_ZH_CN)
                   // 设置目标语种，目前支持中文和英文
                   .setTargetLanguage(MLSimultaneousInterpretationConstants.LAN_EN_US)
                   // 设置识别类型。支持原始文本+翻译文本+翻译语音
                   .setResultType(MLSimultaneousInterpretationConstants.RESULT_TYPE_TEXT_TRANSLATED_VOICE)
                   // 设置发音人，支持英文女声、英文男声、中文女声、中文男声 
                   .setPerson(MLSimultaneousInterpretationConstants.EN_MALE_VOICE) 
                   .create();
    MLSimultaneousInterpretationRecognizer mlSimultaneousInterpretationRecognizer = MLSimultaneousInterpretationRecognizer.getInstance();
   ```

   ```javascript
   "Kotlin"
   val config = MLSimultaneousInterpretationConfig.Factory()
                   // 设置源语种，目前支持中文和英文
                   .setSourceLanguage(MLSimultaneousInterpretationConstants.LAN_ZH_CN)
                   // 设置目标语种，目前支持中文和英文
                   .setTargetLanguage(MLSimultaneousInterpretationConstants.LAN_EN_US)
                   // 设置识别类型。支持原始文本+翻译文本+翻译语音
                   .setResultType(MLSimultaneousInterpretationConstants.RESULT_TYPE_TEXT_TRANSLATED_VOICE)
                   // 设置发音人，支持英文女声、英文男声、中文女声、中文男声  
                   .setPerson(MLSimultaneousInterpretationConstants.EN_MALE_VOICE) 
                   .create()
    val mlSimultaneousInterpretationRecognizer = MLSimultaneousInterpretationRecognizer.getInstance()
   ```

3. 创建语音识别结果监听器回调。

   ```screen
   "Java"
   // 回调实现MLSimultaneousInterpretationListener，实现接口中的方法。
       protected class SIRecognitionListener implements MLSimultaneousInterpretationListener {
           @Override
           public void onStartListening() {
               // 录音器开始接收声音。
    }
           @Override
           public void onVoiceDataReceived(byte[] data) {
               // 返回给用户原始的PCM音频流，该接口并非运行在主线程中，返回结果需要在子线程中处理。
           }
           @Override
           public void onRecognizingResults(Bundle partialResults) {
               // 从SIRecognitionListener接收到持续语音识别的文本。
               // RESULTS_RECOGNIZING:原始文本；RESULTS_TRANS_RECOGNIZING：翻译文本；RESULTS_SN：原始序列号；RESULTS_TRANS_SN：翻译文本序列号
           }
           @Override
           public void onResults(Bundle results) {
               // 从SIRecognitionListener接收到完整的句子
               // RESULTS_RECOGNIZED:原始结果；RESULTS_TRANS_RECOGNIZED：翻译文本结果
           }
           @Override
           public void onError(int error, String errorMessage) {
               // 识别发生错误后调用该接口。
           }
           @Override
           public void onState(int state, Bundle params) {
               // 通知应用状态发生改变。
           }
       }
   ```


4. 绑定同传识别器。

   ```screen
   "Java"
   mlSimultaneousInterpretationRecognizer.setMLSimultaneousInterpretationListener(new SIRecognitionListener());
   ```

   ```screen
   "Kotlin"
   mlSimultaneousInterpretationRecognizer!!.setMLSimultaneousInterpretationListener(SIRecognitionListener())
   ```

5. 调用[startRecognizing](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlsdk-si-recognizer-0000001307429561#section146779311786)启动语音识别。

   ```screen
   "Java"
   // 开始识别。 
    mlSimultaneousInterpretationRecognizer.startRecognizing(config);
   ```

   ```screen
   "Kotlin"
   // 开始识别。 
    mlSimultaneousInterpretationRecognizer.startRecognizing(config)
   ```

6. 识别完成后，结束识别并释放资源。

   ```screen
   "Java"
   if (mlSimultaneousInterpretationRecognizer!= null) {
     mlSimultaneousInterpretationRecognizer.destroy();
     }
   ```

   ```screen
   "Kotlin"
   if (mlSimultaneousInterpretationRecognizer!= null) {
     mlSimultaneousInterpretationRecognizer.destroy()
     }
   ```
