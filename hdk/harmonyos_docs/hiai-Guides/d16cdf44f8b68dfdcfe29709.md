# 版本更新说明

## 11.0.3.300（2022-03-04）

|------------------------------------------------------------------------------|
|**修改内容** 修改开发指南中人脸比对、人脸朝向识别的调用方式。 修改开发指南中卡证识别、图像超分别率、文字图像超分、模板OCR、文档检测矫正的调用方式。|

## SDK依赖说明

温馨提示：您在集成HUAWEI HiAI Engine的过程中，如有问题可[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，可通过"HMS Capabilities & Tools > HUAWEI HiAI >HUAWEI HiAI Engine"反馈相关的问题。
