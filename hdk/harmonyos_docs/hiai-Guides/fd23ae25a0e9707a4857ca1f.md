# 多语言设置

如果您的应用只支持某些特定语言，请忽略本步骤。应用将默认支持所有HMS Core SDK支持的语言。如果您的应用需要设置只支持某些特定语言，则可通过本步骤配置。

1. 在"PROJECT"项目的Info栏下Localizations处点击+号，增加自己需要的语言。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172416.93277274370698354590179219632808:50001231000000:2800:BFE8741D40D7D9E47B6B8E2A8145850372047D0336B16B99DE5FEF6493447D6E.png "点击放大")
2. 创建string file文件，文件名一定要使用Localizable。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172416.87694100250397691020485855420841:50001231000000:2800:2694FC0DEA6402BF31CE9AFA110A17D3122170726D889BF3AFCDC3C1D650B16B.png "点击放大")

3. 点击创建的Localizable.strings文件，在右侧点击蓝色"Localize..."按钮，选择一种您需要添加的语言，点击"Localize"确定。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172416.11580914524951420492495415145107:50001231000000:2800:D2A0629C33E80972321CAE935D7EF310E2621728E3FBEDFCB8277B0087451ED4.png "点击放大")
4. 在右侧勾选您需要的其他语言。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172416.49579138039145974520588266187876:50001231000000:2800:9944C964B27747D87178ABEDE930B2DBDF8133C5F5A46EA8D9650B73E106F333.png "点击放大")

5. 此时Localizable.strings文件下会包含添加的所有语言。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172416.71026852854221980689345318809443:50001231000000:2800:B098315E91EC4762AA177118AA3353E80D049A2A9A5A3FFA488643EA2C0E32EB.png "点击放大")

6. 在对应的语言文件下写入对应的key对应的value。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172416.83909602054400601777013199477988:50001231000000:2800:FC206F52649E9EAEF5FF5DECC7DE761ECA80C7A7A9D92CC860A480566214EC49.png "点击放大")

7. 在项目中需要使用的地方进行调用：

   ```codeblock
   NSLocalizedString(@"Camera", nil)
   ```

   > 说明
   >
   > Camera为其中对应的key，此处只是举例。

HMS Core SDK支持的语言列表请参见[HMS Core SDK支持的语言](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/support-language-0000001050040564)。
