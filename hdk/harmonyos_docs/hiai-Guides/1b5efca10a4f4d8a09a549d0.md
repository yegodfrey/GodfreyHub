# 端侧推理框架

机器学习服务推出的自定义模型端侧推理框架便于集成开发运行到端侧设备，通过引入此推理框架，您能够最小成本的定义自己的模型并实现模型推理，其主要具备以下优势：

1. 提供简单完备的接口，方便您集成端侧自定义模型的推理框架，让您能够通过最简单、快速的方式自定义模型，为您带来玩转机器学习的体验。
2. 兼容并包，支持市场存量的全部主流模型推理，如：MindSpore Lite/TensorFlow Lite/Caffe/Onnx，可以把不同的模型无损转换为ms格式，再通过端侧推理框架完美运行。
3. 自定义的模型占用的存储空间小，支持模型量化压缩，模型能够更快部署执行，同时通过云侧托管模型，运行时按需下载模型，能够降低APK体积。
4. 内核开源，机器学习推理框架的内核代码面向全球开发者开源，汇集全球贡献者的智慧，并持续迭代。不仅带给您友好的开发生态，也是您在机器学习推理道路上的良师益友。

更多端侧推理框架相关内容请参见[MindSpore Lite](https://www.mindspore.cn/lite)。
