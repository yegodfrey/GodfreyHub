# 业务介绍

## 业务简介

定制图像分类支持图片分类。开发者将图片传输到HUAWEI HiAI Engine，算法对图片进行分类，返回分类结果。

## 场景介绍

通过定制图像分类，用户可以在PC上利用训练工具训练模型，并快速部署到手机。

## 功能特点

* 模型训练速度快。

* 实时推理。
