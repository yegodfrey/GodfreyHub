# 在线语种检测

#### 服务介绍

在线语种检测服务可以检测出文本的语种，既支持检测单语种文本，也支持检测混合语种文本。返回对应语种的编码（中文繁体使用BCP-47标准编码，其他语言使用ISO 639-1标准编码）和相应的置信度，或者返回一个置信度最高的语种编码。目前在线语种检测能实现109种语言检测，支持的语言及语种编码的详细信息请参见[语种检测支持的语言列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)。例如，用户可以轻松实现翻译语种检测、网页语种检测，混合语种场景中语种检测等。

#### 应用场景

在线语种检测服务主要应用于翻译App中，能够自动检测文本的语种类型，用户无需选择源语种。或应用于浏览器类的App，对网页翻译前能够先检测确定语种类型。  

#### 注意事项

在线语种检测服务需要网络才能提供检测能力。  

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-config-agc-0000001055443511)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-real-time-language-detection-sdk-0000001062281476)。

1. 导入头文件。

   ```
   #import <MLLangDetection/MLLangDetection.h>
   ```

2. 配置全局云端鉴权码，目前提供以下两种方式进行设置：
   * accessToken方式

     ```
     [[MLLangDetectApplication sharedInstance] setAccessToken:@"your accessToken"];
     ```

   * apiKey方式

     ```
     [[MLLangDetectApplication sharedInstance] setApiKey:@"your apiKey"];
     ```

3. 创建语种检测器。可以通过语种检测器自定义参数类[MLRemoteLangDetectorSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlremotelangdetectorsetting-0000001063042322)创建检测器。

   ```
   MLRemoteLangDetectorSetting *setting = [[MLRemoteLangDetectorSetting alloc] initWithTrustThreshold:0.01f];
   MLRemoteLangDetector *detector = [[MLRemoteLangDetector alloc] initWithSetting:setting];
   ```

4. 进行语种检测（错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/development/hiai-References/mllangdetectionexception-0000001062274282)）。

   ```
   // sourceText表示待检测的文本，长度需小于5000个字符。
   [detector probabilityDetect:@"sourceText" addOnSuccessListener:^(NSArray * _Nonnull mlDetectedLangs) {
       // 成功处理逻辑
   } addOnFilureListener:^(MLLangDetectionException *exception) {
       // 失败处理逻辑
   }];
   ```
