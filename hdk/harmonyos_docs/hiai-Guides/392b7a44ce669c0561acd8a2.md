# 文本分类

通过对输入的文本进行分类，帮助定义文本适用场景。使用文本分类前，需要先借助[HMS ToolKit](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/installation-0000001050145206)工具生成满足实际需要的预置模型，再将一句或一段话通过训练好的预置模型推理到预定义的类别中。目前支持中文文本分类和英文文本分类。  

#### 实现方法

1. 选择自定义训练集来训练模型，训练方法请参见AI Create的[文本分类](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ai-create-0000001055252424#section422310265125)。
2. 模型训练完成后，可以对模型进行验证。 在"Add test image"的"Please select test image dateset"加入需要测试的图片资源即可。工具会自动对训练好的模型进行测试，并显示测试结果。

3. 训练模型结果确认可用后，选择生成Demo工程。

在模型训练结果中点击"Generate Demo"，HMS Toolkit会自动生成Demo工程，该工程自动集成了该训练后的文本分类识别模型，您可以直接运行和编译该Demo工程，生成APK文件在设备上运行，查看文本分类识别的应用效果。
