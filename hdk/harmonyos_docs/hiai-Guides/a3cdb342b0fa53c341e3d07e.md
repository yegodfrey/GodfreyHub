# 配置AndroidManifest.xml文件

如果targetSdkVersion是28或者更高版本，您需要在"AndroidManifest.xml"中manifest便签下添加以下配置，使应用可以下载模型。

```screen
<manifest ...>
    ...
    <application    
        ...    
        android:usesCleartextTraffic="true" >    
        ...
    </application>
        ...
</manifest>
```
