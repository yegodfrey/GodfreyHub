# 添加权限

完整地使用ML Kit SDK提供的服务需要获取一些系统的权限，只需要在Info.plist文件中添加相对应的权限即可。

|权限名称|||**CAMERA**|**INTERNET**|ACCESS_NETWORK_STATE|ACCESS_WIFI_STATE|**READ_EXTERNAL_STORAGE**|**WRITE_EXTERNAL_STORAGE**|
|:----|------|--|:-----------|:-----------|:-------------------|:----------------|:------------------------|:-------------------------|
|**用途**|||**通过相机获取图像**|**访问网络**|**获取网络状态**|**获取Wi-Fi状态**|**读取本地相册**|**升级算法版本**|
|图像类|拍照购物|云侧|√|√|√|-|-|-|
|图像类|图像分割|端侧|√|-|-|-|-|-|
|语音语言类|在线文本翻译|云侧|-|√|√|-|-|-|
|语音语言类|在线语种检测|云侧|-|√|√|-|-|-|

具体操作步骤如下：

```codeblock
<!-- 相册 -->  
<key>NSPhotoLibraryUsageDescription</key>  
<string>需要您的同意，APP才能访问相册</string> 
<key>NSPhotoLibraryAddUsageDescription</key>
<string>需要您的同意，APP才能保存图片到相册</string>
 <!-- 相机 -->  
<key>NSCameraUsageDescription</key>  
<string>需要您的同意，APP才能访问相机</string> 
```
