# 人脸比对

#### 服务介绍

人脸比对服务通过识别并提取模板中的人脸特征，将模板人像和人脸进行高精度比对，输出相似度值，进而判断两者是否为同一个人。  

#### 应用场景

人脸比对服务广泛应用于日常生活中的众多领域。例如，通过比对图库中的人脸，按照人脸相似度将相册中的人脸进行分类，便于用户查找相片和管理相册。在趣味人脸应用中，可以根据人脸相似度开发夫妻脸等有趣玩法。  

#### 注意事项

* 目前暂不支持比对年龄跨度过大，以及遮挡幅度相差30%以上的两张人脸。
* 若模板照片中包含多张人脸，则取最大的人脸为模板人像；若对比图像中有多张人脸，将按照人脸面积排序，取前3张人脸进行比对。
* 满足以下条件可达到最佳比对效果：  

  |场景|人脸暴露区域|光照环境|五官清晰度|人脸与镜头角度|
  |:-|:-----|:--------|:-------------|:------|
  |正常|2/3以上|正常光下|五官清晰|30度以内|
  |困难|1/2以上|强光、逆光、暗光下|至少一只眼睛可见、五官尚清晰|45度以内|

* 比对阈值：  

  |场景|误检率|召回率|阈值|
  |:-|:---|:-----|:-----|
  |正常|1%|0.9802|0.6830|
  |正常|0.1%|0.9104|0.7336|
  |困难|1%|0.9482|0.6727|
  |困难|0.1%|0.8370|0.7231|

* 暂不建议在安全认证场景中使用，如金融支付、手机解锁。

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/faceverify-sdk-0000001071768039)。

1. 创建人脸比对检测器实例。  

   ```
   "Java"
   MLFaceVerificationAnalyzer analyzer = MLFaceVerificationAnalyzerFactory.getInstance().getFaceVerificationAnalyzer();
   ```

   ```
   "Kotlin"
   var analyzer = MLFaceVerificationAnalyzerFactory.getInstance().getFaceVerificationAnalyzer()
   ```

2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象用于设置模版图片，支持的图片格式包括：jpg/jpeg/png/bmp。  

   ```
   "Java"
   // 通过bitmap创建MLFrame
   MLFrame templateFrame = MLFrame.fromBitmap(bitmap);
   ```

   ```
   "Kotlin"
   // 通过bitmap创建MLFrame
   var templateFrame = MLFrame.fromBitmap(bitmap)
   ```

3. 设置人脸比对模版图片。如果模板中无人脸，则表示模板设置失败，保持该实例上一次设置的模板不变。  

   ```
   "Java"
   List<MLFaceTemplateResult> results = analyzer.setTemplateFace(templateFrame);
   for (int i = 0; i < results.size(); i++) {
       // 处理模板图片识别结果
   }
   ```

   ```
   "Kotlin"
   val results = analyzer!!.setTemplateFace(templateFrame)
   for (i in results.indices) {
        // 处理模板图片识别结果
    }
   ```

4. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象用于设置比对图片，支持的图片格式包括：jpg/jpeg/png/bmp。  

   ```
   "Java"
   // 通过bitmap创建MLFrame
   MLFrame compareFrame = MLFrame.fromBitmap(bitmap);
   ```

   ```
   "Kotlin"
   // 通过bitmap创建MLFrame
   val compareFrame = MLFrame.fromBitmap(bitmap)
   ```

5. 调用同步或异步方法进行人脸比对。检测结果主要包括比对图片中检测到的人脸信息、检测到的人脸信息与模板人脸是同一个人的置信度。详细信息请参见[MLFaceVerificationResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlfaceverificationresult-0000001054103657)。
   * 异步方法示例代码：  

     ```
     "Java"
     Task<List<MLFaceVerificationResult>> task = analyzer.asyncAnalyseFrame(compareFrame);
     task.addOnSuccessListener(new OnSuccessListener<List<MLFaceVerificationResult>>() {
         @Override
         public void onSuccess(List<MLFaceVerificationResult> results) {
             // 检测成功
         }
     }).addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
             // 检测失败
         }
     });
     ```

     ```
     "Kotlin"
     val task = analyzer!!.asyncAnalyseFrame(compareFrame)
     task.addOnSuccessListener {
          // 检测成功
     }.addOnFailureListener {
          // 检测失败
      }
     ```

   * 同步方法示例代码：  

     ```
     "Java"
     SparseArray<MLFaceVerificationResult> results = analyzer.analyseFrame(compareFrame);
     for (int i = 0; i < results.size(); i++) {
         // 检测结果处理
     }
     ```

     ```
     "Kotlin"
     val results = analyzer!!.analyseFrame(compareFrame)
     for (i in 0 until results.size()) {
          // 检测结果处理
      }
     ```

6. 检测完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {
       analyzer.stop();
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        analyzer!!.stop()
   }
   ```
