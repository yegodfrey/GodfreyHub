# 合作案例：爱奇艺

业界端侧视频超分首次商用，CANN NPU硬件加速助力爱奇艺提供更优画质  

#### 爱奇艺简介

爱奇艺是国内领先的视频网站，自2010年4月22日正式上线以来，爱奇艺秉承"悦享品质"的宗旨，以"用户体验"为使命，通过持续不断的技术投入、产品创新，为用户提供清晰、流畅、界面友好的观影体验。  

#### 核心痛点

视频超分功能部署至端侧后可以为用户带来了良好的画质体验，但是端侧AI的部署也存在诸多难点：

* 模型的适配迁移难：用户使用机型太多，底层硬件架构差异大，模型适配部署需要耗费巨大的时间成本。
* 降低手机功耗与模型调优难：端侧超分模型对实时性要求较高，需要较高的计算量，这意味手机功耗会比较大，如何降低手机功耗、如何令模型以低功耗高性能运转，需要投入大量的人力成本。  

#### 解决方案

* 机型覆盖：华为手机有统一的硬件架构，能助力开发者一键接入，多端部署。同时，HUAWEI HiAI是面向智能终端的AI能力开放平台，其中的CANN能力不仅能为端侧AI模型提供算力加速，还能让开发者快速实现模型在端侧的调优部署。
* NPU加速，动作更流畅：借助CANN芯片加速能力，将已有的深度学习算法模型快速转化迁移到华为NPU（神经网络计算单元）进行加速，模型推理性能高于GPU和CPU，可以保证视频播放的实时性，有效解决吞帧、卡顿、不连贯的问题。
* 降低功耗，改善机身发热及耗电情况：华为NPU通过图融合的方式降低功耗，在有效降低手机耗电量，抑制机身发热发烫的同时，也得到极高的性能。

体验步骤：

在爱奇艺点开你想看的视频 → 点击右下角"高清"→ 打开最下方的"增强画质"开关。


#### 合作受益

爱奇艺App：

有效提升视频的画质质量，画质变清晰，视频整体画面更显精细，显著改善用户体验。

用户：

在较差的网络环境或者流量受限情况下，享受更清晰的画质，机身也不会发热。
