# 集成在线语种检测服务SDK

> 注意
>
> 在开发前，您需要将"MLLangDetection.framework"集成到您的Xcode开发环境中，SDK支持需要iOS 9.0以上（含9.0）版本。

## Pod导入SDK

1. 首先要确保已经安装了[Cocoapods](https://cocoapods.org/)（可通过终端输入指令：**pod --version**确认是否安装成功）。

2. 在终端输入指令：**cd**，进入到项目的根目录下，如下所示：

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172413.10369431088202270744764348580540:50001231000000:2800:E7752AEADF3A11B79EDEB849D68DF11E827D07CF06046E893CD25256509FBC32.png "点击放大")
3. 执行成功后，会在项目的目录下生成Podfile文件，需要在此文件中添加以下内容：

   ```screen
   pod 'MLLangDetection', '~>2.0.5.300'
   ```

4. 终端执行以下命令：**pod install** 说明
   >
   > 如果已经执行过**pod install** 命令，可以直接执行**pod update**命令。
5. 等待执行成功后，打开工程目录，找到.xcworkspace文件，用Xcode打开，运行工程。

## 手动导入SDK

1. 下载HMS Core SDK，并解压zip包。

   下载地址：[SDK下载（手动方式集成）](https://developer.huawei.com/consumer/cn/doc/hiai-Library/ios-sdk-download-manual-0000001059289747)。
2. 在Xcode工程内右键选择"Add file to "MLTranslateDemo"..."(MLTranslateDemo工程名)，同时"Destination"选项需要勾选"Copy items if needed"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172413.26693043104827542181393126575947:50001231000000:2800:0359B186D2918D52E16110FB4EEEF824D3D4D7941F305EEEBC801FDCBD380A5B.png "点击放大")

   点击"Add"即可完成SDK的添加
3. 点击"TARGETS"下工程名，如：MLTranslateDemo，并选择"Build Phases"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172413.84912901510313263970923244039612:50001231000000:2800:2158074AC7DB05D86BAE3EB34F1CA42E0D77BBAE7FED4A00B415EA41D95A0270.png "点击放大")
4. 点击"TARGETS"下工程名，如：TranslateDemo，选择"Gereral"后，在"Framework,Libraries,and Embedded Content"中，将MLLangDetection.framework的"Embed"设置为"Embed & sign"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172413.48763777087481105826199601944818:50001231000000:2800:64B37C39EEB2B381189C45EB529B99CC39867EB824532DCF4E3A670172D2B660.png "点击放大")
5. 选择"Build Setting"后，在Build Options中将"Enable Bitcode"设置为"NO""。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172414.35123165567705084377605161081549:50001231000000:2800:614B6DE6BC2A01A54981D3F5AB30558CBFB566FED131C9E4A947D55E4A387F22.png "点击放大")
