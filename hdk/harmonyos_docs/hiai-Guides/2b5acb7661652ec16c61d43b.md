# 支持的平台

## CANN版本获取方法

### Android版本获取方法

您可以使用以下两种方法获取CANN Version版本号。

* 方法1：通过Android原生命令。
  * adb命令

    如果您的手机终端直接连接在PC上，可以使用以下命令，并从输出的列表中查找ro.vendor.hiaiversion属性。

    ```screen
    adb shell getprop
    ```

  * __system_property_get接口

    如果需要在App执行过程中识别终端属性，可以参考如下示例代码：

    ```screen
        char ro_vonder_hiaiversion[150] = { 0 };
        __system_property_get("ro.vendor.hiaiversion", ro_vendor_hiaiversion);
        ALOGI("ro_vendor_hiaiversion : %s ", ro_vendor_hiaiversion);
    ```

* 方法2：通过CANN开放接口，具体请参见[GetVersion](https://developer.huawei.com/consumer/cn/doc/hiai-References/getversion-0000001051650680)。

### HarmonyOS版本获取方法

* 方法1：通过hdc原生命令。
  * hdc命令

    如果您的手机终端直接连接在PC上，可以使用以下命令，并从输出的列表中查找const.hiai.vendor.hiaiversion属性。

    ```screen
    param get | grep "const.hiai.vendor.hiaiversion"
    ```

  * HarmonyOS NEXT SDK HMS_HiAI_GetVersion接口

    如果需要在App执行过程中识别终端属性，可以参考如下示例代码：

    ```screen
    #include "CANNKit/hiai_helper.h"
    const char* version = HMS_HiAI_GetVersion();
    OH_LOG_INFO(LOG_APP, "hiai version:%{public}s", version);
    ```

* 方法2：通过CANN开放接口，具体请参见[GetVersion](https://developer.huawei.com/consumer/cn/doc/hiai-References/getversion-0000001051650680)。
