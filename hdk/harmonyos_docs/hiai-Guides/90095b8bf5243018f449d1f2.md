# 合作案例：WPS

HUAWEI HiAI文档检测校正，WPS开拓手机办公的智能密匙  

#### WPS简介

WPS APP是一款办公软件应用，可实现文字、表格、演示等多种常用办公文档的编辑和查看，同时支持用户使用免费云空间及文档模板。  

#### 核心痛点

随着移动终端的兴起与发展，手机越来越多的应用于编辑文档、收发邮件等办公场景。然而，由于没有键盘、鼠标等大神器的辅助，只能通过手指在屏幕滑动完成操作，手机办公效率极低。比如，上课或参加会议、培训时，看到PPT上的要点和干货，我们会立刻拿出手机拍照记录，但拍摄的图片往往有以下几个问题，导致将其整理为PPT时，还需导出手机在电脑上裁剪处理，相当繁琐耗时：

景物干扰：用户拍摄的图片中，除了PPT文档，通常还会有屏幕、墙面、桌椅等其他景物，需做裁剪处理才能使用。

文档变形：当拍摄角度没有正对文档时，文档成像就会有不同程度的变形，被拉伸或被压缩的图像都会影响后续使用。

画质模糊：受光线、距离等因素影响，用户拍摄的图片可能会模糊不清，影响观感和信息辨识度。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250429142006.96586643163524396455493907628448:50001231000000:2800:6DF312954CAF4B8FF0B373953E39AE5D4E55D65AF2D421D8C6DFD5C3546FE418.png "点击放大")

内容无法编辑：另一方面，许多用户在查看拍摄的PPT图片时，或多或少都有编辑修改PPT内容的需求，然而图片内容不能直接编辑，无法满足用户需求。  

#### 解决方案

WPS通过接入HUAWEI HiAI生态，配合以华为Kirin970强劲性能加持，仅需3秒，就能实现多张图片一键生成PPT，轻松解决上述问题：

文档感知，自动识别文档有效区域： 引入HUAWEI HiAI Engine文档检测校正能力后，WPS可以精准识别感知文档所在区域，并自动裁剪滤除屏幕、墙面、桌椅等其他景物。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250429142006.83699733098288689760948479910731:50001231000000:2800:140B368F9297B15F7802E81B2C89CBCA7C03635A4604AD9641587A8E66AE3C0E.png "点击放大")

文档校正，快速调整至正中视角： 这是一项文档翻拍过程的辅助增强功能，能够自动将拍摄视角调整到正对文档的角度上，最大校正角度达45度。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250429142007.83654977095901979727680046225061:50001231000000:2800:4AA8BAD327D2EA56D0BAF9BAD13EBB33A8857BEA266FF1C9034BDF4396F3373F.png "点击放大")

文字超分，使文档内文字更清晰： 同时，HUAWEI HiAI将对包含文字内容的图像进行9倍分辨率放大（高宽各放大3倍），从而显著提升画质清晰度、增强文字可辨识度。

OCR识别，自由编辑图片中文字内容：此外，通过接入通用OCR，可自动识别并提取图片中文字信息，实现自由修改、剪切、复制、删除PPT图片中的文字内容。
