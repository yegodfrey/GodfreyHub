# 业务介绍

## 业务简介

人体骨骼关键点对于描述人体姿态，预测人体行为至关重要。因此人体骨骼关键点检测是诸多计算机视觉任务的基础，例如动作分类，异常行为检测，以及自动驾驶等等。近年来，随着深度学习技术的发展，人体骨骼关键点检测效果不断提升，已经开始广泛应用于计算机视觉的相关领域。

人体骨骼关键点检测即Pose Estimation，主要检测人体的一些关键点，通过关键点描述人体骨骼信息。

## 场景介绍

人体骨骼关键点检测是计算机视觉的基础性算法之一，在计算机视觉的其他相关领域的研究中都起到了基础性的作用，如行为识别、人物跟踪、步态识别等相关领域。具体应用主要集中在智能视频监控，病人监护系统，人机交互，虚拟现实，人体动画，智能家居，智能安防，运动员辅助训练等等。

## 功能特点

用户输入单张内容为人像的图片，可得到图片中每一个人身体上14个关键点的坐标信息。算法实时性高，可在70ms内返回结果。结果中人体姿态信息包括：头、颈、左右肩，左右肘、左右手腕、左右髋、左右膝、左右脚踝。
