# 合作案例：小艾助视器

HUAWEI HiAI联合小艾助视器，为低视力群体还原清晰"视"界  

#### 小艾助视器简介

小艾助视器是由小艾帮帮和华为联合开发的一款低视力辅助工具移动应用，旨在通过提高文字的对比度以改善清晰度，帮助低视力患者解决日常文字阅读困难，以便携性、应用性、较低成本等优点惠及更多低视力群体。正在研发中的小艾助视器课堂版，可对课堂黑板讲义进行拍摄并投放至大屏华为设备上，将帮助低视力学生顺利参与课堂学习。  

#### 核心痛点

低视力是指手术、药物或一般验光配镜无法改善的视功能障碍。低视力患者通常需要通过助视器一类辅助工具才可以完成日常文字阅读需要，然而，传统的高级电子助视器售价还可高达上万元，高昂的价格常常令大多低视力家庭望而却步。在中国，低视力人群已超过800万，14岁以下发病率达0.43%，低视力孩童即使坐在第一排也无法看清黑板，难以适应普通学校的课堂学习，对个人未来发展极为不利。

近年来，移动设备在计算机视觉、光学变焦的技术突破，给助视器移动应用的开发带来曙光。助视器软件面世使低视力人群的选择多样化，高速发展的人工智能技术也更有望开放更多超越传统助视器的功能，如文字语音播报、课堂学习等功能。目前，由于市面上终端软硬件的各种限制，助视器应用在开发时通常面对如下技术痛点：

受限于网络状况：提升文字清晰度的前提是文字识别。如今，大多应用的文字识别算法都是借助云服务器实现，在一些网络状况较差的偏远地区，手机应用就难以完成文字清晰度的提升。

设备光学变焦能力：在我国，教室规模在各个教育阶段不尽相同，从十几人的小课室到可容纳几百人的大讲堂应有尽有。因此，正在开发中的小艾助视器课堂版，必须考虑设备光学变焦能力，以便清晰拍摄长距离黑板讲义，应用于规模较大的教室场景。  

#### 解决方案

HUAWEI HiAI开放通用文字识别API，赋能小艾助视器开发团队一键解决以上技术问题，助力应用功能快速开发：

识别稳定快速，视野更清晰：接入HUAWEI HiAI通用文字识别API，小艾助视器离线即可完成文字识别，不再受限于网络状况，支持更稳定快速的文字识别放大、以及文字语音播报功能，为用户提供听觉和视觉两种有效辅助，让低视力群体看得更清。

将传统的助视器功能"装"进手机：HUAWEI HiAI通用文字识别AI能力将助视器"装"进手机，一款手机应用即可涵盖传统高级电子助视器功能，用更低价格带来阅读辅助工具，硬件购买成本更低、携带更方便。

#### 合作受益

小艾助视器：

一键调用通用文字识别AI能力，节省算法开发时间和成本，在手机快速实现助视器功能落地。

用户：

只需一台手机即可满足视力辅助功能，携带更方便；文字识别放大不受网络影响，稳定性更好，适用性更广。小艾助视器应用落地，以更低的价格将传统的高级电子助视器功能带入万千低视力家庭，而课堂版更是有望帮助低视力群体打破教育壁垒，让他们看见更多选择、更多希望。

在发展人工智能和终端多媒体技术的路上，华为始终坚持寻找同路人，实现超越传统电子助视器的功能体验，将技术造福万千低视力人士。
