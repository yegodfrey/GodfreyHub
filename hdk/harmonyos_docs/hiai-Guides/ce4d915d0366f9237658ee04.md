# 开发指南

#### 应用开发

#### 必须导入类

1. 在使用美学评分API时，将实现美学评分的相关的类添加至工程。

   ```
   import com.huawei.hiai.vision.visionkit.common.Frame; // 加载Frame类
   import com.huawei.hiai.vision.visionkit.common.Video; // 加载Video类
   import com.huawei.hiai.vision.visionkit.image.detector.AestheticsScore; // 加载审美引擎结果类
   import com.huawei.hiai.vision.image.detector.AestheticsScoreDetector; // 加载审美引擎detector类
   import com.huawei.hiai.vision.common.VisionBase; // 加载连接服务的静态类
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
   import com.huawei.hiai.vision.visionkit.image.detector.AEVideoResult; // 加载审美引擎视频结果类
   import com.huawei.hiai.vision.visionkit.image.detector.AEModelConfiguration;
   import com.google.gson.Gson;
   ```

#### 开发

1. 应用VisionBase静态类进行初始化，拿到服务连接的结果。

   ```
   VisionBase.init(mContext, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. 定义aestheticsScoreDetector实例，将此应用的Context当做入参。

   ```
   AestheticsScoreDetector aestheticsScoreDetector = new AestheticsScoreDetector(mContext);
   ```

3. 配置引擎参数（不配置取默认参数，启用全部模型，1开启OSP_MODE，2开启HF_MODE，3开启全部）。

   ```
   AEModelConfiguration aeModelConfiguration = new AEModelConfiguration();
   aeModelConfiguration.getDetetcImageConf().setDetectImageMode(3)
   aestheticsScoreDetector.setAEModelConfiguration(aeModelConfiguration);
   ```

4. 定义VisionImage。

   ```
   VisionImage image= null;
   ```

5. 将需进行美学评分图像的bitmap放入image中。

   ```
   image = VisionImage.fromBitmap(bitmap);
   ```

6. 定义图片美学评分结果AestheticsScore。

   ```
   AestheticsScore outputData = new AestheticsScore();
   ```

7. 调用detectImage()得到图片美学评分。

   ```
   int resultCode = mAestheticsScoreDetector.detectImage(image, outputData, null);
   ```

8. 通过getScore()方法拿到分数。

   ```
   float score = aestheticsScores.getScore();
   ```

9. 通过getFrameTimeStamp()方法拿到时间。

   ```
   float timeStamp = aestheticsScores.getFrameTimeStamp();
   ```

10. 通过getOSPScores()方法拿到子维度分数。

    ```
    float ospScore = aestheticsScores.getOSPScores();
    ```

11. 通过getHFSCore()方法拿到子维度分数。

    ```
    float hfScore = aestheticsScores.getHFSCore();
    ```
