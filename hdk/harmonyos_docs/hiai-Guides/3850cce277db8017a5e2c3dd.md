# 合作案例：亮亮视野

HUAWEI HiAI Engine语音技术助力亮亮视野： 改写交互规则，重构沟通方式  

#### 亮亮视野简介

亮亮视野作为一家专注于AI+AR领域的科技公司，致力于通过第一视角交互技术改变人与万物的沟通方式，提供相关硬件产品及软件服务，如智能AR眼镜等，现已为医疗、工业、安防等多个行业提供了智能解决方案，赋能企业数字化升级。  

#### 核心痛点

5G网络在万众瞩目下问世，与日新月异的大数据和人工智能技术齐头并进，使越来越多的便携设备有望获得感知能力，成为我们的工作与生活的智慧助手。其中，智能眼镜以其便携性、实用性和视觉技术受到广泛关注，发展前景令人翘首以盼。

随着亮亮视野业务的不断拓展和应用场景日益增多，现场噪音过多、网络状况不佳等外部问题日益凸显，因此，客户对智能眼镜的协同交互提出了更高的要求：如更高精度的语音技术、更快更准的文字识别等，这无疑需要对智能眼镜进行软硬件双重升级。

对于亮亮视野开发团队而言，智能眼镜升级的核心痛点主要如下：

方案成本增加：新增的功能需求意味着需要多种集成多种AI能力，从云端调用时将产生费用，导致方案成本增加。

舒适度与性能的较量：亮亮视野智能眼镜作为头戴式工作设备，使用者需要长时间佩戴，轻量化技术是保证佩戴舒适度的前提，但也为硬件升级设下障碍，是体验优化所面临的又一道新关卡。

公网授权管理难：亮亮视野拥有庞大的企业客户群体，信息安全问题是关键，而调用云端AI能力时，需要获得企业信息的公网授权，无疑为企业信息安全提出了新的挑战。  

#### 解决方案

亮亮视野现已接入HUAWEI HiAI语音技术，为用户带来性能升级：只需通过USB线将智能眼镜连接至华为手机，即可在亮亮企服平台上使用语音转文字功能，还可以在视频中精确标记录入的时间点和关键帧，在手机上回放查看。

HUAWEI HiAI作为面向智能终端的AI能力开放平台，助力亮亮视野一并解决方案成本、舒适度与性能、和授权管理等开发难题：

免费本地调用，降低成本：HUAWEI HiAI平台为开发者提供一站式解决方案、开放丰富的端侧AI能力，功能开发无需诉诸多个平台，免除各种许可证申请费用。开发者可以免费从华为终端本地离线调用HUAWEI HiAI能力，无需云服务器费用，零成本实现飞跃式的性能升级。

既保障舒适度，又提升性能：只需将智能眼镜连接华为NPU设备，即可调用精度、抗噪音水准高的HUAWEI HiAI Engine语音识别能力，性能优化无需增加重量负担。

端侧运行，信息安全更有保障：基于华为NPU的强大算力，HUAWEI HiAI Engine能力可以在设备端侧快速完成计算，数据无需上传公共网络，从根源上保障企业用户的信息安全。
