# 配置混淆脚本

如果您在编译APK时需要配置混淆文件，为了避免混淆HMS Core SDK导致功能异常，请按如下操作进行：

1. 在应用级根目录下打开混淆配置文件"proguard-rules.pro"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172254.40326973983236768366593551701879:50001231000000:2800:3A151D641AAC34ADA0F3558347C39CA3988F5BBD0A11B3D8C482FA6C4AE601EF.png)
2. 加入排除HMS Core SDK的混淆配置。

   ```
   -ignorewarnings
   -keepattributes *Annotation*
   -keepattributes Exceptions
   -keepattributes InnerClasses
   -keepattributes Signature
   -keepattributes SourceFile,LineNumberTable
   -keep class com.huawei.hianalytics.**{*;}
   -keep class com.huawei.updatesdk.**{*;}
   -keep class com.huawei.hms.**{*;}
   ```

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172254.29994976735255141514257800884724:50001231000000:2800:98DA3FED196BD4843E377E5A666679F564E7FB283EA533A37B0DA9E6120D8AE5.png)  
   1. 若您需要集成离线语音合成服务，请在加入以上脚本后再配置如下内容：

      ```
      -dontwarn com.huawei.**
      -keep class com.huawei.** {*;}
      -dontwarn org.slf4j.**
      -keep class org.slf4j.** {*;}
      -dontwarn org.springframework.**
      -keep class org.springframework.** {*;}
      -dontwarn com.fasterxml.jackson.**
      -keep class com.fasterxml.jackson.** {*;}
      ```

   2. 若您需要集成离线翻译服务，请在加入以上脚本后再配置如下内容：

      ```
      -keep class com.huawei.noah.bolttranslator.**{*;}
      ```

   3. 若您需要集成声音识别FullSDK，请在加入以上脚本后再配置如下内容：

      ```
      -dontwarn com.huawei.hisi.**
      -keep class com.huawei.hisi.** {*;}
      ```

   4. 若您需要集成动作活体检测FullSDK，请在加入以上脚本后再配置如下内容：

      ```
      -keep class huawei.MlInteractiveLiveness
      ```

3. 如果您使用了AndResGuard，需要在应用级的"build.gradle"文件中加入AndResGuard允许清单。

   ```
   "R.string.hms*",          
   "R.string.connect_server_fail_prompt_toast",          
   "R.string.getting_message_fail_prompt_toast",           
   "R.string.no_available_network_prompt_toast",
   "R.string.third_app_*",          
   "R.string.upsdk_*",   
   "R.layout.hms*",
   "R.layout.upsdk_*",          
   "R.drawable.upsdk*",         
   "R.color.upsdk*",      
   "R.dimen.upsdk*",     
   "R.style.upsdk*",
   "R.string.agc*"
   ```

4. 当您启用R8资源缩减（项目级"build.gradle"文件中"shrinkResources"属性为"true"）和严格引用检查（"res/raw/keep.xml"文件中的"shrinkMode"为"strict"）时，请您配置"keep.xml"文件手动保留layout资源，确保应用正常通过华为应用市场上架审核。

   ```
   <?xml version="1.0" encoding="utf-8"?>
   <resources xmlns:tools="http://schemas.android.com/tools"
       tools:keep="@layout/hms_download_progress,@drawable/screen_off"
       tools:shrinkMode="strict" />
   ```
