# 集成身份证识别服务SDK

身份证识别服务支持Full SDK和基础SDK两种集成方式，您可以参见[Full SDK和基础SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-sdk-0000001051070278#ZH-CN_TOPIC_0000001051070278__li65649285438)，根据您的应用场景选择不同的集成方式。
> 注意
>
> * 若您的应用同时集成了ML Kit提供的多个服务（[ML Kit服务列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-sdk-0000001051070278#ZH-CN_TOPIC_0000001051070278__li1842231414318)），可能会出现编译问题，您需要参见[升级指南](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/upgrade-guide-0000001050038074)将您集成的其他服务升级到最新版本。
> * 若您的应用需要同时集成ML Kit提供的中国第二代居民身份证识别能力和越南身份证识别能力，您需要注意以下内容：
>   * 您需要将中国第二代居民身份证识别能力的版本号升级为2.0.3.303及以上。
>   * 若您是以Full SDK方式集成了中国第二代居民身份证识别能力，那么您需要同样以Full SDK方式集成越南身份证识别能力。

## 方式一：Full SDK方式集成（推荐使用）

将身份证模型与身份证识别插件集成为一个包，信息如下：

|包类型|包名|SDK大小|坐标名称|
|:--------------|:----------------------|:----|:-----------------------------------------------|
|中国第二代居民身份证模型+插件|ml-computer-card-icr-cn|3.87M|com.huawei.hms:ml-computer-card-icr-cn:3.7.0.303|
|越南身份证模型+插件|ml-computer-card-icr-vn|3.98M|com.huawei.hms:ml-computer-card-icr-vn:3.7.0.303|

Full SDK方式集成身份证识别插件的示例代码如下：

* 中国第二代身份证示例代码如下：

  ```codeblock
  dependencies{
      // 引入身份证plugin与识别能力集合包。
      implementation 'com.huawei.hms:ml-computer-card-icr-cn:3.7.0.303'
  }
  ```

* 越南身份证示例代码如下：

  ```codeblock
  dependencies{
      // 引入身份证plugin与识别能力集合包。
      implementation 'com.huawei.hms:ml-computer-card-icr-vn:3.7.0.303'
  }
  ```

## 方式二：基础SDK方式集成

示例代码如下：

* 中国二代身份证示例代码如下：

  ```codeblock
  dependencies{
      // 引入身份证识别plugin包。
      implementation 'com.huawei.hms:ml-computer-card-icr-cn-plugin:3.11.0.301'
  }
  ```

* 越南身份证识别示例代码如下：

  ```codeblock
  dependencies{
      // 引入身份证识别plugin包。
      implementation 'com.huawei.hms:ml-computer-card-icr-vn-plugin:3.7.0.303'
  }
  ```

## 添加AGCP插件配置

用上述两种方式之一集成SDK后，请根据实际情况选择添加AGCP插件配置：

* 方式一：在文件头部声明下一行添加如下配置。

  ```screen
  apply plugin: 'com.huawei.agconnect'
  ```

* 方式二：在**plugins** 中添加如下配置。

  ```screen
  plugins {
      id 'com.android.application'
      // 添加如下配置
      id 'com.huawei.agconnect'
  }
  ```

## 自动更新机器学习模型

添加如下语句到AndroidManifest.xml文件中，用户从华为应用市场安装您的应用后，将自动更新机器学习模型到设备：

```codeblock
<manifest
    ...
    <meta-data
        android:name="com.huawei.hms.ml.DEPENDENCY"
        android:value= "icr"/>
    ...
</manifest>
```
