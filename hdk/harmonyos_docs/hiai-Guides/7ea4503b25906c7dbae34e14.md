# 随时随地一拍即购：HUAWEI ML Kit助力Banggood打造拍照购物服务

#### Banggood简介

Banggood是一款全品类在线购物App，由专注于跨境贸易B2C电子商务的棒谷科技股份有限公司出品，注册用户遍及全球200多个国家，日访问量超过950万。Banggood App作为B2C综合网上购物平台，为用户提供涵盖电子产品、手机、工具、日用品、服饰、箱包等在内的500多个品类商品，旨在让用户以最优惠的价格享受优质的产品和服务。  

#### 业务挑战

随着大数据、人工智能新技术的兴起，越来越多的个人、企业以互联网为依托，实现线上、线下购物一体化；商品的生产、流通与销售过程悄然升级改造，业态结构与生态圈也在不断重塑；满足消费者随时随地甄别和购买商品的诉求越来越迫切。

* 如何实现线下线上购物相结合：在社交媒体看到好友的衣服推荐，觉得很好看，希望能够通过图片搜索到同款；在线下零售店遇见心仪的箱包，想看下线上是否有优惠折扣。拍照购服务越来越成为各大电商争夺用户流量的入口，通过拍照或传入图片即可快速搜索出同款或相似的商品呈现给消费者，实现线下线上购物相结合。
* 自建拍照购服务难度大，成本高：自建一套满足上面诉求的拍照购物服务，需要对海量图片进行数据标注、AI模型开发与训练，以及全球化的云服务部署和计算资源保障。  

#### 解决方案

* 开发成本低，快速上线：Banggood和HUAWEI ML Kit深度合作，通过在手机端集成ML Kit SDK，即可快速构建拍照购物服务。
* 服务全球覆盖：ML Kit云侧服务全球覆盖，为Banggood遍及全球200多个国家的用户提供直达服务。
* 机型广覆盖：HUAWEI ML Kit支持华为及非华为手机，Banggood一次集成，即可覆盖市面上所有安卓系统机型。
