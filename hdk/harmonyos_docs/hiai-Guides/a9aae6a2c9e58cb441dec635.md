# 业务介绍

## 业务简介

通用文字识别核心即为光学字符识别（Optical Character Recognition，OCR）技术，在端侧为手机截屏和相机拍照的图片，提供快捷的文字提取功能。当前端侧通用文字识别能力接口能支持相机拍照和手机截屏两类图片。针对相机拍照的图片类型的能力我们能在一定程度上支持文本倾斜，拍摄角度倾斜，复杂光照条件，以及复杂文本背景等场景，可用于文档翻拍，街景翻拍等图片的文字检测和识别。适用范围广，抗干扰能力强。针对手机截屏的图片类型，在端侧为手机截屏图片提供轻便快捷的文字提取功能，便于后续处理以及服务对接，如：拷贝、编辑、分词、语义分析等。

## 功能特点

* **相机拍照的图片类型：**目前，支持中文、英文、日语、韩语、俄语、意大利语、西班牙语、葡萄牙语、德语，以及法语的文本区域检测、文本内容识别功能，支持多种印刷字体；支持场景较为广泛，并且在有复杂光照、复杂背景以及其它干扰的情况下，仍能保证较高的识别准确率，提供了有效的文本区域检测、文本内容识别能力。
* **手机截屏的图片类型：**结合手机截屏的特点，优化文字提取的算法。针对手机截屏的图片类型，目前支持中英文识别，在国内版本开放。
* **通用OCR特点：**
  * 轻便：利用本API，可以大大节省算法开发的时间，节省算法模型占用的ROM空间，让您的应用更加轻便。
  * 自定义层次结果返回：根据应用的需要，可以返回截屏中文本块(block)、文本行(line)、文字字符(char)的坐标。

### 功能使用限制

|功能|使用限制说明|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|输入图片大小|* 手机截屏的图片目前支持尺寸为：width最大为1440px，height最大为15210px。图片大小超出范围，文字检测识别，会返回错误码200。手机截屏OCR目前仅支持中文和英文识别。 * 相机拍照的图片建议尺寸为：分辨率大于720p，长边短边比小于2:1，当输入图像为非建议图片尺寸时，文字识别的准确度可能会受到影响。|
|多线程调用|HUAWEI HiAI Engine不支持同一应用使用多线程调用同一接口，这样会导致某一线程调用release方法卸载模型后，引起正在运行的另一线程出错。事实上，由于后台服务也是排队执行多任务，所以多线程执行同一功能达不到并行的效果。另外，引擎支持使用多线程调用不同接口，如开启两个线程同时使用手机截屏OCR和人脸检测接口。|
|应用程序位数限制|通用文字识别接口当前仅支持64位应用程序调用。|
