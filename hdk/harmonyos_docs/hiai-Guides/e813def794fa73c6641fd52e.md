# 业务介绍

#### 业务简介

IM类意图识别是指利用机器学习技术对用户短信或聊天类应用（微信、QQ等）的文本消息进行意图分析和识别。

基于语义分析，可以利用机器学习相关的技术识别并理解用户消息的意图，通过IM类意图识别，可以衍生出各种智能的应用场景，使智能设备更智能，智慧。本API提供了一个智能识别用户短信或聊天类APP文本消息的意图接口，通过该API可以对文本消息的意图进行自动分析识别，目前仅开放支持了通知消息类的三个意图，分别为：还款提醒通知、还款成功通知、未接来电通知。  

#### 场景介绍

* 生成智能卡片：可以应用于生成智能卡片，比如：生成未接来电通知卡片。当用户由于某种原因导致未接通呼叫方的电话，电信运营商或服务提供商会给用户发短信提醒，当用户接收到短信提醒，此时就可以识别出未接来电通知意图，并可以分析出呼叫方电话号码和呼叫时间，并生成智能卡片，方便用户查看。

* 生成下拉pad屏：可以应用于开发下拉pad屏，识别用户消息文本的意图，生成下拉pad屏，可以显示重要的信息，方便用户随时查看。  

#### 功能特点

* 智能：能识别用户消息文本的各种意图，可以应用到各种场景，让设备更智能、更懂用户。
* 轻便：可以大大节省算法开发的时间，节省算法模型占用的ROM空间，让您的应用更加轻便。

#### 功能使用限制

|功能|使用限制说明|
|:-----|:------------------------------------------------------------------------------------------------------------------|
|输入文本长度|IM类意图识别文本限制在500字以内，超过字数将返回参数错误，文本要UTF-8格式，格式错误的不报错，但分析结果会不准确。|
|多线程调用|HUAWEI HiAI Engine支持多用户同时接入，但是不支持同一用户并发调用同一个特性，如同一个特性被同一进程同一时间多次调用，则返回系统忙错误，不同进程调用同一特性，则同一时间只有一个进程业务在处理，其他进程进入队列排队。|
