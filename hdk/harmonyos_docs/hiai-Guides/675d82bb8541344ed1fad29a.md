# 集成拍照购物服务SDK

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172414.31826934757581200885890204329010:50001231000000:2800:FE75DD72200C7DD074D42F6A3AADEDCE37D725D922EE6BB04524BAE50C4325D0.png)  
在开发前，您需要将"MLProductVisionSearch.framework"集成到您的Xcode开发环境中，SDK支持需要iOS 9.0以上（含9.0）版本。  

#### Pod导入SDK

1. 首先要确保已经安装了[Cocoapods](https://cocoapods.org)（可通过终端输入指令：pod --version确认是否安装成功）。
2. 在终端输入指令：cd ，进入到项目的根目录下，如下所示： ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172414.91631116197933516101182407377855:50001231000000:2800:77A5D13053FB561D2E714D2CAAC7BDE822885241D042119070B749D3264E06F6.png "点击放大")

   接着终端执行命令：pod init
3. 执行成功后，会在项目的目录下生成Podfile文件，然后在生成的Podfile文件中添加当前版本号，如：

   ```
   pod 'MLProductVisionSearch', '~>2.2.0.300'
   ```

4. 终端执行以下命令：pod install  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172414.18294969898706404253058961039579:50001231000000:2800:9FDD4EB17EFE5FBB14F139C7AECBC531196965D00FAC5811138F7C1B614E132F.png)  
   如果已经执行过pod install命令，可以直接执行pod update命令。
5. 等待执行成功后，打开工程目录，找到.xcworkspace文件，用Xcode打开，运行工程。  

#### 手动导入SDK

1. 下载HMS Core SDK，并解压zip包。 下载地址：[SDK下载（手动方式集成）](https://developer.huawei.com/consumer/cn/doc/hiai-Library/ios-sdk-download-manual-0000001059289747)。

2. 在项目工程的路径下新建一个SDK文件夹（文件名可根据需要自行更改），将解压的文件"MLProductVisionSearch.framework"放入此文件夹下： ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172414.80291341072287939314701654370095:50001231000000:2800:0646D652BAAFF1C53D16D263A60B7723C9D6F366220DF052310ED5E50497DE76.png "点击放大")

   1. 在Xcode工程内右键选择"Add file to "MLProductVisualSearchDemo"..."(MLProductVisualSearchDemo工程名)，同时"Destination"选项需要勾选"Copy items if needed"：

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172414.40430840192503342642721741944536:50001231000000:2800:D8B8F7FBF5F9C86AB4E6B411F166277B3D5A8308FDD1AD2CBA2CC644D06C4783.png "点击放大")
   2. 点击"Add"即可完成SDK的添加。
3. 点击"TARGETS"下工程名，如：MLProductVisualSearchDemo，并选择"Build Phases"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172414.01224211445662797396479633183881:50001231000000:2800:8A39825968BB762C1AFB3CEA9A257B0A7BDB2391085005C5838A307025B7EAD8.png "点击放大")
4. 点击+，选择"New Copy Files Phase"。
5. 在"Copy Files"区域的"Name"中点击+添加".framework"，"Destination"选择"Frameworks"。
