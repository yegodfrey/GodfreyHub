# 业务介绍

#### 业务简介

文档转换提供文档图片转换为文档的能力，应用可以方便的使用接口将文档图片转换为文档（如PPT）。此接口可识别出文档，并将其中的文字识别出来，识别的文档和文字均会返回给客户端，客户端可根据这些信息还原成ppt格式。  

#### 场景介绍

文档图片再编辑和整理存档，用户痛点描述：

* 发布会、交流会拍摄的文档图片或纸质文档手动整理繁琐、文档图片文本内容引用或再编辑优化人工输入低效。
* 开发者需详细理解多个原子化能力进行引用编排，才能完成文档转换，同时容易导致体验上割裂，操作步长过长的问题。  

#### 功能特点

开发者可以只调用一个接口，获取文档检测、矫正，文字超分，OCR的检测结果，方便快捷。
