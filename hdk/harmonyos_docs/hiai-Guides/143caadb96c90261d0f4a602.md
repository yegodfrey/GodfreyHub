# 开发指南

## 应用开发

### 必须导入类

1. 在使用模板OCR API时，将相关的模板OCR的类添加至工程。

   ```screen
   import com.huawei.hiai.pdk.resultcode.HwHiAIResultCode; // 加载引擎状态类
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
   import com.huawei.hiai.vision.common.VisionBase;  // 加载连接服务的静态类
   import com.huawei.hiai.vision.common.VisionImage; // 加载VisionImage类
   import com.huawei.hiai.vision.text.TemplateDetector; // 加载卡证检测类
   import com.huawei.hiai.vision.visionkit.text.config.VisionCardConfiguration;// 加载配置类
   import com.huawei.hiai.vision.visionkit.text.templateocr.TemplateData; // 加载返回结果类
   import com.huawei.hiai.vision.visionkit.text.templateocr.TemplateText;// 加载返回结果类中的成员变量类
   ```

### 开发

1. 应用VisionBase静态类进行初始化，异步获取服务的连接。

   ```screen
   VisionBase.init(MainActivity.this, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. 定义TemplateDetector实例，将此应用的Context当做入参。

   ```screen
   TemplateDetector mTemplateDetector = new TemplateDetector(MainActivity.this);
   ```

3. 定义调用配置项。

   ```screen
   VisionCardConfiguration visionCardConfiguration = new VisionCardConfiguration.Builder()
       .setAppType(VisionCardConfiguration.APP_NORMAL)
       .setProcessMode(VisionCardConfiguration.MODE_IN)
       .setCardType(VisionCardConfiguration.TEMPLATE).build();
   mTemplateDetector.setVisionConfiguration(visionCardConfiguration);
   ```

4. 加载引擎。

   ```screen
   int resultCode = mTemplateDetector.prepare();
   ```

5. 自行准备识别图片bitmap和模板templateJson。
6. 定义VisionImage，并将需进行检测图片的bitmap放入VisionImage中。

   ```screen
   VisionImage image = VisionImage.fromBitmap(bitmap);
   ```

7. 定义结果类。

   ```screen
   TemplateText templateText = new TemplateText();
   ```

8. 调用TemplateDetector的detectTemplate的方法，获取结果。

   ```screen
   int resultCode = mTemplateDetector.detectTemplate(image, templateJson, templateText, null);
   ```

   * 可以直接使用结果类获取识别结果。

     ```screen
     if (resultCode == HwHiAIResultCode.AIRESULT_SUCCESS) {
         int errorCode = templateText.getErrorCode();
         List<TemplateData> templateDataList = templateText.getTemplateData();
     }
     ```

   * 或者也可以将所有输出转化为String（这里json中加入的字段主要为了和卡证体系历史版本保持一致，可忽略）。

     ```screen
     JSONObject json = new JSONObject();
     try {
         json.put("resultCode", resultCode);
         json.put("common_text", new GsonBuilder().disableHtmlEscaping().create().toJson(templateText));
     } catch (JSONException e) {
         e.printStackTrace();
     }
     String totalResult = json. toString();
     ```
