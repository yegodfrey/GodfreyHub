# 银行卡识别

## 服务介绍

银行卡识别服务可以将银行卡信息通过视频流方式输入，得到图像中银行卡的卡号、有效期等重要文本信息，并且支持视频流15度角进行识别。该服务配合身份证识别，可以为用户提供实名认证、身份审核、卡号录入等实用功能，降低输入成本，为用户提供更加友好的操作体验。目前银行卡识别服务支持银行卡详细信息请参见[【ML Kit】银行卡识别支持的银行卡列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172305.34256091423768766186327492919668:50001231000000:2800:83E4B6769AF5609730769774D0B83D71630C79EC66D436077D921695E90E18DF.png "点击放大")

银行卡识别提供处理插件。开发者可以集成银行卡识别插件（集成方式参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/bcr-sdk-0000001050038086)），无需实现相机视频流数据的处理，从而实现银行卡识别能力的快速集成。

## 应用场景

该服务可以快速实现对客户银行卡信息的结构化识别，输出带格式的银行卡重要信息，这在金融场景下的身份认证、电商平台的支付绑卡有着广泛的使用。例如，当用户想要绑定一张银行卡用于网络支付时，使用该服务可以快速对银行卡信息进行录入，准确高效，大幅降低了手工输入出错的概率，提升用户体验。

## 注意事项

当前版本银行卡识别只提供视频流方式，您需要[集成银行卡识别服务插件](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/bcr-sdk-0000001050038086)，获取银行卡识别能力。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/bcr-sdk-0000001050038086)。

### 使用插件进行视频流银行卡识别

您可以直接调用银行卡识别插件，无需自己处理视频流，直接通过回调函数获取识别结果，具体流程以及示例代码如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172305.84233787058689279850132278399002:50001231000000:2800:94A6AB71FC7E31C444CB5848FD0D727CF8445E37D9466F93D31D1A945D092A56.png "点击放大")

1. 创建识别结果回调函数，重载[onSuccess](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section1573185910196)、[onCanceled](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section5689101651912)、[onFailure](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section1522523031913)、[onDenied](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section34812022191910)四个方法。[onSuccess](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section1573185910196)表示识别成功，[MLBcrCaptureResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcaptureresult-0000001050167574)为识别返回结果，[onCanceled](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section5689101651912)表示用户取消，[onFailure](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section1522523031913)表示识别失败，[onDenied](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-callback-0000001204918055#section34812022191910)表示相机不可用等场景。

   ```screen
   "Java"
   private MLBcrCapture.Callback callback = new MLBcrCapture.Callback() {
       @Override
       public void onSuccess(MLBcrCaptureResult bankCardResult){
           // 识别成功处理。
       }
       @Override
       public void onCanceled(){
           // 用户取消处理。
       } 
       // 识别不到任何文字信息或识别过程发生系统异常的回调方法。
       // retCode：错误码。
       // bitmap：检测失败的卡证图片。
       @Override
       public void onFailure(int retCode, Bitmap bitmap){
           // 识别失败处理。
     }
       @Override
       public void onDenied(){
           // 相机不支持等场景处理。
       }
   };
   ```

2. 设置识别参数，调用识别器[captureFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlbcrcapture-0000001050169523#section1778513427181)接口进行识别，识别结果会通过[1](#ZH-CN_TOPIC_0000001051070154__li7816711371)中的回调函数返回。

   ```java
   "Java"
   private void startCaptureActivity(MLBcrCapture.Callback callback) {
       MLBcrCaptureConfig config = new MLBcrCaptureConfig.Factory()
           // 设置银行卡识别期望返回的结果类型。
           // MLBcrCaptureConfig.RESULT_NUM_ONLY：仅识别卡号。
           // MLBcrCaptureConfig.RESULT_SIMPLE：仅识别卡号、有效期信息。
           // MLBcrCaptureConfig.RESULT_ALL：识别卡号、有效期、发卡行、发卡组织和卡类别等信息。
           .setResultType(MLBcrCaptureConfig.RESULT_SIMPLE)
           // 设置识别界面横竖屏，支持三种模式：
           // MLBcrCaptureConfig.ORIENTATION_AUTO: 自适应模式，由物理感应器决定显示方向。
           // MLBcrCaptureConfig.ORIENTATION_LANDSCAPE: 横屏模式。
           // MLBcrCaptureConfig.ORIENTATION_PORTRAIT: 竖屏模式。
           .setOrientation(MLBcrCaptureConfig.ORIENTATION_AUTO)
           .create();
       MLBcrCapture bankCapture = MLBcrCaptureFactory.getInstance().getBcrCapture(config);
       bankCapture.captureFrame(this, callback);
   }
   ```


### 自定义扫描界面功能

1. 如果需要对扫描界面进行定制，使用[CustomView](https://developer.huawei.com/consumer/cn/doc/hiai-References/customview-0000001051056181)可以实现自定义扫描界面。

   ```java
   "Java"
   CustomView remoteView= new CustomView.Builder()
   .setContext(this)
   //设置扫描框矩形坐标，必须设置，否则无法识别。

   // MLBcrCaptureConfig.RESULT_NUM_ONLY：仅识别卡号。

   // 设置识别结果的回调。
   .setOnBcrResultCallback(callback).build();
   ```

   ```screen
   private Rect createScanRect(int screenWidth, int screenHeight) {

       final float CARD_SCALE = 0.63084F;
       int width = Math.round(screenWidth * heightFactor);
   ```
