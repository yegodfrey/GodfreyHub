4. 以Full SDK或基础SDK方式集成。 ML Kit提供两种集成SDK方式：Full SDK方式和基础SDK方式。

   * Full SDK方式：集成后应用的包大小增量较大。
   * 基础SDK方式：集成后应用的包大小增量较小。

   安装HMS Core（APK）4.0.0.300及以上版本的手机或平板支持集成基础SDK或Full SDK，未安装HMS Core（APK）4.0.0.300及以上版本的手机或平板支持集成Full SDK。
