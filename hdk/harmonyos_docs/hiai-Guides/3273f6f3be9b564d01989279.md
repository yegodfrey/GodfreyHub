# 在线语种检测

## 服务介绍

在线语种检测服务可以检测出文本的语种，支持检测文本中的主要语言。返回对应语种的编码（除部分注明的语言代码参数外，其他语言使用ISO 639-1标准编码）和相应的置信度，或者返回一个置信度最高的语种编码。目前在线语种检测能实现109种语言检测，支持的语言及语种编码的详细信息请参见[语种检测支持的语言列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)。例如，用户可以轻松实现翻译语种检测、网页语种检测等。

## 应用场景

在线语种检测服务主要应用于翻译App中，能够自动检测文本的语种类型，用户无需选择源语种。或应用于浏览器类的App，对网页翻译前能够先检测确定语种类型。

## 注意事项

在线语种检测服务需要联网才能提供检测能力。

## 开发步骤

在进行开发之前，您需要完成必要的[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-harmonyos-0000001245919249#section13396143595911)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-harmonyos-0000001252157879)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/real-time-language-detection-sdk-harmonyos-0000001207637050)。
> 注意
>
> 同步语种检测方法需要一定的时间，建议根据设备的性能情况选择是否在UI线程中调用。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建语种检测器。可以通过语种检测器自定义参数类[MLRemoteLangDetectorSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlremlangdetset-harmonyos-0000001201428280)创建检测器。

   ```java
   "Java"
   // 方式一：使用默认的参数配置创建语种检测器。  默认走设备所在地区
    MLRemoteLangDetector mlRemoteLangDetector = MLLangDetectorFactory.getInstance() 
        .getRemoteLangDetector(); 
    // 方式二：使用自定义的参数配置创建语种检测器。 （推荐使用方式二）
    MLRemoteLangDetectorSetting setting = new MLRemoteLangDetectorSetting.Factory() 
        // 设置语种检测的最低置信度阈值。
        .setTrustedThreshold(0.01f)  
   // 此方法已废弃，请使用新的设置规则，参见https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#ZH-CN_TOPIC_0000001229909424__li52602461561。
        .setRegion(MLRemoteLangDetectorSetting.REGION_DR_CHINA)
        .create(); 
    MLRemoteLangDetector mlRemoteLangDetector = MLLangDetectorFactory.getInstance() 
        .getRemoteLangDetector(setting);
   ```

3. 进行语种检测（错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlexception-harmonyos-0000001201100780#section1179258164510)）。

   同步方法实例代码：

   ```java
   "Java"
   // 方式一：返回多个语种检测结果，包括语种编码以及置信度，sourceText表示待检测的文本，长度需小于5000个字符。
    try { 
        List<MLDetectedLang> result= mlRemoteLangDetector.syncProbabilityDetect(sourceText); 
    } catch (MLException mlException) { 
        // 失败的处理逻辑。
        // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
        int errorCode = mlException.getErrCode(); 
        // 获取报错信息，开发者可以结合错误码，快速定位问题。
        String errorMessage = mlException.getMessage(); 
    } 
    // 方式二：返回置信度最高的语种编码，sourceText表示待检测的文本，长度需小于5000个字符。
    try { 
        String language = mlRemoteLangDetector.syncFirstBestDetect(sourceText); 
    } catch (MLException mlException) { 
        // 失败的处理逻辑。
        // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
        int errorCode = mlException.getErrCode(); 
        // 获取报错信息，开发者可以结合错误码，快速定位问题。
        String errorMessage = mlException.getMessage(); 
    }
   ```

   > 注意
   >
   > 同步方法因涉及网络请求，请不要在UI线程中直接使用。
4. 检测完成后，释放资源。

   ```screen
   "Java"
   if (mlRemoteLangDetector != null) {
       mlRemoteLangDetector.stop();
   }
   ```
