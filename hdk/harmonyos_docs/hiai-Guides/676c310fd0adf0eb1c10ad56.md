# 配置AppGallery Connect

## 开启机器学习服务

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，根据网站提示选择"我的项目"并[创建一个应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)。
2. 创建完成后，前往"项目设置 > API管理"中开启"机器学习服务"权限。

## 配置存储位置

配置存储位置决定了您将会连接对应区域的HUAWEI ＭL Kit云侧服务。

在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站上，进入"我的项目"，选择需要设置数据存储位置的项目，进入"项目设置 > 常规"页面，在"项目"下点击"数据处理位置"后的"启用"，并在弹出的提示框中选择数据存储位置，具体操作步骤请参见[设置数据处理位置](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-data-storage-location)。

ML Kit使用[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)全套方案进行配置数据处理位置，当前其在全球范围内提供中国、德国、俄罗斯、新加坡四个数据处理位置供选择。在指定数据处理地时（包括项目默认数据处理位置），您需要考虑有关法律和政策的遵从，您的用户与数据处理地的距离，距离远近会影响网络时延。

ML Kit当前提供两种数据处理位置策略，主动管理并指定数据处理位置和由服务根据用户的活动区域自动匹配数据处理位置，具体配置见AppGallery Connect的[数据处理位置](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-data-storage-location)，修改处理策略后，您的应用需要集成最新版本的agconnect-service配置文件后才能生效。

当选择主动管理并指定数据处理位置策略时，ML Kit提供如下的接口对数据处理地进行设置。

MLApplication.getInstance().[setUserRegion](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlapplication-harmonyos-0000001201420740#section3712458134410) (your region);

对于region的取值范围提供MLApplication.[REGION_DR_CHINA](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlapplication-harmonyos-0000001201420740#section167719453616)、MLApplication. [REGION_DR_GERMAN](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlapplication-harmonyos-0000001201420740#section110912417364)、MLApplication. [REGION_DR_RUSSIA](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlapplication-harmonyos-0000001201420740#section12701143816368)、MLApplication. [REGION_DR_SINGAPORE](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlapplication-harmonyos-0000001201420740#section149348100017)四个常量分别对应中国、德国、俄罗斯、新加坡四个处理位置进行设置。

由于拍照购物业务、离线翻译和离线语音合成中的离线模型下载业务在之前的版本中已经提供设置处理地的接口，为了保证兼容性，以业务设置处理地为优先考虑原则。拍照购物业务是必须设置处理地的，否则业务运行会报错。
