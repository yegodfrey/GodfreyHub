# 离线商品导入

1. 完成"[创建商品集](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-product-visual-search-3-0000001061894271)"后，等待管理员进行审批，审批通过后，商品集状态为上线中。
2. 选择需要导入商品的商品集，点击"新增"按钮。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172443.58520114154012132333928342772332:50001231000000:2800:53A10A3DE1E3FD2B3A1B4357FA0D65C1C53E73BDA07D2F24D7D0F56C308EAE3E.png "点击放大")

   相关参数如下表所示。  

   |参数|说明|
   |:-----|:----------------------------------|
   |名称|商品集名称。|
   |创建时间|此商品集创建时间。|
   |索引更新时间|在此时间之前导入的商品，已经完成索引创建，可以通过图片搜索到对应商品。|
   |商品总量|此商品集下所有商品的数量，不包括已删除商品。|
   |图片总量|此商品集下所有图片的数量，不包括已删除图片。|
   |状态|商品集状态： * 待审批 * 上线中|
   |新增|点击此按钮可以进行离线导入。|

3. 点击上图中的"新增"进入离线导入商品界面，然后点击"离线导入商品"按钮，弹出导入页面。选择准备好的离线包，点击确认。 离线包要求如下：

   * 压缩格式只支持zip。
   * 压缩包名称支持字母、数字、点、下划线、中划线。
   * 文件名只能是product.json，每个商品一行，并使用zip格式进行打包。
   * 压缩包大小不超过100M。
   * JSON格式见[ProductDomain](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-product-visual-search-5-0000001062574180#section56514511419)。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172443.00162899909062739461019417740717:50001231000000:2800:86E35624D5D9EE8440BFF1010F0E01AA9A579ED898A8E45952B872097F92C8BF.png "点击放大")
4. 异常信息查询和导出：只有任务整体失败或者部分商品导入失败，可以查询异常信息。选择一个失败任务，点击查看，展示错误详情，具体错误码详情见[错误码](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-product-visual-search-6-0000001062414186)。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172443.29790970944376772642108764543287:50001231000000:2800:4CC77E9866D685BE981CCFF08599F4BB86D91B770EC1033BF6318521E9C5B8F3.png "点击放大")
   * 相关参数如下表所示。  

     |参数|说明|
     |:----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
     |序号|自增序列，按照创建时间由近及远排序。|
     |商品集名称|商品集名称。|
     |创建时间|离线导入任务创建时间。|
     |商品总量|本次任务包含的商品的数量。|
     |失败数量|本次任务导入失败的商品数量。|
     |状态|* 待导入：任务已提交，待后台处理。 * 导入中：后台已经开始处理任务，未完成。 * 导入失败：由于压缩包格式错误、文件损坏，离线文件大小超限等原因，导致离线文件无法解压、识别等错误，而引起的任务整体失败。 * 索引创建中：商品已导入，服务端正在创建图片索引。 * 索引已创建：索引创建完成，已可以通过本次导入的图片进行搜索商品。|
     |上传进度|实时展示商品导入进度。|
     |失败详情|点击此按钮，可以展示任务整体失败或者部分商品异常的具体异常信息。|
