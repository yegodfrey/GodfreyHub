# 俄罗斯ReadEra使用HUAWEI ML Kit文本翻译提供多语种阅读服务

#### ReadEra简介

ReadEra是俄罗斯一款免费图书阅读类App，无广告、无需注册，支持PDF、EPUB等十多种文档格式的离线阅读。ReadEra提供多种阅读模式，除了可以调整字体大小外，还可以设定不同的背景图片，能够设置屏幕方向和亮度等，提升了用户的阅读体验。另外，ReadEra还支持分屏，能够同时阅读多本书籍或文档。  

#### 业务挑战

ReadEra为读者提供丰富的阅读体验，其中包括提供App内翻译的功能，在集成ML Kit翻译服务之前，只能通过调用第三方的翻译软件实现翻译。

* 使用其他第三方翻译，需要跳转到对应的翻译软件界面，不能为读者提供App内翻译，体验不好。
* 为了提升用户体验，需要更加快速、准确的翻译结果。
* 为了满足全球的用户，在保证用户数据安全的前提下，需要提供全球性的翻译服务。  

#### 解决方案

ReadEra通过集成ML Kit文本翻译服务，实现了App内文本翻译，支持12种语言翻译。凭借ML Kit快速准确的翻译，ReadEra为全球用户提供了稳定准确的翻译服务，改善了用户体验。

* ML Kit文本翻译服务既支持端侧调用，也支持云侧调用，并且端侧免费使用，能为读者提供App内翻译服务。
* 集成过程简单，且翻译结果准确，使ReadEra用最少的时间达到最好的效果。
* ML Kit文本翻译服务覆盖全球，安全性能高，数据处理过程符合GDPR标准。  

#### 合作收益

* ReadEra 集成ML Kit文本翻译服务，翻译速度快，准确度高，有效提升了用户体验。

* ReadEra用户 享受快速高效准确的翻译服务，可以阅读更多语种的书籍，体验更好。
