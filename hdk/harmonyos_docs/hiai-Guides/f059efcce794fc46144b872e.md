# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[Codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HUAWEIMLKitProductVisualSearchKit-iOS)快速体验一个应用的开发过程。  

#### 开发环境

支持iOS 9.0及以上版本。  

#### 开发流程

您需按照流程来完成客户端的开发工作，完整的开发流程如下表格。  

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-config-agc-0000001055443511)|在开发应用前，需要在AppGallery Connect中配置相关信息，包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-config-agc-0000001055443511#section114271577475)、[创建应用](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-config-agc-0000001055443511#section49991530164714)和[配置存储位置](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-config-agc-0000001055443511#section1894353219481)。|
|2|（可选）[开通服务](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-enable-service-0000001055763482)|使用ML Kit云侧服务（端侧服务可不开通）需要开发者在AppGallery Connect上打开ML Kit服务开关。|
|3|（可选）[添加配置文件](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/download-agc-0000001051136994)|在XCode开发环境中添加云侧服务的AppGallery Connect配置文件（端侧服务不需要添加）。|
|4|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-ios-sdk-0000001058762458)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|5|[添加权限](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-add-permissions-0000001051136996)|在"Info.plist"文件中配置应用所需权限，详细信息可参见各能力应用开发。|
|6|[应用开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-real-time-translation-0000001062729936)|根据您的业务需求，完成对语音语言类或图像类服务的开发工作。|
