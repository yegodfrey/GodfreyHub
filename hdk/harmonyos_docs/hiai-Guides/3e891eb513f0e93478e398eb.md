# 静默活体检测

#### 服务介绍

静默活体检测服务支持实时捕捉人脸，不需要用户配合做动作就可以判断是真实人脸，还是人脸攻击（比如：人脸翻拍图片、人脸翻拍视频以及人脸面具等）。

#### 应用场景

静默活体检测服务应用广泛，例如在实名认证、手机解锁的前处理中，首先需要判断人脸是否为活体。  

#### 注意事项

* 静默活体检测服务暂不支持横屏、分屏进行检测。
* 大折叠屏仅支持折叠时使用，小折叠屏仅支持展开时使用。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251117143619.24754062008068329206784523021263:50001231000000:2800:D633BA52B00260D6A04BE04ACC5B0EE4A80796F228CAB4863084C0BFA5D67F0D.png)  
在支付类等高风险业务中，建议使用[动作活体检测服务](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/interactiveliveness-detection-0000001183058584)。  

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/liveness-detection-sdk-0000001052704932)。  
静默活体检测提供两种调用方式，您可以根据需求选择相应的调用方式构建静默活体检测服务。  

|调用方式|活体检测流程|活体检测界面|功能|
|:------|:-------|:-------|:------|
|默认扫描界面|ML Kit处理|ML Kit提供|检测是否为活体|
|自定义扫描界面|ML Kit处理|自定义|检测是否为活体|

#### 默认扫描界面

1. 创建静默活体检测结果回调，用于获取检测结果。  

   ```
   "Java"
   private MLLivenessCapture.Callback callback = new MLLivenessCapture.Callback() {
      @Override
      public void onSuccess(MLLivenessCaptureResult result) {
       //检测成功的处理逻辑，检测结果可能是活体或者非活体。
      }

      @Override
      public void onFailure(int errorCode) {
          //检测未完成，如相机异常CAMERA_ERROR,添加失败的处理逻辑。
      }
   };
   ```

   ```
   "Kotlin"
   private val callback: MLLivenessCapture.Callback = object : MLLivenessCapture.Callback {
        override fun onSuccess(result: MLLivenessCaptureResult) {
            //检测成功的处理逻辑，检测结果可能是活体或者非活体。
        }

        override fun onFailure(errorCode: Int) {
            //检测未完成，如相机异常CAMERA_ERROR,添加失败的处理逻辑。
        }
    }
   ```

2. 创建静默活体检测实例，启动检测。  

   ```
   "Java"
   MLLivenessCapture capture = MLLivenessCapture.getInstance();
   capture.startDetect(activity, callback);
   ```

   ```
   "Kotlin"
   val capture = MLLivenessCapture.getInstance()
   capture.startDetect(activity, callback)
   ```

#### 自定义扫描界面

1. 创建[MLLivenessDetectView](https://developer.huawei.com/consumer/cn/doc/hiai-References/mllivenessdetectview-0000001062409658)，并加载到Activity布局。  

   ```
   "Java"
   /**
   *i.绑定相机预览界面，设置活体识别区域。
   *在相机预览流中，静默活体检测会对人脸在不在图像的中间进行判断，为了提高活体的通过率，建议人脸框放在屏幕中间，且活体识别区域比绘制的人脸框范围略大。
   *ii.设置是否检测口罩。
   *ii.设置结果回调。
   *iii.将MLLivenessDetectView加载到Activity，示例代码如下：
   */
   @Override
   protected void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.activity_liveness_custom_detection);
       mPreviewContainer = findViewById(R.id.surface_layout);
       //ObtainLLivenessDetectView
       mlLivenessDetectView = new MLLivenessDetectView.Builder()
           .setContext(this)
           //设置是否检测口罩
           .setOptions(MLLivenessDetectView.DETECT_MASK)
           // 设置人脸框相对于MLLivenessDetectView的Rect
           .setFaceFrameRect(new Rect(0, 0, 0, 200))
           // 设置结果回调
           .setDetectCallback(new OnMLLivenessDetectCallback() {
               @Override
               public void onCompleted(MLLivenessCaptureResult result) {
                   // 静默活体检测完成时的结果回调
               }

                @Override
               public void onError(int error) {
                   // 静默活体检测发生错误时的错误码回调
               }

               @Override
               public void onInfo(int infoCode, Bundle bundle) {
                   // 静默活体检测提示信息回调，可用于界面提示
                   // if(infoCode==MLLivenessDetectInfo.NO_FACE_WAS_DETECTED){
                        // 当前没有检测到人脸
                   // }
                   // ...
               }

               @Override
               public void onStateChange(int state, Bundle bundle) {
                   // 静默活体检测状态切换回调
                   // if(state==MLLivenessDetectStates.START_DETECT_FACE){
                       // 开始人脸检测
                   // }
                   // ...
               }
           }).build();
       mPreviewContainer.addView(mlLivenessDetectView);
       mlLivenessDetectView.onCreate(savedInstanceState);
   }
   ```
