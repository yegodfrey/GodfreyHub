# 创建商品集

您[申请API Key和APP ID](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-product-visual-search-2-0000001061683905)之后，需要申请添加商品集，审批通过后可以在该商品集下添加商品，商品集最多可以申请3个。

1. 点击"配置"，选择服务接入站点，点击拍照购物，进入拍照购物服务配置页面。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172442.75777160698999088619596654756486:50001231000000:2800:49AB82DD883F40ECA0C2B848AA528226ECCFADB0014EE0135743A07103DB864F.png "点击放大")

2. 在拍照购物服务配置页面中找到"添加商品集"，点击"添加商品集"。输入名称，进行添加商品集。 约束：商品集最大数量3个，超过三个后不可添加。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172443.79408457793334928006243774036950:50001231000000:2800:C6F1B4F3DA51B94B9006FB275E321326F2B819D780B87756D3BA562AC61B5ACC.png "点击放大")
3. 添加商品集后，商品集状态为待审批。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172443.38870810083179094611700208782379:50001231000000:2800:D9166834BF24E6B07EA44D962FF93C5541DD96F2E808E7448A161503BCBFA24A.png "点击放大")  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172443.78998130307516719216009861181083:50001231000000:2800:F8503C63C1CBD938CFBADF2B7D3976D0CB05AE76B97186E2E51C751877B53FDC.png)  
商品集状态为待审批可以删除，商品集审批通过后不可删除。
