# HUAWEI ML Kit助力电子证件照轻松制作高质量证件照片

#### 电子证件照简介

电子证件照是一款证件照制作应用，由长治市玖安网络科技有限公司出品。提供背景处理、冲印裁剪等功能，用于修改或生成工作证、学生证等各类证件照，让个人轻松通过已有素材生成真实感很强的证件照片。  

#### 业务挑战

现今几乎每个人都需要使用证件照片，这类需求市场大，但十分分散。随着互联网信息技术的发展，越来越多人不愿意耗费过多时间和成本去传统的照相馆制作证件照片，很多职场人士、学校学生选择更加方便、实惠的线上图像处理软件制作日常使用的证件照片。

* 将人像人体元素从原有照片素材中完整地分割出来，生成各种尺寸证件照片。
* 处理已有或现场拍照素材时完整保留人像边缘的细节信息。
* 在手机端完成图像分割处理，确保人像图片不会因为上传而泄露。  

#### 解决方案

凭借HUAWEI ML Kit高精度图像分割服务，电子证件照实现了各类证件照的人像分割和一键替换照片背景能力，为用户提供了更加准确、高效的图像编辑服务，用户利用现有素材即可在家制作证件照。

* 采用经过优化的人像分割框架，使每个像素标签化，抠像精细到发丝细节。
* 创新模型训练方式，增强模型对结构性信息的学习，减少白边，使边缘更自然。
* 采用多种数据增强方式增强对不同尺寸和画质图片的泛化能力。
* 优化模型大小和性能，使模型满足端侧处理要求。

#### 合作受益

* 电子证件照： HUAWEI ML Kit图像分割服务免费开放且支持动态更新，降低了电子证件照对图像分割服务的维护成本和使用成本，且ML Kit分割图片速度快、分割准确度高，处理精细，支持各种尺寸背景替换，提升了电子证件照的产品竞争力。

* 电子证件照用户： 即使没有专业人员也可以使用现有照片素材或者拍照的方式轻松制作真实自然的各类证件照片，节省了人力物力成本。
