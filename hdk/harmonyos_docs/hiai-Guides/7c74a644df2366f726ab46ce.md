# （可选）移除未使用的二进制文件

ML Kit同时支持32位和64位架构，如您只需要64位架构的二进制文件，可以参见如下方法移除32位的二进制文件。

```screen
android{
    defaultConfig{
        ndk.abiFilters 'arm64-v8a', 'x86_64'
    }
}
```
