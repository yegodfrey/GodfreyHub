# 详细参数说明

## model_run_tool参数说明

|参数名称|参数描述|是否必选|默认值|
|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---|:-------|
|--model|离线模型路径（注：需在"/data/local/tmp"或其子目录下）。例如： --model=/data/local/tmp/hiai_model.om 注：如上模型名称hiai_model中不能包含"."字符。|是|不涉及|
|--input|推理的输入数据文件路径（注：目录需在"/data/local/tmp"或其子目录下）。 输入文件可以有多个，以逗号","分隔，逗号前后可以有空格。例如： --input=/data/local/tmp/input1.dat --input="./data/local/tmp/input1.dat, ./data/local/tmp/input2.dat, ./data/local/tmp/input2.dat"|否|生成随机输入数据|
|--input_type|指定输入tensor的数据类型。 支持以下值： FP32, FP16, INT32, UINT8, INT8, INT16, BOOL, INT64, UINT32, DOUBLE。 多输入时，以逗号","分隔。例如：--input_type="FP32, FP32" 注：当输入tensor的数据类型为FP32/INT32/UINT32时，可以不指定此参数。|否|不涉及|
|--output_type|指定输出tensor的数据类型。 支持以下值： FP32, FP16, INT32, UINT8, INT8, INT16, BOOL, INT64, UINT32, DOUBLE。 多输出时，以逗号","分隔。例如：--output_type="FP32, FP32" 注：当输出tensor的数据类型为FP32/INT32/UINT32时，可以不指定此参数。|否|不涉及|
|--output_dir|推理输出结果存放的目录（注：需在"/data/local/tmp"或其子目录下）**。** 注：目录必须已存在，不支持动态创建。 推理结果存储为二进制文件，自动命名为output_${index}。|否|当前目录|
|--enable_item|开启或关闭Profiling。 * --enable_item=0或--enable_item=off，不开启Profiling。 * --enable_item=1或--enable_item=profiling，开启Profiling。 * 其它值无效，返回错误。|否|0/off|
|--dev_perf|模型运行的算力要求等级（模型推理使用）。 * --dev_perf=1要求等级为LOW。 * --dev_perf=2要求等级为NORMAL。 * --dev_perf=3要求等级为HIGH。 * --dev_perf=4要求等级为EXTREME。 * --dev_perf=103要求等级为HIGH_COMPUTE_UNIT。 说明 > EXTREME等级并不是所有NPU都支持，不支持时会降到HIGH等级执行。|否|3|
|--aipp_format|静态AIPP模型输入图片的格式。 注：使用兼容格式生成的模型，需要显式指定此参数。 可选值为：YUV420SP_U8, XRGB8888_U8, YUV400_U8, ARGB8888_U8, YUYV_U8, YUV422SP_U8, AYUV444_U8, RGB888_U8, NONE。 当有多输入文件时，会对应有多种格式，格式之间以","分隔。例如：--aipp_format="YUV420SP_U8, XRGB8888_U8, YUV400_U8"。 > 说明 > * 多输入场景下如果某输入不使能AIPP，此输入配置为"NONE"； 如--aipp_format="YUV420SP_U8, XRGB8888_U8,NONE, YUV400_U8"。 > * 当指定该参数时，指定的个数需要和模型的输入个数一致。|否|不涉及|
|--aipp_config|动态AIPP配置文件路径。当模型有多个输入时，需指定多个配置文件，使用","隔开；同一个输入节点有多个输出时，使用"|"分隔；输入不使能AIPP时配置为NONE。例如：-- aipp_config =./dir/input1_0.json|./dir/input1_1.json,NONE,./dir/input2.json。json文件格式见[动态AIPP配置文件参数](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/parameters-in-the-dynamic-aipp-0000001073137922)。 > 说明 > * "|"是特殊字符，在命令行配置时须按转义字符使用，在字符前增加"\"。 > * 配置项aipp_config与aipp_format互斥，不能同时指定。|否|不涉及|
|--input_shape|推理前可变shape场景，指定本次推理输入数据shape。例如："input_name1: n1, c1, h1, w1; input_name2: n2, c2, h2, w2"。input_name必须是转换后的网络模型中的输入节点名称。|否|不涉及|
|--output_shape|推理前可变shape场景，指定本次推理输出数据shape。例如："output_name1: n1, c1, h1, w1; output_name2: n2, c2, h2, w2"。output_name必须是转换后的网络模型中的输出节点名称。|否|不涉及|
|--times|开启profiling时的推理次数，取值范围1~100。例如：--times=100。|否|2|
|--version|查询版本号。|否|不涉及|
|--help|打印帮助和使用信息。|否|不涉及|

## 模型性能数据表参数说明

|项目|描述|
|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|item event|事件类型。有如下定义： * load begin：模型加载开始。 * load end：模型加载结束。 * inference begin：模型推理开始。 * inference end：模型推理结束。 * unload begin：模型卸载开始。 * unload end：模型卸载结束。 > 说明 > 工具执行过程中，模型推理会执行2次。inference begin和inference end会对应生成2条记录。|
|enter time|事件的上报时间。|
|total time|各个事件begin->end的执行时间。单位：us。 仅在end处记录，begin处固定为0。|

## 算子性能数据表参数说明

|项目|描述|
|:----------|:----------------------------------------------------------|
|op name|算子名称(算子类型)。 由执行的模型结构决定。例如：transdata_for_nd_0(TransData)。|
|start time|算子执行的开始时间。|
|total time|算子执行耗时。单位：us。 > 注意 > 同一次推理中，如有算子名重复的NPU算子，需将重复记录的时间加总得到总时间。|
|device type|执行设备类型。 * NPU。 * CPU。|
