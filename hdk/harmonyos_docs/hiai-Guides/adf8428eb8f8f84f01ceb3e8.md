# 异构调优操作流程

异构调优工具heter_tuning_tool位于[Tools下载](https://developer.huawei.com/consumer/cn/doc/hiai-Library/tools-download-0000001060044334)的tools/tools_tuning下，仅支持运行在HarmonyOS 5.0以前的64位Kirin芯片平台上，参数如下：  

|参数名称|参数描述|是否必选|默认值|
|:-----------------------|:--------------------------------|:---|:--------------|
|h/help|显示帮助信息|否|不涉及|
|model|原始框架模型文件路径|是|不涉及|
|mode|运行模式 0：高性能模式 1：低功耗模式|否|0|
|device_memory_reuse_plan|内存复用率 0：高内存复用 1：低内存复用|否|0|
|input|输入数据文件路径（模型使用gatherV2算子时需要指定输入路径）|否|不涉及|
|output_dir|输出目录路径（只能用/data/local/tmp或者其子目录）|否|/data/local/tmp|

1. 使用heter_tuning_tool工具生成model_deviceconfig.json配置文件。

   <br />

   ```
   ./heter_tuning_tool --mode=1 --device_memory_reuse_plan=1 --model=model.om --output_dir=/data/local/tmp/
   ```

   <br />

2. 修改model_deviceconfig.json配置文件。

   <br />

   * 若使用高性能模式或者低功耗模式，步骤3中直接使用[步骤1](#ZH-CN_TOPIC_0000001176673374__li97141273319)生成的配置文件，不做修改。其中步骤1中的mode=0为高性能模式，mode=1为低功耗模式。
   * 若需要按照实际应用场景设置，则修改[步骤1](#ZH-CN_TOPIC_0000001176673374__li97141273319)生成的model_deviceconfig.json文件，根据实际需求指定算子到具体的device执行，算子支持情况可查看json文件。

   <br />

<!-- -->

3. [模型在线编译使能异构调优配置](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/online-compilation-using-heterogeneous-0000001178096212)。

|参数名称|描述|
|:--------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ChipType|芯片类型，由工具生成，不能修改。|
|GenerateBy|生成异构配置的版本信息。 注意： 版本号信息禁止修改。|
|OpExecuteDevice|算子的异构信息集合。 当SupportDevice出现多种硬件时，可以修改ExecuteDevice为可支持的硬件设备。比如Reshape算子的SupportDevice为CPU:NPU，那么此算子的ExecuteDevice可以修改为CPU或者NPU。 * ExecuteDevice：算子执行硬件。 * OpName：算子名称。 * SupportDevice：算子的可执行硬件。 * Type：算子的类型。 以上只能修改ExecuteDevice字段，其余字段禁止修改。|
|DeviceConfigMode|异构模式，由工具生成，不能修改。|
|DeviceMemoryReusePlan|内存复用，有两种模式：高内存复用、低内存复用。|
|FallBackMode|是否支持回滚模式。 * ENABLE：支持回滚模式，当NPU无法支持的场景时会切换至CPU执行。 * DISABLE：不支持回滚模式。|
