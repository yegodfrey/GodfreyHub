# 本地集成

若您选择将模型放到本地集成，则可以确保当云端托管的模型不可用时，模型相关的功能仍然可用。

* 放到assets目录。 如需将MindSpore Lite模型在您的工程里面和应用一起打包，请将模型文件（以.ms结尾的文件）复制到工程assets目录中的新文件夹。如果您的工程目录里面没有assets目录则需要创建。创建方法：右击选择您想放置模型文件路径的工程子目录，选择"新建 > 文件夹"，命名为assets。

  模型文件是不可以被压缩的，在工程的build.gradle做如下配置来保证Gradle在构建应用时不会压缩算法模型：

  ```codeblock
  android {
      // ...
      aaptOptions {
          noCompress "ms"  // Your model's file extension: "ms".
      }
  }
  ```

  完成这些操作后，模型文件会打包到应用软件里，模型推理器会加载模型文件完成推理。


* 放到自定义目录。 把模型文件存储到您的自定义目录，并通过setLocalFullPathFile("yourmodelabsolutepath")来指定此自定义路径。

  ```screen
  "Java"
  MLCustomLocalModel localModel = new MLCustomLocalModel.Factory("yourmodelname")
      .setLocalFullPathFile("yourmodelabsolutepath")
      .create();
  ```

  ```screen
  "Kotlin"
  var localModel = MLCustomLocalModel.Factory("yourmodelname")
           .setLocalFullPathFile("yourmodelabsolutepath")
           .create()
  ```
