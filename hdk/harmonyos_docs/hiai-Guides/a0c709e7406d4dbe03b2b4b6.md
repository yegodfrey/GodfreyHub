# 地标识别

## 服务介绍

集成地标识别服务，您会获得输入图片的地标名称、经纬度、可信度等信息，可信度越高代表输入图片中的地标越有可能是识别出的地标。基于获得的信息，您可以为用户创造更加个性化应用体验。目前已经支持分布在全球超过17,000处地标的识别。

## 应用场景

地标识别服务可应用于旅游服务场景。例如，旅游类App集成该服务，用户拍摄图片，经过ML Kit检测返回地标的名称和地址，App可以根据返回的信息，提供给用户地标的简介、参观游览建议等。

## 注意事项

地标识别服务是端侧调用云侧API进行检测，检测算法模型在云侧运行。因此，调测和使用时需保证设备可正常访问互联网。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/landmark-sdk-0000001050040043)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。


1. 创建地标分析器。可以通过地标识别自定义参数类[MLRemoteLandmarkAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlremotelandmarkanalyzers-0000001050169479)创建分析器。

   ```screen
   "Java"
   // 方式1：使用默认的参数配置。
   MLRemoteLandmarkAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteLandmarkAnalyzer();
   // 方式2：使用自定义的参数配置。
   /**
     * setLargestNumOfReturns 识别结果的最大数量。
     * setPatternType  分析器使用的模式。
     * MLRemoteLandmarkAnalyzerSetting.STEADY_PATTERN：值为1，即稳定模式。
   *MLRemoteLandmarkAnalyzerSetting.NEWEST_PATTERN：值为2，即最新模式。
     */
   MLRemoteLandmarkAnalyzerSetting settings = new MLRemoteLandmarkAnalyzerSetting.Factory()
       .setLargestNumOfReturns(1)
       .setPatternType(MLRemoteLandmarkAnalyzerSetting.STEADY_PATTERN)
       .create();
   MLRemoteLandmarkAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteLandmarkAnalyzer(settings);
   ```

   ```screen
   "Kotlin"
   // 方式1：使用默认的参数配置。
   var analyzer = MLAnalyzerFactory.getInstance().remoteLandmarkAnalyzer
   // 方式2：使用自定义的参数配置。
   /**
     * setLargestNumOfReturns 识别结果的最大数量。
     * setPatternType  分析器使用的模式。
     * MLRemoteLandmarkAnalyzerSetting.STEADY_PATTERN：值为1，即稳定模式。
     * MLRemoteLandmarkAnalyzerSetting.NEWEST_PATTERN：值为2，即最新模式。
     */
   var settings = MLRemoteLandmarkAnalyzerSetting.Factory()
            .setLargestNumOfReturns(1)
            .setPatternType(MLRemoteLandmarkAnalyzerSetting.STEADY_PATTERN)
            .create()
   var analyzer = MLAnalyzerFactory.getInstance().getRemoteLandmarkAnalyzer(settings)
   ```

2. 通过android.graphics.Bitmap构造[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，支持的图片格式包括：jpg/jpeg/png/bmp，建议图片尺寸不小于640*640像素，不大于1920*1920像素。

   ```screen
   "Java"
   MLFrame mlFrame = new MLFrame.Creator().setBitmap(bitmap).create();
   ```

   ```screen
   "Kotlin"
   var mlFrame = MLFrame.Creator().setBitmap(bitmap).create()
   ```

3. 进行地标识别（错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlexception-0000001050169383)）。

   ```screen
   "Java"
   Task<List<MLRemoteLandmark>> task = analyzer.asyncAnalyseFrame(mlFrame);
   task.addOnSuccessListener(new OnSuccessListener<List<MLRemoteLandmark>>() {
       public void onSuccess(List<MLRemoteLandmark> landmarkResults) {
       // 识别成功的处理逻辑。 
       }})
       .addOnFailureListener(new OnFailureListener() {
       public void onFailure(Exception e) {
           // 识别失败的处理逻辑。
           // Recognition failure.
           try {
               MLException mlException = (MLException)e;
               // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
               int errorCode = mlException.getErrCode();
               // 获取报错信息，开发者可以结合错误码，快速定位问题。
               String errorMessage = mlException.getMessage();
           } catch (Exception error) {
              // 转换错误处理。
           }  
      }
   });
   ```

   ```screen
   "Kotlin"
   val task = analyzer!!.asyncAnalyseFrame(mlFrame)
   task.addOnSuccessListener {
   // 识别成功的处理逻辑。
   }
   .addOnFailureListener {e ->
   // 识别失败的处理逻辑。
                // Recognition failure.
                try {
                    val mlException = e as MLException
                    // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
                    val errorCode = mlException.errCode
                    // 获取报错信息，开发者可以结合错误码，快速定位问题。
                    val errorMessage = mlException.message
                } catch (error: Exception) {
                    // 转换错误处理。
                }
            }
   ```

4. 识别完成，停止分析器，释放检测资源。

   ```screen
   "Java"

       try {
           analyzer.stop();
       } catch (IOException e) {
            // 异常处理。
       }
   }
   ```

   ```screen

        try {
            analyzer!!.stop()
        } catch (e: IOException) {
            // 异常处理。
        }
    }
   ```
