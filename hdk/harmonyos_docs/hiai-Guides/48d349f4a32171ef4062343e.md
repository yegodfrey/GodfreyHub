# 合作案例：快手+AI撕漫脸

CANN NPU硬件加速助力快手实现更优的漫画特效画质体验  

#### 快手简介

快手是一款热门短视频社区手机应用，鼓励用户用视频记录、分享自己的生活点滴，为用户提供个性化视频录制、编辑功能，每天产出数百万用户原创视频。  

#### 核心痛点

快手短视频上线AI漫画脸特效，打开相机，选择我的漫画脸，就会根据用户的面部改成漫画的风格。但是传统的算法在很多场景下无法达到很好的效果，所以快手采用AI的方式去构建特效模型。由于CPU和GPU推理AI网络的计算模式会有延迟过高、功耗过高的问题，只能采用较小的AI模型，影响用户体验。

* 推理延迟过高：人脸识别及风格转换过程中，手机需要完成复杂的深度学习算法模型运算，对手机CPU运算能力是一大挑战。当CPU性能无法承载时，就会出现识别率不稳定、动作吞帧、卡顿、不连贯的问题。

* 功耗过高：CPU进行大量复杂运算时，就会耗费大量手机电量，产生大量热量，使机身发热严重。

#### 解决方案

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250429142008.68130105705689515949852868743649:50001231000000:2800:C3A16B8890C56ADF25FFEAA5E1FDFF56EB177B4A00C20EB0D5133636EAC9FFF6.png "点击放大")

快手的神经网络推理框架KwaiNN通过Graph IR的方式接入NPU算子库，使用CANN底层计算能力。在增大模型深度广度的同时实现比CPU更低的功耗，更快的推理性能，从而使漫画特效达到更加逼真生动的体验。

体验步骤：

打开快手拍摄界面 → 点击左下"魔法"选项 → 选择"我的手绘脸"，即可体验。  

#### 合作受益

主干网络模型高效支持depthwise卷积、pointwise卷积等算子，端侧运算，时延更低，在保持低功耗运行的同时，运行时间从300+ms大幅降低至13 ms，显著减少模型调优所需的人力投入，有效突破模型端侧部署难题，实现手绘滤镜功能在华为手机的快速落地。
