# 业务介绍

#### 业务简介

人脸解析，是将人的头部包含人脸五官构成进行分解，得到头发、面部皮肤、眼睛、眉毛、鼻子、嘴、耳朵等区域。

本接口的主要功能是对输入图片中的人脸做解析，给出人脸的各个面部区域解析结果，共计16类。具体有：背景、脸部皮肤、左/右眉毛 、左/右眼睛 、鼻子、上嘴唇/嘴内部/下嘴唇、左/右耳朵 、脖子、眼镜和墨镜。不同的部位用不同颜色予以标注。  

#### 场景介绍

本算法用于将图片中人脸五官构成进行分解，可以应用于APP美颜美肤，表情识别等场景。

* 美颜美肤：根据五官区域进行深度而有针对性的美颜。

<!-- -->

* 表情识别：根据五官区域对人脸表情进行解读，从而达到识别表情的目的。

<!-- -->

* 虚拟试妆：根据不同脸部区域进行针对性渲染，达到虚拟的试妆体验。比如唇彩、腮红等。  

#### 功能特点

* 快速：目前该算法基于深度神经网络开发，充分利用华为手机的NPU芯片，对神经网络进行加速，加速比能达到10倍以上。
* 轻便：利用本API，可以大大节省算法开发的时间，节省算法模型占用的ROM空间，让您的应用更加轻便。

#### 功能使用限制

|功能|使用限制说明|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------|
|输入图片大小|输入图片大小不超过1200w像素，其长或宽都不得小于64像素，作为参数传入人脸解析接口的VisionImage对象中的Bitmap，其类型必须为ARGB888，否则会返回非法的错误码。|
|图片人脸限制|输入图片中仅包含一张人脸，多张人脸需要裁剪成单张再使用。 对于图片质量太差或者图片中人脸过小过大的情况，误识别属于正常可理解的范畴。|
|多线程调用|HUAWEI HiAI Engine支持多用户同时接入，但是不支持同一用户启用多个线程，调用同一个特性，同一个用户的不同线程之间会相互影响。如，线程1启动引擎正在进行人脸解析，而线程2调用release()方法则会将引擎释放，导致线程1的人脸解析出现错误。多用户则不受此影响。|
