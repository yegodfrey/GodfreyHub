# 合作案例：汽车之家

**智能优选视频封面，HUAWEI HiAI携手汽车之家让视频分享更出彩**

## 汽车之家简介

汽车之家以快捷、专业的资讯服务为用户选车、买车、用车提供信息支持，它汇集报道各类汽车新闻资讯、提供市场行情信息、分享养车用车经验，拥有庞大的、高粘度的用户群，是国内领先的垂直互动媒体应用。

## 核心痛点

**视频封面由用户挑选，耗时且效果欠佳：**随着短视频热度的不断提升，用户更倾向于通过视频分享信息，各类应用也由此开辟了基于视频内容的分享交流版块，如汽车之家的旅行家栏目，就为用户提供了分享自驾游等视频的交流平台。然而关于视频封面，大多视频分享平台目前都采用自动挑选第一帧生成封面或由用户自己从拍摄画面中挑选一帧生成封面的方式，但往往第一帧画面画质、构图等效果不佳，最终会影响分享效果，用户自己挑选又太过繁琐耗时。优化封面生成方式，由此成为视频交流平台需要改进的问题。

## 解决方案

**自动挑选优质画面作为视频封面：** 运用HUAWEI HiAI Engine美学评分能力，结合失焦、抖动等技术因素与歪斜、色彩等主观美感，对视频各帧画面进行综合打分，并自动挑选出得分最高的画面作为视频封面，轻松解决第一帧画面欠佳、用户自己挑选耗时费力的问题。

**汽车之家：**

有效提升旅行家版块视频封面质量，改善分享效果的同时，为用户带来优质的视频阅览体验。
