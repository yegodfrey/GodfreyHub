# 开发指南

#### 应用开发

#### 必须导入类

1. 在使用表格识别API时，将实现表格识别的相关的类添加至工程。

   ```
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
   import com.huawei.hiai.vision.common.VisionBase; // 加载连接服务的静态类
   import com.huawei.hiai.vision.common.VisionImage;
   import com.huawei.hiai.vision.text.TableDetector; // 加载表格识别类
   import com.huawei.hiai.vision.visionkit.text.table.Table; // 加载表格结果类
   import com.huawei.hiai.vision.visionkit.text.table.TableCell;
   import com.huawei.hiai.vision.visionkit.text.table.TableContent;
   import com.huawei.hiai.pdk.resultcode.HwHiAIResultCode;
   ```

#### 开发

1. 定义TableDetector实例，将此应用的Context当做入参。

   ```
   TableDetector detector = new TableDetector(context);
   ```

2. 定义表格检测配置。

   ```
   VisionTableConfiguration mTableConfig = new VisionTableConfiguration.Builder()
       .setAPPType(VisionTableConfiguration.APP_NORMAL)
       .setProcessMode(VisionTableConfiguration.MODE_OUT)
       .build();
   mTableDetector.setVisionConfiguration(mTableConfig);
   ```

3. 执行prepare方法。

   ```
   mTableDetector.prepare();
   ```

4. 定义VisionImage和Table，调用detect方法得到表格识别结果。

   ```
   VisionImage image = VisionImage.fromBitmap(mSoureceBitmap);
   Table table = new Table();
   mResult_code = mTableDetector.detect(image, table, null);
   ```
