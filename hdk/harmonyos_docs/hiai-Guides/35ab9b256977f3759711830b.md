# NPU算子约束

## 整体约束

* NCHW场景和NHWC场景，1<=N<=65535。
* 对于Caffe框架，如果存在axis参数，则输入维度不能为1，且输入维度为2或3时axis不能为负数。
* Graph整网中不支持所有Data后直接连接Shape，Size，Rank算子的场景。
* 各算子版本支持情况如下：
  * [Caffe](https://gitee.com/mirrors/caffe)支持版本1.0。
  * [TensorFlow](https://www.tensorflow.org/)支持版本2.0。
  * [ONNX](https://github.com/onnx/onnx)支持opset版本7~18（最高支持到V1.13.1）。
  * [MindSpore](https://www.mindspore.cn/)支持版本0.3~0.5。
