# 示例

#### 普通模型（多输入）推理

```
./model_run_tool --model=./offline.om  --input="./input1.dat,./input2.dat,./input3.dat" --output_dir=./output
```

#### 静态AIPP模型(单输入)推理

```
./model_run_tool --model=./aipp_offline.om --input=image.bin --output_dir=./output --aipp_format=YUV420SP_U8
```

#### 静态AIPP模型(多输入)推理

```
./model_run_tool --model=./aipp_offline.om --input="./image1.bin,./image2.bin,./image3.bin" --output_dir=./output --aipp_format="YUV420SP_U8,XRGB8888_U8,YUV400_U8"
```

#### 动态AIPP模型(单输入)推理

```
./model_run_tool --model=./aipp_offline.om --input=image.bin --output_dir=./output --aipp_config=./aipp_dynamic.json
```

#### 动态AIPP模型(多输入)推理

```
./model_run_tool --model=./aipp_offline.om --input="./image1.bin,./image2.bin,./image3.bin" --output_dir=./output --aipp_config="./aipp0_1.json,NONE,./aipp0_3.json"
```

#### 推理前可变shape模型(单输入单输出)推理

```
./model_run_tool --model=./offline_dy.om --input="./input1.dat" --input_shape="input_name1:5,3,128,128" --output_shape="output_name1:5,212,1,1"  --output_dir=./output
```

#### 开启Profiling推理

最终在result_path指定的目录下生成性能数据（csv格式）。

```
./model_run_tool --model=./offline.om --input="./input1.dat" --output_dir=./output --enable_item=1
./data_proc_tool --result_path=./prof_data
```
