# 离线语音合成

#### 服务介绍

离线语音合成服务支持下载离线模型后，即便在无网络环境下也可以将文字信息转换为语音。当前版本有2种男声发音人，以及7种女声发音人可供选择。

#### 应用场景

离线语音合成服务在日常生活中有广泛应用。例如，在语音导航App中，可以根据导航数据离线合成特定的导航语音，让导航更加个性化，给驾驶增加乐趣。另外，火车站点需要24小时播放站点信息，通过该服务将站点数据合成为语音实现24小时播报，节省大量人力成本。  

#### 注意事项

* 目前离线语音合成服务中eagle模型支持可调整音量、语速及音调，其余模型暂不支持。
* 使用离线语音合成服务需要先下载离线模型后才可正常离线合成语音。
* 建议单次请求文本不超过500个字符。
* 输出音频数据默认规格为PCM单声道，位深为16Bit，音频采样率为16kHZ。  

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/on-device-text-to-speech-sdk-0000001059239344)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建语音合成引擎。可以通过语音合成自定义参数类[MLTtsConfig](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlttsconfig-0000001050169551)创建语音合成引擎，同时支持设置的语种和发音人请参见[MLTtsConstants](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlttsconstants-0000001050167598)。  

   ```
   "Java"
   // 使用自定义参数配置创建语音合成引擎。
   // 发音人名称请参见"音色试听"章节。
   MLTtsConfig mlTtsConfig = new MLTtsConfig()
       // 设置合成文本为英文。
       .setLanguage(MLTtsConstants.TTS_EN_US)
       // 设置发音人为英文女声BEE音色。
       .setPerson(MLTtsConstants.TTS_SPEAKER_OFFLINE_EN_US_FEMALE_BEE)
       // 设置语音合成的模式为离线模式，不设置默认为在线模式。
       .setSynthesizeMode(MLTtsConstants.TTS_OFFLINE_MODE);
   MLTtsEngine mlTtsEngine = new MLTtsEngine(mlTtsConfig);
   // 引擎运行中更新配置。
   mlTtsEngine.updateConfig(mlTtsConfig);
   ```

   ```
   "Kotlin"
   // 使用自定义参数配置创建语音合成引擎。
   // 发音人名称请参见"音色试听"章节。
   var mlTtsConfig = MLTtsConfig() // 设置合成文本为英文。
            .setLanguage(MLTtsConstants.TTS_EN_US) // 设置发音人为英文女声BEE音色。
            .setPerson(MLTtsConstants.TTS_SPEAKER_OFFLINE_EN_US_FEMALE_BEE) // 设置语音合成的模式为离线模式，不设置默认为在线模式。
            .setSynthesizeMode(MLTtsConstants.TTS_OFFLINE_MODE)
   val mlTtsEngine = MLTtsEngine(mlTtsConfig)
   // 引擎运行中更新配置。
   mlTtsEngine.updateConfig(mlTtsConfig)
   ```

3. 新建语音合成回调，用于处理语音合成结果。  

   ```
   "Java"
   MLTtsCallback callback = new MLTtsCallback() {
       @Override
       public void onError(String taskId, MLTtsError err) {
           // 语音合成失败处理。
       }

       @Override
       public void onWarn(String taskId, MLTtsWarn warn) {
           // 告警处理（不影响业务逻辑）。
       }

       @Override
           // 返回当前播放分片和文本对应关系。start表示音频分片在输入文本中的起始位置，end表示音频分片在输入文本中的结束位置（不包含）。
       public void onRangeStart(String taskId, int start, int end) {
           // 当前播放分片和文本对应关系处理。
       }

       @Override
       // taskId 该音频对应的语音合成任务Id。
       // audioFragment 音频数据。
       // offset 一个语音合成任务会对应一个音频合成数据队列，该字段表示本次传输的音频分片在该队列中的偏移量。
       // range 本次传输的音频分片所在的文本区域，range.first为起始位置(包含的)，range.second为结束位置（不包含的）。
       public void onAudioAvailable(String taskId, MLTtsAudioFragment audioFragment, int offset,
           Pair<Integer, Integer> range, Bundle bundle) {
           // Tts合成音频流回调接口，通过此接口将音频合成数据返回给App。
       }

       @Override
       public void onEvent(String taskId, int eventId, Bundle bundle) {
           // 合成事件回调方法。eventId为事件名称。
           boolean isInterrupted;
           switch (eventId) {
               case MLTtsConstants.EVENT_PLAY_START:
                   // 播放开始回调。
                   break;
               case MLTtsConstants.EVENT_PLAY_STOP:
                   // 播放停止回调。
                   isInterrupted = bundle.getBoolean(MLTtsConstants.EVENT_PLAY_STOP_INTERRUPTED);
                   break;
               case MLTtsConstants.EVENT_PLAY_RESUME:
                   // 播放恢复回调。
                   break;
               case MLTtsConstants.EVENT_PLAY_PAUSE:
                   // 播放暂停回调。
                   break;
               // 以下回调事件类型是在不使用内部播放器播放，只关注合成音频数据时，需要关注的回调接口。
               case MLTtsConstants.EVENT_SYNTHESIS_START:
                   // 语音合成开始的回调。
                   break;
               case MLTtsConstants.EVENT_SYNTHESIS_END:
                   // 语音合成结束的回调。
                   break;
               case MLTtsConstants.EVENT_SYNTHESIS_COMPLETE:
                   // 语音合成完成，同时合成的语音流全部传给App。
                   isInterrupted = bundle.getBoolean(MLTtsConstants.EVENT_SYNTHESIS_INTERRUPTED);
                   break;
               default:
                   break;
               }
          }
     };
   ```

5. 离线模式进行语音合成。离线语音合成需要下载对应发音人的模型包，先通过[MLLocalModelManager](https://developer.huawei.com/consumer/cn/doc/hiai-References/mllocalmodelmanager-0000001050328834)判断指定发音人的离线模型是否已下载。  

   ```
   "Java"
   // 创建TTS离线模型管理器。
   MLLocalModelManager localModelManager = MLLocalModelManager.getInstance();
   // 创建MLTtsLocalModel实例，可以设置发音人，从而通过模型管理器下载发音人对应的语言模型。
   MLTtsLocalModel model = new MLTtsLocalModel.Factory(MLTtsConstants.TTS_SPEAKER_OFFLINE_EN_US_FEMALE_BEE).create();
   localModelManager.isModelExist(model).addOnSuccessListener(new OnSuccessListener<Boolean>() {
       @Override
       public void onSuccess(Boolean aBoolean) {
           //如果模型未下载调用下载接口,否则直接调用TTS离线引擎的语音合成接口。
           if (aBoolean) {
               // 调用speak接口进行语音合成，sourceText为需要合成的文本（speak接口的详细说明见步骤6）。
               mlTtsEngine.speak(sourceText, MLTtsEngine.QUEUE_APPEND | MLTtsEngine.OPEN_STREAM);
           } else {
               // 调用步骤5的下载TTS离线模型的接口。
               downloadModel(MLTtsConstants.TTS_SPEAKER_OFFLINE_EN_US_FEMALE_BEE);
           }
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // 查询异常错误提示。
       }
   });
   ```

6. 下载离线语音合成所需要的语言模型，通过[MLLocalModelManager](https://developer.huawei.com/consumer/cn/doc/hiai-References/mllocalmodelmanager-0000001050328834)手动下载所需模型包。  

   ```
   "Java"
   private void downloadModel(String person) {
       // 创建TTS离线模型管理器。
       MLLocalModelManager localModelManager = MLLocalModelManager.getInstance();
       // 创建MLTtsLocalModel实例，传入发音人（person）以下载发音人对应的语言模型。
       final MLTtsLocalModel model = new MLTtsLocalModel.Factory(person)
       .create();
       // 创建下载策略配置器。支持配置条件：1.充电状态；2.Wi-Fi连接状态；3.设备空闲状态。
       MLModelDownloadStrategy request = new MLModelDownloadStrategy.Factory().needWifi().create();
       // 创建离线模型下载进度监听器。
       MLModelDownloadListener modelDownloadListener = new MLModelDownloadListener() {
           @Override
           public void onProcess(long alreadyDownLength, long totalLength) {
               // 展示离线语言模型下载进度。
           }
       };
       // 调用离线模型管理器的下载接口。
       localModelManager.downloadModel(model, request, modelDownloadListener)
           .addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void aVoid) {
                   // 离线模型下载成功。
                   // 调用updateConfig更新引擎模型配置。
                   mlTtsEngine.updateConfig(mlTtsConfig);
                   // 调用speak接口进行语音合成，sourceText为需要合成的文本（speak接口的详细说明见步骤6）。
                   mlTtsEngine.speak(sourceText, MLTtsEngine.QUEUE_APPEND | MLTtsEngine.OPEN_STREAM);
                }
            })
            .addOnFailureListener(new OnFailureListener() {
                @Override
                public void onFailure(Exception e) {
                   // 下载失败异常提示。
                }
            });
   }
   ```

   ```
   "Kotlin"
   private fun downloadModel(person: String) {
        // 创建TTS离线模型管理器。
        val localModelManager = MLLocalModelManager.getInstance()
        // 创建MLTtsLocalModel实例，传入发音人（person）以下载发音人对应的语言模型。

        // 创建下载策略配置器。支持配置条件：1.充电状态；2.Wi-Fi连接状态；3.设备空闲状态。
        val request = MLModelDownloadStrategy.Factory().needWifi()
        .create()
        // 创建离线模型下载进度监听器。
        val modelDownloadListener = MLModelDownloadListener { alreadyDownLength, totalLength ->
            // 展示离线语言模型下载进度。
        }
        // 调用离线模型管理器的下载接口。
        localModelManager.downloadModel(model, request, modelDownloadListener)
                .addOnSuccessListener { // 离线模型下载成功。
                    // 调用updateConfig更新引擎模型配置。
                    mlTtsEngine!!.updateConfig(mlTtsConfig)
                    // 调用speak接口进行语音合成，sourceText为需要合成的文本（speak接口的详细说明见步骤6）。
                    mlTtsEngine.speak(sourceText, MLTtsEngine.QUEUE_APPEND or MLTtsEngine.OPEN_STREAM)
                }
                .addOnFailureListener {
                    // 下载失败异常提示。
                }
    }
   ```
