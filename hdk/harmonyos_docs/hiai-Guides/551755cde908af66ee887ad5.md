# 语音合成

## 服务介绍

语音合成服务支持在线将文字信息转换为语音输出，提供丰富的音色以及可通过调整音量、语速（中英文支持5倍调节）从而使发音达到更加真实自然的效果。该服务采用深度神经网络合成方式，可通过端侧SDK快速集成，能够实时输出音频数据，支持下载离线模型。当前版本有2种标准男声发音，12种标准女声发音可供选择（详细发音信息请参见[音色试听](#section159151291041)）。该服务已在全球部署。

## 应用场景

语音合成服务广泛应用于广播、新闻、语音导航、有声阅读等领域。例如，在阅读小说时，语音合成服务可以将大篇幅的文本转为语音输出，同时在播放时能够实时高亮显示播放的内容，释放双眼，让文字开口说话，为阅读添加乐趣。同样，在语音导航中，可以基于导航数据录制语音片段进而合成为特定的导航语音，让导航更加个性化。

## 注意事项

* 单次请求文本不超过500个字符。
* 法语、西班牙语、德语、意大利语、波兰语、泰语、马来语、阿拉伯语、土耳其语语音合成服务目前仅在亚非拉、欧洲、中国地区部署。
* 语音合成属于云侧服务，调测和使用服务时需保证设备可正常访问互联网。
* 实时输出音频数据默认规格为MP3单声道，位深为16Bit，音频采样率为16kHZ。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/tts-sdk-0000001050122692)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建语音合成引擎。可以通过语音合成自定义配置类[MLTtsConfig](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlttsconfig-0000001050169551)创建语音合成引擎（目前支持的语音编码和发音人编码请参见[支持的发音人列表](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlsdktts-overview-0000001050167594#section17784135144012)）。

   ```java
   "Java"
   // 当前使用语音编码为中文，发音人编码为女声。
   private static final String TTS_ZH_HANS = "zh-Hans";
   private static final String TTS_SPEAKER_MALE_ZH = "zh-Hans-st-1";
   // 使用自定义参数配置创建语音合成引擎。
   MLTtsConfig mlTtsConfig = new MLTtsConfig()
       // 设置合成文本为中文。
       .setLanguage(TTS_ZH_HANS)
       // 设置中文发音音色。
       .setPerson(MLTtsConstants.TTS_SPEAKER_FEMALE_ZH)
       // 设置发音速度。范围：(0, 5.0]，1.0表示正常语速。
       .setSpeed(1.0f)
       // 设置音量。范围：(0, 2)，1.0表示正常音量。
       .setVolume(1.0f);

   MLTtsEngine mlTtsEngine = new MLTtsEngine(mlTtsConfig);
   // 设置内置播放器音量，取值范围：[0, 100] dB(分贝)
   mlTtsEngine.setPlayerVolume(20);
   // 引擎运行中更新配置。
   mlTtsEngine.updateConfig(mlTtsConfig);
   ```

   ```java
       public void onAudioAvailable(String taskId, MLTtsAudioFragment audioFragment, int offset, Pair<Integer, Integer> range, Bundle bundle){
           // Tts合成音频流回调接口，通过此接口将音频合成数据返回给App。
       }
       @Override
       public void onEvent(String taskId, int eventId, Bundle bundle) {
          // 合成事件回调方法。eventId为事件名称。
          switch (eventId) {
           case MLTtsConstants.EVENT_PLAY_START:
               // 播放开始回调。
               break;
           case MLTtsConstants.EVENT_PLAY_STOP:
               // 播放停止回调。
               boolean isInterrupted = bundle.getBoolean(MLTtsConstants.EVENT_PLAY_STOP_INTERRUPTED);
               break;
           case MLTtsConstants.EVENT_PLAY_RESUME:
               // 播放恢复回调。
               break;
           case MLTtsConstants.EVENT_PLAY_PAUSE:
               // 播放暂停回调。
               break;

           //以下回调事件是在不使用内部播放器播放，只关注合成音频数据时，需要关注的回调接口。
           case MLTtsConstants.EVENT_SYNTHESIS_START:
              // 语音合成开始的回调。
               break;
           case MLTtsConstants.EVENT_SYNTHESIS_END:
              // 语音合成结束的回调。
               break;
           case MLTtsConstants.EVENT_SYNTHESIS_COMPLETE:
            // 语音合成完成，同时合成的语音流全部传给App。
               boolean isInterrupted = bundle.getBoolean(MLTtsConstants.EVENT_SYNTHESIS_INTERRUPTED);
               break;
           default:
               break;
           }
       }
   };
   ```

4. 将语音合成回调传入第[2](#ZH-CN_TOPIC_0000001050990249__li981891311318)步中新建的语音合成引擎中，进行语音合成。

   ```java
   "Java"
   mlTtsEngine.setTtsCallback(callback);
   /**
   *第一个参数：sourceText表示需要合成的文本信息，支持最长500个字符的输入（包含500）。
   *第二个参数为合成模式设置，设置格式为：configA | configB | configC。
   *configA支持设置：
   *    MLTtsEngine.QUEUE_APPEND：排队模式，如果当前正在播放，则将任务放在队列中顺序执行；如果当前处于播放暂停状态，则恢复播放，再将任务放入队列中顺序执行；如果当前无播放任务，则立即执行。
   *    MLTtsEngine.QUEUE_FLUSH：清空模式，立即停止正在进行的语音合成任务以及播放，并清空正在排队的语音合成任务，立即执行此次语音合成任务并播放。
   *configB支持设置：
   *    MLTtsEngine.OPEN_STREAM：实时流输出模式，将文本合成的语音数据流通过onAudioAvailable回调输出。
   *configC支持设置：
   *    MLTtsEngine.EXTERNAL_PLAYBACK：外部播放模式，屏蔽SDK自带播放器，需要自行处理onAudioAvailable回调接口输出的音频，此时回调接口中播放相关接口将会失效，仅能监听语音合成相关回调接口。
   */
   // 排队模式进行语音合成，使用SDK内置播放器播放语音。
   String id = mlTtsEngine.speak(sourceText, MLTtsEngine.QUEUE_APPEND);
   ```
