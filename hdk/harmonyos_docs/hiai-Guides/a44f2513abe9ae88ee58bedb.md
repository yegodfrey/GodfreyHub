# 墨西哥Undostres生活服务，通过HUAWEI ML Kit自动识别各类账单号，快捷地完成付款

#### Undostres简介

Undostres是一款综合线上缴费类应用，通过这款应用，用户可以完成生活中的各种线上缴费操作，如水、电、煤气、网络、手机充值等。  

#### 业务挑战

Undostres在实现线上缴费功能时，需要用户录入对应的账单号，然后根据账单号识别缴费信息，完成缴费，在用户录入账单号的过程中遇到如下挑战：

* 账单往往比较长且不固定，用户不容易记且手工录入不方便，希望能够实现拍照自动录入功能。
* 用户在对账单拍照时，账单可能存在弯曲和倾斜的场景，在此类场景下拍照识别效果往往不太理想，没有很好的解决方案。  

#### 解决方案

凭借HUAWEI ML Kit高性能文本识别服务，Undostres实现了账单号的自动识别，用户只需打开摄像头，即可完成所需缴费账单号的自动识别，免手动录入。

* 识别效果好，在账单存在30度以内倾斜和45度弯曲情况下也能很好的完成识别。
* 一次开发，支持非华为手机，覆盖所有机型：HUAWEI ML Kit支持华为及非华为手机，开发者只需要一次集成，即可覆盖市面上所有安卓系统机型。  

#### 合作受益

* Undostre 集成简单，客户2人天的集成投入即实现了账单识别功能的开发。

  扫码和文本识别功能让客户电力、燃气、网络缴费以及用户转账场景均实现了二维码、账单号的自动识别，极大的提高了应用的用户体验！
* Undostre用户 账单号免手工录入，简单快捷。
