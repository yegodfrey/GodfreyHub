# 异构（可选）

#### 概述

异构是CANN提供的异构计算能力，能够使用户App在华为平台上充分享受到硬件平台的计算加速性能，同时提供非华为硬件平台的模型计算兼容性和计算加速，使用户App开发过程归一化，不再需要为不同硬件平台适配不同模型或者计算框架，减少App开发及维护的难度。

异构的原理如下图所示，指定OP1、OP2、OP5\~OPn在CPU上进行推理，OP3、OP4在NPU上进行推理。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150611.21241157312681947109938699453845:50001231000000:2800:61F2BF9D0A0D741DCC5352746B05DCAEC6E6436EFD335A9D8CCC78D5DD931580.png)

异构按照场景分为ROM侧异构和DDK侧异构，其中ROM侧异构仅支持华为自研NPU平台的手机。

* ROM侧异构

  ROM侧异构可以减少APK的so集成，同时可通过[异构调优工具](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-0000001222351583)实现高性能推理，so集成参考[App集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/creating-a-project-0000001052871843)中的[ROM侧异构](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/compiling-the-jni-0000001052751847#ZH-CN_TOPIC_0000001052751847__li75119359185)。
* DDK侧异构

  算子随DDK版本发布，相对于手机版本更新速度较快，即开发中需要用到新算子且当前ROM版本不支持的场景，可以通过更新DDK的方式支持，so集成参考[App集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/creating-a-project-0000001052871843)中的[DDK侧异构](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/compiling-the-jni-0000001052751847#ZH-CN_TOPIC_0000001052751847__li1981193717184)。

#### 使用说明

#### 模型管家V1实现异构

1. 调用[InputMemBufferCreate](https://developer.huawei.com/consumer/cn/doc/hiai-References/inputmem-const-0000001051650682)接口将model.om转为MemBuffer。
2. 调用[BuildModel](https://developer.huawei.com/consumer/cn/doc/hiai-References/buildmodel-0000001053089431)接口实现异构。

   <br />

   ```
   AIStatus BuildModel(const vector<MemBuffer *> &input_membuffer, MemBuffer *output_model_buffer, uint32_t &output_model_size, const BuildOptions &options);
   ```

   <br />

更多异构使用请参见[异构调优示例](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/heterogeneous-optimization-example-0000001222233127)。
