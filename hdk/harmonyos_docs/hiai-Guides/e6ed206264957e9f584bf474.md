# 集成实时语音识别服务SDK

您可以通过两种方式集成实时语音识别服务：

* 集成实时语音识别服务插件。
* 集成实时语音识别服务SDK。

推荐集成实时语音识别服务插件，插件提供拾音界面，SDK只提供实时语音识别的基础服务，拾音界面需要自行开发。

集成插件示例代码如下：

```
dependencies{
    // 引入实时语音识别服务插件
    implementation 'com.huawei.hms:ml-computer-voice-asr-plugin:3.15.1.301'
}
```

集成SDK示例代码如下：

```
dependencies{
    // 引入实时语音识别服务SDK
    implementation (com.huawei.hms:ml-computer-voice-asr:3.15.1.301') {
         exclude group : "com.huawei.hms", module: "network-embedded"
    }
    implementation 'com.huawei.hms:network-embedded:7.0.3.300'
}
```

#### 添加AGCP插件配置

用上述方式集成SDK后，请根据实际情况选择添加AGCP插件配置：

* 方式一：在文件头部声明下一行添加如下配置。

  ```
  apply plugin: 'com.huawei.agconnect'
  ```

* 方式二：在plugins中添加如下配置。

  ```
  plugins {
      id 'com.android.application'
      //添加如下配置
      id 'com.huawei.agconnect'
  }
  ```
