# 在线文本实体抽取

## 服务介绍

在线文本实体抽取服务可以检测出文本中是否存在实体，例如支持日期、金钱、航班号、轨道号、URL、电话号码、银行卡号、快递单号、人名、地名、公司名、地址、歌名、影视名、书籍名、APP名称、电子邮箱地址等。例如，用户可以从文本中获取识别文本中具有特定意义的实体，主要包括人名、地名、专有名词等；高亮实体信息，提高文本阅读效率；高亮实体信息，如：电话号码，方便用户快速复制粘贴；信息提取，如：从非结构化文本中抽取地点（顺丰的快递单地址识别）、商品；知识图谱构建，如：构建复杂人物关系图谱，可以使用NER提取人名。

## 应用场景

在线实体抽取服务主要应用于对语义场景有需求的App中，能够自动检测文本中的实体类型，用户无需选择场景。注意事项：在线文本实体服务需要联网才能提供检测能力。

支持场景如下表：

|场景|实体|备注|
|:--------|:-------------|:-------------|
|出行|地点（location）识别|其余实体在通用场景下均能识别|
|快递收发|地址、电话、人名识别|其余实体在通用场景下均能识别|
|音乐资讯、评论|电影/电视剧名、人名识别|其余实体在通用场景下均能识别|
|阅读平台|书籍名、人名识别|其余实体在通用场景下均能识别|
|应用市场简介、评论|app名称、人名识别|其余实体在通用场景下均能识别|
|新闻|公司名、人名识别|其余实体在通用场景下均能识别|

## 注意事项

在线文本实体抽取服务通过访问云侧接口完成识别服务，调测和使用时需保证设备可正常访问互联网。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-entity-cloud-sdk-0000001230776620)。

## 云侧文本实体抽取

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建在线文本实体构造器。可以通过文本实体构造器自定义参数类[MLRemoteNerSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/entity-cloud-remnerset-0000001230956168)创建文本实体器。

   ```java
   "Java"
   // 使用自定义的参数配置创建语种检测器。
    MLRemoteNerSetting setting = new MLRemoteNerSetting.Factory()
                   .setSourceLangCode("zh")// 只支持"zh"。
                   .create();
   MLRemoteNer ner = MLNerFactory.getInstance().getRemoteNer(setting);
   //进行文本实体抽取（错误码信息可参见：机器学习服务https://developer.huawei.com/consumer/cn/doc/hiai-References/entity-cloud-error-0000001274957009）。
   ```

   ```javascript
   "Kotlin"
   // 使用自定义的参数配置创建语种检测器。
   var setting = MLRemoteNerSetting.Factory()
                   .setSourceLangCode("zh")// 只支持"zh"。
                   .create()
   var ner : MLRemoteNer = MLNerFactory.getInstance().getRemoteNer(setting)
   ```

3. 可通过下面的方法在线获取文本实体抽取。
   * 异步方法示例代码：

   ```java
   "Java"
   ner.asyncEntityExtract(input).addOnSuccessListener(new OnSuccessListener<RemoteNerResultItem[]>() {
               @Override
               public void onSuccess(RemoteNerResultItem[] remoteNerResults) {
                   // 成功的处理逻辑。
                   if(remoteNerResults != null){
                       // 有识别结果
                   }else {
                       //  识别结果为空
                   }
               }
           }).addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   // 识别失败,获取相关异常信息。
                   try {
                       MLException mlException = (MLException) e;
                       // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
                       int errorCode = mlException.getErrCode();
                       // 获取报错信息，开发者可以结合错误码，快速定位问题。
                       String errorMessage = mlException.getMessage();
                   } catch (Exception error) {
                       // 转换错误处理。
                   }
               }
           });
   ```

   ```javascript
   "Kotlin"
   // 使用自定义的参数配置创建语种检测器。
   val task = ner!!.asyncEntityExtract(input)
   task.addOnSuccessListener {
        // 识别成功的处理逻辑。
   }.addOnFailureListener { e ->
        // 识别失败的处理逻辑。
        try {
            val mlException = e as MLException
            // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
            val errorCode = mlException.errCode
            // 获取报错信息，开发者可以结合错误码，快速定位问题。
            val errorMessage = mlException.message
        } catch (error: Exception) {
            // 转换错误处理。
        }
    }
   ```
