# 文本嵌入

## 服务介绍

文本嵌入服务支持您输入需要查询的中英文的词或句子，查询对应的向量值，并在此基础上做进一步研究，其主要用例如下：

* 词/句向量：查询词向量/句向量结果，构建向量库。
* 词/句余弦相似度：查询两个词/句文本的相似值结果，判断词/句间是否相似。
* TopK个相似词：对输入的词进行基于语义的拓展联想。
* 词典版本信息：查询词典版本信息。

## 应用场景

文本嵌入服务可以应用于文本搜索场景。例如，在新闻类app中需要查询关于某个词句的热点新闻时，通过输入关键词句，返回与输入的词句相关的热点内容，提升搜索及浏览效率。

## 注意事项

文本嵌入服务通过访问云侧接口完成识别服务，调测和使用时需保证设备可正常访问互联网。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-embedding-sdk-0000001055244219)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建文本嵌入分析器。可以通过文本嵌入分析器配置文件[MLTextEmbeddingSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mltextembeddingsetting-0000001054094042)创建分析器。

   ```java
   "Java"
   // 创建文本嵌入分析器。
   MLTextEmbeddingSetting setting = new MLTextEmbeddingSetting.Factory()
       // 设置识别语种，目前可支持英文（MLTextEmbeddingSetting.LANGUAGE_EN）、中文简体（MLTextEmbeddingSetting.LANGUAGE_ZH）。
       .setLanguage(MLTextEmbeddingSetting.LANGUAGE_EN)
       .create();
   MLTextEmbeddingAnalyzer analyzer = MLTextEmbeddingAnalyzerFactory.getInstance().getMLTextEmbeddingAnalyzer(setting);
   ```


9. 批量请求云侧的词向量接口。

   ```java
   "Java"
   // 使用analyzer类请求analyseWordVectorBatch批量词向量接口，stringSet为所有需要查询的词组成的HashSet。
   Task<Map<String, Float[]>> wordVectorBatchTask = analyzer.analyseWordVectorBatch(stringSet);
   wordVectorBatchTask.addOnSuccessListener(new OnSuccessListener<Map<String, Float[]>>() {
       @Override
       public void onSuccess(Map<String, Float[]> wordsVector) {
           // 识别成功处理（Map为HashMap，key为查询的词，value为对应向量结果）。
           for (String word :  stringSet) {
              // vector为word对应的词向量。
              Float[] vector = wordsVector.get(word);
              if(vector.length ==  0){
                  // word对应的词向量未找到。
                  continue;
              }
           }
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // 识别失败处理，可参考如下步骤10。
       }
   });
   ```

   ```javascript
   "Kotlin"
   // 使用analyzer类请求analyseWordVectorBatch批量词向量接口，stringSet为所有需要查询的词组成的HashSet。
   val wordVectorBatchTask = analyzer.analyseWordVectorBatch(stringSet)
   wordVectorBatchTask.addOnSuccessListener { wordsVector ->
        // 识别成功处理（Map为HashMap，key为查询的词，value为对应向量结果）。
        for (word in stringSet!!) {
            // vector为word对应的词向量。
            val vector = wordsVector[word]!!
            if (vector.size == 0) {
                // word对应的词向量未找到。
                continue
            }
        }
    }.addOnFailureListener {
        // 识别失败处理，可参考如下步骤10。
    }
   ```
