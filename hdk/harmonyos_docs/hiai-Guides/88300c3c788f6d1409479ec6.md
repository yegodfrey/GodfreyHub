# 开发指南

## 应用开发

### 必须导入类

1. 在使用通用文字识别API时，将实现通用文字识别的相关的类添加至工程。

   ```screen
   import com.huawei.hiai.pdk.resultcode.HwHiAIResultCode; // 加载引擎状态类
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
   import com.huawei.hiai.vision.common.VisionBase; // 加载连接服务的静态类
   import com.huawei.hiai.vision.common.VisionImage; // 加载VisionImage类
   import com.huawei.hiai.vision.text.TextDetector; // 加载卡证检测类
   import com.huawei.hiai.vision.visionkit.text.Text; // 加载Text结果类
   import com.huawei.hiai.vision.visionkit.text.TextDetectType; // 加载Text识别类型
   import com.huawei.hiai.vision.visionkit.text.config.VisionTextConfiguration; // 加载设置类
   ```

### 开发

1. 应用VisionBase静态类进行初始化，异步获取服务的连接。

   ```screen
   VisionBase.init(MainActivity.this, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. 定义TextDetector实例，将此应用的Context当做入参。

   ```screen
   TextDetector detector = new TextDetector(mContext); // 构造Detector
   ```

3. 定义调用配置项，选择需要调用的图片类型（以相机拍照的图片类型，自动语种检测为例）。

   ```screen
   VisionTextConfiguration config = new VisionTextConfiguration.Builder()
       .setAPPType(VisionTextConfiguration.APP_NORMAL)
       .setProcessMode(VisionTextConfiguration.MODE_IN)
       .setDetectType(TextDetectType.TYPE_TEXT_DETECT_FOCUS_SHOOT)
       .setLanguage(TextConfiguration.AUTO).build();
   detector.setVisionConfiguration(config);
   ```

4. 加载引擎。

   ```screen
   int resultCode = detector.prepare();
   ```

5. 定义VisionImage，并传入待检测图片的bitmap放入VisionImage中。

   ```screen
   VisionImage image = VisionImage.fromBitmap(bitmap);
   ```

6. 定义Text类。

   ```screen
   Text result = new Text();
   ```

7. 调用TextDetector的detect的方法，获取结果。

   ```screen
   int resultCode = mTextDetector.detect(image, result, null);
   ```

   * 可以直接使用结果类获取识别结果。

     ```screen
     if (resultCode == HwHiAIResultCode.AIRESULT_SUCCESS) {
         String value = text.getValue();
     }
     ```

   * 或者也可以将所有输出转化为String（这里json中加入的字段主要为了和卡证体系历史版本保持一致，可忽略）。

     ```screen
     JSONObject json = new JSONObject();
     try {
         json.put("resultCode", resultCode);
         json.put("common_text", new GsonBuilder().disableHtmlEscaping().create().toJson(result));
     } catch (JSONException e) {
         e.printStackTrace();
     }
     String totalResult = json.toString();
     ```
