# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HUAWEIMLKitFaceDetectionKit)快速体验一个应用的开发过程。

## 开发环境

* JDK 1.8.211及以上

* 安装Android Studio 3.X及以上
  * minSdkVersion 19及以上（必须）
  * targetSdkVersion 31（推荐）
  * compileSdkVersion 31（推荐）
  * Gradle 4.6及以上（推荐）
* 测试应用的设备：EMUI 5.0及以上的华为手机或Android 4.4及以上的非华为手机（部分能力仅支持华为手机） 如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。

## 开发流程

您需按照流程来完成客户端的开发工作，完整的开发流程如下表格。

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)|在开发应用前，需要在AppGallery Connect中配置相关信息，包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353#section14236151634819)和[创建应用](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353#section89308574495)。|
|2|（可选）[开通服务](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/enable-service-0000001050038078)|使用ML Kit云侧服务（端侧服务可不开通）需要开发者在AppGallery Connect上打开ML Kit服务开关。|
|3|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/add-appgallery-0000001050038080)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|4|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-obfuscation-scripts-0000001050038100)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|5|[添加权限](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/add-permissions-0000001050040051)|在"AndroidManifest.xml"文件中配置应用所需权限，详细信息可参见各能力应用开发。|
|6|[应用开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-recognition-0000001050040053)|根据您的业务需求，完成对文本类、语音语言类、图像类、人脸人体类、自然语言处理类服务或自定义模型的开发工作。|
|7|[开发后自检](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/pre-release-check-0000001050038174)|华为提供对应用自动检查的能力。|
|8|[上架申请](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-release-0000001050750445)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/toolkit-best-experiment-0000001104145588)，了解HMS Toolkit集成该Kit最佳实践。
