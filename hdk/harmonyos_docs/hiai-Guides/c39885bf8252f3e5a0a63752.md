# 离线文本翻译

## 服务介绍

离线文本翻译服务支持在下载离线模型后，可以在没有网络的情况下将源语言文字翻译为目标语言文字。目前离线文本翻译能实现54种语言文字的离线翻译。支持语言文字的详细信息请参见[文本翻译支持的语言列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)。

## 应用场景

离线文本翻译服务同实时文本翻译服务一样可以广泛应用于需要不同语种互译的场景。例如，旅游类App集成该服务，可以提供将外文路牌、菜单等翻译成母语的功能，给游客更贴心服务。与在线文本翻译不同的是，离线翻译服务不需要网络支持，旅途中即使身处无网络环境也可轻松化解沟通障碍。

## 注意事项

使用离线文本翻译服务需要先下载对应的翻译模型（源语言和目标语言都需要下载），没有下载对应模型的语言将无法正常翻译。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/on-device-translate-sdk-0000001050038088)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建本地离线翻译器。可以通过文本翻译器自定义参数类[MLLocalTranslateSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mllocaltranslatesetting-0000001050328790)创建翻译器。

   ```java
   "Java"
   // 创建离线翻译器。
   MLLocalTranslateSetting setting = new MLLocalTranslateSetting.Factory()
       // 设置源语言的编码，使用ISO 639-1标准。此设置为必选项，如果不设置，将可能出现问题。
       .setSourceLangCode("zh") 
       // 设置目标语言的编码，使用ISO 639-1标准。此设置为必选项，如果不设置，将可能出现问题。
       .setTargetLangCode("en")
       .create();
   final MLLocalTranslator mlLocalTranslator = MLTranslatorFactory.getInstance().getLocalTranslator(setting);
   ```

   ```javascript
   "Kotlin"
   // 创建离线翻译器。
   val setting = MLLocalTranslateSetting.Factory() // 设置源语言的编码，使用ISO 639-1标准。此设置为必选项，如果不设置，将可能出现问题。
            .setSourceLangCode("zh") // 设置目标语言的编码，使用ISO 639-1标准。此设置为必选项，如果不设置，将可能出现问题。
            .setTargetLangCode("en")
            .create()
    val mlLocalTranslator = MLTranslatorFactory.getInstance().getLocalTranslator(setting)
   ```

3. 可通过下面的方法查询本地离线翻译所支持的语种。

     ```screen
                 // 成功获取本地离线翻译支持的语种。
             }

     ```

     ```screen

     }
     ```

   * 同步方法示例代码：



4. 下载本地离线翻译所需要的离线模型，我们提供以下两种方式，您可根据需求自行选择下载方式：
   * 方式一：通过[MLLocalModelManager](https://developer.huawei.com/consumer/cn/doc/hiai-References/mllocalmodelmanager-0000001050328834)手动下载所需模型包。

     ```screen
     "Java"
     // 下载成功后，在onSuccess回调中进行文本翻译。
     // 获取模型管理器。
     MLLocalModelManager manager = MLLocalModelManager.getInstance();
     MLLocalTranslatorModel model = new MLLocalTranslatorModel.Factory(sourceLangCode).create();
     // 设置模型下载策略。
     MLModelDownloadStrategy downloadStrategy = new MLModelDownloadStrategy.Factory()
         .needWifi() // 推荐wifi环境下下载。
     // 设置云测模型下载服务器站点，参数支持REGION_DR_CHINA，REGION_DR_GERMAN，REGION_DR_SINGAPORE，REGION_DR_RUSSIA（站点区域需要和配置AppGallery Connect时选择的服务接入站点保持一致）。 
         .setRegion(MLModelDownloadStrategy.REGION_DR_CHINA)
         .create();
     // 新建下载进度监听器。
     MLModelDownloadListener modelDownloadListener = new MLModelDownloadListener() {
         @Override
         public void onProcess(long alreadyDownLength, long totalLength) {
             runOnUiThread(new Runnable() {
                 @Override
                 public void run() {
                     // 对下载进度进行显示或其他操作。
                 }
             });
         }
     };
     // 下载模型。下载成功后在onSuccess回调中进行翻译。
     manager.downloadModel(model, downloadStrategy, modelDownloadListener).addOnSuccessListener(new OnSuccessListener<Void>() {
     @Override
         public void onSuccess(Void aVoid) {
             // 模型包下载成功回调。
         }
     }).addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
             // 模型包下载失败回调。
         }
     });
     ```

     ```javascript
     "Kotlin"
     // 下载成功后，在onSuccess回调中进行文本翻译。
     // 获取模型管理器。
     val manager = MLLocalModelManager.getInstance()

                  }
     }
     ```

     ```javascript
     // 模型包下载成功回调。
          }.addOnFailureListener {
     // 模型包下载失败回调。
          }
     ```

5. 进行文本翻译。
   * 异步方法示例代码：

     ```java
     "Java"
     // input 是输入的String类型文本信息，长度需小于5000个字符。
     final Task<String> task = mlLocalTranslator.asyncTranslate(input);
     // 进行翻译前，需要确保模型下载成功。
     task.addOnSuccessListener(new OnSuccessListener<String>() {
         @Override
         public void onSuccess(String s) {
             // 识别成功的处理逻辑。
         }
     }).addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
             // 识别失败的处理逻辑。
         }
     });
     ```

     ```javascript
     "Kotlin"
     //input 是输入的String类型文本信息，长度需小于5000个字符。
     val input: String? = null
      val task = mlLocalTranslator.asyncTranslate(input)
      // 进行翻译前，需要确保模型下载成功。
     task.addOnSuccessListener {
     // 识别成功的处理逻辑。
     }.addOnFailureListener {
     // 识别失败的处理逻辑。
      }
     ```

   * 同步方法示例代码：

     ```java
     "Java"
     try {
         // input 是输入的String类型文本信息，长度需小于5000个字符。

         // 识别成功的处理逻辑。
     } catch (MLException e) {
         // 识别失败的处理逻辑。
     }
     ```

     ```javascript

     ```

     > 注意
     >
     > 同步翻译方法可能耗费较多时间，所以请不要直接在UI线程中调用文本翻译同步方法，避免出现卡顿与应用无响应情况。
6. 删除不需要的模型包。

   ```screen
   "Java"
   // 获取模型管理器。
   MLLocalModelManager manager = MLLocalModelManager.getInstance();
   MLLocalTranslatorModel model = new MLLocalTranslatorModel
       .Factory("zh") // 设置模型的目的语言编码，使用ISO 639-1标准。
       .create();
   // 删除模型包。
   manager.deleteModel(model).addOnSuccessListener(new OnSuccessListener<Void>() {
       public void onSuccess(Void aVoid) {
           // 模型包删除成功回调。
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // 模型包删除失败回调。
       }
   });
   ```

   ```javascript
   "Kotlin"
   // 获取模型管理器。
   val manager = MLLocalModelManager.getInstance()
    val model = MLLocalTranslatorModel.Factory("zh") // 设置模型的目的语言编码，使用ISO 639-1标准。
            .create()
    // 删除模型包。
   manager.deleteModel(model).addOnSuccessListener {
   // 模型包删除成功回调。
   }.addOnFailureListener {
   // 模型包删除失败回调。
   }

   ```

   ```screen
   }
   ```

   ```screen
   "Kotlin"
   ```
