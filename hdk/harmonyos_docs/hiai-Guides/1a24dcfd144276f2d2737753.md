# 人脸检测

## 服务介绍

人脸检测服务支持检测人脸2D及3D轮廓。2D人脸检测能够识别人脸面部特征，包含表情、年龄、性别、穿戴等信息。3D人脸检测能够获取人脸关键点坐标信息、3D投影矩阵信息，以及人脸偏转角度等信息，您可以通过此信息自行建模。人脸检测服务支持图片检测、视频流检测；支持人脸跨帧跟踪；支持同时检测多张人脸；另外该服务支持按需集成人脸检测能力。

|特性|2D|3D|
|:---|:----------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|人脸轮廓|855个关键点，返回人脸轮廓，眉毛、眼睛、鼻子、嘴巴、耳朵等部位的坐标，人脸偏转角度等信息|* 3D人脸关键点坐标信息：获取人脸完整3D轮廓点集合，包含1591个顶点，可用于3D建模顶点数据的输入。 * 3D投影矩阵信息：将人脸关键点坐标信息和人脸模型转化到投影后的屏幕坐标系，提供投影后的5个人脸关键点，具体点位图请参见[3D人脸点位图](#section94352563255)。 * 人脸偏转角度：支持返回人脸俯仰角度、左右旋转角度、在竖直平面的顺/逆时针旋转角度。|
|面部特征|7种面部特征：左眼是否睁开、右眼是否睁开、戴眼镜的可能性、可能的性别、戴帽子的可能性、有胡子的可能性、年龄|不支持|
|面部表情|7种表情：微笑、无表情、愤怒、厌恶、惊恐、悲伤和惊讶|不支持|

## 应用场景

人脸检测服务提供了丰富的API，可帮助开发者快速构建各种人脸识别类应用。例如：图片处理类App，集成该服务，可以对检测到的人脸进行美化，或是加上有趣的元素增加图片的趣味性。另外，集成3D人脸特征，还可以利用3D投影矩阵信息对模型直接进行投影。

## 注意事项

* 支持的图片格式包括：jpg/jpeg/png，建议图片尺寸不小于224*224像素，不大于1920*1920像素。
* 3D人脸检测功能支持检测5个人脸关键点，具体支持的人脸关键点位置如下：
  * 0：右眼中心点。
  * 1：左眼中心点。
  * 2：鼻尖。
  * 3：嘴唇相交处的右嘴角。
  * 4：嘴唇相交处的左嘴角。

### 2D人脸检测

* 静态图片检测
  1. 创建人脸分析器。可以通过提供的人脸检测自定义参数[MLFaceAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlfaceanalyzersetting-0000001050169395)创建分析器。

     ```java
     "Java"
     // 方式一：使用自定义参数配置。
     // 如使用Full SDK方式集成，需要根据集成的模型包设置对应参数。
     MLFaceAnalyzerSetting setting = new MLFaceAnalyzerSetting.Factory()
         // 设置是否检测人脸关键点。
         .setKeyPointType(MLFaceAnalyzerSetting.TYPE_KEYPOINTS)
         // 设置是否检测人脸特征和表情。
         .setFeatureType(MLFaceAnalyzerSetting.TYPE_FEATURES)
         // 设置仅启用人脸表情检测和性别检测。
         .setFeatureType(MLFaceAnalyzerSetting.TYPE_FEATURE_EMOTION | MLFaceAnalyzerSetting.TYPE_FEATURE_GENDAR)
         // 设置是否检测人脸轮廓点。
         .setShapeType(MLFaceAnalyzerSetting.TYPE_SHAPES)
         // 设置是否开启人脸追踪并指定快捷追踪模式。
         .setTracingAllowed(tracingAllowed, MLFaceAnalyzerSetting.MODE_TRACING_FAST)
         // 设置检测器速度/精度模式。
         .setPerformanceType(MLFaceAnalyzerSetting.TYPE_SPEED)
         // 设置是否开启Pose检测（默认开启）。
         .setPoseDisabled(true)
         .create();
     MLFaceAnalyzer analyzer = MLAnalyzerFactory.getInstance().getFaceAnalyzer(setting);
     // 方式二：使用默认参数配置，集成Lite SDK时可以使用此配置方式。默认参数为：检测关键点、检测人脸轮廓、检测特征点、精度偏好模式、不开启人脸追踪。
     MLFaceAnalyzer analyzer = MLAnalyzerFactory.getInstance().getFaceAnalyzer();
     ```

     ```javascript
     "Kotlin"
     // 方式一：使用自定义参数配置。
      // 如使用Full SDK方式集成，需要根据集成的模型包设置对应参数。

              .setKeyPointType(MLFaceAnalyzerSetting.TYPE_KEYPOINTS) // 设置是否检测人脸特征和表情。
              .setFeatureType(MLFaceAnalyzerSetting.TYPE_FEATURES) // 设置仅启用人脸表情检测和性别检测。
              .setFeatureType(MLFaceAnalyzerSetting.TYPE_FEATURE_EMOTION or MLFaceAnalyzerSetting.TYPE_FEATURE_GENDAR) // 设置是否检测人脸轮廓点。
              .setShapeType(MLFaceAnalyzerSetting.TYPE_SHAPES) // 设置是否开启人脸追踪并指定快捷追踪模式。
              .setTracingAllowed(tracingAllowed, MLFaceAnalyzerSetting.MODE_TRACING_FAST) // 设置检测器速度/精度模式。
              .setPerformanceType(MLFaceAnalyzerSetting.TYPE_SPEED) // 设置是否开启Pose检测（默认开启）。
              .setPoseDisabled(true)
              .create()
     var analyzer = MLAnalyzerFactory.getInstance().getFaceAnalyzer(setting)
     // 方式二：使用默认参数配置，集成Lite SDK时可以使用此配置方式。默认参数为：检测关键点、检测人脸轮廓、检测特征点、精度偏好模式、不开启人脸追踪。
     var analyzer = MLAnalyzerFactory.getInstance().getFaceAnalyzer()
     ```

  2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象用于分析器检测图片，支持的图片格式包括：jpg/jpeg/png，建议图片尺寸不小于320*320像素，不大于1920*1920像素。

     ```java
     "Java"
     //通过bitmap创建MLFrame。
     MLFrame frame = MLFrame.fromBitmap(bitmap);
     ```

     ```javascript
     "Kotlin"
     //通过bitmap创建MLFrame。

     ```

  3. 调用[asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlfaceanalyzer-0000001050167440#section1043319424114)方法进行人脸检测。

     ```java
     "Java"
     Task<List<MLFace>> task = analyzer.asyncAnalyseFrame(frame);
     task.addOnSuccessListener(newOnSuccessListener<List<MLFace>>() {
          @Override
          public voidonSuccess(List<MLFace> faces) {
              // 检测成功。
     }
      }).addOnFailureListener(newOnFailureListener() {
          @Override
          public void onFailure(Exception e) {
              // 检测失败。
     }
     });
     ```

     ```javascript

      task.addOnSuccessListener {
     // 检测成功。
     }.addOnFailureListener {
     // 检测失败。
      }
     ```

  4. 检测完成，停止分析器，释放检测资源。

     ```java
     "Java"
     try {
         if (analyzer != null) {
             analyzer.stop();
         }
     } catch (IOException e) {
         // 异常处理。
     }
     ```

     ```javascript
     "Kotlin"
     try {
          if (analyzer != null) {
              analyzer!!.stop()
          }
      } catch (e: IOException) {
          // 异常处理。
      }
     ```

  以上示例代码中使用了异步调用方式，人脸检测还支持同步调用使用[analyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlfaceanalyzer-0000001050167440#section1773817154113)函数获取检测结果：

  ```screen
  "Java"
  SparseArray<MLFace> faces = analyzer.analyseFrame(frame);
  ```

  ```screen
  "Kotlin"
  val faces = analyzer!!.analyseFrame(frame)
  ```

* 视频流检测

  开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按照上文中静态图像本地检测的方法进行人脸检测。如果开发者调用的是同步检测接口，也可以使用SDK内置的[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)类实现视频流本地人脸检测，示例代码如下：
  1. 创建人脸分析器。

     ```screen
     "Java"
     MLFaceAnalyzer analyzer = MLAnalyzerFactory.getInstance().getFaceAnalyzer();
     ```

     ```screen
     "Kotlin"
     val analyzer = MLAnalyzerFactory.getInstance().faceAnalyzer
     ```

  2. 开发者创建识别结果处理类"FaceAnalyzerTransactor"，该类实现[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)<T>接口，使用此类中的[transactResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216#section7411382071)方法获取检测结果并实现具体业务。

     ```java
     "Java"
     public class FaceAnalyzerTransactor implements MLAnalyzer.MLTransactor<MLFace> {
         @Override
         public void transactResult(MLAnalyzer.Result<MLFace> results) {
             SparseArray<MLFace> items = results.getAnalyseList();
             // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
             // 不可调用ML Kit提供的其他检测相关接口。
         }
         @Override
         public void destroy() {
             // 检测结束回调方法，用于释放资源等。
         }
     }
     ```

     ```javascript
     "Kotlin"
     class FaceAnalyzerTransactor : MLTransactor<MLFace?> {
          override fun transactResult(results: MLAnalyzer.Result<MLFace?>) {
              val items = results.analyseList
              // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
              // 不可调用ML Kit提供的其他检测相关接口。
          }

          override fun destroy() {
              // 检测结束回调方法，用于释放资源等。
          }
      }
     ```

  3. 设置识别结果处理器，实现分析器与结果处理器的绑定。

     ```screen
     "Java"
     analyzer.setTransactor(new FaceAnalyzerTransactor());
     ```

     ```screen
     "Kotlin"
     analyzer!!.setTransactor(FaceAnalyzerTransactor())
     ```

  4. 创建[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)，该类由ML Kit SDK提供，用于捕捉相机动态视频流并传入分析器。建议设置的相机显示尺寸不小于320*320像素，不大于1920*1920像素。

     ```screen
     "Java"
     LensEngine lensEngine = new LensEngine.Creator(getApplicationContext(), analyzer)
         .setLensType(LensEngine.BACK_LENS)
         .applyDisplayDimension(1440, 1080)
         .applyFps(30.0f)
         .enableAutomaticFocus(true)
         .create();
     ```

     ```screen
     "Kotlin"

              .setLensType(LensEngine.BACK_LENS)
              .applyDisplayDimension(1440, 1080)
              .applyFps(30.0f)
              .enableAutomaticFocus(true)
              .create()
     ```

  5. 调用run方法，启动相机，读取视频流，进行识别。

     ```java
     "Java"
     // 请自行实现SurfaceView控件的其他逻辑。
     SurfaceView mSurfaceView = findViewById(R.id.surface_view);
     try {
         lensEngine.run(mSurfaceView.getHolder());
     } catch (IOException e) {
         // 异常处理逻辑。
     }
     ```

     ```javascript
     "Kotlin"
     // 请自行实现SurfaceView控件的其他逻辑。
     val mSurfaceView: SurfaceView? = findViewById(R.id.surface_view)
     try {
          lensEngine!!.run(mSurfaceView.holder)
      } catch (e: IOException) {
          // 异常处理逻辑。
      }
     ```

  6. 检测完成，停止分析器，释放检测资源。

     ```java
     "Java"
     if (analyzer != null) {
         try {
             analyzer.stop();
         } catch (IOException e) {
              // 异常处理。
         }
     }
     if (lensEngine != null) {
         lensEngine.release();
     }
     ```

     ```javascript
     "Kotlin"

          try {
              analyzer?.stop()
          } catch (e: IOException) {
              // 异常处理。
          }
      }
     lensEngine?.release()
     ```

  使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)<T>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见[视频流检测模式多次识别场景开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-video-0000001050040139)。
