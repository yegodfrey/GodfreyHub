# 拍照购物

## 服务介绍

用户通过拍摄商品图片，在预先建立的商品图片库中在线检索同款或相似商品，返回相似商品ID和相关信息。同时，为了更好地进行商品实时管理，该服务支持商品离线导入、商品在线增删改查和商品分发。当前支持10大类商品的搜索，包括：服装（上装、裙装、下装、内衣）、箱包、鞋子、数码家电、家居、玩具、美妆、配饰、食品、其它。

## 应用场景

拍照购物服务主要应用于线上购物场景。例如，购物类App集成该服务可以提供图片搜索商品功能，用户拍摄商品图像时，可以利用该功能快速找到想要的商品。

## 注意事项

* 拍照购物服务在端侧调用云侧API进行商品检测、识别和检索，调测和使用时需保证设备可正常访问互联网。
* ML Kit拍照购物以深度学习技术为核心，通过图像识别和搜索功能，实现定制化商品搜索服务，开发者需先建立商品图片库以便进行商品检索。如需完整体验拍照购物服务（包括商品在线增删改查接口的获取），请[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。

## 开发步骤

您使用拍照购服务须提供自己的商品数据集，在进行开发之前，您需要完成必要的准备工作，准备工作主要有两个方面：

* 离线商品数据导入和SDK准备。离线商品数据导入请参见[拍照物购离线导入商品](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-product-visual-search-2-0000001061683905)。
* SDK准备请参见[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-config-agc-0000001055443511)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-product-sdk-0000001050777020)。同时，请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。

1. 导入头文件。

   ```codeblock
   #import <MLProductVisionSearch/ProductVisionSearch.h>
   ```

2. 配置全局云端鉴权码，目前提供以下两种方式进行设置：
   * accessToken方式

     ```codeblock
     [[MLApplication sharedInstance] setAccessToken:@"your access token"];
     ```

   * apiKey方式

     ```codeblock
     [[MLApplication sharedInstance] setApiKey:@"your apiKey"];
     ```

3. 初始化配置类。

   ```codeblock
   MLRemoteProductVisionSearchAnalyzerSetting *setting = [[MLRemoteProductVisionSearchAnalyzerSetting alloc] init];
   ```

4. 设置配置参数。
   * 设置返回商品的最大数量为20。

     ```codeblock
     setting.maxResult = 20;
     ```

     此处设置的范围为1-100，如果设置数目不在范围内，会抛出异常。


   * 配置productSetId（将自己要设置的值替换**********）。

     ```codeblock
     setting.productSetId = @"**********"；
     ```

5. 开始配置。

   ```codeblock
   [MLRemoteProductVisionSearchAnalyzersetRemoteProductVisionSearchAnalyzerSetting:setting];
   ```

6. 开始检测。

   ```codeblock
   [MLRemoteProductVisionSearchAnalyzer asyncAnalyseImage:self.selectedImage addOnSuccessListener:^(MLProductVisionSearch * _Nonnull productModel) {
       // 此处为成功回调。
   } addOnFailureListener:^(NSInteger errCode, NSString * _Nonnull errMsg) {
       // 此处为失败的回调。
   }]
   ```
