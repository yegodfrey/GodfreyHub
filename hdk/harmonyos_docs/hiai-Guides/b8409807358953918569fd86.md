# 业务介绍

|------------------------------------------------------------------------------------------------------------------|-|
|机器学习服务（ML Kit）提供机器学习套件，为开发者使用机器学习能力开发各类应用，提供优质体验。得益于华为长期技术积累，ML Kit为开发者提供简单易用、服务多样、技术领先的机器学习能力，助力开发者更快更好地开发各类AI应用。| |

## 服务介绍

### 文本类

* [文本识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-recognition-0000001050040053#section16220018134717)：可以识别收据、名片、文档照片等含文字的图片，将其中的文本信息提取出来。
* [文档识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/document-recognition-0000001050038108#section1738193614598)：可以从含有文档的图片中，比如文章、合同等，能识别出带段落格式的文本信息。
* [身份证识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/idcard-recognition-0000001050040063#section18151911047)：支持从带有身份证信息的图像或视频流中，识别出带格式的文本信息。
* [银行卡识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/bank-card-recognition-0000001050038118#section1593515577819)：可以快速识别卡号信息，覆盖全球常见卡证类型，包括银联、美国运通、万事达（Mastercard）、Visa、JCB等。
* [通用卡证识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/general-card-recognition-0000001050040073#section8613173251013)：针对港澳通行证、香港身份证、回乡证等任意固定版式的卡证，基于文字识别技术，提供通用的开发框架，帮助开发者自定义后处理逻辑获取所需信息。
* [表格识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/form-recognition-0000001058920154#section116041733191313)：利用AI技术从输入的图片中识别并返回表格结构信息（包括单元格的行列信息和坐标信息）和表格中的文本信息（包括单元格内的文本内容）。

### 语音语言类

* [在线文本翻译](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/real-time-translation-0000001050040079#section116041733191313)：支持将源语言文字通过云侧服务器翻译为目标语言文字。
* [离线文本翻译](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/on-device-translation-0000001058271775#section116041733191313)：支持在下载离线模型后，可以在没有网络的情况下将源语言文字翻译为目标语言文字。
* [在线语种检测](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/real-time-language-detection-0000001050038134#section106917412151)：支持在线检测文本的语种，既支持检测单语种文本，也支持检测混合语种文本。
* [离线语种检测](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/on-device-language-detection-0000001058122069#section106917412151)：可以在没有网络的情况下检测出文本的语种，既支持检测单语种文本，也支持检测混合语种文本。
* [实时语音识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-asr-0000001050066212#section699935381711)：支持实时将短语音（时长不超过60秒）转换为文本。
* [语音合成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-tts-0000001050068169#section151907583193)：支持在线将文字信息转换为语音输出，能够实时输出音频数据，并且提供丰富的音色以及可通过调整音量、语速从而使发音达到更加真实自然的效果。
* [离线语音合成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/on-device-text-to-speech-0000001058761998#section12541932151614)：支持下载离线模型后，即便在无网络环境下也可以将文字信息转换为语音。
* [音频文件转写](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/audio-file-transcription-0000001050040089#section12541932151614)：可以将5小时内的音频文件转换成文字，支持输出标点符号，以及能够生成带有时间戳的文本信息，目前支持中英文的转写。
* [实时语音转写](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/real-time-transcription-0000001054964200)：支持将输入的长语音（时长不超过5小时）实时转换为文本，支持输出标点符号，同时可以生成带有时间戳的文本信息。
* [声音识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sound-detection-0000001055282786)：支持通过在线（实时录音）模式检测声音事件，基于检测到的声音事件可以帮助开发者进行后续指令动作。
* [同声传译](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-si-0000001307427645)：实现将音频流实时翻译为不同语种的文本以及语音，并实时输出原语音文本、翻译后的文本以及翻译文本的语音播报。

### 图像类

* [图片分类](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/image-classification-0000001050040095#section12243105522418)：通过对图片中的实体对象添加标注信息，如：人、物、环境、活动、艺术形式等信息，帮助定义图片题材和适用场景等。
* [对象检测和跟踪](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/object-detection-track-0000001050038150#section17545545102615)：您可以对图片中多个对象进行位置信息的跟踪与检测，基于此服务您可以实时定位和跟踪对象、对象分类等。
* [地标识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/landmark-recognition-0000001050038154#section1829113662810)：您会获得输入图片的地标名称、经纬度信息，基于获得的信息，您可以为用户创造更加个性化应用体验。
* [图像分割](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/image-segmentation-0000001050040109#section1658976113112)：可以将图片中不同元素的内容分割出来。
* [拍照购物](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/product-visual-search-0000001050038164#section1587811467331)：用户通过拍摄商品图片，在预先建立的商品图片库中在线检索同款或相似商品信息，返回相似商品ID和相关信息。
* [图像超分辨率](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/imagesuper-resolution-0000001051546182#section2806658192714)：提供1x和3x的超分功能，1x超分去除压缩噪声，3x超分不仅有效抑制压缩噪声，而且提供3倍的放大能力。
* [文档校正](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/documentskewcorrection-0000001051703156#section2806658192714)：可以自动识别文档在图片中的位置，根据识别到的位置信息校正拍摄角度，同时支持用户自定义边界点位置进行文档校正，从而拍摄出文档正面图像。
* [文字图像超分辨率](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-image-super-resolution-0000001055442768)：可以对包含文字内容的图片进行3倍放大，同时显著增强图像中文字的清晰度。
* [场景识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/scene-detection-0000001055162807)：通过对图片的场景内容进行分类并添加标注信息，如：室外风景、室内场所、建筑物等，辅助理解图像内容。

### 人脸人体类

* [人脸检测](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/face-detection-0000001050038170#section932719111409)：支持检测人脸2D及3D轮廓。2D人脸检测能够识别人脸面部特征，包含表情、年龄、性别、穿戴等信息。3D人脸检测能够获取人脸关键点坐标信息、3D投影矩阵信息，以及人脸偏转角度等信息。
* [人体骨骼检测](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/skeleton-detection-0000001051008415#section1587811467331)：支持检测人体各部位关键点，能够返回关键点的人体骨骼位置数据，如：头顶、脖子、肩、肘、手腕、髋、膝盖、脚踝等。
* [静默活体检测](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/mlkit-liveness-detection-0000001051386243)：支持不需要用户配合做动作即可识别业务场景中的用户是否为真人。
* [动作活体检测](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/interactiveliveness-detection-0000001183058584)：支持实时捕捉人脸，根据用户配合做动作可以判断是真实活体。
* [手势识别](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/handgesturerecognition-0000001051615541)：提供手部关键点识别和手势识别能力，支持检测21个手部关键点，返回关键点的位置数据。
* [人脸比对](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/faceverification-0000001071919926)：人脸比对服务通过识别并提取模板中的人脸特征，将模板人像和人脸图像进行高精度比对，输出相似度值，进而判断两者是否为同一个人。

### 自然语言处理类

[文本嵌入](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-embedding-0000001055002819)：支持输入需要查询的中英文的词或句子，查询对应的向量值，并在此基础上做进一步研究。

[在线文本实体抽取](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-entity-cloud-0000001230455564#section4663122514312)：支持输入需要实体抽取的文本，查询对应的实体，并在此基础上做进一步研究。

### 自定义模型

自定义模型服务可以帮助您定制新的模型，您可以先通过模型开发在应用中快速训练和生成模型。生成后的模型可以随应用一起打包，也可以将其上传到ML Kit模型托管平台进行托管，通过ML Kit SDK实现模型的下载和更新。最后您可以使用ML Kit SDK，通过此自定义模型进行推理。

* [端侧推理框架](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-mindspore-lite-0000001055328885)：是机器学习服务推出的便于集成开发运行到端侧设备上的机器学习推理框架，通过引入此推理框架，您能够最小成本的定义自己的模型并实现模型推理。
* [模型开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-ai-create-0000001057522137)：提供了迁移学习和模型转换能力，目前已经为您做好了模型训练的准备工作，方便您在应用程序中快速训练和生成新模型，通过此功能进行迁移学习和模型转换，不仅灵活度高，同时也降低了学习成本。
* [模型部署与推理](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-deployment-and-inference-overview-0000001051704932)：机器学习服务支持将模型放在本地集成或通过云端托管模型，可以将模型随应用一起打包，也可以将其上传到ML Kit模型托管平台进行托管，通过ML Kit SDK实现模型的下载和更新。
* [预置模型](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/image-classification-pre-trained-model-0000001055210299)：是开发者根据机器学习服务指定的基础模型以重新训练的方式来获取新模型，也是机器学习服务提供的最简单的端到端自定义模型解决方案，当前提供了图片分类和文本分类预置模型。
