# 集成在线文本翻译服务SDK

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172412.87711841798009638572872914387762:50001231000000:2800:66285F00C04B9674C0B298195333F44242FBA5EA038F5CDE1351510F1CBC8004.png)  
在开发前，您需要将"MLTranslate.framework"集成到您的Xcode开发环境中，SDK支持需要iOS 9.0以上（含9.0）版本。  

#### Pod导入SDK

1. 首先要确保已经安装了[Cocoapods](https://cocoapods.org/)（可通过终端输入指令：pod --version确认是否安装成功）。

2. 在终端输入指令：cd ，进入到项目的根目录下，如下所示：

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172412.51790102027936127001224342808137:50001231000000:2800:1E284C9BBD97907525468292FD526E7C75878F216F34B4CB0FC880CF22078DA7.png "点击放大")

   接着终端执行命令：pod init
3. 执行成功后，会在项目的目录下生成Podfile文件，需要在此文件中添加以下内容：pod 'MLTranslate', '\~\>2.0.5.300'。
4. 终端执行命令：pod install  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172412.52766950648149314447955840448361:50001231000000:2800:DE1DE3957016431C99E8C2384306051ADC74BB794B1C287646396B06A72BA5B9.png)  
   如果已经执行过pod install命令，可以直接执行pod update命令。
5. 等待执行成功后，打开工程目录，找到.xcworkspace文件，用Xcode打开，运行工程。  

#### 手动导入SDK

1. 下载HMS Core SDK，并解压zip包。

   下载地址：[SDK下载（手动方式集成）](https://developer.huawei.com/consumer/cn/doc/hiai-Library/ios-sdk-download-manual-0000001059289747)。
2. 在Xcode工程内右键选择"Add file to "MLTranslateDemo"..."（MLTranslateDemo工程名），同时"Destination"选项需要勾选"Copy items if needed"：

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172412.18535311295395625898202909427261:50001231000000:2800:7E98965C9B0FD7E5BBB67D4D9BE470704C91535B18230D0270A698DB0B01773F.png "点击放大")

   点击"Add"即可完成SDK的添加。
3. 点击"TARGETS"下工程名，如：MLTranslateDemo，并选择"Build Phases"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172412.07518360926220962169256478149299:50001231000000:2800:5FFA045823AD4CD7991AA4DF6F62235CC7746A6F47A117EAD48F7243EDC45AC2.png "点击放大")
4. 点击"TARGETS"下工程名，如：MLTranslateDemo，选择"Gereral"后，在"Framework,Libraries,and Embedded Content"中，将MLTranslate.framework的"Embed"设置为"Embed \& sign"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172412.35136831717137178187037795245046:50001231000000:2800:C1C61B671C97B5298CACBA17D47D2C3835DF29D0D431914DE99DBC22BAF9FF6B.png "点击放大")
5. 选择"Build Setting"后，在Build Options中将"Enable Bitcode"设置为"NO""。
