# 异构调优示例

1. 生成异构配置文件model_deviceconfig.json。例如：模型为model.om，使用高性能模式、内存高复用。

   <br />

   ```
   ./heter_tuning_tool --mode=0 --device_memory_reuse_plan=0 --model=model.om --output_dir=/data/local/tmp/
   ```

   mode=0运行结果：

   ```
   [INFO] NPU process time: 3052
   [INFO] CPU process time: 29157
   [INFO] HeterTuning process time: 2429
   [INFO] NPU gain: 25.65%
   [INFO] CPU gain: 1100.37%
   [INFO] config.deviceMemoryReusePlan: 0
   [INFO] heter_tuning_tool process success.
   ```

   结果说明：
   * NPU process time：为纯npu运行的时间（单位us）。
   * CPU process time:：为纯cpu运行的时间（单位us）。
   * NPU gain：为异构调优对比纯npu的收益。
   * CPU gain：为异构调优对比纯cpu的收益。

   ```
   ./heter_tuning_tool --mode=1 --device_memory_reuse_plan=0 --model=model.om --output_dir=/data/local/tmp/
   ```

   mode=1运行结果：

   ```
   [INFO] heter_tuning_tool run begin.
   [INFO] config.deviceMemoryReusePlan: 0
   [INFO] heter_tuning_tool process success.
   ```

   结果说明：

   mode 1为功耗模式，模型推理能以比较低的功耗运行。

   <br />

2. 修改model_deviceconfig.json文件。所有算子均支持NPU和CPU，且在mode=0的模式中，算法选择NPU为ExecuteDevice，芯片类型为kirin9000，内存复用模式为高复用。

   <br />

   ```
   {"ChipType": "kirin9000","DeviceConfigMode": "OP_LEVEL","DeviceMemoryReusePlan": "HIGH",
   "FallBackMode": "ENABLE","GenerateBy": "100.510.010.029","OpExecuteDevice": [
   {"ExecuteDevice": "NPU","OpName": "Reshape","SupportDevice": "CPU:NPU","Type": "Reshape"},
   {"ExecuteDevice": "NPU","OpName": "conv1","SupportDevice": "CPU:NPU","Type": "Convolution"},
   {"ExecuteDevice": "NPU","OpName": "MaxPool","SupportDevice": "CPU:NPU","Type": "PoolingD"},
   {"ExecuteDevice": "NPU","OpName": "Conv2D","SupportDevice": "CPU:NPU","Type": "Convolution"},
   {"ExecuteDevice": "NPU","OpName": "pool2","SupportDevice": "CPU:NPU","Type": "PoolingD"},
   {"ExecuteDevice": "NPU","OpName": "input3","SupportDevice": "CPU:NPU","Type": "Reshape"},
   {"ExecuteDevice": "NPU","OpName": "MatMul","SupportDevice": "CPU:NPU","Type": "MatMul"},
   {"ExecuteDevice": "NPU","OpName": "BiasAdd_2","SupportDevice": "CPU:NPU","Type": "BiasAdd"},
   {"ExecuteDevice": "NPU","OpName": "fc1","SupportDevice": "CPU:NPU","Type": "Activation"},
   {"ExecuteDevice": "NPU","OpName": "MatMul_1","SupportDevice": "CPU:NPU","Type": "MatMul"},
   {"ExecuteDevice": "NPU","OpName": "BiasAdd_3","SupportDevice": "CPU:NPU","Type": "BiasAdd"},
   {"ExecuteDevice": "NPU","OpName": "out","SupportDevice": "CPU:NPU","Type": "Softmax"}]}
   ```

   * 若使用高性能模式或低功耗模式，则直接使用工具自动生成的.json文件，高性能模式或者低功耗模式本步骤不做修改，直接在[步骤3](#ZH-CN_TOPIC_0000001222233127__li737316187278)中使用。
   * 若需要按照实际应用场景设置，实际使用时需要与[系统调试工具](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-0000001053126910)结合使用，使用profiling功能得到算子在不同硬件的性能，通过选择性能高的算子运行硬件，得到高性能的推理结果，或者低功耗运行。

   <br />

3. [模型在线编译使能异构调优配置](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/online-compilation-using-heterogeneous-0000001178096212)。
