# 目标检测

通过对输入的图片进行目标检测，提取出图片中的目标物体，帮助定义目标物体适用场景。使用目标检测前，需要先借助[HMS ToolKit](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/installation-0000001050145206)工具生成满足实际需要的预置模型，再将提取图片中的目标物体通过训练好的预置模型推理到预定义的场景中。  

#### 实现方法

1. 选择自定义训练集来训练模型，训练方法请参见AI Create的[目标检测](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ai-create-0000001055252424#section1369118013312)。
2. 模型训练完成后，可以对模型进行验证。 在"Add test text"的"Please select test text dateset"加入需要测试的文本资源（JSON文本或文本文件夹）即可。工具会自动对训练好的模型进行测试，并显示测试结果。

3. 训练模型结果确认可用后，选择生成Demo工程。

在模型训练结果中点击"Generate Demo"，HMS Toolkit会自动生成Demo工程，该工程自动集成了该训练后的目标检测识别模型，您可以直接运行和编译该Demo工程，生成APK文件在设备上运行，查看目标检测识别的应用效果。
