# 错误码

|ERROR_MESSAGE|值|错误描述|异常场景描述|解决方案|
|:--------------------------------------|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------|:---------------------------------------------------|
|package download failed|2402|The network is unavailable, the storage system is faulty.|包下载失败|网络不可用，存储系统问题等造成的包无法下载。|
|unsupport compress type|2406|The compression format is not supported. Currently, only ZIP is supported. Compress the file in ZIP format and upload it again.|包压缩格式错误|不支持的压缩格式，目前只支持zip，请使用zip重新打包并上传。|
|package unzip failed|2408|The package cannot be decompressed due to the abnormal source package or the transmission error. Please upload the package again|包解压失败|源包异常，传输过程有损，包存在异常文件导致的无法解压，请重新上传。|
|package size exceed limit|2404|The package size exceeds the specified limit. Upload a package whose size does not exceed 100 MB.|包大小超过限制|包大小超过约定的限制，请上传不超过100M的压缩包。|
|package analysis failed|2403|The package details do not match the type, or the specified file does not exist. Check the file based on the interface specifications.|包解析失败|包详情跟类型不匹配，特定文件不存在等未按照约定格式打包造成的异常，请按照接口规范检查文件。|
|product analysis failed|2203|The offering information does not meet the JSON format requirements and cannot be parsed. Check whether the JSON format of the offering is correct based on the interface specifications.|商品解析失败|商品信息不符合约定的JSON格式，无法解析。请根据接口规范，检查确认其是否为一个正确的商品JSON格式。|
|product parameter verify failed|2204|The offering parameter does not meet the restrictions. Check the offering parameters, including the non-empty, length, and regular expression parameters, based on the interface specifications.|商品参数校验失败|商品参数不符合约束条件。请根据接口规范，检查商品的参数，包含非空、长度、正则表达式等。|
|image file does not exist|2301|Local image upload mode, the local image to be uploaded does not exist. Check whether the actual image exists in the JSON image path.|图片文件不存在|图片上传方式，本地图片不存在。请确认JSON中的图片路径是否存在真实图片。|
|image already exist|2302|duplicate imageId|图片已存在|图片ID重复。|
|image download failed|2303|URL upload mode, the image fails to be downloaded due to network reasons or the image does not exist. Ensure that the image URL is correct.|图片下载失败|URL上传方式，图片下载失败，包括网络原因，图片不存在等。请确保提供的图片url是否能正确下载。|
|unsupport image type|2304|The image format is not supported. Currently, only JPG and PNG are supported.|不支持的图片格式|使用了不支持的图片格式，目前仅支持jpg和png。|
|image size exceed limit|2305|The image size exceeds the specified limit. Please ensure that the size of each image is less than 5 MB.|图片太大|图片大小超过约定限制。请确保每个图片小于5M。|
|image count exceed limit in one product|2306|The number of images under a single product exceeds limit. Please reduce the number of images.|单商品下图片数量超过限制|单个商品下图片数量超过了限制，请减少图片数量。|
|product is already exist|2202|The offering already exists.|商品已存在|商品已存在，不能重复导入。|
|system error|1001|System error|系统异常|包括：图片存储失败，子任务包上传失败，数据库持久化失败。|
