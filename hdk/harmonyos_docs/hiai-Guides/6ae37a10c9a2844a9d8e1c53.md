# HUAWEI ML Kit图像分割服务让视频抠图更流畅，打造一键式视频背景替换

## 视频抠图简介

视频抠图是一款专注于视频类元素分割和内容编辑的App，由米斯克网络科技（深圳）有限公司出品，集合了视频抠像，AI智能抠像，专业视频剪辑等功能，操作简洁可轻松制作并分享内容。

## 业务挑战

视频抠图最大特色功能之一便是图像分割，与以往使用图片场景不同，视频抠图需要在尽量短的时间内完成对于视频流的元素分割处理，对处理性能要求很高；同时对于视频中的人物边缘细节的处理有了更高要求。

* 云侧调用数据传输，部分用户存在隐私安全方面的顾虑：云侧调用由于需要上传视频数据到服务器，部分用户存在隐私安全方面的顾虑，且耗费更多流量和传输时延。
* 端侧视频分割推断速度慢，网络结构复杂：端侧视频分割必须是轻量级，且视频处理速度不够快就会影响视频抠图整体处理流程。
* 数据采集质量要求高，图像数据采集样本复杂：视频图像分割要求采集高质量的数据集，对精细化处理程度要求更高。

## 解决方案

随着ML Kit图像分割服务的上线，向开发者提供识别图片或视频中各类元素的能力，支持您的应用在图像分割结果的基础上实现图像区域调优、人像着色、魔法天空等功能特性。ML Kit图像分割服务完美地帮助视频图像实现业务发展需求。

* 全安卓机型覆盖，适配并优化不同机型处理速度：ML Kit的图像分割服务针对不同机型适配不同处理分辨率，并同时适应CPU和NPU两种推理方式，确保支持低端机型，保证中高端机型帧率稳定，处理流畅画质清晰，并利用CPU多线程减少模型前后处理时间。
* 端侧图片处理，无隐私泄露风险：ML Kit的图像分割服务通过训练优化支持端侧处理，不依赖于用户网络环境，针对视频流采用前帧候选框提升端侧处理帧间连续性和边缘精细度，用户无数据泄露风险。
* 增强对不同画质素材的匹配处理能力：ML Kit图像分割服务精准全面地采集数据，采用多种数据增广方式增强对不同画质的匹配处理能力。
