# 深度融合（可选）

模型推理时结合硬件深度融合，减少对DDR的访问，提升能效比。目前仅支持两种使用场景。

* 编译前可变shape场景，使用接口[SetTuningStrategy](https://developer.huawei.com/consumer/cn/doc/hiai-References/settuningstrategy-0000001200273231)设置模型优化策略为ON_DEVICE_TUNING。
* 通过[NPU算子库动态升级](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/intruduction-0000001152124259)使能深度融合时，使用接口[SetTuningStrategy](https://developer.huawei.com/consumer/cn/doc/hiai-References/settuningstrategy-0000001200273231)设置模型优化策略为ON_DEVICE_PREPROCESS_TUNING。

HarmonyOS 2.0及以后的设备，ON_DEVICE_TUNING、ON_DEVICE_PREPROCESS_TUNING都可以用来设置深度融合。
