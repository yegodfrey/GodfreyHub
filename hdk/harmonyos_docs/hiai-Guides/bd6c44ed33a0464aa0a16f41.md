# 集成图像分割服务SDK

> 注意
>
> 在开发前，您需要将"MLImageSegmentationLibrary.framework"集成到您的Xcode开发环境中，SDK支持需要iOS 11.0及其以上版本。

## Pod导入SDK

推荐使用Cocoapods集成HMS Core SDK。Cocoapods提供一个简单的依赖管理系统，避免手动导入产生的错误。

1. 首先要确保已经安装了[Cocoapods](https://cocoapods.org)（可通过终端输入指令：**pod --version**确认是否安装成功）。
2. 在Xcode项目的根目录下执行命令**pod init** ，然后在生成的Podfile文件中添加当前版本号，如：

   ```screen
   pod 'MLImageSegmentationLibrary','~>2.0.4.300'
   ```

3. 在Podfile同级目录下，执行以下命令集成HMS Core SDK：

   **pod install** 说明
   >
   > 如果已经执行过**pod install** 命令，可以直接执行**pod update**命令。
4. 打开工程目录，找到.xcworkspace文件打开工程。点击"TARGETS"下工程名，如：MLImageSegmentationDemo。选择"Build Settings"后，在"Build Options"中，将"Enable Bitcode"设置为"NO"。

## 手动导入SDK

1. 下载HMS Core SDK，并解压zip包。 下载地址：[SDK下载（手动方式集成）](https://developer.huawei.com/consumer/cn/doc/hiai-Library/ios-sdk-download-manual-0000001059289747)。

2. 将解压的文件"MLImageSegmentationLibrary.framework"放入Xcode工程中。在"Choose options for adding these files"弹框中的"Destination"选项勾选"Copy items if needed"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172415.73365829676082392743516719151076:50001231000000:2800:4AAB809228B70917A4B4D6C123E0BE8EDFE9B4513D015E86FD0A66B88E82580E.png "点击放大")
3. 点击"TARGETS"下工程名，如：MLImageSegmentationDemo。选择"General"后，在"Framework,Libraries,and Embedded Content"中，将MLImageSegmentationLibrary.framework的Embed设置为"Embed & sign"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172415.95072919099449632033932497186341:50001231000000:2800:8C7A74DBC2E213114051003DE672D118838A837567F756B8E426F4F17E60BB81.png "点击放大")
4. 选择"Build Settings"后，在"Build Options"中将"Enable Bitcode"设置为"NO"。
