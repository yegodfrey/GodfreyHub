# 合作案例：元贝驾考

**超分图片，超清体验，HUAWEI HiAI提升元贝驾考应用视觉体验**

## 元贝驾考简介

元贝驾考是一款为驾驶初学者量身定制的学车应用，提供图文并茂的驾考服务，包括报名驾校、预约学车、以及模拟驾考等，致力于打造便捷实用的一站式驾考平台。

## 核心痛点

模拟驾考是元贝驾考的主要特色功能之一，采用内置安装包的图文、视频、语音等多形式结合的模拟驾考，能够有效帮助广大学员快速熟悉考试内容和规范，从而快速通过驾考。

**图片清晰度不足，不利于体验驾考练习：**模拟考题内含大量图片，用以辅助用户进行练习，然而部分低质量图片在普通手机上显示效果不佳，反而影响用户进行驾考练习。

**传统的图片优化依赖网络：**在大部分设备上，模拟驾考的图片优化程序大多依靠联网实现，因此，在网络信号弱或无网络的情况下，图片的画质提升将明显受阻。

## 解决方案

**全面提升画质，视觉体验升级：**智能降噪和9倍分辨率放大，显著改善图片质量，带给用户更多清晰的图片细节，阅览题目图片不费劲，驾考练习体验更舒畅。

**端侧图片处理，摆脱网络约束** **：**依托HUAWEI HiAI端侧学习模型，元贝驾考实现了端侧图片优化放大，同样的图片在华为NPU机型上显示更清晰；同时摆脱网络依赖，在网络不稳定或断网的情况下，用户仍可查看优质大图。
