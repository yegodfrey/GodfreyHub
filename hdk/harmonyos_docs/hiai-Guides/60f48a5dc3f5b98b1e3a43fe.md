# 合作案例：素描画图AR大师

**HUAWEI HiAI赋能素描画图AR大师，识别更稳定，学画更流畅**

## 素描画图AR大师简介

作为一款AR绘画学习软件，素描画图AR大师可以识别如纸张、墙壁等平面，并将手机图片清晰地投影于平面上，以便用户根据投影进行临摹。同时，它还会检测绘画笔触，生成实时指导提示，帮助用户提高绘画技巧。

## 核心痛点

素描画图AR大师常收到用户的抱怨，认为其物体识别速度和灵敏度不高，使用体验大打折扣：物体识别是使用该APP进行临摹的前提，较慢的识别速度增加了用户等待成本，影响使用感受。在作画过程中，识别不稳定导致识别中断情况频发，使得临摹过程被干扰、实时指导提示不稳定，显著干扰用户绘画临摹体验，体验不佳。

**等待成本高：**在普通手机上使用素描画图AR大师，普遍存在画布识别速度慢的问题，识别物体需耗费较长时间，等待成本高。

**绘画学习被中断、指导提示不稳定：**物体识别灵敏度低，常常会使物体识别信息丢失，绘画不得不中断，是用户常见的困扰。同时，物体识别灵敏度不足还会导致提示延迟或无法显示的情况。

## 解决方案

凭借CANN的异构调度和NPU加速，素描画图AR大师的物体识别过程提速超过40%，大幅提升用户绘画体验。

**降低等待成本：**素描画图AR大师借助CANN芯片能力开放，为纸张、墙壁等识别过程进行神经网络加速计算，识别速度有效提升，节省用户的等待成本。

**绘画不中断、指导更顺滑：**大大减少由于识别速度慢、识别灵敏度低所导致的绘画中断或指导延迟等情况。
