# 合作案例：搜狐

**9倍图像超分处理，HUAWEI HiAI携手搜狐呈现更清晰的世界**

## 搜狐新闻客户端简介

搜狐新闻客户端是一款为智能手机用户提供个性化阅读服务的新闻阅读应用。通过将优质媒体资源聚合成适合方寸之间阅读的图文报纸并定时推送，方便用户随时随地获取新闻资讯。

## 核心痛点

**低分辨率图片显示效果欠佳：**随着移动终端屏幕分辨率的提高，人们对高分辨率图像的需求与日俱增。尤其在浏览新闻时，分辨率较低的图片在高分辨率手机屏幕上，显示效果较差，影响用户观感和体验。

**图片处理依赖网络：**图片画质的提升大多需要网络支持，在网络卡顿或无网络情况下，可能无法完成处理程序的运行。

**传统放大存在弊端：**对于分辨率不足的问题，传统解决方案是使用双线性或双三次立方插值方法放大图像，但该方法对图片锐利度、纯净度等的处理还有不足。

## 解决方案

**9倍分辨率放大，图片更清晰：** 通过接入HUAWEI HiAI Engine图像超分辨率能力，搜狐新闻能够将图片分辨率放大9倍（高宽各放大3倍），展现更加清晰的图片细节，并有效抑制原图中JPEG压缩噪声，改善小图片在移动终端中放大浏览时的体验。

**端侧处理，摆脱网络约束：**在华为Kirin970开发基于端侧的学习模型支持下，实现图像的端侧处理，摆脱对网络的依赖，即使没有网络，也能够快速完成图片画质的提升（原始图片需要网络）。

**智能处理，规避传统放大弊端：**基于深度学习在计算机视觉中的广泛应用，将图片进行智能放大，将有效规避传统放大弊端，获得比传统图像处理更加清晰、锐利、干净的照片。
