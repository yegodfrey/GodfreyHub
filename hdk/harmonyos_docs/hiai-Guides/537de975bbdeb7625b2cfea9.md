# 模型推理

如果您想在应用中使用自定义的MindSpore Lite模型，您需要告知推理器您模型所在的位置。推理器加载模型的方式有以下三种：

* 加载本地模型。
* 加载远程模型。
* 混合加载本地和远程模型。

## 加载模型

方式一：加载并初始化本地模型。

1. 加载模型。
   * assets目录

     ```screen
     "Java"
     MLCustomLocalModel localModel = new MLCustomLocalModel.Factory("yourmodelname")
         .setAssetPathFile("assetpathname")
         .create();
     ```

     ```screen
     "Kotlin"
     var localModel = MLCustomLocalModel.Factory("yourmodelname")
              .setAssetPathFile("assetpathname")
              .create()
     ```

   * 自定义目录

     ```screen
     "Java"
     MLCustomLocalModel localModel = new MLCustomLocalModel.Factory("yourmodelname")
         .setLocalFullPathFile("sdfullpathname") 
         .create();
     ```

     ```screen
     "Kotlin"
     var localModel = MLCustomLocalModel.Factory("yourmodelname")
              .setLocalFullPathFile("sdfullpathname")
              .create()
     ```

2. 根据模型创建推理器。

   ```java
   "Java"
   final MLModelExecutorSettings settings = new MLModelExecutorSettings.Factory(localModel).create();
   final MLModelExecutor modelExecutor = MLModelExecutor.getInstance(settings);
   // 调用模型推理，实现细节见下节模型推理；Bitmap待处理的图片。
   executorImpl(modelExecutor, bitmap);
   ```

   ```javascript
   "Kotlin"
   val settings = MLModelExecutorSettings.Factory(localModel).create()
   val modelExecutor = MLModelExecutor.getInstance(settings)
   //调用模型推理，实现细节见下节模型推理；Bitmap待处理的图片。
   executorImpl(modelExecutor, bitmap)
   ```

方式二：加载并初始化远程模型。

加载远程模型时需先判断远程模型是否已经下载完成：

```java
"Java"
final MLCustomRemoteModel remoteModel =new MLCustomRemoteModel.Factory("yourmodelname")
.create();
MLLocalModelManager.getInstance()
.isModelExist(remoteModel)
.addOnSuccessListener(new OnSuccessListener<Boolean>() {
    @Override
    public void onSuccess(Boolean isDownload) {
        if (isDownload) {
            final MLModelExecutorSettings settings =
                new MLModelExecutorSettings.Factory(remoteModel).create();
            final MLModelExecutor modelExecutor = MLModelExecutor.getInstance(settings);
            executorImpl(modelExecutor, bitmap);
        }
    }
})
.addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        // 异常处理。
    }
});
```

```javascript
"Kotlin"
val remoteModel = MLCustomRemoteModel.Factory("yourmodelname")
         .create()
MLLocalModelManager.getInstance()
         .isModelExist(remoteModel)
         .addOnSuccessListener {isDownload ->
if (isDownload) {
                 val settings = MLModelExecutorSettings.Factory(remoteModel).create()
                 val modelExecutor: MLModelExecutor
                 try {
                     modelExecutor = MLModelExecutor.getInstance(settings)
                     executorImpl(modelExecutor, bitmap)
                 } catch (e: MLException) {
                     e.printStackTrace()
                 }
             }
         }
.addOnFailureListener {
// 异常处理。
         }
```

方式三：混合加载本地和远程模型。推荐您使用这种方式，此方法可以确保当远程模型未下载时加载本地模型。

```java
"Java"
localModel = new MLCustomLocalModel.Factory("localModelName")
.setAssetPathFile("assetpathname")
.create();
remoteModel =new MLCustomRemoteModel.Factory("yourremotemodelname").create();
MLLocalModelManager.getInstance()
// 判断远程模型是否存在。
.isModelExist(remoteModel)
.addOnSuccessListener(new OnSuccessListener<Boolean>() {
    @Override
    public void onSuccess(Boolean isDownloaded) {
        MLModelExecutorSettings settings;
        // 如果远程模型存在，优先加载本地已有的远程模型，否则加载本地已有的本地模型。
        if (isDownloaded) {
            settings = new MLModelExecutorSettings.Factory(remoteModel).create();
        } else {
            settings = new MLModelExecutorSettings.Factory(localModel).create();
        }
        final MLModelExecutor modelExecutor = MLModelExecutor.getInstance(settings);
        executorImpl(modelExecutor, bitmap);
    }
})
.addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        // 异常处理。
    }
});
```

```javascript
"Kotlin"
localModel = MLCustomLocalModel.Factory("localModelName")
         .setAssetPathFile("assetpathname")
         .create()
val remoteModel = MLCustomRemoteModel.Factory("yourremotemodelname").create()
MLLocalModelManager.getInstance() // 判断远程模型是否存在。
         .isModelExist(remoteModel)
         .addOnSuccessListener {isDownloaded ->
val settings: MLModelExecutorSettings
             // 如果远程模型存在，优先加载本地已有的远程模型，否则加载本地已有的本地模型。
             settings = if (isDownloaded) {
                 MLModelExecutorSettings.Factory(remoteModel).create()
             } else {
                 MLModelExecutorSettings.Factory(localModel).create()
             }
             val modelExecutor: MLModelExecutor
             try {
                 modelExecutor = MLModelExecutor.getInstance(settings)
                 executorImpl(modelExecutor, bitmap)
             } catch (e: MLException) {
                 e.printStackTrace()
             }
         }
.addOnFailureListener {
// 异常处理。
         }
```

## 模型推理器进行推理

本章示例中的"executorImpl"方法为模型推理的详细流程，声明如下：

```screen
"Java"
void executorImpl(final MLModelExecutor modelExecutor, Bitmap bitmap)
```

```screen
"Kotlin"
fun executorImpl(modelExecutor: MLModelExecutor?, bitmap: Bitmap?) {}
```

以下示例会借助"executorImpl"方法向您详细演示推理器调用您的自定义模型推理的整个过程，此方法内主要包含如下关键处理流程：

1. 设置输入输出格式。 您需要知道您模型的输入输出格式。通过[MLModelInputOutputSettings.Factory](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlmodelinputoutputsettings-factory-0000001052785394)把输入输出格式设置到模型推理器。比如，一个图片分类模型的输入格式为一个float类型的1x224x224x3数组（表示只推理一张大小为224x224的三通道 (RGB)图片），输出格式为一个长度为1001的float型列表（每个值表示该图片经模型推理后1001个类别中各类别的可能性）。对于此模型，请您按照以下方式设置输入输出格式：

   ```screen
   "Java"
   MLModelInputOutputSettings inOutSettings = new MLModelInputOutputSettings.Factory()
       .setInputFormat(0, MLModelDataType.FLOAT32, new int[] {1, 224, 224, 3})
       .setOutputFormat(0, MLModelDataType.FLOAT32, new int[] {1, 1001})
       .create();
   ```

   ```screen
   "Kotlin"
   val inOutSettings : MLModelInputOutputSettings = MLModelInputOutputSettings.Factory()
            .setInputFormat(0, MLModelDataType.FLOAT32, intArrayOf(1, 224, 224, 3))
            .setOutputFormat(0, MLModelDataType.FLOAT32, intArrayOf(1, 1001))
            .create()
   ```

2. 把图片数据输入到推理器。 注意
   >
   > 当前版本MindSpore生成的模型使用的数据格式与tflite类型的模型使用的数据格式相同，均为NHWC，caffe类型的模型使用的数据格式为NCHW。若您需要将模型由caffe转换到MindSpore，请设置为NHWC格式。如下NHWC示例：1*224*224*3表示一张（batch N），大小为224（height H）*224（width W），3通道（channels C）的图片。

   ```java
   "Java"
   private void executorImpl(final MLModelExecutor modelExecutor, Bitmap bitmap){
       // 准备输入数据。
       final Bitmap inputBitmap = Bitmap.createScaledBitmap(srcBitmap, 224, 224, true);
       final float[][][][] input = new float[1][224][224][3];
       for (int i = 0; i < 224; i++) {
           for (int j = 0; j < 224; j++) {
               // batchNum参数由用户传入。
               int pixel = inputBitmap.getPixel(i, j);
               input[batchNum][j][i][0] = (Color.red(pixel) - 127) / 128.0f;
               input[batchNum][j][i][1] = (Color.green(pixel) - 127) / 128.0f;
               input[batchNum][j][i][2] = (Color.blue(pixel) - 127) / 128.0f;
           }
       }
       MLModelInputs inputs = null;
       try {
           inputs = new MLModelInputs.Factory().add(input).create();
           // 若模型需要多路输入，您需要多次调用add()以便图片数据能够一次输入到推理器。
       } catch (MLException e) {
           // 处理输入数据格式化异常。
       }

   // 执行推理。您可以通过"addOnSuccessListener"来监听推理成功，在"onSuccess"回调中处理推理成功。同时，可以通过"addOnFailureListener"来监听推理失败，在"onFailure"中处理推理失败。
       modelExecutor.exec(inputs, inOutSettings).addOnSuccessListener(new OnSuccessListener<MLModelOutputs>() {
           @Override
           public void onSuccess(MLModelOutputs mlModelOutputs) {
               float[][] output = mlModelOutputs.getOutput(0);
                   // 这里推理的返回结果在output数组里，可以进一步处理。
                   }
           }).addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // 推理异常。
           }
       });
   }
   ```

> 注意
>
> 关于模型的安全性问题：
>
> 无论是通过本地加载或远程加载的方式来托管您的模型，ML Kit都会将您的模型存储在本地，这也意味着您的模型存在被他人获取到的可能，请您了解此风险。
