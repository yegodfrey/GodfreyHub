# 开通服务

使用ML Kit云侧服务需要开发者在AppGallery Connect上打开ML Kit服务开关，下面提供两种方式开通服务：

## 在开发者联盟打开服务开关

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)后，点击并进入右上角的"[管理中心](https://developer.huawei.com/consumer/cn/console)"。
2. 点击左侧菜单栏"我的API"，选择您要开通服务的项目，再点击"申请新的HMS API服务"，进入HMS API库的详情页面。
3. 在HMS API库的详情页面，选择"AI > 机器学习服务"，进入机器学习服务的页面。点击"启用"开关，启用机器学习服务。
4. 启用成功之后，在"HMS API服务 > 我的API"中可以看到当前项目下的已启用的API服务列表。

## 在AppGallery Connect打开服务开关

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，点击"我的项目"，选择您要开通机器学习服务的项目。
2. 在项目设置菜单内，打开"API管理"页面，在"构建"区域内找到并打开机器学习服务开关。
