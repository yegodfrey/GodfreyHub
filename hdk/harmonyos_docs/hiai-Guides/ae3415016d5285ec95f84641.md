# 操作流程

> 注意
>
> * model_run_tool开启Profiling并进行推理，只在当次推理生效。
> * model_run_tool不支持任何并发场景使用。

1. 下载[Tools工具](https://developer.huawei.com/consumer/cn/doc/hiai-Library/tools-download-0000001060044334)并解压。将"tools/tools_sysdbg"目录下的所有文件，PUSH到手机环境中，放在"/data/local/tmp"目录下（必须放到/"data/local/tmp"或其子目录下）。
2. 添加动态链接库路径，与步骤1中存放路径保持一致。执行命令：export LD_LIBRARY_PATH={步骤1的so存放路径}。
3. 添加model_run_tool和data_proc_tool的执行权限。执行命令：chmod +x model_run_tool data_proc_tool。
4. 执行model_run_tool（请参见[model_run_tool参数说明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/parameter-description-0000001053445668#section472611403596)）完成推理并生成Profiling数据。
5. 执行data_proc_tool（请参见[data_proc_tool参数说明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/parameter-description-0000001053445668#section69861250185912)），获取Profiling数据并解析。

   当开启Profiling时，生成模型性能数据表和算子性能数据表。模型性能数据表命名格式：模型名_日期_时间_model.csv，记录了模型加载、推理和卸载的性能数据，文件内容请参见[模型性能数据表参数说明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/parameter-description-0000001053445668#section414113715014)。算子性能数据表命名格式为：模型名_日期_时间_op.csv，记录了各算子计算的性能数据，文件内容请参见[算子性能数据表参数说明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/parameter-description-0000001053445668#section12282850524)。

> 说明
>
> * 当前工具暂未支持DDK侧异构，仅提供Rom侧Profiling能力。
