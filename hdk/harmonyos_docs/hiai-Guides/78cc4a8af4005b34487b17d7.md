# 算子包安装

执行算子工程的编译时，编译结果会自动部署到算子包安装目录下。

1. 自定义算子包安装。

   <br />

   算子编译完成后，会自动将算子交付件安装到DDK指定目录，开发者无需关注。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150624.26031375236222267378532289183719:50001231000000:2800:1F8E95C896FA35EE426732C7CA03CBD93267EEBEA2192B377DCECB5F21E1C41B.png)  
   自定义算子包默认安装路径为${DDK_INSTALL_PATH}/tools/platform。

   <br />

2. 安装后的目录结构如下所示：

   <br />

   ```
   platform                            // 平台插件目录
   ├── kirin9020                       // Kirin AI处理器类型
   │   ├── config
   │   │   └── npu_custom_opinfo.json  // 算子信息库
   │   ├── lib64
   │   │   └── libcustom_op.so         // host侧二进制文件
   │   ├── ops
   │   │   └── impl
   │   │       ├── custom              // kernel交付件
   │   │       │   ├── add_custom.cpp
   │   │       │   ├── add_custom.py
   │   │       │   └── op_proto.h
   │   │       └── impl
   │   └── simulator
   └── README.md
   ```

   <br />
