# 合作案例：StorySign

**智慧科技照亮未来特殊教育**

## StorySign简介

StorySign是一款听障儿童阅读识字应用，支持精选儿童经典书籍的手语转译，让聋哑儿童也可以更轻松地享受阅读乐趣，将更多听障家庭的亲子阅读互动变为可能，为听障识字教育带来创新性变革。

## 核心痛点

对于幼年学习者而言，阅读不仅是必须掌握的重要技能，更是他们识字的重要途径。如今，绝大多数儿童主要通过聆听老师和父母的讲解进行阅读学习和识字，然而，世界上还有3.2亿聋哑儿童，因为听觉的缺失或受损，在阅读识字时面临着重重障碍。其中，九成聋哑儿童出生在听力正常的家庭，这意味着他们的父母并不通手语，因此，他们也难以对自己的孩子进行识字教学，亲子阅读互动更是难上加难。

**手语教师数量严重不足：**面对着数量庞大的聋哑幼年初学者，手语教师严重短缺的问题是长期存在的。

**父母不通手语：**九成聋哑儿童的父母听力正常，不通手语，因此无法对自己的孩子进行阅读识字教学。

**数字化教育资源失衡：**现有的数字教育资源依然主要聚焦于主流有声教学，聋哑学习者的数字学习资源和方式选择非常有限。

## 解决方案

HUAWEI HiAI联合非营利组织"欧洲聋哑人联盟"(European Union for the Deaf)、Penguin和动画巨头Aardman联合开发了免费的阅读手语转译软件StorySign，将手机变为听障儿童手语学习和阅读识字的最佳搭档。StorySign精选儿童经典阅读书籍，支持七国语言的识别及其手语转译，用户可根据自己的需求进行选择。打开应用界面，将手机摄像头对着书页，即可快速识别文本，只需点击单词即可翻译为手语。

**自动校正手机检测画面角度：** StorySign借助HUAWEI HiAI Engine的文档检测校正能力，能够有效识别并校正手机所检测到的书页画面。即使手机和书页的相对角度不佳，也能使所检测到的书页画面在手机上变得规整而易于查看，让后续的文本识别更容易、更准确。

**自动识别七国语言** **：** HUAWEI HiAI Engine的通用文字识别能力支持StorySign进行多国语言识别，令其可快速准确提取书页上的各国文字内容并将之翻译成手语。同时，它也支持多国手语翻译，用户还可以选择自己偏好，选择英国、法国、意大利等国家的手语种类。

**StorySign：**

惠普3.2亿听障儿童家庭，随时随地享受阅读和识字的乐趣，为听障识字教育带来创新性变革。

听障儿童和听力正常的父母可以以StorySign为媒介，共同享受阅读时间，听障儿童家庭也可以沉浸于亲子阅读互动的乐趣。
