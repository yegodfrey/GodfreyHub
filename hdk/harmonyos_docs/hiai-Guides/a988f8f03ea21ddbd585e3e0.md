# 集成模型V1接口

模型推理集成流程包含模型预处理和模型推理。DDK提供了同步和异步接口，应用开发者可根据实际需求选择使用方式。

本节阐述同步和异步模式下单模型的使用，从流程上分别阐述每个步骤在DDK层，JNI层以及应用层的实现和调用，具体代码参见[图像分类-Android Studio示例代码](https://developer.huawei.com/consumer/cn/doc/hiai-Examples/sample-code-0000001052989807#section1597885319308)。接口参见[模型管家V1接口](https://developer.huawei.com/consumer/cn/doc/hiai-References/mode-infer-overview-0000001053110730)。

## 模型预处理

模型预处理主要功能如下：

* 获取CANN DDK版本，判断是否支持NPU。
* 判断离线模型是否适合在当前CANN版本上运行。
* OM模型不兼容当前CANN版本时，通过模型推理中的在线编译接口来尝试版本兼容。

### JNI层模型加载

* **原始离线模型模型加载**

  JNI层模型兼容性处理通过获取CANN版本号以及模型兼容性检查接口、在线编译接口来完成判断输入的OM模型能否运行在当前终端NPU上。主要步骤为：

1. 创建AiModelMngerClient对象。
2. 创建AiModelBuilder对象。
3. 获取Membuffer，使用上述builder对象的[InputMemBufferCreate](https://developer.huawei.com/consumer/cn/doc/hiai-References/inputmem-void-0000001052490747)函数，输入离线模型buffer。
4. 调用AiModelDescription对象的[SetModelBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/setmodelbuffer-0000001052689455)函数进行设置。
5. 调用AiModelMngerClient对象的[CheckModelCompatibility](https://developer.huawei.com/consumer/cn/doc/hiai-References/checkmodel-0000001052609428)函数进行兼容性检查。
6. 判断是否满足兼容性，如果满足则加载模型调用步骤1中创建Client的Load接口；如果不满足，则返回失败。
7. 调用[GetModelIOTensorDim](https://developer.huawei.com/consumer/cn/doc/hiai-References/getmodel-0000001052969435)函数获取模型的输入输出shape，通过类AiTensor中的[Init](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001052570723)函数初始化输入张量"inputTensors"和输出张量"outputTensors"。

JNI层代码可参见[图像分类-Android Studio示例代码](https://developer.huawei.com/consumer/cn/doc/hiai-Examples/sample-code-0000001052989807#section1597885319308)"Demo_Source_Code\hiaiv1_inference\src\main\jni\ClassifyJni.cpp"文件Java_com_huawei_demo_utils_ModelManager_loadModel函数。

* **设置精度配置选项（可选）**

模型的推理性能和推理精度是衡量推理框架的重要指标。在使用CPUCL做模型推理时，支持使用FP32和FP16的精度范围做模型推理。可调用AiModelDescription对象的[SetPrecisionMode](https://developer.huawei.com/consumer/cn/doc/hiai-References/setprecisionmode-0000001057514225)函数进行精度配置选项的设置。

## 模型推理

> 说明
>
> 如模型不更换，则首次编译加载完成后可多次推理，即一次编译加载，多次推理。

### 同步模式

同步模式下的模型推理性能分析可以使用Profiling工具，具体的使用请参见[系统调试工具](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-0000001053126910)。

* 应用层实现

1. 调用"getPixels"函数，从图片中获取模型输入。
2. 调用JNI层"runModelSync"函数，进行模型推理。
3. 调用函数env -> GetByteArrayElements(jbuffer, nullptr)和env -> GetArrayLength(jbuffer)获取应用层输入数据和大小。
4. 完成推理后，调用"postProcess"函数进行后处理，输出结果到界面。

实现代码参见"Demo_Source_Code\app\src\main\java\com\huawei\demo\view\ImageClassifyActivity.java"文件中的"runModel"函数，该函数会调用ModelManager.java文件中的"runModelSync"函数。

* JNI层实现

1. 调用函数env -> GetByteArrayElements(jbuffer, nullptr)和env -> GetArrayLength(jbuffer)获取应用层输入数据和大小。
2. （可选）若您需要NPU算子库动态升级能力需要使用计算能力增强功能，请调用接口，具体操作请参见[NPU算子库动态升级集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/integration-0000001105764366)。
3. 将应用层传入的dataBuff通过函数"memmove"拷贝到"inputTensors"。
4. 调用类AiModelMngerClient中的[Process](https://developer.huawei.com/consumer/cn/doc/hiai-References/process-0000001051809424)进行模型推理。
5. 从"outputTensors"中取出推理结果。

JNI实现代码参见"Demo_Source_Code\hiaiv1_inference\src\main\jni\ClassifyJni.cpp"文件中的Java_com_huawei_demo_utils_ModelManager_runModelSync函数。

### 异步模式

* 应用层实现

1. 调用"getPixels"函数，从图片中获取模型输入。
2. 新建并注册ModelManagerListener监听器对象。
3. 调用JNI层"runModelAsync"函数，完成异步模式下模型运行。

实现代码参见"Demo_Source_Code\app\src\main\java\com\huawei\demo\view\ImageClassifyActivity.java"文件中的"runModel"函数，该函数会调用ModelManager.java文件中的函数"runModelAsync"。

* JNI层实现 异步模式下模型运行过程和同步相同，只是在调用类AiModelMngerClient中的[Process](https://developer.huawei.com/consumer/cn/doc/hiai-References/process-0000001051809424)函数时，注意使用的是异步模型管理引擎调用。

  异步模式下运行模型后的后处理操作是通过回调函数[OnProcessDone](https://developer.huawei.com/consumer/cn/doc/hiai-References/onprocessdone-0000001052809455)实现的。如果要使用异步模型管理引擎，需要在新建AiModelMngerClient对象时，调用[Init](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001052570723)函数，初始化ModelManagerListener监听器对象。实现代码参见"Demo_Source_Code\hiaiv1_inference\src\main\jni\ClassifyJni.cpp"文件中的Java_com_huawei_demo_utils_ModelManager_runModelAsync函数。

### 涉及的接口

DDK模型推理所使用到的主要接口函数原型如下。

```screen
AIStatus Init(shared_ptr<AiModelManagerClientListener> listener);
AIStatus CheckModelCompatibility(AiModelDescription &pmodelDesc, bool &pisModelCompatibility);
AIStatus Load(vector<shared_ptr<AiModelDescription>> &model_desc);
AIStatus GetModelIOTensorDim(const string& model_name, vector<TensorDimension>& input_tensor, vector<TensorDimension>& output_tensor);
AIStatus Process(AiContext &context, vector<shared_ptr<AiTensor>> &input_tensor, vector<shared_ptr<AiTensor>> &output_tensor, uint32_t timeout, int32_t &iStamp);
AIStatus UnLoadModel();
```

具体参数含义请参见[模型管家V1接口](https://developer.huawei.com/consumer/cn/doc/hiai-References/mode-infer-overview-0000001053110730)。

设置模型推理优先级和取消模型推理任务用户可根据需要自行设置。

* 设置模型推理优先级请参见[SetModelPriority](https://developer.huawei.com/consumer/cn/doc/hiai-References/setmodelpriority-0000001058722086)，默认值为PRIORITY_LOW，本接口在模型加载后、模型执行前调用。
* 取消模型推理任务请参见[Cancel](https://developer.huawei.com/consumer/cn/doc/hiai-References/cancel-0000001057482169)。
