# Coyote使用HUAWEI ML Kit打造GPS\&汽车辅助驾驶系统

#### Coyote简介

Coyote是一款新一代辅助驾驶应用，能够为用户提供实时的通行指导以及交通事故和违章的提前预警。通过这款应用，用户可以实时了解当前道路的限速情况，避免超速被罚款。同时，Coyote还可以通过对当前交通状况及大数据的判断设定出最优路线，强化GPS的功能。另外，凭借着对道路三十公里内的数据判断，Coyote能够帮助用户预测路途中可能会遇到的干扰以及各种突发状况，例如，交通堵塞、事故、抓拍摄像头、急转弯、禁止车辆等，提醒用户调整驾驶方式。  

#### 业务挑战

随着各国汽车保有量的不断增加，通勤问题日益凸显，如何高效地出行成为了日常生活中绕不开的话题。

* 当道路上发生交通事故时，例如，汽车抛锚、多车相撞等，应用需要实时向用户发送警告消息，让用户及时避险。
* 导航应用对时效性要求很高，录取不同语音消息的工作非常艰巨，对随时可能发生的路名更改和突发状况等情况难以做到及时更新与播报。  

#### 解决方案

凭借HUAWEI ML Kit高性能的语音合成服务，Coyote实现了实时道路指导与提醒，帮助用户提高行车安全。

* 实现提前预警，支持大量路牌、交通警示信息广播。

* 运用ML Kit语音合成服务，能够对道路信息的变更进行实时播报，提高时效性。

#### 合作受益

* Coyote Coyote通过ML Kit语音合成服务可以快速播报道路信息，让用户及时了解道路标志、限速、行车方向、交通干扰等状况，减少软件中的制作成本。

* Coyote用户 通过播报语音消息，用户可以及时获取到应用传递的道路信息，迅速知晓突发状况，在短时间内做出反应，并调整驾驶计划。

HUAWEI ML Kit除了语音合成外，还支持文本识别、对象检测与跟踪、图像分类、地标识别等服务，可参见[机器学习服务](https://developer.huawei.com/consumer/cn/hms/huawei-mlkit)获取更多详细介绍和Demo。
