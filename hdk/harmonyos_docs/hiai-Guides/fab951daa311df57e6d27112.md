# 开发指南

## 应用开发

### 必须导入类

1. 在使用视频封面API时，将实现视频封面的相关的类添加至工程。

   ```screen
   import com.huawei.hiai.vision.visionkit.common.Video; // 加载Video类
   import com.huawei.hiai.vision.visionkit.image.detector.AEVideoResult; // 加载审美引擎静态封面结果类
   import com.huawei.hiai.vision.image.detector.AestheticsScoreDetector; // 加载审美引擎detector类
   import com.huawei.hiai.vision.common.VisionBase; // 加载连接服务的静态类
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
   import com.huawei.hiai.vision.visionkit.image.detector.AEModelConfiguration;
   import com.google.gson.Gson;
   ```

### 开发

1. 利用VisionBase静态类进行初始化，异步获取服务的连接。

   ```screen
   VisionBase.init(MainActivity.this, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. 定义AestheticsScoreDetector实例，将此应用的Context当做入参。

   ```screen
   AestheticsScoreDetector aestheticsScoreDetector = new AestheticsScoreDetector(MainActivity.this);
   ```

3. 视频选取静态封面API。
   1. 配置引擎参数（不配置取默认参数）。

      ```screen
      AEModelConfiguration aeModelConfiguration = new AEModelConfiguration();
      aestheticsScoreDetector.setAEModelConfiguration(aeModelConfiguration);
      ```

   2. 定义video。

      ```screen
      Video video = new Video();
      ```

   3. 将需选取静态封面的视频URI授权并放入video中。

      ```screen
      grantUriPermission("com.huawei.hiai", videoURI, Intent.FLAG_GRANT_READ_URI_PERMISSION);
      video.setPath(videoURI);
      ```

   4. 定义静态封面结果结构体AEVideoResult。

      ```screen
      AEVideoResult outputData = new AEVideoResult();
      ```

   5. 调用getCover()方法得到视频静态封面。

      ```screen
      int resultCode = mAestheticsScoreDetector.getCover(new String[] {video.getPath()}, outputData,
          ImageDetectType.TYPE_IMAGE_GET_VIDEO_STATIC_COVER, null);
      ```

4. 视频选取动态封面API。
   1. 配置引擎参数（不配置取默认参数）。

      ```screen
      AEModelConfiguration aeModelConfiguration = new AEModelConfiguration();
      aeModelConfiguration.getLiveCoverConf().setLiveCoverMaxLen(3);
      aestheticsScoreDetector.setAEModelConfiguration(aeModelConfiguration);
      ```

   2. 定义video。

      ```screen
      Video video = new Video();
      ```

   3. 将需选取动态封面的视频URI授权并放入video中。

      ```screen
      grantUriPermission("com.huawei.hiai", videoURI, Intent.FLAG_GRANT_READ_URI_PERMISSION);
      video.setPath(videoURI);
      ```

   4. 定义动态封面结果结构体AEVideoResult。

      ```screen
      AEVideoResult outputData = new AEVideoResult();
      ```

   5. 调用getCover()方法得到视频动态封面。

      ```screen
      int resultCode = mAestheticsScoreDetector.getCover(new String[] {video.getPath()}, outputData,
          ImageDetectType.TYPE_IMAGE_GET_VIDEO_LIVE_COVER, null);
      ```
