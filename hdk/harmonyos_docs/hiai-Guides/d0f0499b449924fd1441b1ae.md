# 视频流检测模式多次识别场景开发

使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见对象检测和跟踪模块示例代码，大致流程如下：

1. 定义一个Handler，用于接收开始或停止消息：

   ```
   Boolean mlsNeedToDetect = true;
   final int STOP_PREVIEW = 1;
   final int START_PREVIEW = 2;
   private Handler mHandler = new Handler() {
       @Override
       public void handleMessage(Message msg) {
           super.handleMessage(msg);
           switch (msg.what) {
               case START_PREVIEW:
                   mlsNeedToDetect = true;
                   // 开始检测相关代码
                   break;
               case STOP_PREVIEW:
                   mlsNeedToDetect = false;
                   // 停止检测相关代码
                   break;
               default:
                   break;
           }
       }
   };
   ```

2. 在结果处理器的transactResult方法中，加入条件判断以及停止检测代码。

   ```
   public class ObjectAnalyzerTransactor implements MLAnalyzer.MLTransactor<MLObject> {
       @Override
       public void destroy() {
           // 检测结束回调方法，用于释放资源等。
       }
       @Override
       public void transactResult(MLAnalyzer.Result<MLObject> result) {
           SparseArray<MLObject> items = result.getAnalyseList();
           for (int i = 0; i < items.size(); i++) {
               if (items.valueAt(i).getTypeIdentity() == MLObject.TYPE_FOOD) {
                   // 检测到特定内容时，停止检测
                   mlsNeedToDetect = true;
                   mHandler.sendEmptyMessage(STOP_PREVIEW);
               }
           }
       }
   }
   ```

3. 在处理完成后，需要重新检测时，调用开始检测代码。

   ```
   mHandler.sendEmptyMessage(START_PREVIEW);
   ```
