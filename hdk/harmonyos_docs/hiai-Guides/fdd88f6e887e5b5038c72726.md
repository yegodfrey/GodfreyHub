# 手势识别

#### 服务介绍

手势识别服务提供手部关键点识别能力和手势识别能力。手部关键点识别能力支持识别21个手部关键点（包括每个手指指尖、关节点，以及手腕点），并返回关键点的位置数据。手势识别能力能够检测并返回图片或视频中的所有手部矩形框位置，以及手势的类别和置信度，支持识别14种手势，包括点赞、差评、OK、握拳、单手比心、数 字1-9。手部关键点识别能力与手势识别能力都支持静态图片识别、实时视频流识别。

#### 应用场景

手部关键点识别服务在生活中有广泛应用。例如，集成了手部关键点识别能力后，在进行艺术创作时，可以将检测到的手部关键点转换为2D模型，并将生成的手部模型同步到人物模型中，制作出生动的2D动画。在拍摄短视频时，通过识别手部动态轨迹生成特效，进行手指趣味游戏，使视频增加创意和互动性。另外，集成了手势识别能力后，通过识别手势调用指令，无需手动操作即可实现对智能家电的控制，提高人机交互的效率。  

#### 注意事项

|能力|手部遮挡范围|佩戴手套|
|:------|:-----|:---|
|手部关键点识别|不超过50%|不支持|
|手势识别|不超过20%|不支持|

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/handgesturerecognition-sdk-0000001051377295)。  

#### 手部关键点识别能力

#### 静态图片识别

1. 创建手部关键点分析器。  

   ```
   "Java"
   MLHandKeypointAnalyzerSetting setting = new MLHandKeypointAnalyzerSetting.Factory()
   // MLHandKeypointAnalyzerSetting.TYPE_ALL=表示所有结果都返回。
   // MLHandKeypointAnalyzerSetting.TYPE_KEYPOINT_ONLY表示只返回手部关键点信息。
   // MLHandKeypointAnalyzerSetting.TYPE_RECT_ONLY表示只返回手掌区域信息。
       .setSceneType(MLHandKeypointAnalyzerSetting.TYPE_ALL) 
       // 设置同一张图片中最多支持检测的手部区域个数。默认最多支持10个手部区域信息检测。
       .setMaxHandResults(1)
       .create();
   MLHandKeypointAnalyzer analyzer =MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer(setting);
   ```

   ```
   "Kotlin"
   var setting = MLHandKeypointAnalyzerSetting.Factory() // MLHandKeypointAnalyzerSetting.TYPE_ALL=表示所有结果都返回。
            // MLHandKeypointAnalyzerSetting.TYPE_KEYPOINT_ONLY表示只返回手部关键点信息。
            // MLHandKeypointAnalyzerSetting.TYPE_RECT_ONLY表示只返回手掌区域信息。
            .setSceneType(MLHandKeypointAnalyzerSetting.TYPE_ALL) // 设置同一张图片中最多支持检测的手部区域个数。默认最多支持10个手部区域信息检测。
            .setMaxHandResults(1)
            .create()
   var analyzer = MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer(setting)
   ```

2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象用于分析器检测图片，支持的图片格式包括：jpg/jpeg/png，建议图片尺寸不小于320\*320像素，不大于1920\*1920像素。  

   ```
   "Java"
   MLFrame frame = MLFrame.fromBitmap(bitmap);
   ```

   ```
   "Kotlin"
   var frame = MLFrame.fromBitmap(bitmap)
   ```

3. 调用同步或异步方法进行手部关键点检测。检测结果除了包含每个关键点的坐标信息外，还包含每个点的置信度值，可以基于置信度值过滤误识别的无效手部关键点，实际应用中可根据对误识别的容忍程度，设置阙值灵活应用。
   * 异步方法示例代码：  

     ```
     "Java"
     Task<List<MLHandKeypoints>> task = analyzer.asyncAnalyseFrame(frame);
     task.addOnSuccessListener(new OnSuccessListener<List<MLHandKeypoints>>() {
         @Override
         public void onSuccess(List<MLHandKeypoints> results) {
             // 检测成功。
         }
     }).addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
             // 检测失败。
         }
     });
     ```

     ```
     "Kotlin"
     val task = analyzer!!.asyncAnalyseFrame(frame)
     task.addOnSuccessListener {
          // 检测成功。
     }.addOnFailureListener {
          // 检测失败。
      }
     ```

   * 同步方法示例代码：  

     ```
     "Java"
     SparseArray<MLHandKeypoints> mlHandKeypointsSparseArray = analyzer.analyseFrame(frame);
     for (int i = 0; i < mlHandKeypointsSparseArray.size(); i++) {
         // 检测结果处理。
     }
     ```

     ```
     "Kotlin"
     val mlHandKeypointsSparseArray = analyzer!!.analyseFrame(frame)
     for (i in 0 until mlHandKeypointsSparseArray.size()) {
          // 检测结果处理。
      }
     ```

4. 检测完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {
       analyzer.stop();
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        analyzer!!.stop()
   }
   ```

#### 视频流识别

开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按照上文中静态图像本地检测的方法进行手部关键点识别。如果开发者调用的是同步识别接口，也可以使用SDK内置的[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)类实现视频流本地关键点识别，示例代码如下：

1. 创建手部关键点分析器。  

   ```
   "Java"
   // 1.创建自定义分析器。
   MLHandKeypointAnalyzerSetting setting = new MLHandKeypointAnalyzerSetting.Factory()
   // MLHandKeypointAnalyzerSetting.TYPE_ALL表示所有结果都返回。
   // MLHandKeypointAnalyzerSetting.TYPE_KEYPOINT_ONLY表示只返回手部关键点信息。
   // MLHandKeypointAnalyzerSetting.TYPE_RECT_ONLY表示只返回手掌区域信息。
       .setSceneType(MLHandKeypointAnalyzerSetting.TYPE_ALL)
       // 设置同一张图片中最多支持检测的手部区域个数。默认最多支持10个手部区域信息检测。
       .setMaxHandResults(1)
       .create();
   MLHandKeypointAnalyzer analyzer =MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer(setting);
   ```

   ```
   "Kotlin"
   // 1.创建自定义分析器。
   val setting = MLHandKeypointAnalyzerSetting.Factory() // MLHandKeypointAnalyzerSetting.TYPE_ALL表示所有结果都返回。
            // MLHandKeypointAnalyzerSetting.TYPE_KEYPOINT_ONLY表示只返回手部关键点信息。
            // MLHandKeypointAnalyzerSetting.TYPE_RECT_ONLY表示只返回手掌区域信息。
            .setSceneType(MLHandKeypointAnalyzerSetting.TYPE_ALL) // 设置同一张图片中最多支持检测的手部区域个数。默认最多支持10个手部区域信息检测。
            .setMaxHandResults(1)
            .create()
   val analyzer = MLHandKeypointAnalyzerFactory.getInstance().getHandKeypointAnalyzer(setting)
   ```

2. 开发者创建识别结果处理类"HandKeypointTransactor"，该类实现[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>接口，使用此类中的[transactResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216#section7411382071)方法获取检测结果并实现具体业务。检测结果除了包含每个手指点的坐标信息外，还包括手掌置信度，以及每个点的置信度值，可以基于置信度值过滤误识别的无效手掌，实际应用中可根据对误识别的容忍程度，设置阙值灵活应用。  

   ```
   "Java"
   public class HandKeypointTransactor implements MLAnalyzer.MLTransactor<MLHandKeypoints> {
       @Override
       public void transactResult(MLAnalyzer.Result<MLHandKeypoints> results) {
           SparseArray<MLHandKeypoints> analyseList = results.getAnalyseList();
           // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
           // 不可调用ML Kit提供的其他检测相关接口。
       }
       @Override
       public void destroy() {
           // 检测结束回调方法，用于释放资源等。
       }
   }
   ```

   ```
   "Kotlin"
   class HandKeypointTransactor : MLTransactor<MLHandKeypoints?> {
        override fun transactResult(results: MLAnalyzer.Result<MLHandKeypoints?>) {
            val analyseList = results.analyseList
            // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
            // 不可调用ML Kit提供的其他检测相关接口。
        }

        override fun destroy() {
            // 检测结束回调方法，用于释放资源等。
        }
    }
   ```

3. 设置识别结果处理器，实现分析器与结果处理器的绑定。  

   ```
   "Java"
   analyzer.setTransactor(new HandKeypointTransactor());
   ```

   ```
   "Kotlin"
   analyzer!!.setTransactor(HandKeypointTransactor())
   ```

4. 创建[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)，该类由ML Kit SDK提供，用于捕捉相机动态视频流并传入分析器。建议设置的相机显示尺寸不小于320\*320像素，不大于1920\*1920像素。  

   ```
   "Java"
   LensEngine lensEngine = new LensEngine.Creator(getApplicationContext(), analyzer)
       .setLensType(LensEngine.BACK_LENS)
       .applyDisplayDimension(1280, 720)
       .applyFps(20.0f)
       .enableAutomaticFocus(true)
       .create();
   ```

   ```
   "Kotlin"
   val lensEngine = LensEngine.Creator(applicationContext, analyzer)
            .setLensType(LensEngine.BACK_LENS)
            .applyDisplayDimension(1280, 720)
            .applyFps(20.0f)
            .enableAutomaticFocus(true)
            .create()
   ```

5. 调用run方法，启动相机，读取视频流，进行识别。  

   ```
   "Java"
   // 请自行实现SurfaceView控件的其他逻辑。
   SurfaceView mSurfaceView = findViewById(R.id.surface_view);
   try {
       lensEngine.run(mSurfaceView.getHolder());
   } catch (IOException e) {
       // 异常处理逻辑。
   }
   ```

   ```
   "Kotlin"
   // 请自行实现SurfaceView控件的其他逻辑。
   val mSurfaceView: SurfaceView? = findViewById(R.id.surface_view)
   try {
        lensEngine!!.run(mSurfaceView!!.holder)
    } catch (e: IOException) {
        // 异常处理逻辑。
    }
   ```

6. 检测完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {
       analyzer.stop();
   }
   if (lensEngine != null) {
       lensEngine.release();
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        analyzer.stop()
    }
   lensEngine?.release()
   ```

使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见[视频流检测模式多次识别场景开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-video-0000001050040139)。
