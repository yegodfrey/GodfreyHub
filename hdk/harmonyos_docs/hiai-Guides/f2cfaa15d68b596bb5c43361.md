# 开源声明使用指导

MLKit作为module能力被HMSCore动态加载，module模块使用开源软件声明在整体HMSCore整体开放源代码许可体现，可以从设置→HMSCore→开放源代码许可查看。

MLKit能力SDK使用开源软件的开源声明在各能力sdk中体现，在各sdk的aar包中assets/kpms-mlkit目录或assets/kpms-unpack目录以open_source_software_statment*.xml的XML文件体现。
