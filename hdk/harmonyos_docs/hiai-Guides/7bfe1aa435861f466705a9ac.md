# 迁移学习

机器学习服务提供了迁移学习能力，通过深度的机器学习和模型训练，方便您在应用程序中快速训练和生成新模型，通过此功能进行迁移学习，不仅灵活度高，同时也降低了学习成本。当前提供了图片分类和文本分类预置模型能力。  

#### 实现方法

1. 在开发模型前，您需要先准备好[HMS ToolKit](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/overview-0000001050060881)插件。
2. 您需要完成必要的迁移学习准备工作，具体请参见[AI Create](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/ai-create-0000001055252424)。
3. 完成开发准备工作并获取到模型后，开始使用模型，具体请参见[预置模型](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/image-classification-pre-trained-model-0000001055210299)。
