# CANN模型量化端到端应用指南

本章节介绍一个端到端的轻量化模型部署demo。

1. 准备训练好的Caffe、TensorFlow、ONNX等基线模型或者从[Model Zoo](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-zoo-0000001187986457)中选择合适的模型。
2. 使用Quant_INT8-8策略进行[无训练量化](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/no-training-and-quantization-0000001053126892)或[插件式量化](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/retraining-quantization-0000001052526973)。

   <br />

   量化完成后可获得由轻量化工具生成的对应模型文件（.pb、.caffemodel、.onnx）和量化参数（param）。  
   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150614.15317267338954762701268856442848:50001231000000:2800:7C919600230297824A05B133A76173CA002889E6FE8DDCDFF4E6E6597EDE6A30.png)  
   * 当前Kirin平台对外仅开放INT8-8的能力，如果有更多需求请[联系我们](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
   * 对于分类、分割或检测等高层语义任务，推荐优先使用无训练量化，操作简单可以更快速获得结果，如果精度不满足指标可再进行重训练量化。

   <br />

3. 模型转换。将轻量化工具生成的模型及量化参数转换为CANN离线模型（.om），以TensorFlow模型为例转换命令如下。

   <br />

   ```
   ./omg --model mobilenet_v2_1.0_224_frozen.pb --framework 3 --output ./mobilenet_v2 --input_shape "input:1,224,224,3" --out_nodes "MobilenetV2/Predictions/Reshape_1:0"
    --compress_conf=param
   ```

   其中mobilenet_v2_1.0_224_frozen.pb与param为[步骤2](#ZH-CN_TOPIC_0000001554319349__li32309246448)中轻量化工具输出的模型文件和量化参数。

   其他框架的模型转换示例请参考[模型转换示例](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-conversion-example-0000001053125647)。

   <br />

4. [App集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/creating-a-project-0000001052871843)。
