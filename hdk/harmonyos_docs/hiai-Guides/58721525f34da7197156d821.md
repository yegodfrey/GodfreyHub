# 业务介绍

## 业务简介

如今，我们的生活已被各种各样的信息所环绕，关键信息往往裹挟在多余、无用、琐碎的海量消息中。如何在众多的信息中快速提取出关键的信息和想要表达的核心内容，既能节省我们的有效时间，又能避免我们思维处于一种疲惫状态。为此，我们提供关键字提取API能力，以便满足快速提炼文本中心思想的开发需求。

关键字提取API提供了一个提取关键字的接口，通过该API可以在大量信息中提取出文本想要表达的核心内容，可以是具有特定意义的实体，如：人名，地点，电影等。也可以是一些基础但是在文本中属于关键性的词汇。通过该API可以对提取的关键字按照在文本中所占的权重由高到低排序。排序越靠前，权重越高，对文本的核心内容提取的更准确。

## 场景介绍

**双指按压文本弹出卡片** **：**本API可以应用于双指按压开发。从长文本中提取出能反应出其核心思想的关键词汇。用户可以通过双指按压文本，提取出里面的关键词汇，其输出顺序按照权重，由关键到相对非关键。帮助用户快速从长文本中提取出关键信息，快速阅读，也可从弹出的卡片中复制相关信息，去搜索。

## 功能特点

* **轻便：**利用本API，可以大大节省算法开发的时间，节省算法模型占用的ROM空间，让您的应用更加轻便。
* **可配置：**关键词提取个数可以由使用方控制，且提取出的关键词是按权重输出的，使用起来更有实用性。

### 功能使用限制

|功能|使用限制说明|
|:-----|:------------------------------------------------------------------------------------------------------------------|
|输入文本长度|关键字提取标题文本限制在100字以内，正文文本限制在5000字以内，关键词提取个数在20以内，文本要UTF-8格式，格式错误的不报错，但分析结果会不准确。|
|多线程调用|HUAWEI HiAI Engine支持多用户同时接入，但是不支持同一用户并发调用同一个特性，如同一个特性被同一进程同一时间多次调用，则返回系统忙错误，不同进程调用同一特性，则同一时间只有一个进程业务在处理，其他进程进入队列排队。|
