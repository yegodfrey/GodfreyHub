# 合作案例：绿幕侠

HUAWEI HiAI澎湃芯片算力，助绿幕侠一键"穿越时空"  

#### 绿幕侠简介

绿幕侠是一款实时视频抠人像的移动应用，用户在录制视频时，可以实时抠出其中的人像，随心所欲替换背景，支持人像的放大缩小和无限复制，轻松实现空间转换的创意拍摄。无需绿幕影棚和后期制作，用户在卫莎绿幕侠中就可以轻松享受拍摄大片的乐趣，做自己的导演和主角，随时随地 "穿越时空"。  

#### 核心痛点

随着互联网技术的迅速发展， 网络社交方式不断推陈出新，从形式较为单一的文字、图文和语音到视听俱佳的视频应用，视频直播、短视频和vlog近年来频繁进入大众视野并风靡全网，视频拍摄俨然成为年轻一代用户表达个性的不二选择。

作为一家人工智能计算机视觉公司，卫莎深耕图形图像处理技术，致力为用户带来更高效便捷的图片视频应用体验。通过传统图像算法和视觉深度学习神经网络的有机结合，卫莎掌握了领先业界的AI语义分割（视频抠图）技术，然而，纵有高效的算法模型，卫莎视频AI语义分割（视频抠图）技术在实践中仍面临多个商用障碍：

高昂的GPU云服务器成本：以平均每秒30帧的视频为例，视频处理成本就比图像处理成本高出近30倍。成本之高不光小型开发者无法负担，对于拥有千万量级用户的公司，云端处理视频所承担的GPU服务器成本也是鲜有公司可以承受。

端云传输的时延：一般而言，每张图片的云端传输处理时间需要2秒，当视频的每秒平均帧数为30时，每拍摄1秒视频就需要耗费至少60秒的处理时间，终端手机用户将难以接受如此漫长的视频处理等待。

用户信息安全隐患：目前绝大多数APP的复杂模型运算都需要云端协同完成，个人图像与视频数据大量存储于云端各类服务器，增加了用户的个人信息安全隐患。  

#### 解决方案

要突破GPU云服务器所带来的成本、时延和安全问题，关键在于实现终端视频抠图技术，这需要强大的终端芯片算力作为前提和保障，然而，手机芯片算力问题是目前AI应用落地的主要瓶颈。

随着CANN新型AI芯片麒麟810的重磅发布，华为自研的达芬奇架构也揭开了神秘面纱，它专用于海量AI数据处理，开放手机端侧澎湃算力，使手机可以轻松胜任各类如视频编辑、图像识别等AI任务。在由苏黎世联邦理工学院推出的AI芯片测试应用AI-Benchmark的官网榜单中，搭载麒麟810的华为nova5以33863的得分排名第一，其余机型得分在24000至27000不等。

CANN NPU芯片麒麟980搭载达芬奇架构，针对矩阵运算进行提速，大幅提升手机芯片的单位AI算力，使绿幕侠摆脱GPU云服务器依赖，在手机上就可以流畅运算实时视频抠图AI模型。CANN以超强算力赋能卫莎成功突破技术痛点，以三大优势在手机上实现绿幕侠商用落地：

零算力成本：卫莎与华为HiAI核心团队联合定位调试新型的麒麟810NPU芯片，充分调优华为芯片DDK框架，利用该芯片的强大算子，实现在手机端就能处理复杂模型的能力，节省了云端服务器成本。

零端云时延：华为芯片助力算法模型成功从云端"跑"到了移动终端，用户的视频可以手机上直接实时处理，实现零时延体验。

低安全隐患：算法模型在手机芯片离线运行，视频图片处理过程不需要使用网络，从根源上杜绝了用户信息通过网络传输造成信息泄露的隐患，让用户可以更安心地使用产品。  

#### 合作受益

绿幕侠：

创造性地在手机上解锁实时视频抠图技术，以零服务器成本和零时延的优势带来优质的视频体验。

用户：

将繁琐费时的高门槛视频技术简易化，无需绿幕和后期制作也可以轻松完成大片拍摄。

视频拍摄过程不涉及网络传输，信息安全更有保障。
