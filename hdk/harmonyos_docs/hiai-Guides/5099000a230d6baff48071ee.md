# 配置应用签名信息

> 说明
>
> * 若您在模拟器上进行调试并查看运行效果，则无需完成本章节以下步骤，具体操作请参见[使用模拟器运行应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/run_simulator-0000001053303709-V3)和[使用模拟器进行调试](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/ide_debug_emulator-0000001115721921-V3)。
> * 若您在真机上进行调试并查看运行效果，请继续完成本章节以下步骤。

## 通过手动签名方式对应用签名

1. 生成数字证书和调试Profile文件。

   为确保HarmonyOS应用的完整性，HarmonyOS通过数字证书和Profile文件来对应用进行管控，只有签名过的HAP才允许安装到设备上运行。因此，为了保证应用能够安装到调试设备上，您需要提前申请相应的调试证书与调试Profile文件。

   详细步骤如下：
   1. [生成密钥和证书请求文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/publish_app-0000001053223745-V3#section9752152162813)。
      * **密钥**：格式为.p12，包含非对称加密中使用的公钥和私钥，存储在密钥库文件中，公钥和私钥对用于数字签名和验证。
      * **证书请求文件**：格式为.csr，全称为Certificate Signing Request，包含密钥对中的公钥和公共名称、组织名称、组织单位等信息，用于向AppGallery Connect申请数字证书。
   2. [申请应用调试证书](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-manual-0000001177608893#section13331154632718)。

      **数字证书**：格式为.cer，由华为AppGallery Connect颁发，分为应用调试证书和应用发布证书。
   3. [注册调试设备](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-manual-0000001177608893#section7732152932911)。
   4. [申请调试Profile](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-debugapp-manual-0000001177608893#section1774717395304)。

      **Profile文件**：格式为.p7b，包含HarmonyOS应用的包名、数字证书信息、描述应用允许申请的证书权限列表，以及允许应用调试的设备列表（如果应用类型为Release类型，则设备列表为空）等内容，每个应用包中均必须包含一个Profile文件，分为调试Profile和发布Profile。

2. 配置签名信息。

   编译构建App需要使用到制作的密钥（.p12）文件、在AppGallery Connect中申请的证书（.cer）文件和Profile（.p7b）文件，然后在DevEco Studio中对工程进行配置。

   操作指导请参见[配置签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/publish_app-0000001053223745-V3#section280162182818)。配置时，请选择在**File > Project Structure > Project > Signing Configs > Debug**窗口中，配置工程的签名信息。

## 手动生成签名证书指纹

签名证书指纹用于校验应用的真实性，您需要根据密钥文件（.p12文件）在本地生成签名证书指纹，并在应用上架前将签名证书指纹配置到AppGallery Connect。

在生成签名证书指纹前，已通过DevEco Studio或命令行工具[生成密钥文件（.p12文件）和证书请求文件（.csr文件）](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/publish_app-0000001053223745-V3#section9752152162813)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore D:\harmony\key\myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172358.56402965995991723196703071832719:50001231000000:2800:2759A0811522E31625594217AE7BAA885D0AAA134A45DA36A3F8825708B79998.png)

* macOS
  1. 打开Terminal终端。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172358.78559159439065835204156979633277:50001231000000:2800:7D34D32FD95A40D7A89FA3771DA212868298F811B6E5C08F3442C8DEE2688EA2.png)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。<keystore-file>为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/xxxxxx/Downloads/myApplication.p12
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172358.28413821976462181163716759091114:50001231000000:2800:CBA9D21682DB0320C803553041AAF69799BEF5F7539337BBEA181D735BC228C5.png "点击放大")

## 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172358.04753365422077939197186465798683:50001231000000:2800:E553E812615884397E14D7D0BBCBD1C8107A729292E06B8E1C830A7DBFA31FD6.png)
   > 说明
   >
   > 在"项目设置"页面的"应用"区域，点击"Client Secret"后面的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172358.40525698349911691681194022618210:50001231000000:2800:18FDF853110CC165F3D8C419800E1F58672AA2B9C1DB07DBBF8E96C2297DB0EB.png)即可复制Client Secret。

4. 配置完成后，点击"保存"。
