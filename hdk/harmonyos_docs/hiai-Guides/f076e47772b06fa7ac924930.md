# 俄罗斯SOVCOMBANK通过集成HUAWEI ML Kit银行卡识别服务，轻松实现银行卡信息自动录入功能

#### Sovcombank App介绍

Sovcombank App是俄罗斯资产规模最大、利润最高银行集团之一的Sovcombank旗下的手机银行软件，专为用户提供一系列的Sovcombank服务，包括控制账户、申请贷款、查询账户详细信息等。  

#### 业务挑战

俄罗斯Sovcombank为用户提供了良好的线上银行业务，但是由于要手动输入银行卡信息，导致效率低下。在集成HUAWEI ML Kit银行卡识别服务之前，Sovcombank无法实现自动录入银行卡信息的功能。

* 银行卡号等信息需要手动输入。
* 卡号等信息较长，易出错。
* 为了提升办事效率，需要高准确度的银行卡信息识别。  

#### 解决方案

俄罗斯Sovcombank通过集成HUAWEI ML Kit银行卡识别服务，实现了银行卡信息自动录入功能，极高的准确率避免了手动输入的错误率，降低成本，提升录入效率，给予用户良好的操作体验。

* HUAWEI ML Kit银行卡识别可通过拍照识别银行卡信息录入。
* 集成过程简单，识别准确率高。
* HUAWEI ML Kit银行卡识别支持视频流15度角进行识别。

* Sovcombank 集成HUAWEI ML Kit 银行卡识别服务，识别准确率高，降低成本，提升效率。

* Sovcombank用户 银行卡信息自动识别录入，高准确率避免失误，操作体验更好。
