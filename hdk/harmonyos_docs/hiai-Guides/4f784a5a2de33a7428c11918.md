# 集成动作活体检测服务SDK

动作活体检测服务支持Full SDK集成方式，您可以参见[Full SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-sdk-0000001051070278#ZH-CN_TOPIC_0000001051070278__li1484616723811)。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172252.16599020721353532373765971869873:50001231000000:2800:3503154A44E9DAA6ECAFACEE0BDEC997FE47A861466A72AA27684F2838ABDDA7.png)  
若您的应用同时集成了ML Kit提供的多个服务（[ML Kit服务列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-sdk-0000001051070278#ZH-CN_TOPIC_0000001051070278__li1842231414318)），可能会出现编译问题，您需要参见[升级指南](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/upgrade-guide-0000001050038074)将您集成的其他服务升级到最新版本。  

#### Full SDK方式集成

将动作活体检测模型与动作活体检测插件集成为一个包，信息如下：  

|包类型|作用|包名|SDK大小|坐标名称|
|:--------|:-----|:-----------------------------------------------|:----|:-------------------------------------------------------------------------|
|动作活体检测集合包|动作活体检测|ml-computer-vision-interactive-livenessdetection|3.59M|com.huawei.hms:ml-computer-vision-interactive-livenessdetection:3.12.0.300|

Full SDK方式集成的示例代码如下：

```
dependencies{
    // 引入动作活体检测集合包。
    implementation 'com.huawei.hms:ml-computer-vision-interactive-livenessdetection:3.12.0.300'
}
```

#### 添加AGCP插件配置

用上述两种方式之一集成SDK后，请根据实际情况选择添加AGCP插件配置：

* 方式一：在文件头部声明下一行添加如下配置。

  ```
  apply plugin: 'com.huawei.agconnect'
  ```

* 方式二：在plugins中添加如下配置。

  ```
  plugins {
      id 'com.android.application'
      // 添加如下配置
      id 'com.huawei.agconnect'
  }
  ```
