## ONNX Quant_INT8-8无训练量化Demo

### 环境准备

环境准备请参见[环境准备](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/no-training-and-quantization-0000001053126892#section2399333123120)，安装ONNX及依赖。

### 示例代码

将dopt_onnx_py3目录添加到系统环境中，在终端环境执行

```screen
python3 ./dopt_so.py \
    --framework 5 \
    --mode   0 \
    --model "./resnet18_matmul.onnx" \          ## 待量化的ONNX模型
    --cal_conf "./config.prototxt" \            ## 校准集配置文件
    --output  "./resnet18_matmul_quant.onnx" \  ## 量化后的ONNX文件
    --input_shape   input:1,3,128,128 \         ## 浮点模型输入shape  
    --compress_conf  ./mnist_param              ## dopt工具生成的量化文件
```

其中，./config.prototxt配置内容为（[配置文件使用方法](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/no-training-and-quantization-0000001053126892#section1262217244312)）：

```screen
strategy: 'Quant_INT8-8'
device: USE_CPU
preprocess_parameter:
{
    input_type: BINARY
    input_file_path: './input1.bin'
}
```

## PyTorch Quant_INT8-8插件式量化Demo

### 环境准备

请参见[准备PyTorch环境](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/retraining-quantization-0000001052526973#section461318612307)。安装PyTorch-gpu 1.11版本以及其必要的依赖。

```screen
import sys
sys.path.append(".../dopt_tf_py3") ## 其中路径为绝对路径

def generate_config():
    model = build_torch_model()  ## 用户待量化的浮点模型
    generate_config_file(model, input_shape, dst_path="./config_gen.json") # model：torch.nn.Module， input_shape : "input1:input1.shape;input2:input2.shape"
    return model

def train_model():
    model = build_torch_model() ## 用户待量化的浮点模型
    from dopt.dopt_torch.opt_main import optimize_model
    model.load_state_dict(state)  ## load 浮点模型参数
    
    ## 调用optimize model 量化模型
    quanted_model = optimize_model(model, config_path)
    
    ## train model
    quant_loss = get_quant_loss(quant_model)
    optimizer = torch.optim.SGD(quanted_model.parameters(), lr=0.001, momentum=0.9) ## 假设使用SGD优化器
    
    for input_data, label in range(...):
        optimizer.zero_grad()
        outputs = model(input_data)
        loss = loss_fn(outputs, label) ## loss_fn 为原始浮点网络训练loss
        
        total_loss = loss + quant_weight * quant_loss ## quant_weight是指量化损失所占比例
        loss.backward()
        
        optimizer.step()

def calibrate_model():
    model = build_torch_model() ## 用户待量化的浮点模型
    from dopt.dopt_torch.opt_main import optimize_model, set_calibrate_state
    model.load_state_dict(state)  ## load 浮点模型参数
    
    ## 调用optimize model 量化模型
    quanted_model = optimize_model(model, config_path)
    
    calibrate_mode = True
    set_calibrate_state(model, calibrate_mode)
    
    for input_data, label in range(...):
        outputs = model(input_data)

def generate_params():
    model = build_torch_model()
    from dopt.dopt_torch.opt_main import generate_final_model
    generate_final_model(model, 
                        config_file,
                        pth_file="quant.pth",
                        output_dir="./results_dir")

if __name__ == "__main__":
    ## step 1
    ## 用户接入，配置修改
    generate_config()
   
    ## step 2
    ## 训练模型，直至达标
    train_model()
    ## calibrate_model()  ## 无训练模式

    ## step 3
    ## 提取参数，用于后续模型部署
    generate_params()
```

## TensorFlow NASEA网络结构搜索Demo

### NASEA分类网络

分类网络Demo位于"tools_dopt/dopt_tf_py3/demo/nas_ea/ea_cls_imagenet"，包含5个文件，如下图所示：

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150617.82493132542492958543999991616711:50001231000000:2800:3DC98D2C19E5FE1F2CF399F9905284AB38DCEA6E1752DC1CFC79490FC9FCEF41.png "点击放大")

* blocks.so：搜索空间文件
* readme.md：搜索训练指导文件
* run_release.sh：开始搜索的执行脚本
* scen.yaml：配置项
* user_module.py：工具的自定义接口

执行步骤：

1. 准备ImageNet数据集（tfrecord格式），并修改scen.yaml文件中的数据集路径。
2. 环境准备请参见[环境准备](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/network-structure-search-training-0000001052725679#section193737375169)。
3. 加载依赖的开源代码：

   1. 进入分类网络demo目录：

      ```screen
      cd tools_dopt/dopt_tf_py3/demo/nas_ea/ea_cls_imagenet
      ```


   2. 下载开源代码：

      ```screen
      git clone https://github.com/Tensorflow/models.git
      ```


   3. 进入开源代码目录：

      ```screen
      cd models
      ```


   4. 切换到指定版本：
      * 如果TensorFlow版本为1.12.0，执行如下命令：

      ```screen
      git checkout v1.12.0
      ```

      * 如果TensorFlow版本为2.1.0，执行如下命令：

      ```screen
      git checkout v2.1.0
      ```

   5. 返回分类网络demo目录：

      ```screen
      cd ..
      ```

   6. 设置PYTHONPATH默认路径：

      ```screen
      export PYTHONPATH=$PYTHONPATH:`pwd`/models/
      ```

   > 注意
   >
   > 每次打开终端需要重新执行一次上述命令，或添加到"~/.bashrc"文件，并执行"source ~/.bashrc"。

4. 配置demo下的scen.yaml文件，请参见[搜索参数配置](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/network-structure-search-training-0000001052725679#section9753193220185)。scen.yaml中提供了建议参数，用户可根据实际需求修改。
5. 修改demo下的user_module.py文件，模型接口定义请参见[TensorFlow用户自定义接口](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/network-structure-search-training-0000001052725679#section183452511917)。user_module.py中提供了建议配置，用户可根据实际需求进行修改。
6. 执行脚本run_release.sh，在results下，生成多个model_arch_result_*.py文件。用户可根据log_classification中提供的信息选择合适的网络结构进行训练。后续训练可参考readme.md中的指导。

* run_release.sh：开始搜索的执行脚本
* scen.yaml：配置项
* user_module.py：工具的自定义接口

执行步骤：

1. 准备ImageNet数据集（原始格式），并修改scen.yaml文件中的数据集路径。
2. 环境准备请参见[环境准备](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/network-structure-search-training-0000001052725679#section193737375169)。
3. 配置demo下的scen.yaml文件，请参见[搜索参数配置](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/network-structure-search-training-0000001052725679#section9753193220185)。scen.yaml中提供了建议参数，用户可根据实际需求修改。
4. 修改demo下的user_module.py文件，模型接口定义请参见[PyTorch用户自定义接口](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/network-structure-search-training-0000001052725679#section56271946125514)。user_module.py中提供了建议配置，用户可根据实际需求进行修改。
5. 执行脚本run_release.sh，在results下，生成多个model_arch_result_*.py文件。用户可根据log_classification中提供的信息选择合适的网络结构进行训练。后续训练可参考readme.md中的指导。
