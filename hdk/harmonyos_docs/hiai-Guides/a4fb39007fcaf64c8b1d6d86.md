# 添加权限

能力接口需要动态加载so动态库，请确认APK具备相关权限及能力。

完整地使用ML SDK提供的服务需要获取以下权限：

* INTERNET：调用云侧接口完成识别检测功能，需要申请网络权限。
* MICROPHONE：调用语音服务，需要申请录音权限。
* GET_WIFI_INFO：调用实时语音识别服务时，需要获取Wi-Fi状态。
* GET_NETWORK_INFO：调用实时语音识别、实时语音转写服务时，需要获取网络状态权限。

下表中列出的是SDK提供服务所需的最小权限，实际集成时服务可能涉及到其他权限。例如文本识别，若您需要通过拍照的方式进行云侧文本识别，则还需获取相机权限。

|权限名称|||**INTERNET**|GET_WIFI_INFO|MICROPHONE|GET_NETWORK_INFO|
|:----|------|--|:-----------|:------------|:---------|:---------------|
|文本类|文本识别|云侧|√|-|-|-|
|文本类|文档识别|云侧|√|-|-|-|
|语音语言类|语音合成|云侧|√|-|-|-|
|语音语言类|离线语音合成|端侧|-|-|-|-|
|语音语言类|在线文本翻译|云侧|√|-|-|-|
|语音语言类|在线语种检测|云侧|√|-|-|-|
|语音语言类|实时语音识别|云侧|√|√|√|√|
|语音语言类|实时语音转写|云侧|√|√|√|√|

具体操作步骤如下：

在main/config.json中申请权限。

```codeblock
"reqPermissions": [
      {
        "name": "ohos.permission.INTERNET" // 使用网络权限
      },
      {
        "name": "ohos.permission.MICROPHONE" // 使用麦克风进行录音权限
      },
      {
        "name": "ohos.permission.GET_WIFI_INFO" // 获取WLAN信息权限
      },
      {
        "name": "ohos.permission.GET_NETWORK_INFO" // 获取网络状态权限
      }
    ]
```
