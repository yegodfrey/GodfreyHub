# 升级指南

机器学习服务提供的最新SDK版本参见：[ML Kit服务列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/overview-sdk-0000001051070278#ZH-CN_TOPIC_0000001051070278__li1842231414318)，该版本优化了各个服务的使用体验，版本变更请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/version-changehistory-0000001050040023)。

* 初次集成机器学习服务，请使用最新版本的SDK，不涉及升级，请参见：[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/add-appgallery-0000001050038080)。
* 已经集成了机器学习服务SDK的老版本，需要将集成的SDK升级至最新版本。
