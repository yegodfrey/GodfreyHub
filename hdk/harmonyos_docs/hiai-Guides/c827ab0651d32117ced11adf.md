# 业务介绍

## 业务简介

随着信息技术的发展，网络信息量暴增，文本信息得到快速增长，信息成几何级增长逐步成为当今社会的主要特征。为了提取文本关键信息，在搜索引擎等领域，使得分词变得尤为重要。分词作为自然语言处理领域的基础研究，衍生出各类不同的文本处理相关应用。

词性标注API提供了一个文本自动分词并给出词性的接口，对于输入的一段文本，自动通过该API可以对其进行分词，同时提供不同的分词粒度，可以根据需要自定义分词粒度。

## 场景介绍

* **搜索引擎技术** **：** 本API可以应用于搜索引擎开发。对于搜索引擎来说，最重要的并不是找到所有结果，因为在上百亿的网页中找到所有结果没有太多的意义，最重要的是把最相关的结果排在最前面，这也称为相关度排序。分词的准确与否，常常直接影响到对搜索结果的相关度排序。

* **语义分析开发** **：**本API可以应用于语义分析相关软件的开发。在语义分析中，通过分词，理解文本所要表达的正确含义。同时得到词性，可以准确的判断出某个词是名词、动词、形容词等等，使得语义分析更方便扩展，如命名实体识别。

## 功能特点

* **轻便** **：**利用本API，可以大大节省算法开发的时间，节省算法模型占用的ROM空间，让您的应用更加轻便。
* **灵活：**利用本API，可以通过自定义分词的粒度，达到对分词结果进行定制的效果。

### 功能使用限制

|功能|使用限制说明|
|:-----|:------------------------------------------------------------------------------------------------------------------|
|输入文本长度|词性标注文本限制在500字以内，超过字数将返回参数错误，文本要UTF-8格式，格式错误的不报错，但分析结果会不准确。|
|多线程调用|HUAWEI HiAI Engine支持多用户同时接入，但是不支持同一用户并发调用同一个特性，如同一个特性被同一进程同一时间多次调用，则返回系统忙错误，不同进程调用同一特性，则同一时间只有一个进程业务在处理，其他进程进入队列排队。|
