# 场景识别

## 服务介绍

场景识别服务支持对图片的场景内容进行分类并添加标注信息，如：室外风景、室内场所、建筑物等，辅助理解图像内容。基于识别到的信息，可以创造更加个性化应用体验。场景识别目前支持端侧识别，支持102种场景的识别（支持的场景请参见[场景识别类别清单](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)）。

## 应用场景

场景识别服务广泛应用于基于图像场景理解的业务场景。例如，集成该服务可以根据图像场景内容对图片集进行分类，生成智能相册集等。另外，通过识别拍摄场景来选择对应的相机参数，帮助用户拍出更好看的照片。

## 注意事项

场景识别服务目前支持Android 6.0以上版本集成，不支持高通芯片。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/scene-detection-sdk-0000001055124180)。

### 静态图片检测

1. 创建场景识别检测器实例。

   ```java
   "Java"
   // 方式一：使用默认的参数配置。
   MLSceneDetectionAnalyzer analyzer = MLSceneDetectionAnalyzerFactory.getInstance().getSceneDetectionAnalyzer();
   // 方式二：按自定义配置创建场景识别分析器实例。
   MLSceneDetectionAnalyzerSetting setting = new MLSceneDetectionAnalyzerSetting.Factory()
        // 设置场景识别可信度阈值。
        .setConfidence(confidence)
        .create();
   MLSceneDetectionAnalyzer analyzer = MLSceneDetectionAnalyzerFactory.getInstance().getSceneDetectionAnalyzer(setting);
   ```

   ```javascript
   "Kotlin"
   // 方式1：使用默认的参数配置。
   var analyzer = MLSceneDetectionAnalyzerFactory.getInstance().sceneDetectionAnalyzer

    // 方式2：按自定义配置创建场景识别分析器实例。
   var setting = MLSceneDetectionAnalyzerSetting.Factory() // 设置场景识别可信度阈值。
            .setConfidence(confidence)
            .create()
   var analyzer = MLSceneDetectionAnalyzerFactory.getInstance().getSceneDetectionAnalyzer(setting)
   ```

2. 通过android.graphics.Bitmap构造[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，支持的图片格式包括：jpg/jpeg/png/bmp。

   ```screen
   "Java"
   MLFrame frame = new MLFrame.Creator().setBitmap(bitmap).create();
   ```

   ```screen
   "Kotlin"
   var frame = MLFrame.Creator().setBitmap(bitmap).create()
   ```

3. 进行场景识别。

   ```java
   "Java"
   // 方式一：同步识别。
   SparseArray<MLSceneDetection> results = analyzer.analyseFrame(frame);
   // 方式二：异步识别。
   Task<List<MLSceneDetection>> task = analyzer.asyncAnalyseFrame(frame);
   task.addOnSuccessListener(new OnSuccessListener<List<MLSceneDetection>>() {
       public void onSuccess(List<MLSceneDetection> result) {
           // 场景识别成功的处理逻辑。
       }})
       .addOnFailureListener(new OnFailureListener() {
           public void onFailure(Exception e) {
               // 场景识别识别失败的处理逻辑。
               // failure.
               if (e instanceof MLException) {
                   MLException mlException = (MLException)e;
                   // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
                   int errorCode = mlException.getErrCode();
                   // 获取报错信息，开发者可以结合错误码，快速定位问题。
                   String errorMessage = mlException.getMessage();
               } else {
                   // 其他异常。
           }
       }
   });
   ```

   ```javascript
   "Kotlin"
   // 方式1：同步识别。
   val results = analyzer!!.analyseFrame(frame)
    // 方式2：异步识别。
   val task = analyzer!!.asyncAnalyseFrame(frame)
    task.addOnSuccessListener {
   // 场景识别成功的处理逻辑。
   }
   .addOnFailureListener {e ->
   // 场景识别识别失败的处理逻辑。
                // failure.
                if (e is MLException) {
                    val mlException = e
                    // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
                    val errorCode = mlException.errCode
                    // 获取报错信息，开发者可以结合错误码，快速定位问题。
                    val errorMessage = mlException.message
                } else {
                    // 其他异常。
                }
            }
   ```

4. 检测完成，停止分析器，释放检测资源。

   ```screen
   "Java"
   if (analyzer != null) {
       analyzer.stop();
   }
   ```

   ```screen
   "Kotlin"
   if (analyzer != null) {
        analyzer!!.stop()
    }
   ```

### 视频流检测

开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按上文中静态图像检测的方法进行场景识别。如果开发者调用的是同步检测接口，也可以使用SDK内置的[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)类实现视频流场景识别，示例代码如下：

1. 创建场景识别分析器，只支持创建端侧场景识别分析器

   ```screen
   "Java"
   MLSceneDetectionAnalyzer analyzer = MLSceneDetectionAnalyzerFactory.getInstance().getSceneDetectionAnalyzer();
   ```

   ```screen
   "Kotlin"
   val analyzer = MLSceneDetectionAnalyzerFactory.getInstance().sceneDetectionAnalyzer
   ```

2. 开发者创建识别结果处理类"SceneDetectionAnalyzerTransactor"，该类实现[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)<T>接口，使用该接口中的[transactResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216#section7411382071)方法获取检测结果并实现具体业务。

   ```java
   "Java"
   public class SceneDetectionAnalyzerTransactor implements MLAnalyzer.MLTransactor<MLSceneDetection> {
       @Override
       public void transactResult(MLAnalyzer.Result<MLSceneDetection> results) {
           SparseArray<MLSceneDetection> items = results.getAnalyseList();
           // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
           // 不可调用ML Kit提供的其他检测相关接口。
       }
       @Override
       public void destroy() {
           // 检测结束回调方法，用于释放资源等。
       }
   }
   ```

   ```javascript
   "Kotlin"
   class SceneDetectionAnalyzerTransactor : MLTransactor<MLSceneDetection?> {
        override fun transactResult(results: MLAnalyzer.Result<MLSceneDetection?>) {
            val items = results.analyseList
            // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
            // 不可调用ML Kit提供的其他检测相关接口。
        }

        override fun destroy() {
            // 检测结束回调方法，用于释放资源等。
        }
    }
   ```

3. 设置识别结果处理器，实现分析器与结果处理器的绑定

   ```java
   "Java"
   analyzer.setTransactor(new SceneDetectionAnalyzerTransactor());
   // 创建LensEngine，该类由ML Kit SDK提供，用于捕捉相机动态视频流并传入分析器。
   Context context = this.getApplicationContext();
   LensEngine lensEngine = new LensEngine.Creator(context, this.analyzer)
       .setLensType(LensEngine.BACK_LENS)
       .applyDisplayDimension(1440, 1080)
       .applyFps(30.0f)
       .enableAutomaticFocus(true)
       .create();
   ```

   ```javascript
   "Kotlin"
   analyzer!!.setTransactor(SceneDetectionAnalyzerTransactor())
    // 创建LensEngine，该类由ML Kit SDK提供，用于捕捉相机动态视频流并传入分析器。
   val context = applicationContext
   val lensEngine = LensEngine.Creator(context, this.analyzer)
            .setLensType(LensEngine.BACK_LENS)
            .applyDisplayDimension(1440, 1080)
            .applyFps(30.0f)
            .enableAutomaticFocus(true)
            .create()
   ```

4. 调用run方法，启动相机，读取视频流，进行识别

   ```java
   "Java"
   // 请自行实现SurfaceView控件的其他逻辑。
   SurfaceView mSurfaceView = findViewById(R.id.surface_view);
   try {
       lensEngine.run(mSurfaceView.getHolder());
   } catch (IOException e) {
       // 异常处理逻辑。
   }
   ```

   ```javascript
   "Kotlin"
   // 请自行实现SurfaceView控件的其他逻辑。
   val mSurfaceView: SurfaceView? = findViewById(R.id.surface_view)
   try {
        lensEngine!!.run(mSurfaceView!!.holder)
    } catch (e: IOException) {
        // 异常处理逻辑。
    }
   ```

5. 检测完成，停止分析器，释放检测资源

   ```screen
   "Java"
   if (analyzer != null) {
       analyzer.stop();
   }
   if (lensEngine != null) {
       lensEngine.release();
   }
   ```

   ```screen
   "Kotlin"
   if (analyzer != null) {
        analyzer.stop()
    }
   lensEngine?.release()
   ```

使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)<T>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见[视频流检测模式多次识别场景开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-video-0000001050040139)。
