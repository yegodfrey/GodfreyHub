# 内存零拷贝（可选）

## 概述

对于GPU的纹理数据或模型的输入数据等已经存在于ION内存中的场景，就可以使用"内存零拷贝方式"，即将存放数据的ION内存封装为输入输出张量，直接进行推理， 不需要进行输入张量和输出张量的数据拷贝， 以便节省内存以及推理时间。

## 使用说明

对于零拷贝使用场景，在模型加载完成后，使用接口 [Init(const NativeHandle& handle, const TensorDimension* dim, HIAI_DataType pdataType)](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001051490692#section84731652202415)，将ION内存封装为输入张量"input_tensor"输出张量"output_tensor"，执行推理。

具体使用请参考[零拷贝Demo（Android）](https://gitee.com/huawei-hiai-foundation/HiAIDemo/tree/master/HiAIVSR)、[零拷贝Demo（HarmonyOS）](https://gitee.com/huawei-hiai-foundation/HiAIDemo/tree/master/HMOSNextDemo/VulkanVsrSample)
