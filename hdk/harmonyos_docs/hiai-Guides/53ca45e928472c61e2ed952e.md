# 错误码

|错误码|值|描述|解决方法|
|:------------------------------------------------------|:-|:--------------|:---------------------------------------------------------------------------------|
|AI_SUCCESS、SUCCESS、HIAI_SUCCESS|0|运行正常。|执行成功。|
|AI_FAILED、FAILURE、HIAI_FAILURE|1|内部错误。|请根据log信息调整或联系[论坛](https://developer.huawei.com/consumer/cn/support/feedback/#/)支撑。|
|AI_NOT_INIT、UNINITIALIZED、HIAI_UNINITIALIZED|2|模型管家未初始化。|请初始化模型管家。|
|AI_INVALID_PARA、INVALID_PARAM、HIAI_INVALID_PARAM|3|输入参数非法。|请根据log调整输入参数。|
|AI_TIMEOUT、TIMEOUT、HIAI_TIMEOUT|4|执行任务超时返回。|请减小模型计算量或联系[论坛](https://developer.huawei.com/consumer/cn/support/feedback/#/)支撑。|
|UNSUPPORTED、HIAI_UNSUPPORTED|5|目前不支持。|当前不支持，请切换其他的使用方式。|
|MEMORY_EXCEPTION、HIAI_MEMORY_EXCEPTION|6|内存异常。|请检查是否存在导致内存异常。|
|AI_INVALID_API、INVALID_API、HIAI_INVALID_API|7|设备不支持此API接口。|请使用CANN DDK V600及以前版本的API接口。|
|AI_INVALID_POINTER、INVALID_POINTER、HIAI_INVALID_POINTER|8|类成员函数中this指针为空。|请检查空指针情况。|
|CALC_EXCEPTION、HIAI_CALC_EXCEPTION|9|计算异常。|请根据Log信息调整或联系[论坛](https://developer.huawei.com/consumer/cn/support/feedback/#/)支撑。|
|FILE_NOT_EXIST、HIAI_FILE_NOT_EXIST|10|文件不存在。|请检查文件是否存在或权限是否|
|COMM_EXCEPTION、HIAI_COMM_EXCEPTION|11|运行失败。|请根据Log信息调整或联系[论坛](https://developer.huawei.com/consumer/cn/support/feedback/#/)支撑。|
|DATA_OVERFLOW、HIAI_DATA_OVERFLOW|12|数据溢出。|请根据Log信息调整或联系[论坛](https://developer.huawei.com/consumer/cn/support/feedback/#/)支撑。|
|CONNECT_EXCEPTION、HIAI_CONNECT_EXCEPTION|19|连接异常|出现此情况建议释放所有CANN资源，并重新载入模型。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
