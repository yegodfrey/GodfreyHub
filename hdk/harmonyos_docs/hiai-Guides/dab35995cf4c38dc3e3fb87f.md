# 离线语音合成

## 服务介绍

离线语音合成服务内置模型，即便在无网络环境下也可以将文字信息转换为语音。当前版本支持中英语种，都有男声及女声音色可供选择。

## 注意事项

* 目前离线语音合成服务支持可调整音量、语速及音调。
* 输出音频数据默认规格为PCM单声道，位深为16Bit，音频采样率为16kHZ。
* 建议单次请求文本不超过500个字符。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/tts-duance-sdk-harmonyos-0000001259272248)。

1. 创建语音合成引擎。可以通过语音合成自定义配置类[MLTtsConfig](https://developer.huawei.com/consumer/cn/doc/hiai-References/ttsconfig-harmonyos-0000001248118181#section59197915325)创建语音合成引擎（目前仅支持中英语种，语音编码和发音人编码请参见下图）。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172405.89773709911876775998984248555105:50001231000000:2800:437519761A4E01CDEA8BB3434149B65E672A6CB2FC71AFFBC73E960C965B484F.png "点击放大")

   ```java
   "Java"
   // 使用自定义参数配置创建语音合成引擎。
   MLTtsConfig mlTtsConfig = new MLTtsConfig()
       // 设置合成文本为中文。
       .setLanguage(MLTtsConstants.TTS_ZH_HANS)
       // 设置中文发音音色。
       .setPerson(MLTtsConstants.TTS_SPEAKER_OFFLINE_ZH_HANS_FEMALE_EAGLE)
       // 设置语音合成的模式为离线模式，不设置默认为在线模式。
       .setSynthesizeMode(MLTtsConstants.TTS_OFFLINE_MODE)
       // 设置发音速度。范围：(0, 5.0]，1.0表示正常语速。如果传入非法参数，会默认使用1.0f。
       .setSpeed(1.0f)
       // 设置音量。范围：(0, 2)，1.0表示正常音量。如果传入非法参数，会默认使用1.0f。
       .setVolume(1.0f);
    
   MLTtsEngine mlTtsEngine = new MLTtsEngine(mlTtsConfig); // 引擎运行中更新配置。
   mlTtsEngine.updateConfig(mlTtsConfig);
   ```

2. 新建语音合成回调，用于处理语音合成结果。

   ```java
   "Java"
   MLTtsCallback callback = new MLTtsCallback() {
       @Override
       public void onError(String taskId, MLTtsError err) {
           // 语音合成失败处理。
       }
       @Override
       public void onWarn(String taskId, MLTtsWarn warn) {
           // 告警处理（不影响业务逻辑）。
       }
       // 此方法触发正在研发中。
       @Override
       public void onRangeStart(String s, int i, int i1) {
       }
       @Override
       // taskId: 该音频对应的语音合成任务Id。
       // audioFragment: 音频数据。
       // offset: 一个语音合成任务会对应一个音频合成数据队列，该字段表示本次传输的音频分片在该队列中的偏移量。
       // range：本次传输的音频分片所在的文本区域，此功能还在开发中。
       public void onAudioAvailable(String taskId, MLTtsAudioFragment audioFragment, int offset,Pair<Integer, Integer> range, PacMap bundle){
       // Tts合成音频流回调接口，通过此接口将音频合成数据返回给App。
       }
       @Override
       public void onEvent(String taskId, int eventId, PacMap bundle) {
          // 合成事件回调方法。eventId为事件名称。
          switch (eventId) {
           case MLTtsConstants.EVENT_PLAY_START:
               // 播放开始回调。
               break;
           case MLTtsConstants.EVENT_PLAY_STOP:
               // 播放停止回调。
               boolean isInterrupted = bundle.getBooleanValue(MLTtsConstants.EVENT_PLAY_STOP_INTERRUPTED);
               break;
           case MLTtsConstants.EVENT_PLAY_RESUME:
               // 播放恢复回调。
               break;
           case MLTtsConstants.EVENT_PLAY_PAUSE:
               // 播放暂停回调。
               break;
           }
       }
   };
   ```

3. 将语音合成回调传入第1步中新建的语音合成引擎中，进行语音合成。

   ```java
   "Java"
   mlTtsEngine.setTtsCallback(callback);
   /**
   *第一个参数：sourceText表示需要合成的文本信息，建议单次请求文本不超过500个字符。
   *第二个参数为合成模式设置，设置格式为：configA | configB | configC。
   *configA支持设置： 
   *    MLTtsEngine.QUEUE_APPEND：排队模式，如果当前正在播放，则将任务放在队列中顺序执行；如果当前处于播放暂停状态，则恢复播放，再将任务放入队列中顺序执行；如果当前无播放任务，则立即执行。
   *    MLTtsEngine.QUEUE_FLUSH：清空模式，立即停止正在进行的语音合成任务以及播放，并清空正在排队的语音合成任务，立即执行此次语音合成任务并播放。
   *configB支持设置：
   *    MLTtsEngine.OPEN_STREAM：实时流输出模式，将文本合成的语音数据流通过onAudioAvailable回调输出。
   *configC支持设置：
   *    MLTtsEngine.EXTERNAL_PLAYBACK：外部播放模式，屏蔽SDK自带播放器，需要自行处理onAudioAvailable回调接口输出的音频，此时回调接口中播放相关接口将会失效，仅能监听语音合成相关回调接口。
   */
   // 排队模式进行语音合成，使用SDK内置播放器播放语音。
   String id = mlTtsEngine.speak(sourceText, MLTtsEngine.QUEUE_FLUSH); 
   mlTtsEngine.speak(sourceText, MLTtsEngine.QUEUE_FLUSH | MLTtsEngine.OPEN_STREAM);
   ```

4. 播放控制（仅在使用内部播放器时生效）。

   ```java
   "Java"
   // 暂停播放。
   mlTtsEngine.pause();
   // 恢复播放。
   mlTtsEngine.resume();
   // 停止播放。
   mlTtsEngine.stop();
   ```
