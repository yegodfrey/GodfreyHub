# 白描集成HUAWEI ML Kit文本识别服务，提升用户文件扫描体验感

#### 白描介绍

白描是一款准确高效的OCR文件扫描与识别软件，由北京优零科技有限公司开发。该应用识别准确度高，速度快，文件扫描清晰，可多场景使用。  

#### 业务挑战

白描为用户提供良好的扫描识别服务时，需要准确度高的文本识别服务，将图片中的文本信息提取出来并且填入对应位置，代替了人工录入，减少成本。

* 文档处于复杂场景下无法识别。
* 识别出来的信息无法出现在对应的位置。
* 为了提升多样性，需要支持更多场景识别，如：卡片、照片、文档、书籍、PPT等。  

#### 解决方案

白描通过集成ML Kit文本识别服务，实现App内文本识别，对文本中的重要信息进行结构化识别和录入。凭借着ML Kit文本识别服务，为白描用户提供了精准的文本识别功能，提升用户体验。

* ML Kit文本识别能够识别多种语言，且能将识别的文字返回对应位置。
* 集成过程简单，识别检测速度快且准确度高。
* ML Kit文本识别支持多场景、复杂场景识别。

* 白描用户 享受高准确度的文本识别，可以多场景使用，体验更好。
