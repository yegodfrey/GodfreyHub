# 开发指南

## 应用开发

### 必须导入类

1. 在使用人体关键点识别API时，将实现人体关键点识别的相关的类添加至工程。

   ```screen
   import com.huawei.hiai.vision.image.detector.PoseEstimationDetector; // 加载人体关键点识别类
   import com.huawei.hiai.vision.common.VisionImage; // 加载输入数据类
   import com.huawei.hiai.vision.visionkit.image.detector.BodySkeletons; // 加载返回结果类
   import com.huawei.hiai.pdk.resultcode.HwHiAIResultCode; // 加载返回结果码类
   import com.huawei.hiai.vision.visionkit.image.detector.PeConfiguration; 
   import com.huawei.hiai.vision.visionkit.text.config.VisionTextConfiguration;//加载配置类
   import com.huawei.hiai.vision.common.VisionBase; // 加载连接服务的静态类
   import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
   import com.huawei.hiai.vision.common.VisionCallback;
   import com.huawei.hiai.pdk.pluginservice.ILoadPluginCallback;
   ```

### 开发

1. 应用VisionBase静态类进行初始化，拿到服务连接的结果。

   ```screen
   VisionBase.init(MainActivity.this, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. 定义detector实例，将此应用的Context当做入参。

   ```screen
   mPoseEstimationDetector = new PoseEstimationDetector(mContext);
   ```

3. 设置参数。

   ```screen
   PeConfiguration config = new PeConfiguration.Builder()
       .setProcessMode(VisionTextConfiguration.MODE_IN)
       .setDetectType(PeConfiguration.DETECT_TYPE_FRAME)
       .setDetectModel(PeConfiguration.DETECT_MODEL_SINGLE_ACC)
       .build(); 
   mPoseEstimationDetector.setConfiguration(config);
   ```

4. 懒加载进行插件下载，通过getAvailability()函数获取是否需要下载插件。如果需要，可通过loadPlugin()来进行插件下载 。

   ```screen
   int availability = mPoseEstimationDetector.getAvailability();
   int installation = -2;
   if (availability == -6) {
       Lock lock = new ReentrantLock();
       Condition condition = lock.newCondition();
       CVFaceCompVision.LoadPluginCallback cb = new CVFaceCompVision.LoadPluginCallback(lock, condition);
       mPoseEstimationDetector.loadPlugin(cb);
       lock.lock();
       try {
           condition.await(90, TimeUnit.SECONDS);
       } catch (InterruptedException e) {
           Log.e(LOG_TAG, e.getMessage());
       } finally {
           lock.unlock();
       }
       installation = cb.mResultCode;
   }
   ```

5. 定义VisionImage，将需进行人体关键点识别图像的bitmap放入VisionImage中。

   ```screen
   VisionImage image = null;
   if (bitmap != null) {
       image = VisionImage.fromBitmap(bitmap);
   }
   ```

6. 调用detect方法得到人体关键点识别结果。

   ```screen
   List<BodySkeletons> bodySkeletons = new ArrayList<>();
   // 返回结果保存在bodySkeletons 
   resultCode = mPoseEstimationDetector.detect(image, bodySkeletons, null);
   ```
