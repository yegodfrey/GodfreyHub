# 单算子开发

#### 概述

CANN提供独立的算子创建和计算通路，三方框架可以在模型加载、推理过程中，将卷积、深度卷积等算子通过单算子对接的方式迁移至NPU，经过硬件平台的加速计算，从而提升模型整网计算性能。

#### 使用说明

1. 创建单算子执行器。

   <br />

   1. 调用[HiAI_SingleOpOptions_Create](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopoptions-create-0000001890254458)，创建单算子配置对象。
   2. 调用[HiAI_SingleOpDescriptor_CreateConvolution](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopdescriptor-createconvolution-0000001934134193)，创建卷积类算子描述符对象。
   3. 调用[HiAI_SingleOpTensor_CreateFromConst](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-createfromconst-0000001934134185)，分别创建卷积算子的权重、偏置单算子Tensor。
   4. 调用[HiAI_SingleOpTensorDesc_Create](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensordesc-create-0000001890254426)，分别创建单算子输入Tensor、输出Tensor的描述对象。
   5. 调用[HiAI_SingleOpExecutor_CreateConvolution](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-createconvolution-0000001890254466)，将上述创建好的卷积类算子描述符对象、卷积算子的权重Tensor、卷积算子的偏置Tensor、输入Tensor描述、输出Tensor描述作为输入，创建单算子执行器；

      如果需要创建卷积算子与激活算子的融合算子执行器，还需要调用[HiAI_SingleOpDescriptor_CreateActivation](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopdescriptor-createactivation-0000001890254462)，创建激活类算子描述符对象，然后调用[HiAI_SingleOpExecutor_CreateFusedConvolutionActivation](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-createfusedconvactivation-0000001934134205)创建融合算子执行器。

   <!-- -->

   6. 创建成功后，调用[HiAI_SingleOpDescriptor_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopdescriptor-destroy-0000001890414414)释放算子描述符对象，调用[HiAI_SingleOpOptions_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopoptions-destroy-0000001890414410)释放单算子创建配置对象。

   <br />

2. 创建输入/输出Tensor。

   <br />

   1. 调用[HiAI_SingleOpTensor_CreateFromTensorDesc](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-createfromtensordesc-0000001890254446)，分别创建单算子输入Tensor、输出Tensor。
   2. 创建成功后，调用[HiAI_SingleOpTensorDesc_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensordesc-destroy-0000001890414394)释放Tensor描述符对象。
   3. 调用[HiAI_SingleOpTensor_GetBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-getbuffer-0000001890414406)，获取输入/输出Tensor内部的Buffer对象。
   4. 调用[HiAI_SingleOpBuffer_GetData](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopbuffer-getdata-0000001890414398)，获取申请好的输入/输出ION内存地址，可用于该单算子在模型整网推理中的输入写入、输出读取。

   <br />

3. 加载单算子执行器。

   <br />

   1. 调用[HiAI_SingleOpExecutor_GetWorkspaceSize](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-getworkspacesize-0000001934134213)，获取已创建的单算子执行器在执行推理计算时需要的ION内存工作空间大小。
   2. 调用[HiAI_SingleOpBuffer_Create](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopbuffer-create-0000001934134173)，根据单算子执行器所需的ION内存工作空间大小创建足够的工作空间。
   3. 调用[HiAI_SingleOpBuffer_GetData](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopbuffer-getdata-0000001890414398)，获取申请好的ION内存工作空间的地址。
   4. 调用[HiAI_SingleOpExecutor_Init](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-init-0000001890254482)，使用工作空间内存地址、工作空间大小，加载创建好的单算子执行器。

   <br />

4. 执行推理运算。

   <br />

   调用[HiAI_SingleOpExecutor_Execute](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-execute-0000001890414438)，执行同步运算推理。

   <br />

5. 卸载单算子执行器，释放资源。

   <br />

   * 调用[HiAI_SingleOpTensor_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleoptensor-destroy-0000001934134189)，释放输入、输出Tensor对象
   * 调用[HiAI_SingleOpBuffer_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopbuffer-destroy-0000001934134177)，释放工作空间。
   * 调用[HiAI_SingleOpExecutor_Destroy](https://developer.huawei.com/consumer/cn/doc/hiai-References/hiai-singleopexecutor-destroy-0000001890254474)，释放执行器对象。

   <br />

#### 接口声明

开发者可以参考如下单算子接口声明，在端侧打开/vendor/lib64路径下的libai_single_op.so进行动态链接，完成集成。

```
#ifndef HIAI_SINGLE_OP_H
#define HIAI_SINGLE_OP_H
#include <stddef.h>
#include <stdint.h>
#include <stdbool.h>

typedef uint32_t HIAI_Status;
/** 执行成功 */
static const HIAI_Status HIAI_SUCCESS = 0;
/** 执行失败 */
static const HIAI_Status HIAI_FAILURE = 1;

typedef enum {
    HIAI_SINGLEOP_OPTIMIZED = 0,  // 使用单算子性能已优化
    HIAI_SINGLEOP_COMMON, // 使用单算子性能普通
    HIAI_SINGLEOP_UNSUPPORTED, // 不支持该单算子
} HiAI_SingleOp_SupportStatus;

typedef enum {
    HIAI_SINGLEOP_DT_FLOAT = 0,      // float类型
    HIAI_SINGLEOP_DT_FLOAT16 = 1,    // float16类型
    HIAI_SINGLEOP_DT_UNDEFINED = 17, // 数据类型未定义
} HiAI_SingleOp_DataType;

typedef enum {
    HIAI_SINGLEOP_FORMAT_NCHW = 0, /* NCHW */
    HIAI_SINGLEOP_FORMAT_NHWC,     /* NHWC */
    HIAI_SINGLEOP_FORMAT_ND,       /* ND */
    HIAI_SINGLEOP_FORMAT_NC1HWC0,  /* NC1HWC0 */
    HIAI_SINGLEOP_FORMAT_NC4HW4 = 28,
    HIAI_SINGLEOP_FORMAT_NC8HW8 = 31,
    HIAI_SINGLEOP_FORMAT_RESERVED = 255
} HiAI_SingleOp_Format;

typedef enum {
    HIAI_SINGLEOP_CONV_MODE_COMMON = 0,
    HIAI_SINGLEOP_CONV_MODE_TRANSPOSED,
    HIAI_SINGLEOP_CONV_MODE_DEPTHWISE,
} HiAI_SingleOp_ConvMode;

// 卷积的pad_mode枚举类型
typedef enum {
    HIAI_SINGLEOP_PAD_MODE_SPECIFIC = 0,
    HIAI_SINGLEOP_PAD_MODE_SAME,
    HIAI_SINGLEOP_PAD_MODE_SAME_UPPER,
    HIAI_SINGLEOP_PAD_MODE_SAME_LOWER,
    HIAI_SINGLEOP_PAD_MODE_VALID,
} HiAI_SingleOp_PadMode;

// 支持的激活类型
typedef enum {
    HIAI_SINGLEOP_ACTIVATION_TYPE_RELU = 0,
    HIAI_SINGLEOP_ACTIVATION_TYPE_RELU6,
} HiAI_SingleOp_ActivationType;

#ifdef __cplusplus
extern "C" {
#endif

typedef struct HiAI_SingleOpTensorDesc HiAI_SingleOpTensorDesc;
typedef struct HiAI_SingleOpTensor HiAI_SingleOpTensor;
typedef struct HiAI_SingleOpBuffer HiAI_SingleOpBuffer;

// TensorDesc的创建接口
HiAI_SingleOpTensorDesc* HiAI_SingleOpTensorDesc_Create(const int64_t* dims, size_t dimNum,
    HiAI_SingleOp_DataType dataType, HiAI_SingleOp_Format format, bool isVirtual);
// TensorDesc的查询接口
size_t HiAI_SingleOpTensorDesc_GetDimensionCount(const HiAI_SingleOpTensorDesc* tensorDesc);
int64_t HiAI_SingleOpTensorDesc_GetDimension(const HiAI_SingleOpTensorDesc* tensorDesc, size_t index);
HiAI_SingleOp_DataType HiAI_SingleOpTensorDesc_GetDataType(const HiAI_SingleOpTensorDesc* tensorDesc);
HiAI_SingleOp_Format HiAI_SingleOpTensorDesc_GetFormat(const HiAI_SingleOpTensorDesc* tensorDesc);
bool HiAI_SingleOpTensorDesc_IsVirtual(const HiAI_SingleOpTensorDesc* tensorDesc);
size_t HiAI_SingleOpTensorDesc_GetByteSize(const HiAI_SingleOpTensorDesc* tensorDesc);
// TensorDesc的销毁接口
void HiAI_SingleOpTensorDesc_Destroy(HiAI_SingleOpTensorDesc** tensorDesc);

// Buffer的创建接口
HiAI_SingleOpBuffer* HiAI_SingleOpBuffer_Create(size_t dataSize);
// Buffer的查询接口
size_t HiAI_SingleOpBuffer_GetSize(const HiAI_SingleOpBuffer* buffer);
void* HiAI_SingleOpBuffer_GetData(const HiAI_SingleOpBuffer* buffer);
// Buffer的销毁接口
HIAI_Status HiAI_SingleOpBuffer_Destroy(HiAI_SingleOpBuffer** buffer);

// 基于tensordesc创建Tensor并申请data内存（ION）
HiAI_SingleOpTensor* HiAI_SingleOpTensor_CreateFromTensorDesc(const HiAI_SingleOpTensorDesc* desc);
// 基于用户已经申请好的ION内存创建Tensor
HiAI_SingleOpTensor* HiAI_SingleOpTensor_CreateFromSingleOpBuffer(
    const HiAI_SingleOpTensorDesc *desc, void* data, size_t dataSize);
// 创建权重等带data的Tensor
HiAI_SingleOpTensor* HiAI_SingleOpTensor_CreateFromConst(const HiAI_SingleOpTensorDesc* desc,
    void* data, size_t dataSize);
// Tensor的Get接口
HiAI_SingleOpTensorDesc* HiAI_SingleOpTensor_GetTensorDesc(const HiAI_SingleOpTensor* tensor);
HiAI_SingleOpBuffer* HiAI_SingleOpTensor_GetBuffer(const HiAI_SingleOpTensor* tensor);
// Tensor销毁接口
HIAI_Status HiAI_SingleOpTensor_Destroy(HiAI_SingleOpTensor** tensor);

typedef struct HiAI_SingleOpDescriptor HiAI_SingleOpDescriptor;
typedef struct HiAI_SingleOpExecutor HiAI_SingleOpExecutor;
typedef struct HiAI_SingleOpOptions HiAI_SingleOpOptions;

// 创建单算子执行配置
HiAI_SingleOpOptions* HiAI_SingleOpOptions_Create(void);
// 销毁单算子执行配置
void HiAI_SingleOpOptions_Destroy(HiAI_SingleOpOptions** options);

// 创建单算子desc
HiAI_SingleOpDescriptor* HiAI_SingleOpDescriptor_CreateConvolution(
    HiAI_SingleOp_ConvMode convMode, const int64_t strides[2], const int64_t dilations[2],
    const int64_t pads[4], int64_t groups, HiAI_SingleOp_PadMode padMode);
HiAI_SingleOpDescriptor* HiAI_SingleOpDescriptor_CreateActivation(
    HiAI_SingleOp_ActivationType activationType, float coef);
// 算子desc销毁
void HiAI_SingleOpDescriptor_Destroy(HiAI_SingleOpDescriptor** opDesc);

// 创建单算子执行器
HiAI_SingleOp_SupportStatus HiAI_SingleOpExecutor_PreCheckConvolution(
    const HiAI_SingleOpOptions* options, const HiAI_SingleOpDescriptor* opDesc,
    const HiAI_SingleOpTensorDesc* input, const HiAI_SingleOpTensorDesc* output,
    const HiAI_SingleOpTensor* filter, const HiAI_SingleOpTensor* bias);
HiAI_SingleOpExecutor* HiAI_SingleOpExecutor_CreateConvolution(const HiAI_SingleOpOptions* options,
    const HiAI_SingleOpDescriptor* opDesc, const HiAI_SingleOpTensorDesc* input, const HiAI_SingleOpTensorDesc* output,
    const HiAI_SingleOpTensor* filter, const HiAI_SingleOpTensor* bias);
HiAI_SingleOp_SupportStatus HiAI_SingleOpExecutor_PreCheckFusedConvolutionActivation(
    const HiAI_SingleOpOptions* options, const HiAI_SingleOpDescriptor* convOpDesc,
    const HiAI_SingleOpDescriptor* actOpDesc, const HiAI_SingleOpTensorDesc* input,
    const HiAI_SingleOpTensorDesc* output, const HiAI_SingleOpTensor* filter,
    const HiAI_SingleOpTensor* bias);
HiAI_SingleOpExecutor* HiAI_SingleOpExecutor_CreateFusedConvolutionActivation(
    const HiAI_SingleOpOptions* options, const HiAI_SingleOpDescriptor* convOpDesc,
    const HiAI_SingleOpDescriptor* actOpDesc, const HiAI_SingleOpTensorDesc* input,
    const HiAI_SingleOpTensorDesc* output, const HiAI_SingleOpTensor* filter,
    const HiAI_SingleOpTensor* bias);
// 算子执行器销毁
HIAI_Status HiAI_SingleOpExecutor_Destroy(HiAI_SingleOpExecutor** executor);

// 更新指定输出的张量描述
HIAI_Status HiAI_SingleOpExecutor_UpdateOutputTensorDesc(const HiAI_SingleOpExecutor* executor,
    uint32_t index, HiAI_SingleOpTensorDesc* output);

// 获取单算子执行需要的WorkSpace内存大小
size_t HiAI_SingleOpExecutor_GetWorkspaceSize(const HiAI_SingleOpExecutor* executor);
// 加载单算子
HIAI_Status HiAI_SingleOpExecutor_Init(HiAI_SingleOpExecutor* executor, void* workspace,
    size_t workspaceSize);
// 执行单算子
HIAI_Status HiAI_SingleOpExecutor_Execute(HiAI_SingleOpExecutor* executor,
    HiAI_SingleOpTensor* inputs[], int32_t inputNum, HiAI_SingleOpTensor* outputs[], int32_t outputNum);

#ifdef __cplusplus
}
#endif

#endif // HIAI_SINGLE_OP_H
```

#### 使用示例

假定现在有一个深度卷积算子，输入维度为1x8x224x224，输入NCHW格式排布的float32类型数据，准备好NCHW排布的权重与偏置数据，调用单算子接口推理运算获得NCHW格式float32类型的输出可以参考如下示例代码。

```
#include "hiai_single_op.h"
// 示例算子参数
HiAI_SingleOp_ConvMode convMode = HIAI_SINGLEOP_CONV_MODE_DEPTHWISE;
int64_t strides[2] = {1, 1};
int64_t dilations[2] = {1, 1};
int64_t pads[4] = {0, 0, 0, 0};
int64_t groups = 1;
HiAI_SingleOp_PadMode padMode = HIAI_SINGLEOP_PAD_MODE_SAME;
int64_t filterDims[4] = {8, 1, 3, 3};
size_t filterDataSize = 8 * 1 * 3 * 3 * sizeof(float);
void* filterData = malloc(filterDataSize);
int64_t biasDims[1] = {8};
size_t biasDataSize = 8 * sizeof(float);
void* biasData = malloc(biasDataSize);
int64_t inputDims[4] = {1, 8, 224, 224};
HiAI_SingleOp_DataType inputDataType = HIAI_SINGLEOP_DT_FLOAT;
HiAI_SingleOp_Format inputFormat = HIAI_SINGLEOP_FORMAT_NCHW;
bool inputIsVirtual = false;
// 若不指定算子输出数据类型和排布格式，请设置数据类型为HIAI_SINGLEOP_DT_UNDEFINED，排布格式为HIAI_SINGLEOP_FORMAT_RESERVED
// 然后在单算子创建完成后，调用HiAI_SingleOpExecutor_UpdateOutputTensorDesc，将输出Tensor描述更新为硬件适配最优的数据类型和排布格式
int64_t outputDims[4] = {1, 8, 224, 224};
HiAI_SingleOp_DataType outputDataType = HIAI_SINGLEOP_DT_FLOAT;
HiAI_SingleOp_Format outputFormat = HIAI_SINGLEOP_FORMAT_NCHW;
bool outputIsVirtual = false;

// 创建单算子执行器
HiAI_SingleOpOptions* options = HiAI_SingleOpOptions_Create();
HiAI_SingleOpDescriptor* convOpDesc = HiAI_SingleOpDescriptor_CreateConvolution(convMode, strides, dilations, pads, groups, padMode);
HiAI_SingleOpTensorDesc* filterDesc = HiAI_SingleOpTensorDesc_Create(filterDims, 4, HIAI_SINGLEOP_DT_FLOAT, HIAI_SINGLEOP_FORMAT_NCHW, false);
HiAI_SingleOpTensor* filter = HiAI_SingleOpTensor_CreateFromConst(filterDesc, filterData, filterDataSize);
HiAI_SingleOpTensorDesc* biasDesc = HiAI_SingleOpTensorDesc_Create(biasDims, 1, HIAI_SINGLEOP_DT_FLOAT, HIAI_SINGLEOP_FORMAT_NCHW, false);
HiAI_SingleOpTensor* bias = HiAI_SingleOpTensor_CreateFromConst(biasDesc, biasData, biasDataSize);
HiAI_SingleOpTensorDesc* inputDesc = HiAI_SingleOpTensorDesc_Create(inputDims, 4, inputDataType, inputFormat, inputIsVirtual);
HiAI_SingleOpTensorDesc* outputDesc = HiAI_SingleOpTensorDesc_Create(outputDims, 4, outputDataType, outputFormat, outputIsVirtual);
HiAI_SingleOpExecutor* executor = HiAI_SingleOpExecutor_CreateConvolution(options, convOpDesc, inputDesc, outputDesc, filter, bias);
if (executor == nullptr) {
    printf("HiAISingleOp executor create failed. \n");
}
// 后续不需要的资源建议即时销毁
HiAI_SingleOpTensorDesc_Destroy(&filterDesc);
HiAI_SingleOpTensorDesc_Destroy(&biasDesc);
HiAI_SingleOpOptions_Destroy(&options);
HiAI_SingleOpDescriptor_Destroy(&convOpDesc);
HIAI_Status ret = HiAI_SingleOpTensor_Destroy(&filter);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp filter destroy failed.\n");
}
ret = HiAI_SingleOpTensor_Destroy(&bias);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp bias destroy failed.\n");
}

// 创建输入/输出Tensor
HiAI_SingleOpTensor* input = HiAI_SingleOpTensor_CreateFromTensorDesc(inputDesc);
HiAI_SingleOpTensorDesc_Destroy(&inputDesc);
HiAI_SingleOpTensor* output = HiAI_SingleOpTensor_CreateFromTensorDesc(outputDesc);
HiAI_SingleOpTensorDesc_Destroy(&outputDesc);
// 单算子输入Tensor和输出Tensor的内存必须为ION内存以节省拷贝开销
// 创建输入Tensor成功后，可以使用以下方式获取输入Tensor内的ION内存地址进行输入数据填装
// 输出Tensor内的ION内存地址也可以用一下方式获取，在推理计算成功后用于输出数据读取
HiAI_SingleOpBuffer* inputBuffer = HiAI_SingleOpTensor_GetBuffer(input);
void* inputData = HiAI_SingleOpBuffer_GetData(inputBuffer);
size_t inputDataSize = HiAI_SingleOpBuffer_GetSize(inputBuffer);
memset(inputData, 0, inputDataSize);

// 加载单算子执行器
size_t workspaceSize = HiAI_SingleOpExecutor_GetWorkspaceSize(executor);
// 若存在多个单算子执行器，各个执行器的工作空间内存可以复用，只需要申请所需的最大工作空间即可
HiAI_SingleOpBuffer* workspaceBuffer = HiAI_SingleOpBuffer_Create(workspaceSize);
void* workspace = HiAI_SingleOpBuffer_GetData(workspaceBuffer);
ret = HiAI_SingleOpExecutor_Init(executor, workspace, workspaceSize);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp executor init failed.\n");
}

// 执行推理运算
HiAI_SingleOpTensor* inputs[] = {input};
HiAI_SingleOpTensor* outputs[] = {output};
ret = HiAI_SingleOpExecutor_Execute(executor, inputs, 1, outputs, 1);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp executor execute failed.\n");
}

// 卸载单算子执行器，释放资源
ret = HiAI_SingleOpTensor_Destroy(&input);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp input destroy failed.\n");
}
ret = HiAI_SingleOpTensor_Destroy(&output);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp output destroy failed.\n");
}
ret = HiAI_SingleOpBuffer_Destroy(&workspaceBuffer);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp workspaceBuffer destroy failed.\n");
}
ret = HiAI_SingleOpExecutor_Destroy(&executor);
if (ret != HIAI_SUCCESS) {
    printf("HiAI_SingleOp executor destroy failed.\n");
}
free(filterData);
free(biasData);
```
