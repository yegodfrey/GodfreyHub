# 业务介绍

## 业务简介

提供码识别服务，通过识别二维码、条码得到码中包含信息，并根据此信息提供服务框架，可集成于其它应用中。

码检测API涵盖了Wi-Fi，SMS等多达11类型场景的二维码/条码图像的解析，在提供有效码检测的同时，还提供基于检测结果的服务能力。本API可广泛应用于各应用程序中的扫码业务，如二维码、条码识别等业务。

## 场景介绍

这个API可以用于各种应用程序中的扫码业务，如二维码、条码识别业务。

## 功能特点

目前，码检测API提供了Wi-Fi，SMS等多达11类型场景的二维码/条码图像的解析，提供了有效的码检测、基于检测结果的服务提供能力。

### 功能使用限制

|功能|使用限制说明|
|:------|:------------------------------------------------------------------------------------------------|
|输入图片分辨率|旧接口当输入图片大小超过2000万像素时，会得到输入非法的错误码。将图像缩放后传入会有更高的效率与更低的内存。 新接口原则上没有分辨率限制，但图像应尽量大于224*224，并低于2000万像素。|
|同进程调用|本接口不支持32位APK的同进程调用。|
