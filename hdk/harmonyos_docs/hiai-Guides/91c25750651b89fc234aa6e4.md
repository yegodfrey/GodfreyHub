# 身份证识别

#### 服务介绍

身份证识别服务支持从带有身份证信息的图像或视频流中，识别出带格式的文本信息，目前支持识别的内容请参见[身份证识别部署详情](#section9564113910512)。

开发者可以使用两种方式集成身份证识别能力：

* [集成身份证识别服务](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/icr-sdk-0000001050040035)，开发者无需处理相机视频流数据，从而实现身份证识别能力的快速集成。
* 只集成HMS Core SDK，调用SDK的身份证识别接口，只能对身份证图片进行识别。

#### 应用场景

该服务可以对身份证信息做结构化识别和录入，在保险、金融、电商等需要实名认证的行业中广泛应用，不仅可以降低用户身份证信息录入错误的风险，还能以便捷的操作提升用户体验。例如，在金融类应用中使用该服务，可以自动准确识别并录入身份证中的重要信息，有效减少由用户输入错误信息而导致的业务风险。  

#### 注意事项

使用身份证识别服务时，请遵守当地的法律及规范要求。  

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/icr-sdk-0000001050040035)。

#### 端侧中国第二代身份证识别

1. 创建卡证分析器。可以通过提供的自定义参数类[MLIcrAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlicranalyzersetting-0000001050167496)创建分析器。  

   ```
   "Java"
   // 方式一：使用默认的参数配置，默认识别正面。
   MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer();
   // 方式二：使用自定义的参数配置。
   // setSideType 设置身份证正面或反面。
   // MLIcrAnalyzerSetting.FRONT：值为"FRONT"，即正面。
   // MLIcrAnalyzerSetting.BACK：值为"BACK"，即反面。
   MLIcrAnalyzerSetting setting = new MLIcrAnalyzerSetting.Factory()
       .setSideType(MLIcrAnalyzerSetting.FRONT)
       .create();
   MLIcrAnalyzer analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer(setting);
   ```

   ```
   "Kotlin"
   // 方式1：使用默认的参数配置，默认识别正面。
   val analyzer = MLCardAnalyzerFactory.getInstance().icrAnalyzer
    // 方式2：使用自定义的参数配置。
    // setSideType 设置身份证正面或反面。
    // MLIcrAnalyzerSetting.FRONT：值为"FRONT"，即正面。
    // MLIcrAnalyzerSetting.BACK：值为"BACK"，即反面。
   val setting = MLIcrAnalyzerSetting.Factory()
            .setSideType(MLIcrAnalyzerSetting.FRONT)
            .create()
   val analyzer = MLCardAnalyzerFactory.getInstance().getIcrAnalyzer(setting)
   ```

2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，支持的图片格式包括：jpg/jpeg/png/bmp，建议图片尺寸不小于512\*512像素。  

   ```
   "Java"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   MLFrame frame = MLFrame.fromBitmap(bitmap);
   ```

   ```
   "Kotlin"
   val frame = MLFrame.fromBitmap(bitmap)
   ```

3. 将创建的[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象传递给[asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlicranalyzer-0000001050169449#section14897157165311)方法进行卡证识别。  

   ```
   "Java"
   Task<MLIdCard> task = analyzer.asyncAnalyseFrame(frame);
   task.addOnSuccessListener(new OnSuccessListener<MLIdCard>() {
       public void onSuccess(MLIdCard idCard) {
           // 检测成功的处理逻辑。
       }
   }).addOnFailureListener(new OnFailureListener() {
       public void onFailure(Exception e) {
           // 检测失败的处理逻辑。
      }
   });
   ```

   ```
   "Kotlin"
   val task = analyzer!!.asyncAnalyseFrame(frame)
    task.addOnSuccessListener {
        // 检测成功的处理逻辑。
   }.addOnFailureListener {
        // 检测失败的处理逻辑。
    }
   ```

4. 识别完成，停止分析器，释放识别资源。
