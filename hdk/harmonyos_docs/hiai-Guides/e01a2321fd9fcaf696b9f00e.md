# 添加配置文件

在XCode开发环境中添加当前应用的AppGallery Connect配置文件，具体步骤请参见[添加配置文件](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274#section127301513192420)。

1. 登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择"我的项目"。
2. 在项目列表中找到您的项目，在项目列表中点击需要集成SDK的应用。
3. 在"项目设置"页面中，点击"应用"栏下的"agconnect-services.plist"下载配置文件。
4. 将"agconnect-services.plist"文件拷贝到应用级根目录下。 注意
   > * 此章节为云侧开发流程，端侧服务可忽略此步骤。
   > * 如果您在"开发"模块进行过任何修改动作，包括但不限于：设置数据存储位置、开启或管理某些API等。您需要下载最新的"agconnect-services.plist"，并替换iOS应用级根目录下已有的文件
   > * 请勿将api_key存储在agconnect-services.plist配置文件里面，同时也不要将api_key硬编码到代码里面。建议将api_key存储到云端进行获取，或者使用accessToken方式进行云端鉴权，具体请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)。
