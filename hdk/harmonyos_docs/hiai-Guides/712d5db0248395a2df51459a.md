# 对象检测与跟踪

#### 服务介绍

您可以对图片或视频中多个对象进行位置信息的跟踪与检测，基于此服务您可以进行实时定位、对象跟踪、对象分类等。对象检测和跟踪服务目前支持同时识别最多8个对象，七大类对象检测：家居用品、时尚商品、食物、地点、植物、人脸、其他。

#### 应用场景

对象检测与跟踪服务在图片审核、拍照识图等场景中有广泛应用。例如，您可以实时获取对象的位置状态，进行相关分析；还可以进行图片筛选应用的开发，通过类别划分，过滤不感兴趣的某几类对象。  

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/object-sdk-0000001050038092)。  

#### 静态图片检测

1. 创建对象分析器。  

   ```
   "Java"
   // 静态图片使用MLObjectAnalyzerSetting.TYPE_PICTURE。
   MLObjectAnalyzerSetting setting = new MLObjectAnalyzerSetting.Factory()
       .setAnalyzerType(MLObjectAnalyzerSetting.TYPE_PICTURE)
       .allowMultiResults()
       .allowClassification()
       .create();
   MLObjectAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalObjectAnalyzer(setting);
   ```

   ```
   "Kotlin"
   // 静态图片使用MLObjectAnalyzerSetting.TYPE_PICTURE。
   var setting = MLObjectAnalyzerSetting.Factory()
            .setAnalyzerType(MLObjectAnalyzerSetting.TYPE_PICTURE)
            .allowMultiResults()
            .allowClassification()
            .create()
   var analyzer = MLAnalyzerFactory.getInstance().getLocalObjectAnalyzer(setting)
   ```

2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象用于分析器检测图片，支持的图片格式包括：jpg/jpeg/png，建议图片尺寸不小于288\*288像素，不大于4096\*4096像素。  

   ```
   "Java"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   MLFrame frame = MLFrame.fromBitmap(bitmap);
   ```

   ```
   "Kotlin"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   var frame = MLFrame.fromBitmap(bitmap)
   ```

3. 调用[asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlobjectanalyzer-0000001050169461#section1046416244403)方法进行对象检测。  

   ```
   "Java"
   // 创建一个task，处理对象检测器返回的结果。
   Task<List<MLObject>> task = analyzer.asyncAnalyseFrame(frame);
   // 异步处理对象检测器返回结果。
   task.addOnSuccessListener(new OnSuccessListener<List<MLObject>>() {
       @Override
       public void onSuccess(List<MLObject> objects) {
           // 检测成功处理。
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // 检测失败处理。
       }
   });
   ```

   ```
   "Kotlin"
   // 创建一个task，处理对象检测器返回的结果。
   val task = analyzer!!.asyncAnalyseFrame(frame)
    // 异步处理对象检测器返回结果。
   task.addOnSuccessListener {
        // 检测成功处理。
   }.addOnFailureListener {
        // 检测失败处理。
   }
   ```

4. 检测完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {
       try {
           analyzer.stop();
       } catch (IOException e) {
           // 异常处理。
       }
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        try {
            analyzer!!.stop()
        } catch (e: IOException) {
            // 异常处理。
        }
   }
   ```

5. 以上示例代码中使用了异步调用方式，对象检测还支持同步调用使用[analyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlobjectanalyzer-0000001050169461#section14360015267)函数获取检测结果：  

   ```
   "Java"
   SparseArray<MLObject> objects = analyzer.analyseFrame(frame);
   ```

   ```
   "Kotlin"
   val objects = analyzer!!.analyseFrame(frame)
   ```

#### 视频流检测

开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按上文中静态图像检测的方法进行对象检测。如果开发者调用的是同步检测接口，也可以使用SDK内置的[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)类实现视频流对象检测，示例代码如下：

1. 创建对象分析器。  

   ```
   "Java"
   MLObjectAnalyzer analyzer =
   MLAnalyzerFactory.getInstance().getLocalObjectAnalyzer();
   ```

   ```
   "Kotlin"
   val analyzer = MLAnalyzerFactory.getInstance().localObjectAnalyzer
   ```

2. 开发者创建识别结果处理类"ObjectAnalyzerTransactor"，该类实现[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>接口，使用该接口中的[transactResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216#section7411382071)方法获取检测结果并实现具体业务。  

   ```
   "Java"
   public class ObjectAnalyzerTransactor implements MLAnalyzer.MLTransactor<MLObject> {
       @Override
       public void transactResult(MLAnalyzer.Result<MLObject> results) {
           SparseArray<MLObject> items = results.getAnalyseList();
           // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
           // 不可调用ML Kit提供的其他检测相关接口。
       }
       @Override
       public void destroy() {
           // 检测结束回调方法，用于释放资源等。
       }
   }
   ```

   ```
   "Kotlin"
   class ObjectAnalyzerTransactor : MLTransactor<MLObject?> {
        override fun transactResult(results: MLAnalyzer.Result<MLObject?>) {
            val items = results.analyseList
            // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
            // 不可调用ML Kit提供的其他检测相关接口。
        }

        override fun destroy() {
            // 检测结束回调方法，用于释放资源等。
        }
    }
   ```

3. 设置识别结果处理器，实现分析器与结果处理器的绑定。  

   ```
   "Java"
   analyzer.setTransactor(new ObjectAnalyzerTransactor());
   ```

   ```
   "Kotlin"
   analyzer!!.setTransactor(ObjectAnalyzerTransactor())
   ```

4. 创建[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)，该类由ML Kit SDK提供，用于捕捉相机动态视频流并传入分析器。  

   ```
   "Java"
   Context context = this.getApplicationContext();
   LensEngine lensEngine = new LensEngine.Creator(context, this.analyzer)
       .setLensType(LensEngine.BACK_LENS)
       .applyDisplayDimension(1440, 1080)
       .applyFps(30.0f)
       .enableAutomaticFocus(true)
       .create();
   ```

   ```
   "Kotlin"
   val context = applicationContext
   val lensEngine = LensEngine.Creator(context, this.analyzer)
            .setLensType(LensEngine.BACK_LENS)
            .applyDisplayDimension(1440, 1080)
            .applyFps(30.0f)
            .enableAutomaticFocus(true)
            .create()
   ```

5. 调用run方法，启动相机，读取视频流，进行识别。  

   ```
   "Java"
   // 请自行实现SurfaceView控件的其他逻辑。
   SurfaceView mSurfaceView = findViewById(R.id.surface_view);
   try {
       lensEngine.run(mSurfaceView.getHolder());
   } catch (IOException e) {
       // 异常处理逻辑。
   }
   ```

   ```
   "Kotlin"
   // 请自行实现SurfaceView控件的其他逻辑。
   val mSurfaceView: SurfaceView? = findViewById(R.id.surface_view)
   try {
        lensEngine!!.run(mSurfaceView!!.holder)
    } catch (e: IOException) {
        // 异常处理逻辑。
    }
   ```

6. 检测完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {
       try {
           analyzer.stop();
       } catch (IOException e) {
            // 异常处理。
       }
   }
   if (lensEngine != null) {
       lensEngine.release();
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        try {
            analyzer.stop()
        } catch (e: IOException) {
            // 异常处理。
        }
    }
   lensEngine?.release()
   ```

使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见[视频流检测模式多次识别场景开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-video-0000001050040139)。
