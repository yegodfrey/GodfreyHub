# 开发指南

## 应用开发

### 必须导入类

1. 在使用定制图像分类API时，将相关的定制图像分类的类添加至工程。

   ```screen
   import com.huawei.hiai.pdk.resultcode.HwHiAIResultCode;
   import com.huawei.hiai.vision.common.VisionCallback;
   import com.huawei.hiai.vision.common.VisionImage;
   import com.huawei.hiai.vision.image.detector.imageclassifier.ImageClassifierConfiguration;
   import com.huawei.hiai.vision.image.detector.imageclassifier.ImageClassifierDetector;
   import com.huawei.hiai.vision.image.detector.imageclassifier.Prediction;
   import com.huawei.hiai.vision.image.detector.PoseEstimationDetector;
   ```

### 开发

1. 定义detector实例，将此工程的Context和用户模型当做入参。

   ```screen
   Uri modelUri = copyFileFromAssetToFilesDir(context, getModelName());
   ImageClassifierDetector mImageClassifierDetector = new ImageClassifierDetector(context, modelUri); // 构造Detector
   ```

2. 调用接口检查插件状态，根据返回值调用懒加载流程。

   ```screen
   int availability = mImageClassifierDetector.getAvailability();
   if (availability == HwHiAIResultCode.AIRESULT_PLUGIN_PENDING_UPDATE) {
       Lock lock = new ReentrantLock();
       Condition condition = lock.newCondition();
       CVFaceCompVision.LoadPluginCallback cb = new CVFaceCompVision.LoadPluginCallback(lock, condition);
       mImageClassifierDetector.loadPlugin(cb);
       lock.lock();
   try {
       condition.await(90, TimeUnit.SECONDS);
   } catch (InterruptedException e) {
       Log.e("liningl", e.getMessage());
   } finally {
       lock.unlock();
   }}
   ```

3. 定义VisionImage，并传入待检测图片bitmap。

   ```screen
   VisionImage image = VisionImage.fromBitmap(bitmap);
   ```

4. 通过ImageClassifierConfiguration，配置设定类。

   ```screen
   ImageClassifierConfiguration configuration = new ImageClassifierConfiguration.Builder().build();
   ```

5. 调用ImageClassifierDetector的detect的方法，获取结果。

   ```screen
   int result_code = mImageClassifierDetector.detect(image, result, null);
   ```
