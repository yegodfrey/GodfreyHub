# 视频超分SDK

CANN提供的[视频超分场景化Demo](https://developer.huawei.com/consumer/cn/doc/hiai-Examples/sample-code-0000001052989807#section83745593308)，用于指导客户使用CANN集成调测视频超分能力。目前支持横屏下的280p（288x512）三倍超分、480p（480x896）双倍超分、540p（544x960）双倍超分，720p（736x1280）单倍超分。
