# 音频文件转写

## 服务介绍

音频文件转写服务可以将5小时内的音频文件转换成文字，支持输出标点符号，形成断句合理、易于理解的文本信息。同时，该服务支持生成带有时间戳的文本信息，便于后续进行更多功能开发。当前版本支持中英文的转写。

### 音频文件规格

|时长|大小|采样率|声道|采样精度|音频文件格式及对应编码|
|:----|:----------|:-----|:--|:----|:---------------------------------------------------|
|小于1分钟|Base64后小于4M|8k-48k|单声道|16bit|* wav（对应pcm） * m4a（对应aac） * amr（对应amr） * mp3（对应mpeg）|
|小于5小时|300M|8k-48k|单声道|16bit|* wav（对应pcm） * m4a（对应aac） * amr（对应amr） * mp3（对应mpeg）|

## 应用场景

该服务广泛应用于日常生活及工作中的众多领域。例如，在与别人聊天时，如果用户所处环境不方便接听音频，可通过音频文件转写服务将短消息转化转成文字。另外，在视频字幕制作场景中，由于该服务支持带时间戳的转写，可以把视频片段中的音频转写成文字，并标记时间戳，可以极大提升字幕配置的效率。

## 注意事项

* 音频文件转写服务只提供云侧接口，调测和使用时需保证设备可正常访问互联网。
* 如果转写任务和上传的文件中包含个人数据，请点击[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)界面"请设置你的任务存留期限为"配置存留时间（24小时-168小时），如果不设置存留期限，默认时间为48小时。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/audio-sdk-0000001050038090)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 新建音频文件转写引擎并初始化；新建音频文件转写配置器。

   ```java
   "Java"
   // 新建音频文件转写配置器。
   MLRemoteAftSetting setting = new MLRemoteAftSetting.Factory()
       // 设置转写语言编码，使用BCP-47规范，当前支持中文普通话、英文转写。
       .setLanguageCode("zh")
       // 设置是否输出句子出现在音频文件中的时间偏移值,默认为false。
       // true: 除返回整个音频的文字转写结果外,连带输出句子在音频中的时间偏移信息。
       // false: 仅返回整个音频的文字转写结果。
       .enableSentenceTimeOffset(true)
       // 设置是否在转写输出的文本中自动增加标点符号,默认为false。
       // true：转写结果文字中自动添加标点符号。
       // false：转写结果文字中不自动添加标点符号。
       .enablePunctuation(true)
       .create();
   // 新建音频文件转写引擎。
   MLRemoteAftEngine engine = MLRemoteAftEngine.getInstance(); 
   // 引擎初始化，传入当前context。
   engine.init(this);
   ```

   * 长语音转写：适用于时长大于1分钟的音频文件。

     ```screen
     "Java"
     private MLRemoteAftListener aftListener = new MLRemoteAftListener() {
         @Override
         public void onInitComplete(String taskId, Object ext) {
             Log.e(TAG, "MLAsrCallBack onInitComplete");
             // 长语音初始化完成，开始转写
             start(taskId);
         }
         @Override
         public void onUploadProgress(String taskId, double progress, Object ext) {
             Log.e(TAG, " MLAsrCallBack onUploadProgress");
         }
         @Override
         public void onEvent(String taskId, int eventId, Object ext) {
             // 用于长语音
             Log.e(TAG, "MLAsrCallBack onEvent" + eventId);
             if (MLAftEvents.UPLOADED_EVENT == eventId) { // 文件上传成功
                 // 获取转写结果
                 startQueryResult(taskId);
             }
         }
         @Override
         public void onResult(String taskId, MLRemoteAftResult result, Object ext) {
             Log.e(TAG, "MLAsrCallBack onResult taskId is :" + taskId + " ");
             if (result != null) {
                 Log.e(TAG, "MLAsrCallBack onResult isComplete: " + result.isComplete());
                 if (result.isComplete()) {
                     TimerTask timerTask = timerTaskMap.get(taskId);
                     if (null != timerTask) {
                         timerTask.cancel();
                         timerTaskMap.remove(taskId);
                     }
                     if (result.getText() != null) {
                         Log.e(TAG, taskId + " MLAsrCallBack onResult result is : " + result.getText());
                         tvText.setText(result.getText());
                     }
                     List<MLRemoteAftResult.Segment> words = result.getWords();
                     if (words != null && words.size() != 0) {
                         for (MLRemoteAftResult.Segment word : words) {
                             Log.e(TAG, "MLAsrCallBack word  text is : " + word.getText() + ", startTime is : " + word.getStartTime() + ". endTime is : " + word.getEndTime());
                         }
                     }
                     List<MLRemoteAftResult.Segment> sentences = result.getSentences();
                     if (sentences != null && sentences.size() != 0) {
                         for (MLRemoteAftResult.Segment sentence : sentences) {
                             Log.e(TAG, "MLAsrCallBack sentence  text is : " + sentence.getText() + ", startTime is : " + sentence.getStartTime() + ". endTime is : " + sentence.getEndTime());
                         }
                     }
                 }
             }
         }
         @Override
         public void onError(String taskId, int errorCode, String message) {
             Log.i(TAG, "MLAsrCallBack onError : " + message + "errorCode, " + errorCode);
             switch (errorCode) {
                 case MLAftErrors.ERR_AUDIO_FILE_NOTSUPPORTED:
                     break;
             }
         }
     };
     // 上传转写任务
     private void start(String taskId) {
         Log.e(TAG, "start");
         engine.startTask(taskId);
     }
     // 获取转写结果
     private Map<String, TimerTask> timerTaskMap = new HashMap<>();
     private void startQueryResult(final String taskId) {
         Timer mTimer = new Timer();
         TimerTask mTimerTask = new TimerTask() {
             @Override
             public void run() {
                 engine.getLongAftResult(taskId);
             }
         };
         // 10s轮训获取长语音转写结果
         mTimer.schedule(mTimerTask, 5000, 10000);
         // 界面销毁前要清除 timerTaskMap
         timerTaskMap.put(taskId, mTimerTask);
     }
     ```

     ```screen
     "Kotlin"
     private val aftListener: MLRemoteAftListener = object : MLRemoteAftListener {
          override fun onInitComplete(taskId: String, ext: Any?) {
              Log.e(ContentValues.TAG, "MLAsrCallBack onInitComplete")
              // 长语音初始化完成，开始转写
              start(taskId)
          }

          override fun onUploadProgress(taskId: String, progress: Double, ext: Any?) {
              Log.e(ContentValues.TAG, " MLAsrCallBack onUploadProgress")
          }

          override fun onEvent(taskId: String, eventId: Int, ext: Any?) {
              // 用于长语音
              Log.e(ContentValues.TAG, "MLAsrCallBack onEvent$eventId")
              if (MLAftEvents.UPLOADED_EVENT == eventId) { // 文件上传成功
                  // 获取转写结果
                  startQueryResult(taskId)
              }
          }

          override fun onResult(taskId: String, result: MLRemoteAftResult, ext: Any?) {
              Log.e(ContentValues.TAG, "MLAsrCallBack onResult taskId is :$taskId ")
              if (result != null) {
                  Log.e(ContentValues.TAG, "MLAsrCallBack onResult isComplete: " + result.isComplete)
                  if (result.isComplete) {
                      val timerTask = timerTaskMap[taskId]
                      if (null != timerTask) {
                          timerTask.cancel()
                          timerTaskMap.remove(taskId)
                      }
                      if (result.text != null) {
                          Log.e(ContentValues.TAG, taskId + " MLAsrCallBack onResult result is : " + result.text)
                          tvText.setText(result.getText());
                      }
                      val words = result.words
                      if (words != null && words.size != 0) {
                          for (word in words) {
                              Log.e(ContentValues.TAG, "MLAsrCallBack word  text is : " + word.text + ", startTime is : " + word.startTime + ". endTime is : " + word.endTime)
                          }
                      }
                      val sentences = result.sentences
                      if (sentences != null && sentences.size != 0) {
                          for (sentence in sentences) {
                              Log.e(ContentValues.TAG, "MLAsrCallBack sentence  text is : " + sentence.text + ", startTime is : " + sentence.startTime + ". endTime is : " + sentence.endTime)
                          }
                      }
                  }
              }
          }

          override fun onError(taskId: String, errorCode: Int, message: String) {
              Log.i(ContentValues.TAG, "MLAsrCallBack onError : " + message + "errorCode, " + errorCode)
              when (errorCode) {
                  MLAftErrors.ERR_AUDIO_FILE_NOTSUPPORTED -> {
                  }
              }
          }
      }

      // 上传转写任务
     private fun start(taskId: String) {
          Log.e(ContentValues.TAG, "start")
          engine.startTask(taskId)
      }

      // 获取转写结果
     private val timerTaskMap: MutableMap<String, TimerTask> = HashMap()
     private fun startQueryResult(taskId: String) {
          val mTimer = Timer()
          val mTimerTask: TimerTask = object : TimerTask() {
              override fun run() {
                 engine.getLongAftResult(taskId)
              }
          }
          // 10s轮训获取长语音转写结果
          mTimer.schedule(mTimerTask, 5000, 10000)
          // 界面销毁前要清除 timerTaskMap
          timerTaskMap[taskId] = mTimerTask
     }
     ```

   ```java
   "Java"

   engine.shortRecognize(uri, setting);
   // longRecognize为长语音转写接口，用于转写时长大于1分钟，小于5小时的语音。
   engine.longRecognize(uri, setting);
   ```
