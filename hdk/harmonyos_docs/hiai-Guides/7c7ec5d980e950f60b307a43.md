# 扫一扫即搜新闻，Newswav与HUAWEI ML Kit共同构建新闻阅读新玩法

## Newswav简介

Newswav是马来西亚一款既简单又人性化的新闻平台，汇聚不同来源的新闻和内容，提供马来西亚文、中文和英文三种阅读语言。

## 业务挑战

Newswav是提供新闻汇聚的平台，信息繁多，缺少对目标信息进行快速的搜索的功能。

## 解决方案

凭借HUAWEI ML Kit高性能的文本识别服务，Newswav打造出全新新闻阅读体验。仅需扫描感兴趣的关键字，即可为用户搜索相关新闻内容。

* 新增文本识别功能，支持业务场景扩展：扫描感兴趣的关键字，便可快速搜索相关新闻，让用户从繁多的信息中快速找到想要的内容。
* 支持倾斜、弯曲文本和多语种扫描识别：ML Kit支持文本倾斜至30度或弯曲至45度，仍能保证准确识别，支持识别等多种语言，有效支持Newswav业务开展。
* 一次开发，支持非华为手机，覆盖所有机型：ML Kit支持华为及非华为手机，开发者只需要一次集成，即可覆盖市面上所有安卓系统机型。

## 合作收益

* Newswav 一次集成获取多语种文字识别功能，满足马来西亚多语言的使用环境的需求。


* Newswav用户 让客户快速的对看到文本的信息进行相关新闻的搜索，简单易上手，方便又快捷。
