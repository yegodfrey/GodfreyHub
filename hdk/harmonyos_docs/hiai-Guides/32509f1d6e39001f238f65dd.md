# 云端托管

若您选择通过云端托管您的模型，则可以减少您的应用包大小，但在模型首次下载之前，模型相关的功能将无法使用。云端托管支持转换的模型详细信息请参见[云端托管支持转换的模型列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)。
> 说明
>
> 云端托管版本需要和端侧SDK版本配套，具体请参见[集成自定义模型公共SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/custom-model-sdk-0000001051292475)。

1. 把模型上传到云侧。
   1. 在[华为开发者联盟](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站上，进入"我的项目"，选择您创建好的项目。
   2. 在 "项目设置"页面左子树中选择"构建 > 机器学习服务"进入机器学习服务页面，然后选择"Custom ML"。

   4. 填写基本信息，模型名称和关于模型的描述信息，模型名称只能是英文大小写字母、数字、下划线和横杠。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250514172349.47488096541041812582735044847955:50001231000000:2800:D948A369878DC56E5D4E33D6A53EE6F6E7642F8CC3DF43D6D9ABF82EFAB285E3.png "点击放大")

   5. 上传模型。
      1. 选择MindSpore Lite/OM/MC类型文件进行上传，支持的转换算子详细请参见[算子支持](https://www.mindspore.cn/doc/note/zh-CN/r1.1/operator_list_lite.html)，关于MindSpore的更多资料请参见[MindSpore](https://www.mindspore.cn/lite)。

3. （端侧）程序运行时通过远程下载的方式下载到本地加载。

   推理前先将模型下载下来，下载成功后才可以使用模型进行推理。
   1. 设置下载策略。

      ```java
      "Java"
      final MLModelDownloadStrategy strategy = new MLModelDownloadStrategy
          .Factory()
          .needWifi()
          .setRegion(MLModelDownloadStrategy.REGION_DR_CHINA) // 设置站点区域，目前支持站点区域有：REGION_DR_CHINA，REGION_DR_SINGAPORE，REGION_DR_GERMAN，REGION_DR_RUSSIA（站点区域需要和配置AppGallery Connect时选择的服务接入站点保持一致）。
          .create();
      String remoteModelName = "yourModelName";
      final MLCustomRemoteModel customRemoteModel = new MLCustomRemoteModel.Factory(remoteModelName).create();
      ```

      ```javascript
      "Kotlin"
      val strategy = MLModelDownloadStrategy.Factory()
               .needWifi()
               .setRegion(MLModelDownloadStrategy.REGION_DR_CHINA) // 设置站点区域，目前支持站点区域有：REGION_DR_CHINA，REGION_DR_SINGAPORE，REGION_DR_GERMAN，REGION_DR_RUSSIA（站点区域需要和配置AppGallery Connect时选择的服务接入站点保持一致）。
               .create()
       var remoteModelName = "yourModelName"
       val customRemoteModel = MLCustomRemoteModel.Factory(remoteModelName).create()
      ```

   2. 根据下载策略下载远端模型到本地。如果模型已经下载则不会重复下载；如果模型未下载，或模型有较新的版本，则会从ML Kit模型托管平台异步下载此模型。您可以自己制定策略通过调用downloadModel接口保证您的模型是最新的。

      ```java
      "Java"
      // 设置监听器。
      MLModelDownloadListener modelDownloadListener = new MLModelDownloadListener() {
          @Override
          public void onProcess(long alreadyDownLength, long totalLength) {
              // 对下载进度进行处理。
          }
      };
      // 启动下载。
      MLLocalModelManager.getInstance().downloadModel(customRemoteModel, strategy, modelDownloadListener);
      ```

      ```javascript
      "Kotlin"
      // 设置监听器。
      val modelDownloadListener = MLModelDownloadListener { alreadyDownLength, totalLength ->
           // 对下载进度进行处理。
      }
      // 启动下载。
      MLLocalModelManager.getInstance().downloadModel(customRemoteModel, strategy, modelDownloadListener)
      ```

   > 说明
   > * 您可以选择在应用初始化时启动模型下载，或者在使用模型前随时启动下载任务。
   > * 您可以通过配置A/B测试来优化应用体验，灵活配置远程模型，详情请参见[A/B测试](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-introduction-0000001058210679)。
