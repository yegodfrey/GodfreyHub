# 业务介绍

## 业务简介

文档校验能够实现对文档翻拍过程的辅助增强功能，自动识别图片中的文档，返回文档在原图中的位置信息。这里的文档可泛指外形方正的事物，比如书本、相片、画框等。包含两个子功能：文档检测和文档校正。

根据文档在原始图片中的位置信息校正文档的拍摄角度，自动将拍摄视角调整到正对文档的角度上。此功能在纸质旧照片、信件、画作等翻拍为电子版的场景中，有出色表现。

* **文档检测** **：**识别图片中的文档，返回文档在原图中的位置信息。


* **文档校正** **：**根据文档在原始图片中的位置信息校正文档的拍摄角度（可自定义校正的区域）。

## 场景介绍

* **纸质旧照片、信件翻拍成电子版** **：**总有些泛黄的旧照片却带着不褪色的回忆，总有些浸润时光的信件却挡不住岁月的磨洗。我们没有条件像博物馆那样保存这些私人文物，但是可以把它们转化成电子版，永久珍藏，而本API就是能帮助你把它们翻拍成端端正正的样子。


* **博物馆、艺术展览中的妙手偶得** **：**有没有在画展中有这样的经历：遇到的了好喜欢的作品，但是拍起来总是角度不对。或者是作品挂太高了，或者是人太多挤不过去，或者是正对着的角度不巧有强烈的灯光反光。还是本API，轻轻松松帮助你把它们翻拍成端端正正的样子。

## 功能特点

利用本API，可以大大节省算法开发的时间，让你专注在要完成创造性应用上。
