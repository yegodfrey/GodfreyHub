开发指南 应用开发 [h2]必须导入类 在使用人脸比对API时，将实现人脸比对的相关的类添加至工程。 
    
    import com.huawei.hiai.vision.visionkit.common.Frame; // 加载Frame类
    import com.huawei.hiai.vision.face.FaceComparator; // 加载人脸比对类
    import com.huawei.hiai.vision.visionkit.face.FaceCompareResult; // 加载人脸比对结果类
    import com.huawei.hiai.vision.common.VisionBase; //加载连接服务的静态类
    import com.huawei.hiai.vision.common.ConnectionCallback; // 加载连接服务的回调函数
    import com.huawei.hiai.vision.common.VisionImage; // 加载VisionImage
    import com.huawei.hiai.vision.visionkit.face.FaceCompareConfiguration; // 加载人脸比对配置类

[h2]开发
    1. 应用VisionBase静态类进行初始化，拿到服务连接的结果。
           
           VisionBase.init(MainActivity.this, new ConnectionCallback(){
               @Override
               public void onServiceConnect(){
                   Log.i(LOG_TAG, "onServiceConnect");
               }
           
               @Override
               public void onServiceDisconnect(){
                   Log.i(LOG_TAG, "onServiceDisconnect");
               }
           });

    2. 定义人脸比对实例，将应用的Context当做入参。
           
           FaceComparator mFaceComparator = new FaceComparator(mContext);

    3. 定义Frame，并传入人脸图片bitmap。
           
           Frame frame1 = new Frame();
           frame1.setBitmap(mBitmap1);
           
           Frame frame2 = new Frame();
           frame2.setBitmap(mBitmap2);

    4. 调用faceCompare方法得到结果。
           
           JSONObject json = mFaceComparator.faceCompare(frame1,frame2,null);
           FaceCompareResult mFaceCompareResult = mFaceComparator.convertResult(json);
