# NPU算子库动态升级介绍

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260104150612.51146129490736924982979397176804:50001231000000:2800:0448F43713ECF47C0BE9FB3289176365C6206DD0CE103C7B52BCE36EB48C3E17.png)  
Harmony DDK目前不支持NPU算子动态库升级。

计算能力增强功能开放前，NPU算子库的功能、性能优化需要随EMUI升级发布，周期较长，用户无法及时享受到NPU算子库更新带来的功能、性能提升。CANN DDK V520计算能力增强功能支持NPU算子库动态升级能力。可以使用户及时享受到NPU算子库更新带来的功能、性能提升。NPU算子库动态升级能力工作原理如下：

1. 更新NPU算子库。 NPU算子库托管于华为云侧服务器，系统预置的computecapability APP检测到NPU算子库存在新版本后，系统同时在设备充电、连接WiFi、灭屏状态下从云端自动更新。

2. 模型编译。 模型编译时，若满足计算能力增强功能使能，调用computecapability APP提供的服务，可完成模型编译，不再依赖系统中预置的NPU算子库。若不满足计算能力增强功能使能，继续使用系统提供的NPU算子库。

3. 模型加载、运行。 模型编译完成后，模型的加载、运行使用ROM侧资源。
