# 模型在线编译使能异构调优配置

#### V1接口实现异构调优

V1接口实现异构示例关键步骤如下，完整接口使用参考[模型管家V1-BuildModel接口](https://developer.huawei.com/consumer/cn/doc/hiai-References/buildmodel-0000001053089431)。

```
BuildOptions options;
ModelDeviceConfigV1 modelDeviceConfig;
// 1.读取model_deviceconfig.json文件
std::ifstream read(heterConfigPath);
std::string buffer((std::istreambuf_iterator<char>(read)), std::istreambuf_iterator<char>());
if (buffer.empty()) {
    LOGE("[AI_DEMO_ASYNC] cannot find %s.", heterConfigPaths.c_str());
    return FAILED;
}
// 2.调用ParseFromJson接口解析json配置信息，存入modelBuildOptions.modelDeviceConfig中
ret = ModelDeviceConfigParser::ParseFromJson(
      reinterpret_cast<uint8_t*>(const_cast<char*>(buffer.data())), buffer.size(), modelDeviceConfig);
if (ret != hiai::SUCCESS) {
    LOGE("[AI_DEMO_ASYNC] ParseFromJson fail.");
}
options.mode = modelDeviceConfig.mode;
options.opExecuteDeviceConfig = std::move(modelDeviceConfig.opExecuteDeviceConfig);
// 3.调用模型BuildModel接口实现异构，异构配置通过options传入
ret = modelBuilder->BuildModel(inputBuffers, outPutBuffer, outPutBufferSize, options);
```

V1接口的ModelDeviceConfigParser::ParseFromJson接口关键信息：

```
Status ModelDeviceConfigParser::ParseFromJson(
    const uint8_t* jsonBuffer, size_t bufferSize, ModelDeviceConfigV1& modelDeviceConfig)
{
    ge::ExecuteDeviceHelper executeDeviceHelper;
    ge::ExecuteDeviceHelper::ExecuteDeviceConfig deviceConfig;
    if (executeDeviceHelper.ParseDeviceConfigFromJson(jsonBuffer, bufferSize, deviceConfig) != SUCCESS) {
        ALOGE("ParseDeviceConfigFromJson fail");
        return FAILURE;
    }
    // 获取modelDeviceConfig信息
    modelDeviceConfig.mode =
        (deviceConfig.fallBackMode == ge::ExecuteFallBackMode::ENABLE ? ExecuteDeviceSelectMode::AUTO :
                                                                        ExecuteDeviceSelectMode::CUSTOM);
    if (ConvertDeviceType(deviceConfig.opDeviceOrder, modelDeviceConfig.opExecuteDeviceConfig) != SUCCESS) {
        ALOGE("ConvertDeviceType fail");
        return FAILURE;
    }
    return SUCCESS;
}
```

#### 异构调优约束说明

* 当前版本的异构调优工具性能模式不能集成libhiai_hcl_model_runtime.so。
* 若使用异构调优工具性能模式生成的异构配置文件进行异构加速推理，则DDK侧只能集成libhiai.so，且当前版本不能使用插件升级，如果DDK侧集成了libhiai_hcl_model_runtime.so或者使能插件升级，则推理性能与预期不符。若使用功耗模式则DDK侧可以集成libhiai.so、libhiai_hcl_model_runtime.so、libcpucl.so（按需选择，其中libhiai.so为必选）。
* 华为自研NPU平台的手机（Kirin9000及以后芯片）支持使用异构调优功能，手机系统为HarmonyOS 3.0以前版本仅支持功耗模式，3.0及以后版本新增异构调优工具中的最佳性能模式。
