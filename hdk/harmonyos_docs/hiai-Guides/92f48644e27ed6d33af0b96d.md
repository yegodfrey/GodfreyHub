# 开发指南

## 应用开发

### 必须导入类

1. 添加依赖如下，使用ASR功能，需要在项目中依赖huawei-hiai-asr和huawei-hiai-pdk两个sdk，请参考：接入准备/HUAWEI DevEco Studio接入流程或Android Studio接入流程。

   ```screen
   dependencies {
       implementation 'com.huawei.hiai.hiai-engine:huawei-hiai-pdk:11.0.1.300'
       implementation 'com.huawei.hiai.hiai-engine:huawei-hiai-asr:11.0.1.300'
   }
   ```

2. 在使用语音识别API时，将相关的语音识别的类添加至工程。

   ```screen
   import com.huawei.hiai.asr.AsrConstants; // 参数常量的定义类
   import com.huawei.hiai.asr.AsrError; // 错误码的定义类
   import com.huawei.hiai.asr.AsrListener; // 加载语音识别监听类
   import com.huawei.hiai.asr.AsrRecognizer; // 加载语音识别类
   import com.huawei.hiai.asr.AsrEvent; // 加载ASR识别中上报事件的类
   ```

3. 如果要用通过引擎录音获取数据，需要申请录音权限。

   ```screen
   <uses-permission android:name="android.permission.RECORD_AUDIO"/>
   ```

3. 初始化ASR引擎。

   ```screen
   mAsrRecognizer = AsrRecognizer.createAsrRecognizer(this); //创建引擎
   /*配置语音的输入来源:
   ASR_SRC_TYPE_FILE------语音输入来自文件；
   ASR_SRC_TYPE_RECORD------语音输入来自mic录入；
   ASR_SRC_TYPE_PCM------语音输入来自PCM数据流；
   */
   Intent initIntent = new Intent();//初始化引擎
   /*设置VAD（Voice Activity Detection）时间
   ASR_VAD_END_WAIT_MS后置VAD时间，检查到说话停止时间达到vad时间，识别停止
   ASR_VAD_FRONT_WAIT_MS前置VAD时间，检查识别开始后没有说话达到vad时间，识别停止
   */
   initIntent.putExtra(AsrConstants.ASR_VAD_END_WAIT_MS, 2000);
   initIntent.putExtra(AsrConstants.ASR_VAD_FRONT_WAIT_MS, 4000);
   initIntent.putExtra(AsrConstants.ASR_AUDIO_SRC_TYPE, AsrConstants.ASR_SRC_TYPE_RECORD);
   mAsrRecognizer.init(initIntent , mMyAsrListener);
   ```

4. 更新词图。

   支持contact、address、app、song、others 5种类型。长度、大小限制：

   通信录人名<=2000条；应用名<=500条；歌曲名<=2000条；地名<=10000条；其它类型<=1000条；每个类型的单条长度<=20。

   ```screen
   ArrayList<String> nameList = new ArrayList<>();
   JSONObject data = new JSONObject();
   JSONArray jsonArray = new JSONArray();
   jsonArray.put("筚路蓝缕");
   try {
       data.put(AsrConstants.ASR_LEXICON_NAME_OTHERS, jsonArray);
   } catch (JSONException e) {
       Log.e(TAG, "JSON Exception");
   }
   nameList.add(AsrConstants.ASR_LEXICON_NAME_OTHERS); // 热词名称类型列表添加其他类型热词
   Intent updateIntent = new Intent();
   updateIntent.putExtra(AsrConstants.ASR_LEXICON_NAME, nameList); // 添加热词名称类型列表
   updateIntent.putExtra(AsrConstants.ASR_LEXICON_ITEMS, data.toString()); // 添加热词数据列表
   mAsrRecognizer.updateLexicon(updateIntent); //调用更新热词方法
   ```

5. 识别。用户可以不设置参数，使用默认参数。
   1. Vad时间在init时候设置，startListening时重新设置，会覆盖init时候设置的vad值。

      ```screen
      Intent intent = new Intent();
      intent.putExtra(AsrConstants.ASR_VAD_FRONT_WAIT_MS, 4000);//设置前端静音检测时间
      intent.putExtra(AsrConstants.ASR_VAD_END_WAIT_MS, 5000); //设置后端静音检测时间
      intent.putExtra(AsrConstants.ASR_TIMEOUT_THRESHOLD_MS, 20000);//设置超时时间
      mAsrRecognizer.startListening(intent);
      ```

   2. 如果是识别音频文件，需要将音频文件路径传入。

      ```screen
      Intent intent = new Intent();
      if (srcType == AsrConstants.ASR_SRC_TYPE_FILE) {
          intent.putExtra(AsrConstants.ASR_SRC_FILE, filePath);
      }
      mAsrRecognizer.startListening(intent);
      ```

   3. 如果是从PCM数据流获取到的数据，需要在startListening接口调用之后，将获取的数据通过writePcm下发给引擎。

      ```screen
      byte[] buffer = new byte[]{0, 1, 0, 10, 1};
      mAsrRecognizer.writePcm(buffer, buffer.length);
      ```

6. 取消识别或者停止识别。
   1. 取消识别，识别取消且没有最终识别结果返回：

      ```screen
      mAsrRecognizer.cancel();//取消识别
      ```

   2. 停止识别，希望获取识别结果时调用：

      ```screen
      mAsrRecognizer.stopListening();//停止识别
      ```

7. 引擎释放：销毁ASR引擎。

   ```screen
   mAsrRecognizer.destroy();
   ```

8. 识别结果：AsrListener中的onPartialResults返回中间识别结果， onResult(Bundle results)方法返回最终结果。结果封装在json格式中，需要解析得到。

   示例结果（Json）：

   ```screen

       "engine_type": "local_engine",
       "result": [{
           "confidence": 0,

           "word": "返回的结果。"
       }],
       "result_type": "lvcsr",
       "scenario_type": 5
   }}]
   ```
