# 图像分割

## 服务介绍

图像分割服务可以将图片中相同元素（如人体、植物、天空等）的部分从图像整体中"分割"出来，当前支持人像、天空、植物、美食、猫狗、花朵、水面、沙面、建筑、山峰、其他等11大类元素的分割，支持静态图片分割和动态视频流分割，提供人像分割和多类别分割两种能力。支持精细化分割，平均交并比mIoU（衡量图像分割精度的一个指标）优于业界参考水平。

多类别分割返回值为各元素的坐标数组。例如：一张图像中包含人像、天空、植物、猫狗这4种元素，返回值为这4种元素的坐标数组，以便后续进一步处理不同的元素，如替换天空元素。

人像分割返回值包括：人像元素的坐标数组、背景透明的人像前景图以及人像为白色，背景为黑色的灰度图。您的App可以在此返回值的基础上做进一步处理，如视频背景替换、人像抠图等。

## 应用场景

图像分割服务可以广泛应用于影像娱乐类App。例如，图像编辑类App集成该服务，可以快速更换图像背景。拍照类App集成该服务，可以识别不同的元素进行不同的优化，例如对植物元素的优化，让植物显得更加青翠。

## 注意事项

图像分割服务有两种模型包：人像分割模型包和多类型分割模型包。

人像分割模型包用于分割人像和背景，支持视频流和图片分割。如果您只需要分割人像和背景，建议使用人像分割模型包。

多类型分割模型包支持人像、天空、植物、美食、猫狗、花朵、水面、沙面、建筑、山峰、其他11大类元素的分割，当前仅支持图片分割，不支持视频流分割。

## 开发步骤

在开始开发之前，需要完成对应的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/download-agc-0000001051136994)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ios-seg-sdk-0000001055603480)。

### 静态图片分割

1. 创建图像分割器。
   * 集成人像分割模型包

     ```codeblock
     // 方式一：使用默认参数配置图像分割检测器。
     // 默认模式为：人像分割模式 + 精度模式，返回人像分割的所有分割结果（像素级标记信息、背景透明的人像图、人像为白色，背景为黑色的灰度图以及被分割的原图）。
     MLImageSegmentationAnalyzer *analyzer = [MLImageSegmentationAnalyzer sharedInstance];

     // 方式二：使用自定义参数MLImageSegmentationSetting配置图像分割检测器。
     MLImageSegmentationSetting *setting = [[MLImageSegmentationSetting alloc] init];
     // 设置分割精细模式，YES为精细分割模式，NO为速度优先分割模式。
     [setting setExact:YES];
     // 设置分割模式为人像分割。
     [setting setAnalyzerType:MLImageSegmentationAnalyzerTypeBody];
     // 设置返回结果种类。
     // MLImageSegmentationSceneAll: 返回所有分割结果，包括：像素级标记信息、背景透明的人像图和人像为白色，背景为黑色的灰度图以及被分割的原图。
     // MLImageSegmentationSceneMaskOnly: 只返回像素级标记信息。
     // MLImageSegmentationSceneForegroundOnly: 只返回背景透明的人像图。
     // MLImageSegmentationSceneGrayScaleOnly: 只返回人像为白色，背景为黑色的灰度图。
     [setting setScene:MLImageSegmentationSceneForegroundOnly];

     MLImageSegmentationAnalyzer *analyzer = [MLImageSegmentationAnalyzer sharedInstance];
     [analyzer setImageSegmentationAnalyzer:setting];
     ```

   * 集成多类型分割模型包

     使用多类型分割模型包对图像进行多类别分割时，只支持通过图像分割检测配置器MLImageSegmentationSetting创建图像分割检测器。

     ```codeblock
     MLImageSegmentationSetting *setting = [[MLImageSegmentationSetting alloc] init];
     // 设置分割精细模式，YES为精细分割模式，NO为速度优先分割模式。
     [setting setExact:YES];
     // 设置分割模式为图像分割。
     [setting setAnalyzerType:MLImageSegmentationAnalyzerTypeImage];

     MLImageSegmentationAnalyzer *analyzer = [MLImageSegmentationAnalyzer sharedInstance];
     [analyzer setImageSegmentationAnalyzer:setting];
     ```

2. 调用[asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/ios-mlimagesegmentationanalyzer-0000001054182211#section164141834112310)方法进行图像分割。

   ```codeblock
   // 异步处理图像分割检测器返回结果。
   [analyzer asyncAnalyseFrame:frame addOnSuccessListener:^(MLImageSegmentation * _Nonnull imagesegmentation) {
       // 检测成功处理。
   } addOnFailureListener:^(NSError * _Nonnull error) {
       // 检测失败处理。
   }];
   ```

3. 检测完成，停止分析器，释放检测资源。

   ```codeblock
   [analyzer stop];
   ```

以上示例代码中使用了异步调用方式，图像分割还支持同步调用使用[analyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/ios-mlimagesegmentationanalyzer-0000001054182211#section1726413212314)函数获取检测结果：

```codeblock
MLImageSegmentation *segmentation = [analyzer analyseFrame:frame];
```

### 视频流分割（仅人像分割模型包支持）

开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按上文中静态图像检测的方法进行对象检测。示例代码如下：

1. 创建图像分割检测器。

   ```codeblock
   // 使用自定义参数MLImageSegmentationSetting配置图像分割检测器。
   MLImageSegmentationSetting *setting = [[MLImageSegmentationSetting alloc] init]
   // 设置分割精细模式，YES为精细分割模式，NO为速度优先分割模式。
   [setting setExact:NO];
   // 设置返回结果种类。
   // MLImageSegmentationSceneAll: 返回所有分割结果，包括：像素级标记信息、背景透明的人像图和人像为白色，背景为黑色的灰度图以及被分割的原图。
   // MLImageSegmentationSceneMaskOnly: 只返回像素级标记信息。
   // MLImageSegmentationSceneForegroundOnly: 只返回背景透明的人像图。
   // MLImageSegmentationSceneGrayScaleOnly: 只返回人像为白色，背景为黑色的灰度图。
   [setting setScene:MLImageSegmentationSceneForegroundOnly];
   // 设置分割模式，视频流分割时，仅支持设置MLImageSegmentationAnalyzerTypeBody（只分割人体和背景）。
   [setting setAnalyzerType:MLImageSegmentationAnalyzerTypeBody];

   MLImageSegmentationAnalyzer *analyzer = [MLImageSegmentationAnalyzer sharedInstance];
   [analyzer setImageSegmentationAnalyzer:setting];
   ```

2. 将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，按静态图像检测的方法进行对象检测。

   ```codeblock
   MLFrame *frame = [[MLFrame alloc] initWithImage:image];
   MLImageSegmentation *segmentation = [analyzer analyseFrame:frame];
   ```

3. 检测完成，停止分析器，释放检测资源。

   ```codeblock
   [analyzer stop];
   ```
