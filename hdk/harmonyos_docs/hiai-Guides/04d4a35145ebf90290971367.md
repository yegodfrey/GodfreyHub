# HUAWEI DevEco Studio接入流程

HUAWEI HiAI是面向移动终端的AI计算平台，构建三层AI生态：芯片能力开放、应用能力开放和服务能力开放，芯、端、云结合的三层开放平台为用户和开发者带来更多的非凡体验。HUAWEI HiAI Engine应用能力开放，轻松将多种AI能力与应用集成，让应用更加智慧强大。应用能力开放包括：CV，即计算机视觉，计算机能够模拟人的视觉系统感知周围环境，判断、识别、理解空间组成。能力包括图片识别、人体识别、文本识别等。ASR，即自动语音识别，将人的声音转化为文本，便于计算机进一步进行解析理解。能力包括语音识别等。NLU，即自然语言理解，与ASR有机结合，让计算机理解人的声音或文本，进行沟通或自然的动作。能力包括分词、文本的实体识别等。

SDK名称：HUAWEI HiAI Engine SDK

包名：com.huawei.hiai

版本号：11.0.3.300

md5值：0fb3c3561a1453347e1455f1132d0be2

开发者：华为软件技术有限公司

隐私政策：[SDK隐私声明](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001054024739)

合规指引：[HUAWEI HiAI Engine SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/compliance-usage-guide-0000001729879081)

HUAWEI DevEco Studio目前处于Beta阶段，需要向华为申请试用权限。同时也期待您在使用过程中给我们反馈您宝贵的意见，我们将持续进行优化，提升您的使用体验。

在使用HUAWEI DevEco Studio进行应用开发前，您应该提前知道如何"[获取Beta权限](#section022919399323)"和"[获取技术支持](#section972534611328)"通道。

## 获取Beta权限

您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。

1. 访问[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
2. 注册华为开发者联盟帐号，并点击右上角头像旁边的下拉图标，点击"立即前往实名认证上"传信息进行实名认证。
3. 实名认证后，在开发者联盟网站中选择"开发 > 开发工具 > HUAWEI DevEco Studio"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/C73wERlRTS6FVhyxkwqsbg/zh-cn_image_0000001055285844.png?HW-CC-KV=V1&HW-CC-Date=20260909T155551Z&HW-CC-Expire=31536000000&HW-CC-Sign=6D20C101951D51801FA9073D77FF8784CC43991D712D23C0DF5A5BB81DBEF4FF "点击放大")

4. 点击"DevEco Studio 1.0"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/BU9DpwnOQUijWOk3QWRC9g/zh-cn_image_0000001055445913.png?HW-CC-KV=V1&HW-CC-Date=20260909T155551Z&HW-CC-Expire=31536000000&HW-CC-Sign=B72016BBCC63C1424C5C5A139EB12814C24F7E14491BE9D1DEE13CBA4FD4539B "点击放大")

5. 点击"我要报名"，并填写报名信息后，提交给华为进行审核。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/m48kM64FQXiek1axHsFOqw/zh-cn_image_0000001055096299.png?HW-CC-KV=V1&HW-CC-Date=20260909T155551Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8E5B3FC8AC93DA7916903A90CA552CCDE9C0D5DC1CD487FFF50C38A1C468E50 "点击放大")

## 获取技术支持

您在使用HUAWEI DevEco Studio时，如果您有任何的问题或建议，都可以通过如下两种方式与我们取得联系。

* 在线工单：登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)，在菜单栏选择"支持 > 技术支持 > 在线提单"，进入在线提单页面提交工单。
* 邮件反馈：发送邮件至devConnect@huawei.com，反馈问题。

## 安装和配置HUAWEI DevEco Studio

获取Beta权限后，您就可以下载HUAWEI DevEco Studio软件进行开发了。

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
2. 点击右上角"管理中心"，然后在"应用服务 > 开发服务"中，勾选HUAWEI DevEco Studio卡片，然后点击"关闭"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/GVy80v41QFKgE-k7CXwO9A/zh-cn_image_0000001055296319.png?HW-CC-KV=V1&HW-CC-Date=20260909T155551Z&HW-CC-Expire=31536000000&HW-CC-Sign=80D07C91C2E8FB49D492F04A4FC950DAF09A4AD5E882CDD04DC840534A1A8461 "点击放大")

3. 在开发服务中，点击"HUAWEI DevEco Studio"卡片，阅读和签署Beta保密协议。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/NH3mHpfWS0aKWvcvUJ4qSg/zh-cn_image_0000001054936327.png?HW-CC-KV=V1&HW-CC-Date=20260909T155551Z&HW-CC-Expire=31536000000&HW-CC-Sign=9DF72F834E0E9788FFA35814F8523201E77A655F6B10147C9B0D46ACF8615B26 "点击放大")

4. 下载HUAWEI DevEco Studio软件包。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/8ko4hVArTeWbYRPMkEBByQ/zh-cn_image_0000001054736297.png?HW-CC-KV=V1&HW-CC-Date=20260909T155551Z&HW-CC-Expire=31536000000&HW-CC-Sign=6EE2E48A97B80DD88DC46D6709DD1FA1B4BAD6F881E1F922AA0F158A7868A70D "点击放大")

   软件包下载完成后，请根据DevEco Studio使用指南中的[下载与安装软件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/software_install-0000001053582415-V3)和[配置开发环境](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/environment_config-0000001052902427-V3)完成环境的安装和配置。
