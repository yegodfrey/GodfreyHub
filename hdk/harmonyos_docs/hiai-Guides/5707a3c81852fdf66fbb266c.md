# 集成模型

模型的加载、编译和推理主要是通过调用DDK中的接口实现，应用层主要作为数据传递和展示使用。

模型推理之前需要对输入数据进行预处理以匹配模型的输入，同样对于模型的输出也需要做处理获取自己期望的结果。另外DDK中提供了设置模型编译和运行时的配置参数接口，开发者可根据实际需求选择使用接口。

本节阐述同步模式下单模型的使用，从流程上分别阐述每个步骤在应用层和Native层的实现和调用。

## 预置模型

为了让HAP运行时能够读取到模型文件和处理推理结果，需要先把离线模型和模型对应的结果标签文件预置到工程的"entry/src/main/resources/rawfile"目录中。

本示例所使用的离线模型的转换和生成请参考[Caffe模型转换](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-conversion-example-0000001053125647#section329315242618)。

## 加载离线模型

在HAP应用创建时加载模型和读取结果标签文件。

1. 调用NAPI层的LoadModel函数，读取模型的buffer。
2. 把模型buffer传递给HIAIModelManager类的HIAIModelManager::LoadModel接口，该接口调用DDK中的接口和类，首先创建AiModelMngerClient对象，并调用[Init](https://developer.huawei.com/consumer/cn/doc/hiai-References/init-0000001052570723)接口。
3. 创建AiModelDescription对象，并调用接口[SetModelBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/setmodelbuffer-0000001052689455)设置模型的buffer。
4. AiModelMngerClient对象调用[Load](https://developer.huawei.com/consumer/cn/doc/hiai-References/load-0000001051490688)接口，加载模型，加载过程中会对模型进行编译。

   ```screen
   Status HIAIModelManager::LoadModel(void *modelData, size_t modelSize)
   {
       client_ = make_shared<AiModelMngerClient>();
       client_->Init(nullptr);
       shared_ptr<AiModelDescription> modelDesc =
           make_shared<AiModelDescription>(modelName_, AiModelDescription_Frequency_HIGH, HIAI_FRAMEWORK_NONE,
                                           HIAI_MODELTYPE_ONLINE, AiModelDescription_DeviceType_NPU);
       if (modelDesc == nullptr) {
           OH_LOG_ERROR(LOG_APP, "modelDesc make_shared error.");
           return FAILURE;
       }
       modelDesc->SetModelBuffer(modelData, modelSize);
       vector<shared_ptr<AiModelDescription>> modelDescs;
       modelDescs.emplace_back(modelDesc);
       AIStatus status = client_->Load(modelDescs);
       return SUCCESS;
   }
   ```

上述流程可参见Demo中"entry/src/main/cpp/Classification.cpp"文件中的LoadModel函数和"entry/src/main/cpp/HiAiModelManager.cpp"中的HIAIModelManager::LoadModel函数。

## 输入输出数据准备

1. 处理模型的输入，例如示例中模型的输入为1*3*227*227格式Float类型的数据，需要把输入的图片转成该格式后传递到NAPI层。
2. 创建模型的输入和输出Tensor，并把应用层传递的数据填充到输入的Tensor中，调用AiModelMngerClient对象的GetModelIOTensorDim方法，获取输入和输出Tensor的Dimension。
3. 根据dimension创建AiTensor对象，并拷贝输入的Tensor数据到创建的Tensor中。

   ```cpp
   Status HIAIModelManager::InitIOTensors(std::vector<std::pair<float *, size_t>> inputData)
   {
       vector<TensorDimension> inputTensorDimensions;
       vector<TensorDimension> outputTensorDimensions;
       int status = client_->GetModelIOTensorDim(modelName_, inputTensorDimensions, outputTensorDimensions);
       if (status != AI_SUCCESS) {
           OH_LOG_ERROR(LOG_APP, "GetModelIOTensorDim failed.");
           return AI_FAILED;
       }
       // init inputTensors
       for (auto const &inputTensorDimension : inputTensorDimensions) {
           shared_ptr<AiTensor> inputTensor = make_shared<AiTensor>();
           if (inputTensor == nullptr) {
               OH_LOG_ERROR(LOG_APP, "inputTensor make failed.");
               return AI_FAILED;
           }
           AIStatus status = AI_SUCCESS;
           status = inputTensor->Init(&inputTensorDimension);
           if (status != AI_SUCCESS) {
               OH_LOG_ERROR(LOG_APP, "inputTensor init failed.");
               return AI_FAILED;
           }
           inputTensors_.push_back(inputTensor);
       }
       memmove(inputTensors_[0]->GetBuffer(), inputData[0].first, inputData[0].second * sizeof(float));
       // init outputTensors
       for (auto const &outputTensorDimension : outputTensorDimensions) {
           shared_ptr<AiTensor> outputTensor = make_shared<AiTensor>();
           if (outputTensor == nullptr) {
               OH_LOG_ERROR(LOG_APP, "outputTensor create failed.");
               return AI_FAILED;
           }
           AIStatus status = outputTensor->Init(&outputTensorDimension);
           if (status != AI_SUCCESS) {
               OH_LOG_ERROR(LOG_APP, "outputTensor init failed.");
               return AI_FAILED;
           }
           outputTensors_.push_back(outputTensor);
       }
       return AI_SUCCESS;
   }
   ```

上述流程可参见Demo中"entry/src/main/cpp/Classification.cpp"文件中的InitIOTensors函数和"entry/src/main/cpp/HiAiModelManager.cpp"中的HIAIModelManager::InitIOTensors函数。

## 同步推理离线模型

> 说明
>
> 如果不更换模型，则首次编译加载完成后可多次推理，即一次编译加载，多次推理。

调用DDK中AiModelMngerClient对象的Process接口，传入输入和输出的tensor，完成模型的同步推理。

可参见Demo中"entry/src/main/cpp/Classification.cpp"文件中的RunModel函数和"entry/src/main/cpp/HiAiModelManager.cpp"中的HIAIModelManager::RunModel函数。

## 模型输出后处理

1. 调用输出AiTensor的[GetBuffer](https://developer.huawei.com/consumer/cn/doc/hiai-References/getbuffer-0000001051809428)函数得到模型的输出数据。
2. 对输出数据进行相应的处理可得到期望的结果。

   例如本示例demo中模型的输出是1000个label的概率，期望得到这1000个结果中概率最大的三个标签。

3. 调用AiModelMngerClient对象的[UnLoadModel](https://developer.huawei.com/consumer/cn/doc/hiai-References/unloadmodel-0000001052809443)接口，卸载模型。

上述流程可参见Demo中"entry/src/main/cpp/Classification.cpp"文件中的GetResult、UnloadModel函数和"entry/src/main/cpp/HiAiModelManager.cpp"中的HIAIModelManager::GetResult、HIAIModelManager::UnloadModel函数。

> 说明
>
> 用户可根据需要自行设置模型推理优先级。使用AiModelMngerClient对象的[SetModelPriority](https://developer.huawei.com/consumer/cn/doc/hiai-References/setmodelpriority-0000001058722086)接口，默认值为PRIORITY_LOW，本接口应在模型推理前调用。
