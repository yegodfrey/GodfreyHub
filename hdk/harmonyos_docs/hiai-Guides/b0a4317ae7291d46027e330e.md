# AIPP集成方式

|使用场景|AIPP构造方式|使用方式(动/静态AIPP)|支持模型管家接口版本|需集成的so|
|:-------|:--------|:----------------------------------------|:---------|:------------------------------------------------------|
|OMG离线场景|配置文件格式|动态模型（没有使能xx_func）|v1|libhiai.so|
|OMG离线场景|配置文件格式|动态模型（使能了xx_func的switch开关，且dynamic = true）|v1|libhiai.so|
|OMG离线场景|配置文件格式|静态模型|v1|libhiai.so|
|IR在线编译场景|AIPP IR算子|静态模型（使用Const作为输入）|v1|libhiai.so libhiai_ir_build.so libhiai_ir_build_aipp.so|
