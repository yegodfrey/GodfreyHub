# 拍照购物

#### 服务介绍

用户通过拍摄商品图片，在预先建立的商品图片库中在线检索同款或相似商品，返回相似商品ID和相关信息。同时，为了更好地进行商品实时管理，该服务支持商品离线导入、商品在线增删改查和商品分发。当前支持10大类商品的搜索，包括：服装（上装、裙装、下装、内衣）、箱包、鞋子、数码家电、家居、玩具、美妆、配饰、食品、其它。

#### 应用场景

拍照购物服务主要应用于线上购物场景。例如，购物类App集成该服务可以提供图片搜索商品功能，用户拍摄商品图像时，可以利用该功能快速找到想要的商品。  

#### 注意事项

* 拍照购物服务在端侧调用云侧API进行商品检测、识别和检索，调测和使用时需保证设备可正常访问互联网。
* ML Kit拍照购物以深度学习技术为核心，通过图像识别和搜索功能，实现定制化商品搜索服务，开发者需先建立商品图片库以便进行商品检索。如需完整体验拍照购物服务（包括商品在线增删改查接口的获取），请[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。  

#### 开发步骤

您使用拍照购服务须提供自己的商品数据集，在进行开发之前，您需要完成必要的准备工作，准备工作主要有两个方面：

* 离线商品数据导入和SDK准备。离线商品数据导入请参见[拍照物购离线导入商品](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-product-visual-search-2-0000001061683905)。
* SDK准备请参见[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/product-sdk-0000001050040045)。同时，请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。  

#### 拍照购物

1. 创建拍照购物分析器。可以通过拍照购自定义参数类[MLRemoteProductVisionSearchAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlremoteproductvisionsearchanalyzers-0000001050169509)创建分析器。  

   ```
   "Java"
   // 使用自定义的参数配置。
   MLRemoteProductVisionSearchAnalyzerSetting settings = new MLRemoteProductVisionSearchAnalyzerSetting.Factory()
       // 设置最多返回的商品信息数。
       .setLargestNumOfReturns(16)
       // 设置商品集ID（请在线提单获取配置指导）。
       .setProductSetId(productSetId)
       // 设置站点区域，目前支持站点区域有：REGION_DR_CHINA，REGION_DR_GERMAN，REGION_DR_SINGAPORE，REGION_DR_RUSSIA（站点区域需要和配置AppGallery Connect时选择的服务接入站点保持一致）。
       .setRegion(MLRemoteProductVisionSearchAnalyzerSetting.REGION_DR_CHINA)
       .create();
   MLRemoteProductVisionSearchAnalyzer analyzer
       = MLAnalyzerFactory.getInstance().getRemoteProductVisionSearchAnalyzer(settings);
   ```

   ```
   "Kotlin"
    // 使用自定义的参数配置。
   var settings = MLRemoteProductVisionSearchAnalyzerSetting.Factory() // 设置最多返回的商品信息数。
            .setLargestNumOfReturns(16) // 设置商品集ID（请联系mlkit@huawei.com获取配置指导）。
            .setProductSetId(productSetId) // 设置站点区域，目前支持站点区域有：REGION_DR_CHINA，REGION_DR_GERMAN，REGION_DR_SINGAPORE，REGION_DR_RUSSIA（站点区域需要和配置AppGallery Connect时选择的服务接入站点保持一致）。
            .setRegion(MLRemoteProductVisionSearchAnalyzerSetting.REGION_DR_CHINA)
            .create()
   var analyzer = MLAnalyzerFactory.getInstance().getRemoteProductVisionSearchAnalyzer(settings)
   ```

2. 通过android.graphics.Bitmap构造[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，支持的图片格式包括：jpg/jpeg/png/bmp。  

   ```
   "Java"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   MLFrame mlFrame = new MLFrame.Creator().setBitmap(bitmap).create();
   ```

   ```
   "Kotlin"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   var mlFrame = MLFrame.Creator().setBitmap(bitmap).create()
   ```

3. 进行图片检测（错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlexception-0000001050169383)）。  

   ```
   "Java"
   Task<List<MLProductVisionSearch>> task = analyzer.asyncAnalyseFrame(mlFrame);
   task.addOnSuccessListener(new OnSuccessListener<List<MLProductVisionSearch>>() {
       public void onSuccess(List<MLProductVisionSearch> products) {
           // 识别成功的处理逻辑。
       }})
       .addOnFailureListener(new OnFailureListener() {
       public void onFailure(Exception e) {
           // 识别失败的处理逻辑。
           // Recognition failure.
           try {
               MLException mlException = (MLException)e;
               // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
               int errorCode = mlException.getErrCode();
               // 获取报错信息，开发者可以结合错误码，快速定位问题。
               String errorMessage = mlException.getMessage();
           } catch (Exception error) {
              // 转换错误处理。
           }
      }
   });
   ```

   ```
   "Kotlin"
   val task = analyzer!!.asyncAnalyseFrame(mlFrame)
   task.addOnSuccessListener {
        // 识别成功的处理逻辑。
   }
            .addOnFailureListener { e ->
                // 识别失败的处理逻辑。
                // Recognition failure.
                try {
                    val mlException = e as MLException
                    // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
                    val errorCode = mlException.errCode
                    // 获取报错信息，开发者可以结合错误码，快速定位问题。
                    val errorMessage = mlException.message
                } catch (error: Exception) {
                    // 转换错误处理。
                }
            }
   ```

4. 识别完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {
       analyzer.stop();
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        analyzer!!.stop()
    }
   ```

#### 使用插件方式集成拍照购物

1. 创建拍照购物插件配置参数。  

   ```
   "Java"
   // 配置参数。
   MLProductVisionSearchCaptureConfig config = new MLProductVisionSearchCaptureConfig.Factory()
      //设置最大检测结果数量，默认20，范围为1-100。
      .setLargestNumOfReturns(16)
      // 设置自定义商品展示的fragment(继承自AbstractProductFragment)。
      .setProductFragment(new ProductFragment())
      // 设置站点区域，目前支持站点区域有：REGION_DR_CHINA，REGION_DR_GERMAN，REGION_DR_SINGAPORE，REGION_DR_RUSSIA（站点区域需要和配置AppGallery Connect时选择的服务接入站点保持一致）。
      .setRegion(MLProductVisionSearchCaptureConfig.REGION_DR_CHINA)
      // 设置商品集，可以通过云侧AGC门户生成与获取。
      //.setProductSetId("xxxxx")
      .create();
   ```

   ```
   "Kotlin"
   // 配置参数。
   val config = MLProductVisionSearchCaptureConfig.Factory() //设置最大检测结果数量，默认20，范围为1-100。
            .setLargestNumOfReturns(16) // 设置自定义商品展示的fragment(继承自AbstractProductFragment)。
            .setProductFragment<RealProductBean>(ProductFragment()) // 设置站点区域，目前支持站点区域有：REGION_DR_CHINA，REGION_DR_GERMAN，REGION_DR_SINGAPORE，REGION_DR_RUSSIA（站点区域需要和配置AppGallery Connect时选择的服务接入站点保持一致）。
            .setRegion(MLProductVisionSearchCaptureConfig.REGION_DR_CHINA) // 设置商品集，可以通过云侧AGC门户生成与获取。
            //.setProductSetId("xxxxx")
            .create()
   ```
