# HUAWEI ML Kit助力Fave打通O2O线上和线下的支付场景

#### Fave简介

Fave是您的私人助手，可通过FavePay找到旅途中的美食和最优惠的价格，在新加坡、马来西亚和印度尼西亚的上千家Fave-ourite餐厅和商店中都可使用Fave获取您所需的服务。  

#### 业务挑战

Fave是目前东南亚地区成长较快的O2O公司。伴随业务高速发展，支付作为服务闭环的关键环节，需要不断优化和提升用户体验。

* 缺少扫描文本支付的功能：扫描文本支付可实现无需用户手工输入支付代码，是O2O移动支付场景中最常用的支付方式之一，但Fave不支持扫描文本支付功能。
* 其他第3方文本识别服务识别率不高：其他第3方文本识别服务不支持文本倾斜或内容弯曲识别，也不支持识别多语种文本，文本识别成功率不高。
* 缺少同时支持华为和非华为机型的统一方案：Fave缺少能够覆盖华为手机和非华为手机扫描文本支付的统一方案，要么根据不同手机厂家需要集成多次，要么根据算法更新需要重新发布版本，无动态升级机制。

#### 解决方案

凭借HUAWEI ML Kit高性能的文本识别服务，Fave打造出全新的扫描文本支付功能，为用户和商户提供更加灵活、便捷的支付服务，有效打通O2O线上和线下支付场景。

* 新增文本识别功能，支持业务场景扩展：扫描Fave提供的"文本折扣代码"，便可快速获得线上折扣和完成支付，无缝体验让商户和用户连接更顺畅。
* 支持倾斜、弯曲文本和多语种扫描识别：ML Kit支持文本倾斜至30度或弯曲至45度，仍能保证准确识别，且端侧支持识别中文、日文、韩文、拉丁字符等多种语言，有效支持Fave业务开展。
* 一次开发，支持非华为手机，覆盖所有机型：ML Kit支持华为及非华为手机，开发者只需要一次集成，即可覆盖市面上所有安卓系统机型。

#### 合作受益

* Fave： Fave通过HUAWEI ML Kit文本识别服务实现了扫描文本支付的全新功能，拓宽了O2O线上和线下的用户支付场景，且扫描识别准确率与识别速度非常高，为用户和商户带来高效便捷的服务，大大提升应用体验。

* Fave用户\&商户： （1）用户不需要手动输入"文本折扣代码"便可便捷获得折扣和完成支付，而且扫描准确无需反复扫描，体验显著提升。

（2）商户支持更多变现的方式和场景。  

#### 了解更多

HUAWEI ML Kit除了文本识别外，还支持人脸检测、对象检测与跟踪、图像分类、地标识别等服务，可参见[机器学习服务](https://developer.huawei.com/consumer/cn/hms/huawei-mlkit)获取更多详细介绍和Demo。
