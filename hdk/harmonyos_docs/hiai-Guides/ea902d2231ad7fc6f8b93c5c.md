# FAQ

## HUAWEI HiAI Engine开源吗？

能力以API形式开放，源码目前暂未开源。

## 如何判断当前使用的手机是否是Full类型？

使用命令：

```screen
adb shell getprop  ro.build.hw_emui_lite.enable
```

如果是false则为Full类型，如果为true则为Lite手机。

## 在使用HUAWEI HiAI Engine时需要利用两个独立的模型进行预测，但反复load与unload模型会增加耗时，影响程序的实时性。请问能否同时加载两个模型，只利用修改runModel(ModelInfo modelInfo, float[][] inputData) 接口中的modelInfo来运行不同的模型？

可以在Load中一次加载多个模型，process时通过模型名称指定推理。但是这些操作需要保证是在同一个线程中。如果是不同的线程，需要每个线程使用一个client。

## 没有调用接口的prepare()方法可以直接使用detect()方法吗？

可以的，在detect()方法中会默认启动引擎，如果引擎已经启动则不会再次启动，开发者可以放心使用。

## release()方法是什么时候调用？

release()方法会卸载引擎中已经加载的模型，请在应用不再使用人脸比对时及时卸载模型，释放资源。如：

```screen
FaceComparator faceComparator = new FaceComparator(getApplicationContext());
for(...) {
    JSONObject jsonObject = faceComparator.faceCompare(frame1, frame2, null);
    FaceCompareResult result = faceComparator.convertResult(jsonObject);   
    // do something 
}
faceComparator.release();
```

## CV相关能力接口调用，为何绑定不上HUAWEI HiAI Engine，返回错误码101或601？

请进入"设置 > 系统更新 > 华为智慧能力"，确认华为智慧能力的开关开启。

## 人脸识别会有生物识别吗？

暂时没有，我们是通过计算机视觉技术做的人脸识别。

## 人脸识别接口，其他百度旷世收费很贵不知道HUAWEI HiAI收费怎样？

HUAWEI HiAI Engine开放的人脸识别算法是免费的。

## 五官特征检测的特征点有多少个？

五官特征检测可以检测276个特征点。

## 人脸检测中最多能支持多少张人脸像？

目前人脸检测默认是最大10张人脸，您可以自定义这个最大值。其次，我们建议的图片宽度范围在1080px 到 2560px 之间，如果您的班级照，在人脸无遮挡、人脸像素尺寸大的情况下，是可以检测出来的。

## 当图像超分辨率运行出错的时候，应该如何排查问题？

1. 观察Android错误日志，这是最快、最直接能得到错误原因的方法。
2. 观察结果码，可以知道大致的错误类型。
3. 在绝大多数情况下，运行错误的主要原因是输入不合法，请阅读API接口文档中的约束和限制，并仔细检查输入的参数是否符合规定。
4. 查看应用是否有相应的权限，比如存储权限。

## 使用图像超分辨率接口，需要额外管理资源么？

图像超分辨率API将所有附加的资源管理都封装在接口之内，除了用户已有资源外，不需要额外管理任何资源。

## 图像超分辨率实际上目前不支持质量选择，为什么还要在接口中开放？

1. 图像超分辨率接口的超分质量选择，主要是为了后续扩展使用，质量选择主要是为了给用户提供更佳的方案选择。更高质量的超分意味着更大的计算量，也就意味着更高的耗电量和更高的延迟。
2. 在某些场景下，超分的质量并不是特别敏感，或者因人而异，比如：最高质量的超分和质量稍差的超分之间的画质对比，可能只有专家或者放大到100%仔细观察才能发现区别，但运行时间可能相差很多。

## 图像超分辨率处理后图片色彩较明显改变?

1x超分因为要抑制压缩噪声，可能会导致色彩轻微改变。

3x超分理论上不会导致色彩改变，亮度可能有轻微的变化。

色彩明显改变的情况，在实验室中尚未观察到。

## 图像超分功能的多线程支持不太好？

手机只有一个NPU，只支持一个线程。

## 图像超分功能的输入图片限制纵横比么？

超分功能对输入图片尺寸的具体限制是：较长一边的像素数应大于0且小于等于800，较短一边的像素数应大于0且小于等于600，不限制纵横比。

所谓"较长一边"，就是宽度和高度中，像素数较多的那个边；与之对应的"较短一边"，就是宽度和高度中，像素数较少的那个边。比如640x480的图片，和480x640的图片，较长的一边都是640像素，较短的一边都是480像素。

一个典型的例子是：超分功能可以支持最大800x600的尺寸和600x800的尺寸。

## 使用图像超分的时候,没有创建子线程,能力一样能运行出结果, 但是到示例代码有需要子线程,实际开发是不是必须用子线程?

使用开发者联盟网站上最新的HUAWEI HiAI Engine SDK, 目前不强制使用子线程来处理。

## 文档检测校正功能，随便拍一张纯色图比如拍个墙面，明明没有矩形他也能检测出几个点来，如何优化？

HUAWEI HiAI Engine目前对外提供的文档检测能力是端侧处理，无需网络和上传至服务器，我们会根据输入的图片输出矩形区域，如果检测不出，也会保证有输出结果，不会导致开发者程序crash。针对您提出的优化建议，我们接受，也提交给了内部评估。

用户也可以尝试结合HUAWEI HiAI Engine的其他功能，比如OCR识别、标签识别（目前支持100+种，如文档、文字类型）等，做出优化方案，比如没有识别到文字则不检测矩形框，没有识别到文档则不进行检测等。我们的文档检测能力侧重点在于识别出矩形区域。

## 通用文字识别API是否可用于截屏图片的文字识别？

可以的，通用文字识别API相较于手机截屏OCR有着更广的应用范围，支持通过相机拍摄的图片、网络图片等，也可直接应用于手机截屏的图片数据；但手机截屏OCR对手机截屏的场景做了针对性优化，在手机截屏的场景下，手机截屏OCR API的性能和检测效果均优于通用文字识别API，因此，如果应用的使用场景仅涉及截屏图片，建议选用手机截屏OCR API，即，将引擎类型设置为：TextDetectType.TYPE_TEXT_DETECT_SCREEN_SHOT_GENERAL。

## 通用文字识别API，对自然场景图片的文本识别效果如何？

手机截屏OCR目前支持手机中App的截屏，其特点为文本行无倾斜、背景几乎为纯色。手机截屏OCR针对其特点，做了场景上的适配和性能上的优化。而自然场景图片主要是通过相机拍照获取，图片中的文本受到光照、倾斜、复杂背景等因素影响，使用手机截屏OCR API对自然场景图片进行文本识别的效果非常不理想。因此，针对自然场景图片的OCR需求建议设置引擎类型为：TextDetectType.TYPE_TEXT_DETECT_FOCUS_SHOOT；TextDetectType.TYPE_TEXT_DETECT_FOCUS_SHOOT_EF。

## 通用文字识别API支持哪些字体？

目前，通用文字识别支持手机中常用的字体，如思源黑体、黑体、宋体、楷体等；聚焦拍照OCR支持常见的印刷体。

## 模板OCR需要一定要指定参照区域吗？

是的，一定要指定，而且参照区域的数量大于等于4个。

## 模板OCR中参照区域的选择对算法精度有影响吗？

有的，参照区域选的越好，识别精度也会更高。参照区域中的文字是固定不变的，最好刚好包围一行独立的文字，同一行文字有多个部分时，可以包围某个单独部分文字，同时参照区域最好尽量分散在模板图片的四周。

## 语言识别的writePcm()什么时候调用？

开发者可以将获取到的语音数据通过writePcm()方法写入到引擎中，引擎通过识别解码，将语音转化为相应的文本。同时引擎支持自录音和从文件读取的方式进行识别，初始化引擎时可以通过配置ASR_AUDIO_SRC_TYPE参数来实现。文件读取的方式可以进行批量的文件测试。

## 语音识别的cancel()与stopListening()方法的区别是什么？

当用户已经启动了识别后，即识别的过程中，突然想停止上述两种方法都可以停下来，差别是： cancel()停止但是不上报当前已经识别的结果； stopListening()停止且会把当前的结果刷新上报显示。

## 关于现在的语音人机交互能做到什么级别？

语音人机交互可体验下华为手机的语音助手。

## ASR目前知否支持方言，目前很多老人普通话不标准，使用语音助手识别不准确， 导致体验很差？

当前暂不支持， 后续可能考虑支持一些使用量大的方言。

## 语音识别的前端预处理的角色重要吗？

语音的前处理在语音识别之前，主要作用是对MIC收集到的原始语音进行处理，消除噪声，抑制干扰，减少不同说话人带来的影响等等；前处理对语音识别非常重要，需要两者深度配合。

## 自然语言处理的API支持哪些语言？

1. 分词、词性标注，只支持中文。
2. 助手类场景意图、IM类场景意图，只支持中文语境，意图中出现的属性可以为其他语言。
3. 关键词提取、实体识别，本身语言不限制，能支持名称为外文的实体，但整体语境要在中文下。

## 自然语言处理支持自定义模型吗？

目前还不支持。
