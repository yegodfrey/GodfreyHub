# 图片分类

通过对图片中的实体对象进行分类并添加标注信息，如：人、物、环境、活动、艺术形式等信息，帮助定义图片题材和适用场景等。图片分类支持端侧识别和云侧识别。同时，该服务提供了预置模型能力，支持预置图片分类模型，本章节介绍预置图片分类模型的解决方案。

## 实现方法

完成图片分类预置模型需要以下三步操作：

1. 基于机器学习服务预置的图片分类模型，您可以选择自定义训练集来训练模型，训练方法请参见[AI Create](https://developer.huawei.com/consumer/cn/doc/Tools-Guides/ai-create-0000001055252424)。
2. 获取到模型之后，您可以选择将模型通过[本地集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/integrating-locally-0000001052825781)或[云端托管](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/hosting-on-the-cloud-0000001051824955)的方式集成。
3. 使用模型进行推理。
   1. 请先[加载模型](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/model-inference-0000001052064963#section8996330163419)。
   2. 设置输入输出格式。

      ```java
      "Java"
      MLModelInputOutputSettings inOutSettings = new MLModelInputOutputSettings.Factory()
      // 1张图片（batch 1）,224 (图片高度height)，224（图片宽度 width）, 3通道数（channels）
      .setInputFormat(0, MLModelDataType.FLOAT32, new int[] {1, 224, 224, 3})
      // OUTPUT_SIZE 您模型支持的分类数量
      .setOutputFormat(0, MLModelDataType.FLOAT32, new int[] {1, OUTPUT_SIZE})
      .create();
      ```

      ```javascript
      "Kotlin"
      val inOutSettings = MLModelInputOutputSettings.Factory() // 1张图片（batch 1）,224 (图片高度height)，224（图片宽度 width）, 3通道数（channels）
                       .setInputFormat(0, MLModelDataType.FLOAT32, intArrayOf(1, 224, 224, 3)) // OUTPUT_SIZE 您模型支持的分类数量
                       .setOutputFormat(0, MLModelDataType.FLOAT32, intArrayOf(1, OUTPUT_SIZE))
                       .create()
      ```

   3. 根据图片初始化输入数据。

      ```screen
      "Java"
      Bitmap inputBitmap = Bitmap.createScaledBitmap(inputBitmap, 224, 224, true);
      final float[][][][] input = new float[1][224][224][3];
      for (int i = 0; i < 224; i++) {
          for (int j = 0; j < 224; j++) {
              // batchNum参数由用户传入。
              int pixel = inputBitmap.getPixel(i, j);
              input[batchNum][j][i][0] = (Color.red(pixel) - 128.0f) / 128.0f;
              input[batchNum][j][i][1] = (Color.green(pixel) - 128.0f) / 128.0f;
              input[batchNum][j][i][2] = (Color.blue(pixel) - 128.0f) / 128.0f;
          }
      }
      MLModelInputs inputs = new MLModelInputs.Factory().add(input).create();
      ```


   4. 使用步骤b中加载好的modelExecutor(MLModelExecutor) 进行推理。

      ```java
      "Java"
      // 开始推理。
      modelExecutor.exec(inputs, inOutSettings).addOnSuccessListener(new OnSuccessListener<MLModelOutputs>() {
          @Override
          public void onSuccess(MLModelOutputs mlModelOutputs) {
              float[][] output = mlModelOutputs.getOutput(0);
              float[] probabilities = output[0];
              // 这里推理的返回结果在probabilities数组里，请结合分类列表做进一步处理。
              }
      }).addOnFailureListener(new OnFailureListener() {
          @Override
          public void onFailure(Exception e) {
              // 推理异常。
          }
      });
      ```
