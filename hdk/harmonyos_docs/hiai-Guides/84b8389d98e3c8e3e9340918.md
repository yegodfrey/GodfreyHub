# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[Codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HUAWEIMLKitTTSKit-HarmonyOS)快速体验一个应用的开发过程。  

#### 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上

* 安装[HUAWEI DevEco Studio](https://developer.harmonyos.com/cn/develop/deveco-studio) 2.1及以上

  * [HarmonyOS SDK](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/environment_config-0000001052902427#section67391947173214) API Version 5-7

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：HarmonyOS 2.0及以上的手机。  

#### 开发流程

您需按照流程来完成客户端的开发工作，完整的开发流程如下表格。  

|序号|步骤|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-harmonyos-0000001245919249)|在开发应用前，需要在AppGallery Connect中配置相关信息。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/add-appgallery-harmonyos-0000001252277851#section118612040155210)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[添加权限](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/add-permissions-harmonyos-0000001252174619)|在"main/config.json"文件中配置应用所需权限，详细信息可参见各能力应用开发。|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-recognition-harmonyos-0000001201755666#section16220018134717)|根据您的业务需求，完成对语音语言类或图像类服务的开发工作。|
