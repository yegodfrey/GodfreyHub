# 开发指南

#### 应用开发

#### 必须导入类

1. 在使用码检测API时，将相关码检测的类添加至工程。

   ```
   import com.google.gson.GsonBuilder;
   import com.huawei.TestToolCV.AiEngineMgr; 
   import com.huawei.TestToolCV.Config;
   import com.huawei.TestToolCV.Util; 
   import com.huawei.TestToolCV.util.HopeCVLog; 
   import com.huawei.TestToolCV.util.ImageUtils; 
   import com.huawei.TestToolCV.util.YuvUtils; 
   import com.huawei.hiai.vision.barcode.BarcodeDetector; 
   import com.huawei.hiai.vision.common.VisionCallback; 
   import com.huawei.hiai.vision.common.VisionImage; 
   import com.huawei.hiai.vision.common.VisionImageMetadata; 
   import com.huawei.hiai.vision.visionkit.barcode.Barcode; 
   import com.huawei.hiai.vision.visionkit.barcode.ZxingBarcodeConfiguration; 
   import com.huawei.hiai.vision.visionkit.text.config.VisionTextConfiguration;
   ```

#### 开发

1. 定义mBarcodeDetector实例，将此应用的Context当做入参。

   ```
   BarcodeDetector mBarcodeDetector = new BarcodeDetector(mContext); // 构造Detector
   ```

2. 定义VisionImage，并传入待检测图片bitmap。

   ```
   VisionImage image = VisionImage.fromBitmap(bitmap);
   ```

3. 新建ZxingBarcodeConfiguration，设置必要的VisionTextConfiguration。

   ```
   ZxingBarcodeConfiguration config = new ZxingBarcodeConfiguration.Builder()
       .setProcessMode(VisionTextConfiguration.MODE_IN)
       .build(); 
   mBarcodeDetector.setConfiguration(config);
   ```

4. 实现detect接口，调用算法，获取结果（如果使用回调的话需要实现基本回调函数）。

   ```
   if (!AiEngineMgr.isAsync) {
       resultCode = mBarcodeDetector.detect(image, mBarcodes, null);
       endTime = System.currentTimeMillis();
   } else {
       mBarcodeDetector.detect(image, null, new VisionCallback<List<Barcode>>() {
           @Override
           public void onResult(List<Barcode> barcodes) {
               endTime = System.currentTimeMillis();
               mBarcodes = barcodes;
               resultCode = 0;
               isFinished = true;
           }
           @Override
           public void onError(int i) {
               endTime = System.currentTimeMillis();
               resultCode = i;
               isFinished = true;
           }
           @Override
           public void onProcessing(float v) {
           }
       });
   }
   ```
