# 合作案例：快手

**CANN芯片开放能力，助推快手打造畅玩新体验**

## 快手简介

快手是一款热门短视频社区手机应用，鼓励用户用视频记录、分享自己的生活点滴，为用户提供个性化视频录制、编辑功能，每天产出数百万用户原创视频。

## 核心痛点

快手短视频有一款名为魔法表情的舞蹈游戏，进入游戏，就会有卡通小人做出时下流行的舞蹈动作，指引用户跟随音乐模仿，如果用户模仿动作标准到位、节奏合拍，就会获得奖励，以此让所有普通用户都能快速录制出有趣的舞蹈视频，深受用户喜爱。但动作识别不精准、动作卡顿、机身发热及耗电严重三个问题，常常让用户抱怨玩得不够尽兴。

* **动作识别不精准：**用户肢体动作的识别需要复杂的计算机视觉AI能力，尤其在运动场景下，用户快速做出各类动作时，姿势识别难度加大，常导致无法识别或识别错误。

* **动作不流畅：**肢体动作识别过程中，手机需要完成复杂的深度学习算法模型运算，对手机CPU运算能力是一大挑战，当CPU性能无法承载时，就会出现识别率不稳定，动作吞帧、卡顿、不连贯的问题。

* **机身发热及耗电严重：**CPU进行大量复杂运算时，当然也会耗费大量手机电量，产生大量热量，令机身发热发烫。

## 解决方案

* **端侧运算，动作识别更精准：**快手通过接入HUAWEI HiAI，应用HUAWEI HiAI强大的端侧AI能力，能够实现在同等运算时间下动作识别更精准。

* **降低功耗，改善机身发热及耗电情况：**通过华为NPU对深度学习算法进行加速，也将显著改善功耗表现，在获得极高性能的同时，有效降低手机耗电量，抑制机身发热发烫。
