# 离线语种检测

## 服务介绍

离线语种检测服务可以在没有网络的情况下检测出文本的语种，支持检测文本中的主要语言。返回对应语种的编码（使用ISO 639-1标准编码）和相应的置信度，或者返回一个置信度最高的语种编码。目前离线语种检测能实现56种语言检测。支持语言的详细信息请参见[语种检测支持的语言列表](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)。例如，用户可以轻松实现翻译语种检测、网页语种检测等。

## 应用场景

离线语种检测服务主要应用于翻译App中。例如，用户在无网络情况下也可轻松检测出电子说明书上的语种，结合后续的翻译动作，便于了解产品介绍等信息。

## 注意事项

离线语种检测服务无需下载模型可直接使用。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/on-device-language-detection-sdk-0000001050040039)。

1. 创建离线语种检测器。可以通过语种检测器自定义参数类[MLLangDetectorFactory](https://developer.huawei.com/consumer/cn/doc/hiai-References/mllangdetectorfactory-0000001050169501)创建检测器。

   ```java
   "Java"
   // 创建本地语种检测器。
   MLLangDetectorFactory factory = MLLangDetectorFactory.getInstance();
   MLLocalLangDetectorSetting setting = new MLLocalLangDetectorSetting.Factory()
       // 设置语种检测的最低置信度阈值。
       .setTrustedThreshold(0.01f)
       .create();
   MLLocalLangDetector mlLocalLangDetector = factory.getLocalLangDetector(setting);
   ```

   ```javascript
   "Kotlin"
   // 创建本地语种检测器。
   val factory = MLLangDetectorFactory.getInstance()
   val setting = MLLocalLangDetectorSetting.Factory() // 设置语种检测的最低置信度阈值。
            .setTrustedThreshold(0.01f)
            .create()
   val mlLocalLangDetector = factory.getLocalLangDetector(setting)
   ```

2. 进行语种检测。
   * 异步方法示例代码：

     ```screen
     "Java"
     // 方式一：返回多个语种检测结果，包括语种编码以及置信度，sourceText表示待检测的String类型文本信息，长度需小于5000个字符。
     Task<List<MLDetectedLang>> probabilityDetectTask = mlLocalLangDetector.probabilityDetect(sourceText);
     probabilityDetectTask.addOnSuccessListener(new OnSuccessListener<List<MLDetectedLang>>() {
         @Override
         public void onSuccess(List<MLDetectedLang> mlDetectedLangs) {
             // 语种检测成功回调。
         }
     }).addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
             // 语种检测失败回调。
         }
     });
     // 方式二：返回置信度最高的语种编码，sourceText表示待检测的String类型文本信息，长度需小于5000个字符。
     Task<String> firstBestDetectTask = mlLocalLangDetector.firstBestDetect(sourceText);
     firstBestDetectTask.addOnSuccessListener(new OnSuccessListener<String>() {
         @Override
         public void onSuccess(String s) {
             // 成功的处理逻辑。
         }
     }).addOnFailureListener(new OnFailureListener() {
         @Override
         public void onFailure(Exception e) {
             // 失败的处理逻辑。
         }
     });
     ```

     ```javascript
     "Kotlin"
     // 方式一：返回多个语种检测结果，包括语种编码以及置信度，sourceText表示待检测的String类型文本信息，长度需小于5000个字符。
     val probabilityDetectTask = mlLocalLangDetector!!.probabilityDetect(sourceText)
     probabilityDetectTask.addOnSuccessListener {
          // 语种检测成功回调。
     }.addOnFailureListener {
          // 语种检测失败回调。
     }
     // 方式二：返回置信度最高的语种编码，sourceText表示待检测的String类型文本信息，长度需小于5000个字符。
     val firstBestDetectTask = mlLocalLangDetector.firstBestDetect(sourceText)
     firstBestDetectTask.addOnSuccessListener {
          // 成功的处理逻辑。
     }.addOnFailureListener {
          // 失败的处理逻辑。
      }
     ```

   * 同步方法示例代码：

     ```java
     "Java"
     // 方式一：返回多个语种检测结果，包括语种编码以及置信度，sourceText表示待检测的文本，长度需小于5000个字符。
     try {
         List<MLDetectedLang> result = mlLocalLangDetector.syncProbabilityDetect(sourceText);
     } catch (MLException e) {
         // 失败的处理逻辑。
     }
     // 方式二：返回置信度最高的语种编码，sourceText表示待检测的文本，长度需小于5000个字符。
     try {
         String language = mlLocalLangDetector.syncFirstBestDetect(sourceText);
     } catch (MLException e) {
         // 失败的处理逻辑。
     }
     ```

     ```javascript
     "Kotlin"
     //方式一：返回多个语种检测结果，包括语种编码以及置信度，sourceText表示待检测的文本，长度需小于5000个字符。
     try {
          val result = mlLocalLangDetector.syncProbabilityDetect(sourceText)
      } catch (e: MLException) {
          // 失败的处理逻辑。
     }
      //方式二：返回置信度最高的语种编码，sourceText表示待检测的文本，长度需小于5000个字符。
     try {
          val language = mlLocalLangDetector.syncFirstBestDetect(sourceText)
      } catch (e: MLException) {
          // 失败的处理逻辑。
     }
     ```

     > 注意
     >
     > 同步语种检测方法需要一定的时间，建议根据设备的性能情况选择是否在UI线程中调用。
3. 检测完成后，释放资源。

   ```screen
   "Java"
   if (mlLocalLangDetector != null) {
       mlLocalLangDetector.stop();
   }
   ```

   ```screen
   "Kotlin"
   if (mlLocalLangDetector != null) {
        mlLocalLangDetector.stop()
    }
   ```
