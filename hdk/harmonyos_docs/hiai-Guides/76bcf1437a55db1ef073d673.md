# 合作案例：新华字典

语音查字，HUAWEI HiAI助力新华字典"慧"听升级  

#### 新华字典简介

新华字典移动端应用软件完整收录《新华字典》纸书内容，提供单字、词语、汉语拼音、部首、笔画数、四角号码线上查询，同时支持屏幕跟写、即时跟读对比，以及生字本等学习功能，组词、笔顺等知识问答互动功能。  

#### 核心痛点

手动输入慢且不方便：许多应用在需用户输入文字时，只提供手动输入方式，需用户逐字逐句，一笔一划或一个字母一个字母，逐一点击输入，操作繁琐、输入速度慢，且还需用户有一定的拼音或其他读写知识基础。更便捷简单的输入方式，成为用户一大需求。

语音输入有调用次数限制：近年来，随着语音识别技术的进步，越来越多的应用尝试在手动输入外，增加语音输入功能以满足用户对便捷高效输入的需求，但语音识别技术多有调用次数限制，这无疑增加了实现语音输入的成本负担，对应用来讲是一大束缚。  

#### 解决方案

语音识别，智能输入解放双手：新华字典通过接入HUAWEI HiAI生态，运用HUAWEI HiAI Engine语音识别能力，智能识别用户语音内容，并将其转换为文本，实现语音查字典功能，用户只需按住语音键，说出要查的字词，就能完成查询，免去手动输入，操作更便捷。

端侧优势，摆脱调用次数限制：基于HUAWEI HiAI强大的端侧处理能力，其语音识别结果响应时间低于200ms，语音识别准确率达95%，同时完全免费无调用次数限制，还不受网络条件影响，离线环境也能正常识别，能够给予应用更完善的语音识别技术支持，更好的帮助应用实现"慧"听功能。  

#### 合作受益

新华字典：

实现迅捷精准语音输入，显著提升软件用户体验。

摆脱调用次数限制，大幅减少语音识别技术获取成本。

用户：

快速、精准的语音输入，无需再手动操作，输入更便捷。
