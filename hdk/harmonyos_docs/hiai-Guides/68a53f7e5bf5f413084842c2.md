# 模型转换

机器学习服务提供了模型转换能力，通过MindSpore或第三方模型训练平台（需要自行转换模型）训练生成您的MindSpore Lite模型。

* 通过云侧转换获取模型。 云侧支持自动转换，如果模型通过云侧进行托管，会自动转换成可以运行在MindSpore Lite框架的模型，详情请参见[云端托管](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/hosting-on-the-cloud-0000001051824955)。

* 通过HMS ToolKit插件转换获取模型。 支持通过HMS ToolKit插件获取模型，支持将其他框架模型转换为MindSpore Lite框架模型，具体支持的框架模型以及转换步骤请参见[Model Integration](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/model-integration-0000001054933838)。
