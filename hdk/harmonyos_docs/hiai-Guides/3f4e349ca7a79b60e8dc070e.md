# 文档识别

## 服务介绍

文档识别服务可以从含有文档的图片中，比如文章、合同等，能识别出带段落格式的文本信息。文档识别计算量比较大，SDK通过调用云侧接口实现文档识别，仅支持异步调用方式。开发者借助SDK，可快速构建各种文档识别类应用。

## 应用场景

该服务可以从文档材料中提取对应的内容，快速实现从纸质文件到电子文件的转化，大幅提升信息的录入效率，降低人力成本。例如，当需要对医疗单据、法律卷宗等文档进行电子化储存时，可以使用该服务将这些图片中的文字信息按原有位置生成结构化文档，从而实现快速录入、存档的需求。

## 注意事项

文档识别计算量比较大，SDK依赖云侧接口实现文档识别，调测和使用时需保证设备可正常访问互联网。

## 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/doc-sdk-0000001050038084)。

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建文档分析器。推荐使用文档识别自定义参数[MLDocumentSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mldocumentsetting-0000001050169429)设置需要识别的语种列表，创建分析器，以获取更加精确的文本识别结果。

   ```java
   "Java"
   // 方式一：使用自定义参数配置。
   // 创建语言集合。
   List<String> languageList = new ArrayList();
   languageList.add("zh");
   languageList.add("en");
   // 设置参数。
   MLDocumentSetting setting = new MLDocumentSetting.Factory()
       // 设置识别语言列表，使用ISO 639-1标准。
       .setLanguageList(languageList)
       // 设置文本边界框返回格式。
       // MLRemoteTextSetting.NGON：返回四边形的四个顶点坐标。
       // MLRemoteTextSetting.ARC：返回文本排列为弧形的多边形边界的顶点，最多可返回多达72个顶点的坐标。
       .setBorderType(MLRemoteTextSetting.ARC)
       .create();
   MLDocumentAnalyzer analyzer = 
            MLAnalyzerFactory.getInstance().getRemoteDocumentAnalyzer(setting);
   // 方式二：使用默认参数配置，自动检测语种进行识别，文本框返回格式为：MLRemoteTextSetting.NGON。
   MLDocumentAnalyzer analyzer = 
            MLAnalyzerFactory.getInstance().getRemoteDocumentAnalyzer();
   ```

   ```javascript
   "Kotlin"
   // 方式一：使用自定义参数配置。
    // 创建语言集合。
   val languageList: MutableList<String?> = ArrayList< String?>()
   languageList.add("zh")
   languageList.add("en")
   // 设置参数。
   val setting = MLDocumentSetting.Factory() // 设置识别语言列表，使用ISO 639-1标准。
            .setLanguageList(languageList) // 设置文本边界框返回格式。
            // MLRemoteTextSetting.NGON：返回四边形的四个顶点坐标。
            // MLRemoteTextSetting.ARC：返回文本排列为弧形的多边形边界的顶点，最多可返回多达72个顶点的坐标。
            .setBorderType(MLRemoteTextSetting.ARC)
            .create()
   val analyzer = MLAnalyzerFactory.getInstance().getRemoteDocumentAnalyzer(setting)
   // 方式二：使用默认参数配置，自动检测语种进行识别，文本框返回格式为：MLRemoteTextSetting.NGON。
   val analyzer = MLAnalyzerFactory.getInstance().remoteDocumentAnalyzer
   ```

3. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，支持的图片格式包括：jpg/jpeg/png/bmp。

   ```java
   "Java"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   MLFrame frame = MLFrame.fromBitmap(bitmap);
   ```

   ```javascript
   "Kotlin"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   val frame = MLFrame.fromBitmap(bitmap)
   ```

4. 将创建的[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象传递给[asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mldocumentanalyzer-0000001050167474#section79701908717)方法进行文档识别（错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlexception-0000001050169383)）。

   ```java
   "Java"
   Task<MLDocument> task = analyzer.asyncAnalyseFrame(frame);
   task.addOnSuccessListener(new OnSuccessListener<MLDocument>() {
       @Override
       public voidonSuccess(MLDocument document) {
           // 识别成功。
   }
   }).addOnFailureListener(newOnFailureListener() {
       @Override
       public voidonFailure(Exception e) {
           // 识别失败。
           // Recognition failure.
           try {
               MLException mlException = (MLException)e;
               // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
               int errorCode = mlException.getErrCode();
              // 获取报错信息，开发者可以结合错误码，快速定位问题。
              String errorMessage = mlException.getMessage();
          } catch (Exception error) {
              // 转换错误处理。
          }
   }
   });
   ```

   ```javascript
   "Kotlin"
   val task = analyzer!!.asyncAnalyseFrame(frame)
   task.addOnSuccessListener {
   // 识别成功。
   }.addOnFailureListener {e ->
   // 识别失败。

            val errorMessage = mlException.message
        } catch (error: Exception) {
            // 转换错误处理。
        }
    }
   ```

5. 识别完成，停止分析器，释放识别资源。
