# 业务介绍

HUAWEI HiAI是面向移动终端的AI计算平台，构建三层AI生态：芯片能力开放、应用能力开放和服务能力开放，芯、端、云结合的三层开放平台为用户和开发者带来更多的非凡体验。

HUAWEI HiAI Engine应用能力开放，轻松将多种AI能力与应用集成，让应用更加智慧强大。应用能力开放包括：  

#### CV引擎

CV，即计算机视觉，计算机能够模拟人的视觉系统感知周围环境，判断、识别、理解空间组成。能力包括图片识别、人体识别、文本识别等。  

#### ASR引擎

ASR，即自动语音识别，将人的声音转化为文本，便于计算机进一步进行解析理解。能力包括语音识别等。  

#### NLU引擎

NLU，即自然语言理解，与ASR有机结合，让计算机理解人的声音或文本，进行沟通或自然的动作。能力包括分词、文本的实体识别等。
