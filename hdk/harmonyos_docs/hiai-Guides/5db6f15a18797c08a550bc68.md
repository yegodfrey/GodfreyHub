# 开发指南

#### 应用开发

#### 必须导入类

1. 在使用图片分类标签API时，将实现图片分类标签的相关的类添加至工程。

   ```
   import com.huawei.hiai.vision.visionkit.common.Frame; //加载Frame类
   import com.huawei.hiai.vision.visionkit.image.detector.Label; //加载标签检测结果类
   import com.huawei.hiai.vision.visionkit.image.detector.LabelContent//加载标签检测内容类
   import com.huawei.hiai.vision.image.detector.LabelDetector; //加载标签检测detector类
   import com.huawei.hiai.vision.common.VisionBase;//加载连接服务的静态类
   import com.huawei.hiai.vision.common.ConnectionCallback;//加载连接服务的回调函数
   ```

#### 开发

1. 应用VisionBase静态类进行初始化，异步获取服务的连接。

   ```
   VisionBase.init(mContext, new ConnectionCallback(){
       @Override
       public void onServiceConnect(){
           Log.i(LOG_TAG, "onServiceConnect");
       }

       @Override
       public void onServiceDisconnect(){
           Log.i(LOG_TAG, "onServiceDisconnect");
       }
   });
   ```

2. 定义labelDetector实例，将此应用的Context当做入参。

   ```
   LabelDetector labelDetector = new LabelDetector(mContext);
   ```

3. 定义VisionImage, 将需进行标签检测图像的bitmap放入VisionImage中。

   ```
   VisionImage image = (bitmap == null) ? null : VisionImage.fromBitmap(bitmap);
   ```

4. 定义图片标签结果类Label。

   ```
   Label label = new Label();
   ```

5. 调用detect方法得到标签检测结果。

   ```
   int resultCode = labelDetector.detect(image, label, null);
   ```
