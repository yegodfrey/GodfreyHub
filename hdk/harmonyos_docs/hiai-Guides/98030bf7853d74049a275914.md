# 图片分类

#### 服务介绍

通过对图片中的实体对象进行分类并添加标注信息，如：人、物、环境、活动、艺术形式等信息，帮助定义图片题材和适用场景等。图片分类支持端侧识别和云侧识别。端侧识别即在设备上运行检测算法模型，返回识别结果，目前支持超过400个类别，涵盖图片最常见的概念；云侧识别即调用云侧API进行检测，检测算法模型在云侧运行，目前支持12,000个分类。详细的分类信息列表参见[图片分类类别清单](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)。同时，该服务提供了自定义模型能力，支持用户自定义图片分类模型。

#### 应用场景

图片分类服务可以广泛应用于图片分类管理场景。例如，图片管理类App，集成该服务可以快速筛选出包含某种实体的图片集。  

#### 注意事项

云侧识别与端侧识别相比，准确率较高，但是效率更低，且不支持视频流识别，仅支持静态图片识别。  

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/classification-sdk-0000001050040041)。  

#### 端侧静态图片检测

1. 创建图片分类分析器。可以通过图像分类自定义类[MLLocalClassificationAnalyzerSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/localclassificationanalyzersetting-0000001050167516)创建分析器。  

   ```
   "Java"
   // 方式一：端侧识别使用自定义参数配置。
   MLLocalClassificationAnalyzerSetting setting = 
       new MLLocalClassificationAnalyzerSetting.Factory()
           .setMinAcceptablePossibility(0.8f)
           .create(); 
   MLImageClassificationAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalImageClassificationAnalyzer(setting);
   // 方式二：端侧识别使用默认参数配置。
   MLImageClassificationAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalImageClassificationAnalyzer();
   ```

   ```
   "Kotlin"
   // 方式一：端侧识别使用自定义参数配置。
   var setting = MLLocalClassificationAnalyzerSetting.Factory()
            .setMinAcceptablePossibility(0.8f)
            .create()
    var analyzer = MLAnalyzerFactory.getInstance().getLocalImageClassificationAnalyzer(setting)

    // 方式二：端侧识别使用默认参数配置。
    var analyzer = MLAnalyzerFactory.getInstance().localImageClassificationAnalyzer
   ```

2. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，支持的图片格式包括：jpg/jpeg/png/bmp，建议图片尺寸不小于112\*112像素。  

   ```
   "Java"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   MLFrame frame = MLFrame.fromBitmap(bitmap);
   ```

   ```
   "Kotlin"
   // 通过bitmap创建MLFrame，bitmap为输入的Bitmap格式图片数据。
   var frame = MLFrame.fromBitmap(bitmap)
   ```

3. 调用[asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/imageclassificationanalyzer-0000001050167514#section1973015554518)方法进行图像分类（错误码信息可参见：[机器学习服务错误码](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlexception-0000001050169383)）。  

   ```
   "Java"
   Task<List<MLImageClassification>> task = analyzer.asyncAnalyseFrame(frame); 
   task.addOnSuccessListener(new OnSuccessListener<List<MLImageClassification>>() {
       @Override
       public void onSuccess(List<MLImageClassification> classifications) {
           // 识别成功。
           // 遍历返回的列表MLImageClassification，获取分类名称等信息。
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // 识别失败。
           // Recognition failure.
           try {
               MLException mlException = (MLException)e;
               // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
               int errorCode = mlException.getErrCode();
               // 获取报错信息，开发者可以结合错误码，快速定位问题。
               String errorMessage = mlException.getMessage();
           } catch (Exception error) {
               // 转换错误处理。
           }
       }
   });
   ```

   ```
   "Kotlin"
   val task = analyzer!!.asyncAnalyseFrame(frame)
   task.addOnSuccessListener {
        // 识别成功。
   }.addOnFailureListener { e ->
        // 识别失败。
        // Recognition failure.
        try {
            val mlException = e as MLException
            // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
            val errorCode = mlException.errCode
            // 获取报错信息，开发者可以结合错误码，快速定位问题。
            val errorMessage = mlException.message
        } catch (error: Exception) {
            // 转换错误处理。
        }
    }
   ```

4. 识别完成，停止分析器，释放检测资源。  

   ```
   "Java"
   try {
       if (analyzer != null) {
          analyzer.stop();
       }
   } catch (IOException e) {
       // 异常处理。
   }
   ```

   ```
   "Kotlin"
   try {
        if (analyzer != null) {
            analyzer!!.stop()
        }
    } catch (e: IOException) {
        // 异常处理。
    }
   ```

以上示例代码中使用了异步调用方式，图片分类还支持同步调用使用[analyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/imageclassificationanalyzer-0000001050167514#section22163825118)函数获取检测结果：  

```
"Java"
SparseArray<MLImageClassification> classifications = analyzer.analyseFrame(frame);
```

```
"Kotlin"
val classifications = analyzer!!.analyseFrame(frame)
```

#### 视频流检测

开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按上文中静态图像检测的方法进行对象检测。如果开发者调用的是同步检测接口，也可以使用SDK内置的[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)类实现视频流对象检测，示例代码如下：

1. 创建图片分类分析器，只支持创建端侧图片分类分析器。  

   ```
   "Java"
   MLImageClassificationAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalImageClassificationAnalyzer();
   ```

   ```
   "Kotlin"
   var analyzer = MLAnalyzerFactory.getInstance().localImageClassificationAnalyzer
   ```

2. 开发者创建识别结果处理类"ClassificationAnalyzerTransactor"，该类实现[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>接口，使用该接口中的[transactResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216#section7411382071)方法获取检测结果并实现具体业务。  

   ```
   "Java"
   public class ClassificationAnalyzerTransactor implements MLAnalyzer.MLTransactor<MLImageClassification> {
       @Override
       public void transactResult(MLAnalyzer.Result<MLImageClassification> results) {
           SparseArray<MLImageClassification> items = results.getAnalyseList();
           // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
           // 不可调用ML Kit提供的其他检测相关接口。
       }
       @Override
       public void destroy() {
           // 检测结束回调方法，用于释放资源等。
       }
   }
   ```

   ```
   "Kotlin"
   class ClassificationAnalyzerTransactor : MLTransactor<MLImageClassification?> {
        override fun transactResult(results: MLAnalyzer.Result<MLImageClassification?>) {
            val items = results.analyseList
            // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
            // 不可调用ML Kit提供的其他检测相关接口。
        }

        override fun destroy() {
            // 检测结束回调方法，用于释放资源等。
        }
    }
   ```

3. 设置识别结果处理器，实现分析器与结果处理器的绑定。  

   ```
   "Java"
   analyzer.setTransactor(new ClassificationAnalyzerTransactor());
   ```

   ```
   "Kotlin"
   analyzer!!.setTransactor(ClassificationAnalyzerTransactor())
   ```

4. 创建[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)，该类由ML Kit SDK提供，用于捕捉相机动态视频流并传入分析器。  

   ```
   "Java"
   Context context = this.getApplicationContext();
   LensEngine lensEngine = new LensEngine.Creator(context, this.analyzer)
       .setLensType(LensEngine.BACK_LENS)
       .applyDisplayDimension(1440, 1080)
       .applyFps(30.0f)
       .enableAutomaticFocus(true)
       .create();
   ```

   ```
   "Kotlin"
   analyzer!!.setTransactor(ClassificationAnalyzerTransactor())
   val context = applicationContext
   val lensEngine = LensEngine.Creator(context, analyzer)
            .setLensType(LensEngine.BACK_LENS)
            .applyDisplayDimension(1440, 1080)
            .applyFps(30.0f)
            .enableAutomaticFocus(true)
            .create()
   ```

5. 调用run方法，启动相机，读取视频流，进行识别。  

   ```
   "Java"
   // 请自行实现SurfaceView控件的其他逻辑。
   SurfaceView mSurfaceView = findViewById(R.id.surface_view);
   try {
       lensEngine.run(mSurfaceView.getHolder());
   } catch (IOException e) {
       // 异常处理逻辑。
   }
   ```

   ```
   "Kotlin"
   // 请自行实现SurfaceView控件的其他逻辑。
   val mSurfaceView: SurfaceView? = findViewById(R.id.surface_view)
   try {
        lensEngine!!.run(mSurfaceView!!.holder)
    } catch (e: IOException) {
        // 异常处理逻辑。
    }
   ```

6. 检测完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {
       try {
           analyzer.stop();
       } catch (IOException e) {
           // 异常处理。
       }
   }
   if (lensEngine != null) {
       lensEngine.release();
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        try {
            analyzer!!.stop()
        } catch (e: IOException) {
             // 异常处理。
        }
    }
   lensEngine?.release()
   ```

使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见[视频流检测模式多次识别场景开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-video-0000001050040139)。
