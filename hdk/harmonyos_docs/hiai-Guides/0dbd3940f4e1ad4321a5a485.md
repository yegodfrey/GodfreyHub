# 文本识别

#### 服务介绍

文本识别服务可以识别收据、名片、文档照片等含文字的图片，将其中的文本信息提取出来。该服务被广泛应用于印刷、教育、物流等行业。例如，您可以在税务相关应用中，使用该服务代替人工信息录入与检测等操作。

该服务可以同时支持端侧和云侧，不过其能识别的文字种类有区别。当调用端侧接口时，可识别中文（简体）、日文、韩文、拉丁语（包括英文、西班牙文、葡萄牙文、意大利文、德文、法文、俄文、特殊字符，支持的特殊字符请参见[文本识别客户端支持的拉丁字符](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)）。当调用云侧接口时，可以识别中文（简体）、英文、西班牙文、葡萄牙文、意大利文、德文、法文、俄文、日文、韩文、波兰文、芬兰文、挪威文、瑞典文、丹麦文、土耳其文、泰文、阿拉伯文、印地文等文字。

该服务支持静态图片识别和动态视频流识别，同步和异步两种调用方式，通过提供丰富的API，可帮助开发者快速构建各种文本识别应用。  

#### 应用场景

在职场社交、论坛、商务会见等场景下，相互交换名片是常见的行为，通过该服务可以快速实现对名片中重要信息的结构化识别和录入；在寄快递场景下，通过识别上传的图片，能快速将收件人姓名、电话、收件人地址等重要信息填入对应位置，极大地降低了用户的输入成本，快速、方便，提升产品的易用性。  

#### 注意事项

云侧识别与端侧识别相比，准确率较高，不支持视频流识别，不支持同步调用方式。云侧服务需要完成ML Kit服务开通，请参见[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/enable-service-0000001050038078#section6724322143516)。端侧同步、端侧异步、云侧异步以及端侧视频流文本识别创建分析器方式不同，请参照以下开发步骤中的示例代码创建文本分析器。  

|项目|端侧|云侧|
|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------|
|使用场景|相机或视频画面实时处理，图片中稀疏文本识别|文字识别精度要求高、图片中稀疏文本识别、文档图片密集文本识别|
|支持语言|中文（简体）、日文、韩文、拉丁语（包括英文、西班牙文、葡萄牙文、意大利文、德文、法文、俄文、特殊字符，支持的特殊字符请参见[文本识别客户端支持的拉丁字符](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-resource-0000001050038188)）|中文（简体）、英文、西班牙文、葡萄牙文、意大利文、德文、法文、俄文、日文、韩文、波兰文、芬兰文、挪威文、瑞典文、丹麦文、土耳其文、泰文、阿拉伯文、印地文|
|调用方式|同步、异步|异步|

#### 开发步骤

在进行开发之前，您需要完成必要的[开发准备工作](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-agc-0000001050990353)，同时请确保您的工程中已经[配置HMS Core SDK的Maven仓地址](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/config-maven-0000001050040031)，并且完成了本服务的[SDK集成](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/text-sdk-0000001050040033)。  

#### 端侧文本识别

1. 创建文本分析器[MLTextAnalyzer](https://developer.huawei.com/consumer/cn/doc/hiai-References/mltextanalyzer-0000001050167460)用于识别图片中的文字，您可以通过[MLLocalTextSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mllocaltextsetting-0000001050167452)设置识别的语种，不设置语言默认只能识别拉丁字符。  

   ```
   "Java"
   //方式一：使用默认参数配置端侧文本分析器，只能识别拉丁语系文字。
   MLTextAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalTextAnalyzer();

   //方式二：使用自定义参数MLLocalTextSetting配置端侧文本分析器。
   MLLocalTextSetting setting = new MLLocalTextSetting.Factory()
       .setOCRMode(MLLocalTextSetting.OCR_DETECT_MODE)
       // 设置识别语种。
       .setLanguage("zh")
       .create();
   MLTextAnalyzer analyzer = MLAnalyzerFactory.getInstance().getLocalTextAnalyzer(setting);
   ```

   ```
   "Kotlin"
   //方式一：使用默认参数配置端侧文本分析器，只能识别拉丁语系文字。
    val analyzer = MLAnalyzerFactory.getInstance().localTextAnalyzer

   //方式二：使用自定义参数MLLocalTextSetting配置端侧文本分析器。
   val setting = MLLocalTextSetting.Factory()
            .setOCRMode(MLLocalTextSetting.OCR_DETECT_MODE) // 设置识别语种。
            .setLanguage("zh")
            .create()
    val analyzer = MLAnalyzerFactory.getInstance().getLocalTextAnalyzer(setting)
   ```

   ```
   Task<MLText> task = analyzer.asyncAnalyseFrame(frame);
   task.addOnSuccessListener(new OnSuccessListener<MLText>() {
       @Override

           // 识别成功处理。
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // 识别失败处理。
       }
   });
   ```

   ```
   "Kotlin"
   val task = analyzer.asyncAnalyseFrame(frame)
   task.addOnSuccessListener {
        // 识别成功处理。
   }.addOnFailureListener {
        // 识别失败处理。
   }
   ```

   示例代码中使用了异步调用方式，本地文本识别还支持[analyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mltextanalyzer-0000001050167460#section192144210514)同步调用方式，识别结果以"MLText.Block"数组进行提供：  

   ```
   "Java"
   Context context = getApplicationContext();
   MLTextAnalyzer analyzer = new MLTextAnalyzer.Factory(context).setLocalOCRMode(MLLocalTextSetting.OCR_DETECT_MODE).setLanguage("zh").create();
   SparseArray<MLText.Block> blocks = analyzer.analyseFrame(frame);
   ```

   ```
   "Kotlin"
   val context = applicationContext
   val analyzer = MLTextAnalyzer.Factory(context).setLocalOCRMode(MLLocalTextSetting.OCR_DETECT_MODE).setLanguage("zh").create()
   val blocks = analyzer!!.analyseFrame(frame)
   ```

   ```
       // 异常处理。
   }
   ```

   ```
   "Kotlin"
   try {
        if (analyzer != null) {
            analyzer.stop()
        }
    } catch (e: IOException) {
        // 异常处理。
   ```

#### 云侧文本识别

1. 请参见[云端鉴权信息使用须知](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/sdk-data-security-0000001229909424#section2688102310166)，设置您应用的鉴权信息。
2. 创建分析器。推荐通过创建[MLRemoteTextSetting](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlremotetextsetting-0000001050167454)，设置需要识别的语种列表，创建分析器，以获取更加精确的文本识别结果。  

   ```
   "Java"
   // 方式一：使用自定义参数配置。
   // 创建语言集合。
   List<String> languageList = new ArrayList();
   languageList.add("zh");
   languageList.add("en");
   // 设置参数。
   MLRemoteTextSetting setting = new MLRemoteTextSetting.Factory()
       // 设置云侧文本字体模式：
       // 若选择手写体格式，文本检测模式仅支持稀疏文本，语言列表仅支持中文（zh），边界框格式仅支持NGON四顶点坐标。
       // setTextDensityScene、setLnaguageList、setBorderType等方法设置均不生效。
       // 若选择印刷体格式，则需要手动设置语言列表，检测模式和边框样式，或采取默认配置。
       // MLRemoteTextSetting.OCR_HANDWRITTENFONT_SCENE：手写体。
       // MLRemoteTextSetting.OCR_PRINTFONT_SCENE：印刷体。
       .setTextFontScene(MLRemoteTextSetting.OCR_HANDWRITTENFONT_SCENE)
       // 设置云侧文本检测模式：
       // MLRemoteTextSetting.OCR_COMPACT_SCENE：文本密集场景的文本识别。
       // MLRemoteTextSetting.OCR_LOOSE_SCENE：文本稀疏场景的文本识别。
       .setTextDensityScene(MLRemoteTextSetting.OCR_LOOSE_SCENE)
       // 设置识别语言列表，使用ISO 639-1标准。
       .setLanguageList(languageList)
       // 设置文本边界框返回格式。
       // MLRemoteTextSetting.NGON：返回四边形的四个顶点坐标。
       // MLRemoteTextSetting.ARC：返回文本排列为弧形的多边形边界的顶点，最多可返回多达72个顶点的坐标。
       .setBorderType(MLRemoteTextSetting.ARC)
       .create();
   MLTextAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteTextAnalyzer(setting);
   // 方式二：使用默认参数配置，自动检测语种进行识别，适用于文本稀疏场景，文本框返回格式为：MLRemoteTextSetting.NGON。
   MLTextAnalyzer analyzer = MLAnalyzerFactory.getInstance().getRemoteTextAnalyzer();
   ```

   ```
   "Kotlin"
   // 方式一：使用自定义参数配置。
   // 创建语言集合。
   val languageList: MutableList<String?> = ArrayList< String?>()
   languageList.add("zh")
   languageList.add("en")
   // 设置参数。
   val setting = MLRemoteTextSetting.Factory() // 设置云侧文本检测模式：
            // MLRemoteTextSetting.OCR_COMPACT_SCENE：文本密集场景的文本识别。
            // MLRemoteTextSetting.OCR_LOOSE_SCENE：文本稀疏场景的文本识别。
            .setTextDensityScene(MLRemoteTextSetting.OCR_LOOSE_SCENE) // 设置识别语言列表，使用ISO 639-1标准。
            .setLanguageList(languageList) // 设置文本边界框返回格式。
            // MLRemoteTextSetting.NGON：返回四边形的四个顶点坐标。
            // MLRemoteTextSetting.ARC：返回文本排列为弧形的多边形边界的顶点，最多可返回多达72个顶点的坐标。
            .setBorderType(MLRemoteTextSetting.ARC)
            .create()
   val analyzer = MLAnalyzerFactory.getInstance().getRemoteTextAnalyzer(setting)
   // 方式二：使用默认参数配置，自动检测语种进行识别，适用于文本稀疏场景，文本框返回格式为：MLRemoteTextSetting.NGON。
   val analyzer = MLAnalyzerFactory.getInstance().remoteTextAnalyzer
   ```

3. 通过android.graphics.Bitmap创建[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，支持的图片格式包括：jpg/jpeg/png/bmp。  

   ```
   "Java"
   MLFrame frame = MLFrame.fromBitmap(bitmap);
   ```

   ```
   "Kotlin"

   ```

4. 将创建的[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象传递给分析器的[asyncAnalyseFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mltextanalyzer-0000001050167460#section136588510527)方法进行文字识别（错误码信息可参见：[MLException](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlexception-0000001050169383)）。  

   ```
   "Java"
   Task<MLText> task = analyzer.asyncAnalyseFrame(frame);
   task.addOnSuccessListener(new OnSuccessListener<MLText>() {
       @Override
       public void onSuccess(MLText text) {
           // 识别成功。
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // 识别失败,获取相关异常信息。    
           try {        
               MLException mlException = (MLException) e;
               // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。        
               int errorCode = mlException.getErrCode();
               // 获取报错信息，开发者可以结合错误码，快速定位问题。        
               String errorMessage = mlException.getMessage();    
           } catch (Exception error) {
               // 转换错误处理。  
           }
       }
   });
   ```

   ```
   "Kotlin"
   val task = analyzer!!.asyncAnalyseFrame(frame)
   task.addOnSuccessListener {
        // 识别成功。
   }.addOnFailureListener { e ->
        // 识别失败,获取相关异常信息。
        try {
            val mlException = e as MLException
            // 获取错误码，开发者可以对错误码进行处理，根据错误码进行差异化的页面提示。
            val errorCode = mlException.errCode
            // 获取报错信息，开发者可以结合错误码，快速定位问题。
            val errorMessage = mlException.message
        } catch (error: Exception) {
            // 转换错误处理。
        }
    }
   ```

5. 识别完成，停止分析器，释放检测资源。  

   ```
   "Java"
   if (analyzer != null) {  
       try {
           analyzer.stop();
       } catch (IOException e) {
           // 异常处理。
       }
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        try {
            analyzer.stop()
        } catch (e: IOException) {
            // 异常处理。
        }
    }
   ```

#### 端侧视频流文本识别

开发者可以自行处理视频流，将视频帧转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)对象，再按上文中静态图像本地识别的方法识别文字。如果开发者调用的是同步识别接口，也可以使用SDK内置的[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)类实现视频流本地文本检测，创建并初始化一个[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)对象，具体实现请参见示例代码：

1. 创建分析器。  

   ```
   "Java"
   // 方式一：使用默认参数配置文本分析器，只能识别拉丁语系文字。
   MLTextAnalyzer analyzer = new MLTextAnalyzer.Factory(context).create();

   // 方式二：使用自定义参数MLTextAnalyzer.Factory构造文本分析器，可识别其他支持语。
   MLTextAnalyzer.Factory factory = new MLTextAnalyzer.Factory(context);
   // 设置识别语种。
   factory.setLanguage("zh");
   MLTextAnalyzer analyzer = factory.create();
   ```

   ```
   "Kotlin"
   // 方式一：使用默认参数构造文本分析器，只能识别拉丁语系。
   val analyzer = MLTextAnalyzer.Factory(context).create()

   // 方式二：使用自定义参数MLTextAnalyzer.Factory构造文本分析器，可识别其他支持语。
   val factory = MLTextAnalyzer.Factory(context)
   // 设置识别语种。
   factory.setLanguage("zh")
   val analyzer = factory.create()
   ```

2. 开发者创建识别结果处理类"OcrDetectorProcessor"，该类实现[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>接口，使用此类中的[transactResult](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216#section7411382071)方法获取检测结果并实现具体业务。  

   ```
   "Java"
   public class OcrDetectorProcessor implements MLAnalyzer.MLTransactor<MLText.Block> {
       @Override
       public void transactResult(MLAnalyzer.Result<MLText.Block> results) {
           SparseArray<MLText.Block> items = results.getAnalyseList();
           // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
           // 不可调用ML Kit提供的其他检测相关接口。
       }
       @Override
       public void destroy() {
           // 检测结束回调方法，用于释放资源等。
       }
   }
   ```

   ```
   "Kotlin"
   class OcrDetectorProcessor : MLTransactor<MLText.Block?> {
        override fun transactResult(results: MLAnalyzer.Result<MLText.Block?>) {
            val items = results.analyseList
            // 开发者根据需要处理识别结果，需要注意，这里只对检测结果进行处理。
            // 不可调用ML Kit提供的其他检测相关接口。
        }

        override fun destroy() {
            // 检测结束回调方法，用于释放资源等。
        }
    }
   ```

3. 设置识别结果处理器，实现分析器与结果处理器的绑定。  

   ```
   "Java"
   analyzer.setTransactor(new OcrDetectorProcessor());
   ```

   ```
   "Kotlin"
   analyzer!!.setTransactor(OcrDetectorProcessor())
   ```

4. 调用同步接口使用SDK内置[LensEngine](https://developer.huawei.com/consumer/cn/doc/hiai-References/lensengine-0000001050169367)创建对象，并注册分析器，初始化相机参数。  

   ```
   "Java"
   LensEngine lensEngine = new LensEngine.Creator(getApplicationContext(),analyzer)
       .setLensType(LensEngine.BACK_LENS)
       .applyDisplayDimension(1440, 1080)
       .applyFps(30.0f)
       .enableAutomaticFocus(true)
       .create();
   ```

   ```
   "Kotlin"
   val lensEngine = LensEngine.Creator(applicationContext, analyzer)
            .setLensType(LensEngine.BACK_LENS)
            .applyDisplayDimension(1440, 1080)
            .applyFps(30.0f)
            .enableAutomaticFocus(true)
            .create()
   ```

5. 调用run方法，启动相机，读取视频流，进行识别（请参见示例代码实现SurfaceView控件的其他逻辑）。  

   ```
   "Java"
   SurfaceView mSurfaceView = findViewById(R.id.surface_view);
   try {
       lensEngine.run(mSurfaceView.getHolder());
   } catch (IOException e) {
       // 异常处理逻辑。
   }
   ```

   ```
   "Kotlin"
   val mSurfaceView: SurfaceView? = findViewById(R.id.surface_view);
    try {
        lensEngine!!.run(mSurfaceView!!.holder)
    } catch (e: IOException) {
        // 异常处理逻辑。
    }
   ```

6. 检测完成，停止分析器，释放检测资源  

   ```
   "Java"
   if (analyzer != null) {
       try {
           analyzer.stop();
       } catch (IOException e) {
            // 异常处理。
       }
   }
   if (lensEngine != null) {
       lensEngine.release();
   }
   ```

   ```
   "Kotlin"
   if (analyzer != null) {
        try {
            analyzer.stop()
        } catch (e: IOException) {
            // 异常处理。
        }
    }
   lensEngine?.release()
   ```

使用视频流检测，继承[MLAnalyzer.MLTransactor](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlanalyzer-mltransactor-0000001159656216)\<T\>完成检测处理结果时，如果需要实现检测到特定结果后停止检测，待特定结果处理完后继续检测的功能，可以参见[视频流检测模式多次识别场景开发](https://developer.huawei.com/consumer/cn/doc/hiai-Guides/ml-video-0000001050040139)。
