Contains classes for Onehop SDK.

## Interfaces

|------------------|---------------------|
|Interface name|Interface description|
|IOneHopSdkCallback|应用注册OneHop能力时的回调接口。|

## Classes

|-----------|-----------------------------|
|Class name|Class description|
|HwOneHopSdk|用于注册OneHop能力等的一个功能类，以单例的形式出现。|

|-----------------------------------------------------------------------------------------------|
|interface info|
|public interface IOneHopSdkCallback|
|该接口的Stub类用于通知触碰事件。应用向SDK注册OneHop能力，需设置IOneHopSdkCallback.Stub回调接口；由触碰事件事件触发；应用可根据业务需要传递和处理相应数据。|
| |

## Public Method Summary

|------|---------------------------------------------------------|
|Return|Method|
|void|onOneHopReceived(String para)应用注册后，NFC触碰事件发生后调用，在此传递业务数据。|

## Public Methods

void onOneHopReceived(String data)应用注册OneHop能力成功后，在NFC触碰事件发生后会被调用。  

Parameters

|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Parameter name|Parameter desc|
|data|Json格式，通过OneHop传递的业务数据。手机端APP注册后，触碰事件发生，传递的参数为{"onehop_data_type":7, "onehop _receive_type":1, "handoff_data_type":7 }；对端设备在触碰事件发生后，系统OneHop向应用传递的参数为{"onehop_data_type":7, "onehop _receive_type":2, "handoff_data_type":7 "xxx":"xxx", ...}|
