# HwCaasServiceCallBack

|Interface Info|
|:--------------------------------------------------------------------------------------------------|
|public interface HwCaasServiceCallBack CaaS服务回调接口，由开发者实现并传入，作用是初始化CaaS服务和资源释放完成后通知开发者，以便开发者进行下一步操作。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|void|[initSuccess](#ZH-CN_TOPIC_0000001051063757__section387017267153)(HwCaasHandler handler) 初始化[HwCaasHandler](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/vir-devices-calling-hwcaashandler-0000001050729056)成功后的回调。|
|void|[initFail](#ZH-CN_TOPIC_0000001051063757__section1247116011619)(int retCode) 初始化[HwCaasHandler](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/vir-devices-calling-hwcaashandler-0000001050729056)失败后的回调。|
|void|[releaseSuccess](#ZH-CN_TOPIC_0000001051063757__section8415206131614)() [release](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/vir-devices-calling-hwcaasservicemanager-0000001050769085#ZH-CN_TOPIC_0000001050823731__section6487113981814)接口调用成功后的回调。|

#### Public Methods

#### initSuccess

|Method|
|:--------------------------------------------------------------------------------------------------------------|
|void initSuccess(HwCaasHandler handler) 初始化HwCaasHandler成功后的回调，用于给开发者提供可操作的Handler类，开发者通过该Handler类与CaaS服务侧进行交互。|

Parameters  

|Name|Description|
|:--------------------|:---------------------|
|Name|应用事件的名称。|
|HwCaasHandler handler|初始化成功后的HwCaasHandler类。|

#### initFail

|Method|
|:---------------------------------------------------------------|
|void initFail(int retCode) 初始化HwCaasHandler失败后的回调，通知开发者初始化失败的原因。|

Parameters  

|Name|Description|
|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Name|应用事件的名称。|
|int retCode|初始化失败的返回值。 * 2000：CaaS服务不支持（目前仅华为EMUI 10.0及以上版本且支持畅连通话的设备支持）。 * 2001：能力不支持（受软硬件能力限制，某些能力可能不支持，例如设备虚拟化能力目前支持的芯片平台为Kirin980、Kirin990，后续Kirin710、Kirin810、Kirin970及以上的芯片平台该能力会逐步放开）。 * 2002：鉴权失败（确认是否向华为申请API调用权限及是否在AndroidManifest.xml中添加开发者联盟创建应用时生成的appid信息）。 * 2003：CaaS服务侧异常。 * 2004：畅连未开启。 * 2005：畅连通话悬浮窗权限未打开。 * 2006：handlerType设置错误。 * 1000：虚拟化Camera失败。|

#### releaseSuccess

|Method|
|:-----------------------------------------------------------------|
|void releaseSuccess() release接口调用成功后的回调，开发者可以在此处释放自己申请的有关CaaS服务资源。|
