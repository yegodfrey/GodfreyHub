|Method|
|public int registerOneHop(String packageName，int dataType, IOneHopSdkCallback.Stub appCallBack)|
|应用向SDK注册OneHop能力，同时设置回调接口，OneHop SDK通过该回调接口通知应用触碰时间以及传递业务数据。|

Parameters

|--------------|-------------------------------------------------|
|Parameter name|Parameter desc|
|packageName|应用包名|
|dataType|应用类型，具体定义可参见相应contant定义|
|appCallBack|应用向OneHop注册的回调接口，应用通过该接口获取系统的OneHop当前状态变化以及同步事件等。|


**Return**


|----|----------------------------------|
|type|desc|
|int|返回注册结果，ONEHOP_OK为成功，ONEHOP_ERR为失败。|

**Return**


|----|----------------------------------|

|-----------------------------------------------------------------------------------------------------------|
|Method|
|public int oneHopSend(String packageName, JSONObject para)|
|应用通过该接口同步OneHop数据。例如，触碰事件通知到手机端应用，手机端应用将业务数据传递到OneHop。应用调用该接口的时机为OneHop通过之前应用注册的callBack通知应用发生触碰事件，应用收到消息时。|

Parameters

|--------------|---------------|
|Parameter name|Parameter desc|
|packageName|应用包名|
|para|Json格式，同步数据的参数。|


**Return**


|----|----------------------------------|
|type|desc|
|int|返回注册结果，ONEHOP_OK为成功，ONEHOP_ERR为失败。|
