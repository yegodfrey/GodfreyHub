# HwCaasServiceManager

|Class Info|
|:-----------------------------------------------------------------------|
|public final class HwCaasServiceManager Engine侧CaaS服务的管理类，完成初始化和资源释放等操作。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HwCaasServiceManager|[init](#ZH-CN_TOPIC_0000001050783732__section191862005557)() 初始化[HwCaasServiceManager](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-calling-hwcaasservicemanager-0000001050728616)实例。|
|void|[initHandler](#ZH-CN_TOPIC_0000001050783732__section1182751355515)(Context context, int handlerType, HwCaasServiceCallBack hwCaasServiceCallBack) 根据handlerType初始化具体的Handler类。|
|void|[release](#ZH-CN_TOPIC_0000001050783732__section1740413367559)() 释放使用Engine产生的相关资源。|

#### Public Methods

#### init

|Method|
|:---------------------------------------------------------------------------------------|
|public static HwCaasServiceManager init() 初始化HwCaasServiceManager实例，在调用其他接口前需要先调用此接口初始化。|

Return  

|Type|Description|
|:-------------------|:--------------------|
|HwCaasServiceManager|已初始化返回已有实例，未初始化返回新实例。|

#### initHandler

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void initHandler(Context context, int handlerType, HwCaasServiceCallBack hwCaasServiceCallBack) 根据handlerType初始化具体的Handler类， * 如果初始化成功，就会通过[HwCaasServiceCallBack](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-calling-hwcaasservicecallback-0000001050728614)回调接口[h2initSuccess](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-calling-hwcaasservicecallback-0000001050728614#ZH-CN_TOPIC_0000001050783728__section1442012825012)方法返回Handler类，该Handler用于和CaaS服务通信； * 如果初始化失败，就会通过[HwCaasServiceCallBack](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-calling-hwcaasservicecallback-0000001050728614)回调接口[h2initFail](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-calling-hwcaasservicecallback-0000001050728614#ZH-CN_TOPIC_0000001050783728__section126759512503)方法返回错误码。|

Parameters  

|Name|Description|
|:------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
|Context context|应用上下文信息。|
|int handlerType|需要初始化的Handler类型，目前支持： * 0：VIRTUAL_CAMERA_TYPE（虚拟设备音视频通话） * 1：HIDE_NUMBER_TYPE（号码隐藏） * 2：SCREEN_SHARING_TYPE（屏幕共享） * 3：NORMAL_CALL_TYPE（普通畅连通话）|
|HwCaasServiceCallBack hwCaasServiceCallBack|回调接口，由开发者实现并传入。|

#### release

|Method|
|:----------------------------------------------------|
|public void release() Engine服务使用完毕，释放使用Engine产生的相关资源。|
