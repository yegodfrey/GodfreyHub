# 返回码

|场景|含义|常量字段|值|
|:-------|:-----------------------------------------------------------------------------------------------------------------|:------------------------------------|:--|
|通用|非法参数错误|ERROR_CODE_INVALID_ARGUMENT|5|
|通用|设备版本不支持错误|ERROR_CODE_DEVICE_VERSION_NOT_SUPPORT|13|
|通用|设备未连接|ERROR_CODE_DEVICE_IS_NOT_CONNECTED|16|
|手表ping手机|手机侧应用未安装|MSG_ERROR_PING_PHONE_APP_NOT_EXIST|204|
|手表ping手机|手机侧应用已安装|MSG_ERROR_PING_PHONE_APP_NOT_RUNNING|205|
|手表和手机通信|[发送消息失败](https://developer.huawei.com/consumer/cn/doc/connectivity-Guides/faq-0000001050818031#section93836121392)|MSG_ERROR_SEND_FAIL|206|
|手表和手机通信|发送消息成功|MSG_ERROR_SEND_SUCCESS|207|
|手表和手机通信|手表版本过低（建议开发者提示用户：手表版本过低，请使用运动健康App对手表进行版本升级）|MSG_ERROR_CODE_VERSION_TOO_LOW|208|
