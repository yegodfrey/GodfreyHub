### queryCallAbility

|Method|
|:----------------------------------------------------------------------------------------------------------------|
|public int queryCallAbility(String phoneNumberSha256, HwCaasUtils.CallAbilityType abilityType) 查询传入的电话号码是否支持视频通话。|

**Parameters**

|Name|Description|
|:--------------------------------------|:------------------------------------------------------------------------------------|
|String phoneNumberSha256|需要查询的电话号码对应的SHA256加密字段，SHA256加密前的号码必须是带"+"号 + 国家（地区）码 + 号码 的格式，例如+86132xxxxxxxx。|
|HwCaasUtils.CallAbilityType abilityType|查询能力类型： * CallAbilityType.NORMAL_CALL：普通畅连通话能力。 * CallAbilityType.HIDE_NUMBER：号码隐藏能力。|

**Return**

|Type|Description|
|:---|:----------------------------------------------------------------|
|int|调用查询接口的返回值： * 0：查询成功，查询结果查看callAbilityResult的返回码。 * -1：查询失败，服务异常。|

### makeCall

|Method|
|:---------------------------------------------------------------------------------------------------------|
|public int makeCall(String phoneNumberSha256, HwCaasUtils.CallType callType, CustomDisplayInfo info) 拨打电话。|

**Parameters**

|Name|Description|
|:----------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|String phoneNumberSha256|电话号码对应的SHA256加密字段。SHA256加密前的号码必须是带"+"号 + 国家（地区）码 + 号码 的格式，例如+86132xxxxxxxx。|
|HwCaasUtils.CallType callType|通话类型： * CallType.VIDEO_CALL：视频。 * CallType.VOICE_CALL：语音。|
|CustomDisplayInfo info|详见[CustomDisplayInfo](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-cus-calling-customdisplayinfo-0000001050768283)说明。 > 说明 > 传入的字符串必须是UTF-8的编码格式。|

**Return**

|Type|Description|
|:---|:----------------------------------------------------------------------|
|int|调用拨打接口的返回码： * 0：拨打动作已成功通知service端，拨打结果在设置的拨打回调查看。 * 1：拨打动作通知service端失败。|
