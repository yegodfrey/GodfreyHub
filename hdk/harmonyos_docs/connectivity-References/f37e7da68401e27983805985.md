#### doNotification

|Method|
|:-----------------------------------------------------------------------------------------------------------------------------|
|public int doNotification(String deviceId, int notificationId, DvNotification notification, int operationMode) 发送消息通知到虚拟设备的接口。|

Parameters  

|Name|Description|
|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|deviceId|设备id，连接设备的id。|
|notificationId|通知消息分配的ID，由调用者进行划分传入。|
|notification|消息内容。消息内容的具体设置参见[DvNotification](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/dv-notification-0000001052227330)。|
|operationMode|消息通知的操作类型，取值有ADD_NOTIFY、UPDATE_NOTIFY、REMOVE_NOTIFY。|

Return  

|Type|Description|
|:---|:------------------------------------------------------------------------------------------------------------------------------------------------|
|int|0表示参数合法，非0表示调用失败，参见[ReturnCode](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/return-code-0000001052468665)说明。|
