# DvKit

|Class Info|
|:--------------------------------------------------------------------------------------------------------------------------|
|public class DvKit 提供设备虚拟化Engine包信息接口。 该类提供设备虚拟化Engine包信息接口，包括DeviceVirtualization Engine版本信息、获取Engine服务对象、连接DV服务以及断开DV服务等。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
|int|[connect](#section10499115317553)(Context context, IDVKitConnectCallback callback) 内部创建DV服务实例化对象。如果在非华为手机设备上，接口调用会抛NoClassDefFoundError异常。|
|void|[disconnect](#section36667239015)() 释放DV服务实例化对象。|
|String|[getVersion](#section183461747609)() 获取DV Engine版本信息。|
|VirtualManager|[getKitService](#section1033068418)(String serviceClass) 获取DV服务对象。|

#### Public Methods

#### connect

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public int connect(Context context, IDVKitConnectCallback callback) 内部创建DV服务实例化对象，建立与DV服务的连接，该方法是异步调用，对象实例化之后，通过callback回调返回给调用者。如果在非华为手机设备上，接口调用会抛NoClassDefFoundError异常。|

Parameters  

|Name|Description|
|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|context|应用上下文信息。|
|callback|服务实例化回调接口，定义为： ``` IDVKitConnectCallback { void onConnect(int returnCode); void onDisconnect(); } ``` onConnect 接口用于DV服务连接成功通知。 onDisconnect 接口用于DV服务断开通知。|

Return  

|Type|Description|
|:---|:------------------------------------------------------------------------------------------------------------------------------------------------|
|int|0表示调用成功，非0表示调用失败，参见[ReturnCode](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/return-code-0000001052468665)说明。|

#### disconnect

|Method|
|:-----------------------------------------------------------------|
|public void disconnect() 销毁DV服务实例化对象，该方法调用后会断开与DV服务的连接，针对其他服务也都断开。|

#### getVersion

|Method|
|:------------------------------------------------------------|
|public String getVersion() 获取DeviceVirtualization Engine版本信息。|

Return  

|Type|Description|
|:-----|:------------------------------------------------------------------------------|
|String|DeviceVirtualization Engine版本信息，格式M.S.F.B（M：主版本号。S：次版本号。F：特性版本号。B：编译版本号及内部标识位）。|

#### getKitService

|Method|
|:------------------------------------------------------------------------------------------------------------|
|public VirtualManager getKitService(String serviceClass) DeviceVirtualization Engine通过getKitService返回对应的服务对象。|

Parameters  

|Name|Description|
|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|serviceClass|服务定义名称，当前开放VirtualManager服务定义为： ``` public static final String VIRTUAL_DEVICE_CLASS = “VirtualDeviceManager”; public static final String VIRTUAL_SENSOR_SERVICE = “VirtualSensorService”; public static final String VIRTUAL_VIBRATE_SERVICE = “VirtualVibrateService”; public static final String VIRTUAL_NOTIFICATION_SERVICE = “VirtualNotificationService”; ```|

Return  

|Type|Description|
|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|VirtualManager|Engine服务对象。 VirtualDeviceManager是VIRTUAL_DEVICE_CLASS的服务对象。 SensorAgent是VIRTUAL_SENSOR_SERVICE的服务对象。 VibratorService是VIRTUAL_VIBRATE_SERVICE的服务对象。 DvNotificationService是VIRTUAL_NOTIFICATION_SERVICE的服务对象。|
