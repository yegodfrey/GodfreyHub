# 手机系统信息

#### 导入模块

```
import {PeerDeviceClient} from "../wearengine.js"
```

#### PeerDeviceClient.getPeerDevice(Object)

获取手机系统信息。

* 请求参数  

  |参数|类型|必填|说明|
  |:--------------------------------------------------------------------|:-----|:-|:--------|
  |[peerDeviceCallback](#ZH-CN_TOPIC_0000001874111010__li11790175314127)|Object|是|手机系统信息回调。|
  [表1 请求参数]

  * peerDeviceCallback  

    |参数值|类型|说明|
    |:--------|:-------|:---------------|
    |onSuccess|Function|获取手机系统信息成功的回调函数。|
    |onFailure|Function|获取手机系统信息失败的回调函数。|

    * onSuccess返回值  

      |参数|类型|必填|说明|
      |:-------------------------------------------------------|:-----|:-|:-----------|
      |[data](#ZH-CN_TOPIC_0000001874111010__table131052711159)|Object|是|获取手机系统信息返回值。|

      <br />

      |参数|类型|必填|说明|
      |:-------------------------------------------------------------|:-----|:-|:--------|
      |[peerDevice](#ZH-CN_TOPIC_0000001874111010__table131182721511)|Object|是|手机系统信息对象。|
      |errorCode|int|是|错误码。|
      [表2 data]

      |参数|类型|必填|说明|
      |:------|:--|:-|:--------------------------------|
      |mOsType|int|是|手机系统类型，1为Android或HarmonyOS，2为iOS。|
      [表3 peerDevice]

    <!-- -->

    * onFailure返回值  

      |参数|类型|必填|说明|
      |:---------------------------------------------------------|:-----|:-|:-----------|
      |[data](#ZH-CN_TOPIC_0000001874111010__table24631451194016)|Object|是|获取手机系统信息返回值。|

      |参数|类型|必填|说明|
      |:--------|:--|:-|:---|
      |errorCode|int|是|错误码。|
      [表4 data]
