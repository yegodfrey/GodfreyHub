# Interface Summary

|FileName|Description|
|:------------------------|:----------|
|dmsdp_video_encoder_api.h|南向视频编码接口。|

#### Public Method Summary

DMSDPGetVideoEncoderHandler 获取设备视频编码器功能方法，存放在DMSDPVideoEncoderHandler结构体中。

形式：int32_t DMSDPGetVideoEncoderHandler(DMSDPVideoEncoderHandler \*videoEncoderHandler)

参数：\[in\] na \[out\] videoEncoderHandler

输出：0表示成功，\<0表示失败。

描述：获取设备视频编码器功能方法，存放在DMSDPVideoEncoderHandler结构体中。

|:------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
