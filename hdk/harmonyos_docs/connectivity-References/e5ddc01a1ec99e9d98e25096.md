#### Public Methods

#### sendEventToCaasService

|Method|
|:--------------------------------------------------------------|
|public boolean sendEventToCaasService(int event) 发送消息事件给CaaS服务。|

Parameters  

|Name|Description|
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|int event|消息事件。 * 0：SHOW，显示悬浮球。 * 1：HIDE，隐藏悬浮球。 * 2：SHOW_CONTACT，显示联系人列表。 * 3：HIDE_CONTACT，隐藏联系人列表。 * 4：SCREEN_SHARING_PAUSE，暂停共享。 * 5：CREEN_SHARING_RESUME，恢复共享。|

Return  

|Type|Description|
|:------|:-------------------------|
|boolean|* true：发送成功。 * false：发送失败。|
