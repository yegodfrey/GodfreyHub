# Overview

提供用于Wear Engine事件上报和状态查询功能的类。

## Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------|:----------|
|[MonitorListener](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorlistener-0000001059850655)|事件上报的监测接口。|

## Class Summary

|Class|Description|
|:-------------------------------------------------------------------------------------------------------------------|:--------------------------------------------|
|[MonitorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitorclient-0000001059980975)|用于事件上报和状态查询的客户端，比如设备与运动健康App的连接状态。|
|[MonitorData](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitordata-0000001060779124)|监测指标转换为可操作的数据，如：boolean、int、String、HashMap数据。|
|[MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013)|监测设备的指标对象，比如设备与运动健康App的连接状态等。|
