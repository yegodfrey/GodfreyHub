# IVirtualizationCallback

|Interface Info|
|:-------------------------------------------------|
|public interface IVirtualizationCallback 事件监听回调接口。|

#### Constant Summary

|Type|Constant Field|Description|
|:---|:------------------------------|:--------------------------------------------------|
|int|DeviceEvent.CONNECT|设备已连接。|
|int|DeviceEvent.DISCONNECT|设备已断连。|
|int|DeviceEvent. REQUEST_CONNECTION|设备请求连接，可调用acceptConnection接受或者disconnectDevice拒绝连接。|
|int|DeviceEvent. START_PROJECTION|投屏通道已准备，应用此时需显示surface并调用startProjection。|
|int|DeviceEvent. STOP_PROJECTION|投屏已停止，应用需取消surface的显示。|
