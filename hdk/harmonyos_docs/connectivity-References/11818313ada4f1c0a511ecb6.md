# SensorAgent

|Class Info|
|:----------------------------------------------------------------------------|
|public class SensorAgent extends VirtualManager 该类为设备Sensor代理类，提供Sensor相关的接口。|

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220513105006.69531670534274062104613762711997:50530512064512:2800:225E6DDB4DCFCB9C075A2F3EFB264B0FEACDC26C63C6FF3466EFAC5B9489ABC8.png?needInitFileName=true?needInitFileName=true)  
sensor的能力的使用需要申请分布式sensor权限com.huawei.permission.DISTRIBUTED_VIRTUALDEVICE以及对应的Android权限（例如：心率是android.permission.BODY_SENSORS权限）。

本能力需要DV Engine版本在1.0.1.300以上才支持。

#### subscribeSensorDataListener

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------|
|public int subscribeSensorDataListener(IVirtualSensorDataListener listener, VirtualSensor sensor) 注册Sensor监听，使用本接口发起的订阅，上报周期固定为5秒。|

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220513105006.26450654583461547454341153885868:50530512064512:2800:B2C2699509BF7D6C33E58CBCDA354E4B8B20BCE741364B3CAD7DCD5467A16113.png?needInitFileName=true?needInitFileName=true)  
1. 此接口只支持订阅心率计数且上报周期固定为5秒。

2. 推荐使用1.0.3.300上新增的可指定上报周期的订阅接口。

Parameters  

|Name|Description|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|listener|Sensor数据订阅的回调接口，获取发现到的虚拟设备Sensor的数据： public interface IVirtualSensorDataListener { void onSensorChanged(VirtualSensorData data); } onSensorChanged用于获取Sensor上报的数据。|
|sensor|获取的sensor对象。|

Return  

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|0表示调用成功，非0表示调用失败，详见ReturnCode说明。参见[ReturnCode](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/return-code-0000001052468665)。|

#### subscribeSensorDataListener

|Method|
|:----------------------------------------------------------------------------------------------------------------------------|
|public int subscribeSensorDataListener(IVirtualSensorDataListener listener, VirtualSensor sensor, int rate) 指定上报频率注册Sensor监听。|

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220513105006.96730223525806539683240352201950:50530512064512:2800:4BCA1D9BA4456C0F0BCD7CD19ACBE5F837A34FDDD656B43F239CC5CC743B6AC0.png?needInitFileName=true?needInitFileName=true)  
1. 不同器件的数据采集能力不同，如果指定的上报频率超过虚拟设备的采集能力，则返回ReturnCode.ERROR_CODE_DEVICE_NOT_SUPPORT错误码。

2. 本能力需要DV Engine版本在1.0.3.300及以上才支持。

Parameters  

|Name|Description|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|listener|Sensor数据订阅的回调接口，获取发现到的虚拟设备Sensor的数据： public interface IVirtualSensorDataListener { void onSensorChanged(VirtualSensorData data); } onSensorChanged用于获取Sensor上报的数据。|
|sensor|获取的sensor对象。|
|rate|Sensor数据的上报频率。 1. SENSOR_DELAY_FAST：上报频率约为60毫秒 2. SENSOR_DELAY_NORMAL：上报频率约为200毫秒 3. SENSOR_DELAY_SLOW：上报频率约为5000毫秒|

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220513105006.37950978060228073754592322699481:50530512064512:2800:160897CA63F4BA907455A48C57612B9EDC00AD7642E98094E9C8830B7B93C508.png?needInitFileName=true?needInitFileName=true)  
由于不同器件的数据采集精度存在差异，系统将采用合适的频率从设备采集数据，并按照指定的频率上报给应用。

Return  

|Type|Description|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int|0表示调用成功，非0表示调用失败，详见ReturnCode说明。参见[ReturnCode](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/return-code-0000001052468665)。|
