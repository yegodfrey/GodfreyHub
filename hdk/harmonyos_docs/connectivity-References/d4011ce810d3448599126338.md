# Overview

提供用于Wear Engine操作设备sensor功能的类。

## Interface Summary

|Interface|Description|
|:-----------------------------------------------------------------------------------------------------------------------------|:-----------|
|[SensorReadCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorreadcallback-0000001060099095)|读传感器数据的回调接口。|
|[SensorStopCallback](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorstopcallback-0000001059781035)|关闭传感器数据回调接口。|

## Class Summary

|Class|Description|
|:-----------------------------------------------------------------------------------------------------------------|:---------------------------------|
|[DataResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670)|传感器返回的数据结构。|
|[Sensor](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensor-0000001059980981)|传感器类型，当前包含ACC、ECG、GYRO、HR、MAG、PPG。|
|[SensorClient](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130)|用于操作设备传感器。|
