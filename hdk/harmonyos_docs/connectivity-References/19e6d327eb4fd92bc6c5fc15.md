#### Method Detail

#### asFloats

public float\[\] asFloats()

传感器上报的数据最终都是以float\[\]的形式呈现，其中又分为多通道传感器，如PPG、ECG，和非多通道传感器，如ACC、GYRO、HR、MAG；对于非多通道传感器，可以直接通过调用DataResult对象的asFloats方法获取数据。

Returns:

结果数据，具体格式由文档约定

See Also:

[Sensor](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensor-0000001059980981)

Since:

API level 2 (SDK 5.0.1.300)

#### asList

public java.util.List\<[DataResult](https://developer.huawei.com/consumer/cn/doc/connectivity-References/dataresult-0000001060330670)\> asList()

对于支持多通道的传感器，数据在dataResult类中嵌套了一层。以PPG为例，在一种设备上，PPG的数据包含GREEN、RED、IR三路通道， 可以通过DataResult对象的asList方法获得一个List\<DataResult\>，该List的长度即为通道数（比如：PPG为3）， 不同的通道通过各自对象的mChannel属性来区分，具体可参见DataResult定义和Sensor定义，每个通道的数据，可以再调用asFloats方法获取。

Returns:

结果数据，具体格式由文档约定

API level 2 (SDK 5.0.1.300)
