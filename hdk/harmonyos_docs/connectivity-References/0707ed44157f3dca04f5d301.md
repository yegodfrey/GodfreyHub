#### setConnectRequestChooseResult(ConnectRequestChoice choice)

|Method|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public boolean setConnectRequestChooseResult([ConnectRequestChoice](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/connectrequestchoice-0000001051767796) choice) 未连接过设备连接到大屏端时，会通过Constant.[EVENT_ID_PIN_CODE_SHOW](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-0000001052527792#section39668214540)事件通知应用层显示对应的提示框，请大屏端用户确认是否可以允许远端设备投屏，选择结果通过该方法设置。|

|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|choice|连接请求确认结果类，可选值有： * Constant.[CONNECT_REQ_CHOICE_REJECT](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-0000001052527792#section2037225813553)：大屏设备端拒绝连接 * Constant.[CONNECT_REQ_CHOICE_ONCE](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-0000001052527792#section97817313564)：大屏设备端允许一次连接 * Constant.[CONNECT_REQ_CHOICE_ALWAYS](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-0000001052527792#section3860710145712)：大屏设备端总是允许连接|

Return  

|Type|Description|
|:------|:------------------------|
|boolean|* True：设置成功 * False：底层未处理|
