# Interface Summary

|FileName|Description|
|:-------------|:----------|
|dmsdp_device.h|南向设备信息适配接口|

## Public Methods

### DMSDPGetState

|Method|
|:-----------------------------------------------------------------------------------------------------------------------|
|int32_t DMSDPGetState(uint32_t* state) 获取DMSDP服务状态，当厂商不希望设备作为DMSDP设备虚拟化设备并提供服务时，状态为DMSDP_UNAVAILABLE，否则为DMSDP_AVAILABLE。|

**Parameters**

|Name|Description|
|:----|:---------------------------------------------------------------------------------|
|state|DMSDP服务状态。 typedef enum { DMSDP_UNAVAILABLE = 0, DMSDP_AVAILABLE = 1 } DMSDPState;|

**Return**

|Type|Description|
|:------|:----------|
|int32_t|0:成功，<0失败。|

### DMSDPGetDeviceType

|Method|
|:------------------------------------------------------|
|int32_t DMSDPGetDeviceType(uint32_t *type) 获取DMSDP设备类型。|

**Parameters**

|Name|Description|
|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|type|DMSDP设备类型。 typedef enum { DEVICE_TYPE_NONE = 0, DEVICE_TYPE_PHONE = 1, DEVICE_TYPE_PAD = 2, DEVICE_TYPE_TV = 3, DEVICE_TYPE_CAR = 4, DEVICE_TYPE_CAMERA = 5, DEVICE_TYPE_VOICEBOX = 6, DEVICE_TYPE_PC = 7 } DMSDPDeviceType;|

**Return**

|Type|Description|
|:------|:----------|
|int32_t|0:成功，<0失败。|

### DMSDPGetDeviceServiceCapability

|Method|
|:----------------------------------------------------------------------------------------------------|
|int32_t DMSDPGetDeviceServiceCapability(uint32_t* serviceMask, uint32_t* stateMask) 获取DMSDP设备服务能力和状态。|

**Parameters**

|Name|Description|
|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|serviceMask|DMSDP设备服务能力掩码。 每种业务类型1bit typedef enum { SERVICE_TYPE_NONE = 0, SERVICE_TYPE_CAMERA = 0x01, SERVICE_TYPE_MIC = 0x02, SERVICE_TYPE_SPEAKER = 0x04, SERVICE_TYPE_DISPLAY = 0x08, SERVICE_TYPE_GPS = 0x10, SERVICE_TYPE_BUTTON = 0x20 } DMSDPServiceType; 如果同时支持MIC和Speaker，则 MASK为SERVICE_TYPE_MIC | SERVICE_TYPE_SPEAKER|
|stateMask|DMSDP设备服务状态，如果当前设备服务被占用，不可被使用，返回SERVICE_UNAVAILABLE。 每1个服务对应的状态占用2bit，低2bit为Camera业务的状态，依次类推。 typedef enum { SERVICE_UNAVAILABLE = 0, SERVICE_AVAILABLE = 1 } DMSDPServiceState; 如果同时支持MIC和Speaker状态都AVAILABLE MASK为0x00000014|

**Return**

|Type|Description|
|:------|:----------|
|int32_t|0:成功，<0失败。|

### DMSDPDeviceRegisterListener

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------|
|int32_t DMSDPDeviceRegisterListener(const DMSDPListener* listener) 开发者实现此接口，DV Engine调用此接口。注册Device监听，和设备相关的事件或者状态都可以通过注册的listener上报到手机。|

**Parameters**

|Name|Description|
|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|listener|监听回调列表。 typedef struct { //服务状态回调函数,设备状态变化时，通过该接口通知手机； int32_t (*UpdateServiceStatus)(const char* id, uint32_t idLen, const DMSDPServiceStatus status); //服务事件回调函数，通知指定事件给手机 int32_t (*UpdateServiceAction)(const char* id, uint32_t idLen, DMSDPServiceAction* action); } DMSDPListener; //设备状态枚举： typedef enum { /* 外设连接到设备上，比如插入USB Camera */ PLUGIN = 1, /* 外设和设备断开连接，比如USB Camera从车技拔出 */ UNPLUG, /* 外设链接在设备上，处于空闲可用状态 */ AVAILABLE, /* 外设连接在设备上，处于业务运行中，其他应用要用需要抢占 */ UNAVAILABLE, } DMSDPServiceStatus; //事件类型枚举 typedef enum { /* audio focus change */ AUDIO_FOCUS_CHANGE = 1, /* add camera service info, using DMSDPCameraCapabilities struct */ CAMERA_ADD_SERVICE = 2, /* add camera service info, using DMSDPCameraCapabilities struct json string */ CAMERA_ADD_SERVICE_STRING = 3, /* add audio service info, using DMSDPAudioCapabilities struct */ AUDIO_ADD_SERVICE = 4, /* add audio service info, using DMSDPAudioCapabilities struct json string */ AUDIO_ADD_SERVICE_STRING = 5, /* device send common data to application */ DEVICE_SEND_COMMON_DATA = 6, /* notify the hardware state change notify, such as the Speaker Driver broken */ DEVICE_HARDWARE_STATE_NOTIFY = 7 } DMSDPServcieActionType; //服务事件 typdef struct { DMSDPServcieActionType type; void* value; uint32_t valLen; } DMSDPServiceAction; 例如，audio focus为-3，则value为"-3"，valLen为2 //发送到手机侧数据类型 typedef enum { DATA_TYPE_CAR_CTRL_CMD = 1, DATA_TYPE_HOTWORD = 2, DATA_TYPE_KEY_EVENT = 3, DATA_TYPE_HISIGHT_MOTION_EVENT = 4, DATA_TYPE_HISIGHT_KEY_EVENT = 5, DATA_TYPE_MSDP_PORT = 6, DATA_TYPE_AIRSHARING_PORT = 7, DATA_TYPE_AIRSHARING_INPUT = 8, DATA_TYPE_AIRSHARING_HISIGHT_EXT_WINI_NFO = 9, DATA_TYPE_VIRTUAl_KEY_EVENT = 10, DATA_TYPE_INPUT_DEVICE_EVNET = 11, DATA_TYPE_AUDIO_NET_UNSTABLE = 12, DATA_TYPE_DISPLAY_NET_UNSTABLE = 13, DATA_TYPE_AIRSHARING_INPUT_FOUCS = 14, DATA_TYPE_SCREEN_EVENT = 15, DATA_TYPE_DEVICE_POLICY_EVENT = 16, DATA_TYPE_TV_NETWORK_WEAK = 20, } DMSDPDeviceDataType; //通用数据格式，可以作为DMSDPServiceAction的value，dataType可以取值如DATA_TYPE_DEVICE_POLICY_EVENT typedef struct { int32_t dataType; char *data; uint32_t dataLen; int32_t extendInfo; } DMSDPDeviceCommonData;|

**Return**

|Type|Description|
|:------|:----------|
|int32_t|0:成功，<0失败。|
