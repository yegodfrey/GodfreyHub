# VirtualVibrator

|Class Info|
|:-----------------------------------------------------------------------|
|public class VirtualVibrator 该类为虚拟Vibrator的信息定义类，提供Vibrator的相关信息接口和控制接口。|

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220513105006.69950052505081817577652069272401:50530512064512:2800:4F8EACD6F96D3A0E3B0592652100EEC0A10F0EC86328E717BE568CC311517893.png?needInitFileName=true?needInitFileName=true)  
1. vibrator的能力的使用需要申请分布式马达权限com.huawei.permission.DISTRIBUTED_VIRTUALDEVICE以及对应的Android权限android.permission.VIBRATE。

2. 本能力需要DV Engine版本在1.0.1.300以上才支持。

Parameters

|:-----------|:-------------------------------------------------|

#### vibrate

|Method|
|:------------------------------------------------------|
|public void vibrate(long\[\] pattern, int repeat) 多参振动。|

Parameters  

|Name|Description|
|:------|:-------------------------------------------|
|pattern|单位毫秒数组例如：\[1000,2000\] 振动1000ms，暂停2000ms。|
|repeat|震动次数。 0表示一直重复；1表示震动一次；n\>1表示重复震动n次；n\<0为非法值。|
