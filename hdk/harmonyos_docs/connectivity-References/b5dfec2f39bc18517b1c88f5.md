# VirtualVibrator

|Class Info|
|:-----------------------------------------------------------------------|
|public class VirtualVibrator 该类为虚拟Vibrator的信息定义类，提供Vibrator的相关信息接口和控制接口。|

> 说明
>
> 1. vibrator的能力的使用需要申请分布式马达权限com.huawei.permission.DISTRIBUTED_VIRTUALDEVICE以及对应的Android权限android.permission.VIBRATE。
>
> 2. 本能力需要DV Engine版本在1.0.1.300以上才支持。

### vibrate

|Method|
|:-------------------------------------------|
|publicvoid vibrate(long milliseconds) 振动n毫秒。|

**Parameters**

|Name|Description|
|:-----------|:-------------------------------------------------|
|milliseconds|单位毫秒，振动的时长，时间为大于等于0的值，如果等于0则表示一直震动，大于0的值标识震动的具体时间。|

### vibrate

|Method|
|:---------------------------------------------------|
|publicvoid vibrate(long[] pattern, int repeat) 多参振动。|

**Parameters**

|Name|Description|
|:------|:-----------------------------------------|
|pattern|单位毫秒数组例如：[1000,2000] 振动1000ms，暂停2000ms。|
|repeat|震动次数。 0表示一直重复；1表示震动一次；n>1表示重复震动n次；n<0为非法值。|
