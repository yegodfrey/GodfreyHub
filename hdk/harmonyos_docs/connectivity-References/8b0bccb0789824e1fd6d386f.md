|Interface Info|
|:---------------------------------------------------------------------------------|
|public interface HwMakeCallCallBack 拨打执行结果的回调接口，由开发者实现并传入，作用是返回拨打执行的结果，以便开发者进一步操作。|

|:-----------------|:----------------------------------------------------------------------------------------------------------------|

## Public Methods

### makeCallResult

|Method|
|:--------------------------------------------------------------------|
|public void makeCallResult(String phoneNumber, int retCode) 接收拨打执行结果。|

**Parameters**

|Name|Description|
|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|String phoneNumber|拨打时传入的号码。|
|int retCode|* 0：拨打成功。 * 3000：网络错误，查询失败。 * 3001：当前应用不在前台。 * 3002：只支持畅连语音通话，不支持畅连视频通话。 * 3003：当前号码不支持畅连音频和视频通话。 * 3004：当前号码不支持号码隐藏模式。 * 3005：拨打接口入参异常。 * 3006：畅连通话未开启。|
