# Sensor

|--------------------------------------------------------------------------------------------------------------------------------------|
|java.lang.Object |---com.huawei.wearengine.sensor.Sensor public class Sensor extends java.lang.Object implements android.os.Parcelable|

传感器类型，当前包含ACC、ECG、GYRO、HR、MAG、PPG。

穿戴侧支持的传感器类型受限于穿戴设备类型，具体支持的传感器类型请使用[getSensorList](https://developer.huawei.com/consumer/cn/doc/connectivity-References/sensorclient-0000001060779130#ZH-CN_TOPIC_0000001920110369__getSensorList-com_huawei_wearengine_device_Device-)查询。
