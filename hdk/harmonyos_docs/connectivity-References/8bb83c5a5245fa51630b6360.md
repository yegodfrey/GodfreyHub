# DvNotification

|Class Info|
|:------------------------------------------------------------------|
|public class DvNotification 该类为消息通知的消息属性定义类，提供消息通知的相关属性设置接口及属性常量定义。|

> 说明
>
> 本能力需要DV Engine版本在1.0.2.300及以上才支持。

### KEY_DIRECTION_INDEX

|Field|
|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public static final String KEY_DIRECTION_INDEX 导航消息的导航图标索引属性。消息模板为GUIDE_LAYOUT_TEMPLATE时有效，为可选字段。EMUI10.1版本存在预置的图片，对应的索引取值如下： 0x01 左转 0x02 右转 0x03 左前方 0x04 右前方 0x05 左后方 0x06 右后方 0x07 左转调头 0x08 右转调头 0x09 到达。 另请参阅：[Constant-values](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001052649667#section219630194119)。|
