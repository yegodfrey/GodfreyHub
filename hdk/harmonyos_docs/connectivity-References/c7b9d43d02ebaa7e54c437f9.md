# VirtualSensor

|Class Info|
|:---------------------------------------------------------------------------------|
|public class SensorAgent extends VirtualManager 该类为虚拟Sensor的信息定义类，提供Sensor的相关信息接口。|

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220513105006.85533858021225480239922601640206:50530512064512:2800:6D8AF6002550846E0803CD5607A149689EF4AC13FB48E9176B10E7CE056DB378.png?needInitFileName=true?needInitFileName=true)  
1. 使用虚拟Sensor的能力需要申请分布式虚拟化设备的权限com.huawei.permission.DISTRIBUTED_VIRTUALDEVICE以及对应的Android权限android.permission.BODY_SENSORS。

2. 本能力需要DV Engine版本在1.0.1.300以上才支持。
