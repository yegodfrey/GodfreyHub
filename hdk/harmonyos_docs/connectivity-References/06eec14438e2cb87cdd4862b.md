# Class

|-------------------------------------------|
|NSObject \|---WearEngineSDK.WESDeviceClient|

用于设备管理的客户端，开发者可以通过该客户端进行设备连接和查看操作。  

#### Method Summary

|Modifier and Type|Method and Description|
|:----------------|:----------------------------------------------------|
|WESDevice\*|[getCurrentDevices](#section6464173116407) 获取当前连接的设备。|
|void|[getCommonDevices](#section16552950197) 获取所有设备。|
|void|[connectDevice](#section161612521497) 连接设备|

#### getCurrentDevices

- (WESDevice \*)getCurrentDevices;

获取当前连接的设备。同一时刻只有一个设备处于连接中。

Returns:

当前连接的设备。没有设备连接时，返回空。  

#### getCommonDevices

- (void)getCommonDevices:(WESGetDeviceCallback)callback;

获取设备列表。

Parameters:  

|Parameter Name|Parameter Description|
|:-------------|:--------------------|
|callback|通过回调函数返回设备列表。|

#### connectDevice

- (void)connectDevice:(WESDevice \*)device connectCallback:(WESConnectCallback)callback;

连接指定的设备。

Parameters:  

|Parameter Name|Parameter Description|
|:-------------|:--------------------|
|device|指定连接的设备。|
|callback|设备连接的结果。|
