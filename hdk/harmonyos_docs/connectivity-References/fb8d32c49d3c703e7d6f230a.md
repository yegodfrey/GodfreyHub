#### DeviceInfo(String name, int type, int capability, String id, String authData, int triggerType)

|Constructor|
|:-------------------------------------------------------------------------------------------------------------------------------------------|
|public DeviceInfo(String name, int type, int capability, String id, String authData, int triggerType) 构造出一个DeviceInfo对象，配置ID和标签类型，目前用于一碰投场景。|

Parameters  

|Name|Description|
|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|name|大屏端设备名称，要求数据大小为32bytes。|
|type|大屏端设备类型，默认值为[TYPE_UNKNOWN](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)。 可选值有： * [TYPE_UNKNOWN](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：未知设备 <!-- --> * [TYPE_TV](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：电视设备 * [TYPE_PROJECTOR](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：投影仪设备 * [TYPE_WHITEBOARD](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：电子白板设备 * [TYPE_SCREEN_THROWER](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：投屏器设备 * [TYPE_SET_TOP_BOX](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：机顶盒设备|
|capability|投屏模式，默认值为[HW_CAST_MIRROR](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)。 可选值有： * [HW_CAST_MIRROR](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：镜像投射模式 * [HW_CAST_APP_STREAM](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：资源投射模式，暂不支持|
|id|设备ID，目前用于一碰投场景，要求在64bytes以内|
|authData|认证数据，目前用于一碰投场景|
|triggerType|标签类型，默认值为 [UNSPEC_TAG](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)。 可选值有： [UNSPEC_TAG](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：无类型 [PASSIVE_MATCH_TAG](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：无源匹配类型 [ACTIVE_MATCH_TAG](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：有源匹配类型 [PASSIVE_BIND_TAG](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/constant-values-0000001051925695#section6908232864)：无源绑定类型|
