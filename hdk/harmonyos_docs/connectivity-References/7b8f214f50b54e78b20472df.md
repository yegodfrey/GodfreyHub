# VibratorService

|Class Info|
|:------------------------------------------------------------------------------------|
|public class VibratorService extends VirtualManager 该类为设备Vibrator代理类，提供Vibrator相关的接口。|

> 说明
>
> 1. vibrator的能力的使用需要申请分布式马达权限com.huawei.permission.DISTRIBUTED_VIRTUALDEVICE以及对应的Android权限android.permission.VIBRATE。
>
> 2. 本能力需要DV Engine版本在1.0.1.300以上才支持。

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:---------------------------------------------------------------------|
|List|[getVibrateList](#section15580174714567)(String deviceId) 获取选定设备的所有马达。|

## Public Methods

### getVibrateList

|Method|
|:--------------------------------------------------------------------------------|
|publicList getVibrateList(String deviceId) 获取选定设备的所有马达，如果该设备不支持虚拟马达，则返回的list个数为0。|

**Parameters**

|Name|Description|
|:-------|:------------|

**Return**

|Type|Description|
|:---|:----------|
