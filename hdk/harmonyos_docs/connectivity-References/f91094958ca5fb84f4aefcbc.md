## Public Method Summary

DMSDPGetAudioEncoderHandler 获取设备音频编码器功能方法，存放在DMSDPAudioEncoderHandler结构体中。

形式：int32_t DMSDPGetAudioEncoderHandler(DMSDPAudioEncoderHandler *audioEncoderHandler)

参数：[in] na [out]audioEncoderHandler

输出：0表示成功，<0表示失败。

描述：获取设备音频编码器功能方法，存放在DMSDPAudioEncoderHandler结构体中。

### AudioEncoderGetAbility

|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|int32_t (*AudioEncoderGetAbility)( AEncAbility *audioEncAbility, int32_t maxEncNum, int *audioEncCnt) 获取设备音频编码器能力，具体参数存放在audioEncAbility结构体中，audioEncCnt支持几个音频编码器如果支持多个编码器，返回多个编码器，比如同时支持多个编码器。|

**Parameters**

|Name|Description|
|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|audioEncAbility|音频编码能力。 typedef struct { /* 编码器类型，0:AAC，1:G.711A目前仅支持AAC LC */ int32_t codecType; /* 最大声道数，目前支持最大值为2 */ int32_t maxChannel; /* 最小声道数，目前支持最小值为1 */ int32_t minChannel; /* 最大采样率 目前支持最大采样率48K */ int32_t maxSampleRate; /* 最小采样率 目前支持最小采样率8K */ int32_t minSampleRate; /* 最大采样精度，目前支持16bit */ int32_t maxSampleDepth; /*最小采样精度，目前支持16bit */ int32_t minSampleDepth; /* 存储类型，掩码方式，bit0:交织存储，bit1:平面存储，目前支持交织格式 */ int32_t pcmStoreTypeMask; /* 支持最大同时创建编码器的个数 */ int32_t maxCodecNum; /* 是否支持异步输出，如果支持需要通过注册的回调进行输出 */ bool isAsynOutput; } AEncAbility;|
|audioEncCnt|支持编码器个数。|
|maxEncNum|最大编码器个数。|

|Type|Description|
|:------|:----------|
