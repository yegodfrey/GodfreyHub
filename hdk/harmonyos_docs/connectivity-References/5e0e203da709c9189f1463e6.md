# HwCaasServiceManager

|Class Info|
|:-----------------------------------------------------------------------|
|public final class HwCaasServiceManager Engine侧CaaS服务的管理类，完成初始化和资源释放等操作。|

#### Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HwCaasServiceManager|[init](#ZH-CN_TOPIC_0000001050823731__section1966350201814)() 初始化HwCaasServiceManager实例。|
|void|[initHandler](#ZH-CN_TOPIC_0000001050823731__section12511173411185)(Context context, int handlerType, HwCaasServiceCallBack hwCaasServiceCallBack) 根据handlerType初始化具体的Handler类。|
|void|[release](#ZH-CN_TOPIC_0000001050823731__section6487113981814)() 释放使用CaaS服务产生的相关资源。|

#### Public Methods

#### init

|Method|
|:---------------------------------------------------------------------------------------|
|public static HwCaasServiceManager init() 初始化HwCaasServiceManager实例，在调用其他接口前需要先调用此接口初始化。|

Return  

|Type|Description|
|:-------------------|:--------------------|
|HwCaasServiceManager|已初始化返回已有实例，未初始化返回新实例。|

#### initHandler

|Method|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public void initHandler(Context context, int handlerType, HwCaasServiceCallBack hwCaasServiceCallBack) 根据handlerType初始化具体的Handler类。如果初始化成功，就会通过HwCaasServiceCallBack回调接口initSuccess方法返回Handler类，该Handler用于和CaaS服务通信；如果初始化失败，就会通过HwCaasServiceCallBack回调接口initFail方法返回错误码。|

Parameters  

|Name|Description|
|:------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
|Context context|应用上下文信息。|
|int handlerType|需要初始化的Handler类型，目前只有： * 0：VIRTUAL_CAMERA_TYPE（虚拟设备音视频通话）。 * 1：HIDE_NUMBER_TYPE（号码隐藏）。 * 2：SCREEN_SHARING_TYPE（屏幕共享）。 * 3：NORMAL_CALL_TYPE（普通畅连通话）。|
|HwCaasServiceCallBack hwCaasServiceCallBack|回调接口，由开发者实现并传入。|

#### release

|Method|
|:--------------------------------------------------|
|public void release() CaaS服务使用完毕，释放使用CaaS服务产生的相关资源。|
