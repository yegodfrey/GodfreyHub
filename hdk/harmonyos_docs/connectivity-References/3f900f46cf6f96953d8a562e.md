# Overview

## Interface Summary

|Interface|Description|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------|
|[HwCaasServiceCallBack](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-cus-calling-hwcaasservicecallback-0000001050728248)|CaaS服务回调接口，由开发者实现并传入，作用是初始化和资源释放完成后通知开发者，以便开发者进行下一步操作。|
|[HwCallAbilityCallBack](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-cus-calling-hwcallabilitycallback-0000001051008301)|音视频通话能力查询回调接口，由开发者实现并传入，作用是返回支持的音视频通话能力，以便开发者进一步操作。|
|[HwMakeCallCallBack](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/in-app-cus-calling-hwmakecallcallback-0000001051088220)|拨打执行结果的回调接口，由开发者实现并传入，作用是返回拨打执行的结果，以便开发者进一步操作。|
