## Field Detail

### MONITOR_ITEM_CONNECTION

public static final [MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013) MONITOR_ITEM_CONNECTION

设备连接状态。

当监测该状态的时候，监测回调返回，2：连接成功；3：连接断开；4：连接失败；5：设备被删除。

**Since:**

API level 0 (SDK 5.0.0.301)

### MONITOR_ITEM_WEAR

public static final [MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013) MONITOR_ITEM_WEAR

佩戴状态。

支持查询与上报，结果有：1：佩戴；2：未佩戴。

**Since:**

API level 2 (SDK 5.0.1.300)

### MONITOR_ITEM_LOW_POWER

public static final [MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013) MONITOR_ITEM_LOW_POWER

低电量告警，每消耗百分之一的电量上报一次。

只支持上报如需查询请参见[MONITOR_POWER_STATUS](#ZH-CN_TOPIC_0000001919950717__MONITOR_POWER_STATUS)。

API level 2 (SDK 5.0.1.300)

### MONITOR_CHARGE_STATUS

public static final [MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013) MONITOR_CHARGE_STATUS

充电状态。

支持查询与上报，结果有：1：充电开始；2：充电结束；3：充电完成。

**Since:**

API level 2 (SDK 5.0.1.300)

### MONITOR_ITEM_HEART_RATE_ALARM

public static final [MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013) MONITOR_ITEM_HEART_RATE_ALARM

心率告警。

只支持上报，结果有：1：静态心率过高；2：静态心率过低；3：运动心率过高；4：运动心率过低；5：同时超过穿戴设备中设置的运动心率上限和在运动健康App中设置的运动心率上限（若穿戴设备中设置的上限低于App中的，则上报5）。

**Since:**

API level 2 (SDK 5.0.1.300)

### MONITOR_ITEM_POWER_MODE

public static final [MonitorItem](https://developer.huawei.com/consumer/cn/doc/connectivity-References/monitoritem-0000001059433013) MONITOR_ITEM_POWER_MODE

设备模式。

支持查询和上报，结果有：-1：设备不支持模式切换（只有查询会返回）；0：设备处于智能模式；1：设备处于超长续航模式。

**Since:**

API level 12 (SDK 5.0.3.301)
