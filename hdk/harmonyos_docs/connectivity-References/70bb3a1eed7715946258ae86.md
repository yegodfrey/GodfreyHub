# Public Enum

**获取参数类型**。

|Enum Value and Description|
|:---------------------------------------------|
|GET_DEV_MAC 获取设备MAC地址，格式为xx:xx:xx:xx:xx:xx字符串。|
|GET_MODEL_ID 获取设备modelID。|
|GET_DEV_NAME 获取设备名称。|
|GET_MAP_PORT 获取UUID服务的端口。|
|GET_WIFI_ABILITY 获取Wi-Fi的能力，格式为WifiAbility结构体。|

设置参数类型的枚举值。

|Enum Value and Description|
|:-------------------------|
|SET_BLE_PARAMS 设置BLE的参数。|
|SET_BR_UUID 设置BR服务的UUID。|
|SET_WIFI_LOCAL_IP 设置本地化IP。|

通道需要上报的事件枚举值。

|Enum Value and Description|
|:-------------------------------------|
|EVENT_CONNECT = 1 通道连接。|
|EVENT_CONNECT_FAIL 通道连接失败。|
|EVENT_DISCONNECT 通道连接断开。|
|EVENT_SCAN_RESULT 通道扫描结果。|
|EVENT_CREATE_WIFI_SUCCESS 创建GO成功。|
|EVENT_CONFIG_IP_SUCCESS Wi-Fi 本地化IP成功。|

通道类型的枚举值。

|Enum Value and Description|
|:-------------------------|
|CHANNEL_UNSET = 0 通道未设置。|
|CHANNEL_BLE BLE 通道类型。|
|CHANNEL_BREDR BR 通道类型。|
|CHANNEL_P2P P2P 通道类型。|
|CHANNEL_USB USB通道类型。|
