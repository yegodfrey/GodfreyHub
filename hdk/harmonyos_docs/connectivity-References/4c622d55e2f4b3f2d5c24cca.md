## Public Methods

### init

|Method|
|:---------------------------------------------------------------------------------------------------------------------------|
|public static void init(Context context, CameraListener listener) HwDmsdpService初始化，完成与虚拟化服务侧的绑定，并将实现的虚拟Camera所需的回调传给虚拟化服务侧。|

**Parameters**

|Name|Description|
|:----------------------|:-----------------------------------------------------|
|Context context|应用上下文信息。|
|CameraListener listener|开发者需要重写CameraListener中的方法，用于给虚拟化服务侧回调完成自身视频数据虚拟Camera。|

### onDeviceStatusChange

|Method|
|:-----------------------------------------------------------------------------------------------------------|
|public void onDeviceStatusChange(String deviceId, int state) HwDmsdpService封装出来的方法，开发者App发生异常等情况可通知设备虚拟化服务侧。|

**Parameters**

|Name|Description|
|:--------------|:-------------------------------------------|
|String deviceId|状态变化的设备ID。|
|int state|改变后的状态。目前仅支持：DEVICE_DISCONNECT：200，代表设备异常断开。|

### onDevicesParamChange

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------|
|public void onDevicesParamChange(String cameraId, String deviceId, int paramType) HwDmsdpService封装出来的方法，开发者App虚拟Camera参数发生变化时通知设备虚拟化服务侧。|

**Parameters**

|Name|Description|
|:--------------|:----------------------------------------------|
|String cameraId|参数改变的虚拟Camera ID。|
|String deviceId|虚拟Camera所属的设备ID。|
|int paramType|改变的参数类型，目前仅支持： * 100：VIDEO_SIZE_CHANGE，代表分辨率改变。|

### release

|Method|
|:-----------------------------------------------|
|public static void release() HwDmsdpService资源释放。|
