# IEventListener

|Interface Info|
|:----------------------------------------------------------|
|public interface IEventListener 事件接口。主要包含连接请求及连接状态变化等消息的传递。|

## Public Method Summary

|Qualifier and Type|Method Name and Description|
|:-----------------|:-------------------------------------------------------------------------------------------|
|abstract boolean|[onEvent](#section35115713565)(Event event) 上报连接状态。|
|abstract boolean|[onDisplayEvent](#section2047318302530)(int eventId, DisplayInfo displayInfo) 上报界面显示相关事件和信息。|

## Public Methods

### onEvent(Event event)

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
|public abstract boolean onEvent ([Event](https://developer.huawei.com/consumer/cn/doc/development/connectivity-References/event-0000001051449060) event) 上报连接状态。|

**Parameters**

|Name|Description|
|:----|:----------|
|event|事件类对象。|

**Return**

|Type|Description|
|:------|:-------------------------|
|boolean|* True：事件已处理 * False：事件未处理|

### onDisplayEvent(int eventId,DisplayInfo displayInfo)

|Method|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

|boolean|* True：事件已处理 * False：事件未处理|
