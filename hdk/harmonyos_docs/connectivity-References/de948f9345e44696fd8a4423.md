# Intent.ACTION_SEND_MULTIPLE

|Action info|
|:------------------|
|使用该Action进行多个文件的分享。|

## Type

|Value|Description|
|:----|:----------|
|*|通配|

## Package

|Value|Description|
|:--------------------------------|:----------|
|"com.huawei.android.instantshare"|显式启动分享页面包名|

## ParcelableArrayListExtra

|Type|Name|Description|
|:-------------|:------------------|:----------|
|ArrayList<Uri>|Intent.EXTRA_STREAM|分享文件Uri列表|

## Flags

|Value|Description|
|:------------------------------------|:----------|
|Intent.FLAG_ACTIVITY_NEW_TASK|页面在新栈启动|
|Intent.FLAG_GRANT_READ_URI_PERMISSION|分享文件时传递权限|
