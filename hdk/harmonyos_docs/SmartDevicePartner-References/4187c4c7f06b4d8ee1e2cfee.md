# 获取当前模式

## 适用平台

Android、iOS，平台差异如下：

* Android平台：入参不需要resultCallback回调，本节以Android平台为例进行介绍。
* iOS平台：入参需要resultCallback回调，调用方式如下：

  ```screen
  hilink.getDarkMode(String resultCallback);
  ```

## 请求消息

用于获取当前模式，WEB中调用js方法如下：

```screen
hilink.getDarkMode();
```

## 响应消息

该接口将直接返回：

* 1：正常模式
* 2：dark模式
