# 存储设备测量数据

## 适用平台

Android

## 接口描述

hilink.saveHealthData(Data, CallbackName)

将设备测量数据存储到运动健康云。当前支持JS将体温、血氧、体重、血糖数据存储。

## 请求参数

|参数|类型|描述|
|:-----------|:-----|:-------------------------------------|
|Data|String|data参数是一个json字符串，是设备测量的结果，格式详见数据举例和附件。|
|CallbackName|String|运动健康返回存储结果的回调函数，该回调函数有一个参数，详情参看返回参数。|

数据举例：

比如体温测量结果为36.5，则构造以下json字符串传递给参数data。

```screen
{
    "type"：2104"value": {
        "temp": 36.5,
        "unit": ""
    }
}
```

比如血氧饱和度测量结果为98%，则构造以下json字符串传递给参数data。

```screen
{
    "type"：2103"value": {
        "SpO2": 98,
        "unit": ""
    }
}
```

## 返回参数

|参数|类型|描述|
|:---------|:-----|:---------------------------------|
|resultCode|Number|0，表示存储成功。0以外表示存储失败，具体错误信息与运动健康团队确认|
