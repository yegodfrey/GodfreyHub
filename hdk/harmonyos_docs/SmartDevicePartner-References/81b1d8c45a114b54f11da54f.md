# 设置标题名称是否可见

## 适用平台

Android、iOS

## 接口描述

hilink.setTitleNameVisible (isVisible)

设置设备原生页面标题名称是否可见。

## 请求参数

|参数|类型|描述|
|:--------|:------|:--------------------------------|
|isVisible|boolean|true：标题栏中标题可见。 false：标题栏中标题可见不可见。|
