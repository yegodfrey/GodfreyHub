# 附录：运动健康数据格式

## 血糖数据格式

BloodSugar (type: 10001)

|字段Key|数据类型|描述|
|:--------------|:-----|:-------------------------------------|
|beforeBreakfast|double|早餐前血糖，取值范围1.0~100.0，建议保留一位小数，单位mmol/L。|
|afterBreakfast|double|早餐后血糖，取值范围1.0~100.0，建议保留一位小数，单位mmol/L。|
|beforeLunch|double|午餐前血糖，取值范围1.0~100.0，建议保留一位小数，单位mmol/L。|
|afterLunch|double|午餐后血糖，取值范围1.0~100.0，建议保留一位小数，单位mmol/L。|
|beforeDinner|double|晚餐前血糖，取值范围1.0~100.0，建议保留一位小数，单位mmol/L。|
|afterDinner|double|晚餐后血糖，取值范围1.0~100.0，建议保留一位小数，单位mmol/L。|
|beforeBedtime|double|睡前血糖 ，取值范围1.0~100.0，建议保留一位小数，单位mmol/L|
|earlyMorning|double|凌晨血糖，取值范围1.0~100.0，建议保留一位小数，单位mmol/L。|

## 体重数据格式

Weight (type: 10006)

|字段Key|数据类型|描述|
|:-----------------|:-----|:--------|
|weight|double|体重 千克|
|bmi|double|BMI千克/平方米|
|muscleMass|double|肌肉量 千克|
|basalMetabolism|double|基础代谢 千卡/日|
|moisture|double|水分 升/千克|
|visceralFatLevel|double|内脏脂肪等级|
|boneSalt|double|骨盐量 千克|
|proteinRate|double|蛋白质 千克|
|bodyScore|double|身体得分|
|bodyAge|double|身体年龄|
|bodyFatRate|double|体脂率|
|impedance|double|体脂称阻抗 欧姆|
|moistureRate|double|水分率|
|skeletalMuscleMass|double|骨骼肌 千克|
