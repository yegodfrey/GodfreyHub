# 跳转商城页面

## 适用平台

Android、iOS

## 请求消息

当需要在页面中跳转商城时，WEB中调用js方法如下：

```screen
hilink.gotoVmall(
"suffix", // string, 跳转到商城某个产品页面的后缀
);
```

## 响应消息

该接口无回应
