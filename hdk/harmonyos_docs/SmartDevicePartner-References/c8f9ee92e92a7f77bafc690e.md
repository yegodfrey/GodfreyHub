# 修改标题样式

## 适用平台

Android、iOS

## 请求消息

当需要在页面中修改标题样式时，WEB中调用js方法如下：

```screen
hilink.changeTitleStyle(
"styleValue" // int，标题样式值，当前仅支持2（即Emui 10.0风格）。后续可扩展。
);
```

## 响应消息

该接口无回应。
