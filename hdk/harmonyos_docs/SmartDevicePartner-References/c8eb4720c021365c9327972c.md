# 获取JSAPI版本号

## 适用平台

Android、iOS，平台差异如下：

* Android平台：入参不需要resultCallback回调，本节以Android平台为例进行介绍。
* iOS平台：入参需要resultCallback回调，调用方式如下：

  ```screen
  hilink.getApiLevel(String resultCallback)
  ```

## 接口描述

hilink.getApiLevel()

获取智能家居蓝牙设备H5使用的JSAPI的版本号。对于早期版本，调用该接口会抛出异常，此时需捕获异常。

## 返回参数

|参数|类型|描述|
|:-------|:-----|:---------------|
|apiLevel|Number|取值>=1。异常情况下返回-1。|
