# 获取设备数据统计（标量）

## 适用平台

Android、iOS

## 请求消息

当获取设备统计数据（标量）时，WEB中调用js方法如下：

```screen
hilink.getDevScalarData(
"{devid}", // devid,string，需要查询的设备的devid
"serviceId", // string, 需要查询的服务id
"characteristicName", // string, 需要查询的服务id下的属性名
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

```screen
// web页面中需实现该函数，用来获取执行结果
function resultCallback(resultStr){
var result = resultStr; // REST请求的返回结果
}
```

## 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将对应的结果返回到resultStr中。

resultStr的结构如下：

```screen
{
    "regTime": "xxxxxx",
    "beginTime": "xxxxx",
    "total": "xxxxxx",
    "extent": "xxxxx"
}
```

参数说明：

```screen
regTime 必选 String  设备第一次注册时间
beginTime 必选 String   sid第一次上报时间on
total 必选 String   使用总时长(如果是灯，单位为分钟)
extent 必选 String  扩展信息
```

## 错误码

```screen
{
  "errcode": 11
}
```

错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077308408)。
