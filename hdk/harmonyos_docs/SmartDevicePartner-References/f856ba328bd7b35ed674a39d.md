# 删除自动规则

## 适用平台

Android、iOS

## 请求消息

当需要删除自动规则时，WEB中调用js方法如下：

```screen
hilink.deleteRules(
"json_body", // body,string, 需要删除的规则的ruleId数组的json字符串
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
// web页面中需实现该函数，用来获取执行结果
function resultCallback  (resultStr) {
var result = resultStr; // REST请求的返回结果
}
```

## 响应消息

如果调用成功，但有删除失败的规则，返回删除失败规则的ruleId数组的json字符串。如果都删成功，则返回为空[]

```screen
{
  "删除失败的规则ID",
  "删除失败的规则ID"
}
```

## 错误码

```screen
{
  "errcode": 11
}
```

错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077308408)。
