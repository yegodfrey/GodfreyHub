# 跳转到对应的页面

## 适用平台

Android、iOS

## 接口描述

hilink.jumpTo (String uri, String resultCallback)

根据对应的URI，跳转到对应的界面，如跳转到设置界面。

uri固定传入值为：com.huawei.smarthome.deviceSettingActivity

## 请求参数

|参数|类型|描述|
|:-------------|:-----|:-------|
|uri|String|传入对应的字符串|
|resultCallback|String|回调函数的方法名|
