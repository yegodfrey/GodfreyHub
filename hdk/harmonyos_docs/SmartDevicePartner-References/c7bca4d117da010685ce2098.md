# 检查是否有新的固件

## 适用平台

Android、iOS

## 接口描述

hilink.checkBleHota(String deviceId, String versionNum, final String callback)

获取设备的最新固件信息。

如果有新的固件版本则返回新的固件信息，否则返回空。

## 请求参数

|参数|类型|描述|
|:---------|:-----|:--------|
|deviceId|String|蓝牙设备Id|
|versionNum|String|设备当前固件版本号|
|callback|String|回调函数的方法名|

## 返回参数

|参数|类型|描述|
|:----------|:-----|:-------|
|description|String|固件更新内容描述|
|version|String|固件版本号|
|url|String|固件下载地址|
