# 设置连接请求的优先级

## 适用平台

Android、iOS，平台差异如下：

* Android平台：支持设置蓝牙速率。
* iOS平台：不支持设置蓝牙速率，默认蓝牙速率为0。

## 接口描述

hilink.requestConnectionPriority (int connectionPriority)

设置连接请求的优先级。

## 请求参数

|参数|类型|描述|
|:-----------------|:--|:--------------------------------------------------------------------------------------------|
|connectionPriority|int|取值范围为：0、1、2。 0：Bluetooth传输的默认值。 1：请求高优先级，低延迟连接，以便快速传输大量数据。传输完成请再次设置为0，降低功耗。 2：请求低功耗，降低数据传输速率。|

## 返回参数

|参数|类型|描述|
|:------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|errCode|Number|错误码：0, 90001 错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077437634)。|
