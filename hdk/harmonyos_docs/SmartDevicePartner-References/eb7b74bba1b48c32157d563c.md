# 建立蓝牙连接

## 适用平台

Android、iOS

## 接口描述

hilink.createBLEConnection (deviceId)

连接低功耗蓝牙设备。
> 说明
>
> * 若在之前已有搜索过某个蓝牙设备，并成功建立链接，可直接传入之前搜索获取的deviceId直接尝试连接该设备，无需进行搜索操作。
> * 连接成功后，会清除所有蓝牙数据类监听。

## 请求参数

|参数|类型|描述|
|:-------|:-----|:-----|
|deviceId|String|蓝牙设备Id|

## 返回参数

|参数|类型|描述|
|:------|:-----|:------------------|
|retCode|Number|错误码：0, 90001, 90009|
