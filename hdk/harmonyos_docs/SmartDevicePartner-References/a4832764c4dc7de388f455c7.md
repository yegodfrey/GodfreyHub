# 同步系统信息

## 适用平台

Android、iOS

## 接口描述

hilink.getSystemInfoSync (CallbackName)

同步系统信息。

## 返回参数

|参数|类型|描述|
|:--------------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|brand|String|手机品牌|
|model|String|手机型号|
|pixelRatio|String|设备像素比|
|screenWidth|Number|屏幕宽度|
|screenHeight|Number|屏幕高度|
|version|String|APP版本号|
|system|String|操作系统版本|
|platform|String|客户端平台(android, iOS)|
|fontSizeSetting|String|用户字体大小设置。单位：px|
|errCode|Number|错误码：0, 90001 错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077437634)。|
