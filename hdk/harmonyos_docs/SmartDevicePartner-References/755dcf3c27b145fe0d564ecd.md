# 删除设备历史记录

## 适用平台

Android、iOS

## 请求消息

当需要删除Device历史记录时，WEB中调用js方法如下：

```screen
hilink.deleteDeviceHistory(
"{devid}", // devid,string,设备deviceId
"serviceId", // sid,string, 为该设备的service id，取值参见Profile定义
"cursor", // cursor,string, 查询的游标，缺省时为null
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

## 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将结果返回到resultStr中。

resultStr的结构如下：

```screen
{
    "hasMore": true, // true说明已经分页，需要根据cursor查询查询下一页，APP需要携带cursor继续发送删除请求，删除剩余历史记录，直到hasMore返回false。
    "cursor":"317b226c6173745265636f72644b657956616c756" //查询的游标
}
```

## 错误码

```screen
{
  "errcode": 11
}
```

错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077308408)。
