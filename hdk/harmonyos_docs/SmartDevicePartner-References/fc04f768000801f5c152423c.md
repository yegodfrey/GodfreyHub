# 跳转到华为商城

## 适用平台

Android、iOS

## 接口描述

hilink.gotoVmall (int suffix)

跳转到华为商城。

## 请求参数

|参数|类型|描述|
|:-----|:-----|:------------------------------------------------------------------------------------------------------------------------------|
|suffix|String|跳转到华为商城某个产品页面的后缀。 例如"https://www.vmall.com/product/10086769875080.html"为华为手环网址，则要跳转到手环页面，suffix填"/product/10086769875080.html"。|
