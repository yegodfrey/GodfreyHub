# 获取系统语言

## 适用平台

Android

## 接口描述

hilink.getAppLanguageSync()

获取系统的语言和地区，如：zh-CN。

## 返回参数

"zh-CN"代表中文，"en-UK"代表英文，具体请查询国家语言代码表。
