# 发现蓝牙服务

## 适用平台

Android、iOS

## 接口描述

hilink.onBLEServicesDiscovered(CallbackName)

蓝牙设备建立连接后，开始发现设备支持的服务，当服务发现完成，调用本接口通知上层。
> 说明
>
> 该方法可多次注册不同名称回调函数，已注册的全部回调函数，会在hilink.closeBLEConnection调用前生效。hilink.closeBLEConnection后，会清除回调注册。

## 返回参数

|参数|类型|描述|
|:------|:-----|:------------|
|errCode|Number|0，表示发现了BLE服务。|
