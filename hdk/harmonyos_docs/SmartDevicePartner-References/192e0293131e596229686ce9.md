# 更新设备基本信息

## 适用平台

Android、iOS

## 接口描述

hilink.updateDeviceBaseInfo (deviceId,json_body,callback)

更新设备基本信息。

## 请求参数

|参数|类型|描述|
|:--------|:-----|:------------|
|deviceId|String|华为云分配给设备的唯一id|
|Json_body|String|Json字符串，结构看下图|
|callback|String|回调函数的方法名|

Json_body结构：

|字段|必选/可选|类型|描述|
|:-------|:----|:-----------------|:-------------------------------------|
|devInfo|可选|DeviceInfo|设备的基本信息，devInfo或devInfo中参数如果不携带即不修改。|
|services|可选|List<service_info>|设备定义的Profile数据，不携带services则不修改，携带空则置空。|

Json_body具体样式：

```screen
{
    "devInfo": {
        "udid": "string",
        "sn": "string",
        "model": "string",
        "devType": "string",
        "deviceName": "string",
        "manu": "string",
        "prodId": "string",
        "hiv": "string",
        "mac": "string",
        "fwv": "string",
        "hwv": "string",
        "swv": "string",
        "protType": 1
    },
    "services": [
        {
            "st": "string",
            "sid": "string"
        }
    ]
}
```

## 返回参数

|参数|类型|描述|
|:------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|errCode|Number|错误码：0, 90001 错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077437634)。|
