# 获取数据统计

## 适用平台

Android、iOS

## 请求消息

当获取设备统计数据时，WEB中调用js方法如下：

```screen
hilink.getDevStatisticsDataWithQuery(
"{devid}", // devid,string，需要查询的设备的devid
"json_body", // body,string, 请求所需参数的json字符串
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

其中json填入参数：

```screen
devId 必选 String 1-40 设备Id的唯一标识
sid 必选 String 1-64 设备的serviceId
character 必选 String 1-64 设备sid下面的属性名称
startTime 必选 long  查询统计的开始时间戳，精确到秒
endTime 必选 long  查询统计的结束时间，精确到秒
accuracy 必选 String(枚举值)  目前只支持HOUR，DAILY
最大支持查询2年
cursor 可选 String 512 查询游标，缺省值为null
pageSize 可选 int  分页大小，取值范围为1~100，缺省值为100
timeZone 可选 String 16 时区信息
// web页面中需实现该函数，用来获取执行结果
function resultCallback(resultStr){
var result = resultStr; // REST请求的返回结果
}
```

## 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将对应的结果返回到resultStr中。

resultStr的结构如下：

```screen
{
    "devDatas": [
        {
            "time": "xxxxxx",
            "max": "xxxxx",
            "min": "xxxxxx",
            "avg": "xxxxx",
            "sum": "xxxxx",
            "accuracy": "xxxxx",
            "count": "xxxxx"
        }
    ],
    "cursor": "xxx",
    "hasMore": true
}
```

参数说明：

```screen
time 必选 String  小时粒度，则返回值为yyyyMMddhh
天为粒度，则返回值为yyyyMMdd
max 必选 String 1-10 该统计周期内最大值
min 必选 String 1-64 该统计周期内最小值
avg 必选 String  该统计周期内平均值(精度到小数点后两位)
sum 可选 String  该统计周期内求和(每个SID单独求和，不需要时传0)
count 必选 int  该统计周期内上报的数据的次数
accuracy 必选 String(枚举值)  目前只支持HOUR，DAILY
最大支持查询2年
cursor 必选 String 512 下一页查询游标，无下一页则值为null
hasMore 必选 boolean  是否有剩余记录
```

{
