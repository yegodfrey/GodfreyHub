# 获取已注册设备

## 适用平台

Android、iOS

## 接口描述

hilink.getCurrentRegisteredDevice(CallbackName)

获取宫格页面中选择的已注册的设备。此接口用户完成设备注册后，从宫格拉起设备H5后，H5页面中调用。如果errCode不为0，则hilinkDevId，deviceId，deviceName无效。

## 返回参数

|参数|类型|描述|
|:-----------------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|hilinkDevId|String|云端分配的设备唯一标示（设备id）。|
|deviceId|String|用于区分设备的 id，是用户选中的蓝牙设备的MAC地址或序列号SN（即注册接口下发的sn）。|
|deviceName|String|设备名称。|
|errCode|Number|错误码：0, 90001, 90005。 错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077437634)。|
|role|String|用户角色：owner/family。|
|hilinkDeviceEntity|Object|设备信息。|
