# 断开蓝牙连接

## 适用平台

Android、iOS

## 接口描述

hilink.closeBLEConnection (deviceId)

断开与低功耗蓝牙设备的连接。

## 请求参数

|参数|类型|描述|
|:-------|:-----|:-----|
|deviceId|String|蓝牙设备Id|

## 返回参数

|参数|类型|描述|
|:------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|retCode|Number|错误码：0, 90001, 90010 错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077437634)。|
