# 设置页面横竖屏

## 适用平台

Android、iOS

## 接口描述

hilink.setRequestedOrientation(boolean isLandscape)

设置页面横竖屏。

## 请求参数

|参数|类型|描述|
|:----------|:------|:--------------------|
|isLandscape|boolean|是否横屏，true为横屏，false为竖屏|
