# API 概要

## 蓝牙适配器开关操作

三方可通过封装后的JS接口，获取蓝牙适配器的开关状态和设置蓝牙适配器的开关状态。

|接口|说明|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------|
|[openBluetoothAdapter](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/openbluetoothadapter-0000001058135267)|打开手机蓝牙适配器。|
|[closeBluetoothAdapter](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/closebluetoothadapter-0000001057566847)|关闭手机蓝牙适配器。|
|[getBluetoothAdapterState](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/getbluetoothadapterstate-0000001057686851)|获取手机蓝牙适配器状态。|

## 获取已绑定设备的标识

运动健康将测量过程的能力通过JS接口提供给三方，三方只能操作和运动健康App绑定过的设备。

|接口|说明|
|:---------------------------------------------------------------------------------------------------------------------------------|:-----------------------------|
|[getDeviceId](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/getdeviceid-0000001058135269)|获取绑定设备在开发者平台分配的UUID（资源包的UUID）。|

## 标准蓝牙BLE交互操作

三方可通过封装后的JS接口，与蓝牙设备创建连接，获取蓝牙设备的特征值变化等相关操作。三方根据自己定义的蓝牙协议时序，使用封装后的JS接口，进行数据通信，解析数据，获取测量结果。

|接口|说明|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------|
|[createBLEConnection](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/createbleconnection-0000001056726830)|通过指定的设备UUID与手机蓝牙适配器创建连接。|
|[closeBLEConnection](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/closebleconnection-0000001057695280)|通过指定的设备UUID断开与手机蓝牙适配器的连接。|
|[onBluetoothAdapterStateChange](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/onbluetoothadapterstatechange-0000001064337078)|监听手机蓝牙状态的变化。|
|[startBluetoothDevicesDiscovery](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/startbluetoothdevicesdiscovery-0000001064271118)|开始搜寻附近的蓝牙设备。|
|[stopBluetoothDevicesDiscovery](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/stopbluetoothdevicesdiscovery-0000001065039542)|停止搜寻附近的蓝牙设备。|
|[onBluetoothDeviceFound](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/onbluetoothdevicefound-0000001064879694)|订阅发现新的蓝牙设备的事件。|
|[requestConnectionPriority](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/requestconnectionpriority-0000001064042279)|设置蓝牙设备请求连接的优先级。|
|[readBLECharacteristicValue](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/readblecharacteristicvalue-0000001057789163)|读取低功耗蓝牙设备的特征值，以十六进制字符串返回。|
|[writeBLECharacteristicValue](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/writeblecharacteristicvalue-0000001057974880)|通过指定服务的ID写入指定数据。|
|[registerRequestMtu](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/registerrequestmtu-0000001064192901)|订阅设置手机与蓝牙设备传输Mtu值的方法。|
|[requestMtu](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/requestmtu-0000001063924689)|设置手机与设备传输的mtu值。|
|[notifyBLECharacteristicValueChange](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/notifyblecharacteristicvaluechange-0000001058254872)|设置低功耗蓝牙设备是否开启指定服务的特征值的模式，通过onBLECharacteristicValueChange返回设置结果。|
|[onBLEConnectionStateChange](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/onbleconnectionstatechange-0000001057217138)|设备主动上报低功耗蓝牙连接状态的变化。|
|[onBLECharacteristicValueChange](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/onblecharacteristicvaluechange-0000001057377116)|设备主动上报低功耗蓝牙设备的特征值变化。|
|[onBLEServicesDiscovered](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/onbleservicesdiscovered-0000001057417205)|蓝牙设备建立连接后，开始发现设备支持的服务，当服务被成功发现后，回调通知三方。|
|[setEnableIndication](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/setenableindication-0000001058017149)|设置低功耗蓝牙工作模式为启用指示模式或启用通知模式。|

## 数据查询及存储

三方通过BLE交互类API完成测量后，解析出测量结果；使用封装后的JS接口，按照约定的数据格式将测量结果存储到运动健康App。三方还可以查询历史测量结果以及用户的个人信息。

|接口|说明|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------|
|[getUserInfo](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/getuserinfo-0000001057566849)|获取当前用户的个人信息。|
|[getHealthData](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/gethealthdata-0000001057686853)|查询设备历史数据。当前支持查询体温、血氧、体重、血糖、血压数据。|
|[saveHealthData](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/savehealthdata-0000001056726832)|将设备测量数据存储到运动健康平台。当前支持将体温、血氧、体重、血糖、血压数据存储到运动健康。|
|[saveMultipleHealthData](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/savemultiplehealthdata-0000001057695282)|将多条设备测量数据存储到运动健康平台。当前支持将体温、血氧、血糖、体重、血压数据存储到运动健康。|
|[deleteMultipleHealthData](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/deletemultiplehealthdata-0000001072493244)|将多条设备测量数据从运动健康平台删除。当前支持JS删除血糖和跳绳数据。|
|[startScanCode](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/startscancode-0000001063282061)|启动扫码界面，通过扫描设备的SN码获取SN码信息。|
|[syncCloud](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/synccloud-0000001063800434)|将本地数据与云端同步。|
|[bindDevice](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/binddevice-0000001063642398)|将设备与数据中心和云端绑定。|
