# 设备文件获取

## 适用平台

Android、iOS

## 请求消息

当需要获取设备相关文件（如用户头像）时，WEB中调用js方法如下：

```screen
hilink.downloadObjectReq(
"json_body", // body,string, 请求所需参数的json字符串
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

其中json填入参数：

```screen
devId string 设备Id
objectName String 文件名
// web页面中需实现该函数，用来获取执行结果
function resultCallback(resultStr){
var result = resultStr; // REST请求的返回结果
}
```

## 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将文件的base64字符串返回到resultStr中。

resultStr的结构如下：

```screen
{
  "文件的base64字符串"
}
```

## 错误码

```screen
{
  "errcode": 11
}
```

错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077308408)。
