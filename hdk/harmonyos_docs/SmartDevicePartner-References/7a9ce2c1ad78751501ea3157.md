# 修改设备名称

## 适用平台

Android、iOS

## 请求消息

当进入设备设置界面需要修改设备名称时，WEB中调用js方法如下：

```screen
hilink.modifyDeviceName(
"deviceName", // deviceName,String,修改的设备名称字段
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

另有带deviceId的接口，可以修改其他设备的名称：

```screen
hilink.modifyDeviceNameByDevId(
"deviceId", // deviceId,String,修改的设备id
"deviceName", // deviceName,String,修改的设备名称字段
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

## 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将如下结果返回到resultStr中。

```screen
{
  "errcode": 0,
}
```

## 错误码

```screen
{
  "errcode": 11
}
```

错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077308408)。
