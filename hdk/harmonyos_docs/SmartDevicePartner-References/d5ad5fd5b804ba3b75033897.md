# 设备状态数据上报

## 适用平台

Android、iOS

## 请求消息

设备数据上报接口。

```screen
hilink.reportDeviceProfileImpermanency(
"{devid}", // devidstring,请取"0"，表示当前设备
"json_body", // body,string, 设备上报的数据
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

json的数据参数如下：

```screen
{
 "status": "offline",
 "services": [{
  "ts": "string",
  "sid": "string",
  "data": {
   "additionalProp1": "***",
   "additionalProp2": "***",
   "additionalProp3": "***"
  }
 }]
}
```

## 响应消息

```screen
{
  "errcode": 200
}
200： success
400： Bad Request
401： auth Failed
500： Internal Service Error
```
