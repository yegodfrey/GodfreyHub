# Mtu设置成功后的回调

## 适用平台

Android

## 接口描述

hilink.registerRequestMtu(String CallbackName)

设置蓝牙设备Mtu值，当设置成功时，调用本接口通知上层。
> 说明
>
> 该方法可多次注册不同名称回调函数，已注册的全部回调函数，会在hilink.closeBLEConnection调用前生效。hilink.closeBLEConnection后，会清除回调注册。

## 返回参数

|参数|类型|描述|
|:-----|:-----|:-------------------------|
|status|Number|0,成功；非0，失败|
|mtu|Number|默认为设置值，超过手机与设备传输的最大值则返回最大值|
