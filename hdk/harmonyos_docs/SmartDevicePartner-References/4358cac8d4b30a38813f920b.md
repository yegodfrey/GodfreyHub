# 扩展数据删除接口

## 适用平台

Android、iOS

## 请求消息

```screen
hilink.deleteDeviceExtendDataById(
"{devid}", // 设备的devid
"type", //string,扩展属性的类型，即云侧配置的权限
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

## 响应消息

```screen
{
  "errcode": 200
}
200： success
400： Bad Request
401： auth Failed
403： forbidden
500： Internal Service Error
```
