# 停止搜索蓝牙设备

## 适用平台

Android、iOS

## 接口描述

hilink.stopBluetoothDevicesDiscovery()

停止搜寻附近的蓝牙外围设备。

## 返回参数

|参数|类型|描述|
|:------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------|
|retCode|Number|错误码：0, 90001 错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077437634)。|
