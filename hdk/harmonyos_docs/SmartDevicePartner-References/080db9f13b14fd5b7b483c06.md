# 启用重写安卓物理返回键

## 适用平台

Android、iOS

## 请求消息

当重写安卓物理返回键时，WEB中调用js方法如下：

```screen
hilink.overrideBackPressed(
enable, // boolean, true启用，false不启用
resultCallback // string，成功或失败时，将调用传入resultStr返回结果
);
```

示例：

```screen
hilink.overrideBackPressed(
true,
"resultCallback"
);
```

回调函数示例：

```screen
//web页面中需实现该函数，用来获取执行结果
function resultCallback(resultStr){
var result = resultStr; // 请求的返回结果
}
```

当enable为true时，安卓物理返回键将重写为调用一个js方法goBack()。

```screen
// web页面中需实现该函数，用来实现自定义的返回
function goBack(){
// web实现自定义的返回
}
```

## 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将如下结果返回到resultStr中。

```screen
{
  "errcode": 0
}
```

## 错误码

```screen
{
  "errcode": 11
}
```

错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077308408)。
