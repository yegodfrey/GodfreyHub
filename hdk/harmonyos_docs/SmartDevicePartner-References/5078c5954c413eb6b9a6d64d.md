# 设置规则是否使能

## 适用平台

Android、iOS

## 接口描述

hilink.controlRuleActive(String ruleId, String active, String resultCallback)

设置单个规则的激活状态。

## 请求参数

|参数|类型|描述|
|:-------------|:-----|:---------------------|
|ruleId|String|规则的唯一标识符|
|active|String|active为激活，inactive为未激活|
|resultCallback|String|回调函数的方法名|
