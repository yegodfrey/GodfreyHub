# 获取设备事件通知

## 适用平台

Android、iOS

当需要处理设备产生的事件时，WEB中需要实现如下方法：

```screen
// web页面中需实现该函数，用来获取设备产生的事件
function deviceEventCallback(event) {
var result = event; // 事件详情
}
```

event格式如下：

```screen
{
        "devId":"{deviceId}",
        "gatewayId":"xxxxx",
        "services": [{
            "st": "air_conditioner",
            "ts": "20151212T121212Z",
            "sid": "1",
            "data": {
                "characteristicName1": "value1",
                "characteristicName2": "value2"
             }
         }
       ]
}
```
