# BI打点接口

## 适用平台

Android、iOS

## 请求消息

当需要在页面中进行BI打点时，WEB中调用js方法如下：

```screen
hilink.reportH5SingleDevBiInfo(
"biKey", // string, 打点事件key
"biH5Info", // string, 打点事件信息
);
```

## 响应消息

该接口无回应。
