# 重新设置连接的Mtu

## 适用平台

Android

## 接口描述

hilink.requestMtu(int mtu)

重新设置Mtu的大小。

## 请求参数

|参数|类型|描述|
|:--|:-----|:--------------|
|mtu|Number|设置手机与设备传输的mtu值。|
