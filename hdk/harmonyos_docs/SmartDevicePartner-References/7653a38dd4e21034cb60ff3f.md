# 打印敏感信息

## 适用平台

Android

## 接口描述

hilink.h5ConsoleLogPrint(String msgTag,String msgInfo)

打印敏感信息，用户信息级别的log。

## 请求参数

|参数|类型|描述|
|:------|:-----|:--------|
|msgTag|String|打印信息的信息头|
|msgInfo|String|打印信息的信息内容|
