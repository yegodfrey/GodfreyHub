# 获取设备历史健康数据

## 适用平台

Android

## 接口描述

hilink.getHealthData(Param, CallbackName)

获取设备历史健康数据。当前支持JS将体温、血氧、体重、血糖数据查询。

## 请求参数

|参数|类型|描述|
|:-----------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Param|String|* param：参数是一个json字符串。 * startTime：String，查询开始的UTC时间戳，精确到毫秒。 * endTime：String，查询结束的UTC时间戳，精确到毫秒。最大支持30天。 * type：Number，数据类型。枚举值。 * dataTypeName：String，固定值，对应Health Kit的数据类型。|
|CallbackName|String|Health Kit云端返回查询结果的回调函数。该回调函数有一个参数data，详情参见[返回参数](#section15372183711234)。|

请求示例：

```screen
{ 
    "startTime":  16034447680700000000, 
    "endTime":  16034447680700000000, 
    "type": 10006, 
    "dataTypeName": "com.huawei.instantaneous.body_weight",
}
```

## 返回参数

|参数|类型|描述|
|:---------|:-----|:------------------------------------------------------------------------------------------------------------------|
|resultCode|String|处理结果码： * 0：表示成功。返回其他值表示失败。 * 13：表示未授权绑定Health Kit。 * -14：表示设备数据参数校验失败。 * -15：表示Health Kit配置文件初始化失败。 * 400：表示其他通用错误。|
|data|String|存储到Health Kit云的历史数据集。|
