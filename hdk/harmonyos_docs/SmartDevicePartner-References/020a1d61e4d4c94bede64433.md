# 设置标题是否可见

## 适用平台

Android、iOS

## 接口描述

hilink.setTitleVisible (isVisible)

设置设备页面原生标题是否可见。

## 请求参数

|参数|类型|描述|
|:--------|:------|:----------------------------|
|isVisible|boolean|true：整个标题栏可见。 false：整个标题栏不可见。|
