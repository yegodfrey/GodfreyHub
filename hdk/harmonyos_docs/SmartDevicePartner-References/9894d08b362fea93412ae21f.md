# 显示标题栏中的图标

## 适用平台

Android、iOS

## 请求消息

当需要在标题栏中显示图标（最多显示两个）时，WEB中调用js方法如下：

```screen
hilink.showTitleBarIcons(
"json_body", // body,string，图标地址，见下描述
"buttonClick", // string，设置点击图标的回调方法
"isVisible", // boolean，标题栏上的名称控件是否可见
"resultCallback" // resultCallback，成功或失败时，将调用传入resultStr返回结果
);
```

json_body中需要的属性：

```screen
{
  "url": xxx, // 靠近设置按钮的图标的图片地址
  "url": xxx // 远离设置按钮的图标的图片地址
}
```

Body不能为空，否则将失败。

当点击图标时，将根据传入的buttonClick调用对应的js方法，并传入index参数表示点击的是哪一个图标。

```screen
//web页面中需实现该函数，用来实现自定义的返回
function buttonClick(index){
//web 实现点击事件，其中index为0表示点击靠近设置按钮的图标，1为远离设置按钮的图标
}
```

## 响应消息

当调用成功时，JSSDK将调用success对应的回调函数，将如下结果返回到resultStr中。

```screen
{
  "errcode": 0,
}
```

## 错误码

```screen
{
  "errcode": 11
}
```

错误码说明参见[错误码](https://developer.huawei.com/consumer/cn/doc/development/SmartDevicePartner-References/result-codes-0000001077308408)。
