# 距离

此数据记录用户在一小段时间内的距离值，每一条数据都代表该时间段（开始时间-结束时间）内的距离量。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。

## OAuth权限

联盟卡片申请的权限名称：日常活动 > 距离、爬高与海拔

* 读权限：https://www.huawei.com/healthkit/distance.read
* 写权限：https://www.huawei.com/healthkit/distance.write

## 原子采样明细数据类型

* 名称：com.huawei.continuous.distance.delta

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:-------------|:---|:-----|:----|:-|:----------------------------------------------|
|distance_delta|距离增量|float|M|米|1秒区间：(0, 100] 1分钟区间：(0, 6000] 1小时区间：(0, 360000]|

|开放API|查询及时性|数据源|

> 说明

> 华为智能穿戴设备与运动健康App产生的运动记录数据中不包含距离采样明细数据，仅包含距离统计数据。
