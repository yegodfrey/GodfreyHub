# Java SDK

华为分析服务目前已提供[导入自定义用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-import-customized-user-attributes-0000001050747215)和[上报用户行为](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-report-user-behavior-0000001205631635)的API接口，为减小API接口的工作量，现提供Java版本的SDK给开发者集成，用以快速的使用API接口能力。

#### 开发环境

[JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上

#### 操作步骤

      1. 集成SDK，引入jar包。
         1. 在maven工程的“settings.xml”文件中添加SDK所在的仓库地址。
                
                <mirror>
                         <id>central</id>
                         <mirrorOf>central</mirrorOf>
                         <url>https://developer.huawei.com/repo/</url>
                </mirror>

         2. 指定对应的“profile”属性，需要填写对应的“公共仓库地址”和“华为开发者联盟仓库地址”。

其中“公共仓库地址”为您存放公共组件的仓库地址，如官方maven仓库地址， “华为开发者联盟仓库地址”指定为 _https://developer.huawei.com/repo/_ 。
                
                <profiles> 
                    <profile>
                      <id>central</id>
                      <repositories>
                      <repository>
                       <id>_test1_ </id>
                           <url>_公共仓库地址_ </url>
                          <releases><enabled>true</enabled></releases>
                          <snapshots>
                            <enabled>true</enabled>
                            <updatePolicy>always</updatePolicy>
                          </snapshots>
                        </repository>  
                        <repository>
                           <id>_test2_ </id>
                                <url>_https://developer.huawei.com/repo/_ </url>
                          <releases><enabled>true</enabled></releases>
                          <snapshots>
                            <enabled>true</enabled>
                            <updatePolicy>always</updatePolicy>
                          </snapshots>
                        </repository> 
                      </repositories>
                </profile>
                </profiles>

         3. 启用“profile”属性。
                
                <activeProfiles>
                    <activeProfile>central</activeProfile>
                  </activeProfiles>

         4. 在您的项目工程的pom文件中引入对应的jar包。
                
                <dependencies>
                    <dependency>
                        <groupId>com.huawei.wisecloud</groupId>
                        <artifactId>analytics-java</artifactId>
                        <version>6.3.2.302</version>
                    </dependency>
                </dependencies>

      2. 初始化SDK。
         1. 登录[ _AppGallery Connect 网站_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“我的项目”。
         2. 在项目列表中找到您的项目，在项目列表中点击需要集成SDK的应用。
         3. 在“项目设置”页面中，获取App相关信息。

         5. (可选)设置您的上报策略配置，也可以选择使用默认配置SdkConfig.defaultConfig()。
                
                SdkConfig._init_().setMaxCacheSize(_10000_).setCacheTime(_10_).setMaxRetry(_2_).setEventSendSize(_100_).setUserSendSize(_100_).build();

参数 | 参数说明  
---|---  
setMaxCacheSize | 最大缓存数量，设置缓存中最大的数据量；当数量达到限制，会对最老的数据进行淘汰并记录到日志中。设置区间为1-1000000，默认存放10000条数据。  
setCacheTime | 缓存上报的间隔时间，单位为s。设置区间为1-1800s，默认为10s上报一次数据。  
setMaxRetry | 上报重试次数，当上报失败时，会进行重试处理；当达到配置的最大上报次数还是失败时，则会记录日志处理。默认重试2次。  
setEventSendSize | 单次“上报用户行为”的发送数量。设置区间为1-100，默认100，表示单次上报的用户行为数据为100条。  
setUserSendSize | 单次“导入自定义用户属性”的发送数量。设置区间为1-100，默认100，表示单次上报的自定义用户属性为100条。  
  
         6. 初始化SDK。
                
                @Component
                 @Slf4j
                 public class AnalyticsSdkInit {
                     private HuaweiAnalyticsClient huaweiAnalyticsClient;
                     //初始化sdk
                     @PostConstruct
                     public void init() {
                         HuaweiApp huaweiApp = HuaweiApp._init_(_"Android"_ , "_http://123_ ")
                             .setAppId("_123_ ")
                             .setProductId("_123_ ")
                             .setClientId("_123_ ")
                             .setClientSecret("_123_ ")
                             .setPackageName("_123.123_ ")
                             .build();
                         SdkConfig sdkConfig = SdkConfig._init_().setCacheTime(_10_).setMaxCacheSize(_10000_).build(); 
                         HuaweiAnalyticsClient._init_(Collections._singletonList_(huaweiApp), sdkConfig);
                        // 异常结束刷新数据
                        flushData();
                      }  
                 
                    private void flushData() {
                        Runtime.getRuntime().addShutdownHook(new Thread(new Runnable() {
                            @Override
                            public void run() {
                                HuaweiAnalyticsClient.flush();
                            }
                        }));
                    }
                  }

#### 其他配置

Java SDK定义了日志打印的接口AnalyticsLog，如您需要打印Java SDK的日志，请在您的代码中实现AnalyticsLog接口的logData方法，然后在初始化SDK时调用initLogger方法设置自定义的logger。
    
    public static void initLogger(AnalyticsLog logger) {
        }

#### 使用示例

      * 上报用户行为
            
            EventPojo eventPojo = new EventPojo(); 
              eventPojo.setAaid("123"); 
              eventPojo.setUserId(""); 
              eventPojo.setEventTime(1631606679895L); 
              eventPojo.setEventId("$EnterScreen"); 
              eventPojo.setEventSessionName("123"); 
              eventPojo.setFirstSessionEvent("true"); 
              eventPojo.setProperties(""); 
              HuaweiAnalyticsClient.addEvent("123", eventPojo);

      * 导入自定义用户属性
            
            UserDataPojo userDataPojo = new UserDataPojo(); 
              userDataPojo.setId("123"); 
              UserPropertyPojo userPropertyPojo = new UserPropertyPojo(); 
              userPropertyPojo.setId("123"); 
              userPropertyPojo.setValue("123"); 
              userDataPojo.setProperties(Collections._singletonList_(userPropertyPojo)); 
              HuaweiAnalyticsClient.addUser("123", userDataPojo);
