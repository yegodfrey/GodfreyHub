# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_HMSInAppPurchase)快速体验一个应用的开发过程。

## 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上版本
* 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上版本
  * minSdkVersion 19及以上
  * targetSdkVersion 34（推荐）
  * compileSdkVersion 34（推荐）
  * Gradle 5.4.1及以上（推荐）

  如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。
* 测试应用的设备：EMUI 3.0及以上的华为手机或Android 4.4及以上的非华为手机

## 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072)|在开发应用前，需要在AppGallery Connect中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section1464519554325)、[开通商户服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section162559711112)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section15850522183317)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section859813591012)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section19713716202718)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section382112213818)、[配置支付服务参数](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section15820113193119)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/integrating-sdk-0000001050035023)|在开发应用前，您需要将IAP SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-obfuscation-scripts-0000001050260710)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[（可选）配置商品信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-product-0000001050033076)|若您的应用提供[PMS](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-0000001050033062#ZH-CN_TOPIC_0000001050033062__section1229343610526)商品，则需要在AppGallery Connect中完成商品配置，在您的客户端调用购买接口时，只需传入此处配置的商品ID和商品类型。|
|5|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/purchase-subscription-process-0000001050130250)|IAP支持的商品类型包括：消耗型商品、非消耗型商品、订阅型商品。 [开发商品购买](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/dev-guide-0000001050130254)提供了3种商品购买的接入流程。若您的应用提供消耗型商品，则需额外在您的应用中添加[消耗型商品的补单流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/redelivering-consumables-0000001051356573)，订阅相关的说明可参见[订阅专用功能说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/subscription-functions-0000001050130264)。 开发者根据业务需求，完成相应功能开发。|
|6|[（可选）服务端开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/order-verify-purchase-token-0000001050033078)|当您需要与IAP服务器进行业务调用（如Order服务需调用IAP服务器提供的验证购买Token接口），或仅仅依靠您的客户端无法处理更加复杂的业务逻辑时，可开发服务端以满足业务需求。|
|7|[开发后自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001076257572)|华为提供对应用自动检查的能力。|
|8|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001050415459)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/iap-integration-0000001104001920)了解HMS Toolkit集成该Kit最佳实践。
