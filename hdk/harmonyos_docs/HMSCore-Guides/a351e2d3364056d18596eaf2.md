# 标记

用户可以在地图的指定位置添加标记以标识位置、商家、建筑等，并可以通过信息窗口展示详细信息。

## 添加标记

使用默认图标在地图上添加一个简单的标记。

示例代码如下：

```screen
"Java"
private Marker mMarker;

public void addMarker(View view) {
    if (null != mMarker) {
        mMarker.remove();
    }
    MarkerOptions options = new MarkerOptions()
            .position(new LatLng(48.893478, 2.334595))
            .title("Hello Huawei Map")
            .snippet("This is a snippet!");
    mMarker = hMap.addMarker(options);
}
```

```screen
"Kotlin"
private var mMarker: Marker? = null

fun addMarker(view: View?) {
    if (null != mMarker) {
        mMarker?.remove()
    }
    val options = MarkerOptions()
            .position(LatLng(48.893478, 2.334595))
            .title("Hello Huawei Map")
            .snippet("This is a snippet!")
    mMarker = hMap.addMarker(options)
}
```

## 自定义标记图像

您可以使用自定义图像（通常称为图标）修改默认标记图标，通过调用[BitmapDescriptorFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptorfactory-0000001050152411)类中的静态方法生成[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptor-0000001050152403)对象（图片描述文件）。

|方法|功能|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------|
|[fromAsset](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptorfactory-0000001050152411#section177751156105216)(String assetName)|使用assets目录中的Bitmap图像创建自定义标记图标。|
|[fromBitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptorfactory-0000001050152411#section375416351533)(Bitmap image)|通过位图图像创建自定义标记图标。|
|[fromFile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptorfactory-0000001050152411#section338617415546)(String fileName)|使用位于内部存储中的位图文件创建自定义标记图标。|
|[fromPath](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptorfactory-0000001050152411#section1762285545410)(String absolutePath)|通过位图的绝对文件路径创建自定义标记图标。|
|[fromResource](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bitmapdescriptorfactory-0000001050152411#section11216192714558)(int resourceId)|使用位图图像的资源创建自定义标记图标。|

创建一个带有自定义图标的标记。

示例代码如下：

```screen
"Java"
private Marker mMarker;

mMarker = hMap.addMarker(new MarkerOptions()
        .position(new LatLng(48.893478, 2.334595))
        .icon(BitmapDescriptorFactory.fromResource(R.drawable.badge_ph)));
```

```screen
"Kotlin"
private var mMarker: Marker? = null

mMarker = hMap.addMarker(MarkerOptions()
        .position(LatLng(48.893478, 2.334595))
        .icon(BitmapDescriptorFactory.fromResource(R.drawable.badge_ph)))
```

## 聚合标记

地图SDK支持聚合标记功能，该功能可以有效地管理在地图不同缩放级别情况下的多个标记，使用该功能需要标记数量大于等于5个，在小于5个时不支持聚合标记。当以高缩放级别查看地图时，各个标记会显示在地图上（[图1](#ZH-CN_TOPIC_0000001061779995__fig18657810717)）；以较低级别查看地图时，标记会聚集成集群，从而使标记的呈现更有序（[图2](#ZH-CN_TOPIC_0000001061779995__fig9162131914612)）。

可以参见以下示例代码实现标记聚合功能：

示例代码如下：

```java
"Java"
@Override
public void onMapReady(HuaweiMap map) {
    hMap = map;
    hMap.moveCamera(CameraUpdateFactory.newLatLngZoom(
    new LatLng(48.893478, 2.334595),10));
    // 将该Marker加入集群
    hMap.addMarker(new MarkerOptions().position(new LatLng(48.891478, 2.334595)).title("Marker1").clusterable(true));
    hMap.addMarker(new MarkerOptions().position(new LatLng(48.892478, 2.334595)).title("Marker2").clusterable(true));
    hMap.addMarker(new MarkerOptions().position(new LatLng(48.893478, 2.334595)).title("Marker3").clusterable(true));
    hMap.addMarker(new MarkerOptions().position(new LatLng(48.894478, 2.334595)).title("Marker4").clusterable(true));
    hMap.addMarker(new MarkerOptions().position(new LatLng(48.895478, 2.334595)).title("Marker5").clusterable(true));
    hMap.addMarker(new MarkerOptions().position(new LatLng(48.896478, 2.334595)).title("Marker6").clusterable(true));
    // 设置Marker可聚合
    hMap.setMarkersClustering(true);
}
```

```java
"Kotlin"
override fun onMapReady(map: HuaweiMap) {
    hMap = map
    hMap.moveCamera(CameraUpdateFactory.newLatLngZoom(
            LatLng(48.893478, 2.334595), 10f))
    // 将该Marker加入集群
    hMap.addMarker(MarkerOptions().position(LatLng(48.891478, 2.334595)).title("Marker1").clusterable(true))
    hMap.addMarker(MarkerOptions().position(LatLng(48.892478, 2.334595)).title("Marker2").clusterable(true))
    hMap.addMarker(MarkerOptions().position(LatLng(48.893478, 2.334595)).title("Marker3").clusterable(true))
    hMap.addMarker(MarkerOptions().position(LatLng(48.894478, 2.334595)).title("Marker4").clusterable(true))
    hMap.addMarker(MarkerOptions().position(LatLng(48.895478, 2.334595)).title("Marker5").clusterable(true))
    hMap.addMarker(MarkerOptions().position(LatLng(48.896478, 2.334595)).title("Marker6").clusterable(true))
    // 设置Marker可聚合
    hMap.setMarkersClustering(true)
}
```

## 标记事件

### 标记点击事件

可以使用[HuaweiMap.OnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerclicklistener-0000001050152047)来侦听标记上的点击事件。要在地图上设置此侦听器，请调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[setOnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section6157172618712)([HuaweiMap.OnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerclicklistener-0000001050152047))方法。当用户点击标记时，[onMarkerClick](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerclicklistener-0000001050152047#section165540817477)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))将调用该标记并将标记作为参数传递。标记点击事件的默认行为是显示其信息窗口（如果可用），使标记在地图上居中。

示例代码如下：

```screen
"Java"
hMap.setOnMarkerClickListener(new HuaweiMap.OnMarkerClickListener() {
    @Override
    public boolean onMarkerClick(Marker marker) {
        Toast.makeText(getApplicationContext(), "onMarkerClick：" + marker.getTitle(), Toast.LENGTH_SHORT).show();
        return false;
    }
});
```

```screen
"Kotlin"
hMap.setOnMarkerClickListener { marker ->
    Toast.makeText(applicationContext, "onMarkerClick：${marker.title}", Toast.LENGTH_SHORT).show()
    false
}
```

### 标记拖动事件

可以使用[HuaweiMap.OnMarkerDragListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerdraglistener-0000001050150108)来侦听标记上的拖动事件，前提是该[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858)标记已设置拖拽属性为true。要在地图上设置此侦听器，请调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[setOnMarkerDragListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section183907434711)([HuaweiMap.OnMarkerDragListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerdraglistener-0000001050150108))方法。要拖动标记，用户必须长按标记。当用户将手指从屏幕上移开时，标记将保持在该位置。拖动标记时，先调用[onMarkerDragStart](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerdraglistener-0000001050150108#section15750115717498)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))，标记拖动过程中，不断调用[onMarkerDrag](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerdraglistener-0000001050150108#section41919381488)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))。拖动结束时，调用[onMarkerDragEnd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmarkerdraglistener-0000001050150108#section17191517124913)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))。您可以随时通过调用[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858)的[getPosition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section49343761418)()接口获取标记的位置。

示例代码如下：

```java
"Java"
// 设置标记可拖拽
mMarker.setDraggable(true);

hMap.setOnMarkerDragListener(new HuaweiMap.OnMarkerDragListener() {
    @Override
    public void onMarkerDragStart(Marker marker) {
        Log.i(TAG, "onMarkerDragStart: ");
    }
	
    @Override
    public void onMarkerDrag(Marker marker) {
        Log.i(TAG, "onMarkerDrag: ");
    }
	
    @Override
    public void onMarkerDragEnd(Marker marker) {
        Log.i(TAG, "onMarkerDragEnd: ");
    }
});
```

```java
"Kotlin"
// 设置标记可拖拽
mMarker?.isDraggable = true

hMap.setOnMarkerDragListener(object : OnMarkerDragListener {
    override fun onMarkerDragStart(marker: Marker) {
        Log.i(TAG, "onMarkerDragStart: ")
    }
    override fun onMarkerDrag(marker: Marker) {
        Log.i(TAG, "onMarkerDrag: ")
    }
    override fun onMarkerDragEnd(marker: Marker) {
        Log.i(TAG, "onMarkerDragEnd: ")
    }
})
```

## 标记动画

地图SDK提供给标记设置动画效果的方法，涉及到的类有：

|类|描述|
|:------------------------------------------------------------------------------------------------------------------------|:---------|
|[AlphaAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/alphaanimation-0000001050764853)|控制透明度的动画类。|
|[RotateAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rotateanimation-0000001051084794)|控制旋转的动画类。|
|[ScaleAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scaleanimation-0000001050764855)|控制缩放的动画类。|
|[TranslateAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/translateanimation-0000001050724822)|控制移动的动画类。|
|[AnimationSet](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/animationset-0000001051004875)|动画集合。|
|[Animation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/animation-0000001050724820)|所有动画类的父类。|

示例代码如下：

```java
"Java"
// 在地图上添加标记
Marker mParis;
mParis = hMap.addMarker(new MarkerOptions().position(new LatLng(48.893478, 2.334595)).title("paris").snippet("hello"));

// 定义动画的透明度效果
Animation alphaAnimation = new AlphaAnimation(0.2f, 1.0f);
alphaAnimation.setRepeatCount(5);
alphaAnimation.setDuration(1000L);
alphaAnimation.setAnimationListener(new Animation.AnimationListener() {
	@Override
	public void onAnimationStart() {
		Log.d(TAG, "Alpha Animation Start");
	}

	@Override
	public void onAnimationEnd() {
		Log.d(TAG, "Alpha Animation End");
	}
});

// 定义动画的缩放效果
Animation scaleAnimation = new ScaleAnimation(0, 2, 0, 2);
scaleAnimation.setRepeatCount(10);
scaleAnimation.setDuration(1000L);
scaleAnimation.setAnimationListener(new Animation.AnimationListener() {
	@Override
	public void onAnimationStart() {
		Log.d(TAG, "Scale Animation Start");
	}

	@Override
	public void onAnimationEnd() {
		Log.d(TAG, "Scale Animation End");
	}
});

AnimationSet animationSet = new AnimationSet(true);
animationSet.setInterpolator(new LinearInterpolator());
animationSet.addAnimation(alphaAnimation);
animationSet.addAnimation(scaleAnimation);

// 给标记设置动画效果
mParis.setAnimation(animationSet);
// 开始动画
mParis.startAnimation();
```

```java
"Kotlin"
// 在地图上添加标记
```

## 信息窗

信息窗在标记上方的弹出窗口中显示文本或图像，为标记提供详细信息。

### 添加信息窗

添加信息窗的最简单方法是设置相应[MarkerOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/markeroptions-0000001050150930)对象的[title](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/markeroptions-0000001050150930#section144310304569)()和[snippet](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/markeroptions-0000001050150930#section1266276203610)()方法。设置这些属性将导致在点击该标记时显示信息窗。

示例代码如下：

```screen
"Java"
public void addMarker(View view) {
    if (null != mMarker) {
        mMarker.remove();
    }
    MarkerOptions options = new MarkerOptions().position(new LatLng(48.893478, 2.334595));
    options.title("Hello Huawei Map");
    options.snippet("This is a snippet!");
    mMarker = hMap.addMarker(options);
}
```

```screen
"Kotlin"
fun addMarker(view: View?) {
    if (null != mMarker) {
        mMarker?.remove()
    }
    val options = MarkerOptions().position(LatLng(48.893478, 2.334595))
    options.title("Hello Huawei Map")
    options.snippet("This is a snippet!")
    mMarker = hMap.addMarker(options)
}
```

### 显示/隐藏信息窗

信息窗旨在响应用户触摸事件。可以通过调用[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858)对象的[showInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section13223817123711)()显示信息窗，可以通过调用[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858)对象的[hideInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858#section352393481515)()隐藏信息窗。

示例代码如下：

```java
"Java"
// 获取信息窗显示状态
boolean isInfoWindowShown = mMarker.isInfoWindowShown();
if (isInfoWindowShown) {
    mMarker.hideInfoWindow();
} else {
    mMarker.showInfoWindow();
}
```

```java
"Kotlin"
// 获取信息窗显示状态
val isInfoWindowShown: Boolean? = mMarker?.isInfoWindowShown
if (isInfoWindowShown != null && isInfoWindowShown) {
    mMarker?.hideInfoWindow()
} else {
    mMarker?.showInfoWindow()
}
```

### 自定义信息窗

可以自定义信息窗的内容。为此，您必须创建[HuaweiMap.InfoWindowAdapter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889)接口的具体实现，然后[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[setInfoWindowAdapter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section696710332112)()使用您的实现进行调用 。该接口包含两种实现方法：[getInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1927115112273)()和[getInfoContents](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1665805611258)()，这两种方法会按照书写顺序调用。

如果仅仅自定义信息窗格式，则需要实现[getInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1927115112273)()，[getInfoContents](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1665805611258)()返回null；如果仅仅自定义信息窗内容，则需要实现[getInfoContents](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1665805611258)()，[getInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1927115112273)()返回null；如果信息窗口和信息窗口内容都自定义，则[getInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1927115112273)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/marker-0000001050150858))和[getInfoContents](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1665805611258)()都需要实现。设计自定义信息窗的步骤如下：

1. 设置窗口或者内容的布局文件custom_info_window.xml或custom_info_contents.xml，实例代码仅演示[getInfoWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/infowindowadapter-0000001050151889#section1927115112273)()方法的实现。
