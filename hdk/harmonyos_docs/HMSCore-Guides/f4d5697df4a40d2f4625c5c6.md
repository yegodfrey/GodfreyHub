# 使用入门

#### 快游戏介绍

快游戏是一种新型免安装应用。具有以下优点：

                * 成本低，使用相对简单的js和css开发语言，所需代码量仅占安卓原生应用的1/5。 
                * 体验好，采用原生渲染技术，具备安卓原生应用的功能和体验，同时具备自动更新、占用内存少的便捷特点。 
                * 留存高，无需安装，即点即用，并可添加到桌面。 

更多快游戏相关介绍请参见[快游戏简介](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickgame-introduction-0000001159070205)。

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAnalyticsKit-QuickGame)快速体验一个应用的开发过程。

#### 开发环境

                * Cocos Creator 
                * Visual Studio Code 
                * 华为快应用IDE v3.1.1及以上 
                * Android SDK 
                * NDK 
                * 一台安卓手机 

#### 开发流程

您需要按照如下流程完成应用的开发工作。

开发步骤 | 说明  
---|---  
[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickgame-config-agc-0000001193692242) | 在开发应用前，需要在AppGallery Connect中配置相关信息，包括：注册成为开发者、创建应用、开通华为分析服务。  
[_集成SDK_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickgame-integrating-sdk-0000001193852242) | 通过本地方式集成SDK包。  
[_接入Analytics_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickgame-accessing-0000001238932185) | 参见[ _API参考_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickgame-api-analytics-overview-0000001194379572)中的API，实现数据上报功能。
