# 防沉迷

## 场景介绍

根据国家新闻出版署的最新规定，所有网络游戏企业仅可在周五、周六、周日和法定节假日每日20时至21时向未成年人提供1小时网络游戏服务，其他时间均不得以任何形式向未成年人提供网络游戏服务。

## 注意事项

在接入防沉迷方案前，您必须开通强制实名认证功能。按照国家新闻出版署规定，所有网络游戏必须接入国家新闻出版署网络游戏防沉迷实名验证系统。华为HMS Core提供了华为帐号登录时的实名认证功能，您只需向当地的新闻出版局申请接入网络游戏防沉迷实名认证系统，并获取"bizID（游戏备案识别码）"，再将bizID配置到AppGallery Connect，华为将为您的游戏自动对接国家新闻出版署的实名认证系统并开启强制实名认证，无需您进行额外的开发。具体操作请参见[版署实名认证申请](https://developer.huawei.com/consumer/cn/doc/app/game-center-identification-applyfor-0000001193982458)。

## 实名认证

根据相关法律法规要求，所有网络游戏玩家必须使用真实有效身份信息注册并登录网络游戏，玩家在使用华为帐号登录游戏时，会出现页面引导玩家进行实名认证，游戏无需自行开发实名认证系统。

玩家登录会弹出实名认证弹框。如果玩家点击取消认证，会返回错误码7021，游戏可再次调用登录接口弹出实名认证弹框，或直接强制玩家下线游戏。 说明
>
> * 当调用[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)静默登录时返回错误码7021，可以直接在登录失败的回调处进行处理。
> * 当调用[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)显式登录时返回错误码7021，可以在onActivityResult()中进行处理。
> * 当调用[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)静默登录时，如果玩家未实名会直接返回错误码2002，您需要调用[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)显式登录。

## 游戏试玩

根据国家新闻出版署的最新规定，所有网络游戏不得以任何形式（含游客体验模式）向未实名注册的用户提供游戏服务，如果您的游戏涉及"游客模式"等，需要进行整改。华为已关闭原有的游戏试玩模式，如果您已经接入了游戏服务的试玩模式，请尽快下线相关功能。

原有的游戏试玩模式示例代码举例如下：

```screen
PlayersClient client = Games.getPlayersClient(this);
client.setGameTrialProcess(new GameTrialProcess() {
    @Override
    public void onTrialTimeout() {
        //试玩时间结束
    }
  @Override
  public void onCheckRealNameResult(boolean hasRealName) {
     if (hasRealName) {
        //已实名，继续后续的游戏登录处理
        return;
      }
     //未实名，建议您提示玩家后退出游戏或引导玩家重新登录并实名认证
   }
});
```

## 防沉迷监控

根据国家新闻出版署的最新规定，所有网络游戏企业仅可在周五、周六、周日和法定节假日每日20时至21时向未成年人提供1小时网络游戏服务，其他时间均不得以任何形式向未成年人提供网络游戏服务。

Game Service SDK在6.1.0.301及以后版本中提供了未成年人游戏时间自动检测功能，您只需要在[游戏启动](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-start-0000001050123475)时在[JosAppsClient.init(AppParams appParams)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)中设置[AntiAddictionCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/antiaddictioncallback-0000001161473738)防沉迷回调，另外，您必须在[游戏登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526)成功后调用[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)方法获取玩家信息。当满足以下条件时游戏会将结果回调给您，此时您控制玩家退出游戏即可。

* 已实名的未成年人在非规定游戏时间内登录游戏，游戏服务会弹框提示玩家不允许游戏，玩家点击"确定"。
* 已实名的未成年人在规定时间内登录游戏，当游戏进行到晚上21时，游戏服务会弹框提示玩家已到游戏时间，玩家点击"知道了"。

## 支付限额

根据国家新闻出版署的要求，8周岁以下的未成年人不允许充值。8周岁以上未满16周岁的未成年人用户单次充值金额不得超过50元人民币，每月充值金额累计不超过200元人民币。16周岁以上的未成年人用户单次充值金额不得超过100元人民币，每月充值金额累计不得超过400元人民币。

用户在使用华为应用内支付时，华为会自动根据国家新闻出版署的要求进行支付限额控制，您无需处理。
