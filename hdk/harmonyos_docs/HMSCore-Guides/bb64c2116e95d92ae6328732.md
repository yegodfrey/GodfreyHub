# 错误场景

|错误描述|返回错误的场景|解决方法|
|:------|:--------------|:-----------------------------------------------------------------------------------------------------|
|操作成功|-|-|
|系统错误|提交接入申请|服务器系统错误，请联系开发解决。|
|参数校验错误|提交接入申请|参数填写错误，请根据页面上的提示进行修改参数。|
|记录不存在|提交接入申请、查询接入申请详情|请您刷新页面，检查后该问题是否还存在，如果仍然存在，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题。|
|文件上传失败|上传劵码文件|服务器系统错误，请联系开发解决。|
|文件内容重复|上传劵码文件|检查文件内容是否有重复行。|
|文件后缀不正确|上传劵码文件|检查文件后缀扩展名是否为txt。|
|文件过大|上传劵码文件|检查文件是否超过10MB。|
|文件行数过大|上传劵码文件|检查文件行数是否超过10万行。|
|文件内容不正确|上传劵码文件|检查文件内容中是否有某行长度超过128字节。|
|空文件|上传劵码文件|检查文件是否为0字节。|
|文件名非法|上传劵码文件|检查文件名是否存在特殊字符。|

若您的问题仍无法解决，请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)提交问题，华为支持人员会及时处理。
