# 场景介绍

#### 支持的业务场景

* 会员卡、礼品卡、优惠券 用户将[会员卡（Loyalty Cards）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access_membership-0000001050044329)、[礼品卡（Gift Cards）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-gift-0000001050042380)、[优惠券（Coupons）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-offer-0000001050044331)保存在华为钱包后，即可通过钱包及时了解品牌活动、会员权益和积分变化。

* 航空出行 用户将[登机牌（Boarding Passes）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-flight-0000001050044333)保存至华为钱包后，开发者即可在华为钱包设置自动通知和提醒功能，确保乘客及时收到航班的重要信息。

<!-- -->

* 智慧门票 用户将[活动门票（Event Tickets）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-eventticket-0000001050042382)保存至华为钱包后，可在钱包查看已购买的活动门票信息，系统支持给用户发送实时的智能提醒。使用时，无需打开App，通过双击电源键、负一屏等即可轻松调出门票。针对支持NFC技术的商户，基于华为智闪黑科技，给用户带来"熄屏碰一碰"刷开安检闸机的畅快体验。

* 社区门禁卡 用户将[社区门禁卡（Neighborhood access cards）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-doorkey-0000001050160356)模拟到华为钱包，并将该卡片设置为默认卡后，在不打开手机和App的情况下即可享受"熄屏碰一碰"刷卡开门的便利体验。提供NFC白卡开放能力，与社区服务提供商一起快速实现"社区智能卡"功能。

* 园区一卡通 用户将[园区一卡通（All-in-one cards for campuses）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-onecard-0000001050162309)添加到华为钱包，使用手机作为园区一卡通载体相比物理卡片更便捷，且基于华为手机"芯-端-云"一体化的安全能力。提供NFC白卡开放能力，与园区服务提供商一起快速实现"园区智能卡"功能。

* 智能门锁 用户将[智能门锁（Smart locks）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-hotelcard-0000001050162311)模拟到华为钱包，通过将手机与家用/酒店房门所安装的智能门锁进行配对后，手机可以当做家门钥匙和酒店房卡，通过NFC的方式打开房门。

* 车钥匙 用户将[车钥匙（Car keys）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-carcard-client-0000001194901521)模拟到华为钱包后，相比传统车钥匙，使用手机作为车钥匙载体更适用于钥匙分享等新业务场景。结合国内车厂的业界现状，可以快速实现手机车钥匙功能。
