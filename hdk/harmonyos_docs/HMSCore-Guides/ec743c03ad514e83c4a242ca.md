# 桌面角标

推送服务提供了设置桌面角标的API接口，您可以在消息中封装角标参数[badge](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p23206882314)。桌面角标样例如下所示：

消息体示例：

```screen
{
    "validate_only": false,
    "message": {
        "notification": {
            "title": "message title ",
            "body": "message body"
        },
        "android": {
            "notification": {
                "click_action": {
                    "type": 3
                },
                "badge": {
"add_num": 1,
"class": "com.huawei.codelabpush.MainActivity",
"set_num": 10
}
            },
            "ttl": "1000"
        },
        "token": ["pushtoken1"]
    }
}
```

> 说明
>
> * 如果同时设置"[add_num](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p163226882313)"与"[set_num](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p193222892314)"，以"set_num"为准；若"add_num"和"set_num"都设置为空，则应用角标数字默认加1。
> * 打开应用或者点击、清理通知栏消息并不会清理角标数字或圆点，需开发者自行设置清理角标，详情请参见[桌面角标开发指导](https://developer.huawei.com/consumer/cn/doc/development/Corner-Guides/30802)。
> * 绘制自定义角标图片请参见[桌面角标开发指导](https://developer.huawei.com/consumer/cn/doc/development/Corner-Guides/30802)。
> * 此处"com.huawei.codelabpush.MainActivity"仅为示例。
