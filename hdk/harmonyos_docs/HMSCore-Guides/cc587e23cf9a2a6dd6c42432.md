# 及刻与Awareness共同提供全新智慧场景服务

## 背景介绍

及刻聚焦于线下智慧场景服务的建设。历经数载积淀，已覆盖超过1000万生活场景，包括购物中心、餐饮、零售、机场、高铁站、景区等，通过手机终端高效连接人与场景、人与商业，为用户创造更加智能、便捷的服务体验，让消费生活更加美好。目前及刻已为上百家商业实体、数亿终端用户提供智慧场景服务。

## 面临挑战

如何实现线上、线下生活服务的接轨及融合，关键在于实时、精准感知用户当前所处的情景。为了给开发者提供更加符合需求的、贴心的智慧场景服务，及刻面临如下挑战：

* 如何准确感知用户所处情景，实现一次集成获取各种情景感知能力，并且能够组合运用。
* 如何通过一次开发，即可支持华为手机绝大多数机型，同时也支持在非华为手机上使用。

## 解决方案

及刻依托于情景感知服务（Awareness Kit），打造智能近场服务新体验，为开发者提供其用户情景状态感知的组合能力，如用户所处位置、当前时间是否为节假日等，帮助开发者更好服务于用户。

* 掌上高铁 结合及刻及华为情景感知能力，为掌上高铁App提供近场感知能力，提升出行信息、车站大屏等多项服务的即时服务能力，提升高铁、航空旅客的智慧出行体验。


* 一点万象 结合及刻及华为情景感知能力，协助一点万象App充分挖掘自有资源优势及大数据能力，为到场用户提供个性化内容推荐，如优惠、会员、积分、停车等。

## 合作收益

* To及刻 一次集成获取各种情景感知能力，并且能够组合运用，为开发者提供更加智慧的场景服务。


* To及刻开发者

调用及刻SDK即可使用华为情景感知服务丰富的能力。
