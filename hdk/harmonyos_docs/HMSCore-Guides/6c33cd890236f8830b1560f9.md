# 语言培训

#### 事件参数列表

        * kHAEventRegisterAccount

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRegistMethod | 用户来源 | String | 可选 | 用户来源。  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
kHAParamOccurredDate | 注册时间 | String | 可选 | 用户注册帐号的时间。  
kHAParamInviter | 邀请人 | String | 可选 | 邀请该用户进行注册的用户。  
  
        * kHAEventBindAccount

用户绑定其他类型帐号时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
  
        * kHAEventViewProduct

用户浏览商品时，上报此事件。可以分析用户对哪些商品感兴趣，也可以和其他事件组合完成漏斗分析。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamProductId | 商品ID | String | 必选 | 用户浏览商品的ID。  
kHAParamProductName | 商品名称 | String | 必选 | 用户浏览商品的名称。  
kHAParamProductFeature | 商品特征 | String | 可选 | 用户浏览商品的特征。  
kHAParamCategory | 商品分类 | String | 必选 | 用户浏览商品的分类。
          * course：表示商品为课程。
          * practice：表示商品为习题。  
kHAParamBrand | 商品品牌 | String | 可选 | 用户浏览的商品品牌。  
kHAParamPrice | 商品价格 | Double | 可选 | 商品的价格。  
kHAParamQuantity | 数量 | Long | 可选 | 用户准备购买的数量。  
kHAParamRevenue | 收入 | Double | 可选 | 用户购买此商品，预计会给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
kHAParamEnter | 入口 | String | 可选 | 用户浏览商品的入口。  
  
        * kHAEventCreateOrder

用户创建订单时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---

用户升级时，上报此事件。分析产品的用户等级设置是否合理，有针对性地制定优化策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamLevelId | 用户等级 | Long | 必选 | 标识用户提升后的等级。  
kHAParamLevelBefore | 提升前用户等级 | Long | 可选 | 标识角色提升前的等级。  
kHAParamRoleName | 用户角色 | String | 可选 | 标识用户的角色。  
kHAParamIsTopLevel | 是否达到满级 | String | 可选 | 用户升级后等级是否达到满级。
              * 0：没有达到满级
              * 1：达到满级  
  
            * kHAEventCheckIn

用户登录应用点击打卡时上报此事件。

参数ID | 参数名称 | 参数类型  
---|---|---  
kHAParamChannel | 分享渠道 | String | 可选 | 标识用户分享App的渠道信息，如：微信、微博。  
kHAParamEntry | 分享入口 | String | 可选 | 标识用户分享App行为的入口信息。  
  
            * kHAEventShareContent

用户通过社交渠道分享商品或内容时，上报此事件。可以分析用户对产品的忠诚度。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamContentType | 分享内容类型 | String | 必选 | 标识用户分享内容的类型。  
kHAParamContentName | 分享内容名称 | String | 可选 | 用户分享内容的名称，如：优惠券名称等。  
kHAParamProductId | 分享内容ID | String | 必选 | 标识用户分享内容的内容ID。  
kHAParamChannel | 分享方式 | String | 必选 | 标识用户分享的渠道信息。
