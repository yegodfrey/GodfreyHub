# 术语

|术语|说明|
|:----------|:---------------------------|
|文件实体|有文件内容的实体。|
|文件元数据|描述文件夹属性的信息，包含文件夹名称、类型、文件描述等。|
|AccessToken|AT，用户鉴权信息。|
|cursor|游标，分布式id，记录当前时间点以后的操作。|
|缩略图|将图片或者视频的某一帧进行等比例缩小后的图片。|
