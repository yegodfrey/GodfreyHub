# 提升数据开放实时性

为了保障生态应用数据获取的实时性，解决用户未在第三方平台设置允许华为运动健康App后台活动，导致华为运动健康App数据未能够及时同步上云的问题，使运行在Android手机、iOS手机的生态App应用能够从Health Service Kit云及时获取到用户最新的运动健康数据，我们提供如下方案，使第三方应用在获得用户授权的前提下，通过让用户主动触发数据同步的操作，以达到用户数据实时上云的目的，从而增强数据开放实时性。  

#### 接入准备

1. 您的应用接入需在Health Service Kit卡片上申请"数据同步"权限，若您是App应用，请自行填写应用scheme地址。![](https://media:901788166612262441)
2. 在[生成授权码code](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/auth-example-0000001054581058#ZH-CN_TOPIC_0000002516518878__li1118518134711)时在scope中添加权限说明表格中的权限，供用户在登录华为账号之后为应用授予"手动数据同步"权限。
3. 必须限制，在您的应用中通过让用户主动触发的方式实现数据同步操作。
4. 您的应用需提示用户做如下自检：
   * 确保手机上的运动健康App已安装合适版本，iOS：运动健康版本不低于13.1.3.305；Android：运动健康版本不低于13.1.3.300。
   * 需要用户检查手机上的运动健康App，华为账号已登录。
   * 需要用户检查手机上"运动健康App\>我的 \> 隐私管理\>数据同步管理"下的所有开关状态，确保开关都打开。
* iOS用户需检查手机"设置\>华为运动健康\>通知"，确保允许通知开关打开。  

#### 权限说明

联盟卡片申请的权限名称：数据同步 \> 手动数据同步  

|权限|权限描述|说明|
|:----------------------------------------------------------|:----------------------------------------|:-|
|https://www.huawei.com/healthkit/huaweihealthdata.cloudsync|允许触发华为运动健康应用同步个人数据到云（基于华为运动健康应用的数据同步管理设置)|-|

#### Android应用

建议Android应用接入使用DeepLink方式，可参照以下步骤完成数据实时性提升能力的接入。

1. 在您的程序中使用DeepLink功能拉起运动健康App同步进度条，等待进度条完成，数据同步成功。

   <br />

   scheme地址：huaweischeme://healthapp/router/sync  
   示例代码：

   ```
   @Override
       protected void onCreate(@Nullable Bundle savedInstanceState) {
           super.onCreate(savedInstanceState);

           setContentView(R.layout.activity_healthkit_datasync); // 页面布局设置
           startButton = findViewById(R.id.bn1);  // 设置数据同步按钮

           long version;
           try {
               PackageInfo packageInfo =
                   this.getPackageManager().getPackageInfo("com.huawei.health", PackageManager.GET_META_DATA);
               if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
                   version = packageInfo.getLongVersionCode();
               } else {
                   version = packageInfo.versionCode;
               }
           } catch (PackageManager.NameNotFoundException e) {
               version = 0L;
           }
           // 获取当前Android手机上安装的运动健康App版本号，可用于判断当前用户使用的运动健康App版本是否支持数据实时性增强功能
           Log.i(TAG, "find the app, version is : " + version);
           // 通过按钮点击方式拉起运动健康App数据同步scheme
           startButton.setOnClickListener(new View.OnClickListener() {
               @Override
               public void onClick(View view) {
                   
                   // 数据同步进度条颜色自定义
                   int color=0;
                   try {
                         String colorString = "FF11FFFF";
                         color = Color.parseColor("#" + colorString);
                       } catch (IllegalArgumentException e) {
                   }
                   // deeplink参数拼接
                    String redirectUrlEncode = Uri.encode("XXXXX"); // XXXXX直接填入您应用的在AndroidManifest.xml中注册的scheme地址
                    String signatureEncode = generateSignature("您应用的appid","您应用的schemeSecret");  // 分别填入您应用的appid，与scheme Secret
                   // 请求
                    StringBuilder sb2 = new StringBuilder();
                    sb2.append("huaweischeme://healthapp/router/sync");
                    sb2.append("?extraColor=");
                    sb2.append(color);
                    sb2.append("&appId=");
                    sb2.append("您应用的appid");
                    sb2.append("&redirectUrl=");
                    sb2.append(redirectUrlEncode);
                    sb2.append("&signature=");
                    sb2.append(Uri.encode(signatureEncode));
                    Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse(sb2.toString()));
                    intent.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TASK);
                    try {
                       this.startActivity(intent);
                    } catch (ActivityNotFoundException e2) {
                       ActivityNotFoundException activityNotFoundException = e2;
                    }

           });
           private String generateSignature(String appId, String schemeSecret) {
                 StringBuilder str = new StringBuilder();
                 str.append(appId).append("_").append(schemeSecret);
                 byte[] bytes = java.util.Base64.getDecoder().decode(schemeSecret);
                 try {
                     Mac hmacSHA256 = Mac.getInstance("HmacSHA256");
                     hmacSHA256.init(new SecretKeySpec(bytes,"HmacSHA256"));
                     byte[] sinData = hmacSHA256.doFinal(str.toString().getBytes("utf-8"));
                     return Base64.getEncoder().encodeToString(sinData);   // 生成的验证签名内容
                    } catch (NoSuchAlgorithmException | InvalidKeyException | UnsupportedEncodingException e) {
                    // 异常处理
                  }
                  return "";
            }
       }
   ```

#### iOS 应用

建议iOS应用接入使用DeepLink方式，可参照以下步骤完成数据实时性提升能力的接入。

1. 在您的程序中使用DeepLink功能拉起运动健康App数据同步页面，传入您应用的appId、应用的签名信息schemeSecret、以及应用的回调跳转地址，等待同步进度条完成，数据同步成功后，会跳转至你传入的回调地址页面。

   <br />

   示例代码

   ```
   - (NSString *)generateSignatureWithAppId:(NSString *)appId secret:(NSString *)secret {
       NSString *str = [NSString stringWithFormat:@"%@_%@", appId, secret];
       NSData *secretData = [[NSData alloc] initWithBase64EncodedString:secret options:NSDataBase64DecodingIgnoreUnknownCharacters];
       if (!secretData) {
           return nil;
       }
       @try {
           CCHmacContext ctx;
           CCHmacInit(&ctx, kCCHmacAlgSHA256, secretData.bytes, secretData.length);
           NSData *strData = [str dataUsingEncoding:NSUTF8StringEncoding];
           CCHmacUpdate(&ctx, strData.bytes, strData.length);
           unsigned char mac[CC_SHA256_DIGEST_LENGTH];
           CCHmacFinal(&ctx, mac);
           NSData *macData = [[NSData alloc] initWithBytes:mac length:CC_SHA256_DIGEST_LENGTH];
           return [macData base64EncodedStringWithOptions:0];
       } @catch (NSException *exception) {
           return nil;
       }
   }

   - (void)gotoHealth {
       NSString *redirectUrl = @"XXXXX"; //您应用注册的scheme地址
       NSString *signature = [self generateSignatureWithAppId:@"您应用的appid" secret:@"您应用的schemeSecret"];
       redirectUrl = [self encode:redirectUrl];
       NSString * filePath = @"huaweischeme://healthapp/router/sync?extraColor=int型颜色值&appId=您应用的appid&redirectUrl=%@&signature=%@"; // scheme拼接
       NSURL *healthUrl = [NSURL URLWithString:[NSString stringWithFormat:filePath, redirectUrl, signature]];
       [UIApplication.sharedApplication openURL:healthUrl options:@{} completionHandler:nil];
   }

   - (NSString *)encode: (NSString *) param {
       NSCharacterSet *charSet = NSCharacterSet.URLQueryAllowedCharacterSet;
       NSURL *healthUrl = [NSURL URLWithString:[param stringByAddingPercentEncodingWithAllowedCharacters:charSet]];
       return healthUrl.absoluteString;
   }
   ```
