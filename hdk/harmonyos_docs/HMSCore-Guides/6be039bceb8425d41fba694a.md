# 华为帐号登录管理细则

为了保护用户隐私信息，确保用户获得良好的登录体验，根据[《华为开发者服务协议》](https://developer.huawei.com/consumer/cn/doc/start/agreement-0000001052728169)、[《华为APIs使用协议》](https://developer.huawei.com/consumer/cn/doc/20209)、[《华为应用市场审核指南》](https://developer.huawei.com/consumer/cn/doc/50104)、[《元服务审核指南》](https://developer.huawei.com/consumer/cn/doc/distribution/app/50129)等相关协议条款及现行法律法规，平台制定了华为帐号登录管理细则，使用华为帐号登录的应用请遵照执行，具体要求如下：

## 上架审核要求

为了帮助用户省去多次输入不同应用帐号登录的繁琐过程，我们为HarmonyOS应用和元服务开发者提供了使用华为帐号快速登录的能力。提交至华为应用市场的HarmonyOS应用和元服务，需要遵循如下规范：

（1）如果您的应用支持用户使用第三方帐号登录，则该应用需提供华为帐号登录选项。用户可通过华为帐号快速地登录您的应用，并获得安全性保障。

（2）如果您的元服务内存在帐号体系时，需提供华为帐号登录选项。

## 设计规范

### 交互设计要求

为构建鸿蒙生态简单易用、高效、一致的用户体验，HarmonyOS应用与元服务（以下简称应用）的帐号登录页面设计需遵循以下原则：

1. 允许用户有足够的时间和机会体验应用的用途后，才决定是否注册/登录使用。禁止用户进入应用还未开始了解基础功能，就强制要求注册/登录。
2. 当应用调用帐号登录功能时，应提供清晰的取消或拒绝选项按钮，不得强制要求用户登录帐号才能使用。
3. 帐号登录页面应包含应用ICON、应用名称、应用描述文本、隐私相关文本、登录按钮等元素，**突出显示使用"华为帐号快速登录"按钮。**按钮大小与颜色需要按照规范规定的样式呈现。
4. 如用户选择拒绝登录/授权，您可在用户表现出向应用授权的意向后再次提示登录。
5. 应用应提供功能正常且易于发现的"退出"选项。
6. 当用户取消/拒绝授权后，开发者有义务清除并不再继续使用该用户的头像昵称等数据。
