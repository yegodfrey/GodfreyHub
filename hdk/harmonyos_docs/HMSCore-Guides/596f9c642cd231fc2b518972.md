# 电商  
  
#### 事件参数列表

      * kHAEventCompletePurchase

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamProductId | 商品ID | String | 必选 | 被添加到购物车中的商品ID。  
kHAParamProductName | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
kHAParamQuantity | 购买数量 | Long | 必选 | 用户准备购买的数量。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
kHAParamRevenue | 收入 | Double | 可选 | 本次交易给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamTaxFee | 税费 | Double | 可选 | 本次交易产生的税费。  
kHAParamShipping | 运输费 | Double | 可选 | 本次交易产生的运输费。  
kHAParamVoucher | 优惠券 | String | 可选 | 用户在本次交易中使用的优惠券。  
kHAParamBrand | 商品品牌 | String | 可选 | 关联的商品品牌。  
kHAParamCategory | 商品分类 | String | 必选 | 关联的商品分类。  
kHAParamSource | 营销来源 | String | 可选 | 营销活动提供者的标识，如：HUAWEI PPS。  
kHAParamMedium | 营销类型 | String | 可选 | 营销活动的类型，如：CPC、Email、运营坑位、Banner等。  
kHAParamPromotionName | 营销名称 | String | 可选 | 营销活动的名称。  
kHAParamContent | 营销内容 | String | 可选 | 营销活动的营销内容。  
kHAParamKeywords | 关键词 | String | 可选 | 营销活动的关键词。如：搜索广告的关键词。  
kHAParamMaterialName | 创意名称 | String | 可选 | 营销活动使用的创意素材名称。  
kHAParamMaterialSlot | 营销内容展示位置 | String | 可选 | 创意素材被展示的位置信息。  
  
      * kHAEventCreatePaymentInfo

结算过程中，用户已经添加付款信息，但尚未发起支付时，上报此事件。

此事件可以与kHAEventStartCheckout、kHAEventCompletePurchase组合使用，构建结算过程的漏斗分析。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamPayType | 支付方式 | String | 必选 | 用户选择的支付方式。

      * kHAEventAddProduct2Cart

kHAParamPrice | 购买价格 | Double | 可选 | 商品的价格。  
kHAParamRevenue | 预计收入 | Double | 可选 | 用户购买此商品，预计会给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。
