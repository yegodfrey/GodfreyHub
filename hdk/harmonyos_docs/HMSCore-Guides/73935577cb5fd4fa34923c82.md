# 功能描述

本章节主要介绍接入华为云空间服务的开发步骤，以帮助开发者快速了解华为云空间服务提供的客户端接口及其调用方法。请开发者基于应用自身的使用场景，自行选择相应的开发章节。本章代码片段中，包含一些参数或方法未给出定义，请下载完整示例代码。

Drive SDK提供的主要能力以及调用方法如下：

* [获取鉴权信息。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-authentication-0000001064776447)
* [获取用户信息。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-user-0000001064504643)
* [调用Files接口进行文件管理和搜索。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-managing-and-searching-0000001064626787)
* [调用Create和Get接口对应用数据进行备份和恢复。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-storing-data-0000001064744958)
* [调用Changes接口注册资源变化通知channel，开启文件变化通知功能。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-enable-notification-0000001064586728)
* [调用Comments接口评论文件。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-comment-0000001064066731)
* [调用Replies接口对评论进行回复。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-reply-0000001064068543)
* [调用HistoryVersions接口查询文件历史版本。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-quary-history-version-0000001065066358)
* [批量操作。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-batch-operation-0000001064428540)
