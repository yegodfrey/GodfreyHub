# 服务定价

#### 服务订阅说明

  1. 天气服务采用订阅/购买的方式进行结算。
  2. 当您成功注册成为华为开发者用户，在AppGallery Connect创建项目后，通过AppGallery Connect开通付费套餐，具体操作请参见[服务定价与订购](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing)。
  3. 针对所有的AppGallery Connect付费服务，华为将按您使用服务实际产生的使用量向您收费。
