# 海拔

此数据记录用户的海拔高度，每一条数据都代表该时刻的海拔高度。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。
> 说明
>
> * 高原血氧海拔：仅部分华为智能穿戴设备支持高原血氧海拔数据自动持续检测，需要用户在"华为运动健康App > 健康 > 血氧卡片 > 设置 > 高原关爱"查看当前使用的穿戴设备是否支持，并开启高原血氧海拔检测。
> * 运动记录海拔：部分支持气压传感器的华为智能穿戴设备在运动过程中能够持续测量海拔采样数据。

## OAuth权限

联盟卡片申请的权限名称：日常活动 > 距离、爬高与海拔

* 读权限：https://www.huawei.com/healthkit/distance.read
* 写权限：https://www.huawei.com/healthkit/distance.write
