# 通过AppAuth接入华为帐号（Android）

## 概述

本文适用于希望接入华为帐号的Android应用。华为帐号提供了HMS Core SDK来快速接入，但是对于某些无法使用HMS Core SDK的场景，还可以通过OAuth 2.0协议的方式在浏览器中进行华为帐号登录。为了方便快速接入OAuth 2.0授权，您可以使用AppAuth SDK。

## 配置要求

* 接入AppAuth SDK要求应用使用的Android SDK版本在API 16及以上。

* Android客户端上已经安装浏览器。

## 开发准备

### 获取Client ID

在开始开发应用前，需要[创建并管理应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)，获取产品的Client ID（下文中提及的client_id值传此处的Client ID值）。

## 开发流程

### 获取示例代码

您可以从[AppAuth-For-Android的官方网站](https://openid.github.io/AppAuth-Android/)中下载示例代码，或通过以下命令克隆代码：

```screen
git clone https://github.com/openid/AppAuth-Android.git
```

在AndroidStudio中打开该工程。

### 配置请求参数

授权过程需要用到client_id、授权地址等参数信息，您可以将这些信息写到配置文件"/res/raw/auth_config.json"中。使用到的相关配置参数如下：

|参数|必选/可选|示例值|说明|
|:-------------------------|:----|:--------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|client_id|必选|111111111|您在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)创建应用后分配的Client ID，请参见[获取Client ID](#section22863551912)。|
|redirect_uri|必选|com.huawei.apps.ClientID:/oauth2redirect|固定格式，其中ClientID为您在华为开发者联盟申请的Client ID，请参见[获取Client ID](#section22863551912)。|
|authorization_scope|必选|openid email profile|用户实际授予的权限列表，其中OpenID必填，多个Scope通过空格分隔。|
|discovery_uri|可选|https://oauth-login.cloud.huawei.com/.well-known/openid-configuration|OpenID授权服务的动态发现地址，配置了该地址则可选配置authorization_endpoint_uri、token_endpoint_uri。|
|authorization_endpoint_uri|可选|https://oauth-login.cloud.huawei.com/oauth2/v3/authorize|授权接入地址，如果未配置discovery_uri则必填。|
|token_endpoint_uri|可选|https://oauth-login.cloud.huawei.com/oauth2/v3/token|令牌获取地址，如果未配置discovery_uri则必填。|
|https_required|必选|true|是否使用HTTPS请求，在华为帐号登录场景该值为true。|

### 配置回调地址

在[获取的示例代码](#section2064715115217)的应用级gradle文件中，找到**appAuthRedirectScheme** 并将其对应的值修改为com.huawei.apps.***APPID*** ，其中***APPID*** 应替换为您在华为开发者联盟申请的[Client ID](#section22863551912)。

**示例**

```screen
manifestPlaceholders = [
    'appAuthRedirectScheme': 'com.huawei.apps.{APPID}'
]
```

### 运行示例代码

按以上步骤配置好请求参数后，您可以运行[获取的示例代码](#section2064715115217)。用户可以在页面中选择要使用的浏览器，并点击"START AUTHORIZATION"，此时会打开浏览器页签并加载授权登录页面。

在浏览器中登录华为帐号并授权成功后，您会获取到ID Token、Access Token等授权信息。

### 解析ID Token获取用户信息

返回的ID Token是JWT格式的字符串，可以按照JWT格式进行解析，获取用户的Union ID、Email地址、头像等信息。

校验ID Token请参见[验证ID Token有效性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-guide-account-0000001050048888#section56301064278)，ID Token解析后的参数请参见[验证ID Token有效性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-verify-id-token_hms_reference-0000001050050577)中返回值的参数。
