# 操作流程

#### 导入配置

导入功能可以将指定文件中的配置信息导入至当前配置的草稿中。执行导入操作时，服务端会对导入文件的格式及完整性进行校验，为避免校验失败，请您直接使用导出配置的文件进行导入。

    1. 在“配置”页面，点击“导入”按钮。
    2. 选择本地待导入的JSON文件并选中导入策略，点击“导入”。

       * 导入的配置不允许为空，即导入的配置中至少应包含一个变量、条件、代码、分组或可视化埋点。
       * 导入策略分为覆盖和合并两种。其中，覆盖策略将删除配置草稿中的变量、条件、代码、分组和可视化埋点，并使用导入的数据生成新的草稿。
       * 导入时如果选择合并策略，您需要进一步指定在遇到名称相同的变量、条件、代码、分组或可视化埋点时的处理规则：
         1. 新内容覆盖旧内容：以导入数据覆盖草稿中的数据，草稿中原有的重名数据将被删除。
         2. 自动重命名新内容：自动对导入的重名数据进行重命名，可同时保留草稿中原有的数据和导入的数据。
         3. 保留旧内容：重名数据仅保留草稿中原有的数据，丢弃导入的数据。
       * 选择完JSON文件后，选择文件按钮为灰色。

#### 导出配置

导出功能可以将历史版本或当前草稿中的配置信息导出为JSON格式的文件，导出的文件可用于应用间的配置同步或将当前配置还原为某个历史版本数据，详情参见导入配置功能介绍。

    1. 在“配置”页面，点击“导出”按钮。
    2. 选择一个待导出的版本，点击“导出”即可将配置信息保存至本地。

#### 编辑配置

配置创建后，您可以对配置的名称、操作记录存储时间进行修改。

    1. 在“配置”页面，点击“编辑”按钮。
    2. 您可以修改配置名称和操作记录的存储时间。
