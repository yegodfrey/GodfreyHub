# 变量字段说明  
  
#### DOM元素

字段名称 | 属性 | 说明  
---|---|---  
选择方法 | 元素ID | 通过指定的HTML元素的唯一ID选择Dom元素。  
CSS选择器 | 通过id、class等选择Dom元素。  
属性名 | - | 获取Dom元素对应属性名的值。 该项不填为空时，则获取Dom元素的文本内容。  
  
#### 元素属性

字段名称 | 属性 | 说明  
---|---|---  
属性名 | - | 要获取的元素的属性，例如id、class、name等。  
默认值 | - | 当没有提取到元素，或者提取的元素没有目标属性，则返回默认值。  
  
#### 元素可见性

字段名称 | 属性 | 说明  
---|---|---  
选择方法 | 元素ID | 通过指定的HTML元素的唯一ID选择Dom元素。  
CSS选择器 | 通过id、class等选择Dom元素。若找到多个元素，则使用第一个被匹配的元素。  
输出类型 | True/False | 当前元素达到最低可见百分比，则在屏幕上可见，输出true；否则，输出false。  
百分比 | 表示有多少百分比的元素在屏幕上可见。 取值范围：[0,100]。  
最低可见百分比 | - | 当且仅当“输出类型”为“True/False”时，表示元素在屏幕上至少有多少百分比可见，变量才会输出true。  
  
#### 第一方Cookie

字段名称 | 属性 | 说明  
---|---|---  
Cookie名称 | - | 用于获取对应名称Cookie的值。  
URL解码 | - | 勾选则启用URL解码。 如果启用，则对获取的第一方Cookie的值进行URL解码，例如：“age%3D4”解码为“age=4”。  
  
#### 记录层变量

字段名称 | 字段说明  
---|---  
记录层变量名 | 用于标识自定义记录层变量。必填，输入长度不超过1000个字符。 例如：将名为“key”的记录层变量名的值设置为“value”，代码如下：
    
    recordTier.push({'key': 'value'});

说明： “记录层变量名”在网页一级发挥作用，而非会话一级。  
默认值 | 勾选则启用默认值。 如果启用，可以设置“value”的默认值，当该记录层变量无内容时，返回该默认值。  
  
#### Google Analytics设置

字段名称 | 字段说明  
---|---  
跟踪ID | 跟踪ID（也就是trackingId）格式为UA-XXXX-Y，是衡量ID/网络媒体资源ID。 作为必填项，需要用户自行注册，注册方式参见[设置Google Anaytics代码](https://support.google.com/analytics/answer/1008080?visit_id=637252181276895793-1182163595&rd=1)。  
自定义维度 | 用于自定义设置数据的属性。键为数字索引号，必须是正整数。GA360帐号最多可使用200个维度；非GA360帐号最多可使用20个维度。  
自定义指标 | 用于自定义设置衡量的数据。键为数字索引号，必须是正整数。自定义指标对应的值只能是数字。GA360帐号最多可使用200个指标；非GA360帐号最多可使用20个指标。  
内容组 | 根据网页的内容进行分组，键必须是正整数。最多添加5个内容组数据。值是由“/”分隔的分层文字，最多分隔100个文字。例如，“a/b/c”、“HUAWEI/phone”。  
启用谷歌广告ID功能 | 如果您需要集成Google的以下功能：应用安装转化、受众特征报告、受众兴趣报告及Google Analytics（分析）再营销，则勾选该参数。  
名字 | 跟踪器名字，缺省为dtmX（X为自增整数，以区分不同跟踪器）。  
客户端ID | 以匿名方式标识浏览器实例，默认随机生成，作为第一方Google Analytics（分析）Cookie的一部分进行存储，有效期为2年。  
采样率 | 指定应对多大比例的用户进行跟踪。默认值为100（跟踪所有用户），但是大型网站可能需要降低抽样率，以免超出Google Analytics（分析）的处理上限。  
网速采样率 | 此设置决定以何种频率发送网站速度信标。默认情况下，系统会自动跟踪1%的用户。  
将当前主机上的其他网页作为引荐处理 | 系统仅在引荐网站的主机名与当前网页的主机名不一致时发送用于归因流量来源的HTTP引荐来源网址。仅当您想要将当前主机上的其他网页作为引荐处理时，才可启用此设置。  
支持在定位点中搜索自定义广告系列参数 | 默认情况下，analytics.js会在当前网页网址的查询字符串和定位点中搜索utm_source、utm_medium等自定义广告系列参数。若未勾选此项，系统将忽略出现在定位点中的任何自定义广告系列参数。  
Cookie名字 | 用于存储分析数据的Cookie的名称，默认值为_ga。  
Cookie网域 | 指定用于存储分析Cookie的网域。默认值为document.location.hostname。推荐使用auto。如果将此字段设为“none”，系统将不会在设置Cookie时指定网域。  
Cookie有效期 | 指定Cookie有效期，以秒为单位。默认值为63072000（2年）。  
写入Cookie来存储广告系列信息 | 默认情况下，analytics.js会写入Cookie来存储广告系列信息。该字段可用于禁止写入该Cookie。  
旧版Cookie网域 | 此字段用于配置analytics.js如何搜索由ga.js和urchin.js等旧版Google Analytics（分析）衡量脚本生成的Cookie，无默认值。  
analytics.js从ga.js Cookie中导入历史数据 | 指明analytics.js是否应该尝试从ga.js Cookie中导入历史数据。  
启用网域连接器参数分析 | 若勾选此字段，将会启用跨网域连接器参数（用于在网域间传递状态）分析。  
  
#### 正则表达式表格

字段名称 | 属性 | 说明  
---|---|---  
选择变量 | - | 将选择变量的值与正则表达式表格的“键”进行匹配。  
正则表达式表格 | 表达式/输出 | 一组用于与选择变量的值进行正则匹配的键值对。匹配时按照列表从上到下的顺序进行。 若匹配成功，则返回对应的值。  
默认值 | - | 若勾选此项，当没有匹配到正则表达式表格的“表达式”时，则返回默认值。  
忽略大小写 | - | 若勾选此项，则忽略字母大小写。  
完全匹配 | - | 若勾选此项，则将在正则表达式前后隐式加上“^”和“$”，对该正则表达式进行完全匹配。 例如，/^eat$/并不会匹配“neatly”,但是会匹配“eat”。  
匹配分组并替换 | - | 若勾选此项，将允许用户使用$语法，则在输出内容中包含部分输入内容。例如，/I want to (drink) some (water)/匹配“I want to drink some water”时，输出“He needs to $1 more $2”得到结果“He needs to drink more water”。  
  
#### 映射表

字段名称 | 属性 | 说明  
---|---|---  
选择变量 | - | 将选择变量的值与映射表的“输入”进行匹配。  
映射表 | 输入/输出 | 一组用于与选择变量进行映射的键值对。匹配时按照列表从上到下的顺序进行。 若匹配成功，则返回对应的值。  
默认值 | - | 若勾选此项，当没有匹配到映射表的“输入”时，则返回默认值。  
  
#### 网址

字段名称 | 属性 | 说明  
---|---|---  
网址元素 | 完整网址 | 获取完整网址。  
协议 | 获取网址协议。  
主机名 | 获取主机名。 如果需要去掉前缀www，可以勾选启用'去掉“www”'（默认未勾选）。  
端口 | 获取端口号。  
路径 | 获取网址路径，并可以通过“默认页”过滤路径。 默认页为字符串集合，例如：["text","readme","index.html",.....]，其取值范围：
                1. 数组成员不超过100个。
                2. 数组中每个字符串的长度不超过1000个字符。
当网址路径的最后一个“/”后的字符串与默认页中任意字符串匹配，则去掉该“/”后的字符串。 例如，如果默认页是“index.html”，网址是“https://www.xyz.com/a/b/c/index.html”，则变量的值为“/a/b/c/”。  
文件拓展名 | 网址路径中的文件扩展名。  
参数 | 根据指定的“参数名”获取网址中的参数内容。 变量的值是第一个未转义的匹配参数的值。 例如：参数名为“type”，网址为“https://www.xyz.com/?type=cloth&index=0”，则变量的值为“cloth”。 取值范围：参数名长度不超过1000个字符。  
片段 | 获取网址中的片段（即从#开始的部分）。
