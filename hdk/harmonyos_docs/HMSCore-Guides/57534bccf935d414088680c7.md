# HUAWEI Analytics配置

在之前版本的DTM中，集成HA的Web SDK时，需要通过"npm方式"集成，由于该方式没有提供公网下载地址，DTM无法动态下载HA的JS SDK并初始化HA。为解决该问题，可通过配置"HUAWEI Analytics配置"及"HUAWEI Analytics"代码，即可实现HA的Web SDK集成。
> 说明
>
> 若您是新用户，未集成过HA的Web SDK时，可通过"HUAWEI Analytics配置"的方法进行集成；若您是老用户，已经集成过HA的Web SDK，则仍保持原NPM方式，无需配置"HUAWEI Analytics配置"代码。
>
> 每个应用仅能创建一个"HUAWEI Analytics配置"代码，因此该代码不支持复制。

1. 配置"HUAWEI Analytics配置"代码。

   1. 在"新建代码"页面中输入代码名称后，将"扩展"类型选择为"HUAWEI Analytics配置"。
   2. 根据实际情况，配置"API密钥"、"SDK配置"、"数据处理位置"等相关参数。 说明
      >
      > 此处的"触发条件"，建议使用预置的"Initialization - All pages"条件。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/zlm_vk72TO6RX44cgFm1JA/zh-cn_image_0000001392717585.png?HW-CC-KV=V1&HW-CC-Date=20260909T180848Z&HW-CC-Expire=31536000000&HW-CC-Sign=42C0BD0E17AABACDC37FBC506BE4EEA495BF66475A0062AC87E2EDFE2289116D)
   3. 配置完成后，点击"保存"。创建成功后，在"代码"页面可查看到已创建的代码。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/i0FK-v3tRRqfcxgzAIztnw/zh-cn_image_0000001392846537.png?HW-CC-KV=V1&HW-CC-Date=20260909T180848Z&HW-CC-Expire=31536000000&HW-CC-Sign=413BB2C1C6B78EC1DD555B428FE00E910DDB98F64123CD076082D220FF3C16B3)

2. 配置"HUAWEI Analytics"代码。

   1. 在"新建代码"页面中输入代码名称后，将"扩展"类型选择为"HUAWEI Analytics"。
   2. 根据实际情况，配置"事件ID"、"事件参数"和"触发条件"相关参数。

      ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/lhZC9qszRm2CMuWK5Al8PQ/zh-cn_image_0000001343062478.png?HW-CC-KV=V1&HW-CC-Date=20260909T180848Z&HW-CC-Expire=31536000000&HW-CC-Sign=BBB201A788EFB7DC290BA46E9A25636486D5D9999DF4DE5B794D356500BFE959)
   3. 配置完成后，点击"保存"。创建成功后，在"代码"页面可查看到已创建的代码。
