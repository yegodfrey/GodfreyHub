# 礼品卡

#### 概述

礼品卡，即由商家发行的在指定商户和时间段内进行消费的预付费卡（如商超礼品卡等）。用户通过购买特定面额的礼品卡，并在结算时出示礼品卡所对应的付款码，即可完成消费。

Wallet Kit已提供礼品卡接入华为钱包的能力，商户可通过多种方式轻松将卡券集成到华为钱包中。

#### 处理过期卡券

在钱包应用的卡券详情页下如果卡券已过期则会自动标记一个过期的Icon。如果卡券满足过期或无效中的一个条件，系统就会将其移至"过期卡券"部分。

在HwWalletObject.fields.status.expireTime过期后的 24 小时内，卡券会随时移至"过期卡券"。

HwWalletObject.fields.status.state字段标记为expired、inactive或completed。  

#### 地理围栏通知

当前地理围栏通知暂时只支持通过REST API方式添加的卡券。

地理围栏概念

基于华为定位能力，当商户开发者通过REST API接口在模板中设置LocationList时，当前卡券即具备了地理围栏通知的能力，当用户距离设定的目标200米范围内即可触发地理围栏通知。  
![](https://media:101782807013304634)  
每种卡券每天最多通知5次，超过次数当天不会再下发地理围栏通知。

使用REST API接口添加地理围栏目标点坐标

定义模板信息时商户可设置LocationList，每个模板LocationList最多可设置3个目标点。

```
HwWalletObject hwWalletObject = new HwWalletObject(); 
.....
// 地理围栏信息 
List<Location> locationList = new ArrayList<>(); 
Location location = new Location(); 
location.setLongitude("113.0679603815");
location.setLatitude("25.6592051284");
locationList.add(location); 
fields.setLocationList(locationList); 
......
hwWalletObject.setFields(fields);
```

#### 跨设备同步能力

当前能力只开放给通过"App应用内、快应用、华为钱包CardStore方式"添加的卡券。

通过卡券包添加时卡片是以端到端的形式将卡券保存到华为钱包，华为服务器没有保存用户推送的卡券，所以无法做到帐号间共享。如果商户需要实现帐号间共享卡券能力则需要实现Wallet Kit提供的托管能力。

1. 在开发者联盟开放跨设备同步能力。

   <br />

   在"[服务创建](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-server-0000001050160377)"章节配置应用数据时可以选择是否开放跨设备同步能力，此时商户如果想实现此功能则需要开通此服务。

   ![](https://media:101782807013424637 "点击放大")

   <br />

2. 实现下载卡券包接口。

   <br />

   商户打开跨设备同步能力后，当商户推送卡券到华为钱包时，华为钱包会将卡券部分信息托管至华为服务器（只上传下载卡券的部分信息）。当用户在当前帐号下的其他设备登录时，华为钱包应用会去商户服务器下载已领取过的卡券包，商户服务器需实现"[商户服务器实现接口更新卡券](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-common-update-0000001050044317)"步骤供华为钱包调用下载卡券包。

   <br />
