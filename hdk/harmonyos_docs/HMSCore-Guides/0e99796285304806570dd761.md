# 按钮跳转配置

#### App页面跳转

use_type字段请固定设置10，use_button可设置按钮的文本及App跳转链接。

```
{
  "commonFields": [
 {
    "key": "use_type",
    "value": "10"
  },
  {
    "key": "use_button",
    "value": "{
      "packageName": "XXXX",
      "appName": "XXX",
      "schema": "XXX",
      "action": "XXX",
      "className": "XXX"
    }",
    "label": "按钮文本"
  }
  ]
}
```

![](https://media:101782807010489598)  
当配置schema时，优先使用schema跳转，否则，使用action或className跳转，如果要跳转到商户App，请在packageName中配置商户App包名，方便检查App是否安装，如果没安装，会提示取应用市场安装。在appName中配置商户App名称，方便提示时显示App名称。  

#### H5跳转

use_type字段请固定设置11，use_button可设置按钮的文本及H5跳转链接。

```
{
  "commonFields": [
    {
      "key": "use_type",
      "value": "11"
    },
    {
      "key": "use_button",
      "value": "H5链接",
      "label": "按钮文本"
    }
  ]
}
```
