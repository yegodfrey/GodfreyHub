# 征求用户意见

在法律有相应要求的情况下，您必须征得用户的同意才能使用其个人数据（例如OAID）来投放广告。

鲸鸿动能平台投放的广告包括个性化广告和非个性化广告。为了征求用户意见，鲸鸿动能平台提供了Consent SDK。如何使用Consent SDK参见[Consent SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-consent-settings-0000001075342977#section1627005915184)章节。鲸鸿动能JavaScript API提供相应的[方法](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-requestconsentupdate-0000001133473810)更新了用户的意见设置。示例代码如下所示：

```
ppsads.requestConsentUpdate({
    success: function(data) {
        console.log('requestConsentUpdate success data ' + JSON.stringify(data))
    },
    fail: function(data) {
        console.log('requestConsentUpdate fail data ' + JSON.stringify(data))
    }
})
```
