# 图片扫码场景

## 业务流程

Bitmap Mode图片扫码提供[decode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699#section57241230143611)和[decodeWithBitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699#section14774629143713)两种扫码接口，decode接口和decodeWithBitmap接口都支持识别Bitmap图像，但decode接口可以支持多码。2.11.0.300及以上版本推荐使用decode扫码接口。

使用Bitmap图片扫码的主要业务流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/3muMWfb6SkK7KnE_KZiZrQ/zh-cn_image_0000001627038089.png?HW-CC-KV=V1&HW-CC-Date=20260909T134704Z&HW-CC-Expire=31536000000&HW-CC-Sign=CED57E0E57D5E4A32038886361B58E6841423E309DCE9234FB936CDCC694969A "点击放大")

1. 用户打开App发起扫码请求。
2. 校验是否有相机权限和文件读取权限。
3. 权限验证通过后，调用华为统一扫码SDK的[decode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699#section57241230143611)或[decodeWithBitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699#section14774629143713)扫码接口。
4. 返回扫码结果。
5. App封装扫码结果返回给用户。

## decode接口开发步骤

> 说明
>
> 2.11.0.300及以上版本推荐使用。

1. 获取图片，将图片转化为Bitmap。

   ```java
   "Java"
   // data是Intent类型，data.getData是待扫描的条码图片URI
   Bitmap bitmap = MediaStore.Images.Media.getBitmap(this.getContentResolver(), data.getData());
   HmsScanFrame frame = new HmsScanFrame(bitmap);
   ```

   ```kotlin
   "Kotlin"
   // data是Intent类型，data.getData是待扫描的条码图片URI
   val bitmap = MediaStore.Images.Media.getBitmap(this.getContentResolver(), data.getData())
   ```

2. 初始化[HmsScanFrameOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsscanframeoptions-0000001521684732)，设置支持识别的码制式和设置Bitmap模式为图片扫码。

   您可以通过如下方式设置可选参数。
   * [setHmsScanTypes](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options-creator4-0000001050165974#section129951849205918)(int type)：设置码制式，默认识别[Scan Kit支持的码制式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/barcode-formats-supported-0000001050043981)，指定特定码制式，可以提高扫码速度。
   * [setPhotoMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options-creator4-0000001050165974#section174971719172918)(boolean photoMode)：设置Bitmap模式，此时需设置为true。默认值为fasle（相机扫码）。
   * [setMultiMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsscanframeoptions-creator-0000001521925456#section1154695817378)(boolean multiMode)：设置扫描单码或者多码，默认值为false（单码）。
   * [setParseResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsscanframeoptions-creator-0000001521925456#section183083555390)(boolean parseResul)：设置是否调用码值解析功能，若只需要原始码值结果，需设置为false，可提高扫码速度，且识别结果条码格式[getScanType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-hms-scan4-0000001050167739#section6980195925315)()类型将返回纯文本。默认值为true（解析码值结果）。

   ```java
   "Java"
   // "QRCODE_SCAN_TYPE"和"PDF417_SCAN_TYPE"表示只扫描QR和PDF417的码
   HmsScanFrameOptions option = new HmsScanFrameOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE| HmsScan.PDF417_SCAN_TYPE).setMultiMode(false).setParseResult(true).setPhotoMode(true).create();
   ```

   ```kotlin
   "Kotlin"
   // "QRCODE_SCAN_TYPE"和"PDF417_SCAN_TYPE"表示只扫描QR和PDF417的码
   val option = HmsScanFrameOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE| HmsScan.PDF417_SCAN_TYPE).setMultiMode(false).setParseResult(true).setPhotoMode(true).create()
   ```

3. 调用[ScanUtil](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699)的静态方法decode发起扫码请求并获取扫码结果对象[HmsScanResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsscanresult-0000001572628185)，其中包含的信息请参见[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-parsing-result-codes-0000001050043969)。如果您不需要指定只检测特定的码制式，此处的"options"可以置为"null"。

   ```java
   "Java"
   HmsScanResult result = ScanUtil.decode(BitmapActivity.this, frame, options);
   HmsScan[] hmsScans = result.getHmsScans();
   // 处理扫码结果
   if (hmsScans != null && hmsScans.length > 0) {
       // 展示扫码结果
       ...
   }
   ```

   ```kotlin
   "Kotlin"
   val hmsScansResult= ScanUtil.decode(this@BitmapActivity, frame, option)
   val hmsScans = hmsScansResult.hmsScans
   // 处理扫码结果
   if (hmsScans != null && hmsScans.size > 0) {
       // 展示扫码结果
       ...
   }
   ```

## decodeWithBitmap接口开发步骤

1. 获取图片，将图片转化为Bitmap。

   ```java
   "Java"
   // data是Intent类型，data.getData是待扫描的条码图片URI
   Bitmap bitmap = MediaStore.Images.Media.getBitmap(this.getContentResolver(), data.getData());
   ```

   ```kotlin
   "Kotlin"
   // data是Intent类型，data.getData是待扫描的条码图片URI
   val bitmap = MediaStore.Images.Media.getBitmap(this.getContentResolver(), data.getData())
   ```

2. 初始化[HmsScanAnalyzerOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options4-0000001050167925)，设置支持识别的码制式和设置Bitmap模式为图片扫码。

   您可以通过如下方式设置可选参数。
   * [setHmsScanTypes](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options-creator4-0000001050165974#section129951849205918)(int type)：设置码制式，默认识别[Scan Kit支持的码制式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/barcode-formats-supported-0000001050043981)，指定特定码制式，可以提高扫码速度。
   * [setPhotoMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options-creator4-0000001050165974#section174971719172918)(boolean photoMode)：设置Bitmap模式，此时需设置为true。默认值为fasle（相机扫码）。

   ```java
   "Java"
   // "QRCODE_SCAN_TYPE"和"DATAMATRIX_SCAN_TYPE"表示只扫描QR和DataMatrix的码
   HmsScanAnalyzerOptions options = new HmsScanAnalyzerOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE, HmsScan.DATAMATRIX_SCAN_TYPE).setPhotoMode(true).create();
   ```

   ```kotlin
   "Kotlin"
   // "QRCODE_SCAN_TYPE"和"DATAMATRIX_SCAN_TYPE"表示只扫描QR和DataMatrix的码
   val options = HmsScanAnalyzerOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE, HmsScan.DATAMATRIX_SCAN_TYPE).setPhotoMode(true).create()
   ```

3. 调用[ScanUtil](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699)的静态方法[decodeWithBitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699#section14774629143713)发起扫码请求并获取扫码结果对象[HmsScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-hms-scan4-0000001050167739)，其中包含的信息请参见[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-parsing-result-codes-0000001050043969)。如果您不需要指定只检测特定的码制式，此处的"options"可以置为"null"。

   ```java
   "Java"
   HmsScan[] hmsScans = ScanUtil.decodeWithBitmap(BitmapActivity.this, bitmap, options); 
   // 处理扫码结果 
   if (hmsScans != null && hmsScans.length > 0) { 
       // 展示扫码结果
       ...
   }
   ```

   ```kotlin
   "Kotlin"
   val hmsScans = ScanUtil.decodeWithBitmap(this@BitmapActivity, bitmap, options)
   // 处理扫码结果 
   if (hmsScans != null && hmsScans.size > 0) { 
       // 展示扫码结果
       ...
   }
   ```
