# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAnalyticsKit-WeChatMiniProgram)快速体验一个小程序的开发过程。

#### 开发环境

                * 微信小程序IDE开发工具，例如微信开发者工具。开发环境的搭建，具体可参考[微信小程序官方文档](https://developers.weixin.qq.com/miniprogram/dev/framework/)。 
                * 一台测试手机（用于真机测试）。 
                * 包管理工具npm，运行环境Node.js。 

#### 开发流程

您需要按照如下流程完成应用的开发工作。

开发步骤 | 说明  
---|---  
[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/miniprogram-config-agc-0000001152009062) | 在开发应用前，需要在AppGallery Connect中配置相关信息，包括：注册成为开发者、创建应用、开通华为分析服务。  
[_集成SDK_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/miniprogram-integrating-sdk-0000001198008599) | 通过本地或者在线方式集成SDK包。  
[_接入Analytics_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/miniprogram-accessing-0000001152168868) | 参见[ _API参考_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/miniprogram-api-overview-0000001152493170)中的API，实现数据上报功能。
