# 地图交互

## 概览

您可以通过控制地图手势开关以及内置UI控件的可见性，自定义用户与地图交互方式。详情请参见[Flutter示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-flutter-0000001208537346)。

## 地图相机

### 移动相机

地图的移动是通过模拟相机移动的方式实现的。您可以通过改变相机位置，来控制地图的可见区域。您要更改相机位置时，可创建不同类型的"CameraUpdate"对象。

您可以调用"HuaweiMapController"对象中的"animateCamera"或"moveCamera"方法来模拟相机移动。

示例代码如下：

```screen
HuaweiMapController mapController; 
... 
void _onMapCreated(HuaweiMapController controller) {mapController = controller;} 
...
```

**创建CameraUpdate** **对象的方式**

```screen
// 方式1：相机缩放级别加1，保持其他属性不变。
CameraUpdate cameraUpdate = CameraUpdate.zoomIn();
 
// 方式2：相机缩放级别减1，保持其他属性不变。
CameraUpdate cameraUpdate = CameraUpdate.zoomOut(); 
 
// 方式3：指定相机缩放级别的值，保持其他属性不变。
double zoom = 8; 
CameraUpdate cameraUpdate = CameraUpdate.zoomTo(zoom); 
 
// 方式4：按照指定的值增加或减少相机缩放级别。
double amount = 2; 
CameraUpdate cameraUpdate = CameraUpdate.zoomBy(amount); 
 
// 方式5：将相机移动到指定的中心点，并按照指定的值增加或减少相机缩放级别。
// 设置屏幕上的位置点。
double amount = 2; 
CameraUpdate cameraUpdate = CameraUpdate.(amount, Offset(2.0, 2.0)); 
 
// 方式6：设置相机的经纬度，保持其他属性不变。
LatLng latLng1 = new LatLng(31.5, 118.9); 
CameraUpdate cameraUpdate = CameraUpdate.newLatLng(latLng1); 
 
// 方式7：设置可见区域和填充。
double padding = 100; 
LatLng latLng1 = new LatLng(31.5, 118.9); 
LatLng latLng2 = new LatLng(32.5, 119.9); 
LatLngBounds latLngBounds = new LatLngBounds(latLng1, latLng2); 
CameraUpdate cameraUpdate = CameraUpdate.newLatLngBounds(latLngBounds, padding); 
 
// 方式8：设置相机的中心点和缩放级别。
double zoom = 10; 
LatLng latLng2 = new LatLng(32, 119); 
CameraUpdate cameraUpdate = CameraUpdate.newLatLngZoom(latLng2, zoom); 
 
// 方式9：按照指定的像素数滚动相机。
double x = 100; 
double y = 100; 
CameraUpdate cameraUpdate = CameraUpdate.scrollBy(x, y); 
 
// 方式10：指定相机位置。
CameraUpdate.newCameraPosition(CameraPosition( bearing: 2.2, target: LatLng(1, 1), tilt: 13, zoom: 13)); 
CameraUpdate cameraUpdate = CameraUpdate.newCameraPosition(cameraPosition);
```

**修改相机位置的方式**

您可以以动画或非动画模式来移动地图相机。

* 非动画模式下的相机移动

  ```screen
  CameraUpdate cameraUpdate = .... 
  mapController.moveCamera(cameraUpdate);
  ```

* 动画模式下的相机移动

  ```screen
  CameraUpdate cameraUpdate = .... 
  mapController.animateCamera(cameraUpdate);
  ```

### 区域约束

地图服务Flutter插件允许您设置地图相机边界。您可以使用"cameraTargetBounds"属性来指定"LatLngBounds"对象来约束相机目标，以便在用户滚动地图相机时，相机目标不会超出指定的边界。

如果该参数设置为null或CameraTargetBounds.unbounded，则地图相机边界将被清除。

## UI控件和手势

您可以使用"HuaweiMap"对象中的属性来控制UI控件的可见性，以及设置地图手势的开关。UI控件包括缩放控件、指南针以及我的位置图标。

### 缩放控件

地图服务Flutter插件提供内置的缩放控件，默认开启。

示例代码如下：

```screen
// 设置是否开启缩放控件。
HuaweiMap( 
    zoomControlsEnabled: false, 
    ...
```

### 指南针

地图服务Flutter插件提供指南针功能。默认情况下，指南针显示在地图的右上角。如果指南针已开启且地图未朝向正北，则地图右上角会显示指南针图标。用户可以点击指南针图标来旋转地图，使其朝向正北。如果启用了指南针且地图朝向正北，指南针图标将隐藏。如果指南针被禁用，指南针图标将不会显示。

示例代码如下：

```screen
// 设置是否开启指南针。
HuaweiMap( 
    compassEnabled: false, 
    ...
```

### 我的位置图标

启用"我的位置"图标之前，您需要确保已经开启了android.permission.ACCESS_FINE_LOCATION和android.permission.ACCESS_COARSE_LOCATION权限，以及开启了"我的位置"图层。当启用了"我的位置"图标功能时，该图标才会显示在地图上。

示例代码如下：

```screen
// 开启我的位置图层。
HuaweiMap( 
    myLocationEnabled: true, 
    ... 
 
// 开启显示"我的位置"图标功能。
HuaweiMap( 
    myLocationButtonEnabled: true, 
    ...
```

### 地图手势

您可以使用HuaweiMap类中的属性来启用或禁用地图手势。

* 缩放手势：用户可以双击地图将缩放级别提高1（放大），也可以用两个手指点击地图将缩放级别降低1（缩小）。

  ```screen
  // 设置是否开启缩放手势。
  HuaweiMap( 
      zoomGesturesEnabled: false, 
      ...
  ```

* 滚动手势：用户可以拖动地图进行移动。

  ```screen
  // 设置是否开启滚动手势。
  HuaweiMap( 
      scrollGesturesEnabled: false, 
      ...
  ```

* 倾斜手势：用户可以将两个手指在地图上进行向下或向上移动来改变地图的倾斜度。

  ```screen
  // 设置是否开启倾斜手势。
  HuaweiMap( 
      tiltGesturesEnabled: false, 
      ...
  ```

* 旋转手势：用户可以用两个手指来旋转地图。

  ```screen
  // 设置是否开启旋转手势。
  HuaweiMap( 
      rotateGesturesEnabled: false, 
      ...
  ```

## 事件侦听

本节介绍如何设置地图点击事件、长按事件和相机移动事件的侦听器。

### 地图事件侦听

* **点击事件**

  ```screen
  HuaweiMap( 
       onClick: (LatLng latLng) { log("Map Clicked at $latLng"); }, 
       ...
  ```

* **长按事件**

  ```screen
  HuaweiMap( 
       onLongPress: (LatLng latlng) { log("Map LongClicked at $latlng"); }, 
       ...
  ```

### 相机移动事件侦听

设置相机移动事件侦听器后，应用层可侦听相机移动状态。

* 当相机开始移动时，将调用"onCameraMoveStarted"方法。
* 当相机移动或用户与地图交互时，会多次调用"onCameraMove"方法。
* 当相机停止移动时，将调用"onCameraIdle"方法。

  ```screen
  HuaweiMap( 
       onCameraMove: (CameraPosition pos) => { print( "onCameraMove: ${pos.target.lat} : ${pos.target.lng}") }, 
       onCameraIdle: () { print("onCameraIdle"); },  
       onCameraMoveStarted: () { print("onCameraMoveStarted"); }), 
       ...
  ```

### 其他事件侦听

* **标记点击事件**

  ```screen
  Marker( 
       markerId: MarkerId('marker_id_0'), 
       position: LatLng(41.012959, 28.997438), 
       clickable: false, 
       onClick: () { 
           log('marker #0 clicked'); 
       }, 
   ...
  ```

* **信息窗点击事件**

  ```screen
  Marker( 
       markerId: MarkerId('marker_id_1'), 
       position: LatLng(41.002919, 28.980701), 
       infoWindow: InfoWindow( 
           title: 'Marker Title #1', 
           snippet: 'Marker Desc #1', 
           onClick: () { 
               log("infoWindow clicked"); 
           }), 
           onClick: () { 
               log('marker #1 clicked'); 
           }, 
   ...
  ```
