# 海拔

此数据类型记录用户在一段时间内的地理海拔位置。
> 说明
>
> * 高原血氧海拔：仅部分华为智能穿戴设备支持高原血氧海拔数据自动持续检测，需要用户在"华为运动健康App > 健康 > 血氧卡片 > 设置 > 高原关爱"查看当前使用的穿戴设备是否支持，并开启高原血氧海拔检测。
> * 运动记录海拔：部分支持气压传感器的华为智能穿戴设备在运动过程中能够持续测量海拔采样数据。

## OAuth权限

联盟卡片申请的权限名称：锻炼记录 > 距离、爬高与海拔

* 读权限：Scopes.HEALTHKIT_DISTANCE_READ
* 写权限：Scopes.HEALTHKIT_DISTANCE_WRITE

## 原子采样明细数据类型

* 名称：com.huawei.instantaneous.altitude
* Android SDK类型常量：DataType.DT_INSTANTANEOUS_ALTITUDE
