# 心率告警健康记录

本章节提供通过华为Health Service Kit服务端REST API写入以及读取用户心率告警数据的方法示例。心率告警记录数据类型包括com.huawei.health.record.tachycardia（心率过速）和com.huawei.health.record.bradycardia（心率过缓），心率告警明细数据类型com.huawei.instantaneous.heart_rate详情请参见[心率](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/heart-rate-0000001131423780)。

心率告警数据类型对应的Scope为：

* 读权限：https://www.huawei.com/healthkit/hearthealth.read
* 写权限：https://www.huawei.com/healthkit/hearthealth.write

心率明细对应的Scope为：

* 读权限：https://www.huawei.com/healthkit/heartrate.read
* 写权限：https://www.huawei.com/healthkit/heartrate.write

## 读取心率告警数据

通过HealthRecord读取心率告警数据。

**HTTP请求，** 请参见[数据类型健康记录查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/get-health-record-by-datatype-0000001142843917#section9701181322219)接口

```screen
GET 
https://health-api.cloud.huawei.com/healthkit/v2/healthRecords?startTime=***&endTime=***&dataType=***&subDataType=***
```

**请求示例**

```screen
GET 
https://health-api.cloud.huawei.com/healthkit/v2/healthRecords?startTime=1609257600000000000&endTime=1609344000000000000&dataType=com.huawei.health.record.tachycardia&subDataType=com.huawei.instantaneous.heart_rate
```
