# 帐号关联

对于有自己的游戏帐号并且支持存档的游戏，当用户以华为帐号登录游戏时，为保证用户可以在华为帐号下继续之前的游戏，您需要根据以下不同场景进行不同的操作。

* 如果当前华为帐号未关联任何游戏帐号，且当前游戏帐号也未关联任何华为帐号，您可选择自动或提示用户确认后将当前登录华为帐号与当前游戏帐号关联。

* 如果当前华为帐号已与玩家的其他游戏帐号关联，且当前游戏帐号已与其他华为帐号关联，提示并让用户选择执行以下操作：

  * 加载当前登录华为帐号关联的游戏帐号（存档）。
  * 继续当前游戏。
* 如果当前华为帐号已与玩家的其他游戏帐号关联，但当前游戏帐号未与其他华为帐号关联，提示并让用户选择执行以下操作：

  * 加载当前登录华为帐号关联的游戏帐号（存档）。
  * 继续当前游戏。
* 更新当前登录华为帐号绑定的游戏帐号为当前游戏帐号。
