# 读取实时数据

应用集成Health Service kit后，通过调用[AutoRecorderController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/autorecordercontroller-0000001050091345)类中的接口来读取用户实时数据， 如下：

* [启动实时数据读取](#section21929205548)（[startRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/autorecordercontroller-0000001050091345#section35051641993)）
* [停止实时数据读取](#section1981445413548)（[stopRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/autorecordercontroller-0000001050091345#section109711928194718)）

#### 启动实时数据读取

启动实时数据读取时，需明确表明需要启动哪一种类型的数据实时读取。当前支持实时读取的数据类型仅有：

步数总量：[DT_CONTINUOUS_STEPS_TOTAL](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section32912131568)  
![](https://media:901788166652411171)  
* 目前通过实时数据接口读取步数数据，仅支持手机上传的实时步数。
* 启动实时读取步数总量时，为使得到的步数总量数据更加精确，建议开发者将接口调用实现在前台Service中。
* 调用实时数据读取接口时，先确认是否已同意申请HMS Core应用健身运动权限，确认步骤： 华为手机（Android Version \>= 10.0）用户申请权限步骤：打开"设置 \> 应用（和服务） \> 应用管理"，搜索"HMS Core"，打开"权限"，允许"健身运动"。

  非华为手机用户申请权限步骤："打开应用管理 \> HMS Core应用 \> 权限管理 \> 后台弹出界面"。
* 通过HuaweiHiHealth.getAutoRecorderController获取AutoRecorderController时，若传入Activity对象（用于应用包含界面的场景调用），支持触发HMS Core版本强制升级，若传入Context对象（用于应用无界面的场景调用），不支持触发HMS Core版本强制升级。  
使用DT_CONTINUOUS_STEPS_TOTAL数据类型启动实时步数读取。

```
// 请注意此处的this为Activity对象
final AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(this);

// 创建数据回调对象onSamplePointListener打印步数数据
private OnSamplePointListener onSamplePointListener = new OnSamplePointListener() {
    @Override
    public void onSamplePoint(SamplePoint samplePoint) {
        for (Field field : samplePoint.getDataType().getFields()) {
            Log.i("AutoRecorderTest", "Field: " + field.getName() + " Value: " + samplePoint.getFieldValue(field));
        }
    }
};
// 以DT_CONTINUOUS_STEPS_TOTAL为例，启动总步数的实时读取，总步数将以0步开始，上报用户此后的总步数
// 总步数将以固定时间间隔实时回调数据给用户，直至用户结束读取，总步数将停止回调
DataType dataType = DataType.DT_CONTINUOUS_STEPS_TOTAL;
controller.startRecord(dataType, onSamplePointListener).addOnCompleteListener(new OnCompleteListener<Void>() {
    @Override
    public void onComplete(Task<Void> taskResult) {
        // 接口不会一直返回成功，所以需要增加异常回调的处理，目前接口失败的原因包括：应用没有授权，类型不支持
        if (taskResult.isSuccessful()) {
            Log.i("AutoRecorderTest","onComplete startRecordByType Successful");
        } else {
            Log.i("AutoRecorderTest","onComplete startRecordByType Failed");
        }
    }
}).addOnSuccessListener(new OnSuccessListener<Void>() {
    @Override
    public void onSuccess(Void result) {
        Log.i("AutoRecorderTest","onSuccess startRecordByType Successful");
    }
}).addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        Log.i("AutoRecorderTest","onFailure startRecordByType Failed: " + e.getMessage());
    }
});
```

#### 停止实时数据读取

停止实时数据读取时，需明确表明需要停止哪一种类型的数据实时读取。当前仅支持停止实时读取的数据类型有：

步数总量：[DT_CONTINUOUS_STEPS_TOTAL](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section32912131568)  
使用[DT_CONTINUOUS_STEPS_TOTAL](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section32912131568) 数据类型停止实时步数读取。

```
// 请注意此处的this为Activity对象
final AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(this);

// 创建回调对象onSamplePointListener
private OnSamplePointListener onSamplePointListener = new OnSamplePointListener() {
    @Override
    public void onSamplePoint(SamplePoint samplePoint) {
    }
};
// 调用停止实时数据读取接口，传入待停止数据类型DT_CONTINUOUS_STEPS_TOTAL
controller.stopRecord(DataType.DT_CONTINUOUS_STEPS_TOTAL, onSamplePointListener)
    .addOnCompleteListener(new OnCompleteListener<Void>() {
        @Override
        public void onComplete(Task<Void> taskResult) {
            // 接口不会一直返回成功，所以需要增加异常回调的处理，目前接口失败的原因包括：应用没有授权，类型不支持
            if (taskResult.isSuccessful()) {
                Log.i("AutoRecorderTest","onComplete stopRecordByType Successful");
            } else {
                Log.i("AutoRecorderTest","onComplete stopRecordByType Failed");
            }
        }
    })
    .addOnSuccessListener(new OnSuccessListener<Void>() {
        @Override
        public void onSuccess(Void result) {
            Log.i("AutoRecorderTest","onSuccess stopRecordByType Successful");
        }
    })
    .addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            Log.i("AutoRecorderTest","onFailure stopRecordByType Failed: " + e.getMessage());
        }
    });
```
