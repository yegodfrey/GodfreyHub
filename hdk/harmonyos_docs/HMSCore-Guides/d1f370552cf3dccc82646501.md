# 多发送者功能

从Push SDK 5.0.4版本开始，推送服务提供了多发送者功能，该功能支持多个发送者向某个应用推送消息。举例来说，华为钱包在手机上是一个应用，华为商城和华为视频想给安装了华为钱包的用户推送华为商城促销和华为视频会员充值有优惠的营销消息，华为钱包是目标应用，华为商城和华为视频都是发送者，该场景就需要使用多发送者能力。  

#### 配置多发送者权限

目标应用开发者登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"开发与服务"，在项目列表中找到您的项目，通过"增长 \> 推送服务 \> 配置"导航到"配置"页签，添加其他发送者ID（即发送者应用归属的项目ID），为其他发送者配置向您的应用发送消息的权限。

#### 客户端应用开发

1. 目标应用开发者在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站上点击"开发与服务"，在项目列表中找到您的项目，将"项目设置"里的"[agconnect-services.json](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-integrating-sdk-0000001050040084#section126221331197)"文件拷贝到您Android工程应用级根目录下。

   请确认agconnect-services.json文件中含有project_id字段，如果没有，您需重新下载该文件，否则调用[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section197651125175917)(subjectId)会报错。

   <br />

2. 目标应用开发者[集成Push SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-integrating-sdk-0000001050040084)，并通过[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section197651125175917)方法为发送者申请Push Token，这个方法的入参为发送者的项目ID。

   <br />

   ```
   "Java"
   public class MainActivity extends AppCompatActivity {
       private void getSubjectToken() {
           // 创建一个新线程
           new Thread() {
               @Override
               public void run() {
                   try {
                       // 发送者的项目ID
                       String projectId = "the id of sender";                    
                       // 目标应用为发送者申请token
                       String token = HmsInstanceId.getInstance(MainActivity.this).getToken(projectId);
                       Log.i(TAG, "get token success");

                       // 判断token是否为空
                       if(!TextUtils.isEmpty(token)) {
                           sendRegTokenToServer(token);
                       }
                   } catch (ApiException e) {
                       Log.e(TAG, "get token failed, " + e);
                   }
               }
           }.start();
       }
       private void sendRegTokenToServer(String token) {
           Log.i(TAG, "sending token to server.");
       }
   }
   ```

   ```
   "Kotlin"
   class MainActivity : AppCompatActivity {
       private fun getSubjectToken() {
           // 创建一个新线程
           object : Thread() {
               override fun run() {
                   try {
                       // 发送者的项目ID
                       val projectId = "the id of sender"
                       // 目标应用为发送者申请token
                       val token = HmsInstanceId.getInstance(this@MainActivity).getToken(projectId)
                       Log.i(TAG, "get token success")

                       // 判断token是否为空
                       if(!TextUtils.isEmpty(token)) {
                           sendRegTokenToServer(token)
                       }
                   } catch (e: ApiException) {
                       Log.e(TAG, "get token failed, $e")
                   }
               }
           }.start()
       }
       private fun sendRegTokenToServer(token: String?) {
           Log.i(TAG, "sending token to server.")
       }
   }
   ```

   <br />

   EMUI 10.0版本以下的华为终端设备需要从[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section343314205)中接收目标应用为发送者申请的Push Token。  

   ```
   "Java"
   @Override
   public void onNewToken(String token, Bundle bundle) {         
       // 获取push token
       Log.i(TAG, "received refresh token");
       
       // 判断push token是否为空
       if (!TextUtils.isEmpty(token)) {
           refreshedTokenToServer(token);
       }
   }
   private void refreshedTokenToServer(String token) {
       Log.i(TAG, "sending token to server.");
   }
   ```

   ```
   "Kotlin"
   override fun onNewToken(token: String?, bundle: Bundle?) {    
       // 获取push token
       Log.i(TAG, "received refresh token")
       
       // 判断push token是否为空
       if (!token.isNullOrEmpty()) { 
           refreshedTokenToServer(token)    
       }
   }
   private fun refreshedTokenToServer(token: String) { 
       Log.i(TAG, "sending token to server.")
   }
   ```

   <br />

3. 目标应用开发者拿到Push Token后将其传给发送者，发送者获取Push Token后可以给目标应用[推送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-android-0000001136294192)。

   <br />

   * 通知栏消息：当用户点击通知栏消息后，您可以通过在intent中读取"_hw_from"属性来区分发送者，详情可参见[自定义点击消息动作](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/andorid-basic-clickaction-0000001087554076#ZH-CN_TOPIC_0000001700731549__li13256137181616)。
   * 透传消息：在EMUI 9.1.0版本之后，您可以调用RemoteMessages里的[getFrom](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/remotemessage-0000001050171874#section41231931104710)方法，根据返回值来区分发送者。

   <br />

#### 服务端开发指导

1. 发送者服务端获取鉴权信息，可以通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)或者[基于服务账号生成鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)方式。
2. 发送者服务端调用下行消息API为目标应用推送消息，更多消息体内容请参见[下行消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#section8686112674319)，相关错误码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#section13968115715131)。

   <br />

   HTTPS POST URL：

   ```
   POST https://push-api.cloud.huawei.com/v1/[clientid]/messages:send
   ```

   "\[clientid\]"请替换为目标应用的Client ID（在[项目设置页面](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137#section125831926193110)获取）。

   ```
   Content-Type: application/json; charset=UTF-8
   Authorization: Bearer CF3Xl2XV6jM***************vNm3WccUIaDg== 
   ```

   * 请求消息头中的Authorization参数为通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)获取的Access Token或者[基于服务账号生成的鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)。
   * Access Token如果是通过curl命令或者Postman等工具手工获取，需注意JSON字符串中的转义符，请把"\\/"还原为"/"，替换后才是正确的Access Token。如果是从代码运行获取，则采用任意的第三方库均能正确解析JSON串，获取到正确的Access Token。
