# 通知栏消息覆盖展示

通知栏消息到达终端设备展示后，如果用户没有点击或者清理，您可以通过推送服务端REST API设置新推送的消息覆盖之前展示的消息。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095826.90898979475596297841571747611587:50001231000000:2800:C359969F475111472C89AE992784DFDC5401FA0887C8844389AC8371813DF4A7.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
* 您可以指定"tag"、"notify_id"、"group"三个字段来实现消息覆盖功能。三个字段是互斥的，只能使用一个。如果三个字段都设置了，字段优先级为："group"\>"tag"\>"notify_id"。
* "tag"、"notify_id"字段的适用版本请参见[message.android.notification.tag](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/restrictions-0000001050040064#ZH-CN_TOPIC_0000001700850777__p6580172224112)、[message.android.notification.notify_id](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/restrictions-0000001050040064#ZH-CN_TOPIC_0000001700850777__p8514144955020)。  

|通知栏消息展示覆盖设置方式|说明|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|"[tag](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p231917812315)"字段（值为字符串）|具有相同"tag"标签值的新消息覆盖老的消息。 "tag"字段消息体示例： ``` { "message": { "notification": { "title": "message title", "body": "message body" }, "android": { "notification": { "tag": "tagBoom", "click_action": { "type": 3 } } }, "token": ["pushtoken1"] } } ```|
|"[notify_id](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p632058162311)"字段（值为整数）|"notify_id"标识在通知栏显示时的消息。不同的通知栏消息可以有相同的"notify_id"，实现新的通知栏消息覆盖老的。 "notify_id"字段消息体示例： ``` { "message": { "notification": { "title": "message title", "body": "message body" }, "android": { "notification": { "notify_id": 123, "click_action": { "type": 3 } } }, "token": ["pushtoken1"] } } ```|
|"[group](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p332019882318)"字段（值为字符串）|相同"group"的多条消息，只展示最新的一条消息。 "group"字段示例报文： ``` { "message": { "notification": { "title": "message title", "body": "message body" }, "android": { "notification": { "group": "espace", "click_action": { "type": 3 } } }, "token": ["pushtoken1"] } } ```|
