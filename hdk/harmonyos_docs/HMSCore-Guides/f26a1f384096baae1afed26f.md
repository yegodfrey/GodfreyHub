# 开发准备

## 集成SDK

针对Android Studio开发环境，华为提供了Maven仓集成方式的SDK包。在开始开发前，开发者需要将华为支付服务SDK集成到开发者的Android Studio开发环境中。

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

### 添加应用的AppGallery Connect配置文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到开发者的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fe/v3/Bra0-j9ES-C7ehqVpil5CA/zh-cn_image_0000002512279907.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=65C4B041A060413C1A26A428E87C5EC9A02AD789E55BA0A7AE99F481894F2410 "点击放大")

4. 将"agconnect-services.json"文件拷贝到应用级根目录下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/07/v3/_-ZJmv_ZTtKOBe-GoxmGFg/zh-cn_image_0000002480160038.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C3CF138D8D715D00D67FFB3B81A7DC3A3BA7C59875DAE18B11EA1E58D387292)

### 配置SDK的Maven仓地址

参见[Maven仓库地址配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-maven-repository-0000001970825281#section63821917164110)。

### 添加SDK编译依赖

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

1. 打开应用级"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/1dB-v6UuS6exf_gv8hC_xA/zh-cn_image_0000002512199933.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=69A99E8F704144E18800376F939F10382EF5FAFC19384C1852E24C0881067F6D)


2. 在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:paymentservice:6.12.0.300'
   }
   ```

   > 说明
   >
   > SDK版本号索引请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041#section163461949192517)，例如：implementation 'com.huawei.hms:paymentservice:6.12.0.300'。
3. 在完成以上的配置后，点击工具栏中的gradle同步图标，完成"build.gradle"文件的同步，将相关依赖下载到本地。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/jM3SrntzT7u37fFeLYqNUg/zh-cn_image_0000002480160034.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=48F50FFBADF33589ED4EC88FA8D82240A1B30BE929A48A7ABFD1DBE867CB0A89)
   > 说明
   >
   > 1、如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
   >
   > 2、若开发者的APP有添加Gson依赖且依赖华为支付服务SDK后编译或运行时报Gson三方依赖包冲突，需要使用exclude排除Gson依赖冲突，代码如下：
   >
   > ```screen
   > implementation 'com.huawei.hms:paymentservice:6.12.0.300'{
   >     exclude group: 'com.google.code.gson'
   > }
   > ```
