# 配置AppGallery Connect

在开发应用前，需要在AppGallery Connect中配置相关信息。

## 创建应用

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。

## 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法可参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

## 获取应用级ID及Token

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/console#/serviceCards/)网站，在"凭证 > 创建凭证 > 应用级客户端ID"中创建应用级客户端ID。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250620094404.68281230820980715061801666510142:50001231000000:2800:0E2DB3BBAFA983F23EABA4C1052EAB7C2D51766C2E156ACDC70787865BA3D417.png)

2. 根据提示填写您的App基础信息，填写完成后点击"创建"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250620094404.57357557019709465678450287435848:50001231000000:2800:A1430B1CF5E0104842435F2FCF4C57B4CC7E640C96EDDDA37E36554CDF6858D0.png)

3. 创建成功后，点击"API列表"，开启Search Kit权限。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250620094404.33742410301790362503788819724934:50001231000000:2800:6349C6DFCDB2DC8A01D2372C03D9E66057AEA17E8C06650294793E111774BDF1.png)

4. 点击右上角的"添加新的API"，获取Search Kit权限。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250620094404.16496598573695238329217429686068:50001231000000:2800:9DA8A605AB81175EFB399A8C9D33C1E9629306367D83490E49A93B2AC48AA6C9.png "点击放大")

5. 在"适用API"栏目找到"搜索服务"，点击"添加"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250620094404.65930781765209991488224587667362:50001231000000:2800:39BCB43753E717C03493E9F77E0635A0F401C1BFB73E357D42E98B572ADDFDFF.png)

   添加完成后，您可以在"凭证"首页查看获取到的客户端ID和密钥。

6. 获取Token，具体步骤请参见[客户端模式（Client Credentials）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/open-platform-oauth-0000001053629189#section12493191334711)。
