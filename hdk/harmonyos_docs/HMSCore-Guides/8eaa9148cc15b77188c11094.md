# 集成SDK

地图服务（Map Kit）给您提供一套地图开发调用的SDK，地图数据覆盖超过200个国家和地区，支持70+种地图展示与搜索语言，方便您轻松地在应用中集成地图相关的功能，全方位提升用户体验。

SDK名称：华为地图SDK

版本号：6.4.0.302

SHA256：9a6194eb80de7c87c705e14d8d1e34329ffae757f6a7510e50065128655c6c17

开发者：华为软件技术有限公司

个人信息处理规则：[SDK隐私声明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sdk-ios-data-security-0000002258022142)

合规指引：[SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/personal-ios-data-0000002292575389)

## 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.plist"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要集成SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.plist"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/HRM7EZeTRi69G7jyYXTWRQ/zh-cn_image_0000001242964435.png?HW-CC-KV=V1&HW-CC-Date=20260917T022230Z&HW-CC-Expire=31536000000&HW-CC-Sign=E37AF2359B8DE473A404E8FF20E3C52CB028ECDB1F03697B2C6FA68EA5C5F888 "点击放大")

4. 将"agconnect-services.plist"文件拷贝到应用级根目录下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/5remhswmSH6iJMh5vZm7DQ/zh-cn_image_0000001242644445.png?HW-CC-KV=V1&HW-CC-Date=20260917T022230Z&HW-CC-Expire=31536000000&HW-CC-Sign=B95173242EA43C1BE422C33A50CF168C9FA7FFA743951C901715FB4D443FD033 "点击放大")
   > 说明
   > * 在获取"agconnect-services.plist"文件前，请确保已开通地图服务（开通步骤参见[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-config-agc-0000001242634549#section721mcpsimp)）。
   >
   >
   > * 如果您在"开发"模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的"agconnect-services.plist"，并替换iOS项目根目录下已有的文件。

## 在Xcode项目中集成SDK（手动方式集成）

1. 下载Map iOS SDK包，并解压。

   下载地址：[iOS SDK下载](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/ios-sdk-download-0000001248038737)。

2. 在Xcode工程内右键选择"Add file to 工程名"，随后左键去选择要导入的"framework"文件，点击"Add"即可完成SDK的添加。添加的文件包括：HMapKit.framework、AGConnectCore.framework、GRS.framework、HAFormalAnalytics.framework、HMFoundation.framework、ZipArchive.framework。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ae/v3/wj7MlJQIQlCK0y-XfcoZAQ/zh-cn_image_0000001207951304.png?HW-CC-KV=V1&HW-CC-Date=20260917T022230Z&HW-CC-Expire=31536000000&HW-CC-Sign=271EFE622778E7673919B1AA370E10E2E85A1E63D1C85C3947F865F14111985D "点击放大")
   > 说明
   >
   > 待导入的framework库必须和工作空间在相同的磁盘空间里。如果不在，您可以选择注意勾选"Copy items if needed"和"Create groups"，将待导入的framework库工程文件复制到工作空间。

3. 在Xcode工程内右键选择"Add Files To..."，从HMapKit.framework中，把资源文件HMapKit.bundle添加到工程中。再从HAFormalAnalytics.framework中，把资源文件HAFormal.bundle添加到工程中。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/kCfbHBmKTGGKe9_BL9sIXQ/zh-cn_image_0000001252791429.png?HW-CC-KV=V1&HW-CC-Date=20260917T022230Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2671E8A9D770F2203EA46E12AB29040E4C7EDFF43E64845462F765D2AC8BBDF "点击放大")
   > 说明
   >
   > 待导入的framework库必须和工作空间在相同的磁盘空间里。如果不在，您可以选择注意勾选"Copy items if needed"和"Create groups"，将待导入的framework库工程文件复制到工作空间。

4. 添加编译选项：在"TARGETS > Build Settings > > Other Linker Flags"增加：-ObjC 。注意：O和C大写。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fe/v3/DExytQgHTZu5oOBuiZz9rg/zh-cn_image_0000001197924558.jpg?HW-CC-KV=V1&HW-CC-Date=20260917T022230Z&HW-CC-Expire=31536000000&HW-CC-Sign=CB9C61295FC4BDA627A375A2A600B2F6067919BA9BE01598968B1D1CB04D1B9F)

5. 添加依赖库：GLKit.framework、libbz2.tbd、libc++.tbd、libz.tbd。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/YyBRC6sVSaCpt9LwGKhL8Q/zh-cn_image_0000001252551707.png?HW-CC-KV=V1&HW-CC-Date=20260917T022230Z&HW-CC-Expire=31536000000&HW-CC-Sign=790EEA604D79B5D1611E3BA44D97FB194C9640C0A698325722134AD988120B49 "点击放大")
