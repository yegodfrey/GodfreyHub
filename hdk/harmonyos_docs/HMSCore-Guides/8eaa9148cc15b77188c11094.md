# 集成SDK

#### 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.plist"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要集成SDK的应用。
3. 在"项目设置 \> 常规"页面的"应用"区域，点击"agconnect-services.plist"下载配置文件。

   <br />

   ![](https://media:301772613523904806 "点击放大")

   <br />

4. 将"agconnect-services.plist"文件拷贝到应用级根目录下。

   <br />

   ![](https://media:301772613523943807 "点击放大")  
   ![](https://media:301772613523968808)  
   * 在获取"agconnect-services.plist"文件前，请确保已开通地图服务（开通步骤参见[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-config-agc-0000001242634549#section721mcpsimp)）。

   <!-- -->

   * 如果您在"开发"模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的"agconnect-services.plist"，并替换iOS项目根目录下已有的文件。

   <br />

#### 在Xcode项目中集成SDK（手动方式集成）

1. 下载Map iOS SDK包，并解压。

   <br />

   下载地址：[iOS SDK下载](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/ios-sdk-download-0000001248038737)。

   <br />

2. 在Xcode工程内右键选择"Add file to 工程名"，随后左键去选择要导入的"framework"文件，点击"Add"即可完成SDK的添加。添加的文件包括：HMapKit.framework、AGConnectCore.framework、GRS.framework、HAFormalAnalytics.framework、HMFoundation.framework、ZipArchive.framework。

   <br />

   ![](https://media:301772613524011809 "点击放大")  
   ![](https://media:301772613524033810)  
   待导入的framework库必须和工作空间在相同的磁盘空间里。如果不在，您可以选择注意勾选"Copy items if needed"和"Create groups"，将待导入的framework库工程文件复制到工作空间。

   <br />

3. 在Xcode工程内右键选择"Add Files To..."，从HMapKit.framework中，把资源文件HMapKit.bundle添加到工程中。再从HAFormalAnalytics.framework中，把资源文件HAFormal.bundle添加到工程中。

   <br />

   ![](https://media:301772613524060811 "点击放大")  
   ![](https://media:301772613524083812)  
   待导入的framework库必须和工作空间在相同的磁盘空间里。如果不在，您可以选择注意勾选"Copy items if needed"和"Create groups"，将待导入的framework库工程文件复制到工作空间。

   <br />

4. 添加编译选项：在"TARGETS \> Build Settings \> \> Other Linker Flags"增加：-ObjC 。注意：O和C大写。

   <br />

   ![](https://media:301772613524124813)

   <br />

5. 添加依赖库：GLKit.framework、libbz2.tbd、libc++.tbd、libz.tbd。

   <br />

   ![](https://media:301772613524178814 "点击放大")

   <br />

   <br />
