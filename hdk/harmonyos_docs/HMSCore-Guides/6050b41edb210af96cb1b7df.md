# 接收延迟付款型支付关键事件通知

如果您的应用接入了华为IAP延迟付款型支付功能，建议您在开发者联盟[配置订单/订阅通知地址](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050033072#section15820113193119)，用于接收华为应用内支付服务器发送的延迟付款型支付关键事件通知。具体请参见[延迟付款型支付关键事件通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-notifications-about-pending-payment-events-0000001230063777)说明。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135213.50851789039385416274992702727183:50001231000000:2800:65B59E3AE99C11E3DD07F5130D832A251A28B7A9534F53027754ED7D2D3C659F.png)  
建议所有提供延迟付款型支付功能的App均配置该通知地址，以便接收延迟付款型支付关键事件通知，为顾客提供更好、更及时的服务。另外，通知地址必须基于HTTPS并且配置有商业域名机构颁发的证书。
