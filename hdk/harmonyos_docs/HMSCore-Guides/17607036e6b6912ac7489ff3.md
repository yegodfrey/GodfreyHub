# 概述

版本是配置在某一个时间点的快照，可用于对配置的不同阶段进行记录，您可以在任何时候为配置项目创建版本以保存当前配置的最新状态。版本创建后，可以点击版本名称进入到版本详情页面查看版本信息。在版本详情页面，您还可以执行版本预览、发布等操作，版本需要发布后才能被终端设备上的应用自动加载。
