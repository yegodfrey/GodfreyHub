# Training Status

当前运动设备的工作状态

|**参数**|**格式**|**取值**|**含义**|
|:---------------------|:-----|:--------|:---------------------------|
|Flags|Bit0|1|是否存在Training Status参数|
|Flags|Bit1|0|是否存在Training Status String参数|
|Flags|Bit2-7|0|保留|
|Training status|Uint8|0x00|其他未知状态|
|Training status|Uint8|0x01|IDLE状态|
|Training status|Uint8|0x0D|正在跑步时的状态|
|Training status|Uint8|0x0E|Pre-workout，开启前读秒时状态|
|Training status|Uint8|0x0F|Post-workout，结束后读秒时状态|
|Training status|Uint8|0x10-0xFF|保留|
|Training Status String|Octet|-|无需支持|
