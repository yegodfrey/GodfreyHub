# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_HMSAds-OAID)快速体验一个应用的开发过程。

## 开发环境

* JDK 1.7及以上


* 安装Android Studio 3.X及以上
  * minSdkVersion 19及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 4.1及以上（推荐）


* 测试应用的设备：EMUI 3.0及以上的华为手机

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-config-agc-0000001056060573)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-config-agc-0000001056060573#section113257842115)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-config-agc-0000001056060573#section1536810425221)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-integrating-sdk-0000001056460552)|在完成[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)操作后，您需要先将鲸鸿动能SDK集成到您的开发环境中。|
|3|[获取OAID信息（SDK方式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-obtaining-oaid-sdk-0000001050064988)|媒体App、广告平台、三方监测平台等开发者，可集成鲸鸿动能SDK获取华为设备上的OAID。|
|3|[获取转化跟踪参数（SDK方式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-obtaining-installreferrer-sdk-0000001050066937)|广告主App开发者通过广告服务提供的SDK，获得App转化跟踪参数。|
|3|[获取转化跟踪参数（AIDL方式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-obtaining-installreferrer-aidl-0000001050064990)|广告主App开发者调用广告服务的AIDL接口获取华为设备上的转化跟踪参数，这种集成方式不需要集成广告服务提供的SDK。|
|3|[转化跟踪参数单机接入测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-test-installreferrer-0000001050064992)|准备一部华为手机，且HMS Core（APK）版本在2.6.5及以上。完成获取转化跟踪参数后进行编译。完成编译后，生成APK安装并运行。|
|4|[开发后自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001050064994)|使用华为自检工具在线对应用进行自检。|
|5|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001050175478)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/hms-toolkit-0000001102415426)了解HMS Toolkit集成Ads Kit最佳实践。
