# 普通商户

* 即直连商户模式，直接与华为支付对接，使用华为支付服务的经营主体。
* 商户向用户提供商品或服务，该模式下华为支付将用户支付的资金直接结算到商户的结算账户。
* 该模式要求商户具备系统开发能力，商户可自行前往[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/) ，合作身份选择"商户"，填写信息后提交入网申请。
