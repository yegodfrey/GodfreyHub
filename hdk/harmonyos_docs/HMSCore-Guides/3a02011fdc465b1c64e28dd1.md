# 关键字搜索

## 概览

您可以通过指定的关键字和可选的地理范围，查询旅游景点、企业和学校之类的目标地点。

## 使用约束

最多返回500条记录。

## 实现步骤

1. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchservicefactory-0000001050154715)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)实例。

   > 说明
   >
   > 创建SearchService实例需要传入Context类型参数和API密钥。Context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API密钥是您在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API密钥，注意使用时需要调用URLEncoder.encode("Your apiKey", "UTF-8")方法对API密钥进行encodeURI编码。

2. 构建[TextSearchRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearchrequest-0000001050154785)对象，它是关键字查询的请求体。其中query是必选参数，其余可选：

   * query：搜索关键字。
   * location：搜索结果偏向的经纬度。
   * radius：搜索半径，单位：米。取值范围：[1, 50000]，默认50000米。该参数只用于优先显示结果，而非将结果限制在该搜索半径内。
   * poiType：返回地点的POI类型，取值范围参见[LocationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-locationtype-0000001050154741)。推荐使用hwPoiType。
   * hwPoiType：返回地点的华为POI类型，取值范围参见[HwLocationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hwlocationtype-0000001050154745)，推荐使用该类型。
   * countryCode：在指定的国家内搜索，采用ISO 3166-1 alpha-2。该参数用于返回指定国家的结果。
   * language：搜索结果的语种，取值范围参见[支持的语言](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/language-mapping-0000001050162856)的语种代码。如果不指定语种，返回英语，如果没有英语，返回当地语言。
   * pageSize：每页返回的记录数。取值范围：[1, 20]，默认20。
   * pageIndex：当前页数。取值范围：[1, 500]，默认1。
   * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家/地区码，该参数已废弃。
   * children：是否返回子节点。默认为false，不返回子节点。传入children为true，如果有子节点信息，则返回子节点的全量信息。
   * countries：支持传入多个国家码，最多5个。该参数用于返回指定国家的结果。

   > 说明
   > * 如果同时设置了poiType和hwPoiType，搜索结果优先符合hwPoiType。
   > * 要求：pageIndex * pageSize <= 500
   > * 如果同时设置了countryCode和countries，取交集。

3. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象，该对象用来侦听搜索结果。
4. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象调用[textSearch](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711#section0628182563818)()接口，传入第2步创建的[TextSearchRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearchrequest-0000001050154785)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象。
5. 通过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象获取搜索结果[TextSearchResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearchresponse-0000001050154789)对象。通过[TextSearchResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearchresponse-0000001050154789)对象，可从中获取[Site](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781)列表，进而解析具体的地址信息。

示例代码如下：

```screen
"Java"
// 声明SearchService对象 
private SearchService searchService; 
// 创建SearchService实例 
searchService = SearchServiceFactory.create(this, "API key"); 
// 创建请求体 
TextSearchRequest request = new TextSearchRequest(); 
request.setQuery("Paris"); 
Coordinate location = new Coordinate(48.893478, 2.334595); 
request.setLocation(location); 
request.setRadius(1000); 
request.setHwPoiType(HwLocationType.AMUSEMENT_PARK); 
request.setCountryCode("FR"); 
request.setLanguage("fr"); 
request.setPageIndex(1); 
request.setPageSize(5); 
request.setChildren(false);
request.setCountries(Arrays.asList("en", "fr", "cn", "de", "ko"));
// 创建搜索结果侦听器 
SearchResultListener<TextSearchResponse> resultListener = new SearchResultListener<TextSearchResponse>() { 
    // 正常结果返回 
    @Override 
    public void onSearchResult(TextSearchResponse results) { 
        if (results == null || results.getTotalCount() <= 0) { 
            return; 
        }
        List<Site> sites = results.getSites();
        if(sites == null || sites.size() == 0){
            return;
        }
        for (Site site : sites) { 
            Log.i("TAG", String.format("siteId: '%s', name: %s\r\n", site.getSiteId(), site.getName())); 
        } 
    } 
    // 异常结果返回 
    @Override 
    public void onSearchError(SearchStatus status) { 
        Log.i("TAG", "Error : " + status.getErrorCode() + " " + status.getErrorMessage()); 
    } 
}; 
// 调用位置搜索接口 
searchService.textSearch(request, resultListener);
```

```screen
"Kotlin"
// 声明SearchService对象
val searchService: SearchService
// 创建SearchService实例
searchService = SearchServiceFactory.create(this, "API key")
// 创建请求体
val request = TextSearchRequest()
request.query = "Paris"
val location = Coordinate(48.893478, 2.334595)
request.location = location
request.radius = 1000
request.hwPoiType = HwLocationType.AMUSEMENT_PARK
request.countryCode = "FR"
request.language = "fr"
request.pageIndex = 1
request.pageSize = 5
request.countries = listOf("en", "fr", "cn", "de", "ko")
// 创建搜索结果侦听器
val resultListener: SearchResultListener<TextSearchResponse> = object : SearchResultListener<TextSearchResponse> {
    // 正常结果返回
    override fun onSearchResult(results: TextSearchResponse?) {
        if (results == null || results.getTotalCount() <= 0) {
            return
        }
        val sites: List<Site>? = results.getSites()
        if (sites == null || sites.isEmpty()) {
            return
        }
        for (site in sites) {
            Log.i("TAG", "siteId: ${site.getSiteId()}, name: ${site.getName()}")
        }
    }
    // 异常结果返回
    override fun onSearchError(status: SearchStatus) {
        Log.i("TAG", "Error : ${status.getErrorCode()}  ${status.getErrorMessage()}")
    }
}
// 调用位置搜索接口
searchService.textSearch(request, resultListener)
```
