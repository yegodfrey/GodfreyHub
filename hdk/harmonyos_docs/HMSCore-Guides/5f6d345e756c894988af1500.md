# 快速接入华为分析

当您将应用的数据统计分析工作从其他分析平台迁移至华为分析平台，需要与华为分析平台对接。为了减少代码改动量，我们提供了接口转换SDK，帮助您快速接入华为分析并将数据上报到华为分析。

#### 集成SDK（Android）

      1. 集成华为分析SDK，详情请参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876)。
      2. 集成接口转换SDK（HiAnalyticsConverter SDK）。

打开应用级的“build.gradle”文件，在“dependencies”中添加如下编译依赖。
             
             dependencies {
                 implementation "com.huawei.hms:hianalytics-converter:6.3.0.302"
             }

HiAnalyticsConverterSDK Android 6.3.0.302已上线，支持对Android 13的适配。

      3. SDK初始化。

在项目的Application类中初始化SDK，代码如下：
             
             public class App extends Application {
                 @Override
                 public void onCreate() {
                     super.onCreate();
                     // 初始化接口转换SDK
                     HiAnalyticsConverter.initialize(this);
                 }
             }

      4. 修改本地代码。

目前，接口转换SDK对接了友盟、腾讯和GrowingIO三家数据分析平台。

如果您原先使用的数据分析平台是GrowingIO，上报事件代码如下：
             
             try {
                 JSONObject jsonObject = new JSONObject();
                 jsonObject.put("product_id", "xxx");
                 jsonObject.put("product_name", "xxx");
                 jsonObject.put("product_price", 9);
                 GrowingIO.getInstance().track("add_product", jsonObject);
             } catch (JSONException e) {
                 e.printStackTrace();
             }

集成接口转换SDK后，上报华为分析平台，上述代码修改如下：
             
             try {
                 JSONObject jsonObject = new JSONObject();
                 jsonObject.put("product_id", "xxx");
                 jsonObject.put("product_name", "xxx");
                 jsonObject.put("product_price", 9);
                 HiAnalytics4GrowingIO.track("add_product", jsonObject);
             } catch (JSONException e) {
                 e.printStackTrace();
             }

      5. 接入调试，详情请参见[接入调试](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-accessing-0000001050161888#section1284414416588)。

#### 集成SDK（iOS）

      1. 集成华为分析SDK，详情请参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-integrating-sdk-0000001050168479)。
      2. 集成接口转换SDK。
         * 手动集成

选择“Add Files to 工程名”，将接口转换SDK的“framework”文件导入到项目中：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115339.07120913722690503577783022495021:50001231000000:2800:B47DB1E7CD6622D5E0976B7C098DE455496B6BB60F3D7472A4238020B37B689A.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

         * 自动集成

在Podfile文件中配置以下代码：
               
               pod 'HiAnalyticsConverter'

配置完成后在 Podfile 所在目录执行终端命令：
               
               pod update

      3. 修改本地代码。

当前华为分析服务接口转换SDK对接了友盟，腾讯，GrowingIO三家数据分析平台。

如果您原先使用的数据分析平台是GrowingIO，上报事件代码如下：
             
             NSString *eventId = @"add_product";
             NSDictionary *param = @{@"product_id":@"xxx",@"product_name":@"xxx",@"product_price":@(9)};
             [Growing track:eventId withVariable:param];

集成接口转换SDK后，上报华为分析平台，上述代码修改如下:
             
             NSString *eventId = @"add_product";
             NSDictionary *param = @{@"product_id":@"xxx",@"product_name":@"xxx",@"product_price":@(9)};
             [HiAnalytics4GrowingIO track:eventId withVariable:param];

      4. 接入调试，详情请参考[接入调试](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-accessing-0000001050168481#section12460142503316)。
