# 开发者自定义参数分渠道能力

媒体在请求鲸鸿动能广告时，在通过拓展参数中传入0-100的渠道号参数，则后续整个广告流程中，均可通过该渠道号参数做数据跟踪和识别，实现广告的精细化运营。  

#### 支持场景

#### 支持的广告形式

* [原生广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-native-0000001050064968)

* 游戏
* 快应用

#### 接入流程

#### 应用\&游戏对接流程

* SDK本要求：13.4.69.300及以上。
* 接入流程：在拓展参数extras中，传入customerChannel渠道号参数。
* 参数要求：key为customerChannel，value为0-100的数字。
* 媒体请求示例：

  ```
  "Java"
  // "testy63txaom86"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID
  NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
  Map < String, Bundle > extras = new HashMap < > ();
  Bundle bundle = new Bundle();
  bundle.putString("customerChannel", "24");
  extras.put("testy63txaom86", bundle);

  AdParam.Builder builder = new AdParam.Builder();
  builder.setExtras(extras);
  nativeAdLoader.loadAds(builder.build(), 5);
  ```

#### 快应用对接流程

* 快应用引擎版本要求：14.0.1.300及以上
* 接入流程：快应用媒体使用最新的快应用引擎版本，请求广告load时传入指定key，value的类型。
* 参数要求：key为customerChannel，value为0-100的数字
* 媒体请求示例：

  ```
  "Java"
  nativeAd.load({
      extra: {
          // adUnitId
          "testy63txaom86": {
              "customerChannel": 24,
              "key2": "value2"
          }
      }
  })
  ```

#### FAQ

#### 在按照 ad.createNativeAd(object) 方法填写 channel 并且类型是字符串测试之后为何不生效？

开发者需要使用extra参数，customerChannel 为数字的方式传入才有效并且数字不可以超过100。
