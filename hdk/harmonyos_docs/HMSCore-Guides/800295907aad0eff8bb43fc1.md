# 业务简介

华为支付服务集成了华为支付收银台能力，开发者的APP通过集成华为支付服务SDK，简便快捷地实现应用支付能力。

## 支持的设备

|**设备类型**|**OS版本**|HMS Core（APK）版本|
|:--------------|:---------------------------------------|:--------------|
|华为手机（Android）|EMUI8.0或者Android 8.0及以上（API Level 26及以上）|6.11.0.300及以上|
|华为手机（HarmonyOS）|HarmonyOS 2.0及以上|6.11.0.300及以上|
