# 业务介绍

合单支付主要帮助平台类服务商将多个商品合并成一笔订单，用户在付款时仅需一次验密确认操作，即可完成订单的支付。订单对应多笔子交易订单和多个子商户。  
![](https://media:801772763970184108)  
该能力目前仅对受邀平台类商户开放。  

#### 场景介绍

旅游APP场景：

用户购买了一个机酒套餐，包含机票、保险、酒店，这几个产品对应不同的收单商户，但用户是一次支付。
