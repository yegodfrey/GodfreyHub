# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_PetalAdsSDK-BannerAds)快速体验一个应用的开发过程。  

#### 开发环境

* JDK 1.7及以上

<!-- -->

* 安装Android Studio 3.X及以上
  * minSdkVersion 19及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 4.1及以上（推荐）

<!-- -->

* 测试应用的设备：EMUI 3.0及以上的华为手机

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|注册成为开发者|在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。|
|2|创建应用|参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和[在项目下添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717#ZH-CN_TOPIC_0000001146718717__section1112105771619)完成应用的创建。|
|3|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-integrating-sdk-0000001050066913)|在完成[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)操作后，您需要先将鲸鸿动能SDK集成到您的开发环境中。|
|3|[HMS Toolkit最佳实践](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/hms-toolkit-0000001102415426)|HMS Toolkit的"Configuration Wizard"为您提供配置向导，借助该工具可将"开发准备"中多个模块的手动操作自动化完成。|
|4|[横幅广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-banner-0000001050066915)|横幅广告是在应用程序顶部、中部或底部占据一个位置的矩形图片。|
|4|[原生广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-native-0000001050064968)|原生广告是创建与应用内容融于一体的广告形式，包含图片、文字和视频，支持您自由定制界面。|
|4|[激励广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-reward-0000001050066917)|激励广告是一种全屏幕的视频广告，用户可以选择点击观看，以换取相应奖励。|
|4|[插屏广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-interstitial-0000001050064970)|插屏广告是一种在应用开启、暂停或退出时以全屏的形式弹出的广告形式。|
|4|[开屏广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-splash-0000001050066919)|开屏广告是一种在应用启动时且在应用主界面显示之前需要被展示的广告。|
|4|[贴片广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-instream-0000001058253743)|贴片广告是一种在视频播放过程前、中、后插入的视频或图片广告。|
|4|[极速开屏广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-exsplash-0000001051056577)|极速开屏广告在提升用户开屏体验的同时为您提供更便捷的广告变现方案，您无需集成SDK即可接入极速开屏广告。|
|5|[基于受众人群请求广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-audience-settings-0000001076462332)|鲸鸿动能SDK提供了通过设置[RequestOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-0000001050066843)对象，来满足针对不同受众人群请求对应广告内容的能力。|
|5|[基于地理位置请求广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-location-based-0000001163023235)|鲸鸿动能SDK会根据您的应用是否拥有位置权限，在请求广告时决定是否携带位置信息。|
|5|[基于上下文信息请求广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-setcontentbundle-0000001214218860)|鲸鸿动能SDK在[AdParam.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-builder-0000001050066829)类中提供了[setContentBundle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-builder-0000001050066829#section12974114318016)方法，供您在广告请求时设置携带上下文信息。|
|5|[激活提醒弹框](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/activation-notification-dialog-box-0000001255286075)|为提高应用下载类广告从安装到激活的转换率，鲸鸿动能SDK提供了通过[HwAds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hwads-0000001050066833)类设置应用激活提醒弹框的功能，用户点击下载应用并静默安装完成后会弹出该弹框。|
|5|[VAST协议](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-vast-0000001196327501)|VAST（Video Ad Serving Template，视频广告服务模板）协议为IAB（Interactive Advertising Bureau，互联网广告署）指定的开放协议。VAST协议支持线性广告（投放形式为前、中、后贴片广告）。|
|5|[征求用户意见](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-consent-settings-0000001075342977)|鲸鸿动能平台投放的广告包括个性化广告和非个性化广告。为了征求用户意见，鲸鸿动能平台提供了Consent SDK。|
|5|[IAB TCF v2.0用户同意信息传递](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-iab-tcf-0000001075694328)|鲸鸿动能平台不强制要求合作伙伴集成TCF v2.0。|
|6|[获取客户端ID和密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reporting-api-client-id-and-key-0000001050933698)|您调用流量变现报表API前，要先获取客户端ID和密钥。|
|6|[调用流量变现报表API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reporting-api-query-0000001051173751)|您可以使用客户端ID和密钥信息发送access_token申请调用流量变现报表API。|
|6|[获取变现报表数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/reporting-api-data-0000001070835233)|调用流量变现报表API返回的报表数据请参见[响应示例](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/query-publisher-service-reports-0000001050933546#section495411113385)。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/hms-toolkit-0000001102415426)了解HMS Toolkit集成Ads Kit最佳实践。
