# DevEco Studio安装及配置

#### 运行环境要求

为保证DevEco Studio正常运行，建议开发者的电脑配置满足如下要求：

* 操作系统：Windows10 64位或macOS 10.14/10.15/11.2.2
* 内存：8GB及以上
* 硬盘：100GB及以上
* 分辨率：1280\*800像素及以上  

#### 安装及配置过程

1. 下载及安装DevEco Studio。具体操作请参见[下载与安装软件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/software_install-0000001053582415-V3)。
2. 配置DevEco Studio，开发者需要完成设置网络代理及下载HarmonyOS SDK等相关操作。具体操作请参见[配置开发环境](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/environment_config-0000001052902427-V3)。
3. 开发环境配置完成后，可以通过[运行HelloWorld](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/hello_world-0000001054516888-V3)工程来验证环境设置是否正确。
4. 创建开发项目工程，具体操作请参见[创建一个新的工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/create_new_project-0000001053342414-V3)。

   <br />

   如使用JavaScript语言开发，请选择"Empty Ability"，随后再选择JS或eTS语言进行开发。
