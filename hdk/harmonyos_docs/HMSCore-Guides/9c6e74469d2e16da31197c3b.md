# 阻力

此数据记录用户在某时刻的阻力，每一条数据都代表在一定时间的阻力等级。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。推荐采样数据周期为1分钟。

## OAuth权限

联盟卡片申请的权限名称：锻炼记录 > 锻炼记录详情数据

* 读权限：Scopes.HEALTHKIT_ACTIVITY_READ
* 写权限：Scopes.HEALTHKIT_ACTIVITY_WRITE

## 原子采样明细数据类型

* 名称：com.huawei.resistance
* Android SDK类型常量：DataType.DT_RESISTANCE

|**字段**列表|描述|Android SDK常量|**类型**|可选/必选|单位|取值范围|
|:--------------|:---|:---------------------|:-----|:----|:-|:------|
|resistanceLevel|阻力等级|Field.RESISTANCE_LEVEL|int|M|NA|[1,100]|
