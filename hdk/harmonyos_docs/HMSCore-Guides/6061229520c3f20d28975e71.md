## 生成 H5 目录下的 dist 文件

要确保华为运动健康能够识别厂商的 H5 项目工程，需要将 js 工程打包为 dist 文件，并放在 H5 目录下。

1. 准备开发环境：安装 [nodejs node-x64.msi](https://nodejs.org/zh-cn/download/)，并配置源 C:\Users\xxx\.npmrc。
2. 在 js 项目下编译构建：找到 H5 项目工程的根目录，在 cmd 命令窗口执行以下命令：

   ```screen
   npm install
   npm run build
   ```

   **图2**打包命令   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/CkRdBZSVTMS0sOXFTKcMRw/zh-cn_image_0000001453644190.png?HW-CC-KV=V1&HW-CC-Date=20260909T150145Z&HW-CC-Expire=31536000000&HW-CC-Sign=8CF847E163F4BF1B1FBE6E7039C4F5235BF69A3B66870D030651E524D216183B)

   将 js 项目工程打包为 dist 文件夹。然后将 dist 文件夹移到资源包的 H5 目录下。

   **图3**打包为 dist 文件夹

## 修改文字及替换图片

1. 打开 **product.xml** 文件，修改设备类型、蓝牙搜寻模式、蓝牙协议id、设备uuid。厂商需要根据模板文字提示进行修改，不可以更改模板结构。

   **图4**product.xml 文件   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d/v3/oFiLp5XnTiCQIpySUL2p2Q/zh-cn_image_0000001503085101.png?HW-CC-KV=V1&HW-CC-Date=20260909T150145Z&HW-CC-Expire=31536000000&HW-CC-Sign=5A59D88F25D9A31C5635C380FF2128A9B25082433248B89210A4A4E9D1310948 "点击放大")

   > 说明
   >
   > 设备类型可输入：
   > * HDK_BLOOD_PRESSURE（血压计）
   > * HDK_BLOOD_SUGAR（血糖仪）
   > * HDK_WEIGHT（体脂秤）
   > * HDK_BODY_TEMPERATURE（体温计）
   > * HDK_BLOOD_OXYGEN（血氧仪）
   > * HDK_ROPE_SKIPPING （跳绳）
   >
   > 蓝牙协议id可输入：
   > * 7972de7d-de18-4d1a-b043-6f3936fe8e01（血压计）
   > * bb11c776-c510-415d-ae3d-9a20207bd617（血糖仪）
   > * 24e9c24f-4f59-464e-9cf1-1ce81335907c（体脂秤）
   > * eedea31b-de1e-4e79-88b3-835e2e81dea0（体温计）
   > * 4a4027eb-d424-4516-a063-1262c178c16a（血氧仪）
   >
   > 设备ID获取请联系华为接口人获取。

2. 修改 lang 目录下 strings 文件的文字内容。lang 目录下的stringszh-rCN 文件存放product.xml 中所需要的文字信息，strings 文件存放 product.xml 中所需要的文字信息的英文翻译，设备厂商需要修改为实际显示的文字内容。如：修改"列表页设备标题名称"则需要替换 strings 文件和 stringszh-rCN 文件中 "IDS_device_8806_fest_1" 字段的内容。

## 生成资源包

从开发套件中获取打包工具 **tozip.py。**

**方式一** **运行打包工具 tozip.py 生成资源包**

1. 将需要解压的资源压缩包（内含 img 目录，lang 目录以及 protuct.xml 文件）和 H5 文件夹（内含 dist 文件夹）放入同一文件夹内。
2. 将 tozip.py 文件跟 H5 文件夹和资源压缩包放在同一个文件夹里。

   **图7**打包资源包的文件夹结构   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/1qKilkIYS9iL9ah7_pqQgg/zh-cn_image_0000001503004053.png?HW-CC-KV=V1&HW-CC-Date=20260909T150145Z&HW-CC-Expire=31536000000&HW-CC-Sign=9F178D64D4FAB6B9258BBF62953AAD352888530A563FFB548463FD4B93D95803)

3. 打开 cmd 命令行，进入到该文件夹，输入命令：python tozip.py。此脚本是为了将 H5 文件夹和资源包打包并在资源包中增加 type="H5"字段（如果已增加，不会重复增加）。

   ```screen
   python tozip.py
   ```

   **图8**运行 python tozip.py   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/15/v3/6Q-QUB0US4y5VqN6L1o-Fg/zh-cn_image_0000001453644194.png?HW-CC-KV=V1&HW-CC-Date=20260909T150145Z&HW-CC-Expire=31536000000&HW-CC-Sign=A534EF20541938DF6120D5A9148CE8FB92AFFB82A580D015E8D41D9A6AFCAD0C)

   > 说明
   >
   > 要求安装有 python 开发环境，命令才能执行成功。

4. 运行命令后，在当前文件夹可得到目标 zip 压缩包。

   **图9**打包完成   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/7dYRWdfjTOSOo0OQLTYlxA/zh-cn_image_0000001453164602.png?HW-CC-KV=V1&HW-CC-Date=20260909T150145Z&HW-CC-Expire=31536000000&HW-CC-Sign=8AA6919E26AFC77FE88403398461783A127FAA8E87C7B9ACA5504B4203B6BC50)

**方式二** **将打包工具 tozip.py 转化为可执行程序 tozip.exe，用 tozip.exe 生成资源包**

1. 安装 pyinstaller，然后打开 cmd 命令行，运行如下命令，将tozip.py 转化为可执行程序 tozip.exe。

   ```screen
   pyinstaller -w -F .\tozip.py
   ```

2. 将需要解压的资源压缩包（内含 img 目录，lang 目录以及 protuct.xml 文件）和 H5 文件夹（内含 dist 文件夹）放入同一文件夹内。
3. 将 tozip.exe 文件跟 H5 文件夹和资源压缩包放在同一个文件夹里。tozip.exe 是为了将 H5 文件夹和资源包打包并在资源包中增加 type="H5"字段（如果已增加，不会重复增加）。

   **图10**打包资源包的文件夹结构   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/56/v3/_J9_uFaCT7a22xdB-xKGnA/zh-cn_image_0000001453484282.png?HW-CC-KV=V1&HW-CC-Date=20260909T150145Z&HW-CC-Expire=31536000000&HW-CC-Sign=41A300EE234A9B16820E0C1660DBF59889F3088CCD86373BCB9083F0880E4EBE)

4. 运行tozip.exe后，在当前文件夹可得到目标zip压缩包。

   **图11**打包完成   
   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/ZppXq86oRQKDFQysdj4DqA/zh-cn_image_0000001503244117.png?HW-CC-KV=V1&HW-CC-Date=20260909T150145Z&HW-CC-Expire=31536000000&HW-CC-Sign=87AD291753CFCE8D77473398BA5B5E7C8F7FDC6B89F0C2BA2E2873E3AF170EC1)
