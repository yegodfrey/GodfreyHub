# 发送上行消息

从Push SDK 4.0.4版本开始，推送服务提供了发送上行消息的能力，即支持从终端设备上发送消息给您的服务器。

推送服务客户端API提供缓存重发的能力，即应用发送的上行消息由于网络不可用等原因导致消息发送失败时，消息会被缓存到终端设备上，待合适时机后进行重发。

应用可以通过[RemoteMessage.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/remotemessage-builder-0000001050413831)中的[setSendMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/remotemessage-builder-0000001050413831#section15490138115113)方法来设置，sendMode设置为1，则表示需要缓存重发（默认不支持缓存重发）。若消息的缓存时间超过设置的[ttl](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-offline-msg-cache-0000001050040130)值或者缓存条数超过20条，则丢弃该条消息，并通过错误码告知应用。为避免缓存重发的消息被覆盖，需要应用保证messageId的唯一性。
> 说明
>
> 缓存重发不保证消息顺序，如果您对消息有顺序要求，则需要自己做保序处理。

推送服务端侧API提供消息的回执能力，即应用发送的上行消息如果成功送达您的服务器，服务器应答消息会通过[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839)类的[onMessageDelivered](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section055084410236)方法回执给应用。回执能力通过[RemoteMessage.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/remotemessage-builder-0000001050413831)中[setReceiptMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/remotemessage-builder-0000001050413831#section18258164535118)方法来设置，receiptMode设置为1，表示需要回执能力（默认不支持回执）。
> 说明
>
> * 华为设备上Push端侧支持消息的缓存重发与回执需要满足HMS Core（APK）的版本不低于4.0.4，推送服务应用的版本不低于10.1.1.400。
> * 如果不需要缓存与回执能力则要满足：EMUI 10.0以上版本且HMS Core（APK）的版本不低于3.0.0；低于EMUI 10.0的设备需要HMS Core（APK）的版本不低于4.0.3。

基于HTTPS协议发送上行消息的主要步骤如下：

1. 在AppGallery Connect上开通HTTPS上行消息接收能力。
   1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站。
   2. 点击"我的项目"，在项目列表中找到您的项目，在项目中点击您的应用，通过左侧导航栏"增长 > 推送服务 > 配置" ，找到"接收上行消息"点击"开通"。
   3. 配置"接收地址"和PEM格式的"HTTPS证书"。
2. 应用携带指定的URI调用[HmsMessaging](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650)类的[send](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650#section17106147135813)方法发送上行消息。

   ```java
   "Java"
   String messageId = String.valueOf(System.currentTimeMillis());

   // RemoteMessage.Builder方法入参为"push.hcm.upstream"，不可修改
   RemoteMessage remoteMessage = new RemoteMessage.Builder("push.hcm.upstream")
           .setMessageId(messageId)
           .addData("key1", "data1")
           .addData("key2", "data2")
           .build();
   try {
       // 发送上行消息
       HmsMessaging.getInstance(this).send(remoteMessage);
       Log.i(TAG, "send message successfully");
   } catch (Exception e) {
       Log.e(TAG, "send message catch exception: " + e);
   }
   ```

   ```kotlin
   "Kotlin"
   val messageId = System.currentTimeMillis().toString()

   // RemoteMessage.Builder方法入参为"push.hcm.upstream"，不可修改
   val remoteMessage = RemoteMessage.Builder("push.hcm.upstream")        
           .setMessageId(messageId)        
           .addData("key1", "data1")        
           .addData("key2", "data2")        
           .build()
   try {    
       // 发送上行消息
       HmsMessaging.getInstance(this).send(remoteMessage)    
       Log.i(TAG, "send message successfully")
   } catch (e: Exception) {    
       Log.e(TAG, "send message catch exception: $e")
   }
   ```

   > 说明
   >
   > RemoteMessage.Builder方法入参为"push.hcm.upstream"，不可修改。
3. 应用处理上行消息发送结果。

   应用需继承[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839)类，覆写[onMessageSent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section172125618218)与[onSendError](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section63844313230)回调方法以检查上行消息的发送状态。发送失败时，onSendError会返回一个带有错误码的[BaseException](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/base-exception-0000001050171878)对象，您可以调用[getErrorCode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/base-exception-0000001050171878#section684661172219)获取[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/commonerror-0000001059816656)。

   ```java
   "Java"
   public class DemoHmsMessageService extends HmsMessageService {
       @Override
       public void onMessageSent(String msgId) {
           // 获取消息ID
           Log.i(TAG,"message sent successfully, the msgId is " + msgId);
       }
       @Override
       public void onSendError(String msgId, Exception exception) {
           // 如果发送错误，获取错误信息
           Log.e(TAG,"message sent catch exception: " + exception.getMessage());
       }
       @Override
       public void onMessageDelivered(String msgId, Exception exception) {
           // 获取具体的错误码和信息
           int errCode = ((BaseException) exception).getErrorCode();
           String errInfo = exception.getMessage();
           if (errCode != 0) {
               // 您自行处理具体业务需求
           }
       }
   }
   ```

   ```kotlin
   "Kotlin"
   class DemoHmsMessageService : HmsMessageService {
       override fun onMessageSent(msgId: String?) {
           // 获取消息ID
           Log.i(TAG,"message sent successfully, the msgId is $msgId")
       }
       override fun onSendError(msgId: String?, exception: Exception?) {
           // 如果发送错误，获取错误信息
           Log.e(TAG,"message sent catch exception: " + exception.getMessage())
       }
       override fun onMessageDelivered(msgId: String?, exception: Exception?) {
           // 获取具体的错误码和信息
           val errCode = (exception as BaseException).errorCode
           val errInfo = exception.message
           if (errCode != 0) {
               // 您自行处理具体业务需求
           }
       }
   }
   ```

4. 您的服务器接收上行消息并进行校验。

   Push服务器收到上行消息时，会做如下处理：
   1. 将收到上行消息时的时间戳、冒号与上行消息组合成一个待加密的字符数组（比如："123456789:your_data"）。
   2. 将此字符数组使用HMAC验签密钥进行HmacSHA256加密后，再经Base64编码后得到一个签名。
   3. 将签名与时间戳信息分别通过HTTPS请求header中的"X-HW-SIGNATURE"字段与"X-HW-TIMESTAMP"字段传递给应用的服务器。

   您的服务器需要通过HTTPS请求header信息与HMAC验签密钥进行签名校验，以验证上行消息的合法性。

> 说明
>
> 如果您的服务器需要回复上行消息响应报文，详细配置请参见[上行消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-uplink-api-0000001050170915)。
