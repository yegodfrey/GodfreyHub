# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[Codelab](https://github.com/huaweicodelabs/ScanKit)快速体验一个应用的开发过程。

## 开发环境

* Xcode
* iOS系统9.0及以上版本

## 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-integrating-sdk-0000001050172400)|在开发应用前，您需要将华为统一扫码SDK集成到您的开发环境中。|
|2|[添加权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-assighing-permissions-0000001050174381)|在"info.plist"文件中配置应用所需权限。|
|3|[构建扫码功能](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-overview-0000001050745299)|Scan Kit提供了单码能力[Default View Mode](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-default-view-0000001050043961)方式扫码、图片解码能力[Bitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-bitmap-camera-0000001050042014)方式解码和支持您自定义扫码界面的[Customized View Mode](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-customized-view-0000001050042012)。建议您先阅读[扫码模式选择](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-overview-0000001050745299)再进行选择。|
|4|[构建码生成功能](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-build-barcode-generation-0000001050174389)|Scan Kit支持将字符串转换为一维码或二维码，目前已支持的码制式为EAN-8、EAN-13、UPC-A、UPC-E、Codabar、Code 39、Code 93、Code 128、ITF14、QR、DataMatrix、PDF417、Aztec。|
|5|[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-parsing-result-codes-0000001050257274)|您可能需要对码在输入图片中的坐标、码的原始数据、码的制式、结构化数据、zoomValue等信息的解析。|
