# 文件评论

## 场景介绍

华为云空间服务支持用户对云端文件进行评论，并对评论进行查看、更新和删除操作。

## 创建评论

**功能简介**

Comments.create接口实现对某个文件的评论。

**限制**

* 必填参数：fileId，fields。
* description是必须的，但是可以为空即description= " "，不能超过1024个字节。
* quotedContent是可选的，其中的mimeType有默认值，如果quotedContent为null不会生成，但是如果quotedContent不为null，mimeType不管传什么值都会置为"html/text"，传其他值或者特殊字符，均忽略，无报错。其中content可以为空，但是字符不能超过1024个字节。
* position中，revision和region都是必须的。revision的长度为1-64，而且需要满足正则条件[a-zA-Z0-9_\-]。region可以为空即形式为："position":"{'revision':'88-0','region':[]}"，其中region中的分类器中rect为double类型，支持Integer、double但是不支持string类型, 如果出现缺少属性，形如缺少属性x："position":"{'revision':'88-0','region':[{rect:{y:2,w:3,h:4,maxw:3,maxh:5,rotation:8}}]}"是可以正常成功的。
* 一个文件默认可最多创建100条评论。
* 只有writer/commenter/owner可以创建。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive

**发送一个创建评论的请求**

1. 创建一个对Comments.create接口的[POST](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentscreate-0000001050151716)请求。
2. 添加查询参数fileId和fields。

   例如：

   ```screen
   POST https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/comments?fields=*
   ```

3. 填入HTTP headers**。**

   * Accept：接收回复的报文格式
   * Content-Type：发送报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

4. 发送请求**。**

   请求示例：


## 获取评论

**功能简介**

Comments.get接口实现获取某个评论。

**限制**

* 必填参数：fileId，fields，commentId。
* fileId不能为目录Id。
* fileId和commentId需要匹配。
* 只有reader/writer/commenter/owner可以获取。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly

**发送一个获取评论的请求**

1. 创建一个对Comments.get接口的[GET](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentsget-0000001050153665)请求。
2. 添加查询参数fileId、commentId和fields。

   例如：

   ```screen
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/comments/{commentId}?fields=*
   ```

3. 填入HTTP headers**。**

   * Accept：接收回复的报文格式
   * Cache-Control：缓存控制

4. 发送请求**。**

## 获取评论列表

**功能简介**

Comments.list接口实现列出所有对某个文件的评论，用户可以根据startEditedTime设定评论创建的起始时间、根据pageSize的设定获取需要的页面大小等。

**限制**

* 必填参数：fileId，fields。
* pageSize范围1-100，不传默认100。
* startEditedTime格式为RFC 3339。
* form字段暂仅支持"json"，不传默认json。
* 只有reader/writer/commenter/owner可以查看。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly

**说明**

includeDeleted参数功能暂时不支持使用。

**发送一个获取评论列表的请求**

## 删除评论

**功能简介**

Comments.delete接口实现删除某个评论。

**限制**

* 必填参数：fileId，commentId。
* 只有评论的创建者或者文件的拥有者才能删除评论。
* fileId和commentId需要匹配。
* 只有writer/commenter/owner可以删除。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive

**发送一个删除评论的请求**

1. 创建一个对Comments.delete接口的[DELETE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentsdelete-0000001050151718)请求。
2. 添加查询参数fileId、commentId。

   例如：

   ```screen
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/comments/{commentId}
   ```

3. 填入HTTP headers**。**

   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

4. 发送请求**。**

   请求示例：

   ```screen
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/AAAB9Wn0DTQCIqPbW9avGjAQo9dbxg04A/comments/BkytC_85-y5hoiLxCRnNCHZcDynNC_siY HTTP/1.1 
   Authorization: Bearer CV3PnPLZXyr9K2GV7RYZkF962JZvoEkMQhTho3QHQAPQUyma/lEyZskP/IMWrc7FvaeHivO7y0lyibI/fQvulBnTgtXArSVPsjaLKvYNkDsJSaIR2/sx+K40bYDWWpKFvJNKg2U47jRwz2mfiF3ortNk 
   Cache-Control: no-cache 
   ```

   响应：

   ```screen
   HTTP/1.1 204 OK
   ```

## 修改评论

**功能简介**

Comments.update接口实现修改某个评论。

**限制**

* 必填参数：fileId, fields, commentId。
* 只有评论的创建者才能修改评论。
* fileId和commentId需要匹配。
* 请求体是必须的，不能空。description不能为空，但是可以为'' ''，不能超过1024个字节; 其中更新请求只能更新description以及position，其他字段带上，不会报错，也不会更新成功。
* 只有writer/commenter/owner可以更新。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive

**发送一个修改评论的请求**

1. 创建一个对Comments.update接口的[PATCH](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentsupdate-0000001050153667)请求。
2. 添加查询参数fileId、commentId和fields。

   例如：

   ```screen
   PATCH https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/comments/{commentId}?fields=*
   ```

3. 填入HTTP headers**。**

   * Accept：接收回复的报文格式
   * Content-Type：发送报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

4. 发送请求**。**

   请求示例：

   ```screen
   PATCH https://driveapis.cloud.huawei.com.cn/drive/v1/files/AAAB9Wn0DTQCIqPbW9avGjAQo9dbxg04A/comments/BkytC_85-y5hoiLxCRnNCHZcDynNC_siY?fields=* HTTP/1.1
   ```
