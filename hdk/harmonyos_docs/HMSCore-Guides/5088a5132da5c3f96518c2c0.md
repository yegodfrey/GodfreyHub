# 活跃用户

#### 活跃用户趋势

1. 选择"华为分析 \> 用户分析 \> 活跃用户"，进入报告页面。

   报告以上图下表的形式展示了活跃用户的变化趋势及每日详情数据，并支持按日/周/月维度切换。

   系统默认统计30天内每日活跃的用户数，通过"按User-ID和设备"或"仅按设备"方式统计用户。这两种统计方式取决于您设置的"在报告中默认使用的ID"，设置"在报告中默认使用的ID"方法详情请参见[设置用户标识方式](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/analysis-settings-0000001123423149#section182891125344)。

2. 点击"日期"控件，选择需要查询的数据日期。

如需要验证某个时间段内的营销措施是否有效，可筛选相应时间范围，观察活跃用户率的变化情况。  

#### 活跃用户引流来源

支持查看活跃用户引流来源Top10和活跃用户引流来源趋势卡片。

* 活跃用户引流来源Top10：统计活跃用户引流来源排名前十的来源渠道及数据，如负一屏、华为自有媒体等来源渠道。支持按日/周/月维度切换查询。
* 活跃用户引流来源趋势：统计活跃用户引流来源的变化趋势及详情数据。右侧筛选框支持选择全部或部分引流来源查看数据，并支持按日/周/月维度切换。
