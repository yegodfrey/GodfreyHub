# 情绪

此数据记录用户在某一刻的情绪数据，每一条数据都代表该时刻的情绪状态。
> 说明
>
> 该数据类型仅部分国家或地区支持，请以实际申请情况为准。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 情绪数据

* 读权限：https://www.huawei.com/healthkit/emotion.read
* 写权限：暂不支持数据写入

## 原子采样明细数据类型

* 名称：com.huawei.emotion

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:------------|:---|:-----|:----|:-|:-----------------------------|
|emotionStatus|情绪状态|int|O|-|1：负面情绪，不愉快 2：平静情绪，平和 3：积极情绪，愉快|
