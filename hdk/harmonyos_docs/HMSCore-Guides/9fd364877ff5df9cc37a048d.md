# 版本更新说明

#### 6.10.0.300（2023-03-06）

本次macOS版本特性变更如下： **修改特性**
                * 自动采集事件[APPFIRSTOPEN](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-automatic-event-collection-0000001051360025#ZH-CN_TOPIC_0000001055224476__li137353871710)和[LAUNCHAPP](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-automatic-event-collection-0000001051360025#ZH-CN_TOPIC_0000001055224476__li250692244414)的上报时机改为实时上报。
                * 应用切后台时，上报策略改为必选策略。
