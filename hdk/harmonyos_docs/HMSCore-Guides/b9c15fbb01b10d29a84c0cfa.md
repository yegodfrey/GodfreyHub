# 在HUAWEI DevEco Studio项目中集成SDK

## 开发前准备

华为UI Engine是提供给应用开发者进行多设备UI开发的解决方案套餐，其提炼了常见的多端UI设计思路，提炼其中的公共能力，尽可能覆盖TOP频率的需求，解决布局、交互、元素拼装等需求。

华为UI Engine深度集成于HUAWEI DevEco Studio（华为IDE）开发工具中，开发者可以通过此IDE工具获取华为UI Engine所属控件能力，安装请选择1.0.6.1201及以上版本，建议用最新的版本，SDK信息公示如下表。

|SDK名称|SDK包|开发者|版本号|主要功能|个人信息处理规则|合规使用说明|校验码|
|:--------------|:-----------------------------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------|
|华为UI Engine多态控件|深度集成于HUAWEI DevEco Studio，集成方式请参考本章节|华为软件技术有限公司|最新版本号： 1.0.0.500 更多版本： [版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/aar-version-change-history-0000001051486410)|提供的一套UI开发能力集合 主要功能介绍请参见[业务介绍](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/aar-introduction-0000001051780990)|不涉及个人信息处理|您集成和使用我们的SDK时需要遵从个人信息保护基本要求，详细请参考[SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/compliance-usage-guide-0000001701885981)|已经随版本发布提供，可在SDK包中查看|

## 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

> 说明
>
> HUAWEI DevEco Studio目前处于Beta阶段，需要向华为申请试用权限。同时也期待您在使用过程中给我们反馈您宝贵的意见，我们将持续进行优化，提升您的使用体验。

在使用HUAWEI DevEco Studio进行应用开发前，您应该提前知道如何"获取Beta权限"和"获取技术支持"通道。

## 获取Beta权限

您可以通过如下方式获取HUAWEI DevEco Studio的Beta权限。

1. 访问[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
2. 注册华为开发者联盟帐号，并点击右上角头像旁边的下拉图标，点击"立即前往实名认证"上传信息进行[实名认证](https://developer.huawei.com/consumer/cn/verified/enrollment)。
3. 实名认证后，在开发者联盟网站中选择"开发 > 其他开放能力 > 开发工具 > DevEco Studio 1.0"。

## 获取技术支持

您在使用HUAWEI DevEco Studio时，如果您有任何的问题或建议，都可以通过如下两种方式与我们取得联系。

* 在线工单：登录华为开发者联盟，在菜单栏选择"支持 > 技术支持 > 在线提单"，进入在线提单页面，选择"HMS Capabilities & Tools > 开发工具 > HUAWEI DevEco Studio"提交工单。
* 人工服务：您可以通过扫描如下二维码添加"华为DevEco小助手"，然后向我们的小助手进行反馈。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230912163204.44175822655054566274138930044270:50001231000000:2800:E6AA122051914B27776706C3F6E1D401B31E775AA2E26B003888DB9598473255.png?needInitFileName=true?needInitFileName=true)

## 安装和配置HUAWEI DevEco Studio

获取Beta权限后，您就可以下载HUAWEI DevEco Studio软件进行开发了。

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)官网。
2. 点击右上角""管理中心""，然后在""应用服务 > 开发服务""中，勾选"HUAWEI DevEco Studio"卡片，然后点击"关闭"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230912163204.34234537010195269023374419286930:50001231000000:2800:565834340ABEB025C7121C439C1590BEB480A43227CEAF32BEE1EF8819A65034.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 在开发服务中，点击"HUAWEI DevEco Studio"卡片，阅读和签署Beta保密协议。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230912163204.16064812643024254554095609655317:50001231000000:2800:3AFF1C6679486F98A6A70113A637C2C1826B65684820B3E994D1E101FA26EE51.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 下载HUAWEI DevEco Studio软件包。

   软件包下载完成后，请参见[DevEco Studio使用指南](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/service-introduction-0000000000017290)中的[安装DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/install-0000001050028630)和[配置DevEco Studio](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/config-guide-0000000000034467)完成环境的安装和配置。
