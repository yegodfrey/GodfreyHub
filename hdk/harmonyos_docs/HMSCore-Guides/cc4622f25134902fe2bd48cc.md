# 点注释

您可以在地图的指定位置添加点注释以标识位置、商家、建筑等，并可以通过信息窗口展示详细信息。点注释支持功能：

* 支持设置文字、图标碰撞规则。
* 支持设置标题动画、图标动画。
* 支持添加点击事件。

## 添加点注释

创建HPointAnnotationOptionsEx点注释的配置对象类，调用HMapView(PointAnnotation)的addPointAnnotation:接口添加点注释。

```java
// 点注释1
HPointAnnotationOptionsEx *optionsEx = [[HPointAnnotationOptionsEx alloc] init];
optionsEx.position = [[HLatLng alloc] initLatitude:self.owner.mapView.centerCoordinate.latitude withLongitude:self.owner.mapView.centerCoordinate.longitude];
HPointAnnotationExTitle *title = [[HPointAnnotationExTitle alloc] init];
title.content = @"PointAnnotation";
title.size = 20;
optionsEx.title = title;
// 点注释2
HPointAnnotationOptionsEx *otherOptionsEx = [[HPointAnnotationOptionsEx alloc] init];
otherOptionsEx.position = [[HLatLng alloc] initLatitude:self.owner.mapView.centerCoordinate.latitude withLongitude:self.owner.mapView.centerCoordinate.longitude];
HPointAnnotationExTitle *otherTitle = [[HPointAnnotationExTitle alloc] init];
otherTitle.content = @"otherPointAnnotation";
otherTitle.size = 20;
otherOptionsEx.title = otherTitle;
// 添加点注释
[self.mapView addPointAnnotation:optionsEx];
[self.mapView addPointAnnotation:otherOptionsEx];
```

## 点注释事件

可通过HMapViewDelegateAdvance代理类的mapView:didSelectPointAnnotation:代理方法来侦听点注释上的点击事件。

```java
- (void)mapView:(HMapView *)mapView didSelectPointAnnotation:(HPointAnnotationEx *)pointAnnotation {
    NSString *showText = [NSString stringWithFormat:@"%@---priority=%.2f", [NSString stringWithFormat:@"hmsmapkit %s",__FUNCTION__], pointAnnotation.poiOptions.getPriority];
    [[AlertManager sharedManager] showAlertMessageWithMessage:showText];
}
```

## 点注释动画

点注释支持设置标题动画和图标动画效果，标题支持设置字体大小动画（HFontSizeAnimation），图标支持设置透明度动画（HAlphaAnimation）、缩放动画（HScaleAnimation）。创建HAnimation动画对象，将其添加到点注释动画接口setIconAnimation:/setTitleAnimation:中，再调用startIconAnimation/startTitleAnimation开启动画。

```java
HScaleAnimation *animation = [[HScaleAnimation alloc] init];
animation.fromValue = CGPointMake(0.5, 0.5);
animation.toValue = CGPointMake(1.5, 1.5);
animation.delegate = self.owner;
animation.fillMode = 0;
animation.repeatMode = 1;
animation.repeatCount = 1;
animation.duration = 1500;
animation.timingFunction = [HTimingFunction timingFunctionWithName:@"linear"];
[self.poiEx setIconAnimation:animation];
[self.poiEx startIconAnimation];
```
