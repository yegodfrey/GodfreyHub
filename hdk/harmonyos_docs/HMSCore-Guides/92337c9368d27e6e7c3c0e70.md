# 激活提醒弹框

为提高应用下载类广告从安装到激活的转换率，鲸鸿动能SDK提供了通过[HwAds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hwads-0000001050066833)类设置应用激活提醒弹框的功能，用户点击下载应用并静默安装完成后会弹出该弹框。  
示例代码如下所示：

```
"Java"
// 启用激活提醒弹框
HwAds.setAppInstalledNotify(true);
```

```
"Kotlin"
// 启用激活提醒弹框
HwAds.setAppInstalledNotify(true)
```
