# MMO

华为分析服务支持MMO（Massively Multiplayer Online，大型多人在线）类游戏分析报告，您可以清晰洞察MMO类应用的关键指标数值，从数据概览、付费分析、玩家分析、虚拟消费、战斗分析、区服分析、养成系统、副本任务多维度了解用户的行为，并制定精准的运营策略，从而提升MMO类游戏的用户体验，实现获客增长和受益增长。

## 前提条件

* 已在"智能数据接入 > 埋点开发"中配置了MMO行业模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。
* 查看区服分析报告需在端侧埋点及上报用户属性cur_server和pre_server，设置方法请参考[上报用户属性开发说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-predefined-user-attribute-0000001064469606#section884113671612)。

## 典型应用场景

* 查看MMO类应用整体数据分析报告。
* 查看MMO类应用细分指标情况，如数据概览、付费分析、玩家分析、虚拟消费、战斗分析、区服分析、养成系统和副本任务。
* 使用"区服分析"报告细分服务器维度查看数据，可通过数据监控新服务器内容，促进游戏版本调优，进一步助力游戏联运流水增长。

## 功能详述

### 案例

某MMO类App想要通过付费分析、玩家分析、虚拟消费、战斗分析等数据洞察该MMO类App的整体运营情况并寻找增长机会点。

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 行业分析 "，进入"MMO"分析界面。
4. 查看MMO类游戏App数据概览。详情请参见[数据概览](#section12772184121119)。
5. 查看MMO类游戏核心营收指标。详情请参见[付费分析](#section19748018134912)、[玩家分析](#section221644910498)、[虚拟消费](#section1097617207524)、[战斗分析](#section1936183405418)、[区服分析](#section12291676570)、[养成系统](#section190250175911)和[副本任务](#section16655624318)。
