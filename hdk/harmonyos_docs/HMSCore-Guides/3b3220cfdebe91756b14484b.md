# 仅申请OpenID或UnionID的应用接入华为帐号快捷登录

#### 场景介绍

如果应用仅获取华为帐号唯一标识（[OpenID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-authhuaweiid-0000001064638400#section11860164162918)或[UnionID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-authhuaweiid-0000001064638400#section16581158153918)），则可以使用免授权方式登录，华为帐号服务将不会弹出授权框。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230529184004.80109163310837002933172639573469:50001231000000:2800:83BD9F98F7BEC4DB377C7DB81DD67121A6AB3EFAF50692B5EF1119F615D2CBC2.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
仅支持注册地为中国的用户。

使用快速接入华为帐号、ID Token模式接入华为帐号或Authorization Code模式接入华为帐号，当您调用静默登录接口[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185#section322611432359)或者前台登录接口[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauth-0000001063960185#section169782218282)进行登录时，如果配置登录请求参数构造对象[HuaweiIdAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-huaweiidauthparamshelper-0000001064109899)只包括请求用户的ID(OpenID、UnionID)，则可快捷登录。  

#### 构造请求参数示例

* 快速接入华为帐号

  ```
  var signInOption = new HuaweiIdAuthParamsHelper()
          .setId()
          .build();
  ```

<!-- -->

* ID Token模式接入华为帐号

  ```
  var signInOption = new HuaweiIdAuthParamsHelper()
          .setIdToken()
          .setId()
          .build();
  ```

<!-- -->

* Authorization Code模式接入华为帐号

  ```
  var signInOption = new HuaweiIdAuthParamsHelper()
          .setAuthorizationCode()
          .setId()
          .build();
  ```
