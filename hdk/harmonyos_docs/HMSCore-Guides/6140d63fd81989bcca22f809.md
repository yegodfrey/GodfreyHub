# 查询应用信息

在创建应用后AppGallery Connect会为应用ID作为应用的唯一标识，可通过以下方法查询应用信息。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"开发与服务"。
2. 在项目列表中找到您的项目，点击对应的Android应用。
3. 选择"项目设置 > 常规"后，在"应用"信息下，页面中的"APP ID"即为应用ID，"包名"即为应用包名，"Client Secret"为APP Secret。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260112111429.55038320406549443047781076864398:50001231000000:2800:B0046F35BAC711150BCC0BEE5A42FB53F9CEA6AAA292EC98DC7BC419C563F999.png)
