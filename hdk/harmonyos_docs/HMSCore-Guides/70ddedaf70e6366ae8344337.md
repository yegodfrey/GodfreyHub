# 应用状态感知能力

## 导入接口类

使用应用状态感知能力，除需要导入情景感知服务的公共能力类外，还需要导入应用状态相关的类。

```screen
importcom.huawei.hmf.tasks.OnFailureListener;
importcom.huawei.hmf.tasks.OnSuccessListener;
importcom.huawei.hms.kit.awareness.Awareness;
// 导入应用状态快照相关类
import com.huawei.hms.kit.awareness.capture.ApplicationStatusResponse;
import com.huawei.hms.kit.awareness.status.ApplicationStatus;
```

## 能力开发

1. 获取Awareness Kit的"Capture Client"。
2. 通过"Capture Client"调用应用状态查询能力接口查询情景状态。
3. 根据情景感知服务返回的结果，进行应用的业务处理。

   ```screen
   "Java"
   String pkgName = "com.xxx.demo";
    Awareness.getCaptureClient(this).getApplicationStatus(pkgName)
            // 执行成功的回调监听
            .addOnSuccessListener(applicationStatusResponse -> {
                  int state = applicationStatusResponse.getApplicationStatus().getStatus();
                  switch (state) {
                          case ApplicationStatus.UNKNOWN:
                               Log.i(TAG, "it is unknown");
                          case ApplicationStatus.SILENT:
                                Log.i(TAG, "it is silent");
                           case ApplicationStatus.RUNNING:
                                Log.i(TAG, "it is running");
                           default:
                                Log.i(TAG, "it is sth wrong");
             }  
                   })
             // 执行失败的回调监听
             .addOnFailureListener(e -> {
                   Log.d(TAG, "get application status failed");
             });
   ```

   ```screen
   "Kotlin"
   val pkgName = "com.xxx.demo"
   Awareness.getCaptureClient(this).getApplicationStatus(pkgName)
            // 执行成功的回调监听
            .addOnSuccessListener { applicationStateResponse: ApplicationStatusResponse ->
                      val state = applicationStateResponse.applicationStatus.status
                      Toast.makeText(this, "get application snapshot success", Toast.LENGTH_SHORT).show()
            }
            // 执行失败的回调监听
            .addOnFailureListener { e: Exception? ->
                       Log.d(TAG, "get application snapshot failed")
                       Toast.makeText(this, "get application snapshot failed", Toast.LENGTH_SHORT).show()
                       Log.e(TAG, "addOnFailureListener", e)
            }
   ```
