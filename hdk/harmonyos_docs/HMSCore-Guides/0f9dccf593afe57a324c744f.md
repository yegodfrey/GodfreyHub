# 集成SDK

#### 添加当前应用的AppGallery Connect配置文件

    1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”。
    2. 在项目列表中找到您的项目，在项目中点击需要集成HMS Core SDK的应用。
    3. 在“项目设置 > 常规”页面的“应用”区域，点击“agconnect-services.json”下载配置文件。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240126192613.54423690558198691264922122646122:50001231000000:2800:02BD700F568C1ACB536E536352C9822670894A889B290C31F0B4564020E6018F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

       * 在获取“agconnect-services.json”文件前，请确保已经完成分析服务的开通（开通步骤请参见[开通华为分析服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050163815#ZH-CN_TOPIC_0000001054905874__li1031751692618)）。
       * **如果您在 “项目设置”模块进行过任何修改动作，请务必下载最新的“agconnect-services.json”，来替换Android应用模块App的根目录下已有的文件。**“项目设置”模块修改动作包括但不限于：设置数据处理位置、开启或管理某些API等。

#### 配置HMS Core SDK的Maven仓地址

Android Studio的代码库配置在Gradle插件7.0以下版本、7.0版本和7.1及以上版本有所不同。请根据您当前的Gradle插件版本，选择对应的配置过程。

7.0以下版本 | 7.0版本 | 7.1及以上版本  
---|---|---  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240126192613.85833123741258901978786248748216:50001231000000:2800:66FADC81FC0C03B2895E1F97727707F0756F96395B36D8C7E4E59033CF5F3783.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

Maven仓地址无法直接在浏览器中打开访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。

    * **7.0以下版本**
      1. 打开Android Studio项目级“build.gradle”文件。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240126192613.56778841427384432840838406230029:50001231000000:2800:1917CE3D7CBC7313FA5203B5CFC6D3B50A9CBEE83528A47B6243940C3918B426.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

      2. 添加HUAWEI AGC插件以及Maven代码库。
         * 在“buildscript > repositories”中配置HMS Core SDK的Maven仓地址。
         * 在“allprojects > repositories”中配置HMS Core SDK的Maven仓地址。
         * 如果App中添加了“agconnect-services.json”文件则需要在“buildscript > dependencies”中增加AGC插件配置。
    
    buildscript {
        repositories {
            google()
            jcenter()
            // 配置HMS Core SDK的Maven仓地址。
            maven {url 'https://developer.huawei.com/repo/'}
        }
        dependencies {
            ...
            // 增加AGC插件配置，请您参见[AGC插件依赖关系](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-sdk-changenotes-0000001058732550#section7117746172220)选择合适的AGC插件版本。
            classpath 'com.huawei.agconnect:agcp:_1.6.0.300_ '
        }
    }
    
    allprojects {
        repositories {
            google()
            jcenter()
            // 配置HMS Core SDK的Maven仓地址。
            maven {url 'https://developer.huawei.com/repo/'}
        }
    } 

    * **7.0版本**
      1. 打开Android Studio项目级“build.gradle”文件。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240126192613.55471022038372909364696764528377:50001231000000:2800:5E5620847B8EC65469AFA4B2C39DAAB80F0DB53A97E193E3588312A51A16F808.jpg?needInitFileName=true?needInitFileName=true?needInitFileName=true)

      2. 添加HUAWEI AGC插件以及Maven代码库。
         * 在“buildscript > repositories”中配置HMS Core SDK的Maven仓地址。
         * 在“buildscript > dependencies”中增加Android Gradle插件配置。
         * 如果App中添加了“agconnect-services.json”文件，则还需要在“buildscript > dependencies”中增加AGC插件。
    
    buildscript {
        repositories {
            google()
            jcenter()
            // 配置HMS Core SDK的Maven仓地址。
            maven {url 'https://developer.huawei.com/repo/'}
        }
        dependencies {

            classpath 'com.huawei.agconnect:agcp:_1.6.0.300_ '
        }
    }

#### 添加编译依赖

    1. 打开应用级的“build.gradle”文件。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240126192613.25779756908374675386503026517372:50001231000000:2800:9702B8A177B55EE1092D9367E7E826A0A4A37D6617966D6DDB3C66B8E61440BA.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    2. 添加AGC插件配置。请根据实际情况选择：

       * 方式一：在文件头部声明下一行添加如下配置。
             
             apply plugin: 'com.huawei.agconnect'

       * 方式二：在**plugins** 中添加如下配置。
             
             plugins {
                 id 'com.android.application'
                 // 添加如下配置
                 id 'com.huawei.agconnect'
             }

    3. 在“dependencies”中添加如下编译依赖。
           
           dependencies {
               implementation 'com.huawei.hms:hianalytics:_6.x.x.300_ '
           }

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240126192613.48667349039507429432155334435168:50001231000000:2800:D93CE15F52B94E0A77F8730BE06750C465043D714F99C7E9F02536EB94B626AA.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

       * 其中， _6.x.x.300_ 为引用的SDK的版本号，例如6.12.0.301。
       * AGC SDK 1.6.0.300及之前版本与华为分析服务SDK 6.0.0.301至6.3.0.303版本会产生不兼容问题，您需要升级AGC SDK为1.6.1.300及以上版本，或者升级分析服务SDK为6.3.2.300及以上版本。建议您将AGC SDK及分析服务SDK都升级至最新版本。
       * Maven仓地址直接在浏览器中打开，无法进行访问，只能在IDE中配置。
       * 如果应用同时需要集成push、game等其他SDK，有可能导致旧版本（2.3.0.304及之前）的Analytics SDK获取AAID失败，这是因为push、game、Analytics等SDK都依赖了华为HMS Base SDK，最终合并成的HMS Base SDK可能会与旧版本Analytics SDK依赖的OpenDevice SDK不配套，接口不兼容。规避冲突方法： 
         1. 保持HMS Base SDK和OpenDevice SDK版本一致。
         2. 将HMS Base SDK和OpenDevice SDK版本都升级到3.0.3.x及以上，版本可以不一致。
         3. 将所有的SDK都升级到最新。

#### 配置AndroidManifest.xml文件（适配minSdkVersion 18）

Analytics SDK从5.2.0.301版本开始，“build.gradle”中配置的minSdkVersion最小支持为18。如果您的应用minSdkVersion配置为18，需要在“AndroidManifest.xml”中manifest便签下添加以下元素。 
    
    <manifest ...>
        ...
        xmlns:tools="http://schemas.android.com/tools"
        <uses-sdk tools:overrideLibrary="com.huawei.agconnect.credential,com.huawei.agconnect.core,com.huawei.agconnect.https,com.huawei.agconnect.datastore"/>
        ...
    </manifest>

#### （可选）集成Analytics延迟深度链接SDK

使用延迟深度链接功能，除了集成分析服务SDK外，还需要另外集成hianalytics-extended。集成方法如下：
    
    dependencies {
        implementation('com.huawei.hms:hianalytics-extended:_6.12.0.300_ ')
    }

用户点击广告后，鲸鸿动能广告侧判断用户是否已安装应用，如已安装直接跳转至落地页；若用户没有安装应用，则鲸鸿动能广告写入落地页信息至应用市场referrer参数，跳转至应用市场下载该应用，用户下载完成首次激活时，分析服务从华为应用市场查询落地页信息，打开落地页。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240126192613.73537001926733818562618773452266:50001231000000:2800:F6C47DABFEE71D89D5569EAFDEEBE44C0A720EF3226B4AE6E27868AC866F170E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

    * 下载完成首次激活打开落地页时效为15天。

#### 为满足监管要求，集成SDK后要求用户在未同意访问网络前不能发送任何网络请求，如何处理？

    * 用户在未同意访问网络前请不要调用Analytics Kit SDK初始化接口[getInstance](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-api-hianalytics-0000001050707170#section126742153455)。
    * AGC SDK在1.5.0.300版本（分析服务5.3.0.300版本）提供了设置能否发送网络请求的能力，您可以按如下步骤实现。 
      1. 在AndroidManifest.xml的Application中增加如下meta-data配置，value配置为false，表示不发送网络请求。
             
             <meta-data
                  android:name="com.huawei.agconnect.AccessNetwork"
                  android:value="false" />

      2. 在用户同意访问网络后调用setAccessNetwork接口打开网络发送请求开关。
             
             AccessNetworkManager.getInstance().setAccessNetwork(true);

      3. （可选）如果使用了多进程处理机制，则需要在子进程中调用初始化方法。

在Application的onCreate方法中添加初始化代码：
             
             if (AGConnectInstance.getInstance() == null) { 
                  AGConnectInstance.initialize(getApplicationContext()); 
             }
