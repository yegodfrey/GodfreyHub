# 狂野飙车9：竞速传奇集成HUAWEI Account Kit助力玩家增长

#### 狂野飙车9：竞速传奇简介

《狂野飙车9：竞速传奇》是Gameloft公司推出的全球下载量最高、获奖次数最多的赛车系列手游的新作，其超现实的竞速体验吸引了众多玩家。


#### 业务挑战

* 需要更快捷的登录方式 游戏注册登录时往往需要输入一长串帐号密码。一些新用户在试玩游戏时，如果能免注册，快捷地登录帐号，将更有可能留存下来，转化为长期玩家。

* 需要大流量渠道来推广游戏，促进用户付费 游戏市场竞争激烈，寻找曝光量大、用户量多的渠道为自己的游戏应用引流，促进用户付费，是游戏应用的迫切需求。

* 需要让重度玩家便捷管理帐号 许多用户同时在玩多款游戏，管理多个不同的帐号和密码，增加了记忆负担。如果能实现用统一帐号登录多个游戏，将大大提升其体验。

#### 解决方案

* 一键授权登录 《狂野飙车9：竞速传奇》在集成Account Kit后，用户可免注册，通过华为帐号一键授权快速登录游戏，降低注册和登录环节的用户流失。

* 华为联运 目前，华为帐号全球月活用户数亿，遍布190+个国家和地区，支持70+种语言。无论是对中国出海、或想进军中国市场的海外游戏，都可以加入[华为联运服务](https://developer.huawei.com/consumer/cn/appgallery/joint-operation)，上架华为应用市场，集成Account Kit、IAP（应用内支付）等服务，享多种推广资源、营销活动，助力游戏变现。

* 一个帐号畅玩多款游戏 华为终端用户只需登录一次华为帐号，就能在多款游戏中快速授权登录，无需记忆多个帐号密码，减轻记忆负担。

* 《狂野飙车9：竞速传奇》 通过集成Account Kit、IAP、Game Service等服务上架华为应用市场后，下载量大幅上升，全球累计下载量5500万+，有700万+用户使用华为帐号登录，华为游戏论坛互动量20万+（截止2021年4月）。

* 游戏玩家 通过华为帐号一键授权登录，免去注册流程，大大节省了时间。一个华为帐号即可畅玩多款游戏，提升游戏体验。
