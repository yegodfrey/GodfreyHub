# 证券

分析服务支持金融理财行业分析，可以清晰洞察应用的关键指标数值，从数据概览、交易、咨讯等多维度了解销售情况，帮助制定精准的营销方案和产品策略。

## 典型应用场景

* 查看商品的总体销售情况，包括活跃用户数、开户提交用户数、绑卡用户数和股票交易用户数。
* 查看各个商品品类的销售情况，包括理财购买人数、基金交易用户数、销售额。

## 前提条件

已在"智能数据接入 > 埋点开发"中配置了金融理财行业模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。

## 功能详述

### 案例

某金融理财App想要查看近期华为手机用户整体销售额情况以及了解其中最受欢迎的理财或咨询商品品类，制定相应的促销计划。

需求：查看华为手机用户商品销售情况及各个品类的消费情况。

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。


3. 选择"华为分析 > 行业分析"，进入"证券"分析界面。
4. 查看金融理财类App数据概览。详情请参见[数据概览](#section2340727172819)。
5. 查看金融理财类App核心营收指标。详情请参见[交易](#section2034411275285)和[资讯](#section4348192792814)。
