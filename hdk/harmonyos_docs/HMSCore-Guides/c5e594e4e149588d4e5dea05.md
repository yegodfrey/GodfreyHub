# 地图控件

地图控件指华为地图上负责与地图交互的UI控件。华为地图提供了丰富的UI控件，包括比例尺、缩放条、缩放按钮、指北针、平移按钮、版权和"我的位置"按钮，如图所示：

## 比例尺

通过scaleControl、scaleControlOptions属性控制是否显示比例尺、设置比例尺单位。scaleControl值默认false，比例尺不显示；值为true，显示在地图右下角。

```javascript
var mapOptions = {};
mapOptions.center = {lat: 48.856613, lng: 2.352222};
mapOptions.zoom = 10;
// 设置显示比例尺
mapOptions.scaleControl = true; 
mapOptions.scaleControlOptions = {
	// 设置比例尺单位为英制英寸
	units: "imperial" 
};
```

## 缩放条

通过zoomSlider属性控制是否显示缩放拉条。默认false，缩放条不显示；值为true，显示在地图右下方。

```javascript
var mapOptions = {};
mapOptions.center = {lat: 48.856613, lng: 2.352222};
mapOptions.zoom = 10;
// 设置显示缩放条
mapOptions.zoomSlider = true;      
```

## 缩放按钮

通过zoomControl属性设置是否显示缩放按钮。默认true，显示在地图右下方；值为false，缩放按钮不显示。

```javascript
var mapOptions = {};
mapOptions.center = {lat: 48.856613, lng: 2.352222};
mapOptions.zoom = 10;
// 设置不显示缩放按钮
mapOptions.zoomControl = false;      
```

## 指北针

通过rotateControl属性设置是否显示指北针。默认false，指北针不显示；值为true，当地图朝向不是正北方，自动显示在右上角。

```javascript
var mapOptions = {};
mapOptions.center = {lat: 48.856613, lng: 2.352222};
mapOptions.zoom = 10;
// 设置显示指北针
mapOptions.rotateControl= true;      
```

## 平移按钮

通过navigationControl属性设置是否显示平移按钮。默认false，平移按钮不显示；值为true，显示在地图右上方。

```javascript
var mapOptions = {};
mapOptions.center = {lat: 48.856613, lng: 2.352222};
mapOptions.zoom = 10;
// 设置显示平移按钮
mapOptions.navigationControl= true;       
```

## 版权

通过copyrightControl、copyrightControlOptions属性设置是否显示版权、自定义版权内容以及样式等。copyrightControl值默认false，版权不显示。

```javascript
var mapOptions = {};
mapOptions.center = {lat: 48.856613, lng: 2.352222};
mapOptions.zoom = 10;
// 设置显示版权
mapOptions.copyrightControl = true;    
// 设置版权内容
mapOptions.copyrightControlOptions = {value: "<div style='position: absolute;left:170px;bottom:32px;'><font>Huawei Search © </font><a href='https://developer.huawei.com/consumer/cn/doc/development/HMS-Guides/hms-map-js-base-map'>HMS Map</a><font> contributors</font></div>"}
```

## 我的位置

通过locationControl属性设置是否显示"我的位置"按钮。默认false，我的位置不显示；值为true，显示在地图右下方。（仅支持HTML5的浏览器）

```javascript
var mapOptions = {}; 
mapOptions.center = {lat: 48.856613, lng: 2.352222}; 
mapOptions.zoom = 10; 
// 设置显示我的位置按钮
mapOptions.locationControl= true;       
```
