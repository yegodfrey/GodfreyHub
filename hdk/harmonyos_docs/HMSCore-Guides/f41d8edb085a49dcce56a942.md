# Order服务验证购买Token

在完成一笔支付后，您可从HMS Core（APK）获取到商品购买单详情的JSON字符串[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)及其签名字符串。[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中有用于唯一标识商品和用户对应关系的purchaseToken。

通过签名验证，可确保[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)有效性。您可以解析出[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的purchaseToken数据，调用华为应用内支付服务器提供的验证购买Token的接口，获取购买数据及其签名数据，进一步验证购买信息的正确性。为避免资金损失，您在验签成功后，必须校验[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的productId、price、currency等信息的一致性，验证一致后发货。验证方法请参考[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。如果您具备在后端服务器进行购买交易验证的能力，建议您务必验证购买Token。
> 说明
>
> 该接口只针对消耗型商品和非消耗型商品。
