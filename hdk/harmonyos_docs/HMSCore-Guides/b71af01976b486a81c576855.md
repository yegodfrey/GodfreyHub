# 标记

用户可以在地图的指定位置添加标记以标识位置、商家、建筑等，并可以通过信息窗口展示详细信息。  

#### 添加标记

使用默认图标在地图上添加一个简单的标记。

```
- (void)viewDidLoad {
    [super viewDidLoad];
    /* Annotation. */
    CLLocationCoordinate2D position = CLLocationCoordinate2DMake(48.893478, 2.334595);
    HPointAnnotation *annotation = [[HPointAnnotation alloc] init];
    annotation.coordinate = position;
    annotation.title = @"Hello Huawei Map";
    annotation.subtitle = @"This is a subtitle!";
    [self.mapView addAnnotation:annotation];
}
- (HAnnotationView *)mapView:(HMapView *)mapView viewForAnnotation:(id<HAnnotation>)annotation
{
    if ([annotation isKindOfClass:[HPointAnnotation class]])
    {
        HPinAnnotationView *annotationView = [[HPinAnnotationView alloc] init];
        annotationView.canShowCallout   = YES;
        return annotationView;
    }
    return nil;
}
```

您可以自定义图像代替默认图标，还可以设置标记属性来改变图标。标记的以下属性支持自定义：  

|方法|功能|
|:------------------------------------------------------------------------------------------------------------------------|:--------------------------------------|
|[HPointAnnotation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hpointannotation-0000001237517127)|点标注数据，代表一个经纬度点位置的点状覆盖物的数据。|
|CLLocationCoordinate2D coordinate|标记在地图上的经纬度，这是标记唯一必需的属性。|
|NSString \*title|标题。|
|NSString \*subtitle|副标题。|
|[HAnnotationView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hannotationview-0000001188798392)|标注点对应的视图。|
|UIImage \* _Nullable image|设置标注点的图标。|
|int zIndex|z值，决定了AnnotationView之间的压盖顺序，值大的在上部，默认0。|
|CGPoint anchorPoint|标注点显示锚点|
|BOOL draggable|是否支持拖动。默认值为false，不支持。|

```
/**
```

```
   fromOldState:(HAnnotationViewDragState)oldState;
```

#### 信息窗

信息窗在标记上方的弹出窗口中显示文本或图像，为标记提供详细信息。  

#### 添加信息窗

添加信息窗的最简单方法是设置相应[HPointAnnotation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hpointannotation-0000001237517127)对象的title和subtitle属性以及canShowCallout方法。设置这些属性可以在点击该标记时显示信息窗。

```
- (void)viewDidLoad {
    [super viewDidLoad];
    /* Annotation. */
    CLLocationCoordinate2D position = CLLocationCoordinate2DMake(48.893478, 2.334595);
    HPointAnnotation *annotation = [[HPointAnnotation alloc] init];
    annotation.coordinate = position;
    annotation.title = @"Hello Huawei Map";
    annotation.subtitle = @"This is a subtitle!";
    [self.mapView addAnnotation:annotation];
}
```

#### 显示/隐藏信息窗

信息窗旨在响应用户触摸事件。可以通过调用[HAnnotationView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hannotationview-0000001188798392)对象的canShowCallout显示信息窗。

```
- (HAnnotationView *)mapView:(HMapView *)mapView viewForAnnotation:(id<HAnnotation>)annotation
{
    if ([annotation isKindOfClass:[HPointAnnotation class]])
    {
        HPinAnnotationView *annotationView = [[HPinAnnotationView alloc] init];
        annotationView.canShowCallout   = YES;
        return annotationView;
    }
    return nil;
}
```

#### 自定义信息窗

1. 生成并添加[HPointAnnotation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hpointannotation-0000001237517127)。

   <br />

   ```
    /* Annotation. */
   CLLocationCoordinate2D position = CLLocationCoordinate2DMake(48.393478, 2.034595);
   HPointAnnotation *annotation = [[HPointAnnotation alloc] init];
   annotation.coordinate = position;
   annotation.title = @"Hello Huawei Map";
   annotation.subtitle = @"This is a subtitle!";
   [self.mapView addAnnotation:annotation];
   ```

   <br />

2. 实现customCalloutForAnnotationView对应的代理。

   <br />

   ```
   - (UIView *)mapView:(HMapView *)mapView customCalloutForAnnotationView:(HAnnotationView *)annotationView
   {
       return [[UIImageView alloc] initWithImage:[UIImage imageNamed:@"HMapKit.bundle/mapLogoInfo"]];
   }
   ```
