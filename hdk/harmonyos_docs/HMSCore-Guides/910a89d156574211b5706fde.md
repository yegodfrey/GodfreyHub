# 离线用户消息覆盖策略

用户设备离线时，Push服务器会根据[collapse_key](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5318198112317)的值对离线消息进行缓存，用户设备上线后缓存消息会再次下发，取值如下：

* 0：对每个应用发送到该用户设备的离线消息只会缓存最新的一条。
* -1：对所有离线消息都缓存（默认值）。
* 1\~100：离线消息缓存分组标识。设置后将对离线消息进行分组缓存，每个应用每一组最多缓存一条离线消息。

如果您发送了10条消息，其中前5条消息携带的collapse_key为1（该五条消息为"1"组），后5条的collapse_key为2（该五条消息为"2"组）。那么待用户上线后collapse_key为1和2的分别下发最新的一条消息给用户。

消息体示例：

```
{
    "validate_only": false,
    "message": {
        "notification": {
            "title": "message title",
            "body": "message body"
        },
        "android": {
            "collapse_key": 0,
            "notification": {
                "click_action": {
                    "type": 2,
                    "url": "https://example.com"
                }
            }
        },
        "token": [
            "pushtoken1"
        ]
    }
}
```
