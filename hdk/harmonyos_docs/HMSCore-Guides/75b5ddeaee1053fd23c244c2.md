# 路径规划

## 概述

如果您的应用需要请求路径规划以获取路线信息，您首先需要获取导航([MapNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924))实例并手动设置apiKey([setApiKey](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section968033519344))，然后设置运营主体([setDevServerSite](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section105571034102916))，针对步骑行驾车，设置（[RoutingRequestParam](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/routingrequestparam-0000001257768693)）规划参数；针对公交，设置（[BusCqlRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/buscqlrequest-0000001212829602)）规划参数，根据您指定的交通类型([setVehicleType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section101271922539))，选定规划接口，通过([addMapNaviListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section82191361986))注册监听回调获取路线规划的成功与否。如果您成功完成了路径规划，步骑行驾车可以通过([getNaviPaths](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section4538135315314))获得所有路线信息，公交直接在回调中获取规划信息。
> 说明
>
> 本章节未声明对象请参考导航服务示例代码。

## 初始化导航

请在主线程中声明[MapNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924)类对象，传入Context或Activity类型参数。

```java
"Java"
// 声明MapNavi对象
private MapNavi mapNavi;
// 实例化MapNavi对象
mapNavi = MapNavi.getInstance(this);
```

```kotlin
"Kotlin"
// 声明MapNavi对象
private var mapNavi: MapNavi? = null
// 实例化MapNavi对象
mapNavi = MapNavi.getInstance(this)
```

## 设置鉴权秘钥

请在创建[MapNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924)实例后手动设置apiKey，秘钥申请参见[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001214231910#section169441820428)，请对获取到的秘钥进行编码处理后传入。

```java
"Java"
// 设置api秘钥
mapNavi.setApiKey("************************");
```

```kotlin
"Kotlin"
// 设置api秘钥
mapNavi!!.setApiKey("************************")
```

## 设置运营主体

请在设置完apiKey后设置运营主体，参数见[DevServerSiteConstant](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/devserversiteconstant-0000001257365413)。

```java
"Java"
// 设置运营主体
mapNavi.setDevServerSite(DevServerSiteConstant.DR1);
```

```kotlin
"Kotlin"
// 设置运营主体
mapNavi!!.setDevServerSite(DevServerSiteConstant.DR1)
```

## 注册导航监听

请在主线程中创建[MapNaviListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavilistener-0000001212215832)类对象，实现当前业务所需要的回调方法。

```java
"Java"
// 声明并实例化MapNaviListener对象
private MapNaviListener mapNaviListener = new MapNaviListener() {
  @Override    
  public void onArriveDestination(MapNaviStaticInfo mapNaviStaticInfo) {
  }

  @Override    
  public void onArrivedWayPoint(int wayid) { 
  }

  @Override    
  public void onCalculateRouteFailure(int errCode) {
  }
  ......
};
// 注册监听
mapNavi.addMapNaviListener(mapNaviListener);
```

```kotlin
"Kotlin"
// 声明并实例化MapNaviListener对象
private val mapNaviListener: MapNaviListener = object : MapNaviListener() {
  override fun onArriveDestination(mapNaviStaticInfo: MapNaviStaticInfo) {
  }

  override fun onArrivedWayPoint(i: Int) {
  }

  override fun onCalculateRouteFailure(i: Int) {
  }
  ......
}
// 注册监听
mapNavi!!.addMapNaviListener(mapNaviListener)
```

通过[setVehicleType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section101271922539)设置导航交通类型，此处以驾车为例。

## 驾车/步行/骑行规划参数初始化

> 说明
>
> 导航偏好策略驾车有时间最短、避免轮渡、避免高速等，其中避免轮渡、避免收费可组合。步骑行仅可设置是否避免轮渡。

```screen
"Java"
// 起点（需业务实例化）
private NaviLatLng hwFrom; 
// 终点（需业务实例化）
private NaviLatLng hwTo;
// 途经点（需业务填充,非必须）
private ArrayList<NaviLatLng> mWayPoints = new ArrayList<>(); 
// 时间最短
private boolean saveTime = false; 
// 避免轮渡
private boolean avoidFerry = false;  
// 避免高速
private boolean avoidHighway = false;
// 避免收费 
private boolean avoidToll = false; 
// 距离最短
private boolean saveDistance = false;
// 智能路线
private boolean smartRecommend = false;
// 交通方式（需业务填充）
private VehicleType mVehicleType = VehicleType.DRIVING;
// 声明RoutingRequestParam
private RoutingRequestParam routingRequestParam;
// 实例化RoutingRequestParam 
routingRequestParam = new RoutingRequestParam();
// 添加规划起终点
List<NaviRequestPoint> fromPoints = new ArrayList<>();
NaviRequestPoint fromPnt = new NaviRequestPoint();
fromPnt.setPoint(hwFrom);
fromPoints.add(fromPnt);
List<NaviRequestPoint> toPoints = new ArrayList<>();
NaviRequestPoint toPnt = new NaviRequestPoint();
toPnt.setPoint(hwTo);
toPoints.add(toPnt);
// 添加途经点
List<NaviRequestPoint> wayPoints = new ArrayList<>();
if (mWayPoints != null) {
  for (NaviLatLng naviLatLng : mWayPoints) {        
    NaviRequestPoint requestWayPoint = new NaviRequestPoint();        
    requestWayPoint.setPoint(naviLatLng);        
    wayPoints.add(requestWayPoint);    
  }
}
// 导航偏好策略
NaviStrategy naviStrategy = new NaviStrategy();
if (mVehicleType.equals(VehicleType.DRIVING)) {    
    naviStrategy.setSaveTime(saveTime);    
    naviStrategy.setAvoidFerry(avoidFerry);    
    naviStrategy.setAvoidHighway(avoidHighway);    
    naviStrategy.setAvoidToll(avoidToll);    
    naviStrategy.setSaveDistance(saveDistance);    
    naviStrategy.setSmartRecommend(smartRecommend);
} else {    
    naviStrategy.setAvoidFerry(avoidFerry); 
}
Log.i(TAG, "vehicleType: " + mVehicleType.name() + " navi strategy: ");
routingRequestParam.setFromPoints(fromPoints);
routingRequestParam.setToPoints(toPoints);
routingRequestParam.setWayPoints(wayPoints);
routingRequestParam.setStrategy(naviStrategy);
```

## 公交规划参数初始化

```screen
"Java"
// 终点（需业务初始化）
private EditText busEnd;
// 起点（需业务初始化）
private EditText busStart;
// 备选路线个数（需业务初始化）
private EditText alternatives;
// 返回信息（需业务初始化）
private EditText returnArray;
// 步行距离（需业务初始化）
private EditText pedestrianMaxDistance;
// 最大换乘次数（需业务初始化）
private EditText changes;
// 步行速度（需业务初始化）
private EditText pedestrianSpeed;

String latLngStr = busStart.getText().toString();
String[] latLngArrayStart = latLngStr.split(",");

String latLngStr2 = busEnd.getText().toString();
String[] latLngArrayEnd = latLngStr2.split(",");

int alternativesValue = Integer.parseInt(alternatives.getText().toString());
int changeValue = Integer.parseInt(changes.getText().toString());

String returnStr = returnArray.getText().toString();
String[] returnArrayValue = returnStr.split(",");

int pedestrianMaxDistanceValue = Integer.parseInt(pedestrianMaxDistance.getText().toString());
int pedestrianSpeedValue = Integer.parseInt(pedestrianSpeed.getText().toString());

BusCqlRequest routePlan = new BusCqlRequest();
Origin or = new Origin();
if (1 < latLngArrayStart.length) {
    or.setLat(Double.parseDouble(latLngArrayStart[0]));
    or.setLng(Double.parseDouble(latLngArrayStart[1]));
}

Destination des = new Destination();
if (1 < latLngArrayEnd.length) {
    des.setLat(Double.parseDouble(latLngArrayEnd[0]));
    des.setLng(Double.parseDouble(latLngArrayEnd[1]));
}

routePlan.setOrigin(or);
routePlan.setDestination(des);
routePlan.setReturnMode(returnArrayValue);
routePlan.setAlternatives(alternativesValue);
routePlan.setLanguage("en");
// 0 公制 1 英制
routePlan.setUnits(0); 
routePlan.setChanges(changeValue);
routePlan.setPedestrianSpeed(pedestrianSpeedValue);
routePlan.setPedestrianMaxDistance(pedestrianMaxDistanceValue);
if (mapNavi != null) {
    mapNavi.setVehicleType(VehicleType.BUS);
    mapNavi.calculateBusDriveRoute(routePlan);
}
```

```java
"Java"
// 请求驾车规划路线接口
mapNavi.calculateDriveRoute(routingRequestParam);
```

```kotlin
mapNavi!!.calculateDriveRoute(routingRequestParam)
```

## 获取规划结果

通过回调获取规划成功与否，此处以驾车为例。

```java
"Java"
private MapNaviListener mapNaviListener = new MapNaviListener() {
  ......
  // 驾车规划成功回调
  @Override
  public void onCalculateRouteSuccess(int[] routeIds, MapNaviRoutingTip mapNaviRoutingTip) {  
      // 规划成功后可通过mMapNavi.getNaviPaths()获取所有路线   
      Map<Integer, MapNaviPath> naviPaths = mapNavi.getNaviPaths(); 
      String routeInfo = "";    
      Iterator<Map.Entry<Integer, MapNaviPath>> iterator = naviPaths.entrySet().iterator(); 
      while (iterator.hasNext()) {        
        Map.Entry<Integer, MapNaviPath> entry = iterator.next();
        // 路线id        
        Integer routeId = entry.getKey();  
        // 路线信息对象     
        MapNaviPath naviPath = entry.getValue(); 
      }      
  }
  // 驾车规划失败回调
  @Override
  public void onCalculateRouteFailure(int errCode) {
      // errCode为规划失败的错误码
      ToastUtil.showToast(this, "drive cal fail, error: " + errCode); 
  }
  ......
};
```

```kotlin
"Kotlin"
private val mapNaviListener: MapNaviListener = object : MapNaviListener() {
  ......
  // 驾车规划成功回调
  override fun onCalculateRouteSuccess(ints: IntArray, mapNaviRoutingTip: MapNaviRoutingTip) {
    val naviPaths: Map<Int, MapNaviPath> = mapNavi!!.naviPaths
    var routeInfo = ""
    val iterator = naviPaths.entries.iterator()
    while (iterator.hasNext()) {
        val (routeId, naviPath) = iterator.next()
        routeInfo += (" routeId: " + routeId + " routeInfo: " + "{ distance: " + naviPath.allLength
                + "m passTime: " + naviPath.allTime + "s trafficNum: " + naviPath.trafficLightNum + "}")
    }
    Log.i(TAG, "route size：" + naviPaths.size + " routeInfo: " + routeInfo)
    showToast(this, "route size：" + naviPaths.size + " " + routeInfo)
  }

  // 驾车规划失败回调
  override fun onCalculateRouteFailure(errCode: Int) {
      // errCode为规划失败的错误码
      showToast(this@ApiTestActivity, "drive cal fail, error: $errCode")
  }
  ......
}
```
