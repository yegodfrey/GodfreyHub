# 集成SDK  
  
#### 采用npm方式集成SDK

                1. 如果未启用第三方NPM库，即快应用项目的目录下无“package.json”文件，使用以下方式来创建：

依次点击菜单栏中的“Npm > 启用第三方NPM库”，即可生成“package.json”文件，同时生成fa-toolkit tgz压缩包。

                2. 通过运行以下npm命令，安装SDK软件包。
                       
                       npm install --save @hw-hmscore/analytics-sdk-quickapp
