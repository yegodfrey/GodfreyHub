# 概述  
  
变量是在条件、代码中使用的占位符，例如，“Element Text”变量在Web应用中用来获取目标DOM元素的文本内容。

变量可用在条件和代码中：

                * 在条件中：变量用来定义过滤条件，以指定应在何时触发特定代码。例如，当“Event”等于“DTM”时触发条件。
                * 在代码中：变量用来捕获动态值。例如，在代码中标识商品名称和商品价格。

DTM提供了一些预定义的变量，可满足大多数代码和条件的配置需求。若预设变量无法覆盖一些特定要求，您还可以通过创建自定义变量实现。目前总共支持了30种预设变量，以及13种自定义变量。

                * 预设变量：预先创建且不可定义的特殊类型的变量，预设变量无需您指定任何信息便可以在应用系统中获取到相关的值。
                * 自定义变量：您可以自己创建变量，并定义获取数据的方式，以满足预设变量可能无法涵盖的特定要求。

分类 | **变量名称** | **变量含义**  
---|---|---  
实用工具 | Config ID | 当前配置的ID。  
Config Version | 当前配置的版本号。  
Event | 触发事件名称。  
Random Number | 随机数字。取值范围为[0, 2147483647）。  
Undefined Value | 未定义的值。 说明： 
                * DTM 5.0.4版本，您可在自定义变量中配置Undefined Value（未定义的值）。从DTM 5.1.0版本起，将在“配置预设变量”中配置该项。
                * DTM 5.1.0版本可兼容您在DTM 5.0.4版本配置的自定义变量“Undefined Value（未定义的值）”。  
页面元素 | Element | 当条件“点击>所有元素”、“点击>仅链接”或“表单提交”被触发后，通过记录层中的element_键，获取目标DOM元素对象的引用。  
Element Classes | 当条件“点击>所有元素”、“点击>仅链接”或“表单提交”被触发后，通过记录层中的elementClasses_键，获取目标DOM元素的Class。  
Element ID | 当条件“点击>所有元素”“、点击>仅链接”或“表单提交”被触发后，通过记录层中的elementId_键，获取目标DOM元素的ID。  
Element Target | 当条件“点击>所有元素”、“点击>仅链接”或“表单提交”被触发后，通过记录层中的elementTarget_键，获取目标DOM元素的目标对象的引用。  
Element Text | 当条件“点击>所有元素”、“点击>仅链接”或“表单提交”被触发后，通过记录层中的elementText_键，获取目标DOM元素的文本内容。  
Element Type | 当条件“点击>所有元素”、“点击>仅链接”或“表单提交”被触发后，通过记录层中的elementType_键，获取目标DOM元素的标签类型。  
Element URL | 当条件“点击>所有元素”、“点击>仅链接”或“表单提交”被触发后，通过记录层中的elementUrl_键，获取目标DOM元素的网址。  
错误 | Error Line | 当条件“JavaScript 错误”被触发后，通过记录层中的errorLine_键，获取报错所在行的行号。  
Error Message | 当条件“JavaScript 错误”被触发后，通过记录层中的errorMessage_键，获取报错消息。  
Error URL | 当条件“JavaScript 错误”被触发后，通过记录层中的errorUrl_键，获取错误网址。  
Preview Mode | 用于获取预览状态。若处于预览模式时，返回值为true；否则，返回值为false。  
历史记录 | History Source | 当条件“历史记录变更”被触发后，通过记录层中的historySource_键，获取历史记录来源。  
New History Fragment | 当条件“历史记录变更”被触发后，通过记录层中的newHistoryFragment_键，获取历史记录事件发生后相应网址的片段（即“#”后的字符串）。  
New History State | 当条件“历史记录变更”被触发后，通过记录层中的newHistoryState_键，获取触发历史记录事件的状态对象。  
Old History Fragment | 当条件“历史记录变更”被触发后，通过记录层中的oldHistoryFragment_键，获取历史记录事件发生前相应网址的片段（即“#”后的字符串）。  
Old History State | 当条件“历史记录变更”被触发后，通过记录层中的oldHistoryState_键，获取历史记录事件发生前处于活动状态的状态对象。  
网页 | Page Hostname | 当前网址中的主机名。  
Page Path | 当前网址中的路径。  
Page URL | 当前网页的完整网址。  
Referrer | 当前网页的引荐来源网址。  
滚动 | Scroll Depth Threshold | 当条件“滚动深度”被触发后，通过记录层中的scrollDepthThreshold_键，获取“滚动深度”的阈值。 如果单位是“percent”，阈值为[0-100]闭区间的数值；如果单位是“pixels”，阈值为像素数。  
Scroll Depth Units | 当条件“滚动深度”被触发后，通过记录层中的scrollDepthUnits_键，获取“滚动深度”的单位。 其值为“percent”或“pixels”（即“百分比”或“像素”）。  
Scroll Direction | 当条件“滚动深度”被触发后，通过记录层中的scrollDirection_键获取的字符串，表示“滚动深度”的方向。 其值为“vert”或“horiz”（即“垂直”或“水平”）。  
可见性 | Visible Duration | 当条件“元素可见性”被触发后，通过访问recordTier中的visibleDuration_键，获取元素可见的时长。  
Visible Ratio | 当条件“元素可见性”被触发后，通过记录层中的actualScreenRatio_键，获取目标元素在当前页面上的可见百分比。  
  
分类 | 变量名称 | 变量含义  
---|---|---  
网页变量 | 自定义JavaScript | 输入一段有返回值的JavaScript函数，函数执行成功的返回值即为该自定义变量的值。 若函数执行失败或函数未定义返回值，则该自定义变量的值为undefined。 不建议在函数中包含eval、with、Function等关键字。  
[第一方Cookie](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section4878745135513) | 用于获取当前所在网域的第一方Cookie的值。  
JavaScript变量 | 用于获取全局JavaScript变量。  
[记录层变量](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section15441195972910) | 用记录层中的一个键值，标识一个自定义变量，其中“记录层变量名”是键值，记录层由键值对列表组成。 记录层变量可以被代码、条件，甚至其他变量引用，相关操作请参见[记录层变量](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-management-example-0000001089362781#section8637144015482)。  
页面元素 | [DOM元素](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section2926329115612) | 用于获取目标Dom元素的文本内容或指定的元素属性的值。  
[元素属性](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section1498915233174) | 提取触发条件（点击或表单提交）相关元素的属性。  
[元素可见性](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section109354345317) | 用于获取单个目标元素的可见状态，其输出的值有两种类型：
                * True/False：表示元素是否可见；可指定元素最低可见百分比，即元素在屏显示部分与整个元素的比值必须不小于该百分比，才会返回true。
                * 百分比：表示有多少百分比的元素在屏幕上可见，取值范围为0至100。  
其他 | [Google Analytics设置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section975919519614) | 用于设置Google Analytics的共通参数，以方便被多个跟踪器代码引用。 其包含的字段都将作为参数传递给Google Analytics代码。  
实用工具 | [正则表达式表格](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section5607203118274) | 用于使正则表达式表格随选定的变量值自动变化的一组键值对，根据输入的键值从正则表达式表格中获取对应的输出值。  
常量 | 该变量用来设定一个固定的值。  
[映射表](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section17147145202919) | 用于使映射表随选定的变量值自动变化的一组键值对，根据输入的键值从映射表中获取对应的输出值。  
网址 | [网址](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section2838233301) | 该变量可以获取网址的组成部分。其输入是当前页面的网址（通过document.location获取）。 网址被解析后的组成部分，包括：完整网址、协议、主机名、端口、路径、文件扩展名、参数等。  
[HTTP来源网址](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-variable-data-types-0000001070328227#section19441176205517) | 该变量用来获取网址的组成部分。其输入是指向当前页面的上一页面的网址（通过document.referrer获取）。 网址被解析后的组成部分，包括：完整网址、协议、主机名、端口、路径、文件扩展名、参数。
