# 全球速卖通集成HUAWEI Account Kit，提升注册转化

#### 全球速卖通简介

全球速卖通是全球最大的跨境零售平台之一，全球累计买家超过1.5亿，致力于联结中国卖家和国际消费者，在助力卖家实现商业成功的同时为买家用户提供更智能的购物方式。

#### 业务挑战

* 将广告转化为注册用户难 全球速卖通在将广告转化为注册用户方面遇到困难，限制了平台发展和卖家销售。之前，人们如果想从该平台购买商品，必须首先完成一系列登录操作，费时费力。比如，平台要求人们提供大量个人信息方能进行身份认证，这个过程常常出现问题。有的用户比较谨慎，往往不愿意向新网站或不熟悉的网站提供个人信息，因此很可能在这个过程中直接放弃商品购买。在时间有限的情况下，比如商品限量或限时抢购，这些流程问题尤其突出。

* 需要保护用户安全隐私 购物类App涉及到用户使用帐号与平台和其他第三方商家完成交易，需要完善的帐号保护机制来为用户的数字资产和信息保驾护航。

#### 解决方案

* 轻轻一点，快捷注册登录 集成华为帐号服务后，用户只需点击"华为帐号登录"按钮，便能使用其华为帐号登录到全球速卖通平台。特别是在新用户参加促销活动、抢购商品等需要快速登录的场景下，只需一次授权，无需繁琐注册，即可成为平台用户。

* 跨帐号保护，安全隐私无忧 华为帐号服务支持双因子（密码加验证码）身份验证，提供基于RISC的跨帐号保护功能，将帐号异动及时推送给应用，保护用户帐号安全。并遵循GDPR合规要求和OAuth 2.0及OpenID Connect等行业标准协议。同时，华为帐号还获得了欧洲隐私保护认证权威组织EuroPriSe的隐私保护认证，利用先进的行业标准技术来保护用户的隐私和数据。

#### 合作收益

集成华为帐号服务后一年内：

* 有46万+用户通过华为帐号登录全球速卖通。
* 简化了用户操作，提高了注册转化率。
