# 撤销订阅

在收到用户申诉误购买该订阅型商品或不需要该订阅型商品的情况下，您可以调用华为应用内支付服务器提供的撤销订阅接口终止服务，购买的订阅型商品立即消失，同时这笔订阅费用会立即发起返还；可在您或者华为在怀疑用户有欺诈行为时使用。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135213.08858700664431994621960627197386:50001231000000:2800:995693E1DC1B65091385412E370D1D74A25EB787F3F747A526E028CDE58F9668.png)  
退款发起后，需要一定的时间才能到账。如果您希望处理其他往期收据的费用返还，或者最新收据的剩余费用返还，建议联系本地运营或[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)进行退款。

具体实现请参见[撤销订阅](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-unsubscribe-0000001051066056)。
