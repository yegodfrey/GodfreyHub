# 概述  
  
变量是在条件、代码中使用的占位符，例如，“App Name”变量在iOS应用中用来指代当前应用的名称。

变量可用在条件和代码中： 
                * 在条件中：变量用来定义过滤条件，以指定应在何时触发特定代码。例如，当“应用名称”为“DTM”时触发条件。
                * 在代码中：变量用来捕获动态值。例如，在代码中标识商品名称和商品价格。

DTM提供了一些预定义的变量，可满足大多数代码和条件的配置需求。若预设变量无法覆盖一些特定要求，您还可以通过创建自定义变量实现。目前总共支持了18种预设变量，以及6种自定义变量。

                * 预设变量：预先创建且不可定义的特殊类型的变量，预设变量无需您指定任何信息便可以在应用系统中获取到相关的值。
                * 自定义变量：您可以自己创建变量，并定义获取数据的方式，以满足预设变量可能无法涵盖的特定要求。

分类 |  **变量名称** |  **变量含义**  
---|---|---  
应用 |  App ID |  应用ID，需设置应用包名。  
App Name |  应用名称。  
App Version Name |  应用版本名称。  
App Version Code |  应用版本号。  
SDK Version |  SDK版本。  
配置 |  Configuration ID |  提供配置ID。  
Configuration Version |  发布的配置版本。  
设备 |  Device ID |  设备ID。  
Device IP address |  设备IP。  
Device Name |  设备名称。  
Language |  用户设置的语言。  
Limit OAID tracking |  是否启用广告跟踪。  
OAID |  苹果广告标识符。  
OS Version |  应用所在的操作系统版本，返回结果为字符串，例如：“10”。  
Platform |  操作系统（“iOS”）。  
Screen Resolution |  当前运行应用的设备的屏幕分辨率，格式为“宽x高”。  
华为分析 |  Event Name |  返回条件触发的事件名称。  
实用工具 |  Random Number |  生成一个0到2147483647之间的随机整数。  
  
**变量类型** |  **变量含义**  
---|---  
Branch设置 |  Branch变量提供了整型、浮点型、布尔、字符型、数组和键值对这些不同的数据类型。当您使用Branch模板时，您可以根据Branch模板字段的取值范围引用对应类型的Branch变量。  
函数调用 |  当您需要获取一个自定义的变量值时，可以选择函数调用变量，此时您需要指定一个实现了[CustomVariable](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-icustomvariable-0000001061142220)的类的路径，代码运行时将变量值设置为您指定这个类的返回值。在DTM界面配置函数调用变量时，可以配置参数输入值，在您实现接口的类中可以使用这些参数值。  
常量 |  将变量值设置为您指定的常量值。  
映射表 |  是一组键值对，根据输入的键值从映射表中获取对应的参数值，通过映射表，您可以令变量值随输入的变量值自动变化。 如下表，当应用已发布多个版本，版本号“App Version Code”分别为1.0、2.0、3.0，假设此时您定义的变量“Version ID”在不同的应用版本中需要设置不同的参数值，那么您可以通过映射表定义出各个版本的参数值映射关系，代码执行时，通过匹配版本号获取参数值。  
事件参数 |  通常用于代码运行期间从事件上下文中获取上报事件的参数值。  
用户属性 |  用于在执行跟踪代码时获取用户属性值，[用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-analytics-0000001050164675#section1641515536302)值是由HUAWEI Analytics平台设置，您也可以在DTM管理界面为用户属性设置默认值，如果在代码运行期间获取不到用户属性，采用默认值；如果获取不到用户属性且未设置默认值，则对应的属性值为空。
