# 通知栏消息大文本样式

通知栏消息提供了多行文本的样式，该样式（[big_title](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p832028132315)和[big_body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p03201818232)）支持标题单行，内容文字多行（中英文都可显示10余行）。大文本展开后效果如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095830.01649188964993970043263792033195:50001231000000:2800:1B16A64AD5AF83DEC8227F758B92F1D8FC2B083A23D46D352FCBAFB1E9EA0C68.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

消息体示例：

```screen
{
    "validate_only": false,
    "message": {
        "android": {
            "notification": {
                "title": "message title",
                "body": " message body",
                "click_action": {
                    "type": 3
                },
               "style": 1,
"big_title": "推送服务",
"big_body": "推送服务（Push Kit）是华为提供的消息推送平台，建立了从云端到终端的消息推送通道。您通过集成推送服务SDK，可以向客户端应用实时推送消息，构筑良好的用户关系，提升用户的感知度和活跃度。"
            }
        },
        "token": ["pushtoken1"]
    }
}
```

> 说明
>
> EMUI 9.1：大文本样式展开之前显示的标题与内容取自[title](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1031808192312)与[body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p133199817236)字段，非[big_title](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p832028132315)与[big_body](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p03201818232)字段的内容。
>
> EMUI 10及以上版本，HarmonyOS 3.0以下版本：大文本样式展开之前显示的标题取自"title"字段，内容取自"big_body"字段。
>
> HarmonyOS 3.0及以上版本：大文本样式展开之前显示的标题与内容取自"title"与"body"字段。
