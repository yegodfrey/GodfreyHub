# 应用数据存储

#### 场景介绍

云盘中应用程序数据文件夹是一个特殊的隐藏文件夹，您的应用可以使用这个文件夹存储应用特定的数据，例如配置文件、存档等。当您尝试在其中创建文件时，将自动创建应用数据文件夹。使用此文件夹存储用户不应该直接交互的任何文件。该文件夹只能由您的应用访问，并且其内容对用户和其他云盘应用程序都是隐藏的。当用户从云盘取消授权您的应用程序时，该应用数据文件夹将被删除。当然，您的应用也可以提供相关功能，让用户在您的应用中手动删除应用程序的某些数据文件或文件夹。  

#### 开发步骤

1. 调用[Files:create.multipart](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filescreatemultipart-0000001050151694)接口上传（备份）文件到应用目录。

   <br />

   用户向应用数据文件夹上传文件，需要在执行[Files:create.multipart](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filescreatemultipart-0000001050151694)请求的时候，指定文件的父目录为应用数据的根路径："applicationData"。

   请求示例：

   ```
   POST https://driveapis.cloud.huawei.com.cn/upload/drive/v1/files?uploadType=multipart&fields=* HTTP/1.1
   Content-Type: multipart/related;boundary=OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO
   Cache-Control: no-cache 
   Authorization: Bearer CV3PnPLZXyr9K2GV7RYZkF962JZvoEkMQhTho3QHQAPQUyma/lEyZskP/IMWrc7FvaeHivO7y0lyibI/fQvulBnTgtXArSVPsjaLKvYNkDsJSaIR2/sx+K40bYDWWpKFvJNKg2U47jRwz2mfiF3ortNk

   --OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO
   Content-Type: application/json; charset=UTF-8
   content-transfer-encoding:binary

   {
     "fileName":"zztest0014",
     "contentExtras": {
        "thumbnail":{
           "content":"dGVzdDAwMw==",
           "mimeType":"image/png"
           }
     },
     "parentFolder":["applicationData"]
   }
   --OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO
   Content-Type: application/json; charset=UTF-8
   content-transfer-encoding: binary

   [imageData]
   --OP8XTaXZ0UZs-Sjlefcj2OWskqXWwVQO--
   ```

   <br />

2. 调用[Files.List](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-fileslist-0000001050153649)接口搜索应用目录下的文件。

   <br />

   在[Files.List](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-fileslist-0000001050153649)请求中设置Containers参数为"applicationData"，即可读取到已经上传到应用数据文件夹下所有文件信息。

   请求示例：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files?fields=*&containers=applicationData HTTP/1.1
   Content-Type: application/json
   Authorization: Bearer CV3PnPLZXyr9K2GV7RYZkF962JZvoEkMQhTho3QHQAPQUyma/lEyZskP/IMWrc7FvaeHivO7y0lyibI/fQvulBnTgtXArSVPsjaLKvYNkDsJSaIR2/sx+K40bYDWWpKFvJNKg2U47jRwz2mfiF3ortNk
   Cache-Control: no-cache
   Accept: application/json
   ```

   <br />

3. 调用[Files.Get](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filesgetmetadata-0000001050153645)接口查询文件信息。

   <br />

   调用[Files.Get](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filesgetmetadata-0000001050153645)接口，获取已查询到的应用文件目录下的文件元数据：

   请求示例：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}?fields=* HTTP/1.1 
   Accept: application/json 
   Cache-Control: no-cache 
   Authorization: Bearer CF3NTYZSs7MRmxWyj8ssonQQxDgSPAjnDvrf+91NrpN22LdUrMA30A5Kzz0mf55sWao7e7VeLrmjQ0z2OmwPWlt3S00/L1BJppbTFhIgWb74ZBK8CFImUA==
   ```
