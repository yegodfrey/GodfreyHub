# 应用场景介绍  
  
#### DTM帮助运营人员优化广告投放效果

借助DTM配置代码上报至数据分析平台，分析用户喜好的节目分类与投放素材是否相符，优化广告效果。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/dh_IAaKYRgetGUVLf5ayGg/zh-cn_image_0000001171505811.png?HW-CC-KV=V1&HW-CC-Date=20261005T043131Z&HW-CC-Expire=86400&HW-CC-Sign=F1B8A51B623B4FF6CAA1024DBC2B1586A51457802B4F8FF12995428706D832DF)

**场景描述**

                1. 运营人员在广告平台上投放展示广告，推广App。
                2. 用户点击广告，下载并使用App。
                3. 运营人员借助DTM，配置代码上报规则并发布版本。App自动更新配置并根据配置上报数据到监测分析平台，无需修改App源代码。
                4. 运营人员查看监测分析平台上的监测结果，优化广告投放策略。

#### 利用DTM进行反欺诈分析

某次线上营销活动中，注册用户量突增，运营人员怀疑有虚假用户，利用DTM进行反欺诈分析。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/Dut81ApxTT2FzHjD3A5qZw/zh-cn_image_0000001125467447.png?HW-CC-KV=V1&HW-CC-Date=20261005T043131Z&HW-CC-Expire=86400&HW-CC-Sign=1C5AEBEAF39D80925D105BFBC755E18C35230FDC845CADC995AB25ACB8140531)

场景描述：

                1. 运营人员在DTM配置事件。
                2. 运营人员在DTM配置用户注册时上报相关信息到第三方分析平台，如：设备号、位置、请求来源等。运营人员可以在DTM中动态切换第三方分析平台，而无需发布App的版本。
                3. DTM将配置下发至应用App。
                4. 用户在App侧进行相关操作，如：登录、查询、订购等。
                5. DTM将日常运营数据上报至HUAWEI Analytics平台。
                6. DTM将注册信息上报至第三方平台（反欺诈分析）。

#### Web电子商务

Web电子商务应用场景中，基本流程及上报事件说明如下：

流程 | 事件配置说明  
---|---  
浏览页面 | 针对不同浏览深度上报事件，如浏览页面深度的25%、50%、75%和100%。  
浏览商品列表 | 根据页面比例的划分，如商品列表占整体页面上方30%，则可以设置浏览深度达30%且停留时间超过3秒，作为商品列表事件的触发条件。  
点击商品列表 | 当用户点击了商品列表中的特定商品后，产生事件并发送数据。  
加入收藏夹 | 设置一个“自定义事件”并命名为“collectGood”（加入收藏夹）。 配置代码并引用记录层数据，并推送相关商品数据到数据记录层。
    
    recordTier.push({eventName:"collectGood","sku":good.goods_id,  "salePrice":good.price/ 100 , "goodName":good.goods_name , "colorName":this.currentColor.colorName,"peizhiName":this.currentpeizhi.peizhiName} )  
  
加入购物车 | 设置一个“自定义事件”并命名为“addToCart”（加入购物车）。 配置代码并引用记录层数据，并推送相关商品数据到数据记录层。
    
    recordTier.push({eventName:"addToCart",  "salePrice":good.price/ 100 , "goodName":good.goods_name , "colorName":this.currentColor.colorName,"peizhiName":this.currentpeizhi.peizhiName} )  
  
结算付款 | 设置一个“自定义事件”并命名为“settlement”（结算付款）。 配置代码并引用记录层数据，并推送相关交易整体数据到数据记录层，同时还需要推送相关商品数据myprod到数据记录层。
    
    recordTier.push({ eventName: "settlement","myprod": pushdata,"totalPrice":  this.totalPrice,"transportationCost":transportationCost,"taxPayment":taxPayment} )
    recordTier.push({myprod: [{'sku': 'A','name': 'Cloth','category': 'Apparel','price': 11.99,'quantity': 1},{'sku': 'B','name': 'Fruit','category':'Apparel','price': 10,'quantity': 2}]});
