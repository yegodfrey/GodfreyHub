# 快速接入

## 接入流程

商户支付接入流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5d/v3/Mjl5S9FlRN68zydx3wq__g/zh-cn_image_0000002480320018.png?HW-CC-KV=V1&HW-CC-Date=20260910T132632Z&HW-CC-Expire=31536000000&HW-CC-Sign=5B585BD968AC9CE43F98658053AAA6734D8F4E0CE3E5C50A713861CBE95682FE "点击放大")

1. 商户客户端请求商户服务器创建商品订单。
2. 商户服务器调用华为支付服务提供的[APP预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-base-payment-app-prepay-0000001644063453#section95771727125814)接口获取预下单号（prepayId），然后组建[orderStr](#ZH-CN_TOPIC_0000002480159770__li2127133183016)返回给客户端。
3. 商户客户端调用[pay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142#section160418663212)接口调起华为支付服务客户端收银台。
4. 用户在华为支付服务客户端收银台完成支付。
5. 华为支付服务客户端展示支付结果页，用户关闭支付结果页后华为支付服务客户端会返回支付状态给商户客户端。
6. 支付成功后，华为支付服务器会调用回调接口返回支付结果信息给商户服务器；支付失败场景可能不会有支付结果回调通知。
7. 商户服务器收到支付结果回调响应后，使用SM2验签方式对支付结果进行验签。

> 说明
>
> 支付是否成功可以通过回调通知中的orderStatus的返回状态判断：
>
> * TRX_SUCCESS：交易成功
> * TRX_FAILED：交易失败

## 客户端开发

* **获取orderStr接口入参**

商户服务器通过调用[APP预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-base-payment-app-prepay-0000001644063453#section95771727125814)获取预支付ID（prepayId）后商户服务器需要构建orderStr返回给客户端。

orderStr参数说明

|**参数**|**参数类型**|**是否必填**|**描述**|
|:--------|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|app_id|String|否|应用ID。|
|merc_no|String|是|商户号|
|prepay_id|String|是|预下单id，使用预下单请求生成，有效期2小时。|
|timestamp|String|是|当前时间戳，标准北京时间，时区为东八区，自1970年1月1日 0点0分0秒以来的毫秒数，13位。示例值：1666230721315|
|noncestr|String|是|随机字符串，不长于32位。推荐随机数生成算法。 每笔订单都需要重新生成。|
|sign|String|是|签名，使用除了sign字段以外的其他字段计算签名值。可参考[签名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-signature-rule-0000001538533912#section272163402611)章节|
|auth_id|String|是|开放平台分配的鉴权id，一个商户可配置多套证书，请妥善保管|

* **调起支付收银台**

首先要获取[AggrPayClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142)对象，通过[AggrPayClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142)对象去调用支付接口[pay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142#section160418663212)，代码示例如下：

```screen
String orderStr = "{\"merc_no\":\"***\",\"prepay_id\":\"1230331185102089244382635044\",\"timestamp\":\"1680259863114\",\"noncestr\":\"1487b8a60ed9f9ecc0ba759fbec23f4f\",\"sign\":\"****\",\"auth_id\":\"***\"}";
public void payApi(Activity activity, Handler handler) {
    Runnable runnable = () -> {
        AggrPayClient client = Pay.getPayClient(activity);
        PayResult result = client.pay(orderStr);
        handler.post(() -> {
             // 支付完成结果处理和界面刷新跳转等操作。返回示例见下表
        });
    };
    Thread payThread = new Thread(runnable);
    payThread.start();
}
```

> 注意
>
> 支付接口需要在线程中调用

* **支付结果获取和处理**

1. 调用pay接口后同步返回支付结果[PayResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/aggrpay-entity-pay-result-0000001588233533)，通过Handler发送消息在主线程处理支付结果。

   |参数|类型|描述|参考示例|
   |:---------|:-----|:----|:-------------------------------------------------------------------------------------------------------------------------------|
   |returnCode|string|返回状态码|"0"：表示成功，具体返回参考[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-client-error-code-0000001538150100)|
   |returnMsg|string|返回描述|"success"：表示签约成功|

2. 商户在构建[APP预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-base-payment-app-prepay-0000001644063453)请求参数时，传入了一个callbackUrl。在华为支付服务器完成支付后，将以post方式调用callbackUrl，将支付结果返回给商户服务器。

> 注意
>
> **支付成功，不建议以客户端返回作为用户的支付结果，需以服务器接收到的结果通知或者查询API返回为准。**
