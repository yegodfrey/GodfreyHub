# 概览

地图服务iOS SDK增强版，在iOS SDK基础版功能上新增了自动比例尺、路线、3D标记图标、相机动画、点注释、气泡等功能，满足您更多开发场景需求。

集成地图服务iOS SDK增强版，请联系华为地图运营团队（[mapteam@huawei.com](mailto:mapteam@huawei.com)）开通服务。
