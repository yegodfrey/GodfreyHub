# 获取转化跟踪参数（SDK方式）

## 使用场景

广告主App开发者可通过广告服务提供的SDK，获得App转化跟踪参数，广告主可基于转化跟踪参数进行App推广渠道分析，便于广告主清晰掌握各渠道转化效果分析。

## 注意事项

获取转化跟踪参数前，确保App必须已经集成ads-installreferrer SDK，请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-integrating-sdk-0000001056460552)。

## 开发步骤

1. 创建转化跟踪参数状态监听器。

   实现[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerstatelistener-0000001050064948)监听器接口的两个方法onInstallReferrerSetupFinished和onInstallReferrerServiceDisconnected，转化跟踪参数的响应体为[InstallReferrerResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerresponse-0000001382833793)，示例代码如下所示：

   ```java
   ...
   private static final String TAG = "InstallReferrerSdkActivity";
   private InstallReferrerClient mReferrerClient;

   /**
    * 创建一个监听器
    */
   private InstallReferrerStateListener installReferrerStateListener = new InstallReferrerStateListener() {
       @Override
       public void onInstallReferrerSetupFinished(int responseCode) {
           switch (responseCode) {
               case InstallReferrerClient.InstallReferrerResponse.OK:
                   Log.i(TAG, "connect ads kit ok");
                   // 获取结果
                   try {
                       ReferrerDetails referrerDetails = mReferrerClient.getInstallReferrer();
                   } catch (RemoteException e) {
                       Log.i(TAG, "getInstallReferrer RemoteException: " + e.getMessage());
                   } catch (IOException e) {
                       Log.i(TAG, "getInstallReferrer IOException: " + e.getMessage());
                   }
                   break;
               case InstallReferrerClient.InstallReferrerResponse.FEATURE_NOT_SUPPORTED:
                   Log.i(TAG, "FEATURE_NOT_SUPPORTED");
                   break;
               case InstallReferrerClient.InstallReferrerResponse.SERVICE_UNAVAILABLE:
                   Log.i(TAG, "SERVICE_UNAVAILABLE");
                   break;
               default:
                   Log.i(TAG, "responseCode: " + responseCode);
                   break;
           }
       }
       @Override
       public void onInstallReferrerServiceDisconnected() {
           Log.i(TAG, "onInstallReferrerServiceDisconnected");
       }
   };
   ```

2. 创建[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-0000001050064946)实例。

   1. 调用[InstallReferrerClient.newBuilder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-0000001050064946#section19195452266)创建Builder实例。
   2. 调用[build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-builder-0000001050066895#section8146103013119)创建[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-0000001050064946)实例。

   ```screen
   mReferrerClient = InstallReferrerClient.newBuilder(InstallReferrerActivity.this).build();
   ```

3. 建立转化跟踪参数服务连接。

   1. 创建一个子线程。
   2. 设置[startConnection](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-0000001050064946#section14887175719269)的监听器为已创建的[InstallReferrerStateListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerstatelistener-0000001050064948)监听器。

   ```screen
   private Thread connectThread = new Thread() {
       @Override
       public void run() {
           connect();
       }
   }
   /**
   * 连接转化跟踪参数服务
   */
   private void connect() {
       mReferrerClient = InstallReferrerClient.newBuilder(InstallReferrerActivity.this).build();
       mReferrerClient.startConnection(installReferrerStateListener); 
   }
   ```

   > 说明
   >
   > 建立与转化跟踪参数服务的连接，不要在主线程中调用该方法。
