# 控制运动并获取实时运动数据

Health Service Kit服务提供了开始和结束运动的接口 [startSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section17740331181418)/[stopSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section28481654151411)，开发者可以直接在第三方应用内调用接口，后台控制运动健康App中对应运动状态，无需跳转到华为运动健康App运动界面进行操作，此时运动健康App不会弹出运动页面，而是在后台执行，运动结束时若距离超过100m则会在运动健康App内生成一条运动记录。如果用户绑定了华为穿戴设备，启动运动时，穿戴设备将自动进入运动界面；结束运动时，穿戴设备将自动结束运动。目前支持四种运动类型：室外走、室外跑、室外骑行、室内跑。

Health Service Kit服务同时提供了获取实时运动数据和停止获取实时运动数据的接口[registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section747610169154)/[unregisterSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section10927754101518)，为防止数据丢失，一般在开始运动之前调用获取实时运动数据接口。 如果用户连接了穿戴设备且设备支持心率测量，则可以获取到心率数据。具体场景获取的数据类型请参考[实时运动Bundle对象键值](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-bundle-key-0000001420487908)，回调频率：1秒一次。

控制运动和获取实时运动配合使用顺序一般为：

1. [开始获取实时运动数据](#section332425192413)：[registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section747610169154)。
2. [开始运动](#section1830363413424)：[startSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section17740331181418)。
3. [结束运动](#section1306163474213)：[stopSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section28481654151411)。
4. [停止获取实时运动数据](#section17924161515257)：[unregisterSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section10927754101518)。

使用接口前，需要向华为申请开通权限，并获取用户授权，否则接口将调用失败。
> 说明
>
> * 目前该功能只在手机上支持，智能表不支持。
> * 当用户在运动健康App内启动运动或配对运动器械（通过华为认证的跑步机，椭圆机，划船机，动感单车）后在器械上启动运动，开发者调用[registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section747610169154)接口同样可以获取对应运动的实时数据。

## 开始获取实时运动数据

1. 调用[registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section747610169154)方法，开始获取实时运动数据。
2. 从返回结果中，获取数据类型，请参见[实时运动Bundle对象键值](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-bundle-key-0000001420487908)。

   开始获取实时运动数据的示例代码如下：

   ```screen
   import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
   var sportData;
   HMSHealthKit.registerSportData((result) => {
       if (sportData?.data === result?.data) {
           return;
       } else {
           sportData = result;
       }
       // 实时运动回调
       console.info("startSportData callback: " + JSON.stringify(sportData))
   }, this.$app.$def.hmsData.eventCallbackMap);
   ```

   |参数名称|参数类型|参数描述|可选选项|
   |:-----|:-----|:------------------------------------------------------------------------------------------------------------------------------|:---|
   |result|String|实时运动数据回调，请参见[实时运动Bundle对象键值](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-bundle-key-0000001420487908)。|M|
   [**表2**请求参数]

   > 说明
   >
   > 上面的代码片段中用到this.$app.$def.hmsData.eventCallbackMap为全局事件回调集合，定义方法请参照[初始化模块](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-integration-hms-core-sdk-0000001226760449#section159413421451)。

## 停止获取实时运动数据

1. 调用[unregisterSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section10927754101518)方法，停止获取实时运动数据。
2. 返回查询结果。

   停止获取实时运动数据的示例代码如下：

   ```screen
   import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
   HMSHealthKit.unregisterSportData().then((result) => {
       // 调用成功
       console.info("stopSportData success: " + JSON.stringify(result))
   }).catch((error) => {
       // 调用失败
       console.info("stopSportData fail: " + JSON.stringify(error))
   });
   ```

   |参数名称|参数类型|参数描述|
   |:-----|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |result|String|停止获取实时运动回调JSON体。 * errorCode：请参见：[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-error-codes-0000001181292206)。 * errorMsg：错误信息。 * data：接口调用结果。|
   [**表3**响应参数]

## 开始运动

> 说明
>
> * 室外走/跑/骑行运动所需手机系统权限：GPS定位；存储权限；后台位置权限。
> * 室内跑运动所需手机系统权限：存储权限。

开始和结束运动支持的运动类型常量：

|数据开放类型|常量定义|
|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|室外走|[HMSHealthKitActivityRealTimeType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-hmshealthkitactivityrealtimetype-0000001204692698).SPORT_TYPE_WALK|
|室外跑|[HMSHealthKitActivityRealTimeType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-hmshealthkitactivityrealtimetype-0000001204692698).SPORT_TYPE_RUN|
|室外骑行|[HMSHealthKitActivityRealTimeType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-hmshealthkitactivityrealtimetype-0000001204692698).SPORT_TYPE_BIKE|
|室内跑|[HMSHealthKitActivityRealTimeType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-hmshealthkitactivityrealtimetype-0000001204692698).SPORT_TYPE_TREADMILL|

调用[startSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section17740331181418)方法，启动相应类型的运动，返回查询结果。

**示例代码**：

```screen
import {HMSHealthKit, HMSHealthKitActivityRealTimeType} from '@hw-hmscore/hms-js-health'
HMSHealthKit.startSport(HMSHealthKitActivityRealTimeType.SPORT_TYPE_WALK).then((result) => {
    // 调用成功
    console.info("startSport callback: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.info("startSport callback error: " + JSON.stringify(error))
});
```

|activityType|String|运动类型。取值请参见[HMSHealthKitActivityRealTimeType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-hmshealthkitactivityrealtimetype-0000001204692698)。|必选(M)|

## 结束运动

调用[stopSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-obtaining-real-time-activity-data-0000001249953461#section28481654151411)方法，停止相应类型的运动，返回查询结果。

**示例代码**：

```screen
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.stopSport().then((result) => {
    // 调用成功
    console.info("stopSport success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.info("stopSport fail: " + JSON.stringify(error))
});
```

|:-----|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|result|String|结束运动回调。 * errorCode：请参见：[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-error-codes-0000001181292206)。 * errorMsg：错误信息。|
