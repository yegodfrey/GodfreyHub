# PBOC数字签名验证

用上述[读取内部认证指令响应报文](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-authentication-sign-0000001052151367#ZH-CN_TOPIC_0000001052151367__li16780101615135)做PBOC签名验证。  

#### PBOC数字签名流程

本段说明PBOC数字签名流程，无需操作，用户仅执行[PBOC验签流程](#section1469132943117)。

1. 计算[表1](#ZH-CN_TOPIC_0000001051671371__table22715113192)数据串连组成的HASH，Hash算法为SHA1，H长度为20字节。

   <br />

   |字段名|长度|描述|
   |:--------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |签名的数据格式|1|十六进制，值为"05"。|
   |哈希算法标识|1|标识用于产生哈希结果的哈希算法，SHA1: 01。|
   |标准卡动态数据长度|1|标识标准卡动态数据的字节长度，如当前示例中值为"04"。|
   |标准卡动态数据|4|标准卡产生的动态数据。|
   |填充字节|N - 29|（N-29）个值为'BB'的填充字节。|
   |终端动态数据|变长|命令报文数据域的随机数。即[1](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-authentication-sign-0000001052151367#ZH-CN_TOPIC_0000001052151367__li14475178171317)中生成的随机数。|
   [表1 MSG数据组成表]

   ![](https://media:101782807022691841)  
   N为RSA公钥模长。本文使用RSA2048，则N = 256。

   <br />

2. 将MSG拆分成两部分MSG = MSG1 + MSG2。其中MSG1为[表1](#ZH-CN_TOPIC_0000001051671371__table22715113192)中的"签名的数据格式 + 哈希算法标识 + 标准卡动态数据长度 + 标准卡动态数据 + 填充字节"；MSG2为"终端动态数据"，即[1](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-authentication-sign-0000001052151367#ZH-CN_TOPIC_0000001052151367__li14475178171317)中生成的随机数。
3. 定义N字节的字符串X，X = B + MSG1 + H + E。

   <br />

   ![](https://media:101782807022717842)  
   * B固定为"6A"。
   * E固定为"BC"。
   * H = Hash\[MSG\]，Hash算法为SHA1，H长度为20字节。

   <br />

4. 将X用[publicKey](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-in-applet-0000001052511334#ZH-CN_TOPIC_0000001052511334__li1828546201011)，"RSA/ECB/NoPadding"加密得到S，即为[2](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-authentication-sign-0000001052151367#ZH-CN_TOPIC_0000001052151367__li16780101615135)中的响应报文。  

#### PBOC验签流程

验签流程的伪码见[PBOC验签伪码](#section04026582564)。

1. 获取[2](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-authentication-sign-0000001052151367#ZH-CN_TOPIC_0000001052151367__li16780101615135)中的响应报文S。检查S是否由N个字节组成，N为RSA公钥模长（256字节）。
2. 将S用[publicKey](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-in-applet-0000001052511334#ZH-CN_TOPIC_0000001052511334__li1828546201011)，"RSA/ECB/NoPadding"解密得到X，分隔X = B + MSG1 + H + E。

   <br />

   ![](https://media:101782807022741843)  
   ● B为1字节长

   ● H为20字节长

   ● E为1字节长

   ● MSG1由剩余的N-22个字节组成

   <br />

3. 检查B是否等于"6A"，E是否等于"BC"。
4. 获取X中的MSG1和H。生成MSG（MSG1 + [1](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-read-authentication-sign-0000001052151367#ZH-CN_TOPIC_0000001052151367__li14475178171317)中生成的随机数）。
5. 计算MSG的Hash值，resultH = Hash\[MSG\]，Hash算法为SHA1。
6. 检查resultH是否等于H。等于H则PBOC验签通过，否则终止读卡。

shaEncode伪码：

```
public String shaEncode(String inStr) throws Exception {
   MessageDigest sha = null;
   try {
       sha = MessageDigest.getInstance("SHA");
   } catch (Exception e) {
       System.out.println(e.toString());
       e.printStackTrace();
       return "";
   }

   byte[] byteArray = hexToByteArray(inStr);
   byte[] md5Bytes = sha.digest(byteArray);
   StringBuffer hexValue = new StringBuffer();
   for (int i = 0; i < md5Bytes.length; i++) {
       int val = ((int) md5Bytes[i]) & 0xff;
       if (val < 16) {
           hexValue.append("0");
       }
       hexValue.append(Integer.toHexString(val));
   }
   String result = hexValue.toString();
   return result;
}
```
