# 版本更新说明

#### 6.13.0.301（2025-12-24）

|-------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:push:6.13.0.301 修改特性 解决稳定性和性能问题，您只需要升级版本号即可，无需做其他代码适配。|

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260106120428.47231328682499645702545121511635:50001231000000:2800:94489B4D65BF6D3351F2B978058FAF8523B4B5C7A635BB0FACABAB5886AD39F9.png)  
* 建议您使用最新版本的SDK，体验更丰富的推送服务功能。
* 如何集成HMS Core Installer SDK请参见[添加HMS Core Installer SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-integrating-sdk-0000001050040084#ZH-CN_TOPIC_0000001700731565__li1778761702119)。  

#### SDK依赖说明

* 建议SDK匹配HMS Core（APK）6.12.0.300及以上版本。
* 如果您的应用集成的SDK从老版本（SDK3.0及以下）升级为新版本，Push Token会发生变化，建议您及时上报新Push Token至您的服务端。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)与我们取得联系。

#### 4.0.0.300（2020-01-15）^deprecated^

Android版本：com.huawei.hms:push:4.0.0.300

新增特性

* 新增应用在前台时，通知栏消息展示的功能。
* 新增设置应用自动初始化[setAutoInitEnabled](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650#section19198183125511)方法。
* 优化以下功能支持范围。 主题订阅和退订功能可用于EMUI 8.1及以上版本的终端设备（极少量早期EMUI 8.1设备不支持）。

* 新增WebPush消息推送代理能力。
* 新增iOS应用消息推送代理能力。
* Push服务端变更通知栏消息与透传消息的划分依据。 消息体只要存在message.notification或message.android.notification就代表是通知栏消息。
