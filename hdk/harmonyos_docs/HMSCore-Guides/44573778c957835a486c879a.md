# FAQ

如果您在下面没有找到需要的问题，请加入[Stack Overflow](https://stackoverflow.com/questions/tagged/huawei-mobile-services?tab=Frequent)社区参与讨论。

## App中集成鲸鸿动能SDK后，获取不到广告，errorCode为3？

errorCode为3，说明广告请求成功，但是服务器没有返回可用的广告素材。

以下场景也会返回错误码3：

1. 广告位ID未生效。
2. 广告形式不准确，如请求原生广告时错误地使用了激励视频的广告位ID。
3. 手机连接的网络不正确。
4. 手机设置中的国家/地区选择的是不支持的国家/地区。
5. 手机时间日期不是标准时间。

针对以上场景，请参考以下建议：

1. 可以使用测试广告位ID进行测试。如果是正式广告位ID，请检查鲸鸿动能媒体服务平台中的应用市场状态是否显示上架，媒体状态是否启用。如未启用，请参考[中国大陆区域变现](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/ceshiyanzhengjishangxian-0000001085219714)。
2. 确保不同类型广告请求时，使用相应的形式的广告位ID。
3. 检查手机连接的网络是否正确，避免跨站点请求，相关站点请查看广告服务[支持的国家/地区](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/site-and-country-and-area-code-0000001172734088)。
4. 将手机设置中的国家/地区更改为广告服务[支持的国家/地区](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/site-and-country-and-area-code-0000001172734088)：

   设置 -> 系统和更新 -> 语言和输入法 -> 语言和地区 -> 地区。
5. 将手机时间设置与当前标准时间同步。
6. 如果问题仍然存在，请保留详细的Logcat日志（请务必不要进行过滤，以便技术人员进行定位分析），联系客服支持。

## 未有广告请求类问题？

接入的广告未有展示，首先确认是否有进行广告请求，日志导出路径命令：adb pull /sdcard/Android/data/com.huawei.hwid/files/Log/HiAdKitLog.log。根据广告位id全局搜索，如果没有搜索到信息，则说明并相关广告位id没有进行广告请求。

## 接入的广告存在多余请求？

使用Android studio日志过滤，针对具体广告位ID操作广告过程中，日志搜索关键词addEventToCache, event:response，代表一次请求广告的成功返回，addEventToCache, event:imp 代表广告的一次展示，原则上是一次请求对应一次展示，展示完后需重新实时获取，通过此方法定位排查是否存在多余广告请求。

## 用户未同意隐私协议展示广告？

调用广告请求前，必须展示用户隐私协议。

## 常见广告返回错误码

|错误码|含义|
|:--|:------------------------|
|423|广告位ID在服务端不存在，确认广告位id填写正确。|
|424|广告位ID与应用不匹配。|
|404|请求的广告类型错误。|
|421|广告位ID缺失。|
|405|test字段缺失。|

## 原生广告视频播放不了，一直显示加载中？

在targetSdkVersion 28及以上的手机上会存在广告视频素材下载失败的情况，需要配置App允许HTTP(S)网络请求。请参见[配置网络权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-integrating-sdk-0000001050066913#section19869145195218)进行配置。

对于原生广告的展示需合规，必须要有广告标题、广告标识、广告来源、关闭按钮，关闭按钮的功能，对于国内媒体需要自己实现，广告与广告之间不可重叠，广告中的元素与其文案需显示清楚，不可重叠。

## 激励视频广告播放按钮快速多次点击，会出现多个广告覆盖播放问题？

需要媒体针对按钮事件的点击做一个时间间隔有效判断。

示例代码：

```screen
  private final static long CLICK_INTERVAL = 500;
    private static long mLastClickTime = 0;
 
    protected static boolean isFastClick(){
        if(System.currentTimeMillis() - mLastClickTime < CLICK_INTERVAL) {
            return true;
        }
        mLastClickTime = System.currentTimeMillis();
        return false;
    }
```

## 激励视频未请求到广告，相关提示影响用户体验？

激励视频需提前请求，如果能够成功获取数据，才显示广告入口。

## 横幅广告只有360x57和360x144尺寸可以请求到广告？

如果您使用的是中国大陆版本的手机和网络环境，在中国大陆区域横幅广告暂只支持这2个横幅尺寸。而在海外所有尺寸都支持，连接海外环境测试需要海外版本手机和可以访问海外的网络。

## 横幅广告刷新间隔不能低于30s？

横幅广告刷新时间间隔可在媒体管理后台【媒体管理-展示位】设置，后台设置的生效条件是集成SDK时不调用setBannerRefresh接口。（代码中设置的比后台设置的优先级高）。

## 禁止在onAdLoaded或者onAdFailedToLoad中控制横幅广告的可见性？

横幅广告已由SDK渲染成功，直接用于展示。

## 开屏广告为横屏时，为什么会出现开屏显示不全？

媒体Logo不应展示，否则会出现开屏显示不全。

## 对InterstitialAd或RewardAd做一次初始化，广告关闭之后是否允许再次调用loadAd方法？

允许调用，会被记成多次广告请求或广告展示。

## Ads Kit提供的ads-lite和ads-identifier 2个SDK包有什么不同？

* ads-lite：面向广告媒体开发者。您可以根据适合的场景选择不同的广告类型集成到App中，使用广告服务平台提供的高品质广告服务，实现流量变现。
* ads-identifier：面向广告主开发者。广告平台可基于广告标识符（OAID），向用户提供更加个性化的营销活动或商业广告，提升转化效果。
* ads-installreferrer：面向三方广告平台或三方监测平台开发者。提供的转化跟踪参数（Install Referrer），广告主可以跟踪App的转化渠道，对App推广的转化效果进行深度分析。

## 为什么获取鉴权信息失败？

变现报表接口仅支持OAuth 2.0客户端鉴权，请在开发者联盟界面选择正确的鉴权方式。

## 已经获取过access_token，为什么获取变现报表提示无权限？

access_token信息超时，默认有效时间一小时，需要重新获取access_token信息。

## 如何查看HMS Core的版本？

鲸鸿动能SDK依赖HMS Core（APK）4.0.0.300及以上版本。

查看HMS Core的版本的方法：通过设备上"设置 > 应用 > 应用管理"搜索HMS Core。
