# 使用入门

#### 开发流程

您需要按照流程来完成应用的开发工作。  

|序号|步骤|说明|
|:-|:---------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|接入准备|1. [申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)：因Health Service Kit服务需要用到账号服务的能力，需先申请账号服务才能申请Health Service Kit服务。 2. [申请Health Service Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-kitservice-0000001050071707)：申请产品所需的数据读写权限。 若有除该页面上的其他的需求，请发送邮件到[hihealth@huawei.com](mailto:hihealth@huawei.com)邮箱向我们咨询。|
|2|开发准备|Xcode，iPhone(iOS13及以上)，移动设备内安装华为运动健康App(版本15.0.8.305及以上)|
|3|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/add-permissions-0000001050069726)|集成AuthLoginSDK.framework，实现免登录授权功能。|
