# 使用入门

## 开发环境

JavaScript API目前支持以下平台下的浏览器：

|**浏览器**|**平台**|
|:-------------------|:--------------------|
|Chrome 6x|Windows，Android，macOS|
|Chrome 7x|Windows，Android，macOS|
|Chrome 8x|Windows，Android，macOS|
|Internet Explorer 10|Windows|
|Internet Explorer 11|Windows|
|微信 V7.X.X最新版|Android|
|华为浏览器EMUI 9.X|Android|
|华为浏览器EMUI 10.X|Android|
|Safari 12.x|iOS|
|Safari 13.x|iOS|
|Safari 13.x|macOS|

> 说明
>
> Internet Explorer 10、Internet Explorer 11仅支持栅格地图渲染。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-:|:-----------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006)|在开发应用前，需要完成步骤：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section47264296)、[创建项目](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section92411038172816)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section7940182616297)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section470311311307)、[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section175508543353)。 如果您已经在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站创建了应用，可直接[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section175508543353)使用本服务。|
|2|[开通付费](#section7921102111484)|您可以随时变更订阅的按量付费套餐档次。|
|3|[基础地图](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-basic-map-0000001064621312)|通过华为地图API for JavaScript创建一个简单的网页地图。|
|3|[地图交互](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-map-interaction-0000001064096169)|提供丰富的UI控件与地图交互方式，实现在地图上单击、双击、缩放、移动、改变视角等操作。|
|3|[在地图上绘制](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-drawing-on-map-0000001050162118)|在地图上添加标记、信息窗、图片覆盖物等。|
|3|[自定义地图样式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-map-style-customization-0000001051008477)|在应用中添加自定义风格的地图。|
|3|[路径规划](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-path-planning-0000001050164083)|实现路径规划功能，支持步行、骑行、驾车三种路径规划能力，您可以根据需求集成能力。|
|3|[位置搜索](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-location-search-0000001050162130)|提供丰富的位置搜索功能，包括关键字搜索、周边搜索、地址详情、地点搜索建议、搜索控件。|
|3|[地理编码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-geocoding-0000001050162146)|提供正地理编码与逆地理编码接口，实现地址信息与经纬度坐标相互转换。|
