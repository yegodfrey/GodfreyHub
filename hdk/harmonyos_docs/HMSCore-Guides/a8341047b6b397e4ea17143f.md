# 在旧款华为折叠机上测试的方法

当前仅可在华为MateXs2折叠机上运行，如需在旧款华为折叠机测试，请下载并安装以下链接中的"WebView测试APK"强制启用本产品功能。  

|WebView测试APK|SHA256校验码|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------|
|[HwWebView_DittoTest_signed_demo.zip](https://appfile-cn.dbankcdn.com:443/FileServer/getFile/appAttach/011/111/111/0000000000011111111.20220406113754.82448956821843600728579394853281:20471231000000:0001:EAD090EEA2FB6B3DA99747F91B22DA0D34B657514244CA0C53AB9B05780C68AB.zip?needInitFileName=true)|06212a54d4ca595cb4fd1858da073a7abc7874f61cbda3170a888f116f13f1be|

安装"WebView测试APK"流程：

1. 连接华为折叠机至PC。
2. 开启CMD，输入以下指令安装。

   ```
   adb install D:\HwWebView-DittoTest-signed (1).apk 
   ```
