# 沉默唤醒

## 功能概述

您可以在华为分析中的人群洞察里通过用户分群功能，圈选游戏中沉默人群，通过应用市场Push给这些人群发送优惠券、礼包，促使该人群重新打开游戏，从而提升游戏整体活跃。

## 典型应用场景

唤醒不同沉默天数用户，提升游戏活跃人数。

## 操作流程

1. 圈选不同天数沉默受众。
   1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
   2. 选择需要查看分析数据的应用。
   3. 选择"华为分析 > 人群洞察 > 用户分群"，进入用户分群页面。
   4. 点击"新建"并填写受众群组相关信息，圈选出沉默唤醒的目标用户，详情请参见[如何创建受众](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/audience-analysis-new-0000001113372616#section16141458101015)。 说明
      >
      > 也可以在[留存分析](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/retention-analysis-0000001050745159)、[用户生命周期分析报告](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/user-lifecycle-0000001050985175)中自由圈选受众。
2. 同步受众群组至应用市场活动管理。
   1. 创建受众群组后在用户分群页面点击右上角的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115258.65204514679186301689934421175036:50001231000000:2800:E3EBE3B9C9237B764F77A4311FFF5FF8C37538E16F29E64D06A95CEDEAE43FC5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)或者选择"华为分析 > 管理 > 受众同步管理"，进入受众同步管理页面。
   2. 选择"应用市场活动管理"页签。

      展示当前应用下所有离线受众群组，您可以在页面右上角下拉框处切换应用。
   3. 打开想要同步至应用市场活动管理的受众群组的"同步开关"。

      同步成功后，应用市场活动管理中可选择该群组进行操作。

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115258.30974883404830691452719554889702:50001231000000:2800:92DE4BF399BA10186B41F90F31CBCDDD254333301E10D31273BBB5B9A69CF890.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
3. 创建流失召回活动，针对受众人群发送优惠券或礼包。
   1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
   2. 在应用列表页面选择要创建活动的应用。
   3. 选择"运营 > 活动运营 > 活动管理 > 新建活动"进入新建活动页面。
      * "活动目的"选择"用户维系（流失召回）"，该场景不仅可以适用流失召回，同样可以做新用户促活或者付费转化。
      * "用户类型"选择"受众群组（含预测人群）"，在右侧下拉框中选择需要发送礼包的人群。

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115258.25711441015808561645537389435737:50001231000000:2800:8A6D35ADD15D40867EBB59A1C3D1F34AC25573421417E819C69B7E02C056B4A6.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
   4. 完成新建活动的其他信息后提交审核，详情请参见[活动管理](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help--management-activities-0000001100159966#section7207836203712)。审核通过后华为应用市场将会在设定的时间给目标人群发送礼包。
