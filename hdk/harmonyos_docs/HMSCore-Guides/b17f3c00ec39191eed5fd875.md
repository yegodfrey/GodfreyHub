# 环境光感知能力

## 导入接口类

使用环境光状态感知能力，除需要导入情景感知服务的公共能力类外，还需要导入环境光状态相关的类。

```screen
importcom.huawei.hmf.tasks.OnFailureListener;
importcom.huawei.hmf.tasks.OnSuccessListener;
importcom.huawei.hms.kit.awareness.Awareness;
// 导入环境光快照相关类
import com.huawei.hms.kit.awareness.capture.AmbientLightResponse;
import com.huawei.hms.kit.awareness.status.AmbientLightStatus;
// 导入环境光围栏相关类
import com.huawei.hms.kit.awareness.barrier.AmbientLightBarrier;
import com.huawei.hms.kit.awareness.barrier.AwarenessBarrier;
import com.huawei.hms.kit.awareness.barrier.BarrierStatus;
import com.huawei.hms.kit.awareness.barrier.BarrierUpdateRequest;
```

## 能力开发

### Capture

1. 获取Awareness Kit的"Capture Client"。
2. 通过"Capture Client"调用环境光状态查询能力接口查询情景状态。
3. 根据情景感知服务返回的结果，进行应用的业务处理。

   ```screen
   "Java"
   Awareness.getCaptureClient(this).getLightIntensity()
           // 执行成功的回调监听
           .addOnSuccessListener(new OnSuccessListener<AmbientLightResponse>() {
               @Override
               public void onSuccess(AmbientLightResponse ambientLightResponse) {
                   AmbientLightStatus ambientLightStatus = ambientLightResponse.getAmbientLightStatus();
                   Log.i(TAG, "Light intensity is " + ambientLightStatus.getLightIntensity() + " lux");
               }
           })
           // 执行失败的回调监听
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   Log.e(TAG, "get light intensity failed", e);
               }
           });
   ```

   ```screen
   "Kotlin"
   Awareness.getCaptureClient(this).lightIntensity    
            // 执行成功的回调监听    
            .addOnSuccessListener { ambientLightResponse: AmbientLightResponse ->
                  val ambientLightStatus = ambientLightResponse.ambientLightStatus            
                  Log.i(TAG, "Light intensity is " + ambientLightStatus.lightIntensity + " lux")
            }
            // 执行失败的回调监听
            .addOnFailureListener { e: Exception? -> 
                  Log.e(TAG, "get light intensity failed", e) 
            }
   ```

### Barrier

以下以开发环境光"above"的Barrier为例（当环境光强度大于传入数值时触发Barrier）。

1. 定义Barrier。

   ```screen
   "Java"
   final float luxValue = 2500.0f;
   AwarenessBarrier lightAboveBarrier = AmbientLightBarrier.above(luxValue);
   ```

   ```screen
   "Kotlin"
   val luxValue = 2500.0f
   var lightAboveBarrier : AwarenessBarrier = AmbientLightBarrier.above(luxValue)
   ```

2. 定义Barrier状态改变时触发的"PendingIntent"，同时注册一个广播接收器用来接收这个广播。

   ```screen
   "Java"
   final String BARRIER_RECEIVER_ACTION = getApplication().getPackageName() + "LIGHT_BARRIER_RECEIVER_ACTION";
   Intent intent = new Intent(BARRIER_RECEIVER_ACTION); 
   PendingIntent pendingIntent = PendingIntent.getBroadcast(this, 1, intent, PendingIntent.FLAG_UPDATE_CURRENT);
   LightBarrierReceiver barrierReceiver = new LightBarrierReceiver();
   registerReceiver(barrierReceiver, new IntentFilter(BARRIER_RECEIVER_ACTION));
   ```

   ```screen
   "Kotlin"
   val BARRIER_RECEIVER_ACTION = application.packageName + "LIGHT_BARRIER_RECEIVER_ACTION"
   val intent = Intent(BARRIER_RECEIVER_ACTION)
   val pendingIntent = PendingIntent.getBroadcast(this, 1, intent, PendingIntent.FLAG_UPDATE_CURRENT)
   val barrierReceiver = LightBarrierReceiver()
   registerReceiver(barrierReceiver, IntentFilter(BARRIER_RECEIVER_ACTION))
   ```

3. 定义Barrier对应的标签Label，然后添加Barrier。

   ```screen
   "Java"
   String lightBarrierLabel = "light above barrier";
   // 定义更新围栏的请求
   BarrierUpdateRequest.Builder builder = new BarrierUpdateRequest.Builder();
   BarrierUpdateRequest request = builder.addBarrier(lightBarrierLabel, lightAboveBarrier,pendingIntent).build(); 
   Awareness.getBarrierClient(context).updateBarriers(request)
           // 执行失败的回调监听
           .addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void aVoid) {
                   Toast.makeText(getApplicationContext(), "add barrier success", Toast.LENGTH_SHORT).show();
               }
           })
           // 执行失败的回调监听
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   Toast.makeText(getApplicationContext(), "add barrier failed", Toast.LENGTH_SHORT).show();
                   Log.e(TAG, "add barrier failed", e);
               }
           });
   ```

   ```screen
   "Kotlin"
   val lightBarrierLabel = "light above barrier"
   // 定义更新围栏的请求
   val builder = BarrierUpdateRequest.Builder()
   val request = builder.addBarrier(lightBarrierLabel, lightAboveBarrier, pendingIntent).build()
   Awareness.getBarrierClient(context).updateBarriers(request)
           // 执行失败的回调监听
           .addOnSuccessListener { Toast.makeText(applicationContext, "add barrier success", Toast.LENGTH_SHORT).show() 
           }
           // 执行失败的回调监听
           .addOnFailureListener { e ->
               Toast.makeText(applicationContext, "add barrier failed", Toast.LENGTH_SHORT).show()
               Log.e(TAG, "add barrier failed", e)
           }
   ```

4. 定义广播接收器，用于监听Barrier事件，收到事件后进行应用的业务处理。

   ```screen
   "Java"
   // 定义广播接收器
   class LightBarrierReceiver extends BroadcastReceiver {
       @Override
       public void onReceive(Context context, Intent intent) {
           BarrierStatus barrierStatus = BarrierStatus.extract(intent);
           String label = barrierStatus.getBarrierLabel();
           switch(barrierStatus.getPresentStatus()) {
               case BarrierStatus.TRUE:
                   Log.i(TAG, label + " status:true");
                   break;
               case BarrierStatus.FALSE:
                   Log.i(TAG, label + " status:false");
                   break;
               case BarrierStatus.UNKNOWN:
                   Log.i(TAG, label + " status:unknown");
                   break;
           }
       }
   }
   ```

   ```screen
   "Kotlin"
   // 定义广播接收器
   internal inner class LightBarrierReceiver : BroadcastReceiver() {
   override fun onReceive(context: Context, intent: Intent) {
   val barrierStatus = BarrierStatus.extract(intent)
   val label = barrierStatus.barrierLabel
           when (barrierStatus.presentStatus) {
               BarrierStatus.TRUE -> Log.i(TAG, "$label status:true")
               BarrierStatus.FALSE -> Log.i(TAG, "$label status:false")
               BarrierStatus.UNKNOWN -> Log.i(TAG, "$label status:unknown")
           }
       }
   }
   ```

5. 在应用业务处理完成后，根据Barrier对应的标签Label，进行删除Barrier。

   ```screen
   "Java"
   String lightBarrierLabel = "light above barrier";
   // 定义更新围栏的请求
   BarrierUpdateRequest.Builder builder = new BarrierUpdateRequest.Builder();
   BarrierUpdateRequest request = builder.deleteBarrier(lightBarrierLabel).build(); 
   Awareness.getBarrierClient(context).updateBarriers(request)
           // 执行失败的回调监听
           .addOnSuccessListener(new OnSuccessListener<Void>() {
               @Override
               public void onSuccess(Void aVoid) {
                   Toast.makeText(getApplicationContext(), "delete barrier success", Toast.LENGTH_SHORT).show();
               }
           })
           // 执行失败的回调监听
           .addOnFailureListener(new OnFailureListener() {
               @Override
               public void onFailure(Exception e) {
                   Toast.makeText(getApplicationContext(), "delete barrier failed", Toast.LENGTH_SHORT).show();
                   Log.e(TAG, "delete barrier failed", e);
               }
           });
   ```

   ```screen
   "Kotlin"
   val lightBarrierLabel = "light above barrier"
   // 定义更新围栏的请求
   val builder = BarrierUpdateRequest.Builder()
   val request = builder.deleteBarrier(lightBarrierLabel).build()
   Awareness.getBarrierClient(context).updateBarriers(request)
           // 执行失败的回调监听
           .addOnSuccessListener { Toast.makeText(applicationContext, "delete barrier success", Toast.LENGTH_SHORT).show() 
           }
           // 执行失败的回调监听
           .addOnFailureListener { e ->
               Toast.makeText(applicationContext, "delete barrier failed", Toast.LENGTH_SHORT).show()
               Log.e(TAG, "delete barrier failed", e)
           }
   ```
