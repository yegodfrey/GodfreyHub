# 开发指引

为了让您更合理地使用情景感知服务，避免用户产生误解，建议您遵循以下指引。

* 告知用户使用效果 您的App应当明确向用户说明情景感知能力的使用效果。例如，当您的App设定在早晨当用户插入耳机并开始慢跑时，开始播放"晨跑"音乐列表，需要向用户说明这种行为。如果不加说明且用户不期望这种行为，则可能会导致不良的体验。

* 调用注意事项 为了降低调用情景服务对电池的消耗，请避免注册过多的围栏，否则服务会限制返回信息；同时，避免发出过多的快照请求。当前版本，每5s调用API次数总和不超过20次，每1小时调用的次数总和不超过1000次。5s内注册的围栏的总数不超过500个，包含注册后又删除的围栏数量。

  每个CP ID（用于唯一标识当前开发者）可以同时注册的各类围栏的总和不超过200个。当1个组合围栏下面包含n个原子围栏时，每个原子围栏计1个围栏数，组合围栏计1个围栏数，即该组合围栏的围栏总数为n+1个。
* 给用户提供Beacon围栏关闭功能

  当您的App注册了Beacon围栏后，设备会使用蓝牙功能持续的扫描附近的Beacon设备，而引起额外的电量消耗。您需要向用户说明该情况，并提供接口使用户可以关闭Beacon围栏。用户关闭蓝牙后，您依然可以注册或删除Beacon围栏，但Awareness会暂停Beacon能力服务，当用户开启蓝牙后恢复服务。
* 指定车载蓝牙音响设备类型 使用车载蓝牙API时，需要传入设备类型参数以指定车载蓝牙音响的设备类型。

* 确认各情景感知能力支持状态 调用各情景感知能力前，建议先调用[querySupportingCapabilities](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/awareness-captureclient-0000001050164395#section34481100517)接口确定设备是否支持各情景感知能力。
