# 职业与成人  
  
#### 事件参数列表

            * kHAEventRegisterAccount

用户注册帐号时，上报此事件。可以分析用户来源，有针对性地优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRegistMethod | 用户来源 | String | 可选 | 用户来源。  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如邮箱、手机号、微信等。  
kHAParamInviter | 邀请人 | String | 可选 | 邀请该用户进行注册的用户。  
  
            * kHAEventViewProduct

用户浏览商品时，上报此事件。可以分析用户对哪些商品感兴趣，也可以和其他事件组合完成漏斗分析。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamProductId | 商品ID | String | 必选 | 用户浏览商品的ID。  
kHAParamProductName | 商品名称 | String | 必选 | 用户浏览商品的名称。  
kHAParamProductFeature | 商品特征 | String | 可选 | 用户浏览商品的特征。  
kHAParamCategory | 商品分类 | String | 必选 | 用户浏览商品的分类。  
kHAParamBrand | 商品品牌 | String | 可选 | 用户浏览的商品品牌。  
kHAParamPrice | 商品价格 | Double | 可选 | 商品的价格。  
kHAParamRevenue | 收入 | Double | 可选 | 用户购买此商品，预计会给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
kHAParamEnter | 入口 | String | 可选 | 用户浏览商品的入口。  
  
            * kHAEventStartCheckout

用户下单后，点击结算按钮时，触发此事件。可以与kHAEventViewProduct、kHAEventCompletePurchase等事件结合使用，用于分析电商购买漏斗转化情况。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRevenue | 收入 | Double | 可选 | 会给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
  
            * kHAEventCompletePurchase

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamProductId | 商品ID | String | 必选 | 被添加到购物车中的商品ID。  
kHAParamProductName | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
kHAParamStartDate | 生效日期 | String | 可选 | 购买的商品或服务生效开始日期。  
kHAParamEffectiveTime | 生效时长 | Long | 可选 | 购买的商品或服务生效时长。  
kHAParamQuantity | 购买数量 | Long | 必选 | 用户准备购买的数量。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
kHAParamVoucher | 优惠券名称 | String | 可选 | 用户在本次交易中使用的优惠券。  
kHAParamRevenue | 收入 | Double | 可选 | 本次交易给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamPlace | 位置ID | String | 可选 | 商品所在地标识。  
kHAParamBrand | 商品品牌 | String | 可选 | 关联的商品品牌。  
kHAParamCategory | 商品分类 | String | 可选 | 关联的商品分类。
