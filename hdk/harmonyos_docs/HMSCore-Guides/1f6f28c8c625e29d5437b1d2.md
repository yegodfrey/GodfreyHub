## SDK依赖说明

最新版本SDK需要用户设备上安装HMS Core（APK）6.1.0.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。

### 6.0.1.304（2021-09-15）

|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|HarmonyOS（Java）版本：com.huawei.hms:maps-harmony:6.0.1.304 地图服务推出了全新的HarmonyOS Java SDK 6.0.1.304版本，为您提供了一套基于HarmonyOS应用的地图服务编程接口，帮助您在HarmonyOS应用中集成地图相关能力，欢迎广大开发者接入使用。 **新增特性** 首次发布，提供地图呈现、地图交互、地图绘制能力。 * 地图呈现：支持[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-mapview-0000001101552562)地图容器创建地图、支持设置地图类型与地图初始属性、支持开启地图精简模式。 * 地图交互：支持改变地图相机位置移动相机以达到移动地图的效果、支持设置地图手势开关与内置UI控件自定义用户与地图交互方式、支持地图的点击和长按、相机移动、以及标记点击等事件侦听。 * 地图绘制：支持在地图指定位置添加标记、信息窗、形状。|
