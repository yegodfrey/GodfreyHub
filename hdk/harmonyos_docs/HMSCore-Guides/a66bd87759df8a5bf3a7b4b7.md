# 响应式ViewPager

适用于support v4包和androidx包下的ViewPager控件。

## Maven方式引入aar包

使用前需在build.gradle的dependencies中添加所引用控件的依赖。

HwRspViewPager提供了androidx包下的和support V7包下的ViewPager的支持。

* androidx引入AAR包：

  ```screen
  implementation "com.huawei.ui.rspuikit:hwrspviewpager-androidsupx:{version}"
  ```

* support V7引入AAR包：

  ```screen
  implementation "com.huawei.ui.rspuikit:hwrspviewpager-androidsup:{version}"
  ```

> 说明
>
> *{version}*需替换为实际的版本号，具体版本号请参见版本更新说明章节。例如:implementation '"com.huawei.ui.rspuikit:hwrspviewpager-androidsup:1.0.0.8'。

## 接入HwRspViewPager

项目中已使用support v4包或androidx包下的ViewPager控件情况下，接入HwRspViewPager需要以下步骤

* 如果应用直接使用ViewPager，则直接在代码和layout布局文件中将ViewPager替换成HwRspViewPager：

  ```screen
   <com.huawei.rspwidget.androidsupx.viewpager.HwRspViewPager
          android:background="@id/view_pager"
          android:layout_width="match_parent"
          android:layout_height="wrap_content"
          app:rsp_need_adjust="true"
          />
  ```

* 如果自定义View继承了ViewPager，在代码里把继承关系中的ViewPager替换成HwRspViewPager：

  ```screen
  import com.huawei.rspwidget.androidsupx.viewpager.HwRspViewPager;

  public class LooperViewPager extends HwRspViewPager
  ```

* 如果应用还重写了onMeasure或者调用了onMeasure方法，需要将方法名改为onMeasure2，否则编译不通过：

  ```screen
  @Override
  protected void onMeasure2(int widthMeasureSpec, int heightMeasureSpec) {
      super.onMeasure(widthMeasureSpec, heightMeasureSpec);
  }
  ```

## 接入HwRspPagerAdapter（可选）

如果应用不存在一页显示完N个Item的场景（[图1](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/hwrspviewpager-0000001266122141#ZH-CN_TOPIC_0000001266122141__fig206862865512)中N=2），则不需要执行该步骤。

如果应用需要实现[图1](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/hwrspviewpager-0000001266122141#ZH-CN_TOPIC_0000001266122141__fig206862865512)中两张卡片时的效果，则还需要接入HwRspPagerAdapter。将PagerAdapter替换成HwRspPagerAdapter并在重写的instantiateItem方法中调用一次父类的该方法。

```screen
setAdapter(new HwRspPagerAdapter() {
            @Override
            public Object instantiateItem(@NonNull ViewGroup container, int position) {
                super.instantiateItem(container, position);
            }
        });
```

可配置参数的说明和使用方式见下表：

|参数名|参数类型|参数取值|参数说明|使用方式|
|:---------------------|:------|:---------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------|
|rsp_need_adjust|boolean|取值：true/false 默认：true|大屏下是否需要执行响应式逻辑|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_adjust_type|enum|取值：center 默认：center|使用哪种范式来调整ViewPager，默认使用居中的方式|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_indicator_view_id|integer|默认：null|导航点View ID|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_page_margin|integer|默认：null|Item间距，见图5中的PM。如果用户未指定，则使用小屏下设置的值，如果还未设置，则使用默认值12dp|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_width_adjust_mode|enum|取值： un_change/scale/aspect 默认：null|单个Item的宽调整策略: un_change:宽不变，IW_NEW=IW scale:按照配置rsp_scale_width缩放，IW_NEW=IW* rsp_scale_width aspect：按照配置rsp_aspect依据高等比缩放，IW_NEW=IH_NEW* rsp_aspect|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_scale_width|float|默认：null|宽缩放大小，如果未配置则默认为0.5|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_height_adjust_mode|enum|取值：un_change/scale/aspect 默认：null|参见rsp_width_adjust_mode|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_scale_height|float|默认：null|高缩放大小，如果未配置则默认为0.5|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_aspect|float|默认：null|单个Item的高宽比，如果未设置则使用ViewPager的高宽比：VPH/VPW|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_off_page_limit|integer|默认：null|Item的缓存数量，不设置则使用系统默认值|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
|rsp_one_page_item_cnt|integer|默认：null|一页完整显示多少个Item，参见图二的两张卡片。不设置则使用默认值2|方式一:在layout布局文件中配置 方式二:在代码中通过HwRspViewPager.getConfig().setXXX来配置|
