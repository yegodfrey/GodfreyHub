# 场景化示例

#### 导入GTM配置文件

为方便您在DTM上直接引用GTM的配置策略，您可以将GTM配置文件导出后，直接导入DTM，从而简化工作量。

GTM导出文件包括：预设变量、自定义变量、条件、代码和分组信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/Bvh8DGmeSHC5cr1-QnuzgA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=2CD48A30F2E49251A389C1C7E84DED2A8B69353A1B6792D675C7F71B2F3B536E)

若分组为空，则分组信息不会被导出。

      1. 登录[Google Tag Manager](https://tagmanager.google.com/)网站，导出JSON配置文件，具体步骤请参见[容器导出和导入](https://support.google.com/tagmanager/answer/6106997?hl=zh-Hans&ref_topic=9002095)。
      2. 在DTM的“配置”页面，点击“导入”按钮。
      3. 选择本地待导入的JSON文件并选中导入策略，点击“导入”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/RzFvUpqmRCqF3mfVCU_fEQ/zh-cn_image_0000001130549475.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=8433530BC9124C0B0B2F1C96EED7ED011F4A9C5F3AAA31CFDF528F7F35B14DAF)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/g_a-Hge7RduTq7loScCcBQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=5B3E0EB34AF7A7230223F601E5CF116997AA31A772C694DFCEC7BA439FB1B4AD)

GTM配置文件导入时，JSON文件名必须以“GTM-”开头。

      4. 查看导入结果。

         * 导入成功，无需操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/lLJJEldyQ3SzqH6-ziFrow/zh-cn_image_0000001084170462.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=04C4BDB7050A573C6DBE49DA7880414D19C05F93CF605AF40544FAF48FC777BE)

         * 系统弹出“忽略列表”，点击“确定”或关闭弹框后，则导入成功。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6/v3/pWVzTRapR4ao7-7T_aiMLQ/zh-cn_image_0000001130688273.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=F904E5B7809E00218E8932E13440C88E860FAF20301F1F89E4849D0D59FAD962)

对于GTM配置文件中，有如下情况的，DTM导入时提示忽略信息。 

资源类型 | 忽略原因  
---|---  
预设变量 | 在DTM中无对应预设变量类型。  
自定义变量 | 
           * 在DTM中无对应变量类型。
           * 在DTM中有对应变量类型，但引用了被忽略的变量。
           * 与DTM中参数不一致。  
条件 | 
           * 在DTM中无对应条件类型。
           * 在DTM中有对应条件类型，但引用了被忽略的变量。
           * 与DTM中参数不一致。  
代码 | 
           * 在DTM中无对应代码类型。
           * 在DTM中有对应代码类型，但引用了被忽略的变量或条件。
           * 与DTM中参数不一致。  
  
         * 系统提示导入失败，请根据提示信息修改后重新导入。

若GTM中的参数与DTM中的规则不匹配（如格式、校验规则或长度等），则导入失败。

#### 导入可视化埋点配置文件

      1. 在DTM的“配置”页面，点击“导入”按钮。
      2. 选择本地待导入的JSON文件并选中导入策略，点击“导入”。

对于配置文件中，有如下情况的，DTM导入时提示忽略信息。

           * 当用户选择合并，且可视化事件条件与非可视化事件条件的名字重复。
           * 当用户选择合并，且导入文件和数据库中的埋点位置存在重复。
           * 当用户选择合并，且导入文件和数据库中的埋点名称存在重复。

         * 系统提示导入失败，请根据提示信息修改后重新导入。
