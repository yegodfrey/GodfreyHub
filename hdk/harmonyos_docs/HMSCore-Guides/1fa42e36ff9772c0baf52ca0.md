# 覆盖物

地图覆盖物是固定在地图上的图片。  

#### 添加覆盖物

1. 通过经纬度、地图缩放级别、锚点及图片资源构建和添加[HGroundOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hgroundoverlay-0000001235248911)。

   ```
   - (void)viewDidLoad {
       [super viewDidLoad];
       /* GroundOverlay. */
       CLLocationCoordinate2D position = CLLocationCoordinate2DMake(48.893478, 2.334595);
       HGroundOverlay *groundOverlay = [HGroundOverlay groundOverlayWithCoordinate:position zoomLevel:8 anchor:CGPointMake(0.5, 0.5) icon:[UIImage imageNamed:@"HMapKit.bundle/location"]];
       groundOverlay.opacity = 1.f;
       [self.mapView addOverlay:groundOverlay];
   }
   ```

2. 实现添加[HOverlayView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hoverlayview-0000001237437097)的代理。

   ```
   - (HOverlayView *)mapView:(HMapView *)mapView viewForOverlay:(id<HOverlay>)overlay
   {
       if ([overlay isKindOfClass:[HGroundOverlay class]])
       {
           HGroundOverlayView *groundOverlayView = [[HGroundOverlayView alloc] initWithOverlay:overlay];
           return groundOverlayView;
       }
       return nil;
   }
   ```

3. 移除覆盖物。

   ```
   // 移除覆盖物
   [self.mapView removeOverlay:self.selectOverlay];
   ```

4. 设置覆盖物位置。  
   ![](https://media:301772613538817111)  
在显示时，图片的高度根据图片的宽高比例和width参数自动计算匹配。  

#### 覆盖物事件

覆盖物点击事件：触发地图的overlay（如折线、多边形、圆等）点击代理。

```
- (void)mapView:(HMapView *)mapView didTapOverlay:(id<HOverlay>)overlay;
```
