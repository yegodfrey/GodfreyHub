# 跳绳运动记录

#### 写入跳绳活动数据

将跳绳活动统计数据和明细数据写入ActivityRecord。

activityType值为37表示跳绳活动，活动特征数据类型为com.huawei.activity.feature.jumping_rope。

HTTP请求，请参见[创建运动记录](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecords_update-0000001050116813#section25059172122)接口

```
PUT
https://health-api.cloud.huawei.com/healthkit/v2/activityRecords/{activityRecordId}
```

```
PUT 
https://health-api.cloud.huawei.com/healthkit/v2/activityRecords/1624312527039

#### 读取跳绳运动记录数据

通过ActivityRecord读取跳绳运动记录，对应活动类型activityType为37。

HTTP请求，请参见[查询运动记录](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecords_list-0000001050114862#section984123664716)接口

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/activityRecords?startTime=***&endTime=***&activityType=***&detailDataType=***
```

请求示例

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/activityRecords?startTime=1624291200000&endTime=1624377600000&activityType=37&detailDataType=com.huawei.instantaneous.skip_speed&detailDataType=com.huawei.instantaneous.exercise_heart_rate
```

```

x-caller-trace-id: ***
