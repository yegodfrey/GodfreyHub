# 操作流程

#### 启用多工作区

      1. 选择“工作区”页签，点击“启用”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/QQTCtmNFRUyUX6_f6c9utQ/zh-cn_image_0000001196215275.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=36409DC6A8633D0E560E2D95F2B48F76E9D4DF34629D07FC79AF1EB9D8733DDB)

      2. 在弹出的提示框中点击“确定”。

#### 管理工作区

#### [h2]新建工作区

      1. 在“工作区”页签，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b3/v3/XFPKzoG0RFKr7PBCr96CNQ/zh-cn_image_0000001150268850.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=BF90DD311DECDD973CCF98365804FA38ECB287FD4727D5E3E398CA9368ABF379)，进入工作区管理页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/T-nwlYpHQWOdIAegbBwBOg/zh-cn_image_0000001196148731.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=48D1EC26ED1E78B98A5C6CAEC9ABEA6CD11CB5CFF29A27409D032549D941AFAB)

      2. 在“工作区管理”页面，点击“新建”按钮。
      3. 在弹出的“创建工作区”对话框中，设置“工作区名称”和“工作区描述”，点击“确定”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/iHWf8cSWT2WeH8T1LW4o7Q/zh-cn_image_0000001196320709.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=0F53F727C7B2E3210EACB54D32AAAAB4E87B686E35560ACFAD2F15991B76F487)

#### [h2]查看/修改工作区

      1. 在“工作区”页签，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/PsLiCfGBQ62NFVw90fUNdQ/zh-cn_image_0000001150268850.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=7FE0E51142979541CE43B4C8660767ED0A2489BA5111C8880BEB427A1D9C013C)，进入工作区管理页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/XM4SYklKTaibhsvOf7OFPA/zh-cn_image_0000001196148731.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=6A75E8BD7B86431A7EA6AA5B5379C9F9817A415E2EE54D5A57271CCE30826FC7)

      2. 在“工作区管理”页面，点击待查看/修改的工作区名称。
      3. 在弹出的“工作区详情”对话框中，您可以查看该工作区的信息，如“工作区名称”、“工作区描述”、“变更”及“操作记录”信息。

您可以根据需要对“工作区名称”和“工作区描述”进行修改，点击“确定”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/WpohUgJfRk-InL38S2lcSQ/zh-cn_image_0000001150543640.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=3AFAC0D93D14F803713484B5EDD72A17DCB2F071A2D8EA346AF6A2CDFB391689)

#### [h2]切换工作区

      1. 在“工作区”页签，点击工作区下拉框。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/zmPN1x_OSDiSyVGrDbzZ9Q/zh-cn_image_0000001150527896.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=2A7591E2B1612D1FDB162C9B888137AEE2AA4FFCA56AC7C3451B0A4CF90E5971)

      2. 选择待切换的工作区名称。

#### [h2]删除工作区

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/2oMAB_stTZWuuNqv4dzLWA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=8F3C26F93726C040F4D05E847E69002C8459ECA5B1706668A12153198AAE0026)

默认工作区不可删除。

      1. 在“工作区”页签，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a0/v3/cvBQKzYxQhyBBuMVJg82TQ/zh-cn_image_0000001150268850.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=E379A4A97AB1D4BF211F1F9CF6ACC60B0E8694CA3D670C9FC4967F7451C6B7F2)，进入工作区管理页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/zb6BXneVRRChNMpM9FJ4Gg/zh-cn_image_0000001196148731.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=A1FF5A4429266C86A324E9EC96156D96F38E2C972FBBCAFE4AB609E977A20C8A)

      2. 在“工作区管理”页面，点击待删除工作区后面的“删除”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/w-jPCVziSUKbDMZb-bQxNQ/zh-cn_image_0000001196361323.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=3756D84472D359C89AE9E47953E3CAD112A843FB2067A444335B1CE66FE006EC)

      3. 在弹出的提示框中点击“确定”。

#### （可选）同步工作区

当您在自定义工作区操作期间，若默认工作区有数据变更，则请在默认工作区中创建并发布版本。同时，自定义工作区中提示“此工作区已过期”，您需要将最新版本的内容同步至自定义工作区中。

      1. 点击提示框中的“同步”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/OIFIWS55RI-B3Z-X8pqdKg/zh-cn_image_0000001196372241.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=B1466165A60082507C497CF1007BCC693CA809BF34F21C27184846BAC3FC9501)

      2. 在弹出的“同步工作区”对话框中，点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/u4yllhWwQDKi5jOigwlkdQ/zh-cn_image_0000001151141496.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=8D5D16FBDDEA6886C5F5090FEA22ACA739E422252C6588D9DD3ED642093E2648)

      3. （可选）若自定义工作区与最新版本中的配置资源存在重名，则会提示工作区同步错误，请先解决相关错误，再重新同步。

         1. 在“工作区同步错误”提示框中，点击待修改的资源名称。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/OrqswTSmQhiljGVdc9qhwg/zh-cn_image_0000001197093487.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=668A75A17119162E787FCB083AE79F2E02A9E57B37F4C64D73A531FAAF2B94DD)

         2. 在跳转的编辑界面，修改名称后，点击“保存”。
         3. 重新点击同步，并在弹出的“同步工作区”对话框中，点击“确定”。

#### 提交工作区

当您在当前自定义工作区中完成代码配置后，需要提交至默认工作区版本，提交完成后，该自定义工作区将自动删除。

若同一配置资源在自定义工作区与最新版本中存在冲突，则需要您先手动处理，再进行提交。

      1. 在“工作区”页签，选择待提交的工作区，并点击“提交”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/9kW9vaOnQ36N1Fbm4AXCRQ/zh-cn_image_0000001150775626.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=CE1D3E62BD953936C149CC5F72E9BC90187D6A1EFA302EF47EEB9317FA7CA191)

      2. 在弹出的提示框中，填写“版本名称”及“版本描述”，点击“确定”按钮。

系统跳转至“版本详情”页面，并且该工作区自动删除。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/02sEbNXJQxOluBQShXSedg/zh-cn_image_0000001196855211.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=3F372015382A2F2124AE09E88E841F941B7206E81FD36ABC6C3D8DB571EE0E83)

      3. （可选）若系统提示“工作区有冲突”，需要您手动处理。

         1. 在“工作区”页签，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/0n_gSdctT-iv31sjI6f4oA/zh-cn_image_0000001197164633.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=3B23514EF70E3F9DE1679457A9CC44B7871C22FE836D8482685B5A2CABBC50DA)。
         2. 在“工作区管理”页面，选择存在冲突的工作区。
         3. 在弹出的“工作区详情”对话框中，点击存在冲突记录后的“查看变更”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/e-L4qeqnRZCFDq5Zjvn9WQ/zh-cn_image_0000001151083854.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=EF4ACFDF67F0390159083962AEA1F305AF884CAE882F1285D084AB8400EFC7CC)

         4. 在弹出的“冲突”对话框中，手动处理冲突，点击“保存”按钮。

处理冲突时，系统将自动标识该配置在最新版本与当前工作区中的差异，您可以选择保留最新版本或采用当前工作区配置。
            * ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/QuatjY1DSA2MkNmScbO0aA/zh-cn_image_0000001151458680.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=E64E344D8670B227661A04A8238D6712EBD87EDD565BDB443E2E03C49E683BF3)：采用当前工作区配置，舍弃最新版本配置。
            * ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/BS0mz-ifRGaO3ZlKnzBCbQ/zh-cn_image_0000001151459796.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=30C69CDB777560D65BD93E6CF7FB107709477A98A3DD0839B60472BCFC97CF03)：保留最新版本配置，舍弃当前工作区中的配置。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/t1tdBFzDTsGUfvfbEWOuAA/zh-cn_image_0000001197164061.png?HW-CC-KV=V1&HW-CC-Date=20261005T042955Z&HW-CC-Expire=86400&HW-CC-Sign=A9F0386D6E47ED2143A5A39FDBEE650FF741F93720B657E0A4E2360ECB35D84A)

         5. 重新点击“提交”按钮。
         6. 在弹出的提示框中，填写“版本名称”及“版本描述”，点击“确定”按钮。系统跳转至“版本详情”页面，该自定义工作区将自动删除。

      4. 您可以点击“发布”按钮，发布该版本。
