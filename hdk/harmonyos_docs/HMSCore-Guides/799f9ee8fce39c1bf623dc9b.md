# 在Eclipse项目中集成HMS Core SDK

针对Eclipse开发环境，华为提供了下载HMS Core SDK包本地集成的方式。在开始开发前，您需要将HMS Core SDK集成到您的Eclipse开发环境中。

#### 下载SDK

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/pqF33NohSUS8h_o3B1FotQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043009Z&HW-CC-Expire=86400&HW-CC-Sign=30E784DE60D1CEA4FFC54759F2E9855AD0697C39D775F90FB2C292857B72C311)

若使用Eclipse集成DTM SDK，不支持上报数据到Firebase和Adjust平台。

      1. 在集成DTM SDK前，请先确认已经完成Analytics SDK的集成。关于如何集成Analytics SDK请参见[在Eclipse项目中集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-appendix-c-0000001050167156)。
      2. 下载HMS Base SDK和要集成的服务SDK，并解压zip包。

下载地址请参见：[Eclipse SDK下载](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Library/sdk-download-0000001050151556)

      3. 选择菜单“File > Import”，将所有SDK工程导入到您的工作空间。

         1. 选择“Android > Existing Android Code Into Workspace”，点击“Next”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a0/v3/8wNPi2uIRE28Ba7DXR1-Pw/zh-cn_image_0000001071384318.gif?HW-CC-KV=V1&HW-CC-Date=20261005T043009Z&HW-CC-Expire=86400&HW-CC-Sign=5E9B56D931B1926EA0DF3DF91B3C9E8130EC3A7AD2379310EABC3BD2289D6B6F)

         2. 点击“Browse”，选择工程所在的文件夹目录。在“Projects”下显示待导入的工程，默认全部勾选，点击“Finish”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/N4srp12eQBKjx5yGZb9ybw/zh-cn_image_0000001071543910.png?HW-CC-KV=V1&HW-CC-Date=20261005T043009Z&HW-CC-Expire=86400&HW-CC-Sign=EE6F9DAE3A0365F1BFF6CEB83919B2FC0D14A5116646A4D9413A0B010A006DDC)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/04/v3/gF7kG_0pSRqrrltyBh89nA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043009Z&HW-CC-Expire=86400&HW-CC-Sign=E526910F71AE926A69124A084DA1B77E3D26CC51771E21D277F06DDA3D4F1087)

待导入的工程必须和工作空间在相同的磁盘空间里，例如都在“D:\”。如果不在，您可以选择“Copy projects into workspace”，将工程文件复制到工作空间。

#### 添加工程依赖关系

      1. 右键点击您的工程，选择“Properties”。
      2. 在左侧选择“Android”，点击“Add”，选择已导入空间的工程，点击“Apply and Close”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/-oMo0obBTDi_5XflrT24SA/zh-cn_image_0000001071225998.jpg?HW-CC-KV=V1&HW-CC-Date=20261005T043009Z&HW-CC-Expire=86400&HW-CC-Sign=3161F73F190DF314C267B54D86FBB7150F69B5BC7A20B565CD02B484755FB44C)

      3. 由于Eclipse的xml文件不支持$符号，将dtm-api工程下AndroidManifest.xml文件中的“${applicationId}”替换成您的应用包名。应用包名有特殊字符限制，请参见[FAQ](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050169001#section08772412011)。

#### 拷贝DTM SDK资源文件到您的工程目录

将dtm-core工程中assets目录下的资源文件拷贝到您的工程中assets目录下。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/T9qEztHiQNCDFDN4UpNIZA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043009Z&HW-CC-Expire=86400&HW-CC-Sign=FF744DA359A6A1A85E4DBDA248154B2B296986FABB12AC35317AB00287C8EB31)

如果依赖其他的Kit资源，还需要复制对应Kit的资源文件到您的工程目录下。

#### 配置混淆脚本

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/TmT_kGlDTFuG7DQHqrcl7w/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043009Z&HW-CC-Expire=86400&HW-CC-Sign=7115AE2D047E4AF7970A19BC48331BC070FD580CD98BE5F4E31FBC2F1F75C8FE)

若工程配置满足以下所有条件，则无需配置混淆脚本。

      1. 项目中集成的DTM SDK版本号 _{version}_ 不低于5.0.4.300。
      2. 工程目录下“build.gradle”文件中Android Studio的gradle插件版本不低于3.4.0，如：**classpath 'com.android.tools.build:gradle:3.4.0'** 。
      3. Gradle plugin 5.0以下版本，未主动禁用R8代码混淆或在工程目录下“gradle.properties”文件中配置：**android.enableR8=true** 。Gradle plugin 5.0及以上版本，可以忽略该配置。

编译APK前，您需要配置混淆配置文件，避免混淆Analytics Kit和DTM而导致功能异常。

在应用级根目录下打开混淆配置文件“proguard-project.txt”，加入排除Analytics Kit和DTM的混淆配置。
    
    -dontwarn com.huawei.hms.**
    -keep interface com.huawei.hms.analytics.type.HAEventType{*;}
    -keep interface com.huawei.hms.analytics.type.HAParamType{*;}
    -keep class com.huawei.hms.analytics.HiAnalyticsTools{
       public static void enableLog();
       public static void enableLog(int);
    }
    -keep class com.huawei.hms.analytics.HiAnalyticsInstance{*;}
    -keep class com.huawei.hms.analytics.HiAnalytics{*;}
    -keep class com.huawei.hms.feature.** {
       public *;
    }
    -keep public class com.huawei.hms.common.** {
       public *;
    }
    -keep class com.huawei.hms.analytics.internal.filter.EventFilter{
       public void logFilteredEvent(java.lang.String, android.os.Bundle);
       public java.lang.String getUserProfile(java.lang.String);
    }
    -keep public class com.huawei.hms.dtm.EventFilter {
       public <fields>;
       public <methods>;
    }
