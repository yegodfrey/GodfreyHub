# 操作流程

#### 新建条件

  1. 在“条件”页面，点击“新建”按钮。
  2. 在“新建条件”页面中输入条件名称，选择条件类型并输入对应的参数。
  3. 如果您选定条件类型后并设置触发条件为“部分xx”，此时您需要依次选择触发条件的变量和操作符，并填写触发条件需要的属性值。如果您需要填写多个触发条件，点击“添加”按钮可增加条件输入框。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/r1DPRfSYSAuFATdNwtTTZQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=64354FDEDF0A73B475D8B88E2CE4802DA3952CF4AED2AFAB12D5D467239B506F)

在设置触发条件时，可通过下拉框选择已创建的变量。

若您所需的变量还未创建，可通过点击“配置”，配置预设变量；或通过点击“新建”，新建自定义变量。

“此条件的触发条件”的“部分xx”最多可添加100条，若达到100条，则无“添加”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/03/v3/wsitRf9sTLex14EkioSUUg/zh-cn_image_0000001078122650.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=F130DAA7557221DCAF407E9F3997389E8BF32ED6DB57EA9DE70D8EEB01F07F09)

  4. 填写完成后，点击“保存”。
  5. 创建成功后，您可以在“条件”页面中查看到已创建的条件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/70/v3/nyLbt0SbTGSA1i2-8nb-hw/zh-cn_image_0000001116504783.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=E726E05331A7B51EC5DAC2570686D9CA384AEBE02AB03F10B03B2CAB81DE4831)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/KwUjhe6ERaq3zws-Hf0_yA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=5B2835C2CD864E1BA8F59CFD74256411CE367120735CCFC787AFF188733FEE5F)

当一个条件中配置了多条触发条件，必须同时满足所有触发条件才可触发。




#### 修改条件

  1. 在“条件”页面，点击已创建条件的名称。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d7/v3/YGyzQ2baS82d8wz2FQXn8Q/zh-cn_image_0000001078282914.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=EA3DEDC16B2AE91DDEC62F2F912EC7586E827639897BAEBF95597C08BDB9C4B2)

  2. 在“修改条件”页面可以对条件名称、条件类型及触发条件进行修改。修改完成后，点击“保存”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/35/v3/AZUINiC0TkSQRLROhdq9gw/zh-cn_image_0000001116441287.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=AD4828178869C4900A09C59E27ACEA70FA135CDFC6A30981C6C984B5FAE79531)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/iGACy-v-S8K5zPhZKWqjTw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=7F89EB0E222FD5411B4C7CB172640FF881D45452BD8EAE598F62F77BBFBCDF41)

在“修改条件”页面，可查看引用该条件的代码。

若该条件被引用，则在修改完成后，重新[发布版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-version-management-operation-procedure-0000001077092116#section251519217532)，才能生效。




#### 复制条件

  1. 在“条件”页面，点击已创建条件右侧的“复制”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/rcyYyU1GTGmG4oixBMdK8Q/zh-cn_image_0000001116505707.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=1A91A87DFFF75751B7B6F15718EEA07D9DF24FA28C326EDBB9E97DD119433F4F)

  2. 在“复制条件”页面可以对条件名称、条件类型及触发条件进行编辑。编辑完成后，点击“保存”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/7CWt5JyOQ8mkn1sdS42R9g/zh-cn_image_0000001077995006.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=D821ED661140072D4B31F42906B509D4B542C3B58DBA30C4B94914695C4DEA60)

  3. 复制完成后，您可以在“条件”页面，查看复制的条件信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/iylBPJHWRCui1JX_C4zMGw/zh-cn_image_0000001171152099.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=A0271C1F0E337E99D6E19F3480AF0DA5A8853F19F552CF2050D88A237AA1718E)




#### 删除条件

**方法一：单个删除。** 在“条件”页面，点击已创建条件右侧的“删除”，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/L_qG0XAQQDeFrulA8eXQAQ/zh-cn_image_0000001078124032.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=36A18EFC5300A84B362153681560782FAE18567315CE613846AA6EF414F497C6)

**方法二：批量删除。** 若您需要删除多个条件，也可以通过批量删除功能实现。勾选待删除条件前的方框，点击页面右上方的“删除”按钮，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/aQCSGkz1RmW3BuPSYEK9yw/zh-cn_image_0000001130124803.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=ADDAE01E551350F6B01FB4AAFC171E48E868DC3F5B7F818BD9C815AB372538A3)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/6eOutFJzQPi0icvdN7lLvA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052030Z&HW-CC-Expire=86400&HW-CC-Sign=0DC43C2B0743C037284942B58E856D97438C334A44D6B3280CEB07173A550D6C)

如果条件已经被其他代码引用，则无法删除，需要移除引用关系后再执行删除。
