# API列表

服务商与特约商户间的分账：

特约商户分账，主要用于特约商户完成订单收款后的资金分配。根据服务商请求的分账规则，将特约商户的订单款分给分账接收方。

分账接收方可以是特约商户绑定的服务商，也可以是特约商户自行添加的其他合作商户。

资金分账API列表：  

|功能列表|描述|
|:------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------|
|[申请分账](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-apply-0000001590235750#section95771727125814)|交易订单成功后，服务商调用此接口发起分账请求，将订单收款的资金分账给指定的分账接收方。|
|[查询分账结果](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-query-bill-to-sys-0000001590967920#section1089114712582)|服务商发起分账请求后，调用此接口查询订单分账状态。|
|[申请分账回收](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-reclaim-apply-0000001590875182#section95771727125814)|已经分账的订单，可以调用此接口将已分账的资金从分账接收方账户退回给分账方。|
|[查询分账回收结果](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-reclaim-query-bill-to-sys-0000001640888473#section1089114712582)|商户想核实分账回退结果，可调用此接口查询分账回收的结果。|
|[解冻剩余分账金额](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-finish-to-sys-0000001591340368#section1089114712582)|不需要再分账的订单，可调用此接口将订单剩余可分账金额全部解冻给收单商户。|
|[查询剩余可分账金额](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-query-amounts-to-sys-0000001640700369#section1089114712582)|调用此接口可查询订单剩余的可分账金额。|
|[分账结果回调通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-notify-result-0000001590875186#section10267412717)|华为支付服务器调用申请分账请求传入的callbackUrl回调接口，将分账成功消息通知给商户。|
|[分账回收结果回调通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-reclaim-notify-result-0000001591197582#section10267412717)|华为支付服务器调用申请分账回收请求传入的callbackUrl回调接口，将分账回收成功消息通知给商户。|
