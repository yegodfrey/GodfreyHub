# 响应式GridView

应用直接使用原生GridView，接入HwRspGridView可通过在Xml接入方式和代码接入两种方式。  

#### Maven方式引入aar包

使用前需在build.gradle的dependencies中添加所引用控件的依赖。

```
implementation "com.huawei.ui.rspuikit:hwrspgridview:{version}"
```

{version}需替换为实际的版本号，具体版本号请参见版本更新说明章节。例如:implementation '"com.huawei.ui.rspuikit:hwrspgridview:1.0.0.8'。  

#### 布局XML接入方式

xml配置示例

```
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
            xmlns:tools="http://schemas.android.com/tools"
            xmlns:app="http://schemas.android.com/apk/res-auto"
            android:layout_width="match_parent"
            android:layout_height="match_parent"
            tools:context=".MainActivity"
            android:orientation="vertical">
     
<com.huawei.rspuikit.hwrspgridview.widget.HwRspGridView
        android:id="@+id/gv"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:layout_gravity="center"
        android:paddingStart="3dp"
        android:paddingEnd="3dp"
        android:gravity="center"
        app:setRspEnable="true"
        android:stretchMode="columnWidth"
        android:stretchMode_rsp="columnWidth"
        android:numColumns="2"
        app:numColumnsRsp="4"
        android:columnWidth="80dp"
        app:columnWidthRsp="80dp"
        android:horizontalSpacing="5dp"
        app:horizontalSpacingRsp="5dp"
        android:verticalSpacing="1dp" />
</LinearLayout>
```

#### 代码接入方式

动态创建：本方法可以在逻辑代码中直接生成相关的控件。

1. 导入控件包。

   ```
   import com.huawei.rspuikit.hwrspgridview.widget.HwRspGridView
   ```

2. 代码由继承GridView改为继承HwRspGridView或者通过new HwRspGridView直接使用,代码使用示例如下。

   ```
   @Override
   protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        LinearLayout linearLayout = new LinearLayout(this);
        LinearLayout.LayoutParams params = new LinearLayout.LayoutParams(
                LinearLayout.LayoutParams.MATCH_PARENT,
                LinearLayout.LayoutParams.WRAP_CONTENT);
        linearLayout.setLayoutParams(params);
        HwRspGridView hwRspGridView = HwRspGridView(this);
        if (hwRspGridView != null) {
            ViewGroup.LayoutParams params = new ViewGroup.LayoutParams(
                    ViewGroup.LayoutParams.MATCH_PARENT,
                    ViewGroup.LayoutParams.MATCH_PARENT);
            hwRspGridView.setLayoutParams(params);
            // 设置响应式控件生效开关，true 表示生效，false 表示不生效
            hwRspGridView.setRspEnable(true);
            // 设置折叠态和展开态的拉伸模式，支持NO_STRETCH、STRETCH_SPACING、//STRTCH_COLUMN_WIDTH、STRETCH_SPACING_UNIFORM 四种
            hwRspGridView.setStretchMode(HwGridView.STRTCH_COLUMN_WIDTH);
            hwRspGridView.setStretchModeRsp(HwGridView.STRTCH_COLUMN_WIDTH);
            // 设置折叠态和展开态的列数
            hwRspGridView.setNumColumns(2);
            hwRspGridView.setNumColumnsRsp(4);
            // 设置折叠态和展开态的列宽
            hwRspGridView.setColumnWidth(getPixelsFromDp(80));
            hwRspGridView.setColumnWidthRsp(getPixelsFromDp(80));
            // 设置折叠态和展开态的列间距
            hwRspGridView.setHorizontalSpacing(getPixelsFromDp(5));
            hwRspGridView.setHorizontalSpacingRsp(getPixelsFromDp(5));
            linearLayout.addView(hwRspGridView);
        }
        setContent(linearLayout);
    }
   ```

#### 接口能力

响应式控件扩展并兼容原生GridView控件接口，扩展控件接口及说明如下表。  

|接口函数|对应属性|输入|输出|返回值|
|:----------------------|:--------------------|:-------------------------------------------------------------------------------|:----------|:---|
|setRspEnable|switch_rsp|Boolean isRspenable|设置响应式控件是否生效|void|
|setStretchModeRsp|stretchMode_rsp|ENUM{ NO_STRETCH, STRETCH_SPACING, STRTCH_COLUMN_WIDTH, STRETCH_SPACING_UNIFOR }|设置展开态拉伸模式|void|
|setNumColumnsRsp|numColumns_rsp|int numColumnsRsp|设置展开态列数|void|
|setColumnWidthRsp|columnWidth_rsp|int columnWidthRsp|设置展开态列宽|void|
|setHorizontalSpacingRsp|HorizontalSpacing_rsp|int horizontalSpacingRsp|设置展开态列间距|void|

控制展开态是否生效的接口是setRspEnable，只有设置为true时展开态才会响应式调整，若设置为false生效效果与谷歌原生控件一致。

应用可根据自己需要只在展开态显示有问题界面使能。
