# 业务介绍

位置服务（Site Kit）提供POI搜索、地理编码、时区查询等多类搜索服务，依托于海量POI数据，帮助您的应用吸引更多用户。

* [Android SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-introduction-0000001050158571)：位置服务Android SDK是一套提供位置服务能力的开发调用接口，您可以轻松地在Android应用中加入位置查询相关的功能，包括：关键字搜索、周边搜索、地点详情、地点搜索建议等功能，帮助您快速构建基于位置服务的产品。
* [REST API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-introduction-0000001050162828)：位置服务REST API提供HTTPS接口，您可以通过HTTPS形式发起请求，调用相关功能，包括：关键字搜索、周边搜索、地点详情、地点搜索建议、自动补全、地理编码、获取时区等功能。
* [Client Libraries](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/client-library-0000001104033088)：Client Libraries是一套全面的位置服务接口，可以帮助您使用多种编程语言快速集成位置服务能力。
