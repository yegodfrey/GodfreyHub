# 基于地理位置请求广告

鲸鸿动能SDK会根据您的应用是否拥有位置权限，在请求广告时决定是否携带位置信息。

如果用户已为您的应用授予位置权限，鲸鸿动能SDK会使用此数据来改善广告定位准确度，精准的位置信息可提升变现收益。

如何在您的应用中向用户动态申请地理位置权限，请参见[融合定位开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/location-develop-steps-0000001050746143)。
