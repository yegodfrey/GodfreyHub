# 华为IAP范围覆盖

华为应用内支付（In-App Purchases，IAP）已支持全球多个国家/地区的多种支付方式，为当地的消费者和商户提供安全、便捷、高效的支付服务。

目前IAP在全球共支持**182**个国家/地区，其中：

* 银行卡支付（Credit card/Debit card） 全球支持**182**个国家/地区。

* 运营商话费支付DCB（Direct Carrier Billing） 全球支持**47** 个国家/地区，**119**个运营商。

* 花币（HUAWEI Points） 全球支持**135**个国家/地区，币种与银行卡交易币种保持一致。

  注：科威特因付费业务税务风险暂时关闭。
* 第三方支付（Third-party Payment） 全球支持**59**个国家/地区。

> 说明
>
> 由于某些币种在支付平台不支持携带小数，您在设置订单参数amount字段时，应设置为整数金额值，如5.00，不支持5.02。
>
> 涉及币种：
>
> BEF、XOF、XAF、XPF、KMF、GRD、GNF、HUF、IDR、JPY、LUF、MGA、MGF、PYG、PTE、RWF、KRW、ESP、TRL、VND、IQD、COP、CLP、ISK、KES（M-Pesa不支持小数，银行卡、花币、优惠券支持小数，建议amount优先设为整数）
