# 批量操作

## 场景介绍

华为云空间服务支持应用对某些接口进行批量操作，具体接口如下：文件（夹）的批量操作，如创建文件夹、创建文件元数据、复制、更新、删除、订阅等，评论及回复的批量操作，如评论及回复的新增、更新、删除等。

## 批量调用其他接口

**功能简介**

BatchCallback接口实现对其他接口的批量调用。

**限制**

请求字段必须严格按照multipart请求格式。

**发送一个批量调用其他接口的请求**

1. 创建一个对BatchCallback接口的[POST](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-batchcallback-0000001050727110)请求。
2. 填入HTTP headers**。**

   Content-Type：发送报文格式

3. 发送请求**。**
