# 评论回复

## 场景介绍

华为云空间服务支持用户对云端文件的评论进行回复，并对回复进行查看、更新和删除操作。

## 开发前提

1、请确认您已完成[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050185569)。

2、在进行开发之前，您可以下载[华为云空间客户端示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/client-sample-code-0000001050114484)进行快速体验。

## 构造Drive对象

调用[Drive.Builder.build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-builder-0000001050124056#section17968156193912)接口构造Drive对象。

```screen
private Drive buildDrive() {  
    Drive service = new Drive.Builder(CredentialManager.getInstance().getCredential(), context).build();  
    return service;  
}
```

## 创建评论回复

调用[Replies.Create](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-replies-create-0000001050124060)接口创建评论回复：

```screen
/**
 * 创建文件评论回复
 *
 * @param fileId 文件id
 * @param commentId 文件评论id
 */
private Reply createReplies(String fileId, String commentId) {
    Reply replyResponse = null;
    Drive drive = buildDrive();
    try {
        Reply reply = new Reply();
        reply.setDescription("interface test reply");
        reply.setOperate("resolve");
        replyResponse = drive.replies().create(fileId, commentId, reply).setFields("*").execute();
    } catch (Exception ex) {
        Log.e(TAG, "createReplies error: " + ex.toString());
    }
    return replyResponse;
}
```

## 获取评论回复列表

调用[Replies.List](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-replies-list-0000001050126013)接口获取评论回复列表：

```screen
/**
 * 获取评论回复列表
 *
 * @param fileId 文件id
 * @param commentId 评论id
 */
private List<Reply> listReplies(String fileId, String commentId) {
    Drive drive = buildDrive();
    List<Reply> replyResponse = new ArrayList<>();
    String nextCursor = null;
    try {
        Drive.Replies.List listReq = drive.replies().list(fileId, commentId);
        do {
            if (nextCursor != null) {
                listReq.setCursor(nextCursor);
            }
            ReplyList replyList = listReq.setFields("*").execute();
            List<Reply> replies = replyList.getReplies();
            if (replies == null) {
                break;
            }
            replyResponse.addAll(replies);
            nextCursor = replyList.getNextCursor();
        } while (StringUtils.isNullOrEmpty(nextCursor));
    } catch (Exception ex) {
        Log.e(TAG, "listReplies error: " + ex.toString());
    }
    return replyResponse;
}
```

## 获取评论回复详情

调用[Replies.Get](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-replies-get-0000001050124062)接口获取评论回复详情：

```screen
/**
 * 获取评论回复详情
 *
 * @param fileId 文件id
 * @param commentId 评论id
 * @param replyId 回复id
 */
private Reply getReplies(String fileId, String commentId, String replyId) {
    Reply reply = null;
    Drive drive = buildDrive();
    try {
        reply = drive.replies().get(fileId, commentId, replyId).setFields("*").execute();
    } catch (Exception ex) {
        Log.e(TAG, "getReplies error: " + ex.toString());
    }
    return reply;
}
```

## 更新评论回复

调用[Replies.Update](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-replies-update-0000001050124064)接口更新评论回复：

```screen
/**    
 * 更新评论回复 
 *     
 * @paramfileId 文件id    
 * @param commentId 评论id
 * @paramreplyId 回复id 
 */  
private void updateReplies(String fileId, String commentId, String replyId) {
    Drive drive = buildDrive();
    try {
        Reply reply = new Reply();
        reply.setDescription("interface test reply");
        reply.setOperate("reopen");
        drive.replies().update(fileId, commentId, replyId, reply).execute();
    } catch (Exception ex) {
        Log.e(TAG, "updateReplies error: " + ex.toString());
    }
}
```

## 删除评论回复

调用[Replies.Delete](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-replies-delete-0000001050126011)接口删除评论回复：

```screen
/**    
 * 删除评论回复
 *     
 * @paramfileId 文件id    
 * @param commentId 评论id
 * @paramreplyId 回复id 
 */  
private void deleteReplies(String fileId, String commentId, String replyId) {
    Drive drive = buildDrive();
    try {
        drive.replies().delete(fileId, commentId, replyId).execute();
    } catch (Exception ex) {
        Log.e(TAG, "deleteReplies error: " + ex.toString());
    }
}
```

> 注意
>
> 回复评论接口是联网耗时接口，需要放在子线程中调用。
