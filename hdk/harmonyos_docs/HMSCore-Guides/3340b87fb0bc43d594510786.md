# 客户端配置  
  
#### 代码配置

    1. 建议在第一个Activity的onCreate中初始化Analytics Kit，获得HiAnalyticsInstance实例。若配置文件不正确，则会返回null，无法进行打点。
           
           “Java”
           @Override
           protected void onCreate(Bundle savedInstanceState) {
               super.onCreate(savedInstanceState);
               setContentView(R.layout.activity_main);
               // 获得HiAnalyticsInstance实例
               HiAnalyticsInstance instance = HiAnalytics.getInstance(this);
           }
           
           “Kotlin”
           override fun onCreate(savedInstanceState: Bundle?) {
               super.onCreate(savedInstanceState)
               setContentView(R.layout.activity_main)
               // 获得HiAnalyticsInstance实例
               val instance = HiAnalytics.getInstance(this)
           }

    2. （可选）在代码合适位置插入事件上报代码。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ea/v3/X8pb0ddBRuWGi4fUWwWkLQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042943Z&HW-CC-Expire=86400&HW-CC-Sign=C47AA886FE65EF8C0C106F367958DC45DD83272843D57BB56AEB2C8F282B8A90)

如果使用可视化埋点添加埋点事件，可跳过此开发步骤。
           
           “Java”
           // 自定义事件打点上报
           // 自定义事件名称为"Purchase"
           String eventName = "Purchase";
           // 自定义事件相关的字段
           Bundle bundle = new Bundle();
           // 设置Double类型的数据
           bundle.putDouble("price", 9.99);
           // 设置Long类型的数据
           bundle.putLong("quantity", 100L);
           // 设置String类型的数据
           bundle.putString("currency", "CNY");
           
           // 进行事件上报
           if (instance != null) {
           instance.onEvent(eventName, bundle);
           }
           
           “Kotlin”
           // 自定义事件打点上报
           // 自定义事件名称为"Purchase"
           val eventName = "Purchase"
           // 自定义事件相关的字段
           val bundle = Bundle()
           bundle.apply {
             // 设置Double类型的数据
             putDouble("price", 9.99)
             // 设置Long类型的数据
             putLong("quantity", 100L)
             // 设置String类型的数据
             putString("currency", "CNY")
           }
           
           // 进行事件上报
           instance?.let {
             it.onEvent(eventName, bundle)
           }

#### 接入调试

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/JJ9gmCvsQMaLeI819_rSQQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042943Z&HW-CC-Expire=86400&HW-CC-Sign=70CF40E668F3275FF92700D84363E6DA0556DB481537E88EE0BE26FB1CD66D8E)

    * HUAWEI Analytics模板

开始调试命令：**adb shell setprop debug.huawei.hms.analytics.app** _< package_name>_

停用调试命令：**adb shell setprop debug.huawei.hms.analytics.app .none.**

    * Firebase模板

开始调试命令：**adb shell setprop debug.firebase.analytics.app** _< package_name>_

停用调试命令：**adb shell setprop debug.firebase.analytics.app .none.**

    * 其他模板（例如Adjust、AppsFlyer等）

开始调试命令：**adb shell setprop debug.huawei.hms.dtm.app** _< package_name>_

停用调试命令：**adb shell setprop debug.huawei.hms.dtm.app .none.**

在AGC上的具体调试操作，请参见[应用调试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-debugging-0000001051799712)。

在开发过程中可以启动调试模式，实时查看事件的记录情况，观察具体结果并根据需要进行调整。

#### 开启/停用调试模式

如下以HUAWEI Analytics平台为例进行说明。

    1. 在PC端CLI中或者Android Studio的Terminal中，使用adb命令执行工具执行如下命令行，开始调试模式：
           
           adb shell setprop debug.huawei.hms.analytics.app _< package_name>_

调试模式打开后会保持启用状态，所有事件将实时上报。

数据成功上报后，分析服务平台的应用调试上会展示出实时数据，如下图：
