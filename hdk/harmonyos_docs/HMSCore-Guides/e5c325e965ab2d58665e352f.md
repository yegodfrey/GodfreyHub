# 开通服务

      1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。
      2. 选择需要查看动态标签管理数据的应用。
      3. 选择“增长 > 动态标签管理”进入开通服务页面。

         * 开通服务需要您首先点击“开启分析服务”按钮，开通分析服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/4kRmO4OtQgKApozGubpSwQ/zh-cn_image_0000001080334715.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=9B534778B0897DB72362E6375335ABC1B0352AAB0ADF4C328A37374347CC8028)

         * 如果您已经开通分析服务，那么您可以直接点击“开通服务”按钮来开通DTM服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/d3rINp_DSuSJ62_Ufj5_IQ/zh-cn_image_0000001076524394.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=FDED13FD453CDDD5F147FBE459C955A82D72A27D66EAD887B22E6182A57B1AD9)

      4. 您可以在“开通服务”窗口设置配置名称，修改操作记录的储存时间。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/N-eZMyzHSwG1XXlpCvrbFQ/zh-cn_image_0000001088335243.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=B94337365AABDD4907B2E275C5A62E4E0F8731C25CEE05338D4C1B7020C33C72)

      5. 当您设置完成配置信息后，点击“确定”按钮，会进入“配置”页面，您可以看到相关配置信息，并可以进行删除、导入、导出、编辑操作和关闭服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/Y_XcRpoiT7m1RllwNXQHPg/zh-cn_image_0000001075757054.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=40333DE3F2BD2D1AABF0F22CB19D0FA769C0A834ECDC6960C1A639623F6AB29A)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/P10rnNAiT5m9UR7nGpRVag/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043041Z&HW-CC-Expire=86400&HW-CC-Sign=C209957D2682A7167942BBCCA41EABCFDC3359A1E60A26F7629EA13ADE7B9A2B)

         * [团队帐号持有者](https://developer.huawei.com/consumer/cn/doc/start/team-account-guides-0000001053785552)和管理员拥有开通服务的权限。
         * 应用包名与创建应用时填写的包名一致，DTM会根据您的应用自动关联，创建配置时不允许修改。
         * 一个应用只允许创建一个配置，如果您已经完成配置创建，则无需再次创建。
