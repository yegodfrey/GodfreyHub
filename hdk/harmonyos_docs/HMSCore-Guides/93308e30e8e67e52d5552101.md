# 租房买房

分析服务支持租房买房行业分析，可以清晰洞察应用的关键指标数值，从数据概览、用户分析和房屋数据等多维度了解租房买房的具体情况，帮助制定精准的营销方案和产品策略。

## 典型应用场景

查看租房买房用户的分布情况、以及房屋数据详情。

## 前提条件

已在"智能数据接入 > 埋点开发"中配置了租房买房模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。

## 功能详述

### 案例

某房产中介App想要查看近期用户整体租房买房情况，以了解新房、二手房以及租房受欢迎程度，制定相应的促销计划。

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 行业分析"，进入"租房买房"分析界面。
4. 查看租房买房类App数据概览。详情请参见[数据概览](#section1739262775710)。
5. 查看租房买房类App指标情况。详情请参见[用户分析](#section1842322213818)和[房屋数据](#section19141650597)。
