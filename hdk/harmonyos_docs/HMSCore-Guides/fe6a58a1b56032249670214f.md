# 集成SDK

#### 在Xcode项目中集成SDK（Cocoapods方式集成）

                1. 在Xcode开发环境中添加当前应用的AppGallery Connect配置文件。
                   1. 登录[ _AppGallery Connect 网站_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“我的项目”。
                   2. 在项目列表中找到您的项目，在项目列表中点击需要集成SDK的应用。
                   3. 在“项目设置”页面中，点击“应用”栏下的“agconnect-services.plist”下载配置文件。
                   4. 将“agconnect-services.plist”文件拷贝到应用级根目录下。

                      1. 在获取“agconnect-services.plist”文件前，请确保已经完成分析服务的开通（开通步骤参见[开通华为分析服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/macos-config-agc-0000001240728813#section16141910204411)）。
                      2. 如果您在“开发”模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的“agconnect-services.plist”，并替换iOS项目根目录下已有的文件。

                2. 编辑Podfile文件。

增加pod依赖'HiAnalytics'，Podfile示例如下：
                       
                       # Uncomment the next line to define a global platform for your project
                       # platform :macos, '10.12'
                       
                       target 'HiAnalyticsPodDemo' do
                         # Comment the next line if you don't want to use dynamic frameworks
                         use_frameworks!
                       
                         # Pods for HiAnalyticsPodDemo
                          **pod 'HiAnalytics'**
                       
                         target 'HiAnalyticsPodDemoUITests' do
                           # Pods for testing
                         end
                       
                       end

                3. 执行**pod install** ，完成pod的安装。
                       
                       $ pod install

#### 在Xcode项目中集成SDK（手动方式集成）

#### [h2]下载SDK

                1. 请下载**HiAnalytics** SDK及其依赖的SDK包，并解压压缩包。下载地址请参见：[SDK下载（手动方式集成）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/ios-sdk-download-0000001050414801)。
                2. 选择菜单“Add Files to 工程名”，将所有framework库导入到您的工作空间。
                   1. 右键工程，选择“Add Files to 工程名”，随后左键去选择要导入的“framework”文件。

#### [h2]添加资源文件依赖和项目参数

                1. 添加资源文件依赖。

在“Build Phases”页签，点击“+”号将AGCResources.bundle资源文件添加到“Copy Bundle Resources”中。

**资源文件** | **资源文件** 所在库  
---|---  
AGCResources.bundle | Agconnect-credential  
  
                2. 添加系统依赖库。

在“TARGETS > Build Phases > Link Binary With Libraries (4 items)”中，添加如下系统依赖库：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115324.81835556918610728506870579010671:50001231000000:2800:847AEEE4F24236B93B55D58731E7B6373B5BB8ED4D18ADA6955303525F35B1F9.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

                3. 修改工程配置。
                   1. 在项目的构建设置中，在“Build Settings”页签，向“Other Linker Flags”中添加“-ObjC”链接器标志。
