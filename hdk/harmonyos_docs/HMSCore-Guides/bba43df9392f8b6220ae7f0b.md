# ODID

#### 简介

ODID（Open Device Identifier）：开放设备标识符， 是HUAWEI Push Kit提供的一种开发者级别的非永久性设备标志符，开发者是指在华为开发者联盟上注册的一个企业或者个人。

ODID举例：dff3cdfd-7beb-1e7d-fdf7-1dbfddd7d30c

ODID值会在以下场景重新生成：

* 手机恢复出厂设置。
* 同一设备上同一个开发者的应用全部卸载后重新安装时。
* 卸载并重装HMS Core（APK）。

ODID生成规则：

* 同一设备上运行的同一个开发者的应用，ODID相同。
* 同一个设备上不同开发者的应用，ODID不同。
* 不同设备上同一个开发者的应用，ODID不同。
* 不同设备上不同开发者的应用，ODID不同。  

#### 使用场景

* 设备标识 同一设备上同一开发者的多个应用ODID取值相同，可用作设备唯一标识符。

<!-- -->

* 数据上报 同一开发者的多个应用进行数据打点上报时，可携带ODID表示应用之间的联系。

#### 开发准备

如果您的应用要上架华为应用市场，请参见[华为推送服务开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-config-agc-0000001050170137)来做必要的准备工作。如果您只想获取ODID而不上架应用市场，只需集成OpenDevice SDK即可。

* 7.0以下版本
  1. 打开Android Studio项目级"build.gradle"文件。

     ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220922153204.18823473317351793754158895489285:50530921080316:2800:159995AA61FBD8C9EA830801F37E0CE46351E6C5465CF6F2A2200C7DD7F1BDDD.png?needInitFileName=true?needInitFileName=true)
  2. 添加HUAWEI AGC插件以及Maven代码库。
     * 在"buildscript \> repositories"中配置HMS Core SDK的Maven仓地址。
     * 在"allprojects \> repositories"中配置HMS Core SDK的Maven仓地址。
     * 如果App中添加了"agconnect-services.json"文件则需要在"buildscript \> dependencies"中增加AGC插件配置。

     ```
     buildscript {
         repositories {
             google()
             jcenter()
             // 配置HMS Core SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
         dependencies {
             ...
             // 增加AGC插件配置，请您参见AGC插件依赖关系选择合适的AGC插件版本。
             classpath 'com.huawei.agconnect:agcp:1.6.0.300'
         }
     }

     allprojects {
         repositories {
             google()
             jcenter()
             // 配置HMS Core SDK的Maven仓地址。
             maven {url 'https://developer.huawei.com/repo/'}
         }
     } 
     ```

#### 获取ODID

调用OpenDeviceClient.[getOdid](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/opendeviceclient-0000001050831617#section1788692510237)()方法获取ODID值。  

```
"Java"
// 使用getOdid方法获取Odid
Task<OdidResult> idResult = OpenDevice.getOpenDeviceClient(getApplicationContext()).getOdid();

// 添加监听方法
idResult.addOnSuccessListener(new OnSuccessListener<OdidResult>() {
     @Override
     public void onSuccess(OdidResult odidResult) {
            String odid = odidResult.getId();
            Log.d("TAG", "getODID successfully, the ODID is " + odid );
     }
}).addOnFailureListener(new OnFailureListener() {
     @Override
     public void onFailure(Exception myException) {
        Log.d("TAG", "getODID failed, catch exception : " + myException);
     }
});
```

```
"Kotlin"
// 使用getOdid方法获取Odid
val idResult = OpenDevice.getOpenDeviceClient(this).odid

// 添加监听方法
idResult.addOnSuccessListener{ odidResult ->     
    Log.d("TAG", "getODID successfully, the ODID is " + odidResult.getId() )
}.addOnFailureListener{ myException ->
    Log.d("TAG", "getODID failed, catch exception : $myException")
}
```
