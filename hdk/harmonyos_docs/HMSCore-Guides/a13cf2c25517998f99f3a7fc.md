# 精简模式

#### 概览

在精简模式下，地图SDK允许您的应用以指定的缩放级别向用户显示指定位置的静态地图图像。精简模式仅支持静态图像相关的功能。当用户想要在一个屏幕上展示多个地图或者在微信朋友圈等社交应用中分享位置时，精简模式十分有用。

地图SDK在精简模式下支持的功能如下表所示。  

|功能|支持情况|
|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------|
|我的位置|完全支持。|
|交互手势|不支持。|
|地图相机|部分支持（不支持设置tilt和bearing，不支持动画方式移动地图相机）。|
|地图事件|仅支持点击和长按事件。|
|地图类型|仅支持标准地图类型和空地图类型。|
|标记（[Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699)）|除拖拽和旋转外均支持。|
|标记的信息窗|完全支持。|
|覆盖物（[GroundOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-groundoverlay-0000001208344754)/[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlay-0000001253144701)）|不支持|
|形状（[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-circle-0000001208344752)/[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695)/[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polygon-0000001208024792)）|完全支持。|
|自定义地图样式|不支持|

#### 开启地图精简模式

您可以根据下面的代码示例开启地图精简模式。

```
HuaweiMap( 
    liteMode:true, 
    initialCameraPosition:CameraPosition( 
        target:LatLng(51.5160895,-0.1294527), 
        zoom: _zoom, 
    ), 
    onClick: (LatLng latLng) { 
        log("Map Clicked at ${latLng.lat} : ${latLng.lng}"); 
    }, 
    onLongPress: (LatLng latLng) { 
        log("Map LongClicked at ${latLng.lat} : ${latLng.lng}"); 
    }, 
    markers: markers, 
    circles: circles, 
    logoPadding:EdgeInsets.all(8.0), 
)
```
