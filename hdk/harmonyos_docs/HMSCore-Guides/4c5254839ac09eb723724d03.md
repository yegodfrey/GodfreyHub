# 按主题发送消息

按主题发送消息的功能可让您将消息发送至已经选择加入特定主题的多台设备。您可以根据需要撰写主题消息，推送服务负责将消息可靠地传送至正确的设备。

例如，某个天气预报应用的用户可选择加入"天气"主题，并接收关于本地天气的通知。
> 说明
>
> * 主题消息适合传递可通过公开途径获得的信息，例如天气、温度等。
> * 主题消息传递不限制每个主题的订阅数。但是，推送服务有如下限制：
>   * 一个应用订阅的主题数量不能超过2000个。
>   * 单次消息中携带主题数量最大不超过100个。
>   * 在EMUI 10.0以上的华为设备要求HMS Core（APK）的版本不低于3.0.0。低于EMUI 10.0的华为设备上要求HMS Core（APK）的版本不低于4.0.3，高版本的HMS Core（APK）补齐了低版本EMUI缺失的功能。

按主题发送消息的开发步骤如下：

1. 用户通过应用或者应用服务器订阅主题，详细请参见[客户端主题管理](#section138213497566)和[服务端主题管理](#section39821022185711)。
2. 用户订阅完主题后，您就可以根据主题发送消息，详细请参见[发送主题消息](#section372094825714)。

## 客户端应用主题管理

客户端应用可以订阅任何现有主题，也可创建新的主题。开发者使用[subscribe](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650#section1222313413551)方法实现订阅功能，可以通过添加侦听器来侦听订阅是否成功，代码示例如下。

```java
"Java"
public void subscribe(String topic) {
    try {
        // 主题订阅
        HmsMessaging.getInstance(context).subscribe(topic)
        .addOnCompleteListener(new OnCompleteListener<Void>() {
            @Override
            public void onComplete(Task<Void> task) {
                // 获取主题订阅的结果
                if (task.isSuccessful()) {
                    Log.i(TAG, "subscribe topic successfully");
                } else {
                    Log.e(TAG, "subscribe topic failed, return value is " + task.getException().getMessage());
                }
            }
        });
    } catch (Exception e) {
        Log.e(TAG, "subscribe failed, catch exception : " + e.getMessage());
    }
}
```

```kotlin
"Kotlin"
private fun subscribe(topic: String?) {          
    try {    
        // 主题订阅        
        HmsMessaging.getInstance(this@MainActivity)                        
        .subscribe(topic)                        
        .addOnCompleteListener { task ->
            // 获取主题订阅的结果 
            if (task.isSuccessful) {                                                  
                Log.i(TAG, "subscribe topic successfully")                                    
            } else {                                
                Log.e(TAG, "subscribe topic failed, the return value is " + task.exception.message)                            
            }
        }
    } catch (e: Exception) {                
        Log.e(TAG, "subscribe failed, catch exception : $e")          
    }        
}
```

[unsubscribe](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650#section7598115275611)方法实现主题退订功能，代码示例如下。

```java
"Java"
public void unsubscribe(String topic) {
    try {
        // 取消主题订阅
        HmsMessaging.getInstance(context).unsubscribe(topic)
        .addOnCompleteListener(new OnCompleteListener<Void>() {
            @Override
            public void onComplete(Task<Void> task) {
                // 获取取消主题订阅的结果
                if (task.isSuccessful()) {
                    Log.i(TAG, "unsubscribe topic successfully");
                } else {
                    Log.e(TAG, "unsubscribe topic failed, return value is " + task.getException().getMessage());
                }
            }
        });
    } catch (Exception e) {
        Log.e(TAG, "unsubscribe failed, catch exception : " + e.getMessage());
    }
}
```

```kotlin
"Kotlin"
private fun unsubscribe(topic: String?) {          
    try {    
        // 取消主题订阅

            }
        }
    } catch (e: Exception) {                
        Log.e(TAG, "unsubscribe failed, catch exception : $e")          
    }        
}
```

## 应用服务端主题管理

Push Kit服务端给您提供了基本的主题管理API，单次可以为1000个以内的Push Token订阅或者退订某个主题，每个应用最多存在2000个不同的主题。主题与Push Token的订阅关系生效需等待一分钟，待订阅关系生效后，您可以通过指定主题或者组合主题实现消息批量发送。

本功能开发步骤如下：

1. 您可以通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)或者[基于服务账号生成鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)方式获取鉴权信息。
2. 您的服务端调用[主题订阅API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/topic-sub-api-0000001051066122)或[主题退订API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/topic-unsub-api-0000001050746185)进行应用主题订阅或退订，实现对应用主题的管理。

   **主题订阅示例**

   HTTPS POST URL：

   ```screen
   https://push-api.cloud.huawei.com/v1/[clientid]/topic:subscribe
   ```

   > 说明
   >
   > "[clientid]"请替换为您应用的Client ID（在[项目设置页面](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137#section125831926193110)获取）。

   请求消息头示例：

   ```http
   Authorization: Bearer CV0kkX***************************9h2q66KSl5
   Content-Type: application/json
   ```

   > 说明
   > * 请求消息头中的Authorization参数为通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)获取的Access Token或者[基于服务账号生成的鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)。
   > * Access Token如果是通过curl命令或者Postman等工具手工获取，需注意JSON字符串中的转义符，请把"\/"还原为"/"，替换后才是正确的Access Token。如果是从代码运行获取，则采用任意的第三方库均能正确解析JSON串，获取到正确的Access Token。

   请求消息体示例：

   ```screen
   {
       "topic": "weather",
       "tokenArray": [
           "AOffIB70***************Lm8Up1-3K7",
           "AKk3BMXy***************t2s8QkOgnQ"
       ]
   }
   ```

   **主题退订示例**

   HTTPS POST URL：

   ```screen
   https://push-api.cloud.huawei.com/v1/[clientid]/topic:unsubscribe
   ```

   > 说明
   >
   > "[clientid]"请替换为您应用的Client ID（在[项目设置页面](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137#section125831926193110)获取）。

   请求消息头示例：

   ```http
   Authorization: Bearer CV0kk***************Ha9h2q66KSl5
   Content-Type: application/json
   ```

   > 说明
   > * 请求消息头中的Authorization参数为通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)获取的Access Token或者[基于服务账号生成的鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)。
   > * Access Token如果是通过curl命令或者Postman等工具手工获取，需注意JSON字符串中的转义符，请把"\/"还原为"/"，替换后才是正确的Access Token。如果是从代码运行获取，则采用任意的第三方库均能正确解析JSON串，获取到正确的Access Token。

   请求消息体示例：

   ```screen
   {
       "topic": "weather",
       "tokenArray": [
           "AOffIB70***************m8Up1-3K7",
           "AKk3BMXy***************2s8QkOgnQ"
       ]
   }
   ```

## 发送主题消息

当订阅完主题后，您就可以根据主题发送消息，当前支持基于HTTPS协议进行主题消息发送。详情可参见[发送下行消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-server-dev-0000001050040110)。需要注意的是，基于HTTPS协议发送时，消息发送"message"结构体中需要指定发送的主题参数[topic](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p10317128102317)。

消息体示例报文：

```screen
{
    "validate_only": false,
    "message": {
        "notification": {
            "title": "message title",
            "body": "message body"
        },
        "android": {
            "notification": {
                "click_action": {
                    "type": 1,
                    "action": "com.huawei.codelabpush.intent.action.test"
                }
            }
        },
        "topic": "weather"
    }
}
```

同时华为推送服务也支持向组合主题发送消息，即指定目标主题的condition条件表达式，示例请参见[基于条件的消息推送](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-cond-send-0000001050040128)。此时需要注意的是，基于HTTPS协议开发时，消息发送"message"结构体中需要指定发送的主题参数[condition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p20317488232)。
