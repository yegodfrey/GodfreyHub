# 携手Awareness，想去哪儿就去哪儿

#### 背景介绍

去哪儿网是中国领先的无线和在线旅游平台，通过全平台覆盖，随时随地为消费者提供机票、酒店、度假、旅游团购、及旅行信息的深度搜索，帮助消费者找到性价比高的产品、优质的信息和便捷的预订方式，聪明地安排旅行。  

#### 面临挑战

旅行行业经过多年的发展，同质化竞争严重。如何第一时间洞悉用户的需求，在旅行的不同环节间智能衔接，往往成为留住用户形成商业闭环的关键，也是去哪儿网体现差异化竞争优势面临的挑战：

* 如何在用户的旅行状态发生变化时，根据特定用户所处的情景，如所处的位置、节假日信息、天气情况等，提供刚刚好的服务。
* 如何实现一次集成获取各种情景感知能力，并且能够组合运用，免于对算法、架构、隐私等专业人员的需求。

#### 解决方案

情景感知服务（Awareness Kit）提供获取用户情景状态的组合能力，如用户所处位置、当前时间是早晨中午或是下午、天气情况等感知能力。调用这些能力，可以更高效地洞悉用户当前所处的情景，为用户提供更加智慧的旅行体验。

去哪儿网通过调用HMS Core情景感服务，注册地理围栏、时间围栏、查询天气情况等，帮助消费者更聪明地安排旅行。例如，当用户在景区内靠近闭园时间时，发现景区所在地区即将迎来一场暴雨，通过调用Awareness Kit的能力，去哪儿网可以为第一时间洞悉用户情景变化，并为用户推荐景区附近的住宿。
