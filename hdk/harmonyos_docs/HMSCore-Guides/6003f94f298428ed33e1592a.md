# 自动推送通知

自动推送通知支持依据终端用户所处的实际场景智能的推送消息，即在合适的场景中，推送合适的内容给合适的人，实现智能推送与场景推送。这些场景包括：耳机插入时、车载蓝牙断开时、免打扰模式取消时、节假日或休息日、温度范围或紫外线强度变化时、地理围栏条件触发时（"触发条件"：进入、离开、停留）。您可以基于终端用户实际场景触发消息，精确命中用户不同场景下的不同需求，提高用户点击消息的概率，有效提升用户活跃度与粘性。

* 自动推送通知能力依赖HMS Core（APK）的版本不低于5.0.0，EMUI的版本不低于9.1.0，推送服务应用的版本不低于10.1.2.300。
* 自动推送通知仅支持在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)上进行推送，不支持通过调用服务端API进行推送。
* 自动推送通知需要的相关权限可能涉及用户隐私，需要您的应用在启动时向用户以弹出对话框的方式申请授权，显式地由用户决定是否将该权限赋予应用。
* 自动推送通知功能依赖于[情景感知服务（Awareness Kit）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-introduction-0000001050171255)和[定位服务（Location Kit）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050706106)。使用自动推送通知前，请您仔细阅读这两个服务的隐私声明和个人数据处理说明。

自动推送通知包括地理围栏推送与情景智能推送两部分，下面介绍这两个部分实现时需要申请的权限，以及如何在AppGallery Connect上创建自动推送任务。  

#### 地理围栏推送

您可以创建一个半径为R米的地理围栏，当目标用户进入、离开或驻留该地理围栏时向用户推送通知消息。

#### 客户端应用申请权限

在AndroidManifest.xml文件中声明使用如下权限，由于位置权限属于危险权限，请在应用启动运行时向用户弹框申请授权。如果用户拒绝授权，或者设置了"仅使用期间允许"则本功能不可用。

位置权限

```
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
```

* 应用的targetSdkVersion为29或更高版本（Android Q及以上）且包含需要"始终允许"访问设备当前位置的功能，请在AndroidManifest.xml文件中添加以上位置权限。
* 应用的targetSdkVersion为28或更低版本（Android P及以下），当您请求"ACCESS_FINE_LOCATION"或"ACCESS_COARSE_LOCATION"时，系统会自动为应用添加"ACCESS_BACKGROUND_LOCATION"权限。  

#### AppGallery Connect网站创建任务

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"，在项目列表中找到您的项目，在项目中点击您的应用，通过"增长 \> 推送服务 \> 自动推送通知（Beta）"导航到"自动推送通知（Beta）"页签。选择"添加地理围栏推送通知"来进行推送任务的创建。其中"消息内容"、"推送范围"的设置请参见[Android应用推送通知栏消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-android-0000001136294192#section1925353194818)。

"地理围栏"与"推送周期"的设置见下图。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095819.17397750239872910142899291713836:50001231000000:2800:345F318BEFAE019C30AB44914EB5F061A81099F4AF87A030918A839D724A5E7A.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

如何进行地理围栏管理请参见[地理围栏开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/geofence-develop-steps-0000001050986159)。

* 单设备频率控制：为防止用户打扰而设置本功能。您可以设置每设备在特定时间内收到的消息上限条数，也可以设置推送周期内的总条数（设置的时间不超过30天，当前每设备每天不得收到超过1条消息，因此推送周期内总共发送不得超过30条）。
* 推送周期指本次任务的有效期。"开始时间"指任务的生效时间，"结束时间"指任务的失效时间，开始结束时间区间要求不小于1天，不超过30天。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095819.75856395811969065165734722528894:50001231000000:2800:3A3000D4FC40F5784B455C3B671C2DFDD9365AC01F2DDA794B85E79503DE36FF.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
* 地理围栏推送在确定的推送周期中仅支持创建1个任务，不支持创建多个任务。
* 建议您在调试过程中每个任务时间配置不宜过长。

#### 客户端应用申请权限

在AndroidManifest.xml文件中声明使用如下权限，其中蓝牙权限属于基本权限，应用安装后就能自动获取无需用户授权。其余权限都要在应用启动运行时向用户弹框申请授权，如果用户拒绝授权，或者设置了"仅使用期间允许"则本功能不可用。  
位置权限

```
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
```

蓝牙权限

```
<uses-permission android:name="android.permission.BLUETOOTH" />
```

活动探知权限

```
<uses-permission android:name="android.permission.ACTIVITY_RECOGNITION" />
```
