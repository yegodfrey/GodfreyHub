# 极速开屏广告

极速开屏广告由鲸鸿动能平台推出，在提升用户开屏体验的同时为您提供更便捷的广告变现方案，您无需集成SDK即可接入极速开屏广告。  

#### 使用说明

接入了华为极速开屏的应用，在用户同意应用的用户协议之前，极速开屏不会展示。

当用户协议的同意状态发生变化时（用户同意或者撤销同意），需要将最新状态同步到鲸鸿动能平台。

#### 开发步骤

#### 同步用户协议同意状态至鲸鸿动能平台

1. 创建接口ExSplashService的AIDL文件，放置在com.huawei.hms.ads包路径下，如下图：

   <br />

   ![](https://media:201785910050367876 "点击放大")

   <br />

2. 将以下内容复制到AIDL文件中。

   <br />

   ```
   package com.huawei.hms.ads;  

   interface ExSplashService {  
       void enableUserInfo(boolean enable);  
   }
   ```

   <br />

3. 创建一个类，实现Android原生的ServiceConnection接口。

   <br />

   1. 实现ServiceConnection的onServiceConnected方法。
   2. 调用Android原生的ExSplashService.Stub.asInterface方法获取ExSplashService。
   3. 调用enableUserInfo方法同步用户协议状态。

   示例代码如下所示：

   ```
   "Java"
   public final class ExSplashServiceConnection implements ServiceConnection {  

       private static final String TAG = "ExSplashServiceConnection";  

       private Context context;  

       public ExSplashServiceConnection(Context context) {  
           this.context = context;  
       }  

       @Override  
       public void onServiceConnected(ComponentName name, IBinder service) {  
           Log.i(TAG, "onServiceConnected");  
           ExSplashService exSplashService = ExSplashService.Stub.asInterface(service);  
           if (exSplashService != null) {  
               try {  
                   // 是否同意用户协议，同意为true，不同意为false  
                   exSplashService.enableUserInfo(true);  
               } catch (RemoteException e) {  
                   Log.i(TAG, "enableUserInfo error");  
               } finally {  
                   context.unbindService(this);  
               }  
           }  
       }  

       @Override  
       public void onServiceDisconnected(ComponentName name) {  
           Log.i(TAG, "onServiceDisconnected");  
       }  
   }
   ```

   ```
   "Kotlin"
   inner class ExSplashServiceConnection(private val context: Context?) : ServiceConnection { 

       override fun onServiceConnected(name: ComponentName, service: IBinder) {  

           val TAG = ExSplashServiceManager::class.java.simpleName
           Log.i(TAG, "onServiceConnected")  
           exSplashService = ExSplashService.Stub.asInterface(service)  
           if (exSplashService != null) {  
               try {  
                   // 同意为true，不同意为false  
                   exSplashService!!.enableUserInfo(true)  
               } catch (e: RemoteException) {  
                   Log.i(Companion.INNER_TAG, "enableUserInfo error")  
               } finally {  
                   context!!.unbindService(this)  
               }  
           }  
       }  
     
       override fun onServiceDisconnected(name: ComponentName) {  
           Log.i(Companion.INNER_TAG, "onServiceDisconnected")  
       }  
   }
   ```

   <br />

4. 连接极速开屏的AIDL服务。

   <br />

   1. 创建一个ExSplashServiceConnection实例。
   2. 创建一个Intent，action是"com.huawei.hms.ads.EXSPLASH_SERVICE"。
   3. 设置Intent的包名为"com.huawei.hwid"。
   4. 调用bindService连接极速开屏的AIDL服务。

   示例代码如下所示：

   ```
   "Java"
   private boolean bindService() {  
       ExSplashServiceConnection serviceConnection = new ExSplashServiceConnection(context);  
       Intent intent = new Intent("com.huawei.hms.ads.EXSPLASH_SERVICE");  
       intent.setPackage("com.huawei.hwid");  
       boolean result = context.bindService(intent, serviceConnection, Context.BIND_AUTO_CREATE);  
       Log.i(TAG, "bindService result: " + result);  
       return result;  
   }
   ```

   ```
   "Kotlin"
   private fun bindService(): Boolean {  
       var serviceConnection: ServiceConnection? = ExSplashServiceConnection(context)  
       val intent = Intent("com.huawei.hms.ads.EXSPLASH_SERVICE")  
       intent.setPackage("com.huawei.hwid")  
       val result = context!!.bindService(intent, serviceConnection!!, Context.BIND_AUTO_CREATE)
       Log.i(TAG, "bindService result: $result")  
       return result 
   }
   ```

#### （可选）极速开屏广告广播通知

在极速开屏广告展示时，鲸鸿动能平台会通过发送一个广播通知应用，广播的action为"com.huawei.hms.ads.EXSPLASH_DISPLAYED"，应用可以注册一个广播接收器来接收此广播，并自行决策如何使用。

1. 创建广播接收器，实现一个继承BroadcastReceiver的类，并实现onReceive方法。

   <br />

   示例代码如下所示：

   ```
   "Java"
   public class ExSplashBroadcastReceiver extends BroadcastReceiver {  
       @Override  
       public void onReceive(Context context, Intent intent) {  
           if (intent == null) {  
               return;  
           }  
           String action = intent.getAction();  
           if (action.equals("com.huawei.hms.ads.EXSPLASH_DISPLAYED")) {  
               // 根据业务场景处理此通知
           }  
       }  
   }
   ```

   ```
   "Kotlin"
   class ExSplashBroadcastReceiver : BroadcastReceiver() {  
       override fun onReceive(context: Context, intent: Intent) {  
           if (intent == null) {  
               return  
           }  
           val action = intent.action  
           if (action == "com.huawei.hms.ads.EXSPLASH_DISPLAYED") {  
               // 根据业务场景处理此通知
           }  
       }  
   }
   ```

   <br />

2. 注册广播接收器，建议在应用启动时即注册。

   <br />

   示例代码如下所示：

   ```
   "Java"
   IntentFilter filter = new IntentFilter("com.huawei.hms.ads.EXSPLASH_DISPLAYED");  
   registerReceiver(new ExSplashBroadcastReceiver(), filter);
   ```

   ```
   "Kotlin"
   val filter = IntentFilter("com.huawei.hms.ads.EXSPLASH_DISPLAYED")  
   registerReceiver(ExSplashBroadcastReceiver(), filter)
   ```

#### （可选）通知媒体极速开屏广告展示失败

由无广告返回、广告请求超时和未同意用户协议等原因导致的极速开屏广告展示失败，鲸鸿动能平台会发送一个广播通知应用。广播的action为"com.huawei.hms.ads.EXSPLASH_AD_DISMISS"，应用可以通过接收这个广播来确认极速开屏广告展示失败，并自行决策如何使用。

发送的广播为粘性广播，发送后将一直存在于系统的消息容器里面，应用接收后需要调用removeStickyBroadcast(intent)方法将已接收过的广播移除，否则下次还可以获取到此广播数据。  
粘性广播有两种接收方式：

* 方式1：使用普通广播接收器，必须在"AndroidManifest.xml"文件中接收广播或者在广播发送之前动态接收。
* 方式2：不需要使用BroadcastReceiver类，可接收在注册之前发送的广播。  
  示例代码如下所示：

  ```
  "Java"
  IntentFilter filter = new IntentFilter("com.huawei.hms.ads.EXSPLASH_AD_DISMISS");
  Intent intent = registerReceiver(null, filter, "com.huawei.permission.app.DOWNLOAD", null);
  ```

  ```
  "Kotlin"
  val filter = IntentFilter("com.huawei.hms.ads.EXSPLASH_AD_DISMISS")
  val intent = registerReceiver(null,  filter, "com.huawei.permission.app.DOWNLOAD", null)
  ```

举例：在应用启动后，先使用方式2获取消息容器内是否有已发送的广播，再使用方式1注册广播接收器，接收后调用removeStickyBroadcast从消息容器中移除当前广播。接收时可指定发送方权限为"com.huawei.permission.app.DOWNLOAD"。  
示例代码如下所示：

```
"Java"
IntentFilter filter = new IntentFilter("com.huawei.hms.ads.EXSPLASH_AD_DISMISS");
Intent intent = registerReceiver(null, filter, "com.huawei.permission.app.DOWNLOAD", null);
if (intent != null && intent.getAction() != null &&
        intent.getAction().equals("com.huawei.hms.ads.EXSPLASH_AD_DISMISS")) {
    // 根据业务场景处理此广播
    context.removeStickyBroadcast(intent);
}
// 根据业务场景自定义ExSplashAdDismissReceiver类，接收后也需要调用removeStickyBroadcast方法移除当前广播 
registerReceiver(new ExSplashAdDismissReceiver(), filter, "com.huawei.permission.app.DOWNLOAD", null);
```

```
"Kotlin"
val filter = IntentFilter("com.huawei.hms.ads.EXSPLASH_AD_DISMISS")
val intent = registerReceiver(null, filter, "com.huawei.permission.app.DOWNLOAD", null)
if (intent != null && intent.action != null &&
        intent.action =="com.huawei.hms.ads.EXSPLASH_AD_DISMISS") {
    // 根据业务场景处理此广播
    removeStickyBroadcast(intent)
}
// 根据业务场景自定义ExSplashAdDismissReceiver类，接收后也需要调用removeStickyBroadcast方法移除当前广播 
registerReceiver(ExSplashAdDismissReceiver(), filter, "com.huawei.permission.app.DOWNLOAD", null)
```
