# 数据导出说明

#### 场景介绍

分析服务开放了服务端接口，允许您通过接口方式申请导出端侧采集的事件数据，并导入到您自有的BI系统中，进行统一的数据分析。导出完成后，分析服务异步地将导出的数据上传到云端存储对象（Object Storage Service），随后以HTTPS POST请求回调您接口的方式将导出结果和数据的存储路径推送给您。为了保证数据安全，下载链接会在48个小时后失效。

目前导出的状态有：  

|数据下载状态码|状态码描述|原因及处理|
|:---------------|:------------------------------------------------------------------------------------------------|:----------------------------------------------------------|
|EXPORTED|成功导出。|及时处理下载链接。|
|NO_DATA|没有符合条件的数据。|建议更改[数据筛选条件](#ZH-CN_TOPIC_0000001054905880__p454910610412)。|
|EXPORT_FAILED|导出失败。|服务端异常，建议重试。|
|TOO_MANY_RECORDS|一次导出数据量太多。 说明： * 导出数据文件大小超过5G时，提示此信息。 * 如果数据文件大小没有超过5G，但数据量超过了500W条，建议缩减范围，如果不缩减范围将为您随机导出500W条数据。|建议缩小数据导出范围后重新发起请求。|

建议服务端对下载链接的处理，采用异步处理方式，及时将成功状态返回给分析服务器。

附：数据筛选条件  

|属性名称|属性描述|
|:-----------|:----------------------------------------|
|app_ver|应用版本号。|
|device_maker|设备品牌。|
|device_name|设备型号。|
|region_cd|位置编码。|
|os_language|操作系统语言。|
|os_ver|操作系统版本。|
|event_id|事件ID。 说明： 仅支持预置事件以及自定义事件的导出，不支持自动采集事件的导出。|

#### 设置回调接口

1. 点击"我的项目"，在"华为分析 \> 管理 \> 分析设置"页面，勾选配置回调接口可进行相关设置。
2. 配置回调接口地址，您的下载地址接收URL。

   PEM格式的证书与配置HTTPS证书获得的"Base64 编码 X.509(.CER)(S)"格式是一致的。
3. [配置HTTPS证书](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/remarks-0000001050707452#section1781515545513)。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115254.67288079282785462146131291483035:50001231000000:2800:E55098BA4F4D241076ED4F07095A354B2C24679A342E52BDCA259DA0D03C5F85.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   目前分析服务以HTTPS POST请求回调您接口，分析服务会校验您HTTPS证书的合法性，请您的服务器务必使用正式商用的HTTPS证书。
4. 点击"测试回调"可以对回调接口进行功能测试，测试通过后点击"保存"完成回调接口的配置。  

#### 开发指导

在开发回调接口前，需要先准备一个公网域名，及一个可以接收post请求的接口（POST接口需要有HTTPS证书）。

开发过程请参考：

1. 开发回调接口（代码如下），开发的域名为：habackup.hwcloudtest.cn。

   ```
   @RequestMapping(value = "/agc/analytics/callback", method = RequestMethod.POST)
   public ResultResp callback(@RequestBody @Valid ExportDataCallbackReq req) {
       ResultResp result = new ResultResp();
       // Analytics Kit导出任务生成完成后，接收回调
       if (LOGGER.isDebugEnabled()) {
           LOGGER.debug("the download url: {}", req.getFilePath());
       }
       // 拿到下载地址，继续往下做业务逻辑
       result.setResultCode("0");
       result.setResultMsg("success");
       return result;
   }
   ```

   请求对象：

   ```
   public class ExportDataCallbackReq implements Serializable {
       private static final long serialVersionUID = -8014011591749838257L;
       @JsonProperty("request_id")
       private String requestId;
       @JsonProperty("app_id")
       private String appId;
       @JsonProperty("status")
       private String status;
       @JsonProperty("file_path")
       private String filePath;
       @JsonProperty("status_time")
       private String statusTime;
   }
   ```
