# 接入流程

**图1**接入流程   
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/jnkULQMGRLuwFkdWPBoMSQ/zh-cn_image_0000002516519320.png?HW-CC-KV=V1&HW-CC-Date=20260909T130453Z&HW-CC-Expire=31536000000&HW-CC-Sign=3EE53FD37EA5656523F68AC383474616104E72F77642EEA148B3E0AB8E791C1C)

1. 与华为 BD 沟通合作意向，签署合作协议后，[获取 Gym Profile 开发套件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/get-gymprofile-0000001054902790)。
2. 根据本文档和 Gym Profile 开发套件完成运动设备[蓝牙模块功能开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/bluetooth-protocol-0000001054490011)。
3. [设计及部署二维码和 NFC 标签](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/label-0000001050145372)以实现通过手机 NFC 一碰联或者二维码扫码快速连接运动设备。
4. 准备及提交素材资源文件至华为开发者联盟给华为审核，以实现在运动健康App中添加设备（入口：App > 设备 > 添加设备）。参见[准备及提交素材资源文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cardio-prepare-0000001073168603)。
5. 通过测试工具和测试用例测试设备蓝牙模块功能实现是否符合接入运动健康的要求。参见[蓝牙模块功能测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/test-profile-0000001050147323)。
6. 与运动健康App 对接测试：

   1. 使用运动健康App 和测试用例，测试 NFC 一碰联和二维码扫描连接功能（智能跳绳不支持一碰联，无需测试该功能）。参见[一碰联功能测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/test-nfctouch-0000001050145374)。
   2. 将设备资源包拷贝到手机上，使用运动健康App 和测试用例，测试在 App 中添加设备功能是否正常。参见[App 添加设备功能测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cardio-test-adddevice-0000001073758350)。

7. 投递样机，提交测试报告至华为开发者联盟给华为进行认证测试，华为安排测试资源，反馈测试结果（跑步机需要提交至第三方认证机构进行认证测试）。
8. 若涉及到与华为品牌有关的营销材料，需提交华为审核，才可以对外发布。
9. 产品认证通过，营销等资料审核通过，产品可正式发布。
