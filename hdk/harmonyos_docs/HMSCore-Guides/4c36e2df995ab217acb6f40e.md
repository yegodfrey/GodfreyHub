# 事件代理

本章节包含地图的点击和长按、相机移动、以及"我的位置"按钮点击等事件代理回调。

## 地图事件侦听

### 点击事件侦听

```screen
- (void)mapView:(HMapView *)mapView didTapAtCoordinate:(CLLocationCoordinate2D)coordinate;
```

### 长按事件侦听

```screen
- (void)mapView:(HMapView *)mapView didLongGuestureTapAtCoordinate:(CLLocationCoordinate2D)coordinate;
```

## 相机移动侦听

相机移动时，应用层通过设置侦听器，能够对相机移动状态进行侦听。

```screen
/**
* @brief  地图区域即将改变时会调用此接口
* @param mapView 地图View
* @param animated 是否动画
* @param bGesture 是否由手势触发
*/
- (void)mapView:(HMapView *)mapView regionWillChangeAnimated:(BOOL)animated gesture:(BOOL)bGesture;
/**
* @brief  地图区域改变时会调用此接口。视野持续变化时本回调可能会被频繁多次调用, 请不要做耗时或复杂的事情
* @param mapView 地图View
*/
- (void)mapViewRegionChange:(HMapView *)mapView;
/**
* @brief  地图区域改变完成后会调用此接口，如果是由手势触发，当触摸结束且地图region改变的动画结束后才会触发此回调
* @param mapView 地图View
* @param animated 是否动画
* @param bGesture region变化是否由手势触发
*/
- (void)mapView:(HMapView *)mapView regionDidChangeAnimated:(BOOL)animated gesture:(BOOL)bGesture;
```

## 其他事件侦听

### 标记点击事件侦听

```screen
/**
 * @brief 当选中一个annotation view时，调用此接口
 * @param mapView地图View
 * @param view选中的annotation view
 */
- (void)mapView:(HMapView *)mapView didSelectAnnotationView:(HAnnotationView *)view;
```

### 窗口点击事件侦听

```screen
/**
* @brief 当选中一个callout view时，调用此接口
* @param mapView地图View
* @param view选中的callout view对应的annotation view
*/
- (void)mapView:(HMapView *)mapView annotationViewCalloutTapped:(HAnnotationView *)view;
```

### "我的位置"按钮点击事件侦听

```screen
/**
 * @brief 点击地图上的定位图标会调用此接口
 * @param mapView地图View
 * @param location返回定位图标的经纬度
 */
- (void)mapView:(HMapView *)mapView didTapMyLocation:(CLLocationCoordinate2D)location;
```
