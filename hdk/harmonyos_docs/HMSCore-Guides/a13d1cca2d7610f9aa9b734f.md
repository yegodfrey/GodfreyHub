# 体温计

为保证良好的用户体验，与运动健康对接的体温计应满足以下要求：

* 针对蓝牙设备：体温计在待机时应关闭蓝牙（停止广播，断开连接），用户测量时开启蓝牙并发起广播；针对非蓝牙设备：体温计在待机时应关闭连接和传输，用户测量时开启连接并进行测量和传输数据。

* 测量结束后，应立即传输数据，并且在数据传输成功后10s内关闭蓝牙并进入待机状态。

* 体温计应保证测量结果传输的完整性和原子性。

* 支持保存历史数据的体温计，最好支持时钟，以便在脱机状态下能够记录测量时间。

#### 测量协议

支持厂商私有蓝牙协议。  

#### 测量流程

运动健康App接收到体温设备蓝牙广播后，主动发起连接。如果连接成功，则开始发现服务流程。接下来发现服务成功之后，体温设备应至少返回一个厂商自定义的服务。如果超过2分钟没有连接成功，则提示连接超时。
