# 版本更新说明

#### 6.10.0.301（2023-05-16）

HarmonyOS（Java）版本：com.huawei.hms:hianalytics-harmony:6.10.0.301 **修改特性** 优化了SDK包的大小（从2.4M优化至0.68M）。  
---  
  
#### 历史版本

#### [h2]6.10.0.300（2023-03-06）

HarmonyOS（Java）版本：com.huawei.hms:hianalytics-harmony:6.10.0.300 **修改特性**
                * 自动采集事件[APPFIRSTOPEN](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-automatic-event-collection-0000001123074896#ZH-CN_TOPIC_0000001123074896__li1902124561120)和[LAUNCHAPP](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-automatic-event-collection-0000001123074896#ZH-CN_TOPIC_0000001123074896__li197281146256)的上报时机改为实时上报。 
                * 应用切后台时，上报策略改为必选策略。 
                * 修复了部分场景（重新下载替换agconnect-services.json文件）初始化失败问题。   
---  
  
#### [h2]6.9.0.300（2022-12-08）

注意：  分析服务SDK 6.9.0.300及之前版本，如果重新下载替换了agconnect-services.json文件，可能导致初始化失败，6.10.0.300版本解决了此问题，建议升级分析服务SDK为6.10.0.300及以上版本。 HarmonyOS（Java）版本：com.huawei.hms:hianalytics-harmony:6.9.0.300 **新增特性** [HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477)类中新增[getDataUploadSiteInfo](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477#section5371121218)接口。  
---

#### [h2]6.3.2.300（2021-12-06）

HarmonyOS（Java）版本：com.huawei.hms:hianalytics-harmony:6.3.2.300 **新增特性**
                * [自动采集用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-automatic-user-attribute-0000001123074898)中新增“屏幕亮度”、“声音模式”、“深色模式”、“自动旋转开关”、“广告标识符”、“个性化广告开关”、“总存储空间”、“剩余存储空间”、“当前电量”、“充电状态”、“总内存”、“剩余内存”、“字体大小”和“userAgent”。 
                * 华为处理的个人数据清单中新增如下数据： 
                  * 新增“广告标识符”、“个性化广告开关”、“字体信息”、“内存信息”、“存储空间”、“电池状态”和“userAgent”。 
                  * “设备信息”中新增“屏幕亮度”、“声音模式”、“深色模式”和“自动旋转开关”。 
                * [HiAnalytics](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-0000001123080524)类中新增[getInstance(Ability ability, String routePolicy)](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-0000001123080524#section8500174514479)和[getInstance(AbilityContext abilityContext, String routePolicy)](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-0000001123080524#section128031336155212)接口。 
**修改特性** 优化事件上报逻辑。

#### [h2]6.3.0.300（2021-10-14）

HarmonyOS（Java）版本：com.huawei.hms:hianalytics-harmony:6.3.0.300 **新增特性**
                * 新增[语言培训](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-language-training-0000001242320799)类预置事件。 
                * 新增[运动健康](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-sports-health-0000001242240765)类预置事件。 
                * 新增[金融理财](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-financial-management-0000001197440878)类预置事件。 
                * 新增[出行旅游](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-travel-0000001197600858)类预置事件。 
                * [HAEventType](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-haeventtype-0000001204636027)中补充语言培训、运动健康、金融理财、出行旅游相关事件。 
                * [HAParamType](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-haparamtype-0000001122920698)中补充语言培训、运动健康、金融理财、出行旅游相关参数。 
                * [自动采集用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-automatic-user-attribute-0000001123074898)中新增“HASDK类型”，华为处理的个人数据清单中“应用基本信息”补充通过HUAWEI Analytics SDK平台类型维度做统计分析。 
                * [自动采集用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-automatic-user-attribute-0000001123074898)中新增“设备形态”，华为处理的个人数据清单中新增“设备形态”。 
                * [预置用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-predefined-user-attribute-0000001169514863)中新增ISMEMBER属性。 
                * 自动采集事件、预置事件和自定义事件中新增$PrePageId和$CurrPageId参数。
