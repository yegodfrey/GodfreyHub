# 基于RISC的跨帐号保护

#### 概述

跨帐号保护，是一种基于OpenID基金会的RISC标准，用于主动保障开发者应用多帐号安全性的安全加固部件。

开发者应用订阅特定的安全事件，通过该模块，则可及时接收到相关华为帐号变动的异常事件信息（比如华为帐号被冻结、被劫持等）。您可针对异常事件进行主动防控，从而降低帐号之间的污染传递。

例如：某个用户的华为帐号被劫持，为防止劫持者通过该帐号的电子邮件等其他帐户信息进行更大范围的劫持，您可订阅华为帐号的相关事件，在收到劫持的异常事件信息后，暂时禁用该帐号的登录。  

#### 接入前准备

开发者应用在订阅跨帐号保护之前，请先在华为开发者联盟的[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)中新建项目、添加启用RISC API服务，并创建服务帐号密钥类型的凭证。相关操作步骤，请参见[API Console操作指南](https://developer.huawei.com/consumer/cn/doc/start/api-0000001062522591)。

您需妥善保存在[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)上创建并下载的服务帐号密钥文件，在后续生成令牌Access Token与Token签名验证均需用到该密钥文件。  

#### 接入步骤

订阅跨帐号保护功能，您需完成如下：

1. 开发者应用注册事件接收服务，向华为跨帐号保护服务，订阅安全事件并注册消息接收地址。
2. 开发者应用需获得用户允许消息投递的授权。
3. 开发者应用能够接收事件消息体，完成签名验证与解析。

如此，开发者应用即可接收到来自华为投递的安全事件消息。  

#### 注册接收服务

开发者应用在完成接入前准备后，需将订阅的安全事件、接收投递消息的接收地址，向华为跨帐号保护服务进行注册。

1. 生成令牌Access Token。

   JWT（JSON Web Token）为一种特殊类型，服务帐号令牌即为JWT类型格式的Access Token，生成该类鉴权令牌的相关操作，请参见[基于Service Account开放鉴权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-service-account-0000001053509221)。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220623171205.00771541016570945506652911230926:50001231000000:2800:3A13BA35AE79241177731BD09E2A7A3771EC9AEEEB876C82631BA6EC8B315015.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   此鉴权令牌可用于RISC API调用，有效期为一小时。当令牌过期后，请生成一个新令牌以继续进行RISC API调用。
2. 注册接收服务。

   您在本地生成Access Token之后，可通过调用接口（/v1beta/toolkit/risc/stream:update），向华为跨帐号保护服务进行事件接收服务注册、配置修改、服务启停操作。
   * 注册事件接收服务，请通过POST方式调用，示例如下：

     ```
     POST /v1beta/toolkit/risc/stream:update HTTP/1.1
     Host: risc.cloud.huawei.com
     Content-Type: application/json
     Authorization: Bearer <Access Token>
     Cache-Control: no-cache
     Postman-Token: 74f0e351-fdcb-c74a-ed63-670cb5926659
      
     {
       "iss": "id.cloud.huawei.com",
       "aud": [
         "<应用ID-1>",
         "<应用ID-2>",
         "<应用ID-3>"
       ],
       "delivery": {
         "delivery_method": "https://schemas.openid.net/secevent/risc/delivery-method/push",
         "url": "<消息接收URL>"
       },
       "events_requested": [
         "<安全事件类型-1>",
         "<安全事件类型-2>",
         "<安全事件类型-3>"
       ],
       "status": "enabled"
     }
     ```

     |参数|描述|
     |:---------------|:-----------------------------------------------------------------------------------------------|
     |iss|标识数据投递者，固定为"id.cloud.huawei.com"。|
     |aud|接收者关注的应用ID（即APPID）列表，各个应用ID需先获得到用户的授权才可接收到安全消息体，具体授权过程，请参见[获取用户授权](#section10631131114279)。|
     |delivery_method|投递方式，固定为"https://schemas.openid.net/secevent/risc/delivery-method/push"。|
     |url|安全消息的接收者URL，须满足为https协议、域名确定、网络可达等条件。|
     |events_requested|需订阅的安全事件类型，可同时订阅多个，相关安全事件类型，请参见[安全事件类型及应对措施](#ZH-CN_TOPIC_0000001053749185__table1981510591539)。|
     |status|此事件接收服务的状态，分为disabled、enabled。|

     成功注册响应如下：

     ```
     {
       "error": "{\"sub_error\":0,\"error_description\":\"success\",\"error\":0}"
     }
     ```

   * 修改事件接收服务的配置信息，如下： 调用接口（/v1beta/toolkit/risc/stream），通过GET请求获取开发者当前事件接受服务的配置信息，修改响应主体，然后通过POST请求，将修改后的配置调用接口（/v1beta/toolkit/risc/stream:update）更新到华为跨帐号保护服务。

   * 启停消息投递服务，如下： 通过POST请求，调用接口（/v1beta/toolkit/risc/stream/status:update），将消息体{ "status": "disabled" }， 更新到华为跨帐号保护服务，即可停止相关消息投递。反之，将消息体{ "status": "enabled" }更新到华为，即可重启华为的消息投递。您还可通过调用接口（/v1beta/toolkit/risc/stream/status）查询服务的状态。

#### 获取用户授权

在华为向开发者应用投递安全事件消息前，开发者应用应先获取用户的授权同意，允许华为将该帐号的安全事件投递到开发者。

涉及到的权限项如下：  

|权限URL|描述|
|:-----------------------------------------------|:------------------|
|https://www.huawei.com/auth/account/riscdelivery|访问帐号安全事件用于保护您的帐号安全。|

获取用户授权请求链接示例如下：

```
https://oauth-login.cloud.huawei.com/oauth2/v3/authorize?response_type=code&access_type=offline&state=state_parameter_passthrough_value&client_id=<应用ID-1>&redirect_uri=<开发者应用回调地址>&scope=openid+https://www.huawei.com/auth/account/riscdelivery&display=touch
```

获取用户授权相关详细操作，请参见[授权码模式（Authorization Code）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section1022911426469)。  

#### 处理消息体

华为向开发者应用投递消息（消息被JWT签名），所以您在接收到消息后，请先对消息进行本地验签操作，确保消息的完整有效性后解析消息体获取安全事件信息。

1. 验证消息体的签名。

   您可通过任何JWT库（例如：[jwt.io](https://jwt.io/introduction/)）对其进行验证与解码。

   无论使用哪种库，您均需完成如下操作：
   1. 调用接口（https://risc.cloud.huawei.com/v1beta/public/risc/.well-known/risc-configuration），获取发行者标识（issuer）与签名密钥证书URI（jwks_uri）。
   2. 通过依赖的JWT库，对消息头中的令牌进行进行解析，获取签名的KeyId。
   3. 通过签名的KeyId，从签名密钥证书URI中获取到JWT签名的公私钥密钥对。
   4. 校验JWT签名中的aud与[接入前准备](#section164367497318)中获取到密钥文件中的sub_account一致。
   5. 校验JWT签名中的issuer与发行者标识（issuer）一致。

   相关代码如下：

   ```
   private DecodedJWT validateSecurityEventToken(String token) {
       DecodedJWT jwt = null;
       try {
           // Replace the values with the actual ones obtained from https://risc.cloud.huawei.com/v1beta/public/risc/.well-known/risc-configuration
           String issuer = "id.cloud.huawei.com";
           String jwksUri = "https://risc.cloud.huawei.com/v1beta/public/risc/certs";
    
           // Get the ID of the key used to sign the token.
           DecodedJWT unverifiedJwt = JWT.decode(token);
           String keyId = unverifiedJwt.getKeyId();
    
           // Get the public key from Huawei.
           JwkProvider huaweiCerts = new UrlJwkProvider(new URL(jwksUri), null, null);
           PublicKey publicKey = huaweiCerts.get(keyId).getPublicKey();
    
           // Verify and decode the token.
           Algorithm rsa = Algorithm.RSA256((RSAPublicKey) publicKey, null);
           JWTVerifier verifier = JWT.require(rsa)
                   .withIssuer(issuer)
                   // client_id<->aud:
                   .withAudience(unverifiedJwt.getAudience().get(0))
                   .acceptLeeway(60 * 1000)
                   .build();
           jwt = verifier.verify(token);
       } catch (JwkException e) {
           // Key not found. Return HTTP 400.
       } catch (InvalidClaimException e) {
           e.printStackTrace();
       } catch (JWTDecodeException e) {
           // Malformed token. Return HTTP 400.
           e.printStackTrace();
       } catch (MalformedURLException e) {
           // Invalid JWKS URI.
           e.printStackTrace();
       }
       return jwt;
   }
   ```

2. 解析消息体。

   您完成本地签名验证后，可对消息体JWT解码（相关文档请参见[JSON Web Token](https://tools.ietf.org/html/rfc7519)），解码后的消息体示例如下：

   ```
   {
     "aud": "<开发者应用ID>",
     "iss": "id.cloud.huawei.com",
     "iat": 1588675381042,
     "jti": "6672ed7d5c5e4c3c92f343ecac40f326",
     "events": {
       "https://schemas.openid.net/secevent/risc/event-type/account-purged": {
         "subject": {
           "sub": "<触发事件用户的unionId>",
           "subject_type": "iss_sub",
           "extra": "<触发事件用户的openId>",
           "iss": "id.cloud.huawei.com"
         }
       }
     }
   }
   ```

   其中，各字段含义如下：  

   |参数|描述|
   |:------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
   |aud|开发者应用ID（与[接入前准备](#section164367497318)下载密钥文件中的字段sub_account一致）。|
   |iss|消息投递者标识，固定值"id.cloud.huawei.com"。|
   |iat|生成该事件的UTC时间戳。|
   |jti|唯一随机字符串，用于标识此消息体，您可根据此字段来识别重投消息体。|
   |events|具体的安全事件类型与其对应的消息体。|
   |subject|* sub：触发事件用户的unionId（用户对同一个开发者下的所有应用，此值唯一）。 * subject_type：固定为"iss-sub"。 * extra：触发事件用户的openId（用户对同一个应用，此值唯一）。 * iss：标识消息投递者，固定为"id.cloud.huawei.com"。|

   您可根据事件类型采取适当的措施。

   各安全事件类型与应对措施如下：  

   |事件类型|属性|应对措施|
   |:-------------------------------------------------------------------------------------|:--------------------------------------|:------------------------------------------------------------------------------------------------------------------------------|
   |https://schemas.openid.net/secevent/oauth/event-type/tokens-revoked|OAuth主动取消授权|如果令牌用于华为登录，请终止其当前打开的会话。此外，建议您提示用户设置其他登录方法。 如果该令牌用于访问其他需要令牌的华为API，请删除您已存储的用户OAuth令牌。|
   |https://schemas.openid.net/secevent/risc/event-type/account-disabled|帐号被劫持（hijacking）或被认定为批量帐号（bulk-account）|如果帐户被禁用的原因是劫持，请结束当前打开的会话阻止帐号信息进一步被窃取。 如果帐号被禁用的原因是被认定为批量帐号，请分析用户的活动并确定适当的后续操作。 如果未提供原因，请禁止用户登录华为帐号，并禁止通过其他方式恢复该帐号，同时向用户提供其他登录方式。|
   |https://schemas.openid.net/secevent/risc/event-type/account-enabled|解冻|为该用户重新启用华为登录，并允许该用户使用华为帐号关联的电子邮件地址重新激活帐号。|
   |https://schemas.openid.net/secevent/risc/event-type/account-purged|销户|删除帐号信息并为用户提供其他替代登录方法。|
   |https://schemas.openid.net/secevent/risc/event-type/account-credential-change-required|修改密码|请注意您的服务是否存在可疑活动，并采取适当的措施。|
   |https://schemas.openid.net/secevent/risc/event-type/verification|验证消息|记录已收到测试投递事件。|

3. 验证服务。

   您在完成接收服务注册、用户授权后，本地可对接收到的消息体验签与解码，则可通过调用接口（/v1beta/toolkit/risc/stream:verify）验证端到端流程。

   请求示例

   请通过POST方式调用，示例如下：

   ```
   POST /v1beta/toolkit/risc/stream:verify HTTP/1.1
   Host: risc.cloud.huawei.com
   Content-Type: application/json
   Authorization: Bearer <Access Token>
   Cache-Control: no-cache
   Postman-Token: c67f7a42-9118-9d70-c37c-d8763cdb0489
    
   {"state":"RISC Test message form client_id of Tester!!!"}
   ```

   响应示例

   ```
   {
     "error": "{\"sub_error\":0,\"error_description\":\"success\",\"error\":0}"
   }
   ```
