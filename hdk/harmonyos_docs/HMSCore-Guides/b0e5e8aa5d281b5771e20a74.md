# 获取用户授权

开发者调用接口显示华为账号登录和授权界面，由用户授权相应的数据访问权限。用户可以自主选择授权的数据类型，可以只授权部分数据权限。应用所能操作的用户数据，是运动健康应用审批通过的数据和用户授权数据的交集。

![](https://media:901788166637810820 "点击放大")

1. 通过HMS Core SDK登录，并申请Scope权限，用于获取访问Health Service Kit接口的权限。

   <br />

   不同的Scope对应不同的权限， 开发者可以根据自己的业务需要申请对应权限，Scope和权限的对应关系请参见 [权限列表](#ZH-CN_TOPIC_0000002548038787__table19451192131510)。

   ```
   /**
    * 授权登录方法，如果之前没有经过当前账号的授权，会拉起授权界面
    */
   private void signIn() {
       Log.i(TAG, "begin sign in");
       List<Scope> scopeList = new ArrayList<>();

       // 添加需要申请的权限，这里只是举例说明，开发者需要根据实际情况添加所需的权限
       // 包含步数统计、步数详情、距离、热量、运动中高强度
       scopeList.add(new Scope(HiHealthExtendScope.HEALTHKIT_EXTEND_SPORT_READ));

       // 包含性别、出生日期、身高、体重。
       scopeList.add(new Scope(HiHealthExtendScope.HEALTHKIT_EXTEND_HEALTHBEHAVIOR_READ));

       // 包含睡眠得分、睡眠时长等科学睡眠和普通睡眠数据。
       scopeList.add(new Scope(HiHealthAtomicScope.HEALTHKIT_SLEEP_READ));

       // 包含心脏日常统计值和每分钟心率详情值；日常统计值包含心率范围、静息心率（当日平均值）。
       scopeList.add(new Scope(HiHealthAtomicScope.HEALTHKIT_REALTIME_HEARTRATE_READ));
       
       // 设置授权参数
       AccountAuthParamsHelper authParamsHelper = new AccountAuthParamsHelper();
       
       AccountAuthParams authParams = authParamsHelper.setIdToken()
           .setId()
           .setAccessToken()
           .setScopeList(scopeList)
           .createParams();

       // 初始化AccountAuthService对象
       final AccountAuthService authService = AccountAuthManager.getService(this.getApplicationContext(),
           authParams);

       // 静默登录，如果之前已经通过当前账号的授权，调用该接口不会拉起授权界面，为异步方法
       Task<AuthAccount> silentSignInTask = authService.silentSignIn();

       // 增加调用结果的回调
       silentSignInTask.addOnSuccessListener(new OnSuccessListener<AuthAccount>() {
           @Override
           public void onSuccess(AuthAccount authAccount) {
               // 静默登录成功
               Log.i(TAG, "silentSignIn success");
               String openId = authAccount.getOpenId();
               Log.i(TAG, "openid = " + openId);
           }
       }).addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception exception) {
               // 静默登录失败，说明之前没有通过该账号的授权
               if (exception instanceof ApiException) {
                   ApiException apiException = (ApiException) exception;
                   Log.i(TAG, "sign failed status:" + apiException.getStatusCode());
                   Log.i(TAG, "begin sign in by intent");

                   // 通过getSignInIntent()方式调用登录接口
                   Intent signInIntent = authService.getSignInIntent();

                   // 通过Activity的startActivityForResult()方法拉起授权界面
                   // 开发者可以将这里的HihealthKitMainActivity改为实际使用的Activity
                   HihealthKitMainActivity.this.startActivityForResult(signInIntent, REQUEST_SIGN_IN_LOGIN);
               }
           }
       });
   }
   ```

   这里使用的常量如下：

   ```
   // 通过startActivityForResult方式拉起授权界面的请求码，具体数值开发者可以自行定义
   private static final int REQUEST_SIGN_IN_LOGIN = 1002;
   private static final String TAG = "HihealthKitMainActivity";
   ```

2. 覆写onActivityResult方法，处理授权登录结果响应。

   <br />

   ```
   @Override
   protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
       super.onActivityResult(requestCode, resultCode, data);

       // 处理登录响应
       handleSignInResult(requestCode, data);
   }

   /**
    * 授权结果响应处理方法
    * 
    * @param requestCode 拉起授权界面的请求码 
    * @param data 授权结果响应
    */
   private void handleSignInResult(int requestCode, Intent data) {
       // 只处理授权的响应
       if (requestCode != REQUEST_SIGN_IN_LOGIN) {
           return;
       }

       // 从intent中获取授权响应
       Task<AuthAccount> authAccountTask = AccountAuthManager.parseAuthResultFromIntent(data);
       if (authAccountTask.isSuccessful()) {
           Log.i(TAG, "sign in is success");
       }
   }
   ```

   <br />

<!-- -->

3. 授权登录方法可以在App主Activity的onCreate方法中调用，每次启动App时调用一次，刷新授权信息。

   <br />

   ```
   @Override
   protected void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);

       // 每次启动时调用一下授权登录接口
       signIn();
   }
   ```

#### 跳转到用户已授权的权限页面

通过Scheme协议，可以跳转到运动健康App"我的 \> 隐私管理 \> 数据分享与授权 \> 账号授权应用"中指定应用的授权列表。在对应授权应用的页面中，用户可以查看该应用已授权的权限，并且可以选择取消部分或取消所有的权限。

使用方式：

Scheme跳转链接为："huaweischeme://healthapp/oauth/thirdPartyAccountAuth?app_id=XXX"

其中app_id为指定应用的AppID。

图1：以跳转APPID为012345678的应用为例

![](https://media:901788166637838822)

<br />

示例代码：

```
Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse("huaweischeme://healthapp/oauth/thirdPartyAccountAuth?app_id=012345678"));
startActivity(intent);
```
