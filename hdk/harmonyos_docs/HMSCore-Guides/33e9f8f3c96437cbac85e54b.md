# 上线验收

#### 前提条件

已经提交创建服务的申请并通过运营审批，在服务创建列表中对应的卡劵状态为商用，且已在会员中心福利或权益测试上线，如下图：

如未审批通过，请耐心等待1-2工作日。  

#### 验收步骤

1. 登录手机上会员中心App，通过活动、福利或者权益找到对应的运营内容，点击查看详情，观察是否正常。

2. 验证劵码是否正常使用，开发者可以对劵码的code进行核销，观察是否能够正常核销。
