# 离线用户消息缓存时间

当用户设备没有连接网络，暂时无法接收到消息。您可以通过推送服务端API提供的[ttl](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1531816810239)字段来控制消息在Push服务器中进行缓存，缓存时间内若用户设备重新连接网络，被缓存的消息会下发，超过缓存时间后消息会丢弃。

消息体示例：

```
{
    "validate_only": false,
    "message": {
        "notification": {
            "title": "message title ",
            "body": "message body"
        },
        "android": {
            "notification": {
                "click_action": {
                    "type": 2,
                    "url": "https://example.com"
                }
            },
            "ttl": "1000"
        },
        "token": [
            "pushtoken1"
        ]
    }
}
```
