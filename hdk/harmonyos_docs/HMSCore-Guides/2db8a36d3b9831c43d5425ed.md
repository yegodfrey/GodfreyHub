# 开发准备

#### 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。  

#### 创建项目

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)完成项目的创建。  

#### 创建应用

参见[在项目下创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717#section1112105771619)完成应用的创建，配置如下：

* 选择平台：选择"Web"。
* 应用名称：填写新创建的应用名称。

#### 打开定位服务开关

使用[网络定位（API）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-network-location-develop-steps-0000001122001226)和[IP定位（API）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-ip-location-develop-steps-0000001226969155)服务，需要您打开定位服务开关，下面提供两种方式开通服务：

在开发者联盟打开服务开关

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)后，点击并进入右上角的"[管理中心](https://developer.huawei.com/consumer/cn/console)"。
2. 点击左侧菜单栏"我的API"，选择您要开通服务的项目，再点击"申请新的HMS API服务"，进入HMS API库的详情页面。
3. 在HMS API库的详情页面，选择"App Services \> 定位服务"，进入定位服务的页面。点击"启用"开关，启用定位服务。
4. 启用成功之后，在"HMS API服务 \> 我的API"中可以看到当前项目下的已启用的API服务列表。

在AppGallery Connect打开服务开关

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"，选择您要开通定位服务的项目。
2. 在项目设置菜单内，打开"API管理"页面，在"构建"区域内找到并打开定位服务开关。  

#### 获取API key

在调用REST接口时请求体需要传入业务签名参数使用到API key，在服务使用前，获取API key的步骤如下：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在导航栏中找到"常规"页签。
