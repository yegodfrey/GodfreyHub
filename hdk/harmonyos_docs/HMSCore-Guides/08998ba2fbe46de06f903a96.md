# 蓝牙模块功能测试

1. 从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/sport-device-sdk-0000001051809026)的开发套件中获取测试工具 fitnesstool-tool.apk，并安装在手机上。
2. 从开发套件中获取 FitnessTool 使用指南，根据使用指南指导，连接运动设备。
3. 从开发套件中获取运动设备的蓝牙协议测试用例。按照 FitnessTool 使用指南和测试用例进行测试， 确保所有的用例正常测试通过。

   * 测试设备的基本参数：基本参数的范围主要包括蓝牙广播信息、设备信息、设备的能力等在单台设备生命周期内不会变化的参数信息。
   * 测试设备的状态及控制：包括在设备上启动、暂停、恢复、停止运动时的状态是否实时通知到手机App；设备的工作状态是否能正确获取；控制设备的状态、速度、坡度等接口功能是否正常。
   * 测试设备的实时运动数据：此部分主要测试实时的运动数据是否能正确的上报到手机App，上报时间间隔是否正常。
   * 测试华为扩展的功能：此部分主要测试将手机的心率、计步、卡路里参数实时送到运动设备，能在运动设备上实时显示。
