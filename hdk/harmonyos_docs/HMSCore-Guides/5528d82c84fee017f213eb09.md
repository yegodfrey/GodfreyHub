# 获取OAID信息（SDK方式）

## 使用场景

媒体App、广告平台、三方监测平台等开发者，可集成鲸鸿动能SDK获取华为设备上的OAID，您可基于OAID进行个性化广告推荐或广告转化归因分析。

## 注意事项

* 获取OAID信息前，确保App必须已经集成最新版本的ads-identifier SDK，否则会导致应用在部分手机无法获取正确的OAID，请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-integrating-sdk-0000001056460552)和[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-version-change-history-0000001050066927)。
* 调用getAdvertisingIdInfo接口，获取OAID信息，不要在主线程中调用该方法。
* 您不可以缓存使用OAID信息，以保护用户个人数据的隐私安全。
* OAID的获取受应用的跟踪开关影响：当应用的跟踪开关开启时，该应用可获取到OAID；当应用的跟踪开关关闭时，该应用仅能获取全0的OAID。
* 获取OAID信息前，请确保已充分告知用户相关信息并取得用户授权同意。请务必先弹出隐私协议窗口，获得用户的明确同意后再获取OAID。未经用户同意，获取 OAID 将涉嫌违反数据采集相关规定，可能会面临隐私合规风险。

## 开发步骤

创建子线程，并调用静态的[AdvertisingIdClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/advertisingidclient-0000001050066889).[getAdvertisingIdInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/advertisingidclient-0000001050066889#section15201793187)(mContext)方法获取OAID信息，示例代码如下所示：

```java
private static final String TAG = "OaidActivity";
...
/**
 * 在子线程获取OAID信息
 */
private Thread getIdentifierThread = new Thread() {
    @Override
    public void run() {
        try {
            AdvertisingIdClient.Info info = AdvertisingIdClient.getAdvertisingIdInfo(getApplicationContext());
            if (null != info) {
                Log.i(TAG, "getAdvertisingIdInfo id=" + info.getId() +
                        ", isLimitAdTrackingEnabled=" + info.isLimitAdTrackingEnabled());
            }
        } catch (IOException e) {
            Log.i(TAG, "getAdvertisingIdInfo Exception: " + e.toString());
        }
    }
};
```
