# 室外高精度开发

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103218.25324209988850999309220770048196:50001231000000:2800:8F9DB200155B0AF573F6447D2232C8868899F3EA8E84CDF8D1B2938BCDDA2733.png?needInitFileName=true?needInitFileName=true)  
1. 使用室外高精度能力的开发者需要遵守国家法律法规与华为公司共同向国家有关部门申请高精度偏转插件的使用许可。
2. 室外高精度能力当前仅支持中国大陆地区的部分城市：深圳市、广州市、苏州市、杭州市、重庆市、成都市、天津市、东莞市（持续增加中），海外暂不支持。  

#### 概述

如果您的应用需要请求更高精度的（亚米级的）位置信息，首先您需要为应用申请位置权限，然后调用请求位置更新方法（[requestLocationUpdatesEx](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/fusedlocationproviderclient-0000001050746169#section91051750194015)），设置（[LocationRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationrequest-0000001050986189)）请求，详见[获取室外高精度位置信息](#section118251927173810)，根据您的需要指定定位方式，获取持续的位置信息回调。如果您获取位置信息后，想取消位置信息回调，可以调用移除位置更新方法（[removeLocationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/fusedlocationproviderclient-0000001050746169#section14923192365816)），达到取消回调的目的。  

#### 约束条件

为了您的应用能够更好地体验室外高精度服务，需要满足以下条件：

* 目前支持城市如下：深圳市、广州市、苏州市、杭州市、重庆市、成都市、天津市、东莞市。
* 室外高精度服务支持设备：Mate X2、Mate 40、Mate 40E、Mate 40 Pro、Mate 40 Pro+、P50 Pro（麒麟9000版本）、P40、P40 Pro、P40 Pro+、Nova8 Pro、荣耀30 Pro、荣耀30 Pro+【海外版本不支持】 。  
  ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103218.95131240651098954503367329356427:50001231000000:2800:0FC157645288598F8724F0598310AABE6809F8BF6D0F18D91E542918D23ECB2D.png?needInitFileName=true?needInitFileName=true)  
  如上设备仅在手机版本为中国大陆版本时，支持室外高精度服务。
* 接入室外高精度服务需要您在AGC网站上注册，可以参见[Demo集成文档](https://developer.huawei.com/consumer/cn/codelab/HMSLocationKit/index.html#0)。
* 室外高精度服务需要设备登录华为帐号。
* 免费配额（每位开发者100,000次/月），超额请通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)申请配额，具体定价请参见[服务定价说明](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing-0000001058092595 )。

#### 指定应用权限

1. Android提供了两种位置权限： ACCESS_COARSE_LOCATION（粗略的位置权限）和ACCESS_FINE_LOCATION（精确的位置权限）。需要在"AndroidManifest.xml"文件中申请权限：

   ```
   <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
   ```

2. （可选）在Android 10及以上版本中，如果您需要应用程序在后台执行时也具备持续定位能力，还需要在"AndroidManifest.xml"文件中申请ACCESS_BACKGROUND_LOCATION权限：

   ```
   <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION"/>
   ```

#### 创建定位服务客户端

在您的项目中使用到定位服务的Activity中的onCreate()方法中创建一个[FusedLocationProviderClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/fusedlocationproviderclient-0000001050746169)实例，通过该实例调用定位相关接口。

```
"Java"
// 定位交互接入对象
private FusedLocationProviderClient fusedLocationProviderClient; 
protected void onCreate(Bundle savedInstanceState) {   
    super.onCreate(savedInstanceState);
    fusedLocationProviderClient = LocationServices.getFusedLocationProviderClient(this); 
}
```

```
"Kotlin"
// 定位交互接入对象
private lateinit var fusedLocationProviderClient: FusedLocationProviderClient 
override fun onCreate(savedInstanceState: Bundle?) {   
    super.onCreate(savedInstanceState)
    fusedLocationProviderClient = LocationServices.getFusedLocationProviderClient(this) 
}
```

#### 获取室外高精度位置信息

您可以通过[requestLocationUpdatesEx](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/fusedlocationproviderclient-0000001050746169#section91051750194015)接口向HMS Core（APK）请求室外高精度位置，位置回调的结果是在[LocationCallback](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationcallback-0000001050706140)的[onLocationResult](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationcallback-0000001050706140#section18517246182511)()中。如果您想获取详细的位置信息对象，您可以在位置回调结果监听方法中通过locationResult.[getLocations](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationresult-0000001051066114#section0637438308)()或locationResult.[getHWLocationList](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationresult-0000001051066114#section127601552115214)()获得到Location或者[HWLocation](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hwlocation-0000001051066112)列表。

1. 设置室外高精度请求参数。  
   构建[LocationRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationrequest-0000001050986189)请求，仅当字段"priority"设置为"[LocationRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationrequest-0000001050986189).[PRIORITY_HD_ACCURACY](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/constant-values-0000001050746179#ZH-CN_TOPIC_0000001050746179__p1440015504817)"时才能发起室外高精度请求。

   ```
   "Java"
   LocationRequest mLocationRequest = new LocationRequest();
   // 设置位置更新的间隔（单位：毫秒）
   mLocationRequest.setInterval(10000);
   // 设置室外高精度类型
   mLocationRequest.setPriority(LocationRequest.PRIORITY_HD_ACCURACY);
   ```

   ```
   "Kotlin"
   val mLocationRequest = LocationRequest()
   // 设置位置更新的间隔（单位：毫秒）
   mLocationRequest.interval = 10000
   // 设置室外高精度类型
   mLocationRequest.priority = LocationRequest.PRIORITY_HD_ACCURACY
   ```

2. 定义位置更新回调。  

   ```
   "Java"
   LocationCallback mLocationCallback;        
   mLocationCallback = new LocationCallback() {        
       @Override        
       public void onLocationResult(LocationResult locationResult) {        
           if (locationResult != null) {        
               // 获取位置信息
               List<Location> locations = locationResult.getLocations();
               for (Location location : locations) {
                   // TODO：回调结果的处理
               }
           }        
       }        
   };
   ```

   ```
   "Kotlin"
   val mLocationCallback: LocationCallback
   mLocationCallback = object : LocationCallback() {
       override fun onLocationResult(locationResult: LocationResult) {
           if (locationResult != null) {
               // 获取位置信息
               val locations =
                   locationResult.locations
               for (location in locations) {
                   // TODO：回调结果的处理
               }
           }
       }
   }
   ```

3. 调用[requestLocationUpdatesEx](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/fusedlocationproviderclient-0000001050746169#section91051750194015)()进行室外高精度。  

   ```
   "Java"
   fusedLocationProviderClient        
       .requestLocationUpdatesEx(mLocationRequest, mLocationCallback, Looper.getMainLooper())        
       .addOnSuccessListener(new OnSuccessListener<Void>() {        
           @Override        
           public void onSuccess(Void aVoid) {        
               // 接口调用成功的处理        
           }        
       })
       .addOnFailureListener(new OnFailureListener() {        
           @Override        
           public void onFailure(Exception e) {        
              // 接口调用失败的处理        
           }        
       });
   ```

   ```
   "Kotlin"

       .requestLocationUpdatesEx(mLocationRequest, mLocationCallback, Looper.getMainLooper())
       .addOnSuccessListener(OnSuccessListener<Void?> {
           // 接口调用成功的处理
       })
       .addOnFailureListener(OnFailureListener {
           // 接口调用失败的处理
       })
   ```
