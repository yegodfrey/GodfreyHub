# 删除数据

对于应用自己写入的血压、血糖、体重数据，应用可以进行删除，其他数据不可以删除。
> 说明
>
> 针对同时支持写入和删除的数据类型，获取存储数据权限时，同时获得了删除数据权限。

## 删除单个时间段内的数据

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [deleteSample](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__deleteSample-android_content_Context-com_huawei_hihealthkit_data_HiHealthData-com_huawei_hihealth_listener_ResultCallback-) 方法，删除单个时间段内的数据。
2. 通过请求参数 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451) 对象，返回查询结果。

   **示例代码**

   ```screen
   Map map = new HashMap();
   final long endTime = System.currentTimeMillis();
   final long startTime = endTime - 1000L * 60 * 60 * 24;
   // 刪除24小时内的体重数据
   HiHealthSetData hiHealthSetData =
       new HiHealthSetData(HiHealthSetType.DATA_SET_WEIGHT_EX, map, startTime, endTime);
   HiHealthDataStore.deleteSample(context, hiHealthSetData, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object data) {
           Log.i(TAG, "delete sample of the latest 24h onResult: " + resultCode);
           if (resultCode == HiHealthError.SUCCESS) {
               // 删除数据成功
               Log.w(TAG, "Delete success");
           } else if (resultCode == HiHealthError.PARAM_INVALID) {
               // 参数错误
               Log.w(TAG, "Param invalid");
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
               // 授权失效
               Log.w(TAG, "Permission denied");
           } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
               // 未同意运动健康隐私协议
               Log.w(TAG, "Privacy user denied");
           } else if (resultCode == HiHealthError.ERR_NETWORK) {
               // 网络异常
               Log.w(TAG, "Network request failed");
           } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
               // 测试权限的用户数量超过限制
               Log.w(TAG, "Beta scope permission denied");
           } else {
               // 其他错误，建议提示调用失败
               Log.w(TAG, "Other error, invoking method failed");
           }
       }
   });
   ```

   |参数名称|参数类型|参数描述|可选选项|
   |:--------------|:--------------|:----------------------|:----|
   |hiHealthSetData|HiHealthSetData|需要删除的HiHealthSetData 数据|必选(M)|
   |callback|ResultCallback|结果回调|必选(M)|
   [**表1**请求参数]

   |参数名称|参数类型|参数描述|可选选项|
   |:---------|:-----|:------------------------------------------------------------------------------------------------------------------------|:----|
   |resultCode|int|处理结果码 * 0：成功 * 其他：参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-errocode-0000001053256958)|必选(M)|
   |object|Object|处理结果描述 成功：List<Object> 失败：Object|必选(M)|
   [**表2**响应参数]

## 删除多个时间段内的数据

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [deleteSamples](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__deleteSamples-android_content_Context-java_util_List-com_huawei_hihealth_listener_ResultCallback-) 方法，删除多个时间段内的数据（不超过20个），需为同一类型数据。
2. 通过请求参数 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451) 对象，返回查询结果。

   示例代码：

   ```screen
   Map map = new HashMap();
   long oneDayInMillis = 1000L * 60 * 60 * 24;
   long endTime = System.currentTimeMillis();
   long startTime = endTime - oneDayInMillis;
   long secondEndTime = startTime - oneDayInMillis * 3;
   long secondStartTime = secondEndTime - oneDayInMillis;
   // 同时删除两个时间段内的体重数据
   HiHealthSetData hiHealthSetData =
       new HiHealthSetData(HiHealthSetType.DATA_SET_WEIGHT_EX, map, startTime, endTime);
   HiHealthSetData secondHiHealthSetData =
       new HiHealthSetData(HiHealthSetType.DATA_SET_WEIGHT_EX, map, secondStartTime, secondEndTime);
   List<HiHealthSetData> hiHealthSetDatas = new ArrayList<>();
   hiHealthSetDatas.add(hiHealthSetData);
   hiHealthSetDatas.add(secondHiHealthSetData);
   HiHealthDataStore.deleteSamples(context, hiHealthSetDatas, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object object) {
           Log.i(TAG, "delete samples onResult: " + resultCode);
           if (resultCode == HiHealthError.SUCCESS) {
               // 删除数据成功
               Log.w(TAG, "Delete success");
           } else if (resultCode == HiHealthError.PARAM_INVALID) {
               // 参数错误
               Log.w(TAG, "Param invalid");
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
               // 授权失效
               Log.w(TAG, "Permission denied");
           } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
               // 未同意运动健康隐私协议
               Log.w(TAG, "Privacy user denied");
           } else if (resultCode == HiHealthError.ERR_NETWORK) {
               // 网络异常
               Log.w(TAG, "Network request failed");
           } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
               // 测试权限的用户数量超过限制
               Log.w(TAG, "Beta scope permission denied");
           } else {
               // 其他错误，建议提示调用失败
               Log.w(TAG, "Other error, invoking method failed");
           }
       }
   });
   ```

   |参数名称|参数类型|参数描述|可选选项|
   |:---------------|:-----------------|:---------------|:----|
   |hiHealthDataList|List<HiHealthData>|HiHealthData数据集合|必选(M)|
   |callback|ResultCallback|结果回调|必选(M)|
   [**表3**请求参数]

   |参数名称|参数类型|参数描述|可选选项|

   |resultCode|int|处理结果码 * 0：成功 * 其他：参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-errocode-0000001053256958)|必选(M)|
