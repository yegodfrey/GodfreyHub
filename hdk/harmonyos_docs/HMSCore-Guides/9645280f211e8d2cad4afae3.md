# 异步方式

## 业务流程

使用MultiProcessor Mode异步方式的主要业务流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/65/v3/KBoDaA1JRlurNa9FJlD6lA/zh-cn_image_0000001579359264.png?HW-CC-KV=V1&HW-CC-Date=20260909T154521Z&HW-CC-Expire=31536000000&HW-CC-Sign=60AE3835235FC3C6F9A696E5BC38C72C7F900D145C534227075B2424B697CCE8 "点击放大")

1. 用户打开App发起扫码请求。
2. 校验是否有相机权限和文件读取权限。
3. 权限验证通过后，初始化[HmsScanAnalyzer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer4-0000001050167905)。
4. 将图像信息转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)。
5. 调用[HmsScanAnalyzer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer4-0000001050167905)的[analyzInAsyn](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer4-0000001050167905#section6366456334)异步扫码接口。
6. 华为统一扫码SDK回调应用的"onSuccess"或"onFailure"接口传递扫码结果。
7. App封装扫码结果返回给用户。

## 开发步骤

1. （可选）初始化[HmsScanAnalyzerOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options4-0000001050167925)对象，并设置支持识别的码制式。

   您可以通过如下方式设置可选参数。当您不需要定制如下参数时，您可以跳过此步骤。

   [setHmsScanTypes](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer-options-creator4-0000001050165974#section129951849205918)()：设置码制式，默认识别[Scan Kit支持的码制式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/barcode-formats-supported-0000001050043981)，指定扫描特定的码制式，可以提高扫码速度。

   ```java
   "Java"
   // "QRCODE_SCAN_TYPE"和"DATAMATRIX_SCAN_TYPE"表示只扫描QR和DataMatrix的码
   HmsScanAnalyzerOptions options = new HmsScanAnalyzerOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE,HmsScan.DATAMATRIX_SCAN_TYPE).create();
   ```

   ```kotlin
   "Kotlin"
   // "QRCODE_SCAN_TYPE"和"DATAMATRIX_SCAN_TYPE"表示只扫描QR和DataMatrix的码
   val options = HmsScanAnalyzerOptions.Creator().setHmsScanTypes(HmsScan.QRCODE_SCAN_TYPE,HmsScan.DATAMATRIX_SCAN_TYPE).create()
   ```

2. 初始化[HmsScanAnalyzer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer4-0000001050167905)对象。如果您没有指定只扫描特定的码制式，此处的"options"可以置"null"。

   ```java
   "Java"
   HmsScanAnalyzer barcodeDetector = new HmsScanAnalyzer(options);
   ```

   ```kotlin
   "Kotlin"
   val barcodeDetector = HmsScanAnalyzer(options)
   ```

3. 将图像信息转换为[MLFrame](https://developer.huawei.com/consumer/cn/doc/hiai-References/mlframe-0000001050167430)，它是ML Kit封装的图像信息类。

   ```java
   "Java"
   MLFrame image = MLFrame.fromBitmap(bitmap);
   ```

   ```kotlin
   "Kotlin"
   val image = MLFrame.fromBitmap(bitmap)
   ```

4. 调用[HmsScanAnalyzer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer4-0000001050167905)对象的[analyzInAsyn](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-analyzer4-0000001050167905#section6366456334)扫码方法发起扫码请求，同时订阅扫码结果事件来接收扫码结果。扫码结果为[HmsScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-hms-scan4-0000001050167739)数据结构，[HmsScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-hms-scan4-0000001050167739)数据结构的信息请参见[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-parsing-result-codes-0000001050043969)。

   ```java
   "Java"
   barcodeDetector.analyzInAsyn(image).addOnSuccessListener(new OnSuccessListener<List<HmsScan>>() {
       @Override
       public void onSuccess(List<HmsScan> hmsScans) {
           if (hmsScans != null && hmsScans.size() > 0) {
               // 展示扫码结果
               ...
           }
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           String TAG = "AsyncError";
           Log.w(TAG, e);
       }
   });
   ```

   ```kotlin
   "Kotlin"
   barcodeDetector.analyzInAsyn(image).addOnSuccessListener(OnSuccessListener {  
           if (hmsScans != null && it.size > 0) { 
               // 展示扫码结果
               ...
           } 
        
   }).addOnFailureListener(OnFailureListener { 
        val TAG = "asyncError"
        Log.w(TAG, it)
       
   })
   ```
