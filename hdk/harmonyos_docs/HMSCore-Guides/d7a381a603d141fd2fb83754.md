# 已取消或者退费购买查询

当您想查看近期非消耗型商品的退费情况、消耗型商品在已购买尚未消耗场景下的退费情况以及订阅型商品的取消和退费情况，您可以调用华为应用内支付服务器提供的已取消或者退费购买查询接口进行查询，查询的时间范围为最近一个月内。

具体实现请参见[已取消或者退费购买查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-cancel-or-refund-record-0000001050746117)。

为避免批量查询的性能问题，并且https服务本身安全性高，因此返回的购买信息不包含签名信息。
