# 业务简介

地图服务以HTTP/HTTPS形式为第三方开发者提供了API，您可以通过这些接口使用地图数据服务，用于开发、静态图、栅格图等相关功能。在API被调用时，相关数据通过JSON格式返回。

地图服务提供2种认证方式，推荐使用AT认证：

* AT认证，您可以[基于OAuth 2.0获取应用级AT](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section155891726174616)，AT有效期是1个小时
* API KEY认证

## Maps Static API

Maps Static API服务通过HTTP请求发送的URL参数创建地图，并将地图作为可以在网页上显示的图像返回。

本服务具有支持您自定义生成指定区域、附加指定信息的单一成品渲染图的能力。接口返回一张实时渲染的图片，您可以指定请求的地图位置、图片大小、以及在地图上添加覆盖物，如标签、折线、多边形。

## Tile API

Tile API服务通过HTTP请求发送的URL参数允许您直接访问华为地图瓦片数据。通过请求独立的地图瓦片，构建一个地图图层，使得地图可以方便地加载到已有的地图平台中。例如在PC端将瓦片加载到QGIS、Arcgis上；在移动应用中以tile overlay形式加载到已有的地图上。

## Tile Service API

Tile Service提供自定义图层服务，包括数据管理API和图层管理API，提供数据编译、创建图层、自定义图层样式、发布图层等能力，帮助您自由定制地图渲染效果，满足您更多地图场景需求，如火灾图、月球图、温度图等。

## Elevation API

Elevation API服务以HTTPS形式提供一个海拔数据查询接口，查询经纬度对应的海拔信息。本服务支持通过传入指定位置或路径两种方式计算海拔高度，这两种方式均采用经纬度坐标来标识位置点或路径顶点。若在您请求的位置没有精确的高程测量值的情况下，服务会返回离该位置最近的数据记录点的海拔。

## 场景介绍

|场景分类|场景说明|
|:---------------|:----------------------------------------------------------|
|Maps Static API|通过HTTP请求发送的URL参数创建地图图片并直接嵌入到网页中，而无需通过JavaScript或动态页面加载。|
|Tile API|* 在PC端将瓦片加载到QGIS、Arcgis上。 * 在移动应用中以tile overlay形式加载到已有的地图上。|
|Tile Service API|提供自定义图层服务，如火灾图、月球图、温度图。|
|Elevation API|使用Elevation API，您可以开发徒步和骑行应用程序、移动定位应用程序或低分辨率测量应用程序。|

## 功能使用限制

|功能|地域要求|说明|
|:-----------|:------|:------------------------|
|地图加载等涉及数据的功能|不支持中国大陆|无中国大陆数据，例如地图加载、路径规划等|
|不涉及数据的功能|无|不涉及数据的功能，例如添加标记，多边形等都可以使用|
