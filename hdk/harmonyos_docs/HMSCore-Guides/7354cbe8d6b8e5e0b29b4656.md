# 场景概述

|场景|支持的设备|是否需要服务器|遵循的协议|可获取的用户信息|安全性与用户体验|
|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------|:------|:-------------|:-----------------------------|:------------------------------------------------------------------------------------|
|[移动与智慧屏应用快速接入华为帐号](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-scenario-without-identity-verification-0000001162758383)|手机、平板、华为智慧屏、车机|不需要|无|昵称、头像、Email、UnionID、OpenID|1. 应用无法对用户身份进行验证，不能保证用户信息的真实性。 2. 首次登录时，要求用户同意授权，无身份验证信息，不存在验证信息过期问题。|
|[移动与智慧屏应用ID Token模式接入华为帐号（OpenID Connect）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-scenario-id-token-0000001116078504)|手机、平板、华为智慧屏、车机|可选|OpenID Connect|昵称、头像、Email、UnionID、Email是否已验证|1. 可对用户身份进行验证，保证用户信息的真实性。 2. 首次登录时，要求用户同意授权，当身份验证信息到期时，用户每次登录时都应同意授权。|
|[移动与智慧屏应用Authorization Code模式接入华为帐号 (OAuth 2.0)](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-scenario-auth-code-0000001115918596)|手机、平板、华为智慧屏、车机|需要|OAuth 2.0|昵称、头像、Email、OpenID|1. 可对用户身份进行验证，保证用户信息的真实性。 2. 首次登录时，要求用户同意授权，当身份验证信息到期时，只需要从服务器端通过刷新令牌刷新访问令牌，无需用户再次授权。|
