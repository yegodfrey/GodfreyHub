# 如何按华为分析的行业埋点上报事件  
  
华为分析提供了丰富的行业报告，应用按照华为分析提供的预置事件上报数据后，可以在行业分析中查看报告。在不修改代码的情况下，如何上报华为分析的行业埋点？使用埋点开发中的埋点事件映射功能，可以很方便的将已有的埋点转换成华为分析的行业埋点。

#### 开发准备

      * 集成分析服务SDK。Android集成详情请参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876)，iOS集成详情请参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-integrating-sdk-0000001050168479)。
      * 集成动态标签管理服务SDK。Android集成详情请参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-sdk-0000001050041968)，iOS集成详情请参考[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-sdk-0000001061753701)。

#### 配置埋点事件映射

配置埋点事件映射，操作详情请参见[埋点事件映射](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280#section2123141351115)。
