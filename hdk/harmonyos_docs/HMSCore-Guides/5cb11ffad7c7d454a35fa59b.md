# 提交测试报告进行准入认证

1. 登录华为开发者联盟，在"智慧生活"下点击"运动健康（设备接入）"，查看素材资源审核结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/WSfaRTI5RMioQb4Y2bfoHw/zh-cn_image_0000002547959169.png?HW-CC-KV=V1&HW-CC-Date=20261008T175414Z&HW-CC-Expire=31536000000&HW-CC-Sign=43FC9F736DB854FBCFA3ABEDCD024F159CDBFC11EF7260F195CB78C8B145F194 "点击放大")

2. 若素材资源审核通过，点击"产品认证"进入认证报告提交界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/GtxUibM5RgyNeswYyCC5yg/zh-cn_image_0000002516519282.png?HW-CC-KV=V1&HW-CC-Date=20261008T175414Z&HW-CC-Expire=31536000000&HW-CC-Sign=9097609CFC5E33D1E590AE20370F7EA56BD9EE543303F99598DD6565A788DDC3 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0/v3/6O85dK4zSzWadKGOn5P7BQ/zh-cn_image_0000002516359366.png?HW-CC-KV=V1&HW-CC-Date=20261008T175414Z&HW-CC-Expire=31536000000&HW-CC-Sign=F110A7D8447F88A6F5A7A6F74372FC35B9D2FA67708EB8D59A37127E9103F01C "点击放大")

3. 根据界面提示，上传设备实物拍照图（正面、侧面、底部）、自测试报告、样机快递单号。

   > 说明
   >
   > 自测试报告需要提供送测设备的基本信息，如：产品型号、产品版本、芯海SDK版本、蓝牙芯片、称重芯片、测脂芯片、产品固件版本、产品硬件版本等。具体可以参考华为提供的测试报告模板。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/5kewS5trRKe5gIhhwHXj0Q/zh-cn_image_0000002516519284.png?HW-CC-KV=V1&HW-CC-Date=20261008T175414Z&HW-CC-Expire=31536000000&HW-CC-Sign=1F97CD7EB53FBB0C52B9E1D2F15DBB25271FDD1B8569F3C45AB635D6C1CB5E6C "点击放大")

   样机需求如下表，点击"样机寄送地址"旁边的提示符![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/pXXpFe6nTROoRFCA22f-hQ/zh-cn_image_0000002516359362.png?HW-CC-KV=V1&HW-CC-Date=20261008T175414Z&HW-CC-Expire=31536000000&HW-CC-Sign=52241DE7F70D6A00ACEAC4DBF27A0225141EF8C233C0FB749CECD6ECADCBCA91)，可以获取投递地址及收件人。

   |样机用途|数量|
   |:--------------------------|:-|
   |小件设备，如：跳绳、体脂秤、血糖仪、血压计、心率设备|2|
   |大件设备，如：跑步机、椭圆机、划船机、智能单车、走步机|1|

   对于跑步机接入，需要提交第三方认证机构进行准入认证。在界面上选择认证机构后（赛西实验室或泰尔实验室），会显示认证机构的联系方式及报价单，可与对应机构联系人进行业务对接。请厂商根据实际需要选定认证机构。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/dRbDy7DSTu67Qh5HlgaW0w/zh-cn_image_0000002548039161.png?HW-CC-KV=V1&HW-CC-Date=20261008T175414Z&HW-CC-Expire=31536000000&HW-CC-Sign=E39D97433F087474A283BC7C9C706A8A6BC23AF7B43B21C3BF735E2894692837 "点击放大")

4. 提交审核后，等待认证结果。点击图示红框图标可查看审核进度和结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/5U41PIDFQxCcQfKwdByGLg/zh-cn_image_0000002547959163.png?HW-CC-KV=V1&HW-CC-Date=20261008T175414Z&HW-CC-Expire=31536000000&HW-CC-Sign=1329A350962FB57980D371A36E047175A71912A072C476D7AED08DB507CDF507 "点击放大")
