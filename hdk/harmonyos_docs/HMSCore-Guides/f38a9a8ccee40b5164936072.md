# 意图数据共享

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230824165402.75641423472785510861191877492483:50001231000000:2800:DBBD1BDE96E9587E1BA25C5320FF5814577F66E20CDA04EE460FD41604D220E6.png?needInitFileName=true?needInitFileName=true)  
集成意图数据共享之前，请[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)联系华为支撑人员。  

#### 导入接口类

使用意图数据共享能力，除需要导入情景感知服务的公共能力类外，还需要导入意图数据共享相关的类。

```
import com.huawei.hms.kit.awareness.Awareness;
// 导入意图数据共享相关的类
import com.huawei.hms.kit.awareness.DonateClient;
import com.huawei.hms.kit.awareness.donate.message.InsightIntent;
```

#### 能力开发

1. 获取Awareness Kit的"DonateClient"。

   ```
   import com.huawei.hms.kit.awareness.DonateClient;
   ```

2. 通过"DonateClient"调用数据共享接口进行数据共享。
3. 根据情景感知服务返回的结果，进行应用的业务处理。  

   ```
   "Java" 
     try {
               InsightIntent browseNewIntent = new InsightIntent("PurchaseStoreCoupon");
               // 设置意图版本号，初始1.0
               browseNewIntent.setIntentVersion("1.0");
               // 设置共享Intent Identifier，用于标识一次执行行为
               browseNewIntent.setIdentifier("a76026c0577049528b5132b491b24092");
               // 设置Intent的Action信息
               browseNewIntent.setIntentActionInfo(new JSONObject()
                       // 设置Action模式，executed代表执行
                       .put("actionMode", "executed")
                       // 设置执行时间槽位
                       .put("executedTimeSlots", new JSONObject().put("executedStartTime", System.currentTimeMillis())));
               // 设置Intent的Entity信息，按照垂域Intent的Schema定义进行填写
               browseNewIntent.setIntentEntityInfo(new JSONObject()
                       .put("entityId", "0123456789abcdef0123456789abcdef")
                       .put("entityName", "哈哈")
                       .put("title", "深圳一栋大楼起火了")
                       .put("mediaType", "图文")
                       .put("source", "网易新闻")
                       .put("keywords", new String[]{"起火", "深圳"})
                       .put("newsType", "时政")
                       .put("skuId", "455648")
                       .put("skuName", "455648")
                       .put("brandName", "455648")
                       .put("storeName", "455648")
                       .put("availableBeginTime", "454455648")
                       .put("availableEndTime", "454455648")
                       .put("storeLogo", "454455648")
                       .put("skuImage", "http://www.baidu.com"));
               // 设置Intent展示的自定义卡片信息
               browseNewIntent.setCustomFormInfo(new JSONObject()
                       .put("bundleName", "com.huawei.browserfa")
                       .put("moduleName", "news")
                       .put("abilityName", ".XAbility")
                       .put("formName", "aaa")
                       .put("formDimension", new String[]{"2x2", "4x4"}));
               // 设置Intent展示模板卡片时跳转FA信息
               browseNewIntent.setIntentTargetInfo(new JSONObject()
                       .put("faInfo", new JSONObject()
                               .put("bundleName", "com.huawei.browserfa")
                               .put("moduleName", "mycoupon")
                               .put("abilityName", ".XAbility")));
               // 获取DonateClient进行数据共享
               DonateClient awarenessClient = Awareness.getDonateClient(context);
               // 设置DonateClient为同意用户隐私状态
               awarenessClient.setAgreePrivacy(true)
                   .shareIntent(Collections.singletonList(browseNewIntent)) 
                   .addOnSuccessListener(donateResponse -> { 
                        // success 
                   }) 
                   .addOnFailureListener(e -> { 
                       // failure 
                   });
           } catch (JSONException e) {
               e.printStackTrace();
           }
   ```
