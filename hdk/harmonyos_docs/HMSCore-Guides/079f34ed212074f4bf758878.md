# Health Service Kit Android SDK接口调用示例

在完成[获取用户授权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/add-permissions-0000001050069726)和[在运动健康App内开启Health Service Kit](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/managing-fitness-and-health-data-0000001240326527)之后，开发者可以调用Health Service Kit Android SDK接口获取用户的运动数据和健康数据。下图以调用[DataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472).[readTodaySummation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section9463154045415)()接口读取当天步数为例，演示调用Health Service Kit Android SDK接口的步骤。

![](https://media:901788166607015384)  
![](https://media:901788166607049385)  
1. 在调用Health Service Kit SDK接口时，请确保手机处于亮屏状态，否则可能会导致接口调用失败，具体错误参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560#section10673269124)：DISABLE_DATA_OPERATION。
2. 在调用Health Service Kit SDK接口时，请确保您的应用为前台应用或者与前台应用绑定，否则可能会导致接口调用失败，具体错误参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560#section10673269124)：APPLICATION_NOT_FORGROUND。

1. 获取运动健康数据管理的接口[DataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472)。

   <br />

   ```
   // 请注意：
   // 1.此处的this为Activity或Context对象
   // 2.此处的DataController类的对象，请在每次接口调用前初始化，避免相关Activity或Context失效导致的数据读取失败的问题
   // 3.DataController类为管理运动健康数据接口提供类，其中提供了多种接口能力
   DataController dataController = HuaweiHiHealth.getDataController(this); 
   ```

   <br />

2. 调用[DataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472).[readTodaySummation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section9463154045415)()接口。

   <br />

   ```
   // 使用指定的数据类型（步数增量：DT_CONTINUOUS_STEPS_DELTA），调用readTodaySummation接口查询该数据类型的当日统计值。
   // 如果想获取其他的数据类型的当日统计值，请参考readTodaySummation接口调用参数说明。
   Task<SampleSet> todaySummationTask = dataController.readTodaySummation(DataType.DT_CONTINUOUS_STEPS_DELTA);
   ```

   <br />

3. 处理接口调用结果。

   <br />

   ```
   // 调用readTodaySummation接口查询当日步数统计值是异步操作，需要设置成功或失败的Listener，用来监听数据查询成功或失败。
   todaySummationTask.addOnSuccessListener(new OnSuccessListener<SampleSet>() {
       @Override
       public void onSuccess(SampleSet sampleSet) {
           Log.i("TAG", "Success read today summation from HMS core");
           // todo:在这里添加sampleSet的数据展示代码
           Log.i("TAG", "the result sampleSet is:" + sampleSet.toString());
           // todo:在这里调用步骤4的接口与Health Service Kit断开连接
       }
   });
   todaySummationTask.addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           String errorCode = e.getMessage();
           String errorMsg = HiHealthStatusCodes.getStatusCodeMessage(Integer.parseInt(errorCode));
           Log.e("TAG", "errorCode + ": " + errorMsg);
           // 请求返回的错误码处理，请参见HiHealthStatusCodes。
           // todo:在这里调用步骤4的接口与Health Service Kit断开连接
       }
   });
   ```

   <br />

4. 与Health Service Kit断开连接。

   <br />

   ```
   // 为避免功耗等问题，在确保接口调用完成后，请调用以下接口断开与Health Service Kit的连接。
   HuaweiHiHealth.disconnect();
   ```
