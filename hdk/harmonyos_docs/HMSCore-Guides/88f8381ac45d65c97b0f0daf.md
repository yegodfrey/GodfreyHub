# 开发准备

## 集成SDK

针对Android Studio开发环境，华为提供了Maven仓集成方式的SDK包。在开始开发前，开发者需要将华为支付服务SDK集成到开发者的Android Studio开发环境中。

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

### 添加应用的AppGallery Connect配置文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到开发者的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/78/v3/bnBNQhApQ2uHQmbnp97upg/zh-cn_image_0000002480319940.png?HW-CC-KV=V1&HW-CC-Date=20261008T192147Z&HW-CC-Expire=31536000000&HW-CC-Sign=CAE3A7EE885C78FD28BF75B90B51D22FE657BCB1E600AE65DB16B74D7E6834B0 "点击放大")

4. 将"agconnect-services.json"文件拷贝到应用级根目录下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/SOJvze8ITZW_q8yY6ijw7w/zh-cn_image_0000002512199875.png?HW-CC-KV=V1&HW-CC-Date=20261008T192147Z&HW-CC-Expire=31536000000&HW-CC-Sign=1E497CDE5D12B3F68165B5A579E69C44EF1ABBE0000CA05B8F22C3F926B3E382)

### 配置SDK的Maven仓地址

参见[Maven仓库地址配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-maven-repository-0000001970825281#section63821917164110)。

### 添加SDK编译依赖

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

1. 打开应用级"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ae/v3/WCYNM31jQ1a4VFIijk9c1Q/zh-cn_image_0000002512199855.png?HW-CC-KV=V1&HW-CC-Date=20261008T192147Z&HW-CC-Expire=31536000000&HW-CC-Sign=591E40EC76316F81C33A94F9F0239FC0F4DDF44A83ADE1BAEB256FB339A19A58)


2. 在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:paymentservice:6.12.0.300'
   }
   ```

   > 说明
   >
   > SDK版本号索引请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041#section163461949192517)，例如：implementation 'com.huawei.hms:paymentservice:6.12.0.300'。
3. 在完成以上的配置后，点击工具栏中的gradle同步图标，完成"build.gradle"文件的同步，将相关依赖下载到本地。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/ZD5W34Z0RwOJG0ax61LyiA/zh-cn_image_0000002480159974.png?HW-CC-KV=V1&HW-CC-Date=20261008T192147Z&HW-CC-Expire=31536000000&HW-CC-Sign=40D50A79823F6BEDAC128DAD8DB10A971FF96E4FBDC8A55104D9181542615726)
   > 说明
   >
   > 1、如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
   >
   > 2、若开发者的APP有添加Gson依赖且依赖华为支付服务SDK后编译或运行时报Gson三方依赖包冲突，需要使用exclude排除Gson依赖冲突，代码如下：
   >
   > ```screen
   > implementation 'com.huawei.hms:paymentservice:6.12.0.300'{
   >     exclude group: 'com.google.code.gson'
   > }
   > ```
