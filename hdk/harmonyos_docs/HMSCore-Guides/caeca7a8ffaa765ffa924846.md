# 版本更新说明

## 6.5.1.302（2023-10-28）

|----------------------------------------------------------|
|Android版本：com.huawei.hms:site:6.5.1.302 **修改特性** 内部组件升级优化。|

## SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）4.0.3.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
