# 开发准备

## 前置条件

1. 商家有营销系统以及具备开发能力。
2. 商家作为开发者身份，有快应用、元服务AppID。
3. 商家在华为支付完成[商户入网](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-jieruliucheng-0000001251448455)，有商户号，商家券支持普通商户、服务商/特约商户、平台商户使用商家券。

## 开发流程

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[商户入网](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-jieruliucheng-0000001251448455)|在准备开发前，开发者需要在华为支付商户平台入网。商户入网成功后，需要为[商户号绑定AppID](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/binding-appid-to-merc-0000001889931817#section2082462310406)。|
|2|[证书准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/certificate-preparation-0000001596094962#section1557292604420)|商户成功登录商户平台后，须在证书管理中上传商户证书；上传完商户证书后商户方可进行交易；证书必须与商户号相匹配且是有效的。|
|3|[API接入](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-specification-0000001538214720#section10361174218353)|商家券需要接入华为支付服务器接口服务，需要按照华为支付服务器API接入规范联调开发。|
|4|上线自检|API接口对接完毕后，商家提前准备好测试物料，比如券批次、跳转页面等。|

## 典型场景

### 场景1：随机Code+华为平台发放

如果系统对商家券券码无特殊要求，则使用随机券码模式（HWPAY_MODE），华为在代发商家券时，随机生成券码给用户发券，发券成功后会回调通知本次发券所使用的券码。

**管理面交互流程**

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/EY1wbHdmSNus8LHdwV270Q/zh-cn_image_0000002563265269.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=A2C80128F69DC18689C080A3CB2DD7B0CD7082E611E6431A728F4ACC324CB946 "点击放大")

1. 商户系统调华为支付系统[创建商家券批次](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-create-0000001825044808)接口创建批次。
2. 批次创建成功后，华为支付系统返回批次号信息。
3. 如果商户系统没有记录批次信息，需要调用[查询商家券批次详情](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-query-0000001872004157)接口获取批次库存等信息，用于构造修改批次预算接口请求体。
4. 华为支付系统给商户返回批次详情信息。
5. 商户系统调华为支付系统[修改商家券批次预算](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-upbudget-0000001825044812)接口修改批次预算。
6. 华为支付系统返回批次预算修改结果。

**用户面交互流程**

在商户没有券系统记录用户券列表的情况下，交互流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/z1K0YVb6RnGEU4S7xp5glQ/zh-cn_image_0000002532305530.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=3AB1736F124DF5E38D7856DC3BE4DE7B8A2EC58B76C7C424FFF28EBA438C20B1 "点击放大")

1. 用户在负一屏等华为平台领券。
2. 华为平台调华为支付系统接口给用户发券。
3. 华为支付系统通过批次上设置的回调地址给商户服务器发送[发券事件回调通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-callback-distribute-0000001873201553)。
4. 用户在负一屏等华为平台点击"去使用"。
5. 用户点击"去使用"后，引导用户跳转到商户系统使用券。
6. 商户系统调华为支付系统[查询用户优惠券列表](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-query-0000001871884381)查询用户优惠券列表。
7. 华为支付系统返回优惠优惠券列表。
8. 用户在商户系统选择优惠券并下单后，调用[核销优惠券](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-use-0000001825204652)接口核销券，把券状态同步给华为支付系统。
9. 华为支付系统券状态刷新后，把核销结果返回给商户系统。
10. 用户在商户系统上进行退单。
11. 商户系统退单过程中调用华为支付[申请退券](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-refund-0000001871884377)接口退券。
12. 华为支付系统退券处理完后，把退券结果返回给商户系统。

1. 用户在负一屏等华为平台领券。

3. 华为支付系统通过批次上设置的回调地址给商户服务器发送[发券事件回调通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-callback-distribute-0000001873201553)。
4. 商户系统将发出去的券码与自有系统券码做映射。

7. 商户系统在下单成功后，调用[核销优惠券](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-use-0000001825204652)接口核销券，把券状态同步给华为支付系统。
8. 华为支付系统券状态刷新后，把核销结果返回给商户系统。

10. 商户系统退单过程中调用华为支付[申请退券](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-refund-0000001871884377)接口退券。

### 场景2：导入Code+华为平台发放

如果系统中对商家券券码有特殊要求，希望华为平台代发券时使用自有券码，则在创建券批次时选用MERCHANT_UPLOAD模式，并把自有券码通过[上传券预存Code](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-upload-0000001871884373)接口同步到华为商家券系统。华为在代发商家券时，随机选取已上传的券码给用户发券，发券成功后会回调通知本次发放所使用的券码。

2. 批次创建成功后，华为支付系统返回批次号信息。
3. 商户系统调华为支付系统[上传券预存Code](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-upload-0000001871884373)接口上传Code。
4. 华为支付系统返回预存Code结果。
5. 如果商户系统没有记录批次信息，需要调用[查询商家券批次详情](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-query-0000001872004157)接口获取批次库存等信息，用于构造修改批次预算接口请求体。

### 场景3：发放时指定Code+商户平台发放

如果系统对商家券券码有特殊要求，仅希望在华为系统中展示用户在自有应用中领取到的券，则使用商户平台发券 + 指定券码（MERCHANT_API）模式，在调用"发放优惠券"接口时，把券码同步到华为商家券系统。
