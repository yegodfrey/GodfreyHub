# 概览

本章节将向您介绍如何在自己的应用中添加自定义样式的地图。

华为地图提供了[Petal Maps Studio](https://developer.petalmaps.com/console/studio/StyleEditor)云平台，通过更改[Petal Maps Studio](https://developer.petalmaps.com/console/studio/StyleEditor)中的样式选项，您可以自定义地图样式的显示，更改道路、公园、企业和其他兴趣点等功能的可视化显示。另外，您还可以通过[Petal Maps Studio](https://developer.petalmaps.com/console/studio/StyleEditor)新增、修改、删除、发布自定义样式。自定义样式发布后将得到一个唯一ID，在调用接口时指定样式ID，即可渲染出此样式风格。后续在云平台上修改此样式，一旦发布，使用此样式的应用都会自动应用新样式，不需要更新版本。
