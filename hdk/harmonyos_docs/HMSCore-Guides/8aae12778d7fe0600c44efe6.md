# 普通场景化示例

#### 网页可视化埋点

DTM支持iOS应用中网页的普通可视化埋点。

                1. 在AGC侧选择“可视化埋点”页签，进入可视化埋点扫码页面。
                2. 使用手机浏览器扫描二维码，根据提示打开手机网页，手机网页和DTM界面将会同时进入可视化埋点页面。
                3. 在DTM界面的可视化埋点页面右侧有“显示可圈选组件”开关，打开后会以红色框展示出可添加埋点的组件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/9nxFEC-XT2Kpfcl1FZZfDA/zh-cn_image_0000001133998463.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=F696C0C11F369C40190FC24B864C7891DCE93A11DD903D74ED2B5734E42523E0)

                4. （可选）添加页面埋点。该“页面埋点”是针对进入App页面的埋点，只能添加一个。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/TYTlHjNLQuyUCOnx8YwW7g/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=9A111B5542FA71A5BA29E96AB87AAB5DF6EE1C8C0B96A70CEDCA233A95C5992C)

当进入含WebView的App页面时，可以添加页面埋点，其参数只能选择native组件。

                   1. 点击“页面埋点”页签下的“添加埋点”，在弹出的“添加埋点”输入框中填入埋点名称，点击“确定”添加埋点。
                   2. 添加成功后，会在页面右侧的“页面埋点”页签下展示已添加的埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4a/v3/jn9Zw45pQya-64c-0Va5zQ/zh-cn_image_0000001134179553.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=AA6B8548DB4ECD64A6350B15AF092D67DA4B4630159DF0132D3A76CDC45F4F63)

                5. 添加元素埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/gES_mzVPTmid5SBHhXWSAA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=2FB8EC1D61BD1184C8F34CC412EEA4C0F552E1150A33D4D792CF361894510F85)

当进入含WebView的App页面时，若您添加native组件作为元素埋点，只能选择native组件作为参数，不可选择WebView元素；若您添加WebView元素作为元素埋点，只能选择WebView元素作为参数，不可选择native组件。

                   1. 点击可埋点元素，在弹出的“添加埋点”提示框中选择埋点类型，输入“埋点名称”，设置触发条件，点击“确定”添加埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/ABNowb1RQfq3yzMQPaGvqg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=5959E0F116B17653C6180BC78B640ED386C453D4FC1730BEB16C84F93BF10DFD)

WebView埋点可选类型有“当前位置”和“同类元素”。

                      * 当前位置：只对当前位置的元素有效。
                      * 同类元素：即选中元素的某一个就近的父节点内，存在结构、ID或类名一致的元素。适用于列表类的同类元素。例如商品列表等，点击列表中的任何一个同类元素都会触发该埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/sby6BkKoR_-SRFLuHrB8sQ/zh-cn_image_0000001086973766.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=43E8F29F7002B84FD0E7410760D26F12D93D4BD0FEFB90BCF67745F86FB5FB7E)

                   2. 添加成功后，在页面右侧的“元素埋点（可用）”页签下展示出已添加的埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/WFqwPklsRieamtNZsZoUKQ/zh-cn_image_0000001133881293.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=339C88B03CEB39B4BAA87D6D32F6AFB6BECE0D846FA1E261B22AA2DECA46FC57)

                6. （可选）对于已添加的埋点，您可以根据需要，通过埋点名称后面的按钮，进行预览、编辑、删除、添加参数及查看详情等相关操作。

通过点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0a/v3/rHJbYReLRpmKJhTVd-c7dg/zh-cn_image_0000001091499848.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=3CCAF2ECCC5067E944486C3AA4E1CA1B2BEE615502A5E3B06C32C40D3C57D529)按钮，您可以修改埋点名称，但不能修改埋点类型。点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ef/v3/41fG5S_3SOmmOV8j4KP1_Q/zh-cn_image_0000001091371494.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=B98B9B8440AF13D663D36DFE67D44EC2C32AABF370CB7BBA0D17DB006FDA172C)按钮，可以为当前埋点添加参数。
