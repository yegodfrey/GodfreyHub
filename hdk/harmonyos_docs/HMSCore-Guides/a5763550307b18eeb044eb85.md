# 管理个人资料

获取华为运动健康App"我的 \> 个人资料"中的用户性别、出生日期、身高、体重。  
![](https://media:901788166629959664)  
* 目前该功能只在手机上支持，智能表不支持。
* 个人资料中的数据是由用户自己填写的。但如果用户连接了体脂秤，并授权将体脂秤数据同步到个人资料，则体重数据会同步体脂秤数据。  
图1 个人资料

![](https://media:901788166629995665)

#### 获取性别

调用[getGender](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-userinfo-0000001208702446#section18711550154113)方法，获取性别，示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.getGender().then((result) => {
    console.info("getGender success: " + JSON.stringify(result))
}).catch((error) => {
    console.error("getGender Error: " + JSON.stringify(error));
});
```

#### 响应参数

|参数名称|参数类型|参数描述|
|:-----|:-----|:------------------------------------------------------|
|result|String|* 成功：性别，int类型，可选值：0（女）, 1（男）,2（保密）, -1（未设置） * 其他：错误信息描述|

#### 获取出生日期

调用 [getBirthDay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-userinfo-0000001208702446#section6012363412)方法，获取出生日期，示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.getBirthday().then((result) => {
    console.info("getBirthday success: " + JSON.stringify(result))
}).catch((error) => {
    console.error("getBirthday Error: " + JSON.stringify(error));
});
```

#### 响应参数

|参数名称|参数类型|参数描述|
|:-----|:-----|:---------------------------------------------|
|result|String|* 成功：出生年月日，举例：19900801 代表1990年8月1日 * 其他：错误信息描述|

#### 获取身高

调用[getHeight](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-userinfo-0000001208702446#section4909184694110)方法，获取身高，示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.getHeight().then((result) => {
    console.info("getHeight success: " + JSON.stringify(result))
}).catch((error) => {
    console.error("getHeight Error: " + JSON.stringify(error));
});
```

#### 响应参数

|参数名称|参数类型|参数描述|
|:-----|:-----|:-------------------------|
|result|String|* 成功：身高（单位：厘米） * 其他：错误信息描述|

#### 获取体重

调用[getWeight](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-userinfo-0000001208702446#section189985483415)方法，获取体重，示例代码如下：

```
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
HMSHealthKit.getWeight().then((result) => {
    console.info("getWeight success: " + JSON.stringify(result))
}).catch((error) => {
    console.error("getWeight Error: " + JSON.stringify(error));
});
```

#### 响应参数

|参数名称|参数类型|参数描述|
|:-----|:-----|:-------------------------|
|result|String|* 成功：体重（单位：公斤） * 其他：错误信息描述|
