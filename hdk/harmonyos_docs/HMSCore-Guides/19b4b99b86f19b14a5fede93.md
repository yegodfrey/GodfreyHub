# GameTurbo Engine（可选）

GameTurbo Engine通过游戏App给系统提供精细化场景信息、配置信息、网络信息等，系统给游戏App反馈系统状态信息等，使得双方能够利用这些信息进行更紧密和深入的协作，在系统资源有限的情况下进一步改善玩家的游戏体验。
