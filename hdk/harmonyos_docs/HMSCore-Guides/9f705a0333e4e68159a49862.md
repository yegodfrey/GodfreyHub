# 管理默认数据处理位置

## 修改默认数据处理位置

分析服务支持将数据上报到如下四个数据处理位置：

* 中国
* 德国
* 俄罗斯
* 新加坡

您可以选择其中一个作为您项目的数据处理位置并设置为默认，分析服务将在您设置的默认数据处理位置处理您应用及用户的数据。如果后续修改默认数据处理位置，原数据处理位置您应用及用户的数据将会被清除，所以请谨慎设置项目的"默认数据处理位置"。
> 注意
>
> 修改默认数据处理位置后：
>
> * 项目下分析服务的云侧数据将被自动清除且无法恢复。
> * 项目下各应用的现有版本将无法访问分析服务。
> * 您需要为您的项目重新开通分析服务，并为您的应用集成最新版本的agconnect-services配置文件，以保证数据正常上报到新的默认数据处理位置。

修改默认数据处理位置具体操作步骤如下：

1. 登录 [AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"我的项目"。
2. 在项目列表中找到您想修改默认数据处理位置的项目。
3. 进入"项目设置 > 常规"页面，在"项目"下点击"数据处理位置"后的"管理"。

   1. 在"启用"栏为您的项目勾选新的数据处理位置。
   2. 选中新的数据处理位置右侧的"设为默认"栏中的单选框，将其设置为默认数据处理位置。
   3. 在"启用"栏中去勾选原数据处理位置。

## 查看默认数据处理位置

修改完项目的默认数据处理位置后，您可以在"项目设置 > 常规"页面查看项目的默认数据处理位置。
