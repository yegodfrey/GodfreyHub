# 步数写入

步数数据通过SampleSet写入，需要先创建数据采集器DataCollector，然后将详细的步数打点数据写入SampleSet。

1. 创建步数数据采集器DataCollector。

   <br />

   HTTP请求，请参见[创建数据采集器](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacollectors_create-0000001050114852#section984123664716)接口

   ```
   POST
   https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors
   ```

   请求示例

   ```
   POST
   https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors
   ```

   请求体

   ```
   Content-Type: application/json
   Authorization: Bearer ***
   x-client-id: ***
   x-version: ***
   x-caller-trace-id: ***
   {
       "appInfo": {
           "appName": "Example App",
           "desc": "https://huaweiapi.com",
           "appVersion": "1"
       },
       "collectorDataType": {
           "name": "com.huawei.continuous.steps.delta"
       },
       "deviceInfo": {
           "manufacturer": "huawei",
           "modelNum": "mp",
           "devType": "Smart watch",
           "uniqueId": "1234567890",
           "version": "1.0"
       },
       "collectorType": "raw"
   }
   ```

   响应体

   ```
   HTTP/1.1 200 OK
   Content-type: application/json;charset=utf-8
   {
       "collectorId": "cmF3OmNjb250aW51b3VzLnN0ZXBzLmRlbHRhEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg",
       "appInfo": {
           "appName": "Example App",
           "desc": "https://huaweiapi.com", 
           "appVersion": "1" 
       },
       "collectorDataType": {
           "name": "com.huawei.continuous.steps.delta"
           "field": [
               {
                   "name": "steps_delta",
                   "format": "integer"
               }
           ],
       },
       "deviceInfo": {
           "manufacturer": "huawei",
           "modelNum": "mp", 
           "devType": "Smart watch", 
           "uniqueId": "1234567890", 
           "version": "1.0"
       },
       "collectorType": "raw"
   }
   ```

   <br />

2. 步数填充SampleSet。

   <br />

   HTTP请求，请参见[上传采样数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacollectors_samplesets_patch-0000001050114858#section4148124910217)接口

   ```
   PATCH 
   https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors/{dataCollectorId}/sampleSets/{sampleSetId}
   ```

   请求示例

   ```
   PATCH 
   https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors/cmF3OmNjb250aW51b3VzLnN0ZXBzLmRlbHRhEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg/sampleSets/1600446040000000000-1600482049000000000
   ```

   请求体

   ```
   Content-Type: application/json
   Authorization: Bearer ***
   x-client-id: ***
   x-version: ***
   x-caller-trace-id: ***
   {
       "dataCollectorId": "cmF3OmNjb250aW51b3VzLnN0ZXBzLmRlbHRhEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg", 
       "startTime": 1600446040000000000,
       "endTime": 1600482049000000000,
       "samplePoints": [
   	{
               "dataTypeName": "com.huawei.continuous.steps.delta",
               "startTime": 1600446040000000000,
               "endTime": 1600446100000000000,
               "value": [
                   {
           	"fieldName": "steps_delta",
                   "integerValue": 300
                   }
               ],
               "metadata": "{\"motion_type\":\"RUN\"}"
           }
       ]
   } 
   ```

   响应体

   ```
   HTTP/1.1 200 OK
   Content-type: application/json;charset=utf-8
   {
       "startTime": 1600446040000000000,
       "endTime": 1600482049000000000,
       "dataCollectorId": "cmF3OmNjb250aW51b3VzLnN0ZXBzLmRlbHRhEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg",
       "samplePoints": [
           {
               "dataTypeName": "com.huawei.continuous.steps.delta",
               "startTime": 1600446040000000000,
               "endTime": 1600446100000000000,
               "value": [
                   {
           	"fieldName": "steps_delta",
                   "integerValue": 300
                   }
               ],
               "metadata": "{\"motion_type\":\"RUN\"}"
           }
       ]
   }
   ```
