# 沙盒测试

沙盒测试允许您在接入华为应用内支付联调过程中无需真实支付即可完成端到端的测试，您可以在AppGallery Connect中配置测试帐号，并设置允许这些帐号执行沙盒测试。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135208.67599087256394692174137329728600:50001231000000:2800:C9079F28CBACDA019DE51C6552D962AE703B8645849E5B09344CAFA56708BB94.png)  
目前沙盒测试功能只支持集成HMS Core SDK 3.0及以上版本的应用，并且测试设备必须安装3.0以上HMS Core（APK）。如果使用HMS Core SDK 2.0版本的支付接口测试仍将导致真实的扣费。  

#### 配置沙盒测试

* 设置测试帐号 在进行测试前，您需要在AppGallery Connect中的"用户与访问"中添加测试帐号，这些测试帐号都是真实的华为帐号。具体请参见[沙盒测试](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-testaccount-0000001146438651)。

  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135208.10715849138659781204735622901831:50001231000000:2800:CDC2C97B3036DDD4C39A2FA22B4D6FAC1E6A7881499484FE568888CC647651A0.png)  
  沙盒测试帐号添加完成之后需要30min\~1h才能生效。使用时请检查当前的帐号是否支持沙盒测试。
* 配置沙盒测试版本 如果您要测试的应用包此前没有在AppGallery Connect上架过版本，只需要确保测试包的versionCode大于0；如果已有上架的版本，则测试包的versionCode需要大于上架版本的versionCode。

#### 沙盒测试能力未生效自检

如果配置的沙盒帐号未生效，可参见[配置沙盒测试](#section115271533103410)检查当前是否满足沙盒测试的两个条件：

* 是否已在AppGallery Connect添加相关帐号；
* 应用的版本是否满足要求。

此外您也可在应用中使用[IapClient.isSandboxActivated](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section236817311277)接口或[HMSIAP.isSandboxActivated](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-js-hmsiap-0000001333923881#section828423515210)接口来检查当前沙盒环境不可用的原因。  

#### 测试非订阅型商品支付

您可以在设备上登录已配置的测试帐号，并安装该待测试应用。发起一次性商品（非订阅型商品）购买时，华为IAP会检测到该用户为测试用户，跳过实际支付环节，直接支付成功。

* 沙盒测试场景下的购买流程与正式环境的购买流程一致。
* 华为IAP购买成功后的收据信息中，会携带值为0的purchaseType字段，标识此次购买为沙盒测试的记录。
* 当HMS Core（APK）版本小于4.0.2.300时，在沙盒环境下创建一次性商品订单，本质是创建一个已经完成了的支付订单，所以即使中途取消还是会成功购买这个商品。
* 沙盒环境下购买非消耗型商品，购买之后可以执行消耗，之后可以再次购买，以方便测试。
* 沙盒测试拉起收银台时会弹出沙盒环境标志的弹框，收银台和成功页也均有沙盒环境的标志，如下图所示。  
  ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135208.10417655305085597920559747399920:50001231000000:2800:09554C5610C465FEEBD597B49F9A80989626CF1141C8D6FB43422D84D6F41966.png)  
  如果未显示截图的提示页面，表示本次交易未进入沙盒测试环境，继续测试会实际扣费，请检查当前是否满足沙盒测试的两个条件。您也可使用[IapClient.isSandboxActivated](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section236817311277)接口或[HMSIAP.isSandboxActivated](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-js-hmsiap-0000001333923881#section828423515210)接口接口来检查当前沙盒环境是否可用。

#### 测试订阅型商品续订

订阅型商品的购买流程和一次性商品的购买流程类似，但订阅还有其他细节场景，比如续订成功或失败，续订周期时长。为了帮助您快速测试您应用的订阅场景，沙盒环境下的订阅续订时间会比正常情况更快，引入"时光机"概念。比如订阅周期为1周，商品在3分钟后发生续期，此时订阅型商品有效期延长了3分钟。  

|实际时限|测试时限|
|:------|:---|
|1周|3分钟|
|30天/31天|3分钟|
|1个月|5分钟|
|2个月|10分钟|
|3个月|15分钟|
|6个月|30分钟|
|1年|1小时|

* 沙盒环境下发起订阅时仍需要完成签约或绑卡，但该过程不会真实扣费。
* 沙盒环境的订阅模拟扣费最终标识的支付方式payType固定为0。
* 自动续期处理不需要完成真实扣款，华为IAP会直接返回成功。
* 订阅在沙盒场景下会自动续期5次(一共6期)，5次之后需要用户主动发起恢复订阅，且进行恢复订阅操作时，只会使得本次恢复订阅操作立即成功，不会再进行自动续期。
* 沙盒测试拉起收银台时会弹出沙盒标志的弹框，收银台和成功页也均有沙盒标志。
