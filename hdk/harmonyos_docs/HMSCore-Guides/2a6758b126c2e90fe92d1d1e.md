# API列表

|功能列表|描述|
|:----------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------|
|[请求补差](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-subsidies-create-0000002002772881)|商户预下单时添加最大补差金额"subsidyAmount"及延时分账"allocationType=DELAY_ORDER_ALLOCATION"入参，订单支付成功并结算完成后，在发起分账前，可调用该接口进行订单补差。|
|[请求补差退款](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-subsidies-refund-0000001966172660)|开发者可以调用该接口对已完成补差的订单请求补差退款。|
|[取消补差](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-subsidies-cancel-0000001966012880)|对于需要补差的订单，可在发起分账前，调用该接口取消补差，取消补差后可发起分账。|
