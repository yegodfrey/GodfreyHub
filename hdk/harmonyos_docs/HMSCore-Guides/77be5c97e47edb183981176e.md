# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAnalyticsKit-iOS)快速体验一个应用的开发过程。

#### 开发环境

      * 安装 Xcode 10.1 或更高版本。为保证兼容性，要求最低兼容iOS 9.0。

      * 安装CocoaPods 1.10.0或更高版本。 
      * 准备一台用于测试的iPhone设备或者模拟器。

#### 开发流程

您需要按照如下流程完成应用的开发工作。

开发步骤 | 说明  
---|---  
[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001050166522) | 在开发应用前，需要在AppGallery Connect中配置相关信息，包括：注册成为开发者、创建应用、开通华为分析服务。  
[_集成SDK_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-integrating-sdk-0000001050168479) | 通过CocoaPods方式或手动方式集成SDK。  
[_接入Analytics_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-accessing-0000001050168481) | 参见[ _API参考_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-huawei-analytics-overview-0000001050164673)中的API，实现数据上报功能。
