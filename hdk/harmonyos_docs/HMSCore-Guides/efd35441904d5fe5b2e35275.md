# 构建本地实况窗通知

#### 简介

开发者可通过原生发送通知的流程来发送实况窗通知，在通知中添加实况窗通知所需的扩展参数，这样在支持实况窗通知的设备上，所发送的通知就会以实况窗通知的形式显示。

#### 开发步骤

#### [h2]准备工作

与原生的通知流程相同，发送通知前需要获取NotificationManager的对象，创建通知通道NotificationChannel，然后创建通知、指定通知的id，最后使用NotificationManager的notify接口将通知发送出去。示例代码如下：
    
    // 获取NotificationManager对象
    Context context = getApplicationContext();
    String channelId = "test_channel";
    NotificationManager notificationManager = (NotificationManager) context.getSystemService(NOTIFICATION_SERVICE);
    
    // 创建通知通道，若已有通知通道可直接复用，无需重复创建
    NotificationChannel channel = new NotificationChannel(channelId, "test_channel_name", NotificationManager.IMPORTANCE_DEFAULT);
    notificationManager.createNotificationChannel(channel);
    
    // 创建小图标
    Icon smallIcon;
    
    // 创建通知
    Notification notification = new Notification.Builder(context, channelId)
        .setContentTitle("test_title")
        .setContentText("test_text")
        .setSmallIcon(smallIcon)
        .build();
    
    // 发送通知
    notificationManager.notify(1, notification);

#### [h2]创建实况窗通知

实况窗是在通知的基础上附加了扩展参数，若是在支持实况窗的设备上发送，则系统会根据这些扩展参数，将通知按照实况窗的样式进行显示。

更详细的参数请参考[实况窗通知扩展参数API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-live-0000001613100205)。

创建实况窗通知的示例代码如下：
    
    // 创建bundle保存实况窗通知信息
    Bundle liveNotificationData = new Bundle();
    liveNotificationData.putInt("notification.live.operation", 0);
    liveNotificationData.putString("notification.live.event", "TAXI");
    liveNotificationData.putInt("notification.live.type", 1);
    
    // 创建小图标
    Icon smallIcon;
    
    // 创建通知，调用addExtras添加实况窗通知信息
    Notification notification = new Notification.Builder(context, channelId)
        .setContentTitle("test_title")
        .setContentText("test_text")
        .addExtras(liveNotificationData)
        .setSmallIcon(smallIcon)
        .build();
    
    // 发送实况窗通知
    notificationManager.notify(1, notification);

以上为基础类型的实况窗通知的发送方式，若要发送其他类型的实况窗通知则需要携带类型对应的扩展参数，以[强调文本模板类型](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-live-0000001613100205#section16807111912368)的实况窗通知举例：
    
    // 创建bundle保存实况窗通知信息，设置type为4，表示强调文本模板类型
    Bundle liveNotificationData = new Bundle();
    liveNotificationData.putInt("notification.live.operation", 0);
    liveNotificationData.putString("notification.live.event", "PICK_UP");
    liveNotificationData.putInt("notification.live.type", 4);
    
    // 创建bundle保存强调文本模板类型的实况窗通知所需的扩展参数
    Bundle feature = new Bundle();
    feature.putString("notification.live.feature.titleText", "取餐码");
    feature.putString("notification.live.feature.contentText", "750");
    
    // 将feature的bundle设置到实况窗通知参数liveNotificationData中
    liveNotificationData.putBundle("notification.live.feature", feature);
    
    // 创建小图标
    Icon smallIcon;
    
    // 创建通知，调用addExtras添加实况窗通知信息
    Notification notification = new Notification.Builder(context, channelId)
        .setContentTitle("test_title")
        .setContentText("test_text")
        .addExtras(liveNotificationData)
        .setSmallIcon(smallIcon)
        .build();
    
    // 发送实况窗通知
    notificationManager.notify(1, notification);

若发送实况窗通知时还想要实况窗胶囊，则需在Bundle中携带胶囊所需的参数，举例如下：
    
    // 创建bundle保存实况窗通知信息
    Bundle liveNotificationData = new Bundle();
    liveNotificationData.putInt("notification.live.operation", 0);
    liveNotificationData.putString("notification.live.event", "TAXI");
    liveNotificationData.putInt("notification.live.type", 1);
    
    // 创建bundle保存胶囊所需的参数
    Bundle capsule = new Bundle();
    capsule.putInt("notification.live.capsuleStatus", 1);
    capsule.putInt("notification.live.capsuleType", 1);
    capsule.putParcelable("notification.live.capsuleIcon", Icon.createWithResource(context, R.drawable.xxx));
    capsule.putInt("notification.live.capsuleBgColor", Color.parseColor("#FFFF0000"));
    capsule.putString("notification.live.capsuleTitle", "胶囊标题");
    capsule.putString("notification.live.capsuleContent", "胶囊扩展内容");
    
    // 将胶囊参数设置到实况窗通知参数中
    liveNotificationData.putBundle("notification.live.capsule", capsule);
    
    // 创建小图标
    Icon smallIcon;
    
    // 创建通知，调用addExtras添加实况窗通知信息
    Notification notification = new Notification.Builder(context, channelId)
        .setContentTitle("test_title")
        .setContentText("test_text")
        .addExtras(liveNotificationData)
        .setSmallIcon(smallIcon)
        .build();
    
    // 发送实况窗通知
    notificationManager.notify(1, notification);

若发送实况窗通知时要设置折叠小外屏，则需在Bundle中携带外屏所需的参数，举例如下：
    
    // 创建bundle保存实况窗通知信息
    Bundle liveNotificationData = new Bundle();
    liveNotificationData.putInt("notification.live.operation", 0);
    liveNotificationData.putString("notification.live.event", "TAXI");
    liveNotificationData.putInt("notification.live.type", 1);
    
    // 设置外屏
    liveNotificationData.putBoolean("notification.live.externalEnable", true);
    liveNotificationData.putString("notification.live.externalTitle", "外屏标题");
    liveNotificationData.putString("notification.live.externalBody", "外屏内容");
    liveNotificationData.putInt("notification.live.externalType", 1);
    liveNotificationData.putParcelable("notification.live.externalBgImage", Icon.createWithResource(context, R.drawable.xxx));
    liveNotificationData.putInt("notification.live.externalBgColor", Color.RED);
    
    // 创建通知，调用addExtras添加实况通知信息
    Notification notification = new Notification.Builder(context, channelId)
      .setContentTitle("test_title")
      .setContentText("test_text")
      .addExtras(liveNotificationData)
      .build();
            
    // 发送实况通知
    notificationManager.notify(1, notification);

#### [h2]更新和结束实况窗通知

实况窗通知的扩展参数中，字段notification.live.operation表示实况窗通知的生命周期，该字段的取值为0/1/2，0表示创建实况窗通知，1表示更新实况窗通知，2表示结束实况窗通知。示例代码如下：
    
    // 更新通知的标题和内容
    notification.extras.putCharSequence(Notification.EXTRA_TITLE, "update_title");
    notification.extras.putCharSequence(Notification.EXTRA_TEXT, "update_text");
    
    // 设置operation字段为1，表示更新
    notification.extras.putInt("notification.live.operation", 1);
    
    // 使用和创建时相同的id，更新实况窗通知
    notificationManager.notify(1, notification);
    
    // 设置operation字段为2，表示结束
    notification.extras.putInt("notification.live.operation", 2);
    
    // 使用和创建时相同的id，结束实况窗通知
    notificationManager.notify(1, notification);
    
    // 删除通知
    notificationManager.cancel(1);

实况窗通知的更新和结束都是通过NotificationManager的notify接口进行，此时实况窗通知可以正常的更新和结束，在结束之后会根据应用设置的存档期字段留存在通知中心中显示。应用也可以通过NotificationManager的cancel接口来删除实况窗通知，这种情况下实况窗通知将直接删除，同时存档期字段无效，实况窗通知不会继续留存。
