# 根据凭证请求华为API

应用调用华为API时，将Access Token放在请求头部的Authorization字段，以便API提供方进行鉴权。

**示例：** 调用/openapi/inner/v1/sports/dailySteps接口，在前面[接入华为帐号](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-get-access-token-0000001050048946#section1139031473110)时，scope中包含调用此接口的权限项：https://www.huawei.com/health/sport.readonly，则可将获取的Access Token放在请求头Header中来调用此接口。如下：

```screen
POST /openapi/inner/v1/sports/dailySteps?startDate=<业务参数1>&endDate=<业务参数2> HTTP/1.1
Host: <XXX>
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW
Accept: application/json
x-huid: <业务参数3>
x-appid: <业务参数4>
x-client-version: <业务参数5>
x-prdPkgName: <业务参数6>
Cache-Control: no-cache
Authorization: Bearer <已经获得的Access Token>
```
