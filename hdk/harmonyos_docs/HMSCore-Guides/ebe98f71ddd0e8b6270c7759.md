# 游戏登录

本文档仅适用于使用openId作为唯一用户标识的新接入游戏。  

#### 场景介绍

游戏登录是指用户使用自己的华为帐号登录游戏，根据用户的登录体验可分为普通登录和免授权登录。  

#### 普通登录

#### 免授权登录

为避免影响用户转化率，当游戏仅申请获取用户标识，不获取用户其他信息时，可以实现免授权登录，在登录时将不弹出用户信息授权框。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251231154828.35749219825622178280091692648904:50001231000000:2800:BF5BE513E7F07882F9FEE4B349F8EEF82402F4969CF5E4C91FD951A9F243A963.png)  
免授权登录对注册地为非中国大陆玩家无效，即游戏即使接入了免授权登录，非中国大陆玩家登录时仍然会弹出授权框。

使用免授权登录方式的登录界面需满足如下要求：

* 登录界面上必须包含"华为logo的登录框"和"仅登录关联华为帐号，不获取其他个人信息"的提示框。"华为logo的登录框"中华为图标需要满足[华为帐号登录图标使用规范](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/dev-specifications-0000001050048916)。
* "仅登录关联华为帐号，不获取其他个人信息"的提示框仅做展示，不做点击约束。
* 用户需先勾选同意游戏自己的相关隐私协议后才可登录，若用户忘记勾选直接点击登录，建议添加轻微震动提示勾选。

#### 实名认证说明

* 发布地为中国大陆的游戏必须要进行实名认证。按照国家新闻出版署规定，所有网络游戏必须接入国家新闻出版署网络游戏防沉迷实名验证系统。华为HMS Core提供了华为帐号登录时的实名认证功能，您只需向当地的新闻出版局申请接入网络游戏防沉迷实名认证系统，并获取"bizID（游戏备案识别码）"，再将bizID配置到AppGallery Connect，华为将为您的游戏自动对接国家新闻出版署的实名认证系统并开启强制实名认证，无需您进行额外的开发。具体操作请参见[版署实名认证申请](https://developer.huawei.com/consumer/cn/doc/app/game-center-identification-applyfor-0000001193982458)。
* 如果调用华为帐号显式授权接口[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)时返回7021错误码，表示中国大陆玩家在弹出实名认证弹框后取消了实名认证，您需要禁止玩家进入游戏。
* 如果华为帐号静默授权时返回2002错误码，表示中国大陆玩家未实名认证，您需要调用华为帐号显式授权接口[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)登录。  

#### 前提条件

必须在[JosAppsClient.init(AppParams appParams)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)方法调用成功后再实现游戏登录功能，init方法调用请参考[游戏初始化](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-start-0000001050123475)。  

#### 注意事项

* 如果玩家拒绝登录，不要重复调用登录接口，避免玩家在开始游戏时反复拒绝登录。

* 游戏必须在调用[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)成功后才能允许用户进入游戏，否则会导致审核被驳回。
* 发布地为中国大陆的游戏不允许跳过帐号登录或者在游戏内登录。

本功能涉及的关键开发步骤如下：  

#### 华为帐号授权

在游戏登录前，游戏需要调用华为帐号SDK提供的[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)接口进行华为帐号的静默授权，并在授权成功后从[AuthAccount](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/authaccount-0000001050315810#section8573310141110)对象中获取AuthorizationCode。

* 如果静默授权成功，直接跳转到[游戏登录](#section79001559173318)进行游戏登录。
* 如果静默授权失败，再调用显式授权接口[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)，显式拉起华为帐号授权页面进行授权。授权成功后，继续参考[游戏登录](#section79001559173318)进行游戏登录，否则禁止进入游戏。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251231154829.44484004738090199596876066319814:50001231000000:2800:2C20DB6CF689222C833E09FF0F64D00D2710A2E3B9AF78FB57E90A45CE9A6D7F.png)  
请勿直接使用[silentSignIn](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section782995853116)或[getSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section76155516411)返回的openId作为用户标识，否则可能会导致审核不通过。

[普通登录](#section127311543195513)和[免授权登录](#section849817545612)使用的AccountAuthParams存在差异，其余开发步骤完全相同，请您关注如下示例代码。

                                authorizationCode = signInResult.getAccount().getAuthorizationCode();

				showLog("Sign in failed: " + signInResult.getStatus().getStatusCode());
			}
		} catch (JSONException var7) {
			showLog("Failed to convert json from signInResult.");
		}

#### 游戏登录

华为帐号授权成功后，调用[Games.getPlayersClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/games-0000001050121658#section023114101465)方法初始化[PlayersClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668)实例，并调用[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)方法进行游戏登录，从返回的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象获取玩家信息。

* [普通登录](#section127311543195513)场景下：[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象中只有[getDisplayName](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section97851713752)、[getOpenId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section8861615201313)、[getUnionId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section7615821121417)有值，其他方法返回空。用户头像建议从华为帐号授权成功后返回的[AuthAccount](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/authaccount-0000001050315810)获取。
* [免授权登录](#section849817545612)场景下：[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象中只有[getOpenId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section8861615201313)、[getUnionId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666#section7615821121417)有值，其他方法返回空。无法获取用户头像和昵称。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251231154829.82561768909399690050889466950435:50001231000000:2800:23986F0E55A57206D819C008173C1A3BBE1F6FB1EF210BAF4A0994CD7FF3A7E7.png)  
必须使用[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)返回的openId，否则将导致审核不通过。  

```
public void getGamePlayer() {
    // 调用getPlayersClient方法初始化
    PlayersClient client = Games.getPlayersClient(this);
    // 执行游戏登录
    Task<Player> task = client.getGamePlayer();
    task.addOnSuccessListener(new OnSuccessListener<Player>() {
        @Override
        public void onSuccess(Player player) {          
            String displayName = player.getDisplayName(); // 免授权登录场景下无法获取玩家昵称
            String unionId = player.getUnionId();
            String openId = player.getOpenId();
            // 获取玩家信息成功，校验服务器端的玩家信息，校验通过后允许进入游戏
        }
    }).addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception e) {
            if (e instanceof ApiException) {
                String result = "rtnCode:" + ((ApiException) e).getStatusCode();
                // 获取玩家信息失败，不允许进入游戏，并根据错误码处理
                if (7400 == ((ApiException) e).getStatusCode()||7018 == ((ApiException) e).getStatusCode()) {
                    // 7400表示用户未签署联运协议，需要继续调用init接口
                    // 7018表示初始化失败，需要继续调用init接口
                    init();
                }
            }
        }
    });
}
```

#### 通过AuthorizationCode获取Access Token

华为帐号授权成功并获取AuthorizationCode后，请参考[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)使用AuthorizationCode获取Access Token。  

#### 校验用户标识

为了保证用户标识的安全性，游戏可以调用华为游戏服务的[获取用户标识](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gettokeninfo-0000001343252157)接口，根据[通过AuthorizationCode获取Access Token](#section163812617171)获取的Access Token向华为游戏服务器请求获取服务器端的用户标识，再与[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)方法获取的用户标识进行比对，完成用户标识的校验。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251231154829.51337268543409900146161523644286:50001231000000:2800:417040F95F48FC663BEFCB6AA81C72786ACEC8EC278CEF05B211E13B0187AFA2.png)  
* 为了保证安全性，如果您有自己的服务器，强烈建议您在服务器端验证用户标识。
* 如果您当前使用了华为帐号服务的[解析凭证Access Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/account-gettokeninfo-0000001050050585)接口来验证用户信息，请尽快替换为新的游戏服务的[获取用户标识](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gettokeninfo-0000001343252157)接口。  

#### 提交玩家角色信息

在用户登录并选择角色以及服务器后，游戏必须调用[PlayersClient.savePlayerRole](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section14448819342)接口，提交玩家角色信息到华为游戏服务器。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20251231154829.32495342342206272487122617513403:50001231000000:2800:40D31A92D935CB0B47E11081FE90B7BC200AB9DA47F22BBEBD4DDF7DEFA4EF61.png)  
* [PlayersClient.savePlayerRole](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section14448819342)接口当前仅支持中国大陆地区。
* roleId和roleName必传，且不能传""和null。
* playerId、openId、unionId只能传1个，请上传游戏当前正在使用的玩家标识。例如当前使用openId作为用户标识，则只能传openId。
