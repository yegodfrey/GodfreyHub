# 概述

配置是包含可视化埋点、代码、条件、变量、分组和版本的整体设置文件，是可以被浏览器客户端下载并执行的策略文件。

您需要在使用DTM之前创建一个配置以实现对资源的管理，因此在进行其他操作之前您必须创建配置，详情请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-create-configuration-0000001057616572)。

#### 功能介绍

“配置”页面的功能包括：

                * [导入配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-configuration-operation-procedure-0000001091043929#section54809211538)：您可以将本地的配置数据直接导入以实现配置数据的快速同步。
                * [导出配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-configuration-operation-procedure-0000001091043929#section048142115313)：您可以对配置中工作区的数据和任意版本进行导出。
                * [编辑配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-configuration-operation-procedure-0000001091043929#section2048232185313)：您可以对配置名称、网址及操作记录存储时间进行修改。
                * [关闭服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-configuration-operation-procedure-0000001091043929#section165041847125312)：您可以关闭动态标签管理服务，同时将删除所有配置和修改记录。
