# 响应式RecyclerView

#### Maven方式引入aar包

使用前需在build.gradle的dependencies中添加所引用控件的依赖。

HwRspRecyclerView提供了androidx包下的和support V7包下的RecyclerView的支持。

* androidx引入AAR包：

  ```
  implementation "com.huawei.ui.rspuikit:hwrsprecyclerview-androidsupx:{version}"
  ```

* support V7引入AAR包：

  ```
  implementation "com.huawei.ui.rspuikit:hwrsprecyclerview-androidsup:{version}"
  ```

#### 接入HwRspRecyclerView

* 如果直接使用的是RecyclerView，在代码和layout文件里将RecyclerView替换成HwRspRecyclerView：

  ```
   <com.huawei.rspuikit.androidsupx.hwrsprecyclerview.wiget.HwRspRecyclerView
          android:background="@color/white"
          android:layout_width="match_parent"
          android:layout_height="match_parent"
          android:paddingStart="5dp"
          android:paddingEnd="5dp"
          android:id="@+id/myRecyclerView"
          app:expandStateSpanCount="3"
          app:expandStateEnableRsp="true"
          />
  ```

* 如果自定义View继承了RecyclerView，在代码里把继承关系中的RecyclerView替换成HwRspRecyclerView:

  ```
  import com.huawei.rspuikit.androidsupx.hwrsprecyclerview.wiget.HwRspRecyclerView;

  public class MyRecyclerView extends HwRspRecyclerView
  ```

* 代码使用示例。

  ```
  @Override
  protected void onCreate(@Nullable Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.recycler_view);
       HwRspRecyclerView myRecyclerView = findViewById(R.id.myRecyclerView);
       // 设置首行top值
       myRecyclerView.setFirstRowTop(10);
       // 设置item的bottom值
       myRecyclerView.setItemBottom(20);
       // 设置item间距类型
       myRecyclerView.setExpandStateGapType(1);
       // 设置扩展态间距
       myRecyclerView.setExpandStateItemGap(80);
       // 设置响应式控件生效
       myRecyclerView.setRspEnable(true);
       // 设置扩展态列数
       myRecyclerView.setExpandStateSpanCount(3);
       StaggeredGridLayoutManager layoutManager = new StaggeredGridLayoutManager(2, 
           StaggeredGridLayoutManager.VERTICAL);
       myRecyclerView.setLayoutManager(layoutManager);
   }
  ```

* xml参数配置  

  |参数名|参数取值|参数说明|使用方式|
  |:---------------------|:---------|:-------------------------|:-------------|
  |expandStateEnableRsp|True/false|是否使用响应式布局|在layout布局文件中配置|
  |expandStateSpanCount|Integer|展开态控件的列数|在layout布局文件中配置|
  |expandStateItemGap|dimension|展开态Item的列间距|在layout布局文件中配置|
  |expandStateFirstRowTop|dimension|展开态首行top值|在layout布局文件中配置|
  |expandStateGapType|Integer|展开态列间距类型:0代表n个间距；1代表n-1个间距|在layout布局文件中配置|
  |expandStateItemBottom|dimension|展开态item底部bottom值|在layout布局文件中配置|

#### 接口能力

响应式控件扩展并兼容原生RecyclerView控件接口，扩展控件接口及说明如下表。  

|接口函数|输入|输出|返回值|
|:----------------------|:-----------------------|:--------------------------|:---|
|setRspEnable|boolean isRspEnable|设置响应式控件是否生效|void|
|setExpandStateSpanCount|int expandStateSpanCount|设置展开态列数|void|
|setExpandStateItemGap|int expandStateItemGap|设置展开态列间距|void|
|setFirstRowTop|int firstRowTop|设置展开态首行top值|void|
|setExpandStateGapType|int expandStateGapType|设置展开态间距类型:0代表n个间距；1代表n-1个间距|void|
|setItemBottom|int itemBottom|设置展开态item底部bottom值|void|
