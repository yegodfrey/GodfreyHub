# 服务定价

## 服务订阅说明

1. 定位服务为您提供室外高精度（SDK for Android）服务、网络定位（API）服务、IP定位（API）服务、地理围栏（SDK for Android）服务、室内定位（SDK for Android）服务以及位置语义（SDK for Android）服务。
   * 室外高精度（SDK for Android）服务：目前仅在中国大陆部分区域提供服务，收费策略如下表所示。
   * 网络定位（API）服务：在全球提供服务，采用即用即付的方式进行结算，收费策略如下表所示。
   * IP定位（API）服务：目前仅在中国大陆地区提供服务，收费策略如下表所示。
   * 地理围栏（SDK for Android）服务：目前仅在中国大陆地区提供服务，收费策略如下表所示。
   * 室内定位（SDK for Android）服务：目前仅在中国大陆部分区域提供服务，收费策略如下表所示。
   * 位置语义（SDK for Android）服务：目前仅在中国大陆部分区域提供服务，收费策略如下表所示。
2. 当您成功注册成为华为开发者用户，在AppGallery Connect创建项目后，华为会自动帮您开通服务对应的免费档套餐。如需使用定位服务收费接口，请通过AppGallery Connect开通付费套餐，具体操作请参见[服务计费说明](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing-0000001058092595)。
3. 针对所有的AppGallery Connect付费服务，华为将按您使用服务实际产生的使用量向您收费。为防止服务被中断，您可以[设置消费提醒](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-set-expend-reminder-0000001200737801)。
