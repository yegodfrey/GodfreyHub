# 配置应用签名信息

## 准备签名文件

|文件名称||作用|
|:-|-|:--------------------|
|密钥文件（.p12文件）||用于打包项目时进行签名、获取签名证书指纹。|
|证书请求文件（.csr）||用于向华为申请调试证书、发布证书。|
[**表1**需准备的签名文件清单]

搭建完开发环境后，您需要使用DevEco Studio生成密钥文件（.p12文件）与证书请求文件（.csr）。

1. 在DevEco Studio主菜单栏单击**Build > Generate Key** **and CSR**。
2. 在**Key Store File** 中，单击**New**创建密钥库文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9f/v3/QjwFs7xVSVuADY8M-_LTOQ/zh-cn_image_0000002547959197.png?HW-CC-KV=V1&HW-CC-Date=20260909T145433Z&HW-CC-Expire=31536000000&HW-CC-Sign=50CE5011B8C177963BA5B9B932DED412E726C1D2398B1BCA1764B14477DB1C3A "点击放大")

3. 在**Create Key Store** 窗口中，填写密钥库信息后，单击**OK**。

   * **Key Store File** ：选择密钥库文件存储路径，并设置文件名称，单击**OK**。
   * **Password**：设置密钥库密码，必须由大写字母、小写字母、数字和特殊符号中的两种以上字符的组合，长度至少为8位。请记住该密码，后续签名配置需要使用。
   * **Confirm Password**：再次输入密钥库密码。

4. 在**Generate Key** 界面中，继续填写密钥信息后，单击**Next**。

   * **Alias**：密钥的别名信息，用于标识密钥名称。请记住该别名，后续签名配置需要使用。
   * **Password**：密钥对应的密码，与密钥库密码保持一致，无需手动输入。
   * **Validity**：证书有效期，建议设置为25年及以上，覆盖应用的完整生命周期。
   * **Certificate**：输入证书基本信息，如组织、城市或地区、国家码等。

5. 在**Generate CSR** 界面，选择密钥，设置CSR文件存储路径并设置文件名称，单击**OK**。
6. 单击**Finish**按钮，创建CSR文件成功，可以在存储路径下获取生成的密钥库文件（.p12）和证书请求文件（.csr）。

## 配置调试应用的签名信息

### 准备签名信息

为确保HarmonyOS应用的完整性，HarmonyOS通过数字证书和Profile文件来对应用进行管控，只有签名过的HAP才允许安装到设备上运行。因此，为了保证应用能够安装到调试设备上，您需要提前申请相应的调试证书与调试Profile文件。

详细步骤包括[申请应用调试证书](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-debugcert-0000001914263178)、[注册调试设备](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-device-0000001946142249)和[申请调试Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-debugprofile-0000001914423102)。
> 说明
>
> * **调试证书** 仅用于将工程打包安装至调试手机时使用，不可用于上架发布；**发布证书** 仅用于上架发布，不可用于安装调试，申请发布证书请参见[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-release-application-0000001181600758)。
> * 创建Profile文件前，请先完成[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-config-agc-0000001181440830#section1768875005315)，生成的Profile文件与您的项目绑定，如您更换了HarmonyOS应用（如更换包名，更换开发者等），您需要重新申请Profile文件。

### 配置签名信息

编译构建App需要使用到制作的私钥（.p12）文件、在AppGallery Connect中申请的证书（.cer）文件和Profile（.p7b）文件，在DevEco Studio中进行配置，请参见[配置签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V2/signing-0000001587684945-V2#section112371245115818)。
> 说明
>
> 在**File > Project Structure > Project > Signing Configs > Debug**窗口中，配置工程的签名信息。

## 配置SHA256指纹

SHA256指纹用于校验应用的真实性，您需要根据密钥文件（.p12文件）在本地生成SHA256指纹，并在应用上架前将SHA256指纹配置到AppGallery Connect。

### 生成SHA256指纹

在生成SHA256指纹前，已完成[生成密钥和证书请求文件](#section750073715225)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore D:\xxxxxxxx\myApplication.p12
     ```

     输入密钥库口令后，即可获取对应的SHA256指纹。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ac/v3/29u66IuTQuyn23z39xNC6A/zh-cn_image_0000002548039191.png?HW-CC-KV=V1&HW-CC-Date=20260909T145433Z&HW-CC-Expire=31536000000&HW-CC-Sign=6540F226CA212A5A4EDA2E0777DE8E1C53104ACFDFA761A7E994203E8DBFEC8F "点击放大")
* macOS
  1. 打开Terminal终端。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/-YoKjQQNSeqtTRvEtUD3vQ/zh-cn_image_0000002516519302.png?HW-CC-KV=V1&HW-CC-Date=20260909T145433Z&HW-CC-Expire=31536000000&HW-CC-Sign=A2246ECE602A2F1CB7D05896B7D3D31F6C1669E22688E1144B19702EB65E7AA1 "点击放大")

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。<keystore-file>为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/xxxxxx/Downloads/myApplication.p12
     ```

     输入密钥库口令后，即可获取对应的SHA256指纹。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/WXToNSGvTC-DbT7VDcW8Ag/zh-cn_image_0000002547959193.png?HW-CC-KV=V1&HW-CC-Date=20260909T145433Z&HW-CC-Expire=31536000000&HW-CC-Sign=8477EF8724C0B36DC83D7C546E2A59EB7AA1A69F3C27C42C733C5E9A4CA51588 "点击放大")

### 配置SHA256指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，单击"开发与服务"。
2. 在项目列表中找到您的项目，在项目中单击需要配置签名证书指纹的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，单击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/iFPBDfaxS9apoLxBO3Xp2g/zh-cn_image_0000002548039193.png?HW-CC-KV=V1&HW-CC-Date=20260909T145433Z&HW-CC-Expire=31536000000&HW-CC-Sign=7D65DC870B6DA0CC24891402F1A6DDF73211050E7B051EB08CFF373F75A4E541)
   > 说明
   >
   > 在"项目设置"页面的"应用"区域，单击"Client Secret"后面的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/LHXCPKMfQC2l8-SwPG61Og/zh-cn_image_0000002516359390.png?HW-CC-KV=V1&HW-CC-Date=20260909T145433Z&HW-CC-Expire=31536000000&HW-CC-Sign=153B36066CDCBAFE7579B801ECD1B8756E1E7906BACD5D24677BAE9EB85C9C3C)即可复制Client Secret。

4. 配置完成后，单击"保存"。
