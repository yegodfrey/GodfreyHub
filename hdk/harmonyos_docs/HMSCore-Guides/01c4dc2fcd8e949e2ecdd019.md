# 业务介绍

华为平台券（以下简称平台券）是华为支付为推广鸿蒙生态、华为支付而提供的平台补贴优惠券解决方案。平台券可以在商家的结算页前置显示，并由商家展示划扣后的价格。也可以与商家提供的优惠券合并使用，多重优惠，吸引更多的用户消费、提高用户活跃度。

平台券功能使用API接口的方式集成到商家的结算页功能中，有开发意愿的商户或者服务商可使用此API接口查询用户可使用的平台优惠券，并给用户显示划扣后的价格。

#### 业务模式

#### 支持的券类型

当前可支持满减券类型的平台券。  

|类型|说明|
|:--|:------------------------------------------------------|
|满减券|满X元减X元（例如：满10元减5元券）。根据商家的商户号和订单金额等条件，由华为平台券系统自动判断是否可使用。|

#### 平台券的发放渠道

* 支持在华为负一屏鸿蒙有礼中领取。
* 支持在负一屏探索流领取。  

#### 平台券的露出方式

用户可在鸿蒙有礼"我的权益"中查看平台券信息。  

#### 平台券的核销方式

平台券必须使用华为支付作为支付渠道才能进行核销。

商家在调用华为支付提供的预下单接口时，把用户选择的平台券券码传递给华为支付（注意此时订单的支付金额是平台券优惠前的金额，即商家期望的收款金额）。华为支付会自动核销，并扣取用户优惠后的金额。

商家可以根据商户类型，参考[基础支付](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-0000001585274104)指南。  

#### 平台券的商户结算

支付后，商家和华为支付的结算方式不变，收款金额为平台券优惠前金额。

商家可以根据商户类型，参考[资金分账](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/payment-merchant-alloc-0000001635433981)指南。
