# 鲸鸿动能广告归因（非中国大陆）

## 功能概述

您可以配置转化事件并回传转化事件至鲸鸿动能广告，鲸鸿动能广告通过回传的数据对投放的广告效果进行深层次的优化，如优化投放算法、更精准的圈选目标人群等，从而提升广告投放回报率。

如果您使用鲸鸿动能广告投放广告，Analytics SDK将采集广告标识符、IP和useragent并同步至鲸鸿动能广告，用于回传转化事件至鲸鸿动能广告进行归因分析。

系统支持将"次日留存、3日留存、7日留存"相关数据回传至鲸鸿动能广告。
> 说明
>
> 该功能只适用于海外，中国大陆暂不支持。

## 前提条件

该功能适用于Android应用及快应用：

* Android应用需要将SDK升级到6.4.1.300及以上版本，才能正常回传转化事件。6.6.0.300及以上版本支持referrer归因，如果您使用该功能，请集成请Android SDK 6.6.0.300或以上版本。集成SDK及接入分析服务操作详情请参见[开发流程](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-dev-process-0000001050163813#section15960539132113)。
* 快应用需要将SDK升级到6.4.1.300及以上版本，才能正常回传转化事件。集成SDK及接入分析服务操作详情请参见[开发流程](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-dev-process-0000001077610568#section15960539132113)。
* 如果您应用的数据处理地为"中国"，您需要开通多数据处理位置方可使用该功能，开通多数据处理位置操作详情请参见[多数据处理位置使用指导](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/multi-storage-0000001206082423)。

## 配置流程

1. 在"事件管理"页面中，将想要回传的事件标记为转化事件。详情请参见[标记转化事件](#section445055275912)。
2. 在"事件管理"页面中的"配置转化事件回传"下，通过页面右侧的"新增"按钮，进入配置回传转化事件页面，配置回传转化事件的相关信息。详情请参见[配置回传转化事件](#section9933121812545)。
3. 在"营销活动"页面查看归因分析报告。详情请参见[查看营销活动报告](#section1762132210442)。

### 标记转化事件

1. 选择"华为分析 > 管理 > 事件管理"进入事件管理页面。
2. 将需要回传的事件标记为转化事件。

### 配置回传转化事件

1. 选择"配置转化事件回传"页签。
2. 点击页面右侧的"新增"按钮，进入配置回传转化事件页面。
3. 配置回传转化事件相关信息。

   1. 选择平台：选择"鲸鸿动能广告"。
   2. 选择应用：选择需要配置回传事件的应用的名称（支持输入应用名称搜索）。
   3. （可不配置）在选择回传事件下方，配置分析服务事件与广告事件的映射关系。 说明
      > * 分析服务与鲸鸿动能广告部分事件已有默认映射关系，无需再次配置，且已默认勾选回传。如果默认映射的事件不能满足您的需求，您也可以手动配置华为分析服务与鲸鸿动能广告事件的映射关系，无默认映射关系的事件，可在"配置广告事件"列选择广告事件，配置分析服务与鲸鸿动能广告事件的映射关系。
      > * 如果您配置了转化事件回传至鲸鸿动能广告，系统将同时回传次日留存、3日留存、7日留存相关数据。
   4. 勾选需要回传的事件前面的复选框（仅无默认映射关系的需要手动勾选，有默认映射关系的已自动勾选）。
   5. 点击"保存"，完成配置。

### 关闭转化事件回传开关

配置完回传转化事件后，已配置的应用转化事件回传开关默认是开启的，如果您不想回传转化事件，可以选择关闭转化事件回传开关。
> 说明
>
> "转化事件回传开关"关闭时转化事件将不再同步到广告网络。

1. 选择"配置转化事件回传"页签。
2. 点击应用所在行的"转化事件回传开关"，开启或关闭该应用下转化事件回传功能。

### 查看营销活动报告

1. 选择"华为分析 > 营销分析 > 营销活动"进入营销活动页面。

   页面提供营销渠道、广告系列、广告任务维度查看的归因报告，衡量不同营销渠道、广告系列、广告任务带来的转化数据以及相关信息。

2. 查看对应营销活动的归因分析报告。
