# 卸载概览

#### 功能概述

App运营既要重视用户增长，又要重视用户流失。华为卸载分析功能通过分析卸载人群在卸载App前发生的事件详情，洞察人群属性，分析卸载场景。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115235.65301504307600183271038632328054:50001231000000:2800:05D384CD207F602A9EE42BB031E56AC3585B93F487910431800CB80C18750FF5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
卸载概览报告中指标按照设备ID进行统计。  

#### 前提条件

当前项目下包含Android应用。  

#### 典型应用场景

优化运营措施，预防用户流失。  

#### 功能详述

#### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 \> 卸载分析 \> 卸载概览"进入报告页面。
4. 查看卸载概览，掌握整体卸载情况。

   该页面展示了昨日新增用户数、昨日卸载用户数、7日新增用户数、7日卸载用户数等指标。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115235.87619739196069909675180388651254:50001231000000:2800:F335238FF47E55716B4E57ECB65E8DAE3F6CBD2300DA28AE22EB3A65A18E83E1.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")  

   |指标|指标说明|
   |:--------|:---------------|
   |新增用户数（昨日）|统计当前日期前一日的新增用户数。|
   |卸载用户数（昨日）|统计当前日期前一日的卸载用户数。|
   |新增用户数（7日）|统计当前日期前七日的新增用户数。|
   |卸载用户数（7日）|统计当前日期前七日的卸载用户数。|

5. 查看卸载趋势卡片。  
   该卡片展示了所选时间段内卸载人群的变化趋势，可按照应用版本、渠道、操作系统版本、机型维度查看。
   * 点击卸载趋势图中的任一曲线，曲线图下方展示该曲线对应的卸载数据详情。
   * 点击"下载"可导出数据详情的csv文件。
   * 卸载趋势图和卸载详情数据表格支持过滤器和时间选择，且支持按日/周/月维度查询。
