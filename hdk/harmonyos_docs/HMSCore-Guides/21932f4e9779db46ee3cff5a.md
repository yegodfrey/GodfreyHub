# 获取Service Open ID

> 说明
>
> 集成意图数据共享之前，请[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)联系华为支撑人员。

## 导入接口类

```screen
import com.huawei.hms.kit.awareness.Awareness;
import com.huawei.hms.kit.awareness.DonateClient;
```

## 能力开发

1. 获取Awareness Kit的"DonateClient"。

   ```screen
   import com.huawei.hms.kit.awareness.DonateClient;
   ```

2. 通过"DonateClient"调用接口获取Serivce Open Id。
3. 根据返回结果，进行应用的业务处理。

   ```screen
   "Java"    
   DonateClient client = Awareness.getDonateClient(getBaseContext());
   client.getServiceOpenId(false) // 使用缓存的ServiceOpenId，如果没有缓存获取一个新的ServiceOpenId
       .addOnSuccessListener(response -> {
           // success
           ServiceOpenIdStatus status = response.getSidStatus();
           String sid = status.getSid();
       }).addOnFailureListener(error -> {
           // failure
           Toast.makeText(getBaseContext(), "get service open id fail!", Toast.LENGTH_SHORT).show();
       });
   ```

   ```screen
   "Kotlin"
   val client: DonateClient = Awareness.getDonateClient(getBaseContext())
   client.getServiceOpenId(false) // 使用缓存的ServiceOpenId，如果没有缓存获取一个新的ServiceOpenId
       .addOnSuccessListener { response ->
           // success
           val status: ServiceOpenIdStatus = response.getSidStatus()
           val sid: String = status.getSid()
       }.addOnFailureListener { error ->
           // failure
           Toast.makeText(getBaseContext(), "get service open id fail!", Toast.LENGTH_SHORT).show()
       }
   ```
