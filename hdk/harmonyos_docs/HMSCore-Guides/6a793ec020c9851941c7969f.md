# 周边搜索

#### 概览

通过用户传入自己的位置，可以返回周边地点列表，继而通过获取到的SiteID，可以查询该地点的详细信息。

<br />

#### 使用约束

最多返回500条记录。  

#### 实现步骤

1. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchservicefactory-0000001050154715)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)实例。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506195616.52499618109624544298144654839975:50001231000000:2800:11592885A9DD93038857A8E53C3525981D6D268D8A7E6ABD8FB7CFA5643D0E52.png)  
   创建SearchService实例需要传入Context类型参数和API密钥。Context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API密钥是您在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API密钥，注意使用时需要调用URLEncoder.encode("Your apiKey", "UTF-8")方法对API密钥进行encodeURI编码。

   <br />

2. 构建[NearbySearchRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-nearbysearchrequest-0000001050154749)对象，它是周边搜索的请求体。其中location是必选参数，其余可选：

   <br />

   * location：用户当前的位置。
   * radius：搜索半径，单位：米。取值范围：\[1, 50000\]，默认1000米。该参数将结果限制在搜索半径内。
   * query：输入搜索关键字。
   * poiType：返回指定POI类型的地点，取值范围参见[LocationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-locationtype-0000001050154741)。推荐使用hwPoiType。
   * hwPoiType：返回指定华为POI类型的地点，取值范围参见[HwLocationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hwlocationtype-0000001050154745)，推荐使用该类型。
   * language：搜索结果的语种，取值范围参见[支持的语言](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/language-mapping-0000001050162856)的语种代码。如果不指定语种，返回英语，如果没有英语，返回当地语言。
   * pageSize：每页返回的记录数。取值范围：\[1, 20\]，默认20。
   * pageIndex：当前页数。取值范围：\[1, 500\]，默认1。
   * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家/地区码，该参数已废弃。
   * strictBounds：是否严格限制在location+radius内搜索，默认值为true，可通过设置该参数为false得到搜索半径以外的结果。  
     ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506195616.48588473325190946357276986718496:50001231000000:2800:0857B477E55E07D9A77DB4E81E3D17447309EF11C5DE4A0391ED501A0D914D2B.png)  
     * 如果同时设置了poiType和hwPoiType，搜索结果优先符合hwPoiType。
     * 要求：pageIndex \* pageSize \<= 500

   <br />

3. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象，该对象用来侦听搜索结果。
4. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象调用[nearbySearch](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711#section1568363543517)()接口，传入第2步创建的[NearbySearchRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-nearbysearchrequest-0000001050154749)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象。
5. 通过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象获取搜索结果[NearbySearchResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-nearbysearchresponse-0000001050154753)对象。通过[NearbySearchResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-nearbysearchresponse-0000001050154753)对象，可以获取[Site](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781)列表，进而解析具体的地址信息。

示例代码如下：

```
"Java"
// 声明SearchService对象 
private SearchService searchService; 
// 创建SearchService实例 
searchService = SearchServiceFactory.create(this, "API key");
// 创建请求体 
NearbySearchRequest request = new NearbySearchRequest(); 
Coordinate location = new Coordinate(41.88905568, 12.4942679); 
request.setLocation(location); 
request.setQuery("stazione di pomezia"); 
request.setRadius(5000); 
request.setHwPoiType(HwLocationType.NATIONAL_RAILWAY_STATION);
request.setLanguage("en"); 
request.setPageIndex(1); 
request.setPageSize(5); 
request.setStrictBounds(false);
// 创建搜索结果侦听器 
SearchResultListener<NearbySearchResponse> resultListener = new SearchResultListener<NearbySearchResponse>() { 
    // 正常结果返回 
    @Override 
    public void onSearchResult(NearbySearchResponse results) { 
        if (results == null || results.getTotalCount() <= 0) { 
            return; 
        }
        List<Site> sites = results.getSites();
        if(sites == null || sites.size() == 0){
            return;
        }
        for (Site site : sites) { 
            Log.i("TAG", String.format("siteId: '%s', name: %s\r\n", site.getSiteId(), site.getName())); 
        } 
    } 
    // 异常结果返回 
    @Override 
    public void onSearchError(SearchStatus status) { 
        Log.i("TAG", "Error : " + status.getErrorCode() + " " + status.getErrorMessage()); 
    } 
}; 
// 调用周边搜索接口 
searchService.nearbySearch(request, resultListener);
```

```
"Kotlin"
// 声明SearchService对象
val searchService: SearchService
// 创建SearchService实例
searchService = SearchServiceFactory.create(this, "API key")
// 创建请求体
val request = NearbySearchRequest()
val location = Coordinate(41.88905568, 12.4942679)
request.location = location
request.query = "stazione di pomezia"
request.radius = 5000
request.hwPoiType = HwLocationType.NATIONAL_RAILWAY_STATION
request.language = "en"
request.pageIndex = 1
request.pageSize = 5
request.strictBounds = false
// 创建搜索结果侦听器
val resultListener: SearchResultListener<NearbySearchResponse> = object : SearchResultListener<NearbySearchResponse> {
    // 正常结果返回
    override fun onSearchResult(results: NearbySearchResponse?) {
        if (results == null || results.getTotalCount() <= 0) {
            return
        }
        val sites: List<Site>? = results.getSites()
        if (sites == null || sites.isEmpty()) {
            return
        }
        for (site in sites) {
            Log.i("TAG", "siteId: ${site.getSiteId()}, name: ${site.getName()}")
        }
    }
    // 异常结果返回
    override fun onSearchError(status: SearchStatus) {
        Log.i("TAG", "Error : ${status.getErrorCode()}  ${status.getErrorMessage()}")
    }
}
// 调用周边搜索接口
searchService.nearbySearch(request, resultListener)
```
