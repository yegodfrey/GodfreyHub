# 创建地图实例

#### 设置国家码

初始化地图前，可以设置国家码：

使用[HMapService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmapservice-0000001241774031)的setCountryCode方法设置国家码，如果未设置，将以IP自动判断国家码。  

#### 地图容器

目前地图SDK支持的地图容器为[HMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmapview-0000001191938980)。[HMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmapview-0000001191938980)是iOS UIView类的子类，允许您将地图放置在iOS视图中。MapView充当地图的容器。  

#### MapView

1. 在ViewController中创建地图。

   <br />

   ```
   self.mapView = [[HMapView alloc] initWithFrame:CGRectMake(0, 0, CGRectGetWidth(self.view.frame), CGRectGetHeight(self.view.frame) - CGRectGetMinY(self.navigationController.navigationBar.frame))
   self.mapView.delegate = self; 
   self.mapView.centerCoordinate = CLLocationCoordinate2DMake(48.893478, 2.334595); 
   [self.view addSubview:self.mapView]; 
   self.mapView.showsScale = false; 
   ```

   <br />
