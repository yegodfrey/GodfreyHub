# 场景化示例

#### 导入GTM配置文件

为方便您在DTM上直接引用GTM的配置策略，您可以将GTM配置文件导出后，直接导入DTM，从而简化工作量。

GTM导出文件包括：预设变量、自定义变量、条件、代码和分组信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/s3fdZsWCQguY5NRZ2DH9og/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=E8DE8B8D5EDA30F78CE5B9631988BE276C8B30DDDB315EA7FB3E12C72E7D1294)

若分组为空，则分组信息不会被导出。

                1. 登录[Google Tag Manager](https://tagmanager.google.com/)网站，导出JSON配置文件，具体步骤请参见[容器导出和导入](https://support.google.com/tagmanager/answer/6106997?hl=zh-Hans&ref_topic=9002095)。
                2. 在DTM的“配置”页面，点击“导入”按钮。
                3. 选择本地待导入的JSON文件并选中导入策略，点击“导入”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/0EsG9EuVQs2Hg3RaLT3IUQ/zh-cn_image_0000001130549475.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=F29F21BC39CBAACF55070F953DA8C8423F94A66D90801771EEC38ECF4E66BC4C)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/89/v3/DFsuCMaURquvwY19Li5Wyw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=EE6756208AC38932C35EEDD7697EF64424DCBEC8E91AB7A56D446C8A79FC8BBF)

GTM配置文件导入时，JSON文件名必须以“GTM-”开头。

                4. 查看导入结果。

                   * 导入成功，无需操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/JzdUwpk8TQqo4h3IveQ-rg/zh-cn_image_0000001084170462.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=309E8A51278D7AB17A4AC25BC5284B943DF5755CBA9E49AAA3CC3803464F7390)

                   * 系统弹出“忽略列表”，点击“确定”或关闭弹框后，则导入成功。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/euuz5k0ASCKzcN8GfhfuwA/zh-cn_image_0000001130688273.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=B074074F8CDE576451D1EDDEBF2223486F9AA31D2294D04FAE0D9C4123373422)

对于GTM配置文件中，有如下情况的，DTM导入时提示忽略信息。 

资源类型 | 忽略原因  
---|---  
预设变量 | 在DTM中无对应预设变量类型。  
自定义变量 | 
                     * 在DTM中无对应变量类型。
                     * 在DTM中有对应变量类型，但引用了被忽略的变量。
                     * 与DTM中参数不一致。  
条件 | 
                     * 在DTM中无对应条件类型。
                     * 在DTM中有对应条件类型，但引用了被忽略的变量。
                     * 与DTM中参数不一致。  
代码 | 
                     * 在DTM中无对应代码类型。
                     * 在DTM中有对应代码类型，但引用了被忽略的变量或条件。
                     * 与DTM中参数不一致。  
  
                   * 系统提示导入失败，请根据提示信息修改后重新导入。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/OoV3HcSYTEmtkHCb8lcgsg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043135Z&HW-CC-Expire=86400&HW-CC-Sign=68F1CF6A95D0D650E661B61AED6AFA7EB530188B06DEFB143491B72110E0B5E7)

若GTM中的参数与DTM中的规则不匹配（如格式、校验规则或长度等），则导入失败。

#### 导入可视化埋点配置文件

                1. 在DTM的“配置”页面，点击“导入”按钮。
                2. 选择本地待导入的JSON文件并选中导入策略，点击“导入”。

                3. 查看导入结果。

                   * 导入成功，无需操作。

对于配置文件中，有如下情况的，DTM导入时提示忽略信息。

                     * 当用户选择合并，且可视化条件与非可视化条件的名字重复。
                     * 当用户选择合并，且导入文件和数据库中的埋点名称存在重复。

                   * 系统提示导入失败，请根据提示信息修改后重新导入。
