# 构建码生成功能

## 业务流程

使用生成码的主要业务流程如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240709174415.60414266035271216746285338248451:50001231000000:2800:B2EC7006CEB17DD5699934A8164849BBC78AC80367A66FD79590F889555A4A4B.png?needInitFileName=true?needInitFileName=true "点击放大")

1. 用户打开App，输入相关参数。
2. 校验参数是否合法。
3. 参数验证后，调用[HmsMultiFormatWriter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmutiformatwriter-0000001050294896)中"createCodeWithString: size: CodeFormat: error:"生成码接口。
4. 返回生成码结果。
5. App封装生成码结果返回给用户。

## 开发步骤

1. 调用[HmsMultiFormatWriter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmutiformatwriter-0000001050294896)。

   实现方法中的参数，如下：
   * content：生成码的内容。
   * size：生成码的大小，包括码图的宽高，值为CGSize类型。
   * format：码图的类型，包含13种码图类型。
   * error：报错信息。

2. 返回结果UIImage，如下：

   ```screen
   UIImage *image = [HmsMultiFormatWriter createCodeWithString:content size:size CodeFomart:format error:&err];
   ```
