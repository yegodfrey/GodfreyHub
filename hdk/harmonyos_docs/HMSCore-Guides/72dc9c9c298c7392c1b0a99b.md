# 应用包名

## 了解应用包名

当用Android Studio创建一个新的工程时，我们需要填写应用包名。包名命名应符合业界规范，一般而言，一级为com，二级为公司或个人域名或邮箱，三级为应用属性名，四级或以上为应用的功能模块名。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/86j3fe71R5KckqOLQJcsKg/en-us_image_0000002547960423.png?HW-CC-KV=V1&HW-CC-Date=20260909T152021Z&HW-CC-Expire=31536000000&HW-CC-Sign=2799292820B71C1D2C3FE90A30C28849C6F0CE129B4C2BD777B4181C956DC712)

创建工程后，可以看到，工程的文件结构与应用包名相匹配。实际上，软件包名称就是由项目目录结构所定义。如下图，包名为：com.huawei.healthdemoanna。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d6/v3/ycdZaM9RTfamAg4BGZQFpg/zh-cn_image_0000002547960421.png?HW-CC-KV=V1&HW-CC-Date=20260909T152021Z&HW-CC-Expire=31536000000&HW-CC-Sign=9543B1DA6A83391916C5B2C44958F5445BB84E1482EF14111D84A51D663DCE24)

## 修改应用包名

如需修改包名，改为：com.honor.health。

1. 先将huawei修改为honor。操作如下。

   > 说明
   >
   > 如果工程文件在本机电脑中，也可以找到工程文件的位置，直接重命名项目文件夹名。

   把工程中折叠的路径放开，"Compact Middle Packages"项去掉勾选。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/8AKJjESZSeeGc5VXrDthEw/zh-cn_image_0000002547960419.png?HW-CC-KV=V1&HW-CC-Date=20260909T152021Z&HW-CC-Expire=31536000000&HW-CC-Sign=454EB12BFDF47AFEB41CE13A79F679245D89C7B7CC16FF841C5326196F43855D)

   修改包名。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/6qoJO2iaRUSx9yCS1sD7uA/zh-cn_image_0000002547960417.png?HW-CC-KV=V1&HW-CC-Date=20260909T152021Z&HW-CC-Expire=31536000000&HW-CC-Sign=AF90CA442428AC301F5F98CD5F02E3535E3CAED3B7D2B3D6E2C67799D723FB64)


2. 参考上述步骤，继续将healthdemoanna修改为health。
3. 打开AndroidManifest.xml文件，修改package属性为新包名com.honor.health。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/dtpHnPUrRGaRzUenRXkb6g/en-us_image_0000002516520534.png?HW-CC-KV=V1&HW-CC-Date=20260909T152021Z&HW-CC-Expire=31536000000&HW-CC-Sign=AA8749AE2C8D09081E6F242C1E9EA37AB5912FDE4A8DF0929B89E18560CF3591)

4. 打开build.gradle文件，修改applicationId为新包名com.honor.health。然后单击 "Sync Now" 同步。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/Mef6q-O_RteHQVY4u3BZUw/zh-cn_image_0000002516360600.png?HW-CC-KV=V1&HW-CC-Date=20260909T152021Z&HW-CC-Expire=31536000000&HW-CC-Sign=66201EA15EAFFCC72BE5A2E9F04790B3EF695327B622A83ADA91A02D44C54DAA)

5. 为确保修改完整，请单击"Edit > Find >Replace in Path" 把旧的包名全部替换为新的。
6. 单击"Build > Clean Project" 。
