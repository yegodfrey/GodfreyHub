# 最大摄氧量

此数据记录用户的最大摄氧量，每一条数据都代表在一定时间的最大摄氧量。每条数据不能存在交叉，后一条数据的开始时间应该大于前一条数据的结束时间。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 肺功能数据

* 读权限：Scopes.HEALTHKIT_PULMONARY_READ
* 写权限：暂不支持

## 原子采样明细数据类型

* 名称：com.huawei.vo2max
* Android SDK类型常量：DataType.DT_VO2MAX

|**字段**列表|描述|Android SDK常量|**类型**|可选/必选|单位|取值范围|
|:-------|:----|:------------|:-----|:----|:-------|:---|
|vo2max|最大摄氧量|Field.VO2MAX|int|M|毫升/公斤/分钟|-|

### 数据开放说明

|开放API|查询及时性|数据源|
|:-------------------------------------------------------------------------------------------------------------------------------|:----|:-----|
|[读取运动健康数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section0447440145418)|分钟级|手表、手环等|
|[读取最新数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section783193232513)|分钟级|手表、手环等|

> 说明
>
> [读取最新数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section783193232513)接口仅开放最近12个月内的最大摄氧量数据。
