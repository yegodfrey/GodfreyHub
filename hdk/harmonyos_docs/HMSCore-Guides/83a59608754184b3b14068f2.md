**$QuitUserGroup**

事件参数ID | 参数名称 | 参数类型 | 参数描述  
---|---|---|---  
$RoleName | 用户角色 | String | 标识用户的角色。  
$Members | 成员总数 | Long | 用户退出时群组成员总数。  
$UserGroupLevel | 群组等级 | Long | 用户退出的群组等级。  
$UserGroupName | 群组名称 | String | 用户退出的群组名称。  
$UserGroupId | 群组ID | String | 用户退出的群组ID。  
  
**$LosePet**

事件参数ID | 参数名称 | 参数类型 | 参数描述  
---|---|---|---  
$RoleClass | 角色职业 | String | 用户使用的角色职业。  
$Reason | 获取原因 | String | 失去宠物的原因。  
$IsFree | 是否免费 | String | 标识该物品是免费还是付费。
