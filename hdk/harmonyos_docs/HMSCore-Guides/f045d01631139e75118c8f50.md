# （可选）应用包大小优化

当开发者集成Location SDK 6.0.0及以上版本时，可以通过在应用级的"build.gradle"文件配置您的应用无需运行的平台列表来优化您的应用包大小。

1. 打开应用级的"build.gradle"文件。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250508151208.36732370452004946472468456067580:50001231000000:2800:CC7C4581B44F250F7484232BB0BA8148E4824AA2E8AEF06B3801721F3F20D911.png "点击放大")

   <br />

2. 在"android"中新增"packagingOptions"，配置需要删除的运行平台，配置格式如下：

   <br />

   ```
   android {    
       packagingOptions {
           // 删除X86平台依赖的so文件
           exclude "lib/x86/libucs-credential.so"
           // 删除x86_64平台依赖的so文件
           exclude "lib/x86_64/libucs-credential.so"
       } 
   }
   ```

   该声明可以删除Location SDK中，x86和x86_64平台的so文件，预计可减少约360KB的包大小。

   <br />
