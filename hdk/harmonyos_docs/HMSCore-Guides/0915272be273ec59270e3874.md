# 游戏服务术语表

|名词|解释|
|:---|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|应用助手|"应用助手"是为您提供应用使用辅助服务的应用，所提供的服务由华为或第三方开发。您可进入"游戏空间"，添加、移除所支持的游戏，加入游戏空间的游戏应用可获得应用助手所提供的游戏辅助服务。为了便于您专注体验游戏，我们集成了系统的常用设置和应用辅助功能开关，比如，当您玩游戏时，您可以轻松体验消息免打扰、游戏加速、按键防误触等辅助服务。|
