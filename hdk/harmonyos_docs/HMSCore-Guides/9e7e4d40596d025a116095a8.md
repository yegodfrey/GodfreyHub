# 概览

您可以通过控制地图手势开关以及内置UI控件的可见性，自定义用户与地图交互方式。参见[Android示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-0000001050162104)工程中的[CameraDemoActivity.java](https://github.com/HMS-Core/hms-mapkit-demo-java/blob/master/java/app/src/main/java/com/huawei/hms/maps/sample/CameraDemoActivity.java)、[GestureDemoActivity.java](https://github.com/HMS-Core/hms-mapkit-demo-java/blob/master/java/app/src/main/java/com/huawei/hms/maps/sample/GestureDemoActivity.java)等文件。
