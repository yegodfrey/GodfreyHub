# 批量操作

#### 场景介绍

华为云空间服务支持您的应用对某些接口进行批量操作，具体接口如下：文件（夹）的批量操作，如创建文件夹、创建文件元数据、复制、更新、删除、订阅等，评论及回复的批量操作，如评论及回复的新增、更新、删除等。  

#### 构造Drive对象

调用[Drive.Builder.build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-builder-0000001050124056#section17968156193912)接口构造Drive对象。

```
private Drive buildDrive() {   
    Drive service = new Drive.Builder(CredentialManager.getInstance().getCredential(), context).build();   
    return service;   
}
```

#### 完成批量操作

创建JsonBatchCallback回调对象，调用Drive的batch函数获取BatchRequest对象，再调用Files.Create的queue函数将操作添加到队列中，再执行[BatchRequest.execute](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-batchrequest-0000001050126045#section1043021114712)即可完成批量操作。

```
/**
 * 批量创建回调
 */  
JsonBatchCallback<File> callback = new JsonBatchCallback<File>() {
    @Override
    public void onFailure(JsonError e, HttpHeaders responseHeaders) throws IOException {
        Logger.i(TAG, "callback error: " + e.toString());
    }
 
    @Override
    public void onSuccess(File file, HttpHeaders responseHeaders) throws IOException {
        Logger.i(TAG, "callback successful: " + file.toString());
    }
};

/**
 * 批量创建目录
 */  
private void batchCreateDirectory() {
    Drive drive = buildDrive();
    BatchRequest batch = drive.batch();
    try {
        for (int i = 0; i < 2; i++) {
            Map<String, String> appProperties = new HashMap<>();
            appProperties.put("appProperties", "property");
            SimpleDateFormat formatter = new SimpleDateFormat("yyyyMMdd_HHmmss_SSS");
            String dirName = formatter.format(new Date()) + "_" + i;
            Logger.i(TAG, "executeFilesCreate: " + dirName);
 
            File file = new File();
            file.setFileName(dirName)
                    .setAppSettings(appProperties)
                    .setMimeType("application/vnd.huawei-apps.folder");
            Drive.Files.Create create = drive.files().create(file);
            create.queue(batch, callback);
        }
        batch.execute();
    } catch (Exception e) {
        Logger.e(TAG, "batchCreateDirectory error: " + e.toString());
    }
} 
```
