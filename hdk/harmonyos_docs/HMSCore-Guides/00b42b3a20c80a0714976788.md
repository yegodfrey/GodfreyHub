# 防范欺诈和滥用行为的措施

为更好的防范恶意用户的欺诈和滥用行为，您应该利用好本节介绍的建议，减少恶意用户的欺诈和滥用行为对您的应用带来的不利影响。  

#### 将敏感逻辑移至后端服务器

前端设备更容易遭到修改或篡改，在合理的设计内，建议您尽可能将敏感数据和业务逻辑放在您的后端服务器。此外，如果发现了安全或漏洞等问题，在后端服务器端进行修复和发布也会更加方便。  

#### 在授予权益前验证购买交易

1. 建议您在发放权益前验证购买信息，确保在您的服务器端处理敏感数据和业务逻辑，并使用我们的服务端接口（订单：[Order服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/order-verify-purchase-token-0000001050033078)；订阅：[Subscription服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/subscription-verify-purchase-token-0000001050035029)）获取购买信息，服务器端API可以针对网络不佳和恶意攻击等问题提供多一层保护。
2. orderId、payOrderId、 purchaseToken、subscriptionId（订阅特有标识）是标明交易收据唯一性的最关键的4个字段（4者关系见图示）。如果用于发货唯一性判断，我们建议使用payOrderId作为唯一性判断的主键。每一个payOrderId都实际对应一笔支付订单，因此仅能发放一次此次购买对应的权益。payOrderId是全局唯一的，可以作为数据库主键。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135207.87934899851237603047536500068160:50001231000000:2800:A74632E280A75FCF299AB413F217ECFCE97D01A549FE1B9514DAF3C09EC28922.png)

3. payOrderId仅能标明订单的唯一性，如需发货，请确保校验订单状态为已支付状态，并同步校验productId、price、currency等关键字段是否与您的预期一致，详情请参见[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。
4. 订单场景下，请根据[Order服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/order-verify-purchase-token-0000001050033078)接口响应中购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)的purchaseState字段决定是否发货。若purchaseState为0，则执行发货操作。
5. 订阅场景下，请根据[Subscription服务验证购买Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/subscription-verify-purchase-token-0000001050035029)接口响应中购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)的subIsvalid字段决定是否发货。若subIsvalid为true，则执行发货操作。  

#### IAP 2.0切换IAP 4.0注意事项

为了兼容纯客户端应用，华为IAP的安全校验方式从商户私钥签名切换为公钥验签。因此，IAP 4.0对于订单信息的验证，相比IAP 2.0更为重要，特别是productId、price、currency等关键字段，详情请参见[在授予权益前验证购买交易](#section89611254175714)。

同时，请参见[developerPayload处理机制及使用建议](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/key-parameters-0000001354668057#section499104010513)，确保权益能否准确无误的发放给对应的用户。
