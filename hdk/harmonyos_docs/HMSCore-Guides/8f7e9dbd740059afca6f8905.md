# 提交测试报告进行准入认证

1. 登录华为开发者联盟，在"智慧生活"下点击"运动健康（设备接入）"，查看素材资源审核结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/9qMqVMq-SkGKnrVNjMxdhQ/zh-cn_image_0000001453324330.png?HW-CC-KV=V1&HW-CC-Date=20261008T150056Z&HW-CC-Expire=31536000000&HW-CC-Sign=3925CB53F05ECB798A60E53836AC3859D9FF80E566EA74B58F2C766EACCBC3BD "点击放大")

2. 若素材资源审核通过，点击"产品认证"进入认证报告提交界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/aXPif5DERy-VhoQfIpLoZg/zh-cn_image_0000001502884361.png?HW-CC-KV=V1&HW-CC-Date=20261008T150056Z&HW-CC-Expire=31536000000&HW-CC-Sign=E6B4E61EF39AEA3335704BDD6621CA1DB9E6120CB6CEA5911E4781967D6C914D "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/-g7oLARHR0i2jxLVmdHoWQ/zh-cn_image_0000001503004037.png?HW-CC-KV=V1&HW-CC-Date=20261008T150056Z&HW-CC-Expire=31536000000&HW-CC-Sign=0E9C8ABD71DDF2C808ED1B44BFCC8A0F429155A9E40931471633A6D0C4729C32 "点击放大")

3. 根据界面提示，上传设备实物拍照图（正面、侧面、底部）、自测试报告、样机快递单号。

   > 说明
   >
   > 自测试报告需要提供送测设备的基本信息，如：产品型号、产品版本、芯海SDK版本、蓝牙芯片、称重芯片、测脂芯片、产品固件版本、产品硬件版本等。具体可以参考华为提供的测试报告模板。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/XybSM_o3Tomjs_l-96l7Dg/zh-cn_image_0000001453324334.png?HW-CC-KV=V1&HW-CC-Date=20261008T150056Z&HW-CC-Expire=31536000000&HW-CC-Sign=7C2877A5DA581768B9E9B098EF4E0AF5DC347DB1CBC55BBAC2BCC1EEE597C80B "点击放大")

   样机需求如下表，点击"样机寄送地址"旁边的提示符![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2a/v3/yYOen5snQP-gRFLNQTYr0w/zh-cn_image_0000001453484262.png?HW-CC-KV=V1&HW-CC-Date=20261008T150056Z&HW-CC-Expire=31536000000&HW-CC-Sign=70BC62B803DBC52BD5F47F47ACC5B5F6A9194373449546F112A394E60DB8C54D)，可以获取投递地址及收件人。

   |样机用途|数量|
   |:--------------------------|:-|
   |小件设备，如：跳绳、体脂秤、血糖仪、血压计、心率设备|2|
   |大件设备，如：跑步机、椭圆机、划船机、智能单车、走步机|1|

   对于跑步机接入，需要提交第三方认证机构进行准入认证。在界面上选择认证机构后（赛西实验室或泰尔实验室），会显示认证机构的联系方式及报价单，可与对应机构联系人进行业务对接。请厂商根据实际需要选定认证机构。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/-FhyISZETxyuUHeoGYVrvA/zh-cn_image_0000001453164582.png?HW-CC-KV=V1&HW-CC-Date=20261008T150056Z&HW-CC-Expire=31536000000&HW-CC-Sign=4D66619CF2E1B31E525764CA5FBDF94C08AB9CB468F796A455792D474C2E4614 "点击放大")

4. 提交审核后，等待认证结果。点击图示红框图标可查看审核进度和结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c1/v3/46_94ocbSz27_WJZCFnp5g/zh-cn_image_0000001502884353.png?HW-CC-KV=V1&HW-CC-Date=20261008T150056Z&HW-CC-Expire=31536000000&HW-CC-Sign=E357BDA402925D25713B2546BABA89FBBE1F6D37420F7CCA1B094F5D863B6C45 "点击放大")
