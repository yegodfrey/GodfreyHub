# 操作流程

#### 创建版本

    1. 选择“工作区”页签，点击“创建版本”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/30/v3/xzsshut1T224-NP2Tyx3Vw/zh-cn_image_0000001131511380.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=82531E0C0F278AE3F4F9E63598BD300FFE75D5B71749FD1FE99982604B9DFBC3)

    2. 在“创建版本”页面输入版本名称和描述后，选择“创建版本”或“创建并发布此版本”，点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/Rv5ROrdZSbmgbJgiqQpaQw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=360CB1E54E247EE040799ABC6186420E0BE5D9274EC563CD89403548D6FD4E31)

若您需要在创建版本的同时，发布该版本，请选择“创建并发布此版本”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/DMieFoyQRsKzbPNsxEMx0g/zh-cn_image_0000001177510893.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=20BD4E498284751E83C8B0B8ECD91E53FE0400D3949CDC9BED239DF13AF57143)

    3. 若您选择“创建版本”，则系统跳转至“版本详情”页面，您可以查看已创建的版本详情。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f8/v3/ykVIRz68T7eepFb5fvoFAw/zh-cn_image_0000001177550797.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=3C44B32B96D7AC79F3BB459C29F50122B6B0746C574D41EABC198FDEA7220931)

    4. 若您选择“创建并发布此版本”，则系统跳转至“版本详情”页面，且提示版本发布成功，您可以查看已创建的版本详情。

#### 预览草稿版本

在可视化埋点、代码、条件、变量或是分组中进行新建、修改或是删除操作后，您可以在“工作区”页面，点击“预览”，查看实时的配置信息，详情请参见[预览版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-version-management-operation-procedure-0000001077092116#section35141828537)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/JEFC3lVlTIWcvAW5Pqs8ng/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=BFCAEA7502C5F56E7DBC2258AA65D61B6FE40B60957BE570C4ACA17C976FC05F)

通过“工作区 > 预览”与“版本 > 版本详情 > 预览”的功能差异如下：

    * “工作区 > 预览”：您可以预览当前的草稿版本，即当前工作区内实时的配置信息。
    * “版本 > 版本详情 > 预览”：您可以预览当前创建的正式版本，预览内容仅为指定版本的配置信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/_nGfCEjuRrqFnWBbWEVvmw/zh-cn_image_0000001131671148.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=CB135D78F3ACB2A4419E815FA3FD7AB03224D012C043268A87E422EC2DEE56E9)

#### 变更

#### [h2]变更详情

    1. 在可视化埋点、代码、条件或变量中进行新建、修改或是删除操作后，您可以在“概览”页面中，看到变更记录。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/twP7U5h8RDSI2dyUpgDrnw/zh-cn_image_0000001077090008.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=F5DB1F4D7AAF26735C90EA5707AEE4BC53F17DAFA8C850109EAFF4EF78B27202)

    2. 点击“变更”栏下变更类型的名称进入“查看详情”页面，查看当前状态。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f9/v3/qLJ2XAGTT3qhw5Uu-2wruA/zh-cn_image_0000001077249984.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=C398561AE04AC16F8805E603ACB93982A6E5F3BA77E406914079BEF4FC0ACB93)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/Yvp3c8e7RFKgsbD9_e36wQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=FE5DD10053F28E46118BE1F74EF1E317424D80A263BA65FE69CD050BD683FB67)

若“更改”类型为“删除”，则不可点击。

#### [h2]查看变更

通过点击“查看变更”查看历史修改记录，即当前版本与当前草稿中变量、条件或是代码的差异性对比。

    1. 在“版本”中，点击“创建版本”，设置“版本名称”和“版本描述”，点击“保存”。
    2. 在“版本”中，选择所需版本，在“版本详情”页面，点击“发布”。
    3. 对已发布版本中，存在的可视化埋点、代码、条件或变量进行修改操作，修改完毕后选择“工作区 > 概览”，在该可视化埋点、代码、条件或变量名称的右边点击“查看变更”。
    4. 进入“查看变更”页面，通过比较“最新版本”和“当前草稿”，可以看到哪些内容进行了更改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/BLKi2eaUSYOw21XmvEjFkw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=48316A3EB9427EC69D45C156B6276A62D4A6AB28A04BAA997FA60B0CE33860BC)

若“更改”类型为“新增”或“删除”的预设变量，则没有查看变更的功能。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ce/v3/5PWTY0g_RoaxQswJH6yxVg/zh-cn_image_0000001089763993.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=55A9A90CA47EF1D52DB5D75401B778A939B3B2D85DE7605D93EA7A8D3AC4322C)

#### 操作记录

在可视化埋点、代码、条件、变量或是分组中进行新建、修改或是删除操作，然后点击“概览”页面，滑至操作记录，可以看到具体时间的操作行为。此外，您还可以将操作记录导出为Excel文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/AwX3LO55RNCc1NzI73xuMQ/zh-cn_image_0000001090021395.png?HW-CC-KV=V1&HW-CC-Date=20261005T042950Z&HW-CC-Expire=86400&HW-CC-Sign=ACC3CE61FED96B29A36D1BD28AA602DB61DF398BB9A5113B037581EE05BD6E6B)
