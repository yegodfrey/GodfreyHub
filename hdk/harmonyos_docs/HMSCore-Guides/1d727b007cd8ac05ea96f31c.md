# 游戏升级

## 场景介绍

在应用启动完成后或用户在应用中主动检查应用新版本时，应用需要调用HMS Core SDK的升级接口检测华为应用市场是否有新版本应用。如果需要升级，HMS Core SDK将拉起升级提示框提示用户在华为应用市场升级应用。用户可以点击"立即更新"直接升级游戏，或点击"以后再说"继续访问老版本游戏。
> 说明
>
> 智慧屏游戏当前不支持强制升级。

## 前提条件

必须在[JosAppsClient.init(AppParams appParams)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)方法调用成功后再实现游戏升级功能，init方法调用请参考[初始化](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-dev-tv-login-0000001461311313#section984144110340)。

## 开发步骤

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250212154819.14720157808557353846082842199910:50001231000000:2800:DAE302A9603A3B1B44B2F1C0DF6F62C648DA5A07E93D07C5C9E755EC97F96C06.png?needInitFileName=true?needInitFileName=true "点击放大")

本功能涉及的关键开发步骤如下：

1. 调用[JosApps.getJosAppsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josapps-0000001050123631#section162141030162218)方法初始化[AppUpdateClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641)对象，并调用[AppUpdateClient.checkAppUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641#section15712187193218)方法请求检查应用是否有更新。

   ```screen
   public void checkUpdate() {
       AppUpdateClient client = JosApps.getAppUpdateClient(this);
       client.checkAppUpdate(this, callback);
   }
   ```


2. SDK通过回调方式将检查结果返回给应用，应用从回调结果中onUpdateInfo方法返回的[ApkUpgradeInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/apkupgradeinfo-0000001050121688#section772111184216)实例确认应用是否有更新。如果有新版本，则调[AppUpdateClient.showUpdateDialog](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/appupdateclient-0000001050123641#section1113567144514)方法请求拉起升级提示页面。

   ```screen
   private static class Callback implements CheckUpdateCallBack {
       private WeakReference<Context> mContextWeakReference;
       public Callback(Context context) {
           mContextWeakReference = new WeakReference<>(context);
       }
       @Override
       public void onUpdateInfo(Intent intent) {
           if (intent != null) {
               // 更新状态信息
               int status = intent.getIntExtra(UpdateKey.STATUS, -99);
               Log.i(TAG, "check update status is:" + status);
               // 错误码
               int rtnCode = intent.getIntExtra(UpdateKey.FAIL_CODE, -99);
               // 失败信息
               String rtnMessage = intent.getStringExtra(UpdateKey.FAIL_REASON);
               // 强制升级游戏时，弹出对话框后用户是否点击"退出应用"按钮。当前暂不支持强制升级，建议您保留如下代码，后续支持强制升级后，可无需更新客户端版本。
               boolean isExit = intent.getBooleanExtra(UpdateKey.MUST_UPDATE, false);
               Log.i(TAG, "rtnCode = " + rtnCode + "rtnMessage = " + rtnMessage);

               Serializable info = intent.getSerializableExtra(UpdateKey.INFO);
               // 如果info属于ApkUpgradeInfo类型，则拉起更新弹框
               if (info instanceof ApkUpgradeInfo) {
                   Context context = mContextWeakReference.get();
                   if (context != null) {
                       // showUpdateDialog接口中最后一个字段建议您传入false
                       JosApps.getAppUpdateClient(context).showUpdateDialog(context,(ApkUpgradeInfo) info,false);
                   }
                   Log.i(TAG, "check update success and there is a new update");
               }
               Log.i(TAG, "check update isExit=" + isExit);
               if (isExit) {
                   // 强制升级应用时，用户在弹出的升级提示框中选择了"退出应用"，处理逻辑由您自行控制，这里只是举例。当前暂不支持强制升级，建议您保留如下代码。
                   System.exit(0);
               }
           }
       }

       @Override
       public void onMarketInstallInfo(Intent intent) {

       }

       @Override
       public void onMarketStoreError(int i) {

       }

       @Override
       public void onUpdateStoreError(int i) {

       }
   }
   ```
