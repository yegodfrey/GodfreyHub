# "添加到华为钱包"按钮样式

* 大小 调整"添加到华为钱包"按钮的高度和宽度以适合您的版式。如果页面上还有其他按钮，"添加到华为钱包"按钮的大小必须大于或等于这些按钮的大小。不要将"添加到华为钱包"按钮的大小设置为小于其他按钮。

* 样式 "添加到华为钱包"按钮目前只有一种黑色样式。

  ![](https://media:101782807009661580)  

  |组合部分|颜色|尺寸|
  |:-------|:------------|:------|
  |背景|颜色： #FF1D1D1E|圆角：16px|
  |华为钱包logo|-|-|
  |字体|颜色： #FFFFFFFF|大小：64px|
  |分隔线|颜色： #61FFFFFF|宽度：2px|
