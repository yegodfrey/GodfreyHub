# "添加到华为钱包"按钮样式

* 大小 调整"添加到华为钱包"按钮的高度和宽度以适合您的版式。如果页面上还有其他按钮，"添加到华为钱包"按钮的大小必须大于或等于这些按钮的大小。不要将"添加到华为钱包"按钮的大小设置为小于其他按钮。

* 样式 "添加到华为钱包"按钮目前只有一种黑色样式。
