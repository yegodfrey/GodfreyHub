# 获取延迟DeepLink

#### 使用场景

当用户点击您的应用中投放的广告时，深度链接能够将已安装目标应用的用户引导到目标应用的特定页面。可是，如果用户点击广告时还没有安装目标应用，那该如何跳转？在这种场景下，可以设置延迟深度链接。用户点击广告内容后，首先会跳转到华为应用市场进行应用下载。下载完成并打开应用后，即可跳转到目标页面。要使用延迟深度链接，您的应用需要集成ads-installreferrer SDK。  

#### 注意事项

请确保应用已集成ads-installreferrer SDK。具体操作请参见"[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-integrating-sdk-0000001050066913)"。  

#### 开发步骤

1. 创建一个深度链接监听器。

   <br />

   调用[DeeplinkClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/deeplinkclient-0000001361239353)(Context context, [OnDeeplinkAcquiredListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ondeeplinkacruiredlistener-0000001361522561) listener)方法创建[DeeplinkClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/deeplinkclient-0000001361239353)实例，实现[OnDeeplinkAcquiredListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ondeeplinkacruiredlistener-0000001361522561)的launchDeeplink方法，调用[DeeplinkClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/deeplinkclient-0000001361239353)的request方法获取深度链接，然后触发launchDeeplink回调。示例代码如下：

   ```
           DeeplinkClient deeplinkClient = new DeeplinkClient(this, new OnDeeplinkAcquiredListener() {
               @Override
               public boolean launchDeeplink(Uri deeplink) {
                   Log.d(TAG, "deeplink is:" + deeplink);
                   return false;
               }
           });
           /**
   * 异步请求深度链接。
           */
           try {
       deeplinkClient.request();
           } catch (Throwable e) {
               Log.i(TAG, "request deeplink exception: " + e.getMessage());
           }
   ```
