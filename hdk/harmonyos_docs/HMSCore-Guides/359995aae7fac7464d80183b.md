# 平台类商户

* 是华为支付为平台商户交易场景提供的支付、结算解决方案，主要面向对商品交易或服务进行线上撮合和管理的平台。
* 平台类商户接入华为支付后，平台上开展交易的商家入驻华为支付，成为子商户。
* 平台类商户可自行前往[华为支付商户平台](https://petalpay-merchant.cloud.huawei.com/) ，合作身份选择"平台类商户"，填写信息后提交入网申请；
* 子商户的入网指导请[点击这里](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-zishanghuruwang-0000001720049550)查阅。
