# 创建服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 选择需要创建会员开放服务的项目，进入"项目设置"页面。
3. 在左侧导航选择"增长 \> 会员开放服务"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220323160004.73956626390112253816991095311859:50530322093902:2800:71195840D577F77E36A379F8EDC116217F4F4D889B159D2A2129EDFF2A07DD39.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 申请创建会员开放服务，具体劵码接入请参见[批次码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/coupon-code-0000001155164139)。
5. 创建完成后，返回会员开放服务，可对所创建的服务进行查看和修改。提交申请后，华为方会进行审批，审批通过后会有通知消息。查看提交申请如下：

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220323160004.36959684136312789310100278357183:50530322093902:2800:FB0E3348AB34CB4B558401156F1A59534CF0AFBAD0EEFF5C4F62539DE2A6787A.png?needInitFileName=true?needInitFileName=true "点击放大")

   创建完成后，卡劵状态的变化如下：  

   |开发者动作|会员运营动作|服务申请状态|卡劵状态|
   |:------|:-------------|:-------|:---|
   |创建后提交申请|NA|待审批|草稿|
   |NA|审批通过|审批成功|草稿|
   |NA|审批未通过，需要重新修改提交|驳回|草稿|
   |NA|绑定到权益、福利上，然后上线|商用上线|商用|
   |申请修改|NA|申请修改-审批中|商用|
   |NA|申请修改-审批通过|申请修改-通过|商用|
   |NA|申请修改-审批不通过|申请修改-驳回|商用|
   |申请停用|NA|申请停用|商用|
   |NA|申请停用-审批通过|申请停用-通过|下线|
   |NA|申请停用-审批不通过|申请停用-驳回|商用|

   通知消息的开关配置请参见下图，默认情况下是打开的，我们会在审批通过、劵码上线和下线时通知您。
