# 基于Service Account开放鉴权

#### 概述

服务帐号（Service Account）是一种可实现服务器与服务器之间接口鉴权的帐号，在华为开发者联盟的[API Console](https://developer.huawei.com/consumer/cn/console#/credentials/projectKey=dev7519896637536769923)上创建服务帐号，您可根据返回的公私钥在业务应用中生成鉴权令牌，调用支持此类鉴权的华为公开API。  

#### 生成服务帐号鉴权令牌

服务帐号令牌为JWT（JSON Web Token）格式字符串，JWT数据格式包括三个部分：

* Header（头部）
* Payload（负载）
* Signature（签名）

这三个部分通过"."进行连接，其中Signature为通过SHA256withRSA/PSS算法对Header与Payload拼接的字符串签名生成的字符串。

示例

```
eyJraWQiOiJjNjBjMXXX.
eyJhdWQiOiJodHRXXX.
BRNssZfU0r7az5oU7-Zp5g9X2WJVXXX
```

更多JWT的相关知识请参见[Introduction to JSON Web Tokens](https://jwt.io/introduction/)。

#### 生成JWT Header数据

根据文件中的key_id字段拼接JSON体，对JSON体进行BASE64编码。

示例

```
{
  "kid": "******",
  "typ": "JWT",
  "alg": "PS256"
}
```

|字段名|描述|
|:--|:-------------------|
|kid|服务帐号JSON文件中key_id字段。|
|typ|数据类型，固定为：JWT。|
|alg|算法类型，固定为：PS256。|

BASE64编码后为

```
eyJraWQiOiIx******
```

#### 生成JWT Payload数据

根据文件中的sub_account字段拼接JSON体，对JSON体进行BASE64编码。

示例

```
{
  "aud": "https://oauth-login.cloud.huawei.com/oauth2/v3/token",
  "iss": "******",
  "exp": 1581410664,
  "iat": 1581407064
}
```

|字段名|描述|
|:--|:---------------------------------------------------------|
|iss|服务帐号JSON文件中sub_account字段，标识数据生成者。|
|aud|固定为：https://oauth-login.cloud.huawei.com/oauth2/v3/token。|
|iat|JWT签发UTC时间戳，为自UTC时间1970年1月1日00:00:00的秒数（您的服务器时间需要校准为标准时间）。|
|exp|JWT到期UTC时间戳，比iat晚3600秒。|

BASE64编码后为

```
eyJhdWQiOiJodHR******
```

#### 生成JWT Signature数据

将完成BASE64编码后的Header字符串与Payload字符串，通过"."进行连接，并在业务应用中，通过JSON文件中的private_key（华为不进行存储，请您妥善保管），使用SHA256withRSA/PSS算法对拼接的字符串签名。

签名示例：

```
QRodgXa2xeXSt4Gp******
```

至此，已经完成服务帐号鉴权令牌JWT的生成。  

#### 调用华为公开API

应用调用华为公开API时，把已获得服务帐号鉴权令牌，放在Authorization头部来进行鉴权。

示例

```
GET /v1/demo/indexes HTTP/1.1
Authorization: Bearer eyJraWQiOiIx******.eyJhdWQiOiJodHR******.QRodgXa2xeXSt4Gp******
Host: oauth-api.cloud.huawei.com
```
