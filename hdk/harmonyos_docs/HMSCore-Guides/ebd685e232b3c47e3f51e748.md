# 血氧

此数据记录用户在某时刻的血氧，每一条数据都代表该时刻的血氧值。每条数据不能存在交叉，后一条数据的开始时间应该大于或等于前一条数据的结束时间。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 血氧数据

* 读权限：Scopes.HEALTHKIT_OXYGEN_SATURATION_READ
* 写权限：Scopes.HEALTHKIT_OXYGEN_SATURATION_WRITE

## 原子采样明细数据类型

* 名称：com.huawei.instantaneous.spo2
* Android SDK类型常量：HealthDataTypes.DT_INSTANTANEOUS_SPO2

|**字段**列表|字段描述|Android SDK常量|**类型**|可选/必选|单位|取值范围|
|:---------|:----|:----------------------------|:-----|:----|:--|:-------|
|saturation|血氧饱和度|HealthFields.FIELD_SATURATION|double|M|百分比|(0, 100]|
