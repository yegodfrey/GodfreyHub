# 帐号取消授权

#### 场景介绍

为了提升应用隐私安全，应用可以提供入口，供用户取消对应用的授权。

帐号取消授权与退出帐号的区别如下：

* 取消授权：用户取消了华为帐号对该应用的授权，调用静默登录会报2002错误，重新登录会展示授权界面进行授权。
* 退出帐号：只是退出了当前应用对华为帐号的登录状态，华为帐号对当前应用的授权还在，应用再次登录或者静默登录时不会弹出授权界面。  

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:-------------|:-------------------------|:--------------|
|手机、平板、华为智慧屏、车机|EMUI 3.0及以上、Android 4.4及以上|4.0.0.300及以上|

#### 业务流程

整体流程：

1. 用户已经登录应用并授权，在应用中执行取消授权。
2. 应用客户端调用[AccountAuthService.cancelAuthorization](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section9140325133319)方法向帐号SDK请求取消授权。
3. 帐号SDK清理帐号授权信息后，向应用客户端返回取消结果。  

#### 开发步骤

帐号取消授权功能涉及应用的关键开发步骤如下：

1. 应用设置取消授权入口，此部分由应用自行开发。
2. 应用调用[AccountAuthService.cancelAuthorization](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section9140325133319)方法，并处理返回结果。  

   ```
   "Java"
   //service为登录授权时使用getService方法生成的AccountAuthService实例
   service.cancelAuthorization().addOnCompleteListener(new OnCompleteListener<Void>() {
       @Override
       public void onComplete(Task<Void> task) {
           if (task.isSuccessful()) {
               //取消授权成功后的处理
               Log.i(TAG, "onSuccess: ");
           } else {
               //异常处理
               Exception exception = task.getException();
               if (exception instanceof ApiException){
                   int statusCode = ((ApiException) exception).getStatusCode();
                   Log.i(TAG, "onFailure: " + statusCode);
               }
           }
       }
   });
   ```

   ```
   "Kotlin"
   //service为登录授权时使用getService方法生成的AccountAuthService实例
   service.cancelAuthorization().addOnCompleteListener { task ->
       if (task.isSuccessful) {
           //取消授权成功后的处理
           Log.i(TAG, "onSuccess: ")
       } else {
           //异常处理
           val exception = task.exception
           if (exception is ApiException) {
               val statusCode = exception.statusCode
               Log.i(TAG, "onFailure: $statusCode")
           }
       }
   }
   ```
