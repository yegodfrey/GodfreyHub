# 应用开发

## 获取Token

1. 在Xcode中为您的项目启用推送服务，启用"Signing & Capabilities"中的"Push Notifications"，勾选"Signing & Capabilities > Background Modes"中的"Remote notifications"和"Background processing"。

2. 向APNs（苹果推送服务）发起用户允许发送推送通知的请求。

   ```objectivec
   "Objective-C"
   [[UIApplication sharedApplication] registerForRemoteNotificationTypes:(UIRemoteNotificationTypeAlert | 
   UIRemoteNotificationTypeBadge | UIRemoteNotificationTypeSound)];

   UNUserNotificationCenter *center = [UNUserNotificationCenter currentNotificationCenter];
   [center requestAuthorizationWithOptions:(UNAuthorizationOptionAlert | UNAuthorizationOptionBadge | 
   UNAuthorizationOptionSound) completionHandler:^(BOOL granted, NSError *_Nullable error) {
       if (granted) {
           // 授权成功
           [center getNotificationSettingsWithCompletionHandler:^(UNNotificationSettings *_Nonnull settings) {
               if (settings.authorizationStatus == UNAuthorizationStatusAuthorized) {
                   dispatch_async(dispatch_get_main_queue(), ^{
                       NSLog(@"grant authorized");
                       [[UIApplication sharedApplication] registerForRemoteNotifications];
                   });
               }
           }];
       }
   }];
   ```

   ```c
   "Swift"
   func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: 
   [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
       // 请求通知权限
       UNUserNotificationCenter.current()
           .requestAuthorization(options: [.alert, .sound, .badge]) {
               accepted, _ in
               if !accepted {
                   print("user not allow to display")
               }
           }
       // 向APNs请求token
       UIApplication.shared.registerForRemoteNotifications()
       return true
   }
   ```

   用户需要在应用程序点击"允许"才可以接收推送消息。

3. 上述步骤成功后，需要获取device token（苹果设备的唯一标识）。获取device token后需要去掉其中的特殊符号，不同iOS版本的device token格式有所差别，可参见如下代码进行处理。

   ```objectivec
   "Objective-C"
   - (void)application:(UIApplication *)application didRegisterForRemoteNotificationsWithDeviceToken:
   (NSData *)deviceToken {
       PushDemoLog(@"success get token:{%@}", deviceToken);
       // 判断iOS设备版本
       if ([[[UIDevice currentDevice] systemVersion] floatValue] >= 13) {
           if (![deviceToken isKindOfClass:[NSData class]]) {
               return;
           }
           const unsigned *tokenBytes = (const unsigned *)[deviceToken bytes];
           NSString *strToken = [NSString stringWithFormat:@"%08x%08x%08x%08x%08x%08x%08x%08x",
                                 ntohl(tokenBytes[0]), ntohl(tokenBytes[1]), ntohl(tokenBytes[2]),
                                 ntohl(tokenBytes[3]), ntohl(tokenBytes[4]), ntohl(tokenBytes[5]),
                                 ntohl(tokenBytes[6]), ntohl(tokenBytes[7])];
           PushDemoLog(@">=ios13 Get FINAL TOKEN");
           APN_TOKEN = strToken;
           return;
       } else {
           NSString *token = [NSString stringWithFormat:@"%@", deviceToken];
           token = [token stringByReplacingOccurrencesOfString:@"<" withString:@""];
           token = [token stringByReplacingOccurrencesOfString:@">" withString:@""];
           token = [token stringByReplacingOccurrencesOfString:@" " withString:@""];
           PushDemoLog(@"Get FINAL TOKEN");
           APN_TOKEN = token;
       }
   }
   ```

   ```c
   "Swift"
   func application(_ application: UIApplication, didRegisterForRemoteNotificationsWithDeviceToken 
   deviceToken: Data) {
       // 判断iOS设备版本
       if #available(iOS 13.0, *)  {
           var deviceTokenString1 = String()
           let bytes = [UInt8](deviceToken)
           for item in bytes {
               deviceTokenString1 += String(format: "%02x", item & 0x000000FF)
           }
           print(">=ios 13 get deviceToken")
           deviceTokenString = deviceTokenString1;
       } else {
           deviceTokenString = deviceToken.reduce("", { $0 + String(format: "%02X", $1) })
           print("< ios 13, get device token")
       }
   }
   ```

4. 将上一步中成功返回的device token作为入参获取推送服务Token。

   ```objectivec
   "Objective-C"
   NSString *deviceToken = @"your device token";
   NSString *pushToken = [[HmsInstanceId getInstance] getToken:deviceToken];
   ```

   ```c
   "Swift"
   let deviceToken = "your device token";
   let huaweiToken = HmsInstanceId.getInstance().getToken(deviceToken);
   ```

## 发送消息

* 您可以登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站发送消息，详情请参见[iOS应用推送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-ios-0000001182533571)。
* 您可以使用服务端API向应用推送消息。

1. 您可以通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)或者[基于服务账号生成鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)方式获取鉴权信息。

   > 说明
   >
   > * 使用[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)方式时，客户端ID和客户端密钥请输入您在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)项目下的HarmonyOS应用里的OAuth 2.0客户端ID（凭据）中的 Client ID 和 Client Secret；获取的 Access Token 在有效期（expires_in）内可以多次使用，请勿过于频繁请求，否则可能会被流控（当前应用级Access Token的流控阈值为1000个/5分钟，5分钟内申请 Access Token 超过1000个，后续将提示被流控，无法申请。5分钟后重置，可以再次申请）。
   > * 使用[基于服务账号生成的鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)有效期不要超过1小时，有效期内可以多次使用。
   > * 其他错误码请参见[错误与异常机制](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/open-platform-error-0000001053869182#section1077863721110)。

2. 您的服务端调用API推送消息，请求示例如下。

   **HTTPS POST URL：**

   ```screen
   POST https://push-api.cloud.huawei.com/v1/clientid/messages:send
   ```

   > 说明
   >
   > URL中的"clientid"为您在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)项目下的iOS应用里的OAuth 2.0客户端ID（凭据）中的[Client ID](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137#ZH-CN_TOPIC_0000001700850785__li13365141273812)。

   **请求消息头示例：**

   ```http
   Content-Type: application/json; charset=UTF-8
   Authorization: Bearer CF3Xl2XV6jMKZgqYS***********************VrDgAPuzvNm3WccUIaDg== 
   ```

   > 说明
   > * 请求消息头中的Authorization参数为通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)获取的 Access Token 或者[基于服务账号生成的鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)。
   > * 通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)获取的 Access Token，如果是通过curl命令或者Postman等工具手工获取，需注意JSON字符串中的转义符，请把"\/"还原为"/"，替换后才是正确的Access Token。如果是从代码运行获取，则采用任意的第三方库均能正确解析JSON串，获取到正确的Access Token。

   **请求消息体示例：**

   ```screen
   {
       "validate_only": false,
       "message": {
           "apns": {
               "headers": {
                   "apns-topic": "the bundle ID for your app",
                   "apns-priority": "5"
               },
               "hms_options": {
                   "target_user_type": 1
               },
               "payload": {
                   "aps": {
                       "alert": {
                           "title": "ios message title",
                           "body": "ios message body"                        
                       }
                   },
                   "key": "value"
               }
           },
          "token": ["your push token"]
       }
   }
   ```

   > 说明
   >
   > 请求消息体中的"token"值为[推送服务Token](#ZH-CN_TOPIC_0000001652492056__li1658516428349)，更多iOS参数请参见[ApnsConfig](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p53231842314)。

## 上报消息到达事件

1. 您可以调用[EventReport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-api-eventreport-0000001063403418)包里提供的上报消息事件的方法进行事件的上报和查看，示例代码如下。

   ```objectivec
   "Objective-C"
   - (void)userNotificationCenter:(UNUserNotificationCenter *)center
       willPresentNotification:(UNNotification *)notification
           withCompletionHandler:(void (^)(UNNotificationPresentationOptions))completionHandler  
   API_AVAILABLE(ios(10.0))
   {
       // 上报消息体
       NSDictionary *userInfo = notification.request.content.userInfo;
       PushDemoLog(@"handle recv msg:%@", userInfo);
       [self processRecvMsg:userInfo];
       completionHandler(UNNotificationPresentationOptionBadge | UNNotificationPresentationOptionAlert);
   }
   - (void)application:(UIApplication *)application didReceiveRemoteNotification:(NSDictionary *)userInfo {
       PushDemoLog(@"handle recv msg:%@", userInfo);
       [self processRecvMsg:userInfo];
   }
   - (void)processRecvMsg:(NSDictionary *)userInfo {
       if ([self isSilentMsg:userInfo] == true) {
           PushDemoLog(@"this msg is trans,%@", userInfo);
           // 上报静默消息事件
           [[EventReport getInstance] reportPushMsgSilentEvent:userInfo];
       }
       else{
           // 上报消息点击事件
           [[EventReport getInstance] reportPushMsgClickEvent:userInfo];
       }
   }
   ```

   ```c
   "Swift"
   // foreground
   func application(_ application: UIApplication, didReceiveRemoteNotification userInfo: [AnyHashable: Any]) {
       EventReport.getInstance().reportPushMsgClickEvent(userInfo)
       print("foreground Received Notification")
       print("didReceiveRemoteNotification: is: \(userInfo)")
   }
   // background
   func application(_ application: UIApplication, didReceiveRemoteNotification userInfo: [AnyHashable: Any], fetchCompletionHandler completionHandler: @escaping (UIBackgroundFetchResult) -> Void) {
       EventReport.getInstance().reportPushMsgClickEvent(userInfo)
       print("background Received Notification")
       print("didReceiveRemoteNotification: is: \(userInfo)")
       completionHandler(UIBackgroundFetchResult.newData)
   }
   ```

2. 当您的iOS设备上收到消息后点击该消息后，您可以登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"开发与服务"，在项目列表中找到您的项目，上方导航栏选择您的应用，点击左侧导航栏"华为分析>应用调试"，选择iOS设备即可看到数据上报详情。

## FAQ

**如果您的项目报duplicated symbols错误该如何解决？**

由于Push SDK里直接包含了OpenSSL库，您的项目里也引用了OpenSSL库就会导致duplicated symbols错误，您在"Build Settings"页签，向"Other Linker Flags"去掉-all_load即可。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105219.49892985348235183544246906334641:50001231000000:2800:9B27ED263B6A96B0A1877BF04A4D5BAB2951740EB349B8907DD9A8A851A0CE8D.png "点击放大")

**如果您的项目报错Undefined symbols for architecture arm64: "_nghttp2_http2_strerror"如何解决？**

打开您项目目根目录下的".xcworkspace "文件，在"General"页签，点击"+"号添加对framework库的依赖"libapple_nghttp2.tbd"。

**如何开启debug日志进行调试？**

您可以在Xcode中依次选择"Product > Scheme > Edit Scheme"，添加-PushDebug、-HADebugEnabled和-HALogLevelDebug，如下图所示。
