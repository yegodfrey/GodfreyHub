# 使用入门

## 开发环境

* 装有iOS App开发环境的苹果设备。
* 一部iPhone手机用于开发调测App（iPhone8及以上，操作系统iOS 11.0及以上）。
* 开发工具Xcode。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-config-agc-0000001242634549)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-config-agc-0000001242634549#section4668165217444)、[创建项目](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-config-agc-0000001242634549#section707mcpsimp)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-config-agc-0000001242634549#section711mcpsimp)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-config-agc-0000001242634549#section721mcpsimp)。|
|2|[集成SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-integrating-sdk-0000001197754692)|在开发应用前，您需要将SDK集成到您的开发环境中。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-adding-permissions-0000001197914666)|调用地图服务能力，您需要在应用中添加权限。|
|5|[创建地图](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-map-creation-overview-0000001242834559)|使用地图容器快速地获得地图对象，并改变地图类型、在地图上显示"我的位置"等。|
|5|[地图交互](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-map-interaction-overview-0000001242954551)|通过控制地图手势开关以及内置UI控件的可见性，自定义用户与地图交互方式。|
|5|[在地图上绘制](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-drawing-map-overview-0000001242634559)|在地图上绘制标记、覆盖物以及形状等。|
|5|[自定义地图样式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-sdk-map-style-customization-overview-0000001198074662)|在应用中添加自定义风格的地图。|
