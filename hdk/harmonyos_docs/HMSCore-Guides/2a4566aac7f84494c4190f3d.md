# 通知栏消息按钮

推送服务支持通知栏消息上添加按钮，点击按钮可以触发相应的动作，目前支持动作类型可以参见"[Button](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__table7945113316573)"结构体的定义。具体展示效果如下：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095829.36137781603656892614286150251118:50001231000000:2800:955DA6CB966B45A31DEB53C6EC4D48185DA39DF3B75EE604512B0E883AF4E68B.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

消息体示例：

```
{
    "validate_only": false,
    "message": {
        "android": {
            "notification": {
                "title":"消息标题",
                "body":"消息内容",
                "click_action": {
                    "type": 3
                },
                "style": 0,
                "buttons": [
                    {"action_type": 0, "name": "了解更多"},
                    {"action_type": 3,"name": "忽略"}
                ]
            }
        },
        "token": ["pushtoken1"]
    }
}
```

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095829.71603167733681162725206665894021:50001231000000:2800:08B04899828E8C6CAB8E3595B24E67DC05DD50C8166B1A7703753694879D5799.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
* "name"字段的值如果为英文，通知栏消息展示时按钮名字会以全大写字母展示。
* 按钮最多可设置3个。

当"[action_type](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p12346931145812)"字段值为0（打开应用首页）或者1（打开应用自定义页面）时，可以打开自身应用并给应用传递数据，通过"[data](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p17958164414919)"字段来设置，消息体示例：：

```
{
    "validate_only": false,
    "message": {
        "android": {
            "notification": {
                "title":"消息标题",
                "body":"消息内容",
                "click_action": {
                    "type": 3
                },
                "style": 0,
                "buttons": [
                    {
                        "name": "查看更多详情",
                        "action_type": 1,
                        "intent_type": 0,
                        "intent": "intent://com.huawei.codelabpush/deeplink?#Intent;scheme=pushscheme;launchFlags=0x04000000;i.age=180;S.name=abc;end",
                        "data": "{\"key1\":\"value1\",\"key2\":\"value2\",\"keyn\":\"valuen\"}"
                    }
                ]
            }
        },
        "token": ["pushtoken1"]
    }
}
```

透传数据"data"字段值的读取方法参见[打开应用首页](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/andorid-basic-clickaction-0000001087554076#section920614081417)中接收数据部分。
