# 返还订阅费用

本接口仅进行最近一次收据的退费操作，不会对订阅产生额外影响，订阅可以继续正常使用，到期后也会进行自动续费。当用户意外购买订阅型商品申诉退款时，可以调用返还订阅费用接口退还用户费用，让用户在本周期免费试用后考虑是否留存订阅关系。若用户下周期不想继续使用该订阅，您可主动调用取消订阅接口进行取消处理，也可让用户自行在HMS Core（APK）的订阅管理页中取消订阅。

如不希望返还费用后继续让用户使用订阅商品，可调用[撤销订阅](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/unsubscribe-0000001050035035)接口。
> 说明
>
> * 本接口仅对指定订阅的最近一次收费完成退款处理，不会取消订阅，订阅的有效性和后续的续期仍然会正常发生。
> * 在订阅最新收据上已经有退款信息情况下，不会再进行退款。在此情况下，如果您希望处理其他往期收据的费用返还，或者最新收据的剩余费用返还，建议联系本地运营或[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)进行退款。
> * 沙盒购买和购买金额为0的商品，退费直接成功。

具体实现请参见[返还订阅费用](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-refund-subscription-fee-0000001050986131)。
