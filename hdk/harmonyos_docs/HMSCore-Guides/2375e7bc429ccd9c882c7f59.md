# 多日步数统计

本章节提供通过华为Health Service Kit客户端API获取用户多日步数统计数据的方法示例。开发者可以通过调用[readDailySummation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-sampling-data-0000001232012585#section17833834115610)查询[DT_CONTINUOUS_STEPS_DELTA](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-hmshealthkitdatatype-0000001188078014)步数增量数据类型，获取用户多日的步数统计数据。

读取多日步数统计示例代码如下：

```screen
import {HMSHealthKit, HMSHealthKitDataType} from '@hw-hmscore/hms-js-health'
// 使用指定的数据类型（步数增量：DT_CONTINUOUS_STEPS_DELTA），调用readDailySummation接口查询2021年11月1号到7号的每日步数数据，根据异步回调处理查看数据成功或者失败。
HMSHealthKit.readDailySummation(HMSHealthKitDataType.DT_CONTINUOUS_STEPS_DELTA, "20211101", "20211107").then((result) => {
    // 调用成功
    console.info("readDailySummation success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.error("readDailySummation error: " + JSON.stringify(error));
})
```
