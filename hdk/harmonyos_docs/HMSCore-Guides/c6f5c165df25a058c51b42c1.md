# 概览

对于使用**蓝牙私有协议**的三方设备，设备厂商需要开发自定义的设备测量 H5 页面，可以选择复用运动健康App 设备详情页面或开发自定义的 H5 详情页面。

通过将厂商私有蓝牙协议在 JS 内封装，不仅可以减少双方耦合，还可以给厂商更多自由。厂商可以根据产品特性自主开发设备详情及测量界面。目前体温计、体脂秤、血压计、血糖仪、血氧仪的接入支持自定义的 H5 测量页面。跳绳的接入支持自定义的 H5 详情页面。
> 说明
>
> 对于使用标准蓝牙协议的三方设备，无需实现此步骤。

## 使用体验

通过运动健康App 绑定设备后，使用运动健康App 已有的设备详情页面或使用厂商自定义的 H5 详情页面了解设备信息，根据厂商自定义的 H5 测量页面中的测量指导进行测量，测量结束后，数据传输到手机并在运动健康App 上呈现出来。

## 开发套件

为了简化设备厂家的开发过程，并确保接入华为运动健康平台的良好体验，华为提供了如下开发套件供厂商快速集成：

* 实现蓝牙基础能力的 JS API 接口：设备厂商通过调用特定 API，完成对蓝牙的一系列操作。
* 设备 H5 页面示例代码工程及资源包：设备厂商可以根据模板自行设计 H5 页面，实现用户使用设备的过程。
* 华为运动健康App 测试版及资源包打包工具：使用这两个工具可以在本地对 H5 测量页面的功能进行测试，本地测试通过后，再上传至华为开发者联盟。 说明
  > * JS API 接口请参见[设备接入 H5 页面 API 参考（JS）](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/bluetoothadapter-0000001057377112-V5)。
  > * 设备 H5 页面模板、华为运动健康App 测试版及资源包打包工具请从开发套件中获取。

设备厂商只需要实现：

* [H5 页面开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/rope-h5-development-0000001073248506#ZH-CN_TOPIC_0000002548038637)。
* [H5 资源包开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/rope-h5-resource-development-0000001073566432#ZH-CN_TOPIC_0000002548038883)。
