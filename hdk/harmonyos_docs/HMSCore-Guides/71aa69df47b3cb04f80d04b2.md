# 版本更新说明

#### 3.4.85.301（2026-06-16）

|---------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:ads-identifier:3.4.85.301，com.huawei.hms:ads-installreferrer:3.4.85.301 修改特性 修复ads-identifier和ads-installreferrer命名空间冲突问题。|

#### SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）2.6.2及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。  

#### 历史版本

#### 3.4.62.300（2023-03-27）

|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:ads-identifier:3.4.62.300，com.huawei.hms:ads-installreferrer:3.4.62.300 修改特性 支持新的广告标识服务政策。 说明： 特别说明：请确保集成3.4.62.300及更新版本的的ads-identifier SDK，否则会导致应用在部分手机无法获取正确的OAID。|
