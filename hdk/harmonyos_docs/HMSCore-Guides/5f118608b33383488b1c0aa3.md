# 业务介绍

华为支付服务为开发者的应用提供华为支付方式收款能力，适用于在移动端应用（APP、快应用、元服务等）收款的场景。使用产品之前，开发者需要在移动端应用内集成华为支付服务SDK，再调用SDK接口调起华为支付服务提供的收银台，即可帮助用户完成支付，并展示支付结果。

华为支付服务提供了一种方便、安全和快捷的支付方式，将强大的支付、营销、运营等能力，通过接口形式开放给开发者，开发者可以通过SDK工具快速集成至应用。

## 业务特点

* 支持银行卡、华为支付余额等多种支付方式，其中银行卡支持国内主流银行。
* 支持免卡号输入，直接选择银行卡进行验证码绑卡。
