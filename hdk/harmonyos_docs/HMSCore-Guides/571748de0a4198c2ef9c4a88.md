# 转化跟踪参数单机接入测试

准备一部华为手机，且HMS Core（APK）版本在2.6.5及以上。完成上述获取转化跟踪参数业务代码的补全后，就可以进行编译。编译有错误时，根据错误提示，进行代码修改。完成编译后，生成APK安装并运行。

## 生成转化跟踪参数

由于转化跟踪参数需要在鲸鸿动能平台投放后才能正常获取，我们在此处提供了Demo，可以在端侧生成转化跟踪参数，供开发者App在测试阶段调测使用。Demo下载地址参见[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-0000001050066947)。
> 说明
>
> 只有包名为"com.huawei.pps.hms.test"的工程，才可以使用获取转化跟踪参数的测试功能。

## 修改您的App用于测试转化跟踪参数

### SDK方式

在创建[InstallReferrerClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-0000001050064946)时设置为测试模式，调用[setTest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-builder-0000001050066895#section39179372307)(true)，示例代码如下所示：

```screen
InstallReferrerClient mReferrerClient = InstallReferrerClient.newBuilder(mContext).setTest(true).build();
mReferrerClient.startConnection(installReferrerStateListener);
```

> 说明
>
> [setTest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-builder-0000001050066895#section39179372307)(true)仅用于测试，正式发布版本请[setTest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/installreferrerclient-builder-0000001050066895#section39179372307)(false)。

### AIDL方式

在测试时设置绑定的AIDL服务的包名为"com.huawei.pps.hms.test"，示例代码如下所示：

```screen
InstallReferrerServiceConnection mServiceConnection = new InstallReferrerServiceConnection();
Intent intent = new Intent(Constants.SERVICE_ACTION);
intent.setPackage("com.huawei.pps.hms.test");
boolean result = getApplicationContext().bindService(intent, mServiceConnection, Context.BIND_AUTO_CREATE);
```

> 说明
>
> 包名"com.huawei.pps.hms.test"仅用于测试，正式发布版本请使用包名"com.huawei.hwid"。

## 验证转化跟踪参数功能

如果从日志中可以看到正确获取转化跟踪参数，表示您的App已正确集成转化跟踪参数功能。
