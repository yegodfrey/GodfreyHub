# （可选）集成SDK

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/udpkn4nIRTGoOFgava98iA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043140Z&HW-CC-Expire=86400&HW-CC-Sign=283E3079FB8BD56474D3EBF33B5ED3627EEBF4888D02B638E86D92D9A22DE51C)

若您需要将事件上报到HUAWEI Analytics平台，请执行如下操作。

                1. 导入SDK。在您的代码工程的main.js中，拷贝如下代码片段。
                       
                       import agconnect from '@agconnect/api';
                       import '@agconnect/instance';
                       import '@hmscore/analytics-web';

                2. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的项目”，在项目中找到需要集成SDK的应用，然后切换到“项目设置”页面，拷贝agConnectConfig代码片段到您的代码工程的main.js中，并完成SDK的初始化、确保DTM对HUAWEI Analytics接口的调用。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/_QHQ-c4rR0-M8bawdsEROw/zh-cn_image_0000001217750162.png?HW-CC-KV=V1&HW-CC-Date=20261005T043140Z&HW-CC-Expire=86400&HW-CC-Sign=B9C320671F34E253D5A88A6DC1B78BE6F8254C475D97052E6BE6210AB6BB5BAE)
                       
                       // TODO: 用您应用的配置替换下方代码
                       const agConnectConfig = {
                         // ...
                       };
                       // 配置agconnect实例
                       agconnect.instance().configInstance(agConnectConfig);
                       // 初始化分析实例
                       let analytics = agconnect.analytics();
                       // 添加实例，确保DTM对HUAWEI Analytics接口的调用
                       window.agconnect = agconnect;
