# 开始导航

## 概述

当请求路线规划信息完成后，您可以通过调用驾车引导计算接口[MapNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924).[calculateDriveGuide](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section12812238171916)()开启引导计算（Navi Kit 还提供步骑行导航接口，这里以驾车为例），在引导计算成功后调用[MapNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924).[startNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section205961939121010)([NaviMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/navimode-0000001212627452) naviMode)方法开启开始导航流程，公交无引导计算和开始导航。
> 说明
>
> 本章节未声明对象请参考导航服务示例代码。

## 约束条件

* 注意这个请求需在路线规划请求之后发起，如果单独发起该请求会失败
* 调用此接口前，请确认已调用[setVehicleType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section101271922539)正确设置了导航类型

## 示例 -- 驾车开始导航

1. 在路线规划界面，创建开始导航按钮。

```screen
<LinearLayout    
android:layout_width="match_parent"    
android:layout_height="match_parent"    
android:gravity="center"    
android:orientation="vertical">
    <Button    
    android:id="@+id/btn_start_navi"    
    android:layout_width="wrap_content"    
    android:layout_height="wrap_content"    
    android:text="Guiding" />
</LinearLayout>
```

2. 在路线规划结果的Activity中（例如创建一个名为ApiTestActivity的类用于展示路线规划结果和引导计算按钮），注册这个按钮的click事件，点击按钮调用[MapNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924).[calculateDriveGuide](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section12812238171916)方法执行引导计算。 注意
>
> ApiTestActivity也需要注册[MapNaviListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavilistener-0000001212215832)，用以监听请求计算成功的回调，在回调中处理相关逻辑，具体操作详见[注册导航监听](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-path-planning-0000001214234296#section9956114183718)。

```java
"Java"
// 引导计算按钮
private Button naviStartBtn;

// 在路线规划成功回调中 将此值置为true 表示可以开始导航
private boolean isRouteCalculateSuccess = false;

naviStartBtn = (Button) findViewById(R.id.btn_start_navi);

// MapNavi对象
private MapNavi mapNavi;

private void initMapNavi() {
    mapNavi = MapNavi.getInstance(this);  
    mapNavi.addMapNaviListener(this);
}

naviStartBtn.setOnClickListener(v -> {
    if (isRouteCalculateSuccess){
       if (mVehicleType == VehicleType.DRIVING) { 
           mapNavi.calculateDriveGuide(); 
       }
    } else {   
       ToastUtil.showToast(this, "please calculate route first");   
    }
});
```

```kotlin
"Kotlin"
// 引导计算按钮
private var naviStartBtn: Button? = null

// 在路线规划成功回调中 将此值置为true 表示可以开始导航

            mapNavi!!.calculateDriveGuide()
        }
    } else {
        showToast(this, "please calculate route first")
    }
}
```

3. 引导计算成功结束，回调监听到[MapNaviListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavilistener-0000001212215832).[onStartNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavilistener-0000001212215832#section045719964910)方法,设置参数并跳转到导航的Activity中

```java
"Java"
@Override
public void onStartNavi(int code){
    // 若code == 0 代表开始导航成功 可以设置参数跳转至导航页面    
    ToastUtil.showToast(this, "startNavi complete code is :" + code);
    if (code == 0) {    
        Intent intent = new Intent(this, NaviActivity.class);    
        startActivity(intent);
    }
}
```

```kotlin
"Kotlin"
override fun onStartNavi(code: Int) {
    // 若code == 0 代表开始导航成功 可以设置参数跳转至导航页面
    showToast(this@ApiTestActivity, "startNavi complete code is :$code")
    if (code == 0) {
        val intent = Intent(this@ApiTestActivity, NaviActivity::class.java)
        startActivity(intent)
    }
}
```

4. 成功跳转到导航Activity后（例如创建一个名为NaviActivity的类用于展示设置灌点模式与开始导航按钮），您需要重新获取导航实例，并通过实例调用[setUseExtraLocationData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section787411184578)方法设定是外部灌点还是内部传点。

```java
"Java"
// 声明MapNavi对象
private MapNavi mapNavi;
// 声明内部传点设置按钮
private RadioButton internalLocation;
// 声明外部灌点设置按钮
private RadioButton externalLocation;
// 实例化MapNavi对象
mapNavi = MapNavi.getInstance(this);

private void initLocationType() {
    if (internalLocation.isChecked()) {
        // 设置内部传点
        mapNavi.setUseExtraLocationData(false);    
    }

    if (externalLocation.isChecked()) {
        // 设置外部灌点
        mapNavi.setUseExtraLocationData(true);    
    }
}
```

```kotlin
"Kotlin"
// 声明MapNavi对象
private var mapNavi: MapNavi? = null
// 声明内部传点设置按钮
private var internalLocation: RadioButton? = null
// 声明外部灌点设置按钮
private var externalLocation: RadioButton? = null
// 实例化MapNavi对象
mapNavi = MapNavi.getInstance(this)

private fun initLocationType() {
    if (internalLocation!!.isChecked) {
        // 设置内部传点
        mapNavi!!.setUseExtraLocationData(false)
    }

    if (externalLocation!!.isChecked) {
        // 设置外部灌点
        mapNavi!!.setUseExtraLocationData(true)
    }
}
```

5. 设置完灌点模式后，您可以通过[startNavi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section205961939121010)([NaviMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/navimode-0000001212627452) naviMode)方法开始不同类型的导航。

```java
"Java"
// 模拟导航按钮
private Button startEmulatorNavi;
// GPS导航按钮
private Button startGpsNavi;
// 记录是否在导航中
private boolean isGpsNavigation = false;

// 添加按钮点击事件
startEmulatorNavi.setOnClickListener(v -> {    
    startEmulatorNavi();
});
startGpsNavi.setOnClickListener(v -> {    
    startGpsNavi();
});

private void startEmulatorNavi() {
    if (mapNavi != null) {
        if (externalLocation.isChecked()) {            
            ToastUtil.showToast(this, "You can't use external locations to simulate navigation.");        
        } else {
            boolean result = mapNavi.startNavi(NaviMode.EMULATOR);            
            ToastUtil.showToast(this, "start emulator navi result: " + result);        
        }    
    }
}

private void startGpsNavi() {
    if (mapNavi != null) {
        boolean result = mapNavi.startNavi(NaviMode.GPS);        
        ToastUtil.showToast(this, "start navi result: " + result);
        if (result) {
            isGpsNavigation = true;        
        }    
    }
}
```

```kotlin
"Kotlin"
// 模拟导航按钮
private var startEmulatorNavi: Button? = null
// GPS导航按钮
private var startGpsNavi: Button? = null
// 记录是否在导航中
private var isGpsNavigation = false

// 添加按钮点击事件
startEmulatorNavi!!.setOnClickListener { v: View? -> startEmulatorNavi() }
startGpsNavi!!.setOnClickListener { v: View? -> startGpsNavi() }

private fun startEmulatorNavi() {
    if (mapNavi != null) {
        if (externalLocation!!.isChecked) {
            showToast(this, "You can't use external locations to simulate navigation.")
        } else {
            val result = mapNavi!!.startNavi(NaviMode.EMULATOR)
            showToast(this, "start emulator navi result: $result")
        }
    }
}

private fun startGpsNavi() {
    if (mapNavi != null) {
        val result = mapNavi!!.startNavi(NaviMode.GPS)
        showToast(this, "start navi result: $result")
        if (result) {
            isGpsNavigation = true
        }
    }
}
```

> 注意
>
> 1. 设置外部灌点无法正常进行模拟导航。
>
> 2. 设置内部灌点开启GPS导航，导航内部自动实现定位灌点；设置外部灌点开启GPS导航，导航内部灌点不再生效，需外部CP传点。

6. 当设置了外部灌点的情况下，您需要使用外部定位信号源获取位置信息并通过[updateExtraLocationData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section39621758175016)接口更新给导航。此处外部信号源推荐使用[Location Kit](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050706106)，详细使用见[融合定位开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/location-develop-steps-0000001050746143)。

```java
"Java"
// 获取外部信号源位置信息location后通过接口传给导航实例
boolean isSuccess = mapNavi.updateExtraLocationData(location, -1);
```

```kotlin
"Kotlin"
// 获取外部信号源位置信息location后通过接口传给导航实例
val isSuccess = mapNavi!!.updateExtraLocationData(location, -1.0)
```

7. 成功导航后可以通过监听回调获取导航中的位置、信息等变化。

```java
"Java"
// 展示位置信息变化
private TextView locationView;
// 展示距离信息变化
private TextView distanceView;
// 展示时间信息变化
private TextView timeView;

......
@Override
public void onLocationChange(NaviLocation naviLocation) {
    if (naviLocation != null && naviLocation.getCoord() != null) {
        locationView.setText(naviLocation.getCoord().toString());    
    }
}

@Override
public void onNaviInfoUpdate(NaviInfo naviInfo) {
    if (naviInfo != null) {
        distanceView.setText(naviInfo.getPathRetainDistance() + " m");
        timeView.setText(naviInfo.getPathRetainTime() + " s");    
    }
}

......
```

```kotlin
"Kotlin"
// 展示位置信息变化
private var locationView: TextView? = null
// 展示距离信息变化
private var distanceView: TextView? = null
// 展示时间信息变化
private var timeView: TextView? = null

......
override fun onLocationChange(naviLocation: NaviLocation) {
    if (naviLocation != null && naviLocation.coord != null) {
        val text = naviLocation.coord.latitude.toString() + "," + naviLocation.coord.longitude
        locationView!!.text = text
    }
}

override fun onNaviInfoUpdate(naviInfo: NaviInfo) {
    if (naviInfo != null) {
        distanceView!!.text = naviInfo.pathRetainDistance.toString() + " m"
        timeView!!.text = naviInfo.pathRetainTime.toString() + " s"
    }
}

......
```

> 注意
>
> NaviActivity也需要注册[MapNaviListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavilistener-0000001212215832)，用以监听请求计算成功的回调，在回调中处理相关逻辑，具体操作详见[注册导航监听](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-path-planning-0000001214234296#section9956114183718)。

## 其他

上述操作为开发者提供了驾车开始导航的简易实例代码，除了驾车外，Navi Kit还支持步骑行的开始导航，通过设置交通类型来区分。

```java
"Java"
// 设置导航交通类型 - 驾车
mapNavi.setVehicleType(VehicleType.DRIVING);
// 设置导航交通类型 - 步行
mapNavi.setVehicleType(VehicleType.WALKING);
// 设置导航交通类型 - 骑行
mapNavi.setVehicleType(VehicleType.CYCLING);
```

```kotlin
"Kotlin"
// 设置导航交通类型 - 驾车
mapNavi!!.setVehicleType(VehicleType.DRIVING)
// 设置导航交通类型 - 步行
mapNavi!!.setVehicleType(VehicleType.WALKING)
// 设置导航交通类型 - 骑行
mapNavi!!.setVehicleType(VehicleType.CYCLING)
```

步骑行引导计算的方法如下。

```java
"Java"
// 步行规划引导计算
mapNavi.calculateWalkGuide();
// 骑行规划引导计算
mapNavi.calculateCyclingGuide();
```

```kotlin
"Kotlin"
// 步行规划引导计算
mapNavi!!.calculateWalkGuide()
// 骑行规划引导计算
mapNavi!!.calculateCyclingGuide()
```

> 说明
>
> 1.所有引导计算的方法都要保证在路线规划请求之后发起，并正确调用[setVehicleType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavi-0000001211877924#section101271922539)方法设置了导航类型值，返回的boolean仅代表方法成功执行，具体引导计算结果返回的信息参考[MapNaviListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapnavilistener-0000001212215832)中的相关回调。
>
> 2.公交不具备引导计算、开始导航能力。
