# 标记

用户可以在地图的指定位置添加标记以标识位置、商家、建筑等，并可以通过信息窗口展示详细信息。

## 添加标记

下面的代码段使用默认图标在地图上添加一个简单的标记。

```java
// 新建Marker对象
Marker mMarker = null;

// 如果mHuaweiMap为null，程序停止执行
if (null == mHuaweiMap) {
    return;
}

// 如果mMarker不为null，则先从地图上移除，再置为null
if (null != mMarker) {
    mMarker.remove();
    mMarker = null;
}

// 在地图上添加一个Marker
MarkerOptions options = new MarkerOptions()
    .position(new LatLng(48.893478, 2.334595))
    .title("Hello Huawei Map")
    .snippet("This is a snippet!");
mMarker = mHuaweiMap.addMarker(options);
```

## 自定义标记图像

您可以使用自定义图像（通常称为图标）修改默认标记图标，通过Resource类创建自定义图标。

创建一个带有自定义图标的标记。

```screen
Resource resource = null;
try {
    resource = getResourceManager().getResource(ResourceTable.Media_icon);
} catch (IOException e) {
    e.printStackTrace();
} catch (NotExistException e) {
    e.printStackTrace();
}
mMarker = mHuaweiMap.addMarker(new MarkerOptions()
    .position(new LatLng(48.893478, 2.334595))
    .icon(resource));
```

## 修改标记

地图SDK支持在添加标记之后，修改已经设置的标记属性。

```java
// 设置标记的标题
if (mMarker != null) {
    mMarker.setTitle("Marker title"); 
} 
 
... 
 
// 设置标记可拖拽
if (mMarker != null) {
    mMarker.setDraggable(true); 
} 
 
// 设置标记锚点
if (mMarker != null) {
    mMarker.setMarkerAnchor(0.9F, 0.9F); 
}
```

## 标记事件

### 标记点击事件

可以使用[OnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-onmarkerclicklistener-0000001147912397)来侦听标记上的点击事件。要在地图上设置此侦听器，请调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)对象的[setOnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582#section6157172618712)([OnMarkerClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-onmarkerclicklistener-0000001147912397))方法。当用户点击标记时，[onMarkerClick](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-onmarkerclicklistener-0000001147912397#section165540817477)([Marker](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-marker-0000001101552572))将调用该标记并将标记作为参数传递。标记点击事件的默认行为是显示其信息窗口（如果可用），使标记在地图上居中。

```screen
mHuaweiMap.setOnMarkerClickListener(new OnMarkerClickListener() {
    @Override
    public boolean onMarkerClick(Marker marker) {
        new ToastDialog(CommonContext.getContext()).setText("onMarkerClick: " + marker.getTitle()).show();
        return false;
    }
});
```

## 信息窗

信息窗在标记上方的弹出窗口中显示文本或图像，为标记提供详细信息。

### 添加信息窗

添加信息窗的最简单方法是设置相应[MarkerOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-markeroptions-0000001101512570)对象的[title](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-markeroptions-0000001101512570#section144310304569)()和[snippet](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-markeroptions-0000001101512570#section1266276203610)()方法。设置这些属性将导致在点击该标记时显示信息窗。

```screen
if (null != mMarker) {
    mMarker.remove();
    mMarker = null;
}
MarkerOptions options = new MarkerOptions().position(new LatLng(48.893478, 2.334595));
options.title("Hello Huawei Map");
options.snippet("This is a snippet!");
mMarker = mHuaweiMap.addMarker(options);
```
