# 使用入门

## 开发环境

* 装有iOSApp开发环境的苹果设备。
* 一部iPhone手机用于开发调测App（iPhone6及以上，操作系统iOS 9.0及以上）。
* 开发工具Xcode。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001160509492)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001160509492#section19141717123017)、[创建项目](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001160509492#section166771423181511)和[创建应用](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001160509492#section294363472920)和[开通定位服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001160509492#section121661823350)。|
|2|[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-integrate-sdk-0000001160191010#section155568015811)|在开发应用前，您需要将iOS Location SDK集成到您的开发环境中。|
|3|++[添加权限声明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-add-permissionstatement-0000001205871011)++|在开发应用前，您需要在"Info.plist"文件中声明应用所需权限。|
|4|[融合定位开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-location-develop-steps-0000001160031020)|通过调用定位服务的融合定位相关接口，可以让您的应用快速、精准地获取位置信息。|
