# 游戏适配OpenHarmony/HarmonyOS 5.0及以上

为了扩大用户覆盖范围，提升游戏的性能和体验，建议您的Android游戏适配游戏适配OpenHarmony/HarmonyOS 5.0及以上。

游戏适配包括三方库适配、游戏引擎适配、游戏代码适配、系统能力适配：

|适配项|简要说明|
|:-----|:---------------------------------------------------------------------------------------|
|三方库适配|* 商用三方库：联系对应官方获取已适配HarmonyOS 5.0及以上的版本。 * 开源三方库：使用HarmonyOS Toolchain重新编译生成，参考华为提供的编译指导。|
|游戏引擎适配|升级到支持HarmonyOS 5.0及以上的引擎版本。|
|游戏代码适配|若游戏代码存在多平台的处理逻辑，需要根据实际情况添加HarmonyOS 5.0及以上平台处理分支。|
|系统能力适配|游戏使用的系统层相关能力的实现，需要由其他操作系统接口切换到HarmonyOS 5.0及以上接口。|

不同引擎游戏的详细适配指南请参见[游戏适配OpenHarmony/HarmonyOS 5.0及以上](https://developer.huawei.com/consumer/cn/doc/games-guides/games-adapt-platform-0000002252371802)。
