# 简介

专业运动原子采样数据都是在跑步、跳绳等专业运动过程中产生的运动记录关联的原子采样明细数据、关联的原子采样统计数据，它们仅存在于运动记录数据中，并且专业运动原子采样明细数据和原子采样统计数据只能通过运动记录查询接口获取，详情请参见[运动记录数据查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295#section34819155446)。

每个专业的运动记录关联的原子采样数据请参见[运动记录数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/activity-type-constants-0000001135051290)。
