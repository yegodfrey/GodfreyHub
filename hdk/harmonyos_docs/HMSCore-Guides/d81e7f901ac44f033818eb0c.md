# 客户端配置  
  
#### 配置脚本导入

                1. 您可点击“配置”，然后点击“查看”按钮来获取导入脚本。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e0/v3/m-jnycOXSVep3hUmQpIAzQ/zh-cn_image_0000001080340793.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=784979FAC70041FF3FD411C66B1D1899426AE05C485103396EB071E44B833786)

                2. 复制如下代码片段并将其拷贝到网站上每个需要配置代码的网页里。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/02vPDEPRTAKjENe4fTRSMQ/zh-cn_image_0000001071225964.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=ED13AA1119C4288979C39D28DF90D2DB0633E4181AB081D017D8E68C287B2AA2)

此代码拷贝到页面<head>部分中，并使其靠近最顶部位置，以便及时使代码生效。

#### 开发步骤

在网页的<head>合适位置插入配置代码：
    
    <html>
    <head>
        <title>DTM Sample</title>
        <!-- Dynamic Tag Manager -->
          <script>
           (function(){
              window.recordTier = window.recordTier || [], window.recordTier.push({eventName: 'dtm.js'});
              var e = document.getElementsByTagName('script')[0], r = document.createElement('script');
              r.async = !0, r.src = 'https://xxxxxx/dtm.js?id=DTM-yyyy', e.parentNode.insertBefore(r, e);
            })();
          </script>
        <!-- End Dynamic Tag Manager -->
    </head>
    <body>
    </body>
    </html>

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/ER5pqmOtRlCkzUhnstJv1A/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=8F2C90DE7F5813A808BB0E830416E7235556740DE40EAA74DB561BEB0638F3A9)

其中https://xxxxxx/dtm.js?id=DTM-yyyy以实际动态标签管理页面的配置为准。
