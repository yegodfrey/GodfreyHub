# UI控件和手势

#### 缩放控件

地图SDK提供了内置的缩放控件，默认情况下是关闭的。

```
self.mapView.showsZoomControl = YES;
```

#### 指南针

地图SDK提供了指南针功能，默认显示在地图的左上角。如果启用，当地图不是指向正北方向时，点击指南针可使地图旋转为正北方向；如果禁用，将不会显示指南针图标。

```
self.mapView.showsCompass = true;
```

#### "我的位置"按钮

启用"我的位置"按钮之前，您需要确保已经开启了定位权限和"我的位置"图层。当启用了"我的位置"按钮功能时，该按钮才会显示在地图上。

```
self.mapView.showsUserLocation = YES;
self.mapView.showsLocationButton = YES;
```

#### 地图手势控制

* 缩放手势：
  1. 双击可将缩放级别提高1（放大）层级，用两根手指点击可将缩放级别降低1（缩小）层级。
  2. 双指张合，实现放大缩小。

  ```
  // 设置是否允许手势缩放
  self.mapView.zoomEnabled = YES;
  ```

* 滚动平移手势：用户可以通过用手指拖动地图来进行移动。

  ```
  // 设置是否允许手势拖拽
  self.mapView.scrollEnabled = YES;
  ```

* 倾斜手势：用户可以将两个手指在地图上进行向下或向上移动来改变地图的倾斜度。

  ```
  // 设置是否支持倾斜手势
  self.mapView.overlookingEnabled = YES;
  ```

* 旋转手势：用户可以通过将两个手指放在地图上旋转来旋转地图。

  ```
  // 设置是否允许手势旋转
  self.mapView.rotateEnabled = YES;
  ```
