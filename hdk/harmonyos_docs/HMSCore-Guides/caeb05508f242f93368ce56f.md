# Python SDK

华为分析服务目前已提供[导入自定义用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-import-customized-user-attributes-0000001050747215)和[上报用户行为](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-report-user-behavior-0000001205631635)的API接口，为减小API接口的工作量，现提供Python版本的SDK给开发者集成，用以快速的使用API接口能力。

#### 开发环境

[Python](https://www.python.org/downloads/) 3.6.5及以上

#### 操作步骤

      1. 下载Python SDK安装包到本地，下载链接请参见[Python SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/python-server-sdk-0000001238560943)。
      2. 本地解压以后执行如下命令安装SDK。
             
             python -m pip install hw_wisecloud_analytics-*.whl --upgrade

      3. 初始化SDK。
         1. 登录[ _AppGallery Connect 网站_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“我的项目”。
         2. 在项目列表中找到您的项目，在项目列表中点击需要集成SDK的应用。
         3. 在“项目设置”页面中，获取App相关信息。

当填入的参数类型非法时，SDK内部会强行转化输入的参数为指定的类型，如果无法转换，将强制设为默认值，并输出日志。
                
                SdkConfig._init_().set_max_cache_size(_10000_).set_cache_time(_10_).set_max_retry(_2_).set_event_send_size(_100_).set_user_send_size(_100_).set_threshold(_50_).set_import_concurrent(_10_).set_async_mode(_True_).set_shut_down_delay(_0.25_).build();

参数 | 参数说明  
---|---  
set_max_cache_size | 最大缓存数量，设置缓存中最大的数据量；当数量达到限制，会对最老的数据进行淘汰并记录日志。 设置区间为1-1000000，默认存放10000条数据，类型为整数。  
set_cache_time | 缓存上报的间隔时间，单位为s。 设置区间为1-1800s，默认为10s上报一次数据，类型为整数。  
set_max_retry | 上报重试次数，当上报失败时，会进行重试处理；当达到配置的最大上报次数还是失败时，则会记录日志处理。 设置区间为 0-5次，默认重试2次，类型为整数。  
set_event_send_size | 单次“上报用户行为”的发送数量。 设置区间为1-100，默认100，表示单次上报的用户行为数据为100条，类型为整数。  
set_user_send_size | 单次“导入自定义用户属性”的发送数量。 设置区间为1-100，默认100，表示单次上报的自定义用户属性为100条，类型为整数。  
set_threshold | 缓存累积的数据达到缓存总量阈值时，则触发上报流程，单位为百分比。 设置区间为1-100，默认50，类型为整数。  
set_import_concurrent | 设置并发上传任务数。 设置区间为1-100，默认10，类型为整数。  
set_async_mode | 设置异步或同步上传模式，异步上传方式是依赖aiohttp异步请求库，请确保您安装了aiohttp异步请求库；当设置为同步模式时，SDK将利用多线程实现并发。 True表示异步上传方式，False表示同步上传方式， 默认True，类型为布尔。  
set_shut_down_delay | 延迟关闭事件循环等待时间，只有当“set_async_mode”设置为“True”时，此配置生效，单位为秒。 设置区间为0-1，默认0.25，类型为浮点。 说明： Python 3.8及以上版本的asyncio标准库与aiohttp异步请求库配合时，偶发警告日志，不影响实际数据上报，如您想关闭告警日志，可参考[Graceful Shutdown](https://docs.aiohttp.org/en/stable/client_advanced.html?highlight=Graceful shutdown#graceful-shutdown)配置此参数以消减该日志。

#### 其他配置

Python SDK定义了日志打印的类HaSdkLogger，如您需要查看Python SDK打印的日志，则您需要先实现自定义的logging处理器，然后在初始化Python SDK时，调用HaSdkLogger.init()以设置自定义logging处理器。
    
    # 指定输出到文件的日志处理器
    file = logging.FileHandler('_test.log_ ')
    # 指定输出到流的日志处理器，也可以基于StreamHandler派生处理器子类
    stream = logging.StreamHandler()
     
    # 把上述自定义的输出通道传给HaSdkLogger，如果都未定义，则SDK不会输出任何日志
    HaSdkLogger.init(file_handler=file, stream_handler=stream, level=logging.INFO)
