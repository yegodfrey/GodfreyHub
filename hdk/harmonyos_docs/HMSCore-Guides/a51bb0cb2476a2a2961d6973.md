# 门禁卡

#### 概述

门禁卡，即华为钱包为用户提供的一种可以用华为手机模拟实体门禁卡并用手机开门的功能，您可以使用支持门禁卡功能的华为手机，将实体门禁卡信息复制到华为手机芯片中，手机即可当门禁卡使用。

Wallet Kit提供将门禁卡模拟到华为钱包的能力，商户仅需注册开发者联盟应用后再相应位置配置推广服务，开发者联盟会将产品内容上架至华为钱包App内的内容展示位。用户点击内容展示位后通过手机NFC功能，华为钱包可读取实体门禁卡的NFC卡片信息并将其写入手机芯片中。同时华为钱包会模拟商户进行发卡操作，待NFC卡片信息写入完成后华为钱包中将模拟出此种类型的卡片。  
![](https://media:101782807018788737)  
因为华为钱包开放能力对读卡器、门锁、车钥匙等NFC设备存在限制， 商户如要接入华为钱包生态系统，可按照[HUAWEI AI PASS认证服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ai-pass-0000001052778646)步骤申请检测。

#### 功能实现

#### 卡券领取

商户配置推广服务

商户通过申请开发者联盟应用后可配置相应的推广服务 ，可将产品内容上架至华为钱包App内的内容展示位，合作伙伴可触达华为钱包里的优质流量，以提高商品或品牌的曝光度和知名度。

例：通过申请推广服务，合作伙伴可将内容配置到开发者联盟中，图片素材及目的访问URL地址需由合作伙伴提供，华为运营人员审核后发布。

   <br />

读取NFC卡片信息

用户点击推广服务占位图即进入NFC读卡界面，用户需将待写入门禁卡靠近手机后华为钱包将自动进行读取NFC卡片信息操作。

<br />

华为钱包代替商户进行发卡操作

华为钱包应用将读取的NFC卡片信息和商户配置在开发者联盟的模板信息一起写入芯片中，待NFC卡片信息写入完毕后用户即可进行刷卡操作。
