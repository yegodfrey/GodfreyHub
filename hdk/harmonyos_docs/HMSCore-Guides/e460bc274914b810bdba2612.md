# 地图相机

## 相机属性

相机包含以下4个属性：

|属性|描述|
|:---------------|:--------------------------|
|centerCoordinate|地图中心位置的经纬度坐标。|
|rotation|地图以正北方向为0度顺时针旋转的角度。|
|overlooking|相机的倾斜角度，即相机角度与垂直于地球表面直线的夹角。|
|zoomLevel|屏幕中心附近的缩放级别。|

## 移动相机

地图的移动是通过模拟相机移动的方式实现的，您可以通过改变相机位置，来控制地图的可见区域。更改相机位置：

```screen
// 指定相机缩放级数zoom值
self.mapView.zoomLevel = 11;
// 动画方式指定相机缩放级数zoom值
[self.mapView setZoomLevel:11 animated:YES];
// 设置倾斜角
self.mapView.overlooking = 20;
// 动画方式设置倾斜角
[self.mapView setOverlooking:20 animated:YES];
// 设置旋转角度
self.mapView.rotation = 30;
// 动画方式设置旋转角度
[self.mapView setRotation:30 animated:YES];
```

### 移动相机的方式

您可以选择以动画方式或非动画方式移动相机，以非动画方式移动相机是瞬时完成的。

```screen
// 设置相机的经纬度
self.mapView.centerCoordinate = CLLocationCoordinate2DMake(48.393478, 2.034595);
// 动画方式移动相机
[self.mapView setCenterCoordinate:CLLocationCoordinate2DMake(48.393478, 2.034595) animated:YES];
```

### 设置相机最大/最小偏好缩放级别

```screen
// 设置最小/大偏好缩放级别，范围为[3,20]
[self.mapView setMinZoomLevel:3 maxZoomLevel:20];
```
