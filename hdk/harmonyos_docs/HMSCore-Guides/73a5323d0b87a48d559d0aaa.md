# 骑行

骑行相关运动记录类型如下：

|**活动类型常量**|**描述**|数据来源|
|:--------------------------------|:-----|:----------|
|HiHealthActivities.CYCLING|骑行|手机、手表、手环|
|HiHealthActivities.CYCLING_INDOOR|室内单车|室内自行车、室内骑行台|
|HiHealthActivities.SPINNING|动感单车|动感单车|
|HiHealthActivities.BMX|BMX自行车|越野自行车|

## 专业运动特征统计数据

暂无

## 关联的采样统计数据类型说明

每种关联的原子采样数据都需要独立的OAuth权限，具体参见对应采样数据类型的OAuth权限说明章节。

|**采样统计数据类型**|**描述**|可选/必选|备注|
|:---------------------------------------------------|:-----|:----|:-----------------|
|com.huawei.continuous.distance.total|距离统计|M|-|
|com.huawei.continuous.speed.statistics|速度统计|M|-|
|com.huawei.continuous.calories.burnt.total|卡路里统计|M|-|
|com.huawei.continuous.exercise_heart_rate.statistics|运动心率统计|O|用户佩戴华为手表/手环时会包含该数据|
|com.huawei.resistance.statistics|阻力统计|O|动感单车等专业骑行设备|
|com.huawei.continuous.pedaling_rate.statistics|踏频统计|O|动感单车等专业骑行设备|
|com.huawei.continuous.power.statistics|功率统计|O|动感单车等专业骑行设备|
