# 自动比例尺

HMapKitAdvance提供了自动比例尺功能：在相机移动过程中，通过调整最佳比例尺，始终保持设置目标点在视野范围内。

自动比例尺接口初始化可设置：

* 设置一个目标点的经纬度。
* 设置相机在屏幕的位置。
* 设置控制区域四个点屏幕坐标。
* 设置最大最小比例尺。

支持过程更新：

* 相机位置更新。
* 最大最小比例尺更新。
* 四个点坐标更新。

示例代码如下：

```java
// 开启比例尺缩放功能，默认NO
[self.mapView setAutoZoom:YES];
// 设置自动导航缩放层级范围
CGFloat minLevel = 3;
CGFloat maxLevel = 18;
[self.mapView setAutoZoomLevel:minLevel maxZoom:maxLevel];
// 设置自动导航缩放最小层级
CGFloat min = 3;
[self.mapView setAutoZoomMinLevel:min];
// 设置自动导航缩放最大层级
CGFloat max = 18;
[self.mapView setAutoZoomMaxLevel:max];
// 设置自动导航缩放路口转向点
HLatLng *latLng = [[HLatLng alloc] initLatitude:45.00490506 withLongitude:2.332645];
[self.mapView setAutoZoomTurningPoints:latLng];
// 设置自动导航缩放控制区域
[self.mapView setAutoZoomControlArea:UIEdgeInsetsMake(100, 200,200, 200)]; 
// 设置自动导航缩放屏幕坐标
[self.mapView setAutoZoomCameraPosition:CGPointMake(100, 100)];
```
