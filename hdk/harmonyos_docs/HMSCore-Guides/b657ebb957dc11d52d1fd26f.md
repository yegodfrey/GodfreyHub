# 获取鉴权信息

#### 场景介绍

华为帐号是用户访问并使用个人云端文件的凭证，因此在初始化Drive之前，应用需要先引导用户登录华为帐号。在登录成功后，才能通过用户华为帐号基本信息进行Drive RESTful API接口调用。  

#### 业务流程

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916154808.34805118954122966876798212712344:50001231000000:2800:21BDA2137AFEAB15F10B02E490A680D4CFF7E082831283BDA9B3E73C6AD6A664.png "点击放大")

整体流程：

1. 用户选择华为帐号登录方式登录应用。
2. [华为帐号](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-get-access-token-0000001050048946)拉起用户登录授权界面，界面上会根据登录请求中携带的授权域（scope）信息，显式告知用户需要授权的内容。
3. 用户手动允许授权后，华为帐号返回Authorization Code信息。
4. 应用通过填入Authorization Code及待调用接口的必要字段后发送调用请求。
5. 华为云空间服务侧处理相关逻辑，并返回处理后的结果报文。

不同的Drive Scope对应不同的权限，详见下表：  

|Scope名称|权限描述|
|:--------------------------------------------------|:----------------------------------------------|
|https://www.huawei.com/auth/drive.file|只允许访问由应用程序创建或打开的文件。|
|https://www.huawei.com/auth/drive.appdata|支持App数据上传和存储。|
|https://www.huawei.com/auth/drive|用户所有文件访问权限，应用数据文件夹除外。|
|https://www.huawei.com/auth/drive.readonly|允许对文件元数据和文件内容的只读访问。|
|https://www.huawei.com/auth/drive.metadata|允许对文件元数据进行读写访问，但不允许读取、下载、写入或上传文件内容。不支持文件的创建和删除。|
|https://www.huawei.com/auth/drive.metadata.readonly|允许对文件元数据进行只读访问，但不允许读取或下载文件内容。|
