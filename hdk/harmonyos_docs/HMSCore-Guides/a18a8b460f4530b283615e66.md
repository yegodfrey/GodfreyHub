# 软件结构及模块图

用户可以通过运动健康App 查看接入设备的特点、购买和绑定设备、测量及输入参数等。App 通过接口与外设连接并获取数据，当前支持使用蓝牙设备和非蓝牙设备。

## 设备接入结构图

当前程序框架支持三方设备通过蓝牙接口和非蓝牙接口接入，运动健康App 接入三方健康设备后，用户可以在设备管理界面绑定设备，绑定成功后可以使用设备进行测量。

* 设备操作层：定义和实现了设备测量过程中所需要的各种业务接口，包括开始测量、停止测量、上报数据等操作。
* 设备接口层：封装与健康设备通信的基础接口。

## 设备接入模块图

三方设备厂商开发 SDK 解析其设备协议，将 SDK 和设备其他资源按照运动健康插件的形式打包，华为团队审核通过后，将SDK 加密上传到华为服务器。用户查询到新的可用设备后，可以下载相关的插件（通过插件管理模块）。

使用"插件管理"模块下载和管理设备资源。
