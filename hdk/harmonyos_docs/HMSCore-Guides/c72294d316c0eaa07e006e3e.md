# 控制运动并获取实时运动数据

Health Service Kit扩展能力服务提供了开始和结束运动的接口[startSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__startSport-android_content_Context-int-com_huawei_hihealth_listener_ResultCallback-)/[stopSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__stopSport-android_content_Context-com_huawei_hihealth_listener_ResultCallback-)，开发者可以直接在应用内调用接口，后台控制运动健康App中对应运动状态，无需跳转到华为运动健康App运动界面进行操作，此时运动健康App不会弹出运动页面，而是在后台执行。目前支持的运动类型：户外步行、户外跑步、户外骑行、室内跑步（跑步机）、椭圆机、划船机、室内单车。

如果您的应用是配合生态设备使用的，而且已经提前获取了设备的MAC信息， 开发者可调用[startSportEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__startSportEx-android_content_Context-com_huawei_hihealth_StartSportParam-com_huawei_hihealth_listener_ResultCallback-)方法开启特定设备的运动。支持两种启动方式：前台启动和后台启动。前台运动方式会弹出设备配对页面，配对成功后转至实时运动页面（参考图1）,前台运动只支持划船机。后台运动方式不会弹出页面，会静默连接设备并开启运动，后台运动支持划船机、单车设备、跑步机、椭圆机。

针对上述两种控制方式，如果用户绑定了华为穿戴设备，启动运动时，穿戴设备将自动进入运动界面；结束运动时，穿戴设备将自动结束运动。

Health Service Kit扩展能力服务同时提供了获取实时运动数据和停止获取实时运动数据的接口[registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__registerSportData-android_content_Context-com_huawei_hihealthkit_data_store_HiSportDataCallback-)/[unregisterSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__unregisterSportData-android_content_Context-com_huawei_hihealthkit_data_store_HiSportDataCallback-)，为防止数据丢失，一般在开始运动之前调用获取实时运动数据接口，在停止运动之后调用停止获取实时运动数据接口。 如果用户连接了支持心率测量的穿戴设备，则可以获取到心率数据。具体场景获取的数据类型请参考[实时运动Bundle对象键值](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-bundle-key-0000001420487908)，回调频率：1秒一次。

控制运动和获取实时运动配合使用顺序一般为：

1. [registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__registerSportData-android_content_Context-com_huawei_hihealthkit_data_store_HiSportDataCallback-)，开始获取实时运动数据。
2. [startSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__startSport-android_content_Context-int-com_huawei_hihealth_listener_ResultCallback-)(sportType)/[startSportEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__startSportEx-android_content_Context-com_huawei_hihealth_StartSportParam-com_huawei_hihealth_listener_ResultCallback-)(startSportParam)，开始运动。
3. [sendDeviceControlinstruction](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__sendDeviceControlinstruction-android_content_Context-java_lang_String-com_huawei_hihealth_listener_ResultCallback-)，对设备进行控制。
4. [stopSport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__stopSport-android_content_Context-com_huawei_hihealth_listener_ResultCallback-)()，停止运动。
5. [unregisterSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__unregisterSportData-android_content_Context-com_huawei_hihealthkit_data_store_HiSportDataCallback-)，停止获取实时运动数据。

使用接口前，需要向华为申请开通权限，并获取用户授权，否则接口将调用失败。
> 说明
>
> 当用户在运动健康App内启动运动或配对运动器械（通过华为认证的跑步机、椭圆机、划船机、室内单车）后在器械上启动运动，开发者调用[registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__registerSportData-android_content_Context-com_huawei_hihealthkit_data_store_HiSportDataCallback-)接口同样可以获取对应运动的实时数据。

## 开始获取实时运动数据

1. 调用[HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459)对象的[registerSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__registerSportData-android_content_Context-com_huawei_hihealthkit_data_store_HiSportDataCallback-)方法，开始获取实时运动数据。
2. 通过请求参数[HiSportDataCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hisportdatacallback-0000001072149462)对象，返回查询结果，结果中数据类型参考[实时运动Bundle对象键值](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-bundle-key-0000001420487908)。

示例代码：

```screen
HiHealthDataStore.registerSportData(context, new HiSportDataCallback() {    
    @Override    
    public void onResult(int resultCode) {
        // 接口调用结果 
        Log.i(TAG, "registerSportData onResult resultCode:" + resultCode); 
        if (resultCode == HiHealthError.SUCCESS) {
            // 注册运动数据监听成功
            Log.i(TAG, "Succeeded in registering the callback");
        } else if (resultCode == HiHealthError.ERR_HEALTH_SERVICE_DISCONNECTED) {
            // 与运动健康连接断开
            Log.w(TAG, "HealthKit service was disconnected");
        } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
            // HMS Core版本过低
            Log.w(TAG, "HMS version is too early");
        } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
            // 授权失效
            Log.w(TAG, "Permission denied");
        } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
            // 未同意运动健康隐私协议
            Log.w(TAG, "Privacy user denied");
        } else if (resultCode == HiHealthError.ERR_NETWORK) {
            // 网络异常
            Log.w(TAG, "Network request failed");
        } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
            // 测试权限的用户数量超过限制
            Log.w(TAG, "Beta scope permission denied");
        } else {
            // 其他错误，建议提示调用失败
            Log.w(TAG, "Other error, invoking method failed");
        }
    }

    @Override    
    public void onDataChanged(int state, Bundle bundle) {
        // 实时数据变化回调        
        Log.i(TAG, "registerSportData onChange state: " + state);        
        StringBuffer stringBuffer = new StringBuffer("");              
        if (state == HiHealthKitConstant.SPORT_STATUS_RUNNING) {
            Log.i(TAG, "heart rate : " + bundle.getInt(HiHealthKitConstant.BUNDLE_KEY_HEARTRATE));
            Log.i(TAG, "distance : " + bundle.getInt(HiHealthKitConstant.BUNDLE_KEY_DISTANCE));
            Log.i(TAG, "duration : " + bundle.getInt(HiHealthKitConstant.BUNDLE_KEY_DURATION));
            Log.i(TAG, "calorie : " + bundle.getInt(HiHealthKitConstant.BUNDLE_KEY_CALORIE));
            Log.i(TAG, "totalSteps : " + bundle.getInt(HiHealthKitConstant.BUNDLE_KEY_TOTAL_STEPS));
            Log.i(TAG, "totalCreep : " + bundle.getInt(HiHealthKitConstant.BUNDLE_KEY_TOTAL_CREEP));
            Log.i(TAG, "totalDescent : " + bundle.getInt(HiHealthKitConstant.BUNDLE_KEY_TOTAL_DESCENT));
        } else if (state == HiHealthKitConstant.SPORT_STATUS_PAUSED) {
            // 运动暂停，部分设备能控制运动暂停，端侧需要适配下运动状态变更
            Log.i(TAG, "paused");
        } else if (state == HiHealthKitConstant.SPORT_STATUS_RESUMED) {
            // 运动暂停后恢复，部分设备能控制运动暂停后恢复，端侧需要适配下运动状态变更
            Log.i(TAG, "resumed");
        } else if (state == HiHealthKitConstant.SPORT_STATUS_STOPPED) {
            // 运动停止，部分设备能控制运动停止，端侧需要适配下运动状态变更
            Log.i(TAG, "stopped");
        } else {
            // 其他运动状态
            Log.i(TAG, "Other sport status");
        }
    }
});
```

## 停止获取实时运动数据

1. 调用[HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459)对象的[unregisterSportData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__unregisterSportData-android_content_Context-com_huawei_hihealthkit_data_store_HiSportDataCallback-)方法，停止获取实时运动数据。
2. 通过请求参数[HiSportDataCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hisportdatacallback-0000001072149462)对象，返回查询结果。

示例代码：

```screen
HiHealthDataStore.unregisterSportData(context, new HiSportDataCallback() {    
    @Override    
    public void onResult(int resultCode) {
        // 接口调用结果
        Log.i(TAG, "unregisterSportData onResult resultCode:" + resultCode);   
        if (resultCode == HiHealthError.SUCCESS) {
            // 反注册运动数据监听成功
            Log.i(TAG, "Succeeded in unregistering the callback");
        } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
            // 未同意运动健康隐私协议
            Log.w(TAG, "Privacy user denied");
        } else {
            // 其他错误，建议提示调用失败
            Log.w(TAG, "Other error, invoking method failed");
        }
    }

    @Override    
    public void onDataChanged(int state, Bundle bundle) {
        // 此时不会被调用     
    }
});
```

## 根据运动类型开始运动

> 说明
>
> * 户外步行/跑步/骑行运动所需手机系统权限：GPS定位、存储权限、后台位置权限。
> * 室内跑步（跑步机）/椭圆机/划船机/室内单车/自由训练运动所需手机系统权限：存储权限。

   **示例代码**：

   ```screen
   // 室外跑步
   int sportType = HiHealthKitConstant.SPORT_TYPE_RUN;
   HiHealthDataStore.startSport(context, sportType, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object message) {
           if (resultCode == HiHealthError.SUCCESS) {
               Log.i(TAG, "start sport success");
           } else if (resultCode == HiHealthError.ERR_HEALTH_VERSION_IS_NOT_SUPPORTED) {
               // 运动健康版本过低，不支持此运动类型
               Log.w(TAG, "Health application need to be updated");
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_REPEAT_EXCEPTION) {
               // 重复调用，如：设备连接中但未开始运动时又调用开启运动
               Log.w(TAG, "Repeat error");
           } else if (resultCode == HiHealthError.ERR_DEVICE_NOT_CONNECTED) {
               // 开启有氧四件套运动时，设备被移除
               Log.w(TAG, "Device not connected");
           } else if (resultCode == HiHealthError.ERR_WRONG_DEVICE) {
   ```

## 对设备下发控制指令

> 说明
>
> * 调用了startSport/startSportEx方法，并且成功启动运动后，通过调用设备下发控制指令sendDeviceControlinstruction接口，控制当前正在运动的设备的属性值。
> * 踏频的范围是(0, 655]，功率的范围是(0, 32767]。踏频参数是可选的，参数中不指定则默认是60转/分钟。
> * 当前只支持调节在运动健康已接入、且支持通过踏频和功率调阻协议的单车（当前只支持接入了运动健康的"Mobifitness动感单车"）。其中，踏频和功率值组合起来，发送给设备后，设备查询预置在内部的功率表，查询到最接近的阻力档位，进行调节。
> * 注意：调节单车阻力的目的是便于在竞技场景下，保证不同用户使用不同单车，也能保证相同做功下，有相同的阻尼。
