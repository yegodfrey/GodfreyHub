# 关键字搜索

通过用户输入的关键字，返回地点列表。

* Deeplink样例：

  ```screen
  petalmaps://textSearch?text=xxxtxt&utm_source=fb
  ```

* Applink样例：

  ```screen
  https://www.petalmaps.com/textSearch/?text=xxxtxt&utm_source=fb
  ```

* 参数列表：

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:-----------------------------------|
  |text|是|String|关键字搜索的关键词（deeplink方式），参数text和q只需二选一。|
  |q|是|String|关键字搜索的关键词（applink方式），参数text和q只需二选一。|
  |utm_source|否|String|渠道来源（应用可以传入App包名或者应用名）。|
  |utm_medium|否|String|媒介。|
  |utm_campaign|否|String|运营活动名称。|
  |utm_term|否|String|运营活动关键词。|
  |utm_content|否|String|运营活动内容。|


* 代码样例

  Intent方式：

  ```screen
  Uri content_url = Uri.parse("petalmaps://textSearch?text=xxxtxt&utm_source=fb");
  Intent intent = new Intent(Intent.ACTION_VIEW, content_url); 
  if (intent.resolveActivity(getPackageManager()) != null) {
       startActivity(intent); 
  }
  ```

  直接点击链接方式：

  ```screen
  https://www.petalmaps.com/textSearch/?text=xxxtxt&utm_source=fb
  ```
