# 浮标

## 场景介绍

发布地区包含中国大陆的游戏，必须集成游戏助手。游戏助手是指游戏界面中以浮标方式展示华为游戏中心的入口，用户点击浮标后可以使用用户在华为游戏中心的游戏增值功能，如浏览论坛、领取礼包、查看攻略、游戏录屏等。

不同类型的设备上浮标的显示有差异，如下的浮标示意图供您参考。请您务必使用不同类型的的设备完成浮标功能测试，以便快速通过审核。

### EMUI 9.1以下版本的华为设备或者三方设备

您需要按照本文档要求集成游戏浮标，并且设备必须安装9.0以上版本华为应用市场客户端才能展示浮标。

## 前提条件

必须在[JosAppsClient.init(AppParams appParams)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/josappsclient-0000001050121680#section12941311162615)方法调用成功后实现浮标功能，调用方法请[游戏初始化](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-start-0000001050123475)。

## 注意事项

发布地区包含中国大陆的联运游戏，要求必须集成游戏浮标功能，游戏的所有界面都需要展示游戏浮标。

## 开发步骤

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250212154817.51622667953418556304278894756729:50001231000000:2800:E9F269B00CCF6909CF8C5198370E147F552A5C16528563CB9F7E69960492C361.png?needInitFileName=true?needInitFileName=true)

本功能涉及的关键开发步骤如下：

1. 在游戏初始化成功之后和所有游戏界面Activity的onResume中调用[showFloatWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/buoyclient-0000001050123633#section17952328272)接口展示浮标。

   ```screen
   Games.getBuoyClient(this).showFloatWindow();
   ```

   > 说明
   > * 游戏调试阶段，需要测试浮标能正常拖动、隐藏，翻转手机浮标能显示。如果点击浮标界面提示"没有相关内容"或"无法连接服务器，请稍后重试"，是因为游戏没有在华为应用市场上架过，调试时可忽略。
   >
   > * 如需在EMUI 9.1及以上或者HarmonyOS系统版本终端测试浮标功能，需要通过"设置 > 应用和服务 > 应用助手 > 游戏空间"将应用加入游戏空间中。

2. 在所有游戏界面Activity的onPause中调用[hideFloatWindow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/buoyclient-0000001050123633#section91343409278)接口隐藏浮标。

   ```screen
   Games.getBuoyClient(this).hideFloatWindow();
   ```
