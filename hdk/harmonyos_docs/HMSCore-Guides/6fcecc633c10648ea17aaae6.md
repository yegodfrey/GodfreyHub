# 按华为分析埋点方案操作流程

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/30pzOkfVSkirqrBy2Dcs5g/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=0CC33607F2D931498CC79F68081028884502D210FDFA7A8AF6CEE9E502D80A40)

您最多可以创建100个代码模板，其中包含在HUAWEI Analytics中创建的模板，即在DTM和HUAWEI Analytics中创建的模板总数不超过100个。

                1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击“我的项目”图标。
                2. 在项目列表中找到您的项目，并选择需要埋点的应用。
                3. 选择“华为分析 > 智能数据接入 > 埋点开发”进行埋点方案配置及添加埋点，详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。
