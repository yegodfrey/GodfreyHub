# 将HmsScan对象转化为JSON字符串

1. 引入第三方依赖库，以google gson为例。

   ```screen
   implementation 'com.google.code.gson:gson:2.8.5'
   ```

2. 将HmsScan对象转化为JSON字符串。

   ```screen
   public String hmsScanToGson(HmsScan hmsScan) {
       Gson gson = new Gson();
       String hmsScanStr = gson.toJson(hmsScan);
       return hmsScanStr;
   }
   ```
