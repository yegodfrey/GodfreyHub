# 汽车

#### 事件参数列表

      * REGISTERACCOUNT

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 用户来源 | String | 可选 | 用户来源。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
INVITER | 邀请人 | String | 可选 | 邀请该用户进行注册的用户。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
BRAND | 设备归属品牌 | String | 可选 | 设备品牌。 针对汽车行业代表车辆品牌，如奔驰、宝马等。  
SERIES | 设备归属系列 | String | 可选 | 设备系列。 针对汽车行业代表车系。  
MODEL | 设备型号 | String | 可选 | 设备型号。 针对汽车行业代表车型，比如SUV，轿车、MPV、皮卡、跑车、其他。  
DEVICETYPE | 操作设备类型 | String | 可选 | 当前操作的设备类型枚举值。 针对汽车行业固定值：Car。  
DEVICENAME | 设备名称 | String | 可选 | 设备名称。
