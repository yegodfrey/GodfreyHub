# 实施建议

|**类别**|**实施建议**|
|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|索引组织|可按照帐号、contentType、内部功能模块等多个维度的值组合生成groupid，以便在删除索引的时候，直接基于groupid删除。如使用MD5(登录帐号)+"shoppingcart"作为帐号下购物车数据的Groupid，用户清空购物车的时候，基于如上groupid来删除。|
|索引维护|displayName、title在检索匹配阶段相同的优先级，仅设置一个即可。|
|索引维护|增量管理索引。在App内部管理索引状态，避免整体删除、插入操作。如购物车索引，记录索引到的时间戳。下次增加索引，仅针对上面时间戳之后的数据创建索引。|
|索引维护|更新索引条目，记录metadataModificationDate，以便FusionSearch感知到索引条目的修改时间。|
|索引维护|用户行为数据(isBrowsed、isAddedtocollection、isAddedtoCart、isAddedToFavorites任意一个字段为true)，使用userActivityDate记录用户行为发生的时间。系统默认使用索引创建或更新时间作为"用户行为数据"的userActivityDate的值|
|索引过期 引过期|用户行为数据(isBrowsed、isAddedtocollection、isAddedToFavorites、contentType任意一个字段为true)设置expirationDate为索引项的过期时间。特别是isBrowsed，建议设置为7天后过期。|
|索引过期|非用户行为数据在创建索引的时候，设置expirationDate。以便FusionSearch做定期的数据清理。|
