# 业务简介

## 概述

[HarmonyOS](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/harmonyos-overview-0000000000011903-V3)的应用软件包以Application Package（以下简称APP Pack）形式发布，它是由一个或多个HarmonyOS Ability Package（以下简称HAP）以及描述每个HAP属性的pack.info组成。HAP是[Ability](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/basic-fundamentals-0000000000041611-V3#section121002188527)的部署包，HarmonyOS应用代码围绕Ability组件展开。

集成Account SDK Java ForHarmony后，该HarmonyOS应用可以使用华为帐号进行登录、静默登录、退出、取消授权。

HarmonyOS客户端API请参见[HarmonyOS客户端API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/account-harmonyos-java-api-index-0000001116222750)。

## 服务特点

* 接入方便，规范统一 服务手机、平板等全场景生态，接入规范统一，方便您接入华为生态。

*

  **快捷登录**

  一键快捷登录，用户无需输入帐号、密码等繁琐验证，帮助用户快速登录，提供绝佳的使用体验。

  **按需授权**

  支持逐步授权，应用不必一开始就请求需要的所有信息，可以根据场景按需申请头像昵称、手机号码等数据授权。

  **身份验证**

  提供身份验证服务，在用户进行敏感操作时，支持当前设备指纹、设备人脸、帐号密码以及实名认证等方式，用以验证用户的身份。

  **安全可靠**

  华为帐号受到双因素认证保护，支持基于OpenID基金会的RISC标准，用于主动保障开发者应用多帐号安全性的安全加固部件，风险实时通知，安全保护用户的数字资产和个人隐私。
