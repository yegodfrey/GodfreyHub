# Snap to Roads API

Snap to Roads API可以根据给定的坐标点捕捉道路，将用户的轨迹纠正到道路上，从而返回用户实际驾车经过的道路坐标。

具体使用方式请参见[Snap to Roads API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/snap_to_roads_api-0000001232632093)。
