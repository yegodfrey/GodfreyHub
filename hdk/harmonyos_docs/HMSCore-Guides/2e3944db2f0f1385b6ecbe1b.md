# playerId替换为openId方案

#### 背景说明

为了采用更安全的OAuth 2.0协议实现游戏帐号登录，游戏服务中playerId需要逐步替换为openId。如果您当前使用playerId作为玩家的唯一标识，当前版本仍然兼容，但建议您尽快完成替换。  

#### 第一阶段：建立openId与playerId对应关系

<br />

第一阶段的替换步骤如下：

1. [华为帐号授权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526#section62416388335)成功后使用[PlayersClient.getGamePlayer(boolean isRequirePlayerId)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42711354164416)方法登录游戏，isRequirePlayerId传入true。

   从返回的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象中获取玩家的openId、playerId。
2. playerId和openId的验证不再调用[校验登录签名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/verify-login-signature-0000001050123503)接口，修改为调用[从游戏服务器获取用户标识](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gettokeninfo-0000001343252157)接口，根据玩家[Access Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526#section163812617171)从华为游戏服务器获取用户标识后，与[PlayersClient.getGamePlayer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)返回的用户标识进行比对，完成一致性验证。

   只有验证成功后，您的服务器才能建立openId与playerId的对应关系。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250212154823.13064681944650824872489604244399:50001231000000:2800:3B99670D0927C94F6416588DA728D5050F652A873D9AF98D92FB9567597985A5.png?needInitFileName=true?needInitFileName=true)  
   openId当前非固定长度，最大允许长度256，需进行三倍冗余考虑，不推荐进行长度限制。
3. 此阶段完成后，您需要上架游戏并等待用户更新游戏后重新登录，以获取用户的openId与playerId。在第一阶段期间，如部分用户长时间不更新游戏并重新登录，您可以调用[批量查询openId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/query-openid-0000001452874029)接口查看playerId对应的openId，便于直接建立映射关系。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250212154823.64584719400086947739260636718123:50001231000000:2800:2F576741D4AC6B44FC1EFBFA90B508476E6D99990B7510E43B917D34F3D261FF.png?needInitFileName=true?needInitFileName=true)  
openId与playerId不能长期并存，请您尽快根据当前的用户覆盖率评估是否可以启动第二阶段。  

#### 第二阶段：以openId作为玩家标识，下线playerId

playerId与openId建立了对应关系后，您可以在新版本中进行如下修改：

1. 将[PlayersClient.getGamePlayer(boolean isRequirePlayerId)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42711354164416)方法中的isRequirePlayerId参数传入false或将方法替换为[PlayersClient.getGamePlayer()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668#section42128343142)，返回的[Player](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/player-0000001050121666)对象将不包含playerId、用户头像和玩家等级，用户头像可以从华为帐号授权成功后返回的[AuthHuaweiId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/account-support-hwid-result-authhuaweiid-0000001050048492)获取。玩家等级不再返回，您需要适配修改。
2. 调用[从游戏服务器获取用户标识](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/gettokeninfo-0000001343252157)接口验证用户标识时，不再验证playerId。
3. 下线playerId，使用openId替换。

第二阶段完成后最终的游戏登录流程请参见[游戏登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526)。
