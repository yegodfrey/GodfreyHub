# 处理好友代付

好友代付，即用户在您的应用内购买时，拉起好友代付收银台界面，用户可以将二维码分享给好友，好友扫码完成支付的一种支付方式。好友代付属于一种延迟付款型支付，延迟付款型支付请参考[处理延迟付款型支付](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/process-pending-payment-0000001180993022)。
> 注意
>
> * 您的应用须集成6.10.0.300及以上版本的IAP SDK，才可使用好友代付功能。
> * 好友代付功能不支持沙盒测试。
> * 仅使用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)接口购买一次性商品场景支持好友代付，包括消耗型商品、非消耗型商品。

若您的应用需要支持好友代付，可以按如下步骤改造您的应用。

1. 在应用初始化过程中，您的应用需要调用[enablePendingPurchase](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section19183633182613)方法来使能延迟付款型支付。
2. 构建请求参数[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842)，发起[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)请求。在创建[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842)请求对象时，需通过[setReservedInfor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/basereq-0000001347850688#section5685381934)方法传入如下内容，指定支付方式为好友代付。

   ```screen
   "{\"PayTypePolicy\":{\"DefaultPayment\":\"entrusted\"}}"
   ```

3. 若用户离开收银台时暂未完成支付，您的应用将接收到错误码60057（OrderStatusCode.ORDER_STATE_PENDING），标记此次交易处于Pending状态，代表用户已使用好友代付成功下单，正在等待好友付款，此时用户也可重新发起支付，重新发起支付后，原二维码失效。若已完成支付，您的应用将接收到返回码0（OrderStatusCode.ORDER_STATE_SUCCESS）和购买数据，此时按照标准流程处理即可，具体请参见[确认交易](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/dev-guide-0000001050130254#section1868165018437)。
4. 当订单从Pending状态变更为Purchased时您才能进行发货处理。为了能让您的应用尽快获取到订单的最新状态，及时给用户发货，IAP服务器提供了订单状态从Pending到Purchased的变更通知，具体请参见[接收延迟付款型支付关键事件通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/notifications-about-pending-payment-events-0000001184383570)。您的应用服务器可以通过监听处理该通知刷新订单状态，进行发货处理。
5. 若用户购买的商品是消耗型商品，应用服务器需要在发货成功之后请求服务端[Order服务确认购买](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-purchase-confirm-for-order-service-0000001051066054)接口消耗商品。
