# 写入跑步运动记录

用户可以使用之前收集的历史数据插入[ActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecord_class-0000001050161730)到Health Service Kit中，具体可执行以下操作：

1. 创建一个指定时间段和其他必要信息的[ActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecord_class-0000001050161730)。
2. 使用[ActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecord_class-0000001050161730)和可选的采样集或聚合采样点数据，创建一个[ActivityRecordInsertOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ario_class-0000001050091110)。
3. 使用[ActivityRecordsController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295).[addActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295#section1781411218216)插入[ActivityRecordInsertOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ario_class-0000001050091110)。

```
// 请注意此处的this为Activity对象
final ActivityRecordsController activityRecordsController = HuaweiHiHealth.getActivityRecordsController(this);
Context context = getApplicationContext();

// 1.构造请求对象的时间区间：开始和结束时间
// 请注意此处设置的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳
Calendar cal = Calendar.getInstance();
Date now = new Date();
cal.setTime(now);
long endTime = cal.getTimeInMillis();
cal.add(Calendar.HOUR_OF_DAY, -1);
long startTime = cal.getTimeInMillis();

// 2.构造运动记录配速对象PaceSummary
// ActivitySummary中的PaceSummary用来承载配速统计数据
ActivitySummary activitySummary = new ActivitySummary();
PaceSummary paceSummary = new PaceSummary();
paceSummary.setAvgPace(247.27626);
paceSummary.setBestPace(212.0);
paceSummary.setPartTimeMap((Map<String, Double>) new HashMap<>().put(1.0, 456));
paceSummary.setPaceMap((Map<String, Double>) new HashMap<>().put(1.0, 263));
paceSummary.setPartTimeMap((Map<String, Double>) new HashMap<>().put(1.0, 263));
activitySummary.setPaceSummary(paceSummary);


// 3.构造统计数据样本点，并添加至DataSummary对象
SamplePoint distanceTotalSamplePoint = new SamplePoint.Builder(DataType.DT_CONTINUOUS_DISTANCE_TOTAL).build()
    .setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
distanceTotalSamplePoint.getFieldValue(Field.FIELD_DISTANCE).setDoubleValue(400d);

SamplePoint speedTotalSamplePoint = new SamplePoint.Builder(DataType.POLYMERIZE_CONTINUOUS_SPEED_STATISTICS).build()
    .setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
speedTotalSamplePoint.getFieldValue(Field.FIELD_AVG).setDoubleValue(60.0d);
speedTotalSamplePoint.getFieldValue(Field.FIELD_MIN).setDoubleValue(40.0d);
speedTotalSamplePoint.getFieldValue(Field.FIELD_MAX).setDoubleValue(80.0d);

SamplePoint stepTotalSamplePoint = new SamplePoint.Builder(DataType.DT_CONTINUOUS_STEPS_TOTAL).build()
    .setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
stepTotalSamplePoint.getFieldValue(Field.FIELD_STEPS).setIntValue(1024);
activitySummary
    .setDataSummary(Arrays.asList(distanceTotalSamplePoint, speedTotalSamplePoint, stepTotalSamplePoint));

// 4.构造运动记录，设置统计数据ActivitySummary对象
ActivityRecord activityRecord = new ActivityRecord.Builder()
    .setName("AddActivityRecord")
    .setDesc("This is ActivityRecord add test!")
    .setId("MyAddActivityRecordId")
    .setActivityTypeId(HiHealthActivities.RUNNING)
    .setStartTime(startTime, TimeUnit.MILLISECONDS)
    .setEndTime(endTime, TimeUnit.MILLISECONDS)
    .setActivitySummary(activitySummary)
    .setMetadata("this is a exercise activity test")
    .setTimeZone("+0800")
    .build();

// 5.创建一个明细数据采集器
DataCollector dataCollector = new com.huawei.hms.hihealth.data.DataCollector.Builder()
    .setDataType(DataType.DT_INSTANTANEOUS_STEPS_RATE)
    .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
    .setPackageName(getApplicationContext())
    .setDataCollectorName("AddActivityRecord")
    .build();
// 6.根据明细数据采集器，构造采样集
SampleSet sampleSet = SampleSet.create(dataCollector);

// 7.构造步数增量明细（DT_CONTINUOUS_STEPS_DELTA）采样点对象，添加到明细采样集
SamplePoint samplePointStepDelta = sampleSet.createSamplePoint().setTimeInterval(startTime,endTime,TimeUnit.MILLISECONDS);
samplePointStepDelta.getFieldValue(Field.FIELD_STEP_RATE).setDoubleValue(100.0d);
sampleSet.addSample(samplePointStepDelta);

// 8.构造运动记录请求，设置运动记录activityRecord对象与其关联的明细采样集
ActivityRecordInsertOptions insertOption = new ActivityRecordInsertOptions.Builder()
    .setActivityRecord(activityRecord).addSampleSet(sampleSet).build();

// 9.调用addActivityRecord方法添加运动记录
Task<Void> addTask = activityRecordsController.addActivityRecord(insertOption);
addTask.addOnSuccessListener(new OnSuccessListener<Void>() {
    @Override
    public void onSuccess(Void aVoid) {
        Log.i("ActivityRecords","ActivityRecord add was successful!");
    }
}).addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        Log.i("ActivityRecords","Failed to add ActivityRecord" + e.getMessage());                      
    }
});
```
