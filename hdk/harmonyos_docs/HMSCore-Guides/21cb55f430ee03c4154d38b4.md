# Tile Service API

Tile Service提供自定义图层服务，创建并发布自定义图层大致可分为以下几个步骤：

1. 准备矢量/栅格数据源，调用数据管理API的"新增瓦片数据"接口上传数据。
2. 创建图层，调用图层管理API的"新增瓦片图层"接口指定数据编译规则及图层样式创建图层。
3. 发布图层，调用图层管理API的"发布瓦片图层"接口发布图层。

图层发布成功后，可通过图层ID将自定义图层添加到地图上，实现地图图层个性化位置数据效果展示。

使用Tile Service服务前，请联系华为地图运营团队（[mapteam@huawei.com](mailto:mapteam@huawei.com)）开通Tile Service权限。

## 数据管理API

通过数据管理API，可以上传、更新、查询、删除矢量/栅格数据。

* 矢量数据：geojson格式，按行分隔，且数据类型必须是点、线、面中的一种。
* 栅格数据：geotiff格式，包含坐标系、坐标边界、分辨率参数。

若上传数据文件较大，支持您打包上传，当前系统可处理的数据大小在1GB以内，如需处理超大数据，请联系华为地图运营团队（[mapteam@huawei.com](mailto:mapteam@huawei.com)）。

具体使用方式请参见数据管理API：

## 图层管理API

通过图层管理API，可以新增、更新、查询、删除和发布图层。图层由数据编译规则和图层样式组成，其中数据编译规则可以指定编译的最大/最小层级和编译范围，矢量图层样式支持点样式和面样式。

您还可以查询图层发布进度，若图层发布成功，使用图层ID调用Android客户端接口可以在地图上显示该图层。Android应用如何将自定义图层添加到地图上，请参见Tile Service[自定义图层](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/tile-service-layer-0000001262462347)。
