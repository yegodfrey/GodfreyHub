# 通知栏消息Inbox样式

不同于大文本样式，Inbox样式（[inbox_content](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1112332410540)）除了支持多行文本外还可以做到通知栏消息内容有序展示（您需要手动配置序号）。文本内容最多可展示5行，每行内容展示不了时后边自动添加"..."，如下图所示。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095829.99168710937409411882162806216830:50001231000000:2800:1EE7285E00AE1CA000CF9FEEDA3C13E51B243DD19EC856CF4706C802276F1932.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

消息体示例：

```screen
{
    "validate_only": false,
    "message": {
        "android": {
            "notification": {
                "title": "推送服务",
                "body": " message body",
                "click_action": {
                    "type": 3
                },
               "style": 3,
"inbox_content": ["1.多种推送样式","2.精细人群划分", "3.自动推送通知", "4.推送统计报告", "5.智能消息回执"]
            }
        },
        "token": ["pushtoken1"]
    }
}
```

> 说明
>
> [inbox_content](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1112332410540)数组范围为2至5时建议使用Inbox样式，该范围之外建议采用[通知栏消息大文本样式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-large-text-style-0000001050042081)。
