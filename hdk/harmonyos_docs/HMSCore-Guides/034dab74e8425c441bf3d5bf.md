# 面积计算

计算几何面的面积。

## 实现步骤

1. 通过HWMapJsSDK创建[HWPolygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwpolygon-0000001050710118)对象。
2. 通过HWMapJsSDK.HWGeometryUtil调用getPolygonArea方法，传入第一步创建的[HWPolygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwpolygon-0000001050710118)对象。
3. 返回值为多边形图形面积，单位：平方米。

## 示例代码

```javascript
var map;
var mapOptions = {};
mapOptions.zoom = 15;
map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions);
var polygon = new HWMapJsSDK.HWPolygon({
  map: map,
  paths: [
    [
      {lat: 49, lng: 2},
      {lat: 48.5, lng: 2.5},
      {lat: 48, lng: 1.5}
    ],
  ],
  fillColor: '#333',
  strokeColor: '#488',
  strokeWeight: 5,
  strokeLineDash: [20, 10]
});
var HWGeometryUtil = HWMapJsSDK.HWGeometryUtil;
var polygonArea = HWGeometryUtil.getPolygonArea(polygon);
```
