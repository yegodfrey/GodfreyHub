# 开发准备

## 创建应用

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"，在项目列表中找到您的项目，上方导航栏选择应用处，点击添加应用。
2. 填写应用的相关信息。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095841.45510381112123640343304172187500:50001231000000:2800:4526B8D5460FB854579A998F3A3DC93F6B83A6CD2B4ABFA2E81FC5D749AEB2AF.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
   * 选择平台：选择您应用的平台。
   * 应用名称：Web应用在AppGallery Connect显示的名称，最大64个字符。

## 开通WebPush代理权益

在开通Push基础权益之后，开通WebPush代理权益。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"，在项目列表中找到您的项目，通过"增长 > 推送服务 > 配置"导航到"配置"页签，选择您的Web应用。

## WebPush代理生成密钥对

* 在"Web推送配置"中点击"生成密钥对"，得到有效的密钥对。

  ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095841.00537097440278350323669468867723:50001231000000:2800:C8E24ED7D8E46566D7121A5E1EC9C67FB064FE3FA7EEF0619334369FA436B005.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")


* 您也可使用命令行生成您的密钥对，密钥对生成后在"Web推送配置"选项中导入您的密钥（去除任何的换行符）。
  1. 生成VAPID秘钥。

     ```screen
     openssl ecparam -name prime256v1 -genkey -noout -out vapid_private.pem
     ```

  2. 创建密钥DER形式base64编码。

     ```screen
     openssl ec -in ./vapid_private.pem -outform DER|tail -c +8|head -c 32|base64|tr -d '=
     ' |tr '/+' '_-' >> private_key.txt
     openssl ec -in ./vapid_private.pem -pubout -outform DER|tail -c 65|base64|tr -d '=
     ' |tr '/+' '_-' >> public_key.txt
     ```
