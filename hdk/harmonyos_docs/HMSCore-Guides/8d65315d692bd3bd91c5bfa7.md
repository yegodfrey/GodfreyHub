# 查询健康类数据

查询华为运动健康App中用户的睡眠、压力、体重、血糖、血压、心率、体温、血氧数据集合。

* 睡眠数据来自于用户使用华为穿戴设备记录的用户睡眠数据，包含睡眠得分、睡眠时长等。
* 压力数据来自于用户使用华为穿戴设备记录的压力值，需在华为运动健康App"健康"中点击"压力"卡片开启压力检测功能。
* 体重、血糖、血压数据来自于华为运动健康App"设备 > 添加设备"中支持的体脂秤、血糖仪、血压计测量的数据及手动输入的数据和应用写入的数据集合。
* 心率、体温、血氧数据来自于用户使用华为穿戴设备及来自华为运动健康App"设备 > 添加设备"中支持的心率设备、体温计、血氧仪测量的数据集合。

> 说明
>
> * 若要读取科学睡眠数据，需要进入华为运动健康App"设备"，点击进入设备详情页，打开"科学睡眠"开关。
> * 若集成的是 5.0.0.500 及以下版本，在查询体重、血压、血糖数据时，一次只能查询30天内的数据。超过30天，则需要进行多次查询，如：60天的数据需要分两次查询，每次查询30天的数据。若集成的是 5.1.0.300 及以上版本，则可以使用[分页查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-pagination-query-0000001071262988)，无此限制。
> * 压力、心率详情仅支持查询最近7天内的历史详情数据。
> * 6.3.0.300及以上版本体温使用新类型HiHealthPointType.[DATA_POINT_NEW_BODY_THERMOMETER](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthpointtype-0000001071707433#ZH-CN_TOPIC_0000002516362110__DATA_POINT_NEW_BODY_THERMOMETER)，原有体温类型HiHealthPointType.[DATA_POINT_BODY_THERMOMETER](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthpointtype-0000001071707433#ZH-CN_TOPIC_0000002516362110__DATA_POINT_BODY_THERMOMETER)将废弃。
> * 健康类数据中的体重数据和体脂数据含义相同，均包含体重测值、BMI、脂肪率、肌肉量等体脂秤测量的数据。

## 使用execQuery接口查询健康类数据

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [execQuery](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__execQuery-android_content_Context-com_huawei_hihealthkit_HiHealthDataQuery-int-com_huawei_hihealth_listener_ResultCallback-) 方法，查询健康类数据。
2. 通过请求参数 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451) 对象，返回查询结果。

   **示例代码1**：体重为例

   ```screen
   int timeout = 0;
   // 设置查询的开始和结束时间
   long endTime = System.currentTimeMillis();
   long startTime = endTime - 86400000L * 30;
   HiHealthDataQuery hiHealthDataQuery = new HiHealthDataQuery(HiHealthSetType.DATA_SET_WEIGHT_EX, startTime,
       endTime, new HiHealthDataQueryOption());
   HiHealthDataStore.execQuery(context, hiHealthDataQuery, timeout, new ResultCallback() {
       @Override
       public void onResult(int resultCode, final Object data) {
           if (resultCode == HiHealthError.SUCCESS && data instanceof List) {
               Log.i(TAG, "query not null,enter set data");
               List dataList = (List) data;
               for (Object obj : dataList) {
                   HiHealthSetData hiHealthData = (HiHealthSetData) obj;
                   // the utc start time that generate data
                   Log.i(TAG, "data start time : " + hiHealthData.getStartTime());
                   // the utc end time that generate data
                   Log.i(TAG, "data end time : " + hiHealthData.getEndTime());
                   Map map = hiHealthData.getMap();
                   Log.i(TAG, "weight : weight " + map.get(HiHealthPointType.DATA_POINT_WEIGHT));
                   Log.i(TAG, "weight : bmi " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_BMI));
                   Log.i(TAG, "weight : muscle volume " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_MUSCLES));
                   Log.i(TAG, "weight : basic metabolism " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_BMR));
                   Log.i(TAG, "weight : moisture " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_MOISTURE));
                   Log.i(TAG, "weight : visceral fat " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_FATLEVEL));
                   Log.i(TAG, "weight : bone mineral content "
                       + map.get(HiHealthPointType.DATA_POINT_WEIGHT_BONE_MINERAL));
                   Log.i(TAG, "weight : protein " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_PROTEIN));
                   Log.i(TAG, "weight : body score " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_BODYSCORE));
                   Log.i(TAG, "weight : physical age " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_BODYAGE));
                   Log.i(TAG,
                       "weight : body fat percentage " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_BODYFAT));
                   Log.i(TAG, "weight : body fat scale " + map.get(HiHealthPointType.DATA_POINT_WEIGHT_IMPEDANCE));
                   Log.i(TAG, "weight : moisture percentage "
                       + map.get(HiHealthPointType.DATA_POINT_WEIGHT_MOISTURERATE));
                   Log.i(TAG, "weight : skeletal muscle mass  "
                       + map.get(HiHealthPointType.DATA_POINT_WEIGHT_SKELETAL_MUSCLE_MASS));
                   Log.i(TAG, "weight : LHRH impedance  "
                       + map.get(HiHealthPointType.DATA_POINT_WEIGHT_LHRHIMPEDANCE));
                   Log.i(TAG, "weight : LHRHHF impedance  "
                       + map.get(HiHealthPointType.DATA_POINT_WEIGHT_LHRHHFIMPEDANCE));
               }
           } else if (resultCode == HiHealthError.PARAM_INVALID) {
               // 参数错误
               Log.w(TAG, "Param invalid");
           } else if (resultCode == HiHealthError.ERR_HEALTH_VERSION_IS_NOT_SUPPORTED) {
               // 运动健康版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
               // 授权失效
               Log.w(TAG, "Permission denied");
           } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
               // 未同意运动健康隐私协议
               Log.w(TAG, "Privacy user denied");
           } else if (resultCode == HiHealthError.ERR_NETWORK) {
               // 网络异常
               Log.w(TAG, "Network request failed");
           } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
               // 测试权限的用户数量超过限制
               Log.w(TAG, "Beta scope permission denied");
           } else {
               // 其他错误，建议提示调用失败
               Log.w(TAG, "Other error, invoking method failed");
           }
       }
   });
   ```
