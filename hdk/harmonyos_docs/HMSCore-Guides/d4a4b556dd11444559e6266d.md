# 快应用

登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"，在项目列表中找到您的项目，通过"增长 \> 推送服务 \> 推送通知"，在"推送通知"页签下点击"添加推送通知"新建推送任务。  

#### 推送通知栏消息

#### 设置消息内容

填写消息内容基本信息：  

|字段值|说明|
|:-----|:--------------------------------------------------------------------------------------------------------------------|
|名称|必填字段，标识[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中的推送通知，不会显示在用户终端设备上。|
|消息类型|暂支持通知栏消息。|
|消息摘要|可选字段，通知栏消息的摘要，最多为40个字符长度。|
|消息标题|必填字段，通知栏消息的标题，最多为40个字符长度。|
|消息内容|必填字段，通知栏消息的内容，最多为1024个字符长度。|
|点击通知动作|点击消息后触发的动作，您需要在推送范围中的[后续行为](#ZH-CN_TOPIC_0000001652491944__li151311126184718)中设置。|
|通知按钮|快应用暂不支持。|

#### 设置推送范围

快应用的"推送范围"目前支持"指定设备"、"订阅用户"。

* "指定设备"：根据目标设备的[Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/quick-dev-0000001050042109#section516011831414)进行推送消息，目前最大支持数量为500个。
* "订阅用户"：根据订阅或者未订阅主题列表推送消息。

* 后续行为：当用户点击消息后的操作，可选择跳转应用首页或者跳转应用内页。其中跳转应用内页URI样例如下

  ```
  /page1?key1=value1&key2=value2
  ```

  参数解释如下：
  * /page1：快应用manifest.json中注册的页面的path。

#### 发送消息

当您完成上述步骤后，点击右上方"提交"即可推送消息。
