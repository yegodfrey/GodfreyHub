# 创建地图实例

## 地图容器

目前地图SDK支持的地图容器有六种，包括[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)、[MapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapfragment-0000001050150294)、[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)、[TextureMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/texturemapview-0000001051004791)、[TextureMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/texturemapfragment-0000001050724736)、[TextureSupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/texturesupportmapfragment-0000001051084710)。以下介绍两种常用地图容器[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)、[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)：

* [SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)是Android Fragment的子类，允许您将地图放置在Fragment中。[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)可以充当地图的容器，并提供对[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的访问入口。
* [MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)是Android View类的子类，允许您将地图放置在Android视图中。与[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)非常相似，[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)充当地图的容器，通过[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象展示核心地图功能。在常规地图交互模式下调用API时，[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)类的使用者必须在对应的Activity/Fragment的方法中调用以下方法：[onCreate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section5701320154117)()、[onStart](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1929311316455)()、[onResume](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section127594720434)()、[onPause](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section119871413124319)()、[onStop](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1185125812451)()、[onDestroy](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1991150164217)()、[onSaveInstanceState](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section17492429104415)(Bundle outState)和[onLowMemory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1298412345428)()，具体参见[MapViewCodeDemoActivity.java](https://github.com/HMS-Core/hms-mapkit-demo-java/blob/master/java/app/src/main/java/com/huawei/hms/maps/sample/MapViewCodeDemoActivity.java)。

### SupportMapFragment

下面以[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)为例简单介绍创建Map实例的步骤。

1. 在Activity的布局文件（例如：activity_main.xml）中添加一个Fragment，并通过布局文件设置地图的属性。

   ```screen
   <fragment xmlns:android="http://schemas.android.com/apk/res/android"
       xmlns:map="http://schemas.android.com/apk/res-auto"
       android:id="@+id/mapfragment_mapfragmentdemo"
       class="com.huawei.hms.maps.SupportMapFragment"
       android:layout_width="match_parent"
       android:layout_height="match_parent"
       map:cameraTargetLat="48.893478"
       map:cameraTargetLng="2.334595"
       map:cameraZoom="10" />
   ```

2. 要在应用程序中使用地图，您需要实现[OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378)接口。

   示例代码如下：

   ```screen
   "Java"
   public class SupportMapDemoActivity extends AppCompatActivity implements OnMapReadyCallback {
      ...
   }
   ```

   ```screen
   "Kotlin"
   class SupportMapDemoActivity : AppCompatActivity(),OnMapReadyCallback { 
      ... 
   }
   ```

3. 在加载地图前先初始化SDK，例如在Activity的onCreate方法中。

   初始化SDK有2种方式：
   * [MapsInitializer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366).[initialize](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366#section1516212511479)(Context context)
   * [MapsInitializer](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366).[initialize](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366#section13620131508)(Context context, String routePolicy)，支持设置数据处理路由地。

   在初始化完成后，加载[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)，并调用[getMapAsync](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapfragment-0000001050150294#section11704105017376)()来注册回调。

   示例代码如下：

   ```screen
   "Java"
   // 初始化SDK
   MapsInitializer.initialize(this);
   setContentView(R.layout.mapfragment_mapfragmentdemo);
   SupportMapFragment mSupportMapFragment; 
   mSupportMapFragment = (SupportMapFragment) getSupportFragmentManager().findFragmentById(R.id.mapfragment_mapfragmentdemo);
   mSupportMapFragment.getMapAsync(this);
   ```

   ```screen
   "Kotlin"
   // 初始化SDK
   MapsInitializer.initialize(this);
   setContentView(R.layout.mapfragment_mapfragmentdemo);
   var mSupportMapFragment: SupportMapFragment? = null
   mSupportMapFragment = supportFragmentManager.findFragmentById(R.id.mapfragment_mapfragmentdemo) as SupportMapFragment?
   mSupportMapFragment?.getMapAsync(this)
   ```

   > 说明
   >
   > 建议在用户同意隐私协议后再初始化SDK。

4. 在[onMapReady](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378#section74342919481)回调中获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象。

   示例代码如下：

   ```screen
   "Java"
   public void onMapReady(HuaweiMap huaweiMap) {
       Log.d(TAG, "onMapReady: ");     
       hMap = huaweiMap;
   }
   ```

   ```screen
   "Kotlin"
   override fun onMapReady(huaweiMap: HuaweiMap) {
       Log.d(TAG, "onMapReady: ")
       hMap = huaweiMap
   }
   ```

5. 运行您刚完成的工程就可以在您的App中看到地图了。运行后的效果如下图所示：

### MapView

下面以[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)为例简单介绍创建Map实例的步骤。

1. 在Activity的布局文件中添加一个[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)，并通过XML文件设置地图的属性。

   ```screen
   <com.huawei.hms.maps.MapView xmlns:android="http://schemas.android.com/apk/res/android"
           xmlns:map="http://schemas.android.com/apk/res-auto"
           android:id="@+id/mapview_mapviewdemo"
           android:layout_width="match_parent"
           android:layout_height="match_parent"
           map:cameraTargetLat="48.893478"
           map:cameraTargetLng="2.334595"
           map:cameraZoom="10"/>
   ```

2. 要在应用程序中使用地图，您需要实现[OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378)接口：

   示例代码如下：

   ```screen
   "Java"
   public class MapViewDemoActivity extends AppCompatActivity implements OnMapReadyCallback {
      ...
   }
   ```

   ```screen
   "Kotlin"
   class MapViewDemoActivity : AppCompatActivity(), OnMapReadyCallback { 
      ... 
   }
   ```

3. 在Activity的onCreate()方法中先初始化SDK，然后加载[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)，并调用[getMapAsync](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section18155143712405)()来注册回调。

   示例代码如下：

   ```screen
   "Java"
   // 初始化SDK
   MapsInitializer.initialize(this);
   MapView mMapView;
   mMapView = findViewById(R.id.mapview_mapviewdemo);
   Bundle mapViewBundle = null;
   if (savedInstanceState != null) {
         mapViewBundle = savedInstanceState.getBundle("MapViewBundleKey");
   }
   mMapView.onCreate(mapViewBundle);
   mMapView.getMapAsync(this);
   ```

   ```screen
   "Kotlin"
   // 初始化SDK
   MapsInitializer.initialize(this);
   private lateinit var mMapView: MapView
   mMapView = findViewById(R.id.mapview_mapviewdemo)
   var mapViewBundle: Bundle? = null
   if (savedInstanceState != null) {
       mapViewBundle = savedInstanceState.getBundle("MapViewBundleKey")
   }
   mMapView.onCreate(mapViewBundle)
   mMapView.getMapAsync(this)
   ```

   > 说明
   >
   > 建议在用户同意隐私协议后再初始化SDK。

4. 在[onMapReady](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378#section74342919481)回调中获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象。

   示例代码如下：

   ```screen
   "Java"
   public void onMapReady(HuaweiMap huaweiMap) {
       Log.d(TAG, "onMapReady: ");     
       hMap = huaweiMap; 
   }
   ```

   ```screen
   "Kotlin"
   override fun onMapReady(huaweiMap: HuaweiMap) {
       Log.d(TAG, "onMapReady: ")
       hMap = huaweiMap
   }
   ```

5. 在Activity/Fragment的onStart()、onResume()、onPause()、onStop()、onDestroy()、onSaveInstanceState(Bundle outState)和onLowMemory()方法中调用[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)对应的方法。

   示例代码如下：

   ```screen
   "Java"
   private static final String MAPVIEW_BUNDLE_KEY = "MapViewBundleKey";

   @Override
   public void onSaveInstanceState(Bundle outState) {
       super.onSaveInstanceState(outState);

       Bundle mapViewBundle = outState.getBundle(MAPVIEW_BUNDLE_KEY);
       if (mapViewBundle == null) {
           mapViewBundle = new Bundle();
           outState.putBundle(MAPVIEW_BUNDLE_KEY, mapViewBundle);
       }

       mMapView.onSaveInstanceState(mapViewBundle);
   }

   @Override
   protected void onStart() {
       super.onStart();
       mMapView.onStart();
   }

   @Override
   protected void onResume() {
       super.onResume();
       mMapView.onResume();
   }

   @Override
   protected void onPause() {
       super.onPause();
       mMapView.onPause();
   }

   @Override
   protected void onStop() {
       super.onStop();
       mMapView.onStop();
   }

   @Override
   protected void onDestroy() {
       super.onDestroy();
       mMapView.onDestroy();
   }

   @Override
   public void onLowMemory() {
       super.onLowMemory();
       mMapView.onLowMemory();
   }
   ```

   ```screen
   "Kotlin"
   companion object {
       private const val MAPVIEW_BUNDLE_KEY = "MapViewBundleKey"
   }

   override fun onSaveInstanceState(outState: Bundle?) {
       super.onSaveInstanceState(outState)
   	
       var mapViewBundle: Bundle? = outState?.getBundle(MAPVIEW_BUNDLE_KEY)
       if (mapViewBundle == null) {
           mapViewBundle = Bundle()
           outState?.putBundle(MAPVIEW_BUNDLE_KEY, mapViewBundle)
       }
   	
       mMapView.onSaveInstanceState(mapViewBundle)
   }

   override fun onStart() {
       super.onStart()
       mMapView.onStart()
   }

   override fun onResume() {
       super.onResume()
       mMapView.onResume()
   }

   override fun onPause() {
       super.onPause()
       mMapView.onPause()
   }

   override fun onStop() {
       super.onStop()
       mMapView.onStop()
   }

   override fun onDestroy() {
       super.onDestroy()
       mMapView.onDestroy()
   }

   override fun onLowMemory() {
       super.onLowMemory()
       mMapView.onLowMemory()
   }
   ```

   > 说明
   >
   > [MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)创建的时候，需要至少保证重写Activity/Fragment的onDestroy()方法，使其能回调到[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)生命周期的onDestroy()方法，才可以保证地图不会内存泄漏。另外，在ListView/RecyclerView这种多实体中创建地图的情况下，需要自行在销毁的时候调用各个实体的onDestroy()方法，不然也可能会导致内存泄漏。

## 设置API密钥

自Android Map SDK 5.0.0.300起，初始化地图前，必须要设置"API密钥"。当前提供两种方式设置API密钥：

方式一：直接使用"agconnect-services.json"文件中api_key字段的API密钥。

方式二：调用接口[MapsInitializer.setApiKey](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366#section1389444514617)(String apiKey)设置API密钥。

* 在您的工程入口类设置API密钥。

  示例代码如下：

  ```java
  "Java"
  // 在App主应用的程序入口类（即继承了android.app.Application的类），在覆写的onCreate()方法中调用该方法
  public class MyApp extends Application {
      @Override
      public void onCreate() {
          super.onCreate();
          // 设置API密钥
          MapsInitializer.setApiKey("Your API key");
      }
  }
  ```

  ```java
  "Kotlin"
  // 在App主应用的程序入口类（即继承了android.app.Application的类），在覆写的onCreate()方法中调用该方法
  class MyApp : Application() {
      override fun onCreate() {
          super.onCreate()
          // 设置API密钥
          MapsInitializer.setApiKey("Your API key")
      }
  }
  ```

* 在Fragment或者MapView设置API密钥。

  示例代码如下：

  ```java
  "Java"
  @Override
  protected void onCreate(Bundle savedInstanceState) {
      Log.i(TAG, "onCreate: ");
      super.onCreate(savedInstanceState);
      // 在setContentView之前设置API密钥     
      MapsInitializer.setApiKey("Your API key");
      setContentView(R.layout.basic_demo);
  }
  ```

  ```java
  "Kotlin"
  override fun onCreate(savedInstanceState: Bundle?) {
      Log.i(TAG, "onCreate: ")
      super.onCreate(savedInstanceState)
      // 在setContentView之前设置API密钥
      MapsInitializer.setApiKey("Your API key")
      setContentView(R.layout.basic_demo)
  }
  ```

> 说明
>
> * 使用[MapsInitializer.setApiKey](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366#section1389444514617)(String apiKey)设置"API密钥"的时候，apiKey的取值和"agconnect-services.json"文件中的api_key字段保持一致即可。
> * 如果[MapsInitializer.setApiKey](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366#section1389444514617)方法和"agconnect-services.json"文件中同时设置了"API密钥"，优先使用[MapsInitializer.setApiKey](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapsinitializer-0000001050150366#section1389444514617)中设置的API密钥。
