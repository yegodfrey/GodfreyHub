# 场景化示例  
  
#### 记录层变量

记录层是一种JavaScript对象，用于将数据信息从网站传递到DTM，您可以通过配置记录层变量来获取记录层中的数据。

通过记录层变量，DTM可以获取记录层中的值，并将这些值传递到代码、条件和其他变量。记录层对象由键/值对列表组成。具体操作如下：

                1. 进入“变量”页面，点击右侧“新建”按钮，新建一个自定义变量。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/JLkY9hCyQju5MgEQYU59zw/zh-cn_image_0000001174750053.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=1D212DDF2BE6D867BB22E3698FE64109C2ED2857B1692016D31A4696AAA55052)

                2. 新建一个记录层变量，输入“记录层变量名”，如myprod，然后点击“保存”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c3/v3/9oC2dUx1REead0EwmPsMgQ/zh-cn_image_0000001174629951.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=955F6C9F32AC6798E3EF1B714050CAA74107D2ACEB09443C6892F9ABB64FE63E)

                3. 新建一个配置代码，例如：选用代码模板“Google Analytics（分析）：Universal Analytics”，“上报类型”选择“交易上报”，“商品数据”引用步骤2新建的记录层变量，最后设置触发条件并保存。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/iXQtHz8wQ8yyibuUJxs3hQ/zh-cn_image_0000001128790228.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=C433AD26457B05111290E82BD1FA84871C6AD312964E7EF7F52B83148F925E62)

                4. 下面代码示例如何通过JavaScript实现插入数据到记录层变量，其键值为步骤2中定义的“记录层变量名”。
                       
                       <script>
                           window.recordTier = window.recordTier || [];
                           window.recordTier.push({
                        **myprod** : [{
                                   'sku': 'A-100',
                                   'name': 'Cloth',
                                   'category': 'Apparel',
                                   'price': 11.99,
                                   'quantity': 1,
                                   'currency': 'EUR'
                        }, {
                                   'sku': 'B-101',
                                  'name': 'Toy',
                                   'category': 'Apparel',
                                   'price': 10,
                                   'quantity': 2
                        }]
                           });
                       </script>

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/0-MWufUURmeVmH4ee7ZfJw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=0F0ECC15B691EA0FE33CF2C2EA8BF568FFFEF32455A51D9C6AD308A276E77079)

必须在配置代码被触发执行前，确保插入记录层的JavaScript代码已经执行，否则配置代码无法获取真实的记录层数据。

                5. （可选）您可以通过“版本详情”页面，预览如上所配置的记录层变量。

                   1. 在“工作区”页签，点击“预览”按钮，进入“版本预览”页面。
                   2. 在“版本预览”页面，“输入网址”框内默认填写配置的目标网址，您可以手动编辑修改该网址。并选择勾选“是否进入调试模式”，点击“开始预览”按钮。
                   3. 在调试页面，选择“记录层”页签，预览所配置的记录层变量。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/9s_2fJg9RwOrNk_3F7xmYQ/zh-cn_image_0000001275763765.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=A55B443472CA92C98A3123F7EE18C8F3DACBB298A5D781B423A6E09BB1560DBE)

                   4. 若代码被触发后，您可以在“代码”页签的“被触发代码”中查看该记录层变量详情。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/OOB9BEwNR3OtzTP6xe52pg/zh-cn_image_0000001276126477.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=8DB8D2A856828E43DDEE7ED157B630A84FC4B0AB23522DC1AFDEADDAC02049F4)
