# 场景化示例

#### 导入GTM配置文件

为方便您在DTM上直接引用GTM的配置策略，您可以将GTM配置文件导出后，直接导入DTM，从而简化工作量。 GTM导出文件包括：预设变量、自定义变量、条件、代码和分组信息。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/OmXwxKhmRMuwNtTQwkrSyw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=3F07072BDB4A1D4973947C2E799AE7673C3A3C0A4CD4CE2DAFC2892D76B8F695) 若分组为空，则分组信息不会被导出。
    1. 登录[Google Tag Manager](https://tagmanager.google.com/)网站，导出JSON配置文件，具体步骤请参见[容器导出和导入](https://support.google.com/tagmanager/answer/6106997?hl=zh-Hans&ref_topic=9002095)。
    2. 在DTM的“配置”页面，点击“导入”按钮。
    3. 选择本地待导入的JSON文件并选中导入策略，点击“导入”。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/pK4rabulSUCRBn7ztU5kEw/zh-cn_image_0000001130549475.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=CB1D645CE249AE60A627BCDB4588252C18AF79234A59F1FCAB3F9B0411F9C3A7) ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/AJBYTOq_SiyaYUpkGKfVzA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=77B5D6FAF5EE5C15D6E873983C65F98682D21127623BE9481EC67D5A1C571387) GTM配置文件导入时，JSON文件名必须以“GTM-”开头。
    4. 查看导入结果。
       * 导入成功，无需操作。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6/v3/JpmRtUnmQ1ynitISKDZlag/zh-cn_image_0000001084170462.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=2DEC84456D4A97FD5222A15C8E46CF42E2ECDC5447C054FC928D4ADF980C33FC)
       * 系统弹出“忽略列表”，点击“确定”或关闭弹框后，则导入成功。![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/N05N69L0REa1fFldgb2bRg/zh-cn_image_0000001130688273.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=6CB60205D9EE1EBF6ABCCE51696486F098A22973F670BFC6CE7B3497CB4FE5D6) 对于GTM配置文件中，有如下情况的，DTM导入时提示忽略信息。 | 资源类型 | 忽略原因  
---|---  
预设变量 | 在DTM中无对应预设变量类型。  
自定义变量 | 
         * 在DTM中无对应变量类型。
         * 在DTM中有对应变量类型，但引用了被忽略的变量。
         * 与DTM中参数不一致。  
条件 | 
         * 在DTM中无对应条件类型。
         * 在DTM中有对应条件类型，但引用了被忽略的变量。
         * 与DTM中参数不一致。  
代码 | 
         * 在DTM中无对应代码类型。
         * 在DTM中有对应代码类型，但引用了被忽略的变量或条件。
         * 与DTM中参数不一致。  
  
       * 系统提示导入失败，请根据提示信息修改后重新导入。

若GTM中的参数与DTM中的规则不匹配（如格式、校验规则或长度等），则导入失败。

#### 导入可视化埋点配置文件

    1. 在DTM的“配置”页面，点击“导入”按钮。
    2. 选择本地待导入的JSON文件并选中导入策略，点击“导入”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d9/v3/vRV_8ZgGTBGz3RipV9Io_A/zh-cn_image_0000001089875781.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=76A52459EB9A6D127DC1DE690EFC934739B720424F3761DEC8A2F080BB9D87D4)

    3. 查看导入结果。

       * 导入成功，无需操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/BLdhBy1cTcSo_HMEr7KlKA/zh-cn_image_0000001136115969.png?HW-CC-KV=V1&HW-CC-Date=20261005T042945Z&HW-CC-Expire=86400&HW-CC-Sign=D2DD03C0D89FDDF9AAE65F07035E7AA8E750087CA1B125D7B657FFC97C89BF43)

       * 系统弹出“忽略列表”，点击“确定”或关闭弹框后，则导入成功。

对于配置文件中，有如下情况的，DTM导入时提示忽略信息。

         * 当用户选择合并，且可视化事件条件与非可视化事件条件的名字重复。
         * 当用户选择合并，且导入文件和数据库中的埋点位置存在重复。
         * 当用户选择合并，且导入文件和数据库中的埋点名称存在重复。

       * 系统提示导入失败，请根据提示信息修改后重新导入。
