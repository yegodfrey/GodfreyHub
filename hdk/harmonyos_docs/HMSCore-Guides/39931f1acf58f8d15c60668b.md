# H5 测量页面开发

厂商根据华为 UX 规范和[设备接入 H5 页面 API 参考（JS）](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/bluetoothadapter-0000001057377112-V5)开发实现 H5 页面功能。本文以体温计的 H5 页面开发为例。

1. 设备厂商可以参考开发套件中的 H5 页面模板，开发自定义的 H5 设备页面。开发 H5 页面所需的 JS API 接口及其使用方法请参见[设备接入 H5 页面 API 参考（JS）](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/bluetoothadapter-0000001057377112-V5)。

2. 根据私有协议对测量结果进行解析并储存测量结果。

   拿到特征值变化结果回调以后，需要根据私有协议对测量结果进行解析，并将解析出来的数据通过调用数据储存接口回传运动健康App，不同类型的健康设备有不同的存储结构，具体请参见 [saveHealthData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/savehealthdata-0000001056726832-V5) 和 [saveMultipleHealthData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/savemultiplehealthdata-0000001057695282-V5) 中的示例代码。

   体温计示例如下：

   ```screen
      /**
       * 按照厂商自己的私有蓝牙协议格式解析特征值数据
       */
   parseData: function (data) {
       // 解析第a1位，代表b1
       let b1 = data.substr(a1, 1);
       if (解析成功) {
           this.tempData = b1;
           //保存测量接口到数据平台
           var dataParams = {
               "type": this.globalData.TEMPERATURE_TYPE,
               "value": {
                   "temp": this.tempData,
                   "unit": ""
               }
           };
           window.saveFunctionCallback = this.saveFunctionCallback;
           window.hilink.saveHealthData(JSON.stringify(dataParams), "saveFunctionCallback");
       }
   }
   ```


3. 调用 JS API 储存测量结果并跳转回"结果展示"界面。

   根据不同的跳转类型，跳转到不同的"结果展示"界面，体温计示例（体温数据类型为4，详情参见[跳转类型列表](https://developer.huawei.com/consumer/cn/doc/HMSCore-References-V5/healthtype-field-0000001058017151-V5)）如下：

   ```screen
   saveFunctionCallback: function (response) {
       // 跳转到体温二级页面
       window.location.href = "huaweischeme://healthapp/basicHealth?healthType=4";
       window.JsInteraction.closeWeb();
   }
   ```
