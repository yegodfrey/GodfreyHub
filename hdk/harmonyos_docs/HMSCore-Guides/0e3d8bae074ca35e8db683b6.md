# 定位服务为Kerry Express提供精准定位能力，提升快递收寄体验

#### Kerry Express简介

Kerry Express是东南亚知名快递物流机构，服务于泰国、柬埔寨、越南、马来西亚等区域。它为用户提供从预订、支付、物流信息跟踪等全流程快递物流服务。

#### 业务挑战

* 当用户需要寄快递时，他需要在Kerry Express上搜索附近的Kerry Express服务点，或预约快递员上门取件。在这过程中，Kerry Express面对如何更加准确帮助用户定位其位置的挑战。
* 当用户选择去线下服务点寄快递时，往往需要找出最近的服务点。但用户定位不准确往往导致应用向用户推荐的服务点不是最佳方案，这会损坏用户寄件体验。
* 当用户选择线上预约上门取货时，用户常常需要手动输入当前地址，这会延长用户的操作时间，影响用户体验。  

#### 解决方案

借助定位服务的融合定位能力，Kerry Express实现了精准定位功能。

* 精准定位用户位置，推荐服务点 借助定位服务，Kerry Express的用户能够精准获取其当前位置，从而获得附近的服务点推荐。

* 精准输入位置信息，快速预约 借助定位服务，用户能够利用自身准确的位置信息填写至地址栏中，减少操作时间，快速完成寄件预约。

#### 合作收益

* To Kerry Express 定位服务的融合定位能力免费开放且持续提高精准定位能力，降低Kerry Express对定位功能的开发、维护和使用成本。且通过定位服务，Kerry Express能够更精准地展示其服务点和呈现物流信息，大大提升用户体验。

* To用户 精准定位能力让用户不再对定位偏差感到烦躁，能够享受更好的寄件快递体验。
