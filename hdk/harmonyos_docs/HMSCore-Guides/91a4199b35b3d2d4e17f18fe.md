# 路线规划

提供驾车、步行、骑行和公交路线规划功能。

* Deeplink样例：

  ```screen
  petalmaps://route?saddr=home&daddr=company&type=drive
  ```


* Applink样例：

  ```screen
  https://www.petalmaps.com/routes/?saddr=25.102916,55.165363&daddr=25.164610000000,55.228869000000&type=drive&utm_source=fb
  ```

* 参数列表：

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
  |saddr|否|String|路线规划的起点。可传参数： * 经纬度 * 地点名称，例如：花瓣地图的家庭地址"home"或公司地址"company" * 经纬度+地点名称，例如：48.8754,2.3578(巴黎大酒店) 如果不传saddr参数，默认取当前位置。 > 说明 > 地点名称若含有特殊字符需进行UriEncode编码。|
  |daddr|是|String|路线规划的终点。可传参数： * 经纬度 * 地点名称，例如：花瓣地图的家庭地址"home"或公司地址"company" * 经纬度+地点名称，例如：48.8754,2.3578(巴黎大酒店) > 说明 > 地点名称若含有特殊字符需进行UriEncode编码。|
  |type|否|String|* drive：驾车路径规划。 * walk：步行路径规划。 * bicycle：骑行路径规划。 * bus：公交路径规划。 如果不传type参数，默认为驾车路径规划。|
  |utm_source|否|String|渠道来源（应用可以传入App包名或者应用名）。|
  |utm_medium|否|String|媒介。|
  |utm_campaign|否|String|运营活动名称。|
  |utm_term|否|String|运营活动关键词。|
  |utm_content|否|String|运营活动内容。|


* 代码样例 Intent方式：

  ```screen
  Uri content_url = Uri.parse("petalmaps://route?saddr=25.102916,55.165363&daddr=25.164610000000,55.228869000000&type=drive&utm_source=fb"); 
  Intent intent = new Intent(Intent.ACTION_VIEW, content_url); 
  if (intent.resolveActivity(getPackageManager()) != null) {
      startActivity(intent); 
  }
  ```

  直接点击链接方式：

  ```screen
  https://www.petalmaps.com/routes/?saddr=home&daddr=company&type=drive&utm_source=fb
  ```
