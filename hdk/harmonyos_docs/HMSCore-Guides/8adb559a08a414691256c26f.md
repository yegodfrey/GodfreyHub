# 开发准备

#### 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

#### 设置数据处理位置

您使用推送服务前需要[设置默认数据处理位置](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-datalocation-0000001160439813 )。当前支持选择的区域有中国、德国、俄罗斯和新加坡。如果设置的数据处理位置与您的服务器位置不一致，或者设置的数据处理位置与应用所服务的用户所在地不一致，都会导致推送消息下发时延增加。

推送服务将在您设置的默认数据处理位置存放和处理数据。"默认数据处理位置"适用于项目下所有的应用，若您需要修改默认数据处理位置，请先关闭推送服务后再修改默认数据处理位置，并且原默认数据处理位置下您的数据将在6个月后自动清除且无法恢复，请谨慎修改"默认数据处理位置"。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105214.39713755777098509997190918368915:50001231000000:2800:9C4F4169BF457EB976ECA9F000E15DF304C33D114CF182C97CB66EB435300289.png)  
为了减少下发消息在全球各大区之间跳转导致的时延，建议按照您的应用所服务的用户所在地来设置对应的数据处理位置。例如：如果您是拉美的开发者，您所服务的用户大部分在拉美，建议将您的数据处理位置设置在新加坡；如果您是中国的开发者，但是您所服务的用户大部分在欧洲，建议将您的数据处理位置设置在德国。详情请参见[如何选择数据处理位置](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-datalocation-0000001160439813#section36321221164716)。  

#### 准备iOS推送消息凭证

如果您有现成的密钥，可以直接使用该密钥，不必生成新的密钥。

1. 打开[Apple会员中心](https://developer.apple.com/membercenter/index.action)，登录您的开发者帐号，进入"Certificates, Identifierss \& Profiles"页面。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105214.11664374680832278286921931773895:50001231000000:2800:49E746E2907B5C979D442155D550CBFC124BDD0E7098EFCA9C83508C12D836E7.png "点击放大")

   <br />

2. 在侧边栏打开"Keys"，点击按钮"(+)"进行添加。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105214.66065857698731565320945464531833:50001231000000:2800:18819956FF93BC4D170026BC02FEABEC3965E20572049FFFF2655F5E9D514096.png)

   <br />

3. 创建密钥，输入"Key Name"并且勾选APNs选项，点击"Continue"，再点击"Register"。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105214.24379353625251423729350816170843:50001231000000:2800:BC191F76E558E9ABEAB5DF415173CC59BA5E52774917A726193D9F02BA5D4A3A.png "点击放大")

#### 生成APNs证书

1. 打开[Apple会员中心](https://developer.apple.com/membercenter/index.action)，登录您的开发者帐号，进入"Certificates, Identifierss \& Profiles"页面。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105215.29176606270946222900742747068685:50001231000000:2800:0D9BA9477319EC18D604E23658D7D1CCF6183B0BB467102B7501E1B4012A25BF.png "点击放大")

   <br />

2. 在侧边栏选择"Certificates"，点击按钮"(+)"进行添加。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105215.09847151527154669567853119311852:50001231000000:2800:1F62FF1F0F2186EF4213250478449C6A37C10B438E36F67D53AA297B4435D3ED.png "点击放大")

   <br />

3. 勾选"Services"下面的选项"Apple Push Notification service SSL (Sandbox \& Production)"，点击右上角的"Continue"。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105215.19375856049238221184193326289994:50001231000000:2800:221782A3896553B4651763BB5044F832B690013C2AE9AA3ABC88E3ACF5C39722.png "点击放大")

   <br />

4. 选择推送消息的"App ID"，点击"Continue"，再点击"Download"完成证书的下载。

   <br />

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105215.28387886250415242969252158313297:50001231000000:2800:9F236991B3517E4DA26BCD67CE78800C7FE4C8A558689A4FF60C692ECF57090C.png "点击放大")

   <br />

5. 请参见[Apple生成证书](https://support.apple.com/zh-cn/guide/keychain-access/kyca2793/11.0/mac/12.0)指导生成证书请求文件并保存在您自己的存储位置。在浏览器点击"Choose File"选择刚才生成的证书请求文件（拓展名为.certSigningRequest）生成APNs证书。
6. 点击"Download"下载证书，证书文件的扩展名为.cer。在[钥匙串](https://support.apple.com/zh-cn/guide/keychain-access/kyca2431/mac)中安装这个证书。
7. 这个证书会出现在"钥匙串访问"中的"我的证书"类别中，导出p12文件。

#### Cocoapods方式集成SDK（推荐使用）

1. 打开命令行窗口，导航至Xcode项目路径。创建Podfile文件，如果已经存在，可跳过本步骤。

   <br />

   ```
   cd project-directory
   pod init
   ```

   <br />

2. 编辑Podfile文件，将推送服务SDK添加到PodPodfile文件中。

   <br />

   ```
   pod 'HmsPushSDK'
   ```

   添加完毕后如下图所示：

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105215.63017457498864591796591074833784:50001231000000:2800:4C5373CC0998A61C57008E78DD813EDC816E1FF242D6AFBFEE3EA3F6266ECBBB.png "点击放大")

   <br />

3. 安装pod。

   <br />

   ```
   pod install
   ```

   <br />

4. 打开您项目根目录下的".xcworkspace"文件，在"General"页签，点击"+"号添加对framework库的依赖"libc++.tbd"。
