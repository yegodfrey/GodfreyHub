      1. 在“AppDelegate.m文件”中导入头文件“<HiAnalytics/HiAnalytics.h>”，初始化HiAnalytics。

             // 初始化HUAWEI Analytics
             [HiAnalytics config];

             }

#### 接入调试

在开发过程中可以启动调试模式，实时查看事件的记录情况，观察具体结果并根据需要进行调整。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ae/v3/gijPGBDdSRSf98UM_dWXkg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043040Z&HW-CC-Expire=86400&HW-CC-Sign=E70981D8CBC4769ECCCDF23D06A72573291088CC7D390688257D5C10F5A2C9DE)

      * Huawei Analytics模板

开始调试：在Edit scheme中选择Arguments，添加**-HADebugEnabled** 上报开关。

停用调试：删除-HADebugEnabled上报开关。

      * Firebase模板

开始调试：在Edit scheme中选择Arguments，添加**-FIRAnalyticsDebugEnabled** 和**-FIRDebugEnabled** 上报开关。

停用调试：删除此两项上报开关。

      * 其他模板（例如Adjust、AppsFlyer等）

开始调试：在Edit scheme中选择Arguments，添加**-DTMDebugEnable** 上报开关和日志登记**-DTMLogLevelDebug** 。

停用调试：删除**-DTMDebugEnable** 上报开关以及**-DTMLogLevelDebug** 。

在AGC上的具体调试操作，请参见[应用调试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-debugging-0000001051799712)。

      1. 在Xcode开发工具中的Edit scheme中Arguments加入如下配置，开始调试模式。

调试模式打开后会保持启用状态，所有事件将实时上报。
