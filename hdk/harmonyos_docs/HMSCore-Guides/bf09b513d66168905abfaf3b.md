# 覆盖物

地图覆盖物是固定在地图上的图片。  

#### 添加覆盖物

调用HWMapJsSDK.[HWGroundOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwgroundoverlay-0000001050710116)(imageUrl, bounds, groundOverlayOptions)创建一个覆盖物添加到地图上。

```
var map;
var mGroundOverlay;

function initMap() {
    var mapOptions = {};
    mapOptions.center = {lat: 48.856613, lng: 2.352222};
    mapOptions.zoom = 10;

    map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions);

    var imageBounds = {
        north: 48.902,
        south: 48.82,
        east: 2.42,
        west: 2.257,
    };

    mGroundOverlay = new HWMapJsSDK.HWGroundOverlay(
        // 本地资源图片路径或者是图片的URL
        'covering.png',
        // 显示的填充区域
        imageBounds,
        {
            map: map,
            opacity: 1,
            zIndex: 1
        }
    );
}
```

#### 删除覆盖物

从地图中移除覆盖物，请调用setMap()方法并将null作为传递参数。

```
mGroundOverlay.setMap(null);
```

请注意，上述方法不会删除覆盖物，它只是把覆盖物从地图上移除。如果用户希望删除覆盖物，则应将其从地图上移除，然后将覆盖物本身置为null即可。

```
mGroundOverlay.setMap(null);
mGroundOverlay = null;
```

#### 修改覆盖物

通过[HWGroundOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwgroundoverlay-0000001050710116)提供的方法对属性进行修改，例如调用setUrl(url)方法修改覆盖物的url：

```
<tr>
    <td>URL:</td>
    <td>
        <!-- value可以是本地资源图片路径或者是图片的URL -->
        <input id="urlInput" type="text" value="huawei_logo.png"/>
    </td>
</tr>
<script>
    var url = document.getElementById("urlInput").value;
    mGroundOverlay.setUrl(url);
</script>
```

覆盖物的以下属性支持自定义，具体请参见[HWGroundOverlay方法](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwgroundoverlay-0000001050710116#section718861163213)。  

|属性|含义|
|:------------------|:-------|
|setBounds(bounds)|设置显示范围。|
|setOpacity(opacity)|设置透明度。|
|setUrl(url)|设置图片URL。|
|setMap(map)|设置地图实例。|
