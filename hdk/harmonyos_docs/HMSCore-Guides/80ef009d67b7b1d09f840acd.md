# 在线提单指导

华为支持通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)方式反馈问题，平台将会在1-2个工作日内回复。  

#### 操作步骤

1. 通过官网进入[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)，选择"HMS Core"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103225.06256793709468993073207090604004:50001231000000:2800:ED67C15E86E84A3F772FC957EBEFE048FEDAA3DED8B110D8736B69E7EB336D52.png?needInitFileName=true?needInitFileName=true "点击放大")
2. 下拉页面，找到并选择"定位服务"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103225.16037116454282590830420267226105:50001231000000:2800:22F63AEC015411757AFD6EB58F03FCD9AD9E4E6B3A5D8A536DC26AAB10FDC1C3.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 创建问题单。
   1. 确认提交问题是否包含终端用户隐私数据。
      * 如果您提交的问题中包含终端用户隐私数据，请根据终端用户的所在区域，直接将问题发送至对应的区域邮箱。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103225.35070599409956694227303090641237:50001231000000:2800:B81387DCFDA021915D5EB4289C8A99FB0363194628F0DCEDC92379315C286031.png?needInitFileName=true?needInitFileName=true "点击放大")

      * 如果您提交的问题中包不含终端用户隐私数据，请在下拉框选择不存在。 ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103225.53786143025381290153355820546498:50001231000000:2800:F3229A547E0969B5F70FE8CB698E6DEA73A7B91D5D5ED6A1D7518E6697E12A6E.png?needInitFileName=true?needInitFileName=true "点击放大")

   2. 按提示输入问题描述，填写问题单。（注：带\*号为必填项，为了更好、更快的解决问题，建议尽可能地将所有选项填写详细。）

      ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103225.21831145162343859865088533148541:50001231000000:2800:6E02CEAA4F3BA59C2A16B5602C2C925670359977C14AC6769AF3DECF3DB2CC70.png?needInitFileName=true?needInitFileName=true "点击放大")

      勾选承诺

4. 点击"提交问题"即可完成在线提单。
