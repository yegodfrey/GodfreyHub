# 在运动健康App内开启Health Service Kit

## 手机应用

针对手机上开发的应用，如需访问华为运动健康App的数据，需要引导用户在运动健康App内开启华为运动健康服务。若用户未开启，或在引导页开启后又自行关闭了华为运动健康服务，则在调用查询接口时会查询失败。开发者如果想保持更好的数据交互体验，建议开发者在查询运动健康数据之前，调用[getHealthAppAuthorization](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-authorisation-0000001206472504#section06462055152011)接口检查用户是否已开启华为运动健康服务，如果未开启，开发者需自行提示用户开启，避免查询数据失败的场景。

开发者可以通过[getHealthAppAuthorization](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-authorisation-0000001206472504#section06462055152011)接口，查询用户是否已开启华为运动健康服务：

```screen
import {HMSHealthKit} from '@hw-hmscore/hms-js-health'
// 调用getHealthAppAuthorization接口查询用户是否开启华为运动健康服务
HMSHealthKit.getHealthAppAuthorization().then((result) => {
    // 调用成功
    console.info("getHealthAppAuthorization success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.error("getHealthAppAuthorization Error: " + JSON.stringify(error));
});
```

开发者也可以通过[checkHealthAppAuthorization](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-authorisation-0000001206472504#section102198342110)接口校验用户是否已开启华为运动健康服务，如果用户未开启，则会弹出引导页面，提醒用户开启华为运动健康服务，反之则表示用户已开启华为运动健康服务。
> 说明
>
> 开发者也可以引导用户打开"华为运动健康 > 我的 > 隐私管理 > 华为运动健康服务"开关，提示用户在运动健康App上打开华为运动健康服务开关。
