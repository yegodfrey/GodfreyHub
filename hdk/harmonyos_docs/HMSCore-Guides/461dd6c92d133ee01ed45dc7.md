# 室内定位开发

#### 概述

如果您的应用需要在室内环境请求设备位置信息，可以使用定位服务（Location Kit）的室内定位特性。首先您需要为应用申请位置权限，然后调用请求位置更新方法（[requestLocationUpdatesEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169#section91051750194015)），设置（[LocationRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationrequest-0000001050986189)）请求，根据您的需要指定定位方式，获取持续的位置信息回调。如果您获取位置信息后，想取消位置信息回调，可以调用移除位置更新方法（[removeLocationUpdates](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169#section14923192365816)），达到取消回调的目的。  

#### 约束条件

为了您的应用能够更好地体验室内定位特性，需要满足以下条件：

* 目前支持城市如下：北京市、上海市、深圳市等城市的商场、机场、高铁站等，详情请参见[当前支持的建筑（持续更新中）](#section2036491761714)。
* 支持设备：EMUI 9.1.1及以上版本华为手机。
* HMS Core（APK）版本： 6.0.1及以上。
* 接入室内定位服务需要您在AppGallery Connect（简称AGC）网站上注册，并将AGC配置文件添加到应用中，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001057629153)。
* 网络状态：处于有网环境中。

  建议插入SIM卡并同步开启Wi-Fi或者Wi-Fi扫描功能，可以增加定位成功率和定位精确度。

要使用室内定位服务相关API，需要确保您的设备已经下载并安装了HMS Core（APK）服务组件，并将Location Kit的SDK集成到您的项目中。有关详细信息，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001057629153)。以下仅为代码片段，详情请参见[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-0000001050986087)。  

#### 指定应用权限

1. Android提供了两种位置权限： ACCESS_COARSE_LOCATION（粗略的位置权限）和ACCESS_FINE_LOCATION（精确的位置权限）。需要在"AndroidManifest.xml"文件中配置权限：

   <br />

   ```
   <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
   ```

   <br />

2. （可选）在Android 10及以上版本中，如果您需要应用程序在后台执行时也具备持续定位能力，需要在"AndroidManifest.xml"文件中配置ACCESS_BACKGROUND_LOCATION权限：

   <br />

   ```
   <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
   ```

   <br />

3. 动态申请定位相关权限（Android 6.0及以上版本危险权限要求）：

   <br />

   ```
   "Java"
   // Android SDK<=28 所需权限动态申请
   if (Build.VERSION.SDK_INT <= Build.VERSION_CODES.P) {
       Log.i(TAG, "android sdk <= 28 Q");
       if (ActivityCompat.checkSelfPermission(this,
           Manifest.permission.ACCESS_FINE_LOCATION) != PackageManager.PERMISSION_GRANTED
           && ActivityCompat.checkSelfPermission(this,
               Manifest.permission.ACCESS_COARSE_LOCATION) != PackageManager.PERMISSION_GRANTED) {
           String[] strings =
               {Manifest.permission.ACCESS_FINE_LOCATION, Manifest.permission.ACCESS_COARSE_LOCATION};
           ActivityCompat.requestPermissions(this, strings, 1);
       }
   } else {
       // Android SDK>28 所需权限动态申请，需添加"android.permission.ACCESS_BACKGROUND_LOCATION"权限
       if (ActivityCompat.checkSelfPermission(this,
           Manifest.permission.ACCESS_FINE_LOCATION) != PackageManager.PERMISSION_GRANTED
           && ActivityCompat.checkSelfPermission(this,
               Manifest.permission.ACCESS_COARSE_LOCATION) != PackageManager.PERMISSION_GRANTED
           && ActivityCompat.checkSelfPermission(this,
               "android.permission.ACCESS_BACKGROUND_LOCATION") != PackageManager.PERMISSION_GRANTED) {
           String[] strings = {android.Manifest.permission.ACCESS_FINE_LOCATION,
               android.Manifest.permission.ACCESS_COARSE_LOCATION,
               "android.permission.ACCESS_BACKGROUND_LOCATION"};
           ActivityCompat.requestPermissions(this, strings, 2);
       }
   }
   ```

* ACCESS_COARSE_LOCATION：粗略的位置权限，提供城市街区级别的位置信息精准度。
* ACCESS_FINE_LOCATION：精确的位置权限，提供的位置信息比请求ACCESS_COARSE_LOCATION时所提供的位置信息更精准。

<!-- -->

* ACCESS_BACKGROUND_LOCATION：后台运行权限，在Android 10（API级别29）版本此权限为危险权限需要动态申请。在Android 10之前已授予ACCESS_COARSE_LOCATION权限的应用程序在前后台都可访问位置，在Android 10及更高版本中如需在后台访问位置权限，则需要申请ACCESS_BACKGROUND_LOCATION权限。
* 在Android 11（API 级别30）及以上，以上三个权限不能同时动态申请，需先授予ACCESS_COARSE_LOCATION和ACCESS_FINE_LOCATION权限后再申请ACCESS_BACKGROUND_LOCATION权限。  

#### 创建定位服务客户端

在您的项目中使用到室内定位服务的Activity中的onCreate()方法中创建一个[FusedLocationProviderClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169)实例，通过该实例调用定位相关接口。

```
"Java"
// 定位交互接入对象
private FusedLocationProviderClient fusedLocationProviderClient; 
protected void onCreate(Bundle savedInstanceState) {   
    super.onCreate(savedInstanceState);
    fusedLocationProviderClient = LocationServices.getFusedLocationProviderClient(this); 
}
```

```
"Kotlin"
// 定位交互接入对象
private lateinit var fusedLocationProviderClient: FusedLocationProviderClient 
override fun onCreate(savedInstanceState: Bundle?) {   
    super.onCreate(savedInstanceState)
    fusedLocationProviderClient = LocationServices.getFusedLocationProviderClient(this) 
}
```

#### 获取室内定位位置信息

您可以通过[requestLocationUpdatesEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169#section91051750194015)接口向HMS Core（APK）请求室内定位位置，位置回调的结果是在[LocationCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationcallback-0000001050706140)的[onLocationResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationcallback-0000001050706140#section18517246182511)()中。如果您想获取详细的位置信息对象，可以在位置回调结果监听方法中通过locationResult.[getLocations](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationresult-0000001051066114#section0637438308)()或locationResult.[getHWLocationList](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationresult-0000001051066114#section127601552115214)()获得到Location或者[HWLocation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hwlocation-0000001051066112)列表。

1. 设置室内定位请求参数。

   <br />

   构建[LocationRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationrequest-0000001050986189)请求，仅当字段"priority"设置为"[LocationRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationrequest-0000001050986189).[PRIORITY_INDOOR](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationrequest-0000001050986189#section2459103418136)"时才能发起室内定位请求。

   ```
   "Java"
   LocationRequest mLocationRequest = new LocationRequest();
   // 设置位置更新的间隔（单位：毫秒）
   mLocationRequest.setInterval(10000);
   // 设置定位请求类型为室内定位
   mLocationRequest.setPriority(LocationRequest.PRIORITY_INDOOR);
   ```

   ```
   "Kotlin"
   val mLocationRequest = LocationRequest()
   // 设置位置更新的间隔（单位：毫秒）
   mLocationRequest.interval = 10000
   // 设置定位请求类型为室内定位
   mLocationRequest.priority = LocationRequest.PRIORITY_INDOOR
   ```

   <br />

2. 定义位置更新回调。

   <br />

   ```
   "Java"
   LocationCallback mLocationCallback;        
   mLocationCallback = new LocationCallback() {        
       @Override        
       public void onLocationResult(LocationResult mLocationResult) {        
           if (mLocationResult != null) {        
               // 获取位置信息
               List<HWLocation> mHWLocations = mLocationResult.getHWLocationList();
               for (HWLocation mHWLocation : mHWLocations) {
                   Map<String, Object> maps = mHWLocation.getExtraInfo();
                   parseIndoorLocation(maps);
               }
           }        
       }        
   };
   // 解析室内定位结果信息
   public void parseIndoorLocation(Map<String, Object> maps) {
       if (maps != null && !maps.isEmpty()) {
           if (maps.containsKey("isHdNlpLocation")) {
               Object object = maps.get("isHdNlpLocation");
               if (object instanceof Boolean) {
                   boolean isIndoorLocation = (boolean) object;
                   if (isIndoorLocation) {
                       // floor:楼层ID
                       int floor = (int) maps.get("floor");
                       // floorAcc:楼层置信度（取值范围:0-100）
                       int floorAcc = (int) maps.get("floorAcc");
                       // time:手机开机时间
                       Object obj = maps.get("time");
                       long time = 0;
                       if(obj instanceof Integer){
                           time = ((Integer) obj).longValue();
                       } else if (obj instanceof Long) {
                           time = ((Long) obj).longValue();
                       }
                   }
               }
           }
       }
   }
   ```

   ```
   "Kotlin"
   val mLocationCallback: LocationCallback
   mLocationCallback = object : LocationCallback() {
       override fun onLocationResult(mLocationResult: LocationResult) {
           if (mLocationResult != null) {
               // 获取位置信息
               val mHWLocations =
                   mLocationResult.hwLocationList
               for (mHWLocation in mHWLocations) {
                   val maps = mHWLocation.extraInfo 
                   parseIndoorLocation(maps)
               }
           }
       }
   }
   // 解析室内定位结果信息
   fun parseIndoorLocation(maps: Map<String?, Any?>?) {
       if (maps != null && maps.isNotEmpty()) {
           if (maps.containsKey("isHdNlpLocation")) {
               val objectInMap = maps["isHdNlpLocation"]
               if (objectInMap is Boolean) {
                   if (objectInMap) {
                       // floor:楼层ID
                       val floor = maps["floor"] as Int
                       // floorAcc: 楼层置信度（取值范围:0-100）
                       val floorAcc = maps["floorAcc"] as Int
                       // time:手机开机时间
                       val obj = maps["time"]
                       var time: Long = 0
                       if (obj is Int) {
                           time = obj.toLong()
                       } else if (obj is Long) {
                           time = obj.toLong()
                       }
                   }
               }
           }
       }
   }
   ```

   <br />
