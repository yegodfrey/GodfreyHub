# 开通服务

开通华为分析服务有以下两种场景：

* 创建项目时开通：创建新项目时立即开通。
* 通过点击菜单开通：创建项目时未开通，通过点击"华为分析"下的任意菜单进行开通。

#### 创建项目时开通

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，点击"我的项目"。
2. 在项目页面中点击"添加项目"。

3. 在"创建项目"页面中输入项目名称 ，点击"创建并继续"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115213.44829323614790257497908223931462:50001231000000:2800:65F6B1BDC79E54860DB06429E1B39568BD60C1A64ADCDE1B0991FDD3E779A8BD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   1. 点击"设置"选择默认数据处理位置，设置详情请参见[数据处理位置](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-datalocation-0000001160439813)。

#### 通过点击菜单开通

如果您在创建项目时未开启华为分析服务，即关闭了"为此项目启动分析服务"按钮，则可通过如下步骤开通分析服务。

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要开通分析服务的应用。
3. 点击"华为分析"下的任意菜单，并点击"启动分析服务"可开通分析服务。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115213.17800694651112600215453977937556:50001231000000:2800:6902C08ED39542B28525D65D19B0ECF53805DE57663B2BDFDC5D21E1EC97F7E6.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   需拥有产品管理权限才可开通服务。团队成员的管理权限相关信息参见[管理团队帐号](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-manageaccount-0000001099996700)。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115213.80132273661374209220771151498152:50001231000000:2800:C040C506EFFB810DFC5B3010585C8665E55CFFA31EAB7CDEEF5B2C90839917B5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
4. 进入"项目接入设置"页面，设置数据处理位置、上报路由、选择是否开启"产品改进"功能。并点击"更多设置"完善信息，勾选同意协议的选项框。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115213.52187284734147640081260129616630:50001231000000:2800:1ABE47DD3F4446A8E7DC958440317A6A3AED96BB133614E4217B1D9985C3CADE.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115213.80883554179548548822947470989140:50001231000000:2800:5762CDDE3C763A7D048E4929EABD5E167BAA940EE288E91444B42656B74322F8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)
5. 点击"完成"，即可完成华为分析服务的开通。
