# 商户服务器实现NFC刷卡能力

此方式支持商户为卡券添加NFC刷卡能力，商户需要在卡券实体实例中包含特定节点信息，并在自身服务器侧实现要求的接口。具体如下：

> 说明
>
> * 当前此种方式只支持通过网页、短信、Email、APP方式添加的卡券集成。
> * 集成NFC刷卡能力前请先[添加卡券](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-webpage-0000001050042334)至华为钱包。
> * 功能实现请参考"[示例代码：huawei-wallet-server-windows-nfc-demo.zip](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/java-sample-code-0000001050157448)"。

## LinkDevicePass节点设置

商户如需实现NFC刷卡能力，则需要在用户特有信息的实例中包含*linkDevicePass* *节点,* *华为钱包应用通过linkDevicePass* *中的nfcType* *字段判断* 是否支持NFC刷卡能力，为"1"表示支持*。*

```screen
HwWalletObject hwWalletObject = new HwWalletObject(); 
 ...     
LinkDevicePass linkDevicePass = new LinkDevicePass();    
linkDevicePass.setWebServiceURL("https://xxx/passtools");   
linkDevicePass.setNfcType("1");   
linkDevicePass.setPassVersion("DevicePass version");    
linkDevicePass.setSerialNumber("4527809736");   
linkDevicePass.setSpPublicKey("2353sasxsd");   
linkDevicePass.setToken("34534314194");   
hwWalletObject.setLinkDevicePass(linkDevicePass);
```

***LinkDevicePass*** **字段说明：**

|字段名|字段描述|类型|可空|
|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----|:-----|
|webServiceURL|SP-Server地址|String|不可|
|token|Token，到SP-Server下载DevicePass时的Token|String|不可|
|serialNumber|在发卡方的唯一键值|String|不可|
|passVersion|DevicePass版本。 SP-Server可以通过更新Pass对象中的此信息通知DevicePass需要更新，端侧会与本地DevicePass中的passVersion进行比对，DevicePass中的值如果与此值不匹配，则触发重新下载； > 说明 > 此部分主要用于更新动态信息和隐私数据这种，Applet个人化参数不支持更新。|String|可空|
|spPublickey|由于DevicePass数据是不到WalletServer的，因此需要端侧对获取的数据进行验签，通过此字段端侧对SP返回的签名进行验签，从而保证发卡方是一致的|String|不可|
|nfcType|标识NFC卡片类型，此部分必须为公开的常量值。会依据此类型找到对应的Applet创建脚本，创建对应的Applet实例，值不在公开范围内以及不填写时均会标识为非NFC卡片。|String|固定为"1"|

> 说明
>
> SP-Server：商户服务器地址。

## 商户服务器实现NFC刷卡能力接口

商户服务器需要实现包括"注册"，"申请个人化Token"，"获取个人化数据"，"取消注册"等接口供华为钱包调用，用于完成NFC刷卡能力的开通和卡片信息的更新。

接口功能如下：

### 注册

用户点击卡券详情页激活按钮时，会触发钱包应用调用商户服务器的注册接口，此接口用于获取三方认证授权certificate。

* URL：

  |registerDevice|POST {webServiceURL}/v1/passes/registrations|
  |--------------|--------------------------------------------|


* 请求消息体：

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:----------|:-----------------|:-----|:---|:-------------------------------------|
  |requestBody|passTypeIdentifier|String|必选|注册walletKit服务的passTypeIdentifier。|
  |requestBody|serialNumber|String|必选|Pass对象在发卡方的唯一键值，回调时以便发卡方根据此值识别具体的卡券记录。|
  |requestBody|passVersion|String|可选|版本号，固定10.0。|
  |requestBody|userDeviceId|String|必选|用户在当前设备上的唯一标识。|
  |requestBody|transId|String|必选|随机数。|
  |signature|-|String|必选|Applet的身份私钥对requestBody的Hash值的签名。|
  |certificate|signature|String|必选|WalletServer签发。|
  |certificate|publicKey|String|可选|Applet的身份公钥。|
  |certificate|type|String|可选|类型，默认为私钥签名方式。|


* 返回消息体：

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:---------|:----------|:----------|:---|:------------|
  |httpStatus|-|String|必选|接口网络状态码。|
  |response|certificate|Certificate|可选|SP验证请求后，签发证书。|

  **Certificate** **定义**

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:----------|:--------|:-----|:---|:------------|
  |certificate|signature|String|必选|商户服务器签发。|
  |certificate|publicKey|String|可选|Applet的身份公钥。|
  |certificate|type|String|可选|类型，默认为私钥签名方式。|

  ```screen
  public RegistrationsResponse dealWithRegisterRequest(String token, RegistrationsRequest request) { 
           System.out.println("Register: token=" +token); 
           RegistrationsResponse response = new RegistrationsResponse(); 
           if (token == null || !token.equals(PassData.getLinkDevicePassToken())) { 
               System.out.println("Register:Invalid token."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
           if (!ParamChecker.isValidRegistrationsRequest(request)) { 
               System.out.println("Register:Some key param is empty."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
           Certificate walletCertificate = request.getCertificate(); 
           if (!verifyWalletCert(walletCertificate)) { 
               System.out.println("Register:Verify wallet cert failed."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_SIGN_ERROR)); 
               return  response; 
           } 
    
           if (!ParamChecker.hashSignatureCheck(request.toJsonString(), request.getSignature(), 
                   appletAuthPublicKey, DataConvertUtil.SIGN_MODE_SHA256_RSA_MGF1)) { 
               System.out.println("dealWithRegisterRequest, check body sign fail."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_SIGN_ERROR)); 
               return response; 
           } 
    
           String userDeviceId = request.getRequestBody().getUserDeviceId(); 
           response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_OK)); 
           Response responseBody = new Response(); 
           Certificate serverCert = PassData.getServerCert(appletAuthPublicKey); 
           responseBody.setCertificate(serverCert); 
           response.setResponse(responseBody); 
           System.out.println("Register:{deviceId=" + userDeviceId + ", cert=" + serverCert + "}"); 
           deviceIdCertMap.put(userDeviceId, serverCert); 
           return response; 
       }
  ```

### 申请个人化Token

在调用"获取个人化数据"接口前华为钱包会先到商户服务器取到此Token。调用 "获取个人化数据"接口时会将此Token放入Header中，同时在请求的signature字段中，Token将作为其中requestbody一个key参与Hash值计算，建议商户服务器设置此Token时效性。此接口返回的token用于"获取个人化数据"接口验证请求有效性使用。验证过后该Token便失效，下次调用"获取个人化数据"接口前需要重新获取。所以此接口和"获取个人化数据"接口需要成对使用。

* URL

  |requestPersonalizeToken|POST {webServiceURL}/v1/passes/requestPersonalizeToken|
  |-----------------------|------------------------------------------------------|


* 请求消息体：

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:----------|:-----------------|:----------|:---|:-------------------------------------|
  |requestbody|passTypeIdentifier|String|必选|注册Wallet Kit服务的passTypeIdentifier。|
  |requestbody|serialNumber|String|必选|Pass对象在发卡方的唯一键值，回调时以便发卡方根据此值识别具体的卡券记录。|
  |requestbody|passVersion|String|可选|版本号，固定10.0。|
  |requestbody|userDeviceId|String|必选|用户在当前设备上的唯一标识。|
  |requestbody|transId|String|必选|随机数。|
  |signature|-|String|必选|Applet的身份私钥对requestbody的Hash值的签名。|
  |certificate|-|Certificate|必选|Applet证书，商户服务器签发。|

  **Certificate** **格式如下**

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:----------|:--------|:-----|:---|:-----------------------|
  |certificate|signature|String|必选|商户服务器私钥对Applet的身份公钥签名信息。|
  |certificate|publicKey|String|可选|Applet的身份公钥。|
  |certificate|type|String|可选|类型，默认为私钥签名方式。|


* 返回消息体：

  |父节点参数|子节点参数|**类型**|**是否可选**|**描述**|
  |:---------|:----|:-----|:-------|:--------|
  |Httpstatus|-|int|必选|接口网络状态码。|
  |response|token|String|必选|个人化token。|

  ```screen
  public RequestTokenResponse dealWithTokenRequest(RequestTokenRequest request) { 
           RequestTokenResponse response = new RequestTokenResponse(); 
           String userDeviceId = request.getRequestBody().getUserDeviceId(); 
           Certificate spCertFromRequest = request.getCertificate(); 
           if (CommonUtils.isStringEmpty(userDeviceId) || !ParamChecker.checkSpServerCertificate(spCertFromRequest)) { 
               System.out.println("RequestToken:User device id or sp certificate is empty"); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
           Certificate cachedCert = deviceIdCertMap.get(userDeviceId); 
           if (cachedCert == null) { 
               System.out.println("RequestToken:Certificate not match"); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_SIGN_ERROR)); 
               return response; 
           } 
           if (!ParamChecker.hashSignatureCheck(request.toJsonString(), request.getSignature(), 
                   appletAuthPublicKey, DataConvertUtil.SIGN_MODE_SHA256_RSA_MGF1)) { 
               System.out.println("dealWithTokenRequest, check body sign fail."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_SIGN_ERROR)); 
               return response; 
           } 
           response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_OK)); 
           Response responseBody = new Response(); 
           String personalizeToken = PassData.getPersonalizeToken(); 
           responseBody.setToken(personalizeToken); 
           deviceIdTokenMap.put(userDeviceId, personalizeToken); 
           response.setResponse(responseBody); 
           return response; 
       }
  ```

### 获取个人化数据

华为钱包应用将通过此接口获取商户服务器生成的DevicePass卡券包和个人化数据。

钱包App会将个人化数据写入华为手机芯片，商户可使用特定的读卡器对华为手机进行读卡操作。

* URL

  |requestPersonalize|POST {webServiceURL}/v1/passes/requestPersonalize|
  |------------------|-------------------------------------------------|


* 请求消息体：

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:----------|:-------------------|:----------|:---|:---------------------------------------------------------------------------|
  |requestbody|passTypeIdentifier|String|必选|-|
  |requestbody|serialNumber|String|必选|-|
  |requestbody|passVersion|String|可选|-|
  |requestbody|userDeviceId|String|必选|用户在当前设备上的唯一标识。|
  |requestbody|personalizePublicKey|String|必选|Applet的个人化公钥，用于加密个人化字段值。|
  |requestbody|personalizeCert|String|必选|Applet身份私钥对个人化公钥personalizePublicKey的签名。|
  |requestbody|personalizeCertType|String|必选|固定值，默认为私钥签名。|
  |requestbody|transPublicKey|String|必选|用于加密返回的对称秘钥，用于对返回的数据做数字信封。|
  |requestbody|transId|String|必选|事务流水，用于拼接返回的对称秘钥后进行加密。|
  |signature|-|String|必选|Applet的身份私钥对requestBody的Hash值的签名。 申请到的个人化token作为其中requestbody一个key参与Hash值计算。|
  |certificate|-|Certificate|必选|Applet证书，商户服务器签发。|

  **Certificate** **定义：**

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:----------|:--------|:-----|:---|:------------|
  |certificate|signature|String|必选|商户服务器签发。|
  |certificate|publicKey|String|可选|Applet的身份公钥。|
  |certificate|type|String|可选|类型，默认为私钥签名方式。|


* 返回消息体：

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:---------|:-----------------------------|:-----|:---|:----------------------------------------------------------|
  |Httpstatus|-|String|必选|接口网络状态码。|
  |response|encryptDevicePass|String|可选|预留字段。 SPServer通过生成的sessionKey加密DevicePass卡券包信息。 采用Base64编码。|
  |response|encryptAppletPersonalizeFields|String|可选|SPServer通过生成的sessionKey加密Applet的个人化参数密文。 采用Base64编码。|
  |response|encryptSessionKey|String|可选|SPServer使用请求中的transPublicKey加密生成的sessionKey。采用Base64编码。|
  |signature|-|String|必选|SP Server对response的Hash值进行签名。|

  encryptAppletPersonalizeFields加密前的字段说明如下：

  |父节点参数|子节点参数|类型|是否可选|描述|
  |:----------------------|:---------------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------|
  |AppletPersonalizeFields|card_id|String|必选|发卡方发放的卡片唯一标志，使用temp_key，temp_iv 加密后的结果，并转换成十六进制字符串。 加密方式：数据明文后补800...00到16字节整数倍，然后使用CBC模式加密，加密算法：AES/CBC/NoPadding。|
  |AppletPersonalizeFields|card_key|String|必选|发卡方发放的卡片密钥，使用Applet个人化公钥personalizePublicKey加密，加密算法RSA/NONE/OAEPWithSHA1AndMGF1Padding。 card_key明文之前拼接一个固定的十六进制字符前缀"14010333"后再进行加密。|
  |AppletPersonalizeFields|card_iv|String|必选|读卡设备在外部认证前加密随机数用的AES IV。LV格式，L为IV的长度，V为IV值。|
  |AppletPersonalizeFields|card_privateInfo|String|可选|发卡方发放的卡片私有信息，如卡片有效期、权限等信息，使用temp_key，temp_iv 加密后的结果，并转换成十六进制字符串。 加密方式：数据明文后补800...00到16字节整数倍，然后使用CBC模式加密，加密算法：AES/CBC/NoPadding。|
  |AppletPersonalizeFields|temp_key|String|必选|AES128的key，使用Applet个人化公钥personalizePublicKey加密，加密算法RSA/NONE/OAEPWithSHA1AndMGF1Padding。 temp_key明文之前拼接一个固定的十六进制字符前缀"34810133"后再进行加密。|
  |AppletPersonalizeFields|temp_iv|String|必选|AES128的iv，使用Applet个人化公钥personalizePublicKey加密，加密算法RSA/NONE/OAEPWithSHA1AndMGF1Padding。|

  加密前 AppletPersonalizeFields 数据样例：

  {

  "card_id": "2040B46E38F0BFCDE55F5C7A813ACC1CB96",

  "card_key": "2040B46E38F0BFCDE55F5C7A813ACC1CB96",

  "card_privateInfo": "2040B46E38F0BFCDE55F5C7A813ACC1CB96",

  "temp_key": "2040B46E38F0BFCDE55F5C7A813ACC1CB96",

  "temp_iv": "2040B46E38F0BFCDE55F5C7A813ACC1CB96",

  "card_iv": "10AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"

  }

  其中Key值根据具体的业务定义填写，Value根据Applet的个人化公钥进行加密；

  encryptSessionKey加密前的字段说明

  |参数|类型|是否可选|描述|
  |:---------|:-----|:---|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |sessionKey|String|必选|三方生成 AES128 的 key 和 iv，使用请求中personalizePublicKey 字段加密transId+key+iv，对结果进行base64编码即可。 RSA算法: RSA/ECB/OAEPWithSHA-256AndMGF1Padding。 用途：加密生成 encryptAppletPersonalizeFields 和 encryptDevicePass。|

  > 说明
  >
  > 个人化数据为NFC卡信息,对应接口响应信息中的"encryptAppletPersonalizeFields"字段。
  >
  > 商户如果需要更新用户特有信息的实例中的动态二维码和余额之类信息，则需要在"获取个人化数据"接口中将DevicePass卡券包和个人化数据一起推送给华为钱包应用。

  DevicePass卡券包由signature, hwpass.json, manifest.json文件组成，其中signture, manifest.json两个文件在调用服务端demo生成签名卡券包时会自动生成，不需要商户提供，商户需要按照下方的hwpass.json文件的生成规则生成hwpass.json文件。

  DevicePass卡券包大小应小于150KB，否则无法添加。

  DevicePass卡券包在华为钱包的存储采用文件形式，每个卡券包都需要遵循相同的格式，整个文件采用zip压缩，文件后缀命名为.hwpass，文件名字字符只允许"a-z"，"A-Z"，"0-9"，"_"。

  **DevicePass卡券包组成：**

  |文件名|文件描述|必选/可选|备注|
  |:------------|:------------------|:----|:---------------------|
  |hwpass.json|卡券数据文件|必选|请根据卡片实例填充。|
  |signature|签名文件|必选|通过服务器demo自动生成，无需开发者定义。|
  |manifest.json|对包中各文件的SHA256的Hash值|必选|通过服务器demo自动生成，无需开发者定义。|

  **hwpass.json:**

  |段名|描述|示例|必选/可选|
  |:------------------|:----------------------------------------------|:-------------------------------------------------------------|:----|
  |formatVersion|目前固定填写2.0。|2.0|必选|
  |passTypeIdentifier|在开发者联盟注册的卡券类型Id。|hwpass.membership.hotel|必选|
  |passStyleIdentifier|固定"DevicePassStyle"。|"DevicePassStyle"|必选|
  |organizationName|商户名称。|XX门禁卡|必选|
  |organizationPassId|具体的卡券号。|E15285WF65|必选|
  |webServiceURL|用于手机端侧与发卡系统交互，交互链接地址。|https://www.XXX.com/ download/pass|必选|
  |authorizationToken|用于手机端侧与发卡系统交互，鉴权token。|ae13d3bsdfsfwwd7f9a4a5235f10803c09|必选|
  |serialNumber|用于手机端侧与发卡系统交互，建议与 organizationPassId不相同，防止卡号泄露。|8a452215a35855dsffgwfce3aa94bbee|必选|
  |fields.commonFields|对于某种类型的卡券的必备展示字段，commonFields包含多个Object对象。|[{ "key": "name", "label": "名称", "value": "XXX" }]|必选|
  |fields.appendFields|对于某种类型的卡券的可选展示字段，appendFields包含多个Object对象。|[{ "key": "detail", "label": "详细信息", "value": "https://xxx" }]|可选|

  > 说明
  >
  > commonFields、appendFields区域，至少有一个区域有值。

  commonFields、appendFields区域规则：

  |字段名|字段描述|示例|可空|
  |:----|:----|:---|:-|
  |Key|字段关键字|name|不可|
  |label|字段名称|名称|不可|
  |value|字段值|XXX|不可|

  ```screen
  public PersonalizeResponse dealWithPersonalizeDataRequest(String token, PersonalizeRequest request) { 
           PersonalizeResponse response = new PersonalizeResponse(); 
           RequestBody requestBody = request.getRequestBody(); 
           String userDeviceId = requestBody.getUserDeviceId(); 
           Certificate spCertFromRequest = request.getCertificate(); 
           System.out.println("Personalize: token=" +token); 
           String cachedToken = deviceIdTokenMap.remove(userDeviceId); 
           if (cachedToken == null || !cachedToken.equals(token)) { 
               System.out.println("Personalize:Invalid token."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
           if (CommonUtils.isStringEmpty(userDeviceId) || !ParamChecker.checkSpServerCertificate(spCertFromRequest)) { 
               System.out.println("Personalize:User device id or sp certificate is empty"); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
    
           Certificate cachedCert = deviceIdCertMap.get(userDeviceId); 
           if (cachedCert == null) { 
               System.out.println("Personalize:Certificate not match"); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
           if (!ParamChecker.hashSignatureCheck(request.toJsonString(token), request.getSignature(), 
                   appletAuthPublicKey,DataConvertUtil.SIGN_MODE_SHA256_RSA_MGF1)) { 
               System.out.println("dealWithPersonalizeDataRequest, check body sign fail."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_SIGN_ERROR)); 
               return response; 
           } 
           String personalizePKSign = requestBody.getPersonalizeCert(); 
           byte[] srcBytes = DataConvertUtil.base64Decode(requestBody.getPersonalizePublicKey()); 
           if (!DataConvertUtil.checkSign(srcBytes, personalizePKSign, 
                   appletAuthPublicKey, DataConvertUtil.SIGN_MODE_SHA256_RSA_MGF1)) { 
               System.out.println("dealWithPersonalizeDataRequest, check PK sign fail."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_SIGN_ERROR)); 
               return response; 
           } 
           response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_OK)); 
           PassDataResponse passData = getDevicePassData(requestBody); 
           response.setResponse(passData); 
           String passDataStr = passData.toJsonString(); 
           String passHashValue = DataConvertUtil.encodeSHA256(passDataStr); 
           System.out.println("Personalize, body=" + passDataStr); 
           System.out.println("Personalize, passHashValue=" + passHashValue); 
           String signature = DataConvertUtil.signData(passHashValue, Constants.SERVER_SECRET_KEY); 
           System.out.println("Personalize, signature=" + signature); 
           response.setSignature(signature); 
           return response; 
  }
  ```

### 取消注册

华为钱包的用户主动删除卡券时，华为钱包将调用商户服务器的取消注册接口来告知商户服务器对应卡券已被用户主动删除。商户服务器收到解注册请求之后，可以执行相关数据的清理动作。

* URL：

  |unregistrations|POST {webServiceURL}/v1/passes/unregistrations|
  |---------------|----------------------------------------------|


* 请求消息体：

  |父节点参数|子节点参数|类型|必选/可选|描述|
  |:----------|:-----------------|:-----|:----|:--------------------------------|
  |requestbody|passTypeIdentifier|String|必选|注册walletKit服务的passTypeIdentifier。|
  |requestbody|serialNumber|String|必选|-|
  |requestbody|userDeviceId|String|必选|用户在当前设备上的唯一标识。|
  |requestbody|transId|String|必选|随机数。|
  |signature|-|String|必选|WalletServer对requestBody的Hash签名。|


* 返回消息体：

  |父节点参数|子节点参数|类型|必选/可选|描述|
  |:---------|:----|:-----|:----|:-------|
  |Httpstatus|-|String|必选|接口网络状态码。|

  ```screen
  public UnregistrationsResponse dealWithUnregisterRequest(UnregistrationsRequest request) { 
           UnregistrationsResponse response = new UnregistrationsResponse(); 
           String userDeviceId = request.getRequestBody().getUserDeviceId(); 
           if (CommonUtils.isStringEmpty(userDeviceId)) { 
               System.out.println("Personalize:User device id or sp certificate is empty"); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
           Certificate cachedCert = deviceIdCertMap.remove(userDeviceId); 
           if (cachedCert == null) { 
               System.out.println("Personalize:Certificate not exist."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_PARAM_ERROR)); 
               return  response; 
           } 
           String signature = request.getSignature(); 
           String jsonString = request.toJsonString(); 
           System.out.println("dealWithUnregisterRequest, jsonString=" + jsonString); 
           if (!DataConvertUtil.checkSign(jsonString, signature, Constants.WALLET_PUBLIC_KEY, 
                   DataConvertUtil.SIGN_MODE_SHA256_RSA)) { 
               System.out.println("dealWithUnregisterRequest, checkSign fail."); 
               response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_SIGN_ERROR)); 
               return response; 
           } 
           System.out.println("dealWithUnregisterRequest, success."); 
           response.setHttpStatus(String.valueOf(Constants.RESULT_CODE_OK)); 
           return response; 
       }
  ```
