# 开发准备

## 前提条件

* 请参考[3.6.4.1 申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050747587)完成账号申请。
* 请参考[3.6.4.2 申请Health Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-kitservice-0000001050707556)完成服务申请。

## 操作步骤

1. 在账号服务应用详情页的**"** 回调地址**"** 输入框中补充回调地址：https://h5hosting.dbankcdn.com/cch5/healthkit/oauth-h5/oauth-callback.html，修改办法参考下图。回调地址支持配置多个，如应用中已配置您应用的回调地址，请继续保留**。**

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/74/v3/_Mi0rPsbQz2NrLH_eqjgTg/zh-cn_image_0000002516359386.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=53F10A25E3C0D2D653E484589F5AC6FE9392AE18CAA3A7E99988C110894AF55F "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/8WzayRIFT-yo92jXdWKLDQ/zh-cn_image_0000002547959195.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=ED5EAF799DC75B664A886E03F8A613FF6776FE68E1769F3421357BA1404F269A "点击放大")

2. 在Health Service Kit服务应用详情页的**"** 其他权限**"**处，根据三方应用实际开放区域勾选即可申请免登录授权权限。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/d-GcF1pgQ8eRCkK3kE01Gg/zh-cn_image_0000002547959189.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=802DF57208BB362ADE549E4F5938941229B17D7D69055A8A8B01C9EB11505E77 "点击放大")

3. 在Health Service Kit服务应用详情页的**"** 应用Scheme地址**"**输入框中填写DeepLink链接，应用Scheme地址支持配置多个，如应用中已配置您应用的DeepLink地址，请继续保留。此处填写的DeepLink地址是三方应用授权成功后通过该地址把授权码返回给您的应用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/APlFIP6xS5mE4atIOCACZg/zh-cn_image_0000002547959201.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=8D8A289B15411A1979F0CD37E0FB9EE3976CDEED112A85AE41EFFC0074977BB5 "点击放大")

## 集成SDK

1. 下载Health Service Kit iOS SDK包，并解压。

   下载地址：[iOS SDK下载](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/ios-loginfree-sdk-download-0000002097067069)。

2. 启动 Xcode*，* 打开工程，在**targets > info > URL Types >URL Scheme >填写协议**，配置urlscheme。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/gh69HmidRNW7yyP520NagA/zh-cn_image_0000002516519308.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=844C37CD09838B643BD92888B71A3F81D0D57C7EEB251C9CFEEBEC3CF74430F9 "点击放大")

3. 配置协议白名单，在工程的info.plist中找到LSApplicationQueriesSchemes字段（若无增新增一个），并配置需要跳转到华为运动健康App的scheme：**huaweihealthwearengine**。

   > 说明
   >
   > 白名单最多配置50个，为保证能正确跳转到华为运动健康App，请保证将华为运动健康App的scheme在白名单列表的前50。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/RpNun8PqRLSyHWY7iHcnzQ/zh-cn_image_0000002548039195.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=E66706DF13B27490F44BFED4E0E4C72F06C58050B288F749256EAE2BE84EA7D9 "点击放大")

4. 把下载好的压缩文件中的AuthLoginSDK.framework文件拷贝到项目文件夹下，并导入到项目工程中，在General选项卡中的Frameworks，Libraries和 Embedded Content的Embed选项设置为"**Embed&Sign**"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0e/v3/FtOuVQ3hQSOZbzDsYL3yzw/zh-cn_image_0000002547959187.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=8ADBFEDE20AB0EC439E9B4307D17BBCA1AD9FBC9489BCA062573A6AEA5C4635B "点击放大")

5. 在 **Build Phases** 选项卡的 **Link Binary With Libraries** 中，增加以下依赖：AuthLoginSDK.framework。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/CzIwBkYZTX64p4E-mB7sXw/zh-cn_image_0000002516359388.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=DAE703A3690B02FCA9B30D758A99CD61AC599DD168793A2EA44AEE4FADD5C086 "点击放大")

6. 导入SDK后，在代码中添加import依赖，重新编译项目工程。编译通过，说明依赖引入成功。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c/v3/o7n3xH4ATju_7v1-8x34Qw/zh-cn_image_0000002516519298.png?HW-CC-KV=V1&HW-CC-Date=20261008T145321Z&HW-CC-Expire=31536000000&HW-CC-Sign=1EA7A5CB28657AB94A7380A473D0029765E730380623C35291F797DC045D8796)
