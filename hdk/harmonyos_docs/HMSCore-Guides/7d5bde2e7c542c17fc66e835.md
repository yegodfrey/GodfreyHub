# 开发准备

#### 前提条件

* 请参考[3.6.4.1 申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050747587)完成账号申请。
* 请参考[3.6.4.2 申请Health Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-kitservice-0000001050707556)完成服务申请。  

#### 操作步骤

1. 在账号服务应用详情页的"回调地址"输入框中补充回调地址：https://h5hosting.dbankcdn.com/cch5/healthkit/oauth-h5/oauth-callback.html，修改办法参考下图。回调地址支持配置多个，如应用中已配置您应用的回调地址，请继续保留。

   <br />

   ![](https://media:901788166643834972 "点击放大")

   ![](https://media:901788166643870973 "点击放大")

   <br />

2. 在Health Service Kit服务应用详情页的"其他权限"处，根据三方应用实际开放区域勾选即可申请免登录授权权限。

   <br />

   ![](https://media:901788166643903974 "点击放大")

   <br />

   <br />

3. 在Health Service Kit服务应用详情页的"应用Scheme地址"输入框中填写DeepLink链接，应用Scheme地址支持配置多个，如应用中已配置您应用的DeepLink地址，请继续保留。此处填写的DeepLink地址是三方应用授权成功后通过该地址把授权码返回给您的应用。

   <br />

   ![](https://media:901788166643971976 "点击放大")

   <br />

#### 集成SDK

1. 下载Health Service Kit iOS SDK包，并解压。

   <br />

   下载地址：[iOS SDK下载](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/ios-loginfree-sdk-download-0000002097067069)。

   <br />

2. 启动 Xcode，打开工程，在targets \> info \> URL Types \>URL Scheme \>填写协议，配置urlscheme。

   <br />

   ![](https://media:901788166644111979 "点击放大")

   <br />

3. 配置协议白名单，在工程的info.plist中找到LSApplicationQueriesSchemes字段（若无增新增一个），并配置需要跳转到华为运动健康App的scheme：huaweihealthwearengine。

   <br />

   ![](https://media:901788166644138980)  
   白名单最多配置50个，为保证能正确跳转到华为运动健康App，请保证将华为运动健康App的scheme在白名单列表的前50。

   ![](https://media:901788166644363985 "点击放大")

   <br />

4. 把下载好的压缩文件中的AuthLoginSDK.framework文件拷贝到项目文件夹下，并导入到项目工程中，在General选项卡中的Frameworks，Libraries和 Embedded Content的Embed选项设置为"Embed\&Sign"。

   <br />

   ![](https://media:901788166644403986 "点击放大")

   <br />

5. 在 Build Phases 选项卡的 Link Binary With Libraries 中，增加以下依赖：AuthLoginSDK.framework。

   <br />

   ![](https://media:901788166644454987 "点击放大")

   <br />

6. 导入SDK后，在代码中添加import依赖，重新编译项目工程。编译通过，说明依赖引入成功。

   <br />

   ![](https://media:901788166644483988)

   <br />
