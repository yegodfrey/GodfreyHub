# IAP Kit API 10接口升级指导

尊敬的华为开发者，您好：

感谢您一直以来对IAP Kit的关注与支持。

目前IAP Kit已迭代至API 11版本。在API 11中，IAP Kit为开发者与用户提供了更智能化的接入与体验：

      * 便捷的支付体验，首次支付添加付款方式，后续支付仅需收银台验支付密码/指纹/人脸即可1步完成支付；
      * 支持多种支付方式；
      * 支持订阅、优惠券等重要能力；
      * 商用体验，长期开放；
      * 支持以JSON Web Token为标准的接口请求与响应，为开发者提供更通用的安全接入；
      * 支持丰富的服务端关键事件通知，开发者能够及时感知购买流程中的状态变化；
      * 提供更贴合开发者使用的购买信息参数。

**API 10的开发者资料将不再维护，相关API已标识为废弃，且将于2024年12月31日正式下线，届时您将无法使用相关API，请尽快完成切换。**

有关更多更详细的功能说明请参见[IAP Kit API 11文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/iap-introduction)。

#### 客户端升级变更说明

本次主要变更接口返回的数据和数据格式，同时调整验签的方式，具体可参见[对返回结果验签](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-verifying-signature)。涉及的接口变化如下：

功能 | API 10 | API 11  
---|---|---  
购买接口 | purchase | createPurchase  
发货确认 | consumePurchase | finishPurchase  
查询用户已订购商品的购买数据 | queryOwnedPurchases | queryPurchases  
获取历史消耗的消耗型商品 | queryPurchaseRecords | queryPurchases  
  
#### 客户端升级指导

      1. 升级compileSdkVersion和compatibleSdkVersion为4.1.0(11)。
      2. import iap from '@hms.core.iap';修改为import { iap } from '@kit.IAPKit';
      3. 参见[接入购买](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/iap-integrate-purchase)完成消耗型商品/非消耗型商品购买功能的接口切换。
      4. 参见[确保权益发放](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/iap-delivering-products)完成补单功能的接口切换。

#### 服务端升级变更说明

本次升级需要使用新的服务端接口，涉及的服务端改动点如下：

功能 | API 10 | API 11  
---|---|---  
服务端接口升级 | API 10 IAP Kit Server | [API 11 IAP Kit REST API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-rest)  
服务端请求鉴权方式 | 应用级AT | [以JWT格式为标准的请求token](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-jwt-description)  
返回结果验签 | IAP公钥验签 | [JSON Web Token格式数据验签](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-verifying-signature)  
服务端关键事件通知 | V1/V2通知版本 | [V3通知版本](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-key-event-notifications)  
  
#### 服务端升级指导

      1. 调用服务端API请求时，请求Header使用 Authorization: Bearer <JWT格式的token>传递鉴权信息，具体参见[生成服务端请求的token](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-jwt-description)。
      2. IAP服务器API返回结果以及服务端关键事件通知返回的是JSON Web Signature （JWS）格式的数据，具体参见[对返回结果验签](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-verifying-signature)。
      3. IAP Kit API 11支持更丰富的V3版本服务端关键事件通知，具体参见[服务端关键事件通知](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-key-event-notifications)。
