# 获取客户端ID和密钥

您调用流量变现报表API前，要先获取客户端ID和密钥。

1. 注册成为开发者，完成实名认证。登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)，点击右上角"管理中心"进入主页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/lq0fjFCVTV67Unm43vgKxA/zh-cn_image_0000001227280177.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=A6F89774D20997D769003557D198AFFA6A3CDD8F4F479FF3C6E5EECCA300C062 "点击放大")

2. 创建项目。

   1. 选择"我的API"，根据下图标记顺序填入"项目名称"和"项目别名"新建项目。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/m14bbR9YRUyQIJ7ZkriYUA/zh-cn_image_0000001073780110.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=14D66A5B348DB8A96C9B2D2292276829A5EF3954D21C567E8F035ED660AF8D2B "点击放大")

   2. 选中您创建的项目，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/DqRZcU35RbqkOLLeMa3_Gw/zh-cn_image_0000001074635776.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=06CAF2B9B276D6C57E24159F4A08D64006C96648647FF9E9BC0D4B55261A66A3)

3. 进入"凭证"页面，选择"OAuth 2.0 客户端 ID"创建客户端ID。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/9faHV1l1T6iPgmx1EfCxRQ/zh-cn_image_0000001073667909.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=74D6BAE15DB1BE47E834580B5818F869C0773B973C3026E9C09364FE756192BE)

4. 选择"服务器应用"，输入"产品名称"，选择"应用类型"和"默认语言"，点击"创建"；提示"客户端ID"和"密钥"，点击"确定"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/EeYco3tCQyexnlN9ypTjBg/zh-cn_image_0000001073668115.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=7CAA01AE09E1925896E7CE64333E18A234CCB587227BBD8E20499C4158664732)

5. 进入"我的API"页面，点击"申请新的HMS API服务"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/kqpzHujjTw6xeQs_SYLOXA/zh-cn_image_0000001106157070.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=26D7F304F69FF69392897482544BE481951990E35257F44A9208FD22D22FC1D5)

6. 下拉找到"广告服务"，点击"流量变现服务报表API"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/CrB3X_3iSsiNWsGBV9TXRQ/zh-cn_image_0000001105677450.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=DC749481761B19B38BBC3A6DC10290D0AAF3BA723DD9927F54D45D9F98D7907D)

7. 点击"启用"，可以开始使用流量变现服务报表API。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/8v7E6XAxTQe5aRw_Uy_-ow/zh-cn_image_0000001152517027.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=08445416AF5A489D2F63FA4CB2FFE4B27E396AB70CE872AA2A9909D9B9F09846)
