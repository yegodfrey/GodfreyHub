# 获取客户端ID和密钥

您调用流量变现报表API前，要先获取客户端ID和密钥。

1. 注册成为开发者，完成实名认证。登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/)，点击右上角"管理中心"进入主页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/lq0fjFCVTV67Unm43vgKxA/zh-cn_image_0000001227280177.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=39C4D64E5849748786E7FAE2A275BB830192935EDC02D8849CDB859D4A6695A1 "点击放大")

2. 创建项目。

   1. 选择"我的API"，根据下图标记顺序填入"项目名称"和"项目别名"新建项目。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/24/v3/m14bbR9YRUyQIJ7ZkriYUA/zh-cn_image_0000001073780110.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=C5A0AC6FB8EA34368E32FD701F5BF90AAA3C40A68834B48CB7E2CDF55FF27B04 "点击放大")

   2. 选中您创建的项目，点击"确定"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/99/v3/DqRZcU35RbqkOLLeMa3_Gw/zh-cn_image_0000001074635776.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=9EFCF066372E53866FB282BB92A23B69F5AE99FCD934763F26A59B73792B5CA7)

3. 进入"凭证"页面，选择"OAuth 2.0 客户端 ID"创建客户端ID。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/9faHV1l1T6iPgmx1EfCxRQ/zh-cn_image_0000001073667909.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=C48C98600D353A5355008A45C094BF4D2AB22AE7907E9943FEBE7260A347E5FF)

4. 选择"服务器应用"，输入"产品名称"，选择"应用类型"和"默认语言"，点击"创建"；提示"客户端ID"和"密钥"，点击"确定"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/EeYco3tCQyexnlN9ypTjBg/zh-cn_image_0000001073668115.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=CB9DE3D8326624964DD45816415A7EE5058E1C24A2B7FC50F1C1D1E2081806ED)

5. 进入"我的API"页面，点击"申请新的HMS API服务"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/kqpzHujjTw6xeQs_SYLOXA/zh-cn_image_0000001106157070.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=3611ACF447955E9B78E07850F36F5A88563BAFE7F10E520CF06108198BEF6548)

6. 下拉找到"广告服务"，点击"流量变现服务报表API"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/CrB3X_3iSsiNWsGBV9TXRQ/zh-cn_image_0000001105677450.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=5F698DE83B56934AEE74166389C4227D35BCBEE5C92DE8706B9C9C558BBCABAF)

7. 点击"启用"，可以开始使用流量变现服务报表API。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/8v7E6XAxTQe5aRw_Uy_-ow/zh-cn_image_0000001152517027.png?HW-CC-KV=V1&HW-CC-Date=20261012T062830Z&HW-CC-Expire=31536000000&HW-CC-Sign=CEC81B519CC0C693343957811F18677BDF5B95C55EDFCDD08A6AFA02BD21451A)
