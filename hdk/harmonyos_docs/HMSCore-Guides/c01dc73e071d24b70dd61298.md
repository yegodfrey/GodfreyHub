# 版本更新说明

#### 6.10.0-300（2023-03-06）

本次快游戏版本特性变更如下： **新增特性**
                * 新增定时上报策略、阈值上报策略。 
                * 新增立即上报接口[onReport()](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickgame-api-analytics-0000001238739841#section10604154445114)。 
**修改特性** 自动采集事件[APPFIRSTOPEN](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-automatic-event-collection-0000001090800817#ZH-CN_TOPIC_0000001090800817__zh-cn_topic_0000001077213694_zh-cn_topic_0000001083043169_zh-cn_topic_0000001055104489_li1902124561120)和[LAUNCHAPP](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-automatic-event-collection-0000001090800817#ZH-CN_TOPIC_0000001090800817__zh-cn_topic_0000001077213694_zh-cn_topic_0000001083043169_zh-cn_topic_0000001055104489_li197281146256)的上报时机改为实时上报，快游戏事件相关说明请参见[事件说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickgame-event-0000001193532268)。
