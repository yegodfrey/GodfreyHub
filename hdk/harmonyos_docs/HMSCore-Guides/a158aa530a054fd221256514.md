# Indoor Bike Data

用于智能单车向App发送实时运动数据。数据格式如下，由一个Flag和多个参数组成，具体参数的多少由Flags字段中的值决定。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9b/v3/vo5ahC37RXip0AGJe9Ht1g/zh-cn_image_0000002516519136.png?HW-CC-KV=V1&HW-CC-Date=20260909T133518Z&HW-CC-Expire=31536000000&HW-CC-Sign=F32AB65309E9F3F2AA58502BE397C958DE9ABD8B947D8A72AF642C28ADEF51AC)
