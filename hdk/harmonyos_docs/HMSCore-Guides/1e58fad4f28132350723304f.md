# 潜水闭气训练

闭气训练相关运动记录类型如下：

|运动类型|描述|运动类型常量|数据来源|
|:-------------|:---|:-----|:--------|
|apnea_training|闭气训练|155|部分专业手表、手环|

## 专业运动特征统计数据

闭气训练运动特征统计数据类型：com.huawei.activity.feature.breath_holding_train

|字段列表|字段描述|类型|可选/必选|单位|取值范围|
|:-----------------------|:------|:--|:----|:-|:---|
|breathTime|呼吸时间|int|M|秒|-|
|breathHoldingTime|闭气时间|int|M|秒|-|
|breathHoldingTrainRhythm|闭气训练节奏数|int|O|次|-|

## 关联的采样统计数据类型说明

作为ActivityRecord概要数据的一部分，统一使用运动记录权限，无需每种关联的采样统计数据类型使用单独OAuth权限。

|采样统计数据类型|描述|可选/必选|
|:---------------------------------------------------|:-----|:----|
|com.huawei.continuous.exercise_heart_rate.statistics|运动心率统计|O|

## 关联的原子采样数据说明

关联的原子采样数据权限请参考[OAuth权限说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-fitness-record-data-0000001131831088#section27171294263)。

|原子采样数据类型|描述|可选/必选|
|:-------------------------------------------|:-------|:----|
|com.huawei.instantaneous.exercise_heart_rate|运动心率采样|O|
|com.huawei.recovery_heart_rate|运动恢复心率详情|O|

## 闭气训练数据分段说明

作为ActivityRecord概要数据的一部分，统一使用运动记录权限，无需每种关联的采样统计数据类型使用单独OAuth权限。

|**分段统计数据类型**|**描述**|可选/必选|备注|
|:-----------------------------------------|:-------|:----|:------------|
|com.huawei.breath_holding_train.statistics|闭气训练特征统计|O|闭气训练按闭气节奏自动分段|

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:----------------|:---|:-----|:----|:-|:---|
|breathTime|呼吸时间|int|M|秒|-|
|breathHoldingTime|闭气时间|int|M|秒|-|
