# AAID

## 简介

AAID（Anonymous Application Identifier）：应用匿名标识符，标识运行在移动智能终端设备上的应用实例，只有该应用实例才能访问该标识符，它只存在于应用的安装期。与无法重置的设备级硬件ID相比，AAID具有更好的隐私权属性。

AAID具有以下特性：

* 匿名化、无隐私风险：AAID和已有的任何标识符都不关联，并且每个应用只能访问自己的AAID。
* 同一个设备上，同一个开发者的多个应用，AAID取值不同。
* 同一个设备上，不同开发者的应用，AAID取值不同。
* 不同设备上，同一个开发者的应用，AAID取值不同。
* 不同设备上，不同开发者的应用，AAID取值不同。

## 使用场景

App如果要上报统计事件，也需要获取AAID作为应用唯一标识。

AAID会在包括但不限于下述场景中发生变化：

* App卸载重装。
* App调用删除AAID接口。
* 用户恢复出厂设置。
* 用户清除应用数据。

## 安卓应用开发指导

### 开发准备

您的App要获取AAID之前必须先集成Push SDK。如果您的App要上架华为应用市场，请参见[华为推送服务开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137)。如果您只想获取AAID而不上架应用市场，那么您只需集成必要的SDK就行，如何集成请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-integrating-sdk-0000001050040084)。

### 开发步骤

HMS Core SDK提供了获取AAID与删除AAID的方法，具体的方法描述请参见[HmsInstanceId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1334411365268)类。本节给出获取AAID与删除AAID的开发步骤。

**获取AAID**

调用HmsInstanceId.[getAAID](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section14116320143111)方法获取AAID信息。

```java
"Java"
public void getAAID() {
    Task<AAIDResult> idResult = HmsInstanceId.getInstance(getApplicationContext()).getAAID();
    idResult.addOnSuccessListener(new OnSuccessListener<AAIDResult>() {
        @Override
        public void onSuccess(AAIDResult aaidResult) {
            // 获取AAID方法成功
            String aaid = aaidResult.getId();
            Log.d("TAG", "getAAID successfully, aaid is " + aaid );
        }
    }).addOnFailureListener(new OnFailureListener() {
        @Override
        public void onFailure(Exception myException) {
            // 获取AAID失败
            Log.d("TAG", "getAAID failed, catch exception: " + myException);
        }
    });
}
```

```kotlin
"Kotlin"
fun getAAID() {
    val idResult = HmsInstanceId.getInstance(applicationContext).aaid
    idResult.addOnSuccessListener{ aaidResult ->        
        // 获取AAID成功
        Log.d("TAG", "getAAID successfully, aaid is " + aaidResult.getId())        
    }.addOnFailureListener{ myException ->        
        // 获取AAID失败
        Log.d("TAG", "getAAID failed, catch exception: $myException")
    }
}
```

**删除AAID**

调用HmsInstanceId.[deleteAAID](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section8856440133116)方法删除本地保存的AAID信息。

```java
"Java"
public void deleteAAID() {
    // 创建新线程
    new Thread() {
        @Override
        public void run() {
            try {
                // 删除AAID
                HmsInstanceId.getInstance(getApplicationContext()).deleteAAID();
                Log.i("TAG", "deleteAAID successfully.");
            } catch (Exception myException) {
                Log.i("TAG", "deleteAAID failed, catch exception : " + myException);
            }
        }
    }.start();
}
```

```kotlin
"Kotlin"
fun deleteAAID() {
    // 创建新线程
    object : Thread() {
        override fun run() {
            try {
                // 删除AAID
                HmsInstanceId.getInstance(applicationContext).deleteAAID()
                Log.i("TAG", "deleteAAID successfully.")
            } catch (myException: Exception) {
                Log.i("TAG", "deleteAAID failed, catch exception : $myException")
            }
        }
    }.start()
}
```

## iOS应用开发指导

### 开发准备

您的应用需要先集成AGConnectCore SDK和Analytics SDK。AGConectCore SDK集成详情请参见[iOS使用入门](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-ios-0000001058442274)，Analytics SDk集成详情请参见[集成Analytics SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-integrating-sdk-0000001050168479)。

### 开发步骤

1. 初始化AGConnectCore SDK和Analytics SDK。当agconnect-services.plist文件导入成功后，在AppDelegate.m中通过[AGCInstance startup]和[HiAnalytics config]完成初始化。
2. 调用[HiAnalytics.AAID](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-analytics-0000001050164675#section10770121143112 )方法获取AAID。

   Objective-C示例代码：

   ```screen
   #import "AppDelegate.h" 
   #import <AGConnectCore/AGConnectCore.h> 
   #import <HiAnalytics/HiAnalytics.h> 
   @interface AppDelegate ()
   @end
   @implementation AppDelegate
   ...
   - (BOOL)Application:(UIApplication *)Application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
       // 应用启动后执行
       [AGCInstance startup];
       [HiAnalytics config];
       NSString * AAID = [HiAnalytics AAID];
       return YES;
   }
   ...
   @end
   ```
