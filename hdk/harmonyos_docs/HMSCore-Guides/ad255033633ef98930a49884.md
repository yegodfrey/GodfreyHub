# 地点搜索建议

#### 概览

该功能可用于在用户键入查询内容的时候，返回建议的查询结果，实现查询预测效果。  

#### 使用约束

最多返回5条记录。  

#### 实现步骤

1. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchservicefactory-0000001050154715)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)实例。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506195621.91479326311022818447156966123158:50001231000000:2800:454631B218A2ED412E0349B8AEC3DC680DEB947C911E8F7736F35FD9E6F7C818.png)  
   创建SearchService实例需要传入Context类型参数和API密钥。Context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API密钥是您在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API密钥，注意使用时需要调用URLEncoder.encode("Your apiKey", "UTF-8")方法对API密钥进行encodeURI编码。

   <br />

2. 构建[QuerySuggestionRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-querysuggestionrequest-0000001050154769)对象，它是搜索建议的请求体。其中query是必选参数，其余可选：

   <br />

   * query：搜索关键字。
   * location：搜索结果偏向的经纬度。
   * radius：搜索半径，单位：米。取值范围：\[1, 50000\]，默认50000米。该参数只用于优先显示结果，而非将结果限制在该搜索半径内。
   * bounds：搜索结果偏向的范围。
   * poiTypes：指定返回地点的POI类型，取值范围是[LocationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-locationtype-0000001050154741#section48131858163210)的子集，包括：  

     |字段|描述|
     |:------------|:-------------------------------------------------------------------------------------------------------------------------------------|
     |GEOCODE|仅返回地理编码结果（如国家、城市、街道等），而不返回商业结果（如酒店、餐馆、火车站等）。可以使用此类型过滤掉商业数据，消除用户输入中存在的歧义。例如：用户输入中国时，返回中国，不返回中国银行等数据。|
     |ADDRESS|GEOCODE的子集。仅返回具有精确地址的地理编码结果，不返回商业结果和粗粒度的地理编码结果（如国家、城市等），推荐在搜索完整地址时使用此类型。|
     |ESTABLISHMENT|GEOCODE的补集。仅返回作为商业结果（如酒店、餐馆、火车站等），不返回地理编码结果（如国家、城市、街道等）。例如：用户输入中国时，返回中国银行等数据，不返回中国。|
     |REGIONS|GEOCODE的子集。仅返回与以下类型匹配的地点： * LOCALITY * SUBLOCALITY * POSTAL_CODE * COUNTRY * ADMINISTRATIVE_AREA_LEVEL_1 * ADMINISTRATIVE_AREA_LEVEL_2|
     |CITIES|仅返回LOCALITY或ADMINISTRATIVE_AREA_LEVEL_3类型的地点。|

   * countryCode：在指定的国家内搜索，采用ISO 3166-1 alpha-2。
   * language：搜索结果的语种，取值范围参见[支持的语言](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/language-mapping-0000001050162856)的语种代码。如果不指定语种，返回英语，如果没有英语，返回当地语言。
   * politicalView：政治观点参数，采用ISO 3166-1-alpha-2规范的2位国家/地区码，该参数已废弃。
   * children：是否返回子节点，默认为false。传入children为true，返回子节点的siteId。
   * strictBounds：是否严格限制在Bounds内搜索，默认值为false。
   * countries：支持传入多个国家码，最多5个。搜索结果将严格限制在所传的国家范围内。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506195621.88841010435913134832271571666383:50001231000000:2800:C165E7973255A16BE832CE2259A2B8D938736779230079586899B6EFC12E2BD4.png)  
   * 如果bounds、location都传的话，那么bounds优先。
   * 如果同时设置了countryCode和countries，取并集。

   <br />

3. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象，该对象用来侦听搜索结果。
4. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象调用[querySuggestion](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711#section15111545173619)()接口，传入第2步创建的[QuerySuggestionRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-querysuggestionrequest-0000001050154769)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象。
5. 通过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象获取搜索结果[QuerySuggestionResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-querysuggestionresponse-0000001050154773)对象。通过[QuerySuggestionResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-querysuggestionresponse-0000001050154773)对象，可以获取[Site](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781)列表，进而解析具体的地址信息。

示例代码如下：

```
"Java"
// 声明SearchService对象 
private SearchService searchService; 
// 创建SearchService实例 
searchService = SearchServiceFactory.create(this, "API key");
// 创建请求体 
QuerySuggestionRequest request = new QuerySuggestionRequest(); 
request.setQuery("Paris"); 
Coordinate location = new Coordinate(48.893478, 2.334595); 
request.setLocation(location); 
request.setRadius(50);  
request.setCountryCode("FR"); 
request.setLanguage("fr"); 
request.setChildren(false);
request.setStrictBounds(false);
request.setCountries(Arrays.asList("en", "fr", "cn", "de", "ko"));
// 创建搜索结果侦听器 
SearchResultListener<QuerySuggestionResponse> resultListener = new SearchResultListener<QuerySuggestionResponse>() { 
    // 正常结果返回 
    @Override 
    public void onSearchResult(QuerySuggestionResponse results) { 
        if (results == null) { 
            return; 
        } 
        List<Site> sites = results.getSites(); 
        if (sites == null || sites.size() <= 0){
            return;
        }
        for (Site site : sites) { 
            Log.i("TAG", String.format("siteId: '%s', name: %s\r\n", site.getSiteId(), site.getName())); 
        } 
    } 
    // 异常结果返回 
    @Override 
    public void onSearchError(SearchStatus status) { 
        Log.i("TAG", "Error : " + status.getErrorCode() + " " + status.getErrorMessage()); 
    } 
}; 
// 调用地点搜索建议接口 
searchService.querySuggestion(request, resultListener);
```

```
"Kotlin"
// 声明SearchService对象
val searchService: SearchService
// 创建SearchService实例
searchService = SearchServiceFactory.create(this, "API key")
// 创建请求体
val request = QuerySuggestionRequest()
request.query = "Paris"
val location = Coordinate(48.893478, 2.334595)
request.location = location
request.radius = 50
request.countryCode = "FR"
request.language = "fr"
request.strictBounds = false
request.countries = listOf("en", "fr", "cn", "de", "ko")
// 创建搜索结果侦听器
val resultListener: SearchResultListener<QuerySuggestionResponse> = object : SearchResultListener<QuerySuggestionResponse> {
    // 正常结果返回
    override fun onSearchResult(results: QuerySuggestionResponse?) {
        if (results == null) {
            return
        }
        val sites: List<Site>? = results.getSites()
        if (sites == null || sites.isEmpty()) {
            return
        }
        for (site in sites) {
            Log.i("TAG", "siteId: ${site.getSiteId()}, name: ${site.getName()}")
        }
    }
    // 异常结果返回
    override fun onSearchError(status: SearchStatus) {
        Log.i("TAG", "Error : ${status.getErrorCode()}  ${status.getErrorMessage()}")
    }
}
// 调用地点搜索建议接口
searchService.querySuggestion(request, resultListener)
```
