# 鉴权后读取子应用私有数据

卡片验证读卡设备。读卡设备用目标卡片的card_key，使用AES 128 CBC模式加密applet生成的随机数，applet解密并验证。

1. 生成16字节的AES IV，并写入EF10文件。

   选择"EF10"文件：

   ```screen
   00A4000002EF10
   ```

   将AES IV写入"EF10"文件，文件内容为LV（Length+Value）格式。例如IV = "FF6A7D01AC09C16198844D8FE15102CF"，则写入"10FF6A7D01AC09C16198844D8FE15102CF"：

   ```screen
   00D600001110FF6A7D01AC09C16198844D8FE15102CF
   ```

2. Applet生成16字节随机数，读取响应的随机数，指令如下：

   ```screen
   0084000010
   ```

   获取生成的随机数。将随机数使用目标卡片的card_key，用"AES/CBC/NoPadding"加密为"encryStr"。
   > 说明
   >
   > card_key的生成方式由用户自定义。保证服务器下发的目标卡片的card_key，与本节读卡设备用于加密随机数的密钥一致即可。

3. 发送外部认证指令，"0082000310"+encryStr，指令如下：

   ```screen
   00820003100B0740D3B02E6FD66FD25D5A1C362E3F resp : 9000
   ```

   成功则返回"9000"。

4. 读取卡片个人化数据。

   卡片个人化数据，如下。

   |名称|标识|文件名|最大长度（字节）|用途|
   |:----|:---------------|:---|:-------|:-------------------------|
   |卡证书文件|card_certificate|EF01|2048|发卡方发放的卡片证书信息。|
   |卡标识|card_id|EF02|128|发卡方发放的卡片唯一标识。|
   |卡私有信息|card_privateInfo|EF03|256|发卡方发放的卡片私有信息，如卡片有效期，权限等信息。|

   读取卡片个人化数据，成功则返回"9000"，例如：

   ```screen
   // 选择"EF01"
   00A4000002EF01 resp : 9000
   // 读"EF01"，2048字节
   00B00000FF resp : xxxxx
   00B000FFFF resp : xxxxx
   00B001FEFF resp : xxxxx
   00B002FDFF resp : xxxxx
   00B003FCFF resp : xxxxx
   00B004FBFF resp : xxxxx
   00B005FAFF resp : xxxxx
   00B006F9FF resp : xxxxx
   00B007F808 resp : xxxxx

   // 选择"EF02"
   00A4000002EF02 resp : 9000
   // 读"EF02"，128字节
   00B0000080 resp : xxxxx

   // 选择"EF03"
   00A4000002EF03 resp : 9000
   // 读"EF03"，256字节
   00B00000FF resp : xxxxx
   00B000FF01 resp : xxxxx
   ```
