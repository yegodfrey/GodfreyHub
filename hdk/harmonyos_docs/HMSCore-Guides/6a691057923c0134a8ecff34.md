# 卸载召回

## 功能概述

开发者使用华为分析用户分群功能精准圈选卸载人群，通过应用市场的Push精准触达卸载用户并发放优惠券、礼包，有效召回流失人群，助力企业提升ROI。

## 典型应用场景

* 召回近14天卸载应用的用户，提升召回率。
* 唤醒长期沉默用户，提升用户活跃度，促进消费。

## 操作流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115257.55163664360568085404062867867881:50001231000000:2800:86687ECDDA9F49CA49797D0760FC949EC16DFCDBBA4C57859D15A5E3E60E886E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

1. 精准圈选流失受众。
   1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
   2. 选择需要查看分析数据的应用。
   3. 选择"华为分析 >人群洞察>用户分群"，进入用户分群页面。
   4. 点击"新建"并填写受众群组相关信息，精准圈选出本次召回的目标用户，详情请参见[如何创建受众](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/audience-analysis-new-0000001113372616#section16141458101015)。 说明
      >
      > 也可以在[留存分析](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/retention-analysis-0000001050745159)、[用户生命周期分析报告](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/user-lifecycle-0000001050985175)中自由圈选受众。
2. 同步受众群组至应用市场活动管理。
   1. 创建受众群组后在用户分群页面点击右上角的![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115257.26401240911775872603080913963163:50001231000000:2800:2D2D544119F87F16B1DE6DCF491B5BFD8B599AB435D006A55777A988E8A7F2C2.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)或者选择"华为分析 > 管理 > 受众同步管理"，进入受众同步管理页面。
   2. 选择"应用市场活动管理"页签。

      展示当前应用下所有离线受众群组，您可以在页面右上角下拉框处切换应用。
   3. 打开想要同步至应用市场活动管理的受众群组的"同步开关"。

      同步成功后，应用市场活动管理中可选择该群组进行操作。

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115257.10502152015413189798986377430760:50001231000000:2800:BA1C5CD1313DBBB4DB21057998F4437CE162877A17CDA6525C9957923544022C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
3. 创建流失召回活动，针对受众人群发送优惠券或礼包。
   1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
   2. 在应用列表页面选择要创建活动的应用。
   3. 选择"运营 > 活动运营 > 活动管理 > 新建活动"进入新建活动页面。
      * "活动目的"选择"用户维系（流失召回）"，该场景不仅可以适用流失召回，同样可以做新用户促活或者付费转化。
      * "用户类型"选择"受众群组（含预测人群）"，在右侧下拉框中选择需要发送礼包的人群。

      ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115257.04818539795385240173386991075325:50001231000000:2800:E0E9263E56822CD4818251743B2493B44C64EA1903851944C276A98D7A95547D.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
   4. 完成新建活动的其他信息后提交审核，详情请参见[活动管理](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help--management-activities-0000001100159966#section7207836203712)。审核通过后华为应用市场将会在设定的时间给目标人群发送礼包。
