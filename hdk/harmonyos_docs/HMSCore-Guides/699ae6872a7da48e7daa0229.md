# 文件管理和搜索

#### 场景介绍

华为云空间服务的核心能力是对云端文件的管理，用户可以通过华为云空间服务方便快捷的管理、编辑华为云盘上的文件，支持创建、获取文件列表、拷贝、修改、删除文件、移入回收站、清空回收站文件及搜索云盘上的文件等能力。  

#### 列举文件列表

功能简介

Files.list接口实现根据条件列举出目录或文件列表功能。

限制

* 查询参数中的fields为可选参数，格式需要满足Partial-response要求。
* 查询参数中的queryParam，根据属性过滤文件，可选值为parentFolder, fileName等。
* 查询参数中的orderBy是逗号分隔的列表，可选值为createdTime，folder，editedTime，fileName和size。每个键默认情况下升序排列，可以使用desc反转。例如orderBy=folder，editedTimedesc，fileName。注意如果超过10万文件，将忽略orderBy。
* 查询参数中的pageSize默认值是100，如果设置为null或者负数，取默认值，大小校验值在1\~100。
* 查询参数中的containers，指查询范围，可选值drive和applicationData，或两者的组合，以逗号连接。默认是drive。
* fileName字段不能超过250字节, 文件名中有单引号要使用转义\\', 不能包括 \<\>\|:"\*?/\\ 中的任意一个字符和emoji ，不能等于.. 或者 . 。
* form参数暂仅支持"json"，不传默认json。
* 没有父目录的文件可根据fileName查询。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.appdata
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly
  * https://www.huawei.com/auth/drive.metadata
  * https://www.huawei.com/auth/drive.metadata.readonly

发送一个列举文件列表的请求

1. 创建一个对Files.list接口的[GET](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-fileslist-0000001050153649)请求。
2. 填入HTTP headers。

   <br />

   * Accept：接收回复的报文格式
   * Content-Type：发送报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

   <br />

3. 发送请求。

   <br />

   请求示例：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files?fields=* HTTP/1.1
   Content-Type: application/json

#### 清空回收站

功能简介

Files.emptyRecycle接口实现清理用户云盘回收站的功能，并可以根据参数containers选择是否清理当前应用的回收站。

限制

* 入参containers为可选参数，只能为drive或applicationData，或两者的组合，以逗号连接；containers为空时，默认为drive。
* containers为drive，调用该接口将会清空网盘回收站，此时需要设置scope为https://www.huawei.com/auth/drive。
* containers为applicationData，调用该接口将会清空应用回收站，此时需要设置scope为https://www.huawei.com/auth/drive.appdata。
* containers为drive,applicationData，调用该接口将会同时清空网盘回收站和应用回收站，此时需要同时设置scope为https://www.huawei.com/auth/drive和https://www.huawei.com/auth/drive.appdata。

发送一个清空回收站的请求

1. 创建一个对Files.emptyRecycle接口的[DELETE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filesemptyrecycle-0000001050151698)请求。
2. 填入HTTP headers。

   <br />

   Authorization：填入从华为帐号获取的authorization code

   <br />

3. 发送请求。

   <br />

   请求示例：

   ```
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/recycle HTTP/1.1
   Authorization: Bearer CV3PnPLZXyr9K2GV7RYZkF962JZvoEkMQhTho3QHQAPQUyma/lEyZskP/IMWrc7FvaeHivO7y0lyibI/fQvulBnTgtXArSVPsjaLKvYNkDsJSaIR2/sx+K40bYDWWpKFvJNKg2U47jRwz2mfiF3ortNk
   ```

   响应：

   ```
   HTTP/1.1 204 OK
   ```

   <br />

#### 订阅文件变化

功能简介

Files.subscribe接口实现订阅目录或文件变化的功能，主要针对的是某个资源维度的变化。

限制

* 必填参数：fileId，id，type，url。
* id只支持大小写字母及数字的组合，且长度不超过256个字符。
* url参数采用允许清单机制，只支持设置在允许清单中的url。允许清单中url的设置通过AGC网页添加，以www格式开头，仅支持https协议。因此本接口请求体中的url需要以https://格式开头。（url清单添加请参考: [开启文件变化通知步骤1](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-enable-notification-0000001064341112#section154524710915)）
* type，只支持 web_hook。
* expirationTime，UTC时间戳，默认一小时。
* 仅支持80/8080/443/8443/8888此范围内端口回调
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.appdata
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly
  * https://www.huawei.com/auth/drive.metadata
  * https://www.huawei.com/auth/drive.metadata.readonly

说明

回调url通知变更消息使用POST请求。

发送一个订阅文件变化的请求

1. 创建一个对Files.subscribe接口的[POST](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filessubscribe-0000001050153637)请求。
2. 添加查询参数 fileId，fields。

#### 删除文件

功能简介

Files.delete接口实现将文件彻底删除，无法恢复。

限制

* 只能删除普通目录，并且是递归删除，不包括根目录。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.appdata

<!-- -->

* 如果文件或者文件夹的父目录或者子目录层级中含有owner是其他用户的文件夹时，无法删除该文件。此时只能使用叶子文件的owner执行删除操作。

发送一个删除文件的请求

1. 创建一个对Files.delete接口的[DELETE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filesdelete-0000001050153647)请求。
2. 添加路径参数fileId。

   <br />

   例如：

   ```
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}
   ```

   <br />

3. 填入HTTP headers。

   <br />

   * Content-Type：发送报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/DSQpEkxcAAADKXEPJAYABgOUVrNwA8Cu HTTP/1.1
   Content-Type: application/json
   Authorization: Bearer CV3PnPLZXyr9K2GV7RYZkF962JZvoEkMQhTho3QHQAPQUyma/lEyZskP/IMWrc7FvaeHivO7y0lyibI/fQvulBnTgtXArSVPsjaLKvYNkDsJSaIR2/sx+K40bYDWWpKFvJNKg2U47jRwz2mfiF3ortNk
   Cache-Control: no-cache
   ```

   响应：

   ```
   HTTP/1.1 204 OK
   ```

#### 修改并上传文件（multipart方式）

功能简介

Files.update.multipart接口实现更新文件元数据（元数据全量更新）、缩略图、文件内容的功能，用户可以通过fileId指定要更新的文件。

限制

* 必填参数：fileId、uploadType、request body请求体、Content-Type。
* Content-Type类型必须为 multipart/related 类型，uploadType必须为multipart，且request body体需要满足 multipart要求格式。
* 元数据中的时间格式参数（editedTime、createdTime）需要满足RFC 3339格式。
* 更新需要带文件内容。
* fileId、fileName、description等字符型属性内容不支持emoji表情。
* 同一目录下不允许存在重名文件。
* addParentFolder和removeParentFolder 为可选字段，且addParentFolder和removeParentFolder 必须成对出现或者都为空。
* appSettings大小不超过30个键值对。
* 时间参数必须为RFC 3339格式。
* description不能包含表情符号，且长度不能超过512字节。
* fileName、originalFilename长度不能超过250字节，不能包括 \<\>\|:"\*?/\\ 中的任意一个字符和emoji ，不能等于.. 或者 .。
* parentFolder不能包含".."。
* properties大小不超过30个键值对, 每个字段长度不能超过256字节。
* sha256符合文件sha256，长度必须64字节。
* contentExtras可不传。若有值，则thumbnail的content必须base64编码，不能大于2MB。若传值非法，则忽略，并基于可支持类型的上传文件生成默认缩略图。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.appdata
  * https://www.huawei.com/auth/drive.file

<!-- -->

* mimeType采用通用格式规范。
* 请求体中元数据必须在文件内容之前。

说明

PUT更新方式为全量更新，PATCH更新方式为增量更新。

#### 修改并准备续传文件

功能简介

调用Files.update.resume接口进行初始化断点更新，对已有文件元数据进行全量更新，解析元数据，最终返回uploadId以供使用。

限制

* 接口路径必填参数：fileId，uploadType=resume。
* 必填参数：X-Upload-Content-Length。
* addParentFolder和removeParentFolder要么都为空，要么都不为空。
* request body体只支持"json"，或为空。
* addParentFolder和removeParentFolder不支持回收站路径。
* appSettings大小不超过30个键值对。
* 时间参数必须为RFC 3339格式。
* description不能包含表情符号，且长度不能超过512字节。

#### 续传文件

功能简介

Files.resume接口实现了使用断点续传Files.create.resume或Files.update.resume接口返回的location信息查询当前文件的断点信息；根据返回的断点信息，续传新的分片内容，最终实现断点上传大文件的功能。

限制

* 必填参数：uploadId。
* 单次上传大小限制为64M。
* uploadId 标识具体申请的断点续传。
* uploadType=resume 指明上传类型为断点续传类型。
* Content-Length大小与body中包含的内容长度相同，Content-Length为0的时候默认为查询断点信息状态。
* Content-Range 形式如bytes start-end/totalFileSize, 其中start为当前上传的body内容在整个文件中的开始位置end为结束位置，totalFileSize为之前调用Files.create.resume接口中申请的文件大小，end-start+1的大小应该与Content-Length相同。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.appdata
  * https://www.huawei.com/auth/drive.file

<!-- -->

* contentType采用通用格式规范。

说明

* 返回308指明当前文件上传到的断点位置，返回200/201上传成功，404当前LOCATION信息失效，需要从调用Files.create.resume接口开始重新进行。
* 本接口需要在最后一次上传文件成功后，再次触发本接口才可以获取文件元数据信息（例如，小于64MB的文件上传时，需要调用两次本接口获取文件元数据信息）。

功能简介

Files.get接口实现获取某个文件的元数据信息。

限制

* fields为可选字段，格式需要满足Partial-response要求。
* 只有reader/writer/commenter/owner可以获取。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.appdata
  * https://www.huawei.com/auth/drive.metadata
  * https://www.huawei.com/auth/drive.readonly
  * https://www.huawei.com/auth/drive.metadata.readonly

发送一个获取文件元数据的请求

1. 创建一个对Files.get接口的[GET](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filesgetmetadata-0000001050153645)请求。
2. 添加查询参数fileId和fields。

   <br />

   例如：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}?fields=*
   ```

   <br />

3. 填入HTTP headers。

   <br />

   * Accept：接收回复的报文格式
   * Content-Type：发送报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/DSQpEkxcAAADKXEPJAYABgOUVrNwA8Cu HTTP/1.1

#### 下载文件内容

功能简介

File.get.content接口实现下载文件数据，用户可以根据Range指定下载文件的数据范围。

限制

* 必填参数：fileId。
* Range格式为bytes=start-end。
* form字段暂仅支持"content"，不传报错。
* 只支持下载文件数据，不支持元数据和文件夹。
* 只有owner可以下载该文件。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive.readonly
  * https://www.huawei.com/auth/drive.appdata

发送一个下载文件内容的请求

1. 创建一个对Files.get.content接口的[GET](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-filesgetcontent-0000001050153651)请求。
2. 添加查询参数 fileId和fields。

   <br />

   例如：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}?form=content
   ```

   <br />

3. 填入HTTP headers。

   <br />

   Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/DSQpEkxcAAADKXEPJAYABgEZivNwAmCu?form=content HTTP/1.1
   Authorization: Bearer CV3PnPLZXyr9K2GV7RYZkF962JZvoEkMQhTho3QHQAPQUyma/lEyZskP/IMWrc7FvaeHivO7y0lyibI/fQvulBnTgtXArSVPsjaLKvYNkDsJSaIR2/sx+K40bYDWWpKFvJNKg2U47jRwz2mfiF3ortNk
   ```

   响应：

   ```
   HTTP/1.1 200 OK
   [imageData]
   ```
