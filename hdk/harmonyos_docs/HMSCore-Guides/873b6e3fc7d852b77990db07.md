# 端侧接入

#### 概述

华为数字车钥匙依托华为钱包数字车钥匙业务集成方案，基于华为手机"芯-端-云"一体化的安全能力，且满足ICCE标准，可快速实现手机模拟车钥匙的功能。

相较于传统的车钥匙，华为数字车钥匙无需借助车钥匙实体，仅将车钥匙功能集成在移动智能终端设备中，基于SE、TEE等安全功能，使用NFC技术连接手机和车，即可实现车辆的开门、启动等功能。  
![](https://media:101782807019562756)  
此方式当前仅支持中国大陆区域。

#### 生命周期

数字车钥匙主要的业务操作包括四步：钥匙开通、钥匙使用、钥匙分享、钥匙删除。

钥匙的开通、分享和删除均属于钥匙生命周期管理，且需要基于Internet网络发起操作、同步钥匙状态；而钥匙使用则不依赖于Internet网络，只需移动终端正确开通钥匙即可使用。

#### 添加钥匙

1. 商户需要先校验本地的钱包版本是否支持数字车钥匙，具体版本请向华为运营人员确认。
2. 商户App调用[canAddPass](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section19229134124911)接口判断当前钱包是否可以添加钥匙。
3. 商户App调用[addPass](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section148541848134914)接口将服务器生成的钥匙包推送至华为钱包，华为钱包根据其类型创建Applet实例。具体操作请参考[App应用集成Wallet Kit SDK后推送钥匙包到华为钱包应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-hms-sdk-add-card-0000001050166747)。  

#### 激活钥匙

商户可根据添加钥匙的结果来决定是否执行激活钥匙的操作，若华为钱包返回成功状态，商户可直接调用钱包SDK的注册和个人化接口实现NFC钥匙信息的写入，具体操作请参考[调用Wallet Kit SDK接口实现NFC写卡能力](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-common-nfc-0000001050044325)。待华为钱包将NFC钥匙信息写入手机芯片，则钥匙激活完毕。

1. 商户App调用[requestRegister](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section12769754173112)和[confirmRegister](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section45719114599)接口认证应用实例。
2. 商户App调用[requestPersonalize](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section154105517143)和[confirmPersonalize](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section46909298229)接口写入NFC钥匙信息。  

#### 钥匙查询

商户App调用[queryPassStatus](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section499825711517)接口查询钥匙状态。

```
// 调用钱包SDK查询钥匙状态
WalletPassApiResponse response = mWalletPassApi.queryPassStatus(passTypeIdentifier,passId);
```

#### 钥匙删除

钥匙删除的两种方式：

* 商户APP删除：商户APP删除车钥匙后，调用[deletePass](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-hw-passsdk-walletpassapi-0000001050986379#section77184565117)接口删除钱包内的车钥匙。

  ```
  // 调用钱包SDK删除钥匙
  WalletPassApiResponse response = mWalletPassApi.deletePass(passTypeIdentifier,passId,sign);
  ```

<!-- -->

* 华为钱包删除：华为钱包删除钥匙后，钱包会上报删除事件至钱包服务器，由服务器通知商户钥匙已被删除。

#### 特殊场景说明

1. 钥匙挂失
   * 合作伙伴挂失 合作伙伴通过服务器将车端钥匙的数据置为无效状态。

   * 华为挂失 方式一：运营人员通过钱包管理台将手机侧的钥匙数据删除。

     方式二：用户使用华为帐号登录HiCloud网站，进行自助远程删除。
2. 退出华为帐号 退出帐号时可选择保留或删除钥匙数据。

3. 恢复出厂设置 手机恢复出厂设置会删除钥匙数据。

![](https://media:101782807019902762)  
钥匙被挂失或删除后，服务器会通知合作伙伴钥匙已被删除。  

#### 认证交互流程

数字车钥匙认证交互采用基于随机数衍生会话密钥做双向鉴权的密钥认证逻辑。

具体内容请参考《智慧车联产业生态联盟数字车钥匙系统》文档第一部分第六章节中的钥匙使用。  

#### 关键参数说明

|参数|说明|来源及生成时机|字节长度|必选/可选|
|:------------------|:----------------------------------------------------------------------------------------------------------------------------------------------|:------------|:-------------|:----|
|CardKey（即Dkey）|车钥匙业务密钥，用于协商会话密钥的基础密钥。|车端写卡时生成|16bytes|必选|
|CardKeyIV|计算会话秘钥的基础向量IV，不传入默认全0，传入则需要同步下发车端。|车端写卡时生成|16bytes|必选|
|ReaderRnd|车侧随机数。|车端刷卡时生成|8bytes|必选|
|CardRnd|车钥匙应用卡片随机数。|手机端刷卡时生成|8bytes|必选|
|ReaderKeyParameter|车侧会话密钥分散因子。|车端刷卡时生成|变长|可选|
|SessionKey|* AES128会话秘钥。 * 计算方式： Last ENCblock = AES128_CBC（CardKey，CardKeyIV，ReaderRnd\|\|CardRnd\|\| ReaderKeyParameter）。 * 填充方式：ALG_AES_CBC_ISO9797_M2。|手机端和车端刷卡时计算生成|加密结果的后16bytes|必选|
|SessionIV|AES128会话秘钥IV，由ReaderRnd\|\|CardRnd取值直接拼接Value获取。|手机端和车端刷卡时计算生成|16bytes|必选|
|Card Info1|车钥匙应用自定义数据，CardPrivateInfo取值中9F05Tag下的内容。|车端写卡时生成|100 bytes以内|可选|
|ReaderType|读卡器类别。|车端写卡时生成|变长，建议不超过6bytes|可选|
|ReaderId|Reader唯一标识。|车端写卡时生成|建议8bytes|必选|
|CardId|卡片唯一标识。|车端写卡时生成|16bytes|必选|
|CardSEId|Applet唯一标识。|手机端写卡时生成|8bytes|必选|
|CardATC|卡端计数器。|手机端刷卡时生成|4bytes|必选|
|CardAuthParameter|车企自定义认证数据，下发到卡端，车端同步下发，CardPrivateInfo取值中9F31Tag下的内容。|车端写卡时生成|30bytes以内|必选|
|ReaderAuthParameter|车企自定义认证数据。|车端刷卡时生成|建议10bytes|可选|

![](https://media:101782807019928763)  
* 协商生成的SessionKey及SessionIV用于后续所有的ALG_AES_CBC_ISO9797_M2加密场景，直至本次交易结束。
* ALG_AES_CBC_ISO9797_M2填充方式说明： 明文数据右端先填充0x80，填充后的字节长度不足16字节整数倍时，则填充0x00至16字节整数倍。

#### APDU指令说明

1. 选择应用

   <br />

   说明：选择AID。

   Request："00A40400"+Lc+AID。  
   指令样例：

   ```
   00A4040010A000000048575041590600000102000200
   ```

   Response："6F"+Lc +"84"+Lc+AID +"A5" +LC +"9F08"+Lc+APP version（2bytes）+status（9000）。

   响应样例：

   ```
   6F198410A0000000485750415906000001020002A5059F080281159000
   ```

   <br />

2. 获取处理数据

   <br />

   说明：读卡器执行getProcessData，发送ReaderId、ReaderRnd及ReaderKeyParameter信息给Applet，Applet选择对应的ADF文件，并协商会话秘钥SessionKey后，以明文和密文方式返回处理数据。

   Request："80CA0000"+Lc+"9F35"（可选）+Lc+ReaderType+"9F1E"+Lc+ReaderID+"9F37"+Lc+ReaderRnd+"9F0C"（可选）+Lc+ ReaderKeyParameter。  
   指令样例：

   ```
   80CA0000299F1E08F5C7A813ACC1CB969F3708F5C7A813ACC1CB969F0C10F5C7A813ACC1CB96F5C7A813ACC1CB96
   ```

   Response："77"+Lc+"5A"+Lc+CardSEId +"9F3B"+Lc+CardId +"9F3E"+Lc+CardRnd+"9F05"（可选）+Lc+Card Info1+"73"+Lc+密文（SessionKey及IV加密【"9F36"+Lc+CardATC+"9F37"+Lc+ReaderRnd】）+status（9000）。  
   响应样例：

   ```
   774B5A089F1E08F5C7A813AC9F3B109F1E08F5C7A813AC9F1E08F5C7A813AC9F3E089F1E08F5C7A813AC9F05109F1E08F5C7A813AC9F1E08F5C7A813AC730CAAAABBBBCCCCDDDDEEEEFFFF9000
   ```

   <br />

3. AUTH认证

   <br />

   说明：
   1. 读卡设备依据根秘钥分散出CardKey，结合CardKeyIV、ReaderRnd 、CardRnd及ReaderKeyParameter生成会话秘钥SessionKey，使用SessionIV作为IV解密GetProcessData响应报文中密文数据，并发起Auth认证。
   2. 卡片端使用SessionKey解密后，校验CardATC及CardRnd，返回加密数据。
   3. 读卡设备使用SessionKey和SessionIV解密77后密文内容，校验摘要信息一致，一致则Auth认证通过。

   Request："80800000"+LC+"77"+Lc+密文（SessionKey及IV加密【"9F36"+Lc+CardATC+"9F0A"（可选）+Lc+ReaderAuthParameter+"9F3E"+Lc+CardRnd】）。  
   指令样例：

   ```
   80800000227720D2253A0E3D097CDEF92C3A08DA28E69CA368DAE3C007AF7EAC056B1232AE0D55
   ```

   Response："77"+Lc+SessionKey及SessionIV加密【SHA256（"9F31"+Lc+CardAuthParameter+"9F0A"（可选）+Lc+ReaderAuthParameter +"9F37"+Lc+ReaderRnd）】+ status（9000）。

   响应样例：

   ```
   7722A5089F1E08F5C7A813AC9F3B109F1E08F5C7A813AC9F1E08F5C7A813AC9F3E089000
   ```
