# 停止文件变化通知

#### 场景介绍

华为云空间服务支持您的应用关闭推送指定的Channel的变化通知，关闭后，该Channel不再收到文件变化通知。注意构造的Channel对象中的Id和resourceId与Changes中subscribe的Channel对象的Id和resourceId一致。  

#### 开发前提

1、请确认您已完成[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050185569)。

2、在进行开发之前，您可以下载[华为云空间客户端示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/client-sample-code-0000001050114484)进行快速体验。  

#### 构造Drive对象

调用[Drive.Builder.build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-builder-0000001050124056#section17968156193912)接口构造Drive对象。

```
private Drive buildDrive() {  
    Drive service = new Drive.Builder(CredentialManager.getInstance().getCredential(), context).build();  
    return service;  
}
```

#### 停止指定channel的文件变化通知

获取之前注册推送通知时缓存的watchId和resourceId，调用[Channels.Stop](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-channels-stop-0000001050126005)接口停止指定channel的文件变化通知。

```
/**  
 * 关闭指定的Channel  
 * @param context 上下文环境
 * @param id UUID或其他字符串，唯一标识channel, 与subscribe接口的id保持一致
 */  
private void stopChannel(Context context, String id) {  
    try {  
        Drive drive = buildDrive();  
        SharedPreferences preferences = context.getSharedPreferences("channel_config", Context.MODE_PRIVATE);  
        String resourceId = preferences.getString("resourceId", "");  
        Channel channel = new Channel();  
        channel.setId(id); 
        channel.setCategory("api#channel");  
        channel.setResourceId(resourceId);  
        Drive.Channels.Stop stopReq = drive.channels().stop(channel);  
        stopReq.execute();  
    } catch (Exception e) {  
        Log.e(TAG, "stopChannels error: " + e.toString());  
    }  
}
```
