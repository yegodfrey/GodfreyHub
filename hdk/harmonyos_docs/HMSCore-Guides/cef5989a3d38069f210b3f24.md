#### 原子采样数据

#### 日常活动

支持获取智能表上的日常活动数据：步数、距离、卡路里。当前只支持的查询当日的统计数据（当日0点到当前时间的总数），不支持查询历史统计数据。  
当日统计查询接口请参考：[查询用户的运动健康数据当日统计值](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-datacontroller-develop-0000001183583998#section102611572032) ，读取当日步数统计示例代码如下：

```
import {HMSHealthKit, HMSHealthKitDataType} from '@hw-hmscore/hms-js-health'
// 使用指定的数据类型（步数增量：DT_CONTINUOUS_STEPS_DELTA），调用readTodaySummation接口查询该数据类型的当日统计值
// 调用readTodaySummation接口查询当日的统计值是异步操作，需要设置成功或失败Listener，返回数据查询成功或失败
HMSHealthKit.readTodaySummation(HMSHealthKitDataType.DT_CONTINUOUS_STEPS_DELTA).then((result) => {
    // 调用成功
    console.info("readTodaySummation success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.error("readTodaySummation error: " + JSON.stringify(error));
})
```

若要查询距离、卡路里的当日统计数据，可将查询类型指定为：DT_CONTINUOUS_DISTANCE_DELTA，DT_CONTINUOUS_CALORIES_BURNT。  

#### 健康采样

支持在智能表上获取健康采样数据：心率、静息心率、血氧、压力、体温、皮肤体温。用户在运动健康APP健康监测开启状态不同，会影响接口调用结果。

* 若运动健康App健康监测开启连续测量心率，支持查询心率最新数据；若未开启，只支持查询手动测量的历史数据。
* 若运动健康App健康监测开启血氧自动检测，支持查询血氧最新数据和手动测量的历史数据；若未开启，只支持查询手动测量的历史数据。
* 若运动健康App健康监测开启压力自动检测，支持查询压力最新数据和历史数据。
* 体温、皮肤体温只支持查询手动测量的历史数据。

1. 查询最新数据接口请参考：[查询用户的运动健康数据最新数据点](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-datacontroller-develop-0000001183583998#section390695615451)，查询用户的健康采样最新数据点示例代码如下：

```
import {HMSHealthKit, HMSHealthKitDataType} from '@hw-hmscore/hms-js-health'
// 步骤1：构造数据类型列表
const dataTypes = []
// 添加心率数据类型
dataTypes.push(HMSHealthKitDataType.DT_INSTANTANEOUS_HEART_RATE)
// 添加血氧数据类型
dataTypes.push(HMSHealthKitDataType.DT_INSTANTANEOUS_SPO2)
// 添加压力数据类型
dataTypes.push(HMSHealthKitDataType.DT_INSTANTANEOUS_STRESS)
// 步骤2：调用readLatest接口,根据异步回调处理查看数据成功或者失败
// 调用readLatest接口,读取心率、血氧、压力的最新数据采样点。
HMSHealthKit.readLatest(dataTypes).then((result) => {
    // 调用成功
    console.info("read success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.error("read Error: " + JSON.stringify(error));
})
```

2. 查询手动测量历史数据接口请参考：[查询用户的运动健康数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-datacontroller-develop-0000001183583998#section1474917531145)，查询用户的健康采样数据点示例代码如下：

```
import {HMSHealthKit, HMSHealthKitDataType, ReadOptions} from '@hw-hmscore/hms-js-health'
// 步骤1：构造数据类型列表
const dataTypes = []
// 构造将要查询的数据类型列表
dataTypes.push(HMSHealthKitDataType.DT_INSTANTANEOUS_STRESS);
// 步骤2：构造查询请求体
// 设置起止时间、将要读取的数据类型列表、将要读取的数据源、读取分页大小、是否设置读取前进行一次Health Service Kit数据同步。
let readOption = new ReadOptions("1624774020000", "1624774320000", dataTypes, null, null, "false")

// 步骤3：调用read接口,根据异步回调处理查看数据成功或者失败
HMSHealthKit.read(readOption).then((result) => {
    // 调用成功
    console.info("read success: " + JSON.stringify(result));
}).catch((error) => {
    // 调用失败
    console.error("read error: " + JSON.stringify(error));
})
```

#### 健康记录

支持在智能表上获取睡眠记录数据，数据字段仅支持：入睡时间（fall_asleep_time），出睡时间（wake_up_time），全部睡眠时长（all_sleep_time）；且不支持查询关联的睡眠状态采样数据。

健康记录查询接口请参考：[查询健康记录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-healthrecord-develop-0000001228985219#section117913110232)，查询用户的睡眠记录示例代码如下：

```
import {HMSHealthKit, HMSHealthKitDataType, HMSHealthKitDeviceType, DeviceInfo, DataCollector, Healthrecord, HealthRecordReadOptions} from '@hw-hmscore/hms-js-health'
// 步骤1：构造请求对象HealthRecordReadOptions
// 基于时间等参数创建健康记录读取参数
let readOptions = new HealthRecordReadOptions("1624774020000", "1624774320000", null, HMSHealthKitDataType.DT_HEALTH_RECORD_SLEEP, null);

// 步骤2：调用getHealthRecord接口，根据请求体条件获取Health Service Kit中的睡眠健康记录
HMSHealthKit.getHealthRecord(readOptions).then((result) => {
    // 调用成功
    console.info("getHealthRecord success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.error("getHealthRecord fail: " + JSON.stringify(error));
})
```

#### 运动记录

在智能表上，HealthKit只支持查询手表与南向生态设备联动产生的运动记录，目前支持的设备类型有跑步机和动感单车。

![](https://media:901788166631981688)

运动记录查询接口请参考：[读取Health Service Kit的运动记录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-activityrecord-develop-0000001228823659#section112141380218)，查询南向的运动记录示例代码如下：

```
import {HMSHealthKit, HMSHealthKitDataType, ActivityRecordReadOptions} from '@hw-hmscore/hms-js-health'
// 步骤1：创建一个ActivityRecordReadOptions实例
const dataTypeNameList = []
// 创建需要读取的运动记录关联的详情数据
dataTypeNameList.push(HMSHealthKitDataType.DT_INSTANTANEOUS_EXERCISE_HEART_RATE)
// 基于起止时间、详情数据集合，创建读取运动记录的参数
let readOption = new ActivityRecordReadOptions("1624774020000", "1624774320000", dataTypeNameList)
// 步骤2：使用getActivityRecord方法获取运动记录数据
HMSHealthKit.getActivityRecord(readOption).then((result) => {
    // 调用成功
    console.info("getActivityRecord success: " + JSON.stringify(result))
}).catch((error) => {
    // 调用失败
    console.error("getActivityRecord error: " + JSON.stringify(error));
})
```
