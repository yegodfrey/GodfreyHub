# POI详情页

提供查询POI详情功能。

* Deeplink样例：

  ```screen
  petalmaps://poidetail?center=13.7457891,100.5528094&z=x&placeId=xxx&marker=xx,xx
  petalmaps://poidetail?center=13.7457891,100.5528094&z=x&marker=xx,xx
  ```


* Applink样例：

  ```screen
  https://www.petalmaps.com/place/?center=13.7457891,100.5528094&z=x&marker=xx,xx&utm_source=fb
  ```

* 参数列表：

  |参数|是否必选|参数类型|描述|
  |:-----------|:---|:-----|:---------------------------------|
  |center|否|String|图区中心点，格式：纬度，经度。默认取marker作为图区中心点。|
  |z|否|int|缩放级别，取值范围：[3, 20]，默认15。|
  |placeId|否|String|地点ID。|
  |marker|是|String|placeId对应POI的经纬度或标记点的经纬度，格式：纬度，经度。|
  |utm_source|否|String|渠道来源（应用可以传入App包名或者应用名）。|
  |utm_medium|否|String|媒介。|
  |utm_campaign|否|String|运营活动名称。|
  |utm_term|否|String|运营活动关键词。|
  |utm_content|否|String|运营活动内容。|

* 代码样例 Intent方式：

  ```screen
  Uri content_url = Uri.parse("petalmaps://poidetail?center=13.7457891,100.5528094&z=10&marker=xx,xx&utm_source=fb"); 
  Intent intent = new Intent(Intent.ACTION_VIEW, content_url); 
  if (intent.resolveActivity(getPackageManager()) != null) {
       startActivity(intent); 
  }
  ```

  直接点击链接方式：

  ```screen
  https://www.petalmaps.com/place/?center=13.7457891,100.5528094&z=x&placeId=xxxmarker=xx,xx&utm_source=fb
  ```
