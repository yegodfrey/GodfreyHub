# 融合定位开发

#### 概述

Android SDK为开发者提供了一套获取设备位置信息的解决方案，主要面向有一定 Android 编程经验和了解面向对象编程的开发者。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240624175810.40661367106879968406841214157082:50001231000000:2800:C4B21919434FE2FAFC292FEF96340D7DCD6350B0EC1CFCC8A923326AA908331C.png?needInitFileName=true?needInitFileName=true)  
融合定位返回的位置信息默认使用WGS-84坐标系。  

#### 指定应用权限

1. Android提供了两种位置权限： ACCESS_COARSE_LOCATION（粗略的位置权限）和ACCESS_FINE_LOCATION（精确的位置权限）。需要在"AndroidManifest.xml"文件中配置权限：

   <br />

   ```
   <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
   ```

   <br />

2. （可选）在Android 10及以上版本中，如果您需要应用程序在后台执行时也具备持续定位能力，需要在"AndroidManifest.xml"文件中配置ACCESS_BACKGROUND_LOCATION权限：

   <br />

   ```
   <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
   ```

   <br />

3. 动态申请定位相关权限（Android 6.0及以上版本危险权限要求）：

   <br />

   ```
   "Java"
   // Android SDK<=28 所需权限动态申请
   if (Build.VERSION.SDK_INT <= Build.VERSION_CODES.P) {
       Log.i(TAG, "android sdk <= 28 Q");
       if (ActivityCompat.checkSelfPermission(this,
           Manifest.permission.ACCESS_FINE_LOCATION) != PackageManager.PERMISSION_GRANTED
           && ActivityCompat.checkSelfPermission(this,
               Manifest.permission.ACCESS_COARSE_LOCATION) != PackageManager.PERMISSION_GRANTED) {
           String[] strings =
               {Manifest.permission.ACCESS_FINE_LOCATION, Manifest.permission.ACCESS_COARSE_LOCATION};
           ActivityCompat.requestPermissions(this, strings, 1);
       }
   } else {
       // Android SDK>28 所需权限动态申请，需添加"android.permission.ACCESS_BACKGROUND_LOCATION"权限
       if (ActivityCompat.checkSelfPermission(this,
           Manifest.permission.ACCESS_FINE_LOCATION) != PackageManager.PERMISSION_GRANTED
           && ActivityCompat.checkSelfPermission(this,
               Manifest.permission.ACCESS_COARSE_LOCATION) != PackageManager.PERMISSION_GRANTED
           && ActivityCompat.checkSelfPermission(this,
               "android.permission.ACCESS_BACKGROUND_LOCATION") != PackageManager.PERMISSION_GRANTED) {
           String[] strings = {android.Manifest.permission.ACCESS_FINE_LOCATION,
               android.Manifest.permission.ACCESS_COARSE_LOCATION,
               "android.permission.ACCESS_BACKGROUND_LOCATION"};
           ActivityCompat.requestPermissions(this, strings, 2);
       }
   }
   ```

* ACCESS_COARSE_LOCATION：粗略的位置权限，提供城市街区级别的位置信息精准度。
* ACCESS_FINE_LOCATION：精确的位置权限，提供的位置信息比请求ACCESS_COARSE_LOCATION时所提供的位置信息更精准。

<!-- -->

* ACCESS_BACKGROUND_LOCATION：后台运行权限，在Android 10（API级别29）版本此权限为危险权限需要动态申请。在Android 10之前已授予ACCESS_COARSE_LOCATION权限的应用程序在前后台都可访问位置，在Android 10及更高版本中如需在后台访问位置权限，则需要申请ACCESS_BACKGROUND_LOCATION权限。
* 在Android 11（API 级别30）及以上，以上三个权限不能同时动态申请，需先授予ACCESS_COARSE_LOCATION和ACCESS_FINE_LOCATION权限后再申请ACCESS_BACKGROUND_LOCATION权限。  

#### 检查设备定位开关状态

定位设置状态会直接影响定位服务的定位结果，例如位置开关处于关闭状态时，将无法获取到位置信息。因此，建议您在持续获取位置信息之前，检查设备定位开关状态。

1. 调用[getSettingsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationservice-0000001050746175#section96644536583)()接口获取[SettingsClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/settingsclient-0000001051066118)实例。

   <br />

   ```
   "Java"
   SettingsClient settingsClient = LocationServices.getSettingsClient(this);
   ```

   ```
   "Kotlin"
   var settingsClient = LocationServices.getSettingsClient(this)
   ```

   <br />

2. 调用[checkLocationSettings](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/settingsclient-0000001051066118#section1653772245611)()检查设备开关设置。

   <br />

   ```
   "Java"
   LocationSettingsRequest.Builder builder = new LocationSettingsRequest.Builder();
   LocationRequest mLocationRequest = new LocationRequest();
   builder.addLocationRequest(mLocationRequest);
   LocationSettingsRequest locationSettingsRequest = builder.build();
   // 检查设备定位设置
   settingsClient.checkLocationSettings(locationSettingsRequest)
       // 检查设备定位设置接口调用成功监听
       .addOnSuccessListener(new OnSuccessListener<LocationSettingsResponse>() {
           @Override
           public void onSuccess(LocationSettingsResponse locationSettingsResponse) {
               LocationSettingsStates locationSettingsStates =
                   locationSettingsResponse.getLocationSettingsStates();
               StringBuilder stringBuilder = new StringBuilder();
               // 定位开关是否打开
               stringBuilder.append(",\nisLocationUsable=")
                   .append(locationSettingsStates.isLocationUsable());
               // HMS Core是否可用
               stringBuilder.append(",\nisHMSLocationUsable=")
                   .append(locationSettingsStates.isHMSLocationUsable());
               Log.i(TAG, "checkLocationSetting onComplete:" + stringBuilder.toString());
           }
       })
       // 检查设备定位设置接口失败监听回调
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               Log.i(TAG, "checkLocationSetting onFailure:" + e.getMessage());
           }
       });
   ```

   ```
   "Kotlin"
   val builder = LocationSettingsRequest.Builder()
   var mLocationRequest = LocationRequest()

   builder.addLocationRequest(mLocationRequest)
   val locationSettingsRequest = builder.build()
   // 检查设备定位设置
   settingsClient.checkLocationSettings(locationSettingsRequest) 
       // 检查设备定位设置接口调用成功监听
       .addOnSuccessListener(OnSuccessListener { locationSettingsResponse ->
           val locationSettingsStates = locationSettingsResponse.locationSettingsStates

           // HMS Core是否可用
           stringBuilder.append(",\nisHMSLocationUsable=")
               .append(locationSettingsStates.isHMSLocationUsable)

       }) 
       // 检查设备定位设置接口失败监听回调
       .addOnFailureListener(OnFailureListener { e ->
           Log.i(TAG, "checkLocationSetting onFailure:" + e.message)
       })
   ```

#### 初始化定位

请在主线程中声明[FusedLocationProviderClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169)类对象，传入Context或Activity类型参数。  

```
"Java"
// 声明fusedLocationProviderClient对象
private FusedLocationProviderClient fusedLocationProviderClient; 
// 实例化fusedLocationProviderClient对象
fusedLocationProviderClient = LocationServices.getFusedLocationProviderClient(this); 
```

```
"Kotlin"
// 定位交互接入对象
private lateinit var fusedLocationProviderClient: FusedLocationProviderClient
// 实例化fusedLocationProviderClient对象
fusedLocationProviderClient = LocationServices.getFusedLocationProviderClient(this)
```

#### 选择定位模式

Location SDK提供了单次定位、持续定位、后台定位能力，开发者可以根据自己的应用场景选择合适的定位模式。不同定位模式设置方式如下：  

#### 单次定位

```
"Java"
LocationRequest mLocationRequest = new LocationRequest();
// 设置定位类型
mLocationRequest.setPriority(LocationRequest.PRIORITY_HIGH_ACCURACY);
// 设置回调次数为1
mLocationRequest.setNumUpdates(1);
```

```
"Kotlin"
val mLocationRequest = LocationRequest()
// 设置定位类型
mLocationRequest.priority = LocationRequest.PRIORITY_HIGH_ACCURACY
// 设置回调次数为1
mLocationRequest.numUpdates = 1
```

#### 持续定位

```
"Java"
LocationRequest mLocationRequest = new LocationRequest();
// 设置位置更新的间隔（单位：毫秒）
mLocationRequest.setInterval(10000);
// 设置定位类型
mLocationRequest.setPriority(LocationRequest.PRIORITY_HIGH_ACCURACY);
```

```
"Kotlin"
val mLocationRequest = LocationRequest()
// 设置位置更新的间隔（单位：毫秒）
mLocationRequest.interval = 10000
// 设置定位类型
mLocationRequest.priority = LocationRequest.PRIORITY_HIGH_ACCURACY
```

#### 后台定位

1. 在"AndroidManifest.xml"中添加注册后台定位权限的服务。

   <br />

   ```
   <service        
   android:name="com.huawei.location.service.BackGroundService"        
   android:foregroundServiceType="location" /> 
   ```

   <br />

2. （可选）在Android 9及以上版本中，为保证后台定位权限的正常使用，需要在"AndroidManifest.xml"文件中配置FOREGROUND_SERVICE权限：

   <br />

   ```
   <uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
   ```

   <br />

3. 调用[enableBackgroundLocation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169#section16667181221311)()方法，传入服务通知开启后台定位能力。

   <br />

   <br />

   ```
   "Java"
   Notification.Builder builder;
   Notification mNotification;
   int notificationId = 1;
   if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
       NotificationManager notificationManager =
           (NotificationManager) context.getSystemService(NOTIFICATION_SERVICE);
       String channelId = context.getPackageName();
       NotificationChannel notificationChannel =
           new NotificationChannel(channelId, "LOCATION", NotificationManager.IMPORTANCE_LOW);
       notificationManager.createNotificationChannel(notificationChannel);
       builder = new Notification.Builder(context, channelId);
   } else {
       builder = new Notification.Builder(context);
   }
   if (android.os.Build.VERSION.SDK_INT >= Build.VERSION_CODES.JELLY_BEAN) {
       mNotification = builder.build();
   } else {
       mNotification = builder.getNotification();
   }
   fusedLocationProviderClient.enableBackgroundLocation(notificationId,mNotification);        
   ```

   ```
   "Kotlin"
   val builder: Notification.Builder
   val mNotification: Notification
   var notificationId = 1
   builder = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {

           NotificationChannel(channelId, "LOCATION", NotificationManager.IMPORTANCE_LOW)

   } else {
       builder.notification
   }

   ```

#### 获取最后的已知位置

您的应用可以调用[getLastLocation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169#section1167913136559)()方法获取设备最后的已知位置，大多情况下，该位置即为设备的当前位置。代码样例如下：

```
"Java"
// 获取最后的已知位置
Task<Location> task = fusedLocationProviderClient.getLastLocation()        
    // 获取最后的已知位置成功监听回调
    .addOnSuccessListener(new OnSuccessListener<Location>() {        
        @Override      
        public void onSuccess(Location location) {        
            if (location == null) {        
               return;        
            }        
            // TODO：成功时Location对象处理逻辑
        }        
    })
    // 获取最后的已知位置失败监听回调
    .addOnFailureListener(new OnFailureListener() {        
        @Override        
        public void onFailure(Exception e) {        
           // TODO：接口调用失败处理      
        }        
    });
```

```
"Kotlin"
val lastLocation =
    fusedLocationProviderClient.lastLocation
lastLocation.addOnSuccessListener(OnSuccessListener { location ->
    if (location == null) {
        return@OnSuccessListener
    }
    // TODO：成功时Location对象处理逻辑
    return@OnSuccessListener
})
    // 获取最后的已知位置失败监听回调
    .addOnFailureListener {

#### 使用模拟位置信息功能

具体操作：打开"设置 \> 系统和更新 \> 开发人员选项 \> 选择模拟位置信息应用 \> 选择要模拟位置信息应用"（如果没有发现"开发人员选项"，请执行如下操作："设置 \> 关于手机 \> 版本号"，连续点击"版本号"7次，"开发人员选项"会出现在"系统与更新"页面，再重复上述操作），代码开发步骤如下：

1. 在AndroidManifest.xml文件中配置模拟定位权限。

   <br />

   ```
   <uses-permission
       android:name="android.permission.ACCESS_MOCK_LOCATION"
       tools:ignore="MockLocation,ProtectedPermissions" />
   ```

   <br />

2. 设置mock模式，调用[setMockMode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169#section1333112213152)(boolean isMockMode)。

   <br />

   ```
   "Java"
   // 设置mock模式，参数传入ture：模拟模式；false:正常状态
   boolean mockFlag = true;
   fusedLocationProviderClient.setMockMode(mockFlag).addOnSuccessListener(new OnSuccessListener<Void>() {
       @Override
       public void onSuccess(Void aVoid) {
           Log.i(TAG, "setMockMode onSuccess");
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           Log.i(TAG, "setMockMode onFailure:" + e.getMessage());
       }
   });
   ```

   ```
   "Kotlin"
   // 设置mock模式，参数传入ture：模拟模式；false:正常状态
   val mockFlag = true
   fusedLocationProviderClient.setMockMode(mockFlag)
       .addOnSuccessListener { Log.i(TAG, "setMockMode onSuccess") }
       .addOnFailureListener { e ->
           Log.i(TAG,"setMockMode onFailure:" + e.message)
       }
   ```

   <br />

3. 设置模拟位置信息，调用[setMockLocation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/fusedlocationproviderclient-0000001050746169#section888218474112)(Location mockLocation)。

   <br />

   ```
   "Java"
   // 设置模拟位置信息
   final Location mockLocation = new Location(LocationManager.GPS_PROVIDER);
   mockLocation.setLongitude(118.76);
   mockLocation.setLatitude(31.98);
   fusedLocationProviderClient.setMockLocation(mockLocation)
       // 设置模拟位置信息成功监听回调
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void aVoid) {
               Log.i(TAG, "setMockLocation onSuccess");
           }
       })
       // 设置模拟位置信息失败监听回调
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               Log.i(TAG, "setMockLocation onFailure:" + e.getMessage());
           }
       });
   ```

   ```
   "Kotlin"
   // 设置模拟位置信息

       }
