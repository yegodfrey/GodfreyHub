# 名词解释

#### AAID

应用匿名设备标识符（Anonymous Application Identifier），[AAID](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aaid-overview-0000001050171862)用来标识运行在终端设备上的应用实例。  

#### APNs

苹果官方推送通知服务（Apple Push Notification service），使您能够向安装在苹果设备上的应用程序推送消息。  

#### APNs证书

使用苹果推送服务需要的证书，有"Sandbox"版本和"Production"版本。您在使用推送服务向iOS推送消息时，请确保在AGC上传的证书版本和APNs中的一致，否则，推送将会失败。  

#### APP ID

唯一应用标识符，在AppGallery Connect创建应用时生成。  

#### Client ID

应用中OAuth 2.0客户端ID（凭据），在AppGallery Connect创建应用时生成。  

#### Badge

角标，显示在应用图标的右上角，用于提示未读消息。  

#### HAP

HarmonyOS Ability Package，HarmonyOS的用户应用程序包以APP Pack（Application Package）形式发布，它是由一个或多个HAP以及描述每个HAP属性的pack.info组成。HAP是[Ability](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/basic-fundamentals-0000000000041611#section121002188527)的部署包，HarmonyOS应用代码围绕Ability组件展开。  

#### NC

统一消息中心（Notification Center），是华为终端设备上预置的系统级应用，可通过华为应用市场（名称为推送服务）进行更新，主要功能是展示华为终端设备上应用的通知栏消息。  

#### ODID

开放设备标识符（Open Device Identifier），开发者可以使用[ODID](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/opendevice-pkg-overview-0000001051071637)来标识设备。  

#### Push Kit

推送服务的英文名称，是华为为您提供的消息推送平台，建立了从云端到终端的消息推送通道，助力开发者便捷高效触达终端用户。  

#### Push Token

Push Token是推送令牌，每个设备上的每个应用的Push Token都是唯一存在的，您可以通过Push Token向应用推送消息。  

#### 上行消息

终端设备向开发者服务器发送的消息。  

#### 下行消息

开发者通过调用推送服务API，向终端设备推送的消息。
