# 接入Analytics  
  
分析服务提供基于您上报事件的分析数据模型。

分析数据模型采用了Event-Param-User模型来记录数据，通过不同的参数对事件进行描述，同时对用户的特征也进行了描述。

术语 | 名称 | 说明  
---|---|---  
Event | 事件 | 描述一个用户在某个时间点、某个地方、以某种方式完成了某个具体的事情。包含who、when、where、how、what等关键要素。  
Param | 参数 | 事件上报的关联参数。如加入购物车事件中的商品名称参数和商品价格参数，支持后续的深入分析。  
UserProfiles | 用户属性 | 用户的属性表，常见的用户属性有设备型号、应用版本、自定义的用户属性（如食品偏好）等。  
  
Analytics Kit会收集AAID。AAID是应用匿名标识符，每个App在同一个设备上会分配不同的AAID。AAID用于连通华为提供的各项服务，例如Push、分析服务和远程配置等。

AAID会在如下场景重置：

  * 用户卸载后重装应用。 
  * 用户恢复出厂设置。 
  * 用户清除应用数据。 
  * 应用主动调用[clearCachedData](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section7238134312)接口。 



#### 接入步骤

  1. 配置应用安装来源。

通过配置应用安装来源，您可以自主设置安装来源，例如：可以用于分析下载应用的应用市场，解析营销方案的实际效果。

打开您的工程“AndroidManifest.xml”文件，配置应用的安装来源。在“application”模块根节点下添加meta-data参数，格式如下。
         
         <application>
             ……
             <meta-data
                 android:name="install_channel"
                 android:value="_install_channel_value_ ">
             </meta-data>
             ……
         </application>

将“install_channel_value”替换为您的应用安装来源。例如：安装来源为华为应用市场，则将“install_channel_value”替换为“AppGallery”。

     * 安装来源命名规范：支持英文字母、阿拉伯数字、下划线、中划线和空格，不能以空格开头和结尾，长度不超过128个字符。可填写便于您记忆和理解的安装来源名称。 
     * 应用安装来源也可以通过[setChannel](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section769506184513)接口进行设置。通过接口设置的值，优先级低于通过“AndroidManifest.xml”文件配置的值，如果“AndroidManifest.xml”中配置的安装来源有值，则[setChannel](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section769506184513)接口设置的值不生效。 

  2. 初始化Analytics SDK。

SDK通过[getInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-0000001050707170#section4210134665720)接口根据配置完成初始化。

     * SDK初始化时会发送网络请求，请您务必在用户同意隐私协议后再初始化SDK。设置能否发送网络请求实现方法详情请参见[为满足监管要求，集成SDK后要求用户在未同意访问网络前不能发送任何网络请求，如何处理？](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876#section3638114945120)

  3. （可选）如果您需要从Google Play查询Referrer，可以添加如下示例代码。

            implementation 'com.android.installreferrer:installreferrer:2.2'

     2. 在初始化分析服务SDK之后，调用[setCustomReferrer](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section1484117422326)方法设置自定义Referrer。

            // 获取HiAnalyticsInstance实例

                @Override
                public void onInstallReferrerSetupFinished(int responseCode) {
                    if (responseCode == InstallReferrerClient.InstallReferrerResponse.OK) {
                        try {
                            ReferrerDetails details = client.getInstallReferrer();
                            // 设置自定义Referrer
                            instance.setCustomReferrer(details.getInstallReferrer());
                        } catch (RemoteException exception) {
                            // 捕获异常
                        }
                    }
                }
                @Override
                public void onInstallReferrerServiceDisconnected() {
                    // 断开service
                }
            });

                        } catch (exception: RemoteException) {
                            // 捕获异常

                    }
                }

                }

  4. （可选）设置上报策略。

Analytics SDK提供了四种事件上报策略，支持多种策略自由组合，任何一种策略满足时即可触发事件上报。您可以根据场景选择合适的事件上报策略。

如果设置上报策略，建议包含应用切后台上报策略，防止应用退出后部分事件缓存在本地不能及时上报。

策略 | 描述 | 说明  
---|---|---  
ON_APP_LAUNCH_POLICY | 应用启动上报策略 | 应用启动时上报事件。选择该策略时会立即上报一次，此后每次应用启动时上报一次。  
ON_MOVE_BACKGROUND_POLICY | 应用切后台上报策略 | 应用切后台时上报事件，包括应用退出。  
ON_SCHEDULED_TIME_POLICY | 定时上报策略 | 根据指定的间隔时间上报事件，取值范围为【60-1800】秒（默认60秒），如果设置的值超过给定范围则取边界值。  
ON_CACHE_THRESHOLD_POLICY | 阈值上报策略 | 缓存事件条数达到阈值时上报事件，取值范围为【30-1000】条（默认30条），如果设置的值超过给定范围则取边界值。  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115304.50141869498179320957367736249235:50001231000000:2800:9C04AEAE62239514210C5CE7203F6C34CC0CC23011DDDB516491E63FB8D88E3F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

     * 以上上报策略仅在非调试模式下生效。上报策略持久化保存。 
     * 应用切后台上报策略和阈值上报策略为必选策略，无论设置什么策略，这两个策略都会生效，但是可以改变阈值上报策略的阈值。 
     * 多次调用设置上报策略的接口，会刷新上报策略，仅最后一次设置的策略生效，请谨慎多次调用。 
     * 当策略满足触发事件上报时，如果没有网络，则会将事件缓存在本地，等待下次条件满足继续上报。 

  5. 如果您的应用使用了[智能运营](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/introduction-0000001131819611)服务，请务必调用[onNewIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section1698131684011)接口。
  6. 通过[onEvent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section15204518184114)接口记录定义事件。

事件的定义请参见[自动采集事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-automatic-event-collection-0000001051757143)、[通用](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-predefined-events-general-0000001051997159)、[自定义事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-custom-events-0000001051597159)。

#### （可选）配置“AndroidManifest.xml”文件

  1. 配置是否允许采集广告标识符。

是否允许采集广告标识符，您可以通过配置广告标识符采集开关的值来实现。配置方法如下：

打开您的工程“AndroidManifest.xml”文件，在“application”模块根节点下添加meta-data参数，格式如下。
         
         <application>
             ……
             <meta-data
                 android:name="analyticskit_adsid_collection_enabled"
                 android:value=_"true"_ >
             </meta-data>
             ……
         </application>

是否允许采集广告标识符默认的**value** 值为**true** ，即允许采集。您可以根据需要进行设置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115304.44961007176802145985999516024311:50001231000000:2800:555B5CB560530FC9B70D029BA4DFEA136B61E0527932165D88C01D9C0AD92EE5.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

是否允许采集广告标识符也可以通过[setCollectAdsIdEnabled](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-hianalytics-instance-0000001050987219#section38991155123016)接口进行设置。通过接口设置的值，优先级高于通过“AndroidManifest.xml”文件设置的值。

  2. 配置是否允许采集pushToken。

是否允许采集pushToken，您可以通过配置pushToken采集开关的值来实现。配置方法如下：

打开您的工程“AndroidManifest.xml”文件，在“application”模块根节点下添加meta-data参数，格式如下。
         
         <application>
             ……
             <meta-data
                 android:name="analyticskit_pushtoken_collection_enabled"
                 android:value="true">
             </meta-data>
             ……
         </application>

是否允许采集pushToken默认的**value** 值为**true** ，即允许采集。您可以根据需要进行设置。

  3. 配置禁止采集系统属性。

禁止采集系统属性，您可以通过如下配置方法来实现：

打开您的工程“AndroidManifest.xml”文件，在“application”模块根节点下添加meta-data参数，格式如下。
         
         <application>
             ……
             <meta-data
                 android:name="analyticskit_properties_collection_disabled" 
                 android:value="userAgent">
             </meta-data>
             ……
         </application>

**value** 的值为禁止采集的属性字符串，仅支持**userAgent** 。
