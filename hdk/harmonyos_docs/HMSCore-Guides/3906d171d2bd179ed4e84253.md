# 出行旅游

分析服务支持出行旅游行业分析，可以清晰洞察应用的关键指标数值，从数据概览、出行分析、酒店分析等多维度了解商品的销售情况，帮助制定精准的营销方案和产品策略。

## 典型应用场景

* 查看商品的总体销售情况，包括酒店销售额、火车票累计订单数、新增用户数和火车票销售额趋势，以及航空公司订单分布变化趋势等。
* 查看各个品类的销售情况，包括机票订单趋势、火车票订单趋势、酒店类型分布。

## 前提条件

已在"智能数据接入 > 埋点开发"中配置了出行旅游行业模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。

## 功能详述

### 案例

某出行App想要查看近期华为手机用户整体销售额情况以及了解其中最受欢迎的酒店订单和交通方式，制定相应的目的地促销计划。

需求：查看华为手机用户酒店销售情况及各个航空公司或火车票的消费情况。

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 行业分析"，进入"出行旅游"分析界面。
4. 查看出行旅游类App数据概览。详情请参见[数据概览](#section1780665211289)。
5. 查看出行旅游类App核心营收指标。详情请参见[出行分析](#section1080965214281)和[酒店分析](#section19811452172813)。
