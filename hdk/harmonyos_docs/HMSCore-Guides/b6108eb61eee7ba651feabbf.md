# 推送数量管理细则

> 注意
>
> **自2023年9月15日起，华为推送服务将对应用发送的本地通知频次及消息分类实施灰度管控** **。**本地资讯营销消息将计入每日推送总频次，云端与本地渠道共享同一限额。建议开发者统筹规划两类渠道的资讯营销消息发送策略（云端+本地资讯营销消息频次总量不可超过限定频次）。
>
> 例1：应用可发送资讯营销消息配额为5条/天，此时本地通知发送3条资讯营销消息，则通过云端通知可发送的资讯营销消息条数为5-3=2条。
>
> 例2：应用可发送资讯营销消息配额为5条/天，此时通过云端通知发送5条资讯营销消息，则通过本地通知可发送的资讯营销消息条数为5-5=0条。

为优化用户体验并营造清朗的网络环境，华为推送服务已按消息类别统一管理推送频次。

## 每日推送数量上限要求

为规范消息推送并基于[消息分类标准](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835)，华为推送服务将通知消息分为资讯营销、服务与通讯两类。自2023年1月5日起，资讯营销类消息将按应用类型设每日推送上限，服务与通讯类消息则不设限制。

|**消息分类**|**类型说明**|**推送数量限制**|
|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------|
|资讯营销类消息|**内容资讯：**内容推荐，新闻，财经动态，生活资讯，社交动态，调研，其他。 **营销活动：**产品促销，功能推荐，运营活动。 具体类别请参见[资讯营销类消息场景说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835#section174056776)。|根据应用类别限制每日推送数量，具体要求参见[不同应用类别的推送数量上限要求](#section199311418515)。|
|服务与通讯类消息|**社交通讯：**即时聊天，音频、视频通话。 **服务提醒：**订阅，出行，健康，工作事项提醒，帐号动态，订单&物流，财务，设备提醒，系统提示，邮件，闹钟/计时器，秒表，进度，位置共享。 具体类别请参见[服务与通讯类消息场景说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835#section5101818813)。|无限制。|

## FAQ

1. **如何获悉当日推送数量已经超过限制的Push Token？**

   您可以开通[消息回执](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-receipt-guide-0000001050040176)并基于接收到的回执状态码[256](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-receipt-guide-0000001050040176#ZH-CN_TOPIC_0000001700731529__p119616151514)来获取推送数量超过限制的Push Token。建议您在推送资讯营销类消息前，根据此回执信息过滤掉当日已经超过限制的Push Token，避免无效的消息推送请求。

   另外，当向某Push Token推送的消息数量已经超过当日可推送数量限制时，若您的消息推送请求仍携带该Push Token，则依旧会返回成功给您，不会影响您请求中其他Push Token的消息推送。该规则同样适用于您的推送请求中仅携带了该Push Token的场景。响应示例如下：

   ```screen
   {
       "code": "80000000",
       "msg": "Success",
       "requestId": "1574*******006"
   }
   ```

   **从2023年9月15日开始 ，将对应用发送本地通知进行分类管理，应用推送数量超过限制可能是由于应用发送了本地营销消息占用了频次，建议应用合理规划两个发送渠道的营销消息发送策略。**
2. **如何处理应用类别误分类？**

   未发布应用，可以登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"应用发布"，在应用列表中找到您的应用，修改应用分类。关于应用分类信息，请参见[华为应用市场应用分类示例](https://developer.huawei.com/consumer/cn/doc/50103)。
3. **如何处理消息分类误分类？**

   应用在不违反[华为通知违规行为](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/volation-classification-violation-penalty-criteria-0000001356540133)的前提下推送消息，可按要求申请消息[自分类权益](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835#section3410731125514)。
4. **如果推送数量不够用怎么处理？**

   建议您优化推送策略，做精细化推送，尽量减少或避免全量用户的推送。如果您的消息内容中有符合服务与通讯类消息的内容，建议您申请和接入消息自分类，申请方式请参见《[消息分类标准](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835)》，接入后该类消息将不受限制。
5. **海外也会限制消息的发送频次吗？**

   本上限管理要求仅适用中国境内地区（为免疑义，不含港澳台），暂不包括其他国家和地区。
6. **发送测试消息是否会被频控？**

   为了方便开发者测试消息，在推送消息时可以设置[target_user_type](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p119823515519)参数为1。每个应用每日可发送500条测试消息且不受[每日推送数量上限要求](#section104849311415)。
7. **本地通知的服务与通讯类消息被频控了怎么处理？**

   应用可通过申请自分类权益，对本地消息进行分类管理；应用若已申请云端相关消息类型，将自动生效本地通知类型，本地通知无需重复申请，但应用仍需[适配开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835#section1085395991513)。
