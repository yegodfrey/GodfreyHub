# 场景化示例  
  
#### 函数调用

“函数调用”自定义变量，可以调用应用中的某个类方法，传入对应参数键的值。比如某商城App，在点击购买某商品的事件中只设置了商品名称的信息。现在希望点击购买时，上报商品库存的信息，那么可以用如下方式实现。

      1. 若App中已有一个获取商品库存的通用类Inventory.java（如果没有这个类，可以先实现这个通用类），通过调用方法query(String goodName)传入商品名称可以获取当前商品库存信息。即在App中创建如下类实现[com.huawei.hms.dtm.ICustomVariable](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/dtm-icustomvariable-0000001050043805)接口，并通过[getValue](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/dtm-icustomvariable-0000001050043805#section19381825171016)方法调用Inventory类获取当前商品库存信息。
             
             package com.example.dtm;
             
             import com.huawei.hms.dtm.ICustomVariable;
             import java.util.Map;
             import com.example.goods.Inventory;
             
             public class InventoryDTMVariable implements ICustomVariable {
                 @Override
                 public String getValue(Map<String, Object> params) {
                     if (params == null) {
                         return "";    
                     } else {
                         return new Inventory().query(params.get("goodName"));
                     }
                 }
             }

      2. 创建一个“事件参数”类型的自定义变量，用于获取购买的商品名称。
