# 使用入门

RESTful API应用开发流程如下：

|序号|步骤|说明|
|:-|:-------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-config-agc-0000001063664041)|在开发应用前，需要在AppGallery Connect中配置相关信息，即[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050185569#section0795122891016)并[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050185569#section12770145621018)|
|2|[应用接入](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-preparations-0000001050185577)|开发者接入华为云空间服务时需要同时集成HMS Core SDK和Drive SDK|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-preparations-0000001050185577#section82011538185718)|开发者编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|获取鉴权信息|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用About.get获取用户信息|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用Files接口管理和搜索用户文件|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用Changes接口接收文件变化通知|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用Channels接口停止文件变化通知|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用Comments接口评论文件|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用Replies接口回复评论|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用HistoryVersion接口查询文件历史版本|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-func-description-0000001064491576)|调用Drive.batch接口实现批量操作|
|5|[开发后自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001050420197)|为尽早发现问题，尽量减少开发者集成业务提交审核后被打回的概率，HMS业务提供了提交审核前自检checklist|
|6|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001050172834)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。
