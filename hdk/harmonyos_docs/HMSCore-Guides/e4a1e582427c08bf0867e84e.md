# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSMapKit)快速体验一个应用的开发过程。

## 开发环境

* JDK 1.8及以上
* 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上

  * minSdkVersion 19及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 5.6.4及以上（推荐） Android Gradle插件 3.6.0及以上

* 测试应用的设备：EMUI 5.0及以上的华为手机、平板或Android 7.0 ~ 13的非华为手机。

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-:|:-------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289#section47264296)、[创建项目](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289#section83893131911)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289#section0592162815915)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289#section147011294331)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289#section4972271336)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289#section58097464)、[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001061560289#section169441820428)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-integrating-sdk-0000001061671869)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-obfuscation-scripts-0000001061882229)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-adding-permissions-0000001062720346)|调用地图服务能力，您需要在应用中添加权限。|
|5|[创建地图](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-map-creation-overview-0000001063041676)|使用地图容器快速地获得地图对象，并改变地图类型、在地图上显示"我的位置"，以及开启地图的精简模式等。|
|5|[地图交互](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-map-interaction-overview-0000001061674961)|通过控制地图手势开关以及内置UI控件的可见性，自定义用户与地图交互方式。|
|5|[在地图上绘制](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-drawing-map-overview-0000001062277660)|在地图上绘制标记、覆盖物以及形状等。|
|5|[自定义地图样式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-map-style-customization-overview-0000001062727534)|在应用中添加自定义风格的地图。|
|6|[从Google Maps迁移到HMS Core Map Kit](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/google-maps-to-map-kit-0000001050741577)|从最基本的环境配置开始，介绍如何将Android应用程序从Google Maps SDK for Android切换到Map Kit提供的SDK for Android。|
|7|[开发后自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001061672245)|华为提供对应用自动检查的能力。|
|8|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001193844818)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/hms-toolkit-integrating-0000001102987534)了解HMS Toolkit集成Map Kit最佳实践。
