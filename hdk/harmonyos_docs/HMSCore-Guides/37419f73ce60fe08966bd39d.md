# 集成HMS Core SDK

地图服务（Map Kit）给您提供一套地图开发调用的SDK，地图数据覆盖超过200个国家和地区，支持70+种地图展示与搜索语言，方便您轻松地在应用中集成地图相关的功能，全方位提升用户体验。

SDK名称：华为地图SDK

包名：com.huawei.hms:maps-harmony

版本号：6.4.0.300

开发者：华为软件技术有限公司

个人信息处理规则：[SDK隐私声明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sdk-java-data-security-0000002257965226)

合规指引：[SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/personal-java-data-0000002292662321)

针对DevEco Studio开发环境，华为提供了Maven仓集成方式的HMS Core SDK包。在开始开发前，您需要将HMS Core SDK集成到您的DevEco Studio开发环境中。

## 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.json"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/W4uFPAkgQRG8yA9r3Xc_nA/zh-cn_image_0000001195797943.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=34FF4CC00BC543B1CE22D48821F01C67C5F3E8D2FF802963C0A0A2FC1C0FFDB6)

4. 将"agconnect-services.json"文件拷贝到应用所在目录，路径为"entry\src\main\resources\rawfile"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/pyH0Bry3TaOJ4nxh_wNQwQ/zh-cn_image_0000001152294008.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=2AB0CEFF85D38A567B646F95391231BC53A442D30B8BF36A54A9ADACD224A91F)

## 配置HMS Core SDK的Maven仓地址

在进行HarmonyOS应用的编译构建前，需要对工程和编译构建的Module进行设置，请根据实际情况进行修改：

1. [工程级build.gradle](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/build_config-0000001052902431#section5241115818285)：工程根目录下的工程级"build.gradle"，用于工程的全局设置。
2. [模块级build.gradle](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/build_config-0000001052902431#section96415482292)：各模块下的"build.gradle"，只对本模块生效。
3. [config.json配置文件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/build_config-0000001052902431#section145162214114)：应用配置文件，用于描述应用的全局配置信息、在具体设备上的配置信息和HAP的配置信息。HarmonyOS应用的每个模块下包含一个"config.json"配置文件，在编译构建前，需要对照检查和修改"config.json"文件。

## 添加编译依赖

1. 打开应用级的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/qECRjGDnQPuHZvLbkpefqQ/zh-cn_image_0000001198399573.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC2028B2DD627C702B3482EA075016B955DD4E25ADF21A57D8CBB6AFF2B23DE7)

2. 添加编译依赖。

   在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies { 
       implementation 'com.huawei.hms:maps-harmony:{version}'  
   }
   ```

   > 说明
   >
   > *{version}* 需替换为实际的SDK版本号，版本号索引请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-sdk-version-change-history-0000001101099390)，例如：implementation 'com.huawei.hms:maps-harmony:**6.4.0.300**'。

## 同步工程

在完成以上的配置后，点击右上角"Sync Now"，完成"build.gradle"文件的同步，将相关依赖下载到本地。 说明
>
> 如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
