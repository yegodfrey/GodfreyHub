# 接入流程

**图1**接入流程   
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/FwxQZ8SYRZG__xGJH1bM7A/zh-cn_image_0000002548039037.png?HW-CC-KV=V1&HW-CC-Date=20260909T141917Z&HW-CC-Expire=31536000000&HW-CC-Sign=936EB3095BC8A84B691128CF3C5F553781972AE842D9D429C1EB47BCCD4288CB)

1. 与华为 BD 沟通合作意向，签署合作协议后，[获取 Wellness Profile 开发套件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/get-wellnessprofile-0000001055541446)。
2. 根据本文档和 Wellness Profile 开发套件完成健康设备[蓝牙模块功能开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/bluetooth-protocol-0000001054810151)（其中标准蓝牙设备需要符合标准蓝牙协议，蓝牙私有协议的设备需要自行实现设备扫描的接口并反馈设备信息进行绑定）。
3. 对于使用蓝牙私有协议的设备，还需要根据本文档和 Wellness Profile 开发套件完成[设备 H5 页面开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-h5-0000001058399933)。


4. 准备及提交素材资源文件至华为开发者联盟给华为审核。以实现在运动健康App 中添加设备（入口：App > 设备 > 添加设备）。对于蓝牙私有协议的设备，还需要上传设备 H5 页面的 zip 压缩包（包含设备详情、测量指导及测量操作界面），以实现用户在运动健康App 中使用设备并进行测量的操作。参见[准备及提交素材资源文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/prepare-0000001050724766)。
5. 测试设备蓝牙模块功能实现是否符合接入运动健康的要求。参见[蓝牙模块功能测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/weight-0000001050764801)。
6. 与运动健康App对接测试：

   1. 使用运动健康App 和测试用例，测试 NFC 一碰联和二维码扫描连接功能（当前仅血压计支持一碰联功能）。参见[一碰联功能测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/test-nfctouch-0000001055183723)。
   2. 将设备资源包拷贝到手机上，使用运动健康App 和测试用例，测试在 App 中添加设备、使用设备测量的功能是否正常。参见[App 添加设备功能测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/health-app-test-0000001050764803)。

7. 投递样机，提交测试报告至华为开发者联盟给华为进行认证测试，华为安排测试资源，反馈测试结果。
8. 若涉及到与华为品牌有关的营销材料，需提交华为审核，才可以对外发布。
9. 产品认证通过，营销等资料审核通过，产品可正式发布。
