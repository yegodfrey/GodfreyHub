# 插屏广告

插屏广告是一种在应用开启、暂停或退出时以全屏的形式弹出的广告形式，展示时机巧妙避开用户对应用的正常体验，尺寸大，曝光效果好。

## 添加插屏广告

1. 通过[ppsads.createInterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-createinterstitialad-0000001133473808)创建广告对象。

   ```screen
   const interstitialAd=ppsads.createInterstitialAd({
       slotId: "testb4znbuh3n2"
   });
   ```

2. 调用[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[load()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)加载广告，成功加载广告后再显示广告的播放入口。

   ```screen
   interstitialAd.load();
   ```

   * 成功执行[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[onLoad(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)回调：

     ```screen
     interstitialAd.onLoad(() => {});
     ```

   * 失败执行[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[onError(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)回调：

     ```screen
     interstitialAd.onError((errorCode) => {});
     ```

     > 说明
     >
     > errorCode详情请参见[JavaScript错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/error-code-0000001133633596)。
3. 调用[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[isLoaded()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)判断广告是否加载成功。

   ```screen
   if(interstitialAd.isLoaded()) {};
   ```

4. 调用[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[show()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)展示广告。

   ```screen
   interstitialAd.show();
   ```

5. 调用[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[onClose(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)监听插屏广告的关闭。

   ```screen
   interstitialAd.onClose(()=>{});
   ```

6. 调用[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[onShow(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)监听插屏广告的展示。

   ```screen
   interstitialAd.onShow(()=>{});
   ```

7. 当应用页面销毁时，调用[InterstitialAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173).[destroy()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/interstitialad-0000001179593173#section19464184724816)销毁插屏广告。

   ```screen
   interstitialAd.destroy();
   ```

## 测试插屏广告

测试插屏广告时，需要使用专门的测试广告位ID来获取测试广告，以避免在测试过程中产生无效的广告点击量。测试广告位ID仅作为功能调试使用，不可用于广告变现。您应在应用发布前先进入[流量变现官网](https://developer.huawei.com/consumer/cn/monetize)，点击"开始变现"，登录[鲸鸿动能媒体服务平台](https://developer.huawei.com/consumer/cn/service/ads/publisher/html/index.html?lang=zh)，申请正式的广告位ID并替换测试广告位ID，具体操作详情请参见[展示位创建](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/zhanshiweichuangjian-0000001132700049)。

以下表格中提供了插屏广告的专用测试广告位ID：

|广告形式|展示形式|屏幕方向|尺寸（宽*高，以px为单位）|测试广告位ID|
|:---|:---|:---|:-------------|:-------------|
|插屏广告|图片|竖屏|1080*1620|teste9ih9j0rc3|
|插屏广告|视频|竖屏|720*1080|testb4znbuh3n2|

具体实现可以参见[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-0000001050066947#section1798718513277)，运行示例代码可以看到如下效果图：
