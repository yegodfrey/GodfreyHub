# 管理健康记录

应用集成Health Service Kit后，通过调用HMSHealthKit中的接口来操作用户的健康记录数据，如下：

* [写入健康记录](#section83541252102214)（[addHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section13164153916570)）
* [删除健康记录](#section51464710234)（[deleteHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section10688164519573)）
* [修改健康记录](#section323582032316)（[updateHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section525520514574)）
* [查询健康记录](#section117913110232)（[getHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section17136185616578)）

![](https://media:901788166628968649)  
应用在操作健康记录前，需先确认是否已拥有健康记录数据操作权限，数据类型及所需权限，请参见[健康记录数据类型](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sleep-record-0000001135051288)。

<br />

#### 写入健康记录

1. 创建一个指定采集器、时间段、健康数据统计信息、健康数据明细信息和其他必要信息的HealthRecord。

   <br />

   ![](https://media:901788166628998650)  
   插入的健康记录的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。

   <br />

2. 使用[HealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-healthrecord-0000001256528953)创建一个[HealthRecordInsertOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-health-record-insert-options-0000001229884275)。
3. 调用[addHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section13164153916570)方法将[HealthRecordInsertOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-health-record-insert-options-0000001229884275)插入Health Service Kit。

   <br />

   [addHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section13164153916570)方法的回调中的HealthRecordId需要被妥善保存，以便后期[修改Health Service Kit中的健康记录](#section323582032316)或者[删除Health Service Kit中的健康记录](#section51464710234)使用。

   ```
   import {HMSHealthKit, HMSHealthKitDataType, HMSHealthKitDeviceType, DeviceInfo, DataCollector, Value, SamplePoint, SampleSet, HealthRecord, HealthRecordInsertOptions} from '@hw-hmscore/hms-js-health'
   // 步骤1：创建一个指定采集器、时间段、健康数据统计信息、健康数据明细信息和其他必要信息的HealthRecord。
   // 根据设备生产商、设备模型编号、设备uuid、设备类型构造设备信息
   let deviceInfo = new DeviceInfo("manufacturer", "modelName", "uuid", HMSHealthKitDeviceType.TYPE_PHONE);
   // 根据设备信息、应用包名、数据类型构造数据采集器
   let healthRecordDataCollector = new DataCollector(deviceInfo, "com.health.demo", HMSHealthKitDataType.DT_HEALTH_RECORD_TACHYCARDIA);

   // fieldMap的值
   const values = []
   values.push(new Value("threshold", "120"));
   values.push(new Value("avg_heart_rate", "120"));
   values.push(new Value("max_heart_rate", "140"));
   values.push(new Value("min_heart_rate", "100"));

   // 创建心率统计数据源
   let summaryDataCollector = new DataCollector(deviceInfo, "com.health.demo", HMSHealthKitDataType.POLYMERIZE_CONTINUOUS_HEART_RATE_STATISTICS);
   // 设置心率统计值
   let summaryValues = [];
   summaryValues.push(new Value("avg", 100));
   summaryValues.push(new Value("max", 120));
   summaryValues.push(new Value("min", 60));
   summaryValues.push(new Value("last", 80));
   let summarySamplePoints = [];
   summarySamplePoints.push(new SamplePoint(summaryValues, 1624774020000, 1624774320000, "here is customized text"));
   let summarySampleSets = [];
   summarySampleSets.push(new SampleSet(summaryDataCollector, summarySamplePoints));
   // 创建心率明细数据源
   let detailsDataCollector = new DataCollector(deviceInfo, "com.health.demo", HMSHealthKitDataType.DT_INSTANTANEOUS_HEART_RATE);
   // 设置心率明细数据值
   let detailValues = [];
   detailValues.push(new Value("bpm", 110));
   let detailSamplePoints = []
   detailSamplePoints.push(new SamplePoint(detailValues, 1624774020000, 1624774320000, "here is customized text"));
   let detailSampleSets = [];
   detailSampleSets.push(new SampleSet(detailsDataCollector, detailSamplePoints));
   // 基于时间等参数创建健康记录
   let healthrecord = new HealthRecord(1624774020000, 1624774320000, healthRecordDataCollector, values, "here is customized text", summarySampleSets, detailSampleSets);
   // 步骤2：使用HealthRecord创建一个HealthRecordInsertOptions
   // 创建健康记录等参数创建插入健康记录参数
   let healthRecordInsertOptions = new HealthRecordInsertOptions(healthrecord);
   // 步骤3：调用addHealthRecord方法将HealthRecordInsertOptions插入Health Service Kit
   HMSHealthKit.addHealthRecord(healthRecordInsertOptions).then((result) => {
       // 调用成功
       console.info("addHealthRecord success: " + JSON.stringify(result))
       // 成功回调中的HealthRecordId需要被妥善保存，以便后期修改Health Service Kit中的健康记录或者删除Health Service Kit中的健康记录使用。
       this.healthRecordId = result.data;
   }).catch((error) => {
       // 调用失败
       console.error("addHealthRecord fail: " + JSON.stringify(error));
   })
   ```

#### 删除健康记录

1. 根据healthRecordIds或起止时间及数据类型创建一个[HealthRecordDeleteOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-health-record-delete-options-0000001184446080)。

   <br />

   ![](https://media:901788166629025651)  
   1. 删除的运动健康数据的健康记录数据的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。
   2. 删除运动记录数据时，若healthRecordIds不为空则根据healthRecordIds删除，否则根据健康记录数据类型及起止时间删除。

   <br />

2. 调用[deleteHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section10688164519573)方法，将满足[HealthRecordDeleteOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-health-record-delete-options-0000001184446080)参数的健康记录从Health Service Kit中删除 。

   <br />

   删除Health Service Kit的健康记录示例代码如下：

   ```
   import {HMSHealthKit, HMSHealthKitDataType, HealthRecordDeleteOptions} from '@hw-hmscore/hms-js-health'
   // 步骤1：创建一个HealthRecordDeleteOptions
   const subDataTypes = []
   // 设置关联删除的详情数据类型
   subDataTypes.push(HMSHealthKitDataType.DT_INSTANTANEOUS_HEART_RATE)

   const healthRecordIds = []
   // 此处填写的healthRecordId为写入健康记录成功回调中保存的信息
   healthRecordIds.push(this.healthRecordId)
   // 基于起止时间、健康记录数据类型、关联删除详情数据类型列表、健康记录id、是否关联删除健康记录关联的详情数据等参数创建删除健康记录参数
   let deleteOption = new HealthRecordDeleteOptions("1624774010000", "1624774330000", HMSHealthKitDataType.DT_HEALTH_RECORD_TACHYCARDIA, subDataTypes, healthRecordIds, "true")
   // 步骤2：调用deleteHealthRecord方法
   HMSHealthKit.deleteHealthRecord(deleteOption).then((result) => {
       // 调用成功
       console.info("deleteHealthRecord success: " + JSON.stringify(result))
   }).catch((error) => {
       // 调用失败
       console.error("deleteHealthRecord error: " + JSON.stringify(error));
   })
   ```

#### 修改健康记录

![](https://media:901788166629058652)  
1. 插入的健康记录的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。

2. 如果想要通过HealthRecordId修改的健康记录不存在，会抛出[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560#section10673269124)：HEALTH_RECORDS_NOT_EXIST。

1. 创建一个指定采集器、时间段、健康数据统计信息、健康数据明细信息和其他必要信息的HealthRecord。
2. 使用HealthRecord和[插入HealthRecord](#section83541252102214)回调中的HealthRecordId，创建一个[HealthRecordUpdateOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-health-record-update-options-0000001184764554)。
3. 调用[updateHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section525520514574)方法修改Health Service Kit中的健康记录及相关数据。

   <br />

   修改Health Service Kit的健康记录示例代码如下：

   ```
   import {HMSHealthKit, HMSHealthKitDataType, HMSHealthKitDeviceType, DeviceInfo, DataCollector, Value, SamplePoint, SampleSet, HealthRecord, HealthRecordUpdateOptions} from '@hw-hmscore/hms-js-health'
   // 步骤1：创建一个指定采集器、时间段、健康数据统计信息、健康数据明细信息和其他必要信息的HealthRecord
   // 根据设备生产商、设备模型编号、设备uuid、设备类型构造设备信息
   let deviceInfo = new DeviceInfo("manufacturer", "modelName", "uuid", HMSHealthKitDeviceType.TYPE_PHONE);
   // 根据设备信息、应用包名、数据类型构造数据采集器
   let healthRecordDataCollector = new DataCollector(deviceInfo, "com.health.demo", HMSHealthKitDataType.DT_HEALTH_RECORD_TACHYCARDIA);

   // fieldMap的值
   const values = []
   values.push(new Value("threshold", "130"));
   values.push(new Value("avg_heart_rate", "130"));
   values.push(new Value("max_heart_rate", "150"));
   values.push(new Value("min_heart_rate", "110"));

   // 创建心率统计数据源
   let summaryDataCollector = new DataCollector(deviceInfo, "com.health.demo", HMSHealthKitDataType.POLYMERIZE_CONTINUOUS_HEART_RATE_STATISTICS);
   // 设置心率统计值
   let summaryValues = [];
   summaryValues.push(new Value("avg", 100));
   summaryValues.push(new Value("max", 120));
   summaryValues.push(new Value("min", 60));
   summaryValues.push(new Value("last", 80));
   let summarySamplePoints = [];
   summarySamplePoints.push(new SamplePoint(summaryValues, 1624774020000, 1624774320000, "here is customized text"));
   let summarySampleSets = [];
   summarySampleSets.push(new SampleSet(summaryDataCollector, summarySamplePoints));

   // 创建心率明细数据源
   let detailsDataCollector = new DataCollector(deviceInfo, "com.health.demo", HMSHealthKitDataType.DT_INSTANTANEOUS_HEART_RATE);
   // 设置心率明细数据值
   let detailValues = [];
   detailValues.push(new Value("bpm", 120));
   let detailSamplePoints = []
   detailSamplePoints.push(new SamplePoint(detailValues, 1624774020000, 1624774320000, "here is customized text"));
   let detailSampleSets = [];
   detailSampleSets.push(new SampleSet(detailsDataCollector, detailSamplePoints));
   // 基于时间等参数创建健康记录
   let healthrecord = new HealthRecord(1624774020000, 1624774320000, healthRecordDataCollector, values, "here is customized text", summarySampleSets, detailSampleSets);
   // 步骤2：创建一个HealthRecordUpdateOptions
   // 注意这里的this.healthRecordId为写入健康记录成功回调中保存的信息。
   let healthRecordUpdateOptions = new HealthRecordUpdateOptions(healthrecord, this.healthRecordId);
   // 步骤3：调用updateHealthRecord方法修改Health Service Kit中的健康记录
   HMSHealthKit.updateHealthRecord(healthRecordUpdateOptions).then((result) => {
       // 调用成功
       console.info("updateHealthRecord success: " + JSON.stringify(result))
   }).catch((error) => {
       // 调用失败
       console.error("updateHealthRecord fail: " + JSON.stringify(error));
   })
   ```

#### 查询健康记录

![](https://media:901788166629083653)  
1. 调用查询运动健康数据接口，接口参数中的起止时间均需大于2014年1月1号对应的UNIX时间戳。
2. 调用查询运动健康数据的健康记录数据接口，接口参数中的开始时间和结束时间之间的时间跨度不允许超过10天。

1. 应用需先确认是否已拥有健康记录数据操作权限，数据类型详见[健康记录数据类型](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sleep-record-0000001135051288)。
2. 根据查询时间和相关条件，创建一个[HealthRecordReadOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-health-record-read-options-0000001184604636)。
3. 使用[getHealthRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-health-records-0000001232134027#section17136185616578)方法查询Health Service Kit中存储的健康记录相关数据。

   <br />

   查询Health Service Kit的健康记录示例代码如下：

   ```
   import {HMSHealthKit, DeviceInfo, DataCollector, HMSHealthKitDeviceType, HMSHealthKitDataType, HealthRecordReadOptions} from '@hw-hmscore/hms-js-health'
   // 步骤2：根据查询时间和相关条件，创建一个HealthRecordReadOptions
   // 根据设备生产商、设备模型编号、设备uuid、设备类型构造设备信息
   let deviceInfo = new DeviceInfo("manufacturer", "modelName", "uuid", HMSHealthKitDeviceType.TYPE_PHONE);
   // 根据设备信息、应用包名、数据类型构造数据采集器
   let healthRecordDataCollector = new DataCollector(deviceInfo, "com.health.demo", HMSHealthKitDataType.DT_HEALTH_RECORD_TACHYCARDIA);

   let subDataTypeList = [];
   // 设置关联查询的心率详情数据
   subDataTypeList.push(HMSHealthKitDataType.DT_INSTANTANEOUS_HEART_RATE);

   // 基于时间等参数创建健康记录读取参数
   let healthRecordReadOptions = new HealthRecordReadOptions("1624774020000", "1624774320000", healthRecordDataCollector, HMSHealthKitDataType.DT_HEALTH_RECORD_TACHYCARDIA, subDataTypeList);
   // 步骤3：使用getHealthRecord方法查询Health Service Kit中存储的健康记录相关数据
   HMSHealthKit.getHealthRecord(healthRecordReadOptions).then((result) => {
       // 调用成功
       console.info("getHealthRecord success: " + JSON.stringify(result))
   }).catch((error) => {
       // 调用失败
       console.error("getHealthRecord fail: " + JSON.stringify(error));
   })
   ```
