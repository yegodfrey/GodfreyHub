# 开发准备

## 前提条件

* 请参考[3.6.4.1 申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050747587)完成账号申请。
* 请参考[3.6.4.2 申请Health Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-kitservice-0000001050707556)完成服务申请。

## 操作步骤

1. 在账号服务应用详情页的**"** 回调地址**"** 输入框中补充回调地址：https://h5hosting.dbankcdn.com/cch5/healthkit/oauth-h5/oauth-callback.html，修改办法参考下图。回调地址支持配置多个，如应用中已配置您应用的回调地址，请继续保留**。**

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/MAwkYy4BQtOmsBZZ6WX0Wg/zh-cn_image_0000002516359262.png?HW-CC-KV=V1&HW-CC-Date=20260909T154650Z&HW-CC-Expire=31536000000&HW-CC-Sign=25BA8AD51B076F3A9BAA4A56002CA993AB2D84B5959C6B23240F0AFE80389FA4 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/CnRxXh03RdCkVjsUYBnhBQ/zh-cn_image_0000002547959071.png?HW-CC-KV=V1&HW-CC-Date=20260909T154650Z&HW-CC-Expire=31536000000&HW-CC-Sign=039DEFF646AFEFEB3AAD31DA58DFD97548100A438A1126CFBED0E5BF9C1E7589 "点击放大")

2. 在Health Service Kit服务应用详情页的**"** 其他权限**"**处，根据三方应用实际开放区域勾选即可申请免登录授权权限。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/x0o0G1u2TSutVF_SW912uQ/zh-cn_image_0000002516359264.png?HW-CC-KV=V1&HW-CC-Date=20260909T154650Z&HW-CC-Expire=31536000000&HW-CC-Sign=91DFCF54A52ACBB342A2057CC37ED734BF88E7A753DCA17DA647D00F57E4652C "点击放大")

3. 在Health Service Kit服务应用详情页的**"** 应用scheme地址**"**输入框中填写DeepLink链接，应用Scheme地址支持配置多个，如应用中已配置您应用的DeepLink地址，请继续保留。此处填写的DeepLink地址是三方应用授权成功后通过该地址把授权码返回给您的应用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/yVdzzAlMTgalukm53MeHng/zh-cn_image_0000002516359266.png?HW-CC-KV=V1&HW-CC-Date=20260909T154650Z&HW-CC-Expire=31536000000&HW-CC-Sign=A46FA23F36D2DFB86A24AF5EC5BDD95F35B617A8F94A84EF826BE545A39B9FA9 "点击放大")

## 后续操作

* 请参考[3.7.2.1.4.3 集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/integrating-sdk-0000001050069724)在开发前完成集成。
* 编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。请参考[3.7.2.1.4.4 配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-obfuscation-scripts-0000001050071675)完成配置。
* 请参考[3.7.2.1.4.5 导入证书指纹、修改包名、配置JDK编译版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/change-0000001050170085)完成证书导入、包名配置以及JDK编译版本配置。
