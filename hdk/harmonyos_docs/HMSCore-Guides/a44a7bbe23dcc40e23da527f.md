# 开发准备

## 前提条件

* 请参考[3.6.4.1 申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050747587)完成账号申请。
* 请参考[3.6.4.2 申请Health Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-kitservice-0000001050707556)完成服务申请。

## 操作步骤

1. 在账号服务应用详情页的**"** 回调地址**"** 输入框中补充回调地址：https://h5hosting.dbankcdn.com/cch5/healthkit/oauth-h5/oauth-callback.html，修改办法参考下图。回调地址支持配置多个，如应用中已配置您应用的回调地址，请继续保留**。**

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8f/v3/MAwkYy4BQtOmsBZZ6WX0Wg/zh-cn_image_0000002516359262.png?HW-CC-KV=V1&HW-CC-Date=20261008T164552Z&HW-CC-Expire=31536000000&HW-CC-Sign=2169D2181F310A3EE23678C5F851DCB826EA746E1F4D3C7F43A735217E8E56BA "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/CnRxXh03RdCkVjsUYBnhBQ/zh-cn_image_0000002547959071.png?HW-CC-KV=V1&HW-CC-Date=20261008T164552Z&HW-CC-Expire=31536000000&HW-CC-Sign=5F33E406C39464BA017DE2474E9DFBEC13F2B9ED7A60709907338F2CC0E5526A "点击放大")

2. 在Health Service Kit服务应用详情页的**"** 其他权限**"**处，根据三方应用实际开放区域勾选即可申请免登录授权权限。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/x0o0G1u2TSutVF_SW912uQ/zh-cn_image_0000002516359264.png?HW-CC-KV=V1&HW-CC-Date=20261008T164552Z&HW-CC-Expire=31536000000&HW-CC-Sign=B38DF5AA67085EC0476B26C7C8D7361EE813ACF7DA25DB30E44AE037CDE7DC0A "点击放大")

3. 在Health Service Kit服务应用详情页的**"** 应用scheme地址**"**输入框中填写DeepLink链接，应用Scheme地址支持配置多个，如应用中已配置您应用的DeepLink地址，请继续保留。此处填写的DeepLink地址是三方应用授权成功后通过该地址把授权码返回给您的应用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ad/v3/yVdzzAlMTgalukm53MeHng/zh-cn_image_0000002516359266.png?HW-CC-KV=V1&HW-CC-Date=20261008T164552Z&HW-CC-Expire=31536000000&HW-CC-Sign=5F50224D685F1C8B77EE47EF8FFD3B5A671DF2C2CE876D70D7BEE49260B1CA36 "点击放大")

## 后续操作

* 请参考[3.7.2.1.4.3 集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/integrating-sdk-0000001050069724)在开发前完成集成。
* 编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。请参考[3.7.2.1.4.4 配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-obfuscation-scripts-0000001050071675)完成配置。
* 请参考[3.7.2.1.4.5 导入证书指纹、修改包名、配置JDK编译版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/change-0000001050170085)完成证书导入、包名配置以及JDK编译版本配置。
