# 查询每日活动量

查询华为运动健康App中用户每日活动量，包含步数统计、步数详情、距离、热量及运动中高强度。

这部分数据来源于手机或华为穿戴设备记录统计的用户每日活动数据。  
![](https://media:901788166645443011)  
可以查询统计数据和详情数据：

* 统计数据包括：步数、距离、热量及运动中高强度
  * 若查询的是历史数据，则为每日总数。
  * 若查询的是当天数据，则为当日0点到当前时间的总数。
  * 距离、热量及运动中高强度仅支持查询每日活动量总数。

<!-- -->

* 详情数据包括：步数详情
* 只能查询最近7天内的历史数据，返回每分钟步数详情（不包含0值）。

#### 使用 execQuery 接口查询用户每日活动量

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [execQuery](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__execQuery-android_content_Context-com_huawei_hihealthkit_HiHealthDataQuery-int-com_huawei_hihealth_listener_ResultCallback-) 方法，查询用户每日活动量。
2. 通过请求参数 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451) 对象，返回查询结果。

   <br />

   ![](https://media:901788166645506014)  
   HiHealthDataQuery 和 HiHealthDataQueryOption 导包时，请选择 com.huawei.hihealthkit。

   示例代码：步数统计为例

   ```
   int timeout = 0;
   // 查询当天步数
   Calendar currentDate = Calendar.getInstance();
   currentDate.set(Calendar.HOUR_OF_DAY, 0);
   currentDate.set(Calendar.MINUTE, 0);
   currentDate.set(Calendar.SECOND, 0);
   long startTime = currentDate.getTimeInMillis();
   long endTime = System.currentTimeMillis();
   // 查询步数
   HiHealthDataQuery hiHealthDataQuery = new HiHealthDataQuery(HiHealthPointType.DATA_POINT_STEP_SUM, startTime,
       endTime, new HiHealthDataQueryOption());
   HiHealthDataStore.execQuery(context, hiHealthDataQuery, timeout, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object data) {
           Log.i(TAG, "query steps resultCode: " + resultCode);
           if (resultCode == HiHealthError.SUCCESS && data instanceof List) {                             
               List dataList = (ArrayList) data;
               for (Object obj : dataList) {
                   HiHealthPointData pointData = (HiHealthPointData) obj;
                   Log.i(TAG, "start time : " + pointData.getStartTime());
                   Log.i(TAG, "query steps : " + String.valueOf(pointData.getValue()));
               }
           } else if (resultCode == HiHealthError.PARAM_INVALID) {
               // 参数错误
               Log.w(TAG, "Param invalid");
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
               // 授权失效
               Log.w(TAG, "Permission denied");
           } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
               // 未同意运动健康隐私协议
               Log.w(TAG, "Privacy user denied");
           } else if (resultCode == HiHealthError.ERR_NETWORK) {
               // 网络异常
               Log.w(TAG, "Network request failed");
           } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
               // 测试权限的用户数量超过限制
               Log.w(TAG, "Beta scope permission denied");
           } else {
               // 其他错误，建议提示调用失败
               Log.w(TAG, "Other error, invoking method failed");
           }
       }
   });
   ```

#### 使用 getCount 接口查询用户每日活动量数据的条目

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [getCount](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__getCount-android_content_Context-com_huawei_hihealthkit_HiHealthDataQuery-com_huawei_hihealth_listener_ResultCallback-) 方法，查询用户每日活动量数据的条目。
2. 通过请求参数 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451) 对象，返回查询结果。

   <br />

   示例代码：步数统计为例

   ```
   long endTime = System.currentTimeMillis();
   // 查询时间范围:30 天
   long startTime = endTime - 1000 * 60 * 60 * 24 * 30L;
   // 查询步数
   HiHealthDataQuery hiHealthDataQuery = new HiHealthDataQuery(HiHealthPointType.DATA_POINT_STEP_SUM, startTime,
       endTime, new HiHealthDataQueryOption());
   HiHealthDataStore.getCount(context, hiHealthDataQuery, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object data) {
           Log.i(TAG, "query steps count resultCode: " + resultCode);
           if (resultCode == HiHealthError.SUCCESS) {
               if (data != null) {
                   int count = (int) data;
                   Log.i(TAG, "query steps count: " + count);
               }
           } else if (resultCode == HiHealthError.PARAM_INVALID) {
               // 参数错误
               Log.w(TAG, "Param invalid");
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
               // 授权失效
               Log.w(TAG, "Permission denied");
           } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
               // 未同意运动健康隐私协议
               Log.w(TAG, "Privacy user denied");
           } else if (resultCode == HiHealthError.ERR_NETWORK) {
               // 网络异常
               Log.w(TAG, "Network request failed");
           } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
               // 测试权限的用户数量超过限制
               Log.w(TAG, "Beta scope permission denied");
           } else {
               // 其他错误，建议提示调用失败
               Log.w(TAG, "Other error, invoking method failed");
           }
       }
   });
   ```

   |参数名称|参数类型|参数描述|可选选项|
   |:----------------|:----------------|:---|:----|
   |hiHealthDataQuery|HiHealthDataQuery|查询条件|必选(M)|
