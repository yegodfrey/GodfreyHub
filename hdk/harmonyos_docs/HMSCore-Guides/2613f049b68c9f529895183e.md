# 显示定位

增强版地图Android SDK，提供了原生定位能力。如果需要使用高精定位能力，请参见以下步骤集成华为定位SDK作为定位源实现高精定位功能。

在打开定位点显示开关前，需要为地图设置定位源（[LocationSource](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationsource-0000001050150264)），定位源可为定位点提供要放置的位置。

1. 实现[LocationSource](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/locationsource-0000001050150264)。  
   示例代码如下：

   ```
   "Java"
   private LocationSource.OnLocationChangedListener mLocationChangedListener;
   LocationSource hwLocationSource = new LocationSource() {
       @Override
       public void activate(LocationSource.OnLocationChangedListener listener) {
           mLocationChangedListener = listener;
       }
       @Override
       public void deactivate() {
           mLocationChangedListener = null;
       }
   };
   ```

   ```
   "Kotlin"
   var mLocationChangedListener: LocationSource.OnLocationChangedListener? = null
       var hwLocationSource: LocationSource = object : LocationSource {
       override fun activate(listener: LocationSource.OnLocationChangedListener) {
           mLocationChangedListener = listener
       }
       override fun deactivate() {
           mLocationChangedListener = null
       }
   }
   ```

2. 设置定位源并打开位置显示开关。  
   示例代码如下：

   ```
   "Java"
   hwMap.setLocationSource(hwLocationSource);
   hwMap.setMyLocationEnabled(true);
   ```

   ```
   "Kotlin"
   hMap.setLocationSource(hwLocationSource)
   hMap.isMyLocationEnabled = true
   ```
