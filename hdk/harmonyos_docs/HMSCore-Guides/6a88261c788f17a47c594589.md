# 快速接入

## 接入流程

商户支付接入流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/-8LuJFhnTB2l9gJK-BEcCQ/zh-cn_image_0000002480319974.png?HW-CC-KV=V1&HW-CC-Date=20260910T132632Z&HW-CC-Expire=31536000000&HW-CC-Sign=CEDAA62995841401CAACAE14416AEC5A4670A1297402A14DFF227196AD33E9EB)

1. 用户发起购买后，商户APP向商户服务器发起请求，创建合单支付订单。
2. 商户服务器请求华为支付服务器的[APP预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-combined-app-prepay-0000001622395644)接口，获取到预下单号（prepayId）。
3. 商户服务器获取到prepayId后，需要组参[orderStr](#ZH-CN_TOPIC_0000002512279617__li2127133183016)返回给商户客户端。除sign外，其他字段都需要使用商户私钥签名并赋值给sign。
4. 商户APP调用[combinedPay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142#section149681049348)接口调起华为支付服务收银台，完成支付。
5. 支付成功后，华为支付服务器会调用商户入参的callbackUrl接口，返回支付结果给商户服务器；支付失败场景可能不会有支付结果回调通知。
6. 商户服务器收到支付结果回调响应后，使用SM2验签方式对支付结果进行验签。

> 说明
>
> 支付是否成功可以通过回调通知中的orderStatus的返回状态判断：
>
> * TRX_SUCCESS：交易成功
> * TRX_FAILED：交易失败

## 客户端开发

* **获取orderStr接口入参**

商户服务器通过调用[APP预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-combined-app-prepay-0000001622395644)获取预支付ID（prepayId）后商户服务器需要构建orderStr返回给客户端。

orderStr参数说明

|**参数**|**参数类型**|**是否必填**|**描述**|
|:--------|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|app_id|String|否|应用ID。|
|merc_no|String|是|商户号|
|prepay_id|String|是|预下单id，使用预下单请求生成，有效期2小时。|
|timestamp|String|是|当前时间戳，标准北京时间，时区为东八区，自1970年1月1日 0点0分0秒以来的毫秒数，13位。示例值：1666230721315|
|noncestr|String|是|随机字符串，不长于32位。推荐随机数生成算法。 每笔订单都需要重新生成。|
|sign|String|是|签名，使用除了sign字段以外的其他字段计算签名值。可参考[签名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-signature-rule-0000001538533912#section272163402611)章节|
|auth_id|String|是|开放平台分配的鉴权id，一个商户可配置多套证书，请妥善保管|

* **调起支付收银台**

首先要获取[AggrPayClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142)对象，通过[AggrPayClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142)对象去调用支付接口[combinedPay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142#section149681049348)，代码示例如下：

```screen
String orderStr = "{\"merc_no\":\"***\",\"prepay_id\":\"1230331185102089244382635044\",\"timestamp\":\"1680259863114\",\"noncestr\":\"1487b8a60ed9f9ecc0ba759fbec23f4f\",\"sign\":\"****\",\"auth_id\":\"***\"}";
Runnable runnable = () -> {
    AggrPayClient client = Pay.getPayClient(activity);
    PayResult result = client.combinedPay(orderStr);
    handler.post(() -> {
         // 支付完成结果处理和界面刷新跳转等操作。返回示例见下表
    });
};
Thread payThread = new Thread(runnable);
payThread.start();
```

> 注意
>
> 支付接口需要在线程中调用

* **支付结果获取和处理**

1. 调用[combinedPay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-aggrpay-client-0000001537864142#section149681049348)接口后同步返回支付结果[PayResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/aggrpay-entity-pay-result-0000001588233533)，通过Handler发送消息在主线程处理支付结果。

   |参数|类型|描述|参考示例|
   |:---------|:-----|:----|:-------------------------------------------------------------------------------------------------------------------------------|
   |returnCode|string|返回状态码|"0"：表示成功，具体返回参考[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-client-error-code-0000001538150100)|
   |returnMsg|string|返回描述|"success"：表示签约成功|

2. 商户在构建[APP预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-combined-app-prepay-0000001622395644)请求参数时，传入了一个callbackUrl。在华为支付服务器完成支付后，将以post方式调用callbackUrl，将支付结果返回给商户服务器。

> 注意
>
> **若支付成功,建议以服务器接收到的结果通知或者查询API返回为准。**
