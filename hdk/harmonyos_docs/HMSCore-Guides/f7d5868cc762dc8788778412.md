# 埋点开发

## 功能概述

分析服务为您提供了多种行业（游戏、教育、电商、运动健康、房产、汽车、金融理财、出行旅游和通用）的埋点方案模板及代码样例。发挥代码埋点和可视化埋点互补功能，覆盖更多埋点场景，您可以选择任意一种方式进行埋点。代码埋点控制精准，使用者可以方便地设置自定义属性、自定义事件，传递丰富的数据到华为分析；可视化埋点界面操作简易明了，为运营人员埋点操作提供便捷。

## 典型应用场景

* 简化埋点场景，将较为复杂的埋点场景精简成以行业为主题的系列埋点方案模板，支持多种行业埋点方案。
* 支持跨行业埋点，选中一个行业进行埋点，当行业埋点事件不满足需求时可选择其他行业的模板进行添加并埋点。
* 双效埋点，提供代码埋点和可视化埋点两种埋点方式，可视化埋点与代码埋点场景互补，解决埋点场景覆盖问题。

## 使用限制

* 部分埋点无法通过点击页面元素去埋点，可视化埋点无法解决此类问题，需要通过代码进行埋点。
* 可视化埋点支持Android、iOS、Web应用。
* 可视化埋点前请确认您在App中已集成动态标签管理（Dynamic Tag Manager，以下简称"DTM"） SDK 5.3.0或以上版本，Android应用请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-sdk-0000001050041968)，iOS应用请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-sdk-0000001061753701)，Web应用请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/web-sdk-0000001150331734)。
