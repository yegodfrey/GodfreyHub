# 使用入门

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-:|:--------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-preparations-0000001168761025)|在开发应用前，需要完成的步骤：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-preparations-0000001168761025#section47264296)、[创建项目](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-preparations-0000001168761025#section166771423181511)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-preparations-0000001168761025#section294363472920)。 如果您已经在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站创建了应用，可跳过本步骤。|
|2|[网络定位（API）开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-network-location-develop-steps-0000001122001226)|接口实现了定位请求功能，提供HTTPS接口。提供了室内定位、室外定位。|
|2|[IP定位（API）开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/server-ip-location-develop-steps-0000001226969155)|提供了IP定位能力，通过用户IP获取其所属国家，省份，城市以及城市中心的经纬度信息。|
