# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/GameKit)快速体验一个应用的开发过程。  

#### 开发环境

* [Android Studio 3.X](https://developer.android.com/studio)及以上版本
* 测试应用的设备：EMUI 10.1及以上的华为手机  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/gamekit-agc-preparations-0000001126745481)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：创建应用、生成签名证书指纹、配置签名证书指纹、打开相关服务。|
|2|[集成GameTurbo Engine](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/gamekit-integration-android-studio-0000001052153116)|在开发应用前，您需要将GameTurbo Engine集成到您的开发环境中。|
|3|[权限申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/gamekit-permission-request-0000001051753076)|基于安全考虑，您使用GameTurbo Engine相关接口需要向华为方申请对应权限。|
