# 静息热量

## 静息热量

安静状态下维持身体每天基础生理活动所消耗的能量，包含基础代谢以及精神活动、食物消化、准静止状态下肌肉活动等产生的能量消耗，受活动影响而变化，通常比基础代谢高20%左右。

### OAuth权限

联盟卡片申请的权限名称：日常活动> 热量数据

* 读权限：https://www.huawei.com/healthkit/calories.read
* 写权限：暂不支持数据写入

### 原子采样明细数据类型

* 名称：com.huawei.resting_calories

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:-------|:---|:-----|:----|:-|:------------------------------------------------------------------------|
|calories|静息热量|float|M|千卡|1秒区间：(0, 0.555555555555556) 1分钟区间：(0, 33.333333333333333) 1小时区间：(0, 2000]|

### 数据开放说明

静息热量明细数据来源于手机或者穿戴设备，**当前版本不支持明细数据开放**。

### 原子采样统计数据类型

* 名称：com.huawei.resting_calories.statistics

|**字段列表**|描述|**类型**|可选/必选|**单位**|
|:----------------|:-----------|:-----|:----|:-----|
|predictedCalories|静息热量预估总值|float|O|千卡|
|totalCalories|当前累计消耗的静息热量值|float|M|千卡|

### 数据开放说明

|开放API|查询及时性|统计数据维度|数据源|
|:--------------------------------------------------------------------------------------------------------------------|:----|:------------|:--------|
|[多日统计查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/sampleset_daily_polymerize-0000001078113560)|小时级|采样数据按照自然日进行统计|手机、手表、手环等|

暂不支持数据订阅功能。
