# 地图属性

通过[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)提供的方法自定义地图属性，修改地图中心点、缩放系数以及地图朝向等。例如修改地图中心点：

```screen
<tr>
    <td>Latitude:</td>
    <td><input id="latInput" type="text" value="48.95"/></td>
</tr>
<tr>
    <td>Longitude:</td>
    <td><input id="lngInput" type="text" value="2.35"/></td>
</tr>

var lat = Number(document.getElementById("latInput").value);
var lng = Number(document.getElementById("lngInput").value);
map.setCenter({lat: lat, lng: lng});
```

地图的以下属性支持自定义，具体请参见[HWMap方法](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165#section173112931512)。

|**属性**|**含义**|
|:------------------|:------------------|
|setCenter(latlng)|设置地图中心点坐标。|
|setHeading(heading)|设置地图朝向，即地图与正北方向的夹角。|
|setOpacity(opacity)|设置地图透明度。|
|setTitle(title)|设置地图所在容器的提示信息。|
|setZoom(zoom)|设置地图缩放级别。|
|zoomOut()|地图缩小一个级别。|
|zoomIn()|地图放大一个级别。|
