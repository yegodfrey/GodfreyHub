# 配置Manifest文件

1. 在您的项目中创建一个新的"service"并继承[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839)类，用于[接收透传消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-basic-receivemsg-0000001087370610#section1021703451115)、[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-client-dev-0000001050042041#section876955375919)。此处以"DemoHmsMessageService"类为例。

   ```screen
   ...
   import com.huawei.hms.push.HmsMessageService;
   ...
   public class DemoHmsMessageService extends HmsMessageService {
       ...
   }
   ```

2. 在"AndroidManifest.xml"文件的"application"标签中找到您上一步定义的"service"，在"intent-filter"标签中传入推送服务的"action"值，如下所示。

   ```screen
   <manifest ...>
       ...
       <application ...>
         <service android:name=".DemoHmsMessageService" android:exported="false">
   <intent-filter>
   <action android:name="com.huawei.push.action.MESSAGING_EVENT"/>
   </intent-filter>
   </service>
       </application>
       ...
   </manifest>
   ```

   > 说明
   > * exported属性需要设置为**false**，限制其他应用的组件唤醒该service。
   > * 请确保仅定义了一个继承[HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839)类的"service"。
   > * 当设备开机或重启后但用户尚未解锁设备时，若定义的"service"未配置"直接启动"模式，在您发送透传消息时会无法拉起透传服务。此时，需要您在定义的"service"中添加如下配置：
   >
   >   ```screen
   >   <manifest ...>
   >       ...
   >       <application ...>
   >           <service 
   >               ...
   >   android:directBootAware="true"
   >               ...>
   >           </service>
   >       </application>
   >       ...
   >   </manifest>
   >   ```
