# 应用购买记录相关支付订单查询

当您想查询指定48小时或者48小时内购买记录相关的付款和退款订单时，可以调用该接口查询。

具体实现请参见[应用购买记录相关支付订单查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-application-query-orderinfo-0000001431190629)。
> 说明
>
> 由于当天的实时订单信息还有可能变化，因此不建议使用此接口查询当天的实时订单数据，建议延迟一天查询。
