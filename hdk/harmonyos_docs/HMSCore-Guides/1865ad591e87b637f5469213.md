# 使用入门

#### 快应用介绍

快应用是一种新型免安装应用。具有以下优点：

                * 成本低，使用相对简单的js和css开发语言，所需代码量仅占安卓原生应用的1/5。 
                * 体验好，采用原生渲染技术，具备安卓原生应用的功能和体验，同时具备自动更新、占用内存少的便捷特点。 
                * 留存高，无需安装，即点即用，并可添加到桌面。具有统一行业标准，可跨手机品牌完成社交无缝传播。 

更多快应用相关介绍请参见[快应用简介](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-introduction-0000001126786237)。

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAnalyticsKit-QuickApp)快速体验一个应用的开发过程。

#### 开发环境

                * 华为快应用 IDE v3.1.1及以上。 
                * 包管理工具npm，运行环境Node.js。 
                * 一台安卓手机。 

#### 开发流程

您需要按照如下流程完成应用的开发工作。

开发步骤 | 说明  
---|---  
[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-config-agc-0000001077770540) | 在开发应用前，需要在AppGallery Connect中配置相关信息，包括：注册成为开发者、创建应用、开通华为分析服务。  
[_集成SDK_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-integrating-sdk-0000001090944199) | 通过本地或者远程方式集成SDK包。  
[_接入Analytics_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-accessing-0000001090739247) | 参见[ _API参考_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-huawei-analytics-overview-0000001091099897)中的API，实现数据上报功能。
