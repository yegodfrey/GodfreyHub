# 一碰联功能测试

1. 在手机上下载并安装最新版华为运动健康App。打开运动健康App，扫描设备上的[二维码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/label-0000001054823025)连接设备。或者打开手机的蓝牙及 NFC，用手机 NFC 部位碰一碰设备上的 [NFC 标签](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/label-0000001054823025#section334711645511)，连接设备。

   <br />

   ![](https://media:901788166620330531 "点击放大")

   <br />

2. 从开发套件中获取设备的功能测试用例。按照测试用例进行测试， 确保所有的用例正常测试通过。
