# 运动健康

#### 事件参数列表

              * kHAEventRegisterAccount

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRegistMethod | 用户来源 | String | 可选 | 用户来源。  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
kHAParamInviter | 邀请人 | String | 可选 | 邀请该用户进行注册的用户。  
  
              * kHAEventBindAccount

用户绑定其他类型帐号时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---
