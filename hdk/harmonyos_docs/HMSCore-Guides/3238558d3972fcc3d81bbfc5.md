# Client Libraries

位置服务（Site Kit）以Client Libraries形式为您提供一套全面的位置服务接口，帮助您快速集成位置服务能力。Client Libraries当前支持Java Client、Python Client、Go Client、JavaScript Client等多种客户端库，在[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0.html)授权许可下开源。GitHub上提供了安装说明与示例代码，您可前往GitHub下载并使用Client Libraries：

* [Go Client for map services](https://github.com/huaweicodelabs/Maps-utils-android/tree/master/go)
* [Java Client for map services](https://github.com/huaweicodelabs/Maps-utils-android/tree/master/java)
* [JavaScript Client for map services](https://github.com/huaweicodelabs/Maps-utils-android/tree/master/javascript)
* [Objective-C Client for map services](https://github.com/huaweicodelabs/Maps-utils-android/tree/master/objective-c)
* [PHP Client for map services](https://github.com/huaweicodelabs/Maps-utils-android/tree/master/php)
* [Python Client for map services](https://github.com/huaweicodelabs/Maps-utils-android/tree/master/python)
* [Swift Client for map services](https://github.com/huaweicodelabs/Maps-utils-android/tree/master/swift)

#### 为什么使用Client Libraries？

Client Libraries可以帮助您使用多种编程语言方便快捷地集成位置服务能力。

Client Libraries封装了以下接口功能：

* [关键字搜索](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-keyword-search-0000001050161916)
* [周边搜索](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-nearby-search-0000001050163873)
* [地点详情](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-detail-search-0000001050161918)
* [地点搜索建议](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-query-suggestion-0000001050161966)
* [自动补全](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/autocomplete-0000001052250492)
* [正地理编码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-forward-geo-0000001050163921)
* [逆地理编码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-reverse-geo-0000001050161968)
* [获取时区](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-time-zone-0000001050161920)  

#### 获取API密钥

接口调用时，您需要通过"API密钥"进行身份验证。获取API密钥的步骤如下：

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击对应的应用名称。
