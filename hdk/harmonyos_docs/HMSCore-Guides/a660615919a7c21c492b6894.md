# ArrayList和Bundle类型数据说明

#### 场景介绍

华为分析服务SDK支持开发者上报嵌套形式的事件参数，可以更好地满足DTM (Dynamic Tag Manager，动态标签管理器) 支撑开发者增强型电子商务的场景。

增强型电子商务，可以让您衡量用户在其购物历程中与商品的互动，包括查看商品列表、点击商品、浏览商品详情、将商品添加到收藏夹、将商品添加到购物车、移除购物车中商品、结帐流程、购买以及退款等。

#### 使用约束

SDK上报的事件中可以有多个ArrayList、Bundle类型事件参数，

      * Bundle内value支持的类型：Bundle、ArrayList、String、int、long、double、boolean、float、char、byte、short。Bundle内key值由数字、字母、下划线组成，不能以数字开头。
      * 最外层Bundle只能内嵌一个Bundle，一个ArrayList对象，内嵌的Bundle参数只支持基本数据类型，ArrayList的元素可以是Bundle或者基本数据类型，ArrayList中的Bundle也只能嵌套基本类型，ArrayList的size最多支持50个。

#### 示例代码

以下为添加商品到收藏夹事件的示例代码，您可以根据实际商品填写相关事件参数名和参数值，更多事件参数详情参见[通用](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-predefined-events-general-0000001051997159)。
    
    Bundle bundle_pre1 = new Bundle();
    bundle_pre1.putString(HAParamType.PRODUCTID,"item_id");
    bundle_pre1.putString(HAParamType.PRODUCTNAME,"name1");
    bundle_pre1.putString(HAParamType.CATEGORY, "category");
    bundle_pre1.putLong(HAParamType.QUANTITY, 100L);
    bundle_pre1.putDouble(HAParamType.PRICE, 10.01);
    bundle_pre1.putDouble(HAParamType.REVENUE, 10);
    bundle_pre1.putString(HAParamType.CURRNAME, "currency");
    bundle_pre1.putString(HAParamType.PLACEID, "location_ID");
    
    Bundle bundle_pre2 = new Bundle();
    bundle_pre2.putString(HAParamType.PRODUCTID,"item_id");
    bundle_pre2.putString(HAParamType.PRODUCTNAME,"name2");
    bundle_pre2.putString(HAParamType.CATEGORY, "category");
    bundle_pre2.putLong(HAParamType.QUANTITY, 68L);
    bundle_pre2.putDouble(HAParamType.PRICE, 8.01);
    bundle_pre2.putDouble(HAParamType.REVENUE, 12);
    bundle_pre2.putString(HAParamType.CURRNAME, "currency");
    bundle_pre2.putString(HAParamType.PLACEID, "location_ID");
    
    ArrayList<Bundle> listBundle = new ArrayList<>();
    listBundle.add(bundle_pre1);
    listBundle.add(bundle_pre2);
    
    Bundle commonBundle = new Bundle();
    commonBundle.putString(HAParamType.SEARCHKEYWORDS,"phone");
    commonBundle.putParcelableArrayList("items", listBundle);
    instance.onEvent(HAEventType.ADDPRODUCT2WISHLIST, commonBundle);
