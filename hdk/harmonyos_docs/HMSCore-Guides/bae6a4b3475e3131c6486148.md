# 普通场景化示例

#### 同类元素埋点

同类元素，即选中元素的某一个就近的父节点内，存在结构、ID或类名一致的元素。选择同类元素埋点后，系统将自动圈选这些相同元素作为埋点。若需要添加参数，只能选择该埋点父节点下的参数，或直接输入常量。适用于如商品列表等场景，点击列表中的任何一个同类元素都会触发该埋点。

                1. 选择“可视化埋点”页签，进入可视化埋点。输入框默认填写当前项目配置的网址，可手动修改目标埋点网址。点击“开始埋点”，系统跳转至埋点页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/NiTUd6JGSVOR82MOWcK8ZQ/zh-cn_image_0000001091251921.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=43D889213C7AC049FD2799CD64BB8D25468443583CC9E130917CFEE56AD33F82)

                2. 点击“添加埋点”，在页面右侧，选择您要埋点的元素类型，并在左侧页面圈选埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/puDZIV1YTQqIRjcJASgNyg/zh-cn_image_0000001131697308.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=5063D80AB9DD9BE88A5DB70981A7CFF08AD8BC884889660661B2197FDA048936)

                3. 在弹出的提示框中，选择“确定”。添加成功后，所圈选的元素及其同类元素均以蓝色框展示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/46/v3/GFn-8-GHSfmNz0jUg4BUjg/zh-cn_image_0000001131537458.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=B4182CCED43A6CE2D662B4A525DD3B0000299300D89F7625B249581A3F042B5E)

                4. 设置埋点名称。
                5. 添加参数。点击“添加”按钮添加参数行，一个埋点的参数不能超过10个。
                6. 点击“确定”添加埋点，您可以在右侧的“埋点列表”页面查看所创建的埋点信息。

创建完成后，当用户点击列表中的任意元素，均会触发并上报事件。

#### 动态参数埋点

动态参数是指当页面加载完后，某些class类名未存在于页面元素上，而是通过某些操作（比如点击、鼠标悬浮等）给页面元素动态添加或者更改class类名。

若class类名未存在于页面元素上，则普通参数埋点无法获取；若class类名存在于页面元素上，但位置可改变，则普通参数埋点时获取的路径可能存在偏差，导致上报数据有误。动态参数埋点则能根据动态添加的class在不同元素上的位置，上报该元素的文本或值，从而弥补了普通参数埋点的弊端。

例如用户在华为商城购买手机，手机颜色会展示多个选项，如亮黑色、星河银、翡冷翠、罗兰紫等，您可以通过动态参数埋点上报的选中的颜色。

                1. 选择“可视化埋点”页签，进入可视化埋点。输入框默认填写当前项目配置的网址，可手动修改目标埋点网址。点击“开始埋点”，系统跳转至埋点页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f6/v3/T7z-T2HsQduE-X-YO5QQpg/zh-cn_image_0000001091251921.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=F1EA9B48EB274DA0349555F43E640B61D560D958898BED9342E5702B153719A6)

                2. 点击“添加埋点”，在页面右侧，选择您要埋点的元素类型，并在左侧页面圈选埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/-Uo6SqH5QGmlQhm8pI9KVg/zh-cn_image_0000001127495747.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=F8045BDAE81C5BF2C2304AC3684C20416C3C335D5BCE616F40BDFADCBA1CB49E)

                3. 在弹出的提示框中，选择“取消”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4c/v3/gmgUyO8sQk2ayriw0rShGg/zh-cn_image_0000001077627928.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=DBC4EE2EA85F63F398B3270A980CE510EB51E293692502955C49D8095CB32874)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/a-100ZDkTTeAYhT93wuiLQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=FA751BFA6E2B6DA221B8EA40306B2419826F66A57B7A7959D1D45571D93205AE)

动态参数的结构为非同类元素，参数埋点时为一个参数对应一个埋点，而同类参数埋点则是多个参数对应多个埋点。因此，此处必须埋点为非同类元素。

                4. 通过自定义输入设置埋点名称。
                5. 添加动态参数。点击“添加”按钮添加参数行，并勾选“获取动态参数”。一个埋点的参数不能超过10个。

                   1. 手动输入参数名称。必填项，不能超过255个字符，名称只能包含中文、英文、俄文、数字、下划线、空格且参数名称不能重复。
                   2. 通过![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f5/v3/36qWq4YkQvaJCGmKU3v_7w/zh-cn_image_0000001124286042.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=92FEB1FCBEA2A06161AF67D4A91C34E4590FBF1D7E69937F0CA6E07B40BAD47C)图标在左侧页面中圈选动态参数范围。当鼠标移动到可圈选元素范围时，该范围会出现红色圈选效果。当圈选元素范围后，左侧页面上的红色圈选效果变更为绿色虚线框。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e1/v3/mX6sE5HCSBCeAqYZ-JDZXQ/zh-cn_image_0000001080587766.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=1F12FEEC00F5F1E5DA36C682757B853941F921E393CF1B890F8DACB47450E80E)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/jFH8EX8KRbSioyF0SwluSg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=2318658EF796CE8F16A1FA414630513EFC52FAF12697BAE68D18AEF375EE9F3B)

当某个页面元素的节点下，存在一系列的同类子元素，或这些子元素的唯一（不能有旁系）子元素是同类元素，则该元素节点可以被圈选。此处的同类是指层级、节点名一致且含有相同的class。

                   3. 在圈选的动态参数范围内，动态添加一个class，如选择任意一个元素。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/Cjsia1KJSU-lEUk0cTFzLw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=EA33045F7F110687FEE29AE8D05F607158E77C99020833A890DAE69F6F47391B)

动态参数是从同类元素中获取唯一的元素，具有唯一性，因此只支持添加一个class。若动态class添加在多个元素上，则可视化功能无法获取该参数。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/vKIxD8SMRFWJ8DeTrGTlbw/zh-cn_image_0000001127864927.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=3B5BFA3EE39F51B2D38F2278B93EC32005B52B0E9750FA425015DEC2913E55ED)

                   4. 点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/fhUOKZsLSOGU-LiKkQXg-Q/zh-cn_image_0000001127631285.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=CEE68B01659288F231A4B0BD17C5D35FBE47CF31B83F2DBABACFE96633EE1F85)图标，选中的元素形成高亮，在系统弹出的提示框中，点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/UNbJF_W2RNew39QaQvRlQQ/zh-cn_image_0000001127631409.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=92A6D694578D0B957CB6DA1380681E48FB3225C5626E7CDC699B0C4508D2ABC6)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/73WI6XB3RjKq_wpuX9biKw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=6F515E237BE9A35B3755EE933FFED48AB307BF916D085972E7441464C8CB90A3)

完成动态参数埋点后，若打开选择器按钮，选择器路径不可编辑。

                6. 完成获取动态参数后，单击“确定”，完成埋点添加。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/MsAEMGg-QSCFkx9c6DPqUQ/zh-cn_image_0000001081049716.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=2E856C9231C9863B296DBCBC5870BF9D2F7E5024E00BA70C854CCC294460B302)

#### 弹框埋点

添加弹框埋点后，埋点状态有如下几种情况：
                * 当DOM结构从关闭到打开，埋点状态为绿色；
                * 当DOM结构从关闭到打开再到关闭，且关闭后DOM结构一直存在，埋点状态为绿色；
                * 当DOM结构从关闭到打开再到关闭，且关闭后DOM结构消失，埋点状态为灰色。

                1. 选择“可视化埋点”页签，进入可视化埋点。输入框默认填写当前项目配置的网址，可手动修改目标埋点网址。点击“开始埋点”，系统跳转至埋点页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/esG9AYppSHiZ7wsvSrqSqA/zh-cn_image_0000001129140964.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=C4492F2558A12F2CB4B4B5F2B8D7158B9B8A9F82A4E4CC8963E5BBE906443A1E)

                2. 点击“购物车”，打开弹框。
                3. 在页面右侧，点击“添加埋点”，选择埋点元素为“任何元素”，在弹框中圈选埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5/v3/adk4BgScTk-ZdT3Wknl3uw/zh-cn_image_0000001098279756.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=F26FE00F1FB2C55FB0434117D8E9DDE4476582275C34D47ED31B7FA442E8F4AA)

                4. 设置“埋点名称”、“参数”及“触发事件”，单击“确定”，完成埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/BBIKPe3gRsmZxYkfq439CQ/zh-cn_image_0000001131417411.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=35CC93B25C5673562E33F2CD819B640EAF0918F43A6F1F41ABD35FC8F17F7163)

                5. 您可以在“埋点列表”中查看到该埋点信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ab/v3/gA4gGYYORDib96I_CLVGcA/zh-cn_image_0000001084675314.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=C5BCA8ABBF6484E0943C6C5A574EDEB413688387A30C5D593CB7076F71908DC3)

                6. 点击页面左上角的刷新![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/oWsmoAMvRFm-dOWxSrtejg/zh-cn_image_0000001131572077.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=1D5342EEA771133D1E887DB1C45731B44C3A29E487117ADFFB62BEA863FCE038)按钮，刷新页面后，埋点状态为灰色。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/xgkA9dOrQTCS1zdNfmdAeA/zh-cn_image_0000001131639521.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=C5614A2036BED2B6E65BE8C3FAC0119BEC7FBC9BDEE5B96C3DC487AE24D8BB25)

                7. 点击“购物车”，打开弹框，埋点状态为绿色。此时，若您关闭弹框，状态仍为绿色。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1/v3/3E1gA6n5TW2WATwExiWOvA/zh-cn_image_0000001131463929.png?HW-CC-KV=V1&HW-CC-Date=20261005T043143Z&HW-CC-Expire=86400&HW-CC-Sign=F09E52F405FBF7333D026F638722250EB89FEDAC054DFC6BDA910761CAC71985)
