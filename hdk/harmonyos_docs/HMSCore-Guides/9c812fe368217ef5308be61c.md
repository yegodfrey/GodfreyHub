# 使用入门

## 开发环境

* 安装[HUAWEI DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/) 2.1及以上

* [HarmonyOS SDK](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/environment_config-0000001052902427-V3#section67391947173214) API Version 5 - 7
* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上

## 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:------|:---------------|:--------------|
|华为手机和平板|HarmonyOS 2.0及以上|5.0.0及以上|

## 开发流程

您需要按照如下流程完成应用的开发工作。

|开发步骤|说明|
|:----------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
|[准备开发环境](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-development-environment-0000001227370647)|在开发HarmonyOS应用前，需要准备HarmonyOS应用的开发环境。|
|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-config-agc-0000001181770948)|在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中创建HarmonyOS应用、开通推送服务并且设置数据处理位置。|
|[配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-signature-0000001181930920)|HarmonyOS通过数字证书和Profile文件来对应用进行管控，您需要生成证书文件并且在AppGallery Connect上配置HarmonyOS应用的SHA256指纹。|
|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-sdk-0000001182089480)|在DevEco Studio中添加配置文件，集成推送服务SDK。|
|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-config-obfuscation-scripts-0000001212672954)|避免混淆HMS Core SDK导致功能异常。|
|[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-devguides-0000001199425951#section1663211917216)|获取接入推送服务的Token。|
|[发送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-devguides-0000001199425951#section1383018511495)|您可以通过服务端API向HarmonyOS应用推送消息。|
