# 事件说明  
  
快游戏自动采集事件中无ADDQUICKAPP事件，其它自动采集事件、预置事件以及自定义事件均和快应用一致，事件说明详情请分别参见[自动采集事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-automatic-event-collection-0000001090800817)、[预置事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-predefined-events-0000001171795079)和[自定义事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-custom-events-0000001077610570)。
