# 管理运动健康采样数据

应用集成Health Service kit后，通过调用[DataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472)类中的接口来操作用户的运动数据和健康数据， 如下：

* [插入用户的运动健康数据](#section4676181754913)（[insert](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section10704529103014)）
* [删除用户的运动健康数据](#section2044014482494)（[delete](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section8421540145419)）
* [修改用户的运动健康数据](#section20462104815492)（[update](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section356393833817)）
* [查询用户的运动健康数据](#section173731516509)（[read](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section0447440145418)）
* [查询用户的运动健康数据当日统计值](#section7869219155117)（[readTodaySummation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section9463154045415)）
* [查询用户的运动健康数据多日统计值](#section034816481920)（[readDailySummation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section295981925017)）
* [查询用户的运动健康数据最新数据点](#section390695615451)（[readLatestData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section783193232513)）
* [清空用户端云两侧的运动与健康数据](#section1961313115531)（[clearAll](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section172200211248)）

在调用上述接口前，必须先初始化一个[DataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472)对象如dataController，通过调用dataController对象的接口来操作用户数据。初始化[DataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472)对象的示例代码如下：

```screen
// 请注意：
// 1.此处的this为Activity对象
// 2.此处的https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472类的对象，请在每次接口调用前初始化，避免相关Activity或Context失效导致的数据读取失败的问题
DataController dataController = HuaweiHiHealth.getDataController(this); // 此处的this为Activity对象
```

> 说明
>
> 1. 在调用Health Service Kit SDK接口时，请确保手机处于亮屏状态，否则可能会导致接口调用失败，具体错误参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560#section10673269124)：DISABLE_DATA_OPERATION。
> 2. 在调用Health Service Kit SDK接口时，请确保您的应用为前台应用或者与前台应用绑定，否则可能会导致接口调用失败，具体错误请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560#section10673269124)：APPLICATION_NOT_FORGROUND。
> 3. 在本开发指导中，使用步数增量（[DT_CONTINUOUS_STEPS_DELTA](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562)）和身高（[DT_INSTANTANEOUS_HEIGHT](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section16298192019470)）两种数据类型进行示例说明，初始化DataController对象（dataController）时，仅请求了步数增量和身高的读写权限，即初始化后的dataController对象拥有步数增量和身高数据的读写权限。以下文档中context变量为android.content.Context对象，是Android系统提供的抽象实现类，具体代码中需依据具体场景获取对应的对象。
> 4. 通过[HuaweiHiHealth.getDataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweihihealth-0000001050091513#section11864115318103)获取[DataController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472)对象时，若传入Activity对象（用于应用包含界面的场景调用），支持触发HMS Core版本强制升级，若传入Context对象（用于应用无界面的场景调用），不支持触发HMS Core版本强制升级。
> 5. 在开始调用Health Service Kit接口之前，请阅读[Health Service Kit Android SDK接口调用示例](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/interface-invoking-example-0000001322195686)章节，了解Health Service Kit Android SDK接口调用流程。

## 插入用户的运动健康数据

> 说明
>
> 请注意插入的运动健康数据的采样点数据的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。

1. 构造一个数据采集器对象。
2. 根据数据采集器，创建一个采样集。
3. 构造一个步数增量（[DT_CONTINUOUS_STEPS_DELTA](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562)）采样点的开始时间、结束时间、增量步数。
4. 构造一个步数增量采样点。
5. 将一个步数增量采样点存储到采样集，也可以重复执行步骤3 ~ 步骤5添加多个样本点数据到采样集。
6. 调用[insert](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section10704529103014)接口， 将采样集插入到Health Service Kit中。
7. 调用[insert](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section10704529103014)接口插入采样集数据是异步操作，需要设置成功或失败的Listener，用来返回数据插入成功或失败结果。

   插入用户的运动健康数据到Health Service Kit示例代码如下：

   ```java
   // 步骤1：构造一个数据采集器对象。
   DataCollector dataCollector = new DataCollector.Builder().setPackageName(getApplicationContext())
       .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .setDataStreamName("STEPS_DELTA")
       .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
       .build();

   // 步骤2：根据数据采集器，创建一个采样集。
   final SampleSet sampleSet = SampleSet.create(dataCollector);

   // 步骤3：构造一个步数增量（https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562）采样点的开始时间、结束时间、增量步数。
   SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
   Date startDate = null;
   Date endDate = null;
   try {
       // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳，时间戳不涉及时区
       // 请注意此处设置的插入运动健康数据的采样点数据的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳，且时间间隔大于1分钟
       startDate = dateFormat.parse("2020-03-17 09:00:00");
       endDate = dateFormat.parse("2020-03-17 09:05:00");
   } catch (ParseException e) {
       logger("Time parsing error");
   }
   int stepsDelta = 200;

   // 步骤4：构造一个步数增量采样点。
   SamplePoint samplePoint = sampleSet.createSamplePoint()
       .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS);
   samplePoint.getFieldValue(Field.FIELD_STEPS_DELTA).setIntValue(stepsDelta);
   // 若写入的步数数据需要在运动健康App首页上展示，需要使用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/samplepoint_class-0000001050164515#section67423170142对采样点添加如下元数据
   samplePoint.addMetadata("motion_type", "RUN");

   // 步骤5：将一个步数增量采样点存储到采样集，也可以重复执行步骤3 ~ 步骤5添加多个样本点数据到采样集。
   sampleSet.addSample(samplePoint);

   // 步骤6：调用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section10704529103014接口， 将采样集插入到Health Service Kit中。
   Task<Void> insertTask = dataController.insert(sampleSet);

   // 步骤7：调用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section10704529103014接口插入采样集数据是异步操作，需要设置成功或失败的Listener，用来监听数据插入成功或失败。
   insertTask.addOnSuccessListener(new OnSuccessListener<Void>() {
       @Override
       public void onSuccess(Void result) {
           logger("Successfully insert a SampleSet into HMS core");
           showSampleSet(sampleSet);
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           Log.i("DataController","Failed to insert the sample set into the HMS core:" + e.getMessage());
       }
   });
   ```

   > 说明
   >
   > 上面的代码片段中用到两个辅助函数：Health Service Kit返回数据的显示函数showSampleSet(SampleSet sampleSet) ，输出结果保存到日志函数logger(String string)。这两个函数的代码示例如下：
   >
   > ```screen
   > /**
   >  * 将SampleSet对象中的SamplePoint打印输出
   >  *
   >  * @param sampleSet 采样集
   >  */
   > private void showSampleSet(SampleSet sampleSet) {
   >     SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
   >
   >     for (SamplePoint samplePoint : sampleSet.getSamplePoints()) {
   >         logger("Sample point type: " + samplePoint.getDataType().getName());
   >         logger("Start: " + dateFormat.format(new Date(samplePoint.getStartTime(TimeUnit.MILLISECONDS))));
   >         logger("End: " + dateFormat.format(new Date(samplePoint.getEndTime(TimeUnit.MILLISECONDS))));
   >         for (Field field : samplePoint.getDataType().getFields()) {
   >             logger("Field: " + field.getName() + " Value: " + samplePoint.getFieldValue(field));
   >         }
   >     }
   > }
   >
   > /**
   >  * 输出操作结果日志到logcat
   >  *
   >  * @param string 日志字符串
   >  */
   > private void logger(String string) {
   >     Log.i("DataController", string);
   > }
   > ```

## 删除用户的运动健康数据

从Health Service Kit删除历史数据，只能删除本应用插入的数据。

1. 构造删除条件：一个数据采集器对象。
2. 构造删除条件时间区间：开始、结束时间。
3. 构造删除的参数对象。
4. 使用指定的条件删除对象，调用[delete](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section8421540145419)接口删除数据样本集。
5. 调用[delete](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section8421540145419)接口删除采样集数据是异步操作，需要设置成功或失败的Listener，用来监听数据删除成功或失败。

   ```screen
   // 步骤1：构造删除条件：一个数据采集器对象。
   DataCollector dataCollector = new DataCollector.Builder().setPackageName(getApplicationContext())
       .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .setDataStreamName("STEPS_DELTA")
       .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
       .build();

   // 步骤2：构造删除条件时间区间：开始、结束时间。
   SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
   Date startDate = null;
   Date endDate = null;
   try {
       // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳。删除满足时间戳范围的数据点，时间戳不涉及时区
       startDate = dateFormat.parse("2020-03-17 09:00:00");
       endDate = dateFormat.parse("2020-03-17 09:05:00");
   } catch (ParseException e) {
       logger("Time parsing error");
   }

   // 步骤3：构造删除的参数对象。
   DeleteOptions deleteOptions = new DeleteOptions.Builder().addDataCollector(dataCollector)
       .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS)
       .build();

   // 步骤4：使用指定的条件删除对象，调用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section8421540145419接口删除数据样本集。
   Task<Void> deleteTask = dataController.delete(deleteOptions);

   // 步骤5：调用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section8421540145419接口删除采样集数据是异步操作，需要设置成功或失败的Listener，用来监听数据删除成功或失败。
   deleteTask.addOnSuccessListener(new OnSuccessListener<Void>() {
       @Override
       public void onSuccess(Void result) {
           logger("Successfully delete sample data from HMS core");
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           Log.i("DataController","Failed to delete sample data from HMS core:" + e.getMessage());
       }
   });
   ```

   > 说明
   >
   > 上面的代码片段中用到辅助函数：输出结果保存到日志logger(String string)。这个函数的代码示例如下：
   >
   > ```screen
   > /**
   >  * 输出操作结果日志到logcat
   >  *
   >  * @param string 日志字符串
   >  */
   > private void logger(String string) {
   >     Log.i("DataController", string);
   > }
   > ```

## 修改用户的运动健康数据

> 说明
>
> 请注意修改的运动健康数据的区间范围的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。

1. 构造修改条件：一个数据采集器对象。
2. 构造修改采样集：根据数据采集器，创建一个修改采样集。
3. 构造一个修改步数增量（[DT_CONTINUOUS_STEPS_DELTA](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562)）采样点的开始，结束时间，增量步数。
4. 构造一个修改步数增量采样点。
5. 将一个修改步数增量采样点添加到修改采样集，也可以重复执行步骤3 ~ 步骤5添加多个修改样本点数据到修改采样集。
6. 构造一个修改操作的参数对象。
7. 使用指定的修改参数对象，调用[update](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section356393833817)接口修改数据样本集。
8. 调用[update](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section356393833817)接口修改采样集数据是异步操作，需要设置成功或失败的Listener，用来返回数据修改成功或失败。

   ```screen
   // 步骤1：构造修改条件：一个数据采集器对象。
   DataCollector dataCollector = new DataCollector.Builder().setPackageName(getApplicationContext())
       .setDataType(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .setDataStreamName("STEPS_DELTA")
       .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
       .build();

   // 步骤2：构造修改采样集：根据数据采集器，创建一个修改采样集。
   SampleSet sampleSet = SampleSet.create(dataCollector);

   // 步骤3：构造一个修改步数增量（https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562）采样点的开始，结束时间，增量步数。
   SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
   Date startDate = null;
   Date endDate = null;
   try {
       // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳。更新满足时间戳范围的数据点，时间戳不涉及时区
       // 请注意此处设置的修改运动健康数据的区间范围的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳
       startDate = dateFormat.parse("2020-03-17 09:00:00");
       endDate = dateFormat.parse("2020-03-17 09:05:00");
   } catch (ParseException exception) {
       logger("Time parsing error");
   }
   int stepsDelta = 200;

   // 步骤4：构造一个修改步数增量采样点。
   SamplePoint samplePoint = sampleSet.createSamplePoint()
       .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS);
   samplePoint.getFieldValue(Field.FIELD_STEPS_DELTA).setIntValue(stepsDelta);
   // 若修改的步数数据需要在运动健康App首页上展示，需要使用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/samplepoint_class-0000001050164515#section67423170142对采样点添加如下元数据
   samplePoint.addMetadata("motion_type", "RUN");

   // 步骤5：将一个修改步数增量采样点添加到修改采样集，也可以重复执行步骤3 ~ 步骤5添加多个修改样本点数据到修改采样集。
   sampleSet.addSample(samplePoint);

   // 步骤6：构造一个修改操作的参数对象。
   UpdateOptions updateOption = new UpdateOptions.Builder()
       .setTimeInterval(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS)
       .setSampleSet(sampleSet)
       .build();

   // 步骤7：使用指定的修改参数对象，调用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section356393833817接口修改数据样本集。
   Task<Void> updateTask = dataController.update(updateOption);

   // 步骤8：调用https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section356393833817接口修改采样集数据是异步操作，需要设置成功或失败的Listener，用来返回数据修改成功或失败。
   updateTask.addOnSuccessListener(new OnSuccessListener<Void>() {
       @Override
       public void onSuccess(Void result) {
           logger("Successfully update sample data from HMS core");
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           Log.i("DataController","Failed to update sample data from HMS core:" + e.getMessage());
       }
   });
   ```

## 查询用户的运动健康数据

从Health Service Kit查询历史数据，例如读取某一时间段的步数，可以在[ReadOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ro_class-0000001050091216)指定读取的条件，如指定数据采集器、读取的数据类型、读取详情数据。
> 说明
>
> 1. 调用查询运动健康数据接口，接口参数中的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。
> 2. 调用查询运动健康数据接口，接口参数中的开始时间和结束时间之间的时间跨度不允许超过31天。
> 3. 调用查询运动健康数据接口，查询步数详情数据为空，请参见FAQ：[查询步数明细数据时，查询不到数据，如何处理](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001467892241)。

1. 构造查询条件时间区间：开始、结束时间。
2. 构造查询条件的查询对象。
3. 使用指定的条件查询对象，调用[read](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section0447440145418)接口查询数据集。
4. 调用[read](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section0447440145418)接口查询采样集数据是异步操作，需要设置成功或失败的Listener，用来监听数据查询成功或失败。

   ```screen
   // 步骤1：构造查询条件时间区间：开始、结束时间。
   SimpleDateFormat dateFormat = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
   Date startDate = null;
   Date endDate = null;
   try {
       // 此处填写的开始、结束时间，存储时使用标准UNIX时间戳。查询时间戳范围的数据点，时间戳不涉及时区。
       // 请注意此处设置的查询运动健康数据的区间范围的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳。
       startDate = dateFormat.parse("2020-03-17 09:00:00");
       endDate = dateFormat.parse("2020-03-17 09:05:00");
   } catch (ParseException exception) {
       logger("Time parsing error");
   }

   // 步骤2：构造查询条件的查询对象。
   // 此处填写的DataType.DT_CONTINUOUS_STEPS_DELTA，可用来查询用户的步数健康数据。
   ReadOptions readOptions = new ReadOptions.Builder().read(DataType.DT_CONTINUOUS_STEPS_DELTA)
       .setTimeRange(startDate.getTime(), endDate.getTime(), TimeUnit.MILLISECONDS)
       .build();
   ```
