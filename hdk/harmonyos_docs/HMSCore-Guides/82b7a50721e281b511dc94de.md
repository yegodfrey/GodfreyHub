# 服务定价

## 服务订阅说明

1. 位置服务面向企业开发者，根据开发者实际调用发生的区域，采用不同的计费模式。
   * 当调用发生在非中国大陆区域，位置服务采用[按量计费](#section15282547125513)的方式进行结算。
     * 免费档套餐：自2021年1月1日起，华为每月为每位海外企业开发者提供**CNY¥2398代金券免费使用** ，用于定位、地图、位置、导航服务，每月代金券**仅限当月使用**。当您成功注册成为华为开发者用户，在AppGallery Connect创建项目后，华为会自动帮您开通服务对应的免费档套餐。
     * 升级付费档：如需使用位置服务收费接口，请通过AppGallery Connect开通付费套餐，具体操作请参见[升级到付费档](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing-0000001058092595#section1337763420106)。升级到付费档后，每月优先使用代金券抵扣费用，若调用收费接口产生的费用超出代金券额度时，则需要您付费使用。
   * 当调用发生在中国大陆区域，位置服务采用[基础商业授权与增值付费](#section12432214814)的方式进行结算。当基础商业授权内的调用额度或QPS限额不能满足开发者的调用需求时，可通过购买单接口流量包、单接口包月或购买QPS的方式提升调用量。
2. 位置服务面向个人开发者，系统会自动为您提供部分免费配额。
3. 针对所有的AppGallery Connect付费服务，华为将按您使用服务实际产生的使用量向您收费。为防止服务被中断，请保障您的账户余额充足。具体操作可参见[服务定价与订购](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-service-billing-0000001058092595)。
