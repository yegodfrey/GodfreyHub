# 申请账号服务

1. 登录[开发者联盟网站](https://developer.huawei.com/consumer/cn/)，单击右上角"管理中心"。

   若您之前未注册开发者账号，请参见[注册账号](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)和[实名认证](https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172)成为开发者并完成实名认证。开发者可实名认证为个人开发者或者企业开发者，认证前，请先了解二者的[权益区别](https://developer.huawei.com/consumer/cn/doc/start/dbiae-0000001336403980#section10229144715113)。
   > 说明
   > * 如果有明确大规模用户使用场景和商用目的，建议优先认证为企业账号，一个企业仅能认证一个账号。


2. 单击"账号"。若无"账号"卡片，请单击右上角"自定义桌面"添加卡片。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/0w0qNnc7TBGoST9GfOXIvw/zh-cn_image_0000002548039179.png?HW-CC-KV=V1&HW-CC-Date=20260909T141433Z&HW-CC-Expire=31536000000&HW-CC-Sign=5DC8EF123290F61251329EBE2EF17D4D2B99ECD1C24150F02CCE1F25585F2DA0)


3. 单击"申请账号服务"，同意协议后，进入产品信息填写页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6e/v3/T8I0I8djQu-NSwm7WvQNHg/zh-cn_image_0000002548039177.png?HW-CC-KV=V1&HW-CC-Date=20260909T141433Z&HW-CC-Expire=31536000000&HW-CC-Sign=F957D5EAE4D9ECAE39C269318304C18CCC43167DF7056FF86E64BECDBF66600D)

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/wSQtwb5HROiEtMh-ACwl1g/zh-cn_image_0000002547959183.png?HW-CC-KV=V1&HW-CC-Date=20260909T141433Z&HW-CC-Expire=31536000000&HW-CC-Sign=B53A0B4F4882C65170261938D123A1C1411C412835B9146BA3648F549BCE3BDC)

   |**项目**|**填写说明**|
   |:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |产品类型|* 如果是客户端开发，请选择"移动应用"。 * 如果是服务器对接，请选择"服务器应用"。|
   |账号接入方式|如果是移动应用，默认为"SDK接入"。|
   |选择产品|1. 如果此前已创建过产品，则从已创建的产品列表里选择产品。 如果未创建，请单击"创建产品"。 > 说明 > * 创建产品时填写的应用相关信息如"应用名称"、"应用图标"等将展示给用户，且应用名称不支持后续修改。 > * 应用名称需要与软件包中的应用名称一致，否则可能会[申请华为运动健康服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-kitservice-0000001050707556)审核不通过。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/FFeXv7LlTv6o2BmaSt6Mhg/zh-cn_image_0000002547959185.png?HW-CC-KV=V1&HW-CC-Date=20260909T141433Z&HW-CC-Expire=31536000000&HW-CC-Sign=8033FA4802C9052767BA26C167ECB5BEB6E139380206B2D5E35C675621A552FB "点击放大") 2. 创建成功后，生成APP ID以及Secret信息。用来唯一标识应用。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/6xwW86v9ST69GqRXzcxXtQ/zh-cn_image_0000002516519292.png?HW-CC-KV=V1&HW-CC-Date=20260909T141433Z&HW-CC-Expire=31536000000&HW-CC-Sign=03D5EC397896EDE66CA69B4B481AE7BC0051D85B3CD7E049FE118E08614A5889 "点击放大")|
   |回调地址|服务器应用此处必选，由您的技术人员提供。后续可修改。 > 说明 > 以http(s)开头，且是合法的URL，长度最大255，不能以"/"结尾，不能包含字符"?"，不能包含get参数，支持IP地址和端口。必须全路径匹配。|
   |应用访问地址|服务器应用此处必选，为三方服务器出口IP地址，支持配置多个。由您的技术人员提供。后续可修改。|
   |应用包名|填写[应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241)。如"com.health.demo"，务必与APK包名一致，填写后不能修改。 > 注意 > 如果您需要使用[自定义数据类型](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-0000001177423513#section2803105912431)，包名请勿使用com.huawei开头。|
   |SHA256证书指纹|填写[应用证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-certificate-guide-0000001530080540)。 签名证书指纹用于在通过华为HMS Core SDK调用HMS Core（APK）时，校验应用的真实性。|


4. 单击"提交"，即完成"账号服务"的开通。
