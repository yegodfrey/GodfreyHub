# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[Codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_pushkit-android)快速体验一个应用的开发过程。

针对华为手机，在正式开发应用之前，还可以通过[推送体验应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/push-experience-app-0000001075089636)体验华为消息推送功能，包括推送样式体验（大文本样式、Inbox样式、按钮样式）、场景化推送体验（耳机插入/连接时推送，关闭免打扰时推送等）。  

#### 开发环境

* JDK 1.8.211及以上
* 安装Android Studio Chipmunk \| 2021.2.1及以上

  * minSdkVersion 19及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 4.6及以上（推荐）
* 测试应用的设备：建议使用EMUI 10及以上的华为手机。

如果您同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:-------|:---------------|:--------------|
|华为手机和平板|EMUI 3.0及以上|3.0.0及以上|
|非华为手机和平板|Android 4.4 - 13|3.0.0及以上|

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|开发步骤|说明|
|:------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137)|开发应用前需要您在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。|
|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-integrating-sdk-0000001050040084)|通过本地或者远程方式集成SDK包。|
|[配置Manifest文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-cfg-manifest-0000001050042037)|集成HMS Core Push SDK后要在"AndroidManifest.xml"文件的"application"标签中注册您自己的"service"，用于[接收透传消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-basic-receivemsg-0000001087370610)、[获取Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-client-dev-0000001050042041#section876955375919)。|
|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-obfuscation-scripts-0000001050176973)|避免混淆HMS Core SDK导致功能异常。|
|基础能力开发|基础能力包括[获取和注销Token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-client-dev-0000001050042041)、[发送测试消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-basic-sendtestmsg-0000001087842114)、[获取消息数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-basic-receivemsg-0000001087370610)、[自定义点击消息动作](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/andorid-basic-clickaction-0000001087554076)和[设置通知栏消息开关](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/configuring-notification-messages-0000001134381639)。|
|增强能力开发（可选）|增强能力包括[按照主题发送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-topic-based-sending-0000001050040114)、[自动推送通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/automated-notifications-0000001051072150)、[多发送者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/multisender-0000001057626308)等功能。|
|其他能力开发（可选）|其他能力包括[自定义通知渠道](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-custom-chan-0000001050040122)、[离线用户消息覆盖](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-offline-msg-overwr-0000001050042079)、[基于条件的消息推送](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-cond-send-0000001050040128)等功能。|
|通知栏消息样式（可选）|样式包括[桌面角标](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-badging-0000001050042083)、[大文本样式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-large-text-style-0000001050042081)、[Inbox样式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-inbox-style-0000001050042085)、[通知消息按钮](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-action-buttons-0000001050040136)等功能。|
|[开发后自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001050040222)|使用华为自检工具在线对应用进行自检。|
|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001050174928)|将完成的应用提交华为方进行审核，审核时间一般为1\~2个工作日。|
