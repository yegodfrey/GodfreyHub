# ECG健康记录

本章节提供通过华为Health Service Kit服务端REST API写入用户ECG数据的方法示例。ECG记录数据类型com.huawei.continuous.ecg_record请参见[ECG心电测量记录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ecg-measurement-record-0000001131831084)，ECG明细数据类型com.huawei.continuous.ecg_detail请参见[心电测量明细](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ecg-measurement-details-0000001131423786)。

ECG数据类型对应的Scope为：

* 读权限：https://www.huawei.com/healthkit/hearthealth.read
* 写权限：https://www.huawei.com/healthkit/hearthealth.write

#### 读取ECG数据

通过HealthRecord读取ECG数据。

HTTP请求，请参见[数据类型健康记录查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/get-health-record-by-datatype-0000001142843917#section9701181322219)接口

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/healthRecords?startTime=***&endTime=***&dataType=***&subDataType=***
```

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/healthRecords?startTime=1613961730000000000&endTime=1613961780000000000&dataType=com.huawei.continuous.ecg_record&subDataType=com.huawei.continuous.ecg_detail
```
