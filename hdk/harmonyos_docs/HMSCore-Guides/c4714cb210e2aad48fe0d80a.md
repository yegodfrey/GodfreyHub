# 登机牌

#### 概述

登机牌即在用户购买机票后所产生的电子登机凭据，用户添加登机牌后可以实时获取到航班动态。

Wallet Kit已提供登机牌接入华为钱包的能力，商户可通过多种方式轻松将卡券集成到华为钱包中。

#### 卡券更新

* 网页、短信、Email、App应用内方式更新卡券 请参见"[调用华为服务器接口更新卡券](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-overa-update-0000001050042360)"章节来实现卡券更新操作。

  更新登机牌模板接口地址如下，请更换示例代码中的接口地址。

  ```
  https://xxx/hmspass/v1/flight/model/{modelId}
  ```

  更新登机牌用户特有信息的实例（Instance）接口地址如下，请更换示例代码中的接口地址。


#### 跨设备同步能力

当前能力只开放给通过"App应用内、快应用、华为钱包CardStore方式"添加的卡券。

通过卡券包添加时卡片是以端到端的形式将卡券保存到华为钱包，华为服务器没有保存用户推送的卡券，所以无法做到帐号间共享。如果商户需要实现帐号间共享卡券能力则需要实现Wallet Kit提供的托管能力。

1. 在开发者联盟开放跨设备同步能力。

   <br />

   在"[服务创建](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-server-0000001050160377)"章节配置应用数据时可以选择是否开放跨设备同步能力，此时商户如果想实现此功能则需要开通此服务。

   ![](https://media:101782807018029723 "点击放大")

   <br />

2. 实现下载卡券包接口。

   <br />

   商户打开跨设备同步能力后，当商户推送卡券到华为钱包时，华为钱包会将卡券部分信息托管至华为服务器（只上传下载卡券的部分信息）。当用户在当前帐号下的其他设备登录时，华为钱包应用会去商户服务器下载已领取过的卡券包，商户服务器需实现"[商户服务器实现接口更新卡券](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-common-update-0000001050044317)"步骤供华为钱包调用下载卡券包。

   <br />

#### 起飞提醒通知

华为钱包针对登机牌提供有起飞前提醒，商户为卡券设置PassObject.fields.timeList.scheduledDepartureTime.value后华为钱包会在起飞前4小时提醒用户。

提醒会在00:00-06:00分静默，如果通知是在此时段内则会在静默时间前30分钟提醒。
