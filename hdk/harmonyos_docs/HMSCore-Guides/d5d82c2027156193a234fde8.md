# REST API

#### 开发流程

      1. 开发者根据需求，选择套餐。参见表1。
      2. [开通白名单权限](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/about-charging-0000001256292551#ZH-CN_TOPIC_0000001256292551__p6696151514112)。
      3. 根据经纬度信息获取基础citycode信息。参见[位置类API](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/location-api-0000001211886946#section67635558718)。

或根据名称获取citycode。参见[城市编码表](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/city-dictionary-0000001256958081)。

      4. 调用您所需的天气API。

#### 天气类API

根据城市查询天气实况信息、逐日预报、逐小时预报，具体使用方式请参见 ：[天气类-天气实况-基础实况](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/weather-live-api-0000001255549371)、[天气类-N天逐日预报](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/weather-everyday-api-0000001210789426)、[天气类-N天逐小时预报](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/weather-everyhour-api-0000001255690855)。

#### 空气类API

根据城市查询空气质量数据，实况AQI、逐日AQI预报、逐小时AQI预报，具体使用方式请参见 ：[空气类-实况AQI](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/air-aqi-live-api-0000001211336770)、[空气类-逐小时AQI预报](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/air-aqi-everyhour-api-0000001256101031)、[空气类-逐天AQI预报](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/air-aqi-everyday-api-0000001256221081)。
