# 延迟结算

您的App在推出优惠活动的时候，例如奖励用户使用商品时长，可以调用应用内支付服务器提供的延迟结算接口，将用户的下一个结算日期推迟。用户将继续享受已经付费的服务和内容，但在延迟期内不会被扣款。系统会根据延迟时间更新订阅续订日期。您可以通过延迟结算完成以下操作：

* 将免费内容或者服务作为套餐或特别优惠提供给用户（例如，让订阅年度杂志的用户免费访问特定内容）。
* 向特定用户赠送内容或者服务的访问权限。

每次调用API的结算最短可延迟一天，最长为一年（365天）。您可以在新的结算日期到来之前再次调用API以进一步延迟结算。延期后，下个续期周期的开始日期为延期后的时间。

您的App需要使用电子邮件或在应用中通知用户的结算日期已被延迟（发生更改）。

具体实现请参见[延迟结算](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-delayed-settlement-0000001050706082)。
