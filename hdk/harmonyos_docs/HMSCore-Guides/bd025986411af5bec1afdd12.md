# 原生广告

原生广告是与应用内容融于一体的广告，通过"和谐"的内容呈现广告信息，在不破坏用户体验的前提下，为用户提供有价值的信息，展示形式包含图片、文字和视频，支持您自由定制界面。

## 添加原生广告

原生广告可以通过组件方式和编程方式添加。

### 组件方式

鲸鸿动能JavaScript API提供原生容器、视频播放、应用下载按钮组件，组件内部实现了广告事件上报、视频播放、应用下载的能力。

1. 通过const nativeAd=ppsads.createNativeAd创建广告对象。

   ```screen
   const nativeAd = ppsads.createNativeAd({
       slotId: "testy63txaom86"
   });
   ```

2. 调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[load()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)加载广告。

   ```screen
   nativeAd.load();
   ```

   * 成功执行[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[onLoad(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)回调：

     ```screen
     nativeAd.onLoad((adlist) => {
     });
     ```

   * 失败执行[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[onError(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)回调：

     ```screen
     nativeAd.onError((errorCode) => {});
     ```

     > 说明
     >
     > errorCode详情请参见[JavaScript错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/error-code-0000001133633596)。
3. 使用原生广告组件展示广告。

   ```screen
   <!-- 下载类视频广告模板 -->
   <template id="native-video-with-btn-template">
       <ads-native class="native native-video-tmpl hidden">
           <div>
               <ads-native-video class="native__video-view"></ads-native-video>
           </div>
           <div class="native__footer" >
               <div>
                   <div>
                       <span class="native__title"></span>
                   </div>
                   <div>
                       <span class="native__ad-source"></span>
                       <span class="native__ad-flag"></span>
                   </div>
               </div>
               <div>
                   <ads-app-button class="native__app-btn"></ads-app-button>
               </div>
           </div>
       </ads-native>
   </template>
   <script>
   function createVideoWithAppDownloadBtnTemplate (adData) {  
       let content = document.getElementById("content");  
       let videoBtnTmpl = document.getElementById("native-video-with-btn-template");  
       let clone = document.importNode(videoBtnTmpl.content, true);  
       content.innerHTML = "";  
       content.appendChild(clone);  
       const nativeView = document.querySelector(".native");  
       const titleView = document.querySelector(".native__title");  
       const sourceView = document.querySelector(".native__ad-source");  
       const flagView = document.querySelector(".native__ad-flag");  
       const videoView = document.querySelector(".native__video-view");  
       const btnView = document.querySelector(".native__app-btn");  
       customElements.whenDefined("ads-native").then(() => {   
           // ads-native组件注册的广告素材adData要和当前渲染布局模板的广告素材数据保持一致 
           nativeView.registerNativeAd(adData, null, videoView);    
           nativeView.registerAppButton(btnView);  
       });  
       titleView.textContent = adData.title;  
       sourceView.textContent = adData.source;  
       flagView.textContent = "AD";
       this.showAdView(nativeView);
   };
   </script>
   ```

   > 说明
   >
   > 广告加载成功后，您需要创建新的[ads-native](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsnative-0000001133473812)组件绑定广告素材数据，不能复用已使用过的[ads-native](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsnative-0000001133473812)组件。

### 编程方式

鲸鸿动能JavaScript API加载广告成功返回广告素材数据，媒体自行渲染广告位DOM布局，并通过鲸鸿动能JavaScript API接口上报事件、打开落地页、应用下载。该方式需要审核，实现前请与运营人员联系。

1. 通过[ppsads.createNativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-createnativead-0000001133633586)创建广告对象。

   ```screen
   const nativeAd = ppsads.createNativeAd({
       slotId: "testy63txaom86"
   });
   ```

2. 调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[load()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)加载广告。

   ```screen
   nativeAd.load();
   ```

   * 成功执行[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[onLoad(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)回调：

     ```javascript
     nativeAd.onLoad((adList) => {
         // 注册和填充素材
     });
     ```

   * 失败执行[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[onError(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)回调：

     ```screen
     nativeAd.onError((errorCode) => {
     });
     ```

     > 说明
     >
     > errorCode详情请参见[JavaScript错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/error-code-0000001133633596)。
3. 调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[reportAdShow(object)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)上报广告曝光。

   ```screen
   nativeAd.reportAdShow({
       adId: "xxxxx" 
   });
   ```

4. 调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[reportAdClick(object)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)上报广告点击。

   ```screen
   nativeAd.reportAdClick({
       adId: "xxxxx"
   });
   ```

5. 调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[reportAdClose(object)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)上报广告关闭。

   ```screen
   nativeAd.reportAdClose({
       adId: "xxxxx" 
   });
   ```

6. 每次用户点击广告调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[onAdClick(object)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)执行跳转落地页动作。

   ```screen
   nativeAd.onAdClick({
       adId: "xxxxx" 
   });
   ```

7. 调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[startDownload(object)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)等接口进行应用下载。

   ```screen
   nativeAd.startDownload({
       adId: "xxxxx" 
   });
   ```

8. 当应用页面销毁时，调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814).[destroy()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001133473814#section157377342512)销毁原生广告。

   ```screen
   nativeAd.destroy();
   ```

## 展示关联启动文案

* 判断interactionType为0/1/2，即纯展示广告、网页推广、应用下载时，保持初始UX不变，即不显示跳转文案，只显示广告标签和广告来源。
* 当interactionType等于9时，获取abilityDetailInfo，若abilityDetailInfo不为空，取abilityName，若abilityName为空，显示文案"点击打开鸿蒙服务"；若abilityName不为空，显示文案"点击打开 + abilityName"。
* 当interactionType等于10且promoteInfo不为空，promoteInfo.type类型是2，promoteInfo.name不为空时，显示文案"点击打开xxx"。如果interactionType等于10，且promoteInfo为空，或promoteInfo.name为空时，显示文案"点击打开微信小程序"。
* 当interactionType等于3，promoteInfo.type类型是1且promoteInfo.name不为空时，显示文案"点击打开xxx"，若promoteInfo.name为空，显示文案"点击打开快应用"。
* 应用推广、应用促活类，如果apkInfo为空，显示文案"点击了解详情"。判断应用未安装，则不显示关联启动文案。如果apkInfo中appName不为空且应用已安装，显示文案"点击打开xxx"，若appName为空，显示文案"点击了解详情"。

interactionType值：

|推广目的|返回值|
|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
|interactiontype|0：纯展示（即点击无反应）。 1：网页推广（目的是点击打开网页）。 2：应用下载（目的是下载普通应用）。 3：应用促活（目的是点击进入应用内）或者快应用。 5：应用推广（未安装则下载，已安装则促活）。 7：电商网页（安装则进入应用，未安装打开网页）。 8：预约下载。 9：鸿蒙服务。 10：拉起小程序。|

PromoteInfo结构：

|推广子类型|推广实体名称|
|:----------------|:---------------------------------|
|1. 快应用。 2. 微信小程序。|被推广的实体名称。是URL编码过的，客户端在使用前要进行URL解码。|

示例代码：

```screen
export const i18nLanguage = {
  clickOpen: '点击打开',
  learnMore: '了解详情',
  swipeLeftClick: '向左滑动或点击',
  swipeRightClick: '向右滑动或点击',
  clickOpenWechatMiniSpec: "点击打开微信小程序",
  clickOpenQuickApp: "点击打开快应用",
  clickOpenOHarmonyService: "点击打开鸿蒙服务",
  openTo: '打开',
  clickToLearnMore: "点击了解详情",
  fastAppSpec: "快应用",
  wechatMiniSpec: "微信小程序",
  harmonyServiceSpec: "鸿蒙服务"
}

export const INTERACTION_TYPE_APP_DOWNLOAD = 2;

export const INTERACTION_TYPE_OPEN_APP = 3;

export const INTERACTION_TYPE_APP_PROMT = 5;

export const INTERACTION_TYPE_OPEN_FA = 9;

export const INTERACTION_TYPE_OPEN_WECHAT_MINI = 10;

export const APPSTATUS_INSTALLED = 'INSTALLED';

setPromote(status = null) {
      if (this.nativeAd == null) {
        return;
      }
      let promotePreTxt = this.i18nLanguage.clickOpen;
      if (this.isInteract) {
      //判断是否已有交互文案，有则不显示交互文案
        promotePreTxt = this.i18nLanguage.openTo;
      }
      const name = utf8Decode(this.nativeAd.promoteInfo && this.nativeAd.promoteInfo.name);
      if (this.nativeAd.interactionType === INTERACTION_TYPE_OPEN_WECHAT_MINI) {
        this.setPromoteTxt(promotePreTxt, name, this.i18nLanguage.wechatMiniSpec, this.i18nLanguage.clickOpenWechatMiniSpec);
      } else if (this.nativeAd.promoteInfo && this.nativeAd.promoteInfo.type == 1) {
        this.setPromoteTxt(promotePreTxt, name, this.i18nLanguage.fastAppSpec, this.i18nLanguage.clickOpenQuickApp);
      } else if (this.nativeAd.interactionType == INTERACTION_TYPE_OPEN_FA) {
        const abilityName = this.getAbilityName(this.nativeAd);
        this.setPromoteTxt(promotePreTxt, abilityName, this.i18nLanguage.harmonyServiceSpec, this.i18nLanguage.clickOpenOHarmonyService);
      } else if (
        (status == APPSTATUS_INSTALLED &&
          (this.nativeAd.interactionType == INTERACTION_TYPE_APP_DOWNLOAD ||
            this.nativeAd.interactionType == INTERACTION_TYPE_OPEN_APP ||
            this.nativeAd.interactionType == INTERACTION_TYPE_APP_PROMT)) ||
        (isVoid(this.appInfo) && this.nativeAd.interactionType == INTERACTION_TYPE_OPEN_APP)
      ) {
        if (this.appInfo && this.appInfo.appName) {
          this.promoteTxt = setI18nLangText(promotePreTxt, this.appInfo.appName);
        } else if (this.isInteract) {
          promotePreTxt = this.i18nLanguage.learnMore;
        } else {
          this.promoteTxt = this.i18nLanguage.clickToLearnMore;
        }
      } else {
        this.promoteTxt = '';
      }
    },
    setPromoteTxt(promotePreTxt, name, baseName, basePromoteTxt) {
      if (name) {
        this.promoteTxt = promotePreTxt+name;
      } else if (this.isInteract) {
        this.promoteTxt = promotePreTxt+baseName;
      } else {
        this.promoteTxt = basePromoteTxt;
      }
    },
    getAbilityName(nativeAd) {
      if (nativeAd.abilityInfo) {
        try {
          const info = JSON.parse(nativeAd.abilityInfo);
          return info.abilityName;
        } catch (e) {
          return null;
        }
      }
    },
```

## 测试原生广告

原生广告测试广告位ID，仅可用于调测原生广告功能，不可用于广告变现，在应用正式发布前需替换为正式的原生广告位ID。您应在应用发布前先进入[流量变现官网](https://developer.huawei.com/consumer/cn/monetize)，点击"开始变现"，登录[鲸鸿动能媒体服务平台](https://developer.huawei.com/consumer/cn/service/ads/publisher/html/index.html?lang=zh)，申请正式的广告位ID并替换测试广告位ID，具体操作详情请参见[展示位创建](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/zhanshiweichuangjian-0000001132700049)。
