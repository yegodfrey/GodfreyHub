# 同程旅行

#### 同程旅行简介

同程旅行致力于打造在线旅行一站式平台，业务涵盖交通票务预订（机票、火车票、汽车票、船票等）、在线住宿预订、景点门票预订，及多个出行场景的增值服务，用户规模超过2亿，是中国两大出行平台之一。

#### 合作方式

通过接入会员开放服务，同程旅行将黑鲸会员体验卡券码投放在华为会员中心福利模块，获得了较高的用户曝光和会员留存。  

#### 合作收益

* 功能上线3月内，累计曝光次数500万+，黑鲸会员体验卡发放约200万，使用转化率达40%。

* 与华为合作的40+ A/B类网媒资源带来的活动宣传流量和口碑。

* 借助华为会员中心流量，为合作伙伴提供多种导流服务，提升精准曝光，扩大会员体量。

#### 用户受益

免费领取同程旅行价值99元黑鲸会员卡，享受高品质出行服务权益。
