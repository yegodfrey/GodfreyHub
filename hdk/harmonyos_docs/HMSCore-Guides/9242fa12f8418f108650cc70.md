# 快应用

## 快应用介绍

华为快应用是一种新型免安装应用。相比于传统Android应用，具有以下优点：

* 成本低，代码量是传统应用的五分之一，开发语言简单，主要有Java Script和Cascading Style Sheets(CSS)。
* 体验好，原生渲染并且可以访问系统。
* 留存高，无需安装并且可以引导用户添加到桌面。

推送服务支持向华为快应用推送消息的能力。

## 开发准备

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

1. 注册成为开发者
2. 创建快应用
3. 生成证书指纹
4. 开通推送服务

详情请参见[快应用开发指南](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-create-quickapp-0000001079835824)。

## 开发指导

### 申请Token

如何申请Token请参见[接入Push服务](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-access-push-kit-0000001126547701)。

### 发送消息

快应用推送消息是通过设置自定义消息负载（即消息类型为透传消息）进行消息推送，消息内容由快应用引擎进行解析，以下是快应用消息体中具体的参数字段：

|**参数** **值**|**取值类型**|**必选(M)/** **可选(O)**|**参数说明**|
|:-----------|:---------------------------------------------------------------|:-------------------|:-------------------------------------------------------------------------------|
|pushtype|Integer|M|快应用推送消息类型，取值如下： * 0：通知栏消息 * 1：透传消息|
|pushbody|[PushBody](#ZH-CN_TOPIC_0000001652651336__p1552120481573) Object|M|快应用推送消息体，结构说明请参见[PushBody](#ZH-CN_TOPIC_0000001652651336__p1552120481573)结构体的定义。|

**PushBody**

|**参数** **值**|**取值类型**|**必选(M)/** **可选(O)**|**参数说明**|
|:-----------|:-------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------|
|title|String|O|通知栏消息标题。|
|description|String|O|通知栏消息内容。|
|page|String|O|点击通知栏消息跳转到的快应用界面的path。|
|params|Object|O|点击通知栏消息跳转到快应用界面时可携带的数据。样例：{\"key1\":\"test1\",\"key2\":\"test2\"}。 > 说明 > 当pushtype=0时，不携带params参数消息可以发送成功，但不会展示该条通知栏消息。|
|messageId|String|O|透传消息的ID。|
|data|String|O|透传消息携带的内容。|

**您可以通过两种方式推送消息：**

* 在AppGallery Connect网站发送：适用选取部分目标用户发送，支持推送到现网的快应用和加载器上运行的快应用，详情请参见[快应用消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-quickapp-0000001136453988)。
* 通过[服务端接口发送](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-access-push-kit-0000001126547701#section1645612260410)：适用面向大批量用户发送，支持推送到现网的快应用和加载器上运行的快应用。

满足如下前提条件的快应用才可以接收到PUSH消息：

|消息类型|前提条件|
|:----|:----------------------------------------------------------------------------------------------------------------------|
|通知栏消息|快应用必须有使用记录，并满足如下条件之一： * 快应用中心低于3.2.1版本：在桌面有快捷方式的快应用、 加入"我的快应用"的快应用、 快应用处于运行状态 * 快应用中心从3.2.1版本开始：在桌面有快捷方式的快应用、加入"收藏"的快应用|

> 说明
>
> * 如果使用华为快应用加载器进行调试，必须确保加载器进程处于运行状态。
> * 如果手机安装了手机管家，请务必在"自启动"选项中，将快应用中心的开关打开。
> * 可参考[示例代码](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-access-push-kit-0000001126547701#section174521722124520)进行开发适配您的快应用。
