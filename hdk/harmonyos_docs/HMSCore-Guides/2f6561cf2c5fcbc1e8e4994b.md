# 距离计算

根据经纬度计算两点之间的直线距离。  

#### 实现步骤

1. 通过HWMapJsSDK初始化[HWDistanceCalculator](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwdistancecalculator-0000001052863506)对象。
2. 通过创建的[HWDistanceCalculator](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwdistancecalculator-0000001052863506)对象调用computeDistanceBetween方法，传入两点的经纬度、球体半径（可选）。
3. 返回值为两点之间的直线距离，单位：米。  

#### 示例代码

```
var DistanceClass = new HWMapJsSDK.HWDistanceCalculator();
var fromPostion = {lng: 2.35, lat: 48.85};
var toPosition = {lng: 2.33, lat: 48.75};
var distance = DistanceClass.computeDistanceBetween(fromPostion, toPosition);
```
