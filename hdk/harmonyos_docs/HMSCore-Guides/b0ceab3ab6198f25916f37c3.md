# 原生广告

原生广告是与应用内容融于一体的广告，通过"和谐"的内容呈现广告信息，在不破坏用户体验的前提下，为用户提供有价值的信息，展示形式包含图片、文字和视频，支持您自由定制界面。

## 添加原生广告

1. 构建NativeAdLoader。

   [NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloader-0000001050064916)类提供了[NativeAdLoader.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloader-builder-0000001050066865)类，可用于设置广告位ID、设置自定义选项和构建[NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloader-0000001050064916)对象。示例代码如下所示：

   ```java
   "Java"
   // "testy63txaom86"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID
   NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
   builder.setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
       @Override
       public void onNativeAdLoaded(NativeAd nativeAd) {
           // 广告加载成功后调用
           ...
       }
   }).setAdListener(new AdListener() {
       @Override
       public void onAdFailed(int errorCode) {
           // 广告加载失败时调用
           ...
       }
   });
   NativeAdLoader nativeAdLoader = builder.build();
   ```

   ```java
   "Kotlin"
   // "testy63txaom86"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID
   val builder = NativeAdLoader.Builder(this, "testy63txaom86")
   builder.setNativeAdLoadedListener { nativeAd ->
       // 广告加载成功后调用
       ...
   }.setAdListener(object : AdListener() {
       override fun onAdFailed(errorCode: Int) {
           // 广告加载失败时调用
           ...
       }
   })
   val nativeAdLoader = builder.build()
   ```

   当加载广告成功后，SDK会调用[NativeAd.NativeAdLoadedListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloadedlistener-0000001050064908)监听器的onNativeAdLoaded()方法返回[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855)对象。

   当加载广告失败后，SDK会调用[AdListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adlistener-0000001050066825)监听器的onAdFailed()方法。
   > 说明
   >
   > errorCode详情请参见[Android错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-error-code-0000001130129080)。

2. 加载广告。

   [NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloader-0000001050064916)提供loadAd()和loadAds()两种方法加载广告。
   * loadAd()请求单个原生广告。

     [AdParam](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-0000001050066827)是唯一的参数。调用loadAd()后，SDK将对添加的监听器方法进行一次成功或失败的回调。示例代码如下所示：

     ```screen
     "Java"
     nativeAdLoader.loadAd(new AdParam.Builder().build());
     ```

     ```screen
     "Kotlin"
     nativeAdLoader.loadAd(AdParam.Builder().build())
     ```

   * loadAds()请求多个原生广告。

     loadAds()请求有两个参数，除[AdParam](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-0000001050066827)外，"maxAdsNum"是请求加载的最大广告数量，最大值为5。SDK返回的广告数量将会小于等于所请求的广告数量。示例代码如下所示：

     ```screen
     "Java"
     nativeAdLoader.loadAds(new AdParam.Builder().build(), 5);
     ```

     ```screen
     "Kotlin"
     nativeAdLoader.loadAds(AdParam.Builder().build(),5)
     ```

     当加载广告成功后，SDK会多次调用[NativeAd.NativeAdLoadedListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloadedlistener-0000001050064908)监听器的onNativeAdLoaded()方法分别返回一个[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855)对象，在广告都返回后再调用[AdListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adlistener-0000001050066825)监听器的onAdLoaded()方法回调通知此次请求成功；当加载广告失败后，SDK会调用[AdListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adlistener-0000001050066825)监听器的onAdFailed()方法。示例代码如下所示：

     ```java
     "Java"
     // "testy63txaom86"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID
     NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
     NativeAdLoader nativeAdLoader = builder.setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
         @Override
         public void onNativeAdLoaded(NativeAd nativeAd) {
             // 广告加载成功回调，多个广告对应多个回调
             ...
         }
     }).setAdListener(new AdListener() {
         @Override
         public void onAdLoaded() {
             // 广告全部返回后回调，说明所有广告返回成功
             ...
         }
         @Override
         public void onAdFailed(int errorCode) {
             // 广告加载失败回调
             ...
         }
     }).build();
     AdParam.Builder builder = new AdParam.Builder();
     // 可选 设置实时bidding广告位参数
     BiddingParam biddingParam = new BiddingParam();
     String slotId = "testy63txaom86";
     builder.addBiddingParamMap(slotId, biddingParam);
     builder.setTMax(500);
     builder.setCur("币种字符列表");
     nativeAdLoader.loadAds(new AdParam.Builder().build(), 5);
     ```

     ```java
     "Kotlin"
     // "testy63txaom86"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID。
     val builder = NativeAdLoader.Builder(this, "testy63txaom86")
     val nativeAdLoader = builder.setNativeAdLoadedListener {
         // 广告加载成功回调，多个广告对应多个回调
         ...
     }.setAdListener(object : AdListener() {
         override fun onAdLoaded() {
             // 广告全部返回后回调，说明所有广告返回成功
             ...
         }
         override fun onAdFailed(errorCode: Int) {
             // 广告加载失败回调
             ...
         }
     }).build()
     nativeAdLoader.loadAds(AdParam.Builder().build(), 5)
     ```

     > 说明
     > * 再次使用[NativeAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloader-0000001050064916)加载广告前，请确保先前的请求已经完成。
     > * errorCode详情请参见[Android错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-error-code-0000001130129080)。

3. 展示原生广告。

   获取到广告后在监听器的回调方法中展示原生广告，需要在每个广告视图的一角展示["为什么显示此广告"图标"i"](#ZH-CN_TOPIC_0000001057043311__p121161372118)或["不再显示此广告"图标"x"](#ZH-CN_TOPIC_0000001057043311__p1487293941716)，并且必须展示广告标识。
   > 说明
   >
   > 以下两种方案可二选一：
   >
   > 方案一：点击图标"x"后，出现"隐藏广告"和"为什么看到此广告"的视图，就不用做"i"图标；
   >
   > 方案二：仅做直接关闭广告的"x"图标，就保留一个"i"图标。

   以下是展示原生广告的步骤：
   1. 定义原生广告布局。 需要自定义一个布局用于展示[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855)中的素材。

      > 说明
      >
      > 必须将[NativeView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeview-0000001050064918)作为原生广告的根布局，否则会影响广告收益。

      对于使用RelativeLayout来展示素材视图的原生广告，其视图层次结构示例如下：

      ```screen
      <com.huawei.hms.ads.nativead.NativeView xmlns:android="http://schemas.android.com/apk/res/android"
          android:orientation="vertical"
          android:layout_width="match_parent"
          android:layout_height="wrap_content"
          ... >
          <RelativeLayout
              android:layout_width="match_parent"
              android:layout_height="wrap_content"
              ... >
              <!-- 多媒体视图 -->
              <com.huawei.hms.ads.nativead.MediaView
                  android:id="@+id/ad_media"
                  android:layout_width="75dp"
                  android:layout_height="50dp"
                  ... />
              <RelativeLayout
                  ... >
              <TextView
                  android:id="@+id/ad_title"
                  android:layout_width="match_parent"
                  android:layout_height="34dp"
                  ... />
              <!-- 其他素材 -->
              ...
              </RelativeLayout>
              <!-- 其他素材 -->
              ...
          </RelativeLayout>
      </com.huawei.hms.ads.nativead.NativeView>
      ```

   2. 注册和填充素材视图。 获取到[NativeView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeview-0000001050064918)对象后，需要注册和填充素材。

      注册和填充标题、多媒体的示例代码如下所示：

      ```java
      "Java"
      private void initNativeAdView(NativeAd nativeAd, NativeView nativeView) {
          // 注册和填充标题素材视图
          nativeView.setTitleView(nativeView.findViewById(R.id.ad_title));
          ((TextView) nativeView.getTitleView()).setText(nativeAd.getTitle());
          // 注册和填充多媒体素材视图
          nativeView.setMediaView((MediaView) nativeView.findViewById(R.id.ad_media));
          nativeView.getMediaView().setMediaContent(nativeAd.getMediaContent());
          // 注册和填充其他素材视图
          nativeView.setAdSourceView(nativeView.findViewById(R.id.ad_source));
          nativeView.setCallToActionView(nativeView.findViewById(R.id.ad_call_to_action));
          if (null != nativeAd.getAdSource()) {
              ((TextView) nativeView.getAdSourceView()).setText(nativeAd.getAdSource());
          }
          nativeView.getAdSourceView()
                  .setVisibility(null != nativeAd.getAdSource() ? View.VISIBLE : View.INVISIBLE);
          if (null != nativeAd.getCallToAction()) {
              ((Button) nativeView.getCallToActionView()).setText(nativeAd.getCallToAction());
          }
          nativeView.getCallToActionView()
                  .setVisibility(null != nativeAd.getCallToAction() ? View.VISIBLE : View.INVISIBLE);

          // 注册原生广告对象
          nativeView.setNativeAd(nativeAd);
      }
      ```

          "Kotlin"
          private fun initNativeAdView(nativeAd: NativeAd?, nativeView: NativeView) {
              // 注册和填充标题素材视图
              nativeView.titleView = nativeView.findViewById(R.id.ad_title)
              (nativeView.titleView as TextView).text = nativeAd!!.title
              // 注册和填充多媒体素材视图
              (nativeView.titleView as TextView).text = nativeAd!!.title
              nativeView.mediaView.setMediaContent(nativeAd.mediaContent)
              // 注册和填充其他素材视图
              nativeView.adSourceView = nativeView.findViewById(R.id.ad_source)
              nativeView.callToActionView = nativeView.findViewById(R.id.ad_call_to_action)
              if (null != nativeAd.adSource) {
                  (nativeView.adSourceView as TextView).text = nativeAd.adSource
              }
              nativeView.adSourceView.visibility = if (null != nativeAd.adSource) View.VISIBLE else View.INVISIBLE
              if (null != nativeAd.callToAction) {
                  (nativeView.callToActionView as Button).text = nativeAd.callToAction
              }
              nativeView.callToActionView.visibility = if (null != nativeAd.callToAction) View.VISIBLE else View.INVISIBLE
          }

      依次设置其他要展示的广告素材。

      [MediaView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mediaview-0000001050066853)用于展示多媒体素材。如果获取的广告含有视频素材，则视频会在[MediaView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mediaview-0000001050066853)内播放。否则[MediaView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mediaview-0000001050066853)会显示一个图片素材。
   3. 向NativeView注册原生广告对象。

      示例代码如下所示：

      ```screen
      "Java"
      nativeView.setNativeAd(nativeAd);
      ```

      ```screen
      "Kotlin"
      nativeView.setNativeAd(nativeAd)
      ```

   4. 展示NativeView。

      将[NativeView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeview-0000001050064918)添加到界面即可展示原生广告。示例代码如下所示：

      ```java
      "Java"
      private void loadAd() {
          NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
          builder.setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
              @Override
              public void onNativeAdLoaded(NativeAd nativeAd) {
                  ...
                  // 获取NativeView视图
                  NativeView nativeView = (NativeView) getLayoutInflater().inflate(R.layout.ad_native, null);
                  // 注册和填充原生广告素材视图
                  initNativeAdView(nativeAd, nativeView);
                  // 将NativeView添加到界面
                  FrameLayout adFrameLayout = findViewById(R.id.frame_layout_ad);
                  adFrameLayout.removeAllViews();
                  adFrameLayout.addView(nativeView);
                  ...
              }
          });
          ...
      }
      private void initNativeAdView(NativeAd nativeAd, NativeView nativeView) {
          // 注册和填充标题素材视图
          nativeView.setTitleView(nativeView.findViewById(R.id.ad_title));
          ((TextView) nativeView.getTitleView()).setText(nativeAd.getTitle());
          // 注册和填充多媒体素材视图
          nativeView.setMediaView((MediaView) nativeView.findViewById(R.id.ad_media));
          nativeView.getMediaView().setMediaContent(nativeAd.getMediaContent());
          // 注册和填充其他素材视图
          ...
          // 注册原生广告对象
          nativeView.setNativeAd(nativeAd);
      }
      ```

          "Kotlin"

              builder.setNativeAdLoadedListener { nativeAd ->
                  // 获取NativeView视图

                  // 注册和填充原生广告素材视图

   为原生广告添加事件监听器的示例代码如下所示：

   ```java

       @Override
       public void onAdClicked() {
           // 广告点击时调用
           ...
       }
       ...
   }).build();
   ```

       "Kotlin"
       val nativeAdLoader = builder.setAdListener(object : AdListener() {
           override fun onAdClicked() {
               // 广告点击时调用
               ...
           }
           ...
       }).build()

5. 销毁广告。

   当原生广告不再展示时，应将其销毁。示例代码如下所示：

   ```screen
   "Java"
   nativeAd.destroy();
   ```

   ```screen
   "Kotlin"
   nativeAd!!.destroy()
   ```

## 原生广告模板

为了方便您快速实现原生广告的展示，我们提供了三套原生广告模板，可以集成到应用中使用。

## 原生广告下载按钮控件

### 自定义版"不再显示该广告"

* 通过[NativeAdConfiguration.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadconfiguration-builder-0000001050064912)类中的[setRequestCustomDislikeThisAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadconfiguration-builder-0000001050064912#section1834017475137)()方法可以设置是否要自定义"不再显示该广告"。当设置为自定义版"不再显示该广告"时，原生广告将会显示"为什么看到此广告"图标。如果需要隐藏"为什么看到此广告"图标，可调用[NativeAdConfiguration.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadconfiguration-builder-0000001050064912)类中的[setChoicesPosition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadconfiguration-builder-0000001050064912#section8995193618112)()方法将其设置为不可见。

  示例代码如下所示：

  ```java
  "Java"
  NativeAdConfiguration adConfiguration = new NativeAdConfiguration.Builder()
      // 需要自定义"不再显示该广告"
      .setRequestCustomDislikeThisAd(true)
      // 隐藏"为什么看到此广告"图标
      .setChoicesPosition(NativeAdConfiguration.ChoicesPosition.INVISIBLE)
      .build();
  NativeAdLoader nativeAdLoader = builder.setNativeAdOptions(adConfiguration).build();
  ```

  ```java
  "Kotlin"
  val adConfiguration = NativeAdConfiguration.Builder()
      // 需要自定义"不再显示该广告"
      .setRequestCustomDislikeThisAd(true)
      // 隐藏"为什么看到此广告"图标
      .setChoicesPosition(NativeAdConfiguration.ChoicesPosition.INVISIBLE)
      .build()
  val nativeAdLoader = builder.setNativeAdOptions(adConfiguration).build()
  ```

  > 说明
  >
  > 若要隐藏"为什么看到此广告"图标，则需要在自定义广告选项列表中添加"为什么看到此广告"选项。当点击"为什么看到此广告"选项时，调用[NativeView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeview-0000001050064918)类中的[gotoWhyThisAdPage](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855#section1643310455369)()方法即可跳转到"为什么看到此广告"的页面。
* 当原生广告加载完成时，可调用[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855).[isCustomDislikeThisAdEnabled](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855#section1877511465318)()判断是否已设置为要自定义"不再显示该广告"。另外，可通过[NativeAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855).[getDislikeAdReasons](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855#section112031533162010)()方法获取"不再显示该广告"的信息列表，然后将其显示在您自定义界面中。

### 展示广告主信息

原生广告未通过com.huawei.hms.ads.nativead.NativeAdConfiguration.Builder#setChoicesPosition接口隐藏adChoice控件时，无需额外适配，在有广告主信息时，SDK在展示广告时，会在adChoice控件点击时展示广告主信息；当隐藏adChoice控件时，需要在展示广告时，自行渲染广告主信息控件，用户点击控件时，调用NativeView提供的接口展示广告主信息控件。

示例代码：

```screen
"Java"
// advertiserIcon为自渲染的图标。
NativeAdLoader.Builder builder = new NativeAdLoader.Builder(context, adId)
    .setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
        @Override
        public void onNativeAdLoaded(NativeAd ad) {
            if (!ad.hasAdvertiserInfo()) {
                advertiserIcon.setVisibility(View.GONE); // 未下发广告主信息时，隐藏广告主信息图标。
            }
        }
    });
advertiserIcon.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        if (nativeAd.hasAdvertiserInfo()) { // 下发广告主信息时，调用接口拉起广告主信息弹框
            nativeView.showAdvertiserInfoDialog(advertiserIcon, true);
        }
    }
});
```

### 展示关联启动文案

* 判断[getInterActionType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855#section553417212213)()为0/1/2，即纯展示广告、网页推广、应用下载时，保持初始UX不变，即不显示跳转文案，只显示广告标签和广告来源。
