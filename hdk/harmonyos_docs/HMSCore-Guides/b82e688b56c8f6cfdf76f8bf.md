# 运动健康

分析服务支持运动健康行业分析，可以清晰洞察应用的关键指标数值，从数据概览、付费分析、行为分析和社区与售后等多维度了解用户的运动和健康状态，帮助制定精准的营销方案和产品策略。  

#### 典型应用场景

* 查看新增付费会员数、付费会员收入、课程销售额、会员购买路径了解用户付费情况。
* 基于用户行为分析，包括课活动目标完成率、运动时长等了解用户的运动类型偏好。  

#### 前提条件

已在"智能数据接入 \> 埋点开发"中配置了运动健康行业模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。  

#### 案例

某运动App想要查看近期用户新增付费情况以及了解其中最受欢迎的运动种类，制定相应的促销计划。

需求：查看App用户付费情况及热门运动类型。  

#### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。

<!-- -->

3. 选择"华为分析 \> 行业分析"，进入"运动健康"分析界面。
4. 查看运动类App数据概览。详情请参见[数据概览](#section155928554279)。
5. 查看运动类App核心营收指标。详情请参见[付费分析](#section659519556274)、[行为分析](#section0598165516279)和[社区与售后](#section86005557278)。
