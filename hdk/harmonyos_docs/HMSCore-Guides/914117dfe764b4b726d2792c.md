# 业务简介

服务商分账主要用于帮助特约商户完成订单收单成功后的资金分配。

## 场景介绍

**服务商抽成**

服务商为特约商户提供技术支持等增值服务，根据服务商与特约商户的协议约定，服务商可以从特约商户的订单款中抽取一定的技术服务费。

**分润给合作伙伴**

特约商户因业务需要，与其他合作方合作，根据协议约定，将订单款分给合作商户，如：物流供应商、主播等。

> 说明
>
> 收单方：一笔订单的实际资金入账方。服务商作为交易发起方，调用收单接口，收单方为对应的特约商户。
>
> 分账发起方：发起分账的一方，这里指服务商或平台类商户。
>
> 分账方：资金分账的出资方，也是对应交易的收单方。
>
> 分账接收方：指资金分账的收款方，要求与分账方之间存在分账关系。分账接收方可以是特约商户绑定的服务商；也可以是特约商户自行添加的其他合作商户。
>
> 分账资金流：资金流从分账方流出，流入分账接收方。
