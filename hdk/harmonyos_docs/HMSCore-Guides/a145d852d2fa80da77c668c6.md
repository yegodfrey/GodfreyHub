# 与运动健康App对接测试

## 安装测试程序

从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library/sport-device-sdk-0000001051809026)的开发套件中获取 HuaweiHealth-test.apk（华为运动健康App测试版），将其安装在手机上。可以通过以下两种方式进行安装。

* 将 Android 手机连接至电脑 USB 口，打开电脑的cmd窗口，通过adb方式安装测试程序。如下图所示：

  ```screen
  adb install -r E:\HealthSDK\HuaweiHealth-test.apk
  ```

  ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a/v3/l-qbu6mLQy2iVncDl2gzpw/zh-cn_image_0000002547959131.png?HW-CC-KV=V1&HW-CC-Date=20260909T130439Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1506814AFE0444E7EE594EB2D98C9B7E10ADED208CC49D3F44D40F7EC6FEA69 "点击放大")

  提示Success表示安装成功。如果安装失败，请检查手机上是否已经存在运动健康程序，卸载后再执行以上安装步骤即可。
* 如果无法通过adb方式安装测试程序，可以将程序拷贝到手机SD卡上，直接在手机上点击安装即可。

## 使用自测程序

1. 在测试过程中，确保测试手机的网络（移动网络/WLAN）处于关闭状态（防止云端资源和本地测试资源出现冲突而造成本地资源无法显示的现象）。在手机上打开安装后的运动健康App，选择"我的">"设置">"设备测试"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/lD_EfdUwRfacRb5-RDlt3w/zh-cn_image_0000002547959139.png?HW-CC-KV=V1&HW-CC-Date=20260909T130439Z&HW-CC-Expire=31536000000&HW-CC-Sign=1CCC81BDDDF1A31D7689AB7F4AA372FEC89A42E3E9E98B39DEE43C3D5FAEF4E6 "点击放大")


2. 将素材资源包拷贝到在手机 SD 卡上。然后点击测试程序上的"设备接入"按钮，在弹出的文件浏览框中选中"文件管理"，然后在相应的目录下找到资源包"resource.zip"（resource.zip 是通过打包素材资源文件生成的资源包）。点击确定后程序将跳转到以下界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3e/v3/ool0q0gsT3y88-a80XFvDQ/zh-cn_image_0000002548039133.png?HW-CC-KV=V1&HW-CC-Date=20260909T130439Z&HW-CC-Expire=31536000000&HW-CC-Sign=6A15A6595C71EEF06B803A4F562187E47ED2100C404BAB26F939C4D1E6F6C640 "点击放大")

3. 按程序向导，点击"添加"新设备，选择对应的设备类型和产品，找到导入资源的设备，完成设备绑定。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b7/v3/8bqIPadBSayEIv5GLfiezQ/zh-cn_image_0000002516519238.png?HW-CC-KV=V1&HW-CC-Date=20260909T130439Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C599EC51C96D194FBD5342F59C38FC7BD210CC821155A17831195D56935D574 "点击放大")

4. 点击该设备开始扫描设备操作，请确保蓝牙设备处于广播状态。
5. 点击该设备后，就完成了绑定设备的操作。跳转到如下页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/28/v3/w6O-Lb0ZQOC1ihe0PJjvhw/zh-cn_image_0000002548039125.png?HW-CC-KV=V1&HW-CC-Date=20260909T130439Z&HW-CC-Expire=31536000000&HW-CC-Sign=A75B9BF926E3C981407A5C82F9023751336967172995072236185C50B9026999)

6. 当前apk心率设备的使用是配合跑步时候显示心率，点击感受心率开始跑步。则进入到以下页面，页面显示心率数据说明接入设备的功能正常。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/xkM-fxD9SdyWdkq5D3DIVw/zh-cn_image_0000002547959133.png?HW-CC-KV=V1&HW-CC-Date=20260909T130439Z&HW-CC-Expire=31536000000&HW-CC-Sign=4721E94D4047998E317F51F40ADA3D714FC1522304EF6F71BE9E147B2A9B326C)

   如果开发者接入的是非心率设备，假设为血压设备，前面的使用操作是一样的，最后绑定设备成功后，跳转到数据自动回传方法介绍页面。如下所示。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/IZJKWwblShe19NNdc8HvEA/zh-cn_image_0000002548039131.png?HW-CC-KV=V1&HW-CC-Date=20260909T130439Z&HW-CC-Expire=31536000000&HW-CC-Sign=268F154A1EB35F1A612F79903BB44E87635018140F94B8A73B26645D0C025A17 "点击放大")
