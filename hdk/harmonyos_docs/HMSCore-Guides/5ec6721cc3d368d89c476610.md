# 基于第三方审核结果的消息推送

推送服务禁止推送包含敏感词的消息，建议您在推送消息前先接入三方机构的审核平台对推送消息内容进行审核，然后使用推送服务推送消息，避免您的消息存在可疑敏感词内容无法推送至目标用户。
> 说明
>
> 推送服务的敏感词列表和规则不对外提供，需要您自行接入第三方审核平台检测。

1. 登录[推必安](https://tuibian.mobileservice.cn/)网站，注册帐号。
2. 与推必安审核平台建立请求。

   **请求地址：**

   ```screen
   POST https://push.tuibianchina.com/v1/token
   ```

   **请求参数：**

   |字段|数据类型|说明|
   |:--------------|:-----|:-----------------------------------------|
   |accessKeyId|string|开发者accessKeyId，申请通过后可在"推必安官⽹-开发者信息"⻚获取。|
   |signatureMethod|string|签名⽅法，⽬前⽀持"HMAC-SHA256"。|
   |signatureNonce|string|随机字符串，36个字符以内。每次请求时⽆论成功失败，必须重新⽣成。|
   |timestamp|string|秒级时间戳，字符串格式，与服务器时间相差必须在5分钟以内。如：1659943094。|
   |signature|string|签名，签名⽅式请⻅下方示例。|

   签名生成方法：
   1. 申请通过后，在推必安官⽹开发者中⼼可获取accessKeyId及accessKeySecret。
   2. 将accessKeyId、signatureMethod、signatureNonce和timestamp四个字段按照顺序使⽤符号"&"拼接成字符串。
   3. 使⽤accessKeySecret作为"key"，以"HMAC-SHA256"⽅法对上一步⽣成的字符串进⾏签名 。
   4. 对第3步得到的结果进⾏"base64"处理，得到最终的"signature"。
   5. 伪代码如下：

      ```screen
      const accessKeyId = "a064325ab3******e891c316ab6"
      const accessKeySecret = "598661b6*******8f8e448130" 
      const signatureMethod = "HMAC-SHA256" 
      const signatureNonce = "93fea3da-72******a-e37c88cd3e17" 
      const timestamp = time.Now().Timestamp() 

      //拼接字符串
      const unsignedText = accessKeyId + "&" + signatureMethod + "&" + signatureNonce + "&" + timestamp
      // 使用HMAC-SHA256对unsignedText签名
      const rawSign = signWithHmacSha256(unsignedText, accessKeySecret)
      // 使用base64加密rawSign
      const signature = base64Encode(rawSign) 
      ```

   **返回值**：

   当服务器端正常返回时，会返回如下信息：

   |字段|数据类型|说明|
   |:--------|:-----|:--------------------|
   |code|int|200表示请求成功，非200表示请求错误。|
   |msg|string|响应内容。|
   |data|JSON|返回数据。|
   |ts|int|时间戳。|
   |requestId|string|请求ID。|

   data：

   |字段|数据类型|说明|
   |:----------|:-----|:--------------------|
   |expiresIn|int|accessToken有效时间，单位：秒。|
   |accessToken|string|调⽤⽂本审核接⼝时的凭证。|

   **请求示例：**

   ```screen
   {
       "accessKeyId": "9ea93*******4168a3061",
       "signatureMethod": "HMAC-SHA256",
       "signatureNonce": "d04*****e7c4d",
       "timestamp": "1660200514",
       "signature": "NJiXVZt2EnVs7k3*******hqigkA6uwM+yXqmU="
   }
   ```

   **返回示例：**

   错误返回

   ```screen
   {
       "code": 40010,
       "ts": 1659421654502,
       "requestId": "b86baf0f********eb5567dca28a",
       "msg": "INVALID SIGNATURE"
   }
   ```

   正常返回

   ```screen
   {
       "code": 200,
       "ts": 1659421654502,
       "requestId": "92******15476",
       "msg": "ok",
       "data": {
           "accessToken": "IDp7WVJyJV**********XlbCkd7LWA",
           "expiresIn": 604800 
       }
   }
   ```

3. 与推必安文本审核接口建立请求。

   **请求地址：**

   ```screen
   POST https://push.tuibianchina.com/v1/audit
   ```

   **请求头参数：**

   ```http
   Content-Type: application/json
   Audit-Access-Token: f3a*****4d0
   ```

   > 说明
   >
   > "Audit-Access-Token"为上一步成功响应获取的"accessToken"。

   **请求示例：**

   ```screen
   {
       "pkg": "com.test",
       "content": "{\"android\":{\"collapse_key\":0,\"notification\":{\"click_action\":{\"type\":2,\"url\":\"https://example.com\"}}},\"notification\":{\"body\":\"message body\",\"title\":\"message title\"}}"
   }
   ```

   > 说明
   >
   > "pkg"为您的应用包名，"content"为[消息体内容](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p153162820230)中token、topic、condition字段去掉后，再对剩余字段按ASCII码升序排序后的消息结构体，最大长度为10000。
   >
   > "content"对应的原始请求体示例：
   >
   > ```screen
   > {
   >     "validate_only": false,
   >     "message": {
   >         "notification": {
   >             "title": "message title",
   >             "body": "message body"
   >         },
   >         "android": {
   >             "collapse_key": 0,
   >             "notification": {
   >                 "click_action": {
   >                     "type": 2,
   >                     "url": "https://example.com"
   >                 }
   >             }
   >         },
   >         "token": [
   >             "pushtoken1"
   >         ]
   >     }
   > }
   > ```

   **响应体示例（文本审核通过）：**

   ```screen
   {
       "code": 200,
       "data": {
           "auditEngine": "bjgyy",
           "auditId": "83bae******fb95605",
           "labels": []
       },
       "msg": "Pass",
       "sign": "Viej********oBoF9uW8+RsF0HI="
   }
   ```

   > 说明
   > * "code"表示响应码，"200"为通过。
   > * 如果您的审核文本存在敏感词，响应体会将敏感词显示在"labels"中。
   > * 更多字段值和响应码内容详情请参见[推必安内容审核系统接口文档](https://tuibian.mobileservice.cn/static_dl/推必安内容审核系统接口文档.pdf)。

4. 将推必安返回的审核结果放在[Review](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1259423618254)结构体中的"result"对象中，调用[下行消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-server-dev-0000001050040110)API推送消息。

   消息体示例：

   ```screen
   {
       "validate_only": false,
       "message": {
           "notification": {
               "title": "message title",
               "body": "message body"
           },
           "android": {
               "collapse_key": 0,
               "notification": {
                   "click_action": {
                       "type": 2,
                       "url": "https://example.com"
                   }
               }
           },
           "token": [
               "pushtoken1"
           ]
       },
       "review": [
           {
               "reviewer": "tuibian",
               "type": 0,
             "result": {
   "code": 200,
   "data": {
   "auditEngine": "t****ine",
   "auditId": "0f74b*******0b3f490d",
   "labels": []
   },
   "msg": "Pass",
   "sign": "MEQCIBHc********IqLjw=="
   }
           }
       ]
   }
   ```

5. 只有当推必安的"code"值为"200"时，推送服务不会拦截。若您发送的消息，被系统误判或者对系统处理的方式有争议，请提供应用名、应用包名、发送时间、发送内容、存在争议的内容通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=111)与我们进行联系，我们将进行分析优化，感谢您的支持与理解。
