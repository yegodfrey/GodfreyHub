# 概述

华为数字车钥匙依托华为钱包数字车钥匙业务集成方案，基于华为手机"芯-端-云"一体化的安全能力，且满足ICCE标准，可快速实现手机模拟车钥匙的功能。

相较于传统的车钥匙，华为数字车钥匙无需借助车钥匙实体，仅将车钥匙功能集成在移动智能终端设备中，基于SE、TEE等安全功能，使用蓝牙、NFC技术连接手机和车，即可实现车辆的开门、启动等功能。
> 说明
>
> 此方式当前仅支持中国大陆区域。

## 整体架构

数字车钥匙的整体架构如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/PBixfaI6RPWV0C-zmqTYZA/zh-cn_image_0000001666657306.png?HW-CC-KV=V1&HW-CC-Date=20260909T170653Z&HW-CC-Expire=31536000000&HW-CC-Sign=6DF5047DF757D26A2749D6AB21B03245542C37938B58CD26A261B65BD0FDB295 "点击放大")

* 按照参与各方的角色划分如下:

  |角色|角色描述|
  |:---------|:---------------------------------------------------------|
  |DK|数字钥匙|
  |车钥匙 Applet|各车厂共用一个Applet实例，通过ADF隔离，华为提供安全通道供车厂将秘钥以及车厂独有的数据写入Applet实例。|
  |鸿蒙OS|鸿蒙操作系统|
  |BLE|低功耗蓝牙|
  |NFC|近场通信|

* 典型的交互流程如下: 用户持手机在车主APP申请开通车钥匙：

  a) DK业务管理服务将钥匙卡片信息通过钱包云服务器传递给华为钱包，同时写入到手机安全芯片的车钥匙 Applet实例。

  车辆和移动终端的通信方式：

  a) 车辆NFC模块（通常位于主驾后视镜，主驾B柱），使用NFC通道和终端设备安全芯片通信。

  b) 车辆BLE模块，通过蓝牙通道，使用终端设备上的华为钱包，和终端设备的安全芯片通信。
