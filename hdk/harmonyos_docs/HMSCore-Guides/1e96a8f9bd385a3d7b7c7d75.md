# 获取服务端 API level

![](https://media:901788166655609219)  
* 调用该接口前无需授权。
* 若集成的 SDK 为 5.0.0.500 及之前版本，无此接口。

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [getApiLevel](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__getApiLevel-android_content_Context-com_huawei_hihealth_listener_ResultCallback-) 接口，获取服务端 API level。
2. 通过请求参数对象 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451)，返回查询结果。

   <br />

   示例代码：

   ```
   HiHealthDataStore.getApiLevel(context, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object message) {
           if (resultCode == HiHealthError.SUCCESS) {
               Log.i(TAG, "getApiLevel success");
               if (message instanceof Integer){
                   int apiLevel = (int) message;
                   Log.i(TAG," apiLevel:" + apiLevel);
               }
           } else {
               // 其他错误，建议提示调用失败
               Log.w(TAG, "Other error, invoking method failed");
         }
       }
   });
   ```

   |参数名称|参数类型|参数描述|可选选项|
   |:------------------|:-------------|:---|:----|
   |getApiLevelcallback|ResultCallback|结果回调|必选(M)|
   [表1 请求参数]

   |参数名称|参数类型|参数描述|可选选项|
   |:---------|:-----|:------------------------------------------------------------------------------------------------------------------------|:----|
   |resultCode|int|处理结果码 * 0：成功 * 其他：参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-errocode-0000001053256958)|必选(M)|
   |message|Object|服务端apilevel值（int）|必选(M)|
   [表2 响应参数]
