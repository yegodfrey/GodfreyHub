# 集成SDK

#### 采用本地方式集成SDK

在“assets/Lib”目录下放入hw-hmscore-analytics-sdk-quickgame-xx.xx.xx.esm.js和agconnect-quickgame-xx.xx.xx-min.js文件，并在Cocos Creator中设置为“导入为插件”。
