# 快应用

本章节主要介绍接入服务号Javascript SDK的开发步骤，以帮助您快速了解服务号提供的JS-SDK接口及其调用方法。

本章节所面向的主要**开发者** 为**已****开通服务号** 的商家，并希望在自有的或者待开发的快应用中接入服务号能力。

#### 开发流程

序号 | 步骤 | 说明  
---|---|---  
1 | 开发准备 | 
                * 注册成为开发者。
                * 创建快应用。  
2 | 获取顶层对象 | 启动第三方NPM库构建，获取HBT顶层对象。  
3 | 实现关注接口 | 使用agreeFollow接口，传入参数实现用户对商家服务号的关注。  
4 | 申请上架 | 参见[快应用上架指南](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-prepare-doc-0000001129385459)，上架快应用。  
  
#### 开发准备

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

                1. 注册成为开发者
                2. 创建快应用

详情请参见[快应用开发指南](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-jssdk-hwservice-0000001079488508)。

#### 开发步骤

                1. 参见[快应用开发指南](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-jssdk-hwservice-0000001079488508)，启动第三方NPM库构建。

请确保在除app.ux页面外的UX文件中引用和依赖相关接口。

                2. 在快应用加载器中通过NPM方式下载资源，在cmd命令行中执行如下命令。
                       
                       npm install @hmscore/hms-js-hbt
                       备注：小程序转快应用在打包前需要执行npm install（1090+）

                3. 防止语法不兼容，在命令行中执行如下命令。
                       
                       npm install @babel/preset-typescript

                4. 在代码中使用如下语句获取HBT顶层对象。
                       
                       import HBT from "@hmscore/hms-js-hbt"

                5. 使用接口实现业务，使用如下语句调用接口。
                       
                       HBT._xxx_

                   1. [agreeFollow](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js_agreefollow-0000001058207795)接口，用于启动关注流程。需要传递您的快应用的appId、您的服务号对应的pubId、pubName、succ和fail参数。
                          
                          let succ = function(res) {
                              //成功回调函数
                              ...
                          }
                          let fail = function(res) {
                              //失败回调函数
                              ...
                          }
                          HBT.agreeFollow(appId, pubId, pubName, succ, fail)

                   2. [agreeFollow2](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js_agreefollowv2-0000001101717508)接口，用于关注目标服务号。
                          
                          let fun = function(){ 
                                let param = {
                                  appId: 'string',
                                  pubId: 'string',
                                  pubName: 'string',
                                  componentTitle: 'string',
                                  logoUrl: 'string',
                                  componentType: 'string',
                                  componentAction: 0,
                                } 
                                let succ = function(res) { 
                                  //成功回调 
                                } 
                                let fail = function(error) { 
                                  //失败回调 
                                } 
                                HBT.agreeFollow2(param, succ, fail) 
                          }

                   3. [checkFollowStatus](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js_checkfollowstatus-0000001148197455)接口，用于获取目标服务号的关注状态。
                          
                          let fun = function(){ 
                              let param = {
                                  appId: 'string',
                                  pubId: 'string',
                              } 
                              let succ = function(res) { 
                                  //成功回调 
                              } 
                              let fail = function(error) { 
                                  //失败回调 
                              } 
                              HBT.checkFollowStatus(param, succ, fail) 
                          }

                   4. [goPubPortal](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js_gopubportal-0000001101397522)接口，用于跳转目标服务号主页。
                          
                          let fun = function(){ 
                              let param = {
                                  appId: 'string',
                                  pubId: 'string',
                                  componentType: 'string',
                              } 
                              let succ = function(res) { 
                                  //成功回调 
                              } 
                             let fail = function(error) { 
                                  //失败回调 
                              } 
                              HBT.goPubPortal(param, succ, fail) 
                          }
