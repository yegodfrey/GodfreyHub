# 位置

此数据记录用户在某一时刻的位置信息，每一条数据都代表该时刻的GPS位置。

## OAuth权限

联盟卡片申请的权限名称：锻炼记录 > 锻炼记录位置详情数据

* 读权限：https://www.huawei.com/healthkit/location.read
* 写权限：https://www.huawei.com/healthkit/location.write

## 原子采样明细数据类型

* 名称：com.huawei.instantaneous.location.sample

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:---------|:---|:-----|:----|:-|:-------------------|
|latitude|纬度|float|M|度|-|
|longitude|经度|float|M|度|-|
|precision|精度|float|O|米|-|
|coordinate|坐标系|int|M|-|* 1：WGS84 * 2：GCJ-02|

### 数据开放说明

|开放API|查询及时性|数据源|
|:--------------------------------------------------------------------------------------------------------------|:----|:--------|
|[运动记录查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecords_list-0000001050114862)|分钟级|手机、手表、手环等|

### 数据订阅说明

位置数据不支持订阅。

## 原子采样统计数据类型

* 名称：com.huawei.location.statistics

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:---------|:----|:-----|:----|:-|:-----------------------------|
|startLat|起始点纬度|float|M|度|-|
|startLon|起始点经度|float|M|度|-|
|endLat|结束点纬度|float|M|度|-|
|endLon|结束点经度|float|M|度|-|
|coordinate|坐标系|int|M|-|* 1：WGS84 * 2：GCJ-02 * 3：BD-09|

### 数据开放说明

|开放API|查询及时性|统计数据维度|数据源|
|:--------------------------------------------------------------------------------------------------------------|:----|:-------|:--------|
|[运动记录查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecords_list-0000001050114862)|分钟级|运动记录概要统计|手机、手表、手环等|

### 数据订阅说明

位置统计数据不支持订阅。
