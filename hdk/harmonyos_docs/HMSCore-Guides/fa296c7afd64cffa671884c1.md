#### 集成SDK

#### [h2]Android SDK下载

                1. 导入HMS SDK。

                   1. 在工程的“build.gradle”文件中添加HMS Maven仓： 
                          
                          allprojects {
                              repositories {
                                  google()
                                  jcenter()
                                  maven { url 'https://developer.huawei.com/repo/' }
                              }
                          }

                   2. 在模块的“build.gradle”文件中增加依赖： 
                          
                          implementation 'com.huawei.hms:ads-lite-inner:_13.4.90.300_ '

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/9hZ1KjDQQ5qcfSsgbZSxew/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043055Z&HW-CC-Expire=86400&HW-CC-Sign=17351D8E26A93062BC93F67BD7CD1D0E869F5FFE4E714C9923EF196368F45655)

如果您需要导入广告SDK aar包，请在工程中新建aar文件夹，并将鲸鸿动能SDK的aar文件拷贝进去。

                2. 修改AndroidManifest.xml。

                   1. 鲸鸿动能SDK minSdkVersion为19，如果应用的minSdkVersion小于19，则添加： 
                          
                          <uses-sdk tools:overrideLibrary="com.huawei.openalliance.ad"/>

                   2. 鲸鸿动能SDK从Android Q（API LEVEL 29）版本开始不再声明android.permission.READ_PHONE_STATE权限，实现如下： 
                          
                          <uses-permission android:name="android.permission.READ_PHONE_STATE" android:maxSdkVersion="28"/>

                   3. 因此对于在Android Q版本以后仍然需要使用该权限的应用，需要在声明该权限时增加node配置，实现如下： 
                          
                          <uses-permission android:name="android.permission.READ_PHONE_STATE" tools:node="replace" />

                3. 代码混淆。在混淆文件中添加：
                       
                       -keep class com.huawei.openalliance.ad.** { *; }

                4. 处理动态权限。鲸鸿动能SDK需要获取设备的DeviceId，在Android 6.0及以上版本，需要动态申请android.permission.READ_PHONE_STATE权限。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/43/v3/UNirY9RASLCZbX2E-1c9Xw/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043055Z&HW-CC-Expire=86400&HW-CC-Sign=E44EDCD1BD3219983A0238FDDE4687A06028B2FB55168CDA779C9DF4CD867518)

如果动态申请READ_PHONE_STATE未成功，请避免显示权限获取引导界面，鲸鸿动能SDK能兼容没有此权限的场景（用户可能勾选“禁止后不再提示”复选框。若没有权限，导致每次都会显示引导界面，体验较差）。

#### 同意和取消用户协议

用户同意媒体App的用户协议后，媒体App调用SDK的接口设置为工作状态后才能获取到广告；同样的，用户撤销同意后媒体App应调用SDK接口将SDK设置为非工作状态。用户同意和撤销同意用户协议的状态由媒体保存。SDK设置为工作状态的接口调用场景：

                * 应用程序首次使用，用户同意协议后。
                * 用户协议发生变更，用户同意协议后。
                * 用户撤销同意用户协议后。

#### 接入开屏广告

                1. 开屏广告集成。 

鲸鸿动能SDK提供了开屏广告的控件，开屏广告的渲染由鲸鸿动能SDK完成，开发者实现开屏页面Activity和跳转到主界面的逻辑。

                2. 开屏广告素材类型。 

支持静态图片和GIF图片两种类型。

                3. 开屏广告模式。 

开屏广告支持如下几种模式：

                   * 实时模式：应用打开时，实时从鲸鸿动能云端获取广告，获取广告期间，展示应用的Slogan，广告获取成功后，则展示广告。
                   * 缓存模式：应用打开时，如果当前没有缓存广告，则不显示广告，直接进入应用；如果已缓存广告则显示广告；同时从云端获取广告，供下次开屏时使用。
                4. 开屏广告如需获取实时bidding的广告能力，请参考实时竞价广告。

#### [h2]获取和展示广告

                1. 获取广告。 

使用com.huawei.openalliance.ad.views.PPSSplashView：控件来获取并展示开屏广告。

                2. 开屏广告代码示例。 
                       
                       import com.huawei.openalliance.ad.beans.parameter.AdSlotParam;
                       import com.huawei.openalliance.ad.inter.HiAd;
                       import com.huawei.openalliance.ad.inter.HiAdSplash;
                       import com.huawei.openalliance.ad.inter.listeners.AdListener;
                       import com.huawei.openalliance.ad.views.PPSSplashView;
                       
                       public class SplashActivity extends Activity{
                           /**
                            * 终端设备类型：4：手机，5：平板
                            */
                           private static final int DEVICE_TYPE = 4;
                       
                           /**
                            * 异常保护使用：广告展示超时时间 单位：毫秒
                            */
                           private static final int AD_TIMEOUT = 10000;
                       
                           /**
                            * 异常保护使用：广告超时消息标记
                            */
                           private static final int MSG_AD_TIMEOUT = 1001;
                       
                           /**
                            * 返回键标志位 按返回键退出时应用不被重新拉起，但是在展示广告时下拉通知栏仍然需要正常跳转
                            */
                           private boolean hasPaused = false;
                           private RelativeLayout splashContainer;
                       
                           /**
                            * 超时消息回调handler
                            */
                           private Handler timeoutHandler = new Handler(new Handler.Callback(){
                               @Override
                               public boolean handleMessage(Message msg){
                                   if (SplashActivity.this.hasWindowFocus()){
                                       jump();
                                   }
                                   return false;
                               }
                           });
                       
                           @Override
                           protected void onCreate(Bundle savedInstanceState){
                               ...
                       
                               // 构造获取广告请求参数
                               AdSlotParam.Builder slotParamBuilder = new AdSlotParam.Builder();
                               List<String> adIds = new ArrayList<String>(1);
                               adIds.add("开屏广告位ID");
                               RequestOptions.Builder reqOptBuilder = new RequestOptions.Builder(); 
                               // 设置屏幕方向
                               int orientation = ActivityInfo.SCREEN_ORIENTATION_PORTRAIT;
                       
                               slotParamBuilder
                                   // 设置广告位ID
                                   .setAdIds(adIds)
                                   // 设置终端类型，取值：4：手机，5：平板 
                                   .setDeviceType(DEVICE_TYPE) 
                                   // 设置屏幕方向
                                   .setOrientation(orientation)
                                   // 是否请求测试广告，上线版本必须是false 
                                   .setTest(false); 
                             // 可选 设置RequestOption参数
                               .setRequestOptions(reqOptBuilder.build());
                       
                               // 设置logan展示时间，云端可配置。
                               HiAdSplash.getInstance(this).setSloganDefTime(2000);
                       
                               // 判断是否存在广告和Slogan
                               if (!HiAdSplash.getInstance(this).isAvailable(slotParamBuilder.build())){
                                   jump();
                                   return;
                               }
                       
                               // 获取PPSSplashView控件
                               PPSSplashView splashAdView = (PPSSplashView)findViewById(R.id.pps_splash_view);
                               // 设置广告位参数
                               splashAdView.setAdSlotParam(slotParamBuilder.build());
                               // 设置默认Slogan图片资源ID
                               splashAdView.setSloganResId(defaultSlogan);
                               // 设置默认logo图片资源
                               splashAdView.setLogo(findViewById(R.id.logo));
                       
                               // 全屏开屏广告，显示在左上角的应用图标
                               splashAdView.setLogoResId(R.drawable.ic_launcher);
                               // 全屏开屏广告，显示在左上角的应用名称
                               splashAdView.setMediaNameResId(R.string.app_name);
                       
                               // 设置广告记载事件监听器
                               splashAdView.setAdListener(new AdListener(){
                                   @Override
                                   public void onAdFailedToLoad(int errorCode){
                                       // 广告加载失败
                                       Log.d(TAG, "onAdFailedToLoad: " + errorCode);
                                   }
                       
                                   @Override
                                   public void onAdLoaded(){
                                       // 广告加载成功
                                       Log.d(TAG, "onAdLoaded");
                                   }
                       
                                   @Override
                                   public void onAdDismissed(){
                                       // 广告消失，进入应用主界面
                                       Log.d(TAG, "onAdDismissed");
                                       jump();
                                   }
                               });
                       
                               // 加载广告
                               splashAdView.loadAd();
                       
                               // 启动广告超时保护定时器，注意：在onStop时要移除此消息，否则会影响正常广告展示
                               timeoutHandler.removeMessages(MSG_AD_TIMEOUT);
                               timeoutHandler.sendEmptyMessageDelayed(MSG_AD_TIMEOUT, AD_TIMEOUT);
                           }
                       
                           public void jump(){
                               // 进入应用主界面
                               if (!hasPaused){
                                   hasPaused = true;
                                   startActivity(new Intent(SplashActivity.this, MainActivity.class));
                                   finish();
                               }
                           }
                       
                           @Override
                           public void onConfigurationChanged(Configuration newConfig){
                               super.onConfigurationChanged(newConfig);
                               if (isMultiWin()){
                                   jump();
                                   return;
                               }
                           }
                       
                           @Override
                           protected void onStop(){
                               // 移除超时消息
                               timeoutHandler.removeMessages(MSG_AD_TIMEOUT);
                               hasPaused = true;
                               super.onStop();
                           }
                       
                           @Override
                           protected void onRestart(){
                               // 从其他页面回到开屏页面时调用，进入应用
                               super.onRestart();
                               hasPaused = false;
                               jump();
                           }
                       
                           @TargetApi(24)
                           private boolean isMultiWin()
                           {
                               if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.N && isInMultiWindowMode())
                               {
                                   return true;
                               }
                               return false;
                           }
                           ...
                       }

#### [h2]获取和展示开屏广告

使用com.huawei.openalliance.ad.views.SmartScreenSplashView控件来获取并展示广告。示例代码如下所示：
    
    public class TvSplashActivity extends Activity {
        private static final String TAG = "TvSplash";
    
        private static final String ALLOW_MOBILE_TRAFFIC = "allow_mobile_traffic";
    
        private static final String SPLASH_AD_START_VOL = "splash_ad_start_vol";
    
        private static final String SPLASH_AD_ID = "splash_ad_id";
    
        private static final String DEMO_AD_ID_SP = "DemoAdId";
    
        /**
         * 广告展示超时时间：单位毫秒
         */
        private static final int AD_TIMEOUT = 10000;
    
        /**
         * 广告超时消息标记
         */
        private static final int MSG_AD_TIMEOUT = 1001;
    
        private SmartScreenSplashView smartScreenSplashView;
    
        private int defaultSlogan = R.drawable.default_slogan;
    
        /**
         * 返回键标志位 按返回键退出时应用不被重新拉起，但是在展示广告时下拉通知栏仍然需要正常跳转
         */
        private boolean hasPaused = false;
    
        SharedPreferences splashSp;
    
        /**
         * 超时消息回调handler
         */
        private final Handler timeoutHandler = new Handler(Looper.myLooper(), new Handler.Callback() {
    
            @Override
            public boolean handleMessage(Message msg) {
                if (hasWindowFocus()) {
                    jump();
                }
                return false;
            }
        });
    
        @Override
        protected void onCreate(Bundle savedInstanceState) {
            super.onCreate(savedInstanceState);
            setContentView(R.layout.activity_tv_splash);
            splashSp = getSharedPreferences(DEMO_AD_ID_SP, MODE_PRIVATE);
            loadAd();
        }
    
        @Override
        public boolean onKeyDown(int keyCode, KeyEvent event) {
            Log.i(TAG, "onKeyDown: " + keyCode);
            // 不处理返回键，SmartScreenSplashView会处理返回键并给onAdDismiss回调
            if (KeyEvent.KEYCODE_BACK == keyCode) {
                return false;
            }
            return super.onKeyDown(keyCode, event);
        }
    
        private void loadAd() {
            Log.d(TAG, "loadAd");
           
            // 为优化开屏时延，建议在应用Application中初始化HiAd
            IHiAd hiad = HiAd.getInstance(this); 
            hiad.initLog(true, Log.DEBUG);
    
            initGrs(TvSplashActivity.this);
    
            int brand = SpHelper.getInstance(this).getBrand();
            if (brand > 0) {
                hiad.setBrand(brand);
            }
    
            int mode = FileUtil.readDefaultSplashMode(this);
            Log.d(TAG, "load default mode:" + mode);
            HiAdSplash.getInstance(this).setDefaultSplashMode(mode);
    
            AdSlotParam.Builder slotParamBuilder = new AdSlotParam.Builder();
            List<String> adIds = new ArrayList<String>(1);
            // 从sp文件读取设置的广告位ID
            SharedPreferences splashSp = getSharedPreferences(DEMO_AD_ID_SP, MODE_PRIVATE);
            String splashId = splashSp.getString(SPLASH_AD_ID, "");
            if (!TextUtils.isEmpty(splashId)) {
                adIds.add(splashId);
                Log.d(TAG, "use input adId: " + splashId);
            } else {
                adIds.add(Constants.SPLASH_ADID);
                Log.d(TAG, "use default adId");
            }
            Location location = DemoVerifyManager.getInstance(this).getLocationConfig();
            slotParamBuilder.setAdIds(adIds)
                    .setDeviceType(DeviceType.TV)
                    .setOrientation(ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE)
                    .setTest(Constants.SPLASH_TEST_FLAG)
                    .setContentBundle(FileUtil.getContentBundle(this))
                    .setLocation(location);
            RequestParams params = RequestParams.getInstance();
            slotParamBuilder.setRequestOptions(Parser.initRequestOptions(TvSplashActivity.this, params));
    
            // 设置第一次启动时的slogan展示时间，如果应用必须展示广告界面则调用
            HiAdSplash.getInstance(this).setSloganDefTime(2000);
    
            SharedPreferences pref = getSharedPreferences(getPackageName(), MODE_PRIVATE);
            int allowMobileTraffic = pref.getInt(ALLOW_MOBILE_TRAFFIC, -1);
            HiAdSplash.getInstance(this).setAllowMobileTraffic(allowMobileTraffic);
    
            if (!HiAdSplash.getInstance(this).isSmartSplashAvailable(slotParamBuilder.build())) {
                jump();
                return;
            }
    
            smartScreenSplashView = findViewById(R.id.splash_ad_view_tv);
    
            smartScreenSplashView.setAdSlotParam(slotParamBuilder.build());
            // sloganResId调用slotParam前, 请先设置setAdSlotParam
            smartScreenSplashView.setSloganResId(defaultSlogan);
            smartScreenSplashView.setSloganView(findViewById(R.id.splash_slogan_view));
            View logoView = View.inflate(this, R.layout.splash_tv_icon_layout, null);
            smartScreenSplashView.setLogo(logoView);
            float startVol = splashSp.getFloat(SPLASH_AD_START_VOL, 0.18f);
            smartScreenSplashView.setStartMaxVol(startVol);
            smartScreenSplashView.setAudioFocusType(AudioFocusType.NOT_GAIN_AUDIO_FOCUS_WHEN_MUTE);
            smartScreenSplashView.setAdListener(new AdListener() {
                @Override
                public void onAdFailedToLoad(int errorCode) {
                    Log.d(TAG, "onAdFailedToLoad: " + errorCode);
                }
    
                @Override
                public void onAdLoaded() {
                    Log.d(TAG, "onAdLoaded");
                    timeoutHandler.removeMessages(MSG_AD_TIMEOUT);
                }
    
                @Override
                public void onAdDismissed() {
                    Log.d(TAG, "onAdDismissed");
                    jump();
                }
            });
            smartScreenSplashView.setAdActionListener(new AdActionListener() {
                @Override
                public void onAdShowed() {
                    Log.d(TAG, "onAdShowed: ");
                }
    
                @Override
                public void onAdClick() {
                    Log.d(TAG, "onAdClick: ");
    
                }
            });
    
            smartScreenSplashView.loadAd();
    
            /**
             * 发送延迟消息,用来处理广告超时时能够返回
             */
            timeoutHandler.removeMessages(MSG_AD_TIMEOUT);
            timeoutHandler.sendEmptyMessageDelayed(MSG_AD_TIMEOUT, AD_TIMEOUT);
        }
    
        private void jump() {
            Log.d(TAG, "jump hasPaused: " + hasPaused);
            if (!hasPaused) {
                hasPaused = true;
                Log.d(TAG, "jump into application");
                startActivity(new Intent(TvSplashActivity.this, MainActivity.class));
                Handler mainHandler = new Handler(Looper.myLooper());
                mainHandler.postDelayed(new Runnable() {
                    @Override
                    public void run() {
                        finish();
                    }
                }, 1000);
    
            }
        }
    
        private void initGrs(final Context context) {
            // 应用初始化自己的GRS
            Log.i(TAG + "ServerConfig", "initGrs");
            GrsBaseInfo hmsGrsInfo = new GrsBaseInfo();
            CountryCodeBean countryCodeBean = GrsApi.getCountryCode(context, false);
            hmsGrsInfo.setAppName(AdInfoUtil.getGrsAppName());
    
            String countryCode = FileUtil.readGrsCountryCode(context);
            if (TextUtils.isEmpty(countryCode)) {
                countryCode = countryCodeBean.getCountryCode();
            }
            hmsGrsInfo.setSerCountry(countryCode);
            Log.i(TAG + "ServerConfig", "country:" + countryCode);
            hmsGrsInfo.setCountrySource(countryCodeBean.getCountrySource());
            GrsApi.grsSdkInit(context.getApplicationContext(), hmsGrsInfo);
            Map<String, String> serverUrlMap = GrsApi.synGetGrsUrls("com.huawei.cloud.pps");
            if (null != serverUrlMap && !serverUrlMap.isEmpty()) {
                for (String url : serverUrlMap.values()) {
                    Log.i(TAG + "ServerConfig", "url:" + url);
                }
            }
    
            // 通知SDK初始化GRS
            if (AdInfoUtil.isHuaweiPhone(context)) {
                HiAd.getInstance(context).initGrs(AdInfoUtil.getGrsAppName());
            } else {
                String grsCountryCode = SpHelper.getInstance(this.getApplicationContext()).getGrsCountryCode();
                Log.i(TAG, Build.MANUFACTURER + "grsCountryCode " + grsCountryCode);
                if (!TextUtils.isEmpty(grsCountryCode)) {
                    HiAd.getInstance(context).initGrs(AdInfoUtil.getGrsAppName(), grsCountryCode);
                }
            }
        }
    
        @Override
        protected void onPause() {
            super.onPause();
            if (smartScreenSplashView != null) {
                smartScreenSplashView.pauseView();
            }
        }
    
        @Override
        protected void onStop() {
            Log.d(TAG, "onStop");
            // 移除超时消息
            timeoutHandler.removeMessages(MSG_AD_TIMEOUT);
            hasPaused = true;
            super.onStop();
        }
    
        @Override
        protected void onResume() {
            super.onResume();
            if (smartScreenSplashView != null) {
                smartScreenSplashView.resumeView();
            }
        }

                1. 获取广告。 

同一界面的多个广告时，请使用如下两种方式来获取广告：

                   1. 不同位置的价格不一样，使用多个广告位；获取广告时将所有广告位ID设置到RewardAdLoader中，一次性获取所有广告位的广告。
                   2. 不同位置价格一致，使用一个广告位ID，在开发者Portal上将最多返回广告数配置成所需的个数；获取广告时将该广告位ID设置到RewardAdLoader中，一次性获取N个广告。

                       import com.huawei.openalliance.ad.media.MediaPlayerAgent;
                       import com.huawei.openalliance.ad.media.listener.MediaErrorListener;
                       import com.huawei.openalliance.ad.media.listener.MediaStateListener;
                       ...
                       
                       /**
                        * 视频播放顺序管理器。
                        */
                       public class VideoPlayerManager implements IMultiMediaPlayingManager {
                           /**
                            * 视频播放任务对象
                            */
                           private static class Task {
                               /**视频播放地址*/
                               final String url;
                               /**视频播放器*/
                               final MediaPlayerAgent player;
                       
                               Task(String url, MediaPlayerAgent player) {
                                   this.url = url;
                                   this.player = player;
                               }
                       
                               @Override
                               public boolean equals(Object obj) {
                                   if (obj == null || !(obj instanceof VideoPlayerManager.Task)) {
                                       return false;
                                   }
                       
                                   if (this == obj) {
                                       return true;
                                   }
                                   VideoPlayerManager.Task toObj = (VideoPlayerManager.Task) obj;
                                   return TextUtils.equals(this.url, toObj.url) && this.player == toObj.player;
                               }
                       
                               @Override
                               public int hashCode() {
                                   int urlHashcode = url != null ? url.hashCode() : 0xffffffff;
                                   int playerHashcode = player != null ? player.hashCode() : 0xffffffff;
                                   return super.hashCode() & urlHashcode & playerHashcode;
                               }
                           }
                       
                           private final byte[] opLock = new byte[0];
                       
                           /**当前正在播放的播放器*/
                           private MediaPlayerAgent currentPlayer;
                           /**视频播放任务队列*/
                           private Queue<VideoPlayerManager.Task> playTaskQueue = new ConcurrentLinkedQueue<Task>();
                           private Context context;
                       
                           /**
                            * 自动播放
                            * @param url 视频的播放地址
                            * @param player 视频播放器
                            */
                           @Override
                           public void autoPlay(final String url, final MediaPlayerAgent player) {
                               if (TextUtils.isEmpty(url) || null == player) {
                                   return;
                               }
                       
                               synchronized (opLock) {
                                   if (player == currentPlayer || null == currentPlayer) {
                                       // 开始播放视频
                                       player.addMediaStateListener(mediaStateListener);
                                       player.addMediaErrorListener(mediaErrorListener);
                                       player.playWhenUrlMatchs(url);
                                       currentPlayer = player;
                                   } else {
                                       // 已经有视频正在播放，先放入队列
                                       VideoPlayerManager.Task task = new VideoPlayerManager.Task(url, player);
                                       playTaskQueue.remove(task);
                                       playTaskQueue.add(task);
                                   }
                               }
                           }
                       
                           /**
                            * 用户手动点击播放按钮播放
                            * @param url 视频的播放地址
                            * @param player 视频播放器
                            */
                           @Override
                           public void manualPlay(final String url, final MediaPlayerAgent player) {
                               if (TextUtils.isEmpty(url) || null == player) {
                                   return;
                               }
                       
                               synchronized (opLock) {
                                   // 用户手动点击播放，强制播放当前视频
                                   if (currentPlayer != null && player != currentPlayer) {
                                       // 停止正在播放的视频
                                       currentPlayer.stop();
                                   }
                       
                                   player.addMediaStateListener(mediaStateListener);
                                   player.addMediaErrorListener(mediaErrorListener);
                                   player.playWhenUrlMatchs(url);
                                   currentPlayer = player;
                       
                                   // 从等待队列中移除
                                   playTaskQueue.remove(new VideoPlayerManager.Task(url, player));
                               }
                           }
                       
                           /**
                            * 停止播放
                            * @param url 视频的播放地址
                            * @param player 视频播放器
                            */
                           @Override
                           public void stop(final String url, final MediaPlayerAgent player) {
                               if (TextUtils.isEmpty(url) || null == player) {
                                   return;
                               }
                               synchronized (opLock) {
                                   if (player == currentPlayer) {
                                       // 正在播放，则停止
                                       currentPlayer = null;
                                       player.stopWhenUrlMatchs(url);
                                   } else {
                                       // 正在等待，则从队列中移除
                                       playTaskQueue.remove(new VideoPlayerManager.Task(url, player));
                                       removeListenersForMediaPlayerAgent(player);
                                   }
                               }
                           }
                       
                           /**
                            * 暂停播放
                            * @param url 视频的播放地址
                            * @param player 视频播放器
                            */
                           @Override
                           public void pause(final String url, final MediaPlayerAgent player) {
                               if (TextUtils.isEmpty(url) || null == player) {
                                   return;
                               }
                               synchronized (opLock) {
                                   if (player == currentPlayer) {
                                       // 正在播放，则暂停
                                       player.pauseWhenUrlMatchs(url);
                                   } else {
                                       // 正在等待，则从队列中移除
                                       playTaskQueue.remove(new VideoPlayerManager.Task(url, player));
                                       removeListenersForMediaPlayerAgent(player);
                                   }
                               }
                           }
                       
                           /**播放状态监听器*/
                           private MediaStateListener mediaStateListener = new MediaStateListener() {
                               /**通知播放进度*/
                               @Override
                               public void onProgress(int percentage, int playTime) {
                               }
                       
                               /**通知播放开始*/
                               @Override
                               public void onMediaStart(MediaPlayerAgent playerAgent, int playTime) {
                               }
                       
                               /**通知播放暂停*/
                               @Override
                               public void onMediaPause(MediaPlayerAgent playerAgent, int playTime) {
                                   checkAndPlayNext();
                               }
                       
                               /**通知播放停止*/
                               @Override
                               public void onMediaStop(MediaPlayerAgent playerAgent, int playTime) {
                                   checkAndPlayNext();
                               }
                       
                               /**通知播放完成*/
                               @Override
                               public void onMediaCompletion(MediaPlayerAgent playerAgent, int playTime)
                                   playNextTask();
                               }
                       
                               /**播放下一个视频*/
                               private void checkAndPlayNext() {
                                   synchronized (opLock) {
                                       if (null == currentPlayer) {
                                           playNextTask();
                                       }
                                   }
                               }
                           };
                       
                           /**播放出错监听器*/
                           private MediaErrorListener mediaErrorListener = new MediaErrorListener() {
                               /**通知播放出错*/
                               @Override
                               public void onError(MediaPlayerAgent playerAgent, int playTime, int errorCode, int extra) {
                                   synchronized (opLock) {
                                       playerAgent.removeMediaErrorListener(this);
                                   }
                                   playNextTask();
                               }
                       
                           };
                       
                           /**播放下一个视频*/
                           private void playNextTask() {
                               if (!NetworkUtil.isWifiNetwork(context)) {
                                   return;
                               }
                       
                               synchronized (opLock) {
                                   VideoPlayerManager.Task task = playTaskQueue.poll();
                                   if (task != null) {
                                       task.player.addMediaStateListener(mediaStateListener);
                                       task.player.addMediaErrorListener(mediaErrorListener);
                                       task.player.playWhenUrlMatchs(task.url);
                                       currentPlayer = task.player;
                                   } else {
                                       currentPlayer = null;
                                   }
                               }
                           }
                       
                           /**删除播放器*/
                           @Override
                           public void removeMediaPlayerAgent(final MediaPlayerAgent player) {
                               if (null == player) {
                                   return;
                               }
                       
                               synchronized (opLock) {
                                   if (player == currentPlayer) {
                                       removeListenersForMediaPlayerAgent(currentPlayer);
                                       currentPlayer = null;
                                   }
                                   Iterator<Task> iterator = playTaskQueue.iterator();
                                   while (iterator.hasNext()) {
                                       VideoPlayerManager.Task task = iterator.next();
                                       if (task.player == player) {
                                           removeListenersForMediaPlayerAgent(task.player);
                                           iterator.remove();
                                       }
                                   }
                               }
                           }
                       
                           /**删除监听器*/
                           @Override
                           public void removeListenersForMediaPlayerAgent(MediaPlayerAgent playerAgent){
                               synchronized (opLock) {
                                   if (playerAgent != null) {
                                       playerAgent.removeMediaStateListener(mediaStateListener);
                                       playerAgent.removeMediaErrorListener(mediaErrorListener);
                                   }
                               }
                           }
                       }

#### [h2]实时竞价广告

目前鲸鸿动能广告SDK客户端 v13.4.75.300以上版本添加客户端实时竞价能力。（此能力需要向流量运营申请开通）。

**支持场景**

                * 原生广告
                * 激励广告
                * 插屏广告
                * 开屏广告

**接入流程**

                1. 请求： 

媒体侧在发起广告请求时，需要设置相关bidding的参数，具体参数：bidFloor（广告位底价）、bidFloorCur（广告位底价币种）、bpkgName（禁投的应用名单，List类型）、tMax（最大请求超时时间）、cur（广告请求中交易的币种），在AdParam.Builder类中，setTMax(Integer tMax) 设置交易的最大超时间、setCur(List<String> curs)设置交易币种、addBiddingParamMap(String slotId, BiddingParam biddingParam) 针对该广告位设置，或者通过setBiddingParamMap(Map<String, BiddingParam> biddingParamMap) 也可以设置多个广告，传入Map，key = slotId，value = 该广告位的bidding请求参数，具体参考[BiddingParam](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddingparam-0000001920059660)和[AdParam.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-builder-0000001050066829)相关接口。

                2. 返回： 

获取鲸鸿动能广告的竞标出价，调用各广告类型的广告对象，调用getBiddingInfo()接口获取竞价结果，如原生广告 BiddingInfo biddingInfo = nativeAd.getBiddingInfo()；再通过[getPrice](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376#section68119411565)() 接口获取本条广告的eCPM出价（元/千次展示）；若鲸鸿动能广告竞胜，调用[getNurl](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376#section14704560583)() 竞价成功通知URL，URL中含有宏替换 SECOND_PRICE、AUCTION_CURRENCY，通知SDK竞胜结果；若广告竞败，调用[getLurl](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376#section18085225575)() 获取竞价失败通知其他成功的URL，URL中含有宏替换（具体宏：AUCTION_LOSS、AUCTION_PRICE、AUCTION_CURRENCY、AUCTION_APP_PKG、AUCTION_APP_NAME、AUCTION_CP_ID）传入竞败原因，及其他广告竞胜方的出价；具体参考[BiddingInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376)、sendBiddingSuccess(Map<String, Object> sendSuccessInfo, [ReportUrlListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/reporturllistener-0000002039342792) reportUrlListener) （竞价成功）和 sendBiddingFailed(Map<String, Object> sendFailInfo, [ReportUrlListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/reporturllistener-0000002039342792) reportUrlListener)（竞价失败）。

                3. 展示： 

按正常广告展示方式曝光。

**详情请参考下列各广告形式代码示例。**

注：宏说明：

宏 |  说明  
---|---  
SECOND_PRICE |  竞胜时，其他DSP最高出价，单位元。价格明文，样例： 3.6。  
AUCTION_PRICE |  竞败时，其他DSP最高出价，单位元。价格明文，样例： 3.6。  
AUCTION_LOSS |  竞价结果，如果没有走到参竞环节也需要回调，并替换具体过滤结果码。 枚举： 102：竞价失败。 103：底价过滤。 104：包名过滤。 105：其他原因过滤。 4005：超时未返回--理论上不存在，媒体如果存在返回转换等流程未完成导致超时，使用此结果码。  
AUCTION_CURRENCY |  价格币种。 支持币种：CNY、USD、EUR、GBP、JPY。  
AUCTION_APP_PKG |  竞败时，竞胜DSP推广App包名。  
AUCTION_APP_NAME |  竞败时，竞胜DSP推广App名称。  
AUCTION_CP_ID |  竞败时，竞胜的DSP编号： 1：广点通 2：穿山甲 3：百青藤 4：快手联盟 5：爱奇艺 6：阿里 7：VIVO 8：OPPO 9：小米 10：京东 11：拼多多 100：其他
