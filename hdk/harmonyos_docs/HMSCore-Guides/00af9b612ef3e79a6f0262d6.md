# 运动健康

#### 事件参数列表

    * REGISTERACCOUNT

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 用户来源 | String | 可选 | 用户来源。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
INVITER | 邀请人 | String | 可选 | 邀请该用户进行注册的用户。  
  
    * BINDACCOUNT

用户绑定其他类型帐号时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
  
    * BINDDEVICE

用户绑定穿戴设备时上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
BRAND | 设备归属品牌 | String | 可选 | 设备品牌。 针对运动健康行业代表穿戴设备品牌，如华为。  
SERIES | 设备归属系列 | String | 可选 | 设备系列。 针对运动健康行业代表穿戴设备系列。  
MODEL | 设备型号 | String | 可选 | 设备型号。 针对运动健康行业代表穿戴设备型号。  
DEVICETYPE | 操作设备类型 | String | 必选 | 当前操作的设备类型枚举值。 针对运动健康行业代表穿戴设备类型，比如手表、手环、心率带、体脂秤、耳机等。  
DEVICENAME | 设备名称 | String | 可选 | 用户绑定穿戴设备的名称。
