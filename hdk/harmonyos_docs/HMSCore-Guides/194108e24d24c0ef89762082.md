# 服务创建

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/76/v3/BHp0GsruQkafUaquDC6pHA/zh-cn_image_0000001051464956.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=A50B7394A458B4FAF9DED472CF100581C0683706EC8438DD5C0C131340A0A281 "点击放大")

2. 选择需要创建Wallet Kit服务的项目，进入项目设置页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/ar3LUslURFKQMx9ygiRm9A/zh-cn_image_0000001052583688.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=E4A4B7E0B9259952B991E5EE7A6CC783E1D190AEE7C16DF90D5B58CB41DEF860 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/3V8n_H3xT0yBuqQDDnNFYA/zh-cn_image_0000001051625112.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=C6878933220A0C5BD24D7C37D36F5B6D2AFDF01DA197B7556547F649F4B50F92 "点击放大") 说明
   > 1. 国内老用户是通过联盟入口使用Wallet Kit服务的，此次发布的新版本，均采用AGC入口使用Wallet Kit服务。
   > 2. 国内老用户之前通过联盟入口使用Wallet Kit服务创建的产品，如果在AGC的产品列表里没有直接展示出来，此时需要用户手动在AGC中做二次创建。

   例如：老用户之前通过联盟入口使用Wallet Kit服务创建了一个产品，产品名称为：wallet.demo.test。该产品名称在AGC的产品列表中没有直接展示出来，需要点击AGC产品新建按钮，在新建产品的弹框中，点击"应用名称"下拉框，选择在联盟创建的产品名称：wallet.demo.test（后面紧接着的数字是该产品的ID），完成老产品的创建，从而可以在AGC中继续使用老产品来申请Wallet Kit服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/zYwDGf7kTRemnVkzEikZAg/zh-cn_image_0000001050164118.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=B7A16D751D556100EA89EE35A24E6C2DACF7DA6E7E40E1A83BCF72FD08984DED "点击放大")

3. 在"项目设置"页签，左侧导航选择"盈利 > 华为钱包"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/9tGrFwAGSLeqvNZuENbm-Q/zh-cn_image_0000001052783723.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=99D27FE422AF0A1F4ADFE7D5C6B3A6A68F5E1B0C13EA3072DA6B329B1E214C21 "点击放大")

4. 申请创建Wallet Kit服务。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8e/v3/wEkLVix1T_GnWhITx8aT5g/zh-cn_image_0000001050164211.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=08EB5C5895ADB1FB7B4268E48012CB04EAB8D9F3F4A503901437B48496424F0B "点击放大")

5. 设置Wallet Kit服务基本信息。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d0/v3/xAmWt1bWQYyI7OFMDla0Jg/zh-cn_image_0000001097139193.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=39D0A0152988BB875C6089C70901DD3FB1EAD0FB1F2D5D09BCEF2F4C53D1DB44 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/AGWw8C5ERB2y1xtyM8NPgQ/zh-cn_image_0000001097439655.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=1B39935AA8CFDCE4A87D0A34333722A57A13B861CC5118B85448447EF06EF06A "点击放大")

   说明：
   * 服务类型：分为卡、票、券，开发者选择其中的一种。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cd/v3/lbuJDgTVRg-Sk9WID2nvEQ/zh-cn_image_0000001078250224.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=D0FAD7D81AEAB9CD2A366934C14F223D4927F182DBEEAE00497D7E66029B273D "点击放大")

   * 服务项目：服务项目依赖所选择的服务类型，不同的服务类型，有不同的服务项目。例如当服务类型选择"卡"时，对应的服务项目有："会员卡"、"公交卡"、"礼品卡"。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7b/v3/kShAJKrNSRyMD9ew0JcPUQ/zh-cn_image_0000001050162260.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=D283C49F78AFDB2D39C8B15C870108BC80DDC87339F6F2517C33FBEFBDC3C737 "点击放大")

   * 服务名称：Wallet Kit首页列表展示该开发者所有创建的服务时，服务名称用于区分不同的服务。
   * 服务号：用于Wallet Kit服务器区分不同的服务且保证唯一性。填写时需要遵守一定的格式要求： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/KBmbCrsLQ7u9Ahu6Q379mg/zh-cn_image_0000001077962214.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=E6736B9A5A5441AE5B81B6CE7DC8831AB980D2DF791F29A4B39F73775F93AEC8 "点击放大")

   * 接入方式：国内支持三种接入方式，App接入对应"App应用内、快应用、华为钱包CardStore方式"方式，云端接入对应"网页、短信、Email、App应用内方式"方式，**代理接入对应"网页、短信、Email、App应用内方式"方式** 。商户可以根据自己的需求选择适合自己类型的接入方式。

     选择云端接入时用户需要填写"回调地址"、"用户公钥"二项资料，选择App接入则只需要上传证书请求文件生成证书即可，**选择代理接入时用户需要填写"回调地址"一项资料，而用户公钥则会发送默认值到Wallet Kit服务器**。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/gIHg-PA3SFmdusHWGC2aLQ/zh-cn_image_0000001097040441.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C48F1393769FA0923BAD260BDB071BC2E165BC8D38AAB44A4F028DF83C6C700 "点击放大")

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/05/v3/M7lwUIEnSHOy1utKDaz4uw/zh-cn_image_0000001078250552.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=136F1C7F68869DE751C00AEA2539FB55921A6B2B1A8D7A6B32D79AD818E39E46 "点击放大")

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a2/v3/8tNXmdIyRTihinjPARTgrw/zh-cn_image_0000001097047503.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8F0D1353422FEE96BB7D499E424F256A9903C818C871CCEEA3B73971F27AAEF "点击放大")
   * 回调地址：开发者提供给Wallet Kit的地址，用于Wallet Kit反向回调开发者，用户领卡成功或删卡时回调开发者，具体请参见[回调接口公共定义](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/public-0000001050158472)。注：如果不需要Wallet Kit通知开发者用户领卡或删卡的状态，可以不填该字段。
   * 公钥：开发者将在[安全组件申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-rsa-0000001135545395)步骤中生成的公钥复制粘贴到此处，后续该公钥将作为Wallet Kit服务器认证开发者身份的方式。
   * 证书请求：开发者将在[安全组件申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-certificates-0000001088723154)步骤中生成的证书请求文件内容复制粘贴到此处，Wallet Kit服务器一般会在5分钟后生成公钥证书，可在Wallet Kit首页列表中点击对应的服务名称超链接后进入详情页面，点击"服务号.cer"文件即可下载到本地。

6. 点击"下一步"，进入NFC参数设置页面。

   * 是否支持跨移动设备同步：用户领取卡券后可通过此能力在同一帐号下的多设备中共享此卡券。商户默认选择"否"即可（如果需要支持此能力需要对应实现开发指南章节[商户实现卡券更新流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/access-common-update-0000001050044317)的接口）。

   * 是否开通NFC能力：服务类型为门钥匙、一卡通、门禁卡、交通卡、社会保障卡、港澳通行证、护照时，需要开通NFC能力，同时需要配置应用号和文件参数。其余的服务类型可以选择不开通NFC能力。

   * 应用ID（AID）：可以使用已有的应用ID；也可以通过右侧的"获取AID"按钮新创建新应用ID，该字段要求所填写的内容格式为16 进制数 (字符为 0-F)，最大长度为32（推荐32位），建议以"A000000048575041590100"开头。

   * 外部认证密钥：用于离线读写卡时外部认证校验。该字段要求所填写的内容格式为16进制数（字符为 0-F），最大长度为32（推荐32位）。

   * 文件参数定义：需要设置秘钥信息、备注，该秘钥用于对指定文件区域读写权限的控制，该字段要求所填写的内容格式为16进制数 (字符为 0-F)，最大长度为32（推荐32位）。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/blFaFDJZSoqlrFoFPfcr4A/zh-cn_image_0000001053063755.png?HW-CC-KV=V1&HW-CC-Date=20260909T170512Z&HW-CC-Expire=31536000000&HW-CC-Sign=A08FAA9A212D780003187EF4055752988970F59349596C06923611B04D1AFD79 "点击放大")
