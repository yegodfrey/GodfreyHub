# 使用入门

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-:|:-----------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001077961278)|在开发应用前，需要完成步骤：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001077961278#section47264296)、[创建项目](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001077961278#section196902382910)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001077961278#section294363472920)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001077961278#section2119133716579)、[获取AT](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001077961278#section169441820428)。 如果您已经在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站创建了应用，可直接[获取AT](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-api-preparations-0000001077961278#section169441820428)使用本服务。|
|2|[开通付费](#section12268164318111)|您可以随时变更订阅的按量付费套餐档次。|
|3|[Maps Static API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-static-map-introduction-0000001059170753)|将地图以图片的形式嵌入到您的网页中。|
|3|[Tile API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-tile-api-introduction-0000001059579175)|直接访问华为地图瓦片数据，请求独立的地图瓦片，构建地图图层。|
|3|[Tile Service API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-tile-service-introduction-0000001214239418)|提供自定义图层服务，支持创建并发布自定义图层。|
|3|[Elevation API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-elevation-api-introduction-0000001158669505)|查询经纬度对应的海拔数据。|
