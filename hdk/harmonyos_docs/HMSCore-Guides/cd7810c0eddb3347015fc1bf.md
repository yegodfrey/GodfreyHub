# 业务介绍

|-------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|钱包服务（Wallet Kit）集成了终端"芯-端-云"全栈技术的开放能力，可实现卡、证、券、票、钥匙等各类凭证电子化。让用户能够轻松地将门票、登机牌、会员卡、优惠劵、礼品卡保存在手机中，以便在适当的时间使用。同时Wallet Kit提供了通过基于位置的通知、实时动态更新、NFC等能力与用户进行互动。| |

## 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:----|:------------------------------|:--------------|
|手机、平板|Android 4.4及以上（API Level 19及以上）|4.0.0及以上|

## 服务优势

* 一键添加：提供网页、邮件、短信、华为钱包CardStore、快应用、App等多种接入方式，用户仅需点击按钮或链接一键添加卡片到华为钱包。
* 快速接入：4步（注册、认证，配置服务、开发应用），少量开发即可上线服务。
* 精准触达：基于时间、位置、Wi-Fi和nearby的精准实时智能提醒 。
* 便捷使用：支持指纹、双击电源键、设置主屏图标（homescreen icon）、App图标点击、熄屏刷卡等多种使用方式，并支持基于协议、位置和AI的智闪卡（AI Selected）功能。
* 全球覆盖：全球覆盖[200+的国家/地区](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-country-0000001121005720)。
