# UrlList跳转配置

## 跳转H5

如果想跳转商户H5请设置type为 "**URL**"即可。

```screen
{
  "urlList": [
    {
      "key": "urlList[0]",
      "value": "https://www.xxx.com.cn",//H5跳转地址
      "label": "label显示名称",//导流栏目显示名称
      "type": "URL" //固定
    }
  ]
}
```

## 跳转App

如果想跳转商户App请设置type为 "**APP**"即可,，另外需要设置一个appendFields字段，且key值需要和urlList中的key值相同。

```screen
{
  "urlList": [
    {
      "key": "urlList[0]",
      "value": "csa://android.mbp.csair.com:80",
      "label": "label显示名称",//导流栏目显示名称
      "type": "APP"
    }
  ],"appendFields": [
    {
      "key": "urlList[0]",
      "value": "应用App包名",
      "label": "App名称",
      "type": "APPGalery_PKG"
    }
  ]
}
```

## 跳转快应用

如果想跳转商户快应用请设置type为 "**FASTAPP**"即可。

```screen
{
  "urlList": [
    {
      "key": "urlList[0]",
      "value": "hwfastapp://com.xxx.xxx",//快应用跳转地址
      "label": "label显示名称",//导流栏目显示名称
      "type": "FASTAPP" //固定
    }
  ]
}
```
