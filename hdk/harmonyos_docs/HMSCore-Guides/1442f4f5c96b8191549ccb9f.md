# 写入跳绳运动记录

用户可以调用[addActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295#section1781411218216)方法插入跳绳运动记录，使用步骤如下：

1. 使用[跳绳](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/rope-jumping-0000001135051292)数据类型，在[ActivitySummary](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activity-summary-0000001055215648)结构中添加跳绳活动的特征数据结构ActivityFeature。
2. 构造[ActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecord_class-0000001050161730)，设置activityType名称为跳绳，名称取值参见[HiHealthActivities](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthactivities-0000001050089540)。
3. 构造[ActivityRecordInsertOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ario_class-0000001050091110)，使用[ActivityRecordsController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295).[addActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecordscontroller-0000001050091295#section1781411218216)插入跳绳运动记录数据到Health Service Kit。

   <br />

   ```
   // 请注意此处的this为Activity对象
   final ActivityRecordsController activityRecordsController = HuaweiHiHealth.getActivityRecordsController(this);

   // 1.构造请求对象的时间区间：开始和结束时间
   // 请注意此处设置的开始时间和结束时间均需大于2014年1月1号对应的UNIX时间戳
   Calendar cal = Calendar.getInstance();
   Date now = new Date();
   cal.setTime(now);
   long endTime = cal.getTimeInMillis();
   cal.add(Calendar.HOUR_OF_DAY, -1);
   long startTime = cal.getTimeInMillis();

   // 2.根据跳绳活动，构造跳绳活动的特征数据结构ActivityFeature,并将其添加至ActivitySummary结构中
   SamplePoint activityFeature = new SamplePoint.Builder(DataType.DT_ACTIVITY_FEATURE_JUMPING_ROPE).build();
   activityFeature.setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
   activityFeature.getFieldValue(Field.SKIP_NUM).setIntValue(125);
   activityFeature.getFieldValue(Field.STUMBLING_ROPE).setIntValue(2);
   activityFeature.getFieldValue(Field.MAX_SKIPPING_TIMES).setIntValue(2);
   activityFeature.getFieldValue(Field.DOUBLE_SHAKE).setIntValue(3);
   activityFeature.getFieldValue(Field.TRIPLE_SHAKE).setIntValue(1);
   ActivitySummary activitySummary = new ActivitySummary();
   activitySummary.setActivityFeature(activityFeature);


   // 3.根据跳绳速度统计数据采集器，构造统计数据样本点，并添加至DataSummary对象
   SamplePoint samplePointJumpRope = new SamplePoint.Builder(DataType.DT_CONTINUOUS_SKIP_SPEED_STATISTICS).build();
   samplePointJumpRope.setTimeInterval(startTime + 1L, startTime + 300000L, TimeUnit.MILLISECONDS);
   samplePointJumpRope.getFieldValue(Field.AVG).setIntValue(125);
   samplePointJumpRope.getFieldValue(Field.MAX).setIntValue(150);
   samplePointJumpRope.getFieldValue(Field.MIN).setIntValue(100);
   activitySummary.setDataSummary(Arrays.asList(samplePointJumpRope));

   // 4.构造运动记录，设置跳绳活动的ActivitySummary，与ActivityTypeId
   ActivityRecord activityRecord = new ActivityRecord.Builder()
       .setName("AddActivityRecord")
       .setDesc("This is ActivityRecord add test!")
       .setId("MyAddActivityRecordId")
       .setStartTime(startTime, TimeUnit.MILLISECONDS)
       .setEndTime(endTime, TimeUnit.MILLISECONDS)
       .setActivitySummary(activitySummary)
       .setActivityTypeId(HiHealthActivities.JUMPING_ROPE)
       .setMetadata("this is a jumping rope activity test")
       .setTimeZone("+0800")
       .build();

   // 5.创建一个跳绳速度明细数据采集器
   DataCollector dataCollectorSkip = new com.huawei.hms.hihealth.data.DataCollector.Builder()
       .setDataType(DataType.DT_INSTANTANEOUS_SKIP_SPEED)
       .setDataGenerateType(DataCollector.DATA_TYPE_RAW)
       .setPackageName(getApplicationContext())
       .setDataCollectorName("AddActivityRecord")
       .build();

   // 6.根据明细数据采集器，构造采样集
   SampleSet sampleSetSkip = SampleSet.create(dataCollectorSkip);

   // 7.构造跳绳速度明细（DT_INSTANTANEOUS_SKIP_SPEED）采样点对象，添加到明细数据采样集
   SamplePoint samplePointSkip = sampleSetSkip.createSamplePoint().setTimeInterval(startTime,endTime,TimeUnit.MILLISECONDS);
   samplePointSkip.getFieldValue(Field.SKIP_SPEED).setIntValue(110);
   sampleSetSkip.addSample(samplePointSkip);

   // 8.构造运动记录请求，设置运动记录activityRecord对象与其关联的明细数据采样集
   ActivityRecordInsertOptions insertOption = new ActivityRecordInsertOptions.Builder()
       .setActivityRecord(activityRecord).addSampleSet(sampleSetSkip).build();

   // 9.调用addActivityRecord方法添加跳绳运动记录
   Task<Void> addTask = activityRecordsController.addActivityRecord(insertOption);
   addTask.addOnSuccessListener(new OnSuccessListener<Void>() {
       @Override
       public void onSuccess(Void aVoid) {
           Log.i("ActivityRecords","ActivityRecord add was successful!");
       }
   }).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           Log.i("ActivityRecords", "Failed to add ActivityRecord" + e.getMessage());
       }
   });
   ```
