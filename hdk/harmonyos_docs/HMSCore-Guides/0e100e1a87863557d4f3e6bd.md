## 权益类问题

**如何开通推送服务权益？**

打开服务开关和配置推送服务参数，具体操作步骤请参见[开通推送服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137#section9471122085218)。

**如何查看应用是否已经开通推送服务权益？**

* 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择您的项目，点击"项目设置 > API管理"，查看"推送服务"开关，确保"推送服务"处于打开状态。
* 在您的项目设置页签，选择左侧导航栏"增长"里的推送服务，确保"推送服务"处于开通状态。

**推送服务权益异常如何排查？**

1. 请先检查您的应用是否已经成功开通推送服务，重复开通权益会报错。
2. 请检查您的应用是否已经在其他帐号中上传，如已上传，请到其他帐号中将应用删除或申请应用转移，详情请参见[应用转移操作指南](https://developer.huawei.com/consumer/cn/doc/50112)。
3. 请检查您的项目下是否已经存在应用，如未存在，请正常创建添加应用后重新开通推送服务权益。已存在应用的情况下，开通推送服务提示"应用不存在"，请检查之前是否执行过同包名应用的应用认领、删除应用等操作，如有该类操作，请先关闭原始项目的推送服务权益后再开通当前项目的推送服务权益。
4. 排除上述原因，若还不能解决，请提供您应用包名、应用APP ID、企业名称和帐号，通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=111)与我们进行联系。

**应用认领和应用转移对推送权益是否有影响？**

* 应用认领会导致某个应用推送服务权益失效和应用的APP ID变化，该应用需要重新申请推送服务权益并且更新之前应用的APP ID。
* 应用转移对推送权益没有影响。

**未发布到华为应用市场的应用是否可以使用推送服务？**

可以正常使用推送服务。建议您及时通过[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)将应用上架到应用市场以获得更好的服务体验。

## 接入类问题

**推送服务在非华为手机上的使用是否有限制？**

有限制，非华为手机需安装HMS Core APK才能正常使用推送服务，但可能存在兼容性问题，建议您使用华为手机进行测试。

**设备接收推送消息的条件？**

1. 设备：非华为手机需安装HMS Core APK（从您设备上的应用市场搜索下载），华为手机无特殊要求。
2. 网络：手机处于联网且网络稳定的状态。
3. EMUI版本：部分EMUI 4.0、4.1设备，EMUI 5.0及之后的设备。建议您使用EMUI 5.0以上设备。

受Android API的限制，海外低版本的华为手机和非华为手机推送只能在Android API level 21（Android 5.0）以上使用。

**如何给海外的用户推送消息？**

推送服务支持跨区域发送消息，但是跨区域消息下发性能会受到影响。建议您在用户聚集地部署服务器，减少跨区域消息发送。

**为什么推送消息失败？**

1. 请检查您是否已获取Token，如果获取Token失败，请参见[常见错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/commonerror-0000001059816656)查看获取Token失败原因。
2. 如果您已获取Token且使用推送运营平台推送消息，您可以在推送运营平台[测试推送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-basic-sendtestmsg-0000001087842114#section97511196319)。如果也推送失败则是Token存在问题，尝试重新获取Token。
3. 如果您已获取Token且使用REST API推送消息，请检查HTTP响应以确定消息头和消息内容是否正确，详情请参见[服务端API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197)返回码进行排查。
4. 您还可以通过[Push自助分析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/self-service-analysis-0000001404574041)功能，输入"requestId"和"token"查询消息具体发送情况。
5. 排除上述原因仍无法定位问题，请尽可能提供消息对应的"requestid"、发送的token、发送消息的时间、应用包名、应用APP ID、设备SN号，通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=111)与我们进行联系。

**终端设备上如何抓取日志** **？**

首先在您的电脑上安装adb，请参见[Android官方指导](https://developer.android.google.cn/studio/command-line/adb)。

1. 使用adb连上手机后，分别执行下面命令：

   ```screen
   adb shell setprop log.tag.hwpush VERBOSE
   adb logcat -v threadtime 1> D:\hwpush.log
   ```

2. 尝试复现您遇到的问题场景。
3. 按快捷键"Ctrl+C"完成日志抓取。

同时请您尽可能记录出现问题的设备型号、EMUI版本号、HMS Core（APK）版本号、集成的推送服务SDK版本号以及复现问题的步骤，以便技术人员可以更快的为您进行技术定位。

**客户端V2、V3版本和服务端V2、V3版本相互间的兼容？**

客户端V2、V3版本是指Push SDK的版本与HMS Core的版本。服务端V2、V3版本是指服务端提供的REST API版本，目前版本是V3版本，前向兼容V2版本。服务端V3版本提供了一些最新功能，需要端侧版本配套来完成，如果不升级端侧的版本新功能将无法使用，因此建议您尽快切换最新的版本。

**客户端获取的AAID是否需要及时清除？**

AAID不需要及时清除。

**推送服务是否强依赖华为帐号登录？**

推送不依赖华为帐号，用户不登录华为帐号也能够接收推送消息。

**推送服务是否支持推送语音消息？**

暂不支持直接推送语音消息，您可以通过下发[高优先级透传消息](#ZH-CN_TOPIC_0000001652491960__p134031056111017)使您的应用自己转语音消息。

**推送服务能否实现发送通知栏消息，当应用处于前台运行时不通过NC展示，通过某种方法将数据传递给应用？**

支持，请参见[前台应用的通知处理](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-fgrd-show-0000001050040126)。

## 消息呈现类问题

**为什么有些消息呈现样式不一致？**

从EMUI 10.0版本开始不同消息类型提醒方式和呈现样式上会有差异，具体请参见[消息分类标准](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835)。

**如何将展示的营销通知消息改为非营销通知消息？**

从EMUI 10.0版本开始推送服务智能的将通知消息分为服务与通讯消息、资讯营销消息。若要修改通知消息类型，需要[自分类权益申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835#section3410731125514)。自分类权益生效后，应用的推送消息将根据[message.android.category](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5203378238)字段进行归类。

**消息已经显示发送成功，但我的设备为什么收不到** **？**

1. 请确认您发送的是[通知栏消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/funtion-description-0000001050148080#ZH-CN_TOPIC_0000001700850773__p1064914503575)而不是[透传消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/funtion-description-0000001050148080#ZH-CN_TOPIC_0000001700850773__p66501501573)。
2. 请确认您发送的消息是否被归为[资讯营销类消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835#ZH-CN_TOPIC_0000001652651372__p18209135364510)，资讯类消息仅在下拉通知栏时才能看到，请下拉通知栏查看是否收到消息。
3. 请确认单个应用收到的通知栏消息未超过上限（EMUI 10&11上限为24条，EMUI 9为49条），超过上限后新消息直接丢弃，需要手动点击或删除一条展示的消息。
4. 通过[Push自助分析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/self-service-analysis-0000001404574041)功能查看消息发送情况。
5. 排除上述原因仍不能解决请尽可能提供消息对应的"requestid"、发送的token、发送消息的时间、应用包名、应用APP ID、设备SN号以及终端设备上的日志文件，通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=111)与我们进行联系。 说明
   >
   > 华为终端设备上请通过文件管理App搜索"push.log"和"NC.log"日志文件。

**推送服务点击消息无法打开目标activity，如何解决？**

1. 请确认点击消息是否跳转到您自己的应用，您无权打开其他应用activity。
2. 请检查目标activity是否存在且其"exported"属性为"true"，即目标activity要对外公开，并且无权限保护。
3. 请检查跳转的URI是否正确，请参见[自定义点击消息动作](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/andorid-basic-clickaction-0000001087554076)进行排查。
4. 排除上述原因仍不能解决请通过[在线工单系统](https://developer.huawei.com/consumer/cn/support/feedback/#/add/13?level2=111)与我们进行联系。

**推送服务是否支持消息撤回或消息覆盖？**

当前不支持消息撤回。消息覆盖请参见[通知栏消息覆盖展示](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-disp-overwr-0000001050042077)。

**在应用进程关闭的状态下，是否可以收到透传消息？**

* 普通透传消息，若应用启动管理为自动管理，则无法收到透传消息。
* [高优先级透传消息](#ZH-CN_TOPIC_0000001652491960__p134031056111017)，若EMUI版本为10.0.0及以上且应用启动管理为自动管理，则可以收到透传消息。

## 消息管控类问题

**推送服务在推送次数和频率方面有什么限制？**

推送次数限制：每天向某个设备上某个应用（非Token）发送消息数量不超过3000条，超过3000条进行限流（限流24小时后恢复）。

推送速率限制：华为推送服务对推送速度的分配，主要依据应用在华为终端上的月活和应用类型进行计算分配。

应用QPS=应用MAU × 应用类别权重 × 整体分配系数。
> 说明
>
> * QPS（Quantity per second）：每秒推送消息条数。
> * MAU（Monthly Active User）：月活跃用户人数。
> * 若您的应用通过QPS公式计算所得的值不足6000，将执行默认6000的QPS；同时，全网流量较高时，也会出现系统级流控（流控对应的状态码为[HTTP 503](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p43119414166)）。
> * QPS计算规则只适用于中国大陆。

应用在华为终端上MAU查询路径："华为开发者联盟 > 管理中心 > 应用服务 > AppGallery Connect > 开发与服务 > 推送服务 > 推送报告 > 推送用户详情 > 30日活跃用户数"

应用类别：应用在应用市场上架时选择的应用二级分类，查询路径："华为开发者联盟 > 管理中心 > 应用服务 > AppGallery Connect > APP > 应用信息 > 应用分类 > 应用二级分类"。

**使用REST 接口单次推送消息数量是多少？**

Push Kit服务器每次最多根据Token发送1000条消息。如果多于这个数字，需要开发者分批次发送。

**推送消息的最大大小为4KB，这是否意味着给1000个Token推送消息将超过此限制？**

消息体大小限制不包括Token。

**发送测试消息是否会被频控？**

为了方便开发者测试消息，在推送消息时可以设置[target_user_type](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p119823515519)参数为1。每个应用每日可发送500条测试消息且不受[每日单设备推送数量上限要求](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-restriction-description-0000001361648361#section104849311415)。

## 消息回执类问题

**消息回执是什么功能？**

消息回执是指Push Kit服务端将消息推送到用户终端之后，Push Kit端侧会给Push Kit服务端反馈送达结果，与此同时，Push Kit服务端会将消息送达状态以回执消息形式发送给您的应用回执服务端。

**推送服务的回执状态码有哪些？**

回执状态码详情请参见[消息回执](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-receipt-guide-0000001050040176)。

**消息回执的出口IP是什么？**

回执出口IP会变，不建议配置IP白名单，如果是出于安全考虑，建议[配置回调用户名和回调秘钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-receipt-guide-0000001050040176#ZH-CN_TOPIC_0000001700731529__li1967238121017)进行身份验证。

**如何更换回执服务器证书？**

* 场景1：新旧证书均为商用CA签发证书或自签证书但CA未改变。 您只需更换回执服务器上的证书，不需要登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站做其他修改。

* 场景2：新证书为商用CA签发证书，旧证书为自签证书。 您需要更换回执服务器上的证书，并登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站同步修改回执配置。此操作过程中回执服务不会中断。

  修改回执配置操作：
  1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"开发与服务"，在项目列表中找到您的项目，通过"增长 > 推送服务 > 配置"导航到"配置"页签。
  2. 选择需要修改回执的应用，点击"修改"应用回执状态。
  3. 在"选择回执"页面，选择需要更换证书的回执，点击"修改"。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/31/v3/t9t12aocSU6x37Ibl_NXsA/zh-cn_image_0000001700850957.png?HW-CC-KV=V1&HW-CC-Date=20260915T074230Z&HW-CC-Expire=31536000000&HW-CC-Sign=7339FEAF0DC2CF6FD078E631F135E3A65818FB4B0CA09E78EBDF545E89658EAE)
  4. 在"回执配置"页面，回执服务会检测最新的证书信息，您无需做任何修改。
  5. 点击"提交"，保存回执信息。
  6. 点击"确定"，返回"配置"页面。
* 场景3：新旧证书均为自签证书且CA有变化。 为确保新旧证书替换过程中回执服务不中断，在更换回执服务器上的证书前，您需要先登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，将新证书设置为"备用证书"。

  在30天内现有证书和备用证书均被回执服务信任，30天后若回执服务器已完成证书更换，回执服务将使用备用证书替换现有证书。

  设置备用证书操作：
  1. 参考[场景2](#ZH-CN_TOPIC_0000001652491960__li616213236713)的[1](#ZH-CN_TOPIC_0000001652491960__li107723205182)~[3](#ZH-CN_TOPIC_0000001652491960__li0773122016181)进入"回执配置"页面。
  2. 在"回执配置"页面，点击"设置备用证书"，填入新证书信息。

     ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/pS2Zw1raTg-qKPgv_bZ0Nw/zh-cn_image_0000001700850953.png?HW-CC-KV=V1&HW-CC-Date=20260915T074230Z&HW-CC-Expire=31536000000&HW-CC-Sign=99F614A477E9055AA0E51FAFD6F77EC95EDC4E2CC59749F25505310D75CC4E6E)

  4. 点击"确定"，返回"配置"页面。

## 消息报表类问题

**推送服务报表统计数据怎么查看？**

* 统计报表查看路径："华为开发者联盟 > 管理中心 > 应用服务 > AppGallery Connect > 开发与服务 > 推送服务 > 推送报告"
* 统计报表规则：当前报表不是实时更新，统计数据会有1天的延迟。

**报表数据条目各字段是什么意思？**

字段详情请参见[推送报告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oper-report-0000001050042123)。

**报表数据中"未达消息详情 > 其他原因"主要是什么原因？**

未达消息详情中的其他原因大多数情况是通知栏消息点击后无权限打开应用内页面下intentUri指向的activity。

解决方案：

1. 点击消息拉起应用内页面，都是通过跨应用启动Activity的方式来实现，需要保证要拉起的目标Activity存在且其"exported"属性为"true"，即目标Activity要对外公开，并且目标Activity无权限保护。
2. 请参见[打开应用自定义页面](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/andorid-basic-clickaction-0000001087554076#section17768170161516)生成正确的intent参数。

请参见[HMS公共方法](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/huaweiapiavailability-0000001050121134)判断。

**在Android 13设备上，应用的通知默认处于关闭状态，此时用户无法接收通知栏消息，应用如何进行适配？**

* 若应用的targetSdkVersion为33或更高版本，您的应用需要注册新的通知权限"POST_NOTIFICATIONS"，且动态申请该应用权限。
* 若应用的targetSdkVersion为32或更低版本，请及时适配并且升级最新的[Push SDK版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-app-version-0000001074227861)。

具体操作请参见[Android官方指导](https://developer.android.google.cn/about/versions/13/changes/notification-permission)。

**在Android 11上，已安装HMS Core（APK）最新版本，仍然提示升级，如何解决？**

Android 11更改了应用查询用户在设备上已安装的其他应用以及与之交互的方式。您应用的"targetSdkVersion"是30或者更高版本，并且集成的Push Kit 6.1.0.300之前版本时，将无法访问HMS Core（APK），并且持续提示升级。

您可以通过以下两种方法解决。

* 方法一： 升级Push Kit的SDK至6.1.0.300及以上版本，版本信息请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-app-version-0000001074227861)。


* 方法二： 如果不升级SDK，需要在"AndroidManifest.xml"中manifest下添加<queries>标签。

  ```screen
  <manifest ...>
      ...
      <queries>
          <intent>
              <action android:name="com.huawei.hms.core.aidlservice" />
          </intent>
      </queries>
      ...
  </manifest>
  ```

  > 说明
  >
  > <queries>标签对工具的要求如下：
  > * Android Studio需升级至3.3或更高版本。
  > * Android Gradle插件需升级至3.3.3、3.4.3、3.5.4、3.6.4、4.0.1或4.1.0及更高版本。
