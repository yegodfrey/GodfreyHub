# 在华为钱包内领取卡券

#### 概述

商户注册开发者联盟应用后需要在相应位置配置推广服务，开发者联盟会将产品内容上架至华为钱包App内的内容展示位，用户点击内容展示内可加载出商户添加卡券入口(商户H5添卡界面)，用户根据引导可以将卡券添加至华为钱包中。  
![](https://media:101782807015849678)  
目前这种方式暂时只支持中国大陆区域开放。

![](https://media:101782807015888679 "点击放大")  

#### 商户配置推广服务

商户通过申请开发者联盟应用后可配置相应的推广服务 ，可将产品内容上架至华为钱包App内的内容展示位，合作伙伴可触达华为钱包里的优质流量，以提高商品或品牌的曝光度和知名度。

例：通过申请推广服务，合作伙伴可将内容配置到开发者联盟中，图片素材及目的访问URL地址需由合作伙伴提供，华为运营人员审核后发布。

1. 创建Wallet Kit推广服务。

   <br />

   ![](https://media:101782807015917680)

   <br />

2. 选择推广样式。

   <br />

   ![](https://media:101782807015960681 "点击放大")

   <br />

3. 上传资料。

   <br />

   ![](https://media:101782807015988682)

   <br />

4. 创建推广服务成功。

   <br />

   ![](https://media:101782807016018683)

   推广服务可以让用户在访问华为钱包会员卡等栏目时浏览到商户配置的推广服务展示位，用户可以点击配置的展示位跳转到商户相对应的推广H5，此H5推广界面可以是用户申领会员卡界面或其他推广内容。

   <br />

#### 商户H5领取卡券到钱包

用户可以通过点击钱包内配置的推广服务展示位进入商户的H5页面，在完成商户H5中的业务操作后，可以允许用户添加卡券到华为钱包并在卡包中展示。基本流程为：

1. 商户H5提交用户领卡请求到商户服务器。
2. 商户生成JWE数据。

   <br />

   ![](https://media:101782807016043684)  
   1. 商户服务器生成jwe业务逻辑请参考[codelab](https://developer.huawei.com/consumer/cn/codelab/HMSWalletKit/index.html#0)。
   2. codelab中的[服务器示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/java-sample-code-0000001050157448)为"JWE示例代码"。
   3. codelab第6步中生成的jwe可用于后续步骤3。

   <br />

3. 商户服务器返回jwe给H5页面，H5通过特定方式（schema）拉起钱包完成领卡。

   <br />

   H5从商户服务器获取jwe后，可通过以下方式在钱包内完成领卡：

   ```
   //H5中调用schema
   <a href="wallet://com.huawei.wallet/walletkit/consumer/pass/save?content={jwe_content}">ADD</a>
   ```

   ![](https://media:101782807016066685)  
   最终的访问链接请不要带"{}"，即content=xxxx即可。

   如果添卡时需要跳过钱包端侧添加预览页面，可以在链接后添加\&preview=0跳过预览，无参或传参非0时仍展示钱包端侧预览页面，例如：

   \<a href="wallet://com.huawei.wallet/walletkit/consumer/pass/save?content={jwe_content}\&preview=0"\>ADD\</a\>

   <br />

4. 用户领取卡券或删除卡券时，华为服务器会回调商户服务器进行通知，商户服务器可以[开发回调接口](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References-V5/callback-0000001050160427-V5)实现该能力。
