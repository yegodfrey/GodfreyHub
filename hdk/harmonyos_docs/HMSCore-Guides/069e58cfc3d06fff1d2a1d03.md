# 购买非PMS商品场景

#### 发起非PMS商品购买

您的应用需要使用[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)接口发起非PMS购买，同时在[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842)中传入签名内容。开发步骤如下：

      1. 构造请求参数[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842)。在创建[PurchaseIntentReq](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentreq-0000001050135842)请求对象时，需通过[setReservedInfor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/basereq-0000001347850688#section5685381934)方法传入orderExt，其中包含自定义商品信息、productId及developerPayload等，具体可参见reservedInfor参数。

您在构造orderExt中的orderExtParamSignature参数时，需要传递使用支付私钥进行加签后生成的加密字符串，签名算法请使用“SHA256WithRSA/PSS”，具体请参见orderExtParam签名处理。

示例如下： 
             
             "{\"orderExt\":{\"orderExtParam\":\"{\\\"reservedCommonInfo\\\":{\\\"applicationId\\\":\\\"10066668\\\",\\\"nonce\\\":\\\"4e03fd4a36c74d769d8bc6bdc1384ff6\\\",\\\"timestamp\\\":1689148288242},\\\"productId\\\":\\\"sku1\\\",\\\"developerPayload\\\":\\\"1a3ec4d2872c40f5bc62214d66474cf8\\\",\\\"extCustomProductInfo\\\":{\\\"price\\\":100,\\\"currency\\\":\\\"CNY\\\",\\\"productName\\\":\\\"testProduct\\\",\\\"sdkChannel\\\":\\\"1\\\",\\\"srvCatalog\\\":\\\"X5\\\"}}\",\"orderExtParamSignature\":\"**********\"}}"

      2. 发起[createPurchaseIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1255302563115)请求。当接口请求成功时，您可获取到一个[PurchaseIntentResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseintentresult-0000001050135852)对象，其[getStatus](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/result-0000001050123085#section32821622269)方法返回了一个[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象，您的应用需要通过[Status](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132)对象的[startResolutionForResult](https://developer.huawei.com/consumer/cn/doc/hmscore-common-References/status-0000001050121132#section04641751152411)方法来启动华为IAP收银台。

      3. 在您的应用拉起收银台并且当用户完成支付后（成功购买商品或取消购买），华为IAP会通过onActivityResult方式将此次支付结果返回给您的应用。您可以使用[parsePurchaseResultInfoFromIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/iapclient-0000001050137587#section1317716106377)方法获取包含结果信息的[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseresultinfo-0000001050135886)对象。

         * 当用户购买成功时，可从[PurchaseResultInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/purchaseresultinfo-0000001050135886)对象中获取到购买数据[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)及其签名数据，您需要使用在华为AppGallery Connect分配的公钥进行签名验证。为避免资金损失，您在验签成功后，必须校验[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)中的productId、price、currency等信息的一致性，验证一致后发货。验证方法和公钥获取请参见[验证InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verifying-inapppurchasedata-0000001494212281)。

IAP SDK的[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)类可用于解析[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/json-inapppurchasedata-0000001050986125)字符串，您可使用该类构造一个[InAppPurchaseData](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/inapppurchasedata-0000001050137635)对象并从该对象中获取相关信息。

         * 用户购买消耗型商品时，如果返回以下支付异常则需要检查是否存在掉单情况，具体请参见[消耗型商品的补单流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/redelivering-consumables-0000001051356573)。 
           * 支付失败（OrderStatusCode.ORDER_STATE_FAILED）
           * 已拥有该商品（OrderStatusCode.ORDER_PRODUCT_OWNED)
           * 默认返回码（OrderStatusCode.ORDER_STATE_DEFAULT_CODE）
    
    “Java”
    @Override
    protected void onActivityResult(int requestCode, int resultCode, Intent data) {
        super.onActivityResult(requestCode, resultCode, data);
        if (requestCode == 6666) {
            if (data == null) {
                Log.e("onActivityResult", "data is null");
                return;
            }
            // 调用parsePurchaseResultInfoFromIntent方法解析支付结果数据
            PurchaseResultInfo purchaseResultInfo = Iap.getIapClient(this).parsePurchaseResultInfoFromIntent(data);
            switch(purchaseResultInfo.getReturnCode()) {
                case OrderStatusCode.ORDER_STATE_CANCEL:
                    // 用户取消
                    break;
                case OrderStatusCode.ORDER_STATE_FAILED:
                case OrderStatusCode.ORDER_STATE_DEFAULT_CODE:
                case OrderStatusCode.ORDER_PRODUCT_OWNED:
                    // 检查是否存在未发货商品
                    break;
                case OrderStatusCode.ORDER_STATE_SUCCESS:
                    // 支付成功
                    String inAppPurchaseData = purchaseResultInfo.getInAppPurchaseData();
                    String inAppPurchaseDataSignature = purchaseResultInfo.getInAppDataSignature();
                    // 使用您应用的IAP公钥验证签名
                    // 若验签成功，必须校验InAppPurchaseData中的productId、price、currency等信息的一致性，验证一致后发货
                    // 若用户购买商品为消耗型商品，您需要在发货成功后调用consumeOwnedPurchase接口进行消耗
                    break;
                default:
                    break;
            }
        }
    }

#### orderExtParam签名处理

发起非PMS购买时，您需通过[setReservedInfor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/basereq-0000001347850688#section5685381934)方法传入签名内容，其中orderExtParamSignature签名值的获取，请参照如下示例生成：

      1. 构造待签名订单扩展参数字符串。

         * 参见orderExtParam参数说明，创建orderExtParam对象。
         * 将构造好的orderExtParam对象，转化为JSON字符串。

例如：
    
    "{\"reservedCommonInfo\":{\"applicationId\":\"10066668\",\"nonce\":\"4e03fd4a36c74d769d8bc6bdc1384ff6\",\"timestamp\":1689577778336},\"productId\":\"sku1\",\"developerPayload\":\"1a3ec4d2872c40f5bc62214d66474cf8\",\"extCustomProductInfo\":{\"price\":100,\"currency\":\"CNY\",\"productName\":\"testProduct\",\"sdkChannel\":\"1\",\"srvCatalog\":\"X5\"}}"

      2. 使用支付私钥对订单扩展参数源字符串进行签名。

         * 获取用于签名的支付私钥。

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135224.43099515721496072086575708419594:50001231000000:2800:B93A63D318D72E368FF19E0C1D8B419AD3F0A06415F1DB049D4B21E072B4CF37.png)

         1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn)，点击“管理中心”。
         2. 在“生态服务-应用服务”页面，选择“开发服务-支付”，然后点击“获取支付信息”。

         * 将源串使用SHA256WithRSA/PSS算法进行签名，签名后的字符数组经过Base64.encode编码，生成签名值。 

![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135224.95112427790631547074200677222718:50001231000000:2800:CD82FE472CD250D7D48512F5EFEC17E236691CE62C85B1ADEC77A9ADC29977B2.png)

业务可能持有多对支付公私钥，orderExtParamSignature需要标注使用哪把支付私钥签名，签名值格式：密钥编号-签名字符串，例如0-签名。

Java示例： 
    
    /**
     * 使用支付私钥对orderExtParam对象进行签名处理
     * @param orderExtParam 订单扩展参数
     * @param privateKey 支付私钥
     * @return orderExtParamSignature
     */
    public static String getSignData(OrderExtParam orderExtParam, String privateKey){
        // orderExtParamSignature需要标注使用哪把支付私钥签名，签名值格式：密钥编号-签名字符串，例如0-签名
        // JsonUtil为自定义类，您需要自定义objec对象转JSON String方法
        return "0-" + sign(JsonUtil.toJson(orderExtParam), privateKey);
    }
    /**
     * 使用SHA256WithRSA/PSS签名
     *
     * @param content 待签名的JSON String内容
     * @param privateKey 支付私钥
     * @return 签名后的值
     */
    public static String sign(String content, String privateKey) {
        try {
            byte[] privateKeyArray = org.apache.commons.codec.binary.Base64.decodeBase64(privateKey);
            PKCS8EncodedKeySpec priPKCS8 = new PKCS8EncodedKeySpec(privateKeyArray);
            KeyFactory keyf = KeyFactory.getInstance("RSA");
            PrivateKey priKey = keyf.generatePrivate(priPKCS8);
            Security.addProvider(new BouncyCastleProvider());
            Signature signature = Signature.getInstance("SHA256WithRSA/PSS");
            signature.initSign(priKey);
            signature.update(content.getBytes(StandardCharsets.UTF_8));
            byte[] signed = signature.sign();
            // 将签名后的字符数组经过Base64.encode编码
            return Base64.encode(signed);
        } catch (Exception e) {
            log.error("Exception when signing", e);
            throw new IapRuntimeException(e);
        }
    }
