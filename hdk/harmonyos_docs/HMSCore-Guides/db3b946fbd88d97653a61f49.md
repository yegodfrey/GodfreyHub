# 获取个人资料

获取华为运动健康App"我的 \> 个人资料"中的用户性别、出生日期、身高、体重。  
![](https://media:901788166641116891)  
个人资料中的数据是由用户自己填写的。如果用户连接了体脂秤，并授权将体脂秤数据同步到个人资料，则体重数据会同步体脂秤数据。  
图1 个人资料   
![](https://media:901788166641145893)

使用这4个接口前，需要向华为申请开通权限，并获取用户授权，否则接口将调用失败。

#### 获取用户性别

1. 调用[HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459)对象的[getGender](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__getGender-android_content_Context-com_huawei_hihealth_listener_ResultCallback-)方法，获取用户性别。
2. 通过请求参数[ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451)对象，返回查询结果。

   <br />

   示例代码：

   ```
   HiHealthDataStore.getGender(context, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object gender) {
           if (resultCode == HiHealthError.SUCCESS) {
               // 获取用户性别数据成功：0 女，1 男，2 保密，-1 未设置
               int value = (int) gender;
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
               // 授权失效
               Log.w(TAG, "Permission denied");
           } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
               // 未同意运动健康隐私协议
               Log.w(TAG, "Privacy user denied");
           } else if (resultCode == HiHealthError.ERR_NETWORK) {
               // 网络异常
               Log.w(TAG, "Network request failed");
           } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
               // 测试权限的用户数量超过限制
               Log.w(TAG, "Beta scope permission denied");
           } else {
               // 其他错误，调用失败
               Log.w(TAG, "Other error, invoking method failed");
           }
       }
   });
   ```

   |参数名称|参数类型|参数描述|可选选项|
   |:-------------|:-------------|:---|:----|
   |genderCallback|ResultCallback|结果回调|必选(M)|
   [表2 请求参数]

   |参数名称|参数类型|参数描述|
   |:---------|:-----|:------------------------------------------------------------------------------------------------------------------------|
   |resultCode|int|处理结果码 * 0：成功 * 其他：参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-errocode-0000001053256958)|
   |gender|Object|* 成功：性别。int类型，可选值为： * 0（女）； * 1（男）； * 2（保密）； * -1（未设置） * 其他：错误信息描述（String）|
   [表3 响应参数]

   <br />
