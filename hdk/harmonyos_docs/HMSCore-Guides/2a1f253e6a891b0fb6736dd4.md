# 基于主题组合条件的消息推送

支持基于布尔表达式的主题组合条件来进行消息推送。消息体示例展示了向订阅了"weather"和"sports"主题的用户推送消息。目前只有Android应用可以使用条件推送，字段详细说明请参见"[condition](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p20317488232)"。

消息体示例：

```screen
{
    "validate_only": false,
    "message": {
        "notification": {
            "title": "message title",
            "body": "message body"
        },
        "android": {
            "notification": {
                "click_action": {
                    "type": 1,
                    "action": "com.huawei.codelabpush.intent.action.test"
                }
            }
        },
        "condition": "'weather' in topics && 'sports' in topics"
    }
}
```
