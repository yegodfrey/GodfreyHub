# 使用入门

#### 开发环境

Android 平台

* 安装Android Studio 3.6.1及以上

* JDK 1.8.211及以上
* 您的应用应满足以下条件：

  * minSdkVersion 23
  * targetSdkVersion 33 (推荐)
  * compileSdkVersion 33（推荐）
  * Gradle 5.4.1及以上 （推荐）
* 测试应用的设备：

  * EMUI 4.0及以上版本的华为手机或手机系统为HarmonyOS
* 手机装有华为运动健康App  

#### 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。  

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|接入准备|1. [申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)：因Health Service Kit服务需要用到账号服务的能力，需先申请账号服务才能申请Health Service Kit服务。若在基础能力服务中已经创建移动应用则可以跳过该步骤。 2. [申请 Health Service Kit 服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-apply-kitservice-0000001211703555)：申请产品所需的数据读写权限。 若有除该页面上的其他的需求，请发送邮件到[hihealth@huawei.com](mailto:hihealth@huawei.com)邮箱向我们咨询。 说明： 权限申请通过后才能走通后续的调测过程，否则会由于权限校验失败导致 Health Service Kit 扩展能力服务相关功能无法按照期望运行。|
|2|开发准备|1. [集成 HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-integrating-sdk-0000001050060847)：在开发应用前，您需要将Health Service Kit扩展服务能力的SDK集成到您的开发环境中。 2. [配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-config-obfuscation-scripts-0000001071222399)：编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|3|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-requesting-user-authorization-0000001071733944)|使用Android Studio开发环境，根据本手册指导，完成应用接入Health Service Kit扩展能力服务相关功能的开发。|
|4|[调测验证](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-commissioning-verification-0000001050159257)|对照测试用例，进行测试。|
|5|[申请验证](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/verification-0000001196917670)|应用开发完成后，提交申请验证，以获得Health Service Kit正式权限。|
|6|应用上架|1. [上架前自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001241357623)：使用华为自检工具在线对应用进行自检，并按照华为提供的自检Checklist进行开发自检。 2. [上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001196437746)：将完成的应用提交华为方进行审核，审核时间一般为1\~2个工作日。|
