# 接入流程  
  
#### 开通与集成

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115211.36945242440180250975382391142093:50001231000000:2800:AAA64096FDE22A7141976832D6791C4312B7D79B0A60C8AAE5CA8D4A9A86D996.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

使用流程 | 说明  
---|---  
开通华为分析服务 | 请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-enabling-0000001050745155)  
集成对应平台的SDK | 
                * Android：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876)
                * HarmonyOS（JAVA）：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-integrating-sdk-0000001122915056)
                * HarmonyOS（JavaScript）：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-integrating-sdk-0000001204836867)
                * iOS：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-integrating-sdk-0000001050168479)
                * macOS：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/macos-integrating-sdk-0000001195808936)
                * Web：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-integrating-sdk-0000001051065743)
                * 快应用：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickapp-integrating-sdk-0000001090944199)
                * 快游戏：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/quickgame-integrating-sdk-0000001193852242)
                * 微信小程序：[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/miniprogram-integrating-sdk-0000001198008599)  
创建自定义属性（可选） | 当预置属性无法满足用户使用时，使用[数据管理](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-management-0000001078364352)创建自定义属性。  
自定义用户属性导入云侧（可选） | 当需要导入自定义用户属性用于数据分析时，使用[云侧接入](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/cloud-side-access-0000001135700508)。  
上报数据 | 华为分析服务SDK[自动采集事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-automatic-event-collection-0000001051757143)、埋点上报[预置事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-usage-guide-0000001135571462)、埋点上报[自定义事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-custom-events-0000001051597159)。  
华为分析服务SDK[自动采集用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-automatic-user-attribute-0000001050705118)、埋点上报[预置用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-predefined-user-attribute-0000001064469606)、埋点上报[自定义属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-import-customized-user-attributes-0000001050747215)。  
可视化分析与下钻研究 | 查看[丰富的数据分析报告](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dashboard-0000001050985173)。  
使用[过滤器](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/filter-introduction-0000001123199087)与时间选择器进行下钻分析。  
精准触达，驱动智能决策 | 集成[华为推送服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-introduction-0000001050040060)，针对细分受众精准推送消息。  
开通[A/B测试](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-introduction-0000001058210679)，针对不同受众测试应用的界面、文案等更改是否更符合用户需求，提高决策准确率。  
集成[远程配置](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-video-remoteconfig-0000001086672820)，针对不同受众定制应用风格及内容。  
集成[崩溃服务](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-video-crash-0000001086864686)，监控应用质量，提升用户体验。  
集成[应用内消息](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-video-appmessage-0000001133409387)，实现情景式精准触达。  
集成[应用内支付](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/introduction-0000001050033062)，分析用户付费转化，洞察指标背后增长点。
