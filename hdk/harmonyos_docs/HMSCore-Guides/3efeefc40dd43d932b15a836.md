# 存储数据

应用可以将血压、血糖、体重、科学睡眠详情和心率详情数据写入华为运动健康App。可以一次存储单条数据，也可以一次存储多条数据。  
![](https://media:901788166653190186)  
* 若存储的是体重、血压数据，存入的开始时间要等于结束时间（startTime= endTime），否则将存储失败。
* 若存储科学睡眠详情数据，存入的开始时间和结束时间必须为整分钟时间戳(startTime % 60000 = 0，endTime % 60000 = 0)，且开始时间和结束时间只能相差一分钟（endTime= startTime + 60000），否则存储失败。

存储这些数据前，需要向华为申请开通权限，并获取用户授权，否则接口将调用失败。

#### 存储单个数据

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [saveSample](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__saveSample-android_content_Context-com_huawei_hihealthkit_data_HiHealthData-com_huawei_hihealth_listener_ResultCallback-) 方法，存储单个数据。
2. 通过请求参数 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451) 对象，返回查询结果。

   <br />

   示例代码 体重为例

   ```
   Map map = new HashMap();
   // 可以在HiHealthPointType类中查找样本集中的所有类型
   map.put(HiHealthPointType.DATA_POINT_WEIGHT, 70.5D);
   map.put(HiHealthPointType.DATA_POINT_WEIGHT_BMI, 18.8D);
   map.put(HiHealthPointType.DATA_POINT_WEIGHT_MUSCLES, 33.5D);
   map.put(HiHealthPointType.DATA_POINT_WEIGHT_BODYFAT, 23.5D);
   map.put(HiHealthPointType.DATA_POINT_WEIGHT_PROTEIN, 14.5D);
   map.put(HiHealthPointType.DATA_POINT_WEIGHT_PROTEIN_VALUE, 12.5D);
   final long endTime = System.currentTimeMillis();
   final long startTime = endTime;
   HiHealthSetData hiHealthSetData =
       new HiHealthSetData(HiHealthSetType.DATA_SET_WEIGHT_EX, map, startTime, endTime);
   HiHealthDataStore.saveSample(context, hiHealthSetData, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object object) {
           Log.i(TAG, "saveSample resultCode is " + resultCode);
           if (resultCode == HiHealthError.SUCCESS) {
               Log.i(TAG, "saveSample resultList: " + object);
           } else if (resultCode == HiHealthError.PARAM_INVALID) {
               // 参数错误
               Log.w(TAG, "Param invalid");
           } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
               // HMS Core版本过低
               Log.w(TAG, "HMS version is too early");
           } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
               // 授权失效
               Log.w(TAG, "Permission denied");
           } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
               // 未同意运动健康隐私协议
               Log.w(TAG, "Privacy user denied");
           } else if (resultCode == HiHealthError.ERR_NETWORK) {
               // 网络异常
               Log.w(TAG, "Network request failed");
           } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
               // 测试权限的用户数量超过限制
               Log.w(TAG, "Beta scope permission denied");
           } else {
               // 其他错误，建议提示调用失败
               Log.w(TAG, "Other error, invoking method failed");
           }
       }
   });
   ```

#### 存储多个数据

1. 调用 [HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459) 对象的 [saveSamples](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__saveSamples-android_content_Context-java_util_List-com_huawei_hihealth_listener_ResultCallback-) 方法，存储多个数据，需为同一类型数据。
2. 通过请求参数 [ResultCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/resultcallback-0000001071549451) 对象，返回查询结果。

   <br />

   示例代码 体重为例

   ```

   map1.put(HiHealthPointType.DATA_POINT_WEIGHT_BMI, 20.8D);

       currentTime - oneDayInMillis, currentTime - oneDayInMillis);

   Map map2 = new HashMap();
   map2.put(HiHealthPointType.DATA_POINT_WEIGHT, 73D);

       new HiHealthSetData(HiHealthSetType.DATA_SET_WEIGHT_EX, map2, currentTime, currentTime);
   hiHealthDataList.add(hiHealthSetData2);
   HiHealthDataStore.saveSamples(context, hiHealthDataList, new ResultCallback() {
       @Override
       public void onResult(int resultCode, Object object) {
   ```
