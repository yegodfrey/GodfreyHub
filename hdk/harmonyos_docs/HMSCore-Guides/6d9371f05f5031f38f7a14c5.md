# 简介

智能跳绳设备通过 Gym Profile 可以接入华为运动健康App。跳绳设备与华为运动健康App 绑定后，支持自由跳绳，定时计数，定数计时三种跳绳模式，跳绳过程中，显示时间，个数，平均速度，最快速度，当前连跳等多种数据，并且支持与华为穿戴心率设备联动。

## 智能跳绳设备接入运动健康的使用体验

**图2**智能跳绳设备绑定流程   
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/u72hfqzgS7ySUnb1RZJG0Q/zh-cn_image_0000002547959091.png?HW-CC-KV=V1&HW-CC-Date=20261008T164851Z&HW-CC-Expire=31536000000&HW-CC-Sign=F9EA319FB5FEA11D8189AE8A2812DB5162D8113A4C3EC49A5DD7F4CE28F145A3 "点击放大")

1. 在运动健康App的设备管理中添加设备，选择智能跳绳设备
2. 根据界面上的提示，使得智能跳绳设备进入蓝牙配对模式。
3. 选择已经搜索到的智能跳绳设备，完成配对。

**图3**跳绳运动的三种模式   
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6d/v3/VsgqAcBtSvyNsPJ5KhcSrw/zh-cn_image_0000002548039091.png?HW-CC-KV=V1&HW-CC-Date=20261008T164851Z&HW-CC-Expire=31536000000&HW-CC-Sign=13400AA76366B333602170CEF0274E4DA356312A2CCD2B4D313BC7E1AB88AD9C "点击放大")

设备绑定后，支持在运动健康App 中启动自由跳绳，定时计数，定数计时三种模式的跳绳活动，并且跳绳过程中可以与华为穿戴设备联动获取实时心率数据。

跳绳过程中显示跳绳个数，时间，热量，平均速度，绊绳，最多连跳，平均心率（需要与华为穿戴设备联动）。
