# 设计及部署二维码和 NFC 标签

从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library-V5/sport-device-sdk-0000001051809026-V5)的开发套件中获取"一碰联二维码样例及说明"。

## 设计标签

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/K8xcZFuSTF6YOjOPo30_pw/zh-cn_image_0000001222805124.png?HW-CC-KV=V1&HW-CC-Date=20261008T144416Z&HW-CC-Expire=31536000000&HW-CC-Sign=0A483F906ECBD51465EEA71BEA85072C187F0D8D6116269BE4A2920EE978A832)

* 二维码大小：19mm * 24mm；
* 二维码内容示例：https://url.cloud.huawei.com/1Lfn1eswP6?a=c&t=262&n=Huawei-xxxx&p=2&pid=xxxx

  |参数|值|
  |:---|:---------------------------|
  |t|设备类型，跳绳 -- 262|
  |n|被连接设备的蓝牙广播名称|
  |pid|ProdID，即产品ID （在开发者联盟注册时可获取到）|
  |其他参数|不变|
  [**表1**参数]

* 使用在线二维码生成工具生成二维码。

**图2**NFC标签

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5d/v3/fO87aypYSKuz7RWGRFkwuA/zh-cn_image_0000001223285052.png?HW-CC-KV=V1&HW-CC-Date=20261008T144416Z&HW-CC-Expire=31536000000&HW-CC-Sign=CA305EFB8C7DA89BD64F7F175D5842D06CDE26D7CC9B12E61EC3447E1269BAA6)

* 标签线圈大小： 11mm * 27mm（小件设备）
* 标签NDEF格式（携带两个NDEF Record，按顺序存放）：
  1. Record1： - mime-type：huawei.sports/address

     - content： t=x&ble=xx:xx:xx:xx:xx:xx&pid=xxxx

     Record1参数解释：
     * 标签名是 Android 系统需要读的
     * t=x 表示设备类型。跳绳--262
     * ble=xx:xx:xx:xx:xx:xx。表示蓝牙Mac 地址，后面由分号结尾
     * pid=xxxx。表示ProdID，即产品ID （在开发者联盟注册时可获取到）
  2. Record2： - mime-type：AAR

     - content：com.huawei.health

     Record2参数解释：
     * AAR：标准的 Android Application Record 类型定义
     * com.huawei.health： 运动健康App的包名

## 部署标签

1. 从[下载中心](https://developer.huawei.com/consumer/cn/doc/HMSCore-Library-V5/sport-device-sdk-0000001051809026-V5)的开发套件中获取部署工具 sporthealthdeploytool_tool.apk，并安装在手机上。
2. 从开发套件中获取部署工具使用指南，根据使用指南和 sporthealthdeploytool_tool 将蓝牙模块信息写入写入二维码/NFC标签。


3. 将标签粘贴在设备上。
