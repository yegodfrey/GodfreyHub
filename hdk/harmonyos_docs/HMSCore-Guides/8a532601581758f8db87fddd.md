# 优惠券

## 概述

商家在开展促销业务时所制作、投放的有效凭证，用户可以领取多种形式的优惠券后对原有商品/服务的价格进行减免。

Wallet Kit已提供优惠券接入华为钱包的能力，商户可通过多种方式轻松将卡券集成到华为钱包中。

### 处理过期卡券

在钱包应用的卡券详情页下如果卡券已过期则会自动标记一个过期的Icon。如果卡券满足过期或无效中的一个条件，系统就会将其移至"过期卡券"部分。

在HwWalletObject.fields.status.expireTime过期后的 24 小时内，卡券会随时移至"过期卡券"。

HwWalletObject.fields.status.state字段标记为expired、inactive或completed。

### 地理围栏通知

当前地理围栏通知暂时只支持通过REST API方式添加的卡券。

**地理围栏概念**

基于华为定位能力，当商户开发者通过REST API接口在模板中设置LocationList时，当前卡券即具备了地理围栏通知的能力，当用户距离设定的目标200米范围内即可触发地理围栏通知。
> 说明
>
> 每种卡券每天最多通知5次，超过次数当天不会再下发地理围栏通知。

**使用REST API** **接口添加地理围栏目标点坐标**

定义模板信息时商户可设置LocationList，每个模板LocationList最多可设置3个目标点。

```screen
HwWalletObject hwWalletObject = new HwWalletObject(); 
.....
// 地理围栏信息 
List<Location> locationList = new ArrayList<>(); 
Location location = new Location(); 
location.setLongitude("113.0679603815");
location.setLatitude("25.6592051284");
locationList.add(location); 
fields.setLocationList(locationList); 
......
hwWalletObject.setFields(fields);
```

### 链接到已保存的卡券

用户保存某张卡券后，钱包提供二种方式查看卡券。

* 浏览器方式查看卡券

  ```screen
  https://{walletkit_website_url}/walletkit/consumer/pass/instance?issuerId=xxx&instanceId=xxxx
  ```

  请求地址中的*{walletkit_website_url}*变量需要开发者根据服务器所属区域自行选择，列表如下：

  |China|walletpass-drcn.cloud.huawei.com|
  |Russia|walletpass-drru.cloud.huawei.com|
  |Asia, Africa, and Latin America|walletpass-dra.cloud.huawei.com|
  |Europe|walletpass-dre.cloud.huawei.com|

  > 说明
  > * 如果用户手机安装了华为钱包应用，且当前方式使用Intent加载时会弹出选择框给用户，用户可选择用钱包或者浏览器加载此链接。
  > * instanceId：卡券实例Id。
  > * issuerId：对应[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上AppId，请参见下图。

### 优惠结束通知

华为钱包针对优惠券提供有优惠结束提醒，商户为卡券设置PassObject.Status.expireTime后华为钱包会在优惠结束24小时提醒用户优惠即将到期。

提醒会在00:00-06:00分静默，如果通知是在此时段内则会在静默时间前30分钟提醒。
