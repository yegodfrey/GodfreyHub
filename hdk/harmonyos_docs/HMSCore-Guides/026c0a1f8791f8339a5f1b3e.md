# 3D地形

HuaweiMapEx提供3D地形功能，可展示地形的高低起伏及山脉走向。

开启3D地形功能，请调用HuaweiMapEx的render3DTerrain方法，开启3D地形后，地图上的点线面等覆盖物会根据地形起伏进行展示。
> 说明
>
> * 安卓的要求为CPU：高通骁龙845、天玑9000、麒麟810及更高配置；RAM：4GB以上；推荐系统：Android 8.1及以上系统。ios的配置要求为iPhone-8-Plus及以上机型iPad-Air（第三代)，iPad-mini（第五代），iPad-Pro（第二代）10.5英寸及以上机型；支持系统：iOS9.0及以上系统。
> * 剩余运行内存需大于850M。

示例代码如下：

```screen
"Java"
mhwMapEx.setMapType(mhwMapEx.MAP_TYPE_TERRAIN);
// 开启3D地形功能
mhwMapEx.render3DTerrain(true);
```

```screen
"Kotlin"
mhwMapEx?.setMapType(mhwMapEx?.MAP_TYPE_TERRAIN)
// 开启3D地形功能
mhwMapEx?.render3DTerrain(true)
```

（可选）为增强3D视觉效果，可通过terrain3DScale方法设置3D地形拉伸系数，增强对比度。

示例代码如下：

```screen
"Java"
mhwMapEx.setMapType(mhwMapEx.MAP_TYPE_TERRAIN);
// 开启3D地形功能
mhwMapEx.render3DTerrain(true);
// 设置3D地形拉伸系数
mhwMapEx.terrain3DScale(10.0f);
```

```screen
"Kotlin"
mhwMapEx?.setMapType(mhwMapEx?.MAP_TYPE_TERRAIN)
// 开启3D地形功能
mhwMapEx?.render3DTerrain(true)
// 设置3D地形拉伸系数
mhwMapEx?.terrain3DScale(10.0f)
```
