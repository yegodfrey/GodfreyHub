# 3D自由相机

基于3D地图场景下，为实现沉浸式地图浏览效果，HuaweiMapEx提供了更加灵活和精准的相机控制接口moveCamera。

## 相机移动

当相机位置与目标位置坐标不一致时，移动相机步骤：

1. 构建FreeCameraPosition对象，设置参数：目标位置、相机高度、相机位置。
2. 调用HuaweiMapEx的moveCamera方法，并传入FreeCameraPosition对象。

示例代码如下：

```screen
"Java"
LatLng target = new LatLng(48.52, 2.25);
LatLng lo = new LatLng(48.62, 2.35);
FreeCameraPosition cameraPos = new FreeCameraPosition(target, 50.0f, lo);
hMapEx.moveCamera(cameraPos);
```

```screen
"Kotlin"
val target = LatLng(47.893478, 2.334595)
val lo = LatLng(48.893478, 3.334595)
val cameraPos = FreeCameraPosition(target, 50.0f, lo)
hMapEx?.moveCamera(cameraPos)
```

## 相机移动（垂直视角）

当相机位置与目标位置坐标一致时，垂直视角移动相机步骤：

1. 构建FreeCameraPosition对象，设置参数：目标位置、相机高度、相机位置、相机上方向。
2. 调用HuaweiMapEx的moveCamera方法，并传入FreeCameraPosition对象。

设置不同的相机上方向值，可实现更加灵活的3D相机移动效果。

* 设置相机上方向为(0, 1)。

  示例代码如下：

  ```screen
  "Java"
  LatLng target = new LatLng(48, 2);
  LatLng lo = new LatLng(48, 2);
  FreeCameraPosition cameraPos = new FreeCameraPosition(target, 150000.0f, lo);
  DPoint3D dPoint3D=new DPoint3D(0, 1);
  // 设置相机上方向(0, 1)
  cameraPos.setUp(dPoint3D);
  hMapEx.moveCamera(cameraPos);
  ```

  ```screen
  "Kotlin"
  val target = LatLng(48.0, 2.0)
  val lo = LatLng(48.0, 2.0)
  val cameraPos = FreeCameraPosition(target, 150000.0f, lo)
  val dPoint3D = DPoint3D(0, 1)
  // 设置相机上方向(0, 1)
  cameraPos.setUp(dPoint3D)
  hMapEx?.moveCamera(cameraPos)
  ```

* 设置相机上方向为(1, 1)。

  示例代码如下：

  ```screen
  "Java"
  LatLng target = new LatLng(48, 2);
  LatLng lo = new LatLng(48, 2);
  FreeCameraPosition cameraPos = new FreeCameraPosition(target, 150000.0f, lo);
  DPoint3D dPoint3D=new DPoint3D(1, 1);
  // 设置相机上方向(1, 1)
  cameraPos.setUp(dPoint3D);
  hMapEx.moveCamera(cameraPos);
  ```

  ```screen
  "Kotlin"
  val target = LatLng(48.0, 2.0)
  val lo = LatLng(48.0, 2.0)
  val cameraPos = FreeCameraPosition(target, 150000.0f, lo)
  val dPoint3D = DPoint3D(1, 1)
  // 设置相机上方向(1, 1)
  cameraPos.setUp(dPoint3D)
  hMapEx?.moveCamera(cameraPos)
  ```

"相机位置"与"目标位置"坐标同为(48, 2)时，相机上方向设置为(0, 1)与(1, 1)的效果展示：
