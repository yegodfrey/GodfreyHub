# 在地图上绘制

## 概览

本节介绍如何在地图上绘制标记和形状。详情请参见[Flutter示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-flutter-0000001208537346)。

## 标记

用户可以在地图的指定位置添加标记以标识位置、商家、建筑等，并可以通过信息窗口展示详细信息。

### 添加标记

以下示例代码使用默认图标在地图上添加一个简单标记：

```screen
HuaweiMap( 
    markers: _markers, 
    ...
Marker? marker1; 
marker1 = Marker( 
    markerId: MarkerId('marker_id_0'), 
    position: LatLng(41.012959, 28.997438), 
    infoWindow: InfoWindow( 
        title: 'Marker Title #0', 
        snippet: 'Marker Desc #0', 
    ), 
    clickable: false, 
    icon: BitmapDescriptor.defaultMarker, 
    ); 
_markers.add(marker1!);
```

您可以用自定义图像代替默认图标，还可以设置标记属性来改变标记图标。

### 自定义标记

您可以使用自定义图像修改默认标记图标。自定义图像由"BitmapDescriptor"对象（图像描述文件）指定，该对象可以由[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-bitmapdescriptor-0000001208024788)类的构造函数生成。

以下代码片段创建一个带有自定义图标的标记：

```screen
Marker? marker1; 
marker1 = Marker( 
    markerId: MarkerId('marker_id_0'), 
    position: LatLng(41.012959, 28.997438), 
    infoWindow: InfoWindow( 
        title: 'Marker Title #0', 
        snippet: 'Marker Desc #0', 
    ), 
    clickable: false, 
    icon: _markerIcon, 
    ); 
_markers.add(marker1!); 
 
Future<void> _createMarkerImageFromAsset(BuildContext context) async { 
    if (_markerIcon == null) { 
        final ImageConfiguration imageConfiguration = 
            createLocalImageConfiguration(context); 
        BitmapDescriptor.fromAssetImage(imageConfiguration, 'assets/huawei.png') 
            .then(_updateBitmap); 
    } 
} 
   
void _updateBitmap(BitmapDescriptor bitmap) { 
    setState(() { 
      _markerIcon = bitmap; 
    }); 
}
```

### 修改标记

地图服务Flutter插件不支持直接修改标记的属性，因为标记是不可变的。要修改标记属性，请调用[Marker.updateCopy](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-marker-0000001253144699#section1181mcpsimp)方法。

示例代码如下：

```screen
Marker? marker1; 
marker1 = Marker( 
    markerId: MarkerId('marker_id_0'), 
    position: LatLng(41.012959, 28.997438), 
    infoWindow: InfoWindow( 
        title: 'Marker Title #0', 
        snippet: 'Marker Desc #0', 
    ), 
    clickable: false, 
    onClick: () { 
        log('marker #0 clicked'); 
    }, 
    icon: BitmapDescriptor.defaultMarker, 
); 
       
marker1 = marker1!.updateCopy( 
    infoWindow: InfoWindow( 
        title: 'Marker #0 Title', 
        snippet: 'Marker #0 Desc', 
    ), 
    rotation: 45); 
    ...
```

### 聚合标记

地图服务Flutter插件支持对标记进行聚合，以便在不同缩放级别的地图上有效地管理标记。当用户将地图缩放级别调整到高级别（放大地图）时，所有标记都会显示在地图上。当用户将地图缩放级别调整到低级别（缩小地图）时，标记会进行聚合，以便在地图上有序地展示。

您可以参见如下步骤实现标记聚合功能：

1. 将HuaweiMap中的"markersClusteringEnabled"设置为true。

   ```screen
   HuaweiMap( 
        /* 
        Other Configurations 
        */ 
        markerClusteringEnabled: true, 
        ...
   ```

2. 将需要聚合的标记的"clusterable"属性设置为true。

   ```screen
   Marker( 
        markerID: MarkerId("clusterMarker01"), 
        position: Latlng(41.004919, 28.980701), 
        clusterable: true 
   )
   ```

### 标记事件侦听

* **标记点击事件**

  您可以使用"onClick"来侦听标记点击事件。标记点击事件的默认动作是显示标记的信息窗口（如果可用），并将标记置于地图上的中心点。

  ```screen
  Marker(
  markerId: MarkerId('marker_id_2'),
  position: LatLng(41.070978, 29.037736),
  clickable: true,
  onClick: () {
  log('marker #2 clicked');
  },
  ...
  ```

* **标记拖拽事件**

  您可以使用"onDragEnd"来侦听标记拖拽事件。要拖动标记，用户需要长按标记，将其拖动到屏幕上的指定位置，然后释放。当用户停止拖动标记时，将调用onDragEnd(LatLng)方法。

  ```screen
  Marker(
  markerId: MarkerId('marker_id_2'),
  position: LatLng(41.070978, 29.037736),
  draggable: true,
  clickable: true,
  onDragEnd: (pos) {
  log("marker #2 dragEnd : ${pos.lat}:${pos.lng}");
  },
  ...
  ```

### 设置标记的动画

地图服务SDK提供了设置标记动画的方法。涉及的类如下表所示。

|类|描述|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:---------|
|[HmsMarkerAlphaAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkeralphaanimation-0000001208344756)|控制透明度的动画类。|
|[HmsMarkerRotateAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkerrotateanimation-0000001208504730)|控制旋转的动画类。|
|[HmsMarkerScaleAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkerscaleanimation-0000001253144703)|控制缩放的动画类。|
|[HmsMarkerTranslateAnimation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-hmsmarkertranslateanimation-0000001252864739)|控制移动的动画类。|

以下代码创建动画和标记：

```screen
// 定义动画并设置其属性。
HmsMarkerAlphaAnimation alphaAnimation = HmsMarkerAlphaAnimation( 
      animationId:"alphaAnimation", fromAlpha:0.1, toAlpha:1.0); 
 
// 定义标记并将其添加到地图上。
Marker? marker0; 
marker0 = Marker( 
    markerId:MarkerId("marker_id_0"), 
    position:LatLng(41.048641,28.977033), 
    clusterable:true, 
    animationSet: [alphaAnimation] 
); 
 
_markers.add(marker0!);
```

### 添加信息窗口

信息窗在标记上方的弹出窗口中显示文本或图像，为标记提供详细信息。

添加标记信息窗的最简单方法是设置相应"Marker"对象的"infoWindow"属性。如果用户点击标记，则会显示该标记的信息窗口。

示例代码如下：

```screen
Marker( 
    markerId: MarkerId('marker_id_2'), 
    position: LatLng(41.070978, 29.037736), 
    infoWindow: InfoWindow( 
        title: 'Marker Title #2', 
        snippet: 'Marker Desc #2', 
    ), 
...
```

## 覆盖物

地图覆盖物是固定在地图上的图片。

### 添加覆盖物

1. 为您的覆盖物创建由[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-bitmapdescriptor-0000001208024788)对象（图像描述文件）指定的自定义图像，该对象可以由[BitmapDescriptor](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-bitmapdescriptor-0000001208024788)类的构造函数生成。
2. 使用"groundOverlayId"、"width"、"height"、"position"和"imageDescriptor"参数来添加一个覆盖物。

   示例代码如下：

   ```screen
   HuaweiMap( 
       groundOverlays: _groundOverlays, 
       ...
   _groundOverlays.add(GroundOverlay( 
       groundOverlayId:GroundOverlayId("go_2"), 
       imageDescriptor: _groundOverlayImage, 
       position: LatLng(41.028682, 29.115737), 
       width:1500, 
       height:1500, 
       clickable:true, 
       onClick: () { 
           log("Ground Overlay #2 pressed."); 
      }, 
   ));
   ```

地图SDK不支持直接修改覆盖物的属性，因为覆盖物是不可变的。要修改覆盖物属性，请调用[GroundOverlay.updateCopy](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-groundoverlay-0000001208344754#section2838mcpsimp)方法。

示例代码如下：

```screen
GroundOverlay? go1; 
go1 = GroundOverlay( 
    groundOverlayId:GroundOverlayId("go_1"), 
    imageDescriptor: _groundOverlayImage, 
    position: position, 
    onClick: () { 
        log("Ground Overlay #1 pressed."); 
    }, 
    width:3000, 
    height:3000, 
    anchor:Offset(0.1,0.2), 
    zIndex:10.0, 
    transparency:0.0, 
    clickable:true, 
    ); 
       
go1 = go1!.updateCopy( 
    width:4000,  
    height:4000,  
    transparency:0.5 
);
```

### 侦听覆盖物事件

您可以设置GroundOverlay对象的clickable属性，以指定相关的覆盖物是否可点击。您可以为"onClick"字段设置函数来侦听覆盖物点击事件。

示例代码如下：

```screen
GroundOverlay( 
    groundOverlayId:GroundOverlayId("go_2"), 
    imageDescriptor: _groundOverlayImage, 
    position: LatLng(41.028682, 29.115737), 
    width:1500, 
    height:1500, 
    clickable:true, 
    onClick: () { 
        log("Ground Overlay #2 pressed."); 
    },         
);
```

## 形状

地图服务Flutter插件支持在地图上添加不同的形状，包括折线、多边形和圆。

### 添加折线

折线由多个有序的[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-latlng-0000001252864733)对象组成。

1. 创建折线对象。 示例代码如下：

   ```screen
   List<LatLng> dots1 = [ LatLng(41.003285, 28.954506), LatLng(40.998218, 29.031455), ];

   Polyline polyline = Polyline(
   polylineId: PolylineId('polyline_id_0'),
   points: dots1,
   color: Colors.green[900],
   zIndex: 2,
   clickable: true,
   onClick: () {
   log("Polyline #0 clicked");
   });
   ```

   **图3**折线

2. 修改折线对象。 地图SDK不支持直接修改折线的属性，因为折线是不可变的。要修改折线的属性，可以调用[Polyline.updateCopy](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polyline-0000001253264695#section2316mcpsimp)方法。

### 添加多边形

和折线类似，多边形由一组有序的坐标组成。不同的是，多边形是一个封闭的区域。

1. 创建多边形。 示例代码如下：

   ```screen
   dots1 = [ LatLng(41.012959, 28.997438), LatLng(41.007243, 29.040482), LatLng(41.029763, 28.988469) ];

   Polygon(
   polygonId: PolygonId('polygon_id_0'),
   points: dots1,
   fillColor: Colors.green[500],
   strokeColor: Colors.green[900],
   strokeWidth: 5,
   zIndex: 2,
   ...
   ```

2. 修改多边形。 地图SDK不支持直接修改多边形的属性，因为多边形是不可变的。要修改多边形的属性，可以调用[Polygon.updateCopy](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-polygon-0000001208024792#section1773mcpsimp)方法。

   示例代码如下：

   ```screen
   Polyline? polygon;
   polygon = Polygon(
   polygonId: PolygonId('polygon_id_0'),
   points: dots1,
   fillColor: Colors.green[500],
   strokeColor: Colors.green[900],
   strokeWidth: 5,
   zIndex: 2,
   });

   polygon = polygon!.updateCopy(
   points: [ LatLng(40.990743, 29.029218), LatLng(41.041527, 29.007200), LatLng(41.032397, 29.030850) ]
   );
   ```

3. 侦听多边形点击事件。 您可以设置Polygon对象的clickable属性来指定对应的多边形是否可点击。

   您还可以使用"onClick"来侦听多边形点击事件。

   示例代码如下：

   ```screen
   Polygon(
   polygonId: PolygonId('polygon_id_1'),
   points: dots2,
   fillColor: Colors.yellow[300],
   strokeColor: Colors.yellow[900],
   zIndex: 1,
   clickable: true,
   onClick: () {
   log("Polygon #1 clicked");
   }
   ...
   ```

## 瓦片图层

瓦片图层是显示在基础地图瓦片上方的图像集合。

### 添加瓦片图层

1. 创建瓦片对象列表并设置所需的参数。 示例代码如下：

   ```screen
   List<Tile> tiles =
   [Tile(
       x:4,
       y:2,
       zoom:3,
       imageData: imageData,
   ),
       Tile(
       x:4,
       y:3,
       zoom:3,
       imageData: imageData,
   ),
   ];
   ```

2. 创建[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlay-0000001253144701)对象并设置所需的参数。

   示例代码如下：

   ```screen
   TileOverlay? tileOverlay = TileOverlay(
   tileOverlayId:TileOverlayId("tile"),
   tileProvider: tiles,
   fadeIn:true,
   transparency:0.5,
   visible:true,
   zIndex:2,
   );
   ```

3. 将创建的[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-tileoverlay-0000001253144701)对象添加到HuaweiMap中。

   ```screen
   HuaweiMap(
   tileOverlays: _tileOverlays,
   ...
   _tileOverlays.add(tileOverlay!);
   ```
