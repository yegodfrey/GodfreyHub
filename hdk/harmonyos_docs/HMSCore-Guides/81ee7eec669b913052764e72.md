# 配置AppGallery Connect

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115323.38865263086338456169568566183682:50001231000000:2800:CBFE53C7B3F753093065065704ED2A20704DC313CED91BF63C083C39CFC918F3.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

在项目中添加应用时，平台选择“iOS”。

#### 操作步骤

                1. 如果没有[华为开发者联盟](https://developer.huawei.com/consumer/cn/)帐号，需要先注册帐号并通过实名认证。详细操作请参见[ _帐号注册认证_](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
                2. 参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。
                3. 开通华为分析服务：
                   1. 登录[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。 
                   2. 选择已创建完成的应用。 
                   3. 点击“华为分析”下的任意菜单，并点击“启动分析服务”可开通分析服务。（注：需拥有产品管理权限才可开通服务。）

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115323.69734529075032227675255737793099:50001231000000:2800:024CF7F3F27FB3D7FC5EB84DFE0914B21580B90273C67BB63B21911398D5FF71.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

                   4. 进入“项目接入设置”页面，设置数据处理位置、设置用户数据留存时间、设置自然周定义后，点击“完成”，即完成Analytics Kit服务开通。 

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115323.52477377579458397678439845285832:50001231000000:2800:8C20C7751B442F62C06AB78FECAAB0651DA5CF48258D63B9834DA52D7C2CDB56.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

如果您的应用发布到全球多个国家，建议您启用多数据处理位置，使用[configWithRoutePolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ios-api-analytics-0000001050164675#section6458123533116)初始化SDK，按照用户实际使用区域指定数据上报位置。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115323.64425309263431589248563740957590:50001231000000:2800:9F6ED4EE493B8E988650FC566E5B89F1422F9D8F5E09FB2392DD6459041AC839.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

请打开[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的项目”，在项目列表中找到您要打开的项目并点击，在AppGallery Connect界面选择“项目设置  > API管理”查看是否开启华为分析。
