# 免登录授权开发

三方应用云侧接入SDK支持Health Service Kit免登录授权提供两种方案。

[方案一](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud-free-auth-login-overview-0000002054076576#section172541133124513)通过调用[LoginFreeAuthController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-android-package-loginfreeauthcontroller-0000002055258508)类中的接口[requestLoginFreeAuthorizationIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-android-package-loginfreeauthcontroller-0000002055258508#ZH-CN_TOPIC_0000002547959337__section2994161111515)来实现，[方案二](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud-free-auth-login-overview-0000002054076576#section2569123718475)通过调用[LoginFreeAuthController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-android-package-loginfreeauthcontroller-0000002055258508)类中的接口[requestAuthorizationWithPrivacyIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-android-package-loginfreeauthcontroller-0000002055258508#section46669234509)来实现，两种方案接口入参一致，参数说明如下。

如果华为账号未登录时，应用直接拉起华为账号登录和授权界面，由用户授权相应的数据访问权限。如果账号已登录时，再次请求授权，用户无需重复登录即可直接拉起授权界面，由用户授权相应的数据访问权限。用户可以自主选择授权的数据类型，可以只授权部分数据权限。应用所能操作的用户数据，是用户授权和Health Service Kit服务审批通过的数据权限的交集。  

#### 参数说明

调用免登录授权接口共需要准备以下5个参数：scopes，state，clientId，deepLinkUrl，signature：

* scopes是申请授权的Scope字符串数组，一个字符串数组，以空格分开（URL编码后空格变为加号+），必须包含字符串"openid" ，更多权限请参见[OAuth权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/steps-0000001177343435#section165119447225)。
* state是随机串，用于防CSRF，在返回授权码Code时原封不动返回。

* clientId是三方在[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050747587)过程中创建应用生成的APP ID值，可在应用详情里服务信息中应用 ID查看该参数clientId的值。

  ![](https://media:901788166646402043 "点击放大")
* deepLinkUrl是三方应用deeplink拉起授权页授权后可以把授权结果返回给三方应用的Scheme地址，可在应用详情里Scheme信息中的应用Scheme地址查看该参数deepLinkUrl的值。 ![](https://media:901788166646450044 "点击放大")

* signature是申请Scheme地址时云端分配的secret，可在应用详情里Scheme信息中的Scheme Secret查看该参数signature内容。 ![](https://media:901788166646500046)

  <br />

#### 方案一开发步骤

1. 在应用主Activity的onCreate方法中初始化[LoginFreeAuthController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-android-package-loginfreeauthcontroller-0000002055258508)，并启动授权流程。

   <br />

   ```
   @Override
   protected void onCreate(Bundle savedInstanceState){
       super.onCreate(savedInstanceState);
       initService();
       // 步骤2授权流程，每次启动时调用一下
       requestAuth();
   }

   /**
    * 初始化LoginFreeAuthController
    */
   private void initService(){
       // 请注意此处的this为Activity对象
       mLoginFreeAuthController = HuaweiHiHealthLite.getLoginFreeAuthController(this);
   }
   ```

   这里定义的变量如下：

   ```
   // LoginFreeAuthController对象
   private LoginFreeAuthController mLoginFreeAuthController;
   ```

   <br />

2. 需要申请的Scope权限（权限请参见[OAuth权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/steps-0000001177343435#section165119447225)），通过[LoginFreeAuthController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-android-package-loginfreeauthcontroller-0000002055258508)的[requestLoginFreeAuthorizationIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/lite-sdk-android-package-loginfreeauthcontroller-0000002055258508#ZH-CN_TOPIC_0000002547959337__section2994161111515)获取集成华为账号Scope授权、华为运动健康App和H5授权的Intent。

   <br />

   ```
   /**
    * 声明需要申请的Scope，并获取Intent启动授权流程，此方法必须在Activity中使用
    */
   private void requestAuth(){
       // 添加需要申请的权限，这里只是举例说明，开发者需要根据实际情况添加所需的权限
       String[] scopes = new String[] {
           "https://www.huawei.com/healthkit/step.read",
           "https://www.huawei.com/healthkit/distance.read",
           "https://www.huawei.com/healthkit/heartrate.read"
       };
       // 获取注册应用时获得的App ID
       String appid = "xxx";
       // 开发者申请免登录授权时设置的schema信息，即授权完成后接收授权码的deeplink url地址
       String deepLinkUrl = "xxx";
       // 根据 appid和应用注册回调链接的scheme secrect
       String signature = "您应用的Scheme信息中的Scheme Secret";
       // 随机串，和授权码一起返回
       String state = "xxx";
       // 获取授权流程Intent
       Intent intent = mLoginFreeAuthController.requestLoginFreeAuthorizationIntent(scopes, state, appid, deepLinkUrl, signature);
       // 打开授权流程页面
       Log.i(TAG, "start authorization activity");
       startActivityForResult(intent, REQUEST_AUTH_LOGIN_FREE);
   }
   ```

   这里使用的常量如下：

   ```
   // 通过startActivityForResult方式拉起授权流程界面的请求码，具体数值开发者可以自行定义
   private static final int REQUEST_AUTH_LOGIN_FREE = 2000;
   private static final String TAG = "HealthKitLoginFreeAuthActivity";
   ```

   <br />

3. 获取授权码。在三方应用中创建一个LoginFreeDeepLinkActivity接收授权码，并在AndroidManifest.xml清单中添加一个包含以下元素和属性值的 Intent，假设注册应用时申请的回调链接为test://demo/comeback，清单文件配置如下：

   <br />

   ```
   <activity android:name=".activity.healthkit.healthauth.LoginFreeDeepLinkActivity">
       <intent-filter>
           <action android:name="android.intent.action.VIEW"/>
           <category android:name="android.intent.category.DEFAULT"/>
           <category android:name="android.intent.category.BROWSABLE"/>
           <data android:scheme="test"
                 android:host="demo"
                 android:path="/comeback"/>
       </intent-filter>
   </activity>
   ```

   LoginFreeDeepLinkActivity中代码如下：

   ```
   public void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.main);

       Intent intent = getIntent();
       String action = intent.getAction();
       Uri data = intent.getData();
       if (data == null) {
           Log.i(TAG, "Intent data is null. ");
           return;
       }
       try {
           String scheme = data.getScheme();
           String host = data.getHost();
           // 如果code不为空，即授权成功
           String code = data.getQueryParameter("code");
           // 此处state为授权时传入的state，因为该参数非必填，所以state可能为空
           String state = data.getQueryParameter("state");
           // 如果授权失败，可根据返回的error和error_description字段判断授权失败原因，错误码可参考：错误码
           String error = data.getQueryParameter("errorCode");
       } catch (Exception e) {
           Log.i(TAG, "Failed to get intent data.");
       }
   } 
   ```

   <br />

4. 如果三方应用deepLinkUrl错误或者该参数正确但是该参数与清单文件配置不一致，此时三方应用无法通过deepLinkUrl接收授权结果信息，三方应用开发者可以通过覆写onActivityResult方法获取错误码，示例代码如下：

   <br />

   ```
   @Override
   protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
       super.onActivityResult(requestCode, resultCode, data);
       Log.i(TAG, "HealthKitLoginFreeAuthActivity onActivityResult");
       if (requestCode == REQUEST_AUTH_LOGIN_FREE) {
           if (data == null) {
               Log.i(TAG, "Intent data is null.");
           } else {
               if (data.getIntExtra("DEEPLINK_RESULT", 0) == 0) {
                   Log.i(TAG, "deeplink success");
               } else {
                   int error = data.getIntExtra("DEEPLINK_RESULT", 0);
                   String errorMsg = data.getStringExtra("DEEPLINK_MSG");
                   Log.e(TAG, "deeplink fail,error is: " + error + ",errorMsg is: " + errorMsg);
               }
           }
       }
   }
   ```
