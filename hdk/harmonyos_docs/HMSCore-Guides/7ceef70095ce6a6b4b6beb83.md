# 开发准备

## 集成SDK

华为支付服务集成了收银台能力，开发者的APP通过集成华为支付服务SDK，简便快捷地实现应用支付能力。

|--------------------------------------------------------------------------------------------------------------------------------------|
|SDK名称：华为支付服务SDK|
|开发者：花瓣支付（深圳）有限公司|
|版本号：6.13.0.300|
|主要功能：华为支付服务SDK的主要功能介绍请参见[业务介绍](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-introduction-0000001536000984)|
|个人信息处理规则：[SDK隐私声明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sdk-privacy-statement-0000001586756085)|
|合规使用说明：[SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sdk-compliance-user-guide-0000001721336757)|

针对Android Studio开发环境，华为提供了Maven仓集成方式的SDK包。在开始开发前，开发者需要将华为支付服务SDK集成到开发者的Android Studio开发环境中。

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

### 添加应用的AppGallery Connect配置文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到开发者的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2f/v3/D6FlhwoJTOeo_l3nRoTb2g/zh-cn_image_0000002512199745.png?HW-CC-KV=V1&HW-CC-Date=20261008T172505Z&HW-CC-Expire=31536000000&HW-CC-Sign=4E3FEF6327DF0457BC34B143D7C2C210EE0A59005009432EE1B51FB2D6064E0D "点击放大")

4. 将"agconnect-services.json"文件拷贝到应用级根目录下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/8Gz9z5lcSpGapfKerZNWuQ/zh-cn_image_0000002512279721.png?HW-CC-KV=V1&HW-CC-Date=20261008T172505Z&HW-CC-Expire=31536000000&HW-CC-Sign=CAE61FA3A951FA6B99ABD57E0FD5CF4D71E22CA3D7B4ADC7613C2218E450B808)

### 配置SDK的Maven仓地址

参见[Maven仓库地址配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-maven-repository-0000001970825281#section63821917164110)。

### 添加SDK编译依赖

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

1. 打开应用级"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/VfjcjgHDQGW-8zp6SVjdHA/zh-cn_image_0000002480159848.png?HW-CC-KV=V1&HW-CC-Date=20261008T172505Z&HW-CC-Expire=31536000000&HW-CC-Sign=263C7024A5FBA583548711BD4C6F47104AF71909E381A9C4B31EB7BFAACFA48D)


2. 在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:paymentservice:6.12.0.300'
   }
   ```

   > 说明
   >
   > SDK版本号索引请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041#section163461949192517)，例如：implementation 'com.huawei.hms:paymentservice:6.12.0.300'。
3. 在完成以上的配置后，点击工具栏中的gradle同步图标，完成"build.gradle"文件的同步，将相关依赖下载到本地。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1b/v3/uGXVKFXkSi2Dk66elYNxmQ/zh-cn_image_0000002480159846.png?HW-CC-KV=V1&HW-CC-Date=20261008T172505Z&HW-CC-Expire=31536000000&HW-CC-Sign=D508405EC6C76D0D7673EBE9473E95908EA08DB7CF71934413D2E8399CEE1CD3)
   > 说明
   >
   > 1、如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
   >
   > 2、若开发者的APP有添加Gson依赖且依赖华为支付服务SDK后编译或运行时报Gson三方依赖包冲突，需要使用exclude排除Gson依赖冲突，代码如下：
   >
   > ```screen
   > implementation 'com.huawei.hms:paymentservice:6.12.0.300'{
   >     exclude group: 'com.google.code.gson'
   > }
   > ```
