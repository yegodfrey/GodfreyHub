# 集成SDK  
  
      1. 在HUAWEI DevEco Studio开发环境中添加当前应用的AppGallery Connect配置文件。
         1. 登录[ _AppGallery Connect 网站_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“我的项目”。
         2. 在项目列表中找到您的项目，在项目列表中点击需要集成SDK的应用。
         3. 在“项目设置”页面中，点击“应用”栏下的“agconnect-services.json”下载配置文件。
         4. 将“agconnect-services.json”文件拷贝到entry模块根目录下。

         * 在获取“agconnect-services.json”文件前，请确保已经完成分析服务的开通（开通步骤请参见[开通华为分析服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-config-agc-0000001204716897#section16141910204411)）。
         * 如果您在“项目设置”模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的“agconnect-services.json”，来替换HarmonyOS应用模块entry的根目录下已有的文件。

      2. 打开HUAWEI DevEco Studio项目级“build.gradle”文件，并添加Maven仓地址和agconnect服务依赖。
             
             buildscript { 
                 repositories { 
                     maven { url 'https://repo.huaweicloud.com/repository/maven/' } 
                     // 确保配置了华为Maven仓地址 
                    ** maven {url 'https://developer.huawei.com/repo/'}** 
                     jcenter() 
                 } 
                 dependencies { 
                     classpath 'com.huawei.ohos:hap:3.1.0.5' 
                     // 添加agconnect服务依赖 
                     **classpath 'com.huawei.agconnect:agcp-harmony:1.5.0.300'**
                 } 
             } 
              
             allprojects { 
                 repositories { 
                     maven { url 'https://repo.huaweicloud.com/repository/maven/' } 
                     // 确保配置了华为Maven仓地址 
                    ** maven {url 'https://developer.huawei.com/repo/'}** 
                     jcenter()  
                 } 
             } 

      3. 打开应用级的“build.gradle”文件，添加插件配置和SDK的版本集成。
         1. 添加AGC插件配置。

在文件头部声明下一行添加如下配置。
                
                apply plugin: 'com.huawei.agconnect'

         2. 在“dependencies”中添加如下编译依赖。
                
                dependencies {
                    implementation 'com.huawei.hms:hianalytics-harmony:_6.10.0.301_ '
                }

Maven仓地址直接在浏览器中打开，无法进行访问，只能在IDE中配置。

      4. 点击“Sync Now”或“File > Sync Project with Gradle Files”开始构建工程。

      5. 选择Terminal页签，进入cmd命令行，在当前根目录entry下执行如下命令以npm方式安装SDK。
             
             npm install @hw-hmscore/analytics-sdk-harmony

#### 初始化AGC SDK

采用默认配置来初始化AGC SDK。详情可参考[初始化AGC SDK](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-get-started-harmonyos-0000001184684961#section1963129135219)。
