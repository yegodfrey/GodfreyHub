# 路线导入

本章节提供通过华为Health Service Kit服务端REST API写入用户路线方法示例。用户的路线是以GPX文件格式导入，可以导入轨迹（Track）或路程（Route）类型的数据。整个流程分为两步：

1. 通过REST API导入路线数据；
2. 判断运动健康App版本，以及通过DeepLink方式将路线自动导入至运动健康App。

三方生态应用路线导入路线后，Health Service Kit服务端会生成并返回路线的唯一ID，生态应用可基于路线ID通过DeepLink方式跳转运动健康App我的路线详情页面，自动导入路线至运动健康App中。  
![](https://media:901788166616454475)  
* 路线导入对应的Scope权限为：https://www.huawei.com/healthkit/location.write
* 通过DeepLink方式完成路线自动导入至运动健康App，暂仅支持Android生态应用。
* 运动健康App版本不低于13.0.1.310。  

#### 路线写入

#### DeepLink跳转运动健康App完成路线自动导入

#### Android

获取华为运动健康App版本号

```
long versionCode;
try {
	PackageInfo packageInfo =
		this.getPackageManager().getPackageInfo("com.huawei.health", PackageManager.GET_META_DATA);
	if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
		versionCode= packageInfo.getLongVersionCode();
	} else {
		versionCode= packageInfo.versionCode;
	}
} catch (PackageManager.NameNotFoundException e) {
	versionCode = 0L;
}
```

DeepLink跳转

当获取华为运动健康App版本号返回的versionCode不低于1300001310 时，可使用DeepLink跳转功能。  

|跳转类型|跳转地目的地|目标类型|跳转地址|跳转参数|是否必填|参数类型|跳转参数说明|
|:-------|:---------------|:-------|:------------------------------------------|:-------|:---|:-----|:-----------------|
|DeepLink|运动健康App-我的路线详情页面|Activity|huaweischeme://healthapp/router/routeDetail|fromFlag|是|String|填写固定值："cloud_flag"|
|DeepLink|运动健康App-我的路线详情页面|Activity|huaweischeme://healthapp/router/routeDetail|routeId|是|long|路线写入成功后返回的路线ID|

示例代码：

```
String deeplink = "huaweischeme://healthapp/router/routeDetail?fromFlag=cloud_flag&routeId=" + routeId;
Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse(deeplink));
intent.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP | Intent.FLAG_ACTIVITY_SINGLE_TOP);
startActivity(intent);
```

#### IOS

iOS版本15.0.12.305及以上。

DeepLink跳转  

|跳转类型|跳转地目的地|目标类型|跳转地址|跳转参数|是否必填|参数类型|跳转参数说明|
|:-------|:---------------|:-------|:-----------------------------------------------------------------------------------|:------|:---|:---|:-------------|
|DeepLink|运动健康App-我的路线详情页面|Activity|huaweischeme://healthapp/router/routeDetail?fromFlag=cloud_flag\&routeId=" + routeId|routeId|是|long|路线写入成功后返回的路线ID|

示例代码：

```
let routeId: String = "1234"
            let deeplink: String = "huaweischeme://healthapp/router/routeDetail?fromFlag=cloud_flag&routeId=\(routeId)"
            guard let openUrl = URL(string: deeplink) else {
                return false
            }
            if UIApplication.shared.canOpenURL(openUrl) {
                UIApplication.shared.open(openUrl, options: [:], completionHandler: nil)
            }
```
