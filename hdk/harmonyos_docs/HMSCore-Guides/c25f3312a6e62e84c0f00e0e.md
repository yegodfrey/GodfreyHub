# 版本更新说明

## 3.8.0.300（2023-10-26）

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:awareness:3.8.0.300 **新增特性** AwarenessKit支持service类型意图框架数据接入SDK发布。 [InsightIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/insightintent-0000001556686061)新增[addIntentInfo(String key, JSONObject intentInfo)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/insightintent-0000001556686061#section56231114394)方法。|

## SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）4.0.2.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
