# 出行旅游

#### 事件参数列表

      * REGISTERACCOUNT

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 用户来源 | String | 可选 | 用户来源。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
  
      * CREATEORDER

用户创建订单时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
CATEGORY | 商品分类 | String | 必选 | 关联的商品分类，如：Flight、Train、Hotel、Car、Travel。  
DESTINATION | 目的地 | String | 可选 | 目的地。  
CARMODE | 用车类型 | String | 可选 | 用车类型，如：打车、机场接送等。  
CARTIME | 用车时间 | String | 可选 | 用户预约的用车时间。  
CARTYPE | 车辆类型 | String | 可选 | 车辆类型，如：舒适型、经济型、商务型、豪华型。  
SUPPLIER | 供应商 | String | 可选 | 供应商。  
  
      * COMPLETEPURCHASE

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
CATEGORY | 商品分类 | String | 必选 | 关联的商品分类，如：Flight、Train、Hotel、Car、Travel。  
PRODUCTID | 商品ID | String | 可选 | 商品ID。  
CITY | 城市 | String | 可选 | 城市。  
FROMCITY | 出发城市 | String | 可选 | 出发城市。  
TOCITY | 目的城市 | String | 可选 | 目的城市。  
CLASS | 预定等级 | String | 可选 | 预定等级。  
DISCOUNT | 折扣 | String | 可选 | 折扣。  
AIRLINE | 航空公司 | String | 可选 | 航空公司，如："MU"、"CZ"。  
TRAINTYPE | 列车类型 | String | 可选 | 列车类型，如：高铁、动车、普通。  
HOTELNAME | 酒店名称 | String | 可选 | 酒店名称。  
HOTELTYPE | 酒店类型 | String | 可选 | 酒店类型，如：豪华型、经济型、舒适型。  
REVENUE | 收入 | Double | 可选 | 订单收入。  
CURRNAME | 货币类型 | String | 可选 | 标识收入的货币类型。  
PRODUCTNAME | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
FIRSTPAY | 是否首次支付 | String | 可选 | 标识用户是否首次购买此商品。
        * 0：表示非首次购买。
        * 1：表示首次购买。
