# Customized View Mode

Customized View支持您自定义扫码界面，扫码过程和相机控制将由Scan Kit完成。您可以参见我们提供的[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/android-sample-code-0000001050734383)快速构建扫码界面UI。  
![](https://media:301775707693466568)  
使用此种模式时请确保您的应用没有关闭硬件加速，即"hardwareAccelerated"为"true"。否则在个别机型可能会出现黑屏问题。  

#### 业务流程

使用Customized View Mode的主要业务流程如下：  
![](https://media:301775707693597569 "点击放大")

1. 用户打开App发起扫码请求。
2. 校验是否有相机权限和文件读取权限。
3. 初始化应用定制的view，构建扫码界面，开始扫码。
4. 如果扫码成功，华为统一扫码SDK回调应用的[onResult](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-onresultcallback4-0000001050165738#section86181033165412)接口传递扫码结果。
5. App封装扫码结果返回给用户。  

#### 开发步骤

* 自定义扫码页面元素。 参见[Customized View自定义页面元素](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/custom-elements-0000001050042032)。

* 通过Customized View实现相机扫码功能。
  1. 创建[RemoteView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteview4-0000001050167711)，并加载到Activity布局。
     1. 绑定相机预览界面，设置扫码识别区域。 在相机预览流中，Scan Kit只截取扫码识别区域的图像，为了获得较好的自动放大效果，建议扫码框放在屏幕中间，且扫码识别区域比绘制的扫码框范围略大。

     2. 设置支持识别的码类型并初始化[RemoteView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteview4-0000001050167711)，设定页面元素的操作。

        您可以指定Scan Kit只扫码特定的码制式，以提高扫码速度。例如，当仅需要检测QR码和DataMatrix码时，通过[setFormat](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteviewbuilder4-0000001050165770#section316985514316)(HmsScan.QRCODE_SCAN_TYPE, HmsScan.DATAMATRIX_SCAN_TYPE)方法实现。当不指定特定的码制式时，不需要调用[setFormat](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteviewbuilder4-0000001050165770#section316985514316)方法，默认检测[Scan Kit支持的码制式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/barcode-formats-supported-0000001050043981)。
     3. 将[RemoteView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteview4-0000001050167711)加载到Activity，示例代码如下：

     ```
     "Java"
     @Override
     protected void onCreate(Bundle savedInstanceState) {
         super.onCreate(savedInstanceState);
         setContentView(R.layout.activity_defined);
         // 绑定相机预览布局
         frameLayout = findViewById(R.id.rim);
         // 设置扫码识别区域，您可以按照需求调整参数
         DisplayMetrics dm = getResources().getDisplayMetrics();
         float density = dm.density;
         mScreenWidth = getResources().getDisplayMetrics().widthPixels;
         mScreenHeight = getResources().getDisplayMetrics().heightPixels;
         // 当前Demo扫码框的宽高是300dp
         final int SCAN_FRAME_SIZE = 300;
         int scanFrameSize = (int) (SCAN_FRAME_SIZE * density);
         Rect rect = new Rect();
         rect.left = mScreenWidth / 2 - scanFrameSize / 2;
         rect.right = mScreenWidth / 2 + scanFrameSize / 2;
         rect.top = mScreenHeight / 2 - scanFrameSize / 2;
         rect.bottom = mScreenHeight / 2 + scanFrameSize / 2;
         // 初始化RemoteView，并通过如下方法设置参数:setContext()（必选）传入context、setBoundingBox()设置扫描区域、setFormat()设置识别码制式，设置完毕调用build()方法完成创建。通过setContinuouslyScan（可选）方法设置非连续扫码
         remoteView = new RemoteView.Builder().setContext(this).setBoundingBox(rect).setContinuouslyScan(false).setFormat(HmsScan.QRCODE_SCAN_TYPE, HmsScan.DATAMATRIX_SCAN_TYPE).build();
         // 将自定义view加载到activity的frameLayout中
         remoteView.onCreate(savedInstanceState);
         FrameLayout.LayoutParams params = new FrameLayout.LayoutParams(LinearLayout.LayoutParams.MATCH_PARENT, LinearLayout.LayoutParams.MATCH_PARENT);
         frameLayout.addView(remoteView, params);
     }
     ```

     ```
     "Kotlin"
     override fun onCreate(savedInstanceState:Bundle?) {
         super.onCreate(savedInstanceState)
         setContentView(R.layout.activity_defined)
         // 绑定相机预览布局
         frameLayout = findViewById(R.id.rim)
         // 设置扫码识别区域，您可以按照需求调整参数
         val dm = getResources().getDisplayMetrics()
         val density = dm.density
         mScreenWidth = getResources().getDisplayMetrics().widthPixels
         mScreenHeight = getResources().getDisplayMetrics().heightPixels
         // 当前Demo扫码框的宽高是300dp
         val SCAN_FRAME_SIZE = 300
         val scanFrameSize = (SCAN_FRAME_SIZE * density).toInt()
         val rect = Rect()
         rect.left = (mScreenWidth / 2 - scanFrameSize / 2).toInt()
         rect.right = (mScreenWidth / 2 + scanFrameSize / 2).toInt()
         rect.top = (mScreenHeight / 2 - scanFrameSize / 2).toInt()
         rect.bottom = (mScreenHeight / 2 + scanFrameSize / 2).toInt()
         // 初始化RemoteView，并通过如下方法设置参数:setContext()（必选）传入context、setBoundingBox()设置扫描区域、setFormat()设置识别码制式，设置完毕调用build()方法完成创建。通过setContinuouslyScan（可选）方法设置非连续扫码
         remoteView =  RemoteView.Builder().setContext(this).setBoundingBox(rect).setContinuouslyScan(false).setFormat(HmsScan.QRCODE_SCAN_TYPE, HmsScan.DATAMATRIX_SCAN_TYPE).build()
         // 将自定义view加载到activity的frameLayout中
         remoteView.onCreate(savedInstanceState)
         val params = FrameLayout.LayoutParams(LinearLayout.LayoutParams.MATCH_PARENT, LinearLayout.LayoutParams.MATCH_PARENT)
         frameLayout.addView(remoteView, params)
     }
     ```

  2. 对[RemoteView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteview4-0000001050167711)设置结果回调监听，获取扫码结果对象[HmsScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-hms-scan4-0000001050167739)，其中包含的信息参见[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-parsing-result-codes-0000001050043969)。

     ```
     @Override
     protected void onCreate(Bundle savedInstanceState) {
         …
         // 识别结果回调事件订阅
         remoteView.setOnResultCallback(new OnResultCallback() {
             @Override
             public void onResult(HmsScan[] result) {
                 // 获取到扫码结果HmsScan
                 ...
             } 
         });
     }
     ```

     ```
     "Kotlin"
     ```

  5. （可选）暂停或恢复扫码。
     1. 您在扫码成功后，如不想结束当前"Activity"并继续进行其他操作，可以调用暂停扫码接口。  

        ```
        "Java"
        remoteView.pauseContinuouslyScan();
        ```

        ```
        "Kotlin"
        remoteView!!.pauseContinuouslyScan();
        ```

     2. 需要从暂停扫码状态恢复扫码，可以调用恢复扫码接口，恢复当前"Activity"接收扫码结果。  

        ```
        "Java"
        remoteView.resumeContinuouslyScan();
        ```

        ```
        "Kotlin"
        remoteView!!.resumeContinuouslyScan();
        ```

        ![](https://media:301775707693623570)  
        暂停扫码会重置相机焦距。例如，若焦距处在放大状态，暂停扫码并恢复扫码后，焦距恢复正常状态。
  6. （可选）设置非连续扫码。  
     通过[setContinuouslyScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteviewbuilder4-0000001050165770#section863432919281)方法设置，默认为true，连续扫码，此时扫码结果会连续返回；设置为false，非连续扫码，此时相同的码值只会返回一次。

     ```
     "Java"
     // setContinuouslyScan设置为false，非连续扫码
     remoteView = new RemoteView.Builder().setContext(this).setContinuouslyScan(false).build();
     ```

     ```
     "Kotlin"
     // setContinuouslyScan设置为false，非连续扫码
     remoteView = RemoteView.Builder().setContext(this).setContinuouslyScan(false).build()
     ```

  7. （可选）设置扫码成功后是否返回原图。  
     通过[enableReturnBitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-remoteviewbuilder4-0000001050165770#section516066173114)方法设置扫码成功后返回原图，默认不返回。可以通过[HmsScan](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-hms-scan4-0000001050167739)对象的[getOriginalBitmap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-hms-scan4-0000001050167739#section4985104135012)获取结果。

     ```
     "Java"
     remoteView = new RemoteView.Builder().setContext(this).enableReturnBitmap().build();
     ```

     ```
     "Kotlin"
     remoteView = RemoteView.Builder().setContext(this).enableReturnBitmap().build()
     ```

     ![](https://media:301775707693862571)  
     如果扫码后需要返回用户提交的原图，请向用户告知。并且您需要满足当地法律法规的要求。
  8. 如果您需要增加从图片文件扫描码的功能，可使用Bitmap Mode实现。
     1. 设定导入图片扫码的按钮。
2. 参见Bitmap Mode[图片扫码场景](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-bitmap-images-0000001050043965)。
