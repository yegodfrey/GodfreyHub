# 开发准备

## 构建开发环境

开发者需要在本地安装如下软件：

* Node.js。参见[Node.js环境构建](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-node-env-0000001943620470)。
* 华为快应用IDE。下载及安装具体操作请参见[下载与安装软件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-installtool-0000001126543467)。

## 集成SDK

华为支付服务支持快应用集成收银台能力，开发者的快应用通过集成华为支付服务 JS SDK后，可以通过SDK支付接口拉起华为支付服务收银台快捷地实现支付能力。

|------------------------------------------------------------------------------------------------------------------------------------------|
|SDK名称：华为支付服务 JS SDK|
|开发者：花瓣支付（深圳）有限公司|
|版本号：6.11.0.300|
|主要功能：华为支付服务 JS SDK的主要功能介绍请参见[业务介绍](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/base-payment-introduction-0000001536000984)|
|个人信息处理规则：[SDK隐私声明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sdk-js-privacy-statement-0000002531465308)|
|合规使用说明：[SDK合规使用指南](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sdk-js-compliance-user-guide-0000002562225279)|

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

1. 如果未启用第三方NPM库，即快应用项目的目录下无"package.json"文件，使用以下方式来创建： 依次点击菜单栏中的"Npm > 启用第三方NPM库"，即可生成"package.json"文件，同时生成fa-toolkit tgz压缩包。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3/v3/a3AYRAHbTmCsyEiDbSCwlg/zh-cn_image_0000002512199993.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=0EF223D2B783A77FF6B41C08A5E1F7B1CF65C2F97F9C808FBFD83F27C8690BF2 "点击放大")
2. 通过运行以下npm命令，安装SDK软件包。

   ```screen
   npm install --save @hw-hmscore/hms-payment
   ```

> 说明
>
> 若在引入SDK后，出现编译报错可尝试在quickapp.config.js中添加如下配置：
>
> module.exports = {
>
> lintOnBuild: false
>
> }
>
> 如果没有quickapp.config.js文件则在项目根目录下创建一个。
