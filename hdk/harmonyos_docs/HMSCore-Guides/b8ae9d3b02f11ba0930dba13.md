# 上报结果

写入读卡结果到applet。

上述章节所有步骤（内部认证、选择子应用、鉴权后读取子应用私有数据）都成功执行则读卡成功，否则失败。读卡成功的结果码"resultCode"为"0020"，失败为"0021"，将结果码存入"A0F1"文件。为了保障结果码的传输安全，采用MAC鉴别方式对传输的数据附加 4 字节的 MAC 码，Applet收到后首先校验，只有正确的数据才予以接受，这样就防止了对传输数据的篡改。

1. 将读卡结果写入A0F1。例如：

   ```screen
   // 选择A0F1
   00A4000002A0F1
   // 写入读卡结果，"04D6000006"+ resultCode + 4字节MAC
   04D600000600207b42dd6e
   ```

   写A0F1伪码如下：

   ```screen
   public void writeReadResult(String resultCode) {
       String adpuData = "04D6000006" + resultCode;
       String appKey = "00000000000000000000000000000000";
       byte[] IVC = new byte[]{0, 0, 0, 0, 0, 0, 0, 0};
       String mac = null;
       try
       {
           byte[] data = hexToByteArray(adpuData);
           byte[] key = hexToByteArray(appKey);
           byte[] allResult = calculatePboc3desMAC(data, key, IVC);
           byte[] leftResult = new byte[4];
           System.arraycopy(allResult, 0, leftResult, 0, 4);
           mac = bytesToHex(leftResult);
       } catch (Exception e) {
           e.printStackTrace(); 
       }

       if (mac == null) {
           return;
       }

       // 选择文件 A0F1，成功则返回"9000"
       String cmd = "00A4000002A0F100";
       excuteCommand(cmd);

       // 写A0F1，成功则返回"9000"
       cmd = adpuData + mac;
       excuteCommand(cmd);
   }
   ```

   "calculatePboc3desMAC"MAC计算方法伪码：

   ```screen
   /**
    * 计算MAC
    *
    * @param data 带计算的数据
    * @param key  16字节密钥
    * @param icv  算法向量
    * @return mac签名
    * @throws Exception
    */
   public byte[] calculatePboc3desMAC(byte[] data, byte[] key, byte[] icv) throws Exception
   {
       if (key == null || data == null)
       {
           throw new RuntimeException("data or key is null.");
       }
       if (key.length != 16)
       {
           throw new RuntimeException("key length is not 16 byte.");
       }

       byte[] leftKey = new byte[8];
       System.arraycopy(key, 0, leftKey, 0, 8);

       // 拆分数据（8字节块/Block）
       final int dataLength = data.length;
       final int blockCount = dataLength / 8 + 1;
       final int lastBlockLength = dataLength % 8;

       byte[][] dataBlock = new byte[blockCount][8];
       for (int i = 0; i < blockCount; i++)
       {
           int copyLength = i == blockCount - 1 ? lastBlockLength : 8;
           System.arraycopy(data, i * 8, dataBlock[i], 0, copyLength);
       }
       dataBlock[blockCount - 1][lastBlockLength] = (byte) 0x80;

       byte[] desXor = xOr(dataBlock[0], icv);
       for (int i = 1; i < blockCount; i++)
       {
           byte[] des = encryptByDesCbc(desXor, leftKey); // DES/CBC/NoPadding
           desXor = DesUtils.xOr(dataBlock[i], des);
       }
       desXor = encryptBy3DesCbc(desXor, key); // DES/CBC/NoPadding
       return desXor;
   }
   ```

   异或方法"xOr"伪码：

   ```screen
   /**
    * 将b1和b2做异或，然后返回
    *
    * @param b1
    * @param b2
    * @return 异或结果
    */
   public byte[] xOr(byte[] b1, byte[] b2)
   {
       byte[] tXor = new byte[Math.min(b1.length, b2.length)];
       for (int i = 0; i < tXor.length; i++)
       {
           // 异或(Xor)
           tXor[i] = (byte) (b1[i] ^ b2[i]);
       }
       return tXor;
   }
   ```

2. 成功则返回"9000"。
