# 订阅数据

Health Service Kit扩展能力服务提供了运动健康App的数据订阅/取消订阅接口[subscribeDataEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__subscribeDataEx-android_content_Context-com_huawei_hihealth_model_Subscriber-com_huawei_hihealth_model_EventTypeInfo-com_huawei_hihealth_listener_ResultCallback-)/[unSubscribeDataEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__unSubscribeDataEx-android_content_Context-com_huawei_hihealth_model_Subscriber-com_huawei_hihealth_model_EventTypeInfo-com_huawei_hihealth_listener_ResultCallback-)，开发者可以直接在第三方应用上调用接口订阅/取消订阅数据。目前支持订阅的数据：日总步数、日总距离、日总卡路里数、日步行时长、日睡眠时长。且运动健康App会保存应用的订阅记录，订阅记录有效期内无需重复订阅。  

#### 数据订阅扩展交互流程

1. 在联盟卡片[申请Health Service Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-kitservice-0000001050707556)时，选择已经创建的产品，勾选注册订阅通知能力。选择端侧订阅方式，填写接收广播用的action名称。
2. 应用接入Health Service Kit扩展能力，订阅事件。
3. 订阅事件满足时，实时通知应用。
4. 应用收到通知消息，调用[查询用户每日活动量](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-querying-dailyactivity-0000001053253403#section1269593195415)/[查询健康类数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-querying-singleworkout-record-0000001053333367#section83824515219)从运动健康App获取具体数据。

#### 参数要求

* 订阅者[Subscriber](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/subscriber-0000001321657037)：需填充审核通过后分配的订阅者id(subscriberId)、秘钥（secret）。
* 订阅事件[EventTypeInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/eventtypeinfo-0000001271177072)：目前仅支持一种订阅事件[GoalInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/goalinfo-0000001270697284)（[EventTypeInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/eventtypeinfo-0000001271177072)的子类），其构造参数需满足：
  * goals：列表大小最大为3。
  * startDay: 注册时需大于等于今天日期，解注册时可以使用注册时的历史日期。
  * recurrence: 只支持天周期 unit=1 , 周期循环次数1\<count\<366。
  * openId: 账号授权时返回的华为openId，不同的华为账号对应不同的openId, openId获取参考[HMSCoreSDK登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-requesting-user-authorization-0000001071733944#ZH-CN_TOPIC_0000002548038787__li1799134713214)。
* 总订阅次数限制5次：超过次数需要先把之前的解订阅才能继续订阅。
* 目标Goal分两种类型：[MetricGoal](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/metricgoal-0000001270857192)和[DurationGoal](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/durationgoal-0000001321337097)，分别对应不同的goalType。

  一次订阅事件中：goalType+dataType要保持唯一，否则校验失败。

  每一次订阅事件中：goalType+dataType+value要保持唯一，否则两次订阅事件认为是同一个，只保留旧事件。

![](https://media:901788166655241214)  
* 传入多个目标时, 同时满足条件才会通知。
* 建议应用在接收订阅事件通知时，对数据进行签名校验。
* 解订阅时，Subscriber和EventTypeInfo要和订阅时传入的内容一致。
* 若注册时数据已经满足条件，数据有更新时才会触发通知。
* 锁屏下也可以注册场景目标事件，且锁屏下仍能收到达标通知，但锁屏通知可能会有一定的时延。

1. 注册广播用于接收消息。
2. 调用[HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459)对象的[subscribeDataEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__subscribeDataEx-android_content_Context-com_huawei_hihealth_model_Subscriber-com_huawei_hihealth_model_EventTypeInfo-com_huawei_hihealth_listener_ResultCallback-)方法，订阅数据。
3. 接收到广播后，对数据进行签名校验，校验通过则解析消息。
4. 不需订阅时，调用[HiHealthDataStore](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459)的[unSubscribeDataEx](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__unSubscribeDataEx-android_content_Context-com_huawei_hihealth_model_Subscriber-com_huawei_hihealth_model_EventTypeInfo-com_huawei_hihealth_listener_ResultCallback-)方法取消订阅，传入的Subscriber和EventTypeInfo要和订阅时传入的内容一致。  

#### 数据订阅场景示例

```
// 步骤1： 注册广播用于接收消息
// init context
MyReceiver receiver = new MyReceiver();
String action = "receiver_action";
IntentFilter intentFilter = new IntentFilter(action);
context.registerReceiver(receiver, intentFilter);

// 步骤2：调用HiHealthDataStore对象的subscribeDataEx方法，订阅数据
ReceiverFilter filter = new ReceiverFilter("package_name", action);
Subscriber subscriber = new Subscriber("appId", "subscriberId", "secret", filter);
int unit = 1; // 代表天维度
int periodCount = 100; // 100 day
Recurrence recurrence = new Recurrence(unit);
recurrence.setCount(periodCount);
MetricGoal stepMetricGoal = new MetricGoal(HiHealthPointType.DATA_POINT_STEP_SUM, "step", 10000);
List<Goal> goals = new ArrayList<>();
goals.add(stepMetricGoal);
int startDay = 20220710;
GoalInfo goalInfo = new GoalInfo(goals, startDay, recurrence, "openId");
HiHealthDataStore.subscribeDataEx(context, subscriber, goalInfo, new ResultCallback() {
    @Override
    public void onResult(int i, Object o) {
        Log.i("TAG", "subscribe result code = " + i + ", message = " + o);
        if (resultCode == HiHealthError.SUCCESS) {
            // 订阅成功
            Log.i(TAG, "Subscription succeeded");
        } else if (resultCode == HiHealthError.PARAM_INVALID) {
            // 订阅参数错误
            Log.w(TAG, "Param invalid");
        } else if (resultCode == HiHealthError.ERR_HEALTH_SERVICE_DISCONNECTED) {
            // 与运动健康连接断开
            Log.w(TAG, "HealthKit service was disconnected");
        } else if (resultCode == HiHealthError.ERR_REPEAT_EXCEPTION) {
            // 重复订阅
            Log.w(TAG, "Repeat error");
        } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
            // HMS Core版本过低
            Log.w(TAG, "HMS version is too early");
        } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
            // 授权失效
            Log.w(TAG, "Permission denied");
        } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
            // 未同意运动健康隐私协议
            Log.w(TAG, "Privacy user denied");
        } else if (resultCode == HiHealthError.ERR_NETWORK) {
            // 网络异常
            Log.w(TAG, "Network request failed");
        } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
            // 测试权限的用户数量超过限制
            Log.w(TAG, "Beta scope permission denied");
        } else {
            // 其他错误，建议提示调用失败
            Log.w(TAG, "Other error, invoking method failed");
        }
    }
});

// 步骤3: 接收到广播后，对数据进行签名校验，校验通过则解析消息
private class MyReceiver extends BroadcastReceiver {
    private static final String TAG = "MyReceiver";
    public void onReceive(Context context, Intent intent) {
        if (!intent.hasExtra(HiHealthKitConstant.EVENT_SIGNATURE)) {
            Log.w(TAG, "wrong message, no need to deal");
            return;
        }
        byte[] signature = intent.getByteArrayExtra(HiHealthKitConstant.EVENT_SIGNATURE);
        // 将自身生成的签名和接收到的签名比对，如果相等，则认为是正确的消息，否则不予处理
        // 签名生成规则：将type,subType,openId依次通过下划线拼接， 然后与secret进行HMAC-SHA256算法加密生成
        if (!intent.hasExtra(HiHealthKitConstant.SAMPLE_EVENT)) {
            Log.w(TAG, "no event is returned");
            return;
        }
        SampleEvent event = intent.getExtras().getParcelable(HiHealthKitConstant.SAMPLE_EVENT);
        MetaData metaData = event.getMetaData().get(0);
        if ("goalStatus".equals(metaData.getMetaKey())) {
            String metaValue = metaData.getMetaValue();
            try {
                JSONObject goalInfo = new JSONArray(metaValue).getJSONObject(0);
                int startDay = goalInfo.getInt("periodStartDay");
                int endDay = goalInfo.getInt("periodEndDay");
                JSONArray goals = new JSONArray(goalInfo.getString("goalAchieve"));
                for (int i = 0; i < goals.length(); i++) {
                    JSONObject goal = goals.getJSONObject(i);
                    if (goal.getInt("goalType") == CharacteristicConstant.GoalType.METRIC_GOAL) {
                        MetricGoal metricGoal = new Gson().fromJson(goal.toString(), MetricGoal.class);
                        Log.i(TAG, "data type " + metricGoal.getDataType() + " value : " + metricGoal.getValue()
                            + " is achieved");
                    } else if (goal.getInt("goalType") == CharacteristicConstant.GoalType.DURATION_GOAL) {
                        DurationGoal durationGoal = new Gson().fromJson(goal.toString(), DurationGoal.class);
                        Log.i(TAG, "data type " + durationGoal.getDataType() + " duration : "
                            + durationGoal.getDuration() + " is achieved");
                    } else {
                        Log.i(TAG, "wrong goal type");
                    }
                }
            } catch (JSONException e) {
                Log.w(TAG, "json exception");
            }
        }
    }
}

// 步骤4：不需订阅时，调用HiHealthDataStore的unSubscribeDataEx方法解订阅
HiHealthDataStore.unSubscribeDataEx(context, subscriber, goalInfo, new ResultCallback() {
    @Override
    public void onResult(int i, Object o) {
        Log.i(TAG, "unsubscribe result code = " + i + ", message = " + o);
        if (state == HiHealthError.SUCCESS) {
            // 解订阅成功
            Log.i(TAG, "Unsubscription succeeded");
        } else if (state == HiHealthError.PARAM_INVALID) {
            // 解订阅参数错误
            Log.w(TAG, "Param invalid");
        } else if (state == HiHealthError.ERR_PRIVACY_USER_DENIED) {
            // 未打开运动健康并同意隐私协议
            Log.w(TAG, "Privacy user denied");
        } else {
            // 其他错误，建议提示调用失败
            Log.w(TAG, "Other error, invoking method failed");
        }
    }
});
```
