# 添加权限

开发者需要在config.json文件中的"reqPermissions"字段中声明访问网络的权限。详情参见[权限开发指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/security-permissions-guidelines-0000000000029886-V3)。

```
{
    "module": {
           "reqPermissions": [
            {
                "name": "ohos.permission.INTERNET",
                "reason": "access internet",
                "usedScene": {
                    "ability": [
                        "com.mycamera.MainAbility"
                    ],
                    "when": "always"
                }
            }
        ]
    }
}
```
