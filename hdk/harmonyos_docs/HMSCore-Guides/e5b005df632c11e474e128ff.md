# 图片扫码场景

## 业务流程

使用Bitmap图片扫码的主要业务流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/YitBxrbYTdmJnvvwNPJg9A/zh-cn_image_0000001577089826.png?HW-CC-KV=V1&HW-CC-Date=20260909T173430Z&HW-CC-Expire=31536000000&HW-CC-Sign=AA7C18AA0E5C631CF47679B94817599C52F77985A96FC7D678C04E3421A127B1 "点击放大")

1. 用户打开App发起扫码请求。
2. 校验是否有相机权限和相册读取权限。
3. 权限验证通过后，调用华为统一扫码SDK的"bitMapForImage:"扫码接口。
4. 返回扫码结果。
5. App封装扫码结果返回给用户。

## 开发步骤

1. 获取图片，格式为UIImage。
2. （可选）根据实际需求创建扫码选项参数。

   ```screen
   // QR_CODE | DATA_MATRIX表示只扫描QR和DataMatrix的码
   HmsScanOptions *options = [[HmsScanOptions alloc] initWithScanFormatType:QR_CODE | DATA_MATRIX];
   此处设置为QR_CODE | DATA_MATRIX，即适配QR和DataMatrix的码
   ```

3. 调用[HmsBitMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsbitmap-0000001050429949)的类方法"bitMapForImage:"或"multiDecodeBitMapForImage:"，方法发起扫码请求并获取扫码结果JSON，其中包含信息请参见[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-parsing-result-codes-0000001050257274)。

   ```screen
   // 获取单码结果
   NSDictionary *dic = [HmsBitMap bitMapForImage:image withOptions:[[HmsScanOptions alloc] initWithScanFormatType:ALL];
   // 获取多码结果
   NSArray *list = [HmsBitMap multiDecodeBitMapForImage:image withOptions:options];
   ```

   返回的值信息参见[Default View Mode](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-default-view-0000001050414343)。
