# 安装Chrome扩展

## 功能介绍

* 该扩展可以去除目标网页中的x-frame-options和Content-Security-Policy等HTTP请求头，防止目标网页被禁止嵌入iframe。
* 在可视化埋点时，支持对埋点的页面或元素进行截图并保存，方便后续查看。
* 支持通过扩展中的开关，控制是否插入dtm.js脚本到未集成DTM的网页中；若打开，则可以实现该网页的可视化埋点及预览调试、跳转页面的跟踪及预览。

## 安装步骤

> 说明
>
> 为了您更好的使用可视化埋点，强烈建议您使用Chrome浏览器。

若您未安装Chrome扩展，或当前Chrome扩展版本较低，请参考如下操作安装HUAWEI DTM可视化埋点扩展。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，下载并解压Chrome扩展包[dtm_chrome_extension.zip](https://developer.huawei.com/consumer/cn/service/josp/agc/WiseCloudDTMPortal/dist/static/dtm_chrome_extension.zip)。
2. 在Chrome浏览器的地址栏中输入chrome://extensions/进入扩展程序页面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/77/v3/7BQ3Kr1LSKO6tL-lOa25zw/zh-cn_image_0000001111925492.png?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=3CC99F4EB9F72FF580A6B05845569CD29CB91B85782B8C08853B97B5AF46F01A "点击放大")

3. 打开右上角的"开发者模式"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/10/v3/JSP07n6OQjKKfiC3AadWYQ/zh-cn_image_0000001158565503.png?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=B8D62A92EC455920343C6AB8180646D2ECA94A0D844D224AD37341D44C5AB235 "点击放大")

4. 点击"加载已解压的扩展程序"，选择扩展程序目录"dtm_chrome_extension"，并点击"选择文件夹"。

   系统显示Huawei DTM可视化埋点扩展，并且在地址栏后方，显示"扩展程序"图标。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d2/v3/-m1EVWABRmavXEYp-gOOsA/zh-cn_image_0000001158578125.png?HW-CC-KV=V1&HW-CC-Date=20260909T141903Z&HW-CC-Expire=31536000000&HW-CC-Sign=652ED3B8C3A8CE61028584F120927890A5C7F3EC068001E519DC82F1C61F232D)

5. Chrome扩展安装完成后，请刷新AGC页面使其生效。
