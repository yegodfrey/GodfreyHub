# 概述

工作区用于统一管理配置资源，解决因配置内容冲突或团队协作时的相互影响问题。

在DTM中，您可以对默认工作区中的可视化埋点、代码、条件和变量等配置资源进行管理，并对这部分更改发布一个版本。若您需要多名团队成员编辑操作不同的代码配置时，或您需要在某正式版本基础上另外进行开发、测试代码配置，则可启动多工作区功能，从而实现版本控制，且互不影响。

自定义工作区作为临时的本地版本，当您在自定义工作区操作期间，若有新版本发布，则需要将最新版本的内容同步至自定义工作区中。自定义工作区提交后该工作区将自动删除。

系统默认不启用多工作区，仅提供一个默认的工作区。若您需要多工作区，可手动开启。

启用多工作区后，您最多可以创建10个自定义工作区。各个工作区之间修改的内容互不影响，当且仅当自定义工作区提交修改内容，其他工作区完成同步后才能看到修改内容。

自定义工作区暂时不支持可视化埋点及可视化埋点资源的相关操作，若您需要可视化埋点，请在默认工作区中进行。
