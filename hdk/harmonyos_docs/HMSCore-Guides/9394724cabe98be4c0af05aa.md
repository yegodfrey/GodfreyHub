# 3D标记图标

## 添加3D标记图标

HAnnotationView支持3D模型图标显示，可通过HAnnotationView的setIcon3DFile方法设置3D车标。

```screen
- (void)viewDidLoad {
    [super viewDidLoad];
    HMapView *mapView = [[HMapView alloc] init];
    mapView.frame = UIScreen.mainScreen.bounds;
    [self.view addSubview:mapView];
    
    HAnnotationOptions *options = [[HAnnotationOptions alloc] init];
    options.title = @"paris";
    options.snippet = @"hello";
    options.draggable = YES;
    options.icon3D = YES;
    
    HAnnotationView *annotationView = [mapView addAnnotationEx:options];
    NSString *file = [NSBundle.mainBundle pathForResource:@"Car.gltf" ofType:nil];
    if(file) {
        [annotationView setIcon3DFile:file scale:50 angleX:0 angleY:0 angleZ:0];
    }
}
```

## 3D标记图标事件

3D标记图标支持点击和拖拽事件。以点击事件为例，要在地图上设置此侦听器，通过HMapViewDelegateAdvance来侦听3D标记图标上的点击事件。

```java
- (void)mapView:(HMapView *)mapView didSelectAnnotationView:(HAnnotationView *)view {
    NSLog(@"Marker is clicked");
}
```
