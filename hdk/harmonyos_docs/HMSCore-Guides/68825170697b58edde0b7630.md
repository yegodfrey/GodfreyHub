# 开发准备

## 构建开发环境

开发者需要在本地安装如下软件：

* Node.js。参见[Node.js环境构建](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-node-env-0000001943620470)。
* 华为快应用IDE。下载及安装具体操作请参见[下载与安装软件](https://developer.huawei.com/consumer/cn/doc/development/quickApp-Guides/quickapp-installtool-0000001126543467)。

## 集成SDK

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

1. 如果未启用第三方NPM库，即快应用项目的目录下无"package.json"文件，使用以下方式来创建： 依次点击菜单栏中的"Npm > 启用第三方NPM库"，即可生成"package.json"文件，同时生成fa-toolkit tgz压缩包。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b2/v3/XHCgzFB8RUy-IpPiWleKWA/zh-cn_image_0000002512199961.png?HW-CC-KV=V1&HW-CC-Date=20260910T132631Z&HW-CC-Expire=31536000000&HW-CC-Sign=49A4D2E00709B60D6C27342594576391F50980CC6332D4A39F0316876E169EBC "点击放大")
2. 通过运行以下npm命令，安装SDK软件包。

   ```screen
   npm install --save @hw-hmscore/hms-payment
   ```

> 说明
>
> 若在引入SDK后，出现编译报错可尝试在quickapp.config.js中添加如下配置：
>
> module.exports = {
>
> lintOnBuild: false
>
> }
>
> 如果没有quickapp.config.js文件则在项目根目录下创建一个。
