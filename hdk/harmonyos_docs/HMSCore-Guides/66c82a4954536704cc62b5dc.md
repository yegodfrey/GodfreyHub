# 使用入门

#### 开发环境的要求

* JDK 1.8.211及以上
* 安装Android Studio 3.6.1及以上
  * minSdkVersion 26及以上（必须）
  * targetSdkVersion 28
  * compileSdkVersion 30（推荐）
  * Gradle 7.0及以上（推荐）
* 测试应用的设备：HarmonyOS3.0及以上的华为手机  

#### 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。  

|序号|开发步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001569051449)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息，注册成为开发者。|
|2|[配置FusionSearchService SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/integrated-sdk-0000001576320925)|通过Maven仓或者直接网页下载FusionSearch SDK，添加FusionSearch的权限。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/add-permissions-0000001568931077)|编译APK前需要配置混淆配置文件，避免混淆SDK导致功能异常。|
