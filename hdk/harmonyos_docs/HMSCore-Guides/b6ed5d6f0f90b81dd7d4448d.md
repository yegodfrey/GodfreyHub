# 业务简介

地图服务提供JavaScript语言开发的应用编程接口，帮助您轻松完成适用于浏览器的地图应用开发。JavaScript API支持基础地图展示，地图交互，路径规划，位置搜索，地理编码等，满足您的大多数需求。

服务使用前，需要您先[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section175508543353)。JavaScript API提供支持PC端和移动端的地图应用开发，支持的浏览器请参见[开发环境](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-getting-started-0000001080092813#section981116332430)。

## 场景介绍

通过JavaScript API可帮助您在网站中构建功能丰富、交互性强的地图应用，包括：

* 基础地图展示：创建一个简单的网页地图。
* 地图交互：支持地图的平移、缩放、拖拽等操作。
* 地图绘制：可根据自身的个性化需求在地图上添加图标，自定义地图样式。
* 路径规划：提供步行、骑行、驾车三种交通方式的路径规划能力。
* 位置搜索：提供位置搜索能力，包含自动补齐搜索文字、搜索地点、查询地点详细信息。

## 功能使用限制

|功能|地域要求|说明|
|:-------|:---|:------------------------|
|不涉及数据的功能|无|不涉及数据的功能，例如添加标记，多边形等都可以使用|
