# 创建地图

本章节将向您介绍通过华为地图API for JavaScript创建一个简单的网页地图。

JavaScript提供2种认证方式初始化地图，推荐使用AT认证：

* [AT认证](#section1163413713365)，AT生成方式参见[基于OAuth 2.0获取应用级AT](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/open-platform-oauth-0000001053629189#section155891726174616)。
* [API KEY认证](#section157487211386)，*API KEY* 的获取请参见[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section175508543353)。

## AT认证

> 说明
>
> * AT有效期是1个小时，请及时更新。
> * 如果同时设置了[API KEY](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-map-instance-creation-0000001062881706#section147441922143612)和AT，优先使用AT认证。
> * 使用AT认证时推荐新申请AT接入MapKit。
> * 如果请求携带traceId，可用于问题跟踪定位。

1. 创建一个HTML文件，并在文件头声明以下内容，以支持大多数浏览器。

   ```screen
   <!DOCTYPE html>
   ```

2. 在head标签对里添加style标签对，来设置容器样式大小。

   ```screen
   <head>
       <meta charset="UTF-8">
       <style>
           #map {
               height: 800px;
               width: 100%;
               margin: 0 auto;
           }
       </style>
   </head>
   ```

3. 引入华为地图API文件。

   ```screen
   <script src="https://mapapi.cloud.huawei.com/mapjs/v1/mapkit.js"></script>
   ```

   如果需要设置路由地，可通过accessRegion参数设置。

   ```screen
   <script src="https://mapapi.cloud.huawei.com/mapjs/v1/mapkit.js?accessRegion=CN"></script>
   ```

4. 在body内部创建地图容器元素。

   ```screen
   <body>
   <div id="map"></div>
   </body>
   ```

5. 创建初始化地图脚本，以巴黎为中心的地图。调用HWMapJsSDK.[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)(div, mapOptions)，传入地图初始化参数[MapOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165#section12313153115171)设置地图初始状态，设置AT。

   ```javascript
   <script>
       function initMap() {
           var mapOptions = {};
           // 设置地图中心点坐标
           mapOptions.center = {lat: 48.856613, lng: 2.352222};
           // 设置地图初始化缩放级别
           mapOptions.zoom = 8;
           // 设置地图语言
           mapOptions.language='ENG';
           // 设置地图加载时使用的瓦片类型，支持vector（矢量）或raster（栅格）
           mapOptions.sourceType = 'raster';
           // 设置AT
           mapOptions.authOptions = {accessToken: token}
           // 创建地图对象
           var map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions);
       }
   </script>
   ```

## API KEY认证

> 说明
>
> 如果请求携带traceId，可用于问题跟踪定位。

1. 创建一个HTML文件，并在文件头声明以下内容，以支持大多数浏览器。


   ```screen

       <style>
           #map {
               height: 800px;
               width: 100%;
               margin: 0 auto;
           }
       </style>
   </head>
   ```

3. 引入华为地图API文件，其中key要经过URL转码。*API KEY* 的获取请参见[获取API密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/javascript-api-preparations-0000001078448006#section175508543353)。

   ```screen
   <script src="https://mapapi.cloud.huawei.com/mapjs/v1/api/js?callback=initMap&key=API KEY"></script>
   ```

4. 在body内部创建地图容器元素。

   ```screen

   ```
