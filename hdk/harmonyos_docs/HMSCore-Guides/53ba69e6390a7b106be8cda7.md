# 征求用户意见

鲸鸿动能平台投放的广告包括个性化广告和非个性化广告。

若您的业务在以下范围内，且出于实现个性化广告的目的需要收集、使用和共享用户的个人数据，须先获得用户的有效同意。您必须清楚地识别因您使用鲸鸿动能而可能收集、接收或使用您用户个人数据的各方，并提供有关各方使用用户个人数据的重要信息。

* Aspiegel SE服务的所有业务区域。业务区域对应国家清单，详见《[华为开发者服务协议](https://developer.huawei.com/consumer/cn/doc/20201)》第14条"分发区域和签约主体"。请阅读相关的《[关于鲸鸿动能与隐私的声明](https://legal.cloud.huawei.com/terms/scope/huawei/ads/privacy-statement.htm?&code=EU&language=zh-CN&branchid=0&contenttag=default)》。
* 华为服务（香港）有限公司服务的部分区域：阿拉伯联合酋长国，中国台湾，南非，阿根廷，巴西。 请阅读相关的《[关于鲸鸿动能与隐私的声明](https://legal.cloud.huawei.com/terms/scope/huawei/ads/privacy-statement.htm?&code=HK&language=zh-CN&branchid=0&contenttag=default)》。

默认情况下，向鲸鸿动能平台发出的广告请求会投放个性化广告，并根据以前收集的用户数据筛选广告。鲸鸿动能平台也支持通过配置广告请求来投放非个性化广告。详情请参见《[鲸鸿动能隐私与数据安全相关政策](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/policy4-0000001146675575)》"个性化广告和非个性化广告"。

请注意，我们服务的个性化和非个性化广告都需要移动标识符才能实现。根据法律规定，您必须获取用户同意后方可使用移动标识符。

为了征求用户意见，您可以使用鲸鸿动能平台提供的Consent SDK，也可以使用符合IAB TCF v2.0规范的CMP，详情请参见[IAB TCF v2.0用户同意信息传递](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-iab-tcf-0000001075694328)。

本章节介绍了如何使用Consent SDK征求用户意见，以及在征得用户意见后如何根据用户意见获取广告。

2. 更新用户意见状态。

   使用Consent SDK时，应确保Consent SDK获得的是鲸鸿动能平台广告技术提供商的最新信息。如果在征求用户意见后，广告技术提供商的列表发生改变，则Consent SDK会自动将用户意见置为未知状态。因此在每次启动应用时都必须通过调用[requestConsentUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consent-0000001057445071#section18155153513433)()方法确定用户意见状态。示例代码如下所示：

   ```java
   "Java"
   ...
   import com.huawei.hms.ads.consent.*;
   ...
   public class ConsentActivity extends BaseActivity {
       ...
       @Override
       protected void onCreate(Bundle savedInstanceState) {
           ...
           // 检查用户意见状态
           checkConsentStatus();
           ...
       }
       ...
       private void checkConsentStatus() {
           ...
           Consent consentInfo = Consent.getInstance(this);
           ...
           consentInfo.requestConsentUpdate(new ConsentUpdateListener() {
               @Override
               public void onSuccess(ConsentStatus consentStatus, boolean isNeedConsent, List<AdProvider> adProviders) {
                   // 获取用户意见状态成功
                   ...
               }
               @Override
               public void onFail(String errorDescription) {
                   // 获取用户意见状态失败
                   ...
               }
           });
          ...
       }
       ...
   }
   ```

   如果成功更新用户意见信息，那么会通过[ConsentUpdateListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentupdatelistener-0000001057245006)的onSuccess()方法提供更新后的用户意见状态参数"ConsentStatus"、"isNeedConsent"参数（是否需要consent）和广告技术提供商的adProviders列表。

   [ConsentStatus](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentstatus-0000001057594717)具有以下三种状态：

   |用户意见状态|定义|
   |:-----------------------------|:--------------------------|
   |ConsentStatus.PERSONALIZED|用户已同意接收个性化广告与非个性化广告。|
   |ConsentStatus.NON_PERSONALIZED|用户已同意接收非个性化广告。|
   |ConsentStatus.UNKNOWN|用户既未同意接收也未拒绝接收个性化广告或非个性化广告。|

   * 如果回调参数"isNeedConsent"取值为"false"，则表明可以向鲸鸿动能SDK请求个性化广告。
   * 如果回调参数"isNeedConsent"取值为"true"，则表明该用户在欧洲经济区内或其他敏感地区内，需要进一步确认用户意见。
     * 当返回的[ConsentStatus](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentstatus-0000001057594717)为"PERSONALIZED"或"NON_PERSONALIZED"，则表明已征求过用户意见，不需要再次征求。
     * 当返回的[ConsentStatus](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentstatus-0000001057594717)为"UNKNOWN"，则需要通过弹框等方式征求用户意见。
   * 如果[ConsentUpdateListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentupdatelistener-0000001057245006)返回onFail()时，则直接请求非个性化广告。

   [AdProvider](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/approvider-0000001058045021)为广告技术提供商信息，参数定义如下：

   |字段|定义|
   |:---------------|:-----------------|
   |id|广告技术提供商的ID。|
   |name|广告技术提供商的名称。|
   |serviceArea|广告技术提供商的服务地。|
   |privacyPolicyUrl|广告技术提供商的隐私政策链接URL。|

   > 说明
   >
   > [requestConsentUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consent-0000001057445071#section18155153513433)()方法每次会请求网络以更新广告技术提供商列表，为了保障用户体验，媒体可以自行实现超时控制。

      如果您需要针对未达到法定承诺年龄的用户请求对应的广告，则在调用[requestConsentUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consent-0000001057445071#section18155153513433)()前必须通过调用[setUnderAgeOfPromise](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consent-0000001057445071#section1184744818297)设置"未达到法定承诺年龄用户"的标记。示例代码如下所示：

      ```java
      "Java"
      // 设置"未达到法定承诺年龄用户"的标记
      Consent.getInstance(getApplicationContext()).setUnderAgeOfPromise(true);
      ```

      ```java
      "Kotlin"
      // 设置"未达到法定承诺年龄用户"的标记
      Consent.getInstance(getApplicationContext()).setUnderAgeOfPromise(true)
      ```

      一旦将此设置为"true"，则每次[requestConsentUpdate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consent-0000001057445071#section18155153513433)()请求均会回调[onFail](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consentupdatelistener-0000001057245006#section92217503212)(String errorDescription)方法，并提供给用户错误描述参数errorDescription，此时不需要再展示征求用户意见弹框。设置为"false"表明用户已达到法定承诺年龄。
      > 说明
      >
      > 当Consent SDK设置了此标记后，在请求广告时，[基于受众人群请求广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-audience-settings-0000001076462332)中[setTagForUnderAgeOfPromise](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section9201111519261)的参数应与Consent参数保持一致。

4. 根据用户意见获取广告。

   请求广告时，默认不设置[setNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section175111735202616)方法，请求个性化广告与非个性化广告。如果用户在Consent阶段没有做出选择，则只能请求非个性化广告。

   [setNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section175111735202616)方法的值可以设置为：
   * [ALLOW_ALL](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nonpersonalizedad-0000001050064874#section5558312151218)：个性化广告与非个性化广告
   * [ALLOW_NON_PERSONALIZED](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nonpersonalizedad-0000001050064874#section20375228161215)：非个性化广告

   示例代码如下所示：

   ```java
   "Java"
   // setNonPersonalizedAd设置为ALLOW_NON_PERSONALIZED时，只请求非个性化广告
   RequestOptions requestOptions = HwAds.getRequestOptions();
   requestOptions = requestOptions.toBuilder().setNonPersonalizedAd(ALLOW_NON_PERSONALIZED).build();
   HwAds.setRequestOptions(requestOptions);
   AdParam adParam = new AdParam.Builder().build();
   adView.loadAd(adParam);
   ```

   ```java
   "Kotlin"
   // setNonPersonalizedAd设置为ALLOW_NON_PERSONALIZED时，只请求非个性化广告
   var requestOptions: RequestOptions? = HwAds.getRequestOptions()
   ```

## Consent SDK测试

为了让您能轻松地测试应用，Consent SDK提供了可设置的调试选项。

1. 调用[getTestDeviceId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consent-0000001057445071#section18429154121819)()获取设备ID。

   示例代码如下所示：

   ```screen
   "Java"
   String testDeviceId = Consent.getInstance(getApplicationContext()).getTestDeviceId();
   ```

   ```screen
   "Kotlin"
   val testDeviceId = Consent.getInstance(getApplicationContext()).testDeviceId
   ```

2. 使用获取的设备ID将您的设备作为调试设备列入允许清单。

   示例代码如下所示：

   ```screen
   "Java"
   Consent.getInstance(getApplicationContext()).addTestDeviceId(testDeviceId);
   ```

   ```screen
   "Kotlin"
   Consent.getInstance(getApplicationContext()).addTestDeviceId(testDeviceId)
   ```

3. 调用[setDebugNeedConsent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/consent-0000001057445071#section487614772518)设置是否需要Consent。

   示例代码如下所示：

   ```java
   "Java"
   // 设置调试需要Consent，此时ConsentUpdateListener方法返回的isNeedConsent参数为true
   Consent.getInstance(getApplicationContext()).setDebugNeedConsent(DebugNeedConsent.DEBUG_NEED_CONSENT);
   // 设置调试不需要Consent，此时ConsentUpdateListener方法返回的isNeedConsent参数为false
   Consent.getInstance(getApplicationContext()).setDebugNeedConsent(DebugNeedConsent.DEBUG_NOT_NEED_CONSENT);
   ```

   ```java
   "Kotlin"
   // 设置调试需要Consent，此时ConsentUpdateListener方法返回的isNeedConsent参数为true
   Consent.getInstance(getApplicationContext()).setDebugNeedConsent(DebugNeedConsent.DEBUG_NEED_CONSENT)
   // 设置调试不需要Consent，此时ConsentUpdateListener方法返回的isNeedConsent参数为false
   Consent.getInstance(getApplicationContext()).setDebugNeedConsent(DebugNeedConsent.DEBUG_NOT_NEED_CONSENT)
   ```

完成这些步骤后，调用更新用户意见状态时会根据您的调试状态返回isNeedConsent的值。
> 说明
>
> 如果把设备设置为测试设备，那么会返回固定的测试广告技术提供商列表，无法验证真实广告技术提供商列表变化的场景。

如果您需要了解更多Consent SDK相关信息，请查看此[示例代码](https://github.com/HMS-Core/hms-ads-demo-java/blob/master/app/src/main/java/com/huawei/hms/ads/sdk/ConsentActivity.java)
