# 业务简介

定位服务（iOS Location SDK ）提供单次定位、连续定位、后台定位、朝向获取等功能，赋予应用开发者快速、精准地获取用户位置信息的能力，构建全球定位服务能力，助力开发者发展全球业务。  

#### 支持的设备

|设备类型|支持版本|
|:-----|:---------|
|iPhone|iOS 9.0及以上|
