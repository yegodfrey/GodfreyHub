# 语言培训

分析服务支持语言培训行业分析，可以清晰洞察应用的关键指标数值，从数据概览、付费转换、学习统计和活动运营等多维度了解用户的学习、付费情况，帮助制定精准的营销方案和产品策略。  

#### 典型应用场景

* 查看新增付费会员数、ARPU、课程销售额、付费会员收入，以及课程销量top5、课程浏览次数了解用户使用情况。
* 查看分享用户数、收藏用户数、优惠券来源，优惠券使用次数、咨询情况制定营销策略。  

#### 前提条件

已在"智能数据接入 \> 埋点开发"中配置了语言培训行业模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。  

#### 功能详述

#### 案例

某语言学习App想要查看近期用户付费情况以及了解其中最受欢迎的课程，制定相应的促销计划。

需求：查看用户付费金额以及课程排名情况。  

#### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。

<!-- -->

3. 选择"华为分析 \> 行业分析"，进入"语言培训"分析界面。
4. 查看语言培训类App数据概览。详情请参见[数据概览](#section18909151019277)。
5. 查看语言培训类App核心营收指标。详情请参见[付费转换](#section791211032714)、[学习统计](#section7914161019276)和[活动运营](#section5921171012279)。
