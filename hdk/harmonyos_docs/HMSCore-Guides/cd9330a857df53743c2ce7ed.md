# Elevation API

Elevation API可以通过指定经纬度或者path+采样点，查询经纬度对应的海拔信息。

具体使用方式请参见[Elevation API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/elevation-api-0000001158669981)。

Elevation API不支持中国大陆。
