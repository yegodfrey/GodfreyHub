# 多日步数统计

本章节提供通过华为Health Service Kit客户端API获取用户多日步数统计数据的方法示例。开发者可以通过调用[readDailySummation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section295981925017)查询[DT_CONTINUOUS_STEPS_DELTA](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datatype-0000001050089916#section185941927562)步数增量数据类型，获取用户多日的步数统计数据。

示例代码如下：

```screen
// 1. 初始化开始和结束时间，成形数据的前四位代表年份，中间两位代表月份，最后两位代表月份天
// 请注意此处设置的开始时间和结束时间均需大于20140101代表的2014年1月1号日期时间
int startTime = 20200818;
int endTime = 20200827;
 
// 2. 使用指定的数据类型（DT_CONTINUOUS_STEPS_DELTA）、开始时间和结束时间调用readDailySummation接口查询该数据类型的多日统计数据
Task<SampleSet> daliySummationTask =
    dataController.readDailySummation(DataType.DT_CONTINUOUS_STEPS_DELTA, startTime, endTime);

daliySummationTask.addOnSuccessListener(new OnSuccessListener<SampleSet>() {
    @Override
    public void onSuccess(SampleSet sampleSet) {
        logger("Successfully read daily summation from HMS core");
        if (sampleSet != null) {
            showSampleSet(sampleSet);
        }
    }
});
daliySummationTask.addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        logger("readTodaySummation" + e.toString());
    }
});
```

> 说明
>
> 若直接拷贝使用上述示例代码，会有三处报错，错误点和解决办法请参见API文档中[readDailySummation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section295981925017)。
