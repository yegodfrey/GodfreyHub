# 帐号校验功能

从Push SDK 5.0.4版本开始，推送服务提供了帐号校验功能，该功能支持您根据终端设备上不同帐户属性来推送消息。举例来说：某华为手机上，有用户A和用户B，用户A和B名下都有华为钱包应用，华为钱包给用户A推送消息时，只有用户A登录时才展示，其他用户登录消息不展示，这就使用了帐号校验功能。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105221.54868138975087709362986119216934:50001231000000:2800:1EC7D0232B5AF958228BBD821803506C1AC18CFFFDCAAE2681CF144C01562530.png)  
帐号校验功能暂只支持[通知栏消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-basic-sendtestmsg-0000001087842114#section97511196319)；如果您想使用透传消息实现本功能，需要您自行将帐号信息下发至客户端应用，与当前终端设备已登录帐号进行校验。  

#### 客户端应用开发指导

1. 您调用[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)方法，获取Push Token。
2. 调用[isSupportProfile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsprofile-0000001057586645#section78129196156)方法判断当前设备是否支持帐号校验能力。
3. 若当前设备支持帐号校验能力且需要对发送消息的应用做帐号校验，开发者需要给帐号生成一个唯一的profileId，该属性作为帐号的唯一标识。
4. 调用[addProfile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsprofile-0000001057586645#section8475185931912)方法，添加当前设备上该用户与应用的关系，您需要传入type和上一步中生成的profileId。type值为[HUAWEI_PROFILE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsprofile-0000001057586645#section14671716193815)表示关联华为帐号，type值为[CUSTOM_PROFILE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsprofile-0000001057586645#section7406202415401)表示关联其他帐号（非华为帐号）。

   <br />

   ```
   "Java"
   // 添加当前设备上该用户与应用的关系
   HmsProfile.getInstance(this).addProfile(type,profileId).addOnCompleteListener(new OnCompleteListener<Void>() {
       @Override
       public void onComplete(Task<Void> task) {
           // 获取结果
           if (task.isSuccessful()){
               Log.i(TAG, "add profile success.");
           } else{
               Log.e(TAG, "add profile failed: " + task.getException().getMessage());
           }
       }
   });
   ```

   ```
   "Kotlin"
   // 添加当前设备上该用户与应用的关系
   HmsProfile.getInstance(this).addProfile(type,profileId)
   .addOnCompleteListener { task ->
       // 获取结果
       if (task.isSuccessful()){
           Log.i(TAG, "add profile success.")
       } else{
           Log.e(TAG, "add profile failed: " + task.exception.message)
       }
   }
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105221.78405747863895676768576508574060:50001231000000:2800:89D615A76C3E2F9316260F46257FCCF18F3C92FD1C452426C941ADB7D6208331.png)  
   * 关联华为帐号：在华为设备上，当前登录的华为帐号与您的应用形成绑定关系，一旦该华为帐号退出或者切换其他帐号，不会展示发给该帐号的消息。
   * 关联其他帐号（非华为帐号）：当用户切换帐号或退出帐号时，您需要主动调用[deleteProfile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsprofile-0000001057586645#section655417438283)方法删除profileId。

   <br />

5. [addProfile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsprofile-0000001057586645#section8475185931912)方法成功后，您需要将获取到的Token和生成的profileId上报到自己的服务器。  

#### 应用服务端开发指导

1. 您可以通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)或者[基于服务账号生成鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)方式获取鉴权信息。
2. 您的服务端调用下行消息API为目标应用推送消息，更多消息体内容请参见[下行消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#section8686112674319)，相关错误码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#section13968115715131)。

   <br />

   HTTPS POST URL：

   ```
   POST https://push-api.cloud.huawei.com/v1/[clientid]/messages:send
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105222.18645970130449695683492879223936:50001231000000:2800:C0C32DF77E7B76FA39EB2DD5E32CCB5207B3D602C97F3D4BD4220B49533BD995.png)  
   "\[clientid\]"请替换为目标应用的Client ID（在[项目设置页面](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137#section125831926193110)获取）。

   请求消息头示例：

   ```
   Content-Type: application/json; charset=UTF-8
   Authorization: Bearer CF3Xl2XV6jMK*********************rDgAPuzvNm3WccUIaDg== 
   ```

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250830105222.46516413495520625984854872132045:50001231000000:2800:FE416B768136C5A581EFEA3C9C9BD49A80FF741CF1B02DC5BB9325FC69C40773.png)  
   * 请求消息头中的Authorization参数为通过[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)获取的 Access Token 或者[基于服务账号生成的鉴权令牌（JSON Web Token）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/push_jwt_token-0000002342515678)。
   * Access Token如果是通过curl命令或者Postman等工具手工获取，需注意JSON字符串中的转义符，请把"\\/"还原为"/"，替换后才是正确的Access Token。如果是从代码运行获取，则采用任意的第三方库均能正确解析JSON串，获取到正确的Access Token。

   通知栏消息体中需要在[AndroidNotification](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p516983952612)结构体添加profile_id字段。

   ```
   {
       "validate_only": false,
       "message": {
           "notification": {
               "title": "title",
               "body": "body"
           },
           "android": {
               "notification": {
                   "title": "android title",
                   "body": "android body",
                   "profile_id": "yourProfileId",
                   "click_action": {
                       "type": 3
                   }
               }
           },
           "token": ["pushtoken1"]
       }
   }
   ```

   <br />

3. 推送服务端将消息下发到终端设备上。推送服务会校验消息中携带的profile_id和本地保存的profileId，若一致则展示消息，不一致则丢弃本条消息。
