# 评论回复

#### 场景介绍

华为云空间服务支持用户对云端文件的评论进行回复，并对回复进行查看、更新和删除操作。  

#### 创建评论回复

功能简介

Replies.create接口实现创建对某个评论的回复。

限制

* 必填参数：fileId，commentId，fields。
* form字段暂仅支持"json"，不传默认json。
* 只有writer/commenter/owner角色可以创建回复。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive

<!-- -->

* 不能对目录创建回复。
* 一个评论下面最多只能创建20个回复。
* 请求体是可选的，其中的operate字段包括reopen/resolve两种选择。

发送一个创建评论回复的请求

1. 创建一个对Replies.create接口的[POST](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-repliescreate-0000001050151722)请求。
2. 添加查询参数fileId、commentId和fields。

   <br />

   例如：

   ```
   POST https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/comments/{commentId}/replies?fields=*
   ```

   <br />

3. 填入HTTP headers。

   <br />

   * Accept：接收回复的报文格式
   * Content-Type：发送报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```
   POST https://driveapis.cloud.huawei.com.cn/drive/v1/files/AAAB9Wn0DTQCIqPbW9avGjAQo9dbxg04A/comments/BkytC_85-y5hoiLxCRnNCHZcDynNC_siY/replies?fields=* HTTP/1.1

#### 获取评论回复

功能简介

Replies.get接口实现获取某个回复的内容信息。

限制

* 必填参数：fileId，commentId，replyId，fields。
* reader/writer/commenter/owner角色可以获取回复。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly

<!-- -->

* form字段暂仅支持"json"，不传默认json。

#### 获取评论回复列表

功能简介

Replies.list接口实现列出所有对某个评论的回复，用户可以根据pageSize的设定获取需要的页面大小等。

限制

* 必填参数：fileId, commentId, fields。
* pageSize范围1-100，不传默认100。
* form字段暂仅支持"json"，不传默认json。
* 只有reader/writer/commenter/owner可以查看。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly

说明

includeDeleted参数功能暂时不支持使用。

#### 删除评论回复

功能简介

Replies.delete接口实现删除某条回复。

限制

* 必填参数：fileId，commentId，replyId。
* 只有writer/commenter/owner角色可以删除回复。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive

<!-- -->

* 只有回复的创建者或者文件的创建者才能删除回复。

发送一个删除评论回复的请求

1. 创建一个对Replies.delete接口的[DELETE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-repliesdelete-0000001050151724)请求。
2. 添加查询参数fileId、commentId、replyId。

   <br />

   例如：

   ```
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/comments/{commentId}/replies/{replyId}
   ```

   <br />

3. 填入HTTP headers。

   <br />

   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/AAAB9Wn0DTQCIqPbW9avGjAQo9dbxg04A/comments/BkytC_85-y5hoiLxCRnNCHZcDynNC_siY/replies/BpMy9fyvWDfDM2rRKzfpNbqDkNfOnVg7w HTTP/1.1 
   Authorization: Bearer CV3PnPLZXyr9K2GV7RYZkF962JZvoEkMQhTho3QHQAPQUyma/lEyZskP/IMWrc7FvaeHivO7y0lyibI/fQvulBnTgtXArSVPsjaLKvYNkDsJSaIR2/sx+K40bYDWWpKFvJNKg2U47jRwz2mfiF3ortNk 
   Cache-Control: no-cache

   响应：

   ```
   HTTP/1.1 204 OK
   ```

#### 修改评论回复

功能简介

Replies.update接口实现对回复内容进行更新。

限制

* 必填参数：fileId，commentId，replyId，fields。
* 请求体必填，请求体中description字段必填。
* 只有writer/commenter/owner角色可以更新回复。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive

<!-- -->

* 不能对目录更新回复。
* 只有回复的创建者才能更新回复。
* form字段暂仅支持"json"，不传默认json。
