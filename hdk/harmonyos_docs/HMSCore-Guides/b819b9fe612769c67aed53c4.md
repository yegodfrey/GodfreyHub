# 测试和上线

1. 开发者收集好测试人员华为账号对应的手机号。
2. 联系[华为运营人员](https://developer.huawei.com/consumer/cn/support/feedback/#/)添加白名单手机号进行测试。
3. 联系华为运营人员并提供测试结果录屏，录屏内容包括商家券领取、展示以及核销完整流程。
4. 华为运营人员审核测试录屏，无问题后配置全网上线。
5. 如果有任何问题可联系运营协助定位或[查看FAQ](https://developer.huawei.com/consumer/cn/doc/service/intents-kit73-0000002504448462)。
