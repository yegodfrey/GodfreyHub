# 气泡

您可以通过气泡在道路上指定位置显示测速、拥堵情况。气泡支持功能：

* 支持设置四个方向的图标（传入的图标宽高需要相同）。
* 支持设置图标碰撞规则。
* 支持设置当前气泡的候选坐标段，通过计算使气泡在最佳的线段位置上。
* 支持设置图标动画。
* 支持添加点击事件。

## 添加气泡

创建HBubbleOptions气泡的配置对象类，调用HMapView(Bubble)的addBubble:接口添加气泡。

```java
HBubbleOptions *bubbleOption = [[HBubbleOptions alloc] init];
NSString *path = [NSBundle.mainBundle pathForResource:@"HMapKitAdvance.bundle" ofType:nil];
path = [path stringByAppendingString:@"/hwmap_marker_default.png"];
UIImage *icon = [UIImage imageWithContentsOfFile:path];
bubbleOption.position = [[HLatLng alloc] initLatitude:48.61245 withLongitude:116.24515];
bubbleOption.iconArray = [NSArray arrayWithObjects:icon, icon, icon, icon, nil];
[self.mapView addBubble:bubbleOption];
```

## 气泡事件

可通过HMapViewDelegateAdvance代理类的mapView:didSelectBubble:代理方法来侦听气泡上的点击事件。

```screen
- (void)mapView:(HMapView *)mapView didSelectBubble:(HBubble *)bubble {
    NSString *showText = [NSString stringWithFormat:@"%@---priority=%.2f", [NSString stringWithFormat:@"hmsmapkit %s",__FUNCTION__], bubble.bubbleOptions.getPriority];
    [[AlertManager sharedManager] showAlertMessageWithMessage:showText];
}
```

## 气泡动画

气泡支持设置的图标动画效果包括：透明度动画（HAlphaAnimation）、缩放动画（HScaleAnimation），创建HAnimation动画对象，将其添加到气泡动画接口setIconAnimation:中，再调用startIconAnimation开启动画。

```java
HScaleAnimation *animation = [[HScaleAnimation alloc] init];
animation.fromValue = CGPointMake(0.5, 0.5);
animation.toValue = CGPointMake(1.5, 1.5);
animation.delegate = self.owner;
animation.fillMode = 0;
animation.repeatMode = 1;
animation.repeatCount = 1;
animation.duration = 1500;
animation.timingFunction = [HTimingFunction timingFunctionWithName:@"linear"];
[self.poiEx setIconAnimation:animation];
[self.poiEx startIconAnimation];
```
