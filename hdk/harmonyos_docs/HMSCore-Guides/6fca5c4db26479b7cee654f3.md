# 集成方式

## 示例代码

在js中调用如下代码：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230912163213.20164139951100088581780065819361:50001231000000:2800:6C3A4DEFF8F03103CB745CFA67CF1C0D573DD1E86C20C0027458783E19DBBEC2.png?needInitFileName=true?needInitFileName=true)

默认情况下，使用如下代码启动重排即可：

```screen
<script lang="javascript">
    if (Ditto) {
        let para = new Ditto.HwParameter();
        Ditto.Main.start(para);
    }
</script>
```

## 注意点

1. 本应用最小生效粒度为单个Web页面。
2. 本应用会修改viewport，所以必须运行在所有js之前。
3. 完整的参数配置请见对应的[API参考](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/ditto-overview-0000001248219716)章节。
