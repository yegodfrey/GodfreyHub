# 数据导出

分析服务面向您提供事件数据下载的能力，这些数据下载下来后可以导入到您自有的分析系统中，用于构建自定义报告或用于生成自定义受众，以进一步进行个性化分析或营销活动制定。

数据导出提供两种导出方式，您可以选择任意一种方式进行数据导出：

* 通过界面创建数据导出任务。导出成功后，状态显示"已完成"，可以点击右侧的"下载"进行下载。
* 通过API接口创建数据导出任务。提供数据下载接口[创建数据导出任务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-create-data-export-task-0000001050987231)，支持您通过编程的方式，周期性的提取数据。

> 说明
>
> 数据导出功能目前仅对部分邀请伙伴开放，您可以通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/)方式申请开通此功能，申请模板请参考[在线提单指导](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/online-application-guide-0000001174952406#section970144417471)。如果您需要每天定期回传全量数据，建议您[集成DTM（Dynamic Tag Manager）](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-sdk-0000001050041968)和DTM结合使用。

## 典型应用场景

* 通过界面创建数据导出请求，导出成功后，可以直接点击下载链接进行下载。
* 对于导出失败的场景，您可以通过"导出失败"的提示信息，获取解决方法。

## 功能详述

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 管理 > 数据导出"进入页面。
4. 通过界面或API接口创建数据导出任务，详情请参见[通过界面创建导出任务](#section147121537151615)或[通过API接口创建导出任务](#section17541357153418)。
5. 对于导出失败的场景，您可以通过"导出失败"的提示信息，获取解决方法，详情请参见[查看导出失败解决方法](#section8712153791620)。

### 通过界面创建导出任务

1. 进入数据导出页面。

   在"数据导出"页面，您可以查看数据导出请求的基本信息，包括任务名称、创建时间、起始时间、结束时间、创建方式、状态。
2. 点击右上角"创建导出请求"，可导出某一时间段内的事件数据。

   支持用户属性和导出事件作为过滤条件，同时展示"预计可导出事件数"，根据您选择不同的时间段和过滤条件，预估事件数会随之改变。
   > 说明
   > * 创建导出请求后，界面状态显示"待启动"。导出任务每小时周期执行，当在等待时显示"待启动"，如果您想缩短排队时间，建议您在整点前创建任务。
   > * 过滤条件支持用户属性和导出事件，导出事件仅支持预置事件以及自定义事件，不支持自动采集事件。
   > * 数据量超过100万条或者大于1G时，会分为多个csv文件导出。
   > * 数据量超过500万条时，随机导出500万条数据。

1. 进入数据导出页面。
2. 对于导出失败的场景，您可以重试或者点击"客服工单"联系华为支撑人员。

### 导出数据使用EXCEL打开时丢失精度如何处理？

使用EXCEL打开数据导出的CSV文件时，可能会出现丢失数据精度的情况，解决办法请参见[数据导出CSV文件如何不丢失数据精度转化成EXCEL文件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/csv-to-excel-0000001280260901)。
