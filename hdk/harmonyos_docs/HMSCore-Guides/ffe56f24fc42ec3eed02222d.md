# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSAccounts-HarmonyOS-JavaScript)快速体验一个应用的开发过程。  

#### 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上

* 安装[HUAWEI DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio) 2.1及以上

* [HarmonyOS SDK](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/environment_config-0000001052902427-V3#section67391947173214) API Version 5-Version 7
* [HarmonyOS SDK](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/environment_config-0000001052902427-V3#section67391947173214) API Version测试应用的设备：HarmonyOS 2.0及以上的手机
* 安装[Node.js](https://nodejs.org/en/download/) LTS  

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:---------------------------------------|:---------------|:--------------|
|手机、平板|HarmonyOS 2.0及以上|5.0.0.300及以上|
|车机|HarmonyOS 2.0及以上|6.2.0.300及以上|
|华为智慧屏、智能手表（wearable，不支持运动手表liteWearable）|HarmonyOS 2.0及以上|6.5.0.300及以上|

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-|:--------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-preparations-environment-0000001195338707)|在开发HarmonyOS应用前，开发者需要先完成开发准备，包括： 1. [准备开发环境](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-preparations-environment-0000001195338707) 2. [配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-config-agc-0000001195178823) 3. [配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-config-app-signing-0000001199412499) 4. [集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-integration-hms-core-sdk-0000001149139136) 5. [配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-config-obfuscation-script-0000001594489197)|
|2|[登录华为帐号](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-login-0000001151310900)|华为帐号服务提供[Authorization Code登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-login-0000001151310900#section482362015242)和[ID Token登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-login-0000001151310900#section179491049132715)两种登录模式，您可根据实际情况选择其中一种模式实现。|
|2|[静默登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-login-silentsignin-0000001197230457)|用户首次使用帐号登录应用后，再次登录时，无需重复授权。|
|2|[仅申请OpenID或UnionID的应用接入华为帐号快捷登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-scenario-openid-unionid-0000001524858940)|如果应用仅获取华为帐号唯一标识（[OpenID](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-js-authhuaweiid-0000001064638400#section11860164162918)或[UnionID](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-js-authhuaweiid-0000001064638400#section16581158153918)），则可以使用免授权方式登录，华为帐号服务将不会弹出授权框。|
|2|[退出华为帐号](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-logout-0000001151470700)|帐号退出是指应用向用户提供退出当前帐号的入口，用户退出登录后应用需要通知HMS Core SDK清除本地当前已经登录的帐号信息。|
|2|[华为帐号取消授权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-js-cancelauthorization-0000001197310551)|为了提升应用隐私安全，应用可以提供入口，供用户取消对应用的授权。|
