# ECG心电测量记录

心电图（ECG）数据是对促使心脏跳动电信号的图形记录。通过阅读心电图，医生可以深入了解您的心脏起搏点和心律等情况，并判断是否有不规律的情况发生。

![](https://media:901788166617697489 "点击放大")  

#### OAuth权限

联盟卡片申请的权限名称：健康数据 \> 心脏健康数据

* 读权限：https://www.huawei.com/healthkit/hearthealth.read
* 写权限：https://www.huawei.com/healthkit/hearthealth.write  

#### ECG测量记录数据类型

名称：com.huawei.continuous.ecg_record  

|特征数据字段列表|字段描述|类型|可选/必选|单位|取值范围|
|:--------------------|:------------|:-----|:----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|ecg_type|心电图类别|int|M|-|1：单导 6：6导 12：12导 18：18导|
|avg_heart_rate|平均心率|float|M|次/分钟|(0，255)|
|ecg_arrhythmia_type|心律失常类型|long|O|-|0：无结果 1：窦性心律 2：房性早搏 4：室性早搏 8：房颤 16：心率过高 32：心率过低 64：不确定 128：信号质量差|
|user_symptom|用户手动选择的症状|long|O|-|使用bit位描述用户症状。每一个bit位为1则存在此症状，0则不存在。每个bit位描述如下 Bit 0：无不适感 Bit 1：胸闷 Bit 2：胸痛 Bit 3：心慌 Bit 4：气短 Bit 5：头晕 Bit 6：疲劳 Bit 7：睡眠不佳 Bit 8：感冒发烧 Bit 9：其他不适 该字段值为0代表无症状。 举例：如返回的字段值为1022。 1022=1111111110 Bit1\~Bit9值均为1，代表用户症状包含胸闷、胸痛、心慌、气短、头晕、疲劳、睡眠不佳、感冒发烧、其他不适共计9类症状。|
|sampling_frequency|采样频率|int|O|Hz|\[0, 1000\]|
|ecg_algorithm_version|ECG算法版本号|String|O|-|-|
|ecg_data_sources|数据来源，表示设备厂商名称|String|O|-|-|
|ecg_data_length|数据长度|int|O|-|-|
|package_name|包名|String|O|-|-|
