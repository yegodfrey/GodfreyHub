# 调测验证

对照如下测试用例，使用[华为运动健康App测试版](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/sport-device-sdk-0000001051809026)进行测试。  

|用例名称|预置条件|测试步骤|预期结果|
|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|数据共享授权|1. 开发者已在华为开发者联盟申请需要的运动数据或健康数据权限，并已审核通过。 2. 手机已安装应用、华为运动健康App和HMS Core（APK）。 3. 开发者已按照开发指导，实现通过华为账号接口向用户申请读/写对应数据项的权限。|打开应用，调用账号授权。|跳转到账号授权页面，页面上展示应用申请的所有数据项，权限默认全部去勾选。打开开关，即同意数据共享授权。|
|读取华为运动健康App开放的数据|1. 开发者已在华为开发者联盟申请需要的运动数据或健康数据权限，并已审核通过。 2. 手机已安装应用、华为运动健康App和HMS Core（APK）。 3. 用户已同意数据共享授权。 4. 华为运动健康App存在运动和健康数据。 5. 开发者按照开发指导，实现查询数据的接口调用。|调用查询数据的execQuery方法，查询已获得授权的数据。例如以"步数"为例，数据类型为"HiHealthPointType.DATA_POINT_STEP_SUM"，查询时间为当天。|接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，同时返回当日步数统计值，与运动健康App首页显示的步数数据一致。|
|读取实时运动数据|1. 开发者已在华为开发者联盟申请需要的运动数据或健康数据权限，并已审核通过。 2. 手机已安装应用、华为运动健康App和HMS Core（APK）。 3. 用户已同意数据共享授权。 4. 用户已同意运动健康App获取存储权限、位置权限。 5. 开发者按照开发指导，实现开始和结束运动的接口调用。|1. 调用获取实时运动数据的 registerSportData 方法，开始获取实时运动数据。 2. 调用startSport方法，传入对应的sportType，例如"HiHealthKitConstant.SPORT_TYPE_RUN"，即开启室外跑步运动。 3. 调用stopSport接口，停止运动。 4. 调用unregisterSportData接口，停止获取实时运动数据。|1. 接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，启动注册实时运动数据。 2. 接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，手机信息通知栏处有运动信息显示且状态为运动中。运动启动后，可以返回实时运动数据集合Bundle。 3. 接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，运动停止，停止返回实时运动数据。 4. 接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，取消注册实时运动数据。|
|读取实时心率数据|1. 开发者已在华为开发者联盟申请需要的运动数据或健康数据权限，并已审核通过。 2. 手机已安装应用、华为运动健康App和HMS Core（APK）。 3. 用户已同意数据共享授权。 4. 支持心率的穿戴设备已在运动健康App上配对成功，处于连接状态。 5. 开发者按照开发指导，实现获取实时心率数据的接口调用。|1. 调用获取实时心率数据的 startReadingHeartRate方法，开始获取实时心率数据。 2. 调用stopReadingHeartRate方法，停止获取实时心率数据。|1. 接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，获取心率实时数据成功，按照固定时间间隔返回以下的数据： {"heartRateCredibility":0,"hri_info":0,"hr_info":69,"hrsqi_info":0,"time_info":1591361991000} 2. 接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，停止返回实时心率数据。|
|写入数据到华为运动健康App|1. 开发者已在华为开发者联盟申请需要的运动数据或健康数据权限，并已审核通过。 2. 手机已安装应用、华为运动健康App和HMS Core（APK）。 3. 用户已同意数据共享授权。 4. 开发者按照开发指导，实现存储数据的接口调用。|调用saveSample方法，存储数据。例如以"体重"为例，数据类型为"HiHealthSetType.DATA_SET_WEIGHT_EX"。|接口调用成功，返回[SUCCESS](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__SUCCESS)，同时返回存储成功信息\[true,true\]。在运动健康App首页体重卡片或者进入体重二级页面，显示的体重值与写入的数据一致。|
|用户手动取消数据共享授权|1. 应用开发者已在华为开发者联盟申请需要的运动数据或健康数据权限，并已审核通过。 2. 手机已安装应用、华为运动健康App和HMS Core（APK）。 3. 用户已同意数据共享授权。 4. 华为运动健康App存在运动和健康数据。 5. 开发者按照开发指导，实现查询数据的接口调用。|1. 打开"运动健康App \> 我的 \> 隐私管理 \> 数据分享与授权 \> 账号授权应用 \> 应用名称"，进入数据项授权页面，关闭允许读取数据开关，点击确认。 2. 调用查询数据接口，查询已停止共享的数据项。|1. 关闭开关后，即停止数据共享授权。 2. 无法读取数据，接口调用返回[ERR_PERMISSION_EXCEPTION](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealtherror-0000001071707423#ZH-CN_TOPIC_0000002516362104__ERR_PERMISSION_EXCEPTION)。|
