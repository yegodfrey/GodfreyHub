# 房产  
  
#### 事件参数列表

      * VIEWHOUSELIST

用户查看房源列表时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
CATEGORY | 列表归属板块 | String | 必选 | 列表归属板块。取值范围：
        * purchase：购房
        * rent：租房  
FEATURE | 房源特征 | String | 必选 | 房源特征。取值范围：
        * new：新房
        * second_hand：二手房  
  
      * VIEWHOUSEDETAIL

用户查看房源详情时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
CATEGORY | 列表归属板块 | String | 必选 | 列表归属板块。取值范围：
        * purchase：购房
        * rent：租房  
FEATURE | 房源特征 | String | 必选 | 房源特征。取值范围：
        * new：新房
        * second_hand：二手房  
ROOMS | 房间数量 | String | 必选 | 房间数量。取值范围：
        * 1：一室
        * 2：二室
        * 3：三室
        * 4：四室
        * 5+：五室以上  
SALEPRICE | 房源售价 | String | 可选 | 房源售价，CATEGORY=purchase时必填。取值范围：
        * 0-2000000
        * 2000000-3000000
        * 3000000-4000000
        * 4000000-5000000
        * 5000000-8000000
        * 8000000-10000000
        * 10000000+  
RENTFEE | 租房价格 | String | 可选 | 租房价格，CATEGORY=rent时必填。取值范围：
        * 0-300
        * 300-500
        * 500-800
        * 800-1000
        * 1000-1500
        * 1500-2000
        * 2000-3000
        * 3000-5000
        * 5000+  
RENTTYPE | 租房类型 | String | 可选 | 租房类型，取值范围：
        * whole_rent：整租
        * sharing_rent：合租  
CURRNAME | 货币类型 | String | 可选 | 货币类型。  
BRAND | 房产商 | String | 可选 | 房产商。  
  
      * REGISTERACCOUNT

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
REGISTMETHOD | 用户来源 | String | 可选 | 用户来源。  
ACOUNTTYPE | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
  
      * SHARECONTENT

用户通过社交渠道分享商品或内容时，上报此事件。可以分析用户对产品的忠诚度。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
CONTENTTYPE | 分享内容类型 | String | 必选 | 标识用户分享内容的类型。  
CONTENTNAME | 分享内容名称 | String | 可选 | 用户分享内容的名称。  
PRODUCTID | 分享内容ID | String | 必选 | 标识用户分享内容的内容ID。  
CHANNEL | 分享方式 | String | 必选 | 标识用户分享的渠道信息。  
  
      * VIEWCAMPAIGN

用户参与一个营销活动的内容时，触发此事件。可以用于分析评价营销活动的转化情况。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
SOURCE | 营销来源 | String | 可选 | 营销活动提供者的标识，如：HUAWEI PPS。  
MEDIUM | 营销类型 | String | 可选 | 营销活动的类型，如：CPC、Email等。  
PROMOTIONNAME | 营销名称 | String | 可选 | 营销活动的名称。  
KEYWORDS | 关键词 | String | 可选 | 营销活动的关键词。如：搜索广告的关键词。  
CONTENT | 营销内容 | String | 可选 | 营销活动的营销内容。  
MATERIALNAME | 创意名称 | String | 可选 | 营销活动使用的创意素材名称。  
MATERIALSLOT | 营销内容展示位置 | String | 可选 | 创意素材被展示的位置信息。  
CLICKID | 广告网络标记参数 | String | 可选 | 广告网络生成的用于标记广告点击的参数。  
MATERIALSLOTTYPE | 展示位置类型 | String | 可选 | 创意素材被展示的位置类型，如：广告位、运营坑位、Banner等。  
PAGENAME | 页面名称 | String | 必选 | 创意呈现的页面名称。  
EXTENDPARAM | 自定义参数 | String | 可选 | 自定义参数。
