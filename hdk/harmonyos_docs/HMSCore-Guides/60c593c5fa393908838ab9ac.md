# 快速接入

#### 接入流程

商户支付接入流程：

![](https://media:801773305073814618)

1. 用户发起购买后，商户元服务向商户服务器发起请求，创建合单支付订单。
2. 商户服务器请求华为支付服务器的[快应用预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-combined-qucikapp-prepay-0000001622075920)接口，获取到预下单号（prepayId）。
3. 商户服务器获取到prepayId后，需要组参[orderStr](#section324281723615)返回给商户客户端。除sign外，其他字段都需要使用商户私钥签名并赋值给sign。
4. 商户元服务调用[combinedPay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/quick-app-client-hms-aggrpay-0000001538347902#section196769337438)接口调起华为支付服务收银台，完成支付。
5. 支付成功后，华为支付服务器会调用商户入参的callbackUrl接口，返回支付结果给商户服务器；支付失败场景可能不会有支付结果回调通知。
6. 商户服务器收到支付结果回调响应后，使用SM2验签方式对支付结果进行验签。

![](https://media:801773305073846619)  
支付是否成功可以通过回调通知中的orderStatus的返回状态判断：

* TRX_SUCCESS：交易成功
* TRX_FAILED：交易失败  

#### 客户端开发

* 获取orderStr入参

商户服务器通过调用[快应用预下单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-combined-qucikapp-prepay-0000001622075920)获取预支付ID（prepayId）后商户服务器需要构建orderStr返回给客户端。

orderStr参数说明  

|参数|参数类型|是否必填|描述|
|:--------|:-----|:---|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
|app_id|String|否|应用ID。|
|merc_no|String|是|商户号|
|prepay_id|String|是|预下单id，使用预下单请求生成，有效期2小时。|
|timestamp|String|是|当前时间戳，标准北京时间，时区为东八区，自1970年1月1日 0点0分0秒以来的毫秒数，13位。示例值：1666230721315|
|noncestr|String|是|随机字符串，不长于32位。推荐随机数生成算法。 每笔订单都需要重新生成。|
|sign|String|是|签名，使用除了sign字段以外的其他字段计算签名值。可参考[签名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-signature-rule-0000001538533912#section272163402611)章节|
|auth_id|String|是|开放平台分配的鉴权id，一个商户可配置多套证书，请妥善保管|

* 调起支付收银台

开发者可使用@hw-hmscore/hms-payment的HMSPAYMENT对象方法拉起支付页面。

```
// 快应用appId
const appId = "****";
const orderStr = "{\"merc_no\":\"***\",\"prepay_id\":\"1230331185102089244382635044\",\"timestamp\":\"1680259863114\",\"noncestr\":\"1487b8a60ed9f9ecc0ba759fbec23f4f\",\"sign\":\"****\",\"auth_id\":\"***\"}";
HMSPAYMENT.combinedPay(orderStr, appId).then(res => {
  console.info("res: "+ JSON.stringify(res));
  // 参考下表解析res,此处可以处理支付结果，界面刷新和跳转等操作   
}).catch(err => {
    console.error("err: "+ JSON.stringify(err));
  })
```

* 支付结果获取和处理

1. 调用[combinedPay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/quick-app-client-hms-aggrpay-0000001538347902#section196769337438)接口后同步返回支付结果 ，通过Handler发送消息在主线程处理支付结果。

   回调结果说明  

   |参数|参数类型|描述|参考示例|
   |:------|:-----|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |errCode|string|返回码|见[HMS Core SDK错误码](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/error-code-0000001050045846)说明|
   |errMsg|string|返回信息描述|示例："{\\"PayResult\\":\\"{\\\\\\"returnCode\\\\\\":\\\\\\"0\\\\\\",\\\\\\"returnMsg\\\\\\":\\\\\\"pay success\\\\\\"}\\"}" returnCode为0时表示成功，具体返回参考[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/quick-app-client-error-code-0000001538667594)|

2. 商户在构建支付请求参数时，传入了一个callbackUrl。在华为支付服务器完成支付后，将以post方式调用callbackUrl，将支付结果返回给商户服务器。

![](https://media:801773305073880620)  
若支付成功，不建议以客户端返回作为用户的支付结果，需以服务器接收到的结果通知或者查询API返回为准。
