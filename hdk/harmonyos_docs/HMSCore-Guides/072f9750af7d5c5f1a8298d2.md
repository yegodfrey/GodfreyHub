# 消息分类标准

> 注意
>
> * 2023年2月28日发布：[《华为消息分类调整通知》](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/push_notice-0000001529940921)
> * 2023年7月21日发布：《[本地通知频次及分类管控通知](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-Guides/push_notice_local-0000001615143510)》
>
> 为了给用户提供更好的消息通知体验，从**2023年9月15日** 开始，**华** **为推送服务将对应用发送的本地通知频次及分类进行灰度管控** 。应用发送的本地资讯营销消息将计入总的资讯营销消息频次数量，每天应用的推送频次有总量限制，具体请参见《[推送数量管理细则](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-restriction-description-0000001361648361)》。
>
> 应用可通过[申请自分类权益](#section3410731125514)，对本地通知进行分类管理（应用若已申请云端相关消息类型，将自动生效对应的本地通知类型，本地通知无需重复申请，但应用仍需适配开发）。
>
> 本地通知自分类申请和适配请参考[指导](#ZH-CN_TOPIC_0000001652651372__p84118160194)。

为了改善终端用户推送体验、营造良好可持续的通知生态，华为推送将对推送消息分类进行管理。根据消息内容，华为推送将通知分类为服务与通讯、资讯营销两大类别。

## 华为通知定义

**华为通知**为华为终端设备上展示的通知消息，显示位置包括锁屏、通知中心等，通常包含云端通知和本地通知。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/yiutvFr5TDSflczBkwtNvA/zh-cn_image_0000001652651548.png?HW-CC-KV=V1&HW-CC-Date=20260915T074230Z&HW-CC-Expire=31536000000&HW-CC-Sign=1291021576A6A8F31E0780C69FDD57990FB6F4D579D73A8A7DA5FE42F1B418EE "点击放大")

* 云端通知，指的是通过华为推送服务发送的通知。（应用服务端调用华为推送服务API发送的通知）
* 本地通知，指的是应用在运行时发送的通知。（应用客户端直接调用系统接口发送的通知）

云端通知与本地通知统一按照《消息分类标准》进行分类，若应用出现违规行为，华为推送将根据《华为通知消息管理规则》对该应用进行处罚。

## 消息分类方式

华为通知（云端通知和本地通知）的消息分类方式统一为消息自分类。如您希望消息分类能更精准地符合业务需要，可以[申请自分类权益](#section3410731125514)。

* 华为推送服务接受开发者自分类权益的申请。当您申请成功后，允许开发者根据《华为消息分类标准》，自行对消息进行分类（举例：具有消息自分类权益且申请了自分类消息类型IM消息，当您发送消息时携带"category"字段且赋值为"IM"，则该消息的提醒方式为锁屏+铃声+振动）。
* 未接入消息自分类的应用，消息通知类型将会默认归为**资讯营销类消息** ，资讯营销消息每日推送数量上限要求请参考《[推送数量管理细则](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-restriction-description-0000001361648361)》。

## 概要

华为将根据消息分类方案对不同类别消息的提醒方式、消息展示位置进行差异化管理，具体如下：

|**消息类型**|**提醒方式**|推送数量限制|
|:-------|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------|
|服务与通讯|锁屏、铃声、振动|无限制|
|资讯营销|静默通知，仅在通知中心（更多通知）里展示消息|根据应用类别限制每日推送数量，具体要求参见《[推送数量管理细则](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-restriction-description-0000001361648361)》|

> 注意
>
> 提醒方式的差异在EMUI 10.0及以上的版本生效。

## 消息分类标准

### 定义

服务与通讯，包括社交通讯类消息和服务提醒类消息。

* 社交通讯，指用户间的聊天消息、通话等信息。
* 服务提醒，指应用借助通知中心及时向用户传递重要通知提醒，通常用户对接收此类消息有预期。

资讯营销，包括资讯类消息和营销类消息，指的是运营人员向用户发送的活动信息、内容推荐、资讯等。

### 分类标准

结合应用的消息内容和消息发送场景，华为推送将消息分为以下消息类型。
> 注意
>
> 随着应用的消息发送场景不断变化，华为推送的分类标准也将不断演进和补充，请及时留意本文档最新的分类说明。

## 申请步骤

**申请原则**

当您充分了解了[通知消息分类方式](#section1653845862216)，准备申请通知消息自分类权益前，建议您先确认申请是否满足以下原则：

1. 应用的推送消息按照一定维度进行分类，且分类符合[消息分类标准](#section1076611477914)。
2. 应用遵守《[华为推送服务使用协议](https://developer.huawei.com/consumer/cn/doc/app/20213)》和相关规范，且未产生违规记录。
3. 消息类型需与分类规则要求一致，消息内容示例需与消息类型描述对应。

**创建本地通知示例代码：**

```screen
// 获取NotificationManager对象
NotificationManager notificationManager = (NotificationManager) context.getSystemService(Context.NOTIFICATION_SERVICE);

// 创建通知通道，若已有通知通道可直接复用，无需重复创建
notificationManager.createNotificationChannel(new NotificationChannel("test_channel_id", "test_channel_name", NotificationManager.IMPORTANCE_DEFAULT));

// 创建通知，设置通知内容，消息类别
Notification notification = new Notification.Builder(context, "test_channel_id").setContentTitle("test_title")
    .setContentText("notification content")
    .setSmallIcon(appIcon) // appIcon为应用图标
    .setCategory(Notification.CATEGORY_ALARM) // 设置消息类别
    .build();

// 发送通知
notificationManager.notify(1, notification);
```

### 违规处罚

应用云端通知与本地通知都需遵守[《消息分类标准》](#section1076611477914)，如出现分类错误，违反消息分类标准的场景，将被判为违规。

本地通知需按照消息类型，正确配置[setCategory](https://developer.android.google.cn/reference/android/app/Notification.Builder#setCategory(java.lang.String))值和[importance](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p11320685234)级别，如出现消息提醒方式错误，违反消息分类标准的场景，将被判为违规。

违规行为及相应的处理措施请参见[违规分类、违规行为及违规处罚标准](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/volation-classification-violation-penalty-criteria-0000001356540133)。
