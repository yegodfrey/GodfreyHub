# FTMS 华为扩展特征值

|特征值|属性|UUID|用途说明|
|:---------------------|:----|:-----------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|Fitness Extension Data|write|d18d2c10-c44c-11e8-a355-529269fb1459|在FTMS扩展的特征值， 1. 用于解锁跑步机的蓝牙控制通道，只有解锁后，才能通过Fitness Machine Control Point发送主动控制指令（椭圆机、划船机、智能单车、走步机不支持解锁码）。 2. 用于将心率、计步、卡路里每秒传递给运动设备（包括跑步机、椭圆机、划船机、智能单车、走步机）。|

华为扩展特征值的作用有如下几个：

* 对设备的控制功能进行解锁。基于安全考虑，未解锁情况下，不允许蓝牙设备直接控制设备的启动、停止、速度、坡度等。

* 将手机的实时心率、计步、卡路里参数推送到设备进行同步显示。

|参数|格式|大小|取值(0:Not 1:Present)|含义|
|:-------------|:-----|:------|:------------------|:------------------------|
|Flags|16bits|2octets|Bit0|参数包含解锁码|
|Flags|16bits|2octets|Bit1|参数包含心率|
|Flags|16bits|2octets|Bit2|参数包含总卡路里|
|Flags|16bits|2octets|Bit3|参数包含动态卡路里|
|Flags|16bits|2octets|Bit4|参数包含计步|
|Flags|16bits|2octets|Bit5-15|保留|
|UnlockCode|Octets|6|厂家自定义，6字节解锁码|厂家自定义，6字节解锁码，解锁码为0-F的6个数字|
|Heart Rate|Uint8|1|心率值|心率值|
|Total Energy|Uint16|2|总卡路里|总卡路里|
|Dynamic Energy|Uint16|2|动态卡路里|动态卡路里|
|Step Count|Uint16|2|实时步数|实时步数|
