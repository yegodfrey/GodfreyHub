# 页面管理

#### 功能概述

通过页面管理可查看项目下所有页面的基本情况，以及对页面进行新增、编辑和删除操作，这些页面的访问次数、次均停留时间等数据，将会在"页面分析"报告中呈现。详情请参见[页面分析](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/page-analysis-0000001078204750)。  

#### 典型应用场景

* 查看页面的基本信息，包括页面ID、页面名称、页面说明、分组名称、创建时间等。
* 管理页面分组。
* 创建、编辑或删除页面。
* 禁用或启用页面。
* 隐藏禁用页面。  

#### 功能详述

#### 案例

某App开发人员想要查看项目下所有页面基本情况，并且增加一个新的页面。

需求：查看页面报告，新建页面。  

#### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 \> 管理 \> 页面管理"，进入页面管理页面。
4. 新建分组，详情请参加[新建页面分组](#section357573714511)。
5. 新建页面，详情请参见[新建页面](#section184861454101115)。
6. 管理现有页面，详情请参见[编辑、删除、禁用、转移页面](#section164871354161110)。
7. 批量管理页面，详情请参见[批量管理页面](#section15488954101110)。
8. 批量编辑页面，详情请参见[批量编辑页面](#section104748351335)。  

#### 新建页面分组

1. 点击页面组后的"管理"，可以添加分组、删除分组、编辑分组、置顶或者取消置顶分组。
   * 新增分组名称同项目唯一，默认最多支持十个分组，超过以后"添加分组"按钮置灰。
   * 编辑分组信息时，分组名称不可编辑。
   * 删除分组时，将组内的所有页面释放到"未分组"中。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115251.58715658361859420993723444977617:50001231000000:2800:40FF104ECCBBBF18F04C0760106406DB013A56391B19E4A9BAFE68BFEAF3125F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)
2. 置顶页面分组。

   进入管理页面分组页面，点击"置顶"即可置顶页面分组。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115251.55215947035793550622916516505823:50001231000000:2800:43952ABDFDE02CC6C59045BE3EE06498DFBA45D1F5ACCCAE2F03EE3D02AAA50E.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   * 当页面分组中只有一个分组时，默认置顶该页面分组。
* 置顶当前页面分组后，该页面分组里所有页面会在页面分析里优先呈现。  

#### 新建页面

1. 进入"页面管理"页面。

   该页面展示了项目下的所有页面信息，可以在页面组下拉框选择对应分组，查询该分组下的的页面信息，包括页面ID、页面名称、页面说明、分组名称、创建时间等。

   单一项目下最多只能创建1500个页面，当到达1500个页面以后，新建页面提示页面数量超过最大值。若需要添加新的页面，请先删除部分页面，页面数量小于1500后再添加。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115251.72007077295823576777066960317640:50001231000000:2800:4039A173DBB66F1395E2DE5244670FA9B3EDAF72EDE992D4AF1649BE1E39927D.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
2. 点击"新建"，弹出新建页面窗口。

   填写页面ID、页面名称、页面说明，新建的页面默认属于"未分组"。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115251.59446902042495792345202449459485:50001231000000:2800:24F75CB6C200224514B526E3CDBCD26D8672B83ECAD255AF32664BA7D46F9F66.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

   参数填写说明：  

   |参数|填写说明|
   |:---|:-----------------------------------------|
   |页面ID|长度不超过256。|
   |页面名称|长度不超过255，名称请勿包含特殊字符\<\>"'\[\]$%+\\/\*;=\^,|
   |页面说明|长度不超过1000，说明请勿包含特殊字符\<\>"'\[\]$%+\\/\*;=\^|

3. 点击"保存"即可新建成功。

3. 点击"删除"，即可删除该页面。

#### 批量管理页面

1. 进入页面管理页面。
2. 点击页面右上角"批量管理"，进入批量管理页面。
3. 点击"下载模板"，下载页面批量填写模板。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115251.64463814140226093408870378535015:50001231000000:2800:BBCDDCA0E70FD364F3CE78DA75141497CEE8630368B6788A3172C1A561B53047.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
4. 模板文件中填写页面ID、页面名称和页面说明。

   模板文件中参数填写说明：  

   |参数|参数名称|填写说明|
   |:---------|:---|:------------------------------------|
   |page_id1|页面ID|长度在256个字符以内。页面ID不能重复。|
   |page_name1|页面名称|长度在255个字符以内，填写便于您记忆和理解的页面名称。页面名称不能重复。|
   |page_desc1|页面描述|长度在1000个字符以内，填写您定义此页面的目的、场景等信息。|

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115251.09979941316351207653797353248284:50001231000000:2800:8DBA515C9CEE0F84219F242CA76326CC9211F6FFEF9DEBE3E1E428BB6C598BD4.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   模板文件其它约束：
   * 文件不能为空
   * 文件格式为xls、xlsx
   * 文件大小不超过1M
   * 文件总行数不超过1500行
   * 文件中页面名称和页面描述均不能包含换行及特殊字符\<\>"'\[\]$%+\\/\*;=\^,
   * 一个帐号一分钟内只能批量上传一次
5. 填写完毕后点击"选择文件"，批量导入页面。  

#### 批量编辑页面

1. 点击"下载"，批量下载现有的已采集数据。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115251.60148065552621099087530993787356:50001231000000:2800:80E06D0CE38291222EDBDA9ACAD8B01258317C820CB2DDB690547F9EF5DBC387.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
2. 编辑已导出表格中的页面数据。
3. 点击右上角"批量管理"，进入批量管理页面。
4. 点击"选择文件"，批量导入已编辑页面。
5. 点击"确定"，完成页面数据的批量更新。
