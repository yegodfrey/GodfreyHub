# 概述

准入条件：

* 具备能够独立完成对接的技术能力。
* 公司运营状况良好，拥有一定客户群。
* 支持合作后进行服务联动，及时提供数据反馈和处理用户异议。
* 通过开发者联盟注册、企业实名认证和资格审查。
* 完成网签协议签署。
* 支持WEB方式接入Wallet Kit服务。

<br />

Wallet Kit服务提供两种卡券接入方式，请根据业务需要选择适合自己的开发方式。  
方式一：网页、短信、Email、App应用内方式领取卡券  

|步骤|章节|动作|用途说明|
|:--|:-------------------|:--------------------------------------------------------------------------------------------------------------|:-----------------|
|第一步|AppGallery Connect配置|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050193505)|配置申请Wallet Kit相关服务|
|第二步|安全组件申请|[生成安全密钥](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-rsa-0000001135545395)|用于加密推送至华为服务器的JWE数据|
|第三步|服务创建|[服务创建](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-server-0000001050160377)|创建Wallet Kit服务|

方式二：App应用内、快应用、华为钱包CardStore方式领取卡券  

|步骤|章节|动作|用途说明|
|:--|:-------------------|:--------------------------------------------------------------------------------------------------------------|:--------------------------|
|第一步|AppGallery Connect配置|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050193505)|配置申请Wallet Kit相关服务。|
|第二步|安全组件申请|[证书申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-certificates-0000001088723154)|通过此方式申请证书和私钥签名卡券包推送至华为钱包应用。|
|第三步|服务创建|[服务创建](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-server-0000001050160377)|创建Wallet Kit服务。|
