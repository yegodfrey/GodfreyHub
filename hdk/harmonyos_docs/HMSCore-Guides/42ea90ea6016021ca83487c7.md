# 功能测试

在您的游戏开发过程中，可参考本节内容创建测试帐号，并完成典型场景的功能测试。  

#### 创建测试帐号

在应用测试阶段，您可以在AppGallery Connect中[创建沙盒测试帐号](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-testaccount-0000001146438651)，并设置允许这些帐号执行沙盒测试。沙盒测试可以测试[支付测试](#ZH-CN_TOPIC_0000001050123493__p1045713254162)，包括非消耗商品、消耗商品、自动续费订阅型商品支付，联调过程中无需真实支付即可完成端到端的测试。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250424141807.38833536199705027775915567989922:50001231000000:2800:4A9BBDCAC1EA5AA27B6D0E4416DE0815A5257BF8FD7378D32F96B66C9A904650.png)  
目前支付沙盒测试功能只支持集成HMS Core SDK 3.0及以上版本的应用，并且测试设备必须安装3.0以上HMS Core（APK）。如果使用HMS Core SDK 2.0版本的支付接口测试仍将导致真实的扣费。
