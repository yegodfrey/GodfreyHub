# 创建地图

#### 概览

本章节将向您介绍如何使用地图容器快速地获得地图对象、修改地图类型以及在地图上绘制形状和标记。详情请参见[Flutter示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-flutter-0000001208537346)。  

#### 一般用法

构建[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimap-0000001253024725)组件，该组件中地图上的特征（例如标记和多边形）可作为子元素使用。提供了一个接口来声明性地控制地图上的特征。

```
import 'package:huawei_map/map.dart';
```

#### 地图实例创建

下面介绍如何使用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimap-0000001253024725)来创建地图实例。

1. 在main.dart文件中添加[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimap-0000001253024725)对象，并设置地图属性。

   <br />

   ```
   HuaweiMap( 
       mapType: MapType.normal, 
       tiltGesturesEnabled: true, 
       buildingsEnabled: true, 
       compassEnabled: true, 
       zoomControlsEnabled: false, 
       rotateGesturesEnabled: true, 
       myLocationButtonEnabled: true, 
       myLocationEnabled: true, 
       trafficEnabled: true, 
       .... 
   )
   ```

   <br />

2. 运行您的项目以在您的应用中查看地图，如下图所示。

   <br />

   ![](https://media:301772613561256558)

   设置地图上显示的初始位置。对象创建后再修改该属性将不会促使相机位置改变。

   ```
   HuaweiMap( 
     initialCameraPosition: CameraPosition( 
       target: const LatLng(41.012959, 28.997438), 
       zoom: 12, 
     ), 
   ...
   ```

   或者，您可以使用控制状态并跟踪地图中心点的坐标。

   ```
   double _zoom = 12; 
   LatLng _center = const LatLng(41.012959, 28.997438); 
   ... 
   HuaweiMap( 
     initialCameraPosition: CameraPosition( 
       target: _center, 
       zoom: _zoom, 
     ), 
   ...
   ```

   详情请参见[Flutter示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-flutter-0000001208537346)中的文件。

   <br />

#### 地图类型

目前HuaweiMap支持两种地图类型：

* MapType.normal：标准地图。展示道路、建筑物以及河流等重要的自然特征。
* MapType.none：空地图。没有加载任何数据的地图。

要设置地图类型，可以设置HuaweiMap对象的mapType属性，并传递[MapType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-maptype-0000001208024796)中定义的枚举值。

如果要设置空地图，请将HuaweiMap对象的mapType属性设置为MapType.none。地图显示效果如[图1](#ZH-CN_TOPIC_0000001207381558__fig0232153211598)所示。

示例代码如下：

```
HuaweiMap( 
    mapType: MapType.none, 
    ... 
)
```

如果要设置标准地图，请将HuaweiMap对象的mapType属性设置为MapType.normal。地图显示效果如[图2](#ZH-CN_TOPIC_0000001207381558__fig323213321599)所示。

示例代码如下：

```
HuaweiMap( 
    mapType: MapType.normal, 
    ... 
)
```

#### 我的位置

我的位置功能允许用户在使用您的应用时获取他们当前所在的位置。在使用该功能之前，请确保您的应用已被授予定位权限。Android操作系统提供两种位置权限："ACCESS_COARSE_LOCATION"（粗略位置权限）和"ACCESS_FINE_LOCATION"（精确位置权限）。您需要在Manifest文件中声明这些权限。

```
<!-- 允许应用通过WiFi或基站信号获取用户的大致经纬度坐标。--> 
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/> 
<!-- 允许应用通过GPS芯片从卫星接收位置信息。--> 
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
```

在Manifest文件中添加上述信息后，需要在代码中动态申请这些权限（Android 6.0危险权限要求）。

要启用此功能，请将HuaweiMap对象中的"MyLocationEnabled"设置为true。

示例代码如下：

```
HuaweiMap( 
    myLocationButtonEnabled: true, 
    myLocationEnabled: true, 
    ...
```

启用此功能后，地图右下角默认显示"我的位置"图标，且用户当前位置显示为蓝点。当用户点击此图标时，用户的当前位置（如果获得）将显示在屏幕中央。

您也可以在HuaweiMap对象中设置"myLocationButtonEnabled"为false，以隐藏"我的位置"图标。

#### 地图属性设置

* "mapType"：地图类型。取值包括none和normal。
* "initialCameraPosition"：相机处于初始位置时，地图中心点的经纬度和缩放级别。
* "zoomControlsEnabled"：是否开启缩放控件。缩放控件默认开启。
* "compassEnabled"：是否开启指南针。指南针默认开启。
* "zoomGesturesEnabled"、"scrollGesturesEnabled"、"rotateGesturesEnabled"和"tiltGesturesEnabled"：是否开启缩放手势、滚动手势、旋转手势和倾斜手势。这些手势默认开启。
* "minMaxZoomPreference"：偏好的最小和最大缩放级别。
* "cameraTargetBounds"：CameraTargetBounds对象边界的经纬度，用于约束相机目标，使用户移动相机时，相机目标不会移出此边界范围。
* "markers"：初始标记对象。
* "circles"：初始圆对象。
* "polylines"：初始折线对象。
* "polygons"：初始多边形对象。
* "groundOverlays"：初始地面覆盖物对象。
* "tileOverlays"：初始瓦片图层对象。
* "markersClusteringEnabled"：是否开启标记聚合功能。
* "padding"：地图填充。该属性可用于定义地图上的可见区域，以便可以向地图发送信号来指示地图边缘周围的某些部分可能被遮挡。例如，缩放控件和指南针等图标会被移动以适应地图可见区域，相机将相对于可见区域的中心点移动。

详情请参见[HuaweiMap属性](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimap-0000001253024725#section5288mcpsimp)。  

#### 地图填充

华为地图服务是通过模拟相机来实现的。地图相机区域已目标位置为中心进行填充。地图控件（如指南针、缩放图标和我的位置图标等）放置在地图相机区域的边缘。默认情况下，指南针放置在地图相机区域的右上角，缩放图标和我的位置图标放置在地图相机区域的右下角。您可以使用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/flutter-plugin-huaweimap-0000001253024725)接口的padding字段设置地图相机区域边界和地图控件之间的填充。
