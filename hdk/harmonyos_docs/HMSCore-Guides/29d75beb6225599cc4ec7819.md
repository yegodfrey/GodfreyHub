# 概述

当低权限用户需要发布时，需经过拥有审批权限用户的审核，审核通过后，版本才能正常发布。

低权限用户可以提交审核或撤销审核；拥有审批权限的用户可以进行审核操作或转移审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/Bcdj1LdUTeetb4P_dXtT7A/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042952Z&HW-CC-Expire=86400&HW-CC-Sign=063CA9BC3A541A3594EFE87B94036292AD1879AC8C83595650D63AFACFECDFB2)

    * 仅有编辑DTM配置权限的用户为低权限用户，如运营、开发人员。
    * 拥有发布DTM配置权限的用户则拥有审批权限，如帐号持有者、管理员、App管理员。
