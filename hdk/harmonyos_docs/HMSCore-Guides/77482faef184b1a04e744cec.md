# 网页、短信、Email、App应用内方式生成安全密钥

在创建Wallet Kit服务之前，需要提前使用华为提供的公私钥生成工具，按照如下步骤生成公钥和私钥。

1. 下载[RSAUtils.zip](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260630161020.63711048031187405418423428521595:50001231000000:2800:30538E985D685ED3EEF49D5DCB1D95A492F917A441F990C17973D186C40A061E.zip?needInitFileName=true)压缩包，解压并打开RSAUtils文件夹，双击运行**start.bat**文件：

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/cmEwGi-bQ26Xqh9UdssEkg/zh-cn_image_0000001135401049.png?HW-CC-KV=V1&HW-CC-Date=20260909T142710Z&HW-CC-Expire=31536000000&HW-CC-Sign=8C685D99FCA2E14467E35538455C26C5BA1D242FFC0922FBA723C29ABA6D4B1F "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/SF-733_1SF29LchbtswhTQ/zh-cn_image_0000001088275254.png?HW-CC-KV=V1&HW-CC-Date=20260909T142710Z&HW-CC-Expire=31536000000&HW-CC-Sign=3509471CF353B1EB2F7D7A5CFE5F712B80E6AD3FEFB3DA0C12EB514212B246E0 "点击放大")

2. 运行成功后，请打开当前路径下的out文件夹即可查看生成的公私钥文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/80/v3/HRP60-ZwR4miAD5wp-1-GA/zh-cn_image_0000001135662771.png?HW-CC-KV=V1&HW-CC-Date=20260909T142710Z&HW-CC-Expire=31536000000&HW-CC-Sign=2C982C55C1602B08D0BCDC5B2960513DAA0495E87937EA4BC6567ECD00311684 "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/17/v3/qkvAwZX8Q5qc4BBDKLnnYA/zh-cn_image_0000001088403752.png?HW-CC-KV=V1&HW-CC-Date=20260909T142710Z&HW-CC-Expire=31536000000&HW-CC-Sign=2D825823DCC08A76A90139A999AEB02880074C0F287C5D16D9C60ED98A401B00 "点击放大")

3. 公钥文件为publickey.txt，私钥文件为privateKey.txt，公钥文件在[华为开发者联盟网站AGC](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)上注册Wallet Kit服务时使用，请妥善保存当前生成的公私钥文件。
