# SDK自渲染模板广告接入

#### 获取广告

使用"[NativeAdLoader.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeadloader-builder-0000001050066865)"构建 NativeAdLoader 来获取原生广告。

NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "广告位 ID");

builder.setNativeAdLoadedListener(new NativeAdLoadedListener (){...});

nativeAdLoader.loadAd(new AdParam.Builder().setSupportTemplate(true).build());  
示例代码：

```
import com.huawei.hms.ads.AdListener;
import com.huawei.hms.ads.AdParam;
import com.huawei.hms.ads.nativead.NativeAd;
import com.huawei.hms.ads.nativead.NativeAdLoader
…
public class AdActivity extends Activity implements NativeAd.NativeAdLoadedListener {
    private static final int PHONE = 4;

    private ListView listView;

    private AdAdapter adapter;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_list);
        …
        listView = (ListView) findViewById(R.id.list);
        // AdAdapter处理广告展示
        adapter = new AdAdapter(this);
        listView.setAdapter(adapter);

        // 实例化NativeAdLoader,传入广告位id列表
        NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, 广告位ID);
        NativeAdLoader nativeAdLoader = builder.setNativeAdLoadedListener(this)
        .setAdListener(new AdListener(){
            @Override
            public void onAdLoaded() {
                Log.i(TAG, "load ad, success:");
            }
            @Override
            public void onAdFailed(int errorCode) {
                Log.e(TAG, "fail to load ad, errorCode is:" + errorCode);
            }
        }).build();
        …
        // setSupportTemplate:当开发者完成适配后，需求设置为true才会返回SDK自渲染广告
        // 从云端获取广告
        nativeAdLoader.loadAd(new AdParam.Builder().setSupportTemplate(true).build());
    }

    // 实现监听器的加载成功方法
    @Override
    public void onNativeAdLoaded(NativeAd nativeAd) {
        // AdAdapter添加广告并展示
        adapter.addAds(nativeAd);
    }
    …
}
```

#### 代码

AdAdapter 加载广告数据后通过 notifyDataSetChanged()通知 getView()渲染广告页。

```
import com.huawei.hms.ads.AdFeedbackListener;
import com.huawei.hms.ads.nativead.NativeAd;
import com.huawei.hms.ads.nativead.NativeView;
…
public class AdAdapter extends BaseAdapter {
    private static final int TEMPLATE_AD = 99;

    private List<NativeAd> adList = new ArrayList<>();
    …
    public void addAds(NativeAd ad) {
        adList.add(ad);
        if (ad != null) {
            ad.setNativeListener(new NativeListener() {
                @Override
                public void onAdClicked() {
                    Log.d(TAG, "点击回调");
                }

                @Override
                public void onAdImpression() {
                    Log.d(TAG, "曝光回调");
                }
            });
        }
        // 通知getView处理广告并展示
        notifyDataSetChanged();
    }

    @Override
    public View getView(int position, View convertView, ViewGroup parent) {
        View view = null;
  NativeAd nativeAd = adList.get(position); 
        if (convertView == null) {
            if (nativeAd.getCreativeType() == TEMPLATE_AD) {
                // 根据广告创意类型，选择不同的布局，模板广告布局内仅需要包含NativeView
                LayoutInflater inflater = LayoutInflater.from(context);
                view = inflater.inflate(R.layout.list_item, parent, false);
            } else {
                …
            }
        } else {
            view = convertView;
        }

        // 获取NativeView
        NativeView nativeAdView = view.findViewById(R.id.ad_root_layout);
        nativeAdView. setNativeAd(nativeAd);  // 注册广告内容对象
        // 设置负反馈监听（可选）
        nativeAdView.setAdFeedbackListener(adFeedbackListener);     
        // 设置关闭监听（可选）
        nativeAdView.setAdCloseBtnClickListener(adCloseBtnClickListener);
        return view;
    }

    private final AdFeedbackListener adFeedbackListener = new AdFeedbackListener() {
        @Override
        public void onAdFeedbackShowFailed() {
            Log.d(TAG, "AdFeedbackListener, showFeedbackFailed");
            // ***feedback view弹出失败，可选择自行弹窗负反馈界面
            //   ***若需要上报负反馈事件，调用NativeView.onClose()接口上报

            // 也可选择直接移除广告画面
        }
        @Override
        public void onAdLiked() {
            Log.d(TAG, "AdFeedbackListener, onAdLiked");
        }
        @Override
        public void onAdDisliked() {
            Log.d(TAG, "AdFeedbackListener, onAdDisliked");
        }
    }

    private final AdCloseBtnClickListener adCloseBtnClickListener = new AdCloseBtnClickListener() {
        @Override
        public void onCloseBtnClick() {
            // 广告关闭按钮监听回调, 目前仅在原生横幅、原生插屏中使用
            Log.d(TAG, "AdClosedBtnClickListener, onCloseBtnClick");
        }
    };
}
```

1. 设置本次请求是否支持模板渲染广告：[setSupportTemplate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-builder-0000001050066829#section17899723114920)。
2. 获取创意类型：[getCreativeType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativead-0000001050066855#section752075813145)
   * 99： 模板广告（SDK 渲染广告）。
   * 其他： 开发者自渲染广告。
3. 模板广告接口调用说明：[NativeView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeview-0000001050064918)。
4. 应用设计的广告 Layout 文件中，NativeView 需要作为根节点。
5. 当返回的 ad 是模板广告（creativeType = 99），则需要调用下列接口： [setAdFeedbackListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/nativeview-0000001050064918#section14497143918564)
6. 动态模板原生广告控制项
