# 开发准备

## 集成SDK

针对Android Studio开发环境，华为提供了Maven仓集成方式的SDK包。在开始开发前，开发者需要将华为支付服务SDK集成到开发者的Android Studio开发环境中。

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

### 添加应用的AppGallery Connect配置文件

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到开发者的项目，在项目中点击需要集成HMS Core SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.json"下载配置文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/48/v3/EDAHELktRW2BQTAA4PGtvg/zh-cn_image_0000002512279973.png?HW-CC-KV=V1&HW-CC-Date=20261008T180238Z&HW-CC-Expire=31536000000&HW-CC-Sign=6480A295AC8671427E9758A4AB5819A1B3EC1056175EA8504F96A69C17499C64 "点击放大")

4. 将"agconnect-services.json"文件拷贝到应用级根目录下。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/87/v3/zRk89zOzTsqowNKR6n5tMQ/zh-cn_image_0000002480160106.png?HW-CC-KV=V1&HW-CC-Date=20261008T180238Z&HW-CC-Expire=31536000000&HW-CC-Sign=1F9732190E226B537370A6D7B6F6DCA28ABEF4CA8F414D5EC89971DE0FB5E771)

### 配置SDK的Maven仓地址

参见[Maven仓库地址配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-maven-repository-0000001970825281#section63821917164110)。

### 添加SDK编译依赖

SDK版本参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041)。

1. 打开应用级"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/LdtQuuzSSp2ZrvE0LCQEKw/zh-cn_image_0000002512200003.png?HW-CC-KV=V1&HW-CC-Date=20261008T180238Z&HW-CC-Expire=31536000000&HW-CC-Sign=046D307CB5B7D459FEBA7F99EACDCF3FCB40C0F4406DD3F8613CF20E4B4F8EF5)


2. 在"dependencies"中添加如下编译依赖。

   ```screen
   dependencies {
       implementation 'com.huawei.hms:paymentservice:6.12.0.300'
   }
   ```

   > 说明
   >
   > SDK版本号索引请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/appendices-sdk-update-0000001970804041#section163461949192517)，例如：implementation 'com.huawei.hms:paymentservice:6.12.0.300'。
3. 在完成以上的配置后，点击工具栏中的gradle同步图标，完成"build.gradle"文件的同步，将相关依赖下载到本地。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f7/v3/HPIlvU1cR9m0exVmTI26iw/zh-cn_image_0000002512279981.png?HW-CC-KV=V1&HW-CC-Date=20261008T180238Z&HW-CC-Expire=31536000000&HW-CC-Sign=ABFA7F7288791CD4EA236B30E5A76C65FE5F4450C71A1414A999446858ED8898)
   > 说明
   >
   > 1、如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
   >
   > 2、若开发者的APP有添加Gson依赖且依赖华为支付服务SDK后编译或运行时报Gson三方依赖包冲突，需要使用exclude排除Gson依赖冲突，代码如下：
   >
   > ```screen
   > implementation 'com.huawei.hms:paymentservice:6.12.0.300'{
   >     exclude group: 'com.google.code.gson'
   > }
   > ```
