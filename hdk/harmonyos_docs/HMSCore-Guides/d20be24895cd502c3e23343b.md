# 开通支付服务

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[账号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
> 注意
>
> 后续接入涉及AppId绑定，限制只能企业开发者接入。开发者注册后发起实名认证请选择为"企业开发者"认证类型，并且需要准备企业营业执照等必要材料。

## 创建应用

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。

## 生成签名证书指纹

签名证书指纹用于校验应用的真实性，开发者需要根据签名证书在本地生成签名证书指纹，并在应用上架前将签名证书指纹配置到AppGallery Connect。

在生成签名证书指纹前需要满足以下两个条件：

* 已创建应用程序的签名证书，签名证书创建请参见[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#2)。
* 当前PC已经安装[JDK](https://www.oracle.com/java/technologies/javase-downloads.html)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore C:\TestApp.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/59/v3/lB7btVoHQsKOWbdbtPvVOA/zh-cn_image_0000002512199845.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=B3C61C131ABD314A7A334A86DDC17D339AB454630080D8E8819AEF149AC45D5A "点击放大")

* macOS
  1. 打开Terminal终端。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/12/v3/OBVLpK3-Q9ClETIBMoBF2g/zh-cn_image_0000002480159964.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=1D0360F164DBE004C1CBACDC56A9A8ECB2CC6CFADE1B76360F3AC7BF5DCE05A1)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/admin/Downloads/HmsDemo.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/jmAyLxM_TGC3ueE74wneNg/zh-cn_image_0000002512279853.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=04E83FED7B5C72474DC410314F16488C77A1D4A52321685013D0DA03623C3A2B)

## 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到开发者的项目，在项目中点击需要配置签名证书指纹的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/aNa84zVXSm-R8F0nTKKxvg/zh-cn_image_0000002512279831.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=5A2A81AE45651BDAD62559A03C8A8D2CC1F385FE5E313A4D82D1BC845148A7D6)
   > 说明
   >
   > 在"项目设置"页面的"应用"区域，点击"Client Secret"后面的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/32/v3/RpwkSBY4Q_yrScL1dWsOfQ/zh-cn_image_0000002480159946.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=3A5A57686789B157B7178EA8F4FF282CD8AC8D41841E595682E5FF13423101A6)即可复制Client Secret。

4. 配置完成后，点击"保存"。

## 开通步骤

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择"我的项目"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/ZRI4K5HAQ4eseKs_zuwWDQ/zh-cn_image_0000002512279809.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=C319C01422D3033D81481EC0172D85652D4BD925C7F1177F701CEF454D7F80AC "点击放大")

2. 在项目列表中找到开发者的项目，在项目下的应用列表中选择需要开通华为支付服务的应用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/13/v3/G7dmkeutQQuTCEmI9R7FUQ/zh-cn_image_0000002512199867.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=1753523FFE807DE1C7F3AF68242A2745227A3C515CFD292C556DFC268644DFDE "点击放大")

3. 在左侧导航栏选择"盈利 > 鸿蒙支付服务（可在'全部功能'中搜索服务并固定到导航栏） > 支付服务（非虚拟类）> 立即开通"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3c/v3/Lt0mgdS4Quaim3_tjL-KEw/zh-cn_image_0000002480319906.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=69FE24D25FBE242EC0A4F94C7B267A4BD979A1449F45567FDF4E85EA4591CC08 "点击放大")

4. 开通服务后，开发者还需要点击"申请支付商户号"，如果已有商户号则忽略。详细介绍参考[华为支付商户入网](https://developer.huawei.com/consumer/cn/doc/pay-docs/hwzf-jieruliucheng-0000001251448455)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/Ky5AK98jQvagntiyKSgKuA/zh-cn_image_0000002512199887.png?HW-CC-KV=V1&HW-CC-Date=20260910T132630Z&HW-CC-Expire=31536000000&HW-CC-Sign=786C3B9DBD4D5806448372C365BD42358734C5741B358E8AF65F8E0C254DF52D "点击放大")

5. 申请商户号后，开发者还需要为商户号申请绑定AppID，详细参见[商户号绑定AppID](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/binding-appid-to-merc-0000001889931817#section2082462310406)，至此开发者已完成华为支付服务的开通准备工作。
