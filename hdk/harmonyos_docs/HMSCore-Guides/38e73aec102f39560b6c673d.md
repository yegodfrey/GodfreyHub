# 压力

此数据记录用户在某一刻的压力数据，每一条数据都代表该时刻的压力状态。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 压力数据

* 读权限：https://www.huawei.com/healthkit/stress.read
* 写权限：https://www.huawei.com/healthkit/stress.write

## 原子采样明细数据类型

* 名称：com.huawei.instantaneous.stress

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:-----------|:--------------------|:-----|:----|:-|:------------------------|
|score|压力得分|int|M|-|[1, 99]|
|grade|压力等级|int|M|-|取值如下： 1：放松 2：正常 3：中等 4：偏高|
|measure_type|主被动标志(用来区分主动测量还是被动测量)|int|O|-|取值如下： 1：主动 2：被动|
