# 集成SDK

## 添加当前应用的AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.plist"文件添加到您的应用中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要集成SDK的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"agconnect-services.plist"下载配置文件。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103221.15434914502651816139050681875930:50001231000000:2800:EA80E109D40EB66F6900D7E2470A70B9C2A74703C352D3AFD18774921763E41A.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 将"agconnect-services.plist"文件拷贝到应用级根目录下。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103221.58307449914410631675547639067798:50001231000000:2800:4F7DF8EDBBA66056129EB62C99DCBA873ECF29C4BC60AE1F3DC8616DBE6ACF44.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   > * 在获取"agconnect-services.plist"文件前，请确保已经完成定位服务的开通（开通步骤参见[开通定位服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ios-config-agc-0000001160509492#section121661823350)）。
   > * 如果您在"开发"模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等。您需要下载最新的"agconnect-services.plist"，并替换iOS项目根目录下已有的文件。

## 在Xcode项目中集成SDK（Cocoapods方式集成）

1. 首先要确保已经安装了Cocoapods。 说明
   >
   > 可通过终端输入指令：**pod --version**来确认Cocoapods是否安装成。
2. 在终端输入指令：**cd**，进入到项目的根目录下，如下所示：

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103221.39512556081899089961311259155219:50001231000000:2800:5F4D802F70996A267E5D52F454EC7794D598A5F789D6D654F686034C910C48C5.png?needInitFileName=true?needInitFileName=true "点击放大")
3. 接着在终端执行命令：**pod init**。
4. 执行成功后，会在项目的目录下生成Podfile文件，需要在此文件中添加以下内容：**pod 'HMSLocation', '~>1.1.0.300'**。
5. 终端执行命令：**pod install**。 说明
   >
   > 如果已经执行过**pod install** 命令，可以直接执行**pod update**命令。
6. 等待执行成功后，打开工程目录，找到.xcworkspace文件，用Xcode打开，运行工程。

## 在Xcode项目中集成SDK（手动方式集成）

1. 下载iOS Location SDK的包，并解压压缩包。

   下载地址：[iOS SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/ios-sdk-download-0000001206279307)。
2. 在Xcode工程内右键选择"Add file to 工程名"，随后左键去选择要导入的"framework"文件，点击"Add"即可完成SDK的添加。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103221.57332555171522073096448308021006:50001231000000:2800:07E4B4F2257C7CC7B694F2868CA46B20830F60AB85A685E21C0B2D6F3AD1E400.png?needInitFileName=true?needInitFileName=true "点击放大")
   > 说明
   >
   > 待导入的framework库必须和工作空间在相同的磁盘空间里。如果不在，您可以选择注意勾选"Copy items if needed"和"Create groups"，将待导入的framework库工程文件复制到工作空间。
