# 路线

HMapView提供了路线绘制功能，支持您自定义路线：

* 可根据路况设置路线分段，基于路线上的点索引设置分段，每个分段可以设置对应的分段样式，包括：填充色、描边色。
* 支持显示道路流向方向的箭头，可设置显示或不显示。
* 支持多条路线设置不同的样式（主、备选路线）。
* 支持路线点击事件。
* 支持路名显示。
* 支持路线动画：延展动画、透明动画。

#### 绘制路线

创建HRouteLine的配置对象类，调用HMapView(RouteLine)的addRouteLine:接口添加导航线。

```
HRouteLineOptions *options = [[HRouteLineOptions alloc]init];
NSInteger COUNT = 4;
CLLocationCoordinate2D naviArrowCoors[COUNT];
naviArrowCoors[0].latitude  = 36.0f;
naviArrowCoors[0].longitude = 116.0f;
naviArrowCoors[1].latitude  = 36.123;
naviArrowCoors[1].longitude = 116.0f;
naviArrowCoors[2].latitude  = 36.123;
naviArrowCoors[2].longitude = 116.123f;
naviArrowCoors[3].latitude  = 36.0f;
naviArrowCoors[3].longitude = 116.123f;
NSMutableArray *lineCoordsArr = [NSMutableArray array];
for (NSInteger i = 0; i < COUNT; i ++) {
    HLatLng *latLng = [[HLatLng alloc]initLatitude:naviArrowCoors[i].latitude withLongitude:naviArrowCoors[i].longitude];
    [lineCoordsArr addObject:latLng];
}
[options addWithPoints:lineCoordsArr];
self.routeLine = [self.mapView addRouteLine:options];
self.mapView.centerCoordinate = CLLocationCoordinate2DMake(36.123, 116.0f);
```

#### 设置路名

通过HRouteLine的setLabelsText方法设置路名。

```
[self.routeLine setLabelsText:@[@"text"] indexes:@[@0,@1] languageCode:@"CN" isClean:NO];
[self.routeLine setLabelsSize:20 refresh:YES];
[self.routeLine setLabelsColor:[UIColor redColor] refresh:YES];
```

#### 路线延展动画

创建HLineAnimation动画对象，将其添加到路线动画接口setAnimationWithAnimation:中，再调用startAnimation开启动画。

```
HLineExtendAnimation *animation = [[HLineExtendAnimation alloc] init];
animation.delegate = self;
animation.duration = 1500;
animation.timingFunction = [HTimingFunction timingFunctionWithName:@"linear"];
[self.routeLine setAnimationWithAnimation:animation];
[self.routeLine startAnimation];
```
