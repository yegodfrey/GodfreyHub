# 蓝牙协议标准

用户可以通过运动健康App 查看接入设备的特点、购买和绑定设备、测量及输入参数等。App 通过接口与外设连接并获取数据，当前支持使用蓝牙设备和非蓝牙设备。

## 设备接入标准

运动健康当前预置了四种标准蓝牙连接类型的健康设备，包括：体脂秤、血糖仪、血压计和心率设备。体温计、血氧仪使用的厂商私有蓝牙协议。

* 不同设备类型的蓝牙协议要求如下：

  |**设备类型**|**采集数据**|**蓝牙协议**|接入方式|
  |:-------|:----------|:-------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------|
  |心率设备|心率|[HRP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=239865)|Native（HRP）|
  |体脂秤|体重、体脂率。|[WSP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=293525)、私有协议|Native（WSP）、[H5（私有协议）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-h5-0000001058399933)|
  |血压计|收缩压、舒张压、脉搏。|[BLP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=243125&_ga=1.123872906.1469285867.1479213658)、私有协议|Native（BLP）、[H5（私有协议）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-h5-0000001058399933)|
  |血糖仪|血糖值|[GLP](https://www.bluetooth.org/docman/handlers/downloaddoc.ashx?doc_id=248025)、私有协议|Native（GLP）、[H5（私有协议）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-h5-0000001058399933)|
  |体温计|温度|私有协议|[H5（私有协议）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-h5-0000001058399933)|
  |血氧仪|血氧|私有协议|[H5（私有协议）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-h5-0000001058399933)|

  > 说明
  >
  > **标准蓝牙协议** ，参考：[https://www.bluetooth.com/specifications/adopted-specifications](https://www.bluetooth.com/specifications/adopted-specifications)。
* 若为非蓝牙设备，因为无法直接连接运动健康平台，需要将设备数据上传到合作伙伴的服务器上，再由其服务器通过运动健康平台云侧接口（IF2）将数据传到运动健康服务器。因此，合作伙伴需要开发App（或其它 UI）以支持用户输入华为账号并给予授权。其组网图如下： ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/qqChjKj7Q2erDgE7aanCiA/zh-cn_image_0000002548039773.png?HW-CC-KV=V1&HW-CC-Date=20260909T150303Z&HW-CC-Expire=31536000000&HW-CC-Sign=38D0B5FBB24786CEE69975ECDC57EA3F1A1C90651D3F5B2568A4F5E855BBAA04 "点击放大")

## 设备对接要求

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/9kPnRLl0Symll5D1KCZVrg/zh-cn_image_0000002547959775.png?HW-CC-KV=V1&HW-CC-Date=20260909T150303Z&HW-CC-Expire=31536000000&HW-CC-Sign=13F7F8342D8D2719E109695F7EA8CE85B64DFBAA32A0664CB87BDD4D9D0C86C5 "点击放大")

运动健康对接的每一款设备，都需要上传一个对应的资源包到华为服务器。用户在手机上运行运动健康App 时，会从服务器上下载对应的资源。下载完成后，用户即可绑定和使用设备。

上图中的（1. 资源文件） 和（2. 三方接入设备） 由三方设备厂商开发。
