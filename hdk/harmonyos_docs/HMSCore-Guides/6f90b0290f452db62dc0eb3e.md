# 业务简介

华为支付服务支持华为支付收银台能力，开发者的元服务通过集成华为支付服务 JS SDK，实现拉起华为支付服务收银台完成支付，并且用户可以在支付完成后选择完成免密代扣签约能力。

## 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:---|:---------------|:--------------|
|华为手机|HarmonyOS 2.0及以上|6.13.0.300及以上|
