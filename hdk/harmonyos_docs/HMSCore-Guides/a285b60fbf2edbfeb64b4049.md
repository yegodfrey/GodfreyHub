# 养车

分析服务支持汽车行业分析，可以清晰洞察应用的关键指标数值，从数据概览、车辆服务、购车销售分析和社区与售后等多维度了解汽车行业养车的具体情况，帮助制定精准的营销方案和产品策略。

## 典型应用场景

查看汽车类App数据上报情况，分析汽车行业数据价值。

## 前提条件

已在"智能数据接入 > 埋点开发"中配置了养车行业模板，配置模板方法详情请参见[埋点开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/tracing-point-development-0000001078556280)。

## 功能详述

### 案例

某汽车行业App想要查看近期奔驰车的销售及售后数据详情，以了解奔驰车整体情况以及热门车型有哪些，制定相应的促销计划。

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 行业分析"，进入"养车"分析界面。
4. 查看养车类App数据概览。详情请参见[数据概览](#section1739262775710)。
5. 查看养车类App服务及营收指标。详情请参见[车辆服务](#section1842322213818)、[购车销售分析](#section2155173663514)和[社区与售后](#section19141650597)。
