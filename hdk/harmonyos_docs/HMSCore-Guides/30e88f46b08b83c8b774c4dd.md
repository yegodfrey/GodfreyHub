# 相机扫码场景

#### 业务流程

使用Bitmap图片扫码的主要业务流程如下：  
![](https://media:301775707694203575 "点击放大")

1. 用户打开App发起扫码请求。
2. 校验是否有相机权限和相册读取权限。
3. 权限验证通过后，调用华为统一扫码SDK的[HmsBitMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsbitmap-0000001050429949)中"bitMapForSampleBuffer:"扫码接口。
4. 返回扫码结果。
5. 判断扫码结果是否有效，结果有效则返回扫码结果，结果无效则调整焦距后重新扫码。
6. App封装扫码结果返回给用户。  

#### 开发步骤

1. 获取相机一帧图像，即获得sampleBuffer。

   <br />

   ```
   // 得到相机采样数据sampleBuffer
   -(void)captureOutput:(AVCaptureOutput *)output didOutputSampleBuffer:(CMSampleBufferRef)sampleBuffer fromConnection:(AVCaptureConnection *)connection{
       // 此括号内添加步骤2、3中的示例代码，处理结束后需要注意数据的释放
   }
   ```

   <br />

2. （可选）根据实际需求创建扫码选项参数。

   <br />

   ```
   // QR_CODE | DATA_MATRIX表示只扫描QR和DataMatrix的码
   HmsScanOptions *options = [[HmsScanOptions alloc] initWithScanFormatType:QR_CODE | DATA_MATRIX];
   ```

   此处设置为QR_CODE ｜ DATA_MATRIX ，即适配QR码和DataMatrix的码。

   <br />

3. 调用[HmsBitMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsbitmap-0000001050429949)的类方法"bitMapForSampleBuffer: withOptions:"或"multiDecodeBitMapForSampleBuffer:"发起扫码请求并获取扫码结果JSON，其中包含信息请参见[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-parsing-result-codes-0000001050257274)。

   <br />

   ```
   // 获取单码结果
   NSDictionary *dic = [HmsBitMap bitMapForSampleBuffer:sampleBuffer withOptions:options];
   // 获取多码结果
   NSArray *list = [HmsBitMap multiDecodeBitMapForSampleBuffer:sampleBuffer withOptions:options];
   ```

   返回的值信息参见[Default View Mode](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-default-view-0000001050414343)。

   <br />
