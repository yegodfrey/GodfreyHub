# 业务介绍

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-|
|华为运动健康服务（HUAWEI Health Service Kit，简称Health Service Kit）是为华为生态应用打造的基于华为账号和用户授权的运动健康数据开放平台。在获取用户授权后，开发者可以使用华为运动健康服务提供的开放能力获取运动健康数据，基于多种类型数据构建运动健康领域应用与服务，为用户打造丰富、便捷、专业的运动健康场景体验。| |
| | |

#### 应用服务

优质应用服务联合三方设备，结合华为运动健康服务提供的运动健康数据服务，共同打造"智能运动健康设备+华为终端+应用服务"生态，为用户带来安全、智慧、便捷的运动健康体验。

服务包含华为应用及生态应用：

* 华为应用：
  * 华为运动健康 App为你提供专业的运动记录与减脂塑形等训练课程，结合科学睡眠及健康服务，让你跑得更快更远，变得更健康。
  * 智慧生活App是华为IoT智能设备统一管理平台，可以发现、连接和管理华为8+N智能产品，实现智能设备之间的互联互通，打造您专属的智慧场景，畅享美好生活。

<!-- -->

* 生态应用：运动\&健身、医疗研究、保险等生态应用基于华为智能运动健康设备+华为Health Service Kit数据平台，更易构建专业的场景化用户体验。  

#### HUAWEI Health Service Kit

如上图所示，华为运动健康开放平台提供了多种形式的开放能力，支持应用生态开放能力和设备接入开放能力。提供丰富的运动健康类的API，支持多种运动类型和健康数据的数据开放，如步数、体重、心率等。数据开放详情请参见[数据开放总览](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/data_description-0000001467889369)。

* 基础能力 ：原子化基础运动健康数据开放，例如步数、心率、睡眠等基础运动健康数据开放。
* 扩展能力：实时数据开放，同时包含了部分原子化基础数据开放。例如实时运动、实时心率等实时数据开放。
* 设备接入：支持合作伙伴的运动健康设备接入华为运动健康App，为硬件设备提供测量和上传数据的接口。
* 数据中心：提供数据平台，助力开发者存储运动和健康类的数据。
* 数据安全隐私合规：遵从适用的法律法规，对隐私进行管理。参考GAPP等业界优秀实践，进行个人数据全生命周期管理。  

#### 设备接入

面向运动和健康领域的智能设备开发者，华为运动健康服务提供Gym Profile和Wellness Profile，接入生态伙伴硬件产品，实现设备智能互联、数据同步、数据记录等科学运动和健康管理场景。Gym Profile和Wellness Profile采用标准蓝牙协议，经过用户主动绑定后，与生态伙伴的硬件产品建立安全的蓝牙传输通道进行数据传输。

开发者接入请参见[设备接入服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/health-app-note-0000001246201025)。  

#### 服务优势

#### 更全面：多种API开放，数据类型、标准更完善

* 支持多种数据类型的存储和获取，覆盖运动健康主流场景。
* 支持自定义数据类型，数据类型不设限。  

#### 更精准：数据更精准

依托华为可穿戴设备，提供高质量数据源。  

#### 更安全：遵循严格的隐私保护标准，并基于用户级密钥与芯片级加密，保障端、云数据存储安全

* 数据安全管理
  * 数据分类分级管理。
  * 设备侧、手机侧和云侧的深度协同安全机制。
  * 应用权限隔离管控。
  * 恶意应用禁用管理。

<!-- -->

* 用户授权管理
  * 支持主动授权和取消授权。
  * 数据读、写可分别授权。
  * 细分数据类型可单独授权。
* 隐私合规管理
  * 遵循全球各地的隐私法律要求，包括欧盟GDPR，对隐私进行管理。
  * 参考GAPP等业界优秀实践，进行个人数据全生命周期管理。
