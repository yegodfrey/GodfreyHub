# 通过Push更新实况窗通知

#### 场景介绍

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240423090413.58592860165431252747729987670612:50001231000000:2800:F8EA26DB52B47C7572B57F1A6B539E8DAD092A256968B12EBA096F04AC031AB6.png?needInitFileName=true?needInitFileName=true)

1、您需要先集成Push SDK，获取推送服务Token。

2、构建本地实况窗通知，并将本地实况窗通知的需要刷新的数据信息和Token上报到应用服务端。

3、应用服务端向Push Kit服务端发送实况窗通知刷新请求，更新实况窗通知内容。

#### 频控规则

通过Push Kit更新实况窗通知时，单个实况窗通知，出行打车与赛事比分场景每个设备每5分钟最多更新30次，每小时最多更新180次。其余场景每个设备每5分钟最多更新10次，每小时最多更新60次。超过频次部分将丢弃不下发。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240423090413.24978756801609990262217889342153:50001231000000:2800:FD566D84386C8A6028E572770F8ED062BEF1A2C4269FF4498DC11F9D5460B236.png?needInitFileName=true?needInitFileName=true)

    * 为了确保用户看到的内容是新的且有价值的，实况窗通知支持的最长不刷新时间为2小时，超过2小时未更新的实况窗通知，系统会认为通知结束
    * 原则上，所有实况窗通知的更新需要从Push Kit进行刷新，保证实况窗通知不依赖应用进程的存活。通过Push Kit的更新，实况窗通知完成在生命周期内正常的刷新和结束

#### 开发步骤

#### [h2]获取PushToken

您需要先接入Push SDK来获取PushToken，可参见[指导](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-client-dev-0000001050042041)完成代码的开发。

#### [h2]开通实况窗通知权限

发送实况窗通知前您需要开通对应的场景权限，可参见[指导](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-live-guide-right-0000001562619196)完成权限的申请。

#### [h2]创建本地实况窗通知

实况窗通知的创建，要求应用在前台运行，即用户实际使用应用并且产生了服务合约的情况下，才可以创建实况窗通知。

应用可以调用 NotificationManager notify 接口创建实况窗通知，开发者可以指定id和Notification对象。Id即为实况窗通知activityId，由开发者生成，在设备内要保持唯一，以免影响到实况窗通知的正确更新。如何构建实况窗通知可以参见[构建本地实况通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-live-guide-local-0000001613377893)。

实况窗通知创建成功后，建议您将activityId、实况窗通知场景event、push token以及业务服务相关的状态属性保存到您应用的服务端，当业务服务的用户订单状态发生变化时，通过Push Kit推送更新消息。

#### [h2]更新和结束实况窗通知

当用户的服务订单状态发生变化时，开发者可以调用Push Kit服务端开放的REST服务接口，更新或者结束实况窗通知。

详细接口请参考[实况窗通知刷新API](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rest-live-0000001562939968)。

#### [h2]详细示例

**创建本地实况窗通知**
    
    // 创建bundle保存实况窗通知信息 
    Bundle liveNotificationData = new Bundle(); 
    // 创建实况窗通知
    liveNotificationData.putInt("notification.live.operation", 0);         
    // 指定实况窗通知的应用场景为 出行打车
    liveNotificationData.putString("notification.live.event", "TAXI");     
    // 设置布局类型为强调文本模型           
    liveNotificationData.putInt("notification.live.type", 4);
    // 设置通知主标题，该值会覆盖setContentText方法设置的内容
    liveNotificationData.putCharSequence("notification.live.titleOverlay", "司机已到达");
    // 设置通知副文本，该值会覆盖setContentText方法设置的内容
    liveNotificationData.putCharSequence("notification.live.contentOverlay", "AITO M5新能源 | 曾师傅"); 
     
    // 创建bundle保存强调文本模板类型的实况窗通知所需的扩展参数 
    Bundle feature = new Bundle(); 
    // 设置扩展区标题
    feature.putString("notification.live.feature.titleText", "车牌号"); 
    // 设置扩展区内容
    feature.putString("notification.live.feature.contentText", "苏AD88888");
    // 设置扩展区内容下划线颜色
    feature.putString("notification.live.feature.underlineColor", "#FFFF6666"); 
    // 设置扩展区右侧描述图片，descPic图片文件为您自定义的图片，下图以汽车为例
    Picture descPic;
    feature.putParcelable("notification.live.feature.descPic", descPic); 
    
    // 将feature的bundle设置到实况窗通知参数liveNotificationData中
    liveNotificationData.putBundle("notification.live.feature", feature); 
    
    // 创建小图标
    Icon smallIcon;
    
    // 创建通知，调用addExtras添加实况窗通知
    Notification notification = new Notification.Builder(context, channelId) 
        .setContentTitle("test_title") 
        .setContentText("test_text") 
        .setSmallIcon(smallIcon)     
        .addExtras(liveNotificationData) 
        .build(); 
     
    // 发送通知 
    notificationManager.notify(1, notification);
