# 接入Skill说明

商家券接入Skill 是一套面向开发者/外部商户接入的能力，将"文档阅读"转化为"任务清单执行"，帮助开发者更快完成商家券全链路接入。

接入Skill能力可获得：

* 标准接入路径：商家券最小闭环，从创建批次到发放、核销、退券一步到位
* 三种券码模式全覆盖：随机Code、导入Code、指定Code，按场景精准路由
* 关键安全内置：签名规则、回调验签、私钥保护、幂等策略等红线控制
* 稳定性保障：SDK可用性验证闸门、字段契约校验、生产上线检查清单
* 排障提效：错误码速查、签名验签常见问题、回调幂等问题定位路径与修复建议

## 能力覆盖范围

### 支持券码模式

* 随机Code + 华为平台发放（HWPAY_MODE）
* 导入Code + 华为平台发放（MERCHANT_UPLOAD）
* 发放时指定Code + 商户平台发放（MERCHANT_API）

### 全链路操作

* 创建券批次、修改券批次预算、查询券批次详情
* 发放优惠券、核销优惠券、申请退券、使券失效
* 查询用户优惠券列表、查询单张优惠券详情
* 上传券预存Code、设置/查询回调通知地址

### 商户模型支持

直连商户、服务商、平台类商户

### 服务端接入

* Java SDK 接入与 HTTP 网关兜底方案
* 签名生成与回调验签实现

### 排障与质量保障

* 错误码速查（公共错误码 + 各接口专属错误码）
* 签名与验签常见问题
* 回调与幂等常见问题
* 券批次常见问题

## 在工具里触发Skill的使用

在对话中出现这些关键词时会更容易触发：

**商家券 、创建券批次、发放优惠券、核销、退券、券码、Code、回调验签、错误码**。

也可以直接这样提问以"强制触发"：

* 使用"huawei-merccoupon-integration"Skill，给出随机Code模式的最小闭环接入清单。
* 使用该 Skill 帮忙设计导入Code模式的发放流程，并给出验收点。
* 使用"huawei-merccoupon-integration" Skill，排查发券接口返回 CHECK_MERC_STATUS 的原因。

## 注意事项

### 安全红线

* 私钥严禁出现在客户端、日志、公共仓库或对话明文示例中
* 回调必须先验签再更新订单/券状态
* 不得跳过回调验签

### 接入规范

* 场景前置确认：必须先确认券码模式（随机Code / 导入Code / 指定Code），再进入后续接入
* 商户模型先行：涉及服务端接入时，必须先确认商户模型（直连商户 / 服务商 / 平台类商户）
* SDK 可用性验证：要求使用官方 SDK 时，必须先验证依赖可下载、关键类可见、关键 API 可确认；验证失败时降级为 HTTP 网关兜底
* orderStr / contractStr 必须由服务端生成，不得在客户端构造

### 上线前检查

* 验签逻辑必须通过真实回调验证，不得用 MOCK 验签替代
* 幂等策略必须完成压测验证
* 生产上线前务必完成回调地址配置与 HTTPS 校验
