# 操作流程

#### 创建版本

    1. 选择“工作区”页签，点击“创建版本”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/nqizlxfuS4ymc7hbH-wfbg/zh-cn_image_0000001131511380.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=7123C412F8F645AD20AAA4E24DCF1BB4E712210F03B7DA1D8A633B25FA8BEEF2)

    2. 在“创建版本”页面输入版本名称和描述后，选择“创建版本”或“创建并发布此版本”，点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/53/v3/_gi9JqdjQz2O1FxMYuSxtQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=C509159384ABA06B9562E04B4B51B998B7B115466330F46FAF1EA947D94BEB14)

若您需要在创建版本的同时，发布该版本，请选择“创建并发布此版本”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/97/v3/AsviaCxYQg-hj8ntOorM8g/zh-cn_image_0000001177510893.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=0F08D2F8E31C1A45D41CF2922348251DA3F89E4DD108C6C973BA0534DC8BBEDF)

    3. 若您选择“创建版本”，则系统跳转至“版本详情”页面，您可以查看已创建的版本详情。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/I54E7nzlQ2eHASGbjRHbiQ/zh-cn_image_0000001177550797.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=BD78CAE4AE4D2DD2A3D518C35CBD5B87FC3EB3B189732F033521E7498EAF3C09)

    4. 若您选择“创建并发布此版本”，则系统跳转至“版本详情”页面，且提示版本发布成功，您可以查看已创建的版本详情。

#### 预览草稿版本

在可视化埋点、代码、条件、变量或是分组中进行新建、修改或是删除操作后，您可以在“工作区”页面，点击“预览”，查看实时的配置信息，详情请参见[预览版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-version-management-operation-procedure-0000001090721853#section35141828537)。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/q1uaB1f-TG2o4jO23ZyTOA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=A364BCBE6DE343DA40441CF3368ADA9645A0FC9F1E39AFDE7E342510458A7B2E)

通过“工作区 > 预览”与“版本 > 版本详情 > 预览”的功能差异如下：

    * “工作区 > 预览”：您可以预览当前的草稿版本，即当前工作区内实时的配置信息。
    * “版本 > 版本详情 > 预览”：您可以预览当前创建的正式版本，预览内容仅为指定版本的配置信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b5/v3/iVa9sY37T46Dm9Ujkh8kjQ/zh-cn_image_0000001131517132.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=ED31767779ECF4E1AC848ACC66FB738E0B6C80007174A8D2E96E28AEF19B0867)

#### 变更

#### [h2]变更详情

    1. 在可视化埋点、代码、条件或变量中进行新建、修改或是删除操作后，您可以在“概览”页面中，看到变更记录。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/vMyKQIykS4OW9jna_VtsKQ/zh-cn_image_0000001077090008.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=3A9988BF3334DA956ABB65D84D1E5BACACB4EE7BB6EB1C044C9D367E19BB19C6)

    2. 点击“变更”栏下变更类型的名称进入“查看详情”页面，查看当前状态。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/pT1Pv7ixRzauImhCOsLyEw/zh-cn_image_0000001077249984.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=2E881174F7B27C066E7DAEE8D6E4A623C4E7888FBA2E5369CBE65963D13DD42C)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8b/v3/5-IgStu1Ss6I3TbkhW6gfA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=26CF5FB57587CC416BDF730C719C91641AC2CCB780B5A1B5CD5E35166DAABBD6)

若“更改”类型为“删除”，则不可点击。

#### [h2]查看变更

通过点击“查看变更”查看历史修改记录，即当前版本与当前草稿中变量、条件或是代码的差异性对比。

    1. 在“版本”中，点击“创建版本”，设置“版本名称”和“版本描述”，点击“保存”。
    2. 在“版本”中，选择所需版本，在“版本详情”页面，点击“发布”。
    3. 对已发布版本中，存在的可视化埋点、代码、条件或变量进行修改操作，修改完毕后选择“工作区 > 概览”，在该可视化埋点、代码、条件或变量名称的右边点击“查看变更”。
    4. 进入“查看变更”页面，通过比较“最新版本”和“当前草稿”，可以看到哪些内容进行了更改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/91/v3/XPw0ZA2xSMamC6kuOeB_zw/zh-cn_image_0000001089882973.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=EEDC07BA6169289CFE39A18B92B254199C263518F53977D50DBF6332DD91933E)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/BbQ7HxyKRCOc9uAeGXR27w/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=A84778136B36E2335D3B442A42BFD41948D46EBD992A69BE08737137AD9820B4)

若“更改”类型为“新增”或“删除”的预设变量，则没有查看变更的功能。

#### 操作记录

在可视化埋点、代码、条件、变量或是分组中进行新建、修改或是删除操作，然后点击“概览”页面，滑至操作记录，可以看到具体时间的操作行为。此外，您还可以将操作记录导出为Excel文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/JoAAGdJITL6jKcrz3S0bMA/zh-cn_image_0000001077426250.png?HW-CC-KV=V1&HW-CC-Date=20261005T052036Z&HW-CC-Expire=86400&HW-CC-Sign=0C72CA3EB38F66ADF21E998DFF57CFC9FBEF5048D191939F672CFB9CAEB02F17)
