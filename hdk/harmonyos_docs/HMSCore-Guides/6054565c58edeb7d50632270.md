# 功能描述

本章节主要介绍接入华为云空间服务的开发步骤，以帮助开发者快速了解华为云空间服务提供的服务端接口及其调用方法。请开发者参考"[业务介绍-场景介绍](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-0000001050039630#section1525481053)"，基于应用自身的使用场景，自行选择相应的开发章节。

Drive RESTful API提供的主要能力以及调用方法如下：

* [调用About.get()接口获取用户信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-obtaining-user-infomation-0000001064978930)。
* [调用Files接口进行文件管理和搜索](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-obtain-authentication_info-0000001064659348)。
* [调用Changes接口注册资源变化通知channel，开启文件变化通知功能](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-enable-notification-0000001064341112)。
* [调用Comments接口评论文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-comment-0000001063690791)。
* [调用Replies接口对评论进行回复](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-reply-0000001063779039)。
* [调用HistoryVersions接口查询文件历史版本。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-quaring-history-version-0000001064501116)
* [调用BatchCallback接口实现请求批处理。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-batch-operations-0000001063861197)
