# 自动比例尺

HuaweiMapEx提供了自动比例尺功能：在相机移动过程中，通过调整最佳比例尺，始终保持设置目标点在视野范围内。

自动比例尺接口初始化可设置：

* 设置一个目标点的经纬度。
* 设置相机在屏幕的位置。
* 设置控制区域四个点屏幕坐标。
* 设置最大最小比例尺。

支持过程更新：

* 相机位置更新。
* 最大最小比例尺更新。
* 四个点坐标更新。

示例代码如下：

```java
"Java"
// 开启比例尺缩放功能，默认false
hMapEx.setAutoZoom(true);
// 设置自动导航缩放层级范围
float minLevel = 3;
float maxLevel = 18;
hMapEx.setAutoZoomLevel(minLevel,maxLevel);
// 设置自动导航缩放控制区域
hMapEx.setAutoZoomControlArea(100,200,200,200);
// 设置自动导航缩放屏幕坐标
hMapEx.setAutoZoomCameraPosition(100,100);
```

```java
"Kotlin"
// 开启比例尺缩放功能，默认false
hMapEx.setAutoZoom(true)
// 设置自动导航缩放层级范围
val minLevel = 3f
val maxLevel = 18f
hMapEx.setAutoZoomLevel(minLevel, maxLevel)
// 设置自动导航缩放控制区域
hMapEx.setAutoZoomControlArea(100, 200, 200, 200)
// 设置自动导航缩放屏幕坐标
hMapEx.setAutoZoomCameraPosition(100, 100)
```
