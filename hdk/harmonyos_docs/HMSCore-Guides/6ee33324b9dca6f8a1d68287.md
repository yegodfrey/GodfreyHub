# 业务简介

导航服务（Navi Kit）以HTTP/HTTPS形式为开发者提供了API，您可以通过这些接口使用导航数据服务，用于开发路径规划等相关功能。在API被调用时，相关数据通过JSON格式返回。

服务使用前，需要您先[获取API key](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/preparations-0000001185174404#section169441820428)。

使用路径规划服务时，请确保您规划的路径所在国家均在路径规划所[支持的国家/地区](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/supported-countries-and-regions-0000001187087820)内。
