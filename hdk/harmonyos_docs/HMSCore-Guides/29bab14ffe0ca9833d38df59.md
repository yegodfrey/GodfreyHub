# 匹克球

匹克球运动记录类型如下：  

|运动类型|描述|运动类型常量|数据来源|
|:----------|:--|:-----|:----|
|pickle_ball|匹克球|162|手表、手环|

#### 专业运动特征统计数据

匹克球运动特征统计数据类型：com.huawei.activity.feature.pickleball  

|字段列表|字段描述|类型|可选/必选|单位|取值范围|
|:-----------------|:-----|:--|:----|:----|:----------|
|maxContinuousRally|最大连拍|int|O|次|\[0,10000\]|
|swingTimes|挥拍|int|O|次|\[0,20000\]|
|forehandBackspin|正手削球|int|O|次|\[0,10000\]|
|backhandBackspin|反手削球|int|O|次|\[0,10000\]|
|forehandVolley|正手截击|int|O|次|\[0,10000\]|
|backhandVolley|反手截击|int|O|次|\[0,10000\]|
|forehand|正手击球|int|O|次|\[0,10000\]|
|backhand|反手击球|int|O|次|\[0,10000\]|
|forehandDrop|正手网前吊球|int|O|次|\[0,10000\]|
|forehandDrive|正手抽球|int|O|次|\[0,10000\]|
|backhandDrop|反手网前吊球|int|O|次|\[0,10000\]|
|backhandDrive|反手抽球|int|O|次|\[0,10000\]|
|swingSpeed|挥拍速度|int|O|公里/小时|\[0,500\]|

#### 关联的采样统计数据类型说明

作为ActivityRecord概要数据的一部分，统一使用运动记录权限，无需每种关联的采样统计数据类型使用单独OAuth权限。  

|采样统计数据类型|描述|可选/必选|备注|
|:---------------------------------------------------|:-------|:----|:-----------------|
|com.huawei.continuous.calories.burnt.total|卡路里统计|M|-|
|com.huawei.continuous.exercise_heart_rate.statistics|运动心率统计|O|用户佩戴华为手表/手环时会包含该数据|
|com.huawei.resting_calories.statistics|静息代谢热量统计|O|-|

#### 关联的原子采样数据说明

关联的原子采样数据权限请参考[OAuth权限说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-fitness-record-data-0000001131831088#section27171294263)。  

|原子采样数据类型|描述|可选/必选|备注|
|:-------------------------------------------|:-----|:----|:-----------------|
|com.huawei.continuous.calories.burnt|热量详情|O|-|
|com.huawei.instantaneous.exercise_heart_rate|运动心率详情|O|用户佩戴华为手表/手环时会包含该数据|
|com.huawei.recovery_heart_rate|恢复心率详情|O|-|
