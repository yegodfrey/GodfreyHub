# 概要

Health Service Kit提供了一系列运动和健康数据类型，主要分三组：

* 原子采样数据类型
* 锻炼记录数据类型
* 健康记录数据类型

## 原子采样数据

Health Service Kit在com.huawei命名空间提供了一组公共的采样数据类型，包括：

* 日常活动
* 专业运动
* 健康采样

基于采样数据点呈现形式，主要分两大类：

* 原子采样明细数据类型
* 原子采样统计数据类型

大部分采样数据类型都包含原子采样明细数据类型和原子采样统计数据类型。

### 原子采样明细数据类型

数据采样点由数据类型字段的值和时间戳信息组成，表示瞬时采样获取的采样点数据类型，由数据采集器（如智能手环）采集的原始明细数据都是原子采样明细数据类型。

### 原子采样统计数据类型

数据采样点由数据类型字段的值、时间戳信息和一段时间间隔组成，表示一段时间间隔内获取的原子采样明细数据的统计值。

### 自定义采样数据类型

除了上述的原子采样明细数据类型和原子采样统计数据类型，Health Service Kit也支持新增自定义采样数据类型。
> 说明
>
> 创建的自定义采样数据类型不能使用Health Service Kit的命名空间，即不能使用"com.huawei"。如果包名以com.huawei开头，会和华为已有的数据类型冲突，导致无法创建自定义类型。
>
> 创建自定义数据类型时，必须以应用的包名开头。

**创建自定义数据**

通过创建具有自定义采样数据类型名称及字段的数据采集器（请参见[创建数据采集器](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacollectors_create-0000001050114852)），开发者可创建自定义数据类型。例如：

```screen
POST
https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors
Content-Type: application/json
Authorization: Bearer ***

{
  "collectorName": "DataCollectorExample",
  ...
  "collectorDataType": {
    "field": [
      {
        "name": "customizedField1",
        "format": "integer"
      },
     {
        "name": "customizedField2",
        "format": "float"
      }
    ],
    "name": "customized.datatypename"
  },
  ...
}
```

## 锻炼记录数据

用户一段持续时间的锻炼记录数据，由运动类型、应用信息、设备信息、开始结束时间、运动记录特征值、关联的原子采样统计数据、关联的原子采样明细数据等组成，如跑步、跳绳等锻炼记录。

锻炼记录数据总体介绍以及每个运动类型的详细介绍请参见[锻炼记录数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-fitness-record-data-0000001131831088)。

## 健康记录数据

用户一段持续时间的健康测量记录数据，由健康记录类型、数据采集器信息（应用信息、设备信息）、开始结束时间、健康记录特征值、关联的原子采样统计数据、关联原子采样明细数据等组成，如睡眠记录、ECG测量记录等，例如：com.huawei.health.record.sleep表示睡眠记录。

健康记录数据总体介绍以及每个健康记录类型的详细介绍请参见[健康记录数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ecg-measurement-record-0000001131831084)。

## 智能穿戴与华为运动健康App的数据开放

开发者应用可以通过Health Service Kit的开放能力获取到华为智能穿戴和华为运动健康App产生的运动和健康数据。

Android接入请参见[智能穿戴与华为运动健康App的数据开放](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-0000001147638696#section16817105517457)。

**限制条件**：

开发者需要引导用户开启华为运动健康App的数据通过Health Service Kit开放的授权开关，详细内容请参见[华为运动健康App开放授权示例](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/server-app-auth-example-0000001071757151)章节。

### 可开放的锻炼记录数据类型

开发者应用以ActivityRecord为载体获取到智能穿戴设备或运动健康App的运动记录数据。详细内容请参见[锻炼记录数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/introduction-fitness-record-data-0000001131831088)。

### 可开放的健康记录数据类型

开发者应用以HealthRecord为载体获取到智能穿戴设备或运动健康App的健康测量记录数据。详细内容请参见[健康记录数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ecg-measurement-record-0000001131831084)。

### 数据查询及时性说明

由于功耗等原因华为运动健康App数据不能实时上云，数据存在一定滞后性，详情请参见每个数据类型的数据查询及时性说明。
> 说明
>
> * 数据开放实时性时延是基于用户手机亮屏、保活（非华为手机需要用户手动设置保活状态）状态。
> * 用户可以打开华为运动健康App进行手动同步保障数据开放实时性。
