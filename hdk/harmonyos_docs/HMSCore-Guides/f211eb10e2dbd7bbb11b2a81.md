# 添加权限

1. 在调用Scan Kit时，您需要先在"AndroidManifest.xml"中指定相应的权限。

   <br />

   * 构建相机扫码功能，需要申请"CAMERA"（相机权限）。
   * 构建导入图片扫码功能，需要申请"READ_EXTERNAL_STORAGE"（文件读取权限）。

   ```
   <!--相机权限-->
   <uses-permission android:name="android.permission.CAMERA" />
   <!--文件读取权限，Android 12及更低版本申请-->
   <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
   <!--读存储（媒体和文件）权限，Android 13及更高版本申请-->
   <uses-permission android:name="android.permission.READ_MEDIA_IMAGES"/>
   <uses-permission android:name="android.permission.READ_MEDIA_VIDEO"/>
   <uses-permission android:name="android.permission.READ_MEDIA_AUDIO"/>
   ```

   <br />

2. 在"AndroidManifest.xml"中添加权限后，还需要在代码中动态申请权限。

   <br />

   ```
   "Java"
   // CAMERA_REQ_CODE为用户自定义，用于接收权限校验结果的请求码
   this.requestPermissions(new String[]{Manifest.permission.CAMERA, Manifest.permission.READ_EXTERNAL_STORAGE}, CAMERA_REQ_CODE);
   ```

   ```
   "Kotlin"
   // CAMERA_REQ_CODE为用户自定义，用于接收权限校验结果的请求码
   ActivityCompat.requestPermissions(this,arrayOf(Manifest.permission.CAMERA, Manifest.permission.READ_EXTERNAL_STORAGE), CAMERA_REQ_CODE)
   ```

   <br />

3. 校验是否开启相应的权限，决定是否继续扫码。

   <br />

   ```
   "Java"
   // 实现“onRequestPermissionsResult”函数接收校验权限结果
   final int PERMISSIONS_LENGTH = 2;
   @Override
   public void onRequestPermissionsResult(int requestCode, String[] permissions, int[] grantResults) {
       // 判断“requestCode”是否为申请权限时设置请求码CAMERA_REQ_CODE，然后校验权限开启状态
       if (requestCode == CAMERA_REQ_CODE && grantResults.length == PERMISSIONS_LENGTH && grantResults[0] == PackageManager.PERMISSION_GRANTED && grantResults[1] == PackageManager.PERMISSION_GRANTED) {
           // 调用扫码接口，构建扫码能力
           ...
       }
   }
   ```

   ```
   "Kotlin"
   val PERMISSIONS_LENGTH = 2
   // 实现“onRequestPermissionsResult”函数接收校验权限结果
   override fun onRequestPermissionsResult(requestCode:Int,permissions:Array<out String>, grantResults:IntArray) {
       // 判断“requestCode”是否为申请权限时设置请求码CAMERA_REQ_CODE，然后校验权限开启状态
       if (requestCode == CAMERA_REQ_CODE && grantResults.size == PERMISSIONS_LENGTH && grantResults[0] == PackageManager.PERMISSION_GRANTED && grantResults[1] == PackageManager.PERMISSION_GRANTED) {
           // 调用扫码接口，构建扫码能力
           ...
       }
   }
   ```

为满足最小权限和场景化触发要求，在Default View Mode场景权限申请建议如下：

1. 在调用Scan Kit时，您需要先在"AndroidManifest.xml"中指定相应的权限。

   <br />

   * 构建相机扫码功能，需要申请"CAMERA"（相机权限）。
   * 构建导入图片扫码功能，需要申请"READ_EXTERNAL_STORAGE"（文件读取权限）。

   ```
   <!--相机权限-->
   <uses-permission android:name="android.permission.CAMERA" />
   <!--文件读取权限-->
   <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
   ```

   <br />

2. 在"AndroidManifest.xml"中添加权限后，还需要在代码中动态申请权限相机权限。

   <br />

   ```
   "Java"
   // CAMERA_REQ_CODE为用户自定义，用于接收权限校验结果的请求码
   this.requestPermissions(new String[]{Manifest.permission.CAMERA}, CAMERA_REQ_CODE);
   ```

   ```
   "Kotlin"
   // CAMERA_REQ_CODE为用户自定义，用于接收权限校验结果的请求码
   ActivityCompat.requestPermissions(this,arrayOf(Manifest.permission.CAMERA), CAMERA_REQ_CODE)
   ```

   <br />

3. 开启错误回调及监听。

   <br />

   ```
   "Java"
   public int REQUEST_CODE_SCAN = 0X012;
   HmsScanAnalyzerOptions options = new HmsScanAnalyzerOptions.Creator().setErrorCheck(true).create();
   ScanUtil.startScan(this, REQUEST_CODE_SCAN, options);
   ```

   ```
   "Kotlin"
   val REQUEST_CODE_SCAN = 0x012
   val options = HmsScanAnalyzerOptions.Creator().setErrorCheck(true).create()
   ScanUtil.startScan(this, REQUEST_CODE_SCAN , options)
   ```

   自2.12.0.300版本起，相机扫码功能需要开启相机权限才能正常使用，图片扫码功能不受此权限限制。因此建议您配置相机权限设置引导页面便于用户点击跳转设置相机权限。请注意，后续的步骤5中无需校验相机权限。

   ```
   "Java"
   public int REQUEST_CODE_SCAN = 0X012;
   HmsScanAnalyzerOptions options = new HmsScanAnalyzerOptions.Creator().setShowGuide(true).create();
   ```

   ```
   "Kotlin"
   val REQUEST_CODE_SCAN = 0x012
   val options = HmsScanAnalyzerOptions.Creator().setShowGuide(true).create()
   ```

   <br />

4. 进入扫码界面用户点击相册后，Scan Kit会检测文件读取权限，若无权限，返回错误码[ERROR_NO_READ_PERMISSION](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/scan-scanutil4-0000001050167699#section0648345102710)。再申请文件读取权限。

   <br />

   ```
   "Java"
   protected void onActivityResult(int requestCode, int resultCode, Intent data) {
       super.onActivityResult(requestCode, resultCode, data);
       if (resultCode == RESULT_OK && requestCode == REQUEST_CODE_SCAN && data != null) {
           int errorCode = data.getIntExtra(ScanUtil.RESULT_CODE, ScanUtil.SUCCESS);
           if (errorCode == ScanUtil.ERROR_NO_READ_PERMISSION) {
                this.requestPermissions(new String[]{Manifest.permission.READ_EXTERNAL_STORAGE}, STORAGE_REQ_CODE);
           }
       }
   }
   ```

   ```
   "Kotlin"
   override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
       super.onActivityResult(requestCode, resultCode, data)
       if (resultCode == RESULT_OK && requestCode == REQUEST_CODE_SCAN && data != null) {
           val errorCode: Int = data.getIntExtra(ScanUtil.RESULT_CODE, ScanUtil.SUCCESS)
           if (errorCode == ScanUtil.ERROR_NO_READ_PERMISSION) {
               requestPermissions(
                   arrayOf(Manifest.permission.READ_EXTERNAL_STORAGE),
                   STORAGE_REQ_CODE
               )
           }
       }
   }
   ```

   <br />

5. 校验是否开启相机、相册的权限，决定是否继续扫码。

   <br />

   ```
   "Java"
   // 实现“onRequestPermissionsResult”函数接收校验权限结果
   final int PERMISSIONS_LENGTH = 1;
   @Override
   public void onRequestPermissionsResult(int requestCode, String[] permissions, int[] grantResults) {
       // 判断“requestCode”是否为申请权限时设置请求码CAMERA_REQ_CODE，然后校验权限开启状态
       if (requestCode == CAMERA_REQ_CODE && grantResults.length == PERMISSIONS_LENGTH && grantResults[0] == PackageManager.PERMISSION_GRANTED) {
           // 调用扫码接口，构建扫码能力
           ...
       }
       // 判断“requestCode”是否为申请权限时设置请求码STORAGE_REQ_CODE，然后校验权限开启状态
       if (requestCode == STORAGE_REQ_CODE&& grantResults.length == PERMISSIONS_LENGTH && grantResults[0] == PackageManager.PERMISSION_GRANTED) {
           // 调用扫码接口，构建扫码能力
           ...
       }
   }
   ```

   ```

           ...

           // 调用扫码接口，构建扫码能力
           ...
       }
   }
   ```
