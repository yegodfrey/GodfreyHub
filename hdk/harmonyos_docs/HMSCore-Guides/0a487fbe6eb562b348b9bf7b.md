# 贴片广告

贴片广告是一种在视频播放前、视频播放中或视频播放结束后插入的视频或图片广告。

![](https://media:201785910048968868 "点击放大")  

#### 添加贴片广告

1. 创建InstreamAdLoader。

   <br />

   [InstreamAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamadloader-0000001058104175)类提供了[InstreamAdLoader.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamadloader-builder-0000001058222271)类，可用于设置广告位ID、设置自定义选项和创建[InstreamAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamadloader-0000001058104175)对象。示例代码如下所示：

   ```
   "Java"
   // "testy3cglm3pj0"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID
   InstreamAdLoader.Builder builder = new InstreamAdLoader.Builder(context, "testy3cglm3pj0");
   // 设置贴片最大时长
   InstreamAdLoader adLoader = builder.setTotalDuration(totalDuration)
       // 设置贴片返回的最大数量
       .setMaxCount(maxCount)
       .setInstreamAdLoadListener(new InstreamAdLoadListener() {
           @Override
           public void onAdLoaded(List<InstreamAd> ads) {
               // 广告加载成功后调用
               ...
           }

           @Override
           public void onAdFailed(int errorCode) {
               // 广告加载失败后调用
               ...
           }
       }).build();
   ```

   ```
   "Kotlin"
   // "testy3cglm3pj0"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID
   val builder = InstreamAdLoader.Builder (context, "testy3cglm3pj0")
   // 设置贴片最大时长
   adLoader = builder.setTotalDuration(totalDuration)
       // 设置贴片返回的最大数量
       .setMaxCount(maxCount)
       .setInstreamAdLoadListener(object : InstreamAdLoadListener {
           override fun onAdLoaded(ads: List<InstreamAd>) {
               // 广告加载成功后调用
               ...
           }

           override fun onAdFailed(i: Int) {
               // 广告加载失败后调用
               ...
           }
       }).build()
   ```

   * 当加载广告成功后，SDK会调用[InstreamAdLoadListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamadloadlistener-0000001057956181)监听器的onAdLoaded()方法返回的[InstreamAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamad-0000001057504229)对象列表。
   * 当加载广告失败后，SDK会调用[InstreamAdLoadListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamadloadlistener-0000001057956181)监听器的onAdFailed()方法。

   ![](https://media:201785910048997869)  
   * 您需要根据视频时长合理设置贴片的最大时长以及贴片的数量，鲸鸿动能平台会根据设置的最大时长和贴数返回合适数量的贴片广告。 比如设置最大时长60秒, 最大贴数8，则最多返回4贴15秒或2贴30秒的广告。设置最大时长120秒, 最大贴数4，则最多只会返回4贴总时长不会超过120秒的广告。

   * errorCode详情请参见[Android错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/android-error-code-0000001130129080)。

   <br />

2. 加载广告。

   <br />

   [InstreamAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamadloader-0000001058104175)提供loadAd()方法加载广告。  
   [AdParam](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-0000001050066827)是唯一的参数，示例代码如下所示：

   ```
   "Java"
   AdParam.Builder builder = new AdParam.Builder();
   // 可选 设置实时bidding广告位参数
   BiddingParam biddingParam = new BiddingParam();
   String slotId = "testy3cglm3pj0";
   builder.addBiddingParamMap(slotId, biddingParam);
   builder.setTMax(500);
   builder.setCur("币种字符列表");
   adLoader.loadAd(new AdParam.Builder().build());
   ```

   ```
   "Kotlin"
   adLoader!!.loadAd(AdParam.Builder().build())
   ```

   调用loadAd()后，SDK将对添加的监听器方法进行一次成功或失败的回调。  
   ![](https://media:201785910049050870)  
   再次使用[InstreamAdLoader](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamadloader-0000001058104175)加载广告前，请确保先前的请求已经完成。

   <br />

3. 展示贴片广告。

   <br />

   获取到广告后在监听器的回调方法中展示贴片广告，需要在每个广告视图的一角展示"为什么看到此广告"的图标"i"或者"不再显示该广告"的图标"x"，并且必须展示广告标识。

   以下是展示贴片广告的步骤：
   1. 定义贴片广告布局。 需要定义一个布局用于展示[InstreamAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamad-0000001057504229)列表中的广告素材。

      ```
      <RelativeLayout
          android:id="@+id/instream_ad_container"
          android:layout_width="match_parent"
          android:layout_height="200dp"
          android:visibility="gone">

          <!-- 贴片广告视图 -->
          <com.huawei.hms.ads.instreamad.InstreamView
              android:id="@+id/instream_view"
              android:layout_width="match_parent"
              android:layout_height="match_parent" />

          <!-- 跳过按钮视图 -->
          <TextView
              android:id="@+id/instream_skip"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              ...
              />

          <!-- 倒计时视图 -->
          <TextView
              android:id="@+id/instream_count_down"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              ...
              />

          <!-- 广告标识视图 -->
          <TextView
              android:id="@+id/instream_ad_flag"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              ...
              />

          <!-- 为什么展示此广告视图 -->
          <ImageView
              android:id="@+id/instream_why_this_ad"
              android:layout_width="14dp"
              android:layout_height="14dp"
              ...
              />

          <!-- 点击广告跳转按钮 -->
          <TextView
              android:id="@+id/instream_call_to_action"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              ...
              />
      </RelativeLayout>
      ```

      ![](https://media:201785910049134871)  
      您需要结合您的视频播放的布局来设计相应的贴片广告布局，如贴片广告布局的宽高及各个视图控件的展示位置。
   2. 注册广告到广告视图。  
      获取到[InstreamAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamad-0000001057504229)对象列表后，需要将广告注册到广告视图。示例代码如下所示：

      ```
      "Java"
      instreamView.setInstreamAds(ads);
      ```

      ```
      "Kotlin"
      instreamView!!.setInstreamAds(ads)
      ```

   3. 监听广告状态。  
      贴片广告提供了[InstreamMediaStateListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreammediastatelistener-0000001059221894)、[InstreamMediaChangeListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreammediachangelistener-0000001059061896)和[MediaMuteListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mediamutelistener-0000001058253897)来监听贴片广告状态。示例代码如下所示：

      ```
      "Java"
      instreamView.setInstreamMediaChangeListener(new InstreamMediaChangeListener(){
          @Override
          public void onSegmentMediaChange(InstreamAd ad) {
              // 广告媒体切换
              ...
          }
      });

      instreamView.setInstreamMediaStateListener(new InstreamMediaStateListener() {
          @Override
          public void onMediaProgress(int percent, int playTime) {
              // 播放过程
              ...
          }

          @Override
          public void onMediaStart(int playTime) {
              // 播放开始
              ...
          }

          @Override
          public void onMediaPause(int playTime) {
              // 播放暂停
              ...
          }

          @Override
          public void onMediaStop(int playTime) {
              // 播放停止
              ...
          }

          @Override
          public void onMediaCompletion(int playTime) {
              // 播放完成
              ...
          }

          @Override
          public void onMediaError(int playTime, int errorCode, int extra) {
              // 播放错误
              ...
          }
      });

      instreamView.setMediaMuteListener(new MediaMuteListener() {
          @Override
          public void onMute() {
              // 贴片广告静音
              ...
          }

          @Override
          public void onUnmute() {
              // 贴片广告取消静音
              ...
          }
      });
      ```

      ```
      "Kotlin"

              // 广告媒体切换
              ...
      })

      instreamView!!.setInstreamMediaStateListener(object : InstreamMediaStateListener {
          override fun onMediaProgress(i: Int, i1: Int) {
              // 播放过程

              ...
          }

      instreamView!!.setMediaMuteListener(object : MediaMuteListener {
          override fun onMute() {
              // 贴片广告静音
              ...
          }

              // 贴片广告取消静音
              ...

      ```

   <br />

4. 销毁广告。

   <br />

   当贴片广告展示结束时，应使用[destroy()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/instreamview-0000001058373851#ZH-CN_TOPIC_0000001058373851__p872695617110)方法将贴片广告视图销毁。示例代码如下所示：

   ```
   "Java"
   instreamView.destroy();
   ```

   ```
   "Kotlin"
   instreamView!!.destroy()
   ```

   <br />

#### 展示广告主信息

当贴片广告下发广告主信息时，需要渲染广告主信息图标，用户点击图标时，调用SDK接口，展示广告主信息弹框。  
示例代码：

```
"Java"
// advertiserIcon为媒体自渲染的广告主信息图标
...
advertiserIcon.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        if (instreamAd.hasAdvertiserInfo()) {
            instreamView.showAdvertiserInfoDialog(advertiserIcon, true); 
        }
    }
});
...

// 贴片广告切换时，判断是否下发广告主信息，未下发时，隐藏渲染的广告主信息弹框 
instreamView.setInstreamMediaChangeListener(new InstreamMediaChangeListener() {
    @Override
    public void onSegmentMediaChange(InstreamAd ad) {
        Log.i(TAG, "onSegmentMediaChange");
        if (null != ad && !ad.hasAdvertiserInfo()) {
            advertiserIcon.setVisibility(View.GONE); // 当前广告未下发广告主信息，需要隐藏广告主信息图标
        }
    }
});
```

```
"Kotlin"
// advertiserIcon为媒体自渲染的广告主信息图标
...
advertiserIcon.setOnClickListener(View.OnClickListener {
            if (instreamAd.hasAdvertiserInfo()) {
                instreamView.showAdvertiserInfoDialog(advertiserIcon, true)
            }
        })

        instreamView!!.setInstreamMediaChangeListener { ad ->
            Log.i(FragmentActivity.TAG, "onSegmentMediaChange")
            if (null != ad && !ad.hasAdvertiserInfo()) {
                advertiserIcon.setVisibility(View.GONE) // 当前广告未下发广告主信息，需要隐藏广告主信息图标
            }
        }
```

#### 测试贴片广告

测试贴片广告时，需要使用专门的测试广告位ID来获取测试广告，以避免在测试过程中产生无效的广告点击量。

测试广告位ID仅作为功能调试使用，不可用于广告变现。您应在应用发布前先进入[流量变现官网](https://developer.huawei.com/consumer/cn/monetize)，点击"开始变现"，登录[鲸鸿动能媒体服务平台](https://developer.huawei.com/consumer/cn/service/ads/publisher/html/index.html?lang=zh)，申请正式的广告位ID并替换测试广告位ID，具体操作详情请参见[展示位创建](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/zhanshiweichuangjian-0000001132700049)。

以下表格中提供了贴片广告的专用测试广告位ID：  

|广告形式|展示形式|尺寸（宽\*高，以px为单位）|测试广告位ID|
|:---|:----|:--------------|:-------------|
|贴片广告|图片或视频|640\*360|testy3cglm3pj0|

下载贴片广告的[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-0000001050066947)并运行，可以看到如下效果图：
