# 跑步课程导入

本章节提供通过华为运动健康服务的REST API写入用户自定义跑步课程的方法示例。

* 跑步课程导入对应的Scope权限为：https://www.huawei.com/healthkit/healthplan.write。

* 联盟卡片申请的权限名称：健康管理 \>计划和任务数据。

#### DeepLink跳转运动健康App完成跑步课程自动导入

如果华为智能穿戴设备支持自定义课程，并已与运动健康App绑定，那么开发者可通过该方法跳转到运动健康App自定义课程的详情页面，并实现跑步课程自动下发到该设备；

如果华为智能穿戴设备不支持自定义课程，或者设备未与运动健康App绑定，那么将会跳转到华为运动健康App中的我的跑步课程-自定义TAB页，无法实现跑步课程自动下发到设备。

Android跳转说明：

当[获取华为运动健康App版本号](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/route-import-0000001232362165#section0140355121911)返回的versionCode不低于1300002300 时，可使用DeepLink跳转功能。

参数说明  

|跳转类型|跳转地目的地|目标类型|跳转地址|跳转参数|是否必填|参数类型|跳转参数说明|
|:-------|:----------------------|:-------|:-----------------------------------|:--------|:---|:-----|:--------------------|
|DeepLink|运动健康App-跑步课程功能导入到智能穿戴设备|Activity|huaweischeme://healthapp/fitnesspage|skip_type|是|String|填写固定值："custom_course"|
|DeepLink|运动健康App-跑步课程功能导入到智能穿戴设备|Activity|huaweischeme://healthapp/fitnesspage|version|是|long|2.0|
|DeepLink|运动健康App-跑步课程功能导入到智能穿戴设备|Activity|huaweischeme://healthapp/fitnesspage|id|是|long|跑步课程导入时返回的ID|

示例代码

```
String deeplink = "huaweischeme://healthapp/fitnesspage?skip_type=custom_course&id=workoutId&version=2.0";           
Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse(deeplink));
intent.setFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP | Intent.FLAG_ACTIVITY_SINGLE_TOP);
startActivity(intent);
```
