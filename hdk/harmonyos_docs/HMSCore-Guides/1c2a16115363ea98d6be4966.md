# 最大摄氧量

此数据记录用户的最大摄氧量，每一条数据都代表在一定时间的最大摄氧量。每条数据不能存在交叉，后一条数据的开始时间应该大于前一条数据的结束时间。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 肺功能数据

* 读权限：https://www.huawei.com/healthkit/pulmonary.read
* 写权限：暂不支持

## 原子采样明细数据类型

* 名称：com.huawei.vo2max

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:-------|:----|:-----|:----|:-------|:---|
|vo2max|最大摄氧量|int|M|毫升/公斤/分钟|-|
