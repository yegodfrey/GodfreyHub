# 应用开发

#### 获取Push Token

Token是推送令牌，每个设备上的每个应用的Token都是唯一存在的，客户端调用[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-push-ohos-hmsinstanceid-0000001199553039#section1427213359368)方法向Push服务端请求应用的Token，您可以根据Push服务端返回的Token向应用推送消息。当[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-push-ohos-hmsinstanceid-0000001199553039#section1427213359368)方法返回为空时，可通过[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-push-ohos-hmsmessageservice-0000001153713354#section1633639113715)方法获取Token值。

建议将Push Token上报到您自己的应用服务器，并定时更新Token列表。您可以调用[下行消息API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-server-dev-0000001050040110)，根据这些Token批量推送消息。

1. 创建一个新的线程，并调用getToken方法获取Push Token（建议在应用启动后的首个Ability中调用getToken方法）。

   <br />

   ```
   public class TokenAbilitySlice extends AbilitySlice {
       private static final HiLogLabel LABEL_LOG = new HiLogLabel(HiLog.LOG_APP, 0xD001234, 
   "TokenAbilitySlice");
       private void getToken() {
           // 创建新线程
           new Thread("getToken") {
               @Override
               public void run() {
                   try {
                       // 从agconnect-services.json文件中读取"client_id"
                       String appId = "your client_id";
                       // 输入token标识"HCM"
                       String tokenScope = "HCM";
                       // 获取Push Token
                       String token = HmsInstanceId.getInstance(getAbility().getAbilityPackage(), TokenAbilitySlice.this).getToken(appId, tokenScope);
                   } catch (ApiException e) {
                       // 获取Push Token失败时，打印错误码
                       HiLog.error(LABEL_LOG, "get token failed, the error code is %{public}d", e.getStatusCode());
                   }
               }
           }.start();
       }
   }
   ```

   <br />

2. 在您的service（[已继承HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-sdk-0000001182089480#section102146213408)）中，覆写onNewToken方法，当Token发生变化时以[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-push-ohos-hmsmessageservice-0000001153713354#section1633639113715)方法返回。

   <br />

   ```
   public class DemoHmsMessageServiceAbility extends HmsMessageService {
       private static final HiLogLabel LABEL_LOG = new HiLogLabel(HiLog.LOG_APP, 0xD001234, "DemoHmsMessageServiceAbility");

       @Override
       // 获取Token
       public void onNewToken(String token) {
           HiLog.info(LABEL_LOG, "onNewToken called, get token");
       }

       @Override
       // 获取Token失败，打印错误码
       public void onTokenError(Exception exception) {
           HiLog.error(LABEL_LOG, "get onNewToken error, error code is %{public}d", ((ZBaseException)exception).getErrorCode());
       }
   }
   ```

   <br />

#### 获取透传消息数据

在您的service（[已继承HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmony-java-sdk-0000001182089480#section102146213408)）中，覆写[onMessageReceived](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-push-ohos-hmsmessageservice-0000001153713354#section13971729152013)方法，只要您发送透传消息至终端设备，都会获得透传消息的内容。

```
public class DemoHmsMessageServiceAbility extends HmsMessageService {
    private static final HiLogLabel LABEL_LOG = new HiLogLabel(HiLog.LOG_APP, 0xD001234, 
"DemoHmsMessageServiceAbility");
    @Override
    public void onMessageReceived(ZRemoteMessage message) {
        // 打印消息的内容字段
        HiLog.info(LABEL_LOG, "get data, %{public}s", message.getData());

        ZRemoteMessage.Notification notification = message.getNotification();
        if (notification != null) {
            HiLog.info(LABEL_LOG, "get title, %{public}s", notification.getTitle());
            HiLog.info(LABEL_LOG, "get body, %{public}s", notification.getBody());
        }
    }
}
```

#### 发送消息

* 您可以登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站发送消息，详情请参见[HarmonyOS应用推送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-harmony-0000001233498031)。
* 您可以使用服务端API向应用推送消息：

   * 使用[OAuth 2.0开放鉴权（客户端模式）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/oauth2-0000001212610981#section128682386159)方式时，客户端ID和客户端密钥请输入您在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)项目下的HarmonyOS应用里的OAuth 2.0客户端ID（凭据）中的Client ID和Client Secret；获取的 Access Token 在有效期（expires_in）内可以多次使用，请勿过于频繁请求，否则可能会被流控（当前应用级Access Token的流控阈值为1000个/5分钟，5分钟内申请Access Token超过1000个，后续将提示被流控，无法申请。5分钟后重置，可以再次申请）。

#### 自定义点击消息动作

您可以自定义点击通知栏消息的动作，例如：打开应用首页、打开网页URL和打开应用自定义页面。  

#### 打开App首页

* 您可以通过[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)推送消息，设置点击通知动作为[打开应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-harmony-0000001233498031#ZH-CN_TOPIC_0000001700850813__p8271141442717)、App页面为[首页](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-harmony-0000001233498031#ZH-CN_TOPIC_0000001700850813__li6693172810350)。
* 您可以通过服务端API推送消息：  
  消息体中携带[click_action](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p12319118122313)字段，[type](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p732115812310)取值为3表示点击消息后打开应用首页。

  ```
  {
      "validate_only": false,
      "message": {
          "android": {
              "notification": {
                  "title": "test title",
                  "body": "test body",
                  "click_action": {
                      "type": 3
                  }
              }

      }
  ```

#### 打开应用自定义页面

配置action参数打开应用自定义页面：

1. 客户端应用先创建自定义页面（以"MyActionAbility"为例），在您项目的"entry/src/main"目录下的"config.json"文件中添加该Ability的skills字段。其中entities的值为"entity.system.default"不可改变，actions的值由您自定义（以"com.test.myaction"为例）。

   <br />

   ```

       "name": "com.test.java.MyActionAbility",
       "icon": "$media:icon",
       "description": "$string:myactionability_description",
       "label": "$string:entry_MyActionAbility",
       "type": "page",
       "launchType": "standard",
       "skills": [    
           {
               "entities": ["entity.system.default"],
               "actions": ["com.test.myaction"]    
           } 
       ]
   }
   ```

   <br />

2. 您可以通过[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)推送消息，设置点击通知动作为[打开应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-harmony-0000001233498031#ZH-CN_TOPIC_0000001700850813__p8271141442717)、App页面为[自定义action页面](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-harmony-0000001233498031#ZH-CN_TOPIC_0000001700850813__li19693202811358)（action请输入上一步中定义的actions的值）。

#### 传递数据

您推送消息时可携带[data](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p71649524449)字段，当用户点击消息时通过下述方法将data中的数据传递至客户端应用。

1. 推送消息时携带data字段：

   <br />

   * 通过[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)推送消息且设置[自定义键值对](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-harmony-0000001233498031#ZH-CN_TOPIC_0000001700850813__p344918178273)。
   * 通过服务端API推送消息，消息体中携带[data](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p71649524449)字段。

     ```
     {
         "validate_only": false,
         "message": {
             "android": {
                 "notification": {
                     "title": "test title",
                     "body": "test body",
                     "click_action": {
                         "type": 1,
                         "action":"com.test.myaction"
                     }
                 },
                 "data": "{'key_data':'value_data'}"
             },
             "token": ["pushtoken1"]
         }
     }
     ```

   <br />

2. 在客户端应用开发点击消息跳转的页面获取data字段的功能，此处以点击消息跳转到应用首页（MainAbilitySlice）获取data字段为例。

   <br />

   ```
   public class MainAbilitySlice extends AbilitySlice {
       private static final HiLogLabel LABEL_LOG = new HiLogLabel(HiLog.LOG_APP, 0xD001234, "myDemo");
       @Override    
       public void onStart(Intent intent) {        
           HiLog.info(LABEL_LOG, "MainAbilitySlice get started...");
           super.onStart(intent);
           super.setUIContent(ResourceTable.Layout_ability_main);
           // 调用解析方法
           parseIntent(intent);
       }

       private void parseIntent(Intent intent){
           if (intent == null){return;}    
           IntentParams intentParams = intent.getParams();
           if (intentParams == null) {return;} 
           // 获取data字段中的键值对   
           String key = "key_data";    
           Object obj = intentParams.getParam(key);
           try{
               // 打印data字段中的键值对        
               HiLog.info(LABEL_LOG, "my key: %{public}s, my value: %{public}s", key, obj);    
           }catch (Exception e){
               HiLog.info(LABEL_LOG, "catch exception : " + e.getMessage());    
           }
       }
   }  
   ```

   <br />
