# 地图类型

[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)目前支持四种地图类型，您可以通过mapType属性或setMapType方法设置地图类型：

* ROADMAP：基础地图。展示默认的路网图。支持地图预置样式：standard（默认）、simple、night。
* TERRAIN：地形图。显示地形栅格效果。仅支持standard地图预置样式。
* SATELLITE：卫星图。仅显示卫星图。
* HYBRID：混合地图。在卫星图的基础上显示道路、POI等地图元素。

当sourceType与mapType属性同时设置时，mapType优先级高于sourceType。可展示的地图效果有：  

|mapType（地图类型）\\sourceType（瓦片类型）|sourceType（vector）|sourceType（raster）|
|:------------------------------|:-----------------|:-----------------|
|mapType（ROADMAP）|矢量基础地图|栅格基础地图|
|mapType（TERRAIN）|栅格地形图|栅格地形图|
|mapType（SATELLITE）|栅格卫星图|栅格卫星图|
|mapType（HYBRID）|栅格卫星图+矢量地图元素|栅格卫星图+矢量地图元素|

实现地图类型的切换，支持以下两种方式：

* 调用HWMapJsSDK.[HWMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165)(div, mapOptions)创建地图时，通过[MapOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/js-hwmap-0000001050990165#section12313153115171)中的mapType属性改变地图类型。
* 调用setMapType方法改变地图类型。

示例代码如下：

```
"JavaScript"
<script>
    var map;
    var circle;
    function initMap() {
        var mapOptions = {};
        mapOptions.center = {lng: 4.372970736010767, lat: 44.88813186075487};
        mapOptions.zoom = 9;
        mapOptions.language = 'en';
        // 栅格瓦片
        mapOptions.sourceType = 'RASTER';
        // 方式一：修改mapType属性，切换地图类型（基础地图和地形图）
        mapOptions.mapType = 'ROADMAP';
        // mapOptions.mapType = 'TERRAIN';
        map = new HWMapJsSDK.HWMap(document.getElementById('map'), mapOptions);
    }
    
    function setMapType(){
        // 方式二：调用setMapType方法，切换地图类型为地形图
        map.setMapType('TERRAIN')
    }
</script>
```

```
"HTML"
<div id="map"></div>
<button onclick='setMapType()' class="mapType">setMapType</button>
```

```
"CSS"
<style>

</style>
```
