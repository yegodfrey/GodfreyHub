# 查询可玩状态（可选）

## 场景介绍

部分游戏因国家新闻出版署要求对玩家的年龄有特殊限制，游戏服务为您开放了查询某年龄段是否可玩功能。您申请开通权限后，可以调用接口查询对应年龄段玩家的可玩状态，进而控制玩家是否可以正常进入游戏。

## 权限申请

开通查询指定年龄段可玩状态查询功能，需发送邮件至[game.business@huawei.com](mailto:game.business@huawei.com)进行申请，请按照如下格式填写邮件。

|邮件标题|*应用名称*-申请开通查询指定年龄段可玩状态|
|----|-----------------------------------------------------------------------------------------------------------------------------------|
|邮件内容|APP ID：应用的唯一标识，参考[查看应用基本信息](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)获取。|
|邮件内容|申请查询的年龄段：[A, B） > 说明 > * 目前一个游戏只能申请一个年龄段。 > * 区间值[A, B)是指已满A岁但未满B岁。例如一款游戏国家新闻出版署要求16岁以下不能玩，您应该申请[0, 16)的区间，申请成功后调用接口华为将返回玩家是否可玩该游戏。|

## 注意事项

* 该功能当前仅支持发布地为中国大陆的联运游戏。
* 在接入该功能前，需要发邮件[申请权限](#section03606406114)，若权限不足将返回7026错误码。
* 必须在实现[游戏初始化](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-start-0000001050123475)和[游戏登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526)后再查询玩家的可玩状态，若在游戏登录前查询，未实名的用户会返回不可玩。
* 需集成Game Service SDK 6.5.0.300或以上版本。

## 开发步骤

查询可玩状态功能涉及的关键开发步骤如下：

1. 启动游戏，完成[游戏初始化](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-start-0000001050123475)和[游戏登录](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/game-login-0000001050121526)。

2-3. 调用[Games.getPlayersClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/games-0000001050121658#section023114101465)方法请求初始化[PlayersClient](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/playersclient-0000001050121668)实例。

```screen
PlayersClient client = Games.getPlayersClient(this);
```

4-5. 调用getUserPlayState获取当前玩家的可玩状态。

* 您需要在OnSuccessListener监听回调中判断，若可玩状态为Constant.USER_STATE_PLAYABLE，需要允许玩家游戏，否则禁止玩家游戏。
* 在OnFailureListener监听回调中判断回调的异常对象，若错误码为7026表示未开启权限，您需要先申请权限。其他错误请参考[错误码参考](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-error-0000001050994619)进行必要的错误场景处理。

  ```screen
  Task<Integer> playState = client.getUserPlayState();
  playState.addOnSuccessListener(new OnSuccessListener<Integer>() {
      @Override
      public void onSuccess(Integer canPlay) {
          if (Constant.USER_STATE_PLAYABLE == canPlay) {
              Log.i("PlayState", "user playable.");
          } else {
              Log.i("PlayState", "forbidden play.");
          }
      }
  }).addOnFailureListener(new OnFailureListener() {
      @Override
      public void onFailure(Exception e) {
          if (e instanceof ApiException) {
              int statusCode =  ((ApiException) e).getStatusCode();
              Log.e("PlayState", "statusCode: " + statusCode);
          }
      }
  });
  ```

6. 自行控制玩家是否可进入游戏。
