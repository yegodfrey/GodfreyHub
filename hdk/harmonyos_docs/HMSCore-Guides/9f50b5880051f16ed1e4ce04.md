# 概述

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/I96BmRIrSkurHXa1vca7kg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=3064DF27C5E0D8D0225CA8578C6EADE7C9F0B3F4B192D1BFDFE4732DF263B083)

自定义工作区暂时不支持可视化埋点及可视化埋点资源的相关操作，若您需要可视化埋点，请在默认工作区中进行。

在DTM页面通过可视化的方式添加埋点事件。您需确保所输入的网址已经正确集成“dtm.js”，集成方式请参见[配置脚本导入](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-client-dev-0000001051057565#section16189132217553)。

若您需要向HUAWEI Analytics上报事件，DTM支持从HUAWEI Analytics平台接入，创建埋点方案并对其埋点事件进行管理。为了使用行业化的埋点方案，提升埋点效率，推荐您优先使用该功能，详情请参见[按华为分析埋点方案操作流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-visual-event-tag-ha-0000001151584240)。

可视化埋点分为普通和按Tag模板埋点两种方式，若在Tag模板中有您需要的模板，推荐您优先采用按Tag模板可视化埋点的方式。按Tag模板可视化埋点可在添加埋点时创建Tag，较普通可视化埋点而言，节省了步骤，更为简洁、快捷、高效。

可视化埋点可分为同类元素埋点和非同类元素埋点两种。

                * 同类元素埋点：同类元素即选中元素的某一个就近的父节点内，存在结构或类名一致的元素。

选择同类元素埋点后，系统将自动圈选这些相同元素作为埋点。若需要添加参数，只能选择该埋点父节点下的参数，或直接输入常量。

                * 非同类元素埋点：每次只能圈选单个元素作为埋点。同类元素中的某个元素也可以被埋点为非同类元素埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/f5E9NXcyTNe1agw-D6v4zA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043142Z&HW-CC-Expire=86400&HW-CC-Sign=02F2FCA8E9FB3D8146AF6AEEA3A0D21250D1B42C8DFEAE62A34D12BEDACB4027)

本章节以非同类元素埋点操作进行说明。

当添加埋点或参数时，若出现以下错误提示，请参见[FAQ](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050169001)进行处理。

                * [埋点的选择器不合理，请重新选择埋点](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050169001#section7737111933)
                * [存在非当前埋点参数范围内的参数](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050169001#section16521183841116)
                * [不合法的css选择器](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/faq-0000001050169001#section66231550134115)
