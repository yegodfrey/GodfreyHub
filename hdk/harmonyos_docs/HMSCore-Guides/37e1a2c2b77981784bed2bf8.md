# 踢足球

踢足球运动记录类型如下：  

|运动类型|描述|运动类型常量|数据来源|
|:--------------|:--|:-----|:----|
|football.soccer|踢足球|23|手表、手环|

#### 专业运动特征统计数据

足球运动特征统计数据类型：com.huawei.activity.feature.football  

|字段列表|字段描述|类型|可选/必选|单位|取值范围|
|:-----------------|:-----|:----|:----|:----|:-----------------------------------------------------------------------------------------------------------------------------------------|
|jumpTimes|跳跃次数|int|O|次|\[0,10000\]|
|maxJumpHeight|最大跳跃高度|float|O|米|\[0，∞）|
|sprintTimes|冲刺次数|int|O|次|\[0,10000\]|
|maxAcceleration|最大加速度|float|O|公里/小时|\[0，∞）|
|turnSpeedUpTimes|转身加速次数|int|O|次|\[0,10000\]|
|swerveSpeedUpTimes|变向加速次数|int|O|次|\[0,10000\]|
|playerPosition|球员站位|int|O|NA|0：左前锋 1：前腰 2：球童 3：中场 4：中后卫 5：中锋 6：后腰 7：守门员 8：左后卫 9：左边卫 10：左前卫 11：左边锋 12：摄影师 13：裁判员 14：右后卫 15：右边卫 16：右前卫 17：右前锋 18：右边锋 19：影锋 20：替补球员 21：清道夫|
|goalsTimes|进球次数|int|O|次|\[0,10000\]|
|assistsTimes|助攻次数|int|O|次|\[0,10000\]|
|savesTimes|扑救次数|int|O|次|\[0,10000\]|

#### 关联的采样统计数据类型说明

作为ActivityRecord概要数据的一部分，统一使用运动记录权限，无需每种关联的采样统计数据类型使用单独OAuth权限。  

|采样统计数据类型|描述|可选/必选|备注|
|:---------------------------------------------------|:-------|:----|:-----------------|
|com.huawei.continuous.calories.burnt.total|卡路里统计|M|-|
|com.huawei.continuous.exercise_heart_rate.statistics|运动心率统计|O|用户佩戴华为手表/手环时会包含该数据|
|com.huawei.resting_calories.statistics|静息代谢热量统计|O|-|
|com.huawei.continuous.distance.total|距离统计|O|-|
