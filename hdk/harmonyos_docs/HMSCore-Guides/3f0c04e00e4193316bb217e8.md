# 激励广告

激励广告是一种全屏幕的视频广告，用户可以选择点击观看，以换取相应奖励。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/85SvravoQk-2N19eAQ4kwg/zh-cn_image_0000001056805205.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=6BF04BB404DBEB7AD70451EC2A1CB815A1902EF030B21B6CD089C3FB41EBE09F "点击放大")

## 添加激励广告

1. 通过[ppsads.createRewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-createrewardad-0000001179473259)创建广告对象。

   ```screen
   const rewardAd=ppsads.createRewardAd({
       slotId: "testx9dtjw8hp"
   });
   ```

2. 调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[load()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)加载广告，成功加载广告后再显示广告的播放入口。

   ```screen
   rewardAd.load();
   ```

   * 成功执行[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[load()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)回调：

     ```screen
     rewardAd.onLoad(() => {});
     ```

   * 失败执行[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[onError(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)回调：

     ```screen
     rewardAd.onError((errorCode) => {});
     ```

     > 说明
     >
     > errorCode详情请参见[JavaScript错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/error-code-0000001133633596)。
3. 调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[isLoaded()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)判断广告是否加载成功。

   ```screen
   if(rewardAd.isLoaded()) {};
   ```

4. 调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[show()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)展示广告。

   ```screen
   rewardAd.show();
   ```

5. 调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[onClose(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)监听激励视频广告的关闭。

   ```screen
   rewardAd.onClose(()=>{});
   ```

6. 调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[onReward(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)监听激励视频广告获取奖励。

   ```javascript
   rewardAd.onReward((rewardData)=>{
       // 执行获取奖励逻辑
   });
   ```

7. 调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[onShow(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)监听激励视频广告的展示。

   ```screen
   rewardAd.onShow(()=>{});
   ```

8. 调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[onComplete(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)监听激励视频广告的播放完成。

   ```screen
   rewardAd.onComplete(()=>{});
   ```

9. 当应用页面销毁时，调用[RewardAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265).[destroy()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rewardad-0000001179473265#section291922212588)销毁激励视频广告。

   ```screen
   rewardAd.destroy();
   ```

## 测试激励广告

测试激励广告时，需要使用专门的测试广告位ID来获取测试广告，以避免在测试过程中产生无效的广告点击量。测试广告位ID仅作为功能调试使用，不可用于广告变现。您应在应用发布前先进入[流量变现官网](https://developer.huawei.com/consumer/cn/monetize)，点击"开始变现"，登录[鲸鸿动能媒体服务平台](https://developer.huawei.com/consumer/cn/service/ads/publisher/html/index.html?lang=zh)，申请正式的广告位ID并替换测试广告位ID，具体操作详情请参见[展示位创建](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/zhanshiweichuangjian-0000001132700049)。

以下表格中提供了激励广告的专用测试广告位ID：

|广告形式|展示样式|测试广告位ID|
|:---|:---|:-------------|
|激励视频|视频|testx9dtjwj8hp|

具体实现可以参见[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-0000001050066947#section1798718513277)，运行示例代码可以看到如下效果图：
