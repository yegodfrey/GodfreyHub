# Default View Mode

Default View Mode提供相机扫码和导入图片扫码两个功能，提供完整的页面，不需要您开发扫码界面。

## 业务流程

使用Default View Mode的主要业务流程如下：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c7/v3/N82oM_4GQyq_tW7woNd2Bw/zh-cn_image_0000001627117261.png?HW-CC-KV=V1&HW-CC-Date=20260909T170105Z&HW-CC-Expire=31536000000&HW-CC-Sign=ADDAF57D528523FEC8AEE64543DBD73D88D4A574D37549FC67BC44E24FC748EE "点击放大")

1. 用户打开App发起扫码申请。
2. 校验是否有相机权限和相册读取权限。
3. 权限验证通过后，调用华为统一扫码SDK的[HmsDefaultScanViewController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsdefaultscanviewcontroller-0000001050189871)扫码接口，启动扫码界面。
4. 判断扫码页面启动状态。
5. 用户回调应用的"DefaultScanDelegate"代理，根据扫码状态获取扫码结果。
6. App封装扫码结果返回给用户。

## 开发步骤

1. 初始化[HmsDefaultScanViewController](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsdefaultscanviewcontroller-0000001050189871)，并将Default View加入到您的Controller布局中。

   ```objectc
   // 初始化HmsDefaultScanViewController，实现代理
   HmsDefaultScanViewController *hmsDefaultScanViewController = [[HmsDefaultScanViewController alloc] init];
   hmsDefaultScanViewController.defaultScanDelegate = self;
   [self.view addSubview:hmsDefaultScanViewController.view];
   [self addChildViewController:hmsDefaultScanViewController];
   [self didMoveToParentViewController:hmsDefaultScanViewController];
   // 隐藏导航栏
   self.navigationController.navigationBarHidden = YES;
   ```

2. （可选）根据实际需求创建扫码选项参数。

   Scan Kit默认支持[13种码制式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/barcode-formats-supported-0000001050043981)，您也可以指定Scan Kit只扫描特定的码制式以提高扫码速度。例如，当仅需要检测QR码和DataMatrix码时，请按照以下示例构建[initDefaultScanWithFormatType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsdefaultscanviewcontroller-0000001050189871#section159829542236)初始化方法。

   ```objectc
   // "QR_CODE | DATA_MATRIX"表示只扫描QR和DataMatrix的码
   HmsScanOptions *options = [[HmsScanOptions alloc] initWithScanFormatType:QR_CODE | DATA_MATRIX Photo:FALSE];
   HmsDefaultScanViewController *hmsDefaultScanViewController = [[HmsDefaultScanViewController alloc] initDefaultScanWithFormatType:options];
   ```

3. 用户可以使用相机扫码，也可以通过该页面的"相册"按钮检测图片中的码。
4. 实现Default View的代理方法。

   ```objectc
   - (void)defaultScanDelegateForDicResult:(NSDictionary *)resultDic{
     dispatch_asyns(dispatch_get_main_queue(), ^{
        // 在主线程内处理数据
     });
   }
   - (void)defaultScanImagePickerDelegateForImage:(UIImage *)image{
     dispatch_asyns(dispatch_get_main_queue(), ^{
        // 在主线程内处理数据
     });
   }
   ```

   resultDic返回为JSON键值对格式，可以参见[码值解析](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-parsing-result-codes-0000001050257274)。

5. 如果您需要使用图片文件扫描码的功能，则执行如下操作：

   1. 点击导入图片扫码的按钮。
   2. 参见Bitmap Mode[图片扫码场景](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-bitmap-images-0000001050414347)。
