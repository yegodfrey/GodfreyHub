# 创建地图

增强版SDK支持的地图容器有六种，包括[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)、[MapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapfragment-0000001050150294)、[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)、[TextureMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/texturemapview-0000001051004791)、[TextureMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/texturemapfragment-0000001050724736)、[TextureSupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/texturesupportmapfragment-0000001051084710)。以下介绍两种常用地图容器[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)、[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)：

* [SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)是Android Fragment的子类，允许您将地图放置在Fragment中。[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)可以充当地图的容器，并提供对[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的访问入口。
* [MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)是Android View类的子类，允许您将地图放置在Android视图中。与[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)非常相似，[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)充当地图的容器，通过[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象展示核心地图功能。在常规地图交互模式下调用API时，[MapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338)类的使用者必须在对应的Activity/Fragment的方法中调用以下方法：[onCreate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section5701320154117)()、[onStart](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1929311316455)()、[onResume](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section127594720434)()、[onPause](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section119871413124319)()、[onStop](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1185125812451)()、[onDestroy](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1991150164217)()、[onSaveInstanceState](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section17492429104415)(Bundle outState)和[onLowMemory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapview-0000001050150338#section1298412345428)()。

1. 在Activity的布局文件（例如：activity_main.xml）中添加一个Fragment，并通过布局文件设置地图的属性。

   <br />

   ```
   <fragment xmlns:android="http://schemas.android.com/apk/res/android"
       xmlns:map="http://schemas.android.com/apk/res-auto"
       android:id="@+id/mapfragment_mapfragmentdemo"
       class="com.huawei.hms.maps.SupportMapFragment"
       android:layout_width="match_parent"
       android:layout_height="match_parent"
       map:cameraTargetLat="48.893478"
       map:cameraTargetLng="2.334595"
       map:cameraZoom="10" />
   ```

   <br />

2. 要在应用程序中使用地图，您需要实现[OnMapReadyCallback](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378)接口。

   <br />

   示例代码如下：

   ```
   "Java"
   public class SupportMapDemoActivity extends AppCompatActivity implements OnMapReadyCallback {
      ...
   }
   ```

   ```
   "Kotlin"
   class SupportMapDemoActivity : AppCompatActivity(),OnMapReadyCallback { 
      ... 
   }
   ```

   <br />

3. 在Activity的onCreate()方法中先初始化SDK，然后加载[SupportMapFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/supportmapfragment-0000001050153243)，并调用[getMapAsync](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/mapfragment-0000001050150294#section11704105017376)()来注册回调。

   <br />

   示例代码如下：

   ```
   "Java"
   // 初始化SDK
   MapsInitializer.initialize(this);
   private SupportMapFragment mSupportMapFragment; 
   mSupportMapFragment = (SupportMapFragment) getSupportFragmentManager().findFragmentById(R.id.mapfragment_mapfragmentdemo);
   mSupportMapFragment.getMapAsync(this);
   ```

   ```
   "Kotlin"
   // 初始化SDK
   MapsInitializer.initialize(this);
   private var mSupportMapFragment: SupportMapFragment? = null
   mSupportMapFragment = supportFragmentManager.findFragmentById(R.id.mapfragment_mapfragmentdemo) as SupportMapFragment?
   mSupportMapFragment?.getMapAsync(this)
   ```

   ![](https://media:301772613522736788)  
   建议在用户同意隐私协议后再初始化SDK。

   <br />

4. 在[onMapReady](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onmapreadycallback-0000001050150378#section74342919481)回调中获取[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象。

   <br />

   示例代码如下：

   ```
   "Java"
   public void onMapReady(HuaweiMap huaweiMap) {
       Log.d(TAG, "onMapReady: "); 
       // 将huaweiMap对象转换为HuaweiMapEx
       hMap = (HuaweiMapEx)huaweiMap;
   }
   ```

   ```
   "Kotlin"
   override fun onMapReady(huaweiMap: HuaweiMap) {
       Log.d(TAG, "onMapReady: ")
       hMap = huaweiMap;
   }
   ```

   <br />
