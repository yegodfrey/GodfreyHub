# 独立授权（可选）

## 场景介绍

使用帐号成功授权登录后，若用户在特定的业务场景需要单独获取帐号的某个信息（如：头像和昵称），则需要调用独立授权接口进行独立的Scope信息授权。

## 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:----|:-------------------------|:--------------|
|手机、平板|EMUI 3.0及以上、Android 4.4及以上|4.0.0.300及以上|

## 独立授权弹框限制条件说明

* 独立授权接口只支持单个Scope信息授权，调用独立授权接口时，若您传入多个Scope或不传Scope将无法显示独立授权弹框。
* 调用独立授权接口时，Access Token参数必传，若Access Token为空或者已失效，则无法显示独立授权弹框。
* 以下Scope场景调用独立授权接口会弹框显示Scope相关信息进行授权，否则不会显示独立授权弹框。

|使用场景|具体Scope|
|:------|:------------|
|关联帐号|SCOPE_OPENID|
|获取头像和昵称|SCOPE_PROFILE|
|获取邮箱|SCOPE_EMAIL|

> 注意
>
> * 若用户已使用[getIndependentSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section202596712357)接口完成独立授权成功获取到Access Token后，再次调用[getIndependentSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section202596712357)接口时，不会显示独立授权弹框，直接返回Authorization Code信息。
> * 若用户未使用[getIndependentSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section202596712357)接口完成独立授权成功获取到Access Token，再次调用[getIndependentSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section202596712357)接口时，仍会显示独立授权弹框，返回Authorization Code信息后，您需要使用该Authorization Code向帐号服务器调用[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)接口获取Access Token。

## 业务流程

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230921155613.56063575898212536277968558656425:50001231000000:2800:00E101851B05806D8B17235B341701C9D37EB4ABC989BD7F59B365F2ADCEAA5A.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)

整体流程：

1. 应用客户端使用帐号登录，获取到Access Token后，调用[getIndependentSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section202596712357)接口向帐号SDK请求独立授权，获取Authorization Code。
2. 帐号SDK向HMS Core（APK）请求独立授权，获取Authorization Code。
3. HMS Core（APK）向帐号服务器请求获取Scope信息。
4. 帐号服务器返回Scope信息给HMS Core（APK）。
5. HMS Core（APK）显示独立授权弹框并展示Scope信息。
6. 用户同意授权。
7. HMS Core（APK）向帐号服务器请求独立授权获取Authorization Code。
8. 帐号服务器返回Authorization Code给HMS Core（APK）。
9. HMS Core（APK）返回Authorization Code信息给帐号SDK。
10. 帐号SDK返回Authorization Code信息给应用客户端。
11. 应用客户端将获取到的Authorization Code信息发给应用服务器。
12. 应用服务器向帐号服务器发送请求，获取Access Token、Refresh Token信息。
13. 帐号服务器返回Access Token、Refresh Token信息。

## 开发步骤

独立授权功能涉及应用的关键开发步骤如下：

1. 应用使用[华为帐号登录](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-guide-account-0000001050048888)，获取到Access Token，作为[步骤4](#ZH-CN_TOPIC_0000001140395573__li11920443154810)中调用[getIndependentSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section202596712357)方法的参数。此部分为应用自行完成。
2. 应用通过快捷方式如setEmail、setProfile、setId或setScopeList方法设置请求独立授权的单个Scope，并调用[AccountAuthParamsHelper](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthparamshelper-0000001050438849)的构造方法配置授权参数。

   ```screen
   "Java"
   AccountAuthParams authParams = new AccountAuthParamsHelper().setProfile().createParams();
   ```

   ```javascript
   "Kotlin"
   val authParams = AccountAuthParamsHelper().setProfile().createParams()
   ```

3. 调用[AccountAuthManager](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-support-account-accountauthmanager-0000001050193690)的[getService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/hms-support-account-accountauthmanager-0000001050193690#section1354442711181)方法初始化[AccountAuthService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395)对象。

   ```screen
   "Java"
   AccountAuthService service = AccountAuthManager.getService(MainActivity.this, authParams);
   ```

   ```javascript
   "Kotlin"
   val service : AccountAuthService = AccountAuthManager.getService(this@MainActivity, authParams)
   ```

4. 应用将登录帐号成功后获取到的Access Token作为参数，调用[AccountAuthService.getIndependentSignInIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/accountauthservice-0000001050199395#section202596712357)方法，展示独立授权弹框。

   ```screen
   "Java"
   // accessToken为步骤1获取的Access Token。
   startActivityForResult(service.getIndependentSignInIntent(accessToken), 8888);
   ```

   ```javascript
   "Kotlin"
   // accessToken为步骤1获取的Access Token。
   startActivityForResult(service.getIndependentSignInIntent(accessToken), 8888)
   ```

5. 同意授权完成后处理返回结果。

   ```screen
   "Java"
   @Override 
   protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
       //独立授权结果处理，从AuthAccount中获取Authorization Code  
       super.onActivityResult(requestCode, resultCode, data); 
       if (requestCode == 8888) {
           Task<AuthAccount> authAccountTask = AccountAuthManager.parseAuthResultFromIntent(data); 
           if (authAccountTask.isSuccessful()) {
               //独立授权成功，获取Authorization Code 
               AuthAccount authAccount = authAccountTask.getResult(); 
               Log.i(TAG, "serverAuthCode:" + authAccount.getAuthorizationCode());
           } else {
               //独立授权失败
               Log.e(TAG, "independent sign in failed:" + ((ApiException) authAccountTask.getException()).getStatusCode());
           }
       }
   }
   ```

   ```javascript
   "Kotlin"
   override fun onActivityResult(requestCode: Int, resultCode: Int,  data: Intent?){
       //独立授权结果处理，从AuthAccount中获取Authorization Code
       super.onActivityResult(requestCode, resultCode, data)
       if (requestCode == 8888) {
           val authAccountTask = AccountAuthManager.parseAuthResultFromIntent(data)
           if (authAccountTask.isSuccessful) {
               //独立授权成功，获取Authorization Code
               val authAccount = authAccountTask.result
               Log.i(TAG, "serverAuthCode:" + authAccount.authorizationCode)
           } else {
               //独立授权失败
               Log.e(TAG, "independent sign in failed:" + (authAccountTask.exception as ApiException).statusCode)
          }
      }
   }
   ```

6. 独立授权成功后应用服务器调用[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)的接口向帐号服务器请求获取Access Token、Refresh Token。

   **请求参数**

   |**参数**名|**描述**|
   |:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |grant_type|OAuth 2.0规范定义的字段，该值固定填"authorization_code"。|
   |code|获取的授权码Authorization Code。|
   |client_id|应用中OAuth 2.0客户端ID（凭据）的Client ID，在创建应用后由华为开发者联盟为应用分配的唯一标识。Client ID的查询方法请参见[查看应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|
   |client_secret|应用中OAuth 2.0客户端ID（凭据）的Client Secret，在创建应用后由华为开发者联盟为应用分配公钥。Client Secret查询方法请参见[查看应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-appinfo-0000001100014694)。|
   |redirect_uri|AppGallery Connect中设置的[回调地址](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/set-redirect-uri-0000001055126949)，用于应用服务器在获取用户授权后接收Authorization Code和[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)。|

   **请求示例**

   ```screen
   POST /oauth2/v3/token HTTP/1.1
   Host: oauth-login.cloud.huawei.com
   Content-Type: application/x-www-form-urlencoded
   grant_type=authorization_code&
   code={code}&
   client_id={client_id}&
   client_secret={client_secret}&
   redirect_uri=https%3A%2F%2Fwww.example.com%2Fredirect_uri
   ```

   **响应参数**

   |**参数**名|**描述**|
   |:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   |access_token|用户的Access Token。|
   |refresh_token|如果应用申请帐号服务时，入参中包含access_type=offline，则会返回此参数，该参数用于刷新Access Token。|
   |expires_in|Access Token的过期时间，以秒为单位。60分钟过期。|
   |id_token|如果应用申请帐号服务时，入参scope中包含OpenID，则会返回此参数（[JWT格式数据](https://jwt.io/introduction/)），包含用户基本帐号、用户邮箱等信息。ID Token的描述信息请参见[ID Token验证接口](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-verify-id-token_hms_reference-0000001050050577)中ID Token描述。|
   |scope|生成的凭证Access Token中包含的scope。|
   |token_type|固定返回Bearer，标识返回Access Token的类型。|

   **响应示例**

   ```screen
   HTTP/1.1 200 OK
   Content-Type: application/json;charset=UTF-8
   Cache-Control: no-store
   Pragma: no-cache 
   {
   "access_token": "CFyJ21sNODl16eV9y2vu**************cxxgAd7MZUR5th1giyTk5\/kA+QDAyxou+\/5U2zzBRcf3qgLkkFdtbbC+mM3zFV7xj7CCEMHc5Tw92al0Y=",
   "refresh_token": "CF13G0sRaGybtYt7SIy***************ao5C7j7vtgLPt6ogmXKjdI8RS\/YlyS71z4DyP6kEMnOrRlmNK0KhdOUNWd+qVLLRsEEHkqRIKpuAkPvL8=",
   "expires_in": 3600,
   "scope": "profile",
   "token_type": "Bearer"
   }
   ```

7. 由于Access Token的有效期（目前是60分钟）较短，当Access Token失效或者即将失效时，可以使用Refresh Token（有效期180天）通过[获取凭证Access Token](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-obtain-token_hms_reference-0000001050048618)向帐号服务器请求获取新的Access Token。 说明
   > 1. 当Access Token失效时，若您不使用Refresh Token向帐号服务器请求获取新的Access Token，帐号的授权信息将会失效，导致使用Access Token的功能都会失败。
   > 2. 当Access Token非正常失效（如修改密码，退出帐号，删除设备）时，业务可通过调用退出帐号接口后再调用静默登录接口获取新的Access Token。
