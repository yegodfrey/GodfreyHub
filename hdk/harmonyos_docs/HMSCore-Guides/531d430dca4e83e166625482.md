# 查询文件历史版本

#### 场景介绍

华为云空间服务支持用户查询云端文件的历史版本，并且对文件的历史版本进行查看、更新和删除操作。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916154828.76953752375950657868664553592635:50001231000000:2800:2886E097BCB58D98518830100C24612473C3E671FF91E1AD65BC18E74EFB2394.png)  
1. historyVersion相关接口仅支持安全策略更新后的用户使用。若调用About.get接口查询用户信息时，返回的needUpdate字段为true，则表明该用户未进行安全策略更新。建议开发者针对此类用户做相应的提醒或处理。
2. 安全策略更新由云空间服务器后台触发，开发者不可单独基于用户触发安全策略更新。  

#### 获取文件历史记录

功能简介

HistoryVersions.get接口实现获取文件历史记录。

限制

* 必填参数：fileId，historyVersionId。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly
  * https://www.huawei.com/auth/drive.appdata
  * https://www.huawei.com/auth/drive.metadata
  * https://www.huawei.com/auth/drive.metadata.readonly

<!-- -->

* form字段暂仅支持"json"，不传默认json。

发送一个获取文件历史记录的请求

1. 创建一个对HistoryVersions.get接口的[GET](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentsget-0000001050430911)请求。
2. 添加查询参数fileId、historyVersionId和fields。

   <br />

   例如：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/historyVersions/{historyVersionId}?fields=*
   ```

   <br />

3. 填入HTTP headers。

   <br />

   * Accept：接收回复的报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```

   Cache-Control: no-cache

   响应：

#### 获取文件历史记录列表

功能简介

HistoryVersions.list接口实现列出文件历史记录，用户可以根据pageSize的设定获取需要的页面大小等。

限制

* 必填参数：fileId。
* pageSize范围1-100，不传默认100。
* form字段暂仅支持"json"，不传默认json。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly
  * https://www.huawei.com/auth/drive.appdata
  * https://www.huawei.com/auth/drive.metadata
  * https://www.huawei.com/auth/drive.metadata.readonly

说明

在到达最后的列表之前，实际有可能返回部分或者空结果，需根据返回的nextCursor继续获取。

1. 创建一个对HistoryVersions.list接口的[GET](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentslist-0000001050188698)请求。

   <br />

3. 填入HTTP headers。

#### 删除文件历史记录

功能简介

HistoryVersions.delete接口实现删除文件某个历史记录。

限制

* 必填参数：fileId，historyVersionId。
* 只有writer/owner角色可以删除文件历史记录。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.appdata

发送一个删除文件历史记录的请求

1. 创建一个对HistoryVersions.delete接口的[DELETE](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentsdelete-0000001050188702)请求。
2. 添加查询参数fileId和historyVersionId 。

   <br />

   例如：

   ```
   DELETE https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/historyVersions/{historyVersionId}
   ```

   <br />

3. 填入HTTP headers。

   <br />

   Cache-Control：缓存控制

   Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```
   DELETE 
   https://driveapis.cloud.huawei.com.cn/drive/v1/files/BgZ_uIemYqVW0WYk0eNtKVYLMryFlmKjV/historyVersions/362297555238797056.362297555238797057?fields=* HTTP/1.1

#### 下载文件历史版本

功能简介

HistoryVersions.get.content接口实现对文件历史版本下载。

限制

* 必填参数：fileId，historyVersionId，form。
* 只有writer/owner/reader/commenter角色可以下载文件历史版本。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.readonly
  * https://www.huawei.com/auth/drive.appdata

<!-- -->

* form字段只能为content。

发送一个下载文件历史版本的请求

1. 创建一个对HistoryVersions.get.content接口的[GET](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-historyversionsgetcontent-0000001050747405)请求。
2. 添加查询参数fileId、historyVersionId 和form。

   <br />

   例如：

   ```
   GET https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/historyVersions/{historyVersionId}?form=content
   ```

   <br />

3. 填入HTTP headers。

   <br />

   Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```
   GET
   https://driveapis.cloud.huawei.com.cn/drive/v1/files/BgZ_uIemYqVW0WYk0eNtKVYLMryFlmKjV/historyVersions/362238192574807808.362238192574807809?form=content HTTP/1.1
   Authorization: Bearer
   CgB6e3x9Bjh6m9tm8OB0GXjeMWk0m4pVnLmwteDNWXOKPhh0/tjwtIy6Q+OscvD7zhdrElYD0Rak6xA7dI4BM3GSQTuUgFK6ZwFk7K/fjJS5vB7JFmV3

   ```
   HTTP/1.1 200 OK 
   [imageData]
   ```

   <br />

#### 修改文件历史记录

功能简介

HistoryVersions.update接口实现对文件历史记录进行更新。

限制

* 必填参数：fileId，historyVersionId。
* 请求体必填，请求体中keepPermanent字段必填。
* 只有writer/owner角色可以更新文件历史记录。
* scope至少包含下面其中一个：
  * https://www.huawei.com/auth/drive.file
  * https://www.huawei.com/auth/drive
  * https://www.huawei.com/auth/drive.appdata

<!-- -->

* form字段暂仅支持"json"，不传默认json。

发送一个修改文件历史记录的请求

1. 创建一个对HistoryVersions.update接口的[PATCH](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/server-api-commentsupdate-0000001050190853)请求。
2. 添加查询参数fileId、historyVersionId 和fields。

   <br />

   例如：

   ```
   PATCH https://driveapis.cloud.huawei.com.cn/drive/v1/files/{fileId}/historyVersions/{historyVersionId}?fields=*
   ```

   <br />

3. 填入HTTP headers。

   <br />

   * Accept：接收回复的报文格式
   * Content-Type：发送报文格式
   * Cache-Control：缓存控制
   * Authorization：填入从华为帐号获取的authorization code

   <br />

4. 发送请求。

   <br />

   请求示例：

   ```
   PATCH
