# 日志写入开发

#### 概述

开发者可以传入固定的日志目录，并且将日志写入到目录中，方便根据日志分析和定位问题。  

#### 指定应用权限

如果需要使用日志写入服务API，需要在"AndroidManifest.xml"文件中配置READ_EXTERNAL_STORAGE（读外部存储）权限和WRITE_EXTERNAL_STORAGE（写外部存储）权限。

```
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" /> 
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
```

#### 开启日志写入

您可以通过[LogConfig](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/logconfig-0000001214851527)对象传入日志文件的路径及相关参数设置，然后调用[setLogConfig](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/settingsclient-0000001051066118#section2625115917414)()开启日志写入功能。

1. 调用[getSettingsClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/locationservice-0000001050746175#section96644536583)()接口获取[SettingsClient](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/settingsclient-0000001051066118)实例。  

   ```
   "Java"
   SettingsClient settingsClient = LocationServices.getSettingsClient(this);
   ```

   ```
   "Kotlin"
   var settingsClient = LocationServices.getSettingsClient(this)
   ```

2. 配置日志写入参数。  

   ```
   "Java"
   String filePath = getApplicationContext().getFilesDir().getAbsolutePath() + "/log";
   LogConfig logConfig = new LogConfig();
   // 设置日志文件路径
   logConfig.setLogPath(filePath);
   ```

   ```
   "Kotlin"
   val filePath = applicationContext.filesDir.absolutePath + "/log"
   val logConfig = LogConfig()
   // 设置日志文件路径
   logConfig.setLogPath(filePath)
   ```

3. 调用[setLogConfig](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/settingsclient-0000001051066118#section2625115917414)()开启日志写入。  

   ```
   "Java"
   settingsClient.setLogConfig(logConfig).addOnFailureListener(new OnFailureListener() {
       @Override
       public void onFailure(Exception e) {
           // TODO：当没有失败信息回调时,日志写入功能开启成功。
       }
   });
   ```

   ```
   "Kotlin"
   settingsClient!!.setLogConfig(logConfig).addOnFailureListener {
       // TODO：当没有失败信息回调时,日志写入功能开启成功。
   }
   ```

当开启日志写入后需要更换日志保存路径时，请停止当前已开启日志写入功能App的进程，传入新路径进去并开启日志写入功能。当终止当前应用进程时，会关闭日志写入功能，日志将不会再记录。
