# 3D标记图标

## 添加3D标记图标

MarkerEx支持3D模型图标显示，可通过MarkerEx的setIcon3D方法设置3D标记图标。

示例代码如下：

```java
"Java"
private MarkerEx mParis;
LatLng PARIS = new LatLng(47.893478, 2.334595);
mParis = hMapEx.addMarker(new MarkerOptionsEx().position(PARIS).title("paris")
    .snippet("hello").clusterable(true)
    .icon(BitmapDescriptorFactory.defaultMarker(BitmapDescriptorFactory.HUE_BLUE))
    .icon3D(true));

if (null != mParis) {
    // 3D模型路径
    String path = "/xxx/CesiumMilkTruck.gltf";
    // 3D模型缩放系数，3D模型X轴旋转角度，3D模型Y轴旋转角度，3D模型Z轴旋转角度
    double scale = 50,angleX = 0.0,angleY = 0.0,angleZ = 0.0;
    // 设置3D标记图标
    mParis.setIcon3D(path,scale,angleX,angleY,angleZ);
}
```

```java
"Kotlin"
var mParis : MarkerEx
var PARIS ： LatLng(47.893478, 2.334595)
mParis = hMapEx.addMarker(MarkerOptionsEx().position(PARIS).title("paris")
    .snippet("hello").clusterable(true)
    .icon(BitmapDescriptorFactory.defaultMarker(BitmapDescriptorFactory.HUE_BLUE))
    .icon3D(true))

if (null != mParis) {
    // 3D模型路径
    val path = "/xxx/CesiumMilkTruck.gltf"
    // 3D模型缩放系数，3D模型X轴旋转角度，3D模型Y轴旋转角度，3D模型Z轴旋转角度
    val scale = 50.0
    val angleX = 0.0
    val angleY = 0.0
    val angleZ = 0.0
    // 设置3D标记图标
    mParis.setIcon3D(path, scale, angleX, angleY, angleZ)
}
```

## 3D标记图标事件

3D标记图标支持点击和拖拽事件。以点击事件为例，要在地图上设置此侦听器，请调用HuaweiMapEx父类的setOnMarkerClickListener方法，通过HuaweiMap.OnMarkerClickListener来侦听3D标记图标上的点击事件。

示例代码如下：

```java
"Java"
HuaweiMapEx hMapEx;
hMapEx.setOnMarkerClickListener(new HuaweiMap.OnMarkerClickListener() {
    @Override
    public boolean onMarkerClick(Marker marker) {
        Toast.makeText(getApplicationContext(), "Marker is clicked", Toast.LENGTH_SHORT).show();
        return false;
    }
});
```

```java
"Kotlin"
lateinit var hMapEx: HuaweiMapEx
hMapEx.setOnMarkerClickListener {
    Toast.makeText(applicationContext, "Marker is clicked", Toast.LENGTH_SHORT).show()
    false
}
```
