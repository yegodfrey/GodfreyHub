# 使用入门

## 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上

* 安装[HUAWEI DevEco Studio](https://developer.harmonyos.com/cn/develop/deveco-studio) 2.1及以上

* HarmonyOS SDK API Version 6或7
* 测试应用的设备：HarmonyOS 2.0及以上的手机

## 开发流程

您需要按照如下流程完成应用的开发工作。

|序号|步骤|说明|
|:-|:-----------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|开发准备|在开发HarmonyOS应用前，开发者需要先完成开发准备，包括： 1. [准备开发环境](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-dev-environment-0000001213445760)。 2. [配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-config-agc-0000001181440830)。 3. [申请Health Service Kit服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-apply-kitservice-0000001194699502)。 4. [配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-config-app-signing-0000001252142197)。 5. [集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-integration-hms-core-sdk-0000001226760449)。|
|2|[应用开发](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-add-permissions-0000001228903727)|使用HUAWEI DevEco Studio开发环境，根据指导手册，完成三方应用接入Health Service Kit基础能力服务相关功能的开发。|
|3|[申请验证](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-verification-0000001239730723)|应用开发完成后，提交申请验证，以获得Health Service Kit正式权限。|
|4|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-release-application-0000001181600758)|将完成的应用提交华为方进行审核，审核时间一般为1~2个工作日。|
