# 出行旅游

#### 事件参数列表

                * kHAEventRegisterAccount

用户注册帐号时，上报此事件。可以分析用户来源，有针对性的优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRegistMethod | 用户来源 | String | 可选 | 用户来源。  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
  
                * kHAEventCreateOrder

用户创建订单时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamCategory | 商品分类 | String | 可选 | 关联的商品分类，如：Flight、Train、Hotel、Car、Travel。  
kHAParamDestination | 目的地 | String | 可选 | 目的地。  
kHAParamCarMode | 用车类型 | String | 可选 | 用车类型，如：打车、机场接送等。  
kHAParamCarTime | 用车时间 | String | 可选 | 用户预约的用车时间。  
kHAParamCarType | 车辆类型 | String | 可选 | 车辆类型，如：舒适型、经济型、商务型、豪华型。  
kHAParamSupplier | 供应商 | String | 可选 | 供应商。  
  
                * kHAEventCompletePurchase

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamCategory | 商品分类 | String | 必选 | 关联的商品分类，如：Flight、Train、Hotel、Car、Travel。  
kHAParamCity | 城市 | String | 可选 | 城市。  
kHAParamProductId | 商品ID | String | 可选 | 商品的ID。  
kHAParamFromCity | 出发城市 | String | 可选 | 出发城市。  
kHAParamToCity | 目的城市 | String | 可选 | 目的城市。  
kHAParamHotelName | 酒店名称 | String | 可选 | 酒店名称。  
kHAParamHotelType | 酒店类型 | String | 可选 | 酒店类型，如：豪华型、经济型、舒适型。  
kHAParamClass | 预定等级 | String | 可选 | 预定等级。  
kHAParamDiscount | 折扣 | String | 可选 | 折扣。  
kHAParamAirline | 航空公司 | String | 可选 | 航空公司，如："MU"、"CZ"。  
kHAParamTrainType | 列车类型 | String | 可选 | 列车类型，如：高铁、动车、普通。  
kHAParamRevenue | 收入 | Double | 可选 | 订单收入。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。  
kHAParamProductName | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
kHAParamFirstPay | 是否首次支付 | String | 可选 | 标识用户是否首次购买此商品。
                  * 0：表示非首次购买。
                  * 1：表示首次购买。
