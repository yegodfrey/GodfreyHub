# 使用入门

## 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/tutorials_HMSAwarenessKit)快速体验一个应用的开发过程。

## 开发环境

* JDK 1.8.211及以上

* 安装Android Studio 3.6.1及以上
  * minSdkVersion 24及以上（必须）
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 5.4.1及以上（推荐）
* 测试应用的设备：EMUI 7.0及以上的华为手机或Android 7.0及以上的非华为手机（部分能力仅支持华为手机） 如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。

## 开发流程

您需要按照流程来完成应用的开发工作，完整的开发流程如下。

|序号|步骤|说明|
|:-|:----------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101#section1798190144114)、[创建应用](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101#section1210142918419)、[设置数据存储位置](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101#section0291738144113)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101#section18274388433)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101#section09001246164317)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001050033101#section41011121154919)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/integrating-sdk-0000001050031152)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-obfuscation-scripts-0000001050033103)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[应用开发](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/before-you-start-0000001050144954)|开发者根据业务需求，完成相应功能开发。包括：[时间感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/time-awareness-0000001050121130)、[位置感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/location-awareness-0000001050122983)、[活动感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/behavior-awareness-0000001050121034)、[信标感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/beacon-awareness-0000001050122985)、[音频设备状态感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/bluetooth-car-stereo-awareness-0000001050121036)、[环境光感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/ambient-light-awareness-0000001050122987)、[天气感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/weather-awareness-0000001050121038)、[手机状态感知能力](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/screen-awareness-0000001052618943)。|
|5|[开发后自检](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/pre-release-check-0000001050033113)|华为提供对应用自动检查的能力。|
|6|[上架申请](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/app-release-0000001050707912)|开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。
