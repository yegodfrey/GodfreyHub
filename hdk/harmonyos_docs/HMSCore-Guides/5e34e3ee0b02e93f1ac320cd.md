# 业务介绍

## 业务简介

融合搜索（FusionSearch）支持您捐赠应用内容至设备端侧，并为您提供引擎级的系统全局搜索，支持您的数据内容构建全文索引，为用户提供更加准确、高效的搜索体验。全局搜索（系统级搜索入口）接收终端用户发起的搜索请求，遍历支持全局搜索（系统级搜索入口）的可搜索实体，解析用户输入并构造查询条件，最后通过全局搜索（系统级搜索入口）检索到您捐赠的内容召回/展示，帮助APP获得更多的流量入口曝光。

## 场景介绍

* 在搜索结果中免费为用户呈现应用内容
* 在首页"当下"中展示应用内容，需要CP付费

## 服务优势

融合搜索为开发者提供一套标准的数据和服务接入规范，开发者将应用内的数据和服务捐赠给融合搜索，使得终端用户在智慧搜索搜索对应内容和服务时，能够更精准更智能的匹配。

开发者接入融合搜索的收益：

* 流量曝光更大：捐赠应用内的数据和服务到本机，得到更多的流量入口曝光。
* 搜索结果更准：结合应用捐赠的热门内容、浏览记录等数据，搜索结果相关性更好。
* 用户体验更佳：基于终端用户的应用使用行为的总结，能在众多应用中快速命中用户的搜索意图，搜索体验更佳。

## 您的职责

* 您对实施和维护您的站点/网站负有专属责任。
* 您对接收最终用户的查询并传递给华为以及您与华为之间任何数据的传递负有专属责任。
* 您负责接受和回应最终用户就他们的查询和他们在您的站点/网站上的活动提出的任何通信和任何修改或删除请求。
* 您的站点/网站向本公司发送的所有查询，均符合本公司提供的技术规范。
