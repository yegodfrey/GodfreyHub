# 椭圆机运动记录

#### 读取椭圆机活动数据

通过ActivityRecord读取用户已创建的运动记录列表，activityType值为17表示椭圆机活动，用户可以设置查询条件，如活动开始时间、结束时间、活动类型、关联原子数据类型等。

HTTP请求，请参见[查询运动记录](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/activityrecords_list-0000001050114862#section984123664716)接口

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/activityRecords?startTime=***&endTime=***&activityType=***&detailDataType=***
```

请求示例

```
GET 
https://health-api.cloud.huawei.com/healthkit/v2/activityRecords?startTime=1634726553000&endTime=1634738946000&activityType=17&detailDataType=com.huawei.instantaneous.speed&detailDataType=com.huawei.instantaneous.power.sample&detailDataType=com.huawei.instantaneous.exercise_heart_rate&detailDataType=com.huawei.instantaneous.steps.rate&detailDataType=com.huawei.instantaneous.pedaling_rate
```

请求头

```
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
```
