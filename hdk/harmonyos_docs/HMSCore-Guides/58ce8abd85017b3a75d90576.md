# 应用集成

## 功能概述

通过应用集成功能，您可以对需要集成的应用快速集成华为分析服务SDK，并验证该应用是否集成成功。应用集成主要分为四步，分别为添加配置文件、添加SDK、添加初始化代码及验证初始化代码。支持应用集成的应用类型为Android、HarmonyOS、iOS、Web及快应用。

## 典型应用场景

* 您的应用通过集成配置文件、添加SDK、添加初始化代码及验证初始化代码等集成HMS Core SDK的步骤后，可以帮助您更方便的使用行业分析等华为分析服务能力。
* 集成SDK时想要验证是否集成成功，提供集成校验能力，实时地展示服务端的校验结果。当开始验证时，页面会提示您"正在为您检测App是否初始化成功"，当验证成功时，页面展示"验证成功"。当验证失败时，页面会以抛异常形式提醒您"数据加载失败"，请重新验证。

## 功能详述
