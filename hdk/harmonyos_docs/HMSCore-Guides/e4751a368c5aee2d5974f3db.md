# 数据导出CSV文件如何不丢失数据精度转化成EXCEL文件

      1. 数据导出得到CSV文件。
      2. 新建一个空白的EXCEL文件，打开，选中数据菜单的“自文本”选项。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115337.28798130295753894802059759789699:50001231000000:2800:78A54FE1C3009C58F7F722A688F05FC5686084C495C5A5AA9AFC4417C35652D7.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

      3. 导入下载的CSV文件。
      4. 选择文件类型为“分割符号”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115337.27815728567928379513421994838321:50001231000000:2800:61229E65E78D5EBF0CBEB6C2971DA40482B52A9865A1C12ECF764CA37E99B812.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

      5. 分隔符号选中“逗号”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115337.33956670767274929740219657009525:50001231000000:2800:7CCFFAE38D071B8A076D1BA9A70537984131DE2EC70F6BFD70816EDAA4C21B4F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

      6. “列数据格式”区域选中格式为“文本”。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115337.46507012805989999130705447062000:50001231000000:2800:5064C568E5153BC1E1D9C3F6C9508BC8B6371F2DA063E95AB7CAFB39C3BA7049.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

      7. 点击“完成”，等待插入数据即可。
