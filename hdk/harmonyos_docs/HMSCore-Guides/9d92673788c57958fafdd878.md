# 使用入门

#### 开发环境

浏览器类型及版本要求：  

|终端类型|浏览器类型|版本|
|:---|:------|:--------------|
|PC端|Chrome|78及以上|
|PC端|Firefox|56及以上|
|PC端|Edge|44.18362.1.0及以上|

#### 开发流程

您需要按照如下流程完成web应用的开发工作。  

|开发步骤|说明|
|:---------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------|
|[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-app-preparations-0000001080835864#section14574161253315)|在开发应用前，您需要在AppGallery Connect中配置相关信息，包括：注册成为开发者、创建应用。|
|[开通WebPush代理权益](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-app-preparations-0000001080835864#section357541218334)|在AppGallery Connect中开通WebPush推送代理权益。|
|[WebPush代理生成密钥对](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-app-preparations-0000001080835864#section2576181213318)|在AppGallery Connect "Web推送配置"页面生成密钥对，或者使用命令行生成密钥对后在"Web推送配置"页面导入您的密钥对。|
|[工程配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-dev-guides-0000001080547778#section1158515411195)|复制"Web推送配置"页面的代码段到您的项目工程中。|
|[前台接收消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-dev-guides-0000001080547778#section1088518111715)|通过回调函数实现浏览器在前台运行时接受推送消息。|
|[申请token](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-dev-guides-0000001080547778#section127602319194)|申请接入推送服务的Token。|
|[推送消息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/web-dev-guides-0000001080547778#section16301646171910)|通过服务端API向Web应用推送消息。|
