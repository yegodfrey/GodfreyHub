# 血压

此数据记录用户在某一刻的血压数据，每一条数据都代表该时刻的血压值。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 血压数据

* 读权限：https://www.huawei.com/healthkit/bloodpressure.read
* 写权限：https://www.huawei.com/healthkit/bloodpressure.write

## 原子采样明细数据类型

* 名称：com.huawei.instantaneous.blood_pressure

|**字段**列表|字段描述|**类型**|可选/必选|单位|取值范围|
|:------------------------|:------|:-----|:----|:---|:----------------------------------------------------------------------------------------------------------------------|
|systolic_pressure|收缩压，即高压|float|M|mmHg|[40.0, 300.0]|
|diastolic_pressure|舒张压，即低压|float|M|mmHg|[30.0, 200.0]|
|sphygmus|脉搏|float|O|次/分钟|[30.0, 180.0]|
|measurement_anomaly_flag|测量异常事件|int|O|-|取值如下： 1：正常 2：测量时未和心脏平齐 3：测量时有轻微抖动 4：测量前没有至少5min休息|
|before_measure_activities|测量前活动|string|O|-|int数组的json字符串格式，形如[1,2] 取值如下： 1：身体活动 2：吸烟 3：吃饭 4：饮酒 5：喝咖啡 6：无活动 9：运动/做家务 10：情绪波动 11：未服药 12：睡眠不足 13：环境温度下降 14：其他 100：自定义|
