# 应用证书指纹

## 创建应用的Keystore文件

1. 打开命令行工具，输入"keytool"，验证该命令是否可以运行。

   ```screen
   keytool
   ```

   > 注意
   >
   > 如果提示不是内部或外部命令，也不是可运行的程序，请确保您已安装JDK，并配置好环境变量。
   >
   > 若未配置环境变量，您需要根据JDK的安装位置来运行"keytool"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5c/v3/M918A9kdQvuwcXH4pLG4Pw/zh-cn_image_0000002516360576.png?HW-CC-KV=V1&HW-CC-Date=20261008T155252Z&HW-CC-Expire=31536000000&HW-CC-Sign=FE4D6327C59E39E1D6F76576E294A181A5E9BAED315EBB2547562CF03ECFF1EF)

2. 输入命令。

   ```screen
   keytool -genkey -alias key -keyalg RSA -keystore d:key.keystore -validity 365
   ```

   * genkey：表示生成密钥对。
   * alias：指定生成密钥对的别名，此处命名为key。
   * keyalg：指定生成密钥的算法，此处为RSA加密算法。
   * validity：指定证书的有效期，单位为天，此处为 365 天。
   * keystore：指定密钥库的存储路径，此处表示存储在d：盘。

   您可以根据实际需要，修改对应的描述。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/KiV1U0JZQpe0nD-Hdv5Xow/zh-cn_image_0000002548040395.png?HW-CC-KV=V1&HW-CC-Date=20261008T155252Z&HW-CC-Expire=31536000000&HW-CC-Sign=CB5C4F04A2345105A0AFDAA0BCD055B27DEF666B4249F9D05585F779323A3DA1)
   1. 根据提示，输入密钥库口令。
   2. 根据提示，完成姓名、单位、组织、城市、省、国家的输入。
   3. 确认是否输入正确，若正确，输入"y"，若错误，输入"n"。则重新填写。
   4. 输入密钥口令，可以密钥库口令一致。


3. 至此，我们便创建好了应用的Keystore文件，可以在D盘查看生成的Keystore文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/j59tlgFcQZuRlaJOQGpFtQ/zh-cn_image_0000002547960397.png?HW-CC-KV=V1&HW-CC-Date=20261008T155252Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC096BE3877D0F430BE1752CE91AF27114DA8381237A04D32F64556AE2F4346E)

## 获取Keystore文件对应的SHA256证书指纹

1. 打开命令行工具，执行命令。

   ```screen
   keytool -list -v -keystore d:key.keystore
   ```

2. 根据提示，输入密钥库口令：123456abc。从运行结果中获取对应的SHA256证书指纹。
