# 订阅分析

#### 功能概述

华为分析服务支持查看按照周期订阅型商品的分析报告，通过分析应用的新增订阅用户数、累计订阅用户、累计订阅金额等关键指标洞察用户订阅情况。同时支持查看用户订购明细、留存分析、付费分析以及续订分析报告。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115254.92172012030937710483816559378156:50001231000000:2800:4C247AF2BC174917C651C079AB3D816F241BC64530AD9934D5D5CD27C24CB038.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
订阅分析中的所有报告均基于按User-ID的计算逻辑展示。  

#### 前提条件

开通华为分析服务并集成华为分析SDK。开通华为分析服务操作详情请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-enabling-0000001050745155)，集成Android SDK操作详情请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876)。

#### App侧上报预置事件

数据由App上报，从App端侧上报预置事件，需在华为分析端侧SDK中埋点预置事件。

请参考如下代码在SDK中埋点预置事件及参数：  

```
"Java"
Bundle bundle = new Bundle();
bundle.putString("$ProductId", "123"); 
bundle.putString("$ProductName", "name"); 
instance.onEvent("$Subscribe", bundle);
```

```
"Kotlin"
val bundle = Bundle()
bundle.putString("$ProductId", "123")
bundle.putString("$ProductName", "name")
instance.onEvent("$Subscribe", bundle)
```

集成服务端SDK的方式上报事件信息

如果采用集成服务端SDK的方式，需先集成服务端SDK，通过调用服务端SDK中封装的类实现事件上报。

1. 集成服务端SDK。
   * 针对Java应用：集成方式请参见[JAVA SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/java-server-sdk-0000001193440994)。
   * 针对Python应用：SDK下载及集成方式请参见[Python SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/python-server-sdk-0000001238560943)。
   * 针对NodeJS应用：SDK下载及集成方式请参见[NodeJS SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/nodejs-server-sdk-0000001193281036)。
2. 在服务端埋点上报事件信息。

   以Java应用埋点$Unsubscribe事件为例，参考样例如下：

   ```
     EventPojo eventPojo = new EventPojo(); 
     eventPojo.setAaid("123"); 
     eventPojo.setUserId(""); 
     eventPojo.setEventTime(1631606679895L); 
     eventPojo.setEventId("$Unsubscribe"); 
     eventPojo.setEventSessionName("123"); 
     eventPojo.setFirstSessionEvent("true"); 
     eventPojo.setProperties(""); 
     Map<String,Object> map = new HashMap<>();
     map.put("$ProductId","111");
     map.put("$ProductName","222");
     map.put("$Reason","4");
     eventPojo.setProperties(map);
     HuaweiAnalyticsClient.addEvent("123", eventPojo);
   ```

#### 服务器侧新建预置事件

预置事件上报设置完成后，还需在"华为分析 \> 管理 \> 事件管理"界面中通过新建预置事件的方式将$Subscribe、$Unsubscribe、$CompletePurchase和$RefundOrder事件手动注册到系统。

1. 选择"华为分析 \> 管理 \> 事件管理"进入事件管理页面。
2. 点击"新建"，打开"新建事件"页面。

   新建事件页面左侧"添加事件"下方展示未注册的预置事件列表，可在输入框中输入事件ID或名称搜索后选中并保存。新建事件操作详情可参考[新建预置事件或自定义事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/meta-manage-0000001050985177#section5729142611116)。

#### 事件参数说明

#### $Subscribe

订阅自动续费类型商品时，上报此事件。  

|参数ID|参数名称|参数类型|可选/必选|参数描述|
|:-----------|:---|:-----|:----|:--------|
|$ProductId|商品ID|String|必选|订阅的商品的ID。|
|$ProductName|商品名称|String|必选|订阅的商品的名称。|
|$TaskId|任务ID|String|可选|营销任务ID。|

#### $Unsubscribe

取消订阅自动续费类型商品时，上报此事件。  

|参数ID|参数名称|参数类型|可选/必选|参数描述|
|:-----------|:-----|:-----|:----|:--------------------------------------------------------------------------------------------------------------|
|$ProductId|商品ID|String|必选|取消订阅的商品的ID。|
|$ProductName|商品名称|String|必选|取消订阅的商品的名称。|
|$Reason|取消订阅原因|String|必选|用户取消订阅的原因。取值包括： * 1：用户取消 * 2：商品不可用 * 3：用户签约信息异常 * 4：Billing错误 * 5：用户未同意涨价 * 6：未知错误 同时有多个异常时，优先级为：1 \> 2 \> 3...|
|$TaskId|任务ID|String|可选|营销任务ID。|

#### $CompletePurchase

用户支付完成后，上报此事件。  

|参数ID|参数名称|参数类型|可选/必选|参数描述|
|:------------|:----|:-----|:----|:-------------------------------------------------------------|
|$ProductId|商品ID|String|必选|被添加到购物车中的商品ID。|
|$ProductName|商品名称|String|必选|被添加到购物车中的商品名称。|
|$Quantity|购买数量|Long|必选|用户准备购买的数量。|
|$CurrName|货币类型|String|可选|标识收入的货币类型。与$Revenue一起使用。|
|$Revenue|收入|Double|可选|本次交易给您带来的收入。必须与$CurrName同时使用。|
|$Brand|商品品牌|String|可选|关联的商品品牌。|
|$Category|商品分类|String|可选|关联的商品分类。|
|$PayType|支付方式|String|可选|用户选择的支付方式。|
|$PurchaseType|购买方式|String|必选|购买商品的方式： * 0：普通支付类型 * 1：订单类型 * 2：订阅类型 * 3：代扣类型 针对订阅类型，请填写值"2"。|
|$VoucherName|优惠券名称|String|可选|用户在本次交易中使用的优惠券的名称。|
|$VoucherPrice|优惠价格|String|可选|用户在本次交易中使用的优惠券的价格。|

#### $RefundOrder

用户取消订单后，申请退款时，上报此事件。  

|参数ID|参数名称|参数类型|可选/必选|参数描述|
|:-------------|:-------|:-----|:----|:--------------------------------|
|$CurrName|货币类型|String|可选|退款的货币类型。|
|$Revenue|退款额|Double|可选|退款给您带来的收入损失。|
|$ProductId|商品ID|String|必选|被退款的商品ID。|
|$ProductName|商品名称|String|必选|被退款的商品名称。|
|$Quantity|购买数量|Long|必选|用户准备购买的数量。|
|$Brand|商品品牌|String|可选|关联的商品品牌。|
|$Category|商品分类|String|必选|关联的商品分类。|
|$Source|营销来源|String|可选|营销活动提供者的标识，如：HUAWEI PPS。|
|$Medium|营销类型|String|可选|营销活动的类型，如：CPC、Email、运营坑位、Banner等。|
|$PromotionName|营销名称|String|可选|营销活动的名称。|
|$Content|营销内容|String|可选|营销活动的营销内容。|
|$Keywords|关键词|String|可选|营销活动的关键词。如：搜索广告的关键词。|
|$MaterialName|创意名称|String|可选|营销活动使用的创意素材名称。|
|$MaterialSlot|营销内容展示位置|String|可选|创意素材被展示的位置信息。|
|$Reason|退款原因|String|必选|用户选择退款的原因。|
|$PayType|支付方式|String|可选|用户选择的支付方式。|

#### 查看分析报告

#### 订阅分析

订阅分析报告最上方统计筛选日期范围内整体的累计指标，包括累计订阅用户、累计取消订阅、累计退款人数、累计订阅金额、累计退款金额指标。支持选择应用、自定义时间段查询报告。

累计指标下方报告以趋势图形式展示选定日期下Top5订阅商品的新增订阅用户数和取消订阅用户数。

#### 续订分析

续订分析可以查看上一周期已订阅的用户中，本周期继续订阅的比例，即查看已订阅用户续订率的情况。

续订率基于固定日期计算，续订周期可选择30天或31天。
