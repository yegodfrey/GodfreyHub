# 添加权限声明

（可选）想要使用iOS Location SDK提供的后台定位功能，需要开启"Capabilities"下的"Background Modes"下的"Location updates"。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103222.36258174656751917551019985359491:50001231000000:2800:85CB7F2ED9BF13051A457A4B4DA15EF32BF2D200156BE46F3CA9751FA02CED88.png?needInitFileName=true?needInitFileName=true "点击放大")

使用iOS Location SDK提供的服务需要声明一些系统权限，仅需要在"Info.plist"文件中添加相应的权限声明即可。

iOS 9 - iOS 10 版本：

"NSLocationWhenInUseUsageDescription"：表示应用在前台的时候可以获取到位置信息。

"NSLocationAlwaysUsageDescription"：申请Always权限，以便应用在前台和后台都可以获取到位置信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103222.30245495783952845852149910867214:50001231000000:2800:687F14D90F46A6EE61600BB87C4AF28608C3A90A05F43958A72674DE9838AA10.png?needInitFileName=true?needInitFileName=true "点击放大")

iOS 11 及以上版本：

"NSLocationWhenInUseUsageDescription"：表示应用在前台的时候可以获取到位置信息。

"NSLocationAlwaysAndWhenInUseUsageDescription" 申请Always权限，以便应用在前台和后台（suspend 或 terminated）都可以获取到位置信息。

![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103222.73913378093332092599536984279860:50001231000000:2800:A0C27BD5C9C2AF502AC83E72A92518F95DEC8DE02D3E8DE095F99AF5AD8FC900.png?needInitFileName=true?needInitFileName=true)  
![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230112103222.85343699292250110087622057444173:50001231000000:2800:C23C82063CA7BE87E2C2F08352EF367F78D26AB93CFA21D37BA492B74E7ED768.png?needInitFileName=true?needInitFileName=true)  
如果您的应用需要支持iOS 9及上系统使用定位功能，建议在plist文件中同时添加"NSLocationWhenInUseUsageDescription"、"NSLocationAlwaysUsageDescription"和"NSLocationAlwaysAndWhenInUseUsageDescription"权限声明。

具体操作步骤如下：

```
<key>NSLocationWhenInUseUsageDescription</key>  
<string>APP需要定位权限才可以正常使用</string> 
<key>NSLocationAlwaysUsageDescription</key>
<string> APP需要定位权限才可以使用</string>
<key>NSLocationAlwaysAndWhenInUseUsageDescription</key>  
<string> APP需要定位权限才可以正常使用，如果您需要使用后台定位功能请选择"始终允许"</string> 
```
