# 中信银行动卡空间HarmonyOS版App集成HUAWEI Account Kit，提升金融服务体验

#### 动卡空间简介

中信银行信用卡坚持"无界开放"的理念，发挥金融科技的赋能效应，与华为HMS Core进行深入合作，向终端用户提供流畅的金融服务，并将HarmonyOS生态能力与信用卡的金融服务能力进行深度融合，上线了HarmonyOS原生App------动卡空间App V1.0版。

#### 业务挑战

* 需要创新用户支付体验 随着移动支付的发展，用户对数字金融服务在不同场景及终端中的智能化、便捷化、轻量化提出了更高的要求，为满足用户新的消费习惯，需要创新支付体验。

* 需要提供更快捷的登录方式 在一些场景下，如抢购信用卡限时优惠、领取限定福利时等，用户需要更快速、更方便地完成注册登录的全流程。

* 需要用户授权信息来辅助验证 在消费时，应用需要获取用户授权的手机号来辅助消费验证，确保为用户本人操作。

* 需要保护用户安全隐私 金融类App对安全保护要求非常高，需要完善的帐号保护机制来为用户的数字资产和信息保驾护航。

#### 解决方案

* 跨设备协同，手表快捷支付 动卡空间HarmonyOS版App支持跨设备协同支付，用户只需登录同一个华为帐号，即可使用手机、手表等终端设备直接支付，让用户获得万物互联的顺滑体验。此外，手表的登录和设置，亦可在手机端便捷完成。

* 免注册，一键授权登录 用户只需轻轻一点华为帐号登录，便可一键授权登录，免去输入手机号、验证码进行注册、验证的繁琐流程，即刻使用App。当再次进入App时，无需二次授权即可登录。

* 开放授权助力运营 在用户授权的前提下，应用能通过开放API获取到华为帐号用户的信息（如昵称、头像等），来验证用户身份。也可以用来优化产品功能或者运营策略。

* 跨帐号保护，安全隐私无忧 华为帐号提供基于RISC的跨帐号保护功能，将帐号异动及时推送给应用，保护用户帐号安全。同时，华为HMS Core在隐私安全保护方面已获得多项权威认证，早在2015年就获得ISO/IEC27001、CSAStar安全认证，2019年又先后获得ISO/IEC 27018和ISO/IEC 27701隐私标准认证等。

#### 合作收益

* 对动卡空间HarmonyOS版App 简化的登录流程，可以帮助应用提高用户登录转化率。同时，通过华为帐号用户授权信息，可以优化产品功能、运营策略，增加用户黏性，提升使用体验。

* 对用户 "抬腕即刷"的手表支付体验，提升了支付的便捷性和速度。华为帐号一键授权登录，免注册节省了用户的时间，使其更快捷地享受"指尖"金融。
