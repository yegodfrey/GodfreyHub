# 基于受众人群请求广告

鲸鸿动能JavaScript API提供了通过设置[RequestConfig](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167)对象，来满足针对不同受众人群请求对应广告内容的能力。
> 注意
>
> 您必须将用户是否是儿童的标识，在setTagForChildProtection方法中如实地告知鲸鸿动能平台。**您需要承担因告知错误或没有告知导致广告误投放到儿童的手机上导致的一切后果。**

示例代码如下所示：

```java
ppsads.setGlobalRequestConfig{
    tagForChildProtection: ppsads.settings.TagForChild.PROTECTION_TRUE,
    ...
};
```

[RequestConfig](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167)提供了下面七种参数设置受众人群：

|参数|描述|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[tagForChildProtection](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p15119184816393)|为了满足《儿童在线隐私保护法》（COPPA）的要求，鲸鸿动能JavaScript API提供了"面向儿童内容的标记"的设置。 参数说明： * PROTECTION_TRUE：表明您的广告内容需要符合COPPA的规定。 * PROTECTION_FALSE：表明您的广告内容不需要符合COPPA的规定。 * PROTECTION_UNSPECIFIED：表明您不希望明确您的广告内容是否需要符合COPPA的规定。|
|[tagForUnderAgeOfPromise](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p512034823915)|为了满足[《一般数据保护条例》（GDPR）](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32016R0679)和其他国家关于未成年人保护的要求，鲸鸿动能JavaScript API提供了"未达到法定承诺年龄的用户"的设置。 参数说明： * PROMISE_TRUE：表明您希望按适合未达到法定承诺年龄的用户的方式来处理广告请求。 * PROMISE_FALSE：表明您不希望按适合未达到法定承诺年龄的用户的方式来处理广告请求。 * PROMISE_UNSPECIFIED：表明您未明确是否按适合未达到法定承诺年龄的用户的方式来处理广告请求。|
|[adContentClassification](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p0120164863916)|鲸鸿动能JavaScript API提供了广告内容过滤能力，在请求广告时可以设置广告内容分级的上限。使用此方法获取的广告内容会小于等于设置的分级上限。 设置的分级必须是下述值之一： * CLASSIFICATION_W：适合幼儿及以上年龄段的受众，仅展示内容分级为W的内容。 * CLASSIFICATION_PI：适合少儿及以上年龄段的受众，展示内容分级为PI、W的内容。 * CLASSIFICATION_J：适合青少年及以上年龄段的受众，展示内容分级为J、PI、W的内容。 * CLASSIFICATION_A：仅适合成人受众，展示内容分级为A、J、PI、W的内容。|
|[nonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p1412034843915)|鲸鸿动能JavaScript API支持投放的广告分为个性化广告与非个性化广告两种。通过此方法可以设置请求的广告类型。 参数说明： * ALLOW_ALL：个性化广告与非个性化广告。 * ALLOW_NON_PERSONALIZED：非个性化广告。 说明 > 当[nonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p1412034843915)为0时，使用[hwNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p98873327253)和[thirdNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p94215355254)设置个性化广告是有效的。|
|[hwNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p98873327253)|鲸鸿动能JavaScript API支持针对华为DSP投放的广告设置个性化广告与非个性化广告两种。通过此方法可以设置请求的广告类型。 参数说明： * ALLOW_ALL：个性化广告与非个性化广告。 * ALLOW_NON_PERSONALIZED：非个性化广告。|
|[thirdNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p94215355254)|鲸鸿动能JavaScript API支持针对三方DSP投放的广告设置个性化广告与非个性化广告两种。通过此方法可以设置请求的广告类型。 参数说明： * ALLOW_ALL：个性化广告与非个性化广告。 * ALLOW_NON_PERSONALIZED：非个性化广告。|
|[consent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-setglobalrequestconfig-0000001179593167#ZH-CN_TOPIC_0000001179593167__p101211448193912)|[TCF v2.0](https://iabeurope.eu/tcf-2-0/)用户同意信息字符串，遵循IAB TCF v2.0标准中的[Consent String Format](https://github.com/InteractiveAdvertisingBureau/GDPR-Transparency-and-Consent-Framework/blob/master/TCFv2/IAB Tech Lab - Consent string and vendor list formats v2.md#the-global-vendor-list)格式。|

示例代码如下所示：

```java
ppsads.setGlobalRequestConfig{
    tagForChildProtection: ppsads.settings.TagForChild.PROTECTION_TRUE,
    tagForUnderAgeOfPromise: ppsads.settings.UnderAge.PROMISE_TRUE,
    adContentClassification: ppsads.settings.ContentClassification.CLASSIFICATION_W,
    nonPersonalizedAd: ppsads.settings.NonPersonalizedAd.ALLOW_ALL,
    hwNonPersonalizedAd: ppsads.settings.NonPersonalizedAd.ALLOW_ALL, 
    thirdNonPersonalizedAd: ppsads.settings.NonPersonalizedAd.ALLOW_ALL,
    consent: "tcfString",
};
```
