# 概述

当低权限用户需要发布时，需经过拥有审批权限用户的审核，审核通过后，版本才能正常发布。

低权限用户可以提交审核或撤销审核；拥有审批权限的用户可以进行审核操作或转移审核。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/oS6Bg7J8S72gUtf7B0LWdg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043046Z&HW-CC-Expire=86400&HW-CC-Sign=8C5719C70ED42E4082F8939D72893A6A19046A312E733E7A5494232AE73CFA50)

              * 仅有编辑DTM配置权限的用户为低权限用户，如运营、开发人员。
              * 拥有发布DTM配置权限的用户则拥有审批权限，如帐号持有者、管理员、App管理员。
