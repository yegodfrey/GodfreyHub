# 地点详情

#### 概览

您可以通过某一地点的Site ID来获取该地点的详细信息（如地点名称、地址详细信息、经纬度等），Site ID是地点的唯一标识符。  

#### 使用约束

返回1条记录（或没有）。  

#### 实现步骤

获取地点详情的步骤如下：

1. 声明[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象，并通过[SearchServiceFactory](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchservicefactory-0000001050154715)创建[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)实例。

   <br />

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250506195619.70506443579465891836239517259825:50001231000000:2800:A656B0E88F78E55A362EF8B212C9FAD0FF54FC06FEC8637A5CC5A99E01811563.png)  
   创建SearchService实例需要传入Context类型参数和API密钥。Context参数建议传入Activity类型，否则需要升级HMS Core（APK）时不会弹出升级界面。API密钥是您在[华为开发者联盟](https://developer.huawei.com/consumer/cn)创建应用时生成的API密钥，注意使用时需要调用URLEncoder.encode("Your apiKey", "UTF-8")方法对API密钥进行encodeURI编码。

   <br />

2. 创建[DetailSearchRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-detailsearchrequest-0000001050152780)对象，它是详情查询的请求体。并传入以下参数：

   <br />

   * siteId：地址ID，必选项。
   * language：查询结果的语种，可选项。如果不指定语种，返回英语，如果没有英语，返回当地语言。
   * politicalView：政治观点参数，采用ISO 3166-1 alpha-2规范的2位国家/地区码，该参数已废弃。
   * children：是否返回子节点，默认为false。传入children为true，返回子节点的全量信息。

   <br />

3. 创建[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象，该对象用来侦听搜索结果。
4. 通过第1步创建的[SearchService](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711)对象调用[detailSearch](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-textsearch-0000001050154711#section617714167322)()接口，传入第2步创建的[DetailSearchRequest](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-detailsearchrequest-0000001050152780)对象和第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象。
5. 通过第3步创建的[SearchResultListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchresultlistener-0000001050154707)对象获取搜索结果[DetailSearchResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-detailsearchresponse-0000001050152784)对象。通过[DetailSearchResponse](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-detailsearchresponse-0000001050152784)对象，可以获取[Site](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781)对象，从而获得地点信息，获取地点信息的方法如下表所示：

   <br />

   |方法名|功能|
   |:---------------------------------------------------------------------------------------------------------------------------------|:------------------------|
   |[getSiteId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section26922414385)()|获取地点的ID。|
   |[getName](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section186494433811)()|获取地点名称。|
   |[getFormatAddress](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section96071463818)()|获取格式化的地点详细地址。|
   |[getAddress](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section125568453815)()|获取地址详细信息。|
   |[getLocation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section862814153817)()|获取地点的经纬度。|
   |[getViewport](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section3713104173813)()|获取地点的可视区域。|
   |[getPoi](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section11671124123810)()|获取地点的POI信息。|
   |[getPrediction](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section31451645152414)()|获取自动补全的描述信息。|
   |[getDistance](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section9585134103817)()|获取预测地点和传参location之间的直线距离。|
   |[getUtcOffset](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781#section5328131217414)()|获取地点所在时区和UTC时区的差值，单位：分钟。|

   <br />

示例代码如下：

```
"Java"
// 声明SearchService对象 
private SearchService searchService; 
// 创建SearchService实例 
searchService = SearchServiceFactory.create(this, "API key");
// 创建请求体 
DetailSearchRequest request = new DetailSearchRequest(); 
request.setSiteId("C2B922CC4651907A1C463127836D3957"); 
request.setLanguage("fr"); 
request.setChildren(false);
// 创建搜索结果侦听器 
SearchResultListener<DetailSearchResponse> resultListener = new SearchResultListener<DetailSearchResponse>() { 
    // 正常结果返回 
    @Override 
    public void onSearchResult(DetailSearchResponse result) { 
        Site site;
        if (result == null || (site = result.getSite()) == null) { 
            return; 
        }
         Log.i("TAG", String.format("siteId: '%s', name: %s\r\n", site.getSiteId(), site.getName())); 
    } 
    // 异常结果返回 
    @Override 
    public void onSearchError(SearchStatus status) { 
        Log.i("TAG", "Error : " + status.getErrorCode() + " " + status.getErrorMessage()); 
    } 
}; 
// 调用地点详情接口 
searchService.detailSearch(request, resultListener);
```

```
"Kotlin"
// 声明SearchService对象
val searchService: SearchService
// 创建SearchService实例
searchService = SearchServiceFactory.create(this, "API key")
// 创建请求体
val request = DetailSearchRequest()
request.siteId = "C2B922CC4651907A1C463127836D3957"
request.language = "fr"
// 创建搜索结果侦听器
val resultListener: SearchResultListener<DetailSearchResponse> = object : SearchResultListener<DetailSearchResponse> {
    // 正常结果返回
    override fun onSearchResult(result: DetailSearchResponse?) {
        var site: Site? = null
        if (result == null || result.getSite().also { site = it } == null) {
            return
        }
        Log.i("TAG", "siteId: ${site?.getSiteId()}, name: ${site?.getName()}")
    }
    // 异常结果返回
    override fun onSearchError(status: SearchStatus) {
        Log.i("TAG", "Error : ${status.getErrorCode()}  ${status.getErrorMessage()}")
    }
}
// 调用地点详情接口
searchService.detailSearch(request, resultListener)
```
