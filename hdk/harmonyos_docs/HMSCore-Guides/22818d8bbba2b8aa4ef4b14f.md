# 签署服务使用协议

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 选择需要创建会员开放服务的项目，进入"项目设置"页面。
3. 在左侧导航选择"增长 \> 会员开放服务"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220323160004.23531566005045760342311386070989:50530322093902:2800:C8A26DE0A97F0D6DE0E95F9D60DAAD141BFC0B013A5CBD583F6F6F45B9DB603B.png?needInitFileName=true?needInitFileName=true "点击放大")
4. 首次进入"会员开放服务"菜单时，需要签署"华为会员开放服务使用协议"。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220323160004.61509591670157460430305084077323:50530322093902:2800:FB239DE1D5658E458DFCF00D038F5A8392CEC0A2779F4CEB6B0F42F4727A50E8.png?needInitFileName=true?needInitFileName=true)

   可以点击[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站右上角的![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220323160004.81237466560681060471593542798707:50530322093902:2800:99F53803E8C1A68EBCD65D20708F450BB1DE6C3A9BB7B833FE43CF7C0F9ED073.png?needInitFileName=true?needInitFileName=true)中的"协议签署记录"来查看已经签署过的协议。如已签署过，则无需重复签署。
