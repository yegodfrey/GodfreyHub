# 跑步姿势

此数据类型记录用户在一段时间内的跑步姿势。  

#### OAuth权限

联盟卡片申请的权限名称：锻炼记录 \> 锻炼记录详情数据

* 读权限：Scopes.HEALTHKIT_ACTIVITY_READ
* 写权限：Scopes.HEALTHKIT_ACTIVITY_WRITE  

#### 原子采样明细数据类型

* 名称：com.huawei.continuous.run.posture
* Android SDK类型常量：DataType.DT_CONTINUOUS_RUN_POSTURE

|字段列表|描述|Android SDK常量|类型|可选/必选|单位|取值范围|
|:-------------------------|:------------|:-------------------------------|:-----|:----|:----------------------------------|:-----------|
|ground_contact_time|触地时间|Field.GROUND_CONTACT_TIME|int|M|毫秒|\[0,5000\]|
|ground_impact_acceleration|着地冲击|Field.GROUND_IMPACT_ACCELERATION|int|O|g(重力加速度)|\[0,50\]|
|swing_angle|摆动角度|Field.SWING_ANGLE|int|O|度|\[0,360\]|
|eversion_excursion|外翻幅度|Field.EVERSION_EXCURSION|int|O|度|\[-100,100\]|
|hang_time|腾空时间|Field.HANG_TIME|int|O|毫秒|-|
|ground_hang_time_rate|触地腾空比|Field.GROUND_HANG_TIME_RATE|double|O|-|\[0,500\]|
|fore_foot_strike_pattern|触地方式中的前脚掌触地次数|Field.FORE_FOOT_STRIKE_PATTERN|int|O|次|\[0,100\]|
|hind_foot_strike_pattern|触地方式中的后脚掌触地次数|Field.HIND_FOOT_STRIKE_PATTERN|int|O|次|\[0,100\]|
|whole_foot_strike_pattern|触地方式中的全脚掌触地次数|Field.WHOLE_FOOT_STRIKE_PATTERN|int|O|次|\[0,100\]|
|impact_peak|触地峰值|Field.IMPACT_PEAK|double|O|BW(体重倍数)|\[0,10.0\]|
|vertical_oscillation|垂直振幅|Field.VERTICAL_OSCILLATION|double|O|厘米|\[0,25.6\]|
|vertical_ratio|垂直步幅比|Field.VERTICAL_RATIO|double|O|百分比|\[0,100.0\]|
|gc_time_balance|左右触地平衡|Field.GC_TIME_BALANCE|double|O|百分比（返回数据为左脚的触地平衡，右脚需自行计算，二者之和为100%）|\[0,100.0\]|
