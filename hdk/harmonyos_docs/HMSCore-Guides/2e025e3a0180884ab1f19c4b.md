# 业务介绍

#### 概述

华为VR支付基于华为应用内支付（In-App Purchases，IAP）服务在VR设备中给用户提供沉浸式的支付体验，支付便捷，接入流程简便，帮助您的应用快速变现。  

#### 业务特点

* 接入便捷 完善的接入流程指导，与手机端IAP接入相似的接入流程，帮助您快速轻松的接入华为VR支付。

* 安全可靠 采用业界标准的TLS协议加密传输数据，通过RSA算法签名保护用户消息，保证不会被截取和篡改。数据在后台采用加密和匿名化方式存储，保证用户数据存储安全。后台服务器采用集群部署和冗余设计，7\*24小时实时监控系统运行。

* 提供多种支付方式 支持花币、银行卡、与华为免密签约的微信和支付宝等多种支付方式。

#### 场景介绍

VR应用在接入VR支付服务后，可使用户不用摘下VR眼镜或头盔即可完成支付，支付过程不会中断，提供更佳的游戏体验，增强用户黏性。
