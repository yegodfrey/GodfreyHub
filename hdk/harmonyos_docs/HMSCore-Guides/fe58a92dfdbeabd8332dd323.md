# 概览

Health Service Kit在客户端支持Android应用和HarmonyOS应用接入，支持的开发API类型如下：

* Android JAVA API Android应用集成Android版本的Health Service Kit JAVA SDK，可以获取用户对数据的单独授权，读写运动健康数据。

  * [基础能力服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/overview-dev-android-0000001050071671)提供原子化数据开放，可以通过接口对运动健康、锻炼记录、健康记录等数据进行管理，进行增、删、改、查等操作。同时写入的数据会上传云端保存，保证多设备间数据同步。
  * [扩展能力服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-introduction-0000001050060843)开放更多实时运动和健康数据、运动和健康解决方案场景化数据。

<!-- -->

* HarmonyOS JS API [HarmonyOS](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-overview-0000001226482001)应用集成HarmonyOS版本的Health Service Kit JS SDK，可以获取用户对数据的单独授权，读写运动健康数据。提供原子化数据开放，对运动健康、锻炼记录、健康记录数据进行管理，同时支持实时心率、实时运动控制。
