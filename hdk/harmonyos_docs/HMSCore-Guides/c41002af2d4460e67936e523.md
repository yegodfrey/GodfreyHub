# 地图类型

[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)目前支持三种地图类型：

* MAP_TYPE_NORMAL：标准地图。展示道路、建筑物以及河流等重要的自然特征。
* MAP_TYPE_NONE：空地图。没有加载任何数据的地图。
* MAP_TYPE_TERRAIN：地形图。 说明
  >
  > 地形图使用限制：支持Android 7.0及以上版本。

可通过以下三种方式设置地图类型：

* 调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[setMapType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section3746134811217)方法，并传递[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)中定义的静态常量。

  示例代码如下：

  ```java
  "Java"
  // 设置标准地图类型
  hMap.setMapType(HuaweiMap.MAP_TYPE_NORMAL);
  ```

  ```java
  "Kotlin"
  // 设置标准地图类型
  hMap?.mapType = HuaweiMap.MAP_TYPE_NORMAL
  ```

* 调用[HuaweiMapOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimapooptions-0000001050150194)对象的[mapType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimapooptions-0000001050150194#section2485024181514)方法，并传递[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)中定义的静态常量。

  示例代码如下：

  ```java
  "Java"
  HuaweiMapOptions huaweiMapOptions = new HuaweiMapOptions();
  // 设置标准地图类型
  huaweiMapOptions.mapType(HuaweiMap.MAP_TYPE_NORMAL);
  MapFragment.newInstance(huaweiMapOptions);
  ```

  ```java
  "Kotlin"
  val huaweiMapOptions = HuaweiMapOptions()
  // 设置标准地图类型
  huaweiMapOptions.mapType(HuaweiMap.MAP_TYPE_NORMAL)
  MapFragment.newInstance(huaweiMapOptions)
  ```

* 设置XML文件中的mapType属性。有效值包括：none（空地图）、normal（标准地图）、terrain（地形图）。

  示例代码如下：

  ```screen
  <fragment
      android:id="@+id/mapfragment_circledemo"
      android:name="com.huawei.hms.maps.SupportMapFragment"
      android:layout_width="match_parent"
      android:layout_height="500dp"
      map:mapType="normal"
      map:cameraTargetLng="151.20689"/>
  ```
