# 码值解析

扫码返回数据格式统一为NSDictionary，包含码在输入图片中的坐标、码的原始数据、码的制式、结构化数据、zoomValue等信息。多码结果包含多个NSDictionary数据。

JSON键值对格式如下，例如：

```
{
    // 码图角点坐标位置
    ResultPoint = (
        {
            posX = "323.595001";
            posY = "600.075012";
        },
        {
            posX = "321.975006";
            posY = "316.575012";
        },
        {
            posX = "607.905029";
            posY = "327.1050011";
        },
        {
            posX = "609.525024";
            posY = "610.605042";
        }
    );
    // 曝光值
    exposureAdjustmentValue = 0;
    // 码制式
    formatValue = "QR_CODE";
    // 放大倍数
    zoomValue = 1.0;
    // 码场景类型
    sceneType = WebSite;
    // 码值
    text = ssssss;
    // 码场景
    parserDic = {
        sceneType = WebSite;
        url = "https://www.huawei.com"
    }
}
```

|调用模式|返回对象|包含内容|
|:-------------------|:---------------|:--------------------------------------------------------------------------------------------------------------------|
|Default View Mode|NSDictionary|原始码值text 码制式formatValue 码场景结构化数据parserDic 码在图片中的位置ResultPoint 码场景类型sceneType 放大倍数zoomValue 曝光值exposureAdjustmentValue|
|Customized View Mode|NSDictionary|原始码值text 码制式formatvalue 码场景结构化数据parserDic 码在图片中的位置ResultPoint 码场景类型sceneType 放大倍数zoomValue 曝光值exposureAdjustmentValue|
|Bitmap Mode|NSDictionary（单码）|原始码值text 码制式formatvalue 码场景结构化数据parserDic 码在图片中的位置ResultPoint 码场景类型sceneType 放大倍数zoomValue 曝光值exposureAdjustmentValue|
|Bitmap Mode|NSArray（多码）|数组内包含一个或多个NSDictionary，NSDictionary内数据与单码相同。|

1. zoomValue：焦距调整倍数，您需要根据此数值调整相机焦距，具体参见[相机扫码场景](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-bitmap-camera-0000001050172408)。

   例如，您的应用需要获取SMS或Wi-Fi的结构化数据，可参考如下示例代码：

   ```
   -(void) parseResult(NSDictionary *result) {
       // 针对字段内容获取数据
       if ([[result objectForKey:@"sceneType"] isEqualToString:@"SMS"]) {        
           NSDictionary *parserDic = [result objectForKey:@"parserDic"];
           NSString *text = [parserDic objectForKey:@"text"];
           NSString *body = [parserDic objectForKey:@"body"];      
           NSString *number = [parserDic objectForKey:@"number"];   
       } else if ([[result objectForKey:@"sceneType"] isEqualToString:@"Wi-Fi"]){
           NSDictionary *parserDic = [result objectForKey:@"parserDic"];
           NSString *text = [parserDic objectForKey:@"text"];
           NSString *password = [parserDic objectForKey:@"pass"];        
           NSString *ssidNumber = [parserDic objectForKey:@"ssid"];      
           NSString *type = [parserDic objectForKey:@"type"];    
       }
   }
   ```
