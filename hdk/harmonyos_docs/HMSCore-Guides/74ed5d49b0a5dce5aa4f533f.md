# 体重

此数据类型记录用户在一段时间内的体重。

## OAuth权限

联盟卡片申请的权限名称：健康数据 > 体脂数据

* 读权限：Scopes.HEALTHKIT_HEIGHTWEIGHT_READ
* 写权限：Scopes.HEALTHKIT_HEIGHTWEIGHT_WRITE

## 原子采样明细数据类型

* 名称：com.huawei.instantaneous.body_weight
* Android SDK类型常量：DataType.DT_INSTANTANEOUS_BODY_WEIGHT

|body_weight|体重|Field.FIELD_BODY_WEIGHT|double|M|千克|[10.0,250.0]|
|bmi|身体质量指数|Field.FIELD_BMI|double|O|千克/平方米|[1.0, 200.0]|
|body_fat|体脂量|Field.FIELD_BODY_FAT|double|O|公斤|[10.0,250.0]|
|body_fat_rate|体脂率|Field.FIELD_BODY_FAT_RATE|double|O|百分比|[1.0,49.0]|
|muscle_mass|肌肉量|Field.FIELD_MUSCLE_MASS|double|O|公斤|(0.1, 150)|
