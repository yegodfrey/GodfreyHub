# 概述

配置是包含变量、条件、代码、分组、版本和可视化埋点的整体设置文件，是可以被App、浏览器客户端下载并执行的策略文件。

您需要在使用DTM之前创建一个配置以实现对资源的管理，因此在进行其他操作之前您必须创建配置，详情请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-create-configuration-0000001061539771)。

#### 功能介绍

“配置”页面的功能包括：

      * [导入配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-configuration-operation-procedure-0000001090991875#section9800334134714)：您可以将本地的配置数据直接导入以实现配置数据的快速同步。
      * [导出配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-configuration-operation-procedure-0000001090991875#section1625415635211)：您可以对配置中工作区的数据和任意版本进行导出。
      * [编辑配置](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-configuration-operation-procedure-0000001090991875#section048142115313)：您可以对配置名称及操作记录存储时间进行修改。
      * [关闭服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/ios-configuration-operation-procedure-0000001090991875#section75701019105910)：您可以关闭动态标签管理服务，同时将删除所有配置和修改记录。
