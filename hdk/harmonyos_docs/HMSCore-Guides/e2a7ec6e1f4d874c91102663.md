# 地理编码

## 正地理编码

根据地址获取地点的空间坐标，如经纬度，最多返回10条记录。

具体实现请参见[正地理编码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-forward-geo-0000001050163921)。

## 逆地理编码

根据经纬度获取附近200m内地点的详细地址，最多返回11条记录。

具体实现请参见[逆地理编码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/webapi-reverse-geo-0000001050161968)。
