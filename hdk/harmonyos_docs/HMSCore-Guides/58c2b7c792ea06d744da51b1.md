# 取消授权

在实现[获取用户授权](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-add-permissions-0000001228903727)后，为了提升应用隐私安全，建议开发者为应用提供入口，供用户取消对应用的授权。  
![](https://media:901788166624508586)  
通过调用取消授权可以取消用户的华为账号对该应用的授权，调用静默登录会报2002错误，重新登录会展示授权界面进行授权。

取消授权请参见[华为账号取消授权](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-cancelauthorization-0000001197310551)。
