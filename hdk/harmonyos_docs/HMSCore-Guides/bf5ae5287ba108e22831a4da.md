# 文件评论

## 场景介绍

华为云空间服务支持用户对云端文件进行评论，并对评论进行查看、更新和删除操作。

## 开发前提

1、请确认您已完成[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/config-agc-0000001050185569)。

2、在进行开发之前，您可以下载[华为云空间客户端示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/client-sample-code-0000001050114484)进行快速体验。

## 构造Drive对象

调用[Drive.Builder.build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-builder-0000001050124056#section17968156193912)接口构造Drive对象。

```screen
private Drive buildDrive() {  
    Drive service = new Drive.Builder(CredentialManager.getInstance().getCredential(), context).build();  
    return service;  
}
```

## 创建文件评论

调用[Comments.Create](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-comments-create-0000001050124066)接口创建文件评论：

```screen
/**
 * 创建文件评论
 *
 * @param fileId 文件id
 */
private Comment createComments(String fileId) {
    Comment comment = null;
    Drive drive = buildDrive();
    try {
        Comment content = new Comment();
        content.setDescription("interface test");
        content.setCreatedTime(new DateTime(System.currentTimeMillis()));
        comment = drive.comments().create(fileId, content).setFields("*").execute();
    } catch (Exception ex) {
        Log.e(TAG, "createComments error: " + ex.toString());
    }
    return comment;
}
```

## 获取文件评论列表

调用[Comments.List](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-comments-list-0000001050126019)接口获取文件评论列表：

```screen
/**
 * 获取文件评论列表
 *
 * @param fileId 文件id
 */
private List<Comment> listComments(String fileId) {
    Drive drive = buildDrive();
    ArrayList<Comment> commentArrayList = new ArrayList<>();
    String nextCursor = null;
    try {
        Drive.Comments.List request = drive.comments().list(fileId);
        do {
            if (nextCursor != null) {
                request.setCursor(nextCursor);
            }
            CommentList commentList = request.setPageSize(100).setFields("*").execute();
            ArrayList<Comment> comments = (ArrayList<Comment>) commentList.getComments();
            if (comments == null) {
                break;
            }
            commentArrayList.addAll(comments);
            nextCursor = commentList.getNextCursor();
        } while (!StringUtils.isNullOrEmpty(nextCursor));
    } catch (IOException e) {
        Logger.e(TAG, "comments list error: " + e.toString());
    }
    return commentArrayList;
}
```

## 获取文件评论详情

调用[Comments.Get](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-comments-get-0000001050124068)接口获取文件评论详情：

```screen
/**
 * 获取文件评论详情
 *
 * @param fileId 文件id
 * @param commentId 评论id
 */
private Comment getComments(String fileId, String commentId) {
    Comment comment = null;
    Drive drive = buildDrive();
    try {
        comment = drive.comments().get(fileId, commentId).setFields("*").execute();
        Log.d(TAG, "comment: " + comment.getDescription());
    } catch (Exception ex) {
        Log.e(TAG, "getComments error: " + ex.toString());
    }
    return comment;
}
```

## 更新文件评论

调用[Comments.Update](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-comments-update-0000001050124070)接口更新文件评论：

```screen
/**
 * 更新文件评论
 *
 * @param fileId 文件id
 * @param commentId 评论id
 */
private void updateComments(String fileId, String commentId) {
    Drive drive = buildDrive();
    try {
        Comment content = new Comment();
        content.setDescription("update interface test");
        drive.comments().update(fileId, commentId, content).execute();
    } catch (Exception ex) {
        Log.e(TAG, "updateComments error: " + ex.toString());
    }
}
```

## 删除文件评论

调用[Comments.Delete](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-comments-delete-0000001050126017)接口删除文件评论：

```screen
/**
 * 删除文件评论
 *
 * @param fileId 文件id
 * @param commentId 评论id
 */
private void deleteComments(String fileId, String commentId) {
    Drive drive = buildDrive();
    try {
        drive.comments().delete(fileId, commentId).execute();
    } catch (Exception ex) {
        Log.e(TAG, "deleteComments error: " + ex.toString());
    }
}
```

> 注意
>
> 文件评论接口是联网耗时接口，需要放在子线程中调用。
