# 活动识别开发

#### 概述

如果您的应用需要获取设备的运动状态，例如：步行、跑步、骑自行车等。可以通过以下两种方式获取设备的运动状态：

* 方式一：通过调用活动状态识别更新方法（[createActivityIdentificationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section99642060200)）主动获取当前设备的运动状态。您可以设置检测的时间间隔，以毫秒为单位，检测间隔时间越长，活动检测越少，检测间隔时间越短，活动检测越频繁；调用[deleteActivityIdentificationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section18411141614334)方法即可移除活动识别更新。
* 方式二：通过调用活动状态转换方法（[createActivityConversionUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section189622611204)）监听当前设备的活动状态转换，监听的时间亮屏是5秒，灭屏是200秒。您可以选定需要监听的运动状态，点击[Constant-values](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/constant-values-0000001050746179#section1569121418414)查看所有的运动状态；调用[deleteActivityConversionUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section17434718321)方法即可移除监听。  

#### 约束条件

您需要确保您的设备已经下载并安装了HMS Core（APK），并将Location Kit的SDK集成到您的项目中。有关详细信息，请参见[开发准备](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/config-agc-0000001057629153)。以下仅为代码片段，详情请参见[示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Examples/sample-code-0000001050986087#section15695165913920)。

活动识别支持的手机内存（模拟机的支持情况不在如下范围内）：3G以上。

如果您想提高活动识别的成功率，建议插SIM卡并打开5G/4G/3G/2G网络开关，活动识别的IN_VEHICLE、ON_BICYCLE模式使用到了cell（基站）信息，与移动数据网络的开启有一定的关系。目前海外版本手机活动识别不支持骑自行车和乘车。  

#### 指定应用权限

* 在Android 10以下版本使用活动识别需要在"AndroidManifest.xml"文件中配置以下权限：

  ```
  <uses-permission android:name="com.huawei.hms.permission.ACTIVITY_RECOGNITION"/>
  ```

* 在Android 10及以上版本中，需要在"AndroidManifest.xml"文件中配置以下权限：

  ```
  <uses-permission android:name="android.permission.ACTIVITY_RECOGNITION" />
  ```

#### 注册静态广播

示例代码中活动识别服务的活动状态更新信息需要广播接收，因此需要在"AndroidManifest.xml"文件中注册广播接收器。

```
<!--注册活动识别服务广播接收器-->
<receiver
    android:name=".location.fusedlocation.LocationBroadcastReceiver"
    android:exported="true">
    <intent-filter>
        <action android:name="com.huawei.hmssample.location.LocationBroadcastReceiver.ACTION_PROCESS_LOCATION" />
    </intent-filter>
</receiver>
```

#### 初始化活动识别客户端

请在主线程中声明[ActivityIdentificationService](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183)类对象，传入Context或Activity类型参数。

```
"Java"
private PendingIntent pendingIntent;
private ActivityIdentificationService activityIdentificationService;
// 获取activityIdentificationService实例
activityIdentificationService = ActivityIdentification.getService(this);
// 获取PendingIntent对象
pendingIntent = getPendingIntent();
```

```
"Kotlin"
private var pendingIntent: PendingIntent? = null
private var activityIdentificationService: ActivityIdentificationService? = null
// 获取activityIdentificationService实例
activityIdentificationService = ActivityIdentification.getService(this)
// 获取PendingIntent对象
pendingIntent = getPendingIntent()
```

#### 识别活动状态

首先需要您调用活动识别状态更新接口，用于检测用户当前的状态是步行、骑自行车或静止等。

1. 新建参数PendingIntent。  

   ```
   "Java"
   // 获取自定义静态广播类LocationBroadcastReceiver关联的PendingIntent
   private PendingIntent getPendingIntent() {
       Intent intent = new Intent(this, LocationBroadcastReceiver.class);
       intent.setAction(LocationBroadcastReceiver.ACTION_PROCESS_LOCATION);
       if (Build.VERSION.SDK_INT <= Build.VERSION_CODES.R) {
           return PendingIntent.getBroadcast(this, 0, intent, PendingIntent.FLAG_UPDATE_CURRENT);
       } else {
           // 针对android12及以上设备需要主动配置pendingIntent的可变性，默认配置PendingIntent.FLAG_MUTABLE
           // 如果compileSdkVersion为30及以下，可将PendingIntent.FLAG_MUTABLE用 1<<25 替换
           // buildToolsVersion为31及以上才可使用PendingIntent.FLAG_MUTABLE
           return PendingIntent.getBroadcast(this, 0, intent,
               PendingIntent.FLAG_UPDATE_CURRENT | PendingIntent.FLAG_MUTABLE);
       }
   }
   ```

   ```
   "Kotlin"
   // 获取自定义静态广播类LocationBroadcastReceiver关联的PendingIntent
   private fun getPendingIntent(): PendingIntent? {
       val intent = Intent(this, LocationBroadcastReceiver::class.java)
       intent.action = LocationBroadcastReceiver.ACTION_PROCESS_LOCATION
       return if (Build.VERSION.SDK_INT <= Build.VERSION_CODES.R) {
           PendingIntent.getBroadcast(this, 0, intent, PendingIntent.FLAG_UPDATE_CURRENT)
       } else {
           // 针对android12及以上设备需要主动配置pendingIntent的可变性，默认配置PendingIntent.FLAG_MUTABLE
           // 如果compileSdkVersion为30及以下，可将PendingIntent.FLAG_MUTABLE用 1<<25 替换
           // buildToolsVersion为31及以上才可使用PendingIntent.FLAG_MUTABLE
           PendingIntent.getBroadcast(
               this,
               0,
               intent,
               PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_MUTABLE
           )
       }
   }
   ```

2. 发起活动识别更新请求。  
   通过调用[createActivityIdentificationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section99642060200)(long detectionIntervalMillis, PendingIntent callbackIntent)方法发起活动识别更新请求并监听结果回调。

   ```
   "Java"
   // 发起活动识别请求
   activityIdentificationService.createActivityIdentificationUpdates(5000, pendingIntent)
       // 请求成功监听回调
       .addOnSuccessListener(new OnSuccessListener<Void>() {
           @Override
           public void onSuccess(Void aVoid) {
               // TODO：发起活动识别成功处理
           }
       })
       // 请求失败监听回调
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {
               // TODO：发起活动识别失败处理
           }
       });
   ```

   ```
   "Kotlin"
   // 发起活动识别请求
   activityIdentificationService!!.createActivityIdentificationUpdates(
       5000,
       pendingIntent
   )
       // 请求成功监听回调
       .addOnSuccessListener {
           // TODO：发起活动识别成功处理
       }
       // 请求失败监听回调
       .addOnFailureListener { e ->
           // TODO：发起活动识别失败处理
       }
   ```

   参数说明  

   |参数|类型|描述|备注|
   |:----------------------|:------------|:--------------------------------------------|:-------------------------------------------|
   |detectionIntervalMillis|long|活动检测更新间隔，单位：毫秒，默认值为30000毫秒；|值设置越大，活动检测越少，值设置越小，活动检测越频繁|
   |callbackIntent|PendingIntent|每个活动识别请求关联的pendingIntent，按时间间隔将活动识别结果通过广播通知用户|构造PendingIntent时需设置Class、Action，不能构造空Intent。|

3. 获取活动识别结果

                       activityIdentificationResponse.getActivityIdentificationDatas();

4. 移除活动识别更新。  
   在使用完活动识别后需要进行移除操作。调用[deleteActivityIdentificationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section18411141614334)(PendingIntent pendingIntent)移除活动识别定时监听，参数PendingIntent必须与[createActivityIdentificationUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section99642060200)(long detectionIntervalMillis, PendingIntent callbackIntent)参数里的PendingIntent是同一个。

#### 监听活动转换

活动转换是指检测一种活动状态转换到另一种活动状态的过程，例如用户从走路状态转换到骑自行车状态。活动转换可以让应用通过调用[createActivityConversionUpdates](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityidentificationservice-0000001050986183#section189622611204)([ActivityConversionRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/activityconversionrequest-0000001050986181) request, PendingIntent pendingIntent)方法获取用户活动状态变化。

1. 设置监听活动转换请求参数。  

   ```
   "Java"
   // 创建一个静止状态进入活动转换信息对象
   ActivityConversionInfo activityConversionInfoStillEnter = new ActivityConversionInfo(
       ActivityIdentificationData.STILL, ActivityConversionInfo.ENTER_ACTIVITY_CONVERSION);
   // 创建一个静止状态退出活动转换信息对象
   ActivityConversionInfo activityConversionInfoStillExit = new ActivityConversionInfo(
       ActivityIdentificationData.STILL, ActivityConversionInfo.EXIT_ACTIVITY_CONVERSION);
   List<ActivityConversionInfo> activityConversionInfos = new ArrayList<>();
   activityConversionInfos.add(activityConversionInfoStillEnter);
   activityConversionInfos.add(activityConversionInfoStillExit);
   // 创建一个活动转换请求体实例
   ActivityConversionRequest request = new ActivityConversionRequest();
   request.setActivityConversions(activityConversionInfos);
   ```

   ```
   "Kotlin"
   // 创建一个静止状态进入活动转换信息对象
   val activityConversionInfoStillEnter = ActivityConversionInfo(
       ActivityIdentificationData.STILL,
       ActivityConversionInfo.ENTER_ACTIVITY_CONVERSION
   )
   // 创建一个静止状态退出活动转换信息对象
   val activityConversionInfoStillExit = ActivityConversionInfo(
       ActivityIdentificationData.STILL,
       ActivityConversionInfo.EXIT_ACTIVITY_CONVERSION
   )
   val activityConversionInfos: MutableList<ActivityConversionInfo> =
       ArrayList()
   activityConversionInfos.add(activityConversionInfoStillEnter)
   activityConversionInfos.add(activityConversionInfoStillExit)
   // 创建一个活动转换请求体实例
   val request = ActivityConversionRequest()
   request.activityConversions = activityConversionInfos
   ```

   ```

   task.addOnSuccessListener(new OnSuccessListener<Void>() {
       @Override
       public void onSuccess(Void aVoid) {

       }
   })
       // 任务失败监听回调
       .addOnFailureListener(new OnFailureListener() {
           @Override
           public void onFailure(Exception e) {

           }
       });

      activityIdentificationService!!.createActivityConversionUpdates(request, pendingIntent)

       // TODO：请求活动转换成功处理

       // 任务失败监听回调

           // TODO：请求活动转换失败处理
       })
   ```

   参数说明  

   |参数|类型|描述|备注|
   |:------------|:------------------------|:-------------------------------------------------|:-------------------------------------------|
   |request|ActivtiyConversionRequest|活动转换请求参数，设置需要监听的活动状态（行走、静止等）及相关活动转换进入、退出状态。|构造的活动转换请求体|
   |pendingIntent|PendingIntent|每个活动过渡请求关联的pendingIntent，当检测到活动状态发现变化，将结果通过广播通知用户。|构造PendingIntent时需设置Class、Action，不能构造空Intent。|
