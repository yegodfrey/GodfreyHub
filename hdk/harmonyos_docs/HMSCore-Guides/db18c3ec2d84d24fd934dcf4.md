# 查询文件历史版本

#### 场景介绍

华为云空间服务支持用户查询云端文件的历史版本，并且对文件的历史版本进行查看、更新和删除操作。  
![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20250916154826.57106345904660380391037568971544:50001231000000:2800:459149982F77B047AA91B6CF23059AEAB34D767A644FF915CF42C92CA37CCA86.png)  
1. historyVersion相关接口仅支持安全策略更新后的用户使用。若调用About.get接口查询用户信息时，返回的needUpdate字段为true，则表明该用户未进行安全策略更新。建议开发者针对此类用户做相应的提醒或处理。
2. 安全策略更新由云空间服务器后台触发，开发者不可单独基于用户触发安全策略更新。  

#### 构造Drive对象

调用[Drive.Builder.build](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-builder-0000001050124056#section17968156193912)接口构造Drive对象。

```
private Drive buildDrive() {  
    Drive service = new Drive.Builder(CredentialManager.getInstance().getCredential(), context).build();  
    return service;
}
```

#### 获取文件历史版本列表

调用[HistoryVersions.List](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-historyversions-list-0000001050179045)接口获取文件历史版本列表：

```
/**
 * 获取文件历史版本列表
 *
 * @param fileId 文件id
 */
private HistoryVersionList listHistoryVersions(String fileId) {
    Drive drive = buildDrive();
    HistoryVersionList historyVersionList = null;
    if (drive == null) {
        Logger.e(TAG, "listHistoryVersions error: drive is null.");
        return null;
    }
    try {
        historyVersionList = drive.historyVersions().list(fileId).setFields("*").execute();
    } catch (Exception ex) {
        Logger.e(TAG, "listHistoryVersions error: " + ex.toString());
    }
    return historyVersionList;
}
```

#### 获取文件历史版本详情

调用[HistoryVersions.Get](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-historyversions-get-0000001050418967)接口获取文件历史版本详情：

```
/**
 * 获取文件历史版本详情
 *
 * @param fileId 文件id
 * @param historyVersionId 历史版本id
 */
private HistoryVersion getHistoryVersions(String fileId, String historyVersionId) {
    Drive drive = buildDrive();
    if (drive == null) {
        Logger.e(TAG, "getHistoryVersions error: drive is null.");
        return null;
    }
    HistoryVersion historyVersion = null;
    try {
        historyVersion = drive.historyVersions().get(fileId, historyVersionId).execute();
    } catch (Exception ex) {
        Logger.e(TAG, "getHistoryVersions error: " + ex.toString());
    }
    return historyVersion;
}
```

#### 更新文件历史版本

调用[HistoryVersions.Update](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-historyversions-update-0000001050268280)接口更新文件历史版本：

```
/**
 * 更新文件历史版本
 *
 * @param fileId 文件id
 * @param oldHistoryVersion 待更新的历史版本
 */
private void updateHistoryVersions(String fileId, HistoryVersion oldHistoryVersion) {
    Drive drive = buildDrive();
    if (drive == null) {
        Log.e(TAG, "updateHistoryVersions error: drive is null.");
        return;
    }
    if (oldHistoryVersion == null) {
        Log.e(TAG, "updateHistoryVersions error: oldHistoryVersion is null.");
        return;
    }
    try {
        HistoryVersion historyVersion = new HistoryVersion();
        historyVersion.setKeepPermanent(!oldHistoryVersion.getKeepPermanent());
        drive.historyVersions().update(fileId, oldHistoryVersion.getId(), historyVersion).execute();
    } catch (Exception ex) {
        Log.e(TAG, "updateHistoryVersions error: " + ex.toString());
    }
}
```

#### 删除文件历史版本

调用[HistoryVersions.Delete](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/client-drive-historyversions-delete-0000001050176942)接口删除文件历史版本：

```
/**
 * 删除文件历史版本
 *
 * @param fileId 文件id
 * @param historyVersionId 历史版本id
 */
private void deleteHistoryVersions(String fileId, String historyVersionId) {
    Drive drive = buildDrive();
    if (drive == null) {
        Logger.e(TAG, "deleteHistoryVersions error: drive is null.");
        return;
    }
    try {
        drive.historyVersions().delete(fileId, historyVersionId).execute();
    } catch (Exception ex) {
        Logger.e(TAG, "deleteHistoryVersions error: " + ex.toString());
    }
}
```
