# 转化分析

## 功能概述

归因分析用来衡量待归因事件对目标转化事件的转化贡献。通过定义目标转化事件和待归因事件，并选择归因模型，精准还原每次转化的贡献分布，帮您优化资源配置。

转化分析当前支持广告归因，广告归因支持营销渠道、广告系列或广告任务对目标转化事件的贡献率，可帮助衡量不同渠道、广告系列或任务的转化效果。

## 典型应用场景

识别营销渠道转化效果。

## 功能详述

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 行为分析 > 转化分析"进入转化分析页面。
4. 查看转化分析报告，详情请参见[查看转化分析报告](#section18920414144719)。
5. 查看广告归因分析事件详情，详情请参见[查看广告归因分析报告](#section1841105816512)。

### 查看广告归因分析报告

广告归因报告支持按营销渠道、广告系列、广告任务、广告素材维度查看，包括指定时间段内不同营销渠道、广告系列、广告任务、广告素材的转化事件的转化数量趋势，转化数和贡献率指标，可帮助衡量不同渠道、广告系列、广告任务、广告素材的转化效果。

1. 点击"转化分析"页面中的转化事件名称，跳转到转化事件归因分析详情页面。
2. 点击"广告归因"，可查看对应的转化事件的广告归因报告。

   默认展示包括营销渠道、广告系列、广告任务、广告素材的归因报告，您选择分析维度查看对应的归因报告。其中营销渠道为必选维度不能关闭，其他维度可选择关闭不进行查看。另外在表格右上方点击"下载"，可下载对应的归因报告数据。

   针对[INAPPPURCHASE](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-automatic-event-collection-0000001051757143#ZH-CN_TOPIC_0000001055544428__li1517341211531)和[COMPLETEPURCHASE](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-predefined-events-general-0000001051997159#ZH-CN_TOPIC_0000001054825941__li17848725112414)付费事件，报告中增加"收入"和"收入贡献率"指标的展示，以了解不同广告带来的收入，衡量其价值。
