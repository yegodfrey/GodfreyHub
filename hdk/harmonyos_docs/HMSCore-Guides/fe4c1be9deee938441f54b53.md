# 业务介绍

华为支付服务集成了支付并引导签约能力，可以为商户和用户提供在支付完成后，可以快速完成代扣签约的通道。  
![](https://media:801772763969333098)  
该能力目前仅对受邀商户开放。  

#### 应用场景

* 商城购物场景 在APP应用商城选购完商品支付后，可以提示用户签约，代扣签约完成后可以减少后续购买重复输入密码操作。
