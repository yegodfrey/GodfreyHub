# 申请权限

#### 申请权限

* 开发者可以基于业务场景申请数据，在获得用户同意后，调用相应接口，获取用户帐号的相关信息。面向应用开放的数据如下所示：  

  |华为帐号服务数据|面向应用|
  |:-------|:--------------|
  |头像|所有应用|
  |昵称|所有应用|
  |手机号|HarmonyOS应用/元服务|

* 申请数据需满足"合法、正当、必要"原则，业务场景满足《[常见类型移动互联网应用程序必要个人信息范围规定](http://www.cac.gov.cn/2021-03/22/c_1617990997054277.htm)》中对必要个人信息的定义。  

#### 头像昵称权限申请流程

1. 登录[华为开发者联盟](https://developer.huawei.com/consumer/cn/console#/scopeManage)，选择"管理中心"。
2. 菜单选择"授权管理"，进入页面后，点击左上角下拉框确认待授权项目，选择对应的应用名称（若应用名称重复，请进入凭证页依据客户端ID、创建时间等信息确定待授权应用），选择"华为帐号服务"，在公开权限中选择profile，点击"添加"。![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230720194209.21935907193200875128475257884391:50001231000000:2800:B2EEA23909A5C69EAE462101D8FCEBB239B128AF7CC9F2166930BE41A84F59A0.png?needInitFileName=true?needInitFileName=true?needInitFileName=true)
3. 添加完成后对应权限的状态显示为"已获取"，支持点击"取消"按钮取消该权限。
