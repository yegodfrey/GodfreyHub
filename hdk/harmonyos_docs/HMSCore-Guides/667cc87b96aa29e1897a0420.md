# IAB TCF v2.0用户同意信息传递

IAB Europe与IAB Tech Lab合作，于2019年8月21日宣布[透明度和同意框架2.0版本（TCF v2.0）](https://iabeurope.eu/tcf-2-0/)上线。鲸鸿动能平台已于2020年9月18日加入TCF v2.0的全球供应商列表（GVL），供应商ID为856。

鲸鸿动能平台不强制要求合作伙伴集成TCF v2.0。本文介绍鲸鸿动能平台如何与已经集成或者将要集成TCF v2.0的合作伙伴进行交互，因此不适用于不集成TCF v2.0的合作伙伴。

媒体App不支持TCF v2.0，但依然可以通过Consent SDK向鲸鸿动能平台传递用户同意信息，详见[征求用户意见](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-consent-settings-0000001075342977)。

如果您要集成TCF v2.0，请参见下文中的信息，了解鲸鸿动能平台将如何根据TCF v2.0的透明度和同意字符串（TC String）的内容对广告请求中包含的数据进行互操作。鲸鸿动能平台会不定期更新这些信息。

媒体App需要加入同意管理平台（以下简称CMP）或者注册CMP才能与鲸鸿动能平台通过TCF v2.0进行合作，其他SSP/DSP以及三方分析平台则需要注册成为供应商。  

#### 目的

鲸鸿动能平台在注册成为TCF v2.0供应商时所申明的目的与法律基础如下表所示。为了确保鲸鸿动能平台能够顺利通过TCF v2.0与您合作，请参见下方表格中鲸鸿动能平台对不同目的同意结果的不同策略。

上文中所说的"鲸鸿动能平台通过TCF v2.0与您合作"，包括但不限于：

* 在鲸鸿动能平台对竞价请求进行出价。
* 通过鲸鸿动能平台向需求方发起竞价请求。
* 使用三方分析平台来跟踪和分析广告效果。

|编号|目的/功能|法律基础|
|:----|:----------|:--------|
|目的1|在设备上存储/访问信息|用户同意|
|目的2|选择基本广告|用户同意或合法利益|
|目的3|创建个性化的广告画像|用户同意|
|目的4|投放个性化广告|用户同意|
|目的7|衡量广告效果|用户同意或合法利益|

#### TC String的使用

TC String包含了用户对各目的/特性的同意情况，鲸鸿动能平台支持的TC String遵循IAB Europe发布的TC String格式。针对不同用户对各目的的同意情况，鲸鸿动能平台将根据IAB Europe提供的[TCF Policy](https://iabeurope.eu/iab-europe-transparency-consent-framework-policies/)的要求对数据进行相应的使用与限制。

* 如果您是支持TCF v2.0的媒体App开发者，您可通过鲸鸿动能SDK中的[setConsent(String consent)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hwads-0000001050066833#section148121631162513)字段来向鲸鸿动能平台传递TC String，详情请参见[setConsent(String consent)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hwads-0000001050066833#section148121631162513)。  
  示例代码如下所示：

  ```
  "Java"
  // 设置TCF v2.0用户同意信息字符串
  RequestOptions requestOptions = HwAds.getRequestOptions();
  requestOptions.toBuilder().setConsent("tcfString").build();
  ```

  ```
  "Kotlin"
  // 设置TCF v2.0用户同意信息字符串
  var requestOptions: RequestOptions? = HwAds.getRequestOptions()
  requestOptions.toBuilder().setConsent("tcfString").build()
  ```

* 如果您是支持TCF v2.0的SSP或Ad Exchange提供商，平台可支持在广告/竞价请求中接收TC String，并根据TC String的同意情况处理用户个人数据。详细接口信息，请与您对接的鲸鸿动能平台相关人员获取。
* 如果您是支持TCF v2.0的DSP提供商，只有当TC String包含同意向您分享数据的信息，鲸鸿动能平台才会向您发送携带用户个人数据的竞价请求和TC String。如果TC String不同意向您分享数据，鲸鸿动能平台向您发送的竞价请求中将不会携带用户个人数据。详细接口信息，请从与您对接的鲸鸿动能平台相关人员获取。

#### 灵活的法律基础和媒体限制

[媒体限制](https://github.com/InteractiveAdvertisingBureau/GDPR-Transparency-and-Consent-Framework/blob/master/TCFv2/IAB Tech Lab - Consent string and vendor list formats v2.md#what-are-publisher-restrictions)：媒体可以对供应商使用各个目的的法律基础进行限制。如果媒体将某供应商使用某目的的法律基础限定为用户同意，而该供应商注册目的的法律基础为合法利益，则该供应商不能使用该目的；如果媒体将某供应商使用某目的的法律基础限定为用户同意，且该目的具有灵活性，而该供应商注册目的的法律基础默认为合法利益，则该供应商只能使用用户同意的结果判断是否使用该目的。

鲸鸿动能平台针对[目的2](#ZH-CN_TOPIC_0000001075694328__p973612378192)、[目的7](#ZH-CN_TOPIC_0000001075694328__p107373371191)、[目的9](#ZH-CN_TOPIC_0000001075694328__p173753720193)、[目的10](#ZH-CN_TOPIC_0000001075694328__p7738237191914)注册了灵活的法律基础，默认法律基础为合法利益，除非媒体将这些目的的法律基础限定为用户同意，否则鲸鸿动能平台将根据合法利益使用这些目的。鲸鸿动能平台针对[目的1](#ZH-CN_TOPIC_0000001075694328__p573663715193)、[目的3](#ZH-CN_TOPIC_0000001075694328__p12737113731915)、[目的4](#ZH-CN_TOPIC_0000001075694328__p107372371196)没有注册灵活的法律基础，所以始终需要按照用户同意的结果来使用这些目的。  

#### 广告竞价和个性化广告

IAB TCF v2.0逻辑适用于广告竞价请求。

如果要通过鲸鸿动能平台投放个性化广告，用户必须就[目的1](#ZH-CN_TOPIC_0000001075694328__p573663715193)、[目的3](#ZH-CN_TOPIC_0000001075694328__p12737113731915)和[目的4](#ZH-CN_TOPIC_0000001075694328__p107372371196)给予同意。

如果要通过鲸鸿动能平台向其他供应商投放个性化广告，用户必须就[目的1](#ZH-CN_TOPIC_0000001075694328__p573663715193)、[目的3](#ZH-CN_TOPIC_0000001075694328__p12737113731915)和[目的4](#ZH-CN_TOPIC_0000001075694328__p107372371196)给予同意之外，还必须同意向该供应商传递个人信息，否则该供应商不会收到带有用户个人信息的竞价请求。
