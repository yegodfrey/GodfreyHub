# 自定义概览

|----------------------------------------------------------------------------|-|
|分析服务中的自定义概览功能，可按照需要将您关注的指标、事件、漏斗转化情况等数据集中展示在一个报告中，灵活定制概览报告，便于您快速掌握核心指标数据的动态。| |

## 功能概述

在一款产品运营的过程中，不同角色关注的核心指标不同。例如销售人员主要关注收入情况，市场推广人员更看重新增和活跃用户数，产品经理则要分析各个环节的转化情况以不断促进产品优化。

自定义概览功能，可按照需求将需要关注的指标、事件、漏斗转化情况等数据集中展示在一个报告中，灵活定制概览报告，便于快速掌握核心指标数据的动态、提升运营效率。

## 功能详述

### 操作流程

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 概览 > 自定义概览"进入自定义概览报告页面。
4. 创建自定义概览。详情请参见[创建自定义概览](#section159110307145)。
5. 查看、编辑自定义概览。详情请参见[查看、编辑自定义概览](#section143412110348)。

### 创建自定义概览

1. 点击"创建概览"，弹出创建概览页面。
2. 输入自定义概览名称，根据实际需求设置是否为默认概览。并在"添加指标"页签下选择需要关注的指标，如新增用户数、活跃用户数、累计用户数。

3. 点击"添加卡片"，切换到"添加卡片"页签。

   在卡片区，自定义概览支持添加预置卡片、事件分析卡片及漏斗分析卡片，并支持关键词搜索。

> * 不同帐号下，只能查看到各自帐号创建的概览。

### 查看、编辑自定义概览

1. 点击概览名称下拉框，可自由切换想查看的自定义概览。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115216.85754007984753246631512898349293:50001231000000:2800:032AD123D7AE0D07277578851894E93B718ADBBA1406F16E4DCD58821F58B0B9.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
2. 点击右上方的展开控件，可编辑（添加/删除指标或卡片）、删除选定的自定义概览或者可将其设为默认概览展示。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115216.84845608740011050332200237941521:50001231000000:2800:659D4090FD5B5BEC617EAAAE04499D8B1598F0FD4560C0213273A1F263FF573C.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
3. 点击"添加过滤器"并完成设置，过滤器条件属性详情请参见[添加过滤器组件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/filter-introduction-0000001123199087)。且过滤器支持对卡片数据按照应用平台、应用名称、用户属性、受众和用户获取进行过滤从而做个性化分析。
4. 点击"日期"控件，选择需要查询的数据日期，可查看相应时间段下的卡片数据。
