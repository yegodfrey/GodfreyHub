# 通用  
  
#### 事件参数列表

            * kHAEventRegisterAccount

用户注册帐号时，上报此事件。可以分析用户来源，有针对性地优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRegistMethod | 注册方式 | String | 可选 | 用户的注册方式，如：邮箱、手机号、微信等。  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
            * kHAEventRegisterFailed

用户注册帐号失败时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRegistMethod | 注册方式 | String | 可选 | 用户的注册方式，如：邮箱、手机号、微信等。  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
            * kHAEventBindAccount

用户绑定其他类型帐号时上报此事件。分析用户的登录习惯，有针对性地制定运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户绑定的帐号类型，如：邮箱、手机号、微信等。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
            * kHAEventCompletePurchase

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamProductId | 商品ID | String | 必选 | 被添加到购物车中的商品ID。  
kHAParamProductName | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
kHAParamQuantity | 购买数量 | Long | 必选 | 用户准备购买的数量。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
kHAParamRevenue | 收入 | Double | 可选 | 本次交易给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamPlace | 位置ID | String | 可选 | 商品所在地标识。  
kHAParamBrand | 商品品牌 | String | 可选 | 关联的商品品牌。  
kHAParamCategory | 商品分类 | String | 可选 | 关联的商品分类。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
            * kHAEventCancelCheckout

用户已经下单，并开始支付，支付过程中，取消支付时，上报此事件。可用于分析用户流失原因。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamReason | 取消支付原因 | String | 必选 | 用户取消支付的原因。  
kHAParamStep | 结算步骤数 | String | 必选 | 标识用户当前处于结算过程中的第几个步骤。  
kHAParamRevenue | 收入 | Double | 可选 | 会给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
            * kHAEventVipClick

用户点击开通会员时，上报此事件，用于分析用户开通会员的场景。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---

kHAParamUserId | 用户ID | String | 可选 | 触发事件用户的ID。  
kHAParamUserLevel | 用户等级 | String | 可选 | 触发事件用户的等级。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
            * kHAEventVipFailed

用户开通会员失败时，上报此事件，用于分析用户开通失败的原因。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamVipFailed | 失败原因 | String | 可选 | 用户会员开通失败的原因。  
kHAParamUserId | 用户ID | String | 可选 | 触发事件用户的ID。  
kHAParamUserLevel | 用户等级 | String | 可选 | 触发事件用户的等级。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
            * kHAEventVipSuc

用户开通会员成功时，上报此事件。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamVIPType | VIP类型 | String | 可选 | 用户会员开通的会员类型，如：年度、月度会员。  
kHAParamVipExpireDate | VIP到期时间 | String | 可选 | 用户本次开通会员后的会员到期时间。  
kHAParamUserId | 用户ID | String | 可选 | 触发事件用户的ID。

kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。

kHAParamRemark | 内容简介 | String | 可选 | 用户点击查看的内容关键词或摘要。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。
