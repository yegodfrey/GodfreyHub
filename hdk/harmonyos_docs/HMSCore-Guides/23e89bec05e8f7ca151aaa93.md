# 读取历史数据

查询数据时，出于对用户的数据保护，只允许开发者查询在用户授权之后的数据。例如用户是在2022年2月14日授权，那么2022年2月14日之前的数据将不可查询。

如果需要查询用户授权前的数据，开发者需要得到用户"读取历史数据"相关的授权。  
![](https://media:901788166652989181)  
开发者在查询数据时设置的起始时间若早于历史数据开放时间，会导致调用接口失败，具体错误请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthstatuscodes-0000001050089560#section10673269124)：HISTORY_PERMISSIONS_INSUFFCIENT。

对于历史数据的开放，我们支持基于周、月、年三个时间粒度的开放策略，最多可以开放授权前一年的历史数据。建议开发者基于实际使用场景，最小化读取用户历史数据。  

|权限|权限描述|说明|
|:--------------------------------------|:-----------------|:---------------|
|Scopes.HEALTHKIT_HISTORYDATA_OPEN_WEEK|查看华为运动健康服务前一周的历史数据|只能读取用户授权前一周的历史数据|
|Scopes.HEALTHKIT_HISTORYDATA_OPEN_MONTH|查看华为运动健康服务前一月的历史数据|只能读取用户授权前一月的历史数据|
|Scopes.HEALTHKIT_HISTORYDATA_OPEN_YEAR|查看华为运动健康服务前一年的历史数据|只能读取用户授权前一年的历史数据|

![](https://media:901788166653069184)  
使用此功能的开发者，请集成Health Service Kit SDK 6.10.0.301及以上版本。

需要开发者完成以下操作：

1. 在[Health Service Kit](https://developer.huawei.com/consumer/cn/console#/openCard/AppService/1044)上申请"读取历史数据"的相关权限。
2. 在[获取用户授权时](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/add-permissions-0000001050069726)在scope中添加上述表格中的权限，供用户在登录华为账号之后为应用授予"读取历史数据"权限。
