# 地图类型

[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)目前支持两种地图类型：

* MAP_TYPE_NORMAL：标准地图。展示道路、建筑物以及河流等重要的自然特征。
* MAP_TYPE_NONE：空地图。没有加载任何数据的地图。

设置地图类型，请调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)对象的[setMapType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582#section3746134811217)方法，并传递[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)中定义的静态常量。

```java
// 设置标准地图类型
mHuaweiMap.setMapType(HuaweiMap.MAP_TYPE_NORMAL);
```
