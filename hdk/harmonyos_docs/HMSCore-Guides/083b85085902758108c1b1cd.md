# 自动采集事件

自动采集事件无需埋点，只需开启采集系统事件的开关（初始化时自动开启），即可实现此类事件的自动采集。

自动采集事件的事件ID是分析服务的保留字段，不能被复用。

事件ID | 说明  
---|---  
APPFIRSTOPEN | 用户首次打开Web应用时，上报该事件。  
ENTERSCREEN | 进入Web页面时触发此事件。 说明：  该事件中$CurActivityId、$CurActivityName、$CurrPageId、$PrePageId、$PrevActivityId和$PrevActivityName参数的值默认不带URL参数。该特性仅限Web平台支持，不涉及微信小程序。  
EXITSCREEN | 退出Web页面时触发此事件。 说明：  该事件中$CurActivityId、$CurActivityName、$CurrPageId、$PrePageId、$PrevActivityId和$PrevActivityName参数的值默认不带URL参数。该特性仅限Web平台支持，不涉及微信小程序。  
JOINABTASK | 当用户参与到某个A/B测试时，触发此事件。 说明：  上报此事件，您需要集成[A/B测试](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-abtest-introduction-0000001058210679)。 目前Web支持的AGC最新版本为@agconnect 1.3.1。  
LAUNCHAPP | 用户打开应用时，上报此事件。  
STOPANALYTICSCOLLECTION | 用户关闭采集事件时，上报此事件。 说明：  此事件为开发者设置[setAnalyticsEnabled](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-analytics-0000001050825689#section1644555762111)为false时或者[setRestrictionEnabled](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-analytics-0000001050825689#section069215373517)为true时SDK触发上报。该事件不会用于洞察报告。  
CAMPAIGNPUSHCLICK | 用户点击[智能运营](https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/introduction-0000001131819611)发送的营销Push消息时，上报此事件。 说明：  此事件仅中国大陆使用。

                * APPFIRSTOPEN

当用户安装或重新安装应用后首次启动时触发。此事件在用户首次使用应用时触发，不会在用户将应用下载到设备时触发。
