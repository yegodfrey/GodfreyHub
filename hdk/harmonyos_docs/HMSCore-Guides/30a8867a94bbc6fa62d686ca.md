# Matrix API

## 批量算路-步行

根据多组起终点坐标批量检索符合条件的步行路径规划方案。支持以下功能：

* 起点数乘以终点数需小于100。
* 支持150km以内的步行路径规划能力。
* 融入出行策略（时间最短、避免轮渡）。

具体使用方式请参见[批量算路-步行](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/matrix_api_walking-0000001232750655)。

## 批量算路-骑行

根据多组起终点坐标批量检索符合条件的骑行路径规划方案。支持以下功能：

* 起点数乘以终点数需小于100。
* 支持500km以内的骑行路径规划能力。
* 融入出行策略（时间最短、避免轮渡）。

具体使用方式请参见[批量算路-骑行](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/matrix_api_riding-0000001232510579)。

## 批量算路-驾车

根据多组起终点坐标批量检索符合条件的驾车路径规划方案。支持以下功能：

* 起点数乘以终点数需小于100。
* 支持未来出行规划。
* 支持根据实时路况进行合理路线规划。
* 支持多种路线偏好选择，如时间最短、避免经过收费的公路、避开高速公路、距离优先等。

具体使用方式请参见[批量算路-驾车](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/matrix_api_driving-0000001232832143)。
