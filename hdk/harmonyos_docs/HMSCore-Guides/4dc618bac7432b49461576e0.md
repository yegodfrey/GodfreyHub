# 业务介绍

华为支付服务针对平台商户给用户补贴的场景提供营销补差能力。

营销补差可以结合资金分账使用，在完成用户支付和平台补差后，平台商户可以按照与合作方的约定，将资金分给合作商户。具有以下优点：

灵活性高：订单是否参与营销补差，补差金额等都由商户自由定制。

资金占用少：可通过券、积分等形式完成营销活动后再通过补差完成后续资金补齐。

平台子商户收款体验好：平台类商户发起营销活动，可通过营销补差方式将订单营销活动补差金额转账给收单子商户，子商户基于订单金额发起分账（参见[资金分账](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/partner-alloc-0000001699022945)）。  

#### 场景介绍

平台商户举办营销活动的场景，在用户完成支付后，平台商户可以发起营销补差，将用户支付的资金和平台补贴的资金一并结算至收款商户。如下场景：

* 平台向用户发放由平台出资的满100减10元优惠券，用户领取了一张10元的优惠券。
* 用户购买2件商品订单总价100元，使用一张10元的优惠券，实际仅需支付90元。
* 平台可以利用补差接口，将优惠的10元补差给子商户，子商户账户一共入账为90元加10元等于100元。
* 子商户可以按100元为分账基数向相关分成方进行分账。

#### 资金计算规则

相关资金额度计算规则如下：

* 可分账回收金额 ≤ 分账金额
* 可补差回收金额 ≤ 补差金额
* 可退款金额 ≤ 订单金额  

#### 计算细则

分账金额

* 可分账金额（两者取小）

  ```
  可分账金额 ≤ MIN((订单金额 + 实际补差金额) * 最大可分账比例 - 已分账金额, 订单金额 + 实际补差金额 - 已退款金额 - 已补差回收金额 - 已分账金额)
  ```

<!-- -->

* 可分账回收金额

  ```
  可分账回收金额 ≤ 分账金额 - 已分账回收金额
  ```

补差回收金额

* 分账已完成

  ```
  可补差回收金额 ≤ 实际补差金额 - 已补差回收金额
  ```

<!-- -->

* 分账未完成（两者取小）

  ```
  可补差回收金额 ≤ MIN(实际补差金额 - 已补差回收金额, 订单金额 + 实际补差金额 - 已退款金额 - 已分账金额 - 已补差回收金额)
  ```

退款金额

* 分账已完成

  ```
  可退款金额 ≤ 订单金额 - 已退款金额
  ```

<!-- -->

* 分账未完成（两者取小）

  ```
  可退款金额 ≤ MIN（订单金额 - 已退款金额, 订单金额 + 实际补差金额 - 已退款金额 - 已分账金额 - 已补差回收金额）
  ```

  举例：平台商户举办满100元减10元的活动，用户实际支付90元，平台商户出资10元补差，华为支付服务将100元资金扣除手续费后结算至收款子商户。

  即订单金额为90元，实际补差金额为10元，待退款金额是否可退示例如下：  

  |已分账金额（元）|已退款金额（元）|待退款金额（元）|是否可退|
  |:-------|:-------|:-------|:---|
  |5|10|80以上|否|
  |5|10|80及以下|是|
  |50|10|40以上|否|
  |50|10|40及以下|是|
