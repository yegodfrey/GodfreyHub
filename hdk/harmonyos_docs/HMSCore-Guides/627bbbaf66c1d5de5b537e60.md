# 使用入门

#### 快速上手

在您正式开发应用之前，可以通过[codelab](https://developer.huawei.com/consumer/cn/codelabsPortal/carddetails/HMSSiteKit)快速体验一个应用的开发过程。  

#### 开发环境

* JDK 1.8及以上
* 安装[Android Studio](https://developer.android.com/studio) 3.6.1及以上

  * minSdkVersion 19及以上
  * targetSdkVersion 33（推荐）
  * compileSdkVersion 33（推荐）
  * Gradle 5.4.1及以上（推荐）
* 测试应用的设备：EMUI 3.0及以上的华为手机、平板或Android 5.1 \~ 13的非华为手机。

如果同时使用多个HMS Core的服务，则需要使用各个Kit对应的最大值。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-:|:----------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section47264296)、[创建项目](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section83893131911)、[开通付费](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section1177212364910)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section0592162815915)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section20336192018204)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section9339120162016)、[打开相关服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section477mcpsimp)、[获取API密钥。](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-agc-0000001050158579#section527610250284)。|
|2|[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-integrating-sdk-0000001050156628)|在开发应用前，您需要将HMS Core SDK集成到您的开发环境中。|
|3|[配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-config-obfuscation-scripts-0000001050158581)|编译APK前需要配置混淆配置文件，避免混淆HMS Core SDK导致功能异常。|
|4|[关键字搜索](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-keyword-search-0000001050156630)|通过指定的关键字和可选的地理范围，查询诸如旅游景点、企业和学校之类的地点。|
|4|[周边搜索](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-nearby-place--search-0000001050158585)|通过用户传入自己的位置，可以返回周边地点列表，继而通过获取到的SiteID，可以查询该地点的详细信息。|
|4|[地点详情](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-place-details-0000001050156636)|通过某一地点的Site ID来获取该地点的详细信息（如地点名称、地址详细信息、经纬度等），Site ID是地点的唯一标识符。|
|4|[地点搜索建议](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-search-suggestion-0000001050158591)|可用于在用户键入查询内容的时候，返回建议的查询结果，从而实现查询预测效果。|
|4|[Widget](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-widget-0000001050156642)|内置地点搜索建议功能的搜索组件。|
|4|[自动补全](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/autocomplete-0000001051810574)|根据输入的关键字返回预测的输入关键字和地点查询建议。|
|5|[开发后自检](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/pre-release-check-0000001050158597)|华为提供对应用自动检查的能力。|
|6|[上架申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/app-release-0000001238805213)|开发完成后需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中将应用信息补充完整并提交上架申请。|

华为还为您提供了高效的集成开发工具[HMS Toolkit](https://developer.huawei.com/consumer/cn/doc/development/Tools-Guides/overview-0000001050060881)，该工具提供了包括开发接入、免费真机调测、版本发布等端到端的接入HMS Core的工具链，助力您以更高的开发效率和更低的开发成本集成HMS Core服务，并打造出色的应用。

点击[这里](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/hms-toolkit-integrating-0000001152737941)了解HMS Toolkit集成Site Kit最佳实践。
