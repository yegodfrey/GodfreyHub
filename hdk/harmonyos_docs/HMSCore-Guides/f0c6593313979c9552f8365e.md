# 面向应用开放服务

## 简介

Health Service Kit是华为向开发者提供的运动健康数据开放平台，提供运动健康类应用和设备的数据汇聚、存储、分享能力。在符合为用户提供数据授权、取消授权的个人信息保护机制的前提下，为开发者提供数据读写的开放接口。

## 开放API类型

* Android JAVA API Android应用集成Android版本的Health Service Kit JAVA SDK，可以获取用户对数据的单独授权，读写运动健康数据。同时也可以实时获取连接手机的华为穿戴设备产生的实时数据，如实时步数。


* HarmonyOS JS API HarmonyOS应用集成HarmonyOS版本的Health Service Kit JS SDK，可以获取用户对数据的单独授权，读写运动健康数据。同时也可以实时获取连接手机的华为穿戴设备产生的实时数据，如实时心率。

* REST API 云侧开放能力既支持服务器应用，也支持移动应用。开发者使用REST API接入Health Service Kit数据平台，应用可以获取用户对数据的单独授权，读写运动健康数据。

## 使用场景

Health Service Kit开放丰富的API接口及数据类型，可按照不同开发场景，选择不同API与数据类型进行应用/服务开发。数据类型请参见[数据开放总览](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/data_description-0000001467889369)。

* 跨平台开发：若您的应用需要同时支持Android、iOS应用，或者需要支持微信小程序等WEB场景，优先建议使用Rest API，以便满足不同平台的体验一致性，提升开发效率。
* 鸿蒙应用开发：优先建议使用JS API。如果无法满足业务场景需要，您可以选择使用Rest API。


* Android移动应用：优先建议使用JAVA API。如果无法满足业务场景需要，您可以选择使用Rest API。

> 说明
>
> JAVA API包含基础与扩展能力。基础能力聚焦丰富的原子化数据类型开放；扩展能力适用于强调数据实时性的开发场景，也支持部分原子化数据开放。
>
> * 若应用/服务仅需使用原子化数据，推荐集成基础能力SDK；若功能依赖实时数据联动，推荐集成扩展能力SDK。
>
>
> * 若需要实现实时数据联动同时使用部分原子化运动健康数据，可优先集成扩展能力SDK。扩展能力支持的原子化数据请参见[扩展能力数据开放](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/data_description-0000001467889369#section1447381916192)；若在此基础上，您需要使用更丰富的原子化数据，则需集成扩展能力SDK+基础能力SDK。

## 华为运动健康服务申请接入

开发者申请华为运动健康服务数据权限时，需要满足一定资质要求，申请提交后平台对于不同类型的开发者也会开展相应的评审流程。申请注意事项及详细接入流程请参见[华为运动健康服务接入流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-access-process-0000001611092953)。
