# 选择子应用

1. 读卡器发送readerMatchValue给Applet，Applet选择对应的ADF文件。指令样例：

   ```screen
   80CA0080099F3506202004270001
   ```

   上述指令拼接伪码如下：

   ```screen
   String readerMatchValue; // 推卡json中的readerMatchValue字段
   /* 
      readerMatchValue的匹配模式
      9F1E：按照ReaderId匹配，
      9F35：按照ReaderType匹配
   */
   String tag = "9F35";
   String len = String.format(Locale.ENGLISH,"%02X", readerMatchValue.length()/2);
   String tlvStr = tag + len + readerMatchValue;
   String lc = String.format(Locale.ENGLISH,"%02X", tlvStr.length()/2);
   String cmd = "80CA0080" + lc + tlvStr;
   excuteCommand(cmd);
   ```

2. 成功则返回"9000"。否则终止读卡。
