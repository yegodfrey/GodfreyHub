# 指尖血糖数据

本章节提供通过华为Health Service Kit服务端REST API写入、获取用户指尖血糖数据的方法示例。指尖血糖数据类型com.huawei.instantaneous.blood_glucose有三个字段（level：血糖水平、measure_time：测量时机、sample_source：血糖标本来源），每个数据点代表单个瞬时血糖读数，详情请参见[血糖](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/blood-glucose-0000001177423531)。

血糖数据类型对应的Oauth权限为：

* 读权限：https://www.huawei.com/healthkit/bloodglucose.read
* 写权限：https://www.huawei.com/healthkit/bloodglucose.write

#### 写入指尖血糖数据

血糖数据通过SampleSet写入，需要先创建数据采集器DataCollector，然后将详细的血糖采样数据写入SampleSet。

1. 创建血糖数据采集器DataCollector。

   <br />

   HTTP请求，请参见[创建数据采集器](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacollectors_create-0000001050114852#section984123664716)接口

   ```
   POST
   https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors
   ```

#### 读取指尖血糖数据

通过聚合分组接口读取融合运动健康App后的血糖数据。

HTTP请求，请参见[采样数据明细查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/sampleset_polymerize_detailed-0000001050114864#section984123664716)接口

```
POST 
https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:polymerize
```

请求示例

```
POST 
https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:polymerize
```

请求体

```
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
{

        {
            "dataTypeName": "com.huawei.instantaneous.blood_glucose"
        }
    ],
    "startTime": 1600446040000,

}
```
