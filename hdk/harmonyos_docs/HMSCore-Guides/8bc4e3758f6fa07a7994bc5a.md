# 集成鲸鸿动能JavaScript API

若您需要在App的Web页面呈现广告，请集成鲸鸿动能JavaScript API。您可以根据您的需求场景选择不同的广告形式进行集成：[原生广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-js-native-0000001179595233)、[横幅广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-js-banner-0000001133635648)、[激励广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-js-rewarded-0000001133475864)、[插屏广告](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-js-interstitial-0000001179475321)。在集成鲸鸿动能JavaScript API之前，您需要先完成[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-integrating-sdk-0000001050066913)的操作。  

#### WebView集成JavaScript Bridge代码

```
mWebview = (WebView) findViewById(R.id.webView);
PPSJsBridge.init(new JsbConfig.Builder()
    // 调用enableUserInfo方法同步用户协议状态，同意为true，不同意为false
    .enableUserInfo(true)
    .enableLog(true)
    .build());
// WebView绑定JavaScript Bridge
bridge = new PPSJsBridge(mWebview);
```

#### H5页面集成鲸鸿动能JavaScript API代码

```
<script src="https://h5hosting.dbankcdn.com/cch5/pps-jssdk/mobile/ppsads.js"></script>
```

集成完成后，您需要在[鲸鸿动能媒体服务平台](https://developer.huawei.com/consumer/cn/service/ads/publisher/html/index.html?lang=zh)上选择"媒体管理 \> 设置媒体 \> 域名通行名单"配置域名通行名单，例如：www.huawei.com；并通过[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)联系华为运营人员配置相应权限。
