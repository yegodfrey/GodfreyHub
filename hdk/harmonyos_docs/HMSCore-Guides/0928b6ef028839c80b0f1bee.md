# 通过SDK添加会员卡代码样例

1. 创建你的会员卡实例。

   具体设置项请参见[开发者API文档](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/add-instance-0000001050158466)，示例代码不一一列举：
   > 说明
   >
   > 生成用户特有信息的实例前请先将模板推送至华为服务器，并在用户特有信息的实例中传入模板唯一标识PassStyleIdentifier。
   >
   > 推送模板可参考[服务端示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/java-sample-code-0000001050157448)。

   ```screen
   //PassObject定义可参考客户端示例代码
   PassObject.Builder passBuilder = PassObject.getBuilder();
   passBuilder.setStatus(PassStatus.getBuilder().setState("1"))
       .setOrganizationPassId("123")//实例唯一标识，在模板下唯一，如果未在fields.commonFields[key= cardNumber]定义则钱包详情页将取OrganizationPassId作为卡号
       .setPassStyleIdentifier("class123")//模板卡id
       .setPassTypeIdentifier("hwpass...")//AGC申请的服务号
       .setSerialNumber("12345")
       .addAppendFields(new ArrayList())
       .addCommonFields(new ArrayList())
       .passBuilder.addLocationList(new ArrayList())
       .addImageList(new ArrayList);
   //生成会员卡实例
   PassObject passObject = passBuilder.build();
   ```

   > 说明
   >
   > 创建会员卡实例时需要传入模板卡Id"PassStyleIdentifier"，商户开发者可参照上一章节"[定义模板信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-webpage-0000001050042334#section179891059101817)"先将模板传入华为服务器后再执行此步骤。

2. 将实例转化为JWE。

   开发者需要在自己后台服务器提供将会员卡实例JSON转化为JWE格式的功能，具体实现样例代码如下：

   ```screen
   // 在华为AppGallery Connect网站上注册的应用ID
   String appId = ConfigUtil.instants().getValue("gw.appid");
   //生成一个新的实例并将其绑定到用户
   JSONObject newInstance = JSONObject.parseObject(ConfigUtil
               .readFile("Replace with the instance JSON file to be created. For example: EventTicketInstance.json"));
   newInstance.put("iss", appId);
   String payload = newInstance.toJSONString();

   //您在AGC上申请服务时生成了一对密钥。在此使用该私钥。
   String jweSignPrivateKey = ConfigUtil.instants().getValue("servicePrivateKey");

   //生成JWE
   String jwe = JweUtil.generateJwe(jweSignPrivateKey, payload);
   System.out.println("JWE String: " + jwe + "\n");
   ```

   > 说明
   >
   > 以上代码引用但未实现的类（"ConfigUtil"，"JweUtil"）均可以在[服务器示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/java-sample-code-0000001050157448)中查看具体定义。

3. 创建CreateWalletPassRequest。

   ```screen
   CreateWalletPassRequest request = CreateWalletPassRequest.getBuilder()
       .setContent(contentStr)
       .build();
   ```

4. 创建Client实例。

   ```screen
   //XXXActivity为商户Activity实例
   WalletPassClient walletObjectsClient = Wallet.getWalletPassClient(XXXActivity.this);
   ```

5. 创建Task。

   ```screen
   Task<AutoResolvableForegroundIntentResult> task = walletObjectsClient.createWalletPass(request);
   ```

6. 执行Task。

   ```screen
   // Save_flag为任务执行标志，用于接收任务执行结果。
   ResolveTaskHelper.excuteTask(task, XXXActivity.this, SAVE_FLAG);
   ```

7. 接收添加会员卡结果。

   ```screen
   public void onActivityResult(int requestCode, int resultCode, Intent data) {
       switch (requestCode) {
           //SAVE_FLAG为步骤6设置的常量值
           case SAVE_FLAG:
               switch (resultCode) {
                   case Activity.RESULT_OK:
                       Toast.makeText(this, "save success", Toast.LENGTH_LONG).show();
                       break;
                   case Activity.RESULT_CANCELED:
                       Toast.makeText(this, "cancel by user", Toast.LENGTH_LONG).show();
                       break;
                   default:
                       if (data != null) {
                           int errorCode =
                                   data.getIntExtra(
                                           WalletCommonConstants.EXTRA_ERROR_CODE, -1);
                           Toast.makeText(this, "fail, [" + errorCode + "]：" + errorCode, Toast.LENGTH_LONG).show();
                       } else {
                           Toast.makeText(this, "fail：data is null", Toast.LENGTH_LONG).show();
                       }
                       break;
               }
       }
   }
   ```
