# 形状

地图SDK支持为地图添加形状，主要包括三种形状：折线、多边形、圆。

## 折线

[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polyline-0000001050151144)由若干个[LatLng](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/latlng-0000001050150800)对象连接形成的折线。

1. 创建折线对象，如[图1](#ZH-CN_TOPIC_0000001061566067__fig17281447123611)所示。如果您要在添加折线后更改折线的形状，可以调用[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polyline-0000001050151144)对象的[setPoints](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polyline-0000001050151144#section1721284615510)()方法并为折线提供新的点列表。

   示例代码如下：

   ```java
   "Java"
   // 如果hMap为null，程序停止执行
   if (null == hMap) {
       return;
   }
   // 如果mPolyline不为null，则先从地图上移除，再置为null
   Polyline mPolyline;
   if (null != mPolyline) {
       mPolyline.remove();
       mPolyline = null;
   }
   // 在地图上添加一条折线
   mPolyline = hMap.addPolyline(new PolylineOptions()
       // 折线坐标
       .add(new LatLng(47.893478, 2.334595), new LatLng(48.993478, 3.434595),
                   new LatLng(48.693478, 2.134595), new LatLng(48.793478, 2.334595))
       // 折线颜色
       .color(Color.BLUE)
       // 折线宽度
       .width(3));
   ```

   ```java
   "Kotlin"
   // 如果hMap为null，程序停止执行
   if (null == hMap) {
       return
   }
   // 如果mPolyline不为null，则先从地图上移除，再置为null
   var mPolyline
   if (null != mPolyline) {
       mPolyline?.remove()
       mPolyline = null
   }
   // 在地图上添加一条折线
   mPolyline = hMap.addPolyline(PolylineOptions()
           // 折线坐标
           .add(LatLng(47.893478, 2.334595), LatLng(48.993478, 3.434595),
                   LatLng(48.693478, 2.134595), LatLng(48.793478, 2.334595))
           // 折线颜色
           .color(Color.BLUE)
           // 折线宽度
           .width(3f))
   ```

2. 折线点击事件。可以通过调用[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polyline-0000001050151144)对象的[setClickable](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polyline-0000001050151144#section114084419112)(boolean)方法来启用和禁用可点击性。要在地图上设置此侦听器，请调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[setOnPolylineClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section15655107591)([HuaweiMap.OnPolylineClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onpolylineclicklistener-0000001050150170))方法。

   示例代码如下：

   ```java
   "Java"
   // 设置折线可点击
   mPolyline.setClickable(true);  

   hMap.setOnPolylineClickListener(new HuaweiMap.OnPolylineClickListener() {
       @Override
       public void onPolylineClick(Polyline polyline) {
           Toast.makeText(getApplicationContext(), "Polyline is clicked.", Toast.LENGTH_LONG).show();
       }
   });
   ```

   ```java
   "Kotlin"
   // 设置折线可点击
   mPolyline?.isClickable = true

   hMap.setOnPolylineClickListener { Toast.makeText(applicationContext, "Polyline is clicked.", Toast.LENGTH_LONG).show() }
   ```

## 多边形

[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polygon-0000001050151020)对象与[Polyline](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polyline-0000001050151144)对象类似，因为它们都是由一系列有序坐标组成，但是不同的是，多边形是内部填充的封闭形状。

1. 创建多边形对象，如[图4](#ZH-CN_TOPIC_0000001061566067__fig1674982243818)所示。要在添加多边形后更改多边形的形状，可以调用[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polygon-0000001050151020)对象的[setPoints](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polygon-0000001050151020#section1826199122616)()方法并为多边形的轮廓提供新的点列表。

   示例代码如下：

   ```screen
   "Java"
   if (null == hMap) {
       return;
   }
   Polygon mPolygon;
   if (null != mPolygon) {
       mPolygon.remove();
       mPolygon = null;
   }

   mPolygon = hMap
       .addPolygon(new PolygonOptions().addAll(createRectangle(new LatLng(48.893478, 2.334595), 0.1, 0.1))
           .fillColor(Color.GREEN)
           .strokeColor(Color.BLACK));
   ```

   ```screen
   "Kotlin"
   if (null == hMap) {
       return
   }
   var mPolygon
   if (null != mPolygon) {
       mPolygon?.remove()
       mPolygon = null
   }

   mPolygon = hMap
           .addPolygon(PolygonOptions().addAll(createRectangle(LatLng(48.893478, 2.334595), 0.1, 0.1))
                   .fillColor(Color.GREEN)
                   .strokeColor(Color.BLACK))
   ```

   其中createRectangle()方法的实现如下：

   示例代码如下：

   ```screen
   "Java"
   private List<LatLng> createRectangle(LatLng center, double halfWidth, double halfHeight) {
       return Arrays.asList(new LatLng(center.latitude - halfHeight, center.longitude - halfWidth),
           new LatLng(center.latitude - halfHeight, center.longitude + halfWidth),
           new LatLng(center.latitude + halfHeight, center.longitude + halfWidth),
           new LatLng(center.latitude + halfHeight, center.longitude - halfWidth));
   }
   ```

   ```screen
   "Kotlin"
   private fun createRectangle(center: LatLng, halfWidth: Double, halfHeight: Double): List<LatLng> {
       return listOf(LatLng(center.latitude - halfHeight, center.longitude - halfWidth),
               LatLng(center.latitude - halfHeight, center.longitude + halfWidth),
               LatLng(center.latitude + halfHeight, center.longitude + halfWidth),
               LatLng(center.latitude + halfHeight, center.longitude - halfWidth))
   }
   ```

2. 多边形点击事件。默认情况下，多边形不可点击。可以通过调用[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polygon-0000001050151020)对象的[setClickable](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polygon-0000001050151020#section151966234239)(boolean)方法来启用和禁用可点击性。要在地图上设置此侦听器，需调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[setOnPolygonClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section1893435314811)([HuaweiMap.OnPolygonClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/onpolygonclicklistener-0000001050152109))方法。

   示例代码如下：

   ```java
   "Java"
   // 设置多边形可点击
   mPolygon.setClickable(true);   

   hMap.setOnPolygonClickListener(new HuaweiMap.OnPolygonClickListener() {
       @Override
       public void onPolygonClick(Polygon polygon) {
           Toast.makeText(getApplicationContext(), "Polygon is clicked.", Toast.LENGTH_LONG).show();
       }
   });
   ```

   ```java
   "Kotlin"
   // 设置多边形可点击
   mPolygon?.isClickable = true

   hMap.setOnPolygonClickListener { Toast.makeText(applicationContext, "Polygon is clicked.", Toast.LENGTH_LONG).show() }
   ```

## 圆

圆包括两种情况，一种是实心圆，一种是空心圆。默认是空心圆，可以用[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542)属性进行控制。

1. 创建圆对象，如[图5](#ZH-CN_TOPIC_0000001061566067__fig04882573391)所示。如果您需要在添加圆后更改[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542)的属性，可以调用[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542)对象的[setCenter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542#section1187515316454)()、[setRadius](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542#section1594183211467)()等方法进行重新设置。

   示例代码如下：

   ```screen
   "Java"
   if (null == hMap) {
       return;
   }
   Circle mCircle;
   if (null != mCircle) {
       mCircle.remove();
       mCircle = null;
   }

   mCircle = hMap.addCircle(new CircleOptions()
           .center(new LatLng(48.893478, 2.334595))
           .radius(500)
           .fillColor(Color.GREEN));
   ```

   ```screen
   "Kotlin"
   if (null == hMap) {
       return
   }
   var mCircle
   if (null != mCircle) {
       mCircle?.remove()
       mCircle = null
   }
   mCircle = hMap.addCircle(CircleOptions()
           .center(LatLng(48.893478, 2.334595))
           .radius(500.0)
           .fillColor(Color.GREEN))
   ```

2. 圆点击事件。默认情况下[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542)不可点击。 您可以通过使用[CircleOptions.clickable](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circleoptions-0000001050150596#section4279958496)(boolean)然后调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[addCircle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section7603022114010)([CircleOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circleoptions-0000001050150596))方法，或通过调用[Circle.setClickable](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542#section066010611466)(boolean)来启用和禁用圆的可点击性。

   可以使用[HuaweiMap.OnCircleClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/oncircleclicklistener-0000001050151951)侦听可点击圆上的点击事件。 要在地图上设置此侦听器，请调用[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757)对象的[setOnCircleClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/huaweimap-0000001050151757#section185329145511)([HuaweiMap.OnCircleClickListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/oncircleclicklistener-0000001050151951))方法。

   用户点击圆时，您将收到[onCircleClick](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/oncircleclicklistener-0000001050151951#section07842151362)([Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542))方法的回调。

   示例代码如下：

   ```java
   "Java"
   if (null != mCircle) {
       // 设置圆可点击
       mCircle.setClickable(true);  

       hMap.setOnCircleClickListener(new HuaweiMap.OnCircleClickListener() {
           @Override
           public void onCircleClick(Circle circle) {
               if (circle.equals(mCircle)) {
                   Toast.makeText(getApplicationContext(), "Circle is clicked.", Toast.LENGTH_LONG).show();
               }
           }
       });
   }
   ```

   ```java
   "Kotlin"
   if (null != mCircle) {
       // 设置圆可点击
       mCircle?.isClickable = true

       hMap.setOnCircleClickListener { circle ->
           if (circle == mCircle) {
               Toast.makeText(applicationContext, "Circle is clicked.", Toast.LENGTH_LONG).show()
           }
       }
   }
   ```


   ```java
   // 设置圆的边缘颜色

   // 设置圆的边缘宽度

   ```

### 填充颜色

可设置[Polygon](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/polygon-0000001050151020)和[Circle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/circle-0000001050150542)的填充颜色。

* 多边形

  示例代码如下：

  ```screen
  "Java"
  Polygon mPolygon = hMap.addPolygon(new PolygonOptions().add(new LatLng(48.793478, 2.234595), new LatLng(48.793478, 2.434595), new LatLng(48.993478, 2.434595), new LatLng(48.993478, 2.234595)));
  mPolygon.setFillColor(Color.GREEN);
  ```

  ```screen
  "Kotlin"
  val mPolygon: Polygon = hMap.addPolygon(PolygonOptions().add(LatLng(48.793478, 2.234595),
          LatLng(48.793478, 2.434595), LatLng(48.993478, 2.434595), LatLng(48.993478, 2.234595)))
  ```
