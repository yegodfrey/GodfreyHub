# 准备开发环境

## 运行环境要求

为保证DevEco Studio正常运行，建议您的电脑配置满足如下要求：

* 操作系统：Windows10 64位或macOS 10.14/10.15/11.2.2
* 内存：8GB及以上
* 硬盘：100GB及以上
* 分辨率：1280*800像素及以上

## 安装及配置过程

1. 下载及安装DevEco Studio。具体操作请参见[下载与安装软件](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/software_install-0000001053582415)。
2. 配置DevEco Studio，您需要完成设置网络代理及下载HarmonyOS SDK等相关操作。具体操作请参见[配置开发环境](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/environment_config-0000001052902427)。
3. 开发环境配置完成后，可以通过[运行HelloWorld](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/hello_world-0000001054516888)工程来验证环境设置是否正确。
4. 创建开发项目工程，具体操作请参见[创建一个新的工程](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/create_new_project-0000001053342414)。

   使用Java语言开发，请选择"Empty Ability(Java)"。

> 说明
>
> Push HarmonyOS SDK不支持[feature](https://developer.harmonyos.com/cn/docs/documentation/doc-guides/basic-fundamentals-0000000000041611#section297619205711)模块。
