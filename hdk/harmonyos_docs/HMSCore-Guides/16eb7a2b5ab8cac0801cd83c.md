# 集成SDK

#### 采用npm方式集成SDK

                1. 打开微信小程序IDE开发工具，在当前项目中开启npm功能：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115334.65777092100788563341498294575217:50001231000000:2800:FD8D062132C27F8E7E752A2683DC15B74D261E16C06DE4115AC4AACC122BB0EC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

                2. 如果项目中没有“package.json”文件，可以在项目的根目录下，使用以下命令来创建：
                       
                       npm init

                3. 通过运行以下npm命令，安装SDK软件包。
                       
                       npm install --save @hw-hmscore/analytics-sdk-miniprogram

                4. 点击开发者工具菜单栏中的“工具 > 构建 npm”，构建当前工程的npm库文件。
