# 配置文件说明

#### 公钥配置

由于业务需要，Analytics SDK需要使用公钥加密，服务器私钥解密的场景。

分析服务SDK初始化应用时从云端自动获取公钥信息，获取后本地持久化存储，此后每隔指定时间（24小时）获取一次公钥信息。
