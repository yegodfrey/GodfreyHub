# 鲸鸿动能广告归因（中国大陆）

## 功能概述

广告主在鲸鸿动能广告平台新建资产并添加关联，通过在推广应用中集成华为分析SDK，实现转化事件的上报及回传至鲸鸿动能广告平台，从而实现广告效果的监测，对投放的广告效果进行深层次的优化，提升广告投放回报率。

## 操作步骤

1. 开通华为分析服务并集成、初始化SDK。

   1. 开通华为分析服务详情请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-enabling-0000001050745155)。
   2. 集成Android SDK详情请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-integrating-sdk-0000001050161876)。
   3. 初始化Android SDK详情请参见[初始化AnalyticsSDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-accessing-0000001050161888#ZH-CN_TOPIC_0000001055384434__li10483101605315)。

2. 在鲸鸿动能广告平台新建关联。

   需要为您希望跟踪的每一个应用使用指定的监测工具新建资产，详细请参考[新建资产](https://developer.huawei.com/consumer/cn/doc/promotion/tracking-app-overview-0000001209244840#ZH-CN_TOPIC_0000001209244840__li8351194812211)。

3. 在华为分析服务侧注册并标记转化事件。

   1. 选择"华为分析 > 管理 > 事件管理"进入事件管理页面。
   2. 注册并埋点需要回传的预置事件（自采集事件无需此操作）。
      1. 预置事件注册方法请参考[新建预置事件或自定义事件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/meta-manage-0000001050985177#section5729142611116)。
      2. 预置事件在SDK侧的埋点方法请参考[预置事件使用指导](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-usage-guide-0000001135571462#section884113671612)。
   3. 将需要回传的事件标记为转化事件。 ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240118113405.11616888102108258466586426227406:50001231000000:2800:474532D1D3803010D33164A7AF591D72BA561D17802D0F84F3560C6ADE284BC7.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")

4. 在华为分析服务侧配置转化事件回传。

   1. 选择"华为分析 > 管理 > 事件管理"进入事件管理页面。
   2. 选择"配置转化事件回传"页签，并通过页面右侧的"新增"按钮，进入配置转化事件回传页面。
   3. 配置回传转化事件相关信息。
      1. 选择平台：选择"鲸鸿动能广告"。
      2. 选择应用：选择需要配置回传事件的应用的名称（支持输入应用名称搜索）。
      3. （可不配置）在选择回传事件下方，配置分析服务事件与广告事件的映射关系。 说明
         >
         > 分析服务与鲸鸿动能广告部分事件已有默认映射关系，无需再次配置，且已默认勾选回传。如果默认映射的事件不能满足您的需求，您也可以手动配置华为分析服务与鲸鸿动能广告事件的映射关系，无默认映射关系的事件，可在"配置广告事件"列选择广告事件，配置分析服务与鲸鸿动能广告事件的映射关系。
      4. 勾选需要回传的事件前面的复选框（仅无默认映射关系的需要手动勾选，有默认映射关系的已自动勾选）。
      5. 点击"保存"，完成配置。
