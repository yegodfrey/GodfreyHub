# 接入Analytics

分析服务提供基于您上报事件的分析数据模型。

分析数据模型采用了Event-Param-User模型来记录数据，通过不同的参数对事件进行描述，同时对用户的特征也进行了描述。

术语 | 名称 | 说明  
---|---|---  
Event | 事件 | 描述一个用户在某个时间点、某个地方、以某种方式完成了某个具体的事情。包含who、when、where、how、what等关键要素。  
Param | 参数 | 事件上报的关联参数。如加入购物车事件中的商品名称参数和商品价格参数，支持后续的深入分析。  
UserProfiles | 用户属性 | 用户的属性表，常见的用户属性有设备型号、应用版本、自定义的用户属性（如食品偏好）等。  
  
Analytics Kit会收集AAID。AAID是应用匿名标识符，每个App在同一个设备上会分配不同的AAID。AAID用于连通华为提供的各项服务，例如Push、分析服务和远程配置等。

AAID会在如下场景重置：

      * 用户卸载后重装应用。 
      * 用户恢复出厂设置。 
      * 用户清除应用数据。 
      * 应用主动调用[clearCachedData](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section7238134312)接口。 

#### 接入步骤

      1. 初始化Analytics SDK。

SDK通过[getInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section14289539163414)接口根据配置完成初始化。
             
             import analytics from '@hw-hmscore/analytics-sdk-harmony';
              
             let bundlename = 'com.huawei.hms.analytics.harmony'; // 当前包的bundlename
             analytics.getInstance(bundlename);

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115315.65977636857590906130893995527446:50001231000000:2800:0BF0E56ADAABDC13DF0FAF5D6E0D790AD7C1BA6E4F439E7111792E977AE92DBD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

         * SDK初始化时会发送网络请求，请您务必在用户同意隐私协议后再初始化SDK。 
         * 建议您在app.js的onCreate中初始化Analytics SDK。 
         * 请在您的页面中添加调用[pageStart](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section111581350115113)和[pageEnd](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section8959745205416)接口内容，否则无法正常获取$CurrPageId和$PrePageId参数，在[实时概览](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/real-time-dashboard-new-0000001159732343)页面中“当前页面”和“上一个页面”取值为未知。 

      2. （可选）设置上报策略。

Analytics SDK提供了四种事件上报策略，支持多种策略自由组合，任何一种策略满足时即可触发事件上报。您可以根据场景选择合适的事件上报策略。

如果设置上报策略，建议包含应用切后台上报策略，防止应用退出后部分事件缓存在本地不能及时上报。

策略 | 描述 | 说明  
---|---|---  
ON_APP_LAUNCH_POLICY | 应用启动上报策略 | 应用启动时上报事件。选择该策略时会立即上报一次，此后每次应用启动时上报一次。  
ON_MOVE_BACKGROUND_POLICY | 应用切后台上报策略 | 应用切后台时上报事件，包括应用退出。  
ON_SCHEDULED_TIME_POLICY | 定时上报策略 | 根据指定的间隔时间上报事件，取值范围为【60-1800】秒（默认60秒），如果设置的值超过给定范围则取边界值。  
ON_CACHE_THRESHOLD_POLICY | 阈值上报策略 | 缓存事件条数达到阈值时上报事件，取值范围为【30-1000】条（默认30条），如果设置的值超过给定范围则取边界值。  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115315.78658538656650161638842099905055:50001231000000:2800:5394CEFD65B4D7B32E46FF9E1D4CC46765B74DD634A43AD666936E40808416B1.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

         * 以上上报策略仅在非调试模式下生效。上报策略持久化保存。 
         * 应用切后台上报策略和阈值上报策略为必选策略，无论设置什么策略，这两个策略都会生效，但是可以改变阈值上报策略的阈值。 
         * 多次调用设置上报策略的接口，会刷新上报策略，仅最后一次设置的策略生效，请谨慎多次调用。 
         * 当策略满足触发事件上报时，如果没有网络，则会将事件缓存在本地，等待下次条件满足继续上报。 

      3. 通过[onEvent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section15204518184114)接口记录定义事件。

事件的定义请参见[自动采集事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-automatic-event-collection-0000001204716899)、[预置事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-preset-event-0000001204836869)、[自定义事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-custom-events-0000001158958352)。

      4. 请参见[ _API参考_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmony-js-api-overview-0000001159634576)，调用接口实现各类功能。例如：设置用户属性（[setUserProfile](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-js-api-hianalytics-instance-0000001204763599#section096353619188)）。

#### 示例代码

      1. 导入SDK。
             
             import analytics from '@hw-hmscore/analytics-sdk-harmony';

      2. 在“app.js”中创建全局变量analytics。
             
             globalData: {
                 analytics: null
             },

      3. 在“app.js”的onCreate方法中初始化Analytics SDK，获得HiAnalytics的实例。

请将如下onCreate方法中的bundleName替换为您当前应用的bundleName。 
             
             // TODO: 用您应用的配置替换下方代码 
             onCreate() {
                 let bundleName = '_com.huawei.harmonyos.demo_ ';
                 analytics.getInstance(bundleName);
             },

      4. （可选）设置应用切后台上报策略和定时上报策略。
             
             // 设置应用切后台上报策略和定时上报策略 
             analytics.setReportPolicies({ ON_SCHEDULED_TIME_POLICY: 60, ON_MOVE_BACKGROUND_POLICY: '' });

      5. 在代码合适位置插入埋点代码。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115315.83590358774507688330180550191039:50001231000000:2800:5F377C59B9B3EF3AAA34D47748A9C8C2A5F4D87B57598C750648FCE2DF39A2D7.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

如需使用预置常量，请使用如下命令引入：
             
             import {HAEventType, HAParamType, HAReportPolicy, HAUserProfileType, HALog} from '@hw-hmscore/analytics-sdk-harmony/index.harmony_types';
             
             // 自定义埋点，在工程合适位置插入埋点代码  
             let pacMap ={};
             pacMap.exam_difficulty = 'high';  
             pacMap.exam_level = '1-1';  
             pacMap.exam_time = '20190520-08';  
             analytics.onEvent("begin_examination", pacMap);  
             // 预置事件埋点  
             let pacMapPre = {};
             pacMapPre[HAParamType.PRODUCTID] = 'item_ID';
             pacMapPre[HAParamType.PRODUCTNAME] = 'name';
             pacMapPre[HAParamType.CATEGORY] = 'category';
             pacMapPre[HAParamType.QUANTITY] = 100;
             pacMapPre[HAParamType.PRICE] = 10.01;
             pacMapPre[HAParamType.REVENUE] = 10;
             pacMapPre[HAParamType.CURRNAME] = 'currency';
             pacMapPre[HAParamType.PLACEID] = 'location_ID';
             analytics.onEvent(HAEventType.ADDPRODUCT2WISHLIST, pacMapPre);

#### 接入调试

在开发过程中可以启用调试模式，实时查看事件的记录情况，观察具体结果并根据需要进行调整。

#### [h2]开启/停用调试模式

      * 开启调试模式： 
        1. 执行如下hdc命令，调试模式打开后，所有事件将实时上报，在应用调试界面可实时查看上报的数据。 

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115315.42895166908484257931426977926423:50001231000000:2800:E5833E59AE327AA2947C841292D770EF44A2D85C2A91AAEE77AD96DA0C574262.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

请将命令行中的<package_name>字段替换为您的应用包名。
               
               hdc shell setprop debug.huawei.hms.analytics.hap _< package_name>_

        2. 数据成功上报后，“华为分析 > 应用调试”页面会展示出数据，如下图：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115315.94479346848166370376463461531321:50001231000000:2800:77C94B728EFC75D683C839FE845B5F568233073575E48B7BEECC9C75B9031651.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

        3. 在AGC系统上查看数据，请参见[应用调试](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/app-debugging-0000001051799712)。 
      * 停用调试模式： 

执行如下hdc命令，将停用调试模式。 
            
            hdc shell setprop debug.huawei.hms.analytics.hap .none.
