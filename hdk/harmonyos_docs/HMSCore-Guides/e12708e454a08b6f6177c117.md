# 体温

## 体温数据

此数据记录用户在一段时间内的体温数据。

### OAuth权限

联盟卡片申请的权限名称：健康数据 > 体温数据

* 读权限：Scopes.HEALTHKIT_BODYTEMPERATURE_READ
* 写权限：Scopes.HEALTHKIT_BODYTEMPERATURE_WRITE

### 原子采样明细数据类型

* 名称：com.huawei.instantaneous.body.temperature
* Android SDK类型常量：HealthDataTypes.DT_INSTANTANEOUS_BODY_TEMPERATURE

|**字段**列表|描述|Android SDK常量|**类型**|可选/必选|单位|取值范围|
|:----------|:---|:-----------------------------|:-----|:----|:--|:-----------|
|temperature|身体温度|HealthFields.FIELD_TEMPERATURE|double|M|摄氏度|[34.0, 42.0]|

**数据开放说明**

|开放API|查询及时性|数据源|
|:-------------------------------------------------------------------------------------------------------------------------------|:----|:-----|
|[读取运动健康数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section0447440145418)|分钟级|部分手表支持|

### 原子采样统计数据类型

* 名称：com.huawei.continuous.body.temperature.statistics
* Android SDK类型常量：HealthDataTypes.POLYMERIZE_CONTINUOUS_BODY_TEMPERATURE_STATISTICS

|**字段列表**|描述|Android SDK常量|**类型**|可选/必选|**单位**|取值范围|
|:-------|:-----|:---------------|:-----|:----|:-----|:----------|
|avg|平均体温|Field.FIELD_AVG|double|M|摄氏度|[34.0,42.0]|
|max|最高体温|Field.FIELD_MAX|double|M|摄氏度|[34.0,42.0]|
|min|最低体温|Field.FIELD_MIN|double|M|摄氏度|[34.0,42.0]|
|last|最新一条体温|Field.FIELD_LAST|double|O|摄氏度|[34.0,42.0]|

**数据开放说明**

|开放API|查询及时性|统计数据维度|数据源|
|:-------------------------------------------------------------------------------------------------------------------------------|:----|:------------|:-----|
|[读取当日统计数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section9463154045415)|分钟级|采样数据按照当日进行统计|部分手表支持|
|[读取多日统计数据](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/datacontroller-0000001050089472#section295981925017)|分钟级|采样数据按照自然日进行统计|部分手表支持|
