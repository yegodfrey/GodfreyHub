# 通过AppAuth接入华为帐号（iOS）

#### 概述

本文适用于希望接入华为帐号的iOS应用。为了方便快速接入OAuth 2.0授权，开发者可以使用AppAuth SDK（iOS版）。通过OAuth 2.0协议的方式在浏览器中进行华为帐号登录。  

#### 配置要求

* 接入AppAuth SDK（iOS）要求系统版本在iOS 7及以上。

* 苹果移动设备已经安装Safari浏览器。iOS 9及以上系统可以通过应用内浏览器（SFSafariViewController）打开，iOS 9以下使用自带的Safari浏览器打开。

#### 开发准备

#### 获取Client ID

在开始开发应用前，需要[创建并管理应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)，获取产品的Client ID（下文中提及的clientId值传此处的Client ID值）。  

#### 开发流程

#### 获取示例代码

您可以从[AppAuth-For-iOS的官方网站](https://openid.github.io/AppAuth-iOS/)中下载示例代码，或通过以下命令克隆代码：

```
git clone https://github.com/openid/AppAuth-iOS.git
```

在Xcode中打开该工程。  

#### 配置请求参数

1. 通过域名获取配置。  

   |参数|必选/可选|示例值|说明|
   |:-----|:----|:--------------------------------------------------------------------|:--------------------------------------------------------------------------|
   |issuer|必选|https://oauth-login.cloud.huawei.com/.well-known/openid-configuration|OpenID授权服务的动态发现地址，配置了该地址则可选配置authorization_endpoint_uri、token_endpoint_uri。|

2. 授权请求  

   |参数|必选/可选|示例值|说明|
   |:-----------|:----|:------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
   |clientId|必选|111111111|您在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)创建应用后分配的Client ID，请参见[获取Client ID](#section22863551912)。|
   |scopes|必选|openid email profile|用户实际授予的权限列表，其中OpenID必填，多个Scope通过空格分隔。|
   |redirectURL|必选|com.huawei.apps.APPID:/oauth2redirect|固定格式。|
   |responseType|必选|code|响应类型。|

#### 配置 URL Schemes

iOS 9及以上不需要配置。针对iOS 9以下系统，必须在info.plist中配置URL Schemes。格式：com.huawei.apps.APPID，即上表中redirectURL中前半部分。  

#### 运行示例代码

按以上步骤配置好请求的参数后，您可以运行[获取示例代码](#section2064715115217)获取的[示例代码](https://openid.github.io/AppAuth-iOS/)。

示例代码中有两种获取Access Token的方法：

* 直接获取Access Token。
* 先获取authorization code，再通过authorization code换Access Token。

点击后，会出现提示框提示进行授权。授权后，会打开Safari浏览器并加载授权登录页面。

在浏览器中登录华为帐号成功后，您会从"lastTokenResponse"获取到ID Token、Access Token等授权信息。  

#### 解析ID Token获取用户信息

返回的ID Token是JWT格式的字符串，可以按照JWT格式进行解析，获取用户的Union ID、Email地址、头像等信息。

校验ID Token请参见[验证ID Token有效性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/dev-guide-account-0000001050048888#section56301064278)，ID Token解析后的参数请参见[验证ID Token有效性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/account-verify-id-token_hms_reference-0000001050050577)中返回值的参数。
