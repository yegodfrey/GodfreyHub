# 步数多日统计

本章节提供通过华为Health Service Kit服务端API获取用户每日步数数据的方法示例。每日步数使用SampleSet存储，开发者可以通过发送POST请求查询com.huawei.continuous.steps.delta数据类型获取精确的时间段内的用户步数数据。

**预置数据**

可通过运动健康App进行数据预置用于调试。

**读取用户步数数据**

通过RESTful API的方式获取精确的时间段内的用户步数数据。

**HTTP请求，** 请参见[采样数据多日统计查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/sampleset_daily_polymerize-0000001078113560)接口。

```screen
POST
https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:dailyPolymerize
```

**请求示例**

```screen
POST 
https://health-api.cloud.huawei.com/healthkit/v2/sampleSet:dailyPolymerize
```

**请求体**

建议：

* 请求体中的startDay、endDay为查询的起止日期。
* timeZone设置为当前所在地的时区。

```screen
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
{
    "dataTypes": [
        "com.huawei.continuous.steps.delta"
    ],
    "startDay": "20200811",
    "endDay": "20200812",
    "timeZone": "+0800"
}
```
