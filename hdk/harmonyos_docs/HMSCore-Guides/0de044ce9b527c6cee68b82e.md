# 配置AppGallery Connect

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115332.39420549235199338488995857597358:50001231000000:2800:5153976D62934CFEAF2446FCECEAB3C9A8CF6F4BD3468CE19E7A4A1329358290.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

在项目中添加应用时，“选择平台”点击“快应用”，“应用分类”下拉框中选择“游戏”。

#### 操作步骤

                1. 如果没有[华为开发者联盟](https://developer.huawei.com/consumer/cn/)帐号，需要先注册帐号并通过实名认证。详细操作请参见[ _帐号注册认证_](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
                2. 参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和在[项目中添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。
                3. 开通华为分析服务：
                   1. 登录[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。 
                   2. 选择已创建完成的应用。 
                   3. 点击“华为分析”下的任意菜单，并点击“启动分析服务”可开通分析服务。（注：需拥有产品管理权限才可开通服务。）

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115332.06342712379324097088934386821212:50001231000000:2800:1B116AC1832876211B549C7FBAB1B407A59DDF49D3553BA2164BA671ED25B9C6.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

                   4. 进入“项目接入设置”页面，设置数据处理位置、设置用户数据留存时间、设置自然周定义后，点击“完成”，即完成Analytics Kit服务开通。 

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115332.72938547513322428415476999601324:50001231000000:2800:88295AF034B802080A747625627D0912662C5921CFA6BF1BA0726D559D7B3469.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

如果您的应用发布到全球多个国家，建议您启用多数据处理位置，使用[InitSettings.routePolicy](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickgame-api-initsettings-0000001194219576)初始化SDK，按照用户实际使用区域指定数据上报位置。

请打开[ _AppGallery Connect_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，选择“我的项目”，在项目列表中找到您要打开的项目并点击，在AppGallery Connect界面选择“项目设置  > API管理”查看是否开启华为分析。
