# 使用入门

#### 开发环境

* [JDK](https://www.oracle.com/java/technologies/javase-downloads.html) 1.8及以上

* 安装[HUAWEI DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio) 2.1及以上

* [HarmonyOS SDK](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/environment_config-0000001052902427-V3#section67391947173214) API Version 5-Version 7
* [HarmonyOS SDK](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/environment_config-0000001052902427-V3#section67391947173214) API Version测试应用的设备：HarmonyOS 2.0及以上的手机
* 安装[Node.js](https://nodejs.org/en/download/) LTS  

#### 支持的设备

|设备类型|OS版本|HMS Core（APK）版本|
|:---------------------------------------|:---------------|:--------------|
|手机、平板|HarmonyOS 2.0及以上|5.0.0.300及以上|
|车机|HarmonyOS 2.0及以上|6.2.0.300及以上|
|华为智慧屏、智能手表（wearable，不支持运动手表liteWearable）|HarmonyOS 2.0及以上|6.5.0.300及以上|

HarmonyOS（Java）必须在单HAP包场景下使用，暂不支持多HAP包场景。  

#### 开发流程

您需要按照如下流程完成应用的开发工作。

在场景开发中，开发者可以根据需要选择一种适合开发者应用的登录模式集成即可。  

|序号|步骤|说明|
|:-|:----------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[开发准备](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-preparations-environment-0000001148393172)|在开发HarmonyOS应用前，开发者需要先完成开发准备，包括： 1. [准备开发环境](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-preparations-environment-0000001148393172) 2. [配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-config-agc-0000001153532250) 3. [配置应用签名信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-config-app-signing-0000001199536987) 4. [集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-integration-hms-core-sdk-0000001148191776) 5. [配置混淆脚本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-config-obfuscation-script-0000001194271363) 6. [添加权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-add-permissions-0000001152048968)|
|2|[移动应用快速接入华为帐号](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-without-identity-verification-0000001162739537)|1. 应用无法对用户身份进行验证，不能保证用户信息的真实性。 2. 首次登录时，要求用户同意授权，无身份验证信息，不存在验证信息过期问题。|
|2|[移动应用ID Token模式接入华为帐号（OpenID Connect）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-scenario-id-token-0000001162579519)|1. 可对用户身份进行验证，保证用户信息的真实性。 2. 首次登录时，要求用户同意授权，当身份验证信息到期时，用户每次登录时都应同意授权。|
|2|[移动应用Authorization Code模式接入华为帐号（OAuth 2.0）](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-java-scenario-auth-code-0000001115899748)|1. 可对用户身份进行验证，保证用户信息的真实性。 2. 首次登录时，要求用户同意授权，当身份验证信息到期时，只需要从服务器端通过刷新令牌刷新访问令牌，无需用户再次授权。|
