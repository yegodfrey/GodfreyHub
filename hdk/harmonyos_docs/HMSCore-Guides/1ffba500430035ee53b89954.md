# 概述

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/g2HCKuCcSMm3qLCsdwnuOA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=9B7CC713EEC2ED9745565E2BD98D92E3D0308DCB2DE2303E0FCAF1E06C02ED90)

自定义工作区暂时不支持可视化埋点及可视化埋点资源的相关操作，若您需要可视化埋点，请在默认工作区中进行。

可视化埋点是指您可以将App界面同步至DTM界面，并在DTM界面通过可视化点击的方式添加埋点事件。如果使用该埋点方式，您需要集成DTM SDK 5.0及以上版本。相比于代码埋点，可视化埋点有以下优势：
      * 研发人员仅需要完成DTM SDK集成，免去代码添加埋点的开发成本。
      * 技术门槛低，可以直接在DTM界面上点击添加埋点事件，适合运营人员直接使用。
      * 在应用发布后仍然可以灵活的添加埋点事件，解决前期埋点不充分的问题。

若您需要向HUAWEI Analytics上报事件，DTM支持从HUAWEI Analytics平台接入，创建埋点方案并对其埋点事件进行管理。为了使用行业化的埋点方案，提升埋点效率，推荐您优先使用该功能，详情请参见[按华为分析埋点方案操作流程](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-visual-event-tag-ha-0000001087930288)。
