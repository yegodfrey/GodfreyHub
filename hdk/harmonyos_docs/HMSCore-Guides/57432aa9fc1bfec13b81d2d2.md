# 场景化示例  
  
#### 自定义事件

                1. 在“条件”页面，点击“新建”按钮。
                2. 在“新建条件”页面中输入条件名称，设置条件类型为自定义事件，并输入“事件名称”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2b/v3/AO0J1QoqTp6e8QW59S3-vA/zh-cn_image_0000001091226409.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=ABABB8F7D13527BA94A73358A4FBC6AC4CEE7DCB108D811CDBB3A707F1D45646)

                3. 创建成功后，您可以在“条件”页面中查看到已创建的条件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/31/v3/6JdUuoNyS3ec-zBf88qYAQ/zh-cn_image_0000001077784242.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=584BDF1667D0299C9721BDD77E24D29DC4FF0735B3D43AA5AED3FC9E746641C2)

                4. 新建一个配置代码，例如：代码模板选择“Facebook Pixel”，输入对应的参数，选择步骤2创建的“自定义事件”作为“触发条件”，完成后点击“保存”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5d/v3/KDtbAsPFT9qKj29gKGlzbQ/zh-cn_image_0000001091070039.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=81B77E0D6AA998351D364A623F69179B9C1AA77AB89E654C7B2D67F4433F530F)

                5. 下面的示例代码说明了如何在JavaScript中触发自定义事件。
                       
                       <script>          
                           window.recordTier = window.recordTier || [];
                           window.recordTier.push({
                               '**eventName** ': '**purchase** '
                           });
                       </script>

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/-gstuXm-Qz6AF6NFL93dpw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=2D522B95592C77ACE16C5A8A9B208F84099B71534639DB4F983170188BF13BE0)

推入记录层变量的键必须是'eventName'，而事件值则与步骤2中的输入的“事件名称”保持一致（如果配置条件时，勾选了“使用正则表达式匹配”，则事件值须匹配“事件名称”指定的正则表达式），否则“自定义事件”无法被触发。

#### 元素可见性

元素可见性条件支持监测DOM更改，即当页面加载完成后又新增加元素时，支持对该元素的可见性事件上报。

                1. 在“条件”页面，点击“新建”按钮。
                2. 在“新建条件”页面中输入“条件名称”，设置“条件类型”为“元素可见性”，设置“监测DOM更改”为“启用”，并根据实际情况填写其他参数。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/VIKqee-5Rh6AiBN7tWgUxg/zh-cn_image_0000001111718446.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=8840C1E5FB9EDB60AC0C572F3FC59487166379F3824D225C9A8ADC33AFF0D8C2)

                3. 在“代码”页面，点击“新建”按钮。
                4. 在“新建代码”页面中输入“代码名称”，设置“触发条件”为如上所建的元素可见性条件，并根据实际情况填写其他参数。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/3K3hF5crTxaK6k6sQknLKA/zh-cn_image_0000001158681531.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=ADBBED4A049C2871D558800A8BE538C8B6E6D421E86226524F9FF91A7B7E1B03)

                5. 在“版本”页面，点击“新建”按钮。
                6. 在“创建版本”页面输入版本名称和描述后，选择“创建并发布此版本”，点击“确定”按钮，系统跳转至“版本详情”页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7e/v3/o1_tGGouQMeGaxiAoZ5Q4A/zh-cn_image_0000001111896584.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=13E1D3284BF63E247446ACD1B3B54EE9059EE529BE4201E0211020226D609663)

                7. 在“版本详情”页面，点击“预览”。
                8. 在“版本预览”页面，确认您的网址信息，并选择“是否进入调试模式”，点击“开始预览”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/db/v3/qw6sLe3CSVe8IcOH92Kh1A/zh-cn_image_0000001111887142.png?HW-CC-KV=V1&HW-CC-Date=20261005T043134Z&HW-CC-Expire=86400&HW-CC-Sign=CACA596786DBF96F976A37C8474EA2D9672A1D480EA6D4840F95F68D3FF0D22E)

若您勾选了“是否进入调试模式”，则可以查看到元素可见性事件的相关信息。
