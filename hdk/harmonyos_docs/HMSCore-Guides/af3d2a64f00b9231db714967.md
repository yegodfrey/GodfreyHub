# 沉默期

#### 功能概述

针对沉默期用户，运营人员需要在了解沉默期用户构成的基础上，通过沉默期用户数据看板、用户趋势分析、沉默期用户构成分析、转化趋势分析、召回潜力预测和流失预警分析，设计召回活动，并重点关注新增的沉默用户，这部分用户最有可能被成功召回。  

#### 功能详述

#### 添加过滤器并选择查询日期

1. 点击"添加过滤器"并完成设置，过滤器条件属性详情请参见[添加过滤器组件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/filter-introduction-0000001123199087)。
2. 点击"日期"控件，选择需要查询的数据日期。
3. 设置完成后，过滤条件及日期将作用于沉默期报告以下卡片：沉默期用户看板、用户趋势、用户构成、转化趋势、召回潜力预测与流失预警。  

#### 查看沉默期用户看板

沉默期报告呈现了选定日期下沉默期的用户数、沉默期新增用户数及环比变化情况。  

#### 查看沉默期用户趋势

沉默期用户趋势卡片展示了选定日期前7天内沉默期的用户数、新增用户数变化趋势。

2. 点击"下载数据"，可将选定日期前7天沉默期用户、沉默期新增用户数详情下载到本地，进行个性化分析。

#### 召回潜力预测与流失预警分析

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115242.20469318682553535706030566741247:50001231000000:2800:F5B5711D4D1796A82C61D421CDC3A5FDFAB7C29A5A5A9C9D29205BBBFC970EEC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
* 此功能仅限部分区域开放。
* 月活跃用户数大于1500，且沉默期用户数不等于零，此卡片才会有预测结果。

召回潜力预测展示了沉默期用户转化为新手期、成长期、成熟期用户的潜力，流失预警展示了沉默期用户转化为流失期用户的风险。

潜力系数的分值越高表示转化概率越高，流失风险的分值越高表示流失的风险越高。

1. 将预测用户群存为受众。

   点击潜力预测或流失预警卡片左上角数字，可将预测用户群存为受众，进行精细化运营或精准触达，详情请参见[如何使用受众](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/audience-analysis-new-0000001113372616#section5527930142218)。
