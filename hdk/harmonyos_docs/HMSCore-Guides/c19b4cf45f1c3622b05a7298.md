# 版本更新说明  
  
#### 6.9.9-300（2023-01-31）

本次微信小程序版本特性变更如下： **新增特性**
                * 新增定时上报策略、阈值上报策略。 
                * 新增立即上报接口[onReport()](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/miniprogram-api-wxanalytics-0000001198293007#section82761885241)。 
**修改特性**
                * 自动采集事件[APPFIRSTOPEN](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-automatic-event-collection-0000001051740557#ZH-CN_TOPIC_0000001055104489__li1902124561120)和[LAUNCHAPP](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-automatic-event-collection-0000001051740557#ZH-CN_TOPIC_0000001055104489__li197281146256)的上报时机改为实时上报，微信小程序事件相关说明请参见[事件说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/miniprogram-event-0000001198128703)。 
                * SDK包名由“@hmscore/analytics-sdk-miniprogram”修改为“@hw-hmscore/analytics-sdk-miniprogram”。
