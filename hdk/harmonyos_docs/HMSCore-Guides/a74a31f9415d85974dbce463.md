# 基于受众人群请求广告

鲸鸿动能SDK提供了通过设置[RequestOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-0000001050066843)对象，来满足针对不同受众人群请求对应广告内容的能力。该对象通过[HwAds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hwads-0000001050066833)静态方法获取应用的全局受众人群信息。如果要更新请求配置，请从现有配置中获取构建器，再进行设置更新。
> 注意
>
> 您必须将用户是否是儿童的标识，在setTagForChildProtection方法中如实地告知鲸鸿动能平台。**您需要承担因告知错误或没有告知导致广告误投放到儿童的手机上导致的一切后果。**

示例代码如下所示：

```java
"Java"
// 添加面向儿童的设置
RequestOptions requestOptions = HwAds.getRequestOptions().toBuilder().setTagForChildProtection(TAG_FOR_CHILD_PROTECTION_TRUE).build();
HwAds.setRequestOptions(requestOptions);
```

    "Kotlin"
    // 添加面向儿童的设置
    var requestOptions: RequestOptions? = 
    HwAds.getRequestOptions().toBuilder().setTagForChildProtection(TAG_FOR_CHILD_PROTECTION_TRUE).build()
    HwAds.setRequestOptions(requestOptions);

[RequestOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-0000001050066843)提供了下面七种方法设置受众人群：

|方法|描述|
|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[setTagForChildProtection](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section9827494252)|为了满足《儿童在线隐私保护法》（COPPA）的要求，鲸鸿动能SDK提供了"面向儿童内容的标记"的设置。 参数说明： * TAG_FOR_CHILD_PROTECTION_TRUE：表明您的广告内容需要符合COPPA的规定。 * TAG_FOR_CHILD_PROTECTION_FALSE：表明您的广告内容不需要符合COPPA的规定。 * TAG_FOR_CHILD_PROTECTION_UNSPECIFIED：表明您不希望明确您的广告内容是否需要符合COPPA的规定。|
|[setTagForUnderAgeOfPromise](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section9201111519261)|为了满足欧洲[《数据保护法案》（DSA）](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32022R2065&qid=1695692008722)和其他国家关于未成年人保护的要求，不向未满 18 周岁的用户展示个性化广告。鲸鸿动能SDK提供了"未达到法定承诺年龄的用户"的设置，以标记广告请求是针对未满18周岁的未成年人。 参数说明： * PROMISE_TRUE：表明您希望按适合未达到法定承诺年龄的用户的方式来处理广告请求。 * PROMISE_FALSE：表明您不希望按适合未达到法定承诺年龄的用户的方式来处理广告请求。 * PROMISE_UNSPECIFIED：表明您未明确是否按适合未达到法定承诺年龄的用户的方式来处理广告请求。|
|[setAdContentClassification](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section1716865220145)|鲸鸿动能SDK提供了广告内容过滤能力，在请求广告时可以设置广告内容分级的上限。使用此方法获取的广告内容会小于等于设置的分级上限。 设置的分级必须是下述值之一： * AD_CONTENT_CLASSIFICATION_W：适合幼儿及以上年龄段的受众，仅展示内容分级为W的内容。 * AD_CONTENT_CLASSIFICATION_PI：适合少儿及以上年龄段的受众，展示内容分级为PI、W的内容。 * AD_CONTENT_CLASSIFICATION_J：适合青少年及以上年龄段的受众，展示内容分级为J、PI、W的内容。 * AD_CONTENT_CLASSIFICATION_A：仅适合成人受众，展示内容分级为A、J、PI、W的内容。 说明 > 我们的默认值为A，建议无特殊需求，保持默认值，可获得更多广告填充。|
|[setNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section175111735202616)|鲸鸿动能SDK支持投放的广告分为个性化广告与非个性化广告两种。通过此方法可以设置请求的广告类型。 参数说明： * ALLOW_ALL：个性化广告与非个性化广告。 * ALLOW_NON_PERSONALIZED：非个性化广告。 说明 > 当[setNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section175111735202616)方法的参数为ALLOW_ALL时，使用[setHwNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section9578131665317)方法和[setThirdNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section1884143082318)方法设置个性化广告是有效的。|
|[setHwNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section9578131665317)|鲸鸿动能SDK支持针对华为DSP投放的广告设置个性化广告与非个性化广告两种。通过此方法可以设置请求的广告类型。 参数说明： * ALLOW_ALL：个性化广告与非个性化广告。 * ALLOW_NON_PERSONALIZED：非个性化广告。|
|[setThirdNonPersonalizedAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section1884143082318)|鲸鸿动能SDK支持针对三方DSP投放的广告设置个性化广告与非个性化广告两种。通过此方法可以设置请求的广告类型。 参数说明： * ALLOW_ALL：个性化广告与非个性化广告。 * ALLOW_NON_PERSONALIZED：非个性化广告。|
|[setConsent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/requestoptions-builder-0000001050064896#section112971941052)|[TCF v2.0](https://iabeurope.eu/tcf-2-0/)用户同意信息字符串，遵循IAB TCF v2.0标准中的[Consent String Format](https://github.com/InteractiveAdvertisingBureau/GDPR-Transparency-and-Consent-Framework/blob/master/TCFv2/IAB Tech Lab - Consent string and vendor list formats v2.md#the-global-vendor-list)格式。|

示例代码如下所示：

```java
"Java"
// 面向儿童的设置，表明您的广告内容需要符合COPPA的规定 
RequestOptions requestOptions = HwAds.getRequestOptions().toBuilder().setTagForChildProtection(TAG_FOR_CHILD_PROTECTION_TRUE).build();
// 未达到法定承诺年龄的用户的设置，表明您希望广告请求符合未达到法定承诺年龄用户的广告标准
RequestOptions requestOptions = HwAds.getRequestOptions().toBuilder().setTagForUnderAgeOfPromise(PROMISE_TRUE).build();
// 广告内容过滤，指定返回的广告内容应与分级标签名称对应，但不得高于W
RequestOptions requestOptions = HwAds.getRequestOptions().toBuilder().setAdContentClassification(AD_CONTENT_CLASSIFICATION_W).build();
// 请求个性化广告与非个性化广告，当参数设置为ALLOW_ALL时，setHwNonPersonalizedAd方法和setThirdNonPersonalizedAd方法设置的个性化广告是有效的
RequestOptions requestOptions = HwAds.getRequestOptions();
requestOptions.toBuilder().setNonPersonalizedAd(ALLOW_ALL).build();
// 华为DSP投放的广告设置个性化广告与非个性化广告
RequestOptions requestOptions = HwAds.getRequestOptions();
requestOptions.toBuilder().setHwNonPersonalizedAd(ALLOW_ALL).build();
// 三方DSP投放的广告设置个性化广告与非个性化广告
RequestOptions requestOptions = HwAds.getRequestOptions();
requestOptions.toBuilder().setThirdNonPersonalizedAd(ALLOW_ALL).build();
// 设置TCF v2.0用户同意信息字符串
RequestOptions requestOptions = HwAds.getRequestOptions();
requestOptions.toBuilder().setConsent("tcfString").build();
```
