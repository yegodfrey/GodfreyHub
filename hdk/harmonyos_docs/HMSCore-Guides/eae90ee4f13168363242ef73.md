# 项目概览

|---------------------------------|-|
|本视频介绍了项目概览的功能使用，包括各个卡片的功能意义及应用场景。| |

## 功能概述

在产品运营的工作过程中，需要每日关注产品的核心指标变化情况，监控其整体运营状况。如发现有数据异常，需立即对相应指标进行具体分析，排查问题点。

项目概览通过集中展现当前项目的核心数据指标（如新增用户数、用户活跃情况等），从宏观上展示用户在产品使用过程中的表现，从而快速了解产品整体的数据情况。

## 典型应用场景

* 监控核心指标，快速了解产品的数据表现。
* 支持一键跳转报告详情页，对异常指标下钻分析，助力精细化运营。

## 功能详述

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 概览 > 项目概览"，进入项目概览页面。
4. 查看项目概览分析报告。详情请参见[查看项目概览分析报告](#section13351422162911)。
