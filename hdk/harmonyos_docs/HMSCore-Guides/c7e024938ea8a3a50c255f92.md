# 实时竞价广告

目前鲸鸿动能广告SDK客户端 v13.4.75.300以上版本添加客户端实时竞价能力。（此能力需要向流量运营申请开通）

## 支持场景

* 原生广告
* 激励广告
* 插屏广告
* 开屏广告
* 贴片广告

## 接入流程

1. 请求： 媒体侧在发起广告请求时，需要设置相关bidding的参数，具体参数：bidFloor（广告位底价）、bidFloorCur（广告位底价币种）、bpkgName（禁投的应用名单，List类型）、tMax（最大请求超时时间）、cur（广告请求中交易的币种），在AdParam.Builder类中，setTMax(Integer tMax) 设置交易的最大超时间、setCur(List<String> curs)设置交易币种、addBiddingParamMap(String slotId, BiddingParam biddingParam) 针对该广告位设置，或者通过setBiddingParamMap(Map<String, BiddingParam> biddingParamMap) 也可以设置多个广告，传入Map，key = slotId，value = 该广告位的bidding请求参数，具体参考[BiddingParam](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddingparam-0000001920059660)和[AdParam.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-builder-0000001050066829)相关接口。

2. 返回： 获取鲸鸿动能广告的竞标出价，调用各广告类型的广告对象，调用getBiddingInfo()接口获取竞价结果，如原生广告 BiddingInfo biddingInfo = nativeAd.getBiddingInfo()；再通过[getPrice](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376#section68119411565)() 接口获取本条广告的eCPM出价（元/千次展示）；若鲸鸿动能广告竞胜，调用[getNurl](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376#section14704560583)() 竞价成功通知URL，URL中含有宏替换 SECOND_PRICE、AUCTION_CURRENCY，通知SDK竞胜结果；若广告竞败，调用[getLurl](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376#section18085225575)() 获取竞价失败通知其他成功的URL，URL中含有宏替换（具体宏：AUCTION_LOSS、AUCTION_PRICE、AUCTION_CURRENCY、AUCTION_APP_PKG、AUCTION_APP_NAME、AUCTION_CP_ID）传入竞败原因，及其他广告竞胜方的出价；具体参考[BiddingInfo](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/biddinginfo-0000001920219376)、sendBiddingSuccess(Map<String, Object> sendSuccessInfo, [ReportUrlListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/reporturllistener-0000002039342792) reportUrlListener) （竞价成功）和 sendBiddingFailed(Map<String, Object> sendFailInfo, [ReportUrlListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/reporturllistener-0000002039342792) reportUrlListener)（竞价失败）。

3. 展示： 按正常广告展示方式曝光。

   **详情请参考下列各广告形式代码示例。**

   注：宏说明：

   |宏|说明|
   |:---------------|:-----------------------------------------------------------------------------------------------------------------------------|
   |SECOND_PRICE|竞胜时，其他DSP最高出价，单位元。价格明文，样例： 3.6。|
   |AUCTION_PRICE|竞败时，其他DSP最高出价，单位元。价格明文，样例： 3.6。|
   |AUCTION_LOSS|竞价结果，如果没有走到参竞环节也需要回调，并替换具体过滤结果码。 枚举： 102：竞价失败。 103：底价过滤。 104：包名过滤。 105：其他原因过滤。 4005：超时未返回--理论上不存在，媒体如果存在返回转换等流程未完成导致超时，使用此结果码。|
   |AUCTION_CURRENCY|价格币种。 支持币种：CNY、USD、EUR、GBP、JPY。|
   |AUCTION_APP_PKG|竞败时，竞胜DSP推广App包名。|
   |AUCTION_APP_NAME|竞败时，竞胜DSP推广App名称。|
   |AUCTION_CP_ID|竞败时，竞胜的DSP编号： 1：广点通 2：穿山甲 3：百青藤 4：快手联盟 5：爱奇艺 6：阿里 7：VIVO 8：OPPO 9：小米 10：京东 11：拼多多 100：其他|

## 接入SDK获取实时bidding的广告位参数方式

> 注意
>
> 需要在广告加载完成，获取广告对象调用！！！

### 原生广告

设置参与bidding的广告位请求参数。

示例代码如下：

```screen
"Java"
// "testy63txaom86"为测试专用的广告位ID，App正式发布时需要改为正式的广告位ID
NativeAdLoader.Builder builder = new NativeAdLoader.Builder(this, "testy63txaom86");
AdParam.Builder builder = new AdParam.Builder();
// 设置实时bidding广告位参数
BiddingParam biddingParam = new BiddingParam();
String slotId = "testy63txaom86";
builder.addBiddingParamMap(slotId, biddingParam);
builder.setTMax(500);
builder.setCur("币种字符列表");
nativeAdLoader.loadAds(builder.build(), 5);
```

获取BiddingInfo对象。
> 注意
>
> 因获取BiddingInfo对象可能为null，需要先进行判空处理，然后再处理bidding相关操作。

示例代码如下：

```screen
"Java"
builder.setNativeAdLoadedListener(new NativeAd.NativeAdLoadedListener() {
    @Override
    public void onNativeAdLoaded(NativeAd nativeAd) {
        // 广告加载成功后获取biddingInfo参数 
        if (nativeAd != null) {
            BiddingInfo biddingInfo = nativeAd.getBiddingInfo();
            if (biddingInfo != null) {
                // 处理bidding相关操作
                if ( // 竞胜) {
                    nativeAd.sendBiddingSuccess(sendSuccessInfo, reportUrlListener);
                } else {
                    // 竞败
                    nativeAd.sendBiddingFailed(sendFailedInfo, reportUrlListener);  
                }
            }
        }
        ...
    }
});
```

### 开屏广告

1. 创建SplashAd开屏广告对象，用于调用广告加载和展示。 示例代码如下：

   ```screen
   "Java"
   import android.os.Build;
   import androidx.appcompat.app.AppCompatActivity;
   public class SplashActivity extends AppCompatActivity {
       private RelativeLayout splashContainer;
       // 开屏广告对象
       private SplashAd splashAd;
       // 开屏广告加载状态监听器
       private SplashLoadListener splashLoadListener;
       /**
       * 暂停标志位。
       * 在开屏广告页面展示时：
       * 按返回键退出应用时需设置为true，以确保应用主界面不被拉起；
       * 切换至其他界面时需设置为false，以确保从其他页面回到开屏广告页面时仍然可以正常跳转至应用主界面；
       */
       private boolean hasPaused = false;
       @Override
       protected void onCreate(Bundle savedInstanceState) {
               super.onCreate(savedInstanceState);
               setContentView(R.layout.activity_splash);
               // 获取广告对象
               splashAd = new SplashAd(this)
               // 加载开屏广告
               loadSplashAd();
               // 展示开屏广告
               showSplashAd();
           }

      // 广告展示完毕时，从广告界面跳转至App主界面
      private void jump() {
          if (!hasPaused) {
              hasPaused = true;
              startActivity(new Intent(SplashActivity.this, MainActivity.class));
              finish();
          }
      }

      // 按返回键退出应用时需设置为true，以确保应用主界面不被拉起
      @Override
       protected void onStop() {
           Log.d(TAG, "onStop");
           hasPaused = true;
           super.onStop();
        }
         
           @Override
       /**
       * 暂停标志位。
       * 在开屏广告页面展示时：
       * 按返回键退出应用时需设置为true，以确保应用主界面不被拉起；
       * 切换至其他界面时需设置为false，以确保从其他页面回到开屏广告页面时仍然可以正常跳转至应用主界面；
       */
       protected void onRestart() {
           Log.d(TAG, "onRestart");
           super.onRestart();
           hasPaused = false;
           jump();
       }
       @Override
       protected void onDestroy() {
           super.onDestroy();
       }
   }
   ```

2. 加载广告，调用 SplashAd 对象的 loadAd()方法来加载广告。 示例代码如下：

   ```screen
   "Java"
   private void loadSplashAd() {
       AdParam.Builder builder = new AdParam.Builder();
       String splashId = "testq6zq98hecj";
       // 设置广告位参与实时bidding参数 
       BiddingParam biddingParam = new BiddingParam();
       builder.addBiddingParamMap(slotId, biddingParam);
       builder.setTMax(500);
       builder.setCur("币种字符列表");
       // 锁定设备当前屏幕方向，自适应横竖屏方向 
       setRequestedOrientation(ActivityInfo.SCREEN_ORIENTATION_LOCKED);
       int orientation = getScreenOrientation();
       // 根据当前屏幕方向设置默认Slogan和设置对应的广告位ID 
       if (orientation == ActivityInfo.SCREEN_ORIENTATION_PORTRAIT) {
           splashAd.setSloganResId(R.drawable.default_slogan);
           splashId = getString(R.string.ad_id_splash);
       } else {
           splashAd.setSloganResId(R.drawable.default_slogan_landscape);
           splashId = getString(R.string.ad_id_splash_landscape);
       }
       splashAd.setAdParam(splashId, orientation, adParam.build());
       // 设置视频类开屏广告的音频焦点类型 
       splashView.setAudioFocusType(AudioFocusType.NOT_GAIN_AUDIO_FOCUS_WHEN_MUTE);
       splashAd.loadAd(splashLoadListener);
   }
   private int getScreenOrientation() {
       Configuration config = getResources().getConfiguration();
       if (config.orientation == Configuration.ORIENTATION_LANDSCAPE) {
           return ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE;
       } else {
           return ActivityInfo.SCREEN_ORIENTATION_PORTRAIT;
       }
   }
   ```

3. 展示广告，调用 SplashAd 对象的 showAd()方法来展示广告。 示例代码如下：

   ```screen
   "Java"
   private void showSplashAd() {
       // 是否展示广告开屏slogan
       private boolean isShowSlogan = false;
       SplashView splashView = splashAd.getSplashView();
       // 设置广告点击监听
       splashView.setAdDisplayListener(new SplashAdDisplayListener(){
           private WeakReference<SplashActivity> activityRef = new WeakReference<>(SplashActivity);
           @Override
           public void onAdClick() {
               SplashActivity splashActivity = activityRef.get();
                   if (null == splashActivity) {
                       return;
               }
               super.onAdClick();
               Log.d(TAG, "onAdClick");
           }
       });
       splashContainer.removeAllViews();
       RelativeLayout.LayoutParams splashParam = new RelativeLayout.LayoutParams(ViewGroup.LayoutParams.MATCH_PARENT,
               ViewGroup.LayoutParams.MATCH_PARENT);
       splashContainer.addView(splashView, splashParam);
       splashContainer.bringToFront();
       if (splashAd.isLoaded()) {
           splashAd.showAd(isShowSlogan);
       }
   }
   ```

4. 监听器
   * 在广告加载时，调用SplashLoadListener广告加载状态监听器，用于监听广告加载状态，详情参考API文档中[SplashLoadListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/splashloadlistener-0000001989775133)类。
   * 广告加载成功，可在此时获取BiddingInfo对象。 注意
     >
     > （1）需要先调用isLoaded() 判断广告对象是否加载完成，才可获取BiddingInfo对象。
     >
     > （2）因获取BiddingInfo对象可能为null，需要先进行判空处理，然后再处理bidding相关操作。

     ```screen
     "Java"
     splashLoadListener = new SplashLoadListener() {
         @Override
         public void onAdLoaded() {
             // 广告加载成功，可获取biddingInfo 广告位参数
             if (splashAd.isLoaded()) {
                 BiddingInfo biddingInfo = splashAd.getBiddingInfo();
                 if ( biddingInfo != null ) {
                     // 处理bidding相关操作
                     if ( // 竞胜) {
                         splashAd.sendBiddingSuccess(sendSuccessInfo, reportUrlListener);
                     } else {
                         // 竞败
                         splashAd.sendBiddingFailed(sendFailedInfo, reportUrlListener);
                     }
                 }
             }
         }
         @Override
         public void onAdFailed(int errorCode) {
             // 广告加载失败
         }
     }
     ```

   * 调用SplashAd类的setSplashListener(SplashListener splashListener)方法可以为SplashAd对象添加广告事件监听器SplashListener，并通过SplashListener类中的方法来监听广告事件。详情参考API文档中[SplashListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/splashlistener-0000001989655329)类。

     ```screen
     "Java"
     // 广告展示状态监听器
     private SplashListener splashListener = new SplashListener() {
         @Override
         public void onAdShowStart() {
             // 广告开始展示
         }
      
         @Override
         public void onAdError(int errorCode) {
             // 广告展示失败
         }
      
         @Override
         public void onAdDismissed() {
             // 广告展示完毕时调用, 跳转至App主界面                     
             jump();
         }
     };
     splashAd.setSplashListener(splashListener)
     ```

* 调用SplashView类的setAdDisplayListener(SplashAdDisplayListener adDisplayListener)方法可以为开屏View中添加广告点击事件监听器SplashAdDisplayListener，并通过SplashAdDisplayListener类中的方法来监听广告点击事件。详情参考API文档中[SplashAdDisplayListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/splashaddisplaylistener-0000001050066885)类。

  ```screen
  "Java"
  // 广告展示状态监听器
  private SplashAdDisplayListener adDisplayListener= new SplashAdDisplayListener() {
      private WeakReference<SplashActivity> activityRef = new WeakReference<>(SplashActivity);
      @Override
      public void onAdclick() {
          // 广告点击
          SplashActivity splashActivity = activityRef.get();
          super.onAdClick();  
      }
  };
  SplashView.setAdDisplayListener(adDisplayListener)
  ```
