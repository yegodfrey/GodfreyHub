# 锁屏不展示通知内容

锁屏下不展示通知内容是指当设备处于锁屏状态下，收到通知栏消息后不在锁屏界面上展示通知内容。您可以通过"[visibility](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p1732114822312)"字段实现该功能，字段值说明如下：

* "VISIBILITY_UNSPECIFIED"：默认状态，效果等同于设置了"PRIVATE"。
* "PUBLIC"：锁屏时收到通知栏消息，显示消息内容。
* "SECRET"：锁屏时收到通知栏消息，不提示收到通知消息。
* "PRIVATE"：设置了锁屏密码且在"设置 > 通知 > 隐藏通知内容"启用"隐藏通知内容"，当设备收到通知栏消息将不会显示消息内容。

消息体示例：

```screen
{
    "message": {
        "notification": {
            "title": "message title",
            "body": "message body"
        },
        "android": {
            "notification": {
                "visibility": "PRIVATE",
                "click_action": {
                    "type": 3
                }
            }
        },
        "token": ["pushtoken1"]
    }
}
```
