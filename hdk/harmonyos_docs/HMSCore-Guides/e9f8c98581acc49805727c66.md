# 开通服务

                1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击“我的项目”图标。
                2. 选择需要查看动态标签管理数据的应用。
                3. 选择“增长 > 动态标签管理”进入开通服务页面。点击“开通服务”按钮来开通动态标签管理服务。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/XmX0P61ARH2qPTbKHJWmyA/zh-cn_image_0000001155029935.png?HW-CC-KV=V1&HW-CC-Date=20261005T043136Z&HW-CC-Expire=86400&HW-CC-Sign=0D10E52785E0330C6590EAC227F861DDA7B7BC783A72EA2F1058834B053249D1)

                4. 您可以在“开通服务”窗口设置配置名称，网址地址以及修改操作记录保存时间。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6f/v3/Jfal8ee0SbG8xzD6zKsXAg/zh-cn_image_0000001076742188.png?HW-CC-KV=V1&HW-CC-Date=20261005T043136Z&HW-CC-Expire=86400&HW-CC-Sign=AFAC6C7578F6D4877555B06F71020DBCDE32CD11A901B3B474E32E019CDCF6D0)

                5. 点击“确定”按钮，进入“配置”页面，会提示您安装DTM-WEB端跟踪代码。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fb/v3/DraeW4FJSQuC8exBipBDuQ/zh-cn_image_0000001261202772.png?HW-CC-KV=V1&HW-CC-Date=20261005T043136Z&HW-CC-Expire=86400&HW-CC-Sign=0D1C62BCE7AADBADCA18A1D46EBCF442142D2F13E7A48ADD9D0F55AE7FD4E5DA)

                6. 在“配置”页面，您可以看到相关配置信息，并可以进行导入、导出、编辑和关闭服务操作。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/lxR5_roURSWxiDT9QQqg4Q/zh-cn_image_0000001071543898.png?HW-CC-KV=V1&HW-CC-Date=20261005T043136Z&HW-CC-Expire=86400&HW-CC-Sign=FA334C96094FE522D74A272246E3EBA092CC3A6904C2E248502A7D55A3280F2C)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/2zDUAi_VSxOU6Xko8Hw2sg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043136Z&HW-CC-Expire=86400&HW-CC-Sign=BF538B28CE45A3DCAB30AFD9E64C71D8602D06A586E289E6D43B96EB831B91C1)

                * [团队帐号持有者](https://developer.huawei.com/consumer/cn/doc/start/team-account-guides-0000001053785552)和管理员拥有开通服务的权限。
                * 一个应用只允许创建一个配置，如果您已经完成配置创建，则无需再次创建。
