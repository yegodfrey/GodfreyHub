# 回访用户

1. 选择"华为分析 \> 用户分析 \> 回访用户"，进入报告页面。

   报告根据新增用户数，7天回访用户数，8-30天回访用户数，31-90天回访用户数，91-180天回访用户数，历史回访用户数6项指标，展示了每一天的回访用户分布情况，可衡量产品对用户的吸引力。

   假设最近一个月内进行了流失用户召回，就可以通过查看该时间段内31-90天回访用户或91-180天回访用户是否有明显增加来判断营销效果。

2. 将光标放在任一日期的柱形图上，会显示该日的回访用户分布。

   下方则以表格形式显示了每日详情数据。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115218.93173796612354475250598156598503:50001231000000:2800:92FA48C39DF88AA3DEA8D6E072B4201A2AD20082EE45331DBFBD732A0E7F3E4F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)
3. 点击"下载"，可将数据以csv的形式下载到本地，进行个性化分析。
