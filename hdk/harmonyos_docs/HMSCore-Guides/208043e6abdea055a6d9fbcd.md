# 分页查询

为避免给定查询时间范围内，因一次查询数据量过大而导致查询较慢，Kit支持分页查询，分批返回数据。分页查询总分两步：

1. 使用 [getCount](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__getCount-android_content_Context-com_huawei_hihealthkit_HiHealthDataQuery-com_huawei_hihealth_listener_ResultCallback-) 方法获取数据总数。
2. 使用 [execQuery](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdatastore-0000001071549459#ZH-CN_TOPIC_0000002547961909__execQuery-android_content_Context-com_huawei_hihealthkit_HiHealthDataQuery-int-com_huawei_hihealth_listener_ResultCallback-) 中的 [HiHealthDataQueryOption](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hihealthdataqueryoption-0000001183790424) 指定数据起止范围。

   **示例代码**：步行为例

   ```screen
   final long endTime = System.currentTimeMillis();
   final long startTime = 0; // 开始时间为0，可以查询全部数据
   HiHealthDataQuery hiHealthDataQuery =
       new HiHealthDataQuery(HiHealthSetType.DATA_SET_WALK_METADATA, startTime, endTime, null);
   HiHealthDataStore.getCount(context, hiHealthDataQuery, new ResultCallback() {
       @Override
       public void onResult(final int resultCode, final Object data) {
           if (resultCode == HiHealthError.SUCCESS) {
               final int count = (int) data;
               Log.i(TAG, "getCount : total count=" + count);
               // 查询数据条数限制在limit条以内，即每页条数，需根据实际情况自行修改，建议不超过400
               int limit = 100;
               // 分页数
               int pages = count / limit;
               if (count % limit != 0) {
                   pages++;
               }
               // 数据从offset条开始查询
               int offset = 0;
               // 根据数据产生时间的升序进行查询
               int order = 0;
               // 指定分页数
               for (int i = 0; i < pages; i++) {
                   offset = limit * i;
                   final int pageIndex = i;
                   HiHealthDataQuery hiHealthDataQuery =
                       new HiHealthDataQuery(HiHealthSetType.DATA_SET_WALK_METADATA, startTime, endTime,
                           new HiHealthDataQueryOption(limit, offset, order));
                   HiHealthDataStore.execQuery(context, hiHealthDataQuery, 0,
                       new ResultCallback() {
                           @Override
                           public void onResult(int resultCode, Object data) {
                               // 处理数据
                               if (resultCode == HiHealthError.SUCCESS && data instanceof List) {
                                   Log.i(TAG,
                                       "getCount : page=" + pageIndex + " count= " + ((List) data).size());
                               } else if (resultCode == HiHealthError.PARAM_INVALID) {
                                   // 参数错误
                                   Log.w(TAG, "Param invalid");
                               } else if (resultCode == HiHealthError.ERR_HEALTH_VERSION_IS_NOT_SUPPORTED) {
                                   // 运动健康版本过低，不支持此功能
                                   Log.w(TAG, "Health application need to be updated");
                               } else if (resultCode == HiHealthError.ERR_HMS_UNAVAILABLE_VERSION) {
                                   // HMS Core版本过低
                                   Log.w(TAG, "HMS version is too early");
                               } else if (resultCode == HiHealthError.ERR_PERMISSION_EXCEPTION) {
                                   // 授权失效
                                   Log.w(TAG, "Permission denied");
                               } else if (resultCode == HiHealthError.ERR_PRIVACY_USER_DENIED) {
                                   // 未同意运动健康隐私协议
                                   Log.w(TAG, "Privacy user denied");
                               } else if (resultCode == HiHealthError.ERR_NETWORK) {
                                   // 网络异常
                                   Log.w(TAG, "Network request failed");
                               } else if (resultCode == HiHealthError.ERR_BETA_SCOPE_EXCEPTION) {
                                   // 测试权限的用户数量超过限制
                                   Log.w(TAG, "Beta scope permission denied");
                               } else {
                                   // 其他错误，建议提示调用失败
                                   Log.w(TAG, "Other error, invoking method failed");                            
                               }
                           }
                   });
               }
           }
       }
   });
   ```

   |参数名称|参数类型|参数描述|可选选项|
   |:----------------|:----------------|:--------------|:----|
   |hiHealthDataQuery|HiHealthDataQuery|查询条件|必选(M)|
   |timeout|int|超时时间（预留字段，目前没用）|必选(M)|
   |callback|ResultCallback|结果回调|必选(M)|
   [**表1**请求参数]

   |参数名称|参数类型|参数描述|可选选项|
   |:-----|:---|:-----------------------------|:----|
   |limit|int|查询限制最大个数（参数需大于等于0），当为0时查询全部数据|必选(M)|
   |offset|int|偏移量（从第几个开始查询，参数使用需大于等于0）|必选(M)|
   |order|int|查询按时间排序（只能传0或1，0为时间升序，1为时间降序。）|必选(M)|
   [**表2**HiHealthDataQueryOption 参数]

   |参数名称|参数类型|参数描述|
   |:---------|:-----|:------------------------------------------------------------------------------------------------------------------------|
   |resultCode|int|处理结果码 * 0：成功 * 其他：参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/extended-errocode-0000001053256958)|
   |data|Object|数据列表 成功（有数据）：List<HiHealthSetData> 或List<HiHealthPointData> 成功（无数据）: 空列表List<>(0) 其他：错误描述信息（String）|
   [**表3**响应参数]
