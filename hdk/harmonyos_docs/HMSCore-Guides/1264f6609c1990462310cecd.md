# 接入Analytics  
  
分析服务提供基于您上报事件的分析数据模型。

分析数据模型采用了Event-Param-User模型来记录数据，通过不同的参数对事件进行描述，同时对用户的特征也进行了描述。

术语 | 名称 | 说明  
---|---|---  
Event | 事件 | 描述一个用户在某个时间点、某个地方、以某种方式完成了某个具体的事情。包含who、when、where、how、what等关键要素。  
Param | 参数 | 事件上报的关联参数。如加入购物车事件中的商品名称参数，商品价格参数，支持后续的深入分析。  
UserProfile | 用户属性 | 用户的属性表，常见的用户属性有设备型号、应用版本、自定义的用户属性（如食品偏好）等。  
  
Analytics Kit会收集AAID。AAID是应用匿名标识符，每个App在同一个设备上会分配不同的AAID。AAID用于连通华为提供的各项服务，例如分析服务和远程配置。

AAID会在如下场景重置：

                * 用户删除后再次启动快应用。 
                * 用户恢复出厂设置。 
                * 用户清除应用数据。

                1. 导入并初始化SDK。
                   1. 导入SDK。

                            // ...
                          };

#### 示例代码

                1. 导入SDK。
                       
                       import agconnect from '@hw-agconnect/api';
                       import '@hw-agconnect/instance';
                       import '@hw-hmscore/analytics-sdk-quickapp';

                2. 初始化配置拷贝成功后，在“app.ux”的入口初始化Analytics SDK，获得[HiAnalytics](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/quickapp-api-analytics-0000001077322170)的实例。若拷贝的内容不正确，则无法进行埋点。
                       
                       // TODO: 用您应用的配置替换下方代码
                       const agConnectConfig = {
                         // ...
                       };
                       // 配置agconnect实例
                       agconnect.instance().configInstance(agConnectConfig);
                       // 初始化分析实例
                       let analytics = agconnect.analytics();

                3. 自定义事件埋点，在代码合适位置插入埋点代码。
                       
                       // 自定义事件埋点，在工程合适位置插入埋点代码
                       let eventId = "Complete_Exam";
                       let eventParams = {
                         "Score": 95,
                         "Level": "high"
                       };
                       analytics.onEvent(eventId, eventParams);

                4. 预置事件埋点，在代码合适位置插入埋点代码。
                       
                       // 预置事件埋点，在工程合适位置插入埋点代码
                       let preDefineParams = agconnect.analytics.ParamName;
                       let preDefineEvents = agconnect.analytics.EventName;
                       let eventParams = {};
                       eventParams[preDefineParams.PRODUCTID] = 'item_ID';
                       eventParams[preDefineParams.PRODUCTNAME] = 'name';
                       eventParams[preDefineParams.CATEGORY] =  'category';
                       eventParams[preDefineParams.QUANTITY] =  100;
                       eventParams[preDefineParams.PRICE] =  10.01;
                       eventParams[preDefineParams.REVENUE] =  10;
                       eventParams[preDefineParams.CURRNAME] =  'currency';
                       eventParams[preDefineParams.PLACEID] =  'location_ID';
                       analytics.onEvent(preDefineEvents.ADDPRODUCT2WISHLIST, eventParams);

#### 接入调试

在开发过程中可以启用调试模式，实时查看事件的记录情况，观察具体结果并根据需要进行调整。

#### [h2]开启调试模式

在SDK初始化之前，添加以下代码以启用调试模式（切勿在生产环境使用调试模式）。
    
    // 启用调试模式
    agconnect.analytics.InitSettings.debugMode = true;
    // 调试模式下，自定义终端标识
    agconnect.analytics.InitSettings.terminalName = "custom terminal name";
    // 初始化分析实例 
    let analytics = agconnect.analytics();

调试模式打开后，所有事件将实时上报，在“华为分析 > 应用调试”界面可实时查看上报的数据如下图：

#### 禁用控制台日志打印

快应用SDK默认打印控制台日志，如果您想禁用日志打印功能，可以在SDK初始化之前添加如下启动配置项：
    
    // 是否禁用日志打印
    agconnect.analytics.InitSettings.logDisabled = true;
    // 打印的最小日志级别，不区分大小写，支持的配置：INFO|WARN|ERROR
    agconnect.analytics.InitSettings.logLevel = 'INFO';
