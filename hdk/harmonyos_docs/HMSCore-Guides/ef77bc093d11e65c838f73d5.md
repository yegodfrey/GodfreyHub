# 存储与查询数据

以步数为例，介绍如何通过HTTP REST接口存储与查询一组数据，详细的HTTP REST接口请参见[Health Service Kit REST API参考](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/rest-overview-0000001254420693)。  

#### 创建数据采集器

在HUAWEI Health Service Kit，采样点是基于数据采集器（dataCollector）收集存储的，因此上传采样点前，必须先创建数据采集器。如下创建了数据类型为com.huawei.continuous.steps.delta的数据采集器，用于采集步数信息。

URL请求：

POST https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors

请求体：

```
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
x-caller-trace-id: ***
{
    "collectorName": "DataCollectorExample",
    "collectorType": "raw",
    "appInfo": {
        "appName": "Example App",
        "desc": "https://huaweiapi.com",
        "appVersion": "1"
    },
    "collectorDataType": {
        "name": "com.huawei.continuous.steps.delta"
    },
    "deviceInfo": {
        "manufacturer": "huawei",
        "modelNum": "ExampleTablet",
        "devType": "Phone",
        "uniqueId": "1000",
        "version": "1.0"
    }
}
```

如果数据采集器创建成功，响应码为 200 OK，响应体如下：

```
HTTP/1.1 200 OK
Content-type: application/json;charset=utf-8
{
    "collectorId": "cmF3OmNjb250aW51b3VzLnN0ZXBzLmRlbHRhEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg",
    "collectorName": "DataCollectorExample",
    "collectorType": "raw",
    "collectorDataType": {
        "name": "com.huawei.continuous.steps.delta",
        "field": [
            {
                "name": "steps_delta",
                "format": "integer"
            }
        ]
    },
    "deviceInfo": {
        "uniqueId": "1000",
        "devType": "Phone",
        "version": "1.0",
        "modelNum": "ExampleTablet",
        "manufacturer": "huawei"
    },
    "appInfo": {
        "appName": "Example App",
        "appVersion": "1",
        "desc": "https://huaweiapi.com",
        "clientId": "101272135"
    }
}
```

![](https://media:901788166613312451)  
响应体中返回的collectorId在后续上传采样点、查询采样数据等场景均有使用。  

#### 上传采样点

创建数据采集器后，可以上传步数的采样点（SamplePoint），采样点的上传是依托于采样集（SampleSet）实现的。

#### 查询采样数据

如果开发者希望获取某时间段内的采样数据，可以通过GET方法进行查询。

URL请求：

GET https://health-api.cloud.huawei.com/healthkit/v2/dataCollectors/cmF3OmNjb250aW51b3VzLnN0ZXBzLmRlbHRhEwMTI3ODUwMTpqEF7rB3uBcGykpv6T2TisfTMhfZAvz1BP2Kcz70d1Sg/sampleSets/1584460800000000000-1584626400000000000

请求头:

```
Content-Type: application/json
Authorization: Bearer ***
x-client-id: ***
x-version: ***
```
