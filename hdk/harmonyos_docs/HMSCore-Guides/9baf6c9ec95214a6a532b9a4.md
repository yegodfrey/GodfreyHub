#### 导入接口类

使用数据捐赠能力，除需要导入情景感知服务的公共能力类外，还需要导入数据捐赠相关的类。

```
import com.huawei.hms.kit.awareness.Awareness;
// 导入数据捐赠相关的类
import com.huawei.hms.kit.awareness.DonateClient;
import com.huawei.hms.kit.awareness.donate.message.Content;
import com.huawei.hms.kit.awareness.donate.message.ContentData;
import com.huawei.hms.kit.awareness.donate.message.Message;
import com.huawei.hms.kit.awareness.donate.message.Session;
```

#### 能力开发

1. 获取Awareness Kit的"DonateClient"。

   <br />

   ```
   import com.huawei.hms.kit.awareness.DonateClient;
   ```

   <br />

2. 通过"DonateClient"调用数据捐赠接口进行数据捐赠。
3. 根据情景感知服务返回的结果，进行应用的业务处理。

   <br />

   ```
   "Java"    
           // 0 创建客户端
           DonateClient client = Awareness.getDonateClient(this);
           // 1 创建session对象用于构造message对象
           Session session = new Session();
           session.setMessageName("featurePrediction");
           session.setMessageId("111"); // MessageId不能重复
           session.setDeviceModel(Build.MODEL);
           session.setDeviceCategory("phone");
           session.setDeviceName("SystemPropertiesEx.");
           JSONObject eventCommonInfo = new JSONObject();
           JSONObject faResource = new JSONObject();
           JSONObject predictInfo = new JSONObject();
           try {
               // 2 创建eventCommonInfo用于构造contentData对象
               eventCommonInfo.put("timeZone", TimeZone.getDefault().getDisplayName(false, TimeZone.SHORT));
               eventCommonInfo.put("createTime", System.currentTimeMillis());
               // 3 创建业务自定义payload用于构造contentData对象
               faResource.put("bundleName", "xxxx"); // 根据自己的功能实际填写
               faResource.put("moduleName", "yyyy"); // 根据自己的功能实际填写
               faResource.put("abilityName", "zzzz"); // 根据自己的功能实际填写
               faResource.put("formName", "aaaa"); // 根据自己的功能实际填写
               // 4 填写功能推测时间
               predictInfo.put("featureName", "playListRecommend"); // 根据自己的功能实际填写
               JSONArray timelineInfo = new JSONArray();
               JSONObject timelineInfoItem1 = new JSONObject();
               timelineInfoItem1.put("startTime", System.currentTimeMillis()); // 根据自己的功能实际填写
               timelineInfoItem1.put("endTime", System.currentTimeMillis() + 30 * 60 *1000); // 时间范围在当前时间-7天之内
               timelineInfo.put(timelineInfoItem1);
               predictInfo.put("timelineInfo", timelineInfo);
           } catch (JSONException e) {
               Log.w(TAG, "dataReport JSONException");
           }
           // 5 创建ContentData用于构造message对象
           ContentData contentData = new ContentData();
           // 设置header用于构造contentData对象
           contentData.setHeader("namespace", "event");
           contentData.setHeader("name", "featurePrediction");
           // 设置事件载体用于构造contentData对象
           contentData.setPayload("eventCommonInfo", eventCommonInfo);
           contentData.setPayload("predictInfo", predictInfo);
           contentData.setPayload("faFormInfo", faFormInfo);
           List<ContentData> contentDatas = new ArrayList<>();
           contentDatas.add(contentData);
           // 6 创建Content对象用于构造message对象
           Content content = new Content();
           content.setContentVersion("2.1");
           content.setContentData(contentDatas);
           // 7 创建Message，用于调用数据捐赠接口
           Message message = new Message();
           message.setSession(session);
           message.setContent(content);
           // 8 上报数据，处理结果
           client.sendMessage(message).addOnSuccessListener(donateResponse -> {
               // success
               Toast.makeText(this, "sendMessage success!", Toast.LENGTH_SHORT).show();
           }).addOnFailureListener(e -> {
               // failure
               Toast.makeText(this, "sendMessage failed!", Toast.LENGTH_SHORT).show();
           });
   ```

   // 0 创建客户端
           val client: DonateClient = Awareness.getDonateClient(this)
           // 1 创建Session
           val session = Session()

               // 3 创建业务自定义payload

           val message = Message()

           message.setContent(content)
           // 8 上报数据，处理结果
           client.sendMessage(message).addOnSuccessListener { donateResponse ->
               // success
               Toast.makeText(this@DonateActivity, "sendMessage success!", Toast.LENGTH_SHORT).show()
           }.addOnFailureListener { e ->
               // failure
               Toast.makeText(this@DonateActivity, "sendMessage failed!", Toast.LENGTH_SHORT).show()
           }
