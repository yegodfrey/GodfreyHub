# 读取实时步数

本章节提供通过华为Health Service Kit客户端读取用户实时总步数的方法示例。

若需操作启、停实时总步数的读取，建议您给应用申请WakeLock，且在前台Service服务中调用华为Health Service Kit客户端提供的启停实时读取总步数接口。前台Service的实现有很多种，在此举例绑定通知栏实现前台Service，代码实现详见[示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sample_code-0000001417949178)。

实时步数读取能力如下：

* 三方应用在前台Service中调用开启实时总步数读取接口，该接口将从0开始计步，并实时回调步数总量数据。
* 三方应用在前台Service中调用停止实时总步数读取接口，该接口将停止实时计步，步数总量数据将不再回调至三方应用。

使用实时步数读取能力前请阅读如下内容：

* 官方推荐：建议三方应用申请WakeLock，再使用前台Service调用实时步数读取接口，这样能保证在手机灭屏场景下，实时步数仍持续回调。
* 官方不建议：第三方应用采用前台应用集成实时步数读取接口，该场景设备屏幕亮起状态数据能正常回调，屏幕熄灭数据将无法实时回调。
* 同一个第三方应用集成实时步数读取功能，该接口目前只支持1个listener回调。
* 支持同一设备多个生态第三方应用集成实时步数读取功能，回调数据互不干扰。
* 第三方应用在开启实时步数读取功能后，若应用crash则停止实时步数读取。
* 第三方应用每次调用[startRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/autorecordercontroller-0000001050091345#section35051641993)接口，实时步数都重新以0开始计步，实时返回start-stop期间产生的步数数据。该时间段内产生的步数数据需三方应用自行存储。
* 调用实时数据读取接口时，确认是否已同意申请HMS Core应用健身运动权限，确认步骤 ： 华为手机（Android Version \>= 10.0）用户申请权限步骤："打开HMS Core应用 \> 权限 \> 健身运动"。

  非华为手机用户申请权限步骤："打开应用管理 \> HMS Core应用 \> 权限管理 \> 后台弹出界面"。

接口调用可执行以下操作：

开启实时读取：

```
// 请注意此处的this为Activity对象
final AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(this);
// 创建数据回调对象onSamplePointListener打印步数数据
private OnSamplePointListener onSamplePointListener = new OnSamplePointListener() {
    @Override
    public void onSamplePoint(SamplePoint samplePoint) {
        for (Field field : samplePoint.getDataType().getFields()) {
            Log.i("AutoRecorderTest", "Field: " + field.getName() + " Value: " + samplePoint.getFieldValue(field));
        }
    }
};

// 1. 使用指定的数据类型（步数总量：DT_CONTINUOUS_STEPS_TOTAL），调用开始实时步数总量读取接口
DataType dataType = DataType.DT_CONTINUOUS_STEPS_TOTAL;
// 2. 启动总步数的实时读取，总步数将以0步开始，记录用户此后的总步数
// 摇动手机时，总步数将以固定时间间隔实时回调数据给用户，当用户主动结束读取，总步数将停止回调
controller.startRecord(dataType, onSamplePointListener).addOnCompleteListener(new OnCompleteListener<Void>() {
    @Override
    public void onComplete(Task<Void> taskResult) {
        // 接口不会一直返回成功，所以需要增加异常回调的处理，目前接口失败的原因包括：应用没有授权，类型不支持
        if (taskResult.isSuccessful()) {
            Log.i("AutoRecorderTest", "onComplete startRecordByType Successful");
        } else {
            Log.i("AutoRecorderTest", "onComplete startRecordByType Failed");
        }
    }
}).addOnSuccessListener(new OnSuccessListener<Void>() {
    @Override
    public void onSuccess(Void result) {
        Log.i("AutoRecorderTest", "onSuccess startRecordByType Successful");
    }
}).addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        Log.i("AutoRecorderTest", "onFailure startRecordByType Failed: " + e.getMessage());
    }
});
```

停止实时读取：

```
// 请注意此处的this为Activity对象
final AutoRecorderController controller = HuaweiHiHealth.getAutoRecorderController(this);
// 创建回调对象onSamplePointListener
private OnSamplePointListener onSamplePointListener = new OnSamplePointListener() {
    @Override
    public void onSamplePoint(SamplePoint samplePoint) {
    }
};
// 1. 使用指定的数据类型（步数总量：DT_CONTINUOUS_STEPS_TOTAL），调用停止实时步数总量读取接口
DataType dataType = DataType.DT_CONTINUOUS_STEPS_TOTAL;
// 2. 启动总步数的实时读取，总步数将以0步开始，记录用户此后的总步数
// 摇动手机时，总步数将以固定时间间隔实时回调数据给用户，当用户主动结束读取，总步数将停止回调
controller.stopRecord(dataType, onSamplePointListener).addOnCompleteListener(new OnCompleteListener<Void>() {
    @Override
    public void onComplete(Task<Void> taskResult) {
        // 接口不会一直返回成功，所以需要增加异常回调的处理，目前接口失败的原因包括：应用没有授权，类型不支持

            Log.i("AutoRecorderTest", "onComplete stopRecordByType Successful");
        } else {
            Log.i("AutoRecorderTest", "onComplete stopRecordByType Failed");
        }
    }
}).addOnSuccessListener(new OnSuccessListener<Void>() {
    @Override
    public void onSuccess(Void result) {
        Log.i("AutoRecorderTest", "onSuccess stopRecordByType Successful");
    }
}).addOnFailureListener(new OnFailureListener() {
    @Override
    public void onFailure(Exception e) {
        Log.i("AutoRecorderTest", "onFailure stopRecordByType Failed: " + e.getMessage());
    }
});
```
