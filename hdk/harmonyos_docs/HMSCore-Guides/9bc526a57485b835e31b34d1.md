# 版本更新说明

#### 6.9.9-300（2023-01-31）

本次Web版本特性变更如下： **新增特性**
                * 新增定时上报策略、阈值上报策略。 
                * 新增立即上报接口[onReport()](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/javascript-api-analytics-0000001050825689#section10604154445114)。 
**修改特性**
                * 自动采集事件[APPFIRSTOPEN](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-automatic-event-collection-0000001051740557#ZH-CN_TOPIC_0000001055104489__li1902124561120)和[LAUNCHAPP](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-automatic-event-collection-0000001051740557#ZH-CN_TOPIC_0000001055104489__li197281146256)的上报时机改为实时上报。 
                * [ENTERSCREEN](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-automatic-event-collection-0000001051740557#ZH-CN_TOPIC_0000001055104489__li12461726121319)和[EXITSCREEN](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/javascript-automatic-event-collection-0000001051740557#ZH-CN_TOPIC_0000001055104489__li1142811481511)事件的参数值默认不带URL参数。
