# 配置AppGallery Connect

在开始开发应用前，需要在AppGallery Connect中配置相关信息。

## 注册成为开发者

在开发应用前需要在[华为开发者联盟](https://developer.huawei.com/consumer/cn)网站上注册成为开发者并完成实名认证，具体方法请参见[帐号注册认证](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。

## 开通商户服务

您需要开通商户服务才能使用华为应用内支付服务。具体请参见[商户服务](https://developer.huawei.com/consumer/cn/doc/start/merchant-service-0000001053025967)。

商户服务里配置的银行卡账号、币种，用于您接收华为分成收益。需要您提供如下信息：

* 收款银行卡信息（开户行国家、开户银行、开户行支行、开户行号、开户名等）
* 税务信息（税务地点、税务注册地址、税票类型）
* 联系人（市场、财务、法务、业务合作）

当您销售商品后，可以选择"管理中心 > 我的账户"，选择"收益"，进入自助结算页面，查看商品产生的收益结算单并申请结算，详情见[自助结算指南](https://developer.huawei.com/consumer/cn/doc/start/checkoutguide-0000001053128363)。也可以选择"管理中心 > 我的报表 > 支付报表"，查看或导出指定时间段内支付明细和优惠券明细。

## 创建应用

参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和[创建应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。

## 生成签名证书指纹

签名证书指纹用于校验应用的真实性，您需要根据签名证书在本地生成签名证书指纹，并在应用上架前将签名证书指纹配置到AppGallery Connect。

在生成签名证书指纹前需要满足以下两个条件：

* 已创建应用程序的签名证书，签名证书创建请参见[生成签名证书](https://developer.huawei.com/consumer/cn/codelab/HMSPreparation/index.html#2)。
* 当前PC已经安装[JDK](https://www.oracle.com/java/technologies/javase-downloads.html)。

操作步骤如下：

* Windows
  1. 执行CMD命令打开命令行工具，执行**cd** 命令进入keytool.exe所在的目录（以下样例为JDK安装在C盘的Program Files目录）。

     ```screen
     cd C:\Program Files\Java\jdk\bin
     ```

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore C:\TestApp.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.76139908735807615541013923823138:50001231000000:2800:F83F21E04097589F2F1C7C5033D4777526F0D90C8C3CCF54953F585D1DAD7E56.png "点击放大")

* macOS
  1. 打开Terminal终端。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.03432127489296358312416617465240:50001231000000:2800:5D82CF72398F4999040E8E66EEB603BC14CC3734B0F771A2974925BB5E3C97B7.png)

  2. 执行命令**keytool -list -v -keystore** *<keystore-file>* ，按命令行提示进行操作。*<keystore-file>* 为应用签名证书的完整路径。

     例如：

     ```screen
     keytool -list -v -keystore /Users/admin/Downloads/HmsDemo.jks
     ```

  3. 根据结果获取对应的SHA256指纹。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.30984732390408625363523678727476:50001231000000:2800:A21934AEB6FFCAF8C0280D9871C646CEADF66FE1DD9E4EBA55238A25B6141BF8.png)

## 配置签名证书指纹

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，点击"我的项目"。
2. 在项目列表中找到您的项目，在项目中点击需要配置签名证书指纹的应用。
3. 在"项目设置 > 常规"页面的"应用"区域，点击"SHA256证书指纹"后的"添加证书指纹"，输入生成的SHA256指纹。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.02606889697957961026914836353509:50001231000000:2800:E8BB651CFD642BF9B38CDA5D41F19AC89078282F5CCC3573FEF11CEBBA52C80E.png)
   > 说明
   >
   > 在"项目设置"页面的"应用"区域，点击"Client Secret"后面的![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.94753846616732483380607375314643:50001231000000:2800:666355D51D6461ED66644DBD2459AFFBAD5F792AFBC4D7C5FDDE9FC3858C1F2E.png)即可复制Client Secret。

4. 配置完成后，点击"保存"。

## 打开相关服务

需要使用华为应用内支付功能的应用必须打开应用内支付服务开关。打开服务开关是应用级别的，即每个需要使用华为应用内支付服务的应用都需要先打开应用内支付服务开关。

1. 登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"我的项目"。
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要开通服务的应用。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.30030431848905488333939857369797:50001231000000:2800:8285B35B4C46DC66FD964E30F8D5A91EEFE9543B8F29850A3CA7CE7280E5F1B6.png "点击放大")

3. 点击"API管理"页签，打开应用内支付服务所在行的开关。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.48787151400693304320572186862422:50001231000000:2800:C88A5753C808E5F3555F1FCFB307D7A6C877190D7AEE91538938DDAF86AF8865.png)

## 配置支付服务参数

1. 登录[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，选择"开发与服务"。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.24352055401319770805214522420545:50001231000000:2800:8B0606CFF0E34053CBBB479CD48F446F10CFB5E15780F68908F1DA08A363C6F3.png)
2. 在项目列表中找到您的项目，在项目下的应用列表中选择需要配置支付服务参数的应用。 ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.07527679696910076006106753989751:50001231000000:2800:92C2EC560020B4C309E4315959394FA339B1D77EF382157BAB27E10995C4CB0C.png "点击放大")

3. 在左侧导航栏选择"盈利 > 应用内支付服务"，点击"设置"。

   如果首次配置会弹出签署协议弹框。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.24156173695583372121424237244398:50001231000000:2800:8D6926349F20FE9DC18E55B1D9697C33A2D568F5613B22846B6C8FFD916836BA.png)
   > 说明
   >
   > 设置完成后页面中会生成公钥信息，请保存获取到的公钥，此公钥将用于IAP SDK接口返回数据的验签，以保证数据没有被篡改。
4. （可选）打开"订单/订阅关键事件通知"所在行开关。选择通知服务版本，v1仅支持订阅服务关键通知，v2新增支持订单事件通知；配置通知接收地址，完成后点击"确认"。 说明
   > * 用户购买一次性商品和订阅型商品后，华为应用内支付服务器会在订单/订阅场景的某些关键事件发生时通知您配置的订单/订阅通知地址，具体可参见[接收订单/订阅关键事件通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/notifications-about-subscription-events-0000001050035037)。
   > * 用户使用延迟付款型支付功能时，华为应用内支付服务器会在该场景的某些关键事件发生时通知您配置的订单/订阅通知地址，具体请参见[接收延迟付款型支付关键事件通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/notifications-about-pending-payment-events-0000001184383570)。

   ![](https://alliance-communityfile-drcn.dbankcdn.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20260206135214.66804789421033232222855998354641:50001231000000:2800:DFF1E40D9053F7D403D8B40DBEA8435FD9973923B89A9BC1A5748AA4CA2B5780.png "点击放大")

5. （可选）打开"使用SHA256WithRSA/PSS签名算法"所在行开关，可指定[关键事件通知版本v1](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-notifications-about-subscription-events-0000001050706084)和[关键事件通知版本v2](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-notifications-about-subscription-events-v2-0000001385268541)请求体中的签名使用SHA256WithRSA/PSS算法。关闭该开关时，订单/订阅关键事件通知请求体中的签名使用SHA256WithRSA算法。开关初始状态为关闭状态。
