# 应用发布

#### 了解上架规则

您完成集成服务，提交应用上架前，请先了解如下上架规则和审核常见问题：

* [华为应用市场审核指南](https://developer.huawei.com/consumer/cn/doc/distribution/app/50104)
* [应用审核FAQ](https://developer.huawei.com/consumer/cn/doc/distribution/app/50106)

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20240807155804.89097837442117817566338454198457:50001231000000:2800:912E985EA04559488F19A802912DDE869397494270DCAE9633678369219C5AB0.png?needInitFileName=true?needInitFileName=true)  
按照应用市场的[隐私政策](https://developer.huawei.com/consumer/cn/doc/distribution/app/50104#h2-1656069583693-3)，所有上架App只要集成了第三方SDK，都需要在App的隐私政策中逐一明示SDK收集个人信息的目的、方式和范围，不然可能会导致上架不通过。本SDK的明示信息请参见开发指南"SDK隐私声明"章节。  

#### 发布应用

您完成HarmonyOS应用开发后，按如下步骤将应用打包成App，并发布到华为应用市场。

1. [生成密钥和证书请求文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/publish_app-0000001053223745-V3#section9752152162813)
2. [申请应用发布证书](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-releaseapp-0000001126380068#section77704814290)
3. [申请发布Profile](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-harmonyos-releaseapp-0000001126380068#section154181517295)
4. [配置签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/publish_app-0000001053223745-V3#section280162182818)
5. [编译构建App](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/publish_app-0000001053223745-V3#section1992513343374)
6. [发布App到华为应用市场](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V3/publish_app-0000001053223745-V3#section52722118382)
