# 商户服务器实现接口更新卡券

商户应用通过SDK将卡券添加到华为钱包App后，如需要更新，则需要在其服务器实现下列接口，供华为钱包App调用以查询和更新所添加的卡券包。

## 注册监听卡券更新接口

接口功能：钱包App通过此接口到商户服务器监听卡券更新。

场景介绍**：** 卡券包添加到钱包后，钱包会将一个由当前移动设备和用户信息确定的唯一ID（后描述为用户设备ID）和该卡券包的唯一标识(*serialNumber*)通过此接口发送给商户服务器，商户服务器需建立该ID和此唯一标识所代表的卡券包对应关系，当此卡券包有更新时需将对应用户设备ID通过钱包服务器的更新接口通知到钱包服务器，钱包服务器在收到更新请求后，会向此ID对应的设备发送卡券更新通知。
> 说明
>
> 因华为设备的pushToken可能会变化，所以此接口需要支持更新操作，当设备的pushToken变化时华为钱包会再次调用此接口来更新pushToken。

* URL：

  ```screen
  POST {webServiceURL}/version/devices/{deviceId}/registrations/{passTypeIdentifier}/{serialNumber}
  ```

  URL中的参数说明：

  |名称|类型|描述|可选O/必选M|
  |:-----------------|:-----|:------------------------------------------------|:------|
  |webServiceURL|String|地址为商户服务器接口请求地址，对应卡券包中hwpass.json中的webServiceURL字段|M|
  |version|String|固定值v1|M|
  |*deviceId*|String|手机设备ID|M|
  |passTypeIdentifier|String|卡券类型ID|M|
  |serialNumber|String|卡券序列号|M|

  > 说明
  >
  > 由于是直接拼装URL，不可以包含特殊字符。


* 请求参数

  请求消息头

  |名称|类型|描述|可选O/必选M|
  |:------------|:-----|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------|
  |Authorization|String|HuaweiPassToken+空格+Base64（卡卷包hwpass.json中的authorizationToken字段），authorizationToken主要用于商户服务器验证当前华为钱包请求是否有效，商户判断authorizationToken是否由商户自己签发。 完整示例："HuaweiPassToken CUDJEMSDIJGHSAESJEMSDIJGHSAESCUD"。|M|

  请求消息体（json格式）：

  |名称|类型|描述|可选O/必选M|
  |:--------|:-----|:------------------------|:------|
  |pushToken|String|商户发送Pass更新通知时需要传入的Token值。|M|

  样例：

  ```screen
  {
   "pushToken":"xxxxxx"
  }
  ```

* 响应参数：

  |名称|类型|描述|可选O/必选M|
  |:---------|:----------|:-----------------------------|:------|
  |HttpStatus|HTTP Status|* 200：成功。 * 401：请求错误（token错误）。|M|

## 发送卡券更新通知接口

接口功能：商户服务器通过调用此接口告知钱包服务器有卡券列表更新。

场景介绍：商户服务器调用此接口来告知钱包服务器已有卡券包更新，此时钱包服务器会根据传递过来的对应用户设备ID向对应的手机用户推送Push通知告知钱包端测去商户服务器获取卡券更新列表

* URL：

  ```screen
  POST https://{domain:port}/Wallet/pass/push/update
  ```

* 请求参数 参数说明：

  |名称|类型|描述|可选O/必选M|
  |:--------|:-----|:---------------------------------------------------------------------------------------------------------------------|:------|
  |signature|String|使用华为签发的证书采用PKCS7 attached模式(签名带签名数据)对pushMessage签名并Base64编码。 示例：Base64(PKCS7Sign(JSON(pushMessage).getBytes("UTF-8"))。|M|

  pushMessage是一个json的数据,json结构定义如下：

  |参数名|类型|说明|可选O/必选M|
  |:--------|:-----|:--------------------|:------|
  |pushToken|String|必传，卡片注册时获取的pushToken。|M|

* 响应参数

  |名称|类型|描述|可选O/必选M|
  |:---------|:----------|:-------------------------------|:------|
  |returnCode|String|* 0：成功。 * 其他：失败。|M|
  |returnDesc|String|返回值描述|M|
  |HttpStatus|HTTP status|* 200: 成功 * 400：请求错误（验签失败或包内容错误）|M|

  请求示例：

  ```screen
  ObjectNode messageJson = JsonNodeFactory.instance.objectNode();
  messageJson.put("pushToken","");
  byte[] messageBytes = messageJson.toString().getBytes(StandardCharsets.UTF_8);
  byte[] signMessage = passFileService.signMessage(messageBytes, passType);
  String signByteStr = Base64.encodeBase64String(signMessage);
  return signByteStr;
  ```

## 获取卡券更新列表接口

接口功能：钱包App通过此接口获取卡券更新列表。

场景介绍：钱包应用收到卡券更新通知，调用此接口获取该商户所有待更新卡片的serialNumber列表。

* URL：

  ```screen
  GET {webServiceURL}/version/devices/{deviceId}/registrations/{passTypeIdentifier}?passesUpdatedSince={tag}
  ```

  URL中参数说明：

  |名称|类型|描述|可选O/必选M|
  |:-----------------|:-----|:------------------------------------------------------|:------|
  |webServiceURL|String|地址为商户服务器接口请求地址，对应卡券包中hwpass.json中的webServiceURL字段。|M|
  |version|String|固定值v1。|O|
  |devices|String|固定值devices。|O|
  |*deviceId*|String|手机设备ID。|O|
  |registrations|String|固定值registrations。|O|
  |passTypeIdentifier|String|卡券类型ID。|M|
  |passesUpdatedSince|String|*华为钱包应用将Pass包hwpass.json中*passesUpdatedSince的值传递给商户服务器。|M|

  > 说明
  >
  > 由于是直接拼装url，不可以包含特殊字符。
* 请求参数 请求消息头：

  |名称|类型|描述|可选O/必选M|
  |:------------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------|
  |Authorization|String|HuaweiPassToken+空格+Base64(卡卷包hwpass.json中的authorizationToken字段)，authorizationToken主要用于商户服务器验证当前华为钱包请求是否有效，商户判断authorizationToken是否由商户自己签发。 完整示例："HuaweiPassToken CUDJEMSDIJGHSAESJEMSDIJGHSAESCUD"|M|

* 响应参数

  |名称|类型|描述|可选O/必选M|
  |:---------|:----------|:-------------------------------|:------|
  |HttpStatus|HTTP Status|* 200: 成功。 * 401: 请求错误(token错误)。|M|

  响应消息体（json格式）:

  |名称|类型|描述|可选O/必选M|
  |:------------|:-----|:---------------------|:------|
  |lastUpdated|String|最新的Tag，可以用于与本地Tag进行比对。|M|
  |serialNumbers|String|更新的Pass序号列表。|O|

  样例：

  ```screen
  {
   "lastUpdated":"xxxxxx",
   "serialNumbers" :[ "1001","1020","6045"]
  }
  ```

## 获取更新后的卡券包

接口功能：钱包App通过此接口到商户服务器获取最新的卡券包。

场景介绍：钱包App将通过调用此接口，获取某一个serialNumber所标识的卡券的最新内容。

* URL：

  ```screen
  GET {webServiceURL}/version/passes/{passTypeIdentifier}/{serialNumber}
  ```

  URL中参数说明：

  |名称|类型|描述|可选O/必选M|
  |:-----------------|:-----|:-------------------------------------------------|:------|
  |webServiceURL|String|地址为商户服务器接口请求地址，对应卡券包中hwpass.json中的webServiceURL字段。|O|
  |version|String|固定值v1。|M|
  |passTypeIdentifier|String|卡类型ID。|M|
  |serialNumber|String|卡序列号。|M|

* 请求参数 请求消息头:

  |名称|类型|描述|可选O/必选M|
  |:------------|:-----|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------|
  |Authorization|String|HuaweiPassToken+空格+Base64(卡卷包hwpass.json中的authorizationToken)，authorizationToken主要用于商户服务器验证当前华为钱包请求是否有效，商户判断authorizationToken是否由商户自己签发。 完整示例："HuaweiPassToken CUDJEMSDIJGHSAESJEMSDIJGHSAESCUD"|M|

* 响应参数

  |名称|类型|描述|可选O/必选M|
  |:---------|:----------|:-------------------------------|:------|
  |HttpStatus|HTTP Status|* 200: 成功。 * 401: 请求错误(token错误)。|M|
  |HttpBody|HTTP Body|Pass包的二进制内容。|M|

## 取消监听卡券更新接口

接口功能：钱包App通过此接口到商户服务器取消监听卡券更新。

场景介绍：用户在钱包应用删除一张卡券时，钱包app将通过调用此接口，将该移动设备的用户设备ID与此卡券的serialNumber上传到商户服务器，商户服务器需要解除此用户设备ID与此卡券serialNumber的对应关系。

* URL

  ```screen
  DELETE {webServiceURL}/version/devices/{deviceId}/registrations/{passTypeIdentifier}/{serialNumber}
  ```

  URL中参数说明：

  |名称|类型|描述|可选O/必选M|
  |:-----------------|:-----|:-------------------------------------------------|:------|
  |webServiceURL|String|地址为商户服务器接口请求地址，对应卡券包中hwpass.json中的webServiceURL字段。|M|
  |version|String|固定值v1。|O|
  |*deviceId*|String|手机设备ID。|O|
  |passTypeIdentifier|String|卡券类型ID。|M|
  |serialNumber|String|卡券序列号。|M|

* 请求参数 请求消息头：

  |名称|类型|描述|可选O/必选M|
  |:------------|:-----|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------|
  |Authorization|String|HuaweiPassToken+空格+Base64(卡卷包hwpass.json中的authorizationToken)，authorizationToken主要用于商户服务器验证当前华为钱包请求是否有效，商户判断authorizationToken是否由商户自己签发。 完整示例："HuaweiPassToken CUDJEMSDIJGHSAESJEMSDIJGHSAESCUD"。|M|
