# 集成HMS Core SDK

您接入广告服务时，可根据需要集成如下其中1个或2个SDK：

* ads-identifier sdk：获取OAID。
* ads-installreferrer sdk：获取转化跟踪参数。

您可以配置Maven仓地址自动下载鲸鸿动能SDK，不需要手工下载，配置步骤如下：

## 配置鲸鸿动能SDK的Maven仓地址

Android Studio的代码库配置在Gradle 插件7.0以下版本、7.0版本和7.1及以上版本有所不同。请根据您当前的Gradle 插件版本，选择对应的配置过程。

|--------------------------------|----------------------------|--------------------------------|
|[7.0以下版本](#section1775514180816)|[7.0版本](#section95932024190)|[7.1及以上版本](#section187948541792)|

> 说明
>
> Maven仓地址无法直接在浏览器中打开访问，只能在IDE中配置。如需添加多个Maven代码库，请将华为公司的Maven仓地址配置在最后。

### 7.0以下版本

1. 打开Android Studio项目级"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/80/v3/jV_sxWp3T1OPeaO8avHirw/zh-cn_image_0000001257774807.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=553FBD5A2A1AC646A0D00E732FB97F8D60BDED8DC3B36232AEC718D3F0E1CE01)
2. 添加Maven代码库。
   * 在"buildscript > repositories"中配置Maven仓地址。
   * 在"allprojects > repositories"中配置Maven仓地址。

   ```screen
   buildscript {
       repositories {
           google()
           jcenter()
           // 配置鲸鸿动能SDK的Maven仓地址
           maven {url 'https://developer.huawei.com/repo/'}
       }
   }

   allprojects {
       repositories {
           google()
           jcenter()
           // 配置鲸鸿动能SDK的Maven仓地址
           maven {url 'https://developer.huawei.com/repo/'}
       }
   } 
   ```

### 7.0版本

1. 打开Android Studio项目级"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/FK-UoNmDTPKN6h1G5bdAeA/zh-cn_image_0000001257694749.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C9F6D7A73FC59BBA5DCB98C4E13A8CFE8A0FB68DF77BB2F971FE0F6ECC204FC)
2. 添加Maven代码库。

   在"buildscript > repositories"中配置Maven仓地址。

   ```screen
   buildscript {
       repositories {
           google()
           jcenter()
           // 配置鲸鸿动能SDK的Maven仓地址
           maven {url 'https://developer.huawei.com/repo/'}
       }
   }
   ```

3. 打开项目级"settings.gradle"文件，配置Maven仓地址。

   ```screen
   dependencyResolutionManagement {
       ...
       repositories {
           google()
           jcenter() 
           // 配置鲸鸿动能SDK的Maven仓地址
           maven {url 'https://developer.huawei.com/repo/'}
       }
   }
   ```

### 7.1及以上版本

打开项目级"settings.gradle"文件，配置Maven仓地址。

```screen
pluginManagement {
    repositories {
        gradlePluginPortal()
        google()
        mavenCentral()
        // 配置鲸鸿动能SDK的Maven仓地址
        maven { url 'https://developer.huawei.com/repo/' }
    }
}
dependencyResolutionManagement {
    ...
    repositories {
        google()
        mavenCentral()
        // 配置鲸鸿动能SDK的Maven仓地址
        maven { url 'https://developer.huawei.com/repo/' }
    }
}
```

## 配置依赖

在应用级的"build.gradle"文件中添加编译依赖。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/15/v3/hpk2iIP8SLWQP34a978_kA/zh-cn_image_0000001062451263.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=4B640E6ADC697FA2AF5824C307F8A6F427B28059A6081C5BFF96FAE842FC07E9)

将*{version}* 替换为实际的SDK版本号，版本号索引请参见[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/identifier-service-version-change-history-0000001050066927)，修改如下：

```screen
dependencies {
    implementation 'com.huawei.hms:ads-identifier:3.4.85.301'
    implementation 'com.huawei.hms:ads-installreferrer:3.4.85.301'
}
```

> 说明
>
> 可以根据需要选择依赖的SDK。
>
> * 如果需要获取OAID，仅依赖com.huawei.hms:ads-identifier即可。
> * 如果需要获取转化跟踪参数，仅依赖com.huawei.hms:ads-installreferrer即可。

## 同步工程

在完成以上的配置后，点击工具栏中的gradle同步图标，完成"build.gradle"文件的同步，将相关依赖下载到本地。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/33/v3/krrqsqhZSDibwn8RGDGNSQ/zh-cn_image_0000001050057091.png?HW-CC-KV=V1&HW-CC-Date=20260910T013830Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F9BB67BD44CF12657E43E8420251358C83E0DDED0A935A2D55A8CE0A31BE0E4) 说明
>
> 如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。

## 配置混淆脚本

您编译APK前需要配置混淆配置文件，避免混淆鲸鸿动能SDK导致功能异常。

打开Android工程应用级根目录下的混淆配置文件"proguard-rules.pro"，加入排除鲸鸿动能SDK的混淆配置。

```screen
-keep class com.huawei.hms.ads.** {*; }
-keep interface com.huawei.hms.ads.** {*; }
```
