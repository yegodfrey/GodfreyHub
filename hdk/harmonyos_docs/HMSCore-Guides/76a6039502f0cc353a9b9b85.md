# 开发后自检  
  
#### 自检Checklist

为尽早发现问题，尽量减小您集成业务提交审核后被打回的概率，HMS Core业务提供了提交审核前自检Checklist。请下载[华为分析服务开发自检Checklist](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115304.81532063598145526021590266515594:50001231000000:2800:B4D90915447C194FE9C8CCD814BE1B723B6A71D5FCD7628328F82002B7361AEE.xlsx?needInitFileName=true)进行自检，检查通过后，再提交上架应用。

#### 自检工具

华为提供对应用自动检查的能力。您只需填写应用相关信息、上传APK包，平台将自动扫描APK并输出自检报告。您可以根据自检报告改进应用，自检通过即可提交应用上架申请，是您上架应用的好帮手。

自检步骤请参见AppGallery Connect帮助中心的[接入检测](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-self-check-0000001100158786)。
