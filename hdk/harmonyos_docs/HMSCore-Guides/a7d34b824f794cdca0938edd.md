# Widget

#### 概览

widget是内置地点搜索建议功能的搜索组件。当用户在搜索框输入搜索词时，组件会显示一个可供选择的预测地点列表，当用户选择列表中任意一项时，会返回一个[Site](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781)对象，然后您的应用可以使用该对象获取所选地点的详细信息。

有两种方式可以在您的应用中使用搜索组件：

* 方式一：添加SearchFragment。
* 方式二：使用Intent启动搜索组件。

#### 添加SearchFragment

通过[SearchFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfragment-0000001050152850)将搜索组件添加到您的应用中，请执行以下步骤：

1. 将[SearchFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfragment-0000001050152850)添加到Activity中。请在Activity的XML布局中添加一个fragment元素，例如：

   <br />

   ```
    <fragment
           android:id="@+id/widget_fragment"
           android:name="com.huawei.hms.site.widget.SearchFragment"
           android:layout_width="match_parent"
           android:layout_height="wrap_content" />
   ```

   <br />

2. 给[SearchFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfragment-0000001050152850)添加侦听器。将[SearchFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfragment-0000001050152850)绑定到Activity中，并添加搜索结果列表项的侦听器[SiteSelectionListener](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-siteselectionlistener-0000001050152858)，当用户点击任意搜索结果时，会返回被点击的[Site](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781)对象。完整示例请参见[SearchFragmentActivity.java](https://github.com/HMS-Core/hms-sitekit-demo/blob/master/java/app/src/main/java/com/huawei/hms/site/sample/SearchFragmentActivity.java)。

   <br />

   示例代码如下：

   ```
   "Java"
   SearchFragment fragment = (SearchFragment) getSupportFragmentManager().findFragmentById(R.id.widget_fragment);
   // 设置SearchFragment的API key
   fragment.setApiKey("API key"); 
   fragment.setOnSiteSelectedListener(new SiteSelectionListener() {
               @Override
               public void onSiteSelected(Site data) {
                   Toast.makeText(getApplication(), data.getName(), Toast.LENGTH_LONG).show();
               }
               @Override
               public void onError(SearchStatus status) {
                   Toast
                       .makeText(getApplication(), status.getErrorCode() + "\n" + status.getErrorMessage(),
                           Toast.LENGTH_LONG)
                       .show();
               }
   });
   ```

   ```
   "Kotlin"
   val fragment: SearchFragment = supportFragmentManager.findFragmentById(R.id.widget_fragment) as SearchFragment
   // 设置SearchFragment的API key
   fragment.setApiKey("API key")
   fragment.setOnSiteSelectedListener(object : SiteSelectionListener {
       override fun onSiteSelected(data: Site) {
           Toast.makeText(application, data.getName(), Toast.LENGTH_LONG).show()
       }
       override fun onError(status: SearchStatus) {
           Toast
                   .makeText(application, status.getErrorCode() + "\n" + status.getErrorMessage(),
                           Toast.LENGTH_LONG)
                   .show()
       }
   })
   ```

#### 使用Intent启动搜索组件

使用Intent启动搜索组件，请按照以下步骤操作：

1. 创建[SearchIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchintent-0000001050152854)对象，并设置[SearchIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchintent-0000001050152854)的API密钥。

   <br />

   示例代码如下：

   ```
   "Java"
   private SearchIntent searchIntent;
   searchIntent = new SearchIntent();
   searchIntent.setApiKey("API key"); 
   ```

   ```
   "Kotlin"
   private val searchIntent = SearchIntent()
   searchIntent.setApiKey("API key")
   ```

   <br />

2. 创建Intent对象，使用startActivityForResult(Intent intend, int requestCode)启动[SearchIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchintent-0000001050152854)。

   <br />

   示例代码如下：

   ```
   "Java"
   Intent intent = searchIntent.getIntent(this);
   startActivityForResult(intent, SearchIntent.SEARCH_REQUEST_CODE);
   ```

   ```
   "Kotlin"
   val intent = searchIntent.getIntent(this)
   startActivityForResult(intent, SearchIntent.SEARCH_REQUEST_CODE)
   ```

   <br />

3. 重写Activity的onActivityResult(int requestCode, int resultCode, Intent data)，并调用父类的onActivityResult(requestCode, resultCode, data)方法。被点击的[Site](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-site-0000001050154781)对象可以从回传的Intent对象中获取。完整示例请参见[SearchIntentActivity.java](https://github.com/HMS-Core/hms-sitekit-demo/blob/master/java/app/src/main/java/com/huawei/hms/site/sample/SearchIntentActivity.java)。

   <br />

   示例代码如下：

   ```
   "Java"
   @Override
   protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
   	super.onActivityResult(requestCode, resultCode, data);
   	if (SearchIntent.SEARCH_REQUEST_CODE == requestCode) {
   		if (SearchIntent.isSuccess(resultCode)) {
   			Site site;
   			site = searchIntent.getSiteFromIntent(data);
   			Toast.makeText(getApplication(), site.getName(), Toast.LENGTH_LONG).show();
   		}
   	}
   }
   ```

   ```
   "Kotlin"
   override fun onActivityResult(requestCode: Int, resultCode: Int, @Nullable data: Intent?) {
       super.onActivityResult(requestCode, resultCode, data)
       if (SearchIntent.SEARCH_REQUEST_CODE == requestCode) {
           if (SearchIntent.isSuccess(resultCode)) {
               val site: Site = searchIntent.getSiteFromIntent(data)
               Toast.makeText(application, site.getName(), Toast.LENGTH_LONG).show()
           }
       }
   }
   ```

   <br />

#### 限制地点搜索建议结果

[SearchFragment](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfragment-0000001050152850)和[SearchIntent](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchintent-0000001050152854)都可以通过setFilter([SearchFilter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846))限制搜索建议结果，此时需要创建[SearchFilter](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846)对象来设置限制条件，如下表所示。  

|接口|描述|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[setQuery](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section7871115714111)(String query)|设置搜索关键字。|
|[setLocation](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section9862165714115)([Coordinate](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-coordinate-0000001050152772) location)|设置搜索结果偏向的经纬度。|
|[setRadius](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section6875757911)(Integer radius)|设置搜索半径，单位：米。取值范围：\[1, 50000\]，默认50000米。|
|[setBounds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section48498571115)([CoordinateBounds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-coordinatebounds-0000001050152776) bounds)|设置搜索结果偏向的范围。|
|[setCountryCode](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section785325717117)(String countryCode)|设置在指定国家内搜索，采用ISO 3166-1 alpha-2。|
|[setLanguage](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section19857125712110)(String language)|设置搜索结果返回的语言，取值范围参见[支持的语言](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/language-mapping-0000001050162856)的语种代码。如果不指定语种，返回英语，如果没有英语，返回当地语言。|
|[setPoiType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section6866357315)(List\<[LocationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-locationtype-0000001050154741)\> poiType)|设置返回地点的POI类型。取值范围是[LocationType](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-locationtype-0000001050154741#section48131858163210)的子集，包括GEOCODE、ADDRESS、ESTABLISHMENT、REGIONS、CITIES五种类型。|
|[setPoliticalView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section52421021181914)(String politicalView)|设置政治观点。 注意： 该接口已废弃。|
|[setChildren](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section12396183494913)(boolean children)|设置是否返回子节点。|
|[setStrictBounds](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-searchfilter-0000001050152846#section2091716245592)(Boolean strictBounds)|设置是否严格限制在Bounds内搜索，默认值为false。|
