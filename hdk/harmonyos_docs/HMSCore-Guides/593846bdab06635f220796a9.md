# 广播包华为自定义参数

AD Type 为 0xFF时，代表厂家自定义广播参数。如下广播参数代表符合华为运动健康规范的运动器材，可以在华为运动健康App进行广播扫描时识别。  

|1字节|1字节|2字节|n字节|
|:-----|:------|:--------|:--------------------------|
|Length|AD Type|Vendor ID|Type-Len-Value(Len和Value可选)|

* AD Type = 0xFF
* Vendor ID = 0x7D02
* Type = 0x01
* Len = N/A（0x01的Value为定长，故Len不存在）
* Value = 0x05 0x00 0xFF 0xFF
