# 开发流程

您需要按照如下流程完成应用的开发工作。  

|序号|步骤|说明|
|:-:|:--------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|1|[准备开发环境](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-preparing-development-environment-0000001207861490)|要使用地图服务Flutter插件，您需要在计算机上设置Flutter开发环境。|
|2|[配置AppGallery Connect](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467)|在开发应用前，需要在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)中配置相关信息。包括：[注册成为开发者](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467#section117741544174818)、[创建应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467#section677544444811)、[生成签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467#section147782044104815)、[生成签名文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467#section1277894411482)、[从签名文件中获取SHA256指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467#section1978318441483)、[配置签名证书指纹](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467#section778617447482)、[开启地图服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-config-agc-0000001252581467#section278804412481)。|
|3|[集成地图服务Flutter插件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-integrating-plugin-0000001252461503)|在开发应用前，您需要集成地图服务Flutter插件。|
|4|[添加权限](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-adding-permissions-0000001252341511)|调用地图服务能力，您需要在应用中添加权限。|
|4|[创建地图](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-creating-map-0000001207381558)|使用地图容器快速地获得地图对象、修改地图类型以及在地图上绘制形状和标记。|
|4|[地图交互](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-map-interaction-0000001207541548)|通过控制地图手势开关以及内置UI控件的可见性，自定义用户与地图交互方式。|
|4|[在地图上绘制](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-drawing-on-map-0000001207701516)|在地图上绘制标记和形状。|
|4|[精简模式](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/flutter-plugin-lite-mode-0000001207861492)|开启地图精简模式。|
