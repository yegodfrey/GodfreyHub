# 概览

智能数据接入服务提供概览、应用集成、埋点开发、埋点验证、云侧接入及数据管理功能，为您提供行业化的埋点方案，提升埋点的效率，并对埋点信息进行管理。智能数据接入服务帮助您采集埋点上报信息，为后续华为分析服务使用数据进行多维度、多属性、多类型分析提供数据基础。

目前支持的能力有：

* 应用集成：多平台、多终端智能接入。
* 多行业埋点方案：热点行业的埋点方案模板及代码样例。通过一站式的埋点流程，提升埋点效率，降低埋点成本。


* 埋点验证：保证您根据系统提供的埋点方案埋点的准确性，及时发现埋点异常，规避业务风险。
* 云侧接入：通过[导入自定义用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-import-customized-user-attributes-0000001050747215)接口，导入自定义的用户属性，可用于各种分析报告及受众管理中。
* 数据管理：分为事件管理和属性管理，事件管理对于埋点事件可以进行暂停或恢复计算，属性管理针对导入的自定义用户属性进行编辑、删除或上报操作。
* 监控核心指标：快速了解埋点事件的数据表现及当前项目下的应用数量、埋点模板的使用次数、埋点事件数等。

## 前提条件

* 如果您还没有华为开发者联盟帐号，需要先注册帐号并完成实名认证。详细操作请参见[++帐号注册认证++](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)。
* 参见[创建项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)和[在项目中添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717)完成应用的创建。
* 智能数据接入服务依赖华为分析服务，因此必须接入华为分析服务，具体操作参见[启用华为分析](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-enabling-0000001050745155)。

## 功能详述

### 操作指导

1. 登录[AppGallery Connect网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，点击"我的项目"图标。
2. 选择需要查看分析数据的应用。
3. 选择"华为分析 > 智能数据接入 > 概览"菜单。
4. 进入概览页面查看当前项目下的应用接入总览、属性和事件总览、埋点模板总览，请参见[概览详情](#section1993864173110)。
