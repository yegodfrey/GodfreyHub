# API列表

|功能列表|描述|
|:----------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------|
|[创建商家券批次](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-create-0000001825044808)|商户可以通过该接口创建商家券。创建成功后返回商家券批次号给到商户，商户可调用发券接口发放该批次商家券。|
|[修改商家券批次基本信息](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-update-0000001825204640)|商户可以通过该接口修改商家券基本信息。|
|[修改商家券批次预算](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-upbudget-0000001825044812)|商户可以通过该接口修改批次单天发放上限数量或者批次最大发放数量。|
|[查询商家券批次详情](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-query-0000001872004157)|商户可通过该接口查询已创建的商家券批次详情信息。|
|[上传批次预存Code](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-upload-0000001871884373)|商家券的code码支持商户自定义。如商家已有自己的优惠券系统，可直接使用自定义模式。即商家预先向华为支付上传券code，当券在发放时，华为支付自动从已导入的code中随机取值（不能指定），派发给用户。|
|[发放优惠券](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-distribute-0000001872004165)|发放商家券，支持一个请求最大发放10张券，可以是一个批次下的多张，也可以是多个批次下的券，多个批次一起发放时一个批次发放失败，不影响其它批次的处理。|
|[核销优惠券](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-use-0000001825204652)|在用户满足优惠门槛后，商户可通过该接口核销用户卡包中具体某一张商家券。|
|[申请退券](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-refund-0000001871884377)|商户可以在退款之后调用此退券API，调用成功后，券恢复到用户的卡包里面，并且在有效期内可以正常再被使用。|
|[使券失效](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-deactivate-0000001825044816)|失效一张券，券被失效后无法再被核销。|
|[查询用户优惠券列表](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-query-0000001871884381)|商户自定义筛选条件（如创建商户号、归属商户号、发放商户号等），查询指定用户卡包中满足对应条件的所有商家券信息。|
|[查询用户单张优惠券详情](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-query-one-0000001825044820)|商户可通过该接口查询用户卡包中某一张商家券的详情信息。|
|[发券事件回调通知](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-callback-distribute-0000001873201553)|当在华为平台流量场景（负一屏、支付结果页、搜索等）为用户发放了商家的优惠后，会通过此回调接口通知商家发券信息。|
|[设置回调通知地址](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-callbackurl-update-0000002058290698)|商户可以通过该接口设置商家券事件通知地址。|
|[查询回调通知地址](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-coupbatch-callbackurl-select-0000002094449569)|商户可以通过该接口获取商家券事件通知地址。|
|[同步第三方用户名](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/payment-merc-coup-api-ucoup-synchronizing-0000002631528714)|京东等第三方将其系统的用户名同步进来。|
