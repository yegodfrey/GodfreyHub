# 埋点验证

#### 功能概述

当完成埋点开发后，通过埋点验证模块可以帮助您快速验证已埋点事件是否埋点正确，及时发现埋点遗漏及异常情况，提高埋点开发的准确度，降低业务风险。  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115248.09324784409757519746499805475205:50001231000000:2800:C0F59389DCD69BFE7544A3A51CDE9A3397552D27DB1E39159E2F17C4247FFCFC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
* 埋点验证：仅与已提交状态的行业埋点方案的模板做对比。
* 对比规则：埋点参数个数与预置事件参数是否一致（通过参数ID匹配）。  

#### 典型应用场景

#### 普通场景

* 当上报的埋点数据与已提交状态的模板埋点数据进行比对，如果埋点事件存在且参数正确，页面60s后更新事件状态为成功，说明埋点事件验证成功。
* 支持埋点报告功能，查询事件验证的详细信息。  

#### 异常场景

当上报的埋点数据与已提交状态的模板埋点数据进行比对，如果上报参数不正确，页面更新事件状态为异常状态，同步展示异常数据。您可以及时检查事件参数，保证埋点验证的正确性。

#### FAQ

#### DEBUG模式没有数据上报该如何解决？

1. 请确认选择了正确的应用。
2. 请确保在获取agconnect-services.plist文件前，已经完成华为分析服务的开通。
3. 查看log日志数据是否上报成功，如果日志中有打印"resultCode: 200"说明数据上报成功。
4. 确认调试模式为开启状态，具体方法请参见[开启/停用调试模式](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-accessing-0000001050161888#section81991426811)。
