# SDK版本更新说明

1. 最新版本SDK需要用户手机上安装HMS Core（APK）6.11.0.300及以上版本。
2. HMS Core（APK）6.0.7.300版本以下无法拉起支付收银台，非HMS Core最新版本可能会在首次拉起收银台时会提示更新HMS Core。

温馨提示：如果开发者在集成SDK时遇到问题可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。
