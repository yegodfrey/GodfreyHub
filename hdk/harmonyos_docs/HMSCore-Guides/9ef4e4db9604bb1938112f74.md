# NodeJS SDK

华为分析服务目前已提供[导入自定义用户属性](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-import-customized-user-attributes-0000001050747215)和[上报用户行为](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/android-api-report-user-behavior-0000001205631635)的API接口，为减小API接口的工作量，现提供NodeJS版本的SDK给开发者集成，用以快速的使用API接口能力。

#### 开发环境

[Node.js](https://nodejs.org/en/) 10及以上

#### 操作步骤

      1. 下载NodeJS SDK安装包到本地，下载链接请参见[NodeJS SDK下载](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Library/nodejs-server-sdk-0000001193281036)。
      2. 本地解压以后执行如下命令安装SDK。
             
             npm install hw-hmscore-analytics-node-6.4.0-303.tgz

      3. 集成SDK。

SDK目前提供了CommonJS和ESM的两种方式集成。
             
             “CommonJS”
             const HaNodeSDK = require('@hw-hmscore/analytics-node');
             
             “ESM”
             import { HuaweiApp, CachePolicy, HuaweiAnalyticsClient } from '@hw-hmscore/analytics-node';

      4. 配置日志。

如果您需要捕获异常场景信息，可调用NodeJS SDK的initLogger接口，生成相关日志记录。
             
             “CommonJS”
             // 集成winston
             const winston = require('winston');
             const logger = winston.createLogger({
               transports: [
                 new winston.transports.Console(),
                 new winston.transports.File({filename: 'combined.log'})
               ]
             });
             
             HaNodeSDK.HuaweiAnalyticsClient.initLogger(logger); 
             
             “ESM”
             // 集成winston
             const winston = require('winston');
             const logger = winston.createLogger({
               transports: [
                 new winston.transports.Console(),
                 new winston.transports.File({filename: 'combined.log'})
               ]
             });
             
             HuaweiAnalyticsClient.initLogger(logger);

      5. 获取应用信息。
         1. 登录[ _AppGallery Connect 网站_](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“我的项目”。
         2. 在项目列表中找到您的项目，在项目列表中点击需要集成SDK的应用。
         3. 在“项目设置”页面中，获取App相关信息。

      7. 初始化上报策略配置。
         * 使用默认配置。
               
               “CommonJS”
               HaNodeSDK.HuaweiAnalyticsClient.init(apps);****
               
               “ESM”
               HuaweiAnalyticsClient.init(apps);

         * 使用自定义配置。
               
               “CommonJS”
               let config = new HaNodeSDK.CachePolicy();
               
               config.setCacheTime(_10_); // 设置缓存时间，单位:s
               config.setMaxRetry(_2_); // 设置上报重试次数
               config.setUserSendSize(_100_); // 设置单次导入自定义用户属性的发送数量
               config.setEventSendSize(_100_); // 设置单次上报用户行为的发送数量
               config.setMaxCacheSize(_10000_); // 设置最大缓存数量
               ****
               HaNodeSDK.HuaweiAnalyticsClient.init(apps, config);
               ****
               
               “ESM”
               let config = new CachePolicy();
               
               config.setCacheTime(_10_); // 设置缓存时间，单位:s
               config.setMaxRetry(_2_); // 设置上报重试次数
               config.setUserSendSize(_100_); // 设置单次导入自定义用户属性的发送数量
               config.setEventSendSize(_100_); // 设置单次上报用户行为的发送数量
               config.setMaxCacheSize(_10000_); // 设置最大缓存数量
               ****
               HuaweiAnalyticsClient.init(apps, config);

参数 | 参数说明  
---|---  
setCacheTime | 缓存上报的间隔时间，单位为s。 设置区间为1-1800s，默认为10s上报一次数据，类型为整数。  
setMaxRetry | 上报重试次数，当服务端错误导致上报失败时，会进行重试处理；当达到配置的最大上报次数还是失败时，则会记录日志处理。 设置区间为 0-5次，默认重试2次，类型为整数。  
setUserSendSize | 单次“导入自定义用户属性”的发送数量。 设置区间为1-100，默认100，表示单次上报的自定义用户属性为100条，类型为整数。  
setEventSendSize | 单次“上报用户行为”的发送数量。 设置区间为1-100，默认100，表示单次上报的用户行为数据为100条，类型为整数。  
setMaxCacheSize | 最大缓存数量，设置缓存中最大的数据量；当数量达到限制，会对最老的数据进行淘汰并记录日志。 设置区间为1-1000000，默认存放10000条数据，类型为整数。

当服务升级、重启等导致进程关闭的场景时，可以调用flush方法，上报所有数据。
             
             “CommonJS”
             // 发送所有收集的信息
             HaNodeSDK.HuaweiAnalyticsClient.flush();
             
             “ESM”
             // 发送所有收集的信息
             HuaweiAnalyticsClient.flush();
