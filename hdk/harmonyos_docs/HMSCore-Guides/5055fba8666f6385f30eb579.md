# 准备开发环境

您需要在本地安装如下软件：

* Node.js
* HUAWEI DevEco Studio

## 下载和安装Node.js

**Node.js**是JavaScript运行所需要的开源、跨平台运行环境。

1. 登录[Node.js](https://nodejs.org/en/download/)官方网站，选择LTS版本，下载和安装对应的软件包。

   > 说明
   >
   > 如果安装Node.js没有选择默认安装目录，则需要在系统环境变量"path"中增加Node.js的安装路径。

2. 检验是否安装成功。

   打开命令行工具，输入**node -v**命令，能正常查询Node.js的版本号，说明Node.js安装成功。

## 安装及配置HUAWEI DevEco Studio

### 运行环境要求

为保证DevEco Studio正常运行，建议您的电脑配置满足如下要求：

* 操作系统：Windows10 64位或macOS 10.14/10.15/11.2.2
* 内存：8GB及以上
* 硬盘：100GB及以上
* 分辨率：1280*800像素及以上

### 安装及配置过程

1. 下载及安装DevEco Studio。具体操作请参见[下载与安装软件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V2/software_install-0000001053582415-V2)。
2. 配置DevEco Studio，您需要完成设置网络代理及下载HarmonyOS SDK等相关操作。具体操作请参见[配置开发环境](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V2/environment_config-0000001052902427-V2)。
3. 开发环境配置完成后，可以通过[运行HelloWorld](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V2/hello_world-0000001054516888-V2)工程来验证环境设置是否正确。
4. 创建开发项目工程，具体操作请参见[创建一个新的工程](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V2/create_new_project-0000001053342414-V2)。

   使用JavaScript语言开发，请选择"Empty Ability(JS)"。
