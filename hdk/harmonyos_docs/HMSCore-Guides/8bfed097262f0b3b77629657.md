# 开发准备

#### 配置ICCE车钥匙服务

华为钱包ICCE数字车钥匙是华为钱包提供的众多服务中的一种。您需要在我们的开发者网站上进行简单的注册和配置，开通对应的权限后，才能使用华为钱包提供的ICCE数字车钥匙服务。

这其中包括：

* 通用的注册配置，如注册开发者联盟帐号，创建应用；
* 车钥匙服务配置，如配置walletkit服务告诉我们您的接入服务号，以便我们对不同的发卡机构进行管理；配置NFC参数告诉我们在NFC车钥匙刷卡时需要使用的密钥信息

下面我们将指导您进行相应的配置。  

#### 注册开发者联盟帐号

具体的注册方法参见[官网](https://developer.huawei.com/consumer/cn/doc/start/registration-and-verification-0000001053628148)；

注册完成之后，登录[AGC官网](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)；

如首页最上面提示没有实名认证，请先实名认证。  

#### 创建应用

如果您已经创建了对应的项目，则可直接跳过该部分。

* [创建AGC项目](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createproject-0000001100334664)
* [在项目中添加应用](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-createapp-0000001146718717#section1112105771619)

  应用添加成功后，您将会看到您创建的如下应用信息，其中Client ID和Client Secret这两个值会用于DK业务管理服务向华为钱包云服务器发起https请求时[获取AccessToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/cloud_implementss-0000001225460853#section1640016310164)。

#### 配置Walletkit服务参数

* 在[AppGallery Connect 网站](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)首页选择"我的项目"。
* 在项目列表中点击您的项目。
* 点击页面左侧导航栏中的"盈利"-\>"华为钱包"；点击右上角的"申请Wallet Kit服务"： ![](https://media:101782807022195831 "点击放大")

* 点击"产品接入华为钱包服务"中的"点击申请"： ![](https://media:101782807022255832 "点击放大")

* 配置WalletKit服务参数： ![](https://media:101782807022291833 "点击放大")

  |名称|值|
  |:---|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  |服务类型|钥匙|
  |服务项目|ICC车钥匙|
  |服务名称|xxx数字车钥匙服务（xxx可为公司名称/产品名称）。该字段仅用于方便开发者区分自己配置的多个服务，没有其他用途|
  |服务号|hwpass.stdcarkey.xxx.xxx（xxx可为公司/产品名称，总长度不超过32个英文小写字符，请严格按照此规则定义）。ICCE车钥匙卡片的发卡机构，用于唯一表明某一发卡机构。钱包可根据此值进行发卡机构的管控；在预置模板、生成钥匙卡片以及开通激活过程的请求体中会携带该值|
  |接入方式|云端接入|
  |回调地址|用于用户添加/删除卡券时回掉通知发卡机构；示例：商户服务器地址/v1/passes/nfccallback；注意：地址必须使用https。|
  |用户公钥|按照"[公钥操作步骤指导说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/guide-rsa-0000001135545395)"提供的第一种方式："网页、短信、Email、App应用内方式生成安全密钥"，将生成的公钥内容粘贴在此处|

#### 配置NFC参数

![](https://media:101782807022316834 "点击放大")  

|名称|值|
|:----------|:-|
|是否支持跨设备移动同步|是|
|是否开通NFC能力|是|

![](https://media:101782807022338835)  
这里的"是否开通NFC能力"，即便您现在只支持蓝牙功能，也请选择是。  

#### 打开钱包权限

在AGC的API管理页面，下拉找到华为钱包，打开对应的开关；用于钱包对车钥匙管理台向钱包服务器发起http/https请求时的权限控制。关闭状态下，车钥匙管理台将访问不了钱包服务器。

![](https://media:101782807022394836 "点击放大")  

#### 配置车钥匙管理台地址至钱包服务器

在车钥匙的开通激活阶段，钱包需要向您请求数据；这整个的数据链路为：华为钱包APP-\>钱包云服务器-\>DK业务管理服务。

钱包云服务器向DK业务管理服务请求需要知道DK业务管理服务的地址，因此需要将DK业务管理服务的地址配置进钱包云服务器。  
您只需按照如下格式将地址提供给华为接口人，华为接口人会帮您配置：

```
{    
    "registrationsUrl": "商户服务器地址/v1/passes/registrations",
    "requestPersonalizeTokenUrl": "商户服务器地址/v1/passes/requestPersonalizeToken",
    "requestPersonalizeUrl": "商户服务器地址/v1/passes/requestPersonalize",
    "spNfcOperCallBackUrl"："商户服务器地址/v1/passes/nfccallback" // 用于回调开卡和删卡结果
}
```

![](https://media:101782807022417837)  
商户服务器地址请替换成DK业务管理服务的真实地址。
