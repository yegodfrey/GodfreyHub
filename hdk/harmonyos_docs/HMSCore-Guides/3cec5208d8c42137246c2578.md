# 读取自由潜运动记录

1. 构造请求对象readOption。
2. 调用[getActivityRecord](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-manage-activity-records-0000001186732884#section12846719145719)接口，根据请求体条件获取Health Service Kit中的自由潜运动记录。

   读取自由潜运动记录示例代码如下：

   ```screen
   import {HMSHealthKit, HMSHealthKitDataType, ActivityRecordReadOptions} from '@hw-hmscore/hms-js-health'
   // 步骤1：构造请求对象readOption
   const dataTypeNameList = []
   // 创建需要关联读取的运动记录关联的详情数据
   dataTypeNameList.push(HMSHealthKitDataType.DT_INSTANTANEOUS_FREEDIVING_ASCENT_SPEED)
   dataTypeNameList.push(HMSHealthKitDataType.DT_INSTANTANEOUS_FREEDIVING_DESCENT_SPEED)
   // 基于时间等条件创建读取运动记录的参数
   let readOption = new ActivityRecordReadOptions("1624774020000", "1624774320000", dataTypeNameList)
   // 步骤2：调用getActivityRecord接口，根据请求体条件获取Health Service Kit中的自由潜运动记录
   HMSHealthKit.getActivityRecord(readOption).then((result) => {
       // 调用成功
       console.info("getActivityRecord success: " + JSON.stringify(result))
   }).catch((error) => {
       // 调用失败
       console.error("getActivityRecord error: " + JSON.stringify(error));
   })
   ```
