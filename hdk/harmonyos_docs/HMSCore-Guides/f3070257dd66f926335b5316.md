# Petal Ads  
  
如果您已在DTM配置了“Petal Ads”代码，Petal Ads将使用DTM来跟踪网站上的转化数据，当用户通过点击文字、图片广告或观看视频广告并参与您的广告互动时，Petal Ads会在落地页的URL中自动添加广告跟踪参数（“tracking_url”），当用户在您的落地页进行操作时，DTM会将相应转化信息以及URL中携带的广告跟踪参数发送回Petal Ads。

如果您的网站在特殊场景下，需要停止向Petal Ads上报转化信息（例如仅在获得用户Cookie Consent同意后，才允许DTM向Petal Ads上报转化信息），详情请参见停止向Petal Ads上报转化信息。

如果您的网站有多级页面或者跨网域，在从落地页跳转到其他子页面过程中，URL中的广告跟踪参数可能会丢失，将导致无法跟踪其他子页面中的转化信息。因此，您需要在DTM中配置跟踪链接器代码，以便将广告参数从落地页传递到二级、三级页面，确保DTM可以跟踪您网站中每个页面的转化信息。

DTM的“跟踪链接器”有两种方案来解决多级页面跳转跟踪的问题，您可以同时使用，也可以选择其中一种方案。建议您同时使用两种方案，以提升转化信息上报率。方案介绍如下：

#### 方案一：一方Cookie

DTM使用一方Cookie来存储广告跟踪参数。当您指定的落地页首次加载时，DTM会将广告跟踪参数写入一方Cookie。当用户在您的网站上完成转化时，您添加的转化跟踪代码会读取该Cookie，并将其与相应转化信息一起发送回Petal Ads。

DTM默认不会使用一方Cookie，您必须配置跟踪链接器中的“Cookie同意”参数，通过该参数设置DTM是否使用一方Cookie来存储广告跟踪参数。

如果您的网站允许使用一方Cookie，您可以在“跟踪链接器”中配置“Cookie同意”。当用户同意后，跟踪参数将会保存到第一方Cookie中，且优先基于一方的顶级域名保存。

当该值为true时，表示用户同意；否则，表示不同意。仅当该字段为true时，DTM才会将跟踪参数保存到第一方Cookie中。

某些国家或地区在读写一方Cookie时，要求必须获得用户明示同意，例如欧洲经济区以及英国。因此，您需要根据各国或各地区对Cookie Consent明示同意要求的不同，选择如下一种配置场景进行配置：

#### [h2]场景一：网站不需要Cookie Consent明示同意

在“代码”中，新建“跟踪链接器”代码，将“Cookie同意”参数配置为“true”，DTM将使用一方Cookie，并始终上报转化信息给Petal Ads。

#### [h2]场景二：网站需要Cookie Consent明示同意

您必须将Cookie Consent结果通知DTM，DTM仅当用户同意使用Cookie的情况下才会使用一方Cookie。具体配置步骤如下：

      1. 当网页重新加载或用户修改Cookie Consent结果后，您需要执行“跟踪链接器”代码，所以您需要两个触发条件：

         * **网页加载。** 即预置条件“Initialization - All pages”。
         * **Cookie Consent状态变更。** 若用户进入页面后仍可以修改同意结果，还需要监听用户同意结果并更新事件，获取用户最新的同意结果。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/iNxCWSivQKCmyqqHkfhzaA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=44BA1661A2A974012120C301DE7B5CC7C13CF257E1485262008A34016C6AB9C5)

本步骤可选，但建议您配置本步骤。

如果不配置本触发条件，当用户修改Cookie Consent同意结果后，DTM仍会使用以前的Cookie Consent同意结果。一旦用户刷新了当前页面或发生了页面跳转，便会自动使用触发条件一，自动刷新Cookie Consent状态。

           1. 在“条件”中新建条件，设置“条件名称”为“OnConsentChanged”，“条件类型”为“自定义事件”，“事件名称”为“OnConsentChanged”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2d/v3/84ehgAndSQKeF0T7uWPTNA/zh-cn_image_0000001129302052.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=FCEE00225C120A582317848F44AE3DB34BD25249A8515A86A08C845A374F9380)

           2. 在“代码”中新建“自定义 HTML”代码，用于绑定OneTrust的Consent更改事件，即跟踪用户对隐私同意的更改。

建议将代码的“触发条件”设置为“Initialization - All pages”，表示所有页面的浏览均会触发。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cf/v3/JscCx3LcQ1igijlSlZ8yBA/zh-cn_image_0000001308451802.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=AB951F5156CE4BA073D820BFB1F3EAC2FCEE0CB6AD8D48AE2CD114791F2B35B8)

“自定义HTML”代码用于将DTM的回调方法绑定到OneTrust的OnConsentChanged接口中。

即当OneTrust的Consent状态发生变更后，OneTrust会自动调用**window.recordTier.push({eventName: 'OnConsentChanged'})** ，将向DTM发送自定义事件“OnConsentChanged”，用于通知DTM。请确保push的eventName的取值与“条件”中的“事件名称”一致。

“自定义HTML代码”示例：
                  
                  <script type="text/javascript"> 
                      Optanon.OnConsentChanged(function () { 
                          window.recordTier.push({eventName: 'OnConsentChanged'}); 
                      }); 
                  </script>

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7a/v3/TQBkUKPASiOFAdIlFPbShg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=54A08F8C00933B1E122BA9C331E8A5266A4EA9FFCBF0D652606897F9165080F5)

上述方法仅适用于[OneTrust Consent配置](https://community.cookiepro.com/s/topic/0TO1Q000000bCetWAE/cookie-compliance)方案，您需要根据您自己选择的Consent厂家的方案进行相应调整和修改。

      2. 读取用户隐私同意结果。

在“变量”中新建一个“自定义JavaScript”变量，用于读取用户隐私同意结果。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/66/v3/UuU43znESQKM7_QFdd9Z6A/zh-cn_image_0000001175421545.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=141514AB6691C1B926B6E6B454951E6AFA710C333DA49583D62500C47023D989)

自定义JS中的“OneTrustGroupID”，请根据实际在OneTrust平台配置的分组ID值进行修改。

根据Cookie Consent提供商的方案，读取Consent结果，如果返回值为“true”，则表示同意；否则，表示不同意。

如下为使用OneTrust Cookie方案的样例，您需要根据您使用的Cookie Consent提供商的方案进行修改：

                     return true;

             }

      3. 在“代码”中新建一个“跟踪链接器”代码，将“Cookie同意”设置为“Read_OneTrust_Consent”，并建议将代码的“触发条件”设置为“Initialization - All pages”和“OnConsentChanged”。

#### 方案二：URL传递参数

如果您的网站是跨域的或者本域内有多级页面跳转，在一些情况下，如部分用户的浏览器设置不允许使用一方Cookie，或者您的网站不允许DTM使用Cookie等，导致用于存储广告互动信息的Cookie方案不可用。此时，您可以使用URL传递参数方案。

      * 若您的网站在本域内有多级页面跳转

您可以将跟踪链接器中的“URL传递参数”配置为“true”，如果用户点击的是链接或表单提交，则DTM会把当前页面URL中的广告跟踪参数自动附加到下级网页链接和表单URL中。

如果将“URL传递参数”配置为“false”，则DTM不会将广告跟踪参数自动附加到下级网页链接和表单URL中。

建议将这个参数配置为“true”，以最大程度提升转化信息上报率。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/f2u6SXzQQZeZQiNblVBt7g/zh-cn_image_0000001525610709.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=A87D4ECB4AAD857213751BDFD382C9CFB7670F814BC8D97716C835AA0CDA2021)

      * 若您的网站需要跨域

如果从本网域（如www.a.com）跳转到第三方网域(例如www.b.com)，您可以在跟踪链接器中的“链接网域”添加第三方网域的域名。在跨网域跳转过程中，DTM自动将广告跟踪参数附加到下级网页链接和表单URL里。

如果只在本网域内跳转，则不需要配置“链接网域”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/J0dV3-hxSS6I8hOMFqrp7A/zh-cn_image_0000001525490857.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=1F665ED295DB6DCBC2DAAE13FE64E5531B7E032660345985B175B77AB8B19313)

#### 停止向Petal Ads上报转化信息

用户进入落地页后，DTM会自动根据落地页URL地址中的广告跟踪参数，默认上报转化信息到Petal Ads。

      * 如果您的网站要求暂时停止向Petal Ads上报转化信息，相关配置如下：

在“代码”中新建一个“自定义 HTML”代码，建议将代码的“触发条件”设置为“Initialization - All pages”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/ATjU8VTFQXCJBLUZFY7dRA/zh-cn_image_0000001410031698.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=1A8F8C5A86F09EB98D08310BAF313C96E722E8B0FA3735B3284E59E8D81221C9)

自定义HTML代码示例如下：
            
            <script>
            window.recordTier.push({'report_enable': 'false'});
            </script>

      * 如果您的网站要求，仅在获得用户Cookie Consent同意后，才允许DTM向Petal Ads上报转化信息，您需要使用**window.recordTier.push** 函数设置“report_enable”上报开关值。如果上报开关设置为“false”，DTM将不会向Petal Ads的上报任何转化信息；如果上报开关设置为“true”，DTM才会将转化信息上报给Petal Ads。

如下是使用OneTrust Cookie方案的样例，您需要根据您使用的Cookie Consent提供商的方案进行修改。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d8/v3/OFzAq6epSMC5FiqPfpLCvQ/zh-cn_image_0000001308477836.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=46C0B95A3F13491EEF45FA16F2FCD4EB6B5C2106F8D02C3EF32BB6E9A7FAFA8E)

自定义HTML代码示例如下：
            
            <script>
            window.recordTier.push({'report_enable': 'false'}); 
            
            Optanon.OnConsentChanged(function () {   
            var OneTrustGroupID = '4';   
                if (window.OnetrustActiveGroups && window.OnetrustActiveGroups.indexOf(',' + OneTrustGroupID + ',') != -1) { 
                    window.recordTier.push({'report_enable': 'true'});   
            } 
            else { 
            window.recordTier.push({'report_enable': 'false'});   
            } 
                }); 
            </script>

#### 隐私说明

Petal Ads只会收集您部署了关联代码的网页的数据。

请务必清楚、全面地向用户说明您在网站上收集的数据，在具有相应法律要求的情况下，必须征得用户同意后进行数据收集。

如果您在跟踪链接器中，将“Cookie同意”设置为“true”，允许DTM将广告跟踪参数写入一方Cookie，则DTM会从URL中获取“tracking_url”参数，写入一方Cookie，key为“dtm_trlnk_tracking_url”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/94/v3/o4CAxwZYTjSBPErVPpGr7A/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=EA350A5857E77C7A7DA905F707703C14C2EA9809F68768C80ADC785B245CAEFA)

DTM仅使用一方Cookie存储广告跟踪参数，不会使用三方Cookie。

上报到Petal Ads的数据不包括个人数据。

不同国家和地区隐私要求不一样，各个国家的广告主需要根据自己国家的法规确定自己的隐私策略，采用不同的配置方法。请根据Petal Ads的使用地区选择以下隐私声明。

      * 区域1：如果您的居住地是中国大陆，请参见[关于鲸鸿动能广告与隐私的声明（中国大陆版）](https://privacy.consumer.huawei.com/legal/ads/privacy-statement.htm?&code=CN&language=zh-CN&branchid=0&contenttag=default)。
      * 区域2：如果您的居住地是欧洲、美国、加拿大、土耳其、澳大利亚、新西兰、塞浦路斯、格陵兰岛、圣文森特和格林纳丁斯、圣马力诺、荷属圣马丁或以色列，请参见[关于鲸鸿动能广告与隐私的声明（欧洲版）](https://privacy.consumer.huawei.com/legal/ads/privacy-statement.htm?&code=EU&language=zh-cn&branchid=0&contenttag=default)。
      * 区域3：如果您的居住地是非洲、拉丁美洲、大洋洲（澳大利亚和新西兰除外）、中亚、南亚、东南亚、西亚或东北亚，请参见[关于鲸鸿动能广告与隐私的声明（中国香港版）](https://privacy.consumer.huawei.com/legal/ads/privacy-statement.htm?&code=HK&language=zh-cn&branchid=0&contenttag=default)。

#### 异常处理

通过Petal Ads与DTM的配置，您可以轻松实现网页的转化跟踪，但是在某些情况下，Petal Ads无法收到转化跟踪事件，请按如下步骤定位处理。

      1. 检查网页是否已经集成正确的DTM JS代码。

         1. 在DTM的“配置”页面，点击“查看”按钮获取DTM JS代码。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/qOw4RNG_ROmXOP2apyNy_A/zh-cn_image_0000001309315437.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=EC426FF41B005E36C6FC7324E6AB09165FD0369CF796594D6940A472FCE1509B)

         2. 在您的网页按“F12”键，进入浏览器的调试模式。
         3. 刷新网页后，在“Network”页签中查看是否有加载dtm.js，且其中的配置ID是否与DTM“配置”中的DTM JS代码（DTM-xxxx）一致。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1e/v3/PJ4r3_wZQHm516Lk0DdgDA/zh-cn_image_0000001172879109.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=18334C479FF0EE239DF8F15776B8DB37814796B04F5DE9CABFABCD0CA0226046)

            * 若没有加载dtm.js，说明当前网页没有集成DTM，则需要将DTM JS代码片段拷贝到您网站的每个网页上。
            * 若加载了dtm.js，请确认dtm.js中的配置ID（DTM-xxxx）是否与DTM“配置”中的DTM JS代码（DTM-xxxx）一致。

      2. 在DTM中配置了跟踪链接器且用户同意广告跟踪时，检查广告跟踪参数（“tracking_url”）是否写入到Cookie的“_dtm_trlnk_tracking_url”字段中。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bf/v3/hV0d4X-lQ12PMP-sgMIiTA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=052100072F5C933C9BFC4A510A816E2BB5FCB04124E66F9DD7FABD712F4BB76E)

如果是单页面跟踪场景，只在落地页进行跟踪，则不需要用到跟踪链接器，请忽略该步骤。

在您的网页按“F12”键，进入浏览器的调试模式。在“Application”页签中查看当前网页域名的Cookie，搜索“_dtm_trlnk_tracking_url”字段。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c0/v3/z9si0rQgTMWkbMag2W0D5Q/zh-cn_image_0000001127178278.png?HW-CC-KV=V1&HW-CC-Date=20261005T043038Z&HW-CC-Expire=86400&HW-CC-Sign=47918E21E5576DFE21BF854AE6F2374E5E3E0A63B3059FB96544398ED52F0F4B)

若不存在“_dtm_trlnk_tracking_url”字段，则说明广告跟踪参数（“tracking_url”）未写入，请做如下检查：

         1. 用户是否选择了同意Cookie。
         2. DTM的“代码”页面，“跟踪链接器”中的Cookie同意是否配置正确。

           * 利用Chrome DevTools检查
             1. 通过如下命令，在App中启用WebView调试，开启调试后，Chrome DevTools才对WebView进行远程调试。
                    
                    WebView.setWebContentsDebuggingEnabled(true);

             2. 在Chrome浏览器的地址栏中输入chrome://inspect/#devices，打开App并进入需要调试的WebView页面，点击“inspect”按钮开始调试。
