# 通用  
  
#### 事件参数列表

      * kHAEventRegisterAccount

用户注册帐号时，上报此事件。可以分析用户来源，有针对性地优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRegistMethod | 注册方式 | String | 可选 | 用户的注册方式，如：邮箱、手机号、微信等。  
kHAParamAcountType | 帐号类型 | String | 可选 | 用户帐号类型，如：邮箱、手机号、微信等。  
kHAParamTaskId | 任务ID | String | 可选 | 营销任务ID。  
  
      * kHAEventWinVirtualCoin

用户获取到虚拟币时，上报此事件。可以用于分析用户获取虚拟币的难易程度，优化产品设计。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamRoleName | 用户角色 | String | 可选 | 标识用户的角色。  
kHAParamWinReason | 获取原因 | String | 可选 | 获取虚拟币的原因。  
kHAParamVirtualCurrName | 虚拟币类型名称 | String | 必选 | 标识用户获取到的虚拟币类型。  
kHAParamLevel | 关卡 | String | 可选 | 获取虚拟币的关卡。  
kHAParamEntry | 入口 | String | 可选 | 获取虚拟币的入口。  
kHAParamRevenue | 虚拟币数量 | Long or Double | 必选 | 用户获取到的虚拟币数量。  
kHAParamBalance | 虚拟币余额 | Long or Double | 可选 | 用户获取虚拟币后虚拟币余额。  
  
      * kHAEventCompletePurchase

用户支付完成后，上报此事件。可以用于分析用户对哪些商品或内容更感兴趣，优化运营策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamProductId | 商品ID | String | 必选 | 被添加到购物车中的商品ID。  
kHAParamProductName | 商品名称 | String | 必选 | 被添加到购物车中的商品名称。  
kHAParamQuantity | 购买数量 | Long | 必选 | 用户准备购买的数量。  
kHAParamCurrName | 货币类型 | String | 可选 | 标识收入的货币类型。与kHAParamRevenue一起使用。  
kHAParamRevenue | 收入 | Double | 可选 | 本次交易给您带来的收入。必须与kHAParamCurrName同时使用。  
kHAParamTaxFee | 税费 | Double | 可选 | 本次交易产生的税费。  
kHAParamLevel | 关卡 | String | 可选 | 获取虚拟币的关卡。  
kHAParamEntry | 入口 | String | 可选 | 获取虚拟币的入口。  
kHAParamRoleName | 用户角色 | String | 可选 | 针对游戏场景，标识购买商品的游戏角色。  
kHAParamDiscount | 折扣 | Double | 可选 | 本次交易折扣金额。  
kHAParamFirstPay | 是否首次支付 | String | 可选 | 标识用户是否首次购买此商品。
        * 0：非首次购买
        * 1：首次购买  
kHAParamPayType | 支付方式 | String | 可选 | 用户选择的支付方式。  
  
      * kHAEventUpgradeLevel

游戏应用中用户升级时，上报此事件。分析产品的用户等级设置是否合理，有针对性地制定优化策略。

参数ID | 参数名称 | 参数类型 | 可选/必选 | 参数描述  
---|---|---|---|---  
kHAParamLevelId | 用户等级 | Long | 必选 | 标识用户提升后的等级。  
kHAParamRoleName | 用户角色 | String# 通用
