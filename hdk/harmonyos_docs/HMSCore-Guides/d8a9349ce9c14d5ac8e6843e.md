# 获取和注销Token

## 获取Push Token

### 场景介绍

Token是每台设备上每个应用的唯一标识，应用调用[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)方法向Push服务端请求Token，当[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)方法返回为空时，Token可通过[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section343314205)方法返回，因此您必须实现[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section343314205)方法。您也可以通过SDK的[自动初始化](#section13546121751811)能力来自动获取Token。获取到Token后需要将Token上报到您自己的应用服务器。后续您可以调用[下行消息API](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-server-dev-0000001050040110)，根据Token来推送消息。

Token与华为帐号不相关，仅与您的App ID相关，因此切换华为帐号后Token不会变化。建议您直接使用推送服务提供的[帐号校验功能](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/account-profile-0000001057562781)来开发帐号相关功能，无需通过Token来判断。

Token一般情况不会变化，仅下列场景Token会发生变化。因此，禁止频繁申请Token，尤其严禁常驻应用定期频繁申请Token。

* 清除应用数据（例如卸载应用并重新安装、设备恢复出厂设置等）后重新打开应用。
* 应用显式调用[注销Push Token](#section15753161611016)方法并重新调用[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)方法。

> 说明
>
> 推送服务为了提升安全性，在2020年11月更新了Token的编码规则，用户只要升级了新版的推送服务应用，当您的应用被卸载重装后，重新打开时申请到的Token即为最新的编码格式。

### 注意事项

* 请勿使用Push Token跟踪标记用户。
* 应用不要固定判断Push Token长度，因为后续长度可变。
* 禁止应用频繁申请Token。对于非常驻应用每次启动时获取Token，对于常驻应用严禁定期频繁申请Token，如果一定要周期申请建议周期大于1天。


* 只有在AppGallery Connect平台[打开推送服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-config-agc-0000001050170137#section9471122085218)后，[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)方法才会返回Push Token。
* **请注意** **您在代码中必须同时声明[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)方法和[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section343314205)方法**，确保Push Token成功返回。

### 开发步骤

建议在应用启动后首个Activity的onCreate方法中调用getToken方法。

1. 调用getToken方法获取Push Token。

   > 说明
   > * 不建议在子进程中申请Push Token。
   > * 如果存在多处调用getToken方法的场景，请确保各处入参"appId"的值一致。
   > * 调用getToken方法一定要增加异常捕获处理且获取Push Token后一定要做判空处理。
   > * HmsInstanceId类及其提供的方法请参见[HmsInstanceId](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634)。

   ```java
   "Java"
   private void getToken() {
       // 创建一个新线程
       new Thread() {
           @Override
           public void run() {
               try {
                   // 从agconnect-services.json文件中读取APP_ID
                   String appId = "your APP_ID";

                   // 输入token标识"HCM"
                   String tokenScope = "HCM";
                   String token = HmsInstanceId.getInstance(MainActivity.this).getToken(appId, tokenScope);
                   Log.i(TAG, "get token success");
                   
                   // 判断token是否为空
                   if(!TextUtils.isEmpty(token)) {
                       sendRegTokenToServer(token);
                   }
               } catch (ApiException e) {
                   Log.e(TAG, "get token failed, " + e);
               }
           }
       }.start();
   }
   private void sendRegTokenToServer(String token) {
       Log.i(TAG, "sending token to server.");
   }
   ```

   ```kotlin
   "Kotlin"
   private fun getToken() {   
       // 创建一个新线程
       object : Thread() {
           override fun run() {
               try {
                   // 从agconnect-services.json文件中读取APP_ID
                   val appId = "your APP_ID"
                   
                   // 输入token标识"HCM"
                   val tokenScope = "HCM"
                   val token = HmsInstanceId.getInstance(this@MainActivity).getToken(appId, tokenScope)
                   Log.i(TAG, "get token success")
                   
                   // 判断token是否为空
                   if (!TextUtils.isEmpty(token)) { 
                       sendRegTokenToServer(token)
                   }                
               } catch (e: ApiException) { 
                   Log.e(TAG, "get token failed, $e")
               }
           }
       }.start()
   }
   private fun sendRegTokenToServer(token: String) { 
       Log.i(TAG, "sending token to server.")
   }
   ```

2. 在您的service（[已继承HmsMessageService](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-cfg-manifest-0000001050042037#ZH-CN_TOPIC_0000001652651328__li1869714333285)）中，覆写[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section343314205)方法，Push Token发生变化时会在onNewToken方法中返回。

   > 说明
   > * 获取Push Token后一定要做判空处理。
   > * 如果您集成的Push SDK版本低于**5.0.4.302** ，请及时升级[最新Push SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-app-version-0000001074227861)。

   ```java
   "Java"
   @Override
   public void onNewToken(String token, Bundle bundle) {         
       // 获取token
       Log.i(TAG, "have received refresh token.");
       
       // 判断token是否为空
       if (!TextUtils.isEmpty(token)) {
           refreshedTokenToServer(token);
       }
   }

   private void refreshedTokenToServer(String token) {
       Log.i(TAG, "sending token to server.");
   }
   ```

   ```kotlin
   "Kotlin"
   override fun onNewToken(token: String, bundle: Bundle) {    
       // 获取token
       Log.i(TAG, "have received refresh token.")
       
       // 判断token是否为空
       if (token.isNotEmpty()) { 
           refreshedTokenToServer(token)    
       }
   }

   private fun refreshedTokenToServer(token: String) { 
       Log.i(TAG, "sending token to server.")
   }
   ```

## 注销Push Token

### 场景介绍

用户拒绝接受您应用的使用协议和隐私声明后，您可以调用[deleteToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1142844881810)方法删除Push服务器上对应的Push Token。删除成功后，客户端应用将不再接收到消息。

不建议您调用[deleteToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1142844881810)方法删除Push Token，建议您将拒绝应用使用协议和隐私声明用户的Push Token状态设置为无效状态，并控制应用服务端不再向Push Token无效的客户端推送消息，此举可减少应用服务端向Push Kit服务端请求的频率。
> 说明
>
> * 禁止频繁注销Push Token。
> * 注销Push Token需要HMS Core（APK）的版本不低于3.0.0。
> * 如果您不希望应用接收消息，可以调用[turnOffPush](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650#section943612533595)方法关闭通知栏消息。
> * 您应用的使用协议和隐私声明必须包含并遵守《[华为推送服务使用协议](https://developer.huawei.com/consumer/cn/doc/app/20213)》和《[SDK隐私安全说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sdk-data-security-0000001050042177)》。

### 开发步骤

注销Push Token方法示例：

```java
"Java"
private void deleteToken() {
    // 创建一个新线程
    new Thread() {
        @Override
        public void run() {
            try {
                // 从agconnect-services.json文件中读取APP_ID
                String appId = "your APP_ID";
                
                // 输入token标识"HCM"
                String tokenScope = "HCM";

                // 注销Token
                HmsInstanceId.getInstance(context).deleteToken(appId, tokenScope);
                Log.i(TAG, "token deleted successfully");
            } catch (ApiException e) {
                Log.e(TAG, "delete token failed." + e);
            }
        }
    }.start();
}
```

```kotlin
"Kotlin"
private fun deleteToken() {   
    // 创建一个新线程
    object : Thread() {
        override fun run() {
            try {
                // 从agconnect-services.json文件中读取appId
                val appId = "your APP_ID"
                
                // 输入token标识"HCM"
                val tokenScope = "HCM"

                // 注销token
                HmsInstanceId.getInstance(this@MainActivity).deleteToken(appId, tokenScope)
                Log.i(TAG, "token deleted successfully")
            } catch (e: ApiException) { 
                Log.e(TAG, "delete token failed, $e")
            }
        }
    }.start()
}
```

## 自动初始化

Push SDK 4.0版本开始提供了自动生成AAID和获取Push Token的能力。配置本能力后，不需要显式的调用[getToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hms-instanceid-0000001050255634#section1796315281618)申请Push Token，Push Token以[onNewToken](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessageservice-0000001050173839#section343314205)回调的方式返回。设置自动初始化的方式如下：

* 方式一

  在"AndroidManifest.xml"文件的<application>标签内添加<meta-data>元数据，其中"name"为固定值"push_kit_auto_init_enabled"，"value"可设置为"true"（启用了自动初始化）或"false"（未启用自动初始化），示例如下：

  ```xml
  <manifest ...>
      ...
      <application ...>      
          <meta-data
  android:name="push_kit_auto_init_enabled"
  android:value="true"/>
          ...
      </application>
      ...
  </manifest>
  ```

* 方式二（推荐） 在主Activity类中显式调用[setAutoInitEnabled](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650#section19198183125511)方法，参数enable表示是否启用自动初始化，取值为true或false。该参数值会保存在应用本地的"shared_prefs"目录下的文件中。

  ```java
  "Java"
  private void setAutoInitEnabled(final boolean isEnable) {
      if(isEnable){
          // 设置自动初始化
          HmsMessaging.getInstance(this).setAutoInitEnabled(true);
      } else {
          // 禁止自动初始化
          HmsMessaging.getInstance(this).setAutoInitEnabled(false);
      }
  }
  ```

  ```kotlin
  "Kotlin"
  private fun setAutoInitEnabled(isEnable: Boolean) {
      if (isEnable) {
          // 设置自动初始化        
          HmsMessaging.getInstance(this).isAutoInitEnabled = true    
      } else {
          // 禁止自动初始化       
          HmsMessaging.getInstance(this).isAutoInitEnabled = false
      }
  }
  ```

> 注意
>
> * 若应用存在使用协议和隐私声明需要用户手动同意，请使用"方式二"进行自动初始化。因为方式一在应用启动时会自动生成AAID并申请Token，即在用户同意使用协议和隐私声明前就触发了自动初始化，不满足个人数据保护规范。
> * 用户同意后调用[setAutoInitEnabled](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/hmsmessaging-0000001050255650#section19198183125511)方法启用自动初始化。
> * 如果终端设备应用本地"shared_prefs"目录下的文件中保存了对应key（push_kit_auto_init_enabled）的配置信息，Push SDK会直接从中读取信息并判断是否启动了自动初始化。如果应用本地文件中没有保存对应key的配置信息，Push SDK才会从<meta-data>元数据中读取信息。
