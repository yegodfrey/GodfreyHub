# 读取Applet身份公钥及签名

Applet身份公钥，以及钱包服务器对其的签名存放于"A0F8"中。

1. 选择aid，"00A40400"+ aid字节长度 + aid，例如：

   ```screen
   00A4040010A0000000485750415906000001000004
   ```

   成功则返回"9000"。

2. 选择"A0F8"文件。成功则返回"9000"。

   ```screen
   00A4000002A0F8
   ```

3. 读取"A0F8"的内容。"A0F8"最大容纳2048字节，每次最多读取255字节，例如：

   ```screen
   00B00000FF resp : xxxxx
   00B000FFFF resp : xxxxx
   00B001FEFF resp : xxxxx
   00B002FDFF resp : xxxxx
   00B003FCFF resp : xxxxx
   00B004FBFF resp : xxxxx
   00B005FAFF resp : xxxxx
   00B006F9FF resp : xxxxx
   00B007F808 resp : xxxxx
   ```

   解析从"A0F8"中读取的内容。将上述"resp"中的响应数据拼接去掉末尾的"0"后，转换为ASCII码，会解析出如下json格式数据。其中"publicKey"为Applet身份公钥，"signature"为钱包服务器私钥对"publicKey"的签名，签名算法为"SHA256WithRSA"。

   ```screen
   {
       "signature":"xxxxxxx",
       "publicKey":"xxxxxxx"
   }
   ```

   对上述"publicKey"和"signature"做base64解码后，用钱包服务器公钥验证签名，签名算法为"SHA256WithRSA"。验签通过则继续，否则终止读卡。
