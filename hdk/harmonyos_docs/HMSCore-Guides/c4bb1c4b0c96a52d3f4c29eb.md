# 操作流程

#### 创建代码

                1. 在“代码”页面，点击“新建”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b8/v3/H1xrobJmQOirchPMCpJu3Q/zh-cn_image_0000001077999092.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=31F3E18D2F558CBB886601EE4A5C4FEE8F7FDA41107D969A342C09801DB1D8CB)

                2. 在“新建代码”页面的“配置”区域输入代码名称，选择代码扩展类型并输入对应的参数。
                3. 在“新建代码”页面的“条件”区域设置代码的“触发条件”和“例外条件”。

                   * “触发条件”满足时将上报事件至HUAWEI Analytics。
                   * “例外条件”满足时将阻止事件上报。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/sju_ZFjYTQOuTNGfa9nGow/zh-cn_image_0000001078127558.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=BE7639ECB9E72B6E9E73C553262A9E6C99388D9E9A5BBBA0A4C09B4CB449B10C)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cc/v3/UV3n7rmTRp-SRWdn-TnMbw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=2F6BFE396C7E86A19094B22D468EE0E05C0C1EA2D2F3282C043C7ADE8A49E3BB)

                   * 配置代码参数时，若输入框右侧有引用符号![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/eb/v3/KicBpFDdSZi9MlGpHPTu1A/zh-cn_image_0000001090021417.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=77313C287714AD18ACA68D4CDC0935E3027139F4493F64AC53E243314C8782CB)，点击该符号可以对已创建变量进行引用。对于引用变量，页面中使用“{{}}”进行标注。

若您所需的变量还未创建，可通过点击“配置”按钮，配置预设变量；或通过点击“新建”按钮，新建自定义变量。

                   * 代码配置应至少包含一个触发条件，若同时配置了触发条件和例外条件，优先触发例外条件。

                4. 设置完成后，点击“保存”。

#### 编辑代码

                1. 在“代码”页面，点击已创建代码的名称。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/40/v3/iz_d3gDUTEe8M6xa0ACLLA/zh-cn_image_0000001078447240.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=CE2B050B0C246BF6BD9046B6991B5FE6EB0A7C6164E5F0E380E13FCE2723A4EA)

                2. 在“编辑代码”页面可以对代码的配置和条件进行修改。修改完成后，点击“保存”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/cfyypgotRx2sftxKhy9ysw/zh-cn_image_0000001077745860.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=131AECAA4FDE9403F0C114D9316BCFB4294AD14A0A11BFD227B05FC724C80394)

#### 复制代码

                1. 在“代码”页面，点击已创建代码右侧的“复制”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/QPobC-0iRB-2nVHPcZGrSg/zh-cn_image_0000001116514931.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=62CF0DFC474044409E99F29EABB2472A1F960DAEDA050005481643DE17170EC1)

                2. 在“复制代码”页面可以对代码的配置和条件进行修改。修改完成后，点击“保存”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/CkAUCCr_TE-pOmNu1bmlrw/zh-cn_image_0000001090141409.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=1D2F68368A3C16AA27641D39C3366634590637B39FC92CE388C3F8AF55028806)

                3. 复制完成后，您可以在“代码”页面，查看复制的代码信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/19/v3/VBkb_NNaQqiRbmYoS43Hcw/zh-cn_image_0000001171228503.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=F95B85B8B5E44BF12197CFCDA20BE07A1F56B62A1D409F9325076F4AB7E72A10)

#### 暂停/执行代码

                1. 在“代码”页面，点击已创建代码右侧的“暂停”，确认“暂停代码”对话框中的提示信息后点击“确定”。

暂停成功后，系统提示“代码已暂停”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/xrRRHcXRQ8S3PB8SbUcnnQ/zh-cn_image_0000001077999240.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=AD88FAE68B10F48B7C7E1596CED2F2DA0084C3793D4077A4A0AB0EC100B3C406)

若您需要暂停多个代码，也可以通过批量暂停功能实现。勾选待暂停代码前的方框，点击页面右上方的“暂停”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5b/v3/nFIoZ5ObTWK_XXnsj9cPPg/zh-cn_image_0000001130126875.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=D7B118EFC9E4FBDC10CCBCEDAB4C6ECF469F373C7B90CBAD3A6FB2FB45F28BE4)

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/DLC-2NkkQ1mL_yYH9O92sQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=C6A14CE1E44CB2A66D15D42ACB6F477505EA5E03E78E06454B316FB55CF2F2D3)

代码置为暂停状态后，代码名称前会出现暂停标识，暂停状态下的代码在后续创建的版本中不会触发事件上报。

                2. 点击已暂停代码右侧的“执行”，代码恢复为可执行状态。代码恢复后，代码名称前的暂停标识会自动取消，在后续创建的版本中将正常触发事件上报。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/Fq_BozTmQFSEg-Gn0kUoag/zh-cn_image_0000001078127742.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=766A132F697EB8D717DA738984EDFE3E894CF7D73E1C9C974B8E2859D3D66535)

若您需要执行多个代码，也可以通过批量执行功能实现。勾选待执行代码前的方框，点击页面右上方的“执行”按钮。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/eLHnB8ceQ_Sdmf1SxAXslg/zh-cn_image_0000001083530652.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=913B243D88A6E2BCE1430F532F4CA30104E0CE2AEEF607194BD6D332BDB6816C)

#### 删除代码

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9c/v3/Vv2UBGJfRFClfnDWmNH9Yg/caution_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=9C861ADF68FCE7646AB640AD4BF7EF59ADD4B69D32A88920741B79621ED6BC64)

代码删除后将不可恢复，删除前请确认代码已不再使用。如果您只是暂时不使用该代码，您可以暂停代码。

**方法一：单个删除。** 在“代码”页面，点击已创建代码右侧的“删除”，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/txdJnSbJRKGTOjS4N5k3Kg/zh-cn_image_0000001078447320.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=50A58E5A93A1159BFF57676EE015CB754AE491C65BB5A0F5CDFD374F83EBBF71)

**方法二：批量删除。** 若您需要删除多个代码，也可以通过批量删除功能实现。勾选待删除代码前的方框，点击页面右上方的“删除”按钮，确认对话框中的提示信息后点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/VVS11M-rT3qdQRX9k5o5Bg/zh-cn_image_0000001130278117.png?HW-CC-KV=V1&HW-CC-Date=20261005T043047Z&HW-CC-Expire=86400&HW-CC-Sign=AA0D22D0434F616C9DDB8D951D2B428A1C658636EA365B40B1DA5CEA0A8D8294)
