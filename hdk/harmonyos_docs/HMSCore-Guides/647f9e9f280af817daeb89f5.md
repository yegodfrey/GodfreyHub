# 应用市场付费推广归因（中国大陆）

#### 功能概述

开通华为分析服务后，广告主在应用市场付费推广平台（简称商推）创建推广任务时，可以选择华为分析进行归因监测。选择华为分析平台作为监测平台，具有以下优点：

* 可通过华为分析便捷地进行推广归因，降低开发者接入监测、回传归因操作成本。
* 有助于实时监测并优化投放任务，提升ROI。
* 转化事件回传通道稳定、高效。
* 赋能oCPX 投放，提升获客效率, 优化获客成本。  

#### 前提条件

* 已开通华为分析服务。开通华为分析服务详情请参见[开通服务](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/service-enabling-0000001050745155)。
* 该功能适用于Android SDK 6.4.1.300及以上版本，请将SDK升级到6.4.1.300及以上版本。集成SDK及接入分析服务操作详情请参见[开发流程](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-dev-process-0000001050163813#section15960539132113)。

1. 开通华为分析服务并集成SDK。操作详情请参见[开发流程](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-dev-process-0000001050163813#section15960539132113)。  
   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115300.42806931332025380502279429333813:50001231000000:2800:B4BB285B4B228F804F3E63439AD4D5B9E0A03CE1BA02504E1566FD35C4D4FFDC.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)  
   开通华为分析服务并集成SDK后，广告主需申请开通监测链接，详情请参见[申请开通](https://developer.huawei.com/consumer/cn/doc/distribution/promotion/bp-functions-link-apply-0000001298858800)。
2. 广告主在华为应用市场推广门户先创建归因监测平台为"华为分析"的数据源，之后创建推广任务时归因方式选择"华为分析监测"。详情请参见[创建数据源](#section116651757153516)和参见[创建推广任务](#section1326015366254)。
3. 应用市场推广门户向应用市场付费推广平台下发广告任务。
4. 应用市场付费推广平台投放广告至应用市场推广榜单。
5. 当终端用户在对应的广告位进行了浏览、点击、下载、安装操作时，数据上报至应用市场付费推广平台。
6. 应用市场付费推广平台通过接口将"点击"行为信息传输至华为分析服务。
7. 华为分析服务根据"末次点击"归因模型进行归因，并将激活应用、启动应用、付费、注册、下单转化事件数据回传至华为应用市场付费推广平台。您可在华为分析服务侧查询回传的转化事件，详情请参见[查看自动回传转化事件](#section13824185010582)。
8. 在华为应用市场付费推广平台查看归因数据的报告。详情请参见[在商推侧查看归因报告](#section25299521085)。
9. 在华为分析服务平台查看买量用户分析报告。详情请参见[查看买量用户分析报告](#section183471222103017)。
10. 在"营销活动"页面查看归因分析报告。详情请参见[查看营销活动报告](#section33101714125511)。

技术原理：

1. 用户在华为应用市场付费推广平台点击广告位，广告平台通过接口将点击行为信息传输至华为分析服务。
