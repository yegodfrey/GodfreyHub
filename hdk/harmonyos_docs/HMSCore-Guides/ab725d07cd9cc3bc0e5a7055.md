# 批次码

批次码的具体创建如下：

1. 申请创建会员开放服务。本期暂时只开放"服务类型"为"劵码"，"服务项目"为"批次码"的内容。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220323160004.75871867802946346719231713763100:50530322093902:2800:DAA646AE1CD7EC297ECE59142AC283ABA39133AC57D1FCAD094A35BF4A139353.png?needInitFileName=true?needInitFileName=true "点击放大")
2. 设置Membership Kit卡劵基本信息。在填写"标题"、"副标题"等信息之后，会在右侧的预览图中看到具体的效果。开发者可以根据自己的需求设置批次劵码的信息。

   ![](https://communityfile-drcn.op.hicloud.com/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20220323160004.45763276971857658882577112580909:50530322093902:2800:2311F8D214985DD2AE97C57C39BA3E0CC8EA46E9A99BF1A6ECD2F82DC9A29672.png?needInitFileName=true?needInitFileName=true "点击放大")

运营审核创建后，将劵码绑定到对应的活动、权益或者福利上线后，就能在会员中心App上看到劵码。
