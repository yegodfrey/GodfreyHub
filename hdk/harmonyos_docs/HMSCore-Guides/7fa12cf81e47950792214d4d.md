# 调用Wallet Kit SDK接口实现NFC写卡能力

商户开发者可通过Wallet SDK实现NFC写卡能力。  
![](https://media:101782807014974662)  
* 当前此种方式只支持通过[App应用集成HMS Core SDK后推送卡券包到华为钱包应用](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-hms-sdk-add-card-0000001050166747)方式集成。
* 集成NFC刷卡能力前请先[添加卡券](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-webpage-0000001050042334)至华为钱包。
* 功能实现请参考"[示例代码：huawei-wallet-server-windows-nfc-demo.zip](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/java-sample-code-0000001050157448)"。  

#### 申请注册

商户通过此接口可以获取Applet的公钥和认证请求信息。registerRequestBody字段请参考接口文档定义，registerRequestBody通过requestBody.toJson()方式获取得到，requestBody类中的passTypeIdentifier和serialNumber字段为添加卡券时由商户服务器定义。

接口定义：

接口定义：WalletPassApiResponse requestRegister(String registerRequestBody)

输入参数：  

|父节点参数|子节点参数|类型|必选/可选|描述|
|:----------|:-----------------|:-----|:----|:-------------------------------------|
|requestBody|passTypeIdentifier|String|必选|注册walletKit服务的passTypeIdentifier。|
|requestBody|serialNumber|String|必选|Pass对象在发卡方的唯一键值，回调时以便发卡方根据此值识别具体的卡券记录。|

WalletPassApiResponse定义：  

|参数名|参数类型|参数描述|
|:----------|:-----|:----------|
|returnCode|String|结果码，0：添加成功。|
|responseStr|String|注册请求信息。|

responseStr定义如下：  

|父节点参数|子节点参数|类型|可选/必选|描述|
|:-----------|:-----------------|:-----|:----|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
|responseBody|passTypeIdentifier|String|必选|注册walletKit服务的passTypeIdentifier。|
|responseBody|serilNumber|String|必选|Pass对象在发卡方的唯一键值，回调时以便发卡方根据此值识别具体的卡券记录。|
|responseBody|passVersion|String|可选|版本号，固定10.0。|
|responseBody|userDeviceId|String|必选|用户在当前设备上的唯一标识。|
|responseBody|transId|Sring|必选|随机数。|
|signature|-|String|必选|Applet的身份私钥对responseBody的SHA256RSA签名，其中responseBody以Key的字母顺序排序计算Hash，样例如下：SHA256(passTypeIdentifier=xxx\&serialNumber=xxx\&transId=xxx\&userDeviceId=xxx)。|
|certificate|signature|String|必选|WalletServer签发。|
|certificate|publicKey|String|可选|Applet的身份公钥。|
|certificate|type|String|可选|类型。|

```
//申请注册流程
WalletPassApiResponse response = mWalletPassApi.requestRegister(registerRequestBody);
```

#### 确认注册

商户通过此接口可以导入Applet的认证信息。registerConfirmBody字段中certificate的值为"申请注册"接口返回值，请参考接口定义处理。

接口定义：

接口定义：WalletPassApiResponse confirmRegister(String registerConfirmBody)

输入参数：  

|父节点参数|子节点参数|类型|必选/可选|描述|
|:----------|:----------|:----------|:----|:--------------------------|
|requestBody|certificate|Certificate|可选|SP验证请求后，SP私钥给Applet公钥的签名信息。|

Certificate定义:  

|名称|类型|必选/可选|描述|
|:--------|:-----|:----|:-----------|
|signature|String|必选|商户服务器签名。|
|publicKey|String|可选|Applet的身份公钥。|
|type|String|可选|类型。|

WalletPassApiResponse:  

|参数名|参数类型|参数描述|
|:---------|:-----|:---|
|returnCode|String|结果码。|

```
//确认注册流程
WalletPassApiResponse response = mWalletPassApi.confirmRegister(registerConfirmBody);
```

#### 申请个人化

商户应用通过此接口可以申请Applet个人化信息。personalizeRequestBody中的token为商户自己定义，一般为16字节字符串，接口成功后华为钱包会将token返回给商户，建议商户校验接口返回的token是否有效。

接口定义：

接口定义：WalletPassApiResponse requestPersonalize(String personalizeRequestBody)

输入参数：  

|父节点参数|子节点参数|类型|必选/可选|描述|
|:----------|:-----------------|:-----|:----|:-------------------------------------|
|requestBody|passTypeIdentifier|String|必选|注册walletKit服务的passTypeIdentifier。|
|requestBody|serialNumber|String|必选|Pass对象在发卡方的唯一键值，回调时以便发卡方根据此值识别具体的卡券记录。|
|requestBody|token|String|必选|个人化的token，商户服务器生成。|

![](https://media:101782807014996663)  
personalizeRequestBody为requestBody的toJsonString格式。

WalletPassApiResponse：  

|参数名|参数类型|参数描述|
|:----------|:-----|:---------------------------------------------------------------------------------------------------------------------------|
|returnCode|String|结果码，0：成功，错误码请参见[错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/guide-appendix-errorcode-0000001050756333)。|
|responseStr|String|具体Json定义如下示意。|

|父节点参数|子节点参数|类型|必选/可选|描述|
|:-----------|:-------------------|:----------|:----|:-----------------------------------------|
|responseBody|passTypeIdentifier|String|必选|-|
|responseBody|serialNumber|String|必选|-|
|responseBody|passVersion|String|可选|-|
|responseBody|userDeviceId|String|必选|用户在当前设备上的唯一标识。|
|responseBody|personalizePublicKey|String|必选|Applet的个人化公钥，用于加密个人化字段值。|
|responseBody|personalizeCert|String|必选|Applet身份私钥对个人化公钥personalizePublicKey的签名。|
|responseBody|personalizeCertType|String|必选|固定值。|
|responseBody|transPublicKey|String|必选|用于加密返回的对称秘钥，用于对返回的数据做数字信封。|
|responseBody|transId|String|必选|随机数，在WalletApp侧生成。|
|responseBody|Token|String|必选|请求的个人化token,建议校验。|
|signature|-|String|必选|请求的个人化token作为其中responseBody一个key参与Hash值计算。|
|certificate|-|Certificate|必选|商户服务器签发给Applet的证书。|

```
//申请个人化流程
WalletPassApiResponse response = mWalletPassApi.requestPersonalize(personalizeRequestBody);
```

#### 确认个人化

商户应用通过此接口可以导入Applet个人化信息。personalizeConfirmBody字段生成请参考NFC刷卡服务器示例代码WhiteCardManager.getDevicePassData ()实现，RequestBody内容为申请个人化时华为钱包返回字段。

接口定义：

接口定义：WalletPassApiResponse confirmPersonalize(String personalizeConfirmBody)

输入参数：  

|父节点参数|子节点参数|类型|必选/可选|描述|
|:----------|:-----------------------------|:-----|:----|:----------------------------------------------------------------------------------------------------------------|
|confirmCode|-|String|必选|* 200：成功。 * 401：请求错误（token错误）。 * 402：验签错误。将对encryptAppletPersonalizeFields和encryptSessionKey字段的校验结果放入resultCode中。|
|requestBody|encryptAppletPersonalizeFields|String|可选|SPServer通过生成的sessionKey加密Applet的个人化参数Json，采用Base64编码。|
|requestBody|encryptSessionKey|String|可选|SPServer使用请求中的transPublicKey加密生成sessionKey，采用Base64编码。|
|signature|-|String|必选|SP Server对response的Hash值进行签名。|

WalletPassApiResponse：  

|参数名|参数类型|参数描述|
|:---------|:-----|:--------|
|returnCode|String|结果码，0：成功。|

```
//确认个人化流程
WalletPassApiResponse response = mWalletPassApi.confirmPersonalize(personalizeRequestBody);
```
