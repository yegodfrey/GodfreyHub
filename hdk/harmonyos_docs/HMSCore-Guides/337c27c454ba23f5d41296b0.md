# 受众发送

受众细分是精细化运营的重要方法之一。由于用户的偏好不同，对产品的需求也不一样，要想更好地培养用户粘性，就需要因人施策，精细化运营。受众细分是根据用户属性和行为数据，将具有相同或类似特征的用户归为一个群组的过程。

通过对受众进行洞察分析，了解产品对什么样的用户更有吸引力，针对不同的受众制定不同的运营策略，以提升用户体验，提高留存与转化。

推送服务可结合华为分析服务创建的细分受众进行精准触达。  

#### 应用场景

* 整体用户留存率出现了降低趋势，定位出拉低留存均值的用户群体。
* 快速找到领取了优惠券或积分，但却没有使用的用户，并促使其尽快使用。
* 针对不同地域、机型、年龄、消费水平的用户进行分层运营。
* 基于用户行为和兴趣触发情景式消息。
* 针对老版本用户多场景触发升级提醒。  

#### 开发步骤

1. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)上选择您的项目，左侧导航栏选择"华为分析"，点击"智能数据接入 \> 应用集成"。
2. 根据页面上的"集成配置"指导，在您的工程中[集成分析服务SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/android-dev-process-0000001050163813)。

3. 在您工程中第一个Activity的onCreate方法中初始化分析服务SDK。  

   ```
   "Java"
   @Override  
   protected void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       setContentView(R.layout.activity_main);
       // 打开分析服务日志开关
       HiAnalyticsTools.enableLog();
       // 初始化分析服务
       HiAnalyticsInstance instance = HiAnalytics.getInstance(this);
   }
   ```

   ```
   "Kotlin"
   override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // 打开分析服务日志开关
        HiAnalyticsTools.enableLog()
        // 初始化分析服务
        val instance = HiAnalytics.getInstance(this)
   }
   ```

4. 打开您需要验证的应用，等待1天后即可生成受众群组人数。

   ![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20231103095815.97142567336662520218948527492203:50001231000000:2800:16E509DAFE928B56B3C014B1D5240592E05369B03E45DEEED1E2C26E4968A5C8.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true "点击放大")
5. 在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)上给目标受众群组推送消息，操作步骤详情请参见[设置推送范围](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/msg-sending-android-0000001136294192#section7814456194918)。
