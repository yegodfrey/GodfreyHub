# 配置商品信息

若您使用IAP的PMS支付，则需要在AppGallery Connect中提前录入商品信息（包括商品ID、商品类型、不同国家的商品价格、商品名称等），在您的客户端调用购买接口时，只需传入此处配置的商品ID和商品类型，IAP会根据用户当前的帐号服务地展示对应国家/地区的商品信息（包括商品价格、商品名称等），而无需您自行管理商品价格。

* 如果新增非订阅类商品，请参见[非订阅类商品](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-create-product-0000001099854866#section10697151616123)。
* 如果为非订阅类商品设置促销价格，请参见[设置促销价格](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-modify-product-0000001146814541#section1658714562570)。
* 如果新增订阅类商品，请参见[订阅类商品](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-create-product-0000001099854866#section198483101318)。
* 如果为订阅类商品设置促销，请参见[设置促销价格](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-modify-product-0000001146814541#section12306131519586)。

> 注意
>
> 在AppGallery Connect完成商品配置后，AppGallery Connect不会跟随汇率实时刷新商品价格，您需要定期[手动刷新价格](https://developer.huawei.com/consumer/cn/doc/distribution/app/agc-help-modify-product-0000001146814541#section19520167327)，在商品的价格编辑页面点击刷新并保存，即可根据当时的汇率刷新商品价格。

在开发测试阶段，可以使用沙盒测试帐号来测试商品支付，测试帐号处于测试时间段内发起购买，华为应用内支付服务器会检测到该用户为测试帐号，直接支付成功，具体说明请参见[沙盒测试](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/sandbox-testing-0000001050035039)。
