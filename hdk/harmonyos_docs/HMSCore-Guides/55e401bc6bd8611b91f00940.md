# 导入证书指纹、修改包名、配置JDK编译版本

## 导入Keystore文件

将[创建应用的Keystore文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-certificate-guide-0000001530080540#section1222773391512)生成的Keystore文件导入到应用中。

1. 在菜单栏，单击"File > Project Structure..."

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/mXJDJr9VRhaKl95BErN8IQ/zh-cn_image_0000002516359354.png?HW-CC-KV=V1&HW-CC-Date=20260909T152728Z&HW-CC-Expire=31536000000&HW-CC-Sign=18DF109BDABEFF53766CAE5A953A8B194C516884AE343D2796E3A4809E29BBE2)

2. 在左侧列表单击"Modules"，选择"Signing Configs"，单击"Store File"栏的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/fOIZ8hq1TsuEgiNcLS7dGA/zh-cn_image_0000002547959149.png?HW-CC-KV=V1&HW-CC-Date=20260909T152728Z&HW-CC-Expire=31536000000&HW-CC-Sign=B11769F9AA606E2F6BCCFB1EEC7805A28DB70ECC10F50F293B4C56CA6856BA24)，选择D盘中的key.keystore文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/dMrDxW7mQ0O1Wq1_p3bOpQ/zh-cn_image_0000002516519272.png?HW-CC-KV=V1&HW-CC-Date=20260909T152728Z&HW-CC-Expire=31536000000&HW-CC-Sign=F37E493F3BD2C948A9258666E8D9FAB2A24C0DC8D7D1DDBB5D710D8AC01952A6 "点击放大")

3. 输入此前创建签名时设置的密码和别名，单击"OK"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/9SM8p9C1TfiW_WwnHYfRkA/zh-cn_image_0000002516359360.png?HW-CC-KV=V1&HW-CC-Date=20260909T152728Z&HW-CC-Expire=31536000000&HW-CC-Sign=1AE597CC8ABFA0E1C4BCCE9FD789F870AC721BD484D3AD2D6E397F782A561E5C "点击放大")

   导入后，打开应用级的"build.gradle"文件，可以看到导入的结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/JBazJV6CTC-jD2Xv4A-baw/zh-cn_image_0000002516359356.png?HW-CC-KV=V1&HW-CC-Date=20260909T152728Z&HW-CC-Expire=31536000000&HW-CC-Sign=4425258CC7AFCD2D76F13F8DB19504E4F7F4D075B51012EBB57A997B8A3D0363 "点击放大")

## 修改应用包名

如果您的应用包名与"[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)"中填写的包名不一致，请参见"[修改应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241#section18355123714179)"修改为一致。

## 配置JDK编译版本

1. 打开App下应用级根目录的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/WRdhTJh5SlWGKuXL-wY3pw/zh-cn_image_0000002516519266.png?HW-CC-KV=V1&HW-CC-Date=20260909T152728Z&HW-CC-Expire=31536000000&HW-CC-Sign=19426D6325EB57F2A7C3919E26FE3D365D59A78A4F2AC74B6459B0376C05D966 "点击放大")

2. 在**"** android**"**中新增compileOptions配置，配置格式如下：

   ```screen
   compileOptions {
       sourceCompatibility = '1.8'
       targetCompatibility = '1.8'
   }
   ```
