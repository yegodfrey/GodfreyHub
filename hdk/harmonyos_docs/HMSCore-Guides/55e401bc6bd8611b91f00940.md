# 导入证书指纹、修改包名、配置JDK编译版本

#### 导入Keystore文件

将[创建应用的Keystore文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-certificate-guide-0000001530080540#section1222773391512)生成的Keystore文件导入到应用中。

1. 在菜单栏，单击"File \> Project Structure..."

   <br />

   ![](https://media:901788166647881091)

   <br />

2. 在左侧列表单击"Modules"，选择"Signing Configs"，单击"Store File"栏的![](https://media:901788166647907092)，选择D盘中的key.keystore文件。

   <br />

   ![](https://media:901788166648019095 "点击放大")

   <br />

   <br />

3. 输入此前创建签名时设置的密码和别名，单击"OK"。

   <br />

   ![](https://media:901788166648091097 "点击放大")

   <br />

   导入后，打开应用级的"build.gradle"文件，可以看到导入的结果。

   <br />

   ![](https://media:901788166648127098 "点击放大")

   <br />

   <br />

#### 修改应用包名

如果您的应用包名与"[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)"中填写的包名不一致，请参见"[修改应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241#section18355123714179)"修改为一致。  

#### 配置JDK编译版本

1. 打开App下应用级根目录的"build.gradle"文件。

   <br />

   ![](https://media:901788166648210099 "点击放大")

   <br />

2. 在"android"中新增compileOptions配置，配置格式如下：

   <br />

   ```
   compileOptions {
       sourceCompatibility = '1.8'
       targetCompatibility = '1.8'
   }
   ```

   ![](https://media:901788166648253100)

   <br />
