# 导入证书指纹、修改包名、配置JDK编译版本

## 导入Keystore文件

将[创建应用的Keystore文件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-certificate-guide-0000001530080540#section1222773391512)生成的Keystore文件导入到应用中。

1. 在菜单栏，单击"File > Project Structure..."

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/63/v3/mXJDJr9VRhaKl95BErN8IQ/zh-cn_image_0000002516359354.png?HW-CC-KV=V1&HW-CC-Date=20261008T162647Z&HW-CC-Expire=31536000000&HW-CC-Sign=D7A45856E6C9E7BF40DE0BFF12C92D8D64779781573C64BE1CD9D462E379EE13)

2. 在左侧列表单击"Modules"，选择"Signing Configs"，单击"Store File"栏的![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/fOIZ8hq1TsuEgiNcLS7dGA/zh-cn_image_0000002547959149.png?HW-CC-KV=V1&HW-CC-Date=20261008T162647Z&HW-CC-Expire=31536000000&HW-CC-Sign=6E05228968666ABB1BDA28F1C3350112C8ADD8D67B4730D38F771423F17FC665)，选择D盘中的key.keystore文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/dMrDxW7mQ0O1Wq1_p3bOpQ/zh-cn_image_0000002516519272.png?HW-CC-KV=V1&HW-CC-Date=20261008T162647Z&HW-CC-Expire=31536000000&HW-CC-Sign=1CC1526E3A22AD94A4DC77658522254CE61B9E188DF31CC3313EBCE024668B40 "点击放大")

3. 输入此前创建签名时设置的密码和别名，单击"OK"。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/9SM8p9C1TfiW_WwnHYfRkA/zh-cn_image_0000002516359360.png?HW-CC-KV=V1&HW-CC-Date=20261008T162647Z&HW-CC-Expire=31536000000&HW-CC-Sign=D00E884FB80D28DD9AA0EE0A3ACEDC2D76D3974535EBA028321A33113290BF6E "点击放大")

   导入后，打开应用级的"build.gradle"文件，可以看到导入的结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fa/v3/JBazJV6CTC-jD2Xv4A-baw/zh-cn_image_0000002516359356.png?HW-CC-KV=V1&HW-CC-Date=20261008T162647Z&HW-CC-Expire=31536000000&HW-CC-Sign=A495A48647C2153C4554A5658E8F9A107346E0E07B0B50BDDB1D1220C8ADDCE2 "点击放大")

## 修改应用包名

如果您的应用包名与"[申请账号服务](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/apply-id-0000001050069756)"中填写的包名不一致，请参见"[修改应用包名](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/application-package-name-0000001580840241#section18355123714179)"修改为一致。

## 配置JDK编译版本

1. 打开App下应用级根目录的"build.gradle"文件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/WRdhTJh5SlWGKuXL-wY3pw/zh-cn_image_0000002516519266.png?HW-CC-KV=V1&HW-CC-Date=20261008T162647Z&HW-CC-Expire=31536000000&HW-CC-Sign=32AEE6B02AC337F96888F09D039242F96DD2A18F4B5B269E2B6ED0109376A5D8 "点击放大")

2. 在**"** android**"**中新增compileOptions配置，配置格式如下：

   ```screen
   compileOptions {
       sourceCompatibility = '1.8'
       targetCompatibility = '1.8'
   }
   ```
