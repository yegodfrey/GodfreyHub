# 瓦片图层

瓦片图层是显示在基础地图瓦片上方的图像集合。  

#### 添加瓦片图层

1. 创建[TileProvider](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-tileprovider-0000001206790328)对象并重写[getTile](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-tileprovider-0000001206790328#section44133551418)()方法以构造瓦片图层。

   <br />

   ```
   // 设置瓦片的大小为256*256
   int mTileSize = 256;
   PixelMap.InitializationOptions initializationOptions = new PixelMap.InitializationOptions();
   initializationOptions.size = new Size(mTileSize, mTileSize);
   initializationOptions.pixelFormat = PixelFormat.ARGB_8888;
   int[] colors = new int[mTileSize * mTileSize];
   Arrays.fill(colors, Color.BLUE.getValue());
   PixelMap pixelMap = PixelMap.create(colors, initializationOptions);
    
   ImagePacker imagePacker = ImagePacker.create();
   ByteArrayOutputStream byteArrayOutputStream = new ByteArrayOutputStream();
   imagePacker.initializePacking(byteArrayOutputStream, new ImagePacker.PackingOptions());
   imagePacker.addImage(pixelMap);
   imagePacker.finalizePacking();
   byte[] bytes = byteArrayOutputStream.toByteArray();

   // 创建TileProvider对象，以本地生成瓦片为例
   TileProvider mTileProvider = new TileProvider() {
       @Override
       public Tile getTile(int x, int y, int zoom) {
           return new Tile(mTileSize, mTileSize, bytes);
       }
   };
   ```

   <br />

2. 创建[TileOverlayOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-tileoverlayoptions-0000001207270268)对象来确定瓦片图层、透明度、透明度更改时淡入淡出动画等属性。

   <br />

   ```
   TileOverlayOptions options = new TileOverlayOptions().tileProvider(mTileProvider).transparency(0.5f).fadeIn(true);
   ```

   <br />

3. 通过[HuaweiMap](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582)对象的[addTileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-huaweimap-0000001101312582#section12241957204519)([TileOverlayOptions](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-tileoverlayoptions-0000001207270268))方法添加瓦片图层，如[图1](#ZH-CN_TOPIC_0000001251803923__fig35338534213)所示，该方法将返回该[TileOverlay](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-tileoverlay-0000001207110294)对象。

   <br />

   ```
   mTileOverlay = mHuaweiMap.addTileOverlay(options);
   ```

#### 修改瓦片图层

地图SDK支持在添加瓦片图层之后，修改已经设置的瓦片图层属性。

```
// 设置瓦片图层透明度
if (null != mTileOverlay) {
    mTileOverlay.setTransparency(0.3f);
}
 
// 关闭瓦片图层淡入动画
if (null != mTileOverlay) {
    mTileOverlay.setFadeIn(false);
}
 
// 设置瓦片图层不可见
if (null != mTileOverlay) {
    mTileOverlay.setVisible(false);
}
```

#### 移除瓦片图层

当不需要瓦片图层时，您可以调用以下方法移除图层。

```
if (null != mTileOverlay) {
    mTileOverlay.remove();
}
```

如果瓦片图层指示的图块变得"陈旧"，例如图块改变，您可以调用[clearTileCache](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/harmonyos-tileoverlay-0000001207110294#section1976495145817)()强制刷新，重新加载此瓦片图层上的所有图块。

```
if (null != mTileOverlay) {
    mTileOverlay.clearTileCache();
}
```
