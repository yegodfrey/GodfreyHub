# 概览

您可以通过控制地图手势开关以及内置UI控件的可见性，自定义用户与地图交互方式。参见[HarmonyOS示例代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Examples/sample-code-harmonyos-0000001149992195)工程中的[MapViewCameraDemo.java](https://github.com/HMS-Core/hms-mapkit-demo/blob/master/harmonyos/entry/src/main/java/com/huawei/harmony/hms/maps/demo/slice/MapViewCameraDemo.java)、[GestureDemo.java](https://github.com/HMS-Core/hms-mapkit-demo/blob/master/harmonyos/entry/src/main/java/com/huawei/harmony/hms/maps/demo/slice/GestureDemo.java)、[MapEventsDemo.java](https://github.com/HMS-Core/hms-mapkit-demo/blob/master/harmonyos/entry/src/main/java/com/huawei/harmony/hms/maps/demo/slice/MapEventsDemo.java)等文件。
