# 乳酸阈

随着运动负荷的增加，血液中乳酸浓度会逐渐上升。当运动强度达到某一特定负荷时，血乳酸浓度会急剧升高，急剧升高的转折点称为乳酸阈。转折点对应的心率称为乳酸阀心率，对应的速度称为乳酸阈配速。  

#### OAuth权限

联盟卡片申请的权限名称：锻炼记录 \> 锻炼记录详情数据

* 读权限：https://www.huawei.com/healthkit/activity.read
* 写权限：https://www.huawei.com/healthkit/activity.write  

#### 原子采样统计数据类型

* 名称：com.huawei.lactate_threshold

|字段|描述|类型|可选/必选|单位|取值范围|
|:-------|:----|:------|:----|:---|:------|
|lthrHr|乳酸阈心率|integer|O|次/分钟|(0，255)|
|lthrPace|乳酸阈配速|integer|O|秒/公里|-|
