# FAQ

## 如何验证是否适配成功？

集成好GameTurbo Engine后，请连接手机并打开adb调试功能。执行命令：

```screen
adb logcat --v time > log.txt
```

可以在log.txt中查看Kit log。Log打印的TAG为：Game Kit。

对于updateGameAppInfo API，Log中若打印出reportData message关键字，则下发成功。

例如：

```screen
4211  4234 I Game Kit : reportData message {"MessageType":3,"SceneID":1,"Description":"Game Start","ImportantLevel":"2","RecommendFps":60,"KeyThread":"render|10001|logic|6665|net|7170"}
```

## 设备上报信息能用来做什么？

设备上报的温度状态为高时，建议应用侧实行优化方案，比如降一档画质。不过，请注意设备温度反馈的频度，不建议反复调高调低画质。

此外，请注意降画质的方式。有些游戏在收到温度信息为高时，会弹框提示用户降低帧率或降低画质。 而根据用户反馈舆情，这个弹框体验并不好。

## 在开发中应该注意哪些事项？

1. 建议不要在主线程中调用GameTurbo Engine API。
2. updateGameAppInfo() API调用不能过于频繁。调用间隔需大于10ms，否则第二次调用会被过滤。
3. 调用updateGameAppInfo() API向设备发送消息时，每次调用只发送一个消息，不要多条消息合并发送。
4. 涉及开局的游戏，发送游戏开局消息时，一局开始/结束需要匹配。请特别验证如下几类场景：
   * 对局过程前后台切换，灭屏亮屏。
   * 网络断开重连。
   * 切换到后台比较长时间后，游戏回到主界面。

## GameTurbo Engine支持哪些开发环境？

支持Android Studio开发环境。

## GameTurbo Engine能力对手机开发环境的要求？

目前支持EMUI 10.1及以上版本。
