# 集成HMS Core SDK

在开发前，您需要将HMS Core SDK集成到您的开发环境中。  

#### 添加AppGallery Connect配置文件

如果在AppGallery Connect中开通了相关服务则需要将"agconnect-services.json"文件添加到您的App中。

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站，单击"开发与服务"。
2. 在项目列表中找到您的项目，在项目中单击需要集成HMS Core SDK的应用。
3. 在"项目设置 \> 常规"页面的"应用"区域，单击"agconnect-services.json"下载配置文件。

   <br />

   ![](https://media:901788166627417625)

   <br />

   <br />

4. 将"agconnect-services.json"文件拷贝到"entry"应用级根目录下。

   <br />

   ![](https://media:901788166627448626 "点击放大")  
   ![](https://media:901788166627478627)  
   如果您在"项目设置"模块进行过任何修改动作，包括但不限于：设置数据处理位置、开启或管理某些API等，您需要下载最新的"agconnect-services.json"，来替换HarmonyOS应用模块entry的根目录下已有的文件。

   <br />

#### 添加编译依赖

1. 打开项目级"build.gradle"文件，添加agconnect服务依赖。

   <br />

   ![](https://media:901788166627506628)

   ```
   buildscript { 
       dependencies { 
           // 添加agconnect服务依赖 
           classpath 'com.huawei.agconnect:agcp-harmony:1.3.0.300'
       } 
   } 
   ```

   <br />

2. 在"entry"目录下的"build.gradle"文件中添加agc插件配置和编译依赖。

   <br />

   ![](https://media:901788166627536629)
   1. 添加agcp插件配置。  
      在文件头部声明下一行添加如下配置。

      ```
      apply plugin: 'com.huawei.agconnect'
      ```

   2. 在"dependencies"中添加JSBridge SDK的编译依赖。JSBridge SDK用于JS API和HMS Core（APK）内的Health Service Kit保持通信。

      ```
      dependencies {
          implementation 'com.huawei.hms:jsb-ohos-adapter:5.3.0.303'
      }
      ```

   3. 在"dependencies"中添加agconnect的编译依赖。

      ```
      dependencies { 
          // agconnect依赖组件
          implementation 'com.huawei.agconnect:agconnect-core-harmony:1.3.0.300'
      }
      ```

   <br />

3. 在"entry/src/main/config.json"文件添加如下配置。

   <br />

   ```
   "deviceConfig": {
       "default": {
           "allowComponentsProxy": true
       }
   }
   ```

   ![](https://media:901788166627563630)  
   entry模块中config.json里bundleName和package名称必须相同。

   <br />

#### 下载HMS Core SDK

1. 执行CMD命令打开命令行工具，执行cd命令进入HarmonyOS应用"entry"目录。
2. 执行NPM命令下载Base SDK。

   <br />

   ```
   npm install @hw-hmscore/hms-js-base
   ```

   ![](https://media:901788166627588631)  
   * npm install @hw-hmscore/hms-js-base表示下载最新版本Base SDK，如需下载指定版本Base SDK，可使用npm install @hw-hmscore/hms-js-base@6.5.0-300。
   * 详细版本信息请参见Base SDK的[版本更新说明](https://www.npmjs.com/package/@hw-hmscore/hms-js-base/v/6.5.0-300?activeTab=versions)。  
   出现如下提示，说明下载成功：

   ```
   npm WARN testtest@1.0.0 No description
   npm WARN testtest@1.0.0 No repository field.

   + @hw-hmscore/hms-js-base@6.5.0-300
   added 1 package from 1 contributor in 1.192s
   ```

   <br />

3. 执行NPM命令下载Account SDK。

   <br />

   ```
   npm install @hmscore/hms-jsb-account
   ```

   ![](https://media:901788166627612632)  
   * npm install @hmscore/hms-jsb-account表示下载最新版本的Account SDK，如需下载指定版本Account SDK，可使用npm install @hmscore/hms-jsb-account@6.5.300。
   * 详细版本信息请参见Account SDK的[版本更新说明](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-js-update-history-0000001063670243)。

   <br />

<!-- -->

4. 执行NPM命令下载Health Service Kit JS SDK。

   <br />

   ```
   npm install @hw-hmscore/hms-js-health
   ```

   ![](https://media:901788166627647633)  
   * npm install @hw-hmscore/hms-js-health表示下载最新版本的HealthKit JS SDK，如需下载指定版本HealthKit JS SDK，可使用npm install @hw-hmscore/hms-js-health@6.9.300。
   * 详细版本信息请参见HealthKit JS SDK的[版本更新说明](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/harmonyos-version-change-history-0000001226601951)。

   <br />

5. 在"entry/src/main/config.json"的module节点增加如下属性配置。

   <br />

   其中"value"的值为开发者的OAuth 2.0客户端ID（在[AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)网站单击"开发与服务"，在项目列表中找到您的项目，在"项目设置 \> 常规"页面的"应用"区域获取"OAuth 2.0客户端ID（凭据）：Client ID"的值）。

   ```
   "metaData": {
         "customizeData": [
           {
             "name": "com.huawei.hms.client.appid",
             "value": "OAuth Client ID"  // 替换为OAuth 2.0客户端ID
           }
       ]
   }
   ```

   <br />

   <br />

#### 初始化模块

HarmonyOs应用使用HealthKit JS SDK，依赖JSBridge SDK提供通道，使得JS可以和HMS Core（APK）内部的Health Service Kit保持通信。因此在应用开发前，需要初始化[JSB](#section171215083312)。

1. 在entry\>src\>main\>java目录中的应用入口文件（默认为MyApplication）的onInitialize方法初始化JSB，在onEnd方法结束JSB模块的使用。

   <br />

   ```
   import com.huawei.hms.jsb.adapter.har.bridge.HmsBridge;
   import ohos.aafwk.ability.AbilityPackage;

   public class MyApplication extends AbilityPackage {
       private HmsBridge mHmsBridge;
       @Override
       public void onInitialize() {
           // 初始化JSB
           mHmsBridge = HmsBridge.getInstance();
           mHmsBridge.initBridge(this);
           super.onInitialize();
       }

       @Override
       public void onEnd() {
           // 结束JSB
           mHmsBridge.destoryBridge();
           super.onEnd();
       }
   }
   ```

   <br />

2. 在HarmonyOS应用"entry/src/main/js/default/app.js"文件中添加如下代码。

   <br />

   ```
   import {hmsjsb} from '@hw-hmscore/hms-js-base'
   export default {
       hmsData: {
           eventCallbackMap: {}
       },
       onCreate() {
           console.info('AceApplication onCreate');
           hmsjsb.init(this.hmsData.eventCallbackMap);
       },
       onDestroy() {
           console.info('AceApplication onDestroy');
       }
   }
   ```

   <br />

#### 同步工程

在完成以上的配置后，单击右上角"Sync Now"，完成"build.gradle"文件的同步，将相关依赖下载到本地。  
![](https://media:901788166627673634)  
如果出现错误，请检查网络连接是否正常，以及检查"build.gradle"文件是否正确。
