# 按Tag模板场景化示例

#### 网页可视化埋点

DTM支持iOS系统中的网页按Tag模板的可视化埋点。

                1. 在AGC侧选择“可视化埋点”页签，点击页面右上角的“按Tag模板埋点”按钮，系统跳转至Tag模板埋点页面。
                2. 在左侧“选择代码模板”页面，新建并选择Tag模板。在右侧的“添加埋点”页面，使用手机浏览器扫描二维码，根据提示打开手机网页，手机网页和DTM界面将会同时进入可视化埋点页面。
                3. 在DTM界面的可视化埋点页面右侧有“显示可圈选组件”开关，打开后会以红色框展示出可添加埋点的组件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/68/v3/IaQUzYKBTQO6RU36C3Imog/zh-cn_image_0000001104932248.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=67BEDC4B035FBC5A357995C415A26668AD8157B388E9E4972F88DE82088C5992)

                4. （可选）添加页面埋点。该“页面埋点”是针对进入App页面的埋点，只能添加一个。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/jRM05__fTymkEQg7TxJz1Q/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=8FB2DA5E962A28C8C721A6DCE14CBAB0983820419D4ADBFEEC41820A3D703561)

当进入含WebView的App页面时，可以添加页面埋点，其参数只能选择native组件。

                   1. 点击“页面埋点”页签下的“添加埋点”，在弹出的“添加埋点”输入框中填入埋点名称，点击“确定”添加埋点。
                   2. 添加成功后，会在页面右侧的“页面埋点”页签下展示已添加的埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/95/v3/7UVAUW9FQ0-enJPj1GU0Xw/zh-cn_image_0000001151492259.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=20AA029566AAE07786FE08FBC826DFB898907922BBEDF806238DD49358E32404)

                5. 添加元素埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/jXA_5HUIQCWbYZo5rhMyhA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=2A0CD7E971BC79FB25B8FA77A1F90834E0210039DA1EEE9CDA1E4581535703E2)

当进入含WebView的App页面时，若您添加native组件作为元素埋点，只能选择native组件作为参数，不可选择WebView元素；若您添加WebView元素作为元素埋点，只能选择WebView元素作为参数，不可选择native组件。

                   1. 点击可埋点元素，在弹出的“添加埋点”提示框中设置埋点类型，并点击“确定”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/14/v3/xhHUkSyzQ32mDBHr54urZg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=CC635F8D1A9B0076FBA236B7C91BFC14B4CC8A02D0D8AA9CEC86B0F06C6EF667)

WebView埋点可选类型有“当前位置”和“同类元素”。

                      * 当前位置：只对当前位置的元素有效。
                      * 同类元素：即选中元素的某一个就近的父节点内，存在结构、ID或类名一致的元素。适用于列表类的同类元素。例如商品列表等，点击列表中的任何一个同类元素都会触发该埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a9/v3/BlL5jYEMRi6nvAvnSr_Mgg/zh-cn_image_0000001087426462.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=DC1167F4844085AD7E42574D6D5BB5506CA358949896D258D2C5A357C150FE96)

                   2. 设置“埋点名称”、“参数”及“触发事件”，单击“确定”完成埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/fj1OAnZsQOGI1ynhUo7B6g/zh-cn_image_0000001087266700.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=16368FC05F748B8F3FD180B65F4645509BD9991926DB5387444BB04BBA71E560)

                6. （可选）对于已添加的埋点，您可以根据需要，通过埋点名称后面的按钮，进行预览、编辑、删除、添加参数及查看详情等相关操作。

通过点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/93/v3/y_bMTuR6QvawARz4uxrUvg/zh-cn_image_0000001091499848.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=A0B81AE5144E5624CC41D149BDE717EBE2AF4ED0B71325614C7D1FCD7531FDBD)按钮，您可以修改埋点名称，但不能修改埋点类型。点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f0/v3/Tg_j9qh-SlGym63VVIayDw/zh-cn_image_0000001091371494.png?HW-CC-KV=V1&HW-CC-Date=20261005T043049Z&HW-CC-Expire=86400&HW-CC-Sign=F49E1AED61B9968EC71CB22E1BC0F98AC6F21ACD790F65AB90D4557EF9A0E9BE)按钮，可以为当前埋点添加参数。
