# 横幅广告

横幅广告又名Banner广告，横幅广告是在应用程序顶部、中部或底部占据一个位置的矩形图片，广告内容每隔一段时间会自动刷新，点击内容时会跳转到广告主的页面。

![](https://media:201785910043841822 "点击放大")  

#### 添加横幅广告

横幅广告可以通过编程方式和组件方式添加。  

#### 编程方式

通过调用鲸鸿动能JavaScript API接口，请求展示广告。

1. 通过[ppsads.createBannerAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-createbannerad-0000001179593165)创建广告对象。

   ```
   <div id="banner-container"></div>
   <script>
       const bannerContainer = document.getElementById("banner-container");      
       // 创建Banner广告对象
       window.ppsads.ready(() => {    
           const bannerAd = window.ppsads.createBannerAd({      
               slotId: "testw6vs28auh3",
               width: "360",
               height: "57",  
               container: bannerContainer,    
           }); 
       });
   </script>
   ```

2. 调用[BannerAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263).[load()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263#section413617383419)加载广告。

   ```
   bannerAd.load();
   ```

   * 成功执行[BannerAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263).[onLoad(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263#section413617383419)回调：

     ```
     bannerAd.onLoad(() => {});
     ```

   * 失败执行[BannerAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263).[onError(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263#section413617383419)回调：

     ```
     bannerAd.onError((errorCode) => {});
     ```

     ![](https://media:201785910043876823)  
     errorCode详情请参见[JavaScript错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/error-code-0000001133633596)。
3. 当应用页面销毁时，调用[BannerAd](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263).[destroy()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/bannerad-0000001179473263#section413617383419)销毁横幅广告。

   ```
   bannerAd.destroy();
   ```

#### 组件方式

鲸鸿动能JavaScript API提供Banner容器组件。

1. 通过[AdsBanner](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsbanner-0000001179593169)容器组件创建广告对象。

   ```
   <ads-banner id="banner-view" slot-id="testw6vs28auh3" width="320" height="50" />
   ```

2. 调用[AdsBanner](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsbanner-0000001179593169).[load()](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsbanner-0000001179593169#section5614359137)加载广告。

   ```
   <script>
       const bannerView = document.getElementById("banner-view");    
       // 广告加载
       bannerView.load();
   </script>
   ```

   * 成功执行[AdsBanner](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsbanner-0000001179593169).[onAdLoad(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsbanner-0000001179593169#section5614359137)回调：

     ```
     bannerView.onLoad((adlist) => {})
     ```

   * 失败执行[AdsBanner](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsbanner-0000001179593169).[onAdError(callback)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adsbanner-0000001179593169#section5614359137)回调：

     ```
     bannerView.onError((errorCode) => {})
     ```

     ![](https://media:201785910043901824)  
errorCode详情请参见[JavaScript错误码](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/error-code-0000001133633596)。  

#### 常用广告尺寸

常用的标准横幅广告尺寸宽高对应关系如下表所示：  

|宽（px）|高（px）|说明|
|:----|:----|:-------|
|320|50|普通横幅广告。|
|320|100|大型横幅广告。|
|300|250|中矩形横幅广告。|
|360|57|普通横幅广告。|
|360|144|大型横幅广告。|

![](https://media:201785910043937825)  
在中国大陆区域暂只支持360\*57px和360\*144px。

更多广告尺寸请参见API文档中的[ppsads.createBannerAd(object)](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ppsads-createbannerad-0000001179593165#section455613917416)类。  

#### Smart Banner广告

Smart Banner是一种不拘泥于屏幕尺寸、屏幕方向，可在设备上展示与屏幕等宽的横幅广告。加载广告时鲸鸿动能JavaScript API会根据当前设备屏幕方向，创建与屏幕等宽的广告视图，而广告高度是根据当前屏幕方向的高度来决定。Smart Banner可实现三种广告高度：  

|广告高度|屏幕高度|设备|
|:---|:-----------------|:----------|
|32px|≤ 400px|手机，横屏显示。|
|50px|\> 400px 且 ≤ 720px|手机，竖屏显示。|
|90px|\> 720px|平板，横屏或竖屏显示。|

当广告图片素材不足以占据所分配的整个空间时，系统会居中放置图片，然后填充剩余的空间。

![](https://media:201785910043989826 "点击放大")  
![](https://media:201785910044086827)  
* Smart Banner广告在中国大陆区域暂未支持，中国大陆区域的用户不会收到Smart Banner广告。
* 注册地为中国大陆的出海开发者，暂时不建议使用Smart Banner功能。  

#### 测试横幅广告

测试横幅广告时，需要使用专门的测试广告位ID来获取测试广告，以避免在测试过程中产生无效的广告点击量。测试广告位ID仅作为功能调试使用，不可用于广告变现。您应在应用发布前先进入[流量变现官网](https://developer.huawei.com/consumer/cn/monetize)，点击"开始变现"，登录[鲸鸿动能媒体服务平台](https://developer.huawei.com/consumer/cn/service/ads/publisher/html/index.html?lang=zh)，申请正式的广告位ID并替换测试广告位ID，具体操作详情请参见[展示位创建](https://developer.huawei.com/consumer/cn/doc/distribution/monetize/zhanshiweichuangjian-0000001132700049)。

以下表格中提供了横幅广告的专用测试广告位ID：  

|广告形式|展示形式|测试广告位ID|

|Banner|纯图|testw6vs28auh3|
