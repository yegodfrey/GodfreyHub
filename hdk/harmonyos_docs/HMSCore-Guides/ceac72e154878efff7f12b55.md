# API列表

商户进件API列表  

|功能列表|描述|
|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|[子商户入网](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-register-submerc-0000001642382965#section95771727125814)|服务商通过此接口提交子商家材料添加子商户入网。|
|[创建子商户入网邀请链接](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-invite-register-0000002532657540)|服务商可以通过调用此接口创建子商户入网邀请链接。|
|[子商户入网撤销](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-submerc-cancel-0000002505847543)|服务商可以调用此接口撤销子商户入网申请。|
|[冻结子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-freeze-submerc-0000001593101828#section95771727125814)|服务商调用此接口冻结指定的子商户。|
|[解冻子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-ufreeze-submerc-0000001592624240#section95771727125814)|服务商调用此接口解冻指定的子商户。|
|[注销子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-delete-submerc-0000001592782432#section95771727125814)|服务商调用此接口注销指定的子商户。|
|[商户电子流查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-flow-0000001592942152#section95771727125814)|服务商通过子商户号、流程ID或者业务类型查看该商户下的流程进度，如：子商户入网审批进度、子商户冻结审批进度等。|
|[子商户进件状态查询](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-mgmt-submerc-query-0000002084858325)|服务商通过子商户号、流程ID查询该商户下子商户进件流程进度的状态信息。|
|[审核结果回调](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-notify-result-0000001642224233#section10267412717)|华为支付服务器调用[添加分账白名单](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-alloc-receivers-add-0000001639876341#section95771727125814)、[子商户入网](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-register-submerc-0000001642382965#section95771727125814)、[冻结子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-freeze-submerc-0000001593101828#section95771727125814)、[解冻子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-ufreeze-submerc-0000001592624240#section95771727125814)、[注销子商户](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-partner-merc-manage-delete-submerc-0000001592782432#section95771727125814)接口传入的callbackUrl向开发者服务器发送相关的审核结果事件。|
