# 基于上下文信息请求广告

鲸鸿动能平台投放的广告支持个性化广告和非个性化广告。非个性化广告是不基于用户过去行为的广告，使用上下文信息进行定向。上下文信息包括基于当前位置的粗略（例如城市级别）地理定位，以及当前应用程序的内容或当前应用搜索关键字上的内容。

鲸鸿动能SDK在[AdParam.Builder](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-builder-0000001050066829)类中提供了[setContentBundle](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/adparam-builder-0000001050066829#section12974114318016)方法，供您在广告请求时设置携带上下文信息。若您要使用该功能，请先集成HUAWEI鲸鸿动能，详情请参见[集成HMS Core SDK](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/publisher-service-integrating-sdk-0000001050066913)。

示例代码如下所示：

```screen
"Java"
rewardAd = new RewardAd(this, rewardId);
AdParam.Builder adParam = new AdParam.Builder();
String mediaContent = "{\"channelCategoryCode\":[\"剧集\"],\"title\":[\"西游记\"],\"tags\":[\"神魔\",\"冒险\"],\"relatedPeople\":[\"张三\"],\"content\":[\"该剧讲述了师徒四人西天取经......\"],\"contentID\":[\"123123\"],\"category\":[\"经典剧场\"],\"subcategory\":[\"古装\"],\"thirdCategory\":[\"悬疑\"]}\n";
adParam.setContentBundle(mediaContent);
RewardAdLoadListener rewardAdLoadListener = new RewardAdLoadListener(){
    @Override
    public void onRewardAdFailedToLoad(int errorCode) {
        // 广告请求失败处理流程
    }
    @Override
    public void onRewardedLoaded() {
        // 广告请求成功处理流程
    }
};
rewardAd.loadAd(adParam.build(),rewardAdLoadListener);
```
