# 地图类型

[HMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmapview-0000001191938980)目前支持三种地图类型：

* HMapTypeNormal：标准地图。展示道路、建筑物以及河流等重要的自然特征。
* HMapTypeNone：空地图。没有加载任何数据的地图。
* HMapTypeTerrain：地形图。

![](https://media:301772613538560106)  
地形图使用限制：支持iOS 11.0及以上版本。

设置地图类型，请调用[HMapView](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/ios-hmapview-0000001191938980)对象的setMapType方法。

```
// 设置标准地图类型
[self.mapView setMapType:HMapTypeNormal];
```
