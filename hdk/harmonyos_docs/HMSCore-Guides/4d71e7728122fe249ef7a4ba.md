# 业务介绍

#### 业务简介

天气服务（Weather Kit）融合多家行业TOP供应商，提供专业、精准、稳定的数据服务以及量身定制的行业解决方案，帮助开发者为用户提供更贴心的本地生活服务，支撑行业客户防灾减灾、降本增效。

      * 基础类天气数据：提供天气类、空气类、生活地理类天气数据。
      * 专业类天气数据（即将发布）：提供高分辨率类、海洋天气类、气象图层类数据。
      * 行业解决方案（即将发布）：为气象敏感型行业用户量身定制解决方案。

#### REST API

天气服务REST API提供HTTPS接口，您可以通过HTTPS形式发起请求，调用基础类天气数据、专业类天气数据。

#### 功能限制

通过天气服务获取的国内气象数据，只支持在中华人民共和国境内存储、使用，不能传输至海外。
