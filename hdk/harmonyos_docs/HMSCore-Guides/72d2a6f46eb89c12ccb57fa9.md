# 消息发送方案

## 概要

为了保障即时聊天、音视频通话、订单等服务通讯类消息能够更快到达用户设备，华为推送根据消息分类情况，对消息进行了发送加快处理，具体方案如下：

|消息一级分类|**消息详细类型**|发送管理|
|:------|:---------------------------------------------------------|:---|
|服务与通讯消息|即时聊天，音视频通道，订阅，出行，健康，工作事项提醒，帐号动态，订单&物流，财务，设备提醒，系统提示，邮件，语音播报|加快发送|
|资讯营销消息|内容推荐、新闻、财经动态、生活资讯、社交动态、调研、产品促销、功能推荐、运营活动|正常发送|

> 说明
>
> 加快发送的消息，比正常发送的消息平均时延小。

## 发送管理调用方案

首先，您需要获取消息自分类权限，具体请参见[自分类权益申请](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/message-classification-0000001149358835#section3410731125514)。

获取消息自分类权限后，您需要按照下表，根据申请消息类别，调整消息报文中[category](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5203378238)字段的传值。当[category](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5203378238)传值为空或者其他无效值时，消息将不会加快发送。

|消息一级分类|消息类型|接口传值（所有字母大写）|
|:-----|:----------------------------------------------------------|:--------------|
|服务与通讯类|即时聊天|IM|
|服务与通讯类|音视频通话|VOIP|
|服务与通讯类|订阅|SUBSCRIPTION|
|服务与通讯类|出行|TRAVEL|
|服务与通讯类|健康|HEALTH|
|服务与通讯类|工作事项提醒|WORK|
|服务与通讯类|帐号动态|ACCOUNT|
|服务与通讯类|订单&物流|EXPRESS|
|服务与通讯类|财务|FINANCE|
|服务与通讯类|设备提醒|DEVICE_REMINDER|
|服务与通讯类|系统提示|SYSTEM_REMINDER|
|服务与通讯类|邮件|MAIL|
|服务与通讯类|语音播报（仅透传消息支持）|PLAY_VOICE|
|资讯营销类|内容推荐、新闻、财经动态、生活资讯、社交动态、调研、产品促销、功能推荐、运营活动（仅对内容进行标识，不会加快消息发送）|MARKETING|

> 说明
>
> * 服务通讯类消息加快发送，仅依赖自分类权限申请。没有自分类权限，消息将不会加快发送。您在自分类申请审批通过后，根据申请消息内容类别在[category](https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-send-api-0000001050986197#ZH-CN_TOPIC_0000001700731289__p5203378238)字段传入对应传值即可。
> * 消息加快发送能力，适用于通知栏消息和透传消息。
> * 若发现应用有违规分类的场景，将根据规范管理，暂停或取消自分类权益，同时应用的服务通讯类消息将不再加快发送。请确保您分类的结果满足规范要求。
