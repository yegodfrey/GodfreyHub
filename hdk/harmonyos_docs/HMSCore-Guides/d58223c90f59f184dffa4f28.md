# 版本更新说明

## 6.13.0.300（2023-09-10）

|-------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:6.13.0.300 **修改特性** 适配Android 14系统，targetSdkVersion升级到34。|

## SDK依赖说明

最新版本SDK需要用户手机上安装HMS Core（APK）4.0.0.300及以上版本。

温馨提示：如果您在集成SDK或上架应用到华为应用市场时遇到问题，可以[在线提单](https://developer.huawei.com/consumer/cn/support/feedback/#/)。

## 历史版本

### 6.4.0.302（2022-09-19）

|------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:6.4.0.302 **修改特性** 适配Android 13系统，targetSdkVersion升级到33。|

### 6.4.0.301（2022-03-30）

|----------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:6.4.0.301 **修改特性** 优化HMS Core（APK）引导下载的能力。|

### 6.2.0.300（2021-11-01）

|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:6.2.0.300 **修改特性** 预置<queries>配置，以实现您的应用在Android11上运行时，正常调用HMS Core（APK）。您的开发环境必须满足[Android Studio](https://developer.android.com/studio) 3.6.1及以上版本、[Android Gradle插件](https://developer.android.com/studio/releases/gradle-plugin) 3.5.4及以上。|

### 5.3.0.300（2021-05-14）

|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:5.3.0.300 **新增特性** [UserAddress](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/useraddress-0000001050051846)类中增加[getCountryISOCode](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/useraddress-0000001050051846#section853913531552)方法，您可通过该接口获取对应地址的国家码，用于区分国家信息。|

### 5.1.0.300（2020-12-29）

|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:5.1.0.300 **修改特性** 增加Kotlin版本示例代码。具体请参见[示例代码](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Examples/android-sample-code-0000001050038478)。|

### 4.0.4.300（2020-05-30）

|-------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:4.0.4.300 **修改特性** 修复在某些非华为手机上无法拉起服务问题。|

### 4.0.1.300（2020-01-21）

|--------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:4.0.1.300 **新增特性** 增加Eclipse依赖包，使用Eclipse开发环境的您可通过集成此包来使用用户身份服务。|

### 4.0.0.300（2020-01-15）

|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|Android版本：com.huawei.hms:identity:4.0.0.300 华为推出了全新的HMS Core Identity SDK 4.0.0版本，该SDK中用户身份服务是首次发布，包含地址查询、管理特性，欢迎广大开发者接入。 **新增特性** Identity提供了地址查询接口，您仅需三步即可获取用户地址并解析。 * 使用new [UserAddressRequest](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/useraddressrequest-0000001050053779)实例化请求对象，调用[getUserAddress](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/addressclient-0000001050053765#section1627114915257)接口。 * 调用[Status](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/status-0000001050121132)的[startResolutionForResult](https://developer.huawei.com/consumer/cn/doc/development/hmscore-common-References/status-0000001050121132#section04641751152411)方法拉起选择用户身份服务的地址选择页面。 * 用户选择地址完成后在页面的onActivityResult中调用[UserAddress](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/useraddress-0000001050051846)的[parseIntent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/useraddress-0000001050051846#section27231755102913)方法从结果中获取用户选择的地址信息。|
