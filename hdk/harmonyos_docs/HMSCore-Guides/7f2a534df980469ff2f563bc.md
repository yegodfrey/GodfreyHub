# 接入Analytics

分析服务提供基于您上报事件的分析数据模型。

分析数据模型采用了Event-Param-User模型来记录数据，通过不同的参数对事件进行描述，同时对用户的特征也进行了描述。

术语 | 名称 | 说明  
---|---|---  
Event | 事件 | 描述一个用户在某个时间点、某个地方、以某种方式完成了某个具体的事情。包含who、when、where、how、what等关键要素。  
Param | 参数 | 事件上报的关联参数。如加入购物车事件中的商品名称参数和商品价格参数，支持后续的深入分析。  
UserProfiles | 用户属性 | 用户的属性表，常见的用户属性有设备型号、应用版本、自定义的用户属性（如食品偏好）等。  
  
Analytics Kit会收集AAID。AAID是应用匿名标识符，每个App在同一个设备上会分配不同的AAID。AAID用于连通华为提供的各项服务，例如Push、分析服务和远程配置等。

AAID会在如下场景重置：

      * 用户卸载后重装应用。 
      * 用户恢复出厂设置。 
      * 用户清除应用数据。 
      * 应用主动调用[clearCachedData](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477#section7238134312)接口。 

#### 接入步骤

      1. 初始化Analytics SDK。

SDK通过[getInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-0000001123080524#section4210134665720)接口根据配置完成初始化。
             
             HiAnalyticsInstance instance = HiAnalytics.getInstance(ability);

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115309.40704834677809834432932715983188:50001231000000:2800:573AB2DE4AD0D32BAD27F23FB7E4A60EFEE503EBADF6BA8C97BD19A5235F6D69.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

         * SDK初始化时会发送网络请求，请您务必在用户同意隐私协议后再初始化SDK。 
         * 必须在MainAbility的onStart中初始化Analytics SDK，否则会导致生命周期相关事件采集不准确。 

      2. （可选）设置上报策略。

Analytics SDK提供了四种事件上报策略，支持多种策略自由组合，任何一种策略满足时即可触发事件上报。您可以根据场景选择合适的事件上报策略。

如果设置上报策略，建议包含应用切后台上报策略，防止应用退出后部分事件缓存在本地不能及时上报。

策略 | 描述 | 说明  
---|---|---  
ON_APP_LAUNCH_POLICY | 应用启动上报策略 | 应用启动时上报事件。选择该策略时会立即上报一次，此后每次应用启动时上报一次。  
ON_MOVE_BACKGROUND_POLICY | 应用切后台上报策略 | 应用切后台时上报事件，包括应用退出。  
ON_SCHEDULED_TIME_POLICY | 定时上报策略 | 根据指定的间隔时间上报事件，取值范围为【60-1800】秒（默认60秒），如果设置的值超过给定范围则取边界值。  
ON_CACHE_THRESHOLD_POLICY | 阈值上报策略 | 缓存事件条数达到阈值时上报事件，取值范围为【30-1000】条（默认30条），如果设置的值超过给定范围则取边界值。  
  
![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115309.15304007622790089082231138230303:50001231000000:2800:21676A347DF0368EA092CD632FC38BF46D0286DF1090FA713D5164111D008E9F.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

         * 以上上报策略仅在非调试模式下生效。上报策略持久化保存。 
         * 应用切后台上报策略和阈值上报策略为必选策略，无论设置什么策略，这两个策略都会生效，但是可以改变阈值上报策略的阈值。 
         * 多次调用设置上报策略的接口，会刷新上报策略，仅最后一次设置的策略生效，请谨慎多次调用。 
         * 当策略满足触发事件上报时，如果没有网络，则会将事件缓存在本地，等待下次条件满足继续上报。 

      3. 通过[onEvent](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477#section15204518184114)接口记录定义事件。

事件的定义请参见[自动采集事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-automatic-event-collection-0000001123074896)、[预置事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-events-general-0000001242440785)、[自定义事件](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-custom-events-0000001169634747)。

      4. 请参见[ _API参考_](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-analytics-overview-0000001169640369)，调用接口实现各类功能。例如：设置用户属性[setUserProfile](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477#section096353619188)。

#### 示例代码

      1. “agconnect-services.json”文件导入成功后，在第一个Ability的onStart初始化Analytics SDK，获得[HiAnalyticsInstance](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-References/harmonyos-api-hianalytics-instance-0000001169520477)实例。

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115310.04399065733445087535214529159528:50001231000000:2800:D25D90DC9DBA378AC4CDC1C758781548F13B1CF76EFBA0DA8A7E646BE9D10F2A.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

若“agconnect-services.json”文件不正确，则无法进行埋点。导入“agconnect-services.json”文件请参见[集成SDK](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/harmonyos-integrating-sdk-0000001122915056)。
             
             @Override   
             public void onStart(Intent intent) { 
                 super.onStart(intent); 
                 super.setMainRoute(MainAbilitySlice.class.getName()); 
                 // 打开SDK日志开关   
                 HiAnalyticsTools.enableLog(); 
                 HiAnalyticsInstance instance = HiAnalytics.getInstance(this); 
                 // （可选）设置用户属性
                 instance.setUserProfile("userKey","value");  
             }

      2. （可选）设置应用切后台上报策略和定时上报策略。
             
             // 创建应用切后台上报策略 
             HAReportPolicy moveBackgroundPolicy = HAReportPolicy.ON_MOVE_BACKGROUND_POLICY; 
             // 创建定时上报策略 
             HAReportPolicy scheduledTimePolicy = HAReportPolicy.ON_SCHEDULED_TIME_POLICY; 
             // 设置定时上报时间周期为600秒 
             scheduledTimePolicy.setThreshold(600); 
             Set<HAReportPolicy> reportPolicies = new HashSet<>(); 
             // 添加定时上报策略和应用切后台上报策略 
             reportPolicies.add(scheduledTimePolicy); 
             reportPolicies.add(moveBackgroundPolicy); 
             // 设置应用切后台上报策略和定时上报策略 
             instance.setReportPolicies(reportPolicies);

      3. 在代码合适位置插入埋点代码。
             
             // 自定义埋点，在工程合适位置插入埋点代码  
             PacMap pacMap = new PacMap();  
             pacMap.putString("exam_difficulty", "high");  
             pacMap.putString("exam_level", "1-1");  
             pacMap.putString("exam_time", "20190520-08");  
             instance.onEvent("begin_examination", pacMap);  
             // 预置事件埋点  
             PacMap pacMapPre = new PacMap();  
             pacMapPre.putString(HAParamType.PRODUCTID, "item_ID");  
             pacMapPre.putString(HAParamType.PRODUCTNAME, "name");  
             pacMapPre.putString(HAParamType.CATEGORY, "category");  
             pacMapPre.putLongValue(HAParamType.QUANTITY, 100L);  
             pacMapPre.putDoubleValue(HAParamType.PRICE, 10.01);  
             pacMapPre.putDoubleValue(HAParamType.REVENUE, 10);  
             pacMapPre.putString(HAParamType.CURRNAME, "currency");  
             pacMapPre.putString(HAParamType.PLACEID, "location_ID");  
             instance.onEvent(HAEventType.ADDPRODUCT2WISHLIST, pacMapPre);

#### 接入调试

在开发过程中可以启用调试模式，实时查看事件的记录情况，观察具体结果并根据需要进行调整。

#### [h2]开启/停用调试模式

      * 开启调试模式： 
        1. 执行如下hdc命令，调试模式打开后，所有事件将实时上报，在应用调试界面可实时查看上报的数据。 

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115310.56411074249129599001897299674563:50001231000000:2800:B497DD7E1EBBC4C7F988B66EC2B96028D2A2B21DBBA901A183A9C1945A1B89AD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

请将命令行中的<package_name>字段替换为您的应用包名。
               
               hdc shell setprop debug.huawei.hms.analytics.hap _< package_name>_

        2. 数据成功上报后，“华为分析 > 应用调试”页面会展示出数据，如下图：

![](https://communityfile-drcn.op.dbankcloud.cn/FileServer/getFile/cmtyPub/011/111/111/0000000000011111111.20230926115310.77476095770242515807411270854476:50001231000000:2800:95952D103518539736DB1DA761B15E79318BD2476EE43FF071D86BF80700A6AD.png?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true?needInitFileName=true)

        3. 在AGC系统上查看数据，请参见[应用调试](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/app-debugging-0000001051799712)。 
      * 停用调试模式： 

执行如下hdc命令，将停用调试模式。 
            
            hdc shell setprop debug.huawei.hms.analytics.hap .none.
