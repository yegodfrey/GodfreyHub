# 提交测试报告进行准入认证

1. 登录华为开发者联盟，在"智慧生活"下点击"运动健康（设备接入）"，查看素材资源审核结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/kJWe4DbtSJSCYdfHWMzdLw/zh-cn_image_0000001453324330.png?HW-CC-KV=V1&HW-CC-Date=20260909T163032Z&HW-CC-Expire=31536000000&HW-CC-Sign=BBDFB2B2E7D6284D70108CF47124730D85D35A4E6CEDA79A7548EDA0F5BC11E2 "点击放大")

2. 若素材资源审核通过，点击"产品认证"进入认证报告提交界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/U3fP7uYaRLK4Hrd1JKhkNg/zh-cn_image_0000001502884361.png?HW-CC-KV=V1&HW-CC-Date=20260909T163032Z&HW-CC-Expire=31536000000&HW-CC-Sign=FA71D1A09E455BF0910A09DF4FCCC645D997D86F6ED261AA3D97DE554E69449A "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/BXr8KStSSuea6i3vXTYxQA/zh-cn_image_0000001503004037.png?HW-CC-KV=V1&HW-CC-Date=20260909T163032Z&HW-CC-Expire=31536000000&HW-CC-Sign=42C64DAF4CF6083C79F63B3774ACFACA50F2F1455C1A14E9D90103147C03BA4F "点击放大")

3. 根据界面提示，上传设备实物拍照图（正面、侧面、底部）、自测试报告、样机快递单号。

   > 说明
   >
   > 自测试报告需要提供送测设备的基本信息，如：产品型号、产品版本、芯海SDK版本、蓝牙芯片、称重芯片、测脂芯片、产品固件版本、产品硬件版本等。具体可以参考华为提供的测试报告模板。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/MTpf_6sTSOemyYDXbLs_Bw/zh-cn_image_0000001453324334.png?HW-CC-KV=V1&HW-CC-Date=20260909T163032Z&HW-CC-Expire=31536000000&HW-CC-Sign=F8496831B71E4651CDE5D1F42446A6D904722C35D95A3C00531772B8B3393B90 "点击放大")

   样机需求如下表，点击"样机寄送地址"旁边的提示符![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/yF5CcxWeQGO8RXNzEEbNyw/zh-cn_image_0000001453484262.png?HW-CC-KV=V1&HW-CC-Date=20260909T163032Z&HW-CC-Expire=31536000000&HW-CC-Sign=9C7FE3F44AC1FCEACC74E2831CB26C6BCED797FF5349C2782FEA6A5FD9BAB4F5)，可以获取投递地址及收件人。

   |样机用途|数量|
   |:--------------------------|:-|
   |小件设备，如：跳绳、体脂秤、血糖仪、血压计、心率设备|2|
   |大件设备，如：跑步机、椭圆机、划船机、智能单车、走步机|1|

   对于跑步机接入，需要提交第三方认证机构进行准入认证。在界面上选择认证机构后（赛西实验室或泰尔实验室），会显示认证机构的联系方式及报价单，可与对应机构联系人进行业务对接。请厂商根据实际需要选定认证机构。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/AnUBE98ETVedhTriR_-jcA/zh-cn_image_0000001453164582.png?HW-CC-KV=V1&HW-CC-Date=20260909T163032Z&HW-CC-Expire=31536000000&HW-CC-Sign=25EA6ED1965E1D3CC03F21F58CB3391CD5E702454CF672864771744B235405FB "点击放大")

4. 提交审核后，等待认证结果。点击图示红框图标可查看审核进度和结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/vaXdj09hSFu7Sg6VXLr0-g/zh-cn_image_0000001502884353.png?HW-CC-KV=V1&HW-CC-Date=20260909T163032Z&HW-CC-Expire=31536000000&HW-CC-Sign=EC1DC5D0C2DEC7F03233F3A38730D67500C8620D69427274DCE1FC57DC251AB8 "点击放大")
