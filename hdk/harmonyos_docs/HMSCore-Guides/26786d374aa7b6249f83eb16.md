# 提交测试报告进行准入认证

1. 登录华为开发者联盟，在"智慧生活"下点击"运动健康（设备接入）"，查看素材资源审核结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/kJWe4DbtSJSCYdfHWMzdLw/zh-cn_image_0000001453324330.png?HW-CC-KV=V1&HW-CC-Date=20261008T172858Z&HW-CC-Expire=31536000000&HW-CC-Sign=1612D31A12AC8781509837868ECBEED2FAE285EBF771316423079E20EF7EFA7D "点击放大")

2. 若素材资源审核通过，点击"产品认证"进入认证报告提交界面。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/U3fP7uYaRLK4Hrd1JKhkNg/zh-cn_image_0000001502884361.png?HW-CC-KV=V1&HW-CC-Date=20261008T172858Z&HW-CC-Expire=31536000000&HW-CC-Sign=5FB6835305CB22FEF5D45737E2DFD06E9079567DBC9B83FBC66FDB86157CD54C "点击放大")

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/BXr8KStSSuea6i3vXTYxQA/zh-cn_image_0000001503004037.png?HW-CC-KV=V1&HW-CC-Date=20261008T172858Z&HW-CC-Expire=31536000000&HW-CC-Sign=A7409EE3E5B102D0B9D143049222E7D134CFCF37D76275A7DA86BB07EF134BFF "点击放大")

3. 根据界面提示，上传设备实物拍照图（正面、侧面、底部）、自测试报告、样机快递单号。

   > 说明
   >
   > 自测试报告需要提供送测设备的基本信息，如：产品型号、产品版本、芯海SDK版本、蓝牙芯片、称重芯片、测脂芯片、产品固件版本、产品硬件版本等。具体可以参考华为提供的测试报告模板。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/58/v3/MTpf_6sTSOemyYDXbLs_Bw/zh-cn_image_0000001453324334.png?HW-CC-KV=V1&HW-CC-Date=20261008T172858Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C5A52FB88AE3D96593D37E4308084AD5942DD2745A1051C401DD2894ED92AE6 "点击放大")

   样机需求如下表，点击"样机寄送地址"旁边的提示符![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/39/v3/yF5CcxWeQGO8RXNzEEbNyw/zh-cn_image_0000001453484262.png?HW-CC-KV=V1&HW-CC-Date=20261008T172858Z&HW-CC-Expire=31536000000&HW-CC-Sign=5F15843DE56B588DF2CF7E415D3FD4A86DEB1A4B152BA2D945224C4A7DE40DF2)，可以获取投递地址及收件人。

   |样机用途|数量|
   |:--------------------------|:-|
   |小件设备，如：跳绳、体脂秤、血糖仪、血压计、心率设备|2|
   |大件设备，如：跑步机、椭圆机、划船机、智能单车、走步机|1|

   对于跑步机接入，需要提交第三方认证机构进行准入认证。在界面上选择认证机构后（赛西实验室或泰尔实验室），会显示认证机构的联系方式及报价单，可与对应机构联系人进行业务对接。请厂商根据实际需要选定认证机构。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e7/v3/AnUBE98ETVedhTriR_-jcA/zh-cn_image_0000001453164582.png?HW-CC-KV=V1&HW-CC-Date=20261008T172858Z&HW-CC-Expire=31536000000&HW-CC-Sign=337C7C4F80E91D204B7F3F90E34D1B7B28DEBB1023E2C7B2966E31BC2FA7DDAB "点击放大")

4. 提交审核后，等待认证结果。点击图示红框图标可查看审核进度和结果。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a1/v3/vaXdj09hSFu7Sg6VXLr0-g/zh-cn_image_0000001502884353.png?HW-CC-KV=V1&HW-CC-Date=20261008T172858Z&HW-CC-Expire=31536000000&HW-CC-Sign=BEEE5E89593231B24A163A5D818F08A12462483B29B9DB1EF0CA6774878A4A6B "点击放大")
