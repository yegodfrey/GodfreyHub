# 普通场景化示例

#### Fragment可视化埋点

#### [h2]应用场景

对于使用Fragment组件的Android App，可以参照如下操作，将一小段代码添加至您的App代码中，再通过可视化点击的方式添加埋点事件。这样，当App用户自定义页签顺序时，您的埋点位置也不会随之改变。

#### [h2]操作步骤

      1. 在创建Fragment时添加value。
             
             Fragment fragment = new Fragment();
                 Bundle bundle = new Bundle();
                 // value值为非空字符串，即当您在创建Fragment时，通过Fragment的setArguments方法，向Bundle中添加key值为“DTM_FRAGMENT_TAG”的value。
                 bundle.putString("DTM_FRAGMENT_TAG","value");
                 fragment.setArguments(bundle);

      2. （可选）在您的App的Fragment组件代码中，覆写onResume方法，添加如下代码：

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/E0vt__mkSI695-tNRl7HGg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=6D5B4CB649B8028D576C173C5A9D43885A1ABE8C6B19B050902FAA1BF88AE758)

若您集成了DTM插件，可忽略该步骤，详情请参见[（可选）集成DTM插件](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-sdk-0000001050041968#section39741922104616)。
             
             @Override
                 public void onResume() {
                     super.onResume();
                     if (getView() != null && getArguments() != null) {
                         // value值为非空字符串，通过步骤1设置。
                         String value = getArguments().getString("DTM_FRAGMENT_TAG");
                         // getView().setTag中的key值固定为0xffff0000，不可更改。
                         getView().setTag(0xffff0000,value);
                     }
                 }

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a8/v3/oIds-HBGRhSwUn2RWJUUHA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=6125DADBF68EC0A279932E0E1A5D1BF3C5EE218AB08AE9C65389A99597019869)

为提高埋点准确度，相同Fragment实例中的value值需保持唯一。

      3. 在DTM页面，选择“可视化埋点”页签，进入可视化埋点扫码页面。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/kmaQzfG5QLaJmdZmZcQyXA/zh-cn_image_0000001133009661.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=AE7902500E3CEC08836124AB596EC274D3D4235FF4E01D0DFE81272682E4A3AC)

      4. 使用手机浏览器扫描二维码，根据提示打开手机App，手机App和DTM页面会同时进入可视化埋点页面，DTM页面显示如下。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a0/v3/Vn0YAitMRYScA2HD5oT8Kg/zh-cn_image_0000001090335437.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=BF22A28B0F6BC85E8438907DAD50FDD6A88DEDD6254F15F87B2363ED5A5357D9)

      5. 在DTM可视化埋点页面右侧有“显示可圈选组件”开关，打开后会以红色框展示出可添加埋点的组件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cd/v3/1_AxrwuESjGhRyciFCEZKg/zh-cn_image_0000001077744038.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=0D47A4892EBAEEE83FD1931A735921FDE968272CE2062FCC9A0A9B585C1EE2CE)

      6. 您可以选中可埋点组件添加元素埋点。选中可埋点组件时，控件会以黄色框覆盖该组件。

         1. 点击可埋点组件，在弹出的“添加埋点”提示框中选择埋点类型，输入埋点名称，点击“确定”添加埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/05/v3/nYCS0444S5KmLswP_8fegQ/zh-cn_image_0000001090179485.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=298518A2DA662DA0DFBC67B20901DB7F6CDF6131F23315998D6FEC44B8FD2025)

         2. 添加成功后，在页面右侧的“元素埋点（可用）”页签下展示出已添加的埋点，已添加埋点的组件会以绿色框展示。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/lEUBuqXBTiKBa5D1umLvyA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=CB3456C6A7FA592DF70F58FBC910A881184ED098E28911FD06930654C455DB34)

埋点可选类型有“当前位置”、“同类元素”和“相同文字”三种类型。

            * 当前位置：只对当前位置的组件有效。
            * 同类元素：即选中元素的某一个就近的父节点内，存在结构、ID或类名一致的元素。适用于ListView、GridView、RecyclerView、ViewPager等同类元素组件。例如商品列表等，点击列表中的任何一个同类元素都会触发该埋点。
            * 相同文字：只对相同文字的组件有效。

本章节以同类元素埋点操作进行说明。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/dVKLbUTXRyW3IkjI2AUU_w/zh-cn_image_0000001090134211.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=DFD32757E5F3B586785DAE4CFBC9EBB4BF9DDF3E8ED94E298B78D4343D0255C7)

      7. 点击已创建埋点右侧对应的按钮，可对已创建的埋点进行预览、编辑、删除和添加参数。
      8. 选择当前页面的组件作为埋点的参数，在弹出的输入框中填入“参数名”。

参数与埋点存在绑定关系，如果代码的触发条件选择为可视化埋点类型，则可以引用该埋点下添加的参数，事件上报时会获取被引用参数组件对应的值上报分析平台。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e4/v3/JUIuB_55TiG6p4-6_sNrjQ/zh-cn_image_0000001077295994.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=41BBDD27E7530CCFF0F1E4B46866F30C36D339A6D9DDAC588BDDD5ECC774CDE5)

      9. 完成埋点创建后，您需要将可视化埋点配置为代码触发条件以使埋点生效，此时您可以参见[代码](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-tag-management-0000001056773833)、[版本](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/android-version-management-0000001056603541)完成最后的版本并发布。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4e/v3/SuYq-1oMQ5-fRE879dM6Xg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=94B0BE19F979449BBA15E23543FC4C61CA5A29FAB61F8B19CED6974BB1251404)

建代码时触发条件若选择为可视化埋点，页面会自动将该埋点的参数添加至代码自定义参数列表中（如果代码支持自定义参数），同时您可以对参数引用进行手动调整。

#### 网页可视化埋点

DTM支持Android应用中网页的普通可视化埋点。

      1. 在AGC侧选择“可视化埋点”页签，进入可视化埋点扫码页面。
      2. 使用手机浏览器扫描二维码，根据提示打开手机App进入网页页面，手机端应用和DTM界面将会同时进入可视化埋点页面。
      3. 在DTM界面的可视化埋点页面右侧有“显示可圈选组件”开关，打开后会以红色框展示出网页中可添加埋点的组件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c7/v3/EYTT3hh9R3mIsOx1lzHRdg/zh-cn_image_0000001145725709.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=38E2597EDB222193480563638C97F592762AD56590D10F1DB81FA5C4F331A0CF)

      4. （可选）添加页面埋点。该“页面埋点”是针对进入App页面的埋点，只能添加一个。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/29vYu_xBS_uscKxvIyzuFw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=E39EFE2BAA1BA795FA4EA0342749652471DBA957DD86A967E455C78486A16819)

当进入含WebView的App页面时，可以添加页面埋点，其参数只能选择native组件。

         1. 点击“页面埋点”页签下的“添加埋点”，在弹出的“添加埋点”输入框中填入埋点名称，点击“确定”添加埋点。
         2. 添加成功后，您可以在页面右侧的“页面埋点”页签下查看已添加的埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/51/v3/LvHDsdLFT26crVQOtXzQog/zh-cn_image_0000001145727755.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=40117150CDE19990A918AC79109009D6613C97A7208056FAAD3211B645624EFA)

      5. 添加元素埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ed/v3/6Bx3gvYGQtq6Wb-yHeEpoQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=7B4B28B62DCF227DCB021FE6D126BBBE4C59610E6056C71A206DE7F9FE59308E)

当进入含WebView的App页面时，若您添加native组件作为元素埋点，只能选择native组件作为参数，不可选择WebView元素；若您添加WebView元素作为元素埋点，只能选择WebView元素作为参数，不可选择native组件。

         1. 点击可埋点元素，在弹出的“添加埋点”提示框中选择埋点类型，输入“埋点名称”，设置触发条件，点击“确定”添加埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/r_LkqknCSpO3qsaDYwXxjA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=8446C5ACECFAE35F4E15028CB457107DDF857791557304122B01379C8F7E980D)

WebView埋点可选类型有“当前位置”和“同类元素”。

            * 当前位置：只对当前位置的元素有效。
            * 同类元素：即选中元素的某一个就近的父节点内，存在结构、ID或类名一致的元素。适用于列表类的同类元素。例如商品列表等，点击列表中的任何一个同类元素都会触发该埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/uDGXYQbvQXCPrXiwHwqHzQ/zh-cn_image_0000001134184991.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=0880D6613337455982B1414FB8E652A0F81A9D31F51026F56CBD1206639EEF8B)

         2. 添加成功后，在页面右侧的“元素埋点（可用）”页签下展示出已添加的埋点。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/79/v3/suCjml6eSZWLIH4UVglzZA/zh-cn_image_0000001086979200.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=5D76562685E21CAFAEC4D91DB3ADB0F99E27174C3E44821F65FB2CA09E868F0E)

      6. （可选）对于已添加的埋点，您可以根据需要，通过埋点名称后面的按钮，进行预览、编辑、删除、添加参数及查看详情等相关操作。

通过点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/X-s9_g3pQIeLOZ_ONZOIIA/zh-cn_image_0000001138320829.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=BDFDD00EA922CF09DA5A3F7F80CF370563681EDCC1D47BCFF133E916E095C4AF)按钮，您可以修改埋点名称，但不能修改埋点类型。点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/H_uhoY3PRzCnalr6AL08Kg/zh-cn_image_0000001091501842.png?HW-CC-KV=V1&HW-CC-Date=20261005T042954Z&HW-CC-Expire=86400&HW-CC-Sign=0CD558F6661170E8033491E5137770A734D7C8D4B7F0A9A4B99AC7F2A33568CE)按钮，可以为当前埋点添加参数。
