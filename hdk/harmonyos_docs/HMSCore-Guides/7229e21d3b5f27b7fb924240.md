# 日常活动数据

此数据记录用户每天的日常活动统计。该统计包含了用户每天的统计数据（步数，活动热量，锻炼时长，活动小时数）以及用户每天的日常活动的目标值（步数目标，活动热量目标，锻炼时长目标，活动小时数目标）。  
![](https://media:901788166652192168)  
日常活动统计接口能力在运动健康App 14.0.8.300及以上版本支持调用。  

#### OAuth权限

联盟卡片申请的权限名称：日常活动\> 日常活动数据

* 读权限：https://www.huawei.com/healthkit/dailyactivitysummary.read  

#### 原子采样统计数据类型

* 名称：com.huawei.daily_activity_summary

|字段列表|字段描述|类型|可选/必选|单位|取值范围|
|:-----------------|:------|:--|:----|:-|:---|
|steps|步数统计|int|M|步|-|
|activeCalories|活动热量统计|int|M|千卡|-|
|exerciseTime|锻炼时长统计|int|M|分钟|-|
|activeHours|活动小时数统计|int|M|次数|-|
|stepsGoal|步数目标|int|M|步|-|
|activeCaloriesGoal|活动热量目标|int|M|千卡|-|
|exerciseTimeGoal|锻炼时长目标|int|M|分钟|-|
|activeHoursGoal|活动小时数目标|int|M|次数|-|
