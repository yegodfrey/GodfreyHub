# 业务简介

为H5网页接入华为支付服务提供快捷的支付体验和简单的接入流程。开发者的网页通过拉起华为支付中转界面实现调起华为支付服务收银台。  

#### 支持的设备

|---------------|----------------------------------------|---------------------|
|设备类型|OS版本|支持的HMSCore版本|
|华为手机（Android）|EMUI8.0或者Android 8.0及以上（API Level 26及以上）|HMSCore 6.11.0.300及以上|
|华为手机（HarmonyOS）|HarmonyOS 2.0及以上|HMSCore 6.11.0.300及以上|
