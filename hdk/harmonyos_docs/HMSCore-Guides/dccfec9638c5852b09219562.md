# 添加权限

（可选）想要使用后台定位功能，需要开启"Capabilities > Back > ground Modes"下的"Location updates"。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3b/v3/pijXbQD7TwyGY8FvppyMsQ/zh-cn_image_0000001248744595.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=C1E14FE6F2B504FB9A9FCF5DDF6F493AC6F86D7807977C4BB615738DEB2E741B "点击放大")

**iOS 11及以上版本：**

（可选）想要使用"我的位置"按钮功能，定位到当前位置，可以根据需要，选择添加如下权限：

* "NSLocationWhenInUseUsageDescription"：表示应用在前台的时候可以获取到位置信息。
* "NSLocationAlwaysAndWhenInUseUsageDescription" ：申请Always权限，以便应用在前台和后台（suspend或terminated）都可以获取到位置信息。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e3/v3/3HRMGj5ZSzOdFF5DSqfJSQ/zh-cn_image_0000001242644693.png?HW-CC-KV=V1&HW-CC-Date=20260922T085431Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB4CD90FD67F1F27BDFDEDE5D0CB341724291988C81090831BFB478636CB6543 "点击放大")
> 说明
>
> 如果您的应用需要使用定位功能，请在plist文件中同时添加"NSLocationWhenInUseUsageDescription"、"NSLocationAlwaysUsageDescription"和"NSLocationAlwaysAndWhenInUseUsageDescription"权限声明。具体操作步骤如下：
>
> ```screen
> <key>NSLocationWhenInUseUsageDescription</key>
> <string>APP需要定位权限才可以正常使用</string>
> <key>NSLocationAlwaysUsageDescription</key>
> <string>APP需要定位权限才可以使用</string>
> <key>NSLocationAlwaysAndWhenInUseUsageDescription</key>
> <string>APP需要定位权限才可以正常使用，如果您需要使用后台定位功能请选择"始终允许"</string>
> ```
